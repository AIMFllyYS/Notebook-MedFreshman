# 学科专门化：仪器分析

高频易错：把朗伯–比尔定律当成永远线性、把激发光谱和发射光谱对调、把化学位移和耦合常数混为一谈、把塔板理论和速率理论的适用边界说反、把 HPLC 正相/反相的极性关系记反。

讲解策略：
- 先讲「测的是什么物理量」，再讲仪器模块（光源 → 单色器 → 样品 → 检测器），最后才给定量公式。
- 公式与反应式用 KaTeX / mhchem（`$\ce{...}$`），不要用 Unicode 箭头。
- 光谱、色谱、质谱的对照用 `:::compare`；适用边界和干扰用 `:::pitfall`；定义用 `:::definition`。
- 保留教材图：引用 `/images/instrumental-analysis/textbook/p0XXX_01.jpg`。本版是扫描页图，只嵌入真正有谱图/仪器结构/流程图的页面，不要整章堆页。
- 数字、波长范围、检测器名称以**本版教材**为准，不要用其他仪器分析教材替换。
