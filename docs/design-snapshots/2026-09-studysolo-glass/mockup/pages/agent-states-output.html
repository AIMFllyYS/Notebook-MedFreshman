样本空间与事件

我们把一次随机试验所有可能结果组成的集合称为样本空间，记作 Ω 。例如掷一枚均匀骰子，可能出现 1 至 6 点，于是 Ω={1,2,3,4,5,6}；而「出现偶数」就是其中的一个事件 A={2,4,6}

03 · Markdown 全集

两种表示

  • 列举法：直接写出全部基本结果，如 Ω={1,2,3,4,5,6}
  • 描述法：用成员满足的条件来刻画，如 Ω={x | x 为骰子朝上的点数}

求解三步

  1. 明确随机试验：掷一次均匀骰子；
  2. 列出所有两两互斥的结果：1 点到 6 点；
  3. 写成集合形式，即得到样本空间 Ω。

注意：事件是样本空间的子集，而不是元素本身。

掷骰子时六个面等可能出现，因此可以直接写成 Ω={1,2,3,4,5,6}，而事件 A 只是它的一个子集。

运算记号含义

互斥A∩B=∅A 与 B 不可能同时发生
对立AᶜA 不发生，且 Aᶜ=Ω\A
05 · 代码块

用一段 Python 模拟掷骰子，并统计事件 A=出现偶数 的频率：

dice.py 
1# 模拟掷一枚均匀骰子
2import random
3
4def roll_dice(n=600):
5    counts = {k: 0 for k in range(1, 7)}
6    for _ in range(n):
7        face = random.randint(1, 6)
8        counts[face] += 1
9    return counts
10
11A = {2, 4, 6}
12data = roll_dice()
13p = sum(data[k] for k in A) / 600
14print(f"P(A) = {p:.3f}")
06 · 数学公式

在古典概型下，每个基本结果出现的机会相等。例如事件 A=出现偶数，共有 3 个有利结果，行内公式写作 P(A)=|A|/|Ω|=3/6=1/2。

P(A) = ( n∑k=1 Ik ) / n

09 · 结构化卡片
核心概念
定义

样本空间 Ω 是随机试验全部可能结果组成的集合；事件 A 是 Ω 的子集。

公式
P(A)=|A|/|Ω| 0 ≤ P(A) ≤ 1 A ⊆ Ω
例子

掷一枚均匀骰子：Ω={1,2,3,4,5,6}，事件「出现偶数点」A={2,4,6}。

随堂练习

掷一枚均匀骰子，事件 A=出现偶数，求 P(A)。

偶数有 2、4、6 共 3 个，而样本空间 Ω 包含 6 个等可能的基本结果，因此 P(A)=3/6=1/2，选 C。
