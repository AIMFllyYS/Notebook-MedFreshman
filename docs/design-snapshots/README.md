# docs/design-snapshots

设计探索快照存档区。

这里存放阶段性的设计系统 / 设计稿快照，**仅作历史记录保留，不是项目的设计规范，也不是开发实现的参考依据**。

与 `docs/archive/` 的区别：

- `docs/archive/`：从仓库跟踪中移除的历史材料。
- `docs/design-snapshots/`：仍被 git 跟踪的设计快照，但对应体系尚未成熟、未被产品采纳，不允许新开发直接照搬。

## 使用约定

- 快照内的令牌、组件、页面结构均为当时的探索结论，可能与现行产品完全不一致。
- 新功能设计与前端开发前，请先确认当前生效的设计规范，不要引用本目录内容。
- 每个快照以 `YYYY-MM-<名称>/` 为目录，目录内 README 记录其来源与状态；快照内容原则上只读，不再回改。
