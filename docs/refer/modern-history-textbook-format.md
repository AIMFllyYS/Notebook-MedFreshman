# 近现代史纲要教材 Markdown 结构化格式规范

本文档定义 `content/modern-history/textbook/` 下教材 Markdown 文件的结构化渲染规范。目标是将纯文本墙转化为**可快速定位、可记忆、可测验**的知识块。

## 1. 设计原则

- **史实不变**：不增删、不篡改教材原文的历史事实和观点。
- **呈现分层**：时间轴、概念、事件、结论、必背清单分层展示。
- **机器可读**：使用 Markdown 容器指令，统一由 `remarkDirectives` 解析并渲染为 React 组件。
- **学习友好**：每节提供时间轴、核心结论、必背要点，便于复习与抽测。

## 2. 通用指令

所有指令均为 Markdown 容器指令（`:::directive{attr=value}` ... `:::`）。

### 2.1 timeline（时间轴）

用于章节概览，将关键时间线呈现为时间轴组件。

```markdown
:::timeline{period=本章概览}
- **1840** 鸦片战争——中国近代史开端
- **1842** 《南京条约》——开始沦为半殖民地半封建社会
- **1919** 五四运动——旧民主主义革命向新民主主义革命转变
- **1949** 新中国成立——结束半殖民地半封建社会
:::
```

- `period`：时间轴标题，通常填“本章概览”或具体历史阶段名。
- 列表项使用 `**年份** 事件——意义` 的格式，便于提取和记忆。

### 2.2 eventcard（事件卡）

用于突出单一重大事件，包含时间、地点、人物、意义。

```markdown
:::eventcard{title=武昌起义 date=1911.10.10 place=武昌 significance=辛亥革命高潮}
1911 年 10 月 10 日晚，湖北新军工程第八营的革命党人率先起义，一夜之间占领武昌城，成立湖北军政府。武昌起义掀起了辛亥革命的高潮，打开了清王朝统治的缺口。
:::
```

- `title`：事件名称。
- `date`：发生时间。
- `place`：发生地点。
- `significance`：一句话意义，用于快速定位。

### 2.3 conceptcard（概念卡）

用于定义关键概念，渲染为概念卡片。

```markdown
:::conceptcard{term=半殖民地半封建社会}
近代中国的一种特殊社会形态：形式上保持独立，但主权被帝国主义控制；封建经济逐步解体，资本主义因素有所发展但未能成为主要形式。
:::
```

- `term`：概念名称，正文给出定义或阐释。

### 2.4 comparetable（对比表）

用于对比两个或多个对象，如新旧民主主义革命、不同方案等。

```markdown
:::comparetable{title=新旧民主主义革命对比 headers=旧民主主义革命|新民主主义革命}
- 领导阶级 | 资产阶级 | 无产阶级
- 革命前途 | 资本主义 | 社会主义
- 所属范畴 | 世界资产阶级革命一部分 | 世界无产阶级革命一部分
:::
```

- `title`：表格标题。
- `headers`：用 `|` 分隔的表头。
- 每一行用 `|` 分隔单元格内容。

### 2.5 causeeffect（因果链）

用于展示因果关系，适合“原因—结果”分析。

```markdown
:::causeeffect{title=鸦片战争爆发的原因与结果}
- 原因：英国为扭转对华贸易逆差，向中国走私鸦片；清政府禁烟运动损害英国利益。
- 结果：清政府战败，签订《南京条约》，中国开始沦为半殖民地半封建社会。
:::
```

### 2.6 keypoint（重点框）

用于突出核心结论或考试重点。

```markdown
:::keypoint{label=核心结论}
近代中国半殖民地半封建社会的性质，决定了反帝反封建的民主革命是历史发展的必然要求。
:::
```

- `label`：标签，如“核心结论”“考试重点”“易错提醒”。

### 2.7 historymap（历史地图）

用于展示历史地理信息，如条约割让区域、势力范围等。

```markdown
:::historymap{title=《南京条约》开放的五口通商口岸 regions=广州|厦门|福州|宁波|上海 note=清政府被迫开放东南沿海五处为通商口岸，打破闭关政策}
1842 年《南京条约》规定开放广州、厦门、福州、宁波、上海五处港口城市为通商口岸，中国闭关政策被打破。
:::
```

### 2.8 memory（必背清单）

用于每节末尾，列出本节必须记忆的关键点。

```markdown
:::memory{label=本节必背要点}
- 鸦片战争是中国近代史的开端。
- 中国近代史从 1840 年鸦片战争到 1949 年新中国成立。
- 近代中国社会性质是半殖民地半封建社会。
- 近代中国主要矛盾是帝国主义和中华民族的矛盾、封建主义和人民大众的矛盾。
- 近代中国两大历史任务：民族独立、人民解放；国家富强、人民幸福。
:::
```

## 3. 章节结构约定

每节 Markdown 建议按以下顺序组织：

1. **H1 标题**：如 `# （一）鸦片战争前后的中国与世界`
2. **timeline**：章节概览时间轴。
3. **正文段落**：保留教材原文，适当分段。
4. **conceptcard / eventcard**：在关键概念或事件首次出现处插入。
5. **comparetable / causeeffect**：在需要对比或分析因果的段落插入。
6. **keypoint**：在章节末尾或重要结论处插入。
7. **memory**：每节末尾固定放置必背清单。

## 4. 示例片段

### 4.1 鸦片战争章节

```markdown
# （一）鸦片战争前后的中国与世界

:::timeline{period=本章概览}
- **1840** 鸦片战争——中国近代史开端
- **1842** 中英《南京条约》——中国开始沦为半殖民地半封建社会
- **1844** 中美《望厦条约》、中法《黄埔条约》——列强侵略特权扩大
:::

:::conceptcard{term=中国封建社会}
以封建地主土地所有制为基础、高度中央集权的封建君主专制制度为政治特征、儒家思想为正统意识形态的社会形态。
:::

鸦片战争前的中国是一个拥有几千年历史的文明古国。但在鸦片战争后，中国逐步沦为半殖民地半封建社会。

:::keypoint{label=核心结论}
鸦片战争是中国近代史的开端，从此中国开始丧失完整主权，社会性质发生根本变化。
:::

:::memory{label=本节必背要点}
- 鸦片战争是中国近代史的开端。
- 1842 年《南京条约》是中国近代史上第一个不平等条约。
- 鸦片战争后，中国开始沦为半殖民地半封建社会。
:::
```

### 4.2 辛亥革命章节

```markdown
# （二）辛亥革命与中华民国的建立

:::timeline{period=辛亥革命大事记}
- **1911.10.10** 武昌起义——辛亥革命高潮
- **1912.1.1** 中华民国成立——孙中山任临时大总统
- **1912.2.12** 清帝退位——封建君主专制制度终结
- **1912.3** 《中华民国临时约法》颁布——第一部资产阶级共和国宪法性质法典
:::

:::eventcard{title=武昌起义 date=1911.10.10 place=武昌 significance=辛亥革命高潮}
1911 年 10 月 10 日晚，湖北新军工程第八营的革命党人率先起义，一夜之间占领武昌城。武昌起义掀起了辛亥革命的高潮。
:::

:::comparetable{title=辛亥革命成功与失败之处 headers=成功|失败}
- 政治制度 | 推翻两千多年封建君主专制 | 未能改变半殖民地半封建社会性质
- 思想启蒙 | 民主共和观念深入人心 | 未彻底反帝反封建
- 经济发展 | 有利于民族资本主义发展 | 未解决土地问题
:::

:::memory{label=本节必背要点}
- 1911 年武昌起义是辛亥革命的高潮。
- 1912 年 1 月 1 日中华民国成立。
- 《中华民国临时约法》是中国历史上第一部资产阶级共和国宪法性质的法典。
- 辛亥革命是一次比较完全意义上的资产阶级民主革命。
:::
```

## 5. 批量改写脚本

`scripts/one-off/transform-modern-history-textbook.py` 提供批量改写能力，为每节自动添加：

- 章节概览时间轴
- 核心概念卡片（按内置章节配置）
- 章节末尾核心结论 keypoint
- 每节必背 memory 清单

运行方式：

```bash
python scripts/one-off/transform-modern-history-textbook.py
```

脚本会跳过已包含 `::timeline` 或 `::memory` 的文件（如已手动精修的样章）。

## 6. 校验清单

提交教材 Markdown 改动前，请确认：

- [ ] 每节均包含 `::timeline` 和 `::memory`。
- [ ] 关键概念已使用 `::conceptcard` 或 `::keypoint` 突出。
- [ ] 对比/因果内容优先使用 `::comparetable` 或 `::causeeffect`。
- [ ] 历史事实与教材原文一致，未增删内容。
- [ ] 运行 `pnpm build` 与 `pnpm test` 通过。
