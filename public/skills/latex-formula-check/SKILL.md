# LaTeX 公式检查

当任务涉及在笔记、卡片或回答中写入数学/化学公式时，按以下清单自查后再输出。

## 渲染环境

本应用用 **KaTeX** 渲染公式。KaTeX 覆盖常见数学命令，但**不含** mhchem 等宏包。

## 检查清单

1. **定界符配对**：行内 `$...$` 或 `\(...\)`，独立行 `$$...$$` 或 `\[...\]`——每个开符号必须有对应闭符号，且成对出现在同一行/同一段。
2. **命令合法性**：只写 KaTeX 支持的命令（`\frac \sqrt \sum \int \partial \alpha \beta \cdot \times \leq \geq \rightarrow` 等）。不支持的宏包命令要换写法：
   - `\ce{H2O}` → 写 `$\mathrm{H_2O}$` 或纯文本 `H₂O`
   - `\pu{mol/L}` → `$\mathrm{mol/L}$`
   - `\begin{cases}` 可用；`\begin{align}` 需用 `\begin{aligned}` 替代
3. **下标/上标**：多个字符必须加花括号——`x_10` 是错的（只下标了 1），应写 `x_{10}`。
4. **中文与公式混排**：中文说明放在公式外或 `\text{…}` 内，不要直接裸写在 `$…$` 里（会挤在一起且字体错误）。
5. **百分号与特殊字符**：公式内 `%` 要写 `\%`，`#` 写 `\#`，`&` 写 `\&`。
6. **函数名正体**：`\sin \cos \ln \log` 等用命令而不是直接敲字母（`sin` 会变斜体连乘）。

## 输出约定

- 发现问题时：先给修正后的整段公式，再列「问题 → 改法」的对应表，不要只口头描述。
- 没有问题也要一句话确认「公式写法可在 KaTeX 下正常渲染」。
- 拿不准某个命令是否被支持时，选更保守的等价写法，并在末尾标注「该写法为保守替代」。
