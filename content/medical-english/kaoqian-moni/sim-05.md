## 一、阅读理解（本页仅第 54–55 题）

### 第 54 题

:::callout{kind="note" label="题目"}
To knowingly allow oneself to pursue unhealthy habits is compared by Fries and Crapo to ______.

A. deliberately ending one's life
B. improving the quality of one's life
C. limiting one's personal health choice
D. breaking the rules of social behaviour
:::

:::callout{kind="insight" label="解析"}
**【答案】**A（据课文推断）

Fries & Crapo 把明知故犯地维持不健康习惯比作慢性自毁，即 deliberately ending one's life（慢性自杀）。B 与原意相反；C/D 不是他们的比喻。
:::

:::callout{kind="note" label="知识卡片：Fries and Crapo"}
| 命题 | 课文立场 |
|------|----------|
| 不健康习惯 | 近于故意结束生命 |
| 健康选择依据 | statistical evidence，而非朋友看法或法律 |
| 个人选择 | 重要，但受知识、同伴、环境等多因素影响 |
:::

:::callout{kind="tip" label="结论速记"}
明知故犯的不健康习惯 ≈ **deliberately ending one's life**。
:::

### 第 55 题

:::callout{kind="note" label="题目"}
According to Fries and Crapo sound health choices should be based on ______.

A. personal decisions
B. statistical evidence
C. Friends' opinions
D. society's laws
:::

:::callout{kind="insight" label="解析"}
**【答案】**B（据课文推断）

sound health choices 应建立在统计证据上，而不是个人拍板、朋友意见或社会法律。A 是「选择由谁做」，不是「依据什么」。
:::

:::callout{kind="pitfall" label="易错警示"}
personal decisions 看起来像「个人选择很重要」，但题干是 based on（依据），应选 **statistical evidence**。
:::

:::callout{kind="note" label="知识卡片：选择的依据"}
Fries & Crapo：sound health choices based on statistical evidence，不是朋友意见或法律。
:::

:::callout{kind="tip" label="结论速记"}
Fries & Crapo：健康选择依据 **statistical evidence**。
:::

## 二、Part III Combining Forms（10%）

Directions: From answers marked A, B, C, and D, choose the one that is fit in meaning for the numbered parts.

### 第 56 题

:::callout{kind="note" label="题目"}
laryngo-

A. stomach　　B. throat　　C. mouth　　D. kidney
:::

:::callout{kind="insight" label="解析"}
**【答案】**B（据词根推断）

laryngo- = larynx / throat。stomach = gastro-，mouth = stomato-，kidney = nephro-。
:::

:::callout{kind="note" label="知识卡片：喉"}
laryngitis 喉炎，laryngoscopy 喉镜检查，laryngectomy 喉切除。
:::

:::callout{kind="tip" label="结论速记"}
laryngo- = **throat**。
:::

### 第 57 题

:::callout{kind="note" label="题目"}
masto-

A. liver　　B. lung　　C. breast　　D. intestine
:::

:::callout{kind="insight" label="解析"}
**【答案】**C（据词根推断）

masto- = breast（与 mammo- 竞争形式）。liver = hepato-，lung = pneumo-/pulmo-，intestine = entero-。
:::

:::callout{kind="note" label="知识卡片：乳房竞争形式"}
masto- 与 mammo- 都是 breast。hepato- 肝，pneumo- 肺，entero- 肠。
:::

:::callout{kind="tip" label="结论速记"}
masto- = **breast**。
:::

---

### 第 58 题

:::callout{kind="note" label="题目"}
-ectomy

A. tying　　B. cutting　　C. outlet-forming　　D. cutting out
:::

:::callout{kind="insight" label="解析"}
**【答案】**D（据词根推断）

-ectomy = cutting out / excision。cutting 更近 -tomy；outlet-forming 是 -stomy；tying 近 -desis 或结扎。
:::

:::callout{kind="note" label="知识卡片：-tomy 家族"}
| 后缀 | 意义 |
|------|------|
| -tomy | 切开 |
| -ectomy | 切除 |
| -stomy | 造口 |
:::

:::callout{kind="tip" label="结论速记"}
-ectomy = **cutting out**，不是单纯 cutting。
:::

### 第 59 题

:::callout{kind="note" label="题目"}
ecto-

A. outside　　B. inside　　C. between　　D. through
:::

:::callout{kind="insight" label="解析"}
**【答案】**A（据词根推断）

ecto- = outside / outer。inside = endo-，between = meso-，through = dia-。例：ectoderm 外胚层，ectopic 异位。
:::

:::callout{kind="note" label="知识卡片：ecto- / endo-"}
ecto- 外（ectoderm, ectopic）；endo- 内；meso- 中；dia- 穿过。
:::

:::callout{kind="tip" label="结论速记"}
ecto- = **outside**。
:::

### 第 60 题

:::callout{kind="note" label="题目"}
chromo-

A. color　　B. time　　C. form　　D. origination
:::

:::callout{kind="insight" label="解析"}
**【答案】**A（据词根推断）

chromo- = color。time = chrono-，form = morpho-，origination 近 -genesis。chromosome 本义「可染色小体」。
:::

:::callout{kind="pitfall" label="易错警示"}
chromo-（色）与 chrono-（时）只差一个字母。
:::

:::callout{kind="note" label="知识卡片：chromo- 本义"}
chromo- = color。chromosome 原义「可染色小体」。chrono- 才是时间。
:::

:::callout{kind="tip" label="结论速记"}
chromo- = **color**。
:::

### 第 61 题

:::callout{kind="note" label="题目"}
fixing

A. -pexy　　B. -plasty　　C. -plasia　　D. -rrhaphy
:::

:::callout{kind="insight" label="解析"}
**【答案】**A（据词根推断）

-pexy = surgical fixation。-plasty 成形，-plasia 发育/形成，-rrhaphy 缝合。
:::

:::callout{kind="note" label="知识卡片：成形 vs 固定 vs 缝合"}
| 后缀 | 意义 | 例词 |
|------|------|------|
| -pexy | 固定 | mastopexy, nephropexy |
| -plasty | 成形 | mammoplasty |
| -plasia | 发育 | hyperplasia |
| -rrhaphy | 缝合 | tenorrhaphy |
:::

:::callout{kind="tip" label="结论速记"}
fixing → **-pexy**。
:::

### 第 62 题

:::callout{kind="note" label="题目"}
gland

A. cardio-　　B. myelo-　　C. spleno-　　D. adeno-
:::

:::callout{kind="insight" label="解析"}
**【答案】**D（据词根推断）

adeno- = gland。cardio- 心，myelo- 骨髓/脊髓，spleno- 脾（脾是器官，不是「腺」的通用词根）。
:::

:::callout{kind="note" label="知识卡片：腺"}
adeno- = gland（adenoma, adenitis）。spleno- 是脾这一器官，不是「腺」的通用根。
:::

:::callout{kind="tip" label="结论速记"}
gland → **adeno-**。
:::

### 第 63 题

:::callout{kind="note" label="题目"}
sweet

A. proteo-　　B. chole-　　C. lipo-　　D. glycol-
:::

:::callout{kind="insight" label="解析"}
**【答案】**D（据词根推断）

glycol- / gluco- = sweet / sugar。proteo- 蛋白，chole- 胆汁，lipo- 脂肪。
:::

:::callout{kind="note" label="知识卡片：甜/糖"}
glycol-/gluco- = sweet/sugar。chole- 胆汁，lipo- 脂，proteo- 蛋白。
:::

:::callout{kind="tip" label="结论速记"}
sweet → **glycol-**。
:::

### 第 64 题

:::callout{kind="note" label="题目"}
between

A. endo-　　B. retro-　　C. meso-　　D. dia-
:::

:::callout{kind="insight" label="解析"}
**【答案】**C（据词根推断）

meso- = middle / between。endo- 内，retro- 后，dia- 穿过。mesocolon、mesencephalon。
:::

:::callout{kind="note" label="知识卡片：between"}
meso- = between/middle。dia- = through。mesocolon、mesencephalon。
:::

:::callout{kind="tip" label="结论速记"}
between → **meso-**。
:::

### 第 65 题

:::callout{kind="note" label="题目"}
skin

A. necro-　　B. dermato-　　C. gastro-　　D. cysto-
:::

:::callout{kind="insight" label="解析"}
**【答案】**B（据词根推断）

dermato- / dermo- = skin。necro- 死，gastro- 胃，cysto- 膀胱/囊。
:::

:::callout{kind="note" label="知识卡片：皮肤"}
dermato-/dermo-/cutane- = skin。necro- 死，gastro- 胃，cysto- 囊/膀胱。
:::

:::callout{kind="tip" label="结论速记"}
skin → **dermato-**。
:::
