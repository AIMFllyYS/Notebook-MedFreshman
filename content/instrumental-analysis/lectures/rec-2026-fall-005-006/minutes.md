## 二、核心知识点

### 2.1 检出限

**空白信号基础**：
- 无待测组分的纯溶剂检测出的信号偏差属于**系统误差**
- 叠加**随机误差**后信号在基准值上下波动

**信号检出限**：
- 通用规则：取**空白标准偏差的3倍**
- 不同检测方法可调整为2倍等其他数值

**浓度检出限换算**：
- 校准曲线表达式：**Y = A + S·C**
  - Y = 检测信号（纵坐标）
  - C = 待测物浓度（横坐标）
  - A = 截距（背景信号）
  - S = 斜率（方法灵敏度）
- 浓度检出限 = (信号检出限 - 截距A) / 斜率S

**定量限**（了解）：
- 用于待测物的准确定量（区别于仅判断存在的检出限）
- 对应空白标准偏差的**10倍**

### 2.2 试样采集基础概念与原则

**完整实验流程**：采样 → 制样前处理 → 测定 → 数据处理 → 出具报告
- 制样与前处理占整体实验时长的**最大比例**

**核心术语**：

| 术语 | 定义 |
|---|---|
| 总体 | 分析对象的全体 |
| 个体 | 总体内的单个单位 |
| 样本 | 从总体中抽取的代表性个体集合 |
| 样本容量 | 样本包含的个体数量 |

**采样三大原则**：

1. **代表性**（核心，必须掌握）：少量样品的检测结果可代表整批分析对象的整体情况
2. **典型性**：匹配检测目标的特定范围（如检测污染需在污染源附近采样）
3. **事实性**：易变质样品需严格控制采样与检测的时间间隔

**采样方法**：
- **随机采样**：需足够样本量保障代表性
- **系统采样**：按固定规则采样，可减少样本量
- **判断采样**：基于专业判断选择采样点
- 具体参数可查国标

### 2.3 气体样品采集

**高浓度场景**：直接采样法（如早年苹果代工厂正己烷浓度极高，直接采集车间空气）

**低浓度场景**：富集法
- **滤膜阻留**：抽气泵搭配特定孔径滤膜（如PM2.5检测，滤膜抽气24小时富集）
- **固体吸附**：吸附剂管富集
- **低温冷凝**：低温冷凝富集

**PM2.5相关**：
- 滤膜采样可同步检测苯并芘等致癌物
- 我国环境空气质量标准：苯并芘日均值 = 0.0025 μg/m³
- 超标时段与肺癌发病率存在相关性

**气溶胶病毒采集方案**（课堂讨论）：
- 方案一：抽气→选择性透过膜→抗原抗体荧光标记→实时检测
- 方案二：抽气→带溶剂的离心装置富集→送检
- 优化方向：滤膜预筛杂质 + 富集溶剂提前加入灭活成分 + 多病毒并行检测

### 2.4 液体样品采集

**地表水采样垂线**（按河流宽度）：

| 河流宽度 | 采样垂线数 |
|---|---|
| < 50米 | 1条 |
| 50-100米 | 2条 |
| > 100米 | 3条 |

**地表水采样深度**（按水深）：

| 水深 | 采样层 |
|---|---|
| < 5米 | 上层 |
| 5-10米 | 上下两层 |
| > 10米 | 上中下三层 |

> 东湖常规月度监测严格遵循该规范。

**容器选择**：

| 检测目标 | 优先容器 | 原因 |
|---|---|---|
| 金属离子 | 塑料容器 | 避免玻璃容器离子渗出干扰 |
| 有机物 | 玻璃容器 | 避免塑料单体溶出干扰 |

**保存要求**：
- 清洁水样保存时间最长，重污染水样需尽快检测
- **余氯、细菌总数、pH值**需采样后**立即测定**（避免组分挥发或环境干扰）

### 2.5 固体与生物样品采集

**散装粮食采样**：
- 工具：**双螺旋套管采样器**（带凹槽）
- 方法：插入粮堆，通过凹槽采集不同深度样本
- 优点：无需拆封整袋包装即可实现多深度采样

**果蔬样品缩分**：
- 先去除不可食用部分
- **四分法缩分**：取对角线部分样品捣碎后制备待测样
- 国标对各类果蔬采样量有明确规定

**生物试样**：

| 样品类型 | 容器/要求 |
|---|---|
| 尿液、血液 | 聚乙烯、聚丙烯容器或硬质玻璃管 |
| 毛发 | 贴近头皮部分反映近期情况 |
| 唾液 | 同尿液/血液容器要求 |

**活体动物采样（瘦肉精检测）**：
- 家畜瘦肉精检测可采集尿液样本
- 试纸条现场快速筛查
- 现场采样不少于10mL
- **所有样本需备双份**：一份当场检测，一份封存留作阳性复检用（避免争议）

### 2.6 样品保存

**通用保存方式**：
1. **密封**：避免组分挥发和污染
2. **冷藏**：低温抑制微生物活动和化学反应
3. **添加化学防腐剂**：抑制微生物生长

**核心目标**：避免样品组分变质、待测物损失，同时避免引入干扰后续检测的杂质

**特殊保存要求**：
- 检测**易挥发组分**的水样：需将容器**装满至溢流后密封**，避免顶空空间导致待测组分挥发→检测结果偏低

### 2.7 样品预处理

**三大目标**（核心，必须掌握）：
1. 将样品处理为**适配检测的形态**（便于分析）
2. **去除检测干扰组分**（除干扰）
3. **浓缩低浓度待测组分**（浓缩）

**两项关键要求**：
1. 严格避免**待测组分损失**
2. 不得**引入新的干扰物质**

### 2.8 溶解法预处理

- **水溶性组分**：饮料中的色素、苯甲酸、山梨酸等可直接用水溶解
- **常规食品防腐**：高糖、高盐可实现无添加防腐
- **溶剂选择逻辑**：根据待测组分化学性质选择
  - 油脂中的金属离子 → 酸性溶液浸出
  - 有机氯农药残留 → 有机溶剂提取

### 2.9 分解法预处理

**干法灰化**：
- 样品置于坩埚中，**400-700℃**马弗炉高温氧化分解
- 仅剩余无机待测组分
- 优点：无需额外添加试剂
- 适用：不易挥发的待测组分
- 缺点：高温可能导致易挥发组分损失

**低温灰化**：
- 通过射频放电产生**氧自由基**
- **~100℃**即可实现样品氧化分解
- 适用：易挥发待测组分的前处理
- 优点：无需高温，减少挥发损失

**湿法消化**：
- 加入浓硝酸、高氯酸、硫酸等强氧化剂
- 加热条件下分解有机物
- 反应温度由试剂沸点控制，**低于干法灰化温度**
- 适用：易挥发组分
- 优点：温度较低，减少挥发损失

### 2.10 消化液选择与操作安全

**消化液组合规则**：

| 试剂 | 特性 | 作用 |
|---|---|---|
| 硝酸 | 适配易消解样品 | 基础消解 |
| 硫酸 | 高沸点 | 提升反应温度 |
| 高氯酸 | 强氧化性、高沸点 | 强氧化，彻底消解 |

三者组合可适配绝大多数常规样品。

**高氯酸操作安全**：
- 高氯酸接触**酚类、羟基类有机物**易生成易爆物质
- 消解过程**全程不得离人**
- 若发现样品变黑 → 立即停止加热 → 冷却后补加硝酸

**氢氟酸操作安全**：
- 氢氟酸可与骨骼中的钙结合造成**不可逆损伤**（俗称"化骨水"）
- 操作时必须**全程佩戴全套防护用具**，避免直接接触

**实验室通用安全**：
- 常用气罐有固定颜色标识，不认识的气罐不得随意拧动
- 所有加热类实验操作**全程不得离开人**
- "凡是发生事故的，一定有无数个先兆在提醒你，都没有被发现，才会出现事故"

### 2.11 特殊消解技术

**密闭罐消解**：
- 带聚四氟乙烯/聚乙烯内衬的不锈钢密闭罐
- 类似高压锅的高压环境 → 大幅提升消解效率
- 适配氢氟酸等强腐蚀性试剂的使用场景

**微波消解**：
- 微波 = 厘米级波长的交变电场
- 使样品中的极性分子快速转动摩擦生热
- 实现从**分子层面的均匀加热**
- 消解效率远高于常规方法

## 五、主动回忆题

**Q1：如何从信号检出限换算得到浓度检出限？**

A：首先建立校准曲线Y = A + S·C，其中Y为检测信号，C为待测物浓度，A为截距（背景信号），S为斜率（方法灵敏度）。信号检出限通常取空白标准偏差的3倍。将信号检出限代入校准曲线，扣除背景截距A后除以斜率S，即得到浓度检出限：C检出限 = (信号检出限 - A) / S。

**Q2：样品采集的核心原则是什么？地表水采样垂线和采样深度如何确定？**

A：采样的核心原则是**代表性**——少量送检样品的检验结果能代表整批物料。此外还有典型性（匹配检测目标范围）和事实性（易变质样品注意时效性）。地表水采样垂线按河流宽度确定：<50米设1条，50-100米设2条，>100米设3条。采样深度按水深确定：<5米采上层，5-10米采上下两层，>10米采上中下三层。

**Q3：干法灰化、低温灰化和湿法消化三种分解法各有什么特点和适用范围？**

A：干法灰化在400-700℃马弗炉中高温氧化分解，无需额外试剂，适用于不易挥发的待测组分，但高温可能导致易挥发组分损失。低温灰化通过射频放电产生氧自由基，在约100℃即可氧化分解，适用于易挥发待测组分。湿法消化加入浓硝酸、高氯酸、硫酸等强氧化剂，加热分解有机物，反应温度由试剂沸点控制（低于干法灰化温度），也适用于易挥发组分，温度较低可减少挥发损失。

**Q4：样品预处理的三大目标和两项关键要求是什么？为什么高氯酸和氢氟酸操作需要特别注意安全？**

A：预处理三大目标：①将样品处理为适配检测的形态（便于分析）；②去除检测干扰组分；③浓缩低浓度待测组分。两项关键要求：①严格避免待测组分损失；②不得引入新的干扰物质。高氯酸接触酚类、羟基类有机物易生成易爆物质，消解全程不得离人，样品变黑需立即停止加热。氢氟酸可与骨骼中的钙结合造成不可逆损伤（俗称"化骨水"），必须全程佩戴全套防护用具。
