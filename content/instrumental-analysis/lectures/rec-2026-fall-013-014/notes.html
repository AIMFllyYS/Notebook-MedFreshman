一、作业讲评（01:20-06:55）

1.1 有机溶剂中朗伯比尔定律的应用

  • 有机溶剂中测新普林（新霉素类？）：仍符合朗伯比尔定律
  • 关键：澄清透明溶液即可，不限定溶剂必须是水
  • 截距问题：用空白吸收池作参比（未用有机溶剂调零）→截距=有机溶剂本身的吸收
  • 摩尔吸光系数=拟合直线的斜率（与截距无关）
  • 若改用有机溶剂作参比→截距消除→直线过原点
🔔 作业要点：斜率=待测物摩尔吸光系数；截距=溶剂吸收。

二、双波长法复习与应用（07:10-13:54）

2.1 双波长法选波长原则（⭐重点）

回顾上节课内容：

  1. 先做待测组分和干扰组分的吸收曲线
  2. 从待测组分选择一个波长λ₁
  3. 在干扰组分的吸收曲线上找等吸收点λ₂（干扰组分在λ₁和λ₂处吸光度相等）
  4. ΔA = ΔK·b·c——与干扰无关，仅与待测组分浓度成正比

    5. 选波长两个原则：

    • 干扰组分在两波长处吸光度相等（等吸收点）
    • 待测组分在两波长处吸光度差ΔK足够大（灵敏度高）

    2.2 血氧饱和度测定（双波长法实例）

    • 原理：氧合血红蛋白（HbO₂）和去氧血红蛋白（Hb）吸收曲线不同但有重叠
    • 常用波长：660nm（红光）和940nm（近红外）
    • 无创测量：光线照射→反射光被接收器接收
    • 不同厂家波长略有不同，但都满足双波长选点原则
    • 可穿戴设备（手表、戒指、眼镜）原理类似
    💬 老师拓展：智能手表测心率、血氧都是光度法原理。

    三、导数光谱法（13:54-18:07）

    3.1 原理

    对吸收光谱A(λ)求n阶导数。零阶（不导）→一阶→二阶→三阶→四阶。

    两大优点：

    1. 峰位不变：零阶峰的极大处→一阶导数为0、二阶导数为极小、三阶导数为0、四阶导数为极大。峰始终在原波长位置，不漂移——有利于定性。
    2. 峰变窄（收缩）：高阶导数使峰围绕各自中心变窄→原本重叠的两个峰可能被分开——提高选择性/分辨率。
      1. 背景扣除：若背景与波长无关（常数），求导后背景自动消除。

        2. 缺点：信噪比降低（灵敏度损失）。

        🔔 考试要点：导数法最大优点是提高选择性（分辨重叠峰）、扣除背景。

        四、催化动力学光度法（20:00-27:24）

        4.1 基本原理

        • 热力学讲平衡，动力学讲速率
        • 通过测量化学反应速率来测定物质浓度
        • 测的是催化剂（如酶）的浓度/活性，不是反应物
        • 选择一个本身反应很慢的反应，加入催化剂后加速

        4.2 实验设计要点

        • 催化剂用量少（过量则反应瞬间完成无法测量）
        • 底物（反应物）浓度大且过量→反应过程中浓度变化可忽略
        • 反应速率只与催化剂浓度成正比
        • 监测指标：反应物或产物的吸光度随时间的变化速率
        • 关键是时间控制：同时加催化剂、同时终止反应

        终止方法：加抑制剂（如重金属离子抑制酶）、沸水浴、稀释等。

        4.3 灵敏度

        • 灵敏度极高：10⁻⁶~10⁻⁹ g/mL，最高可达10⁻¹² g/mL
        • 缺点：影响因素多，时间不易严格控制
        🔔 核心记忆：催化动力学光度法测的是催化剂（酶），灵敏度极高。

        五、分子荧光分析法（MFS）（28:19-结束）

        5.1 基本概念

        定义：某些物质受到紫外/可见光照射时，发射出不同颜色、不同强度的光；光照停止则发光停止。

        缩写：

        • MFS = Molecular Fluorescence Spectroscopy（分子荧光光谱法）
        • AFS = Atomic Fluorescence Spectroscopy（原子荧光，不讲）
        🔔 荧光 vs 化学发光：荧光棒是化学发光（化学反应供能）；MFS是光致发光（光激发供能），不涉及化学反应本身。

        5.2 荧光方法的特点

        1. 灵敏度高：比紫外可见法高2-4个数量级（测核酸、DNA测序都用荧光法）
        2. 选择性好：因为能发荧光的物质少——别人不发它发，自然干扰少
        3. 时间分辨：荧光有寿命（微秒/纳秒级），可利用寿命差异区分不同荧光物质

          4. 荧光寿命：激发光停止后荧光并不立即消失，而是按指数衰减。利用寿命差异可设计时间分辨荧光技术——关掉激发光后延迟检测，等短寿命干扰物熄灭后再测长寿命待测物，进一步消除散射和背景干扰。

          🔍 老师讲历史：最早记录荧光的是16世纪植物学家泡树皮发现蓝光；最早记录余辉（磷光）的是一个鞋匠（Shoemaker）发现晒过的石头进屋后还亮。

          5.3 分子能级与多重态

          电子自旋与分子多重态：M = 2S + 1（S=总自旋量子数）

          状态电子自旋M=2S+1名称
          基态单线态S₀↑↓（相反）1单线态
          激发单线态S₁/S₂↑↓（仍相反）1单线激发态
          三线态T₁↑↑（平行）3三线态（三重态）
          🔔 S→T跃迁是自旋禁阻的，概率小。含有重原子（I、Br）或有氧（顺磁性）时更容易发生。

          5.4 Jablonski能级图（⭐核心）

          激发后能量弛豫路径：

          1. 吸收（激发）：S₀的V₀ → S₂或S₁的不同振动能级
          2. 振动弛豫（VR）：同一电子态内，从高振动能级→低振动能级，以热能/动能形式释放
          3. 内转换（IC）：S₂的V₀ → S₁的高振动能级（都是单线态）
          4. 系间窜越（ISC）：S₁ → T₁（自旋改变，重原子/氧气促进）
          5. 荧光：从S₁的V₀ → S₀的各振动能级，以光子形式释放
          6. 磷光：从T₁的V₀ → S₀的各振动能级，以光子形式释放
            7. 🔔 关键结论：所有荧光都从S₁的V₀出发！不管激发到哪个能级，最终都要弛豫到S₁V₀才发荧光。

            5.5 荧光vs磷光vs激发光的波长比较

            波长与能级差成反比（能级差越小→波长越长）：

            • 激发光（吸收）：能量最大→波长最短
            • 荧光：能量较小→波长比激发光长（斯托克斯位移）
            • 磷光：能量最小（T₁比S₁还低）→波长最长
            🔔 必考结论：波长顺序：激发光 < 荧光 < 磷光。

            5.6 散射光及其干扰

            瑞利散射：

            • 散射光波长=激发光波长（弹性碰撞，吸多少发多少）
            • 原因：微小颗粒尺寸与波长可比拟
            • 天为什么是蓝的？散射强度∝1/λ⁴（紫光散射最强，但人眼对蓝敏感）

            拉曼散射：

            • 散射光波长≠激发光波长（非弹性碰撞），有固定位移
            • 对荧光测定干扰更大——因为波长与激发光不同，可能落在荧光峰附近
            • 消除方法：改变激发光波长→拉曼散射位置随之移动，与荧光峰分开
            🔍 例题（硫酸奎宁）：
            - 448nm峰：用320和350激发都出现，且与激发波长无关→荧光
            - 320/350nm处：波长=激发波长，空白硫酸也有→瑞利散射
            - 360/400nm处：随激发波长移动而位移→拉曼散射
            - 拉曼散射干扰更大，但可通过改变激发波长消除

            5.7 激发光谱与荧光光谱

            光谱类型做法横坐标
            激发光谱固定荧光发射波长，扫描激发波长激发光波长
            荧光光谱固定最佳激发波长，扫描发射波长荧光波长
            • 激发光谱形状≈吸收光谱形状（但取决于振动能级分布是否相似）
            • 荧光光谱与吸收光谱大致呈镜像对称
            • 激发光波长改变→荧光波长不变（始终在S₁V₀→S₀），但强度改变

            三维荧光光谱（指纹图谱）：

            • 两个变量（激发波长×发射波长）→荧光强度的等高线图
            • 每个物质的三维光谱独一无二→"荧光指纹"
            • 应用：纵火案油品溯源、复杂体系定性

            5.8 荧光量子效率（⭐概念）

            定义：发出荧光的光子数 / 吸收激发光的光子数。

            • Φ_f ≤ 1（最大为1）
            • 数值越大，荧光越强

            5.9 荧光与分子结构的关系

            前提条件：必须有大的共轭π键体系（先吸光才能发光）

            影响因素：

            1. 共轭程度：苯(Φ=0.11) < 萘(Φ增大) < 蒽(Φ更大)——共轭越大，荧光量子效率越高
            2. 共平面性：分子越共平面，电子云重叠越好，共轭越好→荧光越强
            3. 芘（平面）Φ≈1.0 vs 联苯（可旋转）Φ≈0.2
            4. 荧光素 vs 酚酞：结构极相似，荧光素有氧桥固定共平面→强荧光；酚酞可旋转→无荧光
            5. 取代基：给电子基团（-NH₂、-OH）增强荧光；吸电子基团（-NO₂、-COOH）减弱荧光
              6. 💬 老师举例：β-胡萝卜素（无苯环但有大共轭）→有荧光；国标测维生素A用荧光法；牛奶中核黄素（维生素B2）用荧光法测定，但见光易分解。

              老师强调的重点/考点汇总

              1. 双波长法选波长原则：干扰组分等吸收点+待测组分ΔK足够大
              2. 导数光谱法：优点=提高选择性、扣除背景；缺点=信噪比下降
              3. 催化动力学光度法：测催化剂（酶）活性，灵敏度极高
              4. MFS定义：光致发光，光照停止发光停止
              5. 荧光三大特点：灵敏度高、选择性好、有寿命（时间分辨）
              6. 分子多重态：单线态(S) vs 三线态(T)，M=2S+1
              7. Jablonski图：振动弛豫、内转换、系间窜越、荧光、磷光
              8. 荧光都从S₁V₀出发
              9. 波长顺序：激发光 < 荧光 < 磷光
              10. 瑞利vs拉曼散射：瑞利波长=激发波长；拉曼波长≠激发波长，干扰更大
              11. 消除拉曼干扰：改变激发光波长
              12. 荧光量子效率：发射光子数/吸收光子数
              13. 荧光结构条件：大共轭体系+共平面性

                主动回忆题

                Q1：双波长分光光度法选择两个波长的原则是什么？

                答案要点

                ①干扰组分在两个波长处吸光度相等（等吸收点）；②待测组分在两个波长处的吸光度差ΔK足够大（灵敏度高）。这样ΔA=ΔKbc，只与待测组分浓度成正比。

                Q2：导数光谱法有什么优点和缺点？

                答案要点

                优点：峰位不变（利于定性）；高阶导数使峰变窄→分辨重叠峰（提高选择性）；线性背景自动扣除。缺点：信噪比下降，灵敏度降低。

                Q3：催化动力学光度法测量的是什么物质？为什么灵敏度高？

                答案要点

                测量催化剂（如酶）的浓度/活性。因为催化剂微量即可显著加速反应，在底物过量、催化剂不足的条件下，反应速率与催化剂浓度成正比。灵敏度可达10⁻⁶~10⁻⁹ g/mL。缺点是时间不易严格控制。

                Q4：画出Jablonski能级图并说明荧光和磷光的产生过程。

                答案要点

                吸收→S₂/S₁激发；振动弛豫（同一电子态内降振动能级）；内转换（S₂→S₁）；系间窜越（S₁→T₁，自旋翻转）。荧光=从S₁V₀→S₀各振动能级发光；磷光=从T₁V₀→S₀发光。所有荧光都从S₁V₀出发。

                Q5：瑞利散射和拉曼散射有什么区别？哪种对荧光测定干扰更大？如何消除？

                答案要点

                瑞利散射：波长=激发波长（弹性散射）；拉曼散射：波长≠激发波长（非弹性散射，有固定位移）。拉曼散射干扰更大，因为它的波长可能落在荧光峰附近。消除方法：改变激发光波长，使拉曼散射峰移到荧光峰以外。

                Q6：什么样结构的物质容易发荧光？

                答案要点

                ①必须有大的共轭π键体系（先能吸光）；②分子共平面性好（电子云重叠充分）；③给电子取代基增强荧光，吸电子取代基减弱荧光。荧光量子效率=发射光子数/吸收光子数，≤1。
