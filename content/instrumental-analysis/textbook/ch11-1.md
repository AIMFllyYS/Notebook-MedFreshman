# 第1节　概述

本章打开色谱分析导论。先把户头写成：色谱法兼具分离与分析，是处理多组分复杂体系最有力的手段之一。本节只立起源、特点和三条分类轴。保留时间、死时间、分离度放到第 2 节；塔板理论与 van Deemter 方程放到第 3 节；多维联用、整体柱和微流控放到第 4 节简介，不要在这里扩成第 13 章高效液相或第 14 章气相的专章。

“色谱”这一名称源于 20 世纪初俄国植物学家茨维特（Mikhail S. Tswett）所发明的一个分离植物色素成分的方法。他将细颗粒碳酸钙放在竖立的玻璃管中，从顶端倒入植物叶子的石油醚提取液，然后用石油醚由上而下淋洗。结果，由于不同颜色的色素从上至下移行速度不同，在玻璃管的不同部位形成不同颜色的色带。1906 年茨维特发表了他的研究成果，并将这种方法命名为 chromatography（色谱法）。固定在管中的填充物保持不动，称为固定相（stationary phase）；携带样品向一定方向移动的液体称为流动相（mobile phase）；放置固定相的直管称为色谱柱（column）。虽然后来色谱法不仅限于分离有色物质，但这一名称仍然沿用至今。

:::definition{label="色谱法"}
chromatography。茨维特 1906 年命名。起初是把植物色素在碳酸钙柱上淋洗成不同颜色的色带；后来不限于有色物质，名称仍沿用。
:::

:::definition{label="固定相"}
stationary phase。固定在管中、保持不动的填充物。
:::

:::definition{label="流动相"}
mobile phase。携带样品向一定方向移动的流体。茨维特原实验里是石油醚；后来可以是气体、液体或超临界流体。
:::

:::definition{label="色谱柱"}
column。放置固定相的直管。平面色谱把固定相铺成平面，不再用这根直管，但两相“一动一静”的户头不变。
:::

:::concept{term="先问谁不动、谁在走，再问峰何时出来"}
看见色谱，先不要跳到塔板数或高压泵。户头是：固定相不动，流动相带着样品走，不同组分与两相作用不同，移行速度不同。把“色谱”听成“只分离有颜色的东西”，后面无色药物、气体样品和紫外检测器都会对空。把本节听成第 13、14 章仪器构造，高压输液泵和毛细管进样会被提前写满。
:::

:::note{label="英文不要粘连，人名按本版"}
本版写成 Mikhail S. Tswett，中间有点号和空格。扫描稿里的 MikhailS.Tswett 是 OCR 粘连，不是另一个拼法。chromatography、stationary phase、mobile phase、column 都是分写的英文，不要并成一个词。
:::

## 一、色谱法的起源和发展历程

茨维特的工作在当时很长时间内并没有得到科学界的足够重视。直到 20 世纪 30 年代，德国化学家 Kuhn 采用柱层析分离出多种胡萝卜素，这种方法才引起人们的关注。20 世纪 30 至 40 年代出现了纸色谱法（paper chromatography，PC）和薄层色谱法（thin layer chromatography，TLC）。1941 年，英国的 Martin 和 Synge 开创性地发明分配色谱，并提出塔板理论，因此获得了 1952 年诺贝尔化学奖，标志着现代色谱分析的开端，使色谱法发展为分析化学的重要分支。20 世纪 70 年代发展起来的高效液相色谱法（high-performance liquid chromatography，HPLC）成为生物、医学、药学及食品领域的重要分离分析技术。20 世纪 80 年代，Jorgenson 等人的研究工作使毛细管电泳（capillary electrophoresis）开始在生命科学分析领域发挥分离分析作用。而后先后发展起来的超临界流体色谱（supercritical fluid chromatography，SPC）、固相微萃取（solid phase micro-extraction，SPME）、逆流色谱（counter current chromatography，CCC）等，使色谱法的应用范围不断拓展。学术界普遍认为，色谱的发展和色谱理论的形成，让分离技术发展为研究物质分离、富集、纯化和检测的一门独立的学科——分离科学（separation science）。

:::timeline{period="从色带到分离科学"}
- **20 世纪初** 茨维特用碳酸钙柱、石油醚淋洗植物色素，得到不同颜色的色带
- **1906 年** 茨维特发表成果，命名 chromatography；给出固定相、流动相、色谱柱
- **此后相当长时间** 工作未得到足够重视
- **20 世纪 30 年代** Kuhn 用柱层析分出多种胡萝卜素，方法重新引起关注
- **20 世纪 30–40 年代** 纸色谱（PC）、薄层色谱（TLC）出现
- **1941 年** Martin 与 Synge 发明分配色谱，提出塔板理论
- **1952 年** 二人因此获诺贝尔化学奖，标志现代色谱分析开端
- **20 世纪 70 年代** HPLC 成为生物、医学、药学及食品领域的重要分离分析技术
- **20 世纪 80 年代** Jorgenson 等使毛细管电泳进入生命科学分析
- **此后** 超临界流体色谱（本版缩写 SPC）、固相微萃取（SPME）、逆流色谱（CCC）等拓展应用范围；分离科学独立成学科
:::

:::definition{label="纸色谱法与薄层色谱法"}
纸色谱法（paper chromatography，PC）和薄层色谱法（thin layer chromatography，TLC）出现于 20 世纪 30 至 40 年代。二者都属于后文的平面色谱，固定相铺在纸或薄层板上，不是装在高压不锈钢柱里。
:::

:::definition{label="分配色谱与塔板理论的年代"}
Martin 和 Synge 于 1941 年发明分配色谱并提出塔板理论，1952 年获诺贝尔化学奖。本版把这一年写成现代色谱分析的开端。塔板模型的四条假设和公式放到第 3 节，不要在概述里提前展开 $N=16(t_{\mathrm{R}}/W)^{2}$。
:::

:::definition{label="高效液相色谱法"}
high-performance liquid chromatography，HPLC。20 世纪 70 年代发展起来，成为生物、医学、药学及食品领域的重要分离分析技术。泵、梯度、检测器留给第 13 章。
:::

:::definition{label="毛细管电泳"}
capillary electrophoresis。20 世纪 80 年代因 Jorgenson 等人的工作，开始在生命科学分析领域发挥分离分析作用。电泳驱动力不是本章的流动相泵送，不要和 HPLC 并成同一种柱色谱。
:::

:::definition{label="本版随后点名的三种拓展"}
超临界流体色谱（supercritical fluid chromatography，SPC）、固相微萃取（solid phase micro-extraction，SPME）、逆流色谱（counter current chromatography，CCC）。本版把超临界流体色谱的缩写印成 SPC，不是把方法改名。
:::

:::definition{label="分离科学"}
separation science。色谱的发展和色谱理论的形成，让分离技术成为研究物质分离、富集、纯化和检测的独立学科。
:::

:::pitfall{label="诺贝尔奖年份不要写成 1941，胡萝卜素不要读成胡萝下素"}
发明分配色谱和提出塔板理论是 1941 年；获奖是 1952 年。扫描稿常把胡萝卜素打成“胡萝下素”。Kuhn 用的是柱层析分胡萝卜素，不要改写成茨维特 1906 年那次实验的翻版。
:::

:::pitfall{label="本版超临界流体色谱缩写是 SPC"}
通用文献多写 SFC。本版印刷是 SPC。概述题按本版答；不要在导论里用别的书把缩写“改正”后再说教材印错。SPME、CCC 的连字符和逗号按本版，扫描粘连 solidphasemicro-extraction 不是另一个方法名。
:::

:::insight{label="名称沿用，对象早已不限有色物质"}
茨维特看见的是色带，所以叫 chromatography。后来气相、高效液相、电泳分离的多数是无色组分，靠检测器出峰，名称仍叫色谱。第 2 节的流出曲线，户头就在“不一定有颜色、但一定有差速迁移”。
:::

:::keypoint{label="概述时间线只记到学科独立"}
- 写：茨维特 1906；Kuhn 的胡萝卜素；PC／TLC；Martin 与 Synge 1941／1952；HPLC 70 年代；CE 80 年代；SPC、SPME、CCC；分离科学。
- 不写：第 13 章的高压输液泵型号、第 14 章的填充柱／毛细管柱固定液名单。那些不是导论的深度。
:::

## 二、色谱法的特点

色谱法因兼具强大的分离与分析的功能，成为分析混合物最有力的手段。其具有高灵敏度、高选择性、高效能、分析速度快及应用范围广等优点，可以解决诸多分析方法和技术在面对含有多种组分的复杂体系时存在的困难。目前，色谱法广泛用于生命科学、材料科学、环境科学等各科学领域，在药物分析中也有着极为重要的地位，已成为实验室常规分析手段。

:::definition{label="色谱法的五点优点"}
高灵敏度、高选择性、高效能、分析速度快、应用范围广。本版把它写成分析混合物最有力的手段，因为它兼具分离与分析。
:::

:::definition{label="复杂体系这一句针对什么"}
诸多分析方法和技术在面对含有多种组分的复杂体系时存在困难。色谱先把组分在柱（或平面）上分开，再逐一检测，所以能处理混合物，而不是要求样品事先是纯物质。
:::

:::definition{label="应用落点（概述）"}
生命科学、材料科学、环境科学；药物分析中有极为重要的地位；实验室常规分析手段。药学里的具体品种和流动相配方，分别留给第 13、14 章。
:::

:::compare{title="五点优点各自管哪一头"}
| 优点 | 本节落到哪 | 后面哪一节展开 |
|------|------------|----------------|
| 高灵敏度 | 能看复杂体系里的微量组分 | 检测器属于各论，导论不列型号 |
| 高选择性 | 固定相／流动相种类决定 $\alpha$ | 第 3 节分离因子 |
| 高效能 | 反复分配，微小差异也能分开 | 第 3 节塔板数 $N$ |
| 分析速度快 | 兼顾 $k$ 与时间 | 第 3 节 $k$ 常取 $1\sim 10$ |
| 应用范围广 | 气、液、超临界；柱、平面、逆流 | 本节第三条分类轴 |
:::

:::insight{label="分离和分析是同一件事的两面"}
没有差速迁移，检测器再灵也只是把混合物当成一个信号。没有检测，色带再漂亮也报不出含量。第 2 节流出曲线把“分离的空间过程”画成“检测器对时间的信号”，两点在图 11-1、图 11-2 接上。
:::

:::pitfall{label="不要把「目前」读成「自前」，也不要把优点听成没有限度"}
扫描稿常把“目前”打成“自前”。五点优点是相对许多非分离方法而言。定量时仍要求分离度 $R\ge 1.5$（第 2 节），柱效仍受流速、粒度和液膜厚度限制（第 3 节）。不要在概述里把色谱写成万能、无条件。
:::

:::memory{label="五点优点口诀"}
灵敏、选择、效能、速度、范围。对应后面的检测、$\alpha$、$N$、分析时间、三条分类轴。缺哪一个，复杂混合物就会在那一头卡住。
:::

## 三、色谱法的分类

经过了一个多世纪的发展，色谱法已成为包括许多分支的分离科学，可从不同的角度对其进行分类。本版给三条轴：流动相与固定相的分子聚集状态、操作形式、分离机理。三条轴是正交的，不要并成一张名单。

### （一）按流动相与固定相的分子聚集状态分类

在色谱法中流动相可以是气体、液体和超临界流体，这些方法相应称为气相色谱法（gas chromatography，GC）、液相色谱法（liquid chromatography，LC）和超临界流体色谱法。固定相又有固体或液体，气相色谱法又可分为气固色谱法（gas-solid chromatography，GSC）与气液色谱法（gas-liquid chromatography，GLC）；液相色谱法又可分为液固色谱法（liquid-solid chromatography，LSC）与液液色谱法（liquid-liquid chromatography，LLC）。

:::definition{label="按聚集状态的三种流动相"}
流动相可以是气体、液体和超临界流体，对应气相色谱法（GC）、液相色谱法（LC）和超临界流体色谱法。
:::

:::definition{label="气固色谱与气液色谱"}
气相色谱按固定相聚集状态再分：气固色谱法（GSC），固定相是固体；气液色谱法（GLC），固定相是液体（涂在载体上）。
:::

:::definition{label="液固色谱与液液色谱"}
液相色谱按固定相聚集状态再分：液固色谱法（LSC）；液液色谱法（LLC）。
:::

:::compare{title="流动相 × 固定相 四个常见组合"}
| 方法 | 流动相 | 固定相 | 本版缩写 |
|------|--------|--------|----------|
| 气固色谱 | 气体 | 固体 | GSC |
| 气液色谱 | 气体 | 液体 | GLC |
| 液固色谱 | 液体 | 固体 | LSC |
| 液液色谱 | 液体 | 液体 | LLC |
:::

:::pitfall{label="扫描稿在 GSC 处断行，不要把气液色谱吞掉"}
印刷页在“gas-solid chromatography，GSC）与气液色谱法（gas-liquid chromatography，GLC）”处换行，OCR 常把 GSC 后半句切掉。四个组合要写全。超临界流体色谱在这条轴上是第三种流动相，不要把它误并进 GC 或 LC。
:::

:::note{label="GC、LC 是流动相轴，GSC／GLC、LSC／LLC 是固定相再分"}
问“气相色谱包括哪两种”，答 GSC 与 GLC，不要答 HPLC 与 TLC。HPLC 是液相色谱在操作压力和粒度上的发展，户头仍在 LC。
:::

### （二）按操作形式分类

可分为柱色谱法（column chromatography）、平面色谱法（plane chromatography）、逆流色谱法等类别。

柱色谱法是将固定相固定于柱管内构成色谱柱，流动相通过重力或压力的方式流经固定相。根据色谱柱尺寸、结构和制备方法的不同，柱色谱法又可分为填充柱色谱、毛细管柱色谱、整体柱色谱、开管柱色谱等。

固定相呈平面状的称为平面色谱，包括固定相以均匀薄层涂布于平面的载板上的薄层色谱法、固定相固定于纸纤维或基质膜上的纸色谱法和薄膜色谱法。

逆流色谱法是将液体的固定相装入特制的螺旋管内，流动相通过加压作用泵入做旋转运动的螺旋管内，与固定相形成逆向对流。物质的分离依据其在两相中分配系数的不同而实现，因而避免了因不可逆吸附而引起的样品损失、失活、变性等，尤其适合于天然生物活性成分的分离。

:::definition{label="柱色谱法"}
column chromatography。固定相固定于柱管内构成色谱柱，流动相靠重力或压力流经固定相。
:::

:::definition{label="柱色谱的四种再分"}
按尺寸、结构和制备方法：填充柱色谱、毛细管柱色谱、整体柱色谱、开管柱色谱。整体柱怎样原位聚合，放到第 4 节“第四代分离介质”那一笔，本节只立户头。
:::

:::definition{label="平面色谱法"}
plane chromatography。固定相呈平面状。包括：薄层色谱法（均匀薄层涂布于平面载板）；纸色谱法（固定相固定于纸纤维）；薄膜色谱法（固定相固定于基质膜）。
:::

:::definition{label="逆流色谱法"}
液体固定相装入特制螺旋管，流动相加压泵入做旋转运动的螺旋管，与固定相形成逆向对流。分离依据分配系数不同。避免不可逆吸附引起的样品损失、失活、变性，尤其适合天然生物活性成分。
:::

:::compare{title="三种操作形式"}
| 形式 | 固定相怎么放 | 流动相怎么走 | 本版强调 |
|------|--------------|--------------|----------|
| 柱色谱 | 装在柱管里 | 重力或压力流过 | 填充／毛细管／整体／开管 |
| 平面色谱 | 铺成平面 | 展开 | TLC、纸色谱、薄膜色谱 |
| 逆流色谱 | 液体固定相在螺旋管里 | 加压泵入旋转管，逆向对流 | 无不可逆吸附，适合天然活性成分 |
:::

:::insight{label="逆流色谱的固定相也是液体，但操作形式不是 LLC 柱"}
LLC 是液液色谱的聚集状态名；逆流色谱是操作形式名：没有固体载体，靠螺旋管里的两相逆流。问分类时先声明走哪一条轴，否则“液液”和“逆流”会对串。
:::

:::pitfall{label="不要把平面色谱听成只能做定性"}
本节只按操作形式分类，没有写“平面色谱不能定量”。薄层扫描定量是后话，不要在导论里用别的书补一条禁令进来顶替本版分类。
:::

### （三）按分离机理分类

可分为分配色谱法（partition chromatography）、吸附色谱法（adsorption chromatography）、离子交换色谱法（ion exchange chromatography，IEC）、分子排阻色谱法（molecular exclusion chromatography，MEC）和亲和色谱法（affinity chromatography，AC）等类型。

:::definition{label="分配色谱法"}
partition chromatography。组分在互不相溶的两相之间分配。Martin 与 Synge 1941 年发明的就是这一类；第 3 节塔板模型也以分配色谱为例。
:::

:::definition{label="吸附色谱法"}
adsorption chromatography。固定相是吸附剂，靠吸附–解吸附差异分离。第 2 节图 11-1 画的就是吸附柱色谱过程。
:::

:::definition{label="离子交换色谱法"}
ion exchange chromatography，IEC。固定相带可交换离子，按离子交换作用分离。
:::

:::definition{label="分子排阻色谱法"}
molecular exclusion chromatography，MEC。按分子尺寸在孔中的排阻差异分离。第 4 节多维平台里的体积排阻色谱（SEC）落在这一户。
:::

:::definition{label="亲和色谱法"}
affinity chromatography，AC。利用生物特异结合。导论只立户头，不要在这里写配基偶联步骤。
:::

:::compare{title="五类分离机理"}
| 类型 | 英文／缩写 | 分开靠什么 |
|------|------------|------------|
| 分配色谱 | partition chromatography | 两相中的分配系数差异 |
| 吸附色谱 | adsorption chromatography | 吸附剂上的吸附能力差异 |
| 离子交换色谱 | IEC | 离子交换 |
| 分子排阻色谱 | MEC | 分子尺寸／排阻 |
| 亲和色谱 | AC | 特异亲和 |
:::

:::pitfall{label="三条分类轴不要并成一张名单"}
“气相、薄层、分配”不是同一层的三个选项。气相是流动相聚集状态，薄层是操作形式，分配是分离机理。一张多选题如果把 HPLC、GSC、TLC、IEC 并列，先看题干问的是哪一条轴。第 1 章若已出现过色谱分类，以本章印刷名单为准。
:::

:::keypoint{label="本节只写到哪一层"}
- 写：色带实验与三个名词；时间线到分离科学；五点优点；三条分类轴及各轴名单。
- 不写：保留时间公式、塔板数、van Deemter 三项、HPLC 泵压。那些分别是第 2、3、13 节的账。
:::

:::memory{label="第1节收口"}
- 1906 茨维特：固定相、流动相、色谱柱；名称沿用，对象不限有色。
- 1941／1952 Martin 与 Synge：分配色谱＋塔板理论，现代色谱开端。
- 70 年代 HPLC，80 年代 CE；本版随后写 SPC、SPME、CCC。
- 优点五条：灵敏、选择、效能、速度、范围。
- 分类三轴：气／液／超临界 × 固／液；柱／平面／逆流；分配／吸附／IEC／MEC／AC。
