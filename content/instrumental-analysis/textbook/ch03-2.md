# 第2节　电磁辐射的性质

光学分析法的物理底子是电磁辐射。本节按本版符号把波动性（周期 $T$、频率 $\nu$、波长 $\lambda$、波数 $\sigma$、传播速率 $v$）、粒子性（$E=h\nu=hc/\lambda=hc\sigma$）、电磁波谱分区、辐射与物质的相互作用摊开。可见光按本版写 $360\sim 760\,\mathrm{nm}$，不要换成别的物理教材的 $400\sim 700\,\mathrm{nm}$。吸收只点到跃迁和量子化，朗伯–比尔定律留给第4章。

电磁辐射是一种以极大速率（在真空中为光速）通过空间，不需要以任何物质作为传播媒介的能量。它包括无线电波、微波、红外光、紫外光、可见光、X 射线、γ 射线等形式。电磁辐射具有波动性和粒子性，称为波粒二象性。

:::definition{label="电磁辐射"}
电磁辐射是一种以极大速率（在真空中为光速）通过空间、不需要以任何物质作为传播媒介的能量。形式包括无线电波、微波、红外光、紫外光、可见光、X 射线、γ 射线等。
:::

:::definition{label="波粒二象性"}
电磁辐射具有波动性和粒子性，称为波粒二象性。波动性用波长 $\lambda$、频率 $\nu$ 和波数 $\sigma$ 作为特征；粒子性用每个光子具有的能量 $E$ 作为表征。光子能量公式把二者联系起来。
:::

:::concept{term="先问这是波还是粒子，再问落在电磁波谱哪一区"}
传播、反射、衍射、干涉、折射、散射，用正弦波描述。发射和吸收、光电效应、康普顿效应，必须把辐射看成光子。分区则按波长（或频率、能量）排队。三问没分开，公式 $E=h\nu$ 会对不上户头。
:::

:::pitfall{label="电磁辐射不需要介质，不要写成机械波"}
教材写明：不需要以任何物质作为传播媒介。把光听成“空气里才能走”，真空紫外、X 射线、γ 射线的户头会丢。
:::

## 一、电磁辐射的波动性

根据经典物理学的观点，电磁波是在空间传播着的交变电场和磁场。当辐射通过物质时，就与物质粒子的电场或磁场发生相互作用，在辐射和物质之间产生能量交换。波的传播及反射、衍射、干涉、折射、散射等现象表现了电磁辐射具有波的性质，可以用经典的正弦波加以描述。

:::definition{label="电磁波"}
电磁波是在空间传播着的交变电场和磁场。通过物质时，与物质粒子的电场或磁场发生相互作用，在辐射和物质之间产生能量交换。
:::

:::definition{label="波动性的宏观表现"}
传播、反射、衍射、干涉、折射、散射表现了电磁辐射具有波的性质，可用经典正弦波描述。
:::

电磁波可用下列波参数来描述。

**（1）周期 $T$**　两个相邻矢量极大（或极小）通过空间某固定点所需的时间间隔叫作辐射的周期，单位为秒（$\mathrm{s}$）。

:::definition{label="周期 T"}
周期 $T$：两个相邻矢量极大（或极小）通过空间某固定点所需的时间间隔。单位为秒（$\mathrm{s}$）。
:::

**（2）频率 $\nu$**　空间某点的电场每秒钟到达正极大值的次数，即每秒内辐射振荡的次数称为频率。它等于周期的倒数，即 $\nu=1/T$，单位为赫兹（$\mathrm{Hz}$），$1\,\mathrm{Hz}=1\,\mathrm{s}^{-1}$。

:::definition{label="频率 ν"}
频率 $\nu$：空间某点的电场每秒钟到达正极大值的次数，即每秒内辐射振荡的次数。$\nu=1/T$，单位赫兹（$\mathrm{Hz}$），$1\,\mathrm{Hz}=1\,\mathrm{s}^{-1}$。
:::

**（3）波长 $\lambda$**　相邻两极大值或极小值之间的距离称为波长。不同的电磁波谱区可采用不同的波长单位，可以是米（$\mathrm{m}$）、厘米（$\mathrm{cm}$，$10^{-2}\,\mathrm{m}$）、微米（$\mathrm{\mu m}$，$10^{-6}\,\mathrm{m}$）或纳米（$\mathrm{nm}$，$10^{-9}\,\mathrm{m}$）。

:::definition{label="波长 λ"}
波长 $\lambda$：相邻两极大值或极小值之间的距离。单位随波谱区选用 $\mathrm{m}$、$\mathrm{cm}$（$10^{-2}\,\mathrm{m}$）、$\mathrm{\mu m}$（$10^{-6}\,\mathrm{m}$）或 $\mathrm{nm}$（$10^{-9}\,\mathrm{m}$）。
:::

**（4）波数 $\sigma$ 或 $\bar{\nu}$**　波长的倒数，它表示每厘米长度内所具有的波的数目，单位为 $\mathrm{cm}^{-1}$。将波长换算为波数的关系式为

$$
\frac{\sigma}{\mathrm{cm}^{-1}}=\frac{\mathrm{cm}}{\lambda}=\frac{10^{4}\,\mathrm{\mu m}}{\lambda}\qquad (3\text{-}1)
$$

:::definition{label="波数 σ"}
波数 $\sigma$ 或 $\bar{\nu}$ 是波长的倒数，表示每厘米长度内所具有的波的数目，单位 $\mathrm{cm}^{-1}$。式（3-1）给出本版换算：$\sigma/\mathrm{cm}^{-1}=\mathrm{cm}/\lambda=10^{4}\,\mathrm{\mu m}/\lambda$。$\lambda$ 以厘米计时 $\sigma=1/\lambda$；$\lambda$ 以微米计时 $\sigma=10^{4}/\lambda$。
:::

**（5）传播速率 $v$**　辐射的速率等于频率乘以波长，即 $v=\nu\lambda$。在真空中所有的电磁辐射传播速率都等于光速 $c$（$c$ 的值已被准确地测定为 $2.997\,924\,58\times 10^{8}\,\mathrm{m}\cdot\mathrm{s}^{-1}$）。

:::definition{label="传播速率 v 与真空光速 c"}
传播速率 $v=\nu\lambda$。真空中所有电磁辐射的传播速率都等于光速 $c=2.997\,924\,58\times 10^{8}\,\mathrm{m}\cdot\mathrm{s}^{-1}$。
:::

:::compare{title="五个波参数（本版符号）"}
| 参数 | 本版符号 | 定义 | 单位 | 关系 |
|------|----------|------|------|------|
| 周期 | $T$ | 相邻矢量极大（或极小）通过固定点的时间间隔 | $\mathrm{s}$ | $\nu=1/T$ |
| 频率 | $\nu$ | 每秒振荡次数；电场每秒到达正极大值的次数 | $\mathrm{Hz}$，$1\,\mathrm{Hz}=1\,\mathrm{s}^{-1}$ | $\nu=1/T=v/\lambda$ |
| 波长 | $\lambda$ | 相邻两极大或极小之间的距离 | $\mathrm{m}$、$\mathrm{cm}$、$\mathrm{\mu m}$、$\mathrm{nm}$ | $v=\nu\lambda$ |
| 波数 | $\sigma$ 或 $\bar{\nu}$ | 每厘米内的波的数目，波长的倒数 | $\mathrm{cm}^{-1}$ | 式（3-1） |
| 传播速率 | $v$；真空中为 $c$ | 频率乘以波长 | $\mathrm{m}\cdot\mathrm{s}^{-1}$ | 真空中 $v=c$ |
:::

:::derivation{title="波数与波长如何换算"}
波数是波长的倒数，且以每厘米内的波数来报。若 $\lambda$ 以 $\mathrm{cm}$ 计，$\sigma=1/\lambda$，单位 $\mathrm{cm}^{-1}$。因为 $1\,\mathrm{cm}=10^{4}\,\mathrm{\mu m}$，若 $\lambda$ 以 $\mathrm{\mu m}$ 计，则

$$
\sigma\,(\mathrm{cm}^{-1})=\frac{10^{4}}{\lambda\,(\mathrm{\mu m})}
$$

这就是式（3-1）的含义。红外区习惯用 $\mathrm{cm}^{-1}$，可见、紫外习惯用 $\mathrm{nm}$，不要混单位再除一次。
:::

:::pitfall{label="本版波数符号是 σ（或 ν̄），不要换成另一本物理书的 k"}
教材正文同时给出 $\sigma$ 或 $\bar{\nu}$，式（3-1）、式（3-2）用 $\sigma$。不要把波数改写成圆波数 $k=2\pi/\lambda$，后面 $E=hc\sigma$ 会对不上。
:::

:::pitfall{label="真空中 v 就是 c，不要按介质折射率改光速再去算频率"}
真空中所有电磁辐射传播速率都等于 $c$。频率由光源决定，进入介质时波长和速率变、频率不变。本节公式先按真空写。
:::

## 二、电磁辐射的粒子性

电磁辐射的波动性不能解释辐射的发射和吸收现象。对于光电效应、康普顿（Compton）效应、黑体辐射的能量分布等，需要把辐射看成粒子（光子）才能得到满意的解释。电磁辐射的粒子性表现为辐射的能量不是均匀连续地分布在它传播的空间，而是集中在辐射产生的粒子上。普朗克（Planck）认为，物质吸收或发射能量是不连续的，只能按一个基本固定量一份一份地或以基本固定量的整数倍来进行。也就是说，能量是“量子化”的。这种能量的最小单位即为“光子”。

:::definition{label="光子与量子化"}
辐射的能量不是均匀连续地分布在传播空间，而是集中在辐射产生的粒子上。物质吸收或发射能量不连续，只能按一个基本固定量或其整数倍进行，即能量量子化。这种能量的最小单位即为光子。
:::

:::definition{label="光电效应与康普顿效应"}
光电效应、康普顿效应、黑体辐射的能量分布等，波动性不能满意解释，必须把辐射看成光子。它们体现光的粒子性。
:::

光子是具有能量的，光子的能量与光的频率成正比，或与光的波长成反比，而与光的强度无关。

$$
E=h\nu=hc/\lambda=hc\sigma\qquad (3\text{-}2)
$$

式中，$E$ 代表每个光子的能量，单位常用焦耳（$\mathrm{J}$）或电子伏特（$\mathrm{eV}$）表示，$1\,\mathrm{eV}=1.602\times 10^{-19}\,\mathrm{J}$；$h$ 为普朗克常量，$h=6.626\times 10^{-34}\,\mathrm{J}\cdot\mathrm{s}$；$\nu$ 为频率；$\lambda$ 为波长；$c$ 为光速。

:::definition{label="光子能量公式"}
光子能量 $E=h\nu=hc/\lambda=hc\sigma$。$E$ 与频率成正比，与波长成反比，与光的强度无关。$h=6.626\times 10^{-34}\,\mathrm{J}\cdot\mathrm{s}$；$1\,\mathrm{eV}=1.602\times 10^{-19}\,\mathrm{J}$。
:::

:::keypoint{label="式（3-2）里的四个量"}
- $E$：每个光子的能量，单位 $\mathrm{J}$ 或 $\mathrm{eV}$。
- $\nu$：频率，单位 $\mathrm{Hz}$。
- $\lambda$：波长；除法时单位必须与 $c$、$h$ 配套。
- $\sigma$：波数；本版写 $E=hc\sigma$。
:::

光子能量公式或普朗克公式（式 3-2）把光的波动性和粒子性联系了起来。光的波动性用波长 $\lambda$、频率 $\nu$ 和波数 $\sigma$ 作为特征，光的折射、衍射、偏振、干涉等体现了光的波动性。光的粒子性用每个光子具有的能量 $E$ 作为表征，光子的能量与光的频率 $\nu$ 成正比，与光的波长 $\lambda$ 成反比，光电效应体现了光的粒子性。

:::compare{title="波动性与粒子性各用什么说话"}
| 项目 | 波动性 | 粒子性 |
|------|--------|--------|
| 特征量 | $\lambda$、$\nu$、$\sigma$ | 每个光子的能量 $E$ |
| 现象 | 折射、衍射、偏振、干涉 | 光电效应；发射与吸收 |
| 经典图像 | 交变电场和磁场、正弦波 | 能量一份一份，集中在光子上 |
| 联系 | 式（3-2）$E=h\nu=hc/\lambda=hc\sigma$ | 同左 |
:::

:::pitfall{label="光子能量与光的强度无关"}
把灯调亮，增加的是光子数目，不是单个光子的 $E$。$E$ 只跟 $\nu$（或 $\lambda$、$\sigma$）走。把“强光能量大”听成“每个光子更重”，光电效应的阈值频率会讲反。
:::

:::example{label="同一公式三种写法不要拆成三套理论"}
$E=h\nu$、$E=hc/\lambda$、$E=hc\sigma$ 是同一句话。已知波长求能量，用 $hc/\lambda$；已知波数，用 $hc\sigma$；已知频率，用 $h\nu$。不要把波数公式当成另一本教材的附加约定。
:::

:::insight{label="强度管光子数，频率管每个光子的能量"}
光谱法定量常常测强度，定性常常测波长（或波数）。两本账不要并成“峰越高能量越大”——峰高是光子数目（或跃迁概率），峰位才对应 $E=h\nu$。
:::

## 三、电磁波谱

电磁辐射具有广泛的波长（或频率、能量）分布。将电磁辐射按照波长（或频率、能量）顺序排序，称为电磁波谱（electromagnetic spectrum）。如图3-1所示，电磁波谱的不同区段，从 X 射线、紫外光、可见光、红外光、微波和无线电波，其能量递减，波长变长，其区别在于波长或频率不同，即光子的能量不同。

:::definition{label="电磁波谱"}
电磁波谱（electromagnetic spectrum）是将电磁辐射按照波长（或频率、能量）顺序排序。区段不同，区别在于波长或频率不同，即光子的能量不同。
:::

从表3-1可以看出：

（1）电磁波谱的排列表现出明显的规律性。从上到下，随着波长的逐渐增大，频率和光子的能量逐渐减小。γ 射线的波长最短，能量最大；其后是 X 射线区、紫外–可见光区和红外光区；无线电波区波长最长，能量最小。波长在量上的渐变，引起了各种类型电磁辐射质上的区别。

（2）各种电磁辐射不仅波长不同，而且产生机理也不同。例如，基于低电子能级向高电子能级的跃迁可以建立紫外–可见吸收光谱，跃迁所涉及的能量对应于紫外–可见波长区域；而基于低振动–转动能级向高振动–转动能级的跃迁可以建立红外吸收光谱，跃迁所涉及的能量对应于红外波长区域。

:::keypoint{label="表3-1 的两条读法"}
- 波长↑ → 频率↓、光子能量↓。γ 射线最短最硬，无线电波最长最软。
- 波长不同，产生机理也不同：价电子 ↔ 紫外可见；振动 ↔ 红外；转动 ↔ 远红外／微波；自旋 ↔ 无线电波。
:::

:::pitfall{label="可见光本版是 360～760 nm，真空紫外是 10～200 nm"}
不要用口诀 $400\sim 700\,\mathrm{nm}$ 或 $380\sim 780\,\mathrm{nm}$ 替换。近紫外与可见的界是 $360\,\mathrm{nm}$，可见与近红外的界是 $760\,\mathrm{nm}$（$0.76\,\mathrm{\mu m}$）。真空紫外 $10\sim 200\,\mathrm{nm}$，近紫外 $200\sim 360\,\mathrm{nm}$，两区都是价电子跃迁，不要并成一个“紫外”。
:::

:::pitfall{label="中红外 2.5～25 μm，不要把近红外的振动账漏掉"}
近红外 $0.76\sim 2.5\,\mathrm{\mu m}$ 和中红外 $2.5\sim 25\,\mathrm{\mu m}$ 在表3-1里都写振动能级。远红外才改写转动。把“红外＝振动”听成只有中红外，近红外那一行会对空。
:::

:::memory{label="波长变长，能量变小，跃迁从核到自旋"}
问法：从表3-1从上往下，波长、能量、跃迁如何变？
答：波长增大，频率和光子能量减小。γ 核 → X 内层电子 → 真空/近紫外/可见价电子 → 近红外/中红外振动 → 远红外/微波转动 → 无线电波电子和核的自旋。
:::

:::example{label="看见 500 nm 先落到可见光、价电子"}
$500\,\mathrm{nm}$ 落在本版可见光区 $360\sim 760\,\mathrm{nm}$，表3-1跃迁类型是价电子。不要写成振动或转动；也不要因为“绿光”就改用别的书的分区界。
:::

## 四、电磁辐射与物质的相互作用

电磁辐射与物质的相互作用是普遍发生的物理现象。当辐射通过固体、液体或气体等透明介质时，电磁辐射的交变电场导致分子（或原子）外层电子相对其核的振荡，造成这些分子（或原子）周期性的极化。如果入射的电磁辐射能量正好与介质分子（或原子）基态与激发态之间的能量差相等，介质分子（或原子）就会选择性地吸收这部分辐射能，从基态跃迁到激发态（激发态的寿命很短，约 $10^{-8}\,\mathrm{s}$），并通常以热的形式释放出能量，回到基态。在某些情况下，处于激发态的分子（或原子）可发生化学变化（光化学反应），或以荧光、磷光等形式发射出所吸收的能量，并回到基态。

如果入射的电磁辐射能量与介质分子（或原子）基态与激发态之间的能量差不相等，则电磁辐射不被吸收，分子（或原子）极化所需的能量仅被介质分子（或原子）瞬间（$10^{-15}\sim 10^{-14}\,\mathrm{s}$）保留，然后被再发射，从而产生光的透射、非拉曼散射、反射、折射等物理现象。

:::definition{label="选择性吸收"}
入射电磁辐射能量正好等于介质分子（或原子）基态与激发态之间的能量差时，介质选择性地吸收这部分辐射能，从基态跃迁到激发态。
:::

:::definition{label="激发态寿命"}
激发态的寿命很短，约 $10^{-8}\,\mathrm{s}$。通常以热的形式释放能量回到基态；某些情况下发生光化学反应，或以荧光、磷光发射所吸收的能量回到基态。
:::

:::definition{label="不被吸收时的再发射"}
入射能量与能级差不相等时不被吸收。极化所需能量仅被瞬间（$10^{-15}\sim 10^{-14}\,\mathrm{s}$）保留，然后被再发射，产生透射、非拉曼散射、反射、折射等。
:::

:::compare{title="能量匹配与不匹配"}
| 项目 | 能量正好等于能级差 | 能量不等于能级差 |
|------|--------------------|------------------|
| 是否吸收 | 选择性吸收 | 不被吸收 |
| 分子／原子 | 基态 → 激发态 | 瞬时极化后能量再发射 |
| 时间尺度 | 激发态寿命约 $10^{-8}\,\mathrm{s}$ | 保留 $10^{-15}\sim 10^{-14}\,\mathrm{s}$ |
| 回去的路 | 热；或光化学；或荧光、磷光 | 透射、非拉曼散射、反射、折射 |
:::

:::pitfall{label="10⁻⁸ s 是激发态寿命，10⁻¹⁵～10⁻¹⁴ s 是不被吸收时的瞬时保留"}
两本时间账不要对调。荧光、磷光走激发态那一本；透射、折射、非拉曼散射走瞬时再发射那一本。
:::

:::note{label="相互作用点到跃迁为止"}
本节说明“匹配则吸收、不匹配则再发射”。吸光度如何随浓度变化，是第4章的事。不要在这里插入朗伯–比尔定律。
:::

### （一）吸收

当电磁波作用于固体、液体和气体物质时，若电磁波的能量正好等于物质某两个能级（如基态和第一激发态）之间的能量差时，电磁辐射就可以被物质所吸收，此时电磁辐射能被转移到组成物质的原子或分子上，原子或分子从较低能态吸收电磁辐射而被激发到较高能态，这一过程叫作吸收跃迁。由于物质的能级组成是量子化的，因此吸收也是量子化的。

:::definition{label="吸收跃迁"}
电磁波能量正好等于物质某两个能级（如基态和第一激发态）之间的能量差时，电磁辐射被物质吸收，原子或分子从较低能态被激发到较高能态。这一过程叫作吸收跃迁。能级量子化，故吸收也量子化。
:::

### （二）发射

当原子或分子处于较高能态时，可以光子形式释放多余的能量而回到较低能态，产生电磁辐射，这一过程叫作发射跃迁。发射跃迁可以理解为吸收跃迁的相反过程。发射跃迁所发射的电磁辐射的能量等于较高和较低两个能态之间的能量差，因而对特定物质具有特定频率。由于原子或分子的能级组成是量子化的，因此发射跃迁也是量子化的。

:::definition{label="发射跃迁"}
原子或分子处于较高能态时，以光子形式释放多余能量回到较低能态，产生电磁辐射。发射跃迁是吸收跃迁的相反过程。发射能量等于两能态之差，故特定物质有特定频率；能级量子化，发射也量子化。
:::

:::insight{label="吸收和发射都是一份一份，所以光谱才有“线”和“带”"}
量子化不是口号：吸收、发射都只能按能级差来。原子能级间隔大且分立，看起来是线状光谱；分子还叠了振动、转动，看起来是带状光谱。第3节再分户。
:::

### （三）散射

对光来讲，当按一定方向传播的光子与其他粒子碰撞时，会改变其传播方向，而且方向的改变在宏观上具有不确定性，这种现象称为光的散射。通常情况下，被照射样品分子的直径小于入射光的波长，当光子与分子发生弹性碰撞时，相互间没有能量交换，这时所发生的散射称为瑞利（Rayleigh）散射；当光子与分子发生非弹性碰撞时，相互间有能量交换，使光子的能量增加或减少，这时将产生与入射光波长不同的散射光，这种散射称为拉曼（Raman）散射。

:::definition{label="散射"}
按一定方向传播的光子与其他粒子碰撞，改变传播方向，且方向改变在宏观上具有不确定性，称为光的散射。
:::

:::definition{label="瑞利散射"}
通常样品分子直径小于入射光波长。光子与分子弹性碰撞、没有能量交换，为瑞利（Rayleigh）散射。
:::

:::definition{label="拉曼散射"}
光子与分子非弹性碰撞、有能量交换，光子能量增加或减少，产生与入射光波长不同的散射光，为拉曼（Raman）散射。
:::

:::compare{title="瑞利散射与拉曼散射"}
| 项目 | 瑞利散射 | 拉曼散射 |
|------|----------|----------|
| 碰撞 | 弹性 | 非弹性 |
| 能量交换 | 无 | 有，光子能量增加或减少 |
| 散射光波长 | 与入射光相同 | 与入射光不同 |
| 第3节归属 | 不涉及振动能级变化的方向改变 | 拉曼散射光谱法，属光谱法 |
:::

:::pitfall{label="不要把所有散射都写成非光谱法"}
瑞利散射没有能量交换，波长不变。拉曼有能量交换，波长变，第3节把它写成光谱法。表3-2里散射浊度法才是非光谱法。
:::

### （四）反射和折射

当光从一种介质传播照射到另一种介质的界面时，一部分光在界面上改变方向返回原介质，称为光的反射；另一部分则改变方向，以一定的折射角度进入另一种介质，称为光的折射。光的折射是由于光在两种不同折射率的介质中传播速率不同而引起的。不同物质的折射率不同，不同波长的光对同一物质的折射率也是不同的，棱镜的分光作用就是基于光的这种性质。

:::definition{label="反射"}
光从一种介质照射到另一种介质的界面时，一部分在界面上改变方向返回原介质，称为反射。
:::

:::definition{label="折射"}
另一部分改变方向，以一定折射角进入另一种介质，称为折射。原因是光在两种不同折射率介质中传播速率不同。
:::

:::insight{label="棱镜分光的物理底子是“同一物质、不同波长、折射率不同”"}
不同物质折射率不同；不同波长对同一物质的折射率也不同。第4节棱镜正是靠这一点把复合光按波长展开。光栅走的是衍射和干涉，不要提前并成一种色散。
:::

### （五）干涉和衍射

当频率相同、振动相同、相位相等或相差保持恒定的波源所发射的相干波互相叠加时，会产生波的干涉现象。通过干涉现象，可以得到明暗相间的条纹。当两列波相互加强时，可得到明亮条纹；当两列波相互抵消时，则得到暗条纹。这些明暗条纹称为干涉条纹。

光波绕过障碍物而弯曲地向它后面传播的现象，称为波的衍射现象。常用的对混合光进行分光的装置是光栅，而光栅的色散作用就是多缝干涉和单缝衍射结合的结果。基于光的衍射现象而建立的分析方法最常见的是 X 射线衍射法，它是基于 X 射线照射晶体产生衍射现象，由于各种晶体的衍射规律不同，因此可作为测定晶体化合物结构的依据。

:::definition{label="干涉"}
频率相同、振动相同、相位相等或相差保持恒定的波源所发射的相干波互相叠加，产生干涉。相互加强得明条纹，相互抵消得暗条纹，合称干涉条纹。
:::

:::definition{label="衍射"}
光波绕过障碍物而弯曲地向它后面传播，称为衍射。
:::

:::definition{label="光栅色散"}
光栅的色散作用是多缝干涉和单缝衍射结合的结果。第4节还要写：多缝干涉决定谱线位置，单缝衍射决定强度分布。
:::

:::definition{label="X 射线衍射法"}
基于光的衍射建立的分析方法最常见的是 X 射线衍射法：X 射线照射晶体产生衍射，各种晶体衍射规律不同，可作为测定晶体化合物结构的依据。第3节把它划为非光谱法。
:::

:::keypoint{label="相互作用五种，先问有没有能级跃迁"}
- 吸收、发射：能级跃迁，量子化，光谱法的底子。
- 拉曼散射：非弹性，有能量交换，后面划为光谱法。
- 瑞利散射、反射、折射、干涉、衍射：方向、速率或叠加方式变，不要求内部能级跃迁。
:::

:::memory{label="E＝hν＝hc／λ＝hcσ，强度不管每个光子"}
问法：本版光子能量怎么写？和强度什么关系？
答：$E=h\nu=hc/\lambda=hc\sigma$。$h=6.626\times 10^{-34}\,\mathrm{J}\cdot\mathrm{s}$，$1\,\mathrm{eV}=1.602\times 10^{-19}\,\mathrm{J}$。能量与频率成正比、与波长成反比，与强度无关。
:::
