# 第4节　高效毛细管电泳仪

第 3 节把模式写完。本节落到仪器四块：毛细管及温度控制、进样、电路、检测及数据处理。最小配置在第 1 节已经说过——高压电源、检测器、一截毛细管；商品仪器把温控和进样加上。定性用迁移时间、定量用峰面积，细则在第 5 节。不要把 HPLC 进样阀和柱后流通池搬进来，CE 是柱上检测、管端浸入样品瓶。

:::definition{label="毛细管电泳仪四块"}
毛细管及温度控制系统、进样系统、电路系统、检测系统。图 15-8。
:::

:::concept{term="先问区带在哪根细管里走，再问怎样把几纳升送进去"}
看见仪器，先不要默写 DAD 光谱。户头是：两端各插一个缓冲液小瓶，铂电极接高压，样品在外加电压下沿管迁移，按速率排序到达检测窗，计算机按迁移时间和峰面积或峰高做定性、定量。把进样理解成液相的六通阀，死体积会把柱效吃掉。
:::

毛细管电泳仪的基本结构见图 15-8。毛细管两端分别插入两个装有运行缓冲溶液的小瓶中，同时两缓冲液中分别接入连有高压电源的铂电极。分析样品在外加电压的驱动下沿着毛细管迁移，各组分迁移速率存在差异，经过一段时间后，各组分按其迁移速率的大小排序，依次到达检测窗并转化为电信号，由计算机绘制电泳图谱，并根据谱峰的迁移时间和峰面积或峰高进行定性和定量分析。

:::insight{label="图谱长得像色谱图，轴的名字不要照搬"}
「与色谱图极为相似的电泳分离图谱」（第 2 节）。横轴是迁移时间，不是保留时间；定量用峰面积或峰高。第 5 节会写 CE 重现性不如 HPLC，宜用内标或叠加对比。
:::

## 一、毛细管及温度控制系统

毛细管是 CE 的核心部件。最常用的毛细管为外部具有聚酰亚胺涂层的石英毛细管，内径为 $20\sim 75\,\mu\mathrm{m}$，有效长度为 $50\sim 75\,\mathrm{cm}$。在毛细管电泳中，毛细管周围的环境需要保持恒温以保证分离的重现性。CE 温度控制系统主要分为风冷控温和液冷控温两种方式。

:::definition{label="石英毛细管"}
外有聚酰亚胺涂层。最常用内径 $20\sim 75\,\mu\mathrm{m}$，有效长度 $50\sim 75\,\mathrm{cm}$。聚酰亚胺不透明，检测窗处要烧掉或刮掉一段涂层，才有柱上光学检测。
:::

:::definition{label="风冷与液冷"}
第 2 节：冷却温控一是气冷、二是液冷，后者效果为佳，一般条件下气冷已可满足要求。本节仪器语言改成风冷控温、液冷控温，同一件事。
:::

:::pitfall{label="内径、有效长度三处数字"}
第 1 节概述 $25\sim 100\,\mu\mathrm{m}$；第 2 节常用 $25\sim 75\,\mu\mathrm{m}$；本节最常用 $20\sim 75\,\mu\mathrm{m}$、有效长度 $50\sim 75\,\mathrm{cm}$。有效长度不是总长，$L_{\mathrm{d}}$ 到检测器为止，总长 $L_{\mathrm{t}}$ 还要再出一段到出口缓冲瓶。
:::

:::note{label="温控首先保重现性"}
第 3 节：温度每变 $1\,^{\circ}\mathrm{C}$，黏度变 $2\%\sim 3\%$，EOF、迁移时间和压力进样体积都跟着变。恒温不是装饰。
:::

## 二、进样系统

毛细管分离通道十分细小，整个柱体积一般只有 $4\sim 5\,\mu\mathrm{L}$，所需的样品区带只有几纳升。常规色谱进样方法由于存在较大的死体积，会使毛细管电色谱分离效率严重下降，因此不适用于 CEC。毛细管电泳的进样方式一般是将毛细管的一端从缓冲液移出，放入样品瓶中，使毛细管直接与样品接触，然后由重力、电场力或其他动力来驱动样品流入管中。进样量可以通过控制驱动力的大小或时间长短来控制。

目前有三种方法可以让样品直接进入毛细管，即电动法、压力法和浓差扩散法。

电动进样法的原理为：当把毛细管的进样端插入样品溶液并加上电场时，组分因电迁移和电渗作用进入管内。电动进样对毛细管内填充介质没有特别限制，可实现自动化操作，是常用的进样方法，但电动进样对组分存在进样歧视现象，即对淌度大的组分进样量要大些。

压力进样也称流动进样，它要求毛细管中的填充介质具有流动性，比如溶液等。当将毛细管的两端置于不同的压力环境中时，管中溶液即能流动，将进样带入。压力的产生有三种方法，即正压、负压和重力虹吸作用。压力进样没有进样歧视问题，但选择性差，样品及本底溶剂都同时被引进管中，对后续分离性能产生影响。

利用浓度差扩散原理同样可将样品分子引入毛细管：当将毛细管插入样品溶液时，样品分子因管口界面存在浓度差而向管内扩散。浓差扩散进样时间在 $10\sim 60\,\mathrm{s}$ 之间，扩散进样对管内介质没有任何限制，属普适性进样方法。

:::definition{label="柱体积与进样量"}
整柱一般 $4\sim 5\,\mu\mathrm{L}$；样品区带几纳升。扫描稿常把 $\mu\mathrm{L}$ 吃成 L，不要写成 $4\sim 5\,\mathrm{L}$。
:::

:::definition{label="管端浸入式进样"}
一端离开缓冲液、插入样品瓶，直接接触，再靠重力、电场或其他动力把样品赶进管。进样量由驱动力大小或时间长短控制。
:::

:::definition{label="电动进样"}
加电场，组分靠电迁移和电渗进管。填充介质无特别限制，易自动化，常用。有进样歧视：淌度大的组分进得更多。
:::

:::definition{label="进样歧视"}
电动进样时，淌度大的组分进样量更大。定量若用外标、又不校正歧视，高淌度组分会被高估。第 5 节因此偏向内标或叠加对比。
:::

:::definition{label="压力进样"}
流动进样。介质须能流动（溶液等）。正压、负压、重力虹吸。无歧视；选择性差，样品和本底溶剂一起进管。
:::

:::definition{label="浓差扩散进样"}
管口浓度差，分子向管内扩散。时间 $10\sim 60\,\mathrm{s}$。对管内介质无限制，普适。
:::

:::compare{title="三种进样"}
| | 电动 | 压力 | 扩散 |
|--|------|------|------|
| 驱动力 | 电迁移＋电渗 | 正压／负压／虹吸 | 浓度差 |
| 介质限制 | 无特别限制 | 须能流动 | 无限制（普适） |
| 歧视 | 有，淌度大进得多 | 无 | 本版未写成歧视主因 |
| 其他 | 易自动化、常用 | 本底溶剂一并引入 | $10\sim 60\,\mathrm{s}$ |
:::

:::pitfall{label="不要用液相六通阀去灌 CE"}
常规色谱进样死体积大，毛细管电色谱柱效会严重下降，不适用于 CEC。CE／CEC 都是管端直接接触样品。第 3 节写温度升高时压力进样体积增加、峰面积增加，和这里「时间或驱动力控制进样量」是同一条链。
:::

## 三、电路系统

包括直流高压电源、电极、电极槽、导线和电解质缓冲液等。高压电源要能提供 $30\,\mathrm{kV}$ 的直流电压和 $200\sim 300\,\mu\mathrm{A}$ 的电流，电源最好使用双极性电源。理想的电源应能输出单极直流高压，能进行电压、电渗流和电功率的梯度控制。

:::definition{label="高压电源指标"}
$30\,\mathrm{kV}$ 直流；$200\sim 300\,\mu\mathrm{A}$。最好双极性。理想：单极直流高压，并能做电压、电渗流、电功率梯度。
:::

:::definition{label="电极"}
铂电极插在两端缓冲液里。图 15-8。不要答成石墨炉或玻璃电极。
:::

:::insight{label="30 kV 从 1981 年就没换档"}
Jorgenson 和 Lukacs 用的就是 $30\,\mathrm{kV}$。本节电源「要能提供 $30\,\mathrm{kV}$」，不是另给一个工作电压上限表。电场 $E=U/L_{\mathrm{t}}$，管长变了电场跟着变。
:::

:::pitfall{label="电流是微安级"}
$200\sim 300\,\mu\mathrm{A}$，不是 HPLC 泵的压力数字，也不是安培计的安培。焦耳热来自这一档电流穿过缓冲液。
:::

## 四、检测及数据处理系统

毛细管电泳采用柱上检测，避免了因死体积和组分混合导致的谱带展宽问题。目前最常用的毛细管电泳检测器是紫外检测器（UV）和荧光检测器（FD）。紫外检测器包括可变波长检测器及二极管阵列检测器（DAD）。由于受到毛细管内径的限制，UV 的检测光程短，灵敏度较低。荧光检测器灵敏度比 UV 高，适用于具有荧光性质或可以通过衍生化反应具有荧光的样品的检测；激光诱导荧光检测器（LIF）是目前 CE 灵敏度最高的检测器，可实现单分子和单原子检测；电化学检测器中安培检测器应用最广泛，这种检测器需要被测物质具有良好的电化学活性。另外两种检测模式分别为电位检测、电导检测。毛细管电泳–质谱联用技术（CE-MS）是近年来发展迅速的一种联用技术，它通过一定的接口装置将 CE 高速高效的分离能力与 MS 的高灵敏度及能提供的丰富结构信息结合起来，为生物大分子、药物小分子、中药等复杂样品的定性、定量分析提供了一种强有力的手段。

:::definition{label="柱上检测"}
检测窗开在管壁上，区带未出管就被测。避免死体积和组分混合导致的展宽。第 1 节「大大消除柱外效应」就是这一笔。
:::

:::definition{label="紫外检测器"}
最常用之一。可变波长及 DAD。光程受内径限制，浓度灵敏度较低。第 5 节用 DAD 紫外光谱定性，但特征性较差。
:::

:::definition{label="荧光与 LIF"}
FD 比 UV 灵敏，用于自身荧光或衍生后荧光的样品。LIF（激光诱导荧光）是目前 CE 灵敏度最高的检测器，可单分子、单原子检测。扫描稿常把「激光诱导」打成「激发诱导」，以印刷和第 1 节 LIF 为准。
:::

:::definition{label="电化学检测三档"}
安培应用最广泛，要求电化学活性；另有电位检测、电导检测。
:::

:::definition{label="CE-MS"}
接口把 CE 的高速高效与 MS 的高灵敏度和结构信息接起来。生物大分子、药物小分子、中药等复杂样品的定性、定量手段。第 5 节会写：最有前途的定性方法，但多数背景电解质含非挥发性盐，限制了广泛应用。
:::

:::compare{title="检测器怎么选"}
| 检测器 | 本版定位 | 限制 |
|--------|----------|------|
| UV／DAD | 最常用；DAD 可给紫外光谱 | 光程短，浓度灵敏度不及 HPLC |
| FD | 比 UV 灵敏 | 要有荧光或能衍生 |
| LIF | 目前最高；单分子／单原子 | 仪器和标记门槛 |
| 安培 | 电化学里最常用 | 要有电化学活性 |
| 电位／电导 | 另外两种电化学模式 | 本节未展开 |
| CE-MS | 结构信息＋高灵敏 | 非挥发性盐背景 |
:::

:::keypoint{label="仪器四块收口"}
- 管：聚酰亚胺石英，$20\sim 75\,\mu\mathrm{m}$，$L_{\mathrm{d}}$ 常 $50\sim 75\,\mathrm{cm}$；风冷或液冷。
- 进样：浸入式；电动（有歧视）、压力（无歧视）、扩散（$10\sim 60\,\mathrm{s}$）。
- 电源：$30\,\mathrm{kV}$，$200\sim 300\,\mu\mathrm{A}$，最好双极性。
- 检测：柱上；UV／FD 最常用，LIF 最灵，CE-MS 管结构。
:::

:::memory{label="仪器口诀"}
两端瓶子两根铂丝，中间一截石英管。几纳升靠浸入，不要六通阀。柱上看窗，光程就是内径。
:::
