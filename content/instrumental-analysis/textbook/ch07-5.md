# 第5节　实验技术

前四节把原理、仪器和 $A=K'c$ 三种定量立住。本节写实验室真正要选的条件：样品预处理、分析线、火焰／石墨炉程序，以及物理、化学、电离、光谱四类干扰及抑制。分析线通常是共振线，但不是任何情况都选共振线。干扰总体较小，但不能听成“AAS 没有干扰”。不要把第 6 节药典示例提前搬进来顶替条件选择。

## 一、样品预处理

对于微量元素分析来说，样品预处理过程中所用试剂的纯度对分析测定结果有很大影响。如溶解样品用的水、酸碱、光谱缓冲剂、电离抑制剂、释放剂、萃取溶剂、配制标准溶液的基体等，都必须是高纯度的，应不污染待测元素。

:::definition{label="预处理试剂必须高纯"}
水、酸碱、光谱缓冲剂、电离抑制剂、释放剂、萃取溶剂、标准溶液的基体等，都必须是高纯度的，应不污染待测元素。
:::

此外，在实际工作中，为了避免被测元素的损失，可使储备液的浓度尽量大一些（一般来说浓度为 $1\text{‰}$ 的储备液在一年内使用其结果不受影响），小于 $0.001\text{‰}$ 的溶液不宜作为储备液。标准曲线工作溶液因为浓度较稀应于当天使用，久放则其曲线斜率会有改变。

:::definition{label="储备液与工作溶液"}
浓度 $1\text{‰}$ 的储备液在一年内使用结果不受影响。小于 $0.001\text{‰}$ 的溶液不宜作为储备液。标准曲线工作溶液应于当天使用，久放则斜率会改变。
:::

在火焰原子化法中，样品经过预处理后才能进行原子吸收光谱测定。样品的预处理是将样品处理成溶液状态，也就是对样品进行分解，使微量元素处于溶解状态。不同的样品有不同的预处理方法，同一样品也有多种预处理方法，选择不同处理方法的依据是方便快捷，同时又要尽量减少样品的用量，减少有效成分的流失。目前，原子吸收测定前样品预处理常用的方法有干法消化法、湿法消化法、酸溶解法及密封微波溶样法等。无机固体样品需要用合适的溶剂和方法溶解，尽可能将被测元素完全转入溶液中，并控制溶液总盐量在合适范围内。有机固体样品则先用干法或湿法消化有机物，再将消化后的残留物溶解在合适的溶剂中。挥发性元素如 $\mathrm{Hg}$、$\mathrm{As}$、$\mathrm{Cd}$、$\mathrm{Pd}$、$\mathrm{Se}$ 等不宜采用干法灰化。

:::definition{label="火焰法常用预处理"}
干法消化、湿法消化、酸溶解、密封微波溶样。无机固体：溶解完全并控制总盐量。有机固体：先消化有机物，再溶残留物。
:::

:::pitfall{label="Hg、As、Cd、Pd、Se 不宜干法灰化"}
本版点名的挥发性元素是 $\mathrm{Hg}$、$\mathrm{As}$、$\mathrm{Cd}$、$\mathrm{Pd}$、$\mathrm{Se}$。不要用别的书改成另一组名单，也不要把“有机样品都要干法灰化”当成定理。石墨炉可以直接分析固体样品，程序升温把易挥发或易热解的基体在原子化前除去，那是另一条路。
:::

使用石墨炉原子化器可以直接分析固体样品，采用程序升温，可以分别控制样品的干燥、灰化、原子化和净化过程，将易挥发的或易热解的基体在原子化前除去。

:::definition{label="石墨炉可直接分析固体"}
程序升温分别控制干燥、灰化、原子化、净化，把易挥发或易热解的基体在原子化前除去。
:::

## 二、测定条件的选择

原子吸收分光光度法中，测定条件的选择对测定的灵敏度、准确度等都会有较大的影响，因此，通过选择合适的测定条件才能获得满意的分析结果。

### （一）分析线的选择

分析线就是用于原子吸收测定的吸收线。由于共振吸收线一般是最灵敏的吸收线，所以通常选用共振吸收线为分析线。但并不是任何情况都选择共振吸收线作为分析线。如 $\mathrm{Hg}$、$\mathrm{As}$、$\mathrm{Se}$ 等元素的共振吸收线位于远紫外区，火焰组分对来自光源的光有明显吸收，不宜选择其共振吸收线作分析线，此时可选择灵敏度较低的非共振吸收线作为分析线。此外，当被测元素的共振吸收线受其他谱线干扰时，也不能选择共振吸收线作为分析线。即使共振线不受干扰，在实际工作中，也未必都要选用共振吸收线为分析线，如在分析较高浓度的样品时，有时宁愿选取灵敏度较低的谱线为分析线，以便得到适度的吸收值，改善标准曲线的线性范围。最适宜的分析线应视具体情况由实验决定。

实验方法是：首先扫描锐线光源的发射光谱，了解有哪几条可供选用的谱线，然后喷入样品溶液，观察溶液对这些谱线的吸收情况，应该选用不受干扰且吸收值适度的吸收线作为分析线，最强的吸收线最适于微量元素的测定。

:::definition{label="分析线"}
用于原子吸收测定的吸收线。通常选用最灵敏的共振吸收线，但不是任何情况都选共振线。
:::

:::keypoint{label="什么时候不选共振线"}
- $\mathrm{Hg}$、$\mathrm{As}$、$\mathrm{Se}$ 等共振线在远紫外，火焰组分明显吸收。
- 共振线受其他谱线干扰。
- 较高浓度样品：改用灵敏度较低的线，让吸收值适度、改善线性范围。
- 最强的吸收线最适于微量元素。最终由实验决定：先扫灯的发射，再喷样品看吸收。
:::

:::pitfall{label="不要把“通常选共振线”听成“永远选最灵敏的那根”"}
思考题第 1 题问为什么常常选共振线：因为一般最灵敏，且第 2 节已说明对大多数元素它是所有谱线中最灵敏的。答完“常常”还要留下第 5 节这几条例外，否则高浓度样品会把标准曲线顶出直线。
:::

### （二）原子化条件

**火焰原子化法。** 火焰的类型和特性是影响原子化效率的主要因素，火焰的氧化还原特性对原子化效率和基态原子在火焰中的分布都有较大影响。分析线在 $200\,\mathrm{nm}$ 以下的短波区元素如 $\mathrm{Se}$、$\mathrm{P}$ 等，由于烃类火焰对这些元素有明显吸收，不宜使用乙炔火焰，宜使用氢火焰。易电离元素如碱金属和碱土金属，不宜使用高温火焰。易形成难解离氧化物的元素如 $\mathrm{B}$、$\mathrm{Al}$、$\mathrm{Zr}$ 等，应选用高温火焰，最好用富燃火焰。对于氧化物不十分稳定的元素如 $\mathrm{Cu}$、$\mathrm{Mg}$、$\mathrm{Fe}$、$\mathrm{Co}$、$\mathrm{Ni}$ 等，可采用化学计量火焰或贫燃火焰。为了获得所需特性的火焰，可以调节燃气和助燃气的流量。此外，在火焰区内，基态原子的分布是不均匀的，为了使来自光源的光束通过基态原子浓度最大的区域，应调节燃烧器的高度，从而获得较高的测定灵敏度。

:::definition{label="火焰类型怎样选"}
$200\,\mathrm{nm}$ 以下（$\mathrm{Se}$、$\mathrm{P}$ 等）：不宜乙炔（烃类火焰明显吸收），宜氢火焰。易电离（碱金属、碱土金属）：不宜高温火焰。难解离氧化物（$\mathrm{B}$、$\mathrm{Al}$、$\mathrm{Zr}$）：高温、最好富燃。氧化物不十分稳定（$\mathrm{Cu}$、$\mathrm{Mg}$、$\mathrm{Fe}$、$\mathrm{Co}$、$\mathrm{Ni}$）：化学计量或贫燃。
:::

:::definition{label="燃烧器高度"}
火焰区内基态原子分布不均匀。调节燃烧器高度，使光束通过基态原子浓度最大的区域，以获得较高灵敏度。
:::

:::compare{title="火焰氧化还原特性（本版点名的元素）"}
| 对象 | 不宜 | 宜用 |
|------|------|------|
| $\mathrm{Se}$、$\mathrm{P}$ 等，$<200\,\mathrm{nm}$ | 乙炔（烃类吸收） | 氢火焰 |
| 碱金属、碱土金属 | 高温火焰（易电离） | 较低温火焰 |
| $\mathrm{B}$、$\mathrm{Al}$、$\mathrm{Zr}$ | 低温、贫燃 | 高温，最好富燃 |
| $\mathrm{Cu}$、$\mathrm{Mg}$、$\mathrm{Fe}$、$\mathrm{Co}$、$\mathrm{Ni}$ | — | 化学计量或贫燃 |
:::

**石墨炉原子化法。** 合理选择干燥、灰化、原子化和净化的温度与时间十分重要。干燥是低温除去溶剂的过程，应在稍低于溶剂沸点的温度下进行，以防止试液飞溅。灰化的目的是破坏和蒸发除去样品的基体，在保证被测元素没有损失的前提下，应尽可能使用较高的灰化温度。原子化阶段应选择能达到最大吸收信号的最低温度作为原子化温度。净化的目的是消除残留物产生的记忆效应，温度应高于原子化温度。各阶段的加热时间，依样品不同而不同，需通过实验确定，如原子化时间的选择是需要保证样品完全原子化。石墨炉原子化法常用的保护气体是氩气，流速通常为 $1\sim 5\,\mathrm{L}\cdot\mathrm{min}^{-1}$，且在原子化阶段应停止通保护气，以延长基态原子在石墨炉内的平均停留时间。

:::definition{label="石墨炉四段温度"}
干燥：稍低于溶剂沸点，防飞溅。灰化：被测元素无损失的前提下尽可能高，除去基体。原子化：能达最大吸收信号的最低温度。净化：高于原子化温度，消除记忆效应。
:::

:::definition{label="石墨炉保护气"}
常用氩气，流速通常 $1\sim 5\,\mathrm{L}\cdot\mathrm{min}^{-1}$。原子化阶段应停止通保护气，以延长基态原子平均停留时间。
:::

:::pitfall{label="原子化阶段不要继续猛吹氩气"}
第 3 节说保护气防止氧化、延长石墨管寿命；第 5 节补一句：原子化时停气，让基态原子多留一会儿。两句都要，停气不是把保护气整段关掉。干燥温度若高于沸点，试液飞溅，后面灰化、原子化都对不上。
:::

:::keypoint{label="石墨炉四段各管一件事"}
- 干燥：去溶剂，稍低于沸点。
- 灰化：去基体，尽量高但不丢待测元素。
- 原子化：最大信号的最低温度；停保护气。
- 净化：比原子化更高，清记忆效应。
:::

## 三、干扰及抑制

原子吸收分光光度法的干扰总体较小，但仍然存在，实际工作中某些情况下的干扰问题不容忽视。原子吸收分光光度法的干扰效应主要有物理干扰、化学干扰、电离干扰和光谱干扰。

:::definition{label="四类干扰"}
物理干扰、化学干扰、电离干扰、光谱干扰。总体较小，不是没有。
:::

### （一）物理干扰

物理干扰是指样品在转移、蒸发和原子化过程中，由于样品物理特性的变化而引起吸光度下降的效应。在火焰原子化法中，试液的黏度改变将影响进样速度，表面张力会影响形成雾珠的大小，试剂的蒸气压将影响蒸发速度和凝聚损失，雾化气体压力、取样管的直径和长度则影响取样量的多少。在石墨炉原子化法中，进样量的多少、保护气的流速将影响基态原子在吸收区的平均停留时间，所有这些因素最终都将改变样品的吸光度。

物理干扰是非选择性干扰，对样品中各元素的影响基本上是相似的。配制与被测样品组成相似的标准样品，是消除物理干扰最常用的方法。此外，用标准加入法消除物理干扰也是一种行之有效的方法。

:::definition{label="物理干扰"}
转移、蒸发和原子化过程中，样品物理特性变化引起吸光度下降。非选择性：对各元素影响基本相似。消除：组成相似的标准样品；标准加入法。
:::

:::insight{label="物理干扰和标准加入法对得上"}
第 4 节标准加入法就是为克服标样与试样不一致的基体效应。黏度、表面张力、盐分这些物理量变了，喷雾和停留时间跟着变，匹配基体或把标准加进样品，走的是同一条路。
:::

### （二）化学干扰

化学干扰是待测元素在原子化过程中与基体组分原子或分子之间发生化学作用，从而影响被测元素的解离及其原子化。化学干扰取决于待测元素和共存物质的性质，以及原子化方法及条件。

化学干扰与特定的反应相关，属于选择性干扰。减少或消除化学干扰的方法包括改变原子化条件、加入释放剂和保护剂、使用基体改进剂和化学分离等。

:::definition{label="化学干扰"}
原子化过程中待测元素与基体组分原子或分子发生化学作用，影响解离和原子化。选择性干扰。抑制：改变原子化条件；释放剂、保护剂；基体改进剂；化学分离。
:::

### （三）电离干扰

电离干扰是电离能较低的金属元素在原子化过程中产生电离而使火焰中待测元素的基态原子数减少，引起原子吸收信号降低。加入易电离元素、提高金属元素总浓度、增加火焰中的自由电子浓度及采用强还原性的富燃火焰或者采用标准加入法都可以有效地抑制和消除电离干扰。碱金属元素电离电位低，是一种常用的消电离剂。

:::definition{label="电离干扰"}
电离能较低的金属在原子化时电离，基态原子数减少，吸收信号降低。抑制：加易电离元素；提高金属总浓度；增加火焰自由电子；富燃火焰；标准加入法。碱金属电离电位低，常用作消电离剂。
:::

:::pitfall{label="碱金属既是易电离对象，也是消电离剂"}
测碱金属、碱土金属时不宜高温火焰，因为它们自己容易电离。往别的元素的试液里加碱金属，则是提供自由电子、压住待测元素的电离。同一族元素，角色取决于它是被测物还是添加剂。不要写成“碱金属一律不能出现在火焰里”。
:::

### （四）光谱干扰

吸收谱线的重叠、原子化过程中产生的复合光谱及可能存在的非吸收线等都会产生光谱干扰，影响测定结果。另外，由分子吸收及光散射形成的背景干扰也属于光谱干扰。消除光谱干扰的方法主要是针对产生干扰的因素，正确选择仪器条件，或采用仪器配置的各种背景校正技术进行校正。

:::definition{label="光谱干扰"}
谱线重叠、复合光谱、非吸收线；分子吸收及光散射形成的背景也属于光谱干扰。消除：正确选择仪器条件，或用仪器的背景校正技术。
:::

:::compare{title="四类干扰怎样分户"}
| 类型 | 选择性 | 典型原因 | 本版点名的抑制 |
|------|--------|----------|----------------|
| 物理 | 非选择性 | 黏度、表面张力、蒸气压、管径、进样量、保护气流速 | 组成相似的标准；标准加入法 |
| 化学 | 选择性 | 与基体发生化学反应，影响解离／原子化 | 改原子化条件；释放剂、保护剂；基体改进剂；化学分离 |
| 电离 | 针对易电离金属 | 基态原子被电离掉 | 消电离剂（碱金属）；富燃；标准加入等 |
| 光谱 | 针对谱线／背景 | 重叠、复合光谱、非吸收线；分子吸收、光散射 | 选仪器条件；背景校正 |
:::

:::pitfall{label="标准加入消不了光谱背景"}
第 4 节已经写：标准加入主要克服基体效应，对分子和背景吸收引起的干扰仍不能消除。物理干扰、部分电离干扰可以靠它；光谱干扰要换条件或开背景校正。把“有标准加入就不用扣背景”写进答卷，四类干扰并户了。
:::

:::memory{label="实验技术三句"}
- 储备液 $1\text{‰}$ 可用一年；$<0.001\text{‰}$ 不当储备液；工作溶液当天用。$\mathrm{Hg}$、$\mathrm{As}$、$\mathrm{Cd}$、$\mathrm{Pd}$、$\mathrm{Se}$ 不干法灰化。
- 分析线通常是共振线；远紫外、有干扰、高浓度则改线。火焰按元素选氢焰／富燃／贫燃；石墨炉四段，原子化停氩气 $1\sim 5\,\mathrm{L}\cdot\mathrm{min}^{-1}$。
- 干扰四类：物理非选择、化学选择、电离减基态、光谱含背景。
:::
