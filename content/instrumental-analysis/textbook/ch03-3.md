# 第3节　光学分析法的分类

第2节把辐射写成波和光子。本节按三把钥匙分类：测量信号是否与能级跃迁有关（光谱法／非光谱法）；电磁辐射作用于原子还是分子（原子光谱／分子光谱）；能级跃迁方向（吸收／发射／拉曼）。表3-2、表3-3、表3-4按本版名单抄全。原子光谱是线状光谱，分子光谱是带状光谱；电子能级差按本版 $1\sim 20\,\mathrm{eV}$（$1250\sim 60\,\mathrm{nm}$），不要改用别的书的约数。

由于各种电磁辐射的能量不同，与物质相互作用的机理不同，因此所产生的物理现象也不同，可以建立不同的光学分析方法。

:::concept{term="先问有没有跃迁，再问作用的是原子还是分子，再问跃迁往哪边走"}
三把钥匙不要并成一句“都是光谱”。没有内部跃迁的折射、衍射、旋光走非光谱；气态原子的线状光谱不能回答分子结构；吸收是从低到高，发射是从高到低，拉曼是非弹性散射。
:::

## 一、光谱法和非光谱法

按测量信号是否与能级跃迁有关，光学分析法可分为光谱法和非光谱法两大类。

当物质与电磁辐射相互作用时，物质内部发生能级跃迁，记录由能级跃迁所产生的辐射能强度随波长（或相应单位）的变化，所得的图谱称为光谱（又称为波谱，spectrum）。利用物质的光谱进行定性、定量和结构分析的方法称为光谱分析法，简称为光谱法。光谱法涉及不同能级之间的跃迁，可进一步划分为多种分析方法，应用甚广，是现代分析化学的重要组成部分。

非光谱法是当物质与电磁辐射相互作用时，测量辐射的某些性质（如折射、散射、干涉、衍射、偏振等）变化的分析方法。非光谱法不涉及物质内部能级的跃迁，在药物分析中应用较少。

:::

:::definition{label="光谱法"}
利用物质的光谱进行定性、定量和结构分析的方法称为光谱分析法，简称光谱法。它涉及不同能级之间的跃迁。
:::

:::

:::pitfall{label="第1节说非光谱法药学有用，第3节说药物分析中应用较少"}
两句话不打架：第1节点名折光率、旋光度被《中国药典》收载、后续课程学习；第3节说非光谱法在药物分析中应用较少、本书主线是光谱法。不要用其中一句把另一句删掉。
:::

:::insight{label="光谱是“强度对波长”，不是随便一张图"}
教材把光谱写成：辐射能强度随波长（或相应单位）的变化。波数、频率也可以当横轴，所以括号里写“或相应单位”。没有能级跃迁，就没有这张谱，那是非光谱法。
:::

## 二、原子光谱法和分子光谱法

按电磁辐射作用于物质粒子的类型，光谱法可分为原子光谱法和分子光谱法。

### （一）原子光谱法

原子光谱法（atomic spectroscopy）是以测量气态原子（或离子）外层或内层电子能级跃迁所产生的原子光谱为基础的分析方法。

当物质中原子受外界能量激发时，其核外电子由基态跃迁至激发态。由于每种原子的结构和核外电子排布不同，不同元素的原子只能激发到特定的激发态，所以每种原子所能吸收的辐射能量不同，即被吸收的光的波长不同。电子从基态跃迁至第一激发态所产生的吸收谱线称为共振吸收线（简称为共振线）。当电子由第一激发态跃迁回到基态时，发射出同样波长的光，对应的谱线称为共振发射线（简称为共振线）。原子光谱便是由一条条彼此分立的谱线组成的线状光谱（图3-2），每条光谱线对应于一定的波长，这种线状光谱反映了原子或离子的性质，但与原子或离子来源的分子状态无关。所以，原子光谱可以确定物质的元素组成和含量，但不能给出物质分子结构的信息。

:::definition{label="原子光谱法"}
原子光谱法（atomic spectroscopy）是以测量气态原子（或离子）外层或内层电子能级跃迁所产生的原子光谱为基础的分析方法。
:::

:::definition{label="共振吸收线"}
电子从基态跃迁至第一激发态所产生的吸收谱线称为共振吸收线，简称共振线。
:::

:::definition{label="共振发射线"}
电子由第一激发态跃迁回到基态时，发射出同样波长的光，对应的谱线称为共振发射线，也简称共振线。
:::

:::definition{label="线状光谱"}
原子光谱由一条条彼此分立的谱线组成，称为线状光谱。每条光谱线对应于一定的波长。它反映原子或离子的性质，与来源的分子状态无关。
:::

::figure{src="/images/instrumental-analysis/textbook/p0057_01.jpg" caption="图3-2　铁的原子光谱。235～246 nm 区间一条条彼此分立的谱线，标为铁谱，是线状光谱的教材例。" alt="铁的原子发射线状光谱：横轴波长 235 至 246 纳米，多条分立竖线，右标铁谱"}

:::note{label="图3-2 与教材对齐"}
图3-2用铁谱说明线状光谱：谱线分立，每条对应一定波长。它能说明“这是铁”，不能说明铁来自哪种分子。
:::

:::keypoint{label="原子光谱能做什么、不能做什么"}
- 能：确定物质的元素组成和含量。
- 不能：给出物质分子结构的信息。
- 原因：线状光谱与原子或离子来源的分子状态无关。
:::

原子光谱法可分为三种类型：基于原子外层电子跃迁的原子发射光谱法、原子吸收分光光度法、原子荧光光谱法；基于原子内层电子跃迁的 X 射线荧光光谱法；基于原子核与 γ 射线相互作用的穆斯堡尔谱法（Mössbauer spectroscopy）等。在药物分析领域中，常用的是原子吸收分光光度法和原子荧光光谱法。

:::compare{title="原子光谱法的三种类型"}
| 类型 | 依据 | 方法 | 药物分析 |
|------|------|------|----------|
| 外层电子跃迁 | 气态原子外层电子 | AES、AAS、AFS | 常用 AAS、AFS |
| 内层电子跃迁 | 原子内层电子 | X 射线荧光光谱法 | 本章列入，不作为药物分析常用项点名 |
| 核与 γ 射线 | 原子核 | 穆斯堡尔谱法 | 表3-3 有户头 |
:::

:::pitfall{label="共振线既指吸收也指发射，都是基态↔第一激发态"}
共振吸收线和共振发射线都简称共振线，波长相同。不要把“共振”听成核磁共振那一本账，也不要写成任意激发态之间的线。
:::

:::pitfall{label="原子光谱确定元素，不定分子结构"}
铁谱再密，也只说明样品里有铁。氧化物、络合物、有机铁的结构要问分子光谱。把原子吸收当成“结构鉴定”，红外和核磁会没有位置。
:::

### （二）分子光谱法

分子光谱法（molecular spectroscopy）是基于物质分子与电磁辐射作用时，分子内部发生了量子化的能级跃迁，测量由此产生的反射、吸收或散射辐射的波长和强度而进行分析的方法。

分子中存在电子运动、振动和转动三种运动状态，分别对应于相应的电子能级、振动能级和转动能级。分子光谱表现为带状光谱，比原子光谱复杂得多，这是因为在分子中，除了电子能级跃迁之外，还有组成分子的各原子之间的振动能级跃迁和分子作为整体的转动能级跃迁，这三种不同的能级跃迁都是量子化的（图3-3）。电子能级间的能量差 $\Delta E_{\mathrm{e}}$ 一般为 $1\sim 20\,\mathrm{eV}$（$1250\sim 60\,\mathrm{nm}$），相当于紫外光和可见光的能量；振动能级间的能量差 $\Delta E_{\mathrm{v}}$ 一般为 $0.05\sim 1\,\mathrm{eV}$（$25\,000\sim 1\,250\,\mathrm{nm}$），相当于红外光的能量；转动能级间的能量差 $\Delta E_{\mathrm{r}}$ 一般为 $0.005\sim 0.05\,\mathrm{eV}$（$250\sim 25\,\mathrm{\mu m}$），相当于远红外至微波的能量。因为在同一电子能级上还有很多间隔较小的振动能级和间隔更小的转动能级，当用紫外–可见光照射时，不仅发生电子能级的跃迁，同时发生振动能级的跃迁和转动能级的跃迁。因此，在电子能级间发生跃迁时，得到的是很多光谱带，这些光谱带都对应不同的 $\Delta E_{\mathrm{e}}$ 值，并且包含许多 $\Delta E_{\mathrm{v}}$ 和 $\Delta E_{\mathrm{r}}$ 值，形成一个光谱带系。对于一种分子来说，可以观察到不同电子能级跃迁的光谱带系，分子的紫外–可见吸收光谱实际上是电子–振动–转动光谱，是复杂的带状光谱。实际上，只有用远红外光或微波照射分子时才能得到纯粹的转动光谱，而纯粹的振动光谱和电子光谱是难以得到的。

:::definition{label="分子光谱法"}
分子光谱法（molecular spectroscopy）是基于物质分子与电磁辐射作用时，分子内部发生量子化的能级跃迁，测量由此产生的反射、吸收或散射辐射的波长和强度而进行分析的方法。本版定义用“反射、吸收或散射”，不要擅自改成别的书的“发射、吸收或散射”。
:::

:::definition{label="分子的三种运动"}
分子中存在电子运动、振动和转动三种运动状态，分别对应于电子能级、振动能级和转动能级。三种跃迁都是量子化的。
:::

:::definition{label="带状光谱"}
分子光谱表现为带状光谱，比原子光谱复杂。同一电子能级上还有间隔较小的振动能级和间隔更小的转动能级，电子跃迁总是带着振动、转动一起走，得到光谱带系。
:::

:::compare{title="本版三种分子能级差"}
| 能级 | 能量差 | 对应波长 | 相当于 |
|------|--------|----------|--------|
| 电子 $\Delta E_{\mathrm{e}}$ | $1\sim 20\,\mathrm{eV}$ | $1250\sim 60\,\mathrm{nm}$ | 紫外光和可见光 |
| 振动 $\Delta E_{\mathrm{v}}$ | $0.05\sim 1\,\mathrm{eV}$ | $25\,000\sim 1\,250\,\mathrm{nm}$ | 红外光 |
| 转动 $\Delta E_{\mathrm{r}}$ | $0.005\sim 0.05\,\mathrm{eV}$ | $250\sim 25\,\mathrm{\mu m}$ | 远红外至微波 |
:::

:::note{label="图3-3 与教材对齐"}
图3-3把电子、振动、转动画成套叠：电子能级间距最大，振动次之，转动最密。紫外–可见照射时三条账一起动，所以得到带状光谱而不是一条条原子线。
:::

:::keypoint{label="紫外–可见分子光谱实际是电子–振动–转动光谱"}
- 用紫外–可见光照射：电子跃迁 $+$ 振动跃迁 $+$ 转动跃迁。
- 得到很多光谱带，形成光谱带系。
- 只有远红外或微波才能得到纯粹的转动光谱。
- 纯粹的振动光谱和电子光谱难以得到。
:::

:::pitfall{label="不要把分子紫外–可见当成“纯电子光谱”"}
教材写明：分子的紫外–可见吸收光谱实际上是电子–振动–转动光谱，是复杂的带状光谱。把带状光谱听成仪器没调好，后面红外、微波的户头会对错。
:::

:::pitfall{label="电子能级差按本版 1～20 eV（1250～60 nm）"}
不要用别的书的 $2\sim 10\,\mathrm{eV}$ 或 $200\sim 800\,\mathrm{nm}$ 替换。振动是 $0.05\sim 1\,\mathrm{eV}$（$25\,000\sim 1\,250\,\mathrm{nm}$），转动是 $0.005\sim 0.05\,\mathrm{eV}$（$250\sim 25\,\mathrm{\mu m}$）。
:::

分子光谱法包括紫外–可见吸收光谱法、红外吸收光谱法、分子荧光和磷光光谱法等。

## 三、吸收光谱法、发射光谱法和拉曼散射光谱法

按能级跃迁方向的不同，光谱分析法可分为吸收光谱法、发射光谱法和拉曼散射光谱法。

### （一）吸收光谱法

吸收光谱是物质吸收相应的辐射能而产生的光谱，其产生的必要条件是所提供的辐射能量恰好满足该吸收物质两能级间跃迁所需的能量。利用物质的吸收光谱进行定性、定量和结构分析的方法称为吸收光谱法（absorption spectrometry，AS）。

根据物质对不同波长的辐射能的吸收，建立了各种吸收光谱法（表3-3）。在药物分析中应用较多的吸收光谱法主要有紫外–可见吸收光谱法、红外吸收光谱法、核磁共振波谱法、原子吸收分光光度法等。

:::definition{label="吸收光谱"}
吸收光谱是物质吸收相应的辐射能而产生的光谱。必要条件：所提供的辐射能量恰好满足该吸收物质两能级间跃迁所需的能量。
:::

:::definition{label="吸收光谱法"}
利用物质的吸收光谱进行定性、定量和结构分析的方法称为吸收光谱法（absorption spectrometry，AS）。
:::

| X 射线吸收光谱法 | X 射线；放射性同位素 | $Z>10$ 的重元素原子的内层电子 | 吸收后的 X 射线 |
| 原子吸收分光光度法 | 紫外光、可见光 | 气态原子外层的电子 | 吸收后的紫外光、可见光 |

:::

:::note{label="红外吸收的辐射能按本版写 2.5～25 μm"}
表3-3写炽热硅碳棒等 $2.5\sim 25\,\mathrm{\mu m}$ 红外光，对应表3-1中红外区，作用物质是分子振动。不要改成别的书的波数扫描范围。
:::

### （二）发射光谱法

发射光谱是指构成物质的原子、离子或分子受到激发而产生的光谱。利用物质的发射光谱进行定性、定量和结构分析的方法称为发射光谱法（emission spectrometry，ES）。

根据物质发射的辐射不同，建立了各种发射光谱法（表3-4）。在药物分析中应用较多的发射光谱法主要有原子发射光谱法、分子荧光光谱法等。

:::definition{label="发射光谱"}
发射光谱是构成物质的原子、离子或分子受到激发而产生的光谱。
:::

:::definition{label="发射光谱法"}
利用物质的发射光谱进行定性、定量和结构分析的方法称为发射光谱法（emission spectrometry，ES）。
:::

:::compare{title="表3-4　发射光谱法"}
| 方法名称 | 辐射能 | 作用物质 | 检测信号 |
|----------|--------|----------|----------|
| X 射线荧光光谱法 | X 射线（$0.01\sim 2.5\,\mathrm{nm}$） | 原子内层电子的逐出，外层能级电子跃入空位（电子跃迁） | 特征 X 射线（X 射线荧光） |
| 原子发射光谱法 | 火焰、电弧、火花、离子炬等 | 气态原子外层电子 | 紫外光、可见光 |
| 原子荧光光谱法 | 高强度紫外光、可见光 | 气态原子外层电子跃迁 | 原子荧光 |
| 分子荧光光谱法 | 紫外光、可见光 | 分子 | 荧光（紫外光、可见光） |
| 磷光光度法 | 紫外光、可见光 | 分子 | 磷光（紫外光、可见光） |
| 化学发光分析法 | 化学能 | 分子 | 可见光 |
:::

:::pitfall{label="荧光、磷光、X 射线荧光都写在发射光谱法表里"}
它们的激发方式不同：X 射线荧光用 X 射线打内层电子；原子／分子荧光用紫外、可见光；化学发光用化学能。检测的都是样品自己发出来的辐射，所以进表3-4，不要因为名字带“光”就并进吸收表。
:::

:::compare{title="药物分析点名较多的吸收法与发射法"}
| 类别 | 本版点名“应用较多” |
|------|----------------------|
| 吸收光谱法 | 紫外–可见吸收光谱法、红外吸收光谱法、核磁共振波谱法、原子吸收分光光度法 |
| 发射光谱法 | 原子发射光谱法、分子荧光光谱法 |
:::

### （三）拉曼散射光谱法

当用单色光照射到透明样品时，大部分光按原来的方向透射，而小部分光则按不同的角度散射开来。如果由于辐射与待测物质分子相互作用时发生能量交换，引起分子振动能级的变化，并有辐射能量的增加或减小，因而产生与入射光波长不同的散射光，这种散射称为拉曼散射。根据拉曼散射光谱而建立起来的分析方法称为拉曼散射光谱法（Raman scattering spectroscopy）。

:::definition{label="拉曼散射"}
单色光照射透明样品，大部分透射，小部分按不同角度散射。辐射与分子发生能量交换，引起分子振动能级变化，辐射能量增加或减小，产生与入射光波长不同的散射光，称为拉曼散射。
:::

:::definition{label="拉曼散射光谱法"}
根据拉曼散射光谱建立的分析方法称为拉曼散射光谱法（Raman scattering spectroscopy）。
:::

:::compare{title="吸收、发射、拉曼：跃迁方向不同"}
| 项目 | 吸收光谱法 | 发射光谱法 | 拉曼散射光谱法 |
|------|------------|------------|----------------|
| 能量流向 | 辐射 → 物质，物质从低到高 | 物质从高到低，辐射出来 | 散射过程中与分子交换能量 |
| 必要条件／特征 | 辐射能量恰好等于两能级差 | 原子、离子或分子被激发 | 非弹性散射，波长与入射光不同 |
| 振动账 | 红外吸收直接对应振动 | 荧光／磷光是电子激发后的发射 | 拉曼引起振动能级变化 |
| 本版英文 | absorption spectrometry，AS | emission spectrometry，ES | Raman scattering spectroscopy |
:::

:::memory{label="三把分类钥匙"}
问法：光学分析法按什么分？
答：①有没有内部能级跃迁 → 光谱／非光谱。②作用粒子 → 原子（线状）／分子（带状）。③跃迁方向 → 吸收／发射／拉曼。
:::

:::example{label="铁谱是原子线，紫外–可见分子谱是带"}
图3-2的铁谱一条条分立，只能回答“有铁”。图3-3的分子能级套叠决定了紫外–可见分子吸收是带状的电子–振动–转动光谱。两张图不要并用成“光谱都是线”。
:::

:::definition{label="火焰光度法"}
表3-2在辐射的发射下列出火焰光度法，类型为光谱法。它与原子发射光谱法近亲：用火焰提供激发能，检测发射。本节按表立户，不要改写成非光谱。
:::

:::definition{label="核磁共振法与电子自旋共振法"}
二者都在表3-2“辐射的吸收”、光谱法。表3-3进一步写：核磁共振用 $0.1\sim 100\,\mathrm{MHz}$ 射频，作用原子核磁量子／有机分子质子；电子自旋共振用 $10\,000\sim 800\,000\,\mathrm{MHz}$ 微波，作用未成对电子。不要因为“波谱”二字就把它们划出光学分析法。
:::

:::definition{label="X 射线荧光光谱法"}
基于原子内层电子跃迁。表3-4：入射 X 射线 $0.01\sim 2.5\,\mathrm{nm}$，内层电子被逐出，外层电子跃入空位，检测特征 X 射线（X 射线荧光）。它是发射光谱法，不是吸收表里的 X 射线吸收光谱法。
:::

:::definition{label="化学发光分析法"}
表3-4：辐射能是化学能，作用物质是分子，检测可见光。激发不靠灯，靠化学反应，但仍属发射光谱法——样品自己发光。
:::

:::definition{label="激光光声光谱法与激光热透镜光谱法"}
表3-3把二者列入吸收光谱法。光声检测的是声压，热透镜检测的仍是吸收；作用物质分别是分子（气体、液体、固体）和分子（溶液）。不要因为检测信号不是“吸收后的光”就把它们划出吸收法。
:::

:::keypoint{label="三张表怎么用"}
- 表3-2：先按原理（发射／吸收／散射／折射／衍射／旋转）分，再标光谱或非光谱。
- 表3-3：吸收光谱法的辐射能、作用物质、检测信号。
- 表3-4：发射光谱法同样四列。拉曼不进这两张吸收／发射表，单独成第三类。
:::
