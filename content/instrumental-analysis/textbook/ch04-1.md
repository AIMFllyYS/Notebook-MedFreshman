# 第1节　紫外-可见分光光度法的基本原理

本章打开紫外–可见分光光度法。先把光区写成 $200\sim 760\,\mathrm{nm}$：其中 $200\sim 360\,\mathrm{nm}$ 为紫外光，$360\sim 760\,\mathrm{nm}$ 为可见光。根据物质分子对这一光区电磁波的吸收特性进行定性和定量分析的方法，就是紫外–可见分光光度法（ultraviolet-visible spectrophotometry，UV-Vis）。紫外–可见吸收光谱属于电子光谱；电子光谱强度较大，测定灵敏度高，一般可达到 $10^{-7}\sim 10^{-4}\,\mathrm{g}\cdot\mathrm{mL}^{-1}$ 或更低，适用于微量和痕量组分。本节只立原理：吸收曲线、价电子跃迁、生色团与吸收带、朗伯–比尔定律 $A=Elc$、偏离因素，以及吸光系数与空白对比。仪器构造放到第 2 节，定性定量方法放到第 3 节。不要把第 5 章分子荧光提前搬进来。

:::definition{label="紫外-可见光区"}
本版把紫外–可见光区写成波长在 $200\sim 760\,\mathrm{nm}$ 范围内的电磁辐射。其中 $200\sim 360\,\mathrm{nm}$ 为紫外光，$360\sim 760\,\mathrm{nm}$ 为可见光。不要用别的教材把紫外改写成 $200\sim 400\,\mathrm{nm}$，也不要把第 2 节仪器“波长范围一般为 $200\sim 800\,\mathrm{nm}$”提前并进这一句定义。
:::

:::definition{label="紫外-可见分光光度法"}
紫外–可见分光光度法（ultraviolet-visible spectrophotometry，UV-Vis）根据物质分子对紫外–可见光区电磁波的吸收特性进行定性和定量分析。紫外–可见吸收光谱属于电子光谱。
:::

:::insight{label="电子光谱强度大，所以灵敏度高"}
教材把灵敏度写成：电子光谱强度较大，故测定灵敏度高，一般可达到 $10^{-7}\sim 10^{-4}\,\mathrm{g}\cdot\mathrm{mL}^{-1}$ 或更低，适用于微量和痕量组分。这一句只给数量级，不要另造检测限或仪器型号来“补全”。
:::

:::concept{term="先问价电子跳到哪，再问 A 与 c 怎样成正比"}
看见 UV-Vis，先不要跳到比色皿操作。户头是分子价电子吸收紫外–可见光后跃迁，画出吸收曲线；定量再落到朗伯–比尔定律。把本节听成“只测有色溶液”，紫外区无色样品和对苯、丙酮、氯霉素那几笔都会丢。
:::

## 一、紫外-可见吸收光谱的基本概念

### （一）紫外-可见吸收光谱

紫外–可见吸收光谱是一种分子吸收光谱，由分子中价电子的跃迁而产生。在不同波长下测定物质对光吸收的程度（吸光度），以波长 $\lambda$（$\mathrm{nm}$）为横坐标、吸光度 $A$ 为纵坐标所绘制的曲线，称为吸收曲线，又称吸收光谱。测定波长范围在紫外–可见区时，称紫外–可见光谱，简称紫外光谱。

:::definition{label="紫外-可见吸收光谱"}
紫外–可见吸收光谱是分子吸收光谱，由分子中价电子的跃迁而产生。以 $\lambda$（$\mathrm{nm}$）为横坐标、$A$ 为纵坐标绘制的曲线称为吸收曲线，又称吸收光谱。
:::

:::definition{label="吸收峰与最大吸收波长"}
吸收曲线的峰称为吸收峰，它所对应的波长为最大吸收波长，常用 $\lambda_{\max}$ 表示。
:::

:::definition{label="最小吸收波长"}
曲线的谷所对应的波长称为最小吸收波长，常用 $\lambda_{\min}$ 表示。
:::

:::definition{label="末端吸收"}
在吸收曲线上短波长端底只能呈现较强吸收但又不成峰形的部分，称为末端吸收。
:::

:::definition{label="肩峰"}
在峰旁边一个小的曲折、形状像肩的部位，称为肩峰，其对应的波长用 $\lambda_{\mathrm{sh}}$ 表示。
:::

某些物质的吸收光谱上可出现几个吸收峰。不同的物质有不同的吸收峰。同一物质的吸收光谱有相同的 $\lambda_{\max}$、$\lambda_{\min}$、$\lambda_{\mathrm{sh}}$，而且同一物质相同浓度的吸收曲线应相互重合。因此，吸收光谱上的 $\lambda_{\max}$、$\lambda_{\min}$、$\lambda_{\mathrm{sh}}$ 及整个吸收光谱的形状取决于物质的分子结构，可作定性依据。

::figure{src="/images/instrumental-analysis/textbook/p0067_01.jpg" caption="图4-1　吸收光谱示意图。1—吸收峰；2—谷；3—肩峰；4—末端吸收。" alt="吸收曲线：横轴波长，纵轴吸光度；标出吸收峰、谷、肩峰和短波端末端吸收"}

:::keypoint{label="定性先看形状，再看 λmax、λmin、λsh"}
- 不同物质：吸收峰位置可以不同。
- 同一物质：$\lambda_{\max}$、$\lambda_{\min}$、$\lambda_{\mathrm{sh}}$ 相同；相同浓度的曲线应相互重合。
- 形状和这些特征波长取决于分子结构，是定性依据，不是定量时随便改波长的借口。
:::

:::pitfall{label="末端吸收不是峰，肩峰也不是第二个 λmax"}
短波端底“较强但不成峰”叫末端吸收，不要写成 $\lambda_{\max}$。峰旁像肩的曲折叫肩峰，波长记 $\lambda_{\mathrm{sh}}$，不要升级成另一个最大吸收峰。后文选定量波长时，一般不选靠近短波长末端的吸收峰，户头就在这里。
:::

### （二）电子跃迁类型

紫外吸收光谱由分子中价电子的跃迁而产生，因而决定于分子中价电子的分布和结合情况。按分子轨道理论，有机化合物分子中有几种不同性质的价电子：形成单键的电子称为 $\sigma$ 电子，形成双键的电子称为 $\pi$ 电子；氧、氮、卤素等含有未成键的孤对电子，称为 $\mathrm{n}$ 电子（或 $\mathrm{p}$ 电子）。电子围绕分子或原子运动的概率分布叫轨道。轨道不同，电子所具有的能量不同。吸收一定能量后，跃迁到能级更高的轨道而呈激发态；未受激发的较稳定状态为基态。成键电子的能级比未成键电子的能级低。

:::definition{label="σ 电子、π 电子与 n 电子"}
形成单键的电子为 $\sigma$ 电子，形成双键的电子为 $\pi$ 电子。氧、氮、卤素等含有未成键的孤对电子，称为 $\mathrm{n}$ 电子（或 $\mathrm{p}$ 电子）。
:::

:::definition{label="基态与激发态"}
未受激发的较稳定状态为基态。电子吸收一定能量后跃迁到能级更高的轨道，呈激发态。
:::

如图 4-2，两个氢原子形成一个氢分子时，两个氢原子上的 $\mathrm{s}$ 电子形成 $\sigma$ 键后能量降低，成为更稳定的状态，称为成键轨道，以 $\sigma$ 表示。分子外层还有一种更高的能级，称作反键轨道，以 $\sigma^{*}$ 表示。分子中有 $\pi$ 键时，还有成键轨道 $\pi$ 和反键轨道 $\pi^{*}$。分子中价电子的五种轨道能级高低次序是

$$
\sigma < \pi < \mathrm{n} < \pi^{*} < \sigma^{*}
$$

:::definition{label="五种轨道的能级次序"}
分子中价电子五种轨道的能级高低次序为 $\sigma < \pi < \mathrm{n} < \pi^{*} < \sigma^{*}$。成键低于未成键，未成键低于反键；$\sigma$ 最低，$\sigma^{*}$ 最高。
:::

分子中价电子的跃迁方式与键的性能有关，也就是与化合物的结构有关。跃迁类型见图 4-3。

::figure{src="/images/instrumental-analysis/textbook/p0068_01.jpg" caption="图4-2　H₂ 的成键和反键轨道。两个 H 的 1s 组合成成键 σ 和反键 σ*。" alt="氢分子轨道：两个 1s 原子轨道组合成能量较低的成键 σ 和较高的反键 σ*"}

::figure{src="/images/instrumental-analysis/textbook/p0068_01.jpg" caption="图4-3　分子中价电子能级及跃迁类型示意图。能级自下而上：σ、π、n、π*、σ*；跃迁包括 σ→σ*、n→σ*、π→π*、n→π*。" alt="五条能级横线，箭头标出四种价电子跃迁"}

**（1）$\sigma\to\sigma^{*}$ 跃迁**　处于成键 $\sigma$ 轨道的电子吸收光能后跃迁到 $\sigma^{*}$ 反键轨道。饱和烃只有能级低的 $\sigma$ 键，它的反键轨道是 $\sigma^{*}$。$\sigma$ 与 $\sigma^{*}$ 的能级差大，实现 $\sigma\to\sigma^{*}$ 跃迁需要能量高，吸收峰在远紫外区。例如，甲烷的吸收峰在 $125\,\mathrm{nm}$，乙烷的吸收峰在 $135\,\mathrm{nm}$，饱和烃类吸收峰波长一般都小于 $150\,\mathrm{nm}$，超出一般仪器的测定范围。

:::definition{label="σ→σ* 跃迁"}
$\sigma$ 成键轨道上的电子跃迁到 $\sigma^{*}$ 反键轨道。饱和烃只有 $\sigma$ 键，能级差大，吸收峰在远紫外区：甲烷 $125\,\mathrm{nm}$，乙烷 $135\,\mathrm{nm}$，饱和烃一般小于 $150\,\mathrm{nm}$，超出一般仪器测定范围。
:::

**（2）$\pi\to\pi^{*}$ 跃迁**　不饱和化合物中有 $\pi$ 电子，吸收能量后跃迁到 $\pi^{*}$ 反键轨道上。所吸收能量比 $\sigma\to\sigma^{*}$ 小，吸收峰一般在 $200\,\mathrm{nm}$ 左右，摩尔吸光系数 $\varepsilon$ 很大，属于强吸收。例如，乙烯 $\mathrm{CH_2{=}\,CH_2}$ 的吸收峰在 $165\,\mathrm{nm}$，$\varepsilon$ 为 $10^{4}$；丁二烯吸收峰在 $217\,\mathrm{nm}$，$\varepsilon$ 为 $21\,000$。

:::definition{label="π→π* 跃迁"}
不饱和化合物中 $\pi$ 电子跃迁到 $\pi^{*}$ 反键轨道。能量小于 $\sigma\to\sigma^{*}$，吸收峰一般在 $200\,\mathrm{nm}$ 左右，$\varepsilon$ 很大，属强吸收。乙烯 $165\,\mathrm{nm}$，$\varepsilon=10^{4}$；丁二烯 $217\,\mathrm{nm}$，$\varepsilon=21\,000$。
:::

**（3）$\mathrm{n}\to\pi^{*}$ 跃迁**　含有杂原子的不饱和基团，如有 $\gt\mathrm{C{=}\,O}$ 基、$-\mathrm{C{=}\,N}$ 基、$\gt\mathrm{C{=}\,S}$、$-\mathrm{N{=}\,N}-$ 等的化合物，在杂原子上含有未成键的 $\mathrm{n}$ 电子，能级较高。激发 $\mathrm{n}$ 电子跃迁至 $\pi^{*}$ 反键轨道，即 $\mathrm{n}\to\pi^{*}$ 跃迁。这类跃迁所需能量较小，近紫外区的光能就可激发。$\mathrm{n}\to\pi^{*}$ 跃迁的 $\varepsilon$ 小，属弱吸收。例如，丙酮除 $\pi\to\pi^{*}$ 跃迁为强吸收外，还有吸收峰在 $280\,\mathrm{nm}$ 左右的 $\mathrm{n}\to\pi^{*}$ 跃迁吸收峰，$\varepsilon$ 为 $10\sim 30$。

:::definition{label="n→π* 跃迁"}
含杂原子的不饱和基团（如 $\gt\mathrm{C{=}\,O}$、$-\mathrm{C{=}\,N}$、$\gt\mathrm{C{=}\,S}$、$-\mathrm{N{=}\,N}-$）上未成键 $\mathrm{n}$ 电子跃迁到 $\pi^{*}$。能量较小，近紫外区即可激发；$\varepsilon$ 小，属弱吸收。丙酮约 $280\,\mathrm{nm}$，$\varepsilon=10\sim 30$。
:::

**（4）$\mathrm{n}\to\sigma^{*}$ 跃迁**　含有杂原子的饱和基团，如 $-\mathrm{OH}$、$-\mathrm{NH_2}$、$-\mathrm{X}$、$-\mathrm{S}$ 等基团连在分子上时，杂原子上未共用的 $\mathrm{n}$ 电子跃迁到 $\sigma^{*}$ 反键轨道，形成 $\mathrm{n}\to\sigma^{*}$ 跃迁。这类跃迁所需能量与 $\pi\to\pi^{*}$ 接近，吸收波长在 $200\,\mathrm{nm}$ 左右。例如，三甲基胺 $(\mathrm{CH_3})_3\mathrm{N}$ 有 $\sigma\to\sigma^{*}$、$\mathrm{n}\to\sigma^{*}$ 跃迁，后者吸收峰在 $227\,\mathrm{nm}$，$\varepsilon$ 为 $900$，为中强吸收。

:::definition{label="n→σ* 跃迁"}
含杂原子的饱和基团（$-\mathrm{OH}$、$-\mathrm{NH_2}$、$-\mathrm{X}$、$-\mathrm{S}$ 等）上未共用 $\mathrm{n}$ 电子跃迁到 $\sigma^{*}$。能量与 $\pi\to\pi^{*}$ 接近，波长约 $200\,\mathrm{nm}$。三甲基胺的 $\mathrm{n}\to\sigma^{*}$ 在 $227\,\mathrm{nm}$，$\varepsilon=900$，中强吸收。
:::

电子由基态跃迁到激发态所需能量不同，所以吸收不同波长的光能。所需光能大小，由图 4-3 所示，其顺序为

$$
\sigma\to\sigma^{*} > \mathrm{n}\to\sigma^{*} \ge \pi\to\pi^{*} > \mathrm{n}\to\pi^{*}
$$

其中 $\mathrm{n}\to\pi^{*}$ 跃迁所需能量在紫外–可见光区；单独的 $\pi\to\pi^{*}$ 与 $\mathrm{n}\to\sigma^{*}$ 所需能量差不多，它们都靠近 $200\,\mathrm{nm}$ 一边，在吸收光谱上呈末端吸收。另外，$\pi\to\pi^{*}$ 跃迁的摩尔吸光系数比 $\mathrm{n}\to\pi^{*}$ 大得多。若 $\pi-\pi$ 有共轭双键时，由于电子离域，易激发，所需能量减小，如丁二烯的 $\lambda_{\max}$ 为 $217\,\mathrm{nm}$，$\varepsilon$ 为 $21\,000$。

:::compare{title="四种价电子跃迁"}
| 跃迁 | 典型结构 | 能量／波长 | $\varepsilon$ | 本版例子 |
|------|----------|------------|---------------|----------|
| $\sigma\to\sigma^{*}$ | 饱和烃只有 $\sigma$ 键 | 最高；远紫外，一般 $<150\,\mathrm{nm}$ | — | 甲烷 $125\,\mathrm{nm}$，乙烷 $135\,\mathrm{nm}$ |
| $\mathrm{n}\to\sigma^{*}$ | $-\mathrm{OH}$、$-\mathrm{NH_2}$、$-\mathrm{X}$、$-\mathrm{S}$ | 与 $\pi\to\pi^{*}$ 接近，约 $200\,\mathrm{nm}$ | 中强 | 三甲基胺 $227\,\mathrm{nm}$，$\varepsilon=900$ |
| $\pi\to\pi^{*}$ | 不饱和 $\pi$ 键 | 一般约 $200\,\mathrm{nm}$；共轭则红移 | 很大，强吸收 | 乙烯 $165\,\mathrm{nm}$，$\varepsilon=10^{4}$；丁二烯 $217\,\mathrm{nm}$，$\varepsilon=21\,000$ |
| $\mathrm{n}\to\pi^{*}$ | $\gt\mathrm{C{=}\,O}$ 等含杂原子不饱和基团 | 最低；近紫外即可 | 小，弱吸收 | 丙酮约 $280\,\mathrm{nm}$，$\varepsilon=10\sim 30$ |
:::

:::pitfall{label="一般仪器看不到饱和烃的 σ→σ*"}
甲烷 $125\,\mathrm{nm}$、乙烷 $135\,\mathrm{nm}$、饱和烃一般小于 $150\,\mathrm{nm}$，超出一般仪器测定范围。不要把“四种跃迁都能在本仪器紫外区画出峰”当成定理。单独的 $\pi\to\pi^{*}$ 与 $\mathrm{n}\to\sigma^{*}$ 靠近 $200\,\mathrm{nm}$，常常只呈末端吸收。
:::

:::insight{label="共轭把 π→π* 从末端拉进可测区"}
电子离域使激发更容易、能量减小。丁二烯 $\lambda_{\max}=217\,\mathrm{nm}$、$\varepsilon=21\,000$，已经离开“单独双键约 $165\,\mathrm{nm}$、靠近仪器下限”的位置。后文 K 带随共轭双键增加而长移、增强，户头就在这一句。
:::

除以上四种基本跃迁外，某些无机配合物分子和有机化合物分子受到电磁辐射，电子从电子给予体向电子接受体相联系的轨道跃迁，称为电荷转移跃迁。电荷转移跃迁是一个内氧化还原过程，其相应的吸收光谱称为电荷转移吸收光谱。电荷转移吸收的波长取决于电子给予体和电子接受体所对应的电子轨道的能量差。这类光谱的最大特点是摩尔吸光系数较大（$\varepsilon_{\max}>10^{4}$），灵敏度高，可用于定量分析。

:::definition{label="电荷转移跃迁"}
电子从电子给予体向电子接受体相联系的轨道跃迁，称为电荷转移跃迁。它是一个内氧化还原过程，相应光谱称电荷转移吸收光谱。波长取决于给予体与接受体电子轨道的能量差。最大特点是 $\varepsilon_{\max}>10^{4}$，灵敏度高，可用于定量分析。
:::

还有位于可见光区、吸光较弱（$\varepsilon<100$）的配位场跃迁。元素周期表中第四、第五周期的过渡金属元素分别含有 $3\mathrm{d}$ 和 $4\mathrm{d}$ 轨道，镧系和锕系元素分别含有 $4\mathrm{f}$ 和 $5\mathrm{f}$ 轨道。在配体存在下，过渡元素能量相等的 5 个 $\mathrm{d}$ 轨道及镧系、锕系元素的 7 个 $\mathrm{f}$ 轨道分别分裂成几组能量不等的 $\mathrm{d}$ 轨道和 $\mathrm{f}$ 轨道。当它们吸收光子时，低能态的 $\mathrm{d}$ 电子和 $\mathrm{f}$ 电子会分别跃迁到高能态的 $\mathrm{d}$ 轨道或 $\mathrm{f}$ 轨道上。这种跃迁必须在配体的配位场作用下才能够发生，因此称为配位场跃迁。

:::definition{label="配位场跃迁"}
位于可见光区、吸光较弱（$\varepsilon<100$）。过渡元素 5 个 $\mathrm{d}$ 轨道及镧系、锕系 7 个 $\mathrm{f}$ 轨道在配体存在下分裂；低能态 $\mathrm{d}$、$\mathrm{f}$ 电子吸收光子跃迁到高能态 $\mathrm{d}$ 或 $\mathrm{f}$ 轨道。必须在配体的配位场作用下才能发生。
:::

:::compare{title="电荷转移跃迁对配位场跃迁"}
| 项目 | 电荷转移跃迁 | 配位场跃迁 |
|------|--------------|------------|
| 过程 | 给予体 → 接受体，内氧化还原 | 分裂后的 $\mathrm{d}$ 或 $\mathrm{f}$ 轨道之间 |
| $\varepsilon$ | $\varepsilon_{\max}>10^{4}$，强，可定量 | $\varepsilon<100$，弱 |
| 光区 | 由给予体／接受体能级差决定 | 可见光区 |
| 前提 | 有电子给予体和接受体 | 必须有配体的配位场 |
:::

:::pitfall{label="不要把电荷转移和配位场都写成“第四种价电子跃迁”"}
四种基本跃迁是 $\sigma\to\sigma^{*}$、$\pi\to\pi^{*}$、$\mathrm{n}\to\pi^{*}$、$\mathrm{n}\to\sigma^{*}$。电荷转移和配位场是“除以上四种基本跃迁外”另立的两本账。把 $\varepsilon>10^{4}$ 的电荷转移听成配位场，或把 $\varepsilon<100$ 的可见区弱吸收听成 K 带，定量灵敏度会对错户头。
:::

### （三）生色团和助色团

**（1）生色团**　有机化合物分子结构中有 $\pi\to\pi^{*}$ 或 $\mathrm{n}\to\pi^{*}$ 跃迁的基团，如 $\gt\mathrm{C{=}\,C}\lt$、$\gt\mathrm{C{=}\,O}$、$-\mathrm{C{\equiv}\,C}-$ 等，能在紫外–可见光范围内产生吸收。这样的基团为生色团。

:::definition{label="生色团"}
分子结构中有 $\pi\to\pi^{*}$ 或 $\mathrm{n}\to\pi^{*}$ 跃迁、能在紫外–可见光范围内产生吸收的基团，如 $\gt\mathrm{C{=}\,C}\lt$、$\gt\mathrm{C{=}\,O}$、$-\mathrm{C{\equiv}\,C}-$ 等。
:::

**（2）助色团**　与生色团或饱和烃相连，能使吸收峰向长波方向移动，并使吸收强度增加的带有杂原子的饱和基团，如 $-\mathrm{OH}$、$-\mathrm{NH_2}$ 及卤素等。

:::definition{label="助色团"}
与生色团或饱和烃相连，能使吸收峰向长波方向移动并使吸收强度增加的、带有杂原子的饱和基团，如 $-\mathrm{OH}$、$-\mathrm{NH_2}$ 及卤素等。
:::

吸收峰向长波方向移动的现象称为红移或长移，向短波方向移动的现象称为蓝移或短移。

:::definition{label="红移（长移）"}
吸收峰向长波方向移动，称为红移或长移。
:::

:::definition{label="蓝移（短移）"}
吸收峰向短波方向移动，称为蓝移或短移。
:::

:::memory{label="生色团吸收，助色团推着峰走"}
- 生色团：自己能在紫外–可见区吸收（$\pi\to\pi^{*}$ 或 $\mathrm{n}\to\pi^{*}$）。
- 助色团：$-\mathrm{OH}$、$-\mathrm{NH_2}$、卤素等，连上去使峰红移、强度增加。
- 红移＝长移＝向长波；蓝移＝短移＝向短波。
:::

### （四）吸收带

吸收带就是吸收峰在紫外–可见光谱中的位置。根据分子结构与取代基团的种类，把吸收带分为四种类型。在解析光谱时可以从这些吸收带的归属，推测化合物分子结构的信息。

:::definition{label="吸收带"}
吸收带就是吸收峰在紫外–可见光谱中的位置。本版按分子结构与取代基团分成 R、K、B、E 四种。
:::

**（1）R 带**　由 $\mathrm{n}\to\pi^{*}$ 跃迁引起的吸收带，是含杂原子的不饱和基团如 $\gt\mathrm{C{=}\,O}$、$-\mathrm{NO}$、$-\mathrm{NO_2}$、$-\mathrm{N{=}\,N}-$ 等这类生色团的特征吸收带。它的特点是处于较长波带范围（$250\sim 500\,\mathrm{nm}$），是弱吸收（$\varepsilon<100$）。

:::definition{label="R 带"}
由 $\mathrm{n}\to\pi^{*}$ 跃迁引起。含杂原子不饱和基团（$\gt\mathrm{C{=}\,O}$、$-\mathrm{NO}$、$-\mathrm{NO_2}$、$-\mathrm{N{=}\,N}-$ 等）的特征吸收带。较长波带 $250\sim 500\,\mathrm{nm}$，弱吸收 $\varepsilon<100$。
:::

**（2）K 带**　是由共轭双键中的 $\pi\to\pi^{*}$ 跃迁引起的吸收带。其 $\varepsilon>10^{4}$，为强吸收。随共轭双键增加，产生长移，且吸收强度增加。例如：

$$
\begin{aligned}
\mathrm{CH_2{=}\,CH{-}CH{=}\,CH_2} &\quad \pi\to\pi^{*}\quad \text{K 带}\ \lambda_{\max}=217\,\mathrm{nm},\ \varepsilon=21\,000\\
\mathrm{CH_2{=}\,CH{-}CH{=}\,CH{-}CH{=}\,CH_2} &\quad \pi\to\pi^{*}\quad \text{K 带}\ \lambda_{\max}=258\,\mathrm{nm},\ \varepsilon=35\,000
\end{aligned}
$$

:::definition{label="K 带"}
由共轭双键中 $\pi\to\pi^{*}$ 跃迁引起。$\varepsilon>10^{4}$，强吸收。共轭双键增加则长移且强度增加。丁二烯 $217\,\mathrm{nm}$，$\varepsilon=21\,000$；己三烯 $258\,\mathrm{nm}$，$\varepsilon=35\,000$。
:::

**（3）B 带**　是芳香族化合物的特征吸收带。苯处于气态下，在 $230\sim 270\,\mathrm{nm}$ 出现精细结构的吸收光谱，反映出孤立分子振动、转动能级跃迁。在苯溶液中，因分子间作用加大，转动消失，仅出现部分振动跃迁，因此谱带较宽；在极性溶剂中，溶剂和溶质间作用更大，因而精细结构消失，B 带出现一宽峰，其中心在 $256\,\mathrm{nm}$ 附近，$\varepsilon$ 为 $220$ 左右，见图 4-4。

:::definition{label="B 带"}
芳香族化合物的特征吸收带。苯蒸气在 $230\sim 270\,\mathrm{nm}$ 有精细结构（孤立分子的振动、转动）；溶液中转动消失、谱带变宽；极性溶剂中精细结构消失，宽峰中心约 $256\,\mathrm{nm}$，$\varepsilon$ 约 $220$。
:::

::figure{src="/images/instrumental-analysis/textbook/p0070_01.jpg" caption="图4-4　苯环的 B 带吸收光谱。（a）苯蒸气，精细结构清楚；（b）乙醇中苯的稀溶液，谱带变宽。" alt="两幅苯的 B 带：蒸气谱有密集振动结构，乙醇溶液谱为较宽的包络"}

**（4）E 带**　也是芳香族的特征吸收带，由苯环中三个双键组成的环状共轭体系所引起的 $\pi\to\pi^{*}$ 跃迁。E 带可细分为 $\mathrm{E_1}$ 和 $\mathrm{E_2}$ 带。如苯环的 $\mathrm{E_1}$ 带约在 $180\,\mathrm{nm}$ 处（$\varepsilon=47\,000$），$\mathrm{E_2}$ 带约在 $200\,\mathrm{nm}$ 处（$\varepsilon=8\,000$）。当苯环上有生色团取代，并和苯环共轭时，$\mathrm{E_2}$ 带与 K 带合并，称为 K 带，吸收带红移，B 带也红移。当苯环上有助色团（如 $-\mathrm{Cl}$、$-\mathrm{OH}$ 等）取代时，$\mathrm{E_2}$ 带产生红移，但波长一般不超过 $210\,\mathrm{nm}$。

:::definition{label="E 带"}
芳香族特征吸收带，由苯环三个双键的环状共轭体系引起的 $\pi\to\pi^{*}$ 跃迁，细分为 $\mathrm{E_1}$、$\mathrm{E_2}$。正文：苯的 $\mathrm{E_1}$ 约 $180\,\mathrm{nm}$（$\varepsilon=47\,000$），$\mathrm{E_2}$ 约 $200\,\mathrm{nm}$（$\varepsilon=8\,000$）。
:::

:::pitfall{label="苯的 E1：正文 47 000，表 4-1 写 60 000"}
4.1.1 正文把苯环 $\mathrm{E_1}$ 写成约 $180\,\mathrm{nm}$、$\varepsilon=47\,000$；表 4-1 同一行写 $\varepsilon_{\max}=60\,000$。两处都是本版印刷数字，答题时写明出处，不要擅自“统一”成某一个课外手册值。
:::

### （五）影响吸收带的因素

紫外吸收光谱吸收带的位置易受分子的结构因素和测定条件等多种因素的影响，在较宽的范围内发生移动。

**（1）位阻影响**　化合物中若有两个生色团产生共轭效应，可使吸收带红移。但若两个生色团由于立体位阻妨碍它们处于同一平面上，会影响共轭效应，这种影响在光谱图上能反映出来。例如，二苯乙烯的反式结构 K 带 $\lambda_{\max}$ 比顺式明显红移，且摩尔吸光系数 $\varepsilon_{\max}$ 也明显增大。其原因是顺式结构有立体位阻，使苯环不能与乙烯双键在同一平面上，不易产生共轭。

:::example{label="二苯乙烯顺式与反式"}
顺式（cis）：$\lambda_{\max}=280\,\mathrm{nm}$，$\varepsilon=10\,500$。反式（trans）：$\lambda_{\max}=295.5\,\mathrm{nm}$，$\varepsilon=29\,000$。反式共平面好、共轭好，K 带更红、更强。
:::

:::pitfall{label="位阻破坏的是共平面，不是“生色团消失”"}
两个生色团仍在分子里；立体位阻妨碍它们处于同一平面，共轭效应减弱。不要把顺式二苯乙烯听成没有苯环或没有双键。
:::

**（2）跨环效应**　有些 $\beta,\gamma$ 不饱和酮中，虽然双键与酮基不产生共轭体系，由于适当的立体排列，使羰基氧的孤对电子和双键的 $\pi$ 电子发生作用，以致使 $\mathrm{n}\to\pi^{*}$ 跃迁的 R 吸收带向长波方向移动，同时吸收强度增加。如降冰片烯酮类骨架在 $214\,\mathrm{nm}$ 处显示一中等强度的吸收带，同时在 $284\,\mathrm{nm}$ 处出现一 R 带。此外，当 $\mathrm{C{=}\,O}$ 基团的 $\pi$ 轨道与一个杂原子的 $\mathrm{p}$ 轨道能够有效交盖时，也会出现跨环效应。例如，环状氨基酮的 $\lambda_{\max}=238\,\mathrm{nm}$，$\varepsilon_{\max}=2\,535$。

:::definition{label="跨环效应"}
双键与酮基并不共轭，但立体排列使羰基氧孤对电子与双键 $\pi$ 电子作用，使 $\mathrm{n}\to\pi^{*}$ 的 R 带长移、强度增加；$\mathrm{C{=}\,O}$ 的 $\pi$ 轨道与杂原子 $\mathrm{p}$ 轨道有效交盖时同样可出现。
:::

**（3）溶剂效应**　化合物在溶液中的紫外吸收光谱受溶剂影响较大，一般应注明所用溶剂。溶剂的极性不同，对 $\pi\to\pi^{*}$、$\mathrm{n}\to\pi^{*}$ 跃迁所产生的吸收峰位置移动方向不同。当改用极性较大的溶剂时，使 $\pi\to\pi^{*}$ 跃迁吸收峰长移：激发态的极性比基态极性大，激发态与极性溶剂之间相互作用所降低的能量比基态与极性溶剂发生作用所降低的能量大，使能级差变小，所以产生长移。而在 $\mathrm{n}\to\pi^{*}$ 跃迁中，基态的极性大，非键电子（$\mathrm{n}$ 电子）与极性溶剂之间能形成较强的氢键，使基态能量降低大于 $\pi^{*}$ 反键轨道与极性溶剂相互作用所降低的能量，因而 $\mathrm{n}\to\pi^{*}$ 跃迁能级差变大，故产生短移，见图 4-5。

:::definition{label="溶剂效应"}
紫外吸收光谱受溶剂影响较大，一般应注明所用溶剂。改用极性较大的溶剂：$\pi\to\pi^{*}$ 吸收峰长移，$\mathrm{n}\to\pi^{*}$ 吸收峰短移。
:::

::figure{src="/images/instrumental-analysis/textbook/p0072_01.jpg" caption="图4-5　极性溶剂对两种跃迁能级差的影响。左：n→π*，ΔE非>ΔE极，短移；右：π→π*，ΔE非<ΔE极，长移。" alt="两组能级图：极性溶剂使 n→π* 能级差变大、π→π* 能级差变小"}

:::cause-effect{title="极性溶剂为什么让两种跃迁走反方向"}
- **因（π→π*）** 激发态极性比基态大，激发态被极性溶剂降低得更多 → 能级差变小 → 长移
- **因（n→π*）** 基态极性大，n 电子与极性溶剂形成较强氢键，基态降低得更多 → 能级差变大 → 短移
:::

:::pitfall{label="溶剂极性加大不是“所有峰都红移”"}
$\pi\to\pi^{*}$ 长移，$\mathrm{n}\to\pi^{*}$ 短移，方向相反。把丙酮的 R 带和丁二烯的 K 带用同一句“极性溶剂红移”概括，归属会反。
:::

**（4）体系 pH 的影响**　体系的 $\mathrm{pH}$ 对紫外吸收光谱的影响比较普遍，无论对酸性、碱性或中性样品都有明显影响。例如，酚类化合物由于体系的 $\mathrm{pH}$ 不同，解离情况不同，而产生不同的吸收光谱。苯酚 $\lambda_{\max}=210.5\,\mathrm{nm}$、$270\,\mathrm{nm}$；酚氧负离子 $\lambda_{\max}=235\,\mathrm{nm}$、$287\,\mathrm{nm}$。

:::example{label="酚与酚氧负离子"}
$\mathrm{PhOH}$：$\lambda_{\max}=210.5\,\mathrm{nm}$、$270\,\mathrm{nm}$。$\mathrm{PhO}^{-}$：$\lambda_{\max}=235\,\mathrm{nm}$、$287\,\mathrm{nm}$。解离后共轭与电荷分布改变，峰红移。后文定性鉴别“换不同酸碱性溶剂再比光谱”，户头在这一笔。
:::

## 二、朗伯-比尔定律

朗伯–比尔定律（Lambert–Beer law）是吸收光谱的基本定律，是描述物质对单色光吸收的强弱与吸光物质的厚度和浓度间关系的定律。

:::definition{label="朗伯-比尔定律"}
朗伯–比尔定律（Lambert–Beer law）描述物质对单色光吸收的强弱与吸光物质的厚度和浓度间的关系。本版数学式为 $A=-\lg(I/I_0)=Ecl$。
:::

假设一束平行单色光通过一个含有吸光物质的物体，物体的截面积为 $S$，厚度为 $l$，如图 4-6 所示。物质中含有 $n$ 个吸光质点。光通过后，一些光子被吸收。光强从 $I_0$ 降至 $I$。

::figure{src="/images/instrumental-analysis/textbook/p0072_01.jpg" caption="图4-6　光通过截面积 S、厚度 l 的吸光物质。入射光强 I₀，出射光强 I。" alt="长方体吸光介质：截面 S，厚度 l，入射 I0 从左侧进入，透射 I 从右侧离开"}

:::derivation{label="由吸光质点截面推到 A=Ecl"}
取物体中一极薄层，所含吸光质点数为 $\mathrm{d}n$。这些能捕获光子的质点可看作截面 $S$ 上被占去一部分不让光子通过的面积 $\mathrm{d}S$，即

$$
\mathrm{d}S = k\,\mathrm{d}n
$$

$k$ 是比例常数。光子通过断层时，被吸收的概率是 $\mathrm{d}S/S = k\,\mathrm{d}n/S$，因而使投射于此断层的光强 $I_{x}$ 被减弱了 $\mathrm{d}I_{x}$，所以有

$$
\frac{\mathrm{d}I_{x}}{I_{x}} = -\frac{k\,\mathrm{d}n}{S}
$$

光通过厚度为 $l$ 的物体时，

$$
-\int_{I_0}^{I}\frac{\mathrm{d}I_{x}}{I_{x}} = \int_{0}^{n}\frac{k\,\mathrm{d}n}{S},\qquad -\ln\frac{I}{I_0}=\frac{kn}{S}
$$

换成常用对数：

$$
-\ln\frac{I}{I_0}=(\lg\mathrm{e})k\frac{n}{S}=E\frac{n}{S}
$$

截面积 $S$ 与体积 $V$、质点总数 $n$ 与浓度 $c$ 有 $S=V/l$、$n=Vc$，故 $n/S=lc$，于是

$$
-\lg\frac{I}{I_0}=Ecl \tag{4-1}
$$
:::

式（4-1）为朗伯–比尔定律的数学表达式，$I_0$ 为入射光强度，$I$ 为透射光强度，$I/I_0$ 是透光率（$T$），常用百分数表示，$A=-\lg T$，$A$ 称为吸光度，于是

$$
A=-\lg T=Elc \tag{4-2}
$$

或

$$
T=10^{-A}=10^{-Elc} \tag{4-3}
$$

:::definition{label="透光率"}
透光率 $T=I/I_0$，常用百分数表示。
:::

:::definition{label="吸光度"}
吸光度 $A=-\lg T$。本版定量式 $A=Elc$，其中 $E$ 为吸光系数，$l$ 为厚度，$c$ 为浓度。
:::

:::definition{label="吸光系数 E"}
式（4-2）、（4-3）中 $E$ 是比例常数，称为吸光系数。吸光度与浓度或厚度成正比；透光率与浓度或厚度是指数函数关系。
:::

式（4-3）表明单色光通过吸光介质后，透光率 $T$ 与浓度 $c$ 或厚度 $l$ 之间的关系是指数函数关系。例如，浓度增大一倍时，透光率从 $T$ 降至 $T^{2}$。吸光度与浓度或厚度之间是正比关系。

:::insight{label="浓度加倍，T 变成平方，A 才加倍"}
$T=10^{-Elc}$。$c$ 加倍则 $T$ 变成原来的平方，不是减半。$A$ 才与 $c$ 成正比。把 $T$ 当直线去内插浓度，定量会错。
:::

在多组分体系中，如果各组分吸光物质之间没有相互作用，则朗伯–比尔定律仍适用，这时体系的总吸光度等于各组分吸光度之和，即各物质在同一波长下，吸光度具有加和性：

$$
A_{\text{总}}=A_{\mathrm{a}}+A_{\mathrm{b}}+A_{\mathrm{c}}+\cdots
$$

利用此性质可进行多组分的测定。

:::definition{label="吸光度加和性"}
各组分吸光物质之间没有相互作用时，同一波长下总吸光度等于各组分吸光度之和。第 3 节多组分定量（解线性方程组、双波长）都靠这一句。
:::

## 三、影响朗伯-比尔定律的因素

按照朗伯–比尔定律，浓度 $c$ 与吸光度 $A$ 之间的关系应是一条通过原点的直线。实际工作中，特别是溶液浓度较高时，会出现偏离直线的现象，如图 4-7 中的虚线，称偏离朗伯–比尔定律。

::figure{src="/images/instrumental-analysis/textbook/p0073_01.jpg" caption="图4-7　吸光度与浓度的关系。实线过原点；虚线标出正偏离与负偏离。" alt="A–c 图：过原点实直线，上方虚线为正偏离，下方虚线为负偏离"}

:::definition{label="偏离朗伯-比尔定律"}
$A$ 对 $c$ 本应是过原点的直线；实际尤其在较高浓度时出现偏离直线的现象，称偏离朗伯–比尔定律。图 4-7 用虚线标出正偏离和负偏离。
:::

实际上在推导朗伯–比尔定律时包含了这样两个假设：入射光是单色光，溶液是吸光物质的稀溶液。因此导致偏离的主要因素表现在光学和化学两个方面。

:::keypoint{label="本版偏离因素只写光学和化学两本账"}
推导假设：①入射光是单色光；②溶液是稀溶液。主要因素就是光学因素和化学因素。透光率测量误差是另一笔随机误差（暗噪声、信号噪声），不要把第 2 节仪器指标里的杂散光提前写成第三条“定律偏离条款”。
:::

### （一）光学因素

朗伯–比尔定律只适用于单色光，但一般单色器提供的入射光并不是纯的单色光，而是波长范围较窄的光带，实际上仍是复合光。由于物质对不同波长光的吸收程度不同，因而就产生偏离。现假设入射光由波长 $\lambda_1$ 和 $\lambda_2$ 的光组成，两个波长的入射光强各为 $I_{01}$ 和 $I_{02}$。因为

$$
I=I_0\,10^{-Ecl}
$$

故此混合光的透光率为

$$
\begin{aligned}
T&=\frac{I_1+I_2}{I_{01}+I_{02}}=\frac{I_{01}10^{-E_1cl}+I_{02}10^{-E_2cl}}{I_{01}+I_{02}}\\
&=10^{-E_1cl}\frac{I_{01}+I_{02}10^{(E_1-E_2)cl}}{I_{01}+I_{02}}
\end{aligned}
$$

$$
A=-\lg T=E_1cl-\lg\frac{I_{01}+I_{02}10^{(E_1-E_2)cl}}{I_{01}+I_{02}} \tag{4-4}
$$

由式（4-4）可知，只有当 $E_1=E_2$ 时，$A=E_1cl$ 符合线性关系；若 $E_1\neq E_2$，则 $A$ 与 $c$ 不呈直线关系，$E_1$ 与 $E_2$ 差别越大，$A$ 与 $c$ 偏离线性关系越大。

:::definition{label="非单色光引起的偏离"}
单色器给出的仍是窄光带（复合光）。只有当组成波长的吸光系数相等（$E_1=E_2$）时 $A=E_1cl$ 仍线性；$E_1$ 与 $E_2$ 差别越大，偏离越大。
:::

因此测定时应选择较纯的单色光（即波长范围很窄的光）。同时选择吸光物质的最大吸收波长作测定波长，因为此处吸收曲线较平坦，$E_1$ 和 $E_2$ 差别不大，对朗伯–比尔定律的偏离就较小，而且吸光系数大，测定有较高的灵敏度，如图 4-8 中的 a 所示。若用谱带 b 的复合光测量，其 $E$ 的变化较大，因而会出现较明显的偏离。

::figure{src="/images/instrumental-analysis/textbook/p0074_01.jpg" caption="图4-8　测定波长的选择。谱带 a 在峰顶较平坦，E 变化小；谱带 b 在陡坡，E 变化大。" alt="吸收曲线上两段水平谱带：a 压在峰顶平台，b 压在峰侧陡坡"}

:::tip{label="定量波长选 λmax，既为灵敏度，也为少偏离"}
峰顶平坦，$E_1\approx E_2$，非单色光的伤害小；同时 $E$ 大，灵敏度高。第 3 节“通常应选择被测物质吸收光谱的吸收峰处”“一般不选靠近短波长末端的吸收峰”，与图 4-8 是同一把钥匙。
:::

### （二）化学因素

朗伯–比尔定律假设溶液中吸光粒子是独立的，即彼此无相互作用。然而实际表明，这种情况在稀溶液才成立。浓度高时，粒子间距小，相互之间的作用不能忽略不计，这将使粒子的吸光能力发生改变，引起对朗伯–比尔定律的偏离。浓度越大，偏离越大，故朗伯–比尔定律只适用于稀溶液。

另一方面，吸光物质可因浓度改变而有解离、缔合、溶剂化及配合物组成改变等现象，使吸光物质的存在形式发生改变，因而影响物质对光的吸收能力，导致比尔定律的偏离。例如，图 4-9 是亚甲蓝阳离子水溶液的吸收光谱，单体的吸收峰在 $660\,\mathrm{nm}$ 处，而二聚体的吸收峰在 $610\,\mathrm{nm}$ 处。随着浓度的增大，$660\,\mathrm{nm}$ 处吸收峰减弱，而 $610\,\mathrm{nm}$ 吸收峰增强，吸收光谱形状改变。正是由于这个现象的存在，吸光度与浓度关系发生偏离。

::figure{src="/images/instrumental-analysis/textbook/p0075_01.jpg" caption="图4-9　亚甲蓝阳离子水溶液的吸收光谱。单体 λmax=660 nm，二聚体 λmax=610 nm。a：6.36×10⁻⁶ mol·L⁻¹；b：1.27×10⁻⁵ mol·L⁻¹；c：5.97×10⁻⁴ mol·L⁻¹。" alt="亚甲蓝吸收曲线随浓度升高，660 nm 峰下降、610 nm 峰上升"}

:::definition{label="化学因素导致的偏离"}
稀溶液中吸光粒子才可视为独立。浓度高时粒子相互作用改变吸光能力。浓度改变还可引起解离、缔合、溶剂化及配合物组成改变，存在形式变了，吸收能力就变了。朗伯–比尔定律只适用于稀溶液。
:::

:::example{label="亚甲蓝单体与二聚体"}
单体 $\lambda_{\max}=660\,\mathrm{nm}$，二聚体 $\lambda_{\max}=610\,\mathrm{nm}$。浓度增大： $660\,\mathrm{nm}$ 减弱、$610\,\mathrm{nm}$ 增强，光谱形状改变，$A$–$c$ 偏离直线。
:::

有些化合物在水溶液中有多种存在形式，如 $\mathrm{Cr(VI)}$ 的两种离子，$\mathrm{Cr_2O_7^{2-}}$（橙色）与 $\mathrm{CrO_4^{2-}}$（黄色）有以下平衡：

$$
\mathrm{Cr_2O_7^{2-}}+\mathrm{H_2O}\rightleftharpoons 2\,\mathrm{CrO_4^{2-}}+2\mathrm{H^{+}}
$$

两种离子有不同的吸收光谱，溶液的吸光度将是两种离子吸光度之和。如果溶液浓度改变时，两种离子浓度的比值 $[\mathrm{CrO_4^{2-}}]/[\mathrm{Cr_2O_7^{2-}}]$ 能保持不变，则浓度与吸光度之间可有直线关系。但由于上述解离平衡，两种离子的比值在水溶液中不能始终保持恒定。浓度降低时，$[\mathrm{CrO_4^{2-}}]/[\mathrm{Cr_2O_7^{2-}}]$ 值变大，使 $\mathrm{CrO_4^{2-}}$ 的吸光度在溶液总吸光度中所占比值增大。由于两者的吸光系数有很大差别，使 $\mathrm{Cr(VI)}$ 的总浓度与吸光度之间的关系偏离直线。

:::example{label="Cr(VI) 的铬酸根与重铬酸根"}
橙色 $\mathrm{Cr_2O_7^{2-}}$ 与黄色 $\mathrm{CrO_4^{2-}}$ 平衡。总浓度降低时 $[\mathrm{CrO_4^{2-}}]/[\mathrm{Cr_2O_7^{2-}}]$ 变大，两种离子 $\varepsilon$ 差别大，$A$ 对总浓度偏离直线。
:::

为了防止这类偏离，必须根据物质对光的吸光能力、溶液中的化学平衡的知识，严格控制显色反应条件，使被测物质定量地保持在吸光能力相同的形式，以获得较好的分析结果。

:::tip{label="化学偏离的对策是控存在形式，不是改定律"}
显色反应条件要把被测物定量保持在吸光能力相同的形式。第 3 节比色法选酸度、显色剂用量，就是在落实这一句。
:::

### （三）透光率的测量误差

透光率测量误差 $\Delta T$ 是测量中的随机误差，来自仪器的噪声。$\Delta T$ 是仪器测得透光率的不确定部分，主要包含两类性质不同的因素。一类与光信号无关，称为暗噪声；另一类随光信号强弱而变化，称为信号噪声。

由朗伯–比尔定律可导出

$$
c=\frac{A}{El}=-\frac{\lg T}{El}
$$

微分后除以上式，可得浓度的相对误差 $\Delta c/c$ 为

$$
\frac{\Delta c}{c}=\frac{0.434\,\Delta T}{T\lg T} \tag{4-5}
$$

:::definition{label="透光率测量误差"}
$\Delta T$ 是测得透光率的不确定部分，来自仪器噪声，是随机误差。一类与光信号无关，称暗噪声；一类随光信号强弱而变，称信号噪声。浓度相对误差由式（4-5）与 $T$、$\Delta T$ 联系。
:::

式（4-5）表明，测定结果的相对误差是透射率 $T$ 的函数，同时也取决于 $\Delta T$ 的大小。

**（1）暗噪声**　暗噪声是光电检测器与放大电路等各部件的不确定性。这种噪声的强弱取决于各种电子元件和线路结构质量、工作状态及环境条件等。不管有光照射或无光照射，$\Delta T$ 可视为一个常量。测定结果的相对误差与测量值之间的关系如图 4-10 中的实线。当 $A$ 值为 $0.2\sim 0.7$（$T$ 值 $65\%\sim 20\%$）时，曲线平坦，相对误差 $\Delta c/c$ 较小，是测定较为适宜的区域。超出这个范围，虽然透光率测量的误差 $\Delta T$ 不变，但 $\Delta c/c$ 的值急剧上升。因此要求测量在最适宜范围（$A$ 值 $0.2\sim 0.7$）即可。

:::definition{label="暗噪声与适宜吸光度范围"}
暗噪声与有无光照无关，$\Delta T$ 可视为常量。$A=0.2\sim 0.7$（$T=65\%\sim 20\%$）时 $\Delta c/c$ 较小，是测定较为适宜的区域。
:::

**（2）信号噪声**　信号噪声亦称信号散粒噪声。光敏元件受光照时的电子迁移，如光电管中电子从阴极飞向阳极，或光电池中电子越过堰层，电子是一个一个受激发而迁移的。用很小的时间单位来衡量，每一单位时间中电子迁移的数量是不相等的，而是某一均值周围的随机数，形成测定光强的不确定性。随机变动的幅度随光照增强而增大，信号噪声与被测光强的平方根成正比，其比值 $K$ 与光的波长及光敏元件的品质有关。由信号噪声产生的 $\Delta T$ 可用下式表示：

$$
\Delta T=TK\sqrt{\frac{1}{T}+1}
$$

代入式（4-5）得

$$
\frac{\Delta c}{c}=\frac{0.434K}{\lg T}\sqrt{\frac{1}{T}+1} \tag{4-6}
$$

图 4-10 中虚线即表示按式（4-6）所得的浓度相对误差与测定值间的关系。误差较小的范围一直延伸到高吸光度区，对测定是个有利因素。

::figure{src="/images/instrumental-analysis/textbook/p0076_01.jpg" caption="图4-10　暗噪声（实线）与信号噪声（虚线）的误差曲线。横轴为吸光度 A。" alt="Δc/c 对 A：实线在 A=0.2～0.7 较平坦后两端上扬；虚线在高 A 区仍较低"}

:::compare{title="暗噪声与信号噪声"}
| 项目 | 暗噪声 | 信号噪声（散粒噪声） |
|------|--------|----------------------|
| 与光信号 | 无关；有光无光 $\Delta T$ 可视为常量 | 随光信号强弱而变；与被测光强平方根成正比 |
| 来源 | 检测器与放大电路等部件的不确定性 | 电子一个一个迁移，单位时间内数目涨落 |
| $\Delta c/c$ 曲线 | 图 4-10 实线；$A=0.2\sim 0.7$ 较适宜 | 图 4-10 虚线；较小误差范围延伸到高吸光度区 |
:::

:::pitfall{label="适宜区 0.2～0.7 是暗噪声那条实线的结论"}
不要把 $A=0.2\sim 0.7$ 听成“任何噪声模型下都不能超出”。信号噪声的虚线在高 $A$ 区仍较有利。操作上教材要求测量落在最适宜范围即可，但解释时要分清实线／虚线。
:::

## 四、吸光系数和吸光度的测量

### （一）吸光系数

吸光系数的物理意义是吸光物质在单位浓度及单位厚度时的吸光度。在一定条件下（单色光波长、溶剂、温度等），吸光系数是物质的特性常数。不同物质对同一波长的单色光，可有不同的吸光系数。吸光系数愈大，表明该物质的吸光能力愈强，灵敏度愈高，所以吸光系数是定性和定量依据。

:::definition{label="吸光系数"}
吸光物质在单位浓度及单位厚度时的吸光度。在一定条件（单色光波长、溶剂、温度等）下是物质的特性常数，既是定性依据也是定量依据。愈大则吸光能力愈强、灵敏度愈高。
:::

吸光系数常用两种表示方式。

**（1）摩尔吸光系数**　用 $\varepsilon$ 表示，其意义是在一定波长下，溶液浓度为 $1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$，厚度为 $1\,\mathrm{cm}$ 时的吸光度。

:::definition{label="摩尔吸光系数"}
$\varepsilon$：一定波长下，浓度为 $1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$、厚度为 $1\,\mathrm{cm}$ 时的吸光度。
:::

**（2）比吸光系数**　又称百分吸光系数，用 $E_{1\,\mathrm{cm}}^{1\%}$ 表示，指在一定波长下，溶液质量浓度为 $1\%$（$\mathrm{g}/100\,\mathrm{mL}$），厚度为 $1\,\mathrm{cm}$ 时的吸光度。

:::definition{label="比吸光系数（百分吸光系数）"}
$E_{1\,\mathrm{cm}}^{1\%}$：一定波长下，质量浓度为 $1\%$（$\mathrm{g}/100\,\mathrm{mL}$）、厚度为 $1\,\mathrm{cm}$ 时的吸光度。
:::

:::note{label="计算时略去单位"}
为使用方便，本版在计算摩尔吸光系数和比吸光系数时将单位略去。
:::

两种吸光系数之间的关系是

$$
\varepsilon=\frac{M}{10}E_{1\,\mathrm{cm}}^{1\%} \tag{4-7}
$$

式中，$M$ 是吸光物质的摩尔质量。

:::definition{label="ε 与 E1%1cm 的换算"}
$\varepsilon=(M/10)\,E_{1\,\mathrm{cm}}^{1\%}$，$M$ 为摩尔质量。不要把分母 10 丢掉，也不要把 $E_{1\,\mathrm{cm}}^{1\%}$ 直接当成 $\varepsilon$。
:::

摩尔吸光系数一般不超过 $10^{5}$ 数量级。通常将 $\varepsilon$ 值达 $10^{4}$ 划为强吸收，小于 $10^{2}$ 划为弱吸收，介于两者之间的称为中强吸收。吸光系数不能直接用 $1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ 或 $1\%$ 这样高的浓度进行测定，需用准确的稀溶液测得吸光度换算而得到。

:::compare{title="强、中强、弱吸收"}
| 划分 | $\varepsilon$ | 前文落点 |
|------|---------------|----------|
| 强吸收 | 达 $10^{4}$（一般不超过 $10^{5}$ 数量级） | $\pi\to\pi^{*}$、K 带、电荷转移 $\varepsilon_{\max}>10^{4}$ |
| 中强吸收 | $10^{2}\sim 10^{4}$ 之间 | 三甲基胺 $\mathrm{n}\to\sigma^{*}$，$\varepsilon=900$ |
| 弱吸收 | $<10^{2}$ | $\mathrm{n}\to\pi^{*}$、R 带、配位场 $\varepsilon<100$ |
:::

:::example{label="例4-1　氯霉素的 ε 与 E1%1cm"}
氯霉素（$M=323.15\,\mathrm{g}\cdot\mathrm{mol}^{-1}$）的水溶液在 $278\,\mathrm{nm}$ 处有最大吸收。用纯品配制 $100\,\mathrm{mL}$ 含 $2.00\,\mathrm{mg}$ 的溶液，以 $1.00\,\mathrm{cm}$ 厚的吸收池在 $278\,\mathrm{nm}$ 处测得透光率为 $24.3\%$，求吸光度 $A$、摩尔吸光系数 $\varepsilon$ 和比吸光系数 $E_{1\,\mathrm{cm}}^{1\%}$。

**解：**

$$
A=-\lg T=-\lg 0.243=0.614
$$

质量浓度按 $\mathrm{g}/100\,\mathrm{mL}$ 计为 $2.00\times 10^{-3}$，

$$
E_{1\,\mathrm{cm}}^{1\%}=\frac{A}{cl}=\frac{0.614}{2.00\times 10^{-3}\times 1}=307
$$

$$
\varepsilon=\frac{M}{10}E_{1\,\mathrm{cm}}^{1\%}=\frac{323.15}{10}\times 307=9\,921
$$
:::

:::pitfall{label="E1% 的 c 是 g/100 mL，不是 mol·L⁻¹"}
例 4-1 把 $2.00\,\mathrm{mg}/100\,\mathrm{mL}$ 写成 $2.00\times 10^{-3}\,\mathrm{g}/100\,\mathrm{mL}$。若误把 $c$ 当成 $2.00\,\mathrm{mg}\cdot\mathrm{mL}^{-1}$ 或摩尔浓度，$\varepsilon$ 与 $E_{1\,\mathrm{cm}}^{1\%}$ 会对不上式（4-7）。$T=24.3\%$ 要写成 $0.243$ 再取 $-\lg$。
:::

### （二）吸光度的测量

**（1）溶剂和容器**　测量溶液吸光度的溶剂和吸收池应在所用的波长范围内有较好的透光性。玻璃不能透过紫外光，所以在紫外光区只能使用石英吸收池。许多溶剂本身在紫外光区有吸收峰，只能在它吸收较弱的波段使用。表 4-2 列出一些溶剂适用的最短波长（截止波长），低于这些波长就不宜使用。

:::definition{label="截止波长"}
溶剂适用的最短波长。低于截止波长不宜使用该溶剂。
:::

:::pitfall{label="紫外区不要用玻璃吸收池"}
玻璃不能透过紫外光，紫外光区只能使用石英吸收池。可见光区才选用玻璃吸收池——那一笔在第 2 节吸收池，不要提前把两种池子写反。
:::

:::insight{label="水、甲醇、环己烷截止在 200 nm，丙酮要到 330 nm"}
常用溶剂里，水、甲醇、环己烷的截止波长是 $200\,\mathrm{nm}$，乙醚、乙醇略高。丙酮 $330\,\mathrm{nm}$、吡啶 $305\,\mathrm{nm}$、二硫化碳 $380\,\mathrm{nm}$，不能拿来测 $278\,\mathrm{nm}$ 的氯霉素。截止波长不是“溶剂自己的 $\lambda_{\max}$”，是“低于此就不宜用”。
:::

**（2）空白对比**　测定吸光度，实际上是测定透光率。而在测定光强减弱时，不只是由待测物质的吸收所致，还有溶剂和容器的吸收、光的散射和界面反射等因素，都可使透射光减弱。用空白对比，可排除这些因素的干扰。空白是指与样品完全相同的溶液和容器，只是不含待测物质。采用光学性质相同、厚度相同的吸收池分别装入空白溶液和待测溶液。首先让空白溶液进入光路作为参比，调节仪器，使透过参比吸收池的吸光度为零（$A=0$），以及透光率 $T=100\%$。然后再将装有待测溶液的吸收池移入光路中测量，得到被测物质的吸光度。

:::definition{label="空白对比"}
空白是与样品完全相同的溶液和容器，只是不含待测物质。先让空白进入光路作参比，调节至 $A=0$、$T=100\%$，再测待测溶液，以排除溶剂和容器吸收、散射和界面反射。
:::

:::memory{label="第1节收口"}
- 光区：$200\sim 760\,\mathrm{nm}$（紫外 $200\sim 360$，可见 $360\sim 760$）；方法名 UV-Vis；电子光谱，灵敏度 $10^{-7}\sim 10^{-4}\,\mathrm{g}\cdot\mathrm{mL}^{-1}$。
- 曲线：$\lambda_{\max}$、$\lambda_{\min}$、$\lambda_{\mathrm{sh}}$、末端吸收；形状取决于分子结构。
- 能级：$\sigma<\pi<\mathrm{n}<\pi^{*}<\sigma^{*}$；能量 $\sigma\to\sigma^{*}>\mathrm{n}\to\sigma^{*}\ge\pi\to\pi^{*}>\mathrm{n}\to\pi^{*}$。
- 生色团／助色团；红移／蓝移；R、K、B、E 带。
- 定律：$A=-\lg T=Elc$；$T$ 对 $c$ 指数，$A$ 对 $c$ 正比；加和性。
- 偏离：光学（非单色光，选 $\lambda_{\max}$）＋化学（稀溶液、控存在形式）；测量误差 $A=0.2\sim 0.7$。
- $\varepsilon=(M/10)E_{1\,\mathrm{cm}}^{1\%}$；紫外用石英池；空白调 $A=0$、$T=100\%$。
:::
