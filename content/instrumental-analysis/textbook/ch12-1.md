# 第1节　概述

第 11 章把色谱写成固定相不动、流动相带着样品走。本章落到**液相、常压**这一档：经典液相色谱法。按本版，液相色谱法先按固定相规格、流动相输送方式、柱效、分离周期和检测灵敏度，分成经典液相色谱法和现代液相色谱法。本节只立这条分界、1906 年茨维特那一次柱实验，以及今天还把经典方法留在制备、纯化和条件摸索里的原因。吸附、分配、离子交换、分子排阻四本账放到第 2 节；薄层、纸色谱和比移值 $R_{\mathrm{f}}$ 放到第 3 节。不要把高压泵、梯度洗脱和在线检测器提前写成第 14 章高效液相，也不要吞第 13 章气相。

:::definition{label="经典液相色谱法"}
常压液相色谱技术。本版点名包括经典柱色谱、常规薄层色谱、纸色谱等。固定相用普通规格，流动相常压输送，一般不具备在线检测器。
:::

:::definition{label="经典柱色谱"}
概述名单里的第一种。柱状固定相加常压淋洗，第 2 节称为柱层析，以制备或半制备为目的。机理仍按固定相拆成四本账。
:::

:::definition{label="常规薄层色谱"}
概述名单里的第二种。固定相涂成薄层，常压展开。第 3 节与高效薄层（HPTLC）对照；本节只挂「常规」这一档。
:::

:::definition{label="纸色谱"}
概述名单里的第三种。纸为载体，第 3 节把它写成分配色谱：固定相是纸纤维上的水。20 世纪 60 年代以后应用逐渐减少，但基本要求仍要熟悉平面操作。
:::

:::definition{label="现代液相色谱法"}
与经典方法相对的另一档：固定相规格更细、流动相靠高压输送、柱效更高、分离周期更短、常配在线检测器。专章是第 14 章高效液相色谱法（HPLC），本节只用来对照，不写泵压和填料粒径。
:::

:::definition{label="常压输送"}
经典方法的流动相靠重力或毛细管作用推动，不靠高压泵。柱色谱是淋洗，平面色谱是展开。把「常压」听成「没有流动相」，层析柱会变成干柱静置。
:::

:::definition{label="在线检测器"}
装在柱出口、随流出液连续给出信号的检测器。经典液相一般不具备；收集流分后用薄层或化学法检查，或薄层展开后显色、扫描，都是离线检出。
:::

:::concept{term="先问常压还是高压，再问柱还是平面"}
看见「液相色谱」，先不要跳到 $C_{18}$ 柱和紫外检测器。户头是：流动相是液体。常压、普通填料、多半离线检出，是经典液相；高压、细颗粒、在线检测，是第 14 章。把本章听成 HPLC，后面层析柱、展开剂和 $R_{\mathrm{f}}$ 都会对空。把本章听成气相，沸点和热稳定性那一笔限制会被写反。
:::

:::insight{label="液相色谱先按操作档次切开，再按机理切开"}
本版第一刀不是吸附／分配，而是经典对现代。第 2 节才按固定相把柱色谱写成吸附、分配、离子交换、分子排阻四本账；第 3 节把平面色谱写成薄层和纸。两刀正交，不要并成「经典＝吸附、现代＝分配」。
:::

:::pitfall{label="不要把本章答成第 14 章，也不要吞第 13 章"}
HPLC 的泵、进样阀、梯度、检测器在第 14 章。气相色谱在第 13 章。本章可以写「样品不受沸点、热稳定性限制」——那是相对气相而言的一句对照，不是把毛细管柱和载气搬进来。扫描页旁的二维码、页眉「第12章　经典液相色谱法」、页码都不写入正文。
:::

## 一、从茨维特的色带到常压液相

1906 年，俄国植物学家茨维特（Tswett）分离植物色素：细颗粒碳酸钙装在竖管里，石油醚提取液从顶端倒下，再用石油醚淋洗，不同颜色的色素移行速度不同，在管的不同部位形成色带。第 11 章已经用这次实验给出固定相、流动相、色谱柱三个名词。本版把同一次实验写成**最原始、最典型的经典液相柱色谱法**：流动相是液体，推动力是常压（重力／毛细），填料是普通规格的固体吸附剂，没有在线检测器，结果靠眼睛看色带。

:::definition{label="茨维特实验在本章的落点"}
1906 年 Tswett 分离植物色素，是最原始、最典型的经典液相柱色谱。第 11 章用它给 chromatography 起名；本章用它给「经典液相」起范。
:::

:::timeline{period="经典液相在本版里的位置"}
- **1906 年** 茨维特用碳酸钙柱、石油醚淋洗植物色素，得到色带；本版称为最原始、最典型的经典液相柱色谱
- **此后** 柱层析长期用于制备和色素、天然产物分离
- **20 世纪 40 年代** 纸色谱出现（第 3 节）
- **20 世纪 60 年代** 薄层色谱发展和普及，纸色谱应用逐渐减少（第 3 节）
- **20 世纪 70 年代** 高效液相色谱兴起，分析目的大量转到第 14 章
- **20 世纪 80 年代** 仪器化薄层色谱配薄层扫描仪，定量重现性和准确度提高（第 3 节）
- **今天** 经典液相较少用于纯粹分析，仍用于样品制备、纯化、实验条件优化；薄层作为初始分离手段仍很广
:::

:::note{label="层析和色谱是同一个英文词"}
第 2 节会写：经典柱色谱又称为柱层析（column chromatography），用「层析」主要是为了和现代色谱区别，其实层析或色谱均来自 chromatography。概述里先记住：不要把层析听成另一种原理。
:::

:::memory{label="1906 这一笔不要改年代"}
茨维特是 1906 年，不是 1903 也不是 1910。扫描稿有时把 Tswett 粘成一个词，本版人名按 Tswett。碳酸钙柱、石油醚、植物色素三件套不要改成硅胶柱、甲醇、生物碱。
:::

## 二、经典液相和现代液相怎样分户

按照固定相的种类和规格、流动相的输送方式、柱效、分离周期和检测灵敏度的不同，液相色谱法分为经典液相色谱法和现代液相色谱法。本版把分界写在这五项上，不是写在「有没有颜色」上。

:::definition{label="五项分界"}
固定相种类和规格、流动相输送方式、柱效、分离周期、检测灵敏度。五项一起把液相切成经典档和现代档。
:::

:::definition{label="普通规格固定相"}
经典柱色谱吸附剂颗粒大多为直径 $0.07\sim 0.15\,\mathrm{mm}$；常规薄层硅胶粒度为 $10\sim 40\,\mu\mathrm{m}$。第 14 章细颗粒高压填料不在本节展开。数字先挂上，操作细节在第 2、3 节。
:::

:::definition{label="柱效与分离周期"}
本版写经典液相分离周期比较长、分离效率比较低。柱效是反复分配的次数和谱带宽度；周期是一次分离要等多久。不要用「分析速度快」（并行多样品）把这两项改写成比 HPLC 更高、更短。
:::

:::compare{title="经典液相色谱对现代液相色谱"}
| | 经典液相 | 现代液相（第 14 章） |
|--|----------|----------------------|
| 固定相 | 普通规格（柱色谱颗粒常为 $0.07\sim 0.15\,\mathrm{mm}$；薄层硅胶常为 $10\sim 40\,\mu\mathrm{m}$） | 细颗粒、高压填料 |
| 流动相输送 | 常压（重力、毛细） | 高压泵 |
| 检测 | 一般不具备在线检测器；薄层靠显色、扫描离线看 | 在线检测器 |
| 分离周期 | 比较长 | 比较短 |
| 柱效／分离效率 | 比较低 | 比较高 |
| 设备与费用 | 仪器简单，费用低 | 仪器复杂，费用高 |
| 样品限制 | 不受沸点、热稳定性限制；预处理要求不高 | 专章再写进样和溶剂 |
| 样品通量 | 能同时分析多个样品（尤其薄层、纸色谱） | 通常一次进一针 |
:::

:::insight{label="「分析速度快」指的是可以并行，不是指一根柱的线速度"}
教材写经典液相「分析速度快，能同时分析多个样品」。对照表里分离周期其实更长。两句话不打架：一根常压柱淋洗可以很慢，但一块薄层板上可以平行点一排样品。把「快」理解成 van Deemter 最优流速，户头就搬到第 11 章第 3 节去了。
:::

:::pitfall{label="一般不具备在线检测器，不是禁止任何检测"}
经典柱色谱收集流出液后，用薄层或化学法做定性检查；薄层展开后显色、或用薄层扫描仪离线扫描。这些都是检测，只是不装在柱出口当在线检测器。不要把「无在线检测器」答成「不能定量、不能看斑点」。
:::

:::keypoint{label="样品不受沸点、热稳定性限制"}
这一句是相对气相色谱（第 13 章）说的：液体流动相在常温附近工作，不要求样品气化。不要由此推出「经典液相什么都能分离」——离子型、大分子、强极性各有第 2 节的固定相账。也不要把第 13 章的载气、毛细管柱、程序升温写进本章。
:::

## 三、今天还把经典方法留在哪

虽然经典液相色谱法在今天的分析化学中已经较少用于纯粹的分析目的，但在样品制备、纯化、实验条件优化等方面仍然发挥着一定的作用。特别是薄层色谱法在有机合成、化学工业、药物筛选、临床检验、生化分析等领域，常常作为初始分离分析的手段，仍然有着非常广泛的应用。

:::definition{label="经典液相今天的三类用途"}
样品制备、纯化、实验条件优化。纯粹的定量分析大多已经交给第 14 章；条件摸索和制备量仍常用常压柱和薄层。
:::

:::definition{label="样品制备与纯化"}
把混合物里要留下的组分从柱上洗下来、收集、浓缩。经典柱色谱的制备、半制备目的落在这里。不是第 14 章的含量测定。
:::

:::definition{label="实验条件优化"}
先在薄层上换展开剂、换吸附剂活性、看斑点能不能分开，再决定要不要装柱或上 HPLC。概述只点用途，Stahl 三角放到第 3 节。
:::

:::definition{label="薄层作为初始手段"}
有机合成、化学工业、药物筛选、临床检验、生化分析里，薄层常用来先看混合物能不能分开、斑点有几个、极性大概在哪。第 3 节再写展开剂、显色和 $R_{\mathrm{f}}$。
:::

:::definition{label="不受沸点与热稳定性限制"}
液体流动相在常温附近工作，不要求样品气化。这一句相对第 13 章气相而言。热不稳定、高沸点的药物、生物样品可以走液相；不等于任何极性、任何分子量都能用同一根硅胶柱。
:::

:::compare{title="三种经典操作形式在概述里先挂名"}
| 形式 | 本版放在哪 | 固定相怎么放 | 概述里先记住 |
|------|------------|--------------|--------------|
| 经典柱色谱（柱层析） | 第 2 节 | 装在玻璃层析柱里 | 以制备或半制备为目的 |
| 常规薄层色谱 | 第 3 节 | 涂在玻璃、塑料或铝箔上 | 初始分离、可并行多样品 |
| 纸色谱 | 第 3 节 | 纸纤维吸附的水作固定相 | 分配机理，适合极性较大的物质 |
:::

:::insight{label="制备、半制备和分析不是三种机理"}
第 2 节把经典柱色谱写成「以制备或半制备为目的」。规模是操作目的，机理仍是吸附／分配／离子交换／排阻。薄层也可以做半制备和制备（加厚薄层）。问「经典柱色谱是什么」时，先答柱状固定相加淋洗，再补制备目的，不要答成「只能制备、不能分析」。
:::

:::pitfall{label="较少用于纯粹分析，不是已经淘汰"}
教材没有写「经典方法过时、不必学」。基本要求仍要掌握吸附色谱的分离机理和固定相／流动相选择，掌握平面色谱原理和参数。把概述听成「只需知道 HPLC」，章末思考题第 1 问四类固定相会对空。
:::

:::tip{label="实验条件优化为什么还用薄层"}
换展开剂、换吸附剂活性、看 $R_{\mathrm{f}}$ 是否落在 $0.2\sim 0.8$，一块板比装一根高压柱快。第 14 章的流动相条件，有时就是从薄层的展开剂经验迁过去的。概述只点这句用途，配方不要在这里展开。
:::

## 四、本章三节怎样切开

本版第 12 章三节：概述（本节）、经典柱色谱法、平面色谱法。柱色谱按固定相写成四本账；平面色谱相对柱色谱，在平面上展开，主要包括薄层和纸色谱。平面色谱的构成要素和分离机理与柱色谱基本相同，构成形式和操作过程不同：开放、离线，流动相靠毛细管作用或重力，分离过程叫展开，流动相叫展开剂。

:::definition{label="本章不写的两章"}
气相色谱法是第 13 章；高效液相色谱法是第 14 章。本章出现 GSC、GLC、LSC、LLC 时，只用来说明吸附或分配也可以在气相或液相里发生，不是把第 13 章仪器搬进来。
:::

:::compare{title="四本账按固定相分，不要按「新不新」分"}
| 第 2 节类型 | 固定相 | 分开靠什么 | 典型对象 |
|--------------|--------|------------|----------|
| 吸附色谱 | 固体吸附剂（硅胶、氧化铝、聚酰胺、大孔树脂等） | 争夺表面活性中心 | 多数 GSC、LSC；茨维特原法 |
| 分配色谱 | 涂在惰性载体上的固定液 | 两相溶解度／分配系数 | 多数 GLC、LLC |
| 离子交换色谱 | 离子交换树脂 | 离子亲和力 | 离子型化合物 |
| 分子排阻色谱 | 多孔凝胶 | 分子尺寸与孔径 | 蛋白质、多糖等大分子 |
:::

:::keypoint{label="第 1 节写到哪一层为止"}
- 写：经典对现代的五项分界；茨维特 1906 年作为经典液相柱色谱的范例；常压、普通固定相、一般无在线检测器；周期长、效率低，但设备简单、费用低、可并行、预处理要求不高、不受沸点热稳定性限制；今天用于制备、纯化、条件优化；薄层仍作初始手段。
- 不写：吸附系数公式、交联度百分数、$R_{\mathrm{f}}$ 公式、Stahl 三角、薄层扫描是否服从朗伯–比尔定律。那些分别是第 2、3 节的账。
:::

:::memory{label="概述收口"}
- 液相先切经典／现代，再切柱／平面。
- 经典＝常压＋普通固定相＋多半离线检出。
- 1906 茨维特＝最典型的经典液相柱色谱。
- 今天少做纯分析，还做制备、纯化、摸条件。
- 薄层在合成、化工、筛药、临床、生化里仍当第一刀。
- HPLC 去第 14 章，GC 去第 13 章。
:::
