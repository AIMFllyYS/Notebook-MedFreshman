# 第2节　X射线衍射法

第 1 节把 ICP-MS 写成元素的质荷比。本节换户头：X 射线衍射法研究的是物相和晶体结构，测的是衍射方向与强度，不是发射光谱，也不是第 1 章点过名的 X 射线荧光。简介深度停在布拉格方程、衍射仪四块和三类应用，不要扩写成晶体学专著。

X 射线衍射法，简称 XRD（X-ray diffraction），是研究物质的物相和晶体结构的主要方法。当某物质进行 X 射线衍射分析时，该物质被 X 射线照射产生不同程度的衍射现象，物质组成、晶型、分子内成键方式、分子的构型、构象等决定该物质产生特有的衍射图谱。X 射线衍射技术可以测定材料的结构、晶格畸变、晶粒大小、晶体取向、晶体织构、晶体内应力、结晶度，还可以进行固溶体分析、相变研究、电畴或磁畴结构分析等方面的工作。X 射线衍射法具有不损伤样品、无污染、快捷、测量精度高、能得到有关晶体完整性的大量信息等优点。因此，X 射线衍射法作为材料结构和成分分析的一种现代科学方法，已成为认识和改造物质结构的有力工具，是材料科学研究必不可少的基本表征方法之一。

:::definition{label="X 射线衍射法"}
X 射线衍射法，简称 XRD（X-ray diffraction），是研究物质的物相和晶体结构的主要方法。物质被 X 射线照射产生特有的衍射图谱，图谱由组成、晶型、分子内成键方式、分子的构型、构象等决定。
:::

:::definition{label="XRD 能测定什么"}
结构、晶格畸变、晶粒大小、晶体取向、晶体织构、晶体内应力、结晶度；还可做固溶体分析、相变研究、电畴或磁畴结构分析。
:::

:::definition{label="XRD 的优点"}
不损伤样品、无污染、快捷、测量精度高、能得到有关晶体完整性的大量信息。
:::

:::concept{term="先问衍射图是谁的指纹，再问 θ 和 d"}
看见 XRD，先不要跳到测角仪半径。户头是：晶体有周期点阵，X 射线波长和原子间距同数量级，于是发生有选择的衍射。每种晶体一份特有图谱。把 XRD 听成 X 射线荧光（内层电子空位再发射），后面布拉格公式和物相检索都会对错户头。
:::

:::pitfall{label="XRD 不是 XRF，也不是第 1 节的 ICP-MS"}
X 射线荧光是光谱法，测元素。XRD 是衍射，测物相和晶体结构。同一份样品可以含相同元素却是不同晶型——药学里那格列奈、阿立哌唑的鉴别就落在晶型，不落在元素总量。
:::

:::note{label="英文不要粘成一个词"}
本版写成 X-ray diffraction。扫描稿 X-raydiffraction 是 OCR 粘连。
:::

## 一、基本原理

:::timeline{period="X 射线与衍射的两个里程碑"}
- **1895 年** 德国物理学家伦琴发现 X 射线，可窥视肉眼看不见的表面后物体，如人体内骨骼与脏器
- **1912 年** 劳埃发现 X 射线衍射现象，获得探索人眼无法分辨的微观世界的工具
- **1913 年** 布拉格导出 X 射线衍射方程式，即布拉格公式
:::

:::insight{label="两大发现不要并成一件事"}
伦琴解决的是「看不见的宏观内部」；劳埃解决的是「看不见的微观周期」。衍射仪和布拉格公式走劳埃这一支，不要把医用透视机的户头写成 XRD。
:::

### （一）X 射线是什么，为什么会在晶体里衍射

X 射线是由于高能电子的减速运动或原子内层轨道电子跃迁而产生的高能量短波电磁辐射，其波长范围为 $0.01\sim 10\,\mathrm{nm}$。X 射线在本质上是一种电磁辐射，具有电磁辐射的基本性质波粒二象性。但由于 X 射线波长短、能量大，穿透能力强，且 X 射线的波长和晶体内部原子间的距离相近，所以 X 射线在透过晶体时会发生衍射现象。

:::definition{label="X 射线"}
高能电子的减速运动或原子内层轨道电子跃迁产生的高能量短波电磁辐射。波长 $0.01\sim 10\,\mathrm{nm}$。本质是电磁辐射，具有波粒二象性。
:::

:::definition{label="为什么晶体能衍射 X 射线"}
波长短、能量大、穿透能力强，并且波长和晶体内部原子间距离相近，透过晶体时发生衍射。
:::

:::cause-effect{title="波长必须和原子间距同数量级"}
- **因** 衍射要求光栅常数与波长相当。晶体点阵间距正好和 X 射线波长相近
- **果** 可见光波长比原子间距大得多，不能拿可见光做晶体衍射；X 射线可以
:::

:::pitfall{label="波长范围以本版 0.01～10 nm 为准"}
不要用别的书的 $0.001\sim 10\,\mathrm{nm}$ 或按「硬 X 射线／软 X 射线」另划区来改这一句。产生途径本版只写两条：高能电子减速，或内层轨道电子跃迁。
:::

### （二）布拉格公式

由于晶体是由原子、离子或分子在空间规则排列的晶胞构成的，晶体结构的周期性可以用点阵来描述。英国物理学家布拉格（Bragg）把晶体的点阵结构看成为一组相互平行且等距离的原子平面，当单色 X 射线照射到晶体时，由于这些规则排列点阵间的距离与入射 X 射线的波长具有相同的数量级，当 X 射线以入射角 $\theta$ 刚好打在晶体的质点上时，根据反射定律（反射光线在入射平面中，反射角等于入射角），会以同样的角度反射出去（图 9-3）。当两束 X 射线的光程差刚好是波长的整数倍时，X 射线的强度会相互增强，出现衍射现象。据此，布拉格于 1913 年导出了著名的 X 射线衍射方程式，即布拉格公式：

$$
2d\sin\theta=n\lambda\qquad n=0,1,2,3,\ldots
$$

式中，$d$ 为晶面间距，$\theta$ 是晶面与入射线或反射线的夹角，$\lambda$ 是 X 射线的波长，$n$ 为衍射级数。布拉格方程是 X 射线衍射分析的基本依据，X 射线在晶体中的衍射实质上是受 X 射线照射的晶体中所有原子（包括内部）的反射线干涉加强而形成的，晶体对 X 射线的衍射现象并不是任意的，只有当 $\lambda$、$\theta$ 和 $d$ 三者之间满足布拉格方程才能发生，是有选择性的。

:::definition{label="点阵被看成一组平行等距原子平面"}
布拉格把晶体点阵看成一组相互平行且等距离的原子平面。晶胞由原子、离子或分子在空间规则排列构成，周期性用点阵描述。
:::

:::theorem{label="布拉格公式（式 9-1）"}
$2d\sin\theta=n\lambda$，$n=0,1,2,3,\ldots$。$d$：晶面间距。$\theta$：晶面与入射线或反射线的夹角。$\lambda$：X 射线波长。$n$：衍射级数。
:::

:::definition{label="衍射是有选择的干涉加强"}
两束反射线光程差为波长的整数倍时强度相互增强。实质上是晶体中所有原子（包括内部）的反射线干涉加强。只有 $\lambda$、$\theta$、$d$ 满足布拉格方程才发生。
:::

:::insight{label="反射定律只说明出射方向，布拉格公式才说明何时加强"}
反射角等于入射角，给出「以同样角度反射出去」。能否观察到衍射强度，还要光程差 $2d\sin\theta$ 等于 $n\lambda$。只背反射定律答不出「为什么有的角度没有峰」。
:::

::figure{src="/images/instrumental-analysis/textbook/p0230_01.jpg" caption="图9-3　布拉格衍射示意图。一组平行晶面间距为 d；入射线与晶面夹角 θ，按反射定律以同样角度出射；相邻晶面反射线的光程差为 nλ 时干涉加强。" alt="两组平行晶面，入射线与反射线夹角 θ，标晶面间距 d 和光程差 nλ"}

对于一定波长的 X 射线而言，晶体中能产生衍射的晶面数是有限的。从布拉格方程可以看出，$\dfrac{\lambda}{2d}=\sin\theta$，由于 $\sin\theta$ 最大只能等于 1，因此 $\dfrac{\lambda}{2d}\le 1$，即 $\lambda\le 2d$。这就表明，能够被晶体衍射的 X 射线的波长必须小于反射的晶面间距的 2 倍。此外，当 X 射线的波长一定时，晶体中能够参加衍射的晶面也是有限的，它们必须满足 $d\ge\dfrac{\lambda}{2}$，即晶面间距只有大于 $\dfrac{\lambda}{2}$ 的那些晶面才能发生衍射。

:::definition{label="波长上限"}
$\sin\theta\le 1$，故 $\lambda\le 2d$。能够被晶体衍射的 X 射线波长必须小于反射晶面间距的 2 倍。
:::

:::definition{label="晶面间距下限"}
$\lambda$ 一定时，只有 $d\ge\lambda/2$ 的晶面才能衍射。能产生衍射的晶面数是有限的。
:::

:::pitfall{label="不要把 λ≤2d 写成 λ≥2d，也不要把 θ 听成与法线的夹角"}
本版 $\theta$ 是晶面与入射线或反射线的夹角，不是有的书里与晶面法线的夹角。公式里是 $\sin\theta$。把不等号写反，短波 X 射线会被说成「都不能衍射」。
:::

:::derivation{title="由式（9-1）得到两个不等式"}
由 $2d\sin\theta=n\lambda$，取 $n=1$ 的极限情形：$\lambda/(2d)=\sin\theta$。$\sin\theta$ 最大为 1，故 $\lambda/(2d)\le 1$，即 $\lambda\le 2d$。$\lambda$ 固定时，$d\ge\lambda/2$。$n$ 取更大整数只会要求 $d$ 更大或 $\theta$ 更接近 $90^{\circ}$，能参加衍射的晶面仍然有限。
:::

布拉格方程将晶体的周期性特点 $d$、X 射线的本质 $\lambda$ 与衍射规律 $\theta$ 结合起来。在晶体结构分析中，若已知 $\lambda$ 及实验中的测定角 $\theta$，计算 $d$ 就可以确定晶体的周期结构。此外，应用已知 $d$ 的晶体来测量 $\theta$ 角，计算出特征 X 射线的波长，进而在已有资料中查得样品中所含的元素，可实现定性分析。

:::compare{title="布拉格方程的两个用法"}
| 已知 | 测定 | 求得 | 目的 |
|------|------|------|------|
| $\lambda$、$\theta$ | 衍射角 | $d$ | 晶体的周期结构 |
| $d$、$\theta$ | 衍射角 | 特征 X 射线波长 | 查资料报所含元素（定性） |
:::

:::keypoint{label="三个量焊在一起"}
$d$ 是晶体周期，$\lambda$ 是 X 射线本质，$\theta$ 是衍射规律。少一个，布拉格方程解不出来。结构分析走「已知 $\lambda$ 求 $d$」；用已知晶体测特征波长走「已知 $d$ 求 $\lambda$」。
:::

## 二、X 射线衍射仪

X 射线衍射仪是一种最常见的 X 射线衍射分析仪器，其基本构成包括 X 射线发生器、测角仪、检测器及数据记录系统四大部分（图 9-4）。

:::definition{label="衍射仪四块"}
X 射线发生器、测角仪、检测器、数据记录系统。
:::

::figure{src="/images/instrumental-analysis/textbook/p0231_01.jpg" caption="图9-4　X 射线衍射仪示意图。X 射线发生器与检测器分居测角仪圆周，样品在圆心；检测器与 2θ 联动，信号送数据记录系统。" alt="测角仪圆：左侧 X 射线发生器，圆心样品，右侧检测器，下方数据记录系统"}

### （一）X 射线发生器

X 射线发生器主要由高压控制系统和 X 射线管两部分组成，它是产生 X 射线的装置。X 射线管包括灯丝和靶两部分，灯丝产生的电子与靶撞击产生 X 射线，高压发生器产生高达几万伏的电压，加速电子撞击靶。X 射线发生器发出的 X 射线包括连续 X 射线光谱和特征 X 射线光谱，连续 X 射线光谱主要用于判断晶体的对称性和进行晶体的定向劳埃法，特征 X 射线主要用于进行晶体结构研究的旋转晶体法和进行物相鉴定的粉末法。

:::definition{label="X 射线发生器"}
高压控制系统 $+$ X 射线管。X 射线管：灯丝和靶。灯丝电子被高达几万伏的电压加速后撞击靶，产生 X 射线。
:::

:::compare{title="连续谱对特征谱"}
| 光谱 | 主要用途 | 方法名 |
|------|----------|--------|
| 连续 X 射线光谱 | 判断晶体对称性；晶体定向 | 劳埃法 |
| 特征 X 射线光谱 | 晶体结构研究；物相鉴定 | 旋转晶体法；粉末法 |
:::

:::pitfall{label="不要把连续谱和特征谱的用途对调"}
劳埃法定向、看对称性，用连续谱。旋转晶体法做结构、粉末法做物相，用特征谱。把粉末法写成必须用连续谱，物相鉴定的 $d$ 值就没有单色 $\lambda$ 可代入布拉格公式。
:::

:::note{label="几万伏只给数量级"}
本版写高压「高达几万伏」，不给具体管压、靶材波长表。简介不要补 Cu $K\alpha$ 的 $1.54\,\mathrm{\mathring{A}}$ 之类教材没写的数。
:::

### （二）测角仪

测角仪是 X 射线衍射仪的重要部分，X 射线发生器发出的射线焦点与检测器计数管窗口分别位于测角仪圆周上，样品位于测角仪圆的中心。测角仪的内外圆可分别绕中心转动，通过圆周运动改变入射角。当 X 射线发生器加以高压时，产生的 X 射线经过发射狭缝照射到样品上，晶体中与样品表面平行的面网在符合布拉格衍射条件时可产生衍射而被检测器接收。

:::definition{label="测角仪几何"}
射线焦点与检测器计数管窗口在圆周上，样品在圆心。内外圆可分别绕中心转动，用圆周运动改变入射角。
:::

:::definition{label="谁在衍射"}
X 射线经发射狭缝打到样品上。晶体中与样品表面平行的面网，在符合布拉格条件时产生衍射，被检测器接收。
:::

:::insight{label="图9-4 上的 2θ 不要和公式里的 θ 对调"}
公式中 $\theta$ 是晶面与入射线（或反射线）的夹角。测角仪上检测器常常走 $2\theta$。读图时认「样品在圆心、发生器与检测器在圆周」，不要把 $2\theta$ 直接代进 $2d\sin\theta=n\lambda$ 里当 $\theta$。
:::

### （三）检测器与数据记录

检测器的作用是接收样品产生的衍射线强度，将其转化为电信号，常用的有闪烁计数器和正比计数器等。衍射线被检测器计数管记录转换成电信号后，经放大处理后得到样品的衍射图谱。

:::definition{label="检测器"}
接收衍射线强度并转化为电信号。常用闪烁计数器、正比计数器等。
:::

:::definition{label="衍射图谱从哪来"}
计数管记录 → 电信号 → 放大处理 → 样品的衍射图谱。
:::

:::keypoint{label="四块各管一件事"}
发生器出 X 射线（连续谱或特征谱）。测角仪改 $\theta$。检测器把强度变成电信号。数据记录系统出图。缺一块，布拉格方程的 $\theta$ 或强度都落不到纸上。
:::

## 三、应用

目前，X 射线衍射法已经成为研究晶体物质和某些非晶态物质微观结构的有效方法。物质 X 射线衍射图谱与物质内部晶体结构有关，通过分析待测样品的 X 射线衍射图谱，不仅可以知道物质的化学成分，还能知道它们的存在状态。同时，根据 X 射线衍射图谱还可以进行晶体物质的定量分析、晶粒大小的测量和晶粒的取向分析等。

:::definition{label="图谱能回答什么"}
化学成分；存在状态；定量分析；晶粒大小；晶粒取向。对象以晶体为主，也包括某些非晶态物质的微观结构。
:::

:::insight{label="「成分」在 XRD 里常常是物相，不只是元素"}
同一元素可以形成不同晶型、不同化合物。图谱指纹对应的是物相。ICP-MS 报元素总量，XRD 报这个元素以什么晶体形式存在着。
:::

### （一）物相分析

物相分析是 X 射线衍射在材料分析中最常见的应用，分为定性物相分析和定量物相分析两类。由于每种晶体物质有其唯一对应的衍射图谱，定性物相分析将待测样品的衍射图谱与各种已知单相标准物质的衍射图谱相比较，从而确定材料中存在的物相。确定相组成后，定量物相分析则根据衍射线的强度来确定材料中各相物质的相对含量。内标法是最经典的定量物相分析方法，在被测的样品中加入一种含量一定的标准物质制成复合样品，通过测定复合样品中待测相的某一衍射线强度与内标物质某一衍射线强度的比值，测定待测相的含量。

:::definition{label="定性物相分析"}
每种晶体物质有唯一对应的衍射图谱。把待测图谱与已知单相标准物质的图谱相比较，确定存在哪些物相。
:::

:::definition{label="定量物相分析"}
相组成确定之后，根据衍射线强度确定各相相对含量。
:::

:::definition{label="内标法"}
最经典的定量物相分析方法。向样品加入含量一定的标准物质制成复合样品，测待测相某衍射线强度与内标某衍射线强度的比值，得待测相含量。
:::

:::compare{title="定性物相对定量物相"}
| 项目 | 定性 | 定量 |
|------|------|------|
| 依据 | 图谱指纹（峰位，即 $d$／$\theta$） | 衍射线强度 |
| 做法 | 与单相标准图谱比较 | 内标法：强度比 |
| 前提 | 每种晶体一份唯一图谱 | 先确定相组成 |
:::

:::pitfall{label="不要把定性物相当成元素定性"}
比较的是整张衍射图谱与标准物相卡片，不是把峰位换算成特征 X 射线波长再去查元素表。上一节「已知 $d$ 求 $\lambda$ 查元素」是布拉格方程的另一种用法，和「物相指纹检索」不是同一道手续。
:::

### （二）晶体点阵常数的测定

点阵常数是晶体物质的基本结构参数，测定点阵常数在研究固态相变、确定固溶体类型、测定固溶体溶解度曲线、测定热膨胀系数等方面都得到了应用。点阵常数的测定是通过 X 射线衍射线的位置（$\theta$）的测定而获得的，通过测定衍射图谱中每一条衍射线的位置均可计算得到一个点阵常数值。

:::definition{label="点阵常数"}
晶体物质的基本结构参数。由衍射线位置 $\theta$ 测定。图谱中每一条衍射线的位置都可算出一个点阵常数值。
:::

:::definition{label="点阵常数用在哪"}
固态相变、确定固溶体类型、测定固溶体溶解度曲线、测定热膨胀系数。
:::

:::cause-effect{title="为什么位置能算出点阵常数"}
- **因** 布拉格方程把 $\theta$ 和 $d$ 焊在一起；点阵常数与 $d$ 有几何关系
- **果** 测准 $\theta$ 就能算点阵常数。强度用来定量物相，位置用来测点阵常数，两本账不要并
:::

### （三）晶粒尺寸和点阵畸变的测定

若晶体材料的晶粒无畸变、足够大，理论上其 X 射线衍射图谱的谱线应特别锋利。但在实际实验中，由于仪器因素及物理因素等的综合影响，衍射谱线会有一定的基底展宽。此外，衍射谱线的形状和宽度由样品的平均晶粒尺寸、尺寸分布及晶体点阵中的主要缺陷决定，因此分析衍射线的形状可以获得晶粒尺寸和点阵畸变的信息。

:::definition{label="理想谱线与基底展宽"}
晶粒无畸变且足够大时，谱线应特别锋利。实际因仪器因素及物理因素，谱线有基底展宽。
:::

:::definition{label="形状和宽度告诉什么"}
由平均晶粒尺寸、尺寸分布及点阵主要缺陷决定。分析衍射线形状，得到晶粒尺寸和点阵畸变信息。
:::

:::pitfall{label="不要把「锋利」听成仪器坏了才变宽"}
理想锋利只在无畸变、晶粒足够大时成立。展宽既有仪器因素，也有晶粒尺寸和缺陷。把所有宽峰都怪到测角仪，晶粒尺寸这一项应用就丢了。本版不给谢乐公式，简介不要自行补 $D=K\lambda/(\beta\cos\theta)$。
:::

综上所述，X 射线衍射技术在材料分析中有着十分广泛的应用，是研究材料尤其是晶体材料最方便、最重要的手段。随着实验技术的不断创新和设备的不断完善，X 射线衍射技术在材料分析领域必将拥有更广阔的应用前景。

在药物分析中，部分化学药品中存在多晶型现象，当不同晶型状态对药品的安全性或有效性产生影响时，应对其晶型进行研究，必要时应在标准中对其有效晶型予以控制。《中国药典》（2015 年版）加强了对多晶型品种的研究，建立了适宜的检测方法。如那格列奈和阿立哌唑的质量标准中采用 X 射线衍射法进行鉴别，确定有效晶型。

:::definition{label="多晶型与药典控制"}
部分化学药品存在多晶型。晶型影响安全性或有效性时，应研究晶型，必要时在标准中控制有效晶型。《中国药典》（2015 年版）加强多晶型研究。那格列奈、阿立哌唑用 XRD 鉴别有效晶型。
:::

:::memory{label="XRD 一页纸"}
- 波长 $0.01\sim 10\,\mathrm{nm}$；布拉格 $2d\sin\theta=n\lambda$；$\lambda\le 2d$，$d\ge\lambda/2$。
- 已知 $\lambda$、$\theta$ 求 $d$（结构）；已知 $d$、$\theta$ 求 $\lambda$（查元素）。
- 四块：发生器、测角仪、检测器、记录。连续谱→劳埃法；特征谱→旋转晶体法、粉末法。
- 物相：指纹定性，强度定量（内标）；$\theta$ 测点阵常数；峰形测晶粒尺寸和畸变。
