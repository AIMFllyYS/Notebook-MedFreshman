# 第4节　红外光谱仪及制样

前三节把峰从哪来、落在哪讲完。本节写仪器和制样：三代仪器（棱镜已淘汰、光栅仍在用、20 世纪 70 年代 FTIR）；光栅仪样品放在光源和单色器之间，与紫外相反；FTIR 用迈克耳孙干涉仪，全程扫描小于 $0.1\,\mathrm{s}$；制样以固态 KBr 压片最常用。波数范围、能斯特灯温度、聚苯乙烯校正峰一律按本版，不要用别的红外教材替换。

红外光谱仪（infrared spectrophotometer）由光源、吸收池、单色器、检测器及记录装置等部件组成。常见的红外光谱仪的波数范围为 $4000\sim 400\,\mathrm{cm}^{-1}$ 或 $4000\sim 200\,\mathrm{cm}^{-1}$。仪器的发展大体经历三个阶段，主要区别是单色器。

:::definition{label="红外光谱仪"}
红外光谱仪（infrared spectrophotometer）由光源、吸收池、单色器、检测器及记录装置等部件组成。常见波数范围 $4000\sim 400\,\mathrm{cm}^{-1}$ 或 $4000\sim 200\,\mathrm{cm}^{-1}$。
:::

:::definition{label="三代仪器"}
第一代：棱镜红外分光光度计，岩盐棱镜作色散元件，易吸潮损坏、分辨率低，已被淘汰。第二代：光栅红外分光光度计，分辨率超过棱镜，对安装环境要求不高、价格便宜，使用至今，但扫描速率较慢。第三代：20 世纪 70 年代诞生的干涉调频傅里叶变换红外光谱仪（Fourier transform infrared spectrophotometer，FTIR），分光器多用迈克耳孙干涉仪，分辨率很高，一次全程扫描小于 $0.1\,\mathrm{s}$，结构简单、体积小、质量轻，有取代第二代的趋势。
:::

:::concept{term="先问色散还是干涉，再问样品在单色器前还是后"}
光栅仪仍是“光源 → 样品 → 单色器 → 检测器”的色散扫描。紫外把样品放在单色器之后，红外光栅仪把样品放在光源和单色器之间。FTIR 不再用光栅当主色散件，先得到干涉图再傅里叶变换。
:::

本节主要介绍现在仍在使用的光栅红外分光光度计和傅里叶变换红外光谱仪的主要部件和工作原理。

## 一、光栅红外分光光度计

光栅红外分光光度计由光源、样品池、单色器、检测器及工作站 5 部分组成，其色散元件为光栅。它的组成部件与紫外分光光度计相似，主要区别在于红外分光光度计的样品放在光源和单色器之间，而紫外分光光度计的样品放在单色器之后。

光栅红外分光光度计原理示意图见图6-28。自光源发出的红外辐射被分成等强度的两束：一束通过样品池，另一束通过参比池。两光束汇合于斩光器处，最后样品光束和参比光束交替地进入单色器，交替落在检测器上，最后被检测出来。

:::definition{label="光栅红外分光光度计"}
五部分：光源、样品池、单色器、检测器及工作站。色散元件为光栅。样品在光源和单色器之间。双光束：样品束与参比束等强度，经斩光器交替进入单色器、落在检测器上。
:::

:::pitfall{label="红外光栅仪的样品不在单色器之后"}
紫外：单色器之后再过样品，减少杂散光引起的光化学反应。红外：样品放在光源和单色器之间。把两套光路画成同一张，斩光器和样品位置都会错。
:::

### （一）光源

凡是能发射连续波长的红外光，且发散度小、寿命长的物体均可作为红外光源。中红外区常用的辐射源有能斯特灯、硅碳棒等。

① **能斯特灯（Nernst glower）**　由氧化锆、氧化钍、氧化钇等的混合物烧结而成，工作温度在 $1800^{\circ}\mathrm{C}$ 左右，最大发射波数为 $7100\,\mathrm{cm}^{-1}$。优点是其发光强度是同温度硅碳棒的两倍，寿命长，稳定性好；缺点是性脆易碎且价格较贵。

② **硅碳棒（globar）**　由碳化硅烧结制成的实心棒，一般工作温度为 $1200\sim 1500^{\circ}\mathrm{C}$，最大发射波数为 $5500\sim 5000\,\mathrm{cm}^{-1}$。优点是坚固、寿命长、稳定性好、结构简单、点燃容易，缺点是必须用变压器调压后才能使用。

:::definition{label="能斯特灯"}
$\mathrm{ZrO_2}$、$\mathrm{ThO_2}$、$\mathrm{Y_2O_3}$ 等混合物烧结。工作温度约 $1800^{\circ}\mathrm{C}$，最大发射波数 $7100\,\mathrm{cm}^{-1}$。同温度下发光强度约为硅碳棒的两倍；性脆、价贵。
:::

:::definition{label="硅碳棒"}
碳化硅实心棒。工作温度 $1200\sim 1500^{\circ}\mathrm{C}$，最大发射波数 $5500\sim 5000\,\mathrm{cm}^{-1}$。坚固、易点燃，须变压器调压。
:::

:::compare{title="中红外常用光源"}
| 光源 | 材料 | 工作温度 | 最大发射波数 | 要点 |
|------|------|----------|--------------|------|
| 能斯特灯 | $\mathrm{ZrO_2}$、$\mathrm{ThO_2}$、$\mathrm{Y_2O_3}$ 等 | 约 $1800^{\circ}\mathrm{C}$ | $7100\,\mathrm{cm}^{-1}$ | 更亮、脆、贵 |
| 硅碳棒 | SiC | $1200\sim 1500^{\circ}\mathrm{C}$ | $5500\sim 5000\,\mathrm{cm}^{-1}$ | 坚固，要调压 |
:::

### （二）检测器

光栅红外分光光度计常用的检测器是真空热电偶。

:::definition{label="真空热电偶"}
光栅红外分光光度计常用检测器。FTIR 全称扫描约 $1\,\mathrm{s}$，真空热电偶响应时间不能满足要求，故 FTIR 改用热电型或光电导型检测器。
:::

## 二、傅里叶变换红外光谱仪

### （一）主要部件

傅里叶变换红外光谱仪主要由光源、干涉仪、样品池、检测器、计算机和数据记录系统组成，示意如下：

光源 $\rightarrow$ 干涉仪 $\rightarrow$ 样品池 $\rightarrow$ 检测器 $\rightarrow$ 计算机（傅里叶变换）$\rightarrow$ 数据记录系统

**（1）光源**　较常用的是改进型的硅碳棒（EVER-GLO）光源及空气冷却陶瓷光源。EVER-GLO 光源发射波长范围为 $9600\sim 20\,\mathrm{cm}^{-1}$，覆盖中红外及部分近红外区。空气冷却陶瓷光源发射波长范围为 $9600\sim 50\,\mathrm{cm}^{-1}$。

:::definition{label="FTIR 光源"}
常用改进型硅碳棒（EVER-GLO）$9600\sim 20\,\mathrm{cm}^{-1}$，覆盖中红外及部分近红外；空气冷却陶瓷光源 $9600\sim 50\,\mathrm{cm}^{-1}$。
:::

**（2）干涉仪**　FTIR 用迈克耳孙（Michelson）干涉仪代替了红外分光光度计中的色散元件，工作原理示意图如图6-29 所示。当干涉光透过样品（或被样品反射）时，干涉光中某些波长的光可被样品吸收，使得干涉图发生变化。干涉图信号经检测器转变成电信号，在计算机内经傅里叶变换后即得红外光谱图。

迈克耳孙干涉仪由固定镜（$\mathrm{M_1}$）、动镜（$\mathrm{M_2}$）及光束分裂器（BS）组成（图6-29）。$\mathrm{M_2}$ 可沿图示方向移动，故称为动镜。在 $\mathrm{M_1}$ 与 $\mathrm{M_2}$ 间放置呈 $45^{\circ}$ 的半透膜光束分裂器 BS。BS 可使 $50\%$ 的入射光透过，其余 $50\%$ 反射。当由光源 S 发出的光进入干涉仪后，被分裂为透射光 I 与反射光 II。I、II 两束光分别被 $\mathrm{M_2}$ 与 $\mathrm{M_1}$ 反射后于 BS 形成相干光。当 $\mathrm{M_2}$ 移动，可改变两束光的光程差。当光程差是波长整数倍时，为相长干涉，亮度最大（亮条）；当光程差是半波长的奇数倍时，为相消干涉，亮度最小（暗条）。因此，当 $\mathrm{M_2}$ 匀速往复移动时，连续改变两束的光程差，得到干涉图。

:::definition{label="迈克耳孙干涉仪"}
固定镜 $\mathrm{M_1}$、动镜 $\mathrm{M_2}$、呈 $45^{\circ}$ 的半透膜光束分裂器 BS（透射 $50\%$、反射 $50\%$）。动镜匀速移动改变光程差，得到干涉图。光程差为波长整数倍时相长（亮），为半波长奇数倍时相消（暗）。
:::

:::derivation{title="干涉图怎样变成光谱"}
光源 → 干涉仪得到干涉图 → 干涉光过样品（某些波长被吸收，干涉图改变）→ 检测器变成电信号 → 计算机做傅里叶变换 → 以波数为横轴的红外光谱图。光栅仪是“先分光再测强度”；FTIR 是“先测干涉再还原光谱”。
:::

**（3）样品池**　常用液体池与气体池，分别用于液体样品与气体样品。为了使红外光能透过，样品池都具有岩盐窗片。常用岩盐窗片的透过限度为 $\mathrm{KBr}\,28\,\mathrm{\mu m}$，$\mathrm{CsI}\,56\,\mathrm{\mu m}$。样品池不用时需在干燥器中保存。固体样品常与 $\mathrm{KBr}$ 混匀压片，直接测定。

:::definition{label="岩盐窗片透过限度"}
$\mathrm{KBr}$ 窗片 $28\,\mathrm{\mu m}$，$\mathrm{CsI}$ 窗片 $56\,\mathrm{\mu m}$。不用时放干燥器。固体常用 $\mathrm{KBr}$ 压片直接测定。
:::

**（4）检测器**　由于 FTIR 的全程扫描小于 $1\,\mathrm{s}$，而真空热电偶的响应时间不能满足要求。因此，常用热电型检测器（如氘代硫酸三甘肽检测器）或光电导型检测器（如汞镉碲检测器）。这两类检测器的响应约为 $1\,\mathrm{\mu s}$。

:::definition{label="DTGS"}
氘代硫酸三甘肽（deuterated triglycine sulfate detector，DTGS）检测器是将氘代硫酸三甘肽晶体切割成几十微米厚的薄片，在薄片两侧引出 2 个电极，通至检测器的前置放大器。DTGS 晶体在红外干涉光的照射下，产生微弱电信号，经放大、傅里叶变换而产生红外光谱。
:::

:::definition{label="MCT"}
汞镉碲（mercury cadmium tellurium，MCT）检测器由宽频带的半导体碲化镉与半金属碲化汞按一定比例混合而成。改变比例可获得不同检测范围及检测灵敏度的 MCT（A、B 及 C 型）检测器。MCT 检测范围比 DTGS 窄，但灵敏度是 DTGS 的十几倍。
:::

:::compare{title="光栅仪与 FTIR 的检测器"}
| | 光栅红外分光光度计 | FTIR |
|--|----------------------|------|
| 常用检测器 | 真空热电偶 | DTGS（热电型）或 MCT（光电导型） |
| 响应 | 跟不上 FTIR 全扫描 | 约 $1\,\mathrm{\mu s}$ |
| 灵敏度比较 | — | MCT 范围较窄，灵敏度约为 DTGS 的十几倍 |
:::

### （二）工作原理

FTIR 工作原理示意图如图6-30 所示。

::figure{src="/images/instrumental-analysis/textbook/p0154_01.jpg" caption="图6-30　FTIR 工作原理示意图。R—红外光源；M1—定镜；M2—动镜；BS—光束分裂器；S—样品；D—检测器；A—放大器；F—滤光器；A/D—模数转换器；D/A—数模转换器。" alt="FTIR 框图：干涉仪到样品、检测器、A/D、计算机、键盘与光谱输出"}

由光源发射出红外光经准直系统变为束平行光束后进入干涉仪系统，经干涉仪调制得到一束干涉光，干涉光通过样品后成为带有样品信息的干涉光到达检测器，检测器将干涉光信号变为电信号，但这种带有光谱信息的干涉信号难以进行光谱解析。将它通过模数转换器（A/D）送入计算机，由计算机进行傅里叶变换的快速计算，将这一干涉信号所带有的光谱信息转换成以波数为横坐标的红外光谱图。

:::definition{label="FTIR 光路一句话"}
平行红外光 → 干涉仪调制 → 过样品 → 检测器成电信号 → A/D → 计算机傅里叶变换 → $T$（或 $A$）–$\sigma$ 光谱。
:::

FTIR 具有分辨率高、波数范围宽、扫描时间快、灵敏度高（$10^{-9}\,\mathrm{g}$）等优点，也是实现色谱–光谱联用较理想的仪器，已有 GC–FTIR 及 HPLC–FTIR 等联用的仪器商品。

:::keypoint{label="FTIR 相对光栅仪的优点"}
- 分辨率高、波数范围宽。
- 扫描快：本节开头写一次全程扫描小于 $0.1\,\mathrm{s}$；检测器段写全程扫描小于 $1\,\mathrm{s}$（相对热电偶）。
- 灵敏度高，可达 $10^{-9}\,\mathrm{g}$。
- 适于 GC–FTIR、HPLC–FTIR。
:::

## 三、仪器性能

红外光谱仪的性能指标有分辨率、波数准确度与重复性、透光率或吸光度的准确度与重复性、$I_0$（$100\%$）线的平直度、检测器的满度量程输出、狭缝线性及杂散光等项，其中前两项为仪器的最主要指标。这些指标关系到光谱图中的峰位、峰强及峰形的准确描述，直接影响到光谱解析与结构确认的正确性。

:::definition{label="最主要的两项性能"}
分辨率；波数准确度与重复性。它们直接关系峰位、峰强、峰形，从而关系解析可靠性。
:::

### （一）分辨率

红外光谱仪的分辨率多采用在某波数处恰能分开两个吸收峰的相对波数差为指标（$\Delta\sigma/\sigma$）。通常也可采用一些简便的方法：

① 用测定某一样品在某一波数区间所能分辨出的峰数表示；

② 用一定波数处相邻峰的分离深度表示。

FTIR 仪器的分辨率可达到 $0.5\sim 0.2\,\mathrm{cm}^{-1}$。

《中国药典》（2015 年版）规定，红外光谱仪用聚苯乙烯薄膜校正仪器，要求在 $3110\sim 2850\,\mathrm{cm}^{-1}$ 应能清晰地分辨出 7 个峰（5 个不饱和碳氢伸缩峰、2 个饱和碳氢伸缩振动峰）；峰 $2851\,\mathrm{cm}^{-1}$ 与谷 $2870\,\mathrm{cm}^{-1}$ 之间的分辨深度不小于 $18\%$ 透光率；峰 $1583\,\mathrm{cm}^{-1}$ 与谷 $1589\,\mathrm{cm}^{-1}$ 之间的分辨深度不小于 $12\%$ 透光率，仪器的分辨能力除另有规定外，应不低于 $2\,\mathrm{cm}^{-1}$。

:::definition{label="药典 2015 分辨率（聚苯乙烯薄膜）"}
$3110\sim 2850\,\mathrm{cm}^{-1}$ 清晰分辨 7 个峰；峰 $2851$ 与谷 $2870$ 分辨深度 $\geqslant 18\%\,T$；峰 $1583$ 与谷 $1589$ 分辨深度 $\geqslant 12\%\,T$。除另有规定外，分辨能力应不低于 $2\,\mathrm{cm}^{-1}$。FTIR 可达 $0.5\sim 0.2\,\mathrm{cm}^{-1}$。
:::

:::note{label="图6-1（b）的 >18% 与 >12%"}
第1节苯的 $T$–$\sigma$ 图上标了 $>18\%$、$>12\%$，与这里聚苯乙烯校正的分辨深度同一类读法：看峰–谷的透光率差，不是看峰位本身。
:::

### （二）波数准确度与重复性

仪器测定所得波数值与文献值（标准值）比较之差称为波数准确度，多次（$3\sim 5$ 次）重复测量同一样品，所得同一吸收峰波数的最大值与最小值之差称为波数重复性。

《中国药典》（2015 年版）规定：可使用傅里叶变换红外光谱仪或色散型红外光谱仪。用聚苯乙烯薄膜（厚度约为 $0.04\,\mathrm{mm}$）校正仪器，绘制得到聚苯乙烯薄膜的红外吸收光谱，用波数 $3027\,\mathrm{cm}^{-1}$、$2851\,\mathrm{cm}^{-1}$、$1601\,\mathrm{cm}^{-1}$、$1028\,\mathrm{cm}^{-1}$ 及 $907\,\mathrm{cm}^{-1}$ 处的吸收峰对仪器的波数进行校正。傅里叶变换红外光谱仪在 $3000\,\mathrm{cm}^{-1}$ 附近的波数误差应不大于 $\pm 5\,\mathrm{cm}^{-1}$，在 $1000\,\mathrm{cm}^{-1}$ 附近的波数误差应不大于 $\pm 1\,\mathrm{cm}^{-1}$。聚苯乙烯薄膜用于波数校正的吸收峰的波数见表6-7。

:::definition{label="波数准确度与重复性"}
准确度：测得波数与文献（标准）值之差。重复性：同一样品 $3\sim 5$ 次测量，同一峰最大值与最小值之差。
:::

:::definition{label="药典 2015 波数校正"}
聚苯乙烯薄膜约 $0.04\,\mathrm{mm}$。用 $3027$、$2851$、$1601$、$1028$、$907\,\mathrm{cm}^{-1}$ 校正。FTIR：$3000\,\mathrm{cm}^{-1}$ 附近误差 $\leqslant\pm 5\,\mathrm{cm}^{-1}$，$1000\,\mathrm{cm}^{-1}$ 附近 $\leqslant\pm 1\,\mathrm{cm}^{-1}$。
:::

## 四、制样

红外吸收光谱分析对样品的主要要求：

（1）样品的纯度需大于 $98\%$，以便与 Sadtler 纯化合物光谱对照（该纯化合物光谱由纯度大于 $98\%$ 的样品测得）。若为商业规格的样品，如药典规格等，所测得的光谱需与商业光谱对照。

（2）样品应不含水分，否则不仅干扰样品中羟基峰的观察，而且影响高波数区吸收峰的判定。样品更不得是水溶液，若制成溶液，需用符合所测光谱波段要求的溶剂配制。

气态、液态或固态样品皆可测定其红外光谱，但以固态样品最方便。

:::definition{label="样品两项要求"}
纯度 $>98\%$，以便对照 Sadtler 纯化合物光谱（也由 $>98\%$ 样品测得）；商业规格对照商业光谱。必须无水：水干扰羟基峰和高波数区；不得是水溶液。
:::

:::pitfall{label="水不是“多一根 OH 那么简单”"}
水既干扰羟基观察，也搅高波数区。样品更不得直接拿水溶液上中红外。溶液法必须选测定波段无强吸收、且不污染样品的溶剂。
:::

### （一）固态样品

**（1）压片法**　压片法是测定固体样品应用最广的一种方法。取样品 $1\sim 2\,\mathrm{mg}$ 和 $200$ 目光谱纯、干燥的 $\mathrm{KBr}$ 粉末共 $200\,\mathrm{mg}$，在玛瑙乳钵中研匀（在红外灯下操作），装入压片模具，加压制得厚约 $1\,\mathrm{mm}$ 的透明 $\mathrm{KBr}$ 样品片。将样品片装入样品池，即可测定。

:::definition{label="KBr 压片法"}
样品 $1\sim 2\,\mathrm{mg}$ 加 $200$ 目光谱纯干燥 $\mathrm{KBr}$ 共 $200\,\mathrm{mg}$，玛瑙乳钵研匀（红外灯下），压成约 $1\,\mathrm{mm}$ 厚透明片。固体样品应用最广。
:::

**（2）糊糊法**　将固体样品研细后分散在与其折射率相接近的液体介质中研磨成均匀糊剂，取适量使试品糊剂夹于两块空白 $\mathrm{KBr}$ 片中，测定红外吸收光谱。常用的液体分散介质有液体石蜡、六氯丁二烯和卤化煤油等。

:::definition{label="糊糊法"}
研细固体分散在折射率相近的液体介质中成糊，夹于两块空白 $\mathrm{KBr}$ 片中测定。介质：液体石蜡、六氯丁二烯、卤化煤油等。
:::

**（3）薄膜法**　制备合适厚度（$0.01\sim 0.1\,\mathrm{mm}$）的薄膜的方法依样品的理化性质而定：低熔点的样品可在熔融后倾于平滑的表面上制膜；结晶性样品可在熔化后置于岩盐窗片上制膜；不溶于水的样品热熔后倾入水中，使其在水面上成膜；倾在汞面上成膜特别理想，取膜容易，也不会污染样品。因此，想要获取既没有溶剂影响，又没有分散介质影响的光谱最好是选择薄膜法。

:::definition{label="薄膜法"}
厚度 $0.01\sim 0.1\,\mathrm{mm}$。低熔点倾于平滑表面；结晶性样品熔化后置于岩盐窗片；不溶于水的热熔后水面成膜；汞面成膜取膜容易、不污染。要同时避开溶剂和分散介质，最好选薄膜法。
:::

### （二）液态样品

**（1）液体池法**　将样品溶解在适当溶剂中制成浓度为 $1\%\sim 10\%$ 的溶液，装入具有岩盐窗片的液体池中，测定样品的吸收光谱。必须选择在测定波段区间无强吸收的溶剂，否则用空白抵偿也不能完全抵消。常用的溶剂有 $\mathrm{CCl_4}$（$4000\sim 1350\,\mathrm{cm}^{-1}$）及 $\mathrm{CS_2}$（$1350\sim 600\,\mathrm{cm}^{-1}$），但 $\mathrm{CCl_4}$ 在 $1580\,\mathrm{cm}^{-1}$ 处稍有干扰。

:::definition{label="液体池法"}
浓度 $1\%\sim 10\%$ 溶液，岩盐窗片液体池。溶剂在测定波段无强吸收。常用 $\mathrm{CCl_4}$（$4000\sim 1350\,\mathrm{cm}^{-1}$）和 $\mathrm{CS_2}$（$1350\sim 600\,\mathrm{cm}^{-1}$）；$\mathrm{CCl_4}$ 在 $1580\,\mathrm{cm}^{-1}$ 稍有干扰。
:::

**（2）夹片法**　对于挥发性不大的液体样品可采用夹片法，即将液体样品滴在一片 $\mathrm{KBr}$ 窗片上，用另一片 $\mathrm{KBr}$ 窗片夹住后装入样品池测定，方法简便实用。

:::definition{label="夹片法"}
挥发性不大的液体：滴在一片 $\mathrm{KBr}$ 窗片上，另一片夹住，装入样品池。简便实用。
:::

:::compare{title="制样怎么选"}
| 样品 | 方法 | 本版要点 |
|------|------|----------|
| 固体（最常用） | KBr 压片 | $1\sim 2\,\mathrm{mg}$ 样品 $+200\,\mathrm{mg}$ $\mathrm{KBr}$，片厚约 $1\,\mathrm{mm}$ |
| 固体 | 糊糊法 | 液体石蜡、六氯丁二烯、卤化煤油 |
| 固体 | 薄膜法 | $0.01\sim 0.1\,\mathrm{mm}$；要避开溶剂和分散介质时首选 |
| 液体 | 液体池 | $1\%\sim 10\%$；$\mathrm{CCl_4}$／$\mathrm{CS_2}$ 分段 |
| 液体（挥发性不大） | 夹片法 | 两片 $\mathrm{KBr}$ 夹一滴 |
:::

:::memory{label="光栅样品在前，FTIR 走干涉，压片 1～2 mg"}
问法：红外仪器和紫外差在哪？FTIR 凭什么快？固体怎么制样？
答：光栅红外样品在光源与单色器之间；色散用光栅，棱镜已淘汰。FTIR 用迈克耳孙干涉仪，一次全程扫描小于 $0.1\,\mathrm{s}$，灵敏度可达 $10^{-9}\,\mathrm{g}$。能斯特灯约 $1800^{\circ}\mathrm{C}$、$7100\,\mathrm{cm}^{-1}$；硅碳棒 $1200\sim 1500^{\circ}\mathrm{C}$、$5500\sim 5000\,\mathrm{cm}^{-1}$。固体最常用 KBr 压片：$1\sim 2\,\mathrm{mg}$ 样品、$200\,\mathrm{mg}$ $\mathrm{KBr}$、约 $1\,\mathrm{mm}$ 厚。药典 2015 用 $0.04\,\mathrm{mm}$ 聚苯乙烯薄膜校分辨率和波数。
:::
