# 第3节　拉曼光谱法

前两节分别是元素的质谱和晶体的衍射。本节把户头换成分子振动的散射：拉曼光谱建立在拉曼散射效应上，和红外都研究分子振动，但一个看极化率、一个看偶极矩，彼此补充。第 3 章已经把拉曼划进光谱法、把瑞利写成弹性散射；本节按本版写产生过程、$\mathrm{CCl_4}$ 谱图、与红外对照、五块仪器和药学应用。不要扩写成表面增强拉曼专著，也不要吞第 10 章。章末基本要求和思考题收在这里。

拉曼光谱（Raman spectroscopy）是建立在拉曼散射效应基础上的光谱分析方法。拉曼散射由印度物理学家拉曼（C. V. Raman）于 1928 年研究苯的光散射时首先发现，为此，他获得了诺贝尔奖。但由于拉曼效应较弱及当时的技术限制，使得拉曼光谱法的发展受到严重影响。直到 20 世纪 60 年代，激光问世并引入到拉曼光谱仪作为光源后，拉曼光谱法才迅速发展起来，成为分子光谱学的一个重要分支。

:::definition{label="拉曼光谱"}
拉曼光谱（Raman spectroscopy）是建立在拉曼散射效应基础上的光谱分析方法。
:::

:::timeline{period="拉曼光谱从发现到激光光源"}
- **1928 年** 印度物理学家拉曼（C. V. Raman）研究苯的光散射时首先发现拉曼散射
- **此后** 拉曼因此获得诺贝尔奖；效应弱、技术限制，方法发展受严重影响
- **20 世纪 60 年代** 激光问世并引入拉曼光谱仪作光源，方法迅速发展，成为分子光谱学的重要分支
:::

:::concept{term="先问碰撞有没有交换能量，再问位移还是波长"}
看见拉曼，先不要跳到 $\mathrm{He}$-$\mathrm{Ne}$ 的 $632.8\,\mathrm{nm}$。户头是：单色光打到透明样品，大部分透射，小部分散射；弹性碰撞是瑞利，非弹性碰撞是拉曼。拉曼位移只跟分子振动、转动能级有关，跟换哪根激光无关。把拉曼听成红外吸收的另一种画法，后面活性条件和 $\mathrm{CCl_4}$ 对称峰都会对错户头。
:::

:::insight{label="第 3 章已经立过户，本节展开仪器和与红外对照"}
第 3 章：拉曼是光谱法（有振动能级变化），瑞利是弹性、波长不变。第 3 章 60 年代进展写过激光拉曼。本节补：受激虚态、斯托克斯／反斯托克斯、位移不变、红外互补、五块仪器。
:::

:::pitfall{label="不要把拉曼效应弱写成「所以不用学」"}
教材明确：效应弱曾严重限制发展，激光光源之后才成为重要分支。简介仍要求熟悉散射的产生、拉曼与红外的关系；仪器结构放在了解。
:::

## 一、基本原理

### （一）拉曼散射的产生

当用单色光照射透明样品时，大部分光会按原来方向透过，而一小部分则按不同的角度散射开来，产生散射光。这些光的散射又分为瑞利散射和拉曼散射两种。若光子和样品分子发生弹性碰撞，即光子和分子之间没有能量交换，光子仅改变其运动方向而不改变其频率，这种散射称为瑞利散射。在非弹性碰撞过程中，光子与分子间存在着能量交换，光子不仅改变了运动方向，同时还可能把一部分能量传递给分子或从分子中得到一定的能量，使散射光的频率不同于入射光的频率，这种散射称为拉曼散射。它对称地分布于瑞利散射的两侧，光子失去能量的过程频率比瑞利散射的低，称为斯托克斯（Stokes）线，而光子得到能量的过程频率比瑞利散射的高，称为反斯托克斯（anti-Stokes）线。斯托克斯线或反斯托克斯线与入射光之间的频率差为拉曼位移（$\Delta\nu$）。

:::definition{label="散射光从哪来"}
单色光照射透明样品：大部分按原来方向透过，一小部分按不同角度散射。
:::

:::definition{label="瑞利散射"}
光子与样品分子弹性碰撞：没有能量交换，光子只改变运动方向、不改变频率。
:::

:::definition{label="拉曼散射"}
光子与分子非弹性碰撞：有能量交换。光子改变运动方向，并把一部分能量传给分子或从分子得到能量，散射光频率不同于入射光。
:::

:::definition{label="斯托克斯线"}
光子失去能量，频率比瑞利散射低。对称地分布在瑞利线一侧。
:::

:::definition{label="反斯托克斯线"}
光子得到能量，频率比瑞利散射高。对称地分布在瑞利线另一侧。
:::

:::definition{label="拉曼位移"}
斯托克斯线或反斯托克斯线与入射光之间的频率差，记为 $\Delta\nu$。
:::

:::compare{title="瑞利、斯托克斯、反斯托克斯"}
| 名称 | 碰撞 | 能量 | 频率相对瑞利 |
|------|------|------|----------------|
| 瑞利散射 | 弹性 | 不交换 | 相同 |
| 斯托克斯线 | 非弹性 | 光子失去能量 | 更低 |
| 反斯托克斯线 | 非弹性 | 光子得到能量 | 更高 |
:::

图 9-5 说明了拉曼散射和瑞利散射产生的过程。图中 $E_0$ 为基态振动能级，$E_1$ 为激发态振动能级。当样品分子处于 $E_0$ 或 $E_1$ 的状态下，受能量为 $h\nu_0$ 的入射光子的激发。若入射光子的能量大于振动能级跃迁所需要的能量，但又不足以将分子激发到电子能级激发态，样品分子在吸收了光子后，被激发到 $E_0+h\nu_0$ 或 $E_1+h\nu_0$ 的受激虚态。受激虚态是不稳定的，分子将很快返回到原 $E_0$ 或原 $E_1$ 能态，并将吸收的能量以光子形式释放出来，散射光子的能量仍然为 $h\nu_0$，这就是瑞利散射。如果从 $E_0$ 跃迁到受激虚态的分子不返回至基态 $E_0$，而返回至振动激发态 $E_1$ 能级，即分子保留了一部分能量，此时散射光子的能量为 $h(\nu_0-\Delta\nu)$，$h\Delta\nu$ 为相邻两个振动能级的能量差。此时在瑞利散射线较低频率侧就会出现一根拉曼散射线，这条线即为斯托克斯线。若光子与处于 $E_1$ 态的分子相互作用，使分子激发到更高的受激虚态后又回到 $E_0$，则散射光的能量为 $h(\nu_0+\Delta\nu)$，在瑞利散射线高频率侧会出现一拉曼散射线反斯托克斯线。由于常温下分子大多处于振动基态，所以斯托克斯线比反斯托克斯线强得多。

:::definition{label="受激虚态"}
入射光子能量大于振动跃迁所需，又不足以把分子激发到电子能级激发态。分子被激发到 $E_0+h\nu_0$ 或 $E_1+h\nu_0$，该态不稳定，称为受激虚态。
:::

:::definition{label="瑞利：回到原来那一级"}
从受激虚态很快返回原 $E_0$ 或原 $E_1$，放出光子能量仍为 $h\nu_0$。
:::

:::definition{label="斯托克斯：从 E0 出发，落到 E1"}
$E_0$ → 受激虚态 → $E_1$，分子保留 $h\Delta\nu$，散射光子 $h(\nu_0-\Delta\nu)$，出现在瑞利线低频侧。
:::

:::definition{label="反斯托克斯：从 E1 出发，落到 E0"}
$E_1$ → 更高受激虚态 → $E_0$，散射光子 $h(\nu_0+\Delta\nu)$，出现在瑞利线高频侧。
:::

:::theorem{label="常温下斯托克斯线强得多"}
常温下分子大多处于振动基态 $E_0$，从 $E_1$ 出发的反斯托克斯过程少得多，所以斯托克斯线比反斯托克斯线强得多。
:::

:::pitfall{label="受激虚态不是电子激发态，也不是红外的振动激发"}
虚态能量是 $E_0+h\nu_0$，激光光子本身通常远高于红外振动量子、又够不到电子激发。把拉曼画成「先吸收红外再发射」，就和红外光谱并户了。把虚态画成第 5 章的 $\mathrm{S}_1$，又和荧光并户。
:::

:::pitfall{label="不要把斯托克斯位移和荧光的斯托克斯位移并成一句"}
本节斯托克斯线：散射频率低于入射光。第 5 章斯托克斯位移：荧光波长总大于激发光波长。名字同源，户头不同。思考题问「为何斯托克斯线更强」，答的是常温分子多在 $E_0$，不是答荧光量子产率。
:::

### （二）拉曼散射光谱图

图 9-6 是用波长为 $488.0\,\mathrm{nm}$ 的氩离子激发光源时液体 $\mathrm{CCl_4}$ 的拉曼光谱图，横坐标是以波数为单位的拉曼位移 $\Delta\nu$，纵坐标是强度。同一物质分子，随着入射光频率的改变，拉曼线的频率也改变，但拉曼位移始终保持不变。拉曼位移与入射光频率无关，仅与分子的振动能级和转动能级有关。不同的物质分子具有不同的振动和转动能级，因而具有不同的拉曼位移。利用拉曼光谱可对物质分子进行结构分析和定性鉴别。

:::definition{label="拉曼光谱图的两根轴"}
横坐标：拉曼位移 $\Delta\nu$（波数）。纵坐标：强度。图 9-6 用 $488.0\,\mathrm{nm}$ 氩离子激光测液体 $\mathrm{CCl_4}$。
:::

:::definition{label="拉曼位移与入射光频率无关"}
换入射光频率，拉曼线的绝对频率跟着变，位移 $\Delta\nu$ 不变。位移只由分子振动、转动能级决定。
:::

:::definition{label="拉曼怎样定性"}
不同分子有不同振动、转动能级，因而有不同拉曼位移。可做结构分析和定性鉴别。
:::

:::insight{label="所以谱图横轴用位移，不用激光波长"}
图 9-6 在瑞利峰处标 $\tilde{\nu}_0=20\,492\,\mathrm{cm}^{-1}$、$\lambda_0=488.0\,\mathrm{nm}$，两侧峰用 $\Delta\tilde{\nu}$。斯托克斯一侧约 $-218$、$-314$、$-459\,\mathrm{cm}^{-1}$，反斯托克斯一侧约 $218$、$314$、$459\,\mathrm{cm}^{-1}$，对称。换一根激光，这组位移还在。
:::

:::pitfall{label="不要把横轴读成紫外–可见的 nm"}
拉曼图的定性钥匙是 $\Delta\nu$（$\mathrm{cm}^{-1}$），和红外波数同一类单位，不是 $488.0\,\mathrm{nm}$ 那根激发线。把峰位报成「488 nm 附近」，$\mathrm{CCl_4}$ 三对对称峰就对不上。
:::

### （三）拉曼光谱与红外光谱的关系

从产生光谱的机理来看，拉曼光谱和红外光谱有本质区别，拉曼是分子对激发光的散射引起的，而红外光谱则是由分子对红外光的吸收而产生的。但两者都属于分子光谱，都是用来研究分子振动的重要手段，但是拉曼活性（即产生拉曼吸收）和红外活性（即产生红外吸收）是不同的。通常，分子的非对称性振动和极性基团的振动，都会引起分子偶极矩的变化，具有红外活性。而分子的对称性振动和非极性基团的振动，会引起分子极化率的变化，具有拉曼活性。因此，拉曼光谱适合于研究由相同原子组成的非极性键的振动和对称分子的骨架振动，如 $\mathrm{C-C}$、$\mathrm{N-N}$、$\mathrm{S-S}$ 等键的振动以及 $\mathrm{CS_2}$ 的骨架振动。而不同原子的极性键，如 $\mathrm{N-H}$、$\mathrm{C-H}$、$\mathrm{O-H}$ 等，则在红外光谱上有反映。若分子在振动中既有偶极矩变化又有极化率变化，则在红外和拉曼光谱中同时出现谱带。

:::definition{label="机理不同，都研究振动"}
拉曼：分子对激发光的散射。红外：分子对红外光的吸收。同属分子光谱，都是研究分子振动的重要手段。
:::

:::definition{label="红外活性"}
非对称性振动和极性基团的振动引起偶极矩变化，具有红外活性（产生红外吸收）。
:::

:::definition{label="拉曼活性"}
对称性振动和非极性基团的振动引起极化率变化，具有拉曼活性（教材也称「产生拉曼吸收」）。
:::

:::compare{title="红外活性对拉曼活性"}
| 项目 | 红外 | 拉曼 |
|------|------|------|
| 机理 | 吸收红外光 | 散射激发光 |
| 判据 | 偶极矩变化 $\Delta\mu\neq 0$ | 极化率变化 |
| 典型振动 | 非对称；极性基团 | 对称；非极性基团 |
| 适合看的键 | $\mathrm{N-H}$、$\mathrm{C-H}$、$\mathrm{O-H}$ 等极性键 | $\mathrm{C-C}$、$\mathrm{N-N}$、$\mathrm{S-S}$；$\mathrm{CS_2}$ 骨架 |
| 两者都出现 | 振动中既有偶极矩变化又有极化率变化 | 同左 |
:::

:::pitfall{label="教材说「拉曼吸收」不是改户头为吸收光谱"}
括号里的「产生拉曼吸收」是活性的说法，机理句已经写明是散射。第 6 章红外活性是 $\Delta\mu\neq 0$；本节拉曼活性是极化率。不要因为「吸收」二字把拉曼并进红外。
:::

:::memory{label="极性看红外，非极性骨架看拉曼"}
问法：$\mathrm{O-H}$ 和 $\mathrm{C-C}$ 各上哪张图？
答：$\mathrm{N-H}$、$\mathrm{C-H}$、$\mathrm{O-H}$ 极性键 → 红外。$\mathrm{C-C}$、$\mathrm{N-N}$、$\mathrm{S-S}$、$\mathrm{CS_2}$ 骨架 → 拉曼。既变偶极矩又变化极化率 → 两张图都有带。
:::

图 9-7 是 1,4-二氧杂环己烷的红外光谱及拉曼光谱。从图中可以看到，同一物质，它们的红外光谱和拉曼光谱有很多相似之处，有些峰的红外吸收与拉曼散射完全对应，但也有些峰有拉曼散射却无红外吸收，或有红外吸收却无拉曼散射。1,4-二氧杂环己烷在 $1220\,\mathrm{cm}^{-1}$ 处有一较强的拉曼散射信号，但没有红外吸收信号，该信号是由 $\mathrm{C-O-C}$ 的对称伸缩振动引起的。反之在 $620\,\mathrm{cm}^{-1}$ 处只有红外吸收信号却没有拉曼信号，这是由 $\mathrm{C-O-C}$ 的不对称伸缩振动引起的。可见，拉曼光谱和红外光谱是相互补充的。

:::definition{label="1,4-二氧杂环己烷的两处对照"}
$1220\,\mathrm{cm}^{-1}$：强拉曼、无红外，$\mathrm{C-O-C}$ 对称伸缩。$620\,\mathrm{cm}^{-1}$：只有红外、无拉曼，$\mathrm{C-O-C}$ 不对称伸缩。同一物质两张图既有对应峰，也有互缺峰。
:::

:::insight{label="互补不是「两张图长得一样」"}
相似、有些峰完全对应，是因为都在报振动。互缺的两处才把活性分户写死：对称伸缩走拉曼，不对称伸缩走红外。把互补听成可以互相替代，药典鉴别会只做一张图。
:::

:::pitfall{label="环己烷不要写成环已烷"}
化合物是 1,4-二氧杂环己烷。扫描稿常把「己」认成「已」。峰位 $1220$、$620\,\mathrm{cm}^{-1}$ 以印刷为准。
:::

:::

激光光源多用连续式气体激光器，如波长为 $632.8\,\mathrm{nm}$ 的 $\mathrm{He}$-$\mathrm{Ne}$ 激光器和波长为 $488.0\,\mathrm{nm}$ 和 $514.5\,\mathrm{nm}$ 的氩离子激光器。样品池常用的有液体池、气体池、压片样品架和微量毛细管等。当激光器发出的激光经反光镜照射到样品时，通常在与入射激光垂直的方向收集散射光。单色器是拉曼光谱仪的心脏，要求最大限度地减小杂散光的干扰且色散性能好，目前常采用双单色器甚至是三单色器来提高分辨率。拉曼光谱仪最常用的检测器是光电倍增管，其光谱响应范围宽，量子效率高。

:::definition{label="两种气体激光器"}
连续式气体激光器。$\mathrm{He}$-$\mathrm{Ne}$：$632.8\,\mathrm{nm}$。氩离子：$488.0\,\mathrm{nm}$ 和 $514.5\,\mathrm{nm}$。图 9-6 用的就是 $488.0\,\mathrm{nm}$ 氩离子线。
:::

:::definition{label="样品池"}
液体池、气体池、压片样品架、微量毛细管等。
:::

:::definition{label="垂直收集散射光"}
激光经反光镜照射样品，通常在与入射激光垂直的方向收集散射光。
:::

:::definition{label="单色器是心脏"}
要求最大限度减小杂散光干扰，且色散性能好。常采用双单色器甚至三单色器提高分辨率。
:::

:::definition{label="检测器"}
最常用光电倍增管：光谱响应范围宽，量子效率高。
:::

:::compare{title="拉曼光路对荧光、对红外"}
| 项目 | 拉曼 | 第 5 章荧光 | 第 6 章红外 |
|------|------|-------------|-------------|
| 光源 | 激光（线光源） | 氙灯等 | 红外连续光源 |
| 取光 | 与入射激光垂直 | 与激发光 $90^{\circ}$ | 透射方向 |
| 单色器 | 双／三单色器，压杂散光 | 激发＋发射两台 | 光栅或干涉仪 |
| 检测 | 光电倍增管 | 光电管／光电倍增管 | 红外检测器 |
:::

:::pitfall{label="垂直取光不要写成沿激光透射方向"}
瑞利光比拉曼强得多，沿原方向透过的是大部分光。在垂直方向收集，是为了看散射。把光路画成紫外吸收的直线，单色器再好也压不住瑞利。
:::

:::insight{label="双单色器是因为拉曼弱、瑞利强"}
效应弱是历史限制的原因之一。心脏是单色器，不是激光器型号。简介到双／三单色器为止，不要展开每一级光栅的闪耀波长。
:::

除常规的拉曼光谱外，随着傅里叶变换技术和可调激光技术的发展，新的拉曼光谱法如傅里叶变换拉曼光谱、共振拉曼光谱、表面增强拉曼及非线性拉曼光谱等，已成为拉曼光谱研究中的活跃领域。

:::definition{label="常规之外的四种"}
傅里叶变换拉曼光谱、共振拉曼光谱、表面增强拉曼、非线性拉曼光谱。本版只点名为活跃领域。
:::

章题是简介。了解仪器结构和这串名字即可。不要把表面增强拉曼的基底种类、共振拉曼的电子能级条件扩进来顶替图 9-5 和与红外对照。

## 三、应用

拉曼光谱技术是一种非接触、无损的快速检测技术，目前已广泛用于矿物夹杂物、环境污染、催化剂的成分鉴别、文物的鉴定和修复、材料非均匀性、产品结构的在位和无损检测、法医学等方面。在药物分析中，拉曼光谱法可用于化学物质结构分析、晶型分析、中药材真伪鉴别和成分分析及药物剂型的快速鉴别等。近年来，拉曼技术已在美国、欧洲的数千家制药企业被广泛使用。目前，采用拉曼光谱技术快速检测原辅料的方法已被写入美国药典。在我国，《中国药典》（2010 年版）附录新增了拉曼光谱指导原则，为拉曼光谱用于原料药和制剂鉴别提供了可能。随着《药品生产质量管理规范（2010 年修订）》的执行，制药企业原辅料的检验由抽检过渡为逐批检验，必将使拉曼光谱技术得到更为广泛的应用。

:::definition{label="拉曼作为检测技术的特点"}
非接触、无损、快速。
:::

:::definition{label="一般应用领域"}
矿物夹杂物、环境污染、催化剂成分鉴别、文物鉴定和修复、材料非均匀性、产品结构的在位和无损检测、法医学。
:::

:::definition{label="药物分析中的用途"}
化学物质结构分析、晶型分析、中药材真伪鉴别和成分分析、药物剂型的快速鉴别。
:::

:::definition{label="药典与 GMP 落点"}
美国药典已写入拉曼快速检测原辅料。中国药典 2010 年版附录新增拉曼光谱指导原则，用于原料药和制剂鉴别。GMP（2010 年修订）使原辅料由抽检过渡为逐批检验。
:::

:::compare{title="本章三种方法在药学里不要并户"}
| 方法 | 药学主要问什么 | 本版年份 |
|------|----------------|----------|
| ICP-MS | 重金属／有害元素总量与砷汞形态 | 2010 总量；2015 形态 |
| XRD | 有效晶型 | 2015；那格列奈、阿立哌唑 |
| 拉曼 | 结构、晶型、中药材真伪、剂型、原辅料快速鉴别 | 2010 指导原则；美国药典原辅料 |
:::

:::insight{label="拉曼也能看晶型，但不替代 XRD 那一节"}
药物分析用途里写了晶型分析。XRD 仍是物相和晶体结构的主要方法。拉曼的长处是非接触、无损、快速，适合原辅料逐批。把晶型题全部改答拉曼，布拉格方程就没了；全部改答 XRD，药典指导原则那一笔就没了。

## 五、思考题

1. 简述 ICP-MS 的工作原理。
2. X 射线衍射法的主要用途是什么？
3. 为何斯托克斯线比反斯托克斯线强得多？

:::example{label="思考题如何对着教材答（不编造二维码全文）"}
**1. ICP-MS 的工作原理**　用感应耦合等离子体作离子源，样品以气体、蒸气或气溶胶进入（常用蠕动泵＋气动雾化器）。矩管三层石英：外管冷却气氩气，内管辅助气氩气，中间管样品气溶胶；射频线圈使氩气放电形成高能等离子体，气溶胶瞬间原子化并电离。接口把大气压下的离子引入真空质量分析器。离子经透镜聚焦，由四级杆按质荷比分离（分离原理见第 10 章），电子倍增管脉冲计数。质谱图横轴质荷比（定性），纵轴计数值（定量）。定性用短时间全谱扫描；半定量用低中高质量数混合标准得质量数–灵敏度曲线，相当于单点，误差较大；定量常用系列标准曲线，基体复杂时改内标标准曲线。

**2. XRD 的主要用途**　研究物相和晶体结构。图谱由组成、晶型、成键、构型、构象决定，可测结构、晶格畸变、晶粒大小、取向、织构、内应力、结晶度，以及固溶体、相变、电畴或磁畴。材料分析最常见的是物相分析：定性把待测图谱与单相标准图谱比较；定量按衍射线强度，经典方法是内标法。由 $\theta$ 测点阵常数；由峰形测晶粒尺寸和点阵畸变。药学：多晶型影响安全性和有效性时控制有效晶型，那格列奈、阿立哌唑用 XRD 鉴别。

**3. 为何斯托克斯线更强**　斯托克斯：分子从 $E_0$ 经受激虚态落到 $E_1$，光子 $h(\nu_0-\Delta\nu)$。反斯托克斯：必须从已经处于 $E_1$ 的分子出发，经更高虚态回到 $E_0$，光子 $h(\nu_0+\Delta\nu)$。常温下分子大多处于振动基态 $E_0$，能提供反斯托克斯过程的 $E_1$ 分子少得多，所以斯托克斯线比反斯托克斯线强得多。
:::
