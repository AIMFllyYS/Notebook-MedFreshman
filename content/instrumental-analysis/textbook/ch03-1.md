# 第1节　概述

第3章打开光学分析法。先把这门方法写成一句话：它建立在物质发射的电磁辐射，或电磁辐射与物质相互作用之上。本节只立户头：两个基础、光谱法与非光谱法的分界、本书主要写光谱法。波长、波数、频率和能量的计算放到第2节；原子光谱对分子光谱、吸收对发射对拉曼放到第3节；光源–单色器–样品池–检测器–读出器件放到第4节。不要把第4章紫外–可见的朗伯–比尔定律提前搬进来。

光学分析法（optical analysis）是建立在物质发射的电磁辐射（electromagnetic radiation）或电磁辐射与物质相互作用基础之上的各种分析方法的统称。它是现代分析化学的重要组成部分。光学分析法的基础包括两个方面：①能量作用于待测物质后产生光辐射，该能量形式可以是光辐射和其他辐射能量形式，也可以是声、电、磁或热等能量形式；②光辐射作用于待测物质后发生某种变化，这种变化可以是待测物质物理化学特性的改变，也可以是光辐射光学特性的改变。

:::definition{label="光学分析法"}
光学分析法（optical analysis）是建立在物质发射的电磁辐射（electromagnetic radiation）或电磁辐射与物质相互作用基础之上的各种分析方法的统称。它是现代分析化学的重要组成部分。
:::

:::definition{label="电磁辐射"}
电磁辐射（electromagnetic radiation）是光学分析法赖以建立的物理对象。本节先把它写成“物质可以发射它，它也可以与物质相互作用”；第2节再按波动性、粒子性、电磁波谱和相互作用展开。
:::

:::concept{term="先问能量是不是变成了光，或光是不是改变了物质／光本身"}
看见“光学分析”，先不要跳到比色皿和朗伯–比尔。教材把基础写成两本账：能量打到样品上，样品发出光；或者光打到样品上，样品或光发生了某种变化。两本账都在，后面光谱法、非光谱法才有户头。
:::

:::compare{title="光学分析法的两个基础"}
| 项目 | ①能量作用于待测物质后产生光辐射 | ②光辐射作用于待测物质后发生某种变化 |
|------|----------------------------------|----------------------------------------|
| 入射的是什么 | 光辐射、其他辐射，也可以是声、电、磁或热 | 光辐射 |
| 测的是什么 | 样品被激发后发出的光 | 样品物理化学特性的改变，或光辐射光学特性的改变 |
| 后面落到哪一类 | 发射光谱、荧光、磷光、化学发光等 | 吸收、散射、折射、衍射、偏振等 |
| 本节先记住 | 没有“出来的光”，光学分析没有信号 | 没有“光与物质的作用”，也没有信号 |
:::

:::insight{label="光学分析不是“只用可见光看颜色”"}
“光”在本章里是电磁辐射，覆盖无线电波、微波、红外、可见、紫外、X 射线、γ 射线。把光学分析听成“用眼睛看溶液颜色”，红外、核磁、X 射线荧光都会被开除出本章。
:::

:::pitfall{label="不要把两个基础并成“只有吸收”"}
①是样品发光，②是光打到样品上。吸收只是②里的一种。发射、荧光、拉曼、折射、衍射各有户头。本节若只记住“吸光”，第3节的发射光谱法和非光谱法会对不上。
:::

:::note{label="本节不展开朗伯–比尔定律"}
吸光度与浓度的定量关系是第4章紫外–可见分光光度法的专节。本章点到“辐射与物质相互作用”“吸收跃迁”为止，不要把 $A=\varepsilon bc$ 整节搬进来。
:::

## 一、光谱分析法与非光谱分析法

光学分析法可分为光谱分析法和非光谱分析法。分界钥匙只有一把：测量信号是否与物质内部量子化能级之间的跃迁有关。

:::definition{label="光谱分析法"}
光谱分析法（spectral analysis）是基于物质与辐射能作用时，测量由物质内部发生量子化的能级之间的跃迁而产生的发射、吸收或散射辐射的波长或强度进行分析的方法。
:::

:::keypoint{label="光谱法测什么"}
- 测的是发射、吸收或散射辐射的**波长或强度**。
- 这些辐射来自物质内部**量子化能级之间的跃迁**。
- 不仅可以提供物质的量的信息，还可以提供物质的结构信息。
:::

属于这类分析方法的有原子发射光谱法（AES）、原子吸收分光光度法（AAS）、原子荧光光谱法（AFS）、紫外–可见分光光度法（UV-Vis）、红外吸收光谱法（IR）、分子荧光光谱法（MFS）、分子磷光光谱法（MPS）等。

:::definition{label="原子发射光谱法 AES"}
原子发射光谱法（atomic emission spectrometry，AES）属于光谱分析法：气态原子外层电子被激发后发射紫外、可见辐射。本章只立户头，仪器与定量在后续原子光谱章展开。
:::

:::definition{label="原子吸收分光光度法 AAS"}
原子吸收分光光度法（atomic absorption spectrometry，AAS）属于光谱分析法：气态原子外层电子吸收紫外、可见辐射。药物分析中常用。
:::

:::definition{label="原子荧光光谱法 AFS"}
原子荧光光谱法（atomic fluorescence spectrometry，AFS）属于光谱分析法：高强度紫外、可见光激发气态原子，检测原子荧光。药物分析中常用。
:::

:::definition{label="紫外–可见分光光度法 UV-Vis"}
紫外–可见分光光度法（UV-Vis）属于光谱分析法：分子外层电子吸收紫外、可见辐射。第4章专章，本节不要把吸收定律提前写完。
:::

:::definition{label="红外吸收光谱法 IR"}
红外吸收光谱法（infrared absorption spectrometry，IR）属于光谱分析法：分子振动能级吸收中红外辐射。第6章专章。
:::

:::definition{label="分子荧光光谱法 MFS"}
分子荧光光谱法（molecular fluorescence spectrometry，MFS）属于光谱分析法：分子吸收紫外、可见辐射后发射荧光。第5章专章。
:::

:::definition{label="分子磷光光谱法 MPS"}
分子磷光光谱法（molecular phosphorescence spectrometry，MPS）属于光谱分析法：分子吸收辐射后发射磷光。与荧光同属分子发光，寿命和自旋态不同，细节留给后续分子发光章。
:::

:::compare{title="本节点名的光谱分析法（只立户头）"}
| 方法 | 教材缩写 | 粒子 | 测什么 | 本章后面 |
|------|----------|------|--------|----------|
| 原子发射光谱法 | AES | 气态原子 | 发射的紫外、可见 | 第3节发射光谱；第4节光源 |
| 原子吸收分光光度法 | AAS | 气态原子 | 吸收后的紫外、可见 | 第3节吸收光谱；药物分析常用 |
| 原子荧光光谱法 | AFS | 气态原子 | 原子荧光 | 第3节；药物分析常用 |
| 紫外–可见分光光度法 | UV-Vis | 分子 | 吸收后的紫外、可见 | 第4章，本节点到为止 |
| 红外吸收光谱法 | IR | 分子振动 | 吸收后的红外 | 第6章 |
| 分子荧光光谱法 | MFS | 分子 | 荧光 | 第5章 |
| 分子磷光光谱法 | MPS | 分子 | 磷光 | 与 MFS 并列点名 |
:::

光谱分析法不仅可以提供物质的量的信息，还可以提供物质的结构信息，并广泛地应用于化学、物理、环境、生物和材料等领域，特别是在物质组成研究、结构分析、生物大分子几何构型的确定、表面分析等方面，发挥着重要作用。

:::insight{label="光谱法同时管“有多少”和“是什么结构”"}
化学分析主要回答组成和含量。光谱法在量的信息之外，还能回答结构、几何构型和表面。把光谱法听成“只是更灵敏的滴定”，红外、核磁、X 射线衍射的户头会丢。
:::

非光谱分析法是基于物质与辐射相互作用时，测量辐射的某些性质，如折射、散射、干涉、衍射和偏振等变化的分析方法。它不涉及物质内部能级的跃迁，电磁辐射只改变传播方向、速率或某些物理性质。属于这类分析方法的有折射法、偏振法、散射法、干涉法、衍射法、旋光法、圆二色性法等。非光谱分析法主要用于物质的性质和组成的测定和研究。其中，折光率测定法、旋光度测定法等被《中国药典》收载，在药学中有诸多应用，将在部分专业后续课程中学习。

:::definition{label="非光谱分析法"}
非光谱分析法是基于物质与辐射相互作用时，测量辐射的某些性质（折射、散射、干涉、衍射和偏振等）变化的分析方法。它不涉及物质内部能级的跃迁，电磁辐射只改变传播方向、速率或某些物理性质。
:::

:::definition{label="折射法"}
折射法属于非光谱分析法，测量辐射在界面上的折射。折光率测定法被《中国药典》收载。
:::

:::definition{label="偏振法与旋光法"}
偏振法、旋光法属于非光谱分析法，测量辐射的偏振或旋转。旋光度测定法被《中国药典》收载。
:::

:::definition{label="圆二色性法"}
圆二色性法（circular dichroism）属于非光谱分析法，落在“辐射的旋转”这一本账。第5节写到 20 世纪 50 年代圆二色光谱仪进入实验室，本节只立户头。
:::

:::definition{label="衍射法"}
衍射法属于非光谱分析法。教材点名最常见的是 X 射线衍射法：X 射线照射晶体产生衍射，各种晶体衍射规律不同，可作为测定晶体化合物结构的依据。
:::

:::compare{title="光谱分析法与非光谱分析法"}
| 项目 | 光谱分析法 | 非光谱分析法 |
|------|------------|--------------|
| 英文 | spectral analysis | 本节未另给专名，正文称非光谱分析法 |
| 分界 | 物质内部发生量子化能级跃迁 | 不涉及内部能级跃迁 |
| 测什么 | 发射、吸收或散射辐射的波长或强度 | 折射、散射、干涉、衍射、偏振等变化 |
| 辐射本身 | 因跃迁而改变能量／被吸收／被再发射 | 只改变传播方向、速率或某些物理性质 |
| 教材举例 | AES、AAS、AFS、UV-Vis、IR、MFS、MPS | 折射法、偏振法、散射法、干涉法、衍射法、旋光法、圆二色性法 |
| 能提供什么 | 量的信息 $+$ 结构信息 | 主要用于性质和组成的测定和研究 |
| 药学落点 | 本书主要介绍光谱分析法 | 折光率、旋光度等被《中国药典》收载，后续课程学习 |
| 第3节表3-2 | 辐射的发射、吸收；拉曼散射 | 散射浊度、折射、干涉、衍射、偏振／旋光／圆二色 |
:::

:::pitfall{label="散射不是一张通行证：拉曼是光谱，浊度是非光谱"}
第3节表3-2把“辐射的散射”拆成两行：拉曼光谱法是光谱法，散射浊度法是非光谱法。钥匙仍是有没有内部能级跃迁——拉曼伴随振动能级变化，浊度只改变传播方向。本节若把所有散射都写成非光谱，拉曼会被错划。
:::

:::pitfall{label="非光谱法不是“不重要”，而是本书不作为主线"}
折光率测定法、旋光度测定法已经被《中国药典》收载。教材的意思是：药学里用得到，但放在部分专业后续课程；本书主要介绍光谱分析法。不要写成“非光谱法已被淘汰”。
:::

:::memory{label="光谱法看跃迁，非光谱法看方向和速率"}
问法：光学分析法一分为二，分界是什么？
答：测的信号是否来自物质内部量子化能级跃迁。有跃迁：光谱法，测波长或强度。无跃迁：非光谱法，测折射、散射、干涉、衍射、偏振等。
:::

## 二、本书写什么、下一节问什么

本书主要介绍光谱分析法。为了更好地认识光学分析法的本质，下面将对电磁辐射的基本性质、光学分析法的分类及常用仪器的组成加以介绍。

:::keypoint{label="第3章三块，本节只打开门"}
- 第2节　电磁辐射的性质：波动性（$T$、$\nu$、$\lambda$、$\sigma$、$v$）、粒子性（$E=h\nu=hc/\lambda=hc\sigma$）、电磁波谱、与物质的相互作用。
- 第3节　光学分析法的分类：光谱／非光谱；原子／分子；吸收／发射／拉曼。
- 第4节　光谱分析仪器：光源、样品池、单色器、检测器、读出器件。
- 第5节　进展简介，并把章末基本要求、思考题、习题收进去。
:::

:::tip{label="读本章时先锁三句话"}
光学分析 $=$ 物质发光，或光与物质相互作用。光谱法 $=$ 内部能级跃迁。仪器五块 $=$ 光源、样品池、单色器、检测器、读出器件。三句话对上了，后面各论才不会串户。
:::

:::cause-effect{title="为什么本章先写辐射，再写分类，再写仪器"}
- **因** 各种电磁辐射的能量不同，与物质相互作用的机理不同，产生的物理现象也不同
- **果** 才能建立不同的光学分析方法；仪器的光源、单色器、检测器也必须按波谱区来配
:::

:::example{label="看见一道题先问“有没有跃迁”"}
题目只说“测的是折射率和旋光度”，不要急着写 AES 或 UV-Vis。折射、旋光不涉及内部能级跃迁，户头在非光谱法，《中国药典》收载的也是这一本账。题目若说“测原子吸收线的波长和强度”，才是光谱法里的 AAS。
:::

:::pitfall{label="不要用别的仪器分析教材替换本版名单"}
本版是季一兵主编《仪器分析》，高等教育出版社 2020 年第 1 版。光谱法点名 AES、AAS、AFS、UV-Vis、IR、MFS、MPS；非光谱法点名折射、偏振、散射、干涉、衍射、旋光、圆二色。不要把别的书里的名单或可见光 $400\sim 700\,\mathrm{nm}$ 提前写进本节。
:::

:::definition{label="散射法（非光谱那一本）"}
第1节名单里的散射法，先按非光谱法立户：测量辐射传播方向的改变，不要求内部能级跃迁。第3节表3-2再把拉曼（光谱）和散射浊度（非光谱）拆开。本节不要把“散射”一句话送进光谱法。
:::

:::definition{label="干涉法"}
干涉法属于非光谱分析法：频率相同、振动相同、相位相等或相差恒定的相干波叠加，出现明暗条纹。第2节给物理图像，第3节把它和折射法一起放在“辐射的折射”行。
:::

:::definition{label="火焰光度法与放射化学法"}
表3-2在“辐射的发射”下列出火焰光度法、放射化学法，类型为光谱法。本节第1段点名的 AES／AAS／AFS／UV-Vis／IR／MFS／MPS 是正文举例；表3-2的名单更宽，两张表不要互相删。
:::

:::definition{label="比色法"}
比色法列在表3-2“辐射的吸收”、光谱法。它是吸收光谱法的早期／简易形态，现代仪器几乎都有单色器，第4节再写滤光片与单色器的差别。本节只记住：比色仍属光谱法，因为有能级跃迁。
:::

:::insight{label="药学读者先抓住两条药典方法和四条常用吸收法"}
《中国药典》在本节点名折光率测定法、旋光度测定法，但明确放到后续课程。药物分析里“应用较多”的吸收法是第3节才点名的紫外–可见、红外、核磁、原子吸收。本节若把药典两法和光谱主线并成一句，后面会分不清“收载”和“本书要考”。
:::

:::keypoint{label="概述三句话，后面四节去兑现"}
- 光学分析法建立在物质发射电磁辐射，或电磁辐射与物质相互作用之上，基础有两本账。
- 按有没有内部量子化能级跃迁，分成光谱分析法与非光谱分析法；本书主要介绍光谱分析法。
- 为认识本质，下面写电磁辐射的基本性质、分类和常用仪器组成。
:::

:::definition{label="光学分析法在分析化学中的位置"}
它是现代分析化学的重要组成部分。第1章已经把仪器分析写成当代分析化学的主流；本章把其中“用电磁辐射说话”的那一支打开。电位、色谱、质谱各有专章，不要在本节把光学分析写成分析化学的全部。
:::

| 光谱分析法（spectral analysis） | 非光谱分析法 |
|----------------------------------|--------------|
| AES、AAS、AFS | 折射法、偏振法 |
| UV-Vis、IR | 散射法、干涉法、衍射法 |
| MFS、MPS | 旋光法、圆二色性法 |
| 测波长或强度；内部量子化能级跃迁 | 测折射、散射、干涉、衍射、偏振等；不涉及内部能级跃迁 |
| 量的信息 $+$ 结构信息 | 性质和组成的测定与研究；折光率、旋光度入《中国药典》 |
:::

:::tip{label="读完概述应能回答的三问"}
这是不是光学分析法？看有没有“物质发光”或“光与物质相互作用”。这是光谱还是非光谱？看有没有内部量子化能级跃迁。本书接下来写什么？辐射性质、分类、仪器组成，主线是光谱法。
:::

:::example{label="给一个方法名，先问跃迁再问粒子再问方向"}
看见 AAS：有内部电子跃迁 → 光谱法；作用气态原子 → 原子光谱；电子从低到高吸光 → 吸收光谱法，药物分析常用。看见旋光法：不涉及内部能级跃迁 → 非光谱法，测辐射的旋转，《中国药典》收载但本书不作为主线。看见拉曼：有振动能级变化 → 光谱法，不要因为“散射”二字就划进非光谱。三问的顺序在第3节展开，本节先养成开口习惯。
:::

:::note{label="电磁辐射四个字在本节的职分"}
本节只把电磁辐射写成光学分析法的物理对象，并点名它可以被物质发射、也可以与物质相互作用。无线电波到 γ 射线的名单、波粒二象性，正文在 3.2 开头已经露面，公式和表3-1 留给第2节。不要在概述里把 $E=h\nu$ 提前算完。
:::

:::memory{label="光学分析两本账，光谱法看跃迁"}
问法：光学分析法是什么？光谱法和非光谱法差在哪？本书写哪一类？
答：建立在物质发射电磁辐射，或电磁辐射与物质相互作用之上。光谱法有内部量子化能级跃迁，测波长或强度；非光谱法没有内部跃迁，测折射、散射、干涉、衍射、偏振等。本书主要介绍光谱分析法。
:::
