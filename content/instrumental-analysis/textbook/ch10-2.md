# 第2节　质谱仪

第 1 节把质谱写成质量谱：离子源对光源，质量分析器对单色器。本节把仪器五块立住：样品导入系统、离子源、质量分析器、检测器、数据处理系统，外加真空。离子类型、裂解规律放到第 3 节，不要把第 11 章色谱理论提前搬进来。

质谱仪的基本组成如图 10-2 所示，它主要包括样品导入系统、离子源、质量分析器、检测器及数据处理系统等五个部分。

::figure{src="/images/instrumental-analysis/textbook/p0238_01.jpg" caption="图10-2　质谱仪的基本组成。样品导入系统 → 离子源 → 质量分析器 → 检测器 → 数据处理系统；离子源之后进入高真空。" alt="五块串联框图，下方标高真空系统"}

:::definition{label="质谱仪五块"}
样品导入系统、离子源、质量分析器、检测器、数据处理系统。真空系统贯穿离子源和质量分析器。
:::

:::concept{term="先问样品怎么进去、怎么变成离子、怎么按 m/z 分开、怎么变成电信号"}
看见质谱仪，先不要跳到“哪家公司的四级杆”。户头仍是五块。把离子源听成光源、把质量分析器听成单色器，和光谱仪过程相似；把五块听成“和紫外光度计同一套光路”，真空和 $m/z$ 都会丢。
:::

:::keypoint{label="五块顺序不要倒"}
导入 → 离子源 → 质量分析器 → 检测器 → 数据处理。大气压／高真空的分界在导入与离子源附近；离子源之后必须是高真空。
:::

## 一、样品导入系统

样品导入系统的作用是将被分析的样品引入到质谱仪中。根据被分析物的物理、化学性质不同，可采用不同的样品导入方法。最常见的样品导入方法有热储罐进样（heated reservoir inlet）、直接探头进样（direct probe inlet）、色谱接口进样（chromatographic interface inlet）。

:::definition{label="样品导入系统"}
把被分析样品引入质谱仪。本版三种：热储罐进样、直接探头进样、色谱接口进样。
:::

### （一）热储罐进样

热储罐进样是第一个用于电子轰击源质谱仪的进样技术，它在早期的石油分析及大多数化合物标准质谱图的获取中起着非常重要的作用。热储罐进样系统主要由体积为 $1\,\mathrm{mL}\sim 1\,\mathrm{L}$ 的储样罐以及两个阀门组成（见图 10-3）。

进样之前，首先通过真空系统将储样罐排空，关闭与真空系统相连的阀门，打开与离子源相连的阀门，进行空白质谱扫描，从而消除前一次样品残留的影响。然后关闭所有的阀门，将样品通过微量注射器注入储样罐，并通过加热系统促进样品的汽化，打开与离子源相连的阀门，使汽化的样品通过扩散穿过针孔进入离子源。

::figure{src="/images/instrumental-analysis/textbook/p0239_01.jpg" caption="图10-3　热储罐进样系统结构示意图。储样罐经阀门、针孔通向离子源，并可接真空系统。" alt="热储罐、两个阀门、针孔、离子源和真空系统示意图"}

该方法仅适用于具有较高蒸气压的气体或液体。对于低挥发性的样品不适用，因为它们不容易从储样罐中清除并可能产生“记忆效应”。

:::definition{label="热储罐进样"}
储样罐体积 $1\,\mathrm{mL}\sim 1\,\mathrm{L}$，两个阀门。先抽空、空白扫描，再注入、加热汽化，经针孔扩散进离子源。只适用于较高蒸气压的气体或液体。
:::

:::pitfall{label="低挥发样品会记忆效应"}
不容易从储样罐里清干净的样品，会把上一针带到下一张图上。不要把热储罐当成“什么样品都能进”的通用口。
:::

### （二）直接探头进样

直接探头进样技术中使用的探头可以分成两种：直插式探头（direct insert probe）和接触式探头（direct exposure probe）。

直插式探头主要用于高沸点的液体及具有高蒸气压的固体的进样，它包括不锈钢轴、铜质探头、硼硅玻璃或铝制样品管、电热线圈和白色的陶瓷绝缘体（见图 10-4）。使用时，将样品置于样品管中，然后将探头插入到离子源中并进行电加热，汽化的样品与电子束产生相互作用而离子化。该方法的缺点是样品量过大时容易对质谱仪产生污染。

接触式探头（见图 10-5）的顶端是用化学惰性的金属丝制成的加热环。制样时，将样品溶于适当的溶剂中，然后取一滴样品溶液置于加热环上，溶剂蒸发后在加热环上形成样品膜，最后将探头插入离子源，并进行加热。由于加热环的加热速度可以达到每秒几百摄氏度，导致样品的汽化速度快于其热降解速度，因此该探头主要适用于加热易降解的物质进样。此外，接触式探头由于所需样品量少，可以降低质谱仪被污染的概率。

:::definition{label="直插式探头"}
用于高沸点液体及高蒸气压固体。不锈钢轴、铜质探头、硼硅玻璃或铝制样品管、电热线圈、陶瓷绝缘体。样品量过大易污染仪器。
:::

:::definition{label="接触式探头"}
顶端惰性金属丝加热环。溶液点在环上成膜后插入离子源。加热速度可达每秒几百摄氏度，汽化快于热降解，适于加热易降解样品；用量少，污染概率低。
:::

:::compare{title="两种直接探头"}
| 项目 | 直插式 | 接触式 |
|------|--------|--------|
| 英文 | direct insert probe | direct exposure probe |
| 对象 | 高沸点液体、高蒸气压固体 | 加热易降解物质 |
| 加热 | 样品管电加热 | 金属丝加热环，可达每秒几百摄氏度 |
| 污染 | 样品量过大易污染 | 用量少，污染概率低 |
:::

:::note{label="图10-4、图10-5 是探头实物"}
图 10-4 为直插式探头实物及其结构放大，图 10-5 为接触式探头实物。二者是仪器零件照片，本节优先嵌框图和质谱图，探头照片不重复占页。
:::

### （三）色谱接口进样

色谱–质谱联用技术是采用色谱技术对复杂混合样品进行分离，然后将分离后的组分导入质谱仪中进行检测的一种技术。但是，在色谱–质谱联用中的一个关键问题是如何有效地除去色谱运行中存在的大量载气或有机溶剂。因为色谱是在大气压下运行的，运行过程中含有大量的载气或溶剂；而质谱仪是在高真空度的环境中操作。解决这个问题的关键就是采用接口技术。

:::definition{label="色谱接口要解决的矛盾"}
色谱在大气压下运行，带着大量载气或溶剂；质谱在高真空中操作。接口的任务是把组分送进离子源，同时把载气／溶剂去掉。
:::

在气相色谱–质谱联用中，最常用的接口是直接导入型接口，也就是在毛细管柱的出口和离子源之间采用可加热的玻璃管相连，其结构如图 10-6 所示。毛细管柱末端的流出物经过直接导入型接口进入离子源，由于气相色谱的载气通常是惰性气体，在离子源中难以发生电离，而被真空抽走；而汽化的样品分子经过高能电子的轰击后产生离子化，形成带电荷离子，并经静电透镜聚焦后进入质量分析器。要注意的是，直接导入型接口的温度应高于色谱柱温或者接近色谱柱的最高使用温度，否则将造成流出组分凝结在色谱柱的末端。

::figure{src="/images/instrumental-analysis/textbook/p0240_01.jpg" caption="图10-6　直接导入型接口结构示意图。毛细管柱经可加热玻璃管进入离子源，再经静电透镜进入质量分析器。" alt="GC-MS 直接导入接口：柱温箱、石墨垫圈、电阻加热器、玻璃管、电子枪、离子源、质量分析器"}

直接导入型接口具有结构简单、收率高的优点，其缺点是无浓缩作用，仅适用于毛细管柱气相色谱，流量应控制在 $0.7\sim 1.0\,\mathrm{mL}\cdot\mathrm{min}^{-1}$。此外，在气相色谱–质谱联用中使用的接口还有开口分流型接口、喷射式分子分离器接口等。

:::definition{label="直接导入型接口"}
毛细管柱出口与离子源之间用可加热玻璃管相连。惰性载气难电离、被真空抽走；样品分子被高能电子电离。温度应高于柱温或接近柱最高使用温度。结构简单、收率高，无浓缩作用，流量 $0.7\sim 1.0\,\mathrm{mL}\cdot\mathrm{min}^{-1}$。
:::

:::pitfall{label="接口温度低于柱温会把组分凝在柱末端"}
直接导入型接口不是“接一根冷玻璃管”。温度不够，高沸点组分凝结，谱图丢峰还污染接口。流量超出 $0.7\sim 1.0\,\mathrm{mL}\cdot\mathrm{min}^{-1}$ 也不是本版给的工作点。
:::

高效液相色谱–质谱联用要求样品在进入离子源之前必须将大量的流动相去除。移动带接口（moving belt）是最早研究的液相色谱–质谱联用接口之一。其原理是在色谱柱末端加入移动速度可调节的传送带，样品经分离后，色谱流出物直接滴落在传送带上，通过红外加热除去大部分流动相后，进入高真空系统，在高真空系统中溶剂被进一步脱除，同时待测样品经挥发后进入离子源。该方法的缺点是离子化效率低，尤其是那些沸点比较高、挥发性差的样品很难实现离子化。此外根据质谱仪离子化方式的不同，还有热喷雾接口（thermospray interface）、电喷雾接口（electrospray interface）、大气压化学电离源接口（APCI interface）等。

:::definition{label="移动带接口"}
最早研究的 LC-MS 接口之一。流出物滴在可调速传送带上，红外加热去大部分流动相，再进高真空脱溶剂、挥发进离子源。离子化效率低，高沸点、低挥发样品很难电离。
:::

:::keypoint{label="GC-MS 与 LC-MS 的接口不要并户"}
GC-MS 本版主讲直接导入型，载气是惰性气体、靠真空抽走。LC-MS 必须先去掉大量流动相：移动带是最早的一种，后面还有热喷雾、电喷雾、APCI。不要把“毛细管直接捅进离子源”套到液相上。
:::

## 二、离子源

质谱中根据被分析物的理化性质及电离过程中内部能量转移方式不同，可采用各种不同的离子化方式将样品气相分子电离成带电荷的离子。目前，最常见的离子源有电子轰击源（electron ionization，EI）、化学电离源（chemical ionization，CI）、快原子轰击离子源（fast atom bombardment，FAB）、基质辅助激光解吸离子源（matrix-assisted laser desorption ionization，MALDI）、电喷雾离子源（electrospray ionization，ESI）等。

:::definition{label="五种常见离子源"}
EI、CI、FAB、MALDI、ESI。英文按本版分词写，扫描粘连不是另一种源。
:::

### （一）电子轰击源

电子轰击源是有机质谱中使用最广泛也是最简单的一种方式。如图 10-7 所示，电子轰击源主要包括离子化室和离子加速区两大部分。电子枪中的灯丝（通常是钨丝或其他金属制成的金属丝）受热后产生电子，所产生的电子经过 $50\sim 100\,\mathrm{eV}$（通常为 $70\,\mathrm{eV}$）的加速电压加速后形成向阳极产生定向移动的高能电子束。当通过样品导入系统进入离子化室的气相分子受到高能电子束的轰击，它将被电离成阳离子、阴离子或自由基；其中阳离子受到带正电荷的排斥极作用进入离子加速区，而阴离子、自由基受到排斥极的吸引作用而产生湮灭，中性分子被真空泵抽走。进入离子加速区的阳离子受到 $1\sim 10\,\mathrm{kV}$ 加速电压的作用，获得动能并经聚焦透镜聚焦后形成离子束进入质量分析器。

::figure{src="/images/instrumental-analysis/textbook/p0242_01.jpg" caption="图10-7　电子轰击源剖面结构示意图。灯丝产生电子，70 eV 加速后轰击离子化室；阳离子经排斥极进入加速区和聚焦透镜。" alt="EI 源剖面：灯丝、电子束、阳极、排斥极、离子化室、加速聚焦、真空泵"}

:::definition{label="电子轰击源"}
有机质谱中使用最广泛、最简单。灯丝热电子经 $50\sim 100\,\mathrm{eV}$（通常 $70\,\mathrm{eV}$）加速；阳离子被排斥极送进加速区，$1\sim 10\,\mathrm{kV}$ 加速后聚焦进入质量分析器。阴离子、自由基在排斥极上湮灭，中性分子被抽走。
:::

电子轰击源有如下特点。首先，它能够获得比较丰富的碎片离子，从而可与标准的电子数据库进行比较，确定化合物的类型。因为大多数有机分子的电离能（ionization energy）在 $8\sim 15\,\mathrm{eV}$，而 $70\,\mathrm{eV}$ 的高能电子束轰击有机分子后所形成的较低能量电子仍然可以导致分子离子裂解形成碎片离子。但是，这也意味着由于其分子离子峰的丰度较低，从而在相对分子质量的测定方面带来困难。其次，电子轰击源的离子化效率非常低，虽然现代的电子轰击源中加入了永久磁体使高能电子束与气相分子的碰撞概率增加，但其离子化效率仍然在 $0.001\%\sim 0.01\%$。再次，采用电子轰击源电离的样品必须具有一定的挥发性，对于相对分子质量高的化合物及大多数生物分子都不适宜采用电子轰击源作为离子化的方式。最后，由于离子–分子反应，在电子轰击源中常常形成比分子离子的 $m/z$ 要大的加合离子峰，最常见的是质子与分子产生相互作用形成的 $(\mathrm{M}+\mathrm{H})^{+}$ 加合离子峰（$M+1$），以及在液相色谱–质谱联用中最常出现的 $(\mathrm{M}+\mathrm{Na})^{+}$ 加合离子峰（$M+23$）。

:::definition{label="EI 的四条"}
碎片丰富，可对数据库；分子离子往往弱，测相对分子质量困难。离子化效率 $0.001\%\sim 0.01\%$。样品必须有一定挥发性，高相对分子质量和大多数生物分子不宜。可能出现 $(\mathrm{M}+\mathrm{H})^{+}$、LC-MS 中常见 $(\mathrm{M}+\mathrm{Na})^{+}$。
:::

:::pitfall{label="70 eV 不是电离能，8～15 eV 才是"}
大多数有机分子电离能 $8\sim 15\,\mathrm{eV}$。选 $70\,\mathrm{eV}$ 是为了让打完之后剩下的能量还够把分子离子打碎，好出碎片、好对库。不要把 $70\,\mathrm{eV}$ 听成“有机分子的电离能是 70”。效率不要写成百分之几，本版是 $0.001\%\sim 0.01\%$。
:::

:::insight{label="EI 是硬电离，所以碎片多、分子离子弱"}
“硬”不是仪器外壳硬，是传给分子的内能高。第 3 节裂解规律、第 4 节各类化合物的碎片，默认账本就是 EI。测相对分子质量不够时，下一小节改走 CI。
:::

### （二）化学电离源

在电子轰击源中，高能电子与气相的物质分子直接产生相互作用，这种电离源被认为是一种硬电离源（hard ionization source）。化学电离源是一种软电离源（soft ionization source），它利用气相的样品分子与反应气体离子碰撞而使样品分子产生电离。

化学电离源的结构与电子轰击源的结构非常相似。当气相样品分子与浓度比其高 $1000\sim 10\,000$ 倍的反应气体（通常为甲烷、异丁烷或者氨气）进入离子化室后，由于离子化室的压力通常比电子轰击源的压力高几个数量级，因此反应气体更容易与高能电子束产生碰撞，从而形成反应气体离子。然后样品分子与反应气体离子发生质子转移、电荷转移、形成加合离子等一系列离子–分子反应使样品分子产生电离。

例如，甲烷反应气体受到高能电子束的轰击会产生 $\mathrm{CH_5^+}$ 和 $\mathrm{C_2H_5^+}$ 正离子，其反应式如下：

$$
\begin{align*}
\mathrm{CH_4} + \mathrm{e}^{-} &\longrightarrow \mathrm{CH_4}^{+\,\cdot} + 2\mathrm{e}^{-}\\
\mathrm{CH_4}^{+\,\cdot} + \mathrm{CH_4} &\longrightarrow \mathrm{CH_5^+} + \cdot\mathrm{CH_3}\\
\mathrm{CH_4}^{+\,\cdot} &\longrightarrow \mathrm{CH_3^+} + \mathrm{H}\cdot\\
\mathrm{CH_3^+} + \mathrm{CH_4} &\longrightarrow \mathrm{C_2H_5^+} + \mathrm{H_2}
\end{align*}
$$

然后，气相样品分子 $\mathrm{M}$ 将分别与 $\mathrm{CH_5^+}$ 和 $\mathrm{C_2H_5^+}$ 产生质子转移以及形成加合离子反应，产生 $(\mathrm{M}+\mathrm{H})^{+}$ 离子和 $(\mathrm{M}+\mathrm{C_2H_5})^{+}$ 离子。

$$
\begin{align*}
\mathrm{M} + \mathrm{CH_5^+} &\longrightarrow (\mathrm{M}+\mathrm{H})^{+} + \mathrm{CH_4}\\
\mathrm{M} + \mathrm{C_2H_5^+} &\longrightarrow (\mathrm{M}+\mathrm{C_2H_5})^{+}
\end{align*}
$$

在化学电离源中，分子离子很少进一步发生裂解，因此分子离子峰的丰度比电子轰击源的丰度要大，质谱图更简单，有利于样品相对分子质量的测定。但是由于缺乏足够的碎片离子，对于样品的结构信息提供较少。此外，由于化学电离源中更容易获得加合离子，因此在确定分子离子时需要特别注意。通常，在化学电离源中，可通过选择合适的反应气体，改变离子化的选择性及碎片离子裂解的程度。反应气体的选择应尽可能与反应气体和样品的质子亲和力（proton affinity）相适应，样品和反应气体的质子亲和力差异越大，电离过程中质子从反应气体转移到样品分子中所需能量越多，样品不能产生有效电离。图 10-8 显示了乙酸薰衣草酯的电子轰击源质谱图和化学电离源质谱图。

::figure{src="/images/instrumental-analysis/textbook/p0243_01.jpg" caption="图10-8　乙酸薰衣草酯的电子轰击源和化学电离源的质谱图。(a) EI；(b) CI，反应气体为异丁烷；(c) CI，反应气体为氨气，出现 M+NH4+。" alt="三张质谱：EI 碎片多、MH+弱；异丁烷 CI 的 MH+ 变强；氨气 CI 出现 m/z 214 的 M+NH4+"}

:::definition{label="硬电离源与软电离源"}
EI：高能电子直接打样品分子，硬电离源。CI：样品分子与反应气体离子碰撞而电离，软电离源。
:::

:::definition{label="化学电离源"}
反应气体（甲烷、异丁烷或氨气）浓度比样品高 $1000\sim 10\,000$ 倍，离子化室压力比 EI 高几个数量级。甲烷体系给出 $\mathrm{CH_5^+}$、$\mathrm{C_2H_5^+}$，再与 $\mathrm{M}$ 做质子转移或加合。分子离子很少再裂解，图更简单，利于测相对分子质量；碎片少，结构信息少；加合离子多，认分子离子要小心。
:::

:::pitfall{label="CI 的 MH+ 不是 EI 的分子离子，氨气还会出 M+NH4+"}
图 10-8 里 EI 的 $197$ 处 $\mathrm{MH}^{+}$ 很弱；异丁烷 CI 的 $\mathrm{MH}^{+}$ 变强；氨气 CI 在 $214$ 给出 $\mathrm{M}+\mathrm{NH_4^+}$。不要把最高 $m/z$ 的峰一律写成 $\mathrm{M}^{+\,\cdot}$。质子亲和力差太大，样品电离不起来，不是“换软电离就一定出峰”。
:::

:::compare{title="EI 对 CI"}
| 项目 | EI | CI |
|------|----|----|
| 软硬 | 硬电离 | 软电离 |
| 谁和分子撞 | 高能电子 | 反应气体离子 |
| 离子化室压力 | 较低 | 高几个数量级 |
| 分子离子 | 往往弱 | 丰度大 |
| 碎片 | 丰富，可对库 | 少，结构信息少 |
| 加合离子 | 可出现 $(\mathrm{M}+\mathrm{H})^{+}$、$(\mathrm{M}+\mathrm{Na})^{+}$ | 更容易，认 $\mathrm{M}$ 要小心 |
:::

### （三）快原子轰击离子源

电子轰击源和化学电离源主要适用于挥发性较强的低相对分子质量样品，而对于挥发性不强、相对分子质量高的样品来说，常用的离子源主要有快原子轰击离子源、基质辅助激光解吸离子源。其中，快原子轰击离子源是 20 世纪 80 年代发展起来的一种离子化方式，其结构如图 10-9 所示。

::figure{src="/images/instrumental-analysis/textbook/p0244_01.jpg" caption="图10-9　快原子轰击离子源的结构示意图。FAB 枪产生高能原子束打到探头上的样品，次级离子加速后进入质量分析器。" alt="FAB：灯丝、阳极、碰撞池、氙气、高能原子束、FAB 探头、离子化室"}

中性的快原子轰击气体（通常是惰性气体氩气或氙气）通过针阀进入碰撞池后向快原子轰击枪及离子化室产生扩散。在快原子轰击枪中，当快原子轰击气体与高能电子产生碰撞后，形成快原子轰击气体离子，并经 $4\sim 8\,\mathrm{kV}$ 的加速电压加速、聚焦后使高能快原子轰击气体离子回到碰撞池，并与中性的快原子轰击气体产生电荷交换和能量转移，形成高能原子束。高能原子束照射到装有样品的快原子轰击探头上，使样品产生电离形成次级离子，并经过加速电压加速、聚焦后进入质量分析器。

在快原子轰击离子源中，探头也被称为快原子轰击靶，它常常是由不锈钢或铜制成的，并且装载在探头上的样品与高能原子束呈一定的角度（通常是 $30^{\circ}\sim 60^{\circ}$）。快原子轰击源的主要优势是样品不必是气相分子，它可以直接将样品溶解在基质（如甘油）中形成溶液，并可适当地加入共溶剂增大样品的溶解度，常见的共溶剂有二甲基甲酰胺、二甲亚砜等。因此，它特别适合于高极性、低蒸气压、低热稳定性的有机样品分析。快原子轰击源中样品用量少，甚至可以回收样品而不影响原来的生物活性。所获得的质谱图中具有较强的准分子离子峰及丰富的碎片离子峰。

:::definition{label="快原子轰击离子源"}
20 世纪 80 年代。Ar 或 Xe 经电荷交换形成高能原子束，$4\sim 8\,\mathrm{kV}$ 加速；打到不锈钢或铜靶上，样品与束成 $30^{\circ}\sim 60^{\circ}$。样品溶在甘油等基质中，不必先变成气相。适于高极性、低蒸气压、低热稳定性样品；准分子离子强，碎片也丰富。
:::

:::pitfall{label="FAB 打的是快原子，不是再拿 70 eV 电子轰样品"}
枪里先把气体打成离子，再和中性气体交换电荷，打到样品上的是高能原子束。基质是甘油一类，共溶剂是 DMF、DMSO，不要写成“必须先汽化再 EI”。
:::

### （四）基质辅助激光解吸离子源

基质辅助激光解吸离子源是 1988 年由 Karas 和 Hillenkamp 等人提出的，它主要用于相对分子质量高的、低挥发性及热不稳定的化合物（如蛋白质、寡核苷酸、合成聚合物以及相对分子质量高的无机化合物）的气相电离。其工作原理见图 10-10。

::figure{src="/images/instrumental-analysis/textbook/p0245_01.jpg" caption="图10-10　基质辅助激光解吸离子源的工作原理示意图。紫外脉冲激光打到含样品的基质晶体上，解吸电离后加速进入质量分析器。" alt="MALDI：紫外脉冲激光、样品基质晶体、解吸附、加速器、透镜"}

首先，将样品溶解于含有少量对于激光波长具有强吸收的基质溶液中，并将制得的溶液进行干燥除去液体溶剂，形成掺杂了样品的基质晶体，在基质晶体中，所有的样品分子被基质完全包埋，从而使每一个样品分子与另一个样品分子完全分离。其次，在质谱仪离子源的真空条件下，含有样品的基质晶体受到紫外脉冲激光的照射，基质吸收紫外脉冲激光的能量使基质晶体快速受热产生烧蚀和解吸，而包埋在基质中的样品分子在烧蚀气体的热焰中产生离子化，并经加速后进入质量分析器。

在基质辅助激光解吸离子源中所使用的基质通常是低蒸气压的晶状固体，其主要作用就是稀释样品分子并使样品分子之间不产生相互作用。目前，最常用的对紫外脉冲激光具有吸收的基质分子有烟酸、2,5-二羟基苯甲酸、2,6-二羟基苯乙酮及 4-羟基苯乙烯酸衍生物（如 $\alpha$-氰基-4-羟基苯乙烯酸和 3,5-二甲氧基-4-羟基苯乙烯酸）等。

基质辅助激光解吸离子源具有许多优点。首先，由于在基质晶体中基质的使用量远大于样品分子的量，使样品分子处于相互独立的状态，因此样品分子离子的丰度大大增加，灵敏度高。其次，由于脉冲激光与基质分子产生相互作用，减少了对样品的损害。由于基质分子吸收脉冲激光的过程与样品分子的大小和吸收特性无关，因此基质辅助激光解吸离子源能够使生物大分子产生解吸和离子化。此外，该方法还具有制样简单、对盐和缓冲溶液的污染具有较大的耐受性等优点。但是，基质辅助激光解吸离子源也具有一些缺点，如重现性差、所产生的质谱图形状受样品制备方法的影响等。

:::definition{label="MALDI"}
1988 年 Karas 和 Hillenkamp 提出。样品包埋在强吸收紫外脉冲激光的基质晶体中，激光烧蚀、解吸后样品电离。用于高相对分子质量、低挥发、热不稳定化合物。
:::

:::definition{label="本版点名的 MALDI 基质"}
烟酸；2,5-二羟基苯甲酸；2,6-二羟基苯乙酮；4-羟基苯乙烯酸衍生物（$\alpha$-氰基-4-羟基苯乙烯酸、3,5-二甲氧基-4-羟基苯乙烯酸）。基质是低蒸气压晶状固体，用来稀释样品、避免样品分子互扰。
:::

:::pitfall{label="MALDI 的光是打在基质上，不是直接烧蛋白质"}
基质用量远大于样品，激光先被基质吸收。重现性差、谱图形状受制样影响，是本版写明的缺点，不要写成“大分子质谱没有缺点”。
:::

### （五）电喷雾离子源

电喷雾离子源是液相色谱–质谱联用中最常用的一种软电离方式。含有样品分子的溶液通过毛细管尖被喷射到接近大气压力的加热室中，由于毛细管表面具有 $2\sim 5\,\mathrm{kV}$ 的高压，因此喷射到加热室的溶液变成带电荷的微小液滴。在加热室中，带电荷的液滴遇到干燥气体（通常是氮气）逆流使液滴中的溶剂蒸发，因而每一个液滴的电荷密度不断增加，直至静电排斥力大于液滴的表面张力，液滴被分解成更小的液滴，该过程不断重复，直至气相中只剩下样品离子（见图 10-11）。

::figure{src="/images/instrumental-analysis/textbook/p0246_01.jpg" caption="图10-11　电喷雾离子源的工作原理示意图。毛细管 2～5 kV，液滴经场蒸发和库仑爆炸，对电极收集离子。" alt="ESI：毛细管、高压电源、场蒸发、库仑爆炸、对电极"}

电喷雾离子源主要适用于不易挥发的、热不稳定的化合物。由于它能产生多电荷离子（multiple-charge ions），使大分子离子的 $m/z$ 能够在常用的 $m/z$ 检测范围内被检测，扩大了质谱测定的相对分子质量范围。此外，电喷雾离子源作为一种软电离方式，它能够用来研究大分子（如蛋白质）的非共价结合，并且在合适的质量分析器（如飞行时间质量分析器）条件下，它能测定小分子的准确质量。电喷雾离子源也能用于无机阳离子和阴离子的分析，并能提供价态和分子式的信息。

:::definition{label="电喷雾离子源"}
LC-MS 最常用的软电离。毛细管 $2\sim 5\,\mathrm{kV}$，氮气逆流干燥，电荷密度升高后库仑爆炸，直到气相只剩样品离子。适于不易挥发、热不稳定化合物；产生多电荷离子，扩大可测相对分子质量范围。
:::

:::insight{label="多电荷把大 m 变成常用的 m/z"}
质量分析器认的是 $m/z$。蛋白质带上许多电荷，$m/z$ 落回仪器窗口。后面飞行时间质量分析器“理论上 $m/z$ 范围无限”，和 ESI 的多电荷是两条不同的路，不要并成一句口诀。
:::

:::compare{title="五种离子源怎么分户"}
| 离子源 | 软硬 | 样品要不要先挥发 | 本版关键数字／产物 | 主要用途 |
|--------|------|-------------------|---------------------|----------|
| EI | 硬 | 要 | $70\,\mathrm{eV}$；碎片多，分子离子弱 | 低相对分子质量、挥发性有机物，对库 |
| CI | 软 | 要 | 反应气浓度高 $1000\sim 10\,000$ 倍；$(\mathrm{M}+\mathrm{H})^{+}$ | 测相对分子质量 |
| FAB | 介于二者，准分子离子强且碎片丰富 | 不必 | $4\sim 8\,\mathrm{kV}$，甘油基质 | 高极性、低蒸气压、低热稳定性 |
| MALDI | 软 | 不必（基质晶体） | 1988；紫外脉冲激光 | 蛋白质、寡核苷酸、聚合物 |
| ESI | 软 | 溶液喷雾 | $2\sim 5\,\mathrm{kV}$；多电荷 | LC-MS；热不稳定、非共价 |
:::

## 三、质量分析器

质量分析器是质谱仪的核心，样品电离后形成的离子束经过加速后进入质量分析器，质量分析器根据离子的 $m/z$ 不同使各种不同类型的离子分离。常用的质量分析器有磁偏转质量分析器（magnetic sector mass analyzer）、四极杆质量分析器（quadrupole mass analyzer）、飞行时间质量分析器（time-of-flight mass analyzer）、离子阱质量分析器（ion trap mass analyzer）等。

:::definition{label="质量分析器"}
质谱仪的核心。按 $m/z$ 把离子分开。本版四种：磁偏转、四极杆、飞行时间、离子阱。
:::

### （一）磁偏转质量分析器

磁偏转质量分析器可以分成单聚焦磁偏转质量分析器和双聚焦磁偏转质量分析器。通常，双聚焦磁偏转质量分析器的分辨率大约为单聚焦磁偏转质量分析器分辨率的 10 倍，因此目前所使用的磁偏转质量分析器通常是双聚焦磁偏转质量分析器。为了便于理解，本节主要介绍单聚焦磁偏转质量分析器的工作原理。

样品分子在离子化区被电离，在离子加速区获得动能，并经聚焦后进入质量分析器。离子动能的大小与加速电压的关系可用式（10-1）表示：

$$
\frac{1}{2}mv^{2} = zV \qquad (10\text{-}1)
$$

式中，$m$ 为离子的质量；$v$ 为离子的速率；$z$ 为离子本身所带的电荷数；$V$ 为加速电压。

在磁偏转质量分析器中，由于磁场方向与离子的运动方向垂直，因此离子受到洛伦兹力的影响产生匀速圆周运动（见图 10-12）。匀速圆周运动时的向心力等于磁场力，所以

$$
zvH = \frac{mv^{2}}{r}\quad\text{或}\quad mv = zHr \qquad (10\text{-}2)
$$

式中，$H$ 为磁场强度，$r$ 为匀速圆周运动的曲率半径。将式（10-2）代入式（10-1）后可得

$$
\frac{m}{z} = \frac{H^{2}r^{2}}{2V} \qquad (10\text{-}3)
$$

从式（10-3）可知：当磁场强度和加速电压相同时，$m/z$ 越大的离子，其匀速圆周运动的曲率半径 $r$ 也越大。由于在磁偏转质量分析器中，离子的运行路径具有固定的曲率半径，也就是说，只有一定 $m/z$ 的离子才能穿过质量分析器到达检测器，而 $m/z$ 太大或太小的离子将与质量分析器的内壁产生撞击。但是，可以通过连续改变磁场强度，使离子源中产生的各种离子依次到达检测器被检测，这种方式称为磁场扫描。当然，也可以保持磁场强度不变，改变加速电压的大小，使各种不同 $m/z$ 的离子依次通过质量分析器被检测，这种方式称为电压扫描。

::figure{src="/images/instrumental-analysis/textbook/p0247_01.jpg" caption="图10-12　单聚焦磁偏转质量分析器示意图。磁场中 m/z 较大的离子曲率半径大，只有对准狭缝的离子被检测；可做磁场扫描或电压扫描。" alt="单聚焦磁偏转：离子源、狭缝、磁场、检测器；标出 m/z 较大和较小的离子轨迹"}

双聚焦磁偏转分析器是在单聚焦磁偏转质量分析器和检测器之间增加一个静电场质量分析器，而静电场质量分析器由同轴圆筒电极组成（通常为扇形），外电极带正电荷，内电极带负电荷。经加速后从离子源出来的某一 $m/z$ 的离子速率并不完全相同，因此通过磁偏转质量分析器出来的离子速率也并不完全相同。由于静电场质量分析器内、外电极之间保持一定的电位差，只有一定能量的离子才能通过静电场到达检测器，这一过程也被称为能量色散。通过能量色散后，磁偏转质量分析器的分辨率得到大大改善（见图 10-13）。

::figure{src="/images/instrumental-analysis/textbook/p0248_01.jpg" caption="图10-13　双聚焦磁偏转质量分析器示意图。离子源后先经静电场质量分析器做能量色散，再经磁偏转质量分析器。" alt="双聚焦：离子源、静电场扇形分析器、磁偏转分析器、狭缝、检测器"}

:::definition{label="单聚焦磁偏转"}
动能 $\dfrac{1}{2}mv^{2}=zV$。磁场中 $m/z=H^{2}r^{2}/(2V)$。固定 $r$ 时，磁场扫描或电压扫描让不同 $m/z$ 依次到达检测器。
:::

:::definition{label="双聚焦磁偏转"}
在单聚焦与检测器之间加扇形静电场质量分析器（外正内负），做能量色散。分辨率约为单聚焦的 10 倍。目前使用的磁偏转通常是双聚焦。
:::

:::pitfall{label="式（10-1）不要丢掉 1/2，也不要把 H 写成 B 就改公式"}
本版用 $H$ 表示磁场强度，工作式按印刷写。扫描稿常把 $\frac{1}{2}mv^{2}$ 粘成 $mv^{2}=zV$，后面的 $m/z=H^{2}r^{2}/(2V)$ 会对不上。
:::

### （二）四极杆质量分析器

四极杆质量分析器是由平行于电子束运行方向的四根双曲线电极杆或者四根圆柱形电极杆组成，其中处于相对位置的两对电极分别连接到直流电源的两极，使一对电极的直流电压为 $+U$、另一对电极的直流电压为 $-U$。在每一对电极上叠加一个频率为 $\omega$、电压为 $V$ 的射频振荡电源，且两对电极射频振荡电压的相位相差 $180^{\circ}$。由于射频振荡电压远大于直流电压（例如，射频电压最高可以达到 $1200\,\mathrm{V}$，而直流电压最高只能达到 $200\,\mathrm{V}$），在四极杆内产生强度和相位都不断变化的振荡电场。在一定的射频振荡电压 $V$、振荡频率 $\omega$ 和直流电压 $U$ 下，只有一定 $m/z$ 的离子不断地受到吸引和排斥，以螺旋式的路径通过振荡电场到达检测器；而 $m/z$ 太大或太小的离子在四极杆内产生不稳定的振荡，且振荡的幅度不断增加，直至与电极杆产生碰撞或被真空系统抽走（见图 10-14）。

::figure{src="/images/instrumental-analysis/textbook/p0248_01.jpg" caption="图10-14　四极杆质量分析器工作原理示意图及实物图。(a) 稳定轨迹的离子穿过四极杆到达检测器；(b) 四极杆实物。" alt="四极杆：离子源出来的离子束，稳定离子到检测器，不稳定离子打到杆上"}

四极杆质量分析器的优点主要有：① 离子到达检测器的效率高；② 质量轻、结构紧凑及相对较低的价格；③ 离子加速电压低；④ 扫描速度快等。但是，相比于磁偏转质量分析器，四极杆质量分析器的分辨率和离子检测的 $m/z$ 范围有限，一般常用于 ICP-MS、GC-MS 和 LC-MS 等联用技术中。

:::definition{label="四极杆质量分析器"}
四根双曲线或圆柱电极。相对两对分别接 $+U$、$-U$，再叠加相位差 $180^{\circ}$ 的射频 $V$。射频远大于直流（例：射频最高 $1200\,\mathrm{V}$，直流最高 $200\,\mathrm{V}$）。只有一定 $m/z$ 走螺旋稳定轨迹到达检测器。
:::

:::pitfall{label="四极杆不是“分辨率最高的分析器”"}
优点是效率、重量、价格、低加速电压、扫描快。分辨率和 $m/z$ 范围比不上磁偏转。本版把它放到 ICP-MS、GC-MS、LC-MS 联用里，不要写成“四极杆已经淘汰磁偏转”。
:::

### （三）飞行时间质量分析器

第一个飞行时间质量分析器是由宾夕法尼亚大学的 W. E. Stephens 教授于 20 世纪 40 年代提出并建造的。飞行时间质量分析器不需要借助外力（如电场或磁场）来分离各种 $m/z$ 的离子，而是将加速后的各种不同 $m/z$ 离子引入无外力场的漂移管（drift tube）。各种 $m/z$ 离子进入漂移管的速率为

$$
v = \sqrt{\frac{2zV}{m}} \qquad (10\text{-}4)
$$

由式（10-4）可知：离子进入漂移管的速率取决于离子的 $m/z$；或者当所有离子只带一个电荷时，离子进入漂移管的速率取决于离子的质量。因此，质量越小或 $m/z$ 越小的离子，在漂移管中的飞行速率越快，它比质量越大或 $m/z$ 越大的离子先到达检测器（见图 10-15）。

::figure{src="/images/instrumental-analysis/textbook/p0249_01.jpg" caption="图10-15　基质辅助激光解吸－飞行时间质谱仪示意图。脉冲激光打样品，离子经加速区进入长度为 L 的漂移管，m1>m2>m3 时轻的先到检测器。" alt="MALDI-TOF：样品支架、脉冲激光、加速区、漂移路径 L、检测器"}

假设漂移管的长度为 $L$，离子在漂移管中飞行的时间为 $t$，则

$$
t = L\sqrt{\frac{m}{2zV}} \qquad (10\text{-}5)
$$

由此可知，离子在漂移管中飞行的时间与离子的 $m/z$ 平方根成正比。对于能量相同的离子来说，质量越大，到达检测器所用的时间越长；质量越小，所用时间越短。实际上，相邻质量的两个离子在漂移管中飞行时间的差异只有几微秒，甚至几纳秒，这就需要非常快速的电子设备来准确记录各种离子的飞行时间。

飞行时间质量分析器的优点主要有：① 理论上，飞行时间质量分析器检测的 $m/z$ 范围是无限的；② 可获得完整的质谱图，甚至包括在较短离子化过程（如 MALDI）中形成的离子所产生的质谱峰；③ 离子通过质量分析器的效率高、灵敏度高；④ 质谱图采集速率快；⑤ 仪器设计和构造简单；⑥ 现代的飞行时间质量分析器能够准确测定离子的质量并适用于串联质谱。飞行时间质量分析器的主要缺点是分辨率较低，其分辨率与离子的飞行时间成正比，因此增加漂移管的长度将增加分辨率，目前最常用的方式就是在飞行时间质量分析器中加入各种离子反射器。

:::definition{label="飞行时间质量分析器"}
加速后的离子进无外力场漂移管。$v=\sqrt{2zV/m}$，$t=L\sqrt{m/(2zV)}$。$t$ 与 $\sqrt{m/z}$ 成正比，轻的先到。20 世纪 40 年代由 Stephens 提出。
:::

:::pitfall{label="相邻离子只差几微秒甚至几纳秒，不是“慢慢飞过去数峰”"}
分辨率与飞行时间成正比，加长漂移管或加离子反射器。不要把“理论上 $m/z$ 范围无限”听成“分辨率也无限”。
:::

### （四）离子阱质量分析器

离子阱是一种能够在一定时间内通过电场或磁场形成气相离子和／或储存气相离子的装置。目前在质谱中使用的离子阱主要有三种：四极离子阱（quadrupole ion trap，QIT）、傅里叶变换离子回旋共振（Fourier transform ion-cyclotron resonance，FT-ICR）和轨道离子阱（orbitrap）。其中，四极离子阱最常用，本书中仅介绍四极离子阱。

1960 年四极杆质量分析器的发明者 Paul 和 Steinwedel 就提出离子阱的概念。后来 Finnigan 公司的 Stafford 等人进行了改进，设计了离子阱质量分析器。离子阱质量分析器主要由一个环电极及位于环电极上方或下方的两个双曲面型端帽电极组成（见图 10-16），环电极与固定频率的射频电源相连，而端帽电极接地或与射频电源或直流电源相连。施加电压时，各种不同 $m/z$ 的离子以稳定的轨迹在环电极和端帽电极形成的空间内运动，从而导致各种离子储存在离子阱中。当增加环电极上射频电压的振幅时，$m/z$ 大的离子的轨迹不再稳定，这些离子将向端帽电极产生移动，从而使一定 $m/z$ 的离子穿过端帽电极并被检测器检测。

::figure{src="/images/instrumental-analysis/textbook/p0250_01.jpg" caption="图10-16　离子阱质量分析器剖面结构示意图。环电极夹在两个端帽电极之间，离子从一端进入、从另一端到检测器。" alt="离子阱剖面：两个端帽电极和环电极，离子束进出"}

由于端帽电极的射频电源和直流电源的波形不同，离子阱能够选择性地储存样品离子并消除基质离子的干扰，因此离子阱质量分析器的检测限低、灵敏度高。其次，它适用于多级质谱联用，价格较低、体积较小，可用作色谱的检测器。但是，离子阱质量分析器也具有一定的局限性。由于存储在离子阱中的离子能够产生相互作用，从而使离子阱质量分析器具有较低的动态范围，测定 $m/z$ 时的准确度有限。此外，当离子阱中存在过量的干扰离子时，很难将样品离子从干扰离子中分辨出来，因此离子阱质量分析器用作定量分析时准确度低。

:::definition{label="四极离子阱"}
环电极加两个双曲面端帽。离子先以稳定轨迹储存在阱中，增大环电极射频振幅后，$m/z$ 大的离子轨迹失稳，穿过端帽被检测。本书只介绍四极离子阱；QIT、FT-ICR、orbitrap 三种里它最常用。
:::

:::pitfall{label="离子阱定量准确度低，不要写成万能检测器"}
优点：检测限低、灵敏度高、可多级质谱、便宜、体积小。缺点：离子互扰导致动态范围低，$m/z$ 准确度有限；干扰离子多时分不开，定量准确度低。概述里 1974 年的 FT-ICR 不是这一小节的四极离子阱。
:::

:::compare{title="四种质量分析器"}
| 分析器 | 分开的依据 | 本版要点 | 主要短板 |
|--------|------------|----------|----------|
| 单／双聚焦磁偏转 | $m/z=H^{2}r^{2}/(2V)$ | 双聚焦分辨率约 10 倍于单聚焦 | 体积大、扫描方式要选磁场或电压 |
| 四极杆 | 稳定螺旋轨迹 | 射频例 $1200\,\mathrm{V}$、直流例 $200\,\mathrm{V}$；联用常见 | 分辨率和 $m/z$ 范围有限 |
| 飞行时间 | $t\propto\sqrt{m/z}$ | 理论上 $m/z$ 无限；常配 MALDI | 分辨率较低，靠加长或反射器 |
| 四极离子阱 | 先储存再失稳弹出 | 可多级质谱 | 动态范围低，定量准确度低 |
:::

## 四、检测器

质谱仪中的检测器的功能是检测通过质量分析器的离子并将其转换成可观察的信号。通常，检测器的信号强度与进入检测器的离子数目成正比。目前最常用的检测器主要有法拉第杯（Faraday cup）、电子倍增管（electron multiplier）和阵列检测器（array detector）。

:::definition{label="检测器"}
把通过质量分析器的离子变成可观察信号。信号强度与离子数目成正比。本版三种：法拉第杯、电子倍增管、阵列检测器。
:::

### （一）法拉第杯

法拉第杯由金属杯或者带有小孔的圆柱体组成，杯体通过电阻接地。当离子进入杯内并与杯内壁产生撞击时，离子通过给出电子或者接受电子而呈电中性，从而产生放电电流，该放电电流经过放大后被检测（见图 10-17）。所产生的电流大小与检测器检测的离子数目及单个离子所带的电荷数成正比。

::figure{src="/images/instrumental-analysis/textbook/p0251_01.jpg" caption="图10-17　法拉第杯结构示意图。离子进入杯内中和，电流经放大器检出。" alt="法拉第杯：离子束进入金属杯，电子流向放大器"}

由于离开杯内壁的电子所带的电荷与到达检测器的正离子所带的电荷是一样的，如果不抑制离子二次撞击检测器内壁所发射的二级电子，将产生较大的检测误差。为了改善该检测器的准确度，可使用各种器件更有效地捕获离子并减少二级电子所带来的误差。例如，在法拉第杯上包裹一层碳膜，因为碳膜能够减少二级电子的产生。也可通过改变杯的形状及采用弱磁场减少二级电子的产生。

法拉第杯的优点是结构简单，价格便宜，适合于同位素比质谱法（isotopic ratio mass spectrometry）中某一离子准确比例的测定。但是，该方法具有灵敏度低和响应速度慢的缺点。

:::definition{label="法拉第杯"}
金属杯或带小孔圆柱，经电阻接地。离子中和产生放电电流，电流与离子数目及电荷数成正比。包碳膜或改形状、加弱磁场以抑制二级电子。结构简单、便宜，适于同位素比；灵敏度低、响应慢。
:::

### （二）电子倍增管

目前，质谱仪中广泛使用的检测器是电子倍增管。与光电倍增管相似，电子倍增管上含有数个倍增极（通常为 $12\sim 24$ 个倍增极），当高速移动的电子、阳离子、阴离子或中性粒子撞击到倍增极上，将发射出电子，发射出的电子被加速后撞击第二个倍增极的表面，因此每一个撞击到倍增极上的电子将产生多个电子，该过程不断发生，直至一连串的电子达到收集器（如图 10-18 所示）。通常，一个离子能够产生 $10^{5}$ 个电子甚至更多。

::figure{src="/images/instrumental-analysis/textbook/p0252_01.jpg" caption="图10-18　电子倍增管工作原理示意图。入射离子打在倍增极上，二级电子逐级放大，倍增极电压约 1～2 kV。" alt="电子倍增管：入射离子束、多级倍增极、二级电子、收集器"}

电子倍增管具有响应速度快、灵敏度高的特点。但是，电子倍增管中所产生的二级电子数目与入射的粒子类型、入射角及入射能量相关。发射的二级电子数目会随着入射粒子能量的增大而增大，因此四极杆质量分析器或四极离子阱质量分析器中出来的质量较大的离子在低速时就可以发射出二级电子，而质量较小的离子需要在较高速率时才能发射出二级电子，这种现象称为质量歧视效应（mass discrimination effect）。所以在这些质量分析器的质谱仪中使用电子倍增管作为检测器时，必须消除离子速率的差异。

:::definition{label="电子倍增管"}
通常 $12\sim 24$ 个倍增极。一个离子可产生 $10^{5}$ 个电子甚至更多。响应快、灵敏度高。存在质量歧视效应：大质量离子低速就能打出二级电子，小质量离子要更高速率。
:::

:::pitfall{label="质量歧视不是“检测器坏了”"}
四极杆、四极离子阱配电子倍增管时，必须消除离子速率差异。不要把轻重离子峰高差一律写成“样品里轻的多”。扫描稿常把 $10^{5}$ 粘成 $10^{\circ}$。
:::

### （三）阵列检测器

前面所述的法拉第杯或电子倍增管每次质谱扫描只能检测一种离子，而阵列检测器每次质谱扫描时可以同时检测多种离子。最常见的阵列检测器有微通道板（microchannel plate，MCP），它是在一个平面内分布有 $10^{5}\sim 10^{7}$ 个倍增管的阵列检测器，每一个倍增管的直径只有 $10\sim 100\,\mu\mathrm{m}$（见图 10-19）。

::figure{src="/images/instrumental-analysis/textbook/p0252_01.jpg" caption="图10-19　微通道板的横截面示意图（a）及每个通道内的电子放大示意图（b）。" alt="MCP：平面上密布微通道；单通道内电子倍增"}

由于二级电子在微通道板的通道内运行的距离非常短，具有非常短的响应时间，它特别适合用作飞行时间质谱仪的检测器。此外由于微通道板的检测面积非常大，因此它可用于质量分析器中出来的大离子束检测，不需进行额外的聚焦。但是，微通道板具有易碎、对空气敏感以及价格昂贵的缺点。

:::definition{label="微通道板"}
阵列检测器，一次扫描同时检测多种离子。$10^{5}\sim 10^{7}$ 个倍增管，管径 $10\sim 100\,\mu\mathrm{m}$。响应极短，适于 TOF；检测面积大，大离子束不必再聚焦。易碎、怕空气、贵。
:::

:::compare{title="三种检测器"}
| 检测器 | 一次扫几个 | 本版数字 | 长处 | 短处 |
|--------|------------|----------|------|------|
| 法拉第杯 | 一种 | 电流 ∝ 离子数 × 电荷 | 简单、便宜、同位素比准 | 灵敏度低、响应慢 |
| 电子倍增管 | 一种 | $12\sim 24$ 极；$\sim 10^{5}$ 电子／离子 | 快、灵 | 质量歧视 |
| MCP | 多种 | $10^{5}\sim 10^{7}$ 管；$10\sim 100\,\mu\mathrm{m}$ | 适于 TOF | 易碎、怕空气、贵 |
:::

## 五、真空系统

真空系统的主要作用是为了避免离子与气体分子的碰撞。为了保持质谱仪的高真空度，通常采用两级真空系统。第一级真空系统采用 $1\sim 3$ 个旋片式真空泵（rotary vane pump），它使样品导入系统产生几帕的中等真空度。第二级真空系统采用 $2\sim 3$ 个涡轮式真空泵（turbo pump），其中一个与离子源相连，另一个或两个真空泵与质量分析器相连。通常，离子源与质量分析器的真空度分别为 $10^{-3}\sim 10^{-4}\,\mathrm{Pa}$ 和 $10^{-6}\sim 10^{-5}\,\mathrm{Pa}$。

:::definition{label="两级真空"}
第一级：$1\sim 3$ 个旋片泵，样品导入系统到几帕。第二级：$2\sim 3$ 个涡轮泵，一个接离子源，一或两个接质量分析器。离子源 $10^{-3}\sim 10^{-4}\,\mathrm{Pa}$，质量分析器 $10^{-6}\sim 10^{-5}\,\mathrm{Pa}$。
:::

:::pitfall{label="离子源真空不要写成和质量分析器同一档"}
质量分析器比离子源更“空”一个到两个数量级。扫描稿常把指数粘成 $10^{-}\,\mathrm{Pa}$。没有真空，离子还没飞到检测器就和残气撞上，质谱图无法谈。
:::

## 六、质谱图

质谱图（mass spectrum）是以每种离子的相对丰度作为纵坐标，以离子的 $m/z$ 为横坐标所绘制的二维谱图。离子源中丰度最大的离子在质谱图中产生的峰最高，它所形成的质谱峰称为基峰（base peak）。相对丰度（relative abundant）是指将质谱图中基峰的丰度定义为 $100\%$，其他离子的丰度与基峰丰度的比值。图 10-20 为多巴胺的质谱图，图中 $m/z$ 为 $124$ 的离子峰丰度最大，因此 $m/z$ 为 $124$ 的质谱峰为基峰，其相对丰度为 $100\%$。而其他离子的丰度以基峰丰度的百分数表示。质谱图的数据还可以采用表格的形式表示。例如，图 10-20 中多巴胺的质谱图采用表格表示为表 10-1。

:::definition{label="质谱图、基峰、相对丰度"}
横坐标 $m/z$，纵坐标相对丰度。丰度最大的峰叫基峰，相对丰度定为 $100\%$。本版英文把 relative abundance 印成 relative abundant，不要另造术语。
:::

:::definition{label="多巴胺这张图要记住的两个数"}
基峰 $m/z=124$，相对丰度 $100\%$。分子离子 $M$（$153$）相对丰度 $13.33\%$；$M+1$（$154$）为 $1.48\%$。表 10-1 只收相对丰度 $>1\%$ 的峰。
:::

:::pitfall{label="基峰不一定是分子离子峰"}
多巴胺 $M_{\mathrm{r}}=153$，基峰却是 $124$。把最高峰写成分子量，第 5 节辨认分子离子会整节翻车。表里 $79$ 的 $0.05\%$ 低于 $1\%$，印刷仍列出，不要拿它当基峰。
:::

:::keypoint{label="第 2 节收到这里就可以进第 3 节"}
五块仪器 + 真空 + 一张 $m/z$–相对丰度图。下一节问这张图上的峰分别是分子离子、碎片、同位素、亚稳还是重排。
:::
