# 第1节　概述

第 11～14 章把分离写成固定相不动、流动相带着样品走。本章换一条驱动力：轴向直流电场。荷电粒子在电场里差速迁移，叫电泳；石英毛细管里溶剂整体被拖向阴极，叫电渗。二者叠在同一根细管里，就是高效毛细管电泳法。本节只立定义、简史和七条特点。双电层、Zeta 电位、淌度和谱带展宽放到第 2 节；CZE／MEKC／CEC 等模式放到第 3 节；仪器、进样和检测放到第 4 节。不要把高压泵和 $C_{18}$ 键合相提前写成第 14 章，也不要把平板凝胶电泳的灌胶步骤搬进来。

:::definition{label="电泳现象"}
溶液中的荷电粒子在电场作用下因排斥或吸引而发生差速迁移。本版把发现记在 1808 年俄国物理学家 Von Reuss。
:::

:::definition{label="毛细管电泳"}
毛细管电泳（capillary electrophoresis，CE），也称为高效毛细管电泳（high performance capillary electrophoresis，HPCE）。在细内径熔融石英毛细管中，用高电压做自由溶液电泳。英文按本版分开写，不要粘成 capillaryelectrophoresis。
:::

:::definition{label="高效毛细管电泳法"}
HPCE。与色谱方法并列的分离分析技术。高效来自细管限制焦耳热、柱上检测消除柱外效应、电渗扁平流型不扩张区带。这三笔的公式在第 2 节，本节只立「高效」这个名字。
:::

:::definition{label="毛细管区带电泳"}
毛细管区带电泳（capillary zone electrophoresis，CZE）。Jorgenson 和 Lukacs 从理论上阐述的第一种模式，也是第 3 节最基础、使用最广泛的模式。概述名单里排第一。
:::

:::concept{term="先问驱动力是不是电场，再问管径为什么必须细"}
看见 CE，先不要默写 van Deemter 的 $A$、$B$、$C$。户头是：没有高压泵推液体，靠电渗流和电泳淌度把区带送到检测窗。管径细是为了把焦耳热散掉，不是为了「看起来像气相毛细管柱」。把本章听成第 14 章 HPLC，电渗、Zeta 和进样歧视都会写丢；把本章听成平板凝胶电泳，高压电源和柱上紫外又会对空。
:::

:::insight{label="CE 与色谱并列，不是色谱的一种柱型"}
教材第一句对照是「作为与色谱方法并列的分析技术」。后面 MEKC、CEC 会借色谱的分配和固定相，那是第 3 节的模式，不是把 HPCE 改姓 chromatography。第 13 章气相毛细管柱走的是载气和固定液，不要和这里的开口石英管并户。
:::

## 一、从自由溶液电泳到毛细管

电泳技术起源于 19 世纪初。1808 年俄国物理学家 Von Reuss 首次发现电泳现象：溶液中的荷电粒子在电场作用下会因为受到排斥或吸引而发生差速迁移。1937 年瑞典科学家 Arne Tiselius 成功地把电泳技术用于人血清中不同蛋白质的分离，因此获得了 1948 年诺贝尔化学奖。传统电泳主要是凝胶电泳，因为凝胶可以抑制因热效应而导致的对流。如果在自由溶液中施加高的电压，就会导致大的焦耳热，严重影响分离。因此，人们一直致力于减小分离介质的尺寸，即分析仪器的微型化。

1981 年美国学者 Jorgenson 和 Lukacs 使用内径为 $75\,\mu\mathrm{m}$ 的石英毛细管，配合 $30\,\mathrm{kV}$ 的高电压进行自由溶液电泳，获得了高于每米 $40$ 万理论板数的分离柱效。他们不仅设计出了结构简单的仪器装置，还从理论上阐述了毛细管区带电泳（CZE）的分离机理。这一出色的工作标志着 CE／HPCE 作为一种新型分离分析技术的诞生。从此 CE 以其高效、快速、低成本等特点引起了广泛的关注，并在 20 世纪 80 年代后期迅速发展起来。CE 现已广泛应用于无机离子、中性分子、药物、多肽、蛋白质、DNA 及糖类等各类化合物的分析，并被认为是 20 世纪分析化学领域中最有影响的进步之一。20 世纪 90 年代后期出现的阵列 CE 技术作为基因测序的关键方法，在人类基因组计划中发挥了极其重要的作用。

:::definition{label="Tiselius 与血清蛋白"}
1937 年 Arne Tiselius 用电泳分开人血清中不同蛋白质，1948 年诺贝尔化学奖。扫描稿常把 Arne 打成 Arem，以印刷为准。这一笔给的是平板／自由溶液电泳的起点，不是 1981 年的毛细管。
:::

:::definition{label="凝胶电泳为什么能做、自由溶液为什么怕高压"}
传统电泳主要用凝胶，因为凝胶抑制热效应导致的对流。自由溶液里加高电压会产生大的焦耳热，分离被毁掉。毛细管的对策不是换一种凝胶，而是把内径降到几十微米，让热来得及散。
:::

:::definition{label="Jorgenson 和 Lukacs（1981）"}
内径 $75\,\mu\mathrm{m}$ 石英毛细管，$30\,\mathrm{kV}$，自由溶液电泳，柱效高于每米 $40$ 万理论板数。同时给出简单装置和 CZE 机理。扫描稿把「$40$ 万」打成「$40$ 方」，不要照着 OCR 抄。
:::

:::definition{label="阵列 CE 与人类基因组计划"}
20 世纪 90 年代后期，阵列 CE 作为基因测序的关键方法。第 6 节还会点 1995 年 Mathies 用毛细管微流控芯片做高速 DNA 测序。概述只挂「阵列 CE」这一句，不要把测序试剂方写成正文。
:::

:::pitfall{label="人名、年份和板数不要串档"}
Von Reuss 是 1808 年发现现象；Tiselius 是 1937 年血清蛋白、$1948$ 年奖；Jorgenson／Lukacs 是 1981 年毛细管。不要把诺贝尔奖写到 1981 年头上，也不要把每米 $40$ 万板数写成 HPLC 填充柱的每米 $4$ 万～$8$ 万。
:::

## 二、与传统电泳相比的七条特点

作为与色谱方法并列的分析技术，CE 与传统的电泳技术相比，具有以下特点。

**（1）应用范围广**　CE 既能分析有机和无机小分子，又能分析多肽和蛋白质等生物大分子；既能用于带电荷离子的分离，又能用于中性分子的测定，非常适用于复杂混合物的分离分析及药物对映异构体的纯度测定。中性分子这一句不要理解成 CZE 能拆开中性物——第 3 节写明中性溶质随电渗流一起走，CZE 分不开；要靠 MEKC、MEEKC 或 CEC。概述说「能用于中性分子的测定」，指的是整套 CE 模式，不是单指区带电泳。

**（2）分离效率高**　CE 采用内径 $25\sim 100\,\mu\mathrm{m}$ 的熔融石英毛细管柱，限制了电流的产生和管内发热，并采用柱上检测，大大消除了柱外效应。本版把电场强度印成 $100\sim 500\,\mathrm{V}\cdot\mathrm{m}^{-1}$，柱效可以达到每米几十万到上百万理论塔板数。后文仪器高压电源是 $30\,\mathrm{kV}$、有效长度常 $50\sim 75\,\mathrm{cm}$，对应电场大约 $4\times 10^{4}\sim 6\times 10^{4}\,\mathrm{V}\cdot\mathrm{m}^{-1}$（约 $400\sim 600\,\mathrm{V}\cdot\mathrm{cm}^{-1}$）。答题抓住「细管＋高电压＋每米几十万到上百万板」，不要死记成只能加几百伏每米。

**（3）分离模式多**　目前已经有毛细管区带电泳（CZE）、胶束电动毛细管色谱（MEKC）、毛细管凝胶电泳（CGE）、毛细管等速电泳（CITP）、毛细管等电聚焦（CIEF）和毛细管电色谱（CEC）等模式，而且容易实现各模式之间的切换。第 3 节分类名单换成 CZE、MEKC、CEC、非水毛细管电泳（NACE）、微乳电动色谱（MEEKC）、CGE，没有把 CITP、CIEF 展开。两份名单都按所在小节记，不要把概述六种强行塞进第 3 节，也不要在概述里编 CITP、CIEF 的操作细节。

**（4）最小检测限低**　虽然采用 $25\sim 100\,\mu\mathrm{m}$ 内径的毛细管，光学检测器的光程有限，用一般光吸收检测器时，以浓度表示的灵敏度尚不及 HPLC 高，但以样品绝对量表示的最小检测限却很低。迄今，分离分析领域的最低检测限是 CE 采用激光诱导荧光检测器（LIF）获得的，这也给单分子的检测提供了可能。

**（5）分析成本低**　毛细管本身成本低，且易于清洗；溶剂和试剂消耗量少，废液处理成本低；样品用量少，仅为纳升（$10^{-9}\,\mathrm{L}$）级，这对珍贵的样品尤其有利。

**（6）仪器简单**　只需要一个高压电源、一个检测器和一截毛细管就可组成一台简单的 CE 仪器，由于操作参数少，方法开发也较为简单。第 4 节会把温控、进样、电路和检测四块写全；概述这句是「最小配置」，不是说商品仪器没有自动进样。

**（7）环境友好**　因为分离介质多为水相，且产生的废液量很少，故对环境的影响很小。这符合绿色化学的要求。非水毛细管电泳（NACE）改用有机溶剂，是第 3 节为疏水样品开的旁路，不要用第 7 条去否定 NACE。

:::definition{label="柱上检测"}
检测窗开在毛细管壁上，区带还在管内就被测定。用来消除柱后混合和死体积造成的柱外效应。光程等于内径，所以浓度灵敏度往往不如 HPLC。
:::

:::definition{label="绝对量检测限与浓度灵敏度不要并户"}
一般紫外吸收：浓度灵敏度尚不及 HPLC；绝对进样量（纳升级）的检测限却很低。LIF 拿到分离分析领域迄今最低的检测限，并给单分子检测提供可能。不要答成「CE 的紫外一定比 HPLC 更灵」。
:::

:::definition{label="样品用量纳升级"}
仅为纳升（$10^{-9}\,\mathrm{L}$）级。第 4 节写整个柱体积一般只有 $4\sim 5\,\mu\mathrm{L}$，样品区带只有几纳升。两个数不要并成一个。
:::

:::keypoint{label="高效从哪里来（概述先挂三笔）"}
- 细内径限制电流和管内发热。
- 柱上检测，大大消除柱外效应。
- 电渗是扁平塞流，不扩张区带（图 15-3，第 2 节）。
:::

:::pitfall{label="内径三档不要并成一个数"}
概述写熔融石英毛细管内径 $25\sim 100\,\mu\mathrm{m}$。第 2 节讨论焦耳热时「目前采用的多是内径 $25\sim 75\,\mu\mathrm{m}$」。第 4 节仪器「最常用……内径为 $20\sim 75\,\mu\mathrm{m}$」。三句话出现的位置不同，默写时点名所在小节，不要合成「一律 $50\,\mu\mathrm{m}$」。
:::

:::pitfall{label="不要把本章答成第 14 章，也不要吞凝胶平板"}
HPLC 的泵、进样阀、梯度、键合相在第 14 章。CE 的「泵」是电渗流。传统凝胶电泳抑制对流，CE 用细管散热。扫描页旁的二维码、「动画」「拓展材料」、页眉「第15章　高效毛细管电泳法」、页码都不写入正文。本章到印刷页约 398（PDF 408）思考题／习题止。
:::
