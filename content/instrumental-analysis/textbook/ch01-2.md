# 第2节　仪器分析法的类型

第 1 节把仪器分析写成测物理或物理化学性质。性质是多种多样的，所以方法类型也很多。本版按所测量（或分析中所用）物质属性的不同，把常用仪器分析法分成五类：电化学分析法、光学分析法、色谱分析法、质谱法和其他仪器分析法。光学还要再拆成光谱法与非光谱法；色谱按两相状态、分离原理、固定相固定状态三条轴分类。不要把第 2 章电位分析法的细节提前写进来。

物质的物理或物理化学性质是多种多样的，所以仪器分析内容非常丰富。根据所测量（或分析中所用）物质属性的不同，将常用仪器分析法分为电化学分析法、光学分析法、色谱分析法、质谱法和其他仪器分析法。

:::definition{label="仪器分析法的分类钥匙"}
根据所测量（或分析中所用）物质属性的不同，常用仪器分析法分为电化学分析法、光学分析法、色谱分析法、质谱法和其他仪器分析法。
:::

:::concept{term="先问测的是哪一种属性，再问它落在五类里的哪一类"}
看见“仪器分析法的类型”，先不要背仪器型号。户头是物质属性：电参数走电化学，电磁辐射走光学，两相分配走色谱，气态离子的质荷比走质谱，热和核衰变等放进其他。把色谱听成“也是一种光谱”，或把质谱听成“称量元素的天平”，后面各章会对错入口。
:::

:::compare{title="常用仪器分析法五类（按所测属性）"}
| 类型 | 所依据的属性 | 本节先记住的测量对象 |
|------|----------------|----------------------|
| 电化学分析法 | 电化学原理和溶液的电化学性质及其变化 | 化学电池中的电阻（电导）、电位、电流、电荷量等 |
| 光学分析法 | 物质发射的电磁辐射，或电磁辐射与物质相互作用 | 从 $\gamma$ 射线到无线电波的电磁波谱；再分光谱法与非光谱法 |
| 色谱分析法 | 各组分在固定相和流动相中吸附能力、分配系数或其他亲和作用的差异 | 分离与测定一体化 |
| 质谱法 | 元素的质量与质荷比的关系 | 气态离子按质荷比 $m/z$ 分离，得质谱图 |
| 其他 | 热性质；核衰变产生的放射性辐射等 | 热分析；放射化学分析 |
:::

## 一、电化学分析法

电化学分析法是根据电化学原理和溶液的电化学性质及其变化规律建立的一类分析方法。溶液的电化学现象一般发生于化学电池中，所以测量时要将样品溶液构成化学电池的组成部分。通过测量该电池的某些电参数，如电阻（电导）、电位、电流、电荷量的变化等对待测物质进行分析。根据测量参数的不同，可分为电导分析法、电位分析法、电解和库仑分析法，以及伏安法和极谱法等。

:::definition{label="电化学分析法"}
电化学分析法根据电化学原理和溶液的电化学性质及其变化规律建立。溶液的电化学现象一般发生于化学电池中，测量时要将样品溶液构成化学电池的组成部分，再测该电池的某些电参数对待测物质进行分析。
:::

:::definition{label="电化学分析测量的电参数"}
教材点名的电参数是电阻（电导）、电位、电流、电荷量的变化等。
:::

:::compare{title="按测量参数划分的电化学分析法"}
| 方法 | 主要盯住的电参数 | 本节写到哪一笔 |
|------|------------------|----------------|
| 电导分析法 | 电阻（电导） | 列入分类，细节不在绪论展开 |
| 电位分析法 | 电位 | 列入分类；第 2 章才专讲电位分析法和永停滴定法 |
| 电解和库仑分析法 | 电荷量等 | 列入分类 |
| 伏安法和极谱法 | 电流等 | 列入分类 |
:::

:::pitfall{label="样品溶液必须成为化学电池的组成部分"}
电化学现象一般发生在化学电池里。不是把电极往烧杯边上一靠就算测过了，而是让样品溶液构成电池的一部分，再读电阻（电导）、电位、电流、电荷量。也不要把本节的名单提前写成第 2 章的电极、能斯特方程和永停滴定操作。
:::

:::note{label="电位分析法的专章在后面"}
本版第 2 章标题是“电位分析法和永停滴定法”。绪论只把电位分析法登记为电化学分析法的一种。不要在本节吞进第 2 章正文。
:::

## 二、光学分析法

光学分析法是根据物质发射的电磁辐射或电磁辐射与物质相互作用而建立起来的一类分析方法。这些电磁辐射包括从 $\gamma$ 射线到无线电波的所有电磁波谱范围。光学分析法一般可分为光谱法和非光谱法两大类。

:::definition{label="光学分析法"}
光学分析法根据物质发射的电磁辐射，或电磁辐射与物质相互作用而建立。电磁辐射覆盖从 $\gamma$ 射线到无线电波的所有电磁波谱范围。一般分为光谱法和非光谱法两大类。
:::

:::insight{label="光学分析不是只等于“可见光分光光度”"}
教材把电磁辐射写成从 $\gamma$ 射线到无线电波。紫外–可见、红外、核磁共振、X 射线荧光，都落在这一大类里。不要把“光学”听成只看得到的那一段可见光。
:::

### （一）光谱法

光谱法是通过测定物质的原子或分子的内部能级跃迁所产生的吸收、发射和散射等光谱的波长和强度来进行分析的，它带有物质结构的信息，所以根据特征谱线的波长可以进行定性分析；而光谱强度与物质的含量有关，故可进行定量分析。属于这一类的方法有紫外–可见分光光度法、红外光谱法、核磁共振波谱法、原子发射光谱法、分子荧光光谱法、分子磷光光谱法、化学发光法、激光拉曼光谱法、原子吸收分光光度法、原子荧光光谱法和 X 射线荧光光谱法等。

:::definition{label="光谱法"}
光谱法通过测定物质的原子或分子的内部能级跃迁所产生的吸收、发射和散射等光谱的波长和强度来进行分析。光谱带有物质结构的信息：特征谱线的波长用于定性，光谱强度与含量有关、用于定量。
:::

:::definition{label="光谱法定性与定量"}
根据特征谱线的波长可以进行定性分析；光谱强度与物质的含量有关，故可进行定量分析。钥匙是能级跃迁产生的吸收、发射和散射光谱。
:::

:::keypoint{label="本版列入光谱法的方法名单"}
- 紫外–可见分光光度法
- 红外光谱法
- 核磁共振波谱法
- 原子发射光谱法
- 分子荧光光谱法
- 分子磷光光谱法
- 化学发光法
- 激光拉曼光谱法
- 原子吸收分光光度法
- 原子荧光光谱法
- X 射线荧光光谱法
:::

:::pitfall{label="有“光谱”二字的不一定都已在这一名单里讲完"}
教材用“等”收尾，名单是这一类的代表，不是后文每一章的目录拷贝。定性看特征波长，定量看强度——这一条对光谱法通用。不要把核磁共振波谱法踢出光学分析，也不要把下面的折射、衍射误写成“也是光谱”。
:::

### （二）非光谱法

非光谱法不涉及光谱的测量，亦即不涉及能级的跃迁。它是通过测量电磁辐射与物质相互作用后某些基本性质（如折射、反射、干涉、衍射和偏振等）的变化来进行分析的。属于这类的方法有折射法、干涉法、旋光法、X 射线衍射法和电子衍射法等。

:::definition{label="非光谱法"}
非光谱法不涉及光谱的测量，亦即不涉及能级的跃迁。它通过测量电磁辐射与物质相互作用后某些基本性质（如折射、反射、干涉、衍射和偏振等）的变化来进行分析。
:::

:::compare{title="光谱法与非光谱法"}
| 项目 | 光谱法 | 非光谱法 |
|------|--------|----------|
| 是否涉及能级跃迁 | 涉及：原子或分子内部能级跃迁 | 不涉及能级跃迁，也不测光谱 |
| 读什么 | 吸收、发射、散射等光谱的波长和强度 | 折射、反射、干涉、衍射、偏振等基本性质的变化 |
| 定性／定量 | 特征波长定性，强度定量 | 本节按“性质变化”进行分析，不套用“谱线波长”那一套 |
| 本版举例 | 紫外–可见、红外、核磁共振波谱、原子发射、分子荧光、分子磷光、化学发光、激光拉曼、原子吸收、原子荧光、X 射线荧光等 | 折射法、干涉法、旋光法、X 射线衍射法、电子衍射法等 |
:::

:::pitfall{label="X 射线荧光和 X 射线衍射不要并户"}
X 射线荧光光谱法走光谱法（能级跃迁、荧光光谱）。X 射线衍射法走非光谱法（衍射，不涉及能级跃迁）。都用到 X 射线，不是同一种光学分析法。电子衍射法同样落在非光谱法。
:::

:::example{label="先问有没有能级跃迁，再判断是不是光谱法"}
同样是电磁辐射与物质相互作用：测原子吸收或分子荧光，读的是跃迁光谱的波长和强度，是光谱法；测旋光、折射或晶体衍射，读的是偏振、折射率或衍射花样，不测光谱，是非光谱法。不要看见“光学”两个字就把所有方法写成分光光度。
:::

## 三、色谱分析法

色谱分析法是一种有效的分离与测定一体化的仪器分析方法，它利用混合样品各组分在互不相溶的两相（固定相和流动相）中的吸附能力、分配系数或其他亲和作用的差异达到分离的目的。色谱法有多种分类方法：若按两相所处的状态，可分为气相色谱法、液相色谱法和超临界流体色谱法等；若按分离过程的原理，可分为吸附色谱法、分配色谱法、离子交换色谱法、分子排阻色谱法和亲和色谱法等；若按固定相的固定状态，则可分为柱色谱法和平面色谱法。

:::definition{label="色谱分析法"}
色谱分析法是一种有效的分离与测定一体化的仪器分析方法。它利用混合样品各组分在互不相溶的两相（固定相和流动相）中的吸附能力、分配系数或其他亲和作用的差异达到分离的目的。
:::

:::definition{label="固定相与流动相"}
色谱的两相互不相溶：一相固定，称为固定相；一相流动，称为流动相。分离靠各组分在两相中吸附能力、分配系数或其他亲和作用的差异，不是靠把混合物“一次蒸干”。
:::

:::insight{label="色谱的特别处是分离和测定写在同一套方法里"}
教材把色谱写成“分离与测定一体化”。电化学、光学、质谱常常先假定样品已经适于测量；色谱则先把各组分在两相中拆开，再测定。联用时，色谱负责拆开，光谱或质谱负责认出是谁——这一笔到第 3 节发展趋势还会再出现。
:::

:::compare{title="色谱法的三种分类轴"}
| 分类钥匙 | 分出的方法 | 记住什么 |
|----------|------------|----------|
| 两相所处的状态 | 气相色谱法、液相色谱法、超临界流体色谱法等 | 流动相是气体、液体还是超临界流体 |
| 分离过程的原理 | 吸附色谱法、分配色谱法、离子交换色谱法、分子排阻色谱法、亲和色谱法等 | 靠吸附、分配、离子交换、排阻还是亲和 |
| 固定相的固定状态 | 柱色谱法、平面色谱法 | 固定相装在柱里还是铺在平面上 |
:::

:::pitfall{label="三条分类轴不要并成一张名单"}
气相色谱可以是吸附色谱或分配色谱，也可以是柱色谱。问“这是哪一种色谱”时，先问题目用的是哪一把分类钥匙：两相状态、分离原理，还是固定相的固定状态。把“气相”和“分配”当成互斥选项，后文气相色谱法、高效液相色谱法会对错户头。
:::

:::keypoint{label="色谱三条轴各记全"}
- 按两相状态：气、液、超临界流体。
- 按分离原理：吸附、分配、离子交换、分子排阻、亲和。
- 按固定相状态：柱色谱、平面色谱。
:::

## 四、质谱法

质谱法是根据元素的质量与质荷比的关系来进行分析的方法。将样品转化为运动的气态离子，然后利用离子在电场或磁场中运动性质的差异，将其按质荷比（$m/z$）大小进行分离记录，即得质谱图。根据谱线的位置和谱线的相对强度来进行分析。

:::definition{label="质谱法"}
质谱法根据元素的质量与质荷比的关系来进行分析。将样品转化为运动的气态离子，利用离子在电场或磁场中运动性质的差异，按质荷比（$m/z$）大小分离记录，得到质谱图。
:::

:::definition{label="质谱图读什么"}
根据谱线的位置和谱线的相对强度来进行分析。位置对应 $m/z$，相对强度对应各离子的多少。
:::

:::pitfall{label="质谱不是把样品放在天平上称元素质量"}
教材先写“元素的质量与质荷比的关系”，紧接着就把操作写成：样品 → 运动的气态离子 → 电场或磁场中按 $m/z$ 分离 → 质谱图。称量的不是克数砝码，而是离子的质荷比。没有气态离子，就没有这一节的质谱。
:::

:::cause-effect{title="为什么必须先变成气态离子"}
- **因** 分离依据的是离子在电场或磁场中运动性质随 $m/z$ 的差异
- **果** 样品要先转化为运动的气态离子，才能按 $m/z$ 记录成质谱图；中性分子直接进磁场，这一套分不开
:::

## 五、其他仪器分析方法

五类里的“其他”在本版绪论只展开两支：热分析法和放射化学分析法。

### （一）热分析法

通过测定物质的质量、体积、热导或反应热与温度之间的关系而建立起来的一种分析方法。包括热重法、热滴定法、差热分析法等。

:::definition{label="热分析法"}
热分析法通过测定物质的质量、体积、热导或反应热与温度之间的关系而建立。包括热重法、热滴定法、差热分析法等。
:::

:::keypoint{label="热分析盯住的是对温度的关系"}
自变量是温度；因变量可以是质量、体积、热导或反应热。不要把热分析听成“只称失重”，也不要把它并进电化学的电荷量。
:::

### （二）放射化学分析法

利用核衰变过程中所产生的放射性辐射来进行分析的方法。包括放射活化分析法、同位素稀释法和免疫放射分析法等。放射性同位素经常作为示踪原子应用于生物和化学的研究中。

:::definition{label="放射化学分析法"}
放射化学分析法利用核衰变过程中所产生的放射性辐射来进行分析。包括放射活化分析法、同位素稀释法和免疫放射分析法等。
:::

:::definition{label="示踪原子"}
放射性同位素经常作为示踪原子应用于生物和化学的研究中。户头是同位素跟踪去向，不是把所有光学分析都改写成核辐射。
:::

:::pitfall{label="放射化学分析的辐射来自核衰变"}
扫描稿有时把“放射性”粘成“反射性”。本版这一段的方法名是放射化学分析法，辐射来自核衰变，不是光学里的反射。免疫放射分析法登记在这一类；第 3 节表 1-1 里 R. S. Yalow 的贡献写成开创放射免疫分析法，名称按各页原文记，不要在绪论里改写成同一种仪器。
:::

:::memory{label="五类仪器分析法一口清"}
- 电化学：样品进化学电池，读电阻（电导）、电位、电流、电荷量。
- 光学：从 $\gamma$ 射线到无线电波；光谱法看能级跃迁的波长和强度，非光谱法看折射、衍射、偏振等。
- 色谱：固定相＋流动相，分离与测定一体化；三条分类轴。
- 质谱：气态离子，按 $m/z$ 得质谱图。
- 其他：热分析（质量／体积／热导／反应热对温度）；放射化学（核衰变辐射；示踪原子）。
:::
