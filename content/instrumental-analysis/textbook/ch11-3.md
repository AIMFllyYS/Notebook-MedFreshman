# 第3节　色谱法基本理论

第 2 节把分离度写成 $R=2(t_{\mathrm{R}2}-t_{\mathrm{R}1})/(W_1+W_2)$。要使相邻两组分有足够的分离度，一方面需要两组分的保留时间有足够的差异——保留时间与分配系数相关，是组分热力学参数；另一方面要求色谱峰比较窄——峰宽与色谱动力学有关。因此色谱理论从热力学和动力学两方面展开，分别以塔板理论（plate theory）和速率理论（rate theory）作为代表。本节公式以本版为准。不要把塔板理论的适用边界和 van Deemter 方程的三项写反，也不要在这里扩成第 13、14 章的操作专章。

:::definition{label="分离度的两个来源"}
峰位差来自热力学（分配系数／保留因子）；峰宽来自动力学。塔板理论代表前者的平衡模型，速率理论代表后者的扩散与传质。
:::

:::concept{term="先问能不能分开，再问峰为什么变胖"}
看见 $R$，先拆成“两个峰离得远不远”和“每个峰瘦不瘦”。只改 $K$ 而不管流速，解决不了 $B/u$ 和 $Cu$；只降流速而不让 $\alpha>1$，两峰永远叠在一起。
:::

:::compare{title="塔板理论对速率理论"}
| | 塔板理论 | 速率理论 |
|--|----------|----------|
| 代表人物 | Martin 与 Synge（1941） | van Deemter |
| 问什么 | 平衡次数、流出曲线形状、$N$ 与 $H$ | $H$ 为什么随 $u$ 变 |
| 成功处 | 评价柱效、解释峰形和极大点位置 | 给出 $H=A+B/u+Cu$ |
| 做不到 | 解释流速与柱效；写出 $A$、$B$、$C$ 的来源 | 替代 $K$、$\alpha$ 那些热力学量 |
:::

## 一、塔板理论

塔板理论始于英国学者 Martin 和 Synge 在 1941 年提出的塔板模型。塔板理论把色谱柱比作精馏塔，假设在柱的某一段距离（$H$）所产生的分离效果相当于在精馏塔中一块塔板所完成的分离效果（即完成一次气液相平衡）。

:::definition{label="理论塔板高度"}
柱上某一段距离 $H$，其分离效果相当于精馏塔中一块塔板所完成的一次气液相平衡。
:::

:::insight{label="色谱与精馏的共同基础是分配系数差别"}
被分离组分在两相间的分配系数有差别。正常色谱柱上多次分配平衡后，分配系数最小的组分最先流出，从而与分配系数大的组分分离。图 11-1 的 A 先出、B 后出，和这里同一句话。
:::

### （一）基本假设

为了便于研究组分在两相间的分配行为，塔板理论做了一些理想的假设：

① 色谱柱由内径一致、填充均匀的若干块塔板组成，组分完成一次气液相平衡的距离相当于一块理论塔板高度；

② 流动相不是连续的而是脉冲式进入色谱柱，即一次只进入一块塔板体积；

③ 组分在每块塔板上的两相间瞬时达到平衡，分配系数在所有塔板上都为常数，与组分浓度无关；

④ 样品组分首先加在第 0 块塔板上，忽略塔板间的纵向分子扩散。

:::definition{label="塔板理论四条假设"}
内径一致、填充均匀；流动相脉冲进样（一次一块塔板体积）；瞬时平衡且 $K$ 为常数、与浓度无关；样品先加在第 0 块板，忽略板间纵向扩散。
:::

:::pitfall{label="四条假设里已经把速率理论要管的事排除了"}
“瞬时平衡”排除传质阻抗；“忽略纵向扩散”排除 $B/u$；“脉冲、与流速无关”排除流动相速度。后面批评塔板理论，不是另找缺点，就是这四条与实际不符。
:::

### （二）组分的分配平衡和迁移过程

以分配色谱为例，如图 11-6 所示，假设 A 与 B 两组分的混合物（$K_{\mathrm{A}}=2$，$K_{\mathrm{B}}=0.5$）进入色谱柱后先加载在第 0 块塔板上，完成一次分配平衡后，在流动相（载气）中分配的部分被第二份进入的流动相带入第一块塔板，进行第二次分配平衡。这一“平衡—流动相前移—平衡”的过程不断循环，直到组分流出色谱柱。图 11-6 显示的是经过四次分配平衡（$N=4$）后，组分 A（$K=2$）的浓度分布的极大值（流动相和固定相中质量分数分别为 $0.132$ 和 $0.263$）在第一块塔板上，而组分 B（$K=0.5$）的浓度分布的极大值（流动相和固定相中质量分数分别为 $0.263$ 和 $0.132$）在第三块塔板上。这说明分配系数小的 B 组分移动得快，先流出色谱柱；而分配系数大的 A 组分则相反。事实上，一根色谱柱的理论塔板数往往可以达到 $10^{3}$ 以上，因此通过反复多次的分配平衡，分配系数仅存在微小差异的两组分也能获得良好的分离。

::figure{src="/images/instrumental-analysis/textbook/p0293_01.jpg" caption="图11-6　分配色谱过程模型。$K_{\mathrm{A}}=2$、$K_{\mathrm{B}}=0.5$；从 $N=0$ 进样到 $N=4$，每块塔板分载气层与固定液层。$N=4$ 时 A 的极大在第 1 块板，B 的极大在第 3 块板。" alt="塔板号 0 到 4 的分配色谱模型表：每个 N 分进气与分配平衡两行，A、B 在载气和固定液中的质量分数"}

:::definition{label="平衡—前移—平衡"}
组分在第 0 块板分配后，流动相中的那一份被下一脉冲带入下一块板，再分配。循环直到出柱。
:::

:::keypoint{label="图 11-6 在 N=4 时记住两个极大"}
- A，$K=2$：极大在第 1 块板，流动相 $0.132$、固定相 $0.263$（固定相里更多，走得慢）。
- B，$K=0.5$：极大在第 3 块板，流动相 $0.263$、固定相 $0.132$（流动相里更多，走得快）。
- 真实柱 $N$ 常在 $10^{3}$ 以上，微小的 $K$ 差也能分开。
:::

:::pitfall{label="K 大的反而后出，不要按「K 大先出」记"}
$K=c_{\mathrm{s}}/c_{\mathrm{m}}$，$K$ 大说明固定相中浓度高，滞留多，后出柱。图 11-6 里 $K_{\mathrm{A}}=2$ 的极大还在第 1 块板，$K_{\mathrm{B}}=0.5$ 已经到第 3 块板。思考题第 9 题 $K_{\mathrm{A}}>K_{\mathrm{B}}>K_{\mathrm{C}}$ 则 $t_{\mathrm{R}}$ 也是 A 最大。
:::

:::note{label="图 11-6 是整页模型表，数字以印刷为准"}
进气次数与分配平衡交错排。不要用二项式自己重算一遍再宣称教材的 $0.132$、$0.263$ 印错。
:::

### （三）色谱流出曲线方程

用二项式分布式可以计算经过 $N$ 次分配后各塔板内组分分布的情况。以色谱柱出口处组分的浓度，对加入柱内的流动相体积数作图，就得到色谱流出曲线，即二项式分布曲线（图 11-7）。

::figure{src="/images/instrumental-analysis/textbook/p0294_01.jpg" caption="图11-7　二项式分布曲线。纵轴为分量 $X$，横轴为塔板号 $N$；塔板数很少时曲线不对称。同页给出流出曲线方程（11-14）～（11-17）。" alt="直方图加包络：X 对 N，峰在 N 约 8 附近，左侧较陡右侧拖尾"}

但此曲线的形状很不对称，这是由于塔板数太少的缘故。当塔板数大于 $50$ 时，流出曲线接近正态分布曲线。而一根色谱柱的塔板数在 $10^{3}$ 以上，常用正态分布方程式来讨论流出曲线的浓度（$c$）与时间（$t$）的关系：

$$
c = \frac{m}{V_{\mathrm{R}}}\sqrt{\frac{N}{2\pi}}\,\mathrm{e}^{-\frac{N}{2}\bigl(1-\frac{V}{V_{\mathrm{R}}}\bigr)^{2}} \tag{11-14}
$$

式中，$c$ 为与任意流动相体积 $V$ 时的组分浓度，$N$ 为理论塔板数，$V_{\mathrm{R}}$ 为组分的保留体积，$m$ 为组分的质量。式（11-14）称为色谱流出曲线方程。当 $V=V_{\mathrm{R}}$ 时，$c$ 有极大值：

$$
c_{\max} = \frac{m}{V_{\mathrm{R}}}\sqrt{\frac{N}{2\pi}} \tag{11-15}
$$

则

$$
c = c_{\max}\,\mathrm{e}^{-\frac{N}{2}\bigl(1-\frac{V}{V_{\mathrm{R}}}\bigr)^{2}} \tag{11-16}
$$

该式表示为 $c$ 与洗脱时间 $t$ 的关系：

$$
c = c_{\max}\,\mathrm{e}^{-\frac{N}{2}\bigl(1-\frac{t}{t_{\mathrm{R}}}\bigr)^{2}} \tag{11-17}
$$

式（11-15）及式（11-16）说明，$c_{\max}$ 与进样量和理论塔板数的平方根成正比，与溶质的保留值成反比；理论塔板数越高，色谱峰窄而高；保留值越大的色谱峰扁平，最大浓度低；色谱峰的区域宽度与保留时间存在近似的线性关系。实际的色谱流出曲线与上述描述一致。

:::definition{label="色谱流出曲线方程"}
式（11-14）。正态分布形式。$V=V_{\mathrm{R}}$ 时 $c=c_{\max}$。
:::

:::definition{label="cmax 跟什么成正比、跟什么成反比"}
与进样量 $m$、$\sqrt{N}$ 成正比，与保留值 $V_{\mathrm{R}}$ 成反比。$N$ 高则峰窄而高；保留值大则峰扁平、极大低。区域宽度与 $t_{\mathrm{R}}$ 近似线性。
:::

:::theorem{label="N>50 才接近正态"}
二项式分布在塔板数太少时不对称（图 11-7）。$N>50$ 接近正态；实际柱 $N$ 在 $10^{3}$ 以上，所以日常用式（11-14）～（11-17）。
:::

:::pitfall{label="不要用图 11-7 的偏态去否定正态公式"}
图 11-7 正是“塔板数太少”的反例。真实柱不会停在几十块板上。把流出曲线一律画成严重拖尾，再宣称塔板理论破产，和本版“实际曲线与上述描述一致”对着干。拖尾、前延是第 2 节对称因子的事，不是 $N$ 不够。
:::

### （四）塔板数和塔板高度

根据式（11-17），可以推导出理论塔板数（number of theoretical plates，$N$）与保留时间和区域宽度的关系：

$$
N = \left(\frac{t_{\mathrm{R}}}{\sigma}\right)^{2} = 5.54\left(\frac{t_{\mathrm{R}}}{W_{1/2}}\right)^{2} = 16\left(\frac{t_{\mathrm{R}}}{W}\right)^{2} \tag{11-18}
$$

由于 $t_0$ 不反映各组分与固定相相互作用的本质，应从保留值中扣除。以 $t'_{\mathrm{R}}$ 代替 $t_{\mathrm{R}}$ 后计算出来的塔板数值，称为有效塔板数（$N_{\mathrm{eff}}$）：

$$
N_{\mathrm{eff}} = \left(\frac{t'_{\mathrm{R}}}{\sigma}\right)^{2} = 5.54\left(\frac{t'_{\mathrm{R}}}{W_{1/2}}\right)^{2} = 16\left(\frac{t'_{\mathrm{R}}}{W}\right)^{2} \tag{11-19}
$$

塔板高度、柱长与塔板数之间的关系如下：

$$
H = \frac{L}{N} \tag{11-20}
$$

$$
H_{\mathrm{eff}} = \frac{L}{N_{\mathrm{eff}}} \tag{11-21}
$$

由此可以说明，峰越窄，色谱柱的塔板数越大，塔板高度越小，柱效越高。塔板数和塔板高度是广泛应用于色谱实践中评价色谱柱分离效率的指标，具有非常重要的理论与实用价值。

:::definition{label="理论塔板数"}
$N=(t_{\mathrm{R}}/\sigma)^{2}=5.54(t_{\mathrm{R}}/W_{1/2})^{2}=16(t_{\mathrm{R}}/W)^{2}$。
:::

:::definition{label="有效塔板数"}
$N_{\mathrm{eff}}$。用 $t'_{\mathrm{R}}$ 替换 $t_{\mathrm{R}}$。扣除了不反映固定相作用的死时间。
:::

:::definition{label="塔板高度与有效塔板高度"}
$H=L/N$，$H_{\mathrm{eff}}=L/N_{\mathrm{eff}}$。峰越窄，$N$ 越大，$H$ 越小，柱效越高。
:::

:::insight{label="5.54 和 16 从第 2 节宽度公式来"}
$W_{1/2}=2.355\sigma$，平方约 $5.54$；$W=4\sigma$，平方是 $16$。单位必须一致：例 11-3 把纸上的厘米先除以纸速，换成与 $t_{\mathrm{R}}$ 相同的分钟。
:::

:::example{label="例11-3 苯的塔板数和塔板高度"}
在 $2\,\mathrm{m}$ 长的 $5\%$ 阿皮松柱上，柱温 $100^{\circ}\mathrm{C}$，色谱图标尺为 $2.0\,\mathrm{cm}\cdot\mathrm{min}^{-1}$，测得苯的保留时间为 $1.5\,\mathrm{min}$，半峰宽为 $0.20\,\mathrm{cm}$。求理论塔板数和理论塔板高度。

**解：** 半峰宽先换成时间：$0.20/2.0=0.10\,\mathrm{min}$。

$$
N_{\text{（苯）}}=5.54\left(\frac{t_{\mathrm{R}}}{W_{1/2}}\right)^{2}=5.54\left(\frac{1.50}{0.20/2.0}\right)^{2}=1247
$$

$$
H_{\text{（苯）}}=\frac{L}{N}=\frac{2000\,\mathrm{mm}}{1247}=1.6\,\mathrm{mm}
$$
:::

:::pitfall{label="半峰宽若是长度，必须先除以纸速"}
例 11-3 的 $0.20\,\mathrm{cm}$ 不是 $0.20\,\mathrm{min}$。直接 $5.54(1.50/0.20)^{2}$ 会得到假的大塔板数。有效塔板数还要用 $t'_{\mathrm{R}}$，本例没给 $t_0$，就不要冒充 $N_{\mathrm{eff}}$。
:::

:::keypoint{label="塔板理论能做什么、不能做什么"}
能：评价柱效；解释流出曲线形状和浓度极大点位置。不能：解释流动相速度与柱效的关系；说明 $H$ 受哪些具体因素影响。缺的那一笔，由速率理论补。
:::

## 二、速率理论

塔板理论在评价柱效、解释流出曲线的形状及浓度极大点的位置等方面是成功的。但由于它的某些假设，如分配系数与浓度无关（事实上只能在有限的浓度范围内成立）、纵向扩散可以忽略等与实际色谱过程不符。而且它还排除了一个极其重要的参数——流动相速度，因而不能解释流动相速度与柱效的关系。它更未阐述影响塔板高度的原因。从本质上说，塔板理论的缺陷在于忽视了组分分子在两相中扩散和传质的动力学过程。因此它不能解释许多实验事实，导致了用它来研究组分谱带在迁移中的物理过程的失败。

为了克服塔板理论的不足，荷兰学者 van Deemter 提出的速率理论，充分考虑了组分在两相间达到分配平衡的实际速率，即组分在两相间的扩散和传质过程，导出板高（$H$）与流动相速度（$u$）的关系，以及影响板高的三项主要因素，提出 van Deemter 方程（范氏方程）：

$$
H = A + B/u + Cu \tag{11-22}
$$

式中，$A$、$B$、$C$ 为常数，式中三项分别代表涡流扩散、纵向扩散和传质阻抗对塔板高度的贡献。

:::theorem{label="van Deemter 方程（范氏方程）"}
$H=A+B/u+Cu$。$A$ 涡流扩散，$B/u$ 纵向扩散，$Cu$ 传质阻抗。$u$ 是流动相线速度。
:::

:::pitfall{label="不要把塔板理论的成功处一笔勾销"}
本版先承认它评价柱效、解释峰形和极大点是成功的，再指出流速和动力学这一头失败。答题若只写“塔板理论完全错误”，和教材分寸不一致。速率理论解释的是 $H$ 随 $u$ 怎么变，不是另给一套 $K$。
:::

:::note{label="扫描页旁的三个动画不写入"}
涡流扩散、分子扩散、传质阻抗各有二维码。按本章惯例不把二维码后的动画正文编进来。
:::

### （一）涡流扩散

涡流扩散（eddy diffusion）项也称为多径扩散项。在填充色谱柱中，当同一个组分分子随流动相沿色谱柱方向向前迁移时，由于受到固定相颗粒不规则性的阻碍，不断改变流动方向，形成类似于“涡流”的流动，组分中各分子经过不同长度的路径流出色谱柱，导致谱带展宽。涡流扩散引起的峰扩张示意见图 11-8。

::figure{src="/images/instrumental-analysis/textbook/p0296_01.jpg" caption="图11-8　涡流扩散对峰展宽的影响。①②③为不同分子流经的路径：有的近直穿，有的绕颗粒多走。同页给出 $A=2\lambda d_{\mathrm{p}}$、$B=2\gamma D_{\mathrm{g}}$ 及传质过程叙述。" alt="填充柱剖面：三条路径绕过不规则颗粒，路径长度不同"}

涡流扩散项可表示为

$$
A = 2\lambda d_{\mathrm{p}} \tag{11-23}
$$

式中，$d_{\mathrm{p}}$ 为填充颗粒的平均直径，$\lambda$ 为填充不规则因子。由式（11-23）可知，采用细颗粒且粒度范围窄的固定相，均匀填充，则可缩小 $A$ 值，即缩小此项展宽程度。但要避免采用过细颗粒，造成柱阻力过大，渗透性变差。

:::definition{label="涡流扩散"}
eddy diffusion，又称多径扩散。同一组分分子因颗粒不规则而走不同长度的路径，谱带展宽。$A=2\lambda d_{\mathrm{p}}$，与流速无关。
:::

:::definition{label="填充不规则因子"}
$\lambda$。颗粒填充得越乱，$\lambda$ 越大，$A$ 越大。
:::

:::keypoint{label="怎样缩小 A"}
细颗粒、粒度范围窄、均匀填充。过细则阻力过大、渗透性变差。第 4 节写颗粒已经小于 $2\,\mu\mathrm{m}$，对仪器耐压提出更高要求，户头就在“不要过细”这一句的反面。
:::

### （二）纵向扩散

van Deemter 方程中第二项 $B/u$ 为纵向扩散项或分子扩散项，是指沿色谱柱方向的扩散，它是由浓度梯度造成的。组分进入色谱柱后，在色谱柱内很小的空间呈“塞子”状。它随流动相向前推进，由于“塞子”前后存在浓度梯度，必然自发地向前和向后扩散，造成谱带展宽。常数 $B$ 为纵向扩散系数：

$$
B = 2\gamma D_{\mathrm{g}} \tag{11-24}
$$

式中，$\gamma$ 为弯曲因子，亦称阻碍因子，它反映固定相颗粒的几何形状对自由分子扩散的阻碍情况，一般小于 $1$。$D_{\mathrm{g}}$ 为组分在流动相中的扩散系数，与温度成正比，与流动相的黏度成正比，而黏度又与相对分子质量的平方根成反比。如同一组分在氢气中的扩散系数要大于在氮气中的扩散系数。为降低纵向扩散，可选择合适的流动相、提高流动相速度、降低柱温，以提高柱效。

:::definition{label="纵向扩散"}
longitudinal diffusion，又称分子扩散。沿柱方向，由“塞子”前后的浓度梯度造成。项是 $B/u$，$B=2\gamma D_{\mathrm{g}}$。
:::

:::definition{label="弯曲因子"}
$\gamma$，亦称阻碍因子。反映颗粒几何形状对自由分子扩散的阻碍，一般小于 $1$。
:::

:::definition{label="本版 Dg 的三句"}
$D_{\mathrm{g}}$ 与温度成正比，与流动相的黏度成正比，而黏度又与相对分子质量的平方根成反比。同一组分在氢气中的扩散系数大于在氮气中的扩散系数。
:::

:::insight{label="B/u 所以流速越高，纵向扩散贡献越小"}
停留时间短，来不及扩散。降低纵向扩散：选合适流动相、提高流速、降低柱温。这和传质阻抗要低流速是对着的，所以后面会有一个 $u_{\mathrm{opt}}$。
:::

:::pitfall{label="氢气里 Dg 更大，不等于氢气一定柱效更高"}
$D_{\mathrm{g}}$ 大则 $B$ 大，低流速时纵向扩散更严重；$D$ 大对传质阻抗却有利。本版这一段只讨论纵向扩散，不要顺手把第 14 章载气选择整章搬进来。
:::

### （三）传质阻抗

van Deemter 方程第三项 $Cu$ 为传质阻抗项。$C$ 为传质阻抗系数，它为流动相传质阻抗系数（$C_{\mathrm{m}}$）和固定相传质阻抗系数（$C_{\mathrm{s}}$）之和。组分被流动相带入色谱柱后，由两相界面进入固定相内部，进而达到动态分配“平衡”。当纯净的或含有低于某组分“平衡”浓度的流动相到来时，固定相中该组分的分子将逐次回到两相界面，而被流动相带走（转移）。这种溶解、扩散、转移的过程称为传质过程。影响此过程进行的阻力，称为传质阻抗或传质阻力。由于传质阻抗的存在，组分不能在两相间瞬间达到平衡，在固定相中停留时间增加的组分分子落后于随同流动相流动的分子，使峰展宽。

在气液色谱中，$C$ 为气相传质阻抗系数（$C_{\mathrm{g}}$）和液相传质阻抗系数（$C_{\mathrm{l}}$）之和。$C_{\mathrm{g}}$ 很小，可忽略：

$$
C \approx C_{\mathrm{l}} = \frac{2k}{3(1+k)^{2}}\cdot\frac{d_{\mathrm{f}}^{2}}{D_{\mathrm{l}}} \tag{11-25}
$$

式中，$k$ 为保留因子，$d_{\mathrm{f}}$ 为固定液液膜厚度，$D_{\mathrm{l}}$ 为组分在固定液中的扩散系数。因此降低固定液液膜厚度（$d_{\mathrm{f}}$）是减小传质阻抗系数的主要方法。$d_{\mathrm{f}}$ 还影响 $k$ 值，$d_{\mathrm{f}}$ 小，则 $k$ 越小。在能完全覆盖载体表面的前提下，可适当减少固定液的用量。但也不能太少，造成柱寿命短。

:::definition{label="传质过程"}
溶解、扩散、转移。组分进入固定相内部达到动态分配，再回到界面被流动相带走。
:::

:::definition{label="传质阻抗"}
mass transfer resistance。影响传质过程的阻力。使组分不能瞬间达平衡，落后的分子把峰展宽。项是 $Cu$。
:::

:::definition{label="气液色谱中的 C"}
$C=C_{\mathrm{g}}+C_{\mathrm{l}}$，$C_{\mathrm{g}}$ 很小可忽略。$C\approx C_{\mathrm{l}}=\dfrac{2k}{3(1+k)^{2}}\cdot\dfrac{d_{\mathrm{f}}^{2}}{D_{\mathrm{l}}}$。
:::

:::keypoint{label="减小 C 的主要办法"}
降低液膜厚度 $d_{\mathrm{f}}$。完全覆盖载体的前提下适当减少固定液用量；太少则柱寿命短。$d_{\mathrm{f}}$ 小则 $k$ 也小，和分离度公式里的容量项会打架，后面 $k$ 取 $1\sim 10$ 就是在兼顾。
:::

:::compare{title="A、B/u、Cu 三项"}
| 项 | 名称 | 本版公式 | 与 $u$ | 主要缩小办法 |
|----|------|----------|--------|----------------|
| $A$ | 涡流／多径 | $2\lambda d_{\mathrm{p}}$ | 无关 | 细而匀的颗粒，均匀填充 |
| $B/u$ | 纵向／分子扩散 | $B=2\gamma D_{\mathrm{g}}$ | 反比 | 提高 $u$、降低柱温、选合适流动相 |
| $Cu$ | 传质阻抗 | $C\approx C_{\mathrm{l}}\propto d_{\mathrm{f}}^{2}/D_{\mathrm{l}}$ | 正比 | 薄液膜、较大 $D_{\mathrm{l}}$、低流速 |
:::

:::pitfall{label="前一页 Cm、Cs 与后一页 Cg、Cl 是同一件事的两套称呼"}
一般叙述：流动相 $C_{\mathrm{m}}$＋固定相 $C_{\mathrm{s}}$。气液色谱：气相 $C_{\mathrm{g}}$＋液相 $C_{\mathrm{l}}$，且 $C_{\mathrm{g}}$ 可忽略。不要当成四项相加。
:::

### （四）流速对板高的影响

由 van Deemter 方程可知，板高 $H$ 与流动相速度之间的关系曲线如图 11-9 所示。由于 $H$ 是三个独立展宽过程所贡献的塔板高度的总和，因此一个由三个独立函数总起来的 $H$–$u$ 图，可以分解为三个相互独立的函数的图像。

::figure{src="/images/instrumental-analysis/textbook/p0297_01.jpg" caption="图11-9　板高–流速曲线。纵轴 $H$，横轴 $u$；最低点为 $(u_{\mathrm{opt}},H_{\min})$。三项贡献：1—$B/u$；2—$Cu$；3—$A$（水平）。" alt="H-u 曲线呈 U 形，最低点标 Hmin 和 uopt；三条虚线分别为 B/u、Cu 和水平的 A"}

在 $H$–$u$ 曲线上有一最低点，在此点兼顾了纵向扩散项和传质阻抗项，使两者之和最小。与该点相应的 $H$ 值和 $u$ 值分别称为最小塔板高度（$H_{\min}$）和最佳线速度（$u_{\mathrm{opt}}$）。该点可通过对 van Deemter 方程求极值得到：

$$
\frac{\mathrm{d}H}{\mathrm{d}u} = -\frac{B}{u^{2}} + C = 0
$$

$$
u_{\mathrm{opt}} = \sqrt{B/C} \tag{11-26}
$$

$$
H_{\min} = A + 2\sqrt{BC} \tag{11-27}
$$

当 $u\ge u_{\mathrm{opt}}$ 时，传质阻抗项 $Cu$ 对 $H$ 值的影响逐渐处于控制地位。为了减小传质阻抗，宜采用低流速、较低固定液量、较高柱温及具有较大 $D_{\mathrm{l}}$ 的固定液。

当 $u\le u_{\mathrm{opt}}$ 时，分子扩散项 $B/u$ 对 $H$ 值的影响处于控制地位。为了降低纵向扩散，此时应采用较高流速、较低柱温及相对分子质量较大的物质作流动相。

:::definition{label="最佳线速度与最小塔板高度"}
$H$–$u$ 曲线最低点：$u_{\mathrm{opt}}=\sqrt{B/C}$，$H_{\min}=A+2\sqrt{BC}$。此点纵向扩散与传质阻抗之和最小。
:::

:::derivation{title="由 dH/du=0 得到 uopt"}
$H=A+B/u+Cu$，对 $u$ 求导，$A$ 常数掉，$B/u$ 得 $-B/u^{2}$，$Cu$ 得 $C$。令导数为零：$C=B/u^{2}$，即 $u_{\mathrm{opt}}=\sqrt{B/C}$。代回 $H$：$H_{\min}=A+B/\sqrt{B/C}+C\sqrt{B/C}=A+\sqrt{BC}+\sqrt{BC}=A+2\sqrt{BC}$。
:::

:::compare{title="曲线两侧对策不要写反"}
| 区间 | 控制项 | 本版对策 |
|------|--------|----------|
| $u\ge u_{\mathrm{opt}}$ | $Cu$ 传质 | 低流速、较低固定液量、较高柱温、较大 $D_{\mathrm{l}}$ 的固定液 |
| $u\le u_{\mathrm{opt}}$ | $B/u$ 纵向扩散 | 较高流速、较低柱温、相对分子质量较大的流动相 |
:::

:::pitfall{label="高流速控制项是传质阻抗，不是纵向扩散"}
思考题第 7 题专门问这一点。$B/u$ 在低流速变大；$Cu$ 在高流速变大。把两侧对策对调，柱温、载气分子量会全部答反。$A$ 是水平线，不随 $u$ 变，但过细颗粒会把整条曲线抬高并增加柱压。
:::

:::memory{label="H-u 曲线像一只碗"}
碗底是 $u_{\mathrm{opt}}$。左边 $B/u$ 往上翘，右边 $Cu$ 往上翘，碗深由 $A$ 垫底。想把碗底压低：颗粒细而匀（降 $A$）、液膜薄（降 $C$）。
:::

## 三、提高分离度的方法

色谱条件选择的最后效果要视最难分离物质对的分离情况而定，色谱分析用分离度 $R$ 来衡量两物质分离的程度。

根据式（11-12），假设色谱峰为正常峰，且 $W_1\approx W_2$。分离度与柱效（$N$）、分配系数比（$\alpha$）及保留因子（$k$）间关系如下：

$$
R = \frac{\sqrt{N_2}}{4}\left(\frac{\alpha-1}{\alpha}\right)\left(\frac{k_2}{1+k_2}\right) \tag{11-28}
$$

式中，$(a)$ 为柱效项，$(b)$ 为柱选择性项，$(c)$ 为柱容量项；$N_2$、$k_2$ 分别为色谱柱上相邻两组分的第二组分的理论塔板数和保留因子，$\alpha$ 为分离因子。

由式（11-28）可以看出，若 $K_1=K_2$，则 $\alpha=1$，$(\alpha-1)/\alpha=0$，无法分离。这也证明了分配系数不等是分离的前提。在 $K_1\neq K_2$ 的前提下，$N$、$\alpha$ 及 $k_2$ 越大，分离度越大。但三个参数对 $R$ 的影响有所不同：$N$ 影响峰胖瘦，$\alpha$ 影响峰间距，$k$ 影响峰位，如图 11-10 所示。

::figure{src="/images/instrumental-analysis/textbook/p0298_01.jpg" caption="图11-10　保留因子（$k$）、柱效（$N$）及分离因子（$\alpha$）对分离度的影响。自上而下：原始状态；增加 $k$（两峰右移）；增加 $N$（峰变瘦）；增加 $\alpha$（峰间距拉开）。横轴为 $t$。" alt="四条流出曲线：原始两峰部分重叠；增 k 后峰右移仍重叠；增 N 后峰变窄分开；增 α 后两峰间距明显增大"}

在分离度的三项影响因素中，虽然 $N$ 也受流动相流速的影响，但其主要由色谱柱的性能（固定相的粒度与粒度分布、固定液涂层厚度、柱填充均匀程度及柱长等）所决定。根据式（11-28），当其他色谱条件不变，即理论塔板高度（$H$）不变，仅改变柱长时，有

$$
\frac{R_2}{R_1} = \sqrt{\frac{N_2}{N_1}} = \sqrt{\frac{L_2}{L_1}} \tag{11-29}
$$

式中，$R_2$、$R_1$ 及 $N_2$、$N_1$ 分别是柱长为 $L_2$、$L_1$ 上的分离度和理论塔板数。因此当柱长增加 1 倍，则分离度为原来的 $1.4$ 倍。但增加柱长会使分析时间延长，并使柱压增加，对仪器的耐压性能提出更高的要求。

$\alpha$ 主要受固定相和流动相种类影响，选择不同性质的固定相和流动相，才有可能使几个被分离组分与固定相的分子间作用力存在着差别，而使这些组分的 $\alpha$ 增大。而 $k$ 主要受固定相用量和柱温所左右。一般增大 $k$，分离度提高，但分析时间也增长，因此为了兼顾分析时间和分离度，一般 $k$ 值范围为 $1\sim 10$。式（11-28）是一个很有指导意义的公式。它能提示分离度不佳的症结所在，对症改变实验条件以改善分离度。

:::definition{label="分离度三因子公式"}
$R=\dfrac{\sqrt{N_2}}{4}\cdot\dfrac{\alpha-1}{\alpha}\cdot\dfrac{k_2}{1+k_2}$。$(a)$ 柱效项，$(b)$ 选择性项，$(c)$ 容量项。第二组分的 $N$ 和 $k$。
:::

:::definition{label="三参数各管峰的哪一头"}
$N$ 影响峰胖瘦，$\alpha$ 影响峰间距，$k$ 影响峰位。图 11-10 自上而下就是这三笔。
:::

:::definition{label="柱长加倍，R 变为 1.4 倍"}
$H$ 不变时 $R\propto\sqrt{L}$。$L$ 加一倍，$R$ 为原来的 $\sqrt{2}\approx 1.4$ 倍。代价：时间延长、柱压增加、耐压要求提高。
:::

:::definition{label="α、k 各受什么左右"}
$\alpha$：固定相和流动相种类（分子间作用力差别）。$k$：固定相用量和柱温。兼顾时间与分离度，一般 $k$ 取 $1\sim 10$。
:::

:::compare{title="R 不好时对症改哪一项"}
| 症结 | 图 11-10 看起来 | 改什么 |
|------|-----------------|--------|
| 峰太胖 | 需要增 $N$ | 粒度、粒度分布、液膜、填充、柱长、流速靠近 $u_{\mathrm{opt}}$ |
| 两峰太近 | 需要增 $\alpha$ | 换固定相或流动相种类 |
| 出峰太早、贴着 $t_0$ | 需要增 $k$ | 固定相用量、柱温；$k$ 不要远超 $10$ |
| $\alpha=1$ | 怎样加柱长都分不开 | 先让 $K_1\neq K_2$，否则式（11-28）中间项为零 |
:::

:::example{label="例11-4 苯与甲苯：α、k 和加长柱"}
在 $2.0\,\mathrm{m}$ 长的某色谱柱上，分析苯（1）与甲苯（2）的混合物。测得死时间为 $0.20\,\mathrm{min}$，甲苯的保留时间为 $2.10\,\mathrm{min}$ 及半峰宽为 $0.285\,\mathrm{cm}$，记录纸速为 $2\,\mathrm{cm}\cdot\mathrm{min}^{-1}$。已知苯比甲苯先流出色谱柱，且苯与甲苯的分离度为 $1.0$。求：（1）甲苯与苯的分离因子（$\alpha$）；（2）苯的保留因子与保留时间；（3）达到 $R=1.5$ 所需的柱长。

**解：**

（1）$k_{\text{甲苯}}=(2.10-0.20)/0.20=9.5$

$N_{\text{甲苯}}=5.54\times\bigl(2.10/(0.285/2.00)\bigr)^{2}=1203$

$R=\dfrac{\sqrt{N}}{4}\cdot\dfrac{\alpha-1}{\alpha}\cdot\dfrac{9.5}{1+9.5}=1.0$，得 $\alpha=1.15$

（2）$k_{\text{苯}}=9.5/1.15=8.26$，$t_{\text{苯}}=t_0(1+k_{\text{苯}})=0.20\times(1+8.26)=1.9\,\mathrm{min}$

（3）$L_2=L_1\times(1.5/1.0)^{2}=2.0\,\mathrm{m}\times 2.25=4.5\,\mathrm{m}$
:::

:::pitfall{label="由 R1 到 R2 加柱长，比的是平方而不是 1.4 口诀硬套"}
式（11-29）：$R\propto\sqrt{L}$，所以 $L_2/L_1=(R_2/R_1)^{2}$。例 11-4 从 $1.0$ 到 $1.5$，柱长变为 $2.25$ 倍，得 $4.5\,\mathrm{m}$。口诀“加倍得 $1.4$ 倍”只适用于 $L$ 加一倍那一种情况，不要反过来把 $R$ 乘 $1.5$ 当成 $L$ 乘 $1.5$。
:::

:::pitfall{label="α=1 时加再长的柱也分不开"}
式（11-28）中间项为零。这是第 2 节“分配系数不等是分离的前提”的定量说法。先换固定相或流动相种类把 $\alpha$ 做大，再谈 $N$ 和 $k$。
:::

:::insight{label="式（11-28）是一张诊断表"}
本版原话：它能提示分离度不佳的症结所在，对症改变实验条件。图 11-10 三行不是三种新方法，是三项各自的外观。
:::

:::memory{label="第3节收口"}
- 塔板：四条假设；$N=5.54(t_{\mathrm{R}}/W_{1/2})^{2}=16(t_{\mathrm{R}}/W)^{2}$；$H=L/N$。评价柱效成功，解释不了流速。
- 速率：$H=A+B/u+Cu$；$u_{\mathrm{opt}}=\sqrt{B/C}$；$H_{\min}=A+2\sqrt{BC}$。高流速看 $Cu$，低流速看 $B/u$。
- 分离度：$R=\sqrt{N_2}/4\cdot(\alpha-1)/\alpha\cdot k_2/(1+k_2)$；$k$ 常取 $1\sim 10$；柱长加倍 $R$ 变为约 $1.4$ 倍。
:::
