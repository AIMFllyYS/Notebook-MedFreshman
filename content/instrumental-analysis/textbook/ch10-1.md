# 第1节　概述

本章打开质谱分析法。先把方法写成：把样品中的分子或原子离子化成气相离子，再按各种离子的质荷比（mass-to-charge ratio，$m/z$）及其丰度做定性、定量分析。英文按本版写成 mass spectrometry，缩写 MS。四大波谱里它常和紫外–可见、红外、核磁共振联用，但严格说来质谱既不是光谱也不是波谱，它是质量谱：过程相似、机理不同。离子源、质量分析器、检测器和真空放到第 2 节；离子类型和裂解规律放到第 3 节。不要把第 11 章色谱导论提前搬进来。

质谱分析法（mass spectrometry，MS）是将样品中的分子或原子通过离子化后变成气相离子，然后根据各种离子的质荷比（mass-to-charge ratio，$m/z$）及其丰度的不同进行定性、定量分析的一种实验技术。目前，质谱分析法已经成为仪器分析领域发展最快的一种分析技术。在有机分子的结构测定中，它常常和紫外–可见分光光度法、红外光谱法和核磁共振波谱法联合使用，统称为“四大波谱”。

:::definition{label="质谱分析法"}
质谱分析法（mass spectrometry，MS）将样品中的分子或原子离子化成气相离子，再根据各种离子的质荷比 $m/z$ 及其丰度做定性、定量分析。
:::

:::definition{label="质荷比"}
质荷比（mass-to-charge ratio，$m/z$）是离子质量与其所带电荷数之比。质谱横坐标用 $m/z$，不要写成“分子量坐标”。
:::

:::note{label="英文不要粘连"}
本版英文写成 mass spectrometry、mass-to-charge ratio，都是分词。扫描稿里的 massspectrometry、mass-to-chargeratio 是 OCR 粘连，不是另一个方法名。
:::

:::concept{term="先问谁被做成气相离子、按什么分开，再问峰高是什么"}
看见 MS，先不要跳到四极杆型号或数据库检索。户头是：样品分子（或原子）先变成气相离子，再按 $m/z$ 分开，峰高反映丰度。把质谱听成“又一张吸收光谱”，后面离子源、质量分析器那几笔都会对错户头。
:::

但是，严格意义上来说，质谱分析法既不是光谱，也不是波谱，它是一种质量谱。它是通过样品导入系统将样品导入离子源，在离子源中样品分子形成 $m/z$ 不同的各种离子，并经加速后进入质量分析器，从而使各种不同 $m/z$ 的离子分离并依次进入检测器，产生信号响应。因此，质谱分析法与光谱分析法或波谱分析法是“过程相似，但机理不同”的两种分析技术：质谱仪中的离子源相当于光谱仪中的光源，质量分析器相当于光谱仪的单色器。

:::definition{label="质量谱，不是光谱"}
严格说来质谱既不是光谱，也不是波谱，它是质量谱。样品导入 → 离子源生成不同 $m/z$ 的离子 → 加速后进质量分析器按 $m/z$ 分开 → 检测器出信号。
:::

:::compare{title="质谱对光谱／波谱：过程相似，机理不同"}
| 项目 | 光谱／波谱（UV、IR、NMR） | 质谱（MS） |
|------|---------------------------|------------|
| 测的是什么 | 能级跃迁对电磁辐射的吸收或共振 | 气相离子按 $m/z$ 分开后的丰度 |
| 谱的本质 | 光谱或波谱 | 质量谱 |
| 光源这一块 | 光源提供辐射 | 离子源把样品做成离子 |
| 分开这一块 | 单色器（或磁场）按波长／频率分开 | 质量分析器按 $m/z$ 分开 |
| 过程 | 导入 → 作用 → 色散 → 检测 | 导入 → 离子化 → 按 $m/z$ 分开 → 检测 |
:::

:::pitfall{label="四大波谱里不要把质谱写成第四种吸收光谱"}
教材把 UV、IR、NMR、MS 统称“四大波谱”，紧接着就分户：质谱不是光谱、也不是波谱。相似的是“导入—作用—分开—检测”这条过程，不是“都在吸光”。把离子源听成氘灯、把质量分析器听成光栅，第 2 节整节都会错户。
:::

:::insight{label="离子源对光源，质量分析器对单色器"}
教材把对应关系写死：离子源 ≡ 光源，质量分析器 ≡ 单色器。后面电子轰击源、四极杆、飞行时间，都是在填这两块，不是另起炉灶。
:::

:::cause-effect{title="为什么概述就要写下“机理不同”"}
- **因** 质谱分开的是气相离子的 $m/z$，不是光子的波长
- **果** 必须有离子源和真空，必须谈分子离子、碎片离子和裂解，不能把朗伯–比尔定律或化学位移套进来
:::

## 一、简史

19 世纪 90 年代末期，J. J. Thomson 和 Wien（见图 10-1）分别由于在电子 $m/z$ 的测定及在阳极射线的磁偏转现象方面做出杰出贡献，获得 1906 年和 1911 年的诺贝尔物理学奖。此后，在 1912—1913 年间，J. J. Thomson 等研究了大气的质谱，并采用质谱确定了氖的同位素 $^{22}\mathrm{Ne}$ 的存在，从而证实了“元素具有同位素”这一观点。

目前已知最早的质谱仪是 1918 年由 A. J. Dempster 设计的，其提出的质谱仪基本原理和设计理念一直沿用到今天。1942—1946 年的“曼哈顿计划”（Manhattan Project）中，Ernest O. Lawrence 开发了电磁型同位素分离器用于铀的同位素分离，从而实现大规模富集铀。20 世纪 50 年代，Roland Gohlke 和 Fred McLafferty 将质谱仪作为气相色谱的检测器，导致了色谱–质谱联用技术的发展。1974 年 Alan G. Marshall 和 Melvin B. Comisarow 设计了傅里叶变换离子回旋共振质谱仪（Fourier transform ion cyclotron resonance mass spectrometry），提高了质谱仪的信噪比及灵敏度，并改善了质谱仪的分辨率。20 世纪 80 年代和 90 年代样品导入技术及离子化方式的持续改善，使质谱仪在相对分子质量高的化合物及生物样品分析中得到了广泛应用。迄今为止，至少有五位科学家因为在质谱领域的相关工作获得诺贝尔奖。

:::definition{label="最早的质谱仪"}
目前已知最早的质谱仪是 1918 年由 A. J. Dempster 设计的。基本原理和设计理念一直沿用到今天。
:::

## 二、应用与结构信息

目前，质谱技术在多种领域中发挥重要的作用。例如，在生物技术领域，质谱分析法可用于测定蛋白质、寡核苷酸及多糖的含量和序列；在环境保护方面，科学家们采用质谱技术监控空气和水体的质量；在公共安全和法医领域，质谱分析法被用于机场安全检查及法医现场痕量爆炸物的检测。在医药卫生领域，从先导化合物的发现到药物的合成、从药物动力学到药物代谢组学等方面都采用质谱分析技术测定药物及代谢产物的结构和含量。

:::definition{label="生物技术领域"}
测定蛋白质、寡核苷酸及多糖的含量和序列。高相对分子质量、生物样品进质谱，靠的是第 2 节后面的 MALDI、ESI，不是 70 eV 的 EI。
:::

:::definition{label="环境、公共安全与法医"}
监控空气和水体质量；机场安全检查及法医现场痕量爆炸物检测。
:::

:::definition{label="医药卫生领域"}
从先导化合物发现到药物合成，从药物动力学到药物代谢组学，测定药物及代谢产物的结构和含量。
:::

质谱分析法在测定药物及有机化合物结构方面能够提供的信息主要有：

① 药物及有机化合物的相对分子质量及分子式。

② 化合物的类型及可能的分子结构。

③ 分子中所含的氯原子（$\mathrm{Cl}$）、溴原子（$\mathrm{Br}$）的个数。

:::definition{label="结构方面能提供的三类信息"}
相对分子质量及分子式；化合物类型及可能的分子结构；分子中 $\mathrm{Cl}$、$\mathrm{Br}$ 的个数。
:::

:::keypoint{label="三类信息分别落到后面哪一节"}
- 相对分子质量：先认分子离子峰（第 5 节），软电离往往更清楚（第 2 节 CI）。
- 类型和可能结构：碎片离子、裂解规律（第 3 节）和各类化合物的典型峰（第 4 节）。
- $\mathrm{Cl}$、$\mathrm{Br}$ 个数：同位素峰丰度比（第 3 节图 10-22）。
:::

:::insight{label="Cl、Br 不是靠分子离子整数质量“猜”出来的"}
氯、溴的重同位素天然丰度高，质谱上会出现明显的 $M+2$、$M+4$。概述里先立户头，算法和第 3 节二项式 $(a+b)^{n}$ 再展开。不要用别的书的“氯 3:1、溴 1:1”口诀替换本版表 10-2 的百分数。
:::
