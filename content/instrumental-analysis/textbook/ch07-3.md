# 第3节　原子吸收分光光度计

第 2 节把定量收到 $A=K'c$，前提是锐线光源、发射线与吸收线中心重叠。本节打开仪器：光源、原子化系统、单色器和检测系统四块。如果把原子化系统看作样品池，则结构与紫外–可见分光光度计基本相同——但单色器通常放在原子化器后面，不要把第 4 章“单色器在吸收池前面”原样搬进来。空心阴极灯的电压、窗口材料和火焰／石墨炉参数以本版为准，不要用 Wikipedia 替换。

原子吸收分光光度计由光源、原子化系统、单色器和检测系统四个部分组成，基本构造如图 7-3 所示。由图可见，如果将原子化系统看作样品池，则原子吸收分光光度计的结构与紫外–可见分光光度计基本相同。

:::definition{label="原子吸收分光光度计的四块"}
光源、原子化系统、单色器、检测系统。原子化系统相当于样品池时，与紫外–可见光度计结构基本相同。
:::

:::concept{term="先问灯发出哪根线、样品怎样变成基态原子，再问单色器为什么在后面"}
看见仪器，先不要跳到“按哪个键点火”。户头是：锐线光源给出待测元素的共振辐射，原子化器把样品变成基态原子蒸气，单色器把共振线从邻近线里分开，检测器把透射光变成读数。把单色器听成必须放在原子化器前面，思考题第 3 题会对错方向。
:::

## 一、光源

光源的功能是发射被测元素基态原子所需吸收的特征共振辐射。对光源的基本要求是：发射线的波长半宽度要明显小于吸收线的半宽度，辐射强度足够大，背景低，稳定性好，使用寿命长。目前能满足上述各项要求的理想的锐线光源是空心阴极灯，应用最为广泛。

:::definition{label="光源的功能与要求"}
功能：发射被测元素基态原子所需吸收的特征共振辐射。要求：发射线半宽度明显小于吸收线半宽度；辐射强度足够大；背景低；稳定性好；使用寿命长。
:::

:::definition{label="空心阴极灯"}
空心阴极灯（hollow cathode lamp，HCL）是原子吸收分析中最常用的光源，是目前能满足上述要求的理想锐线光源，应用最为广泛。
:::

空心阴极灯的结构如图 7-4 所示。它是一个由被测元素材料制成的空心阴极和一个钨制阳极组成的气体放电管。阴极为空心圆柱体，内径约为 $2\,\mathrm{mm}$。阴极和阳极密封在带有光学窗口的玻璃管内，内充惰性气体，放电管集中在较小的空间内，可得到很高的辐射强度。光学窗口材料视空心阴极灯发射的共振线波长而定，$370\,\mathrm{nm}$ 以下必须用石英，$370\,\mathrm{nm}$ 以上可以用普通光学玻璃。

::figure{src="/images/instrumental-analysis/textbook/p0173_01.jpg" caption="图7-4　空心阴极灯的结构示意图。灯座、阳极、空心阴极（内壁为待测金属）、光学窗口，管内充惰性气体。" alt="空心阴极灯剖面：灯座、阳极、空心阴极内壁为待测金属、光学窗口、内充惰性气体"}

:::definition{label="空心阴极灯的结构"}
被测元素材料制成的空心阴极 $+$ 钨制阳极，组成气体放电管。阴极空心圆柱体内径约 $2\,\mathrm{mm}$。管内充惰性气体。窗口：$370\,\mathrm{nm}$ 以下必须用石英，$370\,\mathrm{nm}$ 以上可用普通光学玻璃。
:::

空心阴极灯是一种特殊的辉光放电装置，放电主要集中在阴极空腔内。当在两极之间施加 $200\sim 500\,\mathrm{V}$ 电压时，阴极便开始辉光放电。在电场作用下，电子在飞向阳极的途中，与载气原子碰撞并使之电离，放出二次电子。带正电荷的载气离子又从电位差获得动能，轰击阴极表面，将阴极材料的原子从晶格中溅射出来。溅射出来的原子再与电子、原子、离子等发生第二次碰撞而受到激发，于是阴极内的辉光中便出现了阴极物质和内充惰性气体的光谱。

:::definition{label="空心阴极灯的辉光放电过程"}
两极加 $200\sim 500\,\mathrm{V}$，阴极辉光放电。电子碰撞载气使之电离；载气正离子轰击阴极，溅射出阴极材料原子；溅射原子再经第二次碰撞被激发，辉光中出现阴极物质和惰性气体的光谱。
:::

由于灯内填充气压较低，所以阴极溅射的金属蒸气密度相对于大气压下气体放电而言是很低的，因此谱线的碰撞变宽被限制在很小的程度。另外，灯的工作电流通常较小，阴极温度和气体放电温度都不是很高，谱线的多普勒变宽也可控制得很小。由于上述特点，空心阴极灯是一种实用的锐线光源，辐射强度大，稳定性好。空心阴极灯使用中最大的不便是测定一种元素需要换一个灯。

:::insight{label="HCL 能当锐线光源，是因为碰撞变宽和多普勒变宽都被压住"}
低气压 → 碰撞变宽很小；小电流、阴极不太热 → 多普勒变宽很小。第 2 节说一般吸收线展宽主要是多普勒和洛伦兹，灯里这两项被刻意压低，发射线才比吸收线窄。不要把“锐线”听成阴极材料天生只会发一根无限细的线。
:::

:::pitfall{label="不要用别的书改 2 mm、370 nm 和 200～500 V"}
阴极内径约 $2\,\mathrm{mm}$；窗口分界 $370\,\mathrm{nm}$；工作电压 $200\sim 500\,\mathrm{V}$。Wikipedia 或别的教材的灯电流毫安数、氖／氩填充压强，本版这一节没有写，不要补进来。
:::

为了改进原子吸收中测定不同元素需要换灯的麻烦，目前已研制出多元素空心阴极灯。多元素空心阴极灯就是在阴极内含有两个或多个不同元素，点燃阴极负辉区时能同时辐射出两种或多种元素的共振线，只要更换波长，就能用一个灯同时进行几种元素的测定。但多元素空心阴极灯的辐射强度、灵敏度、寿命均不如单元素灯，使用尚不普遍。

:::definition{label="多元素空心阴极灯"}
阴极内含两个或多个不同元素，可同时辐射多种共振线，换波长即可测几种元素。辐射强度、灵敏度、寿命均不如单元素灯，使用尚不普遍。
:::

:::compare{title="空心阴极灯对紫外–可见连续光源"}
| 项目 | 空心阴极灯（AAS） | 钨灯／氘灯（第 4 章） |
|------|-------------------|------------------------|
| 发什么 | 待测元素的特征共振线（锐线） | 连续光谱 |
| 半宽度 | 明显小于吸收线 | 连续，靠单色器切窄 |
| 换元件 | 通常一种元素一盏灯 | 紫外氘灯、可见钨灯，不按元素换 |
| 多元素灯 | 有，但强度、灵敏度、寿命不如单元素灯 | — |
:::

## 二、原子化系统

在原子吸收分析中，样品中被测元素的原子化是整个分析过程的关键环节。原子化系统的功能是提供能量，将样品转化为所需的基态原子。待测元素由样品浓缩、结晶、干燥、蒸发转为气相，解离为基态原子蒸气的过程，称为原子化过程。最常用的原子化方法有两种：火焰原子化法和非火焰原子化法。

:::definition{label="原子化过程"}
待测元素由样品浓缩、结晶、干燥、蒸发转为气相，解离为基态原子蒸气的过程。原子化系统提供能量，将样品转化为所需的基态原子。
:::

:::definition{label="两种常用原子化方法"}
火焰原子化法；非火焰原子化法。非火焰中应用最广的是管式石墨炉原子化器。
:::

### （一）火焰原子化法

火焰原子化法由化学火焰提供能量，使待测元素原子化。实现火焰原子化的原子化器有两种：全消耗型和预混合型。全消耗型原子化器是将样品直接喷入火焰。预混合型原子化器包括喷雾器、雾化室和燃烧器三部分，喷雾器将样品雾化并使雾滴均匀化，然后再喷入燃烧器火焰中将样品原子化。二者各有优缺点，一般仪器常用的是预混合型。图 7-5 为预混合型原子化器示意图。

:::definition{label="全消耗型与预混合型"}
全消耗型：样品直接喷入火焰。预混合型：喷雾器、雾化室、燃烧器三部分，先雾化均匀再喷入火焰。一般仪器常用预混合型。
:::

::figure{src="/images/instrumental-analysis/textbook/p0174_01.jpg" caption="图7-5　预混合型原子化器示意图。试液经喷雾进入雾化室，与空气、乙炔预混合后在燃烧缝上形成火焰，光束横穿火焰，废液排出。" alt="预混合型原子化器：喷雾器、雾化室、燃烧器，标出空气、乙炔、样品、废液和穿过火焰的光束"}

预混合型原子化器的特点是，进入火焰的粒子均匀且细微，在火焰中可瞬时原子化，形成的火焰稳定性好，有效吸收光程长，易于操作。但它的缺点主要是样品利用效率较低，仅有约 $10\%$ 的样品被原子化，而约 $90\%$ 的样品由废液管排出。较低的原子化效率成为其提高灵敏度的主要障碍。

:::definition{label="预混合型的优点与约 10% 原子化"}
粒子均匀细微，瞬时原子化，火焰稳定，有效吸收光程长，易于操作。样品利用效率约 $10\%$ 被原子化，约 $90\%$ 由废液管排出。低原子化效率是提高灵敏度的主要障碍。
:::

:::pitfall{label="不要把 10% 听成“火焰法不能定量”"}
约 $10\%$ 是预混合型的样品利用率，不是方法作废。第 1 节火焰检出限仍到 $10^{-9}$ 数量级、中等高含量 RSD 可低于 $1\%$。石墨炉几乎全部样品参与光吸收，绝对灵敏度更高，但精密度一般为 $3\%\sim 5\%$。两本账不要并成“谁全面碾压谁”。
:::

### （二）非火焰原子化法

非火焰原子化法中，应用最广的原子化器是管式石墨炉原子化器。本质上，它是一个电加热器，利用电能加热盛放样品的石墨容器，使之达到高温，以实现样品的蒸发和原子化。

商品化的管式石墨炉原子化器如图 7-6 所示，由加热电源、惰性气体保护系统和石墨管炉组成。石墨管长约 $50\,\mathrm{mm}$，内径约 $5\,\mathrm{mm}$。石墨管固定在两个电极之间，管的两端开口，安装时其长轴与原子吸收分析的光束通路重合。样品用微量注射器直接由进样孔注入石墨管中。为了防止样品及石墨管氧化，盖板盖上后，石墨管内构成保护气室，室内通以惰性气体 $\mathrm{Ar}$ 或 $\mathrm{N_2}$，以保护原子化的样品不再被氧化，同时也延长石墨管的使用寿命。石墨管作为电阻发热体，通电后可达到 $2000\sim 3000^{\circ}\mathrm{C}$ 高温，以蒸发样品和使样品原子化。

::figure{src="/images/instrumental-analysis/textbook/p0175_01.jpg" caption="图7-6　管式石墨炉原子化器结构示意图。石墨管两端接电源，管内通光束；惰性气体入口、冷却水、可移去的窗口、进样、金属夹套与绝缘体。" alt="管式石墨炉剖面：石墨管、两端电极、惰性气体入口、冷却水、光束穿过石墨管、进样孔"}

:::definition{label="管式石墨炉原子化器"}
电加热器。由加热电源、惰性气体保护系统和石墨管炉组成。石墨管长约 $50\,\mathrm{mm}$，内径约 $5\,\mathrm{mm}$，长轴与光束重合。保护气为 $\mathrm{Ar}$ 或 $\mathrm{N_2}$。通电可达 $2000\sim 3000^{\circ}\mathrm{C}$。
:::

与火焰原子化法相比，石墨炉原子化的特点是：①样品原子化是在充有惰性保护气的气室内，于强还原性石墨介质中进行的，有利于难熔氧化物的分解和自由原子的快速生成。②用样量小，通常固体样品为 $0.1\sim 10\,\mathrm{mg}$，液体样品为 $1\sim 50\,\mu\mathrm{L}$，样品全部蒸发，原子在测定区的有效停留时间长，几乎全部样品参与光吸收，绝对灵敏度高。③排除了化学火焰中常常产生的被测组分与火焰组分之间的相互作用，减小了化学干扰。④固体样品与液体样品均可直接进样。石墨炉原子化法的缺点是：①由于取样量小，样品组成的不均匀性影响较大，测定精密度不如火焰原子化法好。②有强的背景。③设备比较复杂，费用较高。

:::definition{label="石墨炉用样量"}
固体样品通常 $0.1\sim 10\,\mathrm{mg}$，液体样品 $1\sim 50\,\mu\mathrm{L}$。样品全部蒸发，几乎全部参与光吸收。
:::

:::compare{title="火焰原子化对石墨炉原子化"}
| 项目 | 火焰（预混合型） | 石墨炉（管式） |
|------|------------------|----------------|
| 能量 | 化学火焰 | 电加热，$2000\sim 3000^{\circ}\mathrm{C}$ |
| 气氛 | 燃气／助燃气 | 惰性保护气 $\mathrm{Ar}$ 或 $\mathrm{N_2}$，强还原性石墨 |
| 用样 | 连续喷雾；约 $10\%$ 被原子化 | 固体 $0.1\sim 10\,\mathrm{mg}$，液体 $1\sim 50\,\mu\mathrm{L}$，几乎全部参与吸收 |
| 优点 | 稳定、光程长、精密度较好（RSD 可低于 $1\%$） | 绝对灵敏度高；减小火焰化学干扰；固液均可直接进样 |
| 缺点 | 原子化效率低，提高灵敏度的主要障碍 | 精密度不如火焰；强背景；设备复杂、费用高 |
:::

:::pitfall{label="石墨炉参数不要用别的书替换"}
管长约 $50\,\mathrm{mm}$、内径约 $5\,\mathrm{mm}$、温度 $2000\sim 3000^{\circ}\mathrm{C}$、液体 $1\sim 50\,\mu\mathrm{L}$、固体 $0.1\sim 10\,\mathrm{mg}$、保护气 $\mathrm{Ar}$ 或 $\mathrm{N_2}$。第 5 节还会写氩气流速通常 $1\sim 5\,\mathrm{L}\cdot\mathrm{min}^{-1}$、原子化阶段停止通保护气。这些数字以本版为准。
:::

## 三、单色器

单色器的作用是将所需的共振吸收线分离出来。由于原子吸收分光光度计使用锐线光源，吸收值测定采用峰值吸收测定法，而且吸收光谱本身也比较简单，故对单色器分辨率的要求并不高。单色器中的关键部件是色散元件，现多用光栅，刻痕数为 $600\sim 2800$ 条 $/\mathrm{mm}$。为了阻止来自吸收池的所有辐射不加选择地全部进入检测器，单色器通常配置在原子化器以后的光路中。

:::definition{label="单色器的作用与位置"}
作用：将所需的共振吸收线分离出来。色散元件现多用光栅，刻痕 $600\sim 2800$ 条 $/\mathrm{mm}$。通常配置在原子化器以后，防止吸收池的所有辐射不加选择地进入检测器。
:::

:::insight{label="分辨率要求并不高，位置却必须在后面"}
锐线光源 $+$ 峰值吸收 $+$ 光谱简单 → 分辨率要求并不高。但原子化器会发光、会散射，若不把单色器放在后面，这些辐射会全部灌进检测器。紫外–可见光度计单色器在吸收池前面，是因为用连续光源、要先切出一窄带再让溶液吸收。两套光路不要并户。
:::

:::pitfall{label="不要因为“分辨率要求不高”就把单色器删掉"}
光源已经是锐线，邻近线、惰性气体线和原子化器发出的辐射仍要分开。光栅 $600\sim 2800$ 条 $/\mathrm{mm}$ 是本版给出的刻痕范围，不要改成别的仪器说明书。
:::

## 四、检测系统

检测系统主要由检测器、放大器、对数变换器、指示仪表所组成。检测器多为光电倍增管，工作波段一般在 $190\sim 900\,\mathrm{nm}$。一些现代高级原子吸收分光光度计还设有标度扩展、背景自动校正、自动取样等装置，并用计算机进行控制。

:::definition{label="检测系统"}
检测器、放大器、对数变换器、指示仪表。检测器多为光电倍增管，工作波段一般 $190\sim 900\,\mathrm{nm}$。现代仪器可有标度扩展、背景自动校正、自动取样，并用计算机控制。
:::

:::keypoint{label="四块按光路顺序记"}
空心阴极灯（锐线）→ 原子化系统（火焰或石墨炉，相当于样品池）→ 单色器（原子化器之后，光栅 $600\sim 2800$ 条 $/\mathrm{mm}$）→ 检测系统（PMT，$190\sim 900\,\mathrm{nm}$）。
:::

:::memory{label="仪器三句"}
- HCL：阴极内径约 $2\,\mathrm{mm}$，窗口以 $370\,\mathrm{nm}$ 分石英／玻璃，电压 $200\sim 500\,\mathrm{V}$；一种元素一盏灯。
- 火焰预混合约 $10\%$ 原子化；石墨炉 $50\,\mathrm{mm}\times 5\,\mathrm{mm}$，$2000\sim 3000^{\circ}\mathrm{C}$，固 $0.1\sim 10\,\mathrm{mg}$、液 $1\sim 50\,\mu\mathrm{L}$。
- 单色器在原子化器后面；PMT $190\sim 900\,\mathrm{nm}$。
:::
