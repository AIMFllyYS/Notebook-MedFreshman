# 第1节　概述

第 12 章把经典液相写成常压柱、薄层和 $R_{\mathrm{f}}$。第 13 章把流动相换成气体。本章落到**液体作流动相、高压把微粒柱打穿**这一档：高效液相色谱法。本节只立名称、六条特点、与经典液相的表 14-1、与气相的四条差别。速率方程放到第 2 节，正相／反相和键合相放到第 3 节，泵、进样阀和检测器放到第 5 节。不要把第 15 章毛细管电泳提前搬进来。

高效液相色谱法（high performance liquid chromatography，HPLC）是 20 世纪 60 年代末发展起来的一种现代色谱分析方法，其以经典液相色谱法为基础，采用高压输液系统、高效固定相和高灵敏度检测器，并引入气相色谱的理论与实验方法。在 HPLC 的发展过程中，人们根据它的某些特点曾经出现过不同的名称，如高速液相色谱法（high speed liquid chromatography，HSLC）、高压液相色谱法（high pressure liquid chromatography，HPLC）、高分辨液相色谱法（high resolution liquid chromatography，HRLC）等，但高效液相色谱法（HPLC）是色谱工作者普遍认同的名称。

:::definition{label="高效液相色谱法"}
高效液相色谱法（high performance liquid chromatography，HPLC）以经典液相色谱为基础，用高压输液、高效微粒固定相和高灵敏度检测器，并引入气相色谱的理论与实验方法。本版把公认名称写成高效液相色谱法，缩写仍是 HPLC。
:::

:::definition{label="曾经用过的三个别名"}
高速液相色谱法（HSLC）、高压液相色谱法（high pressure liquid chromatography，HPLC）、高分辨液相色谱法（HRLC）。高压那一档的英文缩写也印成 HPLC，不要和“高效”抢户头——考试答公认名称时写高效，不要只写高压。
:::

:::concept{term="先问流动相是不是液体，再问是不是高压微粒柱"}
看见 HPLC，先不要跳到 $C_{18}$ 或二极管阵列。户头是：流动相是液体，柱里是 $3\sim 10\,\mu\mathrm{m}$ 微粒，靠高压把液体打过去。把本章听成第 13 章，载气、气化室和蒸气压限制都会写进来。把本章听成第 12 章，常压玻璃柱和薄层 $R_{\mathrm{f}}$ 又会对空。
:::

:::insight{label="60 年代末那一笔只给年代，不另造发明人"}
本版写成 20 世纪 60 年代末。第 11 章已经把 Martin 与 Synge（1941／1952）用在分配色谱和塔板理论上。本节不要改成“1952 年诺贝尔奖那一年发明 HPLC”，也不要把 Waters 公司提前写进概述——UPLC 的 ACQUITY 放到第 7 节。
:::

:::pitfall{label="不要把本章答成第 13 章，也不要吞第 15 章"}
气相的载气、气化室、TCD／FID／ECD 在第 13 章。毛细管电泳在第 15 章。本节可以写“液体扩散比气体小 $10^{5}$ 倍、柱外效应特别重要”——那是液相自己的弱点，不是把氢焰喷嘴搬进来。扫描页旁的二维码、页眉「第14章　高效液相色谱法」、页码 344 起都不写入正文。

## 一、高效液相色谱法特点

高效液相色谱法具有以下几个突出的特点。

（1）**高压**　液相色谱法以液体为流动相，液体流经色谱柱时受到的阻力较大。为了能迅速地通过色谱柱，必须对流动相施加高压。在 HPLC 中供液压力和进样压力都很高，一般可达到 $150\times 10^{5}\sim 350\times 10^{5}\,\mathrm{Pa}$。

（2）**高速**　HPLC 所需的分析时间一般可在几分钟到几十分钟内完成，流动相的流量一般可达 $1\sim 10\,\mathrm{mL\cdot min^{-1}}$。

（3）**高效**　采用新型的高效微粒固定相（粒度为 $3\sim 10\,\mu\mathrm{m}$），HPLC 填充柱的柱效可达每米 $40\,000\sim 80\,000$ 的理论塔板数，可以分离结构非常近似的化合物，甚至光学异构体。

（4）**高灵敏度**　HPLC 已广泛采用高灵敏度的检测器，如紫外检测器的检测限可达 $10^{-9}\,\mathrm{g}$，荧光检测器的检测限可达 $10^{-12}\,\mathrm{g}$，电化学检测器的检测限可以更低。

（5）**样品适用范围广**　HPLC 有多种分离模式，原则上讲，几乎可以分析所有的有机化合物和无机化合物。

（6）**样品回收方便，很容易将分析放大为制备分离**　由于 HPLC 大多采用非破坏性检测器，故可回收珍贵的样品，这在蛋白质组学的研究和生物工程中尤为重要。

:::definition{label="高压"}
液体过柱阻力大，必须加压。本版供液压力和进样压力一般 $150\times 10^{5}\sim 350\times 10^{5}\,\mathrm{Pa}$。表 14-1 把柱入口压强收成 $10\sim 40\,\mathrm{MPa}$，同一档不要拆成两个互相打架的数字。
:::

:::definition{label="高速"}
分析时间几分钟到几十分钟，流量一般 $1\sim 10\,\mathrm{mL\cdot min^{-1}}$。第 2 节会把分析型流量再收到约 $1\,\mathrm{mL\cdot min^{-1}}$——那是兼顾柱效后的常用点，不是把本节的 $1\sim 10$ 作废。
:::

:::definition{label="高效"}
固定相粒度 $3\sim 10\,\mu\mathrm{m}$，填充柱每米理论塔板数 $40\,000\sim 80\,000$，可分结构近似物甚至光学异构体。第 7 节 UPLC 用 $1\sim 2\,\mu\mathrm{m}$、每米 $150\,000\sim 300\,000$，不要提前并进本节。
:::

:::definition{label="高灵敏度"}
紫外检测限 $10^{-9}\,\mathrm{g}$，荧光 $10^{-12}\,\mathrm{g}$，电化学可以更低。第 5 节会把紫外最小检出量写成 $10^{-12}\sim 10^{-7}\,\mathrm{g}$、荧光写成 $1\times 10^{-10}\,\mathrm{g\cdot mL^{-1}}$——单位和口径不同，不要在概述里对打。
:::

:::compare{title="六条特点各管什么"}
| 特点 | 本版数字／落点 | 不要听成 |
|------|----------------|----------|
| 高压 | $150\times 10^{5}\sim 350\times 10^{5}\,\mathrm{Pa}$ | 常压玻璃柱也能叫 HPLC |
| 高速 | 几分钟～几十分钟；$1\sim 10\,\mathrm{mL\cdot min^{-1}}$ | 必须比 GC 更快 |
| 高效 | $3\sim 10\,\mu\mathrm{m}$；$4\times 10^{4}\sim 8\times 10^{4}\,\mathrm{m^{-1}}$ | 已经等于 UPLC |
| 高灵敏度 | UV $10^{-9}\,\mathrm{g}$；荧光 $10^{-12}\,\mathrm{g}$ | 已经有 GC 那样的通用检测器 |
| 适用范围 | 多种模式，有机、无机原则上都能做 | 沸点高就不能做 |
| 可回收、可制备 | 多为非破坏性检测器 | 质谱检测也一定不破坏样品 |
:::

:::keypoint{label="高压、高速、高效、高灵敏是四高，后两条是范围和制备"}
前四条对应仪器条件：压、速、粒、检测器。后两条对应样品：几乎都能做、多数能回收。把“高效”听成“高压的别名”，粒度、塔板数和光学异构体都会漏。
:::

:::memory{label="四高两广"}
压：$1.5\times 10^{7}\sim 3.5\times 10^{7}\,\mathrm{Pa}$。速：分钟级，$1\sim 10\,\mathrm{mL\cdot min^{-1}}$。效：$3\sim 10\,\mu\mathrm{m}$，每米几万塔板。灵：UV 纳克，荧光皮克。广：有机无机。收：非破坏、可制备。
:::

## 二、高效液相色谱法与经典液相色谱法比较

高效液相色谱法与经典液相色谱法的性能对比如表 14-1 所示。就分离机理而言，两者没有本质的区别。但由于 HPLC 采用了高压输液泵、高效微粒固定相和高灵敏度检测器，HPLC 在分析速度、分离效率、检测灵敏度、操作自动化等方面，都达到了可与 GC 相比的程度，并保持了样品适用范围广、流动相种类多和便于制备的柱色谱优点。因此，HPLC 在生物工程、制药工业、食品工业、环境监测、石油化工等领域获得了广泛的应用。特别是在当今迅速发展的生命科学领域，在蛋白质组学的研究中，HPLC 已经成为必不可少的分析手段。

:::definition{label="与经典液相：机理同，装备不同"}
分离机理没有本质区别。差别在高压泵、微粒固定相、高灵敏度检测器和仪器化。不要把第 12 章的吸附、分配、离子交换、排阻说成“HPLC 另起一套机理”。
:::

:::compare{title="表14-1　高效液相色谱法与经典液相色谱法比较"}
| 项目 | 经典液相色谱法 | 高效液相色谱法（分析型） |
|------|----------------|--------------------------|
| 固定相 | 一般规格 | 特殊规格 |
| 固定相粒度／$\mu\mathrm{m}$ | $75\sim 500$ | $3\sim 10$ |
| 固定相粒度分布（RSD） | $20\%\sim 30\%$ | $<5\%$ |
| 柱长／$\mathrm{cm}$ | $10\sim 100$ | $3\sim 25$（分析型） |
| 柱内径／$\mathrm{cm}$ | $2\sim 5$ | $0.2\sim 0.46$ |
| 柱入口压强／$\mathrm{MPa}$ | $0.001\sim 0.1$ | $10\sim 40$ |
| 柱效（每米理论塔板数） | $10\sim 100$ | $(3\sim 8)\times 10^{4}$ |
| 样品用量／$\mathrm{g}$ | $1\sim 10$ | $10^{-6}\sim 10^{-4}$ |
| 分析所需时间／$\mathrm{h}$ | $1\sim 20$ | $0.05\sim 0.5$ |
| 装置 | 非仪器化 | 仪器化 |
:::

:::insight{label="粒度从几百微米收到几微米，压强就从千帕爬到几十兆帕"}
经典液相 $75\sim 500\,\mu\mathrm{m}$，靠重力或很低的压就能过柱，柱效每米只有几十到一百。HPLC 把粒度收到 $3\sim 10\,\mu\mathrm{m}$、RSD 收到 $<5\%$，阻力上去，入口压强变成 $10\sim 40\,\mathrm{MPa}$，柱效跳到每米几万。表 14-1 是用数字把第 12 章和本章切开，不是另造一种色谱。
:::

:::pitfall{label="分析型柱长 3～25 cm，不要和经典柱的 10～100 cm 对调"}
HPLC 分析柱更短、更细、填料更匀。把“高效”听成“柱更长”，表 14-1 的柱长、内径、样品用量（微克到毫克对克级）会整行写反。制备柱内径放到第 5 节，本节表只标分析型。
:::

:::keypoint{label="HPLC 赶上 GC 的速度和柱效，还保住液相的样品范围"}
本版原话：分析速度、分离效率、检测灵敏度、操作自动化可与 GC 相比；样品适用范围广、流动相种类多、便于制备是柱色谱留下来的优点。蛋白质组学这一句只说明应用地位，不要在概述里展开二维电泳。
:::

## 三、高效液相色谱法与气相色谱法比较

高效液相色谱法所用的基本概念（如保留值、理论塔板数、理论塔板高度、分离度、选择性等）与气相色谱法一致，所用的基本理论（如塔板理论、速率理论）也基本一致。但是由于在 HPLC 中以液体代替 GC 中的气体作为流动相，液体和气体的性质并不相同。此外，HPLC 所用仪器设备和操作条件也与 GC 不同。所以，HPLC 与 GC 又有区别。HPLC 与 GC 的区别主要有以下几个方面。

（1）由于液体的扩散性比气体小 $10^{5}$ 倍，因此，溶质在 HPLC 中的传质速率慢，柱外效应就显得特别重要；而在 GC 中，柱外区域扩张可以忽略不计。

（2）两者应用范围不同。GC 仅能分析在操作温度下能气化而不分解的物质，对高沸点化合物、非挥发性物质、热不稳定物质、离子型化合物和高聚物的分离、分析有困难。因此，GC 应用受到一定程度的限制，据统计只有大约 $20\%$ 的有机物能用 GC 分析。HPLC 则不受样品挥发性和热稳定性的限制，它非常适合于相对分子质量较大、难气化、不易挥发或对热敏感的物质、离子型化合物和高聚物的分离、分析，占有机物的 $70\%\sim 80\%$。

（3）HPLC 能完成难度较高的分离工作。这是因为：① GC 的流动相载气是色谱惰性的，不参与分配平衡过程，与样品分子无亲和作用，样品分子只与固定相相互作用。而在 HPLC 中，流动相液体与固定相争夺样品分子，为提高选择性增加了一个因素，还可选用不同比例的两种或两种以上的液体作流动相，增大分离的选择性；② HPLC 的固定相类型比 GC 多，作为分析时选择的余地大；③ HPLC 通常在室温下操作，较低的温度有利于色谱分离，而 GC 需要高柱温。

（4）HPLC 中制备样品简单，回收样品也比较容易，而且回收是定量的，适合于大量制备。但 HPLC 尚缺乏通用的检测器，仪器比较复杂，价格昂贵。在实际应用中，这两种色谱技术是相互补充的。

HPLC 已经广泛应用于各种药物及其制剂的分析测定，尤其在生物样品、中药等复杂体系的成分分离分析中发挥着极其重要的作用。随着 HPLC 与 MS、NMR 等联用技术的发展，HPLC 的应用将愈加广泛。

:::definition{label="概念和理论与 GC 一致"}
保留值、理论塔板数、塔板高度、分离度、选择性；塔板理论、速率理论。第 2 节会改 van Deemter 的写法，改的是 $B/u$ 和 $C$，不是另起一套名词。
:::

:::definition{label="柱外效应"}
液体扩散性比气体小 $10^{5}$ 倍，传质慢，柱外死体积引起的峰展宽在 HPLC 里特别重要。GC 里柱外区域扩张可以忽略。进样阀、连接管、检测池体积放到第 5 节，本节先立这个名字。
:::

:::compare{title="HPLC 对 GC（本节四条）"}
| 项目 | GC | HPLC |
|------|----|------|
| 流动相 | 气体，色谱惰性，不参与分配 | 液体，与固定相争夺样品分子 |
| 扩散 | 大，柱外效应可忽略 | 约小 $10^{5}$ 倍，柱外效应重要 |
| 样品范围 | 能气化且不分解，约 $20\%$ 有机物 | 不受挥发性和热稳定性限制，约 $70\%\sim 80\%$ |
| 操作温度 | 需要高柱温 | 通常室温，低温有利于分离 |
| 固定相类型 | 相对少 | 比 GC 多 |
| 制备与回收 | 收集气态流出物不便 | 制备简单，回收定量 |
| 检测器 | 有较通用的检测器 | 尚缺乏通用检测器 |
:::

:::insight{label="HPLC 多出来的选择性来自流动相也参与分配"}
GC 里载气几乎不管选择性，只靠固定液。HPLC 里流动相和固定相一起抢样品分子，还可以配多元溶剂。第 4 节会把“溶剂种类管 $\alpha$、配比管 $k$”写死。把流动相听成“只是把样品推过柱的惰性液体”，正相／反相就会记反。
:::

:::pitfall{label="20% 对 70%～80% 是有机物能分析的比例，不是柱效比"}
GC 约 $20\%$，HPLC 约 $70\%\sim 80\%$，口径是“能分析的有机物占比”。不要答成“HPLC 柱效是 GC 的四倍”，也不要把剩下的 $20\%$ 自动派给第 15 章电泳。
:::

:::pitfall{label="HPLC 的短处写在第（4）条后半：缺通用检测器、仪器贵"}
不要只背“HPLC 全面优于 GC”。本版明确：缺乏通用检测器，仪器复杂昂贵；两者相互补充。示差折光、蒸发光散射放到第 5 节当通用型补丁，仍达不到 FID 那种地位。
:::

- 立名称：高效液相色谱法，HPLC。
- 立四高、与经典液相的表 14-1、与 GC 的四条差别。
- 速率方程、正反相、键合相、泵和检测器、UPLC 与 LC-MS 分别在第 2、3、5、7 节。

:::
