# 第2节　电位分析法的基本原理

电位分析法要读原电池电动势。单个电极电位测不到，液接电位又会搅进读数，所以本节先把相界电位、盐桥、原电池与电解池、电极分类、可逆条件和测量电路写成同一本账。数字以本版为准：锌、铜电对标准电极电位分别是 $-0.763\,\mathrm{V}$、$0.337\,\mathrm{V}$，丹聂尔电池 $E=1.100\,\mathrm{V}$；饱和甘汞电极 $0.241\,\mathrm{V}$（$25^{\circ}\mathrm{C}$）。

电位分析法测量的是化学电池。没有相界上的双电层，就没有电极电位；没有盐桥压住液接电位，电动势就含一份测不准的界面项。下面按相界电位和液接电位、化学电池和电池电动势、电极分类、可逆电极和可逆电池、电极电位的测量五块写。

## 一、相界电位和液接电位

### （一）化学双电层与相界电位

金属晶体由排列在晶格点阵上的金属正离子和在其间流动的自由电子组成。当把金属插入该金属盐的溶液中时，一方面，金属表面的正离子受极性水分子的作用，有离开金属进入溶液中的倾向；另一方面，溶液中的金属离子与金属晶体碰撞，受自由电子的作用，有离子和极性分子沉积到金属表面上的倾向。这两种倾向引起电荷在相界面上的转移，破坏了原来两相的电中性。由电荷转移造成金属与溶液中的多余正、负电荷分别集中分布在相界面的两边，形成了化学双电层（chemical double electric layer）。

例如，$\mathrm{Zn}$ 在 $\mathrm{ZnSO_4}$ 溶液中形成 $\mathrm{Zn}$ 带负电荷（有过剩的电子）、溶液带正电荷的双电层；$\mathrm{Ag}$ 在 $\mathrm{AgNO_3}$ 溶液中易形成 $\mathrm{Ag}$ 带正电荷（有过剩的 $\mathrm{Ag}^{+}$）、溶液带负电荷的双电层。化学双电层的形成抑制了电荷继续转移的倾向，达到平衡后，在相界面两边产生一个稳定的电位差，称为相界电位（phase boundary potential），即溶液中的金属电极电位（electrode potential）。

:::definition{label="化学双电层"}
化学双电层（chemical double electric layer）由电荷转移造成：金属与溶液中的多余正、负电荷分别集中分布在相界面两边。它抑制电荷继续转移，平衡后给出稳定的相界电位。
:::

:::definition{label="相界电位"}
相界电位（phase boundary potential）是双电层平衡后在相界面两边产生的稳定电位差，即溶液中的金属电极电位（electrode potential）。
:::

:::compare{title="锌和银插入各自盐溶液时双电层的符号"}
| 电极 | 溶液 | 金属一侧 | 溶液一侧 |
|------|------|----------|----------|
| $\mathrm{Zn}$ | $\mathrm{ZnSO_4}$ | 带负电荷（过剩电子） | 带正电荷 |
| $\mathrm{Ag}$ | $\mathrm{AgNO_3}$ | 带正电荷（过剩 $\mathrm{Ag}^{+}$） | 带负电荷 |
:::

:::insight{label="金属越活泼、离子越稀，电极电位越负"}
金属越活泼，溶液中该金属离子的浓度越低，金属正离子进入溶液的倾向越大，电极的还原性越强，电极电位越负；反之，电极氧化性越强，电极电位越正。后面能斯特公式里 $\lg a_{\mathrm{M}^{n+}}$ 的符号，就是这一句的定量写法。
:::

:::pitfall{label="相界电位不是液接电位"}
相界电位在金属/溶液界面；液接电位在两种电解质溶液的接触界面。盐桥消除的是后者，消除不了电极本身的相界电位——没有相界电位就没有指示电极。
:::

### （二）液接电位与盐桥

两种组成不同，或组成相同而浓度不同的电解质溶液接触界面两边存在的电位，称为液体接界电位（liquid junction potential），简称液接电位。液接电位是由于离子在溶液中扩散速率的差异而引起的。

例如，两种不同浓度的 $\mathrm{AgNO_3}$ 溶液接触时，高浓度溶液中的 $\mathrm{Ag}^{+}$ 和 $\mathrm{NO_3}^{-}$ 将向低浓度溶液一方扩散（图2-1）。由于 $\mathrm{NO_3}^{-}$ 的扩散速率（长箭头）大于 $\mathrm{Ag}^{+}$ 的扩散速率（短箭头），单位时间内越过相界面的 $\mathrm{NO_3}^{-}$ 比 $\mathrm{Ag}^{+}$ 多，使低浓度界面 $\mathrm{NO_3}^{-}$ 过量、带负电荷；高浓度界面 $\mathrm{Ag}^{+}$ 过量、带正电荷。在液接界面上形成了双电层：双电层对 $\mathrm{NO_3}^{-}$ 的进一步扩散起阻碍作用，对 $\mathrm{Ag}^{+}$ 的扩散起促进作用，最终两种离子的扩散达到平衡。此时，溶液界面上形成的微小电位差即液接电位。

::figure{src="/images/instrumental-analysis/textbook/p0017_01.jpg" caption="图2-1　液接电位的产生。两种不同浓度的 AgNO₃ 溶液接触：NO₃⁻ 扩散快于 Ag⁺，低浓侧带负电、高浓侧带正电。" alt="右侧示意图：上下两个半区，上方高浓度 Ag+ 和 NO3-，下方低浓度；NO3- 向下的箭头长于 Ag+ 的箭头"}

在电位分析法测定中常使用有液接电位的电池。液接电位值难以准确测量和计算，会影响电池电动势的准确测定，故必须设法消除。

:::definition{label="液接电位"}
液体接界电位（liquid junction potential），简称液接电位：两种组成不同或组成相同而浓度不同的电解质溶液接触界面两边存在的电位，由离子扩散速率差异引起。
:::

:::definition{label="盐桥"}
消除液接电位常用的方法是在两溶液间连接一个内充高浓度 $\mathrm{KCl}$（或其他适用的电解质）溶液的盐桥（salt bridge）。盐桥由含 $3\%$ 琼脂的高浓度 $\mathrm{KCl}$（或其他适用的电解质）溶液填充到一个 U 形管或直管中构成。
:::

由于 $\mathrm{KCl}$ 的浓度比较高，这样在两溶液接触的界面上形成的液接电位主要是由 $\mathrm{KCl}$ 扩散引起的，而 $\mathrm{K}^{+}$ 与 $\mathrm{Cl}^{-}$ 的迁移速率相近，故产生的液接电位很小（$1\sim 2\,\mathrm{mV}$），且两端液接电位的方向相反，互相抵消，其对电位测量的影响可忽略不计。

:::keypoint{label="盐桥为什么能把液接电位压到可忽略"}
- 高浓度 $\mathrm{KCl}$ 主导界面扩散。
- $\mathrm{K}^{+}$ 与 $\mathrm{Cl}^{-}$ 迁移速率相近，界面电荷分离小，$1\sim 2\,\mathrm{mV}$。
- 盐桥两端液接电位方向相反，互相抵消。
:::

:::pitfall{label="盐桥不是把两种溶液混成一相"}
盐桥阻止两种溶液混合，又为通电时的离子迁移提供通道。把盐桥听成“把两边倒在一起”，无液接界电池和有液接界电池的分户会消失。
:::

## 二、化学电池和电池电动势

:::definition{label="化学电池"}
化学电池（chemical cell）是一种电化学反应器，通常由两根电极和电解质溶液组成。电化学反应发生在电极与电解质溶液界面间的氧化还原反应。
:::

:::definition{label="无液接界电池与有液接界电池"}
两根电极插在同一种溶液中组成的化学电池称为无液接界电池；两根电极分别插在两种组成不同、但能相互连通的溶液中组成的化学电池称为有液接界电池。有液接界电池通常用某种多孔物质隔膜将两种溶液隔开，或用一盐桥装置将两种溶液连接起来：阻止两种溶液混合，又为通电时的离子迁移提供必要的通道。
:::

:::definition{label="原电池"}
原电池（galvanic cell）的电极反应能够自发进行，将化学能转变为电能。
:::

:::definition{label="电解池"}
电解池（electrolytic cell）的电极反应不能自发进行，只有在外加电压情况下电极反应才能进行，将电能转变为化学能。
:::

:::insight{label="区分原电池和电解池看工作状态，不看结构"}
同一结构的电池通过改变实验条件可进行相互转化。区分的依据是电池的工作状态，而不是它们的结构。丹聂尔电池外加反向电压大于 $1.100\,\mathrm{V}$ 后，就变成电解池。
:::

### （一）铜锌原电池（丹聂尔电池）

以铜锌原电池（丹聂尔电池）为例：将金属锌片插入 $1\,\mathrm{mol}\cdot\mathrm{L}^{-1}\,\mathrm{ZnSO_4}$ 溶液中，将金属铜片插入 $1\,\mathrm{mol}\cdot\mathrm{L}^{-1}\,\mathrm{CuSO_4}$ 溶液中，组成两个半电池，中间以饱和 $\mathrm{KCl}$ 盐桥连接，如图2-2所示。

::figure{src="/images/instrumental-analysis/textbook/p0018_01.jpg" caption="图2-2　铜锌原电池示意图。锌极氧化、铜极还原，中间饱和 KCl 盐桥；外电路电子由 Zn 流向 Cu。" alt="U 形盐桥连接左侧 Zn/ZnSO4 和右侧 Cu/CuSO4；盐桥中标 Cl- 向左、K+ 向右；外电路电子从锌流向铜"}

电池表示式为

$$(-)\,\mathrm{Zn}\,|\,\mathrm{ZnSO_4}\,(1\,\mathrm{mol}\cdot\mathrm{L}^{-1})\,||\,\mathrm{CuSO_4}\,(1\,\mathrm{mol}\cdot\mathrm{L}^{-1})\,|\,\mathrm{Cu}\,(+)$$

书写电池表示式的规则如下：

（1）发生氧化反应的电极写在左边，发生还原反应的电极写在右边。

（2）以符号“$|$”表示不同物相之间的接界面，同一相中的不同物质之间用“$，$”隔开；两种溶液通过盐桥连接，用“$||$”表示。

（3）电解质溶液位于两电极之间，并应注明浓度；如为气体，应注明压力、温度。

:::definition{label="电池表示式书写规则"}
左氧化、右还原；相界面用 $|$，同相不同物质用 $,$，盐桥用 $||$；溶液注明浓度，气体注明压力、温度。
:::

电极半反应为

锌极（发生氧化反应，阳极、负极）：

$$\mathrm{Zn}\rightleftharpoons \mathrm{Zn}^{2+}+2\mathrm{e}^{-}\qquad \bigl(\varphi^{\ominus}_{\mathrm{Zn}^{2+}/\mathrm{Zn}}=-0.763\,\mathrm{V}\bigr)$$

铜极（发生还原反应，阴极、正极）：

$$\mathrm{Cu}^{2+}+2\mathrm{e}^{-}\rightleftharpoons \mathrm{Cu}\qquad \bigl(\varphi^{\ominus}_{\mathrm{Cu}^{2+}/\mathrm{Cu}}=0.337\,\mathrm{V}\bigr)$$

电池总反应为

$$\mathrm{Zn}+\mathrm{Cu}^{2+}\rightleftharpoons \mathrm{Zn}^{2+}+\mathrm{Cu}$$

:::definition{label="电池电动势"}
电池电动势（electromotive force）定义为

$$E=\varphi_{(+)}-\varphi_{(-)}\tag{2-1}$$
:::

上述电池电动势 $E=0.337\,\mathrm{V}-(-0.763\,\mathrm{V})=1.100\,\mathrm{V}$。电动势若为正值，该电池为原电池；若为负值，该电池为电解池。

:::pitfall{label="本版数字：锌 −0.763 V、铜 0.337 V、E=1.100 V"}
不要用其他教材的 $-0.76\,\mathrm{V}$、$0.34\,\mathrm{V}$ 或 $1.10\,\mathrm{V}$ 口诀改写本版。后面判断原电池还是电解池，正负号就卡在 $1.100\,\mathrm{V}$ 这一笔。
:::

### （二）外加反向电压后变成电解池

如果向上述原电池两极上施加一个与电池电动势反方向的外加电压，且电压值大于 $1.100\,\mathrm{V}$，电极反应和电流均将改变方向。

此时电极半反应为

锌极（发生还原反应，阴极）：

$$\mathrm{Zn}^{2+}+2\mathrm{e}^{-}\rightleftharpoons \mathrm{Zn}\qquad \bigl(\varphi^{\ominus}_{\mathrm{Zn}^{2+}/\mathrm{Zn}}=-0.763\,\mathrm{V}\bigr)$$

铜极（发生氧化反应，阳极）：

$$\mathrm{Cu}\rightleftharpoons \mathrm{Cu}^{2+}+2\mathrm{e}^{-}\qquad \bigl(\varphi^{\ominus}_{\mathrm{Cu}^{2+}/\mathrm{Cu}}=0.337\,\mathrm{V}\bigr)$$

电池总反应为

$$\mathrm{Zn}^{2+}+\mathrm{Cu}\rightleftharpoons \mathrm{Zn}+\mathrm{Cu}^{2+}$$

该反应是在消耗外加电压的条件下完成的，把电能转化为化学能，此时该电池为电解池，见图2-3。

::figure{src="/images/instrumental-analysis/textbook/p0019_01.jpg" caption="图2-3　电解池示意图。外电源正极接铜、负极接锌，电子从外电路流入锌极；盐桥沟通 Zn²⁺、SO₄²⁻ 与 Cu²⁺、SO₄²⁻ 两室。" alt="外电源标注 + 接 Cu、- 接 Zn；两烧杯由盐桥相连，分别盛 Zn2+、SO4^2- 和 Cu2+、SO4^2-"}

:::compare{title="同一套铜锌电池：原电池对电解池"}
| 项目 | 原电池（图2-2） | 电解池（图2-3） |
|------|-----------------|-----------------|
| 条件 | 自发；$E=1.100\,\mathrm{V}>0$ | 外加反向电压 $>1.100\,\mathrm{V}$ |
| 锌极 | 氧化、阳极、负极 | 还原、阴极 |
| 铜极 | 还原、阴极、正极 | 氧化、阳极 |
| 总反应 | $\mathrm{Zn}+\mathrm{Cu}^{2+}\rightarrow \mathrm{Zn}^{2+}+\mathrm{Cu}$ | $\mathrm{Zn}^{2+}+\mathrm{Cu}\rightarrow \mathrm{Zn}+\mathrm{Cu}^{2+}$ |
| 能量 | 化学能 → 电能 | 电能 → 化学能 |
:::

:::memory{label="原电池：左氧右还；电解池：外加电压把方向拧过来"}
电池表示式永远左氧化、右还原。电解池不是另画一套电极，而是外加电压大于 $E$ 后，原来的负极变成阴极（还原）、正极变成阳极（氧化）。
:::

## 三、电极的分类

### （一）按反应机理分类

#### 1. 金属基电极

金属基电极基于氧化还原反应，以电子的转移为基础。常用的金属基电极有以下 3 种类型。

:::definition{label="金属–金属离子电极（第一类电极）"}
能发生氧化还原反应的金属插在该金属离子的溶液中组成的电极称为金属–金属离子电极，简称金属电极，用 $\mathrm{M}\,|\,\mathrm{M}^{n+}$ 表示。电极电位取决于溶液中金属离子的活度（或浓度），可用于测定金属离子的浓度。此类电极含有 1 个相界面，也称第一类电极。
:::

例如，将银丝插入 $\mathrm{Ag}^{+}$ 溶液中组成的 $\mathrm{Ag}$ 电极，表示式为 $\mathrm{Ag}\,|\,\mathrm{Ag}^{+}$。

电极反应：$\mathrm{Ag}^{+}+\mathrm{e}^{-}\rightleftharpoons \mathrm{Ag}$

$$\varphi=\varphi^{\ominus}+0.0592\,\mathrm{V}\,\lg a_{\mathrm{Ag}^{+}}\quad\text{或}\quad \varphi=\varphi^{\ominus\prime}+0.0592\,\mathrm{V}\,\lg c_{\mathrm{Ag}^{+}}$$

:::definition{label="金属–金属难溶盐电极（第二类电极）"}
由表面涂有同一种金属难溶盐的金属，插在该难溶盐的阴离子溶液中构成，用 $\mathrm{M}\,|\,\mathrm{M}_{m}\mathrm{X}_{n}\,(\mathrm{s})\,|\,\mathrm{X}^{m-}$ 表示。其电极电位随溶液中阴离子浓度的变化而变化，可用于测定难溶盐阴离子的浓度。此类电极含有 2 个相界面，也称第二类电极。
:::

例如，将表面涂有 $\mathrm{AgCl}$ 的银丝插入含 $\mathrm{Cl}^{-}$ 的溶液中，组成 $\mathrm{Ag}\,|\,\mathrm{AgCl}\,(\mathrm{s})\,|\,\mathrm{Cl}^{-}$ 电极。

电极反应：$\mathrm{AgCl}(\mathrm{s})+\mathrm{e}^{-}\rightleftharpoons \mathrm{Ag}+\mathrm{Cl}^{-}$

$$\varphi=\varphi^{\ominus}-0.0592\,\mathrm{V}\,\lg a_{\mathrm{Cl}^{-}}\quad\text{或}\quad \varphi=\varphi^{\ominus\prime}-0.0592\,\mathrm{V}\,\lg a_{\mathrm{Cl}^{-}}$$

:::definition{label="惰性金属电极（零类电极）"}
由惰性金属（铂或金）插入同一元素的氧化型和还原型电对的溶液中组成，用 $\mathrm{Pt}\,(\mathrm{Au})\,|\,\mathrm{M}^{m+},\,\mathrm{M}^{n+}$ 表示。惰性金属本身不参与电极反应，仅在电极反应过程中起传递电子的作用。电极电位取决于溶液中氧化型和还原型活度（或浓度）的比值。此类电极也称氧化还原电极，又称零类电极。
:::

例如，将铂丝插入含有 $\mathrm{Fe}^{3+}$ 和 $\mathrm{Fe}^{2+}$ 的溶液中组成 $\mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$ 电对的铂电极，即 $\mathrm{Pt}\,|\,\mathrm{Fe}^{3+},\,\mathrm{Fe}^{2+}$。

电极反应：$\mathrm{Fe}^{3+}+\mathrm{e}^{-}\rightleftharpoons \mathrm{Fe}^{2+}$

$$\varphi=\varphi^{\ominus}+0.0592\,\mathrm{V}\,\lg\frac{a_{\mathrm{Fe}^{3+}}}{a_{\mathrm{Fe}^{2+}}}\quad\text{或}\quad \varphi=\varphi^{\ominus\prime}+0.0592\,\mathrm{V}\,\lg\frac{c_{\mathrm{Fe}^{3+}}}{c_{\mathrm{Fe}^{2+}}}$$

:::compare{title="三类金属基电极"}
| 类型 | 表示 | 相界面 | 电位取决于 | 例子 |
|------|------|--------|------------|------|
| 第一类：金属–金属离子 | $\mathrm{M}\,|\,\mathrm{M}^{n+}$ | 1 个 | $a_{\mathrm{M}^{n+}}$ | $\mathrm{Ag}\,|\,\mathrm{Ag}^{+}$ |
| 第二类：金属–难溶盐 | $\mathrm{M}\,|\,\mathrm{M}_{m}\mathrm{X}_{n}(\mathrm{s})\,|\,\mathrm{X}^{m-}$ | 2 个 | $a_{\mathrm{X}^{m-}}$ | $\mathrm{Ag}\,|\,\mathrm{AgCl}(\mathrm{s})\,|\,\mathrm{Cl}^{-}$ |
| 零类：惰性金属 | $\mathrm{Pt}(\mathrm{Au})\,|\,\mathrm{Ox},\,\mathrm{Red}$ | 惰性金属不参与反应 | $a_{\mathrm{Ox}}/a_{\mathrm{Red}}$ | $\mathrm{Pt}\,|\,\mathrm{Fe}^{3+},\,\mathrm{Fe}^{2+}$ |
:::

:::pitfall{label="0.0592 V 是 25 °C、n=1 的 2.303RT/F，不要改成 0.059"}
本版能斯特斜率统一写成 $0.0592\,\mathrm{V}$。第一类对阳离子取正号，第二类对阴离子取负号；零类写氧化型/还原型活度比。把第二类也写成 $+0.0592\,\mathrm{V}\,\lg a_{\mathrm{Cl}^{-}}$，银–氯化银和甘汞电极的电位都会随 $\mathrm{Cl}^{-}$ 升而升，方向反了。
:::

#### 2. 膜电极

:::definition{label="膜电极"}
以固体膜或液体膜为传感体、用于指示溶液中某种离子浓度的电极统称膜电极。响应机制主要是基于响应离子在敏感膜上产生交换和扩散。膜电极是电位分析法中应用最多的一种指示电极，多数离子选择电极和测量溶液 $\mathrm{pH}$ 用的玻璃电极均属膜电极，其特性在第 3 节讨论。
:::

:::insight{label="膜电极不靠交换电子，靠交换和扩散离子"}
金属基电极的户头是氧化还原、电子转移；膜电极的户头是敏感膜上的离子交换和扩散。玻璃电极测 $\mathrm{pH}$ 时电极上无电子交换，所以不受溶液中氧化还原剂干扰——第 3 节还要再写一次。
:::

### （二）按电极的功能分类

:::definition{label="指示电极"}
电化学测量过程中，电极电位随溶液中待测离子的活度（或浓度）的变化而变化，并能反映出待测离子活度（或浓度）的电极称为指示电极（indicating electrode）。金属基电极和膜电极均可作为指示电极。
:::

:::definition{label="参比电极"}
在测量过程中，电极电位不受溶液组成变化的影响、电位值基本固定不变的电极称为参比电极（reference electrode）。电位分析法用指示电极和参比电极组成测量电池。常用的参比电极有饱和甘汞电极和银–氯化银电极。
:::

#### 1. 饱和甘汞电极

:::definition{label="饱和甘汞电极"}
饱和甘汞电极（saturated calomel electrode，SCE）：一般的甘汞电极由金属汞、甘汞（$\mathrm{Hg_2Cl_2}$）和 $\mathrm{KCl}$ 溶液组成，用 $\mathrm{Hg}\,|\,\mathrm{Hg_2Cl_2}\,|\,\mathrm{KCl}$ 表示。使用饱和 $\mathrm{KCl}$ 溶液的电极称为饱和甘汞电极。结构简单、制造容易、使用方便、电位稳定，最为常用。
:::

饱和甘汞电极由内、外两个玻璃管构成：内管盛有 $\mathrm{Hg}$ 和 $\mathrm{Hg}$–$\mathrm{Hg_2Cl_2}$ 的糊状混合物，下端用石棉或纸浆类多孔物质堵紧组成内部电极，上端封入一段铂丝与导线连接。外部套管内盛有 $\mathrm{KCl}$ 饱和溶液，电极下部与待测试液接触部分是素烧瓷微孔物质隔层，用于阻止电极内外溶液的相互混合，又为内外溶液提供离子的通道，兼起测量电位时的盐桥作用。结构如图2-4（a）所示。

电极反应：

$$\mathrm{Hg_2Cl_2}(\mathrm{s})+2\mathrm{e}^{-}\rightleftharpoons 2\mathrm{Hg}+2\mathrm{Cl}^{-}$$

$$\varphi=\varphi^{\ominus}-0.0592\,\mathrm{V}\,\lg a_{\mathrm{Cl}^{-}}\quad\text{或}\quad \varphi=\varphi^{\ominus\prime}-0.0592\,\mathrm{V}\,\lg a_{\mathrm{Cl}^{-}}$$

甘汞电极的电极电位取决于 $\mathrm{KCl}$ 溶液的浓度。在 $25^{\circ}\mathrm{C}$，$\mathrm{KCl}$ 溶液浓度分别为 $0.1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$、$1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ 和饱和溶液时，电极电位分别为 $0.334\,\mathrm{V}$、$0.280\,\mathrm{V}$ 和 $0.241\,\mathrm{V}$。

::figure{src="/images/instrumental-analysis/textbook/p0021_01.jpg" caption="图2-4　饱和甘汞电极和银–氯化银电极。（a）内管汞与甘汞糊、外套饱和 KCl、下端多孔物质；（b）Ag/AgCl 丝、Cl⁻ 参比溶液、加液口与多孔陶瓷。" alt="左：饱和甘汞电极剖面，标导线、绝缘体、汞、甘汞糊、饱和KCl、多孔物质；右：银-氯化银电极，标电极帽、加液口、Cl-参比溶液、Ag/AgCl、多孔陶瓷"}

:::compare{title="25 °C 甘汞电极电位与 KCl 浓度"}
| $\mathrm{KCl}$ | 电极电位 |
|----------------|----------|
| $0.1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ | $0.334\,\mathrm{V}$ |
| $1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ | $0.280\,\mathrm{V}$ |
| 饱和（SCE） | $0.241\,\mathrm{V}$ |
:::

#### 2. 银–氯化银电极

:::definition{label="银–氯化银电极"}
银–氯化银电极（silver-silver chloride electrode）由涂覆一层氯化银的银丝插入一定浓度的 $\mathrm{KCl}$ 溶液（或含 $\mathrm{Cl}^{-}$ 的溶液）中组成。电极内充溶液用素烧瓷或其他适用的微孔材料隔层与待测溶液隔开，以阻止电极内外溶液互相混合。图2-4（b）是一种银–氯化银电极的结构。
:::

电极溶液分别为 $0.1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$、$1.0\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ 和饱和 $\mathrm{KCl}$ 溶液时，其电极电位分别为 $0.288\,\mathrm{V}$、$0.222\,\mathrm{V}$ 和 $0.199\,\mathrm{V}$。银–氯化银电极结构简单，可制成很小体积，常用作玻璃电极和其他离子选择电极的内参比电极。

:::compare{title="25 °C 银–氯化银电极电位与 KCl 浓度"}
| $\mathrm{KCl}$ | 电极电位 |
|----------------|----------|
| $0.1\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ | $0.288\,\mathrm{V}$ |
| $1.0\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ | $0.222\,\mathrm{V}$ |
| 饱和 | $0.199\,\mathrm{V}$ |
:::

:::pitfall{label="SCE 是 0.241 V，饱和 Ag/AgCl 是 0.199 V，不要对调"}
甘汞：$0.334/0.280/0.241\,\mathrm{V}$。银–氯化银：$0.288/0.222/0.199\,\mathrm{V}$。内参比常用银–氯化银，外参比常用 SCE。把 $0.241\,\mathrm{V}$ 写到银–氯化银头上，两次测量法的常数项会对错账。
:::

:::keypoint{label="指示电极对参比电极"}
- 指示电极：$\varphi$ 随待测离子活度变，金属基或膜电极都可以当。
- 参比电极：$\varphi$ 基本固定，常用 SCE 和 $\mathrm{Ag}/\mathrm{AgCl}$。
- 测量电池：指示电极（一般为负极）+ 参比电极（一般为正极）。
:::

## 四、可逆电极和可逆电池

当一个无限小的电流以相反方向通过电极时，若发生的电极反应互为逆反应，此类电极反应称为可逆电极反应，如 $\mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$、$\mathrm{Ce}^{4+}/\mathrm{Ce}^{3+}$、$\mathrm{I}_2/\mathrm{I}^{-}$。如果一个电极的电极反应是可逆的，并且反应速率很快，便称为可逆电极。如果电极反应不可逆，反应速率慢，则称为不可逆电极，如 $\mathrm{MnO_4}^{-}/\mathrm{Mn}^{2+}$、$\mathrm{S_2O_8}^{2-}/\mathrm{S_2O_3}^{2-}$。可逆电极达到平衡电位快，测量时电极电位稳定，受扰动后平衡电位恢复得也快。

:::definition{label="可逆电极"}
电极反应可逆且反应速率很快的电极。可逆电极反应的判据：无限小电流以相反方向通过时，发生的电极反应互为逆反应。
:::

:::definition{label="可逆电池"}
组成电池的两个电极都是可逆电极时，此类电池称为可逆电池。如果两个电极或其中之一是不可逆电极，则称为不可逆电池。只有可逆电极与可逆电池才能用热力学公式处理。电位分析法要求电极和电池必须满足可逆电极和可逆电池的条件。
:::

:::compare{title="可逆电对与不可逆电对（本版名单）"}
| | 教材例子 |
|--|----------|
| 可逆 | $\mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$、$\mathrm{Ce}^{4+}/\mathrm{Ce}^{3+}$、$\mathrm{I}_2/\mathrm{I}^{-}$ |
| 不可逆 | $\mathrm{MnO_4}^{-}/\mathrm{Mn}^{2+}$、$\mathrm{S_2O_8}^{2-}/\mathrm{S_2O_3}^{2-}$ |
:::

:::pitfall{label="电位分析法的可逆，和永停滴定里“可逆电对”不是同一句考题"}
本节的可逆电极：反应可逆且快，才能用热力学、电位稳定。第 5 节永停滴定的可逆电对：外加几十毫伏时两个相同铂电极上能同时发生氧化和还原、有电流通过。$\mathrm{I}_2/\mathrm{I}^{-}$ 两处都出现，但判据不同；$\mathrm{S_4O_6}^{2-}/\mathrm{S_2O_3}^{2-}$ 在永停滴定里作为不可逆电对另写。不要把两本账并成一句。
:::

## 五、电极电位的测量

单个电极的电位（$\varphi_{x}$）是无法直接测量的。欲测某电极电位值，是将对待测溶液有响应的指示电极（一般为负极）和合适的参比电极（一般为正极，$\varphi_{\mathrm{R}}$）组成原电池，该电池的电动势为

$$E=\varphi_{\mathrm{R}}-\varphi_{x}+\varphi_{\mathrm{j}}+iR \tag{2-2}$$

式中，$\varphi_{\mathrm{j}}$ 为液接电位，$i$ 为通过电池的电流，$R$ 为电池的内阻，$iR$ 为内阻产生的电位降。实验时可利用盐桥尽量减小液接电位，并控制测量条件降低 $i$ 值，使式（2-2）最后两项小到可以忽略不计，则简化为

$$E=\varphi_{\mathrm{R}}-\varphi_{x} \tag{2-3}$$

式（2-3）表明，在满足近似条件时测得 $E$，便可求得待测电极的电极电位。将参比电极与标准氢电极组成电池，所测得的电池电动势即是参比电极的电极电位（$\varphi_{\mathrm{R}}$）。其他电极的标准电极电位也可以通过此法测得。

:::definition{label="电极电位不能单独测量"}
单个电极电位无法直接测量。必须把指示电极与参比电极组成原电池，在液接电位和 $iR$ 降可忽略时，$E=\varphi_{\mathrm{R}}-\varphi_{x}$。
:::

:::derivation{title="从完整电动势到可计算的 E=φR−φx"}
完整式含四项：$\varphi_{\mathrm{R}}$、$\varphi_{x}$、$\varphi_{\mathrm{j}}$、$iR$。盐桥把 $\varphi_{\mathrm{j}}$ 压到 $1\sim 2\,\mathrm{mV}$；高输入阻抗电子电位计把 $i$ 降到可忽略，于是 $E\approx \varphi_{\mathrm{R}}-\varphi_{x}$。玻璃电极内阻约 $100\,\mathrm{M}\Omega$，第 3 节还要定量说明为什么普通伏特计不能用。
:::

测量上述电池电动势不能用一般的伏特计。因为将伏特计并联到电池两极上测量电动势时，会有相当大的电流通过电池，这一电流产生的电位降不容忽略。现多用直读式电子电位计（电子毫伏计、$\mathrm{pH}$ 计和离子计等）。

:::pitfall{label="不要用普通伏特计去读电位分析的电动势"}
伏特计取电流大，$iR$ 降不能忽略，式（2-3）不成立。直读式电子电位计（电子毫伏计、$\mathrm{pH}$ 计、离子计）才是本节允许的仪表。第 3 节还给出数量级：内阻 $100\,\mathrm{M}\Omega$、电流 $10^{-9}\,\mathrm{A}$ 时 $iR=0.1\,\mathrm{V}$，相当于约 $1.6\,\mathrm{pH}$ 单位的误差。
:::

:::concept{term="先问指示电极对参比电极，再问盐桥和 iR 能不能忽略"}
电位分析法的测量电池永远是一对电极。指示电极把待测活度写成 $\varphi_{x}$，参比电极提供 $\varphi_{\mathrm{R}}$，盐桥和电子电位计把 $\varphi_{\mathrm{j}}+iR$ 丢掉，剩下 $E=\varphi_{\mathrm{R}}-\varphi_{x}$。第 3 节的两次测量法，就是在 $K''$ 未知时用标准缓冲把常数项减掉。
:::
