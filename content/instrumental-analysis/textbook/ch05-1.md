# 第1节　概述

本章打开分子荧光分析法。先把户头写成分子发光分析法：分子吸收能量从基态被激发到较高电子能态，返回基态时以光辐射形式释放能量，通过测量分子的特征发射光谱来研究物质结构和测定化学组成。激发能可以来自光能、化学能、热能、电能等，本版按来源分成光致发光、生物发光和化学发光。最常见的光致发光是荧光和磷光。本章主要介绍荧光分析法，不要把磷光、化学发光写成专章，也不要提前搬第 6 章红外。

物质分子吸收了能量从基态被激发到较高电子能态后，在返回基态时以光辐射形式释放能量，通过测量分子的特征发射光谱来研究物质结构和测定其化学组成的方法，称为分子发光分析法（molecular luminescence analysis）。

:::definition{label="分子发光分析法"}
分子发光分析法（molecular luminescence analysis）通过测量分子的特征发射光谱来研究物质结构和测定其化学组成。前提是：分子吸收能量从基态被激发到较高电子能态，返回基态时以光辐射形式释放能量。
:::

:::concept{term="先问能量从哪来，再问回来时发的是荧光还是磷光"}
看见“发光分析”，先不要跳到荧光计按键。户头是：分子被激发、再以光辐射回到基态，测的是发射光谱而不是吸收光谱。能量来源不同，名字不同：光能是光致发光，生物体内有酶参与的化学反应是生物发光，一般化学反应的化学能是化学发光。回来的路不同，名字也不同：从激发态最低振动能级回基态是荧光，从激发三重态最低振动能级回基态是磷光。把吸收光谱的朗伯–比尔定律直接当成荧光定量，或把荧光和磷光并成同一种光，后面激发光谱、发射光谱和 $90^\circ$ 光路都会对错户头。
:::

:::insight{label="本章测的是发射，不是透射比"}
第 4 章紫外–可见分光光度法测的是分子吸收了多少光。本章测的是分子把吸收的能量再以光辐射形式吐出来。两本账都落在紫外–可见电子能级上，但仪器光路、定量公式和干扰来源都不一样。
:::

## 一、激发能量从哪来：光致发光、生物发光、化学发光

物质分子从基态跃迁到激发态所需的能量可以来自不同方式，如光能、化学能、热能、电能等。

如果分子吸收了光能而被激发，并以发射光辐射的形式回到基态，这种现象称为光致发光（photoluminescence，PL）。

如果分子吸收了生物体内有酶类物质参与的化学反应释放的能量而被激发，并以发射光辐射的形式回到基态，这种现象称为生物发光（bioluminescence，BL）。

如果分子吸收了化学反应的化学能而被激发，并以发射光辐射的形式回到基态，这种现象称为化学发光（chemiluminescence，CL）。

:::definition{label="光致发光"}
光致发光（photoluminescence，PL）：分子吸收光能被激发，再以发射光辐射的形式回到基态。最常见的是荧光和磷光。
:::

:::definition{label="生物发光"}
生物发光（bioluminescence，BL）：分子吸收生物体内有酶类物质参与的化学反应释放的能量而被激发，再以发射光辐射的形式回到基态。
:::

:::definition{label="化学发光"}
化学发光（chemiluminescence，CL）：分子吸收化学反应的化学能而被激发，再以发射光辐射的形式回到基态。
:::

:::compare{title="三种发光按能量来源分户"}
| 名称 | 英文缩写 | 激发能量从哪来 | 回到基态时 |
|------|----------|----------------|------------|
| 光致发光 | photoluminescence，PL | 光能 | 发射光辐射 |
| 生物发光 | bioluminescence，BL | 生物体内有酶参与的化学反应所释放的能量 | 发射光辐射 |
| 化学发光 | chemiluminescence，CL | 化学反应的化学能 | 发射光辐射 |
:::

:::pitfall{label="生物发光不是化学发光的别名"}
二者都靠化学反应供能，但本版把生物发光单独写成：生物体内、有酶类物质参与。把萤火虫和试管里的化学发光并成一户，后面试剂 derivatization 和酶联那几笔会对空。热能、电能本版点了名，但本章不另立热致发光或电致发光专节。
:::

:::keypoint{label="激发能四条来源，本章只用光能那一条做主线"}
- 光能 → 光致发光（荧光、磷光）。
- 化学能 → 化学发光。
- 生物体内有酶参与的化学能 → 生物发光。
- 热能、电能本版点名，不展开。
:::

## 二、荧光、磷光和荧光分析法

最常见的光致发光现象是荧光和磷光。

荧光（fluorescence）是物质分子吸收光子能量被激发后，从激发态的最低振动能级回到基态时所发射的光。根据物质的荧光谱线特性及其强度进行定性、定量分析的方法称为荧光分析法（fluorescence analysis）。

:::definition{label="荧光"}
荧光（fluorescence）是物质分子吸收光子能量被激发后，从激发态的最低振动能级回到基态时所发射的光。
:::

:::definition{label="荧光分析法"}
根据物质的荧光谱线特性及其强度进行定性、定量分析的方法，称为荧光分析法（fluorescence analysis）。
:::

根据被测物质的不同，荧光可以分为分子荧光和原子荧光；根据激发光波长的不同，荧光又可分为紫外–可见荧光、红外荧光和 X 射线荧光。基于某些有机物质的分子在用紫外–可见光激发时发射的荧光建立的方法，称为分子荧光分析法（molecular fluorescence analysis）。

:::definition{label="分子荧光与原子荧光"}
按被测物质分：分子荧光、原子荧光。原子荧光是原子光谱的户头，本章不写原子化器。
:::

:::definition{label="按激发光波长分的三类荧光"}
按激发光波长分：紫外–可见荧光、红外荧光、X 射线荧光。本版只点名，不另给波长表。
:::

:::definition{label="分子荧光分析法"}
分子荧光分析法（molecular fluorescence analysis）基于某些有机物质的分子在用紫外–可见光激发时发射的荧光。本章标题里的“分子荧光”落在这一句。
:::

:::pitfall{label="不要把 X 射线荧光并进本章操作"}
X 射线荧光是按激发光波长分出来的一类荧光，第 1 章已经把它划到光谱法。本章分子荧光分析法明确写：有机分子、紫外–可见光激发。不要把 XRF 的内层电子空位搬进来，也不要把第 6 章红外荧光当成分子荧光的定量主线。
:::

磷光（phosphorescence）是物质分子吸收光子能量被激发后，从激发三重态的最低振动能级回到基态时所发射出的光。由测量磷光强度建立起来的分析方法称为磷光分析法（phosphorescence analysis）。

:::definition{label="磷光"}
磷光（phosphorescence）是物质分子吸收光子能量被激发后，从激发三重态的最低振动能级回到基态时所发射出的光。
:::

:::definition{label="磷光分析法"}
由测量磷光强度建立起来的分析方法，称为磷光分析法（phosphorescence analysis）。
:::

:::compare{title="荧光和磷光：回来的那一级不一样"}
| 项目 | 荧光 | 磷光 |
|------|------|------|
| 定义落点 | 从激发态的最低振动能级回到基态 | 从激发三重态的最低振动能级回到基态 |
| 自旋 | 第 2 节写成激发单重态 $\mathrm{S}_1$ | 第 2 节写成激发三重态 $\mathrm{T}_1$ |
| 分析方法 | 荧光分析法 | 磷光分析法 |
| 本章地位 | 主线 | 对照，室温下很少呈现 |
:::

:::pitfall{label="本节定义里的“激发态最低振动能级”还没写成 S₁"}
概述把荧光写成“激发态的最低振动能级”，把磷光写成“激发三重态的最低振动能级”。单重态、三重态、体系间跨越是第 2 节的事。不要在概述里提前默写完整的 Jablonski 图，但也不要把两句定义听成同一种光。
:::

## 三、分子发光分析法包括哪几类，本章写哪一类

根据发光物质发射的光谱及发射光的强度对待测物进行定性和定量分析的方法，称为化学发光分析法。综上所述，分子发光分析法主要包括分子荧光分析法、磷光分析法和化学发光分析法，本章主要介绍荧光分析法。

:::definition{label="化学发光分析法"}
根据发光物质发射的光谱及发射光的强度对待测物进行定性和定量分析的方法，称为化学发光分析法。
:::

:::definition{label="分子发光分析法的三块"}
分子发光分析法主要包括：分子荧光分析法、磷光分析法、化学发光分析法。本章主要介绍荧光分析法。
:::

:::compare{title="分子发光三块，本章只展开荧光"}
| 方法 | 测什么 | 本章 |
|------|--------|------|
| 分子荧光分析法 | 紫外–可见光激发有机分子后的荧光 | 主线：原理、定量、仪器、应用 |
| 磷光分析法 | 磷光强度 | 第 2 节对照去活化途径；室温少见 |
| 化学发光分析法 | 化学发光的光谱和强度 | 概述点名，不专章 |
:::

:::note{label="化学发光分析法的定义句不要和化学发光现象并丢"}
化学发光（CL）是现象：吸收化学反应的化学能再发光。化学发光分析法是方法：用发射光谱和发射光强度做定性定量。两句都要留。
:::

## 四、分子发光分析法的优点和落点

分子发光分析法具有高灵敏度、高选择性、方法简便、取样量少等优点。近年来，在医药和临床分析中的应用日趋广泛，发展十分迅速，受到分析工作者的广泛关注。

:::definition{label="分子发光分析法的优点"}
高灵敏度、高选择性、方法简便、取样量少。
:::

:::insight{label="优点先登记，灵敏度为什么高于紫外–可见放到第 3 节"}
概述只写四条优点。荧光强度与浓度的线性条件、检测器放大为什么对荧光有用而对透光率比值没用，是第 3 节的推导，不要在这里插入 $F=Kc$。
:::

:::cause-effect{title="为什么医药和临床爱用分子发光"}
- **因** 灵敏度高、选择性高、方法简便、取样量少
- **果** 近年在医药和临床分析中应用日趋广泛，可做体液中药物浓度测定及体内代谢研究（第 5 节再给试剂和实例）
:::

:::memory{label="分子发光三问"}
问法：分子发光分析法测的是什么光谱？能量来源怎么分？荧光和磷光从哪一级回来？本章写哪一块？
答：测分子的特征发射光谱。光能→光致发光（PL），酶参与的生物化学反应→生物发光（BL），化学反应化学能→化学发光（CL）。荧光从激发态最低振动能级回基态，磷光从激发三重态最低振动能级回基态。分子发光包括分子荧光、磷光、化学发光；本章主要介绍荧光分析法，对象是紫外–可见光激发的有机分子。
:::
