# 第1节　化学分析与仪器分析

本章打开仪器分析。先把仪器分析写成：靠测量物质的物理或物理化学性质、参数及其变化，来确定化学组成、成分含量和化学结构的一类分析方法；因为需要较为复杂或特殊的仪器设备，所以叫仪器分析。再和化学分析分户：化学分析以化学反应及其计量关系为基础，是经典分析化学；仪器分析大约从 20 世纪 40 年代发展起来，已成为当代分析化学的主流。二者的区别不是绝对的——绝大部分仪器分析法是相对分析法，标准物含量仍要用化学分析法确定。

仪器分析（instrumental analysis）是通过测量物质的物理或物理化学性质、参数及变化来确定其化学组成、成分含量及化学结构的一类分析方法。由于这类分析方法需要较为复杂或特殊的仪器设备，因此称之为仪器分析。

:::definition{label="仪器分析"}
仪器分析（instrumental analysis）是通过测量物质的物理或物理化学性质、参数及变化来确定其化学组成、成分含量及化学结构的一类分析方法。因为需要较为复杂或特殊的仪器设备，所以称为仪器分析。
:::

:::concept{term="先问测的是哪一类性质，再问为什么必须上仪器"}
看见“仪器分析”，先不要跳到某一种光谱或色谱的操作步骤。户头是：测物理或物理化学性质、参数及其变化，用来回答组成、含量和结构。仪器之所以成为方法名，是因为这类测量通常需要较为复杂或特殊的设备，不是因为“实验室里出现了任何一台仪器”。把化学分析听成“完全不用仪器”，或把仪器分析听成“和化学反应、化学计量无关”，后面相对分析法、预处理和标准物那几笔都会对错户头。
:::

:::note{label="英文不要粘连"}
本版教材把英文写成 instrumental analysis，两个词。扫描稿里的 instrumentalanalysis 是 OCR 粘连，不是另一个学科名。
:::

## 一、分析化学的两大部分

分析化学包括化学分析和仪器分析两大部分。以物质的化学反应及其计量关系为基础的分析方法称为化学分析法，其内容包括定性分析、滴定分析和重量分析等方法，测定时一般只需用化学试剂、天平、玻璃器皿和其他普通实验室器具。这类方法发展较早，应用广泛，是分析化学的基础，所以又有经典分析化学之称，主要应用于物质成分的定性分析和定量分析。

:::definition{label="化学分析法"}
化学分析法以物质的化学反应及其计量关系为基础。内容包括定性分析、滴定分析和重量分析等方法。测定时一般只需用化学试剂、天平、玻璃器皿和其他普通实验室器具。
:::

:::definition{label="经典分析化学"}
化学分析法发展较早，应用广泛，是分析化学的基础，所以又有经典分析化学之称。它主要应用于物质成分的定性分析和定量分析。
:::

:::pitfall{label="化学分析不是“完全不用仪器”"}
教材写的是“一般只需用化学试剂、天平、玻璃器皿和其他普通实验室器具”。天平已经是仪器，只是普通实验室器具，不是“较为复杂或特殊的仪器设备”。不要把化学分析听成徒手、也不要把“用了天平”升级成仪器分析。
:::

:::compare{title="化学分析管什么、不管什么"}
| 项目 | 化学分析法（经典分析化学） | 不要听成 |
|------|----------------------------|----------|
| 基础 | 化学反应及其计量关系 | 测电导、光谱、质荷比也算化学分析 |
| 内容 | 定性分析、滴定分析、重量分析等 | 结构、价态、表面、遥测也已经包括在内 |
| 器具 | 化学试剂、天平、玻璃器皿和其他普通实验室器具 | 完全不用任何器具 |
| 主要用途 | 物质成分的定性分析和定量分析 | 当代分析化学的全部工作 |
| 地位 | 分析化学的基础，发展较早、应用广泛 | 已经被仪器分析淘汰、可以不再学 |
:::

仪器分析是 20 世纪 40 年代发展起来的一类分析方法。它除了用于成分的定性和定量分析之外，还可用于物质的结构、价态和状态分析；表面、微区、纵深分析及遥测、遥控分析；化学反应有关参数的测定及为其他学科提供各种有用化学信息等。因此，仪器分析不仅是重要的分析测试方法，而且是强有力的科学研究手段，已成为当代分析化学的主流。

:::definition{label="仪器分析的工作范围"}
仪器分析除用于成分的定性和定量分析之外，还可用于：物质的结构、价态和状态分析；表面、微区、纵深分析及遥测、遥控分析；化学反应有关参数的测定；以及为其他学科提供各种有用化学信息。
:::

:::insight{label="主流不是“只做定量”，而是测试手段加研究手段"}
教材把仪器分析写成两句话：它是重要的分析测试方法，也是强有力的科学研究手段，因此成为当代分析化学的主流。不要把“主流”听成“化学分析已经作废”，也不要把仪器分析收成只报一个含量。结构、价态、状态、表面、微区、纵深、遥测遥控、反应参数，都在同一本账里。
:::

:::keypoint{label="仪器分析比化学分析多出来的几本账"}
- 成分：定性、定量（化学分析也做）。
- 结构、价态、状态。
- 表面、微区、纵深。
- 遥测、遥控。
- 化学反应有关参数。
- 为其他学科提供化学信息。
:::

当然，仪器分析与化学分析的区别不是绝对的。化学分析需要使用简单的仪器；而仪器分析是在化学分析的基础上建立起来的，一些仪器分析方法的原理会涉及化学分析的基本理论；仪器分析中的预处理，如样品的溶解，共存组分的掩蔽、分离或化学富集等，主要使用化学分析的方法；另外，绝大部分仪器分析法都是相对分析法，即未知物的分析结果都是通过与已知标准物作比较（校准曲线法、标准加入法或对照法）而确定的，而所用标准物的含量都要用化学分析法来确定。

:::definition{label="相对分析法"}
绝大部分仪器分析法都是相对分析法：未知物的分析结果通过与已知标准物作比较而确定。教材点名的比较方式是校准曲线法、标准加入法或对照法。所用标准物的含量都要用化学分析法来确定。
:::

:::definition{label="校准曲线法、标准加入法、对照法"}
这是教材为相对分析法列出的三种与已知标准物作比较的方式。未知物不靠仪器“自己报出一个绝对真值”，而靠和标准物对齐。
:::

:::compare{title="仪器分析与化学分析：区别不是绝对的"}
| 教材原句 | 落点 | 不要听成 |
|----------|------|----------|
| 化学分析需要使用简单的仪器 | 化学分析也用仪器，只是简单、普通 | 化学分析＝零仪器 |
| 仪器分析是在化学分析的基础上建立起来的 | 原理会涉及化学分析的基本理论 | 仪器分析另起炉灶、与化学反应无关 |
| 预处理主要使用化学分析的方法 | 溶解、掩蔽、分离、化学富集仍走化学分析 | 上机前什么都不用做，或预处理也是“另一种仪器分析” |
| 绝大部分仪器分析法是相对分析法 | 未知物与标准物比较；标准物含量用化学分析法确定 | 仪器给出的就是绝对含量，化学分析可以不再标定标准物 |
:::

:::pitfall{label="不要把仪器读数听成绝对含量"}
教材把“绝大部分仪器分析法”写成相对分析法。校准曲线、标准加入、对照，都是在和已知标准物比较。标准物自己的含量，还要用化学分析法来确定。把光谱峰高、色谱峰面积直接当成“绝对克数”，常量、痕量那一笔准确度账会对不上；把标准物听成“仪器厂家已经写死、不必再用化学分析标定”，相对分析法的户头就空了。
:::

:::cause-effect{title="为什么学仪器分析还要巩固化学分析"}
- **因** 仪器分析建立在化学分析之上：原理涉及化学分析基本理论；预处理（溶解、掩蔽、分离、化学富集）主要用化学分析方法；相对分析法所用标准物的含量要用化学分析法确定
- **果** 学习仪器分析时，应继续巩固和进一步熟练掌握化学分析的有关知识和实验技能，才能全面掌握仪器分析法
:::

## 二、与化学分析相比较：仪器分析的优点

与化学分析相比较，仪器分析的优点包括三条。

**① 灵敏度高。** 其绝对灵敏度甚至可达 $1\times 10^{-14}\,\mathrm{g}$，远高于化学分析法。样品用量由化学分析的毫升（$\mathrm{mL}$）、毫克（$\mathrm{mg}$）级降低到仪器分析的微升（$\mu\mathrm{L}$）、微克（$\mu\mathrm{g}$）级，甚至更低的纳克（$\mathrm{ng}$）级。因此，仪器分析比较适用于微量乃至超微量分析，以及痕量、超痕量组分的测定。

:::definition{label="仪器分析的灵敏度"}
仪器分析方法的灵敏度高，其绝对灵敏度甚至可达 $1\times 10^{-14}\,\mathrm{g}$，远高于化学分析法。
:::

:::definition{label="样品用量的数量级"}
化学分析的样品用量一般在毫升（$\mathrm{mL}$）、毫克（$\mathrm{mg}$）级；仪器分析降低到微升（$\mu\mathrm{L}$）、微克（$\mu\mathrm{g}$）级，甚至更低的纳克（$\mathrm{ng}$）级。
:::

:::insight{label="绝对灵敏度那一笔只写到本版给出的数量级"}
本版教材把绝对灵敏度写成“甚至可达 $1\times 10^{-14}\,\mathrm{g}$”，样品用量写成 $\mathrm{mL}/\mathrm{mg}$ 降到 $\mu\mathrm{L}/\mu\mathrm{g}$、甚至 $\mathrm{ng}$。不要另造检测限、波长或仪器型号来“补全”这一句。它说明仪器分析比较适用于微量乃至超微量分析，以及痕量、超痕量组分的测定，不是说任何一台仪器都已经达到 $1\times 10^{-14}\,\mathrm{g}$。
:::

:::compare{title="样品用量：化学分析与仪器分析"}
| 项目 | 化学分析 | 仪器分析 |
|------|----------|----------|
| 体积／质量数量级 | 毫升（$\mathrm{mL}$）、毫克（$\mathrm{mg}$） | 微升（$\mu\mathrm{L}$）、微克（$\mu\mathrm{g}$），甚至纳克（$\mathrm{ng}$） |
| 更适合 | 常量组分、经典滴定和重量 | 微量、超微量；痕量、超痕量组分 |
| 本版点名的绝对灵敏度 | 远低于仪器分析 | 甚至可达 $1\times 10^{-14}\,\mathrm{g}$ |
:::

**② 选择性好。** 有较高的分辨能力，可以通过选择测试或者分离条件，使共存组分的测定相互间不产生干扰，适用于复杂样品的分析，一般化学分析法很难实现。

:::definition{label="仪器分析的选择性"}
仪器分析选择性好，有较高的分辨能力。可以通过选择测试或者分离条件，使共存组分的测定相互间不产生干扰，适用于复杂样品的分析。一般化学分析法很难实现这一点。
:::

:::pitfall{label="选择性好不是“样品不用处理、什么都能同时测”"}
教材写的是：选择测试或者分离条件，让共存组分相互不干扰。户头仍在条件选择，不是仪器自动消掉一切干扰。复杂样品仍然可能要预处理（溶解、掩蔽、分离、化学富集），那些步骤主要还是化学分析方法。
:::

**③ 操作简便，分析速度快，易于实现自动化、信息化。** 一般在数秒或几分钟内就可完成一项测试工作，大大提高了分析工作效率，特别适用于控制生产过程的在线分析。

:::definition{label="仪器分析的速度与自动化"}
仪器分析操作简便，分析速度快，易于实现自动化、信息化。一般在数秒或几分钟内就可完成一项测试，特别适用于控制生产过程的在线分析。
:::

:::keypoint{label="仪器分析相对化学分析的三条优点"}
- 灵敏度高：绝对灵敏度甚至可达 $1\times 10^{-14}\,\mathrm{g}$；样品用量到 $\mu\mathrm{L}$、$\mu\mathrm{g}$ 乃至 $\mathrm{ng}$ 级；适于微量、超微量以及痕量、超痕量。
- 选择性好：分辨能力较高；靠选择测试或分离条件避免共存组分干扰；适于复杂样品。
- 操作简便、速度快、易自动化信息化：数秒或几分钟完成一项测试；适于生产过程在线分析。
:::

## 三、仪器分析的不足之处，以及怎样和化学分析一起用

仪器分析也有其不足之处。

**① 多数仪器分析方法相对误差较大。** 与化学分析相比，多数仪器分析方法相对误差较大，一般为 $5\%$ 左右，有的甚至更大。这样的准确度对常量组分的分析显然是不适宜的；但对痕量组分的测定，由于绝对误差较小，这样的准确度可以接受且较为理想。

:::definition{label="仪器分析的相对误差"}
与化学分析相比，多数仪器分析方法相对误差较大，一般为 $5\%$ 左右，有的甚至更大。
:::

:::pitfall{label="相对误差约 5% 对常量不适宜，对痕量往往可以接受"}
不要把“仪器更先进”听成“准确度一定更高”。教材把相对误差写成一般为 $5\%$ 左右，对常量组分显然不适宜；对痕量组分，因为绝对误差较小，这样的准确度可以接受且较为理想。常量含量要卡得很紧时，经典滴定、重量分析往往更合适；痕量、超痕量才轮到仪器分析发挥灵敏度优势。把 $5\%$ 相对误差套到常量主含量测定上，或反过来因为相对误差大就宣布仪器分析不能做痕量，两头都会考反。
:::

:::compare{title="相对误差约 5%：常量与痕量不是同一本账"}
| 对象 | 相对误差约 $5\%$ 意味着什么 | 教材判断 |
|------|------------------------------|----------|
| 常量组分 | 绝对误差也跟着大，准确度不够 | 显然不适宜 |
| 痕量组分 | 绝对误差较小 | 可以接受且较为理想 |
| 不要并户 | “仪器分析一律更准”或“仪器分析一律不能定量” | 按常量／痕量分户，再决定用哪一类方法 |
:::

**② 仪器设备复杂，价格较高。** 对维护、管理及环境要求较高，分析成本一般比化学分析高。

:::definition{label="仪器分析的设备与成本"}
仪器设备复杂，价格较高，对维护、管理及环境要求较高，分析成本一般比化学分析高。
:::

:::note{label="本页在“分析成”处翻页"}
印刷页第 1 页写到“分析成”，第 2 页接“本一般比化学分析高”。中间没有丢掉别的优点或第三条不足。不足就是相对误差、设备成本这两条。
:::

由此可见，仪器分析法与化学分析法是相辅相成的，在使用时应根据具体情况选择合适的方法，取长补短，充分发挥各自的优势，从而更好地解决分析化学中的各种实际问题。在学习仪器分析时，应继续巩固和进一步熟练掌握化学分析的有关知识和实验技能，这样才能全面掌握仪器分析法。

:::definition{label="相辅相成"}
仪器分析法与化学分析法是相辅相成的。使用时应根据具体情况选择合适的方法，取长补短，充分发挥各自的优势，以解决分析化学中的各种实际问题。
:::

:::tip{label="选题先问常量还是痕量，再问有没有标准物"}
常量、准确度要求高：化学分析往往更合适。微量、超微量、痕量、超痕量、复杂样品、要结构和状态、要在线：仪器分析更合适。无论选哪一边，预处理和标准物含量仍常常落在化学分析上。不要把本章听成“从这一页起只准用仪器”。
:::

:::memory{label="化学分析与仪器分析分户"}
- 化学分析：化学反应＋计量关系；定性、滴定、重量；试剂、天平、玻璃器皿；经典基础。
- 仪器分析：物理或物理化学性质；20 世纪 40 年代发展起来；当代主流；结构／价态／状态／表面／微区／纵深／遥测遥控也在账上。
- 相对分析法：校准曲线、标准加入、对照；标准物含量用化学分析法确定。
- 优点：灵敏度（甚至 $1\times 10^{-14}\,\mathrm{g}$）、选择性、速度与自动化。
- 不足：相对误差约 $5\%$（常量不宜、痕量可接受）；设备贵、维护和环境要求高。
:::
