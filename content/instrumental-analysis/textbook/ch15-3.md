# 第3节　高效毛细管电泳的分离模式

第 2 节把表观淌度写成 $\mu_{\mathrm{app}}=\mu_{\mathrm{ep}}+\mu_{\mathrm{eo}}$，并交代中性分子在 CZE 里分不开。本节按分离机制把模式摊开。概述名单是 CZE、MEKC、CGE、CITP、CIEF、CEC；本节分类名单换成 CZE、MEKC、CEC、NACE、MEEKC、CGE，没有把等速电泳和等电聚焦写成操作专段。CITP、CIEF 只在第 1 节挂名，不要在这里编灌胶、两性电解质梯度。电渗、Zeta、塞流仍以第 2 节为准。

:::definition{label="分离模式多样化"}
各模式机理不同，信息互不相关而又相互补充，满足不同性质样品，从而构成 CE 的多样化应用。
:::

:::concept{term="先问中性分子能不能靠淌度差分开"}
看见「选模式」，先问样品带不带电。只带电、要按淌度差排：CZE。中性物要拆开：MEKC 或 MEEKC（准固定相／微乳分配），或 CEC（真正的色谱固定相）。大分子按尺寸：CGE。疏水、难溶于水：NACE。把所有样品都灌进 CZE，中性峰会叠在 $t_{0}$ 上。
:::

:::compare{title="概述六种对第 3 节六种"}
| 出现位置 | 名单 |
|----------|------|
| 第 1 节概述 | CZE、MEKC、CGE、CITP、CIEF、CEC |
| 本节 15.3.1 | CZE、MEKC、CEC、NACE、MEEKC、CGE |
:::

## 一、毛细管区带电泳

毛细管区带电泳（capillary zone electrophoresis，CZE）作为 CE 中最简单的一种模式，是以具有 $\mathrm{pH}$ 缓冲能力的电解质溶液作为载体，以毛细管为分离通道的一种高压区带电泳。它的分离原理是基于溶质组分的迁移时间或淌度的不同而分离。由于电渗流的存在，正、负离子都可以用 CZE 来分离，中性溶质则随电渗流流出毛细管，不能用 CZE 来分离。CZE 是 HPCE 中最基础、使用最广泛的模式。

在 CZE 中，其分离主要受到操作缓冲溶液的组成和 $\mathrm{pH}$、缓冲溶液添加剂、运行电压和毛细管温度等因素的影响。可以通过对以上条件的优化获得样品的最佳分离结果。

:::definition{label="毛细管区带电泳"}
CZE。最简单、最基础、使用最广泛。载体是有 $\mathrm{pH}$ 缓冲能力的电解质溶液，通道是毛细管，高压区带电泳。按迁移时间或淌度差分离。
:::

:::pitfall{label="CZE 分不开中性溶质"}
正、负离子都可以做，靠的是电渗把阴离子也拖过检测窗。中性溶质随 EOF 一起走，彼此没有淌度差。要拆开中性物，转到 MEKC／MEEKC／CEC。
:::

### （一）缓冲溶液的组成和 pH

缓冲液对于毛细管电泳的分离至关重要。缓冲溶液的选择一般遵循以下要求：在所选择的 $\mathrm{pH}$ 范围内有良好的缓冲容量；截止波长低或在检测波长处吸收较低；分子半径大而电荷数少，以减少电流的产生。此外，缓冲液 $\mathrm{pH}$ 对样品的性质和分离效率也具有显著的影响：$\mathrm{pH}$ 会影响样品的解离状态和带电性质，从而决定溶质在外加电场中的迁移速率和方向；$\mathrm{pH}$ 还会影响毛细管内壁硅羟基的解离程度从而影响电渗流的大小和方向；在手性分离中，$\mathrm{pH}$ 还在很大程度上决定了样品与手性试剂之间相互作用的强度，直接影响手性分离的选择性。

:::definition{label="CZE 缓冲液三条"}
所选 $\mathrm{pH}$ 范围内缓冲容量良好；截止波长低或检测波长处吸收低；分子半径大、电荷数少，减少电流。后一条与第 2 节「低淌度缓冲液、如 Tris」同一方向。
:::

:::keypoint{label="pH 同时管三件事"}
- 样品解离 → 淌度大小和方向。
- 管壁硅羟基 → EOF 大小和方向。
- 手性分离 → 样品与手性试剂作用强度，决定选择性。
:::

### （二）运行电压

当忽略焦耳热的影响时，分离度、迁移时间、柱效与分离电压之间存在近似线性的关系，随外加电压的升高而增加。但是当缓冲溶液浓度较大时，由于产生焦耳热不可忽略，就大大地偏离线性。一般来说，运行电压升高，产生的焦耳热增多，在焦耳热不能有效驱散的情况下，柱温显著升高，导致缓冲溶液黏度减小，双电层增厚，同时由于毛细管内部径向温度梯度的形成，导致柱效和分离度下降。因此应选择适合的条件，以不产生过高的电流和过多的焦耳热为前提使用较高的电压，以提高分离效率和缩短分析时间。

:::insight{label="高压是目标，热是上限"}
式（15-13）分子有 $U$，想要高柱效就想加电压。本段把上限写死：电流和焦耳热不能过高。黏度减小、双电层增厚、径向温度梯度，三件事一起把扁平流型毁掉。
:::

:::pitfall{label="电压升高柱效一定升高——忽略焦耳热才成立"}
缓冲液浓度较大时热不可忽略，大大偏离线性，柱效和分离度下降。不要把式（15-13）理解成「一直加到电源打满」。
:::

### （三）缓冲溶液添加剂

在 CZE 模式中，除了背景电解质外常常还需要在缓冲溶液中添加某些添加剂，通过其与管壁或溶质之间的相互作用改变管壁或溶质的性质，进一步优化分离结果，提高分离选择性和分离度。常用添加剂有以下几类：① 表面活性剂，如季铵盐等；② 有机改性剂，如甲醇、乙醇、乙腈、丙酮、四氢呋喃、二甲亚砜等，其改善分离的机制在于可以使电渗流减小而改善分离，同时抑制碱性药物色谱峰拖尾、提高柱效；③ 手性选择剂，如环糊精、多糖、胆酸盐及大环抗生素等。

:::definition{label="CZE 三类添加剂"}
表面活性剂（季铵盐等）；有机改性剂（甲醇、乙醇、乙腈、丙酮、THF、DMSO）；手性选择剂（环糊精、多糖、胆酸盐、大环抗生素）。扫描稿常把乙腈打成「乙」、二甲亚砜打成「二甲亚矾」。
:::

:::cause-effect{title="有机改性剂为什么能改善碱性药物"}
- 因：EOF 减小；同时抑制碱性药物与管壁作用造成的拖尾
- 果：分离改善，柱效提高
:::

### （四）毛细管柱温度

柱温对电泳迁移的影响主要通过黏度体现：柱温升高，溶液黏度降低，则 EOF 增大。多数情况下，使用较高毛细管柱温度，可以在较短的时间内完成分离。但是柱温选择应综合考虑热效应、重现性、分离效率和分离介质对温度的限制等因素。有研究表明，温度每变化 $1\,^{\circ}\mathrm{C}$，黏度变化 $2\%\sim 3\%$。温度升高，使溶液黏度下降，电渗流加大，迁移时间加快；在压力进样时，温度升高引起黏度下降，还会使进样体积增加，从而增加峰面积。因此，为了提高分离的重现性获得更好的分离结果，应该对毛细管柱温度进行优化。

:::definition{label="温度每变 1℃ 黏度变 2%～3%"}
本版给出的数。黏度↓ → EOF↑ → 迁移加快；压力进样时进样体积↑ → 峰面积↑。温控首先是为了重现性。
:::

:::pitfall{label="升温缩短时间，不是无条件提高柱效"}
多数情况较高柱温可以较短时间完成分离。选择时还要看热效应、重现性、分离效率和介质限制。不要答成「柱温越高越好」。
:::

## 二、胶束电动毛细管色谱法

胶束电动毛细管色谱（micellar electrokinetic chromatography，MEKC）是在运行缓冲液中加入浓度大于临界胶束浓度（CMC）的表面活性剂，使得表面活性剂分子之间聚集形成称为「准固定相」的胶束。这些胶束表现为一种团状结构：表面活性剂分子的疏水端聚集在团状结构内部从而可以避开亲水性的缓冲溶液，而带电荷的一端朝外分布在缓冲溶液中。因此在 MEKC 分离系统中，存在着以胶束形式存在的准固定相和作为载体的液体流动相，溶质在两相之间分配，并且由于其在准固定相和流动相中的分配系数不同而在不同的时间流出，从而使得不同性质的溶质得到分离（图 15-7）。

胶束具有固定相的功能，因此 MEKC 依据组分的表观淌度和分配系数的差异分离，即具有电泳与色谱的双重分离功能。在电动色谱中引入了表面活性剂胶束，溶质与胶束间存在类似色谱保留的作用机制，可以根据本身疏水性的差别而达到分离。阴、阳离子则根据本身及胶束所带电荷的类型和大小不同而获得不同程度的保留：与胶束带相同电荷的离子由于静电排斥作用，保留时间较短；反之，则保留时间长。因此，MEKC 模式能够对在常规 CZE 模式下不能被分离的中性分子实现分离，其分离原理包含了电泳迁移、分配和静电等多种机制。

图 15-7 把正极、EOF、胶束、分析物和负极画在同一根管里：胶束作为准固定相随电泳／电渗迁移，中性分析物在胶束与水相之间分配，电泳图上出现按疏水性拉开的峰。

:::definition{label="胶束电动毛细管色谱"}
MEKC。缓冲液中表面活性剂浓度大于 CMC，形成胶束「准固定相」。溶质在胶束与液体流动相之间分配。电泳＋色谱双重功能。
:::

:::definition{label="临界胶束浓度"}
CMC。低于 CMC：表面活性剂主要调管壁电荷（第 2 节添加剂）。高于 CMC：形成胶束，才叫 MEKC。
:::

:::definition{label="准固定相"}
胶束。疏水端向内、带电端向外的团状结构。不是键合在管壁上的 HPLC 固定相，所以叫「准」。
:::

:::insight{label="中性分子靠疏水性差，不是靠淌度差"}
中性物电泳淌度为零，CZE 叠在 $t_{0}$。进入胶束核的分数不同，保留不同，峰被拉开。思考题第 7 题「为什么 MEKC 可分离中性分子」，答分配，不要答「中性分子突然带电」。
:::

:::cause-effect{title="与胶束同号为什么先出"}
- 因：静电排斥，较难进入胶束，保留弱
- 果：保留时间较短；异号则保留长
:::

胶束在 MEKC 模式中作为分离的载体，对分离起着重要作用。因此 MEKC 中使用的表面活性剂必须符合以下几种要求：在溶液中能够形成与溶质迅速缔合的稳定胶束，这样可以减少溶质扩散，提高分离效率及重现性；CMC 值较低，避免缓冲体系中离子强度过大、产生的焦耳热过多，从而引起径向温度梯度，降低柱效；形成的胶束黏度要小，保证溶质有足够大的淌度。

表面活性剂根据带电性质不同可以分为阳离子型、阴离子型、非离子型和两性离子型。阳离子型表面活性剂有十二烷基三甲基氯化铵（$\mathrm{C_{12}TAC}$）、十二烷基三甲基溴化铵（$\mathrm{C_{12}TAB}$）、十四烷基三甲基溴化铵（$\mathrm{C_{14}TAB}$）和十六烷基三甲基溴化铵（$\mathrm{C_{16}TAB}$）等。阴离子型表面活性剂包括非手性的十二烷基磺酸钠（SDS）、十二烷基硫酸钠（SDS）、十四烷基硫酸钠（STS）等，以及手性的胆酸钠（SC）、脱氧胆酸钠（SDC）、牛磺胆酸钠（STC）、牛磺脱氧胆酸钠（STDC）、$N$-十二烷基-$L$-缬氨酸钠等。非离子型表面活性剂有 Triton X-100、吐温 20、Brij 35、辛基葡萄糖苷、十二烷基-$\beta$-D-麦芽糖苷等类型。两性离子型表面活性剂有 3-（$N$,$N$-二甲基十六烷基铵）丙烷磺酸盐等。

MEKC 实验条件的优化，包括缓冲液的种类和 $\mathrm{pH}$、表面活性剂浓度、离子强度、运行电压等因素。改变缓冲体系会显著影响溶质的容量因子和保留值，同样对 MEKC 体系的分离性能产生显著影响。缓冲溶液中可根据具体情况加入适当浓度的有机改性剂，如甲醇、乙醇等，以增加体系中样品组分的溶解能力，同时增加组分的保留值和选择性，扩大 MEKC 的分离范围。

:::definition{label="MEKC 用表面活性剂的三条要求"}
能形成与溶质迅速缔合的稳定胶束（减扩散、提柱效和重现性）；CMC 较低（避免离子强度和焦耳热过大）；胶束黏度小（溶质淌度足够大）。
:::

:::compare{title="四类表面活性剂（本版点名）"}
| 类型 | 本版例子 |
|------|----------|
| 阳离子 | $\mathrm{C_{12}TAC}$、$\mathrm{C_{12}TAB}$、$\mathrm{C_{14}TAB}$、$\mathrm{C_{16}TAB}$ |
| 阴离子非手性 | 十二烷基磺酸钠（SDS）、十二烷基硫酸钠（SDS）、STS |
| 阴离子手性 | SC、SDC、STC、STDC、$N$-十二烷基-$L$-缬氨酸钠 |
| 非离子 | Triton X-100、吐温 20、Brij 35、辛基葡萄糖苷、十二烷基-$\beta$-D-麦芽糖苷 |
| 两性离子 | 3-（$N$,$N$-二甲基十六烷基铵）丙烷磺酸盐 |
:::

:::pitfall{label="本版把磺酸钠和硫酸钠都缩写成 SDS"}
印刷：十二烷基磺酸钠（SDS）、十二烷基硫酸钠（SDS）。常用试剂「SDS」多指十二烷基硫酸钠。答题跟本版点名走，不要把两个化合物答成同一种结构，也不要说教材写错了一个缩写就整段作废。
:::

:::note{label="有机改性剂在 MEKC 里还管溶解"}
甲醇、乙醇等：增加样品溶解能力，同时增加保留值和选择性，扩大分离范围。与 CZE 里「减小 EOF、抑制碱性药物拖尾」侧重点不同，不要并成一句。
:::

## 三、毛细管电色谱法

毛细管电色谱（capillary electrochromatography，CEC）是将高效液相色谱法（HPLC）的固定相填入毛细管柱，以样品和固定相之间的相互作用为分离机制，以电渗流或电渗流结合压力为流动相驱动力完成分离，同时兼具 HPLC 和 CE 的优势。该方法保留了 HPLC 法固定相种类多、选择面广的特点，克服了液相色谱因流速不均所导致的谱带展宽，具有选择性高，分离时间短，固定相、溶剂和样品用量少等优点。毛细管电色谱柱根据固定相在柱内的存在方式分为以下三种：开管柱毛细管电色谱、填充柱毛细管电色谱及整体柱毛细管电色谱。

:::definition{label="毛细管电色谱"}
CEC。HPLC 固定相进毛细管；分离机制是样品与固定相的相互作用；驱动力是电渗流，或电渗流结合压力。兼具 HPLC 与 CE。
:::

:::compare{title="CZE 对 CEC（思考题 7）"}
| | CZE | CEC |
|--|-----|-----|
| 管的角色 | 主要提供液体通道 | 开管 CEC：管壁固定相就是分离的主力量 |
| 分离机制 | 电泳淌度差 | 样品与固定相的相互作用（色谱） |
| 驱动力 | 电渗＋电泳 | 电渗，或电渗结合压力 |
| 中性分子 | 分不开 | 可按色谱分配／吸附分开 |
:::

:::insight{label="CEC 借 HPLC 的固定相，借 CE 的塞流"}
「克服了液相色谱因流速不均所导致的谱带展宽」——还是第 2 节图 15-3 那句：EOF 扁平，压力流抛物线。固定相种类多是 HPLC 的账，流型是 CE 的账。
:::

### （一）开管柱毛细管电色谱

开管柱毛细管电色谱（open tubular capillary electrochromatography）：毛细管电泳中毛细管的作用主要是提供液体流通的通道，毛细管区带电泳中溶质分离的完成主要是依靠溶质电泳淌度的差异而达到分离的目的。毛细管本身并不作为固定相参与溶质的分配作用；即使在有些电泳模式中毛细管起到了一定的分配作用，这种作用也并不作为分离的主要力量。在开管柱毛细管电色谱中，毛细管则主要参与了溶质的分配作用，溶质的分离分析主要是依靠毛细管管壁上固定相的作用而达到分离的目的。

:::definition{label="开管柱 CEC"}
分离主要靠管壁上的固定相，而不是靠淌度差。相比填充柱，比表面积较低，本版后文写它「较低的不足」。
:::

### （二）填充柱毛细管电色谱

填充柱毛细管电色谱（packed column capillary electrochromatography）：将液相色谱用颗粒固定相装入空毛细管而成。采用微小粒径固定相制备毛细管电色谱柱，应解决的关键是如何很好地将填料填充到毛细管内，同时保持良好的柱效、柱稳定性及重复性。对于填充电色谱柱，不管采用压力匀浆法还是电填充法，或者其他装填方法如 $\mathrm{CO_2}$ 超临界装填法、离心力法等，为了防止固定相颗粒的流失，都需在毛细管柱两端加上塞子来固定填充床层。CEC 填充柱能应用 HPLC 中多种已商品化的固定相，能批量生产而且具有很好的分离选择性。

然而，毛细管柱两端塞子及颗粒化的固定相被认为是填充电色谱柱产生气泡的主要原因，因此填充毛细管电色谱一般在加压条件下运行。同时两端塞子的稳定性也影响了柱子的稳定性，这些因素制约了电色谱的进一步发展。解决填充毛细管柱气泡的产生及稳定性被认为是电色谱亟待解决的问题。毛细管电色谱整体柱不需要在毛细管两端加塞子，管内不易产生气泡，被认为是电色谱将来进一步发展的很有希望的一种柱制备方法。

:::definition{label="填充柱 CEC"}
HPLC 颗粒固定相装进空毛细管。装填：压力匀浆、电填充、$\mathrm{CO_2}$ 超临界、离心力等。两端必须加塞子防填料流失。
:::

:::pitfall{label="填充柱为什么要加压运行"}
两端塞子和颗粒固定相是气泡的主要来源。一般在加压条件下运行。不要答成「CEC 必须用高压泵当唯一驱动力」——驱动力仍是电渗或电渗结合压力，加压首先是为了压气泡。
:::

### （三）整体柱毛细管电色谱

整体柱毛细管电色谱（monolithic column capillary electrochromatography）：在毛细管内根据自由基原位聚合的方法合成多孔聚合物，并以此多孔聚合物作为电色谱固定相。毛细管电色谱整体柱的成功制备不仅避免了填充毛细管电色谱柱两端加塞子的问题，同时也克服了开管毛细管电色谱柱较低的不足。因此，毛细管电色谱整体柱在最近几年得到了迅速发展。

与前两种毛细管电色谱模式相比，整体柱不再需要在柱子的两端加塞子，而是在毛细管内原位合成连续柱床，同时可方便地控制柱长，可根据分离所需选用不同的有机单体进行聚合反应，也可通过调节参加反应的单体与致孔剂比率灵活地控制聚合物的孔隙大小及孔隙率。

:::definition{label="整体柱 CEC"}
毛细管内自由基原位聚合多孔聚合物作固定相。不加塞、连续柱床、柱长好控，用单体种类和单体／致孔剂比率调孔隙。既避开填充柱气泡，又补开管柱比表面低。
:::

:::compare{title="CEC 三种柱"}
| | 开管柱 | 填充柱 | 整体柱 |
|--|--------|--------|--------|
| 固定相在哪 | 管壁 | 颗粒填料＋两端塞子 | 原位聚合连续床 |
| 优点 | 结构简单 | 商品 HPLC 填料、选择性好、可批量 | 无塞、少气泡、孔隙可调 |
| 本版指出的不足 | 较低（比表面／容量） | 气泡、塞子稳定性 | ——（本节写成有希望的发展方向） |
:::

## 四、其他分离模式

### （一）非水毛细管电泳

非水毛细管电泳（nonaqueous capillary electrophoresis，NACE）是指使用非水溶剂作为电泳介质，代替以水为介质的缓冲溶液进行电泳的一种分离方法。该方法拓展了毛细管电泳技术分析对象的范围，与其他常规 CE 分离模式相比具有以下优势：因其采用有机溶剂代替水相，可以对很多难溶的疏水性物质进行分离分析；样品的 $\mathrm{p}K_{\mathrm{a}}$ 值的差别在非水溶剂中被放大数倍，从而易于分离；可以分离在水相介质中淌度十分接近的物质，如弱酸、弱碱、胺类药物；检测方式灵活，可与荧光、质谱和电化学等多种检测方式联用；非水溶剂可以降低被分离物质与毛细管壁的相互作用，降低峰宽并改善拖尾。NACE 在药物的杂质检查、手性药物分析、生物样本中药物和代谢物的分析方面都有应用。

NACE 中溶剂的性质对分离影响非常显著，改变溶剂可以改变电渗流的方向和大小。选择非水溶剂需要考虑溶剂的挥发性、介电常数、黏度和偶极矩等多种因素。常用的非水溶剂有甲醇、乙醇、乙腈、甲酰胺和 $N$-甲基甲酰胺等，另外 $N$,$N$-二甲基甲酰胺、二甲亚砜、四氢呋喃也常使用。大多数电解质在有机溶剂中的溶解度较低，因此可供选择的电解质种类有限。其中三（羟甲基）氨基甲烷是 NACE 最常用的电解质，因为其粒子的质荷比较大，既能降低缓冲溶液的电导率，又能减小管壁和溶质之间的吸附作用。另外酸及其铵盐也较为常用，如乙酸／乙酸铵、季铵盐、三氟乙酸盐、乙酸镁、柠檬酸、甲酸、甲磺酸及高氯酸盐。

:::definition{label="非水毛细管电泳"}
NACE。非水溶剂作电泳介质。疏水难溶物、放大 $\mathrm{p}K_{\mathrm{a}}$ 差别、拆开水相中淌度接近的弱酸弱碱和胺类药物、降吸附、便于和荧光／MS／电化学联用。
:::

:::definition{label="NACE 常用溶剂"}
甲醇、乙醇、乙腈、甲酰胺、$N$-甲基甲酰胺；另有 DMF、DMSO、THF。选溶剂看挥发性、介电常数、黏度、偶极矩。改变溶剂可以改变 EOF 的方向和大小。
:::

:::definition{label="NACE 最常用电解质"}
Tris。质荷比大：降电导、减吸附。与第 2 节降焦耳热用 Tris 是同一户试剂、两件任务。
:::

:::pitfall{label="NACE 不是否定「环境友好」"}
第 1 节写分离介质多为水相。NACE 是为疏水样品开的有机溶剂旁路，不是把整章改成有机相电泳。
:::

### （二）微乳电动色谱

微乳电动色谱（microemulsion electrokinetic chromatography，MEEKC）是一种较新的 CE 分离模式，其分离原理为溶质分子在水相和油相之间的色谱分配行为和电泳迁移行为的结合。微乳是纳米尺度的液滴形成的光学透明热力学稳定的分散体系，主要分为水包油微乳（water-in-oil，W/O）和油包水微乳（oil-in-water，O/W）两种类型。微乳一般由油相、水相、表面活性剂和共表面活性剂四种成分组成，各组分必须通过适当的配比才能形成稳定的微乳。表面活性剂的疏水端插入油核，而亲水端则伸向水相，共表面活性剂则位于表面活性剂的亲水端之间，用于降低表面活性剂之间的静电排斥力，以及表面活性剂同油相间的界面张力，这种结构能使微乳保持稳定。

在 MEEKC 中常用的表面活性剂包括阴离子表面活性剂如十二烷基硫酸钠（SDS）；阳离子表面活性剂，如十六烷基三甲基溴化铵（$\mathrm{C_{16}TAB}$）和十四烷基三甲基溴化铵（$\mathrm{C_{14}TAB}$）；中性表面活性剂也可使用。共表面活性剂通常是短链醇类化合物，其中以正丁醇最为常用。油相为与水不互溶的有机溶剂，常用的有烷烃，如正辛烷和正庚烷。其他中等链长的醇（如正戊醇、正己醇和正辛醇）、酯（如乙酸乙酯和酒石酸酯）及氯代烃（如氯仿、二氯甲烷和 1-氯丁烷）等也可以用作微乳的油相。此外，利用具有手性中心的疏水性物质作为油相（如酒石酸酯衍生物）或在缓冲液中引入手性选择剂（如环糊精等），也可以实现手性物质的分离。

作为电动色谱分离模式，MEEKC 不仅适合用于分离带电荷物质，也非常适合分离中性分子，这是因为微乳的增溶效果使得很多难溶于水的有机物质也得以分离分析。目前 MEEKC 模式已广泛应用于药物、食品、化妆品、天然产物、生物和环境样品等各类样品的分离分析。

:::definition{label="微乳电动色谱"}
MEEKC。溶质在水相和油相之间的色谱分配＋电泳迁移。微乳：纳米液滴、光学透明、热力学稳定。
:::

:::definition{label="微乳四组分"}
油相、水相、表面活性剂、共表面活性剂。配比不对则不稳定。表面活性剂疏水端插入油核、亲水端伸向水相；共表面活性剂夹在亲水端之间，降静电排斥和界面张力。
:::

:::definition{label="MEEKC 常用配方角色"}
表面活性剂：SDS、$\mathrm{C_{16}TAB}$、$\mathrm{C_{14}TAB}$，中性表面活性剂也可用。共表面活性剂：短链醇，正丁醇最常用。油相：正辛烷、正庚烷；也可用正戊醇、正己醇、正辛醇、乙酸乙酯、酒石酸酯、氯仿、二氯甲烷、1-氯丁烷。
:::

:::pitfall{label="本版把英文缩写写在中文名称后面时对调了"}
印刷：水包油微乳（water-in-oil，W/O）、油包水微乳（oil-in-water，O/W）。通用命名：水包油是 O/W（油滴在水里），油包水是 W/O（水滴在油里）。答题以中文「水包油／油包水」为准，不要按括号里的英文缩写反着记。结构描述「疏水端插入油核、亲水端伸向水相」对应的是水为连续相的那一种。
:::

:::insight{label="MEEKC 对 MEKC：油核把难溶物增溶进去"}
MEKC 的准固定相是胶束核；MEEKC 的油核更大、增溶更强，难溶于水的有机物也能做。两者都能拆中性分子，不要答成只有 MEKC 能做中性物。
:::

### （三）毛细管凝胶电泳

毛细管凝胶电泳（capillary gel electrophoresis，CGE）综合了 CE 和平板凝胶电泳的优点，是一种分离度极高的电泳分离技术，一般用于大分子物质的微型制备。CGE 技术已经成为生物药物分析、DNA 序列测试及指纹图谱测定的有力工具。

CGE 中应用得最多的凝胶介质是交联和非交联的聚丙烯酰胺凝胶、琼脂糖凝胶、葡聚糖、聚乙烯二醇等。凝胶主要起到类似分子筛的作用，使得生物大分子按相对分子质量大小逐一得到分离。手性化合物在 CGE 模式中的分离同时受到电荷性、分子大小和手性选择剂三个因素的影响，特别适用于质荷比不随分子大小改变的大分子化合物的分离。用于手性拆分的 CGE 所用添加剂主要是蛋白质、环糊精和十二烷基硫酸钠等。扫描稿常把聚丙烯酰胺打成聚丙烯酸，以印刷为准。

:::definition{label="毛细管凝胶电泳"}
CGE。CE＋平板凝胶电泳。分离度极高，一般用于大分子微型制备；生物药物、DNA 测序及指纹图谱。
:::

:::definition{label="CGE 的分子筛"}
交联／非交联聚丙烯酰胺、琼脂糖、葡聚糖、聚乙烯二醇。按相对分子质量大小逐一分开，不是按 CZE 的自由溶液淌度。
:::

:::definition{label="质荷比不随分子大小改变的大分子"}
本版写 CGE 特别适用。核酸一类：单位长度电荷相近，自由溶液淌度差不大，要靠凝胶筛分。手性拆分还叠电荷性、分子大小、手性选择剂三因素；添加剂主要是蛋白质、环糊精和 SDS。
:::

:::compare{title="本节模式怎么选"}
| 模式 | 分开靠什么 | 中性分子 | 典型对象 |
|------|------------|----------|----------|
| CZE | 淌度差 | 不能 | 正、负离子；最基础 |
| MEKC | 淌度＋胶束分配＋静电 | 能（疏水性） | 中性药、手性胶束 |
| CEC | 固定相相互作用；EOF（可加压力）驱动 | 能 | 要 HPLC 选择性又要塞流 |
| NACE | 非水介质中的淌度／$\mathrm{p}K_{\mathrm{a}}$ | 视带电情况 | 疏水、弱酸弱碱、胺类 |
| MEEKC | 水相–油相分配＋电泳 | 能（增溶更强） | 难溶有机物 |
| CGE | 分子筛 | 不是它的主场 | DNA、蛋白、大分子制备 |
:::

:::memory{label="模式口诀"}
CZE 管离子，中性交给胶束和微乳。要真固定相走 CEC，三相柱：开管、填充加塞、整体原位聚。怕水走 NACE，按个头走 CGE。
:::
