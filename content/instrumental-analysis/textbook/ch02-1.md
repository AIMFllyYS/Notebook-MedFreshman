# 第1节　电化学分析法概述

第2章打开电位分析法和永停滴定法。先把电化学分析法按所测参数分成电位、电解、电导、伏安四户，再把直接电位法、电位滴定法和永停滴定法从这本账里提出来。本章后文只展开这三户，不要把库仑、电导滴定或极谱提前写成操作规程。

电化学分析法（electrochemical analysis，又称电分析化学）是依据电化学原理和物质的电化学性质建立的一类分析方法：以样品溶液和适当电极构成化学电池，根据电池电化学参数（电位、电流、电荷量等）的强度或变化对待测组分进行分析。仪器简单、操作方便、易于微型化和自动化，是仪器分析的重要组成部分，在生命科学、医药卫生、材料科学、环境分析中应用广泛。本章只把直接电位法、电位滴定法及永停滴定法写全；四类方法的其余户头在后续专章再展开。

:::definition{label="电化学分析法"}
电化学分析法（electrochemical analysis，又称电分析化学）依据电化学原理和物质的电化学性质：以样品溶液和适当电极构成化学电池，根据电池电化学参数（电位、电流、电荷量等）的强度或变化对待测组分进行分析。
:::

:::insight{label="先问测的是哪一个电参数，再问是直接读还是靠滴定突跃"}
同一套电极和溶液，测电位、测电量、测电导、测电流–电压曲线，户头完全不同。电位分析法读原电池电动势；电解分析法读定量电解时的质量或电荷量；电导分析法读溶液电导；伏安法读伏安曲线。把“电化学”听成“就是测 pH”，永停滴定的双铂电流曲线会没有户头。
:::

:::concept{term="样品溶液 + 适当电极 → 化学电池 → 读电参数"}
电化学分析都通过化学电池的电化学反应来实现。没有电极和溶液构成的电池，后面的能斯特公式、指示电极、参比电极都没有落点。第2节先补相界电位、液接电位和电池电动势，就是为这一句做底。
:::

## 一、按测量参数分类

电化学分析法的种类很多，通常习惯上按分析过程中所测量的电化学参数进行分类，如电位分析法、电解分析法、电导分析法、伏安法等。四户都可以再拆成“直接读测量值”和“滴定过程中看突跃（或曲线转折）”两本账。

:::compare{title="四类电化学分析法按所测参数分户"}
| 类别 | 所测参数 | 直接读含量 | 用滴定过程确定终点 |
|------|----------|------------|--------------------|
| 电位分析法 | 原电池电动势 | 直接电位法 | 电位滴定法 |
| 电解分析法 | 电极上的定量电解（质量或电荷量） | 电重量法、库仑法 | 库仑滴定法 |
| 电导分析法 | 溶液电导或电导变化 | 直接电导法 | 电导滴定法 |
| 伏安法 | 电解过程中的电流–电压曲线（伏安曲线） | 极谱法、溶出法 | 电流滴定法（永停滴定法属此类） |
:::

:::keypoint{label="本章真正展开的三户"}
- 直接电位法：电动势测量值直接求含量（第3节）。
- 电位滴定法：滴定过程中电动势突变定终点（第4节）。
- 永停滴定法：固定微小电压下看电流变化定终点，属电流滴定法（第5节）。
- 电解、电导、极谱、溶出只在本节立户，不要在本章写成操作专节。
:::

### 1. 电位分析法

:::definition{label="电位分析法"}
电位分析法（potential analysis）根据测量原电池的电动势，以确定待测物含量。
:::

:::definition{label="直接电位法"}
根据电动势的测量值直接求出待测物的含量，称为直接电位法（direct potentiometry）。
:::

:::definition{label="电位滴定法"}
根据滴定过程中电动势的突变来确定滴定终点，称为电位滴定法（potentiometric titration）。
:::

:::pitfall{label="直接电位法读的是电动势，不是把伏特计当浓度计"}
直接电位法的定量关系在能斯特方程里：电极电位（实验上读到的是电池电动势）与有关离子活度（浓度）成对数关系。第3节的玻璃电极测 pH、离子选择电极测阴、阳离子，户头都在这一句。把“直接”听成“不需要参比电极”，测量电池就组装不起来。
:::

:::compare{title="直接电位法与电位滴定法"}
| 项目 | 直接电位法 | 电位滴定法 |
|------|------------|------------|
| 读什么 | 平衡时的电池电动势 | 滴定过程中电动势随体积的变化 |
| 定量钥匙 | 能斯特方程中 $\varphi$（实为 $E$）与活度（浓度）的对数关系 | 化学计量点附近电位变化率最大，该点即终点 |
| 本章落点 | 第3节：玻璃电极测 pH、离子选择电极 | 第4节：$E$–$V$、一阶导数、二阶导数 |
| 共同点 | 都要指示电极 + 参比电极组成测量电池 | 同左 |
:::

### 2. 电解分析法

:::definition{label="电解分析法"}
电解分析法（electrolytic analysis）根据通电时待测物在电池电极上发生定量作用的性质，以确定待测物含量。
:::

:::definition{label="电重量法"}
电重量法（electrogravimetry）：电解过程中使待测物定量地沉积在电极上，根据电极质量的增加测定待测物。
:::

:::definition{label="库仑法"}
库仑法（coulometry）：根据待测物完全电解时所消耗的电荷量进行分析。
:::

:::definition{label="库仑滴定法"}
库仑滴定法（coulometric titration）：通过电极反应生成所需的滴定剂，与溶液中待测组分作用，根据滴定终点消耗的电荷量确定待测组分含量。
:::

:::insight{label="电解分析法的三户都要“定量电解”，差在读质量还是读电量"}
电重量法称电极增重；库仑法按法拉第定律读完全电解的电荷量；库仑滴定法并不把待测物直接镀到电极上，而是现场电解出滴定剂，再按终点电量定量。把三户都写成“镀层称重”，库仑滴定会没有户头。
:::

:::pitfall{label="库仑滴定不是电位滴定"}
库仑滴定读的是电荷量，电位滴定读的是电动势突跃。前者属电解分析法，后者属电位分析法。药典里大量含量测定用电位滴定指示终点，不要写成库仑滴定。
:::

### 3. 电导分析法

:::definition{label="电导分析法"}
电导分析法（conductometric analysis）根据测量溶液的电导或电导变化来确定待测物含量。
:::

:::definition{label="直接电导法"}
直接电导法（direct conductometry）根据测量的电导数据直接确定待测物的含量。
:::

:::definition{label="电导滴定法"}
电导滴定法（conductometric titration）根据滴定过程中溶液电导的变化以确定滴定终点。
:::

:::compare{title="电位滴定、电导滴定、电流滴定不要混户"}
| 滴定 | 所属大类 | 终点看什么 |
|------|----------|------------|
| 电位滴定 | 电位分析法 | 电动势突变（$\Delta E/\Delta V$ 最大） |
| 电导滴定 | 电导分析法 | 溶液电导变化 |
| 电流滴定（含永停） | 伏安法 | 固定微小电压下电流的变化或突跃 |
:::

:::tip{label="电导滴定本章不展开"}
电导分析法只在概述里立户。本章实验装置图是电位滴定的指示电极–甘汞电极–毫伏电位计，以及永停滴定的双铂电极，都不是电导池。
:::

### 4. 伏安法

:::definition{label="伏安法"}
伏安法（voltammetry）根据电解过程中电流–电压曲线（伏安曲线），对待测物进行定性和定量。
:::

:::definition{label="极谱法"}
极谱法（polarography）以滴汞电极（dropping mercury electrode）为极化电极，通过测量其电流–电位（或电位–时间）曲线来确定溶液中待测物含量。
:::

:::definition{label="溶出法"}
溶出法（stripping method）在某一恒定电压下进行电解，使待测物质先在电极上富集，再用适当的方法使富集物溶解，根据溶出时的电流–电位或电流–时间曲线进行分析。
:::

:::definition{label="电流滴定法"}
电流滴定法（amperometric titration）在固定微小电压下，根据滴定过程中电流的变化确定滴定终点。
:::

:::insight{label="永停滴定法的户头在电流滴定，不在电位滴定"}
第5节的永停滴定法（dead-stop titration）又称双电流或双安培滴定法：两个相同指示电极（通常为铂电极）插入待滴定溶液组成电解池，两极间外加一小电压（约为几十毫伏），根据 $i$–$V$ 曲线或电流突变点定终点。它是电流滴定法中的一种，测量的是电流不是电动势。把永停写成“电位滴定的别名”，双铂电极和外加小电压都会讲丢。
:::

:::pitfall{label="极谱法的工作电极是滴汞电极，不要改写成玻碳或铂"}
本版把极谱法写成以滴汞电极为极化电极、测电流–电位或电位–时间曲线。溶出法另有“先富集、再溶出”两步。不要用其他教材的工作电极名单替换这一句。
:::

:::memory{label="四类方法：位、解、导、安"}
- **位**：电位分析法 → 直接电位 / 电位滴定。
- **解**：电解分析法 → 电重量 / 库仑 / 库仑滴定。
- **导**：电导分析法 → 直接电导 / 电导滴定。
- **安**：伏安法（电流–电压）→ 极谱 / 溶出 / 电流滴定（永停）。
:::

## 二、发展沿革、优点与本章范围

电化学分析法始于 19 世纪初，至今已有约 200 年的历史。20 世纪中期伏安法、电导分析法等领域发展迅速，目前在仪器自动化与联用技术方面仍属快速发展的方向。第 6 节只简介化学修饰电极、超微电极、纳米电分析化学和电分析化学联用，不要扩写成综述。

:::timeline{period="电化学分析法在教材中的时间落点"}
- **19 世纪初** 电化学分析法开始，至今约 200 年
- **20 世纪中期** 伏安法、电导分析法等领域发展迅速
- **20 世纪 60 年代后期** 其他离子选择电极迅速发展（第 3 节）；pH 玻璃电极已有 100 多年应用史
- **1975 年** Miller 和 Murray 报道按人为设计修饰电极表面，化学修饰电极正式问世（第 6 节）
- **目前** 仪器自动化与联用技术仍快速发展
:::

:::definition{label="电化学分析法的优点"}
仪器简单、操作方便、易于微型化和自动化、分析速度快、选择性好、灵敏度高。
:::

:::note{label="优点不要写成“没有缺点”"}
第 1 章已经把仪器分析的相对误差、设备价格和维护写过。本节只给电化学分析法这张优点清单。常量组分若要求很高准确度，仍要回到化学分析或电位滴定（滴定终点比直接电位法的对数误差更经得起看）。
:::

电化学分析法都是通过化学电池的电化学反应来实现的。因此，有必要了解化学电池的电化学基本原理和基础知识。第 2 节从相界电位、液接电位、原电池与电解池、电极分类、可逆电极和电极电位的测量写起。

四类方法共用“样品溶液 + 电极 → 化学电池”这一操作单元，差别只在读哪一个参数、参数是强度还是变化。电位分析法读原电池电动势：平衡时的强度给出直接电位法，滴定过程中的突变给出电位滴定法。电解分析法要求待测物在电极上发生定量作用：镀层称重是电重量法，按法拉第定律读完全电解的电荷量是库仑法，现场电解出滴定剂再按终点电量定量是库仑滴定法。电导分析法读溶液导电能力：电导数据直接定量是直接电导法，滴定过程中电导折点是电导滴定法。伏安法读电解过程中的电流–电压曲线：滴汞电极作极化电极的是极谱法，先恒电位富集再溶出的是溶出法，固定微小电压看电流随滴定剂变化的是电流滴定法——永停滴定法就落在这一户。

:::example{label="看见“滴定”三个字，先问终点读的是电位、电导、电流还是电量"}
同一句“滴定”，电位滴定盯电动势突跃，电导滴定盯电导折点，电流滴定（永停）盯外加小电压下的电流，库仑滴定盯电解生成滴定剂所耗电荷量。四户电极接法、仪表和曲线形状都不一样。把章名里的永停滴定法听成电位滴定的别名，第 5 节的双铂电极会没有来处。
:::

:::compare{title="直接法与滴定法在四类中的对称"}
| 大类 | 直接读测量值 | 滴定过程定终点 |
|------|----------------|----------------|
| 电位 | 直接电位法：能斯特对数关系 | 电位滴定法：$\Delta E/\Delta V$ 最大 |
| 电解 | 电重量法、库仑法 | 库仑滴定法：终点电荷量 |
| 电导 | 直接电导法 | 电导滴定法 |
| 伏安 | 极谱法、溶出法 | 电流滴定法（永停） |
:::

本章后文的阅读顺序可以按测量电池来记。第 2 节先回答：相界电位从哪里来、液接电位怎样用盐桥压住、原电池和电解池怎样靠工作状态对调、指示电极和参比电极怎样配对、为什么不能用普通伏特计。第 3 节把玻璃电极和离子选择电极插进这套电池，两次测量法和标准加入法都是在 $K''$ 或基质不确定时把常数项处理掉。第 4 节不再把 $E$ 换成 $c$，改为在化学计量点附近加密记录体积和电位。第 5 节把参比电极拿掉，换成两支相同铂电极和外加几十毫伏。第 6 节只简介修饰电极、超微电极、纳米电分析和联用，作为本章的边界，不是操作专节。

:::concept{term="先立四户，再把本章三节从电位和伏安里提出来"}
电位分析法给出直接电位法和电位滴定法；伏安法给出电流滴定法，其中一种叫永停滴定法。电解、电导两户在本节立名，操作留给后续章节。这样读第 2–5 节时，不会把库仑滴定的电荷量和电位滴定的电动势突跃写到同一张答题纸上。
:::

:::keypoint{label="读完概述应能回答的三问"}
- 电化学分析法的操作单元是什么？样品溶液 + 适当电极构成的化学电池。
- 按参数如何分四类？电位、电解、电导、伏安。
- 本章三节专论是什么？直接电位法、电位滴定法、永停滴定法。
:::

:::cause-effect{title="为什么本章必须先补化学电池"}
- **因** 电位、电流、电荷量都是电池的电化学参数；没有相界电位和参比电极，电动势读数没有参照
- **果** 第 2 节先写双电层、盐桥、丹聂尔电池、指示电极与参比电极，第 3–5 节的测量电池才能组装
:::
