# 第4节　光谱分析仪器

光谱法原理不同，仪器部件却大致相同。本节按本版把光谱仪写成五个部分：光源、样品池、单色器、检测器、读出器件；再按光路把仪器分成吸收、发射、荧光或散射三类（图3-4）。光源、单色器、样品池材料、检测器都按本版型号和波长写，不要换成别的仪器分析教材的灯或检测器。

用来研究吸收、发射或荧光的电磁辐射强度和波长的关系的仪器叫作光谱仪或分光光度计（spectrophotometer）。尽管各种光谱法所依据的原理不同，但它们均包含三个主要过程：①光源提供能量；②能量与待测物质发生相互作用；③检测相互作用时产生的信号。因此，各类光谱法所用仪器的基本部件大致相同，但部件的结构、排布及光路略有不同。根据光谱分析仪器结构及光与物质的相互作用差异，可以将光谱分析仪器分为三大类：吸收光谱仪、发射光谱仪和荧光或散射光谱仪（图3-4）。典型的光谱仪一般由五个部分组成：光源、样品池、单色器、检测器和读出器件。

:::definition{label="光谱仪／分光光度计"}
用来研究吸收、发射或荧光的电磁辐射强度和波长的关系的仪器叫作光谱仪或分光光度计（spectrophotometer）。
:::

:::definition{label="三个主要过程"}
各类光谱法均包含：①光源提供能量；②能量与待测物质发生相互作用；③检测相互作用时产生的信号。
:::

:::definition{label="典型光谱仪的五个部分"}
典型的光谱仪一般由五个部分组成：光源、样品池、单色器、检测器和读出器件。
:::

## 一、光源

在光谱分析中，光源必须具有足够的输出功率和稳定性。光谱分析仪器一般都配有良好的稳压或稳流装置以提供稳定的电源电压，保证光强稳定不变。光源有连续光源（continuous source）、线光源（line source）等。一般连续光源主要用于分子吸收光谱法，线光源主要用于荧光、原子吸收和拉曼光谱法。光谱分析法中常用的光源如图3-5所示。

:::definition{label="光源的基本要求"}
光源必须具有足够的输出功率和稳定性。仪器配稳压或稳流装置，保证光强稳定不变。
:::

:::definition{label="连续光源"}
连续光源（continuous source）是指在很大的波长范围内主要发射强度平稳的具有连续光谱的光源。一般主要用于分子吸收光谱法。
:::

:::definition{label="线光源"}
线光源（line source）发射分立的线光谱。一般主要用于荧光、原子吸收和拉曼光谱法。
:::

:::note{label="图3-5 与教材对齐"}
图3-5按波谱区画光源覆盖范围。能斯特灯本版写作 $\mathrm{ZnO}_2+\mathrm{Y}_2\mathrm{O}_3$，镍铬丝写作 $\mathrm{Ni}+\mathrm{Cr}$，硅碳棒写作 $\mathrm{SiC}$。不要改成别的书的化学式。

### 1. 连续光源

连续光源是指在很大的波长范围内主要发射强度平稳的具有连续光谱的光源。

**（1）紫外光源**　紫外光源主要采用氢灯或氘灯，它们在低压（$\approx 1.3\times 10^{3}\,\mathrm{Pa}$）下以电激发的方式产生的连续光谱范围为 $160\sim 375\,\mathrm{nm}$。氘灯的工作方式与氢灯相同，光谱强度比氢灯大 $3\sim 5$ 倍，寿命也比氢灯长。

:::definition{label="氢灯与氘灯"}
紫外连续光源主要采用氢灯或氘灯。低压 $\approx 1.3\times 10^{3}\,\mathrm{Pa}$，电激发，连续光谱 $160\sim 375\,\mathrm{nm}$。氘灯工作方式与氢灯相同，强度大 $3\sim 5$ 倍，寿命更长。
:::

**（2）可见光源**　可见光源通常使用钨灯和氙灯。钨灯的工作温度约为 $2870\,\mathrm{K}$，光谱波长范围为 $320\sim 2500\,\mathrm{nm}$。氙灯的光谱强度比钨灯大，发射的连续光谱分布在 $250\sim 700\,\mathrm{nm}$。

:::definition{label="钨灯"}
可见光源常用钨灯。工作温度约 $2870\,\mathrm{K}$，光谱波长 $320\sim 2500\,\mathrm{nm}$。
:::

:::definition{label="氙灯"}
氙灯光谱强度比钨灯大，连续光谱分布在 $250\sim 700\,\mathrm{nm}$。
:::

**（3）红外光源**　红外光源常用硅碳棒和能斯特（Nernst）灯。它是通过电加热的方式使一种惰性固体产生连续波长的红外光源。在 $1500\sim 2000\,\mathrm{K}$ 的温度范围内，所产生的最大辐射强度的波数范围为 $200\sim 6000\,\mathrm{cm}^{-1}$。

:::definition{label="硅碳棒与能斯特灯"}
红外连续光源常用硅碳棒和能斯特（Nernst）灯：电加热惰性固体。$1500\sim 2000\,\mathrm{K}$ 时，最大辐射强度的波数范围 $200\sim 6000\,\mathrm{cm}^{-1}$。
:::

:::compare{title="本版连续光源"}
| 光源 | 主要波谱区 | 本版数据 |
|------|------------|----------|
| 氢灯、氘灯 | 紫外 | $\approx 1.3\times 10^{3}\,\mathrm{Pa}$；$160\sim 375\,\mathrm{nm}$；氘灯强 $3\sim 5$ 倍、寿命更长 |
| 钨灯 | 可见（并伸到近红外） | 约 $2870\,\mathrm{K}$；$320\sim 2500\,\mathrm{nm}$ |
| 氙灯 | 可见（并伸到紫外） | 比钨灯强；$250\sim 700\,\mathrm{nm}$ |
| 硅碳棒、能斯特灯 | 红外 | $1500\sim 2000\,\mathrm{K}$；最大辐射 $200\sim 6000\,\mathrm{cm}^{-1}$ |
:::

:::pitfall{label="氘灯不是氛灯，能斯特灯按本版写 ZnO₂＋Y₂O₃"}
OCR 常把氘认成氛。本版是氢灯或氘灯。图3-5化学式按教材抄，不要用其他专著的 $\mathrm{ZrO}_2$ 替换已经印在图上的 $\mathrm{ZnO}_2$。
:::

### 2. 线光源

**（1）金属蒸气灯**　在透明封套内含有低压气体元素，把电压加到固定在封套上的一对电极上时，就会激发出该元素的特征线光谱。常用的金属蒸气灯是汞灯和钠灯。汞灯产生的线光谱的波长范围为 $254\sim 734\,\mathrm{nm}$，钠灯主要是 $589.0\,\mathrm{nm}$ 和 $589.6\,\mathrm{nm}$ 处的一对谱线。

:::definition{label="金属蒸气灯"}
透明封套内含低压气体元素，电极放电激发出该元素的特征线光谱。常用汞灯和钠灯。汞灯 $254\sim 734\,\mathrm{nm}$；钠灯主要是 $589.0\,\mathrm{nm}$ 和 $589.6\,\mathrm{nm}$ 一对谱线。
:::

**（2）空心阴极灯**　空心阴极灯主要用于原子吸收光谱中，能提供许多元素的线光谱。

:::definition{label="空心阴极灯"}
空心阴极灯主要用于原子吸收光谱，能提供许多元素的线光谱。
:::

**（3）激光**　激光的强度非常高，方向性和单色性好，它作为一种新型光源在拉曼光谱、荧光光谱、发射光谱、傅里叶（Fourier）变换红外光谱、光声光谱等领域极受重视。常用的激光器有主要波长为 $693.4\,\mathrm{nm}$ 的红宝石激光器、主要波长为 $632.8\,\mathrm{nm}$ 的 $\mathrm{He}$-$\mathrm{Ne}$ 激光器和主要波长为 $514.5/488.0\,\mathrm{nm}$ 的 $\mathrm{Ar}$ 离子激光器。

:::definition{label="激光"}
激光强度非常高，方向性和单色性好。本版点名：红宝石 $693.4\,\mathrm{nm}$；$\mathrm{He}$-$\mathrm{Ne}$ $632.8\,\mathrm{nm}$；$\mathrm{Ar}$ 离子 $514.5/488.0\,\mathrm{nm}$。用于拉曼、荧光、发射、傅里叶变换红外、光声等。
:::

:::compare{title="本版线光源"}
| 光源 | 用途／特征 | 本版波长 |
|------|------------|----------|
| 汞灯 | 金属蒸气灯 | $254\sim 734\,\mathrm{nm}$ |
| 钠灯 | 金属蒸气灯 | $589.0\,\mathrm{nm}$、$589.6\,\mathrm{nm}$ |
| 空心阴极灯 | 原子吸收 | 许多元素的线光谱 |
| 红宝石激光器 | 激光 | $693.4\,\mathrm{nm}$ |
| $\mathrm{He}$-$\mathrm{Ne}$ 激光器 | 激光 | $632.8\,\mathrm{nm}$ |
| $\mathrm{Ar}$ 离子激光器 | 激光 | $514.5/488.0\,\mathrm{nm}$ |
:::

:::pitfall{label="连续光源给分子吸收，线光源给荧光、原子吸收和拉曼"}
把钨灯拿去当原子吸收的锐线光源，或把空心阴极灯拿去当紫外–可见分子吸收的连续光源，都是把两类灯的职分写反。
:::

## 二、单色器

在光谱分析仪器中，将复合光分解成单色光或有一定波长范围的谱带的部件叫作分光系统。分光系统分为滤光片（filter）和单色器（monochromator）。早期或简易的光谱仪中，常采用滤光片获得一定波长的光辐射信号。现代光学分析仪器几乎都有单色器。单色器由入射狭缝、准直镜、色散元件和出射狭缝组成。图3-6是单色器的光路示意图。

:::definition{label="分光系统"}
将复合光分解成单色光或有一定波长范围的谱带的部件叫作分光系统，分为滤光片（filter）和单色器（monochromator）。
:::

:::definition{label="单色器"}
现代光学分析仪器几乎都有单色器。单色器由入射狭缝、准直镜、色散元件和出射狭缝组成。
:::

### 1. 色散元件

色散元件是单色器的心脏部分，有棱镜（prism）和光栅（grating）两种类型，如图3-7所示。

:::definition{label="色散元件"}
色散元件是单色器的心脏，有棱镜（prism）和光栅（grating）两种。
:::

::figure{src="/images/instrumental-analysis/textbook/p0063_01.jpg" caption="图3-7　棱镜和光栅。左：棱镜按折射率分光，紫光偏折更大；右：闪耀光栅，图中标出各级光谱与投射光。" alt="棱镜色散示意图与闪耀光栅刻槽、各级光谱示意图"}

**（1）棱镜**　棱镜是根据光的折射现象进行分光的。构成棱镜的光学材料对不同波长的光具有不同的折射率，波长短的光折射率大，波长长的光折射率小。因此，平行光经色散后就按波长顺序分解为不同波长的光，经聚焦后在焦面的不同位置上成像，得到按波长展开的光谱。棱镜分光得到的光谱按波长排列是疏密不均的，长波长区密，短波长区疏，即光距与各条波长是非线性的。

:::definition{label="棱镜分光"}
棱镜根据折射分光：短波折射率大，长波折射率小。光谱按波长疏密不均，长波区密、短波区疏，光距与波长非线性。
:::

**（2）光栅**　光栅分为透射光栅和反射光栅，用得较多的是反射光栅。反射光栅又分为平面反射光栅（简称平面光栅或闪耀光栅）和凹面反射光栅（简称凹面光栅），目前常用的是闪耀光栅。

光栅是一种在高度抛光的表面上刻有许多等宽度、等距离的平行条痕狭缝的色散元件。利用复合光通过条痕狭缝反射后，产生衍射和干涉作用，使不同波长的光有不同的投射方向而起到色散作用。光栅光谱的产生是多狭缝干涉和单狭缝衍射两者联合作用的结果，多缝干涉决定光谱线出现的位置，单缝衍射决定谱线的强度分布。光栅分散后的光谱从短波到长波各谱线间距离相等，是均匀分布的连续光谱。光栅光谱是多级的（包括一、二、三级等谱线），多级光谱均匀地分布在零级光谱两边，但有时出现光谱线的重叠。在实际应用时，应设法消除各级光谱之间的部分重叠现象，如用滤光片滤去高级序光谱。光栅的优点是波长范围比棱镜宽，且色散近乎线性。

:::definition{label="光栅"}
高度抛光表面上刻有许多等宽度、等距离平行条痕狭缝的色散元件。用得较多的是反射光栅；目前常用闪耀光栅（平面反射光栅）。
:::

:::definition{label="光栅光谱"}
光栅光谱是多狭缝干涉和单狭缝衍射联合作用的结果：多缝干涉决定谱线位置，单缝衍射决定强度分布。从短波到长波谱线间距相等，均匀分布。光谱是多级的，分布在零级两边，可能重叠，常用滤光片滤去高级序。优点：波长范围比棱镜宽，色散近乎线性。
:::

:::compare{title="棱镜与光栅"}
| 项目 | 棱镜 | 光栅 |
|------|------|------|
| 物理依据 | 折射；短波折射率大 | 衍射 $+$ 干涉 |
| 光谱排列 | 疏密不均：长波密、短波疏，非线性 | 谱线间距相等，近乎线性 |
| 级次 | 不按多级重叠来讲 | 多级光谱，可能重叠，需滤光片 |
| 波长范围 | 较窄 | 比棱镜宽 |
| 本版常用 | 仍是色散元件之一 | 目前常用闪耀光栅 |
:::

:::pitfall{label="棱镜长波密、短波疏，不要记反"}
可见光里红光波长长，落在密的一边；紫光波长短，落在疏的一边。把“密”听成“短波挤在一起”，和图3-7会对不上。
:::

:::pitfall{label="光栅多级重叠不是故障，是要用滤光片处理的现象"}
一、二、三级谱线可能重叠。教材的办法是滤光片滤去高级序，不是把光栅换成棱镜就算完。
:::

### 2. 狭缝

狭缝（slit）是由两片经过精细加工、具有锐利边缘的不锈钢片组成的。狭缝的两条边缘必须互相平行，并在同一平面内。狭缝为光的进出口，狭缝宽度直接影响分光质量。狭缝过宽，单色光不纯，将影响吸光度；狭缝过窄，则光通量变小，将降低灵敏度。因此，狭缝宽度要恰当。狭缝宽度选择的一般原则是，在不引起吸光度减小的情况下，采用尽可能大的狭缝宽度。

:::definition{label="狭缝"}
狭缝（slit）由两片精细加工、锐利边缘的不锈钢片组成，两条边缘必须互相平行并在同一平面内。它是光的进出口，宽度直接影响分光质量。
:::

:::keypoint{label="狭缝宽了不纯，窄了不灵敏"}
- 过宽：单色光不纯，影响吸光度。
- 过窄：光通量变小，降低灵敏度。
- 一般原则：在不引起吸光度减小的情况下，采用尽可能大的狭缝宽度。
:::

### 3. 准直镜

准直镜是以狭缝为焦点的聚光镜，将进入进口狭缝的发散光变成平行光；又用作聚光镜，将色散后的平行单色光聚集于出口狭缝。

:::definition{label="准直镜"}
准直镜是以狭缝为焦点的聚光镜：进口侧把发散光变成平行光；出口侧把色散后的平行单色光聚集于出射狭缝。
:::

:::memory{label="单色器四件套"}
问法：单色器由哪四部分组成？
答：入射狭缝、准直镜、色散元件（棱镜或光栅）、出射狭缝。
:::

## 三、样品池

样品池（又称试样池、吸收池、比色皿）由光透明材料制成。

在紫外–可见分光光度法中，紫外光区采用石英材料制成的样品池，可见光区采用硅酸盐玻璃制成的样品池；在红外光谱法中，红外光区根据不同的波长范围选用不同材料的晶体制成样品池的窗口，如 $\mathrm{NaCl}$、$\mathrm{KBr}$、KRS-5（$58\%\,\mathrm{TlI}$ 和 $42\%\,\mathrm{TlBr}$ 的混合晶体）等；在原子发射光谱法中，可将样品直接引入光源中；在原子吸收和原子荧光光谱法中，可将样品溶液引入原子化器中。

:::definition{label="样品池"}
样品池又称试样池、吸收池、比色皿，由光透明材料制成。
:::

:::compare{title="不同方法如何安放样品"}
| 方法 | 样品如何放 | 材料／器件（本版） |
|------|------------|-------------------|
| 紫外–可见，紫外光区 | 样品池 | 石英 |
| 紫外–可见，可见光区 | 样品池 | 硅酸盐玻璃 |
| 红外光谱 | 样品池窗口 | $\mathrm{NaCl}$、$\mathrm{KBr}$、KRS-5（$58\%\,\mathrm{TlI}+42\%\,\mathrm{TlBr}$） |
| 原子发射 | 样品直接引入光源 | 无常规液体池 |
| 原子吸收、原子荧光 | 样品溶液引入原子化器 | 原子化器代替比色皿 |
:::

:::pitfall{label="紫外用石英，可见才用玻璃；红外窗口不是玻璃"}
普通硅酸盐玻璃紫外不透明。KRS-5 是 $58\%\,\mathrm{TlI}$ 和 $42\%\,\mathrm{TlBr}$ 的混合晶体，不要写成“一种塑料”。AES 把样品送进光源，AAS／AFS 送进原子化器，不要三法都画成同一只比色皿。
:::

## 四、检测器

在光谱分析法中，检测器的功能是将光辐射信号转换为可量化输出的信号，主要有两类检测器：光电检测器和热检测器。

:::definition{label="检测器"}
检测器把光辐射信号转换为可量化输出的信号。主要两类：光电检测器和热检测器。
:::

### 1. 光电检测器

光电检测器必须在一个较宽的波长范围内对光辐射有响应，且在低辐射功率时反应敏感，对光辐射的响应快，产生可以很快被放大的电信号，噪声小，更重要的是产生的电信号必须与入射光束的强度成正比。这类检测器包括单道光子检测器（如硒光电池、光电管、光电倍增管、硅二极管等）和多道光子检测器（如光电二极管阵列检测器、电荷转移元件阵列检测器等）。

:::definition{label="光电检测器"}
宽波长响应、低功率敏感、响应快、电信号可放大、噪声小，且电信号必须与入射光束强度成正比。分单道（硒光电池、光电管、光电倍增管、硅二极管等）和多道（光电二极管阵列、电荷转移元件阵列等）。
:::

### 2. 热检测器

热检测器是黑体吸收辐射并根据吸收引起的热效应来测量入射辐射的强度的，主要应用于测量红外辐射的强度。因红外辐射光子能量较低，一般不足以引起光电子发射，所以不能用光电检测器检测。常用的热检测器有真空热电偶、热释电检测器等。

:::definition{label="热检测器"}
热检测器是黑体吸收辐射，根据热效应测量入射辐射强度，主要用于红外。红外光子能量较低，一般不足以引起光电子发射，故不能用光电检测器。常用真空热电偶、热释电检测器等。
:::

:::compare{title="光电检测器与热检测器"}
| 项目 | 光电检测器 | 热检测器 |
|------|------------|----------|
| 原理 | 光 → 电（光电子） | 黑体吸收入射辐射 → 热效应 |
| 关键要求 | 电信号与入射光强成正比 | 测热 |
| 本版成员 | 单道：硒光电池、光电管、光电倍增管、硅二极管；多道：二极管阵列、电荷转移阵列 | 真空热电偶、热释电检测器等 |
| 波谱区 | 紫外、可见等能打出光电子的区域 | 红外 |
| 为什么红外不用光电 | — | 红外光子能量低，一般不足以引起光电子发射 |
:::

:::pitfall{label="红外不用光电倍增管，不是因为“红外不重要”"}
原因写在教材里：光子能量低，一般不足以引起光电子发射。真空热电偶、热释电才是红外那一本账。
:::

## 五、读出器件

由检测器将光信号转变为电信号后，可用检流计、记录仪、数字显示器或加入适当的电子线路信号处理系统，来显示或记录测定结果。

:::definition{label="读出器件"}
检测器把光信号变成电信号之后，用检流计、记录仪、数字显示器或电子线路信号处理系统，显示或记录测定结果。图3-4里画成工作站。
:::

:::keypoint{label="五块各管一件事"}
- 光源：给足够且稳定的光（或激发能）。
- 单色器：把复合光变成单色光或窄带。
- 样品池：让光与物质相遇（或让样品进入光源／原子化器）。
- 检测器：光 → 可量化电信号（红外走热检测器）。
- 读出器件：把电信号显示或记录下来。
:::
