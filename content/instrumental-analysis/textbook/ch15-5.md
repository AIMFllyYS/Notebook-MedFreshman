# 第5节　定性和定量分析方法

第 4 节把检测窗写成柱上 UV、DAD、LIF、电化学和 CE-MS。本节只回答两件事：峰是谁、峰有多少。定性三条——相对迁移时间、DAD 紫外光谱、CE-MS；定量两条——内标对比、叠加对比。CE 的重现性不如 HPLC，不要把第 14 章外标一点法直接搬过来当默认。不要编造本版没有的校正因子表。

:::definition{label="电泳图上的两个可测值"}
迁移时间（或相对迁移时间）管「是谁」；峰面积或峰高管「有多少」。图 15-8 已经把这两句话写在仪器出口。
:::

:::concept{term="先问重现性够不够，再问要不要内标"}
看见定量，先不要默写归一化。户头是：电动进样有歧视，压力进样把本底溶剂一并引入，EOF 对温度、$\mathrm{pH}$、离子强度都敏感，所以 CE 重现性不如 HPLC。自动进样重复性 $\le 3\%$ 才达到一般定量要求。找不到内标或峰太密，用叠加对比，不另找内标物。
:::

## 一、定性分析方法

**（1）一般采用组分的相对迁移时间与对照品对比定性。**　绝对迁移时间随 EOF 波动，同一实验室换一根管、换一天缓冲液，$t$ 就会漂。相对迁移时间把样品的 $t$ 除以内标或电渗标记物的 $t$，用来和对照品对比。第 2 节表观淌度 $\mu_{\mathrm{app}}=L_{\mathrm{d}}L_{\mathrm{t}}/(tU)$ 是把迁移时间换成淌度的同一条路：条件固定时，$\mu_{\mathrm{app}}$ 由淌度决定，比裸 $t$ 稳。习题 3 把苯胺、甲苯、苯甲酸的 $t$ 换成 $\mu_{\mathrm{app}}$ 和 $\mu_{\mathrm{ep}}$，定性上就是「这个峰的淌度是否和对照品一致」；不要只报三个秒数。

对照品必须和样品走同一根管、同一缓冲液、同一电压和温度。第 3 节写温度每变 $1\,^{\circ}\mathrm{C}$ 黏度变 $2\%\sim 3\%$，EOF 和迁移时间都跟着变；把对照品昨天的 $t$ 拿到今天的样品图上比，相对迁移时间这条定性就失效。药典或文献给的电泳条件（例 15-1～15-3 的管长、缓冲液、$\mathrm{pH}$）要一起复现，不是只复现检测波长。

**（2）利用二极管阵列检测器（DAD）给出的紫外吸收光谱定性，但特征性较差。**　DAD 在检测窗上扫一段波长，给每个峰一张紫外图。第 4 节已经写过 UV 光程受内径限制；紫外光谱本身指纹性不如红外、质谱，本版明确「特征性较差」。可以用来排除「这个峰的紫外和对照品完全不像」，不足以单独指认复杂混合物里的未知物。

**（3）当前最有前途的方法是用毛细管电泳–质谱联用法（CE-MS）定性。**　虽然 CE-MS 联用能解决 CE 定性难的问题，但还存在多数背景电解质含有非挥发性盐的现象，从而限制了 CE-MS 的广泛应用，是需要解决的课题。

:::definition{label="相对迁移时间定性"}
组分相对迁移时间与对照品对比。一般方法，第一条。不要把绝对 $t$ 当成气相色谱里可以上库检索的保留指数。
:::

:::definition{label="DAD 紫外光谱定性"}
二极管阵列给出紫外吸收光谱。特征性较差。第 4 节 DAD 首先是紫外检测器的一种，本节才把它借来做定性。
:::

:::definition{label="CE-MS 定性"}
当前最有前途。能解决 CE 定性难。限制：多数背景电解质含非挥发性盐，和质谱真空、喷雾不对付。课题还在，不是已经普及到可以不写对照品。
:::

:::compare{title="定性三条的把握"}
| 方法 | 本版用词 | 能做什么 | 不能做什么 |
|------|----------|----------|------------|
| 相对迁移时间 vs 对照品 | 一般采用 | 已知物确认、药典对照 | 未知物结构 |
| DAD 紫外光谱 | 特征性较差 | 辅助排除、峰纯度粗看 | 单独指认 |
| CE-MS | 最有前途 | 结构信息、高灵敏 | 非挥发性盐背景未解决前不能当万能 |
:::

:::insight{label="定性难，是因为没有色谱那么多保留指数库"}
CE 的 $t$ 绑在 EOF 上，EOF 绑在管壁和缓冲液上。相对迁移时间是把对照品和样品放在同一根管、同一次或同一套条件下比。不要发明本版没有的「CE Kovats 指数」。
:::

:::pitfall{label="非挥发性盐不是小问题"}
磷酸盐、硼酸盐、Tris 的许多盐，正是 CZE／MEKC 常用背景。直接喷进 MS 会抑制离子化、污染接口。第 3 节 NACE 写「可与质谱联用」，有机溶剂背景往往更友好，不要把这句话理解成水溶液 CE-MS 已经没有盐的问题。
:::

:::pitfall{label="不要用第 6 节电泳图的峰号去「定性未知物」"}
例 15-1～例 15-3 的峰归属来自文献和对照品（酸性峰／主峰／碱性峰，或左旋紫草素、乙酰紫草素）。那是应用示例，不是本节的第三种定性方法。
:::

:::definition{label="相对迁移时间常用分母"}
分母可以是电渗标记物的 $t_{0}$（中性物，如硫脲、甲苯），也可以是特意加入的内标峰。前者给出的是 $\mu_{\mathrm{app}}/\mu_{\mathrm{eo}}$ 这一类比值，后者把内标淌度当作尺子。本版本节只写「相对迁移时间与对照品对比」，没有另给符号 $t_{\mathrm{r}}'$。
:::

:::note{label="阴极检测时对照品出峰窗口要先估"}
第 2 节顺序：阳离子早于 $t_{0}$，阴离子晚于 $t_{0}$。对照品若是苯甲酸一类阴离子，不要在 $t_{0}$ 之前的窗口里找它。例 15-2 把 $\mathrm{pH}$ 调到 $2.2$，EOF 被压住，对映体窗口会整体后移到约 $28\sim 31\,\mathrm{min}$，不要拿中性标记物的 $1.5\,\mathrm{min}$（习题 1）去套。
:::

## 二、定量分析方法

CE 的重现性不如 HPLC，宜采用内标对比法或叠加对比法进行定量分析。内标对比法同液相色谱。具有自动进样装置的毛细管电泳仪，定量的重复性 $\le 3\%$，可达到定量的一般要求。在很难找到适宜的内标物或电泳峰太多、无处插入内标峰时，可使用叠加对比法。该法不需要内标物，却具有内标法的优点。该法具体做法与分析实例可参考有关文献。

:::definition{label="内标对比法"}
同液相色谱：样品中加入已知量内标，用待测物与内标的峰面积（或峰高）比定量。用来压进样体积、EOF 和检测响应的波动。
:::

:::definition{label="叠加对比法"}
标准加入思路在电泳图上的名字。不需要内标物，却具有内标法的优点。适用于找不到适宜内标，或峰太多无处插入内标峰。具体操作本版指向文献，不要在这里编一套体积公式冒充教材例题。
:::

:::definition{label="自动进样重复性"}
$\le 3\%$，可达到定量的一般要求。这是「有自动进样装置」的仪器，不是手控虹吸进样的默认值。
:::

:::compare{title="为什么定量不首选外标一点法"}
| 来源 | 对峰面积的影响 |
|------|----------------|
| 电动进样歧视 | 淌度大的组分进得更多（第 4 节） |
| 压力进样 | 无歧视，但本底溶剂一并进入 |
| 温度 | 每 $1\,^{\circ}\mathrm{C}$ 黏度 $2\%\sim 3\%$；压力进样体积随黏度变（第 3 节） |
| EOF | $\mathrm{pH}$、离子强度、甲醇、添加剂都会改 $t$ 和过窗速度 |
:::

:::insight{label="峰面积还跟过检测窗的速度有关"}
柱上检测：走得快的区带在窗里停留短，同样浓度积分面积会偏小。内标若和待测物淌度接近，速度因子被比掉。这是「宜用内标」在检测几何上的一句，不是另给公式。
:::

:::keypoint{label="定性三条、定量两条"}
- 定性：相对迁移时间（一般）→ DAD 紫外（特征性较差）→ CE-MS（最有前途，盐未解决）。
- 定量：内标对比（同液相）；叠加对比（无内标可用时）。自动进样 $\le 3\%$。
:::

:::pitfall{label="「同液相色谱」不是「同气相外标」"}
内标对比法同液相色谱，指峰面积比、校正因子那一套操作。不要把第 13 章归一化、校正因子 $f_{i}'$ 的整张表搬进来当本章必背。本版本章没有给出 CE 专用 $f_{i}$ 表。
:::

:::compare{title="峰面积对峰高"}
| | 本版仪器出口怎么写 | 定量时怎么用 |
|--|---------------------|--------------|
| 迁移时间 | 定性 | 用相对值，不用绝对秒数当身份证 |
| 峰面积 | 定量首选 | 内标比或叠加对比；过窗速度会影响面积 |
| 峰高 | 也可以定量 | 展宽、吸附拖尾时不如面积稳 |

第 4 节原文是「根据谱峰的迁移时间和峰面积或峰高进行定性和定量分析」。本节把定量收成内标／叠加，没有禁止峰高，但也没有把它写成优于面积。
:::

:::pitfall{label="手动虹吸不要冒充 ≤3%"}
$\le 3\%$ 写在「具有自动进样装置的毛细管电泳仪」。第 4 节压力进样含重力虹吸，手控时间一抖，体积就变。没有自动进样时更应内标，不要把 $3\%$ 抄成所有 CE 定量的保证值。
:::

:::cause-effect{title="为什么叠加对比能顶内标"}
- 因：同一根管、同一次电泳里，样品峰和后加入的标准增量走同一 EOF、同一进样歧视
- 果：不需要另找内标峰位，却把进样和 EOF 波动比掉；峰太密插不进内标时用这一户
:::

:::tip{label="定量前先问进样方式"}
电动进样：淌度大的组分进得多，外标曲线对高淌度组分会偏高。压力进样：无歧视，但本底溶剂稀释区带。扩散进样：$10\sim 60\,\mathrm{s}$，时间写进方法学。三种进样不要混用同一条外标曲线。
:::

:::memory{label="定性和定量口诀"}
是谁：相对 t，对照品；DAD 光谱把握差；想看结构找 CE-MS，先问盐挥不挥发。有多少：重现不如液相，内标或叠加；自动进样三个百分算及格。
:::
