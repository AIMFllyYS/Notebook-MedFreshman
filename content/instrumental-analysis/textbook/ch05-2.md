# 第2节　分子荧光分析法的基本原理

第 1 节把荧光写成：分子吸收光子后，从激发态最低振动能级回到基态时所发射的光。本节把这句话拆开：分子怎样被激发到单重态、怎样经振动弛豫和内转换落到 $\mathrm{S}_1$ 最低振动能级、怎样发射荧光或跨越到三重态再发磷光；然后写激发光谱与发射光谱、斯托克斯位移、形状与激发波长无关、镜像对称；再写荧光寿命、荧光效率与分子结构；最后写温度、溶剂、pH、熄灭剂和散射光。能级图、激发/发射光谱页嵌进来。不要把第 3 节的 $F=Kc$ 和第 4 节光路提前搬进来。

## 一、分子荧光的产生

### （一）分子的激发过程

物质分子体系中存在着电子能级、振动能级和转动能级。室温下大多数分子处在电子能级基态的最低振动能级，当吸收了一定能量后，会跃迁到较高能级，即处于分子的激发态。此跃迁过程称为激发，所需时间约 $10^{-15}\,\mathrm{s}$。

:::definition{label="激发"}
室温下大多数分子处在电子能级基态的最低振动能级。吸收一定能量后跃迁到较高能级，处于激发态。这一跃迁称为激发，所需时间约 $10^{-15}\,\mathrm{s}$。
:::

根据泡利（Pauli）不相容原理，分子中占据同一轨道的两个电子必须具有相反的自旋方向，即自旋配对。此时两个电子的自旋量子数分别为 $1/2$ 和 $-1/2$，其总电子自旋量子数 $S$ 等于 $0$，即基态没有净自旋。

电子能级的多重态用 $M=2S+1$ 表示，其中 $S$ 为各电子自旋量子数的代数和，其数值为 $0$ 或 $1$。当 $S=0$ 时分子的多重态 $M=1$，该分子处于单重态（singlet state），用符号 $\mathrm{S}$ 表示。符号 $\mathrm{S}_0$、$\mathrm{S}_1$ 和 $\mathrm{S}_2$ 分别表示分子的基态、第一电子激发单重态和第二电子激发单重态。当 $S=1$ 时分子的多重态 $M=3$，该分子处于三重态（triplet state），用符号 $\mathrm{T}$ 表示。符号 $\mathrm{T}_1$ 和 $\mathrm{T}_2$ 分别表示第一电子激发三重态和第二电子激发三重态。大多数有机化合物分子的基态都处于单重态。

:::definition{label="单重态"}
总电子自旋量子数 $S=0$，多重态 $M=2S+1=1$，分子处于单重态（singlet state），符号 $\mathrm{S}$。$\mathrm{S}_0$、$\mathrm{S}_1$、$\mathrm{S}_2$ 分别是基态、第一和第二电子激发单重态。
:::

:::definition{label="三重态"}
$S=1$，$M=3$，分子处于三重态（triplet state），符号 $\mathrm{T}$。$\mathrm{T}_1$、$\mathrm{T}_2$ 分别是第一和第二电子激发三重态。
:::

:::definition{label="多重态"}
电子能级的多重态 $M=2S+1$。$S$ 为各电子自旋量子数的代数和，本版取其值为 $0$ 或 $1$。
:::

:::keypoint{label="基态多数是单重态"}
大多数有机化合物分子的基态都处于单重态。占据同一轨道的两个电子自旋配对，$S=0$，没有净自旋。
:::

当基态的一个电子吸收光辐射被激发而跃迁到较高电子能态时，如果电子在跃迁过程中不发生自旋方向的改变，两个电子的自旋方向仍相反，$S$ 仍等于 $0$，这时分子处于激发单重态（$M=1$）。如果电子在跃迁过程中还伴随着自旋方向的改变，两个电子的自旋方向相同，$S$ 等于 $1$，这时分子处于激发三重态（$M=3$）。激发三重态的能级比激发单重态的能级要低，这是因为根据洪德（Hund）规则，处于分子轨道上的非成对电子平行自旋比成对自旋更稳定。

:::definition{label="激发单重态与激发三重态"}
跃迁中自旋方向不变，$S=0$，为激发单重态。跃迁中自旋方向改变、两个电子自旋相同，$S=1$，为激发三重态。同一电子组态下，激发三重态能级低于激发单重态。
:::

:::insight{label="三重态更低，是因为平行自旋更稳定"}
洪德规则：非成对电子平行自旋比成对自旋更稳定。所以 $\mathrm{T}_1$ 比对应的 $\mathrm{S}_1$ 低。磷光波长比荧光更长，户头就在这里。
:::

::figure{src="/images/instrumental-analysis/textbook/p0099_01.jpg" caption="图5-1　基态、激发单重态和激发三重态的电子分布。a—基态；b—激发单重态；c—激发三重态。" alt="三个自旋示意图：a 基态两电子自旋相反；b 激发单重态自旋仍相反；c 激发三重态两电子自旋平行，能级低于单重态"}

当物质分子受光照射时，若光子的能量恰好为分子的某两个能级的能量差，则电子就会吸收光子发生跃迁。根据自旋禁阻选律，基态分子中的电子只能跃迁到激发单重态的各个不同振动–转动能级（如图 5-2 中的 $\mathrm{S}_1$ 或者 $\mathrm{S}_2$），而不能直接跃迁到激发三重态的各个振动–转动能级。但持续一段时间后，有可能发生电子的自旋，生成激发三重态（如图 5-2 中的 $\mathrm{T}_1$）。

:::definition{label="自旋禁阻选律"}
基态分子中的电子只能跃迁到激发单重态的各个不同振动–转动能级，而不能直接跃迁到激发三重态。激发三重态要靠后来的自旋反转（体系间跨越）生成。
:::

:::pitfall{label="不要把激发直接画到 T₁"}
吸收一步只能 $\mathrm{S}_0\to\mathrm{S}_1$ 或 $\mathrm{S}_2$。$\mathrm{T}_1$ 不是光照当场跳上去的。把磷光听成“吸收后直接从三重态发射”，选律和延迟时间都会讲反。
:::

### （二）分子的去活化过程

图 5-2 是荧光和磷光产生的示意图。处于激发态的分子不稳定，可通过辐射跃迁和非辐射跃迁等分子内的去活化过程释放多余的能量而返回至基态。发射荧光是其中的一条途径。

::figure{src="/images/instrumental-analysis/textbook/p0100_01.jpg" caption="图5-2　荧光和磷光产生的示意图。（a）吸收；（b）振动弛豫；（c）内部能量转换；（d）荧光；（e）体系间跨越；（f）磷光。" alt="Jablonski 图：S2、S1、S0 与 T1；标出吸收、振动弛豫、内转换、荧光、体系间跨越、磷光"}

**（1）振动弛豫（vibrational relaxation）**　分子吸收能量跃迁到第一电子激发态或更高电子激发态的不同振动能级上。处于激发态各振动能级的分子通过与溶剂分子碰撞而将部分振动能量传递给溶剂分子，其电子返回同一电子激发态最低振动能级，这一过程称为振动弛豫。这一部分能量以热的形式释放，而不是以光辐射的形式放出，故振动弛豫属于非辐射跃迁。振动弛豫只能在同一电子能级内进行，发生振动弛豫的时间约为 $10^{-12}\,\mathrm{s}$。

:::definition{label="振动弛豫"}
振动弛豫（vibrational relaxation）：激发态各振动能级的分子与溶剂碰撞，把部分振动能量传给溶剂，返回同一电子激发态的最低振动能级。属非辐射跃迁，只能在同一电子能级内进行，时间约 $10^{-12}\,\mathrm{s}$。
:::

**（2）内部能量转换（internal conversion）**　又称内转换。本版英文印刷为 internal conversation。当两个电子能级非常靠近以致其振动能级有重叠时，常发生电子由高能级以非辐射跃迁方式转移至低能级的过程。如图 5-2（c）所示，激发态 $\mathrm{S}_1$ 上较高振动能级与激发态 $\mathrm{S}_2$ 上较低振动能级的势能非常接近，能量很容易从 $\mathrm{S}_2$ 转移到 $\mathrm{S}_1$。无论电子最初处于哪一个激发单重态，通过内部能量转换及振动弛豫，所有分子均可返回到第一激发单重态的最低振动能级。

:::definition{label="内部能量转换"}
内部能量转换（internal conversion；本版英文印作 conversation）又称内转换。两个电子能级非常靠近、振动能级有重叠时，电子由高能级以非辐射方式转到低能级。配合振动弛豫，所有分子都可回到 $\mathrm{S}_1$ 的最低振动能级。
:::

:::insight{label="先落到 S₁ 最低振动能级，再决定往哪走"}
不管吸收把分子打到 $\mathrm{S}_2$ 还是更高，内转换加振动弛豫都会先送到 $\mathrm{S}_1$ 最低振动能级。所以荧光发射光谱通常只有一个发射带，形状与激发波长无关。
:::

**（3）荧光发射（fluorescence emission）**　激发态分子通过振动弛豫和内部能量转换回到第一电子激发态 $\mathrm{S}_1$ 的最低振动能级后，再以辐射形式发射光量子而跃迁到基态 $\mathrm{S}_0$ 的任一振动能级上，这时分子发射的光量子即称为荧光。由于振动弛豫和内部能量转换损失了部分能量，荧光的能量总小于所吸收的紫外光能量，故发射荧光的波长总比原来照射的紫外光波长更长。发射荧光的过程为 $10^{-9}\sim 10^{-7}\,\mathrm{s}$。由于电子跃迁回到基态时可以停留在任一振动能级上，因此得到的荧光谱线有时呈现几个非常靠近的峰；同时，通过进一步振动弛豫，这些电子都很快地回到基态的最低振动能级。

:::definition{label="荧光发射"}
荧光发射（fluorescence emission）：从 $\mathrm{S}_1$ 的最低振动能级以辐射形式跳到 $\mathrm{S}_0$ 的任一振动能级。过程 $10^{-9}\sim 10^{-7}\,\mathrm{s}$。因为前面已经损失部分能量，荧光波长总比激发用的紫外光更长。
:::

**（4）外部能量转换（external conversion）**　又称外转换。溶液中的激发态分子与溶剂分子或与其他溶质分子之间相互碰撞而失去能量，常以热能的形式放出，这个过程称为外部能量转换。它也是一种热平衡过程，所需时间为 $10^{-9}\sim 10^{-7}\,\mathrm{s}$。这种无辐射跃迁发生在第一电子激发单重态或第一电子激发三重态的最低振动能级向基态转换的过程中。外部能量转换会降低荧光强度，因而常使用黏度较高的溶剂及温度较低的条件以利于产生荧光。

:::definition{label="外部能量转换"}
外部能量转换（external conversion）又称外转换。激发态分子与溶剂或其他溶质碰撞失能，常以热放出。时间 $10^{-9}\sim 10^{-7}\,\mathrm{s}$。会降低荧光强度；高黏度溶剂、较低温度有利于荧光。
:::

**（5）体系间跨越（intersystem crossing）**　是一个受激分子的电子在激发态发生自旋反转而使分子的多重性发生变化的过程。如果单重态 $\mathrm{S}_1$ 的最低振动能级同三重态 $\mathrm{T}_1$ 的最高振动能级有所重叠，则可能发生电子自旋反转的体系跨越。由激发单重态到激发三重态体系间跨越后，荧光强度减弱甚至熄灭。含有重原子如碘、溴等的分子，体系间跨越最为常见。这是因为在高原子序数的原子中，电子的自旋与轨道运动之间的相互作用较大，有利于电子自旋反转的发生。另外在溶液中存在氧分子等顺磁性物质也能增加体系间跨越的发生，从而使荧光减弱。

:::definition{label="体系间跨越"}
体系间跨越（intersystem crossing）：激发态电子自旋反转，分子的多重性改变。$\mathrm{S}_1$ 最低振动能级与 $\mathrm{T}_1$ 最高振动能级重叠时可能发生。结果是荧光减弱甚至熄灭，重原子（碘、溴）和氧等顺磁性物质会促进它。
:::

**（6）磷光发射（phosphorescence emission）**　经过体系间跨越的分子再通过振动弛豫降至三重态的最低振动能级，分子在三重态的最低振动能级可以存活一段时间（故磷光要延迟一定时间才发生），然后发出光辐射跃迁至基态的各个振动能级，这种光辐射称为磷光。由于激发三重态的最低振动能级比激发单重态的最低振动能级能量低，所以磷光辐射的能量比荧光更小，亦即磷光的波长比荧光更长。另外，从紫外光照射到发射荧光的时间为 $10^{-14}\sim 10^{-8}\,\mathrm{s}$，而因为分子在激发三重态的寿命较长，所以磷光发射比荧光更迟，需要 $10^{-4}\sim 10\,\mathrm{s}$ 或更长时间。由于室温下分子间相互碰撞及溶剂间相互作用和各种猝灭效应等因素的影响，处于激发三重态的分子常常通过非辐射过程失活回到基态，因此在室温下很少呈现磷光，只有通过冷冻或固定化而减少外部能量转换才能检测到磷光。所以磷光分析法不如荧光分析法应用普遍。

:::definition{label="磷光发射"}
磷光发射（phosphorescence emission）：体系间跨越之后，经振动弛豫落到 $\mathrm{T}_1$ 最低振动能级，再辐射到 $\mathrm{S}_0$ 的各个振动能级。波长比荧光更长，时间 $10^{-4}\sim 10\,\mathrm{s}$ 或更长。室温下很少呈现，需冷冻或固定化。
:::

:::compare{title="六条去活化途径"}
| 途径 | 辐射？ | 时间（本版） | 落点 |
|------|--------|--------------|------|
| 振动弛豫 | 非辐射（热） | 约 $10^{-12}\,\mathrm{s}$ | 同一电子能级内，回到该激发态最低振动能级 |
| 内部能量转换 | 非辐射 | 与振动弛豫配合 | $\mathrm{S}_2\to\mathrm{S}_1$，最终到 $\mathrm{S}_1$ 最低振动能级 |
| 荧光发射 | 辐射 | $10^{-9}\sim 10^{-7}\,\mathrm{s}$ | $\mathrm{S}_1$ 最低振动能级 $\to\mathrm{S}_0$ 任一振动能级 |
| 外部能量转换 | 非辐射（热） | $10^{-9}\sim 10^{-7}\,\mathrm{s}$ | 与溶剂或溶质碰撞，降低荧光 |
| 体系间跨越 | 非辐射 | — | $\mathrm{S}_1\to\mathrm{T}_1$，自旋反转 |
| 磷光发射 | 辐射 | $10^{-4}\sim 10\,\mathrm{s}$ 或更长 | $\mathrm{T}_1$ 最低振动能级 $\to\mathrm{S}_0$ 各振动能级 |
:::

如图 5-2 所示，假如分子被激发到 $\mathrm{S}_2$ 或以上的某个电子激发单重态的各振动能级，处于这种激发态的分子很快发生振动弛豫回到该激发态的最低振动能级，然后又经由内部能量转换及振动弛豫返回到第一电子激发单重态的最低振动能级。接着可通过以下途径从激发态回到基态：

① 从第一电子激发单重态的最低振动能级发射荧光回到基态。

② 通过外部能量转换从激发态回到基态。

③ 从第一激发单重态体系间跨越跃迁到第一激发三重态，然后通过振动弛豫回到第一激发三重态的最低振动能级，最终通过发射磷光回到基态。

综上所述，荧光和磷光的主要区别在于：荧光是由第一电子激发单重态的最低振动能级回到基态所产生的，而磷光是由第一电子激发三重态的最低振动能级回到基态所产生的。

:::compare{title="荧光对磷光"}
| 项目 | 荧光 | 磷光 |
|------|------|------|
| 出发能级 | $\mathrm{S}_1$ 最低振动能级 | $\mathrm{T}_1$ 最低振动能级 |
| 能量 / 波长 | 较高 / 较短 | 更低 / 更长 |
| 时间 | 紫外照射到发射荧光 $10^{-14}\sim 10^{-8}\,\mathrm{s}$；发射过程 $10^{-9}\sim 10^{-7}\,\mathrm{s}$ | $10^{-4}\sim 10\,\mathrm{s}$ 或更长，要延迟 |
| 室温 | 常见 | 很少；需冷冻或固定化 |
| 应用 | 普遍 | 不如荧光普遍 |
:::

:::pitfall{label="时间账不要对调"}
激发约 $10^{-15}\,\mathrm{s}$，振动弛豫约 $10^{-12}\,\mathrm{s}$，荧光 $10^{-9}\sim 10^{-7}\,\mathrm{s}$，磷光 $10^{-4}\sim 10\,\mathrm{s}$。把磷光听成“比荧光更快”，或把振动弛豫听成荧光寿命，后面时间分辨荧光会对空。
:::

:::memory{label="荧光从 S₁ 回，磷光从 T₁ 回"}
问法：分子被打到 $\mathrm{S}_2$ 以后怎样才能发荧光或磷光？
答：振动弛豫 + 内转换先到 $\mathrm{S}_1$ 最低振动能级。由此：发荧光回 $\mathrm{S}_0$；或外转换热失活；或体系间跨越到 $\mathrm{T}_1$，再振动弛豫后发磷光。吸收不能直接到三重态。
:::

## 二、荧光的激发光谱和发射光谱

任何发射荧光的物质分子都产生两种特征光谱：激发光谱和发射光谱。

激发光谱（excitation spectrum）是指不同激发波长的辐射引起物质发射某一波长荧光所得的光谱。测定时使光源发出的激发光先通过激发单色器分光，以不同波长的入射光激发荧光物质，所产生的荧光通过固定在某一波长的发射单色器后由检测器检测相应的荧光强度。记录荧光强度 $F$ 对激发光波长 $\lambda_\mathrm{ex}$ 的光谱曲线，即激发光谱，其形状与其吸收光谱极为相似。

:::definition{label="激发光谱"}
激发光谱（excitation spectrum）：不同激发波长的辐射引起物质发射某一波长荧光所得的光谱。扫描的是 $\lambda_\mathrm{ex}$，发射单色器固定。形状与吸收光谱极为相似。
:::

发射光谱（emission spectrum）又称荧光光谱（fluorescence spectrum），是指某一激发波长下不同发射波长处荧光的相对强度光谱。测定时使激发光的波长和强度保持不变，让荧光物质所产生的荧光通过发射单色器分光后照射于检测器上，检测不同发射波长下相应的荧光强度。记录荧光强度 $F$ 对发射波长 $\lambda_\mathrm{em}$ 的关系曲线，所得到的谱图称为荧光光谱。

:::definition{label="发射光谱（荧光光谱）"}
发射光谱（emission spectrum）又称荧光光谱（fluorescence spectrum）：某一激发波长下不同发射波长处荧光的相对强度。扫描的是 $\lambda_\mathrm{em}$，激发波长和强度固定。
:::

激发光谱和发射光谱反映了物质的结构特征，因此可用来鉴别荧光物质，并作为在进行荧光测定时选择测定波长的根据。图 5-3 是硫酸奎宁的荧光激发光谱及发射光谱。

::figure{src="/images/instrumental-analysis/textbook/p0102_01.jpg" caption="图5-3　硫酸奎宁的荧光激发光谱（虚线）及发射光谱（实线）。横轴波长约 300～500 nm。" alt="硫酸奎宁激发光谱虚线在短波侧，发射光谱实线在长波侧，两峰分开"}

:::pitfall{label="激发光谱和发射光谱不要对调"}
激发光谱：改激发波长，固定看某一发射波长的 $F$。发射光谱：固定激发，改发射波长看 $F$。图 5-3 里虚线是激发、实线是发射；发射在长波一侧。把两条曲线听反，斯托克斯位移和选波长都会反。
:::

溶液荧光光谱通常具有如下特征。

**（1）斯托克斯位移（Stokes shift）**　在荧光光谱中，斯托克斯位移是指荧光波长总是大于激发光波长的现象，因斯托克斯于 1852 年首次观察到而得名。斯托克斯位移表明在激发与发射之间存在无辐射能量损失。激发态分子由于内部能量转换和振动弛豫过程而迅速到达 $\mathrm{S}_1$ 的最低振动能级，这是产生斯托克斯位移的主要原因。而荧光发射可能使激发态分子返回到基态的各个不同振动能级，然后进一步损失能量，这也会产生斯托克斯位移。这和前面讨论的荧光产生的机制一致。

:::definition{label="斯托克斯位移"}
斯托克斯位移（Stokes shift）：荧光波长总是大于激发光波长。1852 年斯托克斯首次观察到。主要原因是内转换和振动弛豫先把分子送到 $\mathrm{S}_1$ 最低振动能级；发射落到 $\mathrm{S}_0$ 较高振动能级再热弛豫，也会加大位移。
:::

:::timeline{period="斯托克斯位移与胶束增敏在本版中的时间落点"}
- **1852 年** 斯托克斯首次观察到荧光波长总大于激发光波长，后称斯托克斯位移
- **20 世纪 40 年代** 观察到胶束溶液对荧光物质有增溶、增敏和增稳作用（第 4 节）
- **20 世纪 70 年代后** 发展成胶束增敏荧光法（第 4 节）
:::

**（2）荧光光谱的形状与激发波长无关**　虽然分子的电子吸收光谱可能含有几个吸收带，但其荧光光谱却只含一个发射带。虽然分子能被激发到高于 $\mathrm{S}_1$ 的电子激发态的各个振动能级，然而由于内部能量转换和振动弛豫，会先释放能量降低到第一电子激发单重态 $\mathrm{S}_1$ 的最低振动能级后再发射荧光，所以荧光发射光谱只含一个发射带。无论用哪一种波长的光激发电子，荧光发射都指从第一电子激发单重态的最低振动能级返回基态的各个振动能级。因此荧光光谱的形状通常与激发光波长无关。

:::definition{label="荧光光谱形状与激发波长无关"}
荧光发射都从 $\mathrm{S}_1$ 最低振动能级出发，所以通常只有一个发射带，形状与用哪一个波长去激发无关。吸收光谱可以有几个吸收带，不要并户。
:::

**（3）荧光光谱与激发光谱的镜像关系**　比较荧光物质的荧光光谱与其激发（吸收）光谱，便会发现这两种光谱之间存在着“镜像对称”关系，如蒽乙醇溶液的激发光谱和荧光光谱（图 5-4）所示。吸收光谱中的吸收带主要是物质分子由基态激发至第一激发单重态的各个振动能级所致，所以其形状取决于第一激发单重态中振动能级的分布情况。而荧光光谱由受激分子从第一激发单重态的最低振动能级降落至基态中各个振动能级所致，所以荧光光谱的形状取决于基态中振动能级的分布情况。基态中振动能级的分布和第一激发单重态中振动能级的分布是类似的，因此荧光光谱的形状和激发光谱极为相似。

::figure{src="/images/instrumental-analysis/textbook/p0103_01.jpg" caption="图5-4　蒽乙醇溶液的激发光谱（虚线）和荧光光谱（实线）。1—激发光谱；2—荧光光谱；3—磷光光谱。横轴为波数 σ/cm⁻¹。图5-5　蒽分子的能级跃迁示意图：a、b、c、d、e 为吸收，a′、b′、c′、d′、e′ 为发射。" alt="上：蒽乙醇激发、荧光、磷光光谱；下：S1 与 S0 振动能级镜像跃迁"}

由图 5-4 可见，蒽乙醇溶液的吸收光谱由一些明显的小峰 a、b、c、d 等峰组成，它们分别由分子吸收光能后从基态 $\mathrm{S}_0$ 跃迁到第一电子激发单重态 $\mathrm{S}_1$ 的各个不同振动能级而形成（如图 5-5 所示）。图 5-4 中的 a 峰相当于图 5-5 中的 a 跃迁线，b 峰相当于图 5-5 中的 b 跃迁线，依次类推。而蒽乙醇溶液的荧光光谱同样包括 $\mathrm{a}'$、$\mathrm{b}'$、$\mathrm{c}'$、$\mathrm{d}'$ 等一组小峰，它们分别由分子从 $\mathrm{S}_1$ 的最低振动能级跃迁到基态 $\mathrm{S}_0$ 的不同振动能级发出的光辐射所形成。各小峰间波长递减值 $\Delta\lambda$ 与振动能级差 $\Delta E$ 有关，各小峰的高度与跃迁概率有关。

由于电子基态的振动能级分布与激发态的振动能级分布相似，因此荧光光谱和激发光谱的形状相似，并呈现“镜像对称”关系。值得注意的是，这种镜像对称关系表现为频率或波数对称而不是波长对称。根据镜像对称规则，如果有不是激发光谱镜像对称的荧光峰出现，则表示有散射光或杂质荧光存在。

:::definition{label="镜像对称"}
荧光光谱与激发（吸收）光谱呈镜像对称：吸收形状由 $\mathrm{S}_1$ 振动能级分布决定，荧光形状由 $\mathrm{S}_0$ 振动能级分布决定，二者类似。对称是频率或波数对称，不是波长对称。
:::

:::pitfall{label="镜像对称看波数，不看纳米轴对折"}
图 5-4 的横轴是 $\sigma/\mathrm{cm}^{-1}$。在波长轴上硬对折，峰对不上不要急着改理论——先换成波数。多出来的、不是镜像的峰，优先怀疑散射光或杂质荧光。
:::

:::example{label="硫酸奎宁：虚线激发、实线发射，发射更长"}
图 5-3 中激发光谱在短波侧，发射光谱在长波侧，中间就是斯托克斯位移。选测定波长时，激发取激发光谱的峰，发射取发射光谱的峰，不要把两条曲线的峰对调。
:::

## 三、荧光与分子结构的关系

物质分子结构与荧光的发生及其强度紧密相关，可根据物质的分子结构判断该物质的荧光特性。

### （一）荧光寿命和荧光效率

荧光寿命和荧光效率是荧光物质的重要发光参数。

**（1）荧光寿命（fluorescence lifetime）**　是指当除去激发光源后，分子的荧光强度降低到激发态时最大荧光强度的 $1/\mathrm{e}$ 所需的时间，常用 $\tau_\mathrm{f}$ 表示。这里 $\mathrm{e}$ 为常数 $2.718\,28$，$1/\mathrm{e}$ 约为 $37\%$。

当荧光物质受到一个极短时间的脉冲光激发后，它从激发态到基态的变化可用指数衰减定律表示

$$
F_t=F_0\mathrm{e}^{-Kt}\qquad (5\text{-}1)
$$

式中，$F_0$ 和 $F_t$ 分别为在激发态 $t=0$ 时和激发后时间 $t$ 时的荧光强度；$K$ 为衰减常数。假定在时间 $t=\tau_\mathrm{f}$ 时测得的 $F_t$ 为 $F_0$ 的 $1/\mathrm{e}$，即 $F_t=F_0\mathrm{e}^{-1}$，则

$$
F_t=F_0\mathrm{e}^{-K\tau_\mathrm{f}}\qquad (5\text{-}2)
$$

所以

$$
K=1/\tau_\mathrm{f}\qquad (5\text{-}3)
$$

式（5-1）可以写成

$$
F_t=F_0\mathrm{e}^{-t/\tau_\mathrm{f}}\qquad (5\text{-}4)
$$

或

$$
\ln\frac{F_0}{F_t}=\frac{t}{\tau_\mathrm{f}}\qquad (5\text{-}5)
$$

如果以 $\ln(F_0/F_t)$ 对 $t$ 作图，直线斜率即为 $1/\tau_\mathrm{f}$，由此可计算荧光寿命。

一般 $\tau_\mathrm{f}$ 与吸光过程的摩尔吸光系数存在以下的关系

$$
\tau_\mathrm{f}\approx 10^{-5}/\varepsilon_{\max}\quad (\mathrm{s})\qquad (5\text{-}6)
$$

因为 $\varepsilon_{\max}$ 的数值在 $10^{3}\sim 10^{5}$ 范围内，所以荧光寿命常为 $10^{-10}\sim 10^{-8}\,\mathrm{s}$。利用荧光分子寿命的差别，可以进行荧光物质混合物的分析。

:::definition{label="荧光寿命"}
荧光寿命 $\tau_\mathrm{f}$：除去激发光源后，荧光强度降到最大荧光强度的 $1/\mathrm{e}$（约 $37\%$）所需的时间。衰减 $F_t=F_0\mathrm{e}^{-t/\tau_\mathrm{f}}$。由式（5-6），$\varepsilon_{\max}$ 在 $10^{3}\sim 10^{5}$ 时，$\tau_\mathrm{f}$ 常为 $10^{-10}\sim 10^{-8}\,\mathrm{s}$。
:::

:::derivation{title="由指数衰减得到 τf"}
$F_t=F_0\mathrm{e}^{-Kt}$。当 $t=\tau_\mathrm{f}$ 时 $F_t=F_0/\mathrm{e}$，故 $K\tau_\mathrm{f}=1$，$K=1/\tau_\mathrm{f}$。代入得 $F_t=F_0\mathrm{e}^{-t/\tau_\mathrm{f}}$，两边取对数即式（5-5）。斜率为 $1/\tau_\mathrm{f}$，不是 $\tau_\mathrm{f}$ 本身。
:::

**（2）荧光效率（fluorescence efficiency）**　又称荧光量子产率（fluorescence quantum yield），是指激发态分子发射荧光的光子数与基态分子吸收激发光的光子数之比，常用 $\varphi_\mathrm{f}$ 表示，即

$$
\varphi_\mathrm{f}=\frac{\text{激发态分子发射荧光的光子数}}{\text{基态分子吸收激发光的光子数}}\qquad (5\text{-}7)
$$

如果在受激分子回到基态过程中没有其他去活化过程与发射荧光过程竞争，那么所有激发态分子都将以发射荧光的方式回到基态，这一体系的荧光效率就等于 $1$。因此一般物质的荧光效率 $\varphi_\mathrm{f}$ 只能在 $0\sim 1$ 范围内。例如：荧光素钠在水中 $\varphi_\mathrm{f}=0.92$；荧光素在水中 $\varphi_\mathrm{f}=0.65$；蒽在乙醇中 $\varphi_\mathrm{f}=0.30$；菲在乙醇中 $\varphi_\mathrm{f}=0.10$。荧光效率低的物质可能有强的紫外吸收，但所吸收的能量大多以无辐射跃迁形式释放，所以发射荧光的概率低。

:::definition{label="荧光效率"}
荧光效率（fluorescence efficiency）又称荧光量子产率（fluorescence quantum yield），$\varphi_\mathrm{f}=$ 发射荧光的光子数 / 吸收激发光的光子数。范围 $0\sim 1$。本版例子：荧光素钠（水）$0.92$，荧光素（水）$0.65$，蒽（乙醇）$0.30$，菲（乙醇）$0.10$。
:::

:::pitfall{label="有强紫外吸收不等于会发强荧光"}
发射荧光必须同时具备：强的紫外–可见吸收，以及一定的荧光效率。吸收的能量若走外转换、体系间跨越，峰再高也不亮。不要用第 4 章的 $\varepsilon$ 直接当荧光强度。
:::

:::compare{title="本版给出的荧光效率"}
| 物质 | 介质 | $\varphi_\mathrm{f}$ |
|------|------|----------------------|
| 荧光素钠 | 水 | $0.92$ |
| 荧光素 | 水 | $0.65$ |
| 蒽 | 乙醇 | $0.30$ |
| 菲 | 乙醇 | $0.10$ |
:::

### （二）分子结构对荧光效率的影响

能够发射荧光的物质应同时具备两个条件，即物质分子必须有强的紫外–可见吸收和一定的荧光效率。分子结构中有 $\pi\to\pi^{*}$ 跃迁或 $\mathrm{n}\to\pi^{*}$ 跃迁的物质都有紫外–可见吸收，但 $\mathrm{n}\to\pi^{*}$ 跃迁引起的 R 带是弱带，电子跃迁概率小，由此引起的荧光极弱。所以共轭 $\pi\to\pi^{*}$ 跃迁是产生荧光的主要跃迁类型。只有分子结构中存在共轭的 $\pi\to\pi^{*}$ 跃迁，也就是 K 带强吸收时，才可能有荧光发生。而共轭体系上的取代基对荧光强度也有较大影响。一般具有 K 带（$\pi\to\pi^{*}$ 跃迁）紫外吸收的长共轭分子，若具有刚性平面结构，则有较高的荧光效率。

:::definition{label="能发荧光的两个条件"}
① 强的紫外–可见吸收；② 一定的荧光效率。主要跃迁类型是共轭 $\pi\to\pi^{*}$（K 带）。$\mathrm{n}\to\pi^{*}$ 的 R 带弱，荧光极弱。
:::

**（1）长共轭结构**　含有 $\pi\to\pi^{*}$ 跃迁的芳香族化合物可以产生较强的荧光。当 $\pi$ 电子共轭链越长，$\lambda_\mathrm{ex}$ 和 $\lambda_\mathrm{em}$ 都将红移，荧光强度（荧光效率）也会增大。因为芳香环或杂环分子具有长共轭的 $\pi\to\pi^{*}$ 跃迁，所以绝大多数能产生荧光的物质含有芳香环或杂环。任何有利于提高 $\pi$ 电子共轭程度的结构都将提高荧光效率，并使荧光波长向长波方向移动。

本版给出苯、萘、蒽三例：

:::compare{title="苯、萘、蒽：共轭越长，波长越红，效率越高"}
| 化合物 | $\lambda_\mathrm{ex}/\mathrm{nm}$ | $\lambda_\mathrm{em}/\mathrm{nm}$ | $\varphi_\mathrm{f}$ |
|--------|-----------------------------------|-----------------------------------|----------------------|
| 苯 | $205$ | $278$ | $0.11$ |
| 萘 | $286$ | $321$ | $0.29$ |
| 蒽 | $356$ | $404$ | $0.36$ |
:::

除芳香烃外，含有长共轭双键的脂肪烃也可能有荧光，但这一类化合物的数目较少。维生素 A 是能发荧光的脂肪烃之一。本版附图给出带乙酸酯的共轭链，$\lambda_\mathrm{ex}=327\,\mathrm{nm}$，$\lambda_\mathrm{em}=510\,\mathrm{nm}$。

:::definition{label="长共轭与荧光"}
$\pi$ 电子共轭链越长，$\lambda_\mathrm{ex}$、$\lambda_\mathrm{em}$ 红移，荧光效率增大。绝大多数荧光物质含芳香环或杂环；维生素 A 是少数能发荧光的脂肪烃之一。
:::

**（2）刚性平面结构**　荧光效率高的物质的分子多数具有刚性平面结构。因为这种结构可以减少分子的振动，使分子与溶剂或其他溶质分子的相互作用减小（即降低外转换的概率），降低了碰撞去活化的可能性，从而增加了发光效率。

在同样的长共轭分子中，分子的刚性和共平面性越大，荧光效率越大，并且荧光波长产生红移。例如，在相似的测定条件下，联苯和芴的荧光效率 $\varphi_\mathrm{f}$ 分别为 $0.2$ 和 $1.0$，二者的结构差别在于芴的分子中加入亚甲基成桥，使两个苯环不能自由旋转成为刚性分子，共轭电子的共平面性增加，使芴的荧光效率大大增加。

:::definition{label="刚性平面结构"}
刚性平面减少振动和外转换，降低碰撞去活化，提高发光效率。同样长共轭时，刚性和共平面性越大，$\varphi_\mathrm{f}$ 越大，荧光波长红移。
:::

:::example{label="联苯 0.2，芴 1.0"}
联苯两个苯环可旋转，$\varphi_\mathrm{f}=0.2$。芴用亚甲基把两个苯环桥成刚性平面，$\varphi_\mathrm{f}=1.0$。不要把“多一个环”听成唯一原因——本版强调的是不能自由旋转。
:::

又如荧光素和酚酞，它们分子中共轭链长度相同，但荧光素分子中多一个氧桥，使分子的三个环成一个平面，随着分子的刚性和共平面性增加，电子的共轭程度增加，因而荧光素有强烈的荧光，而酚酞的荧光则很弱。

本来不发生荧光或发生较弱荧光的物质一旦与金属离子形成配合物后，如果刚性和共平面性增强，那么就可以发生荧光或增强荧光。例如，8-羟基喹啉是弱荧光物质，与 $\mathrm{Mg}^{2+}$、$\mathrm{Al}^{3+}$ 形成配合物后，荧光就增强。

相反，如果原来结构中共平面性较好，但在分子中引入了较大的取代基团后，由于位阻的原因，分子共平面性下降，则荧光减弱。例如，1-二甲氨基萘-7-磺酸钠的 $\varphi_\mathrm{f}=0.75$，而 1-二甲氨基萘-8-磺酸钠的 $\varphi_\mathrm{f}=0.03$，这是因为后者二甲氨基与磺酸根离子间的位阻效应，使分子发生了扭转，两个环不能共平面，因而使荧光大大减弱。

同理，对于顺反异构体，顺式分子的两个基团在同一侧，由于位阻原因，分子不能共平面而没有荧光。例如，1,2-二苯乙烯的反式异构体有强烈荧光，而顺式异构体没有荧光。

:::compare{title="刚性、配位、位阻、顺反"}
| 对比 | 荧光强的一侧 | 荧光弱的一侧 | 本版原因 |
|------|--------------|--------------|----------|
| 联苯 / 芴 | 芴 $\varphi_\mathrm{f}=1.0$ | 联苯 $\varphi_\mathrm{f}=0.2$ | 亚甲基成桥，不能自由旋转 |
| 荧光素 / 酚酞 | 荧光素（强） | 酚酞（弱） | 荧光素多一个氧桥，三环共平面 |
| 8-羟基喹啉 | 与 $\mathrm{Mg}^{2+}$、$\mathrm{Al}^{3+}$ 成配合物 | 游离配体弱荧光 | 配位后刚性和共平面性增强 |
| 二甲氨基萘磺酸钠 | 7-磺酸 $\varphi_\mathrm{f}=0.75$ | 8-磺酸 $\varphi_\mathrm{f}=0.03$ | 8-位位阻扭转，不能共平面 |
| 1,2-二苯乙烯 | 反式有强烈荧光 | 顺式没有荧光 | 顺式位阻，不能共平面 |
:::

**（3）取代基的影响**　荧光分子上的各种取代基对分子的荧光光谱和荧光强度都产生很大的影响。取代基可分为三大类。

第一类是给电子基团，如 $-\mathrm{NH}_2$、$-\mathrm{OH}$、$-\mathrm{OCH}_3$、$-\mathrm{NHR}$、$-\mathrm{NR}_2$、$-\mathrm{CN}$ 等。这类取代基通常能增加分子的电子共轭程度，使荧光效率提高，荧光波长红移。

第二类是吸电子基团，如 $-\mathrm{COOH}$、$-\mathrm{NO}_2$、$-\mathrm{C=O}$、$-\mathrm{NO}$、$-\mathrm{SH}$、$-\mathrm{NHCOCH}_3$ 等。它们通常会妨碍分子的电子共轭性，使荧光减弱甚至熄灭。

第三类是重原子取代基，如 $-\mathrm{Cl}$、$-\mathrm{Br}$、$-\mathrm{I}$ 等。通常卤素取代基会随着原子序数的增加而导致荧光减弱和磷光增强，如前所述，这可能是由于重原子效应加大了体系间跨越的概率。

此外还有一类取代基对电子共轭体系作用较小，如 $-\mathrm{R}$、$-\mathrm{SO}_3\mathrm{H}$、$-\mathrm{NH}_3$ 等，对荧光的影响不明显。

:::compare{title="取代基四类"}
| 类型 | 本版例子 | 对荧光 |
|------|----------|--------|
| 给电子 | $-\mathrm{NH}_2$、$-\mathrm{OH}$、$-\mathrm{OCH}_3$、$-\mathrm{NHR}$、$-\mathrm{NR}_2$、$-\mathrm{CN}$ | 共轭程度增加，$\varphi_\mathrm{f}$ 提高，波长红移 |
| 吸电子 | $-\mathrm{COOH}$、$-\mathrm{NO}_2$、$-\mathrm{C=O}$、$-\mathrm{NO}$、$-\mathrm{SH}$、$-\mathrm{NHCOCH}_3$ | 妨碍共轭，荧光减弱甚至熄灭 |
| 重原子 | $-\mathrm{Cl}$、$-\mathrm{Br}$、$-\mathrm{I}$ | 原子序数↑，荧光↓、磷光↑（体系间跨越） |
| 影响不明显 | $-\mathrm{R}$、$-\mathrm{SO}_3\mathrm{H}$、$-\mathrm{NH}_3$ | 对共轭作用较小 |
:::

## 四、影响荧光发光的外部因素

分子所处的外界环境，如温度、溶剂、pH、荧光熄灭剂等都会影响荧光效率，甚至影响分子结构及立体构象，从而影响荧光光谱和荧光强度。了解和利用这些因素，选择合适的测定条件，可以提高荧光分析的灵敏度和选择性。

### （一）温度

温度对于溶液的荧光强度有着显著的影响。在一般情况下，随着温度的升高，荧光物质溶液的荧光效率和荧光强度将降低。这是因为，当温度升高时，分子运动速度加快，分子间碰撞概率增加，使无辐射跃迁增加，从而降低了荧光效率。反之，温度降低荧光效率和荧光强度将增加。例如，荧光素钠的乙醇溶液，在 $0^\circ\mathrm{C}$ 以下，温度每降低 $10^\circ\mathrm{C}$，荧光效率增加 $3\%$，在 $-80^\circ\mathrm{C}$ 时，荧光效率 $\varphi_\mathrm{f}$ 为 $1$。

:::definition{label="温度对荧光"}
一般温度升高，$\varphi_\mathrm{f}$ 和荧光强度降低（碰撞↑，无辐射↑）。荧光素钠乙醇溶液：$0^\circ\mathrm{C}$ 以下每降 $10^\circ\mathrm{C}$，$\varphi_\mathrm{f}$ 增加 $3\%$；$-80^\circ\mathrm{C}$ 时 $\varphi_\mathrm{f}=1$。
:::

### （二）溶剂

同一物质在不同溶剂中，其荧光光谱的位置和强度都有差别。一般情况下，荧光波长随着溶剂极性的增大而红移，荧光强度也有增强。这是因为在极性溶剂中，$\pi\to\pi^{*}$ 跃迁所需的能量差 $\Delta E$ 小，而且跃迁概率增加，使紫外吸收和荧光波长均红移，强度也增强。例如，巯基喹啉溶于氯仿中在 $398\,\mathrm{nm}$ 产生荧光峰，荧光效率为 $0.041$，而其乙醇溶液在 $410\,\mathrm{nm}$ 产生荧光峰，荧光效率为 $0.064$。

溶剂黏度减小时，可以增加分子间碰撞机会，使无辐射跃迁增加而荧光减弱。故荧光强度随溶剂黏度的减小而减弱。由于温度对溶剂的黏度也有影响，一般是温度上升，溶剂黏度变小，因此温度上升荧光强度下降。

在含有重原子的溶剂如碘乙烷和四溴化碳中，与将这些成分引入荧光物质中所产生的重原子效应相似，导致荧光减弱磷光增强。若溶剂和荧光物质形成氢键或溶剂使荧光物质解离状态发生改变，则荧光波长和荧光强度也会发生改变。

:::definition{label="溶剂对荧光"}
极性增大：荧光波长红移、强度常增强（$\pi\to\pi^{*}$ 的 $\Delta E$ 变小、跃迁概率增加）。黏度减小：碰撞↑，荧光减弱。含重原子的溶剂（碘乙烷、四溴化碳）：荧光↓、磷光↑。氢键或解离状态改变也会改波长和强度。
:::

:::example{label="巯基喹啉：氯仿 398 nm / 0.041，乙醇 410 nm / 0.064"}
乙醇极性大于氯仿，峰从 $398\,\mathrm{nm}$ 红移到 $410\,\mathrm{nm}$，$\varphi_\mathrm{f}$ 从 $0.041$ 升到 $0.064$。不要把红移听成荧光变弱。
:::

### （三）pH

当荧光物质本身是弱酸或弱碱时，溶液的 pH 对该荧光物质的荧光强度有较大影响，这主要是因为弱酸、弱碱和它们的离子结构有所不同，在不同酸度中分子和离子间的平衡改变，因此荧光强度出现差异。每一种荧光物质都有其适宜的发射荧光的存在形式，也就有相应的 pH 范围，以保持荧光物质和溶剂之间的解离平衡。

苯胺分子和离子间有下列平衡：$\mathrm{pH}<2$ 时主要为 $\mathrm{PhNH}_3^{+}$；$\mathrm{pH}\,7\sim 12$ 时主要为分子 $\mathrm{PhNH}_2$；$\mathrm{pH}>13$ 时主要为 $\mathrm{PhNH}^{-}$。苯胺在 $\mathrm{pH}\,7\sim 12$ 的溶液中主要以分子形式存在，由于 $-\mathrm{NH}_2$ 为提高荧光效率的取代基，故苯胺分子会发生蓝色荧光。但在 $\mathrm{pH}<2$ 和 $\mathrm{pH}>13$ 的溶液中苯胺均以离子形式存在，故不能发射荧光。

又如，$\alpha$-萘酚分子形式无荧光，离子化后显荧光。可见溶液 pH 对荧光强度和荧光光谱有较大的影响，因此在荧光分析中应严格控制溶液的 pH。

:::definition{label="pH 对荧光"}
弱酸或弱碱的分子形式与离子形式结构不同，荧光不同。每种荧光物质有适宜的存在形式和相应 pH 范围。必须严格控制 pH。
:::

:::compare{title="苯胺与 α-萘酚的 pH 账"}
| 物质 | 有荧光的形式 | 无荧光的形式 |
|------|--------------|--------------|
| 苯胺 | $\mathrm{pH}\,7\sim 12$ 的分子（蓝色荧光，$-\mathrm{NH}_2$ 给电子） | $\mathrm{pH}<2$ 的 $\mathrm{PhNH}_3^{+}$；$\mathrm{pH}>13$ 的 $\mathrm{PhNH}^{-}$ |
| $\alpha$-萘酚 | 离子化后 | 分子形式 |
:::

:::pitfall{label="不要把“碱性一定更亮”写成通例"}
苯胺在过碱（$\mathrm{pH}>13$）时离子化，荧光反而没了；$\alpha$-萘酚却是离子化后才有荧光。先问发光的是分子还是离子，再定 pH，不要背“调碱就行”。
:::

### （四）荧光熄灭剂

荧光熄灭又称荧光猝灭，是指荧光物质分子与溶剂分子或溶质分子的相互作用引起荧光强度降低或荧光强度与浓度偏离线性关系的现象。能引起荧光熄灭的物质称为荧光熄灭剂（quenching medium）。常见的熄灭剂有卤素离子、重金属离子、氧分子，以及硝基化合物、重氮化合物、羰基化合物等。

荧光熄灭的原因很多，机制也十分复杂，主要类型包括：① 因荧光物质分子和熄灭剂分子碰撞而损失能量；② 荧光物质分子与熄灭剂分子作用生成了本身不发光的配合物；③ 在荧光物质分子中引入溴或碘后易发生体系间跨越而转变至三重态；④ 溶解氧的存在，使荧光物质氧化，或是由于氧分子的顺磁性，促进了体系间跨越，使激发态的荧光物质分子转成三重态。

荧光熄灭在荧光分析中会产生测定误差，但是如果一种荧光物质在加入某种熄灭剂后，荧光强度的减小和荧光熄灭剂的浓度呈线性关系，则可以利用这一性质测定荧光熄灭剂的含量。这种方法称为荧光熄灭法（fluorescence quenching method）。如利用氧分子对硼酸根–二苯乙醇酮配合物的荧光熄灭效应，可测定微量氧。

当荧光物质的浓度超过 $1\,\mathrm{g}\cdot\mathrm{L}^{-1}$ 时，由于荧光物质分子间碰撞的概率增加，产生荧光自熄灭现象。溶液浓度越高，这种现象越严重。

:::definition{label="荧光熄灭"}
荧光熄灭又称荧光猝灭：荧光物质分子与溶剂或溶质分子相互作用，引起荧光强度降低，或使荧光强度与浓度偏离线性。能引起熄灭的物质称为荧光熄灭剂（quenching medium）。
:::

:::definition{label="荧光熄灭法"}
荧光强度的减小与熄灭剂浓度呈线性时，可用来测定熄灭剂含量，称为荧光熄灭法（fluorescence quenching method）。本版例子：氧分子对硼酸根–二苯乙醇酮配合物的熄灭，测微量氧。
:::

:::definition{label="荧光自熄灭"}
浓度超过 $1\,\mathrm{g}\cdot\mathrm{L}^{-1}$ 时，荧光物质分子间碰撞增加，产生自熄灭。浓度越高越严重。第 3 节稀溶液线性条件与此分开记。
:::

:::keypoint{label="熄灭四条机制"}
- 碰撞失能。
- 生成不发光配合物。
- 引入溴或碘，体系间跨越到三重态。
- 溶解氧：氧化，或顺磁性促进体系间跨越。
:::

### （五）散射光

当一束平行光照射在液体样品上，大部分光线透过溶液，小部分由于光子和物质分子相碰撞，光子的运动方向发生改变而向不同角度散射，这种光称为散射光（scattering light）。

光子和物质分子发生弹性碰撞时，不发生能量的交换，仅是光子运动方向发生改变，这种散射光称为瑞利光，波长与入射光相同。

光子和物质分子发生非弹性碰撞时，在光子运动方向发生改变的同时，光子与物质分子发生能量交换，使光子能量发生改变。如果光子将部分能量转给物质分子，此时分子从振动低能级跃迁至高能级，波长比入射光更长；如果光子从物质分子得到能量，此时分子从振动高能级跌至低能级，波长比入射光为短。这两种光均称为拉曼光。

:::definition{label="散射光"}
平行光照射液体样品，小部分因光子与分子碰撞而改变方向，称为散射光（scattering light）。
:::

:::definition{label="瑞利光"}
弹性碰撞，无能量交换，只改方向。瑞利光波长与入射光相同。
:::

:::definition{label="拉曼光"}
非弹性碰撞，有能量交换。光子给分子能量：波长比入射光更长；光子从分子得能量：波长比入射光更短。两种都叫拉曼光。
:::

散射光对荧光测定有干扰。尤其是波长比入射光波长长的拉曼光，因其波长与荧光波长接近，对荧光测定的干扰更大，必须采取措施消除。选择适当的激发波长可消除拉曼光的干扰。

以硫酸奎宁为例，见图 5-6（a），无论选择 $320\,\mathrm{nm}$ 或 $350\,\mathrm{nm}$ 为激发光，荧光峰总是在 $448\,\mathrm{nm}$ 处。将空白溶剂（$0.1\,\mathrm{mol}\cdot\mathrm{L}^{-1}\,\mathrm{H}_2\mathrm{SO}_4$）分别在 $320\,\mathrm{nm}$ 及 $350\,\mathrm{nm}$ 激发光照射下测定荧光光谱，此时测得的实际上是散射光而非荧光。从图 5-6（b）可见：当激发光波长为 $320\,\mathrm{nm}$ 时，瑞利光波长是 $320\,\mathrm{nm}$，拉曼光波长是 $360\,\mathrm{nm}$；当激发光波长为 $350\,\mathrm{nm}$ 时，瑞利光波长是 $350\,\mathrm{nm}$，拉曼光波长是 $400\,\mathrm{nm}$。波长 $400\,\mathrm{nm}$ 的拉曼光对荧光峰有干扰，而波长 $360\,\mathrm{nm}$ 的拉曼光对荧光测定无影响。因此应选择 $320\,\mathrm{nm}$ 为激发波长。

::figure{src="/images/instrumental-analysis/textbook/p0109_01.jpg" caption="图5-6　硫酸奎宁在不同波长激发下的荧光光谱和溶剂的散射光谱。（a）硫酸奎宁的荧光光谱，激发 320 nm 或 350 nm，荧光峰均在 448 nm；（b）0.1 mol·L⁻¹ H₂SO₄ 的散射光谱，320 nm 激发时拉曼在 360 nm，350 nm 激发时拉曼在 400 nm。" alt="四张光谱：奎宁荧光峰固定在 448 nm；溶剂散射的瑞利峰与拉曼峰随激发波长移动"}

:::example{label="奎宁选 320 nm 而不是 350 nm"}
荧光峰钉在 $448\,\mathrm{nm}$，与激发波长无关（与本节“形状与激发波长无关”一致）。$350\,\mathrm{nm}$ 激发时溶剂拉曼落到 $400\,\mathrm{nm}$，靠近荧光；$320\,\mathrm{nm}$ 激发时拉曼在 $360\,\mathrm{nm}$，不干扰。所以选 $320\,\mathrm{nm}$。不要因为 $350\,\mathrm{nm}$ 更靠近发射峰就当激发波长。
:::

表 5-2 列出了水、乙醇、环己烷和四氯化碳四种常用溶剂在不同波长激发光照射下拉曼光的波长，可供选择激发光波长或溶剂时参考。从表中可见，四氯化碳的拉曼光与激发光的波长比较接近，所以其拉曼光几乎不干扰荧光测定；而水、乙醇及环己烷的拉曼光波长较长，使用时必须注意。

:::memory{label="激发光谱扫 λex，发射光谱扫 λem，荧光总比激发更红"}
问法：两种特征光谱怎么测？斯托克斯位移、形状、镜像各说什么？能发荧光要什么结构？
答：激发光谱固定发射、扫 $\lambda_\mathrm{ex}$，像吸收光谱；发射光谱固定激发、扫 $\lambda_\mathrm{em}$。荧光波长总大于激发波长（1852 斯托克斯）；形状通常与激发波长无关；与激发光谱波数镜像，多峰则疑散射或杂质。结构：强紫外–可见吸收 + 一定 $\varphi_\mathrm{f}$；共轭 $\pi\to\pi^{*}$、长共轭、刚性平面；给电子取代基增敏，吸电子和重原子减荧光。
:::
