# 第4节　荧光分光光度计和荧光分析技术

第 3 节把定量写成稀溶液 $F=Kc$，并规定在与激发光垂直的方向观测。本节打开仪器：光电荧光计和荧光分光光度计两类；荧光分光光度计可以测某一波长的强度，也可以画激发光谱和荧光光谱。光路与紫外–可见光度计部件大致相同，但发射光在与激发光成 $90^\circ$ 的方向上取。然后写灵敏度、波长、光谱三项校正，以及激光诱导、时间分辨、同步荧光、胶束增敏和联用。不要把第 6 章红外光路写进来。

## 一、荧光分光光度计

用于测量荧光强度的仪器有光电荧光计及荧光分光光度计两类。荧光分光光度计既可测量某一波长处的荧光强度，还可绘制激发光谱及荧光光谱。

:::definition{label="两类测荧光强度的仪器"}
光电荧光计和荧光分光光度计。后者既能测某一波长处的荧光强度，还能绘制激发光谱及荧光光谱。
:::

### （一）光电荧光计

光电荧光计的光路示意图如图 5-8 所示。光源采用高压汞灯，产生强度随波长变化的线光谱。单色器采用滤光片，仅让一定波长的光通过。置于光源和样品池间的滤光片为激发滤光片，以获得一定波长范围激发光的谱带。置于样品池和检测器之间的滤光片为发射滤光片，可截去激发光和散射光，获得样品的荧光。样品池采用石英玻璃，检测器一般采用光电管。这种荧光计不能测定光谱，但可用于定量分析。因价格低廉，在实际生产中仍普遍使用。

:::definition{label="光电荧光计"}
光源为高压汞灯（线光谱），单色器为滤光片：激发滤光片在光源与样品池之间，发射滤光片在样品池与检测器之间，截去激发光和散射光。样品池石英玻璃，检测器一般光电管。不能测定光谱，可用于定量，价格低廉，生产中仍普遍使用。
:::

### （二）荧光分光光度计

荧光分光光度计由激发光源、激发单色器、样品池、发射单色器及检测系统组成，其结构如图 5-9 所示。基本部件和紫外–可见分光光度计大致相同。激发光通过入射狭缝，经激发单色器分光后照射到样品池，发射的荧光再经发射单色器分光后用光电倍增管检测，并经信号放大系统放大后记录。为了消除透射光和反射光的干扰，通常在与激发光成 $90^\circ$ 的方向上测定荧光。

荧光分光光度计一般采用氙弧灯作激发光源，发射波长范围在 $230\sim 720\,\mathrm{nm}$ 的连续光谱，谱线强度大，且波长在 $300\sim 400\,\mathrm{nm}$ 的谱线强度几乎相等。但氙弧灯需要稳压电源以保证光源的温度。此外，还可利用各种激光器作为激发光源。

荧光分光光度计均采用光栅作为色散元件。

:::definition{label="荧光分光光度计"}
组成：激发光源、激发单色器、样品池、发射单色器及检测系统。激发光经激发单色器打到样品池，荧光再经发射单色器由光电倍增管检测。为消除透射光和反射光干扰，通常在与激发光成 $90^\circ$ 的方向上测定。色散元件均为光栅。
:::

:::definition{label="氙弧灯"}
荧光分光光度计一般用氙弧灯作激发光源。连续光谱 $230\sim 720\,\mathrm{nm}$，强度大，$300\sim 400\,\mathrm{nm}$ 的谱线强度几乎相等。需要稳压电源以保证光源温度。也可用各种激光器作激发光源。

### （三）仪器的校正

**（1）灵敏度校正**　荧光分光光度计的灵敏度可用被检测出的最低信号来表示，或用某一对照品的稀溶液在一定激发波长光的照射下，能发射出一定信噪比时的荧光强度的最低浓度表示。

荧光分光光度计的灵敏度与光源强度、单色器（包括透镜、反射镜等）的性能、放大系统的特征和光电倍增管的灵敏度有关，还与所选用的测定波长及狭缝宽度及溶剂的拉曼散射、激发光、杂质荧光等有关。由于影响荧光光度计灵敏度的因素很多，同一型号的仪器，甚至同一台仪器在不同时间操作，所测得的结果也不尽相同。因而在每次测定时，在选定波长及狭缝宽度下，应先用一种稳定的荧光物质，配成浓度一致的标准溶液进行校正，使每次所测得的荧光强度调节到相同数值。如果被测物质所产生的荧光很稳定，自身就可作为标准溶液。紫外–可见光范围内最常用的标准荧光物质是硫酸奎宁，产生的荧光十分稳定。通常用 $0.01\,\mathrm{g}$ 的奎宁标准品溶于 $0.05\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ 硫酸中，使其成为 $1\,\mathrm{g}\cdot\mathrm{mL}^{-1}$ 溶液，将此溶液进行稀释后用于仪器的校正。

:::definition{label="灵敏度校正"}
灵敏度可用被检出的最低信号表示，或用对照品稀溶液在一定激发波长下、达到一定信噪比时的最低浓度表示。每次测定，在选定波长和狭缝下，用稳定荧光物质的标准溶液把荧光强度调到相同数值。最常用硫酸奎宁。
:::

:::note{label="奎宁标准溶液的本版写法"}
本版印刷： $0.01\,\mathrm{g}$ 奎宁溶于 $0.05\,\mathrm{mol}\cdot\mathrm{L}^{-1}$ 硫酸，写成 $1\,\mathrm{g}\cdot\mathrm{mL}^{-1}$，再稀释后用于校正。工作液是稀释之后的溶液，不要把印刷的储备浓度当成比色皿里的测定浓度。
:::

**（2）波长校正**　荧光分光光度计的波长在出厂前都经过了校正，但若仪器的光学系统和检测器有所变动，或在较长时间使用之后，或在重要部件更换之后，有必要用汞灯的标准谱线对单色器波长刻度重新校正，特别是在要求较高的测定工作中尤为重要。

:::definition{label="波长校正"}
光学系统、检测器有变动，或久用、或更换重要部件后，用汞灯的标准谱线校正单色器波长刻度。要求较高的测定尤为重要。
:::

**（3）激发光谱和荧光光谱的校正**　用荧光分光光度计所测得的激发光谱或荧光光谱往往是表观的。其原因如单色器的波长刻度不够准确、拉曼散射光的影响以及狭缝宽度较大等，这些因素可予以消除或校正。由于光源的强度随波长而变，每个检测器（如光电倍增管）对不同波长光的接受敏感程度不同以及检测器的感应与波长不成线性，故如果在用单光束荧光分光光度计测定激发或发射光谱时，应先用仪器上的校正装置将各波长的光源强度调整到一致，然后根据每一波长的表观强度除以检测器对每一波长的感应强度进行校正，以消除这种误差。如果采用双光束光路的荧光分光光度计，则可用参比光束自动消除光学误差。

:::definition{label="表观光谱的校正"}
测得的激发光谱或荧光光谱往往是表观的。单色器刻度、拉曼散射、狭缝宽度可以消除或校正。单光束：先把各波长光源强度调到一致，再用表观强度除以检测器对各波长的感应强度。双光束：参比光束自动消除光学误差。
:::

:::pitfall{label="同一台仪器不同时间测得的结果可以不同"}
灵敏度受光源、单色器、放大、光电倍增管、波长、狭缝、拉曼、杂质荧光等牵动。不要拿昨天的读数直接比今天的样品，先用同一稳定标准把强度调到相同数值。
:::

## 二、其他荧光分析技术

随着仪器分析的日趋发展，荧光分析法的技术和仪器日益拓展。时间分辨、同步荧光和胶束增敏等技术的提出和应用，以激光作为光源的仪器的研制和发展，推动和促进了荧光分析法的发展，提高了荧光分析法的灵敏度和选择性。

### （一）激光诱导荧光分析

激光诱导荧光分析（laser-induced fluorometry）采用单色性好、强度大的激光作为光源的荧光分析方法。与一般光源荧光测定相比，灵敏度可提高 $2\sim 10$ 倍，甚至可进行单分子检测。因此，激光诱导荧光分析法已成为分析超低浓度物质灵敏而有效的方法，应用领域越来越广泛。

:::definition{label="激光诱导荧光分析"}
激光诱导荧光分析（laser-induced fluorometry）：以单色性好、强度大的激光为光源。灵敏度比一般光源提高 $2\sim 10$ 倍，甚至可单分子检测。用于超低浓度物质。
:::

### （二）时间分辨荧光分析

由于分子荧光的寿命不同，可在激发和检测之间延缓一段时间，使具有不同荧光寿命的物质可以被选择性检测，这就是时间分辨荧光分析（time-resolved fluorometry）。时间分辨荧光分析采用脉冲激光作为光源。激光照射样品后所发射的荧光是一混合光，它包括待测组分的荧光、其他组分或杂质的荧光和仪器的噪声。如果选择合适的延缓时间，可测定被测组分的荧光而不受其他组分、杂质的荧光及噪声的干扰。故该法在测定混合物中某一组分时的选择性比用化学法处理样品时更好，而且可省去前处理的麻烦。目前已将时间分辨荧光法应用于免疫分析，形成时间分辨荧光免疫分析法（time-resolved fluoroimmunoassay）。

:::definition{label="时间分辨荧光分析"}
时间分辨荧光分析（time-resolved fluorometry）：利用荧光寿命不同，在激发和检测之间延缓一段时间，选择性检测。光源为脉冲激光。合适的延缓时间可避开其他组分、杂质荧光和噪声。已用于免疫分析，形成时间分辨荧光免疫分析法。
:::

:::insight{label="寿命差可以代替化学前处理"}
第 2 节写 $\tau_\mathrm{f}$ 常为 $10^{-10}\sim 10^{-8}\,\mathrm{s}$，不同分子可以不同。这里把寿命差写成：选择性比化学法处理样品更好，可省去前处理。不要把时间分辨听成“把荧光计扫得更慢”。
:::

### （三）同步荧光分析

同步荧光分析（synchronous fluorometry）是在荧光物质的激发光谱和荧光光谱中选择一适宜的波长差值 $\Delta\lambda$（通常选用 $\lambda_\mathrm{ex}^{\max}$ 与 $\lambda_\mathrm{em}^{\max}$ 之差），同时扫描荧光发射波长和激发波长，得到同步荧光光谱。若 $\Delta\lambda$ 的波数相当或大于斯托克斯位移，能获得尖而窄的同步荧光峰。荧光物质浓度 $c$ 与同步荧光峰峰高呈线性关系，故可用于定量分析。同步荧光光谱的信号 $F_\mathrm{sp}(\lambda_\mathrm{em},\lambda_\mathrm{ex})$ 与激发光信号 $F_\mathrm{ex}$ 及荧光光谱信号 $F_\mathrm{em}$ 间的关系为

$$
F_\mathrm{sp}(\lambda_\mathrm{em},\lambda_\mathrm{ex})=Kc F_\mathrm{ex} F_\mathrm{em}\qquad (5\text{-}14)
$$

式中，$K$ 为常数。由式（5-14）可知，当物质浓度 $c$ 一定时，同步荧光信号与所用的激发波长信号及发射波长信号的乘积成正比，具有较高的灵敏度。此外，同步荧光测定法具有使光谱简单、光谱窄化、减少光谱重叠、减少散射光影响、提高选择性等优点。

:::definition{label="同步荧光分析"}
同步荧光分析（synchronous fluorometry）：选适宜 $\Delta\lambda$（通常取 $\lambda_\mathrm{ex}^{\max}$ 与 $\lambda_\mathrm{em}^{\max}$ 之差），同时扫描发射波长和激发波长。$\Delta\lambda$ 的波数相当或大于斯托克斯位移时，峰尖而窄。峰高与 $c$ 线性。$F_\mathrm{sp}=Kc F_\mathrm{ex} F_\mathrm{em}$。
:::

:::keypoint{label="同步荧光的优点"}
光谱简单、光谱窄化、减少光谱重叠、减少散射光影响、提高选择性；浓度一定时信号与 $F_\mathrm{ex}F_\mathrm{em}$ 成正比，灵敏度较高。
:::

### （四）胶束增敏荧光分析

化学方法也可用来提高荧光效率，从而提高荧光分析的灵敏度。从 20 世纪 40 年代起人们就观察到胶束溶液对荧光物质有增溶、增敏和增稳作用。20 世纪 70 年代后发展成胶束增敏荧光法（micellar-enhanced fluorometry）。

胶束溶液即一定浓度的表面活性剂溶液。表面活性剂（如十二烷基硫酸钠）的化学结构都具有一个极性的亲水基和一个非极性的疏水基。在极性溶剂（如水）中，几十个表面活性剂分子聚合成团，将非极性的疏水基尾部靠在一起，形成亲水基向外、疏水基向内的胶束。溶液中胶束数量开始明显增加时的浓度称为临界胶束浓度。低于临界胶束浓度时，溶液中的表面活性剂分子基本上以非缔合形式存在。超过临界胶束浓度后，再增加表面活性剂的量，非缔合分子浓度增加很慢，而胶束数量的增加和表面活性剂浓度的增长基本上成正比。

:::definition{label="胶束与临界胶束浓度"}
胶束溶液是一定浓度的表面活性剂溶液。在水中，几十个分子聚成亲水基向外、疏水基向内的胶束。胶束数量开始明显增加时的浓度为临界胶束浓度。低于它基本以非缔合分子存在；超过后胶束数量与表面活性剂浓度基本上成正比。
:::

极性较小而难溶于水的荧光物质在胶束溶液中溶解度显著增加。例如，室温时芘在水中溶解度为 $(5.2\sim 8.5)\times 10^{-7}\,\mathrm{mol}\cdot\mathrm{L}^{-1}$，而在十二烷基硫酸钠的胶束水溶液中溶解度为 $0.043\,\mathrm{mol}\cdot\mathrm{L}^{-1}$。胶束溶液对荧光物质的增溶作用是因为非极性的有机物与胶束的非极性尾部有亲和作用，使荧光分子定位于胶束的亲脂性内核中，这也对荧光分子起了一定的保护作用，减弱了荧光质点之间的碰撞，减小了分子的无辐射跃迁，增加了荧光效率，从而增加了荧光强度。这就是胶束溶液对荧光的增敏作用。

除此之外，胶束溶液提供了一种激发单重态的保护性环境。荧光物质被分散和定域于胶束中，得到了有效的屏蔽，降低了溶剂中可能存在的荧光熄灭剂的熄灭作用，也降低了荧光物质因自身浓度太大造成的荧光自熄灭，从而使荧光寿命延长。这是胶束溶液对荧光的增稳作用。由于胶束溶液对荧光物质有增溶、增稳和增敏作用，可大大提高荧光分析法的灵敏度和稳定性。

:::definition{label="胶束增敏荧光分析"}
胶束增敏荧光法（micellar-enhanced fluorometry）：利用胶束对荧光物质的增溶、增敏和增稳。芘在水中 $(5.2\sim 8.5)\times 10^{-7}\,\mathrm{mol}\cdot\mathrm{L}^{-1}$，在十二烷基硫酸钠胶束水中 $0.043\,\mathrm{mol}\cdot\mathrm{L}^{-1}$。
:::

:::cause-effect{title="胶束三件事"}
- **增溶** 非极性有机物进入亲脂内核，溶解度显著增加
- **增敏** 定位于内核，碰撞减弱，无辐射减小，$\varphi_\mathrm{f}$ 增加，荧光增强
- **增稳** 屏蔽熄灭剂、减轻自熄灭，荧光寿命延长
:::

### （五）联用技术

荧光分析法可与其他色谱分析技术联用，如高效液相色谱、毛细管电泳等，作为这些分析方法的检测器，可提高检测灵敏度和实现痕量分析，为药物分析的发展开辟了新的途径。

:::definition{label="荧光与色谱联用"}
荧光分析法可作为高效液相色谱、毛细管电泳等的检测器，提高检测灵敏度，实现痕量分析，为药物分析开辟途径。
:::

:::compare{title="四种“其他荧光分析技术”各加哪一笔"}
| 技术 | 英文 | 加在哪 | 本版数字或后果 |
|------|------|--------|----------------|
| 激光诱导 | laser-induced fluorometry | 光源改激光 | 灵敏度提高 $2\sim 10$ 倍，可单分子 |
| 时间分辨 | time-resolved fluorometry | 激发与检测之间延缓 | 按寿命分开；可做免疫分析 |
| 同步荧光 | synchronous fluorometry | 固定 $\Delta\lambda$ 同时扫 $\lambda_\mathrm{ex}$、$\lambda_\mathrm{em}$ | 式（5-14）；峰窄、少重叠、少散射 |
| 胶束增敏 | micellar-enhanced fluorometry | 表面活性剂胶束 | 增溶、增敏、增稳；芘溶解度数量级跃升 |
:::

:::memory{label="荧光计两台单色器，侧面 90° 取光"}
问法：光电荧光计和荧光分光光度计差在哪？和紫外光度计光路差在哪？校正三件事？
答：前者高压汞灯 + 滤光片，不能测光谱；后者氙弧灯 $230\sim 720\,\mathrm{nm}$ + 两台光栅单色器 + 光电倍增管，可画激发/发射光谱。与激发光成 $90^\circ$ 测荧光。校正：灵敏度（常用硫酸奎宁）、波长（汞灯谱线）、表观光谱（单光束逐波长除检测器感应，双光束用参比）。
:::
