# 第2节　经典柱色谱法

第 1 节把经典液相写成常压、普通固定相、多半离线检出。本节把柱状操作写成柱层析，并按固定相把分离机理拆成吸附、分配、离子交换、分子排阻四本账。公式、含水量与活性级数、交联度百分数、渗透系数上下限都以本版为准。不要把高压泵和 $C_{18}$ 键合相提前写成第 14 章，也不要吞第 13 章气相的进样口和检测器。

:::definition{label="经典柱色谱法"}
又称柱层析（column chromatography）。以制备或半制备为目的的色谱分离方法。在柱状固定相（层析柱）上加入待分离样品，用流动相淋洗；组分与固定相、流动相作用力不同，通过层析柱时得到分离。
:::

:::definition{label="层析与色谱"}
采用「层析」主要是为了与现代色谱区别。层析或色谱均来自 chromatography，不是两种原理。
:::

:::definition{label="四本账由固定相决定"}
分离原理可以是吸附、分配、离子交换或分子排阻作用，主要取决于所用的固定相。
:::

:::concept{term="先问固定相是吸附剂、固定液、树脂还是凝胶"}
看见柱层析，先不要默写 $R_{\mathrm{f}}$。户头是：样品加在柱顶，流动相淋洗，组分差速迁移。固定相换成硅胶、涂了固定液的硅藻土、磺酸基树脂或 Sephadex，机理整本账都换。把四种柱听成同一种「硅胶柱」，离子交换的再生和排阻的大分子先出柱都会写反。
:::

:::pitfall{label="制备目的不是禁止分析"}
教材把经典柱色谱写成以制备或半制备为目的。流出液仍可用薄层或化学法做定性检查。不要答成「柱层析不能分析、只能装瓶」。
:::

## 一、吸附色谱法

吸附色谱法（adsorption chromatography）以固体吸附剂为固定相，利用被分离组分对固定相表面活性吸附中心吸附能力的差别实现分离。茨维特建立的色谱法即属于吸附色谱法。大部分气固色谱法（GSC）和液固色谱法（LSC）都属于吸附色谱法。GSC 的流动相是气体，专章在第 13 章；本节按液固吸附把常压柱写完。

:::definition{label="吸附色谱法"}
adsorption chromatography。固体吸附剂作固定相；组分对表面活性吸附中心的吸附能力有差别，因而分开。
:::

:::note{label="GSC 与 LSC 在本节只挂名"}
大部分 GSC、LSC 属于吸附色谱，说的是机理同类。不要把第 13 章热导、氢焰检测器写进层析柱。
:::

### （一）分离机理

吸附过程是样品中溶质分子（X）与流动相分子（Y）争夺吸附剂表面活性中心的过程。吸附平衡可以表示为

$$
\mathrm{X}_{\mathrm{m}} + n\mathrm{Y}_{\mathrm{a}} \rightleftharpoons \mathrm{X}_{\mathrm{a}} + n\mathrm{Y}_{\mathrm{m}}
$$

流动相中的溶质分子 $\mathrm{X}_{\mathrm{m}}$ 与吸附在吸附剂表面的流动相分子 $\mathrm{Y}_{\mathrm{a}}$ 相置换。溶质被吸附，以 $\mathrm{X}_{\mathrm{a}}$ 表示；流动相分子回到流动相内部，以 $\mathrm{Y}_{\mathrm{m}}$ 表示。反应的平衡常数又称为吸附系数（adsorption coefficient，$K_{\mathrm{a}}$）：

$$
K_{\mathrm{a}} = \frac{[\mathrm{X}_{\mathrm{a}}][\mathrm{Y}_{\mathrm{m}}]^{n}}{[\mathrm{X}_{\mathrm{m}}][\mathrm{Y}_{\mathrm{a}}]^{n}} \tag{12-1}
$$

由于流动相分子数量巨大，$[\mathrm{Y}_{\mathrm{m}}]^{n}/[\mathrm{Y}_{\mathrm{a}}]^{n}$ 近似于常数，且吸附只发生于吸附剂表面，故式（12-1）可简化为

$$
K_{\mathrm{a}} = \frac{[\mathrm{X}_{\mathrm{a}}]}{[\mathrm{X}_{\mathrm{m}}]} = \frac{n(X_{\mathrm{a}})/S_{\mathrm{a}}}{n(X_{\mathrm{m}})/V_{\mathrm{m}}} \tag{12-2}
$$

式中，$S_{\mathrm{a}}$ 为吸附剂的表面积，$V_{\mathrm{m}}$ 为流动相的体积，$n(X_{\mathrm{a}})$ 和 $n(X_{\mathrm{m}})$ 分别为 X 在吸附剂表面和流动相中的物质的量。吸附系数 $K_{\mathrm{a}}$ 是与组分的性质、吸附剂和流动相的性质及温度有关的常数。不同组分的 $K_{\mathrm{a}}$ 相差越大，各组分越容易实现分离。通常极性强的物质 $K_{\mathrm{a}}$ 大，易被吸附剂吸附，具有较大的保留值，后流出色谱柱。

::figure{src="/images/instrumental-analysis/textbook/p0305_01.jpg" caption="图12-1　吸附色谱法分离机理。m—流动相；a—吸附剂；$\mathrm{X}_{\mathrm{m}}$—流动相中的组分分子；$\mathrm{Y}_{\mathrm{m}}$—流动相分子；$\mathrm{X}_{\mathrm{a}}$—被吸附的组分分子；$\mathrm{Y}_{\mathrm{a}}$—被吸附的流动相分子。" alt="吸附剂表面活性中心上溶质分子与流动相分子竞争置换的示意图"}

:::definition{label="吸附系数"}
adsorption coefficient，$K_{\mathrm{a}}$。式（12-1）是完整平衡常数；因流动相分子数量巨大且吸附只发生在表面，简化为式（12-2）的表面浓度与流动相浓度之比。
:::

:::definition{label="极性与流出顺序"}
极性强的物质 $K_{\mathrm{a}}$ 大，易被吸附，保留值大，后出柱；极性弱的先出柱。
:::

:::insight{label="吸附是争夺表面，不是溶进固体内部"}
图 12-1 把吸附剂画成表面：$\mathrm{Y}_{\mathrm{a}}$ 占着活性中心，$\mathrm{X}_{\mathrm{m}}$ 把它置换下来。分配色谱的溶质要进入固定相内部（图 12-2），离子交换要换树脂上的反离子（图 12-3）。三张图不要共用一个「挂上去」的动词。
:::

:::pitfall{label="式（12-2）的分母是 Vm 不是 Vs"}
简化式用吸附剂表面积 $S_{\mathrm{a}}$ 和流动相体积 $V_{\mathrm{m}}$。不要把第 11 章分配系数里的 $V_{\mathrm{s}}$ 代进来。$n$ 是置换计量数，不是塔板数。
:::

:::cause-effect{title="Ka 大为什么后出柱"}
- 因：极性强 → 与活性中心作用强 → $K_{\mathrm{a}}$ 大 → 在表面上停留的分数高
- 果：随流动相迁移的速率慢，保留值大，后流出
:::

### （二）固定相——吸附剂

吸附色谱的固定相是具有吸附功能的吸附剂。吸附剂大多是多孔微粒状物质，具有较大的比表面积，表面的活性基团称为吸附中心。不同吸附剂的吸附能力，一是取决于吸附中心（吸附位点）的多少，二是取决于吸附中心与被吸附物形成氢键能力的大小。吸附活性中心越多，形成氢键能力越强，吸附剂的吸附能力越强。最常用的吸附剂硅胶，表面的羟基即为吸附中心。

:::definition{label="吸附中心"}
吸附剂表面的活性基团。能力由位点数目和形成氢键的能力共同决定。
:::

吸附剂分有机和无机两大类。有机类：活性炭、淀粉、蔗糖、聚酰胺、大孔吸附树脂等。无机类：硅胶、氧化铝、氧化镁、碳酸钙、硅藻土等。其中硅胶、氧化铝、聚酰胺和大孔吸附树脂较为常用。

:::compare{title="常用四种吸附剂先分户"}
| 吸附剂 | 吸附中心／特点 | 本节后面的适用对象 |
|--------|----------------|--------------------|
| 硅胶 | 硅醇基（—Si—OH） | 酸性、中性物质 |
| 氧化铝 | 活性可控制；分碱、中、酸三种 | 按 pH 选生物碱、酸性色素或苷、酯 |
| 聚酰胺 | 酰胺羰基、氨基与酚、黄酮、醌、酸形成氢键 | 酚类、黄酮类、酸类、醌类 |
| 大孔吸附树脂 | 无交换基团；吸附＋分子筛 | 水溶性化合物，如皂苷 |
:::

**（1）硅胶**　具有硅氧交联结构、表面有许多硅醇基（—Si—OH）的多孔性微粒，通常用 $\mathrm{SiO_2}\cdot x\mathrm{H_2O}$ 表示。硅醇基是吸附活性中心，能与极性化合物或不饱和化合物形成氢键而具有吸附性。多数活性羟基存在于硅胶表面较小的孔穴中，故表面孔穴较小的硅胶吸附性能较强。

硅胶表面的羟基与水结合形成水合硅醇基后，硅胶就会失去活性或吸附性。加热到 $100^{\circ}\mathrm{C}$ 左右，与羟基结合的水能被可逆地除去，硅胶又恢复吸附能力。所以硅胶的吸附能力与含水量有密切关系。如表 12-1 所示，硅胶含水量越高，活性级数越高，吸附能力越弱。当硅胶含水量达 $17\%$ 以上时，硅胶吸附能力极低。若将硅胶在 $105\sim 110^{\circ}\mathrm{C}$ 加热 $30\,\mathrm{min}$，则硅胶吸附能力增强，这个过程称为活化；若将硅胶加热至 $500^{\circ}\mathrm{C}$，由于硅胶结构内的水（结构水）不可逆地失去，硅醇基结构变成硅氧烷结构，吸附能力显著下降。

:::definition{label="硅胶"}
$\mathrm{SiO_2}\cdot x\mathrm{H_2O}$。硅醇基是吸附活性中心。微酸性，适用于分离酸性和中性物质，如有机酸、氨基酸、甾体等。
:::

:::definition{label="活化"}
将硅胶在 $105\sim 110^{\circ}\mathrm{C}$ 加热 $30\,\mathrm{min}$，可逆除去与羟基结合的水，吸附能力增强。薄层板的活化时间在第 3 节写成 $0.5\sim 1\,\mathrm{h}$，不要和柱用硅胶的 $30\,\mathrm{min}$ 并成同一个数。
:::

:::definition{label="结构水不可逆失去"}
加热至 $500^{\circ}\mathrm{C}$，结构水不可逆失去，硅醇基变成硅氧烷，吸附能力显著下降。这不是活化，是把活性中心烧掉。
:::

:::pitfall{label="活性级数高是吸附能力弱"}
表 12-1：含水量越高，活性级数（I → V）越高，吸附能力越弱。不要把「活性级数高」听成「吸附更强」。$17\%$ 以上吸附能力极低；扫描稿把表头打成「表12-1石」，以印刷表为准。
:::

:::compare{title="表12-1　硅胶和氧化铝的含水量与活性级数、吸附能力"}
| 硅胶含水量／% | 氧化铝含水量／% | 活性级数 | 吸附能力 |
|---------------|-----------------|----------|----------|
| $0$ | $0$ | I | 最强 |
| $5$ | $3$ | II |  |
| $15$ | $6$ | III |  |
| $25$ | $10$ | IV |  |
| $38$ | $15$ | V | 最弱 |
:::

**（2）氧化铝**　吸附能力较强，具有分离能力强、活性可以控制等优点。色谱用氧化铝按制备时 pH 分为碱性、中性和酸性三种。碱性氧化铝（$\mathrm{pH}\,9\sim 10$）适用于碱性（如生物碱）和中性化合物，对酸性物质则难分离；酸性氧化铝（$\mathrm{pH}\,4\sim 5$）适用于酸性化合物，如酸性色素、氨基酸及对酸稳定的中性物质；中性氧化铝（$\mathrm{pH}\,7.5$）适用于分离生物碱、挥发油、萜类、甾体及在酸、碱中不稳定的苷类、酯、内酯等化合物。酸性或碱性氧化铝能分离的化合物，中性氧化铝也能分离。氧化铝的活性也与含水量密切相关（表 12-1），水分增加使氧化铝活性降低，称为脱活性。

:::definition{label="三种氧化铝的 pH"}
碱性 $\mathrm{pH}\,9\sim 10$；酸性 $\mathrm{pH}\,4\sim 5$；中性 $\mathrm{pH}\,7.5$。中性能覆盖酸、碱能分的对象，还多管酸、碱中不稳定的苷、酯、内酯。
:::

:::definition{label="脱活性"}
增加水分使氧化铝活性降低。与硅胶「含水量高、活性级数高、吸附弱」是同一方向。
:::

:::pitfall{label="甾体、萜类不要读成留体、类"}
扫描稿常把甾体打成留体，把萜类打成「类」。碱性氧化铝难分酸性物质，不要拿它去分有机酸。
:::

**（3）聚酰胺**　由酰胺聚合而成的高分子化合物。常用的是聚己内酰胺：酰胺基中的羰基能与酚类、黄酮类、酸类化合物中的羟基形成氢键，氨基能与醌类、脂肪羧酸上的羰基形成氢键，从而产生吸附。不同化合物因活性基团的种类、数目与位置不同，与聚酰胺形成氢键的形式和能力不同，从而实现分离。

:::definition{label="聚酰胺吸附"}
羰基对酚、黄酮、酸的羟基；氨基对醌类、脂肪羧酸的羰基。靠氢键，不是靠离子交换。
:::

**（4）大孔树脂**　大孔吸附树脂不含交换基团，具有大孔网状结构，同时存在吸附和分子筛作用。在水溶液中吸附能力较强且选择性较好，在有机溶剂中吸附能力较弱。主要用于水溶性化合物的分离提纯，如皂苷等与水溶性杂质的分离，也可间接用于水溶液的浓缩，从水溶液中吸附有效成分。

:::definition{label="大孔吸附树脂"}
无交换基团；吸附＋分子筛。水中吸附强，有机溶剂中吸附弱。不要把它答成离子交换树脂。
:::

:::pitfall{label="大孔树脂不是离子交换树脂"}
离子交换树脂骨架上要引入磺酸基、季氨基等可交换基团。大孔吸附树脂明确写「不含交换基团」。皂苷纯化走这一户，不是走第 3 小节的树脂再生。
:::

### （三）色谱条件的选择

吸附色谱的洗脱过程是流动相分子与组分分子竞争占据吸附剂表面活性中心的过程。强极性的流动相分子占据吸附中心的能力强，容易将组分分子从活性中心置换，洗脱作用强；弱极性的流动相分子占据能力弱，洗脱作用弱。要使吸附能力稍有差异的各组分分离，必须同时考虑到被分离组分的结构和性质、吸附剂的活性和流动相的极性。

**（1）被分离组分的结构和性质**　不同类型的有机化合物具有不同的基团，这是判断极性的重要依据。有机化合物极性的强弱顺序为

烷烃 $<$ 烯烃（$\mathrm{C=C}$）$<$ 醚类（—O—）$<$ 硝基（—$\mathrm{NO_2}$）$<$ 二甲胺 $[-\mathrm{N}(\mathrm{CH_3})_2]$ $<$ 酯（—COO—）$<$ 酮（$\mathrm{C=O}$）$<$ 醛（—CHO）$<$ 硫醇（—SH）$<$ 胺（—$\mathrm{NH_2}$）$<$ 酰胺（—$\mathrm{NHCOCH_3}$）$<$ 醇（—OH）$<$ 酚（Ar—OH）$<$ 羧酸（—COOH）。

判断极性还有三条：① 基本母核相同，则分子中基团的极性越强，整个分子的极性也越强；② 分子中双键越多，吸附能力越强；③ 基团的空间排列对吸附性有影响。例如，对同一分子式，能形成分子内氢键的分子比不能形成分子内氢键的分子极性弱，吸附能力也弱。

:::definition{label="有机化合物极性顺序"}
烷烃最弱，羧酸最强。中间按醚、硝基、二甲胺、酯、酮、醛、硫醇、胺、酰胺、醇、酚递增。顺序以本版印刷为准，不要用别的教材插进羧酸衍生物的另一种排法。
:::

:::insight{label="分子内氢键让极性变弱"}
同一分子式，能形成分子内氢键的分子极性弱、吸附弱，先出柱或 $R_{\mathrm{f}}$ 更大。不要把「能形成氢键」一律理解成吸附更强——分子间氢键对着硅醇基才是吸附，分子内氢键是自己把羟基占用了。
:::

**（2）吸附剂的活性**　分离极性弱的物质，选用吸附能力强的吸附剂；反之，分离极性强的物质，选用吸附能力弱的吸附剂。

**（3）流动相的极性**　液固吸附色谱的流动相一般为有机溶剂，洗脱能力主要由极性决定。选择依据「相似相溶」：极性物质易溶于极性溶剂，非极性物质易溶于非极性溶剂。因此，分离极性强的物质应选用极性强的溶剂作流动相，分离极性弱的物质应选用极性弱的溶剂作流动相。常用流动相极性强弱顺序为

石油醚 $<$ 环己烷 $<$ 四氯化碳 $<$ 苯 $<$ 甲苯 $<$ 乙醚 $<$ 氯仿 $<$ 乙酸乙酯 $<$ 正丁醇 $<$ 丙酮 $<$ 乙醇 $<$ 甲醇 $<$ 水。

总之：被分离组分极性较强，选吸附性能较弱的吸附剂和极性较强的洗脱剂；组分极性较弱，选吸附性能较强的吸附剂和极性较弱的洗脱剂。实际工作中常采用多元混合流动相，以得到极性适当的流动相。

:::keypoint{label="三要素对着调"}
- 弱极性样品：强吸附剂 ＋ 弱极性洗脱剂。
- 强极性样品：弱吸附剂 ＋ 强极性洗脱剂。
- 相似相溶：溶剂极性跟着样品极性走；吸附剂极性对着样品极性反着走。
:::

:::pitfall{label="环己烷不要写成环已烷"}
扫描稿常缺一点。石油醚是最弱的常用洗脱剂，水是最强。不要把「洗脱能力强」理解成「分离一定更好」——太强则大家一起被顶下来，分不开。
:::

:::memory{label="吸附柱条件口诀"}
样品极性强，吸附剂要弱、洗脱剂要强；样品极性弱，吸附剂要强、洗脱剂要弱。含水量↑，活性级数↑，吸附↓。
:::

### （四）操作方法

**（1）色谱柱的制备**　色谱柱管为内径均匀、下端缩口的硬质玻璃管，下端用棉花或玻璃纤维塞住，管内装入吸附剂。颗粒应尽可能大小均匀。吸附剂大多采用直径 $0.07\sim 0.15\,\mathrm{mm}$ 的颗粒。柱管尺寸和吸附剂用量根据样品性质和样品量决定：一般硅胶用量为样品质量的 $30\sim 60$ 倍；若样品为难分离物质，则硅胶用量为样品质量的 $500\sim 1000$ 倍。柱要求填装均匀、不能有气泡；松紧不一致会导致移动速率不一致。装柱时先将玻璃柱垂直固定于支架上，再采用干法或湿法装柱。

**（2）加样**　将样品溶于开始洗脱时所用的洗脱剂中，沿色谱管壁缓缓加入，注意不要使吸附剂翻起；或将样品溶于适当溶剂，与少量吸附剂混匀，再使溶剂挥发去尽，呈松散状，加在已制备好的色谱柱上面。若样品在常用溶剂中不溶，可将其与适量吸附剂在乳钵中研磨混匀后加入。

**（3）洗脱**　连续加入洗脱剂，调节合适流速。洗脱剂应保持一定高度的液面，切勿断流。收集流出液，可采用薄层色谱或化学法进行定性检查，直至流出液中所含成分显著减少或不再含有时，再按洗脱剂洗脱能力大小递增变换洗脱剂的种类和比例，直至所有需要的组分被洗脱。

:::definition{label="柱用吸附剂粒度"}
大多采用直径 $0.07\sim 0.15\,\mathrm{mm}$ 的颗粒。薄层硅胶粒度是 $10\sim 40\,\mu\mathrm{m}$，不要并户。
:::

:::definition{label="硅胶用量倍数"}
一般为样品质量的 $30\sim 60$ 倍；难分离物质 $500\sim 1000$ 倍。
:::

:::pitfall{label="切勿断流，也不要翻起吸附剂"}
液面断了会进气泡、裂缝；加样冲翻柱床会把谱带搅乱。变换洗脱剂必须按洗脱能力递增，不要一上来就用甲醇把整柱冲下来。
:::

:::tip{label="流出液用薄层盯"}
常压柱一般没有在线检测器。收集流分后点薄层，看斑点是否还在、是否换带。第 3 节的 $R_{\mathrm{f}}$ 在这里是柱色谱的监视手段，不是把本节改写成平面色谱。
:::

## 二、分配色谱法

分配色谱法（partition chromatography）利用被分离组分在固定相和流动相中的溶解度差别实现分离。气液色谱（GLC）和液液色谱（LLC）大多属于分配色谱法。GLC 的仪器在第 13 章；本节只写常压液液分配的固定液、载体和分配系数。

:::definition{label="分配色谱法"}
partition chromatography。组分在固定相和流动相中溶解度不同而分开。多数 GLC、LLC 属这一类。
:::

### （一）分离机理

图 12-2 中 $\mathrm{X}_{\mathrm{m}}$ 和 $\mathrm{X}_{\mathrm{s}}$ 分别代表溶质在流动相和固定相中的分子。溶质分子在两相中的溶解呈动态平衡，在流动相和固定相中的浓度之比称为分配系数（partition coefficient，$K$）：

$$
K = \frac{c_{\mathrm{s}}}{c_{\mathrm{m}}} = \frac{[\mathrm{X}_{\mathrm{s}}]}{[\mathrm{X}_{\mathrm{m}}]} = \frac{n(\mathrm{X}_{\mathrm{s}})/V_{\mathrm{s}}}{n(\mathrm{X}_{\mathrm{m}})/V_{\mathrm{m}}} \tag{12-3}
$$

式中，$V_{\mathrm{s}}$ 为固定相的体积，$V_{\mathrm{m}}$ 为流动相的体积，$n(\mathrm{X}_{\mathrm{s}})$ 和 $n(\mathrm{X}_{\mathrm{m}})$ 分别为 X 在固定相和流动相中的物质的量。

::figure{src="/images/instrumental-analysis/textbook/p0308_01.jpg" caption="图12-2　分配色谱法分离机理。m—流动相；s—固定相；$\mathrm{X}_{\mathrm{m}}$—流动相中的组分分子；$\mathrm{X}_{\mathrm{s}}$—进入固定相内部的组分分子。" alt="溶质分子在流动相与固定液内部之间分配平衡的示意图"}

溶质分子在固定相中的溶解度越大、在流动相中的溶解度越小，分配系数越大。分配系数取决于两相的组成和性质。

分配色谱的优点在于良好的重现性：一定温度下，同一组分在整个色谱过程中的分配系数是定值。另外，不同极性的物质均能找到相应极性的溶剂进行分离，因此应用范围极其广泛。

:::definition{label="分配系数 K"}
partition coefficient。$K=c_{\mathrm{s}}/c_{\mathrm{m}}$。固定相中溶解度大则 $K$ 大。第 11 章的 $K$ 与这里同一户头；吸附系数 $K_{\mathrm{a}}$、选择性系数 $K_{\mathrm{s}}$、渗透系数 $K_{\mathrm{p}}$ 不要抢这个字母而不加下标。
:::

:::insight{label="图 12-2 的溶质进了固定相内部"}
阴影区标 s，圆点 $\mathrm{X}_{\mathrm{s}}$ 画在相内部，不是贴在表面上。和 图 12-1 的表面置换对照着看。重现性来自「一定温度下 $K$ 是定值」，不是来自高压泵。
:::

:::pitfall{label="K 大的组分后出柱，不要和排阻搞反"}
分配：$K$ 大 → 在固定相里待得久 → 后出柱。分子排阻：大分子进不了孔，$K_{\mathrm{p}}=0$，先出柱。两本账的「系数大」方向相反。
:::

### （二）固定相、载体、固定液和流动相

分配色谱的固定相由涂渍在惰性载体（担体）上的固定液构成。

**（1）载体**　化学惰性，仅起负载固定液的作用。不能溶于固定相和流动相，应有较大的表面积，机械强度好。常用载体有硅藻土、吸水硅胶、纤维素等。硅藻土因其结构中二氧化硅几乎没有吸附活性而被广泛使用。

**（2）固定液**　是样品的良好溶剂，不溶或难溶于流动相，且组分在固定液中的溶解度明显区别于在流动相中的溶解度，以保证较好的分离效果。

**（3）流动相**　一般为有机溶剂、水溶液或两者的混合物。

根据被分离组分在两相中的分配系数不同来选择固定相和流动相。可先使用对各组分溶解度大的溶剂为洗脱剂，再根据分离情况改变洗脱剂组成，调节溶解能力，改变各组分的洗脱速率，从而实现分离。

:::definition{label="载体"}
惰性担体，只负载固定液，本身不提供吸附。硅藻土最常用，因为其中二氧化硅几乎没有吸附活性。
:::

:::definition{label="固定液"}
样品的良好溶剂；不溶或难溶于流动相；使组分在两相中的溶解度有明显差别。
:::

:::pitfall{label="吸水硅胶当载体时，户头仍是分配"}
载体名单里有吸水硅胶。若硅胶表面还在当吸附中心，机理就滑向吸附。分配色谱要求载体惰性；选硅藻土就是为了把吸附活性降掉。不要看见硅胶就一律答吸附。
:::

## 三、离子交换色谱法

离子交换色谱法（ion exchange chromatography）是以离子交换作用分离离子型化合物的液相色谱法。分离对象为离子型化合物，常用于去离子水的制备、离子型生化药物的检测、微量元素的富集等。

:::definition{label="离子交换色谱法"}
ion exchange chromatography。靠离子交换作用分离离子型化合物。用途：去离子水、离子型生化药物检测、微量元素富集。
:::

### （一）分离机理

离子交换作用是指溶液中某一种离子与树脂上的一种离子互相交换：溶液中的离子被交换到树脂上，树脂上的离子被交换到溶液中，根据溶质离子对交换剂的不同亲和力而得以分离。离子交换过程是一个可逆的动态平衡过程：

$$
\mathrm{X}^{+} + \mathrm{RY}^{+} \underset{\text{再生或洗脱}}{\stackrel{\text{交换}}{\rightleftharpoons}} \mathrm{Y}^{+} + \mathrm{RX}^{+}\quad\text{（阳离子交换反应）}
$$

$$
\mathrm{X}^{-} + \mathrm{RY}^{-} \underset{\text{再生或洗脱}}{\stackrel{\text{交换}}{\rightleftharpoons}} \mathrm{Y}^{-} + \mathrm{RX}^{-}\quad\text{（阴离子交换反应）}
$$

式中，$\mathrm{X}^{+}$ 或 $\mathrm{X}^{-}$ 为样品离子，$\mathrm{Y}^{+}$ 或 $\mathrm{Y}^{-}$ 为交换作用后流动相中与样品带相同电荷的离子，$\mathrm{RY}^{+}$ 或 $\mathrm{RY}^{-}$ 为离子交换剂（可吸附相反电荷的离子）。

::figure{src="/images/instrumental-analysis/textbook/p0309_01.jpg" caption="图12-3　阳离子交换色谱法分离机理。m—流动相；E—离子交换剂；1—固定离子；2—可交换离子。" alt="阳离子交换剂上固定离子与可交换离子以及流动相中样品离子交换的示意图"}

交换反应达到平衡时的平衡常数称为选择性系数（selectivity coefficient，$K_{\mathrm{s}}$）或离子交换平衡常数：

$$
K_{\mathrm{s}} = \frac{[\mathrm{RX}^{+}]}{[\mathrm{X}^{+}]}\quad\text{或}\quad K_{\mathrm{s}} = \frac{[\mathrm{RX}^{-}]}{[\mathrm{X}^{-}]} \tag{12-4}
$$

选择性系数 $K_{\mathrm{s}}$ 与离子电荷及半径、流动相、离子交换树脂的性质、温度等有关。

在离子交换色谱中，可用选择性系数 $K_{\mathrm{A/B}}$ 衡量离子交换树脂对 $\mathrm{A}^{+}$、$\mathrm{B}^{+}$ 两种离子的选择交换能力：

$$
K_{\mathrm{A/B}} = \frac{K_{\mathrm{A}}}{K_{\mathrm{B}}} \tag{12-5}
$$

如果 $K_{\mathrm{A/B}}$ 较大，说明树脂对 $\mathrm{A}^{+}$ 结合得比较牢，$\mathrm{A}^{+}$、$\mathrm{B}^{+}$ 流出顺序是 $\mathrm{B}^{+}$ 在前、$\mathrm{A}^{+}$ 在后；如果 $K_{\mathrm{A/B}}$ 较小，说明树脂对 $\mathrm{B}^{+}$ 结合得比较牢，流出顺序是 $\mathrm{A}^{+}$ 在前、$\mathrm{B}^{+}$ 在后。

当被分离的离子随着流动相流经色谱柱时，便与交换树脂上能解离的离子连续地竞争交换。交换能力弱的离子移动速率快，保留时间短，先流出色谱柱；交换能力强的离子移动速率慢，保留时间长，后流出色谱柱。一般来说，离子的价数越高，水合离子半径越小，则离子与交换剂的亲和力就越大。

:::definition{label="选择性系数"}
selectivity coefficient，$K_{\mathrm{s}}$。平衡时树脂相离子浓度与溶液相离子浓度之比。$K_{\mathrm{A/B}}=K_{\mathrm{A}}/K_{\mathrm{B}}$ 比较两种离子谁被抓得更牢。
:::

:::definition{label="亲和力经验规则"}
价数越高、水合离子半径越小，与交换剂的亲和力越大，越后出柱。
:::

:::insight{label="图 12-3 的 1 是固定离子，2 是可交换离子"}
骨架上的电荷（固定离子）不走；反离子（可交换离子）才和样品离子换。不要把固定离子画成随流动相走的溶质。
:::

:::pitfall{label="K_A/B 大则 A 后出，不要写成 A 先出"}
$K_{\mathrm{A/B}}$ 大 → 树脂抓 $\mathrm{A}^{+}$ 更牢 → $\mathrm{B}^{+}$ 先出。和分配色谱「$K$ 大后出」方向一致，和排阻相反。
:::

### （二）固定相——离子交换树脂

最常用的固定相是具有网状立体结构的高分子聚合物，称为离子交换树脂。最常用的是聚苯乙烯型：以苯乙烯为单体、二乙烯苯为交联剂聚合而成球形网状结构，再在网状骨架上引入可被交换的活性基团。按活性基团分为阳离子交换树脂和阴离子交换树脂。

**阳离子交换树脂**　骨架上引入酸性基团，如磺酸基（—$\mathrm{SO_3H}$）、羧基（—COOH）、酚羟基（—OH），这些基团的 $\mathrm{H}^{+}$ 可与溶液中的阳离子交换。因解离度不同，又分为强酸性和弱酸性。常用的多为强酸性，如磺酸基阳离子交换树脂，以 $\mathrm{R-SO_3H}$ 表示，R 代表树脂骨架。弱酸性如 $\mathrm{R-COOH}$ 要在 $\mathrm{pH}>4$ 时才具有离子交换能力，应用受到一定限制。

强酸性阳离子交换树脂的交换反应为

$$
n\mathrm{R-SO_3H} + \mathrm{M}^{n+} \underset{\text{再生或洗脱}}{\stackrel{\text{交换}}{\rightleftharpoons}} (\mathrm{R-SO_3})_n\mathrm{M}^{n+} + n\mathrm{H}^{+}
$$

样品溶液加入色谱柱后，金属离子与氢离子交换，金属离子进入树脂网状结构，氢离子进入溶液。交换反应可逆：已经交换的树脂以适当浓度的酸溶液处理，反应逆向进行，树脂恢复原状，这一过程称为再生或洗脱。因此树脂可以重复使用。

**阴离子交换树脂**　骨架上引入碱性基团，如季氨基 $[-\mathrm{N}(\mathrm{CH_3})_3^{+}]$、伯氨基（—$\mathrm{NH_2}$）、仲氨基（—$\mathrm{NHCH_3}$），这些基团上的氢氧根（$\mathrm{OH}^{-}$）可与溶液中的阴离子交换。同样分为强碱性和弱碱性。常用的多为强碱性，如季氨基阴离子交换树脂，以 $\mathrm{R-N}(\mathrm{CH_3})_3^{+}\mathrm{OH}^{-}$ 表示。

强碱性阴离子交换树脂的交换反应为

$$
n\mathrm{R-N}(\mathrm{CH_3})_3^{+}\mathrm{OH}^{-} + \mathrm{Y}^{n-} \underset{\text{再生或洗脱}}{\stackrel{\text{交换}}{\rightleftharpoons}} [\mathrm{R-N}(\mathrm{CH_3})_3^{+}]_n\mathrm{Y}^{n-} + n\mathrm{OH}^{-}
$$

阴离子交换树脂的再生用一定浓度的稀 $\mathrm{NaOH}$ 溶液冲洗处理。

:::definition{label="聚苯乙烯型离子交换树脂"}
苯乙烯为单体，二乙烯苯为交联剂，球形网状骨架上再引入酸性或碱性基团。
:::

:::definition{label="强酸性阳离子交换树脂"}
$\mathrm{R-SO_3H}$。用酸再生。弱酸性 $\mathrm{R-COOH}$ 需 $\mathrm{pH}>4$ 才有交换能力。
:::

:::definition{label="强碱性阴离子交换树脂"}
$\mathrm{R-N}(\mathrm{CH_3})_3^{+}\mathrm{OH}^{-}$。用稀 $\mathrm{NaOH}$ 再生。
:::

:::compare{title="阳树脂对阴树脂"}
| | 阳离子交换树脂 | 阴离子交换树脂 |
|--|------------------|------------------|
| 骨架基团 | 酸性：—$\mathrm{SO_3H}$、—COOH、酚羟基 | 碱性：季氨基、伯氨基、仲氨基 |
| 可交换离子 | $\mathrm{H}^{+}$ | $\mathrm{OH}^{-}$ |
| 常用强型 | $\mathrm{R-SO_3H}$ | $\mathrm{R-N}(\mathrm{CH_3})_3^{+}\mathrm{OH}^{-}$ |
| 再生 | 适当浓度的酸 | 稀 $\mathrm{NaOH}$ |
| 弱型限制 | $\mathrm{R-COOH}$ 要 $\mathrm{pH}>4$ | 教材未另给弱碱的 pH 下限，不要自造 |
:::

:::pitfall{label="再生不是把样品毁掉，是把树脂还原"}
阳离子树脂用酸把 $\mathrm{M}^{n+}$ 洗下来、氢型恢复；阴离子树脂用稀碱把 $\mathrm{Y}^{n-}$ 洗下来、氢氧型恢复。不要把再生听成一次性消耗树脂。
:::

**性能指标**　用交联度和交换容量评价。

交联度（degree of cross linking）是离子交换树脂中交联剂的含量，通常用质量分数表示。树脂的孔隙大小与交联度有关：交联度越大，网状结构越紧密，网眼越小，因而选择性越好。但交联度也不宜过大，否则网眼过小，交换速率变慢，甚至交换容量下降。通常，阳离子交换树脂交联度以 $8\%$ 左右为宜，阴离子交换树脂交联度以 $4\%$ 左右为宜。

交换容量（exchange capacity）分理论交换容量和实际交换容量。理论交换容量是每克干树脂内所含酸性或碱性基团的数目。实际交换容量是实验条件下每克干树脂真正参加交换的基团数。实际交换容量一般低于理论交换容量，取决于树脂的结构和组成以及溶液的 pH。可用酸碱滴定法测定，单位以 $\mathrm{mmol}\cdot\mathrm{g}^{-1}$ 表示，一般为 $1\sim 10\,\mathrm{mmol}\cdot\mathrm{g}^{-1}$。

:::definition{label="交联度"}
degree of cross linking。交联剂的质量分数。阳离子树脂约 $8\%$，阴离子树脂约 $4\%$。过大则网眼太小，速率慢、容量下降。
:::

:::definition{label="交换容量"}
exchange capacity。理论值是每克干树脂的酸、碱基团数；实际值是真正参加交换的基团数，一般更低。酸碱滴定测定，$1\sim 10\,\mathrm{mmol}\cdot\mathrm{g}^{-1}$。
:::

:::pitfall{label="8% 和 4% 不要对调"}
阳树脂交联度约 $8\%$，阴树脂约 $4\%$。不要写成「越大越好」——教材明确不宜过大。单位是 $\mathrm{mmol}\cdot\mathrm{g}^{-1}$，扫描稿常丢负指数。
:::

### （三）流动相

离子交换色谱法的流动相大多为水溶液，通过调节 pH 和离子强度就可调整溶质组分的保留值，通常使用含有一定离子浓度的缓冲溶液。如果在流动相中添加有机溶剂，可使峰的拖尾现象得到改善，并调节保留值。

:::keypoint{label="水相缓冲液调 pH 和离子强度"}
对象是离子。pH 决定弱酸、弱碱是否带电；离子强度决定竞争交换的强弱。有机溶剂是改善拖尾的添加剂，不是把本节改写成正相吸附。
:::

## 四、分子排阻色谱法

分子排阻色谱法（molecular exclusion chromatography），又称体积排阻色谱法（size exclusion chromatography）、空间排阻色谱法（steric exclusion chromatography）、凝胶色谱法（gel chromatography），以多孔凝胶为固定相，根据凝胶孔隙的孔径大小与高分子样品分子的线团尺寸间的相对关系而对溶质进行分离。主要用于大分子物质（如蛋白质、多糖等）的分离分析。

:::definition{label="分子排阻色谱法"}
又称体积排阻、空间排阻、凝胶色谱。固定相是多孔凝胶；按分子尺寸与孔径的相对关系分离。对象：蛋白质、多糖等大分子。
:::

### （一）分离机理

所用固定相为化学惰性的多孔材料，与溶质之间不存在相互作用。凝胶表面有大量不同尺寸的孔隙。较小的分子能够更多地占据凝胶表面的孔隙，在柱中滞留时间较长；较大分子不能进入孔隙，通过色谱柱所需时间较短。这样可按分子大小顺序分离样品组分。

::figure{src="/images/instrumental-analysis/textbook/p0311_01.jpg" caption="图12-4　分子排阻色谱法分离机理。m—流动相；Ge—凝胶。" alt="大分子走凝胶颗粒间隙先流出、小分子进入孔隙后流出的示意图"}

分子排斥理论是分离机理的一种解释。该理论假设孔内外同等大小的溶质分子处于扩散平衡。达到平衡时，两者的浓度之比为渗透系数（permeation coefficient，$K_{\mathrm{p}}$）：

$$
K_{\mathrm{p}} = \frac{c_{\mathrm{s}}}{c_{\mathrm{m}}} = \frac{V_{\mathrm{R}}-V_{0}}{V_{\mathrm{i}}} \tag{12-6}
$$

式中，$V_{\mathrm{R}}$ 为组分的淋洗体积，$V_{\mathrm{i}}$ 为固定相的孔内总体积，$V_{0}$ 为死体积（即固定相颗粒间的体积）。

当 $V_{\mathrm{R}}=V_{0}$ 时，$K_{\mathrm{p}}=0$，即组分被完全排除；当 $V_{\mathrm{R}}-V_{0}=V_{\mathrm{i}}$ 时，$K_{\mathrm{p}}=1$，即组分完全渗透到固定相中。注意这里 $K_{\mathrm{p}}$ 与前面三种类型色谱不同：$K_{\mathrm{p}}$ 为溶质淋洗体积占固定相体积的比例，其数值一般总是小于 $1$。这种分离主要取决于凝胶的孔径大小与被分离组分分子尺寸之间的关系，与流动相的性质没有直接关系。

:::definition{label="渗透系数"}
permeation coefficient，$K_{\mathrm{p}}=(V_{\mathrm{R}}-V_{0})/V_{\mathrm{i}}$。完全排除 $K_{\mathrm{p}}=0$；完全渗透 $K_{\mathrm{p}}=1$。一般总是小于 $1$。
:::

:::definition{label="死体积 V0"}
本节 $V_{0}$ 是固定相颗粒间的体积。大分子完全排阻时 $V_{\mathrm{R}}=V_{0}$，最先出柱。
:::

:::insight{label="大分子先出，小分子后出"}
图 12-4：大球走颗粒间隙，路程短；小球钻进孔隙，路程长。和吸附、分配、离子交换「作用强的后出」同一句「后出」，原因完全不同——这里固定相与溶质不存在相互作用。
:::

:::pitfall{label="Kp 不要拿去和分配系数比大小"}
教材写明：$K_{\mathrm{p}}$ 与前面三种类型色谱不同，数值一般总是小于 $1$。不要问「蛋白质的 $K$ 是不是 440」。分离与流动相性质没有直接关系——不要靠改甲醇比例来调排阻顺序。
:::

:::compare{title="四种柱色谱的系数和流出顺序"}
| 类型 | 系数 | 系数大意味着 | 先出柱的是 |
|------|------|--------------|------------|
| 吸附 | $K_{\mathrm{a}}$ | 表面吸附强 | 极性弱、$K_{\mathrm{a}}$ 小 |
| 分配 | $K$ | 固定相中溶解度大 | $K$ 小 |
| 离子交换 | $K_{\mathrm{s}}$、$K_{\mathrm{A/B}}$ | 树脂结合牢 | 亲和力弱 |
| 分子排阻 | $K_{\mathrm{p}}$（$0\sim 1$） | 能进孔 | 大分子（$K_{\mathrm{p}}=0$） |
:::

### （二）固定相——凝胶

商品凝胶是干燥的颗粒状物质，只有吸收了大量的溶剂溶胀后才能成为凝胶。按吸收量分为软胶、半软胶、硬胶等。常用的有交联葡聚糖凝胶、聚丙烯酰胺凝胶、琼脂糖凝胶、聚苯乙烯凝胶等。

**（1）交联葡聚糖凝胶**　由葡萄糖和交联剂甘油通过醚键相互交联而成的多孔状物质，外形呈球形，商品名为 Sephadex。不同规格型号用字母 G 表示，G 后面的数字为凝胶溶胀时吸水量的 10 倍。例如，G-25 为每克凝胶溶胀时吸水 $2.5\,\mathrm{g}$。Sephadex LH-20 是 Sephadex G-25 的羟丙基衍生物，能溶于水及亲脂溶剂，用于分离亲脂性物质，如黄酮、蒽醌、色素等。

**（2）聚丙烯酰胺凝胶**　以丙烯酰胺为单体，由甲叉双丙烯酰胺交联而成。经干燥粉碎或加工成形制成粒状，控制交联剂用量可制成各种型号。交联剂越多，孔隙越小。商品名为生物胶-P（Bio-Gel P），型号从 P-2 到 P-300，P 后面的数字再乘以 $1000$ 就相当于凝胶的排阻限度。

**（3）琼脂糖凝胶**　琼脂糖（agarose，AG）是乳糖的聚集体，依靠糖链间的次级链如氢键维持网状结构，疏密依靠琼脂糖的浓度。在 $\mathrm{pH}\,4\sim 9$ 的盐溶液中结构稳定，但在 $40^{\circ}\mathrm{C}$ 以上开始熔化，可用化学灭菌法处理。适于用 Sephadex 不能分级分离的大分子的凝胶过滤。若使用 $5\%$ 以下浓度的凝胶，也能够分级分离细胞颗粒、病毒等。商品名常见的有 Sepharose（瑞典，Pharmacia）、Bio-Gel A（美国，Bio-Rad）等。

**（4）聚苯乙烯凝胶**　由苯乙烯和二乙烯苯聚合而成，有大网孔结构，商品名为 Styrogel。可用于分离相对分子质量 $1600\sim 40\,000\,000$ 的生物大分子，适用于有机多聚物相对分子质量测定和脂溶性天然产物的分级。机械强度好，洗脱剂可用甲基亚砜。

:::definition{label="Sephadex 的 G 值"}
G 后面的数字 $= 10\times$ 每克凝胶溶胀吸水量。G-25 吸水 $2.5\,\mathrm{g}$。LH-20 是 G-25 的羟丙基衍生物，亲脂。
:::

:::definition{label="Bio-Gel P 的排阻限度"}
P 后面的数字 $\times 1000$ 相当于排阻限度。交联剂越多，孔隙越小。
:::

:::definition{label="琼脂糖凝胶的温度上限"}
$\mathrm{pH}\,4\sim 9$ 的盐溶液中稳定；$40^{\circ}\mathrm{C}$ 以上开始熔化。Sephadex 分不了的大分子、细胞颗粒、病毒走这一户。
:::

:::definition{label="Styrogel"}
聚苯乙烯凝胶。相对分子质量 $1600\sim 40\,000\,000$；洗脱剂可用甲基亚砜。
:::

:::pitfall{label="G-25 不是排阻限度 25 万"}
G 值是吸水量的 10 倍，不是相对分子质量。排阻限度那一套数字在 Bio-Gel P 上：P 数乘 $1000$。蒽醌不要读成葱醒；灭菌法不要读成灭菌活；甲基亚砜不要读成甲基亚。
:::

:::memory{label="四种凝胶口诀"}
葡聚糖看 G（吸水×10）；聚丙烯酰胺看 P（×1000＝排阻限度）；琼脂糖怕热（$40^{\circ}\mathrm{C}$）；聚苯乙烯走有机、可用 DMSO。
:::

### （三）实验方法

分子排阻色谱法在药物分析中大量用于对药品的相对分子质量的测定。生物大分子聚合物如多糖、多聚核苷酸、胶原蛋白等具有分子大小不均一的特点，分子排阻色谱法是测定这类生物大分子聚合物相对分子质量及其分布的标准方法。此外，也经常用于对高分子杂质的测定。

:::definition{label="排阻在药学里的两件事"}
测相对分子质量及其分布（多糖、多聚核苷酸、胶原蛋白等）；测高分子杂质。标准方法这一句以本版为准，不要改成「只能粗测」。
:::

:::keypoint{label="第 2 节四本账收口"}
- 吸附：抢表面活性中心；$K_{\mathrm{a}}$；硅胶／氧化铝含水量与活性级数；极性三要素。
- 分配：$K=c_{\mathrm{s}}/c_{\mathrm{m}}$；固定液涂在惰性载体上；一定温度 $K$ 是定值。
- 离子交换：$K_{\mathrm{s}}$；阳 $8\%$／阴 $4\%$；酸再生阳树脂、稀碱再生阴树脂。
- 排阻：$K_{\mathrm{p}}=0\sim 1$；大分子先出；与流动相性质无直接关系。
:::
