# 生化讨论课笔记 · 课堂纪要

这次讨论课没有录音逐字稿，源是三张手写笔记。练习本五道题把高糖不运动、脂肪肝、饥饿、节食和运动供能写成一条因果链；板书把「糖如何转化为脂肪」画成总图，并收回肝的作用、血糖恒定、胰高血糖素级联和减肥措施。下文只整理笔记里出现的箭头和名词。手写看不清处标明「笔记字迹不清」，不补老师没写的 $\mathrm{ATP}$ 产量、饥饿小时数或血糖毫摩尔值。

五道题不是五张互不往来的网。高糖不运动是「糖写成脂」；脂肪肝是「脂写成了、VLDL 装不走」；饥饿和节食是「糖不够时靠动员和异生」；运动是「肌细胞按时间换燃料」。板书橙笔把总开关写成一句：糖如何转化为脂肪。

## 关键词

糖转化为脂肪 · 胰岛素与肥胖 · $\mathrm{VLDL}$ 与脂肪肝 · 必需脂肪酸 · 短期／长期饥饿 · 乙酰 $\mathrm{CoA}$ 羧化酶 · 磷酸肌酸 · 胰高血糖素–$\mathrm{cAMP}$–$\mathrm{PKA}$ · 肉碱与 $\beta$-氧化 · 左旋肉碱

## 核心议题

- 膳食大量糖分、不运动，为何走向肥胖。
- 肝是合成甘油三酯的主要场所，为何反而形成脂肪肝。
- 短期饥饿与长期饥饿各靠谁维持血糖。
- 节食如何从合成侧和动员侧两边减少体脂。
- 运动时燃料按什么顺序换。
- 板书加写：基因与基础代谢率、肝的作用（笔记标 $P268$）、谷氨酸糖异生、减肥措施。

## 一、高糖不运动：糖写成脂

练习本第 1 题：膳食消化吸收大量糖分，不运动。只有小部分葡萄糖用于细胞氧化分解、肝／肌糖原合成、磷酸戊糖途径。为降低血糖，胰岛素分泌增多，加速脂肪酸和脂肪的合成和贮存，导致肥胖。

:::definition{label="高糖不运动的去路"}
吸收进来的葡萄糖，笔记只点名三条消耗：细胞氧化分解、肝和肌糖原合成、磷酸戊糖途径。不运动时这三条吃不完，剩下的账交给胰岛素去写成脂肪酸和脂肪。
:::

:::keypoint{label="第 1 题因果链"}
- 进口：膳食消化吸收大量糖分。
- 条件：不运动。
- 用掉的只是小部分：氧化分解、肝／肌糖原、磷酸戊糖途径。
- 为降低血糖：胰岛素分泌增多。
- 后果：加速脂肪酸和脂肪的合成、贮存 → 肥胖。
:::

:::insight{label="胰岛素在这里不是「治病」，是把多余糖写成脂"}
笔记把胰岛素放在「为降低血糖」之后。降糖的手段之一，就是加速脂肪酸和脂肪的合成贮存。把胰岛素只听成「降糖激素、与肥胖无关」，第 1 题的箭头会断。
:::

:::pitfall{label="不要把「只有小部分氧化」听成糖没被吸收"}
糖已经消化吸收进体内了。问题不是吸收失败，而是去路不够、合成贮存加强。板书同一张图上还写「与基因有关。基础代谢率低」——那是另一条致肥户头，不要和「吃糖不运动」并成一句。
:::

:::definition{label="基础代谢率低"}
板书在糖→脂肪总图旁另起一行：与基因有关，基础代谢率低。笔记没有写基础代谢率的数值，不补。
:::

## 二、脂肪肝：合成得出，VLDL 装不走

练习本第 2 题：肝是合成甘油三酯的主要场所，但不能储存脂肪。需要有足够的载脂蛋白、磷脂和胆固醇等与甘油三酯结合成 $\mathrm{VLDL}$ 分泌入血。后文写必需脂肪酸缺乏，$\mathrm{VLDL}$ 合成受阻，则甘油三酯堆积在肝细胞中，形成脂肪肝。

中间一句作「而□□食的脂肪吸收很少」（笔记字迹不清）。同页后文钉死「必需脂肪酸缺乏」；板书对应句是「不吃油」。按这两处能读的字理解：脂肪摄入／吸收很少 → 必需脂肪酸不够，而不是另造一种药名或病名。

:::definition{label="肝合成甘油三酯，但不能储存脂肪"}
肝是合成甘油三酯的主要场所。笔记明确写「不能储存脂肪」。要运走，必须把甘油三酯与载脂蛋白、磷脂、胆固醇等结合成 $\mathrm{VLDL}$ 分泌入血。装不走就堆在肝细胞里，形成脂肪肝。
:::

:::compare{title="脂肪肝：生成过多还是输出过少"}
| 板书编号 | 笔记原句 | 落点 |
|----------|----------|------|
| ① 生成过多 | 肝细胞内合成甘油三酯活性强，且原料充足 | 糖多、原料多，肝会写 $\mathrm{TG}$ |
| ② 输出过少 | 磷脂不足，导致 $\mathrm{VLDL}$ 合成不足 | 写得出、装不走 |
| ③ 磷脂为何不足 | 不吃油；磷脂上第 2 位为必需脂肪酸，故磷脂合成不足 | 必需脂肪酸缺 → 磷脂缺 → $\mathrm{VLDL}$ 缺 |
:::

:::definition{label="VLDL 组装名单（笔记点名）"}
载脂蛋白、磷脂、胆固醇等，与甘油三酯结合成 $\mathrm{VLDL}$ 分泌入血。三条缺一，笔记都往「合成受阻」上收，不另写血浆密度数字。
:::

:::definition{label="磷脂第 2 位是必需脂肪酸"}
板书：不吃油，磷脂上第 2 位为必需脂肪酸，故磷脂合成不足。户头是「第 2 位这一条链必须从食物来」，不是「磷脂整分子都能由糖写成」。
:::

:::insight{label="脂肪肝不是「肝太能写脂肪」这一笔这么简单"}
第 1 题已经说明糖可以写成脂。第 2 题的刀口在输出：$\mathrm{VLDL}$ 装不走，甘油三酯才堆在肝细胞。只答「合成太强」或只答「吃得太油」，都和笔记「不吃油也会脂肪肝」对不上。
:::

:::pitfall{label="不吃油 ≠ 肝里不会有甘油三酯"}
糖可以经糖酵解、磷酸戊糖、乙酰 $\mathrm{CoA}$ 羧化酶写成脂酸，再与 3-磷酸甘油做成甘油三酯。不吃油缺的是必需脂肪酸和磷脂第 2 位，缺的不是「肝不会合成 $\mathrm{TG}$」。笔记没写载脂蛋白分子量、也没写 $\mathrm{VLDL}$ 半衰期，不补。
:::

## 三、短期饥饿与长期饥饿

练习本第 3 题分两段。短期饥饿：胰高血糖素分泌增多，促进肝糖原分解。长期饥饿：肝糖原几乎耗尽，糖皮质激素促进肌蛋白质分解（笔记在「分解」上方加写「裂解」），产生的氨基酸转移到肝脏进行糖异生；同时糖皮质激素协助胰高血糖素等脂解激素，加速脂肪动员，为糖异生提供原料。当糖异生仍不能维持血糖平衡时，组织细胞停止摄入葡萄糖，酮体成为肝外组织的主要能源物质。

:::compare{title="短期饥饿 vs 长期饥饿（按笔记分层）"}
| 项目 | 短期饥饿 | 长期饥饿 |
|------|----------|----------|
| 激素 | 胰高血糖素分泌增多 | 糖皮质激素为主；并协助胰高血糖素等脂解激素 |
| 糖原 | 促进肝糖原分解 | 肝糖原几乎耗尽 |
| 蛋白质 | 未写 | 促进肌蛋白质分解／裂解，氨基酸入肝糖异生 |
| 脂肪 | 未单列 | 加速脂肪动员，为糖异生提供原料 |
| 血糖仍不稳时 | 未写 | 组织细胞停止摄入葡萄糖；酮体成为肝外组织主要能源 |
:::

:::definition{label="脂解激素（笔记点名）"}
笔记写「胰高血糖素等脂解激素」。糖皮质激素的职分是「协助」它们加速脂肪动员，不是另开一条与胰高血糖素无关的脂肪酶。
:::

:::keypoint{label="长期饥饿三步不要并户"}
- 肝糖原几乎耗尽，才把户头交给糖异生。
- 肌蛋白质分解出的氨基酸入肝；脂肪动员为糖异生提供原料。
- 糖异生仍不能维持血糖平衡时，组织停止摄入葡萄糖，酮体成为肝外主要能源。
:::

:::insight{label="酮体是「糖异生仍不够」之后的账"}
笔记把酮体放在最后一句，前面先写肝糖原、再写糖异生和脂肪动员。不要一看见饥饿就先默写酮体，把肝糖原那一笔跳过。
:::

:::pitfall{label="笔记没写饥饿几小时，不要补"}
「短期／长期」是笔记自己的分层，没有写小时数，也没有写血糖浓度。肌蛋白质那一笔是长期饥饿才出现，不要提前到短期胰高血糖素下面。
:::

## 四、节食：合成关掉，动员打开

练习本第 4 题两条平行的账。

食物中消化吸收的葡萄糖少，糖代谢减弱，$\mathrm{NADPH}$ 和乙酰 $\mathrm{CoA}$ 生成减少，不利于脂肪酸的合成，从而减少脂肪的生成。

长期节食饥饿，脂肪动员加强，使体内储存的脂肪减少；同时肝细胞内脂酰 $\mathrm{CoA}$ 增多，抑制乙酰 $\mathrm{CoA}$ 羧化酶，也抑制脂肪酸的合成。

板书在级联图旁另写：「节食可以减肥　脂肪供能」。

:::definition{label="NADPH 和乙酰 CoA 是写脂酸的原料"}
笔记把二者并列：糖代谢减弱 → $\mathrm{NADPH}$ 和乙酰 $\mathrm{CoA}$ 生成减少 → 不利于脂肪酸合成 → 脂肪生成减少。缺一就写不成脂酸。板书总图上，$\mathrm{NADPH}+\mathrm{H}^{+}$ 出自磷酸戊糖途径，乙酰 $\mathrm{CoA}$ 出自丙酮酸。
:::

:::definition{label="乙酰 CoA 羧化酶被脂酰 CoA 抑制"}
长期节食饥饿时，肝细胞内脂酰 $\mathrm{CoA}$ 增多，抑制乙酰 $\mathrm{CoA}$ 羧化酶，也抑制脂肪酸的合成。这是合成侧的第二道闸，和「原料减少」不是同一句话。
:::

:::compare{title="节食减脂的两本账"}
| 侧 | 笔记机制 | 结果 |
|----|----------|------|
| 合成侧（原料） | 吸收的葡萄糖少 → 糖代谢弱 → $\mathrm{NADPH}$、乙酰 $\mathrm{CoA}$ 少 | 脂肪酸合成不利，脂肪生成减少 |
| 合成侧（关键酶） | 肝细胞内脂酰 $\mathrm{CoA}$ 增多，抑制乙酰 $\mathrm{CoA}$ 羧化酶 | 也抑制脂肪酸合成 |
| 动员侧 | 长期节食饥饿，脂肪动员加强 | 体内储存的脂肪减少；板书收成「脂肪供能」 |
:::

:::insight{label="同一把乙酰 CoA 羧化酶，板书上还负责「糖写成脂」"}
第 1 题胰岛素加速脂肪酸合成，走的是这条酶往前开；第 4 题脂酰 $\mathrm{CoA}$ 把它关掉。板书把乙酰 $\mathrm{CoA}$ 羧化酶画在丙酮酸 → 乙酰 $\mathrm{CoA}$ 之后，产物是丙二酸单酰 $\mathrm{CoA}$。
:::

:::pitfall{label="不要补软脂酸 ATP 口诀"}
笔记只写「生成减少」「储存的脂肪减少」，没有写净得多少 $\mathrm{ATP}$，也没有写软脂酸氧化数字。讨论课这一题的刀口是原料和羧化酶，不是生物氧化表。
:::

## 五、运动供能：先花零钱，再拆库存

练习本第 5 题：最初是 $\mathrm{ATP}$ 供能。$\mathrm{ATP}$ 用完后，磷酸肌酸把高能键转移给 $\mathrm{ADP}$ 生成 $\mathrm{ATP}$。磷酸肌酸耗尽后肌糖原分解。长时间运动则肌蛋白质分解，脂肪动员加强，其水解产物转移至肝中糖异生，生成葡萄糖释放入血供肌细胞利用；同时肝细胞合成酮体加强，肌细胞也可利用酮体。

板书第 (5) 条把顺序收成四个名词：①磷酸肌酸　②肌糖原　③脂肪酸　④分解肌蛋白。

:::definition{label="磷酸肌酸"}
$\mathrm{ATP}$ 用完后，磷酸肌酸把高能键转移给 $\mathrm{ADP}$ 生成 $\mathrm{ATP}$。它排在肌糖原前面，是笔记里的「第二袋零钱」，不是糖原本身。
:::

:::keypoint{label="运动供能顺序（练习本原文）"}
- 最初：$\mathrm{ATP}$ 供能。
- $\mathrm{ATP}$ 用完：磷酸肌酸转移高能键，$\mathrm{ADP}\to\mathrm{ATP}$。
- 磷酸肌酸耗尽：肌糖原分解。
- 长时间运动：肌蛋白质分解；脂肪动员加强。
- 脂肪水解产物入肝糖异生，葡萄糖释入血供肌细胞。
- 同时肝细胞合成酮体加强，肌细胞也可利用酮体。
:::

:::compare{title="练习本五步 vs 板书四个名词"}
| 时间轴 | 练习本 | 板书 (5) |
|--------|--------|----------|
| 最先 | $\mathrm{ATP}$ | 未单列（默认已有） |
| 其次 | 磷酸肌酸 → $\mathrm{ADP}$ 生成 $\mathrm{ATP}$ | ①磷酸肌酸 |
| 再次 | 肌糖原分解 | ②肌糖原 |
| 长时间 | 脂肪动员加强；水解产物入肝异生 | ③脂肪酸 |
| 长时间 | 肌蛋白质分解 | ④分解肌蛋白 |
:::

:::insight{label="长时间运动的糖不是肌糖原直接补血糖"}
笔记写得很清楚：脂肪水解产物转移至肝中糖异生，生成葡萄糖释放入血，供肌细胞利用。肌糖原那一笔在前面，是磷酸肌酸耗尽后就地分解；后面入血的葡萄糖是肝异生出来的。两笔不要并成「肌糖原释放血糖」。
:::

:::pitfall{label="酮体供肌是「加强」，不是唯一燃料"}
长时间运动：脂肪动员、肝糖异生、酮体合成加强、肌细胞也可利用酮体。四件事并列。笔记没有写各占供能百分之几，不补。
:::

## 六、板书总图：糖如何转化为脂肪

板书左上把葡萄糖写成 $\mathrm{Gle}$。主干：

$\mathrm{Gle}$ 糖酵解途径 → 丙酮酸 → 乙酰 $\mathrm{CoA}$ → 柠檬酸循环（笔记作「柠－丙 cycle」）。

旁路与分支：

- 丙酮酸／糖酵解中间物 → 磷酸二羟丙酮 → 3-磷酸甘油，再经甘油三酯途径 → $\mathrm{Fat}$。
- 磷酸戊糖途径 → $\mathrm{NADPH}+\mathrm{H}^{+}$。
- 乙酰 $\mathrm{CoA}$ 羧化酶 → 丙二酸单酰 $\mathrm{CoA}$。
- 有氧氧化 → $\mathrm{ATP}$。
- 左侧标脂酸合成循环四步：①缩合　②加氢　③脱水　④加氢。
- 另有「脂肪动员」箭头画在糖酵解旁，与贮存相对。

橙笔：核心——糖如何转化为脂肪。

:::definition{label="糖转化为脂肪（板书核心）"}
糖要写成脂肪，笔记摊开两条腿：乙酰 $\mathrm{CoA}$ 经羧化酶变成丙二酸单酰 $\mathrm{CoA}$，再按缩合–加氢–脱水–加氢延长碳链；甘油骨架来自磷酸二羟丙酮 → 3-磷酸甘油。磷酸戊糖途径提供 $\mathrm{NADPH}+\mathrm{H}^{+}$。两条腿和还原当量都在，甘油三酯才能指向 $\mathrm{Fat}$。
:::

:::compare{title="总图上三条途径的职分"}
| 途径 | 板书箭头 | 交给脂肪合成的东西 |
|------|----------|--------------------|
| 糖酵解 | $\mathrm{Gle}$ → 丙酮酸 → 乙酰 $\mathrm{CoA}$；并分出磷酸二羟丙酮 | 碳架（乙酰 $\mathrm{CoA}$）＋ 甘油骨架 |
| 磷酸戊糖途径 | 从糖酵解旁路画出 | $\mathrm{NADPH}+\mathrm{H}^{+}$ |
| 柠檬酸循环 | 乙酰 $\mathrm{CoA}$ →「柠－丙 cycle」 | 与有氧氧化、$\mathrm{ATP}$ 相连；不是写脂酸的碳链延长循环 |
:::

:::keypoint{label="脂酸合成循环四步（板书原词）"}
- ①缩合
- ②加氢
- ③脱水
- ④加氢

笔记只写这四个动词，没有写每步的酶名和消耗几分子 $\mathrm{NADPH}$，不补。
:::

:::insight{label="有氧氧化出 ATP，磷酸戊糖出 NADPH，不要并户"}
同一张图上既有有氧氧化 → $\mathrm{ATP}$，也有磷酸戊糖 → $\mathrm{NADPH}+\mathrm{H}^{+}$。写脂酸要的是 $\mathrm{NADPH}$；$\mathrm{ATP}$ 是另一本能量账。把磷酸戊糖听成「也是为了出 $\mathrm{ATP}$」，第 4 题「$\mathrm{NADPH}$ 减少则脂酸合成不利」会没有来源。
:::

:::pitfall{label="柠－丙 cycle 不是脂酸合成的缩合–加氢循环"}
乙酰 $\mathrm{CoA}$ 向右进柠檬酸循环，向「羧化酶」那一侧才进丙二酸单酰 $\mathrm{CoA}$。两套循环都从乙酰 $\mathrm{CoA}$ 出发，箭头一反，糖就写成 $\mathrm{CO}_2$ 而不是脂肪。
:::

## 七、肝的作用（笔记标 P268）

板书在「肝作用」旁写 $P268$，下列五条。这是讨论课抄的页码，不是现行平台教材的页码，不要改写成别的数字。

:::keypoint{label="肝作用五条（按板书）"}
- ① 肝糖原的合成与分解，及肝内糖异生，维持血糖平衡。
- ② 肝在脂质的消化、吸收、合成、运输、分解整个代谢中的作用。
- ③ 肝的 protein（笔记英文原词，未展开具体蛋白名单）。
- ④ 分解代谢　氨基酸（「分解」旁有补字，字迹不清；能读的是氨基酸分解代谢）。
- ⑤ 肝参与多种维生素和辅酶的代谢。
:::

:::definition{label="肝维持血糖平衡（板书①）"}
手段就两条半：肝糖原合成与分解，加上肝内糖异生。和第 3 题「短期肝糖原、长期糖异生」是同一本账。
:::

:::insight{label="脂质那一条要写「整个代谢」"}
板书②不是只写「肝合成甘油三酯」。消化、吸收、合成、运输、分解都在。第 2 题的 $\mathrm{VLDL}$ 运输、第 3 题的脂肪动员与酮体，都能挂在这一条下面。
:::

:::pitfall{label="P268 不要换成肝重量、血流量"}
笔记只标了页码和五条职分，没有写肝重、心输出量分数、日分泌胆汁毫升数。那些数字若出现在别的教材页，不要塞进这张讨论课板书。
:::

## 八、维持血糖恒定：糖原与糖异生

板书 (3) 标题：维持血糖恒定。

- ① 糖原的合成与分解。
- ② 糖异生（以谷氨酸为例）。旁注：主要是生糖氨基酸。另标「△非同步反应必要」。

谷氨酸路径（板书）：

谷氨酸 $\xrightarrow{\text{L-谷氨酸脱氢酶}}$ $\alpha$-酮戊二酸 → 苹果酸 $\xrightarrow{\text{出线粒体}}$ 草酰乙酸 $\xrightarrow{\text{PEP 羧激酶}}$ $\mathrm{PEP}$ → → …

果糖-1,6-二磷酸酶：果糖-1,6-二磷酸 → 果糖-6-磷酸 → 葡萄糖-6-磷酸 $\xrightarrow{\text{葡萄糖-6-磷酸酶}}$ $\mathrm{Gle}$。

:::definition{label="糖异生（以谷氨酸为例）"}
笔记不从丙酮酸写起，而从生糖氨基酸谷氨酸写起：$\mathrm{L}$-谷氨酸脱氢酶生成 $\alpha$-酮戊二酸，经苹果酸出线粒体到草酰乙酸，再由 $\mathrm{PEP}$ 羧激酶写成磷酸烯醇式丙酮酸，后续经果糖-1,6-二磷酸酶、葡萄糖-6-磷酸酶放出葡萄糖。
:::

:::compare{title="板书点名的糖异生酶"}
| 酶 | 笔记上的反应 |
|----|----------------|
| $\mathrm{L}$-谷氨酸脱氢酶 | 谷氨酸 → $\alpha$-酮戊二酸 |
| $\mathrm{PEP}$ 羧激酶 | 草酰乙酸 → $\mathrm{PEP}$ |
| 果糖-1,6-二磷酸酶 | 果糖-1,6-二磷酸 → 果糖-6-磷酸 |
| 葡萄糖-6-磷酸酶 | 葡萄糖-6-磷酸 → $\mathrm{Gle}$ |

丙酮酸羧化酶未出现在这张板书上。谷氨酸走的是 $\alpha$-酮戊二酸／苹果酸入口，不要把没写的酶补进去。
:::

:::insight{label="苹果酸出线粒体，是为了把碳架送到胞质"}
板书在苹果酸 → 草酰乙酸处标明「出线粒体」。糖异生后面几步（$\mathrm{PEP}$ 之后、两个磷酸酶）不在线粒体里做完。只默写「谷氨酸能生糖」、不写穿膜，路径会停在基质。
:::

:::pitfall{label="非同步反应：酵解和异生不要对开空转"}
板书三角标「非同步反应必要」。意思是糖原合成／分解、糖酵解／糖异生不能当成同一套酶正逆对开。笔记没有写底物循环消耗几分子 $\mathrm{ATP}$，不补；只把「必要、非同步」留下。
:::

:::keypoint{label="血糖这一节和练习本第 3 题怎么对上"}
- 糖原合成与分解：对应短期饥饿的肝糖原分解。
- 糖异生、生糖氨基酸：对应长期饥饿肌蛋白分解入肝。
- 葡萄糖-6-磷酸酶放出 $\mathrm{Gle}$：对应「生成葡萄糖释放入血」。
:::

## 九、胰高血糖素级联、脂肪动员与 β-氧化

板书 (4)：胰高血糖素结合胰受体，经 $\mathrm{G}$ 蛋白、腺苷酸环化酶（$\mathrm{AC}$）使 $\mathrm{cAMP}$ 增多，激活 $\mathrm{PKA}$。

$\mathrm{PKA}$ 指向激素敏感性脂肪酶（$\mathrm{HSL}$），开脂肪动员。

脂肪 → 甘油 $+$ 脂肪酸。

- 甘油 → 3-磷酸甘油 → 糖异生。
- 脂肪酸：①活化　②转运（入线粒体），肉碱脂酰基转移酶Ⅰ　③$\beta$ 氧化　④乙酰 $\mathrm{CoA}$ 进入三羧酸循环，生成还原当量　⑤氧化磷酸化。

$\beta$ 氧化四步（板书右侧）：脱氢、加水、再脱氢、硫解。

板书在 $\mathrm{PKA}$ 附近另画「$\mathrm{ATP}$、葡萄糖-1-磷酸 → 糖原」。胰高血糖素级联的生理方向是开糖原分解；这条箭头若按合成来读，会和受体级联打架。磷酸化酶／糖原合酶的磷酸化细节笔记未写，不补。

:::definition{label="胰高血糖素膜受体级联"}
胰高血糖素 $+$ 胰受体 → $\mathrm{G}$ 蛋白 → 腺苷酸环化酶 → $\mathrm{cAMP}$ → $\mathrm{PKA}$。这是板书从激素到酶的一条线，第 3 题「胰高血糖素分泌增多」的分子落点在这里。
:::

:::definition{label="HSL 与脂肪动员"}
$\mathrm{PKA}$ 指向 $\mathrm{HSL}$。脂肪水解成甘油和脂肪酸：甘油走 3-磷酸甘油进入糖异生；脂肪酸走活化、肉碱转入线粒体、$\beta$ 氧化。笔记在动员这一笔只写 $\mathrm{HSL}$，不补其他脂肪酶名称。
:::

:::compare{title="脂酸合成四步 vs β-氧化四步"}
| 顺序 | 合成（板书左上） | $\beta$-氧化（板书右下） |
|------|------------------|-------------------------|
| 1 | 缩合 | 脱氢 |
| 2 | 加氢 | 加水 |
| 3 | 脱水 | 再脱氢 |
| 4 | 加氢 | 硫解 |

合成在羧化酶之后延长碳链；$\beta$-氧化在肉碱转入线粒体之后把碳链切成乙酰 $\mathrm{CoA}$。动词几乎相反，舱室也不是同一间。
:::

:::keypoint{label="脂肪酸从脂滴到还原当量"}
- ①活化。
- ②转运入线粒体：肉碱脂酰基转移酶Ⅰ。
- ③$\beta$ 氧化：脱氢、加水、再脱氢、硫解。
- ④乙酰 $\mathrm{CoA}$ 进三羧酸循环，生成还原当量。
- ⑤氧化磷酸化。
:::

:::insight{label="甘油和脂肪酸分开走"}
动员产物不是一锅烩。甘油 → 3-磷酸甘油 → 糖异生，这是第 3、第 5 题「水解产物入肝异生」的化学身份；脂肪酸 → 乙酰 $\mathrm{CoA}$，可进循环或加强酮体。把甘油也听成 $\beta$-氧化，糖异生会少一条原料。
:::

:::pitfall{label="奇数碳与「脑」两处字迹不要编机制"}
板书在乙酰 $\mathrm{CoA}$ 旁写「$+$ □□个 $\mathrm{C}$ 的脂肪酸」（笔记字迹不清，可见「个 $\mathrm{C}$ 的脂肪酸」）。右侧另写「三碳的丙（酰）」。能确定的只有：除乙酰 $\mathrm{CoA}$ 外还点到三碳丙酰；不要据此补奇数碳脂酸的酶系和 $\mathrm{ATP}$ 数。

同图还写「心肌、肾、肝、脑 → 脂肪酸」（末字按可见字形录「脑」）。笔记没有写各器官氧化脂酸的比例，也不要补「脑直接氧化脂酸」或「脑只氧化酮体」的现成句子。
:::

## 十、减肥措施

板书 (6)：

- ①合理膳食。
- ②坚持长期有氧运动。
- 减肥药物：①左旋肉碱 → 加速脂肪酸的分解代谢。

这和练习本第 1、4、5 题收口：膳食决定有没有多余糖可写成脂；有氧运动把第 5 题的脂肪动员和氧化跑起来；左旋肉碱点的是第 (4) 条里已经出现的肉碱转运。

:::definition{label="左旋肉碱"}
板书把它写成减肥药物之一，作用是加速脂肪酸的分解代谢。同一张图上脂肪酸入线粒体已经点名肉碱脂酰基转移酶Ⅰ。笔记没有写剂量、也没有写「吃了肉碱不必运动」，不补。
:::

:::keypoint{label="减肥三件套（按板书，不另加药名）"}
- 合理膳食：对应第 1 题少把糖写成脂，对应第 4 题原料减少。
- 坚持长期有氧运动：对应第 5 题长时间运动才轮到脂肪酸和肌蛋白。
- 左旋肉碱：加速脂肪酸分解代谢，挂在肉碱转运那一笔上。
:::

:::insight{label="「长期」两个字不要丢掉"}
第 5 题要「长时间运动」才轮到脂肪动员；第 (6) 条要「坚持长期有氧运动」。只做短时间 $\mathrm{ATP}$／磷酸肌酸那一段，和板书减肥措施对不上。
:::

:::pitfall{label="节食可以减肥，但笔记同时写了脂肪肝那一问"}
「节食可以减肥　脂肪供能」是动员侧。第 2 题又写不吃油、必需脂肪酸缺乏会造成脂肪肝。把减肥听成「油越少越好、磷脂第 2 位无所谓」，两道题会互相打脸。合理膳食不是零脂膳食。
:::

:::memory{label="讨论课必背要点"}
- [ ] 高糖不运动：只有小部分葡萄糖走氧化、肝／肌糖原、磷酸戊糖；胰岛素增多，加速脂肪酸和脂肪合成贮存 → 肥胖。
- [ ] 另有一条致肥户头：与基因有关，基础代谢率低（无数值）。
- [ ] 糖写成脂肪：乙酰 $\mathrm{CoA}$ $+$ $\mathrm{NADPH}+\mathrm{H}^{+}$（磷酸戊糖）$+$ 磷酸二羟丙酮来的 3-磷酸甘油。
- [ ] 乙酰 $\mathrm{CoA}$ 羧化酶 → 丙二酸单酰 $\mathrm{CoA}$；脂酸合成四步：缩合、加氢、脱水、加氢。
- [ ] 肝合成甘油三酯但不能储存；需载脂蛋白、磷脂、胆固醇组装成 $\mathrm{VLDL}$ 入血。
- [ ] 不吃油 → 磷脂第 2 位必需脂肪酸缺 → 磷脂不足 → $\mathrm{VLDL}$ 不足 → 脂肪肝。生成过多、输出过少要分开答。
- [ ] 短期饥饿：胰高血糖素 ↑，肝糖原分解。
- [ ] 长期饥饿：肝糖原几乎耗尽；糖皮质激素促进肌蛋白分解，氨基酸入肝糖异生，并协助脂解激素动员脂肪；糖异生仍不够时，组织停摄葡萄糖，酮体成肝外主要能源。
- [ ] 节食：$\mathrm{NADPH}$、乙酰 $\mathrm{CoA}$ 减少，不利脂酸合成；脂酰 $\mathrm{CoA}$ 抑制乙酰 $\mathrm{CoA}$ 羧化酶；动员加强使储存脂肪减少。
- [ ] 运动顺序：$\mathrm{ATP}$ → 磷酸肌酸转移高能键 → 肌糖原 → 长时间则肌蛋白分解 $+$ 脂肪动员；水解产物入肝异生；酮体也可供肌。
- [ ] 肝作用五条（笔记 $P268$）：糖原与糖异生维持血糖；脂质消化吸收合成运输分解；protein；氨基酸分解代谢；维生素和辅酶。
- [ ] 糖异生（谷氨酸）：$\mathrm{L}$-谷氨酸脱氢酶 → $\alpha$-酮戊二酸 → 苹果酸出线粒体 → 草酰乙酸 → $\mathrm{PEP}$ 羧激酶 → … → 果糖-1,6-二磷酸酶、葡萄糖-6-磷酸酶 → $\mathrm{Gle}$。生糖氨基酸；非同步反应必要。
- [ ] 胰高血糖素：受体 → $\mathrm{G}$ 蛋白 → $\mathrm{AC}$ → $\mathrm{cAMP}$ → $\mathrm{PKA}$ → $\mathrm{HSL}$。
- [ ] 脂肪酸：活化 → 肉碱脂酰基转移酶Ⅰ入线粒体 → $\beta$-氧化（脱氢、加水、再脱氢、硫解）→ 乙酰 $\mathrm{CoA}$ 进三羧酸循环出还原当量 → 氧化磷酸化。
- [ ] 甘油走 3-磷酸甘油糖异生，不走 $\beta$-氧化。
- [ ] 减肥：合理膳食、坚持长期有氧运动；左旋肉碱加速脂肪酸分解代谢。
- [ ] 字迹不清处：练习本「而□□食的脂肪吸收很少」；板书「□□个 $\mathrm{C}$ 的脂肪酸」、器官名单末字「脑」。均不编造代谢数字。
:::
