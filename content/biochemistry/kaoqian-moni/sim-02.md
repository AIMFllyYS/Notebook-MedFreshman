## 一、蛋白质的结构与性质

### 第1题

:::callout{kind=note label="题目"}
维持蛋白质二级结构稳定性的主要作用力是（　　）

A. 肽键　　B. 氢键　　C. 二硫键　　D. 离子键　　E. 范德华力（Van der Waals）

来源：练习题.doc 残片 `secondary structure` / `Van der Waals`
:::

:::callout{kind=insight label="解析"}
**【答案】B**

二级结构（$\alpha$-螺旋、$\beta$-折叠、$\beta$-转角）靠主链肽键之间的氢键维持。肽键是一级结构的主键；二硫键、疏水作用、离子键、范德华力主要稳定三级、四级。残片里的 Van der Waals 是干扰项。
:::

:::callout{kind=note label="知识卡片：各级结构的作用力"}
| 层次 | 主键 / 主要作用力 |
|------|-------------------|
| 一级 | 肽键；二硫键位置也写入一级 |
| 二级 | 氢键 |
| 三级 | 疏水作用、氢键、离子键、范德华力；可有二硫键 |
| 四级 | 亚基间非共价键 |
:::

:::callout{kind=tip label="结论速记"}
二级结构看 **氢键**；不要把范德华力或二硫键当成二级结构的主答案。
:::

### 第2题

:::callout{kind=note label="题目"}
蛋白质等电点（isoelectric point）是指（　　）

A. 溶液 $\mathrm{pH}=7$ 时蛋白质所带净电荷为零

B. 蛋白质净电荷为零时溶液的 $\mathrm{pH}$

C. 蛋白质变性时的 $\mathrm{pH}$

D. 肽键全部解离时的 $\mathrm{pH}$

E. 只有碱性氨基酸解离时的 $\mathrm{pH}$

来源：练习题.doc 残片 `(isoelectric point of protein)`
:::

:::callout{kind=insight label="解析"}
**【答案】B**

$\mathrm{pI}$ 是净电荷为零（兼性离子）时的 $\mathrm{pH}$，不等于 7。$\mathrm{pH}<\mathrm{pI}$ 带正电，向负极泳动；$\mathrm{pH}>\mathrm{pI}$ 带负电。
:::

:::callout{kind=note label="知识卡片：等电点与电泳"}
- 氨基酸 $\mathrm{pI}=( \mathrm{p}K_{\mathrm{a1}}+\mathrm{p}K_{\mathrm{a2}})/2$（无解离侧链时）
- 等电点时溶解度最低，可等电沉淀
- 变性破坏空间结构，不改变一级结构，也不是 $\mathrm{pI}$ 的定义
:::

:::callout{kind=tip label="结论速记"}
等电点 = **净电荷为零时的 pH**，不是「等于 7」。
:::

### 第3题

:::callout{kind=note label="题目"}
核酸对紫外线的最大吸收峰在（　　）；多数蛋白质的特征吸收在（　　）。

A. 200 nm；220 nm　　B. 220 nm；240 nm　　C. 260 nm；280 nm　　D. 280 nm；260 nm　　E. 240 nm；280 nm

来源：练习题.doc 残片 `200nm / 220nm / 240mn / 280nm` 及核酸 260 nm 考点
:::

:::callout{kind=insight label="解析"}
**【答案】C**

碱基共轭双键 $\rightarrow$ 核酸 $A_{260}$；色氨酸、酪氨酸 $\rightarrow$ 蛋白质 $A_{280}$。残片把 240 nm 写成 `240mn`，属 OCR/OLE 噪声，选项本身仍是波长比较。
:::

:::callout{kind=note label="知识卡片：紫外定量"}
- $A_{260}/A_{280}$ 用于估计核酸纯度（纯 DNA 约 1.8，纯 RNA 约 2.0）
- 蛋白质定量可用 280 nm 或双缩脲、Folin-酚
:::

:::callout{kind=tip label="结论速记"}
核酸 **260 nm**，蛋白质 **280 nm**。
:::

### 第4题

:::callout{kind=note label="题目"}
下列关于 $\mathrm{DNA}$ 碱基组成的叙述中，错误的是（　　）

A. $\mathrm{A}=\mathrm{T}$　　B. $\mathrm{G}=\mathrm{C}$　　C. $\mathrm{A}+\mathrm{G}=\mathrm{T}+\mathrm{C}$　　D. $\mathrm{A}+\mathrm{T}=\mathrm{G}+\mathrm{C}$　　E. $\mathrm{C}+\mathrm{T}=\mathrm{G}+\mathrm{A}$

来源：练习题.doc 残片 `A+T=G+C`、`C+ T =G+ A`
:::

:::callout{kind=insight label="解析"}
**【答案】D**

Chargaff：$\mathrm{A}=\mathrm{T}$、$\mathrm{G}=\mathrm{C}$，故 $\mathrm{A}+\mathrm{G}=\mathrm{C}+\mathrm{T}$（残片 `C+T=G+A` 为正确式）。$\mathrm{A}+\mathrm{T}=\mathrm{G}+\mathrm{C}$ 一般不成立。
:::

:::callout{kind=note label="知识卡片：配对书写"}
双链互补还要反向平行。残片中模板 `5'-CGGTA-3'` 转录产物应为 `5'-UACCG-3'`（按模板互补且 $5'\rightarrow 3'$ 书写）。
:::

:::callout{kind=tip label="结论速记"}
看到 $\mathrm{A}+\mathrm{T}=\mathrm{G}+\mathrm{C}$ 就当错误项。
:::

### 第5题

:::callout{kind=note label="题目"}
tRNA 3' 端接受氨基酸的结构是（　　）

A. GGA-OH　　B. CCA-OH　　C. AAA-OH　　D. UUA-OH　　E. TTA-OH

来源：练习题.doc 残片 `CCA-OH`
:::

:::callout{kind=insight label="解析"}
**【答案】B**

tRNA 氨基酸臂 3' 端一律是 $-\mathrm{CCA}\text{-OH}$，氨基酸连在 3'（或 2'）羟基上。TTA-OH 是 DNA 写法，tRNA 不含 T（少数稀有碱基除外，接受端仍是 CCA）。
:::

:::callout{kind=note label="知识卡片：tRNA 结构要点"}
- 二级：三叶草（氨基酸臂、DHU 环、反密码环、T$\psi$C 环）
- 三级：倒 L
- 反密码环识别 mRNA 密码子，可有摆动配对
:::

:::callout{kind=tip label="结论速记"}
氨基酸接在 tRNA 的 **CCA-OH**。
:::

## 二、酶与酶促反应

### 第1题

:::callout{kind=note label="题目"}
米氏方程中，当反应速度为最大速度的 50% 时（　　）

A. $K_\mathrm{m}=1/2[\mathrm{S}]$　　B. $[\mathrm{S}]=K_\mathrm{m}$　　C. $[\mathrm{S}]=2K_\mathrm{m}$　　D. $[\mathrm{S}]=3K_\mathrm{m}$　　E. $K_\mathrm{m}=2[\mathrm{S}]$

来源：练习题.doc 残片 `Km=1/2[S]`、`50%`、Michaelis-Menten
:::

:::callout{kind=insight label="解析"}
**【答案】B**

$v=V_{\max}[\mathrm{S}]/(K_\mathrm{m}+[\mathrm{S}])$。令 $v=V_{\max}/2$，得 $[\mathrm{S}]=K_\mathrm{m}$。残片把公式拆碎成 `Vmax[S]/(Km+[S])`，正是米氏方程。$K_\mathrm{m}=1/2[\mathrm{S}]$ 是把定义写反。
:::

:::callout{kind=note label="知识卡片：Km 与 Lineweaver-Burk"}
- $K_\mathrm{m}$：酶与底物亲和力的近似指标，$K_\mathrm{m}$ 越小亲和力越大
- 双倒数：横轴截距 $-1/K_\mathrm{m}$，纵轴截距 $1/V_{\max}$
- 核酶（ribozyme）是有催化活性的 RNA，不是蛋白质酶，但 $K_\mathrm{m}$ 概念仍可借用
:::

:::callout{kind=tip label="结论速记"}
$v=V_{\max}/2$ 时 **$[\mathrm{S}]=K_\mathrm{m}$**。
:::

### 第2题

:::callout{kind=note label="题目"}
竞争性抑制的特点是（　　）

A. 抑制剂与酶活性中心以外的部位结合，$K_\mathrm{m}$ 不变，$V_{\max}$ 下降

B. 抑制剂与底物结构相似，竞争活性中心，$K_\mathrm{m}$ 增大，$V_{\max}$ 不变

C. 抑制剂只与 ES 结合，$K_\mathrm{m}$ 与 $V_{\max}$ 均下降

D. 增大 $[\mathrm{S}]$ 不能减弱抑制

E. 磺胺抑制的是二氢叶酸还原酶

来源：练习题.doc 残片 `E+I / EI`、`ES + I`
:::

:::callout{kind=insight label="解析"}
**【答案】B**

竞争：I 与 S 抢 E 的活性中心（残片 `E+I → EI`）。$V_{\max}$ 不变，$K_\mathrm{m}$ 表观增大。磺胺类似 PABA，抑制细菌**二氢叶酸合成酶**，不是还原酶（甲氨蝶呤才抑制还原酶）。
:::

:::callout{kind=note label="知识卡片：三种可逆抑制"}
| 类型 | 结合对象 | $K_\mathrm{m}$ | $V_{\max}$ |
|------|----------|----------------|------------|
| 竞争 | E（活性中心） | ↑ | 不变 |
| 非竞争 | E 或 ES（中心外） | 不变 | ↓ |
| 反竞争 | 只结合 ES | ↓ | ↓ |
:::

:::callout{kind=tip label="结论速记"}
竞争：$K_\mathrm{m}$↑、$V_{\max}$ 不变；磺胺对的是 **二氢叶酸合成酶**。
:::

### 第3题

:::callout{kind=note label="题目"}
心肌梗死时，血清中升高更有诊断意义的乳酸脱氢酶同工酶主要是（　　）

A. $\mathrm{M}_4$（LDH5）　　B. $\mathrm{H}_4$（LDH1）　　C. $\mathrm{H}_3\mathrm{M}$（LDH2）　　D. $\mathrm{H}_2\mathrm{M}_2$（LDH3）　　E. $\mathrm{HM}_3$（LDH4）

来源：练习题.doc 残片 `M4(LDH5)`、`H4(LDH1)`
:::

:::callout{kind=insight label="解析"}
**【答案】B**

LDH 五聚体同工酶：心富含 $\mathrm{H}_4$（LDH1），骨骼肌/肝富含 $\mathrm{M}_4$（LDH5）。心梗时 LDH1 $>$ LDH2（正常血浆常 LDH2 $>$ LDH1），且释放晚于 CK。同工酶：同反应、不同结构/理化/免疫。
:::

:::callout{kind=note label="知识卡片：同工酶临床"}
CK-MB、LDH1 辅助诊断心梗；LDH5 升高见于肝或骨骼肌损伤。
:::

:::callout{kind=tip label="结论速记"}
心梗看 **LDH1（$\mathrm{H}_4$）**，不要选 LDH5。
:::

## 三、糖、脂、氧化磷酸化

### 第1题

:::callout{kind=note label="题目"}
1 分子葡萄糖彻底有氧氧化生成 $\mathrm{CO}_2$ 和 $\mathrm{H}_2\mathrm{O}$，净得 $\mathrm{ATP}$ 分子数为（　　）

A. $2\,\mathrm{CO}_2+2\,\mathrm{H}_2\mathrm{O}+36\,\mathrm{ATP}$

B. $2\,\mathrm{CO}_2+2\,\mathrm{H}_2\mathrm{O}+38\,\mathrm{ATP}$

C. $6\,\mathrm{CO}_2+6\,\mathrm{H}_2\mathrm{O}+30$ 或 $32\,\mathrm{ATP}$

D. $2\,\mathrm{CO}_2+4\,\mathrm{H}_2\mathrm{O}+12\,\mathrm{ATP}$

E. $2\,\mathrm{CO}_2+4\,\mathrm{H}_2\mathrm{O}+2\,\mathrm{ATP}$

来源：练习题.doc 残片 `2C02+2H20+36ATP` / `38ATP`（旧账，本卷改口径）
:::

:::callout{kind=insight label="解析"}
**【答案】C**

化学计量是 6 $\mathrm{CO}_2$、6 $\mathrm{H}_2\mathrm{O}$。能量账：$\mathrm{NADH}=2.5$，$\mathrm{FADH}_2=1.5$，胞质 NADH 穿梭不同得 30 或 32。残片里的 36/38 是旧口诀，不采用。
:::

:::callout{kind=pitfall label="易错警示"}
原 .doc 选项把 36、38 都列成「正确答案候选」。阅卷与复习以教材表 7-1 为准。
:::

:::callout{kind=note label="知识卡片：穿梭决定 30 还是 32"}
- 苹果酸-天冬氨酸穿梭：胞质 NADH $\rightarrow$ 2.5 ATP
- $\alpha$-磷酸甘油穿梭：胞质 NADH $\rightarrow$ 1.5 ATP
:::

:::callout{kind=tip label="结论速记"}
葡萄糖有氧氧化：**6 CO2 + 净 30 或 32 ATP**。
:::

### 第2题

:::callout{kind=note label="题目"}
磷酸戊糖途径的主要生理意义是生成（　　）

A. $\mathrm{ATP}$　　B. $\mathrm{NADH}$　　C. $\mathrm{FADH}_2$　　D. $\mathrm{NADPH}$　　E. $\mathrm{GTP}$

来源：练习题.doc 残片 `NADPH+H+`、`NADP+`
:::

:::callout{kind=insight label="解析"}
**【答案】D**

磷酸戊糖途径几乎不产能。氧化阶段 6-磷酸葡萄糖脱氢酶、6-磷酸葡萄糖酸脱氢酶以 $\mathrm{NADP}^+$ 为辅酶，生成 $\mathrm{NADPH}$ 和核糖-5-磷酸。蚕豆病就是 G6PD 缺陷，不能提供足够 NADPH 维持红细胞谷胱甘肽还原态。
:::

:::callout{kind=note label="知识卡片：NADH vs NADPH"}
| | NADH | NADPH |
|--|------|--------|
| 主要来源 | 三羧酸循环、酵解 | 磷酸戊糖途径 |
| 去路 | 呼吸链产 ATP | 还原性合成、羟化、维持 GSH |
:::

:::callout{kind=tip label="结论速记"}
磷酸戊糖途径要的是 **NADPH + 核糖磷酸**，不是 ATP。
:::

### 第3题

:::callout{kind=note label="题目"}
空腹静脉血糖的正常参考范围最接近（　　）

A. $3.89\sim 6.11\,\mathrm{mmol/L}$　　B. $6.67\sim 7.78\,\mathrm{mmol/L}$　　C. $7.78\sim 10.00\,\mathrm{mmol/L}$　　D. $<3.89\,\mathrm{mmol/L}$　　E. $>10.00\,\mathrm{mmol/L}$

来源：练习题.doc 残片 `3.89mmol`、`6.11mmol`、`7.78mmol`、`10.00mmol`

:::callout{kind=insight label="解析"}
**【答案】A**

- 餐后 2 h 诊断切点：$11.1\,\mathrm{mmol/L}$
:::

:::callout{kind=tip label="结论速记"}
空腹血糖先记 **3.89–6.11 mmol/L**。

### 第4题

:::callout{kind=note label="题目"}
胆固醇合成的限速酶是（　　）；胆固醇可转变成（　　）。

A. HMG-CoA 合酶；胆汁酸　　B. HMG-CoA 还原酶；维生素 D、胆汁酸、类固醇激素

C. HMG-CoA 裂解酶；酮体　　D. 乙酰 CoA 羧化酶；脂酸　　E. 柠檬酸裂解酶；乙酰 CoA

来源：练习题.doc 残片 `A(HMG-CoA)`、`VitD3`、`25(OH)2D3`
:::

:::callout{kind=insight label="解析"}
**【答案】B**

胞液 HMG-CoA 还原酶是胆固醇合成限速酶（他汀靶点）。肝线粒体 HMG-CoA 合酶/裂解酶走酮体。胆固醇前体可变成维生素 D、胆汁酸、类固醇激素。残片中的 $1,25(\mathrm{OH})_2\mathrm{D}_3$ 是活性维生素 D。
:::

:::callout{kind=note label="知识卡片：HMG-CoA 两条路"}
- 胞液：HMG-CoA $\rightarrow$ 甲羟戊酸 $\rightarrow$ 胆固醇
- 肝线粒体：HMG-CoA $\rightarrow$ 酮体（乙酰乙酸、$\beta$-羟丁酸、丙酮）
:::

:::callout{kind=tip label="结论速记"}
胆固醇限速酶 **HMG-CoA 还原酶**；可变成胆汁酸、激素、Vit D。
:::

### 第6题

:::callout{kind=note label="题目"}
能直接把电子交给 $\mathrm{O}_2$ 的呼吸链组分是（　　）

A. Cyt b　　B. Cyt c1　　C. Cyt c　　D. Cyt aa3　　E. Fe-S

来源：练习题.doc 残片 `Cytaa3`、`CN-`

:::callout{kind=insight label="解析"}
**【答案】D**

## 四、氨基酸与核苷酸

### 第1题

:::callout{kind=note label="题目"}
下列不属于一碳单位的是（　　）

A. $-\mathrm{CH}_3$　　B. $-\mathrm{CH}_2-$　　C. $\mathrm{CO}_2$　　D. $-\mathrm{CH}=$　　E. $-\mathrm{CHO}$

来源：练习题.doc 残片 `CO2`、`-CH2-`、`-CH=`、`one carbon unit`
:::

:::callout{kind=insight label="解析"}
**【答案】C**

一碳单位是有机基团，载体 $\mathrm{FH}_4$。$\mathrm{CO}_2$ 不是。残片同时出现 ornithine cycle、glucogenic and ketogenic amino acid，提醒尿素循环与生糖生酮常和一碳单位捆在一起考。
:::

:::callout{kind=note label="知识卡片：一碳单位形式"}
甲基、亚甲基、次甲基、甲酰基、亚氨甲基。活性甲基供体常考 SAM。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{CO}_2$ 出局；其余带「一个碳的基团」才算。
:::

### 第2题

:::callout{kind=note label="题目"}
自毁容貌综合征（Lesch-Nyhan）是由于缺乏（　　）

A. PRPP 合成酶　　B. HGPRT　　C. 黄嘌呤氧化酶　　D. ADA　　E. APRT

来源：练习题.doc 残片 `Lesch-Nyhan`
:::

:::callout{kind=insight label="解析"}
**【答案】B**

HGPRT 催化次黄嘌呤、鸟嘌呤补救合成 IMP、GMP。缺陷 $\rightarrow$ 磷酸核糖和嘌呤降解堆积 $\rightarrow$ 高尿酸、神经症状、自残。6-MP 也竞争 HGPRT，并在体内变成 6-MP 核苷酸干扰 IMP 代谢。
:::

:::callout{kind=note label="知识卡片：抗代谢物"}
- 6-MP：干扰嘌呤补救与从头
- 5-FU：转变成 dFUMP，抑制胸苷酸合酶
- 甲氨蝶呤：抑制二氢叶酸还原酶
:::

:::callout{kind=tip label="结论速记"}
Lesch-Nyhan = **HGPRT** 缺陷。
:::

### 第3题

:::callout{kind=note label="题目"}
嘌呤核苷酸从头合成首先生成的核苷酸是（　　）

A. AMP　　B. GMP　　C. IMP　　D. XMP　　E. TMP

来源：练习题.doc 残片 `de novo synthesis of purine nucleotide`、`IMP`、`PRPP`
:::

:::callout{kind=insight label="解析"}
**【答案】C**

$\mathrm{PRPP}$ 上逐步装环 $\rightarrow$ IMP，再经腺苷酸代琥珀酸路径到 AMP，或经 XMP 到 GMP。TMP 是嘧啶脱氧核苷酸。
:::

:::callout{kind=note label="知识卡片：嘧啶对照"}
嘧啶先合成乳清酸，再与 PRPP 生成 UMP，然后 UDP/UTP/CTP；dTMP 由 dUMP 甲基化而来。
:::

:::callout{kind=tip label="结论速记"}
嘌呤从头合成先出 **IMP**。
:::

### 第1题

:::callout{kind=note label="题目"}
Meselson-Stahl 实验证明的是（　　）

A. 全保留复制　　B. 半保留复制　　C. 分散复制　　D. RNA 为遗传物质　　E. 蛋白质为遗传物质

来源：练习题.doc 残片 `Meselson`
:::

:::callout{kind=insight label="解析"}
**【答案】B**

$^{15}\mathrm{N}/^{14}\mathrm{N}$ 密度标记证明 DNA 半保留复制。这是残片里少数完整专名。
:::

:::callout{kind=note label="知识卡片：复制酶活性"}
DNA-pol I：聚合 $+3'\rightarrow 5'$ 外切（校读）$+5'\rightarrow 3'$ 外切（切引物）。紫外线最易形成 T-T 二聚体，原核 UvrABC 参与切除修复。
:::

:::callout{kind=tip label="结论速记"}
Meselson-Stahl $\rightarrow$ **半保留复制**。
:::

### 第2题

:::callout{kind=note label="题目"}
紫外线最容易引起的嘧啶二聚体是（　　）

A. C–C　　B. G–T　　C. T–T　　D. T–U　　E. A–T

来源：练习题.doc 残片 `T-T`、`UvrABC`

:::callout{kind=insight label="解析"}

:::callout{kind=tip label="结论速记"}
紫外线 $\rightarrow$ **T-T 二聚体**。

### 第3题

:::callout{kind=note label="题目"}
真核生物 $\mathrm{mRNA}$ 的 $5'$ 帽子结构是（　　）

A. $\mathrm{m}^7\mathrm{UpppNm}$　　B. $\mathrm{m}^7\mathrm{CpppNm}$　　C. $\mathrm{m}^7\mathrm{ApppNm}$　　D. $\mathrm{m}^7\mathrm{GpppN(m)}$　　E. poly A

来源：练习题.doc 残片 `m7GpppNmp`、`hnRNA`
:::

:::callout{kind=insight label="解析"}
**【答案】D**

:::callout{kind=tip label="结论速记"}
帽子只记 **$\mathrm{m}^7\mathrm{GpppN}$**。

### 第4题

:::callout{kind=note label="题目"}
蛋白质合成的起始密码子是（　　）；原核起始 tRNA 携带（　　）。

A. AUG；甲酰甲硫氨酸　　B. UGA；甲硫氨酸　　C. UAA；甲硫氨酸　　D. UAG；色氨酸　　E. AAA；赖氨酸

来源：练习题.doc 残片 `AUG`、`UGA`、`UAA`、`UAG`、`IF`、`EFTu`
:::

:::callout{kind=insight label="解析"}
**【答案】A**

AUG 编码甲硫氨酸，兼作起始密码子。原核起始是 fMet-tRNA；真核是 Met-tRNA$_\mathrm{i}$。UAA、UAG、UGA 是终止密码子，无 tRNA 对应（通常）。延长需要 EF-Tu（原核）或 eEF1，消耗 GTP。
:::

:::callout{kind=note label="知识卡片：遗传密码要点"}
方向性 $5'\rightarrow 3'$、简并性、通用性（线粒体例外）、连续性、摆动性。
:::

:::callout{kind=tip label="结论速记"}
起始 **AUG**；终止 UAA/UAG/UGA。
:::

### 第5题

:::callout{kind=note label="题目"}
cAMP 能直接激活的蛋白激酶是（　　）

A. PKA　　B. PKC　　C. PKG　　D. 受体型酪氨酸激酶　　E. JAK

来源：练习题.doc 残片 `PKA`、`cAMP`、`cGMP`、`JAK-STAT`、`TPK-Ras-MAPK`
:::

:::callout{kind=insight label="解析"}
**【答案】A**

G 蛋白偶联受体 $\rightarrow$ 腺苷酸环化酶 $\rightarrow$ cAMP $\rightarrow$ PKA。cGMP 对应 PKG；DAG/$\mathrm{Ca}^{2+}$ 对应 PKC；JAK-STAT 和 Ras-MAPK 是另一类（常与细胞因子或生长因子受体）。
:::

:::callout{kind=note label="知识卡片：第二信使"}
cAMP、cGMP、DAG、IP3、$\mathrm{Ca}^{2+}$、NO 等。残片还出现 Southern（DNA）、Western（蛋白）——印迹名称不要混。
:::

:::callout{kind=tip label="结论速记"}
cAMP $\rightarrow$ **PKA**。
:::

### 第6题

:::callout{kind=note label="题目"}
名词解释：变构效应、协同效应、分子伴侣、辅基。

来源：练习题.doc 残片 `(allosteric effect)` `(cooperative effect)` `(molecular chaperone)` `(prosthetic group)`
:::

:::callout{kind=insight label="解析"}
**【答案】**

- **变构效应**：效应剂与蛋白质（酶）活性中心以外的部位非共价结合，引起构象改变，从而改变活性或亲和力。
- **协同效应**：寡聚蛋白一个亚基结合配体后，改变其余亚基对配体的亲和力（血红蛋白氧合曲线呈 S 形即正协同）。
- **分子伴侣**：帮助新生肽链正确折叠、组装，自身不构成最终功能蛋白的组成。
- **辅基**：结合酶中与酶蛋白结合牢固、透析不能分开的辅助因子。
:::

:::callout{kind=note label="知识卡片：残片里的结构层次词"}
亚基（subunit）属四级结构；结构域（domain）属三级层次；模序（motif）是二级结构组合。
:::

:::callout{kind=tip label="结论速记"}
变构打「中心外」；协同看寡聚体；伴侣只帮忙折叠；辅基绑得紧。
:::

## 本卷必背

:::memory{label="练习题.doc 清洗后必背"}
- [ ] 二级结构靠氢键；pI 是净电荷为零的 pH
- [ ] 核酸 260 nm，蛋白质 280 nm
- [ ] v = 1/2 Vmax 时 [S] = Km；竞争抑制 Km↑、Vmax 不变
- [ ] 葡萄糖有氧氧化净 30 或 32 ATP，不要选 36/38
- [ ] PPP 产 NADPH；胆固醇限速酶 HMG-CoA 还原酶
- [ ] Lesch-Nyhan = HGPRT；嘌呤先出 IMP
- [ ] Meselson 证半保留；紫外线 T-T 二聚体；cAMP→PKA
:::

:::memory{label="米氏常数定义" mode="cloze"}
酶促反应速度达到 **最大速度一半** 时的底物浓度称为 $K_\mathrm{m}$。
:::
