# 第三节　聚糖结构蕴藏大量生物信息

本节把前两节的聚糖写成信息分子。聚糖参与细胞识别、黏附、分化、免疫识别、信号转导、微生物致病和肿瘤转移；细胞内它还跟着糖蛋白从初始合成走到亚细胞定位。没有核酸／蛋白质那样的模板，序列和糖苷键靠基因编码的糖基转移酶来写；结构多样性（理论上己糖结构可达 $10^{12}$）是携带信息的基础，也就是假定的糖密码。章末收本章小结。

聚糖参与细胞识别、细胞黏附、细胞分化、免疫识别、细胞信号转导、微生物致病过程和肿瘤转移过程等。糖生物学研究表明，特异的聚糖结构被细胞用来编码若干重要信息。在细胞内，聚糖参与并影响糖蛋白从初始合成至最后亚细胞定位的各个阶段及其功能。

:::definition{label="聚糖作为信息分子"}
特异的聚糖结构被细胞用来编码若干重要信息。聚糖参与细胞识别、细胞黏附、细胞分化、免疫识别、细胞信号转导、微生物致病过程和肿瘤转移过程等。
:::

:::keypoint{label="信息账先记两层"}
- 细胞之间、细胞与微生物、肿瘤转移：识别、黏附、分化、免疫、信号转导。
- 细胞之内：从糖蛋白初始合成到最后亚细胞定位的各个阶段及其功能，聚糖都参与并影响。
:::

:::concept{term="先问有没有模板，再问谁把基因信息写到聚糖上"}
看见“聚糖有信息”，先不要写成核酸那样的碱基序列模板。本节先写：没有类似核酸、蛋白质合成所需的模板；糖基序列和糖苷键主要取决于糖基转移酶。把聚糖听成“也是按密码子翻译出来的”，糖密码那一小节会没有需要解释的对象。
:::

## 一、聚糖组分是糖蛋白执行功能所必须

各类多糖或聚糖的合成并没有类似核酸、蛋白质合成所需模板的指导，而聚糖中的糖基序列或不同糖苷键的形成，主要取决于糖基转移酶的特异性识别糖底物和催化作用。依靠多种糖基转移酶特异性地、有序地将供体分子中糖基转运至接受体上，在不同位点以不同糖苷键的方式，形成有序的聚糖结构。

鉴于糖基转移酶由基因编码，糖基转移酶继续了基因至蛋白质信息流，将信息传递至聚糖分子。另外，聚糖（如血型物质）作为某些蛋白质组分与生物表型密切相关，体现生物信息。

:::definition{label="聚糖合成不靠模板"}
各类多糖或聚糖的合成并没有类似核酸、蛋白质合成所需模板的指导。糖基序列或不同糖苷键的形成，主要取决于糖基转移酶特异性识别糖底物并催化。
:::

:::insight{label="基因编码的是糖基转移酶，不是直接编码聚糖序列"}
多种糖基转移酶特异性地、有序地把供体中的糖基转到接受体上，在不同位点以不同糖苷键形成有序结构。酶由基因编码，于是基因 $\rightarrow$ 蛋白质这条信息流被继续到聚糖分子上。血型物质作为某些蛋白质组分与生物表型密切相关，是这条信息流的表型实例。
:::

:::compare{title="核酸／蛋白质有模板，聚糖靠酶的专一性"}
| 项目 | 核酸、蛋白质 | 聚糖 |
|------|--------------|------|
| 有无模板 | 有（复制、转录、翻译所需模板） | 没有类似的模板指导 |
| 序列怎么来 | 模板决定核苷酸／氨基酸顺序 | 糖基转移酶特异性识别底物并催化 |
| 信息从哪来 | 基因直接编码 | 基因编码糖基转移酶，酶再把信息写到聚糖上 |
| 表型例子 | — | 血型物质等聚糖与生物表型密切相关 |
:::

:::example{label="血型物质把聚糖接到表型上"}
第一节已写：$\mathrm{ABO}$ 系统中物质 $\mathrm{A}$ 和 $\mathrm{B}$ 只是在物质 $\mathrm{O}$ 的聚糖非还原端各加上 $\mathrm{GalNAc}$ 或 $\mathrm{Gal}$。本节把这一笔收成：聚糖作为某些蛋白质组分与生物表型密切相关，体现生物信息。仅一个糖基之差就是不同血型。
:::

:::pitfall{label="“所必须”指聚糖组分对糖蛋白执行功能不可缺，不是说肽链没有功能"}
标题是“聚糖组分是糖蛋白执行功能所必须”。不要写成糖蛋白的功能全部由糖来执行。肽链仍在，聚糖把信息接到识别、表型和合成－定位全过程上。
:::

:::cause-effect{title="没有模板，聚糖为什么仍能有序"}
- **因** 多种糖基转移酶能特异性、有序地把供体糖基转到接受体上，位点不同、糖苷键不同
- **果** 仍能形成有序的聚糖结构；因为这些酶由基因编码，基因至蛋白质的信息流被继续到聚糖
:::

## 二、结构多样性的聚糖富含生物信息

聚糖结构的多样性和复杂性很可能赋予其携带大量生物信息的能力。上述复合糖类分子中聚糖在细胞间通信、蛋白质折叠、蛋白质转运与定位、细胞黏附和免疫识别等方面发挥的功能，就是聚糖所携带生物信息的具体体现。目前对聚糖携带生物信息的详细方式、传递途径所知甚少。

:::definition{label="聚糖携带生物信息的具体体现"}
复合糖类中聚糖在细胞间通信、蛋白质折叠、蛋白质转运与定位、细胞黏附和免疫识别等方面发挥的功能，就是其所携带生物信息的具体体现。详细方式和传递途径目前所知甚少。
:::

:::note{label="前两节的例子在这里收成“信息”"}
折叠（钙连蛋白／钙网蛋白）、转运与定位（$6$-磷酸甘露糖）、黏附（选凝素）、免疫识别（$\mathrm{IgG}$ 的 $\mathrm{Fc}$ 聚糖）、血型、精子－卵识别，都是“携带生物信息”的实例，不是另有一套尚未出场的功能。
:::

### （一）聚糖空间结构多样性是其携带信息的基础

聚糖结构具有复杂性与多样性。复合糖类中的各种聚糖结构存在单糖种类、化学键连接方式及分支异构体的差异，形成千变万化的聚糖空间结构。尽管哺乳类动物单糖种类有限，但由于单糖连接方式、修饰方式的差异，使存在于聚糖中的单糖结构不计其数。例如，$2$ 个相同己糖的连接就有 $\alpha$ 与 $\beta\,1,2$ 连接、$1,3$ 连接、$1,4$ 连接和 $1,6$ 连接 $8$ 种方式，加之聚糖中的单糖修饰（如甲基化、硫酸化、乙酰化、磷酸化等），所以从理论上计算，组成复合糖类中聚糖的己糖结构可能达 $10^{12}$ 之多（尽管并非所有的结构都天然存在）。目前已知糖蛋白 $N$-连接型聚糖中的己糖结构已有 $2\,000$ 种。这种聚糖的结构多样性可能是其携带生物信息的基础。

:::definition{label="聚糖空间结构多样性"}
复合糖类中各种聚糖存在单糖种类、化学键连接方式及分支异构体的差异，形成千变万化的空间结构。尽管哺乳类动物单糖种类有限，连接方式与修饰方式的差异仍使聚糖中的单糖结构不计其数。
:::

:::derivation{title="两个相同己糖为什么就有 8 种连接"}
$2$ 个相同己糖：$\alpha$ 与 $\beta$ 各可做 $1,2$、$1,3$、$1,4$、$1,6$ 连接，共

$$
2\times 4=8
$$

种方式。再加上甲基化、硫酸化、乙酰化、磷酸化等修饰，教材从理论上计算，组成复合糖类中聚糖的己糖结构可能达 $10^{12}$ 之多（尽管并非所有结构都天然存在）。目前已知糖蛋白 $N$-连接型聚糖中的己糖结构已有 $2\,000$ 种。
:::

:::compare{title="多样性从哪三处来"}
| 来源 | 教材落点 |
|------|----------|
| 单糖种类 | 哺乳类单糖种类有限，但仍是变量之一 |
| 化学键连接方式 | $\alpha$／$\beta$；$1,2$、$1,3$、$1,4$、$1,6$ |
| 分支异构体及修饰 | 甲基化、硫酸化、乙酰化、磷酸化等 |

三者叠在一起，空间结构千变万化；这可能就是携带生物信息的基础。
:::

:::insight{label="信息量先来自结构花样，不是来自单糖有多少种"}
哺乳类单糖种类有限——教材把这句话写在多样性之前，就是怕把“糖的字母表”听成和核酸一样短、所以信息少。字母少，连接方式和修饰却多，$8$ 种键加上修饰就能涨到 $10^{12}$。
:::

:::pitfall{label="10^12 是理论上限，不是天然都存在"}
教材括号里写明“尽管并非所有的结构都天然存在”。目前已知 $N$-连接型聚糖中的己糖结构是 $2\,000$ 种。答题时不要把理论数目写成体内已经数出来的种类。
:::

### （二）聚糖空间结构多样性受基因编码的糖基转移酶和糖苷酶调控

聚糖空间结构的多样性提示所含信息量可能不亚于核酸。每一聚糖都有一个独特的能被单一蛋白质阅读、并与其相结合的特定空间构象，这就是现代糖生物学家假定的糖密码（sugar code）。如果真的存在糖密码的话，那么糖密码是如何产生的，其上游分子又是什么？这是糖生物学研究领域面临的挑战。

已知构成聚糖的单糖种类与单糖序列是特定的，即存在于同一糖蛋白同一糖基化位点的聚糖结构通常是相同的（但也存在不均一性），提示“糖蛋白聚糖合成规律可能由上游分子控制”。目前，从复合糖类中聚糖的生物合成过程（包括糖基供体、合成所需酶类、合成的亚细胞部位、合成的基本过程）得知，聚糖的合成受基因编码的糖基转移酶和糖苷酶调控。糖基转移酶的种类繁多，已被克隆的糖基转移酶就多达 $130$ 余种，其主要分布于内质网或高尔基体，参与聚糖的生物合成。除了受糖基转移酶和糖苷酶调控外，聚糖结构可能还受到其他因素的影响与调控。

:::definition{label="糖密码"}
糖密码（sugar code）是现代糖生物学家的假定：每一聚糖都有一个独特的、能被单一蛋白质阅读并与其相结合的特定空间构象。多样性提示所含信息量可能不亚于核酸。
:::

:::definition{label="聚糖合成的上游调控"}
同一糖蛋白同一糖基化位点的聚糖结构通常相同（但也存在不均一性），提示合成规律可能由上游分子控制。从供体、酶类、亚细胞部位和基本过程得知：合成受基因编码的糖基转移酶和糖苷酶调控。
:::

:::keypoint{label="糖密码这一小节只记三问"}
- 有没有被单一蛋白质阅读的特定构象？（假定：有，即糖密码。）
- 糖密码如何产生、上游分子是什么？（教材写明：这是面临的挑战。）
- 现在已经知道谁在调控？基因编码的糖基转移酶和糖苷酶；已被克隆的糖基转移酶 $130$ 余种，主要在内质网或高尔基体。还可能有其他因素。
:::

:::compare{title="“通常相同”和糖形并不打架"}
| 说法 | 落在哪 | 含义 |
|------|--------|------|
| 同一糖蛋白同一位点的聚糖结构通常相同 | 本节 | 单糖种类与序列是特定的，提示上游控制 |
| 同一位点也可不同（糖形、微观不均一性） | 第一节 | 不完全糖基化；酶缺乏绝对专一性 |

教材两笔都保留：规律由上游分子控制，同时承认不均一性。
:::

:::cause-effect{title="为什么说信息量可能不亚于核酸"}
- **因** 聚糖空间结构极度多样；每一聚糖可有被单一蛋白质阅读的特定构象
- **果** 所含信息量被提示可能不亚于核酸，并引出“糖密码”这一假定
:::

:::pitfall{label="糖密码是假定，不是已经写成中心法则下一条"}
教材用“假定的糖密码”，并立刻问它如何产生、上游分子是什么。不要把 $130$ 余种糖基转移酶听成“糖密码已经被破译”。调控已知走酶，密码本身仍是挑战。
:::

:::timeline{period="从基因信息写到聚糖"}
- **基因** 编码糖基转移酶和糖苷酶
- **酶所在位置** 已被克隆的糖基转移酶 130 余种，主要分布于内质网或高尔基体
- **写聚糖** 供体、酶类、亚细胞部位和基本过程共同决定单糖种类与序列
- **读聚糖** 假定存在糖密码：特定空间构象被单一蛋白质阅读并结合
- **仍开放的问题** 糖密码如何产生、上游分子是什么；除酶以外可能还有其他调控因素
:::

## 本章小结

在细胞表面和细胞间质中存在着丰富的糖蛋白和蛋白聚糖，两者均由蛋白质部分和聚糖部分所组成。糖蛋白聚糖有 $N$-连接型和 $O$-连接型之分，前者聚糖以共价键方式与糖基化位点即 $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$ 模体中的天冬酰胺的酰胺氮连接，后者与糖蛋白特定丝／苏氨酸残基侧链的羟基共价结合。$N$-连接型聚糖可分成高甘露糖型、复杂型和杂合型三型，都是由特异的糖苷酶和糖基转移酶催化加工而成。糖蛋白的聚糖参与许多生物学功能，如影响新生肽链的加工、运输和糖蛋白的生物半衰期，参与糖蛋白的分子识别和生物活性等。

蛋白聚糖由糖胺聚糖和核心蛋白质组成。体内重要的糖胺聚糖有硫酸软骨素、硫酸肝素、透明质酸等。蛋白聚糖是主要的细胞外基质成分，与胶原以特异的方式相连而赋予基质以特殊的结构。细胞表面的蛋白聚糖还参与细胞黏附、迁移、增殖和分化等功能。

复合糖类中的各种聚糖结构存在单糖种类、化学键连接方式及分支异构体的差异，形成千变万化的聚糖空间结构，其复杂程度远高于核酸或蛋白质结构，很可能赋予其具有携带大量生物信息的能力。聚糖空间结构多样性受到多种因素的调控。

:::definition{label="本章小结里的糖蛋白聚糖"}
糖蛋白聚糖分 $N$-连接型和 $O$-连接型：前者共价连到 $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$ 模体中天冬酰胺的酰胺氮，后者连到特定丝／苏氨酸侧链羟基。$N$-连接分成高甘露糖型、复杂型和杂合型，由特异的糖苷酶和糖基转移酶催化加工。
:::

:::definition{label="本章小结里的蛋白聚糖"}
蛋白聚糖由糖胺聚糖和核心蛋白质组成。体内重要的糖胺聚糖有硫酸软骨素、硫酸肝素、透明质酸等。它是主要的细胞外基质成分，与胶原以特异方式相连；细胞表面的蛋白聚糖还参与黏附、迁移、增殖和分化。
:::

:::compare{title="本章小结：糖蛋白与蛋白聚糖"}
| 项目 | 糖蛋白 | 蛋白聚糖 |
|------|--------|----------|
| 组成 | 蛋白质部分 $+$ 聚糖部分 | 糖胺聚糖 $+$ 核心蛋白质 |
| 连接 | $N$－型（$\mathrm{Asn}$ 酰胺氮）或 $O$－型（$\mathrm{Ser}/\mathrm{Thr}$ 羟基） | $\mathrm{GAG}$ 共价连于核心蛋白质 |
| $N$－聚糖三型 | 高甘露糖型、复杂型、杂合型 | — |
| 功能（小结原句） | 影响新生肽链加工、运输和生物半衰期；参与分子识别和生物活性 | 细胞外基质，与胶原相连；细胞表面参与黏附、迁移、增殖和分化 |
:::

:::insight{label="小结把全章收成三句话"}
糖蛋白的聚糖走 $N$－或 $O$－连接，$N$－型三型都由糖苷酶和糖基转移酶加工，功能落到折叠、运输、半衰期和识别。蛋白聚糖走糖胺聚糖加核心蛋白质，主要做细胞外基质，表面那一笔管黏附、迁移、增殖和分化。聚糖空间结构因单糖、键和分支异构而远比核酸或蛋白质复杂，因而可能携带大量生物信息，并受多种因素调控。
:::

- [ ] 细胞内聚糖影响糖蛋白从初始合成至亚细胞定位的各阶段及其功能。
- [ ] 聚糖合成没有核酸、蛋白质那样的模板。
- [ ] 糖基序列和糖苷键主要取决于糖基转移酶的特异性识别与催化。
- [ ] 多种糖基转移酶有序转运糖基，在不同位点以不同糖苷键形成有序结构。
- [ ] 糖基转移酶由基因编码，继续了基因至蛋白质信息流，将信息传递至聚糖。
- [ ] 血型物质等聚糖作为蛋白质组分与生物表型密切相关。
- [ ] 多样性与复杂性很可能赋予其携带大量生物信息的能力；详细方式和传递途径所知甚少。
- [ ] 信息体现在细胞间通信、蛋白质折叠、转运与定位、细胞黏附和免疫识别。
- [ ] 多样性来自单糖种类、化学键连接方式和分支异构体。
- [ ] $2$ 个相同己糖有 $\alpha$／$\beta$ 的 $1,2$、$1,3$、$1,4$、$1,6$ 共 $8$ 种连接。
- [ ] 修饰包括甲基化、硫酸化、乙酰化、磷酸化等；理论上己糖结构可达 $10^{12}$（并非都天然存在）。
- [ ] 已知 $N$-连接型聚糖中己糖结构已有 $2\,000$ 种。
- [ ] 结构多样性可能是携带生物信息的基础。
- [ ] 信息量被提示可能不亚于核酸。
- [ ] 糖密码（sugar code）：每一聚糖有能被单一蛋白质阅读并结合的特定空间构象（假定）。
- [ ] 糖密码如何产生、上游分子是什么，仍是挑战。
- [ ] 同一糖蛋白同一位点的聚糖通常相同（也有不均一性），提示上游控制。
- [ ] 合成受基因编码的糖基转移酶和糖苷酶调控。
- [ ] 已被克隆的糖基转移酶 $130$ 余种，主要在内质网或高尔基体。
- [ ] 聚糖结构还可能受其他因素影响与调控。
- [ ] 本章小结：$N$－连接走 $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$ 的酰胺氮，$O$－连接走丝／苏氨酸羟基。
- [ ] 三型 $N$－聚糖由特异糖苷酶和糖基转移酶加工；影响加工、运输、半衰期、识别和活性。
- [ ] 蛋白聚糖 $=$ 糖胺聚糖 $+$ 核心蛋白质；重要 $\mathrm{GAG}$ 有硫酸软骨素、硫酸肝素、透明质酸等。
- [ ] 蛋白聚糖是主要细胞外基质成分，与胶原相连；细胞表面的还参与黏附、迁移、增殖和分化。
- [ ] 聚糖空间结构复杂程度远高于核酸或蛋白质，很可能携带大量生物信息，并受多种因素调控。
