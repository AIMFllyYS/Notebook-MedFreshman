# 第四节　蛋白质合成的干扰和抑制

第三节把新生肽链写成折叠、水解、修饰、聚合，再按信号序列送到细胞器或细胞外。本节换到干预面：蛋白质生物合成是许多药物和毒素的靶点。原核与真核翻译既相似又有差别，差别落在临床上就是抗菌药可以杀细菌而不明显伤真核细胞。肽链合成的每一步几乎都可以被特定抗生素挡住，这些分子既是药，也是研究翻译机制的工具。白喉毒素改 $\mathrm{eEF}2$、蓖麻毒蛋白拆 $28\mathrm{S}\,\mathrm{rRNA}$、三尖杉碱解聚多聚核糖体，是本版点名的真核抑制剂。

:::concept{term="先问原核还是真核，再问卡住起始、进位、读码、成肽还是转位"}
看见“抑制蛋白质合成”，不要先背白喉。户头是：原核与真核的差别提供抗菌靶点；真核自己的延长因子和 $28\mathrm{S}\,\mathrm{rRNA}$ 提供毒素靶点。表16-6 按作用位点收口。本版没有把干扰素写成翻译抑制剂，不要用旧版或莱宁格把 $\mathrm{PKR}$／$2'$-$5'\mathrm{A}$ 补进来。
:::

电子版第四节页首仍印着图16-15「核蛋白的靶向输送」。那段属于第三节（六）（五），已写入 `ch16-3.md`。本节从抗生素开始。
:::

蛋白质生物合成是许多药物和毒素的作用靶点。这些药物或毒素通过阻断原核或真核生物蛋白质合成体系中某组分的功能，来干扰和抑制蛋白质合成过程。真核生物与原核生物的翻译过程既相似又有差别，这些差别在临床医学中有重要应用价值。如抗生素能杀灭细菌但对真核细胞无明显影响，因此原核生物蛋白质合成所必需的关键组分可作为研发抗菌药物的靶点。此外，蛋白质合成的每一步反应几乎都可被特定的抗生素所抑制，这些抗生素可被用于蛋白质合成机制的研究。某些毒素作用于基因信息传递过程，对毒素作用机制的研究，不仅有助于理解其致病机制，还可从中探索研发新药的途径。

:::definition{label="蛋白质合成是药物和毒素的靶点"}
药物或毒素阻断原核或真核蛋白质合成体系中某组分的功能，从而干扰和抑制蛋白质合成。
:::

:::definition{label="原核与真核的差别有临床价值"}
抗生素能杀灭细菌、对真核细胞无明显影响，故原核翻译的关键组分可作为抗菌药物靶点。肽链合成每一步几乎都可被特定抗生素抑制，这些抗生素也用于研究翻译机制。
:::

:::definition{label="研究毒素的两层意义"}
某些毒素作用于基因信息传递。研究其作用机制：一是理解致病机制，二是从中探索研发新药的途径。
:::

:::insight{label="“几乎每一步都有抗生素”回指第二节的循环"}
起始、进位、成肽、转位、终止，第二节刚拆完。本节按同一套步骤点名抑制剂。记药名之前先能指出卡在哪一步，表16-6 的「作用原理」列才有着落。
:::

:::pitfall{label="能杀菌不等于对真核完全无作用"}
教材的临床句子是：抗生素杀细菌、对真核细胞**无明显**影响。伊短菌素、嘌呤霉素对原核和真核都有作用；放线菌酮专一抑制真核。把整张表答成“全是抗菌药、绝不伤真核”，抗病毒药／抗肿瘤药／医学研究三户会失踪。
:::

## 一、许多抗生素通过抑制蛋白质合成发挥作用

某些抗生素（antibiotic）可抑制细胞的蛋白质合成。仅仅作用于原核细胞蛋白质合成的抗生素可作为抗菌药，抑制细菌生长和繁殖，预防和治疗感染性疾病。作用于真核细胞蛋白质合成的抗生素可以作为抗肿瘤药。

:::definition{label="抗生素按原核／真核分用途"}
抗生素（antibiotic）可抑制蛋白质合成。仅作用于原核：抗菌药，抑制细菌生长繁殖，预防和治疗感染。作用于真核：可作为抗肿瘤药。
:::

:::compare{title="同一类“抑制翻译的抗生素”，用途不在同一本账"}
| 作用范围 | 教材给的用途 | 表16-6 例子 |
|----------|--------------|-------------|
| 仅原核 | 抗菌药 | 四环素、链霉素／新霉素／巴龙霉素、氯霉素／林可霉素／红霉素、夫西地酸／微球菌素、大观霉素 |
| 真核 | 抗肿瘤或医学研究 | 放线菌酮（医学研究）；三尖杉类也走真核起始 |
| 原核和真核都抑制 | 视情况：抗病毒或抗肿瘤 | 伊短菌素（抗病毒药）；嘌呤霉素（抗肿瘤药） |

先问作用范围，再问用途，不要看见抗生素就写“抗菌”。
:::

### （一）抑制肽链合成起始的抗生素

伊短菌素（edeine）和密旋霉素（pactamycin）可引起 $\mathrm{mRNA}$ 在核糖体上错位，从而阻碍翻译起始复合物的形成，对原核生物和真核生物的蛋白质合成均有抑制作用。伊短菌素还可以影响起始氨酰 $\mathrm{tRNA}$ 的就位和 $\mathrm{IF}3$ 的功能。晚霉素（everninomicin）结合于原核 $23\mathrm{S}\,\mathrm{rRNA}$，阻止 $\mathrm{fMet}$-$\mathrm{tRNA}^{\mathrm{fMet}}$ 的转位。

:::definition{label="伊短菌素和密旋霉素阻碍起始复合物"}
伊短菌素（edeine）和密旋霉素（pactamycin）：引起 $\mathrm{mRNA}$ 在核糖体上错位，阻碍翻译起始复合物形成；对原核和真核都有抑制作用。
:::

:::definition{label="伊短菌素还动 IF3 和起始氨酰 tRNA"}
伊短菌素还可以影响起始氨酰 $\mathrm{tRNA}$ 的就位和 $\mathrm{IF}3$ 的功能。表16-6 把它的作用位点写成原核、真核核糖体的小亚基，应用为抗病毒药。
:::

:::definition{label="晚霉素挡住 fMet-tRNA 的转位"}
晚霉素（everninomicin）：结合原核 $23\mathrm{S}\,\mathrm{rRNA}$，阻止 $\mathrm{fMet}$-$\mathrm{tRNA}^{\mathrm{fMet}}$ 的转位。它出现在起始小节：挡住的是起始氨酰 $\mathrm{tRNA}$ 这一步的转位，不是延长循环里 $\mathrm{EF}$-$\mathrm{G}$ 催的那一格。
:::

:::pitfall{label="晚霉素结合的是 23S rRNA，不是 16S"}
$23\mathrm{S}\,\mathrm{rRNA}$ 在原核大亚基。潮霉素 B、新霉素结合的是 $16\mathrm{S}\,\mathrm{rRNA}$ 及 $\mathrm{rpS}12$，那是读码错误那一户。大、小亚基的 $\mathrm{rRNA}$ 不要对调。
:::

:::pitfall{label="伊短菌素不是“只杀细菌的抗菌药”"}
正文：原核和真核都抑制。表16-6 应用列是抗病毒药。写成一线抗菌药，和四环素、氯霉素并户，表对不上。
:::

### （二）抑制肽链延长的抗生素

延长循环仍是进位、成肽、转位。本版把延长抑制剂分成四组：干扰进位、引起读码错误、影响成肽、影响转位。

#### 1. 干扰进位的抗生素

四环素（tetracycline）特异性结合 $30\mathrm{S}$ 亚基的 A 位，从而抑制氨酰 $\mathrm{tRNA}$ 的进位。粉霉素（pulvomycin）可降低 $\mathrm{EF}$-$\mathrm{Tu}$ 的 $\mathrm{GTP}$ 酶活性，从而抑制 $\mathrm{EF}$-$\mathrm{Tu}$ 与氨酰 $\mathrm{tRNA}$ 结合；黄色霉素（kirromycin）可阻止 $\mathrm{EF}$-$\mathrm{Tu}$ 从核糖体释出。

:::definition{label="四环素挡住 30S 的 A 位"}
四环素（tetracycline）：特异性结合原核 $30\mathrm{S}$ 亚基的 A 位，抑制氨酰 $\mathrm{tRNA}$ 进位。表16-6：作用位点为原核核糖体小亚基，原理为抑制氨酰 $\mathrm{tRNA}$ 与小亚基结合，应用为抗菌药。
:::

:::definition{label="粉霉素和黄色霉素都拿 EF-Tu 开刀，手法不同"}
粉霉素（pulvomycin）：降低 $\mathrm{EF}$-$\mathrm{Tu}$ 的 $\mathrm{GTP}$ 酶活性，抑制 $\mathrm{EF}$-$\mathrm{Tu}$ 与氨酰 $\mathrm{tRNA}$ 结合。黄色霉素（kirromycin）：阻止 $\mathrm{EF}$-$\mathrm{Tu}$ 从核糖体释出。一个不让它带氨酰 $\mathrm{tRNA}$ 进来，一个不让它走。
:::

:::compare{title="进位这一步的三种挡法"}
| 抗生素 | 挡在哪里 |
|--------|----------|
| 四环素 | $30\mathrm{S}$ 的 A 位，氨酰 $\mathrm{tRNA}$ 进不去 |
| 粉霉素 | $\mathrm{EF}$-$\mathrm{Tu}$ 的 $\mathrm{GTPase}$ 下降，不与氨酰 $\mathrm{tRNA}$ 结合 |
| 黄色霉素 | $\mathrm{EF}$-$\mathrm{Tu}$ 不能从核糖体释出 |

进位需要：空着的 A 位 $+$ $\mathrm{EF}$-$\mathrm{Tu}$·$\mathrm{GTP}$ 送氨酰 $\mathrm{tRNA}$ $+$ 送完后 $\mathrm{EF}$-$\mathrm{Tu}$ 离开。三药各拆一环。
:::

:::pitfall{label="四环素是 A 位进位，不是肽酰转移酶"}
成肽在大亚基，氯霉素、林可霉素、红霉素、放线菌酮那一组才碰肽酰转移酶。四环素写进 $50\mathrm{S}$，表16-6 的小亚基列对不上。
:::

#### 2. 引起读码错误的抗生素

氨基糖苷类抗生素能与 $30\mathrm{S}$ 亚基结合，影响翻译的准确性。例如，链霉素（streptomycin）与 $30\mathrm{S}$ 亚基结合，在较低浓度时引起读码错误，在高浓度时是抑制蛋白质合成的起始。潮霉素 B（hygromycin B）和新霉素（neomycin）能与 $16\mathrm{S}\,\mathrm{rRNA}$ 及 $\mathrm{rpS}12$ 结合，干扰 $30\mathrm{S}$ 亚基的解码部位，引起读码错误。这些抗生素均能使延长中的肽链引入错误的氨基酸残基，从而改变细菌蛋白质合成的忠实性。

:::definition{label="氨基糖苷类结合 30S，伤准确性"}
氨基糖苷类与 $30\mathrm{S}$ 亚基结合，影响翻译准确性，使延长中的肽链引入错误氨基酸，改变细菌蛋白质合成的忠实性。
:::

:::definition{label="链霉素低浓度读错，高浓度抑起始"}
链霉素（streptomycin）结合 $30\mathrm{S}$。较低浓度：引起读码错误。高浓度：抑制蛋白质合成的起始。表16-6 把「引起读码错误；抑制起始」写在同一格，浓度不同，不是自相矛盾。
:::

:::definition{label="潮霉素 B 和新霉素干扰解码部位"}
潮霉素 B（hygromycin B）和新霉素（neomycin）：与 $16\mathrm{S}\,\mathrm{rRNA}$ 及 $\mathrm{rpS}12$ 结合，干扰 $30\mathrm{S}$ 亚基的解码部位，引起读码错误。
:::

:::definition{label="表16-6 这一行还有巴龙霉素"}
表16-6 把链霉素、新霉素、巴龙霉素写在同一行：原核核糖体小亚基；引起读码错误；抑制起始；抗菌药。正文举例是链霉素、潮霉素 B、新霉素；巴龙霉素出现在表中，答题按表列入氨基糖苷这一户。
:::

:::pitfall{label="读码错误仍在延长，高浓度链霉素才回到起始"}
低浓度链霉素：延长时把错的氨基酸引进去。高浓度：抑制起始。不要把“氨基糖苷＝只抑起始”或“氨基糖苷＝只抑成肽”。忠实性被改掉，产物可以还在延长，只是序列错了。
:::

:::pitfall{label="rpS12 是小亚基蛋白质，不要写成 50S"}
潮霉素 B／新霉素点名 $16\mathrm{S}\,\mathrm{rRNA}$ 及 $\mathrm{rpS}12$，解码部位在 $30\mathrm{S}$。写成大亚基，和氯霉素并户。
:::

#### 3. 影响成肽的抗生素

氯霉素（chloramphenicol）可结合核糖体 $50\mathrm{S}$ 亚基，通过阻止肽酰转移而抑制肽键形成。林可霉素（lincomycin）作用于 A 位和 P 位，阻止 $\mathrm{tRNA}$ 在这两个位置就位而抑制肽键形成。大环内酯类抗生素如红霉素（erythromycin）能抑制核糖体 $50\mathrm{S}$ 亚基组装与形成、抑制肽酰转移酶、封阻肽链排除通道等而阻止成肽。嘌呤霉素（puromycin）的结构与酪氨酰 $\mathrm{tRNA}$ 相似，在翻译中可取代酪氨酰 $\mathrm{tRNA}$ 而进入核糖体 A 位，中断肽链合成。放线菌酮（cycloheximide）特异性抑制真核生物核糖体肽酰转移酶的活性。

:::definition{label="氯霉素阻止肽酰转移"}
氯霉素（chloramphenicol）：结合原核 $50\mathrm{S}$ 亚基，阻止肽酰转移，抑制肽键形成。
:::

:::definition{label="林可霉素卡住 A 位和 P 位"}
林可霉素（lincomycin）：作用于 A 位和 P 位，阻止 $\mathrm{tRNA}$ 在这两个位置就位，从而抑制肽键形成。
:::

:::definition{label="红霉素对 50S 有三记"}
红霉素（erythromycin）属大环内酯类：抑制 $50\mathrm{S}$ 亚基组装与形成、抑制肽酰转移酶、封阻肽链排除通道，从而阻止成肽。表16-6 把氯霉素、林可霉素、红霉素写在同一行：原核大亚基；抑制大亚基形成、抑制肽酰转移酶及封阻肽链排除通道，阻断肽链延长；抗菌药。
:::

:::definition{label="嘌呤霉素是酪氨酰 tRNA 的假货"}
嘌呤霉素（puromycin）：结构与酪氨酰 $\mathrm{tRNA}$ 相似，进入 A 位取代酪氨酰 $\mathrm{tRNA}$，中断肽链合成。表16-6：原核、真核核糖体都作用；使肽酰基转移到它的氨基上，肽链脱落；抗肿瘤药。
:::

:::definition{label="放线菌酮专一抑制真核肽酰转移酶"}
放线菌酮（cycloheximide）：特异性抑制真核生物核糖体肽酰转移酶，阻断肽链延长。表16-6：真核核糖体大亚基；医学研究。
:::

:::compare{title="成肽组：原核 50S vs 真核大亚基 vs 两端都骗"}
| 抗生素 | 对象 | 手法 | 用途 |
|--------|------|------|------|
| 氯霉素 | 原核 $50\mathrm{S}$ | 阻止肽酰转移 | 抗菌药 |
| 林可霉素 | 原核 A 位和 P 位 | $\mathrm{tRNA}$ 不能就位 | 抗菌药 |
| 红霉素 | 原核 $50\mathrm{S}$ | 组装 $+$ 肽酰转移酶 $+$ 排除通道 | 抗菌药 |
| 放线菌酮 | 真核大亚基 | 抑肽酰转移酶 | 医学研究 |
| 嘌呤霉素 | 原核和真核 | 进 A 位，肽酰基转到它的氨基上，链脱落 | 抗肿瘤药 |

成肽的化学本质在第二节是核酶（原核 $23\mathrm{S}\,\mathrm{rRNA}$，真核 $28\mathrm{S}\,\mathrm{rRNA}$）。本节抑制剂按亚基和大／小来写，不要改口说“氯霉素水解 $\mathrm{rRNA}$”——那是蓖麻毒蛋白的手法。
:::

:::pitfall{label="嘌呤霉素中断的是延长中的肽链，不是只挡起始"}
它进 A 位，肽酰基转到它自己的氨基上，肽链脱落。表16-6 用途是抗肿瘤药，因为它对原核、真核核糖体都有效。写成“专一抗菌”，和伊短菌素、放线菌酮的用途列会乱。
:::

:::pitfall{label="放线菌酮不是抗菌药"}
特异性抑制**真核**肽酰转移酶。表16-6 应用是医学研究。写成一线抗菌药，原核／真核差别这一节的临床价值就讲反了。
:::

#### 4. 影响转位的抗生素

夫西地酸（fusidic acid）、硫链丝菌肽（thiostrepton）和微球菌素（micrococcin）抑制 $\mathrm{EF}$-$\mathrm{G}$ 的转位酶活性，从而阻止核糖体转位。大观霉素（spectinomycin）结合核糖体 $30\mathrm{S}$ 亚基，阻碍小亚基变构，抑制转位反应。

:::definition{label="夫西地酸、硫链丝菌肽、微球菌素抑制 EF-G"}
三者抑制 $\mathrm{EF}$-$\mathrm{G}$ 的转位酶活性，阻止核糖体转位。表16-6 列出夫西地酸、微球菌素：原核延长因子 $\mathrm{EF}$-$\mathrm{G}$；阻止转位；抗菌药。硫链丝菌肽在正文，表中未单列。
:::

:::definition{label="大观霉素阻碍 30S 变构"}
大观霉素（spectinomycin）：结合原核 $30\mathrm{S}$ 亚基，阻碍小亚基变构，抑制转位。表16-6：原核小亚基；阻止转位；抗菌药。同一张表里，“小亚基”还可以是四环素的进位或氨基糖苷的读码，大观霉素这一行的原理列必须写成转位。
:::

:::compare{title="转位：打 EF-G vs 打 30S 变构"}
| | 夫西地酸／硫链丝菌肽／微球菌素 | 大观霉素 |
|--|--------------------------------|----------|
| 靶 | 原核 $\mathrm{EF}$-$\mathrm{G}$（转位酶） | 原核 $30\mathrm{S}$ |
| 手法 | 抑制转位酶活性 | 阻碍小亚基变构 |
| 结果 | 核糖体不能向 $\mathrm{mRNA}$ 的 $3'$ 端移一个密码子 | 转位反应被抑制 |

第二节：转位需要 $\mathrm{EF}$-$\mathrm{G}$ 和 $\mathrm{GTP}$。真核对应因子是 $\mathrm{eEF}2$——白喉毒素的靶，下一节再写。
:::

:::pitfall{label="大观霉素结合 30S，但原理不是四环素那种挡 A 位"}
同是小亚基：四环素挡进位，氨基糖苷改忠实性，大观霉素挡转位。只背“结合 $30\mathrm{S}$”不够，表16-6 的作用原理列才是分户钥匙。
:::

## 二、某些毒素及抗肿瘤药物抑制真核生物的蛋白质合成

某些毒素及抗肿瘤药物可通过干扰真核生物的蛋白质合成而呈现毒性。

:::definition{label="本段的户头是真核"}
白喉毒素、蓖麻毒蛋白、三尖杉紫碱／高三尖杉紫碱，都是干扰真核蛋白质合成。抗菌药那一张表不要混进来，除非题目明确对比原核／真核。
:::

白喉毒素（diphtheria toxin）是真核细胞蛋白质合成的抑制剂。它作为一种修饰酶，可使 $\mathrm{eEF}2$ 发生 $\mathrm{ADP}$ 核糖基化修饰，生成 $\mathrm{eEF}2$-腺苷二磷酸核糖衍生物，使 $\mathrm{eEF}2$ 失活，从而抑制蛋白质的合成（图16-16）。

:::definition{label="白喉毒素使 eEF2 发生 ADP 核糖基化"}
白喉毒素（diphtheria toxin）：真核细胞蛋白质合成的抑制剂。本身是修饰酶：把 $\mathrm{eEF}2$ 做 $\mathrm{ADP}$ 核糖基化，生成 $\mathrm{eEF}2$-腺苷二磷酸核糖衍生物，$\mathrm{eEF}2$ 失活，蛋白质合成被抑制。
:::

:::definition{label="eEF2 对应原核 EF-G"}
第二节：真核延长因子 $\mathrm{eEF}2$ 功能对应于原核 $\mathrm{EF}$-$\mathrm{G}$，管转位。白喉毒素灭的是转位这一步的真核因子。夫西地酸打原核 $\mathrm{EF}$-$\mathrm{G}$；白喉毒素打真核 $\mathrm{eEF}2$。
:::

:::note{label="电子版缺失"}
图16-16「白喉毒素的作用原理」电子版图源 `p0342_01.png` 为 $0$ 字节，不嵌入 `src`。`p0342_page.png` 是第 $342$ 页整页扫描，混有表16-6、蓖麻毒蛋白／三尖杉正文与图16-16，不嵌入以免把整页当插图。画面本身：$\mathrm{NAD}^{+}$ 把 $\mathrm{ADP}$-核糖交给有活性的 $\mathrm{eEF}2$，生成失活的 $\mathrm{ADP}$-核糖基化 $\mathrm{eEF}2$，并释放烟酰胺。
:::

:::cause-effect{title="白喉毒素怎样把转位停住"}
- **因** 毒素以修饰酶身份把 $\mathrm{NAD}^{+}$ 上的 $\mathrm{ADP}$-核糖转到 $\mathrm{eEF}2$ 上，$\mathrm{eEF}2$ 变成腺苷二磷酸核糖衍生物而失活
- **果** 真核核糖体不能完成转位，蛋白质合成被抑制
:::

:::pitfall{label="白喉毒素不是水解 eEF2 的蛋白酶"}
它是修饰酶，做 $\mathrm{ADP}$ 核糖基化。蓖麻毒蛋白 A 链才被本版写成作用于 $28\mathrm{S}\,\mathrm{rRNA}$ 的蛋白酶（脱嘌呤）。两户不要对调。
:::

:::pitfall{label="底物是 eEF2，不是 EF-G，也不是 eEF1"}
$\mathrm{eEF}1\alpha$／$\mathrm{eEF}1\beta\gamma$ 对应 $\mathrm{EF}$-$\mathrm{Tu}$／$\mathrm{EF}$-$\mathrm{Ts}$（进位）。白喉毒素点名 $\mathrm{eEF}2$。写成“修饰所有真核延长因子”，进位那一组还在工作，转位才停。
:::

蓖麻毒蛋白（ricin）是蓖麻籽中所含的植物糖蛋白，由 A、B 两条肽链组成，两条肽链之间由一个二硫键连接。A 链是一种蛋白酶，可作用于真核生物核糖体大亚基的 $28\mathrm{S}\,\mathrm{rRNA}$，特异催化其中一个腺苷酸发生脱嘌呤反应，导致 $28\mathrm{S}\,\mathrm{rRNA}$ 降解而使核糖体大亚基失活。B 链对 A 链发挥毒性起重要的促进作用，另外 B 链上的半乳糖结合位点也是蓖麻毒蛋白发挥毒性作用的活性部位。

:::definition{label="蓖麻毒蛋白是 A、B 两链的植物糖蛋白"}
蓖麻毒蛋白（ricin）：蓖麻籽中的植物糖蛋白。A、B 两条肽链由一个二硫键连接。
:::

:::definition{label="A 链对 28S rRNA 脱嘌呤"}
本版把 A 链写成一种蛋白酶：作用于真核大亚基的 $28\mathrm{S}\,\mathrm{rRNA}$，特异催化其中一个腺苷酸脱嘌呤，导致 $28\mathrm{S}\,\mathrm{rRNA}$ 降解，大亚基失活。考点落在脱嘌呤和 $28\mathrm{S}$，不要改写成水解肽键。
:::

:::definition{label="B 链促进毒性，半乳糖结合位点也是活性部位"}
B 链对 A 链发挥毒性起重要促进作用。B 链上的半乳糖结合位点也是蓖麻毒蛋白发挥毒性作用的活性部位。
:::

| | 白喉毒素 | 蓖麻毒蛋白 |
|--|----------|------------|
| 来源／性质 | 修饰酶 | 蓖麻籽植物糖蛋白，A、B 链，二硫键 |
| 靶 | $\mathrm{eEF}2$ | 真核 $28\mathrm{S}\,\mathrm{rRNA}$（大亚基） |

:::

不要据此答“蓖麻毒蛋白水解肽链”。教材紧接着写的是 $28\mathrm{S}\,\mathrm{rRNA}$ 上一个腺苷酸的脱嘌呤反应。答题用后半句的分子事件。

原核成肽核酶是 $23\mathrm{S}\,\mathrm{rRNA}$；氨基糖苷解码在 $16\mathrm{S}$。蓖麻毒蛋白点名真核 $28\mathrm{S}$。写错 $\mathrm{rRNA}$，原核／真核这一章的临床差别就垮了。
:::

三尖杉紫碱（harringtonine）、高三尖杉紫碱（homoharringtonine）同属三尖杉生物碱类药物，能够抑制真核细胞蛋白质合成的起始阶段、使多聚核糖体解聚，干扰蛋白质合成。

:::definition{label="三尖杉紫碱和高三尖杉紫碱"}
同属三尖杉生物碱类。抑制真核细胞蛋白质合成的起始阶段，使多聚核糖体解聚，从而干扰蛋白质合成。

## 本章小结

蛋白质是生命活动的重要物质基础。蛋白质具有高度的种属特异性，所以各种生物的蛋白质必须由机体自身合成。蛋白质合成体系包括原料氨基酸，模板 $\mathrm{mRNA}$、氨基酸搬运工具 $\mathrm{tRNA}$、蛋白质合成场所核糖体，以及合成各阶段所需的酶和蛋白质因子等，合成过程还需要 $\mathrm{ATP}$ 或 $\mathrm{GTP}$ 供能。

$\mathrm{mRNA}$ 是蛋白质合成的模板。$\mathrm{mRNA}$ 可读框中每 $3$ 个相邻核苷酸编码一种氨基酸，称为密码子。密码子共有 $64$ 个，其中 $61$ 个编码各种氨基酸，$3$ 个作为肽链合成的终止密码子。密码子具有方向性、连续性、简并性、摆动性和通用性等特点。$\mathrm{tRNA}$ 是氨基酸和密码子之间的特异衔接子。$\mathrm{tRNA}$ 与特异氨基酸的连接由氨酰 $\mathrm{tRNA}$ 合成酶催化，$\mathrm{tRNA}$ 通过反密码子与 $\mathrm{mRNA}$ 的密码子识别，为肽链合成提供氨基酸原料。核糖体由大、小亚基组成，具有 A 位、P 位和 E 位三个功能部位，是蛋白质合成的场所。

蛋白质合成过程包括起始、延长和终止三个阶段。肽链合成的起始是在各种起始因子的协助下，$\mathrm{mRNA}$、起始氨酰 $\mathrm{tRNA}$ 分别与核糖体结合，装配成翻译起始复合物的过程。肽链的延长是在核糖体上重复进行的进位、成肽和转位的循环过程，每循环 $1$ 次，肽链上即可增加 $1$ 个氨基酸残基。肽链的延长过程需要数种延长因子以及 $\mathrm{GTP}$ 等参与。当核糖体的 A 位对应于 $\mathrm{mRNA}$ 的终止密码子时，释放因子 $\mathrm{RF}$ 进入 A 位，致使肽酰转移酶转变为酯酶，水解肽链与 $\mathrm{tRNA}$ 间的酯键，新生肽链释放，核糖体大小亚基分离，肽链合成终止。

原核生物和真核生物的肽链合成过程基本相似，只是真核生物的反应更为复杂、涉及的蛋白质因子更多。原核生物和真核生物均以多聚核糖体形式进行肽链的高效合成。原核生物的转录和翻译过程紧密偶联。真核生物的转录发生在细胞核，翻译在细胞质，因此这两个过程分隔进行。

新生肽链并不具有生物活性，需要经过复杂的翻译后加工，才能成为有活性的成熟蛋白质。翻译后加工包括在分子伴侣帮助下的肽链折叠、肽链末端及内部的水解、肽链中氨基酸残基的化学修饰、亚基聚合等方式。蛋白质在细胞质合成后，还需要被靶向输送至其发挥功能的亚细胞区域，或分泌到细胞外。所有需靶向输送的蛋白质，其一级结构都存在分拣信号。

蛋白质生物合成是某些毒素或抗肿瘤药物作用靶点。这些毒素或抗肿瘤药物通过阻断原核或真核生物蛋白质合成体系中某组分的功能，来干扰和抑制蛋白质合成过程。真核生物与原核生物的翻译过程既相似又有差别，这些差别在临床医学中有重要应用价值。

:::definition{label="本章小结里的合成体系"}
原料氨基酸，模板 $\mathrm{mRNA}$，搬运工具 $\mathrm{tRNA}$，场所核糖体，各阶段的酶和蛋白质因子；还需要 $\mathrm{ATP}$ 或 $\mathrm{GTP}$ 供能。蛋白质种属特异，必须由机体自身合成。
:::

:::definition{label="本章小结里的密码子和核糖体"}
可读框中每 $3$ 个相邻核苷酸为一个密码子；$64$ 个密码子里 $61$ 个编码氨基酸，$3$ 个终止。特点：方向性、连续性、简并性、摆动性、通用性。$\mathrm{tRNA}$ 是衔接子，氨酰 $\mathrm{tRNA}$ 合成酶负责连接，反密码子认密码子。核糖体分大、小亚基，有 A、P、E 三个功能部位。
:::

:::definition{label="本章小结里的起始、延长、终止"}
起始：起始因子协助下，$\mathrm{mRNA}$ 和起始氨酰 $\mathrm{tRNA}$ 与核糖体装配成翻译起始复合物。延长：进位、成肽、转位循环，每圈 C- 端加 $1$ 个残基，需延长因子和 $\mathrm{GTP}$。终止：A 位对上终止密码子，$\mathrm{RF}$ 进入，肽酰转移酶变酯酶，酯键水解，肽链释放，大小亚基分离。
:::

:::definition{label="本章小结里的原核偶联与多聚核糖体"}
原核、真核都用多聚核糖体高效合成。原核转录与翻译紧密偶联；真核转录在核、翻译在细胞质，过程分隔。真核反应更复杂、蛋白质因子更多。
:::

:::definition{label="本章小结里的加工和分选"}
新生肽链无活性。加工：分子伴侣帮助折叠、末端及内部水解、侧链化学修饰、亚基聚合。细胞质合成后还要靶向输送到亚细胞区域或细胞外；需输送者一级结构都有分拣信号。
:::

:::definition{label="本章小结里的药物和毒素"}
蛋白质生物合成是某些毒素或抗肿瘤药物的靶点，阻断原核或真核合成体系中某组分。原核与真核翻译的差别在临床上有重要应用价值。
:::

:::keypoint{label="本章小结按节收口"}
- 第一节：自身合成；$\mathrm{mRNA}$ 密码子五特点；$\mathrm{tRNA}$ 衔接子；核糖体 A／P／E。
- 第二节：起始复合物；进位–成肽–转位；$\mathrm{RF}$ 把肽酰转移酶变成酯酶；多聚核糖体；原核偶联、真核分隔。
- 第三节：分子伴侣折叠；水解（含 $\mathrm{POMC}$）；表16-4 修饰；亚基聚合；表16-5 分拣信号；分泌通路与核定位。
- 第四节：抗生素按起始／进位／读码／成肽／转位分户；白喉毒素、蓖麻毒蛋白、三尖杉类打真核。
:::

:::insight{label="小结写“毒素或抗肿瘤药物”，正文还有一整张抗菌药表"}
章末按真核毒素／抗肿瘤收口，但第四节第一大部分是抗菌抗生素。答题若问临床应用，抗菌药、抗病毒药（伊短菌素）、医学研究（放线菌酮）都要能从原核／真核差别里长出来，不要被小结的“毒素或抗肿瘤”缩成两户。
:::

:::pitfall{label="小结的终止不要写成“释放因子水解肽键”"}
水解的是肽链与 $\mathrm{tRNA}$ 之间的**酯键**；酶活性来自肽酰转移酶转变为酯酶。肽键是延长时成肽形成的。把终止答成再切一个肽键，和第二节酯酶那一句冲突。
:::

## 思考题

1. 蛋白质合成过程中有哪些机制保证多肽链翻译的准确性？
2. 对蛋白质合成机制的研究有何重要意义？
3. 真核生物与原核生物的翻译过程既相似又有差别，这些差别在临床医学中有何重要应用价值？

:::tip{label="三道思考题在正文里的户头"}
- 准确性：第一节氨酰 $\mathrm{tRNA}$ 合成酶对氨基酸和 $\mathrm{tRNA}$ 都高度特异（“搭错车”仍按 $\mathrm{tRNA}$ 进肽链，所以连接必须对）；密码子–反密码子配对，摆动在第三位但不取消前两位的特异；第二节进位有时限，只有正确氨酰 $\mathrm{tRNA}$ 能迅速配对进入 A 位，错误的因不能配对而解离；氨基糖苷类降低忠实性，从反面说明 $30\mathrm{S}$ 解码部位在维持准确性。不要把分子伴侣答进“翻译准确性”——那是折叠，不是读码。
- 研究意义：蛋白质必须自身合成，是生命活动基础；合成与降解几乎支撑所有生命活动。机制研究解释致病（白喉毒素灭 $\mathrm{eEF}2$，蓖麻毒蛋白毁 $28\mathrm{S}$），也提供药物靶点和研究工具（几乎每一步都有抗生素）。从毒素机制还可探索新药途径。答题用教材已写的靶点，不要另编药名。
- 临床差别：原核与真核翻译基本相似，真核更复杂、因子更多。差别使仅作用于原核的抗生素可作抗菌药（四环素、$30\mathrm{S}$ 进位；氯霉素／林可霉素／红霉素，$50\mathrm{S}$ 成肽；夫西地酸／微球菌素，$\mathrm{EF}$-$\mathrm{G}$ 转位；大观霉素，$30\mathrm{S}$ 转位；氨基糖苷读码／抑起始），对真核细胞无明显影响。作用于真核的可作抗肿瘤药或研究工具（嘌呤霉素两端都抑，抗肿瘤；放线菌酮专一真核肽酰转移酶，医学研究；三尖杉类抑真核起始并解聚多聚核糖体）。白喉毒素、蓖麻毒蛋白专打真核，解释致病。伊短菌素两端都抑，表中为抗病毒药。本版没有干扰素抑制翻译这一户。
:::
