# 第五节　脂肪组织的生物化学

前四节分别立脑、心肌、肾和骨骼肌。本节只立「脂肪组织的生物化学」：脂肪组织的主要功能是储存和动员甘油三酯。白色脂肪组织是主要的甘油三酯储存和动员部位，棕色脂肪组织的主要功能是氧化脂肪酸产热。脂肪组织作为内分泌器官还产生许多脂肪分泌因子，参与自身及其他器官的信息交流。热量限制具有减重和调节代谢等多种功能。骨骼肌分泌的肌肉因子（包括作为肌肉因子的白细胞介素-6）是第四节的账，本节不把肌肉因子当主线。

:::concept{term="先问白色储存动员、棕色产热，再问瘦素和脂连蛋白怎么反向走"}
看见「脂肪组织的生物化学」，先不要默写第四节的运动供能曲线，也不要把白细胞介素-6 当成肌肉因子再写一遍。户头是：白色脂肪组织储存和动员甘油三酯；棕色脂肪组织氧化脂肪酸产热；瘦素由肥胖基因编码、白色脂肪组织合成，血浆浓度与脂肪量成正比；脂连蛋白循环水平与脂肪量成反比，有胰岛素增敏和抗炎作用。把「脂肪＝只储存」「瘦素和脂连蛋白同一方向」写成开篇，后文弓状核两条神经元和热量限制的 $\mathrm{AMPK}\uparrow\,\mathrm{mTORC1}\downarrow$ 都没有底板。
:::

:::note{label="电子版缺失"}
图27-11（瘦素的作用机制）电子版缺失，正文保留图号，不嵌入空图。机制按下面散文写：瘦素作用于下丘脑弓状核，促进阿黑皮素原（$\mathrm{POMC}$）神经元抑制食欲，同时抑制神经肽 $\mathrm{Y}$／刺鼠相关蛋白（$\mathrm{NPY}/\mathrm{AgRP}$）神经元；还可经交感神经系统和解偶联蛋白 1 增加产热，并直接作用于脂肪细胞。
:::

脂肪组织的主要功能是储存和动员甘油三酯。白色脂肪组织是主要的甘油三酯储存和动员的部位，而棕色脂肪组织的主要功能是氧化脂肪酸产热。脂肪组织作为内分泌器官还产生许多脂肪分泌因子，参与自身及其他器官的信息交流。热量限制具有减重和调节代谢等多种功能。

:::definition{label="脂肪组织的主要功能"}
储存和动员甘油三酯。白色脂肪组织管储存和动员；棕色脂肪组织管氧化脂肪酸产热。后文脂肪因子和热量限制都站在这张底板上面。
:::

:::keypoint{label="开篇四句先钉死"}
- 白色：甘油三酯的主要储存和动员部位。
- 棕色：氧化脂肪酸产热（无颤动产热）。
- 内分泌：脂肪因子、脂质和 $\mathrm{microRNA}$ 参与器官间信息交流。
- 热量限制：不造成营养不良的前提下减少总热量，可减重并增敏胰岛素。
:::

:::pitfall{label="白细胞介素-6 不要从第四节原样搬过来当主线"}
第四节的白细胞介素-6 是第一个被发现的肌肉因子，运动时血浓度上升、常带抗炎色彩。本节名单里的白细胞介素-6 是促炎脂肪因子之一。同一分子、两本账。思考题第 5 题问「脂肪组织产生的白细胞介素-6」，按促炎脂肪因子答，不要写成骨骼肌分泌。
:::

## 一、脂肪组织是储存和动员甘油三酯的重要组织

生理情况下，餐后吸收的脂肪和葡萄糖除部分氧化供能外，其余部分主要以脂肪形式储存于脂肪组织。饥饿时抗脂解激素胰岛素水平降低、脂解激素胰高血糖素等分泌增加，激活脂肪组织甘油三酯脂肪酶（adipose triglyceride lipase，$\mathrm{ATGL}$）和激素敏感脂肪酶（hormone-sensitive lipase，$\mathrm{HSL}$），将储存于脂肪组织的能量以脂肪酸和甘油的形式释放入血，是其他组织的能量来源。

:::definition{label="餐后储存"}
吸收的脂肪和葡萄糖，除部分氧化供能外，其余主要以脂肪形式储存于脂肪组织。户头是「先存起来」，不是「餐后脂肪组织只氧化、不储存」。
:::

:::definition{label="饥饿动员"}
抗脂解激素胰岛素降低，脂解激素胰高血糖素等升高，激活 $\mathrm{ATGL}$ 和 $\mathrm{HSL}$，把储存的甘油三酯水解为脂肪酸和甘油释放入血，供其他组织使用。
:::

:::definition{label="ATGL 和 HSL"}
脂肪组织甘油三酯脂肪酶和激素敏感脂肪酶是本版点名的两把动员酶。问「饥饿时脂肪怎么出库」先答这两把酶，不要先跳到瘦素。
:::

:::compare{title="餐后 vs 饥饿"}
| | 激素局面 | 脂肪组织做什么 | 出库产物 |
|--|---------|--------------|---------|
| 餐后 | 胰岛素相对占上风 | 把多余脂肪和葡萄糖存成甘油三酯 | 暂不出库 |
| 饥饿 | 胰岛素降低，胰高血糖素等升高 | 激活 $\mathrm{ATGL}$、$\mathrm{HSL}$ | 脂肪酸和甘油入血 |

问「为什么禁食时血游离脂肪酸升高」走饥饿这一列。
:::

:::cause-effect{title="胰岛素降、胰高血糖素升 → ATGL/HSL → 脂肪酸和甘油入血"}
饥饿 → 抗脂解激素胰岛素降低、脂解激素胰高血糖素等升高 → 激活 $\mathrm{ATGL}$ 和 $\mathrm{HSL}$ → 甘油三酯水解 → 脂肪酸和甘油释放入血 → 其他组织的能量来源。
:::

:::pitfall{label="动员产物是脂肪酸和甘油，不是完整的甘油三酯颗粒入血"}
本版原句是「以脂肪酸和甘油的形式释放入血」。不要写成「脂肪细胞把整颗脂滴吐进循环」。甘油三酯怎么组装进脂蛋白，是脂质代谢章的账。
:::

:::insight{label="白色脂肪这时是全身的燃料库"}
储存发生在餐后，动员发生在饥饿。后文白色脂肪组织脂解的脂肪酸「主要释放到外周循环」，和棕色脂肪「脂肪酸就地进线粒体产热」不是同一去向。
:::

## 二、脂肪组织具有不同的类型和代谢特征

脂肪组织由多种细胞类型组成，包括脂肪细胞、血管内皮细胞、成纤维细胞和巨噬细胞。脂肪组织分为白色和棕色两种类型。

:::definition{label="脂肪组织的细胞组成"}
脂肪细胞、血管内皮细胞、成纤维细胞和巨噬细胞。后文慢性低度炎症要靠巨噬细胞浸润来写，底板在这里：脂肪组织从来不是「只有脂肪细胞」。
:::

:::definition{label="本版先分两型"}
白色脂肪组织和棕色脂肪组织。米色脂肪细胞具有二者的混合特征，写在两型对照之后，不要先把三型并列成三种器官。
:::

人体的白色脂肪组织主要分布于皮下组织、网膜和肠系膜等处，其中的脂肪细胞有大而单一的脂滴、较少的线粒体和低含量的解偶联蛋白 1（uncoupling protein 1，$\mathrm{UCP1}$），具有特征性的白色外观。在白色脂肪组织中脂解的脂肪酸主要释放到外周循环系统中。

:::definition{label="白色脂肪组织"}
主要分布于皮下、网膜和肠系膜。脂肪细胞：大而单一的脂滴、线粒体较少、$\mathrm{UCP1}$ 含量低，外观白色。脂解产生的脂肪酸主要释放到外周循环，供其他组织氧化。
:::

:::keypoint{label="白色三件套"}
- 部位：皮下、网膜、肠系膜。
- 形态：单房大脂滴，线粒体少，$\mathrm{UCP1}$ 低。
- 去向：脂肪酸出库入血，不是就地产热。
:::

棕色脂肪组织的棕色脂肪细胞有小而多的脂滴，有大量富含铁的线粒体，并分布有丰富的毛细血管，具有特有的棕色外观。棕色脂肪组织主要存在于哺乳动物出生后和冬眠期间，以及人类的婴幼儿期间。棕色脂肪组织特异地分解脂肪，释放脂肪酸进入线粒体氧化分解产生热量，这种无颤动产热可维持体温。

:::definition{label="棕色脂肪组织"}
小而多的脂滴，大量富含铁的线粒体，毛细血管丰富，外观棕色。职分是把脂肪酸送进线粒体氧化产热，不是把脂肪酸大批送进血循环。
:::

:::definition{label="无颤动产热"}
棕色脂肪组织特异地分解脂肪，脂肪酸进入线粒体氧化分解产生热量，用以维持体温。户头是「产热御寒」，不是骨骼肌寒战。
:::

:::definition{label="UCP1"}
解偶联蛋白 1。白色脂肪含量低；棕色和米色脂肪在去甲肾上腺素／$\beta_3$-肾上腺素受体刺激下转录增加，使 $\mathrm{ATP}$ 生成与呼吸链电子传递解偶联，能量以热的形式释放。后文瘦素的交感支会再碰到它。
:::

:::compare{title="白色 vs 棕色"}
| | 白色脂肪组织 | 棕色脂肪组织 | 不要写成 |
|--|------------|------------|---------|
| 脂滴 | 大而单一 | 小而多 | 「棕色也是单房大脂滴」 |
| 线粒体 | 较少 | 大量、富含铁 | 「两型线粒体差不多」 |
| $\mathrm{UCP1}$ | 低含量 | 高，用于解偶联产热 | 「白色靠 $\mathrm{UCP1}$ 供能」 |
| 毛细血管 | 相对不强调 | 丰富 | 「棕色缺血」 |
| 外观 | 白色 | 棕色 | 「名字只是习惯叫法」 |
| 脂肪酸去向 | 主要释放到外周循环 | 进入自身线粒体氧化产热 | 「棕色也是全身燃料库」 |
| 主要职分 | 储存和动员甘油三酯 | 无颤动产热 | 「棕色只在成人腹部」 |

问「减肥是不是把白色脂肪切掉就完」——本版还立了棕色产热和后文脂肪因子，不要停在「少吃多动」四个字。
:::

棕色脂肪组织在新生儿的肩胛间、颈部、脊柱旁有较多的分布，在成人的椎旁交界处、颈部／腋窝区域、气管和血管以及肾周、肾上腺位置也有数量不定但代谢活跃的棕色脂肪组织分布。尽管数量较少，人体棕色脂肪组织代谢活跃时全身能量消耗可增加 $40\%\sim 80\%$。

:::definition{label="棕色脂肪的部位"}
新生儿：肩胛间、颈部、脊柱旁较多。成人：椎旁交界处、颈部／腋窝、气管和血管周围，以及肾周、肾上腺，数量不定但可以代谢活跃。不要写成「成人没有棕色脂肪」。
:::

:::definition{label="数量少、激活时耗能可增 40%～80%"}
人体棕色脂肪组织数量较少，但代谢活跃时全身能量消耗可增加 $40\%\sim 80\%$。户头是「激活后的增量」，不是「静息时已经多耗 $40\%\sim 80\%$」。
:::

:::pitfall{label="40%～80% 不要写成体重份额"}
这是全身能量消耗的增加幅度，不是棕色脂肪占体重的百分数，也不是白色脂肪减少的百分数。
:::

此外，米色脂肪细胞具有二者的混合特征，可由祖细胞分化或在寒冷刺激下由白色脂肪细胞转变而来。

:::definition{label="米色脂肪细胞"}
兼有白色和棕色的混合特征。来源有两条：祖细胞分化，或寒冷刺激下由白色脂肪细胞转变。后文瘦素经交感刺激 $\mathrm{UCP1}$、增加棕色和米色脂肪细胞中的线粒体合成，用的就是这一户。
:::

:::insight{label="米色不是第三种独立器官"}
本版先说「分为白色和棕色两种类型」，再补一句米色。考试若问「脂肪组织分几型」，先答白／棕；若问「白色能不能转产热」，再答米色／寒冷转变。
:::

:::pitfall{label="白色脂肪褐变不要写成第四节肌肉因子的专利"}
第四节的鸢尾素、镍纹样蛋白可以参与白色向棕色或米色的转变。本节自己的机制是寒冷、交感、$\mathrm{UCP1}$ 和瘦素的中枢－交感支。两本账可以碰头，不要并成「只有肌肉因子才能褐变」。
:::

## 三、脂肪组织及其产生的分泌因子是影响体重的关键因素

脂肪组织作为内分泌器官还产生许多脂肪分泌因子，参与自身及其他组织和器官间的信息交流。脂肪组织表达并释放许多蛋白质性质的脂肪因子（adipokine）、脂质和 $\mathrm{microRNA}$ 等分子，这些分子以自分泌、旁分泌或内分泌方式作用于附近或远处的其他组织器官，调节脂质和葡萄糖稳态、能量平衡、炎症和组织修复。

:::definition{label="脂肪因子"}
脂肪细胞表达和释放的蛋白质分子，以自分泌、旁分泌或内分泌方式作用于附近或远处组织器官，调节脂质和糖稳态、能量平衡、炎症和组织修复。本版名词释义与正文一致。
:::

:::definition{label="分泌物不只蛋白质"}
蛋白质性质的脂肪因子之外，还有脂质和 $\mathrm{microRNA}$。问「脂肪组织只分泌瘦素吗」——不是，名单很长，瘦素和脂连蛋白是后文两户主线。
:::

:::keypoint{label="三种作用距离"}
- 自分泌：作用于自身脂肪细胞。
- 旁分泌：作用于附近细胞（如组织内巨噬细胞）。
- 内分泌：经循环到达远处器官（下丘脑、骨骼肌、肝、心血管）。
:::

### （一）脂肪组织分泌多种脂肪因子调控自身和整体代谢

具备促炎作用的脂肪因子包括瘦素（leptin）、抵抗素（resistin）、趋化素（chemerin）、前粒蛋白（progranulin，$\mathrm{PGRN}$）、$\mathrm{Wnt1}$ 诱导的信号通路蛋白 1（$\mathrm{WNT1}$ inducible signaling pathway protein 1，$\mathrm{WISP1}$）、视黄醇结合蛋白-4（retinol binding protein 4，$\mathrm{RBP4}$）、脂肪酸结合蛋白 4（fatty acid binding protein 4，$\mathrm{FABP4}$）、纤溶酶原激活剂抑制剂 1（plasminogen activator inhibitor-1，$\mathrm{PAI}$-$1$）、卵泡抑素样蛋白 1（follistatin-like protein 1，$\mathrm{FSTL1}$）、单核细胞趋化蛋白-1（$\mathrm{MCP}$-$1$）、肿瘤坏死因子 $\alpha$（$\mathrm{TNF}$-$\alpha$）、白细胞介素-6（$\mathrm{IL}$-$6$）和白细胞介素-$1\beta$（$\mathrm{IL}$-$1\beta$）等。

:::definition{label="促炎脂肪因子名单"}
瘦素、抵抗素、趋化素、前粒蛋白、$\mathrm{WISP1}$、$\mathrm{RBP4}$、$\mathrm{FABP4}$、$\mathrm{PAI}$-$1$、$\mathrm{FSTL1}$、$\mathrm{MCP}$-$1$、$\mathrm{TNF}$-$\alpha$、$\mathrm{IL}$-$6$、$\mathrm{IL}$-$1\beta$ 等。名单用来认「肥胖时谁升高」，不要把每一个都展开成独立通路。
:::

:::pitfall{label="瘦素既管能量平衡，高水平时又促炎"}
除在能量平衡中的作用外，高水平瘦素在肥胖个体中发挥促炎作用。不要写成「瘦素只抗炎」或「瘦素只促炎」。后文主线仍是抑制食欲、增加消耗；促炎是肥胖时的另一面。
:::

抵抗素与脂连蛋白具有相似结构，却是一种促炎脂肪因子，并有抵抗胰岛素的作用。脂肪组织固有巨噬细胞、外周血单核细胞、巨噬细胞和骨髓细胞是抵抗素的主要来源，通过 $\mathrm{NF}$-$\kappa\mathrm{B}$ 活化诱导 $\mathrm{TNF}$-$\alpha$、$\mathrm{IL}$-$6$、$\mathrm{IL}$-$12$ 和 $\mathrm{MCP}$-$1$ 过表达。

:::definition{label="抵抗素"}
与脂连蛋白结构相似，功能相反：促炎，并抵抗胰岛素。主要来源是巨噬细胞系统（脂肪组织固有巨噬细胞、外周血单核细胞、巨噬细胞、骨髓细胞），不是「只有脂肪细胞才分泌抵抗素」。
:::

:::cause-effect{title="抵抗素 → NF-κB → 促炎细胞因子过表达"}
抵抗素 → 活化 $\mathrm{NF}$-$\kappa\mathrm{B}$ → $\mathrm{TNF}$-$\alpha$、$\mathrm{IL}$-$6$、$\mathrm{IL}$-$12$、$\mathrm{MCP}$-$1$ 过表达。问「抵抗素怎么加重炎症」走这一条。
:::

:::compare{title="脂连蛋白 vs 抵抗素"}
| | 脂连蛋白 | 抵抗素 | 不要写成 |
|--|---------|--------|---------|
| 结构 | 本版写二者相似 | 相似 | 「完全不同的折叠」——教材先说相似 |
| 炎症 | 抗炎 | 促炎 | 「结构相似所以功能相同」 |
| 胰岛素 | 增敏 | 抵抗 | 「都增敏」 |

结构像、方向反，是命题常用对照。
:::

趋化素是一种 $14\,\mathrm{kDa}$ 的趋化蛋白，在白色脂肪组织中高度表达。肥胖和代谢综合征患者的趋化素水平在全身和脂肪细胞中升高，通过与其 $\mathrm{G}$ 蛋白偶联受体趋化因子样受体-1（chemerin chemokine-like receptor 1，$\mathrm{CMKLR1}$）结合，调节脂肪细胞分化并招募循环浆细胞样树突状细胞到内脏脂肪组织，启动先天免疫反应并导致肥胖个体脂肪组织炎症。脂肪细胞分泌的 $\mathrm{WISP1}$ 直接激活巨噬细胞，释放 $\mathrm{TNF}$-$\alpha$ 和 $\mathrm{IL}$-$6$ 等促炎细胞因子。

:::definition{label="趋化素"}
$14\,\mathrm{kDa}$ 趋化蛋白，白色脂肪组织高表达。肥胖和代谢综合征时全身和脂肪细胞水平升高。受体是 $\mathrm{CMKLR1}$（$\mathrm{GPCR}$）。
:::

:::definition{label="趋化素的两个下游"}
调节脂肪细胞分化；招募循环浆细胞样树突状细胞到内脏脂肪组织，启动先天免疫，造成肥胖个体脂肪组织炎症。两步不要并成「只趋化巨噬细胞」。
:::

:::definition{label="WISP1"}
脂肪细胞分泌，直接激活巨噬细胞，使之释放 $\mathrm{TNF}$-$\alpha$ 和 $\mathrm{IL}$-$6$。户头是「脂肪细胞喊醒巨噬细胞」，和趋化素招募树突状细胞不是同一条路。
:::

具备抗炎作用的脂肪因子包括脂连蛋白（adiponectin）、网膜蛋白-1（omentin-1）、锌 $\alpha 2$ 糖蛋白（zinc-alpha 2-glycoprotein，$\mathrm{ZAG}$）、分泌型卷曲相关蛋白 5（secreted frizzled-related protein 5，$\mathrm{Sfrp5}$）、$\mathrm{C1q}/\mathrm{TNF}$ 相关蛋白（$\mathrm{C1q}/\mathrm{TNF}$-related proteins，$\mathrm{CTRPs}$）、脂质运载蛋白-2（lipocalin-2，$\mathrm{LCN}$-$2$）、腹腔脂肪型丝氨酸蛋白酶抑制剂（vaspin）和白细胞介素-10（$\mathrm{IL}$-$10$）等。

:::definition{label="抗炎脂肪因子名单"}
脂连蛋白、网膜蛋白-1、$\mathrm{ZAG}$、$\mathrm{Sfrp5}$、$\mathrm{CTRPs}$、$\mathrm{LCN}$-$2$、vaspin、$\mathrm{IL}$-$10$ 等。后文主线是脂连蛋白；网膜蛋白-1 本版只点名抑制氧化应激和炎症小体。
:::

脂连蛋白抑制巨噬细胞促炎细胞因子 $\mathrm{TNF}$-$\alpha$ 表达并诱导抗炎细胞因子 $\mathrm{IL}$-$10$ 表达，诱导 $\mathrm{M1}$ 至 $\mathrm{M2}$ 巨噬细胞的极化，从而减轻慢性炎症。网膜蛋白-1 可抑制氧化应激和炎症小体信号通路，减轻炎症反应。在肥胖个体的脂肪组织中脂连蛋白和网膜蛋白-1 表达降低。

:::definition{label="脂连蛋白的抗炎写法（巨噬细胞）"}
抑制 $\mathrm{TNF}$-$\alpha$，诱导 $\mathrm{IL}$-$10$，推动巨噬细胞 $\mathrm{M1}\to\mathrm{M2}$ 极化。后文「胰岛素增敏和抗炎」是总括，这一段是炎症细胞层面的机制。
:::

:::definition{label="网膜蛋白-1"}
抑制氧化应激和炎症小体信号通路。肥胖时与脂连蛋白一起表达降低。
:::

:::compare{title="肥胖时促炎升、抗炎降"}
| | 肥胖时 | 本版例子 |
|--|--------|---------|
| 促炎脂肪因子／趋化因子 | 升高 | 高水平瘦素、抵抗素、趋化素、$\mathrm{WISP1}$ 等 |
| 抗炎脂肪因子 | 降低 | 脂连蛋白、网膜蛋白-1 |

不要写成「肥胖时所有脂肪因子都升高」。
:::

脂肪组织慢性低度炎症是肥胖的标志，并导致各种代谢紊乱。脂肪组织的炎症特征是巨噬细胞浸润和由 $\mathrm{NF}$-$\kappa\mathrm{B}$、$\mathrm{JNK}$ 和 $\mathrm{NLRP3}$ 炎症小体等炎症途径的激活。从脂肪组织、肝和骨骼肌分别产生分泌的脂肪因子、肝分泌因子（hepatic factors）和肌肉因子参与了脂肪组织的慢性炎症调节。肥胖发生时，促炎脂肪分泌因子或趋化因子水平升高，抗炎脂肪分泌因子的水平降低。

:::definition{label="肥胖的炎症标志"}
脂肪组织慢性低度炎症。特征：巨噬细胞浸润；$\mathrm{NF}$-$\kappa\mathrm{B}$、$\mathrm{JNK}$、$\mathrm{NLRP3}$ 炎症小体激活。
:::

:::definition{label="三套分泌因子都来参与"}
脂肪因子（脂肪组织）、肝分泌因子（肝）、肌肉因子（骨骼肌）共同调节脂肪组织慢性炎症。本节展开脂肪因子；肌肉因子细节在第四节，不要在这里重写 $650$ 多种。
:::

脂肪细胞不仅受到自身脂肪分泌因子的调控，也受来自其他器官产生的细胞因子影响，共同调控其代谢和发育、血管生成、炎症等多个过程。脂肪组织功能和代谢的失衡，以及由此产生的脂肪分泌因子和脂代谢变化影响全身整体代谢，并参与胰岛素抵抗和代谢综合征的发生发展。

:::insight{label="脂肪组织既是靶器官也是信号源"}
自己分泌的因子调自己，远处器官的细胞因子也调它。失衡之后，分泌谱和脂代谢一起改，落到胰岛素抵抗和代谢综合征。后文瘦素抵抗、脂连蛋白下降、热量限制增敏，都是这张网的不同切口。
:::

:::pitfall{label="IL-6 在本节名单里是促炎脂肪因子"}
促炎名单含 $\mathrm{IL}$-$6$，抗炎名单含 $\mathrm{IL}$-$10$。不要用第四节「骨骼肌来源的 $\mathrm{IL}$-$6$ 减少 $\mathrm{TNF}$ 和 $\mathrm{IL}$-$1$」来改写本节。思考题若把三者并列，瘦素和脂连蛋白按下面两小节展开，$\mathrm{IL}$-$6$ 按促炎脂肪因子点到即可。
:::

### （二）瘦素直接或间接地减少脂肪组织

瘦素是由肥胖基因编码、白色脂肪组织合成的肽激素，由 $146$ 个氨基酸残基组成。血浆中的瘦素浓度通常与脂肪量成正比，肥胖升高瘦素水平。瘦素受体在结合瘦素后形成二聚体而活化，激活 $\mathrm{JAK}$-$\mathrm{STAT}$ 信号通路，主要通过转录因子信号转导及转录激活蛋白 3（signal transducer and activator of transcription 3，$\mathrm{STAT3}$）发挥效应。瘦素受体在神经元、肝、胰腺、心肌和血管周围组织中表达。

:::definition{label="瘦素"}
由肥胖基因编码、白色脂肪组织合成的肽激素，由 $146$ 个氨基酸残基组成。血浆浓度通常与脂肪量成正比；肥胖升高瘦素水平。直接或间接减少脂肪组织，在控制脂肪总含量中起重要作用。
:::

:::definition{label="瘦素受体"}
结合瘦素后形成二聚体而活化，走 $\mathrm{JAK}$-$\mathrm{STAT}$，主要经 $\mathrm{STAT3}$ 发挥效应。表达部位：神经元、肝、胰腺、心肌和血管周围组织。脂肪组织本身也有受体，后文「直接调节」用这一句。
:::

:::keypoint{label="瘦素四个数字和方向"}
- 基因：肥胖基因。
- 合成部位：白色脂肪组织。
- 肽链：$146$ 个氨基酸残基。
- 方向：浓度与脂肪量成正比。
:::

:::pitfall{label="146 是氨基酸残基数，不要改成别的教材的数字"}
本版瘦素是 $146$ 个氨基酸残基。脂连蛋白是 $30\,\mathrm{kD}$ 的单分子糖蛋白，循环 $3\sim 30\,\mu\mathrm{g}/\mathrm{ml}$。两套标签不要对调，也不要用其他版本的 $167$ 或信号肽前体数字替换。
:::

:::compare{title="瘦素 vs 脂连蛋白：浓度和脂肪量"}
| | 与总脂肪量 | 肥胖时 | 不要写成 |
|--|----------|--------|---------|
| 瘦素 | 成正比 | 升高 | 「瘦了瘦素才高」 |
| 脂连蛋白 | 成反比 | 急剧降低 | 「二者都随肥胖升高」 |

这是本节最常用的反向对照。
:::

瘦素通过中枢间接调节脂肪组织脂质的存储（图27-11）。瘦素通过作用于下丘脑弓状核（arcuate nucleus，$\mathrm{ARC}$）的神经元的受体调节食欲和代谢。弓状核有神经肽 $\mathrm{Y}$／刺鼠相关蛋白（neuropeptide $\mathrm{Y}$／agouti-related peptide，$\mathrm{NPY}/\mathrm{AgRP}$）和阿黑皮素原（pro-opiomelanocortin，$\mathrm{POMC}$）两种类型的神经元。瘦素促进神经元 $\mathrm{POMC}$ 基因的转录，$\mathrm{POMC}$ 的转录产物 $\alpha$-黑色素细胞刺激素（$\alpha$-$\mathrm{MSH}$）结合室旁核（paraventricular nucleus of hypothalamus，$\mathrm{PVN}$）神经元的黑皮质素受体（melanocortin receptors，$\mathrm{MCR}$），激活神经元导致食欲抑制。$\mathrm{NPY}/\mathrm{AgRP}$ 神经元产生和释放神经肽 $\mathrm{Y}$ 和 $\mathrm{AgRP}$，可促进食欲并减少新陈代谢和能量消耗。其中，$\mathrm{AgRP}$ 肽与 $\alpha$-$\mathrm{MSH}$ 竞争性结合 $\mathrm{MCR}$，而瘦素抑制 $\mathrm{NPY}/\mathrm{AgRP}$ 的合成，进而取消 $\mathrm{AgRP}$ 对 $\mathrm{MCR}$ 的抑制作用。

:::note{label="图27-11"}
图27-11　瘦素的作用机制。电子版缺失，不嵌入图片。画面应能分出：白色脂肪组织释放瘦素 → 下丘脑弓状核 $\mathrm{POMC}$ 与 $\mathrm{NPY}/\mathrm{AgRP}$ 两群神经元 → 室旁核黑皮质素受体；另有交感传出到脂肪组织的产热支。下面用散文把两条中枢路径写清。
:::

:::definition{label="弓状核两群神经元"}
$\mathrm{POMC}$ 神经元：抑制食欲。$\mathrm{NPY}/\mathrm{AgRP}$ 神经元：促进食欲，并减少新陈代谢和能量消耗。瘦素对两群的方向相反。
:::

:::definition{label="POMC 路径抑制食欲"}
瘦素促进 $\mathrm{POMC}$ 转录 → 产物 $\alpha$-$\mathrm{MSH}$ → 结合室旁核神经元的 $\mathrm{MCR}$ → 激活该神经元 → 食欲抑制。
:::

:::definition{label="NPY/AgRP 路径促进食欲"}
神经肽 $\mathrm{Y}$ 和 $\mathrm{AgRP}$ 促进食欲、减少代谢和能量消耗。$\mathrm{AgRP}$ 与 $\alpha$-$\mathrm{MSH}$ 竞争性结合 $\mathrm{MCR}$。瘦素抑制 $\mathrm{NPY}/\mathrm{AgRP}$ 合成，从而取消 $\mathrm{AgRP}$ 对 $\mathrm{MCR}$ 的阻断，让 $\alpha$-$\mathrm{MSH}$ 能够抑制食欲。
:::

:::timeline{period="瘦素在弓状核抑制食欲的顺序"}
- **白色脂肪组织** 按脂肪量成比例释放瘦素
- **弓状核 POMC 神经元** 转录增加，产生 alpha-MSH
- **alpha-MSH** 结合室旁核神经元的黑皮质素受体，抑制食欲
- **同时** 瘦素抑制 NPY/AgRP 合成
- **AgRP 减少** 不再与 alpha-MSH 争抢黑皮质素受体，抑制食欲的通路被放开
:::

:::compare{title="弓状核两群：瘦素来了谁开谁关"}
| | 瘦素的作用 | 下游 | 对食欲 |
|--|----------|------|--------|
| $\mathrm{POMC}$ 神经元 | 促进转录 | $\alpha$-$\mathrm{MSH}$ → $\mathrm{PVN}$ 的 $\mathrm{MCR}$ | 抑制 |
| $\mathrm{NPY}/\mathrm{AgRP}$ 神经元 | 抑制合成 | $\mathrm{NPY}$ 促食欲；$\mathrm{AgRP}$ 抢 $\mathrm{MCR}$ | 促食欲这一支被关掉 |

问「瘦素怎么抑制食欲」必须两群都答：开 $\mathrm{POMC}$、关 $\mathrm{NPY}/\mathrm{AgRP}$。
:::

:::pitfall{label="AgRP 不是 alpha-MSH 的别名"}
$\mathrm{AgRP}$ 与 $\alpha$-$\mathrm{MSH}$ 竞争性结合同一类黑皮质素受体，方向相反。不要写成「$\mathrm{AgRP}$ 也是促黑激素」。$\mathrm{NPY}$ 和 $\mathrm{AgRP}$ 由同一群神经元产生，但 $\mathrm{NPY}$ 是促食欲肽，$\mathrm{AgRP}$ 是 $\mathrm{MCR}$ 的内源性拮抗剂，机制不要并成一种分子。
:::

:::insight{label="中枢这一户是「间接减少脂肪」"}
少吃、代谢和能量消耗被重设，脂肪库才会缩小。图27-11 的户头是这条间接路径。直接路径在脂肪细胞自己的瘦素受体上，下一小段才写。
:::

此外，瘦素还可刺激交感神经系统，增加血压、心率和产热，间接调节脂肪组织数量。例如，瘦素调节弓状核神经元，通过交感神经系统向脂肪和其他组织增加去甲肾上腺素的释放，通过 $\beta_3$-肾上腺素受体刺激 $\mathrm{UCP1}$ 的转录，增加棕色和米色脂肪细胞中线粒体的合成。去甲肾上腺素激活蛋白激酶 $\mathrm{A}$（protein kinase $\mathrm{A}$，$\mathrm{PKA}$），引发甘油三酯的分解，所产生的脂肪酸在线粒体中进行氧化，由于 $\mathrm{UCP1}$ 表达增加导致 $\mathrm{ATP}$ 生成与呼吸链电子传递解偶联，增加储备能量的消耗和产热。

:::definition{label="瘦素的交感支"}
刺激交感神经系统，增加血压、心率和产热，间接调节脂肪组织数量。从弓状核到脂肪：去甲肾上腺素释放增加。
:::

:::definition{label="β3-肾上腺素受体 → UCP1"}
去甲肾上腺素经 $\beta_3$-肾上腺素受体刺激 $\mathrm{UCP1}$ 转录，并增加棕色和米色脂肪细胞中的线粒体合成。
:::

:::cause-effect{title="瘦素 → 交感 → NE → PKA → 脂解；UCP1 解偶联产热"}
瘦素调节弓状核 → 交感向脂肪释放去甲肾上腺素 → $\beta_3$ 受体 → $\mathrm{UCP1}$ 转录和线粒体合成增加；同时去甲肾上腺素激活 $\mathrm{PKA}$ → 甘油三酯分解 → 脂肪酸进线粒体氧化。$\mathrm{UCP1}$ 使 $\mathrm{ATP}$ 生成与电子传递解偶联 → 储备能量变成热。
:::

:::timeline{period="瘦素增加产热的顺序"}
- **弓状核** 接到瘦素
- **交感传出** 向脂肪和其他组织释放去甲肾上腺素
- **beta3-肾上腺素受体** 刺激 UCP1 转录，增加棕色和米色细胞线粒体
- **PKA** 引发甘油三酯分解，脂肪酸进入线粒体氧化
- **UCP1 解偶联** ATP 生成与呼吸链电子传递脱钩，能量以热释放
:::

:::pitfall{label="交感支增加的是消耗和产热，不是让人多吃"}
血压、心率、产热是「多耗」；$\mathrm{POMC}$ 路径是「少吃」。两支都减少脂肪，不要把交感写成食欲中枢。
:::

:::compare{title="白色动员 vs 棕色/米色产热"}
| | 脂肪酸去向 | 关键分子 | 与瘦素的关系 |
|--|----------|---------|------------|
| 白色（循环供能） | 释放到外周 | $\mathrm{ATGL}$、$\mathrm{HSL}$ | 直接抑制脂肪生成；间接经少吃、多耗缩小库容 |
| 棕色／米色（产热） | 就地进线粒体 | $\mathrm{UCP1}$、$\beta_3$ 受体、$\mathrm{PKA}$ | 瘦素经交感把这条路打开 |

同一句「脂肪分解」，去向完全不同。
:::

瘦素也直接调节脂肪组织。脂肪组织存在瘦素受体，抑制脂肪细胞的胰岛素反应，导致胰岛素诱导的葡萄糖摄取和白色脂肪细胞脂肪生成减少。

:::definition{label="瘦素直接作用于脂肪"}
脂肪组织有瘦素受体。抑制脂肪细胞的胰岛素反应 → 胰岛素诱导的葡萄糖摄取减少，白色脂肪细胞脂肪生成减少。户头是「本地减合成」，不是再走一遍下丘脑。
:::

:::compare{title="瘦素减少脂肪的三条路"}
| 路径 | 落点 | 结果 |
|------|------|------|
| 中枢食欲 | $\mathrm{ARC}$ 的 $\mathrm{POMC}$ 与 $\mathrm{NPY}/\mathrm{AgRP}$ | 少吃 |
| 中枢交感 | 去甲肾上腺素、$\beta_3$、$\mathrm{UCP1}$ | 多耗、产热 |
| 脂肪局部 | 脂肪细胞瘦素受体 | 胰岛素反应被抑制，葡萄糖摄取和脂肪生成减少 |

问「直接还是间接」——本版标题就是「直接或间接地减少脂肪组织」，三条都要能点名。
:::

瘦素携带着脂肪储备充足的信息，减少能量物质的摄入并增加能量的消耗，调节了脂肪组织的平衡。类似于胰岛素抵抗，肥胖也会引起瘦素抵抗。

:::definition{label="瘦素是「库满」信号"}
脂肪储备充足 → 瘦素升高 → 少摄入、多消耗 → 脂肪库回到平衡。逻辑是负反馈，不是「瘦素把人催肥」。
:::

:::definition{label="瘦素抵抗"}
类似于胰岛素抵抗，肥胖也会引起瘦素抵抗。血浆瘦素已经很高，中枢和外周却不再按比例减少摄入、增加消耗。这是本版解释「瘦素在肥胖临床试验中失败」的底板——不要另编药名。
:::

:::pitfall{label="肥胖时瘦素高，不代表瘦素还能用"}
浓度与脂肪量成正比，所以肥胖者瘦素往往不低。失败原因首先是抵抗，不是「体内没有瘦素」。不要发明本版没有写的临床试验药物商品名。
:::

:::insight{label="和高胰岛素血症同一类写法"}
胰岛素抵抗时胰岛素不低；瘦素抵抗时瘦素不低。都是「信号分子很多，靶细胞不听」。思考题第 6 题走这一户。
:::

### （三）脂连蛋白调节骨骼肌和心血管功能

脂连蛋白是脂肪细胞特异性表达的脂肪分泌因子，是分子量为 $30\,\mathrm{kD}$ 的单分子糖蛋白，以三聚体、六聚体和多聚体形式存在，其中高分子量多聚体脂连蛋白活性最强。与瘦素相反，脂连蛋白的循环水平与总脂肪量成反比，肥胖、$2$ 型糖尿病（$\mathrm{T2D}$）患者的脂连蛋白血浆浓度急剧降低。脂连蛋白以高浓度存在于外周血中（$3\sim 30\,\mu\mathrm{g}/\mathrm{ml}$），占血清总蛋白的 $0.05\%$，其循环浓度与胰岛素、代谢综合征、肥胖、$\mathrm{T2D}$、心血管疾病负相关。

:::definition{label="脂连蛋白"}
脂肪细胞特异性表达的脂肪因子，单分子分子量 $30\,\mathrm{kD}$ 的糖蛋白。循环水平与总脂肪量成反比；肥胖、$2$ 型糖尿病患者血浆浓度急剧降低。有胰岛素增敏和抗炎作用。
:::

:::definition{label="寡聚体与活性"}
以三聚体、六聚体和多聚体形式存在，高分子量多聚体活性最强。不要把 $30\,\mathrm{kD}$ 写成「只有单体才有活性」。
:::

:::definition{label="循环浓度"}
外周血 $3\sim 30\,\mu\mathrm{g}/\mathrm{ml}$，占血清总蛋白的 $0.05\%$。本版强调「高浓度存在」。循环浓度与胰岛素、代谢综合征、肥胖、$\mathrm{T2D}$、心血管疾病负相关。
:::

:::keypoint{label="脂连蛋白四个数字"}
- 单分子：$30\,\mathrm{kD}$。
- 循环：$3\sim 30\,\mu\mathrm{g}/\mathrm{ml}$。
- 占血清总蛋白：$0.05\%$。
- 方向：与总脂肪量成反比。
:::

:::pitfall{label="0.05% 是占总蛋白份额，不是血糖百分数"}
$0.05\%$ 说的是占血清总蛋白；$3\sim 30\,\mu\mathrm{g}/\mathrm{ml}$ 才是浓度区间。不要写成「血清里只有 $0.05\,\mu\mathrm{g}/\mathrm{ml}$」。
:::

:::compare{title="瘦素和脂连蛋白：本版必须能对上的标签"}
| | 瘦素 | 脂连蛋白 |
|--|------|---------|
| 编码／表达 | 肥胖基因；白色脂肪组织合成 | 脂肪细胞特异性表达 |
| 分子 | $146$ 个氨基酸残基的肽激素 | $30\,\mathrm{kD}$ 糖蛋白，三聚体／六聚体／多聚体 |
| 与脂肪量 | 成正比 | 成反比 |
| 肥胖时 | 升高（可伴抵抗） | 急剧降低 |
| 主效应 | 少吃、多耗，直接抑制脂肪生成 | 胰岛素增敏、抗炎，调骨骼肌和心血管 |

命题爱把「正比／反比」对调，先把方向钉死。
:::

脂连蛋白具有胰岛素增敏和抗炎作用，通过结合靶细胞上的脂连蛋白受体 1（adiponectin receptor 1，$\mathrm{AdipoR1}$）和受体 2（adiponectin receptor 2，$\mathrm{AdipoR2}$）发挥其效应。在血管内皮和平滑肌细胞中表达的 $\mathrm{T}$-钙黏蛋白（$\mathrm{T}$-cadherin）可以促进脂连蛋白与受体的结合。$\mathrm{AdipoR1}$ 在骨骼肌、心肌等组织和内皮细胞中表达，而 $\mathrm{AdipoR2}$ 主要在肝中表达。脂连蛋白与其受体结合后，激活骨骼肌、肝、心肌和胰腺等组织的一系列下游信号，包括肝糖异生减少、肝和骨骼肌中的脂肪酸氧化增加、骨骼肌和白色脂肪组织中的葡萄糖摄取增加以及减轻炎症等。

:::definition{label="AdipoR1 和 AdipoR2"}
脂连蛋白的两种受体。$\mathrm{AdipoR1}$：骨骼肌、心肌等组织和内皮细胞。$\mathrm{AdipoR2}$：主要在肝。$\mathrm{T}$-钙黏蛋白在血管内皮和平滑肌，促进脂连蛋白与受体结合。
:::

:::definition{label="受体后的四件代谢事"}
肝糖异生减少；肝和骨骼肌脂肪酸氧化增加；骨骼肌和白色脂肪组织葡萄糖摄取增加；减轻炎症。户头已经是「增敏＋抗炎」，后面骨骼肌和心血管是展开。
:::

:::compare{title="两个脂连蛋白受体"}
| | 主要定位 | 不要写成 |
|--|---------|---------|
| $\mathrm{AdipoR1}$ | 骨骼肌、心肌、内皮 | 「只在肝」 |
| $\mathrm{AdipoR2}$ | 主要在肝 | 「骨骼肌的主受体」 |
| $\mathrm{T}$-钙黏蛋白 | 血管内皮和平滑肌，助结合 | 「第三种独立的信号受体、可以不需要 $\mathrm{AdipoR}$」 |

问「肝怎么接到脂连蛋白」先答 $\mathrm{AdipoR2}$；问「骨骼肌」先答 $\mathrm{AdipoR1}$。
:::

骨骼肌是脂连蛋白重要的作用组织之一。脂连蛋白促进骨骼肌 $\mathrm{GLUT4}$ 细胞膜转运定位，增加骨骼肌的葡萄糖摄取。脂连蛋白激活骨骼肌细胞 $\mathrm{LKB1}$-$\mathrm{AMPK}$ 信号通路，增强骨骼肌对胰岛素的敏感性。脂连蛋白还可以增加胰岛素向骨骼肌的输送而增强胰岛素的作用。脂连蛋白同时通过激活骨骼肌细胞的 $\mathrm{AMPK}$ 以促进脂肪酸氧化，减少肝脏和骨骼肌的脂肪沉积，增加甘油三酯在白色脂肪组织的储存。

:::definition{label="脂连蛋白对骨骼肌葡萄糖"}
促进 $\mathrm{GLUT4}$ 上膜，增加葡萄糖摄取；经 $\mathrm{LKB1}$-$\mathrm{AMPK}$ 增强胰岛素敏感性；还能增加胰岛素向骨骼肌的输送。三句话不要并成「只搬 $\mathrm{GLUT4}$」。
:::

:::definition{label="脂连蛋白对脂肪酸的分工"}
激活骨骼肌 $\mathrm{AMPK}$ → 脂肪酸氧化增加 → 肝和骨骼肌脂肪沉积减少，甘油三酯更多地储存在白色脂肪组织。户头是「异位脂肪减少、正位储存增加」，不是「全身都不能存脂肪」。
:::

:::cause-effect{title="脂连蛋白 → LKB1-AMPK → 糖摄取和脂肪酸氧化"}
脂连蛋白结合 $\mathrm{AdipoR1}$ → $\mathrm{LKB1}$-$\mathrm{AMPK}$ → $\mathrm{GLUT4}$ 上膜、脂肪酸氧化增强 → 骨骼肌胰岛素更敏感，肝和肌的脂肪沉积下降。
:::

:::pitfall{label="增加白色脂肪储存不是「促肥胖」"}
本版原句是减少肝和骨骼肌脂肪沉积，同时增加甘油三酯在白色脂肪组织的储存。异位脂质少了，胰岛素信号才好做。不要写成「脂连蛋白让人更胖」。
:::

:::insight{label="GLUT4 在第四节和本节都会出现"}
骨骼肌 $\mathrm{GLUT4}$ 上膜：胰岛素或运动／$\mathrm{AMPK}$ 可以做（第四节）；脂连蛋白经 $\mathrm{LKB1}$-$\mathrm{AMPK}$ 也可以做。分子相同，上游不同。心肌 $\mathrm{GLUT4}$ 是第二节的账，不要把三节并成一张图。
:::

脂连蛋白还是心血管系统关键调节者，低水平的脂连蛋白血症与不良心血管事件正相关。通过依赖于 $\mathrm{AMPK}$ 和非 $\mathrm{AMPK}$ 途径，脂连蛋白阻断多个动脉粥样硬化过程中的进展环节，可刺激血管生成以修复受损血管，抑制氧化／硝化应激、心脏肥大和间质纤维化，拮抗血栓形成，抑制心血管系统炎症，加上胰岛素增敏和代谢调控作用，发挥心血管保护作用。

:::definition{label="低脂连蛋白血症"}
血浆脂连蛋白低。与不良心血管事件正相关——脂连蛋白越低，事件风险越高。和前面「循环浓度与心血管疾病负相关」是同一方向的两种说法。
:::

:::definition{label="脂连蛋白的心血管保护"}
$\mathrm{AMPK}$ 依赖和非依赖两条路都有。本版点名：阻断动脉粥样硬化进展、刺激血管生成修复、抑制氧化／硝化应激、抑制心脏肥大和间质纤维化、拮抗血栓、抑制心血管炎症，再加上胰岛素增敏和代谢调控。
:::

:::keypoint{label="心血管保护不要只背 AMPK"}
教材写明「依赖于 $\mathrm{AMPK}$ 和非 $\mathrm{AMPK}$ 途径」。只答 $\mathrm{AMPK}$ 会漏掉另一半。
:::

:::pitfall{label="负相关和正相关不要读反"}
脂连蛋白浓度与心血管疾病负相关；低脂连蛋白血症与不良事件正相关。主语一个是「浓度」，一个是「低水平」，符号看起来相反，意思相同。
:::

## 四、热量限制具有减重和增加胰岛素敏感性等多种作用

热量限制（calorie restriction，$\mathrm{CR}$）是指在不造成营养不良的情况下长期减少总热量摄入。热量限制导致摄入的热量小于消耗，实现减重。热量限制不仅可以减重，还是目前已知的能够延缓衰老和延长寿命的策略，推迟和降低多种与老龄相关疾病（如衰老、$\mathrm{T2D}$、肿瘤、心血管疾病）的发病。热量限制通过关键信号通路传递信息，调节机体代谢、生物钟、激素、胃肠道菌群及炎症等。

:::definition{label="热量限制"}
在不造成营养不良的前提下，长期减少总热量摄入。摄入小于消耗则减重。本版还把它写成目前已知能够延缓衰老、延长寿命的策略，并推迟／降低衰老、$\mathrm{T2D}$、肿瘤、心血管疾病等老龄相关疾病。
:::

:::pitfall{label="热量限制不是饥饿性营养不良"}
定语是「不造成营养不良」。把 $\mathrm{CR}$ 写成节食到缺乏必需营养素，后文 $\mathrm{AMPK}$、自噬和增敏胰岛素都失去前提。
:::

:::keypoint{label="CR 开篇三件事"}
- 减重：摄入 $<$ 消耗。
- 寿命与老龄相关疾病：延缓衰老、推迟 $\mathrm{T2D}$、肿瘤、心血管疾病等。
- 通路：代谢、生物钟、激素、菌群、炎症。下面分「基因表达／表观遗传」和「胰岛素敏感性」两户展开。
:::

:::insight{label="不要发明本版没有的药名"}
本节的干预是热量限制本身，以及它调动的 $\mathrm{AMPK}$、$\mathrm{mTORC1}$、$\mathrm{SIRT}$、脂连蛋白。不要把雷帕霉素、二甲双胍或其他临床试验药物写进本版正文。
:::

### （一）热量限制调控基因表达和表观遗传过程

热量限制参与基因表达的调控过程。饮食限制导致大多数常量营养素的摄入减少，包括葡萄糖、特定氨基酸和蛋白质。$\mathrm{AMPK}$ 和哺乳动物雷帕霉素靶蛋白复合物 1（mammalian target of rapamycin complex 1，$\mathrm{mTORC1}$）可感受到葡萄糖及其分解代谢物磷酸二羟丙酮的水平降低，导致 $\mathrm{AMPK}$ 活性增加和 $\mathrm{mTORC1}$ 信号转导降低。$\mathrm{AMPK}$ 影响转录因子肌细胞增强因子 2（myocyte enhancer factor 2，$\mathrm{MEF2}$）、过氧化物酶体增殖物激活受体 $\delta$（peroxisome proliferator-activated receptor $\delta$，$\mathrm{PPAR}\delta$）和过氧化物酶体增殖物激活受体 $\gamma$ 共激活因子 $1\alpha$（$\mathrm{PGC}$-$1\alpha$），参与线粒体生物发生和脂质氧化等调节。

:::definition{label="AMPK 升、mTORC1 降"}
热量限制使葡萄糖及其分解代谢物磷酸二羟丙酮降低。$\mathrm{AMPK}$ 活性增加，$\mathrm{mTORC1}$ 信号转导降低。这是本版热量限制最需要先记住的一对方向。
:::

:::definition{label="AMPK 下游的转录因子"}
$\mathrm{MEF2}$、$\mathrm{PPAR}\delta$、$\mathrm{PGC}$-$1\alpha$，参与线粒体生物发生和脂质氧化。问「$\mathrm{CR}$ 怎么改线粒体」走这一户。
:::

:::cause-effect{title="葡萄糖和磷酸二羟丙酮降低 → AMPK 升、mTORC1 降"}
饮食限制 → 葡萄糖、特定氨基酸、蛋白质减少 → 葡萄糖和磷酸二羟丙酮被 $\mathrm{AMPK}$、$\mathrm{mTORC1}$ 感知 → $\mathrm{AMPK}\uparrow$、$\mathrm{mTORC1}\downarrow$ → 线粒体生物发生和脂质氧化被推向「多耗、少合成」。
:::

葡萄糖和热量限制导致胰岛素和胰岛素样生长因子 1（insulin-like growth factor 1，$\mathrm{IGF}$-$1$）信号转导降低，从而导致 $\mathrm{PI3K}/\mathrm{mTORC2}/\mathrm{AKT}$ 信号级联反应的活性降低。$\mathrm{AKT}$ 对叉头盒蛋白 $\mathrm{O}$（forkhead box $\mathrm{O}$，$\mathrm{FOXO}$）的抑制减弱，$\mathrm{FOXO}$ 依赖性基因转录涉及脂质代谢、蛋白质结构保护、自噬、抗氧化应激和 $\mathrm{DNA}$ 修复。

:::definition{label="胰岛素/IGF-1 下降"}
热量限制降低胰岛素和 $\mathrm{IGF}$-$1$ 信号 → $\mathrm{PI3K}/\mathrm{mTORC2}/\mathrm{AKT}$ 级联活性降低。
:::

:::definition{label="FOXO 依赖性转录"}
$\mathrm{AKT}$ 放松之后，$\mathrm{FOXO}$ 依赖性基因转录涉及脂质代谢、蛋白质结构保护、自噬、抗氧化应激和 $\mathrm{DNA}$ 修复。这些是保护性程序，不是把转录关掉。
:::

:::pitfall{label="AKT 降低不是把 FOXO 一起关掉"}
$\mathrm{AKT}$ 平常磷酸化抑制 $\mathrm{FOXO}$。热量限制让 $\mathrm{AKT}$ 降下来，$\mathrm{FOXO}$ 才转出自噬、抗氧化和 $\mathrm{DNA}$ 修复这批基因。写成「$\mathrm{CR}$ 抑制 $\mathrm{FOXO}$ 所以不自噬」，和教材列出的功能清单相反。
:::

热量限制还参与表观遗传调控过程。甲硫氨酸、支链氨基酸或蛋白质水平的降低同样会抑制 $\mathrm{mTORC1}$ 信号转导，$\mathrm{mTORC1}$ 受到抑制后核糖体的生物发生和蛋白质合成被下调，并且增加自噬。甲硫氨酸水平降低导致代谢物 $S$-腺苷甲硫氨酸（$S$-adenosylmethionine，$\mathrm{SAM}$）水平降低，改变 $\mathrm{DNA}$ 和组蛋白甲基化。$\mathrm{AMPK}$ 的活化也涉及沉默信息调节因子 2 相关酶 1（sirtuin 1，$\mathrm{SIRT1}$）和 3（sirtuin 3，$\mathrm{SIRT3}$），这些酶有蛋白质去乙酰化酶活性，通过表观遗传调节自噬、氧化应激等过程。

:::definition{label="氨基酸不足也抑制 mTORC1"}
甲硫氨酸、支链氨基酸或蛋白质降低 → $\mathrm{mTORC1}$ 抑制 → 核糖体生物发生和蛋白质合成下调，自噬增加。葡萄糖感知和氨基酸感知都会打到 $\mathrm{mTORC1}$。
:::

:::definition{label="SAM 与甲基化"}
甲硫氨酸降低 → $\mathrm{SAM}$ 降低 → $\mathrm{DNA}$ 和组蛋白甲基化改变。这是表观遗传的「甲基供体」户。
:::

:::definition{label="SIRT1 和 SIRT3"}
$\mathrm{AMPK}$ 活化涉及这两种去乙酰化酶，表观遗传地调节自噬和氧化应激。后文热量限制增敏胰岛素还会再碰到 $\mathrm{SIRT1}$。
:::

:::compare{title="热量限制打到的两条感知器"}
| 感知什么 | 方向 | 下游 |
|---------|------|------|
| 葡萄糖、磷酸二羟丙酮 | $\mathrm{AMPK}\uparrow$，$\mathrm{mTORC1}\downarrow$ | $\mathrm{MEF2}$、$\mathrm{PPAR}\delta$、$\mathrm{PGC}$-$1\alpha$；线粒体生物发生、脂质氧化 |
| 甲硫氨酸、支链氨基酸、蛋白质 | $\mathrm{mTORC1}\downarrow$ | 蛋白合成↓、自噬↑；$\mathrm{SAM}$ 降 → 甲基化改变 |
| $\mathrm{AMPK}$ 还牵 | $\mathrm{SIRT1}$、$\mathrm{SIRT3}$ | 去乙酰化，调自噬和氧化应激 |

问「$\mathrm{CR}$ 为什么能延寿」不要只答「吃得少」，要把这对激酶／复合物的方向说出来。
:::

:::timeline{period="热量限制改写代谢程序的顺序"}
- **总热量下降且不造成营养不良**
- **葡萄糖和磷酸二羟丙酮降低**，AMPK 活性增加、mTORC1 信号降低
- **胰岛素和 IGF-1 降低**，PI3K/mTORC2/AKT 放松，FOXO 转出保护性基因
- **甲硫氨酸等不足** 进一步抑制 mTORC1，SAM 下降改变甲基化
- **SIRT1、SIRT3** 去乙酰化，调节自噬和氧化应激
:::

### （二）热量限制增加胰岛素敏感性

胰岛素诱导胰岛素敏感组织（如骨骼肌、脂肪和心肌）的葡萄糖摄取，抑制肝、肾和小肠中的葡萄糖产生，控制血糖。当胰岛素敏感组织对胰岛素的反应性降低，就会发生胰岛素抵抗。肥胖、炎症、线粒体功能障碍、高胰岛素血症、脂毒性／高脂血症、遗传因素、内质网应激和衰老参与胰岛素抵抗。热量限制通过调节激素水平、胰岛素信号通路以及慢性炎症等机制提高胰岛素敏感性。

:::definition{label="胰岛素的两头"}
一头：诱导骨骼肌、脂肪、心肌摄取葡萄糖。另一头：抑制肝、肾和小肠产生葡萄糖。敏感性下降就是胰岛素抵抗。
:::

:::definition{label="本版点名的抵抗原因"}
肥胖、炎症、线粒体功能障碍、高胰岛素血症、脂毒性／高脂血症、遗传因素、内质网应激和衰老。热量限制从激素、受体后信号、炎症三条去对冲。
:::

:::pitfall{label="肾和小肠也会产糖，不要写成只有肝"}
本版写抑制「肝、肾和小肠」的葡萄糖产生。第三节已经立过肾是糖异生器官之一。写成「只有肝异生」，和本章前三节打架。
:::

热量限制调节激素水平。热量限制能降低循环血中胰岛素、$\mathrm{IGF}$-$1$ 和葡萄糖的水平，从而改善胰岛素的敏感性。热量限制也能减少氧自由基的生成和非酶糖基化修饰，进一步减少葡萄糖增加对蛋白质的破坏。此外，热量限制提高循环系统中脂连蛋白的水平，增强胰岛素敏感性并降低炎症引起的胰岛素抵抗。脂连蛋白受体被激活后，激活下游的代谢调节因子 $\mathrm{AMPK}$，促进 $\mathrm{NAD}^{+}$ 补救通路的重要酶烟酰胺磷酸核糖转移酶（nicotinamide phosphoribosyltransferase，$\mathrm{NAMPT}$）的表达，激活 $\mathrm{NAD}^{+}$ 依赖的去乙酰化酶 $\mathrm{SIRT1}$，正调节 $\mathrm{PGC}$-$1\alpha$。这四种代谢调节因子的表达水平均上调，共同增强了胰岛素信号。热量限制还可降低血清瘦素水平，从而抑制性腺轴、生长轴和甲状腺轴，激活肾上腺轴，增加能量消耗。

:::definition{label="CR 降低胰岛素、IGF-1 和葡萄糖"}
循环水平下降，胰岛素敏感性改善；氧自由基和非酶糖基化也减少，蛋白质少受高糖破坏。
:::

:::definition{label="CR 提高脂连蛋白"}
循环脂连蛋白升高 → 增敏胰岛素、减轻炎症引起的抵抗。肥胖时脂连蛋白本来就低，热量限制把这一户往回拉。
:::

:::definition{label="四种代谢调节因子"}
脂连蛋白受体激活后：$\mathrm{AMPK}$、$\mathrm{NAMPT}$、$\mathrm{SIRT1}$、$\mathrm{PGC}$-$1\alpha$ 均上调，共同增强胰岛素信号。$\mathrm{NAMPT}$ 是 $\mathrm{NAD}^{+}$ 补救通路的重要酶，$\mathrm{SIRT1}$ 依赖 $\mathrm{NAD}^{+}$。
:::

:::cause-effect{title="脂连蛋白受体 → AMPK → NAMPT → SIRT1 → PGC-1α"}
热量限制升高脂连蛋白 → 受体激活 → $\mathrm{AMPK}$ → 诱导 $\mathrm{NAMPT}$ → $\mathrm{NAD}^{+}$ 补救增强 → 激活 $\mathrm{SIRT1}$ → 正调节 $\mathrm{PGC}$-$1\alpha$ → 胰岛素信号增强。
:::

:::definition{label="CR 降低血清瘦素"}
瘦素随脂肪量下降而降低，进而抑制性腺轴、生长轴和甲状腺轴，激活肾上腺轴，增加能量消耗。户头是「轴的再分配」，不是「瘦素抵抗被药治好了」。
:::

:::compare{title="热量限制时瘦素和脂连蛋白怎么走"}
| | 热量限制时 | 对胰岛素／能量 |
|--|----------|--------------|
| 脂连蛋白 | 循环水平提高 | 增敏、抗炎；拉开 $\mathrm{AMPK}$-$\mathrm{NAMPT}$-$\mathrm{SIRT1}$-$\mathrm{PGC}$-$1\alpha$ |
| 瘦素 | 血清水平降低 | 抑制性腺／生长／甲状腺轴，激活肾上腺轴，增加消耗 |

肥胖本身：瘦素高（可抵抗）、脂连蛋白低。热量限制把这对方向往生理反馈上扳。
:::

:::pitfall{label="四种调节因子不要漏 NAMPT"}
只背 $\mathrm{AMPK}$ 和 $\mathrm{SIRT1}$ 会漏 $\mathrm{NAD}^{+}$ 补救这一步。教材把 $\mathrm{NAMPT}$ 写进「重要酶」，$\mathrm{PGC}$-$1\alpha$ 是正调节的终点之一。
:::

热量限制调节胰岛素受体信号通路，增加胰岛素敏感性。热量限制通过增加 $\mathrm{SIRT1}$ 介导的 $\mathrm{STAT3}$ 的去乙酰化修饰，增强了骨骼肌 $\mathrm{PI3K}$ 信号转导效率和胰岛素作用。此外热量限制还能降低胰岛素激活的硫氧还蛋白相互作用蛋白（thioredoxin interacting protein，$\mathrm{TXNIP}$）水平，加强葡萄糖利用过程，从而增加外周组织对胰岛素的敏感性。

:::definition{label="SIRT1 去乙酰化 STAT3"}
热量限制增加 $\mathrm{SIRT1}$ 介导的 $\mathrm{STAT3}$ 去乙酰化，增强骨骼肌 $\mathrm{PI3K}$ 信号转导效率和胰岛素作用。这一户的 $\mathrm{STAT3}$ 在骨骼肌胰岛素通路上，不要和瘦素中枢的 $\mathrm{JAK}$-$\mathrm{STAT3}$ 并成一句。
:::

:::definition{label="降低 TXNIP"}
热量限制降低胰岛素激活的 $\mathrm{TXNIP}$，加强葡萄糖利用，增加外周组织对胰岛素的敏感性。
:::

:::pitfall{label="两处 STAT3 不要并户"}
瘦素受体在神经元等组织走 $\mathrm{JAK}$-$\mathrm{STAT3}$ 管食欲和产热。热量限制在骨骼肌用 $\mathrm{SIRT1}$ 去乙酰化 $\mathrm{STAT3}$ 来增强 $\mathrm{PI3K}$。都叫 $\mathrm{STAT3}$，组织和职分不同。
:::

热量限制改善炎症指标，减轻胰岛素抵抗。热量限制降低了总白细胞数目、$\mathrm{IL}$-$1\beta$、$\mathrm{IL}$-$6$、$\mathrm{TNF}$-$\alpha$ 和血清 $\mathrm{C}$ 反应蛋白（$\mathrm{C}$-reactive protein，$\mathrm{CRP}$）的水平，还可以抑制肝促炎蛋白血清胎球蛋白-$\mathrm{A}$ 的分泌。

:::definition{label="CR 改善炎症指标"}
总白细胞数目、$\mathrm{IL}$-$1\beta$、$\mathrm{IL}$-$6$、$\mathrm{TNF}$-$\alpha$、$\mathrm{CRP}$ 下降；肝促炎蛋白血清胎球蛋白-$\mathrm{A}$ 分泌被抑制。慢性炎症是胰岛素抵抗的原因之一，炎症指标下降有助于增敏。
:::

:::compare{title="热量限制增敏胰岛素的三板斧"}
| 板斧 | 本版机制 | 不要写成 |
|------|---------|---------|
| 激素 | 胰岛素、$\mathrm{IGF}$-$1$、葡萄糖下降；脂连蛋白升；瘦素降 | 「只降胰岛素」 |
| 受体后信号 | $\mathrm{SIRT1}$ 去乙酰化 $\mathrm{STAT3}$ 增强骨骼肌 $\mathrm{PI3K}$；$\mathrm{TXNIP}$ 下降 | 「只增加胰岛素分泌」——分泌不是这节的主句 |
| 炎症 | 白细胞、$\mathrm{IL}$-$1\beta$、$\mathrm{IL}$-$6$、$\mathrm{TNF}$-$\alpha$、$\mathrm{CRP}$、胎球蛋白-$\mathrm{A}$ 下降 | 「炎症与胰岛素无关」 |

:::

:::insight{label="本节的 IL-6 在热量限制里再次出现，仍不是肌肉因子主线"}
这里 $\mathrm{IL}$-$6$ 是被热量限制降低的炎症指标，和促炎脂肪因子名单一致，和第四节运动诱导的肌肉因子 $\mathrm{IL}$-$6$ 仍不是同一语境。
:::

:::memory{label="本节必背分户"}
- 白色：单房大脂滴、线粒体少、$\mathrm{UCP1}$ 低；脂肪酸入血。棕色：多房小脂滴、富铁线粒体、毛细血管丰富；脂肪酸就地氧化，无颤动产热。成人仍有代谢活跃的棕色脂肪；激活时全身耗能可增 $40\%\sim 80\%$。米色：混合特征，祖细胞或寒冷下由白色转变。
- 储存与动员：餐后储存；饥饿时胰岛素降、胰高血糖素等升，激活 $\mathrm{ATGL}$ 和 $\mathrm{HSL}$，释放脂肪酸和甘油。
- 瘦素：肥胖基因、白色脂肪组织、$146$ 个氨基酸；浓度与脂肪量成正比。受体二聚化，走 $\mathrm{JAK}$-$\mathrm{STAT3}$。中枢 $\mathrm{ARC}$：开 $\mathrm{POMC}$（$\alpha$-$\mathrm{MSH}$→$\mathrm{MCR}$ 抑制食欲），关 $\mathrm{NPY}/\mathrm{AgRP}$。交感／$\beta_3$／$\mathrm{UCP1}$ 产热。脂肪局部抑制胰岛素反应。肥胖引起瘦素抵抗。图27-11 电子版缺失。
- 脂连蛋白：$30\,\mathrm{kD}$，三聚体／六聚体／多聚体（高分子量最强）；循环 $3\sim 30\,\mu\mathrm{g}/\mathrm{ml}$，占血清总蛋白 $0.05\%$；与脂肪量成反比。$\mathrm{AdipoR1}$（肌、心、内皮）、$\mathrm{AdipoR2}$（肝）；$\mathrm{T}$-钙黏蛋白助结合。增敏、抗炎；$\mathrm{GLUT4}$ 上膜、$\mathrm{LKB1}$-$\mathrm{AMPK}$；心血管保护走 $\mathrm{AMPK}$ 依赖和非依赖。
- 热量限制：不造成营养不良的前提下减少总热量。$\mathrm{AMPK}\uparrow$、$\mathrm{mTORC1}\downarrow$。增敏胰岛素：激素、骨骼肌 $\mathrm{PI3K}$、炎症三条。不要发明本版没有的药名。
:::

:::keypoint{label="本节不写的四本账"}
脑的葡萄糖／酮体、递质四户和阿尔茨海默病在第一节。心肌燃料切换和心衰重编程在第二节。肾的排泄、糖异生、促红细胞生成素和维生素 $\mathrm{D}_3$ 活化在第三节。骨骼肌纤维类型、运动供能曲线和作为肌肉因子的 $\mathrm{IL}$-$6$ 在第四节。本节只把白色／棕色、瘦素、脂连蛋白和热量限制立住。
:::

## 小结

肝以外的重要器官、组织由于可获得的能量物质不同，特异性表达不同代谢物转运体和代谢酶，显现出鲜明的代谢特征以适应各自功能。这些器官、组织还可通过产生多种分泌因子，调节自身功能并进行器官组织间的信息交流。

脑主要利用葡萄糖作为主要的能量来源，特定情况下也可以利用酮体、乳酸、丙酮酸、谷氨酸和谷氨酰胺等作为补充。脑中存在特殊的神经递质合成与清除代谢途径，星形胶质细胞和神经元之间通过谷氨酸–谷氨酰胺循环协调谷氨酸和氮代谢，并参与谷胱甘肽的合成对抗氧化应激等损伤。糖脂代谢紊乱参与了阿尔茨海默病等神经退行性疾病的发生发展。

心肌 $\mathrm{ATP}$ 主要由氧化磷酸化生成，并可利用多种能量物质。心肌主要利用脂肪酸和葡萄糖，其中成人心脏主要消耗脂肪酸，胎儿依赖于葡萄糖的分解，运动时可利用乳酸，在禁食等情况下心脏可利用酮体和支链氨基酸。优势效应调节心肌对葡萄糖和脂肪酸的利用比例。心力衰竭时发生代谢重编程，肌酸磷酸与 $\mathrm{ATP}$ 比率下降，减少脂肪酸的氧化，同时增加葡萄糖和酮体的利用。

肾利用葡萄糖和脂肪酸作为自身能量来源，其中皮层利用脂肪酸或酮体，肾单位远端部分更多地使用糖酵解生成 $\mathrm{ATP}$，导致乳酸生成。肾还是糖异生的器官之一。肾重吸收部分代谢物，包括葡萄糖和氨基酸。肾参与肾素、前列腺素、激肽、促红细胞生成素的生成以及维生素 $\mathrm{D}_3$ 活化，对其他器官代谢具有广泛影响。

骨骼肌可分为红色或慢肌纤维和白色或快肌纤维两种，具备不同代谢特征。骨骼肌中有多个 $\mathrm{ATP}$ 合成途径来供能，骨骼肌主要能量来源是肌糖原、血糖、骨骼肌的脂肪酸和脂肪组织的甘油三酯。运动能量供给受细胞外能量物质的可用性、运动强度以及持续时间影响，受到 $\mathrm{AMP}$ 等关键分子和激素的调节。运动可以预防肥胖和糖尿病。

脂肪组织分为白色和棕色两种类型，有不同的代谢特征，是储存和动员甘油三酯的重要组织。脂肪组织及其产生的分泌因子是影响体重的关键因素，其中瘦素抑制食欲、调控糖脂代谢、控制脂肪组织重量，脂连蛋白增敏胰岛素信号并具备抗炎作用，参与骨骼肌和心血管稳态的维持。热量限制通过调控基因表达和代谢减重并增敏胰岛素信号。

:::keypoint{label="小结五段各自对应哪一节"}
- 脑：葡萄糖为主，特殊情况酮体等；递质四户；糖脂紊乱与阿尔茨海默病——第一节。
- 心肌：氧化磷酸化；脂肪酸／葡萄糖切换；优势效应；心衰重编程与 $\mathrm{PCr}/\mathrm{ATP}$——第二节。
- 肾：皮髓质燃料不同；糖异生；重吸收；肾素、激肽、促红细胞生成素、维生素 $\mathrm{D}_3$——第三节。
- 骨骼肌：慢／快纤维；多种 $\mathrm{ATP}$ 来源；运动时程与强度——第四节。
- 脂肪：白／棕；瘦素和脂连蛋白；热量限制——本节。
:::
