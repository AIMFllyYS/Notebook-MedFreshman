# 第二节　脂质的消化与吸收

第一节把脂质写成不溶于水的大分子：甘油三酯、磷脂、胆固醇酯进不了消化酶的水相。本节写它们怎么进人体：胆汁酸盐乳化成微团，胰脂酶、辅脂酶、磷脂酶 $\mathrm{A}_2$ 和胆固醇酯酶在小肠上段水解；长链产物在肠黏膜再合成甘油三酯，与载脂蛋白组装成乳糜微粒走淋巴。短、中链走门静脉。小肠还是机体内、外脂质之间的选择性屏障。甘油三酯在体内的动员、β-氧化和再合成交给第三节。

:::concept{term="先问乳化有没有做成微团，再问产物走门静脉还是走淋巴"}
脂质不溶于水，酶在水相。没有胆汁酸盐把脂-水界面张力降下，胰脂酶即使分泌了也贴不到底物上。消化在小肠上段做成 $2$-甘油一酯、脂肪酸、溶血磷脂和胆固醇；吸收时再按碳链长度分户：短、中链水解后入门静脉，长链必须在肠黏膜再合成甘油三酯、装进乳糜微粒走淋巴。
:::

## 一、胆汁酸盐协助消化酶消化脂质

脂质（lipid）不溶于水，不能与消化酶充分接触。胆汁酸盐有较强乳化作用，能降低脂-水相间的界面张力，将脂质乳化成细小微团（micelles），使脂质消化酶吸附在乳化微团的脂-水界面，极大地增加消化酶与脂质接触面积，促进脂质消化。含胆汁酸盐的胆汁、含脂质消化酶的胰液分泌后进入十二指肠，所以小肠上段是脂质消化的主要场所。

:::definition{label="脂质消化的主要场所"}
小肠上段是脂质消化的主要场所。含胆汁酸盐的胆汁与含脂质消化酶的胰液在十二指肠汇合。
:::

:::definition{label="微团"}
微团（micelles）是胆汁酸盐乳化脂质形成的细小颗粒。消化酶吸附在乳化微团的脂-水界面上，接触面积增大，才能水解不溶于水的脂质。
:::

:::insight{label="先乳化，后水解，不是把油倒进水里等酶自己找"}
脂质不溶于水，酶在水相。胆汁酸盐降低脂-水界面张力，做成微团，酶才能站到界面上干活。把消化听成“胰脂酶直接咬整滴油”，辅脂酶锚定界面、混合微团过水屏障都没有户头。
:::

:::cause-effect{title="为什么消化主要在小肠上段而不是胃"}
- **因** 胆汁（胆汁酸盐）和胰液（脂质消化酶）都在十二指肠汇合
- **果** 乳化与酶解同时具备的场所是小肠上段
:::

胰腺分泌的脂质消化酶包括胰脂酶（pancreatic lipase）、辅脂酶（colipase）、磷脂酶 $\mathrm{A}_2$（phospholipase $\mathrm{A}_2$，$\mathrm{PLA}_2$）和胆固醇酯酶（cholesterol esterase）。胰脂酶特异水解甘油三酯 $1$、$3$ 位酯键，生成 $2$-甘油一酯（$2$-monoglyceride）及 $2$ 分子脂肪酸。辅脂酶（$M_\mathrm{r}$，$10\,\mathrm{kDa}$）在胰腺泡以酶原形式存在，分泌入十二指肠腔后被胰蛋白酶从 $\mathrm{N}$ 端水解，移去五肽而激活。辅脂酶本身不具脂酶活性，但可通过疏水键与甘油三酯结合（$K_\mathrm{d}$，$1\times 10^{-7}\,\mathrm{mol/L}$）、通过氢键与胰脂酶结合（分子比为 $1{:}1$；$K_\mathrm{d}$ 值为 $5\times 10^{-7}\,\mathrm{mol/L}$），将胰脂酶锚定在乳化微团的脂-水界面，使胰脂酶与脂肪充分接触，发挥水解脂肪的功能。辅脂酶还可防止胰脂酶在脂-水界面上变性、失活。可见，辅脂酶是胰脂酶发挥脂肪消化作用必不可少的辅助因子。

:::definition{label="胰脂酶"}
胰脂酶（pancreatic lipase）特异水解甘油三酯 $1$、$3$ 位酯键，生成 $2$-甘油一酯及 $2$ 分子脂肪酸。不水解 $2$ 位。
:::

:::definition{label="辅脂酶"}
辅脂酶（colipase，$M_\mathrm{r}\ 10\,\mathrm{kDa}$）本身不具脂酶活性，却是胰脂酶必不可少的辅助因子。胰腺泡内以酶原存在，入十二指肠后被胰蛋白酶从 $\mathrm{N}$ 端切去五肽而激活。疏水键结合甘油三酯（$K_\mathrm{d}=1\times 10^{-7}\,\mathrm{mol/L}$），氢键 $1{:}1$ 结合胰脂酶（$K_\mathrm{d}=5\times 10^{-7}\,\mathrm{mol/L}$），把胰脂酶锚定在脂-水界面，并防止其在界面变性、失活。
:::

:::pitfall{label="辅脂酶不是另一种脂酶"}
它不水解酯键。没有它，胰脂酶贴不上乳化微团，还容易在界面变性。把辅脂酶听成“再切 $2$ 位的酶”，产物就变成游离甘油，和后面肠黏膜以 $2$-甘油一酯再合成甘油三酯对不上。
:::

:::pitfall{label="胰脂酶只切 1、3 位"}
产物是 $2$-甘油一酯，不是三分子脂肪酸加游离甘油。第三节小肠黏膜的甘油一酯途径，起点正是这个 $2$-甘油一酯。
:::

:::timeline{period="辅脂酶从酶原到把胰脂酶钉在界面"}
- **胰腺泡** 辅脂酶以酶原形式存在
- **十二指肠腔** 胰蛋白酶从 N 端水解，移去五肽而激活
- **结合甘油三酯** 疏水键，Kd 为 1e-7 mol/L
- **结合胰脂酶** 氢键，分子比 1:1，Kd 为 5e-7 mol/L；锚定在脂-水界面，并防变性
:::

胰磷脂酶 $\mathrm{A}_2$ 催化磷脂 $2$ 位酯键水解，生成脂肪酸（fatty acid）和溶血磷脂（lysophosphatide）。胆固醇酯酶水解胆固醇酯（cholesterol ester，$\mathrm{CE}$），生成胆固醇（cholesterol）和脂肪酸。溶血磷脂、胆固醇可协助胆汁酸盐将食物脂质乳化成更小的混合微团（mixed micelles）。这种微团体积更小，极性更大，易穿过小肠黏膜细胞表面的水屏障被黏膜细胞吸收。

:::definition{label="磷脂酶 A2"}
胰磷脂酶 $\mathrm{A}_2$（phospholipase $\mathrm{A}_2$，$\mathrm{PLA}_2$）催化磷脂 $2$ 位酯键水解，生成脂肪酸和溶血磷脂（lysophosphatide）。
:::

:::definition{label="胆固醇酯酶"}
胆固醇酯酶（cholesterol esterase）水解胆固醇酯（$\mathrm{CE}$），生成胆固醇和脂肪酸。
:::

:::definition{label="混合微团"}
混合微团（mixed micelles）由溶血磷脂、胆固醇协助胆汁酸盐，把食物脂质乳化成体积更小、极性更大的微团，易穿过小肠黏膜细胞表面的水屏障被吸收。
:::

:::compare{title="胰腺四种脂质消化相关蛋白"}
| 名称 | 化学职分 | 产物 |
|------|----------|------|
| 胰脂酶 | 水解甘油三酯 $1$、$3$ 位酯键 | $2$-甘油一酯 $+\,2$ 分子脂肪酸 |
| 辅脂酶 | 无脂酶活性；锚定胰脂酶、防变性 | — |
| 磷脂酶 $\mathrm{A}_2$ | 水解磷脂 $2$ 位 | 脂肪酸 $+$ 溶血磷脂 |
| 胆固醇酯酶 | 水解胆固醇酯 | 胆固醇 $+$ 脂肪酸 |
:::

:::insight{label="消化产物回头帮乳化"}
溶血磷脂和胆固醇不是消化完就结束，它们协助胆汁酸盐做成更小、更极性的混合微团，才能过黏膜表面的水屏障。乳化 → 水解 → 产物加强乳化，是同一条吸收前通路。
:::

:::compare{title="微团和混合微团"}
| 项目 | 微团（micelles） | 混合微团（mixed micelles） |
|------|------------------|----------------------------|
| 何时出现 | 消化开始，胆汁酸盐乳化食物脂质 | 水解已经产生溶血磷脂、胆固醇之后 |
| 组成印象 | 胆汁酸盐 $+$ 尚未充分水解的脂质 | 胆汁酸盐 $+$ 溶血磷脂 $+$ 胆固醇 $+$ 其他消化产物 |
| 体积／极性 | 细小，供酶吸附在脂-水界面 | 更小、极性更大 |
| 下一步 | 胰脂酶、$\mathrm{PLA}_2$、胆固醇酯酶在界面水解 | 穿过小肠黏膜细胞表面的水屏障，进入吸收 |
:::

胆汁酸盐来自肝，胆固醇在肝转变为胆汁酸（第一节已点名）。胰液提供酶。二者缺一，脂质就停在“不溶于水、酶够不着”的状态。辅脂酶把胰脂酶钉在界面上，是乳化之后、水解能够发生的最后一颗钉子。

:::example{label="没有辅脂酶时胰脂酶在界面上会怎样"}
辅脂酶本身不切酯键，但缺少它有两笔失败：胰脂酶不能 $1{:}1$ 锚定在乳化微团的脂-水界面，与甘油三酯接触不充分；即使碰到界面，也容易变性、失活。教材因此把辅脂酶写成“必不可少的辅助因子”，不是可有可无的保护蛋白。
:::

:::keypoint{label="消化阶段三句话"}
- 场所：小肠上段（胆汁 $+$ 胰液入十二指肠）。
- 乳化：胆汁酸盐做微团；溶血磷脂、胆固醇再做成混合微团。
- 酶：胰脂酶切甘油三酯 $1$、$3$ 位，辅脂酶必不可少；$\mathrm{PLA}_2$ 切磷脂 $2$ 位；胆固醇酯酶切胆固醇酯。
:::

## 二、吸收的脂质经再合成进入血循环

脂质及其消化产物主要在十二指肠下段及空肠上段吸收。食入的脂质含少量由中（$6\sim 10\,\mathrm{C}$）、短（$2\sim 4\,\mathrm{C}$）链脂肪酸构成的甘油三酯，它们经胆汁酸盐乳化后可直接被肠黏膜细胞摄取，继而在细胞内脂肪酶作用下，水解成脂肪酸及甘油（glycerol），通过门静脉进入血循环。脂质消化产生的长链（$12\sim 26\,\mathrm{C}$）脂肪酸、$2$-甘油一酯、胆固醇和溶血磷脂等，在小肠进入肠黏膜细胞。长链脂肪酸在小肠黏膜细胞首先被转化成脂肪酰 $\mathrm{CoA}$（acyl $\mathrm{CoA}$），再在滑面内质网脂肪酰 $\mathrm{CoA}$ 转移酶（acyl $\mathrm{CoA}$ transferase）催化下，由 $\mathrm{ATP}$ 供能，被转移至 $2$-甘油一酯羟基上，重新合成甘油三酯。再与粗面内质网上合成的载脂蛋白（apolipoprotein，$\mathrm{apo}$） $\mathrm{B}48$、$\mathrm{C}$、$\mathrm{AI}$、$\mathrm{AIV}$ 等及磷脂、胆固醇共同组装成乳糜微粒（chylomicron，$\mathrm{CM}$），被肠黏膜细胞分泌、经淋巴系统进入血液循环。

:::definition{label="脂质吸收的主要部位"}
脂质及其消化产物主要在十二指肠下段及空肠上段吸收。消化在小肠上段，吸收略向远端挪到十二指肠下段和空肠上段。
:::

:::definition{label="短、中链甘油三酯的吸收"}
由短链（$2\sim 4\,\mathrm{C}$）、中链（$6\sim 10\,\mathrm{C}$）脂肪酸构成的甘油三酯，经胆汁酸盐乳化后可直接被肠黏膜细胞摄取，在细胞内脂肪酶作用下水解成脂肪酸及甘油，通过门静脉进入血循环。不走乳糜微粒，不走淋巴。
:::

:::definition{label="长链产物的再合成"}
长链（$12\sim 26\,\mathrm{C}$）脂肪酸、$2$-甘油一酯、胆固醇和溶血磷脂进入肠黏膜细胞。长链脂肪酸先变成脂肪酰 $\mathrm{CoA}$，再由滑面内质网脂肪酰 $\mathrm{CoA}$ 转移酶、$\mathrm{ATP}$ 供能，把脂肪酰基转到 $2$-甘油一酯羟基上，重新合成甘油三酯。
:::

:::definition{label="乳糜微粒"}
乳糜微粒（chylomicron，$\mathrm{CM}$）由再合成的甘油三酯与粗面内质网上合成的载脂蛋白 $\mathrm{apo}\ \mathrm{B}48$、$\mathrm{C}$、$\mathrm{AI}$、$\mathrm{AIV}$ 等及磷脂、胆固醇共同组装。肠黏膜细胞分泌后经淋巴系统进入血液循环。
:::

:::compare{title="短中链走门静脉，长链走淋巴"}
| 项目 | 短链 $2\sim 4\,\mathrm{C}$、中链 $6\sim 10\,\mathrm{C}$ | 长链 $12\sim 26\,\mathrm{C}$ |
|------|----------------------------------------------------------|------------------------------|
| 入细胞 | 乳化后整分子甘油三酯可直接被摄取 | 消化产物：长链脂肪酸、$2$-甘油一酯、胆固醇、溶血磷脂 |
| 细胞内 | 脂肪酶水解成脂肪酸及甘油 | 长链脂肪酸 → 脂肪酰 $\mathrm{CoA}$，再酯化 $2$-甘油一酯成甘油三酯 |
| 出细胞 | 门静脉 | 组装 $\mathrm{CM}$，经淋巴入血 |
| 载脂蛋白 | 不走 $\mathrm{CM}$ | $\mathrm{apo}\ \mathrm{B}48$、$\mathrm{C}$、$\mathrm{AI}$、$\mathrm{AIV}$ 等 |
:::

:::timeline{period="长链脂质从肠腔到淋巴"}
- **消化** 胰脂酶等在小肠上段做成 2-甘油一酯、长链脂肪酸、胆固醇、溶血磷脂
- **混合微团过水屏障** 十二指肠下段及空肠上段进入肠黏膜细胞
- **再酯化** 脂肪酰 CoA 转移酶把脂肪酰基转到 2-甘油一酯，滑面内质网合成甘油三酯
- **组装 CM** 加上粗面内质网的 apo B48、C、AI、AIV 及磷脂、胆固醇
- **分泌入淋巴** 再进入血液循环
:::

:::pitfall{label="吸收不是把消化产物直接倒进门静脉"}
长链必须在肠黏膜再合成甘油三酯、装进乳糜微粒、走淋巴。只有短、中链那一小部分乳化后入细胞、水解，才走门静脉。把“脂肪吸收＝门静脉”当成全貌，$\mathrm{CM}$ 和 $\mathrm{apo}\ \mathrm{B}48$ 会没有户头。
:::

:::pitfall{label="apo B48 是肠的，不要写成 B100"}
本节组装乳糜微粒点名 $\mathrm{apo}\ \mathrm{B}48$、$\mathrm{C}$、$\mathrm{AI}$、$\mathrm{AIV}$。第三节肝输出极低密度脂蛋白点名 $\mathrm{apo}\ \mathrm{B}100$、$\mathrm{C}$。$\mathrm{B}48$ 对肠、$\mathrm{B}100$ 对肝，不要并户。
:::

碳链长度在本节是吸收路径的钥匙，不是可有可无的括号。短链 $2\sim 4$ 碳、中链 $6\sim 10$ 碳的甘油三酯可以整分子被摄取再在细胞内水解，产物走门静脉；长链从 $12$ 碳起，一直写到 $26$ 碳，必须先在肠腔被胰脂酶等切成 $2$-甘油一酯和脂肪酸，入细胞后再酯化、组装 $\mathrm{CM}$。把“中链”听成 $12$ 碳，会把本该走淋巴的分子错送到门静脉。

:::keypoint{label="碳链长度与去路"}
- 短链 $2\sim 4\,\mathrm{C}$、中链 $6\sim 10\,\mathrm{C}$：乳化 → 入肠黏膜 → 细胞内脂肪酶水解 → 脂肪酸及甘油 → 门静脉。
- 长链 $12\sim 26\,\mathrm{C}$：消化产物入细胞 → 脂肪酰 $\mathrm{CoA}$ → 再酯化 $2$-甘油一酯 → 与磷脂、胆固醇、载脂蛋白组装 $\mathrm{CM}$ → 淋巴 → 血。
- 胆固醇和溶血磷脂随长链产物一起入细胞，并参与混合微团和 $\mathrm{CM}$ 组装。
:::

滑面内质网负责把脂肪酰基装回甘油三酯，粗面内质网负责合成 $\mathrm{apo}\ \mathrm{B}48$、$\mathrm{C}$、$\mathrm{AI}$、$\mathrm{AIV}$。缺少载脂蛋白，再合成的甘油三酯出不了细胞，和第三节肝细胞缺少 $\mathrm{apo}\ \mathrm{B}100$ 时装不成 $\mathrm{VLDL}$、甘油三酯堆在肝里，是同一类“合成得出、组装运不走”的账，只是本节的运载颗粒叫乳糜微粒。

:::insight{label="滑面内质网再酯化，粗面内质网出载脂蛋白"}
脂肪酰 $\mathrm{CoA}$ 转移酶在滑面内质网把链装回甘油三酯；载脂蛋白在粗面内质网合成。两套内质网分工，才能装出 $\mathrm{CM}$。只记“肠细胞再合成”，分泌通路会对不上。
:::

:::example{label="为什么胰脂酶留下 2 位"}
胰脂酶特异切 $1$、$3$ 位，留下 $2$-甘油一酯。肠黏膜不需要从游离甘油重新做骨架，只要脂肪酰 $\mathrm{CoA}$ 转移酶把两条链装回去。第三节把这条路称为甘油一酯途径，与肝、脂肪组织的甘油二酯途径分户。
:::

## 三、脂质消化吸收在维持机体脂质平衡中具有重要作用

体内脂质过多，尤其是饱和脂肪酸、胆固醇过多，在肥胖（obesity）、高脂血症（hyperlipidemia）、动脉粥样硬化（atherosclerosis）、$2$ 型糖尿病（type 2 diabetes mellitus，$\mathrm{T}2\mathrm{DM}$）、高血压（hypertension）和癌（cancer）等发生中具有重要作用。小肠被认为是介于机体内、外脂质间的选择性屏障。脂质通过该屏障过多会导致其在体内堆积，促进上述疾病发生。小肠的脂质消化、吸收能力具有很大可塑性。脂质本身可刺激小肠、增强脂质消化吸收能力。这不仅能促进摄入增多时脂质的消化吸收，保障体内能量、必需脂肪酸（essential fatty acids）、脂溶性维生素供应，也能增强机体对食物缺乏环境的适应能力。小肠脂质消化吸收能力调节的分子机制可能涉及小肠特殊的分泌物质或特异的基因表达产物，可能是预防体脂过多、治疗相关疾病、开发新药物、采用膳食干预措施的新靶标。

:::definition{label="小肠作为内外脂质的选择性屏障"}
小肠介于机体内、外脂质之间，是选择性屏障。脂质通过该屏障过多会在体内堆积，促进肥胖、高脂血症、动脉粥样硬化、$2$ 型糖尿病、高血压和癌等发生。
:::

:::insight{label="消化吸收能力是可塑的，脂质自己会加码"}
脂质本身可刺激小肠、增强消化吸收能力。摄入增多时能保障能量、必需脂肪酸、脂溶性维生素；食物缺乏时也能增强适应。屏障不是固定孔径，而是可调的。
:::

:::keypoint{label="平衡账的两面"}
- 过多、尤其饱和脂肪酸和胆固醇过多：肥胖、高脂血症、动脉粥样硬化、$\mathrm{T}2\mathrm{DM}$、高血压、癌。
- 过少也不行：能量、必需脂肪酸、脂溶性维生素要靠这条吸收通路。
- 调节机制可能涉及小肠特殊分泌物质或特异基因表达产物，是预防体脂过多、治疗相关疾病、新药和膳食干预的潜在靶标。
:::

:::pitfall{label="屏障不是“吸收越少越好”"}
教材同时写：通过过多会堆积致病；能力增强又能在摄入多时保障供应、在缺乏时适应。把小肠听成只负责拦脂肪，必需脂肪酸和脂溶性维生素会没有入口。
:::

第一节把亚油酸、$\alpha$-亚麻酸写成必须从植物食物获得的必需脂肪酸，脂溶性维生素的吸收也依赖脂质微团。本节的消化吸收通路因此不只是“把甘油三酯变成体内脂肪”，还是必需脂肪酸和脂溶性维生素的入口。饱和脂肪酸、胆固醇通过屏障过多，才是肥胖、高脂血症、动脉粥样硬化、$2$ 型糖尿病、高血压和癌那一本致病账。

调节的分子机制教材只写到“可能涉及小肠特殊的分泌物质或特异的基因表达产物”，没有点名具体激素或转运体。把它当成已经查清的单一靶点，会超出本版。能落实的是：能力可塑、脂质本身可刺激增强、因而既是适应饥饿的手段，也是体脂过多时值得干预的关口。

:::tip{label="本节和第三节交接的三张颗粒"}
消化吸收出门的是乳糜微粒（$\mathrm{apo}\ \mathrm{B}48$ 等，走淋巴）。第三节肝合成甘油三酯出门的是 $\mathrm{VLDL}$（$\mathrm{apo}\ \mathrm{B}100$、$\mathrm{C}$ 等）。动员出门的是清蛋白结合的游离脂肪酸。三张颗粒不要并成“血脂”一口。
:::

:::compare{title="本节三块在消化道上的位置"}
| 阶段 | 部位 | 关键事件 |
|------|------|----------|
| 消化 | 小肠上段（十二指肠汇合胆汁与胰液） | 胆汁酸盐乳化；胰脂酶／辅脂酶／$\mathrm{PLA}_2$／胆固醇酯酶水解 |
| 吸收 | 十二指肠下段及空肠上段 | 短中链走门静脉；长链再合成 $\mathrm{CM}$ 走淋巴 |
| 平衡 | 小肠整体作为选择性屏障 | 可塑的消化吸收能力；过多则堆积，过少则缺能量／必需脂肪酸／脂溶性维生素 |
:::

:::memory{label="本节必背要点"}
- [ ] 脂质不溶于水，先靠胆汁酸盐乳化成微团，酶才能在脂-水界面水解
- [ ] 消化主要在小肠上段；吸收主要在十二指肠下段及空肠上段
- [ ] 胰脂酶切甘油三酯 $1$、$3$ 位 → $2$-甘油一酯 $+\,2$ 脂肪酸
- [ ] 辅脂酶 $M_\mathrm{r}\ 10\,\mathrm{kDa}$，本身无脂酶活性，胰蛋白酶切 $\mathrm{N}$ 端五肽激活；$1{:}1$ 锚定胰脂酶
- [ ] $\mathrm{PLA}_2$ 切磷脂 $2$ 位 → 溶血磷脂；胆固醇酯酶 → 胆固醇 $+$ 脂肪酸
- [ ] 溶血磷脂、胆固醇协助做成更小、更极性的混合微团，过水屏障
- [ ] 短 $2\sim 4\,\mathrm{C}$、中 $6\sim 10\,\mathrm{C}$：入细胞水解，走门静脉
- [ ] 长 $12\sim 26\,\mathrm{C}$：再合成甘油三酯，与 $\mathrm{apo}\ \mathrm{B}48$、$\mathrm{C}$、$\mathrm{AI}$、$\mathrm{AIV}$ 等组装 $\mathrm{CM}$，走淋巴
- [ ] 小肠是内外脂质选择性屏障；能力可塑；饱和脂肪酸、胆固醇过多与肥胖、高脂血症、动脉粥样硬化、$\mathrm{T}2\mathrm{DM}$、高血压、癌相关
:::
