# 第二节　水溶性维生素

本节把水溶性维生素写成溶于水、体内很少蓄积、主要作为酶辅因子的那一本账：B 族八种加维生素 C。先按活性形式立户——$\mathrm{TPP}$、$\mathrm{FMN}/\mathrm{FAD}$、$\mathrm{NAD}^{+}/\mathrm{NADP}^{+}$、$\mathrm{CoA}/\mathrm{ACP}$、生物素、磷酸吡哆醛、$\mathrm{FH}_{4}$、甲钴胺素与 $5'$-脱氧腺苷钴胺素、抗坏血酸——再写缺乏症：脚气病、口角炎、糙皮病 3D、巨幼细胞贫血、恶性贫血、坏血病。章末收本章小结和思考题，到此为止。

水溶性维生素是一类溶于水而不溶于脂肪和有机溶剂的有机分子，在体内主要成酶的辅因子（cofactor），包括 B 族维生素（$\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{PP}$、泛酸、生物素、$\mathrm{B}_{6}$、叶酸与 $\mathrm{B}_{12}$）和维生素 C。水溶性维生素依赖食物提供，体内很少蓄积，过多的水溶性维生素可随尿排出体外，一般不发生中毒现象，但供给不足时往往导致缺乏症。

:::definition{label="水溶性维生素"}
水溶性维生素是一类溶于水而不溶于脂肪和有机溶剂的有机分子，在体内主要成酶的辅因子（cofactor），包括 B 族维生素（$\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{PP}$、泛酸、生物素、$\mathrm{B}_{6}$、叶酸与 $\mathrm{B}_{12}$）和维生素 C。
:::

:::definition{label="辅因子"}
辅因子（cofactor）是本节给水溶性维生素的功能落点：B 族多以辅酶或辅基形式参加酶促反应；维生素 C 还另写羟化酶辅因子和强抗氧化剂。
:::

:::compare{title="水溶性维生素与第一节脂溶性对照"}
| 项目 | 水溶性（本节） | 脂溶性（第一节） |
|------|----------------|------------------|
| 溶解 | 溶于水，不溶于脂肪和有机溶剂 | 疏水，易溶于脂质和有机溶剂 |
| 体内去向 | 很少蓄积，过多随尿排出 | 不易排泄，主要储于肝 |
| 供给 | 依赖食物，往往需经常供给 | 不需每日供给 |
| 中毒 | 一般不发生；$\mathrm{PP}$、$\mathrm{B}_{6}$、维生素 C 教材另写了过量表现 | A、D 可中毒；E 人类尚未发现中毒症 |
| 功能主轴 | 酶的辅因子 | 视循环、钙磷、抗氧化、凝血 |
:::

:::concept{term="先问活性形式是哪种辅因子，再问缺乏落在哪条代谢"}
看见 B 族，不要先背病名。$\mathrm{B}_{1}$ 是 $\mathrm{TPP}$，$\mathrm{B}_{2}$ 是 $\mathrm{FMN}/\mathrm{FAD}$，$\mathrm{PP}$ 是 $\mathrm{NAD}^{+}/\mathrm{NADP}^{+}$，泛酸是 $\mathrm{CoA}/\mathrm{ACP}$，生物素是羧化酶， $\mathrm{B}_{6}$ 是磷酸吡哆醛，叶酸是 $\mathrm{FH}_{4}$，$\mathrm{B}_{12}$ 是甲钴胺素和 $5'$-脱氧腺苷钴胺素。病名是活性形式不够之后的临床表现。
:::

:::pitfall{label="“一般不中毒”不是“吃多少都没事”"}
水溶多余可随尿排出，教材写一般不发生中毒。后文仍有：大量烟酸或烟酰胺的血管扩张和肝损伤；日摄入维生素 $\mathrm{B}_{6}$ 超过 $20\,\mathrm{mg}$ 的周围神经病；长期过量维生素 C 增加尿路草酸盐结石危险。不要和第一节“脂溶才中毒”做成绝对对立。
:::

## 一、维生素B1 的活性形式是焦磷酸硫胺素

### （一）维生素B1 是硫胺素

维生素 $\mathrm{B}_{1}$ 由含氨基的嘧啶环和含硫的噻唑环通过亚甲基桥相连而成，又名硫胺素（thiamine）（图6-4）。维生素 $\mathrm{B}_{1}$ 主要存在于豆类和种子外皮、胚芽、酵母和瘦肉中，其纯品为白色粉末状结晶，易溶于水，微溶于乙醇。维生素 $\mathrm{B}_{1}$ 在酸性环境中较稳定、加热 $120^{\circ}\mathrm{C}$ 仍不分解；中性和碱性环境中不稳定、易被氧化和受热破坏。硫胺素易被小肠吸收，入血后主要在肝及脑组织中经硫胺素焦磷酸激酶的催化生成焦磷酸硫胺素（thiamine pyrophosphate，$\mathrm{TPP}$）。$\mathrm{TPP}$ 是维生素 $\mathrm{B}_{1}$ 的活性形式，占体内硫胺素总量的 $80\%$。

:::definition{label="维生素B1（硫胺素）"}
维生素 $\mathrm{B}_{1}$ 由含氨基的嘧啶环和含硫的噻唑环通过亚甲基桥相连而成，又名硫胺素（thiamine）。
:::

:::definition{label="焦磷酸硫胺素（TPP）"}
焦磷酸硫胺素（thiamine pyrophosphate，$\mathrm{TPP}$）由硫胺素在肝及脑组织经硫胺素焦磷酸激酶催化生成，是维生素 $\mathrm{B}_{1}$ 的活性形式，占体内硫胺素总量的 $80\%$。
:::

:::compare{title="维生素B1 的稳定条件"}
| 环境 | 教材原句 |
|------|----------|
| 酸性 | 较稳定，加热 $120^{\circ}\mathrm{C}$ 仍不分解 |
| 中性、碱性 | 不稳定，易被氧化和受热破坏 |
| 食物 | 豆类和种子外皮、胚芽、酵母和瘦肉 |
:::

:::pitfall{label="精米去的是外皮和胚芽，不是“米里没有B1”"}
后文缺乏多见于以精米为主食。$\mathrm{B}_{1}$ 在种子外皮和胚芽，精加工把这一层去掉。酸性稳定、碱性和受热易破坏，是加工和烹饪的另一笔，不要只记“吃米就会有”。
:::

### （二）维生素B1 主要参与能量代谢

维生素 $\mathrm{B}_{1}$ 在体内能量代谢中发挥重要的作用。$\mathrm{TPP}$ 是 $\alpha$-酮酸氧化脱羧酶多酶复合体的辅因子，通过转移醛基参与丙酮酸、$\alpha$-酮戊二酸和 $\alpha$-酮酸的氧化脱羧反应。$\mathrm{TPP}$ 噻唑环上硫和氮原子之间的碳原子十分活泼，易释放 $\mathrm{H}^{+}$ 形成负碳离子，后者可与 $\alpha$-酮酸羧基结合，进而使 $\alpha$-酮酸脱羧。$\mathrm{TPP}$ 也是磷酸戊糖途径中转酮醇酶的辅因子，参与转酮醇作用。

维生素 $\mathrm{B}_{1}$ 在神经传导中起一定作用。合成乙酰胆碱所需的乙酰辅酶 A 主要来自丙酮酸的氧化脱羧反应。维生素 $\mathrm{B}_{1}$ 也是胆碱酯酶抑制剂，参与乙酰胆碱的代谢调控。

:::definition{label="TPP 作为α-酮酸氧化脱羧的辅因子"}
$\mathrm{TPP}$ 是 $\alpha$-酮酸氧化脱羧酶多酶复合体的辅因子，通过转移醛基参与丙酮酸、$\alpha$-酮戊二酸等 $\alpha$-酮酸的氧化脱羧。噻唑环上硫、氮之间的碳易释放 $\mathrm{H}^{+}$ 成负碳离子，与 $\alpha$-酮酸羧基结合而脱羧。
:::

:::definition{label="TPP 作为转酮醇酶的辅因子"}
$\mathrm{TPP}$ 也是磷酸戊糖途径中转酮醇酶的辅因子，参与转酮醇作用。
:::

:::keypoint{label="维生素B1 与乙酰胆碱"}
- 合成乙酰胆碱所需的乙酰辅酶 A，主要来自丙酮酸氧化脱羧。
- 维生素 $\mathrm{B}_{1}$ 也是胆碱酯酶抑制剂，参与乙酰胆碱代谢调控。
- 缺乏时：乙酰胆碱合成障碍、分解加强 → 神经传导异常 → 消化液分泌减少、胃蠕动变慢、消化不良。
:::

:::insight{label="能量代谢和神经传导是同一条丙酮酸脱羧的两端"}
$\mathrm{TPP}$ 不够，丙酮酸氧化脱羧受阻：神经组织供能不足、髓鞘磷脂合成受阻，是脚气病；乙酰 $\mathrm{CoA}$ 来源减少再加胆碱酯酶抑制减弱，是消化方面的神经传导异常。不要把脚气病只写成“缺维生素 B₁ 的神经炎”而不写丙酮酸。
:::

### （三）维生素B1 缺乏可致脚气病

中国成人男性膳食维生素 $\mathrm{B}_{1}$ 的 RNI 为 $1.4\,\mathrm{mg}/\mathrm{d}$，成人女性为 $1.2\,\mathrm{mg}/\mathrm{d}$。维生素 $\mathrm{B}_{1}$ 缺乏多见于膳食中维生素 $\mathrm{B}_{1}$ 含量不足（如以精米为主食）。吸收障碍（如慢性消化紊乱）和需要量增加（如甲状腺功能亢进等）和酒精中毒也可导致维生素 $\mathrm{B}_{1}$ 的缺乏。

维生素 $\mathrm{B}_{1}$ 缺乏时，丙酮酸的氧化脱羧反应发生障碍，使神经组织供能不足以及神经细胞膜髓鞘磷脂合成受阻，导致慢性末梢神经炎和其他神经肌肉变性病变，即脚气病（beriberi）。严重者可致水肿、心力衰竭。

此外，维生素 $\mathrm{B}_{1}$ 缺乏使乙酰胆碱合成障碍，乙酰胆碱分解加强，导致神经传导异常，主要表现为消化液分泌减少、胃蠕动变慢、消化不良等症状。

:::definition{label="脚气病"}
脚气病（beriberi）是维生素 $\mathrm{B}_{1}$ 缺乏所致：丙酮酸氧化脱羧障碍 → 神经组织供能不足、神经细胞膜髓鞘磷脂合成受阻 → 慢性末梢神经炎和其他神经肌肉变性病变。严重者可致水肿、心力衰竭。
:::

:::cause-effect{title="哪些情况会缺维生素B1"}
- **因** 膳食含量不足（精米为主食）；吸收障碍（慢性消化紊乱）；需要量增加（甲状腺功能亢进等）；酒精中毒
- **果** $\mathrm{TPP}$ 不足 → 丙酮酸氧化脱羧障碍 → 脚气病；并可有消化液减少、胃蠕动变慢、消化不良
:::

:::pitfall{label="脚气病不是皮肤科的脚气"}
教材病名是脚气病（beriberi），机制在丙酮酸氧化脱羧和神经髓鞘。皮肤科俗称的“脚气”是足癣，与本节无关。思考题“试述脚气和脚气病的区别”，先把 beriberi 写全，不要写成脚上的真菌感染。
:::

## 二、维生素B2 的活性形式是FMN 和FAD

### （一）维生素B2 是核黄素

维生素 $\mathrm{B}_{2}$ 是核醇与 6,7-二甲基异咯嗪的缩合物，因其呈黄色针状结晶，又名核黄素（riboflavin）。维生素 $\mathrm{B}_{2}$ 在酸性溶液中稳定，在碱性溶液中加热易破坏，但对紫外线敏感，易降解为无活性的产物。奶与奶制品、肝、蛋类和肉类等是维生素 $\mathrm{B}_{2}$ 的丰富来源。核黄素主要在小肠上段通过转运蛋白质主动吸收。吸收后的核黄素在小肠黏膜黄素激酶的催化下转变成黄素单核苷酸（flavin mononucleotide，$\mathrm{FMN}$），后者在焦磷酸化酶的催化下生成黄素腺嘌呤二核苷酸（flavin adenine dinucleotide，$\mathrm{FAD}$），$\mathrm{FMN}$ 及 $\mathrm{FAD}$ 是维生素 $\mathrm{B}_{2}$ 的活性形式。

维生素 $\mathrm{B}_{2}$ 异咯嗪环上的第 1 和第 10 位氮原子与双键连接，此 2 个氮原子可反复接受或释放氢，因而具有可逆的氧化还原性（图6-5）。还原型核黄素及其衍生物呈黄色，于 $450\,\mathrm{nm}$ 处有吸收峰，可用于定量分析。

:::definition{label="维生素B2（核黄素）"}
维生素 $\mathrm{B}_{2}$ 是核醇与 6,7-二甲基异咯嗪的缩合物，因其呈黄色针状结晶，又名核黄素（riboflavin）。
:::

:::definition{label="FMN 与 FAD"}
吸收后的核黄素在小肠黏膜黄素激酶催化下转变成黄素单核苷酸（$\mathrm{FMN}$），再在焦磷酸化酶催化下生成黄素腺嘌呤二核苷酸（$\mathrm{FAD}$）。$\mathrm{FMN}$ 及 $\mathrm{FAD}$ 是维生素 $\mathrm{B}_{2}$ 的活性形式。
:::

- **FMN** 小肠黏膜黄素激酶把核黄素变成 FMN
- **FAD** 焦磷酸化酶再把 FMN 变成 FAD
- **递氢** 异咯嗪环第 1、第 10 位氮反复受氢或放氢

### （二）维生素B2 作为递氢体广泛参与代谢

$\mathrm{FMN}$ 及 $\mathrm{FAD}$ 是体内氧化还原酶（如脂酰 $\mathrm{CoA}$ 脱氢酶、琥珀酸脱氢酶、黄嘌呤氧化酶等）的辅因子，主要通过递氢参与呼吸链、脂肪酸和氨基酸的氧化以及三羧酸循环。

$\mathrm{FMN}$ 还参与维生素 $\mathrm{B}_{6}$ 转变为磷酸吡哆醛的反应，$\mathrm{FAD}$ 参与色氨酸转变为烟酸的过程。每分子谷胱甘肽还原酶含有一分子的 $\mathrm{FAD}$，可维持还原型谷胱甘肽的浓度。此外，$\mathrm{FAD}$ 可与细胞色素 $\mathrm{P}450$ 结合，参与药物代谢。

:::keypoint{label="FMN／FAD 递氢落在哪些酶"}
- 氧化还原酶辅因子：脂酰 $\mathrm{CoA}$ 脱氢酶、琥珀酸脱氢酶、黄嘌呤氧化酶等。
- 通路：呼吸链、脂肪酸和氨基酸氧化、三羧酸循环。
- $\mathrm{FMN}$：维生素 $\mathrm{B}_{6}$ → 磷酸吡哆醛。
- $\mathrm{FAD}$：色氨酸 → 烟酸；谷胱甘肽还原酶维持 $\mathrm{GSH}$；与细胞色素 $\mathrm{P}450$ 结合参与药物代谢。
:::

:::insight{label="B2 不够，B6 活化和 PP 的内源合成都会受牵连"}
$\mathrm{FMN}$ 参与磷酸吡哆醛生成，$\mathrm{FAD}$ 参与色氨酸变烟酸。后文 $60\,\mathrm{mg}$ 色氨酸才生成 $1\,\mathrm{mg}$ 烟酸，还需要维生素 $\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{B}_{6}$。核黄素缺乏不是孤立的口角炎。
:::

### （三）维生素B2 缺乏可导致皮肤黏膜移行部位的炎症

中国成人男性膳食维生素 $\mathrm{B}_{2}$ 的 RNI 为 $1.4\,\mathrm{mg}/\mathrm{d}$，成人女性为 $1.2\,\mathrm{mg}/\mathrm{d}$。淘米过度、牛奶多次煮沸等膳食加工不当是维生素 $\mathrm{B}_{2}$ 缺乏的主要原因，其症状包括口角炎、眼睑炎、畏光等。用光照疗法治疗新生儿黄疸时，可引起维生素 $\mathrm{B}_{2}$ 缺乏症。

:::definition{label="维生素B2 缺乏症"}
膳食加工不当（淘米过度、牛奶多次煮沸）是主要原因。症状包括口角炎、眼睑炎、畏光等。光照疗法治疗新生儿黄疸可引起维生素 $\mathrm{B}_{2}$ 缺乏症。
:::

:::pitfall{label="B2 怕碱、怕紫外，和 B1 怕碱是同一类加工账"}
酸性稳定、碱性加热易破坏，又对紫外线敏感。新生儿黄疸光疗缺的是核黄素，不是硫胺素。RNI 与 $\mathrm{B}_{1}$ 相同（男 $1.4$、女 $1.2\,\mathrm{mg}/\mathrm{d}$），病名不要对调。
:::

## 三、维生素PP 的活性形式是NAD+ 和NADP+

### （一）维生素PP 包括烟酸和烟酰胺

维生素 $\mathrm{PP}$ 包括烟酸（nicotinic acid）和烟酰胺（nicotinamide），曾分别称尼克酸和尼克酰胺，两者均属氮杂环吡啶衍生物。烟酸为吡啶-3-羧酸，很容易转变为烟酰胺。烟酸为稳定的白色针状结晶，在酸、碱、光、氧或加热条件下不易被破坏，是维生素中最稳定的一种。

维生素 $\mathrm{PP}$ 广泛存在于自然界。食物中的维生素 $\mathrm{PP}$ 均以烟酰胺腺嘌呤二核苷酸（nicotinamide adenine dinucleotide，$\mathrm{NAD}^{+}$）或烟酰胺腺嘌呤二核苷酸磷酸（nicotinamide adenine dinucleotide phosphate，$\mathrm{NADP}^{+}$）的形式存在（图6-6）。它们在小肠内被水解生成游离的维生素 $\mathrm{PP}$ 被吸收，并被运输到组织细胞再合成 $\mathrm{NAD}^{+}$ 或 $\mathrm{NADP}^{+}$。$\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$ 是维生素 $\mathrm{PP}$ 在体内的活性形式。

:::definition{label="维生素PP"}
维生素 $\mathrm{PP}$ 包括烟酸（nicotinic acid）和烟酰胺（nicotinamide），曾称尼克酸和尼克酰胺，均为氮杂环吡啶衍生物。烟酸为吡啶-3-羧酸，很容易转变为烟酰胺。它是维生素中最稳定的一种。
:::

:::definition{label="NAD+ 与 NADP+"}
$\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$ 是维生素 $\mathrm{PP}$ 在体内的活性形式。食物中维生素 $\mathrm{PP}$ 以这两种形式存在，小肠内水解成游离维生素 $\mathrm{PP}$ 吸收，再到组织细胞重新合成。
:::

未被利用的烟酸可被甲基化，以 N-甲基烟酰胺和 2-吡啶酮的形式由尿中排出。体内色氨酸代谢也可生成维生素 $\mathrm{PP}$，但效率较低，$60\,\mathrm{mg}$ 色氨酸仅能生成 $1\,\mathrm{mg}$ 烟酸，并且需要维生素 $\mathrm{B}_{1}$、维生素 $\mathrm{B}_{2}$ 和维生素 $\mathrm{B}_{6}$ 的参与。

:::definition{label="色氨酸生成烟酸"}
体内色氨酸代谢也可生成维生素 $\mathrm{PP}$，但效率较低：$60\,\mathrm{mg}$ 色氨酸仅能生成 $1\,\mathrm{mg}$ 烟酸，并且需要维生素 $\mathrm{B}_{1}$、$\mathrm{B}_{2}$ 和 $\mathrm{B}_{6}$ 参与。
:::

未被利用的烟酸可被甲基化，以 N-甲基烟酰胺和 2-吡啶酮的形式由尿中排出。水溶“过多随尿走”在 $\mathrm{PP}$ 这里有具体产物。
:::

### （二）维生素PP 是不需氧脱氢酶的辅因子

$\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$ 分子中的烟酰胺部分具有可逆的加氢及脱氢的特性，常发挥递氢体的作用。糖酵解和三羧酸循环中的一些脱氢酶以 $\mathrm{NAD}^{+}$ 为受氢体，$\mathrm{NADH}+\mathrm{H}^{+}$ 又为丙酮酸生成乳酸提供氢。磷酸戊糖途径中的 G6PD 以 $\mathrm{NADP}^{+}$ 作为受氢体进而生成 $\mathrm{NADPH}+\mathrm{H}^{+}$，$\mathrm{NADPH}+\mathrm{H}^{+}$ 又可作为供氢体参与脂肪酸、胆固醇等物质的合成。

:::definition{label="不需氧脱氢酶的辅因子"}
$\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$ 是不需氧脱氢酶的辅因子。烟酰胺部分可逆加氢、脱氢，发挥递氢体作用。
:::

:::compare{title="NAD+ 与 NADP+ 的受氢／供氢"}
| 辅因子 | 教材通路 | 下一步 |
|--------|----------|--------|
| $\mathrm{NAD}^{+}$ | 糖酵解和三羧酸循环中一些脱氢酶的受氢体 | $\mathrm{NADH}+\mathrm{H}^{+}$ 为丙酮酸生成乳酸提供氢 |
| $\mathrm{NADP}^{+}$ | 磷酸戊糖途径 G6PD 的受氢体 | $\mathrm{NADPH}+\mathrm{H}^{+}$ 作为供氢体参与脂肪酸、胆固醇等合成 |
:::

:::pitfall{label="NAD+ 主要走分解供氢，NADP+ 主要走合成供氢"}
都是维生素 $\mathrm{PP}$ 的活性形式，分工不要并成“都是递氢”。乳酸那一笔用 $\mathrm{NADH}+\mathrm{H}^{+}$；脂酸、胆固醇合成用 $\mathrm{NADPH}+\mathrm{H}^{+}$。G6PD 是磷酸戊糖途径点名的酶。
:::

### （三）维生素PP 的缺乏可致糙皮病

中国成人男性膳食维生素 $\mathrm{PP}$ 的 RNI 为 $15\,\mathrm{mg}/\mathrm{d}$ 的烟酸当量（niacin equivalent，NE），成人女性为 $12\,\mathrm{mg}\,\mathrm{NE}/\mathrm{d}$。人类维生素 $\mathrm{PP}$ 缺乏症亦称为糙皮病（pellagra），主要表现有皮炎、腹泻及痴呆，故维生素 $\mathrm{PP}$ 又称抗糙皮病维生素。

抗结核药物异烟肼的结构与维生素 $\mathrm{PP}$ 相似，两者有拮抗作用，长期服用异烟肼可能引起维生素 $\mathrm{PP}$ 缺乏。近年来，烟酸作为药物已用于临床治疗高胆固醇血症。如果大量服用烟酸或烟酰胺（$1\sim 6\,\mathrm{g}/\mathrm{d}$）会引发血管扩张、脸颊潮红、痤疮及胃肠不适等毒性症状。长期日服用量超过 $500\,\mathrm{mg}$ 可引起肝损伤。

:::definition{label="糙皮病"}
糙皮病（pellagra）即人类维生素 $\mathrm{PP}$ 缺乏症，主要表现有皮炎、腹泻及痴呆（3D）。维生素 $\mathrm{PP}$ 又称抗糙皮病维生素。
:::

:::keypoint{label="糙皮病 3D"}
- 皮炎（dermatitis）
- 腹泻（diarrhea）
- 痴呆（dementia）
:::

:::compare{title="维生素PP 的 RNI、拮抗、药用与毒性"}
| 项目 | 教材原句 |
|------|----------|
| RNI | 男 $15\,\mathrm{mg}/\mathrm{d}$ NE，女 $12\,\mathrm{mg}\,\mathrm{NE}/\mathrm{d}$ |
| 缺乏 | 糙皮病：皮炎、腹泻、痴呆 |
| 拮抗 | 异烟肼结构相似，长期服用可能引起 $\mathrm{PP}$ 缺乏 |
| 药用 | 烟酸用于治疗高胆固醇血症 |
| 大量 $1\sim 6\,\mathrm{g}/\mathrm{d}$ | 血管扩张、脸颊潮红、痤疮、胃肠不适 |
| 长期 $>500\,\mathrm{mg}/\mathrm{d}$ | 肝损伤 |
:::

:::pitfall{label="异烟肼两边都要补：PP 和 B6 不是同一机制"}
异烟肼与维生素 $\mathrm{PP}$ 结构相似、拮抗。后文它又能与磷酸吡哆醛的醛基结合使其失活，服异烟肼时应补维生素 $\mathrm{B}_{6}$。两笔都是抗结核药，缺的维生素和机制不同，不要写成“异烟肼缺 B 族”。
:::

## 四、泛酸的活性形式是辅酶A 和酰基载体蛋白质

### （一）泛酸是遍多酸

泛酸（pantothenic acid）又称遍多酸、维生素 $\mathrm{B}_{5}$，由二甲基羟丁酸和 $\beta$-丙氨酸组成，因广泛存在于动、植物组织中而得名。

泛酸在肠内被吸收后，经磷酸化并与半胱氨酸反应生成 4-磷酸泛酰巯乙胺，后者是辅酶 A（coenzyme A，$\mathrm{CoA}$）（图6-7）及酰基载体蛋白质（acyl carrier protein，$\mathrm{ACP}$）的组成部分。

:::definition{label="泛酸"}
泛酸（pantothenic acid）又称遍多酸、维生素 $\mathrm{B}_{5}$，由二甲基羟丁酸和 $\beta$-丙氨酸组成，因广泛存在于动、植物组织中而得名。
:::

:::definition{label="4-磷酸泛酰巯乙胺"}

### （二）泛酸是酰基转移酶的辅因子

$\mathrm{CoA}$ 和 $\mathrm{ACP}$ 是泛酸在体内的活性形式，二者作为酰基转移酶的辅因子，广泛参与糖、脂质、蛋白质代谢及肝的生物转化作用。如 $\mathrm{CoA}$ 参与肉碱脂酰转移酶转运脂酰 $\mathrm{CoA}$ 进入线粒体的过程，$\mathrm{ACP}$ 是脂肪酸合酶的成分，在脂肪酸合成中发挥重要作用。

### （三）泛酸的严重缺乏可致四肢神经痛

根据《中国居民膳食营养素参考摄入量（2023）》，15 岁以上人群泛酸的适宜摄入量（AI）为 $5.0\,\mathrm{mg}/\mathrm{d}$。泛酸缺乏症很少见。泛酸缺乏的早期表现主要是易疲劳、恶心、腹痛、溃疡等，严重时最显著特征是四肢神经痛（脚趾麻木、步行摇晃、周身酸痛等）。

## 五、生物素是多种羧化酶的辅因子

### （一）生物素是噻吩环与尿素的缩合物

生物素（biotin）是含硫的噻吩环与尿素缩合并带有戊酸侧链的化合物（图6-8），又称维生素 H、维生素 $\mathrm{B}_{7}$、辅因子 R。生物素是天然的活性形式，在肝、肾、酵母、蛋类、花生和啤酒等食品中含量较高，人肠道细菌也能合成。生物素为无色针状结晶体，耐酸不耐碱，氧化剂及高温可使其失活。

:::definition{label="生物素"}
生物素（biotin）是含硫的噻吩环与尿素缩合并带有戊酸侧链的化合物，又称维生素 H、维生素 $\mathrm{B}_{7}$、辅因子 R。它是天然的活性形式。
:::

::figure{src="/images/biochemistry/textbook/p0128_02.png" caption="图6-8　生物素的结构。含硫噻吩环与尿素缩合，并带戊酸侧链（CH₂）₄COOH。" alt="生物素：脲环与含硫五元环稠合，侧链为戊酸"}

### （二）生物素作为羧化酶的辅因子发挥作用

生物素在羧化酶全酶合成酶的催化下与羧化酶蛋白质中赖氨酸残基的 $\varepsilon$-氨基以酰胺键共价结合，形成生物胞素残基，羧化酶则转变成有催化活性的酶。生物素作为丙酮酸羧化酶、乙酰 $\mathrm{CoA}$ 羧化酶等的辅因子，参与 $\mathrm{CO}_{2}$ 固定过程，为脂肪与糖代谢所必需。

现已鉴定，人基因组中有 $2\,000$ 多个基因编码产物的功能依赖生物素。生物素不仅参与细胞信号转导和基因表达，还可使组蛋白生物素化，从而影响细胞周期、基因转录和 DNA 损伤的修复。此外，生物素与动物组织中的抗生物素蛋白质具有高亲和力而易被检测，常被用作分子探针标记物。

:::definition{label="生物胞素残基"}
生物素在羧化酶全酶合成酶催化下，与羧化酶蛋白质中赖氨酸残基的 $\varepsilon$-氨基以酰胺键共价结合，形成生物胞素残基，羧化酶由此获得催化活性。
:::

:::keypoint{label="生物素羧化酶点名两例"}
- 丙酮酸羧化酶。
- 乙酰 $\mathrm{CoA}$ 羧化酶。
- 共同职分：参与 $\mathrm{CO}_{2}$ 固定，为脂肪与糖代谢所必需。
:::

:::insight{label="生物素既是辅因子，也是组蛋白修饰和探针"}
代谢课本位是羧化。教材还写：两千多个基因产物依赖生物素；组蛋白生物素化影响细胞周期、转录和 DNA 修复；与抗生物素蛋白质高亲和力，用作分子探针。后文生鸡蛋清正是这一种抗生物素蛋白质。
:::

### （三）生物素的缺乏可因长期使用抗生素所致

根据《中国居民膳食营养素参考摄入量（2023）》，15 岁以上人群生物素的 AI 是 $40\,\mu\mathrm{g}/\mathrm{d}$。生物素能够与新鲜鸡蛋清中的抗生物素蛋白质结合而不能被吸收，蛋清加热后这种蛋白质遭破坏而失去作用。长期使用抗生素可抑制肠道细菌生长，也可能造成生物素缺乏，主要症状是疲乏、呕吐、食欲缺乏、皮炎及脱屑性红皮病。

:::definition{label="抗生物素蛋白质"}
新鲜鸡蛋清中的抗生物素蛋白质可与生物素结合使其不能被吸收。蛋清加热后该蛋白质被破坏而失去作用。
:::

:::cause-effect{title="生物素怎样缺乏"}
- **因** 生蛋清中抗生物素蛋白质结合生物素；长期抗生素抑制肠道细菌合成
- **果** 吸收减少或内源合成减少；疲乏、呕吐、食欲缺乏、皮炎及脱屑性红皮病
:::

:::pitfall{label="生蛋清绑住生物素，熟蛋清就不再绑"}
缺乏不是“吃鸡蛋会缺生物素”，而是新鲜蛋清里的抗生物素蛋白质。加热破坏该蛋白质。长期抗生素与第一节维生素 K、本节肠菌合成叶酸是同一类“灭菌药伤肠菌”账，缺的维生素仍要分户。
:::

## 六、维生素B6 的活性形式是磷酸吡哆醛

### （一）维生素B6 包括吡哆醇、吡哆醛和吡哆胺

维生素 $\mathrm{B}_{6}$ 包括吡哆醇（pyridoxine）、吡哆醛（pyridoxal）和吡哆胺（pyridoxamine），其基本结构是 2-甲基-3-羟基-5-甲基吡啶（图6-9），其活化形式主要是磷酸吡哆醛。维生素 $\mathrm{B}_{6}$ 的纯品为白色结晶，易溶于水及乙醇，微溶于有机溶剂，在酸性条件下稳定、在碱性条件下易被破坏，对光较敏感，不耐高温。

:::definition{label="维生素B6"}
维生素 $\mathrm{B}_{6}$ 包括吡哆醇（pyridoxine）、吡哆醛（pyridoxal）和吡哆胺（pyridoxamine），基本结构是 2-甲基-3-羟基-5-甲基吡啶。活化形式主要是磷酸吡哆醛。
:::

::figure{src="/images/biochemistry/textbook/p0129_01.png" caption="图6-9　维生素 B₆ 及其活性形式的结构与互变。吡哆醇→吡哆醛⇌吡哆胺；吡哆醛⇌磷酸吡哆醛，吡哆胺⇌磷酸吡哆胺，磷酸吡哆醛与磷酸吡哆胺互变。" alt="五种吡啶衍生物：吡哆醇、吡哆醛、吡哆胺及其磷酸酯，醛与胺、磷酸与非磷酸之间有可逆箭头"}

肝、鱼、肉类、全麦、坚果和蛋黄等均是维生素 $\mathrm{B}_{6}$ 的丰富来源。维生素 $\mathrm{B}_{6}$ 的磷酸酯在小肠碱性磷酸酶的作用下水解，以去磷酸化形式被吸收。吡哆醛和磷酸吡哆醛是血液中的主要运输形式。体内约 $80\%$ 的维生素 $\mathrm{B}_{6}$ 以磷酸吡哆醛的形式存在于肌组织中，并与糖原磷酸化酶相结合。

:::keypoint{label="维生素B6 的吸收、运输和储存"}
- 磷酸酯先经小肠碱性磷酸酶水解，以去磷酸化形式吸收。
- 血液主要运输形式：吡哆醛和磷酸吡哆醛。
- 约 $80\%$ 以磷酸吡哆醛存在于肌组织，并结合糖原磷酸化酶。
:::

### （二）维生素B6 是多种酶的辅因子

**1. 磷酸吡哆醛是多种酶的辅因子**　磷酸吡哆醛参与氨基酸脱氨基与转氨基作用、鸟氨酸循环、血红素合成和糖原分解等过程，在代谢中发挥重要作用。

磷酸吡哆醛也是谷氨酸脱羧酶的辅因子，可促进大脑抑制性神经递质 $\gamma$-氨基丁酸的生成，故临床上常用维生素 $\mathrm{B}_{6}$ 治疗小儿惊厥、妊娠呕吐和精神焦虑等。磷酸吡哆醛还是血红素合成关键酶 ALA 合酶的辅因子，参与血红素的生成。

研究显示，高同型半胱氨酸血症是心血管疾病、血栓生成和高血压的危险因子。维生素 $\mathrm{B}_{6}$ 是催化同型半胱氨酸生成半胱氨酸过程中胱硫醚 $\beta$ 合成酶的辅因子。已知 $2/3$ 以上的高同型半胱氨酸血症与维生素 $\mathrm{B}_{6}$、叶酸和维生素 $\mathrm{B}_{12}$ 的缺乏有关。

:::definition{label="磷酸吡哆醛"}
磷酸吡哆醛是维生素 $\mathrm{B}_{6}$ 的主要活化形式，参与氨基酸脱氨基与转氨基、鸟氨酸循环、血红素合成和糖原分解等。
:::

| 酶／过程 | 教材落点 |
|----------|----------|
| 氨基酸脱氨基、转氨基 | 氨基酸代谢 |
| 鸟氨酸循环 | 尿素生成 |
| 糖原磷酸化酶 | 肌组织中约 $80\%$ 的维生素 $\mathrm{B}_{6}$ 与之结合；糖原分解 |
| 谷氨酸脱羧酶 | 生成抑制性递质 $\gamma$-氨基丁酸；临床用于小儿惊厥、妊娠呕吐、精神焦虑 |
| ALA 合酶 | 血红素合成关键酶 |
| 胱硫醚 $\beta$ 合成酶 | 同型半胱氨酸 → 半胱氨酸 |
:::

**2. 磷酸吡哆醛可终止类固醇激素的作用**　磷酸吡哆醛可作用于类固醇激素-受体复合物，终止这些激素的作用。维生素 $\mathrm{B}_{6}$ 缺乏时，可增加人体对雌激素、雄激素、皮质激素及维生素 D 作用的敏感性，与乳腺、前列腺和子宫激素相关肿瘤的发生发展有关。

:::insight{label="高同型半胱氨酸血症是 B6、叶酸、B12 的共用考题"}
$2/3$ 以上与这三种维生素缺乏有关。$\mathrm{B}_{6}$ 走胱硫醚 $\beta$ 合成酶（同型半胱氨酸 → 半胱氨酸）；叶酸和 $\mathrm{B}_{12}$ 走 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 转甲基生成甲硫氨酸。思考题第 3 题把三本账写全，不要只答叶酸。
:::

### （三）维生素B6 缺乏可致低血色素小细胞性贫血

根据《中国居民膳食营养素参考摄入量（2023）》，15～50 岁人群维生素 $\mathrm{B}_{6}$ 的推荐摄入量（RNI）为 $1.4\,\mathrm{mg}/\mathrm{d}$，维生素 $\mathrm{B}_{6}$ 的 RNI 为 $1.6\,\mathrm{mg}/\mathrm{d}$。人类尚未发现维生素 $\mathrm{B}_{6}$ 缺乏的典型病例。然而，维生素 $\mathrm{B}_{6}$ 缺乏可造成低血色素小细胞性贫血（又称维生素 $\mathrm{B}_{6}$ 反应性贫血）和血清铁增高。维生素 $\mathrm{B}_{6}$ 缺乏的患者还可出现脂溢性皮炎。

此外，抗结核药异烟肼能与磷酸吡哆醛的醛基结合使其失去活性，在服用异烟肼时，应补充维生素 $\mathrm{B}_{6}$。过量服用维生素 $\mathrm{B}_{6}$ 可引起中毒。日摄入量超过 $20\,\mathrm{mg}$ 可引起肢体远端的麻木、疼痛等感觉性周围神经病的症状。

:::definition{label="维生素B6 反应性贫血"}
维生素 $\mathrm{B}_{6}$ 缺乏可造成低血色素小细胞性贫血（又称维生素 $\mathrm{B}_{6}$ 反应性贫血）和血清铁增高。人类尚未发现维生素 $\mathrm{B}_{6}$ 缺乏的典型病例。
:::

:::cause-effect{title="磷酸吡哆醛不够怎样变成小细胞低色素"}
- **因** 磷酸吡哆醛是 ALA 合酶辅因子，缺乏则血红素合成受阻；血清铁增高说明铁并不缺
- **果** 低血色素小细胞性贫血（维生素 B6 反应性贫血）；还可有脂溢性皮炎
:::

:::pitfall{label="同是小细胞低色素，B6 反应性贫血血清铁增高"}
第五章铁缺乏也是小细胞低色素，但那是缺铁。本节血清铁增高，缺的是血红素合成的辅因子。巨幼细胞贫血是叶酸／$\mathrm{B}_{12}$ 另一本账。思考题第 4 题按类型分，不要把贫血都写成“缺维生素”。
:::

:::note{label="异烟肼与醛基结合"}
异烟肼与磷酸吡哆醛的醛基结合使其失活，服药时应补维生素 $\mathrm{B}_{6}$。这与 $\mathrm{PP}$ 的结构拮抗是两条机制。日摄入超过 $20\,\mathrm{mg}$ 可致感觉性周围神经病——水溶维生素里明确写了中毒剂量的一种。
:::

## 七、叶酸的活性形式是四氢叶酸

### （一）叶酸是蝶酰谷氨酸

叶酸（folic acid）由蝶酸（pteroic acid）和谷氨酸结合而成，又称蝶酰谷氨酸，因绿叶中含量丰富而得名（图6-10）。植物中的叶酸多含 $7$ 个谷氨酸残基，谷氨酸之间以 $\gamma$-肽键相连。仅牛奶和蛋黄中含蝶酰单谷氨酸。酵母、肝、水果和绿叶蔬菜均是叶酸的丰富来源。肠菌也有合成叶酸的能力。

:::definition{label="叶酸"}
叶酸（folic acid）由蝶酸（pteroic acid）和谷氨酸结合而成，又称蝶酰谷氨酸，因绿叶中含量丰富而得名。
:::

::figure{src="/images/biochemistry/textbook/p0130_01.png" caption="图6-10　叶酸的结构。蝶酸（蝶啶环 + 对氨基苯甲酸，N⁵、N⁸、N¹⁰ 等位点标出）与谷氨酸相连，整体为叶酸（蝶酰谷氨酸）。" alt="叶酸结构：左侧蝶啶，中间对氨基苯甲酸标 N10，右侧谷氨酸；下方分标蝶酸与谷氨酸"}

食物中的蝶酰谷氨酸主要在小肠被水解，生成蝶酰单谷氨酸，后者易被小肠上段吸收，在小肠黏膜上皮细胞二氢叶酸还原酶的作用下，生成叶酸的活性型——5,6,7,8-四氢叶酸（tetrahydrofolic acid，$\mathrm{FH}_{4}$）。含单谷氨酸的 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 是叶酸在血液循环中的主要形式。在体内各组织中，$\mathrm{FH}_{4}$ 主要以多谷氨酸形式存在。

:::definition{label="四氢叶酸（FH4）"}
5,6,7,8-四氢叶酸（tetrahydrofolic acid，$\mathrm{FH}_{4}$）是叶酸的活性型，由小肠黏膜上皮细胞二氢叶酸还原酶催化生成。
:::

:::definition{label="血液中叶酸的主要形式"}
含单谷氨酸的 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 是叶酸在血液循环中的主要形式。组织中 $\mathrm{FH}_{4}$ 主要以多谷氨酸形式存在。
:::

:::timeline{period="叶酸从食物到 FH4"}
- **食物** 植物中多为 7 个谷氨酸残基，γ-肽键相连；牛奶和蛋黄含蝶酰单谷氨酸
- **小肠水解** 蝶酰谷氨酸 → 蝶酰单谷氨酸，上段吸收
- **黏膜** 二氢叶酸还原酶 → 5,6,7,8-四氢叶酸（FH4）
- **血液** 单谷氨酸的 N5-CH3-FH4
- **组织** 多谷氨酸形式的 FH4
:::

### （二）叶酸主要参与一碳单位代谢

$\mathrm{FH}_{4}$ 是体内一碳单位转移酶的辅因子，分子中 $\mathrm{N}^{5}$、$\mathrm{N}^{10}$ 是一碳单位的结合位点。一碳单位在体内参与嘌呤、胸腺嘧啶核苷酸等多种物质的合成。

抗肿瘤药物甲氨蝶呤和氨蝶呤因其结构与叶酸相似，能抑制二氢叶酸还原酶的活性，使 $\mathrm{FH}_{4}$ 合成减少，进而抑制体内胸腺嘧啶核苷酸的合成，起到抗肿瘤作用。

:::definition{label="一碳单位与 FH4"}
$\mathrm{FH}_{4}$ 是体内一碳单位转移酶的辅因子。分子中 $\mathrm{N}^{5}$、$\mathrm{N}^{10}$ 是一碳单位的结合位点。一碳单位参与嘌呤、胸腺嘧啶核苷酸等多种物质的合成。
:::

:::example{label="甲氨蝶呤、氨蝶呤抗肿瘤"}
结构与叶酸相似，抑制二氢叶酸还原酶 → $\mathrm{FH}_{4}$ 合成减少 → 胸腺嘧啶核苷酸合成受抑制。这是活性型生成这一步被卡住，不是直接抢走一碳单位。
:::

:::pitfall{label="N5、N10 是结合位点，血液主力是 N5-CH3-FH4"}
图6-10 标出蝶啶与 $\mathrm{N}^{10}$。一碳单位结合在 $\mathrm{N}^{5}$、$\mathrm{N}^{10}$。循环中主要运输形式是 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$，后文 $\mathrm{B}_{12}$ 的甲钴胺素正是把这个甲基交给同型半胱氨酸的辅因子。
:::

### （三）叶酸缺乏可致巨幼细胞贫血

中国居民膳食叶酸的 RNI 是 $400\,\mu\mathrm{g}/\mathrm{d}$ 的膳食叶酸当量（dietary folate equivalent，DFE）。叶酸一般不发生缺乏症。叶酸缺乏时，骨髓幼红细胞 DNA 合成减少，细胞分裂速度降低，细胞体积变大，造成巨幼细胞贫血（megaloblastic anemia）。叶酸缺乏还可引起高同型半胱氨酸血症。每日服用 $500\,\mu\mathrm{g}$ 叶酸有益于预防冠心病的发生。叶酸缺乏也可引起 DNA 低甲基化，增加结肠癌、直肠癌等肿瘤的危险性。

此外，孕妇如果叶酸缺乏，可能造成胎儿脊柱裂和神经管缺陷，故孕妇及哺乳期妇女应适量补充叶酸。口服避孕药或抗惊厥药能干扰叶酸的吸收及代谢，如长期服用此类药物时应考虑补充叶酸。

:::definition{label="巨幼细胞贫血"}
巨幼细胞贫血（megaloblastic anemia）：叶酸缺乏时，骨髓幼红细胞 DNA 合成减少，细胞分裂速度降低，细胞体积变大。维生素 $\mathrm{B}_{12}$ 缺乏也可产生巨幼细胞贫血（即恶性贫血）。
:::

:::keypoint{label="叶酸缺乏不止贫血"}
- 巨幼细胞贫血（DNA 合成减少、分裂慢、细胞体积变大）。
- 高同型半胱氨酸血症；每日 $500\,\mu\mathrm{g}$ 叶酸有益于预防冠心病。
- DNA 低甲基化，增加结肠癌、直肠癌等危险。
- 孕妇缺乏：胎儿脊柱裂和神经管缺陷。
- 口服避孕药或抗惊厥药干扰吸收及代谢，长期服用应考虑补充。
:::

:::cause-effect{title="叶酸不够怎样变成巨幼细胞"}
- **因** $\mathrm{FH}_{4}$ 不足，一碳单位不能支撑嘌呤和胸腺嘧啶核苷酸合成，骨髓幼红细胞 DNA 合成减少
- **果** 细胞分裂速度降低，细胞体积变大，巨幼细胞贫血
:::

## 八、维生素B12 主要参与甲基转移

### （一）维生素B12 是钴胺素

维生素 $\mathrm{B}_{12}$ 含有金属元素钴，又称钴胺素（cobalamin），是唯一含金属元素的维生素（图6-11）。维生素 $\mathrm{B}_{12}$ 仅由微生物合成，酵母和动物肝含量丰富，不存在于植物中。维生素 $\mathrm{B}_{12}$ 分子中的钴能与 $-\mathrm{CN}$、$-\mathrm{OH}$、$-\mathrm{CH}_{3}$ 或 $5'$-脱氧腺苷等基团连接，分别形成氰钴胺素、羟钴胺素、甲钴胺素和 $5'$-脱氧腺苷钴胺素，前两者是药用维生素 $\mathrm{B}_{12}$ 的常见形式，而后两者是维生素 $\mathrm{B}_{12}$ 在体内的活性形式。

:::definition{label="维生素B12（钴胺素）"}
维生素 $\mathrm{B}_{12}$ 含金属元素钴，又称钴胺素（cobalamin），是唯一含金属元素的维生素。仅由微生物合成，酵母和动物肝含量丰富，不存在于植物中。
:::

:::compare{title="四种钴胺素"}
| 与钴相连的基团 | 名称 | 教材身份 |
|----------------|------|----------|
| $-\mathrm{CN}$ | 氰钴胺素 | 药用常见形式 |
| $-\mathrm{OH}$ | 羟钴胺素 | 药用常见形式；进入细胞后也可转变成此型 |
| $-\mathrm{CH}_{3}$ | 甲钴胺素 | 体内活性形式 |
| $5'$-脱氧腺苷 | $5'$-脱氧腺苷钴胺素 | 体内活性形式 |
:::

::figure{src="/images/biochemistry/textbook/p0131_01.png" caption="图6-11　维生素 B₁₂ 的结构。中心 Co⁺ 与咕啉环、下方 R 基及上方二甲基苯并咪唑核苷酸相连。R=CN 氰钴胺素，R=OH 羟钴胺素，R=CH₃ 甲钴胺素，R=5′-脱氧腺苷为 5′-脱氧腺苷钴胺素。" alt="钴胺素：咕啉环中央 Co+，下方 R 取代基，上方核苷酸和磷酸"}

食物中的维生素 $\mathrm{B}_{12}$ 常与蛋白质结合而存在，在胃酸和胃蛋白酶的作用下，维生素 $\mathrm{B}_{12}$ 得以游离并与来自唾液的亲钴蛋白质结合。亲钴蛋白质-$\mathrm{B}_{12}$ 复合物在十二指肠经胰蛋白酶的水解游离出维生素 $\mathrm{B}_{12}$。维生素 $\mathrm{B}_{12}$ 需要与由胃黏膜细胞分泌的内因子（intrinsic factor，IF）紧密结合生成 $\mathrm{B}_{12}$-IF 复合物，才能被回肠吸收。在小肠黏膜上皮细胞内，$\mathrm{B}_{12}$-IF 分解并游离出维生素 $\mathrm{B}_{12}$。维生素 $\mathrm{B}_{12}$ 再与转钴胺素Ⅱ蛋白结合存在于血液中。$\mathrm{B}_{12}$-转钴胺素Ⅱ复合物与细胞表面受体结合进入细胞后，维生素 $\mathrm{B}_{12}$ 转变成羟钴胺素、甲钴胺素或进入线粒体转变成 $5'$-脱氧腺苷钴胺素。肝内还有一种转钴胺素Ⅰ，可与 $\mathrm{B}_{12}$ 结合而贮存于肝内。

:::definition{label="内因子"}
内因子（intrinsic factor，IF）由胃黏膜细胞分泌。维生素 $\mathrm{B}_{12}$ 必须与之紧密结合生成 $\mathrm{B}_{12}$-IF 复合物，才能被回肠吸收。
:::

:::timeline{period="维生素B12 的吸收与转运"}
- **胃** 胃酸和胃蛋白酶使食物中与蛋白质结合的 B12 游离，并与唾液亲钴蛋白质结合
- **十二指肠** 胰蛋白酶水解亲钴蛋白质-B12，游离出 B12
- **回肠** B12 与内因子结合成 B12-IF 复合物后被吸收
- **黏膜上皮** B12-IF 分解，游离 B12
- **血液** 与转钴胺素Ⅱ结合
- **入胞** 受体介导进入后，变成羟钴胺素、甲钴胺素，或在线粒体变成 5′-脱氧腺苷钴胺素
- **肝储存** 转钴胺素Ⅰ与 B12 结合贮存
:::

:::pitfall{label="没有内因子就没有回肠吸收，植物性食物本来也没有B12"}
$\mathrm{B}_{12}$ 不存在于植物中，仅微生物合成。萎缩性胃炎、胃全切或内因子先天性缺陷 → 严重吸收障碍。缺的不是“菜吃少了”，是 IF 和回肠这一段。亲钴蛋白质是胃里的临时搬运，真正进回肠靠 IF。
:::

### （二）维生素B12 参与甲硫氨酸循环

甲钴胺素是 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 转甲基酶（甲硫氨酸合成酶）的辅因子，此酶催化同型半胱氨酸生成甲硫氨酸，后者在腺苷转移酶的作用下生成活性甲基供体——S-腺苷甲硫氨酸（SAM）。维生素 $\mathrm{B}_{12}$ 缺乏时，甲硫氨酸合成减少，抑制了 $\mathrm{FH}_{4}$ 再生，一碳单位代谢受阻，造成核酸合成障碍。此外，SAM 可参与胆碱和磷脂等生物合成。

$5'$-脱氧腺苷钴胺素是 L-甲基丙二酰 $\mathrm{CoA}$ 变位酶的辅因子，催化琥珀酰 $\mathrm{CoA}$ 的生成。当维生素 $\mathrm{B}_{12}$ 缺乏时，L-甲基丙二酰 $\mathrm{CoA}$ 大量堆积，因其结构与丙二酰 $\mathrm{CoA}$ 相似，从而影响脂肪酸的正常合成。

:::definition{label="甲钴胺素与甲硫氨酸合成酶"}
甲钴胺素是 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 转甲基酶（甲硫氨酸合成酶）的辅因子，催化同型半胱氨酸生成甲硫氨酸，进而生成活性甲基供体 S-腺苷甲硫氨酸（SAM）。
:::

:::definition{label="5′-脱氧腺苷钴胺素"}
$5'$-脱氧腺苷钴胺素是 L-甲基丙二酰 $\mathrm{CoA}$ 变位酶的辅因子，催化琥珀酰 $\mathrm{CoA}$ 的生成。
:::

:::cause-effect{title="B12 缺乏怎样拖住叶酸再生"}
- **因** 甲钴胺素不足，甲硫氨酸合成酶不能把 N5-CH3-FH4 的甲基交给同型半胱氨酸，FH4 不能再生
- **果** 一碳单位代谢受阻，核酸合成障碍（与叶酸缺乏一样可走向巨幼细胞贫血）；同型半胱氨酸堆积
:::

:::insight{label="两种活性形式两本账：甲基循环 vs 甲基丙二酰CoA"}
甲钴胺素管 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ → 甲硫氨酸 → SAM。$5'$-脱氧腺苷钴胺素管 L-甲基丙二酰 $\mathrm{CoA}$ → 琥珀酰 $\mathrm{CoA}$。缺乏时后者堆积、结构像丙二酰 $\mathrm{CoA}$，脂肪酸合成异常，髓鞘质变性退化。贫血和神经病变不要并成同一条酶。
:::

### （三）维生素B12 缺乏可致巨幼细胞贫血等疾病

中国居民膳食维生素 $\mathrm{B}_{12}$ 的 RNI 是 $2.4\,\mu\mathrm{g}/\mathrm{d}$，因其广泛存在于动物食品中，一般不会缺乏。但萎缩性胃炎、胃全切患者或内因子的先天性缺陷者，可因维生素 $\mathrm{B}_{12}$ 的严重吸收障碍而出现缺乏症。

维生素 $\mathrm{B}_{12}$ 缺乏可产生巨幼细胞贫血（即恶性贫血），故维生素 $\mathrm{B}_{12}$ 也称为抗恶性贫血维生素。维生素 $\mathrm{B}_{12}$ 缺乏不仅可造成高同型半胱氨酸血症，还可使脂肪酸合成异常，导致髓鞘质变性退化。故维生素 $\mathrm{B}_{12}$ 可用于预防冠心病。

:::definition{label="恶性贫血"}
维生素 $\mathrm{B}_{12}$ 缺乏可产生巨幼细胞贫血（即恶性贫血），故维生素 $\mathrm{B}_{12}$ 也称为抗恶性贫血维生素。常见于内因子缺乏所致的严重吸收障碍。
:::

:::compare{title="叶酸缺乏 vs 维生素B12 缺乏"}
| 项目 | 叶酸 | 维生素 $\mathrm{B}_{12}$ |
|------|------|------------------------|
| 活性形式 | $\mathrm{FH}_{4}$ | 甲钴胺素、$5'$-脱氧腺苷钴胺素 |
| 贫血 | 巨幼细胞贫血 | 巨幼细胞贫血（恶性贫血） |
| 共同 | 高同型半胱氨酸血症；核酸合成障碍 | 同左（甲钴胺素不足使 $\mathrm{FH}_{4}$ 不能再生） |
| 叶酸另有 | 神经管缺陷、DNA 低甲基化与结直肠癌 | — |
| $\mathrm{B}_{12}$ 另有 | — | 脂肪酸合成异常、髓鞘质变性退化 |
| 吸收要点 | 水解成单谷氨酸；二氢叶酸还原酶 | 内因子、回肠；不存在于植物 |
:::

:::pitfall{label="巨幼细胞贫血两家都会，恶性贫血点名B12"}
叶酸缺乏：DNA 合成少、细胞分裂慢、细胞变大。$\mathrm{B}_{12}$ 缺乏：同一套巨幼细胞，教材称为恶性贫血，并点名抗恶性贫血维生素。只答“巨幼贫”不够区分；有内因子、髓鞘质、甲基丙二酰 $\mathrm{CoA}$ 的是 $\mathrm{B}_{12}$。
:::

## 九、维生素C 是羟化酶的辅因子和强抗氧化剂

### （一）维生素C 是L-抗坏血酸

维生素 C 又称 L-抗坏血酸（ascorbic acid），是 L-己糖酸内酯，具有不饱和的一烯二醇结构，是天然的活性形式。维生素 C 分子中 C2 和 C3 羟基可以氧化脱氢生成脱氢抗坏血酸，后者可接受氢再还原成抗坏血酸（图6-12）。维生素 C 为无色无臭的片状晶体，易溶于水，不溶于脂溶性溶剂，在酸性溶液中比较稳定，在中性、碱性溶液中加热易被氧化破坏。

:::definition{label="维生素C（L-抗坏血酸）"}
维生素 C 又称 L-抗坏血酸（ascorbic acid），是 L-己糖酸内酯，具有不饱和的一烯二醇结构，是天然的活性形式。
:::

人类和其他灵长类等动物体内不能合成维生素 C，必须由食物供给。维生素 C 广泛存在于新鲜蔬菜和水果中。植物中的抗坏血酸氧化酶能将维生素 C 氧化灭活为二酮古洛糖酸，所以久存的水果和蔬菜中维生素 C 含量会大量减少。干种子中不含维生素 C，但其幼芽可以合成维生素 C，故豆芽富含维生素 C。

维生素 C 主要通过主动转运由小肠上段吸收进入血液循环。还原型 L-抗坏血酸是细胞内与血液中的主要存在形式。血液中 L-脱氢抗坏血酸仅为抗坏血酸的 $1/15$。

### （二）维生素C 参与羟化反应和氧化还原反应

**1. 维生素C 参与羟化反应**　维生素 C 参与体内以下的多种羟化反应：

（1）维生素 C 是含铜羟化酶和 $\alpha$-酮戊二酸-铁羟化酶的辅因子。在含铜羟化酶催化的反应中，$\mathrm{Cu}^{+}$ 被氧化生成 $\mathrm{Cu}^{2+}$，后者在维生素 C 作用下再还原为 $\mathrm{Cu}^{+}$。

（2）维生素 C 是对-羟苯丙酮酸羟化酶的辅因子，参与对-羟苯丙酮酸生成尿黑酸的反应。维生素 C 缺乏时，尿中可出现大量对-羟苯丙酮酸。维生素 C 还是多巴胺 $\beta$-羟化酶的辅因子。维生素 C 缺乏可引起肾上腺髓质和中枢神经系统的儿茶酚胺的代谢异常。

（3）维生素 C 是胆汁酸合成关键酶 $7\alpha$-羟化酶的辅因子，参与将 $40\%$ 的胆固醇正常转变成胆汁酸。维生素 C 也参与肾上腺皮质类固醇合成中的羟化作用。

（4）依赖维生素 C 的含铁羟化酶参与蛋白质翻译后的修饰。如胶原脯氨酸羟化酶和赖氨酸羟化酶分别催化前胶原分子中脯氨酸和赖氨酸残基的羟化，促进胶原的成熟。

（5）体内肉碱合成过程需要依赖维生素 C 的羟化酶参与。维生素 C 缺乏时，由于脂肪酸 $\beta$-氧化减弱，病人往往出现倦怠乏力。

:::definition{label="维生素C 作为羟化酶辅因子"}
维生素 C 是含铜羟化酶和 $\alpha$-酮戊二酸-铁羟化酶的辅因子，并参与对-羟苯丙酮酸羟化、多巴胺 $\beta$-羟化、$7\alpha$-羟化、胶原脯氨酸／赖氨酸羟化以及肉碱合成中的羟化。
:::

:::compare{title="维生素C 点名的羟化"}
| 酶／过程 | 缺乏时教材落点 |
|----------|----------------|
| 含铜羟化酶 | $\mathrm{Cu}^{2+}$ 需维生素 C 还原回 $\mathrm{Cu}^{+}$ |
| 对-羟苯丙酮酸羟化酶 | 尿中大量对-羟苯丙酮酸 |
| 多巴胺 $\beta$-羟化酶 | 肾上腺髓质和中枢儿茶酚胺代谢异常 |

| 肉碱合成羟化酶 | 脂肪酸 $\beta$-氧化减弱，倦怠乏力 |
:::

:::insight{label="坏血病的分子户头是胶原羟化"}
毛细血管易破裂、牙龈腐烂松动、骨折、创伤不易愈合，都落在胶原成熟。肉碱那一笔解释乏力，儿茶酚胺解释神经和肾上腺，胆汁酸解释胆固醇增多。不要把坏血病只写成“缺维生素 C 会出血”。
:::

**2. 维生素C 参与体内氧化还原反应**

（1）维生素 C 可使巯基酶的 $-\mathrm{SH}$ 保持还原状态。维生素 C 在谷胱甘肽还原酶作用下，将氧化型谷胱甘肽（GSSG）还原成还原型（GSH）。GSH 能清除细胞膜的脂质过氧化物以保护细胞膜。

（2）维生素 C 能使红细胞中高铁血红蛋白（MHb）还原为血红蛋白（Hb），使其恢复运氧能力。

（3）小肠中的维生素 C 可将 $\mathrm{Fe}^{3+}$ 还原成 $\mathrm{Fe}^{2+}$，有利于食物中铁的吸收。

（4）维生素 C 作为抗氧化剂，影响细胞内活性氧敏感的信号转导系统，从而调节基因表达，影响细胞分化与细胞功能。维生素 C 还可以清除 $\mathrm{O}_{2}^{\cdot -}$ 及 $\mathrm{OH}^{\cdot}$ 等活性氧类物质。

:::keypoint{label="维生素C 的氧化还原四笔"}
- 保持巯基酶 $-\mathrm{SH}$；GSSG → GSH，GSH 清脂质过氧化物。
- MHb → Hb，恢复运氧。
- 肠内 $\mathrm{Fe}^{3+}\rightarrow\mathrm{Fe}^{2+}$，利于铁吸收。
- 抗氧化：活性氧敏感的信号转导；清除超氧阴离子和羟自由基。
:::

:::note{label="第一节维生素E 的自由基账在这里接头"}
生育酚自由基可在维生素 C、GSH 或 NADPH 作用下还原。本节 GSH 和维生素 C 都写进抗氧化。铁吸收那一笔与第五章“只有 $\mathrm{Fe}^{2+}$ 被吸收”对齐。
:::

**3. 维生素C 具有增强机体免疫力的作用**　维生素 C 不仅促进体内抗菌活性、NK 细胞活性、淋巴细胞增殖和趋化作用，也能提高吞噬细胞的吞噬能力、促进免疫球蛋白的合成，从而提高机体免疫力。临床上用于心血管疾病、感染性疾病等的支持性治疗。

### （三）维生素C 缺乏可致坏血病

根据《中国居民膳食营养素参考摄入量（2023）》，15 岁以上人群维生素 C 的 RNI 为 $100\,\mathrm{mg}/\mathrm{d}$。维生素 C 严重缺乏时可引起维生素 C 缺乏病，又称坏血病（scurvy）。坏血病以毛细血管易破裂、牙龈腐烂和松动、骨折以及创伤不易愈合等为主要症状。因机体在正常状态下可储存一定量的维生素 C，故维生素 C 缺乏 $3\sim 4$ 个月后才出现症状。

维生素 C 缺乏还可引起胆固醇增多，是动脉硬化的危险因素之一。此外，人体长期过量摄入维生素 C 可能增加发生尿路草酸盐结石的危险。

:::definition{label="坏血病"}
坏血病（scurvy）即维生素 C 严重缺乏所致的维生素 C 缺乏病，以毛细血管易破裂、牙龈腐烂和松动、骨折以及创伤不易愈合为主要症状。正常可储存一定量维生素 C，缺乏 $3\sim 4$ 个月后才出现症状。
:::

:::timeline{period="维生素C 缺乏到坏血病"}

- **缺乏 3～4 个月** 才出现症状
- **坏血病** 毛细血管易破裂、牙龈腐烂松动、骨折、创伤不易愈合
- **伴随** 胆固醇增多，动脉硬化危险因素之一
:::

:::pitfall{label="水溶维生素C 仍能储存数月，过量可成草酸盐结石"}
“很少蓄积、多余随尿走”是大类特征。维生素 C 教材写明正常可储存一定量，故数月后才出现坏血病；长期过量又可能增加尿路草酸盐结石危险。不要把水溶听成“当天不吃当天得坏血病”，也不要听成“完全不会过量”。
:::

## 本章小结

维生素是人体内不能合成或合成量甚少，必须由食物供给的一类小分子有机化合物，在调节物质代谢、促进生长发育和维持生理功能等方面发挥重要作用。人体对维生素的日需要量极少，但如果长期缺乏可致缺乏症，而摄入过多可引发中毒。维生素可分为脂溶性维生素和水溶性维生素，前者包括维生素 A、维生素 D、维生素 E 和维生素 K，后者包括 B 族维生素（维生素 $\mathrm{B}_{1}$、维生素 $\mathrm{B}_{2}$、维生素 $\mathrm{PP}$、维生素 $\mathrm{B}_{6}$、维生素 $\mathrm{B}_{12}$、生物素、泛酸和叶酸）和维生素 C。

维生素 A 的活性形式为视黄醇、视黄醛和视黄酸，其作用包括参与视觉传导、调控基因表达和细胞生长与分化、抗氧化和抗癌。维生素 A 缺乏可致“夜盲症”或者“眼干燥症”，长期过量摄入可中毒。维生素 D 的活性形式是 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$，具有调节钙磷代谢和细胞分化的作用。维生素 D 缺乏可导致儿童佝偻病，成人软骨病和骨质疏松症。维生素 E 的活性形式为 $\alpha$-生育酚，其作用包括抗氧化、调节基因表达以及促进血红素合成。维生素 K 有促凝血作用，并参与骨代谢，缺乏时易出血。

B 族维生素通常以酶辅因子形式参与物质代谢。维生素 $\mathrm{B}_{1}$ 的活性形式为焦磷酸硫胺素，是脱羧酶和转酮醇酶的辅因子；其缺乏可引起脚气病。维生素 $\mathrm{B}_{2}$ 的活性形式是 $\mathrm{FMN}$ 及 $\mathrm{FAD}$，两者是氧化还原酶的辅因子，参与糖、氨基酸和脂肪酸等的氧化过程；其缺乏可引起口角炎等症状。维生素 $\mathrm{PP}$ 的活性形式为 $\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$，两者是不需氧脱氢酶的辅因子；其缺乏可引起糙皮病。泛酸的活性形式是辅酶 A 及酰基载体蛋白质，是酰基转移酶的辅因子。生物素是天然的活性形式，是羧化酶的辅因子。维生素 $\mathrm{B}_{6}$ 的活性形式为磷酸吡哆醛，是氨基转移酶、氨基酸脱羧酶以及 ALA 合酶的辅因子；其缺乏可致低血色素小细胞性贫血，而摄入过量可致中毒。$\mathrm{FH}_{4}$ 是叶酸的活性形式，也是一碳单位的载体。维生素 $\mathrm{B}_{12}$ 的活性形式是甲钴胺素和 $5'$-脱氧腺苷钴胺素，是 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 转甲基酶的辅因子。叶酸或者维生素 $\mathrm{B}_{12}$ 缺乏可致巨幼细胞贫血以及高同型半胱氨酸血症。维生素 C 是天然的活性形式，参与苯丙氨酸与胆汁酸代谢、胶原合成过程中的多种羟化反应，维生素 C 也可作为抗氧化剂；其缺乏可致坏血病。

:::definition{label="本章小结里的维生素分类"}
维生素是人体不能合成或合成量甚少、必须由食物供给的小分子有机化合物。脂溶性：A、D、E、K。水溶性：B 族（$\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{PP}$、$\mathrm{B}_{6}$、$\mathrm{B}_{12}$、生物素、泛酸和叶酸）和维生素 C。

- [ ] 异咯嗪第 1、第 10 位氮递氢。$\mathrm{FMN}/\mathrm{FAD}$：脂酰 $\mathrm{CoA}$ 脱氢酶、琥珀酸脱氢酶、黄嘌呤氧化酶等。
- [ ] $\mathrm{FMN}$ 参与 $\mathrm{B}_{6}$→磷酸吡哆醛；$\mathrm{FAD}$ 参与色氨酸→烟酸、谷胱甘肽还原酶、细胞色素 $\mathrm{P}450$。
- [ ] $\mathrm{B}_{2}$ 缺乏：淘米过度、牛奶多次煮沸、光疗；口角炎、眼睑炎、畏光。
- [ ] $\mathrm{PP}$＝烟酸 + 烟酰胺；最稳定。活性形式 $\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$。
- [ ] $60\,\mathrm{mg}$ 色氨酸 → $1\,\mathrm{mg}$ 烟酸，需 $\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{B}_{6}$。
- [ ] $\mathrm{NAD}^{+}$：糖酵解、三羧酸；$\mathrm{NADP}^{+}$：G6PD → $\mathrm{NADPH}$ 供脂肪酸、胆固醇合成。
- [ ] 糙皮病 pellagra：皮炎、腹泻、痴呆（3D）。RNI 男 $15$、女 $12\,\mathrm{mg}\,\mathrm{NE}/\mathrm{d}$。
- [ ] 异烟肼拮抗 $\mathrm{PP}$；烟酸治高胆固醇；大量 $1\sim 6\,\mathrm{g}/\mathrm{d}$ 潮红，长期 $>500\,\mathrm{mg}$ 肝损伤。
- [ ] 泛酸＝遍多酸＝$\mathrm{B}_{5}$＝二甲基羟丁酸 + $\beta$-丙氨酸。经 4-磷酸泛酰巯乙胺进入 $\mathrm{CoA}$ 和 ACP。
- [ ] $\mathrm{CoA}/\mathrm{ACP}$：酰基转移；$\mathrm{CoA}$ 进线粒体脂酰转运，ACP 在脂肪酸合酶。AI $5.0\,\mathrm{mg}/\mathrm{d}$。严重缺乏：四肢神经痛。
- [ ] 生物素＝噻吩环 + 尿素 + 戊酸侧链；天然活性形式；羧化酶全酶合成酶把它连到 Lys $\varepsilon$-氨基成生物胞素。
- [ ] 丙酮酸羧化酶、乙酰 $\mathrm{CoA}$ 羧化酶；$\mathrm{CO}_{2}$ 固定。生蛋清抗生物素蛋白质；长期抗生素可缺乏。AI $40\,\mu\mathrm{g}/\mathrm{d}$。
- [ ] $\mathrm{B}_{6}$：吡哆醇、吡哆醛、吡哆胺；主要活性磷酸吡哆醛。约 $80\%$ 在肌、结合糖原磷酸化酶。
- [ ] 磷酸吡哆醛：转氨／脱氨、鸟氨酸循环、ALA 合酶、谷氨酸脱羧酶（GABA）、胱硫醚 $\beta$ 合成酶。
- [ ] $\mathrm{B}_{6}$ 缺乏：低血色素小细胞性贫血（反应性贫血）、血清铁增高、脂溢性皮炎。异烟肼结合醛基，须补 $\mathrm{B}_{6}$。$>20\,\mathrm{mg}/\mathrm{d}$ 感觉性周围神经病。
- [ ] 叶酸＝蝶酰谷氨酸。二氢叶酸还原酶 → $\mathrm{FH}_{4}$。血液主力 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$。$\mathrm{N}^{5}$、$\mathrm{N}^{10}$ 结合一碳单位。
- [ ] 甲氨蝶呤、氨蝶呤抑制二氢叶酸还原酶。RNI $400\,\mu\mathrm{g}/\mathrm{d}$ DFE。缺乏 → 巨幼细胞贫血、高同型半胱氨酸、神经管缺陷。
- [ ] $\mathrm{B}_{12}$＝钴胺素，唯一含金属维生素；植物中无。药用：氰钴胺素、羟钴胺素；活性：甲钴胺素、$5'$-脱氧腺苷钴胺素。
- [ ] 吸收必须内因子，部位在回肠。转钴胺素Ⅱ运输，转钴胺素Ⅰ肝储存。RNI $2.4\,\mu\mathrm{g}/\mathrm{d}$。
- [ ] 甲钴胺素：甲硫氨酸合成酶。$5'$-脱氧腺苷钴胺素：L-甲基丙二酰 $\mathrm{CoA}$ 变位酶。缺乏 → 恶性贫血、髓鞘变性、高同型半胱氨酸。
- [ ] $2/3$ 以上高同型半胱氨酸血症与 $\mathrm{B}_{6}$、叶酸、$\mathrm{B}_{12}$ 缺乏有关。
- [ ] 维生素 C＝L-抗坏血酸，一烯二醇，天然活性形式。人不能合成。还原型为主，脱氢型约为 $1/15$。
- [ ] 羟化：含铜酶、对-羟苯丙酮酸、多巴胺 $\beta$、$7\alpha$-羟化酶、胶原 Pro／Lys、肉碱。氧化还原：GSH、MHb、$\mathrm{Fe}^{3+}\rightarrow\mathrm{Fe}^{2+}$、活性氧。
- [ ] RNI $100\,\mathrm{mg}/\mathrm{d}$（15 岁以上）。坏血病 scurvy，缺乏 $3\sim 4$ 个月后出现。过量：尿路草酸盐结石危险。
