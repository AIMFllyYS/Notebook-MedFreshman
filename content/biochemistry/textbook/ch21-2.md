# 第二节　DNA损伤修复

第一节把损伤的因素、类型和碱基置换落到密码子上的错义／无义／同义（含 $\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$ 记法）立完。本节只立修复：纠正错配、清除受损碱基或糖基、恢复正常结构。光复活、烷基化碱基的直接修复、碱基切除、核苷酸切除、重组修复、跨越损伤／$\mathrm{SOS}$ 各是一户，不要并成「都是切除修复」。损伤的双重效应和修复缺陷病交给第三节。

:::concept{term="先问哪一种损伤，再问走光复活、直接修复、切除、重组还是 SOS"}
看见“$\mathrm{DNA}$ 修复”，先不要把所有酶写进同一条流水线。表21-1 的列是修复途径、修复对象、参与的酶或蛋白。嘧啶二聚体可以走光复活，也可以走核苷酸切除；烷基化碱基可以走烷基转移酶直接修复，也可以走碱基切除；双链断裂走同源重组或非同源末端连接；大范围损伤或复制中来不及修的，才走跨越和 $\mathrm{SOS}$。一种损伤可通过多种途径修，一种途径也可参与多种损伤——这不是把户头并掉。
:::

在生命的各种活动中，生物体发生 $\mathrm{DNA}$ 损伤是不可避免的。这种损伤所导致的结局取决于 $\mathrm{DNA}$ 损伤的程度，以及细胞对损伤 $\mathrm{DNA}$ 的修复能力。$\mathrm{DNA}$ 损伤修复是指纠正 $\mathrm{DNA}$ 两条单链间错配的碱基、清除 $\mathrm{DNA}$ 链上受损的碱基或糖基、恢复 $\mathrm{DNA}$ 的正常结构的过程。$\mathrm{DNA}$ 修复（DNA repair）是机体维持 $\mathrm{DNA}$ 结构的完整性与稳定性，保证生命延续和物种稳定的重要环节。

:::definition{label="DNA 损伤修复"}
纠正两条单链间错配的碱基、清除链上受损的碱基或糖基、恢复 $\mathrm{DNA}$ 正常结构的过程。英文 DNA repair。户头是「恢复正常结构」，还不是「带错复制过去」。
:::

:::insight{label="结局是损伤程度乘以修复能力"}
第一节已经写了修对、凋亡、不完全修复。本节把「修复能力」拆成具体途径。问结局不要只答诱变剂名字。
:::

细胞内存在多种修复 $\mathrm{DNA}$ 损伤的途径或系统。常见的 $\mathrm{DNA}$ 损伤修复途径或系统包括直接修复、切除修复、重组修复和损伤跨越修复等（表21-1）。值得注意的是，一种 $\mathrm{DNA}$ 损伤可通过多种途径修复，而一种修复途径也可同时参与多种 $\mathrm{DNA}$ 损伤的修复过程。

**表21-1　常见的DNA损伤的修复途径**

| 修复途径 | 修复对象 | 参与修复的酶或蛋白 |
|---------|---------|-------------------|
| 光复活修复 | 嘧啶二聚体 | 光复活酶 |
| 碱基切除修复 | 受损的碱基 | $\mathrm{DNA}$ 糖苷酶、$\mathrm{AP}$ 核酸内切酶 |
| 核苷酸切除修复 | 嘧啶二聚体、$\mathrm{DNA}$ 螺旋结构的改变 | 大肠埃希菌中 $\mathrm{UvrA}$、$\mathrm{UvrB}$、$\mathrm{UvrC}$ 和 $\mathrm{UvrD}$，人 $\mathrm{XP}$ 系列蛋白 $\mathrm{XPA}$ 和 $\mathrm{XPB}$ 等 |
| 错配修复 | 复制或重组中的碱基配对错误 | 大肠埃希菌中的 $\mathrm{MutH}$、$\mathrm{MutL}$ 和 $\mathrm{MutS}$，人的 $\mathrm{MLH}1$、$\mathrm{MSH}2$、$\mathrm{MSH}3$ 和 $\mathrm{MSH}6$ 等 |
| 重组修复 | 双链断裂 | $\mathrm{MRN}$ 复合物、$\mathrm{RAD}51$、$\mathrm{BRCA}1/2$ |
| 损伤跨越修复 | 大范围的损伤或复制中来不及修复的损伤 | $\mathrm{RecA}$、$\mathrm{LexA}$ 以及其他类型的 $\mathrm{DNA}$ 聚合酶 |

:::definition{label="四种常见系统再加光复活和错配"}
表21-1 列出光复活、碱基切除、核苷酸切除、错配、重组、损伤跨越。正文概括为直接修复、切除修复、重组修复和损伤跨越修复等。光复活在正文里归在「直接修复」下，表里单独成行——表和正文都要认，不要删掉光复活这一行。
:::

:::pitfall{label="不要把六行并成「都是切除修复」"}
碱基切除和核苷酸切除才叫切除修复。光复活是可见光下把二聚体解聚；烷基转移酶把烷基搬到自己身上；重组修的是双链断裂；跨越是先复制再设法修，损伤可以还在。并成一句「切掉再补」，表21-1 的对象列就废了。
:::

:::compare{title="表21-1 六行各管什么"}
| 途径 | 认的是什么损伤 | 不要写成 |
|------|--------------|---------|
| 光复活 | 嘧啶二聚体 | 「切掉一段寡核苷酸」 |
| 碱基切除 | 受损的单个碱基 | 「认螺旋扭曲」 |
| 核苷酸切除 | 嘧啶二聚体或螺旋结构改变 | 「只切一个碱基」 |
| 错配修复 | 复制或重组中的配对错误 | 「只修紫外线二聚体」 |
| 重组修复 | 双链断裂 | 「有互补链的原位填补」 |
| 损伤跨越 | 大范围或复制中来不及修 | 「已经把损伤分子修好」 |

嘧啶二聚体既可以走光复活，也可以走核苷酸切除——对象重叠，机制不重叠。
:::

:::keypoint{label="一种损伤多种途径，一种途径多种损伤"}
这是本版原句。$\mathrm{TT}$ 二聚体：光复活或 $\mathrm{NER}$。烷基化碱基：直接修复或 $\mathrm{BER}$。不要为了「一一对应」把表改成互斥。
:::

## 一、有些DNA损伤可以被直接修复

直接修复是最简单的一种 $\mathrm{DNA}$ 损伤的修复方式。修复酶直接作用于受损的 $\mathrm{DNA}$，使之恢复为原来的结构。

:::definition{label="直接修复"}
修复酶直接作用于受损的 $\mathrm{DNA}$，使之恢复为原来的结构。本版下分三户：嘧啶二聚体的光复活、烷基化碱基的烷基转移、单链断裂的连接酶封口。
:::

### （一）DNA的嘧啶二聚体可以被直接修复

嘧啶二聚体的直接修复又被称为光复活修复或光复活作用。生物体内存在着一种光复活酶（photoreactivating enzyme），能够直接识别和结合于 $\mathrm{DNA}$ 链上的嘧啶二聚体部位。在可见光（$400\,\mathrm{nm}$）激发下，光复活酶可将嘧啶二聚体解聚为原来的单体核苷酸形式，完成修复（图21-3）。光复活酶最初在低等生物中发现，有两个与吸收光子有关的生色基团，次甲基四氢叶酸和 $\mathrm{FADH}_{2}$。次甲基四氢叶酸吸收光子后将 $\mathrm{FADH}_{2}$ 激活，再由激活的 $\mathrm{FADH}_{2}$ 将电子转移给嘧啶二聚体，使其还原。鸟类等高等生物虽然也存在光复活酶，但是光复活修复并不是高等生物修复嘧啶二聚体的主要方式。哺乳动物细胞缺乏光复活酶。

:::definition{label="光复活修复"}
又称光复活作用。光复活酶（photoreactivating enzyme）识别并结合嘧啶二聚体；在可见光（$400\,\mathrm{nm}$）激发下，将二聚体解聚为原来的单体核苷酸。不切除、不另合成一段 $\mathrm{DNA}$。
:::

:::definition{label="光复活酶的两个生色基团"}
次甲基四氢叶酸和 $\mathrm{FADH}_{2}$。次甲基四氢叶酸吸收光子后激活 $\mathrm{FADH}_{2}$，再由激活的 $\mathrm{FADH}_{2}$ 把电子转移给嘧啶二聚体，使其还原。最初在低等生物中发现。
:::

:::timeline{period="光复活"}
- **识别** 光复活酶结合嘧啶二聚体部位
- **可见光** 约 400 nm 激发
- **电子** 次甲基四氢叶酸吸光，激活 FADH2，电子交给二聚体
- **产物** 二聚体解聚为原来的单体核苷酸
- **物种** 低等生物为主；鸟类等高等生物有酶但不是主要方式；哺乳动物细胞缺乏光复活酶
:::

::figure{src="/images/biochemistry/textbook/p0437_01.png" caption="图21-3　胸腺嘧啶二聚体的 DNA 光裂合修复" alt="左侧正常双链上相邻两个 T；紫外线照射后两个 T 共价连成嘧啶二聚体并使链局部凸起；光复活酶识别并结合在二聚体部位；可见光激发使二聚体解聚，恢复原来的单体核苷酸"}

:::insight{label="图21-3 是一个圈：UV 做二聚体，可见光把它拆开"}
左上正常 $\mathrm{A}$-$\mathrm{T}$、$\mathrm{T}$-$\mathrm{A}$；箭头「紫外线照射形成嘧啶二聚体」到右上两个蓝色 $\mathrm{T}$ 连在一起；再「光复活酶识别并结合在二聚体部位」到下方酶结合；「可见光激发二聚体解聚」回到左上。损伤用的是紫外线，修复用的是可见光，不要写成「还是紫外线修好的」。
:::

:::pitfall{label="光复活不是切除修复"}
酶结合后解聚，二聚体变回两个单体。没有切寡核苷酸、没有 $\mathrm{DNA}$ 聚合酶填补。写成「光裂合酶把二聚体切掉」，和图21-5 的碱基切除就并户了。
:::

:::pitfall{label="哺乳动物不要写成主要靠光复活修 TT"}
「哺乳动物细胞缺乏光复活酶」。高等生物修嘧啶二聚体的主要方式在后文核苷酸切除。鸟类有酶，但「并不是高等生物修复嘧啶二聚体的主要方式」。
:::

:::compare{title="紫外线损伤 vs 可见光修复"}
| | 波长角色 | 产物 |
|--|---------|------|
| 低波长紫外线 | 同一条链相邻嘧啶共价连接 | $\mathrm{TT}$／$\mathrm{CT}$／$\mathrm{CC}$ 二聚体，链弯曲扭结 |
| 可见光约 $400\,\mathrm{nm}$ | 激发光复活酶 | 二聚体解聚为单体 |

损伤和修复用的不是同一段光谱。
:::

### （二）DNA的烷基化碱基可以被直接修复

催化此类直接修复的酶是一类特异的烷基转移酶，可以将烷基从烷基化核苷酸直接转移到烷基转移酶蛋白自身的肽链上，在修复 $\mathrm{DNA}$ 的同时，酶自身发生不可逆转性失活。比如，人类的 $\mathrm{O}^{6}$-甲基鸟嘌呤-$\mathrm{DNA}$ 甲基转移酶，能够将 $\mathrm{DNA}$ 分子中 $\mathrm{O}^{6}$-甲基鸟嘌呤上的 $\mathrm{O}^{6}$ 位甲基转移到酶蛋白自身的半胱氨酸残基上，使甲基化的鸟嘌呤恢复其正常的结构（图21-4）。

:::note{label="图21-4 电子版缺失"}
图21-4　烷基化碱基的直接修复。对应 `p0437_02.png` 为 $0$ 字节，不嵌入。过程以本段为准：烷基从烷基化核苷酸转移到酶自身肽链，$\mathrm{O}^{6}$-甲基鸟嘌呤的甲基转到酶的半胱氨酸上，酶不可逆失活。
:::

:::definition{label="烷基转移酶直接修复"}
特异的烷基转移酶把烷基从烷基化核苷酸直接转移到酶蛋白自身的肽链上。$\mathrm{DNA}$ 恢复结构，酶自身不可逆失活。不是把烷基「水解掉再循环使用同一分子酶」。
:::

:::definition{label="O6-甲基鸟嘌呤-DNA 甲基转移酶"}
人类的这一种酶，把 $\mathrm{O}^{6}$-甲基鸟嘌呤上的 $\mathrm{O}^{6}$ 位甲基转移到自身半胱氨酸残基上，使甲基化的鸟嘌呤恢复正常结构。
:::

:::pitfall{label="酶修完自己就废了，不是催化剂循环"}
教材写「不可逆转性失活」。把烷基转移酶答成普通可循环酶，化学计量就错了：一分子酶对应一次修复。
:::

:::compare{title="光复活 vs 烷基直接修复"}
| | 识别什么 | 能量或代价 | 酶的命运 |
|--|---------|-----------|---------|
| 光复活 | 嘧啶二聚体 | 可见光约 $400\,\mathrm{nm}$ | 生色基团传递电子，正文未写不可逆失活 |
| 烷基转移 | 烷基化碱基（点名 $\mathrm{O}^{6}$-甲基鸟嘌呤） | 烷基搬到酶自己身上 | 酶不可逆失活 |

两户都叫直接修复：都不切 $\mathrm{DNA}$ 链。对象和代价不同。
:::

### （三）DNA的单链断裂可以被直接修复

$\mathrm{DNA}$ 连接酶能够催化 $\mathrm{DNA}$ 双螺旋结构中一条链上缺口处的 $5'$-磷酸基团与相邻片段的 $3'$-羟基之间形成磷酸二酯键，从而直接参与 $\mathrm{DNA}$ 单链断裂的修复，如电离辐射所造成的 $\mathrm{DNA}$ 单链上的切口。

:::definition{label="连接酶直接修单链切口"}
催化缺口处 $5'$-磷酸与相邻片段 $3'$-羟基形成磷酸二酯键。例：电离辐射造成的单链切口。前提是这条链只是切口、对面互补链还在。
:::

:::pitfall{label="连接酶封口不是同源重组"}
单链切口有互补链，连接酶可以直接封。双链断裂没有互补链，走第三节的同源重组或非同源末端连接。把所有「断了」都交给连接酶，$\mathrm{MRN}$ 和 $\mathrm{Ku}70$-$\mathrm{Ku}80$ 就没有前置。
:::

:::keypoint{label="直接修复三户"}
- 嘧啶二聚体：光复活酶＋可见光，解聚为单体；哺乳动物缺此酶。
- 烷基化碱基：烷基转移到酶自身，酶不可逆失活；点名 $\mathrm{O}^{6}$-甲基鸟嘌呤-$\mathrm{DNA}$ 甲基转移酶。图21-4 电子版缺失。
- 单链切口：连接酶封 $5'$-磷酸与 $3'$-羟基。
:::

## 二、切除修复是最普遍的DNA损伤修复方式

切除修复是生物界最普遍的一种 $\mathrm{DNA}$ 损伤的修复方式。通过此修复方式，可将不正常的碱基或核苷酸切除并替换掉。依据识别损伤机制的不同，又分为碱基切除修复和核苷酸切除修复两种不同的类型。

:::definition{label="切除修复"}
将不正常的碱基或核苷酸切除并替换掉。生物界最普遍。按识别机制分成碱基切除修复（$\mathrm{BER}$）和核苷酸切除修复（$\mathrm{NER}$）。错配修复后文写成碱基切除修复的一种特殊形式，表21-1 仍单独成行。
:::

:::compare{title="碱基切除 vs 核苷酸切除：先分「认什么」"}
| | 认的是什么 | 切掉什么 |
|--|-----------|---------|
| 碱基切除 | 具体的受损碱基（糖苷酶特异识别） | 先切碱基，再切磷酸核糖，换一个核苷酸 |
| 核苷酸切除 | 损伤对双螺旋造成的扭曲，并不识别具体是哪一种损伤 | 损伤两侧切开，去掉一段受损寡核苷酸 |

后文说切除修复「并不局限于某种特殊原因造成的损伤」，主要指 $\mathrm{NER}$ 这一套可以修一系列性质各异的损伤。
:::

碱基切除修复（base excision repair）依赖于生物体内存在的一类特异的 $\mathrm{DNA}$ 糖苷酶。整个修复过程包括：①识别水解：$\mathrm{DNA}$ 糖苷酶特异性识别 $\mathrm{DNA}$ 链中已受损的碱基并将其水解切除，产生一个无碱基位点。②无碱基位点的切除：在此位点的 $5'$ 和 $3'$ 端，无碱基位点核酸内切酶将 $\mathrm{DNA}$ 链的磷酸二酯键切开，同时去除剩余的磷酸核糖部分。③合成：$\mathrm{DNA}$ 聚合酶在缺口处以另一条链为模板修补合成互补序列。④连接：由 $\mathrm{DNA}$ 连接酶将切口重新连接，使 $\mathrm{DNA}$ 恢复正常结构（图21-5）。

抑癌蛋白 $\mathrm{p}53$ 在哺乳动物细胞中参与调控碱基切除修复。直接证据是 $\mathrm{DNA}$ 烷化剂诱导的 $\mathrm{DNA}$ 损伤，在表达野生型 $\mathrm{p}53$ 的细胞可被有效修复，而在 $\mathrm{p}53$ 缺失的细胞，其修复速度明显减慢。

:::definition{label="碱基切除修复"}
碱基切除修复（base excision repair，$\mathrm{BER}$）：依赖特异的 $\mathrm{DNA}$ 糖苷酶。四步：识别水解受损碱基产生 $\mathrm{AP}$ 位点 $\rightarrow$ $\mathrm{AP}$ 核酸内切酶切开并去掉磷酸核糖 $\rightarrow$ 聚合酶以互补链为模板填补 $\rightarrow$ 连接酶封口。
:::

:::definition{label="p53 调控 BER"}
抑癌蛋白 $\mathrm{p}53$ 在哺乳动物细胞中参与调控碱基切除修复。烷化剂诱导的损伤：有野生型 $\mathrm{p}53$ 则有效修复，$\mathrm{p}53$ 缺失则修复明显减慢。这是调控，不是说 $\mathrm{p}53$ 自己是糖苷酶。
:::

:::insight{label="图21-5 按顺时针读：受损碱基 → AP 位点 → 单核苷酸缺口 → 填补连接"}
右上：受损碱基（蓝色短棒）凸起。$\mathrm{DNA}$ 糖苷酶特异性识别并水解，产生 $\mathrm{AP}$ 位点（位子空了，糖还在）。切剩余磷酸核糖，产生单核苷酸缺口。左下：以对应链为模板填补并连接。看图先认「先掉碱基、再掉磷酸核糖」，不要画成一次切掉一整段寡核苷酸——那是 $\mathrm{NER}$。
:::

:::pitfall{label="BER 不要写成一次切掉含损伤的寡核苷酸"}
糖苷酶只切碱基；$\mathrm{AP}$ 内切酶再切磷酸二酯键并去掉磷酸核糖。切一段寡核苷酸是核苷酸切除的第②步。
:::

:::keypoint{label="BER 四步对图21-5"}
- 识别水解 $\rightarrow$ $\mathrm{AP}$ 位点。
- 切磷酸核糖 $\rightarrow$ 单核苷酸缺口。
- 聚合酶填补。
- 连接酶连接。
- $\mathrm{p}53$ 管速度，不是第四种酶。
:::

与碱基切除修复不同，核苷酸切除修复系统并不识别具体的损伤，而是识别损伤对 $\mathrm{DNA}$ 双螺旋结构所造成的扭曲，但修复过程与碱基切除修复相似。①首先，由一个酶系统识别 $\mathrm{DNA}$ 损伤部位；②其次，在损伤部位两侧切开 $\mathrm{DNA}$ 链，去除两个切口之间的一段受损的寡核苷酸；③再次，在 $\mathrm{DNA}$ 聚合酶作用下，以另一条链为模板，合成一段新的 $\mathrm{DNA}$，填补缺损区；④最后由连接酶连接，完成损伤修复。

切除修复是 $\mathrm{DNA}$ 损伤修复的一种普遍形式，它并不局限于某种特殊原因造成的损伤，而能一般性地识别和纠正 $\mathrm{DNA}$ 链及 $\mathrm{DNA}$ 双螺旋结构的变化，修复系统能够使用相同的机制和一套修复蛋白去修复一系列性质各异的损伤。

:::definition{label="核苷酸切除修复"}
核苷酸切除修复（nucleotide excision repair，$\mathrm{NER}$）：不识别具体是哪一种损伤，识别的是损伤对双螺旋造成的扭曲。四步：酶系统识别 $\rightarrow$ 损伤两侧切开并去掉一段受损寡核苷酸 $\rightarrow$ 聚合酶以互补链填补 $\rightarrow$ 连接酶连接。
:::

:::compare{title="BER 四步 vs NER 四步"}
| 步 | $\mathrm{BER}$ | $\mathrm{NER}$ |
|--|------|------|
| ① | 糖苷酶认受损碱基并水解 | 酶系统认损伤部位（认扭曲） |
| ② | $\mathrm{AP}$ 内切酶切磷酸核糖 | 两侧切开，去掉一段寡核苷酸 |
| ③ | 聚合酶补一个（或短）互补序列 | 聚合酶合成一段新 $\mathrm{DNA}$ 填缺损区 |
| ④ | 连接酶 | 连接酶 |

相似的是「认、切、补、连」；不同的是认什么、切多长。
:::

:::insight{label="「普遍形式」这句话主要给 NER"}
「不局限于某种特殊原因」「一套蛋白修一系列性质各异的损伤」。$\mathrm{BER}$ 的糖苷酶是特异的，一种酶认一类受损碱基。把「普遍」写成糖苷酶也不挑碱基，表21-1 的「受损的碱基／$\mathrm{DNA}$ 糖苷酶」就反了。
:::

人类的 $\mathrm{DNA}$ 损伤核苷酸切除修复需要大约 $30$ 多种蛋白质分子的参与。其修复过程如下：①首先，由损伤部位识别蛋白 $\mathrm{XPC}$ 和 $\mathrm{XPA}$ 等，再加上复制蛋白 $\mathrm{SSB}$，结合在损伤 $\mathrm{DNA}$ 的部位；②其次，$\mathrm{XPB}$ 和 $\mathrm{XPD}$ 发挥解旋酶的活性，与上述蛋白质分子共同作用在受损 $\mathrm{DNA}$ 周围形成一个凸起；③再次，$\mathrm{XPG}$ 与 $\mathrm{XPF}$ 发生构象改变，分别在凸起的 $3'$ 端和 $5'$ 端发挥核酸内切酶作用，在增殖细胞核抗原（$\mathrm{PCNA}$）的帮助下，切除并释放受损的寡核苷酸；④再者，遗留的缺损区由 $\mathrm{DNA}$ 聚合酶 $\delta$ 或 $\varepsilon$ 进行修补合成；⑤最后，由连接酶完成连接。

核苷酸切除修复不仅能够修复整个基因组中的损伤，而且还能够修复那些正在转录基因模板链上的损伤，后者又称为转录偶联修复（transcription-coupled repair），因此，更具积极意义。在此修复中，所不同的是由 $\mathrm{RNA}$ 聚合酶承担起识别损伤部位的任务。

:::definition{label="人类 NER 约 30 种蛋白的五步"}
① $\mathrm{XPC}$、$\mathrm{XPA}$ 等加复制蛋白 $\mathrm{SSB}$ 结合损伤部位；② $\mathrm{XPB}$、$\mathrm{XPD}$ 解旋，周围形成凸起；③ $\mathrm{XPG}$ 在凸起 $3'$ 端、$\mathrm{XPF}$ 在 $5'$ 端切开，在 $\mathrm{PCNA}$ 帮助下切除并释放受损寡核苷酸；④ $\mathrm{DNA}$ 聚合酶 $\delta$ 或 $\varepsilon$ 填补；⑤ 连接酶连接。
:::

:::definition{label="转录偶联修复"}
转录偶联修复（transcription-coupled repair）：修正在转录的基因模板链上的损伤。识别损伤部位的任务由 $\mathrm{RNA}$ 聚合酶承担。$\mathrm{NER}$ 既能修整个基因组，也能走这一条，后者更具积极意义。
:::

:::compare{title="全基因组 NER vs 转录偶联修复"}
| | 修哪里 | 谁来识别损伤 |
|--|--------|------------|
| 全基因组核苷酸切除 | 整个基因组中的损伤 | $\mathrm{XPC}$、$\mathrm{XPA}$ 等 |
| 转录偶联修复 | 正在转录的基因模板链 | $\mathrm{RNA}$ 聚合酶 |

后面的解旋、双侧切开、聚合酶 $\delta$／$\varepsilon$、连接，仍是切除修复这一套。差在第一步谁发现损伤。
:::

:::pitfall{label="XPG 在 3′，XPF 在 5′，不要记反"}
表21-2 和五步原文一致：$\mathrm{XPG}$ 走 $3'$ 端，$\mathrm{XPF}$ 走 $5'$ 端。记成「$\mathrm{F}$ 在前所以 $5'$ 对 $\mathrm{XPG}$」会反。
:::

:::pitfall{label="大肠埃希菌 NER 蛋白是 Uvr，人是 XP"}
表21-1：大肠埃希菌 $\mathrm{UvrA}$、$\mathrm{UvrB}$、$\mathrm{UvrC}$、$\mathrm{UvrD}$；人 $\mathrm{XPA}$、$\mathrm{XPB}$ 等。不要把 $\mathrm{Uvr}$ 写进人细胞，也不要用外校的 $\mathrm{UvrABC}$ 逐步取代表21-2。
:::

碱基错配修复校正 $\mathrm{DNA}$ 复制中错配的碱基。错配是指非 Watson-Crick 碱基配对。碱基错配修复也可被看作是碱基切除修复的一种特殊形式，是维持细胞中 $\mathrm{DNA}$ 结构正确的重要方式，主要负责纠正：①复制与重组中出现的碱基配对错误；②因碱基损伤所致的碱基配对错误；③碱基插入；④碱基缺失。从低等生物到高等生物，均拥有保守的碱基错配修复系统或途径。

:::definition{label="错配修复"}
校正非 Watson-Crick 碱基配对。本版也把它看作碱基切除修复的一种特殊形式。纠正四类：复制与重组中的配对错误、损伤所致配对错误、插入、缺失。表21-1 仍单独成行，对象写「复制或重组中的碱基配对错误」。
:::

:::pitfall{label="「特殊形式」不是把 MMR 从账本里删掉"}
可以看成 $\mathrm{BER}$ 的特殊形式，但酶系统是 $\mathrm{MutH}$／$\mathrm{MutL}$／$\mathrm{MutS}$ 和人的 $\mathrm{MLH}1$、$\mathrm{MSH}2$ 等，不是糖苷酶加 $\mathrm{AP}$ 内切酶那一套。并成「就是图21-5」，表21-3 就没有户头。
:::

大肠埃希菌参与 $\mathrm{DNA}$ 复制中错配修复的蛋白包括 $\mathrm{Mut}$（mutase）$\mathrm{H}$、$\mathrm{MutL}$、$\mathrm{MutS}$、$\mathrm{DNA}$ 解旋酶、单链 $\mathrm{DNA}$ 结合蛋白、核酸外切酶Ⅰ、$\mathrm{DNA}$ 聚合酶Ⅲ，以及 $\mathrm{DNA}$ 连接酶等 $10$ 余种蛋白质分子或相关酶成分，修复过程十分复杂。修复过程中面临的主要问题是如何区分母链和子链。在细菌 $\mathrm{DNA}$ 中甲基化修饰是一个重要标志，母链是高度甲基化的，主要是其腺嘌呤 $\mathrm{A}$ 发生甲基化修饰，而新合成子链中的腺嘌呤 $\mathrm{A}$ 的甲基化修饰尚未进行，提示错配修复应在此链上进行。首先由 $\mathrm{MutS}$ 蛋白识别错配碱基，随后由 $\mathrm{MutL}$ 和 $\mathrm{MutH}$ 等蛋白质分子协同相应的核酸外切酶，将包含错配点在内的一小段 $\mathrm{DNA}$ 水解、切除，经修补和连接后，恢复 $\mathrm{DNA}$ 正确的碱基配对。

:::definition{label="细菌靠甲基化区分母链和子链"}
母链腺嘌呤 $\mathrm{A}$ 高度甲基化，新合成子链的 $\mathrm{A}$ 尚未甲基化，错配修复应在子链上进行。这是细菌的标志，不是真核的标志。
:::

:::definition{label="大肠埃希菌 MutS → MutL/MutH"}
$\mathrm{MutS}$ 识别错配；$\mathrm{MutL}$ 和 $\mathrm{MutH}$ 等协同核酸外切酶，把包含错配点在内的一小段 $\mathrm{DNA}$ 水解切除，再修补连接。参与者还有解旋酶、单链结合蛋白、外切酶Ⅰ、聚合酶Ⅲ、连接酶等十余种。
:::

:::cause-effect{title="为什么甲基化能告诉修复系统切哪一条"}
- **因** 复制后母链 $\mathrm{A}$ 已甲基化，子链 $\mathrm{A}$ 尚未甲基化
- **果** 修复系统把尚未甲基化的那一条当作应被切开、切除错配的链
:::

:::pitfall{label="切的是未甲基化的子链，不是把甲基化母链当错误"}
甲基化是「这是旧链」的标记。写成「甲基化的碱基就是损伤，要切掉」，烷基化直接修复和错配修复就并反了。思考题「为什么甲基化状态可以被修复系统利用」落在这一户。
:::

继细菌错配修复机制被揭示之后，真核细胞的错配修复机制的研究也取得很大进展。现已发现多种与大肠埃希菌的 $\mathrm{MutS}$ 和 $\mathrm{MutL}$ 高度同源的参与错配修复的蛋白质分子，如与大肠埃希菌 $\mathrm{MutS}$ 高度同源的人类的 $\mathrm{MSH}2$（MutS Homolog 2）、$\mathrm{MSH}6$ 和 $\mathrm{MSH}3$ 等。$\mathrm{MSH}2$ 和 $\mathrm{MSH}6$ 的复合物可识别包括碱基错配、插入、缺失等 $\mathrm{DNA}$ 损伤，而由 $\mathrm{MSH}2$ 和 $\mathrm{MSH}3$ 形成的蛋白质复合物则主要识别碱基的插入与缺失。真核细胞并不像原核细胞那样以甲基化来区分母链和子链，可能是依赖修复酶与复制复合体之间的联合作用识别新合成的子链。有关人类错配修复系统成员的一般情况见表21-3。

:::keypoint{label="切除修复这一大节的三户"}
- $\mathrm{BER}$：糖苷酶认具体受损碱基，图21-5。
- $\mathrm{NER}$：认螺旋扭曲，切一段寡核苷酸；人约 $30$ 种蛋白，表21-2 为 $\mathrm{XPA}$–$\mathrm{XPG}$；另有转录偶联修复。
- 错配修复：可看作 $\mathrm{BER}$ 特殊形式；细菌 $\mathrm{MutS}/\mathrm{L}/\mathrm{H}$ 加甲基化区分母子链；人表21-3。
:::

## 三、DNA严重损伤时需要同源重组修复或非同源末端连接修复

双链 $\mathrm{DNA}$ 分子中的一条链断裂，可通过模板依赖的 $\mathrm{DNA}$ 修复系统修复，不会给细胞带来严重后果。然而，$\mathrm{DNA}$ 分子的双链断裂是一种极为严重的损伤。与其他修复方式明显不同的是，双链断裂修复由于没有互补链可言，因此难以及时直接提供修复断裂所必需的互补链序列信息。如果 $\mathrm{DNA}$ 双链断裂不能得到及时而准确的修复，可能会导致基因的突变、基因组的不稳定、染色体的丢失或者细胞的凋亡甚至癌变。为此，细胞已经进化出同源重组修复和非同源末端连接修复两种重要的修复机制，相互协调共同修复 $\mathrm{DNA}$ 的双链断裂，维持基因组完整和稳定。

:::definition{label="双链断裂为什么特别严重"}
没有互补链，不能及时直接提供断裂处所需的序列信息。不能及时准确修复：基因突变、基因组不稳定、染色体丢失、凋亡甚至癌变。
:::

:::definition{label="DSB 的两种修复"}
同源重组修复与非同源末端连接修复，相互协调，共同修双链断裂。单链断裂走模板依赖系统，不是这一节的主账。
:::

:::compare{title="单链断裂 vs 双链断裂：修复前提"}
| | 互补信息 | 本版态度 |
|--|---------|---------|
| 一条链断 | 另一条链可当模板 | 不会给细胞带来严重后果 |
| 两条链都断 | 没有互补链可言 | 极为严重；同源重组或非同源末端连接 |

第一节已经写双链断裂与致死性效应直接联系。本节给出两条出路。
:::

**1. 同源重组修复**　所谓的同源重组修复（homologous recombination repair），指的是参加重组的两段双链 $\mathrm{DNA}$ 在相当长的范围内序列相同或十分相近（长度 $\ge 200\,\mathrm{bp}$），这样就能保证重组后生成的新区序列正确。同源重组修复是发生在有同源序列的 $\mathrm{DNA}$ 之间的一种修复方式，具有较高的保真度。真核细胞中，需要以未受损伤的姐妹染色单体的同源序列来作为其修复的模板，因此，同源重组修复过程主要发生在细胞周期的 $\mathrm{S}$ 和 $\mathrm{G}_{2}$ 期。

同源重组修复过程大体分为四个阶段：包括 $\mathrm{DNA}$ 断裂末端切除，单链末端入侵形成置换环，捕获断裂末端进行连接，两条双链 $\mathrm{DNA}$ 解离完成修复。首先 $\mathrm{MRN}$ 复合物（$\mathrm{MRE}11$-$\mathrm{RAD}50$-$\mathrm{NBS}1$ complex）和 $\mathrm{CtIP}$（CtBP-interacting protein，$\mathrm{CtIP}$）共同发挥作用进行 $\mathrm{DNA}$ 断裂末端的切除，产生一段短的 $3'$-单链 $\mathrm{DNA}$（single strand DNA，$\mathrm{ssDNA}$）。$3'$-$\mathrm{ssDNA}$ 一旦产生立即被复制蛋白 $\mathrm{A}$（replication protein A，$\mathrm{RPA}$）复合物结合包裹以防止其被核酸酶降解，然后再经核酸外切酶 $1$（exonuclease 1，$\mathrm{EXO}1$）或核酸酶-解旋酶蛋白复合物 $\mathrm{DNA}2$-$\mathrm{BLM}$ 进一步切除产生长的 $3'$-$\mathrm{ssDNA}$。随后在 $\mathrm{BRCA}2$-$\mathrm{PALB}2$ 以及 $\mathrm{BRCA}1$-$\mathrm{BRAD}1$ 复合物的介导下，重组酶 $\mathrm{RAD}51$（细菌 $\mathrm{RecA}$ 的真核同源物）替换掉 $\mathrm{RPA}$ 加载到 $3'$-$\mathrm{ssDNA}$ 上，形成 $\mathrm{RAD}51$-$\mathrm{ssDNA}$ 核蛋白丝。$\mathrm{RAD}51$-$\mathrm{ssDNA}$ 核蛋白丝入侵至另一条双链 $\mathrm{DNA}$（即「供体」）的同源序列区，称为单链入侵（single strand invasion）。随后 $\mathrm{RAD}51$ 蛋白解离，形成异源双链体 $\mathrm{DNA}$（heteroduplex DNA）产生一个由三链 $\mathrm{DNA}$ 组成的置换环（displacement loop，$\mathrm{D}$-loop）。此时供体双链 $\mathrm{DNA}$ 中的一条链被置换。随后在 $\mathrm{DNA}$ 聚合酶的作用下 $3'$-$\mathrm{ssDNA}$ 合成延伸双链 $\mathrm{DNA}$，置换环也随之向前迁移，直到置换环中的另一供体 $\mathrm{DNA}$ 单链与第二个 $\mathrm{DNA}$ 断端的 $3'$-$\mathrm{ssDNA}$ 退火互补，称为第二断端捕获（second-end capture）。然后经连接反应形成两个霍利迪连接体（double Holliday junction，$\mathrm{dHJ}$）结构。最后 $\mathrm{dHJ}$ 结构被 $\mathrm{DNA}$ 解旋酶解开或被核酸酶切开解离，产生非交叉或交叉双链 $\mathrm{DNA}$ 产物，完成同源重组修复，详见图21-6。重组修复过程中先后有 $\mathrm{MRE}11$、$\mathrm{RAD}50$、$\mathrm{NBS}1$、$\mathrm{EXO}1$、$\mathrm{DNA}2$、$\mathrm{BLM}$、$\mathrm{RPA}$、$\mathrm{BRCA}2$、$\mathrm{PALB}2$、$\mathrm{BRCA}1$、$\mathrm{BRAD}1$ 和 $\mathrm{RAD}51$ 等相关蛋白质或酶的参与。

:::definition{label="同源重组修复"}
同源重组修复（homologous recombination repair）：参加重组的两段双链 $\mathrm{DNA}$ 在相当长范围内序列相同或十分相近（长度 $\ge 200\,\mathrm{bp}$），保证新区序列正确。保真度较高。真核以未受损姐妹染色单体的同源序列为模板，主要发生在 $\mathrm{S}$ 和 $\mathrm{G}_{2}$ 期。
:::

:::definition{label="MRN 复合物"}
$\mathrm{MRE}11$-$\mathrm{RAD}50$-$\mathrm{NBS}1$ complex，与 $\mathrm{CtIP}$ 共同做断裂末端切除，产生短的 $3'$-$\mathrm{ssDNA}$。表21-1 重组修复一行写的「$\mathrm{MRN}$ 复合物、$\mathrm{RAD}51$、$\mathrm{BRCA}1/2$」从这里展开。
:::

:::definition{label="同源重组四阶段"}
①断裂末端切除；②单链末端入侵形成置换环；③捕获断裂末端进行连接；④两条双链解离完成修复。图21-6 把过程画成 $\mathrm{A}$–$\mathrm{G}$。
:::

:::timeline{period="同源重组修复"}
- **末端切除** MRN（MRE11-RAD50-NBS1）加 CtIP，切出短 3'-ssDNA；RPA 包裹防降解；EXO1 或 DNA2-BLM 再切成长 3'-ssDNA
- **换载** BRCA2-PALB2、BRCA1-BRAD1 介导，RAD51（细菌 RecA 的真核同源物）替换 RPA，成核蛋白丝
- **入侵** 核蛋白丝入侵供体同源区（单链入侵）；RAD51 解离，成异源双链和 D-loop
- **延伸与捕获** 聚合酶延伸，D-loop 前移；第二断端捕获；连接成两个霍利迪连接体 dHJ
- **解离** 解旋酶解开或核酸酶切开，得到非交叉或交叉双链产物
:::

先后参与：$\mathrm{MRE}11$、$\mathrm{RAD}50$、$\mathrm{NBS}1$、$\mathrm{EXO}1$、$\mathrm{DNA}2$、$\mathrm{BLM}$、$\mathrm{RPA}$、$\mathrm{BRCA}2$、$\mathrm{PALB}2$、$\mathrm{BRCA}1$、$\mathrm{BRAD}1$、$\mathrm{RAD}51$。本版把 $\mathrm{BRCA}1$ 的伙伴写成 $\mathrm{BRAD}1$。$\mathrm{RAD}51$ 是细菌 $\mathrm{RecA}$ 的真核同源物。不要用其他教材的蛋白全表替换这一句。
:::

:::pitfall{label="同源重组主要在 S/G2，因为要姐妹染色单体当模板"}
没有未受损的同源姐妹染色单体，这条高保真路不好走。写成「整个细胞周期都主要靠同源重组」，非同源末端连接「整个细胞周期的主要途径」那一句就冲突了。
:::

:::pitfall{label="dHJ 解离可以有交叉也可以无交叉"}
最后一步：解旋酶解开或核酸酶切开，产生非交叉或交叉双链 $\mathrm{DNA}$ 产物。写成「同源重组一定交叉互换」，图21-6 的 $\mathrm{G}$ 上半（无交换）就没了。
:::

**2. 非同源末端连接修复**　非同源末端连接（non-homologous end joining，$\mathrm{NHEJ}$）修复，通过直接修饰和连接两个 $\mathrm{DNA}$ 断端，在不需要同源模板的情况下对 $\mathrm{DNA}$ 双链断裂（DNA double strand breaks，$\mathrm{DSB}$）进行容易出错的修复，是整个细胞周期 $\mathrm{DNA}$ 双链断裂修复的主要途径。$\mathrm{DSB}$ 发生后，$\mathrm{Ku}70$-$\mathrm{Ku}80$ 蛋白异源二聚体首先结合到断裂末端，随后 $\mathrm{DNA}$ 依赖性蛋白激酶催化亚基（DNA-dependent protein kinase catalytic subunit，$\mathrm{DNA}\ \mathrm{PKcs}$）被募集至断裂位点并被激活，使断裂的 $\mathrm{DNA}$ 末端保持接近，进而招募 $\mathrm{Artemis}$ 核酸酶对 $\mathrm{DNA}$ 断端进行加工，最后由 $\mathrm{DNA}$ 连接酶 $4$（DNA ligase 4，$\mathrm{LIG}4$）和 $\mathrm{X}$ 射线修复交叉互补蛋白 $4$（X-ray repair cross-complementing protein 4，$\mathrm{XRCC}4$）进行 $\mathrm{DNA}$ 末端的连接，完成修复。非同源末端连接重组修复既是修复 $\mathrm{DNA}$ 损伤的一种方式，又可以被看作是一种生理性基因重组的策略，将原来并未连接在一起的基因或片段连接产生新的组合，如 $\mathrm{B}$ 淋巴细胞和 $\mathrm{T}$ 淋巴细胞的受体基因，以及免疫球蛋白基因的构建与重排等。

:::definition{label="非同源末端连接"}
非同源末端连接（non-homologous end joining，$\mathrm{NHEJ}$）：直接修饰并连接两个 $\mathrm{DNA}$ 断端，不需要同源模板，对 $\mathrm{DSB}$ 进行容易出错的修复。是整个细胞周期双链断裂修复的主要途径。
:::

:::definition{label="NHEJ 的蛋白顺序"}
$\mathrm{Ku}70$-$\mathrm{Ku}80$ 异源二聚体先结合断端 $\rightarrow$ 募集并激活 $\mathrm{DNA}\ \mathrm{PKcs}$，使末端保持接近 $\rightarrow$ $\mathrm{Artemis}$ 加工断端 $\rightarrow$ $\mathrm{LIG}4$ 与 $\mathrm{XRCC}4$ 连接。
:::

:::definition{label="NHEJ 也是生理性基因重组策略"}
可把原来并未连在一起的基因或片段连成新组合。本版点名：$\mathrm{B}$ 淋巴细胞和 $\mathrm{T}$ 淋巴细胞的受体基因，以及免疫球蛋白基因的构建与重排。
:::

:::compare{title="同源重组 vs 非同源末端连接"}
| | 要不要同源模板 | 保真度 | 细胞周期 | 本版关键蛋白 |
|--|--------------|--------|---------|------------|
| 同源重组 | 要，真核主要用姐妹染色单体，同源区 $\ge 200\,\mathrm{bp}$ | 较高 | 主要 $\mathrm{S}$、$\mathrm{G}_{2}$ | $\mathrm{MRN}$、$\mathrm{RAD}51$、$\mathrm{BRCA}1/2$ 等 |
| $\mathrm{NHEJ}$ | 不要 | 容易出错 | 整个细胞周期的主要途径 | $\mathrm{Ku}70$-$\mathrm{Ku}80$、$\mathrm{DNA}\ \mathrm{PKcs}$、$\mathrm{Artemis}$、$\mathrm{LIG}4$、$\mathrm{XRCC}4$ |

「相互协调共同修复」。不是「有同源重组就不用 $\mathrm{NHEJ}$」。
:::

:::pitfall{label="NHEJ 容易出错，不要写成和高保真同源重组一样精确"}
第三节会写：非同源重组修复忠实性差，可能丧失或获得核苷酸，造成染色体畸变。把 $\mathrm{NHEJ}$ 答成「同样高保真」，免疫球蛋白重排可以产生新组合这一句也失去「可错／可创新」的两面。
:::

:::insight{label="淋巴细胞受体基因重排把 NHEJ 从「修损伤」写成「造多样性」"}
同一套连接策略：损伤场景里它容易出错；发育场景里它把未连接的片段连成新受体基因。不要把这一句搬去第十九章位点特异性重组的 $\mathrm{V}$-(D)-$\mathrm{J}$ 细节——本版在这里只点名，不展开重组酶。
:::

## 四、跨越损伤DNA合成是一种保留差错的DNA损伤修复方式

当 $\mathrm{DNA}$ 双链发生大范围的损伤时，$\mathrm{DNA}$ 的损伤部位失去其模板作用，或复制叉已被解开，致使修复系统无法通过上述方式进行有效修复。此时，细胞可以诱导一个或多个应急途径，通过跨过损伤部位先进行复制，再设法对损伤进行修复。而根据损伤部位跨越机制的不同，这种跨越损伤 $\mathrm{DNA}$ 的修复又被分为重组跨越损伤修复与合成跨越损伤修复两种不同的类型。

:::definition{label="跨越损伤 DNA 合成"}
大范围损伤使损伤部位失去模板作用，或复制叉已解开，前述途径无法有效修复时，先跨过损伤部位复制，再设法修。是一种保留差错的方式。分成重组跨越与合成跨越。
:::

:::pitfall{label="跨越不是「已经修好再复制」"}
先复制、再设法修。重组跨越里损伤可以只是转移到另一个子代分子上。写成「跨越＝无错修复」，$\mathrm{SOS}$ 的低保真聚合酶就没有户头。
:::

**1. 重组跨越损伤修复**　当 $\mathrm{DNA}$ 链的损伤较大，致使损伤链不能作为模板复制时，细胞利用同源重组的方式，将 $\mathrm{DNA}$ 模板进行重组交换，使复制能够继续下去。然而，在大肠埃希菌中，还有某些新的机制，当复制进行到损伤部位时，$\mathrm{DNA}$ 聚合酶Ⅲ停止移动，并从模板上脱离下来，然后在损伤部位的下游重新启动复制，从而在子链 $\mathrm{DNA}$ 上产生一个缺口。$\mathrm{RecA}$ 重组蛋白将另一股健康母链上对应的序列重组到子链 $\mathrm{DNA}$ 的缺口处填补。通过重组跨越，解决了有损伤的 $\mathrm{DNA}$ 分子的复制问题，但其损伤并没有真正地被修复，只是转移到了另一个新合成的一个子代的 $\mathrm{DNA}$ 分子上，接下来由细胞内其他修复系统完成后继修复。

:::definition{label="重组跨越损伤修复"}
损伤链不能当模板时，用同源重组交换模板，使复制继续。大肠埃希菌：聚合酶Ⅲ在损伤处停并脱离，下游重新启动，子链留缺口；$\mathrm{RecA}$ 把另一股健康母链对应序列重组到缺口填补。复制问题解决了，损伤本身没有真正被修掉，只是转移到另一个子代分子上，再由其他系统后继修复。
:::

:::insight{label="重组跨越和上一节同源重组修 DSB 不是同一句话"}
上一节：双链都断了，用姐妹染色单体把断端接回去。这里：模板链伤得不能用，先让复制跨过去，损伤分子还在。都用到重组和 $\mathrm{RecA}$／$\mathrm{RAD}51$ 这一类蛋白，问的不是同一件事。表21-4 范科尼贫血写「重组跨越损伤修复」，不要改写成「就是图21-6」。
:::

:::pitfall{label="不要把「转移到另一个子代分子」写成「损伤消失」"}
教材写「并没有真正地被修复」。后继修复才可能真正清除。考试若问「重组跨越是否已恢复原损伤链」，答没有。
:::

**2. 合成跨越损伤修复**　当 $\mathrm{DNA}$ 双链发生大片段、高频率的损伤时，大肠埃希菌可以紧急启动应急修复系统，诱导产生新的 $\mathrm{DNA}$ 聚合酶，$\mathrm{DNA}$ 聚合酶Ⅳ或Ⅴ，替换停留在损伤位点的原来的 $\mathrm{DNA}$ 聚合酶Ⅲ，在子链上以随机方式插入正确甚至错误的核苷酸使复制继续，越过损伤部位之后，这些新的 $\mathrm{DNA}$ 聚合酶在完成使命后从 $\mathrm{DNA}$ 链上脱离，再由原来的 $\mathrm{DNA}$ 聚合酶Ⅲ继续复制。因为诱导产生的这些新的 $\mathrm{DNA}$ 聚合酶的活性低，识别碱基的精确度差，通常无校对功能，所以这种合成跨越损伤复制过程的出错率会大大增加，是大肠埃希菌 $\mathrm{SOS}$ 反应或 $\mathrm{SOS}$ 修复的一部分。

在大肠埃希菌等原核生物中，$\mathrm{SOS}$ 修复反应是由 $\mathrm{RecA}$ 蛋白与 $\mathrm{LexA}$ 阻遏物的相互作用引发的，有近 $30$ 个 $\mathrm{SOS}$ 相关基因编码蛋白参与此修复反应。正常情况下，$\mathrm{RecA}$ 基因以及其他的 $\mathrm{SOS}$ 相关的可诱导基因的上游，有一段共同的操纵序列（$5'$-$\mathrm{CTG}$-$\mathrm{N}_{10}$-$\mathrm{CAG}$-$3'$）可以被阻遏蛋白 $\mathrm{LexA}$ 结合，基因表达被阻遏，只有低水平的转录和翻译，产生少量的相应蛋白。当 $\mathrm{DNA}$ 严重损伤时，$\mathrm{RecA}$ 蛋白表达，其可激活 $\mathrm{LexA}$ 的自水解酶活性。当 $\mathrm{LexA}$ 因被水解从 $\mathrm{RecA}$ 基因以及 $\mathrm{SOS}$ 相关的可诱导基因的操纵序列上解离下来后，一系列受 $\mathrm{LexA}$ 阻遏的基因得以表达，参与 $\mathrm{SOS}$ 修复活动。完成修复后，$\mathrm{LexA}$ 阻遏蛋白重新合成，$\mathrm{SOS}$ 相关的可诱导基因重新关闭（图21-7）。需要指出的是，$\mathrm{SOS}$ 反应诱导的产物可参与重组修复、切除修复和错配修复等修复过程。这种修复机制因海空紧急呼救信号「$\mathrm{SOS}$」而得名。

:::note{label="图21-7 电子版缺失"}
图21-7　$\mathrm{SOS}$ 修复中 $\mathrm{LexA}$-$\mathrm{RecA}$ 操纵子的作用机制。对应 `p0442_01.png` 为 $0$ 字节，不嵌入。过程以本段为准：完好时 $\mathrm{LexA}$ 结合共同操纵序列 $5'$-$\mathrm{CTG}$-$\mathrm{N}_{10}$-$\mathrm{CAG}$-$3'$ 阻遏 $\mathrm{SOS}$ 基因；严重损伤时 $\mathrm{RecA}$ 激活 $\mathrm{LexA}$ 自水解，$\mathrm{SOS}$ 基因开放；修完后 $\mathrm{LexA}$ 重新合成，基因再关。
:::

:::definition{label="合成跨越与 DNA 聚合酶Ⅳ、Ⅴ"}
大片段、高频率损伤时，大肠埃希菌诱导聚合酶Ⅳ或Ⅴ，替换停在损伤位点的聚合酶Ⅲ，在子链上以随机方式插入正确甚至错误的核苷酸，使复制越过损伤。随后Ⅳ／Ⅴ脱离，聚合酶Ⅲ接回。Ⅳ／Ⅴ活性低、精确度差、通常无校对，出错率大大增加。这是 $\mathrm{SOS}$ 反应或 $\mathrm{SOS}$ 修复的一部分。
:::

:::definition{label="SOS 修复"}
由 $\mathrm{RecA}$ 与 $\mathrm{LexA}$ 阻遏物相互作用引发，近 $30$ 个 $\mathrm{SOS}$ 相关基因编码蛋白参与。因海空紧急呼救信号「$\mathrm{SOS}$」得名。诱导产物还可参与重组修复、切除修复和错配修复。
:::

:::definition{label="LexA-RecA 开关"}
完好：共同操纵序列 $5'$-$\mathrm{CTG}$-$\mathrm{N}_{10}$-$\mathrm{CAG}$-$3'$ 被 $\mathrm{LexA}$ 结合，$\mathrm{RecA}$ 及 $\mathrm{SOS}$ 可诱导基因被阻遏，仅低水平表达。严重损伤：$\mathrm{RecA}$ 表达并激活 $\mathrm{LexA}$ 自水解，$\mathrm{LexA}$ 从操纵序列解离，$\mathrm{SOS}$ 基因表达。修完：$\mathrm{LexA}$ 重新合成，基因重新关闭。
:::

:::timeline{period="SOS 开关"}
- **完好** LexA 结合共同操纵序列 CTG-N10-CAG，SOS 基因被阻遏
- **严重损伤** RecA 表达，激活 LexA 自水解，阻遏解除
- **应急** 近 30 个 SOS 相关基因表达；可诱导聚合酶 IV 或 V 做合成跨越
- **修完** LexA 重新合成，可诱导基因再关闭
:::

:::cause-effect{title="RecA 怎样打开 SOS"}
- **因** $\mathrm{DNA}$ 严重损伤，$\mathrm{RecA}$ 表达并激活 $\mathrm{LexA}$ 的自水解酶活性
- **果** $\mathrm{LexA}$ 从操纵序列掉下来，$\mathrm{SOS}$ 相关可诱导基因表达
- **因** 修复完成，$\mathrm{LexA}$ 重新合成
- **果** $\mathrm{SOS}$ 基因重新关闭
:::

:::compare{title="重组跨越 vs 合成跨越"}
| | 怎样跨过损伤 | 损伤本身 | 出错 |
|--|------------|---------|------|
| 重组跨越 | $\mathrm{RecA}$ 把健康母链对应序列填到子链缺口；或重组交换模板 | 未真正修掉，转移到另一子代分子 | 先保复制继续 |
| 合成跨越 | 聚合酶Ⅳ或Ⅴ替换Ⅲ，随机插核苷酸越过损伤 | 损伤位点仍在原处，复制先过去 | Ⅳ／Ⅴ无校对，出错率大增，$\mathrm{SOS}$ 的一部分 |

两户都是「先让复制走下去」。不要并成切除修复。
:::

:::pitfall{label="SOS 不是一种新的切除酶"}
开关是 $\mathrm{LexA}$-$\mathrm{RecA}$。产物可以去参与重组、切除、错配，也可以诱导低保真聚合酶做合成跨越。写成「$\mathrm{SOS}$＝第五种切除修复」，表21-1 最后一行「$\mathrm{RecA}$、$\mathrm{LexA}$ 以及其他类型的 $\mathrm{DNA}$ 聚合酶」就读不成。
:::

:::pitfall{label="思考题 RecA 调节 SOS，不要答成 RAD51 修 DSB"}
$\mathrm{RecA}$ 在本节有两处：重组跨越里填缺口；$\mathrm{SOS}$ 里激活 $\mathrm{LexA}$ 自水解。$\mathrm{RAD}51$ 是它的真核同源物，用在图21-6 的核蛋白丝。问 $\mathrm{SOS}$ 先答 $\mathrm{LexA}$。
:::

此外，对于受损的 $\mathrm{DNA}$ 分子，除了启动上述诸多的修复途径，以修复损伤之外，细胞还可以通过其他的途径将损伤的后果降至最低。比如，通过 $\mathrm{DNA}$ 损伤应激反应活化细胞周期检查点机制，延迟或阻断细胞周期进程，为损伤修复提供充足的时间，诱导修复基因表达，加强损伤的修复，使细胞能够安全进入新一轮的细胞周期。与此同时，细胞还可以激活凋亡机制，诱导严重受损的细胞发生凋亡，在整体上维持生物体基因组的稳定。

:::definition{label="检查点为修复争取时间"}
$\mathrm{DNA}$ 损伤应激反应活化细胞周期检查点，延迟或阻断细胞周期，诱导修复基因表达，加强修复，使细胞能安全进入新一轮周期。
:::

:::definition{label="凋亡清除严重受损细胞"}
激活凋亡，诱导严重受损细胞死亡，在整体上维持基因组稳定。与开篇「不能有效修复则可能走凋亡」是同一户。
:::

:::insight{label="修复途径之外还有「拖时间」和「丢卒保车」"}
检查点是拖时间；凋亡是丢卒保车。都不是表21-1 的六行，但都是把损伤后果降到最低。第三节衰老、肿瘤会再碰到「修不及时」和「该凋亡的没凋亡」。
:::

:::memory{label="本节途径不要并户"}
- 直接修复：光复活（可见光、光裂合酶，图21-3；哺乳动物缺酶）；烷基转移酶（酶不可逆失活，图21-4 缺失）；连接酶封单链切口。
- $\mathrm{BER}$：糖苷酶 $\rightarrow$ $\mathrm{AP}$ $\rightarrow$ 切磷酸核糖 $\rightarrow$ 填补连接（图21-5）；$\mathrm{p}53$ 调控。
- $\mathrm{NER}$：认扭曲，切寡核苷酸；人 $\mathrm{XPA}$–$\mathrm{XPG}$（表21-2），约 $30$ 种蛋白；转录偶联由 $\mathrm{RNA}$ 聚合酶识别。
- 错配：细菌 $\mathrm{MutS}/\mathrm{L}/\mathrm{H}$＋甲基化分母子链；人表21-3。
- $\mathrm{DSB}$：同源重组（图21-6，$\mathrm{MRN}$、$\mathrm{BRCA}1/2$、$\mathrm{RAD}51$，$\mathrm{S}/\mathrm{G}_{2}$）；$\mathrm{NHEJ}$（$\mathrm{Ku}$、$\mathrm{DNA}\ \mathrm{PKcs}$、$\mathrm{Artemis}$、$\mathrm{LIG}4$、$\mathrm{XRCC}4$，全周期、易错）。
- 跨越：重组跨越（损伤转移）；合成跨越（聚合酶Ⅳ／Ⅴ）；$\mathrm{SOS}$ 由 $\mathrm{LexA}$-$\mathrm{RecA}$ 开关（图21-7 缺失）。
- 检查点拖延；凋亡清除。
:::
