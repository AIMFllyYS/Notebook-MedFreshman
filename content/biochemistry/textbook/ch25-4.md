# 第四节　胆色素的代谢与黄疸

第三节把胆汁酸的分类、合成和肠肝循环写完。本节只立胆色素：胆绿素、胆红素、胆素原、胆素，中心是胆红素。来源是铁卟啉降解，主路是衰老红细胞的血红蛋白；生成靠血红素加氧酶系（$\mathrm{CO}$、$\mathrm{Fe}$、$\mathrm{NADPH}$）和胆绿素还原酶；分子量 $585$，脊瓦状折叠 $98^{\circ}\sim 100^{\circ}$，故疏水亲脂。血中与清蛋白结合运输，称未结合胆红素；肝内与葡萄糖醛酸结合后称结合胆红素，经 $\mathrm{MRP}2$ 泌入胆小管。肠道生成胆素原／胆素，少量走肠肝循环。黄疸按本版分成溶血性、肝细胞性、阻塞性。胆汁酸重吸收和肠肝循环已经写在第三节，本节从胆色素起笔。

:::concept{term="先问胆红素从哪来、在血里怎么运，再问黄疸是哪一型"}
看见「黄疸」，先不要默写尿三胆表格。户头是：铁卟啉打开变成胆红素，分子量 $585$，分子内氢键做成脊瓦状，所以怕水、亲脂。血里必须挂在清蛋白上（未结合／间接）；肝里接上葡萄糖醛酸（结合／直接）才能入胆汁、入尿。黄疸问三件事：造得太多、肝处理不了、胆道堵了。把本节写成「第三节胆汁酸的续篇」，血红素加氧酶和凡登白反应就没有户头。
:::

胆色素（bile pigment）是体内铁卟啉类化合物的主要分解代谢产物，包括胆绿素（biliverdin）、胆红素（bilirubin）、胆素原（bilinogen）和胆素（bilin）。这些化合物主要随胆汁排出体外，其中胆红素居于胆色素代谢的中心，是人体胆汁中的主要色素，呈橙黄色。

:::definition{label="胆色素"}
胆色素（bile pigment）：体内铁卟啉类化合物的主要分解代谢产物。名单四户：胆绿素、胆红素、胆素原、胆素。主要随胆汁排出。中心是胆红素，呈橙黄色，是人体胆汁中的主要色素。
:::

:::definition{label="胆红素居中心"}
四户里胆红素是代谢枢纽：上游来自胆绿素，下游变成胆素原和胆素。黄疸黄的就是它。不要把胆绿素或粪胆素写成「胆汁的主要色素」。
:::

第三节末尾是结合型回肠主动、游离型小肠及大肠被动、库 $3\sim 5\,\mathrm{g}$、循环 $6\sim 12$ 次。那些句子属于第三节。本节第一句是胆色素的定义。
:::

## 一、胆红素是铁卟啉类化合物的降解产物

### （一）胆红素主要源自血红蛋白降解

体内铁卟啉类化合物包括血红蛋白、肌红蛋白、细胞色素、过氧化氢酶和过氧化物酶等。正常人每天可生成 $250\sim 350\,\mathrm{mg}$ 胆红素，其中约 $80\%$ 以上来自衰老红细胞破坏所释放的血红蛋白的分解。小部分胆红素来自造血过程中红细胞的过早破坏（无效红细胞生成），还有少量胆红素来自其他各种含血红素蛋白如细胞色素 $\mathrm{P}450$。肌红蛋白由于更新率低，所占比例很小。

:::definition{label="每天生成 250～350 mg 胆红素"}
正常人每天可生成 $250\sim 350\,\mathrm{mg}$ 胆红素。约 $80\%$ 以上来自衰老红细胞的血红蛋白。后文肝每天可清除 $3\,000\,\mathrm{mg}$ 以上，所以正常血清里胆红素甚微。
:::

:::definition{label="80% 以上来自血红蛋白"}
衰老红细胞破坏，释放血红蛋白，分解产生胆红素。这是主路。无效红细胞生成、细胞色素 $\mathrm{P}450$ 等含血红素蛋白是小户；肌红蛋白更新率低，比例很小。
:::

:::compare{title="胆红素的来源分户"}
| 来源 | 本版份额 | 不要写成 |
|------|----------|----------|
| 衰老红细胞的血红蛋白 | 约 $80\%$ 以上 | 「全部来自红细胞」 |
| 无效红细胞生成 | 小部分 | 主路 |
| 细胞色素 $\mathrm{P}450$ 等 | 少量 | 与第二节生物转化的 $\mathrm{P}450$ 并成一句来源 |
| 肌红蛋白 | 很小 | 「肌肉也是胆红素工厂」 |

问「溶血性黄疸为什么未结合胆红素暴涨」——主路突然加大，超过肝的摄取、转化和排泄。
:::

红细胞的平均寿命约 $120$ 天。生理情况下，正常成年人（$70\,\mathrm{kg}$）每小时约有 $(1\sim 2)\times 10^{8}$ 个红细胞被破坏。衰老的红细胞被肝、脾、骨髓等单核吞噬系统细胞识别并吞噬，每天释放约 $6\,\mathrm{g}$ 血红蛋白（每克血红蛋白约可产生 $35\,\mathrm{mg}$ 胆红素）。释出的血红蛋白随后分解为珠蛋白和血红素。珠蛋白可降解为氨基酸供体内再利用。血红素则由单核吞噬系统细胞降解生成胆红素。

:::definition{label="红细胞寿命 120 天"}
平均寿命约 $120$ 天。$70\,\mathrm{kg}$ 成人每小时约破坏 $(1\sim 2)\times 10^{8}$ 个红细胞。场所：肝、脾、骨髓的单核吞噬系统细胞。
:::

:::definition{label="每天 6 g 血红蛋白"}
每天释放约 $6\,\mathrm{g}$ 血红蛋白；每克约产生 $35\,\mathrm{mg}$ 胆红素。$6\times 35 = 210\,\mathrm{mg}$，落在 $250\sim 350\,\mathrm{mg}$ 主路的量级里，其余来自无效造血和其他含血红素蛋白。
:::

:::definition{label="珠蛋白与血红素分道"}
血红蛋白 → 珠蛋白 $+$ 血红素。珠蛋白降解为氨基酸再利用；血红素由单核吞噬系统细胞降解生成胆红素。胆红素不是「整分子血红蛋白变黄」。
:::

:::keypoint{label="生成这一小节三个数字"}
- 每天胆红素 $250\sim 350\,\mathrm{mg}$，血红蛋白贡献 $80\%$ 以上。
- 红细胞 $120$ 天；每小时 $(1\sim 2)\times 10^{8}$ 个（$70\,\mathrm{kg}$ 成人）。
- 每天 $6\,\mathrm{g}$ 血红蛋白，每克 $\to 35\,\mathrm{mg}$ 胆红素。
:::

### （二）血红素加氧酶和胆绿素还原酶催化胆红素的生成

血红素是由 $4$ 个吡咯环连接而成的环形化合物，并螯合 $1$ 个 $\mathrm{Fe}^{2+}$。血红素由单核吞噬系统细胞内质网的血红素加氧酶（heme oxygenase，$\mathrm{HO}$）催化，在至少 $3$ 分子氧和 $3$ 分子 $\mathrm{NADPH}$ 的存在下，血红素原卟啉Ⅸ环上的 $\alpha$ 次甲基桥碳原子的两侧氧化断裂，释放出一分子一氧化碳（$\mathrm{CO}$）和 $\mathrm{Fe}^{2+}$，并将两端的吡咯环羟化，生成线性四吡咯结构的水溶性胆绿素。释出的 $\mathrm{Fe}^{2+}$ 氧化为 $\mathrm{Fe}^{3+}$ 进入铁代谢池，可供机体再利用或以铁蛋白形式储存。

胆绿素在胞质的胆绿素还原酶（biliverdin reductase）催化下，由 $\mathrm{NADPH}$ 供氢，还原生成胆红素（图25-16）。胆红素是由 $3$ 个次甲基桥连接的 $4$ 个吡咯环组成，分子量 $585$。虽然胆红素分子中含有 $2$ 个羟基（醇式）或酮基（酮式）、$4$ 个亚氨基和 $2$ 个丙酸基等亲水基团，但由于这些基团形成 $6$ 个分子内氢键，使胆红素分子形成脊瓦状内旋的刚性折叠结构，赋予胆红素以疏水亲脂的性质，极易自由透过细胞膜进入血液（图25-17）。

:::definition{label="血红素加氧酶"}
定位于单核吞噬系统细胞内质网。至少 $3$ 分子 $\mathrm{O}_2$ 和 $3$ 分子 $\mathrm{NADPH}$ 存在下，打开原卟啉Ⅸ环的 $\alpha$ 次甲基桥，释放 $\mathrm{CO}$ 和 $\mathrm{Fe}^{2+}$，两端吡咯环羟化，生成线性四吡咯的水溶性胆绿素。
:::

:::definition{label="开环三件产物"}
$\mathrm{HO}$ 这一步同时放出：胆绿素、一分子 $\mathrm{CO}$、$\mathrm{Fe}^{2+}$。$\mathrm{Fe}^{2+}$ 再氧化为 $\mathrm{Fe}^{3+}$ 进入铁代谢池。图25-16 箭头旁就标着 $\mathrm{CO}$ 和 $\mathrm{Fe}$。
:::

:::definition{label="胆绿素还原酶"}
在胞质，由 $\mathrm{NADPH}$ 供氢，把胆绿素还原成胆红素。图25-16 中胆绿素中间还是 $=\mathrm{CH}-$，胆红素中间变成 $-\mathrm{CH}_2-$。
:::

:::definition{label="胆红素分子量 585"}
$4$ 个吡咯环由 $3$ 个次甲基桥连接，分子量 $585$。本版按 $585$ 记，不要换成约数。
:::

:::definition{label="脊瓦状刚性折叠 98°～100°"}
$2$ 个羟基（醇式）或酮基（酮式）、$4$ 个亚氨基、$2$ 个丙酸基本是亲水基团，却形成 $6$ 个分子内氢键，分子内旋成脊瓦状刚性折叠。A、B 环一个平面，C、D 环一个平面，夹角 $98^{\circ}\sim 100^{\circ}$。结果：疏水亲脂，极易透过细胞膜入血。
:::

::figure{src="/images/biochemistry/textbook/p0503_01.png" caption="图25-16　胆红素的生成" alt="上方血红素铁卟啉环，中央 Fe；血红素加氧酶系在 O2 和 NADPH+H+ 下释放 CO 和 Fe，开环成胆绿素（两端为 OH）；再还原为胆红素醇式（中间次甲基为 CH2），与酮式互变。侧链标注 M 为甲基、P 为丙酸基"}

:::insight{label="图25-16 先认开环，再认醇式／酮式"}
画面自上而下：血红素（环状，中央 $\mathrm{Fe}$）→ 加氧酶系（$\mathrm{O}_2$、$\mathrm{NADPH}+\mathrm{H}^{+}$ 进入，放出 $\mathrm{CO}$、$\mathrm{Fe}$）→ 胆绿素（线性，两端 $\mathrm{OH}$）→ 胆红素醇式 → 与酮式互变。$\mathrm{M}$ 是 $-\mathrm{CH}_3$，$\mathrm{P}$ 是 $-\mathrm{CH}_2\mathrm{CH}_2\mathrm{COOH}$。开环发生在 $\alpha$ 次甲基桥，次甲桥的碳变成 $\mathrm{CO}$。
:::

::figure{src="/images/biochemistry/textbook/p0504_01.png" caption="图25-17　胆红素的 X 线衍射结构图" alt="两个平面夹成脊瓦状刚性折叠，夹角 98°～100°；分子内氢键把亲水基团锁在内侧，疏水基团朝外"}

:::insight{label="图25-17 亲水基团被氢键锁在里面"}
画面标「脊瓦状刚性折叠 $98^{\circ}\sim 100^{\circ}$」。丙酸基的羧基与对侧环的氧、氮形成氢键；亲水基团在内侧，疏水基团在外侧。所以尽管分子「看起来有很多亲水基」，整体仍疏水亲脂。正文补：C 环丙酸基与 A 环氧及 A、B 环氮成氢键；B 环丙酸基与 C 环氧及 C、D 环氮成氢键。
:::

:::pitfall{label="有亲水基团不等于水溶"}
羟基、亚氨基、丙酸基都在，但 $6$ 个分子内氢键把它们锁住。写成「胆红素有羧基所以水溶」，未结合胆红素就不能解释为什么必须挂清蛋白、为什么间接反应。结合反应破坏氢键之后才水溶。
:::

迄今已发现人体内存在 $3$ 种血红素加氧酶的同工酶：$\mathrm{HO}$-1、$\mathrm{HO}$-2 和 $\mathrm{HO}$-3（表25-6）。$\mathrm{HO}$-1（$32\,\mathrm{kD}$）是一种诱导酶，为热激蛋白 $32$（$\mathrm{HSP}32$）。主要存在于肝、脾和骨髓等降解衰老红细胞的组织器官。$\mathrm{HO}$-2（$36\,\mathrm{kD}$）是组成型酶，仅受糖皮质激素诱导，主要存在于大脑及睾丸组织内，其功能多认为与 $\mathrm{CO}$ 的神经信使作用有关。$\mathrm{HO}$-3（$33\,\mathrm{kD}$）与 $\mathrm{HO}$-2 有 $90\%$ 的同源性，亦属组成型表达，其功能尚未明晰。$\mathrm{HO}$-1 在血红素代谢中居重要地位，其生物合成可被其底物血红素迅速激活，以及时清除循环系统中的血红素。$\mathrm{HO}$-1 亦是迄今所知的诱导物最多的诱导酶。缺氧、高氧、内毒素、重金属、白细胞介素 $10$（$\mathrm{IL}$-10）、一氧化氮（$\mathrm{NO}$）、促红细胞生成素（$\mathrm{EPO}$）、炎症细胞因子等许多能引发细胞氧化应激（oxidative stress）的因素均可诱导此酶的表达，从而增加 $\mathrm{CO}$、胆绿素和继之胆红素的产生。

:::definition{label="HO-1"}
$32\,\mathrm{kD}$，诱导型，即 $\mathrm{HSP}32$。主场：肝、脾、骨髓。可被底物血红素迅速激活；诱导物最多。氧化应激（缺氧、高氧、内毒素、重金属、$\mathrm{IL}$-10、$\mathrm{NO}$、$\mathrm{EPO}$、炎症细胞因子等）都可诱导它，从而增加 $\mathrm{CO}$、胆绿素和胆红素。
:::

:::definition{label="HO-2"}
$36\,\mathrm{kD}$，组成型，仅受糖皮质激素诱导。主场：大脑及睾丸。功能多认为与 $\mathrm{CO}$ 的神经信使作用有关。
:::

:::definition{label="HO-3"}
$33\,\mathrm{kD}$，组成型，与 $\mathrm{HO}$-2 有 $90\%$ 同源性。功能尚未明晰。表25-6 表达部位写「不明」。
:::

:::compare{title="表25-6　血红素加氧酶同工酶"}
| $\mathrm{HO}$ 同工酶 | 分子量／$\mathrm{kD}$ | 表达类型 | 表达部位 | 诱导因子 |
|---------------------|----------------------|----------|----------|----------|
| $\mathrm{HO}$-1 | $32$ | 诱导型 | 肝、脾、骨髓等 | 衰老红细胞；缺氧、高氧、内毒素、重金属、$\mathrm{IL}$-10、$\mathrm{NO}$、$\mathrm{EPO}$、炎症细胞因子等 |
| $\mathrm{HO}$-2 | $36$ | 组成型 | 大脑及睾丸 | 受糖皮质激素诱导；与 $\mathrm{CO}$ 的神经信使作用有关 |
| $\mathrm{HO}$-3 | $33$ | 组成型 | 不明 | — |

问「谁负责清血红素」——$\mathrm{HO}$-1。问「谁跟神经信使 $\mathrm{CO}$ 有关」——$\mathrm{HO}$-2。不要把三户都写成诱导酶。
:::

许多疾病亦表现 $\mathrm{HO}$-1 的表达增加，例如肿瘤、动脉粥样硬化、心肌缺血、阿尔茨海默病等。$\mathrm{HO}$-1 作为一种应激蛋白质，其诱导因素的多样性是对细胞的一种重要保护机制。$\mathrm{HO}$-1 在上述诸多有害环境刺激和疾病存在条件下所呈现的对机体保护作用，主要是通过其催化生成的产物来实现的，这些产物主要是 $\mathrm{CO}$ 与胆红素。$\mathrm{HO}$ 氧化血红素时产生的 $\mathrm{CO}$ 是机体内源性 $\mathrm{CO}$ 的主要来源。$\mathrm{CO}$ 因对 $\mathrm{Hb}$ 有高度亲和力而呈现有害效应。但有研究显示，低浓度 $\mathrm{CO}$ 和 $\mathrm{NO}$ 功能相似，可作为信息分子和神经递质。

:::definition{label="内源性 CO 主要来自 HO"}
$\mathrm{HO}$ 氧化血红素时产生的 $\mathrm{CO}$ 是内源性 $\mathrm{CO}$ 的主要来源。高浓度：对 $\mathrm{Hb}$ 高度亲和，有害。低浓度：与 $\mathrm{NO}$ 相似，可作信息分子和神经递质。
:::

:::insight{label="HO-1 保护靠的是产物，不是酶本身好看"}
肿瘤、动脉粥样硬化、心肌缺血、阿尔茨海默病等可见 $\mathrm{HO}$-1 升高。保护作用主要通过 $\mathrm{CO}$ 与胆红素实现。写成「酶多了就能解毒」，把产物那一户删了。
:::

胆红素过量对人体有害，但适宜水平的胆红素是人体内强有力的内源性抗氧化剂，是血清中抗氧化活性的主要成分，可有效地清除超氧化物和过氧化自由基。氧化应激可诱导 $\mathrm{HO}$-1 的表达，从而增加胆红素的量以抵御氧化应激状态。胆红素的这种抗氧化作用通过胆绿素还原酶循环（biliverdin reductase cycle）实现：胆红素氧化成胆绿素，后者再在分布广、活性强的胆绿素还原酶催化下，利用 $\mathrm{NADH}$ 或 $\mathrm{NADPH}$ 再还原成胆红素。胆绿素还原酶循环可使胆红素的作用增大 $10\,000$ 倍。

:::definition{label="适宜水平的胆红素是抗氧化剂"}
过量有害；适宜水平是强有力的内源性抗氧化剂，是血清抗氧化活性的主要成分，清除超氧化物和过氧化自由基。
:::

:::definition{label="胆绿素还原酶循环"}
胆红素氧化成胆绿素，再被胆绿素还原酶（$\mathrm{NADH}$ 或 $\mathrm{NADPH}$）还原回胆红素。循环可使胆红素的抗氧化作用增大 $10\,000$ 倍。
:::

:::pitfall{label="不要把抗氧化写成「胆红素无毒」"}
过量仍有害，尤其对富含脂质的神经细胞。清蛋白结合只是暂时解毒，根本解毒是肝内葡萄糖醛酸结合。抗氧化是适宜水平的另一面，不是取消毒性这一户。
:::

:::keypoint{label="加氧酶这一小节四件事"}
- 开环：$\mathrm{HO}$ $+$ 至少 $3\,\mathrm{O}_2$、$3\,\mathrm{NADPH}$ → 胆绿素 $+\mathrm{CO}+\mathrm{Fe}^{2+}$。
- 还原：胆绿素还原酶 $+\mathrm{NADPH}$ → 胆红素，分子量 $585$。
- 结构： $6$ 个分子内氢键，脊瓦状 $98^{\circ}\sim 100^{\circ}$，疏水亲脂。
- 同工酶：$\mathrm{HO}$-1 诱导（$32\,\mathrm{kD}$），$\mathrm{HO}$-2／$\mathrm{HO}$-3 组成型。
:::

## 二、胆红素在体内不同部位采取不同运输形式

### （一）血液中的胆红素主要与清蛋白结合而运输

胆红素在单核吞噬系统细胞生成以后释放入血。在血浆中主要以胆红素-清蛋白复合体形式存在和运输。血浆清蛋白（albumin）与胆红素的结合，一方面增加了胆红素的水溶性，提高了血浆对胆红素的运输能力；另一方面限制了它自由通透各种细胞膜，避免了其对组织细胞造成的毒性作用。研究证明，每个清蛋白分子有一个高亲和力结合部位和一个低亲和力结合部位，可结合两分子胆红素。正常人血浆胆红素浓度参考区间为 $0\sim 23.0\,\mathrm{\mu mol/L}$，而每 $100\,\mathrm{ml}$ 血浆清蛋白可结合 $25\,\mathrm{mg}$ 胆红素，故在正常情况下血浆清蛋白结合胆红素的潜力很大，不与清蛋白结合的胆红素甚微。但必须提及的是，胆红素与清蛋白的结合是非特异性、非共价可逆性的。若清蛋白含量明显降低、结合部位被其他物质占据或降低胆红素对结合部位的亲和力，均可促使胆红素从血浆向组织细胞转移。

:::definition{label="胆红素-清蛋白复合体"}
血浆中运输的主要形式。作用两句：增加水溶性、提高运输能力；限制自由通透细胞膜，避免组织毒性。每个清蛋白分子一个高亲和力部位加一个低亲和力部位，可结合两分子胆红素。
:::

:::definition{label="血浆胆红素 0～23.0 μmol/L"}
正常人参考区间 $0\sim 23.0\,\mathrm{\mu mol/L}$。每 $100\,\mathrm{ml}$ 血浆清蛋白可结合 $25\,\mathrm{mg}$ 胆红素，潜力很大。结合是非特异性、非共价、可逆的。
:::

:::insight{label="第一节清蛋白的配基名单在这里兑现"}
第一节写清蛋白携带胆红素。本节展开：暂时解毒靠清蛋白，根本解毒靠肝内葡萄糖醛酸结合。不要把两节并成「清蛋白结合就是结合胆红素」。
:::

某些有机阴离子（如磺胺药、水杨酸、胆汁酸、脂肪酸等）可与胆红素竞争性地结合清蛋白，使胆红素游离。过多的游离胆红素因脂溶性质易穿透细胞膜进入细胞，尤其是富含脂质的脑部基底核的神经细胞，干扰脑的正常功能，称为胆红素脑病（bilirubin encephalopathy）或核黄疸（kernicterus）。有黄疸倾向的病人或新生儿生理性黄疸期，应慎用上述药物。因此，血浆清蛋白与胆红素的结合仅起到暂时性的解毒作用，其根本性的解毒依赖于在肝内胆红素与葡萄糖醛酸结合的生物转化作用。把这种未经肝结合转化的、在血浆中与清蛋白结合运输的胆红素称为未结合胆红素（unconjugated bilirubin）或血胆红素或游离胆红素。未结合胆红素因分子内氢键存在，不能直接与重氮试剂反应，只有在加入乙醇或尿素等破坏氢键后才能与重氮试剂反应，生成紫红色偶氮化合物，故未结合胆红素又称为间接胆红素（indirect bilirubin）。

:::definition{label="核黄疸"}
过多游离胆红素穿透细胞膜，进入富含脂质的脑部基底核神经细胞，干扰脑功能，称为胆红素脑病或核黄疸。磺胺药、水杨酸、胆汁酸、脂肪酸等可与胆红素竞争清蛋白。黄疸倾向病人、新生儿生理性黄疸期应慎用上述药物。
:::

:::definition{label="未结合胆红素"}
未经肝结合转化、在血浆中与清蛋白结合运输的胆红素，又称血胆红素或游离胆红素。分子内氢键还在，不能直接与重氮试剂反应；加乙醇或尿素破坏氢键后才反应，故又称间接胆红素。
:::

:::definition{label="暂时解毒 vs 根本解毒"}
清蛋白结合：暂时性解毒。肝内与葡萄糖醛酸结合：根本性解毒。第二节苯巴比妥诱导 $\mathrm{UGT}$ 治疗新生儿黄疸，用的就是根本这一户。
:::

:::pitfall{label="「游离胆红素」不是「没挂清蛋白」"}
本版把未结合胆红素又称游离胆红素，指的是没接葡萄糖醛酸，血浆里其实主要挂在清蛋白上。真正不与清蛋白结合的胆红素甚微，但那一丁点才容易进脑。写成「游离＝没有清蛋白」，核黄疸的药竞结合就讲反了。
:::

:::cause-effect{title="有机阴离子抢清蛋白 → 核黄疸"}
磺胺、水杨酸、胆汁酸、脂肪酸占据清蛋白结合部位 → 胆红素游离 → 脂溶性分子钻进基底核 → 胆红素脑病／核黄疸。
:::

### （二）胆红素在肝细胞中转变为结合胆红素并泌入胆小管

肝细胞对胆红素的处理，包括摄取、结合、分泌三个过程。

**1. 摄取**　血中游离胆红素以胆红素-清蛋白复合体的形式运输到肝，随即与清蛋白分离。未结合的胆红素以其亲脂性质，可以自由通过肝血窦细胞膜而进入肝细胞；也可经有机阴离子多肽转运体（organic anion transporting peptide，$\mathrm{OATP}$）$1\mathrm{B}1$、$\mathrm{B}3$ 摄取进入肝细胞。胆红素进入肝细胞后，与细胞质配体蛋白（ligandin）Y 蛋白和 Z 蛋白相结合，运输至肝细胞滑面内质网，其中以 Y 蛋白为主。Y 蛋白是谷胱甘肽 $\mathrm{S}$-转移酶（$\mathrm{GST}$）家族成员，含量丰富，占肝细胞质总蛋白质的 $3\%\sim 4\%$，对胆红素有高亲和力。新生儿出生后，肝内 Y 蛋白含量低下，$7$ 周后才达到成人水平。

:::definition{label="摄取：清蛋白卸货，OATP 或自由进入"}
复合体到肝后与清蛋白分离。亲脂的未结合胆红素可自由通过肝血窦细胞膜；也可经 $\mathrm{OATP}1\mathrm{B}1$、$\mathrm{B}3$ 摄取。图25-19 把转运体写成 $\mathrm{OTAP}$（有机阴离子多肽转运体），认图按画面，正文缩写按 $\mathrm{OATP}$。
:::

:::definition{label="Y 蛋白和 Z 蛋白"}
胞质配体蛋白，把胆红素运到滑面内质网，以 Y 蛋白为主。Y 蛋白属 $\mathrm{GST}$ 家族，占肝细胞质总蛋白 $3\%\sim 4\%$，高亲和力。新生儿 Y 蛋白低下，$7$ 周后达成人水平。
:::

:::insight{label="新生儿黄疸有 Y 蛋白这一户"}
第二节写新生儿 $\mathrm{UGT}$ 生后 $5\sim 6$ 天才升、$1\sim 3$ 月近成人。本节补：Y 蛋白 $7$ 周才到成人水平。摄取载体和结合酶都可以是「新生儿结合能力不足」的底板，不要只背 $\mathrm{UGT}$。
:::

**2. 结合**　Y 蛋白-胆红素和 Z 蛋白-胆红素在滑面内质网内，通过胆红素-葡萄糖醛酸基转移酶（$\mathrm{BUGT}$）的作用，由 $\mathrm{UDPGA}$ 提供葡萄糖醛酸基，转变为结合胆红素，即葡萄糖醛酸胆红素（bilirubin glucuronide）。由于胆红素分子中含有 $2$ 个羧基，每分子胆红素可至多结合 $2$ 分子葡萄糖醛酸，结果主要生成胆红素二葡萄糖醛酸酯（$70\%\sim 80\%$）和胆红素一葡萄糖醛酸酯（$20\%\sim 30\%$）（图25-18），两者均可被分泌入胆汁。此外，尚有少量胆红素与硫酸结合生成硫酸酯。肝内的结合反应消除了游离胆红素的毒性，增加了水溶性，能从肾脏排出。

:::definition{label="结合胆红素"}
滑面内质网中 $\mathrm{BUGT}$（即图25-18、图25-21 的 $\mathrm{UGT}$）把 $\mathrm{UDPGA}$ 的葡萄糖醛酸基转到胆红素上，生成葡萄糖醛酸胆红素。消除毒性、增加水溶性，能从肾脏排出。
:::

:::definition{label="双酯 70%～80%，单酯 20%～30%"}
两个羧基最多接两分子葡萄糖醛酸。主要产物：胆红素二葡萄糖醛酸酯 $70\%\sim 80\%$，一葡萄糖醛酸酯 $20\%\sim 30\%$，均可分泌入胆汁。少量走硫酸酯。
:::

::figure{src="/images/biochemistry/textbook/p0506_01.png" caption="图25-18　胆红素双葡萄糖醛酸酯的生成及结构" alt="胆红素经 UGT 两步结合：UDP-葡萄糖醛酸提供糖醛酸基，先成胆红素一葡萄糖醛酸酯，再成胆红素二葡萄糖醛酸酯；下方为双酯结构式，两个葡萄糖醛酸经酯键接在丙酸侧链上"}

:::insight{label="图25-18 是两步 UGT，不是一步接两个"}
画面：胆红素 $\xrightarrow{\mathrm{UGT}}$ 一酯 $\xrightarrow{\mathrm{UGT}}$ 二酯，每步 $\mathrm{UDP}$-葡萄糖醛酸进、$\mathrm{UDP}$ 出。结构式里两个糖醛酸环通过 $-\mathrm{CO}-\mathrm{O}-$ 接在两条丙酸侧链上。$\mathrm{M}$ 为甲基，$\mathrm{V}$ 为乙烯基。
:::

葡萄糖醛酸结合后，胆红素因分子内氢键被破坏，埋藏于分子内部的亚甲桥暴露，可以迅速、直接与重氮试剂发生凡登白反应（Van den Bergh reaction），故结合胆红素又称为直接反应胆红素或直接胆红素（direct bilirubin）。结合胆红素与未结合胆红素不同理化性质的比较见表25-7。

:::definition{label="直接胆红素"}
结合后分子内氢键被破坏，亚甲桥暴露，可迅速直接与重氮试剂发生凡登白反应，故称直接胆红素或肝胆红素。
:::

:::compare{title="表25-7　两种胆红素理化性质的比较"}
| 理化性质 | 未结合胆红素 | 结合胆红素 |
|----------|--------------|------------|
| 同义名称 | 间接胆红素、游离胆红素 | 直接胆红素、肝胆红素 |
| 凡登白反应 | 间接反应 | 直接反应 |
| 与葡萄糖醛酸结合 | 未结合 | 结合 |
| 溶解性 | 脂溶性 | 水溶性 |
| 形成场所 | 单核-巨噬细胞系 | 肝脏 |
| 直接穿透膜能力及毒性 | 大 | 小 |
| 尿内 | 无 | 有 |

问「尿里有没有胆红素」——未结合无，结合有。问「哪一个进脑」——未结合，穿透膜能力大。
:::

:::pitfall{label="间接／直接是凡登白反应，不是「间接来自红细胞」"}
间接：要加乙醇或尿素才显色。直接：氢键破了，立刻显色。不要把「间接」理解成来源间接、把「直接」理解成直接来自血红蛋白。
:::

**3. 分泌**　结合胆红素水溶性强，被肝细胞分泌进入胆管系统，随胆汁排入小肠。分泌是肝脏代谢胆红素的限速步骤，亦是肝脏处理胆红素的薄弱环节。分泌过程是一个逆浓度梯度的主动转运过程，定位于毛细胆管膜的多耐药相关蛋白 $2$（multidrug resistance like protein $2$，$\mathrm{MRP}2$）是肝细胞向胆小管分泌结合胆红素的外排转运体。胆红素排泄一旦发生障碍，结合胆红素就可反流入血。对 $\mathrm{UDP}$-葡萄糖醛酸基转移酶具有诱导作用的苯巴比妥对结合胆红素的逆浓度分泌同样具有诱导作用，可见胆红素的结合转化与分泌构成相互协调的功能体系。

:::definition{label="分泌是限速步骤"}
结合胆红素经毛细胆管膜 $\mathrm{MRP}2$ 主动外排入胆小管。逆浓度梯度。是肝脏代谢胆红素的限速步骤，也是薄弱环节。排泄障碍时结合胆红素反流入血。
:::

:::definition{label="苯巴比妥诱导结合也诱导分泌"}
苯巴比妥诱导 $\mathrm{UGT}$，对结合胆红素的逆浓度分泌同样有诱导作用。结合与分泌相互协调。第二节用它治新生儿黄疸，本节补上分泌这一半。
:::

:::

:::timeline{period="肝细胞处理胆红素的三步"}
- **卸货** 清蛋白复合体到肝血窦，胆红素与清蛋白分离
- **摄取** 亲脂自由进入，或经 OTAP／OATP 进入；Y 蛋白、Z 蛋白运到滑面内质网
- **结合** BUGT 用 UDPGA 做成一酯、二酯，氢键破坏，变成水溶的直接胆红素
- **分泌** MRP2 逆浓度泵入毛细胆管；这一步最慢，也最容易反流入血
:::

:::cause-effect{title="MRP2 堵了 → 结合胆红素反流入血"}
分泌是限速、薄弱环节 → 胆小管压力升高或转运体障碍 → 已结合的水溶性胆红素回漏入血 → 尿胆红素阳性。阻塞性黄疸和肝细胞性黄疸都用得到这一句。
:::

### （三）胆红素在肠道内转化为胆素原和胆素

葡萄糖醛酸胆红素随胆汁进入肠道，在回肠下段和结肠的肠菌作用下，脱去葡萄糖醛酸基，并被还原生成 $\mathrm{d}$-尿胆素原（$\mathrm{d}$-urobilinogen）和中胆素原（mesobilirubinogen）。后者又可进一步还原生成粪胆素原（stercobilinogen），这些物质统称为胆素原。大部分胆素原随粪便排出体外，在肠道下段，这些无色的胆素原接触空气后分别被氧化为相应的 $\mathrm{d}$-尿胆素（$\mathrm{d}$-urobilin）、$\mathrm{i}$-尿胆素（$\mathrm{i}$-urobilin）和粪胆素（stercobilin，$\mathrm{l}$-urobilin），三者合称胆素（图25-20）。胆素呈黄褐色，成为粪便的主要颜色。正常人每日排出总量为 $40\sim 280\,\mathrm{mg}$。胆道完全梗阻时，胆红素不能排入肠道形成粪胆素，因此粪便呈灰白色或白陶土色。婴儿肠道细菌稀少，未被细菌作用的胆红素随粪便排出，可使粪便呈现橘黄色。

:::definition{label="胆素原"}
结合胆红素在回肠下段和结肠被肠菌脱去葡萄糖醛酸基并还原，生成 $\mathrm{d}$-尿胆素原、中胆素原，中胆素原再还原成粪胆素原，统称胆素原。无色。
:::

:::definition{label="胆素"}
胆素原接触空气后氧化为 $\mathrm{d}$-尿胆素、$\mathrm{i}$-尿胆素和粪胆素（$\mathrm{l}$-尿胆素），合称胆素。黄褐色，是粪便的主要颜色。正常人每日排出 $40\sim 280\,\mathrm{mg}$。
:::

:::definition{label="白陶土色粪便"}
胆道完全梗阻，胆红素不能入肠形成粪胆素，粪便呈灰白色或白陶土色。婴儿肠菌稀少，未转化的胆红素随粪便排出，粪便可呈橘黄色。
:::

| 步骤 | 产物 | 颜色／去向 |
|------|------|------------|
| 肠菌脱葡萄糖醛酸并还原 | $\mathrm{d}$-尿胆素原、中胆素原、粪胆素原（胆素原） | 无色；大部分随粪排出 |
| 接触空气氧化 | $\mathrm{d}$-尿胆素、$\mathrm{i}$-尿胆素、粪胆素（胆素） | 黄褐色，粪便主色 |

:::

写成「胆素原把粪便染黄」，氧化这一步就丢了。梗阻时没胆素才白陶土色；婴儿是胆红素本身呈橘黄，不是胆素。
:::

### （四）少量胆素原经肠肝循环回收入肝

肠道中生成的胆素原有 $10\%\sim 20\%$ 可被肠黏膜细胞重吸收，其余随粪便排出。重吸收的胆素原经门静脉入肝，大部分以原形随胆汁再次排入肠腔，形成胆素原的肠肝循环（bilinogen enterohepatic cycle）。只有小部分（$10\%$）胆素原可以进入体循环经肾小球滤出随尿排出，称为尿胆素原（图25-21）。正常人每日随尿排出尿胆素原约 $0.5\sim 4.0\,\mathrm{mg}$。尿胆素原与空气接触后被氧化成尿胆素，成为尿的主要色素。临床上将尿胆素原、尿胆素及尿胆红素合称为尿三胆，是黄疸类型鉴别诊断的常用指标。正常人尿中检测不到尿胆红素。

:::definition{label="胆素原的肠肝循环"}
肠道胆素原 $10\%\sim 20\%$ 被肠黏膜重吸收，经门静脉入肝，大部分以原形再随胆汁入肠。这是胆素原的肠肝循环，不是第三节胆汁酸那一圈。
:::

:::definition{label="尿胆素原 0.5～4.0 mg/d"}
重吸收的胆素原中约 $10\%$ 入体循环，经肾小球滤出随尿排出。每日约 $0.5\sim 4.0\,\mathrm{mg}$。接触空气氧化成尿胆素，成为尿的主要色素。
:::

:::definition{label="尿三胆"}
尿胆素原、尿胆素及尿胆红素。黄疸分型的常用指标。正常人尿中检测不到尿胆红素——尿胆红素阳性意味着血里出现了水溶性的结合胆红素。
:::

:::pitfall{label="正常人尿里没有尿胆红素"}
尿胆素原、尿胆素可以有（少量）；尿胆红素应阴性。尿胆红素阳性是结合胆红素入血的信号，溶血性黄疸这一户通常是阴性。

:::keypoint{label="运输这一大节四站"}
- 血：清蛋白，未结合／间接，暂解毒。
- 肝：摄取（$\mathrm{OATP}$／Y 蛋白）→ 结合（$\mathrm{BUGT}$／$\mathrm{UDPGA}$，双酯 $70\%\sim 80\%$）→ 分泌（$\mathrm{MRP}2$，限速）。
- 肠：肠菌 → 胆素原 → 胆素；粪胆素 $40\sim 280\,\mathrm{mg/d}$。
- 尿：胆素原肠肝循环的小股；$0.5\sim 4.0\,\mathrm{mg/d}$ 尿胆素原；尿三胆。
:::

## 三、胆红素升高可导致高胆红素血症与黄疸

### （一）血清胆红素水平升高可引起黄疸

正常成人空腹血清总胆红素（total bilirubin，$\mathrm{TBIL}$）参考区间为 $0\sim 23.0\,\mathrm{\mu mol/L}$，其中男性 $\leqslant 26.0\,\mathrm{\mu mol/L}$，女性 $\leqslant 21.0\,\mathrm{\mu mol/L}$，其中未结合胆红素约占 $80\%$，其余为结合胆红素（$0\sim 8\,\mathrm{\mu mol/L}$）。未结合胆红素是有毒的脂溶性物质，易透过细胞膜尤其对富含脂质的神经细胞可造成不可逆损伤。胆红素与血浆清蛋白的结合（未结合胆红素）仅起到暂时性的解毒作用，在肝细胞内与葡萄糖醛酸结合（结合胆红素）是对胆红素的根本性解毒方式。肝细胞对胆红素有强大的处理能力，正常人每天产生 $250\sim 350\,\mathrm{mg}$ 胆红素，肝每天可清除 $3\,000\,\mathrm{mg}$ 以上的胆红素，因此正常人血清中胆红素的含量甚微。

:::definition{label="血清总胆红素参考区间"}
空腹 $\mathrm{TBIL}$ $0\sim 23.0\,\mathrm{\mu mol/L}$；男性 $\leqslant 26.0\,\mathrm{\mu mol/L}$，女性 $\leqslant 21.0\,\mathrm{\mu mol/L}$。未结合约占 $80\%$，结合 $0\sim 8\,\mathrm{\mu mol/L}$。
:::

:::definition{label="肝每天可清除 3000 mg 以上"}
每天只产 $250\sim 350\,\mathrm{mg}$，肝能清 $3\,000\,\mathrm{mg}$ 以上，储备很大。黄疸不是「肝一点点 overload」，而是生成暴增或摄取／转化／排泄三条里有人垮了。
:::

:::insight{label="80% 未结合是正常血清的构成，不是溶血"}
正常人血清里未结合就占约 $80\%$。溶血性黄疸是未结合「显著增高」，不是「从没有变成有」。结合正常是 $0\sim 8\,\mathrm{\mu mol/L}$，阻塞时这一户才明显升高。
:::

### （二）黄疸依据病因有溶血性、肝细胞性和阻塞性之分

体内胆红素生成过多，或肝细胞对胆红素的摄取、转化及排泄能力下降等均可引起血浆胆红素含量增多。当血清胆红素含量超过 $23.0\,\mathrm{\mu mol/L}$ 称为高胆红素血症（hyperbilirubinemia）。胆红素为橙黄色物质，过量的胆红素可扩散进入组织造成黄染现象，这一体征称为黄疸（jaundice）。由于皮肤、巩膜、指甲床下和上颚等含有较多弹性蛋白，对胆红素有较强的亲和力，故易被黄染。

:::definition{label="高胆红素血症"}
血清胆红素超过 $23.0\,\mathrm{\mu mol/L}$。成因：生成过多，或肝摄取、转化、排泄能力下降。
:::

:::definition{label="黄疸"}
过量橙黄色胆红素扩散入组织造成黄染。皮肤、巩膜、指甲床下和上颚弹性蛋白多，亲和力强，易被黄染。
:::

黄疸形成原因包括：①胆红素形成过多，如红细胞溶解过多；②肝细胞处理胆红素能力下降，如肝细胞受损，对胆红素摄取、转化和排泄发生障碍；③胆红素肝外排泄障碍：因胆道梗阻等原因导致胆红素无法正常排泄到肠道，胆红素逆流入血，造成黄疸。另外，还有一些药物也容易导致高胆红素血症，如抗菌药物两性霉素 $\mathrm{B}$、异烟肼、利福平、乙胺丁醇、利托那韦等；降脂药物阿托伐他汀，抗肿瘤药物如克唑替尼、瑞格非尼等。临床上常根据黄疸发病的原因不同，将黄疸分为三类。

:::keypoint{label="黄疸成因三句话，对应后面三型"}
- 形成过多（溶血）→ 溶血性黄疸。
- 肝细胞摄取、转化、排泄障碍 → 肝细胞性黄疸。
- 肝外排泄障碍、胆道梗阻、逆流入血 → 阻塞性黄疸。
:::

:::pitfall{label="分型用本版用名，不要用外校三分类替换"}
本版三类：溶血性黄疸、肝细胞性黄疸、阻塞性黄疸。又称肝前性、肝原性、肝后性，是「又称」，不是用来换掉教材标题。不要改成「肝前／肝性／肝后」当唯一用名，也不要把「阻塞性」改成外校的「梗阻性」当本节标题——正文标题是阻塞性黄疸。
:::

**1. 溶血性黄疸**　溶血性黄疸（hemolytic jaundice）又称为肝前性黄疸（prehepatic jaundice）。系各种原因所致红细胞的大量破坏，单核吞噬系统产生胆红素过多，超过了肝细胞摄取、转化和排泄胆红素的能力，造成血液中未结合胆红素浓度显著增高所致。其特征为：①血浆总胆红素、未结合胆红素含量增高；②结合胆红素的浓度改变不大，尿胆红素呈阴性；③因肝对胆红素的摄取、转化和排泄增多，过多的胆红素进入胆道系统，肠肝循环增多，使得尿胆原和尿胆素含量增多，粪胆原与粪胆素亦增加；④伴有其他特征如贫血、脾大及末梢血液网织红细胞增多等。某些药物、某些疾病（如恶性疟疾、过敏、镰状细胞贫血、蚕豆病等）及输血不当等多种因素均有可能引起大量红细胞破坏，导致溶血性黄疸。

:::definition{label="溶血性黄疸"}
又称肝前性黄疸。红细胞大量破坏 → 未结合胆红素显著增高，超过肝的处理能力。结合胆红素改变不大，尿胆红素阴性；尿胆原、尿胆素、粪胆原、粪胆素均增多；常伴贫血、脾大、网织红细胞增多。
:::

:::cause-effect{title="溶血 → 未结合胆红素升高，尿胆红素仍阴性"}
红细胞破坏过多 → 单核吞噬系统造出过量未结合胆红素 → 血里间接胆红素↑↑ → 肝仍能结合、排入肠道 → 胆素原肠肝循环加大 → 尿／粪胆素原增多；因为血里主要是未结合（不入尿），尿胆红素阴性。
:::

**2. 肝细胞性黄疸**　肝细胞性黄疸（hepatocellular jaundice），又称为肝原性黄疸（hepatic jaundice）。由于肝细胞功能受损，造成其摄取、转化和排泄胆红素的能力降低所致的黄疸。一方面肝摄取胆红素障碍，造成血中未结合胆红素升高；另一方面肝细胞受损肿胀，压迫毛细胆管，造成肝内毛细胆管阻塞，而后者与肝血窦直接相通，使肝内部分结合胆红素反流入血，造成血清结合胆红素亦增高。此外，经肠肝循环入肝的胆素原可经损伤的肝细胞进入体循环，并从尿中排出，使尿胆素原升高。其特征为：①血清未结合胆红素和结合胆红素均升高。②尿胆红素呈阳性。③尿胆素原升高，但若胆小管堵塞严重，则尿胆素原反而降低。④粪胆素原含量正常或降低。由于肝功能障碍，结合胆红素在肝内生成减少，粪便颜色可变浅。⑤其他特征如血清谷丙转氨酶（$\mathrm{ALT}$）及谷草转氨酶（$\mathrm{AST}$）活性明显升高。肝细胞性黄疸常见于肝实质性疾病如各种肝炎、肝硬化、肝肿瘤及中毒（如氯仿、四氯化碳）等引发的肝损伤。

:::definition{label="肝细胞性黄疸"}
又称肝原性黄疸。摄取、转化、排泄都差：未结合升高；毛细胆管受压、结合胆红素反流入血。尿胆红素阳性；尿胆素原升高（胆管堵得很厉害时反而降低）；粪胆素原正常或降低；$\mathrm{ALT}$、$\mathrm{AST}$ 明显升高。
:::

:::insight{label="肝细胞性黄疸两头都高"}
未结合高（摄取／转化差）$+$ 结合高（毛细胆管反流）。所以尿胆红素可以阳性——这是和溶血性黄疸最容易分的一户。
:::

**3. 阻塞性黄疸**　阻塞性黄疸（obstructive jaundice）又称为肝后性黄疸（post-hepatic jaundice）。由各种原因引起的胆管系统阻塞，胆汁排泄通道受阻，使胆小管和毛细胆管内压力增高而破裂，导致结合胆红素反流入血，使得血清结合胆红素明显升高。其特征为：①结合胆红素明显升高，未结合胆红素升高不明显；②大量结合胆红素可从肾小球滤出，所以尿胆红素呈强阳性，尿的颜色加深，可呈茶叶水色；③由于胆管阻塞排入肠道的结合胆红素减少，导致肠菌生成胆素原减少，粪便中胆素原及胆素含量降低，完全阻塞的病人粪便可变成灰白色或白陶土色；④其他特征如血清胆固醇和碱性磷酸酶（$\mathrm{ALP}$）活性明显升高等。阻塞性黄疸常见于胆管炎、肿瘤（尤其胰头癌）、胆结石或先天性胆管闭锁等疾病。各种黄疸血、尿、粪胆色素的实验室检查变化见表25-8。

:::definition{label="阻塞性黄疸"}
又称肝后性黄疸。胆管阻塞 → 胆小管／毛细胆管压力高而破裂 → 结合胆红素反流入血。结合胆红素明显升高，未结合升高不明显；尿胆红素强阳性，尿呈茶叶水色；粪胆素原／胆素降低，完全阻塞时白陶土色；血清胆固醇和 $\mathrm{ALP}$ 明显升高。
:::

:::cause-effect{title="胆道阻塞 → 结合胆红素入血，粪便变浅"}
通道堵住 → 结合胆红素回漏 → 尿胆红素强阳性、尿色深；同时入肠的结合胆红素减少 → 肠菌做不出胆素原 → 粪色变浅乃至白陶土色，尿胆素原也下降。
:::
