# 第三节　血细胞物质代谢

第二节把血红素在幼红细胞和网织红细胞里合成完毕。本节只立「血细胞物质代谢」：成熟红细胞没有细胞核和线粒体，糖无氧氧化是获能的唯一途径；$2,3$-$\mathrm{BPG}$ 降低血红蛋白对氧的亲和力；磷酸戊糖途径提供 $\mathrm{NADPH}$ 维持还原型谷胱甘肽。白细胞再按获能、活性氧、超敏反应和蛋白质合成四条收。不要把成熟红细胞写成还能做线粒体氧化磷酸化。

:::concept{term="先问成熟红细胞还剩哪几条路，再问 2,3-BPG 和 GSH 各保护什么"}
看见「血细胞代谢」，先不要默写白细胞分类表。户头是：红细胞运氧，白细胞免疫，血小板凝血；本节重点是红细胞和白细胞。表26-2 把有核、网织、成熟三列对照：成熟红细胞只留下糖无氧氧化和戊糖磷酸途径。$2,3$-$\mathrm{BPG}$ 走图26-5、图26-6；$\mathrm{GSH}$ 和高铁血红素对 $\mathrm{eIF}$-$2$ 的图若电子版缺失，按正文走。
:::

:::note{label="电子版缺失"}
本节嵌入的插图是图26-5（甘油酸-$2,3$-二磷酸支路）和图26-6（甘油酸-$2,3$-二磷酸与血红蛋白的结合）。图26-7（谷胱甘肽的氧化与还原及其有关代谢）和图26-8（高铁血红素对起始因子 $2$ 的调节；$\mathrm{R}$ 为蛋白激酶 $\mathrm{A}$ 调节亚基，$\mathrm{C}$ 为催化亚基）电子版缺失，正文不嵌入，机制按下面散文写。
:::

血液中存在有多种血细胞：红细胞，主要的功能是运送氧；白细胞，在机体免疫反应中发挥重要作用；血小板，在凝血过程中起重要作用。血小板由骨髓造血组织中的巨核细胞脱落的胞质被细胞膜包裹而形成，本节重点介绍红细胞和白细胞的主要代谢特点。

:::definition{label="三类血细胞的职分"}
红细胞运送氧；白细胞参与免疫；血小板参与凝血。血小板来自巨核细胞脱落的胞质被细胞膜包裹。本节展开红、白两系，血小板只点名。
:::

:::pitfall{label="不要把巨核细胞写成血小板的另一种名字"}
血小板是巨核细胞脱落的胞质碎片。写成「血小板在骨髓里分裂增殖」，表26-2 那套有核红细胞的分裂账就会被安到错误的细胞头上。
:::

## 一、糖无氧氧化是成熟红细胞获得能量的唯一途径

红细胞是血液中最主要的细胞，它是在骨髓中由造血干细胞定向分化而成的红系细胞。在红系细胞发育过程中，经历了原始红细胞、早幼红细胞、中幼红细胞、晚幼红细胞、网状红细胞等阶段，最后才成为成熟红细胞。在成熟过程中，红细胞发生一系列形态和代谢的改变（表26-2）。

:::definition{label="红系发育顺序"}
造血干细胞定向分化：原始红细胞 → 早幼红细胞 → 中幼红细胞 → 晚幼红细胞 → 网状红细胞（表26-2 称网织红细胞）→ 成熟红细胞。代谢能力按有核、网织、成熟三列记，不要跳步。
:::

:::compare{title="表26-2　红细胞成熟过程中的代谢变化"}
| 代谢能力 | 有核红细胞 | 网织红细胞 | 成熟红细胞 |
|---------|-----------|-----------|-----------|
| 分裂增殖能力 | $+$ | $-$ | $-$ |
| $\mathrm{DNA}$ 合成 | $+$ | $-$＊ | $-$ |
| $\mathrm{RNA}$ 合成 | $+$ | $-$ | $-$ |
| 蛋白质合成 | $+$ | $+$ | $-$ |
| 血红素合成 | $+$ | $+$ | $-$ |
| 脂质合成 | $+$ | $+$ | $-$ |
| 三羧酸循环 | $+$ | $+$ | $-$ |
| 氧化磷酸化 | $+$ | $+$ | $-$ |
| 糖无氧氧化 | $+$ | $+$ | $+$ |
| 戊糖磷酸途径 | $+$ | $+$ | $+$ |

「$+$」「$-$」分别表示该途径有或无。＊晚幼红细胞为「$-$」。网织红细胞还能合成蛋白质和血红素、还能做三羧酸循环和氧化磷酸化；成熟红细胞只剩糖无氧氧化和戊糖磷酸途径。
:::

:::pitfall{label="成熟红细胞没有线粒体氧化磷酸化"}
哺乳动物成熟红细胞除质膜和胞质外，无细胞核和线粒体等细胞器。表26-2 氧化磷酸化、三羧酸循环、血红素合成、蛋白质合成在成熟列全是「$-$」。写成「红细胞靠有氧氧化供能」，本节标题和后文 $\mathrm{ATP}$ 来源就一起错。网织红细胞尚未丢掉线粒体，不要把网织的「$+$」抄到成熟列。
:::

:::insight{label="晚幼红细胞已经停 DNA 合成"}
表注：$\mathrm{DNA}$ 合成在晚幼红细胞为「$-$」。有核红细胞这一列的「$+$」不能无差别套到每一个有核阶段。$\mathrm{RNA}$ 合成在网织列已是「$-$」，但蛋白质合成仍是「$+$」——网织红细胞用残留 $\mathrm{mRNA}$ 翻译，这是常见考法。
:::

哺乳动物的成熟红细胞除质膜和胞质外，无细胞核和线粒体等细胞器，其代谢比一般细胞简单。葡萄糖是成熟红细胞的主要能量物质。血液循环中的红细胞每天大约从血浆摄取 $30\,\mathrm{g}$ 葡萄糖，其中 $90\%\sim 95\%$ 经糖无氧氧化和甘油酸-$2,3$-二磷酸（$2,3$-bisphosphoglycerate，$2,3$-$\mathrm{BPG}$）支路进行代谢，$5\%\sim 10\%$ 通过戊糖磷酸途径进行代谢。

:::definition{label="成熟红细胞的葡萄糖去路"}
每天大约从血浆摄取 $30\,\mathrm{g}$ 葡萄糖。$90\%\sim 95\%$ 走糖无氧氧化和 $2,3$-$\mathrm{BPG}$ 支路；$5\%\sim 10\%$ 走戊糖磷酸途径。葡萄糖是主要能量物质；获能的唯一途径是糖无氧氧化，戊糖磷酸途径主要提供 $\mathrm{NADPH}$，不是第二条获能途径。
:::

:::keypoint{label="30 g、90%～95%、5%～10% 三笔"}
- $30\,\mathrm{g}/\mathrm{d}$：循环红细胞从血浆摄取的葡萄糖。
- $90\%\sim 95\%$：无氧氧化＋$2,3$-$\mathrm{BPG}$ 支路。
- $5\%\sim 10\%$：戊糖磷酸途径。
- 没有「有氧氧化占百分之几」这一笔，因为成熟红细胞做不了。
:::

### （一）糖无氧氧化产生的 ATP 维持红细胞生理活动

红细胞中存在催化糖无氧氧化所需要的所有的酶和中间代谢物（表26-3），糖无氧氧化的基本反应和其他组织相同。糖无氧氧化是红细胞获得能量的唯一途径，$1\,\mathrm{mol}$ 葡萄糖经无氧氧化生成 $2\,\mathrm{mol}$ 乳酸的过程中，产生 $2\,\mathrm{mol}\,\mathrm{ATP}$，通过这一途径可使红细胞内 $\mathrm{ATP}$ 的浓度维持在 $1\sim 2\,\mathrm{mmol/L}$ 水平。

:::definition{label="糖无氧氧化是成熟红细胞获能的唯一途径"}
$1\,\mathrm{mol}$ 葡萄糖 → $2\,\mathrm{mol}$ 乳酸，净得 $2\,\mathrm{mol}\,\mathrm{ATP}$。红细胞内 $\mathrm{ATP}$ 维持在 $1\sim 2\,\mathrm{mmol/L}$。基本反应和其他组织相同，只是这里没有线粒体把丙酮酸再送进三羧酸循环。
:::

:::compare{title="表26-3　红细胞中糖无氧氧化中间产物的浓度（μmol/L）"}
| 中间产物 | 动脉血 | 静脉血 |
|---------|-------|-------|
| 葡萄糖-$6$-磷酸 | $30.0$ | $24.8$ |
| 果糖-$6$-磷酸 | $9.3$ | $3.3$ |
| 果糖-$1,6$-二磷酸 | $0.8$ | $1.3$ |
| 磷酸丙糖 | $4.5$ | $5.0$ |
| 甘油酸-$3$-磷酸 | $19.2$ | $16.5$ |
| 甘油酸-$2$-磷酸 | $5.0$ | $1.0$ |
| 磷酸烯醇式丙酮酸 | $10.8$ | $6.6$ |
| 丙酮酸 | $87.5$ | $143.2$ |
| 甘油酸-$2,3$-二磷酸 | $3\,400$ | $4\,940$ |

$2,3$-$\mathrm{BPG}$ 比其他中间物高两个数量级，这是支路磷酸酶活性低、生成大于分解的直接数字。静脉血丙酮酸和 $2,3$-$\mathrm{BPG}$ 更高，不要把动脉列抄成「唯一正常值」。
:::

:::insight{label="表26-3 先看 2,3-BPG 那一行有多高"}
葡萄糖-$6$-磷酸只有约 $30\,\mu\mathrm{mol/L}$，丙酮酸到 $10^{2}$ 量级，$2,3$-$\mathrm{BPG}$ 到 $10^{3}$ 量级。后文「红细胞内 $2,3$-$\mathrm{BPG}$ 升高」不是形容词，是表里已经量出来的蓄积。
:::

红细胞中的 $\mathrm{ATP}$ 主要用于维持以下几方面的生理活动。

**1. 维持红细胞膜上钠泵（$\mathrm{Na}^{+},\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶）的运转**　$\mathrm{Na}^{+}$ 和 $\mathrm{K}^{+}$ 一般不易通过细胞膜，钠泵通过消耗 $\mathrm{ATP}$ 将 $\mathrm{Na}^{+}$ 泵出、$\mathrm{K}^{+}$ 泵入红细胞以维持红细胞的离子平衡以及细胞容积和双凹盘状形态。

:::definition{label="钠泵维持双凹盘状"}
$\mathrm{Na}^{+},\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶：$\mathrm{Na}^{+}$ 出、$\mathrm{K}^{+}$ 入。维持离子平衡、细胞容积和双凹盘状形态。没有 $\mathrm{ATP}$，形态先垮，不是「先不能携带氧」。
:::

**2. 维持红细胞膜上钙泵（$\mathrm{Ca}^{2+}$-$\mathrm{ATP}$ 酶）的运行**　将红细胞内的 $\mathrm{Ca}^{2+}$ 泵入血浆以维持红细胞内的低钙状态。正常情况下，红细胞内的 $\mathrm{Ca}^{2+}$ 浓度很低（$20\,\mu\mathrm{mol/L}$），而血浆的 $\mathrm{Ca}^{2+}$ 浓度为 $2\sim 3\,\mathrm{mmol/L}$。血浆内的 $\mathrm{Ca}^{2+}$ 会被动扩散进入红细胞。缺乏 $\mathrm{ATP}$ 时，钙泵不能正常运行，钙将聚集并沉积于红细胞膜，使膜失去柔韧性而趋于僵硬，红细胞流经狭窄的脾窦时易被破坏。

:::definition{label="钙泵维持红细胞内低钙"}
红细胞内 $\mathrm{Ca}^{2+}$ $20\,\mu\mathrm{mol/L}$，血浆 $2\sim 3\,\mathrm{mmol/L}$，相差约两个数量级。钙被动扩散进入，必须靠钙泵耗 $\mathrm{ATP}$ 泵回血浆。缺 $\mathrm{ATP}$ → 钙沉积于膜 → 膜僵硬 → 过脾窦时易被破坏。
:::

**3. 维持红细胞膜上脂质与血浆脂蛋白中的脂质进行交换**　红细胞膜的脂质处于不断地更新中，此过程需消耗 $\mathrm{ATP}$。缺乏 $\mathrm{ATP}$ 时，脂质更新受阻，红细胞的可塑性降低，易于破坏。

:::definition{label="膜脂交换消耗 ATP"}
成熟红细胞不能从头合成脂肪酸（后文第（四）小节），膜脂靠与血浆脂蛋白交换来更新，交换耗 $\mathrm{ATP}$。缺 $\mathrm{ATP}$ → 可塑性降低 → 易于破坏。
:::

**4. 用于谷胱甘肽、$\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$ 的生物合成**　谷胱甘肽是由谷氨酸、半胱氨酸和甘氨酸结合而成的三肽化合物，是机体中重要的抗氧化物质。合成谷胱甘肽需要 $\mathrm{ATP}$ 参与，烟酰胺在体内与 $\mathrm{ATP}$ 反应生成辅酶 $\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$，这两种辅酶在生物氧化还原反应中起电子载体或递氢体作用。

:::definition{label="ATP 还供 GSH、NAD⁺、NADP⁺ 的合成"}
谷胱甘肽：谷氨酸、半胱氨酸、甘氨酸三肽，抗氧化。合成需要 $\mathrm{ATP}$。烟酰胺与 $\mathrm{ATP}$ 生成 $\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$。后文戊糖磷酸途径维持的是已有 $\mathrm{GSH}$ 的还原状态；这里写的是分子本身的合成。
:::

**5. ATP 用于葡萄糖的活化，启动糖无氧氧化过程**　葡萄糖分解的第一步反应就是发生磷酸化而活化，此过程需由 $\mathrm{ATP}$ 供能。

:::definition{label="葡萄糖活化也要 ATP"}
己糖激酶把葡萄糖磷酸化成葡萄糖-$6$-磷酸，消耗 $\mathrm{ATP}$。获能途径的第一步先垫付，净得 $2\,\mathrm{ATP}$ 是整条路算完的结果。
:::

:::compare{title="成熟红细胞的 ATP 五件事"}
| 用途 | 缺 ATP 时 |
|------|----------|
| 钠泵 | 离子失衡，容积和双凹盘状不能维持 |
| 钙泵 | 膜上钙沉积，僵硬，脾窦破坏 |
| 膜脂与血浆脂蛋白交换 | 可塑性降低，易于破坏 |
| $\mathrm{GSH}$、$\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$ 合成 | 抗氧化和递氢体不足 |
| 葡萄糖磷酸化 | 无氧氧化启动不了 |

五条都是「维持」，不是「储存能量供其他器官用」。红细胞自己的 $\mathrm{ATP}$ 不外送。
:::

:::cause-effect{title="ATP 不足 → 膜僵硬、过脾窦破坏"}
钙泵和膜脂更新都耗 $\mathrm{ATP}$。钙沉积加脂质不能更新 → 膜失去柔韧、可塑性下降 → 狭窄脾窦里被扣留破坏。溶血的机制可以落在能量，也可以落在后文 $\mathrm{GSH}$ 不够。两户不要并。
:::

### （二）红细胞的糖无氧氧化存在甘油酸-2,3-二磷酸支路

红细胞内的糖无氧氧化还存在一个特殊途径——甘油酸-$2,3$-二磷酸支路（$2,3$-bisphosphoglycerate shunt）（图26-5）。$2,3$-$\mathrm{BPG}$ 支路的分支点是甘油酸-$1,3$-二磷酸（$1,3$-bisphosphoglycerate，$1,3$-$\mathrm{BPG}$）。正常情况下，$2,3$-$\mathrm{BPG}$ 对甘油酸二磷酸变位酶的负反馈作用大于对磷酸甘油酸激酶的抑制作用，所以 $2,3$-$\mathrm{BPG}$ 支路占糖酵解的 $15\%\sim 50\%$；但是由于 $2,3$-$\mathrm{BPG}$ 磷酸酶的活性较低，$2,3$-$\mathrm{BPG}$ 的生成大于分解，造成红细胞内 $2,3$-$\mathrm{BPG}$ 升高。红细胞内 $2,3$-$\mathrm{BPG}$ 虽然也能供能，但主要功能是调节血红蛋白的运氧功能。

:::definition{label="2,3-BPG 支路"}
从 $1,3$-$\mathrm{BPG}$ 分支。甘油酸二磷酸变位酶：$1,3$-$\mathrm{BPG}\to 2,3$-$\mathrm{BPG}$；$2,3$-$\mathrm{BPG}$ 磷酸酶：$2,3$-$\mathrm{BPG}\to$ 甘油酸-$3$-磷酸，再汇入主路到乳酸。占糖酵解 $15\%\sim 50\%$。磷酸酶活性低 → 生成大于分解 → 细胞内 $2,3$-$\mathrm{BPG}$ 高（表26-3）。
:::

:::definition{label="支路也能供能，但主职是调节运氧"}
绕过磷酸甘油酸激酶就少得一分子底物水平磷酸化的 $\mathrm{ATP}$。教材原句：虽然也能供能，但主要功能是调节血红蛋白的运氧功能。不要把支路写成「红细胞的第二条获能途径」。
:::

::figure{src="/images/biochemistry/textbook/p0518_01.png" caption="图26-5　甘油酸-2,3-二磷酸支路" alt="葡萄糖向下到1,3-BPG后分叉：主路经磷酸甘油酸激酶到3-磷酸甘油酸再向下到乳酸；支路经甘油酸二磷酸变位酶到2,3-BPG，再经2,3-BPG磷酸酶回到3-磷酸甘油酸"}

:::insight{label="图26-5 先认 1,3-BPG 的分叉"}
主路竖直向下：磷酸甘油酸激酶把 $1,3$-$\mathrm{BPG}$ 变成 $3$-磷酸甘油酸，再去乳酸。支路向右：变位酶生成 $2,3$-$\mathrm{BPG}$，磷酸酶再送回 $3$-磷酸甘油酸。两条路在 $3$-磷酸甘油酸会合。不要把 $2,3$-$\mathrm{BPG}$ 画成终产物排出细胞。
:::

$2,3$-$\mathrm{BPG}$ 是调节 $\mathrm{Hb}$ 运氧功能的重要因素，它是一个电负性很高的分子，可与血红蛋白结合，结合部位在 $\mathrm{Hb}$ 分子 $4$ 个亚基的对称中心孔穴内。$2,3$-$\mathrm{BPG}$ 的负电基团与组成孔穴侧壁的 $2$ 个 $\beta$ 亚基的带正电基团形成盐键（图26-6），从而使血红蛋白分子的 $\mathrm{T}$ 构象更趋稳定，降低 $\mathrm{Hb}$ 与 $\mathrm{O}_2$ 的亲和力。当血流经过 $P_{\mathrm{O}_2}$ 较高的肺部时，$2,3$-$\mathrm{BPG}$ 的影响不大，而当血液流过 $P_{\mathrm{O}_2}$ 较低的组织时，红细胞中 $2,3$-$\mathrm{BPG}$ 的存在则显著增加 $\mathrm{O}_2$ 释放，以供组织需要。在 $P_{\mathrm{O}_2}$ 相同条件下，随 $2,3$-$\mathrm{BPG}$ 浓度增大，$\mathrm{HbO}_2$ 释放的 $\mathrm{O}_2$ 增多。人体能通过改变红细胞内 $2,3$-$\mathrm{BPG}$ 的浓度来调节对组织的供氧。

:::definition{label="2,3-BPG 降低 Hb 对 O₂ 的亲和力"}
电负性很高，结合在 $\mathrm{Hb}$ 四个亚基的对称中心孔穴。负电基团与两个 $\beta$ 亚基侧壁的正电基团成盐键，稳定 $\mathrm{T}$ 构象，降低与 $\mathrm{O}_2$ 的亲和力。肺部 $P_{\mathrm{O}_2}$ 高时影响不大；组织 $P_{\mathrm{O}_2}$ 低时显著增加 $\mathrm{O}_2$ 释放。同一 $P_{\mathrm{O}_2}$ 下，$2,3$-$\mathrm{BPG}$ 越高，$\mathrm{HbO}_2$ 放氧越多。
:::

::figure{src="/images/biochemistry/textbook/p0518_02.png" caption="图26-6　甘油酸-2,3-二磷酸与血红蛋白的结合" alt="2,3-BPG 夹在β1链与β2链之间。β1侧正电基团为His143、Lys82、Val1的氨基；β2侧对称为Val1、Lys82、His143。2,3-BPG的磷酸和羧基带负电，与这些正电基团相对"}

:::insight{label="图26-6 只画两个 β 链，正电三位是 His143、Lys82、Val1"}
左侧 $\beta_1$：$\mathrm{His}\,143$、$\mathrm{Lys}\,82$、$\mathrm{Val}\,1$；右侧 $\beta_2$ 对称同一组残基。中央 $2,3$-$\mathrm{BPG}$ 的磷酸和羧基带负电。盐键把 $\mathrm{T}$ 态锁住。不要把结合部位画到 $\alpha$ 链孔穴，也不要把 $\mathrm{Val}\,1$ 写成血红素铁的配位。
:::

:::compare{title="肺部 vs 组织：2,3-BPG 的影响"}
| | $P_{\mathrm{O}_2}$ | $2,3$-$\mathrm{BPG}$ 干什么 |
|--|------------------|--------------------------|
| 肺 | 高 | 影响不大，照样能结合 $\mathrm{O}_2$ |
| 组织 | 低 | 显著增加 $\mathrm{O}_2$ 释放 |
| 同一 $P_{\mathrm{O}_2}$ | — | $2,3$-$\mathrm{BPG}$ 越高，放氧越多 |

人体通过改变红细胞内 $2,3$-$\mathrm{BPG}$ 浓度调节供氧。缺氧、海拔等临床场景用的就是这一户，不是「多合成几个血红蛋白分子」一句话能代替的。
:::

:::pitfall{label="2,3-BPG 是降低亲和力，不是升高"}
稳定 $\mathrm{T}$ 构象 → 亲和力下降 → 组织里更容易放氧。写成「$2,3$-$\mathrm{BPG}$ 帮助血红蛋白在肺里抓氧」，方向反了。肺里 $P_{\mathrm{O}_2}$ 高，教材写影响不大。
:::

:::pitfall{label="变位酶和磷酸甘油酸激酶的反馈强弱不要记反"}
正常情况下，$2,3$-$\mathrm{BPG}$ 对变位酶的负反馈大于对磷酸甘油酸激酶的抑制，所以支路占 $15\%\sim 50\%$，不是 $100\%$，也不是忽略不计。磷酸酶活性低才造成蓄积。三句话：分流比例、磷酸酶弱、主要功能是调节运氧。
:::

### （三）戊糖磷酸途径提供 NADPH 维持红细胞的完整性

红细胞内戊糖磷酸途径的代谢过程与其他细胞相同，主要功能是产生 $\mathrm{NADPH}+\mathrm{H}^{+}$。$\mathrm{NADH}$ 和 $\mathrm{NADPH}$ 是红细胞内重要的还原当量，它们能够对抗氧化剂，保护细胞膜蛋白质、血红蛋白和酶蛋白的巯基等不被氧化，从而维持红细胞的正常功能。戊糖磷酸途径是红细胞产生 $\mathrm{NADPH}$ 的唯一途径。红细胞中的 $\mathrm{NADPH}$ 能维持细胞内还原型谷胱甘肽（$\mathrm{GSH}$）的含量，使红细胞免遭外源性和内源性氧化剂的损害。某些疾病状态，如葡萄糖-$6$-磷酸脱氢酶缺乏症（俗称蚕豆病）病人因红细胞中戊糖磷酸途径关键酶缺乏而导致 $\mathrm{NADPH}$ 量不足，无法维持谷胱甘肽的还原状态，因此在接触强氧化因子时，红细胞细胞膜破裂导致溶血。

:::definition{label="戊糖磷酸途径是红细胞产生 NADPH 的唯一途径"}
主要功能：产生 $\mathrm{NADPH}+\mathrm{H}^{+}$。$\mathrm{NADH}$ 和 $\mathrm{NADPH}$ 对抗氧化剂，保护膜蛋白、血红蛋白和酶蛋白的巯基。$\mathrm{NADPH}$ 维持 $\mathrm{GSH}$，使红细胞免遭外源性和内源性氧化剂损害。
:::

:::definition{label="葡萄糖-6-磷酸脱氢酶缺乏症（蚕豆病）"}
戊糖磷酸途径关键酶缺乏 → $\mathrm{NADPH}$ 不足 → 不能维持谷胱甘肽还原状态 → 接触强氧化因子时膜破裂溶血。俗称蚕豆病。缺的是 $\mathrm{NADPH}$ 这一户，不是缺糖无氧氧化的 $\mathrm{ATP}$。
:::

:::note{label="图26-7 电子版缺失"}
教材图26-7 为谷胱甘肽的氧化与还原及其有关代谢。对应裁切为空文件，不嵌入。正文保留：$\mathrm{NADPH}$ 维持 $\mathrm{GSH}$；$\mathrm{GSH}$ 保护红细胞免遭氧化剂损害；$\mathrm{G}6\mathrm{PD}$ 缺乏时还原状态维持不住。
:::

:::cause-effect{title="G6PD 缺乏 → NADPH 不足 → GSH 不能还原 → 氧化剂溶血"}
关键酶在戊糖磷酸途径。接触强氧化因子（如蚕豆、某些药物）时才明显溶血，不是「没有葡萄糖就不能活」那条 $\mathrm{ATP}$ 账。两条溶血机制：能量（钠泵钙泵膜脂）和氧化还原（$\mathrm{GSH}$）。
:::

:::pitfall{label="NADPH 不是成熟红细胞的获能分子"}
获能唯一途径是糖无氧氧化产 $\mathrm{ATP}$。戊糖磷酸途径占 $5\%\sim 10\%$，产出的是还原当量。写成「蚕豆病是因为红细胞没能量」，钙泵那一户和 $\mathrm{GSH}$ 这一户就并了。
:::

由于氧化作用，红细胞内经常产生少量高铁血红蛋白（methemoglobin，$\mathrm{MHb}$），$\mathrm{MHb}$ 中的铁为三价，不能携带氧。但红细胞内有 $\mathrm{NADH}$-高铁血红蛋白还原酶和 $\mathrm{NADPH}$-高铁血红蛋白还原酶催化 $\mathrm{MHb}$ 还原成 $\mathrm{Hb}$。另外，$\mathrm{GSH}$ 和抗坏血酸也能直接还原 $\mathrm{MHb}$。在上述高铁血红蛋白还原系统中，以 $\mathrm{NADH}$-高铁血红蛋白还原酶最重要。由于有 $\mathrm{MHb}$ 还原系统的存在，使红细胞内 $\mathrm{MHb}$ 只占 $\mathrm{Hb}$ 总量的 $1\%\sim 2\%$。

:::definition{label="高铁血红蛋白 MHb"}
铁为三价，不能携带氧。经常由氧化作用少量产生。还原系统：$\mathrm{NADH}$-高铁血红蛋白还原酶（最重要）、$\mathrm{NADPH}$-高铁血红蛋白还原酶，$\mathrm{GSH}$ 和抗坏血酸也可直接还原。有此系统，$\mathrm{MHb}$ 只占 $\mathrm{Hb}$ 总量的 $1\%\sim 2\%$。
:::

:::compare{title="四种把 MHb 还原回 Hb 的方式"}
| 途径 | 本版地位 |
|------|---------|
| $\mathrm{NADH}$-高铁血红蛋白还原酶 | 最重要 |
| $\mathrm{NADPH}$-高铁血红蛋白还原酶 | 有，但不是主户 |
| $\mathrm{GSH}$ 直接还原 | 有 |
| 抗坏血酸直接还原 | 有 |

$\mathrm{NADPH}$ 的主职仍是维持 $\mathrm{GSH}$；还原 $\mathrm{MHb}$ 最重要的是 $\mathrm{NADH}$ 那一酶。不要因为戊糖磷酸途径产 $\mathrm{NADPH}$，就把 $\mathrm{MHb}$ 还原写成「全靠磷酸戊糖途径」。
:::

:::pitfall{label="MHb 的铁是三价，合成血红素时装的是亚铁"}
第二节亚铁螯合酶结合 $\mathrm{Fe}^{2+}$。运氧靠亚铁；三价是氧化损伤后的高铁血红蛋白。写成「血红素里的铁本来就是三价，靠还原酶才变成能运氧」，合成和损伤两户就反了。
:::

### （四）红细胞不能合成脂肪酸

成熟红细胞的脂质几乎都存在于细胞膜。成熟红细胞由于没有线粒体，因此无法从头合成脂肪酸，但膜脂的不断更新却是红细胞生存的必要条件。红细胞通过主动参入和被动交换不断地与血浆进行脂质交换，维持其正常的脂质组成、结构和功能。

:::definition{label="成熟红细胞不能从头合成脂肪酸"}
没有线粒体。脂质几乎都在细胞膜。生存依赖膜脂更新：主动参入和被动交换，与血浆脂质交换。前面 $\mathrm{ATP}$ 用途第 $3$ 条就是给这个交换付费。
:::

:::pitfall{label="不能从头合成 ≠ 膜脂一成不变"}
教材紧接着写「膜脂的不断更新却是红细胞生存的必要条件」。更新靠交换，不靠自身从头合成。写成「成熟红细胞还能合成脂质」，表26-2 脂质合成成熟列的「$-$」就被改掉了。
:::

### （五）高铁血红素促进珠蛋白的合成

血红蛋白由珠蛋白与血红素构成。珠蛋白的合成与一般蛋白质相同，其合成受血红素的调控。血红素的氧化产物高铁血红素能促进珠蛋白的生物合成。$\mathrm{cAMP}$ 激活蛋白激酶 $\mathrm{A}$ 后，蛋白激酶 $\mathrm{A}$ 能使无活性的 $\mathrm{eIF}$-$2$ 激酶磷酸化。后者再催化 $\mathrm{eIF}$-$2$ 磷酸化而使之失活。高铁血红素有抑制 $\mathrm{cAMP}$ 激活蛋白激酶 $\mathrm{A}$ 的作用，从而使 $\mathrm{eIF}$-$2$ 保持于去磷酸化的活性状态，有利于珠蛋白的合成，进而影响血红蛋白的合成。

:::definition{label="高铁血红素促进珠蛋白合成"}
血红素氧化产物。抑制 $\mathrm{cAMP}$ 激活蛋白激酶 $\mathrm{A}$ → $\mathrm{eIF}$-$2$ 激酶不被磷酸化激活 → $\mathrm{eIF}$-$2$ 保持去磷酸化的活性状态 → 有利于珠蛋白合成。图26-8 中 $\mathrm{R}$ 为蛋白激酶 $\mathrm{A}$ 调节亚基，$\mathrm{C}$ 为催化亚基。
:::

:::note{label="图26-8 电子版缺失"}
教材图26-8 为高铁血红素对起始因子 $2$ 的调节。对应裁切为空文件，不嵌入。机制按上一段：$\mathrm{cAMP}$ → 蛋白激酶 $\mathrm{A}$ → $\mathrm{eIF}$-$2$ 激酶磷酸化（激活）→ $\mathrm{eIF}$-$2$ 磷酸化（失活）；高铁血红素打断第一步，保住活性 $\mathrm{eIF}$-$2$。
:::

:::timeline{period="没有高铁血红素时 eIF-2 怎么被关掉"}
- **cAMP** 激活蛋白激酶A（R 调节亚基，C 催化亚基）
- **蛋白激酶A** 把无活性的 eIF-2 激酶磷酸化，激酶被激活
- **eIF-2 激酶** 再把 eIF-2 磷酸化，eIF-2 失活
- **翻译起始受阻** 珠蛋白合成下降
:::

:::timeline{period="有高铁血红素时珠蛋白合成被保住"}
- **高铁血红素** 抑制 cAMP 激活蛋白激酶A
- **eIF-2 激酶** 不被磷酸化，保持无活性
- **eIF-2** 保持去磷酸化的活性状态
- **珠蛋白合成** 得以进行，进而装配血红蛋白
:::

:::insight{label="第二节的高铁血红素关 ALA 合酶，本节的高铁血红素开珠蛋白"}
血红素合成快于珠蛋白 → 游离血红素氧化成高铁血红素 → 一边强烈抑制 $\mathrm{ALA}$ 合酶（减速造血红素），一边促进珠蛋白翻译（加速造珠蛋白）。两边对齐以后才不会堆积游离血红素。不要只记「高铁血红素有毒」。
:::

:::pitfall{label="磷酸化的 eIF-2 是失活的"}
激酶磷酸化 $\mathrm{eIF}$-$2$ 使之失活。去磷酸化才是活性状态。写成「磷酸化激活起始因子」，方向反了。高铁血红素并不是直接磷酸化 $\mathrm{eIF}$-$2$。
:::

:::pitfall{label="珠蛋白合成发生在有核红细胞和网织红细胞"}
表26-2：成熟红细胞蛋白质合成是「$-$」。这一小节的调控发生在还能翻译的红系阶段。不要写成「成熟红细胞靠高铁血红素继续造珠蛋白」。
:::

## 二、白细胞的代谢与白细胞功能密切相关

人体白细胞由粒细胞、淋巴细胞和单核巨噬细胞三大系统组成。主要功能是对外来入侵起抵抗作用，白细胞的代谢与白细胞的功能密切相关。白细胞的功能将在免疫学详细介绍，故在此只扼要介绍白细胞的代谢特点。

:::definition{label="白细胞三大系统"}
粒细胞、淋巴细胞、单核巨噬细胞。功能是抵抗外来入侵。本节只写与功能相关的代谢：获能、活性氧、超敏反应介质、活性蛋白质。
:::

### （一）糖无氧氧化是白细胞主要的获能途径

由于粒细胞的线粒体很少，故糖无氧氧化是主要的糖代谢途径。中性粒细胞能利用外源性的糖和内源性的糖原进行糖无氧氧化，为细胞的吞噬作用提供能量。单核巨噬细胞虽能进行有氧氧化，但糖无氧氧化仍占很大比重。在免疫反应中，$\mathrm{T}$ 淋巴细胞接受复杂的信号后激活、增殖和分化成不同的细胞亚型。不同状态和阶段的 $\mathrm{T}$ 淋巴细胞其葡萄糖代谢的特点有所不同，例如，免疫反应中 $\mathrm{T}$ 淋巴细胞激活前主要通过葡萄糖的有氧氧化获能，而激活后则主要通过糖无氧氧化获能。

:::definition{label="粒细胞主要靠糖无氧氧化"}
线粒体很少，糖无氧氧化是主要糖代谢途径。中性粒细胞用外源糖和内源糖原做无氧氧化，给吞噬提供能量。
:::

:::definition{label="单核巨噬细胞仍以无氧氧化占很大比重"}
虽能进行有氧氧化，但糖无氧氧化仍占很大比重。不要写成「单核巨噬细胞只做有氧氧化」。
:::

:::definition{label="T 淋巴细胞激活前后换获能方式"}
激活前主要通过葡萄糖有氧氧化获能；激活后主要通过糖无氧氧化获能。状态和阶段不同，代谢特点不同，不要写成「淋巴细胞永远有氧」。
:::

:::compare{title="白细胞获能不要抄成同一句"}
| 细胞 | 本版原句 |
|------|---------|
| 粒细胞 | 线粒体很少，糖无氧氧化是主要途径；中性粒细胞吞噬靠这条路供能 |
| 单核巨噬细胞 | 能有氧氧化，无氧氧化仍占很大比重 |
| $\mathrm{T}$ 淋巴细胞 | 激活前有氧为主，激活后无氧为主 |

与成熟红细胞「唯一途径」不同：白细胞不是没有线粒体，只是有的很少、有的激活后改道。
:::

:::pitfall{label="不要把「主要途径」写成「唯一途径」"}
「唯一途径」是成熟红细胞的原句。粒细胞是「主要」，单核巨噬细胞明确写了还能有氧氧化。抄错程度副词，红细胞和白细胞两节的标题就撞车。
:::

### （二）粒细胞和单核巨噬细胞通过产生活性氧发挥杀菌作用

中性粒细胞和单核巨噬细胞被趋化因子激活后，细胞内戊糖磷酸途径被激活，产生大量的 $\mathrm{NADPH}$。经 $\mathrm{NADPH}$ 氧化酶递电子体系可使 $\mathrm{O}_2$ 接受单电子还原，产生大量的超氧阴离子（$\mathrm{O}_2^{\cdot -}$）。超氧阴离子再进一步转变成 $\mathrm{H}_2\mathrm{O}_2$、$\cdot\mathrm{OH}$ 等活性氧，起杀菌作用。$\mathrm{NADPH}$ 氧化酶递电子体系的成分包括 $\mathrm{NADPH}$ 氧化酶、细胞色素 $b_{558}$ 和两种胞质多肽等。

$$
2\mathrm{O}_2 + \mathrm{NADPH} \rightarrow 2\mathrm{O}_2^{\cdot -} + \mathrm{NADP}^{+} + \mathrm{H}^{+}
$$

:::definition{label="NADPH 氧化酶递电子体系"}
成分：$\mathrm{NADPH}$ 氧化酶、细胞色素 $b_{558}$ 和两种胞质多肽等。趋化因子激活中性粒细胞和单核巨噬细胞 → 戊糖磷酸途径产生大量 $\mathrm{NADPH}$ → $\mathrm{O}_2$ 单电子还原成 $\mathrm{O}_2^{\cdot -}$ → 再变成 $\mathrm{H}_2\mathrm{O}_2$、$\cdot\mathrm{OH}$ 等活性氧杀菌。
:::

:::cause-effect{title="趋化因子 → PPP 产 NADPH → 超氧阴离子 → 杀菌"}
激活的是吞噬细胞的戊糖磷酸途径，不是成熟红细胞那条维持 $\mathrm{GSH}$ 的同一句话。两边都产 $\mathrm{NADPH}$：红细胞用来还原，吞噬细胞用来造活性氧。
:::

:::pitfall{label="红细胞的 NADPH 用来还原，吞噬细胞的 NADPH 用来氧化杀菌"}
同一分子，职分相反。写成「白细胞也靠 $\mathrm{NADPH}$ 维持 $\mathrm{GSH}$ 所以不能杀菌」，活性氧这一小节就空了。
:::

:::insight{label="超氧阴离子是单电子还原，不是四电子变成水"}
反应式左边 $2\mathrm{O}_2+\mathrm{NADPH}$，右边 $2\mathrm{O}_2^{\cdot -}+\mathrm{NADP}^{+}+\mathrm{H}^{+}$。进一步才到 $\mathrm{H}_2\mathrm{O}_2$ 和 $\cdot\mathrm{OH}$。不要把呼吸链末端的 $\mathrm{H}_2\mathrm{O}$ 抄到这里。
:::

### （三）粒细胞和单核巨噬细胞能合成多种物质参与超敏反应

速发型超敏反应（Ⅰ型超敏反应）中，在多种刺激因子作用下，单核巨噬细胞可将花生四烯酸转变成血栓烷和前列腺素；而在脂氧化酶的作用下，粒细胞和单核巨噬细胞可将花生四烯酸转变成白三烯；同时，粒细胞中的大量组氨酸代谢生成组胺。组胺、白三烯和前列腺素都是速发型超敏反应中重要的生物活性物质。

:::definition{label="Ⅰ型超敏反应的三种介质来源"}
单核巨噬细胞：花生四烯酸 → 血栓烷和前列腺素。粒细胞和单核巨噬细胞：脂氧化酶催化花生四烯酸 → 白三烯。粒细胞：组氨酸 → 组胺。三种都是速发型超敏反应的重要生物活性物质。
:::

:::compare{title="花生四烯酸两条下游 vs 组氨酸"}
| 产物 | 细胞 | 酶／原料线索 |
|------|------|-------------|
| 血栓烷、前列腺素 | 单核巨噬细胞 | 花生四烯酸 |
| 白三烯 | 粒细胞和单核巨噬细胞 | 脂氧化酶 |
| 组胺 | 粒细胞 | 组氨酸代谢 |

不要把组胺写成花生四烯酸的产物，也不要把白三烯只留给嗜碱性粒细胞——本版写的是粒细胞和单核巨噬细胞。
:::

### （四）单核巨噬细胞和淋巴细胞能合成多种活性蛋白质

由于成熟粒细胞缺乏内质网，故蛋白质合成量很少。而单核／巨噬细胞的蛋白质代谢很活跃，能合成多种酶、补体和各种细胞因子。在免疫反应中，$\mathrm{B}$ 淋巴细胞分化为浆细胞，产生并分泌多种抗体蛋白，参与体液免疫。

:::definition{label="成熟粒细胞蛋白质合成很少"}
缺乏内质网。不要把抗体、补体、细胞因子都写成粒细胞的分泌物。
:::

:::definition{label="单核／巨噬细胞合成酶、补体和细胞因子"}
蛋白质代谢活跃。补体在第一节已经作为血浆蛋白酶出现；这里补上合成细胞之一。
:::

:::definition{label="B 淋巴细胞 → 浆细胞 → 抗体"}
参与体液免疫。第一节 $\gamma$ 球蛋白由浆细胞合成，在这里接到白细胞代谢。$\mathrm{T}$ 淋巴细胞的获能方式变了，但抗体不是 $\mathrm{T}$ 细胞分泌的。
:::

:::compare{title="谁能大量合成蛋白质"}
| | 内质网／蛋白合成 | 本版产物 |
|--|----------------|---------|
| 成熟粒细胞 | 缺乏内质网，合成量很少 | 不是抗体工厂 |
| 单核／巨噬细胞 | 活跃 | 酶、补体、细胞因子 |
| $\mathrm{B}$ 细胞 → 浆细胞 | 分泌型 | 多种抗体蛋白 |

第一节「绝大多数血浆蛋白质在肝合成，$\gamma$ 球蛋白由浆细胞合成」与这一小节合拢。
:::

:::memory{label="本节必背分户"}
- 成熟红细胞：无核、无线粒体；糖无氧氧化是获能唯一途径；$1\,\mathrm{mol}$ 葡萄糖 → $2\,\mathrm{mol}$ 乳酸＋$2\,\mathrm{mol}\,\mathrm{ATP}$；$\mathrm{ATP}$ 维持在 $1\sim 2\,\mathrm{mmol/L}$。
- 每天摄取约 $30\,\mathrm{g}$ 葡萄糖；$90\%\sim 95\%$ 无氧氧化＋$2,3$-$\mathrm{BPG}$ 支路，$5\%\sim 10\%$ 戊糖磷酸途径。
- $\mathrm{ATP}$ 五件事：钠泵、钙泵（细胞内 $\mathrm{Ca}^{2+}$ $20\,\mu\mathrm{mol/L}$，血浆 $2\sim 3\,\mathrm{mmol/L}$）、膜脂交换、$\mathrm{GSH}/\mathrm{NAD}^{+}/\mathrm{NADP}^{+}$ 合成、葡萄糖活化。
- $2,3$-$\mathrm{BPG}$ 支路占糖酵解 $15\%\sim 50\%$；结合 $\beta$ 链 $\mathrm{His}\,143$、$\mathrm{Lys}\,82$、$\mathrm{Val}\,1$，稳定 $\mathrm{T}$ 态，降低 $\mathrm{Hb}$ 对 $\mathrm{O}_2$ 亲和力。图26-5、图26-6。
- 戊糖磷酸途径是产生 $\mathrm{NADPH}$ 的唯一途径；$\mathrm{GSH}$ 抗氧化；$\mathrm{G}6\mathrm{PD}$ 缺乏（蚕豆病）遇强氧化因子溶血。
- $\mathrm{MHb}$ 铁为三价，不能携氧；$\mathrm{NADH}$-高铁血红蛋白还原酶最重要；$\mathrm{MHb}$ 占 $1\%\sim 2\%$。
- 高铁血红素抑制 $\mathrm{cAMP}$ 激活蛋白激酶 $\mathrm{A}$，保住去磷酸化的活性 $\mathrm{eIF}$-$2$，促进珠蛋白合成。
- 粒细胞线粒体很少，无氧氧化为主；吞噬细胞 $\mathrm{NADPH}$ 氧化酶产 $\mathrm{O}_2^{\cdot -}$ 杀菌；浆细胞分泌抗体。
:::

:::keypoint{label="本章三节的收口"}
血浆蛋白质（电泳五条、清蛋白胶体渗透压、血清酶三类）是第一节。血红素原料、线粒体／胞质分工、$\mathrm{ALA}$ 合酶限速和铅敏感是第二节。成熟红细胞只靠无氧氧化、$2,3$-$\mathrm{BPG}$ 放氧、$\mathrm{GSH}$ 保护是第三节。未成熟红细胞才用琥珀酰 $\mathrm{CoA}$、甘氨酸和 $\mathrm{Fe}^{2+}$ 合成血红素。不要把第二十七章脑、心肌的账写进本节。
:::
