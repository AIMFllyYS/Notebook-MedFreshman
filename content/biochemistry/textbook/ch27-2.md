# 第二节　心肌的生物化学

第一节把脑写成高度依赖葡萄糖、特殊情况才动用酮体和乳酸。本节只立「心肌的生物化学」：心肌的主要能源是葡萄糖和脂肪酸。胎儿心肌很大程度上依赖于葡萄糖分解供能；成人心肌具备代谢灵活性，能按血糖供应在糖和脂肪酸之间切换首选能量物质，也能利用乳酸和酮体，常被称作代谢杂食者。心力衰竭时出现心肌代谢重编程。脑的谷胱甘肽、递质四户和阿尔茨海默病在第一节；骨骼肌运动供能曲线是第四节，本节不写。

:::concept{term="先问心肌以有氧氧化为主、燃料能不能切换，再问心衰怎么重编程"}
看见「心肌的生物化学」，先不要默写骨骼肌的运动供能曲线。户头是：心脏只占全身质量的 $0.5\%$，却消耗全身氧气的 $10\%$；$95\%$ 的 $\mathrm{ATP}$ 来自氧化磷酸化。成人脂肪酸占能量 $40\%\sim 60\%$，葡萄糖约 $20\%\sim 40\%$，酮体 $10\%\sim 15\%$，氨基酸 $1\%\sim 2\%$。优势效应让脂肪酸氧化和葡萄糖氧化互相反馈抑制。把「心肌＝骨骼肌」「心衰就是缺血」写成开篇，后文 $\mathrm{PCr}/\mathrm{ATP}$ 和底物偏好转向都没有底板。
:::

心肌的主要能源是葡萄糖和脂肪酸。胎儿心肌很大程度上依赖于葡萄糖分解供能，而成人心肌代谢则具备代谢灵活性，能够根据血糖供应的程度在糖和脂肪酸之间切换首选能量物质。心肌还能利用乳酸和酮体供能。心力衰竭时会出现心肌代谢的重编程。

:::definition{label="心肌的主要能源"}
葡萄糖和脂肪酸。胎儿很大程度上依赖葡萄糖分解；成人能在糖和脂肪酸之间切换首选能量物质，还能用乳酸和酮体。户头先落在「两种主燃料＋灵活性」，还不是「只吃脂肪」。
:::

:::compare{title="胎儿心肌 vs 成人心肌"}
| | 首选燃料 | 本版用语 | 不要写成 |
|--|---------|---------|---------|
| 胎儿 | 很大程度上依赖葡萄糖分解 | 尚未强调切换 | 「胎儿心肌已经是杂食者」 |

问「为什么新生儿心脏更怕低血糖」走胎儿这一户；问「餐后心脏燃料变不变」走成人灵活性。
:::

:::pitfall{label="不要把脑的开篇数字写进心肌"}
脑约占体重 $2\%$、日耗葡萄糖约 $100\,\mathrm{g}$、约总耗氧 $20\%$。心肌是质量 $0.5\%$、耗氧 $10\%$。两套数字都「体量小、份额大」，分母和百分数都不同。
:::

## 一、心肌以有氧氧化为主供能

心肌以有氧氧化为主产生能量。心脏只占全身质量的 $0.5\%$，但消耗了全身氧气的 $10\%$。心肌细胞富含线粒体，$95\%$ 的 $\mathrm{ATP}$ 生成是通过氧化磷酸化进行，糖酵解产生剩余部分的 $\mathrm{ATP}$。约 $60\%\sim 70\%$ 的 $\mathrm{ATP}$ 被用于产生驱动循环的机械力，其余的部分用于收缩过程的离子泵（主要是肌浆／内质网 $\mathrm{Ca}^{2+}$-$\mathrm{ATPase}$）运行、$\mathrm{Ca}^{2+}$ 的周期性释放和再摄取。

:::definition{label="心脏的质量与耗氧"}
只占全身质量的 $0.5\%$，消耗全身氧气的 $10\%$。户头是「有氧氧化为主」的数量底板。
:::

:::definition{label="95% 的 ATP 来自氧化磷酸化"}
心肌细胞富含线粒体。糖酵解只产生剩余部分的 $\mathrm{ATP}$。不要把心肌写成「缺氧时靠糖酵解也能长期泵血」。
:::

:::definition{label="ATP 的两个去向"}
约 $60\%\sim 70\%$ 用于产生驱动循环的机械力；其余用于收缩过程的离子泵（主要是肌浆／内质网 $\mathrm{Ca}^{2+}$-$\mathrm{ATPase}$）以及 $\mathrm{Ca}^{2+}$ 的周期性释放和再摄取。
:::

:::compare{title="脑钠钾泵 vs 心肌钙泵"}
| | 主要离子泵 | 约占哪一笔能量 | 不要写成 |
|--|-----------|--------------|---------|
| 脑 | $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-$\mathrm{ATPase}$ | 约 $50\%$ 葡萄糖氧化所产能量 | 「心肌也是钠钾泵占一半」 |
| 心肌 | 肌浆／内质网 $\mathrm{Ca}^{2+}$-$\mathrm{ATPase}$ | 机械力拿走 $60\%\sim 70\%$ 之后的「其余」 | 「心肌 $60\%\sim 70\%$ 的 ATP 给钙泵」 |

问「泵血的能量去哪了」先答机械力；问「舒张期钙怎么回去」再答钙泵。
:::

:::keypoint{label="开篇四个数字"}
- 质量份额：$0.5\%$。
- 耗氧份额：$10\%$。
- 氧化磷酸化：$95\%$ 的 $\mathrm{ATP}$。
- 机械力：$60\%\sim 70\%$ 的 $\mathrm{ATP}$。
:::

:::pitfall{label="不要用骨骼肌的供能比例替换心肌"}
骨骼肌运动时可以明显依赖无氧糖酵解，那是第四节的曲线。心肌即使在高负荷下仍以有氧氧化为主，增加的氧需求主要靠冠状动脉流量（可高达 $5$ 倍）来满足。写成「心肌和骨骼肌一样先糖酵解再有氧」，$95\%$ 这一句就删了。
:::

冠状动脉灌注是满足心脏氧需求的主要途径。高耗氧率使心肌保持相对较低的氧分压，有利于血红蛋白的氧释放。在高负荷下心肌氧需求量增加，其中约 $20\%$ 通过增加氧摄取来满足，其余通过增加冠状动脉流量（可高达 $5$ 倍）来保障供氧。心肌还通过释放 $\mathrm{NO}$ 和腺苷调节冠状动脉血管张力和心脏收缩力，发挥短暂的局部调节。

:::definition{label="冠状动脉灌注是供氧主路"}
高耗氧率把心肌氧分压维持得相对较低，有利于血红蛋白放氧。高负荷时新增氧需求：约 $20\%$ 靠增加氧摄取，其余靠冠脉流量（可高达 $5$ 倍）。
:::

:::definition{label="NO 和腺苷的局部调节"}
心肌释放 $\mathrm{NO}$ 和腺苷，调节冠状动脉血管张力和心脏收缩力，作用短暂、局部。户头不是肾素–血管紧张素系统——那是后文心衰适应性改变里点名的全身神经体液，不是本节去写肾 EPO。
:::

:::compare{title="高负荷时氧从哪来"}
| 途径 | 本版份额 | 不要写成 |
|------|---------|---------|
| 增加氧摄取 | 约 $20\%$ | 「主要靠把血里的氧抽干」 |
| 增加冠状动脉流量 | 其余；流量可高达 $5$ 倍 | 「只能靠加快心率」 |

问「为什么冠脉狭窄先出现劳力型症状」走流量这一户：平时低氧分压已经利于放氧，储备主要在流量，不在再多抽一点氧。
:::

:::insight{label="低氧分压是设计，不是衰竭"}
教材写：高耗氧率使心肌保持相对较低的氧分压，有利于血红蛋白的氧释放。这是生理。心力衰竭时的缺氧、血氧饱和度下降是另一户，写在第四节代谢重编程里，不要开篇就宣布心脏一直缺氧。
:::

## 二、心肌可利用多种物质供能

成人心肌主要消耗脂肪酸而不是葡萄糖，也能利用乳酸和酮体，因此成年人的心肌经常被命名为「代谢杂食者」。

:::definition{label="代谢杂食者"}
成人心肌主要消耗脂肪酸而不是葡萄糖，也能利用乳酸和酮体。名字落在「多种底物都能氧化」，不是「没有偏好」。后文数字仍是脂肪酸 $40\%\sim 60\%$ 为大户。
:::

:::pitfall{label="杂食不是平均分配"}
「杂食」说能吃的种类多。定量仍是：脂肪酸 $40\%\sim 60\%$，葡萄糖约 $20\%\sim 40\%$，酮体 $10\%\sim 15\%$，氨基酸 $1\%\sim 2\%$。写成各 $25\%$，优势效应就没有主次。
:::

脂肪酸占成人心肌总能量供应的 $40\%\sim 60\%$，葡萄糖占约 $20\%\sim 40\%$，而酮体和氨基酸的贡献较小（分别为 $10\%\sim 15\%$ 和 $1\%\sim 2\%$）。胰岛素或者 $\mathrm{AMPK}$ 的激活都可以刺激心肌胞内葡萄糖转运蛋白 $\mathrm{GLUT4}$ 向细胞膜的转移，增加葡萄糖的摄取。摄取的葡萄糖可被用来合成糖原，作为能量储存；而当能量耗竭时激活 $\mathrm{AMPK}$，迅速分解糖原产生葡萄糖。无论其来源如何，大多数葡萄糖在心肌细胞中都进入糖酵解途径，生成丙酮酸。脂肪酸主要由脂肪酸转运体白细胞分化抗原 $36$（cluster of differentiation $36$，$\mathrm{CD36}$）介导摄取进入细胞。$\mathrm{CD36}$ 部分定位于心肌细胞的储存囊泡，心脏工作负荷的增加和胰岛素均刺激 $\mathrm{CD36}$ 向细胞膜转移，增加脂肪酸的摄取。

:::definition{label="成人心肌四类燃料的份额"}
脂肪酸 $40\%\sim 60\%$；葡萄糖约 $20\%\sim 40\%$；酮体 $10\%\sim 15\%$；氨基酸 $1\%\sim 2\%$。先记这四笔，再记转运体。
:::

:::definition{label="GLUT4 向细胞膜转移"}
胰岛素或者 $\mathrm{AMPK}$ 激活都可刺激心肌 $\mathrm{GLUT4}$ 向细胞膜转移，增加葡萄糖摄取。摄取的葡萄糖可合成糖原；能量耗竭时 $\mathrm{AMPK}$ 激活，迅速分解糖原。无论来自摄取还是糖原，大多数葡萄糖仍进入糖酵解生成丙酮酸。
:::

:::definition{label="CD36 介导脂肪酸摄取"}
脂肪酸主要由 $\mathrm{CD36}$ 介导入胞。部分 $\mathrm{CD36}$ 存在储存囊泡；心脏工作负荷增加和胰岛素均刺激其向细胞膜转移，增加脂肪酸摄取。
:::

:::compare{title="GLUT4 vs CD36（都可被胰岛素赶到膜上）"}
| | 运什么 | 谁刺激上膜 | 不要写成 |
|--|--------|-----------|---------|
| $\mathrm{GLUT4}$ | 葡萄糖 | 胰岛素或 $\mathrm{AMPK}$ | 「只有胰岛素能让心肌吃糖」 |
| $\mathrm{CD36}$ | 脂肪酸 | 负荷增加和胰岛素 | 「胰岛素只促进糖、抑制脂肪摄取」——本版写胰岛素也刺激 $\mathrm{CD36}$ 上膜 |

胰岛素同时动葡萄糖和脂肪酸的入胞门。真正让氧化侧出现「谁压过谁」的，是后文优势效应，不是「胰岛素一来就只吃糖」。
:::

:::insight{label="AMPK 在心肌既促 GLUT4 也促 CD36"}
能量耗竭、$\mathrm{ATP}/\mathrm{ADP}$ 下降时 $\mathrm{AMPK}$ 激活，既增加葡萄糖摄取，也（后文）诱导 $\mathrm{CD36}$ 易位。$\mathrm{AMPK}$ 不是「只开糖门」的开关。后文空腹路径会把它和丙二酸单酰辅酶 $\mathrm{A}$、肉碱穿梭写在一起。
:::

心肌也可利用酮体和支链氨基酸获取能量。在禁食期间和心脏疾病（例如糖尿病心肌病和心力衰竭）发生时，酮体可以成为心肌的重要能量来源，其中 $\beta$-羟丁酸是主要的供能酮体。在线粒体中，亮氨酸等支链氨基酸首先被线粒体支链氨基酸转移酶分解代谢为支链 $\alpha$-酮酸，然后被支链 $\alpha$-酮酸脱氢酶氧化为琥珀酰辅酶 $\mathrm{A}$ 或乙酰辅酶 $\mathrm{A}$，再进入三羧酸循环分解。

:::definition{label="酮体在禁食和心脏疾病时可成为重要来源"}
禁食、糖尿病心肌病、心力衰竭时，酮体可以成为心肌的重要能量来源。主要供能酮体是 $\beta$-羟丁酸。平时份额只有 $10\%\sim 15\%$，特殊情况下抬头。
:::

:::definition{label="支链氨基酸进 TCA"}
线粒体支链氨基酸转移酶：亮氨酸等 → 支链 $\alpha$-酮酸。支链 $\alpha$-酮酸脱氢酶：氧化为琥珀酰辅酶 $\mathrm{A}$ 或乙酰辅酶 $\mathrm{A}$，进入三羧酸循环。供能份额仅 $1\%\sim 2\%$（后文心衰段再写约 $2\%$），但信号意义大于热量。
:::

:::compare{title="脑用酮体 vs 心肌用酮体"}
| | 平时 | 抬头的情境 | 不要写成 |
|--|------|-----------|---------|
| 脑 | 葡萄糖为主 | 新生儿、长期禁食、未控制糖尿病 | 「成人脑日常靠酮体」 |
| 心肌 | 已占 $10\%\sim 15\%$ | 禁食、糖尿病心肌病、心力衰竭 | 「只有脑能用酮体」 |

$\beta$-羟丁酸两边都出现。脑侧重「葡萄糖不够时的补充」；心肌侧重「杂食者名单里本来就有，疾病时可更重要」。
:::

乳酸也可用于心肌细胞内 $\mathrm{ATP}$ 的生成。乳酸被单羧酸转运蛋白摄取，并通过乳酸脱氢酶转化为丙酮酸，产生 $\mathrm{NADH}+\mathrm{H}^{+}$，随后被氧化生成乙酰辅酶 $\mathrm{A}$ 进入三羧酸循环。在运动等心脏负荷增加的情况下，乳酸主要来源于骨骼肌糖的无氧氧化而不是心肌自身产生的乳酸。

:::definition{label="心肌利用乳酸"}
$\mathrm{MCT}$ 摄取乳酸 → 乳酸脱氢酶 → 丙酮酸 $+\mathrm{NADH}+\mathrm{H}^{+}$ → 氧化成乙酰辅酶 $\mathrm{A}$ 进三羧酸循环。运动等负荷增加时，乳酸主要来自骨骼肌无氧氧化，不是心肌自己产乳酸。
:::

:::pitfall{label="点名骨骼肌乳酸来源，不要把第四节曲线整段搬进来"}
教材只写：运动等心脏负荷增加时，乳酸主要来源于骨骼肌糖的无氧氧化。这是心肌底物的来源说明。不要在本节画骨骼肌「磷酸肌酸 → 糖酵解 → 有氧氧化」的运动供能曲线，那是第四节的账。
:::

:::compare{title="乳酸三户"}
| | 乳酸在干什么 | 本节怎么用这句话 |
|--|-------------|------------------|
| 脑（第一节） | 基础吸收氧化 $8\%\sim 10\%$，剧烈运动可占脑能量 $20\%\sim 25\%$ | 脑的补充燃料 |
| 心肌自己产乳酸 | 不是运动时心肌 $\mathrm{ATP}$ 的主来源 | 心衰重度时糖摄取增加却大量生成乳酸，那是第四节 |

## 三、优势效应调节心肌利用葡萄糖和脂肪酸的比例

心肌代谢的特点是能够在葡萄糖和脂肪酸之间切换首选能量物质，表现为代谢灵活性。优势效应（advantage effect）是指一种物质代谢途径中的代谢物可以反馈抑制其他代谢途径流量的现象。脂肪酸和葡萄糖氧化分解存在相互反馈抑制：脂肪酸氧化代谢的增强抑制葡萄糖的氧化分解，而膳食后或缺氧等情况下，心肌利用更多的葡萄糖并减少脂肪酸的分解。$\mathrm{AMP}$、$\mathrm{ATP}$、丙酮酸、乙酰辅酶 $\mathrm{A}$、丙二酸单酰辅酶 $\mathrm{A}$ 和柠檬酸等代谢物具有调节能量物质利用和切换的功能（图27-5）。

:::note{label="电子版缺失"}
图27-5　心肌中葡萄糖和脂肪酸代谢途径和转换。电子版缺失，正文保留图号，不嵌入空图。下面用两条路径把画面应有的内容写成散文：空腹／生理以脂肪酸为主；进食、心脏负荷增加或缺氧转向葡萄糖。
:::

:::definition{label="代谢灵活性"}
能在葡萄糖和脂肪酸之间切换首选能量物质。这是成人心肌的特点，胎儿段没有把这句话当作主标签。
:::

:::definition{label="优势效应"}
一种物质代谢途径中的代谢物可以反馈抑制其他代谢途径流量的现象。脂肪酸氧化增强 → 抑制葡萄糖氧化；膳食后或缺氧 → 更多利用葡萄糖、减少脂肪酸分解。调节物包括 $\mathrm{AMP}$、$\mathrm{ATP}$、丙酮酸、乙酰辅酶 $\mathrm{A}$、丙二酸单酰辅酶 $\mathrm{A}$ 和柠檬酸。
:::

:::pitfall{label="优势效应不是「谁浓度高就无条件优先」"}
教材给的是代谢物反馈抑制另一条路的流量。空腹时脂肪酸氧化起来，通过乙酰辅酶 $\mathrm{A}/\mathrm{CoA}$、$\mathrm{NADH}/\mathrm{NAD}^{+}$、柠檬酸去关 $\mathrm{PDH}$ 和 $\mathrm{PFK}$；进食时丙酮酸、柠檬酸裂解、丙二酸单酰辅酶 $\mathrm{A}$ 去关肉碱穿梭。背「脂肪压糖、糖也压脂肪」两句方向，不要只背名字。
:::

:::keypoint{label="图27-5 要认的中间物"}
- $\mathrm{AMP}$／$\mathrm{ATP}$：能量电荷，决定 $\mathrm{AMPK}$ 是否激活。
- 丙酮酸：连接糖酵解和 $\mathrm{PDH}$。
- 乙酰辅酶 $\mathrm{A}$：$\beta$-氧化和 $\mathrm{PDH}$ 的共同产物，比值升高抑制 $\mathrm{PDH}$。
- 丙二酸单酰辅酶 $\mathrm{A}$：抑制肉碱穿梭，从而抑制脂肪酸进线粒体。
- 柠檬酸：进胞质抑制 $\mathrm{PFK}$；也可裂解成乙酰辅酶 $\mathrm{A}$ 再羧化成丙二酸单酰辅酶 $\mathrm{A}$。
:::

在生理或空腹状态下，心肌主要利用脂肪酸供能。在生理血浆葡萄糖水平，心肌 $\mathrm{GLUT4}$ 的转运能力饱和，限制心肌对葡萄糖的进一步利用和糖酵解流量。在空腹或饥饿等葡萄糖供应不足的情况下，$\mathrm{ATP}/\mathrm{ADP}$ 比率降低，激活 $\mathrm{AMP}$ 激活的蛋白质激酶（AMP-activated protein kinase，$\mathrm{AMPK}$），诱导 $\mathrm{CD36}$ 和 $\mathrm{GLUT4}$ 向细胞膜易位，促进脂肪酸和葡萄糖的摄取。激活的 $\mathrm{AMPK}$ 通过抑制乙酰辅酶 $\mathrm{A}$ 羧化酶活性等机制减少丙二酸单酰辅酶 $\mathrm{A}$ 产生，抑制脂肪酸的合成，并且解除丙二酸单酰辅酶 $\mathrm{A}$ 对线粒体肉碱穿梭系统的抑制，增加线粒体脂酰辅酶 $\mathrm{A}$ 的摄取并促进 $\beta$-氧化。增加的脂肪酸 $\beta$-氧化升高线粒体乙酰辅酶 $\mathrm{A}/\mathrm{CoA}$ 和 $\mathrm{NADH}/\mathrm{NAD}^{+}$ 的比值，激活丙酮酸脱氢酶激酶（$\mathrm{PDK}$），通过磷酸化丙酮酸脱氢酶（$\mathrm{PDH}$）而抑制其活性，抑制丙酮酸生成乙酰辅酶 $\mathrm{A}$。同时含量增加的柠檬酸通过柠檬酸转运体进入胞质，抑制磷酸果糖激酶（$\mathrm{PFK}$）活性，抑制糖酵解，减少葡萄糖的利用。

:::definition{label="生理血浆葡萄糖时 GLUT4 已饱和"}
生理血浆葡萄糖水平下，心肌 $\mathrm{GLUT4}$ 转运能力饱和，限制进一步利用葡萄糖和糖酵解流量。所以平时即使有糖，氧化侧仍以脂肪酸为主。
:::

:::definition{label="空腹 AMPK 打开脂肪酸氧化"}
葡萄糖供应不足 → $\mathrm{ATP}/\mathrm{ADP}$ 下降 → $\mathrm{AMPK}$ 激活 → $\mathrm{CD36}$ 和 $\mathrm{GLUT4}$ 易位。$\mathrm{AMPK}$ 抑制乙酰辅酶 $\mathrm{A}$ 羧化酶 → 丙二酸单酰辅酶 $\mathrm{A}$ 减少 → 解除对肉碱穿梭的抑制 → 脂酰辅酶 $\mathrm{A}$ 进线粒体、$\beta$-氧化增强。
:::

:::definition{label="β-氧化回头关闭葡萄糖氧化"}
$\beta$-氧化升高乙酰辅酶 $\mathrm{A}/\mathrm{CoA}$ 和 $\mathrm{NADH}/\mathrm{NAD}^{+}$ → 激活 $\mathrm{PDK}$ → 磷酸化抑制 $\mathrm{PDH}$ → 丙酮酸不能顺利变成乙酰辅酶 $\mathrm{A}$。柠檬酸进胞质抑制 $\mathrm{PFK}$，糖酵解也关。这就是「脂肪酸氧化增强抑制葡萄糖氧化分解」。
:::

:::timeline{period="空腹路径：脂肪酸压过葡萄糖"}
- **ATP/ADP 下降** 激活 AMPK
- **CD36 和 GLUT4 上膜** 脂肪酸和葡萄糖都更能进细胞
- **AMPK 抑制乙酰 CoA 羧化酶** 丙二酸单酰 CoA 减少
- **肉碱穿梭解除抑制** 脂酰 CoA 进线粒体，β-氧化增强
- **乙酰 CoA/CoA 和 NADH/NAD+ 升高** 激活 PDK，磷酸化关闭 PDH
- **柠檬酸进胞质** 抑制 PFK，糖酵解流量下降
:::

:::pitfall{label="AMPK 同时上 GLUT4，不等于空腹以糖为主"}
$\mathrm{AMPK}$ 确实让 $\mathrm{GLUT4}$ 上膜。但同一段后半：$\beta$-氧化通过 $\mathrm{PDK}$ 和柠檬酸把 $\mathrm{PDH}$、$\mathrm{PFK}$ 关掉，葡萄糖即使进来也氧化不成主燃料。问「空腹心肌首选」仍答脂肪酸。
:::

:::cause-effect{title="丙二酸单酰 CoA 减少 → 肉碱穿梭开 → β-氧化 → PDH 关"}
$\mathrm{AMPK}$ 抑制乙酰辅酶 $\mathrm{A}$ 羧化酶 → 丙二酸单酰辅酶 $\mathrm{A}$ 下降 → 不再抑制肉碱穿梭 → 脂酰辅酶 $\mathrm{A}$ 进线粒体 → $\beta$-氧化 → 乙酰辅酶 $\mathrm{A}/\mathrm{CoA}$、$\mathrm{NADH}/\mathrm{NAD}^{+}$ 升高 → $\mathrm{PDK}$ 磷酸化 $\mathrm{PDH}$ → 葡萄糖氧化被压。图27-5 缺失时按这条因果链默写。
:::

在进食、心脏负荷增加或缺氧等情况下，心肌从利用脂肪转向分解葡萄糖。上述情况导致血中葡萄糖或乳酸浓度增加，胰岛素通过 $\mathrm{AKT}$ 信号增加 $\mathrm{GLUT4}$ 细胞膜定位，提高葡萄糖的摄取和糖酵解通量。同时，心肌细胞中丙酮酸水平增加，激活丙酮酸脱氢酶磷酸酶（$\mathrm{PDP}$），通过去除丙酮酸脱氢酶（$\mathrm{PDH}$）的磷酸化修饰而激活 $\mathrm{PDH}$，从而增加乙酰辅酶 $\mathrm{A}$ 和柠檬酸水平。此外，心脏负荷增加时，$\beta$-肾上腺素升高胞质的 $\mathrm{Ca}^{2+}$ 浓度，也激活 $\mathrm{PDP}$ 并刺激葡萄糖氧化利用。细胞质柠檬酸在柠檬酸裂解酶作用下裂解产生乙酰辅酶 $\mathrm{A}$ 和草酰乙酸，胞质乙酰辅酶 $\mathrm{A}$ 可进一步羧化转变为丙二酸单酰辅酶 $\mathrm{A}$，促进脂肪酸合成，同时抑制肉碱穿梭系统从而抑制线粒体对脂肪酸的转运和氧化分解。

:::definition{label="进食、负荷或缺氧时转向葡萄糖"}
血中葡萄糖或乳酸增加。胰岛素经 $\mathrm{AKT}$ 增加 $\mathrm{GLUT4}$ 膜定位，提高摄取和糖酵解通量。丙酮酸升高激活 $\mathrm{PDP}$，去磷酸化激活 $\mathrm{PDH}$。负荷增加时 $\beta$-肾上腺素升高胞质 $\mathrm{Ca}^{2+}$，也激活 $\mathrm{PDP}$。
:::

:::definition{label="PDP 对抗 PDK"}
$\mathrm{PDK}$ 磷酸化抑制 $\mathrm{PDH}$（空腹路径）；$\mathrm{PDP}$ 去掉磷酸、激活 $\mathrm{PDH}$（进食／负荷路径）。同一 $\mathrm{PDH}$，方向由激酶和磷酸酶抢。
:::

:::definition{label="胞质柠檬酸裂解后关脂肪酸氧化"}
柠檬酸裂解酶：柠檬酸 → 乙酰辅酶 $\mathrm{A}$＋草酰乙酸。胞质乙酰辅酶 $\mathrm{A}$ 羧化成丙二酸单酰辅酶 $\mathrm{A}$，促进脂肪酸合成，并抑制肉碱穿梭，减少脂肪酸进线粒体氧化。这就是「利用更多葡萄糖并减少脂肪酸分解」。
:::

:::timeline{period="进食或负荷路径：葡萄糖压过脂肪酸"}
- **血糖或血乳酸升高** 胰岛素经 AKT 使 GLUT4 上膜
- **糖酵解通量增加** 丙酮酸升高，激活 PDP
- **PDH 去磷酸化** 丙酮酸顺利变成乙酰 CoA，柠檬酸增加
- **负荷时 Ca2+ 升高** β-肾上腺素也激活 PDP
- **胞质柠檬酸裂解** 乙酰 CoA 羧化成丙二酸单酰 CoA
- **肉碱穿梭被抑制** 脂肪酸氧化下降
:::

:::compare{title="图27-5 两条转换（电子版缺失时按表默写）"}
| | 空腹／生理 | 进食、负荷、缺氧 |
|--|-----------|------------------|
| 首选 | 脂肪酸 | 葡萄糖（及乳酸） |
| 上膜 | $\mathrm{AMPK}$ 诱导 $\mathrm{CD36}$、$\mathrm{GLUT4}$ | 胰岛素／$\mathrm{AKT}$ 使 $\mathrm{GLUT4}$ 上膜 |
| 丙二酸单酰辅酶 $\mathrm{A}$ | 因乙酰辅酶 $\mathrm{A}$ 羧化酶被 $\mathrm{AMPK}$ 抑制而减少 | 因柠檬酸裂解、乙酰辅酶 $\mathrm{A}$ 羧化而增加 |
| 肉碱穿梭 | 解除抑制，$\beta$-氧化开 | 被抑制，脂肪酸氧化关 |
| $\mathrm{PDH}$ | $\mathrm{PDK}$ 磷酸化，关 | $\mathrm{PDP}$ 去磷酸化，开 |
| $\mathrm{PFK}$ | 柠檬酸抑制，糖酵解关 | 糖酵解通量提高 |

问「优势效应怎么切换」先答丙二酸单酰辅酶 $\mathrm{A}$ 和 $\mathrm{PDH}$ 磷酸化状态，不要只答「胰岛素」。
:::

:::compare{title="PDK vs PDP"}
| | 对 PDH 做什么 | 谁把它叫醒 | 净效果 |
|--|-------------|-----------|--------|
| $\mathrm{PDK}$ | 磷酸化，抑制 | $\beta$-氧化升高乙酰辅酶 $\mathrm{A}/\mathrm{CoA}$、$\mathrm{NADH}/\mathrm{NAD}^{+}$ | 少用葡萄糖 |
| $\mathrm{PDP}$ | 去磷酸化，激活 | 丙酮酸；负荷时胞质 $\mathrm{Ca}^{2+}$ | 多用葡萄糖 |

两酶抢同一个 $\mathrm{PDH}$。写成「$\mathrm{PDH}$ 被 $\mathrm{AMPK}$ 直接磷酸化」，$\mathrm{PDK}$ 这一户就没了。
:::

:::insight{label="柠檬酸在两条路径里都出场，位置不同"}
空腹：线粒体柠檬酸进胞质，抑制 $\mathrm{PFK}$，关糖酵解。进食：糖氧化起来之后胞质柠檬酸被裂解，变成丙二酸单酰辅酶 $\mathrm{A}$ 去关脂肪酸氧化。同一中间物，一关糖、一关脂肪，问的是它当时站在哪一步。
:::

:::pitfall{label="缺氧转向葡萄糖，不是改成长期无氧酵解供能"}
教材把缺氧和膳食后、心脏负荷增加并列，写「利用更多的葡萄糖并减少脂肪酸的分解」。心肌仍以有氧氧化为主（开篇 $95\%$）。缺氧时底物偏好转向葡萄糖，不等于第四节心衰那样「摄取的糖大量变成乳酸、有氧氧化跟不上」。
:::

## 四、心力衰竭可致心肌细胞发生代谢重编程

心力衰竭是指各种病因导致心收缩和／或舒张功能发生障碍，心泵血功能降低，心排出量绝对或者相对减少，以致不能满足机体代谢需要。心衰发生时心肌对能量的需求增加并超过供应，包括线粒体功能障碍，不同底物氧化速率和相对偏好的改变。缺氧、代偿性心率增加、血氧饱和度下降进一步加重了心肌细胞能量危机。交感神经系统、肾素–血管紧张素–醛固酮系统、血管紧张素转换酶和血管紧张素Ⅱ受体激活等作用参与心力衰竭后适应性病理改变。

:::definition{label="心力衰竭"}
各种病因导致心收缩和／或舒张功能障碍，泵血功能降低，心排出量绝对或相对减少，不能满足机体代谢需要。户头是泵功能和供需，还不是某一种瓣膜病的名字。
:::

:::definition{label="心衰时的能量危机"}
需求增加并超过供应：线粒体功能障碍，底物氧化速率和相对偏好改变。缺氧、代偿性心率增加、血氧饱和度下降进一步加重。
:::

:::definition{label="心衰后的神经体液激活（点名即可）"}
交感神经系统、肾素–血管紧张素–醛固酮系统、血管紧张素转换酶和血管紧张素Ⅱ受体激活，参与适应性病理改变。本节只把它们写成心衰后的全身反应，不写肾如何分泌 $\mathrm{EPO}$、不展开肾脏本身的 $\mathrm{RAAS}$ 生成部位——那是第三节肾的生物化学。
:::

:::pitfall{label="点名 RAAS 不等于改写第三节"}
教材在心肌节提到肾素–血管紧张素–醛固酮系统，是心衰适应性病理改变的名单。不要在这里写促红细胞生成素、肾素分泌颗粒或醛固酮如何保钠，也不要把脂肪组织的瘦素、弓状核抄进来。
:::

病理性肥大或扩张型心肌病等所致心力衰竭发生时，心肌代谢重编程的标志是底物偏好转向，即减少脂肪酸的氧化，同时增加葡萄糖的利用。在心力衰竭初期，心肌细胞中葡萄糖分解代谢增加，脂肪酸的代谢不受影响。当重度心力衰竭时，肉碱棕榈酰基转移酶（carnitine palmitoyltransferase $1$，$\mathrm{CPT}$-$1$）及 $\beta$-氧化的脂酰基辅酶 $\mathrm{A}$ 脱氢酶活性降低，导致脂肪酸氧化明显降低。另外，在心力衰竭发展过程中，心肌细胞的糖摄取增加，但糖摄取的增加并没有增加糖的有氧氧化而是大量生成乳酸，使葡萄糖的转化率和利用率进一步降低。

:::definition{label="代谢重编程的标志是底物偏好转向"}
减少脂肪酸氧化，同时增加葡萄糖利用。病理性肥大或扩张型心肌病等所致心衰以此为标志。
:::

:::definition{label="初期 vs 重度"}
初期：葡萄糖分解代谢增加，脂肪酸代谢不受影响。重度：$\mathrm{CPT}$-$1$ 及脂酰基辅酶 $\mathrm{A}$ 脱氢酶活性降低，脂肪酸氧化明显降低。
:::

:::definition{label="糖摄取增加却大量生成乳酸"}
心衰发展过程中糖摄取增加，但没有相应增加有氧氧化，而是大量生成乳酸，葡萄糖转化率和利用率进一步降低。「多用糖」不等于「有氧氧化葡萄糖」。
:::

:::compare{title="生理切换 vs 心衰重编程"}
| | 生理优势效应 | 心衰代谢重编程 |
|--|------------|----------------|
| 方向 | 空腹脂肪酸、进食／负荷葡萄糖，可逆切换 | 标志是少氧化脂肪酸、多利用葡萄糖 |
| 初期 | — | 糖分解增加，脂肪酸尚未受影响 |
| 重度 | 缺氧仍以有氧氧化为主 | $\mathrm{CPT}$-$1$、脂酰基辅酶 $\mathrm{A}$ 脱氢酶下降，脂肪酸氧化明显降低 |
| 糖的去向 | 多数进糖酵解再氧化成乙酰辅酶 $\mathrm{A}$ | 摄取增加但大量生成乳酸，有氧氧化跟不上 |

问「心衰是不是把优势效应用过头」——方向看起来像「转向葡萄糖」，但重度时脂肪酸酶活性掉了，糖又变成乳酸，不是健康心脏的灵活切换。
:::

:::pitfall{label="CPT-1 下降出现在重度心衰，不要写成开篇就没有肉碱穿梭"}
生理空腹路径靠解除丙二酸单酰辅酶 $\mathrm{A}$ 对肉碱穿梭的抑制来加强 $\beta$-氧化。心衰重度时是 $\mathrm{CPT}$-$1$ 和脂酰基辅酶 $\mathrm{A}$ 脱氢酶活性降低。一个是调节性抑制，一个是酶活性掉了，不要并成「心衰就是丙二酸单酰辅酶 $\mathrm{A}$ 太高」。
:::

:::cause-effect{title="重度心衰 → CPT-1 和脂酰 CoA 脱氢酶下降 → 脂肪酸氧化明显降低"}
病理性肥大或扩张型心肌病等 → 重编程标志为少脂肪酸、多葡萄糖 → 重度时 $\mathrm{CPT}$-$1$、脂酰基辅酶 $\mathrm{A}$ 脱氢酶活性降低 → 脂肪酸氧化明显降低；同时糖摄取增加却走乳酸 → 转化率和利用率进一步降低。能量危机加重。
:::

肌酸磷酸（phosphocreatine，$\mathrm{PCr}$）是心肌的能量储备，通过高能磷酸基转移，可快速生成 $\mathrm{ATP}$。心力衰竭时线粒体结构和功能异常，呼吸链的功能受损，$\mathrm{ATP}$ 合成减少。由于肌酸转运体功能下调，肌酸磷酸和总肌酸水平在心衰早期阶段就下降，同时肌酸激酶活性下降，肌酸磷酸减少 $50\%\sim 70\%$。而 $\mathrm{ATP}$ 含量很大程度上保持不变，仅在心力衰竭终末期时下降 $30\%$。因此，肌酸磷酸与 $\mathrm{ATP}$ 比率是能量储备、供需平衡的指标，其下降是心衰的代谢特征。

:::definition{label="肌酸磷酸是心肌的能量储备"}
通过高能磷酸基转移可快速生成 $\mathrm{ATP}$。心衰时线粒体结构和功能异常，呼吸链受损，$\mathrm{ATP}$ 合成减少。
:::

:::definition{label="PCr 早降、ATP 晚降"}
肌酸转运体功能下调，心衰早期肌酸磷酸和总肌酸就下降，肌酸激酶活性也下降；肌酸磷酸减少 $50\%\sim 70\%$。$\mathrm{ATP}$ 含量很大程度上保持不变，仅终末期下降 $30\%$。
:::

:::definition{label="PCr/ATP 下降是心衰代谢特征"}
该比率是能量储备和供需平衡的指标。早期 $\mathrm{PCr}$ 已经掉、$\mathrm{ATP}$ 还在，只看 $\mathrm{ATP}$ 浓度会低估危机。
:::

:::compare{title="PCr 与 ATP 谁先掉"}
| | 早期心衰 | 终末期 | 不要写成 |
|--|---------|--------|---------|
| 肌酸磷酸 | 已减少 $50\%\sim 70\%$ | 持续低 | 「和 ATP 一起到终末期才降」 |
| $\mathrm{ATP}$ | 很大程度上不变 | 下降 $30\%$ | 「早期 ATP 已经掉一半」 |
| $\mathrm{PCr}/\mathrm{ATP}$ | 下降（特征） | 更差 | 「ATP 正常所以能量正常」 |

问「心衰早期能量储备」答 $\mathrm{PCr}$ 和 $\mathrm{PCr}/\mathrm{ATP}$，不要等 $\mathrm{ATP}$ 绝对值。
:::

:::pitfall{label="终末期 ATP 下降 30%，不是 PCr 只降 30%"}
$\mathrm{PCr}$ 早期就减少 $50\%\sim 70\%$；$\mathrm{ATP}$ 终末期才下降 $30\%$。两笔百分数不要对调。
:::

:::insight{label="PCr 快速缓冲，解释为什么机械力还能维持一段时间"}
开篇 $60\%\sim 70\%$ 的 $\mathrm{ATP}$ 用于机械力。$\mathrm{PCr}$ 把高能磷酸基迅速交给 $\mathrm{ADP}$，短时间维持 $\mathrm{ATP}$。早期 $\mathrm{PCr}$ 先耗，正是「泵还在跳、储备已经空」的生化写法。
:::

支链氨基酸和酮体在心肌信号转导中也发挥重要作用。支链氨基酸分解供能只占心肌 $\mathrm{ATP}$ 生成的 $2\%$，但心衰过程中支链氨基酸氧化分解受阻可引起支链氨基酸以及支链 $\alpha$-酮酸的堆积，持续激活哺乳动物雷帕霉素靶蛋白（mammalian target of rapamycin，$\mathrm{mTOR}$）信号，通过胰岛素受体底物（insulin receptor substrate，$\mathrm{IRS}$）损害胰岛素信号转导，最终导致胰岛素抵抗。酮体还可以起信号分子的作用，例如，$\beta$-羟丁酸是组蛋白脱乙酰酶的抑制剂，从而抑制促心肌肥大相关基因的转录。

:::definition{label="支链氨基酸供能约 2%，信号意义更大"}
分解供能只占心肌 $\mathrm{ATP}$ 的 $2\%$（与开篇氨基酸 $1\%\sim 2\%$ 是同一量级）。心衰时氧化受阻 → 支链氨基酸和支链 $\alpha$-酮酸堆积 → 持续激活 $\mathrm{mTOR}$ → 经 $\mathrm{IRS}$ 损害胰岛素信号 → 胰岛素抵抗。
:::

:::definition{label="β-羟丁酸是组蛋白脱乙酰酶抑制剂"}
酮体不仅供能，还当信号分子。$\beta$-羟丁酸抑制组蛋白脱乙酰酶，从而抑制促心肌肥大相关基因的转录。户头是表观遗传调控，不是「酮体越多越肥大」。
:::

:::cause-effect{title="BCAA 氧化受阻 → mTOR → IRS 受损 → 胰岛素抵抗"}
心衰中支链氨基酸氧化分解受阻 → 支链氨基酸及支链 $\alpha$-酮酸堆积 → 持续激活 $\mathrm{mTOR}$ → 经 $\mathrm{IRS}$ 损害胰岛素信号 → 胰岛素抵抗。这一户的胰岛素抵抗在心肌，不要写回第一节阿尔茨海默病的 $\mathrm{PI3K}/\mathrm{Akt}$。
:::

:::compare{title="酮体两本账"}
| | 供能 | 信号 |
|--|------|------|
| 平时 | 成人心肌 $10\%\sim 15\%$ | — |
| 禁食／糖尿病心肌病／心衰 | 可成为重要来源；主酮体 $\beta$-羟丁酸 | $\beta$-羟丁酸抑制组蛋白脱乙酰酶，抑制促肥大基因转录 |

问「心衰能不能用酮体」——能，而且可能同时带抗肥大信号。不要只答「酮体是脑的燃料」。
:::

:::pitfall{label="2% 是 BCAA 供能份额，不是 PCr 下降幅度"}
支链氨基酸约 $2\%$ 的 $\mathrm{ATP}$；$\mathrm{PCr}$ 早期减少 $50\%\sim 70\%$；终末期 $\mathrm{ATP}$ 下降 $30\%$。三笔百分数各管各的。
:::

:::memory{label="本节必背分户"}
- 心脏占全身质量 $0.5\%$，耗氧 $10\%$；$95\%$ $\mathrm{ATP}$ 来自氧化磷酸化；机械力用掉 $60\%\sim 70\%$，其余主要给肌浆网 $\mathrm{Ca}^{2+}$-$\mathrm{ATPase}$。
- 高负荷新增氧需求：约 $20\%$ 靠增加摄取，其余靠冠脉流量（可高达 $5$ 倍）。
- 成人份额：脂肪酸 $40\%\sim 60\%$，葡萄糖约 $20\%\sim 40\%$，酮体 $10\%\sim 15\%$，氨基酸 $1\%\sim 2\%$。代谢杂食者。
- $\mathrm{GLUT4}$：胰岛素或 $\mathrm{AMPK}$ 上膜。$\mathrm{CD36}$：负荷和胰岛素上膜。乳酸经 $\mathrm{MCT}$；运动时乳酸主要来自骨骼肌，不是心肌自己产。
- 优势效应：脂肪酸氧化与葡萄糖氧化相互反馈抑制。空腹 $\mathrm{AMPK}$ → 丙二酸单酰辅酶 $\mathrm{A}$ 下降 → 肉碱穿梭开 → $\mathrm{PDK}$ 关 $\mathrm{PDH}$。进食／负荷：$\mathrm{PDP}$ 开 $\mathrm{PDH}$，丙二酸单酰辅酶 $\mathrm{A}$ 关肉碱穿梭。图27-5 电子版缺失。
- 心衰重编程：少脂肪酸、多葡萄糖；重度 $\mathrm{CPT}$-$1$ 和脂酰基辅酶 $\mathrm{A}$ 脱氢酶下降；糖摄取增加却大量生成乳酸。
- $\mathrm{PCr}$ 早期减 $50\%\sim 70\%$，$\mathrm{ATP}$ 终末期才降 $30\%$；$\mathrm{PCr}/\mathrm{ATP}$ 下降是特征。$\mathrm{BCAA}$ 约 $2\%$ 供能，堆积经 $\mathrm{mTOR}/\mathrm{IRS}$ 致胰岛素抵抗。$\beta$-羟丁酸抑制组蛋白脱乙酰酶。
:::

:::keypoint{label="本节不写的三本账"}
脑的葡萄糖／酮体、递质四户和阿尔茨海默病在第一节，文首不要再贴胰岛素抵抗尾巴。肾的排泄、糖异生、$\mathrm{EPO}$ 和肾脏自身的 $\mathrm{RAAS}$ 生成是第三节。骨骼肌运动供能曲线和脂肪组织瘦素、弓状核是第四、五节。本节只把心肌有氧氧化、燃料切换和心衰重编程立住。
:::
