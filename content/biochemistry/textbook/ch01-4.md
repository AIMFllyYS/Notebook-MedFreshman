# 第四节　蛋白质的理化性质

本节写蛋白质与氨基酸相同或相似的理化性质——两性电离及等电点、紫外吸收、呈色反应——以及作为生物大分子才有的胶体性质、变性与复性、沉淀和凝固。朊蛋白的 $\alpha$-螺旋改折成 $\beta$-折叠已在第三节作为构象病写全，这里把“构象毁了，活性和溶解行为就变”接到变性这一本账上。

蛋白质是由氨基酸组成的，故其理化性质必然与氨基酸相同或相似。例如，两性电离及等电点、紫外吸收性质、呈色反应等；但蛋白质又是生物大分子，具有氨基酸没有的理化性质。

:::definition{label="蛋白质理化性质的两本账"}
与氨基酸相同或相似的：两性电离及等电点、紫外吸收、呈色反应。作为生物大分子才有的：胶体性质、变性、复性、沉淀、凝固。不要把蛋白质只当成“放大的氨基酸”。
:::

:::concept{term="先问这是氨基酸也有的性质，还是大分子才有的性质"}
看见“蛋白质的理化性质”，先分户头。两性电离、等电点、 $280\,\mathrm{nm}$ 吸收、茚三酮／双缩脲，是从小分子氨基酸或肽键上长出来的。胶体稳定、变性、复性、凝固，必须有空间构象和水化膜，氨基酸溶液做不出来。把两本账并成“都是酸碱性质”，电泳和盐析后面会没有台阶。
:::

## 一、蛋白质具有两性电离性质

蛋白质分子除两端的氨基和羧基可解离外，氨基酸残基侧链中某些基团，如谷氨酸、天冬氨酸残基中的 $\gamma$ 和 $\beta$-羧基，赖氨酸残基中的 $\varepsilon$-氨基、精氨酸残基的胍基和组氨酸残基的咪唑基，在一定的溶液 $\mathrm{pH}$ 条件下都可解离成带负电荷或正电荷的基团。当蛋白质溶液处于某一 $\mathrm{pH}$ 时，蛋白质解离成正、负离子的趋势相等，即成为兼性离子，净电荷为零，此时溶液的 $\mathrm{pH}$ 称为蛋白质的等电点（protein isoelectric point，$\mathrm{pI}$）。溶液的 $\mathrm{pH}$ 大于某一蛋白质的等电点时，该蛋白质颗粒带负电荷，反之则带正电荷。

体内各种蛋白质的等电点不同，但大多数接近于 $\mathrm{pH}\,5.0$。所以在人体体液 $\mathrm{pH}\,7.4$ 的环境下，大多数蛋白质解离成阴离子。少数蛋白质含碱性氨基酸较多，其等电点偏于碱性，被称为碱性蛋白质，如鱼精蛋白、组蛋白等。也有少量蛋白质含酸性氨基酸较多，其等电点偏于酸性，被称为酸性蛋白质，如胃蛋白酶和丝蛋白等。

:::definition{label="蛋白质的两性电离"}
蛋白质除两端氨基和羧基可解离外，侧链中谷氨酸、天冬氨酸的 $\gamma$ 和 $\beta$-羧基，赖氨酸的 $\varepsilon$-氨基，精氨酸的胍基，组氨酸的咪唑基，在一定 $\mathrm{pH}$ 下都可解离成负电或正电基团。
:::

:::definition{label="蛋白质等电点"}
当蛋白质解离成正、负离子的趋势相等，成为兼性离子、净电荷为零时，溶液的 $\mathrm{pH}$ 称为蛋白质的等电点（protein isoelectric point，$\mathrm{pI}$）。溶液 $\mathrm{pH}$ 大于该蛋白质 $\mathrm{pI}$ 时颗粒带负电荷，反之带正电荷。
:::

:::definition{label="碱性蛋白质与酸性蛋白质"}
体内各种蛋白质 $\mathrm{pI}$ 不同，大多数接近 $\mathrm{pH}\,5.0$。体液 $\mathrm{pH}\,7.4$ 时大多数蛋白质解离成阴离子。含碱性氨基酸较多、$\mathrm{pI}$ 偏碱者称碱性蛋白质，如鱼精蛋白、组蛋白。含酸性氨基酸较多、$\mathrm{pI}$ 偏酸者称酸性蛋白质，如胃蛋白酶和丝蛋白。
:::

:::compare{title="pH 与 pI 怎样决定蛋白质净电荷"}
| 条件 | 净电荷 | 电场中的去向（第五节电泳） |
|------|--------|------------------------------|
| $\mathrm{pH}=\mathrm{pI}$ | 零（兼性离子） | 不泳动；等电聚焦停在这里 |
| $\mathrm{pH}>\mathrm{pI}$ | 负 | 向正极 |
| $\mathrm{pH}<\mathrm{pI}$ | 正 | 向负极 |
| 体液 $\mathrm{pH}\,7.4$，大多数蛋白 $\mathrm{pI}\approx 5.0$ | 负（阴离子） | 多数血浆蛋白向正极一侧 |
:::

:::pitfall{label="等电点不是“蛋白质不能电离”，而是正负趋势相等"}
$\mathrm{pI}$ 时仍是兼性离子，只是净电荷为零。不要听成“到了等电点分子变成中性分子、侧链都不解离”。第五节盐析、沉淀、等电聚焦，用的都是“净电荷为零时最不稳定／不再泳动”，不是“不再电离”。
:::

:::tip{label="碱性蛋白、酸性蛋白按 pI 偏哪边，不按名字好不好记"}
碱性蛋白质：碱性氨基酸多，$\mathrm{pI}$ 偏碱，如鱼精蛋白、组蛋白。酸性蛋白质：酸性氨基酸多，$\mathrm{pI}$ 偏酸，如胃蛋白酶、丝蛋白。组蛋白在核内绑 DNA，正是因为偏碱、体液中带正电。
:::

## 二、蛋白质具有胶体性质

蛋白质属于生物大分子，分子量可达 $1$ 万至 $100$ 万之巨，其分子的直径可达 $1\sim 100\,\mathrm{nm}$，为胶粒范围之内。蛋白质颗粒表面大多为亲水基团，可吸引水分子，使颗粒表面形成一层水化膜，从而阻断蛋白质颗粒的相互聚集，防止溶液中蛋白质沉淀析出。除水化膜是维持蛋白质胶体稳定的重要因素外，蛋白质胶粒表面可带有电荷，也可起胶粒稳定的作用。若去除蛋白质胶体颗粒表面电荷和水化膜两个稳定因素，蛋白质极易从溶液中析出。

:::definition{label="蛋白质胶体"}
蛋白质分子量可达 $1$ 万至 $100$ 万，分子直径 $1\sim 100\,\mathrm{nm}$，落在胶粒范围。溶液中的蛋白质因此具有胶体性质。
:::

:::definition{label="胶体稳定的两个因素"}
维持蛋白质胶体稳定的因素有二：① 表面亲水基团吸引水分子，形成水化膜，阻断颗粒相互聚集；② 胶粒表面带电荷，同种电荷相斥。两个因素都被去除时，蛋白质极易从溶液中析出。
:::

:::cause-effect{title="为什么去电荷、去水化膜就会沉淀"}
- **因** 水化膜阻断颗粒靠近，表面电荷使颗粒相斥；二者是胶体稳定的全部依赖
- **果** 一旦电荷被中和、水化膜被破坏（盐析、有机溶剂、调到 $\mathrm{pI}$ 等），颗粒聚集析出
:::

:::insight{label="第五节的盐析、透析、电泳，都从这层水化膜和这层电荷长出来"}
盐析是加盐中和电荷并破坏水化膜；有机溶剂沉淀同样动这两项；电泳用的是电荷；透析留住的是胶粒级大分子。胶体这一节不是“性质点缀”，是后面分离纯化的物理前提。
:::

## 三、很多因素可导致蛋白质变性

蛋白质的二级结构以氢键维系局部主链构象稳定，三、四级结构主要依赖于氨基酸残基侧链之间的相互作用，从而保持蛋白质的天然构象。但在某些物理和化学因素作用下，其特定的空间构象被破坏，也即有序的空间结构变成无序的空间结构，从而导致其理化性质的改变和生物学活性的丧失，称为蛋白质变性（denaturation）。一般认为蛋白质的变性主要发生二硫键和非共价键的破坏，不涉及一级结构中氨基酸序列的改变。蛋白质变性后，其理化性质及生物学性质发生改变，如溶解度降低、黏度增加、结晶能力消失、生物学活性丧失、易被蛋白酶水解等。造成蛋白质变性的因素有多种，常见的有加热、乙醇等有机溶剂、强酸、强碱、重金属离子及生物碱试剂等。在临床医学领域，变性因素常被应用来消毒及灭菌。此外，为保存蛋白质制剂（如疫苗、抗体等）的有效，也必须考虑防止蛋白质变性，如采用低温贮存等。

:::definition{label="蛋白质变性"}
在某些物理和化学因素作用下，蛋白质特定的空间构象被破坏，有序结构变成无序结构，导致理化性质改变和生物学活性丧失，称为蛋白质变性（denaturation）。一般主要发生二硫键和非共价键的破坏，不涉及一级结构中氨基酸序列的改变。
:::

:::definition{label="天然构象靠什么稳住"}
二级结构以氢键维系局部主链构象；三、四级结构主要依赖氨基酸残基侧链之间的相互作用。变性拆的是这些维系力量，不是肽键。
:::

:::keypoint{label="变性后看得见的改变"}
- 溶解度降低
- 黏度增加
- 结晶能力消失
- 生物学活性丧失
- 易被蛋白酶水解
:::

:::note{label="变性因素与临床两用"}
常见因素：加热、乙醇等有机溶剂、强酸、强碱、重金属离子及生物碱试剂。临床可用来消毒及灭菌；保存疫苗、抗体等蛋白质制剂时则必须防止变性，如低温贮存。同一类因素，灭菌要它发生，制剂要它不要发生。
:::

:::pitfall{label="变性不是水解，一级结构还在"}
变性拆二硫键和非共价键，肽键和氨基酸序列一般还在。第三节 Anfinsen 实验正是：构象没了、活性没了，序列还在，才谈得上复性。若肽键被水解，那是降解，不是变性这个词的户头。
:::

:::insight{label="构象病是“折错了”，变性是“拆开了”"}
第三节朊蛋白：一级结构不变，$\alpha$-螺旋重折成 $\beta$-折叠，变成耐酶、耐热、聚集致病的 $\mathrm{PrP}^{\mathrm{Sc}}$。变性：有序构象被物理化学因素拆成无序，活性丧失、溶解度下降。两者都证明功能依赖特定空间结构；不要把疯牛病写成“加热变性”，也不要把消毒灭菌写成“变成了朊病毒”。
:::

蛋白质变性后，疏水侧链暴露在外，肽链相互缠绕继而聚集，因而从溶液中析出，这一现象被称为蛋白质沉淀。变性的蛋白质易于沉淀，有时蛋白质发生沉淀，但并不变性。

:::definition{label="蛋白质沉淀"}
变性后疏水侧链暴露，肽链相互缠绕继而聚集，从溶液中析出，称为蛋白质沉淀。变性的蛋白质易于沉淀；有时蛋白质发生沉淀，但并不变性。
:::

:::pitfall{label="沉淀不等于变性"}
变性者易沉淀，但沉淀可以不伴随变性——盐析就是典型：去掉电荷和水化膜，蛋白析出来，空间构象仍可保留，所以盐析能用于分离纯化。把“析出来了”一律写成变性，第五节的盐析结晶就自相矛盾。
:::

若蛋白质变性程度较轻，去除变性因素后，有些蛋白质仍可恢复或部分恢复其原有的构象和功能，称为复性（renaturation）。图 1-22 所示，在核糖核酸酶 $\mathrm{A}$ 溶液中加入尿素和 $\beta$-巯基乙醇，可解除其分子中的 $4$ 对二硫键和氢键，使空间构象遭到破坏，丧失生物学活性。变性后如经透析方法去除尿素和 $\beta$-巯基乙醇，并设法使巯基氧化成二硫键，核糖核酸酶 $\mathrm{A}$ 又恢复其原有的构象，生物学活性也几乎全部重现。但是许多蛋白质变性后，空间构象被严重破坏，不能复原，称为不可逆性变性。

:::definition{label="复性"}
变性程度较轻时，去除变性因素后，有些蛋白质仍可恢复或部分恢复其原有构象和功能，称为复性（renaturation）。
:::

:::definition{label="不可逆性变性"}
许多蛋白质变性后空间构象被严重破坏，不能复原，称为不可逆性变性。
:::

:::example{label="核糖核酸酶 A 的变性与复性（与第三节同一套实验）"}
尿素和 $\beta$-巯基乙醇解除核糖核酸酶 $\mathrm{A}$ 的 $4$ 对二硫键和氢键，空间构象破坏，活性丧失。透析去除尿素和 $\beta$-巯基乙醇，并设法使巯基氧化成二硫键，原有构象恢复，生物学活性几乎全部重现。第三节用它证明一级结构是空间构象的基础；这里用它定义复性。
:::

:::timeline{period="核糖核酸酶 A 从变性到复性"}
- **加尿素和 β-巯基乙醇** 4 对二硫键和氢键被解除，构象破坏，活性丧失
- **一级结构仍在** 肽键未断，氨基酸序列未被破坏
- **透析去除尿素和 β-巯基乙醇** 并设法使巯基重新氧化成二硫键
- **复性** 原有构象恢复，生物学活性几乎全部重现
:::

蛋白质经强酸、强碱作用发生变性后，仍能溶解于强酸或强碱溶液中，若将 $\mathrm{pH}$ 调至等电点，则变性蛋白质立即结成絮状的不溶解物，此絮状物仍可溶解于强酸和强碱中。如再加热则絮状物可变成比较坚固的凝块，此凝块不易再溶于强酸和强碱中，这种现象称为蛋白质的凝固作用（protein coagulation）。实际上凝固是蛋白质变性后进一步发展的不可逆的结果。

:::definition{label="蛋白质的凝固作用"}
蛋白质经强酸、强碱变性后仍能溶于强酸或强碱；调至等电点则立即结成絮状不溶物，絮状物仍可溶于强酸和强碱。再加热则变成比较坚固、不易再溶于强酸强碱的凝块，称为蛋白质的凝固作用（protein coagulation）。凝固是变性后进一步发展的不可逆结果。
:::

:::compare{title="变性、沉淀、复性、凝固"}
| 项目 | 一级结构 | 空间构象 | 活性 | 可否回到溶液／原构象 |
|------|----------|----------|------|------------------------|
| 变性 | 一般仍在 | 有序→无序 | 丧失 | 程度轻者可复性；严重者为不可逆性变性 |
| 沉淀 | 可在 | 可变性，也可不变性 | 不一定丧失 | 盐析沉淀常可再溶 |
| 复性 | 必须仍在 | 恢复或部分恢复 | 恢复或部分恢复 | 透析去除尿素／$\beta$-巯基乙醇即其例 |
| 凝固 | 一般仍在 | 不可逆破坏 | 丧失 | 坚固凝块不易再溶于强酸强碱 |
:::

:::cause-effect{title="强酸强碱变性后怎样走到凝固"}
- **因** 强酸、强碱使蛋白质变性，但仍能溶于该强酸或强碱；调到 $\mathrm{pI}$ 时净电荷为零，立即成絮；再加热使絮状物变成坚固凝块
- **果** 出现凝固作用——这是变性进一步发展的不可逆结果，不是简单的“加热沉淀”
:::

## 四、蛋白质在紫外光谱区有特征性光吸收

由于蛋白质分子中含有共轭双键的酪氨酸和色氨酸，因此在 $280\,\mathrm{nm}$ 波长处有特征性吸收峰。在此波长范围内，蛋白质的 $A_{280}$ 与其浓度成正比关系，因此可进行蛋白质定量测定。

:::definition{label="蛋白质的 A280"}
蛋白质因含有共轭双键的酪氨酸和色氨酸，在 $280\,\mathrm{nm}$ 处有特征性吸收峰。此波长范围内 $A_{280}$ 与蛋白质浓度成正比，可用于定量测定。第五节离子交换层析的洗脱图，正是用 $A_{280}$ 跟踪蛋白质峰。
:::

:::pitfall{label="280 nm 不是肽键的吸收，是 Tyr 和 Trp 的共轭双键"}
定量靠的是酪氨酸和色氨酸。不含或很少含这两种残基的蛋白质，$A_{280}$ 会偏低，不能当成“所有蛋白质摩尔吸光系数都一样”。肽键本身的特征吸收不在这一笔。
:::

:::note{label="和氨基酸紫外性质是同一本账"}
本节开头说蛋白质与氨基酸有相同或相似的紫外吸收性质，指的就是侧链芳香族残基。定量测的是蛋白质溶液，依据仍是这些残基。
:::

## 五、应用蛋白质呈色反应可测定溶液中蛋白质含量

### 1. 茚三酮反应

蛋白质经水解后产生的氨基酸也可发生茚三酮反应，详见本章第一节。

:::definition{label="蛋白质的茚三酮反应"}
蛋白质水解产生的氨基酸可发生茚三酮反应。它测的是游离氨基酸，细节见第一节；这里只把户头接到“呈色反应可定量”。
:::

### 2. 双缩脲反应

蛋白质和多肽分子中的肽键在稀碱溶液中与硫酸铜共热，呈现紫色或红色，称为双缩脲反应（biuret reaction）。氨基酸不出现此反应。当蛋白质溶液中蛋白质的水解不断增多时，氨基酸浓度上升，其双缩脲呈色的深度就逐渐下降，因此双缩脲反应可检测蛋白质的水解程度。

:::definition{label="双缩脲反应"}
蛋白质和多肽分子中的肽键在稀碱溶液中与硫酸铜共热，呈现紫色或红色，称为双缩脲反应（biuret reaction）。氨基酸不出现此反应。
:::

:::tip{label="双缩脲跟着肽键走，水解越深颜色越浅"}
蛋白质水解不断增多时，氨基酸浓度上升，双缩脲呈色深度逐渐下降，因此可检测水解程度。茚三酮在水解后才明显，双缩脲在肽键还在时才明显——两个呈色反应方向相反，不要并成同一种“蛋白显色”。
:::

:::compare{title="两种呈色反应"}
| 项目 | 茚三酮反应 | 双缩脲反应 |
|------|------------|------------|
| 反应对象 | 蛋白质水解产生的氨基酸 | 蛋白质和多肽中的肽键 |
| 氨基酸本身 | 可反应（见第一节） | 不出现此反应 |
| 条件要点 | 详见第一节 | 稀碱溶液中与硫酸铜共热，呈紫或红 |
| 水解加深时 | 游离氨基酸增多，茚三酮可增强 | 肽键减少，呈色深度下降 |
| 用途 | 测氨基酸／水解产物 | 测蛋白质／多肽含量，并检测水解程度 |
:::

:::keypoint{label="理化性质怎样接到第五节的分离纯化"}
- 两性电离和 $\mathrm{pI}$ → 电泳、等电聚焦、离子交换层析、调 $\mathrm{pI}$ 沉淀。
- 胶体的电荷与水化膜 → 盐析、有机溶剂沉淀；去掉它们就析出。
- 变性与沉淀有交有离 → 分离时要低温、尽快拿走有机溶剂，避免变性；消毒灭菌则利用变性。
- $A_{280}$ → 层析洗脱监测和蛋白定量。
- 双缩脲 → 含量和水解程度；氨基酸不呈此色。
:::

:::memory{label="本节必背要点"}
- [ ] 蛋白质与氨基酸相同或相似的性质：两性电离及等电点、紫外吸收、呈色反应；大分子才有的：胶体、变性、复性、沉淀、凝固。
- [ ] 可解离基团：两端氨基和羧基；侧链 $\mathrm{Glu}/\mathrm{Asp}$ 的 $\gamma$、$\beta$-羧基，$\mathrm{Lys}$ 的 $\varepsilon$-氨基，$\mathrm{Arg}$ 胍基，$\mathrm{His}$ 咪唑基。
- [ ] $\mathrm{pI}$：正、负离子解离趋势相等，兼性离子，净电荷为零时的 $\mathrm{pH}$。
- [ ] $\mathrm{pH}>\mathrm{pI}$ 带负电，$\mathrm{pH}<\mathrm{pI}$ 带正电。
- [ ] 大多数蛋白质 $\mathrm{pI}$ 接近 $5.0$；体液 $\mathrm{pH}\,7.4$ 时大多数解离成阴离子。
- [ ] 碱性蛋白质（鱼精蛋白、组蛋白）$\mathrm{pI}$ 偏碱；酸性蛋白质（胃蛋白酶、丝蛋白）$\mathrm{pI}$ 偏酸。
- [ ] 分子量 $1$ 万～$100$ 万，直径 $1\sim 100\,\mathrm{nm}$，属胶粒范围。
- [ ] 胶体稳定靠水化膜和表面电荷；两者去除则极易析出。
- [ ] 变性：有序空间构象→无序，理化性质改变、生物学活性丧失；主要破二硫键和非共价键，不改氨基酸序列。
- [ ] 变性后：溶解度降低、黏度增加、结晶能力消失、活性丧失、易被蛋白酶水解。
- [ ] 常见变性因素：加热、乙醇等有机溶剂、强酸、强碱、重金属离子、生物碱试剂。
- [ ] 临床：变性因素用于消毒灭菌；疫苗、抗体等需防变性（低温贮存）。
- [ ] 变性后疏水侧链暴露、肽链缠绕聚集而析出 = 沉淀；变性者易沉淀，沉淀者不一定变性。
- [ ] 复性：变性较轻、去除因素后恢复或部分恢复构象和功能。
- [ ] 核糖核酸酶 $\mathrm{A}$：尿素 + $\beta$-巯基乙醇解除 $4$ 对二硫键和氢键；透析去除后巯基再氧化，构象和活性几乎全部重现。
- [ ] 不可逆性变性：构象严重破坏，不能复原。
- [ ] 凝固：强酸强碱变性后调至 $\mathrm{pI}$ 成絮，再加热成坚固凝块，不易再溶于强酸强碱；是变性进一步发展的不可逆结果。
- [ ] $280\,\mathrm{nm}$ 特征吸收来自含共轭双键的酪氨酸和色氨酸；$A_{280}$ 与浓度成正比，可定量。
- [ ] 茚三酮：水解产生的氨基酸可反应（见第一节）。
- [ ] 双缩脲：肽键在稀碱中与硫酸铜共热呈紫或红；氨基酸不反应；水解越多呈色越浅，可检测水解程度。
- [ ] 第三节 $\mathrm{PrP}^{\mathrm{C}}\to\mathrm{PrP}^{\mathrm{Sc}}$ 是一级结构不变的构象病；不要与变性消毒并户。
:::
