# 第一节　真核基因的结构与功能

第十三章打开第三篇分子生物学。本章不问某一条代谢途径有几步，而问遗传信息写在哪一段 $\mathrm{DNA}$ 上、这段 $\mathrm{DNA}$ 怎样被读出来。本节只立单个真核基因这一户：基因和基因组怎么定义、断裂基因的外显子与内含子、编码区决定产物、启动子／增强子／沉默子／绝缘子怎样调节表达。基因组里有多少重复序列、线粒体基因组有多长，交给第二节；作图、测序和组学交给第三节。

:::concept{term="先问这段 DNA 编不编码、再问旁边有没有启动子和增强子"}
看见“基因”，先不要默写染色体条数。户头是：能编码蛋白质或 $\mathrm{RNA}$、负载遗传信息的基本单位，外加表达所必需的调控序列。编码区决定产物序列；调控区决定何时、何地、多少。剪接、三类启动子和顺式元件是本节的账；重复序列和 $\mathrm{mtDNA}$ 是第二节的账。
:::

:::note{label="电子版缺失"}
教材第 $244$ 页章首「本章数字资源」电子版图源 `p0273_01.png` 为 $0$ 字节，不嵌入 `src`。正文以基因定义、断裂基因和调控序列为准。
:::

随着人们对遗传学和基因组学复杂性的深入了解，似乎越来越难以对基因做一个精确的定义。简而言之，基因（gene）是能够编码蛋白质或 $\mathrm{RNA}$ 等具有特定功能产物、负载遗传信息的基本单位。除了某些以 $\mathrm{RNA}$ 为基因组的 $\mathrm{RNA}$ 病毒外，基因是指存储编码 $\mathrm{RNA}$ 和蛋白质的序列信息及表达这些信息所必需的全部核苷酸序列。

基因作为遗传信息携带分子，其功能实际是基因产物的功能，即基因编码的蛋白质和 $\mathrm{RNA}$ 的功能。对基因产物不同水平的研究，需要采用不同的研究手段：生物信息学序列比对，可预测基因的功能；蛋白质与蛋白质相互作用、蛋白质与 $\mathrm{DNA}/\mathrm{RNA}$ 等的相互作用，可用于了解基因产物的生物学途径；细胞水平上，高表达或者沉默某种基因，观察细胞生物学行为的改变，以了解基因的功能；构建转基因或基因敲除的动物模型，可在整体水平观察基因功能。第三节功能基因组学把这些手段再收成一套系统方法，本节先把“基因是什么”钉住。

:::definition{label="基因"}
基因（gene）是能够编码蛋白质或 $\mathrm{RNA}$ 等具有特定功能产物、负载遗传信息的基本单位。除某些以 $\mathrm{RNA}$ 为基因组的 $\mathrm{RNA}$ 病毒外，基因指存储编码 $\mathrm{RNA}$ 和蛋白质的序列信息、以及表达这些信息所必需的全部核苷酸序列。
:::

:::definition{label="基因的功能就是产物的功能"}
基因作为遗传信息携带分子，其功能实际是基因产物的功能，即它所编码的蛋白质和 $\mathrm{RNA}$ 的功能。预测功能可以比对序列；追途径可以看分子相互作用；看细胞行为可以高表达或沉默；看整体可以转基因或敲除。
:::

:::pitfall{label="基因不只是“一段编码蛋白质的外显子”"}
定义里有两层：编码产物的序列，以及表达所必需的全部核苷酸序列。启动子、增强子等调控区也在基因这一户里。只把基因听成“从起始密码子到终止密码子的开放阅读框”，本节后半的调控序列和第二节“一个基因的全部序列中编码序列仅占 $5\%$”都对不上。
:::

:::insight{label="RNA 病毒是例外，不是把基因改写成 RNA"}
教材把例外写在前：某些以 $\mathrm{RNA}$ 为基因组的 $\mathrm{RNA}$ 病毒。其余情况下基因是 $\mathrm{DNA}$ 序列。不要据此把真核基因物质基础改成 $\mathrm{RNA}$。本节下文明确：$\mathrm{DNA}$ 是基因的物质基础，基因的功能实际上是 $\mathrm{DNA}$ 的功能。
:::

基因组（genome）是指生物体或细胞中一套完整单体具有的遗传信息的总和。$1920$ 年德国科学家 Winkles H. 首先使用基因组一词来描述生物的全部基因和染色体。基因组（GENOME）从“基因（GENe）”和“染色体（chromosOME）”两个词组合而成。人类基因组包含了细胞核染色体 $\mathrm{DNA}$（常染色体和性染色体）及线粒体 $\mathrm{DNA}$ 所携带的所有遗传信息。

不同生物的基因及基因组的大小和复杂程度各不相同，所贮存的遗传信息量有着巨大的差别，其结构与组织形式上也各有特点。基因组学（genomics）是阐明整个基因组结构、结构与功能关系以及基因之间相互作用的科学。根据研究目的不同而分为结构基因组学（structural genomics）、功能基因组学（functional genomics）和比较基因组学（comparative genomics）。第三节展开这三户；本节只把词立住，避免后文把“一个基因”和“一套基因组”并账。

:::definition{label="基因组"}
基因组（genome）是指生物体或细胞中一套完整单体具有的遗传信息的总和。词从“基因（GENe）”和“染色体（chromosOME）”组合而来。$1920$ 年 Winkles H. 用来描述生物的全部基因和染色体。
:::

:::definition{label="人类基因组包含核 DNA 和线粒体 DNA"}
人类基因组包含细胞核染色体 $\mathrm{DNA}$（常染色体和性染色体）及线粒体 $\mathrm{DNA}$ 所携带的所有遗传信息。核基因组的构成、重复序列和 $\mathrm{mtDNA}$ 的 $16\,569\,\mathrm{bp}$、$37$ 个基因，是第二节的账。
:::

:::definition{label="基因组学"}
基因组学（genomics）阐明整个基因组的结构、结构与功能关系以及基因之间的相互作用。按目的分为结构基因组学、功能基因组学和比较基因组学。
:::

:::compare{title="基因、基因组、基因组学不要并成一个词"}
| 词 | 教材原句要抓住的点 |
|----|---------------------|
| 基因 | 编码蛋白质或 $\mathrm{RNA}$ 等产物、负载遗传信息的基本单位；含编码序列和表达所需序列 |
| 基因组 | 一套完整单体的遗传信息总和；人＝核染色体 $\mathrm{DNA}$ $+$ $\mathrm{mtDNA}$ |
| 基因组学 | 研究整个基因组的结构、结构与功能关系、基因之间相互作用 |

问“卵清蛋白基因有几个外显子”走基因；问“人基因组编码序列占百分之几”走基因组；问“HGP 四张图”走基因组学。
:::

:::pitfall{label="基因组不是“全部基因的名单”"}
Winkles 的用法已经把染色体算进去。人基因组既有常染色体和性染色体，也有线粒体 $\mathrm{DNA}$。把基因组听成“两万个蛋白质编码基因的目录”，第二节的重复序列、假基因、基因沙漠和 $\mathrm{mtDNA}$ 都会没户头。
:::

$\mathrm{DNA}$ 是基因的物质基础，基因的功能实际上是 $\mathrm{DNA}$ 的功能。基因的功能包括：①利用 $4$ 种碱基的不同排列荷载遗传信息；②通过复制将所有的遗传信息稳定、忠实地遗传给子代细胞，在这一过程中，体内外环境均可导致随机发生的基因突变，这些突变是生物进化的基础；③作为基因表达（gene expression）的模板，使其所携带的遗传信息通过各种 $\mathrm{RNA}$ 和蛋白质在细胞内有序合成而表现出来。

基因的功能通过两个相关部分信息而完成：一是可以在细胞内表达为蛋白质或功能 $\mathrm{RNA}$ 的编码区（coding region）序列；二是为表达这些基因（即合成 $\mathrm{RNA}$）所需要的启动子（promoter）、增强子（enhancer）等调控区（regulatory region）序列。单个基因的组成结构及一个完整的生物体内基因的组织排列方式统称为基因组构（gene organization）。

:::definition{label="基因的三项功能"}
①用 $4$ 种碱基的不同排列荷载遗传信息；②通过复制把遗传信息稳定、忠实地传给子代，复制中随机发生的突变是进化的基础；③作为基因表达的模板，使遗传信息通过各种 $\mathrm{RNA}$ 和蛋白质有序合成而表现出来。
:::

:::definition{label="编码区与调控区"}
编码区（coding region）可在细胞内表达为蛋白质或功能 $\mathrm{RNA}$。调控区（regulatory region）为表达这些基因（即合成 $\mathrm{RNA}$）所需要，包括启动子、增强子等。两部分合在一起，才是教材所说“表达这些信息所必需的全部核苷酸序列”。
:::

:::definition{label="基因组构"}
基因组构（gene organization）指单个基因的组成结构，以及一个完整生物体内基因的组织排列方式。前半是本节断裂基因和调控序列；后半是第二节基因组的重复序列、基因家族和染色体分布。
:::

:::definition{label="基因表达"}
基因表达（gene expression）使基因携带的遗传信息通过各种 $\mathrm{RNA}$ 和蛋白质在细胞内有序合成而表现出来。转录机制交给第十五章，调控网络交给第十七章；本节只把模板和调控序列立住。
:::

:::keypoint{label="本节先把基因拆成两段信息"}
- 物质基础是 $\mathrm{DNA}$（$\mathrm{RNA}$ 病毒例外）。
- 功能三件事：荷载、复制（可突变）、表达。
- 完成功能靠编码区 $+$ 调控区。
- 基因组构＝单个基因怎么造 $+$ 基因组里怎么排。
:::

:::insight{label="突变写在复制这一条里，不是另开一章才能提"}
教材把体内外环境导致的随机突变，直接写在“忠实地遗传给子代”后面，并点明这些突变是生物进化的基础。编码区一个碱基的改变，本节第二部分会再写：可能丧失功能、获得新功能，也可能不影响产物。不要把“忠实复制”听成“永远不变”。
:::

## 一、真核基因结构的特点是不连续性

基因的基本结构包含编码蛋白质或 $\mathrm{RNA}$ 的编码序列（coding sequence）及相关的非编码序列，后者包括单个编码序列间的间隔序列、转录起始点后的基因 $5'$ 端非翻译区和 $3'$ 端非翻译区，以及表达这些编码序列所需要的启动子、增强子等调控序列。与原核生物相比较，真核基因结构最突出的特点是其不连续性，被称为断裂基因（split gene）或割裂基因（interrupted gene）。

:::definition{label="基因的基本结构"}
编码蛋白质或 $\mathrm{RNA}$ 的编码序列，加上相关的非编码序列。非编码序列包括：编码序列之间的间隔、转录起始点后的 $5'$ 非翻译区和 $3'$ 非翻译区、启动子和增强子等调控序列。
:::

:::definition{label="断裂基因"}
断裂基因（split gene）又称割裂基因（interrupted gene），指真核基因结构最突出的特点——不连续性：编码序列被内含子隔开，成熟 $\mathrm{mRNA}$ 并不保留基因上的全部序列。
:::

:::compare{title="真核基因里哪些是编码、哪些是非编码"}
| 类别 | 教材点名 |
|------|----------|
| 编码序列 | 决定蛋白质或 $\mathrm{RNA}$ 产物序列的区段 |
| 间隔序列 | 单个编码序列之间 |
| 非翻译区 | 转录起始点后的基因 $5'$ 端、$3'$ 端非翻译区 |
| 调控序列 | 启动子、增强子等 |

非编码不等于“没有用”。启动子不被转录也能提供起始信号；内含子被剪掉，但接头序列是剪接识别信号。
:::

如图13-1 所示，如果将成熟的 $\mathrm{mRNA}$ 分子序列与其基因序列（即 $\mathrm{DNA}$ 序列）比较，可以发现并不是全部的基因序列都保留在成熟的 $\mathrm{mRNA}$ 分子中，有一些区段经过剪接（splicing）被去除。在基因序列中，出现在成熟 $\mathrm{mRNA}$ 分子上的序列称为外显子（exon）；位于外显子之间、与 $\mathrm{mRNA}$ 剪接过程中被删除部分相对应的间隔序列则称为内含子（intron）。每个基因的内含子数目比外显子要少 $1$ 个。内含子和外显子同时出现在最初合成的 $\mathrm{mRNA}$ 前体中，在合成后被剪接加工为成熟 $\mathrm{mRNA}$（见第十五章）。

::figure{src="/images/biochemistry/textbook/p0274_01.png" caption="图13-1　真核生物断裂基因。上游／下游增强子夹在两侧侧翼区之外。基因本体自 5′ 端起：启动子、5′ 非翻译区、起始密码子，随后外显子（编码序列，蓝框）与内含子（插入序列，白框）交替，终止密码子落在末外显子内，其后为 3′ 非翻译区和多聚 A 信号。剪接去掉内含子后，成熟 mRNA 只保留外显子和外端非翻译区。" alt="断裂基因：外显子与内含子交替，剪接后成熟 mRNA 只保留外显子和 UTR"}

如全长为 $7.7\,\mathrm{kb}$ 的鸡卵清蛋白基因有 $8$ 个外显子和 $7$ 个内含子，最初合成的 $\mathrm{mRNA}$ 前体与相应的基因是等长的，内含子序列被切除后的成熟 $\mathrm{mRNA}$ 分子的长度仅为 $1.2\,\mathrm{kb}$。不同的基因中外显子的数量不同，少则数个，多则数十个。外显子的数量是描述基因结构的重要特征之一。

:::definition{label="外显子"}
外显子（exon）是基因序列中出现在成熟 $\mathrm{mRNA}$ 分子上的序列。图13-1 把它标成编码序列（蓝框），成熟 $\mathrm{mRNA}$ 两端还带着 $5'$、$3'$ 非翻译区。
:::

:::definition{label="内含子"}
内含子（intron）是位于外显子之间、与 $\mathrm{mRNA}$ 剪接过程中被删除部分相对应的间隔序列。图13-1 把它标成插入序列（白框）。
:::

:::definition{label="剪接"}
剪接（splicing）把 $\mathrm{mRNA}$ 前体中的内含子去掉，把外显子连成成熟 $\mathrm{mRNA}$。内含子和外显子同时出现在最初合成的 $\mathrm{mRNA}$ 前体中；加工过程见第十五章。
:::

:::definition{label="内含子比外显子少一个"}
每个基因的内含子数目比外显子要少 $1$ 个。鸡卵清蛋白基因：$8$ 个外显子、$7$ 个内含子，符合 $n$ 个外显子对应 $n-1$ 个内含子。
:::

:::keypoint{label="鸡卵清蛋白基因是本节唯一给出全长数字的例子"}
- 基因全长 $7.7\,\mathrm{kb}$，$8$ 个外显子、$7$ 个内含子。
- $\mathrm{mRNA}$ 前体与基因等长。
- 切掉内含子后成熟 $\mathrm{mRNA}$ 仅 $1.2\,\mathrm{kb}$。
- 本版没有把“人平均几个外显子”写成另一套数字，不要外补。
:::

:::insight{label="前体等长，说明内含子先被转录再被切掉"}
最初合成的 $\mathrm{mRNA}$ 前体与相应的基因等长，不是“转录时跳过内含子”。断裂发生在基因的 $\mathrm{DNA}$ 序列上，连续性在成熟 $\mathrm{mRNA}$ 上恢复。第十五章写剪接机制，本节只要求能把图13-1 的蓝框、白框和下面那条成熟 $\mathrm{mRNA}$ 对上。
:::

:::pitfall{label="外显子不等于“只编码蛋白质”"}
图13-1 的成熟 $\mathrm{mRNA}$ 两端是空白的非翻译区，它们也出现在成熟 $\mathrm{mRNA}$ 上，按定义属于外显子侧的序列。编码序列决定多肽；$\mathrm{UTR}$、启动子、增强子都不翻译成蛋白质，但仍是基因结构的一部分。把外显子听成“从 $\mathrm{ATG}$ 到终止密码子”，$5'$、$3'$ 非翻译区会没地方放。
:::

:::pitfall{label="不要把内含子数目写成和外显子一样多"}
教材写明少 $1$ 个。若基因两端不是内含子起止，交替排列就是“外显子—内含子—外显子—…—外显子”。把卵清蛋白写成 $8$ 个内含子，图13-1 和 $7.7\,\mathrm{kb}\rightarrow 1.2\,\mathrm{kb}$ 都对不齐。
:::

:::compare{title="基因、前体 mRNA、成熟 mRNA 三条长度"}
| 分子 | 含内含子？ | 鸡卵清蛋白例子 |
|------|------------|----------------|
| 基因 $\mathrm{DNA}$ | 含 | $7.7\,\mathrm{kb}$ |
| $\mathrm{mRNA}$ 前体 | 含，与基因等长 | $7.7\,\mathrm{kb}$ |
| 成熟 $\mathrm{mRNA}$ | 不含 | $1.2\,\mathrm{kb}$ |

少掉的那一截主要是内含子。外显子数量少则数个、多则数十个，是描述基因结构的重要特征。
:::

原核细胞的基因基本没有内含子。高等真核生物绝大部分编码蛋白质的基因都有内含子，但组蛋白编码基因例外。此外，编码 $\mathrm{rRNA}$ 和一些 $\mathrm{tRNA}$ 的基因也都有内含子。内含子的数量和大小在很大程度上决定了高等真核生物基因的大小。低等真核生物的内含子分布差别很大，有的酵母的结构基因较少有内含子，有的则较常见。

在不同种属中，外显子序列通常比较保守，而内含子序列则变异较大。外显子与内含子接头处有一段高度保守的序列，即内含子 $5'$ 末端大多数以 $\mathrm{GT}$ 开始，$3'$ 末端大多数以 $\mathrm{AG}$ 结束，这一共有序列（consensus sequence）是真核基因中 $\mathrm{RNA}$ 剪接的识别信号。

:::definition{label="GT-AG 规则"}
外显子与内含子接头处有一段高度保守的共有序列（consensus sequence）：内含子 $5'$ 末端大多数以 $\mathrm{GT}$ 开始，$3'$ 末端大多数以 $\mathrm{AG}$ 结束。这是真核基因中 $\mathrm{RNA}$ 剪接的识别信号。
:::

:::compare{title="谁有内含子、谁没有"}
| | 内含子 |
|--|--------|
| 原核基因 | 基本没有 |
| 高等真核生物编码蛋白质的基因 | 绝大部分有 |
| 组蛋白编码基因 | 例外，没有 |
| 编码 $\mathrm{rRNA}$、一些 $\mathrm{tRNA}$ 的基因 | 有 |
| 酵母等低等真核 | 差别很大：有的结构基因较少有，有的较常见 |

内含子的数量和大小在很大程度上决定高等真核生物基因的大小。第二节“一个基因的全部序列中编码序列仅占 $5\%$”，就是这条的定量说法。
:::

:::insight{label="外显子保守、内含子易变"}
不同种属比较时，外显子序列通常比较保守，内含子序列变异较大。这为第三节用同源搜索找基因、用种间比较鉴别编码／非编码序列留下伏笔：能对齐的多半是外显子；对不齐的长间隔不一定没有功能，但变异更大。
:::

:::pitfall{label="组蛋白基因不要跟着“真核都有内含子”一起背"}
高等真核绝大部分编码蛋白质的基因有内含子，组蛋白编码基因是教材点名的例外。$\mathrm{rRNA}$ 和一些 $\mathrm{tRNA}$ 基因有内含子，也不能推成“所有 $\mathrm{RNA}$ 基因都连续”。
:::

:::pitfall{label="GT-AG 是大多数，不是每一个内含子的绝对定律"}
教材用“大多数”。把它写成“所有内含子必须以 $\mathrm{GT}$ 开始、$\mathrm{AG}$ 结束”，后文遇到非典型剪接会无路可退。考试默写仍按本版：$\mathrm{GT}$ 开始、$\mathrm{AG}$ 结束，共有序列是剪接识别信号。
:::

为方便叙述基因编码序列和其调节序列的关系，人们约定将一个基因的 $5'$ 端称之为上游，$3'$ 端称为下游；为标定 $\mathrm{DNA}$ 信息的具体位置，将基因序列中开始 $\mathrm{RNA}$ 链合成的第一个核苷酸所对应的碱基记为 $+1$，在此碱基上游的序列记为负数，向 $5'$ 端依次为 $-1$、$-2$ 等；在此碱基下游的序列记为正数，向 $3'$ 端依次为 $+2$、$+3$ 等。零不用于标记碱基位置。

:::definition{label="上游与下游"}
一个基因的 $5'$ 端称为上游，$3'$ 端称为下游。这是叙述编码序列和调节序列相对位置的约定，不是染色体短臂／长臂。
:::

:::definition{label="转录起始点记为 +1"}
开始 $\mathrm{RNA}$ 链合成的第一个核苷酸所对应的碱基记为 $+1$。其上游记负数（$-1$、$-2$…），下游记正数（$+2$、$+3$…）。零不用于标记碱基位置。
:::

:::keypoint{label="编号规则三句"}
- $5'$ 上游，$3'$ 下游。
- $+1$ 是转录起点对应的碱基，不是起始密码子。
- 没有 $0$ 号碱基：$-1$ 紧挨 $+1$。
:::

:::pitfall{label="+1 不是 ATG，上游也不是“染色体短臂”"}
$+1$ 是开始合成 $\mathrm{RNA}$ 的第一个核苷酸。起始密码子在图13-1 里标在 $+1$ 下游的编码区。把 $+1$ 听成翻译起点，启动子“位于转录起点上游、本身通常不被转录”会对不上号。上游／下游按基因的 $5'/3'$ 说，不按染色体 $\mathrm{p}/\mathrm{q}$ 臂说。
:::

:::cause-effect{title="为什么必须先约定 +1 再写启动子"}
- **因** 真核启动子大部分在转录起点上游，本身通常不被转录；有的（如 $\mathrm{tRNA}$ 基因启动子）可在起点下游并被转录
- **果** 没有 $+1$ 这根标尺，就说不清“上游 $-25$ 附近的 $\mathrm{TATA}$ 盒”和“下游的 $\mathrm{A}$ 盒、$\mathrm{B}$ 盒”谁在转录区内、谁不在
:::

## 二、基因编码区编码多肽链和特定的 RNA 分子

基因编码区中的 $\mathrm{DNA}$ 碱基序列决定一个特定的成熟 $\mathrm{RNA}$ 分子的序列，换言之，$\mathrm{DNA}$ 的一级结构决定着其转录产物 $\mathrm{RNA}$ 分子的一级结构。有的基因仅编码一些有特定功能的 $\mathrm{RNA}$，如 $\mathrm{rRNA}$、$\mathrm{tRNA}$ 及其他小分子 $\mathrm{RNA}$ 等；而大多数基因则通过 $\mathrm{mRNA}$ 进一步编码多肽链。无论是编码 $\mathrm{RNA}$ 还是编码多肽链，基本原则是基因的编码序列决定了其编码产物的序列和功能。

因此，编码序列中一个碱基的改变或突变，都有可能使基因功能发生重要的变化。这些变化可能是原有功能的丧失，或是新功能的获得。当然，也有的碱基突变不会影响编码产物的序列或功能。另外同一基因转录后产生的不同 $\mathrm{mRNA}$ 剪接产物可以编码不同的多肽链。

:::definition{label="编码区决定产物序列"}
编码区中的 $\mathrm{DNA}$ 碱基序列决定成熟 $\mathrm{RNA}$ 分子的序列：$\mathrm{DNA}$ 一级结构决定转录产物 $\mathrm{RNA}$ 的一级结构。编码 $\mathrm{RNA}$ 或再经 $\mathrm{mRNA}$ 编码多肽，基本原则相同——编码序列决定产物的序列和功能。
:::

:::definition{label="两类编码产物"}
有的基因只编码有特定功能的 $\mathrm{RNA}$（$\mathrm{rRNA}$、$\mathrm{tRNA}$ 及其他小分子 $\mathrm{RNA}$）；大多数基因通过 $\mathrm{mRNA}$ 进一步编码多肽链。第三节三类启动子分别对应三种 $\mathrm{RNA}$ 聚合酶，就是按产物类型分的。
:::

:::definition{label="同一基因可编码不同多肽"}
同一基因转录后产生的不同 $\mathrm{mRNA}$ 剪接产物可以编码不同的多肽链。第二节会给出定量：大约 $60\%$ 的人基因转录后发生可变剪接，$80\%$ 的可变剪接会使蛋白质的序列发生改变。
:::

:::compare{title="编码区突变的三种下场"}
| 下场 | 教材原句 |
|------|----------|
| 丧失原有功能 | 有可能使基因功能发生重要变化 |
| 获得新功能 | 同上 |
| 不影响产物序列或功能 | 也有的碱基突变不会影响 |

“一个碱基”就可能改功能，不是必须整段缺失。不等于每一个碱基改变都致病。
:::

:::insight{label="可变剪接把“一个基因一个多肽”拆开"}
断裂基因的意义不只是“中间有一段要切掉”。同一套外显子可以按不同组合接到成熟 $\mathrm{mRNA}$ 上，于是一个基因对应多种多肽。这是真核生物用相对有限的基因数支撑更高复杂性的结构基础之一，第二节和思考题第 $4$ 问会再碰到。
:::

:::pitfall{label="不要把“大多数基因编码多肽”写成“基因都编码蛋白质”"}
$\mathrm{rRNA}$、$\mathrm{tRNA}$ 和其他小分子 $\mathrm{RNA}$ 基因是教材点名的另一类。后文Ⅰ类、Ⅲ类启动子主要服务这些 $\mathrm{RNA}$ 基因。把基因定义缩成“编码蛋白质的 $\mathrm{DNA}$”，启动子分类和第二节非编码 $\mathrm{RNA}$ 都会串户。
:::

:::keypoint{label="编码区三句话"}
- $\mathrm{DNA}$ 一级结构 $\rightarrow\mathrm{RNA}$ 一级结构（$\rightarrow$ 多肽）。
- 突变：可能失能、获能，也可能无影响。
- 可变剪接：同一基因可出不同多肽。
:::

## 三、调控序列调节真核基因表达

位于基因转录区前后并与其紧邻的 $\mathrm{DNA}$ 序列通常是基因的调控区，又称为旁侧序列（flanking sequence）。真核基因的调控序列远较原核生物复杂，这些调控序列又被称为顺式作用元件（cis-acting element），包括启动子、上游调控元件、增强子、绝缘子、加尾信号和一些细胞信号反应元件等（图13-2）。

::figure{src="/images/biochemistry/textbook/p0275_01.png" caption="图13-2　真核基因及调控序列的一般结构。自左至右：绝缘子、增强子、上游启动子元件（含 OCT-1、GC 盒）、启动子（CAAT 盒、TATA 盒），转录起始点记为 +1；结构基因由外显子（斜线框）与内含子交替；下游有修饰点 AATAAA、剪接加尾、转录终止点，远端再设绝缘子。OCT-1 为 ATTTGCAT 八聚体。" alt="真核基因一般结构：两侧绝缘子，上游增强子与启动子元件，结构基因外显子内含子交替，下游加尾信号"}

:::definition{label="旁侧序列"}
旁侧序列（flanking sequence）是位于基因转录区前后并与其紧邻的 $\mathrm{DNA}$ 序列，通常就是基因的调控区。图13-1 标为上游侧翼区、下游侧翼区。
:::

:::definition{label="顺式作用元件"}
真核基因的调控序列又称为顺式作用元件（cis-acting element），包括启动子、上游调控元件、增强子、绝缘子、加尾信号和一些细胞信号反应元件等。它们是同一条 $\mathrm{DNA}$ 分子上的序列，与第十七章将写的反式作用因子（蛋白质）成对出现。
:::

:::insight{label="图13-2 把本节后半的元件一次排开"}
从左到右可以按考试默写顺序走：绝缘子 $\rightarrow$ 增强子 $\rightarrow$ 上游启动子元件（$\mathrm{OCT}$-$1$、$\mathrm{GC}$ 盒）$\rightarrow$ 启动子（$\mathrm{CAAT}$ 盒、$\mathrm{TATA}$ 盒）$\rightarrow +1\rightarrow$ 外显子／内含子 $\rightarrow\mathrm{AATAAA}$ 加尾信号 $\rightarrow$ 转录终止点 $\rightarrow$ 下游绝缘子。增强子也可以在下游，图13-1 已经画过两侧增强子。
:::

:::pitfall{label="顺式元件不是“转录出来的 RNA”"}
启动子、增强子、绝缘子是 $\mathrm{DNA}$ 上的序列。大部分启动子本身通常不被转录。不要把顺式作用元件听成一类调节蛋白。结合在这些序列上的是反式作用因子；沉默子要结合反式作用因子才阻遏转录。
:::

:::compare{title="图13-1 和图13-2 各强调什么"}
| 图 | 强调 |
|----|------|
| 图13-1 | 断裂：外显子／内含子交替，剪接到成熟 $\mathrm{mRNA}$；起止密码子、两侧增强子、多聚 $\mathrm{A}$ 信号 |
| 图13-2 | 调控元件在一条线上的相对位置：绝缘子、增强子、$\mathrm{OCT}$-$1$、$\mathrm{GC}$／$\mathrm{CAAT}$／$\mathrm{TATA}$、$+1$、$\mathrm{AATAAA}$ |

两张图都是同一个真核基因的不同切片，不要背成两种基因。
:::

### 1. 启动子提供转录起始信号

启动子是 $\mathrm{DNA}$ 分子上与 $\mathrm{RNA}$ 聚合酶及其辅因子结合形成转录起始复合物并起始 $\mathrm{mRNA}$ 合成所必需的保守序列。大部分真核基因的启动子位于基因转录起点的上游，启动子本身通常不被转录；但有一些启动子（如编码 $\mathrm{tRNA}$ 基因的启动子）的 $\mathrm{DNA}$ 序列可以位于转录起始点的下游，这些 $\mathrm{DNA}$ 序列可以被转录。真核生物主要有 $3$ 类启动子（图13-3），分别对应于细胞内存在的三种不同的 $\mathrm{RNA}$ 聚合酶和相关蛋白质（见第十五章）。

:::definition{label="启动子"}
启动子（promoter）是 $\mathrm{DNA}$ 分子上与 $\mathrm{RNA}$ 聚合酶及其辅因子结合、形成转录起始复合物并起始 $\mathrm{mRNA}$ 合成所必需的保守序列。大部分位于转录起点上游，本身通常不被转录。
:::

:::definition{label="三类启动子对应三种 RNA 聚合酶"}
真核生物主要有 $3$ 类启动子，分别对应于细胞内三种不同的 $\mathrm{RNA}$ 聚合酶和相关蛋白质。Ⅰ类对 $\mathrm{RNA}$ 聚合酶Ⅰ，Ⅱ类对 $\mathrm{RNA}$ 聚合酶Ⅱ，Ⅲ类对 $\mathrm{RNA}$ 聚合酶Ⅲ。聚合酶细节见第十五章。
:::

:::pitfall{label="启动子“通常不被转录”不是“永远不被转录”"}
大部分在上游、本身通常不被转录。编码 $\mathrm{tRNA}$ 基因的启动子可以在转录起点下游，这些 $\mathrm{DNA}$ 序列可以被转录。图13-3 的Ⅲ类启动子把 $\mathrm{A}$ 盒、$\mathrm{B}$ 盒、$\mathrm{C}$ 盒画在转录区内部，就是这条例外的图示。
:::

::figure{src="/images/biochemistry/textbook/p0275_02.png" caption="图13-3　真核基因三类启动子。上：RNApol Ⅰ，UPE 与核心元件（Core element）组成启动子，下游为 18S、5.8S、28S rRNA。中：RNApol Ⅱ 两种，一为远侧增强子加 TATA 盒与 Inr，一为增强子加 Inr 与 DPE。下：RNApol Ⅲ，5S rRNA 为 A 盒与 C 盒，tRNA 为 A 盒与 B 盒，U6 snRNA 为 Oct、PSE 与 TATA 盒。UPE：上游启动子元件；Inr：起始元件；DPE：下游启动子元件；Oct：八聚体寡核苷酸结合序列；PSE：近侧序列元件。" alt="三类启动子：Pol Ⅰ 的 UPE 与核心元件，Pol Ⅱ 的 TATA/Inr 或 Inr/DPE，Pol Ⅲ 的 A/B/C 盒或 Oct/PSE/TATA"}

**（1）Ⅰ类启动子富含 GC 碱基对**　具有Ⅰ类启动子的基因主要是编码 $\mathrm{rRNA}$ 的基因。Ⅰ类启动子包括核心启动子（core promoter）和上游启动子元件（upstream promoter element，$\mathrm{UPE}$）两部分，能增强转录的起始。两部分序列都富含 $\mathrm{GC}$ 碱基对。

:::definition{label="Ⅰ类启动子"}
Ⅰ类启动子主要服务于编码 $\mathrm{rRNA}$ 的基因。由核心启动子（core promoter）和上游启动子元件（$\mathrm{UPE}$）两部分组成，能增强转录起始。两部分都富含 $\mathrm{GC}$ 碱基对。图13-3 中对应 $\mathrm{RNApol}$ Ⅰ，下游接 $18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}$。
:::

**（2）Ⅱ类启动子具有 TATA 盒特征结构**　具有Ⅱ类启动子的基因主要是能转录出 $\mathrm{mRNA}$ 且编码蛋白质的基因和一些 $\mathrm{snRNA}$ 基因。Ⅱ类启动子通常是由 $\mathrm{TATA}$ 盒（$\mathrm{TATA}$ box）、上游调控元件如增强子和起始元件（initiator element，$\mathrm{Inr}$）组成。$\mathrm{TATA}$ 盒的核心序列是 $\mathrm{TATA}(\mathrm{A/T})\mathrm{A}(\mathrm{A/T})$，决定着 $\mathrm{RNA}$ 合成的起始位点。有的Ⅱ类启动子在 $\mathrm{TATA}$ 盒的上游还可存在 $\mathrm{CAAT}$ 盒、$\mathrm{GC}$ 盒等特征序列，共同组成启动子。

:::definition{label="Ⅱ类启动子"}
Ⅱ类启动子主要服务于能转录出 $\mathrm{mRNA}$ 且编码蛋白质的基因，以及一些 $\mathrm{snRNA}$ 基因。通常由 $\mathrm{TATA}$ 盒、上游调控元件（如增强子）和起始元件（$\mathrm{Inr}$）组成。
:::

:::definition{label="TATA 盒"}
$\mathrm{TATA}$ 盒（$\mathrm{TATA}$ box）的核心序列是 $\mathrm{TATA}(\mathrm{A/T})\mathrm{A}(\mathrm{A/T})$，决定着 $\mathrm{RNA}$ 合成的起始位点。有的Ⅱ类启动子在其上游还有 $\mathrm{CAAT}$ 盒、$\mathrm{GC}$ 盒等特征序列，共同组成启动子。
:::

:::definition{label="起始元件 Inr"}
起始元件（initiator element，$\mathrm{Inr}$）是Ⅱ类启动子的组成元件之一。图13-3 给出两种Ⅱ类画法：$\mathrm{TATA}$ 盒 $+\mathrm{Inr}$，或 $\mathrm{Inr}+$ 下游启动子元件（$\mathrm{DPE}$）；远侧都可有增强子。
:::

**（3）Ⅲ类启动子包括 A 盒、B 盒和 C 盒**　具有Ⅲ类启动子的基因包括 $5\mathrm{S}\,\mathrm{rRNA}$、$\mathrm{tRNA}$、$\mathrm{U6}\,\mathrm{snRNA}$ 等 $\mathrm{RNA}$ 分子的编码基因。

:::definition{label="Ⅲ类启动子"}
Ⅲ类启动子包括 $\mathrm{A}$ 盒、$\mathrm{B}$ 盒和 $\mathrm{C}$ 盒。对应基因包括 $5\mathrm{S}\,\mathrm{rRNA}$、$\mathrm{tRNA}$、$\mathrm{U6}\,\mathrm{snRNA}$ 等。图13-3：$\mathrm{5S}\,\mathrm{rRNA}$ 用 $\mathrm{A}$ 盒与 $\mathrm{C}$ 盒；$\mathrm{tRNA}$ 用 $\mathrm{A}$ 盒与 $\mathrm{B}$ 盒；$\mathrm{U6}\,\mathrm{snRNA}$ 用 $\mathrm{Oct}$、$\mathrm{PSE}$ 与 $\mathrm{TATA}$ 盒。
:::

:::compare{title="三类启动子对照"}
| | Ⅰ类 | Ⅱ类 | Ⅲ类 |
|--|------|------|------|
| 主要聚合酶 | $\mathrm{RNApol}$ Ⅰ | $\mathrm{RNApol}$ Ⅱ | $\mathrm{RNApol}$ Ⅲ |
| 主要基因 | $\mathrm{rRNA}$（$18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}$） | $\mathrm{mRNA}$ 编码蛋白质的基因；一些 $\mathrm{snRNA}$ | $5\mathrm{S}\,\mathrm{rRNA}$、$\mathrm{tRNA}$、$\mathrm{U6}\,\mathrm{snRNA}$ |
| 特征元件 | 核心启动子 $+\mathrm{UPE}$，均富含 $\mathrm{GC}$ | $\mathrm{TATA}$ 盒、$\mathrm{Inr}$；可有 $\mathrm{CAAT}$ 盒、$\mathrm{GC}$ 盒、增强子；或 $\mathrm{Inr}+\mathrm{DPE}$ | $\mathrm{A}$ 盒、$\mathrm{B}$ 盒、$\mathrm{C}$ 盒；$\mathrm{U6}$ 另见 $\mathrm{Oct}$、$\mathrm{PSE}$、$\mathrm{TATA}$ 盒 |
| 相对 $+1$ 的位置 | 上游 | 通常上游 | 常在转录区内（可被转录） |

三类分别对应三种 $\mathrm{RNA}$ 聚合酶，不要把 $\mathrm{TATA}$ 盒安到Ⅰ类 $\mathrm{rRNA}$ 基因上，也不要把 $\mathrm{A}$ 盒安到编码蛋白质的Ⅱ类启动子上。
:::

:::keypoint{label="Ⅱ类启动子是编码蛋白质基因的默认图像"}
- $\mathrm{TATA}(\mathrm{A/T})\mathrm{A}(\mathrm{A/T})$ 决定起始位点。
- 上游可有 $\mathrm{CAAT}$ 盒、$\mathrm{GC}$ 盒、增强子。
- 图13-2 画的就是这一类：$\mathrm{OCT}$-$1$、$\mathrm{GC}$、$\mathrm{CAAT}$、$\mathrm{TATA}$、$+1$。
- 不是所有Ⅱ类都有 $\mathrm{TATA}$ 盒：图13-3 第二种用 $\mathrm{Inr}+\mathrm{DPE}$。
:::

:::pitfall{label="TATA 盒决定的是 RNA 合成起点，不是翻译起点"}
核心序列决定 $\mathrm{RNA}$ 合成的起始位点，即靠近 $+1$，不是起始密码子。把 $\mathrm{TATA}$ 盒听成“找 $\mathrm{ATG}$ 的盒子”，编号规则和启动子“通常不被转录”会一起乱。
:::

:::pitfall{label="5S rRNA 走Ⅲ类，18S/28S 走Ⅰ类"}
同是 $\mathrm{rRNA}$，大亚基／小亚基 $\mathrm{rRNA}$（$18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}$）用Ⅰ类启动子；$5\mathrm{S}\,\mathrm{rRNA}$ 用Ⅲ类。第二节还会写：$5\mathrm{S}\,\mathrm{rRNA}$ 基因几乎全部位于 $1\mathrm{q}42$-$43$，与 $13$、$14$、$15$、$21$、$22$ 号染色体核仁组织区的 $\mathrm{rRNA}$ 基因分家。
:::

:::insight{label="U6 snRNA 的启动子长得像Ⅱ类，户头仍是Ⅲ类"}
图13-3 把 $\mathrm{U6}\,\mathrm{snRNA}$ 画成 $\mathrm{Oct}$、$\mathrm{PSE}$、$\mathrm{TATA}$ 盒，表面上像Ⅱ类的 $\mathrm{TATA}$。教材正文把 $\mathrm{U6}\,\mathrm{snRNA}$ 明确写进Ⅲ类基因名单。看图时以基因类型归类，不要只看见 $\mathrm{TATA}$ 就改挂Ⅱ类。
:::

### 2. 增强子增强邻近基因的转录

增强子是存在于基因组中对基因表达有增强作用的 $\mathrm{DNA}$ 调控元件，决定着每一个基因在细胞内的表达水平（见第十七章）。这一调控序列能够在相对于启动子的任何方向和任何位置（上游或者下游）上发挥这种增强作用，但大部分位于上游。增强子序列距离所调控基因距离近的几十个碱基对，远的可达几千个碱基对。通常数个增强子序列形成一簇，有时增强子序列也可位于内含子之中。不同的增强子序列结合不同的调节蛋白。

:::definition{label="增强子"}
增强子（enhancer）是基因组中对基因表达有增强作用的 $\mathrm{DNA}$ 调控元件，决定每一个基因在细胞内的表达水平。可相对于启动子在任何方向、任何位置（上游或下游）起作用，但大部分位于上游。
:::

:::keypoint{label="增强子的位置和距离"}
- 方向、上下游都可以，大部分在上游。
- 近则几十个碱基对，远可达几千个碱基对。
- 常成簇；有时在内含子里。
- 不同增强子结合不同调节蛋白。
:::

:::pitfall{label="增强子不是只能写在基因前面、也不能写成“必须紧挨启动子”"}
“任何方向和任何位置”是教材原句。图13-1 在 $5'$ 和 $3'$ 两侧都画了增强子；图13-3 的Ⅱ类把增强子画在远侧双斜线之外。把它听成“启动子上游几十碱基的一个盒子”，和 $\mathrm{CAAT}$／$\mathrm{GC}$ 盒会并户。距离近的几十碱基、远的几千碱基，都是增强子的工作范围。
:::

:::insight{label="增强子可以藏在内含子里"}
有时增强子位于内含子之中。内含子被剪掉，不等于这段 $\mathrm{DNA}$ 在基因组上没有调控功能。断裂基因的“非编码”间隔，可以同时是增强子的落点。
:::

### 3. 沉默子是负调节元件

沉默子（silencer）是可抑制基因转录的特定 $\mathrm{DNA}$ 序列，当其结合一些反式作用因子时对基因的转录起阻遏作用，使基因沉默。

:::definition{label="沉默子"}
沉默子（silencer）是可抑制基因转录的特定 $\mathrm{DNA}$ 序列。结合一些反式作用因子时，对基因转录起阻遏作用，使基因沉默。它是负调节元件。
:::

:::pitfall{label="沉默子本身不是阻遏蛋白"}
它是 $\mathrm{DNA}$ 序列。起阻遏作用的条件是结合反式作用因子。不要把沉默子和绝缘子并成“都能关掉基因”：沉默子是负向调控转录；绝缘子是挡住增强子或屏蔽附近染色质环境。
:::

### 4. 绝缘子阻碍增强子的作用

绝缘子（insulator）是基因组上对转录调控起重要作用的一种元件，可以阻碍增强子对启动子的作用，或者保护基因不受附近染色质环境（如异染色质）的影响。特异的转录因子如酵母 $\mathrm{RAP1}$ 蛋白和脊椎动物细胞中 $\mathrm{CTCF}$（$\mathrm{CCCTC}$-binding factor）蛋白结合于绝缘子而发挥调控作用。绝缘子阻碍增强子对启动子的作用可能通过影响染色质的三维结构，如使 $\mathrm{DNA}$ 发生弯曲或形成环状结构。

:::definition{label="绝缘子"}
绝缘子（insulator）阻碍增强子对启动子的作用，或保护基因不受附近染色质环境（如异染色质）的影响。酵母 $\mathrm{RAP1}$、脊椎动物 $\mathrm{CTCF}$（$\mathrm{CCCTC}$-binding factor）结合于绝缘子而发挥作用。可能通过使 $\mathrm{DNA}$ 弯曲或成环等三维结构变化，挡住增强子。
:::

:::compare{title="启动子、增强子、沉默子、绝缘子"}
| 元件 | 本质 | 作用 | 位置要点 |
|------|------|------|----------|
| 启动子 | 与 $\mathrm{RNA}$ 聚合酶及辅因子结合的保守序列 | 提供转录起始信号 | 大多在 $+1$ 上游，通常不被转录；$\mathrm{tRNA}$ 等可在下游并被转录 |
| 增强子 | 增强表达的 $\mathrm{DNA}$ 调控元件 | 决定表达水平 | 任何方向、上下游；大部分在上游；近几十 $\mathrm{bp}$、远几千 $\mathrm{bp}$；可成簇、可在内含子 |
| 沉默子 | 抑制转录的特定 $\mathrm{DNA}$ 序列 | 结合反式作用因子后阻遏，使基因沉默 | 负调节元件 |
| 绝缘子 | 转录调控元件 | 阻碍增强子对启动子；或屏蔽异染色质等环境 | 图13-2 画在基因两侧；$\mathrm{RAP1}$／$\mathrm{CTCF}$ 结合 |

思考题第 $2$ 问就是这四行。增强子“开大”，沉默子“关掉”，绝缘子“隔开”，启动子“给起点”。
:::

:::cause-effect{title="绝缘子怎样挡住增强子"}
- **因** $\mathrm{RAP1}$ 或 $\mathrm{CTCF}$ 结合绝缘子，可能使 $\mathrm{DNA}$ 弯曲或成环，改变染色质三维结构
- **果** 增强子无法作用于不该管的启动子；基因也可被保护，不受附近异染色质影响
:::

:::insight{label="绝缘子解释“增强子为什么不会增强所有邻近基因”"}
增强子可在几千碱基外、方向不限。若没有边界，一条增强子会扰动整条染色体上的启动子。绝缘子把基因组隔成相对独立的调控邻域。图13-2 在结构基因两侧都放绝缘子，就是这个意思。
:::

:::pitfall{label="绝缘子不是沉默子的别名"}
沉默子：结合反式因子 $\rightarrow$ 阻遏该基因转录。绝缘子：挡住增强子，或挡住异染色质蔓延。一个是负向调节元件，一个是边界元件。把绝缘子答成“抑制转录的序列”，思考题第 $2$ 问会丢分。
:::

:::memory{label="本节必背要点"}
- [ ] 基因：编码蛋白质或 $\mathrm{RNA}$ 等产物、负载遗传信息的基本单位；含编码序列 $+$ 表达所需序列。$\mathrm{RNA}$ 病毒例外。
- [ ] 基因组：一套完整单体的遗传信息总和。人＝核染色体 $\mathrm{DNA}$（常染色体 $+$ 性染色体）$+\mathrm{mtDNA}$。
- [ ] 基因组学：结构／功能／比较三户。本节只立词。
- [ ] 基因三项功能：荷载、$4$ 种碱基排列；复制（突变是进化基础）；作为表达模板。
- [ ] 真核最突出特点：不连续＝断裂基因／割裂基因。
- [ ] 外显子出现在成熟 $\mathrm{mRNA}$；内含子对应被剪掉的间隔；内含子数 $=$ 外显子数 $-1$。
- [ ] 鸡卵清蛋白：$7.7\,\mathrm{kb}$，$8$ 外显子 $7$ 内含子；前体等长；成熟 $\mathrm{mRNA}$ $1.2\,\mathrm{kb}$。
- [ ] 原核基本无内含子；高等真核编码蛋白基因绝大部分有，组蛋白例外；$\mathrm{rRNA}$ 和一些 $\mathrm{tRNA}$ 基因有内含子。
- [ ] 外显子较保守，内含子较易变。接头共有序列：内含子 $5'$ 多 $\mathrm{GT}$，$3'$ 多 $\mathrm{AG}$。
- [ ] $5'$ 上游、$3'$ 下游；$+1$ 为转录起点；无 $0$ 号碱基。
- [ ] 编码区决定产物；突变可失能、获能或无影响；可变剪接可出不同多肽。
- [ ] 调控区＝旁侧序列＝顺式作用元件：启动子、上游元件、增强子、绝缘子、加尾信号、细胞信号反应元件。
- [ ] 启动子：与聚合酶及辅因子结合，提供起始信号。三类对应三种 $\mathrm{RNA}$ 聚合酶。
- [ ] Ⅰ类：$\mathrm{rRNA}$；核心 $+\mathrm{UPE}$，富含 $\mathrm{GC}$。Ⅱ类：$\mathrm{mRNA}$／蛋白质基因和一些 $\mathrm{snRNA}$；$\mathrm{TATA}(\mathrm{A/T})\mathrm{A}(\mathrm{A/T})$ 定起点，可有 $\mathrm{CAAT}$、$\mathrm{GC}$、$\mathrm{Inr}$、$\mathrm{DPE}$。Ⅲ类：$5\mathrm{S}\,\mathrm{rRNA}$、$\mathrm{tRNA}$、$\mathrm{U6}\,\mathrm{snRNA}$；$\mathrm{A}$／$\mathrm{B}$／$\mathrm{C}$ 盒。
- [ ] 增强子：任何方向位置，大部分上游；几十至几千 $\mathrm{bp}$；可成簇、可在内含子。
- [ ] 沉默子：负调节；结合反式因子后阻遏。
- [ ] 绝缘子：挡增强子或挡异染色质；$\mathrm{RAP1}$、$\mathrm{CTCF}$；可能弯曲／成环。
:::
