# 第四节　氧化磷酸化的影响因素

第三节把氧化磷酸化写成化学渗透：电子传递泵质子，$\mathrm{ATP}$ 合酶让质子回流生成 $\mathrm{ATP}$。本节写这台机器怎么被调速、怎么被拆开。$\mathrm{ADP}$ 是生理调速的主开关；呼吸链抑制剂、毒性气体和 $\mathrm{ATP}$ 合酶抑制剂从不同位点切断电子流或回流；解偶联剂和棕色脂肪的 $\mathrm{UCP}1$ 让质子抄近道产热；甲状腺激素把产热和 $\mathrm{Na}^{+},\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶一起开大；$\mathrm{mtDNA}$ 突变则从基因端抑制氧化磷酸化。位点仍看图10-15。

:::concept{term="先问电子还在不在传，再问质子还走不走合酶"}
抑制剂：电子传不过去，耗氧和 $\mathrm{ATP}$ 一起掉。合酶抑制剂：质子回不来，梯度堆高，电子传递随后也被拖慢。解偶联：电子照传甚至更快，质子不经合酶回去，不产 $\mathrm{ATP}$ 只产热。三套药不要写成“都是抑制呼吸链”。
:::

$\mathrm{ATP}$ 作为机体最主要的能量载体，其生成量主要取决于氧化磷酸化的速率。机体根据自身能量需求，通过调节氧化磷酸化的速率来调节 $\mathrm{ATP}$ 的合成。因此，能够影响 $\mathrm{NADH}$、$\mathrm{FADH}_2$ 的产生、影响呼吸链组分和 $\mathrm{ATP}$ 合酶功能的因素，都会影响氧化磷酸化进而影响 $\mathrm{ATP}$ 的生成。

:::definition{label="氧化磷酸化速率由能量需求调节"}
机体按自身能量需求调节氧化磷酸化速率，从而调节 $\mathrm{ATP}$ 合成量。凡影响 $\mathrm{NADH}/\mathrm{FADH}_2$ 产生、呼吸链组分或 $\mathrm{ATP}$ 合酶功能的因素，都会影响氧化磷酸化。
:::

:::insight{label="上游还原当量、中游呼吸链、下游合酶，三处都能卡"}
糖酵解和柠檬酸循环少产 $\mathrm{NADH}/\mathrm{FADH}_2$，呼吸链没有底物；复合体被药堵住，电子到不了氧；合酶或转位酶被卡，质子回流和 $\mathrm{ADP}$ 供应断掉。第四节按“能量状态—抑制剂—解偶联—$\mathrm{mtDNA}$”四层写，不要只背抑制剂名单。
:::

## 一、能量状态调节氧化磷酸化速率

机体根据能量需求调节氧化磷酸化速率，从而调节 $\mathrm{ATP}$ 的生成量。电子的氧化和 $\mathrm{ADP}$ 的磷酸化是氧化磷酸化的根本。通常线粒体中氧的消耗量是被严格调控的，其消耗量取决于 $\mathrm{ADP}$ 的含量。因此，$\mathrm{ADP}$ 是调节机体氧化磷酸化速率的主要因素，只有 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$ 充足时电子传递的速率和耗氧量才会提高。

:::definition{label="ADP 是氧化磷酸化的主要调速因素"}
线粒体耗氧量取决于 $\mathrm{ADP}$ 含量。$\mathrm{ADP}$ 是调节氧化磷酸化速率的主要因素：只有 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$ 充足时，电子传递速率和耗氧量才会提高。
:::

细胞内 $\mathrm{ADP}$ 的浓度以及 $\mathrm{ATP}/\mathrm{ADP}$ 的比值能够迅速感应机体能量状态的变化。当机体蛋白质合成等耗能代谢反应活跃时，对能量的需求大为增加，$\mathrm{ATP}$ 分解为 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$ 的速率增加，使 $\mathrm{ATP}/\mathrm{ADP}$ 的比值降低、$\mathrm{ADP}$ 的浓度增加，$\mathrm{ADP}$ 进入线粒体后迅速用于磷酸化，氧化磷酸化随之加速，合成的 $\mathrm{ATP}$ 用于满足需求，直到 $\mathrm{ATP}/\mathrm{ADP}$ 的比值回升至正常水平后，氧化磷酸化速率也随之放缓。通过这种方式使 $\mathrm{ATP}$ 的合成速率适应机体的生理需要。

另外，$\mathrm{ATP}$ 和 $\mathrm{ADP}$ 的相对浓度也同时调节糖酵解、柠檬酸循环途径，满足氧化磷酸化对 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的需求。另外 $\mathrm{ATP}$ 的浓度较高时，氧化磷酸化速率会降低，是因为 $\mathrm{ATP}$ 通过别构调节的方式抑制糖酵解、降低柠檬酸循环的速率，协调调节产能的相关途径。

:::timeline{period="ADP 把氧化磷酸化按需打开"}
- **耗能** 蛋白质合成等加速，ATP 分解为 ADP 和 Pi
- **比值下降** ATP/ADP 降低，ADP 浓度升高
- **进线粒体** ADP 经转位酶入基质，迅速磷酸化
- **加速** 电子传递和耗氧提高，ATP 合成跟上需求
- **回升** ATP/ADP 回到正常，氧化磷酸化放缓
:::

:::cause-effect{title="ATP 高为什么连上游也慢"}
- **因** $\mathrm{ATP}$ 浓度较高，别构抑制糖酵解、降低柠檬酸循环速率
- **果** $\mathrm{NADH}$、$\mathrm{FADH}_2$ 供应减少，氧化磷酸化底物不足，速率下降；产能途径被协调关掉，避免空转
:::

:::compare{title="能量状态同时拨三套旋钮"}
| 层次 | $\mathrm{ATP}/\mathrm{ADP}$ 低（$\mathrm{ADP}$ 多） | $\mathrm{ATP}/\mathrm{ADP}$ 高（$\mathrm{ATP}$ 多） |
|------|--------------------------------------------------|--------------------------------------------------|
| 氧化磷酸化本身 | $\mathrm{ADP}$、$\mathrm{P}_\mathrm{i}$ 充足，电子传递和耗氧提高 | 磷酸化底物不足，速率放缓 |
| 糖酵解 | 加快，多产丙酮酸和细胞质 $\mathrm{NADH}$ | $\mathrm{ATP}$ 别构抑制，减速 |
| 柠檬酸循环 | 加快，多产线粒体 $\mathrm{NADH}/\mathrm{FADH}_2$ | 减速，还原当量减少 |
:::

:::pitfall{label="耗氧不是由氧浓度随便决定的，教材把开关写成 ADP"}
“有氧就快呼吸”不是本节的句子。教材：线粒体耗氧量被严格调控，取决于 $\mathrm{ADP}$。氧够用时，缺的是磷酸化受体。解偶联剂会打破这层调控（电子传得很快、不生成 $\mathrm{ATP}$），那是下面另一户。
:::

:::insight{label="和第七章能量状态调节是同一把钥匙"}
第七章：$\mathrm{ATP}/\mathrm{ADP}$ 或 $\mathrm{ATP}/\mathrm{AMP}$ 同时调节磷酸果糖激酶-1、丙酮酸激酶、丙酮酸脱氢酶复合体、柠檬酸合酶、异柠檬酸脱氢酶。本节补上氧化磷酸化本身。上游少产还原当量、下游少耗还原当量，两头一起听 $\mathrm{ADP}$。
:::

:::keypoint{label="生理调速先背 ADP"}
- 主因素：$\mathrm{ADP}$（以及 $\mathrm{P}_\mathrm{i}$）。
- 感应器：$\mathrm{ADP}$ 浓度和 $\mathrm{ATP}/\mathrm{ADP}$ 比值。
- 同时调节糖酵解和柠檬酸循环，保证 $\mathrm{NADH}/\mathrm{FADH}_2$ 供需匹配。
- $\mathrm{ATP}$ 高：别构抑制上游产能途径。
:::

## 二、抑制剂阻断氧化磷酸化过程

抑制剂通过阻断电子传递链的任何环节，或者抑制 $\mathrm{ADP}$ 的磷酸化过程，都可导致 $\mathrm{ATP}$ 的合成减少，同时线粒体对氧的需求也减少，细胞的呼吸作用降低，细胞的各种生命活动都会受到影响。

:::definition{label="氧化磷酸化抑制剂"}
能阻断呼吸链电子传递或抑制 $\mathrm{ADP}$ 磷酸化的物质。后果是 $\mathrm{ATP}$ 合成减少，线粒体耗氧减少，细胞呼吸降低。
:::

:::pitfall{label="抑制剂让耗氧下降；解偶联剂让耗氧上升"}
两类都少产 $\mathrm{ATP}$，氧账相反。呼吸链或合酶被堵住，电子到不了氧，耗氧降。解偶联后电子照传到氧，梯度建不起来，耗氧往往升高、能量变热。火灾中的 $\mathrm{CO}/\mathrm{CN}^{-}$ 是抑制剂，不是解偶联剂。
:::

::figure{src="/images/biochemistry/textbook/p0237_01.png" caption="图10-15　化学渗透假说示意图及各种抑制剂对电子传递链的影响（本节按位点使用）。复合体Ⅰ：鱼藤酮、粉蝶霉素 A、异戊巴比妥，阻断铁硫中心到泛醌。复合体Ⅱ：萎锈灵、噻吩甲酰三氟丙酮。复合体Ⅲ：抗霉素 A，阻断 Cyt b 到 QN。复合体Ⅳ：CN⁻、N3⁻、CO。ATP 合酶：寡霉素、DCCD。解偶联剂：2,4-二硝基苯酚，质子不经合酶回流。" alt="呼吸链各复合体与 ATP 合酶上的抑制剂和解偶联剂作用位点"}

### 1. 呼吸链抑制剂阻断电子传递过程

呼吸链抑制剂能在特异部位阻断线粒体呼吸链中的电子传递、降低线粒体的耗氧量，阻断 $\mathrm{ATP}$ 的产生。例如，鱼藤酮（rotenone）、粉蝶霉素 $\mathrm{A}$（piericidin $\mathrm{A}$）及异戊巴比妥（amobarbital）等可抑制复合体Ⅰ，从而阻断电子从铁硫中心到泛醌的传递。萎锈灵（carboxin）是复合体Ⅱ的抑制剂。抗霉素 $\mathrm{A}$（antimycin $\mathrm{A}$）阻断电子从 $\mathrm{Cyt}\ b$ 到 $\mathrm{Q}_\mathrm{N}$ 的传递，是复合体Ⅲ的抑制剂（图10-15）。图10-15 还在复合体Ⅱ处标出噻吩甲酰三氟丙酮，与萎锈灵并列。

:::definition{label="呼吸链抑制剂"}
在特异部位阻断线粒体呼吸链电子传递的物质。电子传不过去，耗氧降低，$\mathrm{ATP}$ 产生被阻断。
:::

:::compare{title="呼吸链抑制剂按复合体"}
| 抑制剂 | 靶点 | 被切断的步骤 |
|--------|------|----------------|
| 鱼藤酮、粉蝶霉素 $\mathrm{A}$、异戊巴比妥 | 复合体Ⅰ（$\mathrm{NADH}$-泛醌还原酶） | 电子从铁硫中心到泛醌 |
| 萎锈灵；图中尚有噻吩甲酰三氟丙酮 | 复合体Ⅱ（琥珀酸-泛醌还原酶） | 琥珀酸侧电子进入 $\mathrm{Q}$ |
| 抗霉素 $\mathrm{A}$ | 复合体Ⅲ（泛醌-细胞色素 $c$ 还原酶） | 电子从 $\mathrm{Cyt}\ b$ 到 $\mathrm{Q}_\mathrm{N}$ |
:::

:::pitfall{label="抗霉素 A 切断的是 Cyt b → QN，不是“复合体Ⅲ随便哪一段”"}
教材点名 $\mathrm{Cyt}\ b$ 到 $\mathrm{Q}_\mathrm{N}$。$\mathrm{Q}$ 循环里这一笔被卡，后面 $\mathrm{Cyt}\ c$、复合体Ⅳ都拿不到电子。不要写成“抗霉素抑制细胞色素氧化酶”——那是 $\mathrm{CN}^{-}$、$\mathrm{CO}$ 的户头。
:::

:::pitfall{label="鱼藤酮卡复合体Ⅰ，琥珀酸呼吸链仍可从复合体Ⅱ进 Q"}
鱼藤酮、粉蝶霉素 $\mathrm{A}$、异戊巴比妥挡住 $\mathrm{NADH}\rightarrow\mathrm{Q}$。琥珀酸经复合体Ⅱ把电子交给 $\mathrm{Q}$，不经过复合体Ⅰ。用抑制剂定位呼吸链顺序时（第二节），阻断部位以前还原、以后氧化，靠的就是这种位点特异性。
:::

:::insight{label="第二节用抑制剂排顺序，本节用同一张图讲中毒"}
呼吸链组分排序实验之一：特异抑制剂阻断后，前面的组分处于还原态，后面处于氧化态。名单和本节相同。背位点时可以和吸收光谱实验并户，不必另造一套药名。
:::

### 2. 毒性气体阻断电子传递过程

$\mathrm{CN}^{-}$、$\mathrm{N}_3^{-}$ 能够紧密结合复合体Ⅳ中氧化型 $\mathrm{Cyt}\ a_3$，阻断电子由 $\mathrm{Cyt}\ a$ 到 $\mathrm{Cu}_\mathrm{B}$-$\mathrm{Cyt}\ a_3$ 的传递。$\mathrm{CO}$ 与还原型 $\mathrm{Cyt}\ a_3$ 结合，阻断电子传递给 $\mathrm{O}_2$。许多室内的火灾事故，由于装饰材料中的化学物质经高温处理后形成 $\mathrm{HCN}$，造成人员的 $\mathrm{CO}$、$\mathrm{CN}^{-}$ 中毒，能量代谢受阻，细胞的呼吸作用停止，直接威胁生命（图10-15）。

:::definition{label="氰化物、叠氮化物和一氧化碳"}
$\mathrm{CN}^{-}$、$\mathrm{N}_3^{-}$ 紧密结合复合体Ⅳ中氧化型 $\mathrm{Cyt}\ a_3$，阻断电子由 $\mathrm{Cyt}\ a$ 到 $\mathrm{Cu}_\mathrm{B}$-$\mathrm{Cyt}\ a_3$。$\mathrm{CO}$ 与还原型 $\mathrm{Cyt}\ a_3$ 结合，阻断电子传给 $\mathrm{O}_2$。三者都卡在呼吸链最末端。
:::

:::compare{title="Cyt a3 的氧化型和还原型不要并户"}
| 毒物 | 结合哪一种 $\mathrm{Cyt}\ a_3$ | 挡住哪一步 |
|------|------------------------------|------------|
| $\mathrm{CN}^{-}$、$\mathrm{N}_3^{-}$ | 氧化型 | $\mathrm{Cyt}\ a\rightarrow\mathrm{Cu}_\mathrm{B}$-$\mathrm{Cyt}\ a_3$ |
| $\mathrm{CO}$ | 还原型 | 电子交给 $\mathrm{O}_2$ |
:::

:::pitfall{label="CO 结合还原型 Cyt a3，CN- 结合氧化型"}
都是复合体Ⅳ、都是 $\mathrm{Cyt}\ a_3$，价态不同。写成“一氧化碳和氰化物都结合氧化型细胞色素氧化酶”，和教材对不上。火灾现场常是 $\mathrm{CO}$ 与 $\mathrm{HCN}$ 同时存在，两条末端阻断叠在一起。
:::

:::cause-effect{title="室内火灾为什么能把细胞呼吸停掉"}
- **因** 装饰材料高温分解产生 $\mathrm{HCN}$，燃烧不全产生 $\mathrm{CO}$；$\mathrm{CN}^{-}$ 卡氧化型 $\mathrm{Cyt}\ a_3$，$\mathrm{CO}$ 卡还原型 $\mathrm{Cyt}\ a_3$
- **果** 电子到不了 $\mathrm{O}_2$，$\mathrm{ATP}$ 断供，细胞呼吸停止，直接威胁生命
:::

:::note{label="末端阻断没有旁路"}
复合体Ⅰ被卡，琥珀酸还可从Ⅱ进 $\mathrm{Q}$；复合体Ⅳ被卡，两条呼吸链的电子都到不了氧。这是 $\mathrm{CN}^{-}$、$\mathrm{CO}$ 格外凶的原因。
:::

### 3. ATP 合酶抑制剂同时抑制电子传递和 ATP 的生成

$\mathrm{ATP}$ 合酶的抑制剂对电子传递及 $\mathrm{ADP}$ 磷酸化均有抑制作用。例如 $\mathrm{F}_\mathrm{o}$ 对寡霉素敏感、易与之结合，结合后失去转运质子的功能。还有一些小分子化合物，例如二环己基碳二亚胺（dicyclohexyl carbodiimide，$\mathrm{DCCD}$）也可结合 $\mathrm{F}_\mathrm{o}$，阻断 $\mathrm{H}^{+}$ 从 $\mathrm{F}_\mathrm{o}$ 质子半通道回流，抑制 $\mathrm{ATP}$ 合酶活性。由于线粒体内膜两侧质子电化学梯度增高能够影响呼吸链组分的质子泵功能，因此也会抑制电子的传递过程。另外，抑制氧化磷酸化会降低线粒体对氧的需求，氧的消耗会减少。

:::definition{label="寡霉素"}
寡霉素（oligomycin）结合 $\mathrm{F}_\mathrm{o}$（主要结合 $c$ 亚基环），使 $\mathrm{F}_\mathrm{o}$ 失去转运质子的功能，$\mathrm{ATP}$ 合酶不能让质子回流，磷酸化停止。
:::

:::definition{label="DCCD"}
二环己基碳二亚胺（dicyclohexyl carbodiimide，$\mathrm{DCCD}$）结合 $\mathrm{F}_\mathrm{o}$，阻断 $\mathrm{H}^{+}$ 从 $\mathrm{F}_\mathrm{o}$ 质子半通道回流，抑制 $\mathrm{ATP}$ 合酶活性。
:::

:::cause-effect{title="堵住合酶为什么连电子传递和耗氧也下降"}
- **因** 质子不能经 $\mathrm{F}_\mathrm{o}$ 回流，内膜两侧质子电化学梯度增高，反过来压住呼吸链组分的质子泵
- **果** 电子传递被抑制；线粒体对氧的需求降低，耗氧减少。磷酸化和氧化一起慢，不是只停磷酸化
:::

:::compare{title="三类“少产 ATP”的氧账"}
| 类型 | 电子传递 | 质子梯度 | 耗氧 | $\mathrm{ATP}$ |
|------|----------|----------|------|----------------|
| 呼吸链抑制剂（鱼藤酮、抗霉素、$\mathrm{CN}^{-}$ 等） | 在特异位点中断 | 建不起来或不能维持 | 下降 | 下降 |
| $\mathrm{ATP}$ 合酶抑制剂（寡霉素、$\mathrm{DCCD}$） | 随后被高梯度拖慢 | 堆高 | 下降 | 下降 |
| 解偶联剂（$\mathrm{DNP}$、$\mathrm{UCP}1$） | 可继续，常加快 | 被短路 | 常升高 | 下降（能量变热） |
:::

:::insight{label="Fo 既是通道也是药靶"}
第三节：$c$ 亚基环是寡霉素的主要结合位点；$a$ 亚基两条半通道让质子进出。本节：寡霉素、$\mathrm{DCCD}$ 卡的就是回流。$\mathrm{F}_\mathrm{o}$ 的名字（oligomycin-sensitive）在这里才落到实处。
:::

## 三、氧化磷酸化的解偶联促进产热

### 1. 解偶联剂阻断 ADP 的磷酸化过程

解偶联剂（uncoupler）可使氧化与磷酸化的偶联分离，电子可沿呼吸链正常传递，但建立的质子电化学梯度被破坏，不能驱动 $\mathrm{ATP}$ 合酶来合成 $\mathrm{ATP}$。如二硝基苯酚（dinitrophenol，$\mathrm{DNP}$）为脂溶性物质，在线粒体内膜中可自由移动，进入基质时释出 $\mathrm{H}^{+}$，返回细胞质侧时结合 $\mathrm{H}^{+}$，从而破坏了 $\mathrm{H}^{+}$ 的电化学梯度，无法驱动 $\mathrm{ATP}$ 的合成。

:::definition{label="解偶联剂"}
解偶联剂（uncoupler）使氧化与磷酸化的偶联分离：电子可沿呼吸链正常传递，质子电化学梯度被破坏，不能驱动 $\mathrm{ATP}$ 合酶合成 $\mathrm{ATP}$。
:::

:::definition{label="DNP"}
二硝基苯酚（dinitrophenol，$\mathrm{DNP}$）是脂溶性解偶联剂，可在线粒体内膜中自由移动：进入基质时释出 $\mathrm{H}^{+}$，返回细胞质侧时结合 $\mathrm{H}^{+}$，把膜间隙的质子抄近道送回基质，梯度消失，$\mathrm{ATP}$ 不能合成。
:::

:::timeline{period="DNP 怎么把梯度拆掉"}
- **在内膜里移动** 脂溶性，不需要蛋白通道
- **到基质** 放出 H+
- **回细胞质侧** 再结合 H+
- **结果** 质子电化学梯度被反复中和，ATP 合酶没有驱动力；电子传递仍可进行
:::

:::pitfall{label="解偶联不是抑制电子传递"}
$\mathrm{DNP}$ 不卡复合体Ⅰ–Ⅳ。图10-15 把它画在内膜上、箭头指向质子漏回，不画在某个复合体上。说“二硝基苯酚抑制呼吸链”，和化学渗透的定义对着干。
:::

:::insight{label="DNP 是化学渗透的反证"}
第三节支持化学渗透的实验之一：降低膜间隙质子浓度，$\mathrm{ATP}$ 生成减少。$\mathrm{DNP}$ 等于持续把膜间隙 $\mathrm{H}^{+}$ 运回基质。电子还在传、氧还在耗、热还在放，$\mathrm{ATP}$ 却没了——偶联靠的就是那张梯度。
:::

### 2. 解偶联蛋白促进产热

机体存在内源性解偶联剂，使 $\mathrm{H}^{+}$ 不通过 $\mathrm{ATP}$ 合酶，而是通过其他途径回流至线粒体基质，因而 $\mathrm{ATP}$ 的生成受到抑制。如人（尤其是新生儿）、哺乳类动物中存在棕色脂肪组织，该组织中含有大量的线粒体，因而细胞色素蛋白明显增多，大量血红素的强吸光能力而使其带有颜色。棕色脂肪组织的线粒体内膜中富含一种特别的蛋白质，称解偶联蛋白 $1$（uncoupling protein $1$，$\mathrm{UCP}1$）。它是由 $2$ 个 $32\,\mathrm{kD}$ 亚基组成的二聚体，在线粒体内膜上形成质子通道，内膜细胞质侧的 $\mathrm{H}^{+}$ 可经此通道返回线粒体基质，使氧化磷酸化解偶联不生成 $\mathrm{ATP}$，但质子梯度储存的能量以热能形式释放，因此棕色脂肪组织是产热御寒组织。

新生儿硬肿症是因为缺乏棕色脂肪组织，不能维持正常体温而使皮下脂肪凝固所致。现已发现在骨骼肌等组织的线粒体中存在 $\mathrm{UCP}1$ 的同源蛋白质 $\mathrm{UCP}2$、$\mathrm{UCP}3$，但无解偶联作用，它们在禁食条件下表达增加，可能有其他的功能。另外，体内游离脂肪酸也可促进 $\mathrm{H}^{+}$ 经解偶联蛋白回流至线粒体基质中而减少 $\mathrm{ATP}$ 的生成。

:::definition{label="UCP1"}
解偶联蛋白 $1$（uncoupling protein $1$，$\mathrm{UCP}1$）是棕色脂肪组织线粒体内膜上的质子通道，由 $2$ 个 $32\,\mathrm{kD}$ 亚基组成二聚体。内膜细胞质侧的 $\mathrm{H}^{+}$ 经此通道返回基质，氧化磷酸化解偶联，不生成 $\mathrm{ATP}$，梯度中的能量以热释放。
:::

:::definition{label="棕色脂肪组织"}
人（尤其新生儿）及哺乳类动物的产热御寒组织。线粒体极多，细胞色素蛋白多，血红素强吸光而呈棕色。内膜富含 $\mathrm{UCP}1$。
:::

:::definition{label="新生儿硬肿症"}
新生儿硬肿症因缺乏棕色脂肪组织，不能维持正常体温，皮下脂肪凝固所致。
:::

:::compare{title="UCP1 与同源蛋白"}
| 蛋白 | 组织印象 | 解偶联？ | 其他 |
|------|----------|----------|------|
| $\mathrm{UCP}1$ | 棕色脂肪线粒体内膜 | 有，质子通道，产热 | $2\times 32\,\mathrm{kD}$ 二聚体 |
| $\mathrm{UCP}2$、$\mathrm{UCP}3$ | 骨骼肌等线粒体 | 无解偶联作用 | 禁食时表达增加，可能有其他功能 |
:::

:::pitfall{label="UCP2、UCP3 不要写成“也是解偶联产热蛋白”"}
教材明确：同源，但无解偶联作用。禁食表达增加，功能另说。把三个 $\mathrm{UCP}$ 写成同一张棕色脂肪产热表，和本版对不上。
:::

:::insight{label="棕色来自细胞色素，不是脂肪本身染色"}
线粒体多 $\rightarrow$ 细胞色素多 $\rightarrow$ 血红素吸光 $\rightarrow$ 组织发棕。白色脂肪是储脂库（第八章动员），棕色脂肪是炉子。思考题问解偶联剂与白脂、棕脂的关系，先把这两户分开。
:::

:::keypoint{label="内源解偶联三笔"}
- $\mathrm{UCP}1$：棕色脂肪，质子通道，产热御寒。
- 新生儿缺棕色脂肪 $\rightarrow$ 硬肿症。
- 游离脂肪酸可促进 $\mathrm{H}^{+}$ 经解偶联蛋白回流，减少 $\mathrm{ATP}$。
:::

### 3. 甲状腺激素促进氧化磷酸化和产热

甲状腺激素（thyroid hormone）可诱导解偶联蛋白表达，使氧化释能和产热比率均增加，$\mathrm{ATP}$ 合成减少，导致机体耗氧量和产热同时增加。另外，甲状腺激素促进细胞膜上 $\mathrm{Na}^{+},\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶的表达，使 $\mathrm{ATP}$ 加速分解为 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$，$\mathrm{ADP}$ 浓度增加而促进氧化磷酸化。所以甲状腺功能亢进症患者基础代谢率增高。

:::definition{label="甲状腺激素对氧化磷酸化的两点作用"}
甲状腺激素（thyroid hormone）：①诱导解偶联蛋白表达，氧化释能和产热比率增加，$\mathrm{ATP}$ 合成减少，耗氧量和产热同时增加；②促进细胞膜 $\mathrm{Na}^{+},\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶表达，$\mathrm{ATP}$ 加速分解为 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$，$\mathrm{ADP}$ 增多反过来促进氧化磷酸化。甲亢患者基础代谢率增高。
:::

:::cause-effect{title="甲亢基础代谢率为什么高"}
- **因** 解偶联蛋白被诱导，更多能量走产热；$\mathrm{Na}^{+},\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶增多，$\mathrm{ATP}$ 被拆成 $\mathrm{ADP}$，氧化磷酸化被 $\mathrm{ADP}$ 加速
- **果** 耗氧和产热都增加，基础代谢率增高
:::

:::pitfall{label="甲状腺激素不是单纯的呼吸链抑制剂"}
它既开解偶联（少产 $\mathrm{ATP}$、多产热），又靠 $\mathrm{Na}^{+},\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶提高 $\mathrm{ADP}$ 来加速氧化磷酸化。耗氧升高，和 $\mathrm{CN}^{-}$ 中毒的耗氧下降相反。不要把“影响氧化磷酸化”一律理解成抑制。
:::

:::compare{title="外源 DNP、内源 UCP1、甲状腺激素"}
| | 电子传递 | 质子去向 | $\mathrm{ATP}$ | 热／耗氧 |
|--|----------|----------|-----------------|----------|
| $\mathrm{DNP}$ | 可正常进行 | 脂溶性载体来回运 $\mathrm{H}^{+}$ | 不能驱动合酶 | 梯度能变热 |
| $\mathrm{UCP}1$ | 可进行 | 蛋白通道回流 | 解偶联，不生成 $\mathrm{ATP}$ | 棕色脂肪产热御寒 |
| 甲状腺激素 | 因 $\mathrm{ADP}$ 增多而加速 | 诱导解偶联蛋白，部分走漏路 | 合成减少 | 耗氧和产热同时增加 |
:::

## 四、线粒体 DNA 突变抑制氧化磷酸化

### 1. 线粒体基因容易发生突变

线粒体 $\mathrm{DNA}$（mitochondrial $\mathrm{DNA}$，$\mathrm{mtDNA}$）呈裸露的环状双螺旋结构，缺乏蛋白质保护和损伤修复系统，容易受到损伤而发生突变，其突变率远高于核内的基因组 $\mathrm{DNA}$。

:::definition{label="mtDNA"}
线粒体 $\mathrm{DNA}$（mitochondrial $\mathrm{DNA}$，$\mathrm{mtDNA}$）为裸露的环状双螺旋，缺乏蛋白质保护和损伤修复系统，易损伤、易突变，突变率远高于核基因组 $\mathrm{DNA}$。
:::

:::keypoint{label="mtDNA 为什么脆弱"}
- 裸露环状双螺旋，没有组蛋白一类的蛋白质保护。
- 缺乏损伤修复系统。
- 线粒体本身又产活性氧（第五节），近水楼台更易受伤。
:::

### 2. mtDNA 突变直接抑制电子传递或 ADP 的磷酸化

由于线粒体基因编码的基因包括呼吸链复合体亚基以及 $\mathrm{ATP}$ 合酶，其突变直接影响 $\mathrm{ATP}$ 的生成，从而致能量代谢紊乱、引发疾病。$\mathrm{mtDNA}$ 突变造成的功能障碍易出现在耗能较多的组织，如骨骼肌、脑等。随着年龄的增长，如果 $\mathrm{mtDNA}$ 突变严重累积，可导致帕金森病、阿尔茨海默病、糖尿病等疾病的发生。

遗传性 $\mathrm{mtDNA}$ 疾病以母系遗传居多，因每个卵细胞中有几十万个 $\mathrm{mtDNA}$ 分子，每个精子中只有几百个 $\mathrm{mtDNA}$ 分子，受精卵 $\mathrm{mtDNA}$ 主要来自卵细胞，因此卵细胞 $\mathrm{mtDNA}$ 突变产生疾病的概率更高。

:::definition{label="mtDNA 突变如何抑制氧化磷酸化"}
线粒体基因编码呼吸链复合体亚基以及 $\mathrm{ATP}$ 合酶，突变可直接抑制电子传递或 $\mathrm{ADP}$ 的磷酸化，使 $\mathrm{ATP}$ 生成下降，能量代谢紊乱。
:::

:::compare{title="mtDNA 病为什么偏爱某些组织、某种遗传"}
| 问题 | 教材原句 |
|------|----------|
| 易感组织 | 耗能较多的组织，如骨骼肌、脑 |
| 随年龄累积 | 突变严重累积可导致帕金森病、阿尔茨海默病、糖尿病等 |
| 遗传方式 | 母系遗传居多 |
| 数量差 | 卵细胞几十万个 $\mathrm{mtDNA}$ 分子，精子只有几百个；受精卵 $\mathrm{mtDNA}$ 主要来自卵细胞 |
:::

:::pitfall{label="不是核基因遗传病的常染色体算法"}
受精卵 $\mathrm{mtDNA}$ 主要来自卵，精子带进的量可以忽略。不要按孟德尔核基因的分离比去推“父亲也能传一半线粒体病”。卵细胞突变的致病概率更高，是因为拷贝基数大、受精卵几乎全用卵的 $\mathrm{mtDNA}$。
:::

:::insight{label="思考题里的神经退行性变，户头在这一小节"}
章末问氧化磷酸化与神经退行性病变、肿瘤。本节给出的名单是帕金森病、阿尔茨海默病、糖尿病，场景是耗能组织加 $\mathrm{mtDNA}$ 突变累积。不要离开教材另写一篇线粒体医学综述。
:::

:::memory{label="本节必背要点"}
- [ ] 氧化磷酸化速率主要随能量需求调节；$\mathrm{ADP}$ 是主要因素，$\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$ 充足时电子传递和耗氧才提高。
- [ ] $\mathrm{ATP}/\mathrm{ADP}$ 低：氧化磷酸化加速，并带动糖酵解、柠檬酸循环多产还原当量。
- [ ] $\mathrm{ATP}$ 高：别构抑制糖酵解和柠檬酸循环，氧化磷酸化放缓。
- [ ] 抑制剂：阻断电子传递或抑制磷酸化 $\rightarrow\mathrm{ATP}$ 少、耗氧少、细胞呼吸低。
- [ ] 复合体Ⅰ：鱼藤酮、粉蝶霉素 $\mathrm{A}$、异戊巴比妥；铁硫中心 $\rightarrow\mathrm{Q}$。
- [ ] 复合体Ⅱ：萎锈灵（图中还有噻吩甲酰三氟丙酮）。
- [ ] 复合体Ⅲ：抗霉素 $\mathrm{A}$；$\mathrm{Cyt}\ b\rightarrow\mathrm{Q}_\mathrm{N}$。
- [ ] 复合体Ⅳ：$\mathrm{CN}^{-}$、$\mathrm{N}_3^{-}$ 结合氧化型 $\mathrm{Cyt}\ a_3$；$\mathrm{CO}$ 结合还原型 $\mathrm{Cyt}\ a_3$。火灾可同时 $\mathrm{CO}+\mathrm{HCN}$。
- [ ] 合酶抑制剂：寡霉素、$\mathrm{DCCD}$ 结合 $\mathrm{F}_\mathrm{o}$，质子不能回流；梯度增高反过来抑制电子传递，耗氧下降。
- [ ] 解偶联剂：电子照传，梯度被破坏，不驱动合酶。$\mathrm{DNP}$ 脂溶性，基质侧放 $\mathrm{H}^{+}$、胞质侧绑 $\mathrm{H}^{+}$。
- [ ] $\mathrm{UCP}1$：$2\times 32\,\mathrm{kD}$ 二聚体，棕色脂肪质子通道，产热御寒。新生儿缺棕色脂肪 $\rightarrow$ 硬肿症。
- [ ] $\mathrm{UCP}2$、$\mathrm{UCP}3$：骨骼肌等，无解偶联作用，禁食表达增加。游离脂肪酸可促质子经解偶联蛋白回流。
- [ ] 甲状腺激素：诱导解偶联蛋白 $+$ 诱导 $\mathrm{Na}^{+},\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶；甲亢基础代谢率高。
- [ ] $\mathrm{mtDNA}$：裸露环状，缺保护与修复，突变率高；编码呼吸链亚基和 $\mathrm{ATP}$ 合酶。
- [ ] $\mathrm{mtDNA}$ 病：骨骼肌、脑；可累积为帕金森病、阿尔茨海默病、糖尿病；母系遗传（卵几十万 vs 精子几百）。
:::
