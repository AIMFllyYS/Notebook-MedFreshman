# 第五节　基因表达分析技术

第四节已经把蛋白质怎样互相抓住、怎样抓住 $\mathrm{DNA}$、染色质怎样在三维里接触写成相互作用实验。本节问基因表达本身：先查 $\mathrm{NCBI}$、$\mathrm{EBI}$、$\mathrm{DDBJ}$、$\mathrm{CNGBdb}$ 等库，再用实时 $\mathrm{PCR}$ 和芯片去验证。编码区靠 $\mathrm{cDNA}$ 文库和剪接分析；转录起点靠克隆测序和 $5'$-$\mathrm{RACE}$；启动子靠克隆再加核酸–蛋白质相互作用（含足迹法）。拷贝数和分子标记给出时空定位；转录物组和蛋白质组把账做成全景。章末收全章小结和思考题。

:::concept{term="先查库，再验证；先定编码区、TSS 和启动子，再定量、定位，最后才上组学"}
看见“基因表达分析”，不要一上来默写 $\mathrm{Hi}$-$\mathrm{C}$。三维构象已在第四节。本节户头是动态的表达：何时、何组织、多少。本版的一般策略是先查表18-1 的数据库，再用实时 $\mathrm{PCR}$、基因芯片等实验验证。功能区域三条线——编码区、转录起点、启动子——和产物的拷贝数、细胞定位是核心；转录物组、蛋白质组是整体谱。
:::

生物体内的基因表达呈动态变化，即在不同的时间、发育阶段、组织或环境刺激等状态下，基因表达时刻发生着变化。分析基因表达及其差异，对于加深理解现代医学的基本理论和研究现状、深入认识生命运作过程与疾病的发生和发展机制、理解和应用基于分子生物学发展起来的诊断治疗策略和药物研发等都具有极为重要的意义。例如，通过分析发育过程的基因表达并比较不同阶段或时间点的差异，可以了解启动发育和发育表型等的关键决定基因，为衰老、组织损伤修复和再生医学等提供可干预的分子靶点；通过分析疾病发生和发展过程的基因表达及其差异，可以了解疾病的分子机制，为诊断与治疗提供生物标记物和分子靶点；通过分析药物治疗前后的基因表达及其差异，可以了解机体表型变化的分子感知与反应过程，为药物研发奠定基础。

:::definition{label="基因表达的动态变化"}
在不同时间、发育阶段、组织或环境刺激等状态下，基因表达时刻发生着变化。分析的是这种动态及其差异，不是基因组里「有没有这个基因」。
:::

:::definition{label="分析表达差异的三条例子"}
①发育过程不同阶段或时间点：找启动发育和发育表型的关键决定基因，为衰老、损伤修复和再生医学提供可干预靶点。②疾病发生发展：了解分子机制，提供诊断治疗的生物标记物和分子靶点。③药物治疗前后：了解表型变化的分子感知与反应，为药物研发奠基。
:::

:::insight{label="第四节抓的是「谁和谁绑」，本节抓的是「绑上之后基因有没有工作、工作了多少」"}
$\mathrm{ChIP}$ 能告诉你转录因子当时坐在哪；$3\mathrm{C}$ 能告诉你增强子和启动子在空间上挨不挨着。坐着、挨着，不等于已经转录出 $\mathrm{mRNA}$、不等于蛋白质已经出现在这个组织。表达分析从数据库里的表达谱开始，再回到试管和切片。
:::

:::pitfall{label="不要把染色质构象捕获再写一遍当本节开头"}
$3\mathrm{C}$、$4\mathrm{C}$、$5\mathrm{C}$、$\mathrm{Hi}$-$\mathrm{C}$、$\mathrm{ChIA}$-$\mathrm{PET}$ 和图18-8 已在第四节。本版把它们放在「解析基因表达时空特异性机制」的语境里，方法学仍是互作。本节从查库开始。
:::

## 一、生物信息学技术挖掘数据库信息已成为全面分析基因表达的第一步

随着人类基因组计划和多种模式生物基因组测序的完成，后基因组时代对基因组注释的深入，生物信息学技术的发展，深度学习和人工智能软件的开发应用和互联网的普及，基因表达研究已从分析单个基因转变为基因表达谱（gene expression profile）的差异分析，即基因表达模式的解析。其一般策略首先是查询各大数据库（表18-1），进而实验验证基因表达，验证常用的技术有实时 $\mathrm{PCR}$、基因芯片等。

:::definition{label="基因表达谱"}
基因表达谱（gene expression profile）：从分析单个基因转向差异分析之后的对象，也就是基因表达模式。谱里是「哪些基因、在何种状态下、相对多少」，不是一条 $\mathrm{Southern}$ 区带。
:::

:::definition{label="本版的一般策略"}
首先查询各大数据库（表18-1），进而实验验证基因表达。验证常用实时 $\mathrm{PCR}$、基因芯片等。顺序不能倒：先有库里的线索，再用第二节、第一节的实验去核实。
:::

:::pitfall{label="实时 PCR 和芯片是验证手段，不是「不用再查库」"}
第二节已经把实时 $\mathrm{PCR}$ 写成定量核酸；第一节把基因芯片写成规模化杂交。本节把它们放在「查完库之后的验证」。没有数据库线索，验证没有对象；只有芯片热图、没有实验验证，本版不把它当成完整策略。
:::

特定基因的表达分析，可以利用同源检索，在各大生物信息数据库中查询分析。最简单就是利用局部序列比对检索基本工具（basic local alignment search tool，$\mathrm{BLAST}$），获得该基因的染色体定位、序列及多态性、各种功能区域、表达产物等的各方面参考信息，如推断基因所表达的非编码 $\mathrm{RNA}$ 和编码区，并预测编码区所编码多肽链的等电点、跨膜区、信号肽序列、空间结构、相互作用等基本理化性质与生物学功能。并可以追踪不同细胞、组织或状态下该基因表达的信息，进而实验研究该基因在研究者所设定条件下的基因表达情况和功能分析，从而进一步注释该基因。

:::definition{label="BLAST"}
局部序列比对检索基本工具（basic local alignment search tool，$\mathrm{BLAST}$）：特定基因表达分析里最简单的同源检索。用来拿染色体定位、序列及多态性、功能区域、表达产物等参考信息。
:::

:::definition{label="BLAST 之后能推断和预测什么"}
推断：基因所表达的非编码 $\mathrm{RNA}$ 和编码区。预测：编码区所编码多肽链的等电点、跨膜区、信号肽序列、空间结构、相互作用等基本理化性质与生物学功能。再追踪不同细胞、组织或状态下的表达信息，然后做设定条件下的实验，进一步注释该基因。
:::

:::pitfall{label="BLAST 给出的是参考信息和预测，不是实验验证本身"}
等电点、跨膜区、信号肽可以预测；研究者自己设定条件下的表达，仍要回到实时 $\mathrm{PCR}$、芯片或后文的组学实验。把 $\mathrm{BLAST}$ 答成「已经测完表达」，策略的第二步就消失了。
:::

直接或者间接分析某个生物个体细胞或组织等的基因表达谱及其各自丰度，也首先是查询相关数据库，以获得特定状态下的细胞或组织的基因表达模式。例如，美国国立生物技术信息中心（$\mathrm{NCBI}$）创建并维护的基因表达综合数据库（gene expression omnibus data base，$\mathrm{GEO}$）（表18-1），该数据库收录的基因表达信息，截至 $2023$ 年 $8$ 月，已包括通过高通量测序和芯片等 $10$ 余种技术平台，所获得的来自人类和小鼠等 $16$ 种模式生物，超过 $730$ 万个各种状态下生物样品的基因表达谱、基因组变异谱、甲基化谱、蛋白质谱或非编码 $\mathrm{RNA}$ 谱等 $23$ 万个系列的信息。从数据库所获得的基因表达信息，如是研究者所设定条件下的基因表达的原始数据，可进一步利用各种生物信息学工具深入挖掘，然后实验验证；如没有类似研究条件下基因表达数据，可选择 $\mathrm{GEO}$ 中所列的各种研究技术或创建其他方法，开展实验研究，并通过生物信息学分析基因表达模式。

:::definition{label="GEO"}
基因表达综合数据库（gene expression omnibus data base，$\mathrm{GEO}$）：$\mathrm{NCBI}$ 创建并维护。截至 $2023$ 年 $8$ 月：高通量测序和芯片等 $10$ 余种技术平台；人类和小鼠等 $16$ 种模式生物；超过 $730$ 万个样品；基因表达谱、基因组变异谱、甲基化谱、蛋白质谱或非编码 $\mathrm{RNA}$ 谱等 $23$ 万个系列。
:::

:::definition{label="从 GEO 出来的两条路"}
①库里已有研究者设定条件下的原始数据：生物信息学深入挖掘，然后实验验证。②没有类似条件的数据：选用 $\mathrm{GEO}$ 中所列技术或创建其他方法，开展实验，再做生物信息学分析。
:::

:::insight{label="GEO 里不只有 mRNA 芯片"}
教材列举的谱包括表达谱、基因组变异谱、甲基化谱、蛋白质谱或非编码 $\mathrm{RNA}$ 谱。检索「基因表达」时，不要默认只有一条 $\mathrm{RNA}$-seq 跑道。
:::

三个数字不要对调。平台是「$10$ 余种」，不是「只有芯片」或「只有测序」。

## 二、鉴定基因的功能区域可以了解基因表达及其调控

基因上的不同序列及其修饰状态，行使着表达产物和调控表达等不同功能。明确基因转录区是解析基因表达的基础；鉴定顺式作用元件（cis-acting element）和探测基因的空间位置是了解基因表达的关键；分析表达产物可以了解基因表达的时空特性；比较基因表达差异可以洞悉机体感知态势和应对的分子过程。这些都有助于揭示基因功能及功能改变的原因。这里主要简介鉴定基因的编码区、转录起点和启动子的实验技术，其中一些技术也适用于高通量，甚至整体性的基因表达谱分析。

:::definition{label="功能区域四句话"}
转录区：解析表达的基础。顺式作用元件和基因的空间位置：了解表达的关键。表达产物：时空特性。表达差异：机体感知与应对。四句都指向「基因功能及功能改变的原因」。
:::

:::definition{label="顺式作用元件"}
顺式作用元件（cis-acting element）：鉴定它、并探测基因的空间位置，是了解基因表达的关键。启动子分析会回到元件上有没有反式作用因子结合位点。
:::

:::keypoint{label="本部分三条实验线"}
- 编码区：$\mathrm{cDNA}$ 文库、$\mathrm{RACE}$、$\mathrm{RNA}$ 剪接分析。
- 转录起点（$\mathrm{TSS}$）：$\mathrm{cDNA}$ 克隆直接测序；$5'$-$\mathrm{RACE}$；规模化则 $\mathrm{SAGE}$／$\mathrm{CAGE}$。
- 启动子：$\mathrm{PCR}$ 克隆测序；核酸–蛋白质相互作用（$\mathrm{EMSA}$、$\mathrm{ChIP}$、足迹法）。

高通量谱分析可以借用其中若干技术，但户头仍是这三段序列。
:::

### （一）cDNA 文库和 RNA 剪接分析确定基因编码区

基因编码区（coding region）是成熟 $\mathrm{mRNA}$ 序列的一部分，因此对 $\mathrm{cDNA}$ 进行克隆测序或构建 $\mathrm{cDNA}$ 文库是最早分析基因编码区的方法。由可变剪接产生的同一基因的不同编码区，可通过基因芯片等高通量分析确定。

:::definition{label="基因编码区"}
基因编码区（coding region）：成熟 $\mathrm{mRNA}$ 序列的一部分。最早的分析方法是对 $\mathrm{cDNA}$ 克隆测序或构建 $\mathrm{cDNA}$ 文库。可变剪接造成的不同编码区，可用基因芯片等高通量分析确定。
:::

:::pitfall{label="编码区在成熟 mRNA 上，不是把基因组从第一个外显子抄到最后一个内含子"}
分析编码区走 $\mathrm{cDNA}$，是因为内含子已经在 $\mathrm{RNA}$ 剪接里去掉。直接对基因组测序能看到外显子－内含子结构，但「成熟 $\mathrm{mRNA}$ 上的编码区」仍要以 $\mathrm{cDNA}$ 为准。
:::

**1. $\mathrm{cDNA}$ 文库分析基因编码区**　以全长 $\mathrm{cDNA}$ 文库作为编码区的模板，利用 $\mathrm{PCR}$ 法即可将目的基因的编码区扩增出来。一是按基因的保守序列合成 $\mathrm{PCR}$ 引物，即可从 $\mathrm{cDNA}$ 文库中克隆未知基因的编码区；二是通过分析 $\mathrm{PCR}$ 产物来观察 $\mathrm{mRNA}$ 的不同拼接方式；三是可以设计核酸探针，从 $\mathrm{cDNA}$ 文库中筛选出含特定编码区的阳性克隆，测序获得编码区信息。

:::definition{label="cDNA 文库三条用法"}
全长 $\mathrm{cDNA}$ 文库当模板：①按保守序列合成引物，$\mathrm{PCR}$ 克隆未知基因编码区；②看 $\mathrm{PCR}$ 产物，观察 $\mathrm{mRNA}$ 不同拼接方式；③核酸探针筛阳性克隆，测序得编码区。
:::

**2. $\mathrm{RACE}$ 钓取未知基因编码区**　$\mathrm{cDNA}$ 末端快速扩增法（rapid amplification of cDNA end，$\mathrm{RACE}$）（包括 $5'$-$\mathrm{RACE}$ 和 $3'$-$\mathrm{RACE}$）是高效钓取未知基因编码区的一种方法。该方法可以利用 $\mathrm{mRNA}$ 内很短的一段序列，通过逆转录 $\mathrm{PCR}$ 扩增与其互补的 $\mathrm{cDNA}$ 末端序列。以此为线索，经过多次扩增及测序分析，最终可以获得该 $\mathrm{mRNA}$ 的全部编码区。

:::definition{label="RACE"}
$\mathrm{cDNA}$ 末端快速扩增法（rapid amplification of cDNA end，$\mathrm{RACE}$），包括 $5'$-$\mathrm{RACE}$ 和 $3'$-$\mathrm{RACE}$。用 $\mathrm{mRNA}$ 内很短的一段序列，经逆转录 $\mathrm{PCR}$ 扩增互补的 $\mathrm{cDNA}$ 末端；多次扩增及测序，得到该 $\mathrm{mRNA}$ 的全部编码区。
:::

:::pitfall{label="RACE 在编码区这一小节是「钓末端补全长」，鉴定 TSS 时 5′-RACE 再出场"}
这里 $5'$ 和 $3'$ 两种 $\mathrm{RACE}$ 都为了补全编码区。下一小节鉴定转录起点，专门用 $5'$-$\mathrm{RACE}$ 看 $5'$ 末端。同一技术，问题从「编码区还缺哪一端」换成「转录从哪一个核苷酸开始」。
:::

**3. $\mathrm{RNA}$ 剪接分析确定基因编码区**　$\mathrm{RNA}$ 剪接分析的方法主要有 $3$ 种：①基于 $\mathrm{DNA}$ 芯片的分析法：常用的是代表外显子的 $\mathrm{DNA}$ 芯片或外显子／外显子交界的 $\mathrm{DNA}$ 片段芯片。②交联免疫沉淀法：用紫外线将蛋白质和 $\mathrm{RNA}$ 交联在一起，然后用特异性抗体将蛋白质-$\mathrm{RNA}$ 复合物沉淀，通过分析蛋白质结合的 $\mathrm{RNA}$ 序列，便可确定 $\mathrm{RNA}$ 的剪接位点。③体外报告基因（reporter gene）测定法：即将报告基因克隆到载体中，使 $\mathrm{RNA}$ 剪接作为活化报告基因的促进因素，通过分析报告基因的表达水平，即可推测克隆片段的 $\mathrm{RNA}$ 剪接情况，以此为线索便可分析基因的编码区。报告基因又称「报道基因」，在细胞中表达后产生容易被检测的荧光等信号，用以指示与其融合的调控序列或元件（如启动子）的活性。常用的报告基因有荧光素酶基因、绿色荧光蛋白基因、$\beta$-葡萄糖苷酶基因等。

:::definition{label="RNA 剪接分析的三种方法"}
①外显子芯片或外显子／外显子交界芯片。②交联免疫沉淀：紫外线交联蛋白质-$\mathrm{RNA}$，抗体沉淀，读结合的 $\mathrm{RNA}$ 序列以定剪接位点。③体外报告基因：剪接作为活化报告基因的促进因素，看报告基因表达水平反推剪接。
:::

:::definition{label="报告基因"}
报告基因（reporter gene）又称报道基因：在细胞中表达后产生容易被检测的荧光等信号，指示与其融合的调控序列或元件（如启动子）的活性。常用：荧光素酶基因、绿色荧光蛋白基因、$\beta$-葡萄糖苷酶基因。
:::

:::insight{label="剪接分析里的交联免疫沉淀认的是 RNA，不是 ChIP 那条 DNA"}
紫外线交联的是蛋白质和 $\mathrm{RNA}$，抗体沉淀后分析的是 $\mathrm{RNA}$ 序列，目标是剪接位点。第四节 $\mathrm{ChIP}$ 交联的是蛋白质和 $\mathrm{DNA}$。都叫免疫沉淀，核酸种类不同。
:::

:::compare{title="三种剪接分析法各自看见什么"}
| | 芯片 | 交联免疫沉淀 | 报告基因 |
|--|------|--------------|----------|
| 材料 | 外显子或外显子交界的 $\mathrm{DNA}$ 片段 | 蛋白质-$\mathrm{RNA}$ 复合物 | 把剪接写成报告基因能否激活 |
| 读出 | 杂交信号 | 蛋白质结合的 $\mathrm{RNA}$ 序列 | 荧光等报告信号的强弱 |
| 直接回答 | 哪些外显子／交界被用到 | 剪接位点在哪 | 这段序列的剪接是否发生、是否有效 |

三条路都为了确定编码区，不是三种 $\mathrm{ChIP}$。
:::

:::pitfall{label="报告基因不限于剪接，启动子分析也会用到「指示调控序列活性」"}
定义写明：指示与其融合的调控序列或元件（如启动子）的活性。剪接小节里它被当成剪接的读出；后文启动子克隆测序是另一条实验。不要把报告基因只记成「绿色荧光蛋白本身」。
:::

### （二）直接克隆测序和 5′-RACE 确定转录起点

$\mathrm{RNA}$ 聚合酶通过直接或间接识别和结合启动子而在基因的转录起点（transcription start site，$\mathrm{TSS}$）启动转录。本部分主要介绍分析真核生物 $\mathrm{TSS}$ 的技术。

:::definition{label="转录起点"}
转录起点（transcription start site，$\mathrm{TSS}$）：$\mathrm{RNA}$ 聚合酶直接或间接识别、结合启动子之后，在基因上启动转录的位置。本部分技术针对真核生物 $\mathrm{TSS}$。
:::

:::insight{label="TSS 不是启动子，也不是起始密码子"}
启动子是被聚合酶（或转录因子）识别结合的调控序列；$\mathrm{TSS}$ 是 $\mathrm{RNA}$ 实际开始合成的那个核苷酸。起始密码子在成熟 $\mathrm{mRNA}$ 编码区里，还要再往 $3'$ 走一段 $5'$-$\mathrm{UTR}$。三个位置不要画成同一个碱基。
:::

**1. $\mathrm{cDNA}$ 克隆直接测序法鉴定 $\mathrm{TSS}$**　最早对 $\mathrm{TSS}$ 的鉴定方法就是直接对 $\mathrm{cDNA}$ 克隆进行测序分析，所得的 $5'$－末端序列即可确定基因的 $\mathrm{TSS}$ 序列。该方法比较简单，尤其适于对特定基因 $\mathrm{TSS}$ 的分析。但该方法依赖于逆转录合成全长 $\mathrm{cDNA}$。

:::definition{label="cDNA 克隆直接测序鉴定 TSS"}
对 $\mathrm{cDNA}$ 克隆测序，读出的 $5'$－末端序列即 $\mathrm{TSS}$。简单，适于特定基因。前提：逆转录合成了全长 $\mathrm{cDNA}$。逆转录停在中途，读到的「$5'$ 端」就不是真正的起点。
:::

:::pitfall{label="全长 cDNA 是这张方法的命门"}
$\mathrm{mRNA}$ 的 $5'$ 端有帽、有二级结构，逆转录酶容易掉下来。没有全长，$\mathrm{cDNA}$ 的 $5'$ 端只是酶停住的地方。所以本版紧接着给出 $5'$-$\mathrm{RACE}$，专门从低丰度转录本里扩 $5'$ 末端。
:::

**2. $5'$-$\mathrm{RACE}$ 鉴定 $\mathrm{TSS}$**　$5'$-$\mathrm{RACE}$ 是一种基于 $\mathrm{PCR}$、从低丰度的基因转录本中快速扩增 $\mathrm{cDNA}$ 的 $5'$－末端的有效方法。该技术鉴定 $\mathrm{TSS}$ 的流程如图18-9。图中：$\mathrm{CIAP}$ 为碱性磷酸酶；$\mathrm{TAP}$ 为烟草酸焦磷酸酶；$\mathrm{GSP}$ 为基因特异性引物。

::figure{src="/images/biochemistry/textbook/p0382_02.png" caption="图18-9　5′-RACE 鉴定 TSS 的原理。RNA 先用 CIAP（碱性磷酸酶）处理：全长 mRNA 带 5′ m7G 帽得以保留，降解的 mRNA、rRNA、tRNA 和 DNA 被去掉 5′ 磷酸。再用 TAP（烟草酸焦磷酸酶）去帽，全长 mRNA 露出 5′p。连接 5′-RACE 接头后，以随机 9 核苷酸引物逆转录，再用 5′-RACE 外侧／内侧引物与基因特异性引物 GSP1、GSP2 做巢式 PCR。" alt="5′-RACE：CIAP 去磷酸、TAP 去帽、接头连接、逆转录、巢式 PCR"}

:::definition{label="5′-RACE"}
基于 $\mathrm{PCR}$、从低丰度基因转录本中快速扩增 $\mathrm{cDNA}$ $5'$－末端的方法。用来鉴定 $\mathrm{TSS}$。图18-9 的关键试剂：$\mathrm{CIAP}$（碱性磷酸酶）、$\mathrm{TAP}$（烟草酸焦磷酸酶）、$\mathrm{GSP}$（基因特异性引物）。
:::

:::definition{label="图18-9 从全长 mRNA 里只留下能接接头的 5′ 端"}
全长 $\mathrm{mRNA}$ 的 $5'$ 端是 $\mathrm{m}^{7}\mathrm{G}$ 帽（图上写作 $5'\ \mathrm{m}^{7}\mathrm{G}$-$\mathrm{p}$-$\mathrm{p}$-$\mathrm{p}$）。$\mathrm{CIAP}$ 处理时，降解的 $\mathrm{mRNA}$、$\mathrm{rRNA}$、$\mathrm{tRNA}$ 和 $\mathrm{DNA}$ 因没有帽、暴露着 $5'$ 磷酸而被去磷酸，随后接不上接头；全长带帽分子在这一步被留下。$\mathrm{TAP}$ 去帽后全长 $\mathrm{mRNA}$ 露出 $5'\mathrm{p}$，才能连上 $5'$-$\mathrm{RACE}$ 接头。
:::

:::definition{label="接头之后是随机引物逆转录加巢式 PCR"}
连接接头后，用随机 $9$ 核苷酸引物逆转录成 $\mathrm{cDNA}$。扩增走巢式 $\mathrm{PCR}$：$5'$-$\mathrm{RACE}$ 外侧引物配 $\mathrm{GSP1}$，内侧引物配 $\mathrm{GSP2}$。$\mathrm{GSP}$ 认的是已知基因内部序列，接头引物认的是人为加上的 $5'$ 端，两边夹住才能把真正的 $5'$ 末端扩出来。
:::

:::insight{label="CIAP 和 TAP 的顺序不能换"}
先 $\mathrm{CIAP}$：把「不是全长带帽」的 $5'$ 磷酸拆掉，避免它们后来也接上接头。再 $\mathrm{TAP}$：只给全长 $\mathrm{mRNA}$ 去帽、露出一个新的 $5'$ 磷酸。顺序反了，降解片段也会进入接头连接，扩出来的就不是 $\mathrm{TSS}$。
:::

:::pitfall{label="GSP 是基因特异性引物，不是随机 9 核苷酸引物"}
逆转录用的是随机 $9$ 核苷酸引物，为的是把各种 $\mathrm{RNA}$ 都抄成 $\mathrm{cDNA}$。巢式 $\mathrm{PCR}$ 的 $\mathrm{GSP1}/\mathrm{GSP2}$ 才对着目的基因。两个「引物」不要写成同一条寡核苷酸。
:::

:::compare{title="cDNA 直接测序 vs 5′-RACE 鉴定 TSS"}
| | $\mathrm{cDNA}$ 克隆直接测序 | $5'$-$\mathrm{RACE}$ |
|--|---------------------------|---------------------|
| 读什么 | 已有克隆的 $5'$－末端 | 专门扩出来的 $5'$－末端 |
| 对丰度 | 依赖已经拿到的全长克隆 | 教材强调适于低丰度转录本 |
| 关键前提 | 逆转录必须做出全长 $\mathrm{cDNA}$ | $\mathrm{CIAP}$／$\mathrm{TAP}$ 把全长带帽 $\mathrm{mRNA}$ 和降解片段分开，再接头 $+$ 巢式 $\mathrm{PCR}$ |
| 产物 | 一条克隆的序列 | $\mathrm{PCR}$ 片段，测序后定 $\mathrm{TSS}$ |

都看 $5'$ 端；$\mathrm{RACE}$ 多的是「把真正带帽的 $5'$ 选出来再扩」。
:::

**3. $\mathrm{SAGE}$ 规模化地检测基因表达种类及其丰度**　在 $5'$-$\mathrm{RACE}$ 的基础上，建立了基因表达系列分析（serial analysis of gene expression，$\mathrm{SAGE}$）。如 $5'$-$\mathrm{SAGE}$ 技术就是通过在 $\mathrm{mRNA}$ 的 $5'$－末端引入特殊的Ⅱ型限制性核酸内切酶识别位点，可将细胞表达的所有 $\mathrm{mRNA}$ 的 $5'$－末端短片段作为表达序列标签串联在一起，测序即可确定细胞内的所有转录物，包括低丰度转录物；通过测得标签数目，还可获得每种转录物的相对含量。类似的技术有帽分析基因表达（cap analysis gene expression，$\mathrm{CAGE}$）。

:::definition{label="SAGE"}
基因表达系列分析（serial analysis of gene expression，$\mathrm{SAGE}$）：在 $5'$-$\mathrm{RACE}$ 基础上建立，规模化检测基因表达种类及其丰度。
:::

:::definition{label="5′-SAGE"}
在 $\mathrm{mRNA}$ 的 $5'$－末端引入特殊的Ⅱ型限制性核酸内切酶识别位点，把所有 $\mathrm{mRNA}$ 的 $5'$－末端短片段当作表达序列标签串联，测序确定细胞内所有转录物（含低丰度）；标签数目代表每种转录物的相对含量。
:::

:::definition{label="CAGE"}
帽分析基因表达（cap analysis gene expression，$\mathrm{CAGE}$）：与 $5'$-$\mathrm{SAGE}$ 类似、对着帽结构做的规模化 $\mathrm{TSS}$／表达分析。
:::

:::insight{label="SAGE 把「一条 5′ 末端」变成「一串标签」"}
$5'$-$\mathrm{RACE}$ 一次主要对着一个基因。$5'$-$\mathrm{SAGE}$ 把每个转录本的 $5'$ 短片段当成标签，串联后一次测序，种类和丰度一起出。后文拷贝数分析会再次点名 $\mathrm{SAGE}$。
:::

:::pitfall{label="Ⅱ型限制酶在这里是切出短标签，不是基因组作图"}
识别位点被引进 $5'$ 端，为的是切下可串联的短片段。不要把这一句答成第一节限制酶消化后做 Southern。
:::

### （三）启动子克隆和核酸-蛋白质相互作用分析确定启动子

分析启动子对于研究基因表达调控具有重要意义。根据启动子序列特征，生物信息学可以直接提示各类启动子结构。实验分析启动子可通过启动子克隆，以及基于启动子与反式作用因子结合的特性，利用核酸-蛋白质相互作用研究技术进行分析。

:::definition{label="启动子实验的两条路"}
①按序列特征做生物信息学提示，再用 $\mathrm{PCR}$ 克隆、测序看结构。②利用启动子与反式作用因子结合，走核酸–蛋白质相互作用（第四节的 $\mathrm{EMSA}$、$\mathrm{ChIP}$，以及本小节的足迹法）。
:::

**1. $\mathrm{PCR}$ 结合测序技术分析启动子结构**　该方法最为简单和直接，即根据基因的启动子序列，设计一对引物，然后以 $\mathrm{PCR}$ 扩增启动子，经克隆测序分析启动子序列。

:::definition{label="PCR 克隆测序看启动子"}
按已知或预测的启动子序列设计一对引物，$\mathrm{PCR}$ 扩增，克隆测序。最简单、最直接，问的是这段调控 $\mathrm{DNA}$ 的一级结构。
:::

**2. 核酸-蛋白质相互作用研究技术分析启动子**　$\mathrm{EMSA}$ 和 $\mathrm{ChIP}$ 等核酸-蛋白质相互作用技术就能确定基因序列中含有的反式作用因子结合位点。这些结合位点的序列分析，早期常用 $\mathrm{DNA}$ 足迹法（footprinting），现在主要通过 $\mathrm{DNA}$ 测序确定。足迹法用于分析启动子中潜在的调节蛋白结合位点，基本原理就是利用 $\mathrm{DNA}$ 电泳条带连续性中断的图谱特点，判断与分析蛋白质结合的 $\mathrm{DNA}$ 区域及其序列。足迹法需要对被检 $\mathrm{DNA}$ 进行切割，根据切割 $\mathrm{DNA}$ 试剂的不同，足迹法可分为酶足迹法和化学足迹法。酶足迹法基本原理如图18-10。

::figure{src="/images/biochemistry/textbook/p0383_01.png" caption="图18-10　DNase I 足迹法的原理。双链 DNA 先做单链末端标记；加入 DNA 结合蛋白后，用 DNase I 切割并控制反应时间。未结合区被随机切开，得到长短不同片段；蛋白质结合区不被酶切。变性凝胶电泳：无蛋白泳道是连续梯带，蛋白-DNA 泳道出现空白区（蛋白质结合区）。对空白区相应 DNA 克隆测序，对照未经反应的序列标志，鉴定结合序列。" alt="DNase I 足迹法：末端标记、蛋白保护、酶切、变性胶空白区即结合位点"}

:::definition{label="DNA 足迹法"}
$\mathrm{DNA}$ 足迹法（footprinting）：分析启动子中潜在的调节蛋白结合位点。利用 $\mathrm{DNA}$ 电泳条带连续性中断的图谱，判断蛋白质结合的 $\mathrm{DNA}$ 区域及其序列。早期常用；现在结合位点序列主要通过 $\mathrm{DNA}$ 测序确定。
:::

:::definition{label="酶足迹法与化学足迹法"}
足迹法必须切割被检 $\mathrm{DNA}$。按切割试剂分为酶足迹法和化学足迹法。图18-10 是酶足迹法，切割试剂是 $\mathrm{DNase}\ \mathrm{I}$。
:::

:::definition{label="DNase I 足迹法的步骤"}
双链 $\mathrm{DNA}$ 单链末端标记 $\rightarrow$ 加入 $\mathrm{DNA}$ 结合蛋白 $\rightarrow$ $\mathrm{DNase}\ \mathrm{I}$ 切割（控制反应时间）$\rightarrow$ 未结合区被切成长短不同片段，蛋白质结合区不被酶切 $\rightarrow$ 变性凝胶电泳：无蛋白对照为连续梯带，蛋白-$\mathrm{DNA}$ 样品出现空白区 $\rightarrow$ 对空白区相应 $\mathrm{DNA}$ 克隆测序，对照未经反应的序列标志，鉴定结合序列。
:::

:::insight{label="「足迹」就是胶上那一段空白"}
$\mathrm{DNase}\ \mathrm{I}$ 在裸露 $\mathrm{DNA}$ 上几乎随处可切，控制时间后得到差 $1$ 个核苷酸的梯子。蛋白质坐上去的那一段切不到，梯子在这里断一截，看起来像脚印。空白区对着的序列，就是结合区。
:::

:::cause-effect{title="为什么必须末端标记、必须有无蛋白对照"}
- **因** 电泳看见的是带标记的那一端到切口之间的长度；没有标记就没有梯子。没有「无蛋白」泳道，就不知道连续梯带本来长什么样
- **果** 只有「无蛋白＝连续、加蛋白＝同一位置空白」时，才能把空白区写成蛋白质结合区，而不是酶切失败
:::

:::pitfall{label="足迹法的胶是变性胶，EMSA 的胶是非变性胶"}
足迹法要把片段拆成单链、按差 $1$ 个核苷酸分开，所以是变性凝胶电泳。$\mathrm{EMSA}$ 要保住蛋白质-$\mathrm{DNA}$ 复合物，所以非变性、不加 $\mathrm{SDS}$。都在分析结合位点，胶的变性与否相反。
:::

:::pitfall{label="足迹法放在启动子分析，不要搬回第四节当 ChIP 的原理"}
第四节代表技术是 $\mathrm{EMSA}$ 和 $\mathrm{ChIP}$。足迹法本版写在第五节「确定启动子」。$\mathrm{EMSA}/\mathrm{ChIP}$ 告诉你「有结合」；足迹法告诉你「结合占住了哪一段梯子」。现在序列多用测序确定，足迹法仍是理解「空白区＝结合区」的原型。
:::

## 三、基因表达产物及时空特异性检测是基因表达分析的核心内容

$1968$ 年中心法则确立前后，只能通过测定单个代谢酶活性，或采用核素标记结合原位杂交、凝胶电泳、放射自显影分析基因表达。$20$ 世纪 $70$ 年代末，建立了 $\mathrm{RNA}$ 印迹法和蛋白质印迹法，这两种方法逐步成为分析单个特异基因表达的常规技术。$\mathrm{DNA}$ 克隆技术的诞生（$1973$ 年），推动了基因组 $\mathrm{DNA}$ 和 $\mathrm{cDNA}$ 的分离与鉴定，至 $20$ 世纪 $90$ 年代初，已建成各种 $\mathrm{DNA}$、表达序列标签（expressed sequence tag，$\mathrm{EST}$）、$\mathrm{mRNA}$ 数据库。$\mathrm{PCR}$ 技术，特别是实时 $\mathrm{PCR}$ 与数据库检索相结合，通过合成特异引物检测基因表达，几乎取代了先前的 $\mathrm{RNA}$ 印迹法。随着人类基因组测序的完成，各种生物芯片和高通量分析技术应运而生，满足了基因功能注释和从组学水平高通量全局性揭示基因表达的需要。

:::timeline{period="本版写下的表达检测节点"}
:::event{year="1968 前后"}
中心法则确立前后：单个代谢酶活性；核素标记结合原位杂交、凝胶电泳、放射自显影。
:::
:::event{year="1973"}
DNA 克隆技术诞生，推动基因组 DNA 和 cDNA 的分离与鉴定。
:::
:::event{year="1970s 末"}
RNA 印迹法和蛋白质印迹法建立，成为分析单个特异基因表达的常规技术。
:::
:::event{year="1990s 初"}
建成各种 DNA、EST、mRNA 数据库。
:::
:::event{year="PCR 之后"}
实时 PCR 与数据库检索结合，特异引物检测表达，几乎取代 RNA 印迹法。人类基因组测序完成后，芯片和高通量技术承担组学水平的全局分析。
:::
:::

:::definition{label="EST"}
表达序列标签（expressed sequence tag，$\mathrm{EST}$）：$20$ 世纪 $90$ 年代初与 $\mathrm{DNA}$、$\mathrm{mRNA}$ 数据库一并建成的表达序列资源，是后来大规模检索表达的前置。
:::

:::insight{label="实时 PCR「几乎取代」Northern，并没有取消印迹法的可靠性"}
第一节写过：$\mathrm{RNA}$ 印迹法敏感性低于 $\mathrm{PCR}$，但特异性强、假阳性率低，仍被认为是最可靠的 $\mathrm{RNA}$ 定量分析方法之一。本节说的是日常检测几乎被实时 $\mathrm{PCR}$ $+$ 数据库引物取代。两句话同时成立。
:::

:::pitfall{label="1973 是克隆技术，1977 才是测序第一次飞跃"}
不要把 $\mathrm{DNA}$ 克隆的诞生年和桑格／马克萨姆法写成同一年。表达分析这条时间线里，$1973$ 推动的是分离鉴定 $\mathrm{cDNA}$，$90$ 年代初才有成规模的 $\mathrm{EST}$ 库。
:::

### （一）拷贝数分析技术可以了解基因表达丰度

分析某个基因表达的拷贝数，实质上就是对基因表达进行定性和丰度的定量分析。早期常用技术包括 $\mathrm{RNA}$ 印迹法和实时 $\mathrm{PCR}$ 技术等。当前高通量的分析技术，包括高通量测序技术、芯片、$\mathrm{SAGE}$ 等，已成为精确鉴定拷贝数的主要方法。

:::definition{label="拷贝数分析"}
对某个基因表达进行定性和丰度的定量分析。早期：$\mathrm{RNA}$ 印迹法、实时 $\mathrm{PCR}$。当前精确鉴定的主要方法：高通量测序、芯片、$\mathrm{SAGE}$ 等。
:::

:::pitfall{label="这里的拷贝数是表达丰度，不一定是基因组拷贝数变异"}
第三节医学用途里的「基因拷贝数变异」问的是基因组里这段 $\mathrm{DNA}$ 有几份。本节「某个基因表达的拷贝数」问的是转录（或后文蛋白质）有多少。字同，样品不同。
:::

### （二）分子标记等技术可以了解基因表达的组织和细胞内定位

蛋白质是许多基因表达的最终产物，其质和量的变化直接反映了基因的功能。检测蛋白质的技术除了印迹法和芯片技术外，还有许多，本部分仅简要介绍几种代表性的技术。

:::definition{label="定位这一小节为什么转向蛋白质"}
蛋白质是许多基因表达的最终产物，质和量的变化直接反映基因功能。拷贝数可以停在 $\mathrm{RNA}$；组织和细胞内「在哪」常常要看蛋白质。
:::

**1. 酶联免疫吸附实验分析蛋白质**　与蛋白质印迹法相似，酶联免疫吸附分析（enzyme linked immunosorbent assay，$\mathrm{ELISA}$）也是一种建立在抗原-抗体反应基础上的蛋白质分析方法，其主要用于测定可溶性抗原或抗体。该方法需要将已知抗体或抗原吸附于固相载体（如聚苯乙烯微量反应板）表面，使抗原-抗体反应在固相表面进行。

:::definition{label="ELISA"}
酶联免疫吸附分析（enzyme linked immunosorbent assay，$\mathrm{ELISA}$）：与蛋白质印迹法相似，建立在抗原-抗体反应上。主要用于测定可溶性抗原或抗体。已知抗体或抗原吸附于固相载体（如聚苯乙烯微量反应板）表面，反应在固相表面进行。
:::

:::compare{title="Western vs ELISA"}
| | 蛋白质印迹法 | $\mathrm{ELISA}$ |
|--|-------------|----------------|
| 识别 | 抗原－抗体 | 抗原－抗体 |
| 样品事先是否按分子量分开 | 是（$\mathrm{PAGE}$ 再转膜） | 否（直接吸附在板孔表面） |
| 主要回答 | 有没有、分子量大约多少、半定量 | 可溶性抗原或抗体的量 |
| 固相 | $\mathrm{NC}$／$\mathrm{PVDF}$ 膜 | 聚苯乙烯微量反应板等 |

都靠抗体；$\mathrm{ELISA}$ 不跑胶。
:::

**2. 免疫组化实验原位检测组织／细胞表达的蛋白质**　包括免疫组织化学（immunohistochemistry）和免疫细胞化学（immunocytochemistry）技术，两者原理相同，都是用标记的抗体在组织／细胞原位对目标蛋白质进行定性、定量、定位检测。常用技术包括酶免疫组化（酶标记）、免疫荧光组化（荧光标记，可用荧光或激光共聚焦显微镜观察）、免疫金组化（胶体金标记）等。

:::definition{label="免疫组化"}
免疫组织化学（immunohistochemistry）和免疫细胞化学（immunocytochemistry）：原理相同，用标记抗体在组织／细胞原位对目标蛋白质定性、定量、定位。标记可以是酶、荧光（荧光或激光共聚焦显微镜）或胶体金。
:::

:::insight{label="原位二字是和 ELISA、Western 的分界"}
$\mathrm{ELISA}$ 在板孔里测可溶物；Western 在膜上测已经电泳分开的混合物。免疫组化把抗体加到切片或细胞上，看见的是这个蛋白质在哪一种细胞、哪一个亚细胞结构。表达的「空间」从这里开始落地。
:::

**3. 流式细胞术分析表达特异蛋白质的阳性细胞**　流式细胞术（flow cytometry）通常利用荧光标记抗体与抗原的特异性结合，经流式细胞仪分析荧光信号，从而根据细胞表达特定蛋白质的水平对某种蛋白质阳性细胞（即特异基因表达的细胞）作出判断。流式细胞术还可对悬液中微生物或细胞器等进行单个快速识别、分析和分离，用以分析细胞大小、细胞周期、$\mathrm{DNA}$ 含量、细胞表面分子，是对细胞进行快速分析、分选、特征鉴定的一种有效方法。

:::definition{label="流式细胞术"}
流式细胞术（flow cytometry）：荧光标记抗体与抗原特异结合，流式细胞仪读荧光，按蛋白质表达水平判断阳性细胞（即特异基因表达的细胞）。还可对悬液中微生物或细胞器单个快速识别、分析、分离；可分析细胞大小、细胞周期、$\mathrm{DNA}$ 含量、细胞表面分子。
:::

:::keypoint{label="三种分子标记分别停在哪一层空间"}
- $\mathrm{ELISA}$：溶液里有多少可溶性抗原／抗体。
- 免疫组化：组织切片或细胞原位，哪一类细胞、哪个位置。
- 流式：悬液里每一个细胞的荧光强度，并能分选。

都认抗原－抗体，空间分辨率不同。
:::

:::pitfall{label="流式的「阳性细胞」是特异基因表达的细胞，不是测序深度阳性"}
判断依据是该蛋白质的荧光水平。不要把流式答成 $\mathrm{ChIP}$-seq 的 peak，也不要答成 $\mathrm{PCR}$ 的扩增曲线越过阈值。
:::

## 四、整体的基因表达谱信息可以通过转录物组学分析技术获得

转录物组（transcriptome）指细胞内的 $\mathrm{RNA}$ 转录产物，包括 $\mathrm{mRNA}$、$\mathrm{rRNA}$、$\mathrm{tRNA}$ 及其他非编码 $\mathrm{RNA}$。因此，转录物组学（transcriptomics）是通过分析细胞内全部 $\mathrm{RNA}$ 转录产物，研究细胞中所有基因转录及转录调控规律的学科领域。与基因组相比，转录物组最大的特点是受到细胞内外多种因素的调节，即基因在不同细胞或不同组织中表达时间或表达水平不同，呈动态可变。

:::definition{label="转录物组"}
转录物组（transcriptome）：细胞内的 $\mathrm{RNA}$ 转录产物，包括 $\mathrm{mRNA}$、$\mathrm{rRNA}$、$\mathrm{tRNA}$ 及其他非编码 $\mathrm{RNA}$。
:::

:::definition{label="转录物组学"}
转录物组学（transcriptomics）：通过分析细胞内全部 $\mathrm{RNA}$ 转录产物，研究细胞中所有基因转录及转录调控规律的学科领域。
:::

:::pitfall{label="本版转录物组不只是 mRNA"}
定义明确包括 $\mathrm{mRNA}$、$\mathrm{rRNA}$、$\mathrm{tRNA}$ 及其他非编码 $\mathrm{RNA}$。不要用「只统计编码 $\mathrm{mRNA}$ 的外校定义」替换。表18-1 里的 miRbase、$\mathrm{GtRNAdb}$ 也对着非编码这一侧。
:::

:::insight{label="和基因组比，转录物组的最大特点是动态可变"}
同一套基因组，在不同细胞、不同组织、不同时间或发育阶段，表达时间和水平可以不同。所以才需要表达谱，而不是只做一次全基因组测序。
:::

通过 $\mathrm{RNA}$-seq、生物芯片、$\mathrm{SAGE}$、大规模平行标签测序（massively parallel signature sequencing，$\mathrm{MPSS}$）等高通量技术分析转录物，可以获得基因表达谱，即基因在不同细胞或组织、不同时间或发育阶段的总体表达水平，进而生物信息学分析并展示差异表达基因，从而推断基因间的表达调控和表达产物间的相互作用，揭示基因与疾病发生、发展的内在关系。

:::definition{label="高通量拿到表达谱之后做什么"}
$\mathrm{RNA}$-seq、生物芯片、$\mathrm{SAGE}$、$\mathrm{MPSS}$ 等给出总体表达水平 $\rightarrow$ 生物信息学展示差异表达基因 $\rightarrow$ 推断基因间调控和产物间相互作用 $\rightarrow$ 揭示与疾病发生发展的关系。
:::

### （一）比较转录物组学技术获得动态可变的差异表达基因

通过 $\mathrm{RNA}$-seq 开展比较转录物组研究可以同时监控成千上万个基因在不同状态（如生理、病理、发育不同时期、诱导刺激等）下的表达变化，并能够在单核苷酸水平对任意物种的整体转录活动进行检测，在分析转录本的结构和表达水平的同时，还能发现未知转录本和低丰度转录本，发现基因融合，识别可变剪切位点和 $\mathrm{SNP}$，提供全面的转录物组信息。其他一些技术也可获得基因表达的差异性，这里仅简介 $\mathrm{MPSS}$、消减杂交（subtractive hybridization）和 $\mathrm{mRNA}$ 差异显示（mRNA differential display，$\mathrm{mRNA}$-$\mathrm{DD}$）。

:::definition{label="RNA-seq 做比较转录物组能多看见什么"}
同时监控成千上万个基因在生理、病理、发育不同时期、诱导刺激等状态下的变化；单核苷酸水平、任意物种；分析结构与表达水平；发现未知和低丰度转录本、基因融合；识别可变剪切位点和 $\mathrm{SNP}$。
:::

:::keypoint{label="比较转录物组本版点名的四条技术"}
- $\mathrm{RNA}$-seq：当前全面信息的主力。
- $\mathrm{MPSS}$：标签序列测定。
- 消减杂交：把相似表达扣掉，留下差异。
- $\mathrm{mRNA}$-$\mathrm{DD}$：随机引物 $+$ 锚定引物的 $\mathrm{RT}$-$\mathrm{PCR}$，再 $\mathrm{PAGE}$ 看差异条带。

后三条是「其他一些技术」的简介，不要写成已经取代 $\mathrm{RNA}$-seq。
:::

**1. $\mathrm{MPSS}$ 是以标签序列测定为基础的高通量基因表达谱分析技术**　$\mathrm{MPSS}$ 又称大规模平行信号测序，是一种基于序列分析的高通量转录物组分析技术。该技术原理是将每个转录本的 $16\sim 20\,\mathrm{nt}$ 的特异序列作为检测标签，该序列在样品中的拷贝数代表了与其对应基因的表达水平。该方法能够分析表达丰度较低、差异较小的基因，且无须预先知道基因序列。由于省略了基因片段分离、克隆和逐一测序，操作简便耗时短。

:::definition{label="MPSS"}
大规模平行标签测序／大规模平行信号测序（massively parallel signature sequencing，$\mathrm{MPSS}$）：以每个转录本 $16\sim 20\,\mathrm{nt}$ 的特异序列为检测标签，标签在样品中的拷贝数代表对应基因的表达水平。能看低丰度、小差异；无须预先知道基因序列；省略分离、克隆和逐一测序。
:::

**2. 消减杂交是通过核酸杂交扣除相似表达从而获得差异表达基因的分析技术**　消减杂交，曾被称为扣除杂交。该技术原理是利用不同组织、细胞或不同状态下组织、细胞基因表达的差异性，并结合核酸杂交建立的克隆差异表达基因的技术。基本流程是将一种细胞的 $\mathrm{cDNA}$ 或 $\mathrm{mRNA}$ 与另一种细胞或同一种细胞不同状态的 $\mathrm{cDNA}$ 或 $\mathrm{mRNA}$ 相互杂交，其不被杂交的部分就代表了两种细胞基因表达的差异，可用于差异表达基因的克隆。差示筛选、消减探针、消减文库的建立等都是该技术的具体实施。

:::definition{label="消减杂交"}
消减杂交（subtractive hybridization），曾称扣除杂交：把一种细胞的 $\mathrm{cDNA}$ 或 $\mathrm{mRNA}$ 与另一种细胞（或同一细胞不同状态）的 $\mathrm{cDNA}$ 或 $\mathrm{mRNA}$ 杂交，不被杂交的部分代表表达差异，用于克隆差异表达基因。具体实施包括差示筛选、消减探针、消减文库。
:::

:::insight{label="「扣掉」的是共有的转录本"}
两种状态都表达的序列能杂交上，被扣掉；只在一种状态出现的序列杂交不上，留下来建库或当探针。和芯片「两个荧光都亮」的逻辑相反：芯片留下共有和差异的全部信号，消减杂交刻意扔掉共有。
:::

**3. $\mathrm{mRNA}$-$\mathrm{DD}$ 是 $\mathrm{RT}$-$\mathrm{PCR}$ 技术和聚丙烯酰胺凝胶电泳技术的结合**　$\mathrm{mRNA}$ 差异显示，又称为差异显示逆转录 $\mathrm{PCR}$（differential display reverse transcription PCR，$\mathrm{DDRT}$-$\mathrm{PCR}$）。该技术是利用可以扩增所有哺乳类生物 $\mathrm{mRNA}$ 的几条 $5'$－端随机引物和 $3'$－端锚定引物组合，用逆转录 $\mathrm{PCR}$ 扩增出不同状态细胞的 $\mathrm{cDNA}$，然后用聚丙烯酰胺凝胶电泳分离扩增产物，比较两组间产物的差异（图18-11）。这一方法的优点在于所需 $\mathrm{mRNA}$ 量少、较快速、可同时获得高表达和低表达的基因等。这种方法也存在许多严重的缺陷，如假阳性率高达 $70\%$、获得的片段太短等，很难直接判断其功能和意义。尽管有上述缺陷，但因其步骤较简单、可获得较大量信息，在实际研究中仍有应用。

::figure{src="/images/biochemistry/textbook/p0385_01.png" caption="图18-11　mRNA-DD 原理和基本过程示意图。检测 mRNA 与对照 mRNA 分别用 NM（T11）引物逆转录，得到 N′M′（A11）互补链；再以 5′ 端随机引物（图中 XXXXXXXXXX）PCR。两组产物走 PAGE，比较差异条带。" alt="mRNA 差异显示：检测与对照各自 T11 逆转录、PCR 后 PAGE 比较差异条带"}

:::definition{label="mRNA-DD"}
$\mathrm{mRNA}$ 差异显示（mRNA differential display，$\mathrm{mRNA}$-$\mathrm{DD}$），又称差异显示逆转录 $\mathrm{PCR}$（$\mathrm{DDRT}$-$\mathrm{PCR}$）：用可扩增所有哺乳类 $\mathrm{mRNA}$ 的几条 $5'$－端随机引物和 $3'$－端锚定引物组合，逆转录 $\mathrm{PCR}$ 扩增不同状态细胞的 $\mathrm{cDNA}$，聚丙烯酰胺凝胶电泳分离，比较两组产物差异。
:::

:::definition{label="图18-11 的引物和读出"}
检测组与对照组 $\mathrm{mRNA}$ 都用 $\mathrm{NM}$（$\mathrm{T}_{11}$）引物逆转录（互补链写作 $\mathrm{N}'\mathrm{M}'$（$\mathrm{A}_{11}$）），再用 $5'$ 端随机引物 $\mathrm{PCR}$，两组产物上 $\mathrm{PAGE}$，多出来或少掉的带就是差异条带。
:::

:::definition{label="mRNA-DD 的优点和缺陷"}
优点：所需 $\mathrm{mRNA}$ 量少、较快速、可同时获得高表达和低表达的基因。缺陷：假阳性率高达 $70\%$、获得的片段太短，很难直接判断功能和意义。尽管如此，步骤较简单、信息量较大，实际研究中仍有应用。
:::

:::pitfall{label="70% 假阳性是这张方法必须一起背的数字"}
只默写「快速、要的 $\mathrm{mRNA}$ 少」，试卷若问缺陷，答不上 $70\%$ 和片段太短就不完整。差异条带还要再克隆、验证，不能直接当功能结论。
:::

:::pitfall{label="锚定引物是 3′ 端 T11 一类，随机引物在 5′ 端"}
图18-11 逆转录用 $\mathrm{NM}$（$\mathrm{T}_{11}$），对着 $\mathrm{mRNA}$ 的多聚 $\mathrm{A}$ 尾。$5'$ 端那串 $\mathrm{X}$ 是随机引物。不要写成两条都是随机，也不要写成实时 $\mathrm{PCR}$ 的特异一对引物。
:::

:::compare{title="三种「找差异基因」"}
| | $\mathrm{MPSS}$ | 消减杂交 | $\mathrm{mRNA}$-$\mathrm{DD}$ |
|--|---------------|----------|--------------------------|
| 核心化学 | 短标签计数 | 杂交扣除共有序列 | 随机 $+$ 锚定引物 $\mathrm{RT}$-$\mathrm{PCR}$，再 $\mathrm{PAGE}$ |
| 要不要预先知道序列 | 无须 | 不依赖全基因注释，但要有两种 $\mathrm{cDNA}/\mathrm{mRNA}$ | 无须特异基因引物 |
| 明显短板（教材写明的） | — | — | 假阳性约 $70\%$，片段短 |

$\mathrm{RNA}$-seq 能同时给结构、融合、$\mathrm{SNP}$ 和未知转录本；这三张是比较转录物组里点名的其他技术。
:::

### （二）空间转录物组分析技术可以获得全局性的基因表达时空特异性

不同类型的细胞具有不同的转录物组表型，并决定细胞的最终命运。以单细胞为研究模型的转录物组分析，有助于解析单个细胞的行为、机制以及与机体的关系等的分子基础。空间转录物组分析技术（spatial transcriptomic technology）联合使用组织切片的细胞原位鉴定技术和单细胞测序技术，检测出单个组织切片中不同细胞的所有 $\mathrm{mRNA}$，且能够定位和区分功能基因在特定组织区域内的转录数据，从而高效解析组织空间原位的细胞基因表达模式。因此，解决了用全组织样本测序无法解决的细胞异质性问题，尤其适用于存在高度异质性的干细胞、胚胎发育早期的细胞群体和肿瘤组织等。与活细胞成像系统相结合，空间转录物组分析更有助于深入理解细胞分化、细胞重编程及转分化等过程以及相关的基因调节网络，在临床上可以连续追踪疾病基因表达的动态变化，监测病程变化、预测疾病预后。

:::definition{label="空间转录物组分析技术"}
空间转录物组分析技术（spatial transcriptomic technology）：联合组织切片的细胞原位鉴定和单细胞测序，检测单个组织切片中不同细胞的所有 $\mathrm{mRNA}$，定位并区分功能基因在特定组织区域内的转录数据，解析空间原位的细胞基因表达模式。
:::

:::definition{label="空间转录物组解决什么问题"}
全组织样本测序无法解决的细胞异质性。尤其适用于高度异质性的干细胞、胚胎发育早期细胞群体和肿瘤组织。
:::

:::insight{label="单细胞给「哪一个细胞」，空间给「这个细胞在切片的哪一块」"}
不同类型细胞有不同转录物组表型，决定最终命运。只做单细胞而丢掉坐标，异质性看见了，组织结构看不见。原位鉴定 $+$ 单细胞测序，才把表达谱贴回切片。
:::

:::keypoint{label="与活细胞成像联用之后还能多问什么"}
细胞分化、重编程及转分化和相关基因调节网络；临床上连续追踪疾病基因表达动态，监测病程、预测预后。这是时空，不只是一张静态热图。
:::

:::pitfall{label="第三节的单细胞测序是读序能力，本节是把它贴回组织坐标"}
第三节：无须 $\mathrm{PCR}$ 的单分子测序促成单细胞测序，成为空间组学、时空组学的主要技术之一。本节：空间转录物组 $=$ 原位鉴定 $+$ 单细胞测序。不要把两句话并成「纳米孔等于空间转录物组」。
:::

## 五、全面的蛋白质表达、修饰和互作谱信息可以通过蛋白质组学技术获得

蛋白质是生物功能的主要载体。蛋白质组（proteome）是指细胞、组织或机体在特定时间和空间上表达的所有蛋白质。蛋白质组学（proteomics）以所有这些蛋白质为研究对象，分析细胞内动态变化的蛋白质组成、定位、结构、表达模式及功能模式的学科领域，包括鉴定蛋白质的表达、存在方式（修饰形式）或部位、结构、功能和相互作用等，故又称为全景式蛋白质表达谱（global protein expression profile）分析。

:::definition{label="蛋白质组"}
蛋白质组（proteome）：细胞、组织或机体在特定时间和空间上表达的所有蛋白质。
:::

:::definition{label="蛋白质组学"}
蛋白质组学（proteomics）：以这些蛋白质为研究对象，分析细胞内动态变化的蛋白质组成、定位、结构、表达模式及功能模式。包括鉴定表达、存在方式（修饰形式）或部位、结构、功能和相互作用。又称全景式蛋白质表达谱（global protein expression profile）分析。
:::

:::pitfall{label="蛋白质组是「特定时间空间上的全部蛋白质」，不是基因组的简单翻译"}
同一套基因，翻译后还有靶向运输和磷酸化、糖基化等修饰。转录物组可以预测种类和一级结构，蛋白质组还要实验看修饰、定位和互作。不要用「基因有多少个蛋白质就有多少个」替换本版定义。
:::

:::compare{title="基因组、转录物组、蛋白质组"}
| | 对象 | 本版强调的特点 |
|--|------|----------------|
| 基因组 | 全部 $\mathrm{DNA}$ 序列 | 相对稳定；第三节测序 |
| 转录物组 | 全部 $\mathrm{RNA}$（含 $\mathrm{mRNA}$、$\mathrm{rRNA}$、$\mathrm{tRNA}$、其他非编码 $\mathrm{RNA}$） | 动态可变 |
| 蛋白质组 | 特定时间空间上表达的所有蛋白质 | 动态；含修饰、定位、互作；全景式表达谱 |

三张谱不能互相替代。
:::

蛋白质组学可以通过转录物组分析细胞的蛋白质组表达模式（种类及其一级结构），进而预测所表达蛋白质的高级结构及其功能模式，也可以利用人类蛋白质图谱（The Human Protein Atlas，$\mathrm{HPA}$）基于 $27\,520$ 种抗体、靶向 $17\,288$ 种人类蛋白质的组学信息分析（表18-1）。而实验分析，常用高通量鉴定蛋白质组主要是通过生物芯片、二维电泳、二维／多维液相分离等，然后质谱法（mass spectrometry，$\mathrm{MS}$）鉴定。

:::definition{label="蛋白质组从预测走到实验"}
预测：转录物组 $\rightarrow$ 种类和一级结构 $\rightarrow$ 高级结构与功能模式；或查 $\mathrm{HPA}$（$27\,520$ 种抗体，靶向 $17\,288$ 种人类蛋白质）。实验：生物芯片、二维电泳、二维／多维液相分离，再质谱鉴定。
:::

### （一）质谱法可以高通量鉴定蛋白质种类和一级结构信息

利用质谱法鉴定蛋白质主要通过两种策略：①肽质量指纹图（peptide mass fingerprinting，$\mathrm{PMF}$）和数据库搜索匹配。蛋白质经过酶解成肽段后，$\mathrm{MS}$ 获得所有肽段的精确质荷比，形成一个特异的 $\mathrm{PMF}$ 图谱，通过数据库搜索与比对，便可确定待分析蛋白质。②串联质谱法（tandem mass spectrometry）的信息与数据库搜索匹配。通过获得同一蛋白质数段多肽的信息，通过数据库检索来鉴定该蛋白质。可提供更多的结构信息及提高定量分析的专一性。

:::definition{label="质谱法"}
质谱法（mass spectrometry，$\mathrm{MS}$）：高通量鉴定蛋白质种类和一级结构的主要实验读出。前面通常接芯片、二维电泳或二维／多维液相分离。
:::

:::definition{label="肽质量指纹图"}
肽质量指纹图（peptide mass fingerprinting，$\mathrm{PMF}$）：蛋白质酶解成肽段 $\rightarrow$ $\mathrm{MS}$ 给出所有肽段的精确质荷比，形成特异图谱 $\rightarrow$ 数据库搜索匹配，确定蛋白质。
:::

:::definition{label="串联质谱法"}
串联质谱法（tandem mass spectrometry）：获得同一蛋白质数段多肽的信息，再数据库检索鉴定。比单张 $\mathrm{PMF}$ 能提供更多结构信息，并提高定量分析的专一性。
:::

:::compare{title="PMF vs 串联质谱"}
| | $\mathrm{PMF}$ | 串联质谱 |
|--|--------------|----------|
| 输入 | 酶解后全部肽段的质荷比指纹 | 同一蛋白质数段多肽的碎裂／序列信息 |
| 鉴定 | 整张指纹对数据库 | 多段多肽信息对数据库 |
| 教材补充 | — | 更多结构信息，定量分析更专一 |

都要搜库；不是「测序仪上再做一次桑格」。
:::

:::pitfall{label="质谱鉴定依赖数据库匹配，库错了蛋白质就配错"}
两种策略都写了「数据库搜索匹配」。前面 $\mathrm{BLAST}$、$\mathrm{GEO}$、$\mathrm{HPA}$、$\mathrm{PDB}$ 不是装饰，是质谱读出能够落成蛋白质名字的前提。
:::

### （二）整体鉴定蛋白质的各种修饰主要也是依靠质谱法

基因表达产生大量不同蛋白质，大多还要经历靶向运输、翻译后修饰（如磷酸化、糖基化等）等过程，是蛋白质功能调控的重要方式。

:::definition{label="翻译后修饰在蛋白质组里的位置"}
靶向运输和翻译后修饰（如磷酸化、糖基化等）是蛋白质功能调控的重要方式。整体鉴定各种修饰，主要也靠质谱法。
:::

**1. 蛋白质种类和结构鉴定是蛋白质组研究的基础**　细胞在特定状态下表达的所有蛋白质都是蛋白质组学的研究对象。一般利用二维电泳和多维色谱并结合生物质谱法、蛋白质印迹法、蛋白质芯片等技术，对蛋白质进行全面的种类和结构鉴定研究。

:::definition{label="种类和结构鉴定用哪些技术"}
二维电泳、多维色谱，结合生物质谱法、蛋白质印迹法、蛋白质芯片。对象是细胞在特定状态下表达的所有蛋白质。
:::

**2. 翻译后修饰的鉴定有助于蛋白质功能的阐明**　质谱法、抗体技术、蛋白质组学技术和基因编辑技术等多种技术的应用，已能够深入探查蛋白质修饰的类型、位置和功能，从而为疾病的诊断和治疗提供新的思路和策略。

:::definition{label="修饰鉴定的技术组合"}
质谱法、抗体技术、蛋白质组学技术和基因编辑技术。要探查的是修饰的类型、位置和功能，落点是疾病诊断和治疗。
:::

:::keypoint{label="修饰这一小节两句话"}
- 种类和结构是基础：二维电泳／多维色谱 $+$ 质谱／Western／芯片。
- 修饰类型、位置、功能：质谱 $+$ 抗体 $+$ 组学 $+$ 基因编辑。

磷酸化、糖基化是本版点名的例子，不是全部修饰清单。
:::

### （三）蛋白质相互作用研究是认识蛋白质功能的重要内容

细胞中的各种蛋白质分子往往形成蛋白质复合物，共同执行各种生命活动。蛋白质-蛋白质相互作用是维持细胞生命活动的基本方式。要深入研究所有蛋白质的功能，理解生命活动的本质，就必须对蛋白质-蛋白质相互作用有一个清晰的了解，包括受体与配体的结合、信号转导分子间的相互作用及其机制等。目前研究蛋白质相互作用常用的实验方法有酵母双杂交系统、各类亲和层析、荧光共振能量转移等。

:::definition{label="蛋白质组视角下的互作"}
蛋白质常形成复合物共同执行生命活动。互作包括受体与配体、信号转导分子间的相互作用及其机制。常用实验：酵母双杂交、各类亲和层析、荧光共振能量转移。
:::

:::pitfall{label="这里点名的酵母双杂交和亲和层析，原理已在第四节"}
蛋白质组学把互作谱当成全景的一部分。具体实验：酵母双杂交、标签牵拉沉淀（亲和层析／珠子）、$\mathrm{FRET}$，不要在本节再发明一套「干扰素抑制翻译」。第四节已经写过 $\mathrm{BD}/\mathrm{AD}$ 和 $\mathrm{GST}$-$\mathrm{GSH}$。
:::

:::memory{label="本节表达分析一张清单"}
- 策略：先查表18-1（三大库 $\mathrm{NCBI}/\mathrm{EBI}/\mathrm{DDBJ}$，中国 $\mathrm{CNGBdb}/\mathrm{CNCB}$，$\mathrm{GEO}$ 等），再实时 $\mathrm{PCR}$、芯片验证。
- 编码区：$\mathrm{cDNA}$ 文库三条用法；$\mathrm{RACE}$ 补末端；剪接 $=$ 芯片／$\mathrm{RNA}$ 交联沉淀／报告基因。
- $\mathrm{TSS}$：全长 $\mathrm{cDNA}$ 测序；$5'$-$\mathrm{RACE}$（$\mathrm{CIAP}\rightarrow\mathrm{TAP}\rightarrow$ 接头 $\rightarrow$ 巢式 $\mathrm{PCR}$）；$5'$-$\mathrm{SAGE}$／$\mathrm{CAGE}$。
- 启动子：$\mathrm{PCR}$ 克隆测序；$\mathrm{EMSA}/\mathrm{ChIP}$；足迹法（变性胶空白区，$\mathrm{DNase}\ \mathrm{I}$ 是酶足迹）。
- 产物：拷贝数（Northern、实时 $\mathrm{PCR}$、测序、芯片、$\mathrm{SAGE}$）；定位（$\mathrm{ELISA}$、免疫组化、流式）。
- 转录物组 $=$ 全部 $\mathrm{RNA}$（含非编码），动态可变。比较：$\mathrm{RNA}$-seq、$\mathrm{MPSS}$、消减杂交、$\mathrm{mRNA}$-$\mathrm{DD}$（假阳性 $70\%$）。空间转录物组解决异质性。
- 蛋白质组 $=$ 特定时空全部蛋白质；$\mathrm{PMF}$ 与串联质谱搜库；修饰靠质谱等；互作回到酵母双杂交和亲和层析。
:::

## 小结

本章概括介绍了目前医学分子生物学中部分常用技术。

印迹法可以将在凝胶中电泳分离的生物大分子转移到固相介质上并加以检测分析，包括 $\mathrm{DNA}$ 印迹法、$\mathrm{RNA}$ 印迹法和蛋白质印迹法。生物芯片源于规模化集成的印迹法，包括基因芯片、蛋白质芯片和细胞芯片等。基因芯片主要用于基因表达检测、基因突变检测和功能基因组学研究等多个方面。蛋白质芯片广泛应用于蛋白质表达谱、功能及相互作用等研究。

$\mathrm{PCR}$ 的技术原理是以待扩增的 $\mathrm{DNA}$ 分子为模板，用两条寡核苷酸片段作为引物，分别与模板 $\mathrm{DNA}$ 链互补结合；在 $\mathrm{DNA}$ 聚合酶作用下完成两条新链的合成。通过不断重复变性、退火和延伸三个基本反应步骤，即可大量扩增目的 $\mathrm{DNA}$ 片段。以 $\mathrm{PCR}$ 为基础，衍生出 $\mathrm{RT}$-$\mathrm{PCR}$、实时 $\mathrm{PCR}$ 等多种技术。$\mathrm{PCR}$ 及其衍生技术主要用于目的基因的克隆、$\mathrm{DNA}$ 和 $\mathrm{RNA}$ 的微量分析、$\mathrm{DNA}$ 序列测定和基因的体外突变等。

确定一段 $\mathrm{DNA}$ 分子中 $4$ 种碱基的排列顺序称为 $\mathrm{DNA}$ 测序。桑格－库森法和化学降解法是经典的 $\mathrm{DNA}$ 测序。第一代全自动 $\mathrm{DNA}$ 测序技术基于桑格－库森法而建立。高通量 $\mathrm{DNA}$ 测序技术包括焦磷酸测序、单分子实时测序、纳米孔测序等，通过在芯片微孔中不同步的并行循环微量反应与测定等策略，实现了快速、低成本测序，并建成单细胞测序，为医学大数据时代提供了核心技术支撑。$\mathrm{DNA}$ 测序在医学中用于鉴定各种复杂性疾病的易感性预警或早期诊断的疾病标志物和治疗靶点；建立个体基因与疾病易感性、药物敏感性和耐受性以及其他诸多表型之间的联系；用于病原微生物的分子分型。$\mathrm{DNA}$ 测序在法医学领域具有特殊价值。

分析蛋白质-蛋白质、蛋白质-$\mathrm{DNA}$、蛋白质-$\mathrm{RNA}$ 复合物的组成和作用方式是理解生命活动的基础。酵母双杂交技术和标签蛋白质牵拉沉淀是目前分析细胞内蛋白质相互作用的主要手段。$\mathrm{EMSA}$ 和 $\mathrm{ChIP}$ 是目前最常用的在体外和体内分析 $\mathrm{DNA}$ 与蛋白质相互作用的实验方法。染色质构象捕获（$3\mathrm{C}$ 及 $4\mathrm{C}$、$5\mathrm{C}$、$\mathrm{Hi}$-$\mathrm{C}$、$\mathrm{ChIA}$-$\mathrm{PET}$）把空间上靠近的 $\mathrm{DNA}$ 写成可扩增、可测序的连接产物。

广义的基因表达分析包括基因序列测定、染色质构象、转录区域、编码区、转录起点、启动子等功能区域和表达产物（非编码 $\mathrm{RNA}$ 和编码的蛋白质）分析。生物信息学技术挖掘基因信息已成为全面分析基因表达的第一步，主要通过序列搜索与比对已建成的海量生物信息库，从而预测基因表达。实验分析基因的表达可以通过 $\mathrm{cDNA}$ 文库和 $\mathrm{RNA}$ 剪接分析确定编码区，直接克隆测序和 $5'$-$\mathrm{RACE}$ 确定转录起点，启动子克隆和核酸-蛋白质相互作用分析确定启动子。分析基因表达的产物及时空特异性，可以通过拷贝数分析了解基因表达丰度，分子标记等技术了解基因表达的细胞内定位。生命现象是全部基因功能的集体体现，因此，通过研究生物个体及其生命过程中全部基因的表达调控和表达产物的相互作用，主要通过染色质构象捕获和系列组学技术系统分析空间结构、时空特异性表达谱、修饰谱和互作谱等，可以从整体的分子水平还原生命现象。
