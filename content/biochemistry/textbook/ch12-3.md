# 第三节　代谢调节的主要方式

前两节把代谢写成一张可更新的网：共同代谢库、两用途径、乙酰 $\mathrm{CoA}$ 枢纽、$\mathrm{ATP}$ 与 $\mathrm{NADPH}$。本节写这张网怎么被拧住。细胞水平靠关键酶：区隔分布、别构、化学修饰、酶含量；激素通过膜受体或胞内受体落到这些酶上；整体水平再由神经系统整合饱食、空腹、饥饿和应激。代谢一旦配不平，就写成肥胖等代谢性疾病。章末收本章小结和思考题。

:::concept{term="先问调的是酶活性还是酶含量，再问信号来自细胞、激素还是整体"}
数秒到数分钟：别构和化学修饰改酶分子结构。数小时到数天：诱导、阻遏或降解改酶含量。激素和神经并不另做一套化学反应，它们通过细胞水平的关键酶实现调节。饥饿时血糖略降、脂肪酸和酮体上升（图12-4），是整体调节在血浆浓度上的结果。
:::

要保证机体的正常功能，就必须确保糖、脂质、蛋白质、水、无机盐、维生素等营养物质在体内的代谢，能够根据机体的代谢状态和执行功能的需求有条不紊地进行，这就需要对这些物质的代谢方向、速率和流量进行精细调节。正是有了这种精细的调节，使各种物质的代谢井然有序，相互协调进行，机体才能适应各种内外环境的变化，顺利完成各种生命活动。这是生物体的基本特征，是在生物进化过程中形成的一种适应能力。

代谢调节的复杂程度随进化程度增高而增加。单细胞生物主要通过细胞内代谢物浓度的变化，对酶的活性及含量进行调节，即所谓原始调节或细胞水平代谢调节。高等生物不仅细胞水平代谢调节更为精细复杂，还出现了内分泌细胞及内分泌器官，形成了通过激素发挥代谢调节作用的激素水平代谢调节。高等动物的代谢调节还涉及复杂的神经系统，形成了在中枢神经系统控制下，多种激素相互协调，对机体代谢进行综合调节的所谓整体水平代谢调节。上述三级代谢调节中，细胞水平代谢调节是基础，激素及神经对代谢的调节需通过细胞水平代谢调节实现。

这种调节一旦不足以协调各种物质的代谢之间的平衡、不能适应机体内外环境改变的需要，就会使细胞、机体的功能失常，导致疾病发生。

:::definition{label="三级代谢调节"}
细胞水平：细胞内代谢物浓度变化调节酶的活性及含量，是基础，也称原始调节。激素水平：内分泌细胞及器官通过激素调节代谢。整体水平：中枢神经系统控制下多种激素相互协调，对机体代谢综合调节。激素及神经的调节都要通过细胞水平实现。
:::

:::compare{title="三级调节按进化叠加上去"}
| 层次 | 谁在调 | 出现在 |
|------|--------|--------|
| 细胞水平 | 代谢物浓度 $\rightarrow$ 酶活性及含量 | 单细胞生物已有，高等生物更精细 |
| 激素水平 | 内分泌细胞／器官 $\rightarrow$ 激素 | 高等生物 |
| 整体水平 | 中枢神经系统 $+$ 多种激素 | 高等动物 |

方向、速率、流量三件事都要调。调不够就致病。
:::

:::pitfall{label="激素和神经不是绕过酶另走一条路"}
教材写明：激素及神经对代谢的调节需通过细胞水平代谢调节实现。背激素名单时，仍要落到别构、化学修饰或酶含量。
:::

:::keypoint{label="调节什么、谁来调"}
- 调方向、速率、流量。
- 三级：细胞、激素、整体；细胞是基础。
- 对象仍是第一节点名的糖、脂质、蛋白质、水、无机盐、维生素。
:::

## 一、细胞内物质代谢主要通过对关键酶活性的调节来实现

### （一）各种代谢酶在细胞内区隔分布是物质代谢及其调节的基础

在同一时间，细胞内有多种物质的代谢发生。参与同一代谢途径的酶，相对独立地分布于细胞特定区域或亚细胞结构（表12-1），形成所谓区隔分布，有的甚至结合在一起，形成多酶复合体。酶的这种区隔分布，能避免不同代谢途径之间彼此干扰，使同一代谢途径中的系列酶促反应能够更顺利地连续进行，既提高了代谢途径的进行速度，也有利于调控。

:::definition{label="酶的区隔分布"}
参与同一代谢途径的酶相对独立地分布于细胞特定区域或亚细胞结构，有的结合成多酶复合体。区隔避免不同途径彼此干扰，使同一途径的系列反应更顺利地连续进行，既提高速度，也有利于调控。
:::

:::compare{title="表12-1　主要代谢途径（多酶体系）在细胞内的分布"}
| 代谢途径（多酶体系） | 分布 | 代谢途径（多酶体系） | 分布 |
|----------------------|------|----------------------|------|
| $\mathrm{DNA}$、$\mathrm{RNA}$ 合成 | 细胞核 | 糖酵解 | 细胞质 |
| 蛋白质合成 | 内质网、细胞质 | 戊糖磷酸途径 | 细胞质 |
| 糖原合成 | 细胞质 | 糖异生 | 细胞质、线粒体 |
| 脂肪酸合成 | 细胞质 | 脂肪酸 $\beta$-氧化 | 细胞质、线粒体 |
| 胆固醇合成 | 内质网、细胞质 | 蛋白水解酶 | 溶酶体 |
| 磷脂合成 | 内质网 | 三羧酸循环 | 线粒体 |
| 血红素合成 | 细胞质、线粒体 | 氧化磷酸化 | 线粒体 |
| 尿素合成 | 细胞质、线粒体 | | |
:::

:::insight{label="合成和分解常常不在同一区隔"}
脂肪酸合成在细胞质，三羧酸循环和氧化磷酸化在线粒体；糖酵解在细胞质，糖异生跨细胞质和线粒体。区隔本身就是调节：中间物要转运才能跨途径，乙酰 $\mathrm{CoA}$、柠檬酸进出线粒体成为第二节那些别构信号的通路。
:::

:::pitfall{label="区隔分布不是“一个细胞同一时间只做一条途径”"}
教材第一句就是同一时间有多种物质的代谢发生。区隔是为了避免干扰、便于连续反应和调控，不是轮流上班。
:::

:::keypoint{label="表12-1 先抓住地点"}
- 细胞质：糖酵解、戊糖磷酸途径、糖原合成、脂肪酸合成。
- 线粒体：三羧酸循环、氧化磷酸化。
- 跨两处：糖异生、脂肪酸 $\beta$-氧化、血红素合成、尿素合成。
- 核：$\mathrm{DNA}/\mathrm{RNA}$ 合成。内质网：蛋白质合成、磷脂、胆固醇（兼细胞质）。溶酶体：蛋白水解酶。
:::

### （二）关键酶活性决定整个代谢途径的速率和方向

每条代谢途径由一系列酶促反应组成，其反应速率和方向由其中一个或几个具有调节作用的关键酶活性决定。这些在代谢过程中具有调节作用的酶称为关键酶（key enzymes），特点包括：①常常催化一条代谢途径的第一步反应或分支点上的反应，速度最慢，其活性能决定整个代谢途径的总速度。②常催化单向反应或非平衡反应，其活性能决定整个代谢途径的方向。③酶活性除受底物控制外，还受多种代谢物或效应剂调节。改变关键酶或调节酶活性是细胞水平代谢调节的基本方式，也是激素水平代谢调节和整体代谢调节的重要环节。表12-2 列出一些重要代谢途径的关键酶。

代谢调节可按速度分为快速调节和迟缓调节。前者通过改变酶的分子结构改变酶活性，进而改变酶促反应速度，在数秒或数分钟内发挥调节作用。快速调节又分为别构调节和化学修饰调节。迟缓调节通过改变酶蛋白分子的合成或降解速度改变细胞内酶的含量，进而改变酶促反应速度，一般需数小时甚至数天才能发挥调节作用。

:::definition{label="关键酶"}
关键酶（key enzymes）是代谢过程中具有调节作用的酶，其活性决定整条途径的速率和方向。特点：①常催化第一步或分支点反应，速度最慢，决定总速度；②常催化单向或非平衡反应，决定方向；③除受底物控制外，还受多种代谢物或效应剂调节。
:::

:::definition{label="快速调节与迟缓调节"}
快速调节：改变酶分子结构从而改变活性，数秒或数分钟见效，包括别构调节和化学修饰调节。迟缓调节：改变酶蛋白合成或降解速度从而改变酶含量，一般需数小时甚至数天。
:::

:::compare{title="表12-2　某些重要代谢途径的关键的调节酶"}
| 代谢途径 | 关键酶 |
|----------|--------|
| 糖酵解 | 己糖激酶、磷酸果糖激酶-1、丙酮酸激酶 |
| 丙酮酸氧化脱羧 | 丙酮酸脱氢酶复合体 |
| 糖原合成 | 糖原合酶 |
| 糖异生 | 丙酮酸羧化酶、磷酸烯醇式丙酮酸羧激酶、果糖二磷酸酶-1、葡萄糖-6-磷酸酶 |
| 三羧酸循环 | 异柠檬酸脱氢酶、$\alpha$-酮戊二酸脱氢酶复合体、柠檬酸合酶 |
| 脂肪酸合成 | 乙酰 $\mathrm{CoA}$ 羧化酶 |
| 脂肪酸分解 | 肉碱脂肪酰转移酶 $\mathrm{I}$ |
| 糖原分解 | 糖原磷酸化酶 |
| 胆固醇合成 | $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶 |
:::

:::pitfall{label="关键酶不是“活性最高的酶”"}
教材把它写成速度最慢的那一步（常在第一步或分支点），以及单向／非平衡反应。把关键酶听成“催化本领最大”，速率和方向两本账都会反。
:::

:::insight{label="表12-2 能对上前几章，也是思考题第4、第5题的入口"}
脂肪酸分解的关键酶是肉碱脂肪酰转移酶 $\mathrm{I}$：肉碱合成障碍时脂酰基进线粒体受阻，与低血糖那道思考题同一户头。肝细胞大量葡萄糖-6-磷酸时，糖原、戊糖磷酸途径、糖酵解、糖异生（葡萄糖-6-磷酸酶）的流量都会动。
:::

:::keypoint{label="细胞水平调节的时间轴"}
- 改结构（别构、化学修饰）：秒到分钟。
- 改含量（合成／降解）：小时到天。
- 改关键酶活性 $=$ 细胞水平的基本方式，也是激素和整体调节的落点。
:::

### （三）别构调节通过别构效应改变酶活性

**1. 别构调节是生物界普遍存在的代谢调节方式**　一些小分子化合物能与酶蛋白分子活性中心外的特定部位特异结合，改变酶蛋白分子构象，从而改变酶活性。别构调节在生物界普遍存在，表12-3 是一些代谢途径中的别构酶及其别构效应剂。

:::definition{label="别构调节"}
一些小分子化合物与酶蛋白分子活性中心外的特定部位特异结合，改变酶蛋白分子构象，从而改变酶活性。这是生物界普遍存在的代谢调节方式。
:::

:::

:::insight{label="表12-3 能把第二节的交叉再钉一遍"}
$\mathrm{ATP}$ 抑制磷酸果糖激酶-1、丙酮酸激酶、柠檬酸合酶、异柠檬酸脱氢酶——能量充足就关产能。柠檬酸抑制磷酸果糖激酶-1、激活乙酰 $\mathrm{CoA}$ 羧化酶——糖氧化下来的信号改写成脂。乙酰 $\mathrm{CoA}$ 激活丙酮酸羧化酶，给糖异生和草酰乙酸补料。
:::

**2. 别构效应剂通过改变酶分子构象改变酶活性**　别构效应剂能与别构酶的调节位点或调节亚基非共价键结合，引起酶活性中心构象变化，改变酶活性，从而调节代谢。别构效应的机制有两种。其一，酶的调节亚基含有一个“假底物”（pseudosubstrate）序列，当其结合催化亚基的活性位点时能阻止底物的结合，抑制酶活性；当效应剂分子结合调节亚基后，“假底物”序列构象变化，释放催化亚基，使其发挥催化作用。$\mathrm{cAMP}$ 激活 $\mathrm{cAMP}$ 依赖的蛋白激酶通过这种机制实现。其二，别构效应剂与调节亚基结合，能引起酶分子三级和／或四级结构在“$\mathrm{T}$”构象（紧密态、无活性／低活性）与“$\mathrm{R}$”构象（松弛态、有活性／高活性）之间互变，从而影响酶活性。氧对脱氧血红蛋白构象变化的影响通过该机制实现。

:::definition{label="别构效应剂"}
别构效应剂与别构酶的调节位点或调节亚基非共价键结合，引起酶活性中心构象变化，改变酶活性。
:::

:::definition{label="假底物机制"}
调节亚基含“假底物”（pseudosubstrate）序列，占据催化亚基活性位点则抑制酶；效应剂结合调节亚基后，假底物序列构象变化，释放催化亚基。$\mathrm{cAMP}$ 激活 $\mathrm{cAMP}$ 依赖的蛋白激酶走这条。
:::

:::definition{label="T 构象与 R 构象"}
别构效应剂使酶分子三级和／或四级结构在 $\mathrm{T}$ 构象（紧密态、无活性／低活性）与 $\mathrm{R}$ 构象（松弛态、有活性／高活性）之间互变。氧对脱氧血红蛋白构象的影响是这一机制的例子。
:::

:::compare{title="两种别构机制"}
| | 分子事件 | 教材例子 |
|--|----------|----------|
| 假底物序列 | 调节亚基堵住或放开催化亚基活性位点 | $\mathrm{cAMP}$ 激活 $\mathrm{cAMP}$ 依赖的蛋白激酶 |
| $\mathrm{T}\leftrightarrow\mathrm{R}$ | 紧密态／低活性 $\leftrightarrow$ 松弛态／高活性 | 氧对脱氧血红蛋白 |
:::

:::pitfall{label="别构结合是非共价的，不要写成磷酸化"}
效应剂与调节位点或调节亚基非共价键结合。共价修饰是下一小节化学修饰的账。$\mathrm{cAMP}$ 依赖的蛋白激酶本身先被别构打开，再去磷酸化别的酶，两步不要并户。
:::

**3. 别构调节使一种物质的代谢与相应的代谢需求和相关物质的代谢协调**　别构调节具有重要的生理意义。别构效应剂可能是酶的底物，也可能是酶促反应的终产物，或其他小分子代谢物。它们在细胞内浓度的改变能灵敏地反映相关代谢途径的强度和相应的代谢需求，并使关键酶构象改变影响酶活性，从而调节相应代谢的强度、方向，以协调相关代谢、满足相应代谢需求。

代谢终产物堆积表明其代谢过强，超过了需求，常可使其代谢途径的关键酶受到别构抑制，即反馈抑制（feedback inhibition），从而降低整个代谢途径的强度，避免产生超过需要的产物。如脂肪酰 $\mathrm{CoA}$ 可别构抑制乙酰 $\mathrm{CoA}$ 羧化酶，使代谢物的生成不致过多。别构调节可使机体根据需求生产能量，避免生产过多造成浪费。如 $\mathrm{ATP}$ 可别构抑制磷酸果糖激酶-1、丙酮酸激酶及柠檬酸合酶，从而抑制糖酵解、有氧氧化及三羧酸循环，使 $\mathrm{ATP}$ 的生成不致过多，造成浪费。

一些代谢中间产物可别构调节相关的多条代谢途径的关键酶，使这些代谢途径之间能协调进行。如在能量供应充足时，葡萄糖-6-磷酸抑制肌糖原磷酸化酶，阻断糖原分解，从而影响后续的糖酵解及有氧氧化，避免 $\mathrm{ATP}$ 产生过多；同时葡萄糖-6-磷酸激活糖原合酶，使过剩的磷酸葡萄糖合成糖原储存。再如，三羧酸循环活跃时，异柠檬酸增多，$\mathrm{ATP}/\mathrm{ADP}$ 比例增加，$\mathrm{ATP}$ 可别构抑制异柠檬酸脱氢酶，异柠檬酸别构激活乙酰 $\mathrm{CoA}$ 羧化酶，从而抑制三羧酸循环，增强脂肪酸合成。

:::definition{label="反馈抑制"}
代谢终产物堆积、超过需求时，常别构抑制该途径的关键酶，降低整条途径强度，避免产物过多。例如脂肪酰 $\mathrm{CoA}$ 别构抑制乙酰 $\mathrm{CoA}$ 羧化酶。
:::

:::cause-effect{title="ATP 高为什么连糖酵解和三羧酸循环一起关"}
- **因** $\mathrm{ATP}$ 别构抑制磷酸果糖激酶-1、丙酮酸激酶及柠檬酸合酶
- **果** 糖酵解、有氧氧化及三羧酸循环被抑制，$\mathrm{ATP}$ 生成不致过多造成浪费
:::

:::cause-effect{title="葡萄糖-6-磷酸怎样同时关分解、开储存"}
- **因** 能量供应充足时，葡萄糖-6-磷酸抑制肌糖原磷酸化酶，并激活糖原合酶
- **果** 糖原分解被阻断，后续糖酵解及有氧氧化减速；过剩的磷酸葡萄糖写成糖原
:::

:::cause-effect{title="三羧酸循环活跃时为什么转向脂肪酸合成"}
- **因** 异柠檬酸增多，$\mathrm{ATP}/\mathrm{ADP}$ 增加；$\mathrm{ATP}$ 抑制异柠檬酸脱氢酶，异柠檬酸激活乙酰 $\mathrm{CoA}$ 羧化酶
- **果** 三羧酸循环抑制，脂肪酸合成增强
:::

:::keypoint{label="别构的生理意义三句"}
- 效应剂浓度反映途径强度和需求。
- 终产物反馈抑制，避免过多。
- 中间物可同时拨多条途径，使相关代谢协调。
:::

### （四）化学修饰调节通过酶促共价修饰调节酶活性

**1. 酶促共价修饰有多种形式**　酶蛋白肽链上某些氨基酸残基侧链可在另一酶的催化下发生可逆的共价修饰，从而改变酶活性。酶的化学修饰主要有磷酸化与去磷酸化、乙酰化与去乙酰化、甲基化与去甲基化、腺苷化与去腺苷化及 $\mathrm{SH}$ 与 $-\mathrm{S}$-$\mathrm{S}$- 互变等，其中磷酸化与去磷酸化最多见（表12-4）。酶蛋白分子中丝氨酸、苏氨酸及酪氨酸的羟基是磷酸化修饰的位点，在蛋白质激酶（protein kinase）催化下，由 $\mathrm{ATP}$ 提供磷酸基及能量完成磷酸化；去磷酸化是蛋白质磷酸酶（protein phosphatase）催化的水解反应。所以，酶的磷酸化与去磷酸化反应是不可逆的，分别由蛋白质激酶及蛋白质磷酸酶催化（图12-3）。

::figure{src="/images/biochemistry/textbook/p0265_01.png" caption="图12-3　酶的磷酸化与去磷酸化。左侧酶蛋白 Ser/Thr/Tyr 带羟基；蛋白质激酶在 Mg2+ 存在下把 ATP 写成 ADP，羟基变成磷酸酯。右侧酶蛋白带 -O-PO32-；蛋白质磷酸酶加水水解，放出 Pi，回到羟基。两向由不同酶催化，不可逆。" alt="酶蛋白羟基与磷酸酯在蛋白质激酶和蛋白质磷酸酶之间循环"}

:::definition{label="化学修饰调节"}
酶蛋白肽链上某些氨基酸残基侧链在另一酶催化下发生可逆的共价修饰，从而改变酶活性。主要形式：磷酸化与去磷酸化、乙酰化与去乙酰化、甲基化与去甲基化、腺苷化与去腺苷化及 $\mathrm{SH}$ 与 $-\mathrm{S}$-$\mathrm{S}$- 互变。磷酸化与去磷酸化最多见。
:::

:::definition{label="磷酸化与去磷酸化"}
磷酸化位点是丝氨酸、苏氨酸及酪氨酸的羟基。蛋白质激酶以 $\mathrm{ATP}$ 提供磷酸基及能量完成磷酸化；蛋白质磷酸酶催化水解去磷酸化。两向反应不可逆，由两种酶分别催化。
:::

:::compare{title="表12-4　磷酸化／去磷酸化修饰对酶活性的调节"}
| 酶 | 化学修饰类型 | 酶活性改变（磷酸化／去磷酸化） |
|----|--------------|--------------------------------|
| 糖原磷酸化酶 | 磷酸化／去磷酸化 | 激活／抑制 |
| 磷酸化酶 $b$ 激酶 | 磷酸化／去磷酸化 | 激活／抑制 |
| 糖原合酶 | 磷酸化／去磷酸化 | 抑制／激活 |
| 丙酮酸激酶 | 磷酸化／去磷酸化 | 抑制／激活 |
| 磷酸果糖激酶 | 磷酸化／去磷酸化 | 抑制／激活 |
| $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶 | 磷酸化／去磷酸化 | 抑制／激活 |
| $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶激酶 | 磷酸化／去磷酸化 | 激活／抑制 |
| 乙酰 $\mathrm{CoA}$ 羧化酶 | 磷酸化／去磷酸化 | 抑制／激活 |
| 激素敏感性脂肪酶 | 磷酸化／去磷酸化 | 激活／抑制 |
:::

:::pitfall{label="磷酸化不是一律激活"}
糖原磷酸化酶、磷酸化酶 $b$ 激酶、$\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶激酶、激素敏感性脂肪酶：磷酸化激活。糖原合酶、丙酮酸激酶、磷酸果糖激酶、$\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶、乙酰 $\mathrm{CoA}$ 羧化酶：磷酸化抑制。分解侧常被磷酸化打开，合成侧常被磷酸化关上。
:::

:::insight{label="图12-3 把不可逆画成两个酶"}
同一羟基位点，上去靠激酶消耗 ATP，下来靠磷酸酶加水。不要画成一条可逆反应的正逆箭头由同一个酶催化。
:::

**2. 酶的化学修饰调节具有级联放大效应**　化学修饰调节具有如下特点：①绝大多数受化学修饰调节的关键酶都具有无活性（或低活性）和有活性（或高活性）两种形式，它们可分别在两种不同酶的催化下发生共价修饰，互相转变。催化互变的酶在体内受上游调节因素如激素控制。②酶的化学修饰是另一酶催化的酶促反应，一分子催化酶可催化多个底物酶分子发生共价修饰，特异性强，有放大效应。③磷酸化与去磷酸化是最常见的酶促化学修饰反应。酶的 $1$ 分子亚基发生磷酸化常需要消耗 $1$ 分子 $\mathrm{ATP}$，比合成酶蛋白所消耗的 $\mathrm{ATP}$ 要少得多，且作用迅速，又有放大效应，是调节酶活性经济有效的方式。④催化共价修饰的酶自身也常受别构调节、化学修饰调节，并与激素调节偶联，形成由信号分子（激素等）、信号转导分子和效应分子（受化学修饰调节的关键酶）组成的级联反应，使细胞内酶活性调节更精细协调。通过级联酶促反应，形成级联放大效应，只需少量激素释放即可产生迅速而强大的生理效应，满足机体的需要。

:::definition{label="化学修饰的级联放大"}
一分子催化酶可修饰多个底物酶分子。催化互变的酶又受上游激素等控制，并常自身被别构或再修饰，形成激素 $\rightarrow$ 信号转导分子 $\rightarrow$ 关键酶的级联。少量激素即可产生迅速而强大的生理效应。
:::

:::compare{title="别构调节与化学修饰调节"}
| | 别构 | 化学修饰 |
|--|------|----------|
| 键 | 非共价 | 共价 |
| 是否需另一酶催化 | 否（效应剂直接结合） | 是（激酶／磷酸酶等） |
| 起效 | 数秒或数分钟（同属快速调节） | 数秒或数分钟 |
| 放大 | 构象变化改变活性 | 酶促级联，一分子催化酶修饰多个底物酶 |
| 与激素 | 可被代谢物直接反映需求 | 常与激素信号偶联 |
| 耗能 | 不消耗 ATP 去做共价标记 | $1$ 分子亚基磷酸化常耗 $1$ 分子 ATP，仍远少于合成新酶蛋白 |
:::

:::keypoint{label="化学修饰四条特点"}
- 同一酶有无／低活性与有／高活性两型，由两种酶互变，上游受激素控制。
- 酶促反应，特异，有放大。
- 磷酸化最常见；耗 ATP 少、作用快、又有放大，经济有效。
- 修饰酶自身再被调节，与激素级联，少量激素即可强效应。
:::

:::insight{label="别构与化学修饰相辅相成"}
本章小结原句：别构调节与化学修饰调节相辅相成。$\mathrm{cAMP}$ 依赖的蛋白激酶先被 $\mathrm{cAMP}$ 别构打开，再磷酸化糖原磷酸化酶等——一张网里两种快速调节接在一起。
:::

### （五）通过改变细胞内酶含量调节酶活性

除改变酶分子结构外，改变酶含量也能改变酶活性，是重要的代谢调节方式。酶含量调节通过改变其合成或／和降解速率实现，消耗 $\mathrm{ATP}$ 较多，所需时间较长，通常要数小时甚至数日，属迟缓调节。

**1. 诱导或阻遏酶蛋白基因表达调节酶含量**　酶的底物、产物、激素或药物可诱导或阻遏酶蛋白基因的表达。诱导剂或阻遏剂在酶蛋白生物合成的转录或翻译过程中发挥作用，影响转录较常见。体内也有一些酶，其浓度在任何时间、任何条件下基本不变，几乎恒定。这类酶称为组成（型）酶（constitutive enzyme），如甘油醛-3-磷酸脱氢酶（glyceraldehyde 3-phosphate dehydrogenase，$\mathrm{GAPDH}$），常作为基因表达变化研究的内参照（internal control）。

酶的诱导剂经常是底物或类似物，如蛋白质摄入增多时，氨基酸分解代谢加强，鸟氨酸循环底物增加，可诱导参与鸟氨酸循环的酶合成增加。鼠饲料中蛋白质含量从 $8\%$ 增加至 $70\%$，鼠肝精氨酸酶活性可增加 $2\sim 3$ 倍。酶的阻遏剂经常是代谢产物，如 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶是胆固醇合成的关键酶，在肝内的合成可被胆固醇阻遏。但肠黏膜细胞中胆固醇的合成不受胆固醇的影响，摄取高胆固醇膳食，血胆固醇仍有升高的危险。很多药物和毒物可促进肝细胞微粒体单加氧酶（或混合功能氧化酶）或其他一些药物代谢酶的诱导合成，虽然能使一些毒物解毒，但也能使药物失活，产生耐药。

酶的诱导和阻遏普遍存在于生物界，但高等动物和人体内，由于蛋白质合成变化与激素调节、细胞信号传递偶联在一起，形成复杂的基因表达调控网络，单纯的代谢物水平诱导或阻遏不如微生物体内重要。

:::definition{label="组成（型）酶"}
组成（型）酶（constitutive enzyme）浓度在任何时间、任何条件下基本不变。例如甘油醛-3-磷酸脱氢酶（$\mathrm{GAPDH}$），常作为基因表达变化研究的内参照。
:::

:::definition{label="酶的诱导与阻遏"}
底物、产物、激素或药物可诱导或阻遏酶蛋白基因表达，作用于转录或翻译，影响转录较常见。诱导剂常是底物或类似物；阻遏剂常是代谢产物。
:::

:::compare{title="诱导和阻遏的教材例子"}
| | 信号 | 结果 |
|--|------|------|
| 诱导 | 蛋白质摄入增多 $\rightarrow$ 鸟氨酸循环底物增加 | 参与鸟氨酸循环的酶合成增加；鼠饲料蛋白质 $8\%\rightarrow 70\%$，肝精氨酸酶活性增加 $2\sim 3$ 倍 |
| 阻遏 | 胆固醇 | 肝内 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶合成被阻遏；肠黏膜细胞胆固醇合成不受胆固醇影响 |
| 药物／毒物 | 诱导肝微粒体单加氧酶等 | 毒物可解毒，药物也可失活而产生耐药 |
:::

:::pitfall{label="肝的胆固醇合成可被胆固醇阻遏，肠黏膜不能"}
高胆固醇膳食仍可使血胆固醇升高，因为肠黏膜这一头不听胆固醇阻遏。不要写成“全身胆固醇合成都被反馈关掉”。
:::

:::insight{label="人体里单纯代谢物诱导不如微生物重要"}
高等动物的酶量变化与激素、细胞信号偶联，形成基因表达调控网络。鼠肝精氨酸酶那个数字是代谢物诱导的例子，不要把它当成人体调节的主开关。
:::

**2. 改变酶蛋白降解速度调节酶含量**　改变酶蛋白分子的降解速度是调节酶含量的重要途径。细胞内酶蛋白的降解与许多非酶蛋白质的降解一样，有两条途径。溶酶体（lysosome）蛋白水解酶可非特异降解酶蛋白，而酶蛋白的特异性降解通过 $\mathrm{ATP}$ 依赖的泛素-蛋白酶体（proteasomes）途径完成。凡能改变或影响这两种蛋白质降解机制的因素均可主动调节酶蛋白的降解速度，进而调节酶含量。

:::definition{label="酶蛋白降解的两条途径"}
溶酶体蛋白水解酶非特异降解酶蛋白；特异性降解走 $\mathrm{ATP}$ 依赖的泛素-蛋白酶体途径。影响这两条机制的因素都可主动调节酶含量。
:::

:::compare{title="改结构还是改含量"}
| | 改酶分子结构 | 改酶含量 |
|--|--------------|----------|
| 手段 | 别构；化学修饰 | 诱导／阻遏合成；改变降解 |
| 耗能 | 别构不耗 ATP 做共价标记；磷酸化耗少量 ATP | 合成或降解消耗 ATP 较多 |
| 时间 | 秒到分钟 | 通常数小时甚至数日 |
:::

:::keypoint{label="酶含量调节"}
- 属迟缓调节。
- 合成端：诱导／阻遏，多见影响转录；$\mathrm{GAPDH}$ 是组成型内参照。
- 降解端：溶酶体非特异；泛素-蛋白酶体特异、依赖 ATP。
:::

## 二、激素通过特异性受体调节靶细胞的代谢

激素能与特定组织或细胞（即靶组织或靶细胞）的受体（receptor）特异结合，通过一系列细胞信号转导反应，引起代谢改变，发挥代谢调节作用。由于受体存在的细胞部位和特性不同，激素信号的转导途径和生物学效应也有所不同。

:::definition{label="激素调节代谢"}
激素与靶组织或靶细胞的受体特异结合，经细胞信号转导引起代谢改变。受体部位和特性不同，转导途径和生物学效应也不同。
:::

### （一）膜受体激素通过跨膜信号转导调节代谢

膜受体是存在于细胞质膜上的跨膜蛋白。与膜受体特异结合发挥作用的激素包括胰岛素、生长激素、促性腺激素、促甲状腺激素、甲状旁腺素、生长因子等蛋白质、肽类激素，及肾上腺素等儿茶酚胺类激素。这些激素亲水，不能透过脂双层构成的细胞质膜，而是作为第一信使分子与相应的靶细胞膜受体结合后，通过跨膜传递将所携带的信息传递到细胞内，再由第二信使将信号逐级放大，产生代谢调节效应。

:::definition{label="膜受体激素"}
膜受体是细胞质膜上的跨膜蛋白。胰岛素、生长激素、促性腺激素、促甲状腺激素、甲状旁腺素、生长因子等蛋白质／肽类激素，以及肾上腺素等儿茶酚胺类激素，亲水，不能透过脂双层，作为第一信使结合膜受体，经跨膜传递由第二信使逐级放大。
:::

### （二）胞内受体激素通过激素-胞内受体复合物调节代谢

胞内受体激素包括类固醇激素、甲状腺素、$1,25\text{-}(\mathrm{OH})_{2}$-维生素 $\mathrm{D}_3$ 及视黄酸等，为疏水激素，可透过脂双层的细胞质膜进入细胞，与相应的胞内受体结合。大多数胞内受体位于细胞核内，与相应激素特异结合形成激素受体复合物后，作用于 $\mathrm{DNA}$ 的特定序列即激素反应元件（hormone response element，$\mathrm{HRE}$），改变相应基因的转录，促进（或阻遏）蛋白质或酶的合成，调节细胞内酶含量，从而调节细胞代谢。存在于细胞质的胞内受体与激素结合后，形成的激素受体复合物进入核内，同样作用于激素反应元件，通过改变相应基因的表达发挥代谢调节作用。

:::definition{label="胞内受体激素"}
类固醇激素、甲状腺素、$1,25\text{-}(\mathrm{OH})_{2}$-维生素 $\mathrm{D}_3$ 及视黄酸等疏水激素，可透过脂双层，与胞内受体结合。大多数受体在核内；细胞质受体结合后复合物也进入核内。复合物作用于激素反应元件（$\mathrm{HRE}$），改变转录，调节酶含量。
:::

:::compare{title="膜受体与胞内受体"}
| | 膜受体激素 | 胞内受体激素 |
|--|------------|--------------|
| 化学性质 | 亲水（蛋白质、肽类、儿茶酚胺） | 疏水（类固醇、甲状腺素、$1,25\text{-}(\mathrm{OH})_{2}$-$\mathrm{D}_3$、视黄酸） |
| 能否过膜 | 不能 | 能 |
| 受体位置 | 细胞质膜跨膜蛋白 | 多数在核，也可先在细胞质再入核 |
| 信号方式 | 第一信使 $\rightarrow$ 跨膜 $\rightarrow$ 第二信使放大 | 激素-受体复合物 $\rightarrow$ $\mathrm{HRE}$ $\rightarrow$ 转录 |
| 主要落到 | 快速的酶活性改变（常接化学修饰级联） | 酶含量（迟缓调节） |
:::

:::pitfall{label="胞内受体不是都先停在细胞质"}
大多数胞内受体位于细胞核内。细胞质里的那一类结合后再入核，同样打 $\mathrm{HRE}$。不要一律写成“激素进细胞质找受体”。
:::

:::insight{label="两类激素最后仍落到细胞水平"}
膜受体激素常经第二信使接上磷酸化级联，改关键酶结构；胞内受体激素改酶含量。三级调节的第二级没有绕过第一级。
:::

## 三、机体通过神经系统及神经-体液途径协调整体的代谢

高等动物包括人的各组织器官高度分化，具有各自的功能和代谢特点。维持机体的正常功能、适应机体各种内外环境的改变，不仅需要在各组织器官的细胞内各种物质代谢彼此协调，在细胞水平上保持代谢平衡，还必须协调各组织器官之间的各种物质代谢。这就需要在神经系统主导下，调节激素释放，并通过激素整合不同组织器官的各种代谢，实现整体调节，以适应饱食、空腹、饥饿、营养过剩、应激等状态，维持整体代谢平衡。

:::definition{label="整体水平代谢调节"}
在神经系统主导下调节激素释放，通过激素整合不同组织器官的代谢，以适应饱食、空腹、饥饿、营养过剩、应激等状态，维持整体代谢平衡。
:::

:::concept{term="先问肝、肌、脑、脂肪各自干什么，再问胰岛素和胰高血糖素谁高"}
肝：糖原、糖异生、脂肪酸合成、VLDL、酮体。肌：肌糖原、蛋白质分解供丙氨酸和谷氨酰胺。脑和红细胞：优先用葡萄糖，长期饥饿脑改用酮体。脂肪组织：储存甘油三酯并在动员时释放脂肪酸。整体调节就是按膳食和饥饿把这四本账重新分配。
:::

### （一）饱食状态下机体物质代谢与膳食组成有关

通常情况下，人体摄入的膳食为混合膳食，经消化吸收后的主要营养物质以葡萄糖、氨基酸和 $\mathrm{CM}$ 形式进入血液，体内胰岛素水平中度升高。饱食状态下机体主要分解葡萄糖，为机体各组织器官供能。未被分解的葡萄糖，部分在胰岛素作用下，在肝合成肝糖原、在骨骼肌合成肌糖原贮存；部分在肝内转换为乙酰 $\mathrm{CoA}$，合成甘油三酯，以 $\mathrm{VLDL}$ 形式输送至脂肪等组织。若吸收的葡萄糖超过机体糖原贮存能力时，主要在肝大量转化成甘油三酯，由 $\mathrm{VLDL}$ 运输至脂肪组织贮存。吸收的甘油三酯部分经肝转换成内源性甘油三酯，大部分输送到脂肪组织、骨骼肌等转换、储存或利用。

人体摄入高糖膳食后，特别是总热量的摄入又较高时，体内胰岛素水平明显升高，胰高血糖素降低。在胰岛素作用下，小肠吸收的葡萄糖部分在骨骼肌合成肌糖原、在肝合成肝糖原和甘油三酯，后者输送至脂肪等组织储存；大部分葡萄糖直接被输送到脂肪组织、骨骼肌、脑等组织转换成甘油三酯等非糖物质储存或利用。

进食高蛋白膳食后，体内胰岛素水平中度升高，胰高血糖素水平升高。在两者协同作用下，肝糖原分解补充血糖、供应脑组织等。由小肠吸收的氨基酸主要在肝通过丙酮酸异生为葡萄糖，供应脑组织及其他肝外组织；部分氨基酸转化为乙酰 $\mathrm{CoA}$，合成甘油三酯，供应脂肪组织等肝外组织；还有部分氨基酸直接输送到骨骼肌。

进食高脂膳食后，体内胰岛素水平降低，胰高血糖素水平升高。在胰高血糖素作用下，肝糖原分解补充血糖、供给脑组织等。肌组织氨基酸分解，转化为丙氨酸，输送至肝异生为葡萄糖，供应血糖及肝外组织。由小肠吸收的甘油三酯主要输送到脂肪、肌组织等。脂肪组织在接受吸收的甘油三酯同时，也部分分解脂肪成脂肪酸，输送到其他组织。肝氧化脂肪酸，产生酮体，供应脑等肝外组织。

:::definition{label="混合膳食饱食"}
吸收后主要营养物质以葡萄糖、氨基酸和 $\mathrm{CM}$ 入血，胰岛素中度升高。机体主要分解葡萄糖供能。多余葡萄糖：肝糖原、肌糖原；肝内乙酰 $\mathrm{CoA}$ $\rightarrow$ 甘油三酯 $\rightarrow$ $\mathrm{VLDL}$ 送脂肪组织。超过糖原贮存能力时，主要在肝大量写成甘油三酯再经 $\mathrm{VLDL}$ 贮存。
:::

:::compare{title="饱食：三种膳食的激素和走向"}
| | 胰岛素 | 胰高血糖素 | 主要代谢印象 |
|--|--------|------------|--------------|
| 混合膳食 | 中度升高 | （未把升高写成主调） | 主分解葡萄糖；余糖写糖原或肝内甘油三酯（$\mathrm{VLDL}$） |
| 高糖（尤其总热量高） | 明显升高 | 降低 | 肝、肌写糖原；肝写甘油三酯；大部分葡萄糖直接送脂肪、肌、脑转换成非糖物质 |
| 高蛋白 | 中度升高 | 升高 | 两者协同：肝糖原分解供脑；氨基酸在肝异生为糖，部分写甘油三酯，部分送骨骼肌 |
| 高脂 | 降低 | 升高 | 肝糖原分解供脑；肌氨基酸 $\rightarrow$ 丙氨酸 $\rightarrow$ 肝糖异生；$\mathrm{CM}$ 送脂肪和肌；脂肪部分动员；肝产酮体供脑等 |
:::

:::pitfall{label="高蛋白膳食也会升高胰高血糖素，不是“有氨基酸就只升胰岛素”"}
高蛋白：胰岛素中度升高，胰高血糖素也升高，二者协同让肝糖原分解供脑，同时氨基酸在肝异生。高脂则是胰岛素降低、胰高血糖素升高。激素组合随膳食组成改变。
:::

:::insight{label="脑在饱食时仍然优先要糖"}
高蛋白、高脂膳食都专门写了“补充血糖、供应脑组织”。即使餐桌上主要是蛋白质或脂肪，脑这一头仍要葡萄糖（或高脂时的酮体）。组织特异从这里开始记账。
:::

:::keypoint{label="饱食四句话"}
- 混合：胰岛素中度升高，主烧葡萄糖，余糖写糖原或 $\mathrm{VLDL}$。
- 高糖：胰岛素明显升高，胰高血糖素降低。
- 高蛋白：胰岛素中度升高 $+$ 胰高血糖素升高，氨基酸异生供脑。
- 高脂：胰岛素降低 $+$ 胰高血糖素升高，肝糖原分解、肌丙氨酸异生、肝产酮体。
:::

### （二）空腹机体代谢以糖原分解、糖异生和中度脂肪动员为特征

空腹通常指至少 $8$ 小时内无任何热量摄入。此时体内胰岛素水平降低，胰高血糖素升高。事实上，在胰高血糖素作用下，餐后 $6\sim 8$ 小时肝糖原即开始分解补充血糖，主要供给脑，兼顾其他组织需要。餐后 $12\sim 18$ 小时，尽管肝糖原分解仍可持续进行，但由于肝糖原即将耗尽，能用于分解的糖原已经很少，所以肝糖原分解释放的葡萄糖占血糖水平的比例下降，主要靠糖异生补充血糖。同时，脂肪动员中度增加，释放脂肪酸供应肝、肌等组织利用。肝氧化脂肪酸，进而生成酮体，脑、肌组织等利用酮体供能比例增加。骨骼肌在接受脂肪组织输出的脂肪酸同时，部分蛋白质分解为氨基酸，补充肝糖异生的原料。

:::definition{label="空腹"}
空腹通常指至少 $8$ 小时内无任何热量摄入。胰岛素降低，胰高血糖素升高。特征是糖原分解、糖异生和中度脂肪动员。
:::

:::timeline{period="从餐后到空腹"}
- **餐后 6～8 小时** 胰高血糖素作用下肝糖原开始分解补血糖，主供脑，兼顾其他组织
- **餐后 12～18 小时** 肝糖原即将耗尽，分解来的葡萄糖占血糖比例下降，主要靠糖异生
- **同时** 脂肪动员中度增加；肝产酮体，脑和肌利用酮体比例增加
- **骨骼肌** 接受脂肪酸，同时部分蛋白质分解为氨基酸，补充肝糖异生原料
:::

:::compare{title="空腹时各组织的角色"}
| 组织 | 做什么 |
|------|--------|
| 肝 | 先糖原分解，后糖异生为主；氧化脂肪酸生成酮体 |
| 脑 | 优先用葡萄糖，酮体供能比例增加 |
| 肌 | 用脂肪酸和酮体；部分蛋白质分解供氨基酸 |
| 脂肪 | 中度动员，释放脂肪酸 |
:::

:::pitfall{label="空腹不是“已经在烧结构蛋白度日”"}
蛋白质分解在空腹已经开始，但是为糖异生补原料，脂肪动员只是中度。短期饥饿才把脂肪氧化写成大多数组织的主要能源；长期饥饿反而要减少蛋白质分解。时间档不要并成“不吃饭就是分解蛋白质”。
:::

### （三）饥饿时机体以氧化分解脂肪供能为主

**1. 短期饥饿后期糖氧化供能减少而脂肪动员加强**　短期饥饿通常指 $1\sim 3$ 天未进食。由于进食 $18$ 小时后肝糖原基本耗尽，短期饥饿使血糖趋于降低，血中甘油和游离脂肪酸明显增加，氨基酸增加；胰岛素分泌极少，胰高血糖素分泌增加，机体的代谢呈现如下特点。

（1）机体从葡萄糖氧化供能为主转变为脂肪氧化供能为主：除脑组织细胞和红细胞仍主要利用糖异生产生的葡萄糖，其他大多组织细胞减少对葡萄糖的摄取利用，对脂肪动员释放的脂肪酸及脂肪酸分解的中间代谢物——酮体摄取利用增加，脂肪酸和酮体逐渐成为机体的大多数组织的主要能源。

（2）肝糖异生作用明显增强：饥饿使体内糖异生作用增加，以饥饿 $16\sim 36$ 小时增加最多，糖异生生成的葡萄糖约为 $150\,\mathrm{g}/\mathrm{d}$，主要来自氨基酸，部分来自乳酸及甘油。肝是饥饿初期糖异生的主要场所，小部分在肾皮质。

（3）骨骼肌蛋白质分解加强：蛋白质分解增强略早于脂肪动员加强。蛋白质分解加强，释放入血的氨基酸增加。骨骼肌蛋白质分解的氨基酸大部分转变为丙氨酸和谷氨酰胺释放入血，作为肝糖异生的原料。

（4）脂肪动员加强且肝酮体生成增多：糖原耗尽后，白色脂肪组织中储存的脂肪在激素敏感性脂肪酶的作用下，逐步被水解，释放脂肪酸。脂肪酸可在肝内氧化，其中脂肪动员释放的脂肪酸约 $25\%$ 在肝氧化生成酮体。短期饥饿时，脂肪酸和酮体成为心肌、骨骼肌和肾皮质的重要供能物质，部分酮体可被大脑利用。

:::definition{label="短期饥饿"}
短期饥饿通常指 $1\sim 3$ 天未进食。进食 $18$ 小时后肝糖原基本耗尽。血糖趋于降低，血中甘油、游离脂肪酸和氨基酸增加；胰岛素极少，胰高血糖素增加。
:::

:::compare{title="短期饥饿四条代谢特点"}
| 特点 | 教材数字与组织 |
|------|----------------|
| 供能切换 | 大多数组织改用脂肪酸和酮体；脑和红细胞仍主要用糖异生的葡萄糖 |
| 糖异生明显增强 | $16\sim 36$ 小时达最多，约 $150\,\mathrm{g}/\mathrm{d}$；原料主要是氨基酸，部分乳酸及甘油；主场在肝，小部分肾皮质 |
| 肌蛋白质分解加强 | 略早于脂肪动员；大部分变成丙氨酸和谷氨酰胺供肝糖异生 |
| 脂肪动员 $+$ 酮体 | 激素敏感性脂肪酶水解白脂；约 $25\%$ 动员出的脂肪酸在肝生成酮体；脂肪酸和酮体供心肌、骨骼肌、肾皮质，部分酮体供大脑 |
:::

:::pitfall{label="短期饥饿时脑和红细胞并没有改用脂肪"}
“大多数组织”改用脂肪酸和酮体，但脑组织细胞和红细胞仍主要利用糖异生的葡萄糖。把脑写成“一开始就靠酮体”，和 $60\%$ 耗氧那一笔（长期饥饿）时间对不上。
:::

**2. 长期饥饿可造成器官损害甚至危及生命**　长期饥饿指未进食 $3$ 天以上，通常在饥饿 $4\sim 7$ 天后，机体发生与短期饥饿不同的代谢改变。

（1）脂肪动员进一步加强：释放的脂肪酸在肝内氧化生成大量酮体。脑利用酮体增加，超过葡萄糖，占总耗氧量的 $60\%$。脂肪酸成为肌组织的主要能源，以保证酮体优先供应脑。

（2）蛋白质分解减少：机体储存的蛋白质大量被消耗，继续分解就只能分解结构蛋白质，这将危及生命。所以机体蛋白质分解下降，释出氨基酸减少。

（3）糖异生明显减少：与短期饥饿相比，机体糖异生作用明显减少。乳酸和甘油成为肝糖异生的主要原料。随着饥饿时间延长，肾糖异生作用明显增强，每天生成约 $40\,\mathrm{g}$ 葡萄糖，占此时糖异生总量一半，几乎与肝相等。

饥饿发生后，机体血浆葡萄糖、脂肪酸、酮体的浓度变化示意图见图12-4。按理论计算，正常人脂肪储备可维持饥饿长达 $3$ 个月的基本能量需要。但由于长期饥饿使脂肪动员加强，大量产生酮体，由于酮体的主体 $\beta$-羟丁酸和乙酰乙酸均为酸性物质，会影响机体的酸碱平衡，从而可导致酸中毒。加之蛋白质的分解，缺乏维生素、微量元素和蛋白质的补充等，长期饥饿可造成器官损害甚至危及生命。

:::definition{label="长期饥饿"}
长期饥饿指未进食 $3$ 天以上，通常在饥饿 $4\sim 7$ 天后出现与短期饥饿不同的改变：脂肪动员进一步加强，脑用酮体超过葡萄糖（占总耗氧量 $60\%$）；蛋白质分解减少；糖异生明显减少，乳酸和甘油成为肝糖异生主原料，肾每天约 $40\,\mathrm{g}$ 葡萄糖，几乎与肝相等。
:::

:::compare{title="短期饥饿 vs 长期饥饿"}
| | 短期（$1\sim 3$ 天） | 长期（$>3$ 天，$4\sim 7$ 天后更明显） |
|--|---------------------|----------------------------------------|
| 脑的燃料 | 仍主要用糖异生的葡萄糖，部分用酮体 | 酮体超过葡萄糖，占耗氧 $60\%$ |
| 肌的燃料 | 脂肪酸和酮体已是重要能源 | 脂肪酸成为主要能源，把酮体让给脑 |
| 蛋白质 | 分解加强，供丙氨酸、谷氨酰胺 | 分解下降，保护结构蛋白 |
| 糖异生 | 明显增强，约 $150\,\mathrm{g}/\mathrm{d}$，主原料氨基酸，主场在肝 | 明显减少；肝用乳酸和甘油；肾约 $40\,\mathrm{g}/\mathrm{d}$，约占一半 |
:::

:::cause-effect{title="长期饥饿为什么会酸中毒并危及生命"}
- **因** 脂肪动员加强，大量酮体（主体为酸性的 $\beta$-羟丁酸和乙酰乙酸）影响酸碱平衡；蛋白质分解；缺乏维生素、微量元素和蛋白质补充
- **果** 可致酸中毒，造成器官损害甚至危及生命。脂肪储备理论上可维持约 $3$ 个月基本能量需要，并不等于可以安全饿三个月
:::

:::insight{label="图12-4 把三种血浆浓度画在同一时间轴上"}
葡萄糖虚线缓降后略回升；脂肪酸和酮体上升，约第 $3$ 日酮体超过脂肪酸。回升不是“又吃上饭了”，而是长期饥饿时脑改用酮体、糖异生减下来之后，血糖维持在较低水平的那条曲线。
:::

:::keypoint{label="饥饿数字"}
- 肝糖原：进食 $18$ 小时基本耗尽。
- 短期糖异生峰值：$16\sim 36$ 小时，约 $150\,\mathrm{g}/\mathrm{d}$。
- 动员脂肪酸约 $25\%$ 在肝生成酮体。
- 长期：脑酮体占耗氧 $60\%$；肾糖异生约 $40\,\mathrm{g}/\mathrm{d}$。
- 脂肪储备理论约 $3$ 个月；酸中毒和蛋白质／维生素缺乏限制了这个理论值。
:::

### （四）应激使机体分解代谢加强

应激（stress）是机体对特殊内外环境刺激作出一系列反应的“紧张状态”，这些刺激包括中毒、感染、发热、创伤、疼痛、大剂量运动或恐惧等。应激反应可以是“一过性”的，也可以是持续性的。应激状态下，交感神经兴奋，肾上腺髓质、皮质激素分泌增多，血浆胰高血糖素、生长激素水平增加，而胰岛素分泌减少，引起一系列代谢改变。

**1. 应激使血糖升高**　应激状态下肾上腺素、胰高血糖素分泌增加，激活糖原磷酸化酶，促进肝糖原分解。同时，肾上腺皮质激素、胰高血糖素又可使糖异生加强；肾上腺皮质激素、生长激素使外周组织对糖的利用降低。这些激素的分泌改变均可使血糖升高，对保证大脑、红细胞的供能有重要意义。

**2. 应激使脂肪动员增强**　血浆游离脂肪酸升高，成为心肌、骨骼肌及肾等组织主要能量来源。

**3. 应激使蛋白质分解加强**　骨骼肌释出丙氨酸等增加，氨基酸分解增强，尿素生成及尿氮排出增加，机体呈负氮平衡。

总之，应激时糖、脂质、蛋白质／氨基酸分解代谢增强，合成代谢受到抑制，血中分解代谢中间产物，如葡萄糖、氨基酸、脂肪酸、甘油、乳酸、尿素等含量增加（表12-5）。

:::definition{label="应激"}
应激（stress）是机体对特殊内外环境刺激作出一系列反应的“紧张状态”。刺激包括中毒、感染、发热、创伤、疼痛、大剂量运动或恐惧等。可以是一过性的，也可以是持续性的。
:::

:::definition{label="应激时的激素背景"}
交感神经兴奋，肾上腺髓质、皮质激素分泌增多，血浆胰高血糖素、生长激素增加，胰岛素分泌减少。
:::

:::compare{title="表12-5　应激时机体的代谢改变"}
| 内分泌腺／组织 | 激素及代谢变化 | 血中含量变化 |
|----------------|----------------|--------------|
| 垂体前叶 | $\mathrm{ACTH}$ 分泌增加；生长素分泌增加 | $\mathrm{ACTH}\uparrow$；生长素 $\uparrow$ |
| 胰腺 $\alpha$-细胞 | 胰高血糖素分泌增加 | 胰高血糖素 $\uparrow$ |
| 胰腺 $\beta$-细胞 | 胰岛素分泌抑制 | 胰岛素 $\downarrow$ |
| 肾上腺髓质 | 去甲肾上腺素／肾上腺素分泌增加 | 肾上腺素 $\uparrow$ |
| 肾上腺皮质 | 皮质醇分泌增加 | 皮质醇 $\uparrow$ |
| 肝 | 糖原分解增加、糖原合成减少、糖异生增强、脂肪酸 $\beta$-氧化增加 | 葡萄糖 $\uparrow$ |
| 骨骼肌 | 糖原分解增加、葡萄糖摄取利用减少、蛋白质分解增加、脂肪酸 $\beta$-氧化增强 | 乳酸 $\uparrow$、葡萄糖 $\uparrow$、氨基酸 $\uparrow$ |
| 脂肪组织 | 脂肪分解增强、葡萄糖摄取及利用减少、脂肪合成减少 | 游离脂肪酸 $\uparrow$、甘油 $\uparrow$ |
:::

:::cause-effect{title="应激为什么升高血糖还要保证脑和红细胞"}
- **因** 肾上腺素、胰高血糖素激活糖原磷酸化酶，促进肝糖原分解；皮质激素、胰高血糖素加强糖异生；皮质激素、生长激素降低外周组织对糖的利用
- **果** 血糖升高，保证大脑、红细胞供能；肌、心、肾改用脂肪酸
:::

:::pitfall{label="应激是分解加强、合成抑制，不是“代谢全面加快”"}
血中增加的是分解代谢中间产物：葡萄糖、氨基酸、脂肪酸、甘油、乳酸、尿素。蛋白质分解导致负氮平衡。不要写成合成也一起亢进。
:::

:::keypoint{label="应激三件套"}
- 血糖升高（保脑和红细胞）。
- 脂肪动员增强（游离脂肪酸供心、肌、肾）。
- 蛋白质分解加强（丙氨酸、尿素、负氮平衡）。
:::

### （五）代谢失衡会导致代谢性疾病

**1. 肥胖是多种重大慢性疾病的危险因素**　肥胖人群动脉粥样硬化、冠心病、脑卒中、糖尿病、高血压等疾病的风险显著高于正常人群，是这些疾病的主要危险因素之一。不仅如此，肥胖还与痴呆、脂肪肝病、呼吸道疾病和某些肿瘤的发生相关。现代医学将与心血管病、$2$ 型糖尿病发病相关的多种危险因素共存的症候群称为“代谢综合征”（metabolic syndrome），可表现为体脂，尤其是腹部脂肪过剩，高血压，胰岛素耐受，血浆胆固醇水平升高以及血浆脂蛋白异常等。这些危险因素的聚集，会大幅度增加心脏病、脑卒中和糖尿病等的发病风险。

:::definition{label="代谢综合征"}
与心血管病、$2$ 型糖尿病发病相关的多种危险因素共存的症候群，可表现为体脂（尤其腹部脂肪）过剩、高血压、胰岛素耐受、血浆胆固醇升高以及血浆脂蛋白异常。危险因素聚集会大幅度增加心脏病、脑卒中和糖尿病等发病风险。
:::

:::keypoint{label="肥胖相关疾病"}
- 主要危险因素之一：动脉粥样硬化、冠心病、脑卒中、糖尿病、高血压。
- 还相关：痴呆、脂肪肝病、呼吸道疾病和某些肿瘤。
:::

**2. 较长时间的能量摄入大于消耗导致肥胖**　过剩能量以脂肪形式储存是肥胖的基本原因，它源于神经内分泌改变引起的异常摄食行为和运动减少，涉及遗传、环境、膳食、运动等多种因素及复杂的分子机制。正常情况下，当能量摄入大于消耗、机体将过剩的能量以脂肪形式储存于脂肪细胞过多时，脂肪组织就会产生反馈信号作用于摄食中枢，调节摄食行为和能量代谢，不会产生持续性的能量摄入大于消耗。一旦这个神经内分泌机制失调，就会引起摄食行为、物质和能量代谢障碍，导致肥胖。

:::definition{label="肥胖的基本原因"}
较长时间能量摄入大于消耗，过剩能量以脂肪形式储存。源于神经内分泌改变引起的异常摄食行为和运动减少，涉及遗传、环境、膳食、运动及复杂分子机制。正常时脂肪组织反馈摄食中枢，不会持续入超；机制失调才导致肥胖。
:::

**（1）抑制食欲激素功能障碍引起肥胖**　食欲受一些激素调节。脂肪组织体积增加刺激瘦素分泌，通过血循环输送至下丘脑弓状核，与瘦素受体结合，抑制食欲和脂肪合成，同时刺激脂肪酸氧化，增加耗能，减少储脂。瘦素还能增加线粒体解偶联蛋白表达，使氧化与磷酸化解偶联，增加产热。此外，瘦素还有间接降低基础代谢率，影响性器官发育及生殖等作用。胆囊收缩素（cholecystokinin，$\mathrm{CCK}$）是小肠上段细胞在进食时分泌的肽类激素，可引起饱胀感，从而抑制食欲。能抑制食欲的激素还有 $\alpha$-促黑（素细胞）激素（$\alpha$-melanocyte-stimulating hormone，$\alpha$-$\mathrm{MSH}$）等。抑制食欲激素的功能障碍都可能引起肥胖。

:::definition{label="瘦素"}
脂肪组织体积增加刺激瘦素分泌，经血至下丘脑弓状核与瘦素受体结合：抑制食欲和脂肪合成，刺激脂肪酸氧化，增加耗能，减少储脂；增加解偶联蛋白表达使氧化磷酸化解偶联、增加产热。还有间接降低基础代谢率、影响性器官发育及生殖等作用。
:::

:::definition{label="胆囊收缩素与 α-MSH"}
胆囊收缩素（$\mathrm{CCK}$）由小肠上段细胞在进食时分泌，引起饱胀感，抑制食欲。$\alpha$-促黑（素细胞）激素（$\alpha$-$\mathrm{MSH}$）也能抑制食欲。这些抑制食欲激素功能障碍都可能引起肥胖。
:::

**（2）刺激食欲激素功能异常增强引起肥胖**　胃黏膜细胞分泌的生长激素释放激素（growth hormone-releasing hormone，$\mathrm{GHRH}$），通过血循环运送至脑垂体，与其受体结合，促进生长激素的分泌。在食欲调节方面，它能作用于下丘脑神经元，增强食欲。能增强食欲的激素还有神经肽 $\mathrm{Y}$（neuropeptide $\mathrm{Y}$，$\mathrm{NPY}$）。增强食欲激素功能异常增强，导致肥胖。如 Prader-Willi 综合征患者血生长激素释放激素极度升高，引起不可控制的强烈食欲，导致极度肥胖。

:::definition{label="GHRH 与神经肽 Y"}
胃黏膜细胞分泌的生长激素释放激素（$\mathrm{GHRH}$）经血至垂体促进生长激素分泌，并作用于下丘脑神经元增强食欲。神经肽 $\mathrm{Y}$（$\mathrm{NPY}$）也能增强食欲。功能异常增强导致肥胖。Prader-Willi 综合征患者血 $\mathrm{GHRH}$ 极度升高，强烈食欲，极度肥胖。
:::

**（3）肥胖患者脂连蛋白缺陷**　脂连蛋白（adiponectin）由脂肪细胞合成，是 $224$ 个氨基酸残基组成的多肽。它通过增加靶细胞内 $\mathrm{AMP}$ 浓度，激活 $\mathrm{AMPK}$，引起下游效应蛋白磷酸化，可促进骨骼肌对脂肪酸的摄取和氧化，抑制肝内脂肪酸合成和糖异生，促进肝、骨骼肌对葡萄糖的摄取和氧化分解。肥胖患者脂连蛋白表达下降，血中水平显著降低。

:::definition{label="脂连蛋白"}
脂连蛋白（adiponectin）由脂肪细胞合成，为 $224$ 个氨基酸残基的多肽。增加靶细胞 $\mathrm{AMP}$，激活 $\mathrm{AMPK}$，促进骨骼肌摄取和氧化脂肪酸，抑制肝内脂肪酸合成和糖异生，促进肝、骨骼肌摄取和氧化分解葡萄糖。肥胖患者表达下降，血中水平显著降低。
:::

**（4）胰岛素抵抗导致肥胖**　肥胖与高胰岛素血症，即胰岛素抵抗（insulin resistance）密切相关。正常情况下，胰岛素可通过下丘脑受体，抑制神经肽 $\mathrm{Y}$ 释放、刺激促黑（素细胞）激素产生，从而抑制食欲、减少能量摄入，增加产热、加大能量消耗；并通过一定信号途径促进骨骼肌、肝和脂肪组织分解代谢。瘦素、脂连蛋白可增加胰岛素的敏感性。所以，瘦素、脂连蛋白等与胰岛素敏感性有关因子的功能异常，都可引起胰岛素抵抗，导致肥胖。

总之，肥胖源于代谢失衡，它一旦形成，又反过来加重代谢紊乱，导致脂蛋白异常血症、冠心病、脑卒中等严重后果。如在肥胖形成期，靶细胞对胰岛素敏感，血糖降低，耐糖能力正常。在肥胖稳定期则表现出高胰岛素血症，组织对胰岛素抵抗，耐糖能力降低，血糖正常或升高。越肥胖或胰岛素抵抗，血糖浓度越高，糖代谢的紊乱程度越重。同时还引起脂代谢异常，表现为血浆总胆固醇及低密度脂蛋白-胆固醇（low-density lipoprotein cholesterol，$\mathrm{LDL}$-$\mathrm{C}$）升高、高密度脂蛋白胆固醇（high-density lipoprotein cholesterol，$\mathrm{HDL}$-$\mathrm{C}$）降低、甘油三酯升高等。

:::definition{label="胰岛素抵抗"}
肥胖与高胰岛素血症即胰岛素抵抗密切相关。正常时胰岛素经下丘脑受体抑制 $\mathrm{NPY}$、刺激促黑激素，从而抑制食欲、减少摄入、增加产热和消耗，并促进骨骼肌、肝和脂肪组织分解代谢。瘦素、脂连蛋白增加胰岛素敏感性；它们功能异常可引起胰岛素抵抗，导致肥胖。
:::

:::compare{title="肥胖形成期与稳定期"}
| | 胰岛素 | 血糖与耐糖 | 脂代谢 |
|--|--------|------------|--------|
| 形成期 | 靶细胞敏感 | 血糖降低，耐糖能力正常 | （尚未写成稳定期那组异常） |
| 稳定期 | 高胰岛素血症，组织抵抗 | 耐糖能力降低，血糖正常或升高；越肥胖或抵抗，血糖越高 | 总胆固醇及 $\mathrm{LDL}$-$\mathrm{C}$ 升高，$\mathrm{HDL}$-$\mathrm{C}$ 降低，甘油三酯升高 |
:::

:::compare{title="食欲相关激素"}
| | 来源 | 对食欲 | 其他教材点名的效应 |
|--|------|--------|----------------------|
| 瘦素 | 脂肪组织体积增加时分泌 | 抑制 | 抑脂肪合成、促脂肪酸氧化、增耗能、解偶联产热 |
| $\mathrm{CCK}$ | 小肠上段，进食时 | 抑制（饱胀感） | — |
| $\alpha$-$\mathrm{MSH}$ | （抑制食欲激素之一） | 抑制 | 胰岛素可刺激其产生 |
| $\mathrm{GHRH}$ | 胃黏膜细胞 | 增强 | 至垂体促生长激素分泌 |
| $\mathrm{NPY}$ | （增强食欲激素之一） | 增强 | 胰岛素抑制其释放 |
:::

:::pitfall{label="肥胖稳定期不是“胰岛素不够”"}
稳定期是高胰岛素血症加组织抵抗，耐糖能力降低。形成期靶细胞还敏感、血糖甚至降低。不要把肥胖一律写成胰岛素分泌不足。
:::

:::keypoint{label="肥胖这一段的因果链"}
- 入超且神经内分泌反馈失灵 $\rightarrow$ 持续以脂肪储存。
- 抑食欲激素（瘦素、$\mathrm{CCK}$、$\alpha$-$\mathrm{MSH}$）障碍，或促食欲激素（$\mathrm{GHRH}$、$\mathrm{NPY}$）过强。
- 脂连蛋白下降；胰岛素抵抗。
- 一旦形成，又加重脂蛋白异常、冠心病、脑卒中。
:::

## 本章小结

代谢是生命活动的物质基础。代谢分为分解代谢和合成代谢，由许多代谢途径组成。代谢具有整体性、动态性和可调节性。有些不同的代谢途径会共享某些酶促化学反应，所以，各种代谢途径相互联系、相互作用、相互协调和相互制约，形成一个网状的整体。体内各种营养物质通过形成各自共同的代谢库、两用代谢途径及还原当量的多种用途等，保障代谢处于一种动态的平衡之中。

细胞内多种物质的代谢同时进行，需要彼此间相互协调；高等动物包括人的各组织器官高度分化、具有各自的功能和代谢特点，各组织器官之间的各种物质的代谢也需要彼此协调，才能维持细胞、机体的正常功能、适应机体各种内外环境的改变。所以，机体内的各种物质的代谢虽然各不相同，但它们通过共同的中间代谢物、三羧酸循环和氧化磷酸化等形成彼此相互联系、相互转变、相互依存的统一的整体。糖、脂肪、蛋白质等营养物质在供应能量上可互相代替，并互相制约，但不能完全互相转变，因为有些代谢反应是不可逆的。

代谢组学的主要任务就是测定一个生物所有小分子代谢物的组成，描绘其动态变化规律，建立系统代谢图谱，并确定这些变化与基因及其表达以及生物过程的联系。

机体为了适应各种内外环境的变化，需要对各种物质代谢的方向、速率和流量进行精细调节，使各种物质的代谢井然有序，相互协调进行，以顺利完成各种生命活动。高等生物形成了三级代谢调节。代谢的细胞水平调节主要通过改变关键酶活性实现。其中，通过改变酶分子结构调节关键酶活性见效快，方式包括别构调节和化学修饰调节。化学修饰调节以磷酸化与去磷酸化为主；化学修饰调节具有放大效应。别构调节与化学修饰调节相辅相成。酶含量调节通过改变其合成或／和降解速率实现，作用缓慢但持久。激素水平代谢调节是激素通过与靶细胞受体特异结合及后续的一系列细胞信号转导反应，最终引起代谢改变。在神经系统主导下，机体通过调节激素释放，整合不同组织细胞内代谢途径，实现整体调节，以适应饱食、空腹、饥饿、营养过剩、应激等状态，维持整体代谢平衡。代谢失衡会导致代谢性疾病，如肥胖是多种疾病的危险影响因素。

:::definition{label="本章小结里的代谢共性"}
代谢分为分解与合成，由许多途径组成，具有整体性、动态性和可调节性。共同代谢库、两用途径及还原当量的多种用途保障动态平衡。
:::

:::definition{label="本章小结里的互变限度"}
糖、脂肪、蛋白质经共同中间代谢物、三羧酸循环和氧化磷酸化相互联系。供能上可互相代替并互相制约，但不能完全互相转变，因为有些反应不可逆。
:::

:::keypoint{label="本章小结按节收口"}
- 共性：整体、动态、可调节；代谢库、两用途径、还原当量。
- 交叉：乙酰 $\mathrm{CoA}$、三羧酸循环、氧化磷酸化；供能可替代，碳骨架不能完全互变。
- 代谢组学：全部小分子代谢物的组成、动态、系统图谱，及其与基因、表达、生物过程的联系。
- 三级调节：细胞是基础；别构 $+$ 化学修饰（磷酸化为主、有放大）见效快，二者相辅相成；酶含量缓慢持久。
- 激素经受体和信号转导；神经整合饱食、空腹、饥饿、营养过剩、应激。
- 失衡致病，肥胖是多种疾病的危险影响因素。
:::

## 思考题

1. 哪些化合物可以是糖、脂质、氨基酸代谢的枢纽物质？
2. 机体在饱食和空腹状态下的代谢有何区别？有何变化？
3. 酶的别构调节与化学修饰调节有何异同？
4. 为何肉碱合成障碍的患儿常见症状之一有低血糖？
5. 如果肝细胞中含有大量葡萄糖-6-磷酸，哪些代谢途径的流量会发生变化？
6. 若将机体某个细胞分离进行体外培养，试分析在培养液中应提供哪些成分以维持该细胞的存活？

:::tip{label="六道思考题在正文里的户头"}
- 枢纽物质：图12-1 蓝框（乙酰 $\mathrm{CoA}$、丙酮酸、草酰乙酸、$\alpha$-酮戊二酸、葡萄糖-6-磷酸等）；乙酰 $\mathrm{CoA}$ 不能逆行成丙酮酸。
- 饱食 vs 空腹：按混合／高糖／高蛋白／高脂分激素；空腹 $\ge 8$ 小时，餐后 $6\sim 8$ 小时肝糖原分解，$12\sim 18$ 小时糖异生为主，中度脂肪动员。
- 别构 vs 化学修饰：别构非共价；化学修饰共价、需另一酶、有级联放大；同属快速调节，相辅相成。
- 肉碱与低血糖：表12-2 关键酶是肉碱脂肪酰转移酶 $\mathrm{I}$。肉碱不足则 $\beta$-氧化和酮体供能不足，脑和红细胞仍要葡萄糖。本章未展开糖异生耗能细节，不要另造数字。
- 肝细胞大量葡萄糖-6-磷酸：可进糖原合成、戊糖磷酸途径、糖酵解；肝葡萄糖-6-磷酸酶可输出葡萄糖。不要把肌磷酸化酶的 $\mathrm{AMP}$ 激活抄到肝。
- 体外培养：提供可进代谢库的碳源／能源、氨基酸、必要脂质、维生素、无机盐和水。教材未给培养基配方。
:::

:::memory{label="本节必背要点"}
- [ ] 三级调节：细胞（基础）、激素、整体；后两级都通过细胞水平实现。
- [ ] 关键酶：第一步或分支点、最慢、单向／非平衡。快速＝别构＋化学修饰；迟缓＝酶含量。
- [ ] 别构非共价；假底物（PKA）或 T／R（血红蛋白）。$\mathrm{ATP}$ 抑制 PFK-1、丙酮酸激酶、柠檬酸合酶。肌／肝磷酸化酶别构剂不同。
- [ ] 磷酸化最多见；Ser／Thr／Tyr；激酶用 ATP、磷酸酶水解，两向不可逆。分解侧常磷酸化激活，合成侧常磷酸化抑制。有级联放大。
- [ ] GAPDH 组成型内参照。肝 HMG-CoA 还原酶可被胆固醇阻遏，肠黏膜不能。降解：溶酶体非特异；泛素-蛋白酶体特异。
- [ ] 膜受体：亲水，第一／第二信使。胞内受体：疏水，打 HRE，改酶含量。
- [ ] 空腹 $\ge 8$ 小时；餐后 $6\sim 8$ 小时肝糖原分解，$12\sim 18$ 小时糖异生为主。短期饥饿 $1\sim 3$ 天，糖异生峰值约 $150\,\mathrm{g}/\mathrm{d}$，约 $25\%$ 动员脂肪酸在肝成酮体。长期饥饿脑酮体占耗氧 $60\%$，肾糖异生约 $40\,\mathrm{g}/\mathrm{d}$。
- [ ] 应激：分解加强、胰岛素降、负氮平衡。肥胖：瘦素／CCK／α-MSH 抑食欲，GHRH／NPY 增食欲；脂连蛋白激活 AMPK；稳定期高胰岛素血症加抵抗。
:::
