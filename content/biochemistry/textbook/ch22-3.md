## 一、疾病相关基因的发现推动医学进入分子时代

分子医学（molecular medicine）就是从分子水平阐述疾病状态下基因组、基因、基因表达（转录与翻译）变化及其调控规律，推进高效预测、预防、诊断和治疗手段的发展。分子医学主体内容是分子生物学在医学中的应用，涵盖了其主要的理论和技术体系，其中的技术体系是开展该领域研究的核心内容。疾病基因组学、转录组学、蛋白质组学、代谢物组学等是分子医学发展的基础。

:::definition{label="分子医学"}
分子医学（molecular medicine）：从分子水平阐述疾病状态下基因组、基因、基因表达（转录与翻译）变化及其调控规律，推进高效预测、预防、诊断和治疗手段的发展。本版这一句是户头，不要改成「就是基因治疗」或「就是测序」。
:::

:::definition{label="分子医学的主体与基础"}
主体内容：分子生物学在医学中的应用，涵盖主要的理论和技术体系；技术体系是开展该领域研究的核心内容。发展基础：疾病基因组学、转录组学、蛋白质组学、代谢物组学等。
:::

:::compare{title="分子医学 vs 第一节的分子病"}
| | 本版落点 | 不要并户 |
|--|---------|---------|
| 分子病（第一节） | 蛋白质异常落到基因变异这一认识；本版在克隆并定位人 $\alpha$ 珠蛋白基因之后提出 | 不等于已经进入分子医学全套组学 |
| 分子医学（本节） | 疾病状态下基因组、基因、表达变化及其调控；预测、预防、诊断、治疗 | 不等于只研究一种分子病 |

问「镰状细胞贫血那一类蛋白质异常」走分子病；问「组学怎样改诊疗」走分子医学。
:::

:::pitfall{label="分子医学不是『只看基因组』"}
定义并列的是基因组、基因、基因表达（转录与翻译）变化及其调控。后面转录组学、蛋白质组学、代谢物组学都是基础。写成「分子医学＝读完基因组」，表达和代谢那两户就空了。
:::

:::keypoint{label="分子医学先立三句"}
- 水平：分子水平，对象是疾病状态下的基因组、基因、表达与调控。
- 目的：高效预测、预防、诊断和治疗。
- 基础：疾病基因组学、转录组学、蛋白质组学、代谢物组学。
:::

### （一）疾病基因组学阐明发病的分子基础

疾病相关基因和疾病易感性的遗传学基础是疾病基因组学研究的两大任务。定位克隆技术的发展极大地推动了疾病基因或疾病相关基因的发现和鉴定，该技术将疾病相关基因位点定位于某一染色体区域后，根据该区域的基因、$\mathrm{EST}$ 或模式生物所对应的同源区的已知基因等有关信息，直接进行基因突变筛查，从而可确定疾病相关基因。

:::definition{label="疾病基因组学的两大任务"}
①疾病相关基因；②疾病易感性的遗传学基础。两户都要答，不要只背「找致病基因」。
:::

:::definition{label="定位克隆在疾病基因组学里怎么用"}
把疾病相关基因位点定位于某一染色体区域后，根据该区域的基因、$\mathrm{EST}$ 或模式生物对应同源区的已知基因等信息，直接进行基因突变筛查，确定疾病相关基因。这是第二节「定位候选克隆」同一条路，本节用来说明疾病基因组学怎样落到基因。
:::

$\mathrm{SNP}$ 是疾病易感性的重要遗传学基础，例如，$\mathrm{APOE}$ 基因单个碱基变异与阿尔茨海默病（Alzheimer disease，$\mathrm{AD}$）的发生相关，趋化因子受体基因 $\mathrm{CCR}5$ 中一个单纯缺失突变会导致对 $\mathrm{HIV}$ 的抗性等。疾病基因组研究在全基因组 $\mathrm{SNP}$ 制图基础上，筛选和鉴定与疾病相关的 $\mathrm{SNP}$，从而阐明各种疾病易感人群的遗传学背景，为疾病的诊断和治疗提供新的理论基础。

:::definition{label="SNP 是易感性的重要遗传学基础"}
本版点名两例：$\mathrm{APOE}$ 单个碱基变异与阿尔茨海默病（$\mathrm{AD}$）发生相关；$\mathrm{CCR}5$ 单纯缺失突变导致对 $\mathrm{HIV}$ 的抗性。疾病基因组研究在全基因组 $\mathrm{SNP}$ 制图基础上筛选与疾病相关的 $\mathrm{SNP}$，阐明易感人群的遗传学背景。
:::

:::compare{title="两大任务各自先问什么"}
| 任务 | 先得到什么 | 本版手段 |
|------|-----------|---------|
| 疾病相关基因 | 位点内哪一个基因变异是病的分子基础 | 定位到区域后，按基因／$\mathrm{EST}$／同源基因直接突变筛查 |
| 疾病易感性的遗传学基础 | 人群里哪些 $\mathrm{SNP}$ 与易感相关 | 全基因组 $\mathrm{SNP}$ 制图，筛选与疾病相关的 $\mathrm{SNP}$ |

问「这个家系的单基因病基因在哪」走前一户；问「为什么有人容易得 $\mathrm{AD}$、有人对 $\mathrm{HIV}$ 有抗性」走后一户。
:::

:::pitfall{label="CCR5 缺失是抗性，不是易感增加"}
教材写的是「单纯缺失突变会导致对 $\mathrm{HIV}$ 的抗性」。这是易感性遗传学基础的反例：变异可以降低感染风险。写成「$\mathrm{CCR}5$ 缺失使人更容易得艾滋病」，例子就反了。
:::

:::insight{label="这里的 SNP 制图对着第一节的第三代标记"}
第一节：$\mathrm{SNP}$ 频率 $1\%$ 以上、平均每 $300\,\mathrm{bp}$ 一个、约占多态性 $90\%$，关联分析使全基因组定位成为可能。本节把它接到「易感人群的遗传学背景」。不要把 $\mathrm{SNP}$ 只答成「测序读出来的单碱基改变」——罕见变异那一户仍是第一节的账。
:::

### （二）药物基因组学揭示遗传变异对药物效能和毒性的影响

药物基因组学（pharmacogenomics）是功能基因组学与分子药理学的有机结合。药物基因组学以药物效应和安全性为目标，研究各种基因突变与药效及安全性的关系。正因为药物基因组学是研究基因序列变异及其对药物不同反应的科学，所以也是研究高效／特效药物的重要途径，通过它可为患者或者特定人群寻找合适的药物。

:::definition{label="药物基因组学"}
药物基因组学（pharmacogenomics）：功能基因组学与分子药理学的有机结合。以药物效应和安全性为目标，研究各种基因突变与药效及安全性的关系。是研究基因序列变异及其对药物不同反应的科学，也是研究高效／特效药物的重要途径，可为患者或特定人群寻找合适的药物。
:::

:::pitfall{label="不要用别的学科新闻稿替换本版定义"}
本版户头是「功能基因组学与分子药理学的有机结合」，目标是效应和安全性。不要改成「只研究肝药酶 $\mathrm{CYP}$」或「就是伴随诊断」。后文思考题第 $4$ 题（同一靶点药有人极佳、有人无效）对着这一户，不是对着肿瘤专章。
:::

药物基因组学广泛应用遗传学、基因组学、蛋白质组学和代谢组学信息来预测患病人群对药物的反应，从而指导临床试验和药物开发过程。不断涌现的各种生物分析技术，如基因变异检测技术、$\mathrm{SNP}$ 高通量扫描技术、药物作用显示技术、基因分型研究技术等，为药物基因组学的进一步发展提供了技术支撑。药物基因组学使药物治疗模式由诊断定向治疗转为基因定向治疗。

:::definition{label="药物基因组学用哪些组学、哪些技术"}
信息：遗传学、基因组学、蛋白质组学和代谢组学，用来预测患病人群对药物的反应，指导临床试验和药物开发。技术支撑：基因变异检测、$\mathrm{SNP}$ 高通量扫描、药物作用显示、基因分型研究等。
:::

:::definition{label="从诊断定向到基因定向"}
药物治疗模式由诊断定向治疗转为基因定向治疗。户头是「按基因反应选药」，不是取消诊断。
:::

:::compare{title="疾病基因组学 vs 药物基因组学"}
| | 主要问什么 | 本版钉子 |
|--|-----------|---------|
| 疾病基因组学 | 发病的分子基础、易感人群的遗传学背景 | 定位克隆筛突变；全基因组 $\mathrm{SNP}$ 制图 |
| 药物基因组学 | 遗传变异怎样改变药物效能和毒性 | 效应＋安全性；为患者或特定人群找合适的药；基因定向治疗 |

一个对着「会不会得病、为什么得病」；一个对着「同样诊断、药为什么有人有效有人毒」。
:::

:::insight{label="预测反应是为了指导试验和开发，不只是床旁开药"}
「预测患病人群对药物的反应，从而指导临床试验和药物开发过程。」药物基因组学从研发阶段就开始用，不是等药已经上市才做基因分型。
:::

### （三）转录组学可阐明疾病发生机制并推动新诊治方式的进步

利用转录组学，即通过比较研究正常和疾病条件下，或疾病不同阶段基因表达的差异情况，从而为阐明复杂疾病的发生发展机制、筛选新的诊断标志物、鉴定新的药物靶点、发展新的疾病分子分型技术以及开展个体化治疗提供理论依据。

:::definition{label="转录组学在分子医学里做什么"}
比较正常与疾病，或疾病不同阶段的基因表达差异。用来：阐明复杂疾病发生发展机制、筛选新诊断标志物、鉴定新药物靶点、发展新的疾病分子分型、开展个体化治疗。
:::

:::pitfall{label="比较对象有两种，不要只写患者 vs 正常人"}
教材并列「正常和疾病条件下」和「疾病不同阶段」。病程、预后那一条例子（冠状动脉疾病）靠的是后一种。写成「转录组学只做一次病例对照」，阶段差异和分子分型就没有了。
:::

例如，外周血转录物谱可作为冠状动脉疾病（coronary artery diseases，$\mathrm{CAD}$）诊断与病程、预后判定的生物标志物。CardioDx 发展了基于 $23$ 个基因表达谱的诊断试剂盒 Corus $\mathrm{CAD}$，适用于早期阻塞性 $\mathrm{CAD}$ 的诊断。再如，近年研究表明多种疾病（包括肿瘤）与 $\mathrm{miRNA}$ 密切相关，检测血清中 $\mathrm{miRNA}$ 表达谱可指示某些疾病的发生。目前已有 $\mathrm{HBV}$、心脏疾病（包括急性冠脉综合征、急性心肌梗死、高血压、心力衰竭等）、$2$ 型糖尿病和肝癌等的血清 $\mathrm{miRNA}$ 作为诊断标记物的报道。此外，$\mathrm{miRNA}$ 还可作为某些疾病治疗的潜在靶点，例如针对 $\mathrm{miRNA}$-$182$ 的反义寡聚核苷酸可以用于黑色素瘤肝转移的治疗。

:::definition{label="Corus CAD"}
外周血转录物谱可作为 $\mathrm{CAD}$ 诊断与病程、预后判定的生物标志物。CardioDx 的 Corus $\mathrm{CAD}$：基于 $23$ 个基因表达谱的诊断试剂盒，适用于早期阻塞性 $\mathrm{CAD}$。本版数字是 $23$，不要改成别的基因数。
:::

:::definition{label="血清 miRNA 的诊断与治疗"}
多种疾病（包括肿瘤）与 $\mathrm{miRNA}$ 密切相关；血清 $\mathrm{miRNA}$ 表达谱可指示某些疾病发生。本版已报道作为诊断标记物的：$\mathrm{HBV}$、心脏疾病（急性冠脉综合征、急性心肌梗死、高血压、心力衰竭等）、$2$ 型糖尿病、肝癌。治疗靶点例：针对 $\mathrm{miRNA}$-$182$ 的反义寡聚核苷酸，用于黑色素瘤肝转移。
:::

:::compare{title="转录组学两条例子"}
| | 测什么 | 用途 |
|--|--------|------|
| Corus $\mathrm{CAD}$ | 外周血 $23$ 个基因表达谱 | 早期阻塞性 $\mathrm{CAD}$ 诊断；也可作病程、预后标志 |
| 血清 $\mathrm{miRNA}$ | 表达谱 | 诊断标记（本版名单）；也可当治疗靶点（$\mathrm{miRNA}$-$182$） |

第二节图22-2 的 $\mathrm{RNA}$-$\mathrm{seq}$ 五步是「怎么测」；本节问「测完用来干什么」。
:::

:::keypoint{label="血清 miRNA 本版名单"}
- 诊断标记：$\mathrm{HBV}$；心脏疾病（急性冠脉综合征、急性心肌梗死、高血压、心力衰竭等）；$2$ 型糖尿病；肝癌。
- 治疗靶点：$\mathrm{miRNA}$-$182$ 反义寡聚核苷酸 → 黑色素瘤肝转移。
- 不要外补本版没写的癌种或 $\mathrm{miRNA}$ 编号。

### （四）蛋白质组学可发现和鉴别药物新靶点

药物作用靶点的发现与验证是新药发现阶段的重点和难点，成为制约新药开发速度的瓶颈。近年来，随着蛋白质组研究技术的不断进步，蛋白质组学在药物靶点的发现应用中亦显示出越来越重要的作用。

:::definition{label="蛋白质组学卡在新药的哪一步"}
靶点的发现与验证是新药发现阶段的重点和难点，是开发速度的瓶颈。蛋白质组学用来发现和鉴别药物新靶点。
:::

利用蛋白质组学不但可以发现和鉴定在疾病条件下表达异常的蛋白质（这类蛋白质可作为药物候选靶点），而且还可对疾病发生的不同阶段进行蛋白质变化分析，发现一些疾病不同时期的蛋白质标志物（其对药物发现不仅具有指导意义，也是未来诊断学和治疗学的理论基础）。许多疾病与信号转导异常有关，因而信号分子和途径可以作为治疗药物设计的靶点。在信号传递过程中涉及数十或数百个蛋白质分子，蛋白质—蛋白质相互作用发生在细胞内信号传递的所有阶段。而且，这种复杂的蛋白质作用的串联效应可以完全不受基因调节而自发地产生。通过与正常细胞作比较，掌握与疾病细胞中某个信号途径活性增强或丧失有关的蛋白质分子的变化，将为药物设计提供更为合理的靶点。

:::definition{label="蛋白质组学两条产出"}
①疾病条件下表达异常的蛋白质 → 药物候选靶点。②疾病不同阶段的蛋白质变化 → 不同时期的蛋白质标志物；既指导药物发现，也是未来诊断学和治疗学的理论基础。
:::

:::definition{label="信号途径上的蛋白质靶点"}
许多疾病与信号转导异常有关，信号分子和途径可作为治疗药物设计的靶点。传递过程涉及数十或数百个蛋白质；蛋白质—蛋白质相互作用发生在信号传递的所有阶段。
:::

:::insight{label="串联效应可以不受基因调节而自发产生"}
「这种复杂的蛋白质作用的串联效应可以完全不受基因调节而自发地产生。」只测基因组或转录组，不一定看见这条通路已经开或关。蛋白质组学这一户不能被疾病基因组学替代。
:::

:::definition{label="和正常细胞比通路活性"}
比较正常细胞与疾病细胞，掌握与某个信号途径活性增强或丧失有关的蛋白质分子变化，为药物设计提供更为合理的靶点。问的是「这条通路过强还是丧失」，不是只问「哪个蛋白质多了」。
:::

:::compare{title="转录组学标志物 vs 蛋白质组学靶点"}
| | 比较什么 | 本版用途 |
|--|---------|---------|
| 转录组学 | 正常／疾病，或不同阶段的基因表达 | 机制、诊断标志、药物靶点、分子分型、个体化治疗 |
| 蛋白质组学 | 疾病条件下异常蛋白质；不同阶段蛋白质变化；信号通路活性 | 候选靶点、分期标志物；通路增强或丧失指导药物设计 |

转录组可以提出靶点；蛋白质组还要面对「不受基因调节的串联效应」。
:::

:::pitfall{label="蛋白质标志物不只给诊断用"}
教材写它对药物发现有指导意义，也是未来诊断学和治疗学的理论基础。答成「蛋白质组学就是找肿瘤标志物」，靶点发现那一户就丢了。
:::

### （五）医学代谢组学提供新的疾病代谢物标志物

代谢组学经过十余年的发展，方法正日趋成熟，其应用已逐步渗透到生命科学研究领域的多个方面，在医学科学中亦日益彰显出其强有力的潜能。

与基因组学和蛋白质组学相比，代谢组学研究则侧重于代谢物的组成、特性与变化规律。在疾病条件下通过对某些代谢产物进行分析，并与正常人的进行比较，可发现和筛选出疾病新的生物标志物，对相关疾病作出早期预警，并发展新的有效的疾病诊断方法。例如通过代谢组学的研究，证实血清中 $\mathrm{VLDL}$、$\mathrm{LDL}$、$\mathrm{HDL}$ 和胆碱的含量／比值可以判断心脏病的严重程度；血清中脂蛋白颗粒的组成，如脂肪酸侧链的不饱和度、脂蛋白分子之间相互作用的强度（而不是脂质的绝对含量）是影响高血压病人收缩压的主要因素；通过比较病人与正常人尿样中嘌呤和嘧啶化合物图谱，能够实现绝大多数核苷酸相关代谢遗传疾病的诊断。

:::definition{label="代谢组学侧重什么"}
与基因组学和蛋白质组学相比，侧重于代谢物的组成、特性与变化规律。疾病条件下分析某些代谢产物，与正常人比较，发现新的生物标志物，做早期预警，发展新的诊断方法。
:::

:::definition{label="本版三条代谢组学例"}
①血清 $\mathrm{VLDL}$、$\mathrm{LDL}$、$\mathrm{HDL}$ 和胆碱的含量／比值 → 判断心脏病严重程度。②脂蛋白颗粒组成：脂肪酸侧链不饱和度、脂蛋白分子间相互作用强度（而不是脂质的绝对含量）→ 影响高血压病人收缩压的主要因素。③尿样嘌呤和嘧啶化合物图谱 → 绝大多数核苷酸相关代谢遗传疾病的诊断。
:::

:::pitfall{label="高血压那一例不是『血脂高不高』"}
教材写明「而不是脂质的绝对含量」。答成「代谢组学就是看胆固醇定量」，不饱和度和相互作用强度那一户就空了。
:::

:::compare{title="分子医学四块组学各管一层"}
| 组学 | 本版一句话 | 本节钉子 |
|------|-----------|---------|
| 疾病基因组学 | 发病的分子基础、易感性遗传学基础 | 定位克隆筛基因；$\mathrm{SNP}$ 制图；$\mathrm{APOE}$／$\mathrm{CCR}5$ |
| 转录组学 | 比较表达差异 | Corus $\mathrm{CAD}$（$23$ 基因）；血清 $\mathrm{miRNA}$ |
| 蛋白质组学 | 发现和鉴别药物新靶点 | 异常蛋白质、分期标志物、信号通路 |
| 代谢组学 | 代谢物组成、特性与变化 | 脂蛋白／胆碱；不饱和度与相互作用；尿嘌呤嘧啶 |

开篇「代谢物组学」和这里「代谢组学」是同一层，不要另立第五户。
:::

:::keypoint{label="分子时代这一节的收口"}
- 分子医学：分子水平讲基因组、基因、表达与调控，推进预测预防诊断治疗。
- 基础四组学：疾病基因组、转录组、蛋白质组、代谢物组。
- 药物基因组学：功能基因组学 × 分子药理学；诊断定向 → 基因定向。
- 例子按本版记，不外补数据库或 $\mathrm{miRNA}$ 名单。
:::

## 二、疾病相关基因鉴定是实现个体化精准医疗的前提

$2015$ 年 $1$ 月 $20$ 日，美国在其国情咨文中提出「精准医学计划（Precision Medicine Initiative）」，该计划致力于治愈癌症和糖尿病等疾病，目的是让所有人获得健康个性化信息。随后发布了精准医疗计划的相关细节。该计划将加快在基因组层面对疾病的认识，并将最新最好的技术、知识和治疗方法提供给临床医生，使医生能够准确了解病因、针对性用药。

:::definition{label="本版里的精准医学计划"}
$2015$ 年 $1$ 月 $20$ 日美国国情咨文提出 Precision Medicine Initiative。致力于治愈癌症和糖尿病等；目的是让所有人获得健康个性化信息。作用：加快基因组层面对疾病的认识；把最新最好的技术、知识和治疗方法给临床医生，准确了解病因、针对性用药。这是本节的历史句子，不是精准医学的定义本身。
:::

:::pitfall{label="不要用 2015 计划新闻稿替换精准医学定义"}
下一小节的定义才是本版户头：基因测序技术快速进步以及生物信息与大数据科学交叉应用背景下的新型医学概念和医疗模式；将个人基因、环境与生活习惯差异考虑在内的新兴疾病预防与治疗方法。国情咨文可以当时间锚，不能当定义全文。
:::

:::insight{label="鉴定基因是前提，不是精准医疗已经完成"}
标题写的是「疾病相关基因鉴定是实现个体化精准医疗的前提」。第一节、第二节把基因找到，本节才问怎样「量体裁衣」。写成「做完 $\mathrm{GWAS}$ 就是精准医学」，四个层面和临床试验那一户就没有了。
:::

### （一）精准医学依据个人基因组信息实现个体化精准医疗

精准医学（precision medicine）是指在基因测序技术快速进步以及生物信息与大数据科学交叉应用背景下发展起来的新型医学概念和医疗模式，是一种将个人基因、环境与生活习惯差异考虑在内的新兴的疾病预防与治疗方法。

:::definition{label="精准医学"}
精准医学（precision medicine）：在基因测序技术快速进步以及生物信息与大数据科学交叉应用背景下发展起来的新型医学概念和医疗模式；是一种将个人基因、环境与生活习惯差异考虑在内的新兴的疾病预防与治疗方法。
:::

精准医学的本质是通过基因组、蛋白质组等组学技术和医学前沿技术（如现代遗传技术、分子影像技术、生物信息技术等），并结合患者生活环境和临床数据，对于大样本人群与特定疾病类型进行生物标记物的分析与鉴定、验证与应用，从而精确寻找到疾病的病因和治疗的靶点，并对一种疾病不同状态和过程进行精确分类，制定具有个性化的疾病预防和诊疗方案（包括对风险的精确预测、疾病精确诊断、疾病精确分类、药物精确应用、疗效精确评估、疗后精确预测等），最终实现对于疾病和特定患者进行个性化精准治疗的目的，提高疾病诊治与预防的效益。其目的就是全面推动个体基因组研究，依据个人基因组信息「量体裁衣式」（tailored）制定最佳的个性化治疗方案，以达到疗效最大化和副作用最小化。

:::definition{label="精准医学的本质"}
组学技术（基因组、蛋白质组等）＋医学前沿技术（现代遗传技术、分子影像技术、生物信息技术等）＋患者生活环境和临床数据。对大样本人群与特定疾病类型做生物标记物的分析与鉴定、验证与应用 → 精确找到病因和治疗靶点 → 对一种疾病不同状态和过程精确分类 → 个性化预防和诊疗方案。
:::

:::definition{label="六个精确"}
风险的精确预测、疾病精确诊断、疾病精确分类、药物精确应用、疗效精确评估、疗后精确预测。六句都要能点名，不要只答「精确诊断」。
:::

:::definition{label="量体裁衣式"}
全面推动个体基因组研究，依据个人基因组信息 tailored 制定最佳个性化治疗方案，疗效最大化、副作用最小化。英文 tailored 是本版原词，不要改成别的口号。
:::

:::compare{title="分子医学 vs 精准医学"}
| | 本版原句重心 | 还要算什么 |
|--|-------------|-----------|
| 分子医学 | 分子水平阐述基因组、基因、表达变化及其调控；推进预测预防诊断治疗 | 四块组学是基础 |
| 精准医学 | 测序＋生物信息＋大数据下的新型概念和医疗模式 | 个人基因、环境与生活习惯差异；生活环境与临床数据 |

分子医学回答「在哪一层看疾病」；精准医学回答「怎样按这个人来防和治」。
:::

:::pitfall{label="精准医学不是只看个人基因"}
定义写了个人基因、环境与生活习惯；本质里还有生活环境和临床数据、大样本人群与特定疾病类型的生物标记物。写成「测完个人基因组就是精准医学」，环境和生活习惯那两户空了，大样本验证也空了。
:::

:::keypoint{label="精准医学定义三截"}
- 背景：测序进步＋生物信息与大数据交叉。
- 身份：新型医学概念和医疗模式；把基因、环境、生活习惯差异算进去的预防与治疗。
- 目的：量体裁衣，疗效最大、副作用最小。
:::

### （二）精准医学分为短期和长远两个目标

精准医学分为短期目标和长远目标。精准医学的短期目标就是癌症治疗。癌症是常见的疾病，其全球发病率和死亡率逐年上升，而目前临床上尚缺乏有效的、针对性强的治疗方法。精准医学希望通过个体基因组研究，发现和鉴定与癌症发生发展相关的基因和调控因子，发掘新的肿瘤标志物，发展新的肿瘤分子分型技术，开展基于个体基因组的个体化治疗方法与技术。例如，药物伊马替尼（Imatinib）抑制慢性骨髓性白血病 $\mathrm{BCR}$-$\mathrm{ABL}$ 融合基因发挥作用；药物克唑替尼（crizotinib）靶向作用于遗传异常的间变性淋巴瘤激酶（$\mathrm{ALK}$）基因，用于 $\mathrm{ALK}$ 阳性的局部晚期或转移的非小细胞肺癌（$\mathrm{NSCLC}$）的治疗。

:::definition{label="精准医学的短期目标"}
短期目标就是癌症治疗。理由：常见；全球发病率和死亡率逐年上升；临床上尚缺乏有效的、针对性强的治疗方法。做法：个体基因组研究 → 与癌症发生发展相关的基因和调控因子、新的肿瘤标志物、新的肿瘤分子分型、基于个体基因组的个体化治疗。
:::

:::definition{label="本版两个靶向药例"}
伊马替尼（Imatinib）：抑制慢性骨髓性白血病 $\mathrm{BCR}$-$\mathrm{ABL}$ 融合基因。克唑替尼（crizotinib）：靶向遗传异常的 $\mathrm{ALK}$ 基因，用于 $\mathrm{ALK}$ 阳性的局部晚期或转移的 $\mathrm{NSCLC}$。基因、病名、适应证按本版记，不要改写成别的激酶抑制剂名单。
:::

精准医学的长期目标是健康管理。精准医学通过科技进步，将其优势拓展到健康和医疗的各个方面，从而提升对疾病风险评估，对疾病发生、发展和转归机制的认识，以及对疾病最佳治疗方案的预测、制订与实施，为健康和卫生保健等诸多领域带来最大利益。

:::definition{label="精准医学的长期目标"}
长期目标是健康管理。把优势拓展到健康和医疗的各个方面：提升疾病风险评估；提升对发生、发展和转归机制的认识；提升对最佳治疗方案的预测、制订与实施；为健康和卫生保健带来最大利益。
:::

:::compare{title="短期目标 vs 长期目标"}
| | 本版原句 | 落到什么 |
|--|---------|---------|
| 短期 | 癌症治疗 | $\mathrm{BCR}$-$\mathrm{ABL}$／伊马替尼；$\mathrm{ALK}$／克唑替尼；标志物与分子分型 |
| 长期 | 健康管理 | 风险评估、机制认识、方案预测制订实施；卫生保健最大利益 |

问「现在先攻什么」答癌症；问「最终拓展到哪」答健康管理。不要把长期目标写成「把所有癌症治好」——那仍是短期这一户的疾病名单。
:::

:::pitfall{label="短期目标写癌症，不等于本节改写成癌症专章"}
伊马替尼、克唑替尼是精准医学的例子。原癌基因、抑癌基因、多阶段致癌是后面专章的账，不要在本节展开。
:::

### （三）精准医疗是精确诊断和靶向治疗的结合

精准医学是一项系统工程，它包括了 $4$ 个层面的内容：如何发现功能性的遗传信息异常；如何发现针对这些异常的精准靶向药物；如何通过临床试验确定这些药物的疗效；如何在临床实践中使用，缺一不可。简单地说，精准医疗是精确诊断和靶向治疗的结合。

:::definition{label="精准医学四个层面"}
①发现功能性的遗传信息异常；②发现针对这些异常的精准靶向药物；③通过临床试验确定这些药物的疗效；④在临床实践中使用。缺一不可。
:::

:::definition{label="精准医疗"}
简单地说，精准医疗是精确诊断和靶向治疗的结合。本版用「精准医学」指概念和模式，「精准医疗」指诊断＋靶向这一句收口。两词不要混成只有「测序」。
:::

:::cause-effect{title="四个层面为什么缺一不可"}
- **因** 只发现遗传异常，没有靶向药物
- **果** 精确诊断落不到治疗
- **因** 有药但不经临床试验确定疗效
- **果** 不能进入临床实践
- **因** 试验有效但不在实践中使用
- **果** 系统工程仍未闭环
:::

我国于 $2016$ 年正式启动国家重点研发计划「精准医学研究」重点专项，按照全链条部署、一体化实施的原则，部署新一代临床用生命组学技术研发，大规模人群队列研究，精准医学大数据的资源整合、存储、利用与共享平台建设，疾病防诊治方案的精准化研究，精准医学集成应用示范体系建设等五大研究任务。自「精准医学计划」提出后，精准医疗概念迅速席卷全球，近年来更呈逐年加速趋势，各种新技术、新产品不断出现，技术进步推动基因组测序、靶向药物研制、细胞免疫治疗、基因治疗等进入新的阶段。

:::definition{label="2016 年五大研究任务"}
国家重点研发计划「精准医学研究」重点专项，$2016$ 年正式启动。原则：全链条部署、一体化实施。五大任务：①新一代临床用生命组学技术研发；②大规模人群队列研究；③精准医学大数据的资源整合、存储、利用与共享平台建设；④疾病防诊治方案的精准化研究；⑤精准医学集成应用示范体系建设。
:::

:::definition{label="技术进步推进的四件事"}
基因组测序、靶向药物研制、细胞免疫治疗、基因治疗进入新的阶段。本版点名这四项，不外补。
:::

:::compare{title="美国 2015 计划 vs 我国 2016 专项"}
| | 本版时间 | 写了什么 |
|--|---------|---------|
| Precision Medicine Initiative | $2015$ 年 $1$ 月 $20$ 日国情咨文 | 癌症和糖尿病等；健康个性化信息；基因组层面认识；针对性用药 |
| 「精准医学研究」重点专项 | $2016$ 年正式启动 | 五大任务：组学技术、人群队列、大数据平台、防诊治方案精准化、集成应用示范 |

时间锚可以记；定义仍用「测序＋生物信息＋大数据」「基因、环境、生活习惯」那一句。
:::

:::keypoint{label="精准医学这一节的尺子"}
- 定义：测序＋生物信息＋大数据；基因、环境、生活习惯。
- 本质：组学＋前沿技术＋环境与临床数据 → 生物标记物 → 病因和靶点 → 六个精确。
- 短期癌症、长期健康管理。
- 四个层面缺一不可；精准医疗＝精确诊断＋靶向治疗。
- $2016$ 五大任务按名单答。
:::

## 三、转化医学是加速基础研究实际应用的重要路径

转化医学（translational medicine）强调以临床问题为导向，开展基础—临床联合攻关，将基因组学等各种分子生物学研究成果迅速有效地转化为可在临床实际应用的理论、方法、技术和药物。

:::definition{label="转化医学"}
转化医学（translational medicine）：以临床问题为导向，开展基础—临床联合攻关，将基因组学等各种分子生物学研究成果迅速有效地转化为可在临床实际应用的理论、方法、技术和药物。
:::

:::pitfall{label="转化医学不是『把论文发表就算转化』"}
教材要的是可在临床实际应用的理论、方法、技术和药物。导向是临床问题，不是实验室兴趣。写成「基础研究多就是转化医学」，后文 $\mathrm{B}2\mathrm{B}$ 快速通道就没有对象。
:::

:::compare{title="分子医学、精准医学、转化医学三户"}
| | 本版原句重心 | 先问什么 |
|--|-------------|--------- |
| 分子医学 | 分子水平阐述疾病状态下基因组、基因、表达变化及其调控 | 看哪一层、用哪几块组学 |
| 精准医学 | 按个人基因、环境、生活习惯差异来预防和治疗 | 怎样量体裁衣、四个层面是否齐 |
| 转化医学 | 临床问题导向，基础—临床联合，成果变成能用的理论方法技术和药物 | 实验室到病床的通道通不通 |

三户都从疾病相关基因鉴定往临床走，不要并成一个词。
:::

### （一）转化医学的产生基于多方面的原因

转化医学产生的背景主要基于以下几个方面：①基础研究与临床问题解决之间严重脱节；②疾病谱的转变使医疗成本大大增加；③基础科学研究积累大量数据的意义需要解析；④基础研究和药物开发及医学实践三者需要整合。因此，围绕以临床问题为导向，开展医学科学实践，是解决医学根本性问题的有效途径，这也是转化医学的根本目的。

:::definition{label="转化医学产生的四条背景"}
①基础研究与临床问题解决严重脱节；②疾病谱转变使医疗成本大大增加；③基础科学积累大量数据的意义需要解析；④基础研究、药物开发和医学实践三者需要整合。
:::

:::definition{label="转化医学的根本目的"}
围绕以临床问题为导向，开展医学科学实践，解决医学根本性问题。四条背景收在这一句上，不要只背「脱节」。
:::

:::cause-effect{title="四条背景怎样逼出转化医学"}
- **因** 基础与临床脱节
- **果** 成果到不了病床
- **因** 疾病谱转变、成本增加
- **果** 必须提高防治效益
- **因** 数据大量堆积
- **果** 意义需要解析，不能只堆组学
- **因** 基础、药物开发、医学实践三分家
- **果** 需要整合，这就是转化医学要做的
:::

:::insight{label="组学数据多，本身不是转化已经完成"}
第三条写的是「积累大量数据的意义需要解析」。分子医学把组学立为基础；转化医学问这些数据对临床问题有没有答案。只答「测得越全越好」，解析和整合两户空了。
:::

### （二）转化医学是连接基础研究与临床应用的重要桥梁

转化医学是将基础医学研究和临床治疗连接起来的一种新的思维方式。其核心是要在实验室和病床（bench to bedside，简称 $\mathrm{B}2\mathrm{B}$）之间架起一条快速通道，把基础研究获得的知识成果快速转化为临床和公共卫生方面的防治新方法。

:::definition{label="B2B"}
bench to bedside，简称 $\mathrm{B}2\mathrm{B}$：在实验室和病床之间架起一条快速通道，把基础研究获得的知识成果快速转化为临床和公共卫生方面的防治新方法。转化医学是连接基础医学研究和临床治疗的一种新的思维方式。
:::

:::pitfall{label="B2B 不只到专科病房"}
教材写的是「临床和公共卫生方面的防治新方法」。通道的出口包括公共卫生，不只是单个患者的靶向药。
:::

转化医学的目标就是将生命科学和生物技术及相关的现代科学技术相整合、转变现有的医学模式，推动医疗改革，提高人民的健康水平和生活质量，从而达到更精确的预警与诊断，更有效的干预和治疗，降低发病率、推迟发病平均年龄，提高治愈率、减少重症病人，以及降低医疗的综合成本。

:::definition{label="转化医学的目标"}
整合生命科学、生物技术及相关现代科学技术；转变现有医学模式；推动医疗改革；提高健康水平和生活质量。具体达到：更精确的预警与诊断；更有效的干预和治疗；降低发病率；推迟发病平均年龄；提高治愈率；减少重症病人；降低医疗综合成本。
:::

:::compare{title="精准医学的效益句 vs 转化医学的目标句"}
| | 本版怎么写效益 |
|--|----------------|
| 精准医学 | 疗效最大化、副作用最小化；提高疾病诊治与预防的效益 |
| 转化医学 | 更精确预警诊断、更有效干预治疗；降发病率、推迟发病平均年龄、提高治愈率、减少重症、降低综合成本 |

问「这个患者怎样选药」走精准医学；问「基础成果怎样变成可应用的防治新方法、怎样降成本」走转化医学。
:::

:::keypoint{label="转化医学三句"}
- 定义：临床问题导向，基础—临床联合，成果变成能用的理论、方法、技术和药物。
- 背景四条：脱节、成本、数据待解析、三者需整合。
- 核心：$\mathrm{B}2\mathrm{B}$ 快速通道，出口到临床和公共卫生。
:::

## 本章小结

人类几乎所有的疾病都是遗传因素和环境因素相互作用的结果。依据基因变异在疾病发生发展中的作用，可将疾病相关基因分为致病基因和疾病易感基因。单核苷酸多态性（$\mathrm{SNP}$）、拷贝数目变异（$\mathrm{CNV}$）、短串联重复序列（$\mathrm{STR}$）等遗传标记在疾病相关基因鉴定中有重要作用。

疾病相关基因鉴定应遵循一定的原则。疾病相关基因鉴定的策略和方法主要包括：不依赖染色体定位的疾病相关基因克隆策略、定位克隆、全基因组关联研究、全外显子组测序／全基因组测序法。基于连锁分析的定位克隆技术在早期单基因病致病基因的发现和鉴定中取得了很大成功；现在基于 $\mathrm{SNP}$ 分析的全基因组关联研究、全外显子组／全基因组测序在疾病相关基因鉴定中发挥越来越重要的作用。

疾病相关基因—疾病数据库是专门收集和整理疾病相关基因信息的数据库（如：$\mathrm{OMIM}$、$\mathrm{GWAS}$ catalog、Orphanet、$\mathrm{DisGeNET}$、$\mathrm{HGMD}$、GeneCards 等），为研究人员提供方便和高效的资源，帮助研究和理解基因与疾病之间的关联。

随着人类基因组计划的完成以及各种组学的不断发展及其原理／技术与医学、药学等领域交叉，产生了分子医学、精准医学、转化医学等现代医学概念。人们有望从分子水平突破对疾病的传统认识，改变和革新现有的诊断、治疗模式。

:::definition{label="本章小结里的疾病相关基因"}
几乎所有疾病都是遗传因素和环境因素相互作用的结果。按变异作用分成致病基因和疾病易感基因。标记：$\mathrm{SNP}$、$\mathrm{CNV}$、$\mathrm{STR}$ 等。
:::

:::definition{label="本章小结里的鉴定策略"}
不依赖染色体定位的克隆、定位克隆、全基因组关联研究、全外显子组／全基因组测序。早期：连锁分析的定位克隆对单基因病。现在：基于 $\mathrm{SNP}$ 的 $\mathrm{GWAS}$、全外显子组／全基因组测序。
:::

:::definition{label="本章小结里的数据库"}
专门收集和整理疾病相关基因信息。本版点名：$\mathrm{OMIM}$、$\mathrm{GWAS}$ catalog、Orphanet、$\mathrm{DisGeNET}$、$\mathrm{HGMD}$、GeneCards 等。只写这些，不外补全网名单。
:::

:::definition{label="本章小结里的三个现代医学概念"}
人类基因组计划完成，组学原理／技术与医学、药学交叉，产生分子医学、精准医学、转化医学。目的：从分子水平突破传统认识，改变和革新现有诊断、治疗模式。
:::

:::compare{title="本章小结按三节收口"}
| 节 | 收什么 |
|----|--------|
| 第一节 | 疾病相关基因／致病基因／易感基因；$\mathrm{CNV}$、$\mathrm{STR}$、$\mathrm{SNP}$、罕见变异；鉴定原则；不依赖定位的功能克隆、表型克隆、动物模型、半克隆、$\mathrm{EST}$ |
| 第二节 | 定位克隆、$\mathrm{GWAS}$、$\mathrm{RNA}$-$\mathrm{seq}$、$\mathrm{WES}$／$\mathrm{WGS}$；六个基因—疾病数据库 |
| 第三节 | 分子医学及四块组学、药物基因组学；精准医学定义与四个层面；转化医学与 $\mathrm{B}2\mathrm{B}$ |

小结把数据库写在策略之后、三个概念之前。细节仍以各节正文为准。
:::

:::keypoint{label="整章不要并户的三句话"}
- 致病基因 ≠ 易感基因。
- 早期定位克隆 ≠ 现在只有 $\mathrm{GWAS}$。
- 分子医学 ≠ 精准医学 ≠ 转化医学。
:::

## 思考题

1. 如何理解疾病相关基因的鉴定原则？
2. 如何理解基因结构异常及其造成基因表达水平异常的机制？
3. 假设你作为一名临床医师，在长期诊断和治疗胆囊腺癌患者的过程中，意识到大部分原发患者都同时具有相同的其他疾病特征；并且根据目前医学的研究进展，已知该相同的疾病性状与 $\mathrm{X}$ 基因异常有关，请以该临床现象作为切入点，为这个研究课题设计一套研究思路。
4. 假设你作为一名临床医师，职责是对肺癌患者进行治疗。已知某抗肿瘤药物对某些患者群体效果极佳，但对另一些患者则丝毫不起作用，并且已知其作用机制是特异性地抑制肺癌患者的某生长因子受体的活性。请问，你能设计出一套个性化治疗的方案吗？

:::tip{label="四道思考题对着哪一户"}
- 第 $1$ 题：第一节原则三句——表型同质与遗传度、图22-1 多途径、交汇到候选基因（$2$ 万 $\rightarrow$ $10\sim 30$ 仍要逐个排除）。
- 第 $2$ 题：结构异常与表达异常；第一节表型克隆已写差异可来自结构也可来自调控；分子医学把表达（转录与翻译）变化及其调控写进定义。
- 第 $3$ 题：临床表型切入 → 已知另一性状与 $\mathrm{X}$ 基因异常有关。用第一节、第二节的鉴定策略选路（功能／表型／定位／$\mathrm{GWAS}$／测序），不要在本节另编一套未写过的流程。
- 第 $4$ 题：同一机制的药有人极佳、有人无效 → 药物基因组学（基因定向治疗）和精准医学（精确诊断＋靶向治疗、量体裁衣）。受体活性是已知机制，方案要落到基因／表达差异上，不要改写成肿瘤专章。
:::

:::memory{label="本节必背分户"}
- 分子医学：从分子水平阐述疾病状态下基因组、基因、基因表达（转录与翻译）变化及其调控规律，推进高效预测、预防、诊断和治疗。基础：疾病基因组学、转录组学、蛋白质组学、代谢物组学。
- 疾病基因组学两大任务：疾病相关基因；易感性遗传学基础。$\mathrm{APOE}$—$\mathrm{AD}$；$\mathrm{CCR}5$ 缺失—$\mathrm{HIV}$ 抗性。
- 药物基因组学：功能基因组学与分子药理学结合；效应＋安全性；诊断定向 → 基因定向。
- 转录组学：Corus $\mathrm{CAD}$ 为 $23$ 个基因；血清 $\mathrm{miRNA}$ 名单按本版；$\mathrm{miRNA}$-$182$ 反义寡聚核苷酸治疗黑色素瘤肝转移。
- 蛋白质组学：异常蛋白质作候选靶点；分期标志物；信号通路可不受基因调节而串联。
- 代谢组学：组成、特性与变化；$\mathrm{VLDL}$／$\mathrm{LDL}$／$\mathrm{HDL}$／胆碱；不饱和度与相互作用强度而非脂质绝对含量；尿嘌呤嘧啶图谱。
- 精准医学：测序＋生物信息＋大数据；个人基因、环境、生活习惯。六个精确。短期癌症（伊马替尼—$\mathrm{BCR}$-$\mathrm{ABL}$；克唑替尼—$\mathrm{ALK}$／$\mathrm{NSCLC}$），长期健康管理。四个层面缺一不可。$2016$ 五大任务。
- 转化医学：临床问题导向；四条背景；$\mathrm{B}2\mathrm{B}$；降发病率、推迟发病年龄、提高治愈率、减少重症、降低综合成本。
- 数据库只默写小结名单：$\mathrm{OMIM}$、$\mathrm{GWAS}$ catalog、Orphanet、$\mathrm{DisGeNET}$、$\mathrm{HGMD}$、GeneCards。
:::
