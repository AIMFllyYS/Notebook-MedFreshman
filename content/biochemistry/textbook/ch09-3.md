# 第三节　氨的代谢

第二节把 $\alpha$-氨基脱掉，$\alpha$-酮酸交给糖和脂质。氨不能在组织里游离堆积：脑对氨尤其敏感。本节写血氨的来源、转运和去路。来源三笔：氨基酸脱氨基（兼胺类分解）、肠道细菌、肾小管谷氨酰胺。转运两路：骨骼肌走丙氨酸-葡萄糖循环，脑和骨骼肌等走谷氨酰胺。去路主要在肝经鸟氨酸循环写成尿素；$\mathrm{CPS}$ Ⅰ、$N$-乙酰谷氨酸和精氨酸代琥珀酸合成酶管开关。循环断了，就是高血氨和肝性脑病。

体内代谢产生的氨及消化道吸收的氨进入血液，形成血氨。正常生理情况下，血氨水平在 $47\sim 65\,\mu\mathrm{mol/L}$。氨具有毒性，特别是脑组织对氨的作用尤为敏感。

:::definition{label="血氨"}
血氨是体内代谢产生的氨及消化道吸收的氨进入血液后的存在形式。正常生理水平 $47\sim 65\,\mu\mathrm{mol/L}$。氨有毒性，脑组织尤为敏感。
:::

:::concept{term="先问氨从哪来、以什么无毒形式走，再问肝怎么写成尿素"}
看见“氨的代谢”，不要先默写五步鸟氨酸循环。户头是：血氨有三本来源；组织里的氨必须以丙氨酸或谷氨酰胺运走；肝把氨写成尿素，肾把少部分氨写成铵盐。来源与去路失衡，才是高血氨。
:::

:::pitfall{label="血氨正常值不要改写成 mmol 档"}
本版写的是 $47\sim 65\,\mu\mathrm{mol/L}$。把微摩尔听成毫摩尔，数值会差三个数量级，后面“高血氨症”的临床账也对不上。
:::

## 一、血氨有三个重要来源

### （一）氨基酸脱氨基作用和胺类分解均可产生氨

氨基酸脱氨基作用产生的氨是体内氨的主要来源。第二节的转氨基、氧化脱氨基、联合脱氨基，最终都把 $\alpha$-氨基写成游离氨。胺类的分解也可以产生氨：胺氧化酶把 $\mathrm{RCH}_2\mathrm{NH}_2$ 氧化成相应的醛，同时放出 $\mathrm{NH}_3$。

$$
\mathrm{RCH}_2\mathrm{NH}_2 \xrightarrow{\text{胺氧化酶}} \mathrm{RCHO}+\mathrm{NH}_3
$$

:::definition{label="氨的主要来源"}
氨基酸脱氨基作用产生的氨是体内氨的主要来源。胺类分解也可产生氨。
:::

:::insight{label="组织里刚脱掉的氨，还不是血氨的全部"}
脱氨基是“体内代谢产生”的那一笔，也是主要来源。另外两笔——肠道细菌和肾小管谷氨酰胺——可以在肝功能不好或尿偏碱时把血氨再抬一截。三本来源要分开记，不要并成“都是氨基酸脱下来的”。
:::

### （二）肠道细菌作用产生氨

蛋白质和氨基酸在肠道细菌腐败作用下可产生氨，肠道内尿素经细菌尿素酶水解也可产生氨。肠道产氨量较多，每天约为 $4\,\mathrm{g}$。当腐败作用增强时，氨的产生量增多。肠道内产生的氨主要在结肠吸收入血。

在碱性环境中，$\mathrm{NH}_4^{+}$ 易转变成 $\mathrm{NH}_3$，而 $\mathrm{NH}_3$ 比 $\mathrm{NH}_4^{+}$ 易于穿过细胞膜而被吸收。因此肠道偏碱时，氨的吸收增强。临床上对高血氨病人采用弱酸性透析液作结肠透析，而禁止用碱性的肥皂水灌肠，就是为了减少氨的吸收。

:::definition{label="肠道产氨"}
肠道产氨有两条：蛋白质和氨基酸的细菌腐败；肠道内尿素被细菌尿素酶水解。每天约 $4\,\mathrm{g}$，主要在结肠吸收入血。腐败增强则产氨增多。
:::

:::keypoint{label="NH3 比 NH4+ 容易过膜"}
- 偏碱：$\mathrm{NH}_4^{+}\to\mathrm{NH}_3$，吸收增强。
- 偏酸：氨多以 $\mathrm{NH}_4^{+}$ 存在，不易过膜。
- 高血氨：弱酸性透析液作结肠透析；禁止碱性肥皂水灌肠。
:::

:::pitfall{label="灌肠不是“把肠道洗干净就降血氨”"}
肥皂水偏碱，把 $\mathrm{NH}_4^{+}$ 写成 $\mathrm{NH}_3$，吸收反而增强。弱酸性透析液才是把氨留在肠腔。临床上禁止碱性肥皂水灌肠，户头是膜通透，不是清洁程度。
:::

:::cause-effect{title="肠道 pH 如何拨氨的吸收"}
- **因** 碱性环境使 $\mathrm{NH}_4^{+}$ 转变成 $\mathrm{NH}_3$，$\mathrm{NH}_3$ 更易穿过细胞膜
- **果** 结肠吸氨增强，血氨升高；弱酸透析减少吸收，碱性灌肠增加吸收
:::

### （三）肾小管上皮细胞分泌的氨主要来自谷氨酰胺

谷氨酰胺在谷氨酰胺酶的催化下水解成谷氨酸和氨。这部分氨分泌到肾小管管腔中，与尿中的 $\mathrm{H}^{+}$ 结合成 $\mathrm{NH}_4^{+}$，以铵盐的形式由尿排出体外，这对调节机体的酸碱平衡起着重要作用。

酸性尿有利于肾小管细胞中的氨扩散入尿，而碱性尿则妨碍肾小管细胞中 $\mathrm{NH}_3$ 的分泌，此时氨被吸收入血，成为血氨的另一个来源。因此，临床上对因肝硬化而产生腹水的病人，不宜使用碱性利尿药，以免血氨升高。

:::definition{label="肾小管泌氨"}
肾小管上皮细胞分泌的氨主要来自谷氨酰胺：谷氨酰胺酶水解谷氨酰胺，生成谷氨酸和氨。氨入管腔与 $\mathrm{H}^{+}$ 结合成 $\mathrm{NH}_4^{+}$，以铵盐随尿排出，并调节酸碱平衡。
:::

:::compare{title="酸性尿与碱性尿对泌氨的方向"}
| 尿液 | 氨的去向 | 对血氨 |
|------|----------|--------|
| 酸性尿 | 氨扩散入尿，结合成 $\mathrm{NH}_4^{+}$ 排出 | 有利于把氨送出体外 |
| 碱性尿 | 妨碍 $\mathrm{NH}_3$ 分泌，氨被吸收入血 | 成为血氨的另一个来源 |
:::

:::pitfall{label="肝硬化腹水不要用碱性利尿药"}
肾小管这一笔氨本应写成铵盐随尿走。碱性利尿药把尿碱化，泌氨受阻，氨回流入血。肝已经写不好尿素，再给它加一笔血氨，高血氨的风险上升。弱酸透析、禁碱性灌肠、禁碱性利尿，三句临床嘱咐的共同户头都是 $\mathrm{NH}_3/\mathrm{NH}_4^{+}$ 的膜通透。
:::

:::insight{label="同一分子谷氨酰胺，脑用来运氨，肾用来泌氨"}
后面转运一节会把谷氨酰胺写成脑和骨骼肌向肝或肾运氨的形式。到了肾，谷氨酰胺酶再把它水解，氨可以进管腔成铵盐。来源账里的“肾小管泌氨”和转运账里的“谷氨酰胺运氨”是同一条通路的两端，不要并成两套互不相干的氨。
:::

## 二、氨在血液中以丙氨酸和谷氨酰胺的形式转运

氨在人体内是有毒物质。各组织中产生的氨必须以无毒的方式经血液运输到肝合成尿素，或运输到肾以铵盐的形式排出体外。现已知，氨在血液中主要是以丙氨酸和谷氨酰胺两种形式进行转运。

:::definition{label="氨的转运形式"}
氨在血液中主要以丙氨酸和谷氨酰胺两种形式转运：运往肝合成尿素，或运往肾以铵盐排出。游离氨不作为主要运输形式。
:::

:::concept{term="骨骼肌走丙氨酸，脑走谷氨酰胺"}
两路不要记反。骨骼肌有大量丙酮酸（糖酵解），适合用丙氨酸把氨基送走，肝再把碳架异生成葡萄糖送回来。脑更需要把氨固定成谷氨酰胺再运出。谷氨酰胺也可以从骨骼肌运往肝或肾。
:::

### （一）氨通过丙氨酸-葡萄糖循环从骨骼肌运往肝

骨骼肌主要以丙酮酸作为氨基受体，经转氨基作用生成丙氨酸，丙氨酸进入血液后被运往肝。在肝中，丙氨酸通过联合脱氨基作用生成丙酮酸，并释放氨。氨用于合成尿素，丙酮酸经糖异生途径生成葡萄糖。葡萄糖经血液运往肌肉，沿糖酵解转变成丙酮酸，后者再接受氨基生成丙氨酸。丙氨酸和葡萄糖周而复始的转变，完成骨骼肌和肝之间氨的转运，这一途径称为丙氨酸-葡萄糖循环（alanine glucose cycle）（图9-7）。

通过这个循环，骨骼肌组织中氨基酸的氨基（“氨”）以丙氨酸形式运往肝，同时，肝又为骨骼肌提供了生成丙酮酸的葡萄糖。

::figure{src="/images/biochemistry/textbook/p0210_01.png" caption="图9-7　丙氨酸-葡萄糖循环。左侧骨骼肌：肌蛋白质分解出氨基酸，氨基经谷氨酸转到丙酮酸生成丙氨酸入血；葡萄糖酵解补充丙酮酸。右侧肝：丙氨酸与 α-酮戊二酸转氨，氨经尿素循环排出，丙酮酸糖异生为葡萄糖再经血液回肌肉。" alt="丙氨酸-葡萄糖循环：肌肉生成丙氨酸入血，肝脱氨后尿素循环与糖异生，葡萄糖返回肌肉"}

:::definition{label="丙氨酸-葡萄糖循环"}
丙氨酸-葡萄糖循环（alanine glucose cycle）：骨骼肌以丙酮酸为氨基受体生成丙氨酸运往肝；肝经联合脱氨基释放氨（合成尿素），丙酮酸糖异生为葡萄糖运回肌肉再酵解成丙酮酸。骨骼肌的氨基以丙氨酸形式运往肝，肝同时为骨骼肌提供生成丙酮酸的葡萄糖。
:::

:::compare{title="循环两端各自干什么"}
| 部位 | 碳架 | 氨 |
|------|------|----|
| 骨骼肌 | 葡萄糖 $\xrightarrow{\text{酵解}}$ 丙酮酸；丙酮酸接受氨基 | 氨基酸的氨基经转氨写入丙氨酸 |
| 血液 | 葡萄糖（肝→肌）、丙氨酸（肌→肝） | 不以游离氨运输 |
| 肝 | 丙氨酸 $\to$ 丙酮酸 $\xrightarrow{\text{糖异生}}$ 葡萄糖 | 联合脱氨基释放的氨进尿素循环 |
:::

:::insight{label="这一圈同时运氨、又给肌补碳架"}
肌把氨基交给丙氨酸，等于把“毒”送去肝；肝把丙酮酸写成葡萄糖送回肌，等于把碳架送回去再当氨基受体。第七章糖异生已经把饥饿时肌蛋白质以丙氨酸、谷氨酰胺运入肝写成血糖补给的主要来源，和本节是同一本账。
:::

:::pitfall{label="不要把这一圈写成肌自己也能异生"}
肌缺葡萄糖-6-磷酸酶，丙酮酸在肌内变不成血糖。葡萄糖必须由肝异生后再运回。把循环听成“肌肝各写一半葡萄糖”，碳架方向会反。
:::

### （二）氨通过谷氨酰胺从脑和骨骼肌等组织运往肝或肾

谷氨酰胺是另一种转运氨的形式，它主要从脑和骨骼肌等组织向肝或肾运氨。在脑和骨骼肌等组织，氨与谷氨酸在谷氨酰胺合成酶（glutamine synthetase）的催化下合成谷氨酰胺，并经血液运往肝或肾，再经谷氨酰胺酶（glutaminase）的催化水解成谷氨酸及氨。谷氨酰胺的合成与分解是由不同酶催化的不可逆反应，其合成需消耗 $\mathrm{ATP}$。

$$
\text{L-谷氨酸}+\mathrm{NH}_3+\mathrm{ATP}\xrightarrow{\text{谷氨酰胺合成酶}}\text{谷氨酰胺}+\mathrm{ADP}+\mathrm{P}_\mathrm{i}
$$

$$
\text{谷氨酰胺}+\mathrm{H}_2\mathrm{O}\xrightarrow{\text{谷氨酰胺酶}}\text{L-谷氨酸}+\mathrm{NH}_3
$$

可以认为，谷氨酰胺既是氨的解毒产物，又是氨的储存及运输形式。尤其是谷氨酰胺在脑中固定和转运氨的过程中起着重要作用。临床上对氨中毒的病人可服用或输入谷氨酸盐，以降低氨的浓度。

:::definition{label="谷氨酰胺合成酶"}
谷氨酰胺合成酶（glutamine synthetase）催化氨与谷氨酸合成谷氨酰胺，消耗 $\mathrm{ATP}$。分布在脑和骨骼肌等组织，把氨固定成无毒的运输形式。
:::

:::definition{label="谷氨酰胺酶"}
谷氨酰胺酶（glutaminase）催化谷氨酰胺水解成谷氨酸及氨。分布在肝或肾，把运到的谷氨酰胺再拆开。与合成酶不是同一套可逆反应。
:::

:::definition{label="谷氨酰胺运氨"}
谷氨酰胺是氨的解毒产物，也是氨的储存及运输形式：从脑和骨骼肌等组织向肝或肾运氨。脑中固定和转运氨尤其依赖这一条。
:::

:::compare{title="两条运氨路"}
| 项目 | 丙氨酸-葡萄糖循环 | 谷氨酰胺 |
|------|-------------------|----------|
| 主要起点 | 骨骼肌 | 脑和骨骼肌等 |
| 运载分子 | 丙氨酸 | 谷氨酰胺 |
| 到达 | 肝 | 肝或肾 |
| 肝内氨的去路 | 尿素循环 | 尿素循环 |
| 肾内氨的去路 | — | 谷氨酰胺酶水解后可泌氨成铵盐 |
| 是否耗 $\mathrm{ATP}$ | 肝糖异生耗能（见第七章） | 合成谷氨酰胺耗 $1\,\mathrm{ATP}$ |
:::

:::pitfall{label="合成酶和水解酶不是一对可逆酶"}
谷氨酰胺的合成与分解由不同酶催化，合成不可逆、要耗 $\mathrm{ATP}$。不要画成谷氨酰胺合成酶倒着开就能放出氨。脑里固定氨靠合成酶；肝、肾释放氨靠谷氨酰胺酶。
:::

:::insight{label="氨中毒补谷氨酸盐，是在给脑准备固定氨的碳架"}
谷氨酸接受氨写成谷氨酰胺，血氨下降。这一笔和后文高血氨机制里“氨与 $\alpha$-酮戊二酸、谷氨酸结合”是同一方向：先把游离氨固定住。它不能替代肝写尿素，只是降低脑中游离氨。
:::

谷氨酰胺还可以提供氨基使天冬氨酸转变成天冬酰胺。正常细胞能合成足量的天冬酰胺供蛋白质的合成需要。但白血病细胞却不能或很少能合成天冬酰胺，必须依靠血液从其他器官运输而来。因此临床上应用天冬酰胺酶（asparaginase）使天冬酰胺水解成天冬氨酸，从而减少血中天冬酰胺，达到治疗白血病的目的。

$$
\text{天冬酰胺}+\mathrm{H}_2\mathrm{O}\xrightarrow{\text{天冬酰胺酶}}\text{天冬氨酸}+\mathrm{NH}_3
$$

:::definition{label="天冬酰胺酶"}
天冬酰胺酶（asparaginase）水解天冬酰胺成天冬氨酸并放出氨。正常细胞能自己合成足量天冬酰胺；白血病细胞不能或很少能合成，依赖血中供应。降低血中天冬酰胺，可治疗白血病。
:::

:::pitfall{label="天冬酰胺酶治的是“白血病细胞缺合成能力”，不是把所有细胞的天冬酰胺都写没"}
正常细胞能自己合成，白血病细胞必须从血里拿。酶把血中天冬酰胺拆掉，卡的是后者。不要把它听成“氨基酸代谢的普遍解毒药”，和谷氨酸盐降血氨不是同一张处方。
:::

## 三、氨的主要代谢去路是在肝合成尿素

正常情况下体内的氨主要在肝合成尿素，只有少部分氨在肾以铵盐形式随尿排出。正常成人尿素占排氮总量的 $80\%\sim 90\%$，可见肝在氨的解毒中起着重要作用。

:::definition{label="氨的主要去路"}
氨的主要代谢去路是在肝合成尿素。少部分在肾以铵盐随尿排出。正常成人尿素占排氮总量的 $80\%\sim 90\%$。
:::

:::keypoint{label="排氮账先记尿素这一笔"}
- 主路：肝 $\to$ 尿素 $\to$ 尿（$80\%\sim 90\%$）。
- 辅路：肾铵盐。
- 肝写不好尿素，血氨就会升。后文高血氨症的关键就是这一条去路断了。
:::

### （一）肝细胞通过鸟氨酸循环合成尿素

肝是如何合成尿素的？早在 $1932$ 年，德国学者 Krebs H. 和 Henseleit K. 根据一系列实验，首次提出了鸟氨酸循环（ornithine cycle）学说，又称尿素循环（urea cycle），用来解释尿素的合成过程。

$20$ 世纪 $30$ 年代，组织切片技术已普遍应用于中间代谢的研究。用大鼠肝的薄切片和多种可能有关的代谢物以及铵盐共同保温，发现鸟氨酸（ornithine）和瓜氨酸（citrulline）都有催化铵盐合成尿素的作用。赖氨酸与鸟氨酸的结构非常相似，却无这种作用。所以较合理的解释是：在尿素合成的一系列反应中，应当包括 $\mathrm{NH}_3$、$\mathrm{CO}_2$ 和鸟氨酸共同合成一种中间化合物，这个中间化合物在肝中能以合理的速度生成尿素，同时再生成鸟氨酸。精氨酸符合作为这个中间化合物的要求。

上述反应的结果说明：鸟氨酸催化 $\mathrm{NH}_3$ 和 $\mathrm{CO}_2$ 生成了尿素，精氨酸是重要的中间化合物。这个学说不仅表明鸟氨酸在合成尿素时起催化作用，而且也符合前人有关尿素合成的一些发现。如只有哺乳类动物是以尿素为主要的氮代谢最终产物（鸟类氮代谢的最终产物是尿酸），也只有哺乳类动物的肝存在精氨酸酶（arginase）。精氨酸酶能够催化精氨酸水解生成尿素及鸟氨酸。

以 Krebs H. 和 Henseleit K. 的学说为基础，推断瓜氨酸是鸟氨酸转变为精氨酸的中间产物（比较这三种化合物的结构）。同时实验也发现瓜氨酸与鸟氨酸都具有催化铵盐合成尿素的作用。用大量鸟氨酸和铵盐及大鼠肝切片共同保温，可观察到瓜氨酸的积存。总结以上，提出了肝中合成尿素的鸟氨酸循环学说（图9-8）。

::figure{src="/images/biochemistry/textbook/p0211_01.png" caption="图9-8　尿素生成的鸟氨酸循环。鸟氨酸接受 NH3 与 CO2 生成瓜氨酸（放出 H2O）；瓜氨酸再接受一分子 NH3 生成精氨酸（放出 H2O）；精氨酸酶水解精氨酸，放出尿素并再生鸟氨酸。" alt="简化鸟氨酸循环：鸟氨酸、瓜氨酸、精氨酸三元环，尿素由精氨酸酶水解释出"}

:::definition{label="鸟氨酸循环"}
鸟氨酸循环（ornithine cycle）又称尿素循环（urea cycle）：肝细胞以鸟氨酸、瓜氨酸、精氨酸为循环中间物，把 $\mathrm{NH}_3$ 和 $\mathrm{CO}_2$ 写成尿素，同时再生鸟氨酸。$1932$ 年由 Krebs H. 和 Henseleit K. 提出。
:::

:::definition{label="精氨酸酶"}
精氨酸酶（arginase）催化精氨酸水解生成尿素及鸟氨酸。只有哺乳类动物的肝存在此酶；也只有哺乳类以尿素为氮代谢的主要最终产物（鸟类最终产物是尿酸）。
:::

:::insight{label="鸟氨酸是催化剂，尿素的碳和两个氮不是从鸟氨酸净消耗来的"}
循环走完，鸟氨酸再生。尿素分子里的碳来自 $\mathrm{CO}_2$，两个氮分别来自游离 $\mathrm{NH}_3$ 和天冬氨酸（下一步五步反应会写清）。把鸟氨酸听成“尿素的碳架来源”，结构账会错。
:::

:::pitfall{label="赖氨酸长得像鸟氨酸，却不能催化尿素合成"}
肝切片实验里，鸟氨酸、瓜氨酸有催化作用，结构相近的赖氨酸没有。循环中间物是鸟氨酸 $\to$ 瓜氨酸 $\to$ 精氨酸，不是“凡是碱性氨基酸都能转一圈”。
:::

:::compare{title="三种循环中间物"}
| 化合物 | 在循环中的位置 | 实验线索 |
|--------|----------------|----------|
| 鸟氨酸 | 接受氨基甲酰，起点也是再生终点 | 与铵盐保温可催化成尿素；大量保温可积存瓜氨酸 |
| 瓜氨酸 | 鸟氨酸转变为精氨酸的中间产物 | 同样能催化铵盐合成尿素 |
| 精氨酸 | 水解释出尿素并再生鸟氨酸 | 符合“中间化合物既生成尿素又再生鸟氨酸” |
:::

### （二）肝中鸟氨酸循环可分为五步

鸟氨酸循环的具体过程比较复杂，大体可分为以下五步。

**1. $\mathrm{NH}_3$、$\mathrm{CO}_2$ 和 $\mathrm{ATP}$ 缩合生成氨基甲酰磷酸（carbamoyl phosphate）**　尿素的生物合成始于氨基甲酰磷酸。在 $\mathrm{Mg}^{2+}$、$\mathrm{ATP}$ 及 $N$-乙酰谷氨酸（$N$-acetyl glutamic acid，$\mathrm{AGA}$）存在时，$\mathrm{NH}_3$ 与 $\mathrm{CO}_2$ 可由氨基甲酰磷酸合成酶Ⅰ（carbamoyl phosphate synthetase Ⅰ，$\mathrm{CPS}$ Ⅰ）催化生成氨基甲酰磷酸。

$$
\mathrm{NH}_3+\mathrm{CO}_2+\mathrm{H}_2\mathrm{O}+2\mathrm{ATP}\xrightarrow[\mathrm{AGA},\,\mathrm{Mg}^{2+}]{\mathrm{CPS}\,\text{Ⅰ}}\mathrm{H}_2\mathrm{N{-}CO{-}OPO}_3^{2-}+2\mathrm{ADP}+\mathrm{P}_\mathrm{i}
$$

此反应消耗 $2$ 分子 $\mathrm{ATP}$，为酰胺键和酸酐键的合成提供驱动力。$\mathrm{CPS}$ Ⅰ是鸟氨酸循环过程中的关键酶，催化不可逆反应。此酶只有在别构激活剂 $N$-乙酰谷氨酸存在时才能被激活，$N$-乙酰谷氨酸可诱导 $\mathrm{CPS}$ Ⅰ的构象发生改变，进而增加酶对 $\mathrm{ATP}$ 的亲和力。$\mathrm{CPS}$ Ⅰ和 $\mathrm{AGA}$ 都存在于肝细胞线粒体中。

:::definition{label="氨基甲酰磷酸"}
氨基甲酰磷酸（carbamoyl phosphate）是尿素生物合成的起点：$\mathrm{NH}_3$、$\mathrm{CO}_2$ 与 $\mathrm{ATP}$ 在 $\mathrm{CPS}$ Ⅰ催化下缩合而成。尿素分子中的第一个氮原子由此写入。
:::

:::definition{label="CPS Ⅰ"}
氨基甲酰磷酸合成酶Ⅰ（carbamoyl phosphate synthetase Ⅰ，$\mathrm{CPS}$ Ⅰ）是鸟氨酸循环的关键酶，催化不可逆反应。需 $\mathrm{Mg}^{2+}$、$\mathrm{ATP}$ 及别构激活剂 $N$-乙酰谷氨酸。存在于肝细胞线粒体。消耗 $2$ 分子 $\mathrm{ATP}$，提高酶对 $\mathrm{ATP}$ 的亲和力靠 $\mathrm{AGA}$ 诱导构象改变。
:::

:::definition{label="N-乙酰谷氨酸"}
$N$-乙酰谷氨酸（$N$-acetyl glutamic acid，$\mathrm{AGA}$）是 $\mathrm{CPS}$ Ⅰ的别构激活剂，与 $\mathrm{CPS}$ Ⅰ同在肝细胞线粒体。无 $\mathrm{AGA}$ 则 $\mathrm{CPS}$ Ⅰ不被激活。
:::

:::pitfall{label="CPS Ⅰ 这一步就要烧掉 2 个 ATP，不是到精氨酸代琥珀酸才开始耗能"}
总反应写 $3\,\mathrm{ATP}$，其中 $2$ 个已经花在氨基甲酰磷酸上。后面瓜氨酸与天冬氨酸缩合再花 $1$ 个 $\mathrm{ATP}$（生成 $\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$）。把“尿素循环耗 $3\,\mathrm{ATP}$”只记在某一步，账会对不上。
:::

**2. 氨基甲酰磷酸与鸟氨酸反应生成瓜氨酸**　在鸟氨酸氨基甲酰转移酶（ornithine carbamoyl transferase，$\mathrm{OCT}$）催化下，氨基甲酰磷酸上的氨基甲酰部分转移到鸟氨酸上，生成瓜氨酸和磷酸。此反应不可逆，$\mathrm{OCT}$ 也存在于肝细胞线粒体中。

$$
\text{氨基甲酰磷酸}+\text{鸟氨酸}\xrightarrow{\mathrm{OCT}}\text{瓜氨酸}+\mathrm{H}_3\mathrm{PO}_4
$$

:::definition{label="鸟氨酸氨基甲酰转移酶"}
鸟氨酸氨基甲酰转移酶（ornithine carbamoyl transferase，$\mathrm{OCT}$）把氨基甲酰磷酸上的氨基甲酰转到鸟氨酸，生成瓜氨酸和磷酸。不可逆，位于肝细胞线粒体。
:::

:::insight{label="线粒体里只做前两步：写成瓜氨酸再送出去"}
$\mathrm{CPS}$ Ⅰ和 $\mathrm{OCT}$ 都在线粒体。游离 $\mathrm{NH}_3$ 在线粒体内就被氨基甲酰磷酸“抓住”，再交给鸟氨酸。瓜氨酸出线粒体以后，第二个氮才在胞质溶胶由天冬氨酸补上。
:::

**3. 瓜氨酸与天冬氨酸反应生成精氨酸代琥珀酸**　瓜氨酸在线粒体合成后，即被转运到线粒体外，在胞质溶胶中经精氨酸代琥珀酸合成酶（argininosuccinate synthetase）催化，与天冬氨酸反应生成精氨酸代琥珀酸。此反应由 $\mathrm{ATP}$ 供能，天冬氨酸提供了尿素分子中的第二个氮原子。精氨酸代琥珀酸合成酶也是鸟氨酸循环过程中的关键酶。

$$
\text{瓜氨酸}+\text{天冬氨酸}+\mathrm{ATP}\xrightarrow[\mathrm{Mg}^{2+}]{\text{精氨酸代琥珀酸合成酶}}\text{精氨酸代琥珀酸}+\mathrm{AMP}+\mathrm{PP}_\mathrm{i}
$$

:::definition{label="精氨酸代琥珀酸合成酶"}
精氨酸代琥珀酸合成酶（argininosuccinate synthetase）在胞质溶胶催化瓜氨酸与天冬氨酸生成精氨酸代琥珀酸，由 $\mathrm{ATP}$ 供能（产物为 $\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$）。天冬氨酸提供尿素的第二个氮。它也是鸟氨酸循环的关键酶；参与尿素合成的酶系中，此酶活性最低。
:::

:::keypoint{label="尿素两个氮的来源"}
- 第一个氮：游离 $\mathrm{NH}_3$，经氨基甲酰磷酸写入瓜氨酸。
- 第二个氮：天冬氨酸，在胞质溶胶写入精氨酸代琥珀酸。
- $\mathrm{CO}_2$ 提供尿素的碳。
:::

:::pitfall{label="第二个氮不是再来一分子游离 NH3"}
图9-8 的简图在瓜氨酸 $\to$ 精氨酸处画了 $\mathrm{NH}_3$，那是学说示意。五步反应里，这一笔氮来自天冬氨酸。体内多种氨基酸的氨基可通过转氨写成天冬氨酸，再参与尿素合成。
:::

**4. 精氨酸代琥珀酸裂解生成精氨酸与延胡索酸**　精氨酸代琥珀酸在精氨酸代琥珀酸裂解酶的催化下，裂解生成精氨酸与延胡索酸。反应产物精氨酸分子中保留了来自游离 $\mathrm{NH}_3$ 和天冬氨酸分子中的氮。

上述反应裂解生成的延胡索酸可经柠檬酸循环的中间步骤转变成草酰乙酸，后者与谷氨酸在 $\mathrm{AST}$ 催化下进行转氨基反应，又可重新生成天冬氨酸，而谷氨酸的氨基可来自体内的多种氨基酸。由此可见，体内多种氨基酸的氨基可通过天冬氨酸的形式参与尿素的合成。

:::definition{label="精氨酸代琥珀酸裂解酶"}
精氨酸代琥珀酸裂解酶催化精氨酸代琥珀酸裂解为精氨酸与延胡索酸。精氨酸保留来自游离 $\mathrm{NH}_3$ 和天冬氨酸的两个氮；延胡索酸的碳架可经柠檬酸循环回到草酰乙酸，再经 $\mathrm{AST}$ 转氨重生天冬氨酸。
:::

:::insight{label="延胡索酸把尿素循环接到柠檬酸循环"}
裂解不是把天冬氨酸的碳架丢掉。延胡索酸 $\to$ 苹果酸 $\to$ 草酰乙酸，再与谷氨酸转氨，天冬氨酸再生。尿素循环本身不消耗天冬氨酸的碳骨架，消耗的是氨基。图9-9 右侧把这一笔画在胞质溶胶。
:::

**5. 精氨酸水解释放尿素并再生成鸟氨酸**　在胞质溶胶中，精氨酸由精氨酸酶催化，水解生成尿素和鸟氨酸。鸟氨酸通过线粒体内膜上载体的转运再进入线粒体，参与瓜氨酸的合成。如此反复，完成鸟氨酸循环。尿素则作为代谢终产物排出体外。

$$
\text{精氨酸}+\mathrm{H}_2\mathrm{O}\xrightarrow{\text{精氨酸酶}}\text{尿素}+\text{鸟氨酸}
$$

综上所述，尿素合成的总反应为：

$$
2\mathrm{NH}_3+\mathrm{CO}_2+3\mathrm{ATP}+3\mathrm{H}_2\mathrm{O}\longrightarrow \mathrm{H}_2\mathrm{N{-}CO{-}NH}_2+2\mathrm{ADP}+\mathrm{AMP}+4\mathrm{P}_\mathrm{i}
$$

尿素合成的中间步骤及其在细胞中的定位总结于图9-9。图中：①氨基甲酰磷酸合成酶Ⅰ；②鸟氨酸氨基甲酰转移酶；③精氨酸代琥珀酸合成酶；④精氨酸代琥珀酸裂解酶；⑤精氨酸酶。

:::timeline{period="鸟氨酸循环五步"}
- **第1步（线粒体，不可逆）** CPS Ⅰ：NH3 + CO2 + 2 ATP 生成氨基甲酰磷酸，需 AGA、Mg2+
- **第2步（线粒体，不可逆）** OCT：氨基甲酰磷酸 + 鸟氨酸 → 瓜氨酸 + 磷酸
- **第3步（胞质溶胶）** 精氨酸代琥珀酸合成酶：瓜氨酸 + 天冬氨酸 + ATP → 精氨酸代琥珀酸 + AMP + PPi（写入第二个氮）
- **第4步（胞质溶胶）** 裂解酶：精氨酸代琥珀酸 → 精氨酸 + 延胡索酸；延胡索酸可经柠檬酸循环中间步骤重生天冬氨酸
- **第5步（胞质溶胶）** 精氨酸酶：精氨酸 + H2O → 尿素 + 鸟氨酸；鸟氨酸经载体回线粒体
:::

:::compare{title="五步酶的细胞定位"}
| 步骤 | 酶 | 部位 | 可逆性／角色 |
|------|----|------|--------------|
| ① | $\mathrm{CPS}$ Ⅰ | 线粒体 | 不可逆；启动关键酶，需 $\mathrm{AGA}$ |
| ② | $\mathrm{OCT}$ | 线粒体 | 不可逆；生成瓜氨酸 |
| ③ | 精氨酸代琥珀酸合成酶 | 胞质溶胶 | 关键酶，酶系中活性最低 |
| ④ | 精氨酸代琥珀酸裂解酶 | 胞质溶胶 | 放出精氨酸和延胡索酸 |
| ⑤ | 精氨酸酶 | 胞质溶胶 | 水解释出尿素，再生鸟氨酸 |
:::

:::keypoint{label="总反应要记住的三件事"}
- 底物：$2\,\mathrm{NH}_3+\mathrm{CO}_2$。
- 代价：$3\,\mathrm{ATP}$（实际写入产物为 $2\,\mathrm{ADP}+\mathrm{AMP}+4\mathrm{P}_\mathrm{i}$），另加 $3\,\mathrm{H}_2\mathrm{O}$。
- 终产物：尿素；鸟氨酸循环再生，不净消耗。
:::

:::pitfall{label="鸟氨酸进出线粒体靠载体，不是自己渗过去"}
瓜氨酸出线粒体、鸟氨酸进线粒体，图9-9 在内膜上画了载体位点。把循环五步都画在线粒体，或都画在胞质，定位账和两种关键酶的调节都会乱。
:::

### （三）尿素合成受膳食蛋白质和两种关键酶的调节

**1. 高蛋白质膳食增加尿素生成**　尿素合成受食物蛋白质的影响。进食高蛋白质膳食时，蛋白质分解增多，尿素合成速度加快，尿素可占排出氮的 $90\%$；反之，摄取低蛋白质膳食时，尿素合成速度减慢，尿素约占排出氮的 $60\%$。

:::compare{title="膳食蛋白质怎样改写排出氮中尿素的份额"}
| 膳食 | 尿素合成速度 | 尿素占排出氮 |
|------|--------------|--------------|
| 高蛋白质 | 加快 | 可占 $90\%$ |
| 正常（成人） | — | $80\%\sim 90\%$ |
| 低蛋白质 | 减慢 | 约占 $60\%$ |
:::

:::insight{label="低蛋白时尿素份额下降，不等于氨改走了更“好”的路"}
排出氮的组成变了：尿素少了，其他形式（包括铵盐等）相对比例上升。调节的是合成速度，不是把氨变成无害的别的分子。肝功能正常时，高蛋白负荷靠加快循环来排；肝功能不好时，加快不了，血氨就会升。
:::

**2. $\mathrm{AGA}$ 激活 $\mathrm{CPS}$ Ⅰ启动尿素合成**　$\mathrm{CPS}$ Ⅰ是鸟氨酸循环启动的关键酶。如前所述，$\mathrm{AGA}$ 是 $\mathrm{CPS}$ Ⅰ的别构激活剂，它是由乙酰 $\mathrm{CoA}$ 与谷氨酸通过 $\mathrm{AGA}$ 合酶催化生成的。精氨酸是 $\mathrm{AGA}$ 合酶的激活剂，精氨酸浓度增高时，尿素合成增加。

:::definition{label="AGA 合酶"}
$\mathrm{AGA}$ 合酶催化乙酰 $\mathrm{CoA}$ 与谷氨酸生成 $N$-乙酰谷氨酸。精氨酸是 $\mathrm{AGA}$ 合酶的激活剂：精氨酸增多 $\to\mathrm{AGA}$ 增多 $\to\mathrm{CPS}$ Ⅰ被激活 $\to$ 尿素合成增加。
:::

:::cause-effect{title="精氨酸如何通过 AGA 打开循环"}
- **因** 精氨酸激活 $\mathrm{AGA}$ 合酶 $\to\mathrm{AGA}$ 生成增多 $\to$ 别构激活 $\mathrm{CPS}$ Ⅰ（增加对 $\mathrm{ATP}$ 的亲和力）
- **果** 鸟氨酸循环启动加快，尿素合成增加
:::

:::pitfall{label="精氨酸既是循环中间物，又是 AGA 合酶的激活剂"}
不要只把它写成第 $5$ 步的底物。浓度升高时，它通过 $\mathrm{AGA}$ 把 $\mathrm{CPS}$ Ⅰ打开，等于告诉线粒体“循环在转、可以再启动”。把精氨酸只记成“水解出尿素”，启动调节那一笔会丢。
:::

**3. 精氨酸代琥珀酸合成酶促进尿素合成**　参与尿素合成的酶系中，精氨酸代琥珀酸合成酶的活性最低，是尿素合成启动以后的关键酶，可调节尿素的合成速度。

:::compare{title="两个关键酶不要并户"}
| 酶 | 管哪一段 | 调节方式 |
|----|----------|----------|
| $\mathrm{CPS}$ Ⅰ | 启动 | $\mathrm{AGA}$ 别构激活；精氨酸通过 $\mathrm{AGA}$ 合酶间接打开 |
| 精氨酸代琥珀酸合成酶 | 启动以后的速度 | 酶系中活性最低，限速 |

一个管“开不开”，一个管“开了以后有多快”。
:::

:::keypoint{label="尿素合成的三层调节"}
- 膳食：高蛋白加快（尿素可占排出氮 $90\%$），低蛋白减慢（约 $60\%$）。
- 启动：$\mathrm{AGA}$ 别构激活 $\mathrm{CPS}$ Ⅰ；精氨酸激活 $\mathrm{AGA}$ 合酶。
- 速度：精氨酸代琥珀酸合成酶活性最低。
:::

### （四）尿素生成障碍可引起高血氨症或氨中毒

在正常生理情况下，血氨的来源与去路保持动态平衡，而氨在肝中合成尿素是维持这种平衡的关键。当某种原因，例如肝功能严重损伤或尿素合成相关酶遗传性缺陷时，都可导致尿素合成发生障碍，血氨浓度升高，称为高血氨症（hyperammonemia）。常见的临床症状包括呕吐、厌食、间歇性共济失调、嗜睡甚至昏迷等。

高血氨的毒性作用机制尚不完全清楚。一般认为，氨进入脑组织，可与脑中的 $\alpha$-酮戊二酸结合生成谷氨酸，氨也可与脑中的谷氨酸进一步结合生成谷氨酰胺。高血氨时，脑中氨的增加可使脑细胞中的 $\alpha$-酮戊二酸减少，导致三羧酸循环减弱，$\mathrm{ATP}$ 生成减少，引起大脑功能障碍，严重时可发生昏迷（称为肝性脑病）。另一种可能性是谷氨酸、谷氨酰胺增多，渗透压增大引起脑水肿所致。

:::definition{label="高血氨症"}
高血氨症（hyperammonemia）指尿素合成障碍导致血氨浓度升高。原因包括肝功能严重损伤，或尿素合成相关酶遗传性缺陷。来源与去路的动态平衡被打破，关键在“肝写尿素”这一条去路。
:::

:::definition{label="肝性脑病"}
肝性脑病：高血氨时大脑功能障碍，严重时可发生昏迷。机制尚未完全清楚。一般认为氨与脑中 $\alpha$-酮戊二酸结合成谷氨酸，再结合成谷氨酰胺，$\alpha$-酮戊二酸减少使三羧酸循环减弱，$\mathrm{ATP}$ 生成减少；另一种可能是谷氨酸、谷氨酰胺增多，渗透压增大引起脑水肿。
:::

:::compare{title="高血氨伤脑的两种教材说法"}
| 说法 | 中间环节 | 后果 |
|------|----------|------|
| $\alpha$-酮戊二酸被消耗 | 三羧酸循环减弱 | $\mathrm{ATP}$ 减少 $\to$ 大脑功能障碍、昏迷 |
| 谷氨酸、谷氨酰胺增多 | 渗透压增大 | 脑水肿 |
:::

:::cause-effect{title="游离氨如何抽走脑的 α-酮戊二酸"}
- **因** 氨 $+$ $\alpha$-酮戊二酸 $\to$ 谷氨酸；氨 $+$ 谷氨酸 $\to$ 谷氨酰胺
- **果** $\alpha$-酮戊二酸减少，三羧酸循环减弱，$\mathrm{ATP}$ 不足；同时谷氨酸／谷氨酰胺堆积可致脑水肿
:::

:::pitfall{label="谷氨酸盐可以降血氨，高血氨时脑里谷氨酸增多却可以致脑水肿"}
两笔不矛盾：外周给谷氨酸盐，是把血中游离氨固定成谷氨酰胺；脑内已经堆积的谷氨酸、谷氨酰胺，则可能抬高渗透压。治疗思路仍是减少来源、恢复肝写尿素，而不是把脑里的谷氨酰胺再拆成游离氨。
:::

:::example{label="临床三句嘱咐如何对上本节户头"}
高血氨病人：弱酸性液结肠透析、禁碱性肥皂水灌肠——砍肠道吸氨。肝硬化腹水：不用碱性利尿药——避免肾小管氨回流入血。氨中毒：谷氨酸盐——把游离氨写成谷氨酰胺。根本去路仍是肝的鸟氨酸循环；酶缺陷或肝衰竭时，上述措施只能减轻来源或暂时固定氨。
:::

:::memory{label="本节必背要点"}
- [ ] 血氨正常 $47\sim 65\,\mu\mathrm{mol/L}$；脑对氨敏感。
- [ ] 来源三笔：氨基酸脱氨基（主）及胺类分解；肠道细菌（约 $4\,\mathrm{g/d}$，结肠吸收）；肾小管谷氨酰胺。
- [ ] $\mathrm{NH}_3$ 比 $\mathrm{NH}_4^{+}$ 易过膜：偏碱吸收／回流增强；禁碱性灌肠、禁碱性利尿。
- [ ] 转运两路：丙氨酸-葡萄糖循环（骨骼肌 $\leftrightarrow$ 肝）；谷氨酰胺（脑、骨骼肌 $\to$ 肝或肾）。
- [ ] 谷氨酰胺合成酶耗 $\mathrm{ATP}$；谷氨酰胺酶水解；两酶不可逆、不是一对。
- [ ] 天冬酰胺酶降低血中天冬酰胺，用于白血病（白血病细胞自身合成不足）。
- [ ] 去路：肝写尿素为主，正常占排氮 $80\%\sim 90\%$；肾铵盐为辅。
- [ ] $1932$ 年 Krebs、Henseleit：鸟氨酸循环；哺乳类肝有精氨酸酶。
- [ ] 五步：①$\mathrm{CPS}$ Ⅰ（线粒体，不可逆，需 $\mathrm{AGA}$，$2\,\mathrm{ATP}$）；②$\mathrm{OCT}$（线粒体）；③精氨酸代琥珀酸合成酶（胞质，第二氮来自天冬氨酸，活性最低）；④裂解酶（精氨酸 $+$ 延胡索酸）；⑤精氨酸酶（尿素 $+$ 鸟氨酸）。
- [ ] 总反应：$2\mathrm{NH}_3+\mathrm{CO}_2+3\mathrm{ATP}+3\mathrm{H}_2\mathrm{O}\to$ 尿素 $+2\mathrm{ADP}+\mathrm{AMP}+4\mathrm{P}_\mathrm{i}$。
- [ ] 调节：高蛋白尿素可占排出氮 $90\%$，低蛋白约 $60\%$；精氨酸激活 $\mathrm{AGA}$ 合酶从而激活 $\mathrm{CPS}$ Ⅰ。
- [ ] 高血氨症：肝损伤或酶缺陷；肝性脑病：$\alpha$-酮戊二酸减少和／或脑水肿。
:::
