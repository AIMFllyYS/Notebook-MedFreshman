# 第一节　脂溶性维生素

本章打开维生素。先把维生素写成人体不能合成或合成量甚少、必须由食物供给的一类低分子量有机化合物：不是组织组成成分，也不是供能物质，却在调节物质代谢、生长发育和维持正常生理功能上必不可少。再按溶解特性分成脂溶和水溶两本账。本节只写维生素 A、D、E、K：随脂质吸收、主要储于肝、不需每日供给，过量可中毒。第二节才写 B 族和维生素 C 的辅因子账。

维生素（vitamin）是人体内不能合成或合成量甚少，不能满足机体需要，必须由食物供给的一类低分子量有机化合物，是人体的重要营养素之一。维生素不是机体组织的组成成分，也不是供能物质，然而在调节人体物质代谢、生长发育和维持正常生理功能等方面却发挥着极其重要的作用。人体对维生素的日需要量极少，但如果人体长期摄入不足或吸收障碍，可致维生素缺乏症；若人体长期过量摄取某些维生素，也可导致维生素中毒。按照溶解特性，维生素可分为脂溶性维生素（fat-soluble vitamin）和水溶性维生素（water-soluble vitamin）两大类。

:::definition{label="维生素"}
维生素（vitamin）是人体内不能合成或合成量甚少，不能满足机体需要，必须由食物供给的一类低分子量有机化合物，是人体的重要营养素之一。它不是机体组织的组成成分，也不是供能物质。
:::

:::definition{label="脂溶性维生素"}
脂溶性维生素（fat-soluble vitamin）是疏水性化合物，易溶于脂质和有机溶剂，常随脂质被吸收，包括维生素 A、维生素 D、维生素 E 和维生素 K。
:::

:::definition{label="水溶性维生素"}
水溶性维生素（water-soluble vitamin）溶于水而不溶于脂肪和有机溶剂。本章把它写成另一大类，第二节展开：B 族维生素和维生素 C。
:::

:::compare{title="脂溶性与水溶性维生素（本节先立两本账）"}
| 项目 | 脂溶性维生素 | 水溶性维生素 |
|------|--------------|--------------|
| 成员 | 维生素 A、D、E、K | B 族（$\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{PP}$、泛酸、生物素、$\mathrm{B}_{6}$、叶酸、$\mathrm{B}_{12}$）和维生素 C |
| 溶解 | 疏水，易溶于脂质和有机溶剂 | 溶于水，不溶于脂肪和有机溶剂 |
| 吸收与运输 | 常随脂质吸收；血液中与脂蛋白或特异性蛋白质结合而运输 | 依赖食物提供；体内很少蓄积 |
| 储存与排泄 | 不易排泄，主要储存于肝，故不需每日供给 | 过多可随尿排出，一般不中毒 |
| 缺乏与中毒 | 脂质吸收障碍或食物长期缺乏 → 缺乏症；摄入过多可中毒 | 供给不足往往导致缺乏症；一般不发生中毒 |
| 本节深度 | 本节专节 | 点名分类，正文交给第二节 |
:::

:::concept{term="先问溶不溶于脂，再问是储在肝还是随尿走"}
看见“维生素”，不要立刻背缺乏症。先按溶解特性分户：脂溶随脂质走、储于肝、过量可中毒；水溶当辅因子、很少蓄积、缺了才出病。把四类脂溶听成“都是抗氧化剂”，视循环、钙磷和凝血会没有户头。
:::

:::pitfall{label="维生素不是组织砖块，也不是燃料"}
教材先写两句否定：不是机体组织的组成成分，也不是供能物质。日需要量极少，不等于可有可无——长期摄入不足或吸收障碍可致缺乏症，长期过量摄取某些维生素也可中毒。不要把“需要量极少”听成“吃多了也没事”。
:::

脂溶性维生素是疏水性化合物，易溶于脂质和有机溶剂，常随脂质被吸收，包括维生素 A、维生素 D、维生素 E 和维生素 K。脂溶性维生素在血液中与脂蛋白质或特异性蛋白质结合而运输，不易被排泄，在体内主要储存于肝，故不需每日供给。维生素 A、维生素 D、维生素 E 和维生素 K 的结构不同（图6-1），执行不同的生物化学与生理功能。脂质吸收障碍和食物中长期缺乏此类维生素可引起相应的缺乏症，摄入过多则可发生中毒。

::figure{src="/images/biochemistry/textbook/p0122_02.png" caption="图6-1　脂溶性维生素的结构。左上：维生素 A（视黄醇）；右上：维生素 K₁（叶绿醌）；左下：维生素 E（生育三烯酚）；右下：维生素 D（胆钙化醇）。" alt="四种结构式：视黄醇带 β-白芷酮环和多烯醇侧链；叶绿醌为 2-甲基-1,4-萘醌带异戊二烯侧链；生育三烯酚为苯骈二氢吡喃带不饱和侧链；胆钙化醇为环戊烷多氢菲开 B 环"}

图6-1 把四套骨架画在同一页，只说明它们都疏水。A 走视循环和视黄酸受体，D 走 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 调节钙磷，E 走脂溶性抗氧化，K 走 $\gamma$-羧化凝血。脂质吸收障碍可以四种一起缺，缺了出现哪一种病，仍要按各自活性形式记账。
:::

## 一、维生素A 主要参与视循环

### （一）维生素A 是不饱和一元醇

维生素 A（vitamin A）是由 $1$ 分子 $\beta$-白芷酮环和 $2$ 分子异戊二烯构成的不饱和一元醇。天然维生素 A 指 A₁，即视黄醇（retinol），主要存在于哺乳类动物和咸水鱼肝中。维生素 A₂ 即 3-脱氢视黄醇，存在于淡水鱼肝中。

:::definition{label="维生素A"}
维生素 A（vitamin A）是由 $1$ 分子 $\beta$-白芷酮环和 $2$ 分子异戊二烯构成的不饱和一元醇。天然维生素 A 指 A₁，即视黄醇（retinol）。
:::

:::definition{label="维生素A1 与维生素A2"}
维生素 A₁ 即视黄醇，主要存在于哺乳类动物和咸水鱼肝中。维生素 A₂ 即 3-脱氢视黄醇，存在于淡水鱼肝中。
:::

:::compare{title="A1 和 A2 先分产地"}
| 名称 | 化学 | 主要来源 |
|------|------|----------|
| 维生素 A₁（视黄醇） | 天然维生素 A 所指的那一种 | 哺乳类动物和咸水鱼肝 |
| 维生素 A₂（3-脱氢视黄醇） | 环上多一处脱氢 | 淡水鱼肝 |
:::

肝、肉类、蛋黄、乳制品等动物性食品都是维生素 A 的丰富来源。食物中的维生素 A 主要以酯的形式存在，受小肠酯酶的水解生成视黄醇，进入小肠黏膜上皮细胞后又重新被酯化，并掺入乳糜微粒，通过淋巴转运。乳糜微粒中的视黄醇酯可被肝细胞摄取并被水解为游离视黄醇。在血液中，视黄醇与视黄醇结合蛋白质（retinol binding protein，RBP）相结合，后者再结合甲状腺素视黄质运载蛋白质（transthyretin，TTR），形成视黄醇-RBP-TTR 复合体。在细胞内，视黄醇与细胞中 RBP 结合。肝细胞内过多的视黄醇被转移到肝内星状细胞，以视黄醇酯的形式储存。

:::definition{label="视黄醇-RBP-TTR 复合体"}
血液中视黄醇与视黄醇结合蛋白质（RBP）相结合，RBP 再结合甲状腺素视黄质运载蛋白质（transthyretin，TTR），形成视黄醇-RBP-TTR 复合体，作为循环运输形式。
:::

:::timeline{period="维生素A 从食物酯到肝储存"}
- **食物** 主要以酯的形式存在于肝、肉类、蛋黄、乳制品等
- **小肠腔** 酯酶水解生成视黄醇
- **黏膜上皮** 重新酯化，掺入乳糜微粒，经淋巴转运
- **肝细胞** 摄取视黄醇酯并水解为游离视黄醇
- **血液** 视黄醇-RBP-TTR 复合体运输
- **细胞内** 与细胞中 RBP 结合
- **储存** 过多的视黄醇转到肝内星状细胞，以视黄醇酯形式储存
:::

:::pitfall{label="血液里走的是视黄醇-RBP-TTR，不是“溶在血脂里随便漂”"}
脂溶性维生素确实随脂质吸收，但维生素 A 入血后有专一的 RBP，再挂上 TTR。后文中毒写明：摄入量超过 RBP 结合能力，游离维生素 A 才会破坏膜系统。把运输听成“跟乳糜微粒一直走到底”，星状细胞储存和 RBP 过载两笔都会对不上。
:::

植物中含有被称为维生素 A 原（provitamin A）的多种胡萝卜素，其中以 $\beta$-胡萝卜素（$\beta$-carotene）最为重要。$\beta$-胡萝卜素可在小肠黏膜细胞或肝中被双加氧酶分解生成 $2$ 分子全反式视黄醇。小肠黏膜每分解 $6$ 分子 $\beta$-胡萝卜素仅获得 $1$ 分子视黄醇，即 $\beta$-胡萝卜素转化为维生素 A 的转化当量仅为 $1/6$。

:::definition{label="维生素A原与β-胡萝卜素"}
植物中含多种胡萝卜素，称为维生素 A 原（provitamin A），其中以 $\beta$-胡萝卜素最为重要。$\beta$-胡萝卜素可在小肠黏膜细胞或肝中被双加氧酶分解生成 $2$ 分子全反式视黄醇。
:::

:::definition{label="β-胡萝卜素的转化当量"}
小肠黏膜每分解 $6$ 分子 $\beta$-胡萝卜素仅获得 $1$ 分子视黄醇，即 $\beta$-胡萝卜素转化为维生素 A 的转化当量仅为 $1/6$。
:::

:::insight{label="理论切出两分子，记账只按六分之一"}
双加氧酶可以把一分子 $\beta$-胡萝卜素切成两分子全反式视黄醇，这是化学账。膳食换算走另一本：小肠黏膜每分解六分子只得到一分子视黄醇。不要用“一分子胡萝卜素等于两分子维生素 A”去算推荐摄入量。
:::

### （二）维生素A 不仅参与视循环还是抗氧化剂

在细胞内，醇脱氢酶催化视黄醇和视黄醛（retinal）之间的可逆反应。视黄醛在视黄醛脱氢酶的催化下又不可逆氧化生成视黄酸（retinoic acid）。视黄醇、视黄醛和视黄酸是维生素 A 的活性形式。

:::definition{label="维生素A 的三种活性形式"}
视黄醇、视黄醛和视黄酸是维生素 A 的活性形式。醇脱氢酶催化视黄醇与视黄醛之间的可逆反应；视黄醛脱氢酶催化视黄醛不可逆氧化生成视黄酸。
:::

:::compare{title="三种活性形式怎么互变"}
| 形式 | 英文 | 与相邻形式的关系 | 主要落点 |
|------|------|------------------|----------|
| 视黄醇 | retinol | 醇脱氢酶可逆 ↔ 视黄醛 | 运输、储存、进入视循环 |
| 视黄醛 | retinal | 视黄醛脱氢酶不可逆 → 视黄酸 | 11-顺视黄醛构成视紫红质 |
| 视黄酸 | retinoic acid | 由视黄醛不可逆氧化而来 | 核受体，调控基因与分化 |
:::

:::pitfall{label="视黄酸变不回视黄醛，夜盲不能靠“补视黄酸”走视循环"}
教材把视黄醇 ↔ 视黄醛写成可逆，视黄醛 → 视黄酸写成不可逆。视循环用的是 11-顺视黄醛，基因调控用的是全反式视黄酸和 9-顺视黄酸。把三种活性形式听成可以随便互换，夜盲和银屑病会并成同一条路。
:::

**1. 视黄醛参与视觉传导**　人视网膜的光受体细胞分为锥状细胞和杆状细胞。锥状细胞可感受亮光和产生色觉，杆状细胞则感受弱光或暗光。在人视网膜杆状细胞内，全反式视黄醇在异构酶的作用下生成 11-顺视黄醇，并进而氧化为 11-顺视黄醛，后者与光敏感视蛋白结合生成视紫红质。弱光可使视紫红质中 11-顺视黄醛和视蛋白分别发生构型和构象改变，生成含全反式视黄醛的光视紫红质。光视紫红质再经一系列构象变化，生成变视紫红质Ⅱ，后者引起视觉神经冲动并随之解离释放全反式视黄醛和视蛋白。全反式视黄醛经还原生成全反式视黄醇，从而完成视循环（visual cycle）（图6-2）。可见，视紫红质是暗视觉的基础。

:::definition{label="视紫红质"}
11-顺视黄醛与光敏感视蛋白结合生成视紫红质。视紫红质是暗视觉的基础。
:::

:::definition{label="视循环"}
视循环（visual cycle）是杆状细胞内维生素 A 参与暗视觉的循环：全反式视黄醇经异构、氧化成为 11-顺视黄醛，与视蛋白结合成视紫红质；弱光下变为光视紫红质、再变为视紫红质Ⅱ，引起神经冲动并解离，全反式视黄醛还原回全反式视黄醇。
:::

::figure{src="/images/biochemistry/textbook/p0123_01.png" caption="图6-2　视循环。全反式视黄醇经异构酶变为 11-顺视黄醇，氧化为 11-顺视黄醛，与视蛋白结合成视紫红质；光照生成含全反式视黄醛的光视紫红质，再经变视紫红质Ⅱ引起视觉神经冲动，解离后还原回全反式视黄醇。" alt="环形流程：全反视黄醇→11-顺视黄醇→11-顺视黄醛→视紫红质→光视紫红质→变视紫红质Ⅱ，同时放出视蛋白并引出视觉神经冲动，再回到全反视黄醛和全反视黄醇"}

:::timeline{period="视循环（杆状细胞，图6-2）"}
- **异构** 全反式视黄醇在异构酶作用下生成 11-顺视黄醇
- **氧化** 11-顺视黄醇氧化为 11-顺视黄醛
- **成视紫红质** 11-顺视黄醛与光敏感视蛋白结合
- **弱光** 11-顺视黄醛构型改变、视蛋白构象改变，生成含全反式视黄醛的光视紫红质
- **变视紫红质Ⅱ** 光视紫红质再经一系列构象变化；引起视觉神经冲动
- **解离** 释放全反式视黄醛和视蛋白
- **还原** 全反式视黄醛还原生成全反式视黄醇，循环闭合
:::

:::compare{title="锥状细胞与杆状细胞（本节只为视循环服务）"}
| 细胞 | 感受 | 与维生素 A 的关系 |
|------|------|-------------------|
| 锥状细胞 | 亮光和色觉 | 本节点名，不展开色觉色素 |
| 杆状细胞 | 弱光或暗光 | 视紫红质所在；暗视觉的基础 |
:::

:::keypoint{label="视循环先记三处构型／构象"}
- 进入视紫红质的是 11-顺视黄醛，不是全反式。
- 弱光改的是视黄醛的构型和视蛋白的构象，产物是含全反式视黄醛的光视紫红质。
- 引起冲动的是变视紫红质Ⅱ；解离后还原回全反式视黄醇，才能再异构。
:::

:::tip{label="从明处到暗处看不清，先问 11-顺视黄醛够不够"}
视紫红质是暗视觉的基础。11-顺视黄醛补充不足 → 视紫红质合成减少 → 对弱光敏感性降低 → 暗适应时间延长，严重即夜盲症。后文缺乏症这一笔，户头就在图6-2。
:::

**2. 视黄酸调控基因表达和细胞生长与分化**　视黄醇的不可逆氧化产物全反式视黄酸（all-trans retinoic acid，ATRA）和 9-顺视黄酸可与细胞内核受体结合，通过结合 DNA 反应元件，调节基因表达，进而调控细胞的生长、发育和分化。如 ATRA 可参与上皮组织的正常角化过程而用于银屑病的治疗。此外，维生素 A 及其衍生物 ATRA 具有诱导肿瘤细胞分化和凋亡、增加癌细胞对化疗药物敏感性的作用。

:::definition{label="全反式视黄酸（ATRA）"}
全反式视黄酸（all-trans retinoic acid，ATRA）是视黄醇不可逆氧化产物之一。它与 9-顺视黄酸可结合细胞内核受体，再结合 DNA 反应元件，调控生长、发育和分化。
:::

:::example{label="ATRA 用于银屑病"}
ATRA 可参与上皮组织的正常角化过程，因而用于银屑病的治疗。这是基因调控那一本账，不是视循环。
:::

:::insight{label="抗癌那一笔也落在分化和凋亡，不是抗氧化的别名"}
教材写维生素 A 及其衍生物 ATRA 可诱导肿瘤细胞分化和凋亡，并增加癌细胞对化疗药物的敏感性。不要把这一句并进后文“清除活性氧”。视黄酸走核受体，抗氧化走硫氧还蛋白还原酶和 $\mathrm{NO}$。
:::

**3. 维生素A 是有效的抗氧化剂**　维生素 A 具有清除活性氧和防止脂质过氧化的作用。维生素 A 主要通过调控硫氧还蛋白还原酶的基因表达及相关信号通路，影响 $\mathrm{NO}$ 的生成，从而发挥其抗氧化功能。

:::definition{label="维生素A 的抗氧化作用"}
维生素 A 可清除活性氧并防止脂质过氧化。教材把它主要写成：调控硫氧还蛋白还原酶的基因表达及相关信号通路，影响 $\mathrm{NO}$ 的生成。
:::

:::compare{title="维生素A 的三项功能不要并户"}
| 功能 | 关键分子 | 教材落点 |
|------|----------|----------|
| 视觉传导 | 11-顺视黄醛、视紫红质 | 杆状细胞暗视觉；图6-2 |
| 调控基因与分化 | ATRA、9-顺视黄酸、核受体 | 上皮角化、银屑病；诱导肿瘤分化凋亡 |
| 抗氧化 | 活性氧、脂质过氧化、硫氧还蛋白还原酶、$\mathrm{NO}$ | 有效的抗氧化剂 |
:::

### （三）维生素A 缺乏症可致夜盲症和眼干燥症

若 11-顺视黄醛的补充不足，视紫红质合成减少，对弱光敏感性降低，从明处到暗处看清物质所需的时间即暗适应时间延长，严重时导致夜盲症（nyctalopia）。维生素 A 缺乏可引起眼结膜黏液分泌细胞的丢失与角化，以及糖蛋白分泌的减少，均可引起角膜干燥，出现眼干燥症（xerophthalmia）。

:::definition{label="夜盲症"}
夜盲症（nyctalopia）：11-顺视黄醛补充不足 → 视紫红质合成减少 → 对弱光敏感性降低 → 暗适应时间延长，严重时不能在暗处视物。
:::

:::definition{label="眼干燥症"}
眼干燥症（xerophthalmia）：维生素 A 缺乏引起眼结膜黏液分泌细胞丢失与角化，以及糖蛋白分泌减少，导致角膜干燥。
:::

:::definition{label="暗适应时间"}
从明处到暗处看清物质所需的时间称为暗适应时间。视紫红质不足时该时间延长。
:::

:::cause-effect{title="维生素A 缺乏怎样变成夜盲和眼干"}
- **因** 11-顺视黄醛不足，视紫红质合成减少；同时结膜黏液分泌细胞丢失、角化，糖蛋白分泌减少
- **果** 暗适应时间延长，严重为夜盲症；角膜干燥，出现眼干燥症
:::

:::pitfall{label="夜盲和眼干燥不是同一条链上的轻重两级"}
夜盲走视紫红质和杆状细胞；眼干燥走结膜黏液细胞、角化和糖蛋白分泌。都是维生素 A 缺乏，机制不要并成“眼睛缺维生素 A”。思考题“简述夜盲症的发病机制”要写到 11-顺视黄醛和视紫红质，不是只写“缺乏维生素 A”。
:::

如果维生素 A 的摄入量超过 RBP 的结合能力，游离的维生素 A 可通过破坏细胞膜、核膜以及线粒体和内质网等细胞器造成组织损伤。中国成人男性膳食维生素 A 的推荐摄入量（recommended nutrient intake，RNI）为 $770\,\mu\mathrm{g}/\mathrm{d}$ 的视黄醇活性当量（retinol activity equivalent，RAE），成人女性为 $660\,\mu\mathrm{g}/\mathrm{d}$。如果长期过量摄入维生素 A 可出现中毒，其症状主要有头痛、恶心、共济失调等中枢神经系统表现；肝细胞损伤和高脂血症；长骨增厚、高钙血症等钙稳态失调表现以及皮肤干燥、脱屑和脱发等表现。

:::definition{label="推荐摄入量（RNI）"}
推荐摄入量（recommended nutrient intake，RNI）是本章给出膳食需要量的口径之一。维生素 A 另用视黄醇活性当量（retinol activity equivalent，RAE）计量。
:::

:::keypoint{label="维生素A 的 RNI 与中毒"}
- 中国成人男性：$770\,\mu\mathrm{g}/\mathrm{d}$（RAE）；成人女性：$660\,\mu\mathrm{g}/\mathrm{d}$。
- 超过 RBP 结合能力 → 游离维生素 A 破坏细胞膜、核膜、线粒体和内质网。
- 中毒表现：头痛、恶心、共济失调；肝细胞损伤和高脂血症；长骨增厚、高钙血症；皮肤干燥、脱屑、脱发。
:::

:::pitfall{label="中毒的开关是 RBP 结合能力，不是“脂溶性就会中毒”"}
四种脂溶都可以因摄入过多中毒，但维生素 A 教材写明的机制是游离型破坏膜系统。后文维生素 D 中毒走高钙血症和软组织钙化，维生素 E 则人类尚未发现中毒症。不要用同一句“储于肝所以中毒”套四种。
:::

## 二、维生素D 主要参与调节钙磷代谢

### （一）维生素D 是环戊烷多氢菲类化合物

维生素 D（vitamin D）是类固醇的衍生物，为环戊烷多氢菲类化合物。维生素 D 为无色结晶，易溶于脂肪和有机溶剂，除对光敏感外，其化学性质较稳定。

:::definition{label="维生素D"}
维生素 D（vitamin D）是类固醇的衍生物，为环戊烷多氢菲类化合物。无色结晶，易溶于脂肪和有机溶剂；除对光敏感外，化学性质较稳定。
:::

天然维生素 D 包括 D₃ 或称胆钙化醇（cholecalciferol），以及 D₂ 或称麦角钙化醇（ergocalciferol）。鱼油、蛋黄、肝富含维生素 D₃。人体皮肤储存有从胆固醇生成的 7-脱氢胆固醇（维生素 D₃ 原），在紫外线的照射下，可转变成维生素 D₃。适当的日光浴足以满足人体对维生素 D 的需要。植物中的麦角固醇（维生素 D₂ 原）在紫外线的照射下，可转变成维生素 D₂。

:::definition{label="维生素D3（胆钙化醇）"}
维生素 D₃ 又称胆钙化醇（cholecalciferol）。鱼油、蛋黄、肝富含。皮肤中的 7-脱氢胆固醇（维生素 D₃ 原）经紫外线照射转变成维生素 D₃。
:::

:::definition{label="维生素D2（麦角钙化醇）"}
维生素 D₂ 又称麦角钙化醇（ergocalciferol）。植物中的麦角固醇（维生素 D₂ 原）经紫外线照射转变成维生素 D₂。
:::

:::definition{label="7-脱氢胆固醇"}
7-脱氢胆固醇是从胆固醇生成、储存于皮肤的维生素 D₃ 原。紫外线照射下转变成维生素 D₃。适当日光浴足以满足人体对维生素 D 的需要。
:::

:::compare{title="D3 原和 D2 原不要并成“晒太阳”"}
| 项目 | 维生素 D₃ | 维生素 D₂ |
|------|-----------|-----------|
| 别名 | 胆钙化醇 | 麦角钙化醇 |
| 前体（“原”） | 7-脱氢胆固醇（皮肤，由胆固醇生成） | 麦角固醇（植物） |
| 转变条件 | 紫外线 | 紫外线 |
| 食物 | 鱼油、蛋黄、肝 | 本节未把植物性食物写成 D₃ 来源 |
:::

进入血液的维生素 D₃ 主要与血浆中维生素 D 结合蛋白质（vitamin D binding protein，DBP）结合而运输。在肝微粒体 25-羟化酶的催化下，维生素 D₃ 被羟化生成 25-羟维生素 D₃（$25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$）。$25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 是血浆中维生素 D₃ 的主要存在形式，也是在肝中的主要储存形式。$25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 在肾小管上皮细胞线粒体 $1\alpha$-羟化酶的作用下，生成维生素 D₃ 的活性形式 $1,25$-二羟维生素 D₃［$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$］。$25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 和 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 在血液中均与 DBP 结合而运输。

肾小管上皮细胞还存在 24-羟化酶，催化 $25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 羟化生成 $24,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$。$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 通过诱导 24-羟化酶和阻遏 $1\alpha$-羟化酶的生物合成来控制其自身的生成量（图6-3）。

:::definition{label="维生素D结合蛋白质（DBP）"}
进入血液的维生素 D₃ 主要与血浆维生素 D 结合蛋白质（DBP）结合而运输。$25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 和 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 在血液中也均与 DBP 结合。
:::

:::definition{label="25-羟维生素D3"}
$25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 由肝微粒体 25-羟化酶催化维生素 D₃ 羟化生成。它是血浆中维生素 D₃ 的主要存在形式，也是肝中的主要储存形式。尚不是活性形式。
:::

:::definition{label="1,25-二羟维生素D3"}
$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 由肾小管上皮细胞线粒体 $1\alpha$-羟化酶催化 $25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 羟化生成，是维生素 D₃ 的活性形式。
:::

:::definition{label="24-羟化酶与自身反馈"}
肾小管上皮细胞 24-羟化酶催化 $25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 生成 $24,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$。$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 诱导 24-羟化酶、阻遏 $1\alpha$-羟化酶的生物合成，从而控制自身生成量。
:::

::figure{src="/images/biochemistry/textbook/p0124_01.png" caption="图6-3　维生素 D₃ 在体内的转变。胆固醇在皮肤脱氢成 7-脱氢胆固醇，紫外线（日光）下生成 D₃；肝 25-羟化酶生成 25-(OH)-D₃；肾 1α-羟化酶生成活性 1,25-(OH)₂-D₃，24-羟化酶生成 24,25-(OH)₂-D₃，并可继续羟化为 1,24,25-(OH)₃-D₃。" alt="流程图：胆固醇→7-脱氢胆固醇→D3→25-(OH)-D3，再分别经肾 1α-羟化酶和 24-羟化酶走向 1,25-(OH)2-D3、24,25-(OH)2-D3 和 1,24,25-(OH)3-D3"}

:::timeline{period="维生素D3 在体内的转变（图6-3）"}
- **皮肤** 胆固醇脱氢生成 7-脱氢胆固醇（维生素 D3 原）
- **紫外线（日光）** 7-脱氢胆固醇转变成 D3
- **肝** 25-羟化酶生成 25-(OH)-D3（血浆主要形式、肝储存形式）
- **肾（活化）** 1α-羟化酶生成 1,25-(OH)2-D3（活性形式）
- **肾（旁路）** 24-羟化酶生成 24,25-(OH)2-D3；两条路可再羟化成 1,24,25-(OH)3-D3
- **负反馈** 1,25-(OH)2-D3 诱导 24-羟化酶、阻遏 1α-羟化酶，控制自身生成量
:::

:::pitfall{label="活性形式在肾，不在肝；25-OH-D3 是储存和循环主力"}
肝只做 25-羟化。活性型 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 要等肾小管上皮细胞线粒体的 $1\alpha$-羟化酶。测循环维生素 D 水平，教材对应的是血浆中的 $25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$，不要把它听成已经活化。24-羟化酶是自身生成量的刹车，不是另一条“更活性”的路。
:::

:::note{label="图6-3 比正文多画出 1,24,25-(OH)3-D3"}
正文写 24-羟化酶催化 $25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$ 生成 $24,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$，并写 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 诱导 24-羟化酶、阻遏 $1\alpha$-羟化酶。图中还画出 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 经 24-羟化、$24,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 经 $1\alpha$-羟化，都通向 $1,24,25\text{-}(\mathrm{OH})_{3}\text{-}\mathrm{D}_{3}$。活性形式仍是 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$。
:::

### （二）维生素D 不仅调节钙磷代谢还可影响细胞分化

**1. $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 调节钙磷代谢**　$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 可与靶细胞内特异的核受体结合，进入细胞核，调节钙结合蛋白质、骨钙蛋白质等基因的表达。$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 还可通过钙通道实现对钙磷代谢的快速调节。$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 促进小肠对钙、磷的吸收，从而维持血钙和血磷的正常水平，促进骨和牙的钙化。

:::definition{label="1,25-(OH)2-D3 对钙磷的调节"}
$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 与靶细胞特异核受体结合，调节钙结合蛋白质、骨钙蛋白质等基因的表达；还可通过钙通道快速调节。它促进小肠对钙、磷的吸收，维持血钙和血磷正常水平，促进骨和牙的钙化。
:::

:::compare{title="核受体慢调节与钙通道快调节"}
| 方式 | 教材机制 | 生理后果 |
|------|----------|----------|
| 核受体 | 进入细胞核，调节钙结合蛋白质、骨钙蛋白质等基因表达 | 转录水平改变钙磷相关蛋白 |
| 钙通道 | 对钙磷代谢的快速调节 | 不经过那一套基因表达 |
| 共同落点 | 促进小肠吸收钙、磷 | 血钙血磷正常，骨和牙钙化 |
:::

**2. $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 影响细胞分化**　皮肤、大肠、乳腺、心、脑、胰岛 $\beta$ 细胞、T 和 B 淋巴细胞等均存在维生素 D 受体。$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 不仅能促进胰岛 $\beta$ 细胞合成与分泌胰岛素对抗糖尿病，还具有抑制某些肿瘤细胞增殖和促进分化的作用。低日照与大肠癌和乳腺癌的高发病率和死亡率有一定的相关性。

:::keypoint{label="维生素D 受体不只在骨和肠"}
- 点名组织：皮肤、大肠、乳腺、心、脑、胰岛 $\beta$ 细胞、T 和 B 淋巴细胞。
- 胰岛：促进 $\beta$ 细胞合成与分泌胰岛素，对抗糖尿病。
- 肿瘤：抑制某些肿瘤细胞增殖并促进分化。
- 低日照与大肠癌、乳腺癌的高发病率和死亡率有一定相关性。
:::

:::insight{label="钙磷是主职，分化是同一活性分子的另一本账"}
活性形式只有 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$。核受体在肠和骨上写钙结合蛋白、骨钙蛋白；在胰岛和多种上皮上写胰岛素和抗增殖。不要另造一种“抗癌维生素 D”。
:::

### （三）维生素D 缺乏可致佝偻病和骨质疏松症

中国居民膳食维生素 D 的 RNI 为 $10\,\mu\mathrm{g}/\mathrm{d}$。当缺乏维生素 D 时，儿童可患佝偻病（rachitis），成人可发生软骨病（osteomalacia）和骨质疏松症（osteoporosis）。研究也显示，循环维生素 D 水平与癌症发展和死亡风险之间存在一定的相关性。

长期每日过量摄入维生素 D 可引起中毒。维生素 D 中毒的症状主要有皮肤瘙痒、厌食、嗜睡、呕吐、腹泻、尿频以及高钙血症、高血压以及软组织钙化等。由于皮肤储存 7-脱氢胆固醇有限，多晒太阳不会引起维生素 D 中毒。

:::definition{label="维生素D 缺乏症"}
缺乏维生素 D 时，儿童可患佝偻病（rachitis），成人可发生软骨病（osteomalacia）和骨质疏松症（osteoporosis）。
:::

:::cause-effect{title="维生素D 缺乏怎样落到骨"}
- **因** 活性 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 不足，小肠钙磷吸收下降，血钙血磷不能维持，骨和牙钙化受阻
- **果** 儿童佝偻病；成人软骨病和骨质疏松症
:::

:::compare{title="维生素D：RNI、缺乏、中毒、晒太阳"}
| 项目 | 教材原句 |
|------|----------|
| RNI | 中国居民膳食维生素 D 的 RNI 为 $10\,\mu\mathrm{g}/\mathrm{d}$ |
| 缺乏 | 儿童佝偻病；成人软骨病和骨质疏松症 |
| 循环水平 | 与癌症发展和死亡风险之间存在一定相关性 |
| 中毒 | 长期每日过量摄入：皮肤瘙痒、厌食、嗜睡、呕吐、腹泻、尿频、高钙血症、高血压、软组织钙化 |
| 日光 | 皮肤储存 7-脱氢胆固醇有限，多晒太阳不会引起维生素 D 中毒 |
:::

:::pitfall{label="晒太阳不会中毒，口服过量会；佝偻病和骨软化不要并成“缺钙”"}
中毒开关是长期每日过量摄入，不是紫外线。第五章钙磷已经把佝偻病、骨软化症写成维生素 D 缺乏 → 钙吸收障碍，分儿童和成人；骨质疏松另有骨基质丧失和脱盐。本节补上活性分子是 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$。英文 rachitis 与第五章 rickets 是同一病、两种写法，户头仍是儿童佝偻病。
:::

## 三、维生素E 主要作为抗氧化剂发挥作用

### （一）维生素E 是苯骈二氢吡喃的衍生物

维生素 E（vitamin E）是苯骈二氢吡喃的衍生物，包括生育酚（tocopherol）和三烯生育酚（tocotrienol）两类，每类又分 $\alpha$、$\beta$、$\gamma$ 和 $\delta$ 四种。天然维生素 E 主要存在于植物油、油性种子和麦芽等中，以 $\alpha$-生育酚分布最广、活性最高。$\alpha$-生育酚是黄色油状液体，溶于乙醇、脂肪和有机溶剂，对热及酸稳定，对碱不稳定，对氧极为敏感。在正常情况下，$20\%\sim 40\%$ 的 $\alpha$-生育酚可被小肠吸收。在机体内，维生素 E 主要存在于细胞膜、血浆脂蛋白和脂库中。

:::

### （二）维生素E 不仅是抗氧化剂也参与基因表达调控

**1. 维生素E 是体内最重要的脂溶性抗氧化剂**　维生素 E 可保护生物膜及其他蛋白质的结构与功能，维持细胞正常的流动性。维生素 E 能够捕捉过氧化脂质自由基，形成反应性较低且相对稳定的生育酚自由基，后者可在维生素 C、GSH 或 NADPH 的作用下，还原生成生育醌。

:::definition{label="维生素E 作为脂溶性抗氧化剂"}
维生素 E 是体内最重要的脂溶性抗氧化剂。它保护生物膜及其他蛋白质的结构与功能，维持细胞正常流动性；捕捉过氧化脂质自由基，形成反应性较低且相对稳定的生育酚自由基。
:::

:::cause-effect{title="生育酚自由基怎样被还原"}
- **因** 维生素 E 捕捉过氧化脂质自由基，自身变成生育酚自由基
- **果** 生育酚自由基可在维生素 C、GSH 或 NADPH 作用下还原生成生育醌；膜上的自由基链被打断
:::

:::insight{label="E 在膜上抓自由基，C、GSH、NADPH 在水相把账接走"}
脂溶性的维生素 E 站在膜和脂蛋白上；还原它的维生素 C、GSH、NADPH 是水溶性还原体系。第二节维生素 C 写抗氧化和 GSH 时，可以回接到这一笔，但本节不要把维生素 E 听成水溶性抗氧化剂。
:::

**2. 维生素E 可调节基因表达**　生育酚摄取和降解、脂质摄取与动脉硬化、细胞黏附与炎症，以及细胞周期等基因表达都受到维生素 E 的调节。维生素 E 还可降低血浆低密度脂蛋白（LDL）的浓度。故维生素 E 在抗炎、维持正常免疫功能，以及预防和治疗冠状动脉粥样硬化性心脏病、肿瘤和延缓衰老方面具有一定的作用。此外，维生素 E 能提高血红素合成的关键酶 $\delta$-氨基-$\gamma$-酮戊酸（ALA）合酶和 ALA 脱水酶的活性，从而促进血红素的合成。

:::keypoint{label="维生素E 除抗氧化之外还管什么"}
- 调节基因表达：生育酚摄取和降解、脂质摄取与动脉硬化、细胞黏附与炎症、细胞周期。
- 降低血浆 LDL 浓度。
- 抗炎、维持免疫；对冠心病、肿瘤和延缓衰老有一定作用。
- 提高 ALA 合酶和 ALA 脱水酶活性，促进血红素合成。
:::

:::note{label="ALA 合酶这一笔后面维生素B6 还要再写"}
本节维生素 E 提高 ALA 合酶和 ALA 脱水酶活性。第二节磷酸吡哆醛是 ALA 合酶的辅因子。两笔都落在血红素合成，不要并成同一种维生素。
:::

### （三）维生素E 严重缺乏可致溶血性贫血

中国成人膳食维生素 E 的 RNI 为 $14\,\mathrm{mg}/\mathrm{d}$ 的 $\alpha$-生育酚当量（$\alpha$-tocopherol equivalent，$\alpha$-TE）。维生素 E 一般不易缺乏，在严重的脂质吸收障碍和肝严重损伤时可引起缺乏症，表现为红细胞数量减少、脆性增加等溶血性贫血症状。动物缺乏维生素 E 时其生殖器官发育受损，甚至不育。人类尚未发现因维生素 E 缺乏所致的不孕症。临床上常用维生素 E 治疗先兆流产及习惯性流产。早产儿可因维生素 E 缺乏引起轻度溶血性贫血。人类尚未发现维生素 E 中毒症。然而，长期大量服用的副作用不能忽略。

:::definition{label="维生素E 缺乏与溶血性贫血"}
维生素 E 一般不易缺乏。严重脂质吸收障碍和肝严重损伤可引起缺乏，表现为红细胞数量减少、脆性增加等溶血性贫血症状。早产儿可因缺乏引起轻度溶血性贫血。
:::

## 四、维生素K 主要参与凝血过程

### （一）维生素K 是2-甲基-1,4-萘醌的衍生物

维生素 K（vitamin K）是 2-甲基-1,4-萘醌的衍生物。存在于自然界的维生素 K 有 K₁ 和 K₂。维生素 K₁ 即叶绿醌，主要存在于深绿色蔬菜（甘蓝、菠菜、莴苣等）和植物油中。维生素 K₂ 即甲基萘醌，也可由大肠埃希菌合成。维生素 K₃ 是人工合成的水溶性甲萘醌，可口服及注射。2-甲基-1,4-萘醌是维生素 K 的活性形式。

维生素 K 主要在小肠被吸收，随乳糜微粒而代谢。体内维生素 K 的储存量有限，脂质吸收障碍可引发维生素 K 缺乏症。

维生素 K（vitamin K）是 2-甲基-1,4-萘醌的衍生物。存在于自然界的有 K₁ 和 K₂。2-甲基-1,4-萘醌是维生素 K 的活性形式。
:::

:::

### （二）维生素K 既参与凝血也能调节骨代谢

**1. 维生素K 是凝血因子和抗凝血因子活化所必需的辅因子**　血液凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ及抗凝血因子蛋白 C 和蛋白 S 在肝细胞中以无活性前体形式合成。无活性前体分子中的谷氨酸残基需在 $\gamma$-羧化酶作用下生成 $\gamma$-羧基谷氨酸残基才能转变为活性形式。$\gamma$-谷氨酰羧化酶的辅因子是维生素 K，故维生素 K 参与凝血过程。

:::definition{label="维生素K 依赖的γ-羧化"}
凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ及抗凝血因子蛋白 C、蛋白 S 在肝中以无活性前体合成。前体中的谷氨酸残基需经 $\gamma$-羧化酶生成 $\gamma$-羧基谷氨酸残基才有活性。$\gamma$-谷氨酰羧化酶的辅因子是维生素 K。
:::

:::keypoint{label="维生素K 依赖的六种蛋白质"}
- 凝血因子：Ⅱ、Ⅶ、Ⅸ、Ⅹ。
- 抗凝血因子：蛋白 C、蛋白 S。
- 共同工序：肝细胞内 $\gamma$-羧化，辅因子是维生素 K。
:::

:::insight{label="既促凝也抗凝，缺了临床先看见出血"}
依赖维生素 K 的既有凝血因子，也有蛋白 C、蛋白 S。缺乏的主要症状仍是易出血，因为活化这一步过不去。不要把维生素 K 听成“只有促凝、没有抗凝”。
:::

**2. 维生素K 可参与调节骨代谢**　肝、骨等组织中存在维生素 K 依赖蛋白质，如骨钙蛋白和 $\gamma$-羧基谷氨酸蛋白。研究表明，服用低剂量维生素 K 的妇女，其股骨颈和脊柱的骨盐密度明显低于服用大剂量维生素 K 时的骨盐密度。此外，大剂量的维生素 K 可降低动脉硬化的危险性。

:::definition{label="维生素K 依赖的骨蛋白质"}
肝、骨等组织中存在维生素 K 依赖蛋白质，如骨钙蛋白和 $\gamma$-羧基谷氨酸蛋白。低剂量维生素 K 的妇女，股骨颈和脊柱骨盐密度明显低于大剂量时。
:::

### （三）维生素K 缺乏可导致出血

中国成人膳食维生素 K 的适宜摄入量（adequate intake，AI）为 $80\,\mu\mathrm{g}/\mathrm{d}$。因维生素 K 广泛分布于动、植物组织，且体内肠菌也能合成，一般不易缺乏。因维生素 K 不能通过胎盘，新生儿肠道内又无细菌，故新生儿可能出现维生素 K 缺乏。维生素 K 缺乏的主要症状是易出血。胰腺、胆管及小肠黏膜萎缩等脂质吸收障碍的疾病均可出现维生素 K 缺乏症。长期应用抗生素及肠道灭菌药也有引起维生素 K 缺乏的可能性。

:::definition{label="适宜摄入量（AI）"}
适宜摄入量（adequate intake，AI）是本章给出需要量的另一口径。中国成人膳食维生素 K 的 AI 为 $80\,\mu\mathrm{g}/\mathrm{d}$。维生素 A、D、E 本节用的是 RNI。
:::

:::cause-effect{title="谁会缺维生素K"}
- **因** 不能通过胎盘且新生儿肠道无细菌；胰腺、胆管及小肠黏膜萎缩等脂质吸收障碍；长期应用抗生素及肠道灭菌药抑制肠菌
- **果** 新生儿可能缺乏；脂质吸收障碍和长期灭菌药也可缺乏；主要症状是易出血
:::

:::memory{label="本节必背要点"}
- [ ] 维生素：人体不能合成或合成量甚少，必须由食物供给的低分子量有机化合物；不是组织成分，也不是供能物质。
- [ ] 日需要量极少；长期摄入不足或吸收障碍 → 缺乏症；长期过量摄取某些维生素 → 中毒。
- [ ] 脂溶：A、D、E、K；随脂质吸收，与脂蛋白或特异性蛋白质运输，储于肝，不需每日供给。
- [ ] 水溶：B 族 + 维生素 C（第二节）；很少蓄积，多余随尿排出。
- [ ] 维生素 A：$1$ 分子 $\beta$-白芷酮环 + $2$ 分子异戊二烯；A₁ 视黄醇（哺乳类、咸水鱼肝），A₂ 3-脱氢视黄醇（淡水鱼肝）。
- [ ] 食物维生素 A 以酯存在 → 小肠水解 → 黏膜再酯化入乳糜微粒 → 肝水解；血中视黄醇-RBP-TTR；多余以酯储于星状细胞。
- [ ] $\beta$-胡萝卜素是最重要的维生素 A 原；双加氧酶可切出 $2$ 分子全反式视黄醇，转化当量仅为 $1/6$。
- [ ] 三种活性形式：视黄醇、视黄醛、视黄酸；醇脱氢酶可逆，视黄醛脱氢酶不可逆。
- [ ] 视循环：全反式视黄醇 → 11-顺视黄醇 → 11-顺视黄醛 + 视蛋白 → 视紫红质；弱光 → 光视紫红质 → 变视紫红质Ⅱ → 冲动并解离 → 还原。
- [ ] 视紫红质是暗视觉的基础；锥状细胞管亮光和色觉，杆状细胞管弱光。
- [ ] ATRA 和 9-顺视黄酸结合核受体；ATRA 用于银屑病；可诱导肿瘤分化凋亡、增敏化疗。
- [ ] 维生素 A 抗氧化：清除活性氧、防止脂质过氧化；调控硫氧还蛋白还原酶，影响 $\mathrm{NO}$。
- [ ] 缺乏：夜盲症（nyctalopia）、眼干燥症（xerophthalmia）。
- [ ] RNI：男 $770\,\mu\mathrm{g}/\mathrm{d}$ RAE，女 $660\,\mu\mathrm{g}/\mathrm{d}$；超过 RBP 结合能力可中毒。
- [ ] 维生素 D：类固醇衍生物，环戊烷多氢菲；D₃ 胆钙化醇，D₂ 麦角钙化醇。
- [ ] 皮肤：胆固醇 → 7-脱氢胆固醇 → 紫外线 → D₃；适当日光浴可满足需要。
- [ ] 运输靠 DBP。肝 25-羟化酶 → $25\text{-}\mathrm{OH}\text{-}\mathrm{D}_{3}$（血浆主要形式、肝储存形式）。
- [ ] 肾 $1\alpha$-羟化酶 → 活性 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$；24-羟化酶 → $24,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$。
- [ ] $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 诱导 24-羟化酶、阻遏 $1\alpha$-羟化酶，控制自身生成量。
- [ ] 活性型促进小肠吸收钙磷，维持血钙血磷，促进骨和牙钙化；也可经钙通道快速调节。
- [ ] 维生素 D 受体还在皮肤、大肠、乳腺、心、脑、胰岛 $\beta$ 细胞、T 和 B 淋巴细胞等。
- [ ] RNI $10\,\mu\mathrm{g}/\mathrm{d}$。缺乏：儿童佝偻病，成人软骨病和骨质疏松症。
