# 第一节　癌症分子基础概述

第二十三章把「癌症在分子上怎样发生」拆成三户。本节只立概述：临床和研究里「癌症」泛指一切恶性肿瘤，但上皮来源的恶性肿瘤才叫癌（carcinoma）；发生是多病因长期作用、多基因协同参与、多阶段逐步发展（图23-1）；外部环境因素是始动，机体内在因素是基础；与癌症发生密切相关的基因分成原癌基因、抑癌基因和基因组维护基因；癌细胞有一套与正常细胞显著不同的生物学特征。原癌基因怎样经功能获得突变变成癌基因、四种活化机制和图23-2，交给第二节。抑癌基因怎样失活、$\mathrm{RB}$ 与 $\mathrm{E2F}$-$1$、野生型 $\mathrm{p}53$ 走 $\mathrm{p}21$ 与 $\mathrm{Bax}$、结肠癌多步（图23-5），交给第三节。基因诊断和基因治疗是第二十四章的账，本节只点到分子诊断和靶向治疗已经改变临床，不把操作细节写进来。

:::concept{term="先分清癌症、肿瘤和癌这三个词，再问外因内因怎样把基因改坏"}
看见「癌症的分子基础」，先不要默写信号通路名单。户头是：癌症（cancer）在临床和研究中泛指一切恶性肿瘤；肿瘤（tumor）还包含良性；上皮组织来源的恶性肿瘤才称为癌（carcinoma）。外因加内因造成基因异常（原癌基因／抑癌基因），产物异常，通路和代谢异常，细胞增殖、分化、运动、死亡失序，才走到细胞癌变和转移。图23-1 右侧的精准医学、分子诊断、靶向治疗是同一条轴的出口，不是另开一章病因学。
:::

:::note{label="电子版缺失"}
教材章题页装饰图未收入电子版，正文保留章题，不嵌入图文件。本节插图为图23-1：左侧从分子到细胞，外因加内因 → 基因异常（原癌基因／抑癌基因）→ 表达产物异常（蛋白质和非编码 $\mathrm{RNA}$）→ 信号通路异常与代谢途径改变 → 细胞增殖、分化、运动、死亡 → 细胞癌变和癌细胞转移；右侧精准医学 → 分子诊断 → 靶向治疗 → 细胞死亡或表型重塑 → 疾病缓解或痊愈。图23-2 在第二节；图23-3 至图23-5 在第三节。
:::

癌症（cancer）是严重威胁全球人类健康和社会发展的重大疾病。在临床和研究工作中，「癌症」一词泛指一切恶性肿瘤。肿瘤（tumor）是机体在致瘤因素作用下，局部组织的细胞异常增殖而形成的新生物（neoplasm），可分为良性肿瘤（benign tumor）和恶性肿瘤（malignant tumor）。上皮组织发生的恶性肿瘤称为癌（carcinoma），$80\%$ 以上的癌症相关死亡由此造成。非上皮组织恶性肿瘤主要有三类：起源于成纤维细胞、脂肪细胞、成骨细胞、肌细胞等间充质细胞的肉瘤（sarcoma）；起源于造血组织细胞的造血系统恶性肿瘤（hematopoietic malignancies），如白血病和淋巴瘤；以及起源于中枢和外周神经系统细胞的神经外胚层恶性肿瘤（neuroectodermal malignancies），如胶质母细胞瘤和神经母细胞瘤。恶性肿瘤一旦形成，还会侵犯邻近正常组织，甚至经淋巴和血道转移至全身，直至引起机体死亡。

:::definition{label="癌症"}
癌症（cancer）：临床和研究工作中泛指一切恶性肿瘤。户头落在「恶性」这一侧，还没有指定组织来源。后一句才把上皮来源单独叫癌。
:::

:::definition{label="肿瘤"}
肿瘤（tumor）：机体在致瘤因素作用下，局部组织的细胞异常增殖而形成的新生物（neoplasm）。本版明确再分成良性肿瘤和恶性肿瘤两户。不是「肿瘤等于癌症」。
:::

:::definition{label="癌"}
癌（carcinoma）：上皮组织发生的恶性肿瘤。$80\%$ 以上的癌症相关死亡由此造成。英文是 carcinoma，不要和 cancer 并成一个词。
:::

:::definition{label="非上皮恶性肿瘤三类"}
①肉瘤（sarcoma）：成纤维细胞、脂肪细胞、成骨细胞、肌细胞等间充质来源。②造血系统恶性肿瘤（hematopoietic malignancies）：如白血病和淋巴瘤。③神经外胚层恶性肿瘤（neuroectodermal malignancies）：如胶质母细胞瘤和神经母细胞瘤。三户都是恶性肿瘤，因而都落在「癌症」这个总称里，但都不是 carcinoma。
:::

:::compare{title="癌症 vs 肿瘤 vs 癌 vs 三类非上皮恶性"}
| | 本版原句 | 组织来源 | 良恶 |
|--|---------|---------|------|
| 癌症 cancer | 泛指一切恶性肿瘤 | 不限 | 只含恶性 |
| 肿瘤 tumor | 局部细胞异常增殖形成的新生物 | 不限 | 良性＋恶性 |
| 癌 carcinoma | 上皮组织发生的恶性肿瘤 | 上皮 | 恶性；造成 $80\%$ 以上癌症相关死亡 |
| 肉瘤 sarcoma | 间充质细胞来源 | 成纤维、脂肪、成骨、肌细胞等 | 恶性 |
| 造血系统恶性肿瘤 | 造血组织细胞来源 | 如白血病、淋巴瘤 | 恶性 |
| 神经外胚层恶性肿瘤 | 中枢和外周神经来源 | 如胶质母细胞瘤、神经母细胞瘤 | 恶性 |

问「癌症是什么」先答恶性肿瘤总称；问「癌是什么」必须点上皮；问「白血病算不算癌」——算癌症，不算 carcinoma。
:::

:::pitfall{label="不要把 cancer 和 carcinoma 并成一个词"}
教材把「癌症」和「癌」分成两句写。cancer 是恶性肿瘤总称；carcinoma 是上皮来源的那一户，并给出 $80\%$ 以上癌症相关死亡。写成「癌症就是癌」或把 sarcoma、白血病也叫「癌」，后文肉瘤、造血系统和神经外胚层三户就没有着落。
:::

:::insight{label="良性肿瘤也叫肿瘤，但不叫癌症"}
肿瘤这一户先出现，再分成良性和恶性。癌症只收恶性。后文「良性肿瘤的细胞不会侵入局部组织或扩散到身体的其他部位」，对照的是转移这一特征，不是「良性就不是新生物」。
:::

本章主要介绍癌症的分子基础，原癌基因、癌基因和抑癌基因的基本概念，并介绍原癌基因激活和抑癌基因失活的机制及其在肿瘤发生发展中的作用。癌症的发生是多病因长期作用、多基因协同参与、多阶段逐步发展的过程（图23-1）。

:::definition{label="多病因、多基因、多阶段"}
癌症的发生是多病因长期作用、多基因协同参与、多阶段逐步发展的过程。三句并列：不是单一毒物、不是单一基因、不是一步就癌变。图23-1 把这三句画成从外因内因到细胞癌变的链条。
:::

::figure{src="/images/biochemistry/textbook/p0461_02.png" caption="图23-1　癌症发生的分子和细胞基础" alt="左侧纵轴标分子与细胞。最上：外部环境因素加机体内在因素，向下为基因异常（旁注原癌基因、抑癌基因），再向下为表达产物异常（蛋白质和非编码RNA），再向下为信号转导通路异常与代谢途径改变（旁注MAPK通路、PI3K/AKT通路、糖代谢重组即有氧糖酵解、核苷酸合成等），再分为细胞增殖、分化、运动、死亡，最下为细胞癌变和癌细胞转移。右侧自上而下：精准医学、分子诊断、靶向治疗，指向细胞死亡或表型重塑，再到疾病缓解或疾病痊愈"}

:::insight{label="图23-1 先认左侧因果链，再认右侧出口"}
画面左侧是发生：外因＋内因 → 基因异常（原癌基因／抑癌基因）→ 产物异常（蛋白质和非编码 $\mathrm{RNA}$）→ 通路异常和代谢途径改变（$\mathrm{MAPK}$、$\mathrm{PI3K}$／$\mathrm{AKT}$、有氧糖酵解、核苷酸合成）→ 增殖／分化／运动／死亡失序 → 细胞癌变和转移。右侧是干预：精准医学 → 分子诊断 → 靶向治疗 → 细胞死亡或表型重塑 → 缓解或痊愈。不要把右侧四格提前写成第二十四章的基因诊断操作。
:::

:::pitfall{label="不要用别的综述清单替换图23-1 的结构"}
本版图上的分子层是基因、产物、通路与代谢；细胞层是增殖、分化、运动、死亡，出口是癌变和转移。通路格子里点名的是 $\mathrm{MAPK}$、$\mathrm{PI3K}$／$\mathrm{AKT}$、有氧糖酵解和核苷酸合成。后文第三节才把结肠癌多步钉成 $\mathrm{APC}\rightarrow\mathrm{K}$-$\mathrm{RAS}\rightarrow\mathrm{DCC}\rightarrow\mathrm{TP}53$。不要把本章改排成另一张「肿瘤特征」总表。
:::

:::keypoint{label="开篇先立四句"}
- 癌症＝恶性肿瘤总称；肿瘤＝新生物，含良性；癌＝上皮来源恶性，造成 $80\%$ 以上癌症相关死亡。
- 非上皮恶性三户：肉瘤、造血系统、神经外胚层。
- 发生：多病因、多基因、多阶段。
- 图23-1：外因内因 → 基因 → 产物 → 通路／代谢 → 细胞行为 → 癌变转移；右侧才是精准医学／分子诊断／靶向治疗。
:::

## 一、癌症发生的危险因素包括外部环境因素和机体内在因素

目前认为，癌症的发生是外部环境因素和机体内在因素共同作用的结果，其中外部环境因素是肿瘤发生的始动因素，机体内在因素是恶性肿瘤发生的基础。

:::definition{label="外因始动、内因基础"}
外部环境因素是肿瘤发生的始动因素；机体内在因素是恶性肿瘤发生的基础。两句都要答。写成「只有环境」或「只有遗传」，图23-1 最上那一格「外部环境因素＋机体内在因素」就缺了一半。
:::

:::compare{title="外部环境因素 vs 机体内在因素"}
| | 本版角色 | 本节名单 | 后文怎样接到基因 |
|--|---------|---------|----------------|
| 外部环境因素 | 始动因素 | 化学、物理、生物、生活方式 | 化学和物理因素常导致 $\mathrm{DNA}$ 损伤进而诱发基因突变 |
| 机体内在因素 | 发生的基础 | 遗传、免疫、营养、激素水平 | 种系突变走遗传性肿瘤综合征；易感基因多态性走散发性肿瘤风险 |

问「谁先把细胞推上癌变轨道」看外因；问「为什么同样暴露只有一部分人发病」看内因。
:::

### （一）外部环境因素包括化学因素、物理因素、生物因素和生活方式

约 $80\%$ 以上的人类肿瘤可能由环境因素引起或与环境因素相关。外部环境因素包括化学因素、物理因素、生物因素和生活方式等。其中化学因素是最主要的致癌因素，约占环境因素的 $90\%$。化学和物理因素常导致 $\mathrm{DNA}$ 损伤进而诱发基因突变（见第二十一章）。

:::definition{label="环境因素占人类肿瘤的八成以上"}
约 $80\%$ 以上的人类肿瘤可能由环境因素引起或与环境因素相关。这是「可能由／相关」，不是「每一个病例都能指出一种毒物」。
:::

:::definition{label="化学因素约占环境因素的九成"}
化学因素是最主要的致癌因素，约占环境因素的 $90\%$。物理、生物、生活方式仍在名单里，只是占比上化学最大。
:::

:::pitfall{label="80% 和 90% 不要并成一个数"}
$80\%$ 以上是「人类肿瘤与环境因素相关」；$90\%$ 是「环境因素里化学因素占多少」。一个是肿瘤对病因，一个是环境因素内部构成。写成「$90\%$ 的肿瘤都是化学致癌」，物理、生物、生活方式三户就空了。
:::

现经动物实验证明的化学致癌物多达 $2\,000$ 余种，主要包括烷化剂类、多环芳烃类、芳香胺类、偶氮染料和亚硝基化合物等。物理致癌因素包括电离辐射、紫外线辐射和石棉等某些矿物纤维，其中电离辐射是最主要的物理致癌因素。生物因素包括病毒、细菌和寄生虫等，其中病毒是最主要的生物致癌因素。与癌症发生密切相关的生活方式包括饮食习惯不合理、过量饮酒、吸烟、肥胖、缺乏体育锻炼和空气污染等。

:::definition{label="化学致癌物本版五类"}
经动物实验证明的化学致癌物多达 $2\,000$ 余种。本版点名：烷化剂类、多环芳烃类、芳香胺类、偶氮染料、亚硝基化合物。数字停在「$2\,000$ 余种」，不要改成另一本手册的条目数。
:::

:::definition{label="物理致癌因素"}
电离辐射、紫外线辐射和石棉等某些矿物纤维。其中电离辐射是最主要的物理致癌因素。石棉写在矿物纤维这一户，不要并进化学致癌物五类。
:::

:::definition{label="生物致癌因素"}
病毒、细菌和寄生虫等。其中病毒是最主要的生物致癌因素。第二节肿瘤病毒（$\mathrm{RSV}$、$\mathrm{HPV}$、$\mathrm{HBV}$）从这里接下，本节只立「病毒是最主要的生物因素」。
:::

:::definition{label="与癌症相关的生活方式"}
饮食习惯不合理、过量饮酒、吸烟、肥胖、缺乏体育锻炼和空气污染等。本版六项并列，不要把空气污染从生活方式里删掉，也不要只背吸烟一户。
:::

:::compare{title="外因四类各自「最主要」是什么"}
| 大类 | 本版「最主要」 | 其余点名 |
|------|--------------|---------|
| 化学 | 约占环境因素 $90\%$ | 烷化剂、多环芳烃、芳香胺、偶氮染料、亚硝基化合物；$2\,000$ 余种 |
| 物理 | 电离辐射 | 紫外线辐射、石棉等矿物纤维 |
| 生物 | 病毒 | 细菌、寄生虫 |
| 生活方式 | 无单一「最主要」 | 饮食不合理、过量饮酒、吸烟、肥胖、缺乏锻炼、空气污染 |

问「环境里最大的致癌因素」答化学；问「物理里最主要」答电离辐射；问「生物里最主要」答病毒。
:::

:::insight{label="化学和物理走 DNA 损伤，生物因素不一定走同一条"}
「化学和物理因素常导致 $\mathrm{DNA}$ 损伤进而诱发基因突变」指向第二十一章。病毒致癌在第二节另开：急性转化逆转录病毒自带癌基因，慢性转化靠插入激活，DNA 病毒如 $\mathrm{HPV}$ 的 $\mathrm{E}6$／$\mathrm{E}7$ 对病毒复制是必需的。不要把四类外因都写成「都是把碱基改掉」。
:::

### （二）机体内在因素包括遗传因素、免疫因素、营养因素和激素水平

癌症发生的机体内在因素包括遗传因素、免疫因素、营养因素和激素水平等。个体的遗传特征是决定肿瘤易感性的重要因素。遗传因素包括两个方面：一是癌变通路上关键基因的种系突变（germline mutation），常导致受累个体出现某种遗传性肿瘤综合征；二是一些易感基因多态性可导致携带者对环境致癌因素的敏感性升高，使肿瘤发生风险增加，与常见的散发性肿瘤的发病风险增高密切相关。

:::definition{label="内在因素四户"}
遗传因素、免疫因素、营养因素和激素水平。本节把遗传因素展开成种系突变和易感基因多态性两路；免疫、营养、激素点到「包括」为止，不要在本节编造本版没有写的机制。
:::

:::definition{label="种系突变走遗传性肿瘤综合征"}
癌变通路上关键基因的种系突变（germline mutation），常导致受累个体出现某种遗传性肿瘤综合征。户头是「生来就带着的那一次突变」，第三节二次打击假说里视网膜母细胞瘤的生殖细胞突变从这里接下。
:::

:::definition{label="易感基因多态性走散发性肿瘤风险"}
一些易感基因多态性使携带者对环境致癌因素的敏感性升高，肿瘤发生风险增加，与常见的散发性肿瘤的发病风险增高密切相关。户头是「不一定发病，但同样暴露时更容易」。
:::

:::compare{title="种系突变 vs 易感基因多态性"}
| | 改变落在哪 | 本版临床出口 |
|--|-----------|-------------|
| 种系突变 | 癌变通路上的关键基因 | 遗传性肿瘤综合征 |
| 易感基因多态性 | 对环境致癌因素的敏感性 | 常见散发性肿瘤的发病风险增高 |

问「家族性肿瘤综合征」走种系突变；问「散发性肿瘤为什么有易感」走多态性。两户都是遗传因素，不要并成「有家族史才算遗传」。
:::

:::pitfall{label="内在因素不要写成只有免疫低下"}
教材并列遗传、免疫、营养、激素。遗传又分种系突变和多态性。写成「内因就是免疫监视失败」，种系突变和易感多态性两户就没有对象。
:::

:::keypoint{label="危险因素这一节的数字和分户"}
- 外因始动，内因基础。
- 约 $80\%$ 以上人类肿瘤与环境相关；化学约占环境因素 $90\%$；$2\,000$ 余种化学致癌物。
- 物理最主要是电离辐射；生物最主要是病毒。
- 遗传两路：种系突变 → 遗传性肿瘤综合征；易感多态性 → 散发性肿瘤风险。
:::

## 二、癌症的发生主要涉及三类基因

正常机体内，各种细胞的新生、生长、增殖、分化、衰老和死亡受到多种基因的严格调节和控制，从而确保正常生命活动的有序进行。肿瘤发生的关键正是这些基因异常所导致的细胞增殖失去控制，这也是癌细胞区别于正常细胞的一个显著特征。与癌症发生密切相关的基因，可分为三类：①细胞内正常的原癌基因（proto-oncogene），其作用通常是促进细胞的生长和增殖，阻止细胞分化，抵抗凋亡；②抑癌基因，或称肿瘤抑制基因（tumor suppressor gene），通常抑制增殖，促进分化，诱发凋亡；③基因组维护基因（genome maintenance gene），参与 $\mathrm{DNA}$ 损伤修复，维持基因组完整性。当细胞受到各种致癌因素的作用时，可引起原癌基因或抑癌基因的结构或表达调控异常，导致原癌基因活化或抑癌基因失活，直接导致细胞生长增殖的失控而形成肿瘤。而基因组维护基因的编码产物则不直接抑制细胞增殖，这类基因在致癌因素的作用下发生突变失活后，可导致基因组不稳定，从而间接地通过增加基因突变频率、使原癌基因或抑癌基因突变来引发肿瘤发生。因此，基因组维护基因也可归属于抑癌基因。

:::definition{label="肿瘤发生的关键是增殖失控"}
正常时新生、生长、增殖、分化、衰老和死亡受多种基因严格调节。肿瘤发生的关键是这些基因异常导致细胞增殖失去控制。这是癌细胞区别于正常细胞的一个显著特征。后文「生物学特征」还有遗传组成、代谢、接触抑制、血管生成、侵袭转移，但开这一节的钥匙仍是增殖失控。
:::

:::definition{label="原癌基因"}
原癌基因（proto-oncogene）：细胞内正常的基因。作用通常是促进细胞的生长和增殖，阻止细胞分化，抵抗凋亡。正常条件下编码产物并不具致癌活性；第二节才写它怎样被活化成癌基因。
:::

:::definition{label="抑癌基因"}
抑癌基因，或称肿瘤抑制基因（tumor suppressor gene）：通常抑制增殖，促进分化，诱发凋亡。部分或全部失活可显著增加癌症发生风险。展开是第三节。
:::

:::definition{label="基因组维护基因"}
基因组维护基因（genome maintenance gene）：参与 $\mathrm{DNA}$ 损伤修复，维持基因组完整性。编码产物不直接抑制细胞增殖。突变失活后导致基因组不稳定，间接通过增加突变频率、使原癌基因或抑癌基因突变来引发肿瘤。因此也可归属于抑癌基因。
:::

:::compare{title="原癌基因 vs 抑癌基因 vs 基因组维护基因"}
| | 正常功能 | 癌变时怎样变 | 对增殖的关系 |
|--|---------|------------|-------------|
| 原癌基因 | 促生长增殖，阻止分化，抵抗凋亡 | 活化（功能获得）→ 癌基因 | 直接促增殖 |
| 抑癌基因 | 抑制增殖，促进分化，诱发凋亡 | 失活 | 直接负调控增殖 |
| 基因组维护基因 | $\mathrm{DNA}$ 损伤修复，维持基因组完整性 | 突变失活 → 基因组不稳定 | 不直接抑制增殖；间接提高原癌／抑癌基因突变频率；可归入抑癌基因 |

问「三类基因」必须三户都答。问「修复基因算不算抑癌基因」——本版说「也可归属于抑癌基因」，但功能上仍要保留「不直接抑制增殖」这一句。
:::

:::pitfall{label="原癌基因不是癌基因"}
原癌基因是正常细胞里就有的、进化上高度保守的功能基因。只有经过突变等被持续或过度活化后才转变为癌基因。写成「体内本来就有癌基因在等着发病」，第二节「功能获得突变」和「正常条件下并不具致癌活性」就空了。
:::

:::insight{label="基因组维护基因走间接路线"}
原癌基因活化和抑癌基因失活是「直接导致生长增殖失控」。基因组维护基因失活先造成基因组不稳定，再增加原癌／抑癌基因的突变频率。一条是直接，一条是间接。不要把三类都写成「都是直接促癌」。
:::

癌细胞中的突变可分为两类：驱动突变（driver mutation）和乘客突变（passenger mutation）。驱动突变可视为癌症发生或进展的「原因」，对癌症发生和进展起决定性作用。相反，乘客突变是癌症发生或进展过程中的伴随性「结果」，对癌症发生和进展没有决定性作用。

:::definition{label="驱动突变"}
驱动突变（driver mutation）：可视为癌症发生或进展的「原因」，对发生和进展起决定性作用。后文原癌基因活化和抑癌基因失活，落在这一户。
:::

:::definition{label="乘客突变"}
乘客突变（passenger mutation）：发生或进展过程中的伴随性「结果」，没有决定性作用。后文「大多数癌细胞的基因组获得了数千个突变」，里面大量是乘客。
:::

:::compare{title="驱动突变 vs 乘客突变"}
| | 本版比喻 | 对发生和进展 |
|--|---------|-------------|
| 驱动突变 | 「原因」 | 决定性作用 |
| 乘客突变 | 伴随性「结果」 | 没有决定性作用 |

问「哪一类突变决定癌变」看驱动；问「基因组里几千个突变是不是每一个都致病」看乘客。
:::

:::pitfall{label="不要把基因组里所有突变都当成驱动"}
教材紧接着写大多数癌细胞获得数千个突变。若把每一个点突变、缺失、扩增都当成驱动，靶向治疗那一户就没有「该打哪一个」的依据。图23-1 右侧「靶向治疗」对准的是驱动事件。
:::

:::keypoint{label="三类基因加两类突变"}
- 原癌基因：正常促增殖；活化后成癌基因。
- 抑癌基因：正常负调控；失活后风险升高。
- 基因组维护基因：修 $\mathrm{DNA}$、保完整性；失活走间接路线；可归入抑癌基因。
- 驱动突变是原因，乘客突变是伴随结果。
:::

## 三、癌细胞具有与正常细胞显著不同的多种生物学特征

本版按六条写癌细胞与正常细胞的差别：遗传组成显著改变；增殖失控；代谢改变；丧失接触抑制；能刺激血管生成；能侵袭并转移。六条是教材自己的编排，不要改排成另一张特征清单。增殖失控那一条内部出现「生长信号自给自足、对抗增长信号不敏感、逃避凋亡、无限复制」，仍收在「增殖失控」这一户里，不要拆成四条独立标题。

### （一）癌细胞的遗传组成发生显著改变

大多数癌细胞的基因组获得了数千个突变和其他遗传改变，包括点突变、缺失、扩增、染色体重排和整个染色体的获得和丢失。这些遗传变化影响细胞稳态、增殖、组织构成和细胞迁移特性等几乎所有方面，也影响癌细胞在体内其他转移位置的存活和增殖。

:::definition{label="遗传组成显著改变"}
大多数癌细胞的基因组获得了数千个突变和其他遗传改变。本版点名：点突变、缺失、扩增、染色体重排、整个染色体的获得和丢失。影响稳态、增殖、组织构成、迁移，以及在转移位置的存活和增殖。
:::

:::insight{label="数千个改变里既有驱动也有乘客"}
「数千个」和上一节驱动／乘客是同一张账。点突变、扩增、易位在第二节会分别成为原癌基因活化的机制；染色体获得和丢失、杂合性丢失在第三节会成为抑癌基因失活的机制。本节只立「组成已经大改」。
:::

:::pitfall{label="遗传改变不要写成只有点突变"}
名单里还有缺失、扩增、染色体重排和整条染色体的获得丢失。写成「癌细胞就是点突变多」，第二节基因扩增、染色体易位和第三节杂合性丢失就接不上。
:::

### （二）增殖失控是癌细胞的普遍特征

在正常组织中，细胞增殖是一个高度受控的过程。癌症细胞的一个普遍特征是其获得了致癌突变（如原癌基因 $\mathrm{RAS}$ 激活、抑癌基因 $\mathrm{TP}53$ 突变失活和端粒酶活性增加），使其生长信号自给自足，对抗增长信号不敏感，逃避细胞凋亡，具有无限复制的能力，从而逃脱细胞增殖的严格控制，持续无限地增殖。

:::definition{label="增殖失控"}
癌细胞的普遍特征。本版点名的致癌突变例子：原癌基因 $\mathrm{RAS}$ 激活、抑癌基因 $\mathrm{TP}53$ 突变失活、端粒酶活性增加。后果写成四句：生长信号自给自足；对抗增长信号不敏感；逃避细胞凋亡；具有无限复制的能力。四句是「增殖失控」这一户内部的展开，不是另起四章。
:::

:::cause-effect{title="三种致癌突变怎样接到增殖失控"}
- **因** 原癌基因 $\mathrm{RAS}$ 激活
- **果** 增殖信号持续，生长信号趋向自给自足
- **因** 抑癌基因 $\mathrm{TP}53$ 突变失活
- **果** 对抗增长信号不敏感、逃避凋亡的能力增强
- **因** 端粒酶活性增加
- **果** 具有无限复制的能力
:::

:::pitfall{label="不要把增殖失控拆成另一张总表来替换本节结构"}
「自给自足、对抗增长不敏感、逃避凋亡、无限复制」写在「增殖失控」这一小节内部，后面还要单独写代谢、接触抑制、血管生成、侵袭转移。把这四句抽出去当本章大纲，图23-1 和后文六条特征就对不上。
:::

### （三）癌细胞代谢发生改变

癌细胞在显微镜下的形态与正常细胞明显不同，其核质比高，核仁明显，有丝分裂细胞比例增加。癌细胞中整个或部分染色体的丢失和获得导致细胞的蛋白质组成发生显著改变，进而影响许多细胞功能。蛋白质组成的失衡导致很多蛋白质仅部分折叠，可引发应激反应，这也导致癌细胞严重依赖分子伴侣和蛋白酶体进行蛋白质折叠和降解以维持细胞存活。癌细胞的代谢尤其是能量代谢也发生显著改变。绝大多数正常分化细胞依赖高效的线粒体氧化磷酸化供能，仅正常静息状态细胞在缺氧状态下通过无氧糖酵解（anaerobic glycolysis）产生大量乳酸供能。然而，大多数癌细胞无论氧水平高低均依赖糖酵解供能。这种即便在氧存在时仍使用糖酵解供能的现象，称为有氧糖酵解（aerobic glycolysis），因其由生化学家 Warburg O. H. 首次发现，故也称 Warburg 效应（Warburg effect）。癌细胞的有氧糖酵解每分子葡萄糖仅产生 $2$ 分子 $\mathrm{ATP}$，其效率看起来低于有氧氧化途径的每分子葡萄糖可产生约 $36$ 分子 $\mathrm{ATP}$，但癌细胞通过该策略可使用糖酵解和三羧酸循环中的分子用于合成核苷酸、氨基酸和脂质以支持癌细胞快速增殖的需要。

:::definition{label="癌细胞的形态"}
核质比高，核仁明显，有丝分裂细胞比例增加。这是显微镜下的形态账，和能量代谢是同一小节的两段，不要互相替代。
:::

:::definition{label="蛋白质组成失衡与分子伴侣依赖"}
整个或部分染色体的丢失和获得导致蛋白质组成显著改变。很多蛋白质仅部分折叠，引发应激反应；癌细胞严重依赖分子伴侣和蛋白酶体进行折叠和降解以维持存活。户头是「组成乱了必须靠折叠／降解机器吊着」，还不是 Warburg。
:::

:::definition{label="有氧糖酵解与 Warburg 效应"}
大多数癌细胞无论氧水平高低均依赖糖酵解供能。即便在氧存在时仍使用糖酵解，称为有氧糖酵解（aerobic glycolysis）；由 Warburg O. H. 首次发现，也称 Warburg 效应（Warburg effect）。图23-1 通路格子里的「糖代谢重组（有氧糖酵解）」对着这一句。
:::

:::definition{label="本版 ATP 账"}
有氧糖酵解：每分子葡萄糖仅产生 $2$ 分子 $\mathrm{ATP}$。有氧氧化途径：每分子葡萄糖约 $36$ 分子 $\mathrm{ATP}$。数字以本版为准。看起来效率低，但可以把糖酵解和三羧酸循环中的分子用于合成核苷酸、氨基酸和脂质，支持快速增殖。
:::

:::compare{title="正常供能 vs 癌细胞有氧糖酵解"}
| | 氧充足时 | 缺氧时 | 产物去向 |
|--|---------|--------|---------|
| 绝大多数正常分化细胞 | 线粒体氧化磷酸化 | 静息细胞可走无氧糖酵解产乳酸 | 以 $\mathrm{ATP}$ 为主 |
| 大多数癌细胞 | 仍走糖酵解（有氧糖酵解／Warburg） | 同样依赖糖酵解 | $2$ 分子 $\mathrm{ATP}$；中间物去合成核苷酸、氨基酸、脂质 |

问「氧还在为什么还酵解」看合成需求，不要只答「癌细胞缺氧」。
:::

:::pitfall{label="有氧糖酵解不是无氧糖酵解改了名字"}
无氧糖酵解写的是正常静息细胞在缺氧时产乳酸。有氧糖酵解写的是氧在仍走糖酵解。Warburg 效应＝后者。写成「癌细胞只会无氧呼吸」，「无论氧水平高低」那一句就没了。
:::

:::insight{label="2 对约 36 看起来亏，教材立刻补上生物合成"}
效率账是 $2$ 对约 $36$。下一句就说把中间物用于核苷酸、氨基酸和脂质。图23-1 把「有氧糖酵解」和「核苷酸合成」画在同一组通路格子里，不是两件无关的事。
:::

### （四）癌症细胞丧失了接触抑制特性

正常的多细胞生物细胞在进行体外培养时，分散贴壁生长的细胞一旦相互汇合接触，即停止移动和生长，该现象称为接触抑制（contact inhibition）。癌细胞丧失了正常细胞的接触抑制特性，使其能突破正常细胞生长限制而大量生长为三维多层细胞簇。肿瘤组织不单单包含肿瘤细胞，肿瘤可视为由多种细胞组成的复杂器官和生态系统，由肿瘤细胞、微环境基质细胞、浸润到微环境的免疫类细胞、肿瘤血管、细胞外基质以及各种分泌成分和代谢产物等共同构成。肿瘤微环境（tumor microenvironment，$\mathrm{TME}$）在癌症发生发展中具有重要作用，其中癌细胞与其他细胞相互作用以获得最大生长优势。

:::definition{label="接触抑制"}
接触抑制（contact inhibition）：体外培养时，分散贴壁生长的细胞一旦相互汇合接触，即停止移动和生长。癌细胞丧失该特性，能突破生长限制，大量生长为三维多层细胞簇。
:::

:::definition{label="肿瘤微环境"}
肿瘤微环境（tumor microenvironment，$\mathrm{TME}$）：肿瘤可视为由多种细胞组成的复杂器官和生态系统，由肿瘤细胞、微环境基质细胞、浸润的免疫类细胞、肿瘤血管、细胞外基质以及各种分泌成分和代谢产物等共同构成。癌细胞与其他细胞相互作用以获得最大生长优势。
:::

:::pitfall{label="肿瘤不等于一堆纯肿瘤细胞"}
「不单单包含肿瘤细胞」。$\mathrm{TME}$ 名单里有基质细胞、免疫细胞、血管、细胞外基质和分泌／代谢产物。写成「肿瘤就是克隆出来的癌细胞团」，接触抑制之后立刻出现的微环境这一户就空了。
:::

:::insight{label="丧失接触抑制解释的是三维多层生长，微环境解释的是生态"}
前半句是体外培养看到的生长方式；后半句是体内把肿瘤当成器官。两句不要并成「接触抑制就是微环境」。
:::

### （五）癌细胞能刺激血管生成

当肿瘤生长至直径约 $2\,\mathrm{mm}$ 的小球（约 $10^{6}$ 细胞）时，中心区域的细胞会因营养供应不足而死亡。此时，癌细胞会产生生长因子如血管内皮生长因子（$\mathrm{VEGF}$）刺激血管生成，从而使肿瘤长得更大。血管形成也有助于癌细胞的转移。

:::definition{label="血管生成的尺寸门槛"}
直径约 $2\,\mathrm{mm}$ 的小球，约 $10^{6}$ 细胞。到这一规模，中心区域因营养不足而死亡，才刺激血管生成。本版两个数字要一起答。
:::

:::definition{label="VEGF 刺激血管生成"}
癌细胞产生生长因子如血管内皮生长因子（$\mathrm{VEGF}$）刺激血管生成，使肿瘤长得更大；血管形成也有助于转移。第二节表23-1 里 $\mathrm{VEGF}$ 的功能是「促进血管内皮细胞增殖和新生血管形成」，和这里是同一户。
:::

:::cause-effect{title="为什么必须长血管"}
- **因** 长到约 $2\,\mathrm{mm}$（约 $10^{6}$ 细胞）
- **果** 中心营养不足、细胞死亡
- **因** 产生 $\mathrm{VEGF}$ 等刺激血管生成
- **果** 肿瘤可继续增大，并为转移提供通道
:::

:::pitfall{label="2 mm 不是转移的定义"}
$2\,\mathrm{mm}$／$10^{6}$ 是血管生成这一户的尺寸。转移是下一小节：突破基底膜、建立第二生长区域。不要把「开始长血管」写成「已经转移」。
:::

### （六）癌细胞能侵袭局部组织并转移至其他部位

癌细胞往往会侵入周围组织，通常会突破界定组织边界的基底膜，并在体内扩散，建立第二生长区域，这一过程称为转移。大量研究发现，癌细胞的细胞膜组分发生变化，如各种糖蛋白分子中糖链的改变，这些糖蛋白包括细胞黏附分子，这可导致细胞黏附降低和转移。癌细胞的转移是导致癌症患者死亡的主要原因。良性肿瘤的细胞不会侵入局部组织或扩散到身体的其他部位。

:::definition{label="转移"}
转移：癌细胞侵入周围组织，通常突破界定组织边界的基底膜，在体内扩散，建立第二生长区域。是导致癌症患者死亡的主要原因。
:::

:::definition{label="膜糖蛋白改变与黏附降低"}
细胞膜组分变化，如各种糖蛋白分子中糖链的改变；这些糖蛋白包括细胞黏附分子，可导致细胞黏附降低和转移。户头是「黏附分子的糖链变了」，不是另开一种基因突变类型。
:::

:::definition{label="良性肿瘤在转移这一户的对照"}
良性肿瘤的细胞不会侵入局部组织或扩散到身体的其他部位。良恶的分界在这里落到侵袭和转移，而不是「长得大不大」。
:::

:::compare{title="六条生物学特征各自先问什么"}
| 本版小节 | 先看见什么 | 不要答成 |
|---------|-----------|---------|
| 遗传组成 | 数千突变；点突变、缺失、扩增、重排、整条染色体得失 | 只有点突变 |
| 增殖失控 | $\mathrm{RAS}$、$\mathrm{TP}53$、端粒酶；自给自足、抗抑制、逃凋亡、无限复制 | 把四句拆成独立大纲 |
| 代谢 | 形态＋分子伴侣依赖＋Warburg（$2$ 对约 $36$） | 「缺氧所以酵解」 |
| 接触抑制／$\mathrm{TME}$ | 三维多层；肿瘤是生态系统 | 肿瘤＝纯癌细胞 |
| 血管生成 | $2\,\mathrm{mm}$／$10^{6}$，$\mathrm{VEGF}$ | 已经等于转移 |
| 侵袭转移 | 破基底膜、第二生长区；黏附分子糖链改变 | 良性也会转 |

问「癌细胞有哪些特征」按本版六条答；问「为什么病人主要死于转移」看最后一户。
:::

:::keypoint{label="生物学特征六条收回来"}
- 遗传：数千改变，形式不限于点突变。
- 增殖：$\mathrm{RAS}$／$\mathrm{TP}53$／端粒酶，四句能力收在本户。
- 代谢：Warburg，$2$ 分子 $\mathrm{ATP}$ 对约 $36$，中间物去生物合成。
- 接触抑制丧失；$\mathrm{TME}$ 是器官／生态。
- $2\,\mathrm{mm}$／$10^{6}$ 细胞刺激 $\mathrm{VEGF}$ 血管生成。
- 转移破基底膜；良性不侵袭、不扩散；转移是主要死因。
:::

## 四、癌症分子基础研究极大地推动了癌症诊疗变革和生物医学发展

癌症是一类古老的疾病，人类对其认识和研究历史悠久。$3\,500$ 年前，我国殷周时代的甲骨文中出现「瘤」字的记载。在西方，古希腊的希波克拉底（公元前 $460$—前 $377$ 年）在描述恶性肿瘤时，发现其形似螃蟹（crab），「cancer」一词即源于此。随着生命科学的进步，尤其是分子生物学的迅速发展，人类对癌症的研究进入分子水平时代。

:::definition{label="cancer 一词的来历"}
希波克拉底在描述恶性肿瘤时发现其形似螃蟹（crab），「cancer」一词即源于此。这是词源，不是组织学分型。上皮来源仍叫 carcinoma。
:::

:::timeline{period="本版点到的认识节点"}
- **约三千五百年前** 殷周甲骨文出现「瘤」字
- **公元前 460—前 377** 希波克拉底以螃蟹之形称恶性肿瘤，cancer 一词源于此
- **20 世纪 60 年代** 多种癌基因和抑癌基因相继被发现
- **分子水平时代** 诊断到分子和基因水平；治疗进入个体化精准治疗，分子靶向治疗疗效显著
:::

癌症的分子基础研究，不断加深了人类对癌症病因和发病机制的认识，并极大地推动了癌症的预防、诊断和治疗的进步和变革。$20$ 世纪 $60$ 年代，多种癌基因和抑癌基因相继被发现。癌症的诊断现已发展到分子和基因水平，癌症的治疗也进入到个体化精准治疗时代，尤其是分子靶向治疗，临床疗效显著，引发了抗癌治疗理念的变革。此外，癌症分子基础研究也催生了诸如逆转录等挑战传统的分子生物学「中心法则」的重大发现，对生物医学基础研究也产生了深远影响。

:::definition{label="分子诊断与靶向治疗在本节的位置"}
诊断已到分子和基因水平；治疗进入个体化精准治疗，尤其是分子靶向治疗。对着图23-1 右侧「精准医学 → 分子诊断 → 靶向治疗」。具体四个靶点（$\mathrm{BRAF}$、$\mathrm{EGFR}$、$\mathrm{HER}2$、$\mathrm{BCR}$-$\mathrm{ABL}$）是第二节第五部分；基因诊断和基因治疗的操作是第二十四章，本节不写。
:::

:::insight{label="逆转录是癌症研究送给中心法则的账"}
「催生了诸如逆转录等挑战传统中心法则的重大发现」。RNA 肿瘤病毒／逆转录病毒在第二节展开。写成「癌症研究只服务临床」，基础研究这一句就没有对象。
:::

:::pitfall{label="20 世纪 60 年代发现的是基因，不是已经完成靶向治疗"}
教材把「癌基因和抑癌基因相继被发现」写在 $20$ 世纪 $60$ 年代；靶向治疗写在「现已」「进入」。不要把发现基因和临床靶向药并成同一年。
:::

:::memory{label="本节必背分户"}
- 癌症（cancer）泛指恶性肿瘤。肿瘤含良性与恶性。癌（carcinoma）＝上皮来源恶性，造成 $80\%$ 以上癌症相关死亡。非上皮：肉瘤、造血系统恶性肿瘤、神经外胚层恶性肿瘤。cancer 与 carcinoma 不要并词。
- 多病因、多基因、多阶段。图23-1：外因＋内因 → 基因（原癌／抑癌）→ 产物（蛋白质和非编码 $\mathrm{RNA}$）→ 通路／代谢（$\mathrm{MAPK}$、$\mathrm{PI3K}$／$\mathrm{AKT}$、有氧糖酵解、核苷酸合成）→ 细胞行为 → 癌变转移；右侧精准医学／分子诊断／靶向治疗。
- 外因始动（约 $80\%$ 以上肿瘤与环境相关；化学约占环境因素 $90\%$；$2\,000$ 余种；物理最主要电离辐射；生物最主要病毒），内因基础（遗传、免疫、营养、激素；种系突变 vs 易感多态性）。
- 三类基因：原癌基因促增殖；抑癌基因负调控；基因组维护基因修 $\mathrm{DNA}$，不直接抑增殖，可归入抑癌基因。驱动突变是原因，乘客突变是结果。
- 六条特征：遗传组成；增殖失控（$\mathrm{RAS}$、$\mathrm{TP}53$、端粒酶）；代谢（Warburg，$2$ 对约 $36$）；接触抑制丧失与 $\mathrm{TME}$；$2\,\mathrm{mm}$／$10^{6}$ 细胞与 $\mathrm{VEGF}$；侵袭转移是主要死因，良性不转。
- $20$ 世纪 $60$ 年代发现癌基因和抑癌基因。逆转录挑战中心法则。靶点细节和抑癌基因机制不在本节写完。
