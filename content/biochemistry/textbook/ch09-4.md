# 第四节　个别氨基酸的代谢

第三节把氨写成尿素。氨基酸还有侧链：脱羧基生成胺，分解时交出一碳单位，含硫氨基酸提供活性甲基和活性硫酸根，芳香族氨基酸走向神经递质、黑色素和若干遗传病，支链氨基酸主要在骨骼肌分解。本节只写教材点名的这几条特殊途径。章末收全章小结和思考题。

氨基酸的分解代谢除共有代谢途径外，因其侧链不同，有些氨基酸还存在特殊的代谢途径，并具有重要的生理意义。本节仅对几种重要的氨基酸代谢途径进行描述。

:::concept{term="先问侧链做什么，再问产物是递质、一碳还是甲基"}
一般代谢管 $\alpha$-氨基和 $\alpha$-酮酸。个别代谢管侧链：脱羧得胺，一碳单位交给四氢叶酸，甲硫氨酸循环交出 $\mathrm{SAM}$，芳香族走加氧酶，支链在骨骼肌按三阶段切开。不要把二十种氨基酸的降解图一次默完，本版只点名这些户头。
:::

## 一、氨基酸脱羧基作用需要脱羧酶催化

有些氨基酸可通过脱羧基作用（decarboxylation）生成相应的胺类。催化脱羧基反应的酶称为脱羧酶（decarboxylase），氨基酸脱羧酶的辅酶是磷酸吡哆醛。体内胺类含量虽然不高，但具有重要的生理功能。

细胞内广泛存在的胺氧化酶（amine oxidase）能将胺氧化成相应的醛、$\mathrm{NH}_3$ 和 $\mathrm{H}_2\mathrm{O}_2$。醛类可继续氧化成羧酸，羧酸再氧化成 $\mathrm{CO}_2$ 和 $\mathrm{H}_2\mathrm{O}$ 或随尿排出，从而避免胺类的蓄积。胺氧化酶属于黄素蛋白，在肝中活性最高。

$$
\mathrm{R{-}CH(NH}_2\mathrm{){-}COOH}\xrightarrow{\text{脱羧酶}}\mathrm{R{-}CH}_2\mathrm{NH}_2+\mathrm{CO}_2
$$

$$
\mathrm{R{-}CH}_2\mathrm{NH}_2+\mathrm{O}_2+\mathrm{H}_2\mathrm{O}\xrightarrow{\text{胺氧化酶}}\mathrm{RCHO}+\mathrm{NH}_3+\mathrm{H}_2\mathrm{O}_2
$$

:::definition{label="脱羧基作用"}
脱羧基作用（decarboxylation）使氨基酸脱去羧基生成相应的胺。催化酶为脱羧酶（decarboxylase），辅酶是磷酸吡哆醛。
:::

:::definition{label="胺氧化酶"}
胺氧化酶（amine oxidase）将胺氧化成相应的醛、$\mathrm{NH}_3$ 和 $\mathrm{H}_2\mathrm{O}_2$。属黄素蛋白，肝中活性最高。醛再氧化成羧酸，避免胺类蓄积。
:::

:::insight{label="胺要的是功能，不要的是堆积"}
含量不高，但对神经、血管、胃酸、细胞增殖都有用。肝里的胺氧化酶把多余的胺写成醛和氨——氨再走第三节的尿素循环。磷酸吡哆醛既是转氨酶辅酶（第二节），也是脱羧酶辅酶，维生素 $\mathrm{B}_6$ 不足时两本账都会慢。
:::

### （一）谷氨酸脱羧生成 γ-氨基丁酸

谷氨酸由 $\mathrm{L}$-谷氨酸脱羧酶催化脱去羧基生成 $\gamma$-氨基丁酸（$\gamma$-aminobutyric acid，$\mathrm{GABA}$）。$\mathrm{L}$-谷氨酸脱羧酶在脑及肾组织中活性很高，因而 $\gamma$-氨基丁酸在脑组织中的浓度较高。$\mathrm{GABA}$ 是抑制性神经递质，对中枢神经有抑制作用。

$$
\text{L-谷氨酸}\xrightarrow{\text{L-谷氨酸脱羧酶}}\mathrm{GABA}+\mathrm{CO}_2
$$

:::definition{label="GABA"}
$\gamma$-氨基丁酸（$\gamma$-aminobutyric acid，$\mathrm{GABA}$）由 $\mathrm{L}$-谷氨酸脱羧酶催化谷氨酸脱羧生成。该酶在脑及肾活性很高，故脑中 $\mathrm{GABA}$ 浓度较高。$\mathrm{GABA}$ 是抑制性神经递质，对中枢神经有抑制作用。
:::

:::pitfall{label="谷氨酸本身是兴奋性递质，脱羧之后才是抑制性的 GABA"}
不要把“谷氨酸在脑里”一律写成抑制。本节的户头是脱羧产物 $\mathrm{GABA}$。第三节高血氨时氨与谷氨酸结合成谷氨酰胺，那是解毒／渗透压账，不是 $\mathrm{GABA}$ 账。
:::

### （二）组氨酸脱羧生成组胺

组氨酸由组氨酸脱羧酶催化脱去羧基生成组胺（histamine）。组胺在体内分布广泛，乳腺、肺、肝、肌及胃黏膜中含量较高，主要存在于肥大细胞中。

组胺是一种强烈的血管扩张剂，并能增加毛细血管的通透性。组胺可使平滑肌收缩，引起支气管痉挛导致哮喘。组胺还能促进胃黏膜细胞分泌胃蛋白酶原及胃酸。

:::definition{label="组胺"}
组胺（histamine）由组氨酸脱羧酶催化组氨酸脱羧生成。主要存在于肥大细胞；乳腺、肺、肝、肌及胃黏膜含量较高。强烈扩张血管、增加毛细血管通透性；收缩平滑肌可致支气管痉挛和哮喘；促进胃黏膜分泌胃蛋白酶原及胃酸。
:::

:::keypoint{label="组胺三件事"}
- 血管：扩张，通透性增加。
- 支气管平滑肌：收缩 $\to$ 哮喘。
- 胃：促胃蛋白酶原及胃酸分泌。
:::

### （三）色氨酸经过羟化后脱羧生成 5-羟色胺

色氨酸首先经色氨酸羟化酶催化生成 $5$-羟色氨酸（$5$-hydroxytryptophan），然后由 $5$-羟色氨酸脱羧酶催化生成 $5$-羟色胺（$5$-hydroxytryptamine，$5$-$\mathrm{HT}$）。

$5$-羟色胺广泛分布于体内各组织，除神经组织外，还存在于胃、肠、血小板及乳腺细胞中。脑组织中的 $5$-羟色胺是一种神经递质，具有抑制作用，直接影响神经传导。在外周组织，$5$-羟色胺具有强烈的血管收缩作用。$5$-羟色胺经单胺氧化酶催化生成 $5$-羟色醛，进一步氧化生成 $5$-羟吲哚乙酸随尿排出。

:::definition{label="5-羟色胺"}
$5$-羟色胺（$5$-hydroxytryptamine，$5$-$\mathrm{HT}$）：色氨酸先经色氨酸羟化酶生成 $5$-羟色氨酸，再经 $5$-羟色氨酸脱羧酶脱羧而成。脑中为抑制性神经递质；外周强烈收缩血管。经单胺氧化酶生成 $5$-羟色醛，再氧化为 $5$-羟吲哚乙酸随尿排出。
:::

:::compare{title="GABA、组胺、5-HT"}
| 前体 | 产物 | 要点 |
|------|------|------|
| 谷氨酸 | $\mathrm{GABA}$ | 脑、肾脱羧酶活性高；中枢抑制 |
| 组氨酸 | 组胺 | 肥大细胞；扩血管、支气管痉挛、促胃酸 |
| 色氨酸 | $5$-$\mathrm{HT}$ | 先羟化再脱羧；脑抑制、外周缩血管 |
:::

:::pitfall{label="5-HT 在脑和外周方向相反，不要写成“都是抑制”"}
脑：抑制性递质。外周：强烈缩血管。组胺才是扩血管。把 $5$-$\mathrm{HT}$ 和组胺的血管效应记反，临床过敏和止血两套账都会乱。
:::

### （四）某些氨基酸脱羧基可产生多胺类物质

多胺是指含有多个氨基的化合物。在体内，某些氨基酸经脱羧基作用可以产生多胺类物质。例如鸟氨酸经脱羧基作用生成腐胺（putrescine），然后腐胺又可转变成亚精胺（spermidine）及精胺（spermine）。

鸟氨酸脱羧生成腐胺；腐胺接受来自 $S$-腺苷甲硫氨酸（$\mathrm{SAM}$）脱羧后的氨丙基，经氨丙基转移酶生成亚精胺；亚精胺再接受一分子脱羧 $\mathrm{SAM}$ 的氨丙基，生成精胺。

:::definition{label="多胺"}
多胺（polyamine）是含有多个氨基的化合物。体内可由某些氨基酸脱羧产生，如鸟氨酸 $\to$ 腐胺 $\to$ 亚精胺 $\to$ 精胺。
:::

:::definition{label="鸟氨酸脱羧酶"}
鸟氨酸脱羧酶（ornithine decarboxylase）是多胺合成的关键酶。精胺与亚精胺是调节细胞生长的重要物质。
:::

凡生长旺盛的组织，如胚胎、再生肝、肿瘤组织等，鸟氨酸脱羧酶的活性和多胺的含量都有所增加。多胺促进细胞增殖的机制可能与其稳定细胞结构、与核酸分子结合及促进核酸和蛋白质的生物合成有关。在体内多胺大部分与乙酰基结合随尿排出，小部分氧化成 $\mathrm{CO}_2$ 和 $\mathrm{NH}_3$。目前临床上常测定病人血或尿中多胺的水平作为肿瘤辅助诊断及病情变化的生化指标之一。

:::keypoint{label="多胺合成与去路"}
- 关键酶：鸟氨酸脱羧酶。
- 生长旺盛组织（胚胎、再生肝、肿瘤）：酶活性和多胺含量增加。
- 去路：大部分乙酰化随尿排出，小部分氧化成 $\mathrm{CO}_2$ 和 $\mathrm{NH}_3$。
- 临床：血或尿多胺作为肿瘤辅助诊断及病情指标。
:::

:::insight{label="第三节的鸟氨酸在这里脱羧，不是再走尿素循环"}
同一分子鸟氨酸：肝线粒体里它接受氨基甲酰写瓜氨酸；需要多胺时，它脱羧写腐胺。$\mathrm{SAM}$ 在后文甲硫氨酸循环是甲基供体，这里先脱羧再捐氨丙基。户头不同，不要并成一步。
:::

## 二、某些氨基酸在分解代谢中产生一碳单位

### （一）四氢叶酸作为一碳单位的载体参与一碳单位代谢

一碳单位（one carbon unit）是指某些氨基酸在分解代谢过程中产生的含有一个碳原子的有机基团，包括甲基（—$\mathrm{CH}_3$）、亚甲基（—$\mathrm{CH}_2$—）、次甲基（$\mathrm{CH}$—）、甲酰基（—$\mathrm{CHO}$）及亚氨甲基（—$\mathrm{CHNH}$）等。一碳单位不能游离存在，常与四氢叶酸（tetrahydrofolic acid，$\mathrm{FH}_4$）结合被转运并参与代谢，四氢叶酸是一碳单位的运载体。

在体内，四氢叶酸是由叶酸经过二氢叶酸还原酶（dihydrofolate reductase）催化，分两步还原反应生成的：叶酸 $\xrightarrow{\mathrm{NADPH}}$ 二氢叶酸 $\xrightarrow{\mathrm{NADPH}}$ $5,6,7,8$-四氢叶酸（$\mathrm{FH}_4$）。

:::definition{label="一碳单位"}
一碳单位（one carbon unit）是某些氨基酸分解代谢过程中产生的含有一个碳原子的有机基团，包括甲基、亚甲基、次甲基、甲酰基及亚氨甲基等。不能游离存在，由四氢叶酸转运。
:::

:::definition{label="四氢叶酸"}
四氢叶酸（tetrahydrofolic acid，$\mathrm{FH}_4$）是一碳单位的运载体。叶酸经二氢叶酸还原酶分两步还原（均需 $\mathrm{NADPH}$）生成 $5,6,7,8$-四氢叶酸。
:::

:::definition{label="二氢叶酸还原酶"}
二氢叶酸还原酶（dihydrofolate reductase）催化叶酸 $\to$ 二氢叶酸 $\to$ 四氢叶酸，两步都用 $\mathrm{NADPH}$。叶酸类似物（如甲氨蝶呤）抑制此酶，从而抑制 $\mathrm{FH}_4$ 生成。
:::

:::pitfall{label="一碳单位不是游离的甲醛或甲醇"}
教材写明不能游离存在。考试若写成“甲基在血里漂着再交给碱基”，载体 $\mathrm{FH}_4$ 就没有了。结合位点在 $N^{5}$、$N^{10}$。
:::

### （二）由氨基酸产生的一碳单位可相互转变

一碳单位主要来自丝氨酸、甘氨酸、组氨酸及色氨酸的分解代谢，苏氨酸通过间接转变成为甘氨酸也可以产生一碳单位。一碳单位由氨基酸生成的同时即结合在四氢叶酸的 $N^{5}$、$N^{10}$ 位上。四氢叶酸的 $N^{5}$ 结合甲基或亚氨甲基，$N^{5}$ 和 $N^{10}$ 结合亚甲基或次甲基，$N^{5}$ 或 $N^{10}$ 结合甲酰基。

例如：丝氨酸经羟甲基转移酶把羟甲基交给 $\mathrm{FH}_4$，生成 $N^{5},N^{10}$-亚甲基四氢叶酸和甘氨酸；甘氨酸裂解酶使甘氨酸与 $\mathrm{FH}_4$ 反应，也生成 $N^{5},N^{10}$-亚甲基四氢叶酸，并放出 $\mathrm{CO}_2$ 和 $\mathrm{NH}_3$。组氨酸分解可提供 $N^{5}$-亚氨甲基四氢叶酸，再转为 $N^{5},N^{10}$-次甲基四氢叶酸。色氨酸分解可提供甲酰基，生成 $N^{10}$-甲酰四氢叶酸。

:::definition{label="一碳单位的氨基酸来源"}
主要来自丝氨酸、甘氨酸、组氨酸及色氨酸。苏氨酸可间接转变成甘氨酸后再产生一碳单位。生成的同时结合在 $\mathrm{FH}_4$ 的 $N^{5}$、$N^{10}$。
:::

:::compare{title="N5、N10 各结合什么"}
| 结合位点 | 一碳单位 |
|----------|----------|
| $N^{5}$ | 甲基或亚氨甲基 |
| $N^{5}$ 和 $N^{10}$ | 亚甲基或次甲基 |
| $N^{5}$ 或 $N^{10}$ | 甲酰基 |
:::

各种不同形式的一碳单位中，碳原子的氧化状态不同。在适当条件下，它们可以通过氧化还原反应而彼此转变（图9-10）。但是在这些反应中，$N^{5}$-甲基四氢叶酸的生成是不可逆的。

::figure{src="/images/biochemistry/textbook/p0217_01.png" caption="图9-10　各种不同形式一碳单位的转换。N5,N10-亚甲基 FH4 可逆转为 N5,N10-次甲基 FH4，后者与 N5-亚氨甲基 FH4 互变，并与 N10-甲酰 FH4 互变；N5,N10-亚甲基 FH4 还原生成 N5-甲基 FH4 为单向。" alt="一碳单位互变：甲基四氢叶酸生成为不可逆，其余甲酰、次甲基、亚氨甲基、亚甲基可互变"}

:::keypoint{label="N5-甲基四氢叶酸生成不可逆"}
图9-10 顶端那一支只有向上的箭头：$N^{5},N^{10}$-亚甲基 $\mathrm{FH}_4\to N^{5}$-甲基 $\mathrm{FH}_4$。其他形式可氧化还原互变。后面甲硫氨酸循环要把 $N^{5}$-甲基交出去，才能让 $\mathrm{FH}_4$ 再生；这一步卡住，就是巨幼细胞贫血那本账。
:::

:::pitfall{label="本版写 N10-CHO-FH4“为嘌呤提供甲基”，基团本身是甲酰基"}
一碳单位名单里，—$\mathrm{CHO}$ 叫甲酰基，—$\mathrm{CH}_3$ 才叫甲基。后文功能句按教材保留“提供甲基”，读结构时仍按甲酰基写在 $N^{10}$。不要另造一套不在本版的碳原子编号。
:::

### （三）一碳单位的主要功能是参与嘌呤和嘧啶的合成

氨基酸分解代谢过程中产生的一碳单位可作为嘌呤和嘧啶的合成原料。例如，$N^{10}$-$\mathrm{CHO}$-$\mathrm{FH}_4$ 为嘌呤碱基的合成提供甲基。故一碳单位在核酸的生物合成中具有重要作用，一碳单位将氨基酸代谢与核苷酸代谢密切联系起来。

一碳单位代谢障碍或 $\mathrm{FH}_4$ 不足时，可引起巨幼细胞贫血等疾病。应用磺胺类药物可抑制某些细菌合成二氢叶酸，进而抑制细菌繁殖，但对人体影响不大。应用叶酸类似物如甲氨蝶呤等可抑制 $\mathrm{FH}_4$ 的生成，从而抑制核酸的合成，起到抗肿瘤作用。

:::definition{label="一碳单位的主要功能"}
一碳单位主要参与嘌呤和嘧啶的合成。例如 $N^{10}$-$\mathrm{CHO}$-$\mathrm{FH}_4$ 为嘌呤碱基合成提供甲基。由此把氨基酸代谢与核苷酸代谢联系起来。
:::

:::compare{title="磺胺与甲氨蝶呤都动叶酸，对象不同"}
| 药 | 打击点 | 为何对人体影响不同 |
|----|--------|----------------------|
| 磺胺类 | 某些细菌合成二氢叶酸 | 人体不合成叶酸，需从食物摄取，故影响不大 |
| 甲氨蝶呤等叶酸类似物 | 抑制 $\mathrm{FH}_4$ 生成（二氢叶酸还原酶） | 直接减少人体 $\mathrm{FH}_4$，抑制核酸合成，抗肿瘤 |
:::

:::cause-effect{title="FH4 不足如何写成巨幼细胞贫血"}
- **因** 一碳单位代谢障碍或 $\mathrm{FH}_4$ 不足 $\to$ 嘌呤、嘧啶合成原料不够 $\to$ 核酸合成障碍
- **果** 细胞分裂受影响，引起巨幼细胞贫血等。后文维生素 $\mathrm{B}_{12}$ 缺乏因甲基不能从 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 转出，同样使游离 $\mathrm{FH}_4$ 减少，机制汇合到这里。
:::

## 三、含硫氨基酸代谢可产生多种生物活性物质

含硫氨基酸包括甲硫氨酸、半胱氨酸和胱氨酸。甲硫氨酸可以转变为半胱氨酸和胱氨酸，半胱氨酸和胱氨酸又可以互相转变，但后两种都不能转变为甲硫氨酸，所以甲硫氨酸是营养必需氨基酸。

:::definition{label="含硫氨基酸"}
含硫氨基酸包括甲硫氨酸、半胱氨酸和胱氨酸。甲硫氨酸 $\to$ 半胱氨酸、胱氨酸可以；半胱氨酸 $\rightleftharpoons$ 胱氨酸可以；半胱氨酸、胱氨酸 $\to$ 甲硫氨酸不可以。故甲硫氨酸是营养必需氨基酸。
:::

:::pitfall{label="半胱氨酸不是营养必需氨基酸，不等于膳食里可以没有甲硫氨酸"}
体内能由甲硫氨酸写半胱氨酸，所以半胱氨酸不必由食物供给。反过来写不了：没有膳食甲硫氨酸，同型半胱氨酸也没有来源，循环转不起来。第一节营养必需氨基酸的名单以甲硫氨酸为准。
:::

### （一）甲硫氨酸参与甲基转移反应

**1. 甲硫氨酸转甲基作用与甲硫氨酸循环有关**　甲硫氨酸分子中含有 $S$-甲基，通过各种转甲基作用可生成多种含甲基的生理活性物质，如肾上腺素、肉碱、胆碱及肌酸等。但在转甲基反应前，甲硫氨酸必须经腺苷转移酶（adenosyl transferase）的催化与 $\mathrm{ATP}$ 反应，生成 $S$-腺苷甲硫氨酸（$S$-adenosyl methionine，$\mathrm{SAM}$）。$\mathrm{SAM}$ 中的甲基称为活性甲基，故 $\mathrm{SAM}$ 称为活性甲硫氨酸。$\mathrm{SAM}$ 是体内最重要的甲基直接供体。据统计，体内约有 $50$ 余种物质需要 $\mathrm{SAM}$ 提供甲基，生成相应的甲基化合物。

$$
\text{甲硫氨酸}+\mathrm{ATP}\xrightarrow{\text{腺苷转移酶}}\mathrm{SAM}+\mathrm{PP}_\mathrm{i}+\mathrm{P}_\mathrm{i}
$$

:::definition{label="S-腺苷甲硫氨酸"}
$S$-腺苷甲硫氨酸（$S$-adenosyl methionine，$\mathrm{SAM}$）由腺苷转移酶催化甲硫氨酸与 $\mathrm{ATP}$ 生成，又称活性甲硫氨酸。其中的甲基为活性甲基，$\mathrm{SAM}$ 是体内最重要的甲基直接供体。约 $50$ 余种物质需要它提供甲基。
:::

:::insight{label="甲硫氨酸分子上的 S-甲基还不能直接转出去"}
必须先写成 $\mathrm{SAM}$。$\mathrm{ATP}$ 在这里付出的不是普通的一个磷酸，产物是 $\mathrm{PP}_\mathrm{i}+\mathrm{P}_\mathrm{i}$。没有这一步，肾上腺素、肉碱、胆碱、肌酸的甲基都没有直接供体。
:::

$S$-腺苷甲硫氨酸经甲基转移酶（methyltransferase）催化，将甲基转移至另一种物质，使其发生甲基化（methylation）反应，而 $S$-腺苷甲硫氨酸失去甲基后生成 $S$-腺苷同型半胱氨酸，后者脱去腺苷生成同型半胱氨酸（homocysteine）。同型半胱氨酸若再接受 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 提供的甲基，则可重新生成甲硫氨酸。由此形成一个循环过程，称为甲硫氨酸循环（methionine cycle）（图9-11）。

此循环的生理意义是由 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 提供甲基生成甲硫氨酸，再通过 $\mathrm{SAM}$ 提供甲基，以进行体内广泛存在的甲基化反应。由此，$N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 可看成是体内甲基的间接供体。

::figure{src="/images/biochemistry/textbook/p0218_01.png" caption="图9-11　甲硫氨酸循环。甲硫氨酸与 ATP 生成 SAM，转甲基后成 S-腺苷同型半胱氨酸，脱腺苷得同型半胱氨酸；N5-CH3-FH4 在维生素 B12 依赖的转甲基酶催化下把甲基交还，再生甲硫氨酸并放出 FH4。" alt="甲硫氨酸循环：SAM 供甲基，同型半胱氨酸经 B12 依赖酶从甲基四氢叶酸取回甲基"}

:::definition{label="甲硫氨酸循环"}
甲硫氨酸循环（methionine cycle）：甲硫氨酸 $\to\mathrm{SAM}\to S$-腺苷同型半胱氨酸 $\to$ 同型半胱氨酸；同型半胱氨酸再接受 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 的甲基重生甲硫氨酸。生理意义：让 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 作为甲基间接供体，经 $\mathrm{SAM}$ 完成广泛的甲基化。
:::

:::compare{title="直接供体与间接供体"}
| 角色 | 分子 |
|------|------|
| 甲基直接供体 | $\mathrm{SAM}$（活性甲硫氨酸） |
| 甲基间接供体 | $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ |
:::

在甲硫氨酸循环反应中，虽然同型半胱氨酸接受甲基后可以生成甲硫氨酸，但体内不能合成同型半胱氨酸，它只能由甲硫氨酸转变而来，故甲硫氨酸必须由食物提供，不能在体内合成。

$N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 提供甲基使同型半胱氨酸转变成甲硫氨酸的反应由 $N^{5}$ 甲基四氢叶酸转甲基酶催化，此酶又称甲硫氨酸合成酶，其辅酶是维生素 $\mathrm{B}_{12}$，参与甲基的转移。当维生素 $\mathrm{B}_{12}$ 缺乏时，$N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 上的甲基不能转移给同型半胱氨酸。这不仅影响甲硫氨酸的合成，同时也影响四氢叶酸的再生，使组织中游离的四氢叶酸含量减少，一碳单位参与碱基合成受到影响，可导致核酸合成障碍，影响细胞分裂。因此，维生素 $\mathrm{B}_{12}$ 不足时可引起巨幼细胞贫血。另外，同型半胱氨酸在血中浓度升高，可能是动脉粥样硬化和冠心病发生的独立危险因素。

:::definition{label="甲硫氨酸合成酶"}
$N^{5}$ 甲基四氢叶酸转甲基酶又称甲硫氨酸合成酶，催化 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 把甲基交给同型半胱氨酸生成甲硫氨酸。辅酶是维生素 $\mathrm{B}_{12}$。
:::

:::cause-effect{title="维生素 B12 缺乏如何同时卡住甲硫氨酸和 FH4"}
- **因** 甲基不能从 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 转给同型半胱氨酸（图9-10 这一步本就不可逆，只能靠转甲基酶转出）
- **果** 甲硫氨酸合成受阻；游离 $\mathrm{FH}_4$ 减少；一碳单位不能参与碱基合成；核酸合成障碍、细胞分裂受影响；巨幼细胞贫血。同型半胱氨酸升高还与动脉粥样硬化、冠心病相关
:::

:::pitfall{label="循环能再生甲硫氨酸，不等于体内能净合成甲硫氨酸"}
同型半胱氨酸只能由甲硫氨酸变来，体内不能从头写同型半胱氨酸。循环是在周转甲基，不是把非必需氨基酸变成甲硫氨酸。营养必需氨基酸的地位不因循环而改变。
:::

:::insight{label="叶酸不足和 B12 不足都可以是巨幼细胞贫血，卡点前后相连"}
叶酸／$\mathrm{FH}_4$ 不足：一碳单位没载体。$\mathrm{B}_{12}$ 不足：甲基卡在 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 上转不出去，$\mathrm{FH}_4$ 再生不了。思考题第 $1$ 题从氨基酸代谢角度写巨幼细胞贫血，两笔都要落到碱基合成。
:::

**2. 甲硫氨酸为肌酸合成提供甲基**　肌酸（creatine）和磷酸肌酸（creatine phosphate）是能量储存与利用的重要化合物。肌酸是以甘氨酸为骨架，由精氨酸提供脒基，$S$-腺苷甲硫氨酸提供甲基合成的，肝是合成肌酸的主要器官。在肌酸激酶（creatine kinase，$\mathrm{CK}$）催化下，肌酸接受 $\mathrm{ATP}$ 的高能磷酸基形成磷酸肌酸（图9-12）。磷酸肌酸作为能量的储存形式，在心肌、骨骼肌及脑组织中含量丰富。

::figure{src="/images/biochemistry/textbook/p0219_01.png" caption="图9-12　肌酸代谢。精氨酸与甘氨酸经脒基转移酶生成胍乙酸和鸟氨酸；胍乙酸接受 SAM 的甲基生成肌酸；肌酸激酶可逆地将 ATP 的高能磷酸写入磷酸肌酸；肌酸与磷酸肌酸均可生成肌酐。" alt="肌酸合成与磷酸肌酸、肌酐：精氨酸供脒基，SAM 供甲基，CK 磷酸化"}

:::definition{label="肌酸"}
肌酸（creatine）以甘氨酸为骨架，精氨酸提供脒基，$\mathrm{SAM}$ 提供甲基，主要在肝合成。肌酸激酶催化肌酸接受 $\mathrm{ATP}$ 的高能磷酸基形成磷酸肌酸（creatine phosphate）。磷酸肌酸是能量储存形式，心肌、骨骼肌及脑中含量丰富。
:::

肌酸激酶由两种亚基组成，即 $\mathrm{M}$ 亚基（肌型）与 $\mathrm{B}$ 亚基（脑型），构成 $3$ 种同工酶：$\mathrm{MM}$、$\mathrm{MB}$ 和 $\mathrm{BB}$。它们在体内各组织中的分布不同，$\mathrm{MM}$ 主要在骨骼肌，$\mathrm{MB}$ 主要在心肌，而 $\mathrm{BB}$ 主要在脑。当心肌梗死时，血中 $\mathrm{MB}$ 型肌酸激酶的活性增高，因此可作为心肌梗死的辅助诊断指标之一。

肌酸和磷酸肌酸的终末代谢产物是肌酐（creatinine）。肌酐主要在骨骼肌中通过磷酸肌酸的非酶促反应生成。肌酐随尿排出，正常人每日尿中肌酐的排出量恒定。当肾功能障碍时，肌酐排出受阻，血中浓度升高。因此，血中肌酐的测定有助于肾功能不全的诊断。

:::definition{label="肌酐"}
肌酐（creatinine）是肌酸和磷酸肌酸的终末代谢产物，主要在骨骼肌由磷酸肌酸经非酶促反应生成。每日尿排出量恒定；肾功能障碍时排出受阻、血中浓度升高，可辅助诊断肾功能不全。
:::

:::compare{title="CK 三种同工酶"}
| 同工酶 | 亚基 | 主要分布 | 临床 |
|--------|------|----------|------|
| $\mathrm{MM}$ | 肌型 $+$ 肌型 | 骨骼肌 | — |
| $\mathrm{MB}$ | 肌型 $+$ 脑型 | 心肌 | 心肌梗死时血中活性增高 |
| $\mathrm{BB}$ | 脑型 $+$ 脑型 | 脑 | — |
:::

:::pitfall{label="血 CK-MB 看心肌，血肌酐看肾，不要并成一张“肌酸化验单”"}
$\mathrm{CK}$-$\mathrm{MB}$ 升高：心肌损伤，酶漏出。肌酐升高：肾排不出。肌酸合成在肝，储存磷酸化在肌和脑。三处器官各管一段，不要看见肌酸就只想骨骼肌。
:::

:::keypoint{label="肌酸分子的三家原料"}
- 骨架：甘氨酸。
- 脒基：精氨酸（脒基转移酶，同时放出鸟氨酸）。
- 甲基：$\mathrm{SAM}$。
- 器官：肝是合成肌酸的主要器官。
:::

### （二）半胱氨酸与多种生理活性物质的生成有关

**1. 半胱氨酸与胱氨酸可以互变**　半胱氨酸含有巯基（—$\mathrm{SH}$），胱氨酸含有二硫键（—$\mathrm{S}$—$\mathrm{S}$—），两者可以相互转变。

在许多蛋白质分子中，两个半胱氨酸残基间形成的二硫键对于维持蛋白质空间构象的稳定及其功能具有重要作用。如胰岛素的 $\mathrm{A}$、$\mathrm{B}$ 链就是以二硫键连接的，若二硫键断裂，胰岛素即失去其生物活性。体内有许多重要的酶，如琥珀酸脱氢酶、乳酸脱氢酶等，其活性与半胱氨酸的巯基直接有关，故有巯基酶之称。某些毒物，如芥子气、重金属盐等，能与酶分子中的巯基结合而抑制该酶的活性。体内存在的还原型谷胱甘肽能保护酶分子上的巯基，因而有重要的生理功能。

:::definition{label="巯基酶"}
活性与半胱氨酸巯基直接有关的酶称为巯基酶，如琥珀酸脱氢酶、乳酸脱氢酶。芥子气、重金属盐等与巯基结合可抑制酶活性；还原型谷胱甘肽能保护酶分子上的巯基。
:::

:::insight{label="二硫键稳住构象，游离巯基管催化"}
胰岛素 $\mathrm{A}$、$\mathrm{B}$ 链靠二硫键连在一起，键断即失活——这是结构账。琥珀酸脱氢酶、乳酸脱氢酶靠巯基干活——这是催化账。还原型谷胱甘肽把巯基保住，两条账都受它保护。
:::

**2. 半胱氨酸可转变成牛磺酸**　半胱氨酸首先氧化成磺基丙氨酸，再经磺基丙氨酸脱羧酶催化，脱去羧基生成牛磺酸。牛磺酸是结合胆汁酸的组成成分之一。

:::definition{label="牛磺酸"}
牛磺酸由半胱氨酸氧化成磺基丙氨酸后，再经磺基丙氨酸脱羧酶脱羧生成。它是结合胆汁酸的组成成分之一。
:::

:::insight{label="第八章胆汁酸的结合原料，有一笔写在半胱氨酸上"}
结合胆汁酸需要甘氨酸或牛磺酸。牛磺酸不是食物里另立的氨基酸户头，是半胱氨酸侧链氧化、再脱羧的产物。
:::

**3. 半胱氨酸可生成活性硫酸根**　含硫氨基酸氧化分解均可产生硫酸根，但半胱氨酸是体内硫酸根的主要来源。半胱氨酸可以直接脱去巯基和氨基，生成丙酮酸、氨和 $\mathrm{H}_2\mathrm{S}$。$\mathrm{H}_2\mathrm{S}$ 经氧化生成 $\mathrm{H}_2\mathrm{SO}_4$。

体内的硫酸根，一部分以无机盐的形式随尿排出，另一部分由 $\mathrm{ATP}$ 活化生成活性硫酸根，即 $3'$-磷酸腺苷 $5'$-磷酰硫酸（$3'$-phospho adenosine $5'$-phospho sulfate，$\mathrm{PAPS}$）。$\mathrm{ATP}$ 先与 $\mathrm{SO}_4^{2-}$ 生成腺苷-$5'$-磷酰硫酸，再由 $\mathrm{ATP}$ 在 $3'$ 位磷酸化，得到 $\mathrm{PAPS}$。

:::definition{label="PAPS"}
活性硫酸根即 $3'$-磷酸腺苷 $5'$-磷酰硫酸（$3'$-phospho adenosine $5'$-phospho sulfate，$\mathrm{PAPS}$）。硫酸根主要由半胱氨酸氧化而来，经 $\mathrm{ATP}$ 活化生成 $\mathrm{PAPS}$。化学性质活泼。
:::

$\mathrm{PAPS}$ 在肝生物转化中可提供硫酸根使某些物质生成硫酸酯。例如，类固醇激素可形成硫酸酯而被灭活，一些外源性酚类化合物也可以形成硫酸酯而排出体外。此外，$\mathrm{PAPS}$ 还可参与硫酸角质素及硫酸软骨素等分子中硫酸化氨基糖的合成。

:::keypoint{label="半胱氨酸三笔产物"}
- 与胱氨酸互变：二硫键、巯基酶、谷胱甘肽保护。
- 牛磺酸：结合胆汁酸。
- $\mathrm{PAPS}$：肝生物转化（类固醇灭活、酚类排泌）及硫酸化氨基糖（硫酸角质素、硫酸软骨素）。
:::

:::pitfall{label="硫酸根随尿走只是一部分，另一部分要活化成 PAPS 才有功能"}
不要把含硫氨基酸的氧化终产物只写成“无机硫酸盐排出”。类固醇灭活、糖胺聚糖硫酸化用的是 $\mathrm{PAPS}$，不是游离 $\mathrm{SO}_4^{2-}$。
:::

## 四、芳香族氨基酸代谢需要加氧酶催化

芳香族氨基酸包括苯丙氨酸、酪氨酸和色氨酸。酪氨酸可由苯丙氨酸羟化生成。苯丙氨酸与色氨酸为营养必需氨基酸。

:::definition{label="芳香族氨基酸"}
芳香族氨基酸包括苯丙氨酸、酪氨酸和色氨酸。酪氨酸可由苯丙氨酸羟化生成；苯丙氨酸与色氨酸为营养必需氨基酸。
:::

### （一）苯丙氨酸和酪氨酸代谢既有联系又有区别

**1. 苯丙氨酸羟化生成酪氨酸**　正常情况下，苯丙氨酸的主要代谢途径是经羟化作用生成酪氨酸，反应由苯丙氨酸羟化酶（phenylalanine hydroxylase）催化。苯丙氨酸羟化酶主要存在于肝等组织，属一种单加氧酶，辅酶是四氢生物蝶呤，催化的反应不可逆，故酪氨酸不能转变为苯丙氨酸。

$$
\text{苯丙氨酸}+\mathrm{O}_2+\text{四氢生物蝶呤}\xrightarrow{\text{苯丙氨酸羟化酶}}\text{酪氨酸}+\mathrm{H}_2\mathrm{O}+\text{二氢生物蝶呤}
$$

苯丙氨酸除转变为酪氨酸外，少量可经转氨基作用生成苯丙酮酸。先天性苯丙氨酸羟化酶缺陷病人，不能将苯丙氨酸羟化为酪氨酸。因此，苯丙氨酸经转氨基作用生成苯丙酮酸。大量的苯丙酮酸及其部分代谢产物（苯乳酸及苯乙酸等）由尿排出，称为苯丙酮尿症（phenylketonuria，$\mathrm{PKU}$）。苯丙酮酸的堆积对中枢神经系统有毒性，导致脑发育障碍，患儿智力低下。治疗原则是早期发现，并适当控制膳食中苯丙氨酸的含量。

:::definition{label="苯丙氨酸羟化酶"}
苯丙氨酸羟化酶（phenylalanine hydroxylase）主要存在于肝等组织，是单加氧酶，辅酶为四氢生物蝶呤。催化苯丙氨酸羟化生成酪氨酸，反应不可逆，故酪氨酸不能转变为苯丙氨酸。
:::

:::definition{label="苯丙酮尿症"}
苯丙酮尿症（phenylketonuria，$\mathrm{PKU}$）：先天性苯丙氨酸羟化酶缺陷，苯丙氨酸不能羟化为酪氨酸，改经转氨基生成苯丙酮酸，大量苯丙酮酸及其代谢产物（苯乳酸、苯乙酸等）由尿排出。苯丙酮酸堆积损伤中枢，导致脑发育障碍、智力低下。治疗：早期发现，适当控制膳食苯丙氨酸。
:::

:::pitfall{label="酪氨酸写不出苯丙氨酸，PKU 膳食控的是苯丙氨酸不是酪氨酸"}
羟化不可逆，酪氨酸是营养非必需氨基酸，前提是苯丙氨酸羟化酶正常。酶缺了，酪氨酸变成膳食依赖，苯丙氨酸及其转氨产物反而有毒。不要把“控制蛋白质”笼统写成治疗，教材写的是适当控制膳食中苯丙氨酸的含量。
:::

**2. 酪氨酸转变为儿茶酚胺和黑色素或彻底氧化分解**　酪氨酸的进一步代谢与合成某些神经递质、激素及黑色素有关。酪氨酸在肾上腺髓质和神经组织经酪氨酸羟化酶（tyrosine hydroxylase）催化生成 $3,4$-二羟苯丙氨酸（$3,4$-dihydroxyphenylalanine，$\mathrm{DOPA}$），又称多巴。与苯丙氨酸羟化酶相似，酪氨酸羟化酶也是以四氢生物蝶呤为辅酶的单加氧酶。多巴在多巴脱羧酶的作用下，脱去羧基生成多巴胺（dopamine）。多巴胺是一种神经递质。帕金森病（Parkinson disease）病人脑内多巴胺生成减少。

在肾上腺髓质，多巴胺侧链的 $\beta$-碳原子再被羟化，生成去甲肾上腺素（norepinephrine），后者甲基化生成肾上腺素（epinephrine）。多巴胺、去甲肾上腺素及肾上腺素统称为儿茶酚胺（catecholamine）。酪氨酸羟化酶是合成儿茶酚胺的关键酶，受终产物的反馈调节。

:::definition{label="儿茶酚胺"}
儿茶酚胺（catecholamine）包括多巴胺、去甲肾上腺素及肾上腺素。酪氨酸经酪氨酸羟化酶（四氢生物蝶呤为辅酶的单加氧酶）生成多巴，多巴脱羧生成多巴胺；在肾上腺髓质，多巴胺 $\beta$-羟化成去甲肾上腺素，再甲基化成肾上腺素。酪氨酸羟化酶是关键酶，受终产物反馈调节。
:::

:::timeline{period="酪氨酸到儿茶酚胺"}
- **酪氨酸羟化酶** 酪氨酸 → 多巴（关键酶，终产物反馈）
- **多巴脱羧酶** 多巴 → 多巴胺（神经递质；帕金森病时脑内减少）
- **β-羟化** 多巴胺 → 去甲肾上腺素（肾上腺髓质）
- **甲基化** 去甲肾上腺素 → 肾上腺素（甲基来自 SAM）
:::

酪氨酸代谢的另一条途径是合成黑色素（melanin）。在黑色素细胞中，酪氨酸经酪氨酸酶（tyrosinase）作用，羟化生成多巴，后者经氧化、脱羧等反应转变成吲哚醌，最后吲哚醌聚合为黑色素。先天性酪氨酸酶缺乏的病人，因不能合成黑色素，皮肤毛发等发白，称为白化病（albinism）。病人对阳光敏感，易患皮肤癌。

:::definition{label="白化病"}
白化病（albinism）：先天性酪氨酸酶缺乏，不能合成黑色素，皮肤毛发等发白。对阳光敏感，易患皮肤癌。
:::

:::pitfall{label="酪氨酸羟化酶和酪氨酸酶都生成多巴，不是同一个酶"}
- 酪氨酸羟化酶：肾上腺髓质和神经组织，走儿茶酚胺；关键酶，四氢生物蝶呤。
- 酪氨酸酶：黑色素细胞，走黑色素；缺了是白化病。
两条路在多巴处分叉。帕金森病是多巴胺减少，白化病是黑色素不能合成，不要并成“酪氨酸代谢病”。
:::

除上述代谢途径外，酪氨酸还可在转氨酶的催化下，生成对羟苯丙酮酸，后者经尿黑酸等中间产物进一步转变成延胡索酸和乙酰乙酸，然后两者分别沿糖和脂质代谢途径进行代谢。因此，苯丙氨酸和酪氨酸是生糖兼生酮氨基酸。当体内尿黑酸分解代谢的酶先天性缺陷时，尿黑酸的分解受阻，可出现尿黑酸尿症（alkaptonuria）。

:::definition{label="尿黑酸尿症"}
尿黑酸尿症（alkaptonuria）：尿黑酸分解代谢的酶先天性缺陷，尿黑酸分解受阻。酪氨酸经对羟苯丙酮酸、尿黑酸本应写成延胡索酸（生糖）和乙酰乙酸（生酮）。
:::

:::compare{title="苯丙氨酸／酪氨酸三条病"}
| 病 | 缺陷 | 堆积或缺失 | 后果 |
|----|------|------------|------|
| 苯丙酮尿症 $\mathrm{PKU}$ | 苯丙氨酸羟化酶 | 苯丙酮酸、苯乳酸、苯乙酸 | 脑发育障碍、智力低下 |
| 白化病 | 酪氨酸酶 | 不能合成黑色素 | 皮肤毛发发白，易患皮肤癌 |
| 尿黑酸尿症 | 尿黑酸分解酶 | 尿黑酸 | 尿黑酸分解受阻 |
:::

:::keypoint{label="苯丙氨酸和酪氨酸是生糖兼生酮氨基酸"}
彻底氧化：延胡索酸走糖，乙酰乙酸走脂质。第二节表9-2 把二者列入生糖兼生酮，依据就在这一笔碳架。
:::

### （二）色氨酸分解代谢可产生丙酮酸和乙酰乙酰 CoA

色氨酸除生成 $5$-羟色胺外，还可在肝经色氨酸加氧酶（tryptophan oxygenase）催化，生成一碳单位和多种酸性中间代谢产物。色氨酸经分解可产生丙酮酸和乙酰乙酰 $\mathrm{CoA}$，故色氨酸为生糖兼生酮氨基酸。少部分色氨酸还可转变成烟酸，但合成量很少，不能满足机体的需要。

:::definition{label="色氨酸加氧酶"}
色氨酸加氧酶（tryptophan oxygenase）在肝催化色氨酸分解，生成一碳单位和多种酸性中间代谢产物。下游可产生丙酮酸和乙酰乙酰 $\mathrm{CoA}$，故色氨酸为生糖兼生酮氨基酸。
:::

:::pitfall{label="色氨酸能写烟酸，不等于可以不吃维生素 PP"}
教材写明：合成量很少，不能满足机体的需要。烟酸仍按维生素供给。一碳单位、丙酮酸、乙酰乙酰 $\mathrm{CoA}$、$5$-$\mathrm{HT}$ 才是本节要记住的几笔产物。
:::

## 五、支链氨基酸的分解有相似的代谢过程

支链氨基酸包括缬氨酸、亮氨酸和异亮氨酸，它们都是营养必需氨基酸，在体内的分解有相似的代谢过程，大致分为三个阶段：①通过转氨基作用生成相应的 $\alpha$-酮酸；②通过氧化脱羧生成相应的脂酰 $\mathrm{CoA}$；③通过 $\beta$-氧化过程生成不同的中间产物参与三羧酸循环，其中缬氨酸分解产生琥珀酰 $\mathrm{CoA}$，亮氨酸产生乙酰 $\mathrm{CoA}$ 和乙酰乙酰 $\mathrm{CoA}$，异亮氨酸产生琥珀酰 $\mathrm{CoA}$ 和乙酰 $\mathrm{CoA}$。所以，这三种氨基酸分别是生糖氨基酸、生酮氨基酸和生糖兼生酮氨基酸。支链氨基酸的分解代谢主要在骨骼肌中进行（图9-13）。

::figure{src="/images/biochemistry/textbook/p0222_01.png" caption="图9-13　支链氨基酸的分解代谢。缬氨酸、亮氨酸、异亮氨酸先转氨成相应 α-酮酸，再氧化脱羧成相应脂酰 CoA，经 α,β-烯脂酰 CoA 后分开：缬氨酸→琥珀酰 CoA，亮氨酸→乙酰 CoA，异亮氨酸→琥珀酰 CoA 和乙酰 CoA。" alt="支链氨基酸三阶段分解：转氨、氧化脱羧、β-氧化，三种产物分别生糖、生酮或兼有"}

:::definition{label="支链氨基酸"}
支链氨基酸包括缬氨酸、亮氨酸和异亮氨酸，都是营养必需氨基酸。分解主要在骨骼肌，三阶段相似：转氨基 $\to$ 氧化脱羧 $\to\beta$-氧化进入三羧酸循环。
:::

:::compare{title="三种支链氨基酸的碳架终点"}
| 氨基酸 | 三羧酸循环相关产物 | 生糖／生酮 |
|--------|---------------------|------------|
| 缬氨酸 | 琥珀酰 $\mathrm{CoA}$ | 生糖 |
| 亮氨酸 | 乙酰 $\mathrm{CoA}$ 和乙酰乙酰 $\mathrm{CoA}$ | 生酮 |
| 异亮氨酸 | 琥珀酰 $\mathrm{CoA}$ 和乙酰 $\mathrm{CoA}$ | 生糖兼生酮 |
:::

:::pitfall{label="亮氨酸是生酮氨基酸，不要因为“支链”就一律写成生糖"}
三种支链结构相近，碳架终点不同。第二节表9-2：亮氨酸、赖氨酸才是生酮氨基酸；缬氨酸生糖；异亮氨酸兼有。分解主要在骨骼肌，不要画回肝的联合脱氨基当唯一场所。
:::

除了提供能量，支链氨基酸及其分解过程中产生的代谢中间产物，也具有信号分子特性，并通过调控细胞内的营养感知通路，在新陈代谢的平衡中发挥着至关重要的作用。哺乳动物雷帕霉素靶蛋白（mammalian target of rapamycin，$\mathrm{mTOR}$）是细胞内整合营养物质信号与生长因子信号的总开关，而亮氨酸是 $\mathrm{mTOR}$ 的主要激活剂。支链氨基酸分解代谢紊乱与代谢性疾病的发生发展密切相关，循环系统中支链氨基酸浓度过高是肥胖、胰岛素抵抗和 $2$ 型糖尿病等代谢性疾病的重要标志。

:::definition{label="mTOR 与亮氨酸"}
哺乳动物雷帕霉素靶蛋白（mammalian target of rapamycin，$\mathrm{mTOR}$）是细胞内整合营养物质信号与生长因子信号的总开关。亮氨酸是 $\mathrm{mTOR}$ 的主要激活剂。循环中支链氨基酸浓度过高是肥胖、胰岛素抵抗和 $2$ 型糖尿病的重要标志。
:::

综上所述，氨基酸除了作为合成蛋白质的原料外，还可以转变为神经递质、激素及其他重要的含氮生理活性物质（表9-3），其中一氧化氮（$\mathrm{NO}$）的细胞信号转导功能研究亦受到高度关注，而体内 $\mathrm{NO}$ 是由精氨酸在一氧化氮合酶（nitric oxide synthase，$\mathrm{NOS}$）催化下生成的。

$$
\text{精氨酸}+\mathrm{O}_2+\mathrm{NADPH}+\mathrm{H}^{+}\xrightarrow{\mathrm{NOS}}\text{瓜氨酸}+\mathrm{NO}+\mathrm{NADP}^{+}
$$

:::definition{label="一氧化氮合酶"}
一氧化氮合酶（nitric oxide synthase，$\mathrm{NOS}$）催化精氨酸生成一氧化氮（$\mathrm{NO}$）和瓜氨酸，需 $\mathrm{O}_2$ 和 $\mathrm{NADPH}$。$\mathrm{NO}$ 是细胞信号转导分子。
:::

## 本章小结

氨基酸除作为合成蛋白质的原料外，还可转变成某些激素、神经递质及核苷酸等含氮物质。人体内氨基酸的来源有：食物蛋白质的消化吸收、组织蛋白质的分解和体内合成。外源性与内源性的氨基酸共同构成氨基酸代谢库，参与体内代谢。

氨基酸的分解代谢包括一般代谢和个别代谢。氨基酸的一般分解代谢途径是针对氨基酸的 $\alpha$-氨基和 $\alpha$-酮酸共性结构的分解。氨基酸通过转氨基作用、氧化脱氨基作用等方式脱去氨基，生成 $\alpha$-酮酸。有毒的氨以丙氨酸和谷氨酰胺的形式运往肝或肾，在肝经鸟氨酸循环合成尿素。脱去氨基生成的 $\alpha$-酮酸，可转变成糖或脂质，可经氨基化生成营养非必需氨基酸，也可彻底氧化分解并提供能量。

氨基酸代谢除共有的一般代谢途径外，因其侧链不同，有些氨基酸还有其特殊的代谢途径。氨基酸脱羧基作用产生的胺类化合物具有重要的生理功能；某些氨基酸分解代谢过程中产生的一碳单位可用于嘌呤和嘧啶核苷酸的合成；含硫氨基酸代谢产生的活性甲基，参与体内重要含甲基化合物的合成；芳香族氨基酸代谢产生重要的神经递质、激素及黑色素；支链氨基酸除了提供能量，还是某些代谢性疾病的重要标志。

:::definition{label="本章小结里的氨基酸代谢库"}
外源（食物蛋白质消化吸收）与内源（组织蛋白质分解、体内合成）氨基酸共同构成氨基酸代谢库，参与体内代谢。
:::

:::keypoint{label="本章小结按节收口"}
- 来源：食物消化吸收、组织蛋白分解、体内合成；汇入代谢库。
- 一般代谢：脱氨基得 $\alpha$-酮酸；氨以丙氨酸、谷氨酰胺运输；肝鸟氨酸循环写尿素；$\alpha$-酮酸生糖、生脂、再氨基化或氧化供能。
- 脱羧：胺类（$\mathrm{GABA}$、组胺、$5$-$\mathrm{HT}$、多胺）。
- 一碳单位：$\mathrm{FH}_4$ 载体，供嘌呤、嘧啶合成。
- 含硫：$\mathrm{SAM}$ 活性甲基；半胱氨酸写牛磺酸和 $\mathrm{PAPS}$。
- 芳香族：递质、激素、黑色素；$\mathrm{PKU}$、白化病、尿黑酸尿症。
- 支链：骨骼肌三阶段分解；亮氨酸激活 $\mathrm{mTOR}$；循环浓度过高是代谢性疾病标志。
:::

:::memory{label="本节必背要点"}
- [ ] 脱羧酶辅酶：磷酸吡哆醛。胺氧化酶是黄素蛋白，肝活性最高。
- [ ] $\mathrm{GABA}$：谷氨酸脱羧，中枢抑制。组胺：肥大细胞，扩血管、哮喘、促胃酸。
- [ ] $5$-$\mathrm{HT}$：色氨酸先羟化再脱羧；脑抑制、外周缩血管；尿中 $5$-羟吲哚乙酸。
- [ ] 鸟氨酸脱羧酶是多胺关键酶；肿瘤时酶和多胺升高。
- [ ] 一碳单位：甲基、亚甲基、次甲基、甲酰基、亚氨甲基；载体 $\mathrm{FH}_4$。
- [ ] 来源：丝、甘、组、色；苏氨酸间接经甘氨酸。$N^{5}$-甲基 $\mathrm{FH}_4$ 生成不可逆。
- [ ] 叶酸 $\xrightarrow{\text{二氢叶酸还原酶，两步 NADPH}}$ $\mathrm{FH}_4$。磺胺抑细菌二氢叶酸合成；甲氨蝶呤抑 $\mathrm{FH}_4$ 生成。
- [ ] $\mathrm{SAM}$：活性甲基，直接供体，约 $50$ 余种物质需要；$\mathrm{N}^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 是间接供体。
- [ ] 甲硫氨酸循环不能净合成甲硫氨酸；$\mathrm{B}_{12}$ 是甲硫氨酸合成酶辅酶。
- [ ] 肌酸：甘氨酸骨架 $+$ 精氨酸脒基 $+\mathrm{SAM}$ 甲基；肝合成。$\mathrm{CK}$-$\mathrm{MB}$ 辅助诊心肌梗死。
- [ ] 肌酐：磷酸肌酸非酶促；尿排出量恒定；血肌酐辅助诊肾功能不全。
- [ ] $\mathrm{PAPS}$：活性硫酸根，半胱氨酸是硫酸根主要来源。
- [ ] $\mathrm{PKU}$：苯丙氨酸羟化酶；白化病：酪氨酸酶；尿黑酸尿症：尿黑酸分解酶。
- [ ] 儿茶酚胺关键酶：酪氨酸羟化酶。帕金森病：脑内多巴胺减少。
- [ ] 缬氨酸生糖、亮氨酸生酮、异亮氨酸兼有；主要在骨骼肌。亮氨酸激活 $\mathrm{mTOR}$。
- [ ] $\mathrm{NO}$：精氨酸经 $\mathrm{NOS}$ 生成。
:::

## 思考题

1. 请从氨基酸代谢角度简述巨幼红细胞性贫血的机制。
2. 近年来的研究发现，降低肿瘤患者饮食中的甲硫氨酸摄入量，具有一定的抗肿瘤效果，试从一碳单位介导代谢的角度分析其作用机制。
3. 请分析谷氨酸和精氨酸治疗肝性脑病的生化机制。
4. 体内重要的转氨酶有哪几种？测定血清中这些转氨酶的活性有何意义？

:::tip{label="四道思考题在正文里的户头"}
- 巨幼细胞贫血：一碳单位／$\mathrm{FH}_4$ 不足，或维生素 $\mathrm{B}_{12}$ 缺乏使 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$ 的甲基转不出、$\mathrm{FH}_4$ 不能再生，嘌呤嘧啶合成障碍，细胞分裂受影响。
- 限甲硫氨酸抗肿瘤：甲硫氨酸 $\to\mathrm{SAM}\to$ 广泛甲基化；循环依赖 $N^{5}$-$\mathrm{CH}_3$-$\mathrm{FH}_4$；一碳单位还直接参与碱基合成。少供甲硫氨酸，等于少供活性甲基和相关一碳周转，核酸合成和增殖（多胺也要 $\mathrm{SAM}$ 氨丙基）都受压。
- 谷氨酸、精氨酸治肝性脑病：谷氨酸固定氨为谷氨酰胺（第三节运氨／解毒）；精氨酸是鸟氨酸循环中间物，并激活 $\mathrm{AGA}$ 合酶从而激活 $\mathrm{CPS}$ Ⅰ，加快尿素合成、降低血氨。
- 转氨酶：第二节的 $\mathrm{ALT}$、$\mathrm{AST}$ 等；血清活性升高反映肝等组织损伤（酶从细胞漏出）。本题跨回第二节，不要在本节另造新酶名单。
