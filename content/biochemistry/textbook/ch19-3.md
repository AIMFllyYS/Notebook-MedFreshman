## 一、重组DNA技术广泛应用于生物医学

利用重组 $\mathrm{DNA}$ 技术的实际目标是生产用于生物医学应用的物质。该技术至少有两个优点：①可以提供大量传统纯化方法无法获得的物质（如干扰素、组织型纤溶酶原活化因子等）。②生产有药用价值的蛋白质／多肽及疫苗抗原等产品，如用于人类和其他动物疾病治疗（胰岛素和生长激素）和诊断（艾滋病检测）以及疾病预防（乙型肝炎疫苗）等。重组人胰岛素是利用该技术生产的世界上第一个基因工程产品。目前上市的基因工程药物已有百种以上，表19-4 中仅列出部分药物和疫苗。

:::definition{label="重组 DNA 技术用于生物医学的两个优点"}
①提供大量传统纯化方法无法获得的物质（如干扰素、组织型纤溶酶原活化因子）。②生产有药用价值的蛋白质／多肽及疫苗抗原：治疗（胰岛素、生长激素）、诊断（艾滋病检测）、预防（乙型肝炎疫苗）。
:::

:::definition{label="重组人胰岛素是第一个基因工程产品"}
重组人胰岛素是利用重组 $\mathrm{DNA}$ 技术生产的世界上第一个基因工程产品。表19-4 把它的功能写成治疗糖尿病；优点①里点名的干扰素、组织型纤溶酶原活化因子，是「传统纯化拿不到足够量」的例子。
:::

:::pitfall{label="两个优点不要并成「就是做胰岛素」"}
第一句是量：传统纯化拿不到。第二句是种类：药用蛋白／多肽和疫苗抗原，覆盖治疗、诊断、预防。胰岛素是第一号产品，不是唯一产品。
:::

:::compare{title="优点①的量 vs 优点②的用途"}
| | 教材原句指向 | 点名例子 |
|--|--------------|----------|
| 优点① | 传统纯化无法获得的**大量**物质 | 干扰素、组织型纤溶酶原活化因子 |
| 优点② | 药用蛋白质／多肽及疫苗抗原 | 治疗：胰岛素、生长激素；诊断：艾滋病检测；预防：乙型肝炎疫苗 |

:::

表里相邻两行方向相反。写成「重组凝血因子溶血栓」或「tPA 治血友病」，功能户头就反了。优点①里的「组织型纤溶酶原活化因子」与表中「组织纤溶酶原激活剂」是同一类产物。
:::

利用重组 $\mathrm{DNA}$ 技术，可以让细菌、酵母等低等生物成为制药工厂，也使基因工程细菌成为各类生物基因的储藏所；可以将小鼠杂交瘤细胞人源化，让其产生人源化抗体；可以制造基因工程病毒，使病毒保留免疫原性，缺乏感染性或变成不含核酸的类病毒颗粒（virus-like particle，$\mathrm{VLP}$）。

:::definition{label="低等生物当制药工厂，工程菌当基因储藏所"}
细菌、酵母等成为制药工厂；基因工程细菌成为各类生物基因的储藏所。前者对着表19-4 的蛋白质／多肽，后者对着第二节基因组文库、$\mathrm{cDNA}$ 文库那一类「把基因存起来」。
:::

:::definition{label="人源化抗体来自人源化的小鼠杂交瘤"}
将小鼠杂交瘤细胞人源化，让其产生人源化抗体。表19-4「人源化单克隆抗体」的来路是这一句，不是「在大肠埃希菌里直接表达完整人抗体」那么简单。
:::

:::definition{label="类病毒颗粒 VLP"}
类病毒颗粒（virus-like particle，$\mathrm{VLP}$）：基因工程病毒保留免疫原性、缺乏感染性，或变成不含核酸的颗粒。表19-4 乙肝疫苗写成 $\mathrm{HBsAg}$ $\mathrm{VLP}$，$\mathrm{HPV}$ 疫苗写成 $\mathrm{L}1\mathrm{VLP}$。
:::

:::compare{title="三种工程化产物"}
| | 在做什么 | 落点 |
|--|----------|------|
| 细菌／酵母制药工厂 | 表达药用蛋白、多肽 | 表19-4 前半 |
| 人源化杂交瘤 | 产生人源化抗体 | 表19-4 单抗行 |
| 基因工程病毒／$\mathrm{VLP}$ | 保留免疫原性，去掉感染性或核酸 | 乙肝、$\mathrm{HPV}$ 疫苗 |

「缺乏感染性」和「不含核酸」是疫苗安全的两句，不要写成「活病毒疫苗」。
:::

:::pitfall{label="VLP 不是完整的感染性病毒"}
教材：保留免疫原性，缺乏感染性，或变成不含核酸的类病毒颗粒。答成「重组疫苗就是减毒活病毒」，$\mathrm{VLP}$ 这一户就没了。
:::

## 二、重组DNA技术是医学研究的重要技术平台

重组 $\mathrm{DNA}$ 技术可用于医学研究的很多方面，诸如遗传修饰动物模型的建立、遗传修饰细胞模型的建立、基因获得或丧失对生物功能的影响等。

:::definition{label="医学研究平台三件事"}
①遗传修饰动物模型；②遗传修饰细胞模型；③基因获得或丧失对生物功能的影响。后文（一）（二）（三）按这个顺序展开。
:::

### （一）遗传修饰动物模型在医学中具有广泛的应用

重组 $\mathrm{DNA}$ 技术可用于遗传修饰动物模型的研制，从而建立人类疾病的动物模型。目前已经建立了诸多人类疾病的遗传修饰动物模型，用于研究癌症、糖尿病、肥胖、心脏病、老化、关节炎等；遗传修饰猪模型的应用，可望增加器官移植的成功率；改造蚊子的基因组，使其产生对疟疾的免疫反应，可望消灭疟疾。

:::definition{label="遗传修饰动物模型"}
用重组 $\mathrm{DNA}$ 技术研制遗传修饰动物，建立人类疾病的动物模型。本版点名已用于研究癌症、糖尿病、肥胖、心脏病、老化、关节炎等。
:::

:::definition{label="遗传修饰猪与改造蚊子"}
遗传修饰猪模型：可望增加器官移植的成功率。改造蚊子基因组：使其产生对疟疾的免疫反应，可望消灭疟疾。这两句是开篇「物种修饰与改造」在正文里仅有的展开。
:::

:::pitfall{label="「可望」不是已经常规用于临床器官移植或已经消灭疟疾"}
教材对猪和蚊子都写「可望」。改成「已经解决器官短缺」或「疟疾已被基因改造蚊子消灭」，超出本版原文。
:::

:::keypoint{label="动物模型这一小节三层"}
- 疾病模型：癌、糖尿病、肥胖、心脏病、老化、关节炎。
- 移植：遗传修饰猪，可望提高成功率。
- 传染病媒介：改造蚊子对疟疾产生免疫，可望消灭疟疾。
:::

### （二）遗传修饰细胞模型在医学中具有创新应用

重组 $\mathrm{DNA}$ 技术也可用于遗传修饰细胞模型的建立，从而用于基因替代治疗／靶向治疗，或体内示踪。由单基因产物缺乏引起的疾病在理论上都可以接受替代治疗，其策略是将基因的正常副本克隆到载体中，并转入宿主细胞进行可调控的表达。体细胞基因治疗（somatic gene therapy）已经在 $\mathrm{X}$ 连锁联合免疫缺陷病（X-linked SCID）、慢性淋巴细胞白血病（chronic lymphocytic leukemia，$\mathrm{CLL}$）和帕金森病进行了临床研究。改造 $\mathrm{T}$ 淋巴细胞，让其携带嵌合抗原受体（chimeric antigen receptor，$\mathrm{CAR}$），从而达到靶向治疗疾病的 $\mathrm{CAR}$-$\mathrm{T}$ 细胞也是采用重组 $\mathrm{DNA}$ 技术实现的。表19-5 中仅列出部分已获批的基因治疗药物。

:::definition{label="遗传修饰细胞模型的三个去向"}
用于基因替代治疗／靶向治疗，或体内示踪。动物模型是个体水平的模型；这里是细胞水平，可以直接接到治疗和示踪。
:::

:::definition{label="单基因缺乏的替代治疗策略"}
由单基因产物缺乏引起的疾病在理论上都可以接受替代治疗。策略：把基因的正常副本克隆到载体中，转入宿主细胞，进行可调控的表达。
:::

:::definition{label="体细胞基因治疗"}
体细胞基因治疗（somatic gene therapy）：本版写明已经在 $\mathrm{X}$ 连锁联合免疫缺陷病（X-linked SCID）、慢性淋巴细胞白血病（$\mathrm{CLL}$）和帕金森病进行了临床研究。这是「临床研究」，不是这三种病都已常规治愈。
:::

:::definition{label="CAR-T"}
改造 $\mathrm{T}$ 淋巴细胞，让其携带嵌合抗原受体（chimeric antigen receptor，$\mathrm{CAR}$），从而达到靶向治疗疾病。$\mathrm{CAR}$-$\mathrm{T}$ 细胞也是采用重组 $\mathrm{DNA}$ 技术实现的。表19-5 列出靶向 $\mathrm{CD}19$ 和靶向 $\mathrm{BCMA}$ 的获批适应证。
:::

:::pitfall{label="替代治疗写的是「理论上都可以」，策略里必须有载体和可调控表达"}
不是把一段裸 $\mathrm{DNA}$ 随便打进患者。正常副本要克隆到载体中，并转入宿主细胞进行可调控的表达。漏掉「可调控」，和第二节表达载体的调控元件就脱节。
:::

:::pitfall{label="体细胞基因治疗的三个病是临床研究，表19-5 才是部分已获批"}
$\mathrm{X}$-linked SCID、$\mathrm{CLL}$、帕金森病：临床研究。表19-5：部分已获批的基因治疗药物。两张名单不要并成「这些病都已经批准上市」。
:::

| 原理 | 治疗疾病 |
|------|----------|

| 靶向 $\mathrm{CD}19$，$\mathrm{CAR}$-$\mathrm{T}$ 细胞疗法 | 复发或难治性大 $\mathrm{B}$ 细胞淋巴瘤 |
| 靶向 $\mathrm{B}$ 细胞成熟抗原（$\mathrm{BCMA}$），$\mathrm{CAR}$-$\mathrm{T}$ 细胞疗法 | 复发或难治性多发性骨髓瘤 |

| 靶点 | 适应证 |
|------|--------|
| $\mathrm{CD}19$ | 复发或难治性大 $\mathrm{B}$ 细胞淋巴瘤 |
| $\mathrm{BCMA}$（$\mathrm{B}$ 细胞成熟抗原） | 复发或难治性多发性骨髓瘤 |

都是改造 $\mathrm{T}$ 细胞携带 $\mathrm{CAR}$，靶点不同，病种不同。
:::

:::insight{label="RPE65 那一行有「存活视网膜细胞」前提"}
不是任何视力丧失都能导入 $\mathrm{RPE}65$。教材写明：双拷贝 $\mathrm{RPE}65$ 基因突变所致，且保留足够数量的存活视网膜细胞。没有靶细胞，替代基因没有落点。
:::

:::pitfall{label="p53 那一行是复制缺陷型腺病毒，不是野毒株"}
「人工改造的重组复制缺陷型人 $5$ 型腺病毒」。写成「腺病毒感染治疗头颈癌」，感染性与基因治疗载体两户并了。第二节感染是包装后的运载体，这里还加了复制缺陷。
:::

### （三）基因和基因功能的获得与丧失是科学研究的重要领域之一

基因工程生物或细胞模型可用来发现一些基因的新功能，或发现新基因，一般可通过基因的获得（如转基因）或丧失（如基因敲除）进行研究，也可通过示踪实验，如将绿色荧光蛋白质（green fluorescent protein，$\mathrm{GFP}$）与细胞内的某些蛋白质融合，可使细胞变成具有示踪作用的发光细胞，来研究基因表达产物的定位或相互作用信息等，或通过报告基因（如 $\mathrm{GFP}$ 或催化特定底物的酶）与不同启动子相融合的方法实现对基因表达调控的研究。

:::definition{label="获得如转基因，丧失如基因敲除"}
发现基因新功能或发现新基因：一般通过基因的获得（如转基因）或丧失（如基因敲除）。这是后文「完全功能缺失／隐性功能缺失／显性功能获得」等位基因的预告。
:::

:::definition{label="GFP 融合做示踪"}
将绿色荧光蛋白质（$\mathrm{GFP}$）与细胞内某些蛋白质融合，使细胞变成具有示踪作用的发光细胞，用来研究表达产物的定位或相互作用。遗传修饰细胞模型里的「体内示踪」落在这里。
:::

:::definition{label="报告基因融合启动子研究调控"}
报告基因（如 $\mathrm{GFP}$，或催化特定底物的酶）与不同启动子相融合，实现对基因表达调控的研究。看的是启动子能不能驱动报告，不是把报告基因当成治疗基因。
:::

:::compare{title="转基因／敲除 vs 示踪 vs 报告基因"}
| | 在改什么 | 读出什么 |
|--|----------|----------|
| 转基因（获得）／敲除（丧失） | 基因有或无 | 功能表型 |
| $\mathrm{GFP}$ 融合 | 蛋白质挂上荧光 | 定位、相互作用 |
| 报告基因 $+$ 启动子 | 调控序列驱动报告 | 表达调控 |

三户都可以用重组 $\mathrm{DNA}$ 技术实现，问的问题不同。
:::

## 三、重组DNA技术是基因及其表达产物研究的技术基础

重组 $\mathrm{DNA}$ 技术已经成为基因或基因功能获得或丧失研究的技术基础，它可以产生完全功能缺失等位基因、隐性功能缺失等位基因和显性功能获得等位基因。

:::definition{label="三种等位基因"}
以重组 $\mathrm{DNA}$ 技术为技术基础，可以产生：完全功能缺失等位基因、隐性功能缺失等位基因、显性功能获得等位基因。获得／丧失不是只有「敲掉」一种。
:::

:::pitfall{label="功能获得不一定是野生型恢复"}
显性功能获得等位基因是「多出来或变强的功能」，与替代治疗里「补回正常副本」不是同一句话。转基因可以造成获得；敲除偏向缺失。
:::

### （一）在基因组水平上干预基因

重组 $\mathrm{DNA}$ 技术是基因打靶（包括基因敲除和基因敲入）及基因组编辑等的技术基础。例如，基因敲除（gene knock-out），传统的方法是利用同源重组的原理，用目的基因替换基因组上的特定基因，要实现这一目标，需要将目的基因克隆到合适的载体上，并在其两侧加上待敲除基因上的部分序列，使重组 $\mathrm{DNA}$ 进入细胞后能通过同源重组替换基因组的目标基因。条件性基因打靶（conditional gene targeting）是在目的基因两侧构建了 $\mathrm{Cre}$ 重组酶的切割位点。基因组编辑（genome editing）是指一类能定向地在基因组上改变基因序列的技术，其中 $\mathrm{CRISPR}/\mathrm{Cas}9$ 系统是目前应用最多的、脱靶最少的基因组编辑技术，也是细菌抵抗病毒感染的一种获得性免疫机制。利用 $\mathrm{CRISPR}/\mathrm{Cas}9$ 基因组编辑技术对特定基因进行改造，也需要在体外构建含导向 $\mathrm{crRNA}$ 和 $\mathrm{Cas}9$ 编码基因的重组载体，然后将这种重组载体导入受体细胞，才能实现在基因组水平定向地改变特定基因的目的。

:::definition{label="基因打靶包括敲除和敲入"}
基因打靶：基因敲除和基因敲入。重组 $\mathrm{DNA}$ 技术是打靶及基因组编辑的技术基础。第一节已说明打靶的原理是同源重组；本节补上载体怎么建。
:::

:::definition{label="传统基因敲除靠同源重组换掉目标基因"}
基因敲除（gene knock-out）的传统方法：利用同源重组，用目的基因替换基因组上的特定基因。操作：把目的基因克隆到合适载体上，两侧加上待敲除基因上的部分序列，使重组 $\mathrm{DNA}$ 进入细胞后能通过同源重组替换目标基因。
:::

:::definition{label="条件性基因打靶"}
条件性基因打靶（conditional gene targeting）：在目的基因两侧构建 $\mathrm{Cre}$ 重组酶的切割位点。不是全程、全身、随时敲掉，而是留给 $\mathrm{Cre}$ 再切。第一节位点特异性重组的 $\mathrm{Cre}/\mathrm{lox}$ 思路在这里变成打靶策略。
:::

:::definition{label="基因组编辑与 CRISPR/Cas9 在本节的用法"}
基因组编辑（genome editing）：一类能定向地在基因组上改变基因序列的技术。其中 $\mathrm{CRISPR}/\mathrm{Cas}9$ 是目前应用最多、脱靶最少的基因组编辑技术，也是细菌抵抗病毒感染的获得性免疫机制。工程操作：体外构建含导向 $\mathrm{crRNA}$ 和 $\mathrm{Cas}9$ 编码基因的重组载体，导入受体细胞，才能在基因组水平定向改变特定基因。
:::

:::insight{label="本节 CRISPR 只作为打靶工具出现，机制在第一节"}
获得性免疫、间隔序列、$\mathrm{PAM}$、$\mathrm{sgRNA}$ 的账在第一节。本节只强调：它是应用最多、脱靶最少的编辑技术；用它也要先做重组载体再导入。不要在这里重写 $\mathrm{Cas}1$-$\mathrm{Cas}2$ 和 $\mathrm{R}$ 环。
:::

:::compare{title="传统敲除 vs 条件性打靶 vs CRISPR 编辑"}
| | 认什么 | 载体上要带什么 |
|--|--------|----------------|
| 传统敲除 | 待敲除基因两侧的同源序列 | 目的基因 $+$ 两侧同源臂 |
| 条件性打靶 | $\mathrm{Cre}$ 的切割位点 | 目的基因两侧的 $\mathrm{Cre}$ 位点 |
| $\mathrm{CRISPR}/\mathrm{Cas}9$ 编辑 | 导向 $\mathrm{crRNA}$ 指定的靶 | 导向 $\mathrm{crRNA}$ $+$ $\mathrm{Cas}9$ 编码基因 |

三者都要「体外构建重组载体 → 导入受体细胞」，这正是第二节五步在基因组干预上的延伸。
:::

:::pitfall{label="敲除不是把基因组基因直接用限制酶切掉"}
传统方法走同源重组替换，两侧必须有待敲除基因的部分序列。写成「限制酶进细胞核把基因剪掉」，同源臂和打靶载体就没有了。
:::

### （二）在RNA水平上干预基因的功能

$\mathrm{RNA}$ 干扰（RNA interference，$\mathrm{RNAi}$）是通过干扰小 $\mathrm{RNA}$（small interference RNA，$\mathrm{siRNA}$）与靶 $\mathrm{RNA}$ 结合，从而阻止基因表达的方法。$\mathrm{siRNA}$ 可以直接采用化学法合成，也可以利用 $\mathrm{DNA}$ 克隆技术构建干扰小发夹 $\mathrm{RNA}$，即将编码 $\mathrm{siRNA}$ 反向互补序列和间隔序列（linker）克隆入合适的载体，在细胞内转录合成干扰小发夹 $\mathrm{RNA}$，实现 $\mathrm{RNA}$ 干扰目的。除了进行科学研究，已经有很多 $\mathrm{siRNA}$ 用于临床治疗，如靶向转甲状腺素蛋白（$\mathrm{ATTR}$）$\mathrm{mRNA}$ 的 $\mathrm{siRNA}$，治疗成人遗传性转甲状腺素蛋白淀粉样变性伴多发性神经病（$\mathrm{hATTR}$-$\mathrm{PN}$）；靶向羟基酸氧化酶 $1$（$\mathrm{HAO}1$）$\mathrm{mRNA}$ 的 $\mathrm{siRNA}$，治疗原发性高草酸尿症 $1$ 型（$\mathrm{PH}1$）；靶向 $\mathrm{PCSK}9$ $\mathrm{mRNA}$ 的 $\mathrm{siRNA}$，治疗成人原发性高胆固醇血症（杂合子家族性和非家族性）或混合型血脂异常等。

:::definition{label="RNA 干扰"}
$\mathrm{RNA}$ 干扰（RNA interference，$\mathrm{RNAi}$）：通过干扰小 $\mathrm{RNA}$（small interference RNA，$\mathrm{siRNA}$）与靶 $\mathrm{RNA}$ 结合，从而阻止基因表达。作用水平在 $\mathrm{RNA}$，不是改基因组序列。
:::

:::definition{label="siRNA 两条来路"}
①直接化学法合成。②利用 $\mathrm{DNA}$ 克隆：把编码 $\mathrm{siRNA}$ 的反向互补序列和间隔序列（linker）克隆入合适载体，在细胞内转录合成干扰小发夹 $\mathrm{RNA}$，实现 $\mathrm{RNAi}$。第二条才真正用到第二节的克隆技术。
:::

:::definition{label="本版点名的三种治疗用 siRNA"}
①靶向 $\mathrm{ATTR}$ $\mathrm{mRNA}$：成人遗传性转甲状腺素蛋白淀粉样变性伴多发性神经病（$\mathrm{hATTR}$-$\mathrm{PN}$）。②靶向 $\mathrm{HAO}1$ $\mathrm{mRNA}$：原发性高草酸尿症 $1$ 型（$\mathrm{PH}1$）。③靶向 $\mathrm{PCSK}9$ $\mathrm{mRNA}$：成人原发性高胆固醇血症（杂合子家族性和非家族性）或混合型血脂异常。不要另补教材没有的 $\mathrm{siRNA}$ 药物。
:::

:::compare{title="基因组干预 vs RNA 干预"}
| | 改的是什么 | 本版方法 |
|--|------------|----------|
| 基因组水平 | 基因组上的基因序列 | 打靶（敲除／敲入）、条件性 $\mathrm{Cre}$ 位点、$\mathrm{CRISPR}/\mathrm{Cas}9$ |
| $\mathrm{RNA}$ 水平 | 靶 $\mathrm{RNA}$，阻止表达 | $\mathrm{siRNA}$ 化学合成或小发夹克隆 |

$\mathrm{RNAi}$ 不改 $\mathrm{DNA}$ 顺序；打靶和编辑才改。
:::

:::pitfall{label="小发夹 RNA 仍要克隆进载体，不是「RNAi 就不用重组 DNA」"}
化学合成的 $\mathrm{siRNA}$ 可以不走克隆；构建干扰小发夹则必须把反向互补序列和 linker 克隆入载体。本节标题是「重组 $\mathrm{DNA}$ 技术是……技术基础」，连 $\mathrm{RNAi}$ 这一户也有一半落在克隆上。
:::

### （三）研究蛋白质的相互作用

重组 $\mathrm{DNA}$ 技术也是蛋白质相互作用研究的技术基础。例如，酵母双杂交系统（yeast two-hybrid system）是利用分别克隆转录因子 $\mathrm{DNA}$ 结合结构域（DNA binding domain，$\mathrm{DBD}$）和转录激活结构域（transcription activating domain，$\mathrm{TAD}$）的融合基因，对 $\mathrm{DBD}$-融合蛋白质和 $\mathrm{TAD}$-融合蛋白质的融合部分的潜在相互作用能力进行研究。

:::definition{label="酵母双杂交系统"}
酵母双杂交系统（yeast two-hybrid system）：分别克隆转录因子 $\mathrm{DNA}$ 结合结构域（$\mathrm{DBD}$）和转录激活结构域（$\mathrm{TAD}$）的融合基因，用 $\mathrm{DBD}$-融合蛋白与 $\mathrm{TAD}$-融合蛋白的融合部分，研究二者潜在的相互作用。第二节「用酵母双杂交克隆特异性相互作用蛋白质的编码基因」与这里是同一套系统。
:::

:::insight{label="双杂交的「杂交」是两个融合蛋白相遇，不是核酸杂交"}
一边 $\mathrm{DBD}$ 融合物，一边 $\mathrm{TAD}$ 融合物；融合部分若能结合，才把结合域和激活域凑回一个转录因子。菌落核酸原位杂交（图19-19）认的是 $\mathrm{DNA}$ 序列，不要并户。
:::

:::pitfall{label="双杂交克隆的是融合基因，检测的是蛋白质相互作用"}
「分别克隆 $\mathrm{DBD}$ 和 $\mathrm{TAD}$ 的融合基因」是重组 $\mathrm{DNA}$ 操作；读出的是融合部分能不能结合。写成「酵母里做核酸杂交筛基因」，结构域那一户就空了。
:::

:::keypoint{label="三个水平都要先有重组载体"}
- 基因组：同源臂或 $\mathrm{Cre}$ 位点或 $\mathrm{crRNA}+\mathrm{Cas}9$，克隆后导入。
- $\mathrm{RNA}$：小发夹的反向互补序列 $+$ linker，克隆后在细胞内转录。
- 蛋白质：$\mathrm{DBD}$／$\mathrm{TAD}$ 融合基因，分别克隆。
:::

## 本章小结

$\mathrm{DNA}$ 重组是指 $\mathrm{DNA}$ 分子内或分子间发生的遗传信息的重新共价组合过程，包括同源重组、位点特异性重组和转座重组等类型，广泛存在于各类生物。自然界 $\mathrm{DNA}$ 重组方式主要有同源重组、位点特异性重组和转座重组。原核生物还可以接合、转化和转导等作为基因转移的方式。噬菌体在感染细菌后在宿主基因组上留下短序列，从而组成 $\mathrm{CRISPR}$ 序列簇，成为细菌防御病毒感染的重要获得性免疫机制。

重组 $\mathrm{DNA}$ 技术是指通过体外操作将不同来源的两个或两个以上 $\mathrm{DNA}$ 分子重新组合，并在适当细胞中扩增形成新的功能 $\mathrm{DNA}$ 分子的方法。基本操作包括五步：①获取目的 $\mathrm{DNA}$；②选择和准备载体；③目的 $\mathrm{DNA}$ 与载体连接；④重组 $\mathrm{DNA}$ 导入受体细胞；⑤重组体的筛选、鉴定及克隆化。依据载体的不同，重组的目的基因可被克隆扩增或在原核或真核细胞中表达。限制性核酸内切酶、$\mathrm{DNA}$ 连接酶等是重组 $\mathrm{DNA}$ 技术常用的重要工具酶。

拟克隆的基因称为目的基因。获取目的基因的方法包括化学合成、从基因组文库或 $\mathrm{cDNA}$ 文库钓取以及 $\mathrm{PCR}$ 扩增等。载体是指能携带目的基因在受体细胞中复制或表达的 $\mathrm{DNA}$ 分子，可分为克隆载体和表达载体。克隆载体应至少具备复制位点、供目的基因插入的单一酶切位点或多克隆酶切位点和筛选标志，表达载体除了具备克隆载体的一般特征外，还应具备供目的基因在受体细胞中表达的转录单位及必要元件，如真核表达载体的 $\mathrm{poly}(\mathrm{A})$ 加尾信号。筛选和鉴定重组体的方法主要有遗传标志筛选法、序列特异性筛选法、亲和筛选法等。表达目的基因的体系包括原核表达体系和真核表达体系，两者各具优势和不足。常用的原核表达体系是大肠埃希菌表达体系，操作简便，但缺乏对基因表达产物的加工修饰；常用的真核表达体系有酵母表达体系、昆虫表达体系和哺乳细胞表达体系。

重组 $\mathrm{DNA}$ 技术已经成为基因工程制药的重要技术平台，包括重组蛋白质、重组多肽、重组病毒或类病毒颗粒、人源化单克隆抗体等多种药物都是采用重组 $\mathrm{DNA}$ 技术完成的；重组 $\mathrm{DNA}$ 技术也是医学研究的重要平台技术，通过重组 $\mathrm{DNA}$ 技术构建的遗传修饰的各种模式生物已经成为人类疾病研究的重要模型；重组 $\mathrm{DNA}$ 技术也是基因及其功能研究的技术基础，包括基因打靶、基因组编辑、$\mathrm{RNA}$ 干扰及蛋白质相互作用等技术都是以重组 $\mathrm{DNA}$ 技术为基础。

:::definition{label="本章小结里的自然界重组与转移"}
$\mathrm{DNA}$ 重组：分子内或分子间遗传信息重新共价组合，类型为同源、位点特异、转座，广泛存在。原核还可以接合、转化、转导。噬菌体留下短序列组成 $\mathrm{CRISPR}$ 簇，是细菌防御病毒的获得性免疫。
:::

:::definition{label="本章小结里的重组 DNA 五步和工具酶"}
体外把不同来源的两个或两个以上 $\mathrm{DNA}$ 分子连起来，在适当细胞中扩增成新的功能分子。五步：获取目的 $\mathrm{DNA}$；选准备载体；连接；导入受体；筛选鉴定及克隆化。工具酶点名限制性核酸内切酶、$\mathrm{DNA}$ 连接酶。载体不同，则可克隆扩增或在原核／真核中表达。
:::

:::definition{label="本章小结里的目的基因、载体和筛选"}
目的基因：拟克隆的基因。获取：化学合成、基因组文库或 $\mathrm{cDNA}$ 文库钓取、$\mathrm{PCR}$。载体：携带目的基因在受体中复制或表达；克隆载体至少要有复制位点、单一／多克隆酶切位点、筛选标志；表达载体再加表达所需转录单位及元件，真核点名 $\mathrm{poly}(\mathrm{A})$ 加尾信号。筛选：遗传标志、序列特异、亲和。
:::

:::definition{label="本章小结里的表达体系"}
原核与真核各有优劣。常用原核：大肠埃希菌，操作简便，缺乏对产物的加工修饰。常用真核：酵母、昆虫、哺乳细胞。
:::

:::definition{label="本章小结里的三类医学应用"}
①基因工程制药：重组蛋白质、多肽、病毒或类病毒颗粒、人源化单抗。②医学研究平台：遗传修饰模式生物作为人类疾病模型。③基因及其功能研究的技术基础：打靶、基因组编辑、$\mathrm{RNAi}$、蛋白质相互作用。
:::

:::keypoint{label="本章小结按三节收口"}
- 第一节：同源／位点特异／转座；接合、转化、转导；$\mathrm{CRISPR}$ 获得性免疫。
- 第二节：五步；限制酶与连接酶；克隆载体三件套与表达元件；原核简便缺加工，真核有酵母／昆虫／哺乳类。
- 第三节：制药（含 $\mathrm{VLP}$、人源化抗体）；模式生物；打靶、编辑、$\mathrm{RNAi}$、双杂交。
:::

:::insight{label="小结把「转化」写回自然界基因转移，不要和第二节转化操作并句"}

## 思考题

1. 设想一下，生物体基因组 $\mathrm{DNA}$ 自发地频繁发生重组，无论是同源重组、位点特异性重组或转座重组，会对生物体产生哪些潜在的影响？
2. 生物体基因组可以摄取外源 $\mathrm{DNA}$ 留作己用（如细菌的 $\mathrm{CRISPR}$ 阵列），并进化成为自身的防御机制。请思考一下，细菌利用 $\mathrm{CRISPR}/\mathrm{Cas}$ 系统作为获得性免疫机制，人等哺乳动物是否也需要类似的机制？为什么？
3. 重组 $\mathrm{DNA}$ 技术为操作 $\mathrm{DNA}$ 提供了技术平台，如何优化重组 $\mathrm{DNA}$ 技术更精准有效进行 $\mathrm{DNA}$ 改变用于疾病的诊断和治疗？
4. 重组 $\mathrm{DNA}$ 技术的应用涉及伦理道德问题（如基因编辑、克隆等）、环境保护问题（如转基因作物的种植、生物修复等）以及科学研究问题（如疾病诊断和治疗等）等。请思考一下，$\mathrm{DNA}$ 重组技术会对人类社会和环境有哪些影响？

:::tip{label="四道思考题在正文里的户头"}
- 频繁自发重组：第一节三种重组都会改共价组合。同源重组可在减数分裂产生新组合，也可在体细胞（$\mathrm{BRCA}1/\mathrm{BRCA}2$ 缺陷时同源重组率下降、辐射敏感、易癌）。位点特异可整合、切除、倒位（鞭毛相、$\mathrm{V}$-(D)-$\mathrm{J}$）。转座可插入突变、抗性基因搬家。频繁失控：基因组不稳定、基因打断、调控紊乱、有害等位基因扩散；有控制的重组则是多样性和免疫的来源。
- 哺乳动物要不要 $\mathrm{CRISPR}$ 那样的获得性免疫：细菌把噬菌体片段插入阵列，再转录指导 $\mathrm{Cas}$ 切割再入侵的 $\mathrm{DNA}$。人等哺乳动物已有适应性免疫（抗体、$\mathrm{T}$ 细胞受体，$\mathrm{V}$-(D)-$\mathrm{J}$ 也是位点特异重组）和固有的核酸防御，并不等于必须再备一套 $\mathrm{CRISPR}$ 阵列。教材只把 $\mathrm{CRISPR}$ 写成细菌（及古细菌统计）的机制，并把基于 $\mathrm{CRISPR}$ 的遗传病治疗写成「正在谨慎推进」。答题不要断言「人绝对不需要」或「人已经有完全相同的 $\mathrm{CRISPR}$ 座」。
- 更精准的诊断和治疗：第二节把操作钉在限制酶特异切割、定向克隆、测序终判、工程细胞；第三节把临床钉在可调控表达、复制缺陷病毒、靶向 $\mathrm{CAR}$、脱靶最少的 $\mathrm{CRISPR}/\mathrm{Cas}9$、序列特异的 $\mathrm{siRNA}$。优化方向就在这些本版已经写出的约束里：识别序列更特异、筛选更靠序列而不是单抗性、编辑少脱靶、表达可调控、载体复制缺陷。不要另编教材没有的药名或仪器。
- 对社会和环境的影响：本版正文已写遗传修饰动物、改造蚊子、基因编辑治疗「谨慎推进」、人源化抗体和 $\mathrm{VLP}$ 疫苗。思考题额外点出伦理（基因编辑、克隆）、环境（转基因作物、生物修复）和科学研究（诊治）。答题应区分：制药和模式生物是第三节已落地的应用；作物种植、生物修复、生殖系编辑是思考题提出的开放问题，正文没有操作细节，不要写成「教材已经批准转基因作物」或「已经常规基因编辑婴儿」。
:::
