# 第一节　脑的生物化学

第二十七章写肝外器官和组织的代谢特点。本节只立「脑的生物化学」：人脑约占体重 $2\%$，每天约 $100\,\mathrm{g}$ 葡萄糖（约总葡萄糖 $25\%$），约总耗氧量 $20\%$；神经元消耗脑能量 $70\%\sim 80\%$。脑主要用葡萄糖和酮体，缺氧或缺糖会降脑功能；胶质与神经元有广泛代谢互动。谷胱甘肽合成协同、谷氨酸–谷氨酰胺循环、$\mathrm{GABA}$、儿茶酚胺是四户，不要并。糖脂代谢紊乱与阿尔茨海默病写在本节末。心肌交给第二节；肾、骨骼肌、脂肪组织是后三节的账。

:::concept{term="先问脑拿什么供能、胶质和神经元怎么分工，再问递质四户"}
看见「脑的生物化学」，先不要默写儿茶酚胺结构式。户头是：脑主要利用葡萄糖和酮体；葡萄糖或氧气供应不足会降低脑功能，最终导致死亡。神经元消耗脑能量的 $70\%\sim 80\%$，胶质细胞与神经元进行广泛的代谢互动。递质代谢里，谷胱甘肽合成协同不是谷氨酸–谷氨酰胺循环，后者也不是 $\mathrm{GABA}$，更不是儿茶酚胺。把「脑＝只吃糖」或「四条途径画成一张循环」写成开篇，后文酮体、肝性脑病和阿尔茨海默病都没有底板。
:::

人类脑需要计划复杂行为、作出决定以及处理应对情绪和社会环境的变化，有巨大的能量需求，是主要耗能器官之一。脑主要利用葡萄糖和酮体供能，神经元消耗了脑能量的 $70\%\sim 80\%$，胶质细胞与神经元进行了广泛的代谢互动。此外，脑还存在谷氨酸等神经递质特异代谢途径。糖脂代谢紊乱参与了阿尔茨海默病等神经退行性疾病的发生发展。

:::definition{label="脑是主要耗能器官之一"}
计划复杂行为、作出决定、处理情绪和社会环境变化，都要能量。本版开篇原句把脑写成主要耗能器官之一。户头先落在「耗能」和「葡萄糖＋酮体」，还不是「只靠糖原」或「只靠脂肪酸」。
:::

:::keypoint{label="开篇四句先钉死"}
- 燃料：主要利用葡萄糖和酮体。
- 细胞分工：神经元消耗脑能量的 $70\%\sim 80\%$；胶质与神经元广泛互动。
- 特异途径：谷氨酸等神经递质代谢。
- 疾病落点：糖脂代谢紊乱参与阿尔茨海默病等神经退行性疾病。
:::

:::pitfall{label="70%～80% 是细胞户，70% 用于信号转导是功能户"}
开篇「神经元消耗了脑能量的 $70\%\sim 80\%$」说的是细胞类型。后文「脑约 $70\%$ 的能量消耗主要应用于神经元信号转导」说的是用途。两笔都叫 $70\%$，不要并成一句「神经元信号转导用掉脑能量的 $70\%\sim 80\%$」。
:::

## 一、脑主要利用葡萄糖和酮体供能且耗氧量大

### （一）葡萄糖是脑主要的能量来源

脑的功能主要依靠葡萄糖的分解产生 $\mathrm{ATP}$ 和中间代谢物。葡萄糖或氧气供应不足会降低脑功能，最终导致死亡。人脑仅占体重的 $2\%$，但每天消耗约 $100\,\mathrm{g}$ 葡萄糖，约占总葡萄糖的 $25\%$，并消耗约 $20\%$ 的总耗氧量。

:::definition{label="人脑的体量与能耗"}
人脑约占体重的 $2\%$。每天约 $100\,\mathrm{g}$ 葡萄糖，约占总葡萄糖的 $25\%$；约总耗氧量的 $20\%$。户头是「体量小、份额大」，不是「脑重占体重四分之一」。
:::

:::keypoint{label="本版脑能耗四个数字"}
- 体重份额：$2\%$。
- 日耗葡萄糖：约 $100\,\mathrm{g}$。
- 占全身葡萄糖：$25\%$。
- 占全身耗氧：$20\%$。
:::

:::pitfall{label="不要用别的教材替换本版数字"}
有的书把脑重写成 $2\%\sim 3\%$，把日耗葡萄糖写成 $120\,\mathrm{g}$，把耗氧写成 $25\%$。本版是 $2\%$、$100\,\mathrm{g}$、$25\%$、$20\%$。神经元消耗脑能量 $70\%\sim 80\%$ 也按本版，不要改成「几乎全部」。
:::

:::cause-effect{title="缺糖或缺氧 → 脑功能下降 → 死亡"}
葡萄糖分解产生 $\mathrm{ATP}$ 和中间代谢物 → 维持离子梯度和突触传递 → 葡萄糖或氧气供应不足则脑功能降低，最终死亡。问「为什么低血糖会昏迷」走这一条，不要先跳到阿尔茨海默病。
:::

脑约 $70\%$ 的能量消耗主要应用于神经元信号转导，包括静息电位、动作电位、突触后受体、谷氨酸循环以及突触后 $\mathrm{Ca}^{2+}$ 信号。其余能量用于非信号生理功能，如蛋白质、磷脂和寡核苷酸的合成、轴突运输、线粒体质子外排、肌动蛋白细胞骨架重塑等。其中，$\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-$\mathrm{ATPase}$ 等离子泵在神经元和胶质细胞中表达，消耗 $\mathrm{ATP}$ 来维持质膜离子梯度以调控细胞的兴奋性，占到约 $50\%$ 葡萄糖氧化所产生的能量。其中兴奋性神经元消耗约 $80\%\sim 85\%$ 的 $\mathrm{ATP}$，抑制性神经元和神经胶质细胞利用 $15\%\sim 20\%$ 的 $\mathrm{ATP}$。此外，脑的不同区域消耗能量也不同：灰质包含更多神经元，能量消耗远高于白质，而白质的非信号能量需求高于灰质。

:::definition{label="信号转导用能与非信号用能"}
约 $70\%$ 用于神经元信号转导：静息电位、动作电位、突触后受体、谷氨酸循环、突触后 $\mathrm{Ca}^{2+}$ 信号。其余用于蛋白质／磷脂／寡核苷酸合成、轴突运输、线粒体质子外排、肌动蛋白细胞骨架重塑。谷氨酸循环在这里是「耗能项目」，展开机制是后文图27-2 那一户。
:::

:::definition{label="Na+-K+-ATPase 约占葡萄糖氧化产能的一半"}
$\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-$\mathrm{ATPase}$ 等离子泵在神经元和胶质细胞中都表达，靠消耗 $\mathrm{ATP}$ 维持质膜离子梯度、调控兴奋性，约占葡萄糖氧化所产生能量的 $50\%$。户头是「离子泵」，不是「只有神经元才有钠钾泵」。
:::

:::compare{title="三套能量分割不要并成一笔"}
| 尺子 | 本版数字 | 问的是什么 | 不要写成 |
|------|---------|-----------|---------|
| 细胞类型 | 神经元 $70\%\sim 80\%$，其余主要在胶质 | 谁在用 | 「胶质几乎不用能量」 |
| 用途 | 约 $70\%$ 信号转导，其余非信号 | 用来干什么 | 「$70\%$ 全部给钠钾泵」 |
| 葡萄糖氧化产能 | 离子泵约 $50\%$；兴奋性神经元约 $80\%\sim 85\%$ 的 $\mathrm{ATP}$，抑制性神经元＋胶质 $15\%\sim 20\%$ | 泵和兴奋／抑制怎么分 | 「兴奋性神经元消耗脑能量的 $80\%\sim 85\%$」——那是 $\mathrm{ATP}$ 份额，不是体重份额 |

灰质神经元多，总耗能远高于白质；白质的非信号能量需求反而高于灰质。区域差和细胞差是两本账。
:::

:::insight{label="白质不是「不用能量」"}
教材特意写：白质的非信号能量需求高于灰质。髓鞘维持、少突胶质细胞的脂质更新都算非信号。把白质写成「惰性电缆」，后文脑脂质占干重超过 $50\%$ 就没有着落。
:::

葡萄糖转运蛋白（glucose transporters，$\mathrm{GLUT}$）转运葡萄糖进入细胞，$\mathrm{GLUT1}$ 和 $\mathrm{GLUT3}$ 是脑主要的葡萄糖转运蛋白。由于糖基化程度不同，$\mathrm{GLUT1}$ 有 $45\,\mathrm{kDa}$ 和 $55\,\mathrm{kDa}$ 两种分子量形式。$55\,\mathrm{kDa}$ 形式的 $\mathrm{GLUT1}$ 主要定位于脑微血管、脉络丛和室管膜细胞中，转运循环中的葡萄糖到脑实质。$45\,\mathrm{kDa}$ 的 $\mathrm{GLUT1}$ 主要定位在星形胶质细胞和其他神经胶质细胞中。$\mathrm{GLUT3}$ 和胰岛素敏感的 $\mathrm{GLUT4}$ 是神经元的特异性葡萄糖转运蛋白。$\mathrm{GLUT2}$ 在下丘脑和脑干神经核等区域的神经元和星形胶质细胞中表达，可以「感知」葡萄糖水平并参与进食行为的调节和胰岛素释放。$\mathrm{GLUT5}$ 定位于小胶质细胞，参与神经系统的免疫和炎症反应。

:::definition{label="脑主要的葡萄糖转运蛋白是 GLUT1 和 GLUT3"}
$\mathrm{GLUT1}$ 和 $\mathrm{GLUT3}$ 是脑主要的葡萄糖转运蛋白。$\mathrm{GLUT4}$、$\mathrm{GLUT2}$、$\mathrm{GLUT5}$ 各有职分，不要把五户都写成「主要」。
:::

:::definition{label="GLUT1 的两种分子量"}
糖基化程度不同，分成 $45\,\mathrm{kDa}$ 和 $55\,\mathrm{kDa}$。$55\,\mathrm{kDa}$：脑微血管、脉络丛、室管膜，把循环葡萄糖运进脑实质。$45\,\mathrm{kDa}$：星形胶质细胞和其他神经胶质细胞。同一基因产物，定位和糖基化不同，不要写成两种蛋白。
:::

:::definition{label="GLUT3 和 GLUT4"}
二者都是神经元特异性葡萄糖转运蛋白。$\mathrm{GLUT4}$ 还写明「胰岛素敏感」。后文阿尔茨海默病胰岛素抵抗会再碰到 $\mathrm{GLUT}$ 表达下降，底板在这里。
:::

:::definition{label="GLUT2 感知葡萄糖"}
在下丘脑和脑干神经核等区域的神经元和星形胶质细胞中表达，感知葡萄糖水平，参与进食行为调节和胰岛素释放。户头是「感知」，不是「把循环葡萄糖大批运进大脑皮层」。
:::

:::definition{label="GLUT5 在小胶质细胞"}
定位于小胶质细胞，参与神经系统的免疫和炎症反应。不要把 $\mathrm{GLUT5}$ 写成神经元的主转运体。
:::

:::compare{title="脑内 GLUT 五户"}
| | 主要定位 | 职分 | 不要写成 |
|--|---------|------|---------|
| $\mathrm{GLUT1}$（$55\,\mathrm{kDa}$） | 脑微血管、脉络丛、室管膜 | 循环葡萄糖 → 脑实质 | 「胶质细胞自己的 GLUT」 |
| $\mathrm{GLUT1}$（$45\,\mathrm{kDa}$） | 星形胶质细胞和其他胶质 | 胶质摄取葡萄糖 | 「血脑屏障那一户」 |
| $\mathrm{GLUT3}$ | 神经元 | 神经元主转运之一 | 「胰岛素敏感」——那是 $\mathrm{GLUT4}$ |
| $\mathrm{GLUT4}$ | 神经元 | 胰岛素敏感 | 「脑不表达 GLUT4」 |
| $\mathrm{GLUT2}$ | 下丘脑、脑干神经核的神经元和星形胶质细胞 | 感知葡萄糖、进食、胰岛素释放 | 「全脑普遍的主转运」 |
| $\mathrm{GLUT5}$ | 小胶质细胞 | 免疫和炎症 | 「神经元供能」 |

问「葡萄糖怎么进脑」先答 $55\,\mathrm{kDa}$ $\mathrm{GLUT1}$；问「神经元怎么吃糖」再答 $\mathrm{GLUT3}$／$\mathrm{GLUT4}$。
:::

:::pitfall{label="GLUT2 不要写成肝的专户就结束"}
第二十五章肝用 $\mathrm{GLUT2}$ 让肝细胞内葡萄糖跟着血糖走。本节 $\mathrm{GLUT2}$ 在下丘脑和脑干，职分是感知和进食调节。器官不同、职分不同，不要并成「$\mathrm{GLUT2}$ 只在肝」。
:::

葡萄糖进入细胞后通过糖酵解和三羧酸循环进行分解并产生 $\mathrm{ATP}$。糖酵解产生的胞质 $\mathrm{NADH}$ 通过苹果酸–天冬氨酸穿梭转移到线粒体，$\mathrm{NAD}^{+}$ 也通过苹果酸–天冬氨酸穿梭或乳酸脱氢酶催化再生。在缺氧或线粒体受损情况下，糖酵解速率超过苹果酸–天冬氨酸穿梭能力或三羧酸循环速率时会产生乳酸。乳酸胞内积累导致低水平 $\mathrm{NAD}^{+}$，最终抑制糖酵解途径。乳酸可通过单羧酸转运蛋白（monocarboxylate transporters，$\mathrm{MCTs}$）释放到胞外。

:::definition{label="脑内葡萄糖氧化的主路"}
糖酵解＋三羧酸循环产生 $\mathrm{ATP}$。胞质 $\mathrm{NADH}$ 经苹果酸–天冬氨酸穿梭进线粒体；$\mathrm{NAD}^{+}$ 经同一穿梭或乳酸脱氢酶再生。
:::

:::definition{label="缺氧时脑产乳酸"}
缺氧或线粒体受损，糖酵解超过穿梭或三羧酸循环能力，产生乳酸。乳酸在胞内积累压低 $\mathrm{NAD}^{+}$，反过来抑制糖酵解。出口是 $\mathrm{MCT}$ 把乳酸放到胞外。
:::

:::pitfall{label="脑产乳酸不是「脑靠无氧酵解过日子」"}
正常主路是有氧氧化。乳酸是缺氧、线粒体受损或糖酵解过快时的溢出。后文「基础条件下乳酸可占脑能量 $8\%\sim 10\%$」说的是血乳酸被脑吸收氧化，和这一句「自己产乳酸」不是同一户。
:::

:::insight{label="MCT 在脑和心肌都会再出现"}
本节 $\mathrm{MCT}$ 先当乳酸出口；后文酮体、乳酸、丙酮酸进神经细胞也走单羧酸转运蛋白。第二节心肌摄取乳酸同样点名 $\mathrm{MCT}$。名字相同，组织不同，不要并成一张图。
:::

### （二）脑的葡萄糖代谢存在能量供给外的功能

葡萄糖的分解不仅为脑提供能量支持，同时其中间代谢产物可用于合成生糖氨基酸（丝氨酸、甘氨酸、丙氨酸和谷氨酰胺）、神经递质和神经调节剂（谷氨酸、$\gamma$-氨基丁酸、天冬氨酸、$\mathrm{D}$-丝氨酸、甘氨酸和乙酰胆碱），糖脂和糖蛋白中的糖组分，细胞膜和磷脂的脂肪酸组分、胆固醇等其他脂质以及核酸等，为脑结构、功能和可塑性提供物质基础。葡萄糖的戊糖磷酸途径等分支代谢途径还参与防御氧化应激和有毒物的损伤。

:::definition{label="葡萄糖中间物的合成用途"}
生糖氨基酸：丝氨酸、甘氨酸、丙氨酸、谷氨酰胺。神经递质和神经调节剂：谷氨酸、$\mathrm{GABA}$、天冬氨酸、$\mathrm{D}$-丝氨酸、甘氨酸、乙酰胆碱。还有糖脂／糖蛋白的糖组分，膜磷脂的脂肪酸、胆固醇等脂质，以及核酸。户头是「中间物也是原料」，不是「葡萄糖只产 $\mathrm{ATP}$」。
:::

:::keypoint{label="能量账和原料账同时立"}
- 能量：糖酵解、三羧酸循环、氧化磷酸化。
- 原料：氨基酸、递质、糖链、脂质、核酸。
- 防护：戊糖磷酸途径的 $\mathrm{NADPH}$ 和还原型谷胱甘肽。
:::

戊糖磷酸途径的产物 $\mathrm{NADPH}$ 以及还原型的谷胱甘肽（$\mathrm{GSH}$）可对抗活性氧（$\mathrm{ROS}$）产生的氧化应激损伤。呼吸链的电子传递等生理活动产生超氧阴离子，单胺氧化酶（monoamine oxidase，$\mathrm{MAO}$）在 $5$-羟色胺、多巴胺和去甲肾上腺素（norepinephrine，$\mathrm{NE}$）等生物胺类神经递质代谢过程中产生 $\mathrm{H_2O_2}$。超氧化物歧化酶（superoxide dismutase，$\mathrm{SOD}$）转化超氧阴离子为 $\mathrm{H_2O_2}$ 后，谷胱甘肽过氧化物酶（glutathione peroxidase，$\mathrm{GSH}$-$\mathrm{Px}$）催化 $\mathrm{H_2O_2}$ 生成 $\mathrm{H_2O}$ 和 $\mathrm{O_2}$。和星形胶质细胞比较，神经元的谷胱甘肽水平和戊糖磷酸途径活性较低，更容易受到氧化应激的损伤。星形胶质细胞协同调控神经元谷胱甘肽的合成代谢，抵抗氧化应激损伤（图27-1）。这种协同作用受损参与神经退行性疾病进展，例如家族性肌萎缩侧索硬化症是由 $\mathrm{SOD}$ 突变引起的，帕金森病患者的黑质神经元中的谷胱甘肽含量减少。

:::definition{label="NADPH 和 GSH 对抗氧化应激"}
戊糖磷酸途径提供 $\mathrm{NADPH}$，还原型谷胱甘肽直接对抗 $\mathrm{ROS}$。呼吸链出超氧阴离子；$\mathrm{MAO}$ 代谢 $5$-羟色胺、多巴胺、去甲肾上腺素时出 $\mathrm{H_2O_2}$。
:::

:::definition{label="SOD 与 GSH-Px 的接力"}
$\mathrm{SOD}$：超氧阴离子 → $\mathrm{H_2O_2}$。$\mathrm{GSH}$-$\mathrm{Px}$：$\mathrm{H_2O_2}$ → $\mathrm{H_2O}$ 和 $\mathrm{O_2}$。两步不要并成「$\mathrm{SOD}$ 直接把超氧变成水」。
:::

:::definition{label="神经元比星形胶质细胞更怕氧化应激"}
神经元的谷胱甘肽水平和戊糖磷酸途径活性较低，更容易受伤。抵抗要靠星形胶质细胞协同调控神经元的谷胱甘肽合成（图27-1）。
:::

:::compare{title="ROS 两处来源"}
| 来源 | 产物 | 后文落点 |
|------|------|---------|
| 呼吸链电子传递 | 超氧阴离子 | $\mathrm{SOD}$ → $\mathrm{H_2O_2}$ |
| $\mathrm{MAO}$ 代谢生物胺（$5$-$\mathrm{HT}$、多巴胺、$\mathrm{NE}$） | $\mathrm{H_2O_2}$ | $\mathrm{GSH}$-$\mathrm{Px}$ 用 $\mathrm{GSH}$ 清除 |

问「为什么递质代谢也氧化应激」走 $\mathrm{MAO}$ 这一户，不要只答线粒体。
:::

:::pitfall{label="家族性 ALS 的 SOD 突变不要写成「帕金森病」"}
本版两条例：家族性肌萎缩侧索硬化症由 $\mathrm{SOD}$ 突变引起；帕金森病患者黑质神经元谷胱甘肽减少。疾病、分子、脑区三套标签不要对调。
:::

::figure{src="/images/biochemistry/textbook/p0522_01.png" caption="图27-1　星形胶质细胞协同神经元的谷胱甘肽合成" alt="左侧黑色轮廓为星形胶质细胞，右侧蓝色轮廓为神经元。星形胶质细胞摄取谷氨酸、胱氨酸、甘氨酸，合成还原型谷胱甘肽后释放到胞外；膜结合γ-谷氨酰转肽酶裂解胞外谷胱甘肽，释放半胱氨酰甘氨酸。神经元摄取半胱氨酰甘氨酸，经氨基肽酶N得到半胱氨酸和甘氨酸；另从星形胶质细胞接受谷氨酰胺，经谷氨酰胺酶得谷氨酸，再经γ-GluCys合酶和谷胱甘肽合酶合成还原型谷胱甘肽。实心灰框代表转运体。"}

:::insight{label="图27-1 先认左胶质、右神经元，灰框是转运体"}
画面左侧是星形胶质细胞：谷氨酸可转为谷氨酰胺；胱氨酸／半胱氨酸和甘氨酸参与合成还原型谷胱甘肽；还原型谷胱甘肽出胞。膜上 $\gamma$-谷氨酰转肽酶把胞外谷胱甘肽切成半胱氨酰甘氨酸，并释放 $\gamma$-谷氨酰-$\mathrm{X}$。右侧是神经元：谷氨酰胺进细胞后被谷氨酰胺酶水解成谷氨酸；半胱氨酰甘氨酸被氨基肽酶 $\mathrm{N}$ 切成半胱氨酸和甘氨酸；$\gamma$-$\mathrm{GluCys}$ 合酶把谷氨酸和半胱氨酸缩成 $\gamma$-谷氨酰半胱氨酸，谷胱甘肽合酶再加甘氨酸，得到神经元自己的还原型谷胱甘肽。实心框是转运体。这张图的户头是「谷胱甘肽前体怎么交接」，不是突触谷氨酸的清除再生。
:::

:::definition{label="神经元不能直接摄取 GSH"}
星形胶质细胞把合成的 $\mathrm{GSH}$ 释放到胞外，但神经元不能直接摄取 $\mathrm{GSH}$。必须先经膜结合 $\gamma$-谷氨酰转肽酶（$\gamma$-$\mathrm{GT}$）裂解，释放二肽 $\mathrm{CysGly}$；神经元摄取该二肽后，经氨基肽酶 $\mathrm{N}$（aminopeptidase $\mathrm{N}$，$\mathrm{APN}$）裂解为半胱氨酸和甘氨酸。
:::

:::definition{label="神经元 GSH 的第三个前体来自谷氨酰胺"}
星形胶质细胞还转运谷氨酰胺给神经元。神经元内谷氨酰胺酶把谷氨酰胺变成谷氨酸，$\gamma$-$\mathrm{GluCys}$ 合酶将谷氨酸和半胱氨酸缩合成 $\gamma$-$\mathrm{GluCys}$，谷胱甘肽合酶再把甘氨酸加上去，生成 $\mathrm{GSH}$。
:::

:::timeline{period="星形胶质细胞协同神经元合成 GSH 的顺序"}
- **星形胶质细胞** 用半胱氨酸、甘氨酸、谷氨酸合成 GSH 并释放到胞外
- **膜结合 γ-GT** 裂解胞外 GSH，释放二肽 CysGly
- **神经元摄取 CysGly** 经氨基肽酶 N 得到半胱氨酸和甘氨酸
- **胶质转运谷氨酰胺** 神经元谷氨酰胺酶产生谷氨酸
- **γ-GluCys 合酶 + 谷胱甘肽合酶** 神经元自己完成 GSH
:::

:::pitfall{label="图27-1 不是图27-2"}
图27-1 的谷氨酰胺箭头是给神经元合成谷胱甘肽提供谷氨酸前体。图27-2 的谷氨酰胺箭头是把突触间隙的谷氨酸回收再生成神经递质。两张图都出现「谷氨酸／谷氨酰胺／星形胶质细胞／神经元」，户头完全不同。不要两图共用同一张插图，也不要把协同合成 $\mathrm{GSH}$ 写成谷氨酸–谷氨酰胺循环。
:::

$\mathrm{NADPH}$ 和 $\mathrm{GSH}$ 也参与代谢过程中生成的甲基乙二醛、乙二醛和甲醛等有毒物的清除。甲基乙二醛和乙二醛是糖酵解的副产物，由甘油醛-$3$-磷酸和磷酸二羟丙酮自发生成，丙糖磷酸异构酶（triose phosphate isomerase，$\mathrm{TIM}$）加速这个过程。甲基乙二醛也可由丝氨酸和苏氨酸的分解以及脂质过氧化产生。高糖膳食、高血糖和摄入大量果糖后，增加组织甲基乙二醛的水平，并与蛋白质中的氨基酸残基形成亚胺化合物，通过缓慢的非酶催化的糖基化修饰，形成糖和蛋白质结合物即晚期糖基化终末产物（advanced glycation end products，$\mathrm{AGEs}$）。$\mathrm{AGEs}$ 与相邻蛋白质的氨基酸残基发生共价键交联，$\mathrm{AGEs}$ 及其蛋白质交联产物抵抗蛋白酶水解，非常稳定且不可逆转，加速衰老并参与糖尿病、阿尔茨海默病（Alzheimer disease，$\mathrm{AD}$）、动脉粥样硬化等慢性退化性疾病。神经元和星形胶质细胞中具有活跃的乙二醛酶系统，可利用 $\mathrm{GSH}$ 清除甲基乙二醛和乙二醛的毒性。

:::definition{label="甲基乙二醛和乙二醛"}
糖酵解副产物，由甘油醛-$3$-磷酸和磷酸二羟丙酮自发生成；$\mathrm{TIM}$ 加速这一过程。也可来自丝氨酸、苏氨酸分解和脂质过氧化。高糖膳食、高血糖、大量果糖使组织甲基乙二醛升高。
:::

:::definition{label="晚期糖基化终末产物 AGEs"}
甲基乙二醛等与蛋白质氨基酸残基形成亚胺，经缓慢非酶糖基化得到糖–蛋白质结合物，即 $\mathrm{AGEs}$。再与相邻蛋白质共价交联，抵抗蛋白酶水解，稳定且不可逆，加速衰老，参与糖尿病、阿尔茨海默病、动脉粥样硬化。
:::

:::definition{label="乙二醛酶系统"}
神经元和星形胶质细胞中活跃，利用 $\mathrm{GSH}$ 清除甲基乙二醛和乙二醛的毒性。$\mathrm{GSH}$ 在这里是解毒辅因子，不是神经递质。
:::

:::cause-effect{title="高糖 → 甲基乙二醛 → AGEs → 不可逆交联"}
高糖膳食／高血糖／大量果糖 → 甲基乙二醛升高 → 与蛋白质成亚胺 → 非酶糖基化成 $\mathrm{AGEs}$ → 蛋白质交联、抗水解、不可逆 → 衰老及糖尿病、阿尔茨海默病、动脉粥样硬化。后文阿尔茨海默病的糖代谢段会再碰到这一户。
:::

:::pitfall{label="TIM 加速的是副产物生成，不是「TIM 的生理功能就是产毒」"}
丙糖磷酸异构酶本职是糖酵解里磷酸二羟丙酮和甘油醛-$3$-磷酸互变。教材写它「加速」自发形成甲基乙二醛。写成「$\mathrm{TIM}$ 是毒素合酶」，糖酵解主路就讲反了。
:::

此外，$\mathrm{NADPH}$ 还用于参与一氧化氮合酶、细胞色素 $\mathrm{P}450$ 还原酶、醛还原酶（aldehyde reductase）和醛糖还原酶（aldose reductase）催化的反应。由于醛糖还原酶对葡萄糖的 $K_{\mathrm{m}}$ 高（$70\sim 200\,\mathrm{mmol/L}$），正常脑中的山梨醇合成水平非常低。在糖尿病引起葡萄糖水平升高时，$\mathrm{NADPH}$ 参与醛糖还原酶催化葡萄糖生成山梨醇的过程，促进白内障和糖尿病并发症的进展。

:::definition{label="NADPH 的其他去路"}
一氧化氮合酶、细胞色素 $\mathrm{P}450$ 还原酶、醛还原酶、醛糖还原酶。戊糖磷酸途径的 $\mathrm{NADPH}$ 不是只给谷胱甘肽再生。
:::

:::definition{label="醛糖还原酶的高 Km"}
对葡萄糖 $K_{\mathrm{m}}$ 为 $70\sim 200\,\mathrm{mmol/L}$，正常脑山梨醇合成非常低。血糖升高后才大量把葡萄糖还原成山梨醇，促进白内障和糖尿病并发症。
:::

:::pitfall{label="正常脑几乎不靠山梨醇途径处理葡萄糖"}
$K_{\mathrm{m}}$ 远高于生理血糖。写成「脑靠醛糖还原酶代谢葡萄糖」，主路糖酵解就被换掉了。糖尿病时这条支路才抬头，而且是并发症方向。
:::

### （三）特殊情况下脑可以利用酮体、乳酸供能

在特殊情况下脑也可以利用酮体、乳酸、丙酮酸、谷氨酸和谷氨酰胺等作为葡萄糖的补充能源。母乳喂养的新生儿除葡萄糖外，还能利用酮体，包括乙酰乙酸和 $\beta$-羟丁酸。新生儿断奶前后脑能量利用的差异与能量物质供给差异有关，能量物质转运和代谢酶水平也相应发生变化。母乳富含脂质有助于合成髓鞘和细胞膜的磷脂、胆固醇等组分。脂质约占母乳总热量的 $55\%$，而断乳后的膳食脂质只占总热量的 $30\%\sim 35\%$。母乳喂养时脑脉管系统中单羧酸转运蛋白的水平以及脑 $\beta$-羟丁酸脱氢酶活性显著增加，而断乳后这些酶活性下降的同时丙酮酸脱氢酶复合体活性增加。在成人，长时间禁食或饥饿以及未受控制的糖尿病情况下，葡萄糖来源和利用度不足，脂质分解代谢增强而导致血浆酮体升高。此时上述母乳喂养新生儿的适应性机制开始发挥作用，脑重新利用酮体供能。

:::definition{label="脑的补充能源"}
特殊情况下可用酮体、乳酸、丙酮酸、谷氨酸和谷氨酰胺补充葡萄糖。户头是「补充」，不是「平时首选脂肪酸」。
:::

:::definition{label="新生儿脑可利用酮体"}
母乳喂养的新生儿除葡萄糖外还能用乙酰乙酸和 $\beta$-羟丁酸。母乳脂质约占总热量 $55\%$（断乳后膳食脂质 $30\%\sim 35\%$），有助于合成髓鞘和膜磷脂、胆固醇。此时脑脉管系统 $\mathrm{MCT}$ 水平和脑 $\beta$-羟丁酸脱氢酶活性显著增加。
:::

:::definition{label="断乳后酶谱切换"}
断乳后 $\mathrm{MCT}$ 和 $\beta$-羟丁酸脱氢酶活性下降，同时丙酮酸脱氢酶复合体活性增加。燃料从「糖＋酮体」偏向「更依赖葡萄糖氧化」。
:::

:::definition{label="成人饥饿或未控制糖尿病时脑重新用酮体"}
长时间禁食、饥饿或未受控制的糖尿病：葡萄糖来源和利用度不足，脂解增强，血浆酮体升高，新生儿那套适应性机制再启用，脑重新利用酮体供能。
:::

:::compare{title="新生儿 vs 断乳后 vs 成人饥饿"}
| | 主要补充燃料 | 转运／酶 | 不要写成 |
|--|------------|---------|---------|
| 母乳喂养新生儿 | 葡萄糖＋酮体（乙酰乙酸、$\beta$-羟丁酸） | $\mathrm{MCT}$、$\beta$-羟丁酸脱氢酶高 | 「新生儿脑不用葡萄糖」 |
| 断乳后 | 更依赖葡萄糖氧化 | 上述酶下降，$\mathrm{PDH}$ 复合体上升 | 「断乳后脑改吃脂肪酸」 |
| 成人长期禁食／未控制糖尿病 | 血浆酮体升高，脑再启用酮体 | 回到新生儿那套适应 | 「成人脑永远不能用酮体」 |

问「脑能不能用酮体」——能，但是特殊情况；平时主燃料仍是葡萄糖。
:::

:::pitfall{label="不要把脑写成「代谢杂食者」"}
「代谢杂食者」是第二节给成人心肌的名字。脑在特殊情况下才动用酮体、乳酸等补充能源，平时仍以葡萄糖为主。把两节开篇对调，后文心肌脂肪酸 $40\%\sim 60\%$ 和脑日耗 $100\,\mathrm{g}$ 葡萄糖都会对不上。
:::

乳酸和丙酮酸也是脑中的替代能量来源，通过专门的单羧酸转运蛋白进入神经细胞，并通过三羧酸循环和氧化磷酸化在线粒体中产生 $\mathrm{ATP}$。在基础条件下（血浆乳酸约 $1.0\,\mathrm{mmol/L}$），乳酸可被脑吸收并完全氧化，占其能量需求的 $8\%\sim 10\%$。而在中度至剧烈运动期间，血乳酸浓度可上升至 $10\,\mathrm{mmol/L}$，脑部乳酸供能可达脑总能量需求的 $20\%\sim 25\%$。

:::definition{label="乳酸和丙酮酸经 MCT 进神经细胞"}
经单羧酸转运蛋白进入，在线粒体经三羧酸循环和氧化磷酸化产 $\mathrm{ATP}$。基础血浆乳酸约 $1.0\,\mathrm{mmol/L}$ 时，乳酸占脑能量需求的 $8\%\sim 10\%$；中度至剧烈运动血乳酸可至 $10\,\mathrm{mmol/L}$，乳酸供能可达 $20\%\sim 25\%$。
:::

:::compare{title="脑用乳酸的两种情境"}
| | 血浆乳酸 | 占脑能量 | 来源提醒 |
|--|---------|---------|---------|
| 基础条件 | 约 $1.0\,\mathrm{mmol/L}$ | $8\%\sim 10\%$ | 吸收并完全氧化 |
| 中度至剧烈运动 | 可至 $10\,\mathrm{mmol/L}$ | $20\%\sim 25\%$ | 血乳酸升高；不是「脑自己无氧酵解供能 $25\%$」 |

运动时血乳酸主要来自骨骼肌，第四节才展开骨骼肌运动供能。本节只记脑侧能吃多少。
:::

:::pitfall{label="20%～25% 是运动时乳酸占脑能量，不是脑占全身耗氧"}
开篇脑约占总耗氧量 $20\%$，这里运动时乳酸可占脑总能量 $20\%\sim 25\%$。两笔 $20\%$ 问的不是同一件事。
:::

此外，脑也可以分解脂肪酸和氨基酸作为能量来源，但是与葡萄糖相比，对整体脑能量代谢的贡献很小。在人的脑组织中，存在有限的糖原储备，与肝和骨骼肌的糖原含量相比，脑中的糖原浓度非常低，主要存储在星形胶质细胞中。

:::definition{label="脑内脂肪酸和氨基酸供能贡献很小"}
可以分解，但与葡萄糖相比对整体脑能量代谢贡献很小。不要把「能分解」写成「主要燃料」。
:::

:::definition{label="脑糖原主要在星形胶质细胞"}
人脑糖原储备有限，浓度远低于肝和骨骼肌，主要存在星形胶质细胞。神经元不是脑糖原的大仓库。
:::

:::compare{title="脑 vs 肝 vs 骨骼肌的糖原"}
| | 糖原浓度／角色 | 本节用这句话做什么 |
|--|---------------|------------------|
| 肝 | 高，维持血糖 | 第二十五章；本节只对比「脑低」 |
| 骨骼肌 | 高，供自身收缩 | 第四节；本节不写运动供能曲线 |
| 脑 | 非常低，主要在星形胶质细胞 | 解释为什么缺糖会迅速降脑功能 |

问「低血糖为什么先伤脑」——储备少、日常又高度依赖葡萄糖。
:::

## 二、脑存在特殊的神经递质代谢途径

神经递质是神经元之间或神经元与效应器细胞之间传递信息的化学物质。神经递质主要有胆碱类（乙酰胆碱）、单胺类（去甲肾上腺素、多巴胺和 $5$-羟色胺）、氨基酸类（兴奋性递质如谷氨酸和天冬氨酸，抑制性递质如 $\mathrm{GABA}$、甘氨酸和牛磺酸）和神经肽类等。不同于其他组织，脑存在高水平的神经递质代谢途径。

:::definition{label="神经递质"}
神经元之间或神经元与效应器细胞之间传递信息的化学物质。本版四类：胆碱类、单胺类、氨基酸类、神经肽类。
:::

:::compare{title="本版神经递质分类"}
| 类 | 例子 | 后文落点 |
|--|------|---------|
| 胆碱类 | 乙酰胆碱 | $\mathrm{ChAT}$／$\mathrm{AChE}$；乙酰基来自葡萄糖 |
| 单胺类 | 去甲肾上腺素、多巴胺、$5$-羟色胺 | 图27-4；$\mathrm{MAO}$；色氨酸来源 |
| 氨基酸类（兴奋） | 谷氨酸、天冬氨酸 | 图27-2 谷氨酸–谷氨酰胺循环 |
| 氨基酸类（抑制） | $\mathrm{GABA}$、甘氨酸、牛磺酸 | 图27-3 $\mathrm{GABA}$ |
| 神经肽类 | （开篇点名） | 本节不展开结构 |

四类先立住，再进循环和合成降解。不要一上来只默写多巴胺。
:::

### （一）谷氨酸–谷氨酰胺循环参与脑谷氨酸的清除和再生过程

突触释放神经递质及其随后的递质清除是神经元之间信号传递的关键步骤。以兴奋性神经递质谷氨酸为例，细胞外间隙的谷氨酸水平很低（$<3\,\mu\mathrm{mol/L}$），谷氨酸释放突触局部浓度可达 $1\sim 10\,\mathrm{mmol/L}$。星形胶质细胞等通过兴奋性氨基酸转运蛋白（excitatory amino acid transporter，$\mathrm{EAAT}$）可迅速摄取清除胞外的谷氨酸。$\mathrm{EAAT}$ 至少有五种亚型参与兴奋性神经递质的摄取：$\mathrm{EAAT}$-$1$ 和 $\mathrm{EAAT}$-$2$ 亚型仅表达于星形胶质细胞，$\mathrm{EAAT}$-$3$ 和 $\mathrm{EAAT}$-$4$ 主要定位于神经元，而 $\mathrm{EAAT}$-$5$ 在视杆细胞和视网膜双极细胞中表达。

:::definition{label="突触谷氨酸的浓度差"}
细胞外间隙 $<3\,\mu\mathrm{mol/L}$，释放突触局部可达 $1\sim 10\,\mathrm{mmol/L}$。数量级差约 $10^{3}$。清除不及时就会过度激活突触后神经元。
:::

:::definition{label="EAAT 五亚型"}
兴奋性氨基酸转运蛋白，迅速摄取胞外谷氨酸。$\mathrm{EAAT}$-$1$、$\mathrm{EAAT}$-$2$ 仅在星形胶质细胞；$\mathrm{EAAT}$-$3$、$\mathrm{EAAT}$-$4$ 主要在神经元；$\mathrm{EAAT}$-$5$ 在视杆细胞和视网膜双极细胞。
:::

:::pitfall{label="EAAT-1/2 不要写成神经元的主摄取体"}
胶质这一户才是「仅表达」。写成「五种 EAAT 都在神经元」，星形胶质细胞清除突触谷氨酸的故事就断了。
:::

神经元和星形胶质细胞之间的谷氨酸–谷氨酰胺循环（glutamate-glutamine cycle）（图27-2）参与了神经递质谷氨酸的清除和再生过程。神经元释放的谷氨酸完成其生理功能后，星形胶质细胞通过 $\mathrm{EAAT}$ 摄取突触间隙的谷氨酸，由星形胶质细胞特异的谷氨酰胺合成酶（glutamine synthetase，$\mathrm{GS}$）消耗 $\mathrm{ATP}$ 并生成谷氨酰胺。此后，谷氨酰胺由星形胶质细胞释放并被神经元重新摄取。在神经元谷氨酰胺酶作用下，谷氨酰胺水解重新生成谷氨酸，循环再生神经元代谢池中的谷氨酸。

:::note{label="电子版缺失"}
图27-2　星形胶质细胞和神经元之间的谷氨酸–谷氨酰胺循环。电子版缺失，正文保留图号，不嵌入空图。画面应分星形胶质细胞与神经元两室：胶质用 $\mathrm{EAAT}$ 摄取谷氨酸、$\mathrm{GS}$ 耗 $\mathrm{ATP}$ 成谷氨酰胺；神经元用谷氨酰胺酶把谷氨酰胺变回谷氨酸。不要用图27-1 的谷胱甘肽合成图顶替。
:::

:::definition{label="谷氨酸-谷氨酰胺循环"}
神经元释放谷氨酸 → 星形胶质细胞 $\mathrm{EAAT}$ 摄取 → 胶质特异的 $\mathrm{GS}$ 耗 $\mathrm{ATP}$ 生成谷氨酰胺 → 谷氨酰胺释放并被神经元摄取 → 神经元谷氨酰胺酶水解再生成谷氨酸。户头是神经递质谷氨酸的清除和再生，不是谷胱甘肽。
:::

:::definition{label="谷氨酰胺合成酶 GS 是星形胶质细胞特异的"}
消耗 $\mathrm{ATP}$ 把谷氨酸加成谷氨酰胺。神经元侧对应的是谷氨酰胺酶，不是 $\mathrm{GS}$。两酶不要写在同一细胞里对打。
:::

谷氨酸–谷氨酰胺循环及时清除突触间隙中的谷氨酸，防止突触后神经元过度激活所产生的神经毒性，同时转运回神经元的谷氨酰胺可以进一步氧化分解生成 $\mathrm{ATP}$ 为神经元提供能量。循环同时也是缓冲脑氨过高的机制。在肝病患者中，肝对肠道细菌产生的氨的清除受到严重损害，血氨升高引起的肝性脑病的一个特征是脑内谷氨酰胺水平升高。

:::definition{label="循环的三层意义"}
①及时清除突触谷氨酸，防止神经毒性；②谷氨酰胺回到神经元可氧化分解供能；③缓冲脑氨过高。三层都要答，不要只留「回收递质」。
:::

:::definition{label="肝性脑病脑内谷氨酰胺升高"}
肝病时肝对肠道细菌所产氨的清除严重受损，血氨升高。脑内特征之一是谷氨酰胺水平升高——氨被 $\mathrm{GS}$ 接到谷氨酸上。户头在脑侧循环，不是本节去写尿素循环步骤。
:::

:::insight{label="GS 既解毒氨，也制造高谷氨酰胺"}
同一反应：谷氨酸＋氨＋$\mathrm{ATP}$ → 谷氨酰胺。生理时是清除突触谷氨酸、缓冲氨；肝性脑病时这个产物堆在脑内，本身成为特征。不要把「谷氨酰胺升高」写成「脑氨被彻底消灭所以没事」。
:::

并非所有谷氨酸都可以通过谷氨酸–谷氨酰胺循环再生。被摄取进入星形胶质细胞的谷氨酸在转氨酶作用下生成 $\alpha$-酮戊二酸，或者通过谷氨酸脱氢酶（glutamate dehydrogenase，$\mathrm{GDH}$）的氧化脱氨转化为 $\alpha$-酮戊二酸。部分 $\alpha$-酮戊二酸进一步彻底氧化分解为星形胶质细胞提供能量，因此星形胶质细胞需要补充作为能量物质消耗所带来的谷氨酸代谢池损失。星形胶质细胞可利用葡萄糖通过从头合成途径来补充脑谷氨酸代谢池（图27-2）。星形胶质细胞消耗 $\mathrm{NADPH}$，在谷氨酸脱氢酶催化下通过 $\alpha$-酮戊二酸氨化从头合成谷氨酸。其中谷氨酸合成所需氨来自血中的亮氨酸：星形胶质细胞从循环血液中摄取亮氨酸后，在亮氨酸转氨酶（leucine transaminase，$\mathrm{LT}$）催化下将氨基转移给 $\alpha$-酮戊二酸生成谷氨酸和 $\alpha$-酮异己酸（$\alpha$-ketoisocaproate，$\alpha$-$\mathrm{KIC}$）。同时，由于 $\alpha$-酮戊二酸进行氧化分解和谷氨酸合成，必须补充 $\alpha$-酮戊二酸以维持三羧酸循环的通量。星形胶质细胞特异性表达丙酮酸羧化酶，催化糖酵解产物丙酮酸生成草酰乙酸，草酰乙酸与乙酰辅酶 $\mathrm{A}$ 缩合生成柠檬酸，通过三羧酸循环补充 $\alpha$-酮戊二酸。

:::definition{label="胶质内谷氨酸也可进 TCA"}
转氨酶或 $\mathrm{GDH}$ 把谷氨酸变成 $\alpha$-酮戊二酸，部分彻底氧化给星形胶质细胞供能。循环再生不是 $100\%$。
:::

:::definition{label="谷氨酸从头合成"}
星形胶质细胞消耗 $\mathrm{NADPH}$，经 $\mathrm{GDH}$ 把 $\alpha$-酮戊二酸氨化成谷氨酸。氨主要来自血中亮氨酸：$\mathrm{LT}$ 把亮氨酸的氨基交给 $\alpha$-酮戊二酸，得到谷氨酸和 $\alpha$-$\mathrm{KIC}$。
:::

:::definition{label="星形胶质细胞特异表达丙酮酸羧化酶"}
丙酮酸 → 草酰乙酸，再与乙酰辅酶 $\mathrm{A}$ 缩合成柠檬酸，经三羧酸循环补充 $\alpha$-酮戊二酸。回补是为了同时满足氧化分解和谷氨酸合成，不是「胶质没有糖酵解」。
:::

:::compare{title="GDH 的两个方向不要并"}
| 方向 | 底物 → 产物 | 本版原句落点 |
|------|------------|------------|
| 氧化脱氨 | 谷氨酸 → $\alpha$-酮戊二酸 | 胶质把摄取的谷氨酸送进氧化 |
| 氨化（耗 $\mathrm{NADPH}$） | $\alpha$-酮戊二酸 → 谷氨酸 | 从头合成，补充代谢池 |

同一酶、两个方向，问「$\mathrm{GDH}$ 干什么」先问这一步是在耗谷氨酸还是在造谷氨酸。
:::

:::keypoint{label="回补 α-酮戊二酸的两条原料"}
- 碳骨架：葡萄糖 → 丙酮酸 →（丙酮酸羧化酶）草酰乙酸 → 柠檬酸 → $\alpha$-酮戊二酸。
- 氨基：循环亮氨酸经 $\mathrm{LT}$ 转给 $\alpha$-酮戊二酸。
:::

通过星形胶质细胞的谷氨酸从头合成途径以及谷氨酸–谷氨酰胺循环机制，星形胶质细胞和神经元协同调控神经递质谷氨酸和脑组织氮的代谢。

脑内抑制性神经递质 $\mathrm{GABA}$ 不能穿过血脑屏障，必须在神经元内合成（图27-3）。谷氨酸在谷氨酸脱羧酶（glutamate decarboxylase，$\mathrm{GAD}$）作用下脱羧生成 $\mathrm{GABA}$，该酶仅在释放 $\mathrm{GABA}$ 的神经元中表达。原料谷氨酸可由 $\mathrm{GABA}$ 在 $\mathrm{GABA}$ 转氨酶（$\mathrm{GABA}$ aminotransferase，$\mathrm{GABA}$-$\mathrm{T}$）作用下转移氨基给 $\alpha$-酮戊二酸生成，或由谷氨酰胺脱氨生成。$\mathrm{GABA}$ 在突触的作用通过 $\mathrm{GABA}$ 转运蛋白（$\mathrm{GABA}$ transporter，$\mathrm{GAT}$）重新摄取到突触前神经末梢和周围的神经胶质细胞中而终止；回收到神经末梢的 $\mathrm{GABA}$ 可重新利用。在神经胶质细胞中的 $\mathrm{GABA}$ 在 $\mathrm{GABA}$-$\mathrm{T}$ 作用下，将氨基转移给丙酮酸生成丙氨酸，$\mathrm{GABA}$ 转变为琥珀酸半醛，此后琥珀酸半醛在琥珀酸半醛脱氢酶（succinic semialdehyde dehydrogenase，$\mathrm{SSADH}$）催化下生成琥珀酸，进入三羧酸循环，并重新生成谷氨酰胺转运回神经元。$\mathrm{GAD}$ 和 $\mathrm{GABA}$-$\mathrm{T}$ 均需要磷酸吡哆醛作为辅助因子，调节中枢兴奋性和抑制性神经递质的平衡，其功能紊乱参与癫痫和成瘾等疾病过程。

① $\mathrm{GABA}$-$\mathrm{T}$ 把 $\mathrm{GABA}$ 的氨基转给 $\alpha$-酮戊二酸，回成谷氨酸；② 谷氨酰胺脱氨。两路都落在神经元侧。

:::

:::definition{label="胶质内 GABA 进 TCA 并回补谷氨酰胺"}

:::

:::definition{label="GAD 和 GABA-T 都要磷酸吡哆醛"}
二者均需磷酸吡哆醛。调节中枢兴奋／抑制平衡；功能紊乱参与癫痫和成瘾。
:::

### （二）神经递质的代谢受到糖和氧水平的调节

神经递质合成和降解需要葡萄糖的分解和提供羟基化的氧。

乙酰胆碱存在于神经肌肉接头处，主要在脊髓和脑干的运动神经元中合成。乙酰胆碱在胞质中由胆碱和乙酰辅酶 $\mathrm{A}$ 在胆碱乙酰转移酶（choline acetyltransferase，$\mathrm{ChAT}$）的催化下合成，被乙酰胆碱酯酶（acetylcholinesterase，$\mathrm{AChE}$）水解为胆碱和乙酸而清除。乙酰胆碱的乙酰基团来源于葡萄糖，占葡萄糖利用率的 $1\%$，其合成对缺氧极为敏感，其异常导致认知功能障碍。

:::definition{label="乙酰胆碱的合成与清除"}
部位：神经肌肉接头；主要在脊髓和脑干的运动神经元合成。$\mathrm{ChAT}$：胆碱＋乙酰辅酶 $\mathrm{A}$ → 乙酰胆碱。$\mathrm{AChE}$：水解为胆碱和乙酸。乙酰基来自葡萄糖，占葡萄糖利用率的 $1\%$。
:::

:::definition{label="乙酰胆碱合成对缺氧极为敏感"}
缺糖或缺氧先伤乙酰基来源。异常导致认知功能障碍。后文阿尔茨海默病乙酰胆碱传递减少、多奈哌齐抑制 $\mathrm{AChE}$，底板在这一句。
:::

:::pitfall{label="1% 不是「乙酰胆碱只消耗脑能量的 1%」"}
教材写的是乙酰基团来源占葡萄糖利用率的 $1\%$。不要改成能量份额，也不要写成「可以忽略所以缺氧没关系」——同一句后半就是「对缺氧极为敏感」。
:::

儿茶酚胺类神经递质包括多巴胺、去甲肾上腺素和肾上腺素。肾上腺髓质细胞与交感神经元均受中枢神经系统的胆碱能轴突支配，受刺激时释放儿茶酚胺。儿茶酚胺类神经递质的代谢如图27-4 所示。酪氨酸由酪氨酸羟化酶转变为多巴，是儿茶酚胺类物质合成的限速步骤，去甲肾上腺素反馈抑制酪氨酸羟化酶。多巴经芳香族 $\mathrm{L}$-氨基酸脱羧酶（aromatic $\mathrm{L}$-amino acid decarboxylase，$\mathrm{AAAD}$）催化形成多巴胺，该酶在儿茶酚胺能神经元中含量丰富，因此多巴胺的合成量主要取决于可利用的多巴数量。多巴胺随后转运进突触囊泡，由结合在囊泡膜上的多巴胺-$\beta$-羟化酶转变为去甲肾上腺素，利血平可阻遏多巴胺和去甲肾上腺素转运进入囊泡过程。释放多巴胺的神经元含有酪氨酸羟化酶和芳香族 $\mathrm{L}$-氨基酸脱羧酶，但缺乏多巴胺-$\beta$-羟化酶。肾上腺素能神经元中含有苯乙醇胺-$\mathrm{N}$-甲基转移酶（$\mathrm{PNMT}$），催化去甲肾上腺素生成肾上腺素。一旦合成，多巴胺、去甲肾上腺素和肾上腺素被包装在颗粒状囊泡中，以响应神经冲动时分泌。

缺哪一个酶，产物就停在哪一步。不要写成「所有儿茶酚胺能神经元都能做肾上腺素」。
:::

:::pitfall{label="利血平阻的是入囊泡，不是酪氨酸羟化酶"}
利血平：阻遏多巴胺和去甲肾上腺素转运进入囊泡。安非他明和可卡因：阻断重摄取。酪氨酸羟化酶的反馈抑制来自去甲肾上腺素。三药三酶不要对调。
:::

儿茶酚胺的清除首先是钠离子依赖的转运体将儿茶酚胺类递质重新摄入神经末梢，从而终止其在突触间隙的作用，安非他明和可卡因可以阻断该过程。重摄取至轴突末梢后，儿茶酚胺类物质可重新装载入突触囊泡再利用。此外单胺氧化酶（$\mathrm{MAO}$）和乙醛脱氢酶（acetaldehyde dehydrogenase，$\mathrm{ADH}$）可将去甲肾上腺素降解为 $3,4$-二羟基苯乙醇酸（$\mathrm{DOMA}$），而将多巴胺降解为 $3,4$-二羟基苯乙酸（$\mathrm{DOPAC}$）。

:::definition{label="儿茶酚胺清除两路"}
① $\mathrm{Na}^{+}$ 依赖转运体重摄取，终止突触作用，可再装入囊泡；安非他明和可卡因阻断此过程。② $\mathrm{MAO}$＋$\mathrm{ADH}$：去甲肾上腺素 → $\mathrm{DOMA}$，多巴胺 → $\mathrm{DOPAC}$。
:::

:::insight{label="MAO 在 GSH 段已经出过 H2O2"}
前文氧化应激把 $\mathrm{MAO}$ 写成 $\mathrm{H_2O_2}$ 来源；这里 $\mathrm{MAO}$ 是儿茶酚胺降解酶。同一酶两本账：递质清除和过氧化物负担。帕金森病黑质既有多巴胺能退变，也有谷胱甘肽减少，两户都要能答。
:::

合成多巴胺的主要脑区域是黑质。帕金森病患者的脑内多巴胺能神经元缓慢退变直至死亡，而给予多巴可增加存活的神经元内多巴胺的合成，是治疗帕金森病的有效策略。除了作为神经递质的作用外，去甲肾上腺素和肾上腺素还可以调节内分泌功能（如胰岛素分泌）和增加糖原分解和脂肪酸动员，影响新陈代谢率。

:::definition{label="黑质是合成多巴胺的主要脑区"}
帕金森病：多巴胺能神经元缓慢退变直至死亡。给予多巴，增加存活神经元内多巴胺合成。前提仍是 $\mathrm{AAAD}$ 充足、限速在酪氨酸羟化酶／多巴供应。
:::

:::definition{label="去甲肾上腺素和肾上腺素的代谢调节作用"}
除递质外，还可调节内分泌（如胰岛素分泌），增加糖原分解和脂肪酸动员，影响代谢率。户头是全身代谢，不是「只在突触间隙」。
:::

$5$-羟色胺（serotonin，$5$-$\mathrm{HT}$）是一种单胺类神经递质，以色氨酸为前体合成。由于神经元不能合成色氨酸，外周血中色氨酸转运入脑脊液是决定 $5$-$\mathrm{HT}$ 能神经元 $5$-$\mathrm{HT}$ 水平的重要初始环节。与 $5$-$\mathrm{HT}$ 功能相关的行为特别容易受到饮食的影响，例如给予实验动物一天的低蛋白质饮食，然后给予不含色氨酸的氨基酸混合物后，攻击性行为增加并且导致睡眠周期改变。

:::definition{label="5-羟色胺以色氨酸为前体"}
神经元不能合成色氨酸。外周血色氨酸转运入脑脊液，是决定 $5$-$\mathrm{HT}$ 能神经元 $5$-$\mathrm{HT}$ 水平的重要初始环节。
:::

:::insight{label="5-HT 相关行为对饮食敏感"}
本版实验：一天低蛋白质饮食，再给不含色氨酸的氨基酸混合物 → 攻击性增加、睡眠周期改变。问「为什么色氨酸膳食会影响情绪睡眠」走这一户，不要跳到瘦素或弓状核——那是脂肪组织第五节的账。
:::

葡萄糖和氧都是神经递质合成以及降解所必需，其中多巴胺-$\beta$-羟化酶、酪氨酸羟化酶和色氨酸羟化酶催化的羟基化反应需要氧气。

:::definition{label="三种羟化酶需要氧气"}
多巴胺-$\beta$-羟化酶、酪氨酸羟化酶、色氨酸羟化酶。缺糖伤乙酰胆碱的乙酰基；缺氧伤儿茶酚胺和 $5$-$\mathrm{HT}$ 的羟基化。开篇「葡萄糖或氧气供应不足会降低脑功能」在递质这一层落地。
:::

:::keypoint{label="递质四户（必须分清）"}
- 谷胱甘肽合成协同（图27-1）：胶质给前体，神经元自己合成 $\mathrm{GSH}$，抗 $\mathrm{ROS}$。
- 谷氨酸–谷氨酰胺循环（图27-2）：兴奋性谷氨酸的清除、再生、缓冲氨。
- $\mathrm{GABA}$（图27-3）：抑制性，不能过血脑屏障，$\mathrm{GAD}$ 只在 $\mathrm{GABA}$ 能神经元。
- 儿茶酚胺（图27-4）：酪氨酸 → 多巴 → 多巴胺 → 去甲肾上腺素 → 肾上腺素；限速在酪氨酸羟化酶。
:::

图27-1 有谷氨酰胺，图27-2 有谷氨酰胺，图27-3 的原料也是谷氨酸／谷氨酰胺，图27-4 完全是另一条酪氨酸通路。考试若问「星形胶质细胞协同神经元」，先问协同的是 $\mathrm{GSH}$ 还是谷氨酸递质。并成一张图，四道题会互相踩。

## 三、代谢紊乱参与阿尔茨海默病进展

阿尔茨海默病是一种进行性的中枢神经系统退行性疾病，其特征表现是记忆和认知退化，是世界范围内主要公共卫生问题之一。其病理学特征包括 $\beta$ 淀粉样蛋白（$\mathrm{A}\beta$）细胞外聚集形成的老年斑块、微管相关蛋白 $\mathrm{tau}$ 过度磷酸化形成的神经元胞内神经原纤维缠结（neurofibrillary tangles，$\mathrm{NFTs}$）以及海马和新皮层等脑区域中神经元及其突触的丢失。阿尔茨海默病发病机制复杂，除上述经典病理特征外，常伴有全身性和脑糖代谢、脂代谢、氨基酸代谢等代谢异常。

:::definition{label="阿尔茨海默病"}
进行性中枢神经系统退行性疾病，特征是记忆和认知退化。病理三件套：细胞外 $\mathrm{A}\beta$ 老年斑块；胞内过度磷酸化 $\mathrm{tau}$ 的神经原纤维缠结；海马和新皮层神经元及突触丢失。
:::

:::definition{label="AD 还伴代谢异常"}
除经典病理外，常有全身性和脑的糖代谢、脂代谢、氨基酸代谢异常。本节只把糖、脂两本账写清；不要把心肌代谢重编程或肾 EPO 写进来。
:::

:::compare{title="AD 病理三件套"}
| | 分子 | 位置 | 不要写成 |
|--|------|------|---------|
| 老年斑块 | $\mathrm{A}\beta$ | 细胞外 | 「tau 在细胞外成斑」 |
| 神经原纤维缠结 | 过度磷酸化 $\mathrm{tau}$ | 神经元胞内 | 「$\mathrm{A}\beta$ 在胞内缠结」 |
| 神经元／突触丢失 | — | 海马、新皮层等 | 「只有老年斑、没有丢失」 |
:::

### （一）阿尔茨海默病存在糖代谢速率下降和胰岛素抵抗

阿尔茨海默病脑的糖代谢逐步下降，其下降程度与症状严重程度相关。糖代谢障碍发生在阿尔茨海默病脑的特定区域，在顶叶、颞叶、后扣带回和额叶等皮质区域表现明显。代谢功能改变早于脑的结构变化。内侧颞叶等区域糖代谢的下降可被 $\mathrm{PET}$、$\mathrm{MRI}$ 等成像技术显示，是识别轻度认知功能障碍（mild cognitive impairment，$\mathrm{MCI}$）患者相对特异、敏感的标志物，也是阿尔茨海默病的早期指标。

:::definition{label="AD 脑糖代谢逐步下降"}
下降程度与症状严重程度相关。明显区域：顶叶、颞叶、后扣带回、额叶等皮质。代谢改变早于结构变化。
:::

:::definition{label="内侧颞叶糖代谢下降是早期标志"}
$\mathrm{PET}$、$\mathrm{MRI}$ 可显示。对 $\mathrm{MCI}$ 相对特异、敏感，也是阿尔茨海默病的早期指标。户头是「功能成像先于萎缩」，不是「等海马缩小再诊断」。
:::

阿尔茨海默病脑的葡萄糖代谢下降涉及葡萄糖转运蛋白的异常、代谢酶活性下降、氧化应激产生、神经递质代谢紊乱以及线粒体功能紊乱等。阿尔茨海默病患者脑的葡萄糖摄取能力受损，其大脑皮层和海马齿状回等区域的葡萄糖转运体 $\mathrm{GLUT}$s 水平降低。糖代谢的下降进一步引起 $\mathrm{UDP}$-$N$-乙酰葡萄糖胺合成减少和氧–糖连接的蛋白质糖基化修饰下降，降低了 $\mathrm{GLUT}$s 的蛋白稳定性。涉及糖代谢的酶在阿尔茨海默病患者的外周和脑中的活性显著降低，包括丙酮酸脱氢酶复合物、三羧酸循环中的 $\alpha$-酮戊二酸脱氢酶复合物和戊糖磷酸途径中的转酮醇酶，这些酶依赖硫胺素作为辅助因子，补充硫胺素及其衍生物可改善阿尔茨海默病症状。

:::definition{label="AD 葡萄糖摄取受损"}
大脑皮层和海马齿状回等区域 $\mathrm{GLUT}$s 水平降低。糖代谢下降 → $\mathrm{UDP}$-$N$-乙酰葡萄糖胺合成减少 → 氧–糖连接的蛋白质糖基化修饰下降 → $\mathrm{GLUT}$s 蛋白稳定性降低。转运体少了以后更吃不进糖，形成闭环。
:::

:::definition{label="三个硫胺素依赖酶在 AD 中活性下降"}
丙酮酸脱氢酶复合物、$\alpha$-酮戊二酸脱氢酶复合物、转酮醇酶。外周和脑都可下降。补充硫胺素及其衍生物可改善症状。
:::

:::cause-effect{title="糖代谢下降 → UDP-GlcNAc 减少 → GLUT 更不稳"}
葡萄糖代谢下降 → $\mathrm{UDP}$-$N$-乙酰葡萄糖胺合成减少 → $\mathrm{O}$-连接糖基化下降 → $\mathrm{GLUT}$ 稳定性降低 → 摄取更差。这是「越代谢越差」的正反馈，不是一次转运体突变就结束。
:::

:::pitfall{label="转酮醇酶在戊糖磷酸途径，不要写成糖酵解限速酶"}
三酶里：$\mathrm{PDH}$ 接糖酵解和三羧酸循环，$\alpha$-酮戊二酸脱氢酶在三羧酸循环，转酮醇酶在戊糖磷酸途径。并成「糖酵解三酶」，$\mathrm{NADPH}$／$\mathrm{GSH}$ 那一户就连不上。
:::

阿尔茨海默病脑乙酰胆碱传递和代谢减少也是其典型特征之一。糖代谢下降影响乙酰胆碱的合成前体乙酰辅酶 $\mathrm{A}$ 和琥珀酰辅酶 $\mathrm{A}$ 的生成，而乙酰胆碱酯酶抑制剂多奈哌齐是常见的对症治疗阿尔茨海默病的药物。此外，线粒体功能障碍导致氧化磷酸化受损、$\mathrm{ATP}$ 合成减少并增加 $\mathrm{ROS}$ 产生。

:::definition{label="AD 乙酰胆碱传递减少"}
糖代谢下降影响乙酰辅酶 $\mathrm{A}$ 和琥珀酰辅酶 $\mathrm{A}$，乙酰胆碱合成原料不足。多奈哌齐抑制乙酰胆碱酯酶，是常见对症药——减少水解，不直接补葡萄糖。
:::

:::definition{label="AD 线粒体功能障碍"}
氧化磷酸化受损，$\mathrm{ATP}$ 合成减少，$\mathrm{ROS}$ 增加。与前文神经元本就 $\mathrm{GSH}$ 和戊糖磷酸途径偏低相接。
:::

:::insight{label="多奈哌齐对的是 AChE，不是 GLUT"}
前文乙酰胆碱乙酰基占葡萄糖利用率 $1\%$ 却对缺氧极敏感。$\mathrm{AD}$ 糖代谢下降先伤原料，再用 $\mathrm{AChE}$ 抑制剂延长已有乙酰胆碱的作用。不要写成「多奈哌齐把脑葡萄糖代谢治回去了」。
:::

胰岛素抵抗也参与阿尔茨海默病的进展过程。阿尔茨海默病和 $2$ 型糖尿病表现出相似的临床症状和体征，包括认知障碍、空腹血糖受损、慢性高血糖以及海马萎缩，而大多数阿尔茨海默病患者也表现出空腹血糖和胰岛素抵抗异常。临床前和临床研究已经证实，治疗糖尿病、动脉粥样硬化和其他代谢紊乱的常规药物可改善阿尔茨海默病患者的整体状态、行为和细胞功能。

胰岛素信号通路障碍导致胰岛素抵抗，是脑糖代谢紊乱和病理进展的重要原因。胰岛素、胰岛素样生长因子介导的 $\mathrm{PI3K}/\mathrm{Akt}$ 信号通路异常引起 $\mathrm{GLUT}$s 表达和功能降低，促进 $\mathrm{tau}$ 过度磷酸化。此外，参与胰岛素抵抗的其他信号分子也参与了阿尔茨海默病病理生理的改变。

:::definition{label="AD 与 2 型糖尿病的相似表型"}
认知障碍、空腹血糖受损、慢性高血糖、海马萎缩。大多数阿尔茨海默病患者也有空腹血糖和胰岛素抵抗异常。治疗糖尿病、动脉粥样硬化和其他代谢紊乱的常规药物可改善患者整体状态、行为和细胞功能。
:::

:::definition{label="脑胰岛素抵抗伤 GLUT 并促 tau 磷酸化"}
胰岛素、胰岛素样生长因子介导的 $\mathrm{PI3K}/\mathrm{Akt}$ 异常 → $\mathrm{GLUT}$s 表达和功能降低，并促进 $\mathrm{tau}$ 过度磷酸化。糖代谢户和缠结户在这里交汇。
:::

:::pitfall{label="胰岛素抵抗段属于第一节，不要留在心肌节文首"}
$\mathrm{PI3K}/\mathrm{Akt}$、$\mathrm{GLUT}$s、$\mathrm{tau}$ 过度磷酸化是脑糖代谢紊乱的账。第二节从心肌起笔。不要把这段尾巴贴到「心肌的生物化学」标题下面。
:::

:::compare{title="AD 糖代谢下降的五层机制"}
| 层 | 本版原句 | 不要缩成 |
|--|---------|---------|
| 转运 | 皮层、海马齿状回 $\mathrm{GLUT}$s 降低；$\mathrm{O}$-糖基化下降使 $\mathrm{GLUT}$ 不稳 | 「脑不能转运葡萄糖」一句 |
| 酶 | $\mathrm{PDH}$、$\alpha$-酮戊二酸脱氢酶、转酮醇酶下降，硫胺素依赖 | 「线粒体坏了」一句 |
| 递质 | 乙酰辅酶 $\mathrm{A}$、琥珀酰辅酶 $\mathrm{A}$ 不足 → 乙酰胆碱减少 | 「只有胆碱能假说」 |
| 线粒体 | 氧化磷酸化受损，$\mathrm{ATP}$ 少，$\mathrm{ROS}$ 多 | 「只有自由基」 |
| 胰岛素 | $\mathrm{PI3K}/\mathrm{Akt}$ 异常 → $\mathrm{GLUT}$ 降、$\mathrm{tau}$ 磷酸化 | 「AD 就是糖尿病」 |

五层并列，考试答「糖代谢障碍」至少要能点出转运、酶、递质、线粒体、胰岛素抵抗。
:::

### （二）脂代谢紊乱参与阿尔茨海默病病理进展

脂质代谢紊乱与阿尔茨海默病发病机制和进展亦密切相关。脑的 $10\%\sim 12\%$ 的湿重和超过 $50\%$ 的干重由脂质组成，其中磷脂占总脂质含量的约 $50\%$。这些脂质是突触、髓鞘、细胞膜等关键神经系统结构的组成成分，参与并调节信号转导过程。

:::definition{label="脑脂质的体量"}
约占湿重 $10\%\sim 12\%$，干重超过 $50\%$，磷脂约占脂质的 $50\%$。组成突触、髓鞘、细胞膜，并调节信号转导。户头在第一节，不是心肌节的开篇数字。
:::

:::keypoint{label="脑脂质三个百分数"}
- 湿重：$10\%\sim 12\%$。
- 干重：超过 $50\%$。
- 磷脂占脂质：约 $50\%$。
:::

:::pitfall{label="10%～12% 是湿重，超过 50% 是干重"}
两笔都在说「脑很油」，分母不同。写成「脑脂质占体重 $10\%\sim 12\%$」或「湿重一半是脂质」，和开篇脑占体重 $2\%$ 会打架。
:::

在阿尔茨海默病的早期阶段就出现各种脂质水平的改变。阿尔茨海默病患者脑脊液中总游离脂肪酸水平较高，偶数链饱和脂肪酸增加，但 $\omega$-$3$ 多不饱和脂肪酸、单不饱和脂肪酸（油酸）和二十二碳六烯酸（$\mathrm{DHA}$）降低，其中 $\mathrm{DHA}$ 水平与认知能力呈正相关。海马和皮层的磷脂酰胆碱、磷脂酰肌醇和磷脂酰乙醇胺等甘油磷脂水平降低。在额叶和颞叶皮质等区域神经酰胺水平升高，同时鞘磷脂水平降低，神经酰胺水平升高可促进脂质过氧化、氧化应激、线粒体功能障碍和神经元死亡。阿尔茨海默病脑中的甘油三酯水平没有改变，但轻度认知功能障碍和 $\mathrm{AD}$ 脑的额叶皮层中的单酰基甘油和二酰甘油均升高。脑富含胆固醇，占总胆固醇的 $25\%$，由于血脑屏障原因，脑的胆固醇大部分是在中枢神经系统中从头合成。阿尔茨海默病患者的脑胆固醇水平高，同时胆固醇堆集于老年斑块的核心，脑胆固醇水平与疾病严重程度呈正相关。

:::definition{label="AD 早期就有脂质改变"}
脑脊液总游离脂肪酸较高；偶数链饱和脂肪酸增加；$\omega$-$3$ 多不饱和脂肪酸、油酸、$\mathrm{DHA}$ 降低。$\mathrm{DHA}$ 与认知能力正相关。
:::

:::definition{label="甘油磷脂下降、神经酰胺升高"}
海马和皮层：磷脂酰胆碱、磷脂酰肌醇、磷脂酰乙醇胺降低。额叶和颞叶：神经酰胺升高、鞘磷脂降低。神经酰胺升高促进脂质过氧化、氧化应激、线粒体功能障碍和神经元死亡。
:::

:::definition{label="甘油三酯不变，MAG 和 DAG 升高"}
$\mathrm{AD}$ 脑甘油三酯水平没有改变；$\mathrm{MCI}$ 和 $\mathrm{AD}$ 额叶皮层的单酰基甘油、二酰甘油均升高。「脂代谢紊乱」不是「甘油三酯一定升高」。
:::

:::definition{label="脑胆固醇占全身 25% 且多从头合成"}
血脑屏障限制外周胆固醇进入，脑胆固醇大部分在中枢神经系统从头合成。$\mathrm{AD}$ 患者脑胆固醇水平高，堆集于老年斑块核心，与疾病严重程度正相关。
:::

:::compare{title="AD 脂质几笔不要混"}
| 脂质 | AD 中的方向 | 本版要点 |
|------|------------|---------|
| 总游离脂肪酸（脑脊液） | 升高 | 偶数链饱和脂肪酸增加 |
| $\omega$-$3$、油酸、$\mathrm{DHA}$ | 降低 | $\mathrm{DHA}$ 与认知正相关 |
| $\mathrm{PC}$、$\mathrm{PI}$、$\mathrm{PE}$ | 海马／皮层降低 | 甘油磷脂 |
| 神经酰胺 | 额、颞升高 | 鞘磷脂同时降低 |
| 甘油三酯 | 不变 | 不要写成高脂血症 |
| 单酰基甘油、二酰甘油 | 额叶升高 | $\mathrm{MCI}$ 已可见 |
| 胆固醇 | 脑内升高，斑块核心堆集 | 全身份额 $25\%$，多从头合成 |
:::

:::pitfall{label="脑胆固醇 25% 不是「血浆胆固醇的 25%」"}
教材写脑富含胆固醇，占总胆固醇的 $25\%$。由于血脑屏障，大部分在中枢从头合成。写成「降血浆胆固醇就能按比例降脑胆固醇」，后文 $\mathrm{ApoE}$、$\mathrm{ABCA1}$ 就没有户头。
:::

全基因组关联分析（genome wide association study，$\mathrm{GWAS}$）等研究进一步支持脂质代谢紊乱在阿尔茨海默病中的潜在启动作用。在散发性阿尔茨海默病的高风险基因中，$\mathrm{ApoE}$、髓系细胞触发受体 $2$（triggering receptor expressed on myeloid cells $2$，$\mathrm{TREM2}$）、$\mathrm{ApoJ}$、磷脂酰肌醇结合网格蛋白组装蛋白（phosphatidylinositol binding clathrin assembly protein，$\mathrm{PICALM}$）、$\mathrm{ATP}$ 结合盒转运蛋白 $\mathrm{A1}$（$\mathrm{ATP}$-binding cassette transporter $\mathrm{A1}$，$\mathrm{ABCA1}$）和 $\mathrm{ABCA7}$ 都直接参与脂质运输或代谢。载脂蛋白 $\mathrm{ApoE}$ 是散发性阿尔茨海默病相关的最强遗传危险因素。$\mathrm{ApoE}$ 有三个等位基因 $\varepsilon 2$、$\varepsilon 3$ 和 $\varepsilon 4$。一个 $\mathrm{ApoE}\,\varepsilon 4$ 等位基因携带者患阿尔茨海默病的风险增加约 $3.7$ 倍，$\mathrm{ApoE}\,\varepsilon 4$ 纯合子会使风险增加多达 $12$ 倍，而携带单个 $\mathrm{ApoE}\,\varepsilon 2$ 等位基因可将风险降低约 $40\%$，$\mathrm{ApoE}\,\varepsilon 2$ 纯合子进一步降低了风险。此外，$\mathrm{ApoE}\,\varepsilon 4$ 携带者发病年龄较早。固醇调节元件结合蛋白 $2$（sterol-regulatory element-binding protein-$2$，$\mathrm{SREBP}$-$2$）是胆固醇代谢的关键调节因子，在遗传上也与 $\mathrm{AD}$ 风险改变有关。家族性阿尔茨海默病的致病基因 $\mathrm{APP}$、早老素 $1$ 和 $2$（presenilin $1/2$，$\mathrm{PSEN1}/\mathrm{PSEN2}$）也调节脂质代谢。

:::definition{label="散发性 AD 高风险基因多在脂质运输"}
$\mathrm{ApoE}$、$\mathrm{TREM2}$、$\mathrm{ApoJ}$、$\mathrm{PICALM}$、$\mathrm{ABCA1}$、$\mathrm{ABCA7}$ 都直接参与脂质运输或代谢。$\mathrm{GWAS}$ 支持脂质紊乱可能有启动作用，不是「只有淀粉样蛋白一条路」。
:::

:::definition{label="ApoE 是散发性 AD 最强遗传危险因素"}
三个等位基因 $\varepsilon 2$、$\varepsilon 3$、$\varepsilon 4$。一个 $\varepsilon 4$：风险约 $3.7$ 倍；$\varepsilon 4$ 纯合：多达 $12$ 倍；一个 $\varepsilon 2$：风险降低约 $40\%$；$\varepsilon 2$ 纯合进一步降低。$\varepsilon 4$ 携带者发病较早。
:::

:::definition{label="SREBP-2 与家族性致病基因也碰脂质"}
$\mathrm{SREBP}$-$2$ 调节胆固醇代谢，遗传上与 $\mathrm{AD}$ 风险改变有关。家族性致病基因 $\mathrm{APP}$、$\mathrm{PSEN1}$、$\mathrm{PSEN2}$ 也调节脂质代谢。家族性和散发性都和脂质有交点。
:::

:::compare{title="ApoE 等位基因与 AD 风险"}
| 基因型要点 | 本版数字 | 不要写成 |
|------------|---------|---------|
| 一个 $\varepsilon 4$ | 风险约增加 $3.7$ 倍 | 「一定会发病」 |
| $\varepsilon 4$ 纯合 | 风险多达 $12$ 倍 | 「$12$ 岁发病」——说的是倍数不是年龄 |
| 一个 $\varepsilon 2$ | 风险降低约 $40\%$ | 「完全保护」 |
| $\varepsilon 2$ 纯合 | 进一步降低 | 「$\varepsilon 2$ 没有作用」 |
| $\varepsilon 4$ 携带者 | 发病年龄较早 | 「只增加风险、不影响年龄」 |
:::

:::pitfall{label="3.7 倍和 12 倍是风险倍数，不是患病率百分数"}
一个 $\varepsilon 4$ 约 $3.7$ 倍、纯合多达 $12$ 倍，是相对风险。不要改成「$3.7\%$ 的人会得」或「纯合发病率 $12\%$」。
:::

:::memory{label="本节必背分户"}
- 人脑约占体重 $2\%$；每天约 $100\,\mathrm{g}$ 葡萄糖（约总葡萄糖 $25\%$）；约总耗氧量 $20\%$；神经元消耗脑能量 $70\%\sim 80\%$。
- 约 $70\%$ 能量用于神经元信号转导；$\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-$\mathrm{ATPase}$ 约占葡萄糖氧化产能 $50\%$；兴奋性神经元约 $80\%\sim 85\%$ 的 $\mathrm{ATP}$。
- 主转运：$\mathrm{GLUT1}$（$55\,\mathrm{kDa}$ 入脑实质，$45\,\mathrm{kDa}$ 在胶质）和 $\mathrm{GLUT3}$；$\mathrm{GLUT4}$ 胰岛素敏感、神经元；$\mathrm{GLUT2}$ 感知；$\mathrm{GLUT5}$ 小胶质。
- 缺糖或缺氧降脑功能。特殊情况才用酮体、乳酸等；基础乳酸约 $8\%\sim 10\%$，剧烈运动可达 $20\%\sim 25\%$。脑糖原很少，主要在星形胶质细胞。
- 四户：图27-1 $\mathrm{GSH}$ 合成协同 ≠ 图27-2 谷氨酸–谷氨酰胺循环 ≠ 图27-3 $\mathrm{GABA}$ ≠ 图27-4 儿茶酚胺。
- 神经元不能直接摄取 $\mathrm{GSH}$；$\gamma$-$\mathrm{GT}$ → $\mathrm{CysGly}$ → $\mathrm{APN}$。$\mathrm{GS}$ 在胶质，谷氨酰胺酶在神经元。
- $\mathrm{GAD}$、$\mathrm{GABA}$-$\mathrm{T}$ 需磷酸吡哆醛。酪氨酸羟化酶是儿茶酚胺限速酶；黑质；多巴治疗帕金森病。
- 脑脂质：湿重 $10\%\sim 12\%$，干重超过 $50\%$，磷脂约占脂质 $50\%$；脑胆固醇占全身 $25\%$，多从头合成。
- $\mathrm{AD}$：斑块、缠结、突触丢失；糖代谢下降早于结构改变；$\mathrm{ApoE}\,\varepsilon 4$ 约 $3.7$ 倍／纯合可达 $12$ 倍，$\varepsilon 2$ 降约 $40\%$。
:::

:::keypoint{label="本节不写的三本账"}
心肌葡萄糖与脂肪酸切换、优势效应和心力衰竭代谢重编程是第二节。肾的排泄、糖异生和激素是第三节。骨骼肌运动供能曲线和脂肪组织瘦素、弓状核是第四、五节。本节只把脑的燃料、胶质–神经元互动和递质四户立住。
:::
