# 第五节　胆固醇代谢

第四节把膜磷脂写成甘油磷脂和神经鞘磷脂两本账。本节把胆固醇立成“能合成、不能拆核”的那一本：体内每天约合成 $1\,\mathrm{g}$，肝占 $70\%\sim 80\%$；唯一碳源是乙酰 $\mathrm{CoA}$，关键酶是内质网 $\mathrm{HMG\text{-}CoA}$ 还原酶。环戊烷多氢菲母核不能被彻底分解，主要去路是肝内转化成胆汁酸，旁路才是类固醇激素和维生素 $\mathrm{D}_{3}$。

胆固醇有游离胆固醇（free cholesterol，$\mathrm{FC}$；亦称非酯化胆固醇，unesterified cholesterol）和胆固醇酯（cholesterol ester，$\mathrm{CE}$）两种形式，广泛分布于各组织。约 $1/4$ 分布在脑及神经组织，约占脑组织 $2\%$。肾上腺、卵巢等类固醇激素分泌腺，胆固醇含量达 $1\%\sim 5\%$。肝、肾、肠等内脏及皮肤、脂肪组织，胆固醇含量约为每 $100\,\mathrm{g}$ 组织 $200\sim 500\,\mathrm{mg}$，以肝最多。肌组织含量约为每 $100\,\mathrm{g}$ 组织 $100\sim 200\,\mathrm{mg}$。体内胆固醇来自食物和内源性合成两本账；合成多少，主要由 $\mathrm{HMG\text{-}CoA}$ 还原酶开关。

:::definition{label="游离胆固醇与胆固醇酯"}
胆固醇有两种形式：游离胆固醇（free cholesterol，$\mathrm{FC}$；亦称非酯化胆固醇，unesterified cholesterol）和胆固醇酯（cholesterol ester，$\mathrm{CE}$）。
:::

:::compare{title="各组织胆固醇含量（本版教材）"}
| 部位 | 含量 |
|------|------|
| 脑及神经组织 | 约占全身胆固醇 $1/4$；约占脑组织 $2\%$ |
| 肾上腺、卵巢等类固醇激素分泌腺 | $1\%\sim 5\%$ |
| 肝、肾、肠及皮肤、脂肪组织 | 每 $100\,\mathrm{g}$ 组织 $200\sim 500\,\mathrm{mg}$，以肝最多 |
| 肌组织 | 每 $100\,\mathrm{g}$ 组织 $100\sim 200\,\mathrm{mg}$ |
:::

:::concept{term="先问来自食物还是自身合成，再问母核能不能拆"}
看见胆固醇，不要先跳到“吃得少就低”。几乎全身都能合成，肝是主场；母核环戊烷多氢菲不能像糖、脂肪那样彻底分解，去路是改侧链、写成胆汁酸或激素，不是氧化成 $\mathrm{CO}_{2}$。
:::

:::pitfall{label="脑含胆固醇多，不等于成年脑还在大量合成"}
约 $1/4$ 的胆固醇在脑及神经组织，但这是分布账。后文写明：除成年动物脑组织及成熟红细胞外，几乎全身各组织均可合成。成年脑、成熟红细胞不在合成名单里。
:::

## 一、体内胆固醇来自食物和内源性合成

### （一）体内胆固醇合成的主要场所是肝

除成年动物脑组织及成熟红细胞外，几乎全身各组织均可合成胆固醇，每天合成量为 $1\,\mathrm{g}$ 左右。肝是主要合成器官，占自身合成胆固醇的 $70\%\sim 80\%$，其次是小肠，合成 $10\%$。胆固醇合成酶系存在于胞质溶胶及光面内质网膜。

:::definition{label="胆固醇合成的场所"}
除成年动物脑组织及成熟红细胞外，几乎全身各组织均可合成胆固醇，每天约 $1\,\mathrm{g}$。肝占自身合成的 $70\%\sim 80\%$，小肠约 $10\%$。酶系在胞质溶胶及光面内质网膜。
:::

:::keypoint{label="合成地图三笔"}
- 能合成：几乎全身组织。
- 不能合成：成年动物脑组织、成熟红细胞。
- 主场：肝 $70\%\sim 80\%$；次场：小肠 $10\%$；酶在胞质溶胶 $+$ 光面内质网。
:::

:::pitfall{label="小肠 10% 不是“其余 20%～30% 都在小肠”"}
肝 $70\%\sim 80\%$，小肠 $10\%$，其余组织分摊剩下的份额。不要把非肝合成全部记成小肠。
:::

### （二）乙酰 CoA 和 NADPH 是胆固醇合成基本原料

$^{14}\mathrm{C}$ 及 $^{13}\mathrm{C}$ 标记乙酸甲基碳及羧基碳，与肝切片孵育证明：乙酸分子中的 $2$ 个碳原子均参与构成胆固醇，是合成胆固醇唯一碳源。乙酰 $\mathrm{CoA}$ 是葡萄糖、氨基酸及脂肪酸在线粒体的分解产物，不能通过线粒体内膜，需在线粒体内与草酰乙酸缩合生成柠檬酸，通过线粒体内膜载体进入胞质溶胶，裂解成乙酰 $\mathrm{CoA}$，作为胆固醇合成原料。每转运 $1$ 分子乙酰 $\mathrm{CoA}$，由柠檬酸裂解成乙酰 $\mathrm{CoA}$ 时消耗 $1$ 分子 $\mathrm{ATP}$。胆固醇合成还需 $\mathrm{NADPH}$ 供氢、$\mathrm{ATP}$ 供能。合成 $1$ 分子胆固醇需 $18$ 分子乙酰 $\mathrm{CoA}$、$36$ 分子 $\mathrm{ATP}$ 及 $16$ 分子 $\mathrm{NADPH}$。

:::definition{label="胆固醇合成的唯一碳源"}
乙酸分子中的甲基碳和羧基碳都进入胆固醇，是唯一碳源。体内以乙酰 $\mathrm{CoA}$ 的形式提供这两个碳。
:::

:::definition{label="乙酰 CoA 如何出线粒体供胆固醇合成"}
乙酰 $\mathrm{CoA}$ 不能通过线粒体内膜。它在线粒体内与草酰乙酸缩合成柠檬酸，经内膜载体进入胞质溶胶，再裂解成乙酰 $\mathrm{CoA}$。每转运 $1$ 分子乙酰 $\mathrm{CoA}$，柠檬酸裂解消耗 $1$ 分子 $\mathrm{ATP}$。
:::

:::keypoint{label="写 1 分子胆固醇的物料账"}
- $18$ 分子乙酰 $\mathrm{CoA}$（碳架）。
- $36$ 分子 $\mathrm{ATP}$（供能；出线粒体的柠檬酸裂解也计入转运成本）。
- $16$ 分子 $\mathrm{NADPH}$（供氢）。
:::

:::compare{title="乙酰 CoA 的来路与胆固醇合成的交接点"}
| 来路 | 分解场所 | 怎样交给胞质溶胶的胆固醇酶系 |
|------|----------|--------------------------------|
| 葡萄糖、氨基酸、脂肪酸 | 线粒体 | 自身不能穿内膜 → 柠檬酸穿梭 → 裂解成乙酰 $\mathrm{CoA}$ |

碳源只有乙酸／乙酰 $\mathrm{CoA}$ 这一本，不是“三种营养素各提供一部分特殊碳”。
:::

:::pitfall{label="18、36、16 是本版的胆固醇账，不要改成脂肪酸合酶那一套"}
脂肪酸合成也要乙酰 $\mathrm{CoA}$、$\mathrm{ATP}$、$\mathrm{NADPH}$，数字不是这一组。胆固醇是 $18$ 乙酰 $\mathrm{CoA}$、$36\,\mathrm{ATP}$、$16\,\mathrm{NADPH}$。把两笔并成“脂类合成都是 8 个乙酰 $\mathrm{CoA}$”，软脂酸和胆固醇会算乱。
:::

:::insight{label="NADPH 从哪来，教材写在原料栏"}
胆固醇合成在胞质溶胶／内质网，需要大量 $\mathrm{NADPH}$。糖代谢戊糖磷酸途径是供氢的重要来源，但本节只把 $\mathrm{NADPH}$ 写成原料，不另开一条磷酸戊糖。禁食时 $\mathrm{NADPH}$ 不足，后文会变成合成下降的原因之一。
:::

### （三）胆固醇合成由以 HMG-CoA 还原酶为关键酶的一系列酶促反应完成

胆固醇合成过程复杂，有近 $30$ 步酶促反应，大致可划分为三个阶段：乙酰 $\mathrm{CoA}$ 写成甲羟戊酸；甲羟戊酸经 $15$ 碳化合物转变成 $30$ 碳鲨烯；鲨烯环化为羊毛固醇后再变成 $27$ 碳胆固醇。

:::definition{label="胆固醇合成的三个阶段"}
近 $30$ 步酶促反应划分为：①乙酰 $\mathrm{CoA}$ → 甲羟戊酸；②甲羟戊酸经 $15$ 碳化合物 → $30$ 碳鲨烯；③鲨烯 → 羊毛固醇 → $27$ 碳胆固醇。
:::

**1. 由乙酰 CoA 合成甲羟戊酸**　$2$ 分子乙酰 $\mathrm{CoA}$ 在乙酰乙酰 $\mathrm{CoA}$ 硫解酶作用下，缩合成乙酰乙酰 $\mathrm{CoA}$；再在羟基甲基戊二酸单酰 $\mathrm{CoA}$ 合酶（$3$-hydroxy-$3$-methylglutaryl $\mathrm{CoA}$ synthase，$\mathrm{HMG\text{-}CoA}$ synthase）作用下，与 $1$ 分子乙酰 $\mathrm{CoA}$ 缩合成羟基甲基戊二酸单酰 $\mathrm{CoA}$（$3$-hydroxy-$3$-methylglutaryl $\mathrm{CoA}$，$\mathrm{HMG\text{-}CoA}$）。在线粒体中，$\mathrm{HMG\text{-}CoA}$ 被裂解生成酮体；而胞质溶胶生成的 $\mathrm{HMG\text{-}CoA}$，则在内质网 $\mathrm{HMG\text{-}CoA}$ 还原酶（$\mathrm{HMG\text{-}CoA}$ reductase）作用下，由 $\mathrm{NADPH}$ 供氢，还原生成甲羟戊酸（mevalonic acid，$\mathrm{MVA}$）。$\mathrm{HMG\text{-}CoA}$ 还原酶是合成胆固醇的关键酶。

:::definition{label="HMG-CoA"}
羟基甲基戊二酸单酰 $\mathrm{CoA}$（$3$-hydroxy-$3$-methylglutaryl $\mathrm{CoA}$，$\mathrm{HMG\text{-}CoA}$）由乙酰乙酰 $\mathrm{CoA}$ 再缩合 $1$ 分子乙酰 $\mathrm{CoA}$ 生成。线粒体中的 $\mathrm{HMG\text{-}CoA}$ 裂解成酮体；胞质溶胶中的 $\mathrm{HMG\text{-}CoA}$ 被内质网 $\mathrm{HMG\text{-}CoA}$ 还原酶还原成甲羟戊酸。
:::

:::definition{label="HMG-CoA 还原酶"}
$\mathrm{HMG\text{-}CoA}$ 还原酶（$\mathrm{HMG\text{-}CoA}$ reductase）位于内质网，以 $\mathrm{NADPH}$ 供氢，把胞质溶胶来的 $\mathrm{HMG\text{-}CoA}$ 还原成甲羟戊酸（mevalonic acid，$\mathrm{MVA}$）。它是胆固醇合成的关键酶。
:::

:::definition{label="甲羟戊酸"}
甲羟戊酸（mevalonic acid，$\mathrm{MVA}$）是 $\mathrm{HMG\text{-}CoA}$ 还原酶的产物，也是胆固醇合成第一阶段的终点。后续异戊烯单位都从 $\mathrm{MVA}$ 写出。
:::

:::compare{title="同一张 HMG-CoA，线粒体写酮体，胞质写胆固醇"}
| 部位 | $\mathrm{HMG\text{-}CoA}$ 去路 | 关键酶 |
|------|-------------------------------|--------|
| 线粒体 | 裂解生成酮体 | $\mathrm{HMG\text{-}CoA}$ 裂解酶（酮体那一节） |
| 胞质溶胶 → 内质网 | 还原生成甲羟戊酸，进入胆固醇合成 | $\mathrm{HMG\text{-}CoA}$ 还原酶 |

底物同名，细胞器不同，产物完全不是一种东西。
:::

:::pitfall{label="HMG-CoA 还原酶不是 HMG-CoA 合酶，更不是裂解酶"}
合酶把乙酰乙酰 $\mathrm{CoA}$ 加成第三分子乙酰 $\mathrm{CoA}$，写出 $\mathrm{HMG\text{-}CoA}$。还原酶才是胆固醇关键酶，产物是 $\mathrm{MVA}$。裂解酶在线粒体写酮体。三张酶不要并成“HMG 酶”。
:::

:::derivation{title="乙酰 CoA 到甲羟戊酸"}
$2$ 分子乙酰 $\mathrm{CoA}$ $\xrightarrow{\text{乙酰乙酰 }\mathrm{CoA}\text{ 硫解酶}}$ 乙酰乙酰 $\mathrm{CoA}$。

乙酰乙酰 $\mathrm{CoA}$ $+\,1$ 分子乙酰 $\mathrm{CoA}$ $\xrightarrow{\mathrm{HMG\text{-}CoA}\text{ 合酶}}$ $\mathrm{HMG\text{-}CoA}$。

胞质溶胶 $\mathrm{HMG\text{-}CoA}$ $+\,2\,\mathrm{NADPH}$ $\xrightarrow{\text{内质网 }\mathrm{HMG\text{-}CoA}\text{ 还原酶}}$ 甲羟戊酸（$\mathrm{MVA}$），放出 $\mathrm{CoA}$。
:::

**2. 甲羟戊酸经 15 碳化合物转变成 30 碳鲨烯**　$\mathrm{MVA}$ 经脱羧、磷酸化生成活泼的异戊烯焦磷酸（$\Delta^{3}$-isopentenyl pyrophosphate，$\mathrm{IPP}$）和二甲基丙烯焦磷酸（$3,3$-dimethylallyl pyrophosphate，$\mathrm{DPP}$）。$3$ 分子 $5$ 碳焦磷酸化合物（$\mathrm{IPP}$ 及 $\mathrm{DPP}$）缩合成 $15$ 碳焦磷酸法尼酯（farnesyl pyrophosphate，$\mathrm{FPP}$）。在内质网鲨烯合酶（squalene synthase）催化下，$2$ 分子 $15$ 碳焦磷酸法尼酯经再缩合、还原生成 $30$ 碳多烯烃——鲨烯（squalene）。

:::definition{label="异戊烯焦磷酸与二甲基丙烯焦磷酸"}
甲羟戊酸经脱羧、磷酸化生成 $5$ 碳的异戊烯焦磷酸（$\mathrm{IPP}$）和二甲基丙烯焦磷酸（$\mathrm{DPP}$）。二者是缩合鲨烯的活泼异戊烯单位。
:::

:::definition{label="焦磷酸法尼酯"}
$3$ 分子 $5$ 碳焦磷酸化合物（$\mathrm{IPP}$ 及 $\mathrm{DPP}$）缩合成 $15$ 碳焦磷酸法尼酯（farnesyl pyrophosphate，$\mathrm{FPP}$）。
:::

:::definition{label="鲨烯"}
内质网鲨烯合酶催化 $2$ 分子 $\mathrm{FPP}$ 再缩合、还原，生成 $30$ 碳多烯烃鲨烯（squalene）。
:::

:::keypoint{label="5 碳 × 3 → 15 碳；15 碳 × 2 → 30 碳"}
- $\mathrm{MVA}$（$6$ 碳）脱羧、磷酸化 → $\mathrm{IPP}/\mathrm{DPP}$（$5$ 碳）。
- $3$ 个 $5$ 碳单位 → $\mathrm{FPP}$（$15$ 碳）。
- $2$ 个 $\mathrm{FPP}$ → 鲨烯（$30$ 碳）。
:::

**3. 鲨烯环化为羊毛固醇后转变为胆固醇**　$30$ 碳鲨烯结合在胞质溶胶固醇载体蛋白（sterol carrier protein，$\mathrm{SCP}$）上，经内质网单加氧酶、环化酶等催化，环化成羊毛固醇，再经氧化、脱羧、还原等反应，脱去 $3$ 个甲基，生成 $27$ 碳胆固醇（图8-8）。在脂肪酰 $\mathrm{CoA}$：胆固醇脂肪酰转移酶（acyl $\mathrm{CoA}$：cholesterol acyltransferase，$\mathrm{ACAT}$）作用下，细胞内游离胆固醇能与脂肪酰 $\mathrm{CoA}$ 缩合，生成胆固醇酯储存。

::figure{src="/images/biochemistry/textbook/p0189_01.png" caption="图8-8　胆固醇的生物合成。左侧：乙酰 CoA 与乙酰乙酰 CoA 缩合成羟基甲基戊二酸单酰辅酶 A，经 NADPH 还原为甲羟戊酸（MVA）；MVA 消耗 ATP 生成 5-焦磷酸甲羟戊酸，再脱羧生成异戊烯焦磷酸，与二甲丙烯焦磷酸互变；3 个五碳单位缩合成焦磷酸法尼酯，2 分子焦磷酸法尼酯再缩合成鲨烯。右侧：开链鲨烯环化为羊毛固醇，再转变为 27 碳胆固醇。" alt="胆固醇合成流程图：左列从乙酰辅酶A经HMG-CoA、甲羟戊酸、焦磷酸甲羟戊酸、异戊烯焦磷酸、二甲丙烯焦磷酸到焦磷酸法尼酯；右列鲨烯、羊毛固醇、胆固醇的环状结构"}

:::definition{label="固醇载体蛋白"}
$30$ 碳鲨烯结合在胞质溶胶固醇载体蛋白（sterol carrier protein，$\mathrm{SCP}$）上，再交给内质网单加氧酶、环化酶等，环化成羊毛固醇。
:::

:::definition{label="羊毛固醇到胆固醇"}
羊毛固醇经氧化、脱羧、还原等反应，脱去 $3$ 个甲基，生成 $27$ 碳胆固醇。
:::

:::definition{label="ACAT"}
脂肪酰 $\mathrm{CoA}$：胆固醇脂肪酰转移酶（acyl $\mathrm{CoA}$：cholesterol acyltransferase，$\mathrm{ACAT}$）催化细胞内游离胆固醇与脂肪酰 $\mathrm{CoA}$ 缩合，生成胆固醇酯储存。
:::

:::compare{title="三个阶段的碳数"}
| 阶段 | 代表分子 | 碳数 |
|------|----------|------|
| ① 甲羟戊酸 | $\mathrm{MVA}$ | $6$；随后脱羧成 $5$ 碳 $\mathrm{IPP}$ |
| ② 鲨烯 | $\mathrm{FPP}$ → 鲨烯 | $15$ → $30$ |
| ③ 成环、脱甲基 | 羊毛固醇 → 胆固醇 | $30$ → 脱去 $3$ 个甲基 → $27$ |
:::

:::pitfall{label="鲨烯 30 碳不是胆固醇 27 碳，差的是三颗甲基"}
环化先得到羊毛固醇，再氧化、脱羧、还原脱掉 $3$ 个甲基。不要把鲨烯直接听成胆固醇，也不要把 $18$ 分子乙酰 $\mathrm{CoA}$（$36$ 个碳）当成最终分子还剩 $36$ 个碳。
:::

:::insight{label="ACAT 把“能调节代谢的游离胆固醇”写成贮存形式"}
游离胆固醇既是膜成分，也是 $\mathrm{HMG\text{-}CoA}$ 还原酶的调节信号。$\mathrm{ACAT}$ 把它酯化成 $\mathrm{CE}$ 存起来，细胞内游离胆固醇浓度才能被关掉。第六节 LDL 入胞后还会再写一次 $\mathrm{ACAT}$。
:::

### （四）胆固醇合成受 HMG-CoA 还原酶调节

关键酶已经立户，调节就全部落到 $\mathrm{HMG\text{-}CoA}$ 还原酶：昼夜节律、别构、磷酸化修饰、酶蛋白含量、细胞胆固醇含量、餐食状态和激素。

**1. HMG-CoA 还原酶活性具有与胆固醇合成相同的昼夜节律性**　动物实验发现，大鼠肝胆固醇合成有昼夜节律性，午夜最高，中午最低。进一步研究发现，肝 $\mathrm{HMG\text{-}CoA}$ 还原酶活性也有昼夜节律性，午夜最高，中午最低。可见，胆固醇合成的周期节律性是 $\mathrm{HMG\text{-}CoA}$ 还原酶活性周期性改变的结果。

:::definition{label="胆固醇合成的昼夜节律"}
大鼠肝胆固醇合成与肝 $\mathrm{HMG\text{-}CoA}$ 还原酶活性均呈昼夜节律：午夜最高，中午最低。合成的周期节律性来自该酶活性的周期性改变。
:::

:::pitfall{label="午夜最高是大鼠肝实验，不要改写成“人半夜血脂最高”"}
教材写的是动物实验中肝合成酶活性的节律，不是临床采血时点。节律用来证明关键酶和合成同步，不是一张人类午夜胆固醇曲线。
:::

**2. HMG-CoA 还原酶活性受别构调节、化学修饰调节和酶含量调节**　胆固醇合成产物甲羟戊酸、胆固醇及胆固醇氧化产物 $7\beta$-羟胆固醇、$25$-羟胆固醇是 $\mathrm{HMG\text{-}CoA}$ 还原酶的别构抑制剂。胞质溶胶 $\mathrm{cAMP}$ 依赖性蛋白激酶可使 $\mathrm{HMG\text{-}CoA}$ 还原酶磷酸化丧失活性，磷蛋白磷酸酶可催化磷酸化 $\mathrm{HMG\text{-}CoA}$ 还原酶脱磷酸恢复酶活性。$\mathrm{HMG\text{-}CoA}$ 还原酶基因转录如果被抑制，酶蛋白合成减少，也可以引起酶活性降低。

:::compare{title="HMG-CoA 还原酶的三种调节"}
| 方式 | 教材落点 | 效应 |
|------|----------|------|
| 别构 | $\mathrm{MVA}$、胆固醇、$7\beta$-羟胆固醇、$25$-羟胆固醇 | 抑制 |
| 化学修饰 | $\mathrm{cAMP}$ 依赖性蛋白激酶使之磷酸化 | 磷酸化失活；磷蛋白磷酸酶脱磷酸恢复活性 |
| 酶含量 | 基因转录被抑制 → 酶蛋白合成减少 | 活性降低 |
:::

:::pitfall{label="磷酸化是关掉还原酶，不是打开"}
糖原磷酸化酶磷酸化后活性升高；$\mathrm{HMG\text{-}CoA}$ 还原酶相反：$\mathrm{cAMP}$ 依赖性蛋白激酶磷酸化使之丧失活性。胰高血糖素走这一笔化学修饰，后文还会再写一次。
:::

:::keypoint{label="别构抑制剂名单要写全"}
甲羟戊酸、胆固醇、$7\beta$-羟胆固醇、$25$-羟胆固醇。氧化固醇不是“另一个关键酶的底物”，而是还原酶的别构抑制剂。
:::

**3. 细胞胆固醇含量是影响胆固醇合成的主要因素之一**　主要通过改变 $\mathrm{HMG\text{-}CoA}$ 还原酶合成影响胆固醇合成。该酶在肝细胞的半衰期约为 $4$ 小时，如酶蛋白合成被阻断，酶蛋白含量在几小时内便降低。细胞胆固醇升高可抑制 $\mathrm{HMG\text{-}CoA}$ 还原酶合成，从而抑制胆固醇合成。反之，降低细胞胆固醇含量，可解除胆固醇对酶蛋白合成的抑制作用。此外，胆固醇及其氧化产物如 $7\beta$-羟胆固醇、$25$-羟胆固醇可以通过别构调节对 $\mathrm{HMG\text{-}CoA}$ 还原酶活性产生较强抑制作用。

:::definition{label="细胞胆固醇含量对合成的调节"}
细胞胆固醇含量是影响胆固醇合成的主要因素之一，主要通过改变 $\mathrm{HMG\text{-}CoA}$ 还原酶的合成。酶在肝细胞的半衰期约 $4$ 小时，合成一旦被阻断，几小时内酶量就降下来。
:::

:::cause-effect{title="细胞胆固醇升高怎样关合成"}
细胞胆固醇升高 → 抑制 $\mathrm{HMG\text{-}CoA}$ 还原酶合成（半衰期约 $4$ 小时，酶量很快下降）→ 胆固醇合成抑制。胆固醇及 $7\beta$-羟胆固醇、$25$-羟胆固醇还可别构抑制已有酶的活性。
:::

:::insight{label="外源进来的和自己写的，只要升高了细胞胆固醇，都关还原酶"}
本章小结原句：无论是外源性还是自身合成，只要升高了细胞胆固醇含量，都能抑制胆固醇合成。食物胆固醇和内源胆固醇在这一笔上是同一把钥匙。
:::

:::pitfall{label="4 小时是酶蛋白半衰期，不是血浆胆固醇半衰期"}
肝细胞 $\mathrm{HMG\text{-}CoA}$ 还原酶半衰期约 $4$ 小时，用来解释“停合成后几小时酶量就低”。血浆 LDL 半衰期是第六节的 $2\sim 4$ 天，不要串户。
:::

**4. 餐食状态影响胆固醇合成**　饥饿或禁食可抑制肝合成胆固醇。研究发现，大鼠禁食 $48$ 小时，胆固醇合成减少 $11$ 倍，禁食 $96$ 小时减少 $17$ 倍，但肝外组织的合成减少不多。禁食除使 $\mathrm{HMG\text{-}CoA}$ 还原酶活性降低外，乙酰 $\mathrm{CoA}$、$\mathrm{ATP}$、$\mathrm{NADPH}$ 不足也是胆固醇合成减少的重要原因。相反，摄取高糖、高饱和脂肪膳食，肝 $\mathrm{HMG\text{-}CoA}$ 还原酶活性增加，乙酰 $\mathrm{CoA}$、$\mathrm{ATP}$、$\mathrm{NADPH}$ 充足，胆固醇合成增加。

:::compare{title="禁食与高糖高饱和脂肪膳食"}
| 状态 | 肝 $\mathrm{HMG\text{-}CoA}$ 还原酶 | 原料（乙酰 $\mathrm{CoA}$、$\mathrm{ATP}$、$\mathrm{NADPH}$） | 肝胆固醇合成 |
|------|-------------------------------------|--------------------------------------------------------------|--------------|
| 禁食 $48$ 小时 | 活性降低 | 不足 | 减少 $11$ 倍 |
| 禁食 $96$ 小时 | 活性降低 | 不足 | 减少 $17$ 倍 |
| 高糖、高饱和脂肪膳食 | 活性增加 | 充足 | 增加 |

肝外组织在禁食时合成减少不多，主场仍在肝。
:::

:::pitfall{label="控制淀粉也能碰到胆固醇账"}
高糖膳食使肝还原酶活性增加、原料充足，胆固醇合成增加。血浆甘油三酯异常升高要不要控淀粉，思考题会问；理论根据有一笔就在这里：糖可以写成乙酰 $\mathrm{CoA}$ 和 $\mathrm{NADPH}$，既能写脂肪也能写胆固醇。
:::

:::example{label="禁食 48 小时与 96 小时不要记成同一个倍数"}
大鼠肝：禁食 $48$ 小时合成减少 $11$ 倍，$96$ 小时减少 $17$ 倍。数字只用于肝，肝外组织“减少不多”。不要把 $11$ 倍／$17$ 倍说成全身胆固醇合成。
:::

**5. 胆固醇合成受激素调节**　胰岛素及甲状腺素能诱导肝细胞 $\mathrm{HMG\text{-}CoA}$ 还原酶合成，增加胆固醇合成。甲状腺素还能促进胆固醇在肝转变为胆汁酸，所以甲状腺功能亢进患者血清胆固醇含量降低。胰高血糖素能通过化学修饰调节使 $\mathrm{HMG\text{-}CoA}$ 还原酶磷酸化失活，抑制胆固醇合成。皮质醇能抑制并降低 $\mathrm{HMG\text{-}CoA}$ 还原酶活性，减少胆固醇合成。

:::compare{title="四种激素对胆固醇合成"}
| 激素 | 对 $\mathrm{HMG\text{-}CoA}$ 还原酶 | 血清／合成后果 |
|------|-------------------------------------|----------------|
| 胰岛素 | 诱导肝细胞酶蛋白合成 | 胆固醇合成增加 |
| 甲状腺素 | 诱导酶蛋白合成；同时促进胆固醇转变为胆汁酸 | 甲亢患者血清胆固醇含量降低 |
| 胰高血糖素 | 磷酸化使酶失活 | 合成抑制 |
| 皮质醇 | 抑制并降低酶活性 | 合成减少 |
:::

:::definition{label="甲状腺素对胆固醇的双重作用"}
甲状腺素诱导肝 $\mathrm{HMG\text{-}CoA}$ 还原酶合成，增加胆固醇合成；又能促进胆固醇在肝转变为胆汁酸。甲亢患者血清胆固醇含量降低，说明转变／排出这一笔压过了合成增加。
:::

:::pitfall{label="甲亢血清胆固醇低，不是因为不能合成"}
甲状腺素其实诱导还原酶、增加合成。血清反而低，是因为同时把胆固醇加快写成胆汁酸。不要把甲亢听成“还原酶被抑制”。
:::

:::insight{label="胰岛素开合成，胰高血糖素关合成，和脂肪酸那一节同向"}
餐后胰岛素诱导还原酶；饥饿胰高血糖素经 $\mathrm{cAMP}$ 依赖性蛋白激酶把还原酶磷酸化关掉。胆固醇合成跟能量过剩走，不跟“夜里需要膜脂质”走。大鼠午夜酶活性最高，是实验节律，不要和激素的餐食调节并成同一张表。
:::

## 二、胆固醇的主要去路是转化为胆汁酸

胆固醇的母核——环戊烷多氢菲在体内不能被降解，所以胆固醇不能像糖、脂肪那样在体内被彻底分解；但其侧链可被氧化、还原或降解转变为其他具有环戊烷多氢菲母核的产物，或参与代谢调节，或排出体外。

:::definition{label="胆固醇母核不能彻底分解"}
环戊烷多氢菲母核在体内不能被降解。胆固醇不能像糖、脂肪那样彻底分解成 $\mathrm{CO}_{2}$ 和 $\mathrm{H}_{2}\mathrm{O}$；只能改侧链，写成仍带该母核的产物，或随胆汁排出。
:::

:::pitfall{label="“胆固醇代谢”不是 β-氧化"}
脂肪酸可以切成乙酰 $\mathrm{CoA}$ 再进三羧酸循环。胆固醇的环不能拆，没有“胆固醇 $\beta$-氧化”。代谢的意思是改侧链、写成胆汁酸／激素／维生素 $\mathrm{D}_{3}$，或整分子随胆汁走。
:::

在肝被转化成胆汁酸（bile acid）并随胆汁排出是胆固醇在体内代谢的主要去路。游离胆固醇也可随胆汁排出。胆固醇是肾上腺皮质、睾丸、卵巢等合成类固醇激素的原料。肾上腺皮质细胞储存大量胆固醇酯，含量可达 $2\%\sim 5\%$，$90\%$ 来自血液，$10\%$ 自身合成。肾上腺皮质球状带、束状带及网状带细胞以胆固醇为原料分别合成醛固酮、皮质醇及雄激素。睾丸间质细胞以胆固醇为原料合成睾酮，卵泡内膜细胞及黄体以胆固醇为原料合成雌二醇及孕酮。胆固醇可在皮肤被氧化为 $7$-脱氢胆固醇，经紫外光照射转变为维生素 $\mathrm{D}_{3}$。

:::definition{label="胆汁酸是胆固醇的主要去路"}
在肝被转化成胆汁酸（bile acid）并随胆汁排出，是胆固醇在体内代谢的主要去路。游离胆固醇也可随胆汁排出。
:::

:::definition{label="胆固醇作为类固醇激素原料"}
肾上腺皮质、睾丸、卵巢以胆固醇为原料合成类固醇激素。肾上腺皮质细胞储存大量胆固醇酯，含量可达 $2\%\sim 5\%$：其中 $90\%$ 来自血液，$10\%$ 自身合成。
:::

:::compare{title="胆固醇的去路"}
| 去路 | 部位 | 产物 |
|------|------|------|
| 主要 | 肝 | 胆汁酸，随胆汁排出；游离胆固醇亦可随胆汁排出 |
| 类固醇激素 | 肾上腺皮质球状带／束状带／网状带 | 醛固酮、皮质醇、雄激素 |
| 类固醇激素 | 睾丸间质细胞 | 睾酮 |
| 类固醇激素 | 卵泡内膜细胞及黄体 | 雌二醇、孕酮 |
| 维生素 $\mathrm{D}_{3}$ | 皮肤 | 胆固醇氧化为 $7$-脱氢胆固醇，紫外光照射转变为维生素 $\mathrm{D}_{3}$ |
:::

:::keypoint{label="肾上腺皮质三带对激素"}
- 球状带：醛固酮。
- 束状带：皮质醇。
- 网状带：雄激素。
- 原料都是胆固醇；贮存形式主要是胆固醇酯，大部分从血液来。
:::

:::pitfall{label="肾上腺 2%～5% 是细胞储存的胆固醇酯，不是血浆浓度"}
含量 $2\%\sim 5\%$ 写的是肾上腺皮质细胞；$90\%$ 来自血液、$10\%$ 自身合成，说明腺体主要靠摄取循环中的胆固醇（第六节 LDL 受体那一笔），不是靠自己把还原酶开到最大。
:::

:::insight{label="主要去路在肝写成胆汁酸，所以降血清胆固醇可以打这张牌"}
还原酶关掉（少写）、胆汁酸多写（多排）、游离胆固醇随胆汁走，都是“体内胆固醇往哪去”的户头。思考题问治疗血浆胆固醇异常升高有哪些措施，理论根据先落在关键酶和这条主要去路，不要先跳到药名。
:::

:::example{label="维生素 D3 不是肝把胆固醇羟化成胆汁酸的副产物"}
皮肤：胆固醇 → $7$-脱氢胆固醇 → 紫外光 → 维生素 $\mathrm{D}_{3}$。这和肝内胆汁酸是两条去路。不要把 $7$-脱氢胆固醇听成 $7\beta$-羟胆固醇——后者是还原酶的别构抑制剂，不是维生素 $\mathrm{D}$ 前体。
:::

:::memory{label="本节必背要点"}
- [ ] 胆固醇两种形式：游离胆固醇（$\mathrm{FC}$）和胆固醇酯（$\mathrm{CE}$）。
- [ ] 约 $1/4$ 在脑及神经组织；腺体 $1\%\sim 5\%$；肝最多。
- [ ] 每天合成约 $1\,\mathrm{g}$；肝 $70\%\sim 80\%$，小肠 $10\%$；成年脑、成熟红细胞不合成。
- [ ] 酶系：胞质溶胶 $+$ 光面内质网。
- [ ] 唯一碳源：乙酸／乙酰 $\mathrm{CoA}$；$18$ 乙酰 $\mathrm{CoA}$、$36\,\mathrm{ATP}$、$16\,\mathrm{NADPH}$。
- [ ] 乙酰 $\mathrm{CoA}$ 经柠檬酸出线粒体，裂解耗 $1\,\mathrm{ATP}$。
- [ ] 三阶段：$\mathrm{MVA}$ → 鲨烯（$30$ 碳）→ 羊毛固醇 → 脱 $3$ 个甲基得 $27$ 碳胆固醇。
- [ ] 线粒体 $\mathrm{HMG\text{-}CoA}$ → 酮体；胞质 $\mathrm{HMG\text{-}CoA}$ → $\mathrm{MVA}$。
- [ ] 关键酶：内质网 $\mathrm{HMG\text{-}CoA}$ 还原酶。
- [ ] 大鼠肝：午夜最高、中午最低。
- [ ] 别构抑制：$\mathrm{MVA}$、胆固醇、$7\beta$-羟胆固醇、$25$-羟胆固醇。
- [ ] 磷酸化失活，脱磷酸恢复；肝细胞酶半衰期约 $4$ 小时。
- [ ] 细胞胆固醇升高抑制酶蛋白合成；禁食肝合成减少 $11$ 倍／$17$ 倍。
- [ ] 胰岛素、甲状腺素诱导酶合成；甲亢血清胆固醇反而低（促转胆汁酸）。
- [ ] 胰高血糖素磷酸化失活；皮质醇抑制酶活性。
- [ ] 母核不能降解；主要去路：肝 → 胆汁酸。
- [ ] 旁路：类固醇激素；皮肤 $7$-脱氢胆固醇 $\xrightarrow{\text{紫外光}}$ 维生素 $\mathrm{D}_{3}$。
- [ ] $\mathrm{ACAT}$：游离胆固醇 → 胆固醇酯贮存。
:::
