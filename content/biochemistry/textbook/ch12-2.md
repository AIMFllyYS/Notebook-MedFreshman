# 第二节　代谢的相互联系

第一节把代谢写成一张动态的网：共同代谢库、两用途径、还原当量多种用途。本节把网的交叉点写出来。物质代谢与能量代谢靠乙酰 $\mathrm{CoA}$、三羧酸循环、氧化磷酸化和 $\mathrm{ATP}$ 连在一起，$\mathrm{AMPK}$ 是细胞里的能量感应器；糖、脂质、蛋白质经共同中间代谢物互相转变，但有的反应不可逆——葡萄糖可变成脂肪酸，脂肪酸不能变成葡萄糖。代谢组学则从全部小分子中间代谢物这一头看这张网的动态。

:::concept{term="先问碳骨架能不能互变，再问能量账是不是同一套 ATP"}
三大营养物质都汇入乙酰 $\mathrm{CoA}$，都经三羧酸循环和氧化磷酸化彻底氧化。互变不是完全自由：糖 $\rightarrow$ 脂容易，脂 $\rightarrow$ 糖几乎不能；氨基酸可变成多种脂质，脂质几乎不能变成氨基酸。$\mathrm{ATP}$ 把产能和耗能拴在一起，$\mathrm{AMPK}$ 在能量匮乏时把分解打开、把合成关掉。
:::

## 一、物质代谢与能量代谢相互关联

糖、脂肪及蛋白质是人体的主要能量物质。虽然这三大营养物质在体内分解氧化的代谢途径各不相同，但都有共同的中间代谢物乙酰 $\mathrm{CoA}$。三羧酸循环和氧化磷酸化是糖、脂肪、蛋白质最后分解的共同代谢途径，释出的能量以 $\mathrm{ATP}$ 形式储存。

机体的各种生命活动如生长、发育、繁殖、修复、运动，包括各种生命物质的合成等，均需要能量。人体能量的来源是营养物质，但糖、脂肪、蛋白质中的化学能不能直接用于各种生命活动。机体需氧化分解营养物质，释放出化学能，并将其大部分储存在可供各种生命活动直接利用的 $\mathrm{ATP}$ 中。$\mathrm{ATP}$ 作为机体可直接利用的能量载体，将产能的营养物质分解代谢与耗能的物质合成代谢联系在一起，将代谢与其他生命活动联系在一起。

:::definition{label="乙酰 CoA 是三大营养物质的共同中间代谢物"}
糖、脂肪及蛋白质分解氧化的途径各不相同，但都有共同的中间代谢物乙酰 $\mathrm{CoA}$。三羧酸循环和氧化磷酸化是三者最后分解的共同途径，释出的能量以 $\mathrm{ATP}$ 形式储存。
:::

:::definition{label="ATP 是可直接利用的能量载体"}
营养物质中的化学能不能直接用于生命活动。机体氧化分解营养物质，把大部分化学能储存在 $\mathrm{ATP}$ 中。$\mathrm{ATP}$ 把产能的分解代谢与耗能的合成代谢连在一起，也把代谢与生长、发育、繁殖、修复、运动等生命活动连在一起。
:::

:::insight{label="共同途径是三羧酸循环加氧化磷酸化，枢纽分子是乙酰 CoA"}
不要把“共同中间代谢物”和“共同最后途径”并成一句话了事。乙酰 $\mathrm{CoA}$ 是碳骨架的汇合点；三羧酸循环加氧化磷酸化才是彻底氧化并写成 $\mathrm{ATP}$ 的共同末端。图12-1 把乙酰 $\mathrm{CoA}$ 画在环的入口。
:::

:::pitfall{label="糖、脂肪、蛋白质的化学能不能直接做功"}
教材写明：化学能不能直接用于各种生命活动，必须先氧化分解释能，大部分装进 $\mathrm{ATP}$。说“吃糖就是能量、吃肉就是能量”，跳过了 $\mathrm{ATP}$ 这一层载体。
:::

### （一）三大营养物质在供能上互相替代、补充，也互相制约

从能量供应角度看，三大营养物质可以互相替代、互相补充，但也互相制约。一般情况下，供能以糖及脂肪为主，并尽量减少蛋白质的消耗。这不仅因为动物及人摄取的食物中以糖类最多，占总热量的 $50\%\sim 70\%$；脂肪摄入量虽然不是最多，占总热量的 $10\%\sim 40\%$，但它是机体储能的主要形式，可达体重的 $20\%$ 或更多（肥胖者可达 $30\%\sim 40\%$）；还因为蛋白质是机体最重要的组成成分、生命活动的主要执行者，通常无多余储存。

在因疾病不能进食或无食物供给时，为保证血糖恒定，肝糖异生增强，蛋白质分解加强。如饥饿持续（一周以上），长期糖异生增强使蛋白质大量分解，势必威胁生命，故机体通过调节作用转向以保存蛋白质为主，体内各组织改以脂肪酸或酮体为主要能源，蛋白质的分解明显降低。

糖、脂肪、蛋白质都通过三羧酸循环和氧化磷酸化彻底氧化供能，任一供能物质的分解代谢占优势，常能抑制其他供能物质的氧化分解。如脂肪分解增强，生成 $\mathrm{ATP}$ 增多，$\mathrm{ATP}/\mathrm{ADP}$ 比值增高，可别构抑制糖分解代谢关键酶——磷酸果糖激酶-1 的活性，从而减缓葡萄糖的分解代谢。若葡萄糖氧化分解增强，使 $\mathrm{ATP}$ 增多，可抑制异柠檬酸脱氢酶活性，导致柠檬酸堆积；后者透出线粒体，激活乙酰 $\mathrm{CoA}$ 羧化酶，促进脂肪酸合成、抑制脂肪酸分解。

:::definition{label="供能以糖和脂肪为主"}
一般情况下供能以糖及脂肪为主，并尽量减少蛋白质的消耗。食物中糖类占总热量 $50\%\sim 70\%$；脂肪占总热量 $10\%\sim 40\%$，却是储能的主要形式，可达体重的 $20\%$ 或更多（肥胖者 $30\%\sim 40\%$）。蛋白质是最重要的组成成分和生命活动的主要执行者，通常无多余储存。
:::

:::compare{title="三大营养物质的供能地位"}
| | 占总热量 | 体内角色 | 供能策略 |
|--|----------|----------|----------|
| 糖类 | $50\%\sim 70\%$（食物中最多） | 优先动用的能源 | 一般情况下的主要供能物质之一 |
| 脂肪 | $10\%\sim 40\%$ | 储能的主要形式，可达体重 $20\%$ 以上 | 与糖一起作为主要供能物质 |
| 蛋白质 | （未把供能写成主业） | 最重要组成成分、生命活动主要执行者，通常无多余储存 | 尽量少消耗；饥饿一周以上转向保存蛋白质 |
:::

:::timeline{period="饥饿时供能物质怎么换挡"}
- **不能进食** 为保证血糖恒定，肝糖异生增强，蛋白质分解加强
- **一周以上** 长期糖异生会使蛋白质大量分解，威胁生命
- **转向保存蛋白质** 各组织改以脂肪酸或酮体为主要能源
- **蛋白质分解明显降低** 这是整体调节的结果，第三节饥饿段还要展开数字
:::

:::cause-effect{title="脂肪分解占优势为什么能把糖酵解关掉"}
- **因** 脂肪分解增强，$\mathrm{ATP}$ 增多，$\mathrm{ATP}/\mathrm{ADP}$ 增高，别构抑制磷酸果糖激酶-1
- **果** 葡萄糖分解减缓。任一供能物质的分解占优势，常能抑制其他供能物质的氧化分解
:::

:::cause-effect{title="葡萄糖氧化增强为什么反而促进脂肪酸合成"}
- **因** 葡萄糖氧化分解增强，$\mathrm{ATP}$ 增多，抑制异柠檬酸脱氢酶，柠檬酸堆积并透出线粒体，激活乙酰 $\mathrm{CoA}$ 羧化酶
- **果** 促进脂肪酸合成、抑制脂肪酸分解。碳骨架和能量都充足时，多余的糖写成脂肪
:::

:::pitfall{label="互相替代不等于可以完全互相转变"}
供能上可以替代、补充、制约。碳骨架互变另有不可逆步骤（本节第二部分）：脂肪酸不能变成葡萄糖，脂质几乎不能变成氨基酸。不要把“都能彻底氧化成 ATP”听成“三种物质可以随便改写”。
:::

:::keypoint{label="供能账四句话"}
- 共同末端：乙酰 $\mathrm{CoA}$ $\rightarrow$ 三羧酸循环 $+$ 氧化磷酸化 $\rightarrow$ $\mathrm{ATP}$。
- 日常：糖 $+$ 脂肪为主，保护蛋白质。
- 饥饿一周以上：改用脂肪酸或酮体，蛋白质分解明显降低。
- 占优势的那一条会通过 $\mathrm{ATP}$、柠檬酸等别构信号抑制其他条。
:::

### （二）AMPK 感受微环境能量变化

除了营养物氧化分解提供能量满足机体自身的需求外，细胞所处微环境的能量变化也可诱发细胞内代谢变化。细胞内存在特殊的分子感应器，如 $\mathrm{AMP}$ 激活的蛋白激酶（AMP-activated protein kinase，$\mathrm{AMPK}$），能够感受微环境中能量变化而促进分解代谢。

$\mathrm{AMPK}$ 是一种在细胞内进行能量代谢调节的蛋白激酶，由 $\alpha$、$\beta$ 和 $\gamma$ 三种亚基组成，相当于细胞内的“能量感应器”。$\mathrm{AMPK}$ 主要在能量匮乏、营养状态不良时被激活，$\mathrm{AMP}/\mathrm{ATP}$ 比值是调控其活性的重要因素。其激活方式主要是化学修饰调节和别构调节。$\mathrm{AMPK}$ 活化后，催化众多底物蛋白（包括关键酶、转录因子等）发生广泛的磷酸化反应，一方面激活产能的分解代谢，另一方面抑制耗能的合成代谢，并协调整合骨骼肌、肝、脂肪组织、心等重要器官代谢，最主要的效应是加快分解糖和脂肪酸，以便满足能量供应需求。此外，$\mathrm{AMPK}$ 还可抑制蛋白质的合成。

:::definition{label="AMPK"}
$\mathrm{AMP}$ 激活的蛋白激酶（AMP-activated protein kinase，$\mathrm{AMPK}$）由 $\alpha$、$\beta$、$\gamma$ 三种亚基组成，是细胞内的“能量感应器”。主要在能量匮乏、营养状态不良时被激活，$\mathrm{AMP}/\mathrm{ATP}$ 比值是调控其活性的重要因素。激活方式主要是化学修饰调节和别构调节。
:::

:::definition{label="AMPK 活化后的代谢效应"}
催化众多底物蛋白（关键酶、转录因子等）广泛磷酸化：激活产能的分解代谢，抑制耗能的合成代谢；协调整合骨骼肌、肝、脂肪组织、心等器官代谢。最主要效应是加快分解糖和脂肪酸。还可抑制蛋白质合成。
:::

:::compare{title="ATP/ADP 别构与 AMPK 感应不要并户"}
| | 信号 | 本节落到的效应 |
|--|------|----------------|
| 磷酸果糖激酶-1、异柠檬酸脱氢酶等 | $\mathrm{ATP}/\mathrm{ADP}$ 等直接别构 | 脂肪分解占优势时减慢糖分解；糖氧化占优势时经柠檬酸促进脂肪酸合成 |
| $\mathrm{AMPK}$ | $\mathrm{AMP}/\mathrm{ATP}$ 升高时激活 | 能量匮乏时开分解、关合成，加快分解糖和脂肪酸，并抑制蛋白质合成 |

前者是关键酶当场听 $\mathrm{ATP}$；后者是蛋白激酶把信号磷酸化放大，并整合多器官。
:::

:::pitfall{label="AMPK 的比值是 AMP/ATP，不是 ATP/ADP"}
调控 $\mathrm{AMPK}$ 活性的重要因素是 $\mathrm{AMP}/\mathrm{ATP}$。前面别构抑制磷酸果糖激酶-1 用的是 $\mathrm{ATP}/\mathrm{ADP}$。两套比值不要抄反。
:::

:::insight{label="第三节的化学修饰在这里先露头"}
$\mathrm{AMPK}$ 的激活方式已经点名化学修饰和别构。活化后对关键酶、转录因子广泛磷酸化，一边开分解一边关合成。级联放大、磷酸化位点的一般规则在第三节展开。
:::

:::keypoint{label="AMPK 先背这几句"}
- 组成：$\alpha$、$\beta$、$\gamma$ 三种亚基，能量感应器。
- 何时激活：能量匮乏、营养不良；$\mathrm{AMP}/\mathrm{ATP}$ 是重要因素。
- 方式：化学修饰 $+$ 别构。
- 效应：开分解、关合成；加快分解糖和脂肪酸；抑制蛋白质合成；整合肌、肝、脂肪、心。
:::

## 二、糖、脂质和蛋白质代谢通过中间代谢物而相互联系

体内糖、脂质、蛋白质和核酸等的代谢不是彼此孤立的，而是通过共同的中间代谢物、三羧酸循环和生物氧化等彼此联系、相互转变（图12-1）。一种物质的代谢障碍可引起其他物质的代谢紊乱，如糖尿病时糖代谢的障碍，可引起脂质代谢、蛋白质代谢甚至水盐代谢和酸碱平衡紊乱。

:::definition{label="糖、脂质、蛋白质、核酸经中间代谢物联系"}
它们通过共同的中间代谢物、三羧酸循环和生物氧化彼此联系、相互转变。一种物质的代谢障碍可引起其他物质的代谢紊乱。
:::

:::insight{label="糖尿病是这张网被撕开的临床例子"}
教材只点到：糖尿病时糖代谢障碍，可引起脂质代谢、蛋白质代谢甚至水盐代谢和酸碱平衡紊乱。不要在这里另写病理生理学病程；记住“一处卡住，邻路跟着乱”。
:::

:::pitfall{label="图12-1 的虚线是“不能逆行”，不是可逆"}
乙酰 $\mathrm{CoA}$ 指向丙酮酸的那一笔是虚线。脂肪酸 $\beta$-氧化生成的乙酰 $\mathrm{CoA}$ 不能逆行转变为丙酮酸，这是“脂不能变糖”的分子原因。把图上所有箭头都看成可逆，思考题第 1 题的枢纽物质会背错方向。
:::

### （一）葡萄糖可转变为脂肪酸但脂肪酸不能转变为葡萄糖

当摄入的葡萄糖超过体内需要时，除合成少量糖原储存在肝及肌外，葡萄糖氧化分解过程中生成的柠檬酸及最终产生的 $\mathrm{ATP}$ 增多，可别构激活乙酰 $\mathrm{CoA}$ 羧化酶，使葡萄糖分解产生的乙酰 $\mathrm{CoA}$ 羧化成丙二酸单酰辅酶 $\mathrm{A}$，进而合成脂肪酸及脂肪。这样，可把葡萄糖转变成脂肪储存于脂肪组织。所以，摄取不含脂肪的高糖膳食过多，也能使人血浆甘油三酯升高，并导致肥胖。

但是，脂肪分解产生的脂肪酸不能在体内转变为葡萄糖，因为脂肪酸分解生成的乙酰 $\mathrm{CoA}$ 不能逆行转变为丙酮酸。尽管脂肪分解产生的甘油可以在肝、肾、肠等组织甘油激酶的作用下转变成磷酸甘油，进而转变成糖，但与脂肪中大量脂肪酸分解生成的乙酰 $\mathrm{CoA}$ 相比，其量极少。

此外，脂肪酸分解代谢能否顺利进行及其强度，还依赖于糖代谢状况。当饥饿、糖供给不足或糖代谢障碍时，尽管脂肪可以大量动员，并在肝经 $\beta$-氧化生成大量酮体，但由于糖代谢不能满足相应的需要，草酰乙酸生成相对或绝对不足，导致大量酮体不能进入三羧酸循环氧化，在血中蓄积，造成高酮血症。

:::definition{label="葡萄糖转变为脂肪"}
摄入葡萄糖超过需要时，除肝、肌合成少量糖原外，柠檬酸及 $\mathrm{ATP}$ 增多，别构激活乙酰 $\mathrm{CoA}$ 羧化酶，乙酰 $\mathrm{CoA}$ 羧化成丙二酸单酰 $\mathrm{CoA}$，进而合成脂肪酸及脂肪，储存于脂肪组织。不含脂肪的高糖膳食过多，也能使血浆甘油三酯升高并导致肥胖。
:::

:::definition{label="脂肪酸不能转变为葡萄糖"}
脂肪酸分解生成的乙酰 $\mathrm{CoA}$ 不能逆行转变为丙酮酸，故脂肪酸不能在体内转变为葡萄糖。脂肪中的甘油可在肝、肾、肠等组织经甘油激酶变成磷酸甘油再变成糖，但与大量乙酰 $\mathrm{CoA}$ 相比其量极少。
:::

:::definition{label="高酮血症与草酰乙酸不足"}
饥饿、糖供给不足或糖代谢障碍时，脂肪大量动员，肝 $\beta$-氧化生成大量酮体；糖代谢不能满足需要，草酰乙酸相对或绝对不足，酮体不能进入三羧酸循环氧化，在血中蓄积，造成高酮血症。
:::

:::compare{title="糖变脂容易，脂变糖几乎不能"}
| 方向 | 能否转变 | 关键限制 |
|------|----------|----------|
| 葡萄糖 $\rightarrow$ 脂肪酸／脂肪 | 能 | 乙酰 $\mathrm{CoA}$ 羧化酶被柠檬酸、$\mathrm{ATP}$ 别构激活；丙二酸单酰 $\mathrm{CoA}$ 往下合成 |
| 脂肪酸 $\rightarrow$ 葡萄糖 | 不能 | 乙酰 $\mathrm{CoA}$ 不能逆行成丙酮酸 |
| 甘油 $\rightarrow$ 糖 | 能，但量极少 | 肝、肾、肠的甘油激酶 $\rightarrow$ 磷酸甘油 $\rightarrow$ 糖 |
:::

:::cause-effect{title="高糖膳食不含脂肪为什么仍能升高血浆甘油三酯"}
- **因** 多余葡萄糖经乙酰 $\mathrm{CoA}$、丙二酸单酰 $\mathrm{CoA}$ 写成脂肪酸和脂肪
- **果** 血浆甘油三酯升高，并可导致肥胖。脂肪不一定要从膳食脂肪来
:::

:::pitfall{label="酮体堆积不是“脂肪动员不够”，而是糖这边配不上"}
教材把高酮血症写成：脂肪可以大量动员并在肝生成大量酮体，但草酰乙酸不足，酮体进不了三羧酸循环。不要答成“脂肪动员障碍”。糖供给不足或糖代谢障碍时，脂动员越猛，酮体越容易堆。
:::

:::insight{label="乙酰 CoA 羧化酶在上一小节已经出现过一次"}
葡萄糖氧化增强 $\rightarrow$ $\mathrm{ATP}$ 抑制异柠檬酸脱氢酶 $\rightarrow$ 柠檬酸透出线粒体 $\rightarrow$ 激活乙酰 $\mathrm{CoA}$ 羧化酶。本小节把同一开关写成“多余的糖变成脂肪”。两条叙述是同一条别构链。
:::

:::keypoint{label="糖与脂交叉"}
- 糖 $\rightarrow$ 脂：乙酰 $\mathrm{CoA}$ 羧化酶。
- 脂 $\rightarrow$ 糖：脂肪酸不能；甘油能但极少。
- 脂分解依赖糖：草酰乙酸不够则酮体堆积。
:::

### （二）葡萄糖与大部分氨基酸可以相互转变

组成人体蛋白质的 $20$ 种氨基酸中，除生酮氨基酸（亮氨酸、赖氨酸）外，都可通过脱氨作用生成相应的 $\alpha$-酮酸。这些 $\alpha$-酮酸可转变成某些能进入糖异生途径的中间代谢物，循糖异生途径转变为葡萄糖。如丙氨酸经脱氨基作用生成的丙酮酸，可异生为葡萄糖；精氨酸、组氨酸、脯氨酸可先转变成谷氨酸，进一步脱氨生成 $\alpha$-酮戊二酸，再经草酰乙酸、磷酸烯醇式丙酮酸异生为葡萄糖。

葡萄糖代谢的一些中间代谢物，如丙酮酸、$\alpha$-酮戊二酸、草酰乙酸等也可氨基化成某些非必需氨基酸。但苏氨酸、甲硫氨酸、赖氨酸、亮氨酸、异亮氨酸、缬氨酸、苯丙氨酸、组氨酸及色氨酸等 $9$ 种氨基酸不能由糖代谢中间物转变而来。总之，$20$ 种氨基酸除亮氨酸及赖氨酸外均可转变为糖，而糖代谢中间代谢物仅能在体内转变成 $11$ 种非必需氨基酸。

:::definition{label="生酮氨基酸"}
生酮氨基酸为亮氨酸、赖氨酸。二者不能经脱氨后的 $\alpha$-酮酸进入糖异生。其余氨基酸都可通过脱氨生成相应 $\alpha$-酮酸，再进入糖异生。
:::

:::definition{label="氨基酸与葡萄糖的互变范围"}
$20$ 种氨基酸除亮氨酸及赖氨酸外均可转变为糖。糖代谢中间代谢物仅能转变成 $11$ 种非必需氨基酸。苏氨酸、甲硫氨酸、赖氨酸、亮氨酸、异亮氨酸、缬氨酸、苯丙氨酸、组氨酸及色氨酸等 $9$ 种氨基酸不能由糖代谢中间物转变而来。
:::

:::compare{title="氨基酸变糖的两条教材例题"}
| 氨基酸 | 先变成什么 | 再怎么异生成糖 |
|--------|------------|----------------|
| 丙氨酸 | 脱氨基 $\rightarrow$ 丙酮酸 | 直接进入糖异生 |
| 精氨酸、组氨酸、脯氨酸 | 先变成谷氨酸，再脱氨 $\rightarrow$ $\alpha$-酮戊二酸 | 经草酰乙酸、磷酸烯醇式丙酮酸异生为葡萄糖 |
:::

:::compare{title="糖变氨基酸的限度"}
| 能由糖代谢中间物氨基化而来 | 不能由糖代谢中间物转变而来（$9$ 种） |
|------------------------------|--------------------------------------|
| $11$ 种非必需氨基酸；中间物如丙酮酸、$\alpha$-酮戊二酸、草酰乙酸 | 苏氨酸、甲硫氨酸、赖氨酸、亮氨酸、异亮氨酸、缬氨酸、苯丙氨酸、组氨酸、色氨酸 |
:::

:::pitfall{label="“大部分氨基酸可与葡萄糖互变”不是 20 种都能来回走"}
变糖：只排除亮氨酸、赖氨酸（生酮）。糖变氨基酸：只能写成 $11$ 种非必需氨基酸，另 $9$ 种不能由糖中间物来。互变是不对称的。
:::

:::insight{label="图12-1 右侧和环上能对上这些例"}
丙氨酸 $\leftrightarrow$ 丙酮酸；谷氨酸 $\leftrightarrow$ $\alpha$-酮戊二酸，上游有精氨酸、组氨酸、脯氨酸；天冬氨酸 $\leftrightarrow$ 草酰乙酸。蓝框枢纽就是这些 $\alpha$-酮酸。
:::

:::keypoint{label="糖与氨基酸交叉"}
- 生酮氨基酸：亮氨酸、赖氨酸，不能变糖。
- 其余 $18$ 种可经 $\alpha$-酮酸走糖异生。
- 糖只能变成 $11$ 种非必需氨基酸。
- $9$ 种不能由糖中间物生成：苏、甲硫、赖、亮、异亮、缬、苯丙、组、色氨酸。
:::

### （三）氨基酸可转变为多种脂质但脂质几乎不能转变为氨基酸

体内的氨基酸，无论是生糖氨基酸、生酮氨基酸（亮氨酸、赖氨酸），还是生酮兼生糖氨基酸（异亮氨酸、苯丙氨酸、色氨酸、酪氨酸、苏氨酸），均能分解生成乙酰 $\mathrm{CoA}$，经还原缩合反应可合成脂肪酸，进而合成脂肪。氨基酸分解产生的乙酰 $\mathrm{CoA}$ 也可用于合成胆固醇。氨基酸还可作为合成磷脂的原料，如丝氨酸脱羧可变为胆胺，胆胺经甲基化可变为胆碱。丝氨酸、胆胺及胆碱分别是合成丝氨酸磷脂、脑磷脂及卵磷脂的原料。所以，氨基酸能转变为多种脂质。

但脂肪酸、胆固醇等脂质不能转变为氨基酸，仅脂肪中的甘油可转变为某些非必需氨基酸，但量很少。

:::definition{label="生酮兼生糖氨基酸"}
生酮兼生糖氨基酸为异亮氨酸、苯丙氨酸、色氨酸、酪氨酸、苏氨酸。它们与生糖、生酮氨基酸一样，都能分解生成乙酰 $\mathrm{CoA}$。
:::

:::definition{label="氨基酸转变为脂质"}
各类氨基酸都能分解生成乙酰 $\mathrm{CoA}$，经还原缩合合成脂肪酸进而合成脂肪，也可合成胆固醇。丝氨酸脱羧成胆胺，胆胺甲基化成胆碱；丝氨酸、胆胺、胆碱分别是丝氨酸磷脂、脑磷脂、卵磷脂的原料。
:::

:::definition{label="脂质几乎不能转变为氨基酸"}
脂肪酸、胆固醇等脂质不能转变为氨基酸。仅脂肪中的甘油可转变为某些非必需氨基酸，但量很少。
:::

:::compare{title="氨基酸与脂质的单向优势"}
| 方向 | 能否转变 | 途径要点 |
|------|----------|----------|
| 氨基酸 $\rightarrow$ 脂肪酸／脂肪 | 能 | 乙酰 $\mathrm{CoA}$ 还原缩合 |
| 氨基酸 $\rightarrow$ 胆固醇 | 能 | 乙酰 $\mathrm{CoA}$ |
| 氨基酸 $\rightarrow$ 磷脂 | 能 | 丝氨酸、胆胺、胆碱 |
| 脂肪酸、胆固醇 $\rightarrow$ 氨基酸 | 不能 | — |
| 甘油 $\rightarrow$ 某些非必需氨基酸 | 能，量很少 | — |
:::

:::pitfall{label="生酮氨基酸也能写成脂肪，不要只让它们“生酮”"}
亮氨酸、赖氨酸不能变糖，但能分解生成乙酰 $\mathrm{CoA}$，一样可以还原缩合成脂肪酸。生酮、生糖、兼生三类在“变成脂质”这一头是同一条乙酰 $\mathrm{CoA}$ 出路。
:::

:::keypoint{label="氨基酸与脂质交叉"}
- 三类氨基酸都能经乙酰 $\mathrm{CoA}$ 写脂肪酸、胆固醇。
- 丝氨酸 $\rightarrow$ 胆胺 $\rightarrow$ 胆碱，对应三类甘油磷脂原料。
- 脂 $\rightarrow$ 氨基酸几乎不能；甘油量很少。
:::

### （四）一些氨基酸、戊糖磷酸是合成核苷酸的原料

嘌呤碱从头合成需要甘氨酸、天冬氨酸、谷氨酰胺和一碳单位为原料；嘧啶碱从头合成需要天冬氨酸、谷氨酰胺和一碳单位为原料。一碳单位是一些氨基酸在分解过程中产生的。这些氨基酸可直接作为核苷酸合成的原料，也可转化成核苷酸合成的原料。核苷酸中的另一成分戊糖磷酸是葡萄糖经戊糖磷酸途径分解的重要产物。所以，葡萄糖和一些氨基酸可在体内转化为核酸分子的组成成分。

:::definition{label="核苷酸从头合成的氨基酸原料"}
嘌呤碱：甘氨酸、天冬氨酸、谷氨酰胺和一碳单位。嘧啶碱：天冬氨酸、谷氨酰胺和一碳单位。一碳单位来自一些氨基酸的分解。
:::

:::definition{label="戊糖磷酸来自葡萄糖"}
核苷酸中的戊糖磷酸是葡萄糖经戊糖磷酸途径分解的重要产物。葡萄糖和一些氨基酸可在体内转化为核酸分子的组成成分。
:::

:::compare{title="嘌呤与嘧啶从头合成的原料差在甘氨酸"}
| | 甘氨酸 | 天冬氨酸 | 谷氨酰胺 | 一碳单位 | 戊糖磷酸 |
|--|--------|----------|----------|----------|----------|
| 嘌呤碱 | 需要 | 需要 | 需要 | 需要 | 来自戊糖磷酸途径 |
| 嘧啶碱 | 不在本名单 | 需要 | 需要 | 需要 | 同上 |
:::

:::insight{label="图12-1 把核糖-5-磷酸接到核苷酸，甘氨酸接到嘌呤和血红素"}
戊糖磷酸途径从葡萄糖-6-磷酸分出。甘氨酸蓝框指向嘌呤、血红素；天冬氨酸指向天冬酰胺、嘌呤、嘧啶；谷氨酰胺指向嘌呤。核酸不是另起一张与糖、氨基酸无关的网。
:::

:::keypoint{label="通向核酸的两块砖"}
- 碱基：若干氨基酸 $+$ 一碳单位。
- 戊糖磷酸：葡萄糖的戊糖磷酸途径。
:::

:::memory{label="三大营养物质互变的不可逆边界"}
- 糖 $\rightarrow$ 脂：能。脂（脂肪酸）$\rightarrow$ 糖：不能。
- 大部分氨基酸 $\leftrightarrow$ 糖：能，但不对称（$18$ 种可变糖，糖只能成 $11$ 种非必需氨基酸）。
- 氨基酸 $\rightarrow$ 多种脂质：能。脂质 $\rightarrow$ 氨基酸：几乎不能。
- 糖 $+$ 氨基酸 $\rightarrow$ 核苷酸组分：能。
:::

## 三、代谢组学研究代谢物的整体变化

细胞内的生命活动大多发生于代谢层面，因此代谢物的变化更直接地反映了细胞所处的环境，如营养状态、药物作用和环境变化等。代谢组学（metabonomics）是测定一个生物／细胞中所有的小分子中间代谢物组成，描绘其动态变化规律，建立系统代谢图谱，并确定这些变化与生物过程的联系。

代谢组学是一门新兴技术，国际上有两个专业名词进行命名，分别是代谢组学（metabonomics）和代谢物组学（metabolomics）。一般来说，在植物、微生物领域大多用代谢物组学，在药物研究和疾病诊断中一般用代谢组学。但现在这两个定义逐渐模糊化，没有特别的区分。

:::definition{label="代谢组学"}
代谢组学（metabonomics）测定一个生物／细胞中所有的小分子中间代谢物组成，描绘其动态变化规律，建立系统代谢图谱，并确定这些变化与生物过程的联系。代谢物的变化更直接地反映营养状态、药物作用和环境变化等。
:::

:::compare{title="metabonomics 与 metabolomics"}
| 名词 | 教材给出的使用场合 |
|------|----------------------|
| 代谢组学（metabonomics） | 药物研究和疾病诊断中一般用这个 |
| 代谢物组学（metabolomics） | 植物、微生物领域大多用这个 |
| 现在 | 两个定义逐渐模糊，没有特别区分 |
:::

:::pitfall{label="代谢组学测的是小分子中间代谢物，不是基因组或蛋白质组"}
对象是“所有的小分子中间代谢物”。与基因组学、蛋白质组学相比，代谢组学与临床的联系更为紧密（本小节第三部分），但不要把它写成测基因或测酶蛋白。
:::

### （一）代谢组学的任务是分析生物／细胞代谢产物的全貌

根据研究的对象和目的不同，可以将对生物体系的代谢产物分析分为四个层次：①代谢物靶标分析（metabolite target analysis）：对某个或某几个特定组分进行分析；②代谢谱分析（metabolic profiling analysis）：对一系列预先设定的目标代谢物进行定量分析，如某一类结构、性质相关的化合物，或某一代谢途径中所有代谢物，或一组由多条代谢途径共享的代谢物；③代谢组学：对某一生物或细胞所有代谢物进行定性和定量分析；④代谢指纹分析（metabolic fingerprinting analysis）：不分离鉴定具体单一组分，而是对代谢物整体进行高通量的定性分析。

代谢组学主要以生物体液为研究对象，如血样、尿样等，另外还可采用完整的组织样品、组织提取液或细胞培养液等进行研究。血样中的内源性代谢产物比较丰富，信息量较大，有利于观测体内代谢水平的全貌和动态变化过程。尽管尿样所含的信息量相对有限，但样品采集不具损伤性。

:::definition{label="代谢物靶标分析"}
代谢物靶标分析（metabolite target analysis）对某个或某几个特定组分进行分析。
:::

:::definition{label="代谢谱分析"}
代谢谱分析（metabolic profiling analysis）对一系列预先设定的目标代谢物进行定量分析，例如某一类结构、性质相关的化合物，或某一代谢途径中所有代谢物，或一组由多条代谢途径共享的代谢物。
:::

:::definition{label="代谢指纹分析"}
代谢指纹分析（metabolic fingerprinting analysis）不分离鉴定具体单一组分，而对代谢物整体进行高通量的定性分析。
:::

:::compare{title="代谢产物分析的四个层次"}
| 层次 | 做什么 |
|------|--------|
| 代谢物靶标分析 | 某个或某几个特定组分 |
| 代谢谱分析 | 预先设定的一组目标物，定量 |
| 代谢组学 | 某一生物或细胞所有代谢物，定性 $+$ 定量 |
| 代谢指纹分析 | 不鉴定单一组分，整体高通量定性 |
:::

:::compare{title="血样与尿样"}
| 样品 | 优点 | 限制 |
|------|------|------|
| 血样 | 内源性代谢产物较丰富，信息量较大，利于看全貌和动态 | （本节未把采集写成无损伤） |
| 尿样 | 采集不具损伤性 | 信息量相对有限 |
| 其他 | 完整组织样品、组织提取液、细胞培养液 | — |
:::

:::insight{label="四个层次不要都叫做代谢组学"}
只有“对某一生物或细胞所有代谢物进行定性和定量分析”这一层，教材直接叫代谢组学。靶标是几个组分，谱分析是预定的一组，指纹是不拆开的整体定性。
:::

### （二）核磁共振、色谱及质谱是代谢组学的主要分析工具

由于代谢物的多样性，常需采用多种分离和分析手段，其中，核磁共振（nuclear magnetic resonance，$\mathrm{NMR}$）、色谱及质谱（mass spectroscopy，$\mathrm{MS}$）等技术是最主要的分析工具（图12-2）。

①$\mathrm{NMR}$：是当前代谢组学研究中的主要技术。代谢组学中常用的 $\mathrm{NMR}$ 谱是氢谱（$^{1}\mathrm{H}$-$\mathrm{NMR}$）、碳谱（$^{13}\mathrm{C}$-$\mathrm{NMR}$）及磷谱（$^{31}\mathrm{P}$-$\mathrm{NMR}$）。②$\mathrm{MS}$：按质荷比（$m/z$）进行各种代谢物的定性或定量分析，可得到相应的代谢产物谱。③色谱等其他技术：在代谢组学中的色谱技术主要有气相色谱（$\mathrm{GC}$）、液相色谱（$\mathrm{LC}$）、高效液相色谱（$\mathrm{HPLC}$）、超高效液相色谱（$\mathrm{UPLC}$）、薄层色谱（$\mathrm{TLC}$）等，以及毛细管电泳（$\mathrm{CE}$）、傅里叶转换红外线光谱（$\mathrm{FTIR}$）、傅里叶转换拉曼光谱等技术。④色谱-质谱联用技术：这种联用技术使样品的分离、定性、定量一次完成，具有较高的灵敏度和选择性。目前常用的联用技术包括气相色谱-质谱（$\mathrm{GC}$-$\mathrm{MS}$）联用和液相色谱-质谱（$\mathrm{LC}$-$\mathrm{MS}$）联用等。

::figure{src="/images/biochemistry/textbook/p0262_01.png" caption="图12-2　代谢组学研究的技术系统及手段。样品来自生物体、器官、组织、细胞，分离体与在体。离体提取液可走 LC、TLC、GC、CE、HPLC/UPLC 及 LC-NMR-MS；GC、CE、HPLC/UPLC 再进入 MS，CE 与 HPLC/UPLC 也可进入 NMR，HPLC/UPLC 还可进入 UV；在体可走 NMR、FTIR、FT-Raman。各路汇入代谢组学数据。" alt="从生物体样品经离体提取液或在体检测，由色谱、电泳、NMR、MS 等汇入代谢组学数据"}

:::definition{label="代谢组学的主要分析工具"}
核磁共振（$\mathrm{NMR}$）、色谱及质谱（$\mathrm{MS}$）是最主要的分析工具。$\mathrm{NMR}$ 是当前代谢组学研究中的主要技术，常用 $^{1}\mathrm{H}$-$\mathrm{NMR}$、$^{13}\mathrm{C}$-$\mathrm{NMR}$、$^{31}\mathrm{P}$-$\mathrm{NMR}$。
:::

:::definition{label="质谱按质荷比分析"}
质谱按质荷比（$m/z$）对各种代谢物进行定性或定量分析，得到相应的代谢产物谱。
:::

:::definition{label="色谱-质谱联用"}
联用使样品的分离、定性、定量一次完成，灵敏度和选择性较高。目前常用 $\mathrm{GC}$-$\mathrm{MS}$ 和 $\mathrm{LC}$-$\mathrm{MS}$。
:::

### （三）代谢组学技术在生物医学领域具有广阔的应用前景

代谢组学所关注的是小分子代谢物的变化情况及其规律，反映的是内、外环境刺激下细胞、组织或机体的代谢应答变化。与基因组学和蛋白质组学相比，代谢组学与临床的联系更为紧密。疾病导致体内病理生理过程变化，可引起代谢产物发生相应的改变。因此，开展疾病代谢组研究可以提供疾病（如某些肿瘤、肝疾病、遗传性代谢病等）诊断、预后和治疗的评判标准，并有助于加深对疾病发生、发展机制的了解。

此外，利用代谢组学技术可以快速检测毒物和药物在体内的代谢产物和对机体代谢的影响，有利于判定毒物、药物的代谢规律，为深入阐明毒物中毒机制和发展个体化用药提供理论依据；利用代谢组学技术对代谢网络中的酶功能进行有效的整体性分析，可以发现已知酶的新活性并发掘未知酶的功能。最后，由于代谢组学分析技术具有整体性、分辨率高等特点，可广泛应用于中药作用机制、复方配伍、毒性和安全性等方面的研究，为中药现代化提供技术支撑。

:::definition{label="代谢组学与临床的联系"}
它反映内、外环境刺激下细胞、组织或机体的代谢应答。与基因组学和蛋白质组学相比，与临床的联系更为紧密。疾病引起代谢产物改变，可用于某些肿瘤、肝疾病、遗传性代谢病等的诊断、预后和治疗评判，并帮助了解发生、发展机制。
:::

:::keypoint{label="代谢组学的应用四块"}
- 疾病代谢组：诊断、预后、治疗评判，以及机制。
- 毒物／药物：体内代谢产物及对机体代谢的影响，服务中毒机制和个体化用药。
- 酶功能整体分析：发现已知酶的新活性，发掘未知酶功能。
- 中药：作用机制、复方配伍、毒性与安全性，为中药现代化提供技术支撑。
:::

:::insight{label="代谢组学是用分析手段把第一节的“网”拍成全貌"}
第一节说中间代谢物不堆不缺、库在更新。代谢组学把“所有小分子中间代谢物”测出来，看营养、药物、环境怎么改这张网。它不替代关键酶调节，只是观测层。
:::

:::memory{label="本节必背要点"}
- [ ] 三大营养物质途径不同，共同中间物是乙酰 $\mathrm{CoA}$；共同末端是三羧酸循环 $+$ 氧化磷酸化 $\rightarrow$ $\mathrm{ATP}$。
- [ ] $\mathrm{ATP}$ 是可直接利用的能量载体，连接分解与合成、代谢与生命活动。
- [ ] 日常供能以糖、脂肪为主，保护蛋白质。糖类占总热量 $50\%\sim 70\%$；脂肪 $10\%\sim 40\%$，储能可达体重 $20\%$ 以上（肥胖 $30\%\sim 40\%$）。
- [ ] 饥饿一周以上：改用脂肪酸或酮体，蛋白质分解明显降低。
- [ ] 脂肪分解占优势：$\mathrm{ATP}/\mathrm{ADP}$ 升高，别构抑制磷酸果糖激酶-1。
- [ ] 葡萄糖氧化占优势：$\mathrm{ATP}$ 抑制异柠檬酸脱氢酶 $\rightarrow$ 柠檬酸激活乙酰 $\mathrm{CoA}$ 羧化酶 $\rightarrow$ 促脂合成、抑脂分解。
- [ ] $\mathrm{AMPK}$：$\alpha\beta\gamma$ 能量感应器；$\mathrm{AMP}/\mathrm{ATP}$；化学修饰 $+$ 别构；开分解、关合成；加快分解糖和脂肪酸；抑制蛋白质合成。
- [ ] 一种物质代谢障碍可牵动其他物质，如糖尿病。
- [ ] 糖 $\rightarrow$ 脂能；脂肪酸 $\rightarrow$ 糖不能（乙酰 $\mathrm{CoA}$ 不能逆成丙酮酸）；甘油可变糖但极少。
- [ ] 高糖无脂膳食过多仍可升高血浆甘油三酯并致肥胖。
- [ ] 草酰乙酸不足 $\rightarrow$ 酮体不能进三羧酸循环 $\rightarrow$ 高酮血症。
- [ ] 生酮氨基酸：亮氨酸、赖氨酸。$18$ 种可变糖；糖只能成 $11$ 种非必需氨基酸。
- [ ] $9$ 种不能由糖中间物生成：苏、甲硫、赖、亮、异亮、缬、苯丙、组、色氨酸。
- [ ] 生酮兼生糖：异亮、苯丙、色、酪、苏氨酸。三类都能经乙酰 $\mathrm{CoA}$ 写脂肪酸、胆固醇。
- [ ] 丝氨酸、胆胺、胆碱 $\rightarrow$ 丝氨酸磷脂、脑磷脂、卵磷脂。脂质几乎不能变氨基酸。
- [ ] 嘌呤：甘氨酸、天冬氨酸、谷氨酰胺、一碳单位；嘧啶：天冬氨酸、谷氨酰胺、一碳单位；戊糖磷酸来自戊糖磷酸途径。
- [ ] 代谢组学：全部小分子中间代谢物的组成、动态、系统图谱及其与生物过程的联系。
- [ ] 四层次：靶标、谱分析、代谢组学、指纹分析。血样信息量大，尿样无损伤。
- [ ] 主要工具：$\mathrm{NMR}$（当前主要）、色谱、质谱；常用 $^{1}\mathrm{H}/^{13}\mathrm{C}/^{31}\mathrm{P}$-$\mathrm{NMR}$，$\mathrm{GC}$-$\mathrm{MS}$、$\mathrm{LC}$-$\mathrm{MS}$。
:::
