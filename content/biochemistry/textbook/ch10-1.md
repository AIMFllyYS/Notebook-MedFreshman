# 第一节　生物氧化与能量代谢

本章打开生物氧化。糖、脂肪、蛋白质储存的化学能不能被细胞直接花掉，必须经氧化分解转成机体可直接利用的形式，核心是 $\mathrm{ATP}$。本节先把户头摊开：什么叫生物氧化、氧化还原电位怎样变成自由能、营养物质氧化怎样产热和产 $\mathrm{ATP}$；再把 $\mathrm{ATP}$ 写成能量代谢的中心——高能磷酸键、基团转移、腺苷酸激酶与核苷二磷酸激酶、磷酸肌酸缓冲。$\mathrm{NADH}$ 进呼吸链产 $\mathrm{ATP}$，$\mathrm{NADPH}$ 走合成还原，两本账不在本节并户。呼吸链复合体交给第二节，氧化磷酸化的 $\mathrm{P/O}$ 交给第三节。

能量是生命活动的保障，主要由糖、脂肪、蛋白质等营养物质提供。人体主要依赖化学能供能，但营养物质的能量不能被机体直接利用，需要经氧化分解后产生可供利用的能量形式。$\mathrm{ATP}$、$\mathrm{GTP}$、$\mathrm{UTP}$、$\mathrm{CTP}$ 等都是化学能的重要载体，是机体直接利用的能量形式，通过水解磷酸酯键等方式释放能量、参与各种生命活动。营养物质氧化分解释放的能量主要是热能、化学能等，而化学能主要由 $\mathrm{ATP}$ 捕获储存，$\mathrm{ATP}$ 与 $\mathrm{GTP}$、$\mathrm{UTP}$、$\mathrm{CTP}$ 之间可以相互转换，因此 $\mathrm{ATP}$ 既是物质代谢的产物，也是能量代谢的核心。

有机物质在生物体内的氧化过程统称为生物氧化（biological oxidation）。由于氧化反应与还原反应总是相伴而行，生物氧化实际上是机体进行有氧呼吸时，细胞内发生的一系列氧化还原反应。细胞的线粒体（mitochondrion）、过氧化物酶体（peroxisome）等均可进行各种氧化还原反应，但过程及产物各不相同。在线粒体进行的氧化还原反应是生物氧化的核心内容，需要消耗氧，其氧化产物是 $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$ 并释放能量用于生成 $\mathrm{ATP}$ 等。而在过氧化物酶体、内质网等发生的氧化还原反应是对底物进行氧化修饰等，并无 $\mathrm{ATP}$ 的生成。本章重点介绍线粒体的生物氧化及能量的产生与储存。

:::definition{label="生物氧化"}
生物氧化（biological oxidation）是有机物质在生物体内的氧化过程。氧化反应与还原反应总是相伴而行，因此它实际上是机体进行有氧呼吸时细胞内发生的一系列氧化还原反应。
:::

:::definition{label="线粒体生物氧化"}
线粒体中的氧化还原反应是生物氧化的核心：消耗氧，产物是 $\mathrm{CO}_2$ 和 $\mathrm{H}_2\mathrm{O}$，释放的能量用于生成 $\mathrm{ATP}$ 等。真核细胞生成 $\mathrm{ATP}$ 的主要部位在线粒体，第二节把它写成“能量工厂”。
:::

:::definition{label="过氧化物酶体与内质网的氧化"}
过氧化物酶体、内质网等处的氧化还原反应主要对底物进行氧化修饰，并不生成 $\mathrm{ATP}$。不要把细胞内所有“加氧、脱氢”都听成呼吸链产 $\mathrm{ATP}$。第五章、第六章的微粒体加氧、过氧化物酶体处理过氧化氢，与本章线粒体氧化体系分户。
:::

:::concept{term="先问在不在线粒体、产不产 ATP，再问电子交给谁"}
看见“生物氧化”，先不要默写呼吸链复合体。户头是：营养物质的化学能不能直接花，要氧化分解后装进 $\mathrm{ATP}$。线粒体这本账消耗 $\mathrm{O}_2$、产 $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$ 和 $\mathrm{ATP}$；过氧化物酶体、内质网那本账是修饰，不产 $\mathrm{ATP}$。$\mathrm{NADH}$ 怎么进呼吸链，是第二节的事。
:::

:::pitfall{label="NADH 和 NADPH 不在本节并户"}
本节用 $\mathrm{NAD}^{+}$ 接受电子和质子变成 $\mathrm{NADH}$，只是氧化还原的例子，不是把烟酰胺辅酶写成同一种能量货币。$\mathrm{NADH}$ 是呼吸链的底物，彻底氧化产 $\mathrm{ATP}$；$\mathrm{NADPH}$ 的磷酸基团被合成代谢的酶识别，主要用于还原性生物合成，不参与能量代谢。把二者并成“都是递氢体所以都产 $\mathrm{ATP}$”，第二节两条呼吸链和戊糖磷酸途径都会串账。
:::

物质进行分解和合成代谢时，伴随着能量的产生与利用。物质代谢的同时必然进行能量的产生与转换利用，推动机体的新陈代谢、进行各种生命活动。生物合成是利用简单的小分子化合物合成机体所需的生物大分子，是耗能过程；食物中的营养物质通过氧化分解反应降解为 $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$ 等小分子代谢物时释放能量，是释能过程。

## 一、营养物质的生物氧化产生能量

### （一）生物氧化是物质发生的氧化还原反应

机体内的物质可以发生各种化学反应，包括氧化分解、化学修饰等。生物氧化是物质在机体内发生的一系列氧化还原反应，某个物质被氧化的同时伴随着另一个物质的还原，因此氧化反应与还原反应总是相伴进行。另外，体内的生物氧化存在多种形式，包括加氧、脱氢、失电子；并且反应由酶来催化，具有可调节性。

**1. 物质的氧化还原反应存在多种形式**　氧化反应是脱氢、加氧、失去电子，还原反应则是加氢及获得电子的过程。例如，$\mathrm{Fe}^{2+}$ 通过失去一个电子被氧化成 $\mathrm{Fe}^{3+}$；$\mathrm{O}_2$ 接受电子和质子（proton，$\mathrm{H}^{+}$）后被还原为 $\mathrm{H}_2\mathrm{O}$；小分子有机化合物如辅酶 $\mathrm{NAD}^{+}$ 获得电子和质子被还原为 $\mathrm{NADH}+\mathrm{H}^{+}$（简写为 $\mathrm{NADH}$）。因此能够传递电子和氢（$\mathrm{H}\leftrightarrow \mathrm{H}^{+}+\mathrm{e}^{-}$）的物质，如金属离子、小分子有机化合物、某些蛋白质等，称之为递电子体或递氢体，都可参与氧化还原反应。

:::definition{label="氧化反应与还原反应"}
氧化反应是脱氢、加氧、失去电子。还原反应是加氢及获得电子。某一物质被氧化时，必有另一物质被还原，二者总是相伴进行。
:::

:::definition{label="递电子体与递氢体"}
能够传递电子和氢（$\mathrm{H}\leftrightarrow \mathrm{H}^{+}+\mathrm{e}^{-}$）的物质称为递电子体或递氢体，包括金属离子、小分子有机化合物、某些蛋白质。第二节的 $\mathrm{NAD}^{+}$、黄素核苷酸、泛醌、铁硫中心和细胞色素都落在这一类里。
:::

:::compare{title="三种氧化形式不要只记燃烧加氧"}
| 形式 | 教材例子 | 还原一侧 |
|------|----------|----------|
| 失电子 | $\mathrm{Fe}^{2+}\rightarrow\mathrm{Fe}^{3+}+\mathrm{e}^{-}$ | 另一物质得电子 |
| 加氧 | 过氧化物酶体、内质网对底物的氧化修饰 | 氧被还原或掺入底物 |
| 脱氢 | $\mathrm{NAD}^{+}$ 接受电子和质子变成 $\mathrm{NADH}+\mathrm{H}^{+}$ | 递氢体被还原 |

体外燃烧一眼看成加氧放热；体内生物氧化三种形式都有，而且由酶催化、可调节。
:::

:::insight{label="NAD+ 在本节只是氧化还原的例子"}
课文用 $\mathrm{NAD}^{+}\rightarrow\mathrm{NADH}$ 说明小分子有机化合物也能递氢。烟酰胺环怎么加氢、核糖 $2'$ 羟基磷酸化后变成 $\mathrm{NADP}^{+}$，以及 $\mathrm{NADH}$ 呼吸链对 $\mathrm{NADPH}$ 合成还原，都放到第二节再立户。
:::

**2. 氧化还原电位反映物质得失电子的能力**　通常失去电子的物质称为还原剂，得到电子的物质称为氧化剂。物质得失电子的能力可用标准氧化还原电位 $E^{\circ}$（单位：电压 Volts）来表示，是指在特定条件下，参与氧化还原反应的组分对电子的亲和力大小。电位高的组分对电子的亲和力强，易接受电子；电位低的组分倾向于给出电子。在氧化还原体系中，电子总是从电位较低的物质流向电位高的物质。

根据热力学公式，$\Delta G^{\prime\circ}$ 与标准氧化还原电位变化（$\Delta E^{\circ}$）之间存在以下关系：

$$
\Delta G^{\prime\circ}=-nF\Delta E^{\circ}
$$

式中 $n$ 为传递电子数；$F$ 为法拉第常数（$96.5\,\mathrm{kJ/mol\cdot V}$）。一对氧化还原反应可以通过 $\Delta E^{\circ}$ 计算出反应的自由能变化，因此物质得失电子的能力可转变为自由能释放出来。

:::definition{label="标准氧化还原电位"}
标准氧化还原电位 $E^{\circ}$（单位：V）表示特定条件下，参与氧化还原反应的组分对电子的亲和力。电位高：亲和力强，易接受电子；电位低：倾向于给出电子。电子总是从电位较低的物质流向电位较高的物质。
:::

:::definition{label="还原剂与氧化剂"}
失去电子的物质是还原剂，得到电子的物质是氧化剂。呼吸链里 $\mathrm{NADH}$ 给出电子，是还原剂；$\mathrm{O}_2$ 最后接受电子，是氧化剂。
:::

:::definition{label="自由能变化与电位差"}
标准条件下 $\Delta G^{\prime\circ}=-nF\Delta E^{\circ}$。$n$ 是传递电子数，$F=96.5\,\mathrm{kJ/mol\cdot V}$。电位差越大、传的电子越多，可释放的自由能越多。第二节用各氧化还原对的 $E^{\circ}$ 给呼吸链排序，第三节再用同一公式核对偶联部位。
:::

:::keypoint{label="电子从低电位流向高电位"}
- 低 $E^{\circ}$：倾向给出电子，排在呼吸链上游。
- 高 $E^{\circ}$：对电子亲和力强，排在下游，最后是 $\mathrm{O}_2/\mathrm{H}_2\mathrm{O}$。
- $\Delta E^{\circ}$ 经法拉第常数变成 $\Delta G^{\prime\circ}$，这就是“氧化还原能力转变成可做功的自由能”。
:::

:::pitfall{label="电位高不是“能量高、排在前面”"}
电位高的组分对电子抓得紧，排序在后，不是“高能所以先反应”。$\mathrm{NAD}^{+}/\mathrm{NADH}$ 的 $E^{\circ}$ 约 $-0.32\,\mathrm{V}$，排在最前；$1/2\,\mathrm{O}_2/\mathrm{H}_2\mathrm{O}$ 约 $+0.816\,\mathrm{V}$，排在最后。把“高电位”听成“高能磷酸键那种高”，呼吸链方向会写反。
:::

**3. 生物氧化是逐步进行的酶促反应**　机体的反应条件温和，近似常温、常压及中性 $\mathrm{pH}$，因此体内发生的生物氧化反应，和体外的氧化反应相比有自己的特点：反应需要有酶催化，而且是分阶段、逐步完成；氧化还原反应发生化学键的形成与断裂，伴随着能量的变化，细胞内生物大分子体系多通过弱键能的非共价键维系，不能承受能量的大增或大量释放的化学过程，氧化分解过程分步进行，能量也逐步得失；营养物质储存的化学能不能被机体直接利用，需要转变为可利用的能量形式，如 $\mathrm{ATP}$ 储存的化学能。

:::definition{label="生物氧化的特点"}
与体外燃烧相比，体内生物氧化：①由酶催化，可调节；②分阶段、逐步完成；③能量逐步释放，避免高温高热；④营养物质的化学能先转成可直接利用的形式（主要是 $\mathrm{ATP}$）。条件近似常温、常压、中性 $\mathrm{pH}$。
:::

:::compare{title="体外燃烧和体内生物氧化"}
| 项目 | 体外燃烧 | 体内生物氧化 |
|------|----------|--------------|
| 条件 | 高温、火焰 | 常温、常压、中性 $\mathrm{pH}$，需酶 |
| 能量释放 | 一次性，光和热 | 分步释放，热能 $+$ 化学能 |
| 能量形式 | 不能被细胞直接利用 | 化学能主要装进 $\mathrm{ATP}$ |
| 总量 | 彻底氧化释放的总能量与体内相同 | 总量相同，形式和节奏不同 |
:::

:::insight{label="总量相同，形式和节奏不同"}
营养物质在体内彻底氧化释放的能量，与其在体外燃烧释放的能量完全相同。差别不在“一共有多少焦”，而在：体内逐步释放，装进 $\mathrm{ATP}$ 的那一份才能做生化功。第二节呼吸链把 $\mathrm{NADH}$、$\mathrm{FADH}_2$ 的电子一站一站交给氧，就是为了把这一笔分步账做完。
:::

:::pitfall{label="细胞内受不了一次烧完"}
生物大分子多靠弱的非共价键维系。若氧化像燃烧一样瞬间释能，温度和自由能冲击会把结构拆掉。逐步酶促不是“效率低”，是细胞能活下来的前提。
:::

### （二）营养物质的氧化分解产生能量

糖、脂肪、蛋白质等营养物质经过消化后，主要以葡萄糖、脂肪酸、氨基酸等形式被人体吸收后进入各自的代谢过程。其中合成代谢用于产生糖原、脂肪以及蛋白质等；分解代谢主要用于产生简单的小分子化合物、释放能量。营养物质在体内彻底氧化释放的能量，与其在体外燃烧释放的能量（光和热）完全相同，但能量是在物质氧化分解的过程中被逐步释放，而且释放的能量形式不同，是可供机体直接利用的热能和化学能，而且化学能储存于一些特殊的化合物中，主要是 $\mathrm{ATP}$。

营养物质在氧化分解的过程中产生能量，一种方式是通过底物水平磷酸化的方式直接产生少量的 $\mathrm{ATP}$，例如，葡萄糖分解代谢的中间物甘油酸-1,3-二磷酸转变为甘油酸-3-磷酸、磷酸烯醇式丙酮酸生成丙酮酸时产生的 $\mathrm{ATP}$。营养物质的彻底氧化可以产生大量能量。糖、脂肪、蛋白质的分解代谢除了生成乙酰 $\mathrm{CoA}$ 和 $\mathrm{CO}_2$ 外，还进行脱氢反应、产生还原性化合物 $\mathrm{NADH}+\mathrm{H}^{+}$ 等，三羧酸循环有四次脱氢反应、产生大量的 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$。$1\,\mathrm{mol}$ 葡萄糖彻底氧化时生成 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$，其中 $26$ 或 $28\,\mathrm{mol}\,\mathrm{ATP}$ 是来自 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的氧化。因此营养物质氧化分解产生大量的还原性辅酶，它们的彻底氧化是产生 $\mathrm{ATP}$ 的主要方式。

:::definition{label="底物水平磷酸化"}
底物水平磷酸化是把底物分子上的高能磷酸基直接转移给 $\mathrm{ADP}$（或其他核苷二磷酸）生成 $\mathrm{ATP}$。本节点名的两处：甘油酸-1,3-二磷酸 $\rightarrow$ 甘油酸-3-磷酸，磷酸烯醇式丙酮酸 $\rightarrow$ 丙酮酸。产量少，不经过呼吸链。
:::

:::definition{label="还原性辅酶彻底氧化是产 ATP 的主要方式"}
糖、脂肪、蛋白质分解除生成乙酰 $\mathrm{CoA}$ 和 $\mathrm{CO}_2$ 外，还脱氢生成 $\mathrm{NADH}$、$\mathrm{FADH}_2$。三羧酸循环四次脱氢，产生大量 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$。这些还原性辅酶在线粒体经呼吸链彻底氧化，才是 $\mathrm{ATP}$ 的大头。
:::

:::keypoint{label="本版 1 mol 葡萄糖 30 或 32 mol ATP"}
- 总账：$1\,\mathrm{mol}$ 葡萄糖彻底氧化生成 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$（第七章有氧氧化同一套标准）。
- 其中 $26$ 或 $28\,\mathrm{mol}$ 来自 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的氧化。
- 差额 $4\,\mathrm{mol}$ 来自底物水平磷酸化（糖酵解净 $2$、三羧酸循环 $2$ 个 $\mathrm{GTP}/\mathrm{ATP}$）。
- $30$ 还是 $32$，取决于细胞质 $\mathrm{NADH}$ 走哪一条穿梭（第二节末、第三节图10-13／图10-14）：甘油-3-磷酸穿梭按 $\mathrm{FADH}_2$ 入口计 $1.5$，苹果酸-天冬氨酸穿梭按 $\mathrm{NADH}$ 入口计 $2.5$。
:::

:::pitfall{label="本版不要默写 36、38 或 P/O 等于 3 和 2"}
旧口诀把 $\mathrm{NADH}$ 写成 $3\,\mathrm{ATP}$、$\mathrm{FADH}_2$ 写成 $2\,\mathrm{ATP}$，葡萄糖就变成 $36$ 或 $38$。本版与第七、第八章对齐：$\mathrm{NADH}$ 呼吸链约 $2.5\,\mathrm{ATP}$，琥珀酸／$\mathrm{FADH}_2$ 呼吸链约 $1.5\,\mathrm{ATP}$，葡萄糖 $30$ 或 $32$。$\mathrm{P/O}$ 的操作定义在第三节，数字在本节已经按 $2.5/1.5$ 用。
:::

:::compare{title="两种产 ATP 方式"}
| 项目 | 底物水平磷酸化 | 还原性辅酶经呼吸链氧化 |
|------|----------------|------------------------|
| 是否经过呼吸链 | 否，底物高能磷酸基直接给 $\mathrm{ADP}$ | 是，$\mathrm{NADH}$、$\mathrm{FADH}_2$ 把电子交给氧 |
| 本节例子 | 甘油酸-1,3-二磷酸、磷酸烯醇式丙酮酸 | 三羧酸循环四次脱氢产物 |
| 对葡萄糖总账 | $4\,\mathrm{mol}\,\mathrm{ATP}$ 量级 | $26$ 或 $28\,\mathrm{mol}\,\mathrm{ATP}$ |
| 本章后文 | 第七章已写过 | 第二节呼吸链，第三节氧化磷酸化 |
:::

:::insight{label="先记下还原当量，ATP 大头在后头"}
分解代谢的中间产物不一定当时就变成 $\mathrm{ATP}$。脱下来的氢先装进 $\mathrm{NADH}$、$\mathrm{FADH}_2$，到线粒体氧化体系再一站一站交给氧。本节只把“主要方式是还原性辅酶的彻底氧化”钉住，不把复合体Ⅰ–Ⅳ提前抄进能量货币这一页。
:::

## 二、ATP 是能量代谢的核心

$\mathrm{ATP}$ 是生物氧化的重要产物。它能成为能量代谢的核心，是因为糖、脂、蛋白质等营养物质分解代谢释放的能量可储存于 $\mathrm{ATP}$，并且 $\mathrm{ATP}$ 可直接用于机体的各种生命活动。$\mathrm{ATP}$ 属于高能磷酸化合物。所谓高能磷酸化合物，是指那些水解时能释放较大自由能（free energy）的含有磷酸基的化合物。

简单而言，自由能是指在恒温恒压的条件下，一个热力学过程对环境做功的能力，又称 Gibbs 自由能，用符号 $G$ 表示。机体生物化学反应中发生的能量变化常用标准条件下自由能变化（$\Delta G^{\prime\circ}$，单位为 $\mathrm{kJ/mol}$）来表示：$\Delta G^{\prime\circ}<0$，为释放能量的反应，可自发进行；$\Delta G^{\prime\circ}>0$，反应需供能才能进行；而 $\Delta G^{\prime\circ}=0$ 时，反应处于平衡状态。$\Delta G^{\prime\circ}$ 可用于判断化学反应的能量变化及反应进行的方向。

通常，将释放的 $\Delta G^{\prime\circ}>25\,\mathrm{kJ/mol}$ 称为高能化合物，并将水解时释放能量较多的磷酸酯键，称之为高能磷酸键，用“～$\mathrm{P}$”符号表示。$\mathrm{ATP}$ 末端的磷酸酯键水解时 $\Delta G^{\prime\circ}$ 为 $-30.5\,\mathrm{kJ/mol}$，为高能磷酸键；而葡萄糖-6-磷酸的磷酸酯键水解时，其 $\Delta G^{\prime\circ}$ 为 $-13.8\,\mathrm{kJ/mol}$，为普通的磷酸酯键。事实上，共价键的断裂是需要提供能量的，而具有高能磷酸键的化合物作为底物进行水解时，其产物比底物具有更低的自由能，因而释放的能量较多。此外，生物体内还有其他含高能磷酸键、高能硫酯键的化合物，见表10-1。

:::definition{label="自由能"}
自由能（free energy）是恒温恒压条件下一个热力学过程对环境做功的能力，又称 Gibbs 自由能，符号 $G$。生化反应常用标准条件下的自由能变化 $\Delta G^{\prime\circ}$（$\mathrm{kJ/mol}$）。
:::

:::definition{label="ΔG′° 的符号"}
$\Delta G^{\prime\circ}<0$：释能，可自发进行；$\Delta G^{\prime\circ}>0$：需供能才能进行；$\Delta G^{\prime\circ}=0$：平衡。它判断的是能量变化和反应方向，不是反应快慢。
:::

:::definition{label="高能磷酸化合物"}
高能磷酸化合物是水解时能释放较大自由能的含磷酸基化合物。本版把释放的 $\Delta G^{\prime\circ}>25\,\mathrm{kJ/mol}$ 称为高能化合物。
:::

:::definition{label="高能磷酸键"}
水解时释放能量较多的磷酸酯键称为高能磷酸键，用“～$\mathrm{P}$”表示。$\mathrm{ATP}$ 末端磷酸酯键 $\Delta G^{\prime\circ}=-30.5\,\mathrm{kJ/mol}$，是高能磷酸键；葡萄糖-6-磷酸 $\Delta G^{\prime\circ}=-13.8\,\mathrm{kJ/mol}$，是普通磷酸酯键。
:::

:::pitfall{label="高能磷酸键不是“键里藏着一份正能量”"}
共价键断裂本身要消耗能量。所谓“高能”，是水解后产物的自由能比底物低得多，所以净释放的自由能大。不要把 ～$\mathrm{P}$ 画成一根弹簧，好像剪开就喷出 $30.5\,\mathrm{kJ}$。表10-1 的负号表示释放。
:::

### （一）ATP 是能量捕获和释放利用的重要分子

$\mathrm{ATP}$ 是机体可直接利用的能量形式。营养物质分解产生的能量大约 $40\%$ 用于产生 $\mathrm{ATP}$。在标准状态下，$\mathrm{ATP}$ 水解释放的自由能为 $30.5\,\mathrm{kJ/mol}$。但在活细胞中，$\mathrm{ATP}$、$\mathrm{ADP}$ 和无机磷浓度比标准状态低得多，而 $\mathrm{pH}$ 比标准状态的 $\mathrm{pH}\,7.0$ 高，$\mathrm{ATP}$ 和 $\mathrm{ADP}$ 的全部磷酸基都处于解离状态，显示携带 $4$ 个或 $3$ 个负电荷的阴离子形式，并与细胞内 $\mathrm{Mg}^{2+}$ 形成复合物。考虑到浓度等各种影响因素，细胞内 $\mathrm{ATP}$ 水解释放的自由能可能达到 $52.3\,\mathrm{kJ/mol}$。

$\mathrm{ATP}$ 最重要的作用是通过水解高能磷酸键释放大量自由能，当与需要供能的反应偶联时，能促进这些反应在生理条件下完成。$\mathrm{ATP}$ 可直接参与各种代谢物的活化反应和合成生物大分子的反应；可使分解代谢与合成代谢紧密相连；可为耗能的跨膜转运、骨骼肌收缩、蛋白质构象的改变等提供能量。

:::definition{label="ATP 水解释放的自由能"}
标准状态下 $\mathrm{ATP}\rightarrow\mathrm{ADP}+\mathrm{P}_\mathrm{i}$ 的 $\Delta G^{\prime\circ}=-30.5\,\mathrm{kJ/mol}$。活细胞中因浓度、$\mathrm{pH}$、解离状态及与 $\mathrm{Mg}^{2+}$ 形成复合物，实际可释放的自由能可能达到 $52.3\,\mathrm{kJ/mol}$。
:::

:::keypoint{label="大约 40% 装进 ATP"}
营养物质分解产生的能量大约 $40\%$ 用于产生 $\mathrm{ATP}$，其余主要以热能形式释放。第七章写 $1\,\mathrm{mol}$ 葡萄糖完全氧化 $2840\,\mathrm{kJ}$、约 $34\%$ 转入 $\mathrm{ATP}$，是糖这一本账的效率；本节 $40\%$ 是营养物质分解的总括。不要把两笔效率强行合成一个数。
:::

:::insight{label="标准 30.5 和细胞内 52.3 不要并成一个考试数字"}
表10-1、高能阈值、与葡萄糖-6-磷酸比较，一律用 $-30.5\,\mathrm{kJ/mol}$。$52.3\,\mathrm{kJ/mol}$ 是活细胞条件下的估计，用来说明 $\mathrm{ATP}$ 偶联耗能反应为什么在生理条件下推得动，不是另立一套高能标准。
:::

### （二）ATP 为核苷酸相互转变提供能量

细胞中存在的腺苷酸激酶（adenylate kinase）可催化 $\mathrm{ATP}$、$\mathrm{ADP}$、$\mathrm{AMP}$ 间互变。当体内 $\mathrm{ATP}$ 消耗过多（例如骨骼肌剧烈收缩）时，$\mathrm{ADP}$ 累积，在腺苷酸激酶催化下由 $\mathrm{ADP}$ 转变成 $\mathrm{ATP}$。当 $\mathrm{ATP}$ 的需求量降低时，$\mathrm{AMP}$ 从 $\mathrm{ATP}$ 中获得 ～$\mathrm{P}$ 生成 $\mathrm{ADP}$。

$$
2\,\mathrm{ADP}\xrightleftharpoons{\text{腺苷酸激酶}}\mathrm{ATP}+\mathrm{AMP}
$$

$\mathrm{UTP}$、$\mathrm{CTP}$、$\mathrm{GTP}$ 可为糖原、磷脂、蛋白质等合成反应提供能量，但它们一般不能从营养物质氧化过程中直接生成，而是在核苷二磷酸激酶的催化下，从 $\mathrm{ATP}$ 中获得 ～$\mathrm{P}$ 产生。反应如下：

$$
\mathrm{ATP}+\mathrm{UDP}\rightarrow\mathrm{ADP}+\mathrm{UTP}
$$

$$
\mathrm{ATP}+\mathrm{CDP}\rightarrow\mathrm{ADP}+\mathrm{CTP}
$$

$$
\mathrm{ATP}+\mathrm{GDP}\rightarrow\mathrm{ADP}+\mathrm{GTP}
$$

生物体内能量的生成、转移和利用都以 $\mathrm{ATP}$ 为中心。$\mathrm{ATP}$ 分子性质稳定，但寿命仅数分钟，不在细胞中储存，而是不断进行 $\mathrm{ATP}/\mathrm{ADP}$ 的再循环，其相互转变的量十分可观，转变过程中伴随自由能的释放和获得，并促进其他核苷酸的生成，在各种生命活动中完成能量的穿梭转换，因此称为“能量货币”。

:::definition{label="腺苷酸激酶"}
腺苷酸激酶（adenylate kinase）催化 $\mathrm{ATP}$、$\mathrm{ADP}$、$\mathrm{AMP}$ 互变。$\mathrm{ATP}$ 消耗过多、$\mathrm{ADP}$ 累积时，由 $\mathrm{ADP}$ 转变成 $\mathrm{ATP}$；$\mathrm{ATP}$ 需求降低时，$\mathrm{AMP}$ 从 $\mathrm{ATP}$ 获得 ～$\mathrm{P}$ 生成 $\mathrm{ADP}$。
:::

:::definition{label="核苷二磷酸激酶"}
核苷二磷酸激酶催化 $\mathrm{ATP}$ 把 ～$\mathrm{P}$ 转给 $\mathrm{UDP}$、$\mathrm{CDP}$、$\mathrm{GDP}$，生成 $\mathrm{UTP}$、$\mathrm{CTP}$、$\mathrm{GTP}$。后三者一般不能从营养物质氧化过程中直接生成。
:::

:::definition{label="能量货币"}
体内能量的生成、转移和利用都以 $\mathrm{ATP}$ 为中心。$\mathrm{ATP}$ 性质稳定，但寿命仅数分钟，细胞中并不储存大量 $\mathrm{ATP}$，而是不断进行 $\mathrm{ATP}/\mathrm{ADP}$ 再循环，并带动其他核苷酸生成，故称能量货币。
:::

:::compare{title="腺苷酸激酶和核苷二磷酸激酶"}
| 酶 | 反应 | 场合 |
|----|------|------|
| 腺苷酸激酶 | $2\,\mathrm{ADP}\rightleftharpoons\mathrm{ATP}+\mathrm{AMP}$ | 骨骼肌剧烈收缩等 $\mathrm{ADP}$ 堆积时应急生成 $\mathrm{ATP}$；需求下降时 $\mathrm{AMP}$ 再被磷酸化 |
| 核苷二磷酸激酶 | $\mathrm{ATP}+\mathrm{NDP}\rightarrow\mathrm{ADP}+\mathrm{NTP}$ | 糖原要 $\mathrm{UTP}$、磷脂要 $\mathrm{CTP}$、蛋白质合成要 $\mathrm{GTP}$，～$\mathrm{P}$ 都从 $\mathrm{ATP}$ 来 |
:::

:::pitfall{label="UTP、CTP、GTP 不是呼吸链直接产物"}
合成代谢确实花 $\mathrm{UTP}$、$\mathrm{CTP}$、$\mathrm{GTP}$，但营养物质氧化这一头直接装进的是 $\mathrm{ATP}$（加上三羧酸循环的 $\mathrm{GTP}$ 那一笔底物水平磷酸化）。其余 $\mathrm{NTP}$ 要靠核苷二磷酸激酶从 $\mathrm{ATP}$ 转 ～$\mathrm{P}$。不要写成“四种三磷酸核苷都从氧化磷酸化平行产出”。
:::

:::insight{label="ATP 不存仓库，只跑流水"}
寿命数分钟、不储存、循环量极大——这三句合在一起才叫货币。磷酸肌酸才是需能组织里的短期仓库，下一小节立户。把 $\mathrm{ATP}$ 听成“细胞里囤着很多高能分子”，和课文“不在细胞中储存”对着干。
:::

:::cause-effect{title="为什么 ATP 能带动其他核苷酸"}
- **因** $\mathrm{ATP}$ 末端 ～$\mathrm{P}$ 水解（或转移）释放的自由能足够把磷酸交给 $\mathrm{NDP}$；核苷二磷酸激酶催化这一步
- **果** $\mathrm{UTP}$、$\mathrm{CTP}$、$\mathrm{GTP}$ 被充值，糖原、磷脂、蛋白质等合成才有各自的能量币；账本中心仍是 $\mathrm{ATP}$
:::

### （三）ATP 通过转移自身基团来提供能量

因为 $\mathrm{ATP}$ 分子中的高能磷酸键水解释放能量多，并产生 $\mathrm{P}_\mathrm{i}$、$\mathrm{PP}_\mathrm{i}$ 基团，很多酶促反应由 $\mathrm{ATP}$ 通过共价键与底物或蛋白质等相连，将 $\mathrm{ATP}$ 分子中的 $\mathrm{P}_\mathrm{i}$、$\mathrm{PP}_\mathrm{i}$ 或者 $\mathrm{AMP}$ 基团转移到底物或蛋白质分子上而形成中间产物，使其获得更多的自由能，经过化学转变后再将这些基团水解而形成终产物。例如，$\mathrm{ATP}$ 给葡萄糖提供磷酸基和能量，合成的葡萄糖-6-磷酸进入糖酵解或其他代谢途径后更易进行后续的化学反应。因此，$\mathrm{ATP}$ 也通过这种方式参与酶促反应并提供能量，而不仅仅局限于磷酸酯键的水解反应。

:::definition{label="ATP 的基团转移"}
$\mathrm{ATP}$ 可把分子中的 $\mathrm{P}_\mathrm{i}$、$\mathrm{PP}_\mathrm{i}$ 或 $\mathrm{AMP}$ 基团共价转移到底物或蛋白质上，形成自由能更高的中间产物，完成化学转变后再水解掉这些基团。这是供能方式，不只是 $\mathrm{ATP}+\mathrm{H}_2\mathrm{O}\rightarrow\mathrm{ADP}+\mathrm{P}_\mathrm{i}$。
:::

:::insight{label="葡萄糖-6-磷酸是活化，不是高能货币"}
$\mathrm{ATP}$ 把磷酸基交给葡萄糖，产物葡萄糖-6-磷酸的磷酸酯键只有 $-13.8\,\mathrm{kJ/mol}$，本身不是高能化合物。意义是：糖被加上磷酸后更易进入后续途径。把“活化”听成“葡萄糖-6-磷酸也是能量货币”，和高能阈值那一行冲突。
:::

:::compare{title="ATP 供能的两种写法"}
| 写法 | 产物印象 | 教材例子 |
|------|----------|----------|
| 水解偶联 | $\mathrm{ADP}+\mathrm{P}_\mathrm{i}$ 或 $\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$，释放自由能推动另一反应 | 跨膜转运、肌收缩、构象改变 |
| 基团转移 | 底物或蛋白质暂时带上 $\mathrm{P}_\mathrm{i}$、$\mathrm{PP}_\mathrm{i}$ 或 $\mathrm{AMP}$ | 葡萄糖 $\rightarrow$ 葡萄糖-6-磷酸；脂肪酸活化走 $\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$ |
:::

:::pitfall{label="不要把所有 ATP 消耗都写成 ADP + Pi"}
脂肪酸活化是 $\mathrm{ATP}\rightarrow\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$，焦磷酸再水解，实际消耗两个高能磷酸键（第八章）。腺苷酸激酶、核苷二磷酸激酶是转移 ～$\mathrm{P}$，不一定出现游离 $\mathrm{P}_\mathrm{i}$。只背“水解成 $\mathrm{ADP}$”，活化反应和 $\mathrm{PP}_\mathrm{i}$ 那一笔会对不上。
:::

### （四）磷酸肌酸也是储存能量的高能化合物

$\mathrm{ATP}$ 充足时，通过转移末端 ～$\mathrm{P}$ 给肌酸，生成磷酸肌酸（creatine phosphate，$\mathrm{CP}$），储存于需能较多的骨骼肌、心肌和脑组织中。当 $\mathrm{ATP}$ 消耗加快时，磷酸肌酸可将 ～$\mathrm{P}$ 转移给 $\mathrm{ADP}$，生成 $\mathrm{ATP}$，能快速补充 $\mathrm{ATP}$ 的不足（图10-1）。所以 $\mathrm{ATP}$ 在体内能量捕获、转移、储存和利用过程中处于中心位置（图10-2）。

::figure{src="/images/biochemistry/textbook/p0226_01.png" caption="图10-1　高能磷酸键在 ATP 和磷酸肌酸间的转移。肌酸激酶催化：肌酸 + ATP ⇌ 磷酸肌酸 + ADP；磷酸肌酸的胍基氮上标出 ～P。" alt="肌酸与 ATP 在肌酸激酶催化下可逆生成磷酸肌酸和 ADP"}

:::definition{label="磷酸肌酸"}
磷酸肌酸（creatine phosphate，$\mathrm{CP}$）是肌酸接受 $\mathrm{ATP}$ 末端 ～$\mathrm{P}$ 后的高能化合物，水解 $\Delta G^{\prime\circ}=-43.1\,\mathrm{kJ/mol}$。主要储存在骨骼肌、心肌和脑。$\mathrm{ATP}$ 充足时生成 $\mathrm{CP}$；$\mathrm{ATP}$ 消耗加快时，$\mathrm{CP}$ 把 ～$\mathrm{P}$ 转给 $\mathrm{ADP}$ 再生 $\mathrm{ATP}$。
:::

:::definition{label="肌酸激酶"}
肌酸激酶催化肌酸 $+\mathrm{ATP}\rightleftharpoons$ 磷酸肌酸 $+\mathrm{ADP}$（图10-1）。方向由 $\mathrm{ATP}/\mathrm{ADP}$ 比决定：休息时向 $\mathrm{CP}$ 储存，急用时向 $\mathrm{ATP}$ 回补。
:::

:::timeline{period="磷酸肌酸缓冲 ATP"}
- **ATP 充足** 末端高能磷酸基经肌酸激酶交给肌酸，生成磷酸肌酸，存在骨骼肌、心肌和脑
- **ATP 消耗加快** 磷酸肌酸把高能磷酸基转给 ADP，迅速补回 ATP
- **中心不动** 捕获、转移、储存、利用仍以 ATP 为中心，磷酸肌酸是缓冲，不是第二种能量货币
:::

:::pitfall{label="磷酸肌酸不能直接驱动大多数耗能反应"}
$\mathrm{CP}$ 的 $|\Delta G^{\prime\circ}|$ 比 $\mathrm{ATP}$ 大，但它的任务是给 $\mathrm{ADP}$ 回充，不是代替 $\mathrm{ATP}$ 去推动合成、转运或肌球蛋白。图10-2 右侧列出的机械能、渗透能、化学能、电能，都从 $\mathrm{ATP}$ 的 ～$\mathrm{P}$ 出去。把磷酸肌酸写成“肌肉里真正花的能量”，中心位置就从 $\mathrm{ATP}$ 挪走了。
:::

:::insight{label="先有 ATP 中心，才有 CP 仓库"}
图10-1 只画肌酸激酶这一笔可逆反应；图10-2 才把生成（氧化磷酸化 $+$ 底物水平磷酸化）、储存（磷酸肌酸）和利用画成一张循环。考试若只出“高能磷酸键在谁和谁之间转移”，答肌酸与 $\mathrm{ATP}$；若问“能量代谢的中心”，仍是 $\mathrm{ATP}$。
:::

:::memory{label="本节必背要点"}
- [ ] 生物氧化：体内有机物的氧化，氧化还原相伴；线粒体产 $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$、$\mathrm{ATP}$，过氧化物酶体／内质网修饰不产 $\mathrm{ATP}$
- [ ] 氧化＝脱氢、加氧、失电子；递电子体／递氢体传递 $\mathrm{H}\leftrightarrow\mathrm{H}^{+}+\mathrm{e}^{-}$
- [ ] $E^{\circ}$ 高则亲和电子、排在后；电子从低电位流向高电位；$\Delta G^{\prime\circ}=-nF\Delta E^{\circ}$，$F=96.5\,\mathrm{kJ/mol\cdot V}$
- [ ] 体内逐步酶促、常温常压中性 $\mathrm{pH}$；总量与体外燃烧相同，形式是热能 $+$ $\mathrm{ATP}$
- [ ] 底物水平磷酸化产量少；还原性辅酶彻底氧化是 $\mathrm{ATP}$ 大头
- [ ] 本版 $1\,\mathrm{mol}$ 葡萄糖 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$，其中 $26$ 或 $28\,\mathrm{mol}$ 来自 $\mathrm{NADH}$、$\mathrm{FADH}_2$；不要默写 $36/38$ 或 $3/2$
- [ ] $\mathrm{NADH}$ 进呼吸链，$\mathrm{NADPH}$ 走合成还原，本节不并户
- [ ] 释放 $\Delta G^{\prime\circ}>25\,\mathrm{kJ/mol}$ 为高能化合物；$\mathrm{ATP}$ 末端 $-30.5$，葡萄糖-6-磷酸 $-13.8$
- [ ] ～$\mathrm{P}$ 不是键内藏能，而是产物自由能更低；乙酰 $\mathrm{CoA}$ 是高能硫酯
- [ ] 标准水解 $30.5\,\mathrm{kJ/mol}$，细胞内可达 $52.3$；约 $40\%$ 的分解能量用于生成 $\mathrm{ATP}$
- [ ] 腺苷酸激酶：$2\,\mathrm{ADP}\rightleftharpoons\mathrm{ATP}+\mathrm{AMP}$；核苷二磷酸激酶：$\mathrm{ATP}$ 给 $\mathrm{UDP}/\mathrm{CDP}/\mathrm{GDP}$ 充值
- [ ] $\mathrm{ATP}$ 寿命数分钟、不储存，称能量货币；供能可以是水解，也可以转移 $\mathrm{P}_\mathrm{i}$、$\mathrm{PP}_\mathrm{i}$、$\mathrm{AMP}$
- [ ] 磷酸肌酸储存在骨骼肌、心肌、脑，$-43.1\,\mathrm{kJ/mol}$，经肌酸激酶与 $\mathrm{ATP}$ 互转；中心仍是 $\mathrm{ATP}$
:::
