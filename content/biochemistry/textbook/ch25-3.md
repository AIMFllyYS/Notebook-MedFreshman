# 第三节　胆汁与胆汁酸的代谢

第一节把胆汁写成双重输出通道里每天 $600\sim 1\,000\,\mathrm{ml}$ 的那一户，第二节结合反应点过甘氨胆酸、牛磺胆酸。本节只立胆汁与胆汁酸：肝胆汁与胆囊胆汁先分户；游离／结合、初级／次级按图25-13、图25-14；功能是乳化脂质并带走胆固醇；合成关键酶是胆固醇 $7\alpha$-羟化酶；肠肝循环按图25-15 本版数字——合成 $0.4\sim 0.6\,\mathrm{g/d}$、代谢池 $3\sim 5\,\mathrm{g}$、回吸收 $>95\%$、排泄 $0.4\sim 0.6\,\mathrm{g/d}$。胆色素和黄疸交给第四节。遗传多态性、体外诱导／抑制已经写在第二节，本节不再当主线。

:::concept{term="先问胆汁是消化液还是排泄液，再问胆汁酸怎么分类、怎么循环"}
看见「胆汁酸」，先不要默写 $3\alpha$、$7\alpha$、$12\alpha$ 的位置。户头是：胆汁由肝细胞分泌，既消化脂质，也排泄胆固醇、胆红素和异源物。分类两套轴同时记——按结构分游离／结合，按来源分初级／次级。功能先答乳化，再答溶解胆固醇。循环问池有多大、一天转几圈、粪里丢多少。把本节写成「肝解毒续篇」或把胆红素黄疸提前写进来，第四节就没有户头。
:::

图25-13（胆汁酸的分类）和图25-14（几种主要胆汁酸的结构式）电子版缺失，正文保留图号，不嵌入空图。分类树和羟基位置按本版图25-13、图25-14 写进对照表。本节嵌入的插图是图25-15（胆汁酸的肠肝循环：肝合成结合胆汁酸 $0.4\sim 0.6\,\mathrm{g/d}$、代谢池 $3\sim 5\,\mathrm{g}$、回吸收 $>95\%$、肠菌水解脱羧、粪便排泄 $0.4\sim 0.6\,\mathrm{g/d}$）。图25-16 起的胆红素在第四节。
:::

:::pitfall{label="不要把第二节酶多态性再当本节主线"}
醛脱氢酶、葡萄糖醛酸基转移酶、谷胱甘肽 $\mathrm{S}$-转移酶的遗传变异，以及苯巴比妥诱导、保泰松抑制，已经写在第二节。本节从肝胆汁／胆囊胆汁起笔。甘氨酸、牛磺酸结合在这里是胆汁酸分户，不是再讲一遍第二相。
:::

## 一、胆汁可分为肝胆汁和胆囊胆汁

胆汁（bile）由肝细胞分泌。肝细胞最初分泌的胆汁称肝胆汁（hepatic bile）。肝胆汁进入胆囊后，胆囊壁上皮细胞吸收其中的部分水分和其他一些成分，并分泌黏液渗入胆汁，浓缩成为胆囊胆汁（gallbladder bile），经胆总管排入十二指肠，参与脂质的消化与吸收。

:::definition{label="胆汁"}
胆汁（bile）：由肝细胞分泌。最初分泌的是肝胆汁；入胆囊浓缩后成为胆囊胆汁，再经胆总管入十二指肠。户头落在「肝细胞分泌」，不是胆囊自己造出来的。
:::

:::definition{label="肝胆汁"}
肝细胞最初分泌的胆汁。含水约 $96\%\sim 97\%$，固体成分仅 $3\%\sim 4\%$，比重 $1.009\sim 1.013$，$\mathrm{pH}$ $7.1\sim 8.5$，偏稀、偏碱。
:::

:::definition{label="胆囊胆汁"}
肝胆汁进入胆囊后，胆囊壁上皮吸收部分水分和其他成分，并分泌黏液渗入，浓缩而成。含水降至 $80\%\sim 86\%$，固体成分升至 $14\%\sim 20\%$，比重 $1.026\sim 1.032$，$\mathrm{pH}$ $5.5\sim 7.7$。经胆总管排入十二指肠。
:::

:::compare{title="肝胆汁 vs 胆囊胆汁：谁浓缩、谁偏酸"}
| | 肝胆汁 | 胆囊胆汁 |
|--|--------|----------|
| 来历 | 肝细胞刚分泌 | 胆囊吸收水分、渗入黏液后浓缩 |
| 比重 | $1.009\sim 1.013$ | $1.026\sim 1.032$ |
| $\mathrm{pH}$ | $7.1\sim 8.5$ | $5.5\sim 7.7$ |
| 水 | $96\%\sim 97\%$ | $80\%\sim 86\%$ |
| 固体 | $3\%\sim 4\%$ | $14\%\sim 20\%$ |
| 去向 | 入胆囊贮存、浓缩 | 经胆总管入十二指肠 |

问「胆汁是谁分泌的」——肝细胞。问「谁更浓、谁更酸」——胆囊胆汁。不要写成胆囊自己合成胆汁酸。
:::

胆汁的主要固体成分是胆汁酸盐，约占固体成分的 $50\%$。其次是无机盐、黏蛋白、磷脂、胆固醇、胆色素等。除胆汁酸盐与脂质消化、吸收有关，磷脂与胆汁中胆固醇的溶解状态有关外，其他成分多属排泄物。体内某些代谢产物及进入体内的药物、毒物、重金属盐等异源物，均经肝的生物转化后随胆汁排出体外。因此，胆汁既是一种消化液，亦可作为排泄液。

:::definition{label="胆汁酸盐约占固体成分 50%"}
胆汁的主要固体成分是胆汁酸盐。磷脂帮助胆固醇保持溶解；其余多属排泄物。消化和排泄两本账要同时答。
:::

:::definition{label="胆汁既是消化液，亦是排泄液"}
消化：胆汁酸盐乳化脂质。排泄：胆固醇、胆色素，以及经生物转化后的药物、毒物、重金属盐等异源物随胆汁入肠。写成「胆汁只是消化液」，第一节的双重输出和第二节的「经胆汁排出」都会被删掉。
:::

:::insight{label="磷脂这一句已经在预报胆石"}
磷脂与胆汁中胆固醇的溶解状态有关。后文比例小于 $10:1$ 时胆固醇析出成石，用的就是这一户。不要把磷脂只当成「又一种固体成分」。
:::

:::pitfall{label="胆色素在本节只点名"}
固体名单里有胆色素，不等于本节展开血红素加氧酶和黄疸分型。胆红素生成、结合、肠肝循环和三类黄疸是第四节。
:::

:::

## 二、胆汁酸有游离型、结合型及初级、次级之分

胆汁酸（bile acid）按其结构可分为游离胆汁酸（free bile acid）和结合胆汁酸（conjugated bile acid）两大类。游离胆汁酸包括胆酸（cholic acid）、鹅脱氧胆酸（chenodeoxycholic acid）、脱氧胆酸（deoxycholic acid）和少量石胆酸（lithocholic acid）四种。结合胆汁酸是发生了甘氨酸或牛磺酸结合反应的胆汁酸。

胆汁酸按其来源亦可分为初级胆汁酸（primary bile acid）和次级胆汁酸（secondary bile acid）两类。在肝细胞以胆固醇为原料直接合成的胆汁酸称为初级胆汁酸，包括胆酸、鹅脱氧胆酸及其与甘氨酸或牛磺酸的结合产物。初级胆汁酸在肠菌作用下，第 $7$ 位 $\alpha$ 羟基脱氧转变为次级胆汁酸，主要包括脱氧胆酸和石胆酸，及在肝中发生结合反应的胆汁酸。胆汁酸的分类见图25-13，结构式见图25-14。

:::definition{label="游离胆汁酸"}
按结构分出的一户。本版四种：胆酸、鹅脱氧胆酸、脱氧胆酸和少量石胆酸。侧链仍是羧基，还没有接上甘氨酸或牛磺酸。
:::

:::definition{label="结合胆汁酸"}
发生了甘氨酸或牛磺酸结合反应的胆汁酸。图25-14 用甘氨胆酸（侧链 $\mathrm{CONHCH}_2\mathrm{COOH}$）和牛磺胆酸（侧链 $\mathrm{CONHCH}_2\mathrm{CH}_2\mathrm{SO}_3\mathrm{H}$）代表这一户。
:::

:::definition{label="初级胆汁酸"}
肝细胞以胆固醇为原料直接合成。包括胆酸、鹅脱氧胆酸及其与甘氨酸或牛磺酸的结合产物。地点在肝，原料是胆固醇。
:::

:::definition{label="次级胆汁酸"}
初级胆汁酸在肠菌作用下，第 $7$ 位 $\alpha$ 羟基脱氧而成。主要包括脱氧胆酸和石胆酸，以及它们在肝中再发生结合反应的产物。地点在肠道，反应是 $\mathrm{C}7$ 脱氧。
:::

:::pitfall{label="两套分类轴不要并成「四种胆汁酸」"}
游离／结合是结构轴，初级／次级是来源轴。胆酸既是游离的、也是初级的；甘氨胆酸是结合的初级；脱氧胆酸是游离的次级。写成「胆汁酸就四种、结合型另算外校名单」，图25-13 的树就塌了。
:::

:::compare{title="图25-13　胆汁酸的分类（按本版树）"}
| 来源 | 结构 | 本版名单 |
|------|------|----------|
| 初级胆汁酸（肝细胞） | 初级游离胆汁酸 | 胆酸、鹅脱氧胆酸 |
| 初级胆汁酸（肝细胞） | 初级结合胆汁酸 | 甘氨胆酸、甘氨鹅脱氧胆酸、牛磺胆酸、牛磺鹅脱氧胆酸 |

初级写在肝细胞，次级写 $\mathrm{C}7$ 位脱氧、肠道。问「次级是不是肝里羟化出来的」——不是，羟化在肝、脱氧在肠。问「结合是不是只发生在初级」——不是，次级回肝后也可再结合。

胆汁中所含的胆汁酸以结合型为主（占 $90\%$ 以上）。其中甘氨胆汁酸与牛磺胆汁酸的比例为 $3:1$。胆汁中的初级胆汁酸与次级胆汁酸均以钠盐或钾盐的形式存在，形成相应的胆汁酸盐，简称胆盐（bile salts）。

:::definition{label="结合型占 90% 以上"}
胆汁里的胆汁酸以结合型为主。甘氨胆汁酸：牛磺胆汁酸 $= 3:1$。默写时不要把游离型写成「胆汁里的主要形式」。
:::

:::definition{label="胆盐"}
初级与次级胆汁酸均以钠盐或钾盐形式存在，形成胆汁酸盐，简称胆盐（bile salts）。后文乳化、微团，用的是这一户的界面活性。
:::

| | 结合基团 | 图25-14 代表 | 本版比例 |
|--|----------|--------------|----------|
| 甘氨胆汁酸 | 甘氨酸，$\mathrm{CONHCH}_2\mathrm{COOH}$ | 甘氨胆酸 | $3$ |
| 牛磺胆汁酸 | 牛磺酸，$\mathrm{CONHCH}_2\mathrm{CH}_2\mathrm{SO}_3\mathrm{H}$ | 牛磺胆酸 | $1$ |

第二节甘氨酸结合点过甘氨胆酸、牛磺胆酸。本节把比例钉在 $3:1$，后文肝损害时这个比可以从 $2\sim 3$ 降到 $1$。

胆汁酸在结构上系 $24$ 碳的胆烷酸衍生物。初级胆汁酸中的胆酸含有 $3$ 个羟基（$3\alpha$、$7\alpha$、$12\alpha$），鹅脱氧胆酸含有 $2$ 个羟基（$3\alpha$、$7\alpha$）。属于次级胆汁酸的脱氧胆酸和石胆酸的 $\mathrm{C}7$ 位均无羟基存在。

:::definition{label="24 碳胆烷酸衍生物"}
胆汁酸的骨架。胆固醇是 $27$ 碳，侧链氧化断裂后变成 $24$ 碳。后文合成步骤「首先生成 $24$ 碳的胆烷酰 $\mathrm{CoA}$」，用的就是这一句。
:::

| 名称 | 来源 | 羟基 | $\mathrm{C}7$ |
|------|------|------|--------------|
| 胆酸 | 初级游离 | $3\alpha$、$7\alpha$、$12\alpha$（三羟基） | 有 |
| 鹅脱氧胆酸 | 初级游离 | $3\alpha$、$7\alpha$（二羟基） | 有 |
| 脱氧胆酸 | 次级游离 | $3\alpha$、$12\alpha$ | 无 |
| 石胆酸 | 次级游离 | $3\alpha$ | 无 |
| 甘氨胆酸 | 初级结合 | 胆酸骨架 $+$ 甘氨酸 | 有 |
| 牛磺胆酸 | 初级结合 | 胆酸骨架 $+$ 牛磺酸 | 有 |

:::

:::pitfall{label="脱氧胆酸不是「没有羟基的胆酸」"}
脱氧胆酸仍有 $3\alpha$、$12\alpha$ 两个羟基，缺的是 $7\alpha$。石胆酸才只剩 $3\alpha$。写成「次级＝没有羟基」，乳化那一户和三羟基／二羟基的临床比值都会乱。
:::

:::keypoint{label="分类四句先钉死"}
- 游离四种：胆酸、鹅脱氧胆酸、脱氧胆酸、石胆酸。
- 结合：甘氨酸或牛磺酸接在侧链羧基上。
- 初级在肝：胆酸、鹅脱氧胆酸及其结合物。
- 次级在肠：$\mathrm{C}7$ 脱氧 → 脱氧胆酸、石胆酸及其结合物。
:::

## 三、胆汁酸的主要生理功能是促进脂质的消化和吸收

**1. 促进脂质的消化与吸收**　胆汁酸分子含有亲水性和疏水性基团，形成亲水面和疏水面。这种结构特点赋予胆汁酸很强的界面活性，成为较强的乳化剂，将脂质乳化成 $3\sim 10\,\mathrm{\mu m}$ 的细小微团，增加脂质与脂肪酶的接触面积，有利于脂肪的消化。如果胆汁分泌被阻断，可能导致脂肪消化不良引起腹泻。

:::definition{label="胆汁酸是较强的乳化剂"}
分子有亲水面和疏水面，界面活性强。把脂质乳化成 $3\sim 10\,\mathrm{\mu m}$ 细小微团，增大与脂肪酶的接触面积。本版微团直径按 $3\sim 10\,\mathrm{\mu m}$ 记，不要换成别的教材的纳米口径。
:::

:::definition{label="胆汁分泌阻断 → 脂肪泻"}
胆汁分泌被阻断，脂质消化不良，引起腹泻。第一节脂质段的厌油腻、脂肪泻，户头就在这一句。脂溶性维生素 $\mathrm{A}$、$\mathrm{D}$、$\mathrm{E}$、$\mathrm{K}$ 的吸收也会一起受影响。
:::

:::insight{label="亲水／疏水面是乳化的结构原因"}
胆固醇的甾核偏疏水，侧链结合甘氨酸或牛磺酸后极性升高。两面并存才成乳化剂。写成「胆汁酸很油所以能溶脂肪」，把亲水面删了，微团就讲不通。
:::

**2. 溶解和排出胆固醇与胆红素等代谢产物**　人体内约 $99\%$ 的胆固醇随胆汁经肠道排出体外，其中 $1/3$ 以胆汁酸形式，$2/3$ 以直接形式排出体外。胆汁中的胆固醇难溶于水，与胆汁酸及卵磷脂协同作用，使胆固醇分散形成可溶性的微团，使之不易析出沉淀而经胆道转运至肠道排出体外。胆固醇是否从胆汁中沉淀析出主要取决于胆汁中胆汁酸盐和卵磷脂与胆固醇之间的合适比例。如果肝合成胆汁酸或卵磷脂的能力下降、消化道丢失胆汁酸过多或胆汁酸肠肝循环减少，以及排入胆汁中的胆固醇过多（高胆固醇血症）等均可造成胆汁中胆汁酸和卵磷脂与胆固醇的比例下降（小于 $10:1$），易发生胆固醇析出沉淀，形成胆结石（gallstone）。依据胆固醇含量可将胆结石分为 $3$ 类：胆固醇结石（cholesterol stone）、黑色素结石（black pigment stone）和棕色素结石（brown pigment stone）。结石中胆固醇含量超过 $50\%$ 的称为胆固醇结石；黑色素结石一般为 $10\%\sim 30\%$；棕色素结石含胆固醇较少。

:::definition{label="胆固醇随胆汁排出的两本账"}
约 $99\%$ 的胆固醇随胆汁经肠道排出。其中 $1/3$ 以胆汁酸形式，$2/3$ 以直接形式。胆汁酸合成是肝降解胆固醇的最重要途径，但不是唯一出口。
:::

:::definition{label="比例小于 10:1 易成石"}
胆固醇是否析出，主要看胆汁酸盐和卵磷脂与胆固醇的比例。小于 $10:1$ 时胆固醇易沉淀，形成胆结石。成因可以是：肝合成胆汁酸或卵磷脂下降、消化道丢失过多、肠肝循环减少、排入胆汁的胆固醇过多。
:::

:::definition{label="三类胆结石（按胆固醇含量）"}
胆固醇结石：胆固醇超过 $50\%$。黑色素结石：胆固醇一般为 $10\%\sim 30\%$。棕色素结石：含胆固醇较少。本节后文「五」还要按胆汁酸组成比例再讲胆固醇性结石，两处不要并成一句。
:::

:::compare{title="功能两户：乳化 vs 带走胆固醇"}
| | 对象 | 本版要点 | 失败时 |
|--|------|----------|--------|
| 乳化 | 食糜中的脂质 | 亲水／疏水面；$3\sim 10\,\mathrm{\mu m}$ 微团 | 脂肪消化不良、腹泻 |
| 溶解排出 | 胆固醇、胆红素等 | $99\%$ 胆固醇走胆汁；$1/3$ 变胆汁酸、$2/3$ 直接 | 比例 $<10:1$ → 胆结石 |

问「胆汁酸有什么用」先答乳化，再答溶解胆固醇。只答「助消化」，排泄那一户就丢了。
:::

:::cause-effect{title="胆汁酸／卵磷脂相对不足 → 胆固醇结石"}
合成下降、肠道丢失、肠肝循环减少，或胆汁胆固醇过多 → 胆汁酸盐 $+$ 卵磷脂与胆固醇之比 $<10:1$ → 胆固醇析出沉淀 → 胆固醇结石（胆固醇 $>50\%$）。
:::

:::pitfall{label="不要把 99%、1/3、2/3 改成第一节的 50%"}
第一节写：胆固醇肝合成约 $75\%$，约 $50\%$ 在肝内转化成胆汁酸。本节写：排出体外的胆固醇约 $99\%$ 走胆汁，其中 $1/3$ 以胆汁酸形式、$2/3$ 直接形式。前一句是合成／转化份额，后一句是排出路径份额。并成「一半随胆汁排出」，两节数字都错。
:::

## 四、胆汁酸的代谢及胆汁酸的肠肝循环

### （一）初级胆汁酸在肝内由胆固醇转化而来

肝细胞以胆固醇为原料合成初级胆汁酸，这是胆固醇在体内的主要代谢去路。正常人每日约合成 $1\sim 1.5\,\mathrm{g}$ 胆固醇，其中约 $0.4\sim 0.6\,\mathrm{g}$ 在肝内转化为胆汁酸。肝细胞合成胆汁酸的反应步骤较复杂，主要位于内质网和胞质。胆固醇首先在胆固醇 $7\alpha$-羟化酶（cholesterol $7\alpha$-hydroxylase）（$\mathrm{CYP}7\mathrm{A}1$）的催化下生成 $7\alpha$-羟胆固醇。后续的转化反应包括固醇核的 $3\alpha$（$3\beta$-羟基差向异构化为 $3\alpha$-羟基）和 $12\alpha$ 羟化、加氢还原、侧链氧化断裂、与辅酶 $\mathrm{A}$ 结合等多步复杂酶促反应，首先生成 $24$ 碳的胆烷酰 $\mathrm{CoA}$。后者既可水解生成初级游离胆汁酸即胆酸和鹅脱氧胆酸（$12\alpha$ 未羟化），也可直接与甘氨酸或牛磺酸结合生成相应的初级结合胆汁酸，以胆汁酸钠盐或钾盐的形式随胆汁入肠。

:::definition{label="胆固醇转化为胆汁酸 0.4～0.6 g/d"}
正常人每日约合成 $1\sim 1.5\,\mathrm{g}$ 胆固醇，其中约 $0.4\sim 0.6\,\mathrm{g}$ 在肝内转化为胆汁酸。图25-15 把这一户写成「结合胆汁酸合成 $0.4\sim 0.6\,\mathrm{g/d}$」。粪便每日排出也是 $0.4\sim 0.6\,\mathrm{g}$，进出平衡。
:::

:::definition{label="胆固醇 7α-羟化酶（CYP7A1）"}
胆汁酸合成途径的关键酶。胆固醇先在此酶催化下生成 $7\alpha$-羟胆固醇。主要位于内质网和胞质这一套反应的第一步。受终产物胆汁酸的负反馈调节。
:::

:::definition{label="24 碳胆烷酰 CoA"}
羟化、差向异构、加氢还原、侧链氧化断裂、与辅酶 $\mathrm{A}$ 结合之后的枢纽产物。水解 → 初级游离胆汁酸（胆酸；鹅脱氧胆酸为 $12\alpha$ 未羟化）；也可直接与甘氨酸或牛磺酸结合 → 初级结合胆汁酸。
:::

:::insight{label="胆酸和鹅脱氧胆酸的分叉在 12α"}
$12\alpha$ 羟化了，走向胆酸（三羟基）；$12\alpha$ 未羟化，走向鹅脱氧胆酸（二羟基）。后文肝损害时「三羟基胆汁酸量降低最明显」，以及胆酸／鹅脱氧胆酸比值下降，都从这一分叉读。
:::

胆固醇 $7\alpha$-羟化酶是胆汁酸合成途径的关键酶，受终产物胆汁酸的负反馈调节。临床上采用口服考来烯胺减少肠道对胆汁酸的重吸收，促进肝内胆固醇向胆汁酸的转化，以降低血浆胆固醇含量。高胆固醇饮食在抑制 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶合成的同时，亦可诱导胆固醇 $7\alpha$-羟化酶基因的表达。肝细胞通过这两个酶的协同作用维持肝细胞内胆固醇的水平。糖皮质激素、生长激素也可提高胆固醇 $7\alpha$-羟化酶的活性。甲状腺素可诱导胆固醇 $7\alpha$-羟化酶 $\mathrm{mRNA}$ 合成，故甲状腺功能亢进病人血清胆固醇含量降低。

:::definition{label="终产物负反馈"}
胆汁酸多了，反馈抑制胆固醇 $7\alpha$-羟化酶，合成减慢。肠肝循环把大部分胆汁酸送回肝，本身就是这一负反馈的日常来源。
:::

:::definition{label="考来烯胺降胆固醇"}
口服考来烯胺减少肠道对胆汁酸的重吸收 → 回肝的胆汁酸减少 → 负反馈解除 → 肝内胆固醇更多地转化成胆汁酸 → 血浆胆固醇下降。用的是「打断肠肝循环」。
:::

:::definition{label="CYP7A1 与 HMG-CoA 还原酶协同"}
高胆固醇饮食：抑制 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶合成（少造胆固醇），同时诱导胆固醇 $7\alpha$-羟化酶基因表达（多变成胆汁酸）。两酶一起把肝细胞内胆固醇稳住。
:::

:::compare{title="谁在管胆固醇 7α-羟化酶"}
| | 作用 | 本版后果 |
|--|------|----------|
| 胆汁酸（终产物） | 负反馈抑制 | 合成减慢 |
| 考来烯胺 | 减少重吸收，解除负反馈 | 胆固醇更多变成胆汁酸，血浆胆固醇下降 |
| 高胆固醇饮食 | 诱导 $\mathrm{CYP}7\mathrm{A}1$，同时抑制 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶 | 肝内胆固醇水平维持 |
| 糖皮质激素、生长激素 | 提高酶活性 | 转化加快 |
| 甲状腺素 | 诱导该酶 $\mathrm{mRNA}$ 合成 | 甲亢病人血清胆固醇降低 |

问「甲亢为什么血胆固醇低」看这一酶，不要只答「代谢率高」。
:::

:::cause-effect{title="考来烯胺 → 血浆胆固醇下降"}
考来烯胺在肠里拦住胆汁酸 → 重吸收减少 → 肝内胆汁酸少、负反馈解除 → $\mathrm{CYP}7\mathrm{A}1$ 加快胆固醇 → 胆汁酸 → 血浆胆固醇下降。
:::

:::pitfall{label="不要把 0.4～0.6 g 写成胆固醇合成总量"}
每日胆固醇合成是 $1\sim 1.5\,\mathrm{g}$；转成胆汁酸的是其中 $0.4\sim 0.6\,\mathrm{g}$。图25-15 的 $0.4\sim 0.6\,\mathrm{g/d}$ 是结合胆汁酸合成量，也是粪便排泄量，不是胆固醇合成量。
:::

### （二）次级胆汁酸由肠菌作用生成

进入肠道的初级胆汁酸在发挥促进脂质的消化吸收后，在回肠和结肠上段细菌作用下，胆汁酸水解去掉甘氨酸或牛磺酸，释放出游离胆汁酸，然后进一步脱去 $7\alpha$-羟基，生成次级胆汁酸。胆酸脱去 $7\alpha$-羟基生成脱氧胆酸，鹅脱氧胆酸脱去 $7\alpha$-羟基生成石胆酸。这两种游离型次级胆汁酸还可经肠肝循环被重吸收入肝，并与甘氨酸或牛磺酸再次结合成为结合型次级胆汁酸。此外，肠菌还可将鹅脱氧胆酸 $7\alpha$-羟基转变成 $7\beta$-羟基，转化成熊脱氧胆酸（ursodeoxycholic acid）。熊脱氧胆酸含量很少，虽对代谢没有重要意义，但有一定的药理学效应，富含熊脱氧胆酸的熊胆是传统中成药。熊脱氧胆酸在慢性肝病治疗时具有抗氧化应激作用，可降低肝内由于胆汁酸潴留引起的肝损伤，改善肝功能以减缓疾病的进程。

:::definition{label="次级胆汁酸的生成步骤"}
回肠和结肠上段肠菌先水解去掉甘氨酸或牛磺酸，放出游离胆汁酸，再脱去 $7\alpha$-羟基。胆酸 → 脱氧胆酸；鹅脱氧胆酸 → 石胆酸。
:::

:::definition{label="结合型次级胆汁酸"}
游离型次级胆汁酸经肠肝循环回肝后，再与甘氨酸或牛磺酸结合。图25-13 树上的甘氨石胆酸、甘氨脱氧胆酸、牛磺石胆酸、牛磺脱氧胆酸就是这一户。
:::

:::definition{label="熊脱氧胆酸"}
肠菌把鹅脱氧胆酸的 $7\alpha$-羟基转成 $7\beta$-羟基而成。含量很少，对代谢没有重要意义，但有药理学效应：慢性肝病时抗氧化应激，减轻胆汁酸潴留引起的肝损伤。熊胆富含此酸，是传统中成药。
:::

:::compare{title="初级 → 次级：脱的是哪一个羟基"}
| 初级（肝） | 肠菌脱 $7\alpha$-羟基后 | 羟基还剩 |
|------------|----------------------|----------|
| 胆酸（$3\alpha$、$7\alpha$、$12\alpha$） | 脱氧胆酸 | $3\alpha$、$12\alpha$ |
| 鹅脱氧胆酸（$3\alpha$、$7\alpha$） | 石胆酸 | $3\alpha$ |
| 鹅脱氧胆酸（$7\alpha\to 7\beta$） | 熊脱氧胆酸 | 不是「脱氧」，是构型翻转 |

问「脱氧胆酸从哪来」——胆酸脱 $7\alpha$。问「石胆酸从哪来」——鹅脱氧胆酸脱 $7\alpha$。不要对调。
:::

:::insight{label="图25-15 大肠处写的是「水解，脱羧」"}
画面在大肠标「水解，脱羧（肠菌）」，箭头指向排泄 $0.4\sim 0.6\,\mathrm{g/d}$。正文步骤是水解去结合、再脱 $7\alpha$-羟基。认图按画面上的「水解，脱羧」；默写生成次级胆汁酸按正文的 $7\alpha$ 脱氧。两处不要互相覆盖。
:::

:::pitfall{label="熊脱氧胆酸不要写成主要次级胆汁酸"}
本版明文：含量很少，对代谢没有重要意义。主要次级仍是脱氧胆酸和石胆酸。把它写成「第三种主要次级」，图25-13 的树就多出一枝。
:::

### （三）大部分胆汁酸经肠肝循环回收入肝

进入肠道的各种胆汁酸（包括初级和次级、游离型与结合型）约有 $95\%$ 以上可被肠道重吸收，其余的（约为 $5\%$ 石胆酸）随粪便排出。胆汁酸的重吸收有两种方式：结合型胆汁酸在回肠部位被主动重吸收，游离型胆汁酸在小肠各部及大肠被动重吸收。重吸收的胆汁酸经门静脉重新入肝，在肝细胞内，游离胆汁酸被重新转变成结合胆汁酸，与重吸收及新合成的结合胆汁酸一起重新随胆汁入肠。胆汁酸在肝和肠之间的这种不断循环过程称为胆汁酸肠肝循环（enterohepatic circulation of bile acid）。

:::definition{label="回吸收 >95%"}
进入肠道的各种胆汁酸约 $95\%$ 以上被重吸收。图25-15 写成「胆汁酸回吸收 $>95\%$」。其余约为 $5\%$ 石胆酸随粪便排出。
:::

:::definition{label="主动重吸收 vs 被动重吸收"}
结合型：在回肠主动重吸收。游离型：在小肠各部及大肠被动重吸收。两种方式都算进 $>95\%$，不是只有回肠那一户。
:::

:::definition{label="胆汁酸肠肝循环"}
重吸收的胆汁酸经门静脉入肝；肝细胞内游离型重新转变成结合型，与重吸收及新合成的结合胆汁酸一起再随胆汁入肠。肝和肠之间不断循环，称为胆汁酸肠肝循环。
:::

:::compare{title="谁在回肠主动，谁在全程被动"}
| | 部位 | 方式 | 图25-15 |
|--|------|------|---------|
| 结合型胆汁酸 | 回肠 | 主动重吸收 | 回肠段实线箭头「主动吸收」 |
| 游离型胆汁酸 | 小肠各部及大肠 | 被动重吸收 | 小肠／大肠虚线「被动吸收」 |
| 合计 | — | — | 回吸收 $>95\%$，经门静脉回肝 |

问「石胆酸为什么容易丢」——游离、又难溶，主动吸收这一户吃不着它。后文硫酸化是肝给它补的「再丢一次」。
:::

机体内胆汁酸储备的总量称为胆汁酸库（bile acid pool）。成人的胆汁酸库共约 $3\sim 5\,\mathrm{g}$，即使全部排入小肠也难满足每日正常膳食中脂质消化吸收的需要。人体每天约进行 $6\sim 12$ 次肠肝循环，从肠道吸收的胆汁酸总量可达 $12\sim 32\,\mathrm{g}$，借此有效的肠肝循环机制可使有限的胆汁酸库存循环利用，以满足机体对胆汁酸的生理需求（图25-15）。

:::definition{label="胆汁酸库 3～5 g"}
体内胆汁酸储备的总量。成人共约 $3\sim 5\,\mathrm{g}$。图25-15 写成「代谢池 $3\sim 5\,\mathrm{g}$」。全部一次排入小肠也不够一天的脂质消化，所以必须循环。
:::

:::definition{label="每天 6～12 次循环"}
人体每天约进行 $6\sim 12$ 次肠肝循环，从肠道吸收的胆汁酸总量可达 $12\sim 32\,\mathrm{g}$。有限的库存靠循环重复使用。
:::

:::insight{label="3～5 g 乘 6～12 次，约等于 12～32 g"}
库 $3\,\mathrm{g}$ 转 $6$ 次是 $18\,\mathrm{g}$ 量级，库 $5\,\mathrm{g}$ 转 $12$ 次可到 $60\,\mathrm{g}$ 量级；本版给出的吸收总量是 $12\sim 32\,\mathrm{g}$，按这个区间记，不要自己另乘一套。
:::

:::insight{label="图25-15 按画面顺时针认一圈"}
肝：胆固醇 → 结合胆汁酸（合成 $0.4\sim 0.6\,\mathrm{g/d}$，代谢池 $3\sim 5\,\mathrm{g}$）。胆道入小肠。小肠：被动吸收（虚线）加回肠主动吸收（实线），回吸收 $>95\%$，走门静脉回肝。大肠：肠菌「水解，脱羧」，排泄 $0.4\sim 0.6\,\mathrm{g/d}$。进出都是 $0.4\sim 0.6\,\mathrm{g/d}$，池才能维持 $3\sim 5\,\mathrm{g}$。
:::

:::timeline{period="胆汁酸走一圈肠肝循环"}
- **肝里合成** 胆固醇经 CYP7A1 变成初级结合胆汁酸，入胆道
- **小肠乳化** 入肠后把脂质打成 3～10μm 微团
- **回肠主动、全程被动** 结合型在回肠主动重吸收，游离型在小肠各部及大肠被动重吸收，合计大于 95%
- **门静脉回肝** 游离型再结合，与新合成的一起再入胆汁
- **大肠丢一点** 肠菌水解、脱羧，粪便排出 0.4～0.6 g/d，正好补上肝每天新合成的量
:::

未被肠道吸收的小部分胆汁酸在肠菌的作用下，衍生成多种胆烷酸并由粪便排出。每日仅从粪便排出约 $0.4\sim 0.6\,\mathrm{g}$ 胆汁酸，与肝细胞合成的胆汁酸量相平衡。此外，经肠肝循环回收入肝的石胆酸在肝中除了与甘氨酸或牛磺酸结合外，还硫酸化生成硫酸甘氨石胆酸和硫酸牛磺石胆酸。这些双重结合的石胆酸在肠道中不容易去结合，亦不容易被肠道重吸收因而从粪便中排出。因此，正常胆汁中石胆酸的含量甚微。

:::definition{label="粪便排泄 0.4～0.6 g/d"}
每日仅从粪便排出约 $0.4\sim 0.6\,\mathrm{g}$ 胆汁酸，与肝细胞合成量相平衡。图25-15 大肠箭头标的就是这一户。
:::

:::definition{label="石胆酸双重结合后更易排出"}
回肝的石胆酸除与甘氨酸或牛磺酸结合外，还硫酸化，生成硫酸甘氨石胆酸和硫酸牛磺石胆酸。双重结合后不易去结合、不易被重吸收，从粪便排出。所以正常胆汁中石胆酸含量甚微。
:::

:::compare{title="图25-15 四个本版数字"}
| 画面位置 | 本版数字 | 不要写成 |
|----------|----------|----------|
| 肝内结合胆汁酸 | 合成 $0.4\sim 0.6\,\mathrm{g/d}$ | 胆固醇合成 $1\sim 1.5\,\mathrm{g}$ |
| 肝内代谢池 | $3\sim 5\,\mathrm{g}$ | 「十几克库存」 |
| 门静脉回吸收 | $>95\%$ | 「全部吸收」或「约一半」 |
| 大肠排泄 | $0.4\sim 0.6\,\mathrm{g/d}$ | 与合成量不相等 |

四个数字以图25-15 为准。正文「$95\%$ 以上」与画面「$>95\%$」是同一户。
:::

:::pitfall{label="肠肝循环不是「胆汁酸在血液里转圈」"}
循环路径是：肠 → 门静脉 → 肝 → 胆道 → 肠。体循环不是主路。写成「胆汁酸像清蛋白那样在血浆里循环」，和第四节胆红素的血中运输就并了。
:::

:::keypoint{label="肠肝循环三句话"}
- 池只有 $3\sim 5\,\mathrm{g}$，一天要转 $6\sim 12$ 次，吸收总量 $12\sim 32\,\mathrm{g}$。
- 结合型回肠主动，游离型小肠及大肠被动，合计 $>95\%$。
- 粪里只丢 $0.4\sim 0.6\,\mathrm{g/d}$，肝再合成同样多的量补上。
:::

## 五、胆汁酸代谢异常可导致胆石症

### （一）肝细胞损害导致胆汁酸代谢异常

肝实质细胞损害时，总胆汁库量为正常人的 $1/2$ 以下，其中以三羟基胆汁酸量降低最明显。肝组织中 $12\alpha$-羟化酶活力或血清胆汁酸浓度对于判断肝细胞损害及程度，是一种敏感的指标。

:::definition{label="肝损害时胆汁酸库减半"}
肝实质细胞损害时，总胆汁库量为正常人的 $1/2$ 以下。三羟基胆汁酸（胆酸这一户）降低最明显。
:::

:::definition{label="12α-羟化酶与血清胆汁酸"}
肝组织中 $12\alpha$-羟化酶活力或血清胆汁酸浓度，是判断肝细胞损害及程度的敏感指标。$12\alpha$-羟化酶管的是胆酸方向的分叉，所以三羟基这一户先掉。
:::

肝细胞损害时血清总胆酸浓度显著升高，如酒精性肝病患者。肝硬化患者血清总胆汁酸增高，原因是肝脏清除功能降低引起的，另外也与肝血流量下降、肠道吸收功能减退及门-体循环侧枝分流等因素相关。肝细胞损害引起血清胆汁酸比值变化，如甘氨酸结合物与牛磺酸结合物之比，可从正常 $2\sim 3$ 降低到 $1$，胆酸／鹅脱氧胆酸比值明显降低。

:::definition{label="血清总胆汁酸升高"}
肝细胞损害时血清总胆酸显著升高（如酒精性肝病）。肝硬化时增高：肝清除功能降低，加上肝血流量下降、肠道吸收减退、门-体循环侧枝分流。库在肝里变小，血里反而升高——清不掉。
:::

:::definition{label="两个比值都下降"}
甘氨酸结合物／牛磺酸结合物：正常 $2\sim 3$，损害时可降到 $1$。开篇胆汁里甘氨：牛磺是 $3:1$，这里用 $2\sim 3$ 说的是血清结合物之比，按本版各自的句子记。胆酸／鹅脱氧胆酸比值明显降低——还是三羟基这一户先掉。
:::

:::compare{title="肝损害时：库变小，血变多，比值变了"}
| | 正常 | 肝实质损害 |
|--|------|------------|
| 总胆汁酸库 | $3\sim 5\,\mathrm{g}$ | 正常人的 $1/2$ 以下 |
| 三羟基胆汁酸 | 胆酸这一户在 | 降低最明显 |
| 血清总胆汁酸 | 低（肝能清除） | 显著升高 |
| 甘氨／牛磺结合物 | $2\sim 3$ | 可降到 $1$ |
| 胆酸／鹅脱氧胆酸 | 相对较高 | 明显降低 |

问「肝坏了胆汁酸是多是少」——库少、血多。不要只答「合成减少」。
:::

:::cause-effect{title="肝细胞损害 → 血清胆汁酸升高"}
合成／结合／清除都差，加上血流量下降和门-体分流 → 本来该回肝再入胆汁的胆汁酸漏进体循环 → 血清总胆汁酸升高。酒精性肝病、肝硬化都走这一户。
:::

:::pitfall{label="甘氨：牛磺不要混用 3:1 和 2～3"}
胆汁中甘氨胆汁酸与牛磺胆汁酸为 $3:1$。肝损害时血清甘氨酸结合物与牛磺酸结合物之比从正常 $2\sim 3$ 降到 $1$。前一句是胆汁组成，后一句是血清结合物比。并成同一个 $3:1$ 降到 $1$，出处就错了。
:::

### （二）胆汁酸代谢异常导致胆石症

胆固醇性结石与胆汁酸代谢异常有密切关系，主要因素有：胆汁中胆固醇含量过高，胆固醇易于沉淀形成结石；胆汁中胆汁酸盐减少，利于结石形成；胆汁酸的组成比例变化，正常人胆酸、鹅脱氧胆酸及脱氧胆酸比例为 $1.3:1:0.6$，胆石症患者胆酸／鹅脱氧胆酸比例明显降低。

:::definition{label="胆固醇性结石的三个因素"}
①胆汁中胆固醇过高，易于沉淀；②胆汁酸盐减少，利于成石；③组成比例变化。正常人胆酸：鹅脱氧胆酸：脱氧胆酸 $= 1.3:1:0.6$，胆石症患者胆酸／鹅脱氧胆酸比例明显降低。
:::

:::compare{title="成石：前文比例 10:1，这里组成 1.3:1:0.6"}
| | 本版数字 | 问的是 |
|--|----------|--------|
| 胆汁酸盐 $+$ 卵磷脂 ： 胆固醇 | $<10:1$ 易析出 | 够不够把胆固醇溶在微团里 |
| 胆酸 ： 鹅脱氧胆酸 ： 脱氧胆酸 | 正常 $1.3:1:0.6$ | 三种胆汁酸彼此的组成 |
| 胆酸／鹅脱氧胆酸 | 胆石症时明显降低 | 三羟基相对二羟基够不够 |

两类比例都要记。前文三类结石按胆固醇含量分；这里讲的是胆固醇性结石与胆汁酸代谢异常的关系。
:::

:::insight{label="胆酸／鹅脱氧胆酸下降，在肝损害和胆石症里都会出现"}
肝损害段已经写这个比值明显降低；胆石症段再写一次。不是两件无关的事：三羟基合成（$12\alpha$-羟化）弱了，乳化／溶胆固醇的能力一起变差。
:::

:::pitfall{label="不要用外校的「初级全是结合型」替换图25-13"}
本版初级既有游离（胆酸、鹅脱氧胆酸）也有结合（甘氨／牛磺四户）。次级同样两套。胆汁里以结合型为主（$90\%$ 以上），不等于分类树上没有游离型。
:::

:::memory{label="本节必背分户"}
- 胆汁：肝细胞分泌。肝胆汁稀而偏碱；胆囊胆汁浓缩、偏酸。固体一半是胆汁酸盐。既是消化液，也是排泄液。
- 分类两轴：游离（胆酸、鹅脱氧胆酸、脱氧胆酸、石胆酸）／结合（甘氨酸或牛磺酸）；初级（肝，胆酸、鹅脱氧胆酸及其结合物）／次级（肠，$\mathrm{C}7$ 脱氧 → 脱氧胆酸、石胆酸及其结合物）。图25-13。
- 结合型占 $90\%$ 以上；甘氨：牛磺 $= 3:1$。胆酸三羟基 $3\alpha$、$7\alpha$、$12\alpha$；鹅脱氧胆酸 $3\alpha$、$7\alpha$；次级 $\mathrm{C}7$ 无羟基。图25-14。
- 功能：乳化成 $3\sim 10\,\mathrm{\mu m}$ 微团；约 $99\%$ 胆固醇走胆汁（$1/3$ 胆汁酸、$2/3$ 直接）；比例 $<10:1$ 易成石。
- 合成：胆固醇 $1\sim 1.5\,\mathrm{g/d}$，转成胆汁酸 $0.4\sim 0.6\,\mathrm{g/d}$。关键酶 $\mathrm{CYP}7\mathrm{A}1$，负反馈；考来烯胺打断循环以降胆固醇。
- 肠肝循环（图25-15）：池 $3\sim 5\,\mathrm{g}$；回吸收 $>95\%$（结合型回肠主动，游离型小肠及大肠被动）；每天 $6\sim 12$ 次，吸收 $12\sim 32\,\mathrm{g}$；粪排 $0.4\sim 0.6\,\mathrm{g/d}$。石胆酸可再硫酸化后排出。
- 肝损害：库 $<1/2$，三羟基降最明显；血清总胆汁酸升高；甘氨／牛磺结合物比 $2\sim 3\to 1$。胆石症组成比 $1.3:1:0.6$，胆酸／鹅脱氧胆酸下降。
:::

:::keypoint{label="本节不写胆色素和黄疸"}
胆红素来自血红素加氧酶，未结合／结合、清蛋白运输、溶血性／肝细胞性／阻塞性黄疸，全部是第四节。本节固体名单里的「胆色素」只点名。
:::
