# 第五节　逆转录

第四节把核染色体写成多复制子、端粒酶和每个周期只复制一次，把线粒体 $\mathrm{DNA}$ 写成 $\mathrm{D}$ 环。本节换到另一类遗传物质：某些病毒的基因组是 $\mathrm{RNA}$，复制方向是 $\mathrm{RNA}\rightarrow\mathrm{DNA}$，叫做逆转录。不是所有 $\mathrm{RNA}$ 病毒都走这条路。酶是 $1970$ 年发现的逆转录酶，三步把单链 $\mathrm{RNA}$ 写成双链 $\mathrm{DNA}$ 前病毒，可以独立繁殖或整合进宿主基因组。发现本身拓展了中心法则，并落到癌基因、$\mathrm{HIV}$ 和 $\mathrm{cDNA}$ 法。章末收全章小结和思考题。

:::concept{term="先问基因组是不是 RNA、是不是逆转录病毒，再问三步怎么写成双链 DNA"}
看见“逆转录”，不要先跳到 $\mathrm{cDNA}$ 文库。户头是：遗传物质为 $\mathrm{RNA}$ 的一类病毒，信息流动 $\mathrm{RNA}\rightarrow\mathrm{DNA}$，与转录相反。酶有三种活性，产物是前病毒；整合是致病原因之一。中心法则、癌基因、$\mathrm{HIV}$、试管内 $\mathrm{Klenow}$ 做第二链，都挂在这三步后面。
:::

双链 $\mathrm{DNA}$ 是大多数生物的遗传物质。然而，某些病毒的遗传物质是 $\mathrm{RNA}$。原核生物的质粒，真核生物的线粒体 $\mathrm{DNA}$，都是染色体外存在的 $\mathrm{DNA}$。这些非染色体基因组，采用特殊的方式进行复制。

:::definition{label="大多数生物的遗传物质是双链 DNA"}
双链 $\mathrm{DNA}$ 是大多数生物的遗传物质。例外先写在前：某些病毒用 $\mathrm{RNA}$。不要据此把真核基因的物质基础改成 $\mathrm{RNA}$——第十三章已经把 $\mathrm{RNA}$ 病毒写成基因定义里的例外。
:::

:::definition{label="非染色体基因组用特殊方式复制"}
原核质粒、真核 $\mathrm{mtDNA}$ 是染色体外的 $\mathrm{DNA}$；某些病毒则是 $\mathrm{RNA}$ 基因组。教材把它们合称为非染色体基因组，复制方式特殊：质粒自我复制并作载体，$\mathrm{mtDNA}$ 走 $\mathrm{D}$ 环，逆转录病毒走本节。
:::

:::compare{title="三种“特殊复制”不要并成一张图"}
| | 遗传物质 | 复制方式 | 在哪一节 |
|--|----------|----------|----------|
| 质粒 | 染色体外 $\mathrm{DNA}$ | 自我复制；基因工程载体 | 第四节点名来历 |
| $\mathrm{mtDNA}$ | 细胞器 $\mathrm{DNA}$ | $\mathrm{D}$ 环；$\mathrm{pol}\ \gamma$ | 第四节第六部分 |
| 逆转录病毒 | $\mathrm{RNA}$ | $\mathrm{RNA}\rightarrow\mathrm{DNA}$ 前病毒 | 本节 |

“特殊”只说明不走核染色体那一套多复制子机器，不说明机制相同。
:::

:::pitfall{label="染色体外 DNA 不是 RNA 病毒"}
质粒和 $\mathrm{mtDNA}$ 仍是 $\mathrm{DNA}$。只有“某些病毒”把遗传物质换成 $\mathrm{RNA}$。把三者都答成逆转录，第四节的 $\mathrm{D}$ 环和 $\mathrm{pol}\ \gamma$ 会失踪。
:::

## 一、逆转录病毒的基因组RNA以逆转录机制复制

$\mathrm{RNA}$ 病毒的基因组是 $\mathrm{RNA}$ 而不是 $\mathrm{DNA}$，其复制方式是逆转录（reverse transcription），因此也称为逆转录病毒（retrovirus）。但是，并非所有的 $\mathrm{RNA}$ 病毒都是逆转录病毒。逆转录的信息流动方向（$\mathrm{RNA}\rightarrow\mathrm{DNA}$）与转录过程（$\mathrm{DNA}\rightarrow\mathrm{RNA}$）相反，是一种特殊的复制方式。

:::definition{label="逆转录"}
逆转录（reverse transcription）是以 $\mathrm{RNA}$ 为模板合成 $\mathrm{DNA}$ 的过程。信息流动方向 $\mathrm{RNA}\rightarrow\mathrm{DNA}$，与转录（$\mathrm{DNA}\rightarrow\mathrm{RNA}$）相反。
:::

:::definition{label="逆转录病毒"}
基因组是 $\mathrm{RNA}$、复制方式为逆转录的病毒，称为逆转录病毒（retrovirus）。
:::

:::pitfall{label="并非所有 RNA 病毒都是逆转录病毒"}
教材把这句写在定义后面。基因组是 $\mathrm{RNA}$ 只是必要条件之一，还必须走逆转录这条复制方式。把“$\mathrm{RNA}$ 病毒”和“逆转录病毒”画等号，流感一类不走前病毒整合的题目会并户。
:::

:::insight{label="逆转录是复制方式，不是“把转录倒着念一遍”"}
转录：$\mathrm{DNA}$ 模板 $\rightarrow\mathrm{RNA}$ 产物。逆转录：$\mathrm{RNA}$ 模板 $\rightarrow\mathrm{DNA}$ 产物。酶、引物、是否进入宿主基因组，都和 $\mathrm{RNA}$ 聚合酶那一章不是同一套。第十五章的转录不要倒过来当本节机制。
:::

:::compare{title="转录 vs 逆转录"}
| | 转录 | 逆转录 |
|--|------|--------|
| 模板 | $\mathrm{DNA}$ | $\mathrm{RNA}$ |
| 产物 | $\mathrm{RNA}$ | $\mathrm{DNA}$（经杂化双链到双链 $\mathrm{DNA}$） |
| 信息方向 | $\mathrm{DNA}\rightarrow\mathrm{RNA}$ | $\mathrm{RNA}\rightarrow\mathrm{DNA}$ |
| 本节深度 | 只作对照 | 三步、三种酶活性、前病毒、整合 |

中心法则里两条箭头都成立；逆转录是对“只有 $\mathrm{DNA}$ 能传代”的拓展，不是取消转录。
:::

$1970$ 年，$\mathrm{Temin}\ \mathrm{H}.$ 和 $\mathrm{Baltimore}\ \mathrm{D}.$ 分别从 $\mathrm{RNA}$ 病毒中发现能催化以 $\mathrm{RNA}$ 为模板合成双链 $\mathrm{DNA}$ 的酶，称为逆转录酶（reverse transcriptase），全称是依赖 $\mathrm{RNA}$ 的 $\mathrm{DNA}$ 聚合酶（$\mathrm{RNA}$-dependent $\mathrm{DNA}$ polymerase）。

:::definition{label="逆转录酶"}
逆转录酶（reverse transcriptase）能催化以 $\mathrm{RNA}$ 为模板合成双链 $\mathrm{DNA}$，全称依赖 $\mathrm{RNA}$ 的 $\mathrm{DNA}$ 聚合酶（$\mathrm{RNA}$-dependent $\mathrm{DNA}$ polymerase）。$1970$ 年 $\mathrm{Temin}\ \mathrm{H}.$ 和 $\mathrm{Baltimore}\ \mathrm{D}.$ 分别发现。
:::

:::definition{label="逆转录酶其实有三种活性"}
全称只点出“依赖 $\mathrm{RNA}$ 的 $\mathrm{DNA}$ 聚合酶”。后文立刻补上：还有依赖 $\mathrm{DNA}$ 的 $\mathrm{DNA}$ 聚合酶活性和 $\mathrm{RNase}\ \mathrm{H}$ 活性。三步反应三张面孔，缺一不能从单链 $\mathrm{RNA}$ 走到双链 $\mathrm{DNA}$。
:::

:::insight{label="“分别发现”是同一年两家独立的工作"}
教材写 $\mathrm{Temin}$ 和 $\mathrm{Baltimore}$ 分别从 $\mathrm{RNA}$ 病毒中发现。不要改成师生传承或只记一个人。发现的意义放到第二部分：拓展中心法则、癌基因、工具酶。
:::

从单链 $\mathrm{RNA}$ 到双链 $\mathrm{DNA}$ 的生成可分为三步（图14-19）：首先是逆转录酶以病毒基因组 $\mathrm{RNA}$ 为模板，催化 $\mathrm{dNTP}$ 聚合生成 $\mathrm{DNA}$ 互补链，产物是 $\mathrm{RNA}/\mathrm{DNA}$ 杂化双链。然后，杂化双链中的 $\mathrm{RNA}$ 被逆转录酶中有 $\mathrm{RNase}$ 活性的组分水解，被感染细胞内的 $\mathrm{RNase}\ \mathrm{H}$（$\mathrm{H}=\mathrm{Hybrid}$）也可水解 $\mathrm{RNA}$ 链。$\mathrm{RNA}$ 分解后剩下的单链 $\mathrm{DNA}$ 再用作模板，由逆转录酶催化合成第二条 $\mathrm{DNA}$ 互补链。逆转录酶有三种活性：$\mathrm{RNA}$ 依赖的 $\mathrm{DNA}$ 聚合酶活性，$\mathrm{DNA}$ 依赖的 $\mathrm{DNA}$ 聚合酶活性和 $\mathrm{RNase}\ \mathrm{H}$ 活性，作用需 $\mathrm{Zn}^{2+}$ 为辅因子。合成反应也按照 $5'\rightarrow 3'$ 延长的规律。有研究发现，病毒自身的 $\mathrm{tRNA}$ 可用作复制引物。

::figure{src="/images/biochemistry/textbook/p0299_01.png" caption="图14-19　逆转录酶催化的 cDNA 合成。（a）逆转录病毒细胞内复制：虚线 RNA 模板经逆转录酶合成 cDNA 第一链，得 RNA/DNA 杂化双链；RNase H 水解 RNA，剩下单链 DNA；逆转录酶再合成 cDNA 第二链，双链 DNA 前病毒可整合入宿主基因组 DNA。病毒 tRNA 可作为第二链引物。（b）试管内合成 cDNA：带 poly A 的 RNA 模板经逆转录酶得杂化双链（T 配对 A）；碱水解去掉 RNA，单链 cDNA 的 3′ 端形成发夹作引物；DNA 聚合酶Ⅰ（Klenow）合成第二链；S1 核酸酶切去发夹，得到双链 cDNA。" alt="（a）病毒 RNA 经逆转录酶和 RNase H 变成双链 DNA 并整合进宿主基因组；（b）体外 poly A RNA 经逆转录、碱水解、发夹引物、Klenow 和 S1 酶得到双链 cDNA"}

:::definition{label="从单链 RNA 到双链 DNA 的三步"}
①逆转录酶以病毒基因组 $\mathrm{RNA}$ 为模板，催化 $\mathrm{dNTP}$ 聚合，产物是 $\mathrm{RNA}/\mathrm{DNA}$ 杂化双链。②杂化双链中的 $\mathrm{RNA}$ 被逆转录酶的 $\mathrm{RNase}$ 活性水解，被感染细胞的 $\mathrm{RNase}\ \mathrm{H}$ 也可水解。③剩下的单链 $\mathrm{DNA}$ 作模板，逆转录酶合成第二条 $\mathrm{DNA}$ 互补链。
:::

:::definition{label="RNA/DNA 杂化双链"}
第一步的直接产物。还不是前病毒。必须先把 $\mathrm{RNA}$ 水解掉，才露出单链 $\mathrm{DNA}$ 去写第二链。
:::

:::definition{label="RNase H"}
$\mathrm{H}=\mathrm{Hybrid}$。水解 $\mathrm{RNA}/\mathrm{DNA}$ 杂化双链中的 $\mathrm{RNA}$。来源可以是逆转录酶自身的组分，也可以是被感染细胞内的 $\mathrm{RNase}\ \mathrm{H}$。图14-19（a）把这一步标在杂化双链和单链 $\mathrm{DNA}$ 之间。
:::

:::definition{label="逆转录酶的三种活性"}
$\mathrm{RNA}$ 依赖的 $\mathrm{DNA}$ 聚合酶活性；$\mathrm{DNA}$ 依赖的 $\mathrm{DNA}$ 聚合酶活性；$\mathrm{RNase}\ \mathrm{H}$ 活性。辅因子为 $\mathrm{Zn}^{2+}$。合成仍按 $5'\rightarrow 3'$ 延长。
:::

:::definition{label="病毒 tRNA 可作为复制引物"}
有研究发现，病毒自身的 $\mathrm{tRNA}$ 可用作复制引物。图14-19 注：（a）病毒的 $\mathrm{tRNA}$ 可作为 $\mathrm{cDNA}$ 第二链合成的引物。细胞内复制仍要 $3'$-$\mathrm{OH}$，不是无引物起始。
:::

:::timeline{period="细胞内三步写成双链 DNA"}
- **第一链** 逆转录酶以病毒 RNA 为模板聚合 dNTP，得到 RNA/DNA 杂化双链
- **去 RNA** 酶自身的 RNase 活性或细胞内 RNase H 水解杂化双链中的 RNA
- **第二链** 剩下的单链 DNA 作模板，逆转录酶（DNA 依赖的 DNA 聚合酶活性）合成第二条 DNA
- **去向** 双链 DNA 即前病毒：可独立繁殖，或重组整合进宿主基因组
:::

:::compare{title="三种活性各自对应哪一步"}
| 活性 | 模板 | 本节对应 |
|------|------|----------|
| $\mathrm{RNA}$ 依赖的 $\mathrm{DNA}$ 聚合酶 | 病毒基因组 $\mathrm{RNA}$ | 第一步，写 $\mathrm{cDNA}$ 第一链 |
| $\mathrm{RNase}\ \mathrm{H}$ | $\mathrm{RNA}/\mathrm{DNA}$ 杂合体中的 $\mathrm{RNA}$ | 第二步，露出单链 $\mathrm{DNA}$ |
| $\mathrm{DNA}$ 依赖的 $\mathrm{DNA}$ 聚合酶 | 单链 $\mathrm{DNA}$ | 第三步，写第二链 |

全称只覆盖第一栏。答题漏掉后两栏，三步会停在杂化双链。
:::

:::pitfall{label="第一步产物不是双链 DNA 前病毒"}
第一步只得到 $\mathrm{RNA}/\mathrm{DNA}$ 杂化双链。前病毒是三步走完的双链 $\mathrm{DNA}$。把杂化双链答成已经可以整合，第二步 $\mathrm{RNase}\ \mathrm{H}$ 就没有必要。
:::

:::pitfall{label="RNase H 不是随便水解所有 RNA"}
$\mathrm{H}$ 表示 Hybrid。它针对杂化双链里的 $\mathrm{RNA}$。细胞内还有别的 $\mathrm{RNase}$，本节点名的是这一号。图14-19（b）试管内用碱水解去 $\mathrm{RNA}$，那是体外方法，不要写回病毒生活史当生理步骤。
:::

:::pitfall{label="延长方向仍是 5′→3′，不要写成逆转录就反向聚合"}
“逆”指信息方向与转录相反，不指磷酸二酯键从 $3'$ 往 $5'$ 长。引物提供 $3'$-$\mathrm{OH}$，$\mathrm{dNTP}$ 加到 $3'$ 端，和普通 $\mathrm{DNA}$ 聚合酶同一条化学规则。
:::

:::insight{label="Zn2+ 是辅因子，不要改成 Mg2+ 口诀"}
教材写作用需 $\mathrm{Zn}^{2+}$。普通 $\mathrm{DNA}$ 聚合酶常用 $\mathrm{Mg}^{2+}$ 的印象不能覆盖这一句。本版没有另给一套金属离子表，复习按 $\mathrm{Zn}^{2+}$ 记。
:::

:::keypoint{label="三步可以缩成一句话"}
$\mathrm{RNA}$ 模板 $\rightarrow$ 杂化双链 $\rightarrow$ 水解 $\mathrm{RNA}$ $\rightarrow$ 单链 $\mathrm{DNA}$ 模板 $\rightarrow$ 双链 $\mathrm{DNA}$。酶是同一逆转录酶的三种活性，细胞 $\mathrm{RNase}\ \mathrm{H}$ 可以帮忙切 $\mathrm{RNA}$。
:::

按上述方式，$\mathrm{RNA}$ 病毒在细胞内复制成双链 $\mathrm{DNA}$ 的前病毒（provirus）。前病毒保留了 $\mathrm{RNA}$ 病毒全部遗传信息，并可在细胞内独立繁殖。在某些情况下，前病毒基因组通过基因重组（gene recombination），插入到细胞基因组内，并随宿主基因一起复制和表达。这种重组方式称为整合（integration）。前病毒独立繁殖或整合，可成为致病的原因。

:::definition{label="前病毒"}
前病毒（provirus）是 $\mathrm{RNA}$ 病毒在细胞内复制成的双链 $\mathrm{DNA}$。它保留病毒全部遗传信息，并可在细胞内独立繁殖。
:::

:::definition{label="整合"}
前病毒基因组通过基因重组（gene recombination）插入细胞基因组，并随宿主基因一起复制和表达，这种重组方式称为整合（integration）。
:::

:::definition{label="独立繁殖或整合都可致病"}
两条去向教材都写了：前病毒独立繁殖，或整合进宿主基因组。都可以成为致病原因。不是“只有整合才致病”，也不是“整合只是无害寄生”。
:::

:::compare{title="前病毒的两条去向"}
| 去向 | 教材原句 | 图14-19 |
|------|----------|---------|
| 独立繁殖 | 保留全部遗传信息，可在细胞内独立繁殖 | （a）走到双链 $\mathrm{DNA}$ 即可 |
| 整合 | 基因重组插入细胞基因组，随宿主一起复制和表达 | （a）最下一层：插入宿主基因组 $\mathrm{DNA}$ |

致病原因挂在“独立繁殖或整合”这一整句上。
:::

:::pitfall{label="整合不是普通的杂交双链退火"}
教材用的词是基因重组、插入到细胞基因组内。产物随宿主基因一起复制和表达，等于把病毒信息写进宿主染色体。把它答成“$\mathrm{RNA}/\mathrm{DNA}$ 杂化双链贴在宿主 $\mathrm{DNA}$ 旁边”，既不是重组，也不能随宿主复制。
:::

:::insight{label="保留全部遗传信息，所以 RNA 病毒也能传代"}
前病毒是双链 $\mathrm{DNA}$，但信息来自基因组 $\mathrm{RNA}$。这是第二部分“$\mathrm{RNA}$ 同样兼有遗传信息传代功能”的分子落点。没有这三步，中心法则里 $\mathrm{RNA}$ 只能当表达中间体。
:::

:::cause-effect{title="为什么整合能成为致病原因"}
- **因** 前病毒插入宿主基因组后，随宿主一起复制和表达，病毒信息不再只存在于游离 $\mathrm{DNA}$
- **果** 可以长期存在、随细胞分裂传下去，并在表达时干扰宿主；独立繁殖则在细胞内扩增同样可致病
:::

## 二、逆转录的发现拓展了中心法则

逆转录酶或逆转录现象的发现是分子生物学研究中的重大事件。中心法则认为，$\mathrm{DNA}$ 的功能兼有遗传信息的传代和表达，因此 $\mathrm{DNA}$ 处于生命活动的中心位置。逆转录现象说明，至少在某些生物，$\mathrm{RNA}$ 同样兼有遗传信息传代功能。这是对传统的中心法则的拓展。

:::definition{label="传统中心法则里 DNA 的双重功能"}
中心法则认为，$\mathrm{DNA}$ 的功能兼有遗传信息的传代和表达，因此 $\mathrm{DNA}$ 处于生命活动的中心位置。传代靠复制，表达靠转录和翻译。
:::

:::definition{label="逆转录拓展中心法则"}
至少在某些生物，$\mathrm{RNA}$ 同样兼有遗传信息传代功能。这是对传统中心法则的拓展，不是把 $\mathrm{DNA}$ 从中心位置撤掉。
:::

:::pitfall{label="拓展不是“中心法则作废”"}
教材用“拓展”。$\mathrm{DNA}$ 仍处于大多数生物生命活动的中心；补上的是：某些生物的 $\mathrm{RNA}$ 也能传代。把发现答成“中心法则被推翻”，和“大多数生物遗传物质是双链 $\mathrm{DNA}$”那句冲突。
:::

:::insight{label="传代功能挂在前病毒这一步，不是挂在 mRNA"}
细胞里的 $\mathrm{mRNA}$ 仍是表达中间体，不把基因组传给子代。逆转录病毒的基因组 $\mathrm{RNA}$ 经三步写成前病毒 $\mathrm{DNA}$，才进入传代。不要把“$\mathrm{RNA}$ 也能传代”听成“所有 $\mathrm{RNA}$ 都是遗传物质”。
:::

:::compare{title="中心法则箭头在本章怎么排"}
| 过程 | 方向 | 本章位置 |
|------|------|----------|
| 复制 | $\mathrm{DNA}\rightarrow\mathrm{DNA}$ | 第一至第四节 |
| 转录 | $\mathrm{DNA}\rightarrow\mathrm{RNA}$ | 对照；机制在第十五章 |
| 逆转录 | $\mathrm{RNA}\rightarrow\mathrm{DNA}$ | 本节 |
| 翻译 | $\mathrm{RNA}\rightarrow$ 蛋白质 | 本章不展开 |

$\mathrm{RNA}\rightarrow\mathrm{RNA}$ 的复制方式，本版本节未立为逆转录病毒的主路径。
:::

对逆转录病毒的研究，拓宽了 $20$ 世纪初期的病毒致癌理论，至 $20$ 世纪 $70$ 年代初，从逆转录病毒中发现了癌基因。至今，癌基因研究仍是病毒学、肿瘤学和分子生物学领域的重大课题。艾滋病病原为人类免疫缺陷病毒（human immunodeficiency virus，$\mathrm{HIV}$），$\mathrm{HIV}$ 也是 $\mathrm{RNA}$ 病毒，有逆转录活性。

:::definition{label="从逆转录病毒中发现癌基因"}
对逆转录病毒的研究拓宽了 $20$ 世纪初的病毒致癌理论。$20$ 世纪 $70$ 年代初，从逆转录病毒中发现了癌基因。至今仍是病毒学、肿瘤学和分子生物学的重大课题。
:::

:::definition{label="HIV"}
人类免疫缺陷病毒（human immunodeficiency virus，$\mathrm{HIV}$）是艾滋病病原。它也是 $\mathrm{RNA}$ 病毒，有逆转录活性。本节把它写成逆转录病毒这一户的医学例子，不展开生活史各期。
:::

:::compare{title="肿瘤在本章出现的两本账"}
| | 第四节端粒酶 | 本节逆转录病毒 |
|--|--------------|----------------|
| 观察 | 增殖活跃的肿瘤细胞端粒酶活性增高；某些肿瘤端粒反而更短 | $70$ 年代初从逆转录病毒中发现癌基因 |
| 机制落点 | 末端维持、治疗靶点 | 前病毒整合／表达，拓宽病毒致癌理论 |
| 不要并户 | 不是 $\mathrm{HIV}$ | 不是端粒缩短 |

:::

:::pitfall{label="HIV 有逆转录活性，不等于“只有 HIV 才有逆转录酶”"}
$\mathrm{HIV}$ 是例子。酶是 $1970$ 年从 $\mathrm{RNA}$ 病毒中发现的，癌基因是从逆转录病毒中发现的。把逆转录酶写成“艾滋病专用酶”，$\mathrm{cDNA}$ 法和 Temin／Baltimore 都会没来历。
:::

:::insight{label="病毒致癌理论和癌基因不是同一年的事"}
教材分了两档：$20$ 世纪初已有病毒致癌理论；拓宽之后，到 $70$ 年代初才从逆转录病毒里发现癌基因。答题不要把“病毒可以致癌”和“癌基因”压缩成一个年代。
:::

分子生物学研究还应用逆转录酶作为获取基因工程目的基因的重要方法之一，此法称为 $\mathrm{cDNA}$ 法。在人类这样庞大的基因组 $\mathrm{DNA}$（$3.2\times 10^{9}\,\mathrm{bp}$）中，要选取其中一个目的基因，有相当大难度。对 $\mathrm{RNA}$ 进行提取、纯化，相对较为可行。取得 $\mathrm{RNA}$ 后，可以通过逆转录方式在试管内操作。用逆转录酶催化 $\mathrm{dNTP}$ 在 $\mathrm{RNA}$ 模板指引下的聚合，生成 $\mathrm{RNA}/\mathrm{DNA}$ 杂化双链。用酶或碱把杂化双链上的 $\mathrm{RNA}$ 除去，剩下的 $\mathrm{DNA}$ 单链再作为第二链合成的模板。在试管内以 $\mathrm{DNA}\ \mathrm{pol}$ Ⅰ 的大片段，即 $\mathrm{Klenow}$ 片段催化 $\mathrm{dNTP}$ 聚合。第二次合成的双链 $\mathrm{DNA}$，称为 $\mathrm{cDNA}$。$\mathrm{c}$ 是互补（complementary）的意思。$\mathrm{cDNA}$ 就是编码蛋白质的基因，通过转录又得到原来的模板 $\mathrm{RNA}$，现在已利用该方法建立了多种不同种属和细胞来源的含所有表达基因的 $\mathrm{cDNA}$ 文库，方便人们从中获取目的基因。

:::definition{label="cDNA 法"}
用逆转录酶获取基因工程目的基因的方法。人基因组 $\mathrm{DNA}$ 达 $3.2\times 10^{9}\,\mathrm{bp}$，直接选取一个目的基因难度大；提取纯化 $\mathrm{RNA}$ 相对可行，再在试管内逆转录。
:::

:::definition{label="cDNA"}
$\mathrm{cDNA}$ 是 complementary $\mathrm{DNA}$，即互补 $\mathrm{DNA}$。试管内第二次合成的双链 $\mathrm{DNA}$。它就是编码蛋白质的基因，通过转录又可得到原来的模板 $\mathrm{RNA}$。
:::

:::definition{label="Klenow 片段在 cDNA 第二链上的位置"}
试管内以 $\mathrm{DNA}\ \mathrm{pol}$ Ⅰ 的大片段即 $\mathrm{Klenow}$ 片段催化 $\mathrm{dNTP}$ 聚合，合成第二链。第二节：$\mathrm{Klenow}$ 片段共 $604$ 个氨基酸残基，有 $\mathrm{DNA}$ 聚合酶活性和 $3'\rightarrow 5'$ 核酸外切酶活性，是实验室合成 $\mathrm{DNA}$ 的常用工具酶。
:::

:::definition{label="cDNA 文库"}
已利用该方法建立多种不同种属和细胞来源、含所有表达基因的 $\mathrm{cDNA}$ 文库，方便从中获取目的基因。文库反映的是表达出来的 $\mathrm{RNA}$，不是基因组里全部 $\mathrm{DNA}$。
:::

:::timeline{period="试管内 cDNA 法"}
- **取 RNA** 提取、纯化 RNA，避开在 3.2×10^9 bp 基因组里直接捞一个基因
- **第一链** 逆转录酶以 RNA 为模板聚合 dNTP，得 RNA/DNA 杂化双链
- **去 RNA** 用酶或碱除去杂化双链上的 RNA
- **第二链** 单链 DNA 作模板；3′ 端发夹可作引物；Klenow 片段催化聚合
- **成品** 双链 cDNA；可建表达基因的 cDNA 文库
:::

| | （a）细胞内 | （b）试管内 |
|--|-------------|------------|
| 模板 | 病毒基因组 $\mathrm{RNA}$ | 提取的 $\mathrm{RNA}$（图中带 $\mathrm{poly}\ \mathrm{A}$） |
| 写第一链 | 逆转录酶 | 逆转录酶 |
| 去 $\mathrm{RNA}$ | $\mathrm{RNase}\ \mathrm{H}$（酶自身或细胞） | 酶或碱；图中标碱水解 |

:::

:::pitfall{label="cDNA 不是基因组 DNA 的随机片段"}
它来自 $\mathrm{RNA}$ 模板，对应编码蛋白质、已经被转录出来的序列。真核还有内含子：成熟 $\mathrm{mRNA}$ 已切掉内含子，所以 $\mathrm{cDNA}$ 通常不含基因组里的内含子。教材原句：“$\mathrm{cDNA}$ 就是编码蛋白质的基因，通过转录又得到原来的模板 $\mathrm{RNA}$”。把 $\mathrm{cDNA}$ 文库答成“整个人基因组文库”，$3.2\times 10^{9}\,\mathrm{bp}$ 那句就失去意义。
:::

:::pitfall{label="试管内第二链默认不是再靠逆转录酶"}
教材把第二链明确交给 $\mathrm{Klenow}$ 片段。细胞内第二链可以仍用逆转录酶的 $\mathrm{DNA}$ 依赖活性。把（b）也答成“逆转录酶写两条链”，图14-19 右侧的 $\mathrm{DNA}$ 聚合酶Ⅰ和 $\mathrm{S}1$ 核酸酶会对不上。
:::

:::pitfall{label="碱水解是体外去 RNA，不是病毒生活史"}
细胞内靠 $\mathrm{RNase}\ \mathrm{H}$。试管里可以用酶或碱。图14-19（b）画的是碱水解后出现 $3'$ 发夹。不要把氢氧化钠写进 $\mathrm{HIV}$ 复制步骤。
:::

:::insight{label="发夹引物解释为什么体外可以不另加引物"}
单链 $\mathrm{cDNA}$ 的 $3'$ 端能够形成发夹，自身提供 $3'$-$\mathrm{OH}$，$\mathrm{Klenow}$ 就能写第二链。这是图注给出的体外技巧。细胞内则点名病毒 $\mathrm{tRNA}$。两种引物策略不要对调。
:::

:::insight{label="3.2×10^9 bp 是“为什么先抽 RNA”的数量级"}
人基因组太大，直接在 $\mathrm{DNA}$ 里选一个基因很难。表达基因先变成 $\mathrm{RNA}$，种类和长度都更好操作，再逆转录回 $\mathrm{DNA}$。第十三章编码序列只占全基因组 $1.5\%$，和这里“先抽 $\mathrm{RNA}$”是同一方向的理由，本节用的数字是 $3.2\times 10^{9}\,\mathrm{bp}$。
:::

:::keypoint{label="cDNA 法四步"}
- 抽 $\mathrm{RNA}$（避开 $3.2\times 10^{9}\,\mathrm{bp}$ 的基因组）。
- 逆转录酶写杂化双链。
- 酶或碱去 $\mathrm{RNA}$。
- $\mathrm{Klenow}$ 写第二链 $\rightarrow$ 双链 $\mathrm{cDNA}$ $\rightarrow$ 文库。
:::

## 本章小结

$\mathrm{DNA}$ 复制是指 $\mathrm{DNA}$ 基因组的扩增过程。在此过程中，以亲代 $\mathrm{DNA}$ 作为模板，按照碱基配对原则合成子代 $\mathrm{DNA}$ 分子。复制需多种酶和蛋白质辅因子的参与。细胞内的 $\mathrm{DNA}$ 复制有半保留性、半不连续性和双向性等特征。

原核生物的复制过程包括起始、延长和终止。起始是将 $\mathrm{DNA}$ 双链解开形成复制叉。复制的延长由引物或延长中的子链提供 $3'$-$\mathrm{OH}$，供 $\mathrm{dNTP}$ 掺入生成磷酸二酯键，延长中的子链有前导链和后随链之分，复制产生的不连续片段称为冈崎片段。复制的终止需要去除 $\mathrm{RNA}$ 引物、填补留下的空隙并连接片段之间的缺口使之成为连续的子链 $\mathrm{DNA}$。

真核生物复制发生于细胞周期的 $\mathrm{S}$ 期，其过程与原核生物相似，但更为复杂和精致。复制的延长与核小体组蛋白的分离和重新组装有关。复制的终止需要端粒酶延伸端粒 $\mathrm{DNA}$。

非染色体基因组采用特殊的方式进行复制。逆转录是 $\mathrm{RNA}$ 病毒的复制方式。逆转录现象的发现，加深了人们对中心法则的认识，拓宽了 $\mathrm{RNA}$ 病毒致癌、致病的研究。在基因工程操作上，还可用逆转录酶制备 $\mathrm{cDNA}$。$\mathrm{D}$ 环复制是真核生物线粒体 $\mathrm{DNA}$ 的复制方式。

:::definition{label="本章小结里的 DNA 复制"}
以亲代 $\mathrm{DNA}$ 为模板，按碱基配对合成子代 $\mathrm{DNA}$，即基因组扩增。需多种酶和蛋白质辅因子。细胞内特征：半保留、半不连续、双向。
:::

:::definition{label="本章小结里的原核三阶段"}
起始：解开双链形成复制叉。延长：引物或子链提供 $3'$-$\mathrm{OH}$，$\mathrm{dNTP}$ 掺入成磷酸二酯键；前导链与后随链；不连续片段为冈崎片段。终止：去 $\mathrm{RNA}$ 引物、填空隙、连接缺口，成为连续子链。
:::

:::definition{label="本章小结里的真核三点"}
发生在 $\mathrm{S}$ 期；过程相似但更复杂精致。延长与核小体组蛋白的分离和重新组装有关。终止需要端粒酶延伸端粒 $\mathrm{DNA}$。
:::

:::definition{label="本章小结里的特殊复制"}
逆转录是 $\mathrm{RNA}$ 病毒的复制方式：加深中心法则认识，拓宽致癌致病研究，基因工程上制备 $\mathrm{cDNA}$。$\mathrm{D}$ 环复制是真核 $\mathrm{mtDNA}$ 的复制方式。
:::

:::keypoint{label="本章小结按节收口"}
- 第一节：半保留、双向、半不连续、高保真。
- 第二节：原核 $\mathrm{I}/\mathrm{II}/\mathrm{III}$ 与真核 $\alpha/\delta/\varepsilon/\beta/\gamma$；碱基选择和校读。
- 第三节：$\mathrm{oriC}$、$\mathrm{DnaA}/\mathrm{B}/\mathrm{C}$、引发体、前导／后随、连接酶封口。
- 第四节：$\mathrm{S}$ 期多复制子；聚合酶转换与 $\mathrm{PCNA}$；立刻装核小体；端粒酶爬行；$\mathrm{pre}$-$\mathrm{RC}$ 保证一次；$\mathrm{mtDNA}$ 走 $\mathrm{D}$ 环。
- 第五节：逆转录三步、前病毒、拓展中心法则、$\mathrm{cDNA}$ 法。
:::

:::insight{label="小结把真核终止写成端粒酶，把 mtDNA 单列"}
核染色体线性末端交给端粒酶；线粒体环状交给 $\mathrm{D}$ 环。不要在小结里把 $\mathrm{D}$ 环并进“真核复制终止”。逆转录也不并进 $\mathrm{S}$ 期那一套。
:::

:::pitfall{label="小结的“RNA 病毒的复制方式”仍受“并非所有 RNA 病毒”限制"}
章末说逆转录是 $\mathrm{RNA}$ 病毒的复制方式，第一节正文有例外句。答题先写逆转录病毒，再点并非所有 $\mathrm{RNA}$ 病毒都走这条路。
:::

## 思考题

1. 原核生物 $\mathrm{DNA}$ 的复制体系有哪些酶及蛋白质成分？各有何作用？
2. 真核生物的 $\mathrm{DNA}$ 复制如何实现高速及保真性？
3. 端粒有何作用？为何有些肿瘤的发生与端粒酶有关？
4. $\mathrm{DNA}$ 聚合酶、拓扑酶和连接酶都催化 $3'$，$5'$-磷酸二酯键的生成，各有何不同？
5. 阐述逆转录的基本过程和逆转录现象发现的重大研究价值。

:::tip{label="五道思考题在正文里的户头"}
- 原核体系（第一至第三节）：$\mathrm{DnaA}$ 辨认结合 $\mathrm{oriC}$ 反向重复；$\mathrm{DnaB}$ 解旋酶，在 $\mathrm{DnaC}$ 协同下沿解链方向移动；$\mathrm{SSB}$ 稳定单链；拓扑酶Ⅱ切断、旋转、再连接，把正超螺旋转为负超螺旋；引发酶合成 $\mathrm{RNA}$ 引物（约 $5\sim 10$ 核苷酸，对利福平不敏感）；引发体含 $\mathrm{DnaB}$、$\mathrm{DnaC}$、引发酶；$\mathrm{DNA}\ \mathrm{pol}$ Ⅲ 是延长主力（$10$ 种／$17$ 个亚基，核心酶 $\alpha\varepsilon\theta$，$\beta$ 滑动夹，$\gamma$-复合物加载）；$\mathrm{DNA}\ \mathrm{pol}$ Ⅰ 去引物、填空隙、校对；连接酶封 $3'$-$\mathrm{OH}$ 与 $5'$-$\mathrm{P}$ 的缺口（耗 $\mathrm{ATP}$）；$\mathrm{DNA}\ \mathrm{pol}$ Ⅱ 参与应急修复。
- 高速：酶催化速率约 $50$ 个 $\mathrm{dNTP}/\mathrm{s}$，慢于原核 $\mathrm{pol}$ Ⅲ，但每条染色体上千个复制子分组激活，总体不慢；器官、发育、生理状况可调速度。保真：碱基配对氢键；聚合酶对碱基的选择和校读；复制叉复杂结构；复制后修复。真核复制酶高保真运作（表14-1）；$\mathrm{PCNA}$ 夹子维持 $\mathrm{pol}\ \delta$ 持续合成，减少脱离后的随意引发。
- 端粒：线性末端的蛋白质－$\mathrm{DNA}$ 帽子，维持染色体稳定性和复制完整性，防融合、防末端降解、防遗传信息丢失；序列为 $\mathrm{TxGy}$ 多次重复。肿瘤：增殖活跃细胞端粒酶活性增高，支持末端维持从而支持增殖；但活性不一定与长度成正比，某些肿瘤端粒反而显著缩短。已成为发病机制和治疗靶点领域。
- 都生成 $3'$，$5'$-磷酸二酯键，底物和场景不同。$\mathrm{DNA}$ 聚合酶：引物或子链 $3'$-$\mathrm{OH}$ 与 $\mathrm{dNTP}$ 聚合，释放焦磷酸，用于链延长（及填空隙）。拓扑酶：先切断再连接，改变超螺旋，不断开成永久缺口。连接酶：只封双链中已有的单链缺口（$3'$-$\mathrm{OH}$ 对 $5'$-$\mathrm{P}$），耗 $\mathrm{ATP}$，不能把两条游离单链连起来。
- 基本过程：三步（杂化双链 $\rightarrow$ 去 $\mathrm{RNA}\rightarrow$ 第二链），三种活性，$\mathrm{Zn}^{2+}$，$5'\rightarrow 3'$，前病毒可独立繁殖或整合。价值：拓展中心法则（$\mathrm{RNA}$ 也能传代）；拓宽病毒致癌理论并发现癌基因；$\mathrm{HIV}$ 有逆转录活性；$\mathrm{cDNA}$ 法取目的基因、建文库。
:::
