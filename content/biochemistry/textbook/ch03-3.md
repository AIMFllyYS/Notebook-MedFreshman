# 第三节　RNA的空间结构与功能

本章打开 $\mathrm{RNA}$ 的空间结构与功能。先把 $\mathrm{RNA}$ 分成编码 $\mathrm{RNA}$（只有 $\mathrm{mRNA}$）和非编码 $\mathrm{RNA}$（组成性与调控性），再写化学本质与空间结构都不同于 $\mathrm{DNA}$。$\mathrm{mRNA}$ 写全 $5'$-帽、$\mathrm{poly}(\mathrm{A})$ 尾、内含子外显子成熟（鸡卵清蛋白按教材）以及原核与真核差别；$\mathrm{tRNA}$ 写稀有碱基、三叶草二级、倒 $\mathrm{L}$ 三级和反密码子；$\mathrm{rRNA}$ 与核糖体；其他 $\mathrm{RNA}$ 与核酶。第四节才写紫外、变性、$T_\mathrm{m}$、增色和杂交。

一般而言，$\mathrm{RNA}$ 是 $\mathrm{DNA}$ 的转录产物。和 $\mathrm{DNA}$ 一样，$\mathrm{RNA}$ 在生命活动中发挥着重要的作用。$\mathrm{RNA}$ 可以分为编码 $\mathrm{RNA}$（coding $\mathrm{RNA}$）和非编码 $\mathrm{RNA}$（non-coding $\mathrm{RNA}$）。编码 $\mathrm{RNA}$ 是那些从基因组上转录而来、其核苷酸序列可以翻译成蛋白质的 $\mathrm{RNA}$，编码 $\mathrm{RNA}$ 仅有信使 $\mathrm{RNA}$（messenger $\mathrm{RNA}$，$\mathrm{mRNA}$）一种。非编码 $\mathrm{RNA}$ 不编码蛋白质。非编码 $\mathrm{RNA}$ 可以分为两类。一类是确保实现基本生物学功能的 $\mathrm{RNA}$，包括转运 $\mathrm{RNA}$（transfer $\mathrm{RNA}$，$\mathrm{tRNA}$）、核糖体 $\mathrm{RNA}$（ribosomal $\mathrm{RNA}$，$\mathrm{rRNA}$）、端粒 $\mathrm{RNA}$、信号识别颗粒（signal recognition particle，$\mathrm{SRP}$）$\mathrm{RNA}$ 等，它们的丰度基本恒定，故称为组成性非编码 $\mathrm{RNA}$（constitutive non-coding $\mathrm{RNA}$）。另一类是调控性非编码 $\mathrm{RNA}$（regulatory non-coding $\mathrm{RNA}$），它们的丰度随外界环境（应激条件等）和细胞性状（成熟度、代谢活跃度、健康状态等）而发生改变，在基因表达过程中发挥重要的调控作用。

:::definition{label="编码 RNA"}
编码 $\mathrm{RNA}$（coding $\mathrm{RNA}$）是从基因组上转录而来、其核苷酸序列可以翻译成蛋白质的 $\mathrm{RNA}$。编码 $\mathrm{RNA}$ 仅有信使 $\mathrm{RNA}$（messenger $\mathrm{RNA}$，$\mathrm{mRNA}$）一种。
:::

:::definition{label="非编码 RNA"}
非编码 $\mathrm{RNA}$（non-coding $\mathrm{RNA}$）不编码蛋白质。分成组成性非编码 $\mathrm{RNA}$ 和调控性非编码 $\mathrm{RNA}$ 两类。
:::

:::definition{label="组成性非编码 RNA"}
组成性非编码 $\mathrm{RNA}$（constitutive non-coding $\mathrm{RNA}$）确保实现基本生物学功能，丰度基本恒定。教材列出：转运 $\mathrm{RNA}$（$\mathrm{tRNA}$）、核糖体 $\mathrm{RNA}$（$\mathrm{rRNA}$）、端粒 $\mathrm{RNA}$、信号识别颗粒（$\mathrm{SRP}$）$\mathrm{RNA}$ 等。
:::

:::definition{label="调控性非编码 RNA"}
调控性非编码 $\mathrm{RNA}$（regulatory non-coding $\mathrm{RNA}$）的丰度随外界环境（应激条件等）和细胞性状（成熟度、代谢活跃度、健康状态等）而发生改变，在基因表达过程中发挥重要的调控作用。
:::

:::compare{title="编码 RNA 只有 mRNA，非编码再分组成性与调控性"}
| 项目 | 编码 $\mathrm{RNA}$ | 组成性非编码 $\mathrm{RNA}$ | 调控性非编码 $\mathrm{RNA}$ |
|------|-------------------|---------------------------|---------------------------|
| 能否翻译成蛋白质 | 能 | 不能 | 不能 |
| 教材成员 | 仅 $\mathrm{mRNA}$ 一种 | $\mathrm{tRNA}$、$\mathrm{rRNA}$、端粒 $\mathrm{RNA}$、$\mathrm{SRP}$ $\mathrm{RNA}$ 等 | 后文 $\mathrm{miRNA}$、$\mathrm{siRNA}$、$\mathrm{piRNA}$、$\mathrm{lncRNA}$、$\mathrm{circRNA}$ 等 |
| 丰度 | 最低（$2\%\sim 5\%$） | 基本恒定 | 随环境和细胞性状改变 |
| 先记的功能 | 蛋白质合成的模板 | 氨基酸载体、核糖体、端粒、蛋白质转运等基本功能 | 基因表达调控 |
:::

:::concept{term="先问编码还是非编码，再问是帽尾、三叶草还是核糖体"}
看见“$\mathrm{RNA}$”，先不要跳到双螺旋。编码账只有 $\mathrm{mRNA}$；非编码先问丰度恒不恒定：恒定的是组成性（$\mathrm{tRNA}$、$\mathrm{rRNA}$、端粒 $\mathrm{RNA}$、$\mathrm{SRP}$ $\mathrm{RNA}$），随环境变的是调控性。然后再问真核 $\mathrm{mRNA}$ 的帽和尾、$\mathrm{tRNA}$ 的三叶草、核糖体的亚基。把所有 $\mathrm{RNA}$ 听成“都能翻译”，帽尾和反密码子会没有户头。
:::

:::pitfall{label="编码 RNA 只有 mRNA 一种，tRNA 和 rRNA 不是编码 RNA"}
教材写明：编码 $\mathrm{RNA}$ 仅有 $\mathrm{mRNA}$ 一种。$\mathrm{tRNA}$、$\mathrm{rRNA}$ 参与蛋白质合成，但不编码蛋白质，户头在非编码。把它们听成“也是编码 $\mathrm{RNA}$”，后面的可读框和反密码子会对调。
:::

## 一、RNA 的化学本质与空间结构均不同于 DNA

### （一）RNA 由核糖核苷酸组成

构成 $\mathrm{RNA}$ 的核苷酸含核糖而不含脱氧核糖，含尿嘧啶（$\mathrm{U}$）而几乎不含胸腺嘧啶（$\mathrm{T}$）。因此，构成 $\mathrm{RNA}$ 的四种常规核苷酸是一磷酸腺苷（$\mathrm{AMP}$）、一磷酸鸟苷（$\mathrm{GMP}$）、一磷酸胞苷（$\mathrm{CMP}$）和一磷酸尿苷（$\mathrm{UMP}$）。并且 $\mathrm{RNA}$ 含有较多的稀有碱基，具有特殊的生理功能。

:::definition{label="构成 RNA 的四种常规核苷酸"}
构成 $\mathrm{RNA}$ 的核苷酸含核糖而不含脱氧核糖，含尿嘧啶（$\mathrm{U}$）而几乎不含胸腺嘧啶（$\mathrm{T}$）。四种常规核苷酸是 $\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$ 和 $\mathrm{UMP}$。
:::

:::keypoint{label="RNA 与 DNA 在组成上先记两处不同"}
- 戊糖：核糖，不是脱氧核糖。
- 嘧啶：$\mathrm{U}$ 而几乎不含 $\mathrm{T}$。
- 另外：$\mathrm{RNA}$ 含有较多稀有碱基，后文 $\mathrm{tRNA}$ 展开。
:::

### （二）RNA 通常以单链形式存在

$\mathrm{RNA}$ 通常以单链形式存在，较长的 $\mathrm{RNA}$ 可以通过链内的碱基互补配对形成局部的双螺旋二级结构以及复杂的高级结构。$\mathrm{RNA}$ 的种类、丰度、大小和空间结构要比 $\mathrm{DNA}$ 复杂得多，这与它的功能多样性密切相关。

:::definition{label="RNA 的单链与局部双螺旋"}
$\mathrm{RNA}$ 通常以单链形式存在。较长的 $\mathrm{RNA}$ 可以通过链内碱基互补配对形成局部双螺旋二级结构以及复杂的高级结构。种类、丰度、大小和空间结构比 $\mathrm{DNA}$ 复杂得多，与功能多样性相关。
:::

:::pitfall{label="单链不等于没有双螺旋，局部双螺旋是链内配对"}
$\mathrm{RNA}$ 不是“从头到尾都是松散单链”。局部双螺旋来自同一条链内部的互补，不是 $\mathrm{DNA}$ 那种两条反向平行链。把三叶草听成“两条 $\mathrm{RNA}$ 拧在一起”，茎环和倒 $\mathrm{L}$ 都会讲反。
:::

### （三）RNA 具有复杂的空间结构

$\mathrm{RNA}$ 分子具有编码蛋白质信息的功能，是遗传信息传递的重要介质，还可以像蛋白质一样具有酶的催化功能。绝大多数 $\mathrm{RNA}$ 为线性单链结构，其构象没有像 $\mathrm{DNA}$ 那样典型的双螺旋结构；但是绝大多数 $\mathrm{RNA}$ 都会通过分子内的碱基配对形成链内二级结构，并在 $\mathrm{RNA}$ 结合蛋白的介导下折叠成复杂的三维结构。而高度结构化的不同种类的 $\mathrm{RNA}$ 在催化、转录和翻译过程中发挥重要的生物学功能；然而目前人类对于 $\mathrm{RNA}$ 分子的三维立体结构的认识还比较局限。

:::definition{label="RNA 的空间结构"}
绝大多数 $\mathrm{RNA}$ 为线性单链，构象没有 $\mathrm{DNA}$ 那样典型的双螺旋；但绝大多数都会通过分子内碱基配对形成链内二级结构，并在 $\mathrm{RNA}$ 结合蛋白介导下折叠成复杂三维结构。高度结构化的不同种类 $\mathrm{RNA}$ 在催化、转录和翻译中发挥作用；人类对 $\mathrm{RNA}$ 三维结构的认识还比较局限。
:::

:::insight{label="RNA 同时有信息账和催化账"}
教材这一段把两本账摊开：可以编码蛋白质信息，也可以像蛋白质一样具有酶的催化功能。后面 $\mathrm{mRNA}$ 走信息账，核酶走催化账，不要并成“$\mathrm{RNA}$ 只是 $\mathrm{DNA}$ 的复印件”。
:::

:::compare{title="RNA 与 DNA：化学本质和空间结构都不同"}
| 项目 | $\mathrm{DNA}$ | $\mathrm{RNA}$ |
|------|---------------|---------------|
| 戊糖 | 脱氧核糖 | 核糖 |
| 嘧啶 | $\mathrm{T}$，一般无 $\mathrm{U}$ | $\mathrm{U}$，几乎不含 $\mathrm{T}$ |
| 常规核苷酸 | $\mathrm{dAMP}$、$\mathrm{dGMP}$、$\mathrm{dCMP}$、$\mathrm{dTMP}$ | $\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$、$\mathrm{UMP}$ |
| 链 | 双链为主 | 通常单链 |
| 二级结构 | 典型双螺旋 | 链内局部双螺旋、茎环；无 $\mathrm{DNA}$ 那种典型双螺旋构象 |
| 稀有碱基 | 较少 | 较多，有特殊生理功能 |
| 功能口径 | 遗传信息载体、复制和转录模板 | 信息传递介质；还可催化（核酶） |
:::

## 二、mRNA 是蛋白质生物合成的模板

$20$ 世纪 $40$ 年代，科学家发现细胞质内蛋白质的合成速度与 $\mathrm{RNA}$ 水平相关。$1960$ 年，Jacob F. 和 Monod J. 等人用放射性核素示踪实验证实，一类大小不一的 $\mathrm{RNA}$ 才是细胞内合成蛋白质的真正模板。后来这类 $\mathrm{RNA}$ 被证明是在核内以 $\mathrm{DNA}$ 为模板的合成产物，然后转移至细胞质内，被命名为信使 $\mathrm{RNA}$（$\mathrm{mRNA}$）。

在生物体内，$\mathrm{mRNA}$ 的丰度最低，仅占细胞 $\mathrm{RNA}$ 总重量的 $2\%\sim 5\%$。但是 $\mathrm{mRNA}$ 的种类最多，约有 $10^{5}$ 个之多，而且它们的大小也各不相同。$\mathrm{mRNA}$ 的平均寿命也相差甚大，从几分钟到几小时不等。在真核细胞中，细胞核内新生成的 $\mathrm{mRNA}$ 初级产物被称为核不均一 $\mathrm{RNA}$（heterogeneous nuclear $\mathrm{RNA}$，$\mathrm{hnRNA}$）。$\mathrm{hnRNA}$ 在细胞核内合成后，经过一系列的转录后修饰，剪接成为成熟 $\mathrm{mRNA}$，最后被转运到细胞质中。

:::timeline{period="mRNA 被指认为蛋白质合成模板"}
- **20世纪40年代** 发现细胞质内蛋白质合成速度与 RNA 水平相关
- **1960** Jacob F. 和 Monod J. 用放射性核素示踪证实：一类大小不一的 RNA 才是细胞内合成蛋白质的真正模板
- **随后** 证明这类 RNA 在核内以 DNA 为模板合成，再转移到细胞质，命名为信使 RNA（mRNA）
:::

:::definition{label="信使 RNA"}
信使 $\mathrm{RNA}$（messenger $\mathrm{RNA}$，$\mathrm{mRNA}$）是细胞内合成蛋白质的真正模板。它在核内以 $\mathrm{DNA}$ 为模板合成，然后转移至细胞质。
:::

:::definition{label="核不均一 RNA"}
在真核细胞中，细胞核内新生成的 $\mathrm{mRNA}$ 初级产物称为核不均一 $\mathrm{RNA}$（heterogeneous nuclear $\mathrm{RNA}$，$\mathrm{hnRNA}$）。$\mathrm{hnRNA}$ 在核内合成后，经过一系列转录后修饰，剪接成为成熟 $\mathrm{mRNA}$，再转运到细胞质。
:::

:::keypoint{label="mRNA 丰度最低、种类最多、寿命最短"}
- 丰度：仅占细胞 $\mathrm{RNA}$ 总重量的 $2\%\sim 5\%$，三类主要 $\mathrm{RNA}$ 里最低。
- 种类：最多，约 $10^{5}$ 个，大小各不相同。
- 寿命：从几分钟到几小时不等。
- 真核初级产物是 $\mathrm{hnRNA}$，要加帽、加尾、剪接才成熟。
:::

:::pitfall{label="hnRNA 不是成熟 mRNA，核里新合成的还要加工"}
$\mathrm{hnRNA}$ 是初级转录产物，含外显子和内含子，长度远远大于成熟 $\mathrm{mRNA}$。把核里抽到的 $\mathrm{hnRNA}$ 听成“已经能翻译”，帽、尾和剪接三步都会被跳过。
:::

### （一）真核生物 mRNA 的 5′-端有帽结构

大部分真核细胞 $\mathrm{mRNA}$ 的 $5'$-端都有一个反式 $7$-甲基鸟嘌呤-三磷酸核苷（$\mathrm{m}^{7}\mathrm{Gppp}$）的起始结构，被称为 $5'$-帽结构（$5'$-cap structure）（图3-17）。$5'$-帽结构是鸟苷酸转移酶将鸟嘌呤三磷酸核苷加到转录后的 $\mathrm{mRNA}$ 的 $5'$-端，形成了一个 $5'-5'$ 三磷酸键，使 $\mathrm{mRNA}$ 的 $5'$-端不再具有磷酸基团。$5'$-帽结构下游的第一个和第二个核苷酸中 $\mathrm{C}$-$2'$ 的羟基通常也会被甲基化成为甲氧基戊糖，由此产生数种不同的帽结构（图3-17）。原核生物 $\mathrm{mRNA}$ 没有这种特殊的 $5'$-帽结构。

真核生物 $\mathrm{mRNA}$ 的 $5'$-帽结构可以与一类称为帽结合蛋白质（cap binding protein，$\mathrm{CBP}$）的分子结合形成复合体。这种复合体有助于维持 $\mathrm{mRNA}$ 的稳定性，协同 $\mathrm{mRNA}$ 从细胞核向细胞质的转运，以及在蛋白质生物合成中促进核糖体和翻译起始因子的结合。

:::definition{label="5′-帽结构"}
大部分真核细胞 $\mathrm{mRNA}$ 的 $5'$-端有一个反式 $7$-甲基鸟嘌呤-三磷酸核苷（$\mathrm{m}^{7}\mathrm{Gppp}$）的起始结构，称为 $5'$-帽结构（$5'$-cap structure）。鸟苷酸转移酶把鸟嘌呤三磷酸核苷加到转录后 $\mathrm{mRNA}$ 的 $5'$-端，形成 $5'-5'$ 三磷酸键，使 $5'$-端不再具有磷酸基团。
:::

:::definition{label="帽结合蛋白质"}
帽结合蛋白质（cap binding protein，$\mathrm{CBP}$）与 $5'$-帽结构结合形成复合体，有助于：维持 $\mathrm{mRNA}$ 稳定性；协同 $\mathrm{mRNA}$ 从细胞核向细胞质转运；在蛋白质生物合成中促进核糖体和翻译起始因子的结合。
:::

:::keypoint{label="帽结构三件事：m7Gppp、5′-5′ 键、下游 2′ 羟基可甲基化"}
- 帽子本体：反式 $\mathrm{m}^{7}\mathrm{Gppp}$。
- 连接方式：$5'-5'$ 三磷酸键，不是普通的 $3',5'$-磷酸二酯键；$5'$-端因此不再有游离磷酸基团。
- 下游：第一个和第二个核苷酸的 $\mathrm{C}$-$2'$ 羟基通常甲基化成甲氧基戊糖，形成数种不同帽结构。
- 原核生物 $\mathrm{mRNA}$ 没有这种特殊 $5'$-帽。
:::

:::note{label="图3-17 电子版缺失"}
教材图3-17 为真核生物 $\mathrm{mRNA}$ 的 $5'$-帽结构以及加帽过程，用来看清 $\mathrm{m}^{7}\mathrm{Gppp}$、$5'-5'$ 三磷酸键和下游核苷酸 $\mathrm{C}$-$2'$ 甲基化。数字切片 `p0094_01.png`、`p0095_01.png` 为 $0$ 字节，本节不引用这些文件。加帽过程与“原核没有这种帽”的正文仍按教材保留。
:::

:::pitfall{label="5′-5′ 三磷酸键不是 3′，5′-磷酸二酯键，原核 mRNA 没有这种帽"}
帽子是反着接上去的 $\mathrm{m}^{7}\mathrm{G}$，键是 $5'-5'$。把帽听成“普通 $5'$ 端多了一个 $\mathrm{G}$”，或把原核 $\mathrm{mRNA}$ 也写成有 $\mathrm{m}^{7}\mathrm{Gppp}$ 帽，稳定性、出核和翻译起始都会对错物种。
:::

### （二）真核生物 mRNA 的 3′-端有多聚腺苷酸尾的结构

真核生物 $\mathrm{mRNA}$ 的 $3'$ 端是一段由 $80\sim 250$ 个腺苷酸连接而成的多聚腺苷酸结构，称为多聚腺苷酸尾或多聚（$\mathrm{A}$）尾［$\mathrm{poly}(\mathrm{A})$-tail］结构。$\mathrm{poly}(\mathrm{A})$ 尾结构是在 $\mathrm{mRNA}$ 转录完成以后加入的，催化这一反应的酶是多聚腺苷酸聚合酶（图3-18）。在细胞内，$\mathrm{poly}(\mathrm{A})$ 尾结构与 $\mathrm{poly}(\mathrm{A})$ 结合蛋白［$\mathrm{poly}(\mathrm{A})$-binding protein，$\mathrm{PABP}$］结合，大约每 $20$ 个腺苷酸结合一个 $\mathrm{PABP}$ 分子。目前认为，这种 $3'$-多聚（$\mathrm{A}$）尾结构和 $5'$-帽结构共同负责 $\mathrm{mRNA}$ 从细胞核向细胞质的转运、维持 $\mathrm{mRNA}$ 的稳定性以及翻译起始的调控。去除 $3'$-多聚（$\mathrm{A}$）尾和 $5'$-帽结构可导致细胞内的 $\mathrm{mRNA}$ 迅速被降解。有些原核生物 $\mathrm{mRNA}$ 的 $3'$-端也有这种多聚（$\mathrm{A}$）尾结构，虽然它的长度较短，但是同样具有重要的生物学功能。

:::definition{label="多聚（A）尾"}
真核生物 $\mathrm{mRNA}$ 的 $3'$ 端是一段由 $80\sim 250$ 个腺苷酸连接而成的多聚腺苷酸结构，称为多聚腺苷酸尾或多聚（$\mathrm{A}$）尾［$\mathrm{poly}(\mathrm{A})$-tail］。它是转录完成以后由多聚腺苷酸聚合酶加入的，不是基因组里编码出来的一长串 $\mathrm{A}$。
:::

:::definition{label="poly(A) 结合蛋白"}
$\mathrm{poly}(\mathrm{A})$ 结合蛋白［$\mathrm{poly}(\mathrm{A})$-binding protein，$\mathrm{PABP}$］与 $\mathrm{poly}(\mathrm{A})$ 尾结合，大约每 $20$ 个腺苷酸结合一个 $\mathrm{PABP}$ 分子。
:::

:::cause-effect{title="去掉帽和尾，mRNA 迅速被降解"}
- **因** 去除 $3'$-多聚（$\mathrm{A}$）尾和 $5'$-帽结构
- **果** 细胞内的 $\mathrm{mRNA}$ 迅速被降解
:::

:::keypoint{label="帽和尾共同做三件事"}
- 从细胞核向细胞质转运。
- 维持 $\mathrm{mRNA}$ 稳定性。
- 翻译起始的调控。
- 原核：没有这种特殊 $5'$-帽；有些原核 $\mathrm{mRNA}$ 的 $3'$-端也有较短的多聚（$\mathrm{A}$）尾，同样具有重要生物学功能。
:::

### （三）真核生物 mRNA 的成熟需要系列加工修饰

比较 $\mathrm{hnRNA}$ 和成熟 $\mathrm{mRNA}$ 发现，前者的长度远远大于后者。细胞核内的初级转录产物 $\mathrm{hnRNA}$ 含有许多交替相隔的外显子（exon）和内含子（intron）。外显子是构成 $\mathrm{mRNA}$ 的序列片段，而内含子是非编码序列。在 $\mathrm{hnRNA}$ 向细胞质转移的过程中，内含子被剪切掉，外显子连接在一起。再经过加帽和加尾修饰后，$\mathrm{hnRNA}$ 成为成熟 $\mathrm{mRNA}$（图3-19）。

:::definition{label="外显子"}
外显子（exon）是构成 $\mathrm{mRNA}$ 的序列片段。
:::

:::definition{label="内含子"}
内含子（intron）是非编码序列。初级转录产物 $\mathrm{hnRNA}$ 中外显子与内含子交替相隔；向细胞质转移过程中内含子被剪切掉，外显子连接在一起。
:::

:::example{label="鸡卵清蛋白 mRNA 的成熟（按教材图3-19）"}
该基因有 $8$ 个外显子（$\mathrm{L}$ 和 $1\sim 7$）和 $7$ 个内含子（$\mathrm{A}\sim\mathrm{G}$）。经过加帽、加尾和修饰剪接后，原来 $7\,564$ 个碱基对长的基因变成了 $1\,872$ 个核苷酸长的 $\mathrm{mRNA}$。

### （四）mRNA 的核苷酸序列决定蛋白质的氨基酸序列

一条成熟的真核 $\mathrm{mRNA}$ 包括 $5'$-非翻译区、编码区和 $3'$-非翻译区。从成熟 $\mathrm{mRNA}$ 的 $5'$-帽结构到核苷酸序列中第一个 $\mathrm{AUG}$（即起始密码子）之间的核苷酸序列被定义为 $5'$-非翻译区（$5'$-untranslated region，$5'$-$\mathrm{UTR}$）。从这个 $\mathrm{AUG}$ 开始，每三个连续的核苷酸组成一个遗传密码子（genetic codon），每个密码子编码一个氨基酸，直到由三个核苷酸（$\mathrm{UAA}$，或 $\mathrm{UAG}$，或 $\mathrm{UGA}$）组成的终止密码子。由起始密码子和终止密码子所限定的区域定义为 $\mathrm{mRNA}$ 的编码区，也称可读框（open reading frame，$\mathrm{ORF}$）。该区域是编码蛋白质多肽链的核苷酸序列。从 $\mathrm{mRNA}$ 可读框的下游直到多聚 $\mathrm{A}$ 尾的区域称为 $3'$-非翻译区（$3'$-untranslated region，$3'$-$\mathrm{UTR}$）（图3-20）。这些非翻译区通过与调控因子或非编码 $\mathrm{RNA}$ 的相互作用调控蛋白质生物合成。

:::definition{label="5′-非翻译区"}
从成熟 $\mathrm{mRNA}$ 的 $5'$-帽结构到第一个 $\mathrm{AUG}$（起始密码子）之间的核苷酸序列，定义为 $5'$-非翻译区（$5'$-untranslated region，$5'$-$\mathrm{UTR}$）。
:::

:::definition{label="遗传密码子"}
从起始密码子 $\mathrm{AUG}$ 开始，每三个连续的核苷酸组成一个遗传密码子（genetic codon），每个密码子编码一个氨基酸，直到终止密码子 $\mathrm{UAA}$、$\mathrm{UAG}$ 或 $\mathrm{UGA}$。
:::

:::definition{label="可读框"}
由起始密码子和终止密码子所限定的区域定义为 $\mathrm{mRNA}$ 的编码区，也称可读框（open reading frame，$\mathrm{ORF}$）。该区域是编码蛋白质多肽链的核苷酸序列。
:::

:::definition{label="3′-非翻译区"}
从 $\mathrm{mRNA}$ 可读框的下游直到多聚 $\mathrm{A}$ 尾的区域称为 $3'$-非翻译区（$3'$-untranslated region，$3'$-$\mathrm{UTR}$）。$5'$-$\mathrm{UTR}$ 和 $3'$-$\mathrm{UTR}$ 通过与调控因子或非编码 $\mathrm{RNA}$ 的相互作用调控蛋白质生物合成。
:::

:::keypoint{label="成熟真核 mRNA 从 5′ 到 3′ 四段"}
- $5'$-帽（$\mathrm{m}^{7}\mathrm{Gppp}$）。
- $5'$-$\mathrm{UTR}$：帽到第一个 $\mathrm{AUG}$。
- 编码区／$\mathrm{ORF}$：$\mathrm{AUG}$ 起，三联体密码子，到 $\mathrm{UAA}/\mathrm{UAG}/\mathrm{UGA}$。
- $3'$-$\mathrm{UTR}$ + $\mathrm{poly}(\mathrm{A})$ 尾。
:::

:::note{label="图3-20 电子版缺失"}
教材图3-20 为成熟真核生物 $\mathrm{mRNA}$ 的结构示意图：可读框前三个核苷酸是起始密码子 $\mathrm{AUG}$，最后三个是终止密码子。数字切片页面 $96$ 相关文件为 $0$ 字节，本节不引用空文件。$5'$-$\mathrm{UTR}$、$\mathrm{ORF}$、$3'$-$\mathrm{UTR}$ 的正文仍按教材保留。
:::

:::pitfall{label="UTR 不是废物序列，起始密码子是第一个 AUG 不是随便一个 AUG"}
$5'$-$\mathrm{UTR}$ 从帽到第一个 $\mathrm{AUG}$；$3'$-$\mathrm{UTR}$ 从 $\mathrm{ORF}$ 下游到多聚 $\mathrm{A}$ 尾。它们与调控因子或非编码 $\mathrm{RNA}$ 相互作用。把 $\mathrm{UTR}$ 听成“不翻译所以可以忽略”，后文 $\mathrm{miRNA}$ 结合 $3'$-$\mathrm{UTR}$ 会没有落点。
:::

## 三、tRNA 是蛋白质合成中氨基酸的载体

转运 $\mathrm{RNA}$（transfer $\mathrm{RNA}$，$\mathrm{tRNA}$）作为蛋白质合成的底物——氨基酸的载体参与蛋白质合成，为合成中的多肽链提供活化的氨基酸，也是细胞内分子量最小的一类核酸。$\mathrm{tRNA}$ 占细胞 $\mathrm{RNA}$ 总质量的 $15\%$ 左右，已知一级结构的 $100$ 多种 $\mathrm{tRNA}$ 都是由 $74\sim 95$ 个核苷酸组成的。$\mathrm{tRNA}$ 具有稳定的空间结构，其结构具有如下特点。

:::definition{label="转运 RNA"}
转运 $\mathrm{RNA}$（transfer $\mathrm{RNA}$，$\mathrm{tRNA}$）是蛋白质合成中氨基酸的载体，为合成中的多肽链提供活化的氨基酸。它是细胞内分子量最小的一类核酸，约占细胞 $\mathrm{RNA}$ 总质量的 $15\%$。已知一级结构的 $100$ 多种 $\mathrm{tRNA}$ 都由 $74\sim 95$ 个核苷酸组成。
:::

### （一）tRNA 含有稀有碱基

稀有碱基（rare base）是指除 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$ 和 $\mathrm{U}$ 外的一些碱基，包括双氢尿嘧啶（dihydrouracil，$\mathrm{DHU}$）、假尿嘧啶核苷（pseudouridine，$\psi$）和甲基化的嘌呤（$\mathrm{m}^{7}\mathrm{G}$、$\mathrm{m}^{7}\mathrm{A}$）等（图3-21）。正常的嘧啶核苷是杂环的 $\mathrm{N}$-$1$ 原子与戊糖的 $\mathrm{C}$-$1'$ 原子连接形成糖苷键，而假尿嘧啶核苷则是杂环的 $\mathrm{C}5$ 原子与戊糖的 $\mathrm{C}$-$1'$ 原子相连。$\mathrm{tRNA}$ 中的稀有碱基占所有碱基的 $10\%\sim 20\%$。$\mathrm{tRNA}$ 分子中的稀有碱基均是转录后修饰而成的。

:::definition{label="稀有碱基"}
稀有碱基（rare base）是指除 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$ 和 $\mathrm{U}$ 外的一些碱基，包括双氢尿嘧啶（dihydrouracil，$\mathrm{DHU}$）、假尿嘧啶核苷（pseudouridine，$\psi$）和甲基化的嘌呤（$\mathrm{m}^{7}\mathrm{G}$、$\mathrm{m}^{7}\mathrm{A}$）等。$\mathrm{tRNA}$ 中稀有碱基占所有碱基的 $10\%\sim 20\%$，均是转录后修饰而成。
:::

:::definition{label="假尿嘧啶核苷"}
正常嘧啶核苷是杂环的 $\mathrm{N}$-$1$ 与戊糖的 $\mathrm{C}$-$1'$ 形成糖苷键；假尿嘧啶核苷（$\psi$）则是杂环的 $\mathrm{C}5$ 与戊糖的 $\mathrm{C}$-$1'$ 相连。
:::

::figure{src="/images/biochemistry/textbook/p0097_01.png" caption="图3-21　tRNA 的稀有碱基。左：双氢尿嘧啶（DHU）；中：假尿嘧啶（ψ），戊糖 R 连在杂环 C5；右：甲基化鸟嘌呤（m7G），N7 连甲基。" alt="三种稀有碱基结构式：双氢尿嘧啶五、六位饱和；假尿嘧啶的糖基连在 C5 而非 N1；鸟嘌呤 N7 甲基化"}

:::pitfall{label="稀有碱基是转录后修饰出来的，不是基因组另有一套碱基字母"}
$\mathrm{DHU}$、$\psi$、$\mathrm{m}^{7}\mathrm{G}$、$\mathrm{m}^{7}\mathrm{A}$ 都是 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{U}$ 改出来的。把它们听成“第 $5$、$6$ 种编码碱基”，一级结构书写和密码子表会对错字母表。
:::

:::insight{label="假尿苷的糖苷键改在 C5，不是普通的 N1-C1′"}
图3-21 中间那个 $\psi$ 的 $\mathrm{R}$ 连在 $\mathrm{C}5$。看见“假尿嘧啶”，先问糖连在哪个原子，再问它出现在 $\mathrm{T}\psi\mathrm{C}$ 环。
:::

### （二）tRNA 具有特定的“茎-环”结构和倒“L”形空间结构

$\mathrm{tRNA}$ 存在着一些核苷酸序列，能够通过碱基互补配对的原则，形成局部的链内的双螺旋结构。在这些局部的双螺旋结构之间的核苷酸序列不能形成互补的碱基对则膨出形成环状或襻状结构。这样的结构称为茎环（stem-loop）结构或发夹（hairpin）结构。由于这些茎环结构的存在，$\mathrm{tRNA}$ 的二级结构呈现出酷似三叶草（cloverleaf）的形状（图3-22）。位于两侧的发夹结构含有稀有碱基，分别称为 $\mathrm{DHU}$ 环和 $\mathrm{T}\psi\mathrm{C}$ 环；位于上方的茎称为氨基酸臂（amino acid arm），亦称接纳茎；位于下方的发夹结构则称为反密码子环（anticodon loop）。此外，在反密码子环与 $\mathrm{T}\psi\mathrm{C}$ 环之间还有一个可变臂。不同 $\mathrm{tRNA}$ 的可变臂的长短不一，从几个到十几个核苷酸数不等。除可变臂和 $\mathrm{DHU}$ 环外，其他部位的核苷酸数目和碱基对具有高度保守性。$\mathrm{X}$ 射线晶体衍射图分析表明，所有的 $\mathrm{tRNA}$ 都具有相似的倒“$\mathrm{L}$”形的空间结构。稳定 $\mathrm{tRNA}$ 的三级结构的力是某些碱基之间产生的特殊氢键和碱基堆积力。

:::definition{label="茎环结构"}
局部链内双螺旋为茎；其间不能配对的核苷酸膨出成环或襻。这样的结构称为茎环（stem-loop）或发夹（hairpin）。
:::

:::definition{label="tRNA 的三叶草二级结构"}
由于茎环结构的存在，$\mathrm{tRNA}$ 的二级结构酷似三叶草（cloverleaf）。两侧发夹含稀有碱基，分别是 $\mathrm{DHU}$ 环和 $\mathrm{T}\psi\mathrm{C}$ 环；上方的茎是氨基酸臂（amino acid arm），亦称接纳茎；下方的发夹是反密码子环（anticodon loop）；反密码子环与 $\mathrm{T}\psi\mathrm{C}$ 环之间还有可变臂。
:::

:::definition{label="tRNA 的倒 L 三级结构"}
$\mathrm{X}$ 射线晶体衍射表明，所有 $\mathrm{tRNA}$ 都具有相似的倒“$\mathrm{L}$”形空间结构。稳定三级结构的力是某些碱基之间产生的特殊氢键和碱基堆积力。
:::

::figure{src="/images/biochemistry/textbook/p0097_02.png" caption="图3-22　tRNA 的二级结构和空间结构。（a）二级结构形似三叶草：氨基酸臂 3′ 端 CCA 为氨基酸连接位点，两侧为 DHU 环和 TψC 环，下方为反密码子环；（b）空间结构是倒 L 形，TψC 环与 DHU 环靠近，反密码子环在另一端，CCA 末端伸出。" alt="左图三叶草：顶为 3′ CCA 氨基酸臂，左 DHU 环，右 TψC 环，底为反密码子；右图倒 L：一端反密码子环，另一端 CCA 的 OH-3′"}

:::memory{label="三叶草四叶加可变臂"}
- 上：氨基酸臂／接纳茎，$3'$-端 $\mathrm{CCA}$，氨基酸连在末端 $\mathrm{A}$ 的 $\mathrm{C}3'$。
- 左：$\mathrm{DHU}$ 环（含双氢尿嘧啶）。
- 右：$\mathrm{T}\psi\mathrm{C}$ 环（含假尿苷）。

- 额外：反密码子环与 $\mathrm{T}\psi\mathrm{C}$ 环之间的可变臂，几个到十几个核苷酸不等。

- 三级：倒 $\mathrm{L}$；特殊氢键 + 碱基堆积力。
:::

图3-22（a）是二级，（b）才是倒 $\mathrm{L}$。$\mathrm{DHU}$ 环和 $\mathrm{T}\psi\mathrm{C}$ 环在三级里靠到一起，反密码子环在倒 $\mathrm{L}$ 的另一端。把平面三叶草听成“就是空间结构”，氨基酸臂和反密码子的相对位置会对错。

### （三）tRNA 存在反密码子，能够识别 mRNA 中的密码子

所有 $\mathrm{tRNA}$ 的 $3'$-端都是以 $\mathrm{CCA}$ 三个核苷酸结束的，氨酰 $\mathrm{tRNA}$ 合成酶将氨基酸通过酯键连接在腺嘌呤 $\mathrm{A}$ 的 $\mathrm{C}3'$ 原子上，生成了氨酰 $\mathrm{tRNA}$，从而使 $\mathrm{tRNA}$ 成为氨基酸的载体。只有连接在 $\mathrm{tRNA}$ 的氨基酸才能参与蛋白质的生物合成。$\mathrm{tRNA}$ 所携载的氨基酸种类是由 $\mathrm{tRNA}$ 的反密码子（anticodon）所决定的。有的氨基酸只有一种 $\mathrm{tRNA}$，而有的氨基酸有几种 $\mathrm{tRNA}$ 作为载体，以适应 $\mathrm{mRNA}$ 上密码子简并性的需求。

$\mathrm{tRNA}$ 的反密码子环由 $7\sim 9$ 个核苷酸组成，居中的 $3$ 个核苷酸通过碱基互补配对的关系识别 $\mathrm{mRNA}$ 上的密码子，因此被称为反密码子。密码子与反密码子的结合使 $\mathrm{tRNA}$ 能够转运正确的氨基酸参与蛋白质多肽链的合成。例如，携带酪氨酸的 $\mathrm{tRNA}$ 反密码子是 $\mathrm{GUA}$，可以与 $\mathrm{mRNA}$ 上编码酪氨酸的密码子 $\mathrm{UAC}$ 互补配对。在蛋白质合成中，氨酰 $\mathrm{tRNA}$ 的反密码子依靠碱基互补的方式辨认 $\mathrm{mRNA}$ 的密码子，将其所携带的氨基酸正确地转递到合成中的多肽链上（图3-23）。

:::definition{label="氨酰 tRNA"}
所有 $\mathrm{tRNA}$ 的 $3'$-端都以 $\mathrm{CCA}$ 三个核苷酸结束。氨酰 $\mathrm{tRNA}$ 合成酶将氨基酸通过酯键连接在腺嘌呤 $\mathrm{A}$ 的 $\mathrm{C}3'$ 原子上，生成氨酰 $\mathrm{tRNA}$。只有连接在 $\mathrm{tRNA}$ 上的氨基酸才能参与蛋白质生物合成。
:::

:::definition{label="反密码子"}
反密码子环由 $7\sim 9$ 个核苷酸组成，居中的 $3$ 个核苷酸通过碱基互补配对识别 $\mathrm{mRNA}$ 上的密码子，称为反密码子（anticodon）。$\mathrm{tRNA}$ 所携载的氨基酸种类由反密码子决定。
:::

:::example{label="酪氨酸：反密码子 GUA 对密码子 UAC"}
携带酪氨酸的 $\mathrm{tRNA}$ 反密码子是 $\mathrm{GUA}$，与 $\mathrm{mRNA}$ 上编码酪氨酸的密码子 $\mathrm{UAC}$ 互补配对。氨酰 $\mathrm{tRNA}$ 靠这种碱基互补把正确的氨基酸转递到合成中的多肽链上。
:::

:::keypoint{label="简并性在本节先写成：一种氨基酸可以有几种 tRNA"}
有的氨基酸只有一种 $\mathrm{tRNA}$，有的氨基酸有几种 $\mathrm{tRNA}$ 作为载体，以适应 $\mathrm{mRNA}$ 上密码子简并性的需求。本节的识别方式按教材写成碱基互补（酪氨酸 $\mathrm{GUA}$–$\mathrm{UAC}$）。
:::

:::note{label="反密码子的摆动配对不在本节展开"}
密码子通过与反密码子配对发挥作用，有时第三位并不严格遵循 Watson-Crick 配对，称为摆动（wobble）。摆动使一种 $\mathrm{tRNA}$ 识别多种简并密码子。教材把摆动性写在蛋白质生物合成（密码子性质）那一章，本节只把反密码子写成环上居中 $3$ 个核苷酸、与密码子碱基互补，简并性先靠“一种氨基酸可有几种 $\mathrm{tRNA}$”。不要在三叶草图上把第三位不严格配对写成已经讲完。
:::

:::note{label="图3-23 电子版缺失"}
教材图3-23 为 $\mathrm{tRNA}$ 反密码子与 $\mathrm{mRNA}$ 密码子相互识别的示意图：通过正确的碱基配对，$\mathrm{mRNA}$ 密码子与其所编码的氨基酸建立一一对应关系。数字切片 `p0098_01.png` 为 $0$ 字节，本节不引用该文件。酪氨酸 $\mathrm{GUA}$–$\mathrm{UAC}$ 的正文仍按教材保留。
:::

:::pitfall{label="氨基酸连在 3′ 端 CCA 的 A 上，不是连在反密码子上"}
反密码子决定携带哪一种氨基酸，酯键却落在接纳茎 $3'$-端腺嘌呤的 $\mathrm{C}3'$。把氨基酸听成“挂在反密码子环上”，倒 $\mathrm{L}$ 两端的分工会并成一本账。
:::

:::concept{term="先问反密码子对上哪个密码子，再问这种氨基酸有几种 tRNA"}
看见“$\mathrm{tRNA}$ 识别”，先做互补：反密码子居中三联体对 $\mathrm{mRNA}$ 密码子（教材例：$\mathrm{GUA}$ 对 $\mathrm{UAC}$）。再问简并性：一种氨基酸可以有几种 $\mathrm{tRNA}$。第三位摆动是后一章的机制，不要用它替换本节的标准互补例子。
:::

## 四、以 rRNA 为主要成分的核糖体是蛋白质合成的场所

核糖体 $\mathrm{RNA}$（ribosomal $\mathrm{RNA}$，$\mathrm{rRNA}$）是细胞中含量最多的 $\mathrm{RNA}$，约占 $\mathrm{RNA}$ 总重量的 $80\%$ 以上。$\mathrm{rRNA}$ 有确定的种类和保守的核苷酸序列。$\mathrm{rRNA}$ 与核糖体蛋白质（ribosomal protein）共同构成核糖体（ribosome），它将蛋白质生物合成所需要的 $\mathrm{mRNA}$、$\mathrm{tRNA}$ 以及多种蛋白质因子募集在一起，为蛋白质生物合成提供了必需的场所。

:::definition{label="核糖体 RNA"}
核糖体 $\mathrm{RNA}$（ribosomal $\mathrm{RNA}$，$\mathrm{rRNA}$）是细胞中含量最多的 $\mathrm{RNA}$，约占 $\mathrm{RNA}$ 总重量的 $80\%$ 以上。有确定的种类和保守的核苷酸序列。
:::

:::definition{label="核糖体"}
核糖体（ribosome）由 $\mathrm{rRNA}$ 与核糖体蛋白质共同构成。它把蛋白质生物合成所需的 $\mathrm{mRNA}$、$\mathrm{tRNA}$ 以及多种蛋白质因子募集在一起，提供必需的场所。
:::

### （一）核糖体由 rRNA 和核糖体蛋白组成

原核细胞有三种 $\mathrm{rRNA}$，依照分子量的大小分为 $5\mathrm{S}$、$16\mathrm{S}$ 和 $23\mathrm{S}$（$\mathrm{S}$ 是大分子物质在超速离心沉降中的沉降系数）。它们与不同的核糖体蛋白结合分别形成了核糖体的大亚基（large subunit）和小亚基（small subunit）（表3-5）。真核细胞的四种 $\mathrm{rRNA}$ 也利用相类似的方式构成了真核细胞核糖体的大亚基和小亚基。

:::definition{label="沉降系数 S"}
$\mathrm{S}$ 是大分子物质在超速离心沉降中的沉降系数。原核 $\mathrm{rRNA}$ 按分子量分为 $5\mathrm{S}$、$16\mathrm{S}$ 和 $23\mathrm{S}$。
:::

:::

### （二）rRNA 的二级结构具有许多茎环结构

人们已经完成了 $\mathrm{rRNA}$ 的核苷酸测序，并解析了它们的空间结构。$\mathrm{rRNA}$ 的二级结构有许多茎环结构，图3-24 是真核细胞 $18\mathrm{S}$ $\mathrm{rRNA}$ 的二级结构。这些茎环结构为核糖体蛋白结合和组装在 $\mathrm{rRNA}$ 上提供了结构基础。原核细胞 $16\mathrm{S}$ $\mathrm{rRNA}$ 的二级结构也有众多相类似的茎环结构。

将纯化的核糖体蛋白和 $\mathrm{rRNA}$ 在试管内混合，它们就可以自动组装成具有活性的大亚基和小亚基。大亚基和小亚基进一步组装成核糖体。大小亚基的结合区域的沟槽是 $\mathrm{mRNA}$ 的结合部位。核糖体有三个重要的部位，它们分别是 $\mathrm{A}$ 位：结合氨酰 $\mathrm{tRNA}$ 的氨酰位（aminoacyl site）；$\mathrm{P}$ 位：结合肽酰-$\mathrm{tRNA}$ 的肽酰位（peptidyl site）；和 $\mathrm{E}$ 位：释放已经卸载了氨基酸的 $\mathrm{tRNA}$ 的排出位（exit site）（图3-25）。$\mathrm{mRNA}$ 结合在核糖体的大小亚基之间的缝隙中。核糖体的大小亚基形成了三个主要部位用以接受氨酰 $\mathrm{tRNA}$、保留肽酰-$\mathrm{tRNA}$ 和释放已经卸载了氨基酸的 $\mathrm{tRNA}$。

:::definition{label="A 位、P 位、E 位"}
- $\mathrm{A}$ 位：氨酰位（aminoacyl site），结合氨酰 $\mathrm{tRNA}$。
- $\mathrm{P}$ 位：肽酰位（peptidyl site），结合肽酰-$\mathrm{tRNA}$。
- $\mathrm{E}$ 位：排出位（exit site），释放已经卸载了氨基酸的 $\mathrm{tRNA}$。
$\mathrm{mRNA}$ 结合在大小亚基之间的缝隙中；大小亚基结合区域的沟槽是 $\mathrm{mRNA}$ 的结合部位。
:::

教材图3-25 为由核糖体、$\mathrm{mRNA}$ 和 $\mathrm{tRNA}$ 形成的复合体，用来看清 $\mathrm{A}$ 位、$\mathrm{P}$ 位、$\mathrm{E}$ 位以及 $\mathrm{mRNA}$ 夹在大小亚基缝隙中。数字切片 `p0099_01.png`、`p0100_01.png` 为 $0$ 字节，本节不引用这些文件。$\mathrm{A}/\mathrm{P}/\mathrm{E}$ 三位的正文仍按教材保留。

:::insight{label="纯化的 rRNA 和核糖体蛋白在试管里能自动组装"}
活性大、小亚基可以在试管内由纯化组分自动装起来，再进一步装成核糖体。茎环是蛋白结合的结构基础，不是“$\mathrm{rRNA}$ 只是填充物”。
:::

## 五、非编码 RNA 在遗传信息传递、基因表达调控过程中发挥重要作用

除了 $\mathrm{tRNA}$ 和 $\mathrm{rRNA}$ 外，细胞内还存在一些其他的非编码 $\mathrm{RNA}$。非编码 $\mathrm{RNA}$ 包括组成性非编码 $\mathrm{RNA}$ 和调控性非编码 $\mathrm{RNA}$。

### （一）组成性非编码 RNA 参与 RNA 修饰及蛋白质转运

组成性非编码 $\mathrm{RNA}$ 的表达丰度相对恒定，作为关键因子参与 $\mathrm{RNA}$ 的剪接、修饰以及蛋白质的转运过程。除 $\mathrm{tRNA}$ 和 $\mathrm{rRNA}$ 外，组成性非编码 $\mathrm{RNA}$ 主要有以下几种。

**1. 催化小 RNA**　催化小 $\mathrm{RNA}$ 也称为核酶（ribozyme），是细胞内具有催化功能的一类小分子 $\mathrm{RNA}$ 统称，具有催化特定 $\mathrm{RNA}$ 降解的活性，在 $\mathrm{RNA}$ 合成后的剪接修饰中具有重要作用（详见本节“核酶”）。

**2. 核仁小 RNA（small nucleolar RNA，snoRNA）**　$\mathrm{snoRNA}$ 定位于核仁，主要参与 $\mathrm{rRNA}$ 的加工。$\mathrm{rRNA}$ 的核糖 $\mathrm{C}$-$2'$ 的甲基化过程和假尿嘧啶化修饰都需要 $\mathrm{snoRNA}$ 的参与。

**3. 核小 RNA（small nuclear RNA，snRNA）**　细胞核内的短片段 $\mathrm{RNA}$，长度 $100\sim 215$ 个核苷酸，研究较多的为 $7$ 类，由于含 $\mathrm{U}$ 丰富，故编号为 $\mathrm{U}1\sim\mathrm{U}7$。其中 $\mathrm{U}3$ 存在于核仁中，其他 $6$ 种存在于非核仁区的核液里。$\mathrm{U}3$ $\mathrm{snRNA}$ 与核仁内 $28\mathrm{S}$ $\mathrm{rRNA}$ 的成熟有关。$\mathrm{U}7$ 与组蛋白前体 $\mathrm{mRNA}$ 的茎环结构的加工有关。其他 $5$ 种小核 $\mathrm{RNA}$ 是真核生物转录后加工过程中 $\mathrm{RNA}$ 剪接体（spliceosome）的主要成分，参与前体 $\mathrm{mRNA}$ 的加工过程。

**4. 胞质小 RNA（small cytoplasmic RNA，scRNA）**　$\mathrm{scRNA}$ 存在细胞质中，与蛋白质结合形成复合体后发挥生物学功能。例如，$\mathrm{SRP}$-$\mathrm{RNA}$ 与六种蛋白质共同形成信号识别颗粒（signal recognition particle，$\mathrm{SRP}$），引导含有信号肽的蛋白质进入内质网进行合成。

:::definition{label="催化小 RNA"}
催化小 $\mathrm{RNA}$ 也称为核酶（ribozyme），是细胞内具有催化功能的一类小分子 $\mathrm{RNA}$ 统称，具有催化特定 $\mathrm{RNA}$ 降解的活性，在 $\mathrm{RNA}$ 合成后的剪接修饰中具有重要作用。
:::

:::definition{label="核仁小 RNA"}
核仁小 $\mathrm{RNA}$（small nucleolar $\mathrm{RNA}$，$\mathrm{snoRNA}$）定位于核仁，主要参与 $\mathrm{rRNA}$ 的加工。$\mathrm{rRNA}$ 的核糖 $\mathrm{C}$-$2'$ 甲基化和假尿嘧啶化修饰都需要 $\mathrm{snoRNA}$。
:::

:::definition{label="核小 RNA"}
核小 $\mathrm{RNA}$（small nuclear $\mathrm{RNA}$，$\mathrm{snRNA}$）是细胞核内短片段 $\mathrm{RNA}$，长度 $100\sim 215$ 个核苷酸。研究较多的为 $7$ 类，含 $\mathrm{U}$ 丰富，编号 $\mathrm{U}1\sim\mathrm{U}7$。$\mathrm{U}3$ 在核仁，与 $28\mathrm{S}$ $\mathrm{rRNA}$ 成熟有关；其余 $6$ 种在非核仁核液。$\mathrm{U}7$ 参与组蛋白前体 $\mathrm{mRNA}$ 茎环加工；其他 $5$ 种是剪接体（spliceosome）的主要成分，参与前体 $\mathrm{mRNA}$ 加工。
:::

:::definition{label="胞质小 RNA 与信号识别颗粒"}
胞质小 $\mathrm{RNA}$（small cytoplasmic $\mathrm{RNA}$，$\mathrm{scRNA}$）存在于细胞质，与蛋白质结合成复合体后发挥作用。$\mathrm{SRP}$-$\mathrm{RNA}$ 与六种蛋白质共同形成信号识别颗粒（$\mathrm{SRP}$），引导含信号肽的蛋白质进入内质网合成。
:::

:::compare{title="组成性非编码 RNA（除 tRNA、rRNA 外）"}
| 种类 | 位置 | 教材功能 |
|------|------|----------|
| 催化小 $\mathrm{RNA}$（核酶） | 细胞内 | 催化特定 $\mathrm{RNA}$ 降解；剪接修饰 |
| $\mathrm{snoRNA}$ | 核仁 | $\mathrm{rRNA}$ 加工；$\mathrm{C}$-$2'$ 甲基化、假尿嘧啶化 |
| $\mathrm{snRNA}$（$\mathrm{U}1\sim\mathrm{U}7$） | $\mathrm{U}3$ 在核仁，余在核液 | $\mathrm{U}3$：$28\mathrm{S}$ $\mathrm{rRNA}$ 成熟；$\mathrm{U}7$：组蛋白前体 $\mathrm{mRNA}$ 茎环；其余 $5$ 种：剪接体 |
| $\mathrm{scRNA}$（如 $\mathrm{SRP}$-$\mathrm{RNA}$） | 细胞质 | $\mathrm{SRP}$ 引导信号肽蛋白质进内质网 |
:::

:::pitfall{label="U3 在核仁，不要把全部 snRNA 都写成剪接体成分"}
$7$ 类里：$\mathrm{U}3$ 走 $\mathrm{rRNA}$ 成熟，$\mathrm{U}7$ 走组蛋白前体 $\mathrm{mRNA}$，其余 $5$ 种才是剪接体主要成分。把 $\mathrm{U}1\sim\mathrm{U}7$ 一锅写成“都是 spliceosome”，核仁那一本账会丢。
:::

### （二）调控性非编码 RNA 在基因表达过程中发挥调控作用

调控性非编码 $\mathrm{RNA}$ 的表达丰度会随外界环境（应激条件等）和细胞性状（成熟度、代谢活跃度等）的改变而改变，在基因表达过程中发挥重要调控作用。调控性非编码 $\mathrm{RNA}$ 主要有以下几种。

**1. 非编码小 RNA（small non-coding RNA，sncRNA）**　通常认为，$\mathrm{sncRNA}$ 的长度小于 $200\,\mathrm{nt}$。$\mathrm{sncRNA}$ 包括微 $\mathrm{RNA}$（microRNA，$\mathrm{miRNA}$）、干扰小 $\mathrm{RNA}$（small interfering $\mathrm{RNA}$，$\mathrm{siRNA}$）和 $\mathrm{piRNA}$（PIWI-interacting $\mathrm{RNA}$）。

$\mathrm{miRNA}$ 是研究较多的内源性 $\mathrm{sncRNA}$，主要是通过与细胞质中靶 $\mathrm{mRNA}$ 的 $3'$-$\mathrm{UTR}$ 部分互补结合（少量与 $5'$-$\mathrm{UTR}$ 或编码区结合），从而调节 $\mathrm{mRNA}$ 的寿命或抑制 $\mathrm{mRNA}$ 翻译等。

$\mathrm{siRNA}$ 有内源性和外源性之分，内源性 $\mathrm{siRNA}$ 是由细胞自身产生的。外源性 $\mathrm{siRNA}$ 来源于外源入侵的基因表达的双链 $\mathrm{RNA}$，经 Dicer 切割所产生的具有特定长度（$21\sim 23\,\mathrm{bp}$）和特定序列的小片段 $\mathrm{RNA}$。$\mathrm{siRNA}$ 可以诱导 $\mathrm{mRNA}$ 的降解，还有抑制转录的功能。利用这一机制发展起来的 $\mathrm{RNA}$ 干扰（$\mathrm{RNA}$ interference，$\mathrm{RNAi}$）技术是用来研究基因功能的有力工具。

$\mathrm{piRNA}$ 是从哺乳动物生殖细胞中分离得到的一类长度约为 $30\,\mathrm{nt}$ 的小 $\mathrm{RNA}$。这类小 $\mathrm{RNA}$ 与 $\mathrm{PIWI}$ 蛋白家族成员结合才能发挥其调控作用，故称为 $\mathrm{piRNA}$。$\mathrm{piRNA}$ 主要存在哺乳动物生殖细胞和干细胞中，通过与 $\mathrm{PIWI}$ 蛋白家族成员结合形成 $\mathrm{piwi}$ 复合物来调控基因沉默。

**2. 长非编码 RNA（long non-coding RNA，lncRNA）**　长非编码 $\mathrm{RNA}$ 是一类长度为 $200\sim 100\,000$ 个核苷酸的 $\mathrm{RNA}$ 分子。它们不编码任何蛋白质。$\mathrm{lncRNA}$ 由 $\mathrm{RNA}$ 聚合酶Ⅱ转录生成，经剪切加工后，形成具有类似于 $\mathrm{mRNA}$ 的结构。$\mathrm{lncRNA}$ 有 $\mathrm{poly}(\mathrm{A})$ 尾巴和启动子，但序列中不存在可读框。$\mathrm{lncRNA}$ 定位于细胞核内和细胞质内。$\mathrm{lncRNA}$ 具有强烈的组织特异性与时空特异性。

**3. 环状 RNA（circular RNA，circRNA）**　$\mathrm{circRNA}$ 分子呈封闭环状结构，没有 $5'$-端和 $3'$-端，因此不受 $\mathrm{RNA}$ 外切酶的影响，表达更稳定，不易降解。已知的 $\mathrm{circRNA}$ 分子或来自外显子，或兼有外显子和内含子的部分。$\mathrm{circRNA}$ 几乎完全定位于细胞核中。$\mathrm{circRNA}$ 具有序列的高度保守性，具有一定的组织、时序和疾病特异性。

:::definition{label="非编码小 RNA"}
非编码小 $\mathrm{RNA}$（small non-coding $\mathrm{RNA}$，$\mathrm{sncRNA}$）通常认为长度小于 $200\,\mathrm{nt}$，包括 $\mathrm{miRNA}$、$\mathrm{siRNA}$ 和 $\mathrm{piRNA}$。
:::

:::definition{label="微 RNA"}
微 $\mathrm{RNA}$（microRNA，$\mathrm{miRNA}$）是研究较多的内源性 $\mathrm{sncRNA}$，主要与细胞质中靶 $\mathrm{mRNA}$ 的 $3'$-$\mathrm{UTR}$ 部分互补结合（少量与 $5'$-$\mathrm{UTR}$ 或编码区结合），从而调节 $\mathrm{mRNA}$ 的寿命或抑制 $\mathrm{mRNA}$ 翻译。
:::

:::definition{label="干扰小 RNA 与 RNA 干扰"}
$\mathrm{siRNA}$ 分内源性和外源性。外源性 $\mathrm{siRNA}$ 来自外源入侵基因表达的双链 $\mathrm{RNA}$，经 Dicer 切割产生特定长度（$21\sim 23\,\mathrm{bp}$）和特定序列的小片段。$\mathrm{siRNA}$ 可诱导 $\mathrm{mRNA}$ 降解，还可抑制转录。利用这一机制发展起来的 $\mathrm{RNA}$ 干扰（$\mathrm{RNAi}$）是研究基因功能的有力工具。
:::

:::definition{label="piRNA"}
$\mathrm{piRNA}$（PIWI-interacting $\mathrm{RNA}$）从哺乳动物生殖细胞中分离，长度约 $30\,\mathrm{nt}$，与 $\mathrm{PIWI}$ 蛋白家族成员结合才能发挥调控作用。主要存在于哺乳动物生殖细胞和干细胞，形成 $\mathrm{piwi}$ 复合物调控基因沉默。
:::

:::definition{label="长非编码 RNA"}
长非编码 $\mathrm{RNA}$（long non-coding $\mathrm{RNA}$，$\mathrm{lncRNA}$）长度为 $200\sim 100\,000$ 个核苷酸，不编码任何蛋白质。由 $\mathrm{RNA}$ 聚合酶Ⅱ转录，经剪切加工后具有类似于 $\mathrm{mRNA}$ 的结构：有 $\mathrm{poly}(\mathrm{A})$ 尾巴和启动子，但序列中不存在可读框。定位于细胞核和细胞质，具有强烈的组织特异性与时空特异性。
:::

:::definition{label="环状 RNA"}
环状 $\mathrm{RNA}$（circular $\mathrm{RNA}$，$\mathrm{circRNA}$）呈封闭环状，没有 $5'$-端和 $3'$-端，不受 $\mathrm{RNA}$ 外切酶影响，表达更稳定、不易降解。或来自外显子，或兼有外显子和内含子部分；几乎完全定位于细胞核；序列高度保守，具有一定的组织、时序和疾病特异性。
:::

:::compare{title="调控性非编码 RNA 按长度和机制记"}
| 种类 | 长度／形态 | 教材机制 |
|------|------------|----------|
| $\mathrm{miRNA}$ | $<200\,\mathrm{nt}$ 的 $\mathrm{sncRNA}$ | 与靶 $\mathrm{mRNA}$ 的 $3'$-$\mathrm{UTR}$ 部分互补（少量 $5'$-$\mathrm{UTR}$／编码区），调节寿命或抑制翻译 |
| $\mathrm{siRNA}$ | $21\sim 23\,\mathrm{bp}$（外源经 Dicer） | 诱导 $\mathrm{mRNA}$ 降解、抑制转录；$\mathrm{RNAi}$ |
| $\mathrm{piRNA}$ | 约 $30\,\mathrm{nt}$ | 与 $\mathrm{PIWI}$ 结合成 $\mathrm{piwi}$ 复合物，基因沉默；生殖细胞和干细胞 |
| $\mathrm{lncRNA}$ | $200\sim 100\,000\,\mathrm{nt}$ | 像 $\mathrm{mRNA}$（有尾、有启动子）但无 $\mathrm{ORF}$；核＋质；组织／时空特异 |
| $\mathrm{circRNA}$ | 封闭环，无 $5'$/$3'$ 端 | 抗外切酶、更稳定；几乎全在核内 |
:::

:::pitfall{label="lncRNA 长得像 mRNA，但没有可读框，不要把它算进编码 RNA"}
$\mathrm{lncRNA}$ 有 $\mathrm{poly}(\mathrm{A})$ 和启动子，由 $\mathrm{RNA}$ 聚合酶Ⅱ转录，但“不编码任何蛋白质”“序列中不存在可读框”。看见尾巴不要自动写成 $\mathrm{mRNA}$。
:::

:::pitfall{label="circRNA 没有 5′ 端和 3′ 端，帽尾那一套用不上"}
封闭环不受外切酶影响，所以更稳定。不要把 $\mathrm{circRNA}$ 听成“把 $\mathrm{mRNA}$ 头尾接起来仍按线性 $\mathrm{mRNA}$ 翻译”的本节结论——教材把它放在调控性非编码。
:::

## 六、核酶是具有生物催化功能的 RNA 分子

核酶（ribozyme）是一类具有生物催化功能的 $\mathrm{RNA}$ 分子，是生物催化剂。核酶又称核酸类酶、酶 $\mathrm{RNA}$、核酶类酶 $\mathrm{RNA}$；ribozyme 是核糖核酸和酶两个词的缩合词。

:::definition{label="核酶"}
核酶（ribozyme）是一类具有生物催化功能的 $\mathrm{RNA}$ 分子，是生物催化剂。又称核酸类酶、酶 $\mathrm{RNA}$、核酶类酶 $\mathrm{RNA}$。ribozyme 是核糖核酸和酶两个词的缩合词。
:::

### （一）具有催化功能的 RNA 分子被发现

酶的化学本质从发现开始直至 $20$ 世纪 $80$ 年代初，一直被认为是蛋白质。$1981$ 年美国科罗拉多大学博尔德分校的 Cech T. 等人在研究 $\mathrm{rRNA}$ 前体加工成熟时发现四膜虫的 $26\mathrm{S}$ $\mathrm{rRNA}$ 前体中含有插入序列（intervening sequence，$\mathrm{IVS}$），在 $\mathrm{rRNA}$ 前体成熟过程中，$\mathrm{IVS}$ 可以通过剪切反应被除去，并证实这一剪切反应不需要任何蛋白质的参与，是四膜虫的基因内部自行拼接的。与此同时，耶鲁大学 Altman S. 等在从事 $\mathrm{RNase}$ $\mathrm{P}$ 的研究中也发现了这一现象。$1983$ 年，就在 Cech T. 等发现 $\mathrm{RNA}$ 能自行拼接后的两年后，S. Altman 等就证明：在较高的 $\mathrm{Mg}^{2+}$ 浓度下，$\mathrm{RNase}$ $\mathrm{P}$ 中的 $\mathrm{RNA}$（$\mathrm{M1RNA}$）具有催化 $\mathrm{tRNA}$ 前体成熟的功能，而其蛋白质组分却不具备此催化功能。$1984$ 年 *Science* 发表的题为 First true RNA catalyst found 的报道标志着 $\mathrm{RNA}$ 催化剂的正式诞生，也正式改变了生物体内所有的酶都是蛋白质的传统观念，表明 $\mathrm{RNA}$ 不仅含有遗传信息，而且还有催化功能。两位科学家也因此共同获得 $1989$ 年度诺贝尔化学奖。T. Cech 把这类具有催化裂解活性的 $\mathrm{RNA}$（catalytic $\mathrm{RNA}$）分子取名为 Ribozyme，我国 $1994$ 年科学出版社出版的《英汉分子生物学与生物工程词汇》中将其译为核酶。

:::timeline{period="核酶的发现"}
- **至 20 世纪 80 年代初** 酶的化学本质一直被认为是蛋白质
- **1981** Cech T.（科罗拉多大学博尔德分校）：四膜虫 26S rRNA 前体含插入序列 IVS，剪切不需要蛋白质，基因内部自行拼接
- **同时** Altman S.（耶鲁）：RNase P 研究中也发现这一现象
- **1983** Altman 证明较高 Mg2+ 下 RNase P 中的 RNA（M1RNA）催化 tRNA 前体成熟，蛋白质组分无此催化功能
- **1984** Science 发表 First true RNA catalyst found，RNA 催化剂正式诞生
- **1989** Cech 与 Altman 共同获诺贝尔化学奖
- **1994** 科学出版社《英汉分子生物学与生物工程词汇》将 Ribozyme 译为核酶
:::

:::cause-effect{title="核酶改写了“酶都是蛋白质”"}
- **因** Cech 的自拼接 $\mathrm{IVS}$ 与 Altman 的 $\mathrm{M1RNA}$ 证明 $\mathrm{RNA}$ 本身可催化
- **果** 改变“生物体内所有的酶都是蛋白质”的传统观念：$\mathrm{RNA}$ 既含遗传信息，又有催化功能
:::

:::pitfall{label="RNase P 里干活的是 RNA 组分，不是蛋白质组分"}
较高 $\mathrm{Mg}^{2+}$ 下，$\mathrm{M1RNA}$ 有催化功能，蛋白质组分不具备此催化功能。把 $\mathrm{RNase}$ $\mathrm{P}$ 听成“还是蛋白酶、$\mathrm{RNA}$ 只是辅助”，核酶的定义会塌掉。
:::

### （二）核酶通常分为剪接型与剪切型

核酶的分类有很多种方式，一般常根据分子的催化机制将核酶分为剪接型（splicing）核酶和剪切型（cleavage）核酶。

剪接型核酶具有序列特异的核酸内切酶、$\mathrm{RNA}$ 连接酶等酶活性。其作用机制是通过既剪又接的方式除去内含子，整个过程中需要鸟苷酸或鸟苷及镁离子参与。剪接型核酶主要包括Ⅰ类内含子的自我剪接与Ⅱ类内含子的自我剪接。

剪切型核酶（只进行位点特异性切割）主要包括锤头核酶；发夹核酶；丁型肝炎病毒（human hepatitis delta virus，$\mathrm{HDV}$）核酶；$\mathrm{RNase}$ $\mathrm{P}$。剪切型核酶可以催化自体或者异体 $\mathrm{RNA}$ 的切割，相当于核酸内切酶。

:::definition{label="剪接型核酶"}
剪接型（splicing）核酶具有序列特异的核酸内切酶、$\mathrm{RNA}$ 连接酶等酶活性。通过既剪又接除去内含子，需要鸟苷酸或鸟苷及镁离子。主要包括Ⅰ类内含子与Ⅱ类内含子的自我剪接。
:::

:::definition{label="剪切型核酶"}
剪切型（cleavage）核酶只进行位点特异性切割，主要包括锤头核酶、发夹核酶、丁型肝炎病毒（$\mathrm{HDV}$）核酶和 $\mathrm{RNase}$ $\mathrm{P}$。可催化自体或异体 $\mathrm{RNA}$ 切割，相当于核酸内切酶。
:::

:::compare{title="剪接型既剪又接，剪切型只切"}
| 项目 | 剪接型 | 剪切型 |
|------|--------|--------|
| 英文 | splicing | cleavage |
| 做什么 | 既剪又接，除去内含子 | 只进行位点特异性切割 |
| 辅因子／条件 | 鸟苷酸或鸟苷及镁离子 | 按各分子而异 |
| 教材成员 | Ⅰ类、Ⅱ类内含子自我剪接 | 锤头、发夹、$\mathrm{HDV}$、$\mathrm{RNase}$ $\mathrm{P}$ |
| 相当于 | 核酸内切酶 + $\mathrm{RNA}$ 连接酶 | 核酸内切酶 |
:::

### （三）核酶具有不同的空间构象

自然界存在一些不同的核酶，如锤头状核酶（hammerhead ribozyme，$\mathrm{HHR}$）、发夹状核酶（hairpin ribozyme）等，核酶的结构与催化机制差异较大。

锤头状核酶属于自剪切核酶，功能依赖于 $\mathrm{RNA}$ 正确的空间构象，$\mathrm{HHR}$ 二级结构与锤头结构（hammerhead structure）相似，因此得名。典型的锤头结构是由 $11\sim 13$ 个保守的核苷酸和三个茎区构成，而茎区是由互补碱基构成的局部双链结构，包围保守核苷酸构成催化中心；锤头核酶很有可能是分布最为广泛的核酶。

发夹核酶的催化基序最早是在植物卫星病毒（plant satellite virus）中发现的，典型的发夹型结构是由 $50$ 个核苷酸组成，包括四个螺旋区、三个连接区和两个环。目前人工合成的发夹核酶已成为第一个进入基因治疗临床试验阶段的核酶。

大多数核酶主要是催化转酯反应，即通过催化靶位点 $\mathrm{RNA}$ 链中磷酸二酯键的断裂，特异性地剪切底物 $\mathrm{RNA}$ 分子，从而阻断基因的表达。核酶的发现推动了对于生命活动多样性的理解，而针对人类免疫缺陷病毒（human immunodeficiency virus，$\mathrm{HIV}$）的人工合成发夹核酶已经进入临床试验。理论上讲，核酶可以广泛应用于基因产物异常相关疾病的治疗领域。

:::definition{label="锤头状核酶"}
锤头状核酶（hammerhead ribozyme，$\mathrm{HHR}$）属于自剪切核酶，功能依赖于 $\mathrm{RNA}$ 正确的空间构象。二级结构与锤头结构相似故得名。典型结构由 $11\sim 13$ 个保守核苷酸和三个茎区构成；茎区是互补碱基构成的局部双链，包围保守核苷酸构成催化中心。锤头核酶很可能是分布最广泛的核酶。
:::

:::definition{label="发夹核酶"}
发夹核酶（hairpin ribozyme）的催化基序最早在植物卫星病毒中发现。典型发夹型结构由 $50$ 个核苷酸组成，包括四个螺旋区、三个连接区和两个环。人工合成的发夹核酶是第一个进入基因治疗临床试验阶段的核酶；针对 $\mathrm{HIV}$ 的人工合成发夹核酶已进入临床试验。
:::

:::keypoint{label="大多数核酶催化转酯：切断磷酸二酯键"}
通过催化靶位点 $\mathrm{RNA}$ 链中磷酸二酯键的断裂，特异性剪切底物 $\mathrm{RNA}$，从而阻断基因表达。理论上可广泛用于基因产物异常相关疾病的治疗。
:::

:::insight{label="核酶功能依赖于正确构象，不是序列写上就能切"}
锤头要三个茎区围住保守核苷酸；发夹要四螺旋、三连接、两环。把核酶听成“一段能切 $\mathrm{RNA}$ 的碱基序列、折叠无所谓”，自剪切和临床试验那一笔都会失去结构基础。
:::

:::memory{label="本节必背要点"}
- [ ] $\mathrm{RNA}$ 一般是 $\mathrm{DNA}$ 的转录产物；编码 $\mathrm{RNA}$ 仅 $\mathrm{mRNA}$ 一种；非编码分组成性（丰度恒定）和调控性（随环境／细胞性状变）。
- [ ] 组成性：$\mathrm{tRNA}$、$\mathrm{rRNA}$、端粒 $\mathrm{RNA}$、$\mathrm{SRP}$ $\mathrm{RNA}$ 等。
- [ ] $\mathrm{RNA}$ 含核糖、含 $\mathrm{U}$ 而几乎不含 $\mathrm{T}$；常规核苷酸 $\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$、$\mathrm{UMP}$；通常单链，链内可形成局部双螺旋。
- [ ] $\mathrm{mRNA}$ 占 $\mathrm{RNA}$ 总重量 $2\%\sim 5\%$，种类约 $10^{5}$，寿命数分钟至数小时；真核初级产物为 $\mathrm{hnRNA}$。
- [ ] $5'$-帽：反式 $\mathrm{m}^{7}\mathrm{Gppp}$，$5'-5'$ 三磷酸键；下游第一、第二个核苷酸 $\mathrm{C}$-$2'$ 可甲基化；原核无此帽；与 $\mathrm{CBP}$ 结合，稳定、出核、促翻译起始。
- [ ] $3'$-$\mathrm{poly}(\mathrm{A})$ 尾：$80\sim 250$ 个腺苷酸，转录后由多聚腺苷酸聚合酶加入；约每 $20$ 个 $\mathrm{A}$ 结合一个 $\mathrm{PABP}$；有些原核也有较短的尾。
- [ ] 帽和尾共同负责转运、稳定和翻译起始调控；去除则 $\mathrm{mRNA}$ 迅速降解。
- [ ] $\mathrm{hnRNA}$ 含交替的外显子和内含子；内含子剪切、外显子连接，再加帽加尾成为成熟 $\mathrm{mRNA}$。
- [ ] 鸡卵清蛋白： $8$ 个外显子（$\mathrm{L}$、$1\sim 7$）、$7$ 个内含子（$\mathrm{A}\sim\mathrm{G}$），$7\,564\,\mathrm{bp}$ 基因 → $1\,872\,\mathrm{nt}$ $\mathrm{mRNA}$。
- [ ] 成熟真核 $\mathrm{mRNA}$：$5'$-帽、$5'$-$\mathrm{UTR}$、编码区／$\mathrm{ORF}$（$\mathrm{AUG}$ 至 $\mathrm{UAA}/\mathrm{UAG}/\mathrm{UGA}$）、$3'$-$\mathrm{UTR}$、$\mathrm{poly}(\mathrm{A})$ 尾。
- [ ] $\mathrm{tRNA}$ 约占 $15\%$， $74\sim 95$ 个核苷酸；稀有碱基（$\mathrm{DHU}$、$\psi$、$\mathrm{m}^{7}\mathrm{G}$、$\mathrm{m}^{7}\mathrm{A}$）占 $10\%\sim 20\%$，转录后修饰；$\psi$ 是 $\mathrm{C}5$–$\mathrm{C}1'$ 相连。
- [ ] 二级三叶草：氨基酸臂、$\mathrm{DHU}$ 环、$\mathrm{T}\psi\mathrm{C}$ 环、反密码子环、可变臂；三级倒 $\mathrm{L}$，靠特殊氢键和碱基堆积力。
- [ ] $3'$-端 $\mathrm{CCA}$；氨基酸酯连在末端 $\mathrm{A}$ 的 $\mathrm{C}3'$；反密码子环 $7\sim 9$ 核苷酸，居中 $3$ 个为反密码子。
- [ ] 酪氨酸：反密码子 $\mathrm{GUA}$ 对密码子 $\mathrm{UAC}$；一种氨基酸可有几种 $\mathrm{tRNA}$ 以适应简并性；摆动配对在翻译章展开。
- [ ] $\mathrm{rRNA}$ 约占 $80\%$ 以上；原核 $5\mathrm{S}/16\mathrm{S}/23\mathrm{S}$ → $30\mathrm{S}+50\mathrm{S}$；真核再加 $5.8\mathrm{S}$ → $40\mathrm{S}+60\mathrm{S}$。
- [ ] $18\mathrm{S}$ $\mathrm{rRNA}$ 有大量茎环；$\mathrm{A}$ 位氨酰 $\mathrm{tRNA}$，$\mathrm{P}$ 位肽酰-$\mathrm{tRNA}$，$\mathrm{E}$ 位排出空载 $\mathrm{tRNA}$；$\mathrm{mRNA}$ 在大小亚基缝隙。
- [ ] $\mathrm{snoRNA}$：核仁，$\mathrm{rRNA}$ 的 $2'$-$\mathrm{O}$-甲基化与假尿嘧啶化；$\mathrm{snRNA}$ $\mathrm{U}1\sim\mathrm{U}7$；$\mathrm{SRP}$-$\mathrm{RNA}$ 引导信号肽进内质网。
- [ ] $\mathrm{miRNA}$ 结合靶 $\mathrm{mRNA}$ 的 $3'$-$\mathrm{UTR}$（少量 $5'$-$\mathrm{UTR}$／编码区）；$\mathrm{siRNA}$ $21\sim 23\,\mathrm{bp}$，$\mathrm{RNAi}$；$\mathrm{piRNA}$ 约 $30\,\mathrm{nt}$，结合 $\mathrm{PIWI}$。
- [ ] $\mathrm{lncRNA}$：$200\sim 100\,000\,\mathrm{nt}$，有尾无 $\mathrm{ORF}$；$\mathrm{circRNA}$ 封闭环，无 $5'$/$3'$ 端，几乎全在核内。
- [ ] 核酶是催化性 $\mathrm{RNA}$；$1981$ Cech、$1983$ Altman、$1989$ 诺贝尔化学奖。
- [ ] 剪接型：Ⅰ／Ⅱ类内含子，既剪又接，需鸟苷（酸）和镁；剪切型：锤头、发夹、$\mathrm{HDV}$、$\mathrm{RNase}$ $\mathrm{P}$。
- [ ] 锤头：$11\sim 13$ 保守核苷酸 + 三茎区；发夹：$50$ 核苷酸，四螺旋三连接两环，已进基因治疗临床试验。
:::
