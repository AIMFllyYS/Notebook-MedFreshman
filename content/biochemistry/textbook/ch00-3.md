# 第三节　生物化学与分子生物学是生物学、医学的基础和前沿学科

本节先写它为何成为生物学和医学的共同基础与共同语言，再写分子医学怎样从分子水平改写疾病的发生机制、诊断和治疗。绪论在此收口，不另写本章小结。

以研究生命现象与本质为基础的生物学是一个涵盖众多学科的生命科学领域，包括形态学、分类学、生理学、生物化学、遗传学、生态学等。当今生物化学又是生命科学中进展迅速的重要学科之一，它的理论和技术已渗透到生物学各学科乃至基础医学和临床医学的各个领域，使之产生了许多新兴的交叉学科，如分子遗传学、分子免疫学、分子微生物学、分子病理学和分子药理学等。总而言之，生物化学与分子生物学已成为生物学各学科之间、医学各学科之间相互联系的共同语言。

:::definition{label="生物学的学科谱"}
以研究生命现象与本质为基础的生物学涵盖众多学科，包括形态学、分类学、生理学、生物化学、遗传学、生态学等。生物化学是其中之一，而且是当今进展迅速的重要学科。
:::

:::definition{label="交叉学科（分子×医学基础课）"}
生物化学的理论和技术渗透到生物学各学科乃至基础医学和临床医学各领域，产生分子遗传学、分子免疫学、分子微生物学、分子病理学和分子药理学等新兴交叉学科。
:::

:::definition{label="共同语言"}
生物化学与分子生物学已成为生物学各学科之间、医学各学科之间相互联系的共同语言。第二节把它写成工具和“语言”学科，这里落到生物学和医学两张网上。
:::

:::insight{label="共同语言不是比喻，是各科开始用同一套分子词汇"}
形态、分类、生理、遗传、生态，以及病理、免疫、药理、微生物，一旦问到机制，都会说到大分子、代谢和基因信息。把生物化学听成“化学系的课、医学只用结论”，分子遗传学到分子药理学这一串交叉学科会没有来路。
:::

## 一、生物化学与分子生物学是生物学、医学的基础学科

虽然生命体之间具有十分复杂的多样性，但生命的本质是共同的。生命体的化学元素组成相同，它们通过特定的化学规律形成生命体内共同的糖、脂质、蛋白质和核酸等生物大分子和各种小分子，与无机元素一起，组成各种复合体，形成细胞器、细胞，再构建成组织、器官、系统，最终形成各种复杂的生命体。这些生命体都需要与环境进行物质和能量交换，具有相同的代谢基本规律和代谢调节体系。各种生命体具有基本相同的信息（包括遗传信息）编码体系和传递体系，按基本相同的传递规律在体内、个体之间和亲子代之间传递。所以，无论从什么角度、什么层面认识这些生命体及其相关异常和疾病，都需要了解它们的化学组成、代谢及其调节规律、体内大分子的结构与功能的关系。生物化学与分子生物学也就成了生命科学和医学的重要基础学科。

:::definition{label="生命本质的共同性"}
生命体之间多样性十分复杂，但生命的本质是共同的：化学元素组成相同；按特定化学规律形成共同的糖、脂质、蛋白质和核酸等生物大分子及各种小分子。
:::

:::definition{label="从分子到生命体的组建层次"}
大分子与小分子与无机元素一起，组成各种复合体，形成细胞器、细胞，再构建成组织、器官、系统，最终形成各种复杂的生命体。基础学科要写的是这条组建链上的化学组成、代谢和大分子结构与功能，不是跳过分子直接谈器官。
:::

:::definition{label="共同的代谢与信息体系"}
生命体都需要与环境进行物质和能量交换，具有相同的代谢基本规律和代谢调节体系；并具有基本相同的信息（包括遗传信息）编码体系和传递体系，按基本相同的规律在体内、个体之间和亲子代之间传递。
:::

:::concept{term="先问共同本质落在哪三本账，再问为什么医学也必须读"}
多样性很大，本质却收成三本账：共同的化学组成（元素 → 糖、脂质、蛋白质、核酸等）；共同的代谢规律与调节体系；共同的信息编码与传递体系。无论从哪个角度认识生命体及其异常和疾病，都要了解化学组成、代谢及其调节、大分子结构与功能。所以它是生命科学和医学的重要基础学科。把“基础”听成“只背结构式”，代谢和信息传递两本账会从绪论里丢掉。
:::

:::compare{title="多样性很大，本质收成三本账"}
| 共同本质 | 教材原意 | 认识疾病时缺了会怎样 |
|----------|----------|------------------------|
| 化学组成 | 相同元素，按化学规律形成共同的糖、脂质、蛋白质、核酸等大分子及小分子，再逐级建成生命体 | 说不清细胞器和器官是由什么分子搭起来的 |
| 代谢 | 与环境进行物质和能量交换；代谢基本规律和调节体系相同 | 说不清紊乱如何致病 |
| 信息 | 基本相同的编码与传递体系，在体内、个体间、亲子代之间传递 | 说不清遗传病、肿瘤等如何在分子上发生 |
:::

## 二、生物化学与分子生物学带领医学进入分子医学新时代

生物化学与分子生物学的形成和发展，使人们对人体的认识逐渐进入分子水平，从分子水平研究疾病的发生机制、诊断方法、治疗措施（包括药物治疗）。特别是 Pauling L. 于 $1940$ 年采用 X 射线分析发现，珠蛋白结构改变导致了镰状细胞贫血。$1956$ 年，Ingram V. 证实珠蛋白第 $6$ 位氨基酸由谷氨酸突变为缬氨酸是镰状细胞贫血的致病原因。医学从此进入了分子医学新时代。生物化学与分子生物学不仅是重要的临床医学基础课程，也是医学研究的理论基础，还为临床技术、方法和药物的开发提供强大的技术支撑，是进展最快的医学前沿学科之一。

:::definition{label="分子医学新时代"}
人们对人体的认识进入分子水平，从分子水平研究疾病的发生机制、诊断方法、治疗措施（包括药物治疗）。教材把这一转向称为分子医学新时代。
:::

:::definition{label="镰状细胞贫血的分子病因"}
Pauling L. 于 $1940$ 年用 X 射线分析发现，珠蛋白结构改变导致镰状细胞贫血。$1956$ 年 Ingram V. 证实珠蛋白第 $6$ 位氨基酸由谷氨酸突变为缬氨酸是致病原因。医学从此进入分子医学新时代。
:::

:::note{label="这门课在医学里的三重身份"}
它不仅是重要的临床医学基础课程，也是医学研究的理论基础，还为临床技术、方法和药物的开发提供强大的技术支撑，并且是进展最快的医学前沿学科之一。基础课、研究基础、技术支撑、前沿学科——四句话不要并成“只是考研科目”。
:::

:::cause-effect{title="一处氨基酸替换怎样打开分子医学"}
- **因** 珠蛋白第 $6$ 位谷氨酸突变为缬氨酸，结构随之改变
- **果** 导致镰状细胞贫血；人们第一次把一种疾病写成特定分子的改变，医学进入分子医学新时代
:::

:::compare{title="分子医学的三件事"}
| 方向 | 教材标题落点 | 早期例子 | 后来推进到 |
|------|--------------|----------|------------|
| 发生发展机制 | 从分子水平认识疾病的发生发展机制 | 先天性代谢病＝遗传性酶缺陷；镰状细胞贫血 | 调节蛋白质缺陷（如 LDL 受体）；癌基因与肿瘤抑制基因；“原因–途径–靶分子–细胞功能–疾病”范式 |
| 诊断 | 临床诊断进入分子诊断新时代 | 测缺陷酶的底物或产物等代谢物 | 酶活性、蛋白质水平、异位酶/异位蛋白；核酸杂交、扩增、芯片、测序 |
| 治疗 | 医学进入分子治疗新时代 | 苯丙酮尿症限制苯丙氨酸摄入 | 天然或基因工程蛋白质；抗体中和、抑制转录或 mRNA 翻译、活性抑制；基因敲入、编辑、表观遗传修饰 |
:::

### 生物化学与分子生物学带领医学从分子水平认识疾病的发生发展机制

镰状细胞贫血发病机制的阐明，使人们第一次认识到一种疾病由特定分子的改变引起，从此开启了在分子水平研究疾病发生发展机制的新时代。早期从分子水平阐明发病机制的疾病均为先天性代谢疾病，即遗传性酶缺陷。低密度脂蛋白受体基因缺陷导致家族性高胆固醇血症机制的阐明，将疾病发生机制的认识推进到一个新的水平，即调节蛋白质的缺陷也能导致疾病。癌基因、肿瘤抑制基因的发现及其功能的阐明，更是将调节蛋白质改变在维持生命体正常功能和疾病发生发展中作用的认识推向高潮。今天，疾病发生发展机制的研究已经进入了一个全新的时代。什么原因，通过什么调节途径，调节了什么靶分子，引起了细胞的什么代谢或其他功能改变，导致了什么疾病或症状，已经成为对疾病发生发展机制研究和认识的基本范式。

:::definition{label="遗传性酶缺陷"}
早期从分子水平阐明发病机制的疾病均为先天性代谢疾病，即遗传性酶缺陷。户头是酶分子本身有缺陷，还不是后面的“调节蛋白质缺陷”。
:::

:::definition{label="家族性高胆固醇血症（LDL 受体）"}
低密度脂蛋白受体基因缺陷导致家族性高胆固醇血症。这一机制把认识推进到：调节蛋白质的缺陷也能导致疾病。
:::

:::definition{label="癌基因与肿瘤抑制基因"}
癌基因、肿瘤抑制基因的发现及其功能的阐明，将调节蛋白质改变在维持正常功能和疾病发生发展中作用的认识推向高潮。
:::

:::definition{label="发病机制研究的基本范式"}
什么原因，通过什么调节途径，调节了什么靶分子，引起了细胞的什么代谢或其他功能改变，导致了什么疾病或症状——这已成为研究和认识疾病发生发展机制的基本范式。
:::

:::pitfall{label="酶缺陷、调节蛋白质缺陷、癌基因不是同一代认识"}
早期分子机制几乎都是遗传性酶缺陷。LDL 受体基因缺陷把账推进到调节蛋白质也能致病。癌基因和肿瘤抑制基因再把“调节蛋白质改变”推到高潮。今天的范式是原因–途径–靶分子–细胞功能–疾病/症状。五句话并成“都是基因突变”，层次会被抹平。
:::

:::timeline{period="从分子机制走进分子医学"}
- **1940** Pauling 用 X 射线分析发现珠蛋白结构改变导致镰状细胞贫血
- **1956** Ingram 证实珠蛋白第 6 位谷氨酸突变为缬氨酸
- **早期分子机制** 先天性代谢病＝遗传性酶缺陷
- **再推进** LDL 受体基因缺陷 → 家族性高胆固醇血症：调节蛋白质缺陷也能致病
- **推向高潮** 癌基因、肿瘤抑制基因：调节蛋白质改变维持功能并参与疾病发生发展
- **今日范式** 原因 → 调节途径 → 靶分子 → 细胞代谢或其他功能改变 → 疾病或症状
:::

### 生物化学与分子生物学引领临床诊断进入分子诊断新时代

当在分子水平弄清发病机制后，就可能基于发病机制在分子水平上准确诊断。早期在分子水平阐明发病机制的遗传性代谢疾病，就是通过分析患者体内代谢物（缺陷酶的底物或产物）水平的变化，在分子水平上对疾病作出准确的诊断。后来，体内代谢物的分析被更广泛地开发应用于疾病的诊断，并进一步发展到酶活性分析、蛋白质分子水平检测，包括异位酶活性分析和异位蛋白质分子检测。随着分子生物学技术的不断产生和发展，以核酸分子杂交技术、核酸扩增技术、基因芯片技术、基因测序技术等为基础，建立了一系列分子诊断方法，通过分析受检个体（或其携带的病原体）的遗传物质结构或表达水平变化，为疾病的预防、诊断、治疗和预后判断提供依据，大大提高了疾病诊断的准确性、特异性和效率。分子诊断已经成为体外诊断中最重要的发展方向和最快速的发展领域。

:::definition{label="分子诊断"}
在分子水平弄清发病机制后，基于发病机制在分子水平上准确诊断。分子诊断通过分析受检个体（或其携带的病原体）的遗传物质结构或表达水平变化，为预防、诊断、治疗和预后判断提供依据，提高准确性、特异性和效率。它已成为体外诊断中最重要的发展方向和最快速的发展领域。
:::

:::definition{label="从代谢物到蛋白质再到核酸"}
早期遗传性代谢病靠分析缺陷酶的底物或产物等代谢物水平作诊断；后来扩展为酶活性分析、蛋白质分子水平检测（包括异位酶活性分析和异位蛋白质分子检测）；再后以核酸分子杂交、核酸扩增、基因芯片、基因测序等建立系列分子诊断方法。
:::

:::compare{title="分子诊断三层对象"}
| 层 | 检测什么 | 典型用途 |
|----|----------|----------|
| 代谢物 | 缺陷酶的底物或产物等体内代谢物水平 | 早期遗传性代谢病的分子水平诊断 |
| 酶与蛋白质 | 酶活性、蛋白质分子水平；异位酶、异位蛋白质 | 把诊断从“代谢物变化”推进到“催化和分子本身” |
| 核酸 | 杂交、扩增、芯片、测序：遗传物质结构或表达水平 | 个体或其病原体；服务预防、诊断、治疗和预后 |
:::

:::note{label="分子诊断的服务面不只是“确诊”"}
教材写的是为疾病的预防、诊断、治疗和预后判断提供依据，并提高准确性、特异性和效率。不要把分子诊断听成只在入院那一次抽血。
:::

### 生物化学与分子生物学引领医学进入分子治疗新时代

在分子水平准确诊断疾病后，就可以针对特定的分子进行靶向性治疗。如早期建立的苯丙酮尿症诊断方法，在新生儿出生时就可以判断是否患有苯丙酮尿症，并通过调整膳食结构，限制苯丙氨酸摄入，就可以几乎消除苯丙酮尿症的临床症状。随着生物化学与分子生物学的进步和相应技术的发展，人们发现了一些蛋白质含量异常在疾病发生发展中的作用，先是用分离纯化的天然蛋白质治疗一些因蛋白质含量降低造成的疾病。后来，由于基因工程技术的成熟和应用，人们利用该技术产业化生产相应蛋白质，用于疾病的治疗。对一些含量或活性过高而导致疾病的蛋白质，人们采用抗体中和、抑制基因转录或 mRNA 翻译、活性抑制等方法降低相应蛋白质的含量或活性，治疗相应疾病，如肿瘤靶向药物的快速发展。上述一些技术的应用已经产业化，成为当今最活跃、最具发展前景的新兴产业，基因工程药物、基因工程疫苗已经广泛用于疾病的治疗和预防。随着基因敲入技术、基因编辑技术、表观遗传修饰技术的不断发展和成熟，人们正在努力探索在基因水平上纠正疾病的基因变异和/或进行基因的靶向稳定表达，实现更为精准的基因治疗。

:::definition{label="分子治疗"}
在分子水平准确诊断之后，针对特定分子进行靶向性治疗。终点可以是限制底物、补充蛋白质、降低过高的蛋白质，或在基因水平上纠正变异、实现靶向稳定表达。
:::

:::definition{label="苯丙酮尿症的膳食治疗"}
早期建立的苯丙酮尿症诊断方法，可在新生儿出生时判断是否患病，并通过调整膳食、限制苯丙氨酸摄入，几乎消除临床症状。这是“先分子诊断、再针对特定分子干预”的早期样板。
:::

:::definition{label="蛋白质补充与基因工程药物"}
对因蛋白质含量降低造成的疾病，先用分离纯化的天然蛋白质治疗；基因工程技术成熟后，产业化生产相应蛋白质用于治疗。基因工程药物、基因工程疫苗已广泛用于治疗和预防。
:::

:::definition{label="降低过高蛋白质的三条路"}
对含量或活性过高而导致疾病的蛋白质，采用抗体中和、抑制基因转录或 mRNA 翻译、活性抑制等方法降低其含量或活性，如肿瘤靶向药物的快速发展。
:::

:::definition{label="基因治疗（当代探索）"}
随着基因敲入、基因编辑、表观遗传修饰技术的发展和成熟，人们正在探索在基因水平上纠正疾病的基因变异和/或进行基因的靶向稳定表达，实现更为精准的基因治疗。
:::

:::example{label="苯丙酮尿症：诊断立刻接到治疗"}
新生儿即可判断是否患苯丙酮尿症；限制苯丙氨酸摄入，临床症状几乎可消除。教材用它说明：分子诊断不是终点，针对特定分子的干预才把分子医学写完。
:::

:::pitfall{label="分子治疗不是只有基因编辑一条路"}
教材从膳食限制（苯丙酮尿症），写到天然蛋白质补充，再写到基因工程蛋白质，再到抗体中和、抑制转录或翻译、活性抑制，最后才是基因敲入、编辑和表观遗传修饰。把分子治疗听成“只有 CRISPR”，前面已经产业化的基因工程药物和疫苗会被写没。
:::

:::insight{label="机制、诊断、治疗是同一条分子账的三步，不是三门互不往来的课"}
先在分子上写清发病机制，才能基于机制做分子诊断；诊断对准特定分子之后，才能做靶向性治疗。镰状细胞贫血打开机制，代谢物和核酸技术打开诊断，苯丙酮尿症和基因工程药物打开治疗。三步缺一步，分子医学新时代就不完整。
:::

:::keypoint{label="共同语言 + 分子医学三件事"}
- 生物化学的理论和技术渗进生物学和医学各领域，形成分子遗传、免疫、微生物、病理、药理等交叉学科，成为共同语言。
- 生命多样性很大，本质共同：组成、代谢与调节、信息编码与传递；所以它是生命科学和医学的基础学科。
- $1940$/$1956$ 年珠蛋白结构与第 $6$ 位谷氨酸→缬氨酸，打开分子医学新时代。
- 机制：酶缺陷 → 调节蛋白质缺陷 → 癌基因/肿瘤抑制基因 → 原因–途径–靶分子–细胞功能–疾病范式。
- 诊断：代谢物 → 酶和蛋白质（含异位）→ 核酸杂交/扩增/芯片/测序；分子诊断是体外诊断的重要方向。
- 治疗：限制底物、补充蛋白质、降低过高蛋白质、基因水平纠正与稳定表达；基因工程药物和疫苗已经产业化。
:::

:::memory{label="本节必背要点"}
- [ ] 生物学涵盖形态学、分类学、生理学、生物化学、遗传学、生态学等。
- [ ] 生物化学的理论和技术已渗透到生物学各学科以及基础医学和临床医学各领域。
- [ ] 由此产生分子遗传学、分子免疫学、分子微生物学、分子病理学和分子药理学等交叉学科。
- [ ] 生物化学与分子生物学已成为生物学各学科之间、医学各学科之间相互联系的共同语言。
- [ ] 生命体多样性复杂，但生命的本质是共同的。
- [ ] 化学元素组成相同，按特定化学规律形成共同的糖、脂质、蛋白质和核酸等生物大分子及各种小分子。
- [ ] 这些分子与无机元素组成复合体，形成细胞器、细胞，再构建组织、器官、系统，形成复杂生命体。
- [ ] 生命体都与环境进行物质和能量交换，具有相同的代谢基本规律和代谢调节体系。
- [ ] 各种生命体具有基本相同的信息（包括遗传信息）编码体系和传递体系，在体内、个体之间和亲子代之间传递。
- [ ] 无论从什么角度认识生命体及其异常和疾病，都需要了解化学组成、代谢及其调节、大分子结构与功能的关系。
- [ ] 因此生物化学与分子生物学是生命科学和医学的重要基础学科。
- [ ] 学科发展使人们从分子水平研究疾病的发生机制、诊断方法和治疗措施（包括药物治疗）。
- [ ] $1940$ 年 Pauling L. 用 X 射线分析发现珠蛋白结构改变导致镰状细胞贫血。
- [ ] $1956$ 年 Ingram V. 证实珠蛋白第 $6$ 位氨基酸由谷氨酸突变为缬氨酸是致病原因。
- [ ] 医学从此进入分子医学新时代。
- [ ] 本学科是重要的临床医学基础课程、医学研究的理论基础，并为临床技术、方法和药物开发提供技术支撑，是进展最快的医学前沿学科之一。
- [ ] 镰状细胞贫血使人们第一次认识到一种疾病由特定分子的改变引起。
- [ ] 早期从分子水平阐明发病机制的疾病均为先天性代谢疾病，即遗传性酶缺陷。
- [ ] LDL 受体基因缺陷导致家族性高胆固醇血症，说明调节蛋白质的缺陷也能导致疾病。
- [ ] 癌基因、肿瘤抑制基因将调节蛋白质改变在正常功能与疾病中的作用推向高潮。
- [ ] 基本范式：什么原因，通过什么调节途径，调节了什么靶分子，引起细胞什么代谢或其他功能改变，导致什么疾病或症状。
- [ ] 弄清机制后，可基于机制在分子水平上准确诊断。
- [ ] 早期遗传性代谢病通过分析缺陷酶的底物或产物等代谢物水平作出诊断。
- [ ] 后来发展到酶活性分析、蛋白质分子水平检测，包括异位酶和异位蛋白质检测。
- [ ] 核酸分子杂交、核酸扩增、基因芯片、基因测序等建立了一系列分子诊断方法。
- [ ] 分子诊断分析受检个体或其病原体的遗传物质结构或表达水平变化，服务预防、诊断、治疗和预后。
- [ ] 分子诊断已成为体外诊断中最重要的发展方向和最快速的发展领域。
- [ ] 准确诊断后可针对特定分子进行靶向性治疗。
- [ ] 苯丙酮尿症可在新生儿期诊断，限制苯丙氨酸摄入几乎消除临床症状。
- [ ] 蛋白质含量降低的疾病，先用分离纯化的天然蛋白质治疗，后用基因工程产业化生产相应蛋白质。
- [ ] 含量或活性过高的蛋白质，可用抗体中和、抑制基因转录或 mRNA 翻译、活性抑制等治疗，如肿瘤靶向药物。
- [ ] 基因工程药物、基因工程疫苗已广泛用于治疗和预防。
- [ ] 基因敲入、基因编辑、表观遗传修饰技术正探索在基因水平纠正变异和/或靶向稳定表达，实现更精准的基因治疗。
:::
