# 第六节　酶在医学中的应用

本节把酶落到医学三本账：疾病发生（先天性缺陷、继发异常、中毒抑制）、诊断（血清等体液酶）和治疗（酶作药物、药物抑制酶）。再写酶作为试剂：酶偶联测定、酶标记（$\mathrm{ELISA}$）和基因工程工具酶。章末收本章小结，把第一至六节的酶学收成一段。

酶在医学中的应用十分广泛和重要，多种遗传病与酶的先天缺陷有关，许多酶已成为临床上诊断疾病的良好指标，有些酶还可作为药物用来治疗疾病。

:::definition{label="酶在医学中的三本账"}
多种遗传病与酶的先天缺陷有关；许多酶是临床上诊断疾病的良好指标；有些酶可作为药物用来治疗疾病。后文还补上：药物通过抑制体内某些酶达到治疗目的，以及酶作为检验和基因工程试剂。
:::

:::concept{term="先问酶是病因、指标还是药物，再问改的是质还是量"}
看见“酶与医学”，先分户头。酪氨酸酶缺乏是病因；血清丙氨酸转氨酶升高是指标；尿激酶溶栓是把酶当药物；洛伐他汀则是药去抑制酶。把所有血清酶升高都听成“这个人先天缺酶”，诊断和遗传病会对调。
:::

## 一、酶与疾病的发生、诊断及治疗密切相关

### （一）许多疾病与酶的质和量的异常相关

#### 1. 酶的先天性缺陷是先天性疾病的重要病因之一

现已发现 $140$ 多种先天性代谢缺陷中，多由酶的先天性或遗传性缺损所致。例如，酪氨酸酶缺乏引起白化病；苯丙氨酸羟化酶缺乏使苯丙氨酸和苯丙酮酸在体内堆积，高浓度的苯丙氨酸可抑制 $5$-羟色胺的生成，导致精神幼稚化；肝细胞中葡萄糖-$6$-磷酸酶缺陷，可引起 $\mathrm{I}\mathrm{a}$ 型糖原贮积症。

:::definition{label="酶的先天性缺陷"}
现已发现 $140$ 多种先天性代谢缺陷中，多由酶的先天性或遗传性缺损所致。这是先天性疾病的重要病因之一。
:::

:::example{label="三种先天缺酶"}
- 酪氨酸酶缺乏 → 白化病。
- 苯丙氨酸羟化酶缺乏 → 苯丙氨酸和苯丙酮酸堆积；高浓度苯丙氨酸抑制 $5$-羟色胺生成，导致精神幼稚化。
- 肝细胞葡萄糖-$6$-磷酸酶缺陷 → $\mathrm{I}\mathrm{a}$ 型糖原贮积症。
:::

:::cause-effect{title="苯丙氨酸羟化酶缺了为什么会精神幼稚化"}
- **因** 苯丙氨酸羟化酶缺乏，苯丙氨酸和苯丙酮酸在体内堆积；高浓度苯丙氨酸抑制 $5$-羟色胺的生成
- **果** 导致精神幼稚化
:::

:::pitfall{label="先天性缺陷是酶本身缺或坏，不是血清里暂时漏出来"}
白化病、苯丙酮酸堆积、$\mathrm{I}\mathrm{a}$ 型糖原贮积症，户头在酶的质／量先天缺损。下一小节的急性肝炎转氨酶升高，是肝细胞损伤后酶漏入血，酶基因未必缺。两本账不要并。
:::

#### 2. 一些疾病可引起酶活性或量的异常

许多疾病引起酶的异常，这种异常又使病情加重。例如，急性胰腺炎时，胰蛋白酶原在胰腺中被激活，造成胰腺组织被水解破坏。许多炎症都可以导致弹性蛋白酶从浸润的白细胞或巨噬细胞中释放，对组织产生破坏作用。激素代谢障碍或维生素缺乏可引起某些酶的异常。例如，维生素 $\mathrm{K}$ 缺乏时，凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ的前体不能在肝内进一步羧化生成成熟的凝血因子，病人表现出因这些凝血因子的异常所导致的临床征象。

酶活性受到抑制多见于中毒性疾病。例如，有机磷中毒时，抑制胆碱酯酶活性，引起乙酰胆碱堆积，导致神经肌肉和心脏功能的严重紊乱。重金属中毒时，一些巯基酶的活性被抑制而导致代谢紊乱。

:::definition{label="疾病引起的酶异常"}
许多疾病引起酶的异常，这种异常又使病情加重。与先天性缺损不同，这里是疾病在先、酶异常在后，再反过来加重病情。
:::

:::example{label="胰腺炎、炎症弹性蛋白酶、维生素K"}
急性胰腺炎：胰蛋白酶原在胰腺中被激活，胰腺组织被水解破坏——第四节“酶原避免自身消化”被打破。许多炎症：弹性蛋白酶从浸润的白细胞或巨噬细胞中释放，破坏组织。维生素 $\mathrm{K}$ 缺乏：凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ的前体不能在肝内进一步羧化生成成熟凝血因子，出现相应临床征象。激素代谢障碍也可引起某些酶异常。
:::

:::definition{label="中毒抑制酶活性"}
酶活性受到抑制多见于中毒性疾病。有机磷中毒抑制胆碱酯酶，乙酰胆碱堆积，导致神经肌肉和心脏功能严重紊乱。重金属中毒抑制一些巯基酶，导致代谢紊乱。
:::

:::compare{title="先天缺酶、疾病改酶、中毒抑酶"}
| 类型 | 起点 | 教材例子 | 后果 |
|------|------|----------|------|
| 先天性／遗传性缺损 | 酶的质或量先天异常 | 酪氨酸酶 → 白化病；苯丙氨酸羟化酶 → 苯丙氨酸／苯丙酮酸堆积、精神幼稚化；葡萄糖-$6$-磷酸酶 → $\mathrm{I}\mathrm{a}$ 型糖原贮积症 | 先天性疾病 |
| 疾病引起异常 | 疾病在先 | 急性胰腺炎时胰蛋白酶原在胰腺内被激活；炎症释放弹性蛋白酶；维生素 $\mathrm{K}$ 缺乏使凝血因子前体不能羧化 | 异常又使病情加重 |
| 中毒抑制 | 外源毒物 | 有机磷 → 胆碱酯酶；重金属 → 巯基酶 | 乙酰胆碱堆积或代谢紊乱 |
:::

:::insight{label="第四节的酶原保护，在胰腺炎这一笔被写反"}
正常时胰蛋白酶原要到小肠才被肠激酶切开。急性胰腺炎时它在胰腺中就被激活，水解的是自身组织。读第六节这一句，要回到第四节的生理意义，不要当成另一套酶。
:::

:::pitfall{label="维生素K缺乏不是凝血因子基因没了，而是前体羧化不了"}
教材写的是Ⅱ、Ⅶ、Ⅸ、Ⅹ的前体不能在肝内进一步羧化生成成熟凝血因子。不是这四种酶原完全没合成，而是成熟所需的羧化缺了维生素 $\mathrm{K}$。把它听成“先天性凝血因子缺损”，和苯丙氨酸羟化酶缺乏会对错机制。
:::

### （二）体液中酶活性的改变可作为疾病的诊断指标

组织器官损伤可使其组织特异性的酶释放入血，有助于对组织器官疾病的诊断。如急性肝炎时血清谷丙转氨酶（又称丙氨酸转氨酶）活性升高；急性胰腺炎时血、尿淀粉酶活性升高；前列腺癌病人血清酸性磷酸酶含量增高；骨癌病人血中碱性磷酸酶含量升高；卵巢癌和睾丸肿瘤病人血中胎盘型碱性磷酸酶升高。因此，血清中酶的增多或减少可用于辅助诊断和预后判断。

:::definition{label="血清酶作为诊断指标"}
组织器官损伤可使其组织特异性的酶释放入血，有助于诊断。血清中酶的增多或减少可用于辅助诊断和预后判断。
:::

:::example{label="教材列出的体液酶指标"}
- 急性肝炎：血清谷丙转氨酶（丙氨酸转氨酶）活性升高。
- 急性胰腺炎：血、尿淀粉酶活性升高。
- 前列腺癌：血清酸性磷酸酶含量增高。
- 骨癌：血中碱性磷酸酶含量升高。
- 卵巢癌和睾丸肿瘤：血中胎盘型碱性磷酸酶升高。
:::

:::compare{title="几种诊断用酶对什么病"}
| 酶 | 标本 | 升高时提示 |
|----|------|------------|
| 谷丙转氨酶（丙氨酸转氨酶） | 血清 | 急性肝炎 |
| 淀粉酶 | 血、尿 | 急性胰腺炎 |
| 酸性磷酸酶 | 血清 | 前列腺癌 |
| 碱性磷酸酶 | 血 | 骨癌 |
| 胎盘型碱性磷酸酶 | 血 | 卵巢癌、睾丸肿瘤 |
:::

:::pitfall{label="诊断用的是“漏出来的组织酶”，不是先天缺的那本账"}
肝炎时转氨酶升高，是肝细胞损伤后释放入血，不是病人突然多合成了许多转氨酶，更不是苯丙氨酸羟化酶那种先天缺损。碱性磷酸酶还要看同工酶／组织型：骨癌走普通碱性磷酸酶，卵巢癌和睾丸肿瘤走胎盘型。把三种碱性磷酸酶故事并成“$\mathrm{ALP}$ 高就是骨癌”，后两行会丢。
:::

:::note{label="辅助诊断和预后，不是单一金标准"}
教材的收口是“可用于辅助诊断和预后判断”。酶活性改变要和临床及其他检查一起读。
:::

### （三）某些酶可作为药物用于疾病的治疗

#### 1. 有些酶作为助消化的药物

酶作为药物最早用于助消化。如消化腺分泌功能下降所致的消化不良，可服用胃蛋白酶、胰蛋白酶、胰脂肪酶、胰淀粉酶等予以纠正。

:::definition{label="酶作为助消化药物"}
酶作为药物最早用于助消化。消化腺分泌功能下降所致的消化不良，可服用胃蛋白酶、胰蛋白酶、胰脂肪酶、胰淀粉酶等予以纠正。
:::

#### 2. 有些酶用于清洁伤口和抗炎

在清洁化脓伤口的洗涤液中，加入胰蛋白酶、溶菌酶、木瓜蛋白酶、菠萝蛋白酶等可加强伤口的净化、抗炎和防止浆膜粘连等。在某些外敷药中加入透明质酸酶可以增强药物的扩散作用。

:::definition{label="酶用于清洁伤口和抗炎"}
化脓伤口洗涤液中加入胰蛋白酶、溶菌酶、木瓜蛋白酶、菠萝蛋白酶等，可加强净化、抗炎和防止浆膜粘连。外敷药中加入透明质酸酶可增强药物扩散。
:::

#### 3. 有些酶具有溶解血栓的疗效

临床上常用链激酶、尿激酶及纤溶酶等溶解血栓，用于治疗心、脑血管栓塞等疾病。

:::definition{label="溶栓用酶"}
临床上常用链激酶、尿激酶及纤溶酶等溶解血栓，用于治疗心、脑血管栓塞等疾病。
:::

此外，许多药物的作用机制是通过抑制体内的某些酶来达到治疗目的。前述的磺胺类药物是细菌二氢蝶酸合酶的竞争性抑制剂；氯霉素可抑制某些细菌转肽酶的活性从而抑制其蛋白质的合成；抗抑郁药通过抑制单胺氧化酶而减少儿茶酚胺的灭活，治疗抑郁症；洛伐他汀通过竞争性抑制 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶的活性，减少胆固醇合成。甲氨蝶呤、$5$-氟尿嘧啶、$6$-巯基嘌呤等用于治疗肿瘤也是因为它们都是核苷酸合成途径中相关酶的竞争性抑制剂。

:::definition{label="以酶为靶点的药物"}
许多药物通过抑制体内某些酶达到治疗目的。这与“把酶本身当成药物服用”是另一本账。
:::

:::example{label="教材写到的酶靶点药物"}
- 磺胺类药物：细菌二氢蝶酸合酶的竞争性抑制剂。
- 氯霉素：抑制某些细菌转肽酶，从而抑制其蛋白质合成。
- 抗抑郁药：抑制单胺氧化酶，减少儿茶酚胺灭活。
- 洛伐他汀：竞争性抑制 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶，减少胆固醇合成。
- 甲氨蝶呤、$5$-氟尿嘧啶、$6$-巯基嘌呤：核苷酸合成途径中相关酶的竞争性抑制剂，用于治疗肿瘤。
:::

:::compare{title="酶当药物，还是药去抑制酶"}
| 方向 | 做法 | 教材例子 |
|------|------|----------|
| 酶作为药物 | 把酶制剂给病人 | 助消化：胃蛋白酶、胰蛋白酶、胰脂肪酶、胰淀粉酶；清创抗炎：胰蛋白酶、溶菌酶、木瓜蛋白酶、菠萝蛋白酶；透明质酸酶增强扩散；溶栓：链激酶、尿激酶、纤溶酶 |
| 药物抑制酶 | 化合物抑制体内或病原体的酶 | 磺胺 → 二氢蝶酸合酶；氯霉素 → 转肽酶；抗抑郁药 → 单胺氧化酶；洛伐他汀 → $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶；甲氨蝶呤、$5$-氟尿嘧啶、$6$-巯基嘌呤 → 核苷酸合成相关酶 |
:::

:::insight{label="洛伐他汀和第四节的诱导／阻遏不要并成一句"}
第四节：胰岛素诱导 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶合成，胆固醇阻遏其合成。这里：洛伐他汀竞争性抑制已经存在的该酶活性。一本是含量（缓慢），一本是现有酶被竞争性堵住（第三节动力学）。考“调胆固醇合成”时先问走的是哪一本账。
:::

:::pitfall{label="竞争性抑制剂那一行要回到第三节，不要新发明一套结合方式"}
磺胺、洛伐他汀、甲氨蝶呤、$5$-氟尿嘧啶、$6$-巯基嘌呤，教材都点名为竞争性抑制剂：表观 $K_\mathrm{m}$ 增大，$V_{\max}$ 不变。氯霉素写的是抑制转肽酶活性、抑制细菌蛋白质合成，没有在这一句里再标“竞争性”。不要把所有靶酶药物都默写成竞争性。
:::

## 二、酶可作为试剂用于临床检验和科学研究

### （一）有些酶可作为酶偶联测定法中的指示酶或辅助酶

有些酶促反应的底物或产物含量极低，不易直接测定。此时，可偶联另一种或两种酶，使初始反应产物定量地转变为另一种较易定量测定的产物，从而测定初始反应中的底物、产物或初始酶活性。这种方法称为酶偶联测定法。若偶联一种酶，这个酶即为指示酶（indicator enzyme）；若偶联两种酶，则前一种酶为辅助酶（auxiliary enzyme），后一种酶为指示酶。例如，临床上测定血糖时，利用葡萄糖氧化酶将葡萄糖氧化为葡萄糖酸，并释放 $\mathrm{H}_2\mathrm{O}_2$，过氧化物酶催化 $\mathrm{H}_2\mathrm{O}_2$ 与 $4$-氨基安替比林及苯酚反应生成水和红色醌类化合物，测定红色醌类化合物在 $505\,\mathrm{nm}$ 处的吸光度即可计算出血糖浓度。此反应中的过氧化物酶即为指示酶。

:::definition{label="酶偶联测定法"}
初始反应的底物或产物含量极低、不易直接测定时，偶联另一种或两种酶，使初始反应产物定量转变为较易定量测定的产物，从而测定初始反应中的底物、产物或初始酶活性。
:::

:::definition{label="指示酶与辅助酶"}
若偶联一种酶，该酶即为指示酶（indicator enzyme）。若偶联两种酶，前一种为辅助酶（auxiliary enzyme），后一种为指示酶。
:::

:::example{label="血糖的葡萄糖氧化酶–过氧化物酶偶联"}
葡萄糖氧化酶将葡萄糖氧化为葡萄糖酸，并释放 $\mathrm{H}_2\mathrm{O}_2$；过氧化物酶催化 $\mathrm{H}_2\mathrm{O}_2$ 与 $4$-氨基安替比林及苯酚反应，生成水和红色醌类化合物。测定红色醌类化合物在 $505\,\mathrm{nm}$ 处的吸光度，即可计算血糖浓度。此反应中过氧化物酶是指示酶。
:::

:::derivation{title="血糖偶联测定从葡萄糖读到 505 nm"}
1. 葡萄糖氧化酶：葡萄糖 $\rightarrow$ 葡萄糖酸 $+\mathrm{H}_2\mathrm{O}_2$。
2. 过氧化物酶（指示酶）：$\mathrm{H}_2\mathrm{O}_2$ $+$ $4$-氨基安替比林 $+$ 苯酚 $\rightarrow$ 水 $+$ 红色醌类化合物。
3. 在 $505\,\mathrm{nm}$ 读醌类吸光度，反推初始葡萄糖浓度。

读数的不是葡萄糖本身的颜色，而是指示酶做出来的红色产物。
:::

:::pitfall{label="指示酶是最后那个容易读数的酶，不是病人体内被测的酶"}
测血糖时，葡萄糖氧化酶和过氧化物酶都是试剂。过氧化物酶作为指示酶，把 $\mathrm{H}_2\mathrm{O}_2$ 变成 $505\,\mathrm{nm}$ 可读的红色醌。不要把指示酶听成“血清里升高的那种诊断酶”。
:::

### （二）有些酶可作为酶标记测定法中的标记酶

临床上经常需检测许多微量分子，过去一般都采用放射性核素标记法。鉴于其应用不便，现今多以酶标记代替核素标记。例如，酶联免疫吸附测定（enzyme-linked immunosorbent assays，$\mathrm{ELISA}$）法就是利用抗原–抗体特异性结合的特点，将标记酶与抗体偶联，对抗原或抗体作出检测的一种方法。常用的标记酶有辣根过氧化物酶、碱性磷酸酶、葡萄糖氧化酶、$\beta$-$\mathrm{D}$-半乳糖苷酶等。

:::definition{label="酶标记测定"}
检测微量分子时，以酶标记代替放射性核素标记。酶联免疫吸附测定（enzyme-linked immunosorbent assays，$\mathrm{ELISA}$）利用抗原–抗体特异性结合，将标记酶与抗体偶联，对抗原或抗体作出检测。
:::

:::definition{label="常用标记酶"}
常用的标记酶有辣根过氧化物酶、碱性磷酸酶、葡萄糖氧化酶、$\beta$-$\mathrm{D}$-半乳糖苷酶等。
:::

:::compare{title="酶偶联测定与酶标记测定"}
| 项目 | 酶偶联测定 | 酶标记（$\mathrm{ELISA}$） |
|------|------------|---------------------------|
| 目的 | 把不易直接测的底物／产物／酶活性，转成易定量的产物 | 检测微量抗原或抗体 |
| 酶的角色 | 辅助酶、指示酶接在反应序列里 | 标记酶偶联在抗体上 |
| 教材例子 | 血糖：葡萄糖氧化酶 $+$ 过氧化物酶，$505\,\mathrm{nm}$ 读红色醌 | 辣根过氧化物酶、碱性磷酸酶、葡萄糖氧化酶、$\beta$-$\mathrm{D}$-半乳糖苷酶 |
| 代替什么 | 直接测极低浓度底物或产物 | 放射性核素标记 |
:::

:::insight{label="过氧化物酶在两处露面，户头不同"}
测血糖时过氧化物酶是指示酶，读 $505\,\mathrm{nm}$。$\mathrm{ELISA}$ 里辣根过氧化物酶是标在抗体上的标记酶，读的是免疫结合。不要写成“血糖就是用 $\mathrm{ELISA}$ 测的”。
:::

### （三）多种酶成为基因工程常用的工具酶

多种酶现已常规用于基因工程操作过程中，例如Ⅱ型限制性内切核酸酶、$\mathrm{DNA}$ 连接酶、逆转录酶、$\mathrm{DNA}$ 聚合酶等。

:::definition{label="基因工程工具酶"}
多种酶现已常规用于基因工程操作，例如Ⅱ型限制性内切核酸酶、$\mathrm{DNA}$ 连接酶、逆转录酶、$\mathrm{DNA}$ 聚合酶等。
:::

:::note{label="工具酶能对上第五节的分类"}
Ⅱ型限制性内切核酸酶是水解酶（核酸内切）；$\mathrm{DNA}$ 连接酶是连接酶；$\mathrm{DNA}$ 聚合酶、逆转录酶按反应类型靠近转移／聚合。教材在这里只点名用途，分类仍以第五节为准。
:::

:::keypoint{label="酶在医学中的应用收口"}
- 病因：先天缺酶；$140$ 多种先天性代谢缺陷多与此有关。
- 疾病加重：胰腺炎酶原提前激活、炎症弹性蛋白酶、维生素 $\mathrm{K}$ 羧化障碍、有机磷／重金属抑制。
- 诊断：组织酶入血或入尿，辅助诊断和预后。
- 治疗：酶当药（助消化、清创、溶栓）；药抑酶（竞争性抑制剂等）。
- 试剂：偶联测定、酶标记、基因工程工具酶。
:::

## 本章小结

酶是具有催化特定化学反应的生物分子，本章只介绍对其特异底物起高效催化作用的蛋白质。缀合酶由酶蛋白和辅因子组成，只有全酶才具有催化作用。同工酶是指催化相同的化学反应，但酶蛋白的分子结构、理化性质和免疫学特性各不相同的一组酶。

酶对底物具有极高的催化效率、高度的特异性、可调节性及不稳定性。酶的特异性包括绝对特异性与相对特异性。

酶的活性中心是酶分子中能与底物特异结合并催化底物转变为产物的区域。活性中心内外的必需基团对于维持酶活性中心的构象是不可或缺的。

酶催化反应时，先与底物结合形成酶–底物复合物，通过邻近效应、定向排列、表面效应使底物转变成过渡态，并呈现多元催化作用。

酶促反应速率受底物浓度、酶浓度、温度、$\mathrm{pH}$、抑制剂和激活剂等影响。米氏方程揭示了单底物反应的动力学特性，米氏方程的双倒数作图常用来准确求取 $K_\mathrm{m}$ 和 $V_{\max}$。$K_\mathrm{m}$ 值等于反应速率为最大反应速率一半时的底物浓度，在一定条件下可反映酶与底物的亲和力大小。

三种可逆性抑制剂作用的特点：竞争性抑制剂存在时表观 $K_\mathrm{m}$ 增大，$V_{\max}$ 不变；非竞争性抑制剂存在时 $K_\mathrm{m}$ 不变，$V_{\max}$ 下降；反竞争性抑制剂存在时表观 $K_\mathrm{m}$ 和 $V_{\max}$ 均降低。

别构调节是由于别构调节物与别构酶的调节部位结合调节酶的催化活性。化学修饰调节是指酶蛋白多肽链上的某些小分子基团在其他酶的催化下，共价结合到被修饰酶的特定氨基酸残基上，引起酶分子构象变化，从而调节酶活性变化。

酶原是无活性的酶前体。酶原激活的实质是酶的活性中心形成或暴露过程。

根据酶催化的反应类型将其分为 $7$ 大类：氧化还原酶类、转移酶类、水解酶类、裂合酶类、异构酶类、连接酶类以及易位酶类。

:::definition{label="本章小结里的酶"}
酶是具有催化特定化学反应的生物分子。本章只介绍对其特异底物起高效催化作用的蛋白质。缀合酶由酶蛋白和辅因子组成，只有全酶才具有催化作用。
:::

:::definition{label="本章小结里的同工酶"}
同工酶是指催化相同的化学反应，但酶蛋白的分子结构、理化性质和免疫学特性各不相同的一组酶。
:::

:::definition{label="本章小结里的活性中心"}
活性中心是酶分子中能与底物特异结合并催化底物转变为产物的区域。活性中心内外的必需基团对于维持酶活性中心的构象是不可或缺的。
:::

:::compare{title="本章小结：三种可逆抑制"}
| 抑制剂 | 表观 $K_\mathrm{m}$ | $V_{\max}$ |
|--------|---------------------|------------|
| 竞争性 | 增大 | 不变 |
| 非竞争性 | 不变 | 下降 |
| 反竞争性 | 降低 | 降低 |
:::

:::insight{label="小结把全章收成三句话"}
结构账：蛋白质（核酶除外）、全酶才有活性、活性中心结合并催化、同工酶反应同而蛋白不同。动力学账：米氏方程求 $K_\mathrm{m}$、$V_{\max}$；三种可逆抑制改 $K_\mathrm{m}$ 与 $V_{\max}$ 的方式不同。调节与分类账：别构走调节部位，化学修饰走共价基团，酶原激活走活性中心形成或暴露；按反应类型分七大类。
:::

:::memory{label="本节必背要点"}
- [ ] 先天缺酶：$140$ 多种先天性代谢缺陷多由酶的先天性或遗传性缺损所致。
- [ ] 酪氨酸酶缺乏 → 白化病。
- [ ] 苯丙氨酸羟化酶缺乏 → 苯丙氨酸和苯丙酮酸堆积；高苯丙氨酸抑制 $5$-羟色胺，精神幼稚化。
- [ ] 肝细胞葡萄糖-$6$-磷酸酶缺陷 → $\mathrm{I}\mathrm{a}$ 型糖原贮积症。
- [ ] 急性胰腺炎：胰蛋白酶原在胰腺中被激活，水解破坏胰腺组织。
- [ ] 炎症：弹性蛋白酶从白细胞或巨噬细胞释放，破坏组织。
- [ ] 维生素 $\mathrm{K}$ 缺乏：凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ前体不能在肝内羧化成熟。
- [ ] 有机磷抑制胆碱酯酶 → 乙酰胆碱堆积 → 神经肌肉和心脏紊乱。
- [ ] 重金属抑制巯基酶 → 代谢紊乱。
- [ ] 急性肝炎：血清谷丙转氨酶（丙氨酸转氨酶）升高。
- [ ] 急性胰腺炎：血、尿淀粉酶升高。
- [ ] 前列腺癌：血清酸性磷酸酶增高；骨癌：碱性磷酸酶升高；卵巢癌／睾丸肿瘤：胎盘型碱性磷酸酶升高。
- [ ] 血清酶增多或减少用于辅助诊断和预后判断。
- [ ] 助消化：胃蛋白酶、胰蛋白酶、胰脂肪酶、胰淀粉酶。
- [ ] 清创抗炎：胰蛋白酶、溶菌酶、木瓜蛋白酶、菠萝蛋白酶；透明质酸酶增强扩散。
- [ ] 溶栓：链激酶、尿激酶、纤溶酶，用于心、脑血管栓塞。
- [ ] 磺胺：细菌二氢蝶酸合酶竞争性抑制剂。
- [ ] 氯霉素抑制细菌转肽酶，从而抑制蛋白质合成。
- [ ] 抗抑郁药抑制单胺氧化酶，减少儿茶酚胺灭活。
- [ ] 洛伐他汀竞争性抑制 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶，减少胆固醇合成。
- [ ] 甲氨蝶呤、$5$-氟尿嘧啶、$6$-巯基嘌呤：核苷酸合成相关酶的竞争性抑制剂，用于肿瘤。
- [ ] 酶偶联测定：指示酶；两种酶时前者为辅助酶、后者为指示酶。
- [ ] 血糖：葡萄糖氧化酶产生 $\mathrm{H}_2\mathrm{O}_2$，过氧化物酶生成红色醌，$505\,\mathrm{nm}$ 读数；过氧化物酶是指示酶。
- [ ] $\mathrm{ELISA}$：标记酶偶联抗体；常用辣根过氧化物酶、碱性磷酸酶、葡萄糖氧化酶、$\beta$-$\mathrm{D}$-半乳糖苷酶。
- [ ] 工具酶：Ⅱ型限制性内切核酸酶、$\mathrm{DNA}$ 连接酶、逆转录酶、$\mathrm{DNA}$ 聚合酶。
- [ ] 本章小结：全酶才有催化作用；同工酶反应同、蛋白不同；活性中心结合并催化。
- [ ] $K_\mathrm{m}$ 等于速率为 $V_{\max}$ 一半时的底物浓度，可反映亲和力。
- [ ] 竞争性：表观 $K_\mathrm{m}$ 增大、$V_{\max}$ 不变；非竞争性：$K_\mathrm{m}$ 不变、$V_{\max}$ 下降；反竞争性：表观 $K_\mathrm{m}$ 和 $V_{\max}$ 均降低。
- [ ] 别构：调节物结合调节部位；化学修饰：小分子基团共价接到特定残基。
- [ ] 酶原是无活性前体；激活实质是活性中心形成或暴露。
- [ ] 七大类：氧化还原、转移、水解、裂合、异构、连接、易位。
