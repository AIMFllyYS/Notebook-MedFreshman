# 第四节　磷脂代谢

前三节把甘油三酯的消化、动员、$\beta$-氧化和合成写完。本节把膜脂质立成两本账：甘油磷脂以磷脂酸为枢纽，胆碱／乙醇胺走甘油二酯（$\mathrm{CDP}$-胆碱）途径，肌醇／丝氨酸／心磷脂走 $\mathrm{CDP}$-甘油二酯途径；神经鞘磷脂以鞘氨醇为枢纽，原料是软脂酰 $\mathrm{CoA}$、丝氨酸和胆碱。降解分别交给磷脂酶 $\mathrm{A}_{1}/\mathrm{A}_{2}/\mathrm{B}_{1}/\mathrm{B}_{2}/\mathrm{C}/\mathrm{D}$ 和溶酶体鞘磷脂酶。

磷脂是生物膜的结构脂质，也是信号分子的前体。按骨架分成两类：以甘油为骨架的甘油磷脂（glycerophospholipid），和以鞘氨醇为骨架的鞘磷脂（sphingophospholipid）。人体含量最多的鞘磷脂是神经鞘磷脂（sphingomyelin）。甘油磷脂合成的重要中间产物是磷脂酸；神经鞘磷脂合成的重要中间产物是鞘氨醇。两条合成账都要 $\mathrm{CTP}$ 把头基或甘油二酯写成活化中间物；两条降解账切的酯键不同，产物和疾病也不一样。

:::definition{label="甘油磷脂"}
甘油磷脂（glycerophospholipid）以甘油为骨架。合成时先把甘油写成磷脂酸，再按头基分走甘油二酯途径或 $\mathrm{CDP}$-甘油二酯途径。组织及血液中含量最多的是磷脂酰胆碱和磷脂酰乙醇胺。
:::

:::definition{label="鞘磷脂"}
鞘磷脂（sphingophospholipid）以鞘氨醇为骨架。人体含量最多的是神经鞘磷脂（sphingomyelin），由鞘氨醇、脂肪酸及磷酸胆碱构成。
:::

:::compare{title="甘油磷脂与鞘磷脂先立两本账"}
| 项目 | 甘油磷脂 | 神经鞘磷脂 |
|------|----------|------------|
| 骨架 | 甘油 | 鞘氨醇 |
| 合成枢纽 | 磷脂酸 | 鞘氨醇 |
| 基本原料 | 甘油、脂肪酸、磷酸盐、胆碱、丝氨酸、肌醇等 | 软脂酰 $\mathrm{CoA}$、丝氨酸、胆碱 |
| 活化方式 | $\mathrm{CTP}$ 写成 $\mathrm{CDP}$-胆碱、$\mathrm{CDP}$-乙醇胺或 $\mathrm{CDP}$-甘油二酯 | $\mathrm{CDP}$-胆碱提供磷酸胆碱 |
| 合成部位 | 各组织内质网，肝、肾、肠活性最高 | 各组织内质网，脑组织活性最高 |
| 降解酶 | 磷脂酶 $\mathrm{A}_{1}$、$\mathrm{A}_{2}$、$\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{C}$、$\mathrm{D}$ | 溶酶体鞘磷脂酶（属磷脂酶 $\mathrm{C}$ 类） |
:::

:::concept{term="先问骨架是甘油还是鞘氨醇，再问头基怎么活化"}
看见“磷脂代谢”，不要立刻写成甘油三酯那一套。甘油磷脂问磷脂酸和 $\mathrm{CDP}$ 中间物；神经鞘磷脂问鞘氨醇和酰胺键。头基没被 $\mathrm{CTP}$ 活化，两条途径都走不通。
:::

## 一、磷脂酸是甘油磷脂合成的重要中间产物

### （一）甘油磷脂合成的原料来自糖、脂和氨基酸代谢

人体各组织细胞内质网均含有甘油磷脂合成酶系，以肝、肾及肠等活性最高。甘油磷脂合成的基本原料包括甘油、脂肪酸、磷酸盐、胆碱（choline）、丝氨酸（serine）、肌醇（inositol）等。甘油和脂肪酸主要由葡萄糖转化而来；甘油 $2$ 位的多不饱和脂肪酸为必需脂肪酸（essential fatty acids），只能从食物（植物油）摄取。胆碱可由食物供给，亦可由丝氨酸及甲硫氨酸合成。丝氨酸是合成磷脂酰丝氨酸的原料，脱羧后生成乙醇胺，又是合成磷脂酰乙醇胺的原料。乙醇胺从 $S$-腺苷甲硫氨酸获得 $3$ 个甲基生成胆碱。

:::definition{label="甘油磷脂合成的基本原料"}
基本原料包括甘油、脂肪酸、磷酸盐、胆碱、丝氨酸、肌醇等。甘油和脂肪酸主要由葡萄糖转化而来；甘油 $2$ 位多不饱和脂肪酸是必需脂肪酸，只能从植物油摄取。
:::

:::definition{label="胆碱的体内来源"}
胆碱可由食物供给，亦可由丝氨酸及甲硫氨酸合成：丝氨酸脱羧得乙醇胺，乙醇胺再从 $S$-腺苷甲硫氨酸获得 $3$ 个甲基生成胆碱。
:::

:::keypoint{label="头基怎样从氨基酸改写成胆碱"}
- 丝氨酸：合成磷脂酰丝氨酸的原料。
- 丝氨酸脱羧 → 乙醇胺：合成磷脂酰乙醇胺的原料。
- 乙醇胺 $+\,3$ 个甲基（$S$-腺苷甲硫氨酸）→ 胆碱。
- 三条头基账同源，不要把胆碱听成只能吃进去。
:::

甘油磷脂合成还需 $\mathrm{ATP}$、$\mathrm{CTP}$。$\mathrm{ATP}$ 供能；$\mathrm{CTP}$ 参与乙醇胺、胆碱、甘油二酯活化，形成 $\mathrm{CDP}$-乙醇胺（$\mathrm{CDP}$-ethanolamine）、$\mathrm{CDP}$-胆碱（$\mathrm{CDP}$-choline）、$\mathrm{CDP}$-甘油二酯等活化中间物。

:::definition{label="CTP 在甘油磷脂合成中的职分"}
$\mathrm{CTP}$ 把乙醇胺、胆碱或甘油二酯写成活化中间物：$\mathrm{CDP}$-乙醇胺、$\mathrm{CDP}$-胆碱、$\mathrm{CDP}$-甘油二酯。没有这张胞苷二磷酸“发票”，头基或甘油骨架接不上。
:::

:::compare{title="ATP 与 CTP 各管什么"}
| 高能化合物 | 教材职分 |
|------------|----------|
| $\mathrm{ATP}$ | 供能；乙醇胺／胆碱先被磷酸化 |
| $\mathrm{CTP}$ | 参与乙醇胺、胆碱、甘油二酯活化，生成 $\mathrm{CDP}$ 中间物 |

不要把“磷脂合成要能量”只写成 $\mathrm{ATP}$。$\mathrm{CTP}$ 这一笔是甘油磷脂的特征发票。
:::

:::insight{label="丝氨酸一笔连出三种头基"}
丝氨酸本身进磷脂酰丝氨酸；脱羧变成乙醇胺进磷脂酰乙醇胺；乙醇胺再甲基化变成胆碱进磷脂酰胆碱。甲硫氨酸提供甲基，户头在 $S$-腺苷甲硫氨酸，不是“另吃一种维生素就能跳过”。
:::

:::pitfall{label="甘油 2 位多不饱和脂肪酸不是体内能造的"}
甘油和脂肪酸“主要由葡萄糖转化而来”，但甘油 $2$ 位那一条多不饱和链是必需脂肪酸，只能从植物油摄取。把磷脂合成听成“糖够就能写全分子”，膜上的花生四烯酸来源会丢。
:::

乙醇胺、胆碱的活化顺序可以收成一条链：乙醇胺（或胆碱）先被 $\mathrm{ATP}$ 磷酸化，生成磷酸乙醇胺（或磷酸胆碱）；再与 $\mathrm{CTP}$ 缩合，放出焦磷酸，生成 $\mathrm{CDP}$-乙醇胺（或 $\mathrm{CDP}$-胆碱）。后面甘油二酯途径就用这两张 $\mathrm{CDP}$ 发票向甘油二酯移交磷酸乙醇胺或磷酸胆碱。

:::timeline{period="乙醇胺／胆碱写成 CDP 中间物"}
- **磷酸化** ATP 把乙醇胺、胆碱写成磷酸乙醇胺、磷酸胆碱
- **胞苷酰化** CTP 与磷酸头基缩合，生成 CDP-乙醇胺、CDP-胆碱
- **移交** CDP 中间物把磷酸头基交给甘油二酯，放出 CMP
:::

### （二）甘油磷脂合成有两条途径

甘油磷脂并不共用一张头基发票。磷脂酰胆碱（phosphatidyl choline，$\mathrm{PC}$）和磷脂酰乙醇胺（phosphatidyl ethanolamine，$\mathrm{PE}$）走甘油二酯途径：头基先活化成 $\mathrm{CDP}$-胆碱、$\mathrm{CDP}$-乙醇胺，再交给甘油二酯。磷脂酰肌醇、丝氨酸磷脂及心磷脂走 $\mathrm{CDP}$-甘油二酯途径：甘油骨架先活化成 $\mathrm{CDP}$-甘油二酯，肌醇、丝氨酸无须再活化。

:::compare{title="甘油磷脂合成的两条途径"}
| 项目 | 甘油二酯途径（$\mathrm{CDP}$-胆碱途径） | $\mathrm{CDP}$-甘油二酯途径 |
|------|------------------------------------------|---------------------------|
| 产物 | 磷脂酰胆碱（$\mathrm{PC}$）、磷脂酰乙醇胺（$\mathrm{PE}$） | 磷脂酰肌醇、丝氨酸磷脂、心磷脂 |
| 重要中间物 | 甘油二酯 | $\mathrm{CDP}$-甘油二酯 |
| 谁被 $\mathrm{CTP}$ 活化 | 胆碱、乙醇胺 → $\mathrm{CDP}$-胆碱、$\mathrm{CDP}$-乙醇胺 | 磷脂酸／甘油二酯 → $\mathrm{CDP}$-甘油二酯 |
| 头基要不要先活化 | 要 | 肌醇、丝氨酸无须活化 |
| 占组织及血液磷脂 | 这两类占 $75\%$ 以上 | 其余 |
:::

:::pitfall{label="两条途径不要并成“都是 CDP-胆碱”"}
$\mathrm{CDP}$-胆碱途径只写 $\mathrm{PC}$（及同源的 $\mathrm{PE}$）。肌醇、丝氨酸、心磷脂走的是 $\mathrm{CDP}$-甘油二酯，头基不再做成 $\mathrm{CDP}$-肌醇。把心磷脂也写成 $\mathrm{CDP}$-胆碱，线粒体内膜那一笔会对不上。
:::

**1. 磷脂酰胆碱和磷脂酰乙醇胺通过甘油二酯途径合成**　甘油二酯是该途径的重要中间物。胆碱（choline）和乙醇胺（ethanolamine）被活化成 $\mathrm{CDP}$-胆碱（$\mathrm{CDP}$-choline）和 $\mathrm{CDP}$-乙醇胺（$\mathrm{CDP}$-ethanolamine）后，分别与甘油二酯缩合，生成磷脂酰胆碱（phosphatidyl choline，$\mathrm{PC}$）和磷脂酰乙醇胺（phosphatidyl ethanolamine，$\mathrm{PE}$）。这两类磷脂占组织及血液磷脂 $75\%$ 以上。

从糖代谢来的甘油-$3$-磷酸，被 $2$ 分子脂肪酰 $\mathrm{CoA}$ 酯化，生成磷脂酸；磷脂酸脱磷酸得到甘油二酯。甘油二酯再分别接受 $\mathrm{CDP}$-胆碱或 $\mathrm{CDP}$-乙醇胺移交的磷酸头基，放出 $\mathrm{CMP}$，写成 $\mathrm{PC}$ 或 $\mathrm{PE}$。磷脂酸是这一段的枢纽：没有磷脂酸，就没有后面的甘油二酯。

:::definition{label="磷脂酸"}
磷脂酸是甘油磷脂合成的重要中间产物。甘油-$3$-磷酸被两分子脂肪酰 $\mathrm{CoA}$ 酯化即得磷脂酸；脱磷酸后成为甘油二酯，进入甘油二酯途径。
:::

:::definition{label="甘油二酯途径"}
甘油二酯途径以甘油二酯为重要中间物。$\mathrm{CDP}$-胆碱、$\mathrm{CDP}$-乙醇胺分别与甘油二酯缩合，生成 $\mathrm{PC}$ 和 $\mathrm{PE}$。这两类磷脂占组织及血液磷脂 $75\%$ 以上。
:::

:::definition{label="磷脂酰胆碱（PC）"}
磷脂酰胆碱（phosphatidyl choline，$\mathrm{PC}$）是真核生物细胞膜含量最丰富的磷脂，在细胞增殖和分化过程中具有重要作用，对维持正常细胞周期具有重要意义。一些疾病如癌（cancer）、阿尔茨海默病（Alzheimer disease）和脑卒中（stroke）等的发生与 $\mathrm{PC}$ 代谢异常密切相关。
:::

:::insight{label="PC 不只是膜上的“卵磷脂”这个名字"}
教材把 $\mathrm{PC}$ 写成真核细胞膜含量最丰富的磷脂，并点名增殖、分化、细胞周期，以及癌、阿尔茨海默病、脑卒中。户头仍是甘油二酯途径能不能把磷酸胆碱接到甘油二酯上，不是另开一条“疾病代谢”。
:::

尽管 $\mathrm{PC}$ 也可由 $S$-腺苷甲硫氨酸提供甲基，使 $\mathrm{PE}$ 甲基化生成，但这种方式合成量仅占人 $\mathrm{PC}$ 合成总量 $10\%\sim 15\%$。哺乳动物细胞 $\mathrm{PC}$ 的合成主要通过甘油二酯途径完成。该途径中，胆碱需先活化成 $\mathrm{CDP}$-胆碱，所以也被称为 $\mathrm{CDP}$-胆碱途径（$\mathrm{CDP}$-choline pathway）。$\mathrm{CTP}$：磷酸胆碱胞苷转移酶（$\mathrm{CTP}$：phosphocholine cytidylyltransferase，$\mathrm{CCT}$）是关键酶，它催化磷酸胆碱（phosphocholine）与 $\mathrm{CTP}$ 缩合成 $\mathrm{CDP}$-胆碱。后者向甘油二酯提供磷酸胆碱，合成 $\mathrm{PC}$。

:::definition{label="CDP-胆碱途径"}
哺乳动物细胞 $\mathrm{PC}$ 主要通过甘油二酯途径合成。胆碱需先活化成 $\mathrm{CDP}$-胆碱，故又称 $\mathrm{CDP}$-胆碱途径（$\mathrm{CDP}$-choline pathway）。
:::

:::definition{label="CTP：磷酸胆碱胞苷转移酶（CCT）"}
$\mathrm{CTP}$：磷酸胆碱胞苷转移酶（$\mathrm{CTP}$：phosphocholine cytidylyltransferase，$\mathrm{CCT}$）是 $\mathrm{CDP}$-胆碱途径的关键酶，催化磷酸胆碱与 $\mathrm{CTP}$ 缩合成 $\mathrm{CDP}$-胆碱。
:::

:::pitfall{label="PE 甲基化不是人 PC 的主路"}
$S$-腺苷甲硫氨酸给 $\mathrm{PE}$ 加三个甲基，确实能写出 $\mathrm{PC}$，但只占人 $\mathrm{PC}$ 合成总量 $10\%\sim 15\%$。主账仍是 $\mathrm{CDP}$-胆碱途径。把“胆碱可以从丝氨酸做出来”听成“人主要靠甲基化造 $\mathrm{PC}$”，关键酶会错写成甲基转移酶。
:::

:::compare{title="人 PC 的两条来路"}
| 来路 | 反应要点 | 占人 $\mathrm{PC}$ 合成 |
|------|----------|-------------------------|
| $\mathrm{CDP}$-胆碱途径（主） | 胆碱 → 磷酸胆碱 $\xrightarrow{\mathrm{CCT}}$ $\mathrm{CDP}$-胆碱 → 交给甘油二酯 | 主要方式 |
| $\mathrm{PE}$ 甲基化（次） | $S$-腺苷甲硫氨酸供甲基 | $10\%\sim 15\%$ |
:::

人 $\mathrm{CCT}$ 有 $\alpha$ 和 $\beta$ 两种亚型，分别由 $PCYT1a$ 和 $PCYT1b$ 编码。$\mathrm{CCT}\beta$ 又有 $\beta 1$ 和 $\beta 2$ 两种剪接变异体。$\mathrm{CCT}\alpha$、$\beta 1$ 和 $\beta 2$ 分别由 $367$、$330$ 和 $372$ 个氨基酸残基组成，含 $4$ 个结构域，氨基酸残基 $73$–$323$ 是高度同源序列，$\beta$ 剪接变异体之间的差异仅在 $323$ 位氨基酸残基之后的 $\mathrm{C}$ 末端。

:::keypoint{label="人 CCT 亚型与残基数"}
- $\mathrm{CCT}\alpha$：$PCYT1a$ 编码，$367$ 个氨基酸残基。
- $\mathrm{CCT}\beta 1$：$PCYT1b$ 剪接变异体，$330$ 个氨基酸残基。
- $\mathrm{CCT}\beta 2$：$PCYT1b$ 剪接变异体，$372$ 个氨基酸残基。
- 残基 $73$–$323$ 高度同源；$\beta 1$ 与 $\beta 2$ 的差别只在 $323$ 位之后的 $\mathrm{C}$ 端。
:::

四个结构域按教材残基号摊开：氨基酸残基 $1$–$72$ 为 $\mathrm{N}$ 端结构域，$\mathrm{CCT}\alpha$ 在该结构域中含有一个核靶向作用区。氨基酸残基 $73$–$235$ 为催化结构域，其中 $\mathrm{HXGH}$ 和 $\mathrm{RTEGISTS}$ 两个 $\mathrm{CTP}$ 结合模体（motif）是胞苷转移酶家族的特征序列，能与 $\mathrm{CTP}$ 结合；两个 $\mathrm{CTP}$ 结合基序之间的赖氨酸残基高度保守，能结合磷酸胆碱。氨基酸残基 $236$–$299$ 称为膜结合结构域（membrane-binding domain）或结构域 $\mathrm{M}$（domain $\mathrm{M}$），为双性 $\alpha$-螺旋（amphipathic $\alpha$ helix）结构区，能与中性脂质和阴离子脂质结合。$\mathrm{C}$ 末端是磷酸化结构域（phosphorylation domain），也称结构域 $\mathrm{P}$（domain $\mathrm{P}$），含多个丝氨酸残基，能够被磷酸化。

:::compare{title="CCT 的四个结构域"}
| 结构域 | 残基（教材） | 职分 |
|--------|--------------|------|
| $\mathrm{N}$ 端 | $1$–$72$ | $\mathrm{CCT}\alpha$ 含核靶向作用区 |
| 催化结构域 | $73$–$235$ | $\mathrm{HXGH}$、$\mathrm{RTEGISTS}$ 结合 $\mathrm{CTP}$；两模体之间的保守赖氨酸结合磷酸胆碱 |
| 膜结合结构域 $\mathrm{M}$ | $236$–$299$ | 双性 $\alpha$-螺旋；结合中性脂质和阴离子脂质 |
| 磷酸化结构域 $\mathrm{P}$ | $\mathrm{C}$ 末端 | 多个丝氨酸可被磷酸化 |
:::

:::note{label="HXGH 与 RTEGISTS 是家族特征，不是两个酶"}
这两个 $\mathrm{CTP}$ 结合模体写在同一个催化结构域里，是胞苷转移酶家族的特征序列。一个模体对 $\mathrm{CTP}$，中间的保守赖氨酸对磷酸胆碱，这才把两底物凑到一起写成 $\mathrm{CDP}$-胆碱。
:::

$\mathrm{CCT}$ 活性通过游离形式与膜结合形式之间的转换进行调节。游离形式 $\mathrm{CCT}$ 无活性，当其与膜（包括内质网膜和核膜）结合后，转变为有活性。$\mathrm{CCT}$ 通过膜结合结构域感应膜双分子层的弯曲弹性张力（curvature elastic stress），使游离酶蛋白与膜结合或使膜结合酶蛋白解离，从而调节酶活性。$\mathrm{PC}$ 含量是膜双分子层弯曲弹性张力的决定因素之一：$\mathrm{PC}$ 缺乏的膜，能促进 $\mathrm{CCT}$ 与其结合，使 $\mathrm{CCT}$ 转变为活性形式，促进 $\mathrm{PC}$ 合成。$\mathrm{CCT}$ 活性还受转录水平调节。$\mathrm{CCT}\alpha$ 活性的调节主要与细胞增殖、分化和细胞周期有关。

:::definition{label="CCT 的膜结合调节"}
游离形式 $\mathrm{CCT}$ 无活性；与内质网膜、核膜结合后才有活性。膜结合结构域感应双分子层弯曲弹性张力，决定酶是贴膜还是解离。
:::

:::cause-effect{title="PC 缺乏怎样把 CCT 打开"}
$\mathrm{PC}$ 缺乏改变膜双分子层弯曲弹性张力 → 促进 $\mathrm{CCT}$ 与膜结合 → 游离无活性酶转为活性形式 → 加速 $\mathrm{CDP}$-胆碱生成 → 补写 $\mathrm{PC}$。
:::

:::insight{label="关键酶贴膜，是因为产物本身就是膜"}
$\mathrm{PC}$ 写进双分子层，膜的弯曲弹性张力跟着变。$\mathrm{CCT}$ 用结构域 $\mathrm{M}$ 读这张力学信号：缺 $\mathrm{PC}$ 就贴膜开工，够了就解离。这不是别构剂名单里多一个小分子，而是产物直接改写酶所在的膜。
:::

:::pitfall{label="游离 CCT 不是“还没合成出来”"}
游离是已经有的酶蛋白，只是没贴膜、没有活性。不要把“游离无活性”听成“转录还没做”。教材另有一笔转录水平调节；$\mathrm{CCT}\alpha$ 主要跟增殖、分化和细胞周期有关。
:::

磷脂酰丝氨酸也可由磷脂酰乙醇胺羧化或乙醇胺与丝氨酸交换生成。这一笔是头基互换，不是第三条从零写起的合成途径。

:::note{label="磷脂酰丝氨酸有旁路，主路仍在后文 CDP-甘油二酯"}
可由 $\mathrm{PE}$ 羧化，或乙醇胺与丝氨酸交换生成。真正以丝氨酸为头基、从 $\mathrm{CDP}$-甘油二酯缩合的那一本，写在下面第 $2$ 条。
:::

**2. 磷脂酰肌醇、丝氨酸磷脂及心磷脂通过 CDP-甘油二酯途径合成**　肌醇、丝氨酸无须活化，$\mathrm{CDP}$-甘油二酯是该途径重要中间物，与丝氨酸、肌醇或磷脂酰甘油缩合，生成磷脂酰肌醇（phosphatidyl inositol）、丝氨酸磷脂（phosphatidyl serine）及心磷脂（cardiolipin）。

从甘油-$3$-磷酸写成磷脂酸之后，磷脂酸与 $\mathrm{CTP}$ 反应，放出焦磷酸，生成 $\mathrm{CDP}$-甘油二酯。$\mathrm{CDP}$-甘油二酯再把活化的磷脂酰基分别交给肌醇、丝氨酸或磷脂酰甘油，放出 $\mathrm{CMP}$。心磷脂可以看成两分子磷脂酰甘油通过共用的甘油桥连在一起，是线粒体内膜的特征性磷脂。

:::definition{label="CDP-甘油二酯途径"}
$\mathrm{CDP}$-甘油二酯途径以 $\mathrm{CDP}$-甘油二酯为重要中间物。肌醇、丝氨酸无须活化，与 $\mathrm{CDP}$-甘油二酯缩合即得磷脂酰肌醇、丝氨酸磷脂；$\mathrm{CDP}$-甘油二酯与磷脂酰甘油缩合则得心磷脂。
:::

:::definition{label="心磷脂"}
心磷脂（cardiolipin）由 $\mathrm{CDP}$-甘油二酯与磷脂酰甘油缩合生成，是线粒体内膜的特征性磷脂。
:::

:::compare{title="CDP-甘油二酯交出后的三种产物"}
| 接受体 | 产物 |
|--------|------|
| 肌醇 | 磷脂酰肌醇 |
| 丝氨酸 | 丝氨酸磷脂（磷脂酰丝氨酸） |
| 磷脂酰甘油 | 心磷脂 |
:::

甘油磷脂合成在内质网膜外侧面进行。胞质溶胶存在一类促进磷脂在细胞内膜之间交换的蛋白质，称磷脂交换蛋白（phospholipid exchange proteins），催化不同种类磷脂在膜之间交换，使新合成的磷脂转移至不同细胞器膜上，更新膜磷脂。例如在内质网合成的心磷脂可通过这种方式转至线粒体内膜，构成线粒体内膜特征性磷脂。

:::definition{label="磷脂交换蛋白"}
磷脂交换蛋白（phospholipid exchange proteins）存在于胞质溶胶，催化不同种类磷脂在膜之间交换，把内质网新合成的磷脂转到其他细胞器膜上，更新膜磷脂。
:::

:::example{label="心磷脂在内质网写成，却要出现在线粒体内膜"}
合成部位是内质网膜外侧面，线粒体内膜自己并不另开一套心磷脂合成酶系来“就地写”。磷脂交换蛋白把心磷脂从内质网转到线粒体内膜，这才成为内膜的特征性磷脂。
:::

:::pitfall{label="合成在内质网，不等于只留在内质网"}
酶系在内质网，产物要靠磷脂交换蛋白搬家。把“肝、肾、肠活性最高”听成“磷脂只存在于这些器官的内质网”，线粒体、核膜和其他细胞器的膜更新会没有户头。
:::

Ⅱ型肺泡上皮细胞可合成由 $2$ 分子软脂酸构成的特殊磷脂酰胆碱，生成的二软脂酰胆碱是较强乳化剂，能降低肺泡表面张力，有利于肺泡伸张。新生儿肺泡上皮细胞合成二软脂酰胆碱障碍，会引起肺不张。

:::definition{label="二软脂酰胆碱"}
Ⅱ型肺泡上皮细胞合成的特殊磷脂酰胆碱，由 $2$ 分子软脂酸构成。它是较强乳化剂，能降低肺泡表面张力，有利于肺泡伸张。
:::

:::cause-effect{title="新生儿肺不张与二软脂酰胆碱"}
新生儿肺泡上皮细胞合成二软脂酰胆碱障碍 → 肺泡表面张力不能被降低 → 肺泡不易伸张 → 肺不张。
:::

:::insight{label="同一张 PC 发票，肺泡要的是两条软脂酰"}
普通膜 $\mathrm{PC}$ 甘油 $2$ 位常是多不饱和必需脂肪酸；肺泡表面活性物质要的是 $2$ 分子软脂酸的二软脂酰胆碱。碳链饱和、乳化强、降表面张力，户头仍是磷脂酰胆碱，只是脂肪酸组成换成了肺这一笔。
:::

## 二、甘油磷脂由磷脂酶催化降解

生物体内存在多种降解甘油磷脂的磷脂酶（phospholipase），包括磷脂酶 $\mathrm{A}_{1}$、$\mathrm{A}_{2}$、$\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{C}$ 及 $\mathrm{D}$，它们分别作用于甘油磷脂分子中不同的酯键（图8-7），降解甘油磷脂。

::figure{src="/images/biochemistry/textbook/p0187_01.png" caption="图8-7　磷脂酶的甘油磷脂水解作用。甘油骨架：sn-1（上方）接脂肪酰 R₁，sn-2（左侧）接脂肪酰 R₂，sn-3（下方）接磷酸及取代基团 X。磷脂酶 A₁ 切 sn-1 酯键；磷脂酶 A₂ 切 sn-2 酯键；磷脂酶 B 同时覆盖 A₁、A₂ 两处脂肪酰酯键；磷脂酶 C 切甘油与磷酸之间的磷酸酯键；磷脂酶 D 切磷酸与 X 之间的磷酸酯键。X 为取代基团。" alt="甘油磷脂结构式：中央甘油，上方酯键连 R1 标磷脂酶A1，左侧酯键连 R2 标磷脂酶A2，左上磷脂酶B同时指向两处脂肪酰酯键，下方磷酸酯键靠甘油侧标磷脂酶C、靠X侧标磷脂酶D"}

:::definition{label="磷脂酶"}
磷脂酶（phospholipase）按所切酯键分户：$\mathrm{A}_{1}$、$\mathrm{A}_{2}$、$\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{C}$ 及 $\mathrm{D}$，分别作用于甘油磷脂分子中不同的酯键。
:::

:::compare{title="磷脂酶切哪一根酯键"}
| 酶 | 切点（图8-7） | 直接产物要点 |
|----|----------------|--------------|
| 磷脂酶 $\mathrm{A}_{1}$ | 甘油 $1$ 位（$\mathrm{sn}$-$1$）脂肪酰酯键 | 溶血磷脂（$2$ 位脂肪酰仍在） |
| 磷脂酶 $\mathrm{A}_{2}$ | 甘油 $2$ 位（$\mathrm{sn}$-$2$）脂肪酰酯键 | 溶血磷脂 $1$（$1$ 位脂肪酰仍在） |
| 磷脂酶 $\mathrm{B}$（$\mathrm{B}_{1}$／$\mathrm{B}_{2}$） | 两处脂肪酰酯键；$\mathrm{B}_{1}$ 即溶血磷脂酶 $1$，切溶血磷脂 $1$ 的 $1$ 位酯键 | 去掉剩余脂肪酰，溶血活性消失 |
| 磷脂酶 $\mathrm{C}$ | 甘油与磷酸之间的磷酸酯键 | 甘油二酯 $+$ 磷酸头基 |
| 磷脂酶 $\mathrm{D}$ | 磷酸与取代基团 $\mathrm{X}$ 之间的磷酸酯键 | 磷脂酸 $+$ 游离头基 $\mathrm{X}$ |
:::

:::pitfall{label="A1/A2 不是“酸性磷酸酶”，C/D 也不是“切脂肪酰”"}
$\mathrm{A}$ 切脂肪酰酯键，按甘油碳位分 $1$ 位、$2$ 位。$\mathrm{C}$ 切的是甘油－磷酸键，$\mathrm{D}$ 切的是磷酸－$\mathrm{X}$ 键，产物一个是甘油二酯，一个是磷脂酸。把 $\mathrm{C}$、$\mathrm{D}$ 也写成“切掉脂肪酸”，信号通路里的甘油二酯和磷脂酸会对调。
:::

溶血磷脂 $1$ 具较强表面活性，能使红细胞膜或其他细胞膜破坏引起溶血或细胞坏死。溶血磷脂还可进一步水解，如溶血磷脂 $1$ 在溶血磷脂酶 $1$（即磷脂酶 $\mathrm{B}_{1}$）作用下，水解与甘油 $1$ 位 —$\mathrm{OH}$ 缩合的酯键，溶血磷脂 $1$ 失去脂肪酸酰基，就失去了对细胞膜结构的溶解作用。

:::definition{label="溶血磷脂1"}
溶血磷脂 $1$ 是磷脂酶 $\mathrm{A}_{2}$ 切去甘油 $2$ 位脂肪酰后的产物，具较强表面活性，能使红细胞膜或其他细胞膜破坏，引起溶血或细胞坏死。
:::

:::definition{label="溶血磷脂酶1（磷脂酶B1）"}
溶血磷脂酶 $1$ 即磷脂酶 $\mathrm{B}_{1}$，水解溶血磷脂 $1$ 与甘油 $1$ 位 —$\mathrm{OH}$ 缩合的酯键。溶血磷脂 $1$ 失去剩余脂肪酰基后，即失去对细胞膜结构的溶解作用。
:::

:::insight{label="溶血磷脂的毒性在“还留着一条尾巴”"}
只切掉 $2$ 位脂肪酰，分子仍是单尾两亲物，表面活性强，能插进膜把细胞溶掉。磷脂酶 $\mathrm{B}_{1}$ 把 $1$ 位那条尾巴也切掉，两亲结构拆散，溶血作用随之消失。降解不是“切一次就结束”，第二刀是解毒。
:::

:::example{label="蛇毒溶血为什么常写磷脂酶 A2"}
磷脂酶 $\mathrm{A}_{2}$ 专切 $2$ 位酯键，产物正是溶血磷脂 $1$。教材把溶血、细胞坏死写在这一笔上；后续 $\mathrm{B}_{1}$ 才把毒性结构拆掉。不要把“磷脂酶”笼统听成都会溶血。
:::

## 三、鞘氨醇是神经鞘磷脂合成的重要中间产物

神经鞘磷脂（sphingomyelin）是人体含量最多的鞘磷脂，由鞘氨醇、脂肪酸及磷酸胆碱构成。人体各组织细胞内质网均存在合成鞘氨醇酶系，以脑组织活性最高。合成鞘氨醇的基本原料是软脂酰 $\mathrm{CoA}$、丝氨酸和胆碱，还需磷酸吡哆醛、$\mathrm{NADPH}$ 及 $\mathrm{FAD}$ 等辅酶参加。

:::definition{label="神经鞘磷脂"}
神经鞘磷脂（sphingomyelin）是人体含量最多的鞘磷脂，由鞘氨醇、脂肪酸及磷酸胆碱构成。
:::

:::definition{label="鞘氨醇合成的原料与辅酶"}
基本原料是软脂酰 $\mathrm{CoA}$、丝氨酸和胆碱。辅酶：磷酸吡哆醛、$\mathrm{NADPH}$ 及 $\mathrm{FAD}$。酶系在各组织内质网，脑组织活性最高。
:::

在磷酸吡哆醛参与下，由内质网 $3$-酮二氢鞘氨醇合成酶催化，软脂酰 $\mathrm{CoA}$ 与 $\mathrm{L}$-丝氨酸缩合并脱羧生成 $3$-酮基二氢鞘氨醇（$3$-ketodihydrosphingosine），再由 $\mathrm{NADPH}$ 供氢、还原酶催化，加氢生成二氢鞘氨醇，然后在脱氢酶催化下，脱氢生成鞘氨醇。

:::timeline{period="鞘氨醇的合成"}
- **缩合脱羧** 磷酸吡哆醛参与；3-酮二氢鞘氨醇合成酶催化软脂酰 CoA 与 L-丝氨酸缩合并脱羧，生成 3-酮基二氢鞘氨醇
- **还原** NADPH 供氢，生成二氢鞘氨醇
- **脱氢** 脱氢酶（FAD）生成鞘氨醇
:::

:::definition{label="3-酮基二氢鞘氨醇"}
$3$-酮基二氢鞘氨醇（$3$-ketodihydrosphingosine）是软脂酰 $\mathrm{CoA}$ 与 $\mathrm{L}$-丝氨酸在磷酸吡哆醛参与下缩合并脱羧的产物，是写出鞘氨醇之前的第一张中间物。
:::

在脂肪酰转移酶催化下，鞘氨醇的氨基与脂肪酰 $\mathrm{CoA}$ 进行酰胺缩合，生成 $N$-脂肪酰鞘氨醇，最后由 $\mathrm{CDP}$-胆碱提供磷酸胆碱生成神经鞘磷脂。神经鞘磷脂的骨架因此不是甘油三酯那样的三根酯键，而是：鞘氨醇长链、$N$-脂肪酰酰胺键，以及 $1$ 位羟基上的磷酸胆碱。

:::definition{label="N-脂肪酰鞘氨醇"}
鞘氨醇的氨基与脂肪酰 $\mathrm{CoA}$ 酰胺缩合，生成 $N$-脂肪酰鞘氨醇（神经酰胺）。$\mathrm{CDP}$-胆碱再提供磷酸胆碱，即得神经鞘磷脂。
:::

:::compare{title="甘油磷脂与神经鞘磷脂：骨架和键型"}
| 项目 | 甘油磷脂 | 神经鞘磷脂 |
|------|----------|------------|
| 长链疏水尾 | 甘油 $1$、$2$ 位两根脂肪酰酯键 | 鞘氨醇自身长链 $+$ $N$-脂肪酰酰胺键 |
| 极性头 | 磷酸 $+$ 胆碱／乙醇胺／丝氨酸／肌醇等 | 磷酸胆碱 |
| 头基发票 | $\mathrm{CDP}$-胆碱、$\mathrm{CDP}$-乙醇胺或 $\mathrm{CDP}$-甘油二酯 | $\mathrm{CDP}$-胆碱 |
| 中间枢纽 | 磷脂酸 | 鞘氨醇 → $N$-脂肪酰鞘氨醇 |
:::

:::pitfall{label="神经鞘磷脂不是“甘油上接了鞘氨醇”"}
骨架已经换成鞘氨醇，脂肪酸以酰胺键接到氨基上，不是再酯化一根甘油。把鞘磷脂听成甘油磷脂的一个亚类，后面鞘磷脂酶切出 $N$-脂肪酰鞘氨醇这一笔会对不上。
:::

:::insight{label="胆碱在两本账里都出现，职分不同"}
甘油磷脂：胆碱可以吃进来，也可以由丝氨酸经乙醇胺甲基化生成，再写成 $\mathrm{CDP}$-胆碱接甘油二酯。神经鞘磷脂：原料名单同样有胆碱，最后仍由 $\mathrm{CDP}$-胆碱把磷酸胆碱交给 $N$-脂肪酰鞘氨醇。相同的头基发票，骨架不是同一张。
:::

:::keypoint{label="神经鞘磷脂合成四步收口"}
- 软脂酰 $\mathrm{CoA}$ $+$ $\mathrm{L}$-丝氨酸 → $3$-酮基二氢鞘氨醇（磷酸吡哆醛，脱羧）。
- $\mathrm{NADPH}$ 还原 → 二氢鞘氨醇。
- $\mathrm{FAD}$ 脱氢 → 鞘氨醇。
- 酰胺缩合得 $N$-脂肪酰鞘氨醇，再接 $\mathrm{CDP}$-胆碱 → 神经鞘磷脂。
:::

## 四、神经鞘磷脂由鞘磷脂酶催化降解

鞘磷脂酶（sphingomyelinase）存在于脑、肝、脾、肾等组织细胞溶酶体，属磷脂酶 $\mathrm{C}$ 类，能使磷酸酯键水解，产生磷酸胆碱及 $N$-脂肪酰鞘氨醇。如先天性缺乏此酶，则鞘磷脂不能降解，在细胞内积存，引起肝、脾大及痴呆等鞘磷脂沉积病状。

:::definition{label="鞘磷脂酶"}
鞘磷脂酶（sphingomyelinase）存在于脑、肝、脾、肾等组织细胞溶酶体，属磷脂酶 $\mathrm{C}$ 类，水解神经鞘磷脂的磷酸酯键，产生磷酸胆碱及 $N$-脂肪酰鞘氨醇。
:::

:::compare{title="甘油磷脂酶 C 与鞘磷脂酶"}
| 项目 | 磷脂酶 $\mathrm{C}$（甘油磷脂） | 鞘磷脂酶 |
|------|------------------------------|----------|
| 底物 | 甘油磷脂 | 神经鞘磷脂 |
| 所切键 | 甘油与磷酸之间的磷酸酯键 | 鞘氨醇 $1$ 位羟基与磷酸胆碱之间的磷酸酯键 |
| 产物 | 甘油二酯 $+$ 磷酸头基 | $N$-脂肪酰鞘氨醇 $+$ 磷酸胆碱 |
| 部位 | 教材按酯键分类，不限定溶酶体 | 溶酶体 |
:::

:::cause-effect{title="先天性鞘磷脂酶缺乏"}
溶酶体缺乏鞘磷脂酶 → 神经鞘磷脂不能降解、细胞内积存 → 肝、脾大及痴呆等鞘磷脂沉积病状。
:::

:::pitfall{label="鞘磷脂酶属磷脂酶 C 类，不是磷脂酶 A"}
它切的是磷酸酯键，产物是磷酸胆碱和 $N$-脂肪酰鞘氨醇，不是溶血磷脂。不要把鞘磷脂沉积写成“溶血磷脂堆积”。肝、脾大和痴呆是鞘磷脂本身积存在溶酶体里。
:::

:::memory{label="本节必背要点"}
- [ ] 甘油磷脂以磷脂酸为枢纽；鞘磷脂以鞘氨醇为枢纽。
- [ ] 原料：甘油、脂肪酸多来自糖；甘油 $2$ 位多不饱和脂肪酸是必需脂肪酸，来自植物油。
- [ ] 胆碱可食物供给，也可丝氨酸脱羧得乙醇胺，再由 $S$-腺苷甲硫氨酸给 $3$ 个甲基。
- [ ] $\mathrm{ATP}$ 供能，$\mathrm{CTP}$ 写 $\mathrm{CDP}$-乙醇胺、$\mathrm{CDP}$-胆碱、$\mathrm{CDP}$-甘油二酯。
- [ ] 甘油二酯途径：$\mathrm{PC}$、$\mathrm{PE}$，占组织及血液磷脂 $75\%$ 以上。
- [ ] 人 $\mathrm{PC}$ 主路是 $\mathrm{CDP}$-胆碱途径，关键酶 $\mathrm{CCT}$；$\mathrm{PE}$ 甲基化只占 $10\%\sim 15\%$。
- [ ] $\mathrm{CCT}\alpha/\beta 1/\beta 2$ 残基数 $367$、$330$、$372$；游离无活性，贴膜才有活性。
- [ ] $\mathrm{PC}$ 缺乏促进 $\mathrm{CCT}$ 贴膜，加速 $\mathrm{PC}$ 合成。
- [ ] $\mathrm{CDP}$-甘油二酯途径：磷脂酰肌醇、丝氨酸磷脂、心磷脂；肌醇、丝氨酸无须活化。
- [ ] 合成在内质网膜外侧；磷脂交换蛋白把产物转到其他细胞器；心磷脂是线粒体内膜特征磷脂。
- [ ] 二软脂酰胆碱降低肺泡表面张力；新生儿合成障碍 → 肺不张。
- [ ] 磷脂酶 $\mathrm{A}_{1}/\mathrm{A}_{2}$ 切脂肪酰；$\mathrm{C}$ 切甘油－磷酸；$\mathrm{D}$ 切磷酸－$\mathrm{X}$。
- [ ] 溶血磷脂 $1$ 溶血；磷脂酶 $\mathrm{B}_{1}$ 切掉剩余脂肪酰后毒性消失。
- [ ] 神经鞘磷脂 $=$ 鞘氨醇 $+$ 脂肪酸 $+$ 磷酸胆碱；脑内质网活性最高。
- [ ] 鞘磷脂酶属磷脂酶 $\mathrm{C}$ 类，溶酶体；缺乏 → 鞘磷脂沉积（肝、脾大及痴呆）。
