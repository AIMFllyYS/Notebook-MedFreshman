# 第三节　氧化磷酸化与ATP的生成

第二节把两条呼吸链和细胞质 $\mathrm{NADH}$ 的穿梭写完：线粒体 $\mathrm{NADH}$ 走复合体Ⅰ入口，$\mathrm{P/O}$ 约 $2.5$；琥珀酸／$\mathrm{FADH}_2$ 走复合体Ⅱ入口，$\mathrm{P/O}$ 约 $1.5$。本节把这对电子的氧化和 $\mathrm{ADP}$ 的磷酸化钉在同一条线上：化学渗透把释能写成跨内膜质子电化学梯度，$\mathrm{ATP}$ 合酶的 $\mathrm{F}_\mathrm{o}/\mathrm{F}_1$ 把回流的质子写成 $\mathrm{ATP}$。本版合成 $1$ 分子 $\mathrm{ATP}$ 按 $4$ 个 $\mathrm{H}^{+}$ 计（$3$ 个走合酶、$1$ 个走腺苷酸／磷酸盐转运），不要默写旧口诀 $3$ 和 $2$。

:::concept{term="先问电子把质子泵到哪一侧，再问质子从哪回流写成 ATP"}
氧化磷酸化不是“呼吸链某个复合体直接把磷酸接到 $\mathrm{ADP}$ 上”。复合体Ⅰ、Ⅲ、Ⅳ是偶联部位，意思是传递一对电子释放的能量够供磷酸化，真正做 $\mathrm{ATP}$ 的是复合体Ⅴ（$\mathrm{ATP}$ 合酶）。质子从基质泵到膜间隙，再经 $\mathrm{F}_\mathrm{o}$ 回流驱动 $\mathrm{F}_1$ 的结合变构。
:::

细胞内 $\mathrm{ADP}$ 磷酸化生成 $\mathrm{ATP}$ 的方式主要有两种。底物水平磷酸化（见第七章）只产生少量 $\mathrm{ATP}$；人体 $90\%$ 的 $\mathrm{ATP}$ 由线粒体氧化体系产生，即 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 通过线粒体呼吸链逐步失去电子被氧化生成水，电子传递过程伴随着能量的逐步释放，此释能过程驱动 $\mathrm{ADP}$ 磷酸化生成大量 $\mathrm{ATP}$。因此 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的氧化与 $\mathrm{ADP}$ 的磷酸化相偶联、产生 $\mathrm{ATP}$ 的过程，称之为氧化磷酸化（oxidative phosphorylation）。

:::definition{label="氧化磷酸化"}
氧化磷酸化（oxidative phosphorylation）是 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的氧化与 $\mathrm{ADP}$ 的磷酸化相偶联、产生 $\mathrm{ATP}$ 的过程。电子经呼吸链传给氧生成水，释能驱动 $\mathrm{ADP}$ 磷酸化。
:::

:::compare{title="两种磷酸化"}
| 方式 | 场所与机制 | 产额印象 |
|------|------------|----------|
| 底物水平磷酸化 | 糖酵解、三羧酸循环等，底物高能磷酸基团直接转给 $\mathrm{ADP}$ | 少量（见第七章） |
| 氧化磷酸化 | 线粒体；呼吸链氧化 $\mathrm{NADH}/\mathrm{FADH}_2$ 偶联 $\mathrm{ADP}$ 磷酸化 | 人体约 $90\%$ 的 $\mathrm{ATP}$ |
:::

:::pitfall{label="氧化磷酸化不是底物水平磷酸化的别名"}
第七章的 $1,3$-二磷酸甘油酸、磷酸烯醇式丙酮酸、琥珀酰 $\mathrm{CoA}$ 是底物水平户头。本节的户头是呼吸链电子传递＋质子回流＋$\mathrm{ATP}$ 合酶。把“线粒体里生成的 $\mathrm{ATP}$”一律写成底物水平，会把化学渗透整节掏空。
:::

## 一、氧化磷酸化是电子传递和形成 ATP 的偶联过程

氧化磷酸化在线粒体中进行，包含两个关键过程：一是氧化过程，二是磷酸化过程。氧化过程如何产生能量、磷酸化过程如何获取能量产生 $\mathrm{ATP}$，是本节讨论的主要内容。

### （一）还原当量的氧化与 ADP 磷酸化的偶联是重要的产能过程

物质代谢产生不同的还原当量，都可参与氧化还原反应，但各自行使不同的功能。线粒体三羧酸循环产生大量的还原当量 $\mathrm{NADH}$、$\mathrm{FADH}_2$，易被呼吸链复合体结合，成为呼吸链的还原性底物。此过程中电子的依次传递最终与氧原子结合，而 $\mathrm{H}^{+}$ 依赖复合体从线粒体基质排向膜间隙，以及与氧结合生成水。即电子的氧化过程改变了 $\mathrm{H}^{+}$ 的分布，导致内膜两侧的 $\mathrm{H}^{+}$ 浓度和电荷的差异，储存了电子传递过程释放的能量。因此 $\mathrm{NADH}$、$\mathrm{FADH}_2$ 是呼吸链重要的递电子体和递氢体，是产能的关键所在。

$\mathrm{ADP}$ 的磷酸化需要供能且需要酶催化生成 $\mathrm{ATP}$，还原当量氧化释放的能量可用于驱动此过程，所以氧化磷酸化是依赖电子传递的 $\mathrm{ADP}$ 磷酸化过程。

:::definition{label="还原当量在本节的角色"}
三羧酸循环产生的 $\mathrm{NADH}$、$\mathrm{FADH}_2$ 是呼吸链的还原性底物。电子传给氧、质子被泵到膜间隙，内膜两侧出现浓度差和电位差，把电子传递释放的能量先存成质子电化学梯度，再交给磷酸化。
:::

:::insight{label="先改质子分布，再谈 ATP"}
氧化侧做的事不是“当场把 $\mathrm{ADP}$ 变成 $\mathrm{ATP}$”，而是把 $\mathrm{H}^{+}$ 从基质赶到膜间隙。磷酸化侧要等这些质子顺梯度回流。把两步听成一步，第四节的解偶联剂就没有落点：电子还在传，质子却抄近道回来了。
:::

:::keypoint{label="氧化侧和磷酸化侧各管什么"}
- 氧化：$\mathrm{NADH}/\mathrm{FADH}_2$ 的电子经呼吸链到 $\mathrm{O}_2$，生成 $\mathrm{H}_2\mathrm{O}$。
- 质子：复合体Ⅰ、Ⅲ、Ⅳ把 $\mathrm{H}^{+}$ 从基质泵到膜间隙。
- 磷酸化：质子回流驱动 $\mathrm{ATP}$ 合酶，使 $\mathrm{ADP}+\mathrm{P}_\mathrm{i}\rightarrow\mathrm{ATP}$。
:::

### （二）氧化磷酸化的偶联部位位于复合体Ⅰ、Ⅲ、Ⅳ

成对电子经呼吸链传递所能合成 $\mathrm{ATP}$ 的分子数可反映该过程的效率。理论推测，将呼吸链中能产生足够的能量使 $\mathrm{ADP}$ 磷酸化的部位称之为氧化与磷酸化的偶联部位，也就是能够生成 $\mathrm{ATP}$ 的部位。根据实验分析及计算，已大致确定电子经呼吸链复合体Ⅰ、Ⅲ、Ⅳ氧化时释放的能量可满足 $\mathrm{ADP}$ 磷酸化所需的能量。

:::definition{label="偶联部位"}
氧化与磷酸化的偶联部位，指呼吸链中能产生足够能量使 $\mathrm{ADP}$ 磷酸化的部位。本版确定为复合体Ⅰ、Ⅲ、Ⅳ。偶联部位并不等于这三个复合体直接合成 $\mathrm{ATP}$，而是指其传递一对电子释放的能量能够满足磷酸化的需要。
:::

:::pitfall{label="偶联部位不是 ATP 合酶，也不是复合体Ⅱ"}
复合体Ⅰ、Ⅲ、Ⅳ泵质子、释能；真正合成 $\mathrm{ATP}$ 的是复合体Ⅴ。复合体Ⅱ把琥珀酸的电子交给 $\mathrm{Q}$，不泵质子，不是偶联部位。把“能生成 $\mathrm{ATP}$ 的部位”写成 $\mathrm{ATP}$ 合酶，和教材“偶联部位”的定义对不上；把复合体Ⅱ算进去，$\mathrm{P/O}$ $1.5$ 那一笔就没有差口。
:::

**1. 根据 P/O 比值确定氧化磷酸化偶联部位**　一对电子通过氧化呼吸链传递给 $1$ 个氧原子生成 $1$ 分子 $\mathrm{H}_2\mathrm{O}$，其释放的能量使 $\mathrm{ADP}$ 磷酸化合成 $\mathrm{ATP}$，此过程需要消耗氧和磷酸。

:::definition{label="P/O 比值"}
$\mathrm{P/O}$ 比值（phosphate/oxygen ratio）是指氧化磷酸化过程中，每消耗 $1/2$ 摩尔 $\mathrm{O}_2$ 所需磷酸的摩尔数，即所能合成 $\mathrm{ATP}$ 的摩尔数，或一对电子通过呼吸链传递给氧所生成 $\mathrm{ATP}$ 的分子数。
:::

实验证明，丙酮酸等底物脱氢反应产生 $\mathrm{NADH}+\mathrm{H}^{+}$，通过 $\mathrm{NADH}$ 呼吸链传递，$\mathrm{P/O}$ 比值接近 $2.5$，说明一对电子传递给 $1$ 个氧原子需消耗约 $2.5$ 分子的磷酸，因此 $\mathrm{NADH}$ 呼吸链可能存在 $3$ 个 $\mathrm{ATP}$ 生成部位。而琥珀酸脱氢时，$\mathrm{P/O}$ 比值接近 $1.5$，说明琥珀酸呼吸链可能存在 $2$ 个 $\mathrm{ATP}$ 生成部位。根据 $\mathrm{NADH}$、琥珀酸呼吸链 $\mathrm{P/O}$ 比值的差异，提示在 $\mathrm{NADH}$ 和泛醌之间（复合体Ⅰ）存在 $1$ 个 $\mathrm{ATP}$ 生成部位。抗坏血酸底物可以直接通过 $\mathrm{Cyt}\ c$ 传递电子进行氧化，其 $\mathrm{P/O}$ 比值接近 $1$，推测 $\mathrm{Cyt}\ c$ 和 $\mathrm{O}_2$ 之间（复合体Ⅳ）存在 $1$ 个 $\mathrm{ATP}$ 生成部位。由此推测另 $1$ 个 $\mathrm{ATP}$ 生成部位应在 $\mathrm{Q}$ 和 $\mathrm{Cyt}\ c$ 之间（复合体Ⅲ）。

所以，复合体Ⅰ、Ⅲ、Ⅳ可能是氧化磷酸化的偶联部位、用于产生 $\mathrm{ATP}$。一对电子经 $\mathrm{NADH}$ 呼吸链传递，$\mathrm{P/O}$ 比值约为 $2.5$，生成 $2.5$ 分子的 $\mathrm{ATP}$；一对电子经琥珀酸呼吸链传递，$\mathrm{P/O}$ 比值约为 $1.5$，可产生 $1.5$ 分子的 $\mathrm{ATP}$。

:::compare{title="用 P/O 把三个偶联部位钉死"}
| 底物／入口 | 电子路径 | $\mathrm{P/O}$ | 提示的偶联部位 |
|------------|----------|---------------|----------------|
| 丙酮酸等 $\rightarrow\mathrm{NADH}$ | $\mathrm{NADH}$ 呼吸链（经复合体Ⅰ） | 接近 $2.5$ | 可能 $3$ 个 $\mathrm{ATP}$ 生成部位 |
| 琥珀酸 $\rightarrow\mathrm{FADH}_2$ | 琥珀酸呼吸链（经复合体Ⅱ入 $\mathrm{Q}$） | 接近 $1.5$ | 可能 $2$ 个部位；与上相差在复合体Ⅰ |
| 抗坏血酸 $\rightarrow\mathrm{Cyt}\ c$ | 不经复合体Ⅰ、Ⅲ，直接经 $\mathrm{Cyt}\ c$ | 接近 $1$ | $\mathrm{Cyt}\ c$ 与 $\mathrm{O}_2$ 之间＝复合体Ⅳ |
| 差值定位 | $\mathrm{NADH}$ 与 $\mathrm{Q}$ 之间 | — | 复合体Ⅰ |
| 差值定位 | $\mathrm{Q}$ 与 $\mathrm{Cyt}\ c$ 之间 | — | 复合体Ⅲ |
:::

:::derivation{title="本版 P/O 是 2.5 和 1.5"}
1. $\mathrm{NADH}$ 呼吸链：一对电子到 $1$ 个氧原子，$\mathrm{P/O}\approx 2.5$，生成约 $2.5$ 分子 $\mathrm{ATP}$。
2. 琥珀酸呼吸链：$\mathrm{P/O}\approx 1.5$，生成约 $1.5$ 分子 $\mathrm{ATP}$。
3. 差 $1$ 个部位在复合体Ⅰ（$\mathrm{NADH}\rightarrow\mathrm{Q}$）。
4. 抗坏血酸经 $\mathrm{Cyt}\ c$，$\mathrm{P/O}\approx 1$，钉住复合体Ⅳ。
5. 剩下的 $1$ 个部位在复合体Ⅲ（$\mathrm{Q}\rightarrow\mathrm{Cyt}\ c$）。
:::

:::pitfall{label="本版不要默写 P/O＝3 和 2"}
旧口诀把 $\mathrm{NADH}$ 写成 $3\,\mathrm{ATP}$、$\mathrm{FADH}_2$ 写成 $2\,\mathrm{ATP}$。第七章有氧氧化已经按 $2.5$／$1.5$ 把葡萄糖净得写成 $30$ 或 $32$，第八章软脂酸净 $106$ 也用同一套。本节实验值写的是“接近 $2.5$”“接近 $1.5$”。后面质子账 $10/4=2.5$、$6/4=1.5$，和这套数咬合。
:::

**2. 根据自由能变化确定偶联部位**　从电子传递数目、氧化还原电位与自由能变化的计算公式已经看出，电子由低电位向高电位传递过程中，氧化还原电位的变化将转变为自由能释放出来。从 $\mathrm{NAD}^{+}$ 到 $\mathrm{Q}$ 之间测得的还原电位差约 $0.36\,\mathrm{V}$，从 $\mathrm{Q}$ 到 $\mathrm{Cyt}\ c$ 电位差为 $0.19\,\mathrm{V}$，从 $\mathrm{Cyt}\ a$、$a_3$ 到分子氧为 $0.58\,\mathrm{V}$，分别对应复合体Ⅰ、Ⅲ、Ⅳ的电子传递。计算结果，它们相应释放的 $\Delta G^{\prime\circ}$ 分别约为 $69.5$、$36.7$、$112\,\mathrm{kJ/mol}$，而生成 $1$ 分子 $\mathrm{ATP}$ 大约需要 $30.5\,\mathrm{kJ}$，可见复合体Ⅰ、Ⅲ、Ⅳ传递一对电子释放的能量能够满足生成 $\mathrm{ATP}$ 所需的能量。

需要指出的是，偶联部位并非意味着这三个复合体是直接产生 $\mathrm{ATP}$ 的部位，而是指电子传递释放的能量，能满足 $\mathrm{ADP}$ 磷酸化生成 $\mathrm{ATP}$ 的需要。

:::compare{title="三段电位差与自由能"}
| 区段 | 对应复合体 | 还原电位差 | $\Delta G^{\prime\circ}$（约） | 能否覆盖 $30.5\,\mathrm{kJ/mol}$ |
|------|------------|------------|------------------------------|----------------------------------|
| $\mathrm{NAD}^{+}\rightarrow\mathrm{Q}$ | Ⅰ | 约 $0.36\,\mathrm{V}$ | $69.5\,\mathrm{kJ/mol}$ | 能 |
| $\mathrm{Q}\rightarrow\mathrm{Cyt}\ c$ | Ⅲ | $0.19\,\mathrm{V}$ | $36.7\,\mathrm{kJ/mol}$ | 能 |
| $\mathrm{Cyt}\ a$、$a_3\rightarrow\mathrm{O}_2$ | Ⅳ | $0.58\,\mathrm{V}$ | $112\,\mathrm{kJ/mol}$ | 能 |
:::

:::insight{label="复合体Ⅲ的 36.7 kJ 刚刚够"}
三段都能覆盖 $30.5\,\mathrm{kJ}$，但复合体Ⅲ最紧。这解释了为什么偶联部位要靠实验和计算“大致确定”，而不是三个复合体各“直接做出一分子 $\mathrm{ATP}$”。真正的化学计量在后面：泵出的质子数除以每分子 $\mathrm{ATP}$ 所需的 $4$ 个 $\mathrm{H}^{+}$。
:::

:::note{label="与第一节公式同一套"}
第一节已写 $\Delta G^{\prime\circ}=-nF\Delta E^{\circ}$。本节三段电位差就是把那条公式落到复合体Ⅰ、Ⅲ、Ⅳ上。$n$、$F$ 的数值不必另记一版，认这三组教材给出的 $\Delta G^{\prime\circ}$ 即可。
:::

## 二、氧化磷酸化依赖线粒体内膜两侧的质子梯度

英国科学家 Mitchell P 提出的化学渗透假说（chemiosmotic hypothesis）阐明了氧化磷酸化的偶联机制。其基本要点是：①电子经呼吸链传递时释放的能量，通过复合体的质子泵功能，转运 $\mathrm{H}^{+}$ 从线粒体基质到内膜的胞质侧；②由于质子不能自由穿过线粒体内膜返回基质，从而形成跨线粒体内膜的质子电化学梯度（$\mathrm{H}^{+}$ 浓度梯度和电位差），储存电子传递释放的能量；③质子的电化学梯度转变为驱动力，促使质子从膜间隙侧顺浓度梯度回流至基质、释放储存的势能，用于驱动 $\mathrm{ADP}$ 与 $\mathrm{P}_\mathrm{i}$ 结合生成 $\mathrm{ATP}$。图10-15 归纳了呼吸链电子传递和质子回流的过程。

:::definition{label="化学渗透假说"}
化学渗透假说（chemiosmotic hypothesis）认为：呼吸链释能把 $\mathrm{H}^{+}$ 从基质泵到内膜胞质侧；内膜对质子不通透，形成跨膜质子电化学梯度（浓度梯度＋电位差）；质子顺梯度经 $\mathrm{ATP}$ 合酶回流至基质，释放势能驱动 $\mathrm{ADP}+\mathrm{P}_\mathrm{i}\rightarrow\mathrm{ATP}$。
:::

::figure{src="/images/biochemistry/textbook/p0237_01.png" caption="图10-15　化学渗透假说示意图及各种抑制剂对电子传递链的影响。内膜基质侧：NADH 经复合体Ⅰ（NADH-泛醌还原酶）把电子交给 Q；琥珀酸经复合体Ⅱ（琥珀酸-泛醌还原酶）把电子交给 Q。QH2 经复合体Ⅲ（泛醌-细胞色素 C 还原酶）把电子交给 Cyt c，再经复合体Ⅳ（细胞色素 C 氧化酶）把 1/2 O2＋2H⁺ 写成 H2O。复合体Ⅰ、Ⅲ、Ⅳ把质子泵向胞质侧形成质子梯度，梯度驱动 ATP 合酶。抑制剂：鱼藤酮、粉蝶霉素 A、异戊巴比妥阻断复合体Ⅰ；萎锈灵、噻吩甲酰三氟丙酮阻断复合体Ⅱ；抗霉素 A 阻断复合体Ⅲ；CN⁻、N3⁻、CO 阻断复合体Ⅳ；寡霉素、DCCD 阻断 ATP 合酶；解偶联剂 2,4-二硝基苯酚使质子抄近道回流。" alt="线粒体内膜上复合体Ⅰ至Ⅳ与 ATP 合酶，质子泵向胞质侧，并标出各类抑制剂作用位点"}

:::timeline{period="化学渗透三句话"}
- **泵出** 电子传递释能，复合体质子泵把 H+ 从基质转到内膜胞质侧
- **储存** 质子不能自由穿内膜，形成浓度梯度和电位差
- **回流** 质子从膜间隙顺梯度回基质，势能驱动 ADP 与 Pi 生成 ATP
:::

化学渗透假说已得到广泛的实验支持：包括氧化磷酸化需依赖于完整封闭的线粒体内膜；线粒体内膜对 $\mathrm{H}^{+}$、$\mathrm{OH}^{-}$、$\mathrm{K}^{+}$、$\mathrm{Cl}^{-}$ 是不通透的；电子传递链可驱动并形成能够测定的跨内膜电化学梯度；降低膜间隙侧的质子浓度，能使 $\mathrm{ATP}$ 的生成减少等。

:::keypoint{label="支持化学渗透的实验印象"}
- 需要完整封闭的线粒体内膜。
- 内膜对 $\mathrm{H}^{+}$、$\mathrm{OH}^{-}$、$\mathrm{K}^{+}$、$\mathrm{Cl}^{-}$ 不通透。
- 电子传递能形成可测定的跨内膜电化学梯度。
- 降低膜间隙侧质子浓度，$\mathrm{ATP}$ 生成减少。
:::

:::pitfall{label="内膜破了，氧化磷酸化就散架"}
化学渗透把能量存在跨膜梯度里。内膜漏了，质子自己回去，$\mathrm{ATP}$ 合酶没有驱动力。解偶联剂（第四节）就是人为制造这条漏路：电子传递还在，磷酸化停。
:::

这张图既是化学渗透的总图，也是第四节抑制剂的位点图。复合体Ⅰ、Ⅱ、Ⅲ、Ⅳ和 $\mathrm{ATP}$ 合酶、解偶联剂都标在同一张内膜上。第四节会按位点拆开写，不必另记一张“抑制剂地图”。
:::

### （一）呼吸链复合体的质子泵产生跨线粒体内膜的质子梯度

电子传递过程中，能驱动复合体Ⅰ、Ⅲ、Ⅳ将质子从线粒体基质侧泵出至膜间隙侧，质子在膜间隙的浓度逐渐升高。由于线粒体内膜的不通透性，质子不能自由穿过线粒体内膜返回基质，从而形成跨线粒体内膜的质子梯度：一对电子经复合体Ⅰ、Ⅲ、Ⅳ传递分别向膜间隙侧泵出 $4\mathrm{H}^{+}$、$4\mathrm{H}^{+}$ 和 $2\mathrm{H}^{+}$，共 $10$ 个 $\mathrm{H}^{+}$。

由于线粒体内膜的不通透性，复合体的质子泵功能形成内膜两侧的 $\mathrm{H}^{+}$ 浓度和电荷的差异，膜间隙质子的浓度和正电性高于线粒体基质，储存了电子传递过程释放的能量。当质子顺流而下、从高浓度的膜间隙侧回流至基质时可释放能量。

:::definition{label="一对电子泵出的质子数"}
一对电子经复合体Ⅰ、Ⅲ、Ⅳ传递，分别向膜间隙侧泵出 $4\mathrm{H}^{+}$、$4\mathrm{H}^{+}$ 和 $2\mathrm{H}^{+}$，共 $10$ 个 $\mathrm{H}^{+}$。琥珀酸呼吸链不经复合体Ⅰ，每传递 $2$ 个电子泵出 $6$ 个 $\mathrm{H}^{+}$。
:::

:::compare{title="两条呼吸链的泵质子账"}
| 入口 | 经过的质子泵 | 泵出 $\mathrm{H}^{+}$ | 后面除以 $4$ 得到的 $\mathrm{ATP}$ |
|------|--------------|-------------------|-----------------------------------|
| $\mathrm{NADH}$ 呼吸链 | Ⅰ＋Ⅲ＋Ⅳ | $4+4+2=10$ | 约 $2.5$（$10/4$） |
| 琥珀酸／$\mathrm{FADH}_2$ 呼吸链 | Ⅲ＋Ⅳ（不经Ⅰ） | $4+2=6$ | 约 $1.5$（$6/4$） |
:::

:::pitfall{label="复合体Ⅳ泵 2 个 H+，不是 4 个"}
口诀容易把三个偶联部位都写成“各泵 $4\mathrm{H}^{+}$”。本版复合体Ⅳ只泵 $2\mathrm{H}^{+}$。总数 $10$ 不是 $12$，后面 $10/4=2.5$ 才和 $\mathrm{P/O}$ 对齐。
:::

:::insight{label="膜间隙正电性更高"}
泵出去的是 $\mathrm{H}^{+}$，膜间隙浓度高、正电性强，基质相对负。第四节 $\mathrm{ATP}^{4-}$ 往膜间隙泵出、$\mathrm{ADP}^{3-}$ 进来，正好借这张正电性的忙。梯度既是浓度账，也是电荷账。
:::

### （二）跨线粒体内膜的质子顺梯度回流释放能量产生 ATP

**1. 质子顺梯度回流需要跨线粒体内膜的 ATP 合酶转运**　经呼吸链复合体泵至膜间隙的质子不能自由穿过线粒体内膜返回基质，需要通过 $\mathrm{ATP}$ 合酶（$\mathrm{ATP}$ synthase）进行跨膜转运。

:::definition{label="ATP 合酶"}
$\mathrm{ATP}$ 合酶（$\mathrm{ATP}$ synthase）又称复合体Ⅴ（complex Ⅴ），位于线粒体内膜，真核生物常以二聚体发挥作用。蘑菇样多亚基结构，含 $\mathrm{F}_1$（亲水，催化 $\mathrm{ATP}$ 合成）和 $\mathrm{F}_\mathrm{o}$（疏水，对寡霉素敏感，组成质子通道）两个功能结构域。
:::

**（1）ATP 合酶含质子回流和合成 ATP 的结构域**　$\mathrm{F}_1$ 表示第一个被鉴定的与氧化磷酸化相关的因子；$\mathrm{F}_\mathrm{o}$ 的下标为寡霉素（oligomycin）的首字母，表示对寡霉素敏感（oligomycin-sensitive）。$\mathrm{F}_1$ 为线粒体基质侧的蘑菇头状突起，催化 $\mathrm{ATP}$ 合成；而 $\mathrm{F}_\mathrm{o}$ 的大部分结构嵌入线粒体内膜中，组成离子通道，用于质子的回流（图10-16）。

真核细胞中，$\mathrm{ATP}$ 合酶的 $\mathrm{F}_1$ 部分主要由 $\alpha_3\beta_3\gamma\delta\varepsilon$ 亚基（$5$ 个类型、$9$ 个亚基）组成。$3$ 个 $\alpha$、$\beta$ 亚基间隔排列，形成 $\alpha\beta$ 功能单元，像橘子瓣样围绕 $\gamma$ 亚基形成六聚体（图10-16a）。$\mathrm{F}_\mathrm{o}$ 嵌于线粒体内膜中，由疏水的 $ab_2c_{8\sim 17}$ 亚基组成，形成跨内膜的质子通道。$c$ 亚基的数目与物种有关，例如牛的 $\mathrm{F}_\mathrm{o}$ 有 $8$ 个 $c$ 亚基。每个 $c$ 亚基的 $2$ 个反向跨膜 $\alpha$-螺旋通过短环连接，$8\sim 17$ 个 $c$ 亚基围成环状结构（$c$ 亚基环，寡霉素的主要结合位点）；$a$ 亚基紧靠 $c$ 亚基环外侧，含 $5$ 个跨膜 $\alpha$-螺旋，形成 $2$ 个半穿透线粒体内膜的、不连通的亲水质子半通道，两个开口分别位于线粒体的基质侧和膜间隙侧，两个半通道口分别与 $1$ 个 $c$ 亚基对应（图10-16b）。

::figure{src="/images/biochemistry/textbook/p0238_01.png" caption="图10-16　ATP 合酶结构和质子的跨内膜流动机制模式图。（a）Fo-F1 复合体组成可旋转的发动机样结构。基质侧蘑菇头为 F1：α、β 亚基间隔排列，δ 亚基在顶部，γ、ε 伸入 Fo；两条 b 亚基长臂从内膜连到 F1。内膜中 Fo 含 a 亚基和一圈 c 亚基。F1 的 α3、β3 和 δ 以及 Fo 的 a、b2 组成定子；F1 的 γ、ε 及 Fo 的 c 亚基环组成转子。（b）Fo 的 a 亚基有 2 个质子半通道，分别开口于内膜两侧：细胞质侧半通道让 H+ 进入 c 亚基，基质侧半通道让 H+ 排入基质；c 亚基环携带质子转动。" alt="ATP 合酶蘑菇样 Fo-F1 结构及 a 亚基两个质子半通道带动 c 环旋转"}

:::definition{label="F1"}
$\mathrm{F}_1$ 是 $\mathrm{ATP}$ 合酶的亲水部分，位于线粒体基质侧，呈蘑菇头状突起，催化 $\mathrm{ATP}$ 合成。真核生物由 $\alpha_3\beta_3\gamma\delta\varepsilon$ 组成（$5$ 个类型、$9$ 个亚基）。$3$ 个 $\alpha$、$3$ 个 $\beta$ 间隔排列，像橘子瓣围绕 $\gamma$ 形成六聚体。
:::

:::definition{label="Fo"}
$\mathrm{F}_\mathrm{o}$ 是 $\mathrm{ATP}$ 合酶的疏水部分，大部分嵌入线粒体内膜，对寡霉素敏感。由 $ab_2c_{8\sim 17}$ 组成跨内膜质子通道。$c$ 亚基环是寡霉素的主要结合位点；牛的 $\mathrm{F}_\mathrm{o}$ 有 $8$ 个 $c$ 亚基。$a$ 亚基含 $5$ 个跨膜 $\alpha$-螺旋，形成开口分别朝向基质侧和膜间隙侧的两条不连通亲水半通道。
:::

:::compare{title="定子和转子"}
| 部分 | 亚基 | 功能印象 |
|------|------|----------|
| 定子 | $\mathrm{F}_1$ 的 $\alpha_3\beta_3$、$\delta$；$\mathrm{F}_\mathrm{o}$ 的 $a$、$b_2$ | $b_2$ 长亲水端锚定 $\mathrm{F}_1$ 的 $\alpha$，经 $\delta$ 与 $\alpha_3\beta_3$ 稳固结合；$b$ 的疏水端与 $a$ 结合 |
| 转子 | $\mathrm{F}_1$ 的 $\gamma$、$\varepsilon$；$\mathrm{F}_\mathrm{o}$ 的 $c$ 亚基环 | $\gamma$、$\varepsilon$ 成中心轴，上端穿过 $\alpha_3\beta_3$，下端与 $c$ 环紧密结合 |
:::

:::pitfall{label="Fo 的 o 是寡霉素，不是数字 0，也不是氧化"}
$\mathrm{F}_\mathrm{o}$ 读 oligomycin-sensitive。写成 $\mathrm{F}_0$ 或“氧化部分”，和教材下标对不上。寡霉素结合 $c$ 亚基环，第四节还要靠这一笔解释“合酶抑制剂为什么连电子传递也慢下来”。
:::

:::note{label="c 亚基数随物种变"}
教材写 $c_{8\sim 17}$，并点名牛有 $8$ 个 $c$ 亚基。考试认“$8\sim 17$，牛 $8$”即可，不要另记某一物种的环大小当人体唯一答案。
:::

**（2）ATP 合酶的 Fo 转运质子回流至线粒体基质**　质子梯度的强大势能驱动 $\mathrm{H}^{+}$ 从 $\mathrm{F}_\mathrm{o}$ 的 $a$ 亚基膜间隙侧半通道口进入（与 $a$ 亚基的 $\mathrm{His}$ 结合），并将 $\mathrm{H}^{+}$ 转送给位于通道口的 $c$ 亚基。此 $c$ 亚基特定的 $\mathrm{Glu}$ 残基（位于跨膜片段的中部，有的物种采用 $\mathrm{Asp}$）接受 $\mathrm{H}^{+}$ 后，所带负电荷被中和、发生构象变化，启动 $c$ 亚基环发生转动，同时此 $c$ 亚基能与疏水内膜相互接触并随 $c$ 亚基环一起转动。

当 $c$ 亚基环转到能接触 $a$ 亚基的另一半通道口时（线粒体基质侧），基质侧相对较低的 $\mathrm{H}^{+}$ 浓度有利于 $\mathrm{H}^{+}$ 从 $\mathrm{Glu}$ 释放并从半通道出口进入线粒体基质。失去 $\mathrm{H}^{+}$ 的 $\mathrm{Glu}$ 与 $a$ 亚基的 $\mathrm{Arg}$ 通过离子键的作用而暂停转动，当 $\mathrm{Glu}$ 再被质子化时重新进入转动循环（图10-16）。

因此质子梯度是驱动其回流的驱动力，而 $\mathrm{F}_\mathrm{o}$ 中 $a$ 亚基的作用是引导质子顺浓度梯度从膜间隙侧进入并结合到 $c$ 亚基上，促使 $c$ 亚基环旋转到 $a$ 亚基的另一半通道口，将质子排入线粒体基质。

:::timeline{period="Fo 让质子回流并转动 c 环"}
- **进入** H+ 从 a 亚基膜间隙侧半通道进入，与 a 的 His 结合，交给通道口的 c 亚基
- **中和** c 亚基中部的 Glu（有的物种是 Asp）接受 H+，负电荷被中和，构象变，c 环转动
- **排出** 转到基质侧半通道口，低 H+ 浓度使 Glu 放掉质子，质子进入基质
- **暂停** 去质子的 Glu 与 a 亚基 Arg 成离子键，暂停；再次质子化后继续转
:::

:::definition{label="a 亚基的两条半通道"}
$a$ 亚基形成两条不连通的亲水质子半通道：膜间隙侧开口让 $\mathrm{H}^{+}$ 进入并交给 $c$ 亚基；基质侧开口让 $\mathrm{H}^{+}$ 排入基质。两条半通道口各对应 $1$ 个 $c$ 亚基。$a$ 亚基引导质子，不自己把内膜打穿成一条直通道。
:::

:::insight{label="c 环是转子的膜内部分"}
质子化让 $c$ 亚基能贴疏水内膜一起转；去质子后靠 $\mathrm{Arg}$ 刹一下车。第四节寡霉素、$\mathrm{DCCD}$ 卡的就是这条回流通道，$c$ 环转不了，$\mathrm{F}_1$ 也合成不了 $\mathrm{ATP}$。
:::

**2. 质子回流驱动 ATP 合酶催化 ADP 的磷酸化**　$\mathrm{ATP}$ 的合成是酶催化的耗能过程。一对电子自 $\mathrm{NADH}$ 传递至氧可释放约 $220\,\mathrm{kJ/mol}$ 的能量，同时将 $10$ 个 $\mathrm{H}^{+}$ 从基质转移至膜间隙侧，形成的 $\mathrm{H}^{+}$ 梯度储存约 $200\,\mathrm{kJ/mol}$。当质子顺浓度梯度回流至基质时释放储存的势能，$\mathrm{ATP}$ 合酶则利用这些能量催化 $\mathrm{ADP}$ 与 $\mathrm{P}_\mathrm{i}$ 生成 $\mathrm{ATP}$。

:::keypoint{label="一对 NADH 电子的能量账"}
- 传到氧：约释放 $220\,\mathrm{kJ/mol}$。
- 泵出 $10\mathrm{H}^{+}$：梯度约储存 $200\,\mathrm{kJ/mol}$。
- 回流：势能交给 $\mathrm{ATP}$ 合酶。
:::

**（1）质子回流促使 ATP 合酶的构象发生动态变化**　目前认为，$\mathrm{ATP}$ 合酶的 $\mathrm{F}_\mathrm{o}$ 和 $\mathrm{F}_1$ 组装成可旋转的发动机样结构（图10-16），完成质子回流并驱动 $\mathrm{ATP}$ 合成。$\mathrm{F}_\mathrm{o}$ 起支撑作用的 $2$ 个 $b$ 亚基通过长的亲水端锚定 $\mathrm{F}_1$ 的 $\alpha$ 亚基，并通过 $\delta$ 亚基与 $\alpha_3\beta_3$ 稳固结合；嵌入内膜的 $b$ 亚基的疏水端与 $\mathrm{F}_\mathrm{o}$ 的 $a$ 亚基结合，使 $a$、$b_2$ 和 $\mathrm{F}_1$ 中的 $\alpha_3\beta_3$、$\delta$ 亚基组成稳定的“定子”部分。$\mathrm{F}_1$ 部分 $\gamma$ 和 $\varepsilon$ 亚基共同形成中心轴，上端穿过 $\alpha_3\beta_3$ 的六聚体，$\gamma$ 可与 $\beta$ 亚基疏松结合（相互作用），影响 $\beta$ 亚基活性中心构象；下端与嵌入内膜的 $c$ 亚基环紧密结合，使 $c$ 亚基环、$\gamma$ 和 $\varepsilon$ 亚基组成“转子”部分（图10-16）。

当质子顺梯度穿内膜向基质回流时，驱动转子部分围绕定子部分进行旋转，即 $c$ 亚基环和 $\gamma$、$\varepsilon$ 亚基相对于 $\alpha_3\beta_3$ 转动，使 $\mathrm{F}_1$ 中的 $\alpha\beta$ 功能单元利用释放的能量结合 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$ 并生成 $\mathrm{ATP}$。

:::insight{label="转子转的是 γ，催化的是 β"}
$c$ 环在膜里转，轴（$\gamma$、$\varepsilon$）跟着转，$\beta$ 的活性中心被依次拨动。定子（$\alpha_3\beta_3$、$a$、$b_2$、$\delta$）相对不动。不要把“整个蘑菇头在内膜里打转”当成工作图像。
:::

**（2）ATP 合酶的 F1 组分合成 ATP**　Boyer P 提出的结合变构机制（binding change mechanism）解释了 $\mathrm{ATP}$ 的合成过程。$\mathrm{F}_1$ 的 $\alpha\beta$ 单元用于合成 $\mathrm{ATP}$，其中 $\beta$ 亚基至为关键，通过构象变化来结合 $\mathrm{ADP}$、合成 $\mathrm{ATP}$。

$\beta$ 亚基有 $3$ 种构象：$\beta$-$\mathrm{ATP}$ 构象，也称紧密型（tight conformation，$\mathrm{T}$），有催化 $\mathrm{ATP}$ 合成的活性，可紧密结合 $\mathrm{ATP}$；$\beta$-$\mathrm{ADP}$ 构象为疏松型（loose conformation，$\mathrm{L}$），可与 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$ 底物结合；$\beta$-空位（$\beta$-empty）构象为开放型（open conformation，$\mathrm{O}$），是释放了 $\mathrm{ATP}$ 后的空位。

质子回流驱动 $\gamma$ 亚基转动时，会依次接触 $3$ 组 $\alpha\beta$ 单元中的 $\beta$ 亚基，其相互作用导致 $\beta$ 亚基的构象发生周期性循环变化。在某一时刻，当一个 $\beta$ 亚基为 $\beta$-$\mathrm{ATP}$ 构象时，另外二个分别为 $\beta$-$\mathrm{ADP}$ 和 $\beta$-空位构象。当 $\beta$-$\mathrm{ATP}$ 转变为 $\beta$-空位构象时，$\mathrm{ATP}$ 解离并释放；质子流能量驱动合酶的转子部分转动，使空位的 $\beta$ 亚基构象转变为 $\beta$-$\mathrm{ADP}$ 构象，松散地结合基质溶液的 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$；随后的转动使 $\beta$-$\mathrm{ADP}$ 向 $\beta$-$\mathrm{ATP}$ 构象转变、对 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$ 的结合力增强，促进 $\mathrm{ATP}$ 的合成（图10-17）。

这种构象改变产生的功能变化，源自质子势能驱动的中心轴 $\gamma$ 亚基的旋转。$\mathrm{ATP}$ 合酶巧妙利用内膜两侧质子电化学梯度的差异，通过质子跨膜转运时产生的亚基构象的动态变化来催化 $\mathrm{ATP}$ 的合成。因此呼吸链复合体的质子泵功能形成的跨内膜质子电化学梯度是 $\mathrm{ATP}$ 合酶合成 $\mathrm{ATP}$ 的驱动力，即电子的氧化驱动 $\mathrm{ADP}$ 的磷酸化。

::figure{src="/images/biochemistry/textbook/p0239_01.png" caption="图10-17　ATP 合酶的工作机制。（a）质子从膜间隙经 c 环回流（H+ 箭头），驱动 γ 亚基旋转；三个 β 分别处于 O（开放，释放 ATP）、L（疏松，结合 ADP＋Pi）、T（紧密，合成并紧握 ATP）构象。（b）γ 每转一步，三个 β 按 O→L→T→O 循环：L 结合 ADP＋Pi，T 合成 ATP，O 放出 ATP。一周三个 β 各完成一次循环，生成 3 分子 ATP。" alt="ATP 合酶 γ 轴旋转带动三个 β 亚基在开放、疏松、紧密构象间循环合成 ATP"}

:::definition{label="结合变构机制"}
结合变构机制（binding change mechanism）由 Boyer P 提出：$\beta$ 亚基在紧密型 $\mathrm{T}$（$\beta$-$\mathrm{ATP}$，催化并紧握 $\mathrm{ATP}$）、疏松型 $\mathrm{L}$（$\beta$-$\mathrm{ADP}$，结合 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$）、开放型 $\mathrm{O}$（$\beta$-空位，释放 $\mathrm{ATP}$）三种构象间循环。$\gamma$ 亚基旋转依次拨动三个 $\beta$，同一时刻三种构象各占一个 $\beta$。
:::

:::timeline{period="一个 β 亚基的构象圈"}
- **O 开放** 放出 ATP 后的空位
- **L 疏松** 空位转为 β-ADP，松散结合基质中的 ADP 和 Pi
- **T 紧密** β-ADP 转为 β-ATP，结合力增强，合成 ATP
- **再回 O** β-ATP 转为空位，ATP 解离释放
:::

:::compare{title="β 亚基三种构象"}
| 构象 | 别名 | 结合什么 | 正在做什么 |
|------|------|----------|------------|
| $\beta$-$\mathrm{ATP}$ | 紧密型 $\mathrm{T}$（tight） | 紧密结合 $\mathrm{ATP}$ | 有催化合成活性 |
| $\beta$-$\mathrm{ADP}$ | 疏松型 $\mathrm{L}$（loose） | $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$ | 装底物 |
| $\beta$-空位 | 开放型 $\mathrm{O}$（open） | 空 | 刚放出 $\mathrm{ATP}$ |
:::

$\mathrm{ATP}$ 合酶循环转动一周生成 $3$ 分子 $\mathrm{ATP}$。实验数据表明，合成 $1$ 分子 $\mathrm{ATP}$ 需要 $4$ 个 $\mathrm{H}^{+}$，其中 $3$ 个 $\mathrm{H}^{+}$ 通过 $\mathrm{ATP}$ 合酶穿线粒体内膜回流入基质，另 $1$ 个 $\mathrm{H}^{+}$ 用于转运 $\mathrm{ADP}$、$\mathrm{P}_\mathrm{i}$ 和 $\mathrm{ATP}$。每分子 $\mathrm{NADH}$ 经呼吸链传递泵出 $10\mathrm{H}^{+}$，生成约 $2.5$（$10/4$）分子 $\mathrm{ATP}$；而琥珀酸呼吸链每传递 $2$ 个电子泵出 $6\mathrm{H}^{+}$，生成 $1.5$（$6/4$）分子 $\mathrm{ATP}$。

:::derivation{title="每分子 ATP 4 个 H+，所以是 2.5 和 1.5"}
1. 合酶转一周：$3$ 个 $\beta$ 各做一次循环 $\rightarrow 3$ 分子 $\mathrm{ATP}$。
2. 实验：合成 $1$ 分子 $\mathrm{ATP}$ 需 $4$ 个 $\mathrm{H}^{+}$。
3. 其中 $3$ 个 $\mathrm{H}^{+}$ 经 $\mathrm{ATP}$ 合酶回流入基质；$1$ 个 $\mathrm{H}^{+}$ 用于转运 $\mathrm{ADP}$、$\mathrm{P}_\mathrm{i}$ 和 $\mathrm{ATP}$（下一节转位酶）。
4. $\mathrm{NADH}$：$10\mathrm{H}^{+}/4\approx 2.5$ 分子 $\mathrm{ATP}$。
5. 琥珀酸：$6\mathrm{H}^{+}/4=1.5$ 分子 $\mathrm{ATP}$。
:::

:::pitfall{label="不要把“转一周 3 个 ATP”直接当成 P/O"}
一周 $3$ 个 $\mathrm{ATP}$ 是合酶催化计量。$\mathrm{P/O}$ 还要计入把 $\mathrm{ATP}$ 运出线粒体、把 $\mathrm{ADP}$ 和磷酸运进来所花的那 $1$ 个 $\mathrm{H}^{+}$。只按合酶的 $3\mathrm{H}^{+}/\mathrm{ATP}$ 去除以 $10$，会得到与本版 $2.5$ 对不上的数。
:::

:::theorem{label="电子的氧化驱动 ADP 的磷酸化"}
呼吸链复合体的质子泵形成跨内膜质子电化学梯度，是 $\mathrm{ATP}$ 合酶合成 $\mathrm{ATP}$ 的驱动力。氧化（电子传递）与磷酸化（$\mathrm{ADP}+\mathrm{P}_\mathrm{i}$）由此偶联。
:::

## 三、腺苷酸转运蛋白协调转运 ATP 和 ADP 出入线粒体

### （一）线粒体内膜含有多种代谢物的转运体

线粒体的外膜有较高的通透性，而内膜通透性低，对物质进出进行严格控制。内膜含有许多跨膜转运蛋白，能选择性转运各种组分、维持组分间的平衡，以保证生物氧化和基质内旺盛的物质代谢过程能够顺利进行（表10-5）。

:::definition{label="内膜通透性低"}
线粒体外膜通透性较高；内膜通透性低，靠多种跨膜转运蛋白选择性转运代谢物。氧化磷酸化和基质代谢都依赖这张受控的内膜。
:::

:::compare{title="表10-5　线粒体内膜的某些转运蛋白质对代谢物的转运"}
| 转运蛋白质 | 进入线粒体 | 出线粒体 |
|------------|------------|----------|
| $\mathrm{ATP}$-$\mathrm{ADP}$ 转位酶 | $\mathrm{ADP}^{3-}$ | $\mathrm{ATP}^{4-}$ |
| 磷酸盐转运蛋白 | $\mathrm{H}_2\mathrm{PO}_4^{-}+\mathrm{H}^{+}$ | — |
| 二羧酸转运蛋白 | $\mathrm{HPO}_4^{2-}$ | 苹果酸 |
| $\alpha$-酮戊二酸转运蛋白 | 苹果酸 | $\alpha$-酮戊二酸 |
| 天冬氨酸-谷氨酸转运蛋白 | 谷氨酸 | 天冬氨酸 |
| 单羧酸转运蛋白 | 丙酮酸 | $\mathrm{OH}^{-}$ |
| 三羧酸转运蛋白 | 苹果酸 | 柠檬酸 |
| 碱性氨基酸转运蛋白 | 鸟氨酸 | 瓜氨酸 |
| 肉碱转运蛋白 | 脂肪酰肉碱 | 肉碱 |
:::

:::insight{label="表10-5 能对上前几章的穿梭"}
苹果酸／$\alpha$-酮戊二酸、天冬氨酸／谷氨酸是第二节苹果酸-天冬氨酸穿梭的内膜载体；肉碱转运蛋白是第八章脂肪酰 $\mathrm{CoA}$ 进线粒体的户头；鸟氨酸／瓜氨酸是第九章尿素循环进出线粒体的户头。本节新户头是 $\mathrm{ATP}$-$\mathrm{ADP}$ 转位酶和磷酸盐转运蛋白。
:::

:::pitfall{label="丙酮酸进线粒体换出来的是 OH-，不是随便一个阴离子"}
表里单羧酸转运蛋白：丙酮酸进、$\mathrm{OH}^{-}$ 出。不要写成“丙酮酸和 $\mathrm{H}^{+}$ 同向”或“和苹果酸对向”——那是别的载体的账。
:::

### （二）ATP/ADP 转位酶维持线粒体内外 ATP 和 ADP 平衡

氧化磷酸化在线粒体基质中产生大量 $\mathrm{ATP}$ 需转运至细胞质中，同时也需将线粒体外的 $\mathrm{ADP}$ 转运至基质用于磷酸化，因此线粒体内膜含有相关的腺苷酸转运蛋白，同时还有其他相关组分的转运体，例如磷酸盐转运蛋白等。呼吸链产生的质子电化学梯度可用于这些转运蛋白发挥功能。

线粒体内膜富含腺苷酸转运蛋白，也称 $\mathrm{ATP}$-$\mathrm{ADP}$ 转位酶（$\mathrm{ATP}$-$\mathrm{ADP}$ translocase），可占内膜蛋白质总量的 $14\%$。它是由 $2$ 个亚基组成的二聚体，形成跨膜蛋白通道，将膜间隙的 $\mathrm{ADP}^{3-}$（在细胞 $\mathrm{pH}$ 中，$\mathrm{ADP}$ 呈解离状态）转运至线粒体基质中，同时从基质转运出 $\mathrm{ATP}^{4-}$，使经过线粒体内膜的 $\mathrm{ADP}^{3-}$ 进入和 $\mathrm{ATP}^{4-}$ 移出紧密偶联，维持线粒体内外腺苷酸水平基本平衡。每分子 $\mathrm{ATP}^{4-}$ 和 $\mathrm{ADP}^{3-}$ 反向转运时，实际向内膜间隙净转移 $1$ 个负电荷，而膜间隙的高正电性有利于 $\mathrm{ATP}$ 的泵出（图10-18）。

跨膜质子梯度的能量也驱动膜间隙侧的 $\mathrm{H}^{+}$ 和 $\mathrm{H}_2\mathrm{PO}_4^{-}$ 经磷酸盐转运蛋白同向转运到线粒体基质中（图10-18）。因此每分子 $\mathrm{ATP}$ 在线粒体基质中生成并转运到细胞质共需 $4$ 个 $\mathrm{H}^{+}$ 转运进入线粒体基质中。

::figure{src="/images/biochemistry/textbook/p0240_01.png" caption="图10-18　ATP、ADP 及 Pi 的转运。膜间腔侧：H2PO4- 与 H+ 经磷酸盐转运蛋白同向进入基质；ADP3- 经腺苷酸转运蛋白进入基质，ATP4- 反向运出到膜间腔。基质侧 H2PO4-、H+、ADP3- 会合，生成 ATP4- 并放出 H2O。" alt="线粒体内膜上磷酸盐转运蛋白同向转运磷酸和质子，腺苷酸转运蛋白反向转运 ADP 和 ATP"}

:::definition{label="ATP-ADP 转位酶"}
$\mathrm{ATP}$-$\mathrm{ADP}$ 转位酶（$\mathrm{ATP}$-$\mathrm{ADP}$ translocase）即腺苷酸转运蛋白，约占内膜蛋白质总量的 $14\%$，二聚体形成跨膜通道。膜间隙 $\mathrm{ADP}^{3-}$ 进基质，同时基质 $\mathrm{ATP}^{4-}$ 出到膜间隙，二者紧密偶联。
:::

:::definition{label="磷酸盐转运蛋白"}
磷酸盐转运蛋白把膜间隙侧的 $\mathrm{H}^{+}$ 和 $\mathrm{H}_2\mathrm{PO}_4^{-}$ 同向转运进基质，由跨膜质子梯度驱动。
:::

:::derivation{title="为什么每分子 ATP 要 4 个 H+"}
1. 合酶催化：约 $3$ 个 $\mathrm{H}^{+}$ 经 $\mathrm{F}_\mathrm{o}$ 回流，驱动合成 $1$ 分子 $\mathrm{ATP}$。
2. 转运：$\mathrm{ATP}^{4-}$ 出、$\mathrm{ADP}^{3-}$ 进，向膜间隙净移出 $1$ 个负电荷；膜间隙正电性帮忙把 $\mathrm{ATP}$ 泵出。
3. $\mathrm{H}^{+}$ 与 $\mathrm{H}_2\mathrm{PO}_4^{-}$ 同向进基质，相当于再花 $1$ 个 $\mathrm{H}^{+}$。
4. 合计：基质里生成并运到细胞质，共需 $4$ 个 $\mathrm{H}^{+}$ 进入基质。
:::

:::insight{label="膜间隙正电性有利于把 ATP4- 推出去"}
$\mathrm{ATP}$ 比 $\mathrm{ADP}$ 多一个负电荷。内膜胞质侧（膜间隙）正电性高，正好把 $\mathrm{ATP}^{4-}$ 往外推、把 $\mathrm{ADP}^{3-}$ 往里拉。呼吸链质子泵不仅给合酶供能，也给转位酶供势。
:::

:::pitfall{label="基质里做出 ATP 还不等于细胞质已经拿到"}
$\mathrm{P/O}$ $2.5$／$1.5$ 已经把转运那 $1$ 个 $\mathrm{H}^{+}$ 算进去。只数合酶回流的 $3$ 个 $\mathrm{H}^{+}$，会把细胞质可用的 $\mathrm{ATP}$ 算高。
:::

心肌、骨骼肌等耗能多的组织中，线粒体膜间隙存在一种肌酸激酶同工酶，它催化经 $\mathrm{ATP}$-$\mathrm{ADP}$ 转位酶运到膜间腔中的 $\mathrm{ATP}$ 与肌酸之间 $\sim\mathrm{P}$ 的转移，生成的磷酸肌酸经线粒体外膜中的孔蛋白进入细胞质中，由相应的肌酸激酶同工酶催化，将 $\sim\mathrm{P}$ 转移给 $\mathrm{ADP}$ 生成 $\mathrm{ATP}$。因此线粒体内膜的选择性协调转运，对于氧化磷酸化的正常运转至关重要。

:::definition{label="膜间隙肌酸激酶同工酶"}
心肌、骨骼肌等耗能组织的线粒体膜间隙有肌酸激酶同工酶：把转位酶运到膜间腔的 $\mathrm{ATP}$ 的 $\sim\mathrm{P}$ 转给肌酸，生成磷酸肌酸；磷酸肌酸经外膜孔蛋白到细胞质，再由相应同工酶把 $\sim\mathrm{P}$ 转给 $\mathrm{ADP}$ 生成 $\mathrm{ATP}$。
:::

:::note{label="与第九章肌酸账同一套"}
第九章：肌酸在肝由甘氨酸、精氨酸、$\mathrm{SAM}$ 合成；$\mathrm{CK}$-$\mathrm{MB}$ 辅助诊心肌梗死。本节补的是线粒体膜间隙这一层：高耗能组织用磷酸肌酸把 $\sim\mathrm{P}$ 从膜间腔捎到细胞质，不要求 $\mathrm{ATP}$ 自己挤出外膜。
:::

:::memory{label="本节必背要点"}
- [ ] 人体约 $90\%$ 的 $\mathrm{ATP}$ 来自氧化磷酸化：$\mathrm{NADH}/\mathrm{FADH}_2$ 氧化与 $\mathrm{ADP}$ 磷酸化偶联。
- [ ] 偶联部位：复合体Ⅰ、Ⅲ、Ⅳ。不是合酶本身，也不是复合体Ⅱ。
- [ ] $\mathrm{P/O}$：每耗 $1/2\,\mathrm{mol}\,\mathrm{O}_2$ 所耗磷酸摩尔数＝一对电子生成的 $\mathrm{ATP}$ 分子数。
- [ ] 本版：$\mathrm{NADH}$ 呼吸链 $\mathrm{P/O}\approx 2.5$；琥珀酸呼吸链 $\mathrm{P/O}\approx 1.5$。不要默写 $3$ 和 $2$。
- [ ] 抗坏血酸经 $\mathrm{Cyt}\ c$，$\mathrm{P/O}\approx 1$，钉住复合体Ⅳ；$\mathrm{NADH}$ 与琥珀酸之差钉住复合体Ⅰ。
- [ ] 电位差：$\mathrm{NAD}^{+}\rightarrow\mathrm{Q}$ 约 $0.36\,\mathrm{V}$（$69.5\,\mathrm{kJ/mol}$）；$\mathrm{Q}\rightarrow\mathrm{Cyt}\ c$ $0.19\,\mathrm{V}$（$36.7$）；$\mathrm{Cyt}\ a$、$a_3\rightarrow\mathrm{O}_2$ $0.58\,\mathrm{V}$（$112$）。$\mathrm{ATP}$ 约需 $30.5\,\mathrm{kJ}$。
- [ ] 化学渗透（Mitchell）：泵质子 $\rightarrow$ 电化学梯度 $\rightarrow$ 回流驱动合酶。需完整封闭内膜。
- [ ] 一对电子泵出：$4+4+2=10\mathrm{H}^{+}$（Ⅰ、Ⅲ、Ⅳ）。琥珀酸不经Ⅰ，泵 $6\mathrm{H}^{+}$。
- [ ] $\mathrm{ATP}$ 合酶＝复合体Ⅴ；真核常二聚体。$\mathrm{F}_1$ 亲水催化，$\mathrm{F}_\mathrm{o}$ 疏水通道、对寡霉素敏感。
- [ ] $\mathrm{F}_1$：$\alpha_3\beta_3\gamma\delta\varepsilon$（$5$ 型 $9$ 亚基）。$\mathrm{F}_\mathrm{o}$：$ab_2c_{8\sim 17}$；牛 $8$ 个 $c$；寡霉素结合 $c$ 环。
- [ ] 定子：$\alpha_3\beta_3$、$\delta$、$a$、$b_2$。转子：$c$ 环、$\gamma$、$\varepsilon$。
- [ ] $a$ 亚基两条不连通半通道；$\mathrm{His}$ 接 $\mathrm{H}^{+}$，$c$ 的 $\mathrm{Glu}$（或 $\mathrm{Asp}$）质子化后转环，基质侧释放，$\mathrm{Arg}$ 暂停。
- [ ] $\mathrm{NADH}\rightarrow\mathrm{O}_2$ 约 $220\,\mathrm{kJ/mol}$，梯度约存 $200\,\mathrm{kJ/mol}$。
- [ ] 结合变构（Boyer）：$\beta$ 的 $\mathrm{T}/\mathrm{L}/\mathrm{O}$（$\mathrm{ATP}/\mathrm{ADP}/$空位）。一周 $3$ 分子 $\mathrm{ATP}$。
- [ ] 每分子 $\mathrm{ATP}$ 需 $4\mathrm{H}^{+}$：$3$ 个走合酶，$1$ 个走 $\mathrm{ADP}/\mathrm{P}_\mathrm{i}/\mathrm{ATP}$ 转运。$10/4\approx 2.5$，$6/4=1.5$。
- [ ] $\mathrm{ATP}$-$\mathrm{ADP}$ 转位酶占内膜蛋白约 $14\%$；$\mathrm{ADP}^{3-}$ 进、$\mathrm{ATP}^{4-}$ 出，净向膜间隙移 $1$ 个负电荷。
- [ ] 磷酸盐转运蛋白：$\mathrm{H}^{+}$ 与 $\mathrm{H}_2\mathrm{PO}_4^{-}$ 同向进基质。
- [ ] 心肌、骨骼肌膜间隙肌酸激酶：$\mathrm{ATP}$ 的 $\sim\mathrm{P}$ 写成磷酸肌酸，经孔蛋白到细胞质。
:::
