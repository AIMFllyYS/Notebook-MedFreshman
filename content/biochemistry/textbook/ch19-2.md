# 第二节　重组DNA技术

第一节把自然界里 $\mathrm{DNA}$ 怎样重新共价组合、基因怎样在细胞间搬家立完。本节只立体外操作：把不同来源的两个或两个以上 $\mathrm{DNA}$ 分子连起来，再放到适当细胞里扩增成新的功能分子。工具酶、载体、克隆五步和表达是这一节的账；医学应用交给第三节。$\mathrm{CRISPR}/\mathrm{Cas}$ 基因组工程已在第一节，本节不再重开。

:::concept{term="先问是体外把两段 DNA 连起来再扩增，还是细胞内的同源、位点特异、转座"}
看见“重组 $\mathrm{DNA}$”，先不要默写 Holliday 连接。户头是：限制酶切、连接酶连、载体带着目的片段进受体细胞复制。分子克隆、$\mathrm{DNA}$ 克隆、基因工程三个名字指同一件事。蓝白筛选、插入失活、核酸杂交是三种不同的筛法，不要并成一句「长出来就是重组体」。
:::

重组 $\mathrm{DNA}$ 技术又称分子克隆（molecular cloning）、$\mathrm{DNA}$ 克隆（DNA cloning）或基因工程（genetic engineering），是指通过体外操作将不同来源的两个或两个以上 $\mathrm{DNA}$ 分子重新组合，并在适当细胞中扩增形成新功能 $\mathrm{DNA}$ 分子的方法。其主要过程包括：在体外将目的 $\mathrm{DNA}$ 片段与能自主复制的遗传元件（又称载体）连接，形成重组 $\mathrm{DNA}$ 分子，进而在受体细胞中复制、扩增及克隆化，从而获得单一 $\mathrm{DNA}$ 分子的大量拷贝。在克隆目的基因后，还可针对该基因进行表达产物蛋白质或多肽的制备以及基因结构的定向改造。自 $1972$ 年成功构建第一个重组 $\mathrm{DNA}$ 分子以来，重组 $\mathrm{DNA}$ 技术得到了快速发展，人们几乎可以随心所欲地进行分离、分析、切割－连接等操作基因。另外，该技术在生物制药、基因诊断、基因治疗等诸多方面都得到了广泛应用。

:::definition{label="重组 DNA 技术"}
重组 $\mathrm{DNA}$ 技术（recombinant DNA technology）：通过体外操作将不同来源的两个或两个以上 $\mathrm{DNA}$ 分子重新组合，并在适当细胞中扩增形成新功能 $\mathrm{DNA}$ 分子。又名分子克隆、$\mathrm{DNA}$ 克隆或基因工程。第一节只立这个户头；本节把它拆成工具酶、载体、五步操作和表达。
:::

:::timeline{period="重组 DNA 技术起点"}
- **1972** 成功构建第一个重组 DNA 分子
- **此后** 分离、分析、切割-连接几乎可以按设计操作基因
- **应用** 生物制药、基因诊断、基因治疗等交给第三节，本节先把操作账立住
:::

:::pitfall{label="不要把本节答成第一节的 Holliday 或 CRISPR"}
自然界的同源、位点特异、转座，以及细菌 $\mathrm{CRISPR}/\mathrm{Cas}$，是第一节的账。把本节写成「Chi 位点、$\mathrm{attP}/\mathrm{attB}$、间隔序列插入阵列」，限制酶和质粒图谱就没有前置。
:::

:::compare{title="第一节 DNA 重组 vs 本节重组 DNA 技术"}
| | 发生场所 | 在做什么 | 本章位置 |
|--|----------|----------|----------|
| $\mathrm{DNA}$ 重组 | 细胞内，自然界 | 分子内或分子间遗传信息重新共价组合 | 第一节：同源、位点特异、转座 |
| 重组 $\mathrm{DNA}$ 技术 | 体外操作后放入适当细胞扩增 | 把不同来源的两个或两个以上 $\mathrm{DNA}$ 分子连成新的功能分子 | 本节；医学应用在第三节 |

「重组」两个字共用，从第一句就要分开。
:::

## 一、重组DNA技术中常用的工具酶

在重组 $\mathrm{DNA}$ 技术中，常需要一些工具酶用于基因的操作。例如，对目的 $\mathrm{DNA}$（target DNA）进行处理时，需利用序列特异性限制性核酸内切酶（restriction endonuclease），限制性核酸内切酶充当精确的分子剪刀，识别 $\mathrm{DNA}$ 中的特定序列，并将 $\mathrm{DNA}$ 切割成适合克隆的片段；构建重组 $\mathrm{DNA}$ 分子时，在 $\mathrm{DNA}$ 连接酶催化下完成 $\mathrm{DNA}$ 片段与载体共价连接。此外，还有一些工具酶也是重组 $\mathrm{DNA}$ 时所必不可少的。

### （一）常用工具酶具有各自功能

为了方便快速浏览重组 $\mathrm{DNA}$ 技术中一些常用工具酶及其基本功能，教材把它们概括于表19-1。在所有工具酶中，限制性核酸内切酶具有特别重要的地位，因此有关限制性核酸内切酶的内容单独介绍。

**表19-1　重组DNA技术中常用的工具酶**

| 工具酶 | 功能 |
|--------|------|
| Ⅱ型限制性核酸内切酶 | 识别特异序列，切割 $\mathrm{DNA}$ |
| $\mathrm{DNA}$ 连接酶 | 催化 $\mathrm{DNA}$ 中相邻的 $5'$-磷酸基团和 $3'$-羟基末端之间形成磷酸二酯键，使 $\mathrm{DNA}$ 切口封合，或使两个 $\mathrm{DNA}$ 分子或片段连接起来 |
| $\mathrm{DNA}$ 聚合酶Ⅰ | 具有 $5'\rightarrow 3'$ 聚合、$3'\rightarrow 5'$ 外切及 $5'\rightarrow 3'$ 外切活性；用于合成双链 $\mathrm{cDNA}$ 分子或片段连接；缺口平移法制作高比活性探针；$\mathrm{DNA}$ 序列分析；填补 $3'$ 末端 |
| Klenow 片段 | 又名 $\mathrm{DNA}$ 聚合酶Ⅰ大片段，具有完整 $\mathrm{DNA}$ 聚合酶Ⅰ的 $5'\rightarrow 3'$ 聚合及 $3'\rightarrow 5'$ 外切活性，但缺乏 $5'\rightarrow 3'$ 外切活性。常用于 $\mathrm{cDNA}$ 第二链合成、双链 $\mathrm{DNA}$ 的 $3'$ 端标记等 |
| 逆转录酶 | 以 $\mathrm{RNA}$ 为模板的 $\mathrm{DNA}$ 聚合酶，用于合成 $\mathrm{cDNA}$，也用于替代 $\mathrm{DNA}$ 聚合酶Ⅰ进行缺口填补、标记或 $\mathrm{DNA}$ 序列分析等 |
| 多聚核苷酸激酶 | 催化多聚核苷酸 $5'$ 羟基末端磷酸化或标记探针等 |
| 末端转移酶 | 在 $3'$ 羟基末端进行同质多聚物加尾 |
| 碱性磷酸酶 | 切除末端磷酸基团 |

:::definition{label="Klenow 片段缺 5′→3′ 外切"}
Klenow 片段是 $\mathrm{DNA}$ 聚合酶Ⅰ大片段：保留 $5'\rightarrow 3'$ 聚合和 $3'\rightarrow 5'$ 外切，**缺乏** $5'\rightarrow 3'$ 外切。用于 $\mathrm{cDNA}$ 第二链合成、双链 $\mathrm{DNA}$ 的 $3'$ 端标记。把三条活性都写给 Klenow，缺口平移那一户就没有专属的全酶了。
:::

:::compare{title="DNA 聚合酶Ⅰ vs Klenow 片段"}
| | $5'\rightarrow 3'$ 聚合 | $3'\rightarrow 5'$ 外切 | $5'\rightarrow 3'$ 外切 | 教材点名的用途 |
|--|----------------------|----------------------|----------------------|----------------|
| $\mathrm{DNA}$ 聚合酶Ⅰ | 有 | 有 | 有 | 双链 $\mathrm{cDNA}$、缺口平移探针、测序、填补 $3'$ 末端 |
| Klenow 片段 | 有 | 有 | **无** | $\mathrm{cDNA}$ 第二链、双链 $\mathrm{DNA}$ 的 $3'$ 端标记 |

缺口平移需要 $5'\rightarrow 3'$ 外切把缺口往前推，这一步用全酶，不用 Klenow。
:::

:::pitfall{label="多聚核苷酸激酶加的是 5′ 磷酸，碱性磷酸酶是拆 5′ 磷酸"}
激酶：给 $5'$-$\mathrm{OH}$ 磷酸化或做探针标记。碱性磷酸酶：把末端磷酸拿走。方向相反。写成「激酶去磷酸化」，载体自连和探针标记两户都会反。
:::

### （二）限制性核酸内切酶是DNA重组最重要的工具酶

限制性核酸内切酶简称为限制性内切酶或限制酶，是一类核酸内切酶，生物学功能是识别和切割外源 $\mathrm{DNA}$（如受感染病毒的 $\mathrm{DNA}$）。除极少数来自绿藻外，绝大多数来自细菌，与相伴存在的甲基化酶共同构成细菌的限制修饰体系（restriction modification system）。限制性核酸内切酶对甲基化保护的自身 $\mathrm{DNA}$ 不起作用，仅切割外源 $\mathrm{DNA}$，因此对细菌遗传性状的稳定具有重要意义。

:::definition{label="限制性核酸内切酶"}
限制性核酸内切酶简称限制性内切酶或限制酶：一类核酸内切酶，识别并切割外源 $\mathrm{DNA}$（如感染病毒的 $\mathrm{DNA}$）。除极少数来自绿藻外，绝大多数来自细菌。
:::

:::definition{label="限制修饰体系"}
限制性核酸内切酶与相伴存在的甲基化酶共同构成细菌的限制修饰体系（restriction modification system）。自身 $\mathrm{DNA}$ 被甲基化保护，酶对它不起作用；外源 $\mathrm{DNA}$ 未甲基化，被切割。这对细菌遗传性状的稳定具有重要意义。
:::

:::pitfall{label="不要写成限制酶连自身 DNA 一起切"}
教材写明：对甲基化保护的自身 $\mathrm{DNA}$ 不起作用，仅切割外源 $\mathrm{DNA}$。漏掉甲基化酶这一半，限制修饰体系就只剩「乱切基因组」。
:::

#### 1. 分类及其特点

目前发现的限制性核酸内切酶有 $6\,000$ 多种。根据其组成、所需因子及裂解 $\mathrm{DNA}$ 方式的不同可分为三种类型，即Ⅰ、Ⅱ和Ⅲ型。Ⅰ型和Ⅲ型酶为复合功能酶，同时具有内切酶和甲基化酶的活性，且不在所识别的位点特异性切割 $\mathrm{DNA}$；Ⅱ型酶能在 $\mathrm{DNA}$ 双链内部的特异位点识别并切割，不需要 $\mathrm{ATP}$，故其被广泛用作「分子剪刀」，对 $\mathrm{DNA}$ 进行精确切割。因此，重组 $\mathrm{DNA}$ 技术中所说的限制性核酸内切酶通常指Ⅱ型酶。

:::definition{label="重组 DNA 技术里的限制酶通常指 Ⅱ 型"}
Ⅱ型不需要 $\mathrm{ATP}$，切点就在识别序列内部（或由其决定的特异位点），所以被广泛用作分子剪刀。口试「最重要的工具酶」不要答成Ⅰ型或Ⅲ型。
:::

:::pitfall{label="不要把 6 000 多种都当成 Ⅱ 型分子剪刀"}
发现的酶有 $6\,000$ 多种，分成三型。重组操作里「通常指Ⅱ型」是工作约定，不是「只有Ⅱ型存在」。
:::

#### 2. 命名原则

限制性核酸内切酶的命名采用 Smith 和 Nathane 提出的属名与种名相结合的命名法，即第一个字母是酶来源的细菌属名的首字母，用大写斜体；第二、三个字母是细菌菌种名的首字母，用小写斜体；第四个字母（有时无）表示细菌的特定菌株，用大写或小写；罗马数字表示限制性核酸内切酶在此菌种发现的先后顺序。例如，$\mathrm{EcoR}\,\mathrm{I}$：$E$＝Escherichia，埃希菌属；$co$＝coli，大肠埃希菌菌种；$R$＝RY3，菌株名；Ⅰ，为从此菌中第一个分离获得的限制性核酸内切酶。

:::definition{label="EcoR I 四个部件"}
$\mathrm{EcoR}\,\mathrm{I}$：$E$＝Escherichia（埃希菌属），$co$＝coli（大肠埃希菌），$R$＝RY3（菌株），Ⅰ＝该菌中分离到的第一种限制酶。不要把 $\mathrm{R}$ 写成「限制」的缩写。
:::

:::pitfall{label="罗马数字是发现顺序，不是切割类型"}
Ⅰ、Ⅱ、Ⅲ型是酶的分类；$\mathrm{EcoR}\,\mathrm{I}$ 的「Ⅰ」是该菌株里第一种被分出来的酶。把罗马数字答成「这是Ⅰ型酶」，命名和分类两户并了。
:::

#### 3. 识别及切割特异 DNA 序列

Ⅱ型限制性核酸内切酶的识别位点通常为 $6$ 个或 $4$ 个碱基序列，个别的识别 $8$ 个或 $8$ 个以上碱基序列。表19-2 列举了部分Ⅱ型的识别位点。大多数限制性核酸内切酶的识别序列为回文序列（palindrome）。回文结构是指在两条核苷酸链的特定位点，从 $5'\rightarrow 3'$ 方向的序列完全一致。例如，$\mathrm{EcoR}\,\mathrm{I}$ 的识别序列，在两条链上的 $5'\rightarrow 3'$ 序列均为 $\mathrm{GAATTC}$。

:::definition{label="回文序列"}
回文序列（palindrome）：在两条核苷酸链的特定位点，从 $5'\rightarrow 3'$ 方向的序列完全一致。$\mathrm{EcoR}\,\mathrm{I}$ 两条链从 $5'$ 读都是 $\mathrm{GAATTC}$。这是序列对称，不是「从 $5'$ 读和从 $3'$ 读同一个单链」。
:::

:::pitfall{label="回文不是单链从左读到右等于从右读到左那么简单"}
教材定义落在**两条链**、都按 $5'\rightarrow 3'$ 读是否一致。把 $\mathrm{GAATTC}$ 答成「正读倒读都一样的一条链」，$\mathrm{EcoR}\,\mathrm{I}$ 那句例子对不上。
:::

**表19-2　Ⅱ型限制性核酸内切酶的识别位点举例**

| 限制性核酸内切酶 | 识别位点（$'$ 代表切割位点；$\mathrm{N}$ 代表任意碱基） |
|------------------|----------------------------------------------------------|
| $\mathrm{Apa}\,\mathrm{I}$ | $5'$-$\mathrm{GGGCC}'\mathrm{C}$-$3'$／$3'$-$\mathrm{C}'\mathrm{CCGGG}$-$5'$ |
| $\mathrm{Sma}\,\mathrm{I}$ | $5'$-$\mathrm{CCC}'\mathrm{GGG}$-$3'$／$3'$-$\mathrm{GGG}'\mathrm{CCC}$-$5'$ |
| $\mathrm{BamH}\,\mathrm{I}$ | $5'$-$\mathrm{G}'\mathrm{GATCC}$-$3'$／$3'$-$\mathrm{CCTAG}'\mathrm{G}$-$5'$ |
| $\mathrm{Sau3A}\,\mathrm{I}$ | 识别四碱基 $\mathrm{GATC}$（表中以 $\mathrm{GATC}$ 为核心；切割后产生与 $\mathrm{BamH}\,\mathrm{I}$ 相同的 $\mathrm{GATC}$ 黏端核心） |
| $\mathrm{Pst}\,\mathrm{I}$ | $5'$-$\mathrm{CTGCA}'\mathrm{G}$-$3'$／$3'$-$\mathrm{G}'\mathrm{ACGTC}$-$5'$ |
| $\mathrm{Not}\,\mathrm{I}$ | $5'$-$\mathrm{GC}'\mathrm{GGCCGC}$-$3'$／$3'$-$\mathrm{CGCCGG}'\mathrm{CG}$-$5'$ |
| $\mathrm{EcoR}\,\mathrm{I}$ | $5'$-$\mathrm{G}'\mathrm{AATTC}$-$3'$／$3'$-$\mathrm{CTTAA}'\mathrm{G}$-$5'$ |
| $\mathrm{Sfi}\,\mathrm{I}$ | $5'$-$\mathrm{GGCCNNN}'\mathrm{NGGCC}$-$3'$／$3'$-$\mathrm{CCGGN}'\mathrm{NNNCCGG}$-$5'$ |

:::compare{title="表19-2 里三种末端"}
| 末端 | 表中例子 | 切点位置 |
|------|----------|----------|
| $5'$ 黏端 | $\mathrm{EcoR}\,\mathrm{I}$、$\mathrm{BamH}\,\mathrm{I}$、$\mathrm{Not}\,\mathrm{I}$ | 靠识别序列的 $5'$ 侧 |
| $3'$ 黏端 | $\mathrm{Apa}\,\mathrm{I}$、$\mathrm{Pst}\,\mathrm{I}$、$\mathrm{Sfi}\,\mathrm{I}$ | 靠识别序列的 $3'$ 侧 |
| 平端 | $\mathrm{Sma}\,\mathrm{I}$ | 六碱基正中 |

后文黏端连接、平端连接、黏－平端连接，用的就是这三种几何。
:::

#### 4. 同尾酶和同切点酶

有些限制性核酸内切酶所识别的序列虽然不完全相同，但切割 $\mathrm{DNA}$ 双链后可产生相同的单链末端（黏端），这样的酶彼此互称同尾酶（isocaudarner），所产生的相同黏端称为配伍末端（compatible end）。例如，$\mathrm{BamH}\,\mathrm{I}$（$\mathrm{G}'\mathrm{GATCC}$）和 $\mathrm{Bgl}\,\mathrm{II}$（$\mathrm{A}'\mathrm{GATCT}$）在切割不同序列后可产生相同的 $5'$ 黏端，即配伍末端（—$\mathrm{GATC}$—）。配伍末端可共价连接，但连接后的序列通常就不能再被两个同尾酶中的任何一个酶识别和切割了。

有些限制性核酸内切酶虽然来源不同，但能识别同一序列（切割位点可相同或不同），这样的两种酶称同切点酶（isoschizomer）或异源同工酶。例如 $\mathrm{BamH}\,\mathrm{I}$ 和 $\mathrm{Bst}\,\mathrm{I}$ 能识别并在相同位点切割同一 $\mathrm{DNA}$ 序列（$\mathrm{G}'\mathrm{GATCC}$）；$\mathrm{Xma}\,\mathrm{I}$ 和 $\mathrm{Sma}\,\mathrm{I}$ 虽能识别相同序列，但切割位点不同，前者的切点在识别序列的第一个核苷酸后（$\mathrm{G}'\mathrm{GGCCC}$），而后者的切点则在序列的中间（$\mathrm{GGG}'\mathrm{CCC}$）。同切点酶为 $\mathrm{DNA}$ 操作者增加了酶的选择余地。

:::definition{label="同尾酶与配伍末端"}
同尾酶（isocaudarner）：识别序列不完全相同，但切割后产生相同黏端。该相同黏端叫配伍末端（compatible end）。例：$\mathrm{BamH}\,\mathrm{I}$（$\mathrm{G}'\mathrm{GATCC}$）与 $\mathrm{Bgl}\,\mathrm{II}$（$\mathrm{A}'\mathrm{GATCT}$）都留下 $5'$ 的 —$\mathrm{GATC}$—。
:::

:::definition{label="同切点酶（异源同工酶）"}
同切点酶（isoschizomer）或异源同工酶：来源不同，识别同一序列；切割位点可相同或不同。例：$\mathrm{BamH}\,\mathrm{I}$ 与 $\mathrm{Bst}\,\mathrm{I}$ 都在 $\mathrm{G}'\mathrm{GATCC}$ 同一位点切；$\mathrm{Xma}\,\mathrm{I}$ 与 $\mathrm{Sma}\,\mathrm{I}$ 识别相同，切点不同。
:::

:::compare{title="同尾酶 vs 同切点酶"}
| | 识别序列 | 切完的末端 | 本版例子 |
|--|----------|------------|----------|
| 同尾酶 | 不完全相同 | 相同黏端（配伍末端） | $\mathrm{BamH}\,\mathrm{I}$ 与 $\mathrm{Bgl}\,\mathrm{II}$ |
| 同切点酶 | 同一序列 | 切点可相同或不同 | $\mathrm{BamH}\,\mathrm{I}$ 与 $\mathrm{Bst}\,\mathrm{I}$（切点相同）；$\mathrm{Xma}\,\mathrm{I}$ 与 $\mathrm{Sma}\,\mathrm{I}$（切点不同） |

问「能不能连」看同尾酶；问「认的是不是同一段」看同切点酶。
:::

:::pitfall{label="同尾酶连上不等于还能再被原酶切开"}
配伍末端可连，但接头序列通常两个酶都不认。写成「$\mathrm{BamH}\,\mathrm{I}$ 和 $\mathrm{Bgl}\,\mathrm{II}$ 切的东西可以互相切回来」，后文定向克隆和酶切鉴定会判错。
:::

:::pitfall{label="表19-2 的 Sma I 与后文同切点酶举例不要混成一句"}
表19-2 把 $\mathrm{Sma}\,\mathrm{I}$ 写成 $\mathrm{CCC}'\mathrm{GGG}$（平端）。后文举例写 $\mathrm{Xma}\,\mathrm{I}$／$\mathrm{Sma}\,\mathrm{I}$ 识别相同、切点分别在第一个核苷酸后和正中。答题按题目引用的是表还是该段文字来答切点差别，不要把 $\mathrm{Apa}\,\mathrm{I}$ 的 $\mathrm{GGGCCC}$ 拿去顶替表19-2。
:::

## 二、重组DNA技术中常用的载体

载体（vector）是能够自主复制的 $\mathrm{DNA}$ 分子，可以携带目的外源 $\mathrm{DNA}$ 片段、实现外源 $\mathrm{DNA}$ 在受体细胞中无性繁殖或表达蛋白质，按其功能可分为克隆载体和表达载体两大类，有的载体兼有克隆和表达两种功能。

:::definition{label="载体"}
载体（vector）：能够自主复制的 $\mathrm{DNA}$ 分子，携带目的外源 $\mathrm{DNA}$ 片段，实现外源 $\mathrm{DNA}$ 在受体细胞中无性繁殖或表达蛋白质。按功能分克隆载体和表达载体；有的兼有两种功能。
:::

:::pitfall{label="载体必须能自主复制"}
「能够自主复制」是定义的第一句。一段线性目的基因自己没有复制起点，进细胞后不会按质粒那样扩增。把载体答成「任何外源 $\mathrm{DNA}$」，克隆化这一户就空了。
:::

:::compare{title="克隆载体 vs 表达载体"}
| | 主要目的 | 必备 |
|--|----------|------|
| 克隆载体 | 扩增克隆化 $\mathrm{DNA}$ 分子 | 复制起点、选择标志、多克隆位点 |
| 表达载体 | 在宿主中表达外源基因 | 克隆载体的一般特征 $+$ 转录／翻译信号 |

先问这一步是「要拷贝」还是「要蛋白质」，再选哪一类。
:::

### （一）克隆载体用于扩增克隆化DNA分子

克隆载体（cloning vector）是指用于外源 $\mathrm{DNA}$ 片段的克隆和在受体细胞中扩增的 $\mathrm{DNA}$ 分子，一般应具备的基本特点：①至少有一个复制起点使载体能在宿主细胞中自主复制，并能使克隆的外源 $\mathrm{DNA}$ 片段得到同步扩增；②至少有一个选择标志（selection marker），从而区分含有载体和不含有载体的细胞，如抗生素抗性基因、$\beta$-半乳糖苷酶基因（$lacZ$）、营养缺陷耐受基因等；③有多克隆位点（multiple cloning site，$\mathrm{MCS}$），即多种限制性核酸内切酶的单一切点，可供外源基因插入载体。常用克隆载体主要有质粒、噬菌体 $\mathrm{DNA}$ 等。

:::definition{label="克隆载体三条基本特点"}
①至少一个复制起点，使载体自主复制，并让插入的外源片段同步扩增；②至少一个选择标志，区分含载体与不含载体的细胞；③有多克隆位点 $\mathrm{MCS}$，即多种限制酶的单一切点，供外源基因插入。图19-12 把 $\mathrm{pUC}18$ 的 $\mathrm{MCS}$ 画成从 $\mathrm{Hind}\,\mathrm{III}$ 到 $\mathrm{EcoR}\,\mathrm{I}$ 的一串单一切点。
:::

#### 1. 质粒克隆载体

质粒克隆载体是重组 $\mathrm{DNA}$ 技术中最常用的载体，可以是天然质粒，更多是人工改造的质粒。质粒（plasmid）是细菌染色体外的、能自主复制和稳定遗传的双链环状 $\mathrm{DNA}$ 分子，具备作为克隆载体的基本特点。例如，$\mathrm{pUC}18$ 质粒载体，具有一个复制起点 $\mathrm{ori}$，一个选择标志——氨苄西林抗性基因 $\mathit{amp}^{\mathrm{R}}$ 和多克隆位点（图19-12）。

:::definition{label="质粒"}
质粒（plasmid）：细菌染色体外的、能自主复制和稳定遗传的双链环状 $\mathrm{DNA}$ 分子。天然质粒可以改造为克隆载体；实验室里更多是人工改造过的。
:::

:::definition{label="pUC18 三件套"}
$\mathrm{pUC}18$：复制起点 $\mathrm{ori}$、氨苄西林抗性基因 $\mathit{amp}^{\mathrm{R}}$、多克隆位点 $\mathrm{MCS}$。图19-12 还标出全长 $2\,690\,\mathrm{bp}$。三条对应克隆载体的三个基本特点，缺一不可。
:::

::figure{src="/images/biochemistry/textbook/p0400_01.png" caption="图19-12　pUC18 质粒克隆载体图谱" alt="环状 pUC18，2 690 bp；上方蓝弧为 ampR，右侧蓝弧为 MCS，左下灰点为 ori。MCS 从 HindIII、SphI、PstI、SalI/AccI/HincII、XbaI、BamHI、SmaI/XmaI、KpnI、SacI 到 EcoRI"}

:::pitfall{label="pUC18 的抗性是氨苄西林，不是四环素"}
图19-12 只有 $\mathit{amp}^{\mathrm{R}}$。后文插入失活用的 $\mathrm{pBR}322$ 才同时有 $\mathit{amp}^{\mathrm{R}}$ 和 $\mathit{tet}^{\mathrm{R}}$。把 $\mathrm{pUC}18$ 答成双抗插入失活，蓝白筛选和插入失活两户并了。
:::

#### 2. 噬菌体 DNA 载体

噬菌体（phages，bacterial viruses）通常具有线性 $\mathrm{DNA}$ 基因组。外源 $\mathrm{DNA}$ 可以通过特异的限制性内切酶位点插入噬菌体 $\mathrm{DNA}$。噬菌体优点之一是容量大，很容易接受长达约 $20\,\mathrm{kb}$ 的 $\mathrm{DNA}$ 片段。$\lambda$ 和 $\mathrm{M}13$ 噬菌体 $\mathrm{DNA}$ 常用作克隆载体。经 $\lambda$ 噬菌体 $\mathrm{DNA}$ 改造的载体系统有 $\lambda\mathrm{gt}$ 系列（插入型载体，适用于 $\mathrm{cDNA}$ 克隆）和 $\mathrm{EMBL}$ 系列（置换型载体，适用于基因组 $\mathrm{DNA}$ 克隆）；经改造的 $\mathrm{M}13$ 载体有 $\mathrm{M}13\mathrm{mp}$ 系列和 $\mathrm{pUC}$ 系列，它们是在 $\mathrm{M}13$ 的基因间隔区插入了大肠埃希菌（$E.\ coli$）的一段调节基因及 $\beta$-半乳糖苷酶（$\mathrm{LacZ}$）$\mathrm{N}$-端 $146$ 个氨基酸残基编码基因，其编码产物为 $\beta$-半乳糖苷酶的 $\alpha$ 片段。突变的 $E.\ coli$ 宿主（$lac^{-}$）仅表达该酶的 $\omega$ 片段（酶的 $\mathrm{C}$-端）。单独存在 $\beta$-半乳糖苷酶的 $\alpha$ 片段或 $\omega$ 片段都没有酶的活性，只有携带 $\alpha$ 片段基因的 $\mathrm{M}13$ 进入宿主细胞，宿主细胞才能同时表达 $\alpha$ 和 $\omega$ 片段，产生有活性的 $\beta$-半乳糖苷酶，使特异性底物变为蓝色化合物，这就是所谓的 $\alpha$ 互补（$\alpha$ complementation）。当外源基因的插入位点设计在 $LacZ$ 基因内部时，外源基因的插入则会干扰 $LacZ$ 的表达，利用 $lacZ^{-}$ 菌株为宿主细胞，在含 $LacZ$ 底物 $\mathrm{X}$-gal 和诱导剂 $\mathrm{IPTG}$ 的培养基上生长时会出现白色菌落；如果在 $lacZ$ 基因内无外源基因插入，则有 $LacZ$ 表达，转化菌在同样条件下呈蓝色菌落，这就是蓝白筛选（图19-13）。现在，很多质粒载体也构建了蓝白筛选系统。

:::definition{label="α 互补"}
$\alpha$ 互补（$\alpha$ complementation）：宿主（$lac^{-}$）只提供 $\omega$ 片段（$\mathrm{C}$-端），载体提供 $\alpha$ 片段（$\mathrm{N}$-端 $146$ 残基）。单独的 $\alpha$ 或 $\omega$ 都没有酶活性；二者同时存在才组装成有活性的 $\beta$-半乳糖苷酶，把特异底物变成蓝色化合物。
:::

:::definition{label="蓝白筛选：空载体蓝、插入白"}
外源基因插入位点设计在 $LacZ$ 内部，插入干扰 $LacZ$ 表达。$lacZ^{-}$ 宿主在含 $\mathrm{X}$-gal 和 $\mathrm{IPTG}$ 的培养基上：无插入 $\rightarrow$ 有 $LacZ$ 表达 $\rightarrow$ **蓝色**菌落；有插入 $\rightarrow$ 干扰表达 $\rightarrow$ **白色**菌落。这就是蓝白筛选。
:::

::figure{src="/images/biochemistry/textbook/p0401_01.png" caption="图19-13　α互补筛选（蓝白筛选）" alt="左侧空载体含 ampR、MCS 和 β-半乳糖苷酶 α 片段编码序列，导入带 ω 片段的宿主，在 X-gal 和 IPTG 平板上长出蓝色菌落或噬斑；右侧外源 DNA 插入把 α 片段编码序列分割，重组载体导入同一宿主后长出白色菌落或噬斑"}

:::insight{label="图19-13 左蓝右白，插入把 α 编码序列切开"}
左：空载体 $\alpha$ 完整，与染色体 $\omega$ 互补，底物变蓝。右：外源 $\mathrm{DNA}$ 插进 $\mathrm{MCS}$，$\alpha$ 编码序列被分割，不能互补，菌落或噬斑为白。平板都含 $\mathrm{X}$-gal 和 $\mathrm{IPTG}$。
:::

:::pitfall{label="千万不要写成有插入就蓝"}
空载体才蓝，插入才白。写反之后，挑克隆会把空载体当成阳性。图19-13 的左右两侧就是专门用来挡这句的。
:::

:::pitfall{label="α 或 ω 单独都没有酶活性"}
不是「细菌自己会蓝」。必须载体带来 $\alpha$、宿主提供 $\omega$，二者凑齐。宿主写成「完整 $lacZ^{+}$」，蓝白筛选的逻辑就断了。
:::

#### 3. 其他克隆载体

为增加克隆载体携带较长外源基因的能力，还设计有柯斯质粒（cosmid）载体（又称黏粒载体）、细菌人工染色体（bacterial artificial chromosome，$\mathrm{BAC}$）载体和酵母人工染色体（yeast artificial chromosome，$\mathrm{YAC}$）载体等。柯斯质粒是人工构建的含 $\lambda$ $\mathrm{DNA}$ $\mathrm{Cos}$ 序列和质粒复制子的特殊类型质粒载体，自身一般只有 $5\sim 7\,\mathrm{kb}$，但能携带的外源 $\mathrm{DNA}$ 片段最大可达 $45\,\mathrm{kb}$。$\mathrm{BAC}$ 是以大肠埃希菌性因子 $\mathrm{F}$ 质粒（$\mathrm{F}$ 因子）为基础构建的克隆载体，可携带的外源 $\mathrm{DNA}$ 片段在 $50\sim 300\,\mathrm{kb}$ 之间。$\mathrm{YAC}$ 是含酵母染色体上必需的端粒、着丝点和复制起始序列的人工构建载体，能携带 $400\,\mathrm{kb}$ 左右的 $\mathrm{DNA}$ 片段。

:::definition{label="柯斯质粒（黏粒）"}
柯斯质粒（cosmid）又称黏粒载体：人工构建，含 $\lambda$ $\mathrm{DNA}$ 的 $\mathrm{Cos}$ 序列和质粒复制子。自身一般只有 $5\sim 7\,\mathrm{kb}$，外源片段最大可达 $45\,\mathrm{kb}$。
:::

:::definition{label="BAC"}
细菌人工染色体（$\mathrm{BAC}$）：以大肠埃希菌 $\mathrm{F}$ 质粒（$\mathrm{F}$ 因子）为基础构建，外源片段 $50\sim 300\,\mathrm{kb}$。
:::

:::definition{label="YAC"}
酵母人工染色体（$\mathrm{YAC}$）：含酵母染色体必需的端粒、着丝点和复制起始序列，能携带 $400\,\mathrm{kb}$ 左右的 $\mathrm{DNA}$ 片段。
:::

### （二）表达载体用来表达外源基因

表达载体（expression vector）是指具有调控表达克隆基因所需的转录和翻译信号的载体，用来在宿主细胞中表达外源基因，依据其宿主细胞的不同可分为原核表达载体（prokaryotic expression vector）和真核表达载体（eukaryotic expression vector），它们的区别主要在于为外源基因提供的表达元件。利用表达载体提供的表达元件也可在体外建立无细胞表达体系（cell-free expression system），根据表达载体上的表达元件决定提供原核细胞提取物或真核细胞提取物，其基本工作原理相同于在细胞内。下面简介原核表达载体和真核表达载体的结构特点。

:::definition{label="表达载体"}
表达载体（expression vector）：具有调控表达克隆基因所需的转录和翻译信号，用来在宿主细胞中表达外源基因。按宿主分为原核表达载体和真核表达载体，差别主要在提供的表达元件。
:::

#### 1. 原核表达载体

该类载体用于在原核细胞中表达外源基因，除了具有克隆载体的基本特征外，还有供外源基因有效转录和翻译的原核表达调控序列，如启动子、核糖体结合位点即 $\mathrm{SD}$ 序列（Shine-Dalgarno sequence）、转录终止序列等。原核表达载体的基本组成如图19-14 所示。目前应用最广泛的原核表达载体是 $E.\ coli$ 表达载体。

:::definition{label="SD 序列是核糖体结合位点"}
$\mathrm{SD}$ 序列（Shine-Dalgarno sequence）即核糖体结合位点，供原核核糖体认 $\mathrm{mRNA}$、开始翻译。第十六章翻译起始用过同一户；本节它是表达载体框架上的一块砖。
:::

::figure{src="/images/biochemistry/textbook/p0402_01.png" caption="图19-14　原核表达载体的基本框架" alt="从左到右：R 调节序列，P 启动子（-35 区 TTGACA 与 -10 区 TATAAT），SD，编码序列（起始密码子 ATG/GTG/TTG 至终止密码子 TAA/TGA/TAG），TT 转录终止序列，ampR。上方箭头标转录方向"}

:::pitfall{label="ampR 在图19-14 里是筛选标志，不是编码目的蛋白"}
框架最右侧的 $\mathit{amp}^{\mathrm{R}}$ 让宿主在氨苄西林下存活。目的蛋白写在「编码序列」那一段。把抗性基因当成外源蛋白，表达产物就答错了。
:::

#### 2. 真核表达载体

该类载体用于在真核细胞中表达外源基因，除了具备克隆载体的基本特征外，所提供给外源基因的表达元件是来自真核细胞的。质粒真核表达载体一般具备的特点包括：①含有必不可少的原核序列，如复制起点、抗生素抗性基因、多克隆位点（$\mathrm{MCS}$）等，用于真核表达载体在细菌中复制及阳性克隆的筛选；②真核表达调控元件，如真核启动子、增强子、转录终止序列、$\mathrm{poly}(\mathrm{A})$ 加尾信号等；③真核细胞复制起始序列，用于载体或基因表达框架在真核细胞中的复制；④真核细胞药物抗性基因，用于载体在真核细胞中的阳性筛选。图19-15 显示的是真核表达载体的基本组成。根据真核宿主细胞的不同，真核表达载体可分为酵母表达载体、昆虫表达载体和哺乳类细胞表达载体等。

:::definition{label="真核表达载体四类元件"}
①原核序列（复制起点、抗生素抗性、$\mathrm{MCS}$），为了在细菌里扩增和筛选；②真核表达调控元件（真核启动子、增强子、转录终止、$\mathrm{poly}(\mathrm{A})$ 加尾信号）；③真核细胞复制起始序列；④真核细胞药物抗性基因，用于在真核细胞里做阳性筛选。
:::

:::

图19-15 注写明这一点。把真核表达一律答成「必须插入染色体」，瞬时转染和染色体整合两户并了。
:::

差别在给外源基因提供的表达元件，不是「一个有抗性一个没有」。
:::

## 三、重组DNA技术的基本原理及操作步骤

完整 $\mathrm{DNA}$ 克隆过程包括五大步骤（图19-16）：①目的 $\mathrm{DNA}$ 的分离获取（分）；②载体的选择与准备（选）；③目的 $\mathrm{DNA}$ 与载体的连接（连）；④重组 $\mathrm{DNA}$ 转入受体细胞（转）；⑤重组体的筛选及鉴定（筛）。

:::definition{label="DNA 克隆五大步：分、选、连、转、筛"}
①分：目的 $\mathrm{DNA}$ 的分离获取；②选：载体的选择与准备；③连：目的 $\mathrm{DNA}$ 与载体连接；④转：重组 $\mathrm{DNA}$ 转入受体细胞；⑤筛：重组体的筛选及鉴定。图19-16 画的是以质粒为载体的全过程，电子版缺失，用这五步默写。
:::

:::note{label="电子版缺失"}
图19-16　以质粒为载体的 $\mathrm{DNA}$ 克隆过程。图源为 $0$ 字节，不嵌入 `src`。正文按「分、选、连、转、筛」五步写清；图19-17 只画连接这一步（黏－平端），不要把图19-17 当成五步总图。
:::

### （一）目的DNA的分离获取是DNA克隆的第一步

分离获取目的 $\mathrm{DNA}$ 的方法主要有以下几种。

#### 1. 化学合成法

该方法可直接合成目的 $\mathrm{DNA}$ 片段，通常用于小分子肽类基因的合成，其前提是已知基因的核苷酸序列，或能根据氨基酸序列推导出相应核苷酸序列。一般先合成两条完全互补的单链，经退火形成双链，然后克隆于载体。

:::pitfall{label="化学合成不是随便写一条链就去连接"}
两条互补单链退火成双链之后才克隆。只合成一条链，没有模板互补，后文限制酶切和黏端配对都没有分子。
:::

#### 2. 从基因组文库和 cDNA 文库中获取目的 DNA

基因组文库（genomic library）是指把某种生物基因组全部遗传信息通过克隆载体贮存在一个转化子集中。$\mathrm{cDNA}$ 文库（cDNA library）是以 $\mathrm{mRNA}$ 为模板，包含着细胞全部 $\mathrm{mRNA}$ 信息的转化子集。基因文库没有目录来引导我们哪个克隆含有特定的序列，因此，克隆工作的最后一步是从文库中调取所感兴趣的基因。

:::definition{label="基因组文库"}
基因组文库（genomic library）：把某种生物基因组全部遗传信息通过克隆载体贮存在一个转化子集中。含内含子、调控区、重复序列等基因组里实际有的东西。
:::

:::definition{label="cDNA 文库"}
$\mathrm{cDNA}$ 文库（cDNA library）：以 $\mathrm{mRNA}$ 为模板，包含着细胞全部 $\mathrm{mRNA}$ 信息的转化子集。反映的是该细胞当时表达的转录本，不是基因组全套。文库没有目录，最后一步是从中调取所感兴趣的基因。
:::

:::compare{title="基因组文库 vs cDNA 文库"}
| | 模板／来源 | 装的是什么 | 典型后续 |
|--|------------|------------|----------|
| 基因组文库 | 基因组 $\mathrm{DNA}$ | 该生物全部遗传信息 | 基因组克隆；$\lambda$ 的 $\mathrm{EMBL}$ 置换型适用 |
| $\mathrm{cDNA}$ 文库 | $\mathrm{mRNA}\rightarrow\mathrm{cDNA}$ | 该细胞全部 $\mathrm{mRNA}$ 信息 | 编码序列克隆；$\lambda\mathrm{gt}$ 插入型适用；原核表达真核基因也走 $\mathrm{cDNA}$ |

要内含子或调控区，走基因组；要可读框在大肠埃希菌里表达，走 $\mathrm{cDNA}$。
:::

:::pitfall{label="cDNA 文库不是基因组的缩小版"}
它以 $\mathrm{mRNA}$ 为模板，只覆盖当时表达的基因，而且已经切掉内含子。写成「cDNA 文库＝基因组文库去掉重复序列」，原核不能加工真核基因组基因那一条就失去理由。
:::

#### 3. PCR 法

$\mathrm{PCR}$ 是一种高效特异的体外扩增 $\mathrm{DNA}$ 的方法（见第十八章）。使用 $\mathrm{PCR}$ 法的前提是：已知待扩增目的基因或 $\mathrm{DNA}$ 片段两端的序列，并根据该序列合成适当引物。

#### 4. 其他方法

除上述方法外，也可采用酵母单杂交系统克隆 $\mathrm{DNA}$ 结合蛋白的编码基因，或用酵母双杂交系统克隆特异性相互作用蛋白质的编码基因。

### （二）载体的选择与准备是根据目的DNA片段决定的

进行 $\mathrm{DNA}$ 克隆的目的主要有二：一是获取目的 $\mathrm{DNA}$ 片段，二是获取目的 $\mathrm{DNA}$ 片段所编码的蛋白质。针对第一种目的，通常选用克隆载体；针对第二种目的，需选择表达载体。另外，选择载体时还要考虑目的 $\mathrm{DNA}$ 的大小、受体细胞的种类和来源等因素（表19-3）。除了上述需要考虑的因素外，选择载体时还需要注意载体内应有适宜的单一酶切位点或 $\mathrm{MCS}$，以便根据目的 $\mathrm{DNA}$ 片段，对载体进行适当的酶切处理。总之，在重组 $\mathrm{DNA}$ 技术中，载体的选择、准备和改进极富技术性，目的不同，操作基因的性质不同，载体的选择和改建方法也不同。

**表19-3　不同载体的克隆容量及适宜宿主细胞**

| 载体 | 插入 $\mathrm{DNA}$ 片段的适宜长度 | 宿主细胞 |
|------|----------------------------------|----------|
| 质粒 | $<5\sim 10\,\mathrm{kb}$ | 细菌，酵母 |
| $\lambda$ 噬菌体 $\mathrm{DNA}$ 载体 | 约 $20\,\mathrm{kb}$ | 细菌 |
| 黏粒 | 约 $50\,\mathrm{kb}$ | 细菌 |
| $\mathrm{BAC}$ | 约 $400\,\mathrm{kb}$ | 细菌 |
| $\mathrm{YAC}$ | 约 $3\,\mathrm{Mb}$ | 酵母 |

注：$\mathrm{BAC}$：bacterial artificial chromosome，细菌人工染色体；$\mathrm{YAC}$：yeast artificial chromosome，酵母人工染色体。

:::pitfall{label="表19-3 的容量和「其他克隆载体」正文不是同一组数字"}
正文：黏粒外源最大 $45\,\mathrm{kb}$，$\mathrm{BAC}$ 为 $50\sim 300\,\mathrm{kb}$，$\mathrm{YAC}$ 约 $400\,\mathrm{kb}$。表19-3：黏粒约 $50\,\mathrm{kb}$，$\mathrm{BAC}$ 约 $400\,\mathrm{kb}$，$\mathrm{YAC}$ 约 $3\,\mathrm{Mb}$。两处都是本版原文。答题看题干引用的是表19-3 还是柯斯／$\mathrm{BAC}$／$\mathrm{YAC}$ 那段定义，不要擅自「统一」成一组。
:::

### （三）目的DNA与载体连接形成重组DNA

依据目的 $\mathrm{DNA}$ 和线性化载体末端的特点，可采用不同的连接策略。主要连接策略如下。

#### 1. 黏端连接

依靠酶切后的黏性末端进行连接，连接效率较高。根据酶切策略不同可有以下几种黏端连接策略。

**（1）单一相同黏端连接**　如果目的 $\mathrm{DNA}$ 序列两端和线性化载体两端为同一限制性核酸内切酶（或同切点酶，或同尾酶）切割所致，那么所产生的黏端完全相同。这种单一相同黏端连接时会有三种连接结果：载体自连（载体自身环化）、载体与目的 $\mathrm{DNA}$ 连接和 $\mathrm{DNA}$ 片段自连。可见，这种连接的缺点是：容易出现载体自身环化、目的 $\mathrm{DNA}$ 可以双向插入载体（即正向和反向插入）及多拷贝连接现象，从而给后续筛选增加了困难。采用碱性磷酸酶预处理线性化载体 $\mathrm{DNA}$，使之去磷酸化，可有效减少载体自身环化。目的 $\mathrm{DNA}$ 如果反向插入载体，影响外源基因的表达。

:::definition{label="碱性磷酸酶减少载体自连"}
预处理线性化载体，使之去磷酸化，可有效减少载体自身环化。表19-1 碱性磷酸酶「切除末端磷酸基团」就是为这一步准备的。载体两端没了 $5'$ 磷酸，连接酶不能把空载体重新封成环；目的片段两端仍带磷酸，可以接到载体上。
:::

**（2）不同黏端连接**　如果用两种不同的限制性核酸内切酶分别切割载体和目的 $\mathrm{DNA}$，则可使载体和目的 $\mathrm{DNA}$ 的两端均形成两个不同的黏端，这样可以让外源 $\mathrm{DNA}$ 定向插入载体。这种使目的基因按特定方向插入载体的克隆方法称为定向克隆（directed cloning）。定向克隆具有方向性和准确性，可有效避免载体自连和 $\mathrm{DNA}$ 片段的反向插入和多拷贝现象。

:::definition{label="定向克隆"}
定向克隆（directed cloning）：用两种不同限制酶分别切载体和目的 $\mathrm{DNA}$，两端形成两个不同黏端，使目的基因按特定方向插入载体。有方向性和准确性，可有效避免载体自连、反向插入和多拷贝。
:::

:::compare{title="单一相同黏端 vs 不同黏端（定向克隆）"}
| | 酶切 | 插入方向 | 自连／多拷贝 |
|--|------|----------|--------------|
| 单一相同黏端 | 同一酶（或同尾、同切点） | 可正向可反向 | 容易自连、多拷贝；载体可去磷酸化补救自连 |
| 不同黏端 | 两种不同酶 | 定向 | 有效避免自连、反向插入、多拷贝 |

要表达可读框，优先定向克隆，免得反向插入把表达弄没。
:::

**（3）通过其他措施产生黏端的连接**　常用的在末端为平端的目的 $\mathrm{DNA}$ 片段制造黏端的方法有：①人工接头法：用化学合成法获得含限制性核酸内切酶位点的平端双链寡核苷酸接头（adaptor 或 linker），将此接头连接在目的 $\mathrm{DNA}$ 的平端上，然后用相同的限制性核酸内切酶切割人工接头产生黏端，进而连接到载体上。②加同聚物尾法：用末端转移酶将某一核苷酸（如 $\mathrm{dC}$）逐一加到目的 $\mathrm{DNA}$ 的 $3'$-端羟基上，形成同聚物尾（如同聚 $\mathrm{dC}$ 尾）；同时又将与之互补的另一核苷酸（如 $\mathrm{dG}$）加到载体 $\mathrm{DNA}$ 的 $3'$-端羟基上，形成与目的 $\mathrm{DNA}$ 末端互补的同聚物尾（如同聚 $\mathrm{dG}$ 尾）。两个互补的同聚物尾均为黏端，因而可高效率地连接到一起。③$\mathrm{PCR}$ 法：针对目的 $\mathrm{DNA}$ 的 $5'$-端和 $3'$-端设计一对特异引物，在每条引物的 $5'$-端分别加上不同的限制性核酸内切酶位点，然后以目的 $\mathrm{DNA}$ 为模板，经 $\mathrm{PCR}$ 扩增便可得到带有引物序列的目的 $\mathrm{DNA}$，再用相应限制性核酸内切酶切割 $\mathrm{PCR}$ 产物，产生黏端，随后便可与带有相同黏端的线性化载体进行有效连接。另外，在使用 $\mathrm{Taq}\ \mathrm{DNA}$ 聚合酶进行 $\mathrm{PCR}$ 时，扩增产物的 $3'$-端一般多出一个不配对的腺苷酸残基（$\mathrm{A}$）而成为黏端，这样的 $\mathrm{PCR}$ 产物可直接与 $3'$-端带不配对的胸腺嘧啶残基（$\mathrm{T}$）的线性化载体（$\mathrm{T}$ 载体）连接，此即 $\mathrm{T}$-$\mathrm{A}$ 克隆。

:::definition{label="T-A 克隆"}
$\mathrm{Taq}\ \mathrm{DNA}$ 聚合酶扩增产物的 $3'$ 端一般多出一个不配对的 $\mathrm{A}$，成为黏端；可直接与 $3'$ 端带不配对 $\mathrm{T}$ 的线性化载体（$\mathrm{T}$ 载体）连接。此即 $\mathrm{T}$-$\mathrm{A}$ 克隆。
:::

:::pitfall{label="T-A 克隆依赖 Taq 多出的 A，不是所有 PCR 产物都能直接进 T 载体"}
教材写的是使用 $\mathrm{Taq}\ \mathrm{DNA}$ 聚合酶时，$3'$ 端一般多出一个不配对 $\mathrm{A}$。换成具有校正活性、产物为平端的聚合酶，这一户就不成立，要改走平端连接或加接头。
:::

#### 2. 平端连接

若目的 $\mathrm{DNA}$ 两端和线性化载体两端均为平端，则两者之间也可在 $\mathrm{DNA}$ 连接酶的作用下进行连接，其连接结果有三种：载体自连、载体与目的 $\mathrm{DNA}$ 连接和 $\mathrm{DNA}$ 片段自连，但连接效率都较低。为了提高连接效率，可采用提高连接酶用量、延长连接时间、降低反应温度、增加 $\mathrm{DNA}$ 片段与载体的摩尔比等措施。平端连接同样存在载体自身环化、目的 $\mathrm{DNA}$ 双向插入和多拷贝现象等缺点。

#### 3. 黏-平端连接

黏－平末端连接是指目的 $\mathrm{DNA}$ 和载体通过一端为黏端、另一端为平端的方式进行连接。以该方式连接时，目的 $\mathrm{DNA}$ 被定向插入载体（定向克隆）（图19-17），连接效率介于黏端和平端连接之间。可采用提高平端连接效率的措施提高该方式的连接效率。

:::definition{label="黏-平端连接是定向克隆，效率居中"}
一端黏端、一端平端。目的 $\mathrm{DNA}$ 被定向插入载体。效率介于黏端连接与平端连接之间。提高效率的办法同平端：加酶、延时、降温、提高片段／载体摩尔比。图19-17 标出 $\mathrm{T}4$ $\mathrm{DNA}$ 连接酶、$15^{\circ}\mathrm{C}$。
:::

::figure{src="/images/biochemistry/textbook/p0404_01.png" caption="图19-17　黏-平端连接" alt="目的基因与环状载体分别经限制性内切酶切开；T4 DNA 连接酶在 15℃ 把切开的目的片段与线性化载体连成环状重组体"}

:::insight{label="图19-17 画的是切、连、成环，温度写在 15℃"}
目的基因和载体都经限制酶处理，然后 $\mathrm{T}4$ $\mathrm{DNA}$ 连接酶在 $15^{\circ}\mathrm{C}$ 连成重组体。画面是连接步骤，不是图19-16 的五步总流程。$15^{\circ}\mathrm{C}$ 对应「降低反应温度」这一条提效措施。
:::

:::compare{title="三种连接：效率、方向、自连"}
| | 效率 | 能否定向 | 自连／反向／多拷贝 |
|--|------|----------|-------------------|
| 黏端（相同） | 高 | 否，可双向 | 三种产物都有；载体可去磷酸化 |
| 黏端（不同） | 高 | 是，定向克隆 | 有效避免 |
| 平端 | 低 | 否 | 三种产物都有 |
| 黏－平端 | 介于黏端与平端之间 | 是，定向克隆 | 一端黏一端平，方向被钉住 |

效率从高到低大致是：黏端 $>$ 黏－平端 $>$ 平端。
:::

:::pitfall{label="不要把图19-17 说成 DNA 克隆全过程"}
全过程是图19-16（电子版缺失）。图19-17 只覆盖「连」这一步，而且是黏－平端这一种策略。
:::

### （四）重组DNA转入宿主细胞使其得以扩增

重组 $\mathrm{DNA}$ 转入宿主细胞后才能得到扩增。理想的宿主细胞通常是 $\mathrm{DNA}/$蛋白质降解系统和／或重组酶缺陷株，这样的宿主细胞称为工程细胞。工程细胞具有较强的接纳外源 $\mathrm{DNA}$ 的能力，可保证外源 $\mathrm{DNA}$ 长期、稳定地遗传或表达。将重组 $\mathrm{DNA}$ 导入宿主细胞的常用方法有如下几种。

:::definition{label="工程细胞"}
理想宿主通常是 $\mathrm{DNA}/$蛋白质降解系统和／或重组酶缺陷株，称为工程细胞。接纳外源 $\mathrm{DNA}$ 的能力较强，可保证外源 $\mathrm{DNA}$ 长期、稳定地遗传或表达。
:::

#### 1. 转化

转化（transformation）是指将外源 $\mathrm{DNA}$ 直接导入细菌、真菌的过程，例如，重组质粒导入大肠埃希菌。然而，只有细胞膜通透性增加的细菌才容易接受外源 $\mathrm{DNA}$，这样的细菌称作感受态细胞（competent cells）。实现转化的方法包括化学诱导法（如氯化钙法）、电穿孔（electroporation）法等。此外，将质粒 $\mathrm{DNA}$ 直接导入酵母细胞以及将黏粒 $\mathrm{DNA}$ 导入细菌的过程也称作转化。

:::definition{label="转化（本节）"}
转化（transformation）：将外源 $\mathrm{DNA}$ 直接导入细菌、真菌。例：重组质粒导入大肠埃希菌。质粒导入酵母、黏粒导入细菌，也称作转化。
:::

:::definition{label="感受态细胞"}
感受态细胞（competent cells）：细胞膜通透性增加、容易接受外源 $\mathrm{DNA}$ 的细菌。方法：化学诱导（如氯化钙法）、电穿孔等。
:::

:::pitfall{label="本节转化不是第一节自然界的转化作用"}
第一节转化作用：处于敏化状态的细菌主动摄取环境 $\mathrm{DNA}$，是横向基因转移。本节转化：人工制备感受态，把重组分子打进去。名字相同，户头不同。
:::

#### 2. 转染

转染（transfection）是指将外源 $\mathrm{DNA}$ 直接导入真核细胞（酵母除外）的过程。常用的转染方法包括化学方法（如磷酸钙共沉淀法、脂质体融合法等）和物理方法（如显微注射法、电穿孔法等）。此外，将噬菌体 $\mathrm{DNA}$ 直接导入受体细菌的过程也称作转染。

:::definition{label="转染"}
转染（transfection）：将外源 $\mathrm{DNA}$ 直接导入真核细胞（酵母除外）。化学方法：磷酸钙共沉淀、脂质体融合等；物理方法：显微注射、电穿孔等。将噬菌体 $\mathrm{DNA}$ 直接导入受体细菌，也称作转染。
:::

:::pitfall{label="酵母走转化，不是转染；噬菌体 DNA 进细菌叫转染"}
教材把酵母排除在转染之外，质粒进酵母仍叫转化。噬菌体 $\mathrm{DNA}$ 不经包装、直接导入细菌，术语却是转染。不要按「原核都叫转化、真核都叫转染」一刀切。
:::

#### 3. 感染

感染（infection）是指以病毒颗粒作为外源 $\mathrm{DNA}$ 运载体导入宿主细胞的过程。例如，以噬菌体、逆转录病毒、腺病毒等 $\mathrm{DNA}$ 作为载体构建的重组 $\mathrm{DNA}$ 分子，经包装形成病毒颗粒后进入宿主细胞。

:::definition{label="感染"}
感染（infection）：以病毒颗粒作为外源 $\mathrm{DNA}$ 运载体导入宿主细胞。噬菌体、逆转录病毒、腺病毒等载体构建的重组分子，经包装形成病毒颗粒后进入宿主。
:::

:::compare{title="转化 vs 转染 vs 感染"}
| | 教材定义 | 例子 |
|--|----------|------|
| 转化 | 外源 $\mathrm{DNA}$ 直接导入细菌、真菌 | 质粒 $\rightarrow$ 大肠埃希菌或酵母；黏粒 $\rightarrow$ 细菌 |
| 转染 | 外源 $\mathrm{DNA}$ 直接导入真核细胞（酵母除外）；噬菌体 $\mathrm{DNA}$ 直接导入细菌也算 | 磷酸钙、脂质体、显微注射、电穿孔 |
| 感染 | 病毒颗粒当运载体 | 噬菌体、逆转录病毒、腺病毒包装后进入 |

第一节的转导是自然界噬菌体携带细菌 $\mathrm{DNA}$；本节感染是人工包装的重组病毒颗粒。
:::

:::pitfall{label="裸噬菌体 DNA 进细菌叫转染，包装成颗粒进细菌叫感染"}
差在「有没有衣壳当运载体」。写成「噬菌体相关一律转导」，第一节转导和本节感染、转染会并成一句。
:::

### （五）多种方式进行重组体的筛选与鉴定

重组 $\mathrm{DNA}$ 分子导入宿主细胞后，可通过载体携带的选择标记或目的 $\mathrm{DNA}$ 片段的序列特征进行筛选和鉴定，从而获得含重组 $\mathrm{DNA}$ 分子的宿主细胞。筛选和鉴定方法主要有遗传标志筛选法、序列特异性筛选法、亲和筛选法等。

#### 1. 借助载体上的遗传标志进行筛选

载体上通常携带可供重组体筛选的遗传标志，如抗生素抗性基因等，据此可对含重组 $\mathrm{DNA}$ 的宿主细胞进行筛选。

**（1）利用抗生素抗性标志筛选**　将含有某种抗生素抗性基因的重组载体转化宿主细胞，然后在含相应抗生素的培养液中培养此细胞，若细胞能在这种条件下生长，则说明细胞中至少应含有导入的载体，但是否是插入目的 $\mathrm{DNA}$ 的载体，还需要进一步鉴定。若细胞中没有载体，则被抗生素杀死。

:::definition{label="抗生素抗性只证明有载体"}
在相应抗生素下能生长：细胞中**至少**含有导入的载体；是否插入了目的 $\mathrm{DNA}$，还要进一步鉴定。没有载体的细胞被抗生素杀死。
:::

:::pitfall{label="抗性平板上的菌落不是自动等于重组体"}
空载体也有抗性基因，一样长。$\mathrm{pUC}18$ 的 $\mathit{amp}^{\mathrm{R}}$ 只能挡住「没质粒的细胞」。有没有插入，要靠蓝白、插入失活、酶切或杂交。
:::

**（2）利用基因的插入失活／插入表达特性筛选**　针对某些带有抗生素抗性基因的载体，当目的 $\mathrm{DNA}$ 插入抗性基因后，可使该抗性基因失活。如果还以这种抗生素抗性进行筛选，不能生长的细胞应该是含重组 $\mathrm{DNA}$ 的细胞。以这种方式筛选时，通常载体上携带一个以上筛选标志基因。例如 $\mathrm{pBR}322$ 质粒含有氨苄西林抗性基因（$\mathit{amp}^{\mathrm{R}}$）和四环素抗性基因（$\mathit{tet}^{\mathrm{R}}$），如将目的 $\mathrm{DNA}$ 插入 $\mathit{tet}^{\mathrm{R}}$ 中，$\mathit{tet}^{\mathrm{R}}$ 失活，含重组 $\mathrm{DNA}$ 的细胞只能在含氨苄西林的培养基中生长，而不能在含四环素的培养基中生长（图19-18）。

:::definition{label="插入失活"}
目的 $\mathrm{DNA}$ 插入某个抗性基因后使该抗性基因失活。若还用这种抗生素筛选，**不能生长**的细胞才是含重组 $\mathrm{DNA}$ 的细胞。通常载体上有一个以上筛选标志。
:::

:::definition{label="pBR322 的 Amp 抗、Tet 敏"}
$\mathrm{pBR}322$ 有 $\mathit{amp}^{\mathrm{R}}$ 和 $\mathit{tet}^{\mathrm{R}}$。目的 $\mathrm{DNA}$ 插入 $\mathit{tet}^{\mathrm{R}}$（图19-18 用 $\mathrm{BamH}\,\mathrm{I}$ 切在 $\mathit{tet}^{\mathrm{R}}$ 上）后：含重组 $\mathrm{DNA}$ 的细胞能在氨苄西林培养基上生长，不能在四环素培养基上生长。
:::

**（3）利用标志补救筛选**　标志补救（marker rescue）是指当载体上的标志基因在宿主细胞中表达时，宿主细胞通过与标志基因表达产物互补弥补自身的相应缺陷，从而在相应选择培养基中存活。利用该策略可初步筛选含有载体的宿主细胞。例如，$S.\ cerevisiae$ 酵母菌株，因 $\mathit{trp}1$ 基因突变而不能在缺少色氨酸的培养基上生长，当转入带有功能性 $\mathit{trp}1$ 基因的重组载体后，转化菌则能在色氨酸缺陷的培养基上生长。标志补救也可用于外源基因导入哺乳类细胞后阳性克隆的初筛，例如，当将带有二氢叶酸还原酶（$\mathrm{DHFR}$）基因（$\mathit{dhfr}$）的真核表达载体导入 $\mathit{dhfr}$ 缺陷的哺乳类细胞后，则可使细胞在无胸腺嘧啶的培养基中存活，从而筛选出带有载体的克隆（$\mathrm{DHFR}$ 可催化二氢叶酸还原成四氢叶酸，后者可用于合成胸腺嘧啶）。

利用 $\alpha$ 互补筛选携带重组质粒的细菌也是一种标志补救筛选方法。关于 $\alpha$ 互补原理在本节「重组 $\mathrm{DNA}$ 技术中常用载体」部分已有介绍（图19-13）。

:::definition{label="标志补救"}
标志补救（marker rescue）：载体上的标志基因在宿主中表达，其产物弥补宿主自身的相应缺陷，使细胞在相应选择培养基中存活。用来初步筛选含有载体的宿主细胞。
:::

**（4）利用噬菌体的包装特性进行筛选**　$\lambda$ 噬菌体的一个重要遗传特性就是其在包装时对 $\lambda\mathrm{DNA}$ 大小有严格要求，只有当 $\lambda\mathrm{DNA}$ 的长度达到其野生型长度的 $75\%\sim 105\%$ 时，方能包装形成有活性的噬菌体颗粒，进而在培养基上生长时呈现清晰的噬斑，而不含外源 $\mathrm{DNA}$ 的单一噬菌体载体 $\mathrm{DNA}$ 因其长度太小而不能被包装成有活性的噬菌体颗粒，故不能感染细菌形成噬斑。根据此原理可初步筛出带有重组 $\lambda$ 噬菌体载体的克隆。

:::definition{label="λ 包装窗口 75%～105%"}
只有 $\lambda\mathrm{DNA}$ 长度达到野生型的 $75\%\sim 105\%$ 才能包装成有活性的噬菌体颗粒，在培养基上形成清晰噬斑。空的单一噬菌体载体太短，不能包装，不形成噬斑。有噬斑 $\approx$ 初步认为带了重组插入。
:::

#### 2. 序列特异性筛选

根据序列特异性筛选的方法包括限制性核酸内切酶酶切法、$\mathrm{PCR}$ 法、核酸杂交法、$\mathrm{DNA}$ 测序法等。

**（1）酶切法**　针对初筛为阳性的克隆，提取其重组 $\mathrm{DNA}$，以合适的限制性核酸内切酶进行酶切消化，经琼脂糖凝胶电泳便可判断有无目的 $\mathrm{DNA}$ 片段的插入及插入片段的大小。同时，根据酶切位点在插入片段内部的不对称分布，还可鉴定插入 $\mathrm{DNA}$ 片段在载体上的方向；也可用多种限制性核酸内切酶制作并分析插入片段的酶切图谱。

**（2）PCR 法**　利用序列特异性引物，经 $\mathrm{PCR}$ 扩增，可鉴定出含有目的 $\mathrm{DNA}$ 的阳性克隆。如果利用克隆位点两侧载体序列设计引物进行 $\mathrm{PCR}$ 扩增，再结合序列分析，便能可靠地证实插入片段的方向、序列和可读框的正确性。

**（3）核酸杂交法**　该方法可直接筛选和鉴定含有目的 $\mathrm{DNA}$ 的克隆。常用方法是菌落或噬斑原位杂交法，其基本过程如图19-19 所示：将转有外源 $\mathrm{DNA}$ 的菌落或噬斑影印到硝酸纤维素膜上，细菌裂解后所释放出的 $\mathrm{DNA}$ 将被吸附在膜上，将膜与标记的核酸探针杂交，通过检测探针的存在即可鉴定出含有重组 $\mathrm{DNA}$ 的克隆。根据核酸探针标记物的不同，可通过放射自显影、化学发光、酶作用于底物显色等方法来显示探针的存在位置，也就是阳性克隆存在的位置。

:::definition{label="菌落或噬斑核酸原位杂交"}
把转有外源 $\mathrm{DNA}$ 的菌落或噬斑影印到硝酸纤维素膜上，裂解后 $\mathrm{DNA}$ 吸附于膜，与标记核酸探针杂交；探针所在位置即阳性克隆位置。显示可用放射自显影、化学发光或酶底物显色。
:::

::figure{src="/images/biochemistry/textbook/p0406_01.png" caption="图19-19　菌落或噬斑核酸原位杂交筛选重组体" alt="琼脂平板上的菌落或噬斑影印到硝酸纤维素膜；溶菌、中和并固定 DNA；带标记的探针杂交、漂洗、曝光或显色，膜上出现阳性斑点；再依据阳性斑点回平板挑出对应菌落或噬斑"}

:::insight{label="图19-19 是膜上的斑点对回平板，不是 Amp／Tet 影印"}
流程：影印 $\rightarrow$ 溶菌中和固定 $\rightarrow$ 探针杂交漂洗曝光／显色 $\rightarrow$ 按阳性斑点回琼脂平板挑克隆。认的是序列互补，不是抗性生死，也不是 $\mathrm{X}$-gal 颜色。
:::

**（4）DNA 测序法**　该法是最准确的鉴定目的 $\mathrm{DNA}$ 的方法。针对已知序列，通过 $\mathrm{DNA}$ 测序可明确具体序列和可读框的正确性；针对未知 $\mathrm{DNA}$ 片段，可揭示其序列，为进一步研究提供依据。

#### 3. 亲和筛选法

亲和筛选法的前提是重组 $\mathrm{DNA}$ 进入宿主细胞后能够表达出其编码产物。常用的亲和筛选法的原理是基于抗原－抗体反应或配体－受体反应。一般做法与上述菌落或噬斑核酸原位杂交相似，只是被检测的靶分子换成吸附于硝酸纤维素膜上的蛋白质，检测探针换成标记的抗体／抗原或配体／受体。

:::definition{label="亲和筛选看的是表达产物"}
前提：重组 $\mathrm{DNA}$ 能表达编码产物。原理：抗原－抗体或配体－受体。操作像原位杂交，但膜上是蛋白质，探针是标记的抗体／抗原或配体／受体。
:::

| | 看什么 | 阳性 | 本版图 |
|--|--------|------|--------|
| 插入失活 | 第二个抗性基因还在不在 | $\mathrm{Amp}$ 主平板有、$\mathrm{Tet}$ 平板无 | 图19-18，$\mathrm{pBR}322$ |

靶分子从 $\mathrm{DNA}$ 换成蛋白质，探针从核酸换成抗体或配体。写成「杂交筛蛋白质」，第十八章印迹分户也会乱。

## 四、克隆基因的表达

采用重组 $\mathrm{DNA}$ 技术还可进行目的基因的表达，实现生命科学研究、医药或商业目的，这是基因工程的最终目标。基因表达涉及正确的基因转录、$\mathrm{mRNA}$ 翻译、适当的转录后及翻译后的加工过程，这些过程对于不同的表达体系是不同的。克隆目的基因，进而大量地表达出有特殊意义的蛋白质，已成为重组 $\mathrm{DNA}$ 技术中一个专门的领域，这就是重组蛋白质表达。在蛋白质表达领域，表达体系的建立包括表达载体的构建、宿主细胞的建立及表达产物的分离、纯化等技术和策略。基因工程中的表达系统包括原核和真核表达体系。

### （一）原核表达体系

细菌，特别是大肠埃希菌（$E.\ coli$），是当前采用最多的原核表达体系，其优点是培养方法简单、迅速、经济而又适合大规模生产工艺。

#### 1. 原核表达载体的必备条件

运用 $E.\ coli$ 表达有用的蛋白质必须使构建的表达载体符合下述标准：①含 $E.\ coli$ 适宜的选择标志；②具有能调控转录、产生大量 $\mathrm{mRNA}$ 的强启动子，如 $lac$、$tac$ 启动子或其他启动子序列；③含适当的翻译控制序列，如核糖体结合位点和翻译起始点等；④含有合理设计的 $\mathrm{MCS}$，以确保目的基因按一定方向与载体正确连接。

#### 2. 大肠埃希菌表达体系的优点

$E.\ coli$ 表达体系在实际应用中有很多的优点，诸如：①高表达水平：$E.\ coli$ 能够迅速复制和表达外源蛋白质，从而可获得高产量的目标蛋白质。②简单易操作，成本低：$E.\ coli$ 是一种相对简单的微生物，容易控制培养条件，操作简单，培养成本低廉。③易于遗传操作：$E.\ coli$ 基因组结构简单，构建载体相对容易。④基因组和调控机制清晰：$E.\ coli$ 的基因组已被广泛研究，对其基因组结构、调控机制和代谢途径有较清晰的了解，便于通过基因工程手段更好地调控目标蛋白质的表达。

#### 3. 大肠埃希菌表达体系的缺点

$E.\ coli$ 表达体系在实际应用中尚存在一些不足之处，诸如：①由于缺乏转录后加工机制，对于真核基因来说，$E.\ coli$ 表达体系只能表达经逆转录合成的 $\mathrm{cDNA}$ 编码产物，不宜表达从基因组 $\mathrm{DNA}$ 上扩增的基因；②由于缺乏适当的翻译后加工机制，真核基因的表达产物在 $E.\ coli$ 表达体系中往往不能被正确地折叠或糖基化修饰；③真核基因表达的蛋白质常常形成不溶性的包涵体（inclusion body），欲使其具有活性尚需进行复杂的变性－复性处理；④很难用 $E.\ coli$ 表达体系大量表达可溶性蛋白质。

:::definition{label="包涵体"}
包涵体（inclusion body）：真核基因在大肠埃希菌中表达时常常形成的不溶性蛋白质聚集体。要有活性，需复杂的变性－复性处理。后文表达策略还强调：若产物是包涵体，分离纯化后仍要复性或折叠。
:::

:::pitfall{label="不要写成大肠埃希菌完全不能表达真核蛋白"}
它可以表达 $\mathrm{cDNA}$ 编码产物，只是不宜表达带内含子的基因组基因，且加工和可溶性往往不好。重组人胰岛素能成为第一个基因工程产品，靠的就是原核体系能做出蛋白质，不是「原核不能做真核蛋白」。
:::

### （二）真核表达体系

真核表达体系除与原核表达体系有相似之处外，一般还常有自己的特点。真核表达载体通常含有供真核细胞使用的选择标记、启动子、转录和翻译终止信号、$\mathrm{mRNA}$ 的 $\mathrm{poly}(\mathrm{A})$ 加尾信号或染色体整合位点等。

真核表达体系有酵母、昆虫、哺乳动物类细胞等，不仅可以表达克隆的 $\mathrm{cDNA}$，也可表达从真核基因组 $\mathrm{DNA}$ 扩增的基因。哺乳动物细胞内表达的蛋白质通常经过适当的修饰，确保其功能和稳定性。这些蛋白质也会在细胞内特定区域进行适当的分布和积累，以维持细胞的正常生理活动。因此，采用真核表达体系的优势是：①具有转录后加工机制；②具有翻译后修饰机制；③表达的蛋白质不形成包涵体（酵母除外）。当然，操作技术难、费时、费钱是其缺点。

:::definition{label="真核表达三条优势和一条代价"}
优势：①转录后加工；②翻译后修饰；③不形成包涵体（酵母除外）。代价：操作技术难、费时、费钱。哺乳动物细胞内表达的蛋白质通常经适当修饰，并在特定区域分布积累。
:::

:::pitfall{label="「不形成包涵体」要加括号：酵母除外"}
三条优势的第③条教材自己加了「酵母除外」。把真核一律写成可溶、无包涵体，酵母表达那一户会判错。
:::

:::compare{title="原核表达 vs 真核表达"}
| | 大肠埃希菌 | 真核（酵母／昆虫／哺乳类） |
|--|------------|------------------------------|
| 培养与成本 | 简单、迅速、经济、可大规模 | 难、费时、费钱 |
| 真核基因组基因 | 不宜（无转录后加工） | 可以 |
| $\mathrm{cDNA}$ | 可以，但加工常不对 | 可以，哺乳类修饰较合适 |
| 包涵体 | 真核蛋白常形成，要复性 | 一般不形成（酵母除外） |
| 可溶性大量表达 | 很难 | 相对利于得到有功能蛋白 |

选体系时先问：要不要糖基化／正确折叠，能不能接受包涵体复性，有没有成本和规模压力。
:::

### （三）重组蛋白质的表达策略

在实际工作中，蛋白质表达策略颇不一致，需要根据目的不同制定不同的重组蛋白质表达策略。有时表达目的是获得蛋白质抗原，以便制备抗体，此时要求表达的蛋白质或多肽具有抗原性，同时要求表达产物易于分离、纯化。较好的策略是为目的基因连上一个编码标签肽的序列，从而表达为融合蛋白质（fusion protein）。谷胱甘肽-$s$-转移酶（$\mathrm{GST}$）标签系统就是一种常用的策略。但是，即使是非常小的标签也会影响它们所附着的蛋白质的性质，从而影响研究结果。例如，标签可能会对蛋白质的折叠产生不利影响。如果在设计融合基因时，在目的基因和标签序列之间加入适当的裂解位点，则很容易从表达的融合分子中去除标签序列。巧妙地设计标签序列还可大大方便表达产物的分离纯化。

如果表达的蛋白质是为了用于生物化学、细胞生物学研究或临床诊断，除分离纯化方便外，更重要的是考虑蛋白质的功能和生物学活性。一般表达的可溶性蛋白质往往具有特异的生物学功能，如果表达的是包涵体形式，还需要在分离纯化后进行复性或折叠。

:::definition{label="融合蛋白质与标签"}
为目的基因连上编码标签肽的序列，表达为融合蛋白质（fusion protein）。常用策略之一是谷胱甘肽-$s$-转移酶（$\mathrm{GST}$）标签。目的若是做抗原、制备抗体：要有抗原性，并易于分离纯化。
:::

:::definition{label="标签可能影响折叠，裂解位点可去掉标签"}
即使非常小的标签也会影响所附着蛋白质的性质，例如对折叠产生不利影响。在目的基因和标签之间加入适当裂解位点，则很容易从融合分子中去除标签。巧妙设计标签还可大大方便分离纯化。
:::

:::pitfall{label="融合标签不是「越大越好、永远不用切」"}
教材先说标签方便纯化，紧接着说即使很小也会影响性质、可能妨碍折叠，并给出裂解位点去标签。只答「加 $\mathrm{GST}$ 就能纯化」，活性那一问会丢。
:::

:::memory{label="本节必背要点"}
- 重组 $\mathrm{DNA}$ 技术＝分子克隆＝$\mathrm{DNA}$ 克隆＝基因工程。$1972$ 年第一个重组 $\mathrm{DNA}$ 分子。
- 最重要工具酶是限制性核酸内切酶，与甲基化酶构成限制修饰体系；重组操作通常指Ⅱ型。
- 克隆载体三件：$\mathrm{ori}$、选择标志、$\mathrm{MCS}$。$\mathrm{pUC}18$：$2\,690\,\mathrm{bp}$，$\mathit{amp}^{\mathrm{R}}$，$\mathrm{ori}$，$\mathrm{MCS}$（图19-12）。
- 蓝白＝$\alpha$ 互补：空载体蓝，插入白。不要写反。
- 原核表达框架：$\mathrm{R}$-$\mathrm{P}$-$\mathrm{SD}$-编码-$\mathrm{TT}$-抗性（图19-14）。真核还要 $\mathrm{poly}(\mathrm{A})$ 等，图19-15 电子版缺失。
- 五步：分、选、连、转、筛。图19-16 缺失；图19-17 是黏－平端连接（$\mathrm{T}4$ 连接酶 $15^{\circ}\mathrm{C}$）。
- 黏端效率高，平端低，黏－平端居中且可定向。相同黏端有自连、反向、多拷贝；碱性磷酸酶减自连。
- 基因组文库装全基因组；$\mathrm{cDNA}$ 文库装该细胞 $\mathrm{mRNA}$ 信息。文库无目录。
- 插入失活（$\mathrm{pBR}322$ 的 $\mathrm{Amp}^{\mathrm{R}}\mathrm{Tet}^{\mathrm{S}}$）≠ 蓝白 ≠ 核酸杂交。抗性只证明有载体。标志补救：$\mathit{trp}1$、$\mathrm{DHFR}$、$\alpha$ 互补。
- 大肠埃希菌：快、便宜、高表达；无真核加工，常出包涵体，要复性。融合标签方便纯化，但可能影响折叠；裂解位点可去掉标签。
