# 第二节　蛋白质的分子结构

第一节把原料写成 $\mathrm{L}$-$\alpha$-氨基酸，肽键连成肽。本节把同一条肽链摊成四个层次：氨基酸排列顺序是一级结构，$\alpha$-螺旋、$\beta$-折叠、$\beta$-转角和 $\Omega$-环是二级结构，整条肽链的三维排布是三级结构，两条以上肽链再以亚基相配是四级结构。超二级结构、模体和结构域夹在二级与三级之间。不是每一种蛋白质都有四级结构。第三节才写结构与功能如何互证。

蛋白质分子是由许多氨基酸通过肽键相连形成的生物大分子。人体内具有生理功能的蛋白质大都是有序结构，每种蛋白质都有其一定的氨基酸种类、组成百分比、氨基酸排列顺序以及肽链空间的特定排布位置。因此由氨基酸排列顺序及肽链的空间排布等所构成的蛋白质分子结构，才真正体现蛋白质的个性，是每种蛋白质具有独特生理功能的结构基础。由于参与蛋白质生物合成的氨基酸有 $20$ 种，且蛋白质的分子量均较大，因此蛋白质的氨基酸排列顺序和空间位置几乎是无穷尽的，足以为人体多达数以万计的蛋白质提供各异的氨基酸序列和特定的空间结构，使蛋白质完成生命所赋予的数以千万计的生理功能。

:::definition{label="蛋白质分子结构是个性的结构基础"}
人体内具有生理功能的蛋白质大都是有序结构。每种蛋白质都有一定的氨基酸种类、组成百分比、氨基酸排列顺序以及肽链空间的特定排布位置。由氨基酸排列顺序及肽链的空间排布等所构成的分子结构，才真正体现蛋白质的个性，是独特生理功能的结构基础。
:::

$1952$ 年丹麦科学家 Linderstrom L. 建议将蛋白质复杂的分子结构分成 $4$ 个层次，即一级、二级、三级、四级结构，后三者统称为高级结构或空间构象（conformation）。蛋白质的空间构象涵盖了蛋白质分子中的每一原子在三维空间的相对位置，它们是蛋白质特有性质和功能的结构基础。但并非所有的蛋白质都有四级结构，由一条肽链形成的蛋白质只有一级、二级和三级结构，由 $2$ 条或 $2$ 条以上肽链形成的蛋白质才有四级结构。

:::definition{label="空间构象"}
空间构象（conformation）即高级结构，包括二级、三级、四级结构。它涵盖蛋白质分子中每一原子在三维空间的相对位置，是蛋白质特有性质和功能的结构基础。
:::

:::definition{label="四级结构不是每种蛋白质都有"}
由一条肽链形成的蛋白质只有一级、二级和三级结构；由 $2$ 条或 $2$ 条以上肽链形成的蛋白质才有四级结构。肌红蛋白没有四级结构，血红蛋白才有。
:::

:::compare{title="蛋白质结构的四个层次"}
| 层次 | 教材定义的对象 | 主要化学键 / 作用力 | 谁有、谁没有 |
|------|----------------|----------------------|--------------|
| 一级结构 | 从 $\mathrm{N}$-端至 $\mathrm{C}$-端的氨基酸排列顺序；二硫键位置也属一级结构 | 肽键；二硫键 | 所有蛋白质都有 |
| 二级结构 | 某一段肽链的局部空间结构，即主链骨架原子的相对空间位置，不涉及侧链构象 | 主链氢键 | 局部即可出现，一条链上可有多种、多个 |
| 三级结构 | 整条肽链中全部氨基酸残基的相对空间位置 | 疏水作用、盐键、氢键、范德华力；二硫键参与稳定 | 有完整折叠的单链就有 |
| 四级结构 | 各亚基的空间排布及亚基接触部位的布局和相互作用 | 亚基间主要是氢键和离子键 | 两条或两条以上肽链才有 |
:::

:::concept{term="先问有几条肽链，再问四级结构在不在"}
看见“蛋白质结构”，先不要从 $\alpha$-螺旋直接跳到功能。一条肽链：一级、二级、三级就收口。两条及以上、每条都有完整三级结构，才谈亚基和四级结构。把肌红蛋白听成四聚体，或把血红蛋白的一个 $\alpha$ 亚基听成已经能运输氧，后面的例子会对错层次。
:::

## 一、氨基酸的排列顺序决定蛋白质的一级结构

蛋白质一级结构是理解蛋白质结构、作用机制以及生理功能的必要基础。在蛋白质分子中，从 $\mathrm{N}$-端至 $\mathrm{C}$-端的氨基酸排列顺序称为蛋白质一级结构（protein primary structure）。蛋白质一级结构中的主要化学键是肽键；此外，蛋白质分子中所有二硫键的位置也属于一级结构范畴。牛胰岛素是第一个被测定一级结构的蛋白质分子，由英国化学家 Sanger F. 于 $1953$ 年完成，因此他于 $1958$ 年获得诺贝尔化学奖。

:::definition{label="蛋白质一级结构"}
蛋白质一级结构（protein primary structure）是分子中从 $\mathrm{N}$-端至 $\mathrm{C}$-端的氨基酸排列顺序。主要化学键是肽键；所有二硫键的位置也属于一级结构范畴。它是理解结构、作用机制以及生理功能的必要基础。
:::

图1-8 为牛胰岛素的一级结构，胰岛素有 $\mathrm{A}$ 和 $\mathrm{B}$ 二条多肽链，$\mathrm{A}$ 链有 $21$ 个氨基酸残基，$\mathrm{B}$ 链有 $30$ 个氨基酸残基。如果把氨基酸序列（amino acid sequence）标上数码，应以氨基末端为 $1$ 号，依次向羧基末端排列。牛胰岛素分子中有 $3$ 个二硫键，$1$ 个位于 $\mathrm{A}$ 链内，称为链内二硫键，由 $\mathrm{A}$ 链的第 $6$ 位和第 $11$ 位半胱氨酸的巯基脱氢而形成，另 $2$ 个二硫键位于 $\mathrm{A}$、$\mathrm{B}$ 两链间（图1-8），称为链间二硫键。

:::definition{label="牛胰岛素的一级结构"}
牛胰岛素有 $\mathrm{A}$、$\mathrm{B}$ 两条多肽链：$\mathrm{A}$ 链 $21$ 个残基，$\mathrm{B}$ 链 $30$ 个残基。编号从氨基末端为 $1$ 号，向羧基末端排列。$3$ 个二硫键：$\mathrm{A}6$—$\mathrm{A}11$ 为链内二硫键，另 $2$ 个为 $\mathrm{A}$、$\mathrm{B}$ 链间二硫键。它是第一个被测定一级结构的蛋白质，Sanger F. 于 $1953$ 年完成，$1958$ 年获诺贝尔化学奖。
:::

:::note{label="图1-8 电子版缺失"}
教材图1-8 为牛胰岛素的一级结构，标出 $\mathrm{A}21$、$\mathrm{B}30$ 及三处二硫键。数字切片 `p0042_01.png` 为 $0$ 字节，本节不引用该文件。$\mathrm{A}$ 链 $21$、$\mathrm{B}$ 链 $30$、链内 $\mathrm{A}6$—$\mathrm{A}11$、两条链间二硫键的正文仍按教材保留。
:::

体内种类繁多的蛋白质，其一级结构各不相同，一级结构是蛋白质空间构象和特异生物学功能的基础。然而，随着对蛋白质结构研究的深入，已认识到蛋白质一级结构并不是决定蛋白质空间构象的唯一因素。目前已知一级结构的蛋白质数量已相当可观，并且还以更快的速度增加。国际互联网有若干重要的蛋白质数据库（Updated Protein Database），例如 EMBL（European Molecular Biology Laboratory Data Library）、Genbank（Genetic Sequence Databank）和 PIR（Protein Identification Resource Sequence Database）等，收集了大量最新的蛋白质一级结构及其他资料，为蛋白质结构与功能的深入研究提供了便利。

:::definition{label="一级结构是基础，但不是空间构象的唯一决定因素"}
一级结构是蛋白质空间构象和特异生物学功能的基础。教材同时写明：一级结构并不是决定空间构象的唯一因素。后面分子伴侣、折叠条件都要从这一句长出来。
:::

:::note{label="一级结构数据库"}
教材点名的蛋白质数据库包括 EMBL、Genbank 和 PIR，收集大量最新的蛋白质一级结构及其他资料。
:::

:::pitfall{label="二硫键的位置算一级结构，不要把它只写成三级结构的稳定因素"}
肽键是一级结构的主要化学键；所有二硫键的位置也属于一级结构范畴。三级结构里二硫键再作为稳定构象的共价键出现。两本账都要留：位置是序列信息，成键后才去稳三维。
:::

:::keypoint{label="胰岛素一级结构记 A21、B30、三对二硫键"}
- 两条链：$\mathrm{A}21$、$\mathrm{B}30$。
- 编号从 $\mathrm{N}$-端 $1$ 号数到 $\mathrm{C}$-端。
- 链内：$\mathrm{A}6$—$\mathrm{A}11$；另两条为链间二硫键。
- 第一个被测定一级结构的蛋白质：$1953$ 年 Sanger。
:::

## 二、多肽链的局部有规则重复的主链构象为蛋白质二级结构

蛋白质二级结构（protein secondary structure）是指蛋白质分子中某一段肽链的局部空间结构，也就是该段肽链主链骨架原子的相对空间位置，并不涉及氨基酸残基侧链的构象。所谓肽链主链骨架原子即 $\mathrm{N}$（氨基氮原子）、$\mathrm{C}_\alpha$（$\alpha$-碳原子）和 $\mathrm{C}$（羰基碳原子）$3$ 个原子依次重复排列。蛋白质二级结构主要包括 $\alpha$-螺旋、$\beta$-折叠、$\beta$-转角和 $\Omega$-环。由于蛋白质的分子量硕大，因此，一个蛋白质分子可含有多种二级结构或多个同种二级结构，而且在蛋白质分子内空间上相邻的 $2$ 个以上的二级结构还可协同完成特定的功能。

:::definition{label="蛋白质二级结构"}
蛋白质二级结构（protein secondary structure）是某一段肽链的局部空间结构，即该段主链骨架原子的相对空间位置，并不涉及氨基酸残基侧链的构象。主链骨架原子为 $\mathrm{N}$、$\mathrm{C}_\alpha$、$\mathrm{C}$ 依次重复排列。主要包括 $\alpha$-螺旋、$\beta$-折叠、$\beta$-转角和 $\Omega$-环。
:::

:::note{label="无规卷曲不要顶替教材的 Ω-环"}
教材本节列出的四种是 $\alpha$-螺旋、$\beta$-折叠、$\beta$-转角和 $\Omega$-环。肽链中没有确定规律、也不形成上述有规则氢键网络的松散区段，习惯上称为无规卷曲（random coil）。它不是与 $\Omega$-环互相替换的“第四种”：$\Omega$-环有希腊字母 $\Omega$ 那样的特定形状，总出现在球状蛋白表面，以亲水残基为主；无规卷曲只是“没有规则重复”。考试若问教材列出的二级结构种类，先答这四种。
:::

:::definition{label="无规卷曲"}
无规卷曲（random coil）指肽链中没有规则重复的主链构象、也不形成 $\alpha$-螺旋或 $\beta$-折叠那种周期性氢键的松散区段。它仍是主链的局部走向，但不属于教材点名的 $\alpha$-螺旋、$\beta$-折叠、$\beta$-转角、$\Omega$-环这四种有特征形貌的二级结构。
:::

### （一）参与肽键形成的 6 个原子构成一个肽单元

$20$ 世纪 $30$ 年代末，Pauling L. 和 Corey R.B. 应用 $\mathrm{X}$ 射线衍射技术研究氨基酸和寡肽的晶体结构，其目的是要获得一组标准键长和键角，以推导肽的构象，最终提出了肽单元（peptide unit）概念。参与肽键的 $6$ 个原子 $\mathrm{C}_{\alpha 1}$、$\mathrm{C}$、$\mathrm{O}$、$\mathrm{N}$、$\mathrm{H}$、$\mathrm{C}_{\alpha 2}$ 位于同一平面，$\mathrm{C}_{\alpha 1}$ 和 $\mathrm{C}_{\alpha 2}$ 在平面上所处的位置为反式（trans）构型，此同一平面上的 $6$ 个原子构成了所谓的肽单元（图1-9）。其中肽键（$\mathrm{C}-\mathrm{N}$）的键长为 $0.132\,\mathrm{nm}$，该键长介于 $\mathrm{C}-\mathrm{N}$ 的单键长（$0.149\,\mathrm{nm}$）和双键长（$0.127\,\mathrm{nm}$）之间，所以有一定程度双键性能，不能自由旋转。而 $\mathrm{C}_\alpha$ 分别与 $\mathrm{N}$ 和 $\mathrm{C}$（羰基碳）相连的键都是典型的单键，可以自由旋转，$\mathrm{N}$ 与 $\mathrm{C}_\alpha$ 的键角以 $\phi$ 表示，$\mathrm{C}_\alpha$ 与 $\mathrm{C}$ 的键旋转角度以 $\psi$ 表示（图1-9）。也正由于肽单元上 $\mathrm{C}_\alpha$ 原子所连的两个单键的自由旋转角度，决定了两个相邻的肽单元平面的相对空间位置。

:::definition{label="肽单元"}
肽单元（peptide unit）由参与肽键的 $6$ 个原子 $\mathrm{C}_{\alpha 1}$、$\mathrm{C}$、$\mathrm{O}$、$\mathrm{N}$、$\mathrm{H}$、$\mathrm{C}_{\alpha 2}$ 构成，它们位于同一平面。$\mathrm{C}_{\alpha 1}$ 与 $\mathrm{C}_{\alpha 2}$ 在平面上为反式（trans）构型。Pauling 与 Corey 在 $20$ 世纪 $30$ 年代末由氨基酸和寡肽晶体的 $\mathrm{X}$ 射线衍射提出。
:::

:::definition{label="肽键的部分双键性"}
肽键 $\mathrm{C}-\mathrm{N}$ 键长 $0.132\,\mathrm{nm}$，介于单键 $0.149\,\mathrm{nm}$ 与双键 $0.127\,\mathrm{nm}$ 之间，有一定程度双键性能，不能自由旋转。这是肽单元共面的结构原因。
:::

:::definition{label="二面角 φ 与 ψ"}
$\mathrm{C}_\alpha$ 与 $\mathrm{N}$、与羰基碳相连的键都是典型单键，可以自由旋转。$\mathrm{N}-\mathrm{C}_\alpha$ 的转角以 $\phi$ 表示，$\mathrm{C}_\alpha-\mathrm{C}$ 的转角以 $\psi$ 表示。相邻两个肽单元平面的相对空间位置，由这两个角决定。
:::

::figure{src="/images/biochemistry/textbook/p0043_01.png" caption="图1-9　肽键与肽单元。六个原子共面；N—Cα 的转角为 φ，Cα—C 的转角为 ψ。" alt="三个连续的浅蓝肽单元平面，平面上标 Cα、C、O、N、H 和侧链 R，相邻平面之间用弯曲箭头标 ψ 和 φ"}

:::cause-effect{title="肽键为什么把六个原子锁在一个平面上"}
- **因** $\mathrm{C}-\mathrm{N}$ 键长 $0.132\,\mathrm{nm}$，介于单键与双键之间，有部分双键性，不能自由旋转
- **果** $\mathrm{C}_{\alpha 1}$、$\mathrm{C}$、$\mathrm{O}$、$\mathrm{N}$、$\mathrm{H}$、$\mathrm{C}_{\alpha 2}$ 共面，成为肽单元；主链走向只剩下 $\phi$、$\psi$ 两个单键可转
:::

:::pitfall{label="能转的是 Cα 两侧的单键，不是肽键本身"}
把肽键听成“单键、整条主链随便转”，$\alpha$-螺旋的氢键几何就没有平面可依。$\phi$、$\psi$ 转的是肽单元与肽单元之间的夹角，不是把平面拆开。
:::

### （二）α-螺旋是常见的蛋白质二级结构

Pauling L. 和 Corey R.B. 根据实验数据提出了两种肽链局部主链原子的空间构象的分子模型，称为 $\alpha$-螺旋（$\alpha$-helix）和 $\beta$-折叠（$\beta$-pleated sheet），它们是蛋白质二级结构的主要形式。在 $\alpha$-螺旋结构（图1-10）中，多肽链的主链围绕中心轴作有规律的螺旋式上升，螺旋的走向为顺时针方向，即所谓右手螺旋，其 $\psi$ 为 $-47^{\circ}$，$\phi$ 为 $-57^{\circ}$，氨基酸侧链伸向螺旋外侧。每 $3.6$ 个氨基酸残基螺旋上升一圈（即旋转 $360^{\circ}$），螺距为 $0.54\,\mathrm{nm}$。$\alpha$-螺旋的每个肽键的 $\mathrm{N}-\mathrm{H}$ 和第四个肽键的羰基氧形成氢键，氢键的方向与螺旋长轴基本平行。

:::definition{label="α-螺旋"}
$\alpha$-螺旋（$\alpha$-helix）中，主链围绕中心轴作有规律的螺旋式上升，走向为顺时针，即右手螺旋。$\psi=-47^{\circ}$，$\phi=-57^{\circ}$，侧链伸向螺旋外侧。每 $3.6$ 个氨基酸残基上升一圈（旋转 $360^{\circ}$），螺距 $0.54\,\mathrm{nm}$。每个肽键的 $\mathrm{N}-\mathrm{H}$ 和第四个肽键的羰基氧形成氢键，氢键方向与螺旋长轴基本平行。
:::

:::note{label="图1-10 电子版缺失"}
教材图1-10 为 $\alpha$-螺旋。数字切片 `p0044_01.png` 至 `p0044_05.png` 均为 $0$ 字节，本节不引用。残基 $3.6$ 个/圈、螺距 $0.54\,\mathrm{nm}$、右手螺旋、氢键与长轴平行的正文仍按教材保留。
:::

:::derivation{title="α-螺旋的氢键怎么对上“第四个肽键”"}
主链上肽键依次编号。第 $n$ 个肽键的 $\mathrm{N}-\mathrm{H}$ 与沿链再数四个肽键处的羰基氧形成氢键，即残基 $i$ 的羰基氧与残基 $i+4$ 的氨基氢配对。氢键几乎平行于螺旋轴，把相邻圈锁在一起。没有这条主链氢键，就只剩一条可以转的肽链，不是 $\alpha$-螺旋。
:::

一般而言，$20$ 种氨基酸均可参与组成 $\alpha$-螺旋结构，但是 Ala、Glu、Leu 和 Met 比 Gly、Pro、Ser 及 Tyr 更常见。在蛋白质表面存在的 $\alpha$-螺旋，常具有两亲特点，其亲水性和疏水性氨基酸残基有规律地集中排列在与对称轴平行的两个侧面，使之能在极性或非极性环境中存在。这种两亲 $\alpha$-螺旋可见于血浆脂蛋白、多肽激素和钙调蛋白激酶等。肌红蛋白和血红蛋白分子中有许多肽链段落呈 $\alpha$-螺旋结构。毛发的角蛋白、肌组织的肌球蛋白以及血凝块中的纤维蛋白，它们的多肽链几乎全长都卷曲成 $\alpha$-螺旋。数条 $\alpha$-螺旋状的多肽链可缠绕起来，形成缆索，从而增强其机械强度，并具有可伸缩性（弹性）。

:::definition{label="两亲 α-螺旋"}
蛋白质表面的 $\alpha$-螺旋常具两亲特点：亲水性和疏水性氨基酸残基有规律地集中排列在与对称轴平行的两个侧面，使之能在极性或非极性环境中存在。可见于血浆脂蛋白、多肽激素和钙调蛋白激酶等。
:::

:::compare{title="α-螺旋里谁更常见、谁更少见"}
| 更常见 | 更少见 | 几乎全长都是 $\alpha$-螺旋的例子 |
|--------|--------|----------------------------------|
| Ala、Glu、Leu、Met | Gly、Pro、Ser、Tyr | 毛发角蛋白、肌球蛋白、血凝块中的纤维蛋白 |
:::

:::insight{label="侧链在外侧，氢键在主链上"}
$\alpha$-螺旋的氢键是主链 $\mathrm{N}-\mathrm{H}$ 对主链羰基氧，侧链只伸向外侧去选择环境。把 $\alpha$-螺旋听成“靠侧链氢键维持”，两亲螺旋和后面“侧链妨碍螺旋”那一段会对错对象。
:::

### （三）β-折叠使多肽链形成片层结构

$\beta$-折叠与 $\alpha$-螺旋的形状截然不同，呈折纸状。在 $\beta$-折叠结构（图1-11）中，多肽链充分伸展，每个肽单元以 $\mathrm{C}_\alpha$ 为旋转点，依次折叠成锯齿状结构，氨基酸残基侧链交替地位于锯齿状结构的上下方。所形成的锯齿状结构一般比较短，只含 $5\sim 8$ 个氨基酸残基。一条肽链内的若干肽段的锯齿状结构可平行排列，分子内相距较远的两个肽段可通过折叠而形成相同走向，也可通过回折而形成相反走向。两条肽链走向相同时肽链重复节段为 $0.65\,\mathrm{nm}$，相反时肽链重复节段为 $0.70\,\mathrm{nm}$，并通过肽链间的肽键羰基氧和亚氨基氢形成氢键，来稳固 $\beta$-折叠结构，蚕丝蛋白几乎都是 $\beta$-折叠结构，许多蛋白质既有 $\alpha$-螺旋又有 $\beta$-折叠结构。

:::definition{label="β-折叠"}
$\beta$-折叠（$\beta$-pleated sheet）呈折纸状。多肽链充分伸展，每个肽单元以 $\mathrm{C}_\alpha$ 为旋转点，依次折叠成锯齿状，侧链交替地位于上下方。锯齿状结构一般较短，只含 $5\sim 8$ 个氨基酸残基。肽链走向相同（平行）时重复节段 $0.65\,\mathrm{nm}$，相反（反平行）时 $0.70\,\mathrm{nm}$。稳固靠肽链间肽键的羰基氧和亚氨基氢形成的氢键。
:::

:::note{label="图1-11 电子版缺失"}
教材图1-11 为 $\beta$-折叠。对应页数字切片为 $0$ 字节，本节不引用。平行 $0.65\,\mathrm{nm}$、反平行 $0.70\,\mathrm{nm}$、蚕丝蛋白几乎全是 $\beta$-折叠的正文仍按教材保留。
:::

:::compare{title="α-螺旋与 β-折叠"}
| 项目 | $\alpha$-螺旋 | $\beta$-折叠 |
|------|---------------|--------------|
| 主链走向 | 围绕中心轴右手螺旋上升 | 充分伸展，锯齿状折纸 |
| 每段残基数 | 每圈 $3.6$ 个 | 每段一般 $5\sim 8$ 个 |
| 特征距离 | 螺距 $0.54\,\mathrm{nm}$ | 平行重复 $0.65\,\mathrm{nm}$，反平行 $0.70\,\mathrm{nm}$ |
| 氢键 | 螺旋内，每个肽键 $\mathrm{N}-\mathrm{H}$ 对第四个肽键羰基氧，与长轴基本平行 | 肽链之间（或肽段之间），羰基氧对亚氨基氢 |
| 侧链 | 伸向螺旋外侧 | 交替位于锯齿上下方 |
| 教材例 | 角蛋白、肌球蛋白、纤维蛋白；肌红蛋白和血红蛋白中有许多螺旋段 | 蚕丝蛋白几乎都是 $\beta$-折叠 |
:::

### （四）β-转角和 Ω-环存在于球状蛋白质中

除 $\alpha$-螺旋和 $\beta$-折叠外，蛋白质二级结构还包括 $\beta$-转角（$\beta$-turn）（图1-12）和 $\Omega$-环（$\Omega$-loop）。$\beta$-转角常发生于肽链进行 $180^{\circ}$ 回折时的转角上。$\beta$-转角通常由 $4$ 个氨基酸残基组成，其第一个残基的羰基氧（$\mathrm{O}$）与第四个残基的氨基氢（$\mathrm{H}$）可形成氢键。$\beta$-转角的结构较特殊，第二个残基常为脯氨酸，其他常见残基有甘氨酸、天冬氨酸、天冬酰胺和色氨酸。有 $2$ 种类型的 $\beta$-转角，分别是转角Ⅰ和转角Ⅱ。Ⅰ型 $\beta$-转角和Ⅱ型 $\beta$-转角非常相似，只是其中肽键的二面角 $\psi$ 和 $\phi$ 角有所不同。Ⅱ型 $\beta$-转角的第 $3$ 个残基往往是甘氨酸。$\Omega$-环是存在于球状蛋白质中的一种二级结构。这类肽段形状像希腊字母 $\Omega$，所以称 $\Omega$-环。$\Omega$-环这种结构总是出现在蛋白质分子的表面，而且以亲水残基为主，在分子识别中可能起重要作用。

:::definition{label="β-转角"}
$\beta$-转角（$\beta$-turn）常发生于肽链 $180^{\circ}$ 回折的转角上，通常由 $4$ 个氨基酸残基组成，第一个残基的羰基氧与第四个残基的氨基氢可形成氢键。第二个残基常为脯氨酸，其他常见残基有甘氨酸、天冬氨酸、天冬酰胺和色氨酸。分转角Ⅰ和转角Ⅱ，差别在 $\psi$、$\phi$；Ⅱ型第 $3$ 个残基往往是甘氨酸。
:::

:::definition{label="Ω-环"}
$\Omega$-环（$\Omega$-loop）是球状蛋白质中的一种二级结构，肽段形状像希腊字母 $\Omega$。总是出现在蛋白质分子表面，以亲水残基为主，在分子识别中可能起重要作用。
:::

:::note{label="图1-12 电子版缺失"}
教材图1-12 为 $\beta$-转角。对应页数字切片为 $0$ 字节，本节不引用。$4$ 个残基、$1$—$4$ 氢键、第 $2$ 位常为脯氨酸的正文仍按教材保留。
:::

:::pitfall{label="β-转角的氢键是第 1 残基羰基对第 4 残基氨基，不要写成 α-螺旋那一套 i 到 i+4 的圈内氢键"}
两者都说到“第四”，对象不同。$\alpha$-螺旋是沿螺旋轴把相邻圈锁住；$\beta$-转角是把回折的短环锁住。$\Omega$-环更不是无规卷曲的别名。
:::

### （五）氨基酸残基的侧链影响二级结构的形成

蛋白质二级结构是以一级结构为基础的。一段肽链其氨基酸残基的侧链适合形成 $\alpha$-螺旋或 $\beta$-折叠，它就会出现相应的二级结构。例如一段肽链有多个谷氨酸或天冬氨酸残基相邻，则在 $\mathrm{pH}\,7.0$ 时这些残基的游离羧基都带负电荷，彼此相斥，妨碍 $\alpha$-螺旋的形成。同样，多个碱性氨基酸残基在一肽段内，由于正电荷相斥，也妨碍 $\alpha$-螺旋的形成。此外天冬酰胺、苏氨酸、半胱氨酸的侧链较大，如果这些氨基酸在一级结构中非常接近，也会影响 $\alpha$-螺旋形成。脯氨酸的 $\mathrm{N}$ 原子在刚性的五元环中，其形成的肽键 $\mathrm{N}$ 原子上没有 $\mathrm{H}$，所以不能形成氢键，结果肽链走向转折，不形成 $\alpha$-螺旋。形成 $\beta$-折叠的肽段，氨基酸残基的侧链要比较小，能容许两条肽段彼此靠近。

:::definition{label="侧链对二级结构的限制"}
二级结构以一级结构为基础。侧链电荷相斥、侧链过大、脯氨酸不能提供氢键，都会妨碍 $\alpha$-螺旋；$\beta$-折叠还要求侧链比较小，以便两条肽段靠近。
:::

:::compare{title="哪些侧链妨碍 α-螺旋"}
| 情况 | 机制 | 结果 |
|------|------|------|
| 多个 Glu 或 Asp 相邻，$\mathrm{pH}\,7.0$ | 游离羧基都带负电荷，彼此相斥 | 妨碍 $\alpha$-螺旋 |
| 多个碱性残基在同一肽段 | 正电荷相斥 | 妨碍 $\alpha$-螺旋 |
| Asn、Thr、Cys 在一级结构中非常接近 | 侧链较大 | 影响 $\alpha$-螺旋形成 |
| Pro | $\mathrm{N}$ 在刚性五元环中，肽键 $\mathrm{N}$ 上没有 $\mathrm{H}$，不能形成氢键 | 肽链走向转折，不形成 $\alpha$-螺旋 |
| 要形成 $\beta$-折叠 | 侧链须比较小 | 容许两条肽段彼此靠近 |
:::

:::insight{label="脯氨酸打断螺旋，是因为它提供不了那根主链氢键"}
不是“脯氨酸疏水所以不能螺旋”。肽键氮上没有氢，氢键做不成，走向只好转折——这与它在 $\beta$-转角第 $2$ 位常见是同一件事。
:::

## 三、多肽链进一步折叠成蛋白质三级结构

### （一）三级结构是指整条肽链中全部氨基酸残基的相对空间位置

蛋白质三级结构（protein tertiary structure）是指整条肽链中全部氨基酸残基的相对空间位置，也就是整条肽链所有原子在三维空间的排布位置。已知球状蛋白质的三级结构有某些共同特征，如折叠成紧密的球状或椭球状；含有多种二级结构并具有明显的折叠层次，即一级结构上相邻的二级结构常在三级结构中彼此靠近并形成超二级结构，进一步折叠成相对独立的三维空间结构；以及疏水侧链常分布在分子内部等。

:::definition{label="蛋白质三级结构"}
蛋白质三级结构（protein tertiary structure）是整条肽链中全部氨基酸残基的相对空间位置，即整条肽链所有原子在三维空间的排布位置。二级结构不涉及侧链构象；三级结构把侧链也算进来。
:::

:::note{label="球状蛋白质三级结构的共同特征"}
折叠成紧密的球状或椭球状；含有多种二级结构并有明显折叠层次——一级结构上相邻的二级结构常在三级结构中彼此靠近并形成超二级结构，再折叠成相对独立的三维结构；疏水侧链常分布在分子内部。
:::

肌红蛋白是由 $153$ 个氨基酸残基构成的单一肽链蛋白质，含有 $1$ 个血红素辅基。图1-13 显示肌红蛋白的三级结构。肌红蛋白分子中 $\alpha$-螺旋占 $75\%$，构成 $\mathrm{A}$ 至 $\mathrm{H}$ $8$ 个螺旋区，两个螺旋区之间有一段柔性连接肽，脯氨酸位于转角处。由于侧链 $\mathrm{R}$ 基团的相互作用，多肽链缠绕，形成一个球状分子（$4.5\,\mathrm{nm}\times 3.5\,\mathrm{nm}\times 2.5\,\mathrm{nm}$），球表面主要有亲水侧链，疏水侧链位于分子内部。蛋白质三级结构的形成和稳定主要靠次级键如疏水键、盐键、氢键和范德华力（van der Waals force）等（图1-14）。

:::definition{label="肌红蛋白的三级结构"}
肌红蛋白由 $153$ 个氨基酸残基构成单一肽链，含 $1$ 个血红素辅基。$\alpha$-螺旋占 $75\%$，构成 $\mathrm{A}$ 至 $\mathrm{H}$ $8$ 个螺旋区，螺旋区之间有柔性连接肽，脯氨酸位于转角处。分子大小约 $4.5\,\mathrm{nm}\times 3.5\,\mathrm{nm}\times 2.5\,\mathrm{nm}$，表面主要是亲水侧链，疏水侧链在内部。它是单链，没有四级结构。
:::

### （二）结构模体可由 2 个或 2 个以上二级结构肽段组成

结构模体（structural motif）是蛋白质分子中具有特定空间构象和特定功能的结构成分。一个模体总有其特征性的氨基酸序列，并发挥特殊的功能。一般而言，常见的结构模体可以有以下几种形式：$\alpha$-螺旋-$\beta$-转角（或环）-$\alpha$-螺旋模体（见于多种 $\mathrm{DNA}$ 结合蛋白）；链-$\beta$-转角-链（见于反平行 $\beta$-折叠的蛋白质）；链-$\beta$-转角-$\alpha$-螺旋-$\beta$-转角-链模体（见于多种 $\alpha$-螺旋/$\beta$-折叠蛋白质）。在这些结构模体中，$\beta$-转角常为含 $3\sim 4$ 个氨基酸残基的片段；而环（loop）为较大的片段，常连接非规则的二级结构。

:::definition{label="结构模体"}
结构模体（structural motif）是蛋白质分子中具有特定空间构象和特定功能的结构成分。一个模体总有其特征性的氨基酸序列，并发挥特殊的功能。
:::

在许多蛋白质分子中，可由 $2$ 个或 $2$ 个以上具有二级结构的肽段在空间上相互接近，形成一个有规则的二级结构组合，称为超二级结构，此概念由 Rossman M.G. 于 $1973$ 年提出。目前已知的二级结构组合有 $\alpha\alpha$、$\beta\alpha\beta$、$\beta\beta$ 等几种形式（图1-15）。研究发现，$\alpha$-螺旋之间、$\beta$-折叠之间以及 $\alpha$-螺旋与 $\beta$-折叠之间的相互作用，主要是由非极性氨基酸残基参与的。

:::definition{label="超二级结构"}
超二级结构是 $2$ 个或 $2$ 个以上具有二级结构的肽段在空间上相互接近，形成的有规则的二级结构组合。Rossman M.G. 于 $1973$ 年提出。已知组合有 $\alpha\alpha$、$\beta\alpha\beta$、$\beta\beta$ 等。螺旋之间、折叠之间以及螺旋与折叠之间的相互作用，主要是由非极性氨基酸残基参与。
:::

:::note{label="图1-15 电子版缺失"}
教材图1-15 为蛋白质超二级结构与模体：（a）$\beta\alpha\beta$；（b）$\beta\beta$；（c）亮氨酸拉链；（d）$\alpha$-螺旋-环-$\alpha$-螺旋；（e）锌指结构。数字切片 `p0046_02.png`、`p0047_01.png` 为 $0$ 字节，本节不引用。下列模体的正文仍按教材保留。
:::

亮氨酸拉链（leucine zipper）（图1-15c）是出现在 $\mathrm{DNA}$ 结合蛋白和其他蛋白质中的一种结构模体。当来自同一个或不同多肽链的两个两用性的 $\alpha$-螺旋的疏水面（常含有亮氨酸残基）相互作用形成一个圈对圈的二聚体结构，亮氨酸有规律地每隔 $6$ 个氨基酸就出现一次，亮氨酸拉链常出现在真核生物 $\mathrm{DNA}$ 结合蛋白的 $\mathrm{C}$-端，往往与癌基因表达调控功能有关。

在许多钙结合蛋白分子中通常有一个结合钙离子的模体，它由螺旋-环-螺旋（helix-loop-helix）三个肽段组成（图1-15d），在环中有几个恒定的亲水侧链，侧链末端的氧原子通过氢键而结合钙离子。近年发现的锌指（zinc finger）结构也是一个常见的模体例子，它由 $1$ 个 $\alpha$-螺旋和 $2$ 个反平行的 $\beta$-折叠三个肽段组成（图1-15e），具有结合锌离子功能。该模体的 $\mathrm{N}$-端有 $1$ 对半胱氨酸残基，$\mathrm{C}$-端有 $1$ 对组氨酸残基，此 $4$ 个残基在空间上形成一个洞穴，恰好容纳 $1$ 个 $\mathrm{Zn}^{2+}$。由于 $\mathrm{Zn}^{2+}$ 可稳固模体中的 $\alpha$-螺旋结构，使此 $\alpha$-螺旋能镶嵌于 $\mathrm{DNA}$ 的大沟中，因此含锌指结构的蛋白质都能与 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 结合。可见结构模体的特征性空间构象是其特殊功能的结构基础。

:::definition{label="亮氨酸拉链"}
亮氨酸拉链（leucine zipper）出现在 $\mathrm{DNA}$ 结合蛋白和其他蛋白质中。两个两用性 $\alpha$-螺旋的疏水面（常含亮氨酸）相互作用，形成圈对圈的二聚体；亮氨酸有规律地每隔 $6$ 个氨基酸出现一次。常出现在真核生物 $\mathrm{DNA}$ 结合蛋白的 $\mathrm{C}$-端，往往与癌基因表达调控有关。
:::

:::definition{label="螺旋-环-螺旋（钙结合）"}
许多钙结合蛋白中，结合钙离子的模体由螺旋-环-螺旋三个肽段组成。环中有几个恒定的亲水侧链，侧链末端的氧原子通过氢键结合钙离子。
:::

:::definition{label="锌指"}
锌指（zinc finger）由 $1$ 个 $\alpha$-螺旋和 $2$ 个反平行的 $\beta$-折叠三个肽段组成，结合 $\mathrm{Zn}^{2+}$。$\mathrm{N}$-端 $1$ 对半胱氨酸，$\mathrm{C}$-端 $1$ 对组氨酸，四个残基形成洞穴容纳 $1$ 个 $\mathrm{Zn}^{2+}$。$\mathrm{Zn}^{2+}$ 稳固其中的 $\alpha$-螺旋，使之能镶嵌于 $\mathrm{DNA}$ 大沟，故含锌指的蛋白质都能与 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 结合。
:::

| 模体 | 二级结构组合 | 结合或功能 | 序列/残基特征 |
|------|--------------|------------|----------------|
| $\alpha$-螺旋-$\beta$-转角（或环）-$\alpha$-螺旋 | 螺旋-转角/环-螺旋 | 多种 $\mathrm{DNA}$ 结合蛋白 | — |
| 链-$\beta$-转角-链 | 反平行 $\beta$ | 反平行 $\beta$-折叠蛋白质 | — |

锌指先有洞穴接 $\mathrm{Zn}^{2+}$，再让螺旋嵌进 $\mathrm{DNA}$ 大沟；钙结合模体先有环上的氧去氢键结合钙。把它们听成“凡是含锌、含钙的蛋白质都是同一模体”，超二级结构那一张图会对错组合。
:::

### （三）结构域是三级结构层次上具有独立结构与功能的区域

分子量较大的蛋白质常可折叠成多个结构较为紧密且稳定的区域，并各行其功能，称为结构域（domain）。大多数结构域含有序列上连续的 $100\sim 200$ 个氨基酸残基，若用限制性蛋白酶水解，含多个结构域的蛋白质常分解出独立的结构域，而各结构域的构象可以基本不改变，并保持其功能。超二级结构则不具备这种特点。因此，结构域也可看作是球状蛋白质的独立折叠单位，有较为独立的三维空间结构。

例如，由 $2$ 个亚基构成的 $3$-磷酸甘油醛脱氢酶，每个亚基由 $2$ 个结构域组成，$\mathrm{N}$-端第 $1\sim 146$ 个氨基酸残基形成的第一个结构域能与 $\mathrm{NAD}^{+}$ 结合，第二个结构域（第 $147\sim 333$ 氨基酸残基）与底物 $3$-磷酸甘油醛结合（图1-16）。有些蛋白质各结构域之间接触较紧密，从结构上很难划分，因此，并非所有蛋白质的结构域都明显可分。

:::definition{label="结构域"}
结构域（domain）是分子量较大的蛋白质折叠成的多个结构较为紧密且稳定、并各行其功能的区域。大多数含序列上连续的 $100\sim 200$ 个氨基酸残基。限制性蛋白酶水解常可分解出独立结构域，构象基本不改变并保持功能。它是球状蛋白质的独立折叠单位。
:::

:::definition{label="3-磷酸甘油醛脱氢酶的结构域"}
该酶由 $2$ 个亚基构成；每个亚基两个结构域：$\mathrm{N}$-端第 $1\sim 146$ 残基结合 $\mathrm{NAD}^{+}$，第 $147\sim 333$ 残基结合底物 $3$-磷酸甘油醛。
:::

:::compare{title="超二级结构、模体、结构域"}
| 项目 | 超二级结构 | 结构模体 | 结构域 |
|------|------------|----------|--------|
| 提出 / 含义 | Rossman $1973$；几个二级结构肽段的有规则组合 | 有特定构象和特定功能的结构成分，常有特征序列 | 较大蛋白中紧密、稳定、各行其功能的区域 |
| 尺度 | $\alpha\alpha$、$\beta\alpha\beta$、$\beta\beta$ 等局部组合 | 可与超二级结构重叠，如锌指、亮氨酸拉链 | 多为连续 $100\sim 200$ 个残基 |

超二级结构切不下来仍保持功能；结构域常常可以。亚基是整条已有三级结构的肽链，属于四级结构那一本账。$3$-磷酸甘油醛脱氢酶是 $2$ 个亚基，每个亚基里再有 $2$ 个结构域——层次不要并。
:::

### （四）蛋白质的多肽链须折叠成正确的空间构象

理论上讲，如果蛋白质的多肽链随机折叠，可能产生成千上万种可能的空间构象。而实际上，蛋白质合成后，在一定的条件下，可能只形成一种正确的空间构象。除一级结构为决定因素外，还需要在一类称为分子伴侣（molecular chaperone）的蛋白质辅助下，合成中的蛋白质才能折叠成正确的空间构象。只有形成正确的空间构象的蛋白质才具有生物学功能。

:::definition{label="分子伴侣"}
分子伴侣（molecular chaperone）是辅助合成中的蛋白质折叠成正确空间构象的一类蛋白质。一级结构是决定因素，但不是唯一因素；没有正确构象就没有生物学功能。
:::

:::cause-effect{title="为什么不能把折叠写成“序列自动唯一确定构象”"}
- **因** 随机折叠可有成千上万种可能构象；一级结构并不是决定空间构象的唯一因素
- **果** 需要一定条件，并常需分子伴侣辅助，才形成唯一正确的、具有生物学功能的构象
:::

## 四、含有两条以上多肽链的蛋白质可具有四级结构

体内许多功能性蛋白质含有两条或两条以上多肽链。每一条多肽链都有其完整的三级结构，称为亚基（subunit），亚基与亚基之间呈特定的三维空间排布，并以非共价键相连接。蛋白质分子中各个亚基的空间排布及亚基接触部位的布局和相互作用，称为蛋白质四级结构（protein quaternary structure）。

在四级结构中，各亚基间的结合力主要是氢键和离子键。在 $2$ 个亚基组成的四级结构蛋白质中，若亚基结构相同，称之为同二聚体（homodimer），若亚基分子不同，则称之为异二聚体（heterodimer），多个亚基可以此类推。对于 $2$ 个以上亚基构成的蛋白质，单一亚基一般没有生物学功能，完整的四级结构是其发挥生物学功能的保证。

:::definition{label="亚基"}
亚基（subunit）是具有完整三级结构的一条多肽链。亚基与亚基之间呈特定三维排布，并以非共价键相连接。
:::

:::definition{label="蛋白质四级结构"}
蛋白质四级结构（protein quaternary structure）是分子中各个亚基的空间排布及亚基接触部位的布局和相互作用。亚基间结合力主要是氢键和离子键。
:::

:::definition{label="同二聚体与异二聚体"}
两个亚基结构相同为同二聚体（homodimer），亚基分子不同为异二聚体（heterodimer）。更多亚基依此类推。
:::

:::pitfall{label="两条以上肽链才谈四级结构；单一亚基往往没有完整功能"}
对 $2$ 个以上亚基构成的蛋白质，单一亚基一般没有生物学功能，完整的四级结构才是功能保证。不要把“亚基自己也能结合氧”听成“亚基自己就能当血红蛋白用”。
:::

成人血红蛋白的 $\alpha$ 亚基和 $\beta$ 亚基分别含有 $141$ 个和 $146$ 个氨基酸。两种亚基的三级结构颇为相似，且每个亚基都可结合 $1$ 个血红素（heme）辅基（图1-17）。$4$ 个亚基通过 $8$ 个离子键相连，形成血红蛋白四聚体，具有运输 $\mathrm{O}_2$ 和 $\mathrm{CO}_2$ 的功能。但每一个亚基单独存在时，虽可结合氧且与氧亲和力增强，但在体内组织中难于释放氧，失去了血红蛋白原有的运输氧的作用。

:::definition{label="血红蛋白的四级结构"}
成人血红蛋白由 $\alpha$ 亚基（$141$ 个氨基酸）和 $\beta$ 亚基（$146$ 个氨基酸）组成。两种亚基三级结构颇为相似，每个亚基结合 $1$ 个血红素辅基。$4$ 个亚基通过 $8$ 个离子键相连成四聚体，运输 $\mathrm{O}_2$ 和 $\mathrm{CO}_2$。单独亚基虽可结合氧且亲和力增强，但在组织中难于释放氧，失去原有的运输氧作用。
:::

:::note{label="图1-17 电子版缺失"}
教材图1-17 为蛋白质的四级结构——血红蛋白结构示意图。数字切片 `p0048_01.png`、`p0048_02.png` 为 $0$ 字节，本节不引用。$\alpha_{141}$、$\beta_{146}$、四聚体、$8$ 个离子键、单独亚基难于释氧的正文仍按教材保留。
:::

:::example{label="血红蛋白说明四级结构为什么不是“四条链简单捆在一起”"}
每个亚基自己能结合氧，亲和力甚至更强，但运氧要求在肺结合、在组织释放。四聚体通过亚基接触部位的相互作用，才保住“能放氧”这一笔。完整四级结构是功能保证，不是装饰。
:::

:::compare{title="肌红蛋白与血红蛋白（为本节结构层次服务）"}
| 项目 | 肌红蛋白 | 血红蛋白 |
|------|----------|----------|
| 肽链条数 | $1$ 条（$153$ 残基） | $4$ 条（$\alpha_2\beta_2$） |
| 结构层次 | 一、二、三级，无四级 | 一、二、三、四级 |
| 辅基 | $1$ 个血红素 | 每个亚基 $1$ 个血红素，共 $4$ 个 |
| 螺旋 | $\alpha$-螺旋约占 $75\%$，$\mathrm{A}$—$\mathrm{H}$ $8$ 区 | 亚基三级结构与肌红蛋白颇为相似 |
| 功能 | 贮氧（本节先写结构） | 运输 $\mathrm{O}_2$ 和 $\mathrm{CO}_2$；单独亚基难于释氧 |
:::

## 五、蛋白质可依其组成、结构或功能进行分类

除氨基酸外，某些蛋白质还含有其他非氨基酸组分。因此根据蛋白质组成成分可分成单纯蛋白质和缀合蛋白质，前者只含氨基酸，而后者除蛋白质部分外，还含有非蛋白质部分，为蛋白质的生物学活性或代谢所依赖。缀合蛋白质中的非蛋白质部分被称为辅基，绝大部分辅基是通过共价键方式与蛋白质部分相连。构成蛋白质辅基的种类也很广，常见的有色素化合物、寡糖、脂质、磷酸、金属离子甚至分子量较大的核酸。细胞色素 $\mathrm{c}$（cytochrome $\mathrm{c}$，$\mathrm{Cyt}\,c$）是含有色素的缀合蛋白质，其铁卟啉环上的乙烯基侧链与蛋白质部分的半胱氨酸残基以硫醚键相连，铁卟啉中的铁离子是细胞色素 $\mathrm{c}$ 的重要功能位点。免疫球蛋白是一类糖蛋白，作为辅基的数支寡糖链通过共价键与蛋白质部分连接。

:::definition{label="单纯蛋白质"}
单纯蛋白质只含氨基酸。
:::

:::definition{label="缀合蛋白质"}
缀合蛋白质除蛋白质部分外，还含有非蛋白质部分，其生物学活性或代谢依赖这部分。非蛋白质部分称为辅基，绝大部分通过共价键与蛋白质部分相连。
:::

:::definition{label="辅基"}
辅基是缀合蛋白质中的非蛋白质部分。常见种类：色素化合物、寡糖、脂质、磷酸、金属离子，甚至分子量较大的核酸。
:::

:::definition{label="细胞色素 c"}
细胞色素 $\mathrm{c}$（$\mathrm{Cyt}\,c$）是含色素的缀合蛋白质。铁卟啉环上的乙烯基侧链与蛋白质部分的半胱氨酸残基以硫醚键相连；铁卟啉中的铁离子是重要功能位点。
:::

:::definition{label="免疫球蛋白（作为糖蛋白例）"}
免疫球蛋白是一类糖蛋白，作为辅基的数支寡糖链通过共价键与蛋白质部分连接。
:::

蛋白质还可根据其形状分为纤维状蛋白质和球状蛋白质两大类。一般来说，纤维状蛋白质形似纤维，其分子长轴的长度比短轴长 $10$ 倍以上。纤维状蛋白质多数为结构蛋白质，较难溶于水，作为细胞坚实的支架或连接各细胞、组织和器官的细胞外成分，如胶原蛋白、弹性蛋白、角蛋白等。大量存在于结缔组织中的胶原蛋白就是典型的纤维状蛋白质，其长轴为 $300\,\mathrm{nm}$，而短轴仅为 $1.5\,\mathrm{nm}$。球状蛋白质的形状近似于球形或椭球形，多数可溶于水，许多具有生理学功能的蛋白质如酶、转运蛋白、蛋白质类激素、代谢调节蛋白质、基因表达调节蛋白质及免疫球蛋白等都属于球状蛋白质。

:::definition{label="纤维状蛋白质"}
纤维状蛋白质形似纤维，分子长轴比短轴长 $10$ 倍以上。多数为结构蛋白质，较难溶于水，作为细胞支架或细胞外连接成分，如胶原蛋白、弹性蛋白、角蛋白。胶原蛋白长轴 $300\,\mathrm{nm}$、短轴 $1.5\,\mathrm{nm}$。
:::

:::definition{label="球状蛋白质"}
球状蛋白质近似球形或椭球形，多数可溶于水。酶、转运蛋白、蛋白质类激素、代谢调节蛋白质、基因表达调节蛋白质及免疫球蛋白等多属此类。
:::

:::compare{title="单纯 / 缀合，纤维状 / 球状"}
| 分类轴 | 一类 | 另一类 |
|--------|------|--------|
| 组成 | 单纯蛋白质：只含氨基酸 | 缀合蛋白质：蛋白质 $+$ 辅基（色素、寡糖、脂质、磷酸、金属离子、核酸等） |
| 形状 | 纤维状：长轴/短轴 $>10$，多数难溶，结构蛋白 | 球状：近球形，多数可溶，酶、转运、激素、调节、免疫球蛋白等 |
| 教材例 | 胶原蛋白 $300\,\mathrm{nm}\times 1.5\,\mathrm{nm}$ | $\mathrm{Cyt}\,c$（铁卟啉-硫醚键）；免疫球蛋白（寡糖辅基） |
:::

随着蛋白质结构与功能研究的不断深入，发现体内氨基酸序列相似而且空间结构与功能也十分相近的蛋白质有若干，即产生了“蛋白质家族（protein family）”这一概念。属于同一蛋白质家族的成员，称为同源蛋白质（homologous protein）。人们通过对蛋白质家族成员的比较，可得到许多物种进化的重要证据。在体内还发现，$2$ 个或 $2$ 个以上的蛋白质家族之间，其氨基酸序列的相似性并不高，但含有发挥相似作用的同一模体结构，通常将这些蛋白质家族归类为超家族（superfamily）。这些超家族成员是由共同祖先进化而来的一大类蛋白质。

:::definition{label="蛋白质家族"}
蛋白质家族（protein family）指氨基酸序列相似而且空间结构与功能也十分相近的若干蛋白质。
:::

:::definition{label="同源蛋白质"}
属于同一蛋白质家族的成员称为同源蛋白质（homologous protein）。比较家族成员可得到物种进化的重要证据。
:::

:::definition{label="超家族"}
$2$ 个或 $2$ 个以上蛋白质家族之间，氨基酸序列相似性并不高，但含有发挥相似作用的同一模体结构，这些家族归类为超家族（superfamily）。超家族成员是由共同祖先进化而来的一大类蛋白质。
:::

:::compare{title="家族与超家族"}
| 项目 | 蛋白质家族 | 超家族 |
|------|------------|--------|
| 序列 | 氨基酸序列相似 | 家族之间序列相似性并不高 |
| 结构与功能 | 空间结构与功能也十分相近 | 含有发挥相似作用的同一模体 |
| 成员称呼 | 同源蛋白质 | 由共同祖先进化而来的一大类 |
| 用途 | 比较可得物种进化证据 | 把“序列不像、模体像”的家族收在一起 |
:::

:::tip{label="分类先问组成，再问形状，最后才问家族"}
单纯/缀合看有没有辅基；纤维状/球状看长轴短轴和溶解性、功能类型；家族/超家族看序列相似还是只共享模体。三套分类可以叠在同一个分子上：免疫球蛋白既是缀合蛋白质（糖蛋白），又是球状蛋白质，后面还可归入免疫球蛋白超家族——但那是下一节相互作用的账。
:::

:::memory{label="本节必背要点"}
- [ ] $1952$ 年 Linderstrom 将蛋白质结构分为一级、二级、三级、四级；后三者统称高级结构或空间构象。
- [ ] 一条肽链只有一、二、三级结构；两条或两条以上肽链才有四级结构。
- [ ] 一级结构是从 $\mathrm{N}$-端至 $\mathrm{C}$-端的氨基酸排列顺序；主要化学键是肽键，二硫键位置也属一级结构。
- [ ] 牛胰岛素：$\mathrm{A}$ 链 $21$、$\mathrm{B}$ 链 $30$；$3$ 个二硫键（链内 $\mathrm{A}6$—$\mathrm{A}11$，另 $2$ 个链间）；Sanger $1953$ 年测定。
- [ ] 一级结构是空间构象和功能的基础，但不是决定构象的唯一因素。
- [ ] 二级结构是局部主链骨架（$\mathrm{N}$、$\mathrm{C}_\alpha$、$\mathrm{C}$）的空间位置，不涉及侧链；主要包括 $\alpha$-螺旋、$\beta$-折叠、$\beta$-转角和 $\Omega$-环。
- [ ] 肽单元：$6$ 原子共面；$\mathrm{C}-\mathrm{N}$ 键长 $0.132\,\mathrm{nm}$，有部分双键性，不能自由旋转；$\phi$、$\psi$ 决定相邻平面相对位置。
- [ ] $\alpha$-螺旋：右手，$\phi=-57^{\circ}$，$\psi=-47^{\circ}$，$3.6$ 残基/圈，螺距 $0.54\,\mathrm{nm}$；每个肽键 $\mathrm{N}-\mathrm{H}$ 与第四个肽键羰基氧形成氢键，与长轴基本平行。
- [ ] $\beta$-折叠：锯齿状，$5\sim 8$ 残基；平行重复 $0.65\,\mathrm{nm}$，反平行 $0.70\,\mathrm{nm}$；链间氢键稳定；蚕丝蛋白几乎全是 $\beta$-折叠。
- [ ] $\beta$-转角：通常 $4$ 个残基，$1$—$4$ 氢键，第 $2$ 位常为 Pro；$\Omega$-环在表面、亲水、参与识别。无规卷曲是没有规则重复的松散区段，不能顶替 $\Omega$-环。
- [ ] 连续酸性或碱性残基、过大侧链、Pro（肽键 $\mathrm{N}$ 上无 $\mathrm{H}$）妨碍 $\alpha$-螺旋。
- [ ] 三级结构是整条肽链全部原子的三维排布；稳定主要靠疏水键、盐键、氢键、范德华力；二硫键参与稳定。
- [ ] 肌红蛋白：$153$ 残基，单链，$1$ 个血红素，$\alpha$-螺旋 $75\%$，$\mathrm{A}$—$\mathrm{H}$ $8$ 区，$4.5\times 3.5\times 2.5\,\mathrm{nm}$。
- [ ] 超二级结构（Rossman $1973$）：$\alpha\alpha$、$\beta\alpha\beta$、$\beta\beta$ 等。模体有特征序列和特定功能：亮氨酸拉链、螺旋-环-螺旋、锌指。
- [ ] 结构域：连续约 $100\sim 200$ 残基的独立折叠单位；GAPDH 每个亚基两个结构域（$1\sim 146$ 结合 $\mathrm{NAD}^{+}$，$147\sim 333$ 结合底物）。
- [ ] 分子伴侣辅助肽链折叠成正确构象；只有正确构象才有生物学功能。
- [ ] 亚基是具完整三级结构的肽链；四级结构是亚基排布及接触部位相互作用，亚基间主要是氢键和离子键。
- [ ] 成人血红蛋白：$\alpha_{141}$、$\beta_{146}$，四聚体，$8$ 个离子键；单独亚基难于释氧。
- [ ] 单纯蛋白质只含氨基酸；缀合蛋白质含辅基（$\mathrm{Cyt}\,c$ 的铁卟啉、免疫球蛋白的寡糖等）。
- [ ] 纤维状蛋白长轴/短轴 $>10$，多数难溶（胶原 $300\,\mathrm{nm}\times 1.5\,\mathrm{nm}$）；球状蛋白多数可溶，多为功能蛋白。
- [ ] 蛋白质家族：序列、空间结构与功能均相近，成员称同源蛋白质；超家族：序列相似性不高但共享同一模体，来自共同祖先。
:::
