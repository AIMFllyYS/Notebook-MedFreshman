# 第三节　原核生物DNA复制过程

第二节把酶和拓扑摊开：$\mathrm{pol}\,\mathrm{III}$ 真正延长，$\mathrm{pol}\,\mathrm{I}$ 去引物并填空隙，连接酶封 nick，DnaA/B/C、引发酶、SSB、拓扑酶共同解链。本节按大肠埃希氏杆菌把这些零件装回一条环状染色体：固定起点 $\mathrm{oriC}$ 上装配起始复合物并合成 $\mathrm{RNA}$ 引物，同一 $\mathrm{pol}\,\mathrm{III}$ 在复制叉上同时延长前导链和后随链，终止于 $\mathrm{ter}$／Tus，最后把冈崎片段连成完整子链。真核多复制子、聚合酶转换和端粒是第四节的账。

:::concept{term="先问起点序列怎么被认出来，再问引物 3′-OH 从哪来、两股怎样共用一台酶"}
看见“原核复制过程”，按起始—延长—终止走。起始不是随机开口：$\mathrm{oriC}$ $245\,\mathrm{bp}$ 上的 $\mathrm{DUE}$ 和 $\mathrm{R}$ 位点把 DnaA 请来，DnaB/C 解链，引发酶做 $5\sim 10$ 核苷酸的 $\mathrm{RNA}$ 引物。延长仍然 $5'\rightarrow 3'$；后随链模板绕成环，两股对准同一个 $\mathrm{pol}\,\mathrm{III}$。终止靠 Tus 挡住 DnaB，引物换成 $\mathrm{DNA}$ 后才叫完成。
:::

原核生物染色体 $\mathrm{DNA}$ 和质粒等都是共价环状闭合的 $\mathrm{DNA}$ 分子，复制过程具有共同的特点，但并非完全相同。下面以大肠埃希氏杆菌 $\mathrm{DNA}$ 复制为例，介绍原核生物 $\mathrm{DNA}$ 复制的过程和特点。

:::definition{label="原核染色体和质粒都是共价环状闭合 DNA"}
环状闭合是原核复制的共同背景：没有游离的线性末端，双向两叉在环上汇合。质粒与染色体过程有共同点，但并非完全相同；本节以 $E.coli$ 染色体为准。
:::

:::pitfall{label="不要把质粒复制写成和染色体逐步等同"}
教材先写“具有共同的特点，但并非完全相同”，再限定“以大肠埃希氏杆菌 $\mathrm{DNA}$ 复制为例”。$\mathrm{oriC}$、$245\,\mathrm{bp}$、Tus/$\mathrm{ter}$ 是染色体这本账。
:::

## 一、复制起始过程形成起始复合物

起始是复制中较为复杂的环节，在此过程中，各种酶和蛋白质因子在复制起点处装配引发体，形成复制叉并合成 $\mathrm{RNA}$ 引物。

:::definition{label="起始要做成三件事"}
在复制起点装配引发体，形成复制叉，合成 $\mathrm{RNA}$ 引物。没有引物就没有 $\mathrm{DNA}\,\mathrm{pol}$ 能用的 $3'$-$\mathrm{OH}$。
:::

:::keypoint{label="起始顺序先记四步"}
- 认住 $\mathrm{oriC}$ 的反向重复序列（DnaA）。
- DnaB/C 解开足够长度，SSB 稳住单链。
- 拓扑酶 $\mathrm{II}$ 把正超螺旋转为负超螺旋。
- 引发酶进入，合成 $\mathrm{RNA}$ 引物，形成起始复合物（噬菌体 $\Phi\mathrm{X}$ 系统也称引发体）。
:::

### （一）DNA 识别并结合复制起始点的反向重复序列

**1. 复制有固定起点**　复制不是在基因组上的任何部位随机起始。大肠埃希氏杆菌基因组上有一个固定的复制起点，称为 $\mathrm{oriC}$，跨度为 $245\,\mathrm{bp}$，其序列高度保守，含有 $3$ 个 $13\,\mathrm{bp}$ 组成的串联重复序列和 $5$ 个 $9\,\mathrm{bp}$ 组成的重复序列，前者富含 $\mathrm{AT}$（AT rich），又叫 $\mathrm{DNA}$ 解旋元件（DNA unwinding element，$\mathrm{DUE}$），后者为 DnaA 主要结合位点（$\mathrm{R}$ 位点）（图14-11）。此外，在 $\mathrm{oriC}$ 还存在整合宿主因子（integration host factor，$\mathrm{IHF}$）和反转刺激因子（factor for inversion stimulation，$\mathrm{FIS}$）的结合位点。$\mathrm{FIS}$ 和 $\mathrm{IHF}$ 是某些重组反应的必要组分。$\mathrm{DNA}$ 双链中，$\mathrm{AT}$ 间的配对只有 $2$ 个氢键维系，故富含 $\mathrm{AT}$ 的部位容易发生解链。

::figure{src="/images/biochemistry/textbook/p0293_01.png" caption="图14-11　原核生物的复制起始部位 oriC 的序列排列。左侧 3 个 13 bp 重复（GATCTNTNTNTTTT）为 DUE；右侧 5 个 9 bp 重复 TT(A/T)TNCACC 为 DnaA 结合的 R 位点。自左至右标 DUE、R1、IHF、R5、I1、I2、R2、FIS、R3、I3、R4。N 代表四种核苷酸中的任何一种；水平箭头表示序列方向。" alt="oriC 线性示意图：DUE 三个箭头串联，随后 R1、IHF、R5、I1、I2、R2、FIS、R3、I3、R4"}

:::note{label="电子版缺失"}
教材第 $263$ 页 $\mathrm{oriC}$ 叙述旁的「动画」二维码图源 `p0292_03.png`、`p0292_04.png` 为 $0$ 字节，不嵌入 `src`，本任务不写 `::video`。
:::

:::definition{label="oriC"}
$E.coli$ 基因组上固定的复制起点，跨度 $245\,\mathrm{bp}$，序列高度保守。含 $3$ 个 $13\,\mathrm{bp}$ 串联重复（富含 $\mathrm{AT}$ 的 $\mathrm{DUE}$）和 $5$ 个 $9\,\mathrm{bp}$ 重复（DnaA 主要结合的 $\mathrm{R}$ 位点），另有 $\mathrm{IHF}$、$\mathrm{FIS}$ 结合位点。
:::

:::definition{label="DNA 解旋元件 DUE"}
$3$ 个 $13\,\mathrm{bp}$ 串联重复，富含 $\mathrm{AT}$，又称 DNA unwinding element。图14-11 共识序列写作 $\mathrm{GATCTNTNTNTTTT}$。$\mathrm{AT}$ 只有 $2$ 个氢键，故此处容易解链。
:::

:::definition{label="R 位点"}
$5$ 个 $9\,\mathrm{bp}$ 重复，DnaA 主要结合位点。图14-11 共识序列 $\mathrm{TT}(\mathrm{A/T})\mathrm{TNCACC}$，标为 $\mathrm{R1}$、$\mathrm{R5}$、$\mathrm{R2}$、$\mathrm{R3}$、$\mathrm{R4}$。$\mathrm{N}$ 代表四种核苷酸中的任何一种；水平箭头表示序列方向。
:::

:::definition{label="I 位点、IHF 和 FIS"}
$\mathrm{I}$ 位点是额外的 DnaA 结合位点，序列与 $\mathrm{R}$ 不同，图14-11 标为 $\mathrm{I1}$、$\mathrm{I2}$、$\mathrm{I3}$。$\mathrm{IHF}$（整合宿主因子）和 $\mathrm{FIS}$（反转刺激因子）在 $\mathrm{oriC}$ 也有结合位点，二者是某些重组反应的必要组分。
:::

:::keypoint{label="245 bp 里两套重复不要对调"}
- $3\times 13\,\mathrm{bp}$：$\mathrm{DUE}$，AT 富集，解链。
- $5\times 9\,\mathrm{bp}$：$\mathrm{R}$ 位点，DnaA 主结合。
- 另加 $\mathrm{IHF}$、$\mathrm{FIS}$ 以及 $\mathrm{I1}$–$\mathrm{I3}$。
:::

:::pitfall{label="复制不是基因组上随机开口"}
教材第一句就把“任何部位随机起始”否定掉。真核多起点仍是每个起点序列相对固定（第四节酵母 $\mathrm{ARS}$），不是“没有 origin”。
:::

:::insight{label="AT 富集和第二节的两个氢键是同一句话"}
$\mathrm{A}$-$\mathrm{T}$ 两个氢键、$\mathrm{G}$-$\mathrm{C}$ 三个氢键，既用于保真配对，也用于解释为什么 $\mathrm{DUE}$ 先打开。把 $\mathrm{oriC}$ 听成“DnaA 有魔力”，会丢掉序列化学。
:::

**2. DNA 解链需多种蛋白质参与**　$\mathrm{DNA}$ 的解链过程由 DnaA、DnaB、DnaC 三种蛋白质共同参与完成。DnaA 蛋白是一同源四聚体，负责辨认并结合于 $\mathrm{oriC}$ 的反向重复序列上。然后，几个 DnaA 蛋白互相靠近，形成 $\mathrm{DNA}$-蛋白质复合体结构，促使 $\mathrm{AT}$ 区的 $\mathrm{DNA}$ 解链。DnaB 蛋白（解旋酶）在 DnaC 蛋白的协同下，结合并沿解链方向移动，使双链解开足够用于复制的长度，并且逐步置换出 DnaA 蛋白。此时，复制叉已初步形成。

$\mathrm{SSB}$ 此时结合到 $\mathrm{DNA}$ 单链上，在一定时间内使复制叉保持适当的长度，有利于核苷酸依模板掺入。

:::definition{label="DnaA 是同源四聚体"}
辨认并结合 $\mathrm{oriC}$ 的反向重复序列。几个 DnaA 互相靠近，形成 $\mathrm{DNA}$-蛋白质复合体，促使 $\mathrm{AT}$ 区解链。
:::

:::definition{label="DnaB 在 DnaC 协同下置换 DnaA"}
解旋酶 DnaB 由 DnaC 运送、协同，结合后沿解链方向移动，解开足够用于复制的长度，并逐步置换出 DnaA。至此复制叉初步形成。
:::

:::definition{label="SSB 把复制叉维持在适于掺入的长度"}
结合到单链上，在一定时间内使复制叉保持适当长度，利于核苷酸依模板掺入。结合—脱离的方式第二节已写，这里强调“适当长度”——叉既不能马上重新退火，也不必一次打开整个基因组。
:::

:::cause-effect{title="为什么起始解链必须 DnaA、DnaB、DnaC 三个一起"}
- **因** DnaA 只会认起点并促使 $\mathrm{AT}$ 区局部开口；真正沿叉向前解开双链的是解旋酶 DnaB，而 DnaB 需要 DnaC 运送协同
- **果** 缺少任何一名，要么起点不被认，要么开口后叉伸不出去；教材写“共同参与完成”
:::

:::pitfall{label="DnaA 结合之后不是自己当解旋酶"}
DnaA 促使 $\mathrm{AT}$ 区解链，随后被 DnaB 逐步置换。把 DnaA 答成 helicase，表14-4 的 DnaB 行就闲了。
:::

**3. 解链过程中需要 DNA 拓扑异构酶**　解链是一种高速的反向旋转，其下游势必发生打结现象。拓扑异构酶 $\mathrm{II}$ 通过切断、旋转和再连接的作用，实现 $\mathrm{DNA}$ 超螺旋的转型，即把正超螺旋变为负超螺旋。实验证明：负超螺旋 $\mathrm{DNA}$ 比正超螺旋有更好的模板作用。

:::definition{label="起始阶段拓扑酶 II 做超螺旋转型"}
切断、旋转、再连接，把正超螺旋变为负超螺旋。负超螺旋模板作用更好。这是第二节“全过程都需要拓扑酶”在起始这一环的具体说法。
:::

:::pitfall{label="不要写成“解开超螺旋就结束了”"}
这里强调的是转型：正 $\rightarrow$ 负，而且负的更好当模板。只答“打结打开”会漏掉方向。
:::

### （二）引物合成和起始复合物的形成

复制起始过程需要先合成引物（primer），引物是由引发酶（primase）催化合成的短链 $\mathrm{RNA}$ 分子。母链 $\mathrm{DNA}$ 解成单链后，不会立即按照模板序列将 $\mathrm{dNTP}$ 聚合为 $\mathrm{DNA}$ 子链。这是因为 $\mathrm{DNA}\,\mathrm{pol}$ 不具备催化两个游离 $\mathrm{dNTP}$ 之间形成磷酸二酯键的能力，只能催化核酸片段的 $3'$-$\mathrm{OH}$ 末端与 $\mathrm{dNTP}$ 间的聚合。但 $\mathrm{RNA}$ 聚合酶不需要 $3'$-$\mathrm{OH}$ 便可催化 $\mathrm{NTP}$ 的聚合，而引发酶属于 $\mathrm{RNA}$ 聚合酶，故复制起始部位合成的短链引物 $\mathrm{RNA}$ 为 $\mathrm{DNA}$ 的合成提供 $3'$-$\mathrm{OH}$ 末端，在 $\mathrm{DNA}\,\mathrm{pol}$ 催化下逐一加入 $\mathrm{dNTP}$ 而形成 $\mathrm{DNA}$ 子链。

引发酶是复制起始时催化 $\mathrm{RNA}$ 引物合成的酶。它不同于催化转录的 $\mathrm{RNA}$ 聚合酶。利福平（rifampicin）是转录用 $\mathrm{RNA}\,\mathrm{pol}$ 的特异性抑制剂，而引发酶对利福平不敏感。

在 $\mathrm{DNA}$ 双链解链基础上，形成了 DnaB、DnaC 蛋白与 $\mathrm{DNA}$ 复制起点相结合的复合体。此时引发酶进入，形成含有解旋酶 DnaB、DnaC、引发酶和 $\mathrm{DNA}$ 的复制起始区域共同构成的起始复合物结构，该结构在噬菌体 $\Phi\mathrm{X}$ 系统也称为引发体（primosome）。起始复合物蛋白质组分在 $\mathrm{DNA}$ 链上的移动需由 $\mathrm{ATP}$ 供给能量。在适当位置上，引发酶依据模板的碱基序列，从 $5'\rightarrow 3'$ 方向催化 $\mathrm{NTP}$（不是 $\mathrm{dNTP}$）的聚合，生成短链的 $\mathrm{RNA}$ 引物（图14-12）。

引物长度约为 $5\sim 10$ 个核苷酸不等。引物合成的方向也是自 $5'$ 端至 $3'$ 端。已合成的引物必然留有 $3'$-$\mathrm{OH}$ 末端，此时就可进入 $\mathrm{DNA}$ 的复制延长。在 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$ 催化下，引物末端与新配对进入的 $\mathrm{dNTP}$ 生成磷酸二酯键。新链每次反应后亦留有 $3'$-$\mathrm{OH}$，复制就可继续进行下去。

:::

:::definition{label="引物"}
引物（primer）是引发酶催化合成的短链 $\mathrm{RNA}$ 分子，长度约 $5\sim 10$ 个核苷酸，方向 $5'\rightarrow 3'$，留下 $3'$-$\mathrm{OH}$ 供 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$ 接 $\mathrm{dNTP}$。
:::

:::definition{label="引发酶"}
复制起始时催化 $\mathrm{RNA}$ 引物合成的酶（DnaG），属于 $\mathrm{RNA}$ 聚合酶，但不同于转录用 $\mathrm{RNA}\,\mathrm{pol}$。底物是 $\mathrm{NTP}$ 不是 $\mathrm{dNTP}$。
:::

:::definition{label="为什么 DNA pol 必须先有引物"}
$\mathrm{DNA}\,\mathrm{pol}$ 不能催化两个游离 $\mathrm{dNTP}$ 之间形成磷酸二酯键，只能把 $\mathrm{dNTP}$ 加到已有核酸片段的 $3'$-$\mathrm{OH}$ 上。$\mathrm{RNA}$ 聚合酶不需要预先的 $3'$-$\mathrm{OH}$ 就能聚合 $\mathrm{NTP}$，所以先做 $\mathrm{RNA}$ 引物。
:::

:::definition{label="起始复合物与引发体"}
解链后 DnaB、DnaC 与起点 $\mathrm{DNA}$ 结合，引发酶进入，形成含解旋酶 DnaB、DnaC、引发酶和 $\mathrm{DNA}$ 的起始复合物。该结构在噬菌体 $\Phi\mathrm{X}$ 系统也称为引发体（primosome）。蛋白质组分在链上移动需 $\mathrm{ATP}$。
:::

:::definition{label="利福平区分两套 RNA 聚合酶"}
利福平（rifampicin）是转录用 $\mathrm{RNA}\,\mathrm{pol}$ 的特异性抑制剂，引发酶对利福平不敏感。复制引物不是“转录机顺便做的一小段 $\mathrm{RNA}$”。
:::

:::compare{title="引物 RNA 和延长用的 DNA"}
| | 引物 | 子链延长 |
|--|------|----------|
| 酶 | 引发酶（DnaG） | $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$ |
| 底物 | $\mathrm{NTP}$ | $\mathrm{dNTP}$ |
| 长度 | 约 $5\sim 10$ 核苷酸 | 前导链连续；后随链按冈崎片段 |
| 方向 | $5'\rightarrow 3'$ | $5'\rightarrow 3'$ |
| 利福平 | 不敏感 | — |

每次接上 $\mathrm{dNTP}$ 后新链仍留 $3'$-$\mathrm{OH}$，延长才能持续。
:::

:::pitfall{label="引物不是 DNA 短片段"}
教材写明短链 $\mathrm{RNA}$。把它答成“一小段 $\mathrm{DNA}$”，后面“去除 $\mathrm{RNA}$ 引物、换成 $\mathrm{DNA}$”整段终止过程会没有对象。
:::

:::pitfall{label="引发酶对利福平不敏感，不要写成转录抑制剂能挡住复制起始"}
利福平专打转录用 $\mathrm{RNA}\,\mathrm{pol}$。用“利福平抑制 $\mathrm{RNA}$ 合成所以复制也无法起始”会把两套酶并户。
:::

:::insight{label="前导链也要引物，不只是后随链"}
起始部位合成的引物给 $\mathrm{DNA}$ 合成提供第一个 $3'$-$\mathrm{OH}$。后随链每一段冈崎片段另外再引发；前导链在起点也有一次。终止过程会写：前导链同样有引物水解后的空隙，靠环状 $\mathrm{DNA}$ 最后复制的 $3'$-$\mathrm{OH}$ 填上。
:::

## 二、复制延长过程形成复制叉结构

复制中 $\mathrm{DNA}$ 链的延长在 $\mathrm{DNA}\,\mathrm{pol}$ 催化下进行。原核生物催化延长反应的酶是 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$。底物 $\mathrm{dNTP}$ 的 $\alpha$-磷酸基团与引物或延长中的子链上 $3'$-$\mathrm{OH}$ 反应后，$\mathrm{dNMP}$ 的 $3'$-$\mathrm{OH}$ 又成为链的末端，使下一个底物可以掺入。复制沿 $5'\rightarrow 3'$ 延长，指的是子链合成的方向。前导链沿着 $5'\rightarrow 3'$ 方向连续延长，而后随链沿着 $5'\rightarrow 3'$ 方向呈不连续延长。

在同一个复制叉上，前导链的复制先于后随链，但两链是在同一个 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$ 催化下进行延长的。这是因为后随链的模板 $\mathrm{DNA}$ 可以折叠或绕成环状，进而与前导链正在延长的区域对齐（图14-13）。图中可见，由于后随链绕转，前导链和后随链的延长方向和延长点都处在 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$ 核心酶的催化位点上。解链方向就是酶的前进方向，亦即复制叉向前伸展的方向。因为复制叉上解开的模板单链走向相反，所以其中一股出现不连续复制的冈崎片段。

$\mathrm{DNA}$ 复制延长速度相当快。以 $E.coli$ 为例，营养充足、生长条件适宜时，细菌 $20$ 分钟即可繁殖一代。$E.coli$ 基因组 $\mathrm{DNA}$ 全长约 $4\,600\,\mathrm{kb}$，依此计算，每秒钟能掺入的核苷酸达 $3\,800$ 个。

:::definition{label="原核延长酶是 DNA pol III"}
$\mathrm{dNTP}$ 的 $\alpha$-磷酸与引物或子链 $3'$-$\mathrm{OH}$ 反应后，新的 $3'$-$\mathrm{OH}$ 成为末端，下一分子再掺入。前导链连续 $5'\rightarrow 3'$，后随链不连续但仍 $5'\rightarrow 3'$。
:::

:::definition{label="同一 pol III 催化两股：后随链模板绕环"}
同一复制叉上前导链先于后随链，但两链由同一个 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$ 延长。后随链模板折叠或绕成环，与前导链正在延长的区域对齐，两股延长点和延长方向都落在核心酶催化位点上（图14-13）。
:::

:::definition{label="E.coli 延长速度"}
营养充足、条件适宜时 $20$ 分钟繁殖一代。基因组约 $4\,600\,\mathrm{kb}$，每秒掺入核苷酸达 $3\,800$ 个。与第一节 Meselson-Stahl“每一代约 $20$ 分钟”同一世代时间。
:::

:::keypoint{label="图14-13 四标"}
- （a）核心酶 $+$ $\beta$ 亚基。
- （b）后随链已复制片段。
- （c）正在复制的片段（虚线子链，引物为齿状）。
- （d）尚未复制的模板环。
实线母链，虚线子链；前导链在图下方连续伸出。
:::

:::compare{title="两股共用一台酶，并不取消半不连续"}
| 仍不对称的 | 被几何对齐的 |
|------------|----------------|
| 前导链先、连续 | 延长点都在 $\mathrm{pol}\,\mathrm{III}$ 核心上 |
| 后随链迟、冈崎片段 | 解链方向 $=$ 酶前进方向 $=$ 复制叉伸展方向 |
| 模板单链走向相反 | 后随链靠绕环把 $5'\rightarrow 3'$ 扭到与前导链同侧 |

绕环解决的是“一台酶怎么同时碰到两股”，不是让后随链变成连续合成。
:::

:::pitfall{label="不要写成“一个叉上有两台互不相干的 pol III 各抄一股”"}
教材强调同一个 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$。第二节全酶本来就是 $2$ 个核心酶通过 $\beta$ 滑动夹和 $\gamma$-复合物连在一起的不对称异聚合体，图14-13 是这台机器在叉上的工作姿势。
:::

:::pitfall{label="3800 个/s 不要和表14-2 的 250～1000 nt/s 混成同一句话"}
表14-2 是单个 $\mathrm{pol}\,\mathrm{III}$ 的聚合速率范围；此处 $3\,800$ 是按 $4\,600\,\mathrm{kb}$、$20$ 分钟世代算出来的基因组复制掺入速度（双向两叉一起）。本版两处数字都保留，不要改成互相换算后的“标准值”。
:::

:::insight{label="解链方向就是酶的前进方向"}
复制叉往哪伸，解旋酶和 $\mathrm{pol}\,\mathrm{III}$ 就往哪走。后随链看起来“倒着抄”，只因为模板走向相反，必须分段；绕环之后，催化位点上两股都是 $5'\rightarrow 3'$ 往同一侧加。
:::

## 三、复制终止过程包括切除引物和连接切口

复制的终止过程，包括切除引物、填补空缺和连接切口。$E.coli$ 的 $\mathrm{DNA}$ 复制终止点称为 $\mathrm{ter}$ 部位，在复制叉汇合点两侧约 $100\,\mathrm{bp}$ 处各有一个终止区（$\mathrm{ter}\,E/D/A$ 和 $\mathrm{ter}\,C/B$），分别来自一个方向的复制叉的特异终止位点（ter sites）。终止点部位被蛋白 Tus 识别，Tus 具有反解旋酶（contra-helicase）活性，阻止 DnaB 的解链作用，从而抑制复制叉前进。Tus 除了使复制叉停止运动外，还可能造成复制体解体。原核生物基因是环状 $\mathrm{DNA}$，复制是双向复制，从起始点开始各进行 $180^{\circ}$，同时在终止点上汇合。但有些生物两个方向复制是不等速的，起始点和终止点不一定把基因组 $\mathrm{DNA}$ 分为两个等份。因为 Tus 并非同时与两边 $\mathrm{ter}$ 结合，即 Tus 不是同时起作用，只是单向阻止复制，另一边复制多一些，所以汇合点不在 $180^{\circ}$，可能偏 $200\,\mathrm{bp}$ 以内。

:::definition{label="ter 部位与 Tus"}
$E.coli$ 终止点称 $\mathrm{ter}$。汇合点两侧约 $100\,\mathrm{bp}$ 各有终止区 $\mathrm{ter}\,E/D/A$ 和 $\mathrm{ter}\,C/B$，分别挡住一个方向的叉。蛋白 Tus 识别 $\mathrm{ter}$，具有反解旋酶（contra-helicase）活性，阻止 DnaB 解链，抑制叉前进，还可能造成复制体解体。
:::

:::definition{label="汇合点不必严格在 180°"}
环状 $\mathrm{DNA}$ 双向各走 $180^{\circ}$ 是理想图像。有些生物两方向不等速；Tus 并非同时结合两边 $\mathrm{ter}$，只单向阻止，另一边多复制一些，汇合点可能偏 $200\,\mathrm{bp}$ 以内。
:::

:::compare{title="起点 oriC 和终点 ter"}
| | $\mathrm{oriC}$ | $\mathrm{ter}$ |
|--|----------------|--------------|
| 作用 | 固定起始，装配引发体 | 挡住复制叉，结束解链 |
| 关键蛋白 | DnaA 认 $\mathrm{R}$ 位点 | Tus 认 $\mathrm{ter}$，反解旋酶挡 DnaB |
| 位置 | 一个 $245\,\mathrm{bp}$ 区 | 汇合点两侧约 $100\,\mathrm{bp}$ 各一区 |
| 对称性 | 双向从这一点分开 | 不一定把环分成两个等份 |

图14-3a 把终点画成 $\mathrm{ter}$，本节补上 Tus 和可能的 $200\,\mathrm{bp}$ 偏差。
:::

:::pitfall{label="Tus 不是同时把两个叉刹死"}
“不是同时起作用，只是单向阻止复制”。把 Tus 听成对称闸门，汇合点就只能画在正对面，和“偏 $200\,\mathrm{bp}$ 以内”冲突。
:::

:::insight{label="反解旋酶对着的是 DnaB，不是聚合酶"}
叉要前进必须继续解链。Tus 阻止 DnaB，解链停，聚合也就停，复制体还可能解体。这是终止的力学，引物怎么换成 $\mathrm{DNA}$ 是下一小段的化学。
:::

由于复制的半不连续性，在后随链上出现许多冈崎片段。每个冈崎片段上的引物是 $\mathrm{RNA}$ 而不是 $\mathrm{DNA}$。复制的完成还包括去除 $\mathrm{RNA}$ 引物和换成 $\mathrm{DNA}$，最后把 $\mathrm{DNA}$ 片段连接成完整的子链。这一过程用图14-14 加以说明。实际上此过程在子链延长中已陆续进行，不必等到最后的终止才连接。

引物的水解靠细胞核内的 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{I}$，水解后留下空隙（gap）。空隙的填补由 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{I}$ 而不是 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$ 催化，从 $5'$ 端向 $3'$ 端用 $\mathrm{dNTP}$ 为原料生成相当于引物长度的 $\mathrm{DNA}$ 链。$\mathrm{dNTP}$ 的掺入要有 $3'$-$\mathrm{OH}$，在原引物相邻的子链片段提供 $3'$-$\mathrm{OH}$ 继续延伸，即由后复制的片段延长以填补先复制片段的引物空隙。填补至足够长度后，还是留下相邻的 $3'$-$\mathrm{OH}$ 和 $5'$-$\mathrm{P}$ 的缺口（nick）。缺口由连接酶连接。按照这种方式，所有的冈崎片段在环状 $\mathrm{DNA}$ 上连接成完整的 $\mathrm{DNA}$ 子链。前导链也有引物水解后的空隙，在环状 $\mathrm{DNA}$ 最后复制的 $3'$-$\mathrm{OH}$ 端继续延长，即可填补该空隙及连接，完成基因组 $\mathrm{DNA}$ 的整个复制过程。

教材第 $266$ 页本节末至第四节标题前电子版裁图 `p0295_01.png` 为 $0$ 字节，不嵌入 `src`。正文以前导链引物空隙由环状分子最后的 $3'$-$\mathrm{OH}$ 填补并连接、完成基因组复制为准。第四节真核过程不在本节展开。
:::

:::definition{label="终止的化学三步"}
①切除 $\mathrm{RNA}$ 引物；②填补空隙（gap）；③连接切口（nick）。此过程在延长中已陆续进行，不必等到最后才连接。
:::

:::definition{label="空隙由 pol I 填，不由 pol III"}
引物水解靠 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{I}$，留下 gap。填补也由 $\mathrm{pol}\,\mathrm{I}$ 从 $5'\rightarrow 3'$ 用 $\mathrm{dNTP}$ 生成相当于引物长度的 $\mathrm{DNA}$。$3'$-$\mathrm{OH}$ 由相邻、后复制的片段提供，即后复制的片段延长去填先复制片段的引物空隙。
:::

:::definition{label="缺口 nick 交给连接酶"}
填到足够长度后，仍留下相邻的 $3'$-$\mathrm{OH}$ 与 $5'$-$\mathrm{P}$，这是 nick 不是 gap。连接酶耗 $\mathrm{ATP}$ 封口。全部冈崎片段在环上连成完整子链。
:::

:::definition{label="前导链的引物空隙同样要填"}
前导链也有引物水解后的空隙。环状 $\mathrm{DNA}$ 最后复制的 $3'$-$\mathrm{OH}$ 端继续延长，即可填补该空隙并连接，完成整个基因组复制。
:::

:::compare{title="图14-14 四行和酶的对应"}
| 图上一步 | 酶／底物 | 留下什么 |
|----------|----------|----------|
| 齿状引物还在 | — | 两段子链，中间隔着引物 |
| $\mathrm{RNA}$ 酶／$\mathrm{pol}\,\mathrm{I}$ 去引物 | 水解 $\mathrm{RNA}$ | gap：一侧 $3'$-$\mathrm{OH}$，一侧 $5'$-$\mathrm{P}$，中间缺一段 |
| $\mathrm{pol}\,\mathrm{I}+\mathrm{dNTP}$ | 聚合填补 | nick：$\mathrm{OH}$ 紧挨 $\mathrm{P}$ |
| 连接酶 $+\mathrm{ATP}$（$\rightarrow\mathrm{ADP}+\mathrm{P}_\mathrm{i}$） | 生成磷酸二酯键 | 完整子链 |

图中齿状线即教材所注“代表引物”。
:::

:::pitfall{label="填空隙的不是 pol III"}
教材写明“由 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{I}$ 而不是 $\mathrm{DNA}\,\mathrm{pol}\,\mathrm{III}$ 催化”。$\mathrm{pol}\,\mathrm{III}$ 是延长主酶，但不负责把引物换成 $\mathrm{DNA}$。表14-3 把“去除 $\mathrm{RNA}$ 引物，填补空隙”写在原核 $\mathrm{I}$ 那一行。
:::

:::pitfall{label="gap 和 nick 不要混用"}
gap 缺一段核苷酸，必须聚合填上；nick 只缺一个磷酸二酯键，连接酶即可。先 gap 后 nick，顺序不能倒。
:::

:::pitfall{label="后复制的片段去填先复制片段的空隙"}
$3'$-$\mathrm{OH}$ 在相邻片段上。方向仍是 $5'\rightarrow 3'$，看起来像“后面的一段往前补”。不要画成先合成的片段倒过来用自己的 $5'$ 端去填。
:::

:::insight{label="环状分子让前导链引物问题有出口"}
线性染色体会在末端留下无法填的空隙，那是第四节端粒的账。原核环状 $\mathrm{DNA}$ 没有游离末端：前导链引物去掉后，环上最后那个 $3'$-$\mathrm{OH}$ 可以一直延长到把空隙填平再连接。
:::

:::memory{label="本节必背要点"}
- [ ] 以 $E.coli$ 环状染色体为例；质粒过程相近但并非完全相同。
- [ ] $\mathrm{oriC}$：$245\,\mathrm{bp}$；$3\times 13\,\mathrm{bp}$ 的 $\mathrm{DUE}$（AT 富集）；$5\times 9\,\mathrm{bp}$ 的 $\mathrm{R}$ 位点（DnaA）；另有 $\mathrm{IHF}$、$\mathrm{FIS}$、$\mathrm{I1}$–$\mathrm{I3}$。
- [ ] DnaA 同源四聚体认反向重复，促使 $\mathrm{AT}$ 区解链；DnaB 在 DnaC 协同下前移并置换 DnaA；SSB 维持适当叉长。
- [ ] 拓扑酶 $\mathrm{II}$：正超螺旋 $\rightarrow$ 负超螺旋，负超螺旋模板更好。
- [ ] $\mathrm{DNA}\,\mathrm{pol}$ 不能连两个游离 $\mathrm{dNTP}$；引发酶做 $\mathrm{RNA}$ 引物（$5\sim 10\,\mathrm{nt}$，$\mathrm{NTP}$，$5'\rightarrow 3'$）。
- [ ] 引发酶 $\neq$ 转录 $\mathrm{RNA}\,\mathrm{pol}$：利福平抑制后者，引发酶不敏感。
- [ ] 起始复合物：DnaB、DnaC、引发酶 $+$ 起点 $\mathrm{DNA}$；$\Phi\mathrm{X}$ 系统称引发体；移动需 $\mathrm{ATP}$。
- [ ] 延长酶是 $\mathrm{pol}\,\mathrm{III}$；同一酶催化两股，后随链模板绕环对齐；前导链先于后随链。
- [ ] $E.coli$：$20$ 分钟一代，约 $4\,600\,\mathrm{kb}$，约 $3\,800$ 核苷酸/s。
- [ ] $\mathrm{ter}$ 在汇合点两侧约 $100\,\mathrm{bp}$（$\mathrm{ter}\,E/D/A$ 与 $\mathrm{ter}\,C/B$）；Tus 反解旋酶挡 DnaB；汇合可偏 $200\,\mathrm{bp}$ 以内。
- [ ] 去引物、填 gap 用 $\mathrm{pol}\,\mathrm{I}$ 不用 $\mathrm{pol}\,\mathrm{III}$；nick 用连接酶；延长中已陆续进行。
- [ ] 后复制片段提供 $3'$-$\mathrm{OH}$ 填先复制片段的引物空隙；前导链引物空隙由环上最后的 $3'$-$\mathrm{OH}$ 填平。
:::
