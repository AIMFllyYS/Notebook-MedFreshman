# 第二节　线粒体氧化体系与氧化呼吸链

第一节把 $\mathrm{ATP}$ 写成能量货币，并把营养物质氧化的大头交给还原性辅酶。本节进入线粒体：$\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 怎样把氢和电子逐步交给氧，生成水并逐步释能。先认递氢体／递电子体——烟酰胺、黄素、泛醌、铁硫、细胞色素；再把线粒体内膜上的复合体Ⅰ–Ⅳ、可移动的 $\mathrm{Q}$ 和 $\mathrm{Cyt}\,c$ 排成呼吸链。$\mathrm{NADH}$ 从复合体Ⅰ进，$\mathrm{FADH}_2$／琥珀酸从复合体Ⅱ进，二者在泛醌汇合，不把复合体Ⅱ写成复合体Ⅰ的下游。$\mathrm{NADPH}$ 走合成还原，不与 $\mathrm{NADH}$ 并户。$\mathrm{P/O}$ 和质子回流驱动 $\mathrm{ATP}$ 合酶交给第三节。

生物氧化的核心是通过酶促反应使营养物质被彻底氧化、产生能量，而且能量能够被捕获和利用，因此需要特定的氧化体系及底物。线粒体生物氧化体系及酶促反应，能对营养物质氧化分解时产生的还原性辅酶 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 进行彻底氧化，生成 $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$ 并产生 $\mathrm{ATP}$、热能等。$\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 在线粒体被氧化时，需要一系列的酶催化，逐步脱氢、失电子，最终将电子和 $\mathrm{H}^{+}$ 传递给氧而生成水；能量也不会在瞬间大量释放产生高温、高热，而是逐步释放并储存在 $\mathrm{ATP}$ 中。因此，线粒体氧化体系的重要功能是为机体提供能量，是真核细胞生成 $\mathrm{ATP}$ 的主要部位，被称为“能量工厂”。

:::definition{label="线粒体氧化体系"}
线粒体氧化体系把营养物质分解产生的 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 彻底氧化，生成 $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$，并产生 $\mathrm{ATP}$ 和热能。电子和 $\mathrm{H}^{+}$ 经一系列酶逐步交给氧，能量逐步释放并装进 $\mathrm{ATP}$。真核细胞生成 $\mathrm{ATP}$ 的主要部位，称“能量工厂”。
:::

:::concept{term="先问递氢体是谁，再问电子从哪一个复合体进"}
看见“呼吸链”，先不要默写 $\mathrm{P/O}$。户头是：内膜上有会递氢、递电子的组分，按对电子亲和力从低到高排列，最后把电子交给 $\mathrm{O}_2$。$\mathrm{NADH}$ 走复合体Ⅰ，$\mathrm{FADH}_2$ 走复合体Ⅱ，在 $\mathrm{Q}$ 汇合后共用Ⅲ→$\mathrm{Cyt}\,c$→Ⅳ。$\mathrm{NADPH}$ 不进这条产能账。
:::

:::pitfall{label="能量工厂产的是逐步释放的 ATP，不是燃烧式高温"}
第一节已经写：细胞内受不了一次烧完。本节把“逐步”落到分子：每个复合体只传一段电子，有的顺带把 $\mathrm{H}^{+}$ 泵到膜间隙。高温高热不是呼吸链的产品。
:::

## 一、线粒体氧化体系含多种传递氢和电子的组分

线粒体氧化体系主要将 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 中的 $\mathrm{H}^{+}$ 和电子传递给氧，生成水并释能，需要多种具有传递氢和电子的组分参与传递过程。

### （一）烟酰胺腺苷酸类化合物传递氢和电子

$\mathrm{NAD}^{+}$ 是烟酰胺与腺苷酸形成的有机化合物，能通过烟酰胺环传递 $\mathrm{H}^{+}$ 和电子。烟酰胺环的五价氮原子，能接受 $2\mathrm{H}$ 中的双电子成为三价氮，为双电子传递体，同时芳环接受一个 $\mathrm{H}^{+}$ 进行加氢反应。由于此反应只能接受 $1$ 个 $\mathrm{H}^{+}$ 和 $2$ 个电子，游离出一个 $\mathrm{H}^{+}$ 在介质中，因此还原型的 $\mathrm{NAD}^{+}$ 写为 $\mathrm{NADH}+\mathrm{H}^{+}$（$\mathrm{NADH}$）（图10-3，图10-4）。$\mathrm{NAD}^{+}$ 是许多脱氢酶的辅酶，有传递氢和电子的功能。此外，$\mathrm{NAD}^{+}$ 结构中核糖的 $2$ 位羟基被磷酸化后生成 $\mathrm{NADP}^{+}$，通过相同的机制接受氢后生成 $\mathrm{NADPH}+\mathrm{H}^{+}$（简写为 $\mathrm{NADPH}$），发挥传递氢和电子的作用，但参与不同的反应。

::figure{src="/images/biochemistry/textbook/p0227_01.png" caption="图10-3　NAD(P)+ 的结构式。左侧烟酰胺环（蓝色）经核糖、焦磷酸与腺苷相连；NAD+ 的 R＝H，NADP+ 的 R＝磷酸基，磷酸加在腺苷核糖的 2′ 羟基。" alt="NAD+ 与 NADP+ 结构式，烟酰胺环高亮，NADP+ 在腺苷核糖 2′ 位多一个磷酸"}

::figure{src="/images/biochemistry/textbook/p0227_02.png" caption="图10-4　NAD(P)+ 的加氢和 NAD(P)H 的脱氢反应。烟酰胺环五价氮接受双电子，芳环 C-4 加上一个氢，介质中留下一个 H+。" alt="NAD+ 或 NADP+ 的烟酰胺环可逆加氢生成 NADH 或 NADPH，并释放 H+"}

:::definition{label="NAD+"}
$\mathrm{NAD}^{+}$ 是烟酰胺与腺苷酸形成的有机化合物，许多脱氢酶的辅酶。烟酰胺环为双电子传递体：五价氮接受 $2$ 个电子成三价氮，芳环接受 $1$ 个 $\mathrm{H}^{+}$，另一个 $\mathrm{H}^{+}$ 留在介质中，还原型写 $\mathrm{NADH}+\mathrm{H}^{+}$。
:::

:::definition{label="NADP+"}
$\mathrm{NADP}^{+}$ 是 $\mathrm{NAD}^{+}$ 中与腺苷相连的核糖 $2$ 位羟基被磷酸化的产物。加氢机制与 $\mathrm{NAD}^{+}$ 相同，还原型为 $\mathrm{NADPH}+\mathrm{H}^{+}$。传递氢和电子，但参与的反应与 $\mathrm{NADH}$ 不同。
:::

:::compare{title="NADH 和 NADPH 不并户"}
| 项目 | $\mathrm{NADH}$ | $\mathrm{NADPH}$ |
|------|----------------|-----------------|
| 结构差别 | 腺苷核糖 $2'$ 为羟基 | $2'$ 为磷酸基（图10-3 的 $\mathrm{R}$） |
| 加氢机制 | 烟酰胺环：$2\mathrm{e}^{-}+1\,\mathrm{H}^{+}$，介质留 $1\,\mathrm{H}^{+}$ | 相同 |
| 本节后文 | 呼吸链底物，从复合体Ⅰ进，产能 | 磷酸基团被生物合成酶识别，主要用于合成代谢的还原反应，不参与能量代谢 |
| 考试陷阱 | 写成“都是递氢体所以都进呼吸链” | 与戊糖磷酸途径、脂肪酸合成那本账串户 |
:::

:::pitfall{label="NADH 写成 NADH+H+ 不是笔误"}
烟酰胺环只收 $1$ 个 $\mathrm{H}^{+}$ 和 $2$ 个电子，另一个 $\mathrm{H}^{+}$ 在介质里。还原型完整写法是 $\mathrm{NADH}+\mathrm{H}^{+}$，课文常简写 $\mathrm{NADH}$。把 $\mathrm{NAD}^{+}$ 听成“一次收两个氢原子都钉在环上”，图10-4 右侧多出来的 $\mathrm{H}^{+}$ 就没有来处。
:::

:::insight{label="双电子传递体要和后面的单电子载体对接"}
$\mathrm{NAD}^{+}$ 一次传两个电子。后面的铁硫中心、细胞色素一次只传一个电子。中间必须有既能传双电子又能传单电子的衔接者：黄素（经半醌）和泛醌（经半醌）。Q 循环就是为了把双电子的 $\mathrm{QH}_2$ 拆给单电子的 $\mathrm{Cyt}\,c$。
:::

### （二）黄素核苷酸类化合物传递氢和电子

$\mathrm{FMN}$ 和 $\mathrm{FAD}$ 是维生素 $\mathrm{B}_2$ 与核苷酸形成的有机化合物，二者均通过维生素 $\mathrm{B}_2$ 中的异咯嗪环进行可逆的加氢和脱氢反应。异咯嗪环可接受 $1$ 个 $\mathrm{H}^{+}$ 和 $1$ 个电子形成不稳定的 $\mathrm{FMNH}^{\cdot}$ 和 $\mathrm{FADH}^{\cdot}$，再接受 $1$ 个 $\mathrm{H}^{+}$ 和 $1$ 个电子转变为还原型 $\mathrm{FMNH}_2$ 和 $\mathrm{FADH}_2$。因此 $\mathrm{FMN}$、$\mathrm{FAD}$ 发挥传递氢和电子的作用（图10-5），是黄素蛋白（flavoprotein）的辅基。

::figure{src="/images/biochemistry/textbook/p0228_01.png" caption="图10-5　FMN/FAD 的加氢和 FMNH2/FADH2 的脱氢反应。左侧：FAD 比 FMN 多一截 AMP（虚线以上）；异咯嗪环逐步经半醌（FADH·／FMNH·）到全还原型 FADH2／FMNH2。" alt="FMN 与 FAD 结构及异咯嗪环经半醌到全还原型的两步加氢"}

:::definition{label="FMN 与 FAD"}
$\mathrm{FMN}$ 和 $\mathrm{FAD}$ 是维生素 $\mathrm{B}_2$ 与核苷酸形成的化合物，黄素蛋白的辅基。异咯嗪环可逆加氢／脱氢：先成不稳定半醌 $\mathrm{FMNH}^{\cdot}$／$\mathrm{FADH}^{\cdot}$，再成 $\mathrm{FMNH}_2$／$\mathrm{FADH}_2$，故可做双电子传递，也可经半醌做单电子传递。
:::

:::definition{label="黄素蛋白"}
黄素蛋白（flavoprotein）以 $\mathrm{FMN}$ 或 $\mathrm{FAD}$ 为辅基。复合体Ⅰ的黄素蛋白含 $\mathrm{FMN}$，复合体Ⅱ的黄素蛋白含 $\mathrm{FAD}$。
:::

:::compare{title="FMN 在复合体Ⅰ，FAD 在复合体Ⅱ"}
| 辅基 | 所在 | 从谁受氢 | 交给谁 |
|------|------|----------|--------|
| $\mathrm{FMN}$ | 复合体Ⅰ（NADH-泛醌还原酶） | 基质中的 $\mathrm{NADH}$ | $\mathrm{Fe}$-$\mathrm{S}$，再给 $\mathrm{Q}$ |
| $\mathrm{FAD}$ | 复合体Ⅱ（琥珀酸-泛醌还原酶）及若干 $\mathrm{FAD}$ 脱氢酶 | 琥珀酸等 | $\mathrm{Fe}$-$\mathrm{S}$，再给 $\mathrm{Q}$ |

二者都经异咯嗪环，不要写成“$\mathrm{FAD}$ 是 $\mathrm{NADH}$ 呼吸链的入口辅基”。
:::

:::pitfall{label="半醌不稳定，但不是可有可无"}
课文点名 $\mathrm{FMNH}^{\cdot}$、$\mathrm{FADH}^{\cdot}$ 不稳定。没有这一步，黄素就无法在双电子的 $\mathrm{NADH}$／琥珀酸和单电子的 $\mathrm{Fe}$-$\mathrm{S}$ 之间翻译。后面泛醌同样走醌→半醌→氢醌。
:::

### （三）有机化合物泛醌传递氢和电子

泛醌（ubiquinone）又称辅酶 $\mathrm{Q}$（coenzyme $\mathrm{Q}$，$\mathrm{CoQ}$ 或 $\mathrm{Q}$），是一种脂溶性醌类化合物，其结构中异戊二烯单位的数目因物种而异，人体内的 $\mathrm{Q}$ 是 $10$ 个异戊二烯单位连接的侧链，用 $\mathrm{Q}_{10}$ 表示。$\mathrm{Q}$ 的疏水特性使其能在线粒体内膜中自由扩散。$\mathrm{Q}$ 结构中的苯醌部分接受 $1$ 个电子和 $1$ 个 $\mathrm{H}^{+}$ 还原为半醌（${}^{\cdot}\mathrm{QH}$），再接受 $1$ 个电子和 $1$ 个 $\mathrm{H}^{+}$ 还原为二氢泛醌（$\mathrm{QH}_2$）。反之，$\mathrm{QH}_2$ 可逐步失去 $\mathrm{H}^{+}$ 和电子被氧化为 $\mathrm{Q}$。因此 $\mathrm{Q}$ 可进行双、单电子的传递（图10-6）。

::figure{src="/images/biochemistry/textbook/p0228_02.png" caption="图10-6　泛醌的加氢和二氢泛醌的脱氢反应。氧化型（醌型）经半醌型（泛醌 H·）到还原型二氢泛醌（氢醌型）；人体侧链为 n 个异戊二烯单位，人线粒体 n＝10。" alt="泛醌经半醌还原为二氢泛醌的两步可逆反应"}

:::definition{label="泛醌"}
泛醌（ubiquinone）又称辅酶 $\mathrm{Q}$（$\mathrm{CoQ}$ 或 $\mathrm{Q}$），脂溶性醌类化合物。人体为 $\mathrm{Q}_{10}$（$10$ 个异戊二烯单位）。疏水，能在线粒体内膜中自由扩散。苯醌部分经半醌 ${}^{\cdot}\mathrm{QH}$ 到 $\mathrm{QH}_2$，可进行双电子和单电子传递。
:::

:::keypoint{label="Q 为什么是移动的核心"}
- 不固定在某一个复合体里，在内膜脂双层中扩散。
- 从复合体Ⅰ、复合体Ⅱ募集氢，把 $\mathrm{QH}_2$ 送到复合体Ⅲ。
- 既能收双电子，又能拆成单电子，是两条呼吸链的汇合点，也是 Q 循环的底物。
:::

:::insight{label="人体写 Q10，不要只写 CoQ"}
异戊二烯数目因物种而异。人线粒体是 $10$ 个单位。考试若问“人体内的泛醌”，答 $\mathrm{Q}_{10}$，不要只答“辅酶 $\mathrm{Q}$”。
:::

### （四）铁硫蛋白和细胞色素蛋白传递电子

**1. 铁硫蛋白通过铁离子传递电子**　铁硫蛋白（iron-sulfur protein）因其含有铁硫中心（iron-sulfur center，$\mathrm{Fe}$-$\mathrm{S}$ center）而得名。$\mathrm{Fe}$-$\mathrm{S}$ 是 $\mathrm{Fe}$ 离子通过与无机硫（$\mathrm{S}$）原子及铁硫蛋白中半胱氨酸残基的 $\mathrm{SH}$ 连接而成。$\mathrm{Fe}$-$\mathrm{S}$ 有多种形式：可以是单个 $\mathrm{Fe}$ 离子与 $4$ 个半胱氨酸残基的 $\mathrm{SH}$ 相连，也可以是 $2$ 个、$4$ 个 $\mathrm{Fe}$ 离子通过与无机 $\mathrm{S}$ 原子及半胱氨酸残基的 $\mathrm{SH}$ 连接，形成 $\mathrm{Fe}_2\mathrm{S}_2$、$\mathrm{Fe}_4\mathrm{S}_4$（图10-7）。$\mathrm{Fe}$-$\mathrm{S}$ 通过 $\mathrm{Fe}^{2+}\leftrightarrow\mathrm{Fe}^{3+}+\mathrm{e}^{-}$ 的可逆反应，每次传递一个电子，因此铁硫蛋白是单电子传递体。

::figure{src="/images/biochemistry/textbook/p0229_01.png" caption="图10-7　铁硫中心的结构。左：单个 Fe 与 4 个半胱氨酸 SH 相连；中：Fe2S2；右：Fe4S4。蓝色圆为无机硫。" alt="三种铁硫中心：单铁四半胱氨酸、Fe2S2、Fe4S4"}

:::definition{label="铁硫中心"}
铁硫中心（$\mathrm{Fe}$-$\mathrm{S}$）由 $\mathrm{Fe}$ 离子与无机硫及蛋白质半胱氨酸残基的 $\mathrm{SH}$ 连接而成。形式包括：单 $\mathrm{Fe}$ 配 $4$ 个 $\mathrm{Cys}$-$\mathrm{SH}$、$\mathrm{Fe}_2\mathrm{S}_2$、$\mathrm{Fe}_4\mathrm{S}_4$。经 $\mathrm{Fe}^{2+}/\mathrm{Fe}^{3+}$ 每次传一个电子，铁硫蛋白是单电子传递体。
:::

**2. 细胞色素蛋白通过辅基中的铁离子传递电子**　细胞色素（cytochrome，$\mathrm{Cyt}$）是一类含血红素样辅基的蛋白质。各种还原型 $\mathrm{Cyt}$ 均有 $3$ 个特征性的 $\alpha$、$\beta$、$\gamma$ 可见光吸收峰，根据其吸光度和最大吸收波长不同，分为 $\mathrm{Cyt}\,a$、$\mathrm{Cyt}\,b$ 和 $\mathrm{Cyt}\,c$ 三类及不同的亚类（表10-2），其所含的血红素辅基分别称为血红素 $a$、$b$ 和 $c$。$\mathrm{Cyt}$ 光吸收的差异是由于血红素中卟啉环的侧链基团、血红素在蛋白质中所处环境不同所致。

血红素 $a$ 的卟啉环侧链中，$1$ 个甲基被甲酰基取代，$1$ 个乙烯基连接聚异戊二烯长链；血红素 $b$ 的结构与血红蛋白中的血红素相同。血红素 $a$ 和 $b$ 都通过非共价键与 $\mathrm{Cyt}\,a$ 和 $\mathrm{Cyt}\,b$ 蛋白相连。而 $\mathrm{Cyt}\,c$ 蛋白，其血红素卟啉环的乙烯基侧链通过共价键与蛋白中半胱氨酸残基的 $\mathrm{SH}$ 相连。细胞色素蛋白通过辅基血红素中的 $\mathrm{Fe}$ 离子发挥单电子传递体的作用。

:::note{label="电子版缺失"}
教材第 $200$ 页图10-8「细胞色素中 $3$ 种血红素辅基的结构」电子版图源 `p0229_03.png` 为 $0$ 字节，不嵌入 `src`。正文以三类血红素为准：血红素 $a$（甲酰基 $+$ 聚异戊二烯侧链）、血红素 $b$（与血红蛋白中的血红素相同，非共价结合）、血红素 $c$（乙烯基与 $\mathrm{Cys}$-$\mathrm{SH}$ 共价相连）。
:::

:::definition{label="细胞色素"}
细胞色素（cytochrome，$\mathrm{Cyt}$）是含血红素样辅基的蛋白质。还原型有 $\alpha$、$\beta$、$\gamma$ 三个特征可见光吸收峰，据此分为 $\mathrm{Cyt}\,a$、$\mathrm{Cyt}\,b$、$\mathrm{Cyt}\,c$ 及亚类。通过血红素铁 $\mathrm{Fe}^{2+}/\mathrm{Fe}^{3+}$ 每次传递一个电子。
:::

:::definition{label="三种血红素辅基"}
血红素 $a$：一个甲基被甲酰基取代，一个乙烯基连聚异戊二烯长链；与蛋白非共价结合。血红素 $b$：结构与血红蛋白中的血红素相同，非共价结合。血红素 $c$：卟啉乙烯基侧链与蛋白 $\mathrm{Cys}$-$\mathrm{SH}$ 共价相连。
:::

:::

## 二、传递氢和电子的蛋白质复合体是氧化呼吸链的重要组分

$\mathrm{NADH}$、$\mathrm{FADH}_2$ 作为还原性底物在线粒体中通过逐步、连续的酶促反应被氧化，并逐步释放能量。除了产热外，释放的能量主要被 $\mathrm{ADP}$ 捕获用于生成 $\mathrm{ATP}$。催化此连续反应的酶主要是由多个含辅因子的蛋白质复合体组成，按照一定顺序排列在线粒体内膜，形成一条连续的传递电子／氢的反应链，氧分子最终接受电子和 $\mathrm{H}^{+}$ 生成水，故称为电子传递链（electron transfer chain）。由于此体系需要消耗氧，与需氧细胞的呼吸过程有关，也称之为呼吸链（respiratory chain）（图10-9）。

位于线粒体内膜上的四种蛋白质复合体（complex）是组成呼吸链的重要成分，分别称为复合体Ⅰ、Ⅱ、Ⅲ和Ⅳ。每个复合体都由多种酶蛋白、金属离子、辅酶或辅基组成（表10-3）。复合体的辅因子通过得失电子的方式传递电子；有些复合体是跨膜蛋白质，可将 $\mathrm{H}^{+}$ 从线粒体基质侧转运至细胞质侧，形成线粒体内膜两侧 $\mathrm{H}^{+}$ 浓度和电荷的梯度差。因此，呼吸链在传递电子的过程中，伴随着 $\mathrm{H}^{+}$ 的跨膜转运。

:::definition{label="电子传递链"}
电子传递链（electron transfer chain）是排列在线粒体内膜上、按序传递电子／氢的连续反应链，氧分子最终接受电子和 $\mathrm{H}^{+}$ 生成水。因耗氧、与细胞呼吸有关，又称呼吸链（respiratory chain）。
:::

:::definition{label="呼吸链的四种复合体"}
线粒体内膜上的四种蛋白质复合体：Ⅰ NADH-泛醌还原酶，Ⅱ 琥珀酸-泛醌还原酶，Ⅲ 泛醌-细胞色素 $c$ 还原酶，Ⅳ 细胞色素氧化酶。加上可移动的 $\mathrm{Q}$ 和 $\mathrm{Cyt}\,c$，构成完整呼吸链。
:::

:::note{label="表10-3　人线粒体的呼吸链复合体"}
质量、亚基数目按教材。结合位点：Ⅰ、Ⅱ在基质侧接底物、在脂质核心接 $\mathrm{Q}$；Ⅲ、Ⅳ在膜间隙侧接 $\mathrm{Cyt}\,c$。
:::

### （一）复合体Ⅰ将 NADH 的电子传递给泛醌并外排质子

**1. 复合体Ⅰ是 NADH-泛醌还原酶**　复合体Ⅰ又称 NADH-$\mathrm{Q}$ 还原酶或 NADH 脱氢酶（NADH dehydrogenase），是呼吸链的主要入口，其功能是接受来自 $\mathrm{NADH}$ 的电子并转移给 $\mathrm{Q}$。复合体Ⅰ由黄素蛋白、铁硫蛋白等组成，是跨膜蛋白质，呈“L”形：长臂一端突出于线粒体基质，包括黄素蛋白（含 $\mathrm{FMN}$ 和 $\mathrm{Fe}$-$\mathrm{S}$ 辅基）、铁硫蛋白（含 $\mathrm{Fe}$-$\mathrm{S}$ 辅基），可结合基质中的 $\mathrm{NADH}$；嵌于内膜的横臂为疏水部分，含 $\mathrm{Fe}$-$\mathrm{S}$ 辅基。黄素蛋白和铁硫蛋白均通过辅基发挥传递电子作用（图10-9）。

**2. 复合体Ⅰ传递电子并泵出质子**　黄素蛋白辅基 $\mathrm{FMN}$ 从基质中接受 $\mathrm{NADH}$ 中的 $2\mathrm{H}^{+}$ 和 $2\mathrm{e}^{-}$ 生成 $\mathrm{FMNH}_2$，经过一系列的 $\mathrm{Fe}$-$\mathrm{S}$ 将电子传递给内膜中的 $\mathrm{Q}$，形成 $\mathrm{QH}_2$，即：

$$
\mathrm{NADH}\rightarrow\mathrm{FMN}\rightarrow\mathrm{Fe\text{-}S}\rightarrow\mathrm{Q}
$$

由于 $\mathrm{Q}$ 在线粒体内膜中可自由移动，在各复合体间募集并穿梭传递氢，因此在电子传递和质子的移动中发挥核心作用。

复合体Ⅰ还具有质子泵功能：将一对电子从 $\mathrm{NADH}$ 传递给 $\mathrm{Q}$ 的过程中，能将 $4$ 个 $\mathrm{H}^{+}$ 从线粒体的基质侧（negative side，$\mathrm{N}$ 侧）泵到膜间隙侧（positive side，$\mathrm{P}$ 侧），泵出质子所需的能量来自电子传递过程。

:::definition{label="复合体Ⅰ"}
复合体Ⅰ是 NADH-泛醌还原酶（NADH-$\mathrm{Q}$ 还原酶，NADH 脱氢酶），呼吸链主要入口。人线粒体约 $850\,\mathrm{kDa}$、$45$ 个亚基，辅基 $\mathrm{FMN}$ 和 $\mathrm{Fe}$-$\mathrm{S}$。L 形跨膜：基质侧长臂结合 $\mathrm{NADH}$，内膜横臂疏水。电子路径 $\mathrm{NADH}\rightarrow\mathrm{FMN}\rightarrow\mathrm{Fe}$-$\mathrm{S}\rightarrow\mathrm{Q}$；每对电子泵出 $4\,\mathrm{H}^{+}$。
:::

:::definition{label="N 侧与 P 侧"}
基质侧为负电侧（negative side，$\mathrm{N}$ 侧），膜间隙侧为正电侧（positive side，$\mathrm{P}$ 侧）。质子从 $\mathrm{N}$ 侧泵向 $\mathrm{P}$ 侧，形成浓度梯度和电位差，第三节用它驱动 $\mathrm{ATP}$ 合成。
:::

:::timeline{period="复合体Ⅰ"}
- **入口** 基质 NADH 结合在 L 形长臂
- **受氢** FMN 接受 2H+ 和 2e-，成 FMNH2
- **单电子接力** 一系列 Fe-S 把电子传到内膜中的 Q，生成 QH2
- **质子泵** 一对电子从 NADH 到 Q，4 个 H+ 从 N 侧泵到 P 侧
:::

### （二）复合体Ⅱ将琥珀酸的电子传递给泛醌

**1. 复合体Ⅱ是琥珀酸-泛醌还原酶**　复合体Ⅱ是琥珀酸-泛醌还原酶，即三羧酸循环中的琥珀酸脱氢酶（succinate dehydrogenase），其功能是将电子从琥珀酸传递给 $\mathrm{Q}$，主要通过黄素蛋白（$\mathrm{FAD}$ 为辅基）、铁硫蛋白和细胞色素 $b_{560}$ 进行电子传递。人复合体Ⅱ通过其疏水亚基锚定于线粒体内膜，而伸向基质的亚基含有底物琥珀酸的结合位点，以及 $\mathrm{Fe}$-$\mathrm{S}$ 和 $\mathrm{FAD}$ 辅基（图10-9）。

**2. 复合体Ⅱ传递电子但不外排质子**　复合体Ⅱ催化底物琥珀酸的脱氢反应，使 $\mathrm{FAD}$ 转变为 $\mathrm{FADH}_2$，后者再将电子经 $\mathrm{Fe}$-$\mathrm{S}$ 传递到 $\mathrm{Q}$，即：

$$
\text{琥珀酸}\rightarrow\mathrm{FAD}\rightarrow\mathrm{Fe\text{-}S}\rightarrow\mathrm{Q}
$$

此过程释放的自由能较小，不足以将 $\mathrm{H}^{+}$ 泵出线粒体内膜，因此复合体Ⅱ没有 $\mathrm{H}^{+}$ 泵的功能。另外，血红素 $b$ 辅基没有参与该电子传递过程，但它结合此过程中“漏出”的电子，防止单电子从琥珀酸传递给分子氧而产生活性氧。

代谢途径中另外一些含 $\mathrm{FAD}$ 的脱氢酶，如脂酰 $\mathrm{CoA}$ 脱氢酶、甘油-3-磷酸脱氢酶、胆碱脱氢酶等，通过不同的方式将相应底物脱下的氢经 $\mathrm{FAD}$ 传递给 $\mathrm{Q}$，进入呼吸链。

:::definition{label="复合体Ⅱ"}
复合体Ⅱ是琥珀酸-泛醌还原酶，即三羧酸循环的琥珀酸脱氢酶。约 $140\,\mathrm{kDa}$、$4$ 个亚基，辅基 $\mathrm{FAD}$、$\mathrm{Fe}$-$\mathrm{S}$。电子路径：琥珀酸 $\rightarrow\mathrm{FAD}\rightarrow\mathrm{Fe}$-$\mathrm{S}\rightarrow\mathrm{Q}$。不泵质子。
:::

:::definition{label="复合体Ⅱ的血红素 b"}
复合体Ⅱ含细胞色素 $b_{560}$（血红素 $b$），不参加琥珀酸到 $\mathrm{Q}$ 的主路径，而是捕获漏出的单电子，防止其交给分子氧产生活性氧。
:::

:::pitfall{label="复合体Ⅱ不是复合体Ⅰ的下游"}
两条链在 $\mathrm{Q}$ 汇合。复合体Ⅱ不接复合体Ⅰ传来的电子，而是自己从琥珀酸（或其它 $\mathrm{FAD}$ 脱氢酶）进。写成“Ⅰ→Ⅱ→Ⅲ→Ⅳ”，琥珀酸呼吸链和 $\mathrm{P/O}\,1.5$ 都对不上。
:::

:::insight{label="不泵质子，所以 FADH2 少 1 个 ATP 当量"}
复合体Ⅰ那 $4\,\mathrm{H}^{+}$ 这一笔，琥珀酸入口没有。后面Ⅲ、Ⅳ照走，本版一对电子经琥珀酸呼吸链约 $1.5\,\mathrm{ATP}$，经 $\mathrm{NADH}$ 呼吸链约 $2.5\,\mathrm{ATP}$。第三节用 $\mathrm{P/O}$ 把这两个数字钉死。
:::

:::compare{title="还可以经 FAD 进 Q 的脱氢酶"}
| 酶 | 来路 | 交给呼吸链的方式 |
|----|------|------------------|
| 琥珀酸脱氢酶（复合体Ⅱ本身） | 三羧酸循环 | $\mathrm{FAD}\rightarrow\mathrm{Fe}$-$\mathrm{S}\rightarrow\mathrm{Q}$ |
| 脂酰 $\mathrm{CoA}$ 脱氢酶 | 脂肪酸 β-氧化 | 经 $\mathrm{FAD}$ 把氢传给 $\mathrm{Q}$ |
| 甘油-3-磷酸脱氢酶 | 细胞质 $\mathrm{NADH}$ 的甘油-3-磷酸穿梭 | 内膜膜间隙侧的 $\mathrm{FAD}$ 同工酶，直接给 $\mathrm{Q}$ |
| 胆碱脱氢酶 | 胆碱氧化 | 经 $\mathrm{FAD}$ 给 $\mathrm{Q}$ |
:::

### （三）复合体Ⅲ将还原型泛醌的电子传递给细胞色素 c 并外排质子

**1. 复合体Ⅲ是泛醌-细胞色素 c 氧化还原酶**　复合体Ⅲ称为泛醌-细胞色素 $c$ 氧化还原酶（ubiquinone-cytochrome $c$ oxidoreductase），其功能是接受 $\mathrm{QH}_2$ 的电子并传递给 $\mathrm{Cyt}\,c$。$\mathrm{Q}$ 从复合体Ⅰ、复合体Ⅱ募集氢，产生的 $\mathrm{QH}_2$ 穿梭至复合体Ⅲ，后者将电子传递给 $\mathrm{Cyt}\,c$ 蛋白。

人复合体Ⅲ由 $\mathrm{Cyt}\,b$（$b_{562}$，$b_{566}$）、$\mathrm{Cyt}\,c_1$ 和铁硫蛋白组成二聚体，呈梨形。其中 $\mathrm{Cyt}\,c_1$ 和铁硫蛋白的疏水区段将复合体锚定在线粒体内膜。复合体Ⅲ有 $2$ 个 $\mathrm{Q}$ 结合位点，分别处于膜间隙侧（$\mathrm{Q}_\mathrm{P}$）和基质侧（$\mathrm{Q}_\mathrm{N}$ 位点）（图10-10）。

::figure{src="/images/biochemistry/textbook/p0231_01.png" caption="图10-10　复合体Ⅲ的结构及 Q 循环。膜间隙侧 QH2 把一个电子经 Fe-S、血红素 c1 交给细胞色素 c，并放出 2H+；另一个电子经血红素 b 交给基质侧的 Q，再经半醌、基质 2H+ 还原成 QH2。" alt="复合体Ⅲ Q 循环：P 侧 QH2 分出两条电子路径，N 侧 Q 被还原为 QH2"}

**2. 复合体Ⅲ传递电子并泵出质子**　由于 $\mathrm{Q}$ 是双电子传递体，而 $\mathrm{Cyt}\,c$ 是单电子载体，所以复合体Ⅲ将电子从 $\mathrm{QH}_2$ 传递给 $\mathrm{Cyt}\,c$ 的过程是通过“Q 循环”（Q cycle）实现的。

简单而言，$\mathrm{QH}_2$ 结合在 $\mathrm{Q}_\mathrm{P}$ 位点，分别将 $2\mathrm{e}^{-}$ 经 $\mathrm{Fe}$-$\mathrm{S}$ 传递给 $\mathrm{Cyt}\,c_1$ 和结合在 $\mathrm{Q}_\mathrm{N}$ 位点的 $\mathrm{Q}$。此过程重复一次后，$\mathrm{Q}_\mathrm{P}$ 位点的 $\mathrm{QH}_2$ 将 $2\mathrm{e}^{-}$ 经 $\mathrm{Cyt}\,c_1$ 传递给 $2$ 分子 $\mathrm{Cyt}\,c$，重新释放 $\mathrm{Q}$ 到内膜中，而 $\mathrm{Q}_\mathrm{N}$ 位点的 $\mathrm{Q}$ 接受 $2\mathrm{e}^{-}$ 和基质的 $2\mathrm{H}^{+}$ 被还原为 $\mathrm{QH}_2$。因此每 $2$ 分子 $\mathrm{QH}_2$ 经过 Q 循环，生成 $1$ 分子 $\mathrm{Q}$ 和 $1$ 分子 $\mathrm{QH}_2$，将 $2\mathrm{e}^{-}$ 经 $\mathrm{Cyt}\,c_1$ 传递给 $2$ 分子 $\mathrm{Cyt}\,c$。教材把传递顺序简写为：

$$
\mathrm{QH}_2\rightarrow\mathrm{Cyt}\,b\rightarrow\mathrm{Fe\text{-}S}\rightarrow\mathrm{Cyt}\,c_1\rightarrow\mathrm{Cyt}\,c
$$

另外，复合体Ⅲ还具有质子泵的功能，每传递 $2\mathrm{e}^{-}$ 向膜间隙释放 $4\mathrm{H}^{+}$。

$\mathrm{Cyt}\,c$ 是呼吸链中唯一的水溶性球状蛋白质，与线粒体内膜的外表面疏松结合，不包含在上述复合体中。$\mathrm{Cyt}\,c$ 从复合体Ⅲ中的 $\mathrm{Cyt}\,c_1$ 获得电子，传递到复合体Ⅳ。

:::definition{label="复合体Ⅲ"}
复合体Ⅲ是泛醌-细胞色素 $c$ 氧化还原酶。约 $250\,\mathrm{kDa}$、$11$ 个亚基，辅基为血红素和 $\mathrm{Fe}$-$\mathrm{S}$。人源复合体由 $\mathrm{Cyt}\,b$（$b_{562}$、$b_{566}$）、$\mathrm{Cyt}\,c_1$ 和铁硫蛋白组成梨形二聚体。功能：把 $\mathrm{QH}_2$ 的电子交给 $\mathrm{Cyt}\,c$，并经 Q 循环向膜间隙释放质子。
:::

:::definition{label="Q 循环"}
Q 循环（Q cycle）解决双电子载体 $\mathrm{Q}$ 与单电子载体 $\mathrm{Cyt}\,c$ 的对接。$\mathrm{QH}_2$ 在膜间隙侧 $\mathrm{Q}_\mathrm{P}$ 位点氧化：一个电子经 $\mathrm{Fe}$-$\mathrm{S}\rightarrow\mathrm{Cyt}\,c_1\rightarrow\mathrm{Cyt}\,c$，另一个电子经 $\mathrm{Cyt}\,b$ 到基质侧 $\mathrm{Q}_\mathrm{N}$。两轮之后：净消耗 $1$ 分子 $\mathrm{QH}_2$，还原 $2$ 分子 $\mathrm{Cyt}\,c$，向膜间隙释放 $4\mathrm{H}^{+}$，$\mathrm{Q}_\mathrm{N}$ 侧生成 $1$ 分子新的 $\mathrm{QH}_2$。
:::

:::definition{label="细胞色素 c"}
$\mathrm{Cyt}\,c$ 是呼吸链中唯一的水溶性球状蛋白质，疏松结合于线粒体内膜外表面，不包含在四种复合体中。从 $\mathrm{Cyt}\,c_1$ 得电子，交给复合体Ⅳ。
:::

:::keypoint{label="Q 循环净结果"}
- 投入：$2\,\mathrm{QH}_2$ 在 $\mathrm{Q}_\mathrm{P}$ 氧化。
- 产出：$1\,\mathrm{Q}$（回到内膜）$+1\,\mathrm{QH}_2$（在 $\mathrm{Q}_\mathrm{N}$ 再生）$+2$ 个还原型 $\mathrm{Cyt}\,c$。
- 质子：每传递 $2\mathrm{e}^{-}$，膜间隙侧出现 $4\mathrm{H}^{+}$。
- 两个 $\mathrm{Q}$ 位点：$\mathrm{Q}_\mathrm{P}$ 在 $\mathrm{P}$ 侧，$\mathrm{Q}_\mathrm{N}$ 在 $\mathrm{N}$ 侧。
:::

:::pitfall{label="教材简写 QH2→Cyt b→Fe-S→c1→c 不是同一电子的一条直线"}
$\mathrm{QH}_2$ 的两个电子在 $\mathrm{Q}_\mathrm{P}$ 处分道：一条走 $\mathrm{Fe}$-$\mathrm{S}$–$c_1$–$c$，一条走 $\mathrm{Cyt}\,b$ 到 $\mathrm{Q}_\mathrm{N}$。课文那串箭头是组分清单式简写。画成单个电子依次穿过 $b$ 再穿过 $\mathrm{Fe}$-$\mathrm{S}$，Q 循环的“拆双为单”就没了。
:::

:::timeline{period="Q 循环两轮"}
- **第一分子 QH2 到 QP** 一个电子经 Fe-S、血红素 c1 交给 Cyt c，2H+ 释到膜间隙；另一个电子经血红素 b 交给 QN 的 Q，成半醌
- **第二分子 QH2 到 QP** 同样：一个电子交给第二个 Cyt c，2H+ 再释到膜间隙；另一个电子把 QN 半醌还原
- **QN 收尾** 基质侧 2H+ 加上两个电子，生成 QH2 回到内膜
- **净账** 2 QH2 → 1 Q ＋ 1 QH2，2 个电子交给 2 分子 Cyt c，膜间隙 4H+
:::

### （四）复合体Ⅳ将还原型细胞色素 c 的电子传递给氧并外排质子

**1. 复合体Ⅳ是细胞色素氧化酶**　复合体Ⅳ是电子传递链的出口，其功能是接受还原型 $\mathrm{Cyt}\,c$ 的电子并传递给 $\mathrm{O}_2$ 生成 $\mathrm{H}_2\mathrm{O}$，又称之为细胞色素氧化酶（cytochrome oxidase），主要包含细胞色素 $aa_3$、铜结合蛋白等进行电子传递。复合体Ⅳ也有质子泵功能，每传递 $2\mathrm{e}^{-}$ 将 $2$ 个 $\mathrm{H}^{+}$ 泵至膜间隙侧。

人复合体Ⅳ包含 $13$ 个亚基，亚基 $1$～$3$ 构成核心结构，含 $\mathrm{Fe}$、$\mathrm{Cu}$ 离子结合位点，发挥电子传递作用。亚基 $2$ 的半胱氨酸-$\mathrm{SH}$ 可结合 $2$ 个 $\mathrm{Cu}$ 离子，每个 $\mathrm{Cu}$ 离子都可传递电子，形成一个双核中心（binuclear center）的功能单元，第一个双核中心称 $\mathrm{Cu}_\mathrm{A}$ 中心，其结构类似 $\mathrm{Fe}_2\mathrm{S}_2$（图10-11）。$\mathrm{Cu}_\mathrm{A}$ 中心与 $\mathrm{Cyt}\,a$ 蛋白中血红素的 $\mathrm{Fe}$ 极为接近（$1.5\,\mathrm{nm}$），电子可由 $\mathrm{Cu}_\mathrm{A}$ 中心传递到 $\mathrm{Cyt}\,a$。而亚基 $1$ 含血红素 $a$ 和 $a_3$，在血红素 $a_3$ 邻近处结合 $1$ 个 $\mathrm{Cu}$ 离子，称 $\mathrm{Cu}_\mathrm{B}$，因此血红素 $a_3$ 中的 $\mathrm{Fe}$ 离子和 $\mathrm{Cu}_\mathrm{B}$ 形成第二个双核中心，即血红素 $a_3$-$\mathrm{Cu}_\mathrm{B}$（$\mathrm{Fe}$-$\mathrm{Cu}$）中心。双核中心是复合体Ⅳ发挥电子传递的功能单元（图10-11）。

::figure{src="/images/biochemistry/textbook/p0232_01.png" caption="图10-11　复合体Ⅳ的电子传递过程。膜间隙 P 侧 Cyt c 的电子经 CuA、Cyt a 到 a3-CuB 双核中心；基质侧 1/2 O2＋2H+ 生成 H2O；另有 2H+ 被泵到 P 侧。图中按传递 2e-（还原 1/2 O2）计量。" alt="复合体Ⅳ：Cyt c→CuA→Cyt a→a3-CuB→氧，同时泵出质子"}

**2. 复合体Ⅳ传递电子并泵出质子**　复合体Ⅳ通过铁离子、铜离子传递电子，即还原型 $\mathrm{Cyt}\,c$ 提供的电子经 $\mathrm{Cu}_\mathrm{A}$ 中心传递到 $\mathrm{Cyt}\,a$，再到 $\mathrm{Fe}$-$\mathrm{Cu}$ 中心。需要依次传递 $4$ 个电子，并从线粒体基质获得 $4$ 个 $\mathrm{H}^{+}$，最终将 $1$ 分子 $\mathrm{O}_2$ 还原为 $2$ 分子 $\mathrm{H}_2\mathrm{O}$（图10-12）。

其过程为：$\mathrm{Cyt}\,a$ 传递第一个、第二个电子到氧化态的 $\mathrm{Cyt}\,a_3$-$\mathrm{Cu}_\mathrm{B}$ 双核中心（$\mathrm{Cu}^{2+}$ 和 $\mathrm{Fe}^{3+}$），使 $\mathrm{Cu}^{2+}$ 和 $\mathrm{Fe}^{3+}$ 被还原为 $\mathrm{Cu}^{+}$ 和 $\mathrm{Fe}^{2+}$，并结合 $\mathrm{O}_2$ 分子，形成过氧桥连接的 $\mathrm{Cu}_\mathrm{B}$ 和 $\mathrm{Cyt}\,a_3$，相当于 $2\mathrm{e}^{-}$ 传递至结合的 $\mathrm{O}_2$。中心再获得 $2$ 个 $\mathrm{H}^{+}$ 和第三个电子，$\mathrm{O}_2$ 分子键断开，$\mathrm{Cyt}\,a_3$ 出现 $\mathrm{Fe}^{4+}$ 中间态。再接受第四个电子，$\mathrm{Fe}^{4+}$ 还原为 $\mathrm{Fe}^{3+}$ 并形成 $\mathrm{Cu}_\mathrm{B}^{2+}$ 和 $\mathrm{Fe}^{3+}$ 各结合 $1$ 个 $\mathrm{OH}$ 基团的中间态。最后再获得 $2$ 个 $\mathrm{H}^{+}$，双核中心解离出 $2$ 个 $\mathrm{H}_2\mathrm{O}$ 分子后恢复初始的氧化态（图10-12）。即：

$$
\mathrm{Cyt}\,c\rightarrow\mathrm{Cu}_\mathrm{A}\rightarrow\mathrm{Cyt}\,a\rightarrow\mathrm{Cyt}\,a_3\text{-}\mathrm{Cu}_\mathrm{B}\rightarrow\mathrm{O}_2
$$

生成的 $\mathrm{H}_2\mathrm{O}$ 通过亚基 $1$ 和 $3$ 之间的亲水通道排入胞质侧。上述 $\mathrm{O}_2$ 在获得电子过程产生的具有强氧化性的 ${}^{\cdot}\mathrm{O}_2^{-}$ 和 $\mathrm{O}_2^{2-}$ 离子中间物始终和双核中心紧密结合，通常不会对细胞组分造成损伤。

::figure{src="/images/biochemistry/textbook/p0233_01.png" caption="图10-12　复合体Ⅳ的血红素 a3-CuB 中心使 O2 还原生成水的过程。氧化态 Fe3+/CuB2+ 依次接受电子并结合 O2，经过氧桥、Fe4+ 中间态和双羟基中间态，再取 2H+ 放出 2H2O，回到氧化态。" alt="a3-CuB 双核中心还原氧的循环：结合氧、断开 O-O、放出两分子水"}

:::definition{label="复合体Ⅳ"}
复合体Ⅳ是细胞色素氧化酶，电子传递链的出口。人源 $13$ 个亚基（约 $204\,\mathrm{kDa}$），亚基 $1$～$3$ 为核心。接受还原型 $\mathrm{Cyt}\,c$ 的电子，把 $\mathrm{O}_2$ 还原成 $\mathrm{H}_2\mathrm{O}$。每传递 $2\mathrm{e}^{-}$ 泵出 $2\,\mathrm{H}^{+}$；还原 $1$ 分子 $\mathrm{O}_2$ 需 $4\mathrm{e}^{-}$ 和基质 $4\,\mathrm{H}^{+}$，生成 $2$ 分子 $\mathrm{H}_2\mathrm{O}$。
:::

:::definition{label="CuA 中心"}
亚基 $2$ 的半胱氨酸-$\mathrm{SH}$ 结合 $2$ 个 $\mathrm{Cu}$，构成第一个双核中心 $\mathrm{Cu}_\mathrm{A}$，结构类似 $\mathrm{Fe}_2\mathrm{S}_2$。距 $\mathrm{Cyt}\,a$ 的血红素铁约 $1.5\,\mathrm{nm}$，电子从 $\mathrm{Cu}_\mathrm{A}$ 传到 $\mathrm{Cyt}\,a$。
:::

:::definition{label="血红素 a3-CuB 中心"}
亚基 $1$ 含血红素 $a$ 和 $a_3$；$a_3$ 邻近的 $\mathrm{Cu}_\mathrm{B}$ 与 $a_3$ 的铁构成第二个双核中心（$\mathrm{Fe}$-$\mathrm{Cu}$ 中心）。这是结合并还原 $\mathrm{O}_2$ 的功能单元。
:::

:::timeline{period="复合体Ⅳ还原一分子氧"}
- **电子路径** Cyt c → CuA → Cyt a → a3-CuB → O2
- **前两个电子** 氧化态 Fe3+/Cu2+ 还原为 Fe2+/Cu+，结合 O2，形成过氧桥
- **第三个电子加 2H+** O-O 键断开，出现 Fe4+ 中间态
- **第四个电子** Fe4+ 回到 Fe3+，Fe 与 CuB 各结合一个 OH
- **再加 2H+** 放出 2 分子 H2O，中心回到氧化态；水经亚基 1 和 3 之间的亲水通道排出
:::

:::keypoint{label="4 电子、4 个基质质子、2 分子水"}
还原 $1$ 分子 $\mathrm{O}_2$ 必须凑齐 $4\mathrm{e}^{-}$。图10-11 按 $2\mathrm{e}^{-}$／$1/2\,\mathrm{O}_2$ 画泵出 $2\mathrm{H}^{+}$；文字按整分子氧写基质提供 $4\mathrm{H}^{+}$ 生成 $2\,\mathrm{H}_2\mathrm{O}$。两套计量不要混成“传 $2\mathrm{e}^{-}$ 就生成 $2\,\mathrm{H}_2\mathrm{O}$”。
:::

:::pitfall{label="超氧和过氧中间物通常不泄漏"}
${}^{\cdot}\mathrm{O}_2^{-}$、$\mathrm{O}_2^{2-}$ 氧化性很强，但课文写它们始终与双核中心紧密结合，通常不损伤细胞组分。不要把复合体Ⅳ写成“呼吸链漏活性氧的主出口”；复合体Ⅱ的血红素 $b$ 那一笔，才是防漏给分子氧。
:::

## 三、呼吸链通过氧化 NADH 和 FADH2 释放能量

呼吸链是将多个电子／氢的传递体按序排列组合，用于进行连续的氧化还原反应、产生能量。线粒体的内膜形成许多向内折叠的嵴，增加内膜的面积，可结合包括呼吸链在内的许多蛋白质／酶。组成呼吸链的复合体都嵌于线粒体内膜中，按照对电子亲和力逐渐增加的顺序进行排列，最终将电子传递给氧，完成电子的氧化并释放能量。

:::insight{label="嵴是为了铺开内膜"}
呼吸链复合体嵌在内膜上。嵴把内膜面积做大，才能装下足够的复合体。能量工厂的厂房面积，首先是内膜面积。
:::

### （一）蛋白质复合体和泛醌及细胞色素 c 组成呼吸链

**1. 呼吸链组分有序排列传递电子／氢**　上述四个蛋白质复合体是组成呼吸链的主要组分，基本“固定”于线粒体内膜，还需要“流动”的传递手参加方可完成电子的传递，即 $\mathrm{Q}$ 和 $\mathrm{Cyt}\,c$。因此呼吸链的组分包含四个复合体、$\mathrm{Q}$ 和 $\mathrm{Cyt}\,c$。$\mathrm{Q}$ 是脂溶性的小分子化合物，能在内膜中移动进行电子传递；$\mathrm{Cyt}\,c$ 作为水溶性蛋白，在膜间隙侧将电子从复合体Ⅲ传递给复合体Ⅳ；四个蛋白质复合体通过黄素蛋白、铁硫蛋白以及细胞色素等结合的辅基进行电子传递。

呼吸链进行的电子传递，有严格的传递方向和排列顺序，其组分是按照对电子亲和力从小到大的顺序排列，即电子的流动方向是从氧化还原电位较低的传递体依次到较高的组分、最后流向氧分子。组分的排列顺序为（图10-9）：

$$
\text{复合体Ⅰ}\rightarrow\mathrm{Q}\rightarrow\text{复合体Ⅲ}\rightarrow\mathrm{Cyt}\,c\rightarrow\text{复合体Ⅳ}\rightarrow\mathrm{O}_2
$$

$$
\text{复合体Ⅱ}\rightarrow\mathrm{Q}\rightarrow\text{复合体Ⅲ}\rightarrow\mathrm{Cyt}\,c\rightarrow\text{复合体Ⅳ}\rightarrow\mathrm{O}_2
$$

泛醌不包含在复合体中，借助能在脂溶性内膜中移动的特点，在复合体之间穿梭传递电子／氢，成为移动传递者。同样，$\mathrm{Cyt}\,c$ 也不包含在复合体中，作为水溶性电子载体，负责从复合体Ⅲ中的 $\mathrm{Cyt}\,c_1$ 获得电子并传递到复合体Ⅳ。需要注意的是，复合体Ⅱ并不是处于复合体Ⅰ的下游，复合体Ⅰ和复合体Ⅱ分别从各自的底物获得电子、向泛醌传递。

:::definition{label="呼吸链的固定组分与流动组分"}
四种复合体基本固定于内膜。流动组分有两个：脂溶性的 $\mathrm{Q}$ 在内膜中移动；水溶性的 $\mathrm{Cyt}\,c$ 在膜间隙侧移动。没有这两个“传递手”，固定复合体无法把电子送完。
:::

:::pitfall{label="不要把呼吸链写成Ⅰ→Ⅱ→Ⅲ→Ⅳ一条直线"}
正确是两条入口在 $\mathrm{Q}$ 汇合。复合体Ⅱ与复合体Ⅰ并联，不是串联。图10-9 把复合体Ⅱ画在Ⅰ、Ⅲ之间，那是空间位置，不是电子从Ⅰ流进Ⅱ。
:::

**2. 呼吸链组分根据氧化还原能力进行排序**　呼吸链各组分的排列顺序是由下列实验确定的：

① 根据呼吸链各组分的标准氧化还原电位进行排序。电位低的组分倾向于给出电子，排序在前；电位高的组分对电子的亲和力强，易接受电子，排序在后。因此呼吸链中电子从电位低的组分向电位高的组分进行传递（表10-4）。

② 底物存在时，利用呼吸链特异的抑制剂阻断某一组分的电子传递，在阻断部位以前的组分处于还原状态，后面的组分处于氧化状态。根据各组分的氧化和还原状态吸收光谱的改变分析其排列次序。

③ 利用呼吸链各组分特有的吸收光谱，以离体线粒体无氧时处于还原状态作为对照，缓慢给氧，观察各组分被氧化的顺序。

④ 在体外将呼吸链组分拆开和重组，鉴定四种复合体的组成与排列。

:::definition{label="呼吸链排序的四类实验"}
① 按 $E^{\circ}$ 从低到高排；② 特异抑制剂：阻断点以前还原、以后氧化；③ 无氧全还原后缓慢给氧，看谁先被氧化；④ 拆开重组，核对复合体组成与排列。
:::

:::note{label="表10-4　呼吸链中各种氧化还原对的标准氧化还原电位"}
单位 $E^{\circ}/\mathrm{V}$。$\mathrm{Cyt}\,b_\mathrm{L}$（$b_\mathrm{H}$）教材记为 $0.05$（$0.10$）。电子从负电位的 $\mathrm{NAD}^{+}/\mathrm{NADH}$ 流向正电位的 $1/2\,\mathrm{O}_2/\mathrm{H}_2\mathrm{O}$。
:::

| 氧化还原对 | $E^{\circ}/\mathrm{V}$ | 氧化还原对 | $E^{\circ}/\mathrm{V}$ |
|------------|----------------------|------------|----------------------|
| $\mathrm{NAD}^{+}/\mathrm{NADH}$ | $-0.32$ | $\mathrm{Cyt}\,c_1\ \mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$ | $0.22$ |
| $\mathrm{FMN}/\mathrm{FMNH}_2$ | $-0.219$ | $\mathrm{Cyt}\,c\ \mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$ | $0.254$ |
| $\mathrm{FAD}/\mathrm{FADH}_2$ | $-0.219$ | $\mathrm{Cyt}\,a\ \mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$ | $0.29$ |
| $\mathrm{Cyt}\,b_\mathrm{L}$（$b_\mathrm{H}$）$\mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$ | $0.05$（$0.10$） | $\mathrm{Cyt}\,a_3\ \mathrm{Fe}^{3+}/\mathrm{Fe}^{2+}$ | $0.35$ |

:::insight{label="电位表就是呼吸链的路线图"}
从 $-0.32$ 的 $\mathrm{NADH}$ 到 $+0.816$ 的氧，中间 $\mathrm{FMN}/\mathrm{FAD}$、$\mathrm{Q}$、细胞色素逐步抬高。第一节的 $\Delta G^{\prime\circ}=-nF\Delta E^{\circ}$ 在这里变成“每一跳能释放多少自由能”。第三节会用 $\mathrm{NAD}^{+}\rightarrow\mathrm{Q}$、$\mathrm{Q}\rightarrow\mathrm{Cyt}\,c$、$a/a_3\rightarrow\mathrm{O}_2$ 三段电位差，核对Ⅰ、Ⅲ、Ⅳ为什么是偶联部位。
:::

:::pitfall{label="抑制剂实验：堵住的上游是还原态"}
电子流被切断后，前面的载体仍能从底物收电子却交不出去，所以还原；后面的载体把电子交给氧后无法再被补上，所以氧化。不要记反成“阻断点以前氧化”。
:::

### （二）NADH 和 FADH2 为两条呼吸链提供还原当量

通常将 $1$ 摩尔的氢原子（含 $1$ 个质子和 $1$ 个电子）称为 $1$ 个还原当量（reducing equivalent）。营养物质的分解代谢中，大部分脱氢酶以 $\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$、$\mathrm{FMN}$ 或者 $\mathrm{FAD}$ 为辅酶或辅基，用来接受从底物上脱下来的成对氢原子，生成还原态的 $\mathrm{NADH}+\mathrm{H}^{+}$、$\mathrm{NADPH}+\mathrm{H}^{+}$、$\mathrm{FMNH}_2$ 和 $\mathrm{FADH}_2$，它们都是还原当量，也是水溶性的电子／氢载体。$\mathrm{NADPH}$ 所含的磷酸基团可被生物合成过程中的酶特异性识别，主要用于合成代谢的还原反应等，而非参与能量代谢。$\mathrm{FMNH}_2$ 和 $\mathrm{FADH}_2$ 作为黄素蛋白的辅基参与电子传递。$\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 作为许多脱氢酶的辅酶／辅基产物，可在不同酶之间进行电子／氢的传递，是呼吸链的底物，是氢和电子的供体。

:::definition{label="还原当量"}
$1$ 摩尔氢原子（含 $1$ 个质子和 $1$ 个电子）称为 $1$ 个还原当量（reducing equivalent）。$\mathrm{NADH}$、$\mathrm{NADPH}$、$\mathrm{FMNH}_2$、$\mathrm{FADH}_2$ 都携带还原当量；只有 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 是呼吸链的产能底物。
:::

:::pitfall{label="四种还原当量不要都写成呼吸链底物"}
$\mathrm{NADPH}$ 也是还原当量，但磷酸基团让合成酶认得它，主场是还原性生物合成，不是呼吸链。$\mathrm{FMNH}_2$ 是复合体Ⅰ内部的辅基态，不是游离底物。呼吸链门口站着的是 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$（琥珀酸等经 $\mathrm{FAD}$ 进）。
:::

**1. 线粒体 NADH 和 FADH2 通过呼吸链直接被氧化**　由于呼吸链的复合体Ⅰ为 NADH 脱氢酶，可使 $\mathrm{NADH}$ 直接通过呼吸链被彻底氧化。复合体Ⅱ是柠檬酸循环中的琥珀酸脱氢酶，通过结合底物琥珀酸并将其脱氢氧化，产生的 $\mathrm{FADH}_2$ 直接进入呼吸链进行氧化。因此，$\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 分别通过两个入口进入氧化体系，形成了两条电子传递链。

一条称为 NADH 呼吸链，以 $\mathrm{NADH}$ 为底物，从 $\mathrm{NADH}$ 开始将电子／氢传递到 $\mathrm{O}_2$ 使之生成 $\mathrm{H}_2\mathrm{O}$ 并产生 $\mathrm{ATP}$。电子传递顺序是：

$$
\mathrm{NADH}\rightarrow\text{复合体Ⅰ}\rightarrow\mathrm{Q}\rightarrow\text{复合体Ⅲ}\rightarrow\mathrm{Cyt}\,c\rightarrow\text{复合体Ⅳ}\rightarrow\mathrm{O}_2
$$

另一条称为 $\mathrm{FADH}_2$ 呼吸链，也称琥珀酸氧化呼吸链，以 $\mathrm{FADH}_2$ 为底物，经复合体Ⅱ到 $\mathrm{O}_2$ 而生成 $\mathrm{H}_2\mathrm{O}$ 和 $\mathrm{ATP}$。电子传递顺序是：

$$
\text{琥珀酸}\rightarrow\text{复合体Ⅱ}\rightarrow\mathrm{Q}\rightarrow\text{复合体Ⅲ}\rightarrow\mathrm{Cyt}\,c\rightarrow\text{复合体Ⅳ}\rightarrow\mathrm{O}_2
$$

线粒体中 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 分别通过 NADH 呼吸链、$\mathrm{FADH}_2$ 呼吸链被彻底氧化，直接参与能量代谢。因此，三羧酸循环产生的还原当量可直接进入呼吸链用于氧化释能。两个体系同在线粒体中，通过 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 进行接力传递，不仅提高效率，而且还可根据能量的需求变化、通过调节三羧酸循环的速率来调节能量的代谢。

:::definition{label="NADH 呼吸链"}
以 $\mathrm{NADH}$ 为底物：$\mathrm{NADH}\rightarrow$ 复合体Ⅰ $\rightarrow\mathrm{Q}\rightarrow$ 复合体Ⅲ $\rightarrow\mathrm{Cyt}\,c\rightarrow$ 复合体Ⅳ $\rightarrow\mathrm{O}_2$。本版一对电子约生成 $2.5$ 分子 $\mathrm{ATP}$（$\mathrm{P/O}$ 接近 $2.5$，第三节）。
:::

:::definition{label="琥珀酸氧化呼吸链"}
又称 $\mathrm{FADH}_2$ 呼吸链：琥珀酸 $\rightarrow$ 复合体Ⅱ $\rightarrow\mathrm{Q}\rightarrow$ 复合体Ⅲ $\rightarrow\mathrm{Cyt}\,c\rightarrow$ 复合体Ⅳ $\rightarrow\mathrm{O}_2$。本版一对电子约生成 $1.5$ 分子 $\mathrm{ATP}$（$\mathrm{P/O}$ 接近 $1.5$）。
:::

:::compare{title="两条呼吸链"}
| 项目 | NADH 呼吸链 | 琥珀酸（$\mathrm{FADH}_2$）呼吸链 |
|------|-------------|----------------------------------|
| 入口复合体 | Ⅰ（$\mathrm{FMN}$） | Ⅱ（$\mathrm{FAD}$） |
| 是否泵质子于入口 | 是，$4\mathrm{H}^{+}$ | 否 |
| 汇合点 | $\mathrm{Q}$ | $\mathrm{Q}$ |
| 下游 | Ⅲ $\rightarrow\mathrm{Cyt}\,c\rightarrow$ Ⅳ $\rightarrow\mathrm{O}_2$ | 同左 |
| 本版 $\mathrm{ATP}$ | 约 $2.5$ | 约 $1.5$ |
:::

:::keypoint{label="本版 2.5 和 1.5，不要写回 3 和 2"}
旧教材把 NADH 链写成 $3\,\mathrm{ATP}$、琥珀酸链写成 $2\,\mathrm{ATP}$。本版与第七、第八章一致：NADH 链 $2.5$，琥珀酸链 $1.5$。葡萄糖 $30$ 或 $32$、软脂酸净 $106$，都用这一套。第三节用 $\mathrm{P/O}$ 比值和自由能变化解释为什么是这三个偶联部位、为什么数字不是整数 $3$ 和 $2$。
:::

**2. 细胞质中的 NADH 通过穿梭进入线粒体呼吸链被氧化**　$\mathrm{NADH}$ 不能自由穿过线粒体内膜。细胞质中经糖酵解等生成的 $\mathrm{NADH}$，需通过穿梭机制进入线粒体的呼吸链才能被氧化。两条穿梭的图（图10-13、图10-14）与第三节同页，电子版图源留给第三节嵌入。机制要点如下。

（1）甘油-3-磷酸穿梭：也称 $\alpha$-甘油磷酸穿梭（$\alpha$-glycerophosphate shuttle）。在脑和肌组织中，细胞质的 $\mathrm{NADH}$ 主要通过此方式进入线粒体呼吸链。细胞质中的 $\mathrm{NADH}$ 在甘油-3-磷酸脱氢酶催化下，将 $2\mathrm{H}$ 传递给磷酸二羟丙酮，使其还原成甘油-3-磷酸；后者通过线粒体外膜到达内膜的膜间隙侧。内膜膜间隙侧结合着甘油-3-磷酸脱氢酶的同工酶，含 $\mathrm{FAD}$ 辅基，接受甘油-3-磷酸的 $2\mathrm{H}$ 生成 $\mathrm{FADH}_2$ 和磷酸二羟丙酮。$\mathrm{FADH}_2$ 直接将 $2\mathrm{H}$ 传递给 $\mathrm{Q}$ 进入呼吸链。因此 $1$ 分子细胞质 $\mathrm{NADH}$ 经此穿梭按 $\mathrm{FADH}_2$ 入口氧化，本版产生 $1.5$ 分子 $\mathrm{ATP}$。

（2）苹果酸-天冬氨酸穿梭：肝、肾及心肌细胞中主要采用此机制。需要 $2$ 种内膜转运蛋白质和 $2$ 种酶协同：细胞质中的 $\mathrm{NADH}+\mathrm{H}^{+}$ 使草酰乙酸还原生成苹果酸；苹果酸经内膜上的苹果酸-$\alpha$-酮戊二酸转运蛋白进入基质，重新生成草酰乙酸，释放 $\mathrm{NADH}+\mathrm{H}^{+}$；基质中的草酰乙酸转变为天冬氨酸后，经内膜上的天冬氨酸-谷氨酸转运蛋白回到细胞质。进入基质的 $\mathrm{NADH}$ 走 NADH 呼吸链，本版生成 $2.5$ 分子 $\mathrm{ATP}$。

:::definition{label="细胞质 NADH 必须穿梭"}
$\mathrm{NADH}$ 不能自由穿过线粒体内膜。糖酵解产生的细胞质 $\mathrm{NADH}$ 要把还原当量送进呼吸链，只能走穿梭，不能把 $\mathrm{NADH}$ 分子本身运进基质。
:::

:::compare{title="两条穿梭决定葡萄糖是 30 还是 32"}
| 穿梭 | 组织 | 还原当量进呼吸链的身份 | 本版 $1$ 分子细胞质 $\mathrm{NADH}$ |
|------|------|------------------------|-----------------------------------|
| 甘油-3-磷酸穿梭 | 脑、肌 | 内膜间隙侧 $\mathrm{FAD}$ 同工酶 → $\mathrm{Q}$（等同 $\mathrm{FADH}_2$ 入口） | $1.5\,\mathrm{ATP}$ |
| 苹果酸-天冬氨酸穿梭 | 肝、肾、心肌 | 基质重新生成 $\mathrm{NADH}$ → 复合体Ⅰ | $2.5\,\mathrm{ATP}$ |

$2$ 分子细胞质 $\mathrm{NADH}$ 相差 $2\,\mathrm{ATP}$，这就是 $1\,\mathrm{mol}$ 葡萄糖 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$ 的分叉。
:::

:::pitfall{label="穿梭运的是还原当量，不是把 NADH 分子搬进线粒体"}
甘油-3-磷酸、苹果酸才过膜。写成“$\mathrm{NADH}$ 转运蛋白把 $\mathrm{NADH}$ 送进基质”，和“不能自由穿过内膜”直接冲突。脑肌走 $1.5$、肝心肾走 $2.5$，也不要对调。
:::

:::memory{label="本节必背要点"}
- [ ] 线粒体氧化体系氧化 $\mathrm{NADH}$、$\mathrm{FADH}_2$，逐步把电子交给氧，称能量工厂
- [ ] $\mathrm{NAD}^{+}$ 双电子传递，还原型 $\mathrm{NADH}+\mathrm{H}^{+}$；$\mathrm{NADP}^{+}$ 是核糖 $2'$ 磷酸化，机制相同但 $\mathrm{NADPH}$ 走合成还原，不产能
- [ ] $\mathrm{FMN}/\mathrm{FAD}$ 经半醌；人体泛醌是 $\mathrm{Q}_{10}$，脂溶、内膜中扩散，双／单电子都能传
- [ ] 铁硫：单 $\mathrm{Fe}$、$\mathrm{Fe}_2\mathrm{S}_2$、$\mathrm{Fe}_4\mathrm{S}_4$，单电子；细胞色素按 $\alpha\beta\gamma$ 吸收峰分 $a$、$b$、$c$
- [ ] 血红素 $a$ 有甲酰基和聚异戊二烯；血红素 $b$ 同血红蛋白、非共价；血红素 $c$ 与 $\mathrm{Cys}$ 共价
- [ ] 呼吸链 $=4$ 个复合体 $+\mathrm{Q}+\mathrm{Cyt}\,c$；$\mathrm{Q}$ 和 $\mathrm{Cyt}\,c$ 可移动
- [ ] Ⅰ：L 形，NADH→FMN→Fe-S→Q，泵 $4\mathrm{H}^{+}$；Ⅱ：琥珀酸→FAD→Fe-S→Q，不泵 $\mathrm{H}^{+}$，血红素 $b$ 防漏电子
- [ ] Ⅲ：Q 循环，每 $2\mathrm{e}^{-}$ 向膜间隙释放 $4\mathrm{H}^{+}$；$\mathrm{Cyt}\,c$ 水溶、内膜外表面
- [ ] Ⅳ：Cyt c→CuA→Cyt a→a3-CuB→O2；4e- 还原 1 分子 O2 成 2 H2O，每 2e- 泵 2H+
- [ ] 两条链在 Q 汇合：NADH 链 2.5 ATP，琥珀酸链 1.5 ATP；Ⅱ不是Ⅰ的下游
- [ ] 排序靠 E°、抑制剂、给氧光谱、拆开重组；NADH −0.32 V，氧 ＋0.816 V
- [ ] 细胞质 NADH 穿梭：脑肌甘油-3-磷酸 1.5，肝心肾苹果酸-天冬氨酸 2.5
:::
