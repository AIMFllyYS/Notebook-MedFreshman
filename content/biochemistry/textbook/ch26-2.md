# 第二节　血红素的合成

第一节把血浆蛋白质和血清酶三类立住以后，本章转入红细胞里最主要的色素蛋白。本节只立「血红素的合成」：原料是甘氨酸、琥珀酰 $\mathrm{CoA}$ 和 $\mathrm{Fe}^{2+}$；起始和终末在线粒体，中间在胞质（图26-4）；限速酶是 $\mathrm{ALA}$ 合酶，辅酶磷酸吡哆醛；$\mathrm{ALA}$ 脱水酶含巯基，铅敏感。成熟红细胞的获能和 $2,3$-$\mathrm{BPG}$ 交给第三节。

:::concept{term="先问原料和线粒体／胞质怎么分工，再问限速酶和铅打在哪两步"}
看见「血红素」，先不要默写血红蛋白四级结构。户头是：珠蛋白加血红素才是血红蛋白；血红素还是肌红蛋白、细胞色素、过氧化物酶的辅基。合成四步里，图26-2 的 $\mathrm{ALA}$ 合酶是限速，图26-3 的 $\mathrm{ALA}$ 脱水酶和最后的亚铁螯合酶都怕铅。成熟红细胞没有线粒体，故不能合成血红素——这一句既是本节的定位，也是第三节开篇的底板。
:::

:::note{label="电子版缺失"}
本节使用的插图是图26-2（$\delta$-氨基-$\gamma$-酮戊酸的合成）、图26-3（胆色素原的合成）和图26-4（血红素的生物合成：线粒体与胞液分工）。第一节的图26-1 是电泳，不要在本节重嵌。
:::

血红蛋白（hemoglobin，$\mathrm{Hb}$）是红细胞中最主要的成分，由珠蛋白和血红素（heme）组成。血红素不但是 $\mathrm{Hb}$ 的辅基，也是肌红蛋白、细胞色素、过氧化物酶等的辅基。血红素可在机体多种细胞内合成，参与血红蛋白组成的血红素主要在骨髓的幼红细胞和网织红细胞中合成。

:::definition{label="血红蛋白"}
红细胞中最主要的成分，由珠蛋白和血红素组成。本节写血红素怎么来；珠蛋白怎么受高铁血红素调控，是第三节末尾的账。
:::

:::definition{label="血红素"}
铁卟啉化合物，是 $\mathrm{Hb}$、肌红蛋白、细胞色素、过氧化物酶等的辅基。多种细胞都能合成；组成血红蛋白的血红素主要在骨髓的幼红细胞和网织红细胞中合成。成熟红细胞不含线粒体，后文特点第①条把它排除在外。
:::

:::pitfall{label="血红素不是只有红细胞才做"}
教材写「可在机体多种细胞内合成」，紧接着限定「参与血红蛋白组成的血红素主要在骨髓的幼红细胞和网织红细胞」。肝也大量合成血红素，给细胞色素 $\mathrm{P}450$ 等用——调节段会再碰到。写成「只有红系细胞合成血红素」，肝 $\mathrm{ALA}$ 合酶那一户就没了。
:::

:::insight{label="幼红细胞和网织红细胞还有线粒体"}
血红素合成的起始和终末都在线粒体。第三节表26-2 写：有核红细胞和网织红细胞能合成血红素，成熟红细胞不能。两节对同一件事：没有线粒体就做不了这套反应。
:::

## 一、合成血红素的基本原料是甘氨酸、琥珀酰 CoA 和 Fe²⁺

合成血红素的基本原料是甘氨酸、琥珀酰 $\mathrm{CoA}$ 和 $\mathrm{Fe}^{2+}$ 等。合成的起始和终末阶段均在线粒体内进行，而中间阶段在胞质内进行。血红素的生物合成可分为四个步骤。

:::definition{label="血红素合成的原料"}
甘氨酸、琥珀酰 $\mathrm{CoA}$ 和 $\mathrm{Fe}^{2+}$ 等简单小分子。不是「必须先有现成的吡咯环从食物来」。
:::

:::keypoint{label="分区先记成两头线粒体、中间胞质"}
- 起始：线粒体合成 $\mathrm{ALA}$（图26-2）。
- 中间：胞质里 $\mathrm{ALA}$ → 胆色素原 → 尿卟啉原Ⅲ → 粪卟啉原Ⅲ（图26-3、图26-4 右侧）。
- 终末：粪卟啉原Ⅲ回线粒体，变成原卟啉Ⅸ再装 $\mathrm{Fe}^{2+}$（图26-4 左侧）。
- 中间产物进出线粒体的机制，本版写「目前尚不清楚」。
:::

### （一）血红素合成的第一步是在线粒体内合成 δ-氨基-γ-酮戊酸

在线粒体内，由琥珀酰 $\mathrm{CoA}$ 与甘氨酸缩合生成 $\delta$-氨基-$\gamma$-酮戊酸（$\delta$-aminolevulinic acid，$\mathrm{ALA}$）（图26-2）。催化此反应的酶是 $\mathrm{ALA}$ 合酶（$\mathrm{ALA}$ synthase），其辅酶是磷酸吡哆醛。此酶是血红素合成的限速酶，受血红素的反馈调节。

:::definition{label="ALA 合酶"}
催化琥珀酰 $\mathrm{CoA}$ 与甘氨酸缩合生成 $\mathrm{ALA}$。辅酶是磷酸吡哆醛。定位线粒体。是血红素合成的限速酶，受血红素反馈调节。维生素 $\mathrm{B}_6$ 缺乏将影响血红素合成，因为磷酸吡哆醛来自维生素 $\mathrm{B}_6$。
:::

:::definition{label="δ-氨基-γ-酮戊酸 ALA"}
琥珀酰 $\mathrm{CoA}$ 与甘氨酸在线粒体缩合的产物。缩合同时放出 $\mathrm{CO}_2$ 和 $\mathrm{HSCoA}$（图26-2）。$\mathrm{ALA}$ 生成后进入胞质，才开始第二步。
:::

::figure{src="/images/biochemistry/textbook/p0515_01.png" caption="图26-2　δ-氨基-γ-酮戊酸的合成" alt="左侧琥珀酰CoA：羧基连两碳再连羰基硫酯；加上甘氨酸（氨基甲基连羧基）。ALA合酶催化，辅酶磷酸吡哆醛，放出HSCoA和CO2，右侧生成ALA：羧基连两碳，再连羰基，末端为氨甲基"}

:::insight{label="图26-2 先认琥珀酰 CoA 的硫酯和甘氨酸的氨基"}
左侧是带 $\mathrm{\sim SCoA}$ 的琥珀酰 $\mathrm{CoA}$，中间加上甘氨酸的碳链。酶名写在横箭头下：$\mathrm{ALA}$ 合酶（磷酸吡哆醛）。斜上箭头标 $\mathrm{HSCoA}+\mathrm{CO}_2$。右侧产物末端是 $\mathrm{CH}_2\mathrm{NH}_2$，这就是「$\delta$-氨基」。不要把磷酸吡哆醛画成底物。
:::

:::pitfall{label="限速酶是 ALA 合酶，不是 ALA 脱水酶"}
第一步的合酶活性低、受反馈；第二步脱水酶活性比合酶强 $80$ 倍，虽然也可被血红素抑制，但并不引起明显生理效应。铅抑制脱水酶和亚铁螯合酶，那是中毒体征，不要把「铅敏感」误写成「限速」。
:::

### （二）ALA 在胞质内脱水缩合生成胆色素原

$\mathrm{ALA}$ 生成后从线粒体进入胞质，在 $\mathrm{ALA}$ 脱水酶（$\mathrm{ALA}$ dehydrase）催化下，$2$ 分子 $\mathrm{ALA}$ 脱水缩合生成 $1$ 分子胆色素原（porphobilinogen，$\mathrm{PBG}$）（图26-3）。$\mathrm{ALA}$ 脱水酶含有巯基，对铅等重金属的抑制作用十分敏感。

:::definition{label="ALA 脱水酶"}
胞质酶。$2$ 分子 $\mathrm{ALA}$ 脱水缩合生成 $1$ 分子胆色素原，放出 $2\,\mathrm{H}_2\mathrm{O}$（图26-3）。酶含巯基，对铅等重金属十分敏感。活性较 $\mathrm{ALA}$ 合酶强 $80$ 倍。
:::

:::definition{label="胆色素原 PBG"}
第一个吡咯环中间物。两个 $\mathrm{ALA}$ 的羰基和氨基按图26-3 的框对接，环化成吡咯，侧链留下乙酸基和丙酸基。后面四分子胆色素原才缩成线状四吡咯。
:::

::figure{src="/images/biochemistry/textbook/p0515_02.png" caption="图26-3　胆色素原的合成" alt="左侧两分子ALA并排，方框标出即将成环的羰基、亚甲基与氨基；ALA脱水酶催化脱去2分子水，右侧生成胆色素原：吡咯环，环上有氨甲基、乙酸基和丙酸基侧链"}

:::insight{label="图26-3 两个方框就是即将关掉的吡咯环"}
一分子 $\mathrm{ALA}$ 提供羰基，另一分子提供氨基碳。脱水酶箭头标 $2\mathrm{H}_2\mathrm{O}$。产物已经是五元氮杂环，还不是四吡咯大环。铅打的是这一步的巯基，不是打 $\mathrm{ALA}$ 合酶的磷酸吡哆醛。
:::

:::pitfall{label="含巯基、铅敏感的是脱水酶，辅酶磷酸吡哆醛的是合酶"}
两步紧挨着，最容易张冠李戴。合酶：线粒体、磷酸吡哆醛、限速、血红素反馈。脱水酶：胞质、巯基、铅敏感、$2\,\mathrm{ALA}\to 1\,\mathrm{PBG}$。铅中毒还会再打亚铁螯合酶和粪卟啉原氧化酶，那是后文卟啉症。
:::

### （三）胆色素原脱氨缩合转变为尿卟啉原与粪卟啉原

在胞质中，由尿卟啉原Ⅰ合酶（uroporphyrinogen Ⅰ synthase，$\mathrm{UPG}$ Ⅰ synthase，又称胆色素原脱氨酶）催化，使 $4$ 分子胆色素原脱氨缩合生成 $1$ 分子线状四吡咯，后者再由 $\mathrm{UPG}$ Ⅲ合酶催化生成尿卟啉原Ⅲ（$\mathrm{UPG}$ Ⅲ）。$\mathrm{UPG}$ Ⅲ进一步经尿卟啉原Ⅲ脱羧酶催化，使其 $4$ 个乙酸基（$\mathrm{A}$）侧链脱羧基变为甲基（$\mathrm{M}$），从而生成粪卟啉原Ⅲ（coproporphyrinogen Ⅲ，$\mathrm{CPG}$ Ⅲ），反应如图26-4 所示。

:::definition{label="尿卟啉原Ⅰ合酶（胆色素原脱氨酶）"}
胞质。$4$ 分子胆色素原脱氨缩合生成 $1$ 分子线状四吡咯。图26-4 右侧标 $\times 4$ 和 $3\mathrm{NH}_3$。名字带「Ⅰ」，产物却要交给 $\mathrm{UPG}$ Ⅲ合酶才能环化成尿卟啉原Ⅲ。
:::

:::definition{label="UPG Ⅲ合酶"}
把线状四吡咯环化成尿卟啉原Ⅲ。图26-4 再放出 $1\,\mathrm{NH}_3$。没有这一步，会走向尿卟啉原Ⅰ型异构体；本版正文走的是Ⅲ型这条生理主路。
:::

:::definition{label="尿卟啉原Ⅲ脱羧酶"}
$\mathrm{UPG}$ Ⅲ的 $4$ 个乙酸基（$\mathrm{A}$，$-\mathrm{CH}_2\mathrm{COOH}$）脱羧变为甲基（$\mathrm{M}$，$-\mathrm{CH}_3$），生成粪卟啉原Ⅲ。图26-4 画面在线粒体／胞液交界的下方，标 $\mathrm{CO}_2$。
:::

:::compare{title="侧链字母按图26-4 脚注记"}
| 字母 | 本版结构 | 出现在哪一步 |
|------|---------|------------|
| $\mathrm{A}$ | $-\mathrm{CH}_2\mathrm{COOH}$（乙酸基） | 尿卟啉原Ⅲ：四个吡咯带 $\mathrm{A}$ 和 $\mathrm{P}$ |
| $\mathrm{P}$ | $-\mathrm{CH}_2\mathrm{CH}_2\mathrm{COOH}$（丙酸基） | 尿卟啉原、粪卟啉原都有；进入线粒体后 $2$、$4$ 位的 $\mathrm{P}$ 变成 $\mathrm{V}$ |
| $\mathrm{M}$ | $-\mathrm{CH}_3$（甲基） | 乙酸基脱羧而来 |
| $\mathrm{V}$ | $-\mathrm{CH}{=}\mathrm{CH}_2$（乙烯基） | 粪卟啉原Ⅲ氧化脱羧后出现在原卟啉原Ⅸ／原卟啉Ⅸ／血红素 |

问「尿卟啉原和粪卟啉原差在哪」——四个 $\mathrm{A}$ 变成四个 $\mathrm{M}$。问「原卟啉差在哪」——再把两个 $\mathrm{P}$ 变成两个 $\mathrm{V}$。
:::

### （四）粪卟啉原Ⅲ在线粒体内转变为血红素

胞质中生成的粪卟啉原Ⅲ再进入线粒体，经粪卟啉原Ⅲ氧化酶作用，使其 $2$、$4$ 位两个丙酸基（$\mathrm{P}$）氧化脱羧变成乙烯基（$\mathrm{V}$），从而生成原卟啉原Ⅸ（protoporphyrinogen Ⅸ），再由原卟啉原Ⅸ氧化酶催化，使其 $4$ 个连接吡咯环的亚甲基氧化成次甲基，则成为原卟啉Ⅸ（protoporphyrin Ⅸ）。通过亚铁螯合酶（ferrochelatase，又称血红素合成酶）的催化，原卟啉Ⅸ和 $\mathrm{Fe}^{2+}$ 结合，生成血红素（图26-4）。铅等重金属对亚铁螯合酶也有抑制作用。

血红素生成后从线粒体转运到胞质，在骨髓的有核红细胞及网织红细胞中，与珠蛋白结合成为血红蛋白。

:::definition{label="粪卟啉原Ⅲ氧化酶"}
线粒体。粪卟啉原Ⅲ的 $2$、$4$ 位两个丙酸基氧化脱羧成乙烯基，生成原卟啉原Ⅸ。图26-4 标 $2\mathrm{CO}_2$、$4\mathrm{H}$。铅中毒导致卟啉症时，这一酶也在被抑制的名单里。
:::

:::definition{label="原卟啉原Ⅸ氧化酶"}
线粒体。把连接四个吡咯环的亚甲基氧化成次甲基，生成原卟啉Ⅸ。图26-4 标 $6\mathrm{H}$。大环从此出现共轭，颜色和光敏感性与前面无色的卟啉原不同。
:::

:::definition{label="亚铁螯合酶（血红素合成酶）"}
线粒体。原卟啉Ⅸ与 $\mathrm{Fe}^{2+}$ 结合生成血红素。铅等重金属抑制此酶。还需要还原剂（如谷胱甘肽），任何还原条件的中断也会抑制血红素合成。
:::

:::definition{label="从血红素到血红蛋白"}
血红素生成后从线粒体转到胞质，在骨髓有核红细胞及网织红细胞中与珠蛋白结合成为血红蛋白。成熟红细胞既不能合成血红素，也不能合成珠蛋白（第三节表26-2）。
:::

::figure{src="/images/biochemistry/textbook/p0515_03.png" caption="图26-4　血红素的生物合成" alt="中央线粒体，右侧胞液。甘氨酸与琥珀酰辅酶A在线粒体内经ALA合酶生成ALA并放出CO2和辅酶A；ALA出线粒体，胞液中ALA脱水酶使两分子ALA脱水成胆色素原；尿卟啉原Ⅰ合酶使四分子胆色素原脱氨成线状四吡咯；尿卟啉原Ⅲ合酶生成尿卟啉原Ⅲ（四吡咯，侧链A与P）；尿卟啉原Ⅲ脱羧酶生成粪卟啉原Ⅲ（侧链M与P）。粪卟啉原Ⅲ进入线粒体，粪卟啉原氧化酶生成原卟啉原Ⅸ，原卟啉原Ⅸ氧化酶生成原卟啉Ⅸ，亚铁螯合酶加上Fe2+生成血红素；血红素出线粒体与珠蛋白结合成血红蛋白"}

:::insight{label="图26-4 按「出线粒体再进来」读"}
上缘从左到右写「血红蛋白／线粒体／胞液」。右侧胞液是 $\mathrm{ALA}$ → 胆色素原 → 线状四吡咯 → 尿卟啉原Ⅲ；底部尿卟啉原Ⅲ → 粪卟啉原Ⅲ仍在胞液侧；左侧线粒体内从下往上：粪卟啉原Ⅲ进来 → 原卟啉原Ⅸ → 原卟啉Ⅸ → 装上 $\mathrm{Fe}^{2+}$ 成血红素 → 出去与珠蛋白会合。不要把尿卟啉原Ⅲ画进线粒体。
:::

:::pitfall{label="亚铁螯合酶装的是 Fe²⁺，不是 Fe³⁺"}
原料写 $\mathrm{Fe}^{2+}$，酶名是亚铁螯合酶。高铁血红素是血红素过多后氧化的产物，出现在调节段和第三节，不是合成的终产物。写成「血红素里的铁一装上去就是三价」，运氧和 $\mathrm{MHb}$ 两户都会乱。
:::

血红素合成的全过程总结于图26-4。血红素合成的特点可归结如下：①体内大多数组织均具有合成血红素的能力，但合成的主要部位是骨髓与肝，成熟红细胞不含线粒体，故不能合成血红素。②血红素合成的原料是琥珀酰 $\mathrm{CoA}$、甘氨酸及 $\mathrm{Fe}^{2+}$ 等简单小分子物质。其中间产物的转变主要是吡咯环侧链的脱羧和脱氢反应。各种卟啉原化合物的吡咯环之间无共轭结构，均无色，性质不稳定，易被氧化，对光尤为敏感。③血红素合成的起始和最终过程均在线粒体中进行，而其他中间步骤则在胞质中进行。这种定位对终产物血红素的反馈调节作用具有重要意义。关于中间产物进出线粒体的机制，目前尚不清楚。

:::definition{label="血红素合成的三个特点"}
①主要部位骨髓与肝；成熟红细胞无线粒体，不能合成。②原料是小分子；中间变化主要是侧链脱羧和脱氢；卟啉原无共轭、无色、不稳定、易氧化、对光敏感。③起始终末在线粒体，中间在胞质，便于终产物反馈；进出机制不明。
:::

:::compare{title="线粒体里的两头 vs 胞质里的中间"}
| 分区 | 反应 | 酶 |
|------|------|-----|
| 线粒体（起始） | 琥珀酰 $\mathrm{CoA}$＋甘氨酸 → $\mathrm{ALA}$ | $\mathrm{ALA}$ 合酶（磷酸吡哆醛，限速） |
| 胞质 | $2\,\mathrm{ALA}$ → 胆色素原 → 线状四吡咯 → $\mathrm{UPG}$ Ⅲ → $\mathrm{CPG}$ Ⅲ | $\mathrm{ALA}$ 脱水酶；$\mathrm{UPG}$ Ⅰ合酶；$\mathrm{UPG}$ Ⅲ合酶；$\mathrm{UPG}$ Ⅲ脱羧酶 |
| 线粒体（终末） | $\mathrm{CPG}$ Ⅲ → 原卟啉原Ⅸ → 原卟啉Ⅸ → 血红素 | 粪卟啉原Ⅲ氧化酶；原卟啉原Ⅸ氧化酶；亚铁螯合酶 |

铅敏感落在胞质的 $\mathrm{ALA}$ 脱水酶和线粒体的亚铁螯合酶（以及粪卟啉原氧化酶）。限速落在线粒体的 $\mathrm{ALA}$ 合酶。
:::

:::timeline{period="血红素合成四步（按本版）"}
- **线粒体** 琥珀酰CoA与甘氨酸缩合成ALA（ALA合酶，磷酸吡哆醛，限速）
- **胞质** 2分子ALA脱水成胆色素原（ALA脱水酶，含巯基，铅敏感）
- **胞质** 4分子胆色素原经线状四吡咯变成尿卟啉原III，再脱羧成粪卟啉原III
- **线粒体** 粪卟啉原III氧化成原卟啉原IX、原卟啉IX，亚铁螯合酶装上Fe2+成血红素（铅也抑制这一酶）
- **胞质** 血红素与珠蛋白结合成血红蛋白（有核红细胞及网织红细胞）
:::

:::insight{label="卟啉原无色、对光敏感，是为后文卟啉症留的性质"}
无共轭所以无色；不稳定、易氧化、对光敏感。蓄积之后的细胞损伤，卟啉症段会用到。不要把无色写成「血浆里看不到胆红素」——胆红素是血红素分解的下游，不在本节。
:::

## 二、血红素合成的最主要调节步骤是 ALA 的合成

血红素的合成受多种因素的调节，其中最主要的调节步骤是 $\mathrm{ALA}$ 的合成。

### （一）ALA 合酶是血红素合成体系的限速酶

$\mathrm{ALA}$ 合酶是血红素合成体系的限速酶，受血红素的反馈抑制。此外，血红素还可以阻抑 $\mathrm{ALA}$ 合酶的合成。由于磷酸吡哆醛是该酶的辅酶，维生素 $\mathrm{B}_6$ 缺乏将影响血红素的合成。$\mathrm{ALA}$ 合酶本身的代谢较快，半衰期约为 $1$ 小时。正常情况下，血红素合成后迅速与珠蛋白结合成血红蛋白，不致有过多的血红素堆积。血红素结合成血红蛋白后，对 $\mathrm{ALA}$ 合酶不再有反馈抑制作用。如果血红素的合成速度大于珠蛋白的合成速度，过多的血红素可以氧化成高铁血红素，后者对 $\mathrm{ALA}$ 合酶也具有强烈抑制作用。某些固醇类激素，例如睾酮在体内的 $5$-$\beta$ 还原物，能诱导 $\mathrm{ALA}$ 合酶的合成，从而促进血红素的生成。许多在肝中进行生物转化的物质，例如致癌物质、药物、杀虫剂等，均可导致肝 $\mathrm{ALA}$ 合酶显著增加，因为这些物质的生物转化作用需要细胞色素 $\mathrm{P}450$，后者的辅基正是铁卟啉化合物。由此，通过肝 $\mathrm{ALA}$ 合酶的增加，以适应生物转化的需求。

:::definition{label="ALA 合酶的双重反馈"}
已有的酶：血红素反馈抑制其活性。还没有合成的酶：血红素阻抑 $\mathrm{ALA}$ 合酶的合成。酶本身半衰期约 $1$ 小时，代谢快，适合被诱导或阻抑。
:::

:::definition{label="装进血红蛋白的血红素不再反馈"}
正常时血红素迅速与珠蛋白结合，不致堆积；结合后对 $\mathrm{ALA}$ 合酶不再有反馈抑制作用。血红素合成快于珠蛋白时，过多血红素氧化成高铁血红素，高铁血红素对 $\mathrm{ALA}$ 合酶也有强烈抑制。第三节会写高铁血红素反过来促进珠蛋白合成——两节合在一起才是「两边对齐」。
:::

:::definition{label="维生素 B6 与 ALA 合酶"}
磷酸吡哆醛是辅酶，维生素 $\mathrm{B}_6$ 缺乏将影响血红素合成。缺的是辅酶，不是缺甘氨酸或琥珀酰 $\mathrm{CoA}$。
:::

:::definition{label="固醇类激素诱导 ALA 合酶"}
例如睾酮在体内的 $5$-$\beta$ 还原物，能诱导 $\mathrm{ALA}$ 合酶的合成，促进血红素生成。这是诱导合成，不是变构激活已有的酶。
:::

:::definition{label="肝 ALA 合酶可被生物转化需求拉高"}
致癌物质、药物、杀虫剂等在肝生物转化需要细胞色素 $\mathrm{P}450$，其辅基是铁卟啉。肝 $\mathrm{ALA}$ 合酶显著增加，以适应生物转化。这是肝合成血红素的调节，不是骨髓红系的 $\mathrm{EPO}$ 那一户。
:::

:::compare{title="血红素、高铁血红素、血红蛋白对 ALA 合酶"}
| 形式 | 对 $\mathrm{ALA}$ 合酶 | 生理场景 |
|------|---------------------|---------|
| 游离血红素 | 抑制活性，并阻抑酶的合成 | 合成多于结合时堆积 |
| 高铁血红素 | 强烈抑制 | 过多血红素被氧化 |
| 已结合进 $\mathrm{Hb}$ 的血红素 | 不再反馈抑制 | 正常迅速装配 |

问「为什么平时不会把合酶一直关掉」——合成后马上装进珠蛋白。问「为什么珠蛋白不够时要减速」——游离血红素和高铁血红素来关合酶。
:::

:::pitfall{label="药物诱导的是肝 ALA 合酶，不要写成骨髓造血加快"}
致癌物、药物、杀虫剂走细胞色素 $\mathrm{P}450$。$\mathrm{EPO}$ 才是红系繁殖分化的调节剂。两户都能增加血红素合成，器官不同：一个肝，一个肾→骨髓。
:::

### （二）重金属抑制 ALA 脱水酶与亚铁螯合酶活性

$\mathrm{ALA}$ 脱水酶虽然也可被血红素抑制，但并不引起明显的生理效应，因为此酶的活性较 $\mathrm{ALA}$ 合酶强 $80$ 倍，故血红素的抑制基本上是通过 $\mathrm{ALA}$ 合酶起作用。$\mathrm{ALA}$ 脱水酶和亚铁螯合酶对重金属（例如铅）的抑制均非常敏感，因此血红素合成的抑制是铅中毒的重要体征。此外，亚铁螯合酶还需要还原剂（如谷胱甘肽），任何还原条件的中断也会抑制血红素的合成。

:::definition{label="脱水酶比合酶强 80 倍"}
所以血红素抑制脱水酶没有明显生理效应；生理反馈走合酶。铅中毒打的是脱水酶和亚铁螯合酶（以及后文粪卟啉原氧化酶），这才成为体征。
:::

:::definition{label="铅中毒抑制血红素合成"}
$\mathrm{ALA}$ 脱水酶含巯基，亚铁螯合酶也对铅敏感。血红素合成受抑制是铅中毒的重要体征。亚铁螯合酶还依赖谷胱甘肽等还原剂，还原条件中断同样抑制合成。
:::

:::cause-effect{title="铅 → 脱水酶和亚铁螯合酶被抑制 → 血红素合成下降"}
铅等重金属抑制胞质 $\mathrm{ALA}$ 脱水酶和线粒体亚铁螯合酶 → 中间物蓄积、终产物血红素不足 → 铅中毒的重要体征。卟啉症段会把粪卟啉原氧化酶也写进同一名单。
:::

:::pitfall{label="不要把铅写成抑制 ALA 合酶"}
合酶怕的是血红素／高铁血红素反馈和维生素 $\mathrm{B}_6$ 缺乏。铅怕的是巯基酶和亚铁螯合酶。张冠李戴以后，「限速」和「中毒体征」两道题会一起错。
:::

### （三）促红细胞生成素促进红细胞成熟以及血红素和血红蛋白合成

促红细胞生成素（erythropoietin，$\mathrm{EPO}$）是一种集落刺激因子，由 $166$ 个氨基酸组成的糖蛋白，分子量为 $34\,\mathrm{kDa}$。主要在肾合成，缺氧时即释放入血，运至骨髓，结合并激活原始红细胞表面的 $\mathrm{EPO}$ 受体，促进红系爆式集落形成单位（burst forming unit-erythroid，$\mathrm{BFU}$-$\mathrm{E}$）和红系集落形成单位（colony forming unit-erythroid，$\mathrm{CFU}$-$\mathrm{E}$）的繁殖和分化，加速有核红细胞的成熟以及血红素和 $\mathrm{Hb}$ 的合成。因此，$\mathrm{EPO}$ 是红细胞生成的主要调节剂。

:::definition{label="促红细胞生成素 EPO"}
集落刺激因子。$166$ 个氨基酸的糖蛋白，$34\,\mathrm{kDa}$。主要在肾合成，缺氧时释放入血，运至骨髓。结合并激活原始红细胞表面的 $\mathrm{EPO}$ 受体，促进 $\mathrm{BFU}$-$\mathrm{E}$ 和 $\mathrm{CFU}$-$\mathrm{E}$ 的繁殖分化，加速有核红细胞成熟以及血红素和 $\mathrm{Hb}$ 合成。红细胞生成的主要调节剂。
:::

:::keypoint{label="EPO 这一段五个落点"}
- 化学：糖蛋白，$166$ 氨基酸，$34\,\mathrm{kDa}$。
- 来源：主要在肾；缺氧释放。
- 靶：骨髓原始红细胞表面受体。
- 细胞：$\mathrm{BFU}$-$\mathrm{E}$、$\mathrm{CFU}$-$\mathrm{E}$ 繁殖分化；有核红细胞成熟。
- 分子：血红素和血红蛋白合成加快。
:::

:::pitfall{label="EPO 主要在肾合成，不是在骨髓合成"}
骨髓是靶器官。写成「骨髓自己分泌 $\mathrm{EPO}$ 促进自己」，缺氧→肾→血→骨髓这条轴就断了。
:::

:::compare{title="三种加快血红素合成的方式不要并"}
| | 作用点 | 器官 |
|--|------|------|
| 血红素／高铁血红素减少（负反馈解除） | $\mathrm{ALA}$ 合酶 | 合成血红素的细胞自己 |
| 睾酮 $5$-$\beta$ 还原物、药物等 | 诱导肝 $\mathrm{ALA}$ 合酶 | 肝（$\mathrm{P}450$ 需求） |
| $\mathrm{EPO}$ | 红系繁殖分化＋血红素／$\mathrm{Hb}$ 合成 | 肾合成，骨髓执行 |

问「高原缺氧为什么红细胞增多」先答 $\mathrm{EPO}$；问「服药为什么肝血红素需求变大」答 $\mathrm{P}450$。
:::

铁卟啉合成代谢异常而导致卟啉或其中间代谢物浓度异常升高，并在组织中蓄积，造成细胞损伤而引起的一类代谢性疾病称为卟啉症（porphyria）。卟啉症有先天性和后天性两大类。先天性卟啉症是由某种血红素合成酶系的遗传性缺陷所致；后天性卟啉症则主要指重金属中毒或某些药物中毒引起的铁卟啉合成障碍。例如铅中毒抑制 $\mathrm{ALA}$ 脱水酶、亚铁螯合酶和粪卟啉原氧化酶而导致卟啉症。

:::definition{label="卟啉症"}
铁卟啉合成代谢异常，卟啉或其中间代谢物浓度异常升高并在组织中蓄积，造成细胞损伤。先天性：某种血红素合成酶系的遗传性缺陷。后天性：重金属中毒或某些药物中毒引起的铁卟啉合成障碍。
:::

:::definition{label="铅中毒导致卟啉症打三处"}
$\mathrm{ALA}$ 脱水酶、亚铁螯合酶、粪卟啉原氧化酶。前两处在调节第（二）小节已经出现，第三处把第（四）步的粪卟啉原Ⅲ氧化酶补进名单。
:::

:::compare{title="先天性 vs 后天性卟啉症"}
| | 原因 | 本版例子 |
|--|------|---------|
| 先天性 | 某种血红素合成酶系的遗传性缺陷 | 本节不展开具体酶名病种 |
| 后天性 | 重金属或某些药物中毒 | 铅：脱水酶＋亚铁螯合酶＋粪卟啉原氧化酶 |

蓄积的是卟啉或中间代谢物，不是「血红素太多」。血红素太多走的是反馈抑制，不会叫卟啉症。
:::

:::pitfall{label="卟啉症是中间物蓄积伤细胞，不是血红蛋白过多"}
定义落在「卟啉或其中间代谢物浓度异常升高」。合成通路堵住以后，上游中间物堆积、下游血红素不足，可以同时存在。写成「卟啉症＝红细胞太多」，和 $\mathrm{EPO}$、真性红细胞增多症就并户了。
:::

:::memory{label="本节必背分户"}
- 血红蛋白＝珠蛋白＋血红素；血红素也是肌红蛋白、细胞色素、过氧化物酶的辅基。组成 $\mathrm{Hb}$ 的血红素主要在骨髓幼红细胞和网织红细胞合成。
- 原料：甘氨酸、琥珀酰 $\mathrm{CoA}$、$\mathrm{Fe}^{2+}$。起始终末在线粒体，中间在胞质。图26-4。
- $\mathrm{ALA}$ 合酶：线粒体、磷酸吡哆醛、限速；血红素反馈抑制活性并阻抑其合成；半衰期约 $1$ 小时；维生素 $\mathrm{B}_6$ 缺乏影响合成。
- $\mathrm{ALA}$ 脱水酶：胞质、$2\,\mathrm{ALA}\to\mathrm{PBG}$、含巯基、铅敏感；活性较合酶强 $80$ 倍。
- 亚铁螯合酶：原卟啉Ⅸ＋$\mathrm{Fe}^{2+}$；铅抑制；需要谷胱甘肽等还原剂。
- 铅中毒／后天性卟啉症：脱水酶、亚铁螯合酶、粪卟啉原氧化酶。
- $\mathrm{EPO}$：$166$ 氨基酸糖蛋白，$34\,\mathrm{kDa}$，主要肾合成，缺氧释放，骨髓 $\mathrm{BFU}$-$\mathrm{E}$／$\mathrm{CFU}$-$\mathrm{E}$。
- 成熟红细胞无线粒体，不能合成血红素。
:::

:::keypoint{label="本节不写的账"}
$2,3$-$\mathrm{BPG}$ 降低 $\mathrm{Hb}$ 对 $\mathrm{O}_2$ 的亲和力、成熟红细胞只靠糖无氧氧化、谷胱甘肽保护、高铁血红素对 $\mathrm{eIF}$-$2$ 的促进，全部是第三节。本节只把血红素如何合成、如何限速、铅打在哪几步立住。
:::
