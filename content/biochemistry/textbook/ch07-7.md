# 第七节　葡萄糖的其他代谢途径

前六节把葡萄糖写成氧化供能、戊糖磷酸旁路、糖原储存和糖异生。细胞内还有两条所占比例很小、却有明确产物和病理落点的途径：糖醛酸途径生成活化的葡萄糖醛酸（$\mathrm{UDPGA}$），多元醇途径在晶状体、精囊等把葡萄糖写成山梨醇和果糖。本节不产能，也不改写血糖的主账；看的是结合解毒、糖胺聚糖原料，以及高糖时山梨醇堆积。

细胞内葡萄糖除了氧化供能或进入戊糖磷酸途径外，还可代谢生成葡萄糖醛酸、多元醇等重要代谢产物。前六节已经把主账写完：无氧、有氧供能，戊糖磷酸途径提供 $\mathrm{NADPH}$ 和核糖磷酸，糖原储存，非糖异生。剩下这两条在流量上很小，却各自有不能并到主账里的产品。

:::compare{title="进入细胞后的葡萄糖还可以走哪几户"}
| 途径 | 本章位置 | 主要产品／职分 | 流量地位（本版） |
|------|----------|----------------|------------------|
| 无氧氧化 | 第二节 | 乳酸；净 $2\,\mathrm{ATP}$ | 缺氧、红细胞、剧烈运动 |
| 有氧氧化 | 第三节 | $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$；净 $30$ 或 $32\,\mathrm{ATP}$ | 主要产能 |
| 戊糖磷酸途径 | 第四节 | $\mathrm{NADPH}$、核糖磷酸 | 不产能；看 $\mathrm{NADPH}$ 需求 |
| 糖原合成 | 第五节 | 糖原 | 肝、肌的快储备 |
| 糖异生 | 第六节 | 非糖 → 葡萄糖／糖原 | 饥饿补血糖；方向相反 |
| 糖醛酸途径 | 本节 | $\mathrm{UDPGA}$ | 所占比例很小 |
| 多元醇途径 | 本节 | 山梨醇、果糖 | 正常时比例极小；晶状体、精囊 |

本节只展开最后两行。
:::

:::concept{term="先问要的是 UDPGA 还是山梨醇／果糖，再问走哪条小途径"}
糖醛酸途径的产品是尿苷二磷酸葡萄糖醛酸，给糖胺聚糖和肝的结合反应。多元醇途径的产品是山梨醇和果糖，正常血糖时几乎不走，因为醛糖还原酶对葡萄糖亲和力极低。两条都不是供能旁路，不要和戊糖磷酸途径并户。
:::

:::pitfall{label="“其他途径”不是第三条产能通路"}
无氧、有氧才写 $\mathrm{ATP}$。戊糖磷酸途径写 $\mathrm{NADPH}$ 和核糖磷酸。本节两条在糖代谢中所占比例很小：一条为了活化葡萄糖醛酸，一条为了特定组织的果糖和病理情况下的山梨醇。把它们听成“还能再挖出若干 $\mathrm{ATP}$”，和前三节的产能账冲突。
:::

## 一、糖醛酸途径生成葡萄糖醛酸

糖醛酸途径（glucuronate pathway）是指以葡萄糖醛酸为中间产物的葡萄糖代谢途径，在糖代谢中所占比例很小。首先，葡萄糖-6-磷酸转变为尿苷二磷酸葡萄糖（$\mathrm{UDPG}$），过程见糖原合成。然后在 $\mathrm{UDPG}$ 脱氢酶催化下，$\mathrm{UDPG}$ 氧化生成尿苷二磷酸葡萄糖醛酸（uridine diphosphate glucuronic acid，$\mathrm{UDPGA}$）。后者再转变为木酮糖-5-磷酸，与戊糖磷酸途径相衔接（图7-17）。

:::definition{label="糖醛酸途径"}
糖醛酸途径（glucuronate pathway）以葡萄糖醛酸为中间产物，在糖代谢中所占比例很小。葡萄糖-6-磷酸先按糖原合成写成 $\mathrm{UDPG}$，再经 $\mathrm{UDPG}$ 脱氢酶氧化成 $\mathrm{UDPGA}$，随后转变为木酮糖-5-磷酸，与戊糖磷酸途径衔接。
:::

:::timeline{period="糖醛酸途径接到戊糖磷酸途径"}
- **与糖原合成共用** 葡萄糖-6-磷酸 → 葡萄糖-1-磷酸 → UDPG
- **UDPG 脱氢酶** UDPG 氧化生成 UDPGA（活化的葡萄糖醛酸）
- **后续转变** UDPGA 经 1-磷酸葡萄糖醛酸、葡萄糖醛酸、L-古洛糖酸、L-木酮糖、木糖醇、D-木酮糖，生成木酮糖-5-磷酸
- **衔接** 木酮糖-5-磷酸进入戊糖磷酸途径
:::

人体内糖醛酸途径的主要生理意义是生成活化的葡萄糖醛酸——$\mathrm{UDPGA}$。葡萄糖醛酸是蛋白聚糖分子中糖胺聚糖（如透明质酸、硫酸软骨素、肝素等）的组成成分（见第四章），还参与肝内生物转化的结合反应（见第二十五章）。

:::definition{label="UDPGA"}
尿苷二磷酸葡萄糖醛酸（uridine diphosphate glucuronic acid，$\mathrm{UDPGA}$）是活化的葡萄糖醛酸，由 $\mathrm{UDPG}$ 经 $\mathrm{UDPG}$ 脱氢酶氧化生成。它是本途径在人体内的主要产品。
:::

:::definition{label="UDPG 脱氢酶"}
$\mathrm{UDPG}$ 脱氢酶催化 $\mathrm{UDPG}$ 氧化生成 $\mathrm{UDPGA}$。这一步把第五节的“活性葡萄糖”改写成“活性葡萄糖醛酸”，是糖醛酸途径相对糖原合成分叉的关键酶。
:::

::figure{src="/images/biochemistry/textbook/p0162_01.png" caption="图7-17　糖醛酸途径。葡萄糖-6-磷酸→葡萄糖-1-磷酸→UDPG→UDPGA→1-磷酸葡萄糖醛酸→葡萄糖醛酸→L-古洛糖酸→L-木酮糖→木糖醇→D-木酮糖→木酮糖-5-磷酸，进入戊糖磷酸途径。" alt="自上而下的糖醛酸途径：UDPG 氧化为 UDPGA，经葡萄糖醛酸和木酮糖系列接到戊糖磷酸途径"}

图7-17 把正文里“$\mathrm{UDPG}$ 氧化生成 $\mathrm{UDPGA}$，后者再转变为木酮糖-5-磷酸”写成一条完整碳架链。前三段与糖原合成共用：葡萄糖-6-磷酸变位为葡萄糖-1-磷酸，再活化为 $\mathrm{UDPG}$。$\mathrm{UDPG}$ 脱氢酶在此分叉，生成 $\mathrm{UDPGA}$。此后图中依次出现 $1$-磷酸葡萄糖醛酸、葡萄糖醛酸、$L$-古洛糖酸、$L$-木酮糖、木糖醇、$D$-木酮糖，最后磷酸化为木酮糖-5-磷酸，箭头指向戊糖磷酸途径。人体要截取的是中间的活化葡萄糖醛酸；后面那些戊糖是把碳架送回第四节基团转移的接口，不是另开一条产能通路。

:::note{label="图中的中间物按画面记账"}
正文点名的酶是 $\mathrm{UDPG}$ 脱氢酶，点名的产品是 $\mathrm{UDPGA}$ 和木酮糖-5-磷酸。$L$-古洛糖酸、木糖醇等出现在图7-17，用来认衔接，不要另造一套酶名或维生素 $\mathrm{C}$ 合成账——本版人体生理意义只写 $\mathrm{UDPGA}$。
:::

:::compare{title="UDPG 的两条去路"}
| 项目 | 糖原合成（第五节） | 糖醛酸途径（本节） |
|------|--------------------|--------------------|
| 共同前段 | 葡萄糖-6-磷酸 → 葡萄糖-1-磷酸 → $\mathrm{UDPG}$ | 同左 |
| 下一步 | 糖原合酶把葡萄糖基接到非还原末端 | $\mathrm{UDPG}$ 脱氢酶把 $\mathrm{UDPG}$ 氧化成 $\mathrm{UDPGA}$ |
| 产品 | 糖原 | 活化葡萄糖醛酸；碳架最终成木酮糖-5-磷酸 |
| 在糖代谢中的分量 | 储存的主账之一 | 所占比例很小 |
:::

:::keypoint{label="UDPGA 的两件活"}
- 组成：蛋白聚糖中的糖胺聚糖，教材点名透明质酸、硫酸软骨素、肝素（见第四章）。
- 结合：肝内生物转化的结合反应（见第二十五章），把某些代谢物、药物写成葡萄糖醛酸苷，便于排出。
:::

:::insight{label="本途径的意义不在产能，在活化"}
人体要的是 $\mathrm{UDPGA}$ 这个活化形式，不是再挖一笔 $\mathrm{ATP}$。碳架转到木酮糖-5-磷酸后可以进戊糖磷酸途径，那是衔接，不是本途径的生理目的。把图7-17 听成“又一条戊糖磷酸途径”，和第四节会重复记账。
:::

:::pitfall{label="不要把 UDPG 只留给糖原"}
$\mathrm{UDPG}$ 是活性葡萄糖，糖原合成用它，糖醛酸途径也从它脱氢。看见 $\mathrm{UDPG}$ 先问下一酶是糖原合酶还是 $\mathrm{UDPG}$ 脱氢酶。第四章糖胺聚糖的葡萄糖醛酸来自这一户，不要写成“直接氧化葡萄糖”。
:::

:::example{label="肝结合反应为什么要先做 UDPGA"}
生物转化要把某些药物、毒物、胆红素等接上葡萄糖醛酸，供体必须是活化形式。游离葡萄糖醛酸不够格，$\mathrm{UDPGA}$ 才是供体。糖醛酸途径在糖代谢里比例很小，在肝解毒和第四章糖胺聚糖组装里却是刚需。
:::

:::insight{label="第四章和二十五章都要回指这一户"}
透明质酸、硫酸软骨素、肝素的糖醛酸不是细胞直接把葡萄糖氧化到羧基就装上去的，供体是 $\mathrm{UDPGA}$。第二十五章肝内结合反应同样要活化供体。本节在糖代谢章里写得很短，是因为流量小，不是因为可以删。
:::

:::pitfall{label="木酮糖-5-磷酸在这里是出口，不是本途径的目的"}
第四节基团转移本来就有木酮糖-5-磷酸。糖醛酸途径末端接到那里，等于把用剩的碳架送回主旁路。把图7-17 整条链听成“专门为了制造核糖磷酸”，和“主要生理意义是生成 $\mathrm{UDPGA}$”冲突。
:::

:::compare{title="与戊糖磷酸途径如何衔接、如何分工"}
| 项目 | 戊糖磷酸途径（第四节） | 糖醛酸途径（本节） |
|------|------------------------|--------------------|
| 起点 | 葡萄糖-6-磷酸直接脱氢 | 葡萄糖-6-磷酸先写成 $\mathrm{UDPG}$ 再脱氢 |
| 主要产品 | $\mathrm{NADPH}$、核糖磷酸 | $\mathrm{UDPGA}$ |
| 与对方的关系 | 木酮糖-5-磷酸是基团转移的底物之一 | 末端生成木酮糖-5-磷酸，汇入戊糖磷酸途径 |
| 流量地位 | 脂质合成、红细胞抗氧化等场合很活跃 | 在糖代谢中所占比例很小 |
:::

## 二、多元醇途径生成少量多元醇

在某些组织如晶状体、精囊等，还存在将葡萄糖转变成果糖的两步代谢反应，称为多元醇途径（polyol pathway），包括：①在醛糖还原酶作用下，由 $\mathrm{NADPH}$ 供氢，葡萄糖还原生成山梨醇。②由多元醇脱氢酶催化，山梨醇脱氢生成果糖和 $\mathrm{NADH}$。血糖水平正常时，多元醇途径在人体糖代谢中所占比例极小，这是由于醛糖还原酶对葡萄糖的亲和力极低所致（约为 $200\,\mathrm{mmol/L}$）。第八节空腹血糖只在 $3.9\sim 6.0\,\mathrm{mmol/L}$，肾糖阈约为 $10\,\mathrm{mmol/L}$，都远低于这一亲和力数字，所以健康人这条路几乎不开工；糖尿病时局部葡萄糖浓度抬上去，醛糖还原酶才“充分发挥作用”。

:::definition{label="多元醇途径"}
多元醇途径（polyol pathway）是某些组织（如晶状体、精囊）把葡萄糖转变成果糖的两步反应：醛糖还原酶以 $\mathrm{NADPH}$ 供氢，葡萄糖还原成山梨醇；多元醇脱氢酶再使山梨醇脱氢，生成果糖和 $\mathrm{NADH}$。
:::

$$
\text{葡萄糖}+\mathrm{NADPH}+\mathrm{H}^{+}\xrightarrow{\text{醛糖还原酶}}\text{山梨醇}+\mathrm{NADP}^{+}
$$

$$
\text{山梨醇}+\mathrm{NAD}^{+}\xrightarrow{\text{多元醇脱氢酶}}\text{果糖}+\mathrm{NADH}+\mathrm{H}^{+}
$$

:::definition{label="醛糖还原酶"}
醛糖还原酶催化葡萄糖还原为山梨醇，氢来自 $\mathrm{NADPH}$。对葡萄糖的亲和力极低，约为 $200\,\mathrm{mmol/L}$，故正常血糖时这条途径在人体糖代谢中所占比例极小。
:::

:::definition{label="多元醇脱氢酶"}
多元醇脱氢酶催化山梨醇脱氢生成果糖，受氢体是 $\mathrm{NAD}^{+}$，产物为果糖和 $\mathrm{NADH}$。糖尿病时若它来不及处理上游生成的山梨醇，山梨醇就会在晶状体堆积。
:::

:::definition{label="山梨醇"}
山梨醇是多元醇途径的中间产物：葡萄糖被醛糖还原酶还原而成，再被多元醇脱氢酶脱氢写成果糖。生理上它是通往精液果糖的过路分子；病理上它在晶状体堆积，抬高渗透压。
:::

:::pitfall{label="正常血糖几乎不走这条路"}
醛糖还原酶对葡萄糖的亲和力极低（约为 $200\,\mathrm{mmol/L}$），而空腹血糖只在 $3.9\sim 6.0\,\mathrm{mmol/L}$（第八节）。把多元醇途径写成“葡萄糖变成果糖的常规通路”，和“所占比例极小”冲突。只有血糖很高、局部葡萄糖涌入，醛糖还原酶才充分发挥作用。
:::

:::compare{title="两步的辅酶不要对调"}
| 步骤 | 酶 | 底物 | 辅酶 | 产物 |
|------|----|------|------|------|
| ①还原 | 醛糖还原酶 | 葡萄糖 | $\mathrm{NADPH}$ 供氢 | 山梨醇 |
| ②脱氢 | 多元醇脱氢酶 | 山梨醇 | $\mathrm{NAD}^{+}$ 受氢 | 果糖 $+$ $\mathrm{NADH}$ |

第四节的 $\mathrm{NADPH}$ 在这里被当成还原剂用掉，不是戊糖磷酸途径的产品账，是消耗账。
:::

多元醇途径具有重要的生理、病理意义。例如，生精细胞利用多元醇途径，在精液中生成高于 $10\,\mathrm{mmol/L}$ 的果糖，精子活动主要依赖果糖供能，以避免与周围组织竞争葡萄糖能源。又如，糖尿病患者血糖水平高，透入眼中晶状体的葡萄糖显著增多，使醛糖还原酶充分发挥作用，生成较多的山梨醇，而后续多元醇脱氢酶来不及处理，故导致山梨醇堆积，可引起晶状体渗透压升高而出现白内障。

:::example{label="精液果糖为什么要高于 10 mmol/L"}
生精细胞走多元醇途径，把葡萄糖写成果糖并富集到精液。精子活动主要依赖果糖供能，这样不必和周围组织抢葡萄糖。生理意义落在“换一种糖当燃料”，不是给全身供能。
:::

:::cause-effect{title="糖尿病为什么会出渗透性白内障"}
- **因** 血糖高 → 透入晶状体的葡萄糖显著增多 → 醛糖还原酶充分发挥作用 → 山梨醇生成多，多元醇脱氢酶来不及处理 → 山梨醇堆积 → 晶状体渗透压升高
- **果** 白内障。山梨醇是直接渗透压负担；不要把这一笔写成“晶状体缺 $\mathrm{ATP}$”或“缺 $\mathrm{NADPH}$ 抗氧化”（后者是第四节蚕豆病的户头）
:::

:::compare{title="生理落点与病理落点"}
| 场合 | 组织 | 产物命运 | 教材结论 |
|------|------|----------|----------|
| 生理 | 生精细胞／精囊 | 果糖 $>10\,\mathrm{mmol/L}$ | 精子用果糖，避免与周围组织竞争葡萄糖 |
| 病理 | 晶状体（糖尿病） | 山梨醇堆积 | 渗透压升高，白内障 |
| 正常血糖 | 上述组织流量极小 | 醛糖还原酶亲和力约为 $200\,\mathrm{mmol/L}$ | 在人体糖代谢中所占比例极小 |
:::

:::insight{label="晶状体卡住的是第二步跟不上第一步"}
醛糖还原酶在高糖时开工，多元醇脱氢酶来不及把山梨醇写成果糖。堆积的是山梨醇，不是果糖。把白内障听成“晶状体里果糖太多”，渗透压的分子户头会写错。
:::

:::pitfall{label="蚕豆病白内障不要并户"}
第四节：葡萄糖-6-磷酸脱氢酶缺陷 → $\mathrm{NADPH}$ 不足 → 谷胱甘肽不能还原 → 红细胞溶血（蚕豆病）。本节：高糖 → 山梨醇堆积 → 晶状体渗透压升高 → 白内障。都用到 $\mathrm{NADPH}$，场合完全不同：前者是红细胞抗氧化缺还原力，后者是醛糖还原酶消耗 $\mathrm{NADPH}$ 做出山梨醇。糖尿病白内障不要写成蚕豆病机制。
:::

:::compare{title="两条小途径各消耗什么辅酶"}
| 途径 | 关键还原／氧化 | 辅酶 | 和第四节的关系 |
|------|----------------|------|----------------|
| 糖醛酸途径 | $\mathrm{UDPG}$ 脱氢成 $\mathrm{UDPGA}$ | 正文未把这一笔写成供能 | 末端木酮糖-5-磷酸汇入戊糖磷酸途径 |
| 多元醇途径第一步 | 葡萄糖 → 山梨醇 | 消耗 $\mathrm{NADPH}$ | 与戊糖磷酸途径抢还原力，但正常时流量极小 |
| 多元醇途径第二步 | 山梨醇 → 果糖 | 生成 $\mathrm{NADH}$ | 不是有氧氧化的主还原当量账 |

高糖时第一步加速、第二步跟不上，才在晶状体留下山梨醇。
:::

:::example{label="为什么点名晶状体和精囊"}
这两处组织被教材写成“还存在”多元醇途径的例子。精囊／生精细胞把路走完，果糖作为精子燃料分泌出去；晶状体在高糖时第一步过快，山梨醇走不掉。不要推广成“全身细胞都常规走葡萄糖→果糖”。
:::

:::keypoint{label="葡萄糖在细胞内的“其他”两笔"}
- 糖醛酸途径：$\mathrm{UDPG}\rightarrow\mathrm{UDPGA}$；糖胺聚糖；肝结合反应；碳架接到木酮糖-5-磷酸。
- 多元醇途径：葡萄糖 $\xrightarrow{\mathrm{NADPH}}$ 山梨醇 $\xrightarrow{\mathrm{NAD}^{+}}$ 果糖；精液果糖；糖尿病晶状体山梨醇白内障。
- 两条在正常糖代谢中比例都很小，但不能删：第四章、第二十五章和糖尿病并发症都要回指这里。
:::

:::memory{label="本节必背要点"}
- [ ] 糖醛酸途径比例很小；$\mathrm{UDPG}$ 脱氢酶生成 $\mathrm{UDPGA}$
- [ ] $\mathrm{UDPGA}$：透明质酸、硫酸软骨素、肝素等糖胺聚糖；肝生物转化结合反应
- [ ] 末端木酮糖-5-磷酸与戊糖磷酸途径衔接（图7-17）
- [ ] 多元醇途径：醛糖还原酶（$\mathrm{NADPH}$）→ 山梨醇；多元醇脱氢酶（$\mathrm{NAD}^{+}$）→ 果糖
- [ ] 醛糖还原酶对葡萄糖亲和力极低，约为 $200\,\mathrm{mmol/L}$，正常时比例极小
- [ ] 精液果糖高于 $10\,\mathrm{mmol/L}$，精子主要用果糖
- [ ] 糖尿病：晶状体山梨醇堆积 → 渗透压升高 → 白内障
:::
