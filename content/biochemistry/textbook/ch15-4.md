# 第四节　真核生物非编码RNA的生物合成

第三节把 $\mathrm{pol}\,\mathrm{II}$ 的前体 $\mathrm{mRNA}$ 写成加帽、加尾、剪接、编辑和降解。人类基因组约 $3\times 10^{9}$ 个碱基对，能作为模板翻译为蛋白质的 $\mathrm{mRNA}$ 只占少量，余下大量 $\mathrm{RNA}$ 并不编码蛋白质，称为非编码 $\mathrm{RNA}$。本节按组成性和调控性两户来写：组成性包括 $\mathrm{rRNA}$、$\mathrm{tRNA}$、核酶、$\mathrm{snoRNA}$、$\mathrm{snRNA}$、$\mathrm{scRNA}$；调控性包括 $\mathrm{lncRNA}$、$\mathrm{miRNA}$、$\mathrm{siRNA}$、$\mathrm{piRNA}$、$\mathrm{circRNA}$。$45\mathrm{S}$ 前体的剪切、酵母 $\mathrm{tRNA}^{\mathrm{Tyr}}$ 的加工、四类内含子和乒乓循环是本版要钉死的事实。章末收全章小结和思考题。

:::concept{term="先问编不编码，再问是组成性还是调控性，然后才问哪一种 RNA pol、要不要剪接体"}
看见“非编码 $\mathrm{RNA}$”，不要先背 $\mathrm{miRNA}$。户头是：基因组很大，$\mathrm{mRNA}$ 只占少量。组成性含量相对稳定，管细胞基本功能；调控性含量随环境和细胞性状改变。$\mathrm{rRNA}$ 走 $\mathrm{pol}\,\mathrm{I}$ 的 $45\mathrm{S}$ 剪切，$\mathrm{tRNA}$ 走 $\mathrm{pol}\,\mathrm{III}$ 再加碱基修饰和蛋白质催化的内含子切除；组Ⅰ／组Ⅱ型是自剪接核酶。$\mathrm{siRNA}$／$\mathrm{miRNA}$／$\mathrm{piRNA}$ 都由核酸酶切割产生，但配对方式和蛋白搭档不同。
:::

:::definition{label="非编码 RNA"}
不能编码蛋白质的 $\mathrm{RNA}$。人类基因组约 $3\times 10^{9}$ 碱基对，可转录多种 $\mathrm{RNA}$，$\mathrm{mRNA}$ 仅占少量。非编码 $\mathrm{RNA}$ 在哺乳动物、真菌、细菌中广泛存在，发挥重要生理作用。
:::

:::

教材写明在哺乳动物、真菌、细菌中广泛存在。$\mathrm{rRNA}$ 前体主要是 $\mathrm{pol}\,\mathrm{I}$，$\mathrm{tRNA}$ 和 $5\mathrm{S}\,\mathrm{rRNA}$ 是 $\mathrm{pol}\,\mathrm{III}$，$\mathrm{lncRNA}$ 大多才是 $\mathrm{pol}\,\mathrm{II}$。把非编码 $\mathrm{RNA}$ 全部写进表15-2 的Ⅱ列，组成性那一户会失踪。
:::

## 一、组成性非编码RNA的合成

组成性非编码 $\mathrm{RNA}$ 是指主要功能为实现细胞基本生物学功能的非编码 $\mathrm{RNA}$，主要包括 $\mathrm{rRNA}$、$\mathrm{tRNA}$、催化小 $\mathrm{RNA}$（又称核酶，ribozyme）、核仁小 $\mathrm{RNA}$（small nucleolar $\mathrm{RNA}$，$\mathrm{snoRNA}$）、$\mathrm{snRNA}$、胞质小 $\mathrm{RNA}$（small cytoplasmic $\mathrm{RNA}$，$\mathrm{scRNA}$）等，它们在细胞中的含量相对稳定。

:::definition{label="组成性非编码 RNA 的成员"}
$\mathrm{rRNA}$、$\mathrm{tRNA}$、催化小 $\mathrm{RNA}$（核酶）、$\mathrm{snoRNA}$、$\mathrm{snRNA}$、$\mathrm{scRNA}$ 等。含量相对稳定，功能落在细胞基本生物学过程，不是随环境剧烈涨落的那一类。
:::

:::compare{title="组成性成员各管什么，不要并进 mRNA 加工一句"}
| 分子 | 本节怎么用 |
|------|------------|
| $\mathrm{rRNA}$ | 核仁里由 $45\mathrm{S}$ 前体剪切成 $18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}$，再装配核糖体 |
| $\mathrm{tRNA}$ | $5'$ 前导、 $3'$ $\mathrm{CCA}$、稀有碱基、反密码子环内含子 |
| 核酶 | 如 $\mathrm{RNase}\,\mathrm{P}$；组Ⅰ／组Ⅱ型自剪接 |
| $\mathrm{snoRNA}$ | 参与 $45\mathrm{S}$ 的 $2'$-$\mathrm{O}$-核糖甲基化等，$\mathrm{snoRNP}$ |
| $\mathrm{snRNA}$ | 第三节剪接体 $\mathrm{U1}$–$\mathrm{U6}$；本节只把它留在组成性名单里 |
| $\mathrm{scRNA}$ | 胞质小 $\mathrm{RNA}$，点名即可 |
:::

### （一）真核前体rRNA经过剪切形成不同类别的rRNA

真核细胞的 $\mathrm{rRNA}$ 基因（$\mathrm{rDNA}$）属于冗余基因（redundant gene）族的 $\mathrm{DNA}$ 序列，即染色体上一些相似或完全一样的纵列串联基因（tandem gene）单位的重复。属于冗余基因族的还有 $5\mathrm{S}\,\mathrm{rRNA}$ 基因、组蛋白基因、免疫球蛋白基因等。不同物种基因组可有数百或上千个 $\mathrm{rDNA}$，每个基因又被不能转录的基因间隔（gene spacer）分段隔开。可转录片段大小为 $7\sim 13\,\mathrm{kb}$，间隔区也有若干 $\mathrm{kb}$ 大小。这些基因间隔不是内含子。$\mathrm{rDNA}$ 位于核仁内，每个基因各自为一个转录单位。

真核生物基因组的 $\mathrm{rRNA}$ 基因中，$18\mathrm{S}$、$5.8\mathrm{S}$ 和 $28\mathrm{S}\,\mathrm{rRNA}$ 基因是串联在一起的，转录后产生 $45\mathrm{S}$ 的转录产物。$45\mathrm{S}\,\mathrm{rRNA}$ 是 $3$ 种 $\mathrm{rRNA}$ 的前身。$45\mathrm{S}\,\mathrm{rRNA}$ 在 $\mathrm{snoRNA}$ 以及多种蛋白质分子组成的核仁小核糖核蛋白（small nucleolar ribonucleo protein，$\mathrm{snoRNP}$）的介导下经历了 $2'$-$\mathrm{O}$-核糖甲基化等化学修饰，这些修饰可能与其后续的加工、折叠和组装后的核糖体功能有关。$45\mathrm{S}\,\mathrm{rRNA}$ 经过某些核糖核酸内切酶和核糖核酸外切酶的剪切，去除内含子等序列，而产生成熟的 $18\mathrm{S}$、$5.8\mathrm{S}$ 及 $28\mathrm{S}$ 的 $\mathrm{rRNA}$（图15-23）。

$\mathrm{rRNA}$ 成熟后，就在核仁上装配，与核糖体蛋白质一起形成核糖体，输送到胞质。生长中的细胞，其 $\mathrm{rRNA}$ 较稳定；静止状态的细胞，其 $\mathrm{rRNA}$ 的寿命较短。

::figure{src="/images/biochemistry/textbook/p0322_01.png" caption="图15-23　真核前体 rRNA 转录后的剪切。rDNA 上 18S、5.8S、28S 串联，斜线框为内含子，虚线为基因间隔；先转录出 45S rRNA，经两次剪切得到成熟 18S、5.8S 及 28S rRNA。" alt="rDNA 串联重复示意，45S 前体先分成 18S 与 5.8S+28S，再分成三种成熟 rRNA"}

:::definition{label="rDNA 属于冗余基因族"}
染色体上相似或完全一样的纵列串联基因单位的重复。同属冗余基因族的还有 $5\mathrm{S}\,\mathrm{rRNA}$ 基因、组蛋白基因、免疫球蛋白基因等。不同物种可有数百或上千个 $\mathrm{rDNA}$。
:::

:::definition{label="基因间隔不是内含子"}
每个 $\mathrm{rDNA}$ 被不能转录的基因间隔分段隔开。可转录片段 $7\sim 13\,\mathrm{kb}$，间隔区也有若干 $\mathrm{kb}$。这些间隔不是内含子。$\mathrm{rDNA}$ 位于核仁内，每个基因各自为一个转录单位。
:::

:::definition{label="45S rRNA 是 18S、5.8S、28S 的前身"}
三种基因串联在一起，转录出 $45\mathrm{S}$。在 $\mathrm{snoRNA}$ 与多种蛋白质组成的 $\mathrm{snoRNP}$ 介导下发生 $2'$-$\mathrm{O}$-核糖甲基化等化学修饰，可能与后续加工、折叠和组装后的核糖体功能有关。再经核糖核酸内切酶和外切酶剪切，去除内含子等序列，得到成熟 $18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}$（图15-23）。
:::

:::definition{label="成熟 rRNA 在核仁装配核糖体"}
与核糖体蛋白质一起形成核糖体，输送到胞质。生长中的细胞 $\mathrm{rRNA}$ 较稳定；静止状态的细胞寿命较短。
:::

:::keypoint{label="图15-23 两层剪切"}
- $\mathrm{rDNA}$：斜线框标内含子，虚线标基因间隔；$18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}$ 串联。
- $45\mathrm{S}\,\mathrm{rRNA}$ 先剪切成 $18\mathrm{S}\,\mathrm{rRNA}$ 和 $5.8\mathrm{S}+28\mathrm{S}\,\mathrm{rRNA}$，再剪切成三条成熟分子。
- $5\mathrm{S}\,\mathrm{rRNA}$ 不在这张图上，它由 $\mathrm{pol}\,\mathrm{III}$ 在核仁外合成。
:::

:::pitfall{label="基因间隔不要写成内含子，内含子也不要写成间隔"}
间隔不能转录，把串联重复的转录单位隔开；内含子在 $45\mathrm{S}$ 前体内部，要靠内切／外切酶去掉。图15-23 用虚线和斜线框分开画。把间隔答成“$\mathrm{rDNA}$ 的内含子”，冗余基因族和断裂基因会并户。
:::

:::pitfall{label="45S 不要写成四种 rRNA 的共同前体"}
前身只覆盖 $18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}$。$5\mathrm{S}\,\mathrm{rRNA}$ 基因虽也属冗余基因族，转录酶是 $\mathrm{pol}\,\mathrm{III}$，不进 $45\mathrm{S}$。
:::

:::insight{label="生长细胞 rRNA 更稳定，和 mRNA 寿命最短对照"}
第三节说 $\mathrm{mRNA}$ 最不稳定、需经常重新合成，所以 $\mathrm{pol}\,\mathrm{II}$ 最活跃。$\mathrm{rRNA}$ 在生长细胞里较稳定，静止细胞才短命。组成性不是“永不降解”，而是含量相对稳定、功能基础。
:::

### （二）真核前体tRNA的加工包括核苷酸的碱基修饰

真核生物的大多数细胞有 $40\sim 50$ 种不同的 $\mathrm{tRNA}$ 分子。编码 $\mathrm{tRNA}$ 的基因在基因组内都有多个拷贝。前体 $\mathrm{tRNA}$ 分子需要多种转录后加工才能成为成熟的 $\mathrm{tRNA}$。

以酵母前体 $\mathrm{tRNA}^{\mathrm{Tyr}}$ 分子为例，加工主要包括以下变化：①酵母前体 $\mathrm{tRNA}^{\mathrm{Tyr}}$ 分子 $5'$-端的 $16$ 个核苷酸前导序列由核糖核酸酶 $\mathrm{P}$（$\mathrm{RNase}\,\mathrm{P}$）切除，$\mathrm{RNase}\,\mathrm{P}$ 属于核酶（ribozyme）。核酶是具有催化功能的 $\mathrm{RNA}$。②氨基酸臂的 $3'$-端 $2$ 个 $\mathrm{U}$ 被核糖核酸内切酶 $\mathrm{RNase}\,\mathrm{Z}$ 切除，有时核糖核酸外切酶 $\mathrm{RNase}\,\mathrm{D}$ 等也参与切除过程，然后氨基酸臂的 $3'$-端再由核苷酸转移酶加上特有的 $\mathrm{CCA}$ 末端。③茎-环结构中的一些核苷酸碱基经化学修饰为稀有碱基，包括某些嘌呤甲基化生成甲基嘌呤、某些尿嘧啶还原为二氢尿嘧啶（$\mathrm{DHU}$）、尿嘧啶核苷转变为假尿嘧啶核苷（$\Psi$）、某些腺苷酸脱氨成为次黄嘌呤核苷酸（$\mathrm{I}$）等。④通过剪接切除茎-环结构中部 $14$ 个核苷酸的内含子。内含子剪切由 $\mathrm{tRNA}$ 剪接内切酶（$\mathrm{tRNA}$ splicing endonuclease，$\mathrm{TSEN}$）完成。切除后的连接反应由 $\mathrm{tRNA}$ 连接酶催化。前体 $\mathrm{tRNA}$ 分子必须折叠成特殊的二级结构，剪接反应才能发生，内含子一般都位于前体 $\mathrm{tRNA}$ 分子的反密码子环（图15-24）。

::figure{src="/images/biochemistry/textbook/p0322_02.png" caption="图15-24　前体 tRNA 的剪接。左：RNase P（核酶）切 5′ 前导，tRNA 核酸内切酶（蛋白质）切反密码子环内含子；中：RNase Z（蛋白质）切 3′ 端，tRNA 连接酶封内含子切口，核苷酸转移酶加 CCA；右：成熟三叶草，3′ 为 CCA-OH。" alt="三步 tRNA 加工：去 5′ 前导和内含子、去 3′ 并加 CCA、成熟分子"}

:::definition{label="真核 tRNA 有 40～50 种，基因多拷贝"}
大多数细胞 $40\sim 50$ 种不同 $\mathrm{tRNA}$。编码基因在基因组内都有多个拷贝。前体必须多种转录后加工才成熟。
:::

:::definition{label="RNase P 切 5′ 前导，本身是核酶"}
酵母前体 $\mathrm{tRNA}^{\mathrm{Tyr}}$ 的 $5'$-端 $16$ 个核苷酸前导由 $\mathrm{RNase}\,\mathrm{P}$ 切除。$\mathrm{RNase}\,\mathrm{P}$ 属于核酶：具有催化功能的 $\mathrm{RNA}$。
:::

:::definition{label="3′ 端去 2 个 U 再加 CCA"}
氨基酸臂 $3'$-端 $2$ 个 $\mathrm{U}$ 由 $\mathrm{RNase}\,\mathrm{Z}$（核糖核酸内切酶）切除，有时 $\mathrm{RNase}\,\mathrm{D}$ 等外切酶也参与。然后核苷酸转移酶加上特有的 $\mathrm{CCA}$ 末端。图15-24 把 $\mathrm{RNase}\,\mathrm{Z}$ 标为蛋白质。
:::

:::definition{label="稀有碱基四种写法"}
茎-环中一些碱基被修饰：嘌呤甲基化→甲基嘌呤；尿嘧啶还原→二氢尿嘧啶（$\mathrm{DHU}$）；尿嘧啶核苷→假尿嘧啶核苷（$\Psi$）；腺苷酸脱氨→次黄嘌呤核苷酸（$\mathrm{I}$）。
:::

:::definition{label="tRNA 内含子由蛋白质酶切，再由连接酶封口"}
茎-环中部 $14$ 个核苷酸的内含子，由 $\mathrm{TSEN}$（$\mathrm{tRNA}$ 剪接内切酶）剪切，再由 $\mathrm{tRNA}$ 连接酶连接。前体必须折成特殊二级结构剪接才能发生；内含子一般都位于反密码子环（图15-24）。
:::

:::timeline{period="酵母前体 tRNA Tyr 四步加工"}
- **5′ 前导** RNase P（核酶）切掉 16 个核苷酸
- **3′ 端** RNase Z（有时加上 RNase D）切掉 2 个 U，核苷酸转移酶加上 CCA
- **稀有碱基** 甲基嘌呤、DHU、Ψ、I
- **内含子** 反密码子环 14 nt，TSEN 切、tRNA 连接酶连；先折成特殊二级结构
:::

$\mathrm{TSEN}$ 和 $\mathrm{tRNA}$ 连接酶都是蛋白质。后面四类内含子里，这一类单列，不走 $\mathrm{U1}$–$\mathrm{U6}$。把第三节剪接体搬到 $\mathrm{tRNA}^{\mathrm{Tyr}}$，图15-24 的“蛋白质”标注就闲了。

:::pitfall{label="CCA 不是基因组抄出来的末端"}
先切掉 $2$ 个 $\mathrm{U}$，再由核苷酸转移酶加上 $\mathrm{CCA}$。写成“转录到 $\mathrm{CCA}$ 就结束”，和“特有的 $\mathrm{CCA}$ 末端”冲突。
:::

:::insight{label="同一节里核酶和蛋白质酶都要出场"}
$\mathrm{RNase}\,\mathrm{P}$ 是核酶，$\mathrm{RNase}\,\mathrm{Z}$／$\mathrm{TSEN}$／连接酶是蛋白质。不要把“$\mathrm{tRNA}$ 加工都是核酶”或“都是蛋白质”写成一句。组Ⅰ／组Ⅱ型自剪接是下一小节的核酶，对象不是这 $14\,\mathrm{nt}$ 的反密码子环内含子。

### （三）RNA催化一些内含子的自剪接

$1982$ 年，美国科学家 Cech T. 和他的同事发现四膜虫编码 $\mathrm{rRNA}$ 前体的 $\mathrm{DNA}$ 序列含有间隔内含子序列，他们在体外用从细菌纯化得到的 $\mathrm{RNA}\,\mathrm{pol}$ 转录从四膜虫纯化的编码 $\mathrm{rRNA}$ 前体的 $\mathrm{DNA}$，发现在没有任何来自四膜虫的蛋白质情况下，$\mathrm{rRNA}$ 前体能准确地剪接去除内含子。这种由 $\mathrm{RNA}$ 分子催化自身内含子剪接的反应称为自剪接（self-splicing）。随后，在其他原核生物以及真核生物的线粒体、叶绿体的 $\mathrm{rRNA}$ 前体加工中，亦证实了这种剪接。这些自身剪接内含子的 $\mathrm{RNA}$ 具有催化功能，属于核酶。

一些噬菌体的前体 $\mathrm{mRNA}$ 及细菌 $\mathrm{tRNA}$ 前体也发现有这类自身剪接的内含子，并被称为组Ⅰ型内含子（group Ⅰ intron）。组Ⅰ型内含子以游离的鸟嘌呤核苷或鸟嘌呤核苷酸作为辅因子完成剪接。鸟嘌呤核苷或鸟嘌呤核苷酸的 $3'$-$\mathrm{OH}$ 与内含子的 $5'$-磷酸共同参与转酯反应，切除的内含子是线状。

许多生物中还存在组Ⅱ型内含子（group Ⅱ intron）。组Ⅱ型内含子是另一类独特的、能起催化作用的 $\mathrm{RNA}$，其 $\mathrm{RNA}$ 能催化内含子的自剪接。组Ⅱ型内含子不如组Ⅰ型内含子更普遍。这两类内含子有一个共同的特性，就是在体外（in vitro）能够自我剪接，而不需要任何蛋白质酶的催化。但是在体内（in vivo）它们却都需要蛋白质帮助折叠成二级结构。组Ⅱ型内含子与组Ⅰ型内含子的内部保守序列和折叠结构不同。另外，组Ⅱ型内含子通过产生一个套索状中间体来进行自剪接，而组Ⅰ型内含子则不形成套索状中间体（图15-25）。

组Ⅱ型内含子的剪接与前面介绍的前体 $\mathrm{mRNA}$ 的剪接都形成套索状结构，但是前者没有剪接体参与（图15-25）。

与上面三种内含子不同的是，真核细胞 $\mathrm{tRNA}$ 和古菌 $\mathrm{tRNA}$ 的内含子属于 $\mathrm{tRNA}$ 内含子。这些 $\mathrm{tRNA}$ 中位于内部的内含子是由蛋白质催化来进行剪接的，参与的酶是 $\mathrm{tRNA}$ 剪切内切酶和 $\mathrm{tRNA}$ 连接酶。因此，现在发现至少存在有 $4$ 种类型的内含子，它们分别是组Ⅰ型内含子、组Ⅱ型内含子、剪接体内含子和 $\mathrm{tRNA}$ 内含子。

需要指出的是，剪接和剪切等 $\mathrm{RNA}$ 转录后加工在原核生物细胞内的前体 $\mathrm{rRNA}$、前体 $\mathrm{tRNA}$ 等非编码 $\mathrm{RNA}$ 中普遍存在，但是，原核生物细胞内没有剪接体，其编码蛋白质的 $\mathrm{mRNA}$ 没有内含子，不进行剪接等转录后加工，也不进行 $5'$-末端“帽”结构和 $3'$-端多聚腺苷酸尾的添加。

:::note{label="电子版缺失"}
图15-25　四种类型内含子。电子版图源 `p0323_01.png` 为 $0$ 字节，不嵌入 `src`。正文以组Ⅰ型（游离 $\mathrm{G}$ 辅因子，线状内含子、无套索）、组Ⅱ型（套索中间体、无剪接体）、剪接体内含子、$\mathrm{tRNA}$ 内含子（蛋白质酶）为准。
:::

:::definition{label="自剪接"}
由 $\mathrm{RNA}$ 分子催化自身内含子剪接。$1982$ 年 Cech T. 等：体外用细菌纯化的 $\mathrm{RNA}\,\mathrm{pol}$ 转录四膜虫 $\mathrm{rRNA}$ 前体基因，没有任何来自四膜虫的蛋白质，$\mathrm{rRNA}$ 前体仍能准确去除内含子。随后在其他原核生物以及真核线粒体、叶绿体的 $\mathrm{rRNA}$ 前体加工中也证实。这类 $\mathrm{RNA}$ 属于核酶。
:::

:::definition{label="组Ⅰ型内含子"}
见于一些噬菌体前体 $\mathrm{mRNA}$ 及细菌 $\mathrm{tRNA}$ 前体等。以游离的鸟嘌呤核苷或鸟嘌呤核苷酸为辅因子；其 $3'$-$\mathrm{OH}$ 与内含子 $5'$-磷酸共同参与转酯；切除的内含子是线状，不形成套索。
:::

:::definition{label="组Ⅱ型内含子"}
另一类能起催化作用的 $\mathrm{RNA}$，催化自剪接，不如组Ⅰ型普遍。通过套索状中间体自剪接；与前体 $\mathrm{mRNA}$ 剪接都形成套索，但没有剪接体参与。内部保守序列和折叠结构与组Ⅰ型不同。
:::

:::definition{label="体外不需要蛋白质，体内需要蛋白质帮助折叠"}
组Ⅰ型和组Ⅱ型的共同特性：体外能自我剪接，不需要任何蛋白质酶催化；体内都需要蛋白质帮助折叠成二级结构。
:::

:::definition{label="tRNA 内含子是第四类"}
真核细胞 $\mathrm{tRNA}$ 和古菌 $\mathrm{tRNA}$ 内部的内含子由蛋白质催化：$\mathrm{tRNA}$ 剪切内切酶和 $\mathrm{tRNA}$ 连接酶。与组Ⅰ、组Ⅱ、剪接体三类都不同。
:::

:::definition{label="至少四类内含子"}
组Ⅰ型内含子、组Ⅱ型内含子、剪接体内含子、$\mathrm{tRNA}$ 内含子。
:::

:::definition{label="原核 mRNA 没有内含子、没有帽和 poly(A)"}
剪接和剪切等加工在原核前体 $\mathrm{rRNA}$、前体 $\mathrm{tRNA}$ 等非编码 $\mathrm{RNA}$ 中普遍存在；但原核没有剪接体，编码蛋白质的 $\mathrm{mRNA}$ 没有内含子，不进行剪接，也不加 $5'$ 帽和 $3'$ $\mathrm{poly}(\mathrm{A})$。
:::

:::

:::pitfall{label="套索不等于剪接体"}
组Ⅱ型和前体 $\mathrm{mRNA}$ 都走套索，但组Ⅱ型没有剪接体。只看见套索就答“一定是 $\mathrm{U1}$–$\mathrm{U6}$”，会把两类并户。
:::

:::pitfall{label="自剪接“不需要蛋白质”只在体外绝对成立"}
体内组Ⅰ／组Ⅱ都需要蛋白质帮助折叠成二级结构。把 Cech 的体外实验写成“细胞内也完全没有蛋白质参与”，和教材下一句冲突。
:::

:::insight{label="原核不是没有 RNA 加工，是没有剪接体那一套 mRNA 加工"}
前体 $\mathrm{rRNA}$、前体 $\mathrm{tRNA}$ 在原核照样剪切、剪接。缺的是：剪接体、$\mathrm{mRNA}$ 内含子、$5'$ 帽、$3'$ $\mathrm{poly}(\mathrm{A})$。用“原核不加工 $\mathrm{RNA}$”会把本节组成性加工整段否掉。
:::

## 二、调控性非编码RNA的合成

调控性非编码 $\mathrm{RNA}$ 多指具有调控基因表达作用的非编码 $\mathrm{RNA}$，主要包括 $\mathrm{lncRNA}$、$\mathrm{miRNA}$、$\mathrm{siRNA}$、$\mathrm{piRNA}$、环状 $\mathrm{RNA}$（circular $\mathrm{RNA}$，$\mathrm{circRNA}$）等，它们在细胞中的含量往往随外界环境和细胞性状发生改变。

:::definition{label="调控性非编码 RNA"}
多指调控基因表达的非编码 $\mathrm{RNA}$：$\mathrm{lncRNA}$、$\mathrm{miRNA}$、$\mathrm{siRNA}$、$\mathrm{piRNA}$、$\mathrm{circRNA}$ 等。含量随环境和细胞性状改变，和组成性“相对稳定”对读。
:::

### （一）lncRNA的合成形式呈现多样化

$\mathrm{lncRNA}$ 大多由 $\mathrm{RNA}\,\mathrm{pol}\,\mathrm{II}$ 催化生成，其表达过程与 $\mathrm{mRNA}$ 相似，并且与 $\mathrm{mRNA}$ 一样，多数 $\mathrm{lncRNA}$ 都有帽子结构和多聚腺苷酸尾结构。根据 $\mathrm{lncRNA}$ 在基因组上与蛋白质编码基因的相对位置，将其分为基因间型 $\mathrm{lncRNA}$、内含子型 $\mathrm{lncRNA}$、正义型 $\mathrm{lncRNA}$、反义型 $\mathrm{lncRNA}$ 和双向型 $\mathrm{lncRNA}$ 五类。

:::definition{label="lncRNA 大多由 pol II 生成"}
表达过程与 $\mathrm{mRNA}$ 相似，多数有帽子和 $\mathrm{poly}(\mathrm{A})$ 尾。第三节已写基因间区也可转录产生 $\mathrm{lncRNA}$。
:::

:::definition{label="lncRNA 按与编码基因的相对位置分五类"}
基因间型、内含子型、正义型、反义型、双向型。分类依据是基因组位置，不是五种不同的聚合酶。
:::

:::pitfall{label="多数有帽和尾，不等于 lncRNA 就是 mRNA"}
加工相似，但不编码蛋白质。不要因为有帽有尾就把它写进翻译模板。
:::

### （二）siRNA，miRNA和piRNA都由核酸酶切割产生

$\mathrm{siRNA}$ 是一类约 $21\sim 23\,\mathrm{nt}$ 的非编码 $\mathrm{RNA}$ 分子，是在特定情况下通过核酸酶 $\mathrm{Dicer}$（$\mathrm{RNAase}$ Ⅲ 家族中对双链 $\mathrm{RNA}$ 具有特异性的酶）的切割由长双链 $\mathrm{RNA}$ 转变生成的。$\mathrm{siRNA}$ 通过完全互补配对的方式与目标 $\mathrm{mRNA}$ 结合，引起其降解，从而导致靶基因的沉默，在防御外源核酸入侵中发挥重要作用。

$\mathrm{miRNA}$ 是一类长度为 $20\sim 24\,\mathrm{nt}$ 的单链小分子 $\mathrm{RNA}$，广泛存在于真核生物中。$\mathrm{miRNA}$ 是由 $70\sim 90$ 个碱基、具发夹结构单链 $\mathrm{RNA}$ 前体（pre $\mathrm{miRNA}$）经过 $\mathrm{Dicer}$ 酶加工而成，主要通过与靶标基因不完全互补结合，进而抑制翻译或促进 $\mathrm{mRNA}$ 聚腺苷酸尾巴（$\mathrm{polyA}$ tail）的去除等方式调控靶基因的表达。

$\mathrm{piRNA}$ 是一类最早发现于生殖细胞中的长度约为 $24\sim 31\,\mathrm{nt}$ 的小分子非编码 $\mathrm{RNA}$，其作用依赖于 $\mathrm{PIWI}$ 蛋白因此而得名。$\mathrm{piRNA}$ 的合成过程尚不明确，目前认为其合成伴随着来自转座子和 $\mathrm{piRNA}$ 簇的互补转录本的相互切割，这个过程被称为“乒乓循环”（ping-pong cycle）。乒乓循环产生成对的 $\mathrm{piRNA}$（“启动”和“应答”$\mathrm{piRNA}$）。“乒乓循环”由一个结合了 $\mathrm{PIWI}$ 蛋白的“启动”$\mathrm{piRNA}$ 对前体转录物进行剪切所启动，$\mathrm{PIWI}$ 裂解得到的 $5'$-单磷酸基片段被作为 $\mathrm{piRNA}$ 前前体（pre-pre-$\mathrm{piRNA}$）传递给相应的 $\mathrm{PIWI}$ 蛋白，随后被裂解。由此产生的 $5'$ 裂解片段被称为 $\mathrm{piRNA}$ 前体（pre-$\mathrm{piRNA}$），其 $3'$-末端可被 $3'$，$5'$-核酸外切酶 $\mathrm{Trimmer}$ 进一步修饰剪切为成熟长度，同时被甲基转移酶 $\mathrm{Hen}1$ 催化生成“应答”$\mathrm{piRNA}$。

:::definition{label="siRNA"}
约 $21\sim 23\,\mathrm{nt}$。特定情况下由 $\mathrm{Dicer}$（$\mathrm{RNase}$ Ⅲ 家族、对双链 $\mathrm{RNA}$ 特异）切割长双链 $\mathrm{RNA}$ 生成。与目标 $\mathrm{mRNA}$ 完全互补配对，引起降解，沉默靶基因，防御外源核酸入侵。
:::

:::definition{label="miRNA"}
$20\sim 24\,\mathrm{nt}$ 单链，广泛存在于真核生物。由 $70\sim 90$ 个碱基、具发夹结构的单链前体（pre $\mathrm{miRNA}$）经 $\mathrm{Dicer}$ 加工而成。与靶标不完全互补，抑制翻译或促进 $\mathrm{mRNA}$ 的 $\mathrm{polyA}$ 尾去除，从而调控表达。
:::

:::definition{label="piRNA 依赖 PIWI，合成走乒乓循环"}
最早发现于生殖细胞，约 $24\sim 31\,\mathrm{nt}$。因依赖 $\mathrm{PIWI}$ 蛋白得名。合成过程尚不明确；目前认为伴随转座子和 $\mathrm{piRNA}$ 簇互补转录本的相互切割，即乒乓循环，产生成对的“启动”和“应答”$\mathrm{piRNA}$。
:::

:::definition{label="乒乓循环的分子顺序"}
结合了 $\mathrm{PIWI}$ 的“启动”$\mathrm{piRNA}$ 剪切前体转录物 → $5'$-单磷酸片段作为 pre-pre-$\mathrm{piRNA}$ 传给相应 $\mathrm{PIWI}$ 再裂解 → $5'$ 裂解片段为 pre-$\mathrm{piRNA}$ → $3'$ 端被 $3'$，$5'$-核酸外切酶 $\mathrm{Trimmer}$ 修到成熟长度，同时甲基转移酶 $\mathrm{Hen}1$ 催化生成“应答”$\mathrm{piRNA}$。
:::

:::compare{title="三种小 RNA 都由核酸酶切割，但不是同一种产物"}
| | 长度 | 前体 | 酶／蛋白 | 与靶标 | 功能要点 |
|--|------|------|----------|--------|----------|
| $\mathrm{siRNA}$ | $21\sim 23\,\mathrm{nt}$ | 长双链 $\mathrm{RNA}$ | $\mathrm{Dicer}$（$\mathrm{RNase}$ Ⅲ，dsRNA 特异） | 完全互补 | 降解 $\mathrm{mRNA}$，防御外源核酸 |
| $\mathrm{miRNA}$ | $20\sim 24\,\mathrm{nt}$ 单链 | $70\sim 90\,\mathrm{nt}$ 发夹 pre $\mathrm{miRNA}$ | $\mathrm{Dicer}$ | 不完全互补 | 抑翻译或去 $\mathrm{polyA}$ 尾 |
| $\mathrm{piRNA}$ | $24\sim 31\,\mathrm{nt}$ | 转座子／$\mathrm{piRNA}$ 簇转录本 | $\mathrm{PIWI}$、$\mathrm{Trimmer}$、$\mathrm{Hen}1$ | — | 生殖细胞；乒乓循环 |

:::

- **启动 piRNA 结合 PIWI** 剪切前体转录物
- **5′-单磷酸片段** 作为 pre-pre-piRNA 交给相应 PIWI，再被裂解
- **pre-piRNA** 5′ 裂解片段；Trimmer 按 3′，5′ 外切修到成熟长度
- **Hen1 甲基化** 生成应答 piRNA，与启动 piRNA 成对
:::

:::pitfall{label="siRNA 完全互补，miRNA 不完全互补，不要对调"}
完全互补 → 降解 $\mathrm{mRNA}$（$\mathrm{siRNA}$）。不完全互补 → 抑翻译或去尾（$\mathrm{miRNA}$）。长度都在二十多核苷酸，靠配对方式分，不靠“谁更短”。
:::

:::pitfall{label="Dicer 切 siRNA 和 miRNA，不负责 piRNA 的乒乓循环"}
$\mathrm{siRNA}$／$\mathrm{miRNA}$ 点名 $\mathrm{Dicer}$。$\mathrm{piRNA}$ 点名 $\mathrm{PIWI}$、$\mathrm{Trimmer}$、$\mathrm{Hen}1$，而且教材写“合成过程尚不明确”。把三种都答成 $\mathrm{Dicer}$ 产物，乒乓循环没有酶。
:::

:::insight{label="miRNA 去 polyA 尾，直接接到第三节的降解主路"}
第三节：脱腺苷酸化是正常 $\mathrm{mRNA}$ 降解的主要方式，尾缩短翻译活性下降。$\mathrm{miRNA}$“促进 $\mathrm{mRNA}$ 聚腺苷酸尾巴的去除”不是另起一条与脱腺苷酸化无关的魔法，而是把调控性非编码 $\mathrm{RNA}$ 接到那条主路上。
:::

## 本章小结

$\mathrm{RNA}$ 是细胞中广泛分布而且非常丰富的一类多功能分子。多数细胞中有三种主要的 $\mathrm{RNA}$ 类型：$\mathrm{mRNA}$、$\mathrm{rRNA}$ 和 $\mathrm{tRNA}$。$\mathrm{mRNA}$ 的一个重要功能就是将基因组信息传递给蛋白质。$\mathrm{rRNA}$ 和 $\mathrm{tRNA}$ 也是细胞内蛋白质生物合成所必需的。

$\mathrm{RNA}\,\mathrm{pol}$ 以 $\mathrm{DNA}$ 为模板，以 $5'$-三磷酸核糖核苷为原料催化合成与模板互补的 $\mathrm{RNA}$，这个过程称为转录。转录有 $\mathrm{RNA}\,\mathrm{pol}$ 与启动子结合、起始、延长和终止几个阶段，$\mathrm{RNA}$ 合成的方向是从 $5'\rightarrow 3'$。原核生物 $\mathrm{RNA}\,\mathrm{pol}$ 只有一种，全酶形式是 $\sigma\alpha_2\beta\beta'\omega$，以 $\sigma$ 亚基识别启动子，核心酶 $\alpha_2\beta\beta'\omega$ 催化合成 $\mathrm{RNA}$。原核生物的转录终止有 $\rho$ 因子依赖终止和 $\rho$ 因子非依赖终止两种方式。

真核细胞的核内至少具有 $3$ 种主要的 $\mathrm{RNA}\,\mathrm{pol}$。$\mathrm{RNA}\,\mathrm{pol}\,\mathrm{I}$ 合成大部分 $\mathrm{rRNA}$ 前体，$\mathrm{RNA}\,\mathrm{pol}\,\mathrm{II}$ 合成前体 $\mathrm{mRNA}$（precursor $\mathrm{mRNA}$），$\mathrm{RNA}\,\mathrm{pol}\,\mathrm{III}$ 合成 $\mathrm{tRNA}$ 和 $5\mathrm{S}\,\mathrm{rRNA}$ 前体。真核 $\mathrm{RNA}\,\mathrm{pol}$ 由多亚基组成。$\mathrm{RNA}\,\mathrm{pol}\,\mathrm{II}$ 与启动子的结合需要多种转录因子参与；聚合酶Ⅱ最大亚基有羧基末端结构域（$\mathrm{CTD}$），在转录起始和延长阶段被磷酸化。

真核前体 $\mathrm{mRNA}$ 的 $5'$-端加上 $7$-甲基鸟嘌呤核苷残基的帽结构，$3'$-端通过断裂及多聚腺苷酸化加上多聚腺苷酸尾结构，内含子通过剪接切除。一个前体 $\mathrm{mRNA}$ 分子可经过剪接和剪切两种模式而加工成多个 $\mathrm{mRNA}$ 分子。有些真核的 $\mathrm{rRNA}$、$\mathrm{tRNA}$ 和前体 $\mathrm{mRNA}$ 含有自身剪接内含子，这类内含子的剪接不需要蛋白质参与，内含子自身的 $\mathrm{RNA}$ 具有催化剪接的功能。这些 $\mathrm{RNA}$ 具有核酶活性。有些 $\mathrm{mRNA}$ 要经过编辑。

$\mathrm{mRNA}$ 降解是细胞保持其正常的生理状态所必需的。$\mathrm{mRNA}$ 降解包括正常转录物的降解和异常转录物的降解。正常转录物是指细胞产生的有正常功能的 $\mathrm{mRNA}$。异常转录物是细胞产生的一些非正常转录物。在真核细胞中，正常转录物和异常转录物的降解都有多种方式。

除 $\mathrm{mRNA}$、$\mathrm{rRNA}$ 和 $\mathrm{tRNA}$ 外，真核细胞内还有 $\mathrm{snRNA}$、$\mathrm{miRNA}$ 和 $\mathrm{lncRNA}$ 等非编码 $\mathrm{RNA}$，分别与 $\mathrm{mRNA}$ 的剪切和基因表达调控有关（见第二章和第十六章）。对于 $\mathrm{RNA}$ 生物过程的调节，可以导致蛋白质合成速率的改变以及由此而引发的一系列代谢变化，因此了解 $\mathrm{RNA}$ 合成的基本原理甚为重要。这些原理既关系到所有生物是如何适应环境变化的，也关系到细胞特定结构和功能的形成机制。$\mathrm{mRNA}$ 转录物的错误加工和剪切可引起疾病，例如某些类型的地中海贫血。除参与蛋白质的生物合成外，非编码 $\mathrm{RNA}$ 等 $\mathrm{RNA}$ 还具有其他重要的生物学功能。

:::definition{label="本章小结里的三种主要 RNA"}
多数细胞：$\mathrm{mRNA}$、$\mathrm{rRNA}$、$\mathrm{tRNA}$。$\mathrm{mRNA}$ 把基因组信息传递给蛋白质；$\mathrm{rRNA}$ 和 $\mathrm{tRNA}$ 也是蛋白质生物合成所必需。
:::

:::definition{label="本章小结里的转录通式"}
$\mathrm{RNA}\,\mathrm{pol}$ 以 $\mathrm{DNA}$ 为模板、$5'$-三磷酸核糖核苷为原料，合成与模板互补的 $\mathrm{RNA}$。阶段：与启动子结合、起始、延长、终止。方向 $5'\rightarrow 3'$。
:::

:::definition{label="本章小结里的原核 RNA pol"}
只有一种。全酶 $\sigma\alpha_2\beta\beta'\omega$，$\sigma$ 识别启动子，核心酶 $\alpha_2\beta\beta'\omega$ 催化合成。终止：$\rho$ 因子依赖与非依赖两种。
:::

:::definition{label="本章小结里的真核三种酶和 CTD"}
核内至少三种：$\mathrm{pol}\,\mathrm{I}$ 大部分 $\mathrm{rRNA}$ 前体；$\mathrm{pol}\,\mathrm{II}$ 前体 $\mathrm{mRNA}$；$\mathrm{pol}\,\mathrm{III}$ $\mathrm{tRNA}$ 和 $5\mathrm{S}\,\mathrm{rRNA}$ 前体。多亚基。$\mathrm{pol}\,\mathrm{II}$ 结合启动子需多种转录因子；最大亚基有 $\mathrm{CTD}$，起始和延长阶段被磷酸化。
:::

:::definition{label="本章小结里的前体 mRNA 加工"}
$5'$ 加 $7$-甲基鸟嘌呤核苷帽；$3'$ 断裂及多聚腺苷酸化加尾；内含子剪接切除。同一前体可经剪接和剪切两种模式加工成多个 $\mathrm{mRNA}$。有些要编辑。有些 $\mathrm{rRNA}$、$\mathrm{tRNA}$ 和前体 $\mathrm{mRNA}$ 含自身剪接内含子：体外不需蛋白质，内含子 $\mathrm{RNA}$ 有核酶活性。
:::

:::definition{label="本章小结里的降解与疾病"}
正常和异常转录物都要降解，方式都有多种。错误加工和剪切可引起疾病，例如某些类型的地中海贫血。$\mathrm{snRNA}$、$\mathrm{miRNA}$、$\mathrm{lncRNA}$ 等与剪切和表达调控有关（见第二章和第十六章）。
:::

:::keypoint{label="本章小结按节收口"}
- 第一节：转录是主要方式；模板链／编码链；$\mathrm{RNA}\,\mathrm{pol}$ 不需引物。
- 第二节：原核一种全酶 $\sigma\alpha_2\beta\beta'\omega$；$\sigma$ 认启动子；核心酶延长；$\rho$ 依赖／非依赖终止。
- 第三节：三种核酶；$\mathrm{TF}\,\mathrm{II}\mathrm{D}$／$\mathrm{PIC}$／$\mathrm{CTD}$；帽、$\mathrm{poly}(\mathrm{A})$、两次转酯、可变剪接、编辑、脱腺苷酸化与 $\mathrm{NMD}$。
- 第四节：$45\mathrm{S}$ 剪切；$\mathrm{tRNA}$ 修饰与蛋白质催化内含子；四类内含子；$\mathrm{lncRNA}$ 五类；$\mathrm{siRNA}$／$\mathrm{miRNA}$／$\mathrm{piRNA}$ 核酸酶切割。
:::

:::insight{label="小结写“自剪接不需要蛋白质”，正文加了体内折叠这一句"}
章末按 Cech 体外实验收口。答题若问体内，仍要补：组Ⅰ／组Ⅱ在体内需要蛋白质帮助折叠成二级结构。不要用小结去否定第四节（三）的 in vivo 句。

:::pitfall{label="小结的全酶写法不要丢掉 β′"}

## 思考题

1. 真核生物和原核生物的转录起始、转录延长和转录终止有何不同？
2. 真核细胞 $\mathrm{mRNA}$ 的加工方式有哪些？
3. 真核细胞中不同类型的非编码 $\mathrm{RNA}$ 的转录分别是由哪些 $\mathrm{RNA}$ 聚合酶来完成的？
4. 试述 $\mathrm{RNA}$ 降解在基因表达调控中的作用。
5. $\mathrm{RNA}$ 的生物合成知识在临床医学中有哪些潜在的应用？

:::tip{label="五道思考题在正文里的户头"}
- 起始：原核 $\mathrm{RNA}\,\mathrm{pol}$ 直接结合模板，全酶 $\sigma\alpha_2\beta\beta'\omega$ 以 $\sigma$ 认启动子；真核酶不直接绑 $\mathrm{DNA}$，靠 $\mathrm{TF}\,\mathrm{II}\mathrm{D}$ 的 $\mathrm{TBP}$ 认 $\mathrm{TATA}$（管家基因可无 $\mathrm{TATA}$），装配 $\mathrm{PIC}$， $\mathrm{TF}\,\mathrm{II}\mathrm{H}$ 解旋并磷酸 $\mathrm{CTD}$。延长：化学上 $5'\rightarrow 3'$ 相似；原核可与翻译同步（羽毛状多聚核糖体）；真核有核膜不同步，且遇上核小体（体外移位／体内乙酰化推论一时性解聚）。终止：原核 $\rho$ 依赖或非依赖（茎环、多聚 $\mathrm{U}$，图15-8 在第二节）；真核 $\mathrm{mRNA}$ 在 $\mathrm{AATAAA}$／$\mathrm{GT}$ 修饰点切断加 $\mathrm{poly}(\mathrm{A})$，下游无帽降解，不是在尾巴位点上停住。
- 加工：核内进行。$5'$ 帽（$25\sim 30\,\mathrm{nt}$ 时 $5'$，$5'$-三磷酸连 $7$-甲基 $\mathrm{G}$，加帽酶绑 $\mathrm{CTD}$）；$3'$ 先切后加 $\mathrm{poly}(\mathrm{A})$（组蛋白例外）；剪接（套索、两次转酯、剪接体 $\mathrm{U1}$–$\mathrm{U6}$）；剪切与可变剪接；有些还要编辑（$\mathrm{ApoB}$、$\mathrm{GluR}$）。
- 非编码 $\mathrm{RNA}$ 与酶：$\mathrm{pol}\,\mathrm{I}$：大部分 $\mathrm{rRNA}$ 前体（$45\mathrm{S}\rightarrow 18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}$）。$\mathrm{pol}\,\mathrm{II}$：$\mathrm{lncRNA}$、$\mathrm{miRNA}$、$\mathrm{piRNA}$（表15-2）；多数 $\mathrm{lncRNA}$ 还有帽和尾。$\mathrm{pol}\,\mathrm{III}$：$\mathrm{tRNA}$、$5\mathrm{S}\,\mathrm{rRNA}$、一些 $\mathrm{snRNA}$。植物 $\mathrm{pol}\,\mathrm{IV}$ 合成 $\mathrm{siRNA}$。$\mathrm{siRNA}$／$\mathrm{miRNA}$ 还要 $\mathrm{Dicer}$ 切割，那是加工不是改转录酶。
- 降解即调控：封闭环保护正在翻译的 $\mathrm{mRNA}$；脱腺苷酸化是正常降解主路，尾长与寿命、翻译活性相关；直接脱帽、内切酶、$\mathrm{miRNA}$／$\mathrm{RNAi}$ 也是调控方式。异常：$\mathrm{NMD}$ 清含 $\mathrm{PTC}$ 的转录物，防截短蛋白，许多遗传病与 $\mathrm{PTC}$ 有关；另有 $\mathrm{NSD}$、$\mathrm{NGD}$、$\mathrm{REMD}$。
- 临床潜在应用：错误加工和剪切 → 某些类型地中海贫血；$\mathrm{PTC}$ → 遗传病；$\mathrm{ApoB}$ 编辑区分肝／肠脂蛋白；$\mathrm{GluR}$ 编辑改变 $\mathrm{Ca}^{2+}$ 通透；$\mathrm{siRNA}$ 防御外源核酸／沉默靶基因；$\mathrm{miRNA}$ 调翻译或去尾；端到转录因子、$\mathrm{CTD}$、剪接体，都是潜在干预面。答题用教材已写的机制，不要另编药物名。
:::
