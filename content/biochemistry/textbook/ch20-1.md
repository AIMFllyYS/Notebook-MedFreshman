# 第一节　细胞信号转导概述

第二十章把「细胞之间怎样发信、收信并放大」和「胞外信号怎样在细胞内变成有序分子事件」分成两户。本节只立概述：外源信号主要是化学信号，可溶性和膜结合性两种形式；细胞靠特异性受体接收并转换；多条转导途径交互织成网络。细胞内也可因 $\mathrm{DNA}$ 损伤、活性氧、低氧自行启动转导——这段落在第一节末，不要搬去第二节。信号转导分子的名单交给第二节；细胞内受体迁移、离子通道型受体、$\mathrm{GPCR}$ 和酶偶联受体的完整途径交给第三节。

:::concept{term="先问细胞之间怎样发信收信，再问胞外信号怎样变成胞内有序分子事件"}
看见“细胞信号转导”，先不要默写七次跨膜和三级激酶。户头是：多细胞生物里，细胞间或细胞内高度精确、高效地发送与接收信息，并通过放大机制引起快速生理反应，叫细胞通信；细胞对外来刺激作出反应，经多种分子有序作用把胞外信息传到胞内，并据以调节代谢、增殖、分化、功能活动和凋亡，叫信号转导。通信管「谁发给谁、怎样放大」；转导管「进了细胞之后发生哪些有序化学反应」。分子清单是第二节的账，受体途径是第三节的账。
:::

生物体内各种细胞在功能上的协调统一，是通过细胞间相互识别和相互作用来实现的。在多细胞生物中，细胞间或细胞内高度精确和高效地发送与接收信息，并通过放大机制引起快速的细胞生理反应，这一过程称为细胞通信（cell communication）。细胞对来自外界的刺激或信号发生反应，通过细胞内多种分子相互作用引发一系列有序反应，将细胞外信息传递到细胞内，并据以调节细胞代谢、增殖、分化、功能活动和凋亡的过程称为信号转导（signal transduction）。细胞通信和信号转导过程是高等生物生命活动的基本机制。阐明细胞信号转导机制，对于认识生命活动的本质具有重要的理论意义，同时也为医学的发展带来新的机遇和挑战。

:::definition{label="细胞通信"}
细胞通信（cell communication）：在多细胞生物中，细胞间或细胞内高度精确和高效地发送与接收信息，并通过放大机制引起快速的细胞生理反应。户头落在「发送／接收／放大」，对象可以是细胞与细胞之间，也可以发生在细胞内。
:::

:::definition{label="信号转导"}
信号转导（signal transduction）：细胞对来自外界的刺激或信号发生反应，通过细胞内多种分子相互作用引发一系列有序反应，把细胞外信息传递到细胞内，并据以调节细胞代谢、增殖、分化、功能活动和凋亡。户头落在「胞外信息变成胞内有序分子事件」。
:::

:::compare{title="细胞通信 vs 信号转导"}
| | 问的是什么 | 本版关键词 | 本节后文落点 |
|--|-----------|-----------|-------------|
| 细胞通信 | 谁发给谁、怎样精确高效、怎样放大 | 发送、接收、放大机制、快速生理反应 | 可溶性与膜结合性信号、远距离与接触／孔道 |
| 信号转导 | 进了细胞之后发生哪些有序化学反应 | 多种分子相互作用、有序反应、调节代谢增殖分化功能凋亡 | 受体接收与转换、转导途径与网络 |

两户共用「信号」两个字，第一句就要分开。把通信答成「$\mathrm{cAMP}$ 激活 $\mathrm{PKA}$」，第二节的分子清单就没有前置；把转导答成「内分泌激素走血循环」，受体转换这一户就空了。
:::

:::pitfall{label="不要把通信和转导并成一句话"}
通信强调细胞之间（或细胞内）的发送、接收和放大；转强调把已经接到的胞外信号写成胞内有序事件。并成「细胞通信就是信号转导」，表20-1 的距离分类和图20-1 的膜受体／胞内受体对不上同一套问题。
:::

:::insight{label="凋亡在开篇只是转导的一种可能结局"}
定义里写了「调节……凋亡」。后文会再说：在某些情况下，细胞可在外来信号的诱导下进入程序化死亡。这是转导可以通向凋亡，不是把凋亡整章搬进本节。凋亡通路的分子细节不是本节的账。
:::

:::keypoint{label="开篇两户各管一句"}
- 通信：发送、接收、放大，引起快速生理反应。
- 转导：多种分子有序作用，胞外信息进入胞内，调节代谢、增殖、分化、功能活动和凋亡。
- 两者都是高等生物生命活动的基本机制；阐明机制既有理论意义，也给医学带来机遇和挑战。
:::

细胞信号转导是通过多种分子相互作用的一系列有序反应，将来自细胞外的信息传递到细胞内各种效应分子的过程。通过这一过程，细胞可接收细胞间的接触刺激信号，或所处微环境中的各种化学和物理信号，并将其转变为细胞内各种分子数量、分布或活性的变化，从而改变该细胞的某些代谢过程、生长速度或迁移等生物学行为。在某些情况下，细胞可在外来信号的诱导下进入程序化死亡过程（凋亡）。

:::definition{label="细胞信号转导（节内展开）"}
细胞信号转导：多种分子相互作用的一系列有序反应，把来自细胞外的信息传递到细胞内各种效应分子。输入可以是接触刺激，也可以是微环境中的化学或物理信号；输出是分子数量、分布或活性的变化，从而改变代谢、生长速度或迁移等行为。
:::

:::insight{label="转导的产物先是分子账，再才是细胞行为"}
教材把「转变为细胞内各种分子数量、分布或活性的变化」写在行为改变之前。考试先问数量／分布／活性，再问代谢、生长、迁移。直接答「细胞长得快了」而说不出分子发生了什么，途径和网络都没有落点。
:::

:::pitfall{label="不要把凋亡写成细胞信号转导的必经结局"}
教材用「在某些情况下」和「可在外来信号的诱导下」。转导也可以只改代谢、生长或迁移。写成「接到信号就会凋亡」，后文网络调节、冗余代偿都没有对象。
:::

:::compare{title="本节接收的三类外来输入"}
| 输入 | 教材原句里的位置 | 后面怎么走 |
|------|-----------------|-----------|
| 细胞间的接触刺激 | 节定义第一句 | 膜结合性信号、膜表面分子接触通讯 |
| 微环境中的化学信号 | 节定义；后文「外源信号主要是化学信号」 | 可溶性信号分子，水溶走膜受体、脂溶走胞内受体 |
| 微环境中的物理信号 | 节定义点到；后文承认细胞可以感受物理信号 | 本节不展开具体物理受体，完整途径在第三节 |

化学信号是主账，物理信号不要删掉，也不要在本节编一套光、机械的完整通路。
:::

## 一、细胞外化学信号有可溶性和膜结合性两种形式

细胞可以感受物理信号，但体内细胞所感受的外源信号主要是化学信号。化学信号通信的建立，是生物体为适应环境而不断变异、进化的结果。单细胞生物可直接接收来自外界环境的信息；而多细胞生物中的单个细胞则主要接收来自其他细胞的信号，或所处微环境的信息。最原始的通讯方式是细胞与细胞间通过孔道进行的直接物质交换，或者是通过细胞表面分子相互作用实现信息交流，这种调节方式至今仍然是高等动物细胞分化、个体发育及实现整体功能协调、适应的重要方式之一。但是，相距较远细胞之间的功能协调必须有可以远距离发挥作用的信号。

:::definition{label="外源信号主要是化学信号"}
细胞可以感受物理信号，但体内细胞所感受的外源信号主要是化学信号。化学信号通信是生物体适应环境、不断变异进化的结果。默写「细胞外信号」不要把物理信号删掉，也不要把物理信号写成体内的主账。
:::

:::compare{title="单细胞直接接收 vs 多细胞主要接收其他细胞"}
| | 信息从哪里来 | 本节用来说明什么 |
|--|-------------|-----------------|
| 单细胞生物 | 直接接收外界环境 | 化学信号通信有进化来源 |
| 多细胞生物中的单个细胞 | 主要接收其他细胞的信号，或所处微环境 | 后面才分可溶性、膜结合性，以及远距离与接触 |

不要把多细胞写成「不再感受环境」——微环境信息仍在。
:::

:::definition{label="最原始的两种通讯方式"}
①细胞与细胞间通过孔道进行直接物质交换；②通过细胞表面分子相互作用实现信息交流。这两种方式至今仍是高等动物细胞分化、个体发育及整体功能协调、适应的重要方式之一。
:::

:::keypoint{label="远距离必须另有可以远距离发挥作用的信号"}
孔道和表面分子接触解决的是相邻细胞。相距较远的细胞要功能协调，必须有可远距离发挥作用的信号——后文内分泌信号的「$\mathrm{m}$」量级距离就是为这一句准备的。
:::

:::pitfall{label="不要把孔道交换写成已经被高等动物淘汰"}
教材写「至今仍然是」。把接触通讯答成「只有胚胎或低等生物才用」，黏附因子、$\mathrm{T}$ 淋巴细胞与 $\mathrm{B}$ 淋巴细胞表面分子相互作用就没有户头。
:::

:::insight{label="可溶性与膜结合性是化学信号的两种形式，不是物理对化学"}
本小节标题是「细胞外化学信号有可溶性和膜结合性两种形式」。物理信号在上一段已经承认，但不在这两种形式里。问「化学信号怎么分类」先答可溶／膜结合，再在可溶里拆溶解特性和作用距离。
:::

### （一）可溶性信号分子作为游离分子在细胞间传递

多细胞生物中，细胞可通过分泌化学物质（如蛋白质或小分子有机化合物）而发出信号，这些分子作用于靶细胞表面或细胞内的受体，调节靶细胞的功能，从而实现细胞之间的信息交流。可溶性信号分子可根据其溶解特性分为脂溶性化学信号和水溶性化学信号两大类；而根据其在体内的作用距离，则可分为内分泌信号、旁分泌信号和神经递质三大类（表20-1）。有些旁分泌信号还作用于发出信号的细胞自身，称为自分泌。

:::definition{label="可溶性信号分子"}
可溶性信号分子作为游离分子在细胞间传递。发出信号的细胞分泌化学物质（蛋白质或小分子有机化合物），作用于靶细胞表面或细胞内的受体，调节靶细胞功能。
:::

:::definition{label="溶解特性分成脂溶性和水溶性"}
可溶性信号分子按溶解特性分为脂溶性化学信号和水溶性化学信号。图20-1 把这两类画成两条入胞路径：水溶走膜受体，脂溶走胞内受体。溶解特性这一刀不要和作用距离那一刀并成一句。
:::

:::definition{label="按作用距离分成三类"}
按体内作用距离，可溶性信号分子分为内分泌信号、旁分泌信号和神经递质三大类。表20-1 把神经递质写在「神经分泌信号」这一列下。有些旁分泌信号还作用于发出信号的细胞自身，称为自分泌。
:::

:::definition{label="自分泌"}
自分泌：有些旁分泌信号还作用于发出信号的细胞自身。它不是在内分泌、旁分泌、神经递质之外另开第四大距离类型，而是旁分泌里「回头作用到自己」的一种情形。表20-1 的列名写成「旁分泌及自分泌信号」。
:::

:::pitfall{label="溶解特性和作用距离是两套分类，不要并户"}
脂溶／水溶问的是分子能不能进细胞、受体在膜上还是在胞内；内分泌／旁分泌／神经递质问的是走多远。把「水溶性就是旁分泌」写死，胰岛素（水溶、内分泌、膜受体）和甲状腺激素（可走内分泌、可走胞内受体）都会对不上表20-1。
:::

**表20-1　可溶性信号分子的分类**

| 特征 | 神经分泌信号 | 内分泌信号 | 旁分泌及自分泌信号 |
|------|-------------|-----------|------------------|
| 化学信号 | 神经递质 | 激素 | 细胞因子 |
| 作用距离 | $\mathrm{nm}$ | $\mathrm{m}$ | $\mathrm{mm}$ |
| 受体位置 | 膜受体 | 膜或胞内受体 | 膜受体 |
| 举例 | 乙酰胆碱、谷氨酸 | 胰岛素、甲状腺激素、生长激素 | 表皮生长因子、白细胞介素、神经生长因子 |

:::keypoint{label="读表20-1 先看距离再看受体"}
- 神经分泌：神经递质，距离 $\mathrm{nm}$，膜受体；例：乙酰胆碱、谷氨酸。
- 内分泌：激素，距离 $\mathrm{m}$，膜或胞内受体；例：胰岛素、甲状腺激素、生长激素。
- 旁分泌及自分泌：细胞因子，距离 $\mathrm{mm}$，膜受体；例：表皮生长因子、白细胞介素、神经生长因子。

三列里只有内分泌写了「膜或胞内受体」，因为激素里既有走膜受体的（胰岛素），也有走胞内受体的（甲状腺激素）。
:::

:::compare{title="三类可溶性信号不要只背名字"}
| | 距离数量级 | 受体落在哪 | 化学信号叫什么 |
|--|-----------|-----------|--------------|
| 神经分泌 | $\mathrm{nm}$（突触间隙量级） | 只写膜受体 | 神经递质 |
| 内分泌 | $\mathrm{m}$（可经循环到远隔器官） | 膜或胞内受体 | 激素 |
| 旁分泌及自分泌 | $\mathrm{mm}$（局部微环境） | 只写膜受体 | 细胞因子 |

距离差的是数量级，不是「远一点、近一点」的形容词。把旁分泌写成和内分泌一样走血循环，表里的 $\mathrm{mm}$ 对不上。
:::

:::pitfall{label="内分泌不要写成全部走胞内受体"}
表20-1 内分泌的受体位置是「膜或胞内受体」。胰岛素是膜受体的例子，甲状腺激素才是可以走胞内受体的例子。写成「激素都进细胞核」，水溶性激素分子那一户就没了。
:::

:::pitfall{label="神经递质不要写成也可以走胞内受体"}
神经分泌这一列受体位置只写膜受体。乙酰胆碱、谷氨酸是膜受体配体。把它们答成脂溶性核受体配体，图20-1 的水溶性名单也对不上。
:::

:::insight{label="自分泌挂在旁分泌这一列，不是另造距离"}
表头是「旁分泌及自分泌信号」，化学信号仍是细胞因子，距离仍是 $\mathrm{mm}$，受体仍是膜受体。差别只在靶细胞是不是发出信号的细胞自己。
:::

### （二）膜结合性信号分子需要细胞间接触才能传递信号

每个细胞的质膜外表面都有众多的蛋白质、糖蛋白、蛋白聚糖分子。相邻细胞可通过膜表面分子的特异性识别和相互作用而传递信号。当细胞通过膜表面分子发出信号时，相应的分子即为膜结合性信号分子，而在靶细胞表面存在与之特异性结合的分子，通过这种分子间的相互作用而接收信号，并将信号传入靶细胞内。这种细胞通讯方式称为膜表面分子接触通讯。属于这一类通讯的有相邻细胞间黏附因子的相互作用、$\mathrm{T}$ 淋巴细胞与 $\mathrm{B}$ 淋巴细胞表面分子的相互作用等。

:::definition{label="膜结合性信号分子"}
膜结合性信号分子：细胞通过膜表面分子发出信号时，相应的分子。它不是分泌到细胞间隙里的游离分子，必须靠细胞间接触才能把信号交给靶细胞。
:::

:::definition{label="膜表面分子接触通讯"}
相邻细胞通过膜表面分子的特异性识别和相互作用传递信号：一侧是膜结合性信号分子，对侧靶细胞表面有与之特异结合的分子，相互作用后把信号传入靶细胞内。教材点名的例子：相邻细胞间黏附因子的相互作用，$\mathrm{T}$ 淋巴细胞与 $\mathrm{B}$ 淋巴细胞表面分子的相互作用。
:::

:::compare{title="可溶性信号 vs 膜结合性信号"}
| | 分子在哪 | 要不要细胞接触 | 受体在哪一侧 |
|--|---------|---------------|-------------|
| 可溶性 | 分泌后作为游离分子 | 不要求直接接触；可走 $\mathrm{nm}$、$\mathrm{mm}$ 或 $\mathrm{m}$ | 靶细胞表面或细胞内 |
| 膜结合性 | 仍锚在发出信号的细胞质膜外表面 | 必须接触 | 靶细胞表面与之特异结合的分子 |

可溶性问「分泌了没有」；膜结合性问「两张膜有没有碰上」。
:::

:::pitfall{label="膜结合性信号分子不是脂溶性信号分子"}
「膜结合」说的是分子还长在质膜上，需要接触通讯；「脂溶性」说的是分子能穿过脂双层去找胞内受体。黏附因子是膜结合性、走接触通讯，不是类固醇。两套词不要并户。
:::

:::insight{label="质膜外表面的蛋白质、糖蛋白、蛋白聚糖都可能参与识别"}
教材把三类分子并列写在质膜外表面。接触通讯的结构基础不限于一种蛋白质受体，糖蛋白和蛋白聚糖也在名单里。后文「个别糖脂也具有受体作用」与这里的表面分子清单是同一思路。
:::

:::keypoint{label="化学信号先分在不在膜上，再分水溶脂溶"}
- 可溶性：分泌出来，按溶解特性分水溶／脂溶，按距离分神经分泌／内分泌／旁分泌（及自分泌）。
- 膜结合性：不分泌，靠接触，例子是黏附因子和淋巴细胞表面分子。
- 远距离只能靠可溶性里能走得远的那一类；接触和孔道解决相邻细胞。
:::

## 二、细胞经由特异性受体接收细胞外信号

细胞接收信号时，是通过受体（receptor）将信号导入细胞内。受体通常是细胞膜上或细胞内能特异识别生物活性分子并与之结合，进而引起生物学效应的特殊蛋白质，个别糖脂也具有受体作用。能够与受体特异性结合的分子称为配体（ligand）。可溶性和膜结合性信号分子都是常见的配体。

:::definition{label="受体"}
受体（receptor）：通常是细胞膜上或细胞内能特异识别生物活性分子并与之结合，进而引起生物学效应的特殊蛋白质。个别糖脂也具有受体作用。位置可以在膜上，也可以在细胞内。
:::

:::definition{label="配体"}
配体（ligand）：能够与受体特异性结合的分子。可溶性信号分子和膜结合性信号分子都是常见的配体。配体不一定分泌到体液里，膜上的接触分子也可以当配体。
:::

:::pitfall{label="受体通常是蛋白质，但不要写成「只能是蛋白质」"}
教材先写「特殊蛋白质」，紧接着「个别糖脂也具有受体作用」。把受体定义锁死成「全部是蛋白质」，后一句就没有着落。
:::

:::insight{label="配体这一户同时收可溶性和膜结合性"}
第一节前半刚把化学信号分成可溶和膜结合，这里立刻说两者都是常见配体。受体这一节不是只为激素准备的。
:::

### （一）受体有细胞内受体和膜受体两种类型

按照其在细胞内的位置，受体分为细胞内受体和膜受体（图20-1）。细胞内受体包括位于细胞质或胞核内的受体，其相应配体是脂溶性信号分子，如类固醇激素、甲状腺激素、视黄酸等。水溶性信号分子和膜结合性信号分子（如生长因子、细胞因子、水溶性激素分子、黏附分子等）不能进入靶细胞，其受体位于靶细胞的细胞质膜表面。

:::definition{label="细胞内受体"}
细胞内受体：位于细胞质或胞核内的受体。相应配体是脂溶性信号分子。本节正文点名类固醇激素、甲状腺激素、视黄酸等。
:::

:::definition{label="膜受体"}
膜受体：位于靶细胞细胞质膜表面的受体。水溶性信号分子和膜结合性信号分子不能进入靶细胞，只能走膜受体。正文例子：生长因子、细胞因子、水溶性激素分子、黏附分子等。
:::

:::compare{title="细胞内受体 vs 膜受体"}
| | 位置 | 配体溶解性 | 配体能不能进靶细胞 | 本节正文例子 |
|--|------|-----------|-------------------|-------------|
| 细胞内受体 | 细胞质或胞核 | 脂溶性 | 能进入 | 类固醇激素、甲状腺激素、视黄酸等 |
| 膜受体 | 细胞质膜表面 | 水溶性，或膜结合性 | 不能进入 | 生长因子、细胞因子、水溶性激素分子、黏附分子等 |

先问分子进不进得了细胞，再决定受体在膜上还是在胞内。
:::

::figure{src="/images/biochemistry/textbook/p0414_01.png" caption="图20-1　水溶性和脂溶性化学信号的转导" alt="水溶性化学信号（细胞因子、趋化因子、生物活性肽、氨基酸及其衍生物、核苷和核苷酸）结合膜受体，经细胞内反应通向核内基因表达调控；脂溶性化学信号（类固醇激素、甲状腺激素、前列腺素、维生素A、维生素D、脂类和气体）穿过细胞质膜结合胞内受体，再进入胞核调控基因表达"}

:::insight{label="图20-1 把溶解性画成两条路径"}
水溶性化学信号画在细胞外，箭头指向膜受体，再经「细胞内反应」虚线进核做基因表达调控。脂溶性化学信号画成穿过细胞质膜，直接碰到胞内受体，再进核。看图先认「进不进膜」，不要把两条箭头画成同一条。
:::

:::keypoint{label="图20-1 的两类名单以画面为准"}
- 水溶性化学信号：细胞因子、趋化因子、生物活性肽、氨基酸及其衍生物、核苷和核苷酸。
- 脂溶性化学信号：类固醇激素、甲状腺激素、前列腺素、维生素 $\mathrm{A}$、维生素 $\mathrm{D}$、脂类和气体。

正文另外写了视黄酸（与维生素 $\mathrm{A}$ 同路）以及生长因子、水溶性激素分子、黏附分子（走膜受体）。名单以本版图和句子为准，不要用其他教材的「只有类固醇进核」去删掉维生素 $\mathrm{A}$、维生素 $\mathrm{D}$、脂类和气体。
:::

:::compare{title="正文例子 vs 图20-1 名单"}
| | 正文 | 图20-1 |
|--|------|--------|
| 脂溶、走胞内受体 | 类固醇激素、甲状腺激素、视黄酸等 | 类固醇激素、甲状腺激素、前列腺素、维生素 $\mathrm{A}$、维生素 $\mathrm{D}$、脂类和气体 |
| 水溶或膜结合、走膜受体 | 生长因子、细胞因子、水溶性激素分子、黏附分子等 | 细胞因子、趋化因子、生物活性肽、氨基酸及其衍生物、核苷和核苷酸 |

两套名单互补，不是互相否定。黏附分子是膜结合性，图上没有单独画出「接触」，正文补了这一户。
:::

:::pitfall{label="不要把脂溶性名单缩成「只有类固醇」"}
本版图20-1 明确列出甲状腺激素、前列腺素、维生素 $\mathrm{A}$、维生素 $\mathrm{D}$、脂类和气体。用别的书把前列腺素、气体从胞内受体配体里删掉，就不是本版的图。
:::

:::pitfall{label="水溶性信号不要写成可以自由穿过质膜找核受体"}
教材写「不能进入靶细胞」。膜受体把信号转换之后，下游才在细胞内反应；配体本身不进核。写成「胰岛素进细胞核」，图20-1 上半条路径就反了。
:::

### （二）受体结合配体并转换信号

受体识别并与配体结合，是细胞接收外源信号的第一步反应。受体有两个方面的作用：一是识别外源信号分子并与之结合；二是转换配体信号，使之成为细胞内分子可识别的信号，并传递至其他分子引起细胞应答。

:::definition{label="受体的两个方面作用"}
①识别外源信号分子并与之结合；②转换配体信号，使之成为细胞内分子可识别的信号，并传递至其他分子引起细胞应答。只结合不转换，下游分子看不见这个信号；只谈「激活」不谈识别，专一性那一户就空了。
:::

:::insight{label="结合是第一步，转换才把外源语言译成胞内语言"}
配体是细胞外的化学语言，细胞内的酶、第二信使、调节蛋白质并不直接认识它。受体的工作是把这句外语译成构象变化、定位变化、复合物形成或小分子浓度变化——这些译法的清单在第二节。
:::

#### 1. 细胞内受体能够直接传递信号或通过特定的途径传递信号

有许多细胞内受体是基因表达的调控蛋白质，与进入细胞的信号分子结合后，可以直接传递信号，即直接调控基因表达。另有一些细胞内受体可以结合细胞内产生的信号分子（如细胞应激反应中产生的细胞内信号分子），直接激活效应分子或通过一定的信号转导途径激活效应分子。

:::definition{label="细胞内受体的两种传递方式"}
①许多细胞内受体本身就是基因表达的调控蛋白质，结合进入细胞的信号分子后直接调控基因表达。②另一些细胞内受体结合细胞内产生的信号分子（如应激反应中产生的细胞内信号分子），直接激活效应分子，或通过一定的信号转导途径激活效应分子。
:::

:::compare{title="直接调控基因表达 vs 结合胞内产生的信号"}
| | 配体从哪来 | 受体做什么 |
|--|-----------|-----------|
| 多数胞内受体 | 进入细胞的脂溶性外源信号 | 本身是基因表达调控蛋白质，直接调控表达 |
| 另一部分胞内受体 | 细胞内自己产生的信号（如应激） | 直接激活效应分子，或再走一条转导途径 |

「细胞内受体」不等于「全部都是核转录因子等外源激素」。应激产生的胞内信号也可以走胞内受体。
:::

:::pitfall{label="不要把细胞内受体写成只会等类固醇进来"}
第二句明确写了「结合细胞内产生的信号分子」。$\mathrm{DNA}$ 损伤、活性氧、低氧在本节末还会再出现：细胞内事件可以启动转导。把胞内受体锁成「只有激素核受体」，这两处就接不上。
:::

:::insight{label="直接调控表达是胞内受体的一条捷径，不是唯一路径"}
「直接传递信号，即直接调控基因表达」解释的是许多胞内受体。另一些仍要「通过一定的信号转导途径」。第三节会把激素－受体复合物迁入核、结合激素反应元件写开；本节只立「能直接、也能走途径」。
:::

#### 2. 膜受体识别细胞外信号分子并转换信号

膜受体识别并结合细胞外信号分子，将细胞外信号转换成能够被细胞内分子识别的信号，通过信号转导途径将信号传递至效应分子，引起细胞的应答。

:::definition{label="膜受体转换信号"}
膜受体识别并结合细胞外信号分子，把细胞外信号转换成细胞内分子能够识别的信号，再经信号转导途径传到效应分子，引起细胞应答。配体本身通常不进入细胞，进来的是被转换过的胞内信号。
:::

:::compare{title="细胞内受体 vs 膜受体：转换这一步差在哪"}
| | 配体进不进细胞 | 转换之后立刻能做的事 | 完整途径写在哪 |
|--|---------------|---------------------|--------------|
| 细胞内受体 | 脂溶性配体可进入 | 许多可直接调控基因表达；也可再走途径 | 第三节「细胞内受体通过分子迁移传递信号」 |
| 膜受体 | 配体不进入 | 必须转换成胞内分子可识别的信号，再走途径 | 第三节离子通道型、$\mathrm{GPCR}$、酶偶联受体 |

本节只立「有转换这件事」。离子通道怎样把化学信号变成电信号、三聚体 $\mathrm{G}$ 蛋白怎样循环，都不要提前写进概述。
:::

:::pitfall{label="膜受体转换不是把配体泵进细胞"}
转换的产物是「细胞内分子可识别的信号」，不是把原来的配体分子搬过质膜。生长因子、细胞因子仍在膜外。写成「受体把激素转运进胞质」，和第二信使、蛋白质激酶那些户头就冲突了。
:::

### （三）受体与配体的相互作用具有共同的特点

受体在膜表面和细胞内的分布可以是区域性的，也可以是散在的，其作用都是识别和接收外源信号。受体与配体的相互作用有以下特点。

:::definition{label="受体分布可以区域性也可以散在"}
膜表面和细胞内的受体，分布可以是区域性的，也可以是散在的。无论哪种分布，作用都是识别和接收外源信号。分布方式不是另开一种受体类型。
:::

**1. 高度专一性**　受体选择性地与特定配体结合，这种选择性是由分子的空间构象所决定的。受体与配体的特异性识别和结合保证了调控的准确性。

:::definition{label="高度专一性"}
受体选择性地与特定配体结合，选择性由分子的空间构象决定。特异性识别和结合保证调控的准确性。
:::

**2. 高度亲和力**　体内化学信号的浓度非常低，受体与信号分子的高亲和力保证了很低浓度的信号分子也可充分发挥其调控作用。

:::definition{label="高度亲和力"}
体内化学信号浓度非常低。受体与信号分子的高亲和力，保证很低浓度的信号分子也可充分发挥调控作用。
:::

**3. 可饱和性**　细胞内受体和膜受体的数目都是有限的。增加配体浓度，可使受体与配体的结合达到饱和。当受体全部被配体占据时，再提高配体浓度不会增强效应。

:::definition{label="可饱和性"}
细胞内受体和膜受体的数目都是有限的。增加配体浓度可使结合达到饱和；受体全部被占据后再提高配体浓度，不会增强效应。
:::

**4. 可逆性**　受体与配体以非共价键结合，当生物效应发生后，配体即与受体解离。受体可恢复到原来的状态再次接收配体信息。

:::definition{label="可逆性"}
受体与配体以非共价键结合。生物效应发生后，配体与受体解离，受体恢复原来状态，再次接收配体信息。
:::

**5. 特定的作用模式**　受体的分布和含量具有组织和细胞特异性，并呈现特定的作用模式，受体与配体结合后可引起某种特定的生理效应。

:::definition{label="特定的作用模式"}
受体的分布和含量具有组织和细胞特异性，呈现特定的作用模式。受体与配体结合后引起某种特定的生理效应。不是「任何细胞接同一配体都给同一应答」。
:::

:::keypoint{label="受体–配体五个共同特点"}
- 高度专一性：空间构象决定选择性，保证调控准确。
- 高度亲和力：信号浓度很低也能充分发挥作用。
- 可饱和性：受体数目有限，占满后加配体不再增强效应。
- 可逆性：非共价结合，效应后解离，受体可再用。
- 特定的作用模式：分布和含量有组织、细胞特异性，结合后引起特定生理效应。
:::

:::compare{title="五个特点各自挡住哪一类错觉"}
| 特点 | 若没有它，会误以为 |
|------|-------------------|
| 专一性 | 任何配体都能激活任何受体 |
| 亲和力 | 必须把信号分子堆到很高浓度才有效 |
| 可饱和性 | 配体越多效应越强，没有上限 |
| 可逆性 | 结合是共价的、一次性的，受体用过就废 |
| 特定作用模式 | 全身所有细胞对同一配体给出同一反应 |

五个都要能各用一句话还原，不要只背名词。
:::

:::pitfall{label="可饱和性不是「配体用完了所以饱和」"}
饱和的是受体一侧：数目有限，全部被占据。不是体液里配体分子用尽。把饱和答成「激素分泌停了」，再提高配体浓度不会增强效应这一句就没有对象。
:::

:::pitfall{label="可逆性不要写成共价结合"}
教材写明非共价键。写成二硫键或肽键把配体焊在受体上，受体就不能「恢复到原来的状态再次接收」。
:::

:::insight{label="五个特点对膜受体和细胞内受体都成立"}
可饱和性那一句特意写了「细胞内受体和膜受体的数目都是有限的」。不要把这五条只记成膜受体药理学，核受体同样专一、可饱和、可逆。
:::

## 三、细胞内多条信号转导途径形成信号转导网络

细胞内多种信号转导分子，依次相互识别、相互作用，有序地转换和传递信号。由一组特定信号转导分子形成的有序化学变化并导致细胞行为发生改变的过程称为信号转导途径（signal transduction pathway）。一条途径中的信号转导分子可以与其他途径中的信号转导分子间相互作用，不同的信号转导途径之间具有广泛的交互作用（cross talking），由此形成了复杂的信号转导网络（signal transduction network）（图20-2）。信号转导途径和网络的形成是动态过程，随着信号的种类和强度的变化而不断变化。

:::definition{label="信号转导途径"}
信号转导途径（signal transduction pathway）：由一组特定信号转导分子形成的有序化学变化，并导致细胞行为发生改变的过程。图20-2 的图注把途径写成「信号转导过程信号转导分子的排列方式」。
:::

:::definition{label="交互作用"}
交互作用（cross talking）：一条途径中的信号转导分子可以与其他途径中的信号转导分子相互作用。途径不是互相绝缘的管道。
:::

:::definition{label="信号转导网络"}
信号转导网络（signal transduction network）：不同信号转导途径之间广泛交互作用所形成的复杂网络。图20-2 的图注写成「信号转导通路交叉联系形成的调控系统」。途径和网络都是动态的，随信号种类和强度不断变化。
:::

:::definition{label="信号转导分子（图注）"}
图20-2 把信号转导分子定义为「介导信号在细胞内传递的所有分子」。分子的具体分类——小分子第二信使、酶、调节蛋白质——是第二节的账。本节只承认「有这么一类分子在依次相互识别」。
:::

::figure{src="/images/biochemistry/textbook/p0415_01.png" caption="图20-2　细胞信号转导基本方式示意图" alt="左侧自上而下为信号接收、信号转导、应答反应；细胞内转导后通向代谢变化、蛋白质合成、细胞骨架和核内网络（转录因子、染色质相关蛋白、RNA 加工蛋白、RNA 转运蛋白、细胞周期蛋白）；中央灰色区标明信号转导网络"}

:::insight{label="图20-2 先认「接收→转导→应答」，再认四类出路"}
画面左侧是信号接收、信号转导、应答反应三条。进入细胞之后，出路至少有代谢变化、蛋白质合成、细胞骨架，以及核内那一组（转录因子、染色质相关蛋白、$\mathrm{RNA}$ 加工蛋白、$\mathrm{RNA}$ 转运蛋白、细胞周期蛋白）。中央灰色块才是「信号转导网络」。看图不要一上来默写灰色块里的每一个英文缩写。
:::

:::pitfall{label="不要把图20-2 灰色块里的缩写当成第三节必背级联"}
灰色网络里可以看到 $\mathrm{Ras}$、$\mathrm{Raf}$、$\mathrm{MEK}$、$\mathrm{MAPK}$、$\mathrm{PLC}$、$\mathrm{PKC}$ 等许多名字，那是「交叉联系」的示意。$\mathrm{MAPK}$ 三级激酶的完整途径、以及 $\mathrm{G}$ 蛋白偶联受体怎样把信号交给下游效应分子，以第三节本版句子为准，不要借这张示意图提前展开，也不要用其他教材的口诀替换。
:::

:::compare{title="途径 vs 网络"}
| | 教材的定义 | 和对方的关系 |
|--|-----------|-------------|
| 途径 | 一组特定分子的有序化学变化，导致细胞行为改变 | 网络的构件 |
| 网络 | 不同途径广泛交互作用形成的调控系统 | 途径之间可以 cross talking |
| 动态 | 随信号种类和强度不断变化 | 不是一张固定的电路图 |

问「一条途径」要能说出有序变化和细胞行为；问「网络」要能说出途径之间的交互。
:::

在高等动物体内，细胞外信号分子的作用都具有网络调节特点。如一种细胞因子或激素的作用会受到其他细胞因子或激素的影响，发出信号的细胞又受到其他细胞信号的调节。细胞外信号分子的产生及其调控在另一个层次上形成复杂的网络系统。网络调节使得机体内的细胞因子或激素的作用都具有一定程度的冗余和代偿性，单一缺陷不会导致对机体的严重损害。

:::definition{label="细胞外信号也有网络调节"}
一种细胞因子或激素的作用会受到其他细胞因子或激素的影响；发出信号的细胞又受到其他细胞信号的调节。细胞外信号分子的产生及其调控，在另一个层次上形成复杂网络。这和细胞内途径的 cross talking 是两层，不要并成一句。
:::

:::insight{label="冗余和代偿解释「单一缺陷不一定造成严重损害」"}
网络调节使细胞因子或激素的作用具有一定程度的冗余和代偿性，所以单一缺陷不会导致对机体的严重损害。这是概述里对「为什么机体内信号如此交叉」的功能解释，不是说缺陷都无害。
:::

:::pitfall{label="不要把「单一缺陷不会严重损害」写成「信号分子都可以随便缺」"}
教材给的是「一定程度的」冗余和代偿。后文疾病相关的转导异常仍可以致病。这句话解释的是网络为什么交叉，不是给所有突变开脱。
:::

:::cause-effect{title="网络调节怎样接到「单一缺陷」"}
- **因** 一种因子的作用受其他因子影响，发出信号的细胞又被其他信号调节，细胞外和细胞内都是网络
- **果** 作用具有一定程度的冗余和代偿，单一缺陷常常可以被旁路分担，因而不一定造成对机体的严重损害
:::

一些特殊的细胞内事件也可以在细胞内启动信号转导途径。如 $\mathrm{DNA}$ 损伤、活性氧（$\mathrm{ROS}$）、低氧状态等，可通过激活特定的分子而启动信号转导。这些途径可以与细胞外信号分子共用部分转导途径、共用一些信号分子，也可以是一些特殊的途径（如凋亡信号转导途径）。

:::definition{label="细胞内事件也可以启动转导"}
$\mathrm{DNA}$ 损伤、活性氧（$\mathrm{ROS}$）、低氧状态等特殊的细胞内事件，可通过激活特定的分子而启动信号转导。起点不必是细胞外配体。
:::

:::compare{title="胞外配体启动 vs 胞内事件启动"}
| | 起点 | 和已有途径的关系 | 教材点名 |
|--|------|-----------------|----------|
| 胞外信号 | 配体结合受体 | 走膜受体或胞内受体，再进入途径／网络 | 本节前两小节 |
| 胞内事件 | $\mathrm{DNA}$ 损伤、$\mathrm{ROS}$、低氧等 | 可与胞外信号共用部分途径或分子，也可以是特殊途径（如凋亡信号转导途径） | 本节末句 |

共用还是特殊，都仍叫信号转导。不要把「没有外来配体」理解成「没有转导」。
:::

:::pitfall{label="DNA 损伤、ROS、低氧这段不要复制进第二节"}
这段话在教材里属于第一节「信号转导网络」的收尾。dump 时容易掉到第二节文首。分子清单从「信号转导分子」三分类开始，不要把这段再写一遍。
:::

:::pitfall{label="不要把凋亡整章搬进概述"}
教材只说「也可以是一些特殊的途径（如凋亡信号转导途径）」。凋亡可以作为转导的一种特殊途径被点名，分子机制、半胱天冬酶级联不是本节的账。
:::

:::keypoint{label="网络这一小节要带走的四句话"}
- 途径：一组特定分子的有序化学变化，改变细胞行为。
- 网络：途径之间广泛 cross talking，并且是动态的。
- 细胞外信号的产生和调控另有一层网络，带来一定程度的冗余和代偿。
- $\mathrm{DNA}$ 损伤、$\mathrm{ROS}$、低氧等细胞内事件也可以启动转导，可与胞外信号共用分子，也可以走特殊途径。
:::

:::memory{label="本节必背要点"}
- 细胞通信：精确高效地发送与接收信息，并通过放大引起快速生理反应。
- 信号转导：多种分子有序作用，把胞外信息传到胞内，调节代谢、增殖、分化、功能活动和凋亡。
- 外源信号主要是化学信号，也可以感受物理信号。化学信号分可溶性和膜结合性。
- 可溶性按溶解性分水溶／脂溶，按距离分神经分泌（$\mathrm{nm}$、膜受体）、内分泌（$\mathrm{m}$、膜或胞内受体）、旁分泌及自分泌（$\mathrm{mm}$、膜受体）。
- 膜结合性必须接触；例子是黏附因子、$\mathrm{T}$ 与 $\mathrm{B}$ 淋巴细胞表面分子。
- 受体通常是蛋白质，个别糖脂也有受体作用。配体包括可溶性和膜结合性信号分子。
- 水溶性和膜结合性走膜受体；脂溶性（类固醇激素、甲状腺激素、视黄酸；图20-1 还有前列腺素、维生素 $\mathrm{A}$、维生素 $\mathrm{D}$、脂类和气体）走胞内受体。
- 受体两件事：识别结合，以及转换成胞内分子可识别的信号。五个共同特点：专一、高亲和、可饱和、可逆、特定作用模式。
- 途径织成网络，动态变化；胞外信号也有网络，有冗余和代偿。$\mathrm{DNA}$ 损伤、$\mathrm{ROS}$、低氧可在细胞内启动转导。
:::
