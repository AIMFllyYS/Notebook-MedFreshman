# 第五节　细胞信号转导异常与疾病

前四节把通信与转导、分子清单、受体途径和基本规律立完。本节只立异常怎样发生、怎样致病、为什么转导分子能当药物靶位。异常原因以本版名单为准：基因突变、细菌毒素、自身抗体和应激。层次只有两层：受体功能异常，细胞内信号转导分子功能异常。疾病例子用教材原名，不自行替换诊断。

:::concept{term="先问异常发生在受体还是细胞内分子，再问细胞因此得到什么或失去什么"}
看见“细胞信号转导异常与疾病”，先不要默写药物商品名。户头是：信号转导机制研究在医学上的意义，一是深入认识发病机制，二是为诊断提供新标记物、为治疗提供新靶位。目前认识还相对有限。引起异常的原因多种多样，基因突变、细菌毒素、自身抗体和应激均可导致。异常可局限于单一途径，亦可同时或先后累及多条途径，造成网络失衡。机制虽复杂，基本上从两个层次来认识：受体功能异常，和细胞内信号转导分子的功能异常。
:::

信号转导机制研究在医学发展中的意义主要体现在两个方面，一是对发病机制的深入认识，二是为疾病诊断提供新的标记物和治疗提供新靶位。目前，人们对信号转导机制及信号转导异常与疾病关系的认识还相对有限，该领域研究的不断深入将为新的诊断和治疗技术提供更多的依据。

:::definition{label="转导研究的两方面医学意义"}
①深入认识发病机制；②为诊断提供新的标记物，为治疗提供新靶位。认识还相对有限，不要把本节写成已经穷尽所有疾病。
:::

:::insight{label="网络失衡可以是一条途径，也可以是多条"}
异常可以局限于单一途径，亦可同时或先后累及多条，造成信号转导网络失衡。第四节刚写完途径交叉，这里立刻说交叉也可以一起坏。
:::

## 一、信号转导异常可发生在两个层次

引起细胞信号转导异常的原因是多种多样的，基因突变、细菌毒素、自身抗体和应激等均可导致细胞信号转导的异常。细胞信号转导异常可以局限于单一途径，亦可同时或先后累及多条信号转导途径，造成信号转导网络失衡。细胞信号转导异常的原因和机制虽然很复杂，但基本上可从两个层次来认识，即受体功能异常和细胞内信号转导分子的功能异常。

:::definition{label="本版点名的异常原因"}
基因突变、细菌毒素、自身抗体和应激等。名单以这一句为准，不要自行增删成其他教科书的分类。
:::

:::definition{label="两个层次"}
①受体功能异常；②细胞内信号转导分子的功能异常。先问坏在膜上／核内的受体，还是坏在受体之后的分子。
:::

:::compare{title="原因 vs 层次不要并户"}
| | 问的是什么 | 本版例子后文会落到 |
|--|-----------|------------------|
| 原因 | 谁把它弄坏的 | 突变、毒素、自身抗体、应激 |
| 层次 | 坏在哪一层分子 | 受体，或细胞内转导分子 |

自身抗体可以弄坏受体（$\mathrm{TSH}$ 受体刺激性／阻断性抗体）；基因突变可以弄坏受体（胰岛素受体、$ERB$-$B$），也可以弄坏细胞内分子（$\mathrm{G}\alpha$、$RAS$、$\mathrm{PI3K}$ 的 $\mathrm{p85}$）。原因和层次是两把尺子。
:::

:::pitfall{label="不要把应激写成必须另开第三层次"}
原因名单里有应激；层次仍只有受体和细胞内分子两层。应激通过哪一层起作用，教材没有在本节另立专条，不要编一套完整应激通路。
:::

### （一）受体存在异常激活和失能

#### 1. 受体异常激活

在正常情况下，受体只有在结合外源信号分子后才能激活，并向细胞内传递信号。但基因突变可导致异常受体的产生，不依赖外源信号的存在而激活细胞内的信号途径。如 $\mathrm{EGF}$ 受体只有在结合 $\mathrm{EGF}$ 后才能激活 $\mathrm{MAPK}$ 途径，但 $ERB$-$B$ 癌基因表达的变异型 $\mathrm{EGF}$ 受体则不同，该受体缺乏与配体结合的胞外区，而其胞内区则处于活性状态，因而可持续激活 $\mathrm{MAPK}$ 途径。

在某些条件下，受体编码基因可因某些因素的调控作用而过度表达，使细胞表面呈现远远多于正常细胞的受体数量。在这种情况下，外源信号所诱导的细胞内信号转导途径的激活水平会远远高于正常细胞，使靶细胞对外源信号的刺激反应过度。

外源信号异常也可导致受体的异常激活。如自身免疫性甲状腺病中，患者产生针对促甲状腺激素（thyroid-stimulating hormone，$\mathrm{TSH}$）受体的抗体。$\mathrm{TSH}$ 受体抗体分为两种，其中一种是刺激性抗体，与 $\mathrm{TSH}$ 受体结合后能模拟 $\mathrm{TSH}$ 的作用，在没有 $\mathrm{TSH}$ 存在时也可以激活 $\mathrm{TSH}$ 受体。

:::definition{label="受体异常激活"}
正常时受体只有结合外源信号分子后才能激活。异常激活：不依赖外源信号，或对信号反应过度。本版写了三条路：突变产生异常受体、受体数量过多、外源信号异常（自身抗体模拟配体）。
:::

:::definition{label="ERB-B 变异型 EGF 受体"}
$ERB$-$B$ 癌基因表达的变异型 $\mathrm{EGF}$ 受体：缺乏与配体结合的胞外区，胞内区处于活性状态，因而可持续激活 $\mathrm{MAPK}$ 途径。不依赖 $\mathrm{EGF}$ 存在。
:::

:::definition{label="受体过度表达"}
受体编码基因过度表达，细胞表面受体数量远远多于正常。外源信号诱导的途径激活水平远高于正常，靶细胞反应过度。这一条仍然需要外源信号，只是受体太多。
:::

:::definition{label="TSH 受体刺激性抗体"}
自身免疫性甲状腺病中，针对 $\mathrm{TSH}$ 受体的抗体分两种。刺激性抗体：与 $\mathrm{TSH}$ 受体结合后能模拟 $\mathrm{TSH}$ 的作用，在没有 $\mathrm{TSH}$ 存在时也可以激活 $\mathrm{TSH}$ 受体。疾病名称以教材「自身免疫性甲状腺病」为准。
:::

:::compare{title="受体异常激活的三条路"}
| 路 | 还要不要外源配体 | 本版例子 |
|--|----------------|---------|
| 突变产生异常受体 | 不要 | $ERB$-$B$：无胞外配体结合区，胞内区已活化，持续开 $\mathrm{MAPK}$ |
| 受体数量过多 | 要，但反应过度 | 基因过度表达，表面受体远多于正常 |
| 外源信号异常 | 配体被抗体替代 | $\mathrm{TSH}$ 受体刺激性抗体模拟 $\mathrm{TSH}$ |

「不依赖外源信号」只准确描述第一条和刺激性抗体；数量过多那一条仍然依赖外源信号。
:::

:::pitfall{label="ERB-B 不要写成配体结合得更紧"}
变异型缺乏胞外区，不是亲和力升高。持续激活是因为胞内区已经处于活性状态。写成「对 $\mathrm{EGF}$ 更敏感」，就把「不依赖外源信号」删掉了。
:::

:::pitfall{label="刺激性抗体的病名不要自行替换"}
教材在激活这一条写的是自身免疫性甲状腺病和刺激性抗体模拟 $\mathrm{TSH}$。不要改成其他诊断名再倒填机制。阻断性抗体在下一小节，不要和刺激性抗体并成一种。
:::

:::insight{label="刺激性抗体是「外源信号异常」不是受体基因突变"}
坏的是出现了模拟 $\mathrm{TSH}$ 的抗体，受体本身按教材这一句并没有被写成突变。原因落在自身抗体，层次落在受体被异常激活。
:::

#### 2. 受体异常失活

受体分子数量、结构或调节功能发生异常变化时，可导致受体异常失能，不能正常传递信号。如基因突变可导致遗传性胰岛素受体异常，包括：①受体合成减少或结构异常的受体在细胞内分解加速导致受体数量减少；②受体与配体的亲和力降低，如 $735$ 位精氨酸突变为丝氨酸可导致受体与胰岛素亲和力下降；③$\mathrm{RTK}$ 活性降低，如 $1\,008$ 位甘氨酸突变为缬氨酸可致胞内区 $\mathrm{PTK}$ 结构域异常，从而使之磷酸化酪氨酸残基的能力减弱。在这些情况下，受体均不能正常传递胰岛素的信号。

自身免疫性疾病中产生的自身抗体，也可能导致特定受体失活。如前述自身免疫性甲状腺病中产生的 $\mathrm{TSH}$ 受体的两种抗体中，有一种是阻断性抗体。这种抗体与 $\mathrm{TSH}$ 受体结合后，可抑制受体与 $\mathrm{TSH}$ 结合，从而减弱或抑制受体的激活，不能传递 $\mathrm{TSH}$ 的信号。

:::definition{label="受体异常失活"}
受体分子数量、结构或调节功能异常，导致受体异常失能，不能正常传递信号。
:::

:::definition{label="遗传性胰岛素受体异常三型"}
①数量减少：合成减少，或结构异常的受体在细胞内分解加速。②亲和力降低：$735$ 位精氨酸突变为丝氨酸，与胰岛素亲和力下降。③$\mathrm{RTK}$ 活性降低：$1\,008$ 位甘氨酸突变为缬氨酸，胞内区 $\mathrm{PTK}$ 结构域异常，磷酸化酪氨酸残基的能力减弱。三型都不能正常传递胰岛素信号。
:::

:::definition{label="TSH 受体阻断性抗体"}
与 $\mathrm{TSH}$ 受体结合后，抑制受体与 $\mathrm{TSH}$ 结合，减弱或抑制受体激活，不能传递 $\mathrm{TSH}$ 的信号。和刺激性抗体同属自身免疫性甲状腺病中的两种抗体，作用相反。
:::

:::compare{title="胰岛素受体三型失活不要并成一句「受体少了」"}
| | 坏在哪 | 本版点名的突变 |
|--|--------|--------------|
| 数量减少 | 合成减少或分解加速 | 未点名具体残基 |
| 亲和力下降 | 与配体结合这一步 | $735$ 位 $\mathrm{Arg}$→$\mathrm{Ser}$ |
| 激酶活性下降 | 胞内 $\mathrm{PTK}$ 结构域 | $1\,008$ 位 $\mathrm{Gly}$→$\mathrm{Val}$ |

数量、结合、催化三步都可以单独坏。写成只有数量减少，后两型就没有户头。
:::

:::compare{title="TSH 受体两种抗体"}
| | 结合之后做什么 | 层次上的结果 |
|--|--------------|------------|
| 刺激性抗体 | 模拟 $\mathrm{TSH}$，无 $\mathrm{TSH}$ 也能激活受体 | 受体异常激活 |
| 阻断性抗体 | 抑制受体与 $\mathrm{TSH}$ 结合，减弱或抑制激活 | 受体异常失活 |

后文疾病表型：阻断性抗体可抑制甲状腺素分泌，导致甲状腺功能减退。刺激性抗体不要自行改写诊断名。
:::

:::pitfall{label="735 和 1008 不要对调"}
$735$ 位是亲和力；$1\,008$ 位是 $\mathrm{PTK}$ 结构域。对调之后，「结合」和「磷酸化」两步就考反了。
:::

:::pitfall{label="阻断性抗体不是把受体从膜上拆掉"}
机制是抑制受体与 $\mathrm{TSH}$ 结合。不要写成受体数量变成零，也不要写成刺激性抗体的反向突变。
:::

### （二）信号转导分子存在异常激活和失活

细胞内信号转导分子可因各种原因而发生功能的改变。如果其功能异常激活，可持续向下游传递信号，而不依赖外源信号及上游信号转导分子的激活。如果信号转导分子失活，则导致信号传递的中断，使细胞失去对外源信号的反应性。

:::definition{label="转导分子异常激活"}
结构改变可导致其激活并维持在活性状态，持续向下游传递信号，不依赖外源信号及上游分子的激活。坏在受体之后。
:::

:::definition{label="转导分子异常失活"}
表达降低或结构改变导致失活，信号传递中断，细胞失去对外源信号的反应性。
:::

:::compare{title="受体层次 vs 细胞内分子层次"}
| | 坏的是谁 | 激活时还要不要配体／上游 |
|--|---------|------------------------|
| 受体异常激活 | 受体本身（突变、过多、被抗体模拟） | 突变体／刺激性抗体可不依赖配体；过度表达仍依赖配体 |
| 分子异常激活 | $\mathrm{G}\alpha$、$\mathrm{Ras}$ 等 | 不依赖外源信号及上游分子 |
| 受体异常失活 | 受体数量／亲和力／激酶 | 配体来了也传不下去 |
| 分子异常失活 | $\mathrm{PI3K}$ 的 $\mathrm{p85}$、截短 $\mathrm{G}\alpha$ 等 | 受体可以还在，下游中断 |

问「霍乱毒素坏的是哪一层」，答细胞内 $\mathrm{G}$ 蛋白的 $\alpha$ 亚基，不是 $\mathrm{GPCR}$ 本身。
:::

#### 1. 细胞内信号转导分子异常激活

细胞内信号转导分子的结构发生改变，可导致其激活并维持在活性状态。如三聚体 $\mathrm{G}$ 蛋白的 $\alpha$ 亚基可因基因突变而发生功能改变。当 $\alpha$ 亚基的 $201$ 位精氨酸被半胱氨酸或组氨酸所取代，或 $227$ 位谷氨酰胺被精氨酸取代时，可致 $\alpha$ 亚基失去 $\mathrm{GTP}$ 酶活性，使 $\alpha$ 亚基处于持续激活状态，因而持续向下游传递信号。此外，霍乱毒素的 $\mathrm{A}$ 亚基进入小肠上皮细胞后，可直接结合 $\mathrm{G}$ 蛋白的 $\alpha$ 亚基，使其发生 $\mathrm{ADP}$-核糖化修饰，抑制其 $\mathrm{GTP}$ 酶活性，导致 $\alpha$ 亚基持续激活。

小分子 $\mathrm{G}$ 蛋白 $\mathrm{Ras}$ 也可因基因突变而导致其异常激活。$\mathrm{Ras}$ 的 $12$ 位或 $13$ 位甘氨酸、$61$ 位谷氨酰胺被其他氨基酸取代时，均可导致 $\mathrm{Ras}$ 的 $\mathrm{GTP}$ 酶活性降低，使其处于持续活化状态。

:::definition{label="Gα 失去 GTP 酶"}
$201$ 位精氨酸被半胱氨酸或组氨酸取代，或 $227$ 位谷氨酰胺被精氨酸取代 → $\alpha$ 亚基失去 $\mathrm{GTP}$ 酶活性 → 持续激活，持续向下游传递信号。
:::

:::definition{label="霍乱毒素 A 亚基"}
进入小肠上皮细胞后，直接结合 $\mathrm{G}$ 蛋白的 $\alpha$ 亚基，使其发生 $\mathrm{ADP}$-核糖化修饰，抑制其 $\mathrm{GTP}$ 酶活性，导致 $\alpha$ 亚基持续激活。原因是细菌毒素，层次是细胞内转导分子。
:::

:::definition{label="Ras 突变降低 GTP 酶"}
$12$ 位或 $13$ 位甘氨酸、$61$ 位谷氨酰胺被其他氨基酸取代 → $\mathrm{GTP}$ 酶活性降低 → $\mathrm{Ras}$ 持续活化。后文接到 $\mathrm{MAPK}$ 持续激活、肿瘤细胞持续增殖。
:::

:::keypoint{label="关掉 GTP 酶等于关不上开关"}
第三节 $\mathrm{G}$ 蛋白循环：水解 $\mathrm{GTP}$ 才能回到 $\mathrm{GDP}$ 三聚体。第二节：$\mathrm{Ras}$-$\mathrm{GTP}$ 才启动 $\mathrm{MAPK}$。$\mathrm{G}\alpha$ 和 $\mathrm{Ras}$ 的本版突变点都落在「$\mathrm{GTP}$ 酶活性降低或丧失」，所以持续活化。霍乱毒素用 $\mathrm{ADP}$-核糖化达到同一效果。
:::

:::compare{title="Gα 突变 vs 霍乱毒素 vs Ras 突变"}
| | 原因 | 分子 | 怎样关不上 |
|--|------|------|-----------|
| $\mathrm{G}\alpha$ 点突变 | 基因突变 | 三聚体 $\mathrm{G}$ 蛋白 $\alpha$ 亚基 | $201$ 位 $\mathrm{Arg}$→$\mathrm{Cys}$／$\mathrm{His}$，或 $227$ 位 $\mathrm{Gln}$→$\mathrm{Arg}$，失去 $\mathrm{GTP}$ 酶 |
| 霍乱毒素 | 细菌毒素 | 小肠上皮 $\mathrm{G}\alpha$ | $\mathrm{A}$ 亚基使其 $\mathrm{ADP}$-核糖化，抑制 $\mathrm{GTP}$ 酶 |
| $\mathrm{Ras}$ | 基因突变 | 低分子量 $\mathrm{G}$ 蛋白 | $12$／$13$ 位 $\mathrm{Gly}$ 或 $61$ 位 $\mathrm{Gln}$ 被取代，$\mathrm{GTP}$ 酶降低 |

机制同类（关不掉），原因和分子不要混。
:::

:::pitfall{label="201、227 不要写成 Ras 的 12、13、61"}
三聚体 $\mathrm{G}\alpha$ 的残基是 $201$、$227$；$\mathrm{Ras}$ 是 $12$、$13$、$61$。对调就是把两类 $\mathrm{G}$ 蛋白并户。
:::

:::pitfall{label="霍乱毒素不要写成作用于 GPCR 的配体结合部位"}
$\mathrm{A}$ 亚基直接结合 $\mathrm{G}$ 蛋白的 $\alpha$ 亚基做 $\mathrm{ADP}$-核糖化。层次在细胞内分子，不在受体。
:::

#### 2. 细胞内信号转导分子异常失活

细胞内信号转导分子表达降低或结构改变，可导致其失活。胰岛素受体介导的信号转导途径中包括 $\mathrm{PI3K}$ 途径。基因突变可导致 $\mathrm{PI3K}$ 的 $\mathrm{p85}$ 亚基表达下调或结构改变，使 $\mathrm{PI3K}$ 不能正常激活或不能达到正常激活水平，因而不能正常传递胰岛素信号。

在遗传性假性甲状旁腺素低下疾病中，甲状旁腺素信号途径中 $\mathrm{G}$ 蛋白的 $\alpha$ 亚基基因的起始密码子突变为 $\mathrm{GTG}$，使得核糖体只能利用第二个 $\mathrm{ATG}$（第 $60$ 位密码子）起始翻译，产生 $\mathrm{N}$ 端缺失了 $59$ 个氨基酸残基的异常 $\alpha$ 亚基，从而使 $\mathrm{G}$ 蛋白不能向下游传递信号。

:::definition{label="PI3K 的 p85 异常"}
胰岛素途径中包括 $\mathrm{PI3K}$ 途径。$\mathrm{p85}$ 亚基表达下调或结构改变，使 $\mathrm{PI3K}$ 不能正常激活或达不到正常激活水平，不能正常传递胰岛素信号。这是细胞内分子失活，不是胰岛素受体本身那三型。
:::

:::definition{label="遗传性假性甲状旁腺素低下"}
甲状旁腺素信号途径中 $\mathrm{G}\alpha$ 基因起始密码子突变为 $\mathrm{GTG}$，核糖体只能用第二个 $\mathrm{ATG}$（第 $60$ 位密码子）起始翻译，产生 $\mathrm{N}$ 端缺失 $59$ 个氨基酸残基的异常 $\alpha$ 亚基，$\mathrm{G}$ 蛋白不能向下游传递信号。
:::

:::compare{title="胰岛素信号可以坏在受体，也可以坏在 PI3K"}
| 层次 | 本版例子 | 结果 |
|------|---------|------|
| 受体 | 遗传性胰岛素受体异常三型 | 受体不能正常传递胰岛素信号 |
| 细胞内分子 | $\mathrm{PI3K}$ 的 $\mathrm{p85}$ 下调或结构改变 | $\mathrm{PI3K}$ 激活不足，不能正常传递胰岛素信号 |

后文「失去正常的生理调节能力」还会把受体异常接到血糖升高。两层都可以让胰岛素信号中断，不要只记受体。
:::

:::insight{label="同一 Gα，激活是 GTP 酶关不上，失活是 N 端缺一截"}
$201$／$227$ 突变：持续激活。起始密码子突变：从第 $60$ 位才开始翻译，缺 $\mathrm{N}$ 端 $59$ 个残基，不能向下游传递。都是 $\alpha$ 亚基，方向相反。
:::

:::pitfall{label="起始密码子 ATG→GTG 不要答成 GTP 酶位点突变"}
假性甲状旁腺素低下这一例，坏的是翻译起点，产物缺 $\mathrm{N}$ 端。不要拿 $201$ 位精氨酸那一套来答。
:::

## 二、信号转导异常可导致疾病的发生

异常的信号转导可使细胞获得异常功能或者失去正常功能，从而导致疾病的发生，或影响疾病的过程。许多疾病的发生和发展都与信号转导异常有关。本节主要通过一些具体的例子说明较典型的信号转导异常与疾病的关系。

:::definition{label="异常转导的两种细胞结局"}
①细胞获得异常功能或表型；②细胞失去正常功能。都可以导致疾病发生，或影响疾病过程。
:::

:::compare{title="上一小节 vs 这一小节"}
| | 问什么 | 例子怎么用 |
|--|--------|-----------|
| 一、两个层次 | 坏在受体还是细胞内分子，激活还是失活 | 机制分类 |
| 二、导致疾病 | 细胞因此得到什么或失去什么 | 同一机制可以拿到疾病表型里再写一次 |

霍乱毒素在「分子异常激活」里出现一次，在「细胞膜通透性改变」里再落到腹泻。不是两件不相关的事。
:::

### （一）信号转导异常导致细胞获得异常功能或表型

#### 1. 细胞获得异常的增殖能力

正常细胞的增殖在体内受到严格控制。机体通过生长因子调控细胞的增殖能力。当 $ERB$-$B$ 癌基因异常表达时，细胞不依赖 $\mathrm{EGF}$ 的存在而持续产生活化信号，从而使细胞获得持续增殖的能力。$\mathrm{MAPK}$ 途径是调控细胞增殖的重要信号转导途径，$RAS$ 基因突变时，使 $\mathrm{Ras}$ 蛋白处于持续激活状态，因而使 $\mathrm{MAPK}$ 途径持续激活，这是肿瘤细胞持续增殖的重要机制之一。

:::definition{label="异常增殖的两条本版机制"}
①$ERB$-$B$ 异常表达：不依赖 $\mathrm{EGF}$ 持续产生活化信号，细胞获得持续增殖能力。②$RAS$ 突变：$\mathrm{Ras}$ 持续激活 → $\mathrm{MAPK}$ 途径持续激活 → 肿瘤细胞持续增殖的重要机制之一。
:::

:::cause-effect{title="Ras 关不上怎样接到肿瘤增殖"}
- **因** $RAS$ 突变使 $\mathrm{GTP}$ 酶降低，$\mathrm{Ras}$ 处于持续活化状态，$\mathrm{MAPK}$ 途径持续激活
- **果** 增殖信号关不掉，成为肿瘤细胞持续增殖的重要机制之一
:::

:::pitfall{label="两条增殖机制层次不同"}
$ERB$-$B$ 坏在受体；$RAS$ 坏在细胞内分子。都接到 $\mathrm{MAPK}$ 和增殖，不要并成「都是受体突变」。
:::

#### 2. 细胞的分泌功能异常

生长激素（growth hormone，$\mathrm{GH}$）的功能是促进机体生长。$\mathrm{GH}$ 的分泌受下丘脑 $\mathrm{GH}$ 释放激素和生长抑素的调节，$\mathrm{GH}$ 释放激素通过激活 $\mathrm{G}$ 蛋白、促进 $\mathrm{cAMP}$ 水平升高而促进分泌 $\mathrm{GH}$ 的细胞增殖和分泌功能；生长抑素则通过降低 $\mathrm{cAMP}$ 水平抑制 $\mathrm{GH}$ 分泌。当 $\alpha$ 亚基由于突变而失去 $\mathrm{GTP}$ 酶活性时，$\mathrm{G}$ 蛋白处于异常的激活状态，垂体细胞分泌功能活跃。$\mathrm{GH}$ 的过度分泌，可刺激骨骼过度生长，在成人引起肢端肥大症，在儿童引起巨人症。

:::definition{label="GH 分泌的正常双向调节"}
$\mathrm{GH}$ 释放激素：激活 $\mathrm{G}$ 蛋白，升 $\mathrm{cAMP}$，促进分泌 $\mathrm{GH}$ 的细胞增殖和分泌。生长抑素：降低 $\mathrm{cAMP}$，抑制 $\mathrm{GH}$ 分泌。
:::

:::definition{label="Gα 持续激活导致肢端肥大症或巨人症"}
$\alpha$ 亚基突变失去 $\mathrm{GTP}$ 酶 → $\mathrm{G}$ 蛋白异常激活 → 垂体细胞分泌活跃 → $\mathrm{GH}$ 过度分泌 → 骨骼过度生长。成人：肢端肥大症。儿童：巨人症。同一机制，结局按发病年龄分。
:::

:::insight{label="201／227 突变在这里落到垂体"}
上一小节把 $\mathrm{G}\alpha$ 失去 $\mathrm{GTP}$ 酶写成分子机制；这里把同一类突变接到 $\mathrm{GH}$ 过度分泌。不要另编一套「生长激素受体突变」来替换教材的 $\alpha$ 亚基。
:::

:::pitfall{label="肢端肥大症和巨人症不要对调年龄"}
成人 → 肢端肥大症；儿童 → 巨人症。机制都是 $\mathrm{GH}$ 过度分泌。
:::

#### 3. 细胞膜通透性改变

霍乱毒素的 $\mathrm{A}$ 亚基使 $\mathrm{G}$ 蛋白处于持续激活状态，持续激活 $\mathrm{PKA}$。$\mathrm{PKA}$ 通过将小肠上皮细胞膜上的蛋白质磷酸化而改变细胞膜的通透性，$\mathrm{Na}^{+}$ 通道和氯离子通道持续开放，造成水与电解质的大量丢失，引起腹泻和水电解质紊乱等症状。

:::definition{label="霍乱毒素怎样接到腹泻"}
$\mathrm{A}$ 亚基使 $\mathrm{G}$ 蛋白持续激活 → 持续激活 $\mathrm{PKA}$ → 磷酸化小肠上皮细胞膜蛋白质 → $\mathrm{Na}^{+}$ 通道和氯离子通道持续开放 → 水与电解质大量丢失 → 腹泻和水电解质紊乱。
:::

:::cause-effect{title="GTP 酶被抑制怎样变成腹泻"}
- **因** $\mathrm{ADP}$-核糖化抑制 $\mathrm{G}\alpha$ 的 $\mathrm{GTP}$ 酶，$\mathrm{PKA}$ 持续开，$\mathrm{Na}^{+}$、氯离子通道持续开放
- **果** 水与电解质大量丢失，出现腹泻和水电解质紊乱
:::

:::keypoint{label="获得异常功能三例不要记串层次"}
- 增殖：$ERB$-$B$（受体）或 $RAS$（分子）→ $\mathrm{MAPK}$。
- 分泌：$\mathrm{G}\alpha$ 失去 $\mathrm{GTP}$ 酶 → $\mathrm{GH}$ 过多 → 肢端肥大症／巨人症。
- 通透性：霍乱毒素 → $\mathrm{G}\alpha$／$\mathrm{PKA}$ → 肠上皮离子通道。
:::

### （二）信号转导异常导致细胞正常功能缺失

#### 1. 失去正常的分泌功能

如 $\mathrm{TSH}$ 受体的阻断性抗体可抑制 $\mathrm{TSH}$ 对受体的激活作用，从而抑制甲状腺素的分泌，最终可导致甲状腺功能减退。

:::definition{label="阻断性抗体导致甲状腺功能减退"}
$\mathrm{TSH}$ 受体阻断性抗体抑制 $\mathrm{TSH}$ 对受体的激活，抑制甲状腺素分泌，最终可导致甲状腺功能减退。病名用教材的「甲状腺功能减退」。
:::

:::compare{title="TSH 受体抗体两端的分泌结局"}
| 抗体 | 对受体 | 分泌 | 教材落到的病 |
|------|--------|------|------------|
| 刺激性 | 无 $\mathrm{TSH}$ 也能激活 | 本节激活层次已写模拟 $\mathrm{TSH}$ | 自身免疫性甲状腺病（教材原名） |
| 阻断性 | 抑制与 $\mathrm{TSH}$ 结合 | 甲状腺素分泌被抑制 | 甲状腺功能减退 |

两端都不要自行改写诊断名。
:::

#### 2. 失去正常的反应性

慢性长期儿茶酚胺刺激可以导致 $\beta$-肾上腺素能受体（$\beta$-$\mathrm{AR}$）表达下降，并使心肌细胞失去对肾上腺素的反应性，细胞内 $\mathrm{cAMP}$ 水平降低，从而导致心肌收缩功能不足。

:::definition{label="β-AR 下调与心肌收缩不足"}
慢性长期儿茶酚胺刺激 → $\beta$-$\mathrm{AR}$ 表达下降 → 心肌细胞失去对肾上腺素的反应性 → 细胞内 $\mathrm{cAMP}$ 降低 → 心肌收缩功能不足。这是受体数量这一层的失能，原因里对应长期刺激，不是点突变那一句。
:::

:::insight{label="反应过度和反应不足都可以出在受体数量"}
异常激活里：受体过度表达，反应过度。这里：$\beta$-$\mathrm{AR}$ 表达下降，反应不足。数量这本账双向都有。
:::

#### 3. 失去正常的生理调节能力

胰岛素受体异常是一个最典型的例子。由于细胞受体功能异常而不能对胰岛素产生反应，不能正常摄入和贮存葡萄糖，从而导致血糖水平升高。

抗利尿激素（antidiuretic hormone，$\mathrm{ADH}$）的Ⅱ型受体是 $\mathrm{G}$ 蛋白偶联受体，$\mathrm{ADH}$ $\mathrm{V2}$ 受体位于远端肾小管或集合管上皮细胞膜。该受体激活后，通过 $\mathrm{cAMP}$-$\mathrm{PKA}$ 途径使微丝微管磷酸化，促进位于细胞质内的水通道蛋白向集合管上皮细胞管腔侧膜移动并插入膜内，集合管上皮细胞膜对水的通透性增加，管腔内水进入细胞，并按渗透梯度转移到肾间质，使肾小管腔内尿液浓缩。基因突变可导致 $\mathrm{ADH}$ 受体合成减少或受体胞外环结构异常，不能传递 $\mathrm{ADH}$ 的刺激信号，集合管上皮细胞不能有效进行水的重吸收，导致肾性尿崩症的发生。

:::definition{label="胰岛素受体异常与血糖升高"}
受体功能异常 → 不能对胰岛素产生反应 → 不能正常摄入和贮存葡萄糖 → 血糖水平升高。最典型的「失去正常生理调节能力」例子。
:::

:::definition{label="ADH V2 受体与水通道"}
抗利尿激素Ⅱ型受体是 $\mathrm{GPCR}$，位于远端肾小管或集合管上皮细胞膜。激活后走 $\mathrm{cAMP}$-$\mathrm{PKA}$，使微丝微管磷酸化，促进水通道蛋白向管腔侧膜移动并插入，膜对水通透性增加，管腔内水进入细胞并按渗透梯度转移到肾间质，尿液浓缩。
:::

:::definition{label="肾性尿崩症"}
基因突变导致 $\mathrm{ADH}$ 受体合成减少或受体胞外环结构异常，不能传递 $\mathrm{ADH}$ 刺激信号，集合管上皮细胞不能有效重吸收水。
:::

:::keypoint{label="V2 通路六步不要缩成「cAMP 升了就会浓缩尿」"}
受体在远端肾小管／集合管膜上 → $\mathrm{cAMP}$-$\mathrm{PKA}$ → 微丝微管磷酸化 → 水通道蛋白从细胞质插入管腔侧膜 → 通透性增加 → 水按渗透梯度到肾间质。突变坏在受体合成或胞外环，插膜这一步做不成。
:::

:::compare{title="失去正常功能的三例"}
| | 坏在哪 | 细胞失去什么 | 临床落到 |
|--|--------|------------|---------|
| $\mathrm{TSH}$ 阻断性抗体 | 受体被抗体占住 | 正常分泌甲状腺素 | 甲状腺功能减退 |
| 慢性儿茶酚胺 | $\beta$-$\mathrm{AR}$ 表达下降 | 对肾上腺素的反应性 | 心肌收缩功能不足 |
| 胰岛素受体异常 | 受体功能异常 | 摄入和贮存葡萄糖 | 血糖升高 |
| $\mathrm{ADH}$ $\mathrm{V2}$ 突变 | 受体合成减少或胞外环异常 | 集合管重吸收水 | 肾性尿崩症 |

胰岛素和 $\mathrm{ADH}$ 都写在「生理调节能力」下，一是糖，一是水。
:::

:::pitfall{label="肾性尿崩症不要答成 ADH 分泌不足"}
坏的是肾上的 $\mathrm{V2}$ 受体，不能传递 $\mathrm{ADH}$ 的刺激信号。不是下丘脑做不出抗利尿激素。教材病名是肾性尿崩症。
:::

:::pitfall{label="胰岛素这一例不要漏掉「摄入和贮存葡萄糖」"}
血糖升高是因为不能正常摄入和贮存葡萄糖。只答「受体坏了所以血糖高」，中间的细胞功能缺失没有写出来。
:::

## 三、细胞信号转导分子是重要的药物作用靶位

细胞信号转导机制研究的发展，尤其是对于各种疾病过程中的信号转导异常的不断认识，为发展新的疾病诊断和治疗手段提供了更多的机会。在研究各种病理过程中发现的信号转导分子结构与功能的改变为新药的筛选和开发提供了靶位，由此产生了信号转导药物这一概念。信号转导分子的激动剂和抑制剂是信号转导药物研究的出发点，尤其是各种蛋白质激酶的抑制剂更是被广泛用作母体药物进行抗肿瘤新药的研发。

一种信号转导干扰药物是否可以用于疾病的治疗而又具有较小的副作用，主要取决于两点。一是它所干扰的信号转导途径在体内是否广泛存在，如果该途径广泛存在于各种细胞内，其副作用则很难控制。二是药物自身的选择性，对信号转导分子的选择性越高，副作用就越小。基于上述两点，人们一方面正在努力筛选和改造已有的化合物，以发现具有更高选择性的信号转导分子的激动剂和抑制剂，同时也在努力了解信号转导分子在不同细胞的分布情况。这些努力已经使得一些药物得以用于临床，特别是在肿瘤治疗领域。

:::definition{label="信号转导药物"}
病理过程中发现的信号转导分子结构与功能改变，为新药筛选和开发提供靶位，由此产生信号转导药物这一概念。出发点是信号转导分子的激动剂和抑制剂。
:::

:::definition{label="蛋白质激酶抑制剂作为母体药物"}
各种蛋白质激酶的抑制剂被广泛用作母体药物，进行抗肿瘤新药的研发。与本节增殖异常、$\mathrm{MAPK}$ 持续激活相接，但不要编造具体商品名。
:::

:::keypoint{label="副作用小不小看两点"}
- 所干扰的途径在体内是否广泛存在：途径遍布各种细胞，副作用很难控制。
- 药物自身的选择性：对信号转导分子的选择性越高，副作用越小。

因此既要筛选、改造化合物以提高选择性，也要了解分子在不同细胞的分布。已有药物用于临床，特别是肿瘤治疗领域。
:::

:::cause-effect{title="途径太通用为什么副作用难控"}
- **因** 第四节刚写过：许多分子和途径被不同受体共用，有的途径广泛存在于各种细胞
- **果** 干扰这条途径时，正常细胞也被波及，副作用很难控制；所以要更高选择性，并摸清分布
:::

:::pitfall{label="不要把本节写成新药说明书"}
教材停在概念、激动剂／抑制剂、激酶抑制剂作母体、两点副作用原则、肿瘤领域已有药物。不要编造详解、商品名、临床试验。
:::

:::insight{label="开篇的「新靶位」在这里收口"}
医学意义第二句是「为治疗提供新靶位」。靶位就是结构与功能改变了的信号转导分子；药从激动剂和抑制剂做起。
:::

## 小结

细胞通讯和细胞信号转导是机体内一部分细胞发出信号，另一部分细胞接收信号并将其转变为细胞功能变化的过程。细胞信号转导的相关分子包括细胞外信号分子、受体、细胞内信号转导分子。

信号的传递和终止、信号转导过程中的级联放大效应、信号转导途径的通用性和特异性、信号转导途径的复杂且多样性，形成了细胞信号转导的基本规律。

受体的基本类型包括细胞内受体和膜表面受体两大类。膜受体又有离子通道型受体、$\mathrm{G}$ 蛋白偶联型受体和蛋白质激酶偶联受体三个亚类。受体的功能是结合配体并将信号导入细胞。

各种信号转导分子的特定组合及有序的相互作用，构成了不同的信号转导途径。信号转导分子通过引起下游分子的数量、分布或活性状态变化而传递信号。小分子信使以浓度和分布的迅速变化为主，蛋白质信号转导分子通过蛋白质的相互作用而传递信号。受体或细胞内信号转导分子的数量或结构改变，可导致信号转导途径的异常激活或失活，从而使细胞产生异常功能或失去正常功能，导致疾病的发生或影响疾病的进程。

:::keypoint{label="小结四段各自对应哪一节"}
- 通信与转导、三类相关分子：第一、二节。
- 双向、放大、通用与特异、多样性：第四节。
- 受体两大类、膜受体三亚类：第三节（与表20-5、章末这句话一致）。
- 数量／分布／活性；小分子 vs 蛋白质；异常激活或失活致病：第四、五节。
:::

:::pitfall{label="小结里的膜受体三亚类不要改成四类并列"}
「细胞内受体和膜表面受体两大类。膜受体又有离子通道型、$\mathrm{G}$ 蛋白偶联型、蛋白质激酶偶联三个亚类。」酶偶联与蛋白质激酶偶联是同一亚类的两种叫法。不要写成四大类平级。
:::

## 思考题

1. 一种受体为什么可以同时激活几条信号转导途径？
2. 当外源信号分子刺激细胞时，细胞内信号传递和终止的双向反应是否同时发生？为什么？
3. 在 $\mathrm{GPCR}$ 介导的信号途径中，为什么会存在 $\mathrm{G}$ 蛋白循环这一反应？有何意义？
4. 蛋白质分子中有许多含有羟基的氨基酸残基，作为信号转导分子的蛋白质激酶在修饰底物时，是将底物蛋白分子的所有含羟基的氨基酸残基都磷酸化，还是只将一个（或某几个）氨基酸残基磷酸化？

:::insight{label="四道思考题对着哪些户"}
1. 第四节「受体与途径有多样性组合」，如 $\mathrm{PDGF}$ 受体多个磷酸化位点。
2. 第四节「双向反应」：正反向可以同时存在。
3. 第三节 $\mathrm{G}$ 蛋白循环：可逆开关，才能终止并再次接受信号。
4. 第二节激酶的位点特异性：不是把所有含羟基残基都磷酸化。

题干保留，不附解答。
:::

:::memory{label="本节必背要点"}
- 医学意义：认识发病机制；新标记物和新靶位。原因：基因突变、细菌毒素、自身抗体、应激。层次：受体，或细胞内转导分子。
- 受体激活：$ERB$-$B$ 无胞外区持续开 $\mathrm{MAPK}$；受体过多反应过度；$\mathrm{TSH}$ 刺激性抗体模拟 $\mathrm{TSH}$（自身免疫性甲状腺病）。
- 受体失活：胰岛素受体三型（数量、$735$ $\mathrm{Arg}$→$\mathrm{Ser}$ 亲和力、$1\,008$ $\mathrm{Gly}$→$\mathrm{Val}$ 的 $\mathrm{RTK}$）；$\mathrm{TSH}$ 阻断性抗体。
- 分子激活：$\mathrm{G}\alpha$ 的 $201$／$227$ 失去 $\mathrm{GTP}$ 酶；霍乱毒素 $\mathrm{ADP}$-核糖化；$\mathrm{Ras}$ 的 $12$／$13$／$61$。分子失活：$\mathrm{PI3K}$ 的 $\mathrm{p85}$；假性甲状旁腺素低下 $\mathrm{G}\alpha$ 从第 $60$ 位起译。
- 获得功能：持续增殖（$ERB$-$B$、$RAS$）；$\mathrm{GH}$ 过多（成人肢端肥大症，儿童巨人症）；霍乱腹泻。失去功能：甲减（阻断性抗体）；$\beta$-$\mathrm{AR}$ 下调心肌收缩不足；胰岛素受体 → 血糖升高；$\mathrm{ADH}$ $\mathrm{V2}$ → 肾性尿崩症。
- 信号转导药物：激动剂和抑制剂；激酶抑制剂作抗肿瘤母体；副作用看途径是否广泛、药物是否选择性高。
:::
