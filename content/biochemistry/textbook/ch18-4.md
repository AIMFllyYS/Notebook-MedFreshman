# 第四节　生物分子相互作用研究技术

第三节把一段 $\mathrm{DNA}$ 里 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{T}$ 的排列读出来，也把 $\mathrm{ChIP}$-seq 写成测序的一种应用。本节换户头：分子之间怎样形成共价连接、稳定沉淀或可逆结合的复合物。蛋白质–蛋白质走标签牵拉沉淀和酵母双杂交；蛋白质–$\mathrm{DNA}$ 体外走 $\mathrm{EMSA}$、体内走 $\mathrm{ChIP}$（再联芯片或测序）；染色质上远距离接触走 $3\mathrm{C}$ 及 $4\mathrm{C}$、$5\mathrm{C}$、$\mathrm{Hi}$-$\mathrm{C}$、$\mathrm{ChIA}$-$\mathrm{PET}$。基因表达何时何地发生，交给第五节。

:::concept{term="先问互作的双方是蛋白质还是核酸，再问实验是体外牵拉还是体内交联"}
看见“生物分子相互作用”，先不要默写测序仪。户头是：复合物怎么抓住、怎么拆开、怎么读出来。两种已知蛋白质会不会直接碰上，用标签蛋白质牵拉沉淀；细胞内未知伴侣，用酵母双杂交把 $\mathrm{GAL4}$ 的 $\mathrm{BD}$ 和 $\mathrm{AD}$ 重新拼回去。蛋白质认哪一段 $\mathrm{DNA}$，体外看 $\mathrm{EMSA}$ 条带滞不滞后，体内看 $\mathrm{ChIP}$ 抗体沉淀下来的片段。染色质上谁和谁在三维里挨着，是 $3\mathrm{C}$ 这一族，不要并成同一种技术。
:::

生物分子之间相互作用可形成共价连接、稳定沉淀或可逆结合的各种复合物。所有重要生命活动，包括 $\mathrm{DNA}$ 复制、$\mathrm{RNA}$ 转录、蛋白质合成与分泌、信号转导和代谢等，都是由生物分子相互作用完成的。研究分析细胞内各种蛋白质、蛋白质-$\mathrm{DNA}$、蛋白质-$\mathrm{RNA}$ 复合物的组成和作用方式，是理解生命活动基本机制的基础。

:::definition{label="生物分子相互作用"}
生物分子之间形成共价连接、稳定沉淀或可逆结合的各种复合物。复制、转录、蛋白质合成与分泌、信号转导和代谢都靠这类复合物完成。
:::

:::definition{label="本节要解析的三类复合物"}
细胞内各种蛋白质复合物、蛋白质-$\mathrm{DNA}$ 复合物、蛋白质-$\mathrm{RNA}$ 复合物的组成和作用方式。蛋白质–蛋白质是「一」；核酸–蛋白质是「二」；染色质三维接触（$\mathrm{DNA}$–蛋白质–$\mathrm{DNA}$）是「三」。
:::

:::insight{label="第三节的 ChIP-seq 测的是已经沉淀下来的 DNA，本节补的是沉淀这一步"}
$\mathrm{ChIP}$-seq 在第三节出现，是因为高通量测序把它读成序列。序列从哪来？要先在活细胞里把蛋白质-$\mathrm{DNA}$ 交联、切断、用抗体沉淀。没有这一步，测序仪读到的只是基因组，不是「这个蛋白质当时抓住的那段」。
:::

:::pitfall{label="不要把酵母双杂交写成测序"}
诱饵质粒筛选猎物 $\mathrm{cDNA}$ 文库之后，阳性克隆当然可以测序鉴定是哪条基因。实验本身的读出是转录因子 $\mathrm{BD}$ 与 $\mathrm{AD}$ 重新装配、下游报告基因表达，不是芯片上的碱基阶梯。把本节答成「又一种测序」，第三节的桑格／循环芯片和本节的 $\mathrm{GAL4}$ 就并成一户。
:::

有关分子相互作用的研究技术发展迅速。体外测定相互作用速率、亲和力等参数的技术有：等温滴定量热（isothermal titration calorimetry，$\mathrm{ITC}$）、表面等离子共振（surface plasmon resonance，$\mathrm{SPR}$）、生物膜层干涉（bio-layer interferometry，$\mathrm{BLI}$）、微量热泳动（microscale thermophoresis，$\mathrm{MST}$）和表面增强拉曼光谱（surface-enhanced Raman spectroscopy，$\mathrm{SERS}$）等。筛选与分析体内外相互作用的有：各种亲和分离分析（如亲和色谱、免疫共沉淀、标签蛋白质沉淀和串联亲和纯化等）、酵母双杂交系统（yeast two-hybrid system）、$\mathrm{FRET}$ 效应分析、噬菌体展示（phage display）系统和细胞指数富集配体系统进化（cell systematic evolution of ligand by exponential enrichment，$\mathrm{cell}$-$\mathrm{SELEX}$）等。结构细节则可通过核磁共振、晶体衍射、冷冻电镜、分子计算和分子动力学等计算。本节选择性介绍几种利用分子生物学研究成果所构建的生物大分子相互作用研究技术的原理和用途。

:::definition{label="体外测速率和亲和力的五条"}
等温滴定量热（$\mathrm{ITC}$）、表面等离子共振（$\mathrm{SPR}$）、生物膜层干涉（$\mathrm{BLI}$）、微量热泳动（$\mathrm{MST}$）、表面增强拉曼光谱（$\mathrm{SERS}$）。问的是结合快慢、亲和力大小，不是「基因顺序」。
:::

:::definition{label="筛选与分析体内外互作的几条"}
亲和分离（亲和色谱、免疫共沉淀、标签蛋白质沉淀、串联亲和纯化）、酵母双杂交、$\mathrm{FRET}$、噬菌体展示、$\mathrm{cell}$-$\mathrm{SELEX}$。本节展开的是标签牵拉沉淀和酵母双杂交。
:::

:::definition{label="互作结构细节从哪来"}
核磁共振、晶体衍射、冷冻电镜、分子计算和分子动力学。这些给出界面怎么贴；本节的分子生物学实验给出「会不会贴、贴的是哪一段」。
:::

:::keypoint{label="本节真正展开的三张实验"}
- 蛋白质–蛋白质：标签蛋白质牵拉沉淀（体外直接物理结合）；酵母双杂交（细胞内，靠转录因子结构域重组装）。
- 蛋白质–$\mathrm{DNA}$（也可扩到蛋白质–$\mathrm{RNA}$）：$\mathrm{EMSA}$ 体外、温和条件；$\mathrm{ChIP}$ 体内、先交联。
- 染色质三维：交联后酶切、连接，再按读出分成 $3\mathrm{C}$、$4\mathrm{C}$、$5\mathrm{C}$、$\mathrm{Hi}$-$\mathrm{C}$、$\mathrm{ChIA}$-$\mathrm{PET}$。

名单里的 $\mathrm{ITC}$、$\mathrm{SPR}$、冷冻电镜知道有即可，不要把本节答成生物物理仪器学。
:::

:::pitfall{label="不要发明干扰素抑制翻译当本节例题"}
本版在相互作用这一节没有写干扰素、没有写翻译抑制。诱饵是 $\mathrm{GST}$ 融合蛋白质或 $\mathrm{GAL4}$-$\mathrm{BD}$，猎物是待测蛋白质或 $\mathrm{AD}$ 融合的 $\mathrm{cDNA}$ 文库。不要从别的书把「干扰素处理细胞、看翻译停不停」塞进来当原理。
:::

## 一、蛋白质相互作用研究技术可以解析蛋白质行使功能的机制

上述列举的生物大分子相互作用研究技术大多可用于研究蛋白质相互作用。本部分简要介绍标签蛋白质（tagged protein）牵拉沉淀实验（pull-down experiment）和酵母双杂交系统。

:::definition{label="本部分两张蛋白质–蛋白质实验"}
标签蛋白质牵拉沉淀：体外、亲和色谱原理、问直接物理结合。酵母双杂交：酵母细胞内、转录因子结构域重组装、可筛未知伴侣。
:::

:::compare{title="牵拉沉淀 vs 酵母双杂交"}
| | 标签蛋白质牵拉沉淀 | 酵母双杂交 |
|--|-------------------|------------|
| 场所 | 体外温育 | 酵母细胞内 |
| 抓住的依据 | 标签与琼脂糖珠的亲和（如 $\mathrm{GST}$-$\mathrm{GSH}$） | 两种融合蛋白质互作，把 $\mathrm{GAL4}$ 的 $\mathrm{BD}$ 与 $\mathrm{AD}$ 拉到一起 |
| 读出 | 电泳胶上共沉淀的条带 | 下游基因表达被重新激活 |
| 擅长 | 证明直接物理结合、划结构部位、纯化融合蛋白质 | 证明已知对互作、划功能结构域或关键残基、筛 $\mathrm{cDNA}$ 文库找未知猎物 |
| 不是 | 测序反应 | 测序反应 |

一个在管里用珠子捞，一个在细胞核里把转录因子拼回去。
:::

### （一）利用重组表达的融合标签捕获相互作用的蛋白质复合物

标签蛋白质牵拉沉淀实验是基于亲和色谱原理、分析蛋白质体外直接相互作用的方法。该方法利用带有特定标签的纯化融合蛋白质作为钓饵，在体外与待检测的纯化蛋白质或含有此待测蛋白质的细胞裂解液温育，然后用可结合蛋白质标签的琼脂糖珠将融合蛋白质牵拉回收，洗脱液经电泳分离并染色。如果两种蛋白质有结合，待检测蛋白质将与融合蛋白质同时被琼脂糖珠牵拉沉淀，在电泳胶中见到相应条带。

:::definition{label="标签蛋白质"}
标签蛋白质（tagged protein）：带有特定亲和标签的纯化融合蛋白质，在牵拉沉淀里当钓饵。
:::

:::definition{label="牵拉沉淀实验"}
牵拉沉淀实验（pull-down experiment）：基于亲和色谱。钓饵（带标签的融合蛋白质）与待测纯化蛋白质或细胞裂解液体外温育 $\rightarrow$ 能结合该标签的琼脂糖珠把融合蛋白质牵拉回收 $\rightarrow$ 洗脱、电泳、染色。若两者结合，待测蛋白质与融合蛋白质同时出现在胶上。
:::

:::insight{label="「直接物理结合」四个字是这张实验的户头"}
珠子捞上来的是钓饵加上当时贴在钓饵上的分子。教材把它写成分析体外直接相互作用：胶上有共沉淀条带，支持两者在管里直接碰上。酵母双杂交发生在细胞里，中间可能还隔着别的酵母蛋白，户头不同。
:::

:::cause-effect{title="为什么洗脱液电泳能证明结合"}
- **因** 琼脂糖珠认的是标签，不是待测蛋白质本身；待测蛋白质只有贴在钓饵上才会被一起牵下来
- **果** 洗涤去掉未结合的蛋白质后，胶上仍出现待测条带，就支持两者结合；没有条带，就不能用这张胶说它们直接互作
:::

标签蛋白质牵拉沉淀实验可用于证明两种蛋白质分子是否存在直接物理结合、分析两种分子结合的具体结构部位及筛选细胞内与融合蛋白质相结合的未知分子。该方法亦常用于重组融合蛋白质的纯化。

:::definition{label="牵拉沉淀的三用途加一条纯化"}
①证明两种蛋白质是否存在直接物理结合；②分析结合的具体结构部位；③筛选细胞内与融合蛋白质相结合的未知分子。同一套标签–珠子化学，也常用于重组融合蛋白质的纯化。
:::

:::pitfall{label="牵拉沉淀不是免疫共沉淀的别名"}
免疫共沉淀用的是抗体认内源或表位；牵拉沉淀用的是重组标签认珠子。教材把二者并列写在亲和分离名单里，不要并成同一种沉淀。
:::

目前最常用的标签是谷胱甘肽 $\mathrm{S}$ 转移酶（glutathione S-transferase，$\mathrm{GST}$），有各种商品化的载体用于构建与 $\mathrm{GST}$ 融合的基因，并在大肠埃希菌中表达为 $\mathrm{GST}$ 标签蛋白质（图18-7）。利用 $\mathrm{GST}$ 与还原型谷胱甘肽（glutathione，$\mathrm{GSH}$）的结合作用，可以用共价偶联了 $\mathrm{GSH}$ 的琼脂糖珠进行 $\mathrm{GST}$ 融合蛋白质牵拉沉淀实验（GST pull-down assay）。另一个常用的、易于用常规亲和色谱方法纯化的标签分子，是可以与镍离子琼脂糖珠结合的 $6$ 个连续组氨酸（$6\times\mathrm{His}$）的标签。

:::note{label="电子版缺失"}
图18-7　标签蛋白质牵拉沉淀实验流程示意图：电子版图源 `p0378_01.png` 为 $0$ 字节，不嵌入 `src`。禁止使用混排页 `p0377_page.png`。正文按教材图注写出流程：若蛋白质 $\mathrm{X}$ 与蛋白质 $\mathrm{Y}$ 存在相互作用，把蛋白质 $\mathrm{X}$ 的编码基因插到 $\mathrm{GST}$ 编码区下游，表达为 $\mathrm{GST}$-蛋白质 $\mathrm{X}$ 融合蛋白质；融合蛋白质的 $\mathrm{GST}$ 部分与偶联在琼脂糖珠上的 $\mathrm{GSH}$ 结合；蛋白质 $\mathrm{Y}$ 与蛋白质 $\mathrm{X}$ 相互作用，被琼脂糖珠间接牵拉沉淀；洗涤去除未结合蛋白质，再用含游离 $\mathrm{GSH}$ 的缓冲液把 $\mathrm{GST}$-蛋白质 $\mathrm{X}$ 竞争洗脱下来，电泳染色即可证明两者的相互作用。
:::

:::definition{label="GST"}
谷胱甘肽 $\mathrm{S}$ 转移酶（glutathione S-transferase，$\mathrm{GST}$）：目前最常用的融合标签。商品化载体把目的基因接到 $\mathrm{GST}$ 编码区下游，在大肠埃希菌中表达为 $\mathrm{GST}$ 标签蛋白质。
:::

:::definition{label="GST pull-down"}
$\mathrm{GST}$ 融合蛋白质牵拉沉淀实验（GST pull-down assay）：利用 $\mathrm{GST}$ 与还原型谷胱甘肽（$\mathrm{GSH}$）的结合，用共价偶联了 $\mathrm{GSH}$ 的琼脂糖珠把 $\mathrm{GST}$ 融合蛋白质连同其结合伴侣牵下来。
:::

:::definition{label="GSH 竞争洗脱"}
洗涤之后，用含游离 $\mathrm{GSH}$ 的缓冲液把 $\mathrm{GST}$-蛋白质 $\mathrm{X}$ 从珠子上竞争下来。珠子上的 $\mathrm{GSH}$ 是固定的钓饵配体；溶液里的游离 $\mathrm{GSH}$ 把融合蛋白质从珠子上顶走，电泳才能看到条带。
:::

:::definition{label="6×His 标签"}
$6$ 个连续组氨酸（$6\times\mathrm{His}$）：另一常用标签，可与镍离子琼脂糖珠结合，便于常规亲和色谱纯化。
:::

:::compare{title="GST 标签 vs 6×His 标签"}
| | $\mathrm{GST}$ | $6\times\mathrm{His}$ |
|--|--------------|---------------------|
| 认谁 | 还原型 $\mathrm{GSH}$（偶联在琼脂糖珠上） | 镍离子琼脂糖珠 |
| 教材角色 | 牵拉沉淀的最常用标签，图18-7 的主角 | 「另一个常用、易于常规亲和色谱纯化」的标签 |
| 表达宿主（本版写明的） | 大肠埃希菌 | 未另指定宿主，强调的是镍柱纯化 |

标签不同，珠子化学不同；都是「先融合、再按标签捞」。
:::

:::pitfall{label="GSH 是谷胱甘肽，GST 是酶标签，不要写反"}
$\mathrm{GST}$ 是融合在钓饵上的蛋白质标签；$\mathrm{GSH}$ 是珠子上（或洗脱液里）的小分子配体。写成「$\mathrm{GSH}$ 融合蛋白质」或「用 $\mathrm{GST}$ 溶液洗脱」，珠子和钓饵就换了边。
:::

:::pitfall{label="大肠埃希菌表达的是 GST 融合蛋白质，不是酵母双杂交那一套"}
$\mathrm{GST}$ 牵拉沉淀的表达宿主本版写的是大肠埃希菌。酵母双杂交发生在酵母细胞里，用的是 $\mathrm{GAL4}$ 的 $\mathrm{BD}/\mathrm{AD}$。不要把「在大肠埃希菌里表达 $\mathrm{GST}$-$\mathrm{X}$」答成酵母双杂交。
:::

:::keypoint{label="图18-7 即使电子版缺失也要能默写的五步"}
1. 把 $\mathrm{X}$ 接到 $\mathrm{GST}$ 下游，表达 $\mathrm{GST}$-$\mathrm{X}$。
2. $\mathrm{GST}$ 端绑到 $\mathrm{GSH}$-琼脂糖珠上。
3. $\mathrm{Y}$ 若与 $\mathrm{X}$ 互作，被间接牵到珠子上。
4. 洗涤去掉未结合蛋白质。
5. 游离 $\mathrm{GSH}$ 竞争洗脱，$\mathrm{GST}$-$\mathrm{X}$（及贴着的 $\mathrm{Y}$）上胶。
:::

### （二）酵母双杂交的原理是基于融合表达转录因子不同结构域的重组装

酵母双杂交系统目前已经成为分析细胞内未知蛋白质相互作用的主要手段之一。该技术的建立是基于对酵母转录激活因子 $\mathrm{GAL4}$ 的认识。$\mathrm{GAL4}$ 的 $\mathrm{DNA}$ 结合结构域（binding domain，$\mathrm{BD}$）和促进转录的激活结构域（activation domain，$\mathrm{AD}$）被分开后将丧失对下游基因表达的激活作用。如果 $\mathrm{BD}$ 和 $\mathrm{AD}$ 分别融合了具有配对相互作用的两种蛋白质分子后，就可以依靠所融合的蛋白质分子之间的相互作用，重组装成对下游基因的表达具有激活作用的转录因子。

:::definition{label="酵母双杂交"}
酵母双杂交系统（yeast two-hybrid system）：分析细胞内未知蛋白质相互作用的主要手段之一。把酵母转录激活因子 $\mathrm{GAL4}$ 拆成 $\mathrm{DNA}$ 结合结构域（$\mathrm{BD}$）和激活结构域（$\mathrm{AD}$），分别融合两种待测蛋白质；二者互作则 $\mathrm{BD}$ 与 $\mathrm{AD}$ 重组装，下游基因重新被激活。
:::

:::definition{label="GAL4 的 BD"}
$\mathrm{DNA}$ 结合结构域（binding domain，$\mathrm{BD}$）：$\mathrm{GAL4}$ 上负责结合下游基因调控 $\mathrm{DNA}$ 的那一半。单独存在时不能激活转录。
:::

:::definition{label="GAL4 的 AD"}
激活结构域（activation domain，$\mathrm{AD}$）：$\mathrm{GAL4}$ 上促进转录的那一半。单独存在时同样不能激活下游基因。
:::

:::insight{label="「双杂交」的「双」是两段融合蛋白质，不是两次测序"}
一个杂交体是 $\mathrm{BD}$-诱饵，另一个是 $\mathrm{AD}$-猎物。只有诱饵和猎物互相抓住，$\mathrm{BD}$ 和 $\mathrm{AD}$ 才会被拉到同一条下游基因旁边，报告基因才亮。读出的是转录激活，不是碱基荧光。
:::

:::cause-effect{title="为什么拆开 GAL4 就能变成互作探测器"}
- **因** 完整 $\mathrm{GAL4}$ 必须 $\mathrm{BD}$ 和 $\mathrm{AD}$ 同时在场才能激活下游基因；二者分开则激活作用丧失
- **果** 把待测蛋白质 $\mathrm{X}$、$\mathrm{Y}$ 分别融到 $\mathrm{BD}$ 和 $\mathrm{AD}$ 上：$\mathrm{X}$ 与 $\mathrm{Y}$ 互作 $\Leftrightarrow$ 转录因子被重组装 $\Leftrightarrow$ 下游基因表达；不互作则报告基因保持关闭
:::

:::pitfall{label="BD 结合的是下游基因的 DNA，不是猎物蛋白质"}
$\mathrm{BD}$ 的本职是认 $\mathrm{DNA}$。猎物是融在 $\mathrm{AD}$ 上的蛋白质，靠与诱饵蛋白质的相互作用被间接拉过来。写成「$\mathrm{BD}$ 直接结合猎物」，酵母双杂交就变成了 $\mathrm{EMSA}$。
:::

:::pitfall{label="分开后丧失激活，不是丧失 DNA 结合"}
教材写：$\mathrm{BD}$ 和 $\mathrm{AD}$ 被分开后将丧失对下游基因表达的激活作用。$\mathrm{BD}$ 仍可能绑在 $\mathrm{DNA}$ 上，只是没有 $\mathrm{AD}$ 就转不起来。不要答成「拆开之后 $\mathrm{GAL4}$ 不再认 $\mathrm{DNA}$」。
:::

酵母双杂交系统可以用于：①证明两种已知基因序列的蛋白质可以相互作用；②分析已知存在相互作用的两种蛋白质分子的相互作用功能结构域或关键氨基酸残基；③将待研究蛋白质的编码基因与 $\mathrm{BD}$ 基因融合成为「诱饵」表达质粒，可以筛选 $\mathrm{AD}$ 基因融合的「猎物」基因的 $\mathrm{cDNA}$ 表达文库，获得未知的相互作用蛋白质。

:::definition{label="诱饵与猎物"}
诱饵：待研究蛋白质的编码基因与 $\mathrm{BD}$ 基因融合而成的表达质粒。猎物：与 $\mathrm{AD}$ 基因融合的基因（已知编码序列，或 $\mathrm{cDNA}$ 表达文库中的未知克隆）。诱饵用来钓，猎物是被钓的那一侧。
:::

:::definition{label="酵母双杂交的三种用途"}
①证明两种已知序列的蛋白质可以相互作用；②分析已知互作对的功能结构域或关键氨基酸残基；③用 $\mathrm{BD}$ 融合的诱饵质粒筛 $\mathrm{AD}$ 融合的猎物 $\mathrm{cDNA}$ 表达文库，获得未知的相互作用蛋白质。
:::

:::keypoint{label="筛文库那一条不要滑进「测序技术」"}
用途③的产物是未知相互作用蛋白质。实验室里随后会对阳性猎物质粒做插入片段鉴定（常常包括测序），但鉴定是后处理。酵母双杂交这一节的考点是 $\mathrm{BD}/\mathrm{AD}$ 重组装。
:::

:::compare{title="已知对验证 vs 筛未知猎物"}
| | 用途①② | 用途③ |
|--|---------|--------|
| 双方是否已知 | 两种蛋白质的基因序列已知 | 诱饵已知，猎物在 $\mathrm{cDNA}$ 文库里未知 |
| 问什么 | 会不会互作；互作靠哪一段结构域或哪些残基 | 细胞内还有谁跟这个诱饵绑 |
| 读出 | 报告基因是否被重新激活 | 同样靠报告基因，再鉴定阳性克隆是哪条 $\mathrm{cDNA}$ |

①②是验证，③是发现。原理仍是同一套 $\mathrm{GAL4}$ 拆分。
:::

## 二、核酸-蛋白质相互作用研究技术可以解析基因表达调控机制

分析转录因子所结合的 $\mathrm{DNA}$ 序列，或基因的调控序列所结合的蛋白质，是阐明基因表达调控机制的主要研究内容。而蛋白质与 $\mathrm{RNA}$ 的相互作用分析，可以解析 $\mathrm{RNA}$ 的剪接、转运、编辑、胞内定位及翻译调控等的机制，还可以阐释非编码 $\mathrm{RNA}$ 结构与功能的关系。由于核酸-蛋白质相互作用大多为非共价可逆结合，而且往往作用力较弱，因此一个策略是在温和的生理条件下分析，另一策略是用甲醛、紫外光等交联已经靠近的生物大分子，然后分析。这里介绍两种策略中各一种代表性技术。

:::definition{label="核酸-蛋白质相互作用研究什么"}
$\mathrm{DNA}$ 侧：转录因子结合的 $\mathrm{DNA}$ 序列，或调控序列结合的蛋白质——阐明转录调控。$\mathrm{RNA}$ 侧：剪接、转运、编辑、胞内定位及翻译调控，以及非编码 $\mathrm{RNA}$ 结构与功能。
:::

:::definition{label="弱可逆结合的两种策略"}
核酸–蛋白质大多非共价、可逆、往往较弱。策略一：温和生理条件下分析（代表：$\mathrm{EMSA}$）。策略二：用甲醛、紫外光等把已经靠近的大分子交联住再分析（代表：$\mathrm{ChIP}$）。
:::

:::insight{label="先选「还在溶液里轻轻绑着」还是「先固定再切开」"}
$\mathrm{EMSA}$ 把探针和核提取物温育后直接上非变性胶，靠分子量变大而滞后，所以不能加 $\mathrm{SDS}$、不能先把复合物拆掉。$\mathrm{ChIP}$ 要在活细胞里抓住当时的染色质状态，必须先交联，否则切断染色质时复合物就散了。
:::

:::pitfall{label="蛋白质-RNA 互作是研究题目，代表技术仍先写 EMSA 和 ChIP"}
开篇并列了蛋白质-$\mathrm{DNA}$ 和蛋白质-$\mathrm{RNA}$。$\mathrm{EMSA}$ 正文写明也可用于蛋白质-$\mathrm{RNA}$；$\mathrm{ChIP}$ 是体内 $\mathrm{DNA}$ 与蛋白质。第五节剪接分析里的交联免疫沉淀才专门对着蛋白质-$\mathrm{RNA}$ 剪接位点。不要在本节发明一套「干扰素抑制翻译」来填 $\mathrm{RNA}$ 这一侧。
:::

:::compare{title="温和条件 vs 先交联"}
| | 温和生理条件 | 甲醛／紫外交联后再分析 |
|--|--------------|------------------------|
| 复合物状态 | 仍是可逆结合，靠电泳时还没散 | 共价或准共价固定「当时靠近」的分子 |
| 代表 | $\mathrm{EMSA}$（凝胶阻滞） | $\mathrm{ChIP}$（染色质免疫沉淀） |
| 典型样品 | 标记探针 $+$ 核提取物，体外 | 活细胞，体内染色质 |
| 最怕什么 | 变性剂（$\mathrm{SDS}$）把复合物拆开 | 交联不充分，切断时蛋白质掉下 $\mathrm{DNA}$ |

两种策略不是同一实验的前后两步。
:::

### （一）电泳迁移率变动分析技术依赖分子互作后分子量变化

电泳迁移率变动分析（electrophoretic mobility shift assay，$\mathrm{EMSA}$）也称凝胶阻滞分析（gel retardation assay）、凝胶移位结合分析（gel-shift binding assay）或 $\mathrm{DNA}$ 结合分析（DNA binding assay），最初用于研究 $\mathrm{DNA}$ 结合蛋白质与相应 $\mathrm{DNA}$ 序列间的相互作用，可用于定性和定量分析，也可应用于蛋白质-$\mathrm{DNA}$、蛋白质-$\mathrm{RNA}$ 相互作用研究。

:::definition{label="EMSA"}
电泳迁移率变动分析（electrophoretic mobility shift assay，$\mathrm{EMSA}$）：最初用于 $\mathrm{DNA}$ 结合蛋白质与相应 $\mathrm{DNA}$ 序列的相互作用，可定性、定量，也可用于蛋白质-$\mathrm{DNA}$、蛋白质-$\mathrm{RNA}$。
:::

:::definition{label="EMSA 的三个别名"}
凝胶阻滞分析（gel retardation assay）、凝胶移位结合分析（gel-shift binding assay）、$\mathrm{DNA}$ 结合分析（DNA binding assay）。四个名字说的是同一件事：复合物在胶里走得比游离探针慢。
:::

:::pitfall{label="EMSA 是体外结合，不是活细胞染色质上的 ChIP"}
探针和核提取物在管里温育。问的是这段标记 $\mathrm{DNA}$（或 $\mathrm{RNA}$）能不能被提取物里的蛋白质抓住。体内染色质环境下谁绑在基因组上，是下一小节 $\mathrm{ChIP}$。
:::

$\mathrm{DNA}$ 结合蛋白质与特定 $\mathrm{DNA}$ 探针片段结合后分子量变大，在凝胶中的电泳速度慢于游离探针，即表现为条带相对滞后。实验中预先用放射性核素或生物素等标记待检测的 $\mathrm{DNA}$ 探针，再将标记好的探针与细胞核提取物温育一定时间，使其形成 $\mathrm{DNA}$-蛋白质复合物，然后将温育后的反应液进行非变性聚丙烯酰胺凝胶电泳（不加 $\mathrm{SDS}$，以免形成的复合物解离），最后利用标记显示出 $\mathrm{DNA}$ 探针的条带位置。

:::definition{label="条带滞后的物理原因"}
蛋白质绑上探针后分子量变大，电泳速度慢于游离探针，条带相对滞后。看见的是探针的标记，不是把蛋白质染色。
:::

:::definition{label="EMSA 的操作顺序"}
标记 $\mathrm{DNA}$ 探针（放射性核素或生物素等）$\rightarrow$ 与细胞核提取物温育，形成 $\mathrm{DNA}$-蛋白质复合物 $\rightarrow$ 非变性聚丙烯酰胺凝胶电泳 $\rightarrow$ 按标记显示探针条带位置。
:::

:::definition{label="非变性 PAGE 且不加 SDS"}
电泳必须是非变性聚丙烯酰胺凝胶，并且不加 $\mathrm{SDS}$。目的只有一个：不让已经形成的复合物解离。变性胶或加了 $\mathrm{SDS}$，滞后条带消失，不是「没有结合」，是把结合拆掉了。
:::

:::insight{label="胶上至少该有两条账：游离探针和滞后复合物"}
游离探针走得快；绑了蛋白质的探针走得慢。定量看的是滞后条带相对游离条带怎么变。探针自己没标上，整张胶都看不见。
:::

:::pitfall{label="教材原文「聚丙烯凝胶酰胺」指的就是聚丙烯酰胺凝胶"}
排版把「酰胺」二字挪了位。考点是非变性、不加 $\mathrm{SDS}$，不是另发明一种「凝胶酰胺」介质。第一节 Southern 用琼脂糖分基因组大片段；这里要看复合物和游离探针的迁移差别，用的是聚丙烯酰胺。
:::

:::pitfall{label="看见的是 DNA 探针，不是蛋白质染料"}
最后一步「利用标记显示出 $\mathrm{DNA}$ 探针的条带位置」。蛋白质没绑探针就不会在这张图上出现。不要把 $\mathrm{EMSA}$ 答成考马斯亮蓝染蛋白胶。
:::

:::compare{title="EMSA vs 第一节的核酸印迹"}
| | $\mathrm{EMSA}$ | Southern／Northern |
|--|----------------|-------------------|
| 问什么 | 这段探针现在有没有被蛋白质（或 $\mathrm{RNA}$ 结合蛋白）抓住 | 样品里有没有这条核酸、区带在哪 |
| 胶 | 非变性 $\mathrm{PAGE}$，不加 $\mathrm{SDS}$ | 琼脂糖（核酸）或后转到膜 |
| 识别 | 蛋白质与探针结合导致滞后 | 膜上杂交 |
| 标记在哪 | 探针 | 杂交用的核酸探针 |

都看见核酸条带，一个问「绑了蛋白质没有」，一个问「样品里有没有这条序列」。
:::

### （二）染色质免疫沉淀技术是阐明真核生物基因表达机制的重要方法

真核生物的基因组 $\mathrm{DNA}$ 以染色质的形式存在。因此，研究蛋白质与 $\mathrm{DNA}$ 在染色质环境下的相互作用，是阐明真核生物基因表达机制的重要途径。染色质免疫沉淀（chromatin immunoprecipitation，$\mathrm{ChIP}$）技术是目前研究体内 $\mathrm{DNA}$ 与蛋白质相互作用的主要方法。它的基本原理是在活细胞状态下，用化学交联试剂固定蛋白质-$\mathrm{DNA}$ 复合物，并将其随机切断为一定长度范围内的染色质小片段，然后利用特异性抗体沉淀此复合体，经序列分析确定该蛋白质所结合的 $\mathrm{DNA}$ 序列，从而获得相互作用的信息。

:::definition{label="ChIP"}
染色质免疫沉淀（chromatin immunoprecipitation，$\mathrm{ChIP}$）：目前研究体内 $\mathrm{DNA}$ 与蛋白质相互作用的主要方法。活细胞中用化学交联固定蛋白质-$\mathrm{DNA}$ 复合物 $\rightarrow$ 随机切断成一定长度的染色质小片段 $\rightarrow$ 特异性抗体沉淀该复合体 $\rightarrow$ 序列分析确定该蛋白质结合的 $\mathrm{DNA}$。
:::

:::definition{label="为什么必须在染色质环境下问"}
真核基因组 $\mathrm{DNA}$ 以染色质形式存在。只在体外把一段裸 $\mathrm{DNA}$ 探针和纯化蛋白质温育（$\mathrm{EMSA}$），回答不了「在活细胞核的核小体阵列上，这个蛋白质当时有没有绑在这个位点」。
:::

:::insight{label="抗体认的是蛋白质，测序读的是 DNA"}
沉淀靠特异性抗体抓住目标蛋白质（及交联在上面的 $\mathrm{DNA}$）。解开交联之后，真正拿去鉴定的是那段 $\mathrm{DNA}$ 的序列。蛋白质是钓饵，核酸是读出。
:::

:::cause-effect{title="为什么 ChIP 要先交联再切断"}
- **因** 核酸–蛋白质结合弱、可逆；随机切断染色质时，若不固定，蛋白质会从 $\mathrm{DNA}$ 上掉下来
- **果** 活细胞里先用化学交联试剂（教材点名甲醛、紫外光这一类策略）把已经靠近的分子固定，切断后抗体仍能把「蛋白质＋当时的 $\mathrm{DNA}$」一起沉淀下来
:::

:::keypoint{label="ChIP 四步不要颠倒"}
1. 活细胞交联，固定蛋白质-$\mathrm{DNA}$。
2. 随机切断成一定长度的染色质小片段。
3. 特异性抗体沉淀复合体。
4. 序列分析，确定结合的 $\mathrm{DNA}$。

先切断后交联，位点信息在剪切过程中丢失；没有抗体，沉淀的不是「这个蛋白质」的靶序列。
:::

:::pitfall{label="ChIP 是体内，EMSA 是体外，不要用「都能看 DNA 结合」并成一种"}
$\mathrm{EMSA}$：标记探针 $+$ 核提取物，非变性胶滞后。$\mathrm{ChIP}$：活细胞交联 $+$ 抗体沉淀 $+$ 序列分析。一个管里重建结合，一个抓住细胞里当时的染色质。第五节分析启动子时二者都会被点名，户头仍要分开。
:::

:::pitfall{label="「序列分析」不是把 ChIP 改名为测序技术"}
经典 $\mathrm{ChIP}$ 可以对沉淀下来的 $\mathrm{DNA}$ 做 $\mathrm{PCR}$ 或克隆测序，问的是候选位点在不在。全基因组铺开，才联用芯片或高通量测序，那是下一句的 $\mathrm{ChIP}$-chip 和 $\mathrm{ChIP}$-seq。
:::

近年来，人们将 $\mathrm{ChIP}$ 和芯片、测序技术联用，建立起基于微阵列的染色质免疫沉淀（$\mathrm{ChIP}$-chip）、染色质免疫沉淀测序（$\mathrm{ChIP}$-seq）等技术。这些方法能在全基因组范围内高通量筛选细胞或组织中蛋白质和核酸相互作用，可用于检测分析蛋白质结合位点、基因位点特异性组蛋白修饰模式与位置等。

:::definition{label="ChIP-chip"}
基于微阵列的染色质免疫沉淀（$\mathrm{ChIP}$-chip）：$\mathrm{ChIP}$ 与芯片联用。沉淀下来的 $\mathrm{DNA}$ 杂交到基因组微阵列上，在全基因组范围看结合位点。
:::

:::definition{label="ChIP-seq"}
染色质免疫沉淀测序（$\mathrm{ChIP}$-seq）：$\mathrm{ChIP}$ 与测序联用。第三节已把它列为高通量测序在医学中的应用之一；本节补的是前面的免疫沉淀。全基因组筛选蛋白质–核酸互作，也可看位点特异性组蛋白修饰的模式与位置。
:::

:::definition{label="ChIP 联用能看的两本账"}
①蛋白质结合位点；②基因位点特异性组蛋白修饰模式与位置。组蛋白修饰也是「蛋白质（带修饰的组蛋白）与 $\mathrm{DNA}$ 的染色质环境」，同样走抗体沉淀。
:::

:::compare{title="ChIP vs ChIP-chip vs ChIP-seq"}
| | $\mathrm{ChIP}$ | $\mathrm{ChIP}$-chip | $\mathrm{ChIP}$-seq |
|--|----------------|---------------------|---------------------|
| 核心沉淀 | 有 | 有 | 有 |
| 后面读什么 | 针对候选序列做序列分析（如 $\mathrm{PCR}$） | 芯片微阵列 | 高通量测序 |
| 范围 | 已知或候选位点 | 全基因组（受阵列设计限制） | 全基因组 |
| 在教材中的位置 | 本节体内蛋白质–$\mathrm{DNA}$ 的代表 | 与芯片联用 | 与测序联用；第三节已出现名称 |

联用不是另起一种免疫沉淀，是把沉淀产物接到第一节的芯片或第三节的测序上。
:::

:::pitfall{label="ChIP-seq 不能代替「先交联、再抗体」"}
没有交联和特异性抗体，测序读到的不是「这个转录因子／这种组蛋白修饰当时占据的位点」。把 $\mathrm{ChIP}$-seq 只答成「第二种 $\mathrm{RNA}$-seq」，组蛋白修饰那本账就丢了。
:::

## 三、染色质构象捕获技术可以解析远程 DNA 互作与基因表达的时空框架

线性染色质受表观遗传作用，即自身修饰（如胞嘧啶甲基化）、组蛋白及多种修饰和非编码 $\mathrm{RNA}$ 等作用下，遵循特定规律组装成致密但动态可变的三维结构，通过反式作用因子局部或远程发生互作等高效调控染色质重塑（chromatin remodeling）机制，改变染色质可及性（chromatin accessibility），参与协助细胞完成基因表达的精确调控。该调控过程异常或紊乱，可能会导致机体正常功能受损，甚至发生疾病。

:::definition{label="染色质三维结构在调控里的位置"}
线性染色质在表观遗传作用（自身修饰如胞嘧啶甲基化、组蛋白及多种修饰、非编码 $\mathrm{RNA}$）下，组装成致密但动态可变的三维结构。反式作用因子局部或远程互作，调控染色质重塑，改变可及性，从而精确调控基因表达。
:::

:::definition{label="染色质重塑"}
染色质重塑（chromatin remodeling）：在反式作用因子局部或远程互作等作用下，改变染色质的致密／开放状态。它是三维构象通往基因表达的中间环节。
:::

:::definition{label="染色质可及性"}
染色质可及性（chromatin accessibility）：转录装置能不能碰到那段 $\mathrm{DNA}$。三维构象和重塑改变的就是可及性。
:::

:::insight{label="这一节问的是「空间上谁挨着谁」，不是「这段 DNA 的碱基顺序」"}
第三节已经能把序列读出来。增强子和启动子在一维上可能隔很远，三维上却被蛋白质复合物拉到一起。构象捕获先交联「当时靠近」的 $\mathrm{DNA}$–蛋白质、蛋白质–蛋白质，再酶切、连接，把空间邻近写成一条嵌合 $\mathrm{DNA}$ 片段。
:::

:::pitfall{label="染色质构象捕获不是 ChIP 的别名"}
$\mathrm{ChIP}$ 问「这个蛋白质绑在哪些 $\mathrm{DNA}$ 片段上」。$3\mathrm{C}$ 一族问「哪些 $\mathrm{DNA}$ 片段当时在空间上靠近」（中间往往隔着蛋白质）。$\mathrm{ChIA}$-$\mathrm{PET}$ 才在构象捕获上再加一层免疫沉淀，不要把五条技术都写成 $\mathrm{ChIP}$。
:::

解析染色质高级构象，可以借助染色质构象捕获（chromatin conformation capture，$3\mathrm{C}$）技术：将染色质中的 $\mathrm{DNA}$-蛋白质、蛋白质-蛋白质复合物用化学交联予以固定，经酶切、连接、纯化，获得空间位置接近的 $\mathrm{DNA}$ 序列片段，通过对这些片段的 $\mathrm{PCR}$ 扩增产物的定性和定量分析，可以推测出染色质的局部空间构象，如图18-8 所示。基于 $3\mathrm{C}$ 扩展的环状染色质构象捕获技术（circular $3\mathrm{C}$，$4\mathrm{C}$）、染色质构象捕获碳拷贝技术（$3\mathrm{C}$ carbon copy，$5\mathrm{C}$）、高通量染色质构象捕获技术（high-throughput $3\mathrm{C}$，$\mathrm{Hi}$-$\mathrm{C}$）等技术，可以从单个位点构象捕获延伸到全基因组远程相互作用。并与免疫共沉淀（如 $\mathrm{ChIA}$-$\mathrm{PET}$）、核酸杂交、单细胞、高通量测序技术和生物信息学分析偶联，极大推动了染色质构象分析技术在基因时空特异性表达调控中的研究。

::figure{src="/images/biochemistry/textbook/p0381_01.png" caption="图18-8　几种染色质构象捕获技术的异同。顶部为核小体链成环、蛋白质复合物拉近远距离 DNA 后交联。中路：酶切消化、连接、逆转交联，3C 用成对引物 PCR 扩增。左路：ChIA-PET 对靶序列免疫沉淀、超声、加接头、连接，逆转交联后配对末端测序；其下 4C 走逆 PCR，再芯片检测。右路：Hi-C 用生物素标记连接位点，逆转交联、超声、亲和素捕获后配对末端测序；其下 5C 走变性 PCR 扩增再测序。左右不是同一种技术。" alt="交联后分出 ChIA-PET 与 4C、3C、Hi-C 与 5C 五条读出路线"}

:::definition{label="3C"}
染色质构象捕获（chromatin conformation capture，$3\mathrm{C}$）：化学交联固定染色质中的 $\mathrm{DNA}$-蛋白质、蛋白质-蛋白质复合物 $\rightarrow$ 酶切、连接、纯化，得到空间位置接近的 $\mathrm{DNA}$ 片段 $\rightarrow$ 对 $\mathrm{PCR}$ 扩增产物定性、定量，推测局部空间构象。图18-8 中路：酶切消化 $\rightarrow$ 连接 $\rightarrow$ 逆转交联 $\rightarrow$ 成对引物 $\mathrm{PCR}$ 扩增。
:::

:::definition{label="4C"}
环状染色质构象捕获（circular $3\mathrm{C}$，$4\mathrm{C}$）：在 $3\mathrm{C}$ 基础上扩展。图18-8 左下：逆 $\mathrm{PCR}$ 之后用芯片检测。问的是某一个位点（诱饵）在全基因组（或阵列覆盖范围）里还和谁成环，而不是只对预先选定的另一端做一对引物的 $\mathrm{PCR}$。
:::

:::definition{label="5C"}
染色质构象捕获碳拷贝（$3\mathrm{C}$ carbon copy，$5\mathrm{C}$）：在 $3\mathrm{C}$ 基础上扩展。图18-8 右下：变性 $\mathrm{PCR}$ 扩增后测序。把多对相互作用同时拷贝出来，而不是中路 $3\mathrm{C}$ 那种「一对引物看一个接触」。
:::

:::definition{label="Hi-C"}
高通量染色质构象捕获（high-throughput $3\mathrm{C}$，$\mathrm{Hi}$-$\mathrm{C}$）：从单个位点构象捕获延伸到全基因组远程相互作用。图18-8 右路：生物素标记连接位点 $\rightarrow$ 逆转交联、超声处理、亲和素捕获 $\rightarrow$ 配对末端测序。生物素打在连接点上，才能把真正被连接的嵌合片段从碎片里捞出来。
:::

:::definition{label="ChIA-PET"}
配对末端标签测序的染色质相互作用分析（$\mathrm{ChIA}$-$\mathrm{PET}$）：构象捕获与免疫共沉淀偶联。图18-8 左路：针对靶序列（蛋白质）免疫沉淀，超声处理、加接头、连接，逆转交联后做配对末端测序。先问「这个蛋白质在场的接触」，再测两端是哪两段 $\mathrm{DNA}$。
:::

:::insight{label="图18-8 要分户：中路 3C，左路 ChIA-PET 和 4C，右路 Hi-C 和 5C"}
五条技术共享顶部的「交联把空间邻近冻住」。分歧从交联之后开始：中路不免疫沉淀、不打生物素，酶切连接后用 $\mathrm{PCR}$ 看预定的那一对位点，这是 $3\mathrm{C}$。左路多了抗体和接头，走 $\mathrm{ChIA}$-$\mathrm{PET}$ 的配对末端测序，其下另开 $4\mathrm{C}$ 的逆 $\mathrm{PCR}$ $+$ 芯片。右路多了生物素标记连接位点 $+$ 亲和捕获，走 $\mathrm{Hi}$-$\mathrm{C}$ 的配对末端测序，其下另开 $5\mathrm{C}$ 的变性 $\mathrm{PCR}$ $+$ 测序。看见一张总图，不要把左右并成「都叫 $\mathrm{Hi}$-$\mathrm{C}$」。
:::

:::compare{title="3C 一族五条读出"}
| | 交联 | 酶切／连接 | 额外抓住方式 | 读出 | 范围（教材定性） |
|--|------|-----------|--------------|------|------------------|
| $3\mathrm{C}$ | 有 | 有 | 无 | 成对引物 $\mathrm{PCR}$ | 局部、预定位点 |
| $4\mathrm{C}$ | 有 | 有（环状） | 无（图上走逆 $\mathrm{PCR}$） | 逆 $\mathrm{PCR}$ $+$ 芯片 | 从单个位点扩开 |
| $5\mathrm{C}$ | 有 | 有 | 无（图上走变性 $\mathrm{PCR}$） | 变性 $\mathrm{PCR}$ $+$ 测序 | 多对接触的碳拷贝 |
| $\mathrm{Hi}$-$\mathrm{C}$ | 有 | 有 | 生物素标记连接位点，亲和素捕获 | 配对末端测序 | 全基因组远程 |
| $\mathrm{ChIA}$-$\mathrm{PET}$ | 有 | 有（加接头） | 靶蛋白质免疫沉淀 | 配对末端测序 | 该蛋白质在场的接触 |

「扩展」指读出和覆盖范围，不是把五种写成同一次 $\mathrm{PCR}$。
:::

:::keypoint{label="从单位点到全基因组，教材原句怎么走"}
- $3\mathrm{C}$：局部空间构象，$\mathrm{PCR}$ 定性定量。
- $4\mathrm{C}$、$5\mathrm{C}$、$\mathrm{Hi}$-$\mathrm{C}$：从单个位点构象捕获延伸到全基因组远程相互作用。
- 再与免疫共沉淀（如 $\mathrm{ChIA}$-$\mathrm{PET}$）、核酸杂交、单细胞、高通量测序、生物信息学偶联。

偶联对象写在「并与……偶联」，不是 $3\mathrm{C}$ 的同义词。
:::

:::pitfall{label="4C 的「环状」不是纳米孔，也不是第四节开头的测序仪"}
$4\mathrm{C}$ 是 circular $3\mathrm{C}$：连接产物成环后从已知诱饵做逆 $\mathrm{PCR}$。不要写成第三节的单分子纳米孔，也不要把「连接」理解成测序仪上的连接酶读序。
:::

:::pitfall{label="Hi-C 的生物素打在连接位点上，ChIA-PET 的抗体认的是蛋白质"}
右路亲和捕获靠生物素–亲和素，捞的是被连接过的 $\mathrm{DNA}$ 接头。左路免疫沉淀认的是靶蛋白质。两个「捞」的化学不同：一个捞连接事件，一个捞蛋白质在场的事件。
:::

:::pitfall{label="染色质构象捕获可以解释时空表达，但实验本身仍是互作"}
本版把 $3\mathrm{C}$ 写进基因表达分析的大背景下，因为它改变可及性、参与精确调控。方法学户头仍是交联后的 $\mathrm{DNA}$–蛋白质、蛋白质–蛋白质邻近。第五节不再把这张图重写一遍，只在表达分析的策略里点到「构象已经能抓」。
:::

:::cause-effect{title="构象乱了为什么会致病"}
- **因** 三维结构通过重塑改变可及性，协助完成基因表达的精确调控
- **果** 该过程异常或紊乱，机体正常功能受损，甚至发生疾病——所以医学上要解析高级构象，而不是只测一维序列
:::

:::compare{title="EMSA、ChIP、3C 问的不是同一件事"}
| | $\mathrm{EMSA}$ | $\mathrm{ChIP}$ | $3\mathrm{C}$ 一族 |
|--|----------------|---------------|-------------------|
| 主要问题 | 这段探针体外能不能被蛋白质抓住 | 活细胞里这个蛋白质当时绑在哪些 $\mathrm{DNA}$ 上 | 哪些 $\mathrm{DNA}$ 片段当时在空间上靠近 |
| 交联 | 无 | 有 | 有 |
| 抗体 | 无 | 有（$\mathrm{ChIP}$-chip／seq 仍有） | $3\mathrm{C}$/$4\mathrm{C}$/$5\mathrm{C}$/$\mathrm{Hi}$-$\mathrm{C}$ 无；$\mathrm{ChIA}$-$\mathrm{PET}$ 有 |
| 读出 | 非变性胶滞后 | 沉淀 $\mathrm{DNA}$ 的序列／芯片／测序 | $\mathrm{PCR}$、芯片、配对末端测序等 |

三种都可以出现在「基因表达调控」试卷上，化学从第一问就要分开。
:::

:::memory{label="本节相互作用一张清单"}
- 复合物：共价连接、稳定沉淀或可逆结合；复制、转录、翻译与分泌、信号、代谢都靠它。
- 蛋白质–蛋白质：牵拉沉淀 $=$ 体外、标签钓饵、珠子、电泳共沉淀；最常用 $\mathrm{GST}$-$\mathrm{GSH}$（大肠埃希菌表达），也可用 $6\times\mathrm{His}$-镍；游离 $\mathrm{GSH}$ 竞争洗脱。酵母双杂交 $=$ $\mathrm{GAL4}$ 的 $\mathrm{BD}+\mathrm{AD}$ 分开则不能激活，融上互作的一对蛋白质就重组装；诱饵筛猎物文库。
- 蛋白质–核酸：弱、可逆。温和 $\rightarrow$ $\mathrm{EMSA}$（标记探针，核提取物，非变性 $\mathrm{PAGE}$ 不加 $\mathrm{SDS}$，条带滞后）。交联 $\rightarrow$ $\mathrm{ChIP}$（活细胞交联、切断、抗体沉淀、序列分析）。联用：$\mathrm{ChIP}$-chip、$\mathrm{ChIP}$-seq（结合位点 $+$ 位点特异性组蛋白修饰）。
- 染色质三维：交联 $\rightarrow$ 酶切连接。$3\mathrm{C}$ 局部 $\mathrm{PCR}$；$4\mathrm{C}$ 逆 $\mathrm{PCR}$ $+$ 芯片；$5\mathrm{C}$ 变性 $\mathrm{PCR}$ $+$ 测序；$\mathrm{Hi}$-$\mathrm{C}$ 生物素连接位点 $+$ 配对末端测序；$\mathrm{ChIA}$-$\mathrm{PET}$ 免疫沉淀 $+$ 配对末端测序。图18-8 左右分户。
- 不是测序课，不是干扰素翻译抑制。
:::

:::memory{label="三张胶／珠子／抗体不要混"}
- 牵拉沉淀：认标签的珠子，胶上看共沉淀蛋白质。
- $\mathrm{EMSA}$：认的是标记探针，胶上看滞后。
- $\mathrm{ChIP}$：认的是抗体，后面读 $\mathrm{DNA}$ 序列。
:::
