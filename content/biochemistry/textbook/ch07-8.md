# 第八节　血糖及其调节

前七节把葡萄糖的来路、去路和旁路逐条写完。本节把它们收成血中的那一笔浓度：来源是肠道吸收、肝糖原分解和糖异生，去路是氧化、合成糖原、转变成甘油三酯。空腹维持在 $3.9\sim 6.0\,\mathrm{mmol/L}$，靠胰岛素降糖、胰高血糖素／糖皮质激素／肾上腺素升糖。糖代谢失调表现为低血糖、高血糖和糖尿病；高糖还通过非酶糖化生成晚期糖化终产物损伤细胞。

血糖（blood glucose）指血中的葡萄糖。血糖的来源为肠道吸收、肝糖原分解和糖异生生成的葡萄糖释入血液内。血糖的去路则是被机体各组织器官摄取，用于氧化供能、合成糖原、转变成甘油三酯等。

:::definition{label="血糖"}
血糖（blood glucose）指血中的葡萄糖。来源：肠道吸收、肝糖原分解、糖异生释入血液。去路：各组织摄取后氧化供能、合成糖原、转变成甘油三酯等。
:::

:::concept{term="先问来源与去路是否配平，再问哪一种激素在拨开关"}
浓度本身只是结果。餐后、空腹、饥饿三套来源不同，去路也跟着开或关。激素不另造一条代谢途径，只是整合前七节已经出现的关键酶。
:::

## 一、血糖水平保持恒定

空腹血糖水平相当恒定，始终维持在 $3.9\sim 6.0\,\mathrm{mmol/L}$，这是由于血糖的来源与去路保持动态平衡所致：①餐后血糖主要来自食物消化吸收，此时所有去路均保持活跃，用于供能与合成各种储备。②空腹时，血糖主要来自肝糖原分解，仅用于满足基本供能需求。③饥饿时，血糖主要来自非糖物质的糖异生，此时除少数对葡萄糖极为依赖的组织仍用糖供能外，其他大多数组织改用脂肪能源，以节约葡萄糖。总之，恒定的血糖水平是糖、脂肪、氨基酸代谢相协调的结果，也是肝、肌、脂肪组织等器官代谢相协调的结果。

:::definition{label="空腹血糖的恒定范围"}
空腹血糖始终维持在 $3.9\sim 6.0\,\mathrm{mmol/L}$。这是来源与去路动态平衡的结果，不是某一条途径单独锁死的浓度。
:::

:::compare{title="餐后、空腹、饥饿三套来源与去路"}
| 状态 | 主要来源 | 去路 | 节约策略 |
|------|----------|------|----------|
| 餐后 | 食物消化吸收 | 全部活跃：供能 $+$ 合成糖原、甘油三酯等储备 | 把多余血糖写成储备 |
| 空腹 | 肝糖原分解 | 仅满足基本供能 | 不靠肠道，也不急着拆蛋白质 |
| 饥饿 | 非糖物质的糖异生 | 脑、红细胞等仍用糖；大多数组织改用脂肪 | 节约葡萄糖 |

恒定是糖、脂肪、氨基酸代谢协调，也是肝、肌、脂肪组织协调。
:::

:::pitfall{label="空腹不是饥饿，肝糖原也不是异生"}
空腹主账是肝糖原分解（第五节）。饥饿、肝糖原耗尽后才换糖异生（第六节，$16\sim 24$ 小时）。把三套来源并成“血糖都来自肝”，餐后肠道吸收那一笔会丢。
:::

:::insight{label="大多数组织改用脂肪，是为了把糖留给少数组织"}
饥饿时异生补给有限。脑、红细胞、骨髓、视网膜、神经仍要糖；其他组织切换脂肪，不是“全身都不需要葡萄糖了”。第八节后文低血糖休克，户头仍在脑依赖葡萄糖。
:::

## 二、血糖稳态主要受激素调节

调节血糖的激素主要有胰岛素、胰高血糖素、肾上腺素和糖皮质激素等。这些激素整合调节多种组织中若干代谢途径的关键酶，不断适应体内能量需求和燃料供给的变化，从而维持血糖稳态。

:::keypoint{label="调节血糖的激素名单"}
- 降糖：胰岛素（餐后主要激素）。
- 升糖：胰高血糖素（饥饿时主要）、糖皮质激素、肾上腺素（应激时强有力）。
- 手段：整合前七节关键酶，不另开一条糖代谢途径。
:::

### （一）胰岛素是降低血糖的主要激素

胰岛素（insulin）由胰岛 $\beta$ 细胞分泌，是餐后降低血糖的主要激素。其降糖机制是使血糖的去路增强、来源减弱，主要包括：①促进肌、脂肪组织等通过 $\mathrm{GLUT}4$ 摄取葡萄糖。②通过激活磷酸二酯酶而降低 $\mathrm{cAMP}$ 水平，使糖原合酶被活化、磷酸化酶被抑制，加速糖原合成、抑制糖原分解。③通过激活丙酮酸脱氢酶磷酸酶而使丙酮酸脱氢酶复合体活化，加快糖的有氧氧化。④抑制肝内糖异生，一方面是因为磷酸烯醇式丙酮酸羧激酶的合成减少，另一方面是由于氨基酸加速合成肌蛋白质从而使糖异生的原料减少。⑤糖的分解产物乙酰 $\mathrm{CoA}$ 和 $\mathrm{NADPH}$ 供应增多，促进合成脂肪酸。简而言之，胰岛素的总效应是促进葡萄糖分解利用，抑制糖异生，同时将多余的血糖转变为糖原（储存于肝和肌）和甘油三酯（储存于脂肪组织），从而控制餐后血糖水平不至于过高。

:::definition{label="胰岛素"}
胰岛素（insulin）由胰岛 $\beta$ 细胞分泌，是餐后降低血糖的主要激素。总效应：去路增强、来源减弱——促进葡萄糖分解利用，抑制糖异生，把多余血糖写成肝／肌糖原和脂肪组织甘油三酯。
:::

:::keypoint{label="胰岛素降糖五笔"}
- 摄取：肌、脂肪等经 $\mathrm{GLUT}4$。
- 糖原：激活磷酸二酯酶，降低 $\mathrm{cAMP}$ → 合酶活、磷酸化酶抑制。
- 有氧氧化：激活丙酮酸脱氢酶磷酸酶 → 丙酮酸脱氢酶复合体活化。
- 异生：磷酸烯醇式丙酮酸羧激酶合成减少；氨基酸改去合成肌蛋白，原料减少。
- 脂肪：乙酰 $\mathrm{CoA}$ 和 $\mathrm{NADPH}$ 增多，促进脂肪酸合成。
:::

:::pitfall{label="胰岛素降低 cAMP，不是再走一遍 PKA 级联"}
第五节胰高血糖素／肾上腺素经 $\mathrm{cAMP}$、蛋白质激酶 $\mathrm{A}$ 把合酶关掉、磷酸化酶打开。胰岛素激活磷酸二酯酶，把 $\mathrm{cAMP}$ 水解掉，级联撤掉，方向相反。不要把胰岛素也写成“激活腺苷酸环化酶”。
:::

:::compare{title="胰岛素对来源和去路"}
| 方向 | 具体落点 |
|------|----------|
| 去路增强 | $\mathrm{GLUT}4$ 摄取；糖原合成；有氧氧化；脂肪酸合成 |
| 来源减弱 | 糖原分解抑制；肝糖异生抑制（酶量 $+$ 原料） |
:::

### （二）体内有多种升高血糖的激素

饥饿或应激等状况发生时，机体可分泌多种升高血糖的激素。

**1. 胰高血糖素是主要的升糖激素**　胰高血糖素（glucagon）由胰岛 $\alpha$ 细胞分泌，是饥饿时升高血糖的主要激素。其升糖机制是通过 $\mathrm{cAMP}$ 依赖的磷酸化反应，使血糖的来源增强、去路减弱，主要包括：①激活磷酸化酶而抑制糖原合酶，加速肝糖原分解。②通过激活果糖二磷酸酶-2、抑制磷酸果糖激酶-2，使果糖-2,6-二磷酸的合成减少，进而抑制糖酵解、促进糖异生。③抑制肝内丙酮酸激酶，使糖酵解减慢；同时促进磷酸烯醇式丙酮酸羧激酶的合成，使糖异生加强。④激活脂肪组织内激素敏感性脂肪酶，促进脂肪分解供能，以节约血糖。简而言之，胰高血糖素的总效应是促进肝糖原分解和糖异生，同时抑制糖酵解而改用脂肪供能，从而控制饥饿时血糖水平不至于过低。

:::definition{label="胰高血糖素"}
胰高血糖素（glucagon）由胰岛 $\alpha$ 细胞分泌，是饥饿时升高血糖的主要激素。经 $\mathrm{cAMP}$ 依赖的磷酸化，来源增强、去路减弱：开肝糖原分解和糖异生，关糖酵解，动员脂肪节约血糖。
:::

:::keypoint{label="胰高血糖素升糖四笔"}
- 肝糖原：磷酸化酶开、合酶关。
- 果糖-2,6-二磷酸：果糖二磷酸酶-2 开、磷酸果糖激酶-2 关 → 酵解关、异生开（与第六节同一开关）。
- 丙酮酸激酶抑制；磷酸烯醇式丙酮酸羧激酶合成增多。
- 脂肪组织激素敏感性脂肪酶激活，改用脂肪。
:::

**2. 糖皮质激素可升高血糖**　糖皮质激素（glucocorticoid）的升糖机制主要包括：①促进肌蛋白质分解而使糖异生的原料增多，同时促进合成磷酸烯醇式丙酮酸羧激酶，从而加速糖异生。②通过抑制丙酮酸的氧化脱羧，使葡萄糖分解利用减少。③协同增强其他激素促进脂肪动员的效应，切换为脂肪供能。

:::definition{label="糖皮质激素升糖"}
糖皮质激素（glucocorticoid）升糖：拆肌蛋白增加异生原料，并促进磷酸烯醇式丙酮酸羧激酶合成；抑制丙酮酸氧化脱羧，减少糖的利用；协同其他激素动员脂肪。
:::

**3. 肾上腺素是强有力的升糖激素**　肾上腺素（adrenaline 或 epinephrine）主要在应激状态下发挥作用，它升高血糖的效力很强。给动物注射肾上腺素后，血糖水平迅速升高且持续几小时，同时血中乳酸水平也升高。肾上腺素的升糖机制是，通过肝和肌细胞内依赖 $\mathrm{cAMP}$ 的磷酸化级联反应，激活磷酸化酶，加速糖原分解。肝糖原分解为葡萄糖，直接升高血糖；肌糖原无氧氧化生成乳酸，再经乳酸循环间接升高血糖。

:::definition{label="肾上腺素升糖"}
肾上腺素（adrenaline / epinephrine）主要在应激时发挥作用，升糖效力强。肝、肌均走 $\mathrm{cAMP}$ 磷酸化级联激活磷酸化酶。肝糖原 → 葡萄糖，直接升血糖；肌糖原 → 乳酸 → 乳酸循环，间接升血糖。注射后血糖迅速升高并持续几小时，血乳酸也升高。
:::

:::compare{title="三种升糖激素"}
| 项目 | 胰高血糖素 | 糖皮质激素 | 肾上腺素 |
|------|------------|------------|----------|
| 场合 | 饥饿时主要升糖激素 | 协同升糖 | 应激，效力强 |
| 来源 | 胰岛 $\alpha$ 细胞 | （本章不展开腺体来源） | 应激分泌 |
| 肝糖原 | $\mathrm{cAMP}$ 级联分解 | 不是主账 | $\mathrm{cAMP}$ 级联分解，直接成葡萄糖 |
| 肌糖原 | 不是主账 | 拆蛋白供异生原料 | 分解成乳酸，经乳酸循环间接升糖 |
| 异生 | 降果糖-2,6-二磷酸；诱导磷酸烯醇式丙酮酸羧激酶；关丙酮酸激酶 | 原料 $+$ 磷酸烯醇式丙酮酸羧激酶合成；关丙酮酸氧化脱羧 | 间接（乳酸循环） |
| 脂肪 | 激素敏感性脂肪酶 | 协同增强动员 | —— |
:::

:::pitfall{label="肾上腺素升糖有直接和间接两笔"}
肝：有葡萄糖-6-磷酸酶，糖原分解直接成血糖。肌：没有此酶，产物是乳酸，要经第六节乳酸循环才变成血糖。只记“肾上腺素分解糖原”，会漏掉血乳酸升高和间接那一圈。
:::

### （三）胰岛素和胰高血糖素的分泌呈反相关

在饥饿-进食循环中，血糖水平双向调节胰岛的分泌功能，使血中胰岛素和胰高血糖素的水平反相关：①餐后血糖水平升高，引起胰岛素分泌增多。其促分泌机制是，胰岛 $\beta$ 细胞借助 $\mathrm{GLUT}2$ 摄取高浓度的血糖，再经葡萄糖激酶催化，使进入糖酵解的代谢流量增大、产生 $\mathrm{ATP}$ 增多，导致细胞膜上 $\mathrm{ATP}$ 调控的 $\mathrm{K}^{+}$ 通道关闭。$\mathrm{K}^{+}$ 外流减少使 $\beta$ 细胞膜去极化，引起细胞膜上电压调控的 $\mathrm{Ca}^{2+}$ 通道开放。$\mathrm{Ca}^{2+}$ 流入触发 $\beta$ 细胞外排释放胰岛素。而此时，胰高血糖素的分泌则被抑制。②饥饿时血糖水平降低，使胰岛 $\alpha$ 细胞分泌胰高血糖素增多。此时胰岛素的分泌水平虽显著降低，但仍有少量分泌，以适当发挥拮抗作用，避免升糖过度。

总之，饥饿-进食循环中的血糖变化，引起血中胰岛素与胰高血糖素的比值动态变化，再进一步调节血糖，使血糖在正常范围内保持较小幅度的波动。

:::timeline{period="餐后 β 细胞释放胰岛素"}
- **GLUT2 摄取** 胰岛 β 细胞摄入高浓度血糖
- **葡萄糖激酶** 酵解流量增大，ATP 增多
- **K+ 通道关闭** ATP 调控的 K+ 通道关闭，K+ 外流减少，膜去极化
- **Ca2+ 流入** 电压调控的 Ca2+ 通道开放，触发胰岛素外排；此时胰高血糖素分泌被抑制
:::

:::definition{label="胰岛素与胰高血糖素反相关"}
饥饿-进食循环中，血糖双向调节胰岛：餐后胰岛素升、胰高血糖素被抑制；饥饿时胰高血糖素升，胰岛素显著降低但仍有少量，避免升糖过度。真正拨血糖的是二者比值，不是单一激素的有无。
:::

:::pitfall{label="β 细胞用 GLUT2 和葡萄糖激酶，不是 GLUT4"}
组织摄取看胰岛素诱导的 $\mathrm{GLUT}4$（肌、脂肪）。$\beta$ 细胞感知血糖用 $\mathrm{GLUT}2$ 加葡萄糖激酶，再靠 $\mathrm{ATP}$ 关钾通道。把 $\mathrm{GLUT}4$ 写进胰岛，感知机制和外周摄取会并户。
:::

:::insight{label="饥饿时胰岛素不是零"}
教材写明：胰岛素显著降低，但仍有少量分泌，适当拮抗，避免升糖过度。把“饥饿＝胰岛素关死”写成绝对，胰高血糖素会没有刹车。
:::

## 三、糖代谢障碍导致血糖水平异常

正常人体内存在一整套精细的糖代谢调节机制，当一次性食入大量葡萄糖后，血糖水平不会持续升高，也不会出现大的波动。若糖代谢失调，将造成血糖水平紊乱，出现低血糖或高血糖。

### （一）口服葡萄糖耐量试验检测糖代谢调节异常

口服葡萄糖耐量试验（oral glucose tolerance test，$\mathrm{OGTT}$）是一种葡萄糖负荷试验，用于检测机体对糖代谢的调节能力。先测量空腹静脉血糖，成人饮用 $75\,\mathrm{g}$ 无水葡萄糖后，分别于 $30$ 分钟、$1$ 小时、$2$ 小时、$3$ 小时测量静脉血糖值，绘制曲线。正常人对摄入的葡萄糖有很强的耐受能力：服糖后血糖在 $0.5\sim 1$ 小时达到高峰，但一般不超过肾小管的重吸收能力（约为 $10\,\mathrm{mmol/L}$，称为肾糖阈），所以很难检测到糖尿；血糖在此峰值之后逐渐降低，$2$ 小时可降至 $7.8\,\mathrm{mmol/L}$ 以下，$3$ 小时恢复到空腹血糖水平。

糖尿病患者出现糖耐量异常，表现在：空腹血糖高于正常值；服糖后血糖浓度急剧升高，超过肾糖阈，导致糖尿；血糖在此峰值之后缓慢降低，一般 $2$ 小时后仍可高于 $11.1\,\mathrm{mmol/L}$。

:::definition{label="口服葡萄糖耐量试验"}
口服葡萄糖耐量试验（oral glucose tolerance test，$\mathrm{OGTT}$）是葡萄糖负荷试验，检测机体对糖代谢的调节能力。先测空腹静脉血糖，成人饮用 $75\,\mathrm{g}$ 无水葡萄糖，于 $30$ 分钟、$1$ 小时、$2$ 小时、$3$ 小时再测，绘制曲线。
:::

:::definition{label="肾糖阈"}
肾糖阈约为 $10\,\mathrm{mmol/L}$，即肾小管重吸收葡萄糖的能力上限。血糖一般不超过此值，很难检测到糖尿；超过则出现糖尿。
:::

:::compare{title="OGTT：正常人与糖尿病"}
| 项目 | 正常人 | 糖尿病糖耐量异常 |
|------|--------|------------------|
| 空腹 | $3.9\sim 6.0\,\mathrm{mmol/L}$ 范围内 | 高于正常值 |
| 峰时 | 服糖后 $0.5\sim 1$ 小时 | 急剧升高 |
| 与肾糖阈（约 $10\,\mathrm{mmol/L}$） | 一般不超过，很难检测到糖尿 | 超过，出现糖尿 |
| $2$ 小时 | 可降至 $7.8\,\mathrm{mmol/L}$ 以下 | 一般仍可高于 $11.1\,\mathrm{mmol/L}$ |
| $3$ 小时 | 恢复到空腹水平 | 下降缓慢 |
:::

:::pitfall{label="2 小时 7.8 和 11.1 不要记反"}
正常人 $\mathrm{OGTT}$ $2$ 小时 $<7.8\,\mathrm{mmol/L}$。糖尿病教材写成 $2$ 小时仍可高于 $11.1\,\mathrm{mmol/L}$。肾糖阈约 $10\,\mathrm{mmol/L}$ 是糖尿出不出现的门槛，不是这两条曲线的 $2$ 小时切点。
:::

### （二）低血糖是指血糖浓度低于 2.8 mmol/L

对于健康人群，血糖浓度低于 $2.8\,\mathrm{mmol/L}$ 时称为低血糖（hypoglycemia）。脑细胞主要依赖葡萄糖氧化供能，因此血糖过低就会影响脑的正常功能，出现头晕、倦怠无力、心悸等，严重时发生昏迷，称为低血糖休克。如不及时给患者静脉补充葡萄糖，可导致死亡。出现低血糖的病因有：①胰性（胰岛 $\beta$ 细胞功能亢进、胰岛 $\alpha$ 细胞功能低下等）；②肝性（肝癌、糖原贮积症等）；③内分泌异常（垂体功能低下、肾上腺皮质功能低下等）；④肿瘤（胃癌等）；⑤饥饿或不能进食者等。

:::definition{label="低血糖"}
健康人群血糖浓度低于 $2.8\,\mathrm{mmol/L}$ 称为低血糖（hypoglycemia）。脑依赖葡萄糖，过低则头晕、倦怠无力、心悸，严重昏迷为低血糖休克；不及时静脉补充葡萄糖可致死。
:::

:::keypoint{label="低血糖病因五类"}
- 胰性：胰岛 $\beta$ 细胞功能亢进、$\alpha$ 细胞功能低下等。
- 肝性：肝癌、糖原贮积症等。
- 内分泌异常：垂体功能低下、肾上腺皮质功能低下等。
- 肿瘤：胃癌等。
- 饥饿或不能进食者等。
:::

:::cause-effect{title="为什么低血糖先打在脑上"}
- **因** 脑细胞主要依赖葡萄糖氧化供能（第六节：己糖激酶 $K_\mathrm{m}$ 低，血糖偏低仍要用糖）
- **果** 血糖过低首先影响脑功能，可至低血糖休克；处理是及时静脉补葡萄糖
:::

### （三）高血糖是指空腹血糖高于 7 mmol/L

空腹血糖浓度高于 $7\,\mathrm{mmol/L}$，称为高血糖（hyperglycemia）。如果血糖浓度高于肾糖阈，就会形成糖尿。引起糖尿的原因分为病理性和生理性两大类，具体包括：①遗传性胰岛素受体缺陷；②某些慢性肾炎、肾病综合征等引起肾对糖的重吸收障碍，但血糖及糖耐量曲线均正常；③情绪激动时交感神经兴奋，肾上腺素分泌增加，使肝糖原大量分解，导致生理性高血糖和糖尿；④临床上静脉滴注葡萄糖速度过快，使血糖迅速升高而出现糖尿。

:::definition{label="高血糖"}
空腹血糖浓度高于 $7\,\mathrm{mmol/L}$ 称为高血糖（hyperglycemia）。高于肾糖阈则形成糖尿。糖尿可来自病理性或生理性原因，不一定等于糖尿病。
:::

:::compare{title="糖尿不一定先有高血糖"}
| 类型 | 机制 | 血糖／糖耐量 |
|------|------|----------------|
| 遗传性胰岛素受体缺陷 | 胰岛素不能有效降糖 | 高血糖，可超过肾糖阈 |
| 慢性肾炎、肾病综合征等 | 肾重吸收障碍 | 血糖及糖耐量曲线均正常 |
| 情绪激动 | 肾上腺素使肝糖原大量分解 | 生理性高血糖和糖尿 |
| 静脉滴注葡萄糖过快 | 血糖迅速升高 | 一过性糖尿 |
:::

:::pitfall{label="肾性糖尿血糖可以正常"}
慢性肾炎、肾病综合征等可以在血糖和糖耐量都正常时出现糖尿，因为门槛在肾小管重吸收，不在代谢调节。看见糖尿不要直接写成糖尿病或高血糖。
:::

### （四）糖尿病是最常见的糖代谢紊乱疾病

糖尿病（diabetes mellitus）的特征是持续性高血糖和糖尿，特别是空腹血糖和糖耐量曲线高于正常范围。其主要病因是部分或完全缺失胰岛素、胰岛素抵抗（因细胞胰岛素受体减少或受体敏感性降低，导致对胰岛素的调节作用不敏感）。临床上将糖尿病分为四型：胰岛素依赖型（$1$ 型）、非胰岛素依赖型（$2$ 型）、妊娠糖尿病和特殊类型糖尿病。$1$ 型糖尿病多发生于青少年，因自身免疫而使胰岛 $\beta$ 细胞功能缺陷，导致胰岛素分泌不足。$2$ 型糖尿病和肥胖关系密切，可能是由细胞膜上胰岛素受体功能缺陷所致。

糖尿病常伴有多种并发症，如糖尿病视网膜病变、糖尿病性周围神经病变、糖尿病周围血管病变、糖尿病肾病等。这些并发症的严重程度与血糖水平升高的程度、病史的长短有相关性。

:::definition{label="糖尿病"}
糖尿病（diabetes mellitus）特征是持续性高血糖和糖尿，空腹血糖和糖耐量曲线高于正常范围。主要病因：胰岛素部分或完全缺失，或胰岛素抵抗（受体减少或敏感性降低）。
:::

:::compare{title="本版四型糖尿病"}
| 分型 | 教材要点 |
|------|----------|
| $1$ 型（胰岛素依赖型） | 多见于青少年；自身免疫致胰岛 $\beta$ 细胞功能缺陷，胰岛素分泌不足 |
| $2$ 型（非胰岛素依赖型） | 与肥胖关系密切；可能是细胞膜胰岛素受体功能缺陷 |
| 妊娠糖尿病 | 列入四型，本章不展开机制 |
| 特殊类型糖尿病 | 列入四型，本章不展开机制 |
:::

:::keypoint{label="并发症与血糖、病程相关"}
- 糖尿病视网膜病变。
- 糖尿病性周围神经病变。
- 糖尿病周围血管病变。
- 糖尿病肾病。
- 严重程度与血糖升高程度、病史长短有相关性。生化机制见下一节晚期糖化终产物。
:::

:::pitfall{label="2 型不是“没有胰岛素”"}
$1$ 型是 $\beta$ 细胞缺陷、分泌不足。$2$ 型教材落到受体功能缺陷、胰岛素抵抗，并与肥胖相关。把二型也写成“胰岛完全不分泌”，和“非胰岛素依赖”对不上。
:::

## 四、高糖对细胞具有损伤效应

引起糖尿病并发症的生化机制仍不太清楚，可能与高血糖刺激细胞生成晚期糖化终产物（advanced glycation end product，$\mathrm{AGE}$）有关。例如，红细胞通过 $\mathrm{GLUT}1$ 摄取血中的葡萄糖，首先使血红蛋白的氨基发生不依赖酶的糖化作用（hemoglobin glycation），生成糖化血红蛋白（glycated hemoglobin，$\mathrm{GHB}$），此过程与酶催化的糖基化反应（glycosylation）不同。$\mathrm{GHB}$ 可进一步反应生成 $\mathrm{AGE}$（如羧甲基赖氨酸等），并从红细胞释出，产生两方面效应：① $\mathrm{AGE}$ 与体内多种蛋白质发生广泛的共价交联，对肾、视网膜、心血管等造成损伤。② $\mathrm{AGE}$ 被其细胞膜受体（$\mathrm{RAGE}$）识别，激活转录因子 $\mathrm{NF}$-$\kappa\mathrm{B}$，促进炎性因子表达。

:::definition{label="晚期糖化终产物"}
晚期糖化终产物（advanced glycation end product，$\mathrm{AGE}$）可由高血糖刺激细胞生成。红细胞经 $\mathrm{GLUT}1$ 摄取葡萄糖后，血红蛋白氨基发生不依赖酶的糖化作用，生成糖化血红蛋白，再进一步变成 $\mathrm{AGE}$（如羧甲基赖氨酸等）并释出。
:::

:::definition{label="糖化作用与糖基化"}
血红蛋白糖化（hemoglobin glycation）不依赖酶，生成糖化血红蛋白（glycated hemoglobin，$\mathrm{GHB}$）。酶催化的糖基化反应（glycosylation）是另一本账。不要把 $\mathrm{GHB}$ 写成糖基化血红蛋白。
:::

:::compare{title="AGE 的两笔效应"}
| 途径 | 机制 | 落点 |
|------|------|------|
| 共价交联 | $\mathrm{AGE}$ 与多种蛋白质广泛交联 | 肾、视网膜、心血管损伤 |
| 受体通路 | 细胞膜受体 $\mathrm{RAGE}$ 识别 $\mathrm{AGE}$，激活 $\mathrm{NF}$-$\kappa\mathrm{B}$ | 促进炎性因子表达 |
:::

糖化血红蛋白（$\mathrm{GHB}$）可作为糖尿病的诊治指标。红细胞的寿命约为 $120$ 天，所以检测 $\mathrm{GHB}$ 的数量可反映患者近 $8\sim 12$ 周血糖控制的平均水平，这一相对定量法比基于葡萄糖氧化酶的绝对定量法更稳定、更准确。$\mathrm{GHB}$ 已被用作糖尿病的诊断指标，超过 $6.5\%$ 即为异常；也可用作疗效评价的重要参考，糖尿病的治疗目标是将 $\mathrm{GHB}$ 控制在 $7\%$ 以下。

:::definition{label="糖化血红蛋白作为诊治指标"}
红细胞寿命约 $120$ 天，$\mathrm{GHB}$ 反映近 $8\sim 12$ 周血糖控制的平均水平，比葡萄糖氧化酶绝对定量更稳定、更准确。诊断：超过 $6.5\%$ 为异常。疗效：治疗目标将 $\mathrm{GHB}$ 控制在 $7\%$ 以下。
:::

:::pitfall{label="6.5% 是诊断切点，7% 是治疗目标"}
超过 $6.5\%$ 即为异常（诊断）。治疗要把 $\mathrm{GHB}$ 控制在 $7\%$ 以下（疗效）。两笔不要并成同一个数字。$\mathrm{GHB}$ 也不是“当天血糖”，它平均的是近 $8\sim 12$ 周。
:::

:::example{label="为什么不单靠空腹血糖看控制得好不好"}
空腹血糖和葡萄糖氧化酶法给的是当下浓度。红细胞已经在血里走了约 $120$ 天，血红蛋白持续被非酶糖化，$\mathrm{GHB}$ 把这几个月的平均暴露写成一个百分比。高糖损伤（$\mathrm{AGE}$、交联、$\mathrm{RAGE}$）看的也是长期暴露，不是某一餐后的峰值。
:::

:::memory{label="本节必背要点"}
- [ ] 血糖＝血中葡萄糖；空腹 $3.9\sim 6.0\,\mathrm{mmol/L}$
- [ ] 来源：吸收、肝糖原分解、糖异生；去路：氧化、糖原、甘油三酯
- [ ] 胰岛素降糖：$\mathrm{GLUT}4$、降 $\mathrm{cAMP}$、开有氧氧化、关异生、促脂肪酸合成
- [ ] 胰高血糖素升糖：$\mathrm{cAMP}$ 磷酸化，开肝糖原和异生，关酵解，动员脂肪
- [ ] 肾上腺素：肝直接、肌经乳酸循环间接；糖皮质激素：原料 $+$ 酶量 $+$ 少用糖
- [ ] $\beta$ 细胞：$\mathrm{GLUT}2$—葡萄糖激酶—$\mathrm{ATP}$—关 $\mathrm{K}^{+}$—开 $\mathrm{Ca}^{2+}$；胰岛素与胰高血糖素反相关
- [ ] $\mathrm{OGTT}$：$75\,\mathrm{g}$；正常峰 $0.5\sim 1$ 小时，肾糖阈约 $10$；$2$ 小时 $<7.8$；糖尿病 $2$ 小时可 $>11.1$
- [ ] 低血糖 $<2.8$；高血糖空腹 $>7$；糖尿不等于糖尿病
- [ ] 糖尿病四型；$1$ 型自身免疫分泌不足，$2$ 型肥胖、受体缺陷
- [ ] 非酶糖化 → $\mathrm{GHB}$ → $\mathrm{AGE}$；$\mathrm{GHB}>6.5\%$ 异常，治疗目标 $<7\%$；反映 $8\sim 12$ 周
:::

## 本章小结

糖类消化后主要以单体形式在小肠被吸收。细胞摄取糖需要葡萄糖转运蛋白。葡萄糖进入细胞后，可通过无氧氧化、有氧氧化和戊糖磷酸途径分解，提供能量或其他重要产物；也可储存为糖原形式；体内非糖物质还可异生转化为糖。

糖的无氧氧化是指机体不利用氧将葡萄糖分解为乳酸的过程，在细胞质中分两个阶段进行：葡萄糖先分解为丙酮酸，称为糖酵解；丙酮酸再还原生成乳酸。糖酵解是糖分解的必经之路，其流量调节的关键酶是磷酸果糖激酶-1（尤为重要）、丙酮酸激酶和己糖激酶。糖的无氧氧化可为机体快速供能，$1$ 分子葡萄糖通过底物水平磷酸化净生成 $2$ 分子 $\mathrm{ATP}$。

糖的有氧氧化是指机体利用氧将葡萄糖彻底氧化为 $\mathrm{CO}_2$ 和 $\mathrm{H}_2\mathrm{O}$ 的过程，在细胞质和线粒体中分三个阶段进行：糖酵解、丙酮酸氧化脱羧生成乙酰 $\mathrm{CoA}$（关键酶是丙酮酸脱氢酶复合体）、三羧酸循环。其中，三羧酸循环主要通过偶联氧化磷酸化生成大量 $\mathrm{ATP}$，而经底物水平磷酸化生成的 $\mathrm{ATP}$ 则很少，关键酶是柠檬酸合酶、异柠檬酸脱氢酶和 $\alpha$-酮戊二酸脱氢酶复合体。糖的有氧氧化是主要产能途径，$1$ 分子葡萄糖经有氧氧化可净生成 $30$ 或 $32$ 分子 $\mathrm{ATP}$，主要受能量供需平衡调节。

戊糖磷酸途径发生在细胞质中，不产能而可产生核糖磷酸和 $\mathrm{NADPH}$。关键酶是葡萄糖-6-磷酸脱氢酶，主要受 $\mathrm{NADPH}$ 的供需平衡调节。

肝糖原和肌糖原是体内糖的储存形式。肝糖原在空腹时补充血糖，肌糖原则可通过无氧氧化为肌收缩供能。糖原合成与分解的关键酶分别是糖原合酶和糖原磷酸化酶，二者的酶活性调节彼此相反，主要受磷酸化与去磷酸化修饰调节。

糖异生是指非糖物质在肝和肾转变为葡萄糖或糖原的过程，主要在饥饿时补充血糖。关键酶是丙酮酸羧化酶、磷酸烯醇式丙酮酸羧激酶、果糖二磷酸酶-1 和葡萄糖-6-磷酸酶。糖异生和糖酵解的反向调节主要针对两个底物循环。

血糖水平相对恒定，受多种激素调控。胰岛素可降低血糖，胰高血糖素、糖皮质激素、肾上腺素则可升高血糖。糖代谢紊乱可导致高血糖或低血糖，糖尿病是最常见的糖代谢紊乱疾病。

:::keypoint{label="本章小结按途径收口"}
- 摄取：单体吸收；$\mathrm{SGLT}$／$\mathrm{GLUT}$。
- 无氧：细胞质，酵解 $+$ 乳酸，净 $2\,\mathrm{ATP}$；关键酶 $\mathrm{PFK}$-$1$（尤为重要）、丙酮酸激酶、己糖激酶。
- 有氧：酵解 → 丙酮酸脱氢酶复合体 → 三羧酸循环，净 $30$ 或 $32\,\mathrm{ATP}$。
- 戊糖磷酸：不产能；核糖磷酸 $+$ $\mathrm{NADPH}$；关键酶葡萄糖-6-磷酸脱氢酶。
- 糖原：合酶 vs 磷酸化酶，磷酸化修饰效应相反；肝补血糖，肌供收缩。
- 异生：四关键酶；两个底物循环；饥饿补血糖。
- 血糖：胰岛素降，胰高血糖素／糖皮质激素／肾上腺素升；紊乱见糖尿病。
:::
