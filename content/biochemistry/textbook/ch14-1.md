# 第一节　DNA复制的基本规律

第十四章打开第三篇里「遗传信息怎样被抄成新的 $\mathrm{DNA}$」这一户。体内或细胞内的 $\mathrm{DNA}$ 合成主要包括 $\mathrm{DNA}$ 复制、$\mathrm{DNA}$ 修复合成和逆转录合成 $\mathrm{DNA}$。本节只立复制本身的四条规律：半保留、双向、半不连续、高保真。酶和拓扑交给第二节；原核从 $\mathrm{oriC}$ 走到终止交给第三节；真核复制和逆转录分别是第四、五节。修复合成按章首交给第二十三章，本节高保真里点到的复制后修复按正文见第二十一章。

:::concept{term="先问子代留下几条亲代链，再问从几个起点、哪一股连续"}
看见“复制”，先不要默写聚合酶名单。户头是：亲代双链解开后各当模板，子代各保留一股亲链（半保留）；从固定起点向两个方向解链（双向）；同一复制叉上前导链连续、后随链分段（半不连续）；错配概率约 $10^{-10}$（高保真）。冈崎片段长度、真核聚合酶表是本节末的账；$\mathrm{pol}\,\mathrm{I}/\mathrm{III}$、拓扑酶、连接酶是第二节的账。
:::

生物体内或细胞内进行的 $\mathrm{DNA}$ 合成主要包括 $\mathrm{DNA}$ 复制、$\mathrm{DNA}$ 修复合成和逆转录合成 $\mathrm{DNA}$ 等过程。$\mathrm{DNA}$ 复制（replication）是以 $\mathrm{DNA}$ 为模板的 $\mathrm{DNA}$ 合成，是基因组的复制过程。在这个过程中，亲代 $\mathrm{DNA}$ 作为合成模板，按照碱基配对原则合成子代分子，其化学本质是酶促脱氧核糖核苷酸的聚合反应。$\mathrm{DNA}$ 的忠实复制以碱基配对规律为分子基础，酶促修复系统可以校正复制中可能出现的错误。原核生物和真核生物 $\mathrm{DNA}$ 复制的规律和过程相似，但在具体细节上有许多差别，真核生物 $\mathrm{DNA}$ 复制过程和参与的分子更为复杂和精致。本章主要讨论 $\mathrm{DNA}$ 复制和 $\mathrm{DNA}$ 逆转录合成，$\mathrm{DNA}$ 修复合成将在第二十三章叙述。

:::definition{label="DNA 复制"}
$\mathrm{DNA}$ 复制（replication）是以 $\mathrm{DNA}$ 为模板的 $\mathrm{DNA}$ 合成，是基因组的复制过程。亲代 $\mathrm{DNA}$ 作为合成模板，按碱基配对原则合成子代分子，化学本质是酶促脱氧核糖核苷酸的聚合反应。
:::

:::definition{label="体内 DNA 合成的三本账"}
①复制：以 $\mathrm{DNA}$ 为模板合成 $\mathrm{DNA}$，抄基因组；②修复合成：校正损伤或错配，章首交给第二十三章；③逆转录：以 $\mathrm{RNA}$ 为模板合成 $\mathrm{DNA}$，本章第五节。本节到第四节都在第一本账里。
:::

:::definition{label="忠实复制的分子基础"}
碱基配对规律是分子基础；酶促修复系统校正复制中可能出现的错误。规律在前，校正在后，二者合在一起才是教材所说的忠实。
:::

| | 模板 | 产物 | 本章位置 |
|--|------|------|----------|
| 复制 | $\mathrm{DNA}$ | $\mathrm{DNA}$（基因组） | 第一至第四节 |
| 逆转录 | $\mathrm{RNA}$ | $\mathrm{DNA}$ | 第五节 |

问“子代怎么留下亲代的一股链”走复制；问“$\mathrm{RNA}$ 病毒基因组怎样进宿主染色体”走逆转录；问“紫外造成的嘧啶二聚体怎么切掉重补”走修复。
:::

章首把三本账并列。复制是其中以 $\mathrm{DNA}$ 为模板、抄基因组的那一种。把修复合成或逆转录也答成 replication，后文聚合酶表里的旁路酶、第五节逆转录酶都会没户头。
:::

:::insight{label="原核真核规律相似，细节不共用一张酶表"}
教材先写规律和过程相似，紧接着写具体细节有许多差别，真核更复杂精致。半保留、双向、半不连续、高保真四条两边都认；$\mathrm{oriC}$、$\mathrm{DnaA}$、$\mathrm{pol}\,\mathrm{III}$ 是原核的账，真核多复制子、聚合酶转换交给第四节。
:::

$\mathrm{DNA}$ 复制特征主要包括半保留复制（semi-conservative replication）、双向复制（bidirectional replication）和半不连续复制（semi-discontinuous replication）。$\mathrm{DNA}$ 的复制具有高保真性（high fidelity）。

:::keypoint{label="本节四条规律一次排开"}
- 半保留：亲代每一股各进一个子代双链。
- 双向：从起点向两个方向解链，形成复制叉。
- 半不连续：前导链连续，后随链分段（冈崎片段）。
- 高保真：错配概率约 $10^{-10}$。
:::

:::pitfall{label="高保真不是第四种“复制方式”，是保真程度"}
前三条是复制怎样进行；高保真性是复制有多准。不要把 high fidelity 和半保留、双向、半不连续并成四种互斥方式。
:::

## 一、DNA 以半保留方式进行复制

$\mathrm{DNA}$ 生物合成的半保留复制规律是遗传信息传递机制的重要发现之一。在复制时，亲代双链 $\mathrm{DNA}$ 解开为两股单链，各自作为模板，依据碱基配对规律，合成序列互补的子链 $\mathrm{DNA}$ 双链。亲代 $\mathrm{DNA}$ 模板在子代 $\mathrm{DNA}$ 中的存留有 $3$ 种可能性：全保留式、半保留式或混合式（图14-1a）。

:::definition{label="半保留复制"}
半保留复制（semi-conservative replication）：亲代双链解开为两股单链，各自作为模板，按碱基配对合成互补子链。每一个子代双链都保留一股亲代链、新合成一股子链。
:::

:::compare{title="亲代模板在子代里的三种存留方式"}
| 方式 | 子代双链长什么样（图14-1a） |
|------|------------------------------|
| 全保留式 | 一条子代分子两条都是亲代链（全蓝），另一条两条都是新链（全白） |
| 半保留式 | 每个子代分子都是一条亲代链 $+$ 一条新链 |
| 混合式 | 亲代链被打散，新旧片段在同一条链上镶嵌（图中蓝底白格） |

三种都“用了亲代信息”，只有中间那种叫半保留。实验要做的，就是把全保留和混合式排除掉。
:::

::figure{src="/images/biochemistry/textbook/p0284_02.png" caption="图14-1　证明 DNA 半保留复制的经典实验。（a）DNA 复制方式的 3 种可能性：全保留式、半保留式、混合式；（b）含 15N-DNA 的细菌转入普通培养液后，第一代只出现杂交 DNA 中密度带，第二代出现 14N-DNA 低密度带与杂交带并存。" alt="上：全保留、半保留、混合三种子代着色；下：15N 标记细菌转入 14N 后第一代、第二代离心管带型"}

$1958$ 年，Meselson M. 和 Stahl F.W. 用实验证实自然界的 $\mathrm{DNA}$ 复制方式是半保留式的。他们利用细菌能够以 $\mathrm{NH}_4\mathrm{Cl}$ 为氮源合成 $\mathrm{DNA}$ 的特性，将细菌在含 $^{15}\mathrm{NH}_4\mathrm{Cl}$ 的培养液中培养若干代（每一代约 $20$ 分钟），此时细菌 $\mathrm{DNA}$ 全部是含 $^{15}\mathrm{N}$ 的“重”$\mathrm{DNA}$；再将细菌放回普通的 $^{14}\mathrm{NH}_4\mathrm{Cl}$ 培养液中培养，新合成的 $\mathrm{DNA}$ 则有 $^{14}\mathrm{N}$ 的掺入；提取不同培养代数的细菌 $\mathrm{DNA}$ 做密度梯度离心分析，因 $^{15}\mathrm{N}$-$\mathrm{DNA}$ 和 $^{14}\mathrm{N}$-$\mathrm{DNA}$ 的密度不同，$\mathrm{DNA}$ 因此形成不同的致密带。

结果表明：细菌在 $^{15}\mathrm{NH}_4\mathrm{Cl}$ 培养基中生长繁殖时合成的 $^{15}\mathrm{N}$-$\mathrm{DNA}$ 是 $1$ 条高密度带；转入普通培养基培养 $1$ 代后得到 $1$ 条中密度带，提示其为 $^{15}\mathrm{N}$-$\mathrm{DNA}$ 链与 $^{14}\mathrm{N}$-$\mathrm{DNA}$ 链的杂交分子；在第二代时可见中密度和低密度 $2$ 条带，表明它们分别为 $^{15}\mathrm{N}$-$\mathrm{DNA}$ 链/$^{14}\mathrm{N}$-$\mathrm{DNA}$ 链、$^{14}\mathrm{N}$-$\mathrm{DNA}$ 链/$^{14}\mathrm{N}$-$\mathrm{DNA}$ 链组成的分子（图14-1b）。随着在普通培养基中培养代数的增加，低密度带增强，而中密度带保持不变。这一实验结果证明，亲代 $\mathrm{DNA}$ 复制后，是以半保留形式存在于子代 $\mathrm{DNA}$ 分子中的。

:::timeline{period="Meselson-Stahl 证明半保留"}
- **1958** Meselson 与 Stahl 用氮同位素标记细菌 DNA，密度梯度离心区分重链与轻链
- **在 15NH4Cl 中培养若干代** 每一代约 20 分钟，DNA 全部成为含 15N 的重 DNA，离心只见一条高密度带
- **转入普通 14NH4Cl 培养 1 代** 只得到一条中密度带，即 15N 链与 14N 链的杂交分子
- **第二代** 中密度带与低密度带并存，分别对应杂交分子与两条 14N 链组成的分子
- **继续传代** 低密度带增强，中密度带保持不变，排除全保留式与混合式
:::

:::definition{label="Meselson-Stahl 实验"}
利用细菌以 $\mathrm{NH}_4\mathrm{Cl}$ 为氮源合成 $\mathrm{DNA}$：先在 $^{15}\mathrm{NH}_4\mathrm{Cl}$ 中培养若干代（每代约 $20$ 分钟）得到全重 $\mathrm{DNA}$，再转入 $^{14}\mathrm{NH}_4\mathrm{Cl}$，按代提取 $\mathrm{DNA}$ 做密度梯度离心。带型符合半保留，不符合全保留或混合。
:::

:::keypoint{label="离心管上必须能默写的三代带"}
- 全 $^{15}\mathrm{N}$：一条高密度带。
- 转入 $^{14}\mathrm{N}$ 后第一代：只有一条中密度带（杂交 $^{15}\mathrm{N}/^{14}\mathrm{N}$）。
- 第二代：中密度 $+$ 低密度（杂交 $+$ $^{14}\mathrm{N}/^{14}\mathrm{N}$）。
- 再传代：低密度增强，中密度带保持不变。
:::

:::cause-effect{title="为什么第一代一条中密度带就能排除全保留"}
- **因** 全保留式会让亲代双链原封不动留下，新合成的双链全是轻链，第一代应同时出现高密度带和低密度带
- **果** 实验第一代只有中密度带，说明每个分子都是一股重链配一股轻链，不是“整分子留下、整分子新做”
:::

:::cause-effect{title="为什么中密度带保持不变能排除混合式"}
- **因** 混合式把亲代链打散镶进每一条新链，随着 $^{14}\mathrm{N}$ 掺入，整条分子的密度会一代代连续变轻，不应长期保留一条位置固定的中密度带
- **果** 实验中密度带位置不变、只是相对变弱，低密度带另起一条并增强——亲代重链一直整股存留在杂交分子里
:::

:::pitfall{label="第一代不是“一半重带一半轻带”"}
那是全保留的预言。半保留第一代**全部**是杂交分子，离心只有一条中密度带。把第一代画成重、轻两条，图14-1b 右边那一列试管对不上。
:::

:::pitfall{label="第二代不要写成三条带"}
教材写中密度和低密度 $2$ 条带。全重带在转入 $^{14}\mathrm{N}$ 之后不再出现——亲代两条重链已经分到两个杂交分子里，不会再有 $^{15}\mathrm{N}/^{15}\mathrm{N}$ 双链。画出高、中、低三条，是把“还没转培养基”的那一管混进第二代了。
:::

:::insight{label="每代约 20 分钟是本版点名的细菌世代"}
标记实验能按“代”取样，是因为细菌在该条件下约 $20$ 分钟一代。第三节计算 $E.coli$ 复制速度时还会用这个 $20$ 分钟，和全长约 $4\,600\,\mathrm{kb}$、每秒约 $3\,800$ 个核苷酸是同一本账，不要另换世代时间。
:::

半保留复制规律的阐明，对于理解 $\mathrm{DNA}$ 的功能和物种的延续性有重大意义。依据半保留复制的方式，子代 $\mathrm{DNA}$ 中保留了亲代的全部遗传信息，亲代与子代 $\mathrm{DNA}$ 之间碱基序列高度一致（图14-2）。

::figure{src="/images/biochemistry/textbook/p0285_01.png" caption="图14-2　半保留复制保证子代和亲代 DNA 碱基序列一致。（a）母链 DNA；（b）复制过程打开的复制叉；（c）两个子代细胞的双链 DNA，实线链来自母链，虚线链是新合成的子链。" alt="母链双螺旋打开成复制叉，两个子代分子各保留一条实线母链并配一条虚线新链，碱基序列与亲代一致"}

:::definition{label="半保留保证序列高度一致"}
子代 $\mathrm{DNA}$ 中保留了亲代的全部遗传信息，亲代与子代碱基序列高度一致。图14-2：实线是母链，虚线是新子链；两个子代双链的碱基对都与（a）母链相同。
:::

:::insight{label="图14-2 把“保留一股”画成序列不丢"}
（a）到（c）不是换了一套碱基，而是母链序列被两套互补子链各抄一遍。实线在两个子代里都还在，所以物种能延续；虚线按配对长出来，所以子代和亲代高度一致。后面讲变异，是在这张图上叠加突变，不是把这张图作废。
:::

遗传的保守性是相对的，自然界还存在着普遍的变异现象。遗传信息的相对稳定是物种稳定的分子基础，但并不意味着同一物种个体与个体之间没有区别。例如病毒是简单的生物，流感病毒就有很多不同的毒株，不同毒株的感染方式、毒性差别可能很大，在预防上有相当大的难度。又如，地球上曾有过的人口和现有的几十亿人，除了单卵双胞胎之外，两个人之间不可能有完全一样的 $\mathrm{DNA}$ 分子组成（基因型）。因此，在强调遗传保守性的同时，不应忽视其变异性。

:::definition{label="遗传保守性是相对的"}
遗传信息的相对稳定是物种稳定的分子基础，但不意味着同一物种个体之间没有区别。教材点名：流感病毒多毒株；除单卵双胞胎外，两个人不可能有完全一样的 $\mathrm{DNA}$ 组成（基因型）。
:::

:::pitfall{label="不要把半保留听成“子代永远等于亲代”"}
教材把变异写在图14-2 后面：保守性是相对的。复制可以高度一致，仍允许突变；突变是进化的基础（第十三章已写在基因的三项功能里）。把半保留答成“绝对不变”，流感毒株和人类基因型多样性都没有入口。
:::

:::compare{title="物种稳定和个人差异不是同一句话"}
| 教材强调 | 落到什么 |
|----------|----------|
| 相对稳定 | 物种能延续，亲代与子代序列高度一致 |
| 普遍变异 | 流感多毒株；除单卵双胞胎外，两个人基因型不可能完全一样 |

问“为什么子代能认出是同一个物种”走保守；问“为什么预防流感很难、为什么法医学能辨人”走变异。
:::

## 二、DNA 复制从起点双向进行

细胞的增殖有赖于基因组复制而使子代得到完整的遗传信息。原核生物基因组是环状 $\mathrm{DNA}$，只有一个复制起点（origin）。复制从起点开始，向两个方向进行解链，进行的是单点起始双向复制（图14-3a）。复制中的模板 $\mathrm{DNA}$ 形成 $2$ 个延伸方向相反的开链区，称为复制叉（replication fork）。复制叉指的是正在进行复制的双链 $\mathrm{DNA}$ 分子所形成的 $\mathrm{Y}$ 形区域，其中，已解旋的两条模板单链以及正在进行合成的新链构成了 $\mathrm{Y}$ 形的头部，尚未解旋的 $\mathrm{DNA}$ 模板双链构成了 $\mathrm{Y}$ 形的尾部。

:::definition{label="复制起点"}
复制起点（origin）是复制开始解链的固定部位。原核环状基因组只有一个；真核每个染色体有多个。复制不是在基因组上任何部位随机起始——固定起点的序列细节是第三节 $\mathrm{oriC}$ 的账。
:::

:::definition{label="单点起始双向复制"}
原核环状 $\mathrm{DNA}$ 从唯一起点向两个方向解链。图14-3a：$\mathrm{ori}$ 打开后形成 $2$ 个复制叉，绕环汇合于复制终点 $\mathrm{ter}$。
:::

:::definition{label="复制叉"}
复制叉（replication fork）是正在复制的双链 $\mathrm{DNA}$ 所形成的 $\mathrm{Y}$ 形区域。已解旋的两条模板单链以及正在合成的新链构成 $\mathrm{Y}$ 的头部；尚未解旋的模板双链构成 $\mathrm{Y}$ 的尾部。
:::

:::keypoint{label="一个起点产生两个方向相反的复制叉"}
- 双向 $=$ 两个叉，不是“从起点只往一个方向长”。
- 两个叉的延伸方向相反。
- 复制完成时，复制叉相遇并汇合连接。
:::

真核生物基因组庞大而复杂，由多个染色体组成，全部染色体均需复制，每个染色体又有多个起点，呈多起点双向复制特征（图14-3b）。每个起点产生两个移动方向相反的复制叉，复制完成时，复制叉相遇并汇合连接。从一个 $\mathrm{DNA}$ 复制起点起始的 $\mathrm{DNA}$ 复制区域称为复制子（replicon）。复制子是含有一个复制起点的独立完成复制的功能单位。高等生物有数以万计的复制子，复制子间长度差别很大，约在 $13\sim 900\,\mathrm{kb}$ 之间。

::figure{src="/images/biochemistry/textbook/p0286_01.png" caption="图14-3　DNA 复制的起点和方向。（a）原核生物环状 DNA 的单点起始双向复制：ori 打开后形成 2 个复制叉，汇合于 ter；（b）真核生物 DNA 的多起点双向复制：一条线性分子上多个复制起点各自形成双向开链区。" alt="上：环状 DNA 从 ori 双向复制到 ter；下：线性 DNA 多个起点形成多个双向复制泡"}

:::definition{label="多起点双向复制"}
真核由多个染色体组成，全部染色体均需复制；每个染色体又有多个起点。每个起点产生两个移动方向相反的复制叉，相遇后汇合连接。
:::

:::definition{label="复制子"}
复制子（replicon）是从一个 $\mathrm{DNA}$ 复制起点起始的 $\mathrm{DNA}$ 复制区域，是含有一个复制起点、独立完成复制的功能单位。高等生物有数以万计的复制子，长度约 $13\sim 900\,\mathrm{kb}$。
:::

:::compare{title="原核单起点 vs 真核多复制子"}
| | 原核（图14-3a） | 真核（图14-3b） |
|--|----------------|----------------|
| 基因组形态 | 环状 $\mathrm{DNA}$ | 多条线性染色体 |
| 起点数目 | 一个 | 每条染色体多个；高等生物数以万计复制子 |
| 方向 | 双向，两叉在 $\mathrm{ter}$ 汇合 | 每个起点仍双向，邻叉相遇汇合 |
| 复制子 | 整个环往往就是一个复制子 | 一个起点对应一个复制子，$13\sim 900\,\mathrm{kb}$ |

两边都是双向。差别在起点个数和基因组是否环状，不在“真核改成单向”。
:::

:::pitfall{label="双向复制不是两个起点"}
原核只有一个 origin，双向是“一个点往两边走”。把双向听成“必须有两个 $\mathrm{ori}$”，图14-3a 的单点起始就读不通。真核的多个起点，每一个自己仍然双向。
:::

:::pitfall{label="复制叉的头和尾不要画反"}
教材：已解旋的模板单链 $+$ 正在合成的新链 $=$ $\mathrm{Y}$ 的头部；尚未解旋的双链 $=$ 尾部。把还没打开的双链画成叉口，半不连续那一节的“解链方向只有一个”会对不上。
:::

:::insight{label="复制子长度跨度本身就是真核的账"}
$13\sim 900\,\mathrm{kb}$ 差了近两个数量级。高等生物不是把基因组切成等长片段再同时抄，而是数以万计、长短差别很大的独立单位。第四节还会写复制有时序性、复制子分组激活；本节只把“一个起点 $=$ 一个复制子”立住。
:::

:::keypoint{label="图14-3 两幅不要背串"}
- （a）环、一个 $\mathrm{ori}$、两个叉、一个 $\mathrm{ter}$。
- （b）线、$5'/3'$ 两端、多个复制起点、多个开链泡。
- 两幅都是双向；只有（a）是单点。
:::

## 三、DNA 复制以半不连续方式进行

$\mathrm{DNA}$ 双螺旋结构的特征之一是两条链的反向平行，一条链为 $5'$ 至 $3'$ 方向，其互补链是 $3'$ 至 $5'$ 方向。$\mathrm{DNA}$ 聚合酶只能催化 $\mathrm{DNA}$ 链从 $5'$ 至 $3'$ 方向的合成，故子链沿着模板复制时，只能从 $5'$ 至 $3'$ 方向延伸。在同一个复制叉上，解链方向只有一个，此时一条子链的合成方向与解链方向相同，可以边解链，边合成新链。然而，另一条链的复制方向则与解链方向相反，只能等待 $\mathrm{DNA}$ 全部解链，方可开始合成，这样的等待在细胞内显然是不现实的。

:::definition{label="子链只能 5′→3′ 延长"}
$\mathrm{DNA}$ 聚合酶只能催化 $\mathrm{DNA}$ 链从 $5'$ 至 $3'$ 方向合成。模板可以是 $3'\rightarrow 5'$ 走向，子链仍只能 $5'\rightarrow 3'$ 长。化学理由（底物 $5'$-$\mathrm{P}$ 加到引物 $3'$-$\mathrm{OH}$ 上）是第二节的账；本节先用这条方向限制引出半不连续。
:::

:::cause-effect{title="反向平行加单向聚合，迫使一股分段"}
- **因** 双链反向平行；同一复制叉解链方向只有一个；聚合酶又只许 $5'\rightarrow 3'$
- **果** 与解链同向的那股可以边解边合成（前导链）；反向的那股若等全部解完再从头合成，细胞内不现实，于是分段引发、分段延长（后随链）
:::

:::pitfall{label="不要发明一条 3′→5′ 的 DNA 聚合酶来“解决”反向平行"}
教材的解法是半不连续，不是换聚合方向。把后随链答成“沿 $3'\rightarrow 5'$ 连续合成”，冈崎片段、引物、连接酶整串都会多余。
:::

$1968$ 年，Okazaki R. 用电子显微镜结合放射自显影技术观察到，复制过程中会出现一些较短的新 $\mathrm{DNA}$ 片段，后人证实这些片段只出现于同一复制叉的一股链上。由此提出，子代 $\mathrm{DNA}$ 合成是以半不连续的方式完成的，从而克服 $\mathrm{DNA}$ 空间结构对 $\mathrm{DNA}$ 新链合成的制约。

目前认为，在 $\mathrm{DNA}$ 复制过程中，沿着解链方向生成的子链 $\mathrm{DNA}$ 的合成是连续进行的，这股链称为前导链（leading strand）；另一股链因为复制方向与解链方向相反，不能连续延长，只能随着模板链的解开，逐段地从 $5'\rightarrow 3'$ 生成引物并复制子链。模板被打开一段，起始合成一段子链；再打开一段，再起始合成另一段子链，这一不连续复制的链称为后随链（lagging strand）。前导链连续复制而后随链不连续复制的方式称为半不连续复制（图14-4）。在引物生成和子链延长上，后随链都比前导链迟一些。因此，两条互补链的合成是不对称的。

沿着后随链的模板链合成的新 $\mathrm{DNA}$ 片段被命名为冈崎片段（Okazaki fragment）。真核生物的冈崎片段长度约 $100\sim 200$ 核苷酸，而原核生物约 $1\,000\sim 2\,000$ 核苷酸。复制完成后，这些不连续片段经过去除引物，填补引物留下的空隙，连接成完整的 $\mathrm{DNA}$ 长链。

::figure{src="/images/biochemistry/textbook/p0286_02.png" caption="图14-4　DNA 的半不连续复制。解链方向朝向已打开的叉口；前导链沿 5′→3′ 连续延长，后随链上可见两段带斜线框引物的短片段，各自仍从 5′ 向 3′ 生长。" alt="复制叉：上方前导链连续，下方后随链两段冈崎片段，引物为斜线框"}

:::definition{label="前导链"}
前导链（leading strand）是沿着解链方向生成、合成连续进行的那股子链。图14-4 标在与解链方向一致的一侧，引物在 $5'$ 端，链向 $3'$ 延长。
:::

:::definition{label="后随链"}
后随链（lagging strand）因复制方向与解链方向相反，不能连续延长：模板打开一段，就从 $5'\rightarrow 3'$ 生成引物并复制一段；再打开一段，再起始另一段。
:::

:::definition{label="半不连续复制"}
前导链连续复制、后随链不连续复制的方式称为半不连续复制（semi-discontinuous replication）。不是两条链都不连续，也不是两条都连续。
:::

:::definition{label="冈崎片段"}
冈崎片段（Okazaki fragment）是沿着后随链的模板合成的新 $\mathrm{DNA}$ 片段。$1968$ 年 Okazaki R. 用电子显微镜结合放射自显影观察到较短新 $\mathrm{DNA}$ 片段，后人证实只出现于同一复制叉的一股链上。真核约 $100\sim 200$ 核苷酸，原核约 $1\,000\sim 2\,000$ 核苷酸。
:::

:::definition{label="后随链片段如何连成整链"}
复制完成后，不连续片段去除引物，填补引物留下的空隙，再连接成完整 $\mathrm{DNA}$ 长链。填补和连接的酶是第二节 $\mathrm{pol}\,\mathrm{I}$ 与连接酶、第三节终止过程的账。
:::

:::compare{title="同一复制叉上的前导链和后随链"}
| | 前导链 | 后随链 |
|--|--------|--------|
| 与解链方向 | 相同 | 相反 |
| 合成 | 连续，$5'\rightarrow 3'$ | 不连续，仍每段 $5'\rightarrow 3'$ |
| 引物 | 起始处一次 | 每一段冈崎片段都要 |
| 相对快慢 | 较早 | 引物生成和子链延长都迟一些 |
| 产物片段 | 一条长链 | 冈崎片段（真核 $100\sim 200\,\mathrm{nt}$，原核 $1\,000\sim 2\,000\,\mathrm{nt}$） |

两条互补链的合成是不对称的。图14-4 的斜线框是引物，不是“反向聚合的标记”。
:::

:::pitfall{label="半不连续不是“两条链都不连续”"}
前导链是连续的。把半不连续听成整分子都分段，前导链的定义和“迟一些”的不对称都会没意义。
:::

:::pitfall{label="冈崎片段不要写成两条链上都有"}
后人证实这些短片段只出现于同一复制叉的**一股**链上。把前导链也画满短片段，就退回“全不连续”，和教材命名冲突。
:::

:::pitfall{label="真核冈崎片段更短，不要和原核对调"}
真核约 $100\sim 200$ 核苷酸，原核约 $1\,000\sim 2\,000$ 核苷酸。第四节还会把真核片段与核小体 $135\,\mathrm{bp}$ 联系起来；本节先把两档数字钉住，不要背成“原核更短”。
:::

:::insight{label="后随链“迟一些”已经预告引物酶和连接酶"}
引物生成和子链延长都比前导链迟，所以同一复制叉上两股并不齐头。第三节会用后随链模板绕成环，让两股仍由同一个 $\mathrm{pol}\,\mathrm{III}$ 催化——那是延长几何，不取消这里的不对称。
:::

:::keypoint{label="图14-4 读图三件事"}
- 解链方向只有一个，叉口朝已打开的一侧。
- 前导链一条箭头到底；后随链两小段，每段仍 $5'\rightarrow 3'$。
- 斜线框在新链 $5'$ 端，是引物。
:::

## 四、DNA 复制具有高保真性

$\mathrm{DNA}$ 复制具有高度保真性，其错配概率约为 $10^{-10}$。“半保留复制”确保亲代和子代 $\mathrm{DNA}$ 分子之间信息传递的绝对保真性。高保真 $\mathrm{DNA}$ 聚合酶利用严格的碱基配对原则是保证复制保真性的机制之一。另外，体内复制叉的复杂结构提高了复制的准确性；$\mathrm{DNA}$ 聚合酶的核酸外切酶活性和校读功能以及复制后修复系统（详见第二十一章）对错配加以纠正，四种机制协同进一步提高了复制的保真性。

细菌复制酶有多个错误修复系统。真核细胞有许多 $\mathrm{DNA}$ 聚合酶，复制酶高保真运作。复制酶有复杂的结构，不同亚基具有不同功能（表14-1）。除了 $\beta$ 酶，修复酶都有低保真度。修复酶的结构相对简单。

:::definition{label="复制的高保真性"}
错配概率约为 $10^{-10}$。四种机制协同：①半保留复制保证亲代与子代信息传递的绝对保真性；②高保真聚合酶的严格碱基配对；③体内复制叉的复杂结构；④聚合酶的核酸外切酶活性／校读，以及复制后修复系统。
:::

:::keypoint{label="保真性四条不要漏一条"}
- 半保留：亲代链整股留下。
- 碱基配对：高保真聚合酶选择正确 dNTP。
- 复制叉结构：复杂结构提高准确性。
- 校读 $+$ 复制后修复：外切酶改错；复制后修复见第二十一章。
:::

:::pitfall{label="错配概率不是聚合酶一次掺入错误率单独能解释的数"}
教材把四种机制写成协同。碱基选择、校读是第二节的酶学；复制后修复不在本章展开。把 $10^{-10}$ 只记成“$\mathrm{A}$-$\mathrm{T}$、$\mathrm{G}$-$\mathrm{C}$ 配对很严”，会少掉复制叉和外切酶两层。
:::

:::pitfall{label="章首第二十三章和高保真处第二十一章都按教材留着"}
章首：修复合成将在第二十三章叙述。本节：复制后修复系统详见第二十一章。本版两处章号不同，不要擅自改成同一章，也不要外补修复途径名单。
:::

:::compare{title="复制酶和修复酶（表14-1 先立结构反差）"}
| | 复制酶 | 修复酶 |
|--|--------|--------|
| 保真度 | 高保真运作 | 除 $\beta$ 酶外都有低保真度 |
| 结构 | 复杂，不同亚基不同功能 | 相对简单 |
| 细菌 | 有多个错误修复系统 | — |
| 真核 | 许多 $\mathrm{DNA}$ 聚合酶；复制用的那些高保真 | 旁路、切除等见下表 |

$\beta$ 是教材点名的高保真修复例外，不要把“修复酶都低保真”写成没有例外。
:::

**表14-1　部分真核生物 DNA 聚合酶功能和结构**

| 类别 | $\mathrm{DNA}$ 聚合酶 | 功能 | 结构 |

:::definition{label="真核复制用的四种高保真聚合酶"}
$\alpha$：引发酶，$350\,\mathrm{kD}$ 四聚体。$\delta$：后随链合成，$250\,\mathrm{kD}$ 四聚体。$\varepsilon$：前导链合成，$350\,\mathrm{kD}$ 四聚体。$\gamma$：线粒体 $\mathrm{DNA}$ 复制，$200\,\mathrm{kD}$ 二聚体。$\delta$／$\varepsilon$ 谁抄哪一股、聚合酶转换，第二节和第四节再展开。
:::

:::definition{label="β 酶是高保真修复"}
$\mathrm{DNA}\,\mathrm{pol}\,\beta$ 做碱基切除修复，$39\,\mathrm{kD}$ 单体。表14-1 把它放在高保真修复；正文写“除了 $\beta$ 酶，修复酶都有低保真度”。
:::

:::definition{label="低保真修复四名"}
$\zeta$：碱基损伤旁路，异聚体。$\eta$：胸腺嘧啶二聚体旁路，单体。$\iota$：减数分裂相关，单体。$\kappa$：碱基替换与缺失，单体。结构相对简单（单体或异聚体），与复制酶的四聚体／二聚体对照。
:::

:::pitfall{label="α 是引发酶，不要写成前导链或后随链的主聚合酶"}
表14-1：$\alpha$ 引发酶，$\delta$ 后随链，$\varepsilon$ 前导链。第二节会写 $\alpha$ 合成引物后被 $\delta$、$\varepsilon$ 替换（聚合酶转换）。把 $\alpha$ 答成“真核真正的复制酶”，和原核把 $\mathrm{pol}\,\mathrm{I}$ 误当成主酶是同一类错。
:::

:::pitfall{label="γ 不要搬到细胞核复制叉上"}
$\gamma$ 是线粒体 $\mathrm{DNA}$ 复制。核内前导／后随是 $\varepsilon$／$\delta$。第四节还会再写 $\mathrm{pol}\,\gamma$，本节表里先分户。
:::

:::insight{label="复制酶复杂、修复酶简单，和保真度写在同一张表里"}
高保真复制酶都是四聚体或二聚体、分子量 $200\sim 350\,\mathrm{kD}$；$\beta$ 虽高保真但是 $39\,\mathrm{kD}$ 单体；低保真旁路酶多为单体。结构复杂不是装饰，正文说不同亚基具有不同功能——第二节 $\mathrm{pol}\,\mathrm{III}$ 的 $\alpha$、$\varepsilon$、$\beta$ 滑动夹就是原核版的同一句话。
:::

:::memory{label="本节必背要点"}
- [ ] 体内 $\mathrm{DNA}$ 合成三本账：复制、修复合成、逆转录。本章主要讨论复制和逆转录。
- [ ] 复制：以 $\mathrm{DNA}$ 为模板的 $\mathrm{DNA}$ 合成，化学本质是酶促 dNTP 聚合。
- [ ] 四条规律：半保留、双向、半不连续、高保真（错配约 $10^{-10}$）。
- [ ] 三种存留方式：全保留、半保留、混合。自然界是半保留。
- [ ] Meselson-Stahl（$1958$）：$^{15}\mathrm{N}\rightarrow ^{14}\mathrm{N}$，每代约 $20$ 分钟；第一代仅中密度杂交带，第二代中 $+$ 低，中密度带保持不变。
- [ ] 保守性相对：流感多毒株；除单卵双胞胎外两个人基因型不可能完全一样。
- [ ] 原核：环状 $\mathrm{DNA}$，单起点双向，两叉在 $\mathrm{ter}$ 汇合。
- [ ] 复制叉：$\mathrm{Y}$ 形；头＝已解旋模板 $+$ 新链，尾＝未解旋双链。
- [ ] 真核：多染色体、多起点双向；复制子 $=$ 含一个起点的独立复制单位，高等生物数以万计，$13\sim 900\,\mathrm{kb}$。
- [ ] 聚合酶只催化 $5'\rightarrow 3'$；同一叉解链方向只有一个。
- [ ] 前导链连续，后随链不连续；合成不对称，后随链更迟。
- [ ] 冈崎片段只在一股上：真核 $100\sim 200\,\mathrm{nt}$，原核 $1\,000\sim 2\,000\,\mathrm{nt}$；去引物、填空隙、连接成整链。
- [ ] 保真四机制：半保留、严格配对、复制叉结构、外切校读 $+$ 复制后修复。
- [ ] 表14-1：$\alpha$ 引发酶，$\delta$ 后随链，$\varepsilon$ 前导链，$\gamma$ 线粒体；$\beta$ 高保真碱基切除；$\zeta\eta\iota\kappa$ 低保真。除 $\beta$ 外修复酶低保真。
:::
