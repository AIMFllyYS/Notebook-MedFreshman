# 第二节　蛋白聚糖分子中的糖胺聚糖

本节写蛋白聚糖分子中的糖胺聚糖。先把蛋白聚糖立成“以聚糖含量为主、糖胺聚糖共价连在核心蛋白质上”的复合糖类，再按教材把六种重要糖胺聚糖的重复二糖摊开：硫酸软骨素、硫酸皮肤素、硫酸角质素、透明质酸、肝素和硫酸类肝素。然后写核心蛋白质（丝甘蛋白聚糖、饰胶蛋白聚糖、黏结蛋白聚糖）和瓶刷状蛋白聚糖聚合体，合成时在多肽链上逐个加糖，最后落到细胞间基质和各自的特殊功能。

蛋白聚糖（proteoglycan）是一类非常复杂的复合糖类，以聚糖含量为主，由糖胺聚糖（glycosaminoglycan，$\mathrm{GAG}$）共价连接于不同核心蛋白质形成的糖复合体。一种蛋白聚糖可含有一种或多种糖胺聚糖。糖胺聚糖是由二糖单位重复连接而成的杂多糖，不分支。二糖单位中一个是糖胺（$N$-乙酰葡萄糖胺或 $N$-乙酰半乳糖胺），另一个是糖醛酸（葡萄糖醛酸或艾杜糖醛酸）。由于糖胺聚糖的二糖单位含有糖胺故而得名。除糖胺聚糖外，蛋白聚糖还含有一些 $N$- 或 $O$-连接型聚糖。核心蛋白质种类颇多，加之核心蛋白质相连的糖胺聚糖的种类、长度以及硫酸化程度等复杂因素，使蛋白聚糖的种类更为繁多。

:::definition{label="蛋白聚糖"}
蛋白聚糖（proteoglycan）是一类非常复杂的复合糖类，以聚糖含量为主，由糖胺聚糖（glycosaminoglycan，$\mathrm{GAG}$）共价连接于不同核心蛋白质形成的糖复合体。一种蛋白聚糖可含有一种或多种糖胺聚糖。
:::

:::definition{label="糖胺聚糖"}
糖胺聚糖（glycosaminoglycan，$\mathrm{GAG}$）是由二糖单位重复连接而成的杂多糖，不分支。二糖单位中一个是糖胺（$N$-乙酰葡萄糖胺或 $N$-乙酰半乳糖胺），另一个是糖醛酸（葡萄糖醛酸或艾杜糖醛酸）。因二糖单位含有糖胺而得名。
:::

:::compare{title="蛋白聚糖与糖蛋白"}
| 项目 | 糖蛋白（第一节） | 蛋白聚糖（本节） |
|------|------------------|------------------|
| 重量比 | 蛋白质重量百分比大于聚糖 | 以聚糖含量为主；聚糖可占一半以上甚至 $95\%$ |
| 聚糖是什么 | $N$-／$O$-连接型聚糖，由七种单糖构成，常有分支 | 糖胺聚糖：不分支的重复二糖杂多糖；此外还可含一些 $N$- 或 $O$-连接型聚糖 |
| 二糖／寡糖 | 五糖核心、天线，不是“己糖醛酸＋己糖胺”无限重复 | 糖胺 $+$ 糖醛酸（角质素例外：半乳糖 $+\,N$-乙酰葡萄糖胺） |
| 核心 | 蛋白质本身就是功能主体 | 核心蛋白质种类多；$\mathrm{GAG}$ 的种类、长度、硫酸化程度使种类更繁 |
:::

:::concept{term="先问重复二糖是哪一种 GAG，再问连在哪条核心蛋白质上"}
看见“蛋白聚糖”，先不要跳到软骨或抗凝。先问二糖单位里的糖胺和糖醛酸是谁、带不带硫酸；再问核心蛋白质是丝甘、饰胶、黏结还是聚合成瓶刷。把蛋白聚糖听成糖蛋白换了个名字，六种 $\mathrm{GAG}$ 会对不上户头。
:::

:::pitfall{label="蛋白聚糖里也可以有 N-或 O-连接型聚糖，但主体仍是糖胺聚糖"}
教材写明：除糖胺聚糖外，蛋白聚糖还含有一些 $N$- 或 $O$-连接型聚糖。不要把这一笔听成“所以蛋白聚糖就是糖蛋白”。主体仍是不分支的重复二糖。
:::

## 一、糖胺聚糖是己糖醛酸和己糖胺组成的重复二糖单位

体内重要的糖胺聚糖有 $6$ 种：硫酸软骨素（chondroitin sulfate）、硫酸皮肤素（dermatan sulfate）、硫酸角质素（keratan sulfate）、透明质酸（hyaluronic acid）、肝素（heparin）和硫酸类肝素（heparan sulfate）。这些糖胺聚糖都是由重复的二糖单位组成（图4-4）。除透明质酸外，其他的糖胺聚糖均带有硫酸。

:::definition{label="六种重要的糖胺聚糖"}
硫酸软骨素、硫酸皮肤素、硫酸角质素、透明质酸、肝素和硫酸类肝素。都由重复二糖单位组成。除透明质酸外，其他均带有硫酸。
:::

:::note{label="图4-4 电子版缺失"}
教材图4-4 为重要糖胺聚糖的重复二糖单位。数字切片 `p0109_01.png` 为 $0$ 字节，本节不引用该文件。六种二糖单位、硫酸化部位和分布仍按教材正文保留。
:::

硫酸软骨素的二糖单位由 $N$-乙酰半乳糖胺和葡萄糖醛酸组成，最常见的硫酸化部位是 $N$-乙酰半乳糖胺残基的 $\mathrm{C}4$ 和 $\mathrm{C}6$ 位。单个聚糖约有 $250$ 个二糖单位，许多这样的聚糖与核心蛋白质以 $O$-连接方式相连，形成蛋白聚糖。

硫酸角质素的二糖单位由半乳糖和 $N$-乙酰葡萄糖胺组成。它所形成的蛋白聚糖可分布于角膜中，也可与硫酸软骨素共同组成蛋白聚糖聚合物，分布于软骨和结缔组织中。

硫酸皮肤素分布广泛，其二糖单位与硫酸软骨素很相似，仅一部分葡萄糖醛酸为艾杜糖醛酸所取代，所以硫酸皮肤素含有两种糖醛酸。葡萄糖醛酸转变为艾杜糖醛酸是在聚糖合成后进行，由差向异构酶催化。

肝素的二糖单位为葡萄糖胺和艾杜糖醛酸（iduronic acid），葡萄糖胺的氨基氮和 $\mathrm{C}6$ 位均带有硫酸。肝素合成时都是葡萄糖醛酸，然后差向异构化为艾杜糖醛酸，并随之进行 $\mathrm{C}2$ 位硫酸化。肝素所连接的核心蛋白质几乎仅由丝氨酸和甘氨酸组成。肝素分布于肥大细胞内，有抗凝作用。硫酸类肝素是细胞膜成分，突出于细胞外。

透明质酸的二糖单位为葡萄糖醛酸和 $N$-乙酰葡萄糖胺。一分子透明质酸可由 $50\,000$ 个二糖单位组成，但它所连接的蛋白质部分很小。透明质酸分布于关节滑液、眼的玻璃体及疏松的结缔组织中。

:::definition{label="硫酸软骨素"}
二糖单位：$N$-乙酰半乳糖胺 $+$ 葡萄糖醛酸。最常见硫酸化部位是 $N$-乙酰半乳糖胺残基的 $\mathrm{C}4$ 和 $\mathrm{C}6$。单个聚糖约 $250$ 个二糖单位，以 $O$-连接连到核心蛋白质。
:::

:::definition{label="硫酸角质素"}
二糖单位：半乳糖 $+\,N$-乙酰葡萄糖胺。所成蛋白聚糖可在角膜中；也可与硫酸软骨素共同组成蛋白聚糖聚合物，分布于软骨和结缔组织。
:::

:::definition{label="硫酸皮肤素"}
二糖单位与硫酸软骨素很相似，仅一部分葡萄糖醛酸为艾杜糖醛酸所取代，故含有两种糖醛酸。葡萄糖醛酸 $\rightarrow$ 艾杜糖醛酸在聚糖合成后由差向异构酶催化。分布广泛。
:::

:::definition{label="肝素"}
二糖单位：葡萄糖胺 $+$ 艾杜糖醛酸。葡萄糖胺的氨基氮和 $\mathrm{C}6$ 均带硫酸。合成时先是葡萄糖醛酸，再差向异构化为艾杜糖醛酸，并随之 $\mathrm{C}2$ 硫酸化。核心蛋白质几乎仅由丝氨酸和甘氨酸组成。分布于肥大细胞内，有抗凝作用。
:::

:::definition{label="硫酸类肝素"}
硫酸类肝素（heparan sulfate）是细胞膜成分，突出于细胞外。
:::

:::definition{label="透明质酸"}
二糖单位：葡萄糖醛酸 $+\,N$-乙酰葡萄糖胺。一分子可由 $50\,000$ 个二糖单位组成，所连蛋白质部分很小。分布于关节滑液、眼的玻璃体及疏松的结缔组织。不带硫酸。
:::

:::pitfall{label="透明质酸是六种里唯一不带硫酸的"}
“除透明质酸外，其他的糖胺聚糖均带有硫酸。”把透明质酸也写成硫酸糖胺聚糖，软骨基质吸水和角膜透明那两笔会对错电荷账。
:::

:::pitfall{label="硫酸角质素的二糖没有糖醛酸"}
标题写“己糖醛酸和己糖胺组成的重复二糖”，但角质素是半乳糖 $+\,N$-乙酰葡萄糖胺。肝素的糖胺是葡萄糖胺（不必乙酰化），不要一律写成 $N$-乙酰糖胺。
:::

:::insight{label="艾杜糖醛酸是合成之后才差向异构出来的"}
硫酸皮肤素、肝素都先按葡萄糖醛酸装上去，聚糖合成后再由差向异构酶变成艾杜糖醛酸。肝素还随之做 $\mathrm{C}2$ 硫酸化。不要把艾杜糖醛酸听成“一开始就有的另一种原料”。
:::

:::example{label="长度先记两个数量级"}
硫酸软骨素单个聚糖约 $250$ 个二糖单位。透明质酸一分子可由 $50\,000$ 个二糖单位组成。二者都长，但透明质酸所连蛋白质部分很小。
:::

## 二、糖胺聚糖共价连接于核心蛋白质

与糖胺聚糖链共价结合的蛋白质称为核心蛋白质。核心蛋白质均含有相应的糖胺聚糖取代结构域，一些蛋白聚糖通过核心蛋白质特殊结构域锚定在细胞表面或细胞外基质的大分子中。

核心蛋白质最小的蛋白聚糖称为丝甘蛋白聚糖（serglycan），含有肝素，主要存在于造血细胞和肥大细胞的贮存颗粒中，是一种典型的细胞内蛋白聚糖。

饰胶蛋白聚糖（decorin）的核心蛋白质分子质量为 $3.6$ 万，富含亮氨酸重复序列的模体，能与胶原相互作用，调节胶原纤维的形成和细胞外基质的组装。

黏结蛋白聚糖（syndecan）的核心蛋白质分子质量为 $3.2$ 万，含有胞质结构域、插入质膜的疏水结构域和胞外结构域。细胞外结构域连接有硫酸肝素和硫酸软骨素，是细胞膜表面主要蛋白聚糖之一。

蛋白聚糖聚合体（aggrecan）是细胞外基质的重要成分之一，由透明质酸长聚糖两侧经连接蛋白而结合许多蛋白聚糖而成。由于糖胺聚糖上羧基或硫酸根均带有负电荷，彼此相斥，所以在溶液中蛋白聚糖聚合物呈瓶刷状（图4-5）。

:::definition{label="核心蛋白质"}
与糖胺聚糖链共价结合的蛋白质称为核心蛋白质。均含有相应的糖胺聚糖取代结构域；一些蛋白聚糖通过核心蛋白质特殊结构域锚定在细胞表面或细胞外基质的大分子中。
:::

:::definition{label="丝甘蛋白聚糖"}
丝甘蛋白聚糖（serglycan）是核心蛋白质最小的蛋白聚糖，含有肝素，主要存在于造血细胞和肥大细胞的贮存颗粒中，是一种典型的细胞内蛋白聚糖。
:::

:::definition{label="饰胶蛋白聚糖"}
饰胶蛋白聚糖（decorin）核心蛋白质分子质量为 $3.6$ 万，富含亮氨酸重复序列模体，能与胶原相互作用，调节胶原纤维的形成和细胞外基质的组装。
:::

:::definition{label="黏结蛋白聚糖"}
黏结蛋白聚糖（syndecan）核心蛋白质分子质量为 $3.2$ 万，含胞质结构域、插入质膜的疏水结构域和胞外结构域。胞外结构域连接硫酸肝素和硫酸软骨素，是细胞膜表面主要蛋白聚糖之一。
:::

:::definition{label="蛋白聚糖聚合体"}
蛋白聚糖聚合体（aggrecan）是细胞外基质的重要成分之一，由透明质酸长聚糖两侧经连接蛋白而结合许多蛋白聚糖而成。糖胺聚糖上羧基或硫酸根均带负电荷、彼此相斥，溶液中呈瓶刷状。
:::

## 三、蛋白聚糖合成时在多肽链上逐一加上糖基

在内质网上，蛋白聚糖先合成核心蛋白质的多肽链部分，多肽链合成的同时即以 $O$-连接或 $N$-连接的方式在丝氨酸或天冬酰胺残基上进行聚糖加工。聚糖的延长和加工修饰主要是在高尔基体内进行，以单糖的 $\mathrm{UDP}$ 衍生物为供体，在多肽链上逐个加上单糖，而不是先合成二糖单位。每一单糖都有其特异性的糖基转移酶，使聚糖依次延长。聚糖合成后再予以修饰，糖胺的氨基来自谷氨酰胺，硫酸则来自“活性硫酸”，即 $3'$-磷酸腺苷 $5'$-磷酰硫酸。差向异构酶可将葡萄糖醛酸转变为艾杜糖醛酸。

:::definition{label="活性硫酸（PAPS）"}
硫酸来自“活性硫酸”，即 $3'$-磷酸腺苷 $5'$-磷酰硫酸。聚糖合成后再进行硫酸化等修饰。
:::

:::keypoint{label="蛋白聚糖合成只记这条顺序"}
- 内质网：先合成核心蛋白质多肽链；同时在 $\mathrm{Ser}$ 或 $\mathrm{Asn}$ 上作 $O$-或 $N$-连接加工。
- 高尔基体：延长和加工修饰；供体是单糖的 $\mathrm{UDP}$ 衍生物。
- **逐个加上单糖，而不是先合成二糖单位。**
- 合成后再修饰：氨基来自谷氨酰胺；硫酸来自活性硫酸；差向异构酶把葡萄糖醛酸变成艾杜糖醛酸。
:::

:::compare{title="N-连接聚糖合成 vs 糖胺聚糖延长"}
| 项目 | 第一节 $N$-连接聚糖 | 本节糖胺聚糖 |
|------|----------------------|--------------|
| 载体 | 长萜醇；可先装到 $14$ 糖再整体转移 | 没有长萜醇这本账；在已有多肽链上逐个加 |
| 是否先做成重复单位再接上去 | 先做成前体寡糖 | **不是先合成二糖单位** |
| 供体 | $\mathrm{UDP}$ 或 $\mathrm{GDP}$ 衍生物 | 单糖的 $\mathrm{UDP}$ 衍生物 |
| 合成后修饰 | 切葡萄糖／甘露糖，再加天线 | 氨基、硫酸、差向异构 |
:::

:::pitfall{label="重复二糖是结构单位，不是合成时先做好再聚合"}
结构上糖胺聚糖是二糖单位重复；合成上却是在多肽链上逐个加单糖。把“重复二糖”听成“先合成二糖再聚合”，会和教材原句直接相反。
:::

:::derivation{title="合成后再改三处"}
聚糖骨架先在高尔基体上延长，然后才：

1. 糖胺的氨基来自谷氨酰胺；
2. 硫酸来自 $3'$-磷酸腺苷 $5'$-磷酰硫酸（活性硫酸）；
3. 差向异构酶：葡萄糖醛酸 $\rightarrow$ 艾杜糖醛酸。

硫酸皮肤素和肝素的艾杜糖醛酸都走第 $3$ 步，不是另备一套糖醛酸供体。
:::

## 四、蛋白聚糖是细胞间基质的重要成分

### （一）蛋白聚糖最主要的功能是构成细胞间基质

在细胞基质中各种蛋白聚糖以特异的方式与弹性蛋白、胶原蛋白相连，赋予基质特殊的结构。基质中含有大量透明质酸，可与细胞表面的透明质酸受体结合，影响细胞与细胞的黏附、细胞迁移、增殖和分化等过程。由于蛋白聚糖中的糖胺聚糖是多阴离子化合物，可结合 $\mathrm{Na}^{+}$、$\mathrm{K}^{+}$，从而吸收水分子；糖的羟基也是亲水的，所以基质内的蛋白聚糖可以吸引、保留水而形成凝胶，容许小分子化合物自由扩散但阻止细菌通过，发挥保护作用。

细胞表面也有众多类型的蛋白聚糖，大多数含有硫酸肝素，分布广泛，在神经发育、细胞识别结合和分化等方面起重要的调节作用。有些细胞还存在丝甘蛋白聚糖，它的主要功能是与带正电荷的蛋白酶、羧肽酶或组织胺等相互作用，参与这些生物活性分子的贮存和释放。

:::definition{label="蛋白聚糖的基质功能"}
蛋白聚糖最主要的功能是构成细胞间基质。它们以特异方式与弹性蛋白、胶原蛋白相连，赋予基质特殊结构。
:::

:::cause-effect{title="多阴离子怎样把基质做成凝胶"}
- **因** 糖胺聚糖是多阴离子，可结合 $\mathrm{Na}^{+}$、$\mathrm{K}^{+}$ 从而吸水；糖的羟基也亲水
- **果** 基质内蛋白聚糖吸引、保留水而形成凝胶：小分子可自由扩散，细菌被阻止通过，起保护作用
:::

:::keypoint{label="基质账、表面账、颗粒账"}
- 基质：与弹性蛋白、胶原相连；大量透明质酸结合细胞表面透明质酸受体，影响黏附、迁移、增殖、分化。
- 细胞表面：大多数含硫酸肝素；神经发育、细胞识别结合和分化。
- 丝甘蛋白聚糖：与带正电荷的蛋白酶、羧肽酶或组织胺相互作用，参与贮存和释放。
:::

:::insight{label="凝胶要的是水，抗菌靠的是挡细菌、放小分子"}
教材没有把蛋白聚糖写成“杀菌剂”。保护作用来自凝胶的筛：小分子过得去，细菌过不去。
:::

### （二）各种蛋白聚糖有其特殊功能

肝素是重要的抗凝剂，能使凝血酶失活；还能特异地与毛细血管壁的脂蛋白脂肪酶结合，促使后者释放入血。在软骨中硫酸软骨素含量丰富，维持软骨的机械性能。角膜的胶原纤维之间充满硫酸角质素和硫酸皮肤素，使角膜透明。在肿瘤组织中各种蛋白聚糖的合成发生改变，可能与肿瘤增殖和转移有关。

:::example{label="四种特殊功能按组织记"}
- 肝素：抗凝（凝血酶失活）；结合毛细血管壁脂蛋白脂肪酶并促其入血。
- 硫酸软骨素：软骨中含量丰富，维持机械性能。
- 硫酸角质素 $+$ 硫酸皮肤素：充满角膜胶原纤维之间，使角膜透明。
- 肿瘤：各种蛋白聚糖合成发生改变，可能与增殖和转移有关。
:::

:::compare{title="肝素的两笔功能不要并成一笔"}
| 功能 | 对象 | 结果 |
|------|------|------|
| 抗凝 | 凝血酶 | 使凝血酶失活 |
| 脂代谢相关 | 毛细血管壁的脂蛋白脂肪酶 | 特异结合，促使其释放入血 |

第一节里脂蛋白脂肪酶还需要 $N$-连接核心五糖才有酶活性。肝素这一笔是把它从管壁上“请”进血液，不是改它的聚糖。
:::

:::pitfall{label="角膜透明写的是角质素加皮肤素，不是透明质酸"}
透明质酸在关节滑液、玻璃体和疏松结缔组织。角膜胶原纤维之间是硫酸角质素和硫酸皮肤素。名字里有“透明”的那种 $\mathrm{GAG}$，并不承担角膜透明。
:::

:::memory{label="本节必背要点"}
- [ ] 蛋白聚糖：以聚糖为主，糖胺聚糖共价连于不同核心蛋白质；一种可含一种或多种 $\mathrm{GAG}$。
- [ ] $\mathrm{GAG}$：不分支的重复二糖杂多糖；糖胺（$\mathrm{GlcNAc}$ 或 $\mathrm{GalNAc}$）$+$ 糖醛酸（葡萄糖醛酸或艾杜糖醛酸）。
- [ ] 除 $\mathrm{GAG}$ 外，蛋白聚糖还可含一些 $N$- 或 $O$-连接型聚糖。
- [ ] 六种：硫酸软骨素、硫酸皮肤素、硫酸角质素、透明质酸、肝素、硫酸类肝素。
- [ ] 除透明质酸外均带硫酸。
- [ ] 硫酸软骨素：$\mathrm{GalNAc}+$ 葡萄糖醛酸；$\mathrm{C}4$／$\mathrm{C}6$ 硫酸化；约 $250$ 个二糖；$O$-连接。
- [ ] 硫酸角质素：半乳糖 $+\mathrm{GlcNAc}$；角膜；也可与软骨素组成聚合物。
- [ ] 硫酸皮肤素：部分葡萄糖醛酸换成艾杜糖醛酸；差向异构在合成后。
- [ ] 肝素：葡萄糖胺 $+$ 艾杜糖醛酸；氨基氮和 $\mathrm{C}6$ 硫酸；合成时先葡萄糖醛酸再差向异构并 $\mathrm{C}2$ 硫酸化；肥大细胞；抗凝。
- [ ] 硫酸类肝素：细胞膜成分，突出于细胞外。
- [ ] 透明质酸：葡萄糖醛酸 $+\mathrm{GlcNAc}$；可 $50\,000$ 个二糖；蛋白质部分很小；滑液、玻璃体、疏松结缔组织。
- [ ] 核心蛋白质含 $\mathrm{GAG}$ 取代结构域，可锚定在细胞表面或细胞外基质。
- [ ] 丝甘蛋白聚糖：核心最小，含肝素，造血／肥大细胞贮存颗粒，细胞内蛋白聚糖。
- [ ] 饰胶蛋白聚糖：核心 $3.6$ 万，亮氨酸重复，调胶原纤维和基质组装。
- [ ] 黏结蛋白聚糖：核心 $3.2$ 万，三结构域，胞外连硫酸肝素和硫酸软骨素，膜表面主要蛋白聚糖之一。
- [ ] 蛋白聚糖聚合体（aggrecan）：透明质酸 $+$ 连接蛋白 $+$ 许多蛋白聚糖；负电荷相斥呈瓶刷状。
- [ ] 合成：内质网先做核心肽链，同时 $O$／$N$-连接；高尔基体用 $\mathrm{UDP}$-单糖逐个加，不是先合成二糖。
- [ ] 修饰：氨基来自谷氨酰胺；硫酸来自 $3'$-磷酸腺苷 $5'$-磷酰硫酸；差向异构酶改糖醛酸。
- [ ] 最主要功能：构成细胞间基质，与弹性蛋白、胶原相连。
- [ ] 透明质酸结合细胞表面受体，影响黏附、迁移、增殖、分化。
- [ ] 多阴离子结合 $\mathrm{Na}^{+}$、$\mathrm{K}^{+}$ 吸水成凝胶：小分子扩散，细菌被挡。
- [ ] 细胞表面蛋白聚糖大多含硫酸肝素，调节神经发育、识别和分化。
- [ ] 丝甘蛋白聚糖贮存／释放带正电的蛋白酶、羧肽酶或组织胺。
- [ ] 肝素抗凝并促脂蛋白脂肪酶入血；软骨素维持软骨机械性能；角质素 $+$ 皮肤素使角膜透明。
- [ ] 肿瘤组织中蛋白聚糖合成改变，可能与增殖和转移有关。
:::
