# 第三节　蛋白质结构与功能的关系

本节先把蛋白质写成生命活动的主要执行分子，摊开结构、运输、催化、信息、免疫、供能、酸碱平衡和血浆渗透压八项功能；再写它怎样与小分子、核酸及其他蛋白质相互作用（胰岛素–胰岛素受体、抗原–抗体／免疫球蛋白）；然后用 Anfinsen 核糖核酸酶、胰岛素种属差异、泛素、细胞色素 $\mathrm{c}$ 进化和镰状细胞贫血，证明一级结构是高级结构与功能的基础；最后用角蛋白／丝心蛋白、肌红蛋白与血红蛋白的氧解离曲线、$\mathrm{T}/\mathrm{R}$ 态、正协同、别构和 $2,3\text{-BPG}$，以及朊蛋白构象病，把“功能依赖特定空间结构”写全。

人体的每一个细胞和所有重要组成部分都有蛋白质存在。蛋白质是生命活动的执行者，参与完成体内的各种生理生化反应。

:::definition{label="蛋白质是生命活动的执行者"}
蛋白质存在于人体每一个细胞和所有重要组成部分，参与完成体内各种生理生化反应。它不是“有时帮忙的结构材料”，而是生命活动的主要执行分子。
:::

## 一、蛋白质是生命活动的主要执行分子

已知有些蛋白质具有多种功能，也有些蛋白质功能至今尚未阐明，蛋白质在机体内几乎无处不发挥各种特有的功能。

:::note{label="功能清单不是封闭的"}
教材先承认两件事：有的蛋白质一身兼多职；有的功能至今尚未阐明。下面八项是已经写清的主要执行方式，不是“蛋白质只有这八种用途”。
:::

### 1. 构成细胞和生物体结构

蛋白质是组成人体各种组织、器官、细胞的重要成分。人的肌肉、内脏、神经、血液、骨骼等，包括皮肤、毛发都含有丰富的蛋白质。蛋白质是细胞的重要结构组分，如膜蛋白质、细胞器的组成蛋白质、染色体蛋白质等。这些组织细胞每天都在不断地更新。因此，人体必须每天摄入一定量的蛋白质，作为构成和补充组织细胞的原料。

:::definition{label="蛋白质的结构功能"}
蛋白质是组成人体各种组织、器官、细胞的重要成分，也是细胞的重要结构组分，例如膜蛋白质、细胞器组成蛋白质、染色体蛋白质。组织细胞每天更新，所以必须每天摄入一定量蛋白质，作为构成和补充组织细胞的原料。
:::

### 2. 物质运输

体内的各种物质主要通过血液进行运输。人体不断地将从外界获取的营养物质和氧气运输到组织细胞，将代谢产生的废物排出体外。血红蛋白可以携带氧气到身体的各个部分，供组织细胞代谢使用。体内有许多营养素必须与某种特异的蛋白质结合，将其作为载体才能运转，例如血液中的载脂蛋白不仅运输脂质，还具有调节被运输脂质代谢的作用。清蛋白能与脂肪酸、$\mathrm{Ca}^{2+}$、胆红素、磺胺等多种物质结合。此外，血浆中还有皮质激素传递蛋白质、运铁蛋白、铜蓝蛋白等。

:::definition{label="运输蛋白"}
许多营养素必须与某种特异蛋白质结合、作为载体才能运转。血红蛋白运氧；载脂蛋白运输脂质并调节被运输脂质的代谢；清蛋白结合脂肪酸、$\mathrm{Ca}^{2+}$、胆红素、磺胺等；血浆中还有皮质激素传递蛋白质、运铁蛋白、铜蓝蛋白等。
:::

:::tip{label="载体不是“只是口袋”"}
载脂蛋白那一笔写了两件事：运脂质，还调节被运输脂质的代谢。把运输蛋白只听成“装上就走”，调节那半句会丢。
:::

### 3. 催化功能

人体内每时每刻都进行着化学反应来实施新陈代谢。大量的酶类快速精准地催化化学反应，所有的生命活动都离不开酶和水的参与，没有酶就没有生命。这些各具特殊功能的酶，绝大多数是蛋白质。

:::definition{label="酶绝大多数是蛋白质"}
生命活动离不开酶和水；没有酶就没有生命。各具特殊功能的酶，绝大多数是蛋白质。后文核酶是对“生物催化剂都是蛋白质”的补充，此处先立“绝大多数”。
:::

### 4. 信息交流

存在于细胞膜上使细胞对外界刺激产生相应的效应的受体是蛋白质。信号转导通路中的衔接蛋白，含有各种能与其他蛋白质结合的结构域，能形成各种信号复合体。通过特异性的蛋白质-蛋白质相互作用形成蛋白质复合体来激活下游信号通路。

:::definition{label="受体与衔接蛋白"}
使细胞对外界刺激产生相应效应的膜受体是蛋白质。信号转导通路中的衔接蛋白含有能与其他蛋白质结合的结构域，形成信号复合体；通过特异性蛋白质–蛋白质相互作用激活下游通路。
:::

### 5. 免疫功能

保护机体抵抗相应病原体的感染的抗体、淋巴因子等免疫分子都是蛋白质。

:::definition{label="免疫分子是蛋白质"}
抗体、淋巴因子等保护机体抵抗相应病原体感染的免疫分子都是蛋白质。后面免疫球蛋白的结构，是把这一笔展开。
:::

### 6. 氧化供能

体内的蛋白质可以彻底氧化分解为水、二氧化碳，并释放能量。正常膳食情况下，机体首先利用糖提供能量。饥饿时，组织蛋白质分解增加，故氧化供能是蛋白质的生理功能。

:::pitfall{label="氧化供能是生理功能，但不是优先供能方式"}
蛋白质可以彻底氧化分解为水、$\mathrm{CO}_2$ 并释能，所以氧化供能算生理功能。正常膳食下机体首先利用糖供能；饥饿时组织蛋白质分解才增加。不要把“能氧化供能”听成“日常靠蛋白质供能”。
:::

### 7. 维持机体的酸碱平衡

机体内组织细胞必须处于合适的酸碱度范围内，才能完成其正常的生理活动。机体的这种维持酸碱平衡的能力是通过肺、肾以及血液缓冲系统来实现的。蛋白质缓冲体系是血液缓冲系统的重要组成部分，因此，蛋白质在维持机体酸碱平衡方面起着十分重要的作用。

:::definition{label="蛋白质缓冲体系"}
维持酸碱平衡靠肺、肾以及血液缓冲系统。蛋白质缓冲体系是血液缓冲系统的重要组成部分。
:::

### 8. 维持正常的血浆渗透压

血浆胶体渗透压主要由蛋白质分子构成，其中，血浆清蛋白分子量较小，数目较多，决定血浆胶体渗透压的大小。血浆渗透压能使血浆和组织之间的物质交换保持平衡，如果血浆蛋白质特别是清蛋白的含量降低，血液内的水分便会过多地渗入周围组织，造成临床上的营养不良性水肿。

:::definition{label="血浆胶体渗透压与清蛋白"}
血浆胶体渗透压主要由蛋白质分子构成。血浆清蛋白分子量较小、数目较多，决定血浆胶体渗透压的大小。血浆蛋白质特别是清蛋白含量降低，水分过多渗入周围组织，造成营养不良性水肿。
:::

:::cause-effect{title="清蛋白降低怎样变成水肿"}
- **因** 血浆清蛋白分子量小、数目多，是决定血浆胶体渗透压的主要因素；其含量降低使血浆胶体渗透压下降
- **果** 血液内水分过多渗入周围组织，出现临床上的营养不良性水肿
:::

## 二、蛋白质通过与其他生物分子相互作用执行功能

### （一）蛋白质与小分子相互作用行使生物学功能

生物体内众多生命活动是与物质代谢及能量代谢密切相关的。细胞在特定时间或环境下含有众多低分子量代谢物，其中包括各种代谢路径的酶催化底物、抑制剂、代谢中间物和产物、副产物等小分子代谢物。蛋白质通过与小分子代谢物的相互作用，参与众多的生命活动过程，如酶的催化作用、物质转运、信息传递等，从整体上维持生物体新陈代谢活动的进行。

:::definition{label="蛋白质与小分子互作"}
细胞在特定时间或环境下含有众多低分子量代谢物，包括酶的底物、抑制剂、代谢中间物和产物、副产物等。蛋白质与这些小分子相互作用，参与催化、物质转运、信息传递等，从整体上维持新陈代谢。
:::

:::example{label="小分子互作落在三条账上"}
酶的催化作用、物质转运、信息传递，都是蛋白质与小分子代谢物互作的现场。后文血红蛋白与 $\mathrm{O}_2$、$2,3\text{-BPG}$ 的结合，是把这一段做成可画曲线的例子。
:::

### （二）蛋白质与核酸的相互作用发挥生物学效应

蛋白质和核酸是组成生物体的两种重要的生物大分子。蛋白质是基因表达的产物，基因的表达又离不开蛋白质的作用。蛋白质与核酸的相互作用存在于生物体内基因表达的各个水平之中。蛋白质有几种模体，如锌指模体、亮氨酸拉链、螺旋-转角-螺旋等专门结合 $\mathrm{DNA}$ 并发挥生物学效应。

$\mathrm{RNA}$ 存在于细胞质和细胞核中，目前发现的 $\mathrm{RNA}$ 除了少部分能以“核酶”形式单独发挥功能以外，绝大部分 $\mathrm{RNA}$ 都是与蛋白质形成 $\mathrm{RNA}$-蛋白质复合物。例如核糖体是细胞内蛋白质合成的场所，核糖体的两个亚基由精确折叠的蛋白质和 $\mathrm{rRNA}$ 组成；端粒酶（telomerase）是一种由催化蛋白和 $\mathrm{RNA}$ 模板组成的酶，可合成染色体末端的 $\mathrm{DNA}$；剪接体（spliceosome）是指进行 $\mathrm{RNA}$ 剪接时形成的多组分复合物，主要是由小分子的核 $\mathrm{RNA}$ 和蛋白质组成。蛋白质与 $\mathrm{RNA}$ 的相互作用在蛋白质合成、细胞发育调控等生理过程中起着决定性的作用。

:::definition{label="结合 DNA 的蛋白质模体"}
蛋白质有几种专门结合 $\mathrm{DNA}$ 并发挥生物学效应的模体，如锌指模体、亮氨酸拉链、螺旋-转角-螺旋。蛋白质与核酸的互作存在于基因表达的各个水平。
:::

:::definition{label="核酶"}
少部分 $\mathrm{RNA}$ 能以“核酶”形式单独发挥功能。除此以外，绝大部分 $\mathrm{RNA}$ 都与蛋白质形成 $\mathrm{RNA}$-蛋白质复合物。
:::

:::definition{label="核糖体"}
核糖体是细胞内蛋白质合成的场所。它的两个亚基由精确折叠的蛋白质和 $\mathrm{rRNA}$ 组成。
:::

:::definition{label="端粒酶"}
端粒酶（telomerase）由催化蛋白和 $\mathrm{RNA}$ 模板组成，可合成染色体末端的 $\mathrm{DNA}$。
:::

:::definition{label="剪接体"}
剪接体（spliceosome）是进行 $\mathrm{RNA}$ 剪接时形成的多组分复合物，主要由小分子核 $\mathrm{RNA}$ 和蛋白质组成。
:::

:::insight{label="基因表达不是“核酸单向指挥蛋白质”"}
蛋白质是基因表达的产物，基因的表达又离不开蛋白质。锌指、亮氨酸拉链、螺旋-转角-螺旋去结合 $\mathrm{DNA}$；核糖体、端粒酶、剪接体则是 $\mathrm{RNA}$–蛋白质复合物。把互作听成“核酸自己完成表达”，蛋白质合成和发育调控两本账会没有执行者。
:::

### （三）蛋白质相互作用是蛋白质执行功能的主要方式

蛋白质-蛋白质相互作用（protein-protein interaction，$\mathrm{PPI}$）是指两个或两个以上的蛋白质分子通过非共价键相互作用并发挥功能的过程。细胞进行生命活动过程是蛋白质在一定时空下相互作用的结果。生物学中的许多现象如物质代谢、信号转导、蛋白质翻译、蛋白质分泌、蛋白质剪切、细胞周期调控等均受蛋白质间相互作用的调控。通过蛋白质间相互作用，可改变细胞内酶的动力学特征，也可产生新的结合位点，改变蛋白质对底物的亲和力。蛋白质相互作用控制着大量的细胞活动事件，如细胞的增殖、分化和凋亡。

人体具有非常复杂的生物学功能，即使简单的功能也需要若干蛋白质共同参与完成。两个或多个蛋白质相互作用时，通过各自分子中特殊的局部空间结构，通过稳定的相互作用或瞬间的相互作用而相互识别并结合。

:::definition{label="蛋白质-蛋白质相互作用"}
蛋白质-蛋白质相互作用（protein-protein interaction，$\mathrm{PPI}$）是指两个或两个以上的蛋白质分子通过非共价键相互作用并发挥功能的过程。细胞生命活动是蛋白质在一定时空下相互作用的结果。
:::

:::definition{label="稳定互作与瞬间互作"}
两个或多个蛋白质通过各自分子中特殊的局部空间结构相互识别并结合，可以是稳定的相互作用，也可以是瞬间的相互作用。即使简单的功能，也往往需要若干蛋白质共同参与。
:::

:::keypoint{label="PPI 调控的不只是“黏在一起”"}
- 受 PPI 调控的现象包括：物质代谢、信号转导、蛋白质翻译、蛋白质分泌、蛋白质剪切、细胞周期调控。
- 互作的后果可以是：改变细胞内酶的动力学特征；产生新的结合位点；改变蛋白质对底物的亲和力。
- 控制的细胞事件包括增殖、分化和凋亡。
- 键的性质是非共价键，不是再做一条肽键把两个蛋白焊死。
:::

下面列举蛋白质相互作用的实例。

#### 1. 胰岛素与胰岛素受体的相互作用

人胰岛素与牛胰岛素的氨基酸序列高度相似。其种族差异，只在 $\mathrm{A}$ 链或 $\mathrm{B}$ 链中的个别氨基酸残基有所不同，$51$ 个氨基酸残基中有 $3$ 个不同。人胰岛素通过与体细胞膜表面的胰岛素受体相互作用发挥生物学作用。胰岛素受体属于受体酪氨酸激酶家族（receptor tyrosine kinases，$\mathrm{RTK}$）成员，是一种糖蛋白。胰岛素受体由 $\alpha$、$\beta$ 各两个亚基组成。两个 $\alpha$ 亚基之间、$\alpha$ 亚基与 $\beta$ 亚基之间通过二硫键连接。$\alpha$ 亚基一端暴露在细胞膜表面，具有胰岛素结合位点。$\beta$ 亚基由细胞膜向胞质延伸，其胞内结构域具有蛋白质激酶活性，可将酪氨酸残基进行磷酸化修饰，是胰岛素引发细胞内效应的功能单位。胰岛素与胰岛素受体 $\alpha$ 亚基结合后，导致 $\beta$ 亚基构象改变并激活其酪氨酸激酶活性，催化胰岛素受体发生自身磷酸化（图 1-18）。胰岛素通过两个结合位点激活胰岛素受体，磷酸化的胰岛素受体暴露其活性部位用于结合并磷酸化其他蛋白质。胰岛素受体的一个重要底物就是胰岛素受体底物（insulin receptor substrate，$\mathrm{IRS}$）。活化后的胰岛素受体可将 $\mathrm{IRS}$ 上具有重要作用的十几个酪氨酸残基磷酸化，磷酸化的 $\mathrm{IRS}$ 能够结合并激活下游效应物，将胰岛素信号向下游传递。胰岛素通过与胰岛素受体结合，启动胰岛素信号通路，发挥促进体细胞对葡萄糖的吸收，增强糖原、脂肪、蛋白质合成等作用，从而使血糖稳定在一定范围内。在 $2$ 型糖尿病患者体内，由于体细胞胰岛素受体数量降低，或者胰岛素信号不敏感，导致胰岛素与胰岛素受体之间亲和力下降，蛋白质-蛋白质之间相互作用变弱，同样数量的胰岛素就不能发挥应有的降低血糖的作用，因此 $2$ 型糖尿病患者的血糖处于较高水平。

:::definition{label="胰岛素受体"}
胰岛素受体属于受体酪氨酸激酶家族（$\mathrm{RTK}$）成员，是一种糖蛋白，由 $\alpha$、$\beta$ 各两个亚基组成。两个 $\alpha$ 亚基之间、$\alpha$ 与 $\beta$ 之间以二硫键相连。$\alpha$ 亚基一端暴露在膜表面，具有胰岛素结合位点；$\beta$ 亚基向胞质延伸，胞内结构域具有蛋白质激酶活性，是引发细胞内效应的功能单位。
:::

:::definition{label="自身磷酸化与 IRS"}
胰岛素与受体 $\alpha$ 亚基结合后，$\beta$ 亚基构象改变，酪氨酸激酶活性被激活，催化受体自身磷酸化。磷酸化的受体暴露活性部位，结合并磷酸化其他蛋白质。一个重要底物是胰岛素受体底物（$\mathrm{IRS}$）：活化受体可将 $\mathrm{IRS}$ 上十几个重要酪氨酸残基磷酸化，磷酸化的 $\mathrm{IRS}$ 结合并激活下游效应物。
:::

:::definition{label="胰岛素信号通路的代谢效应"}
胰岛素与受体结合后，促进体细胞对葡萄糖的吸收，增强糖原、脂肪、蛋白质合成，使血糖稳定在一定范围内。
:::

:::cause-effect{title="胰岛素怎样把膜外结合写成膜内磷酸化"}
- **因** 胰岛素与受体 $\alpha$ 亚基结合，引起 $\beta$ 亚基构象改变并激活其酪氨酸激酶活性
- **果** 受体自身磷酸化，再磷酸化 $\mathrm{IRS}$ 上十几个重要酪氨酸残基，信号向下游传递，促进葡萄糖吸收并增强糖原、脂肪、蛋白质合成
:::

:::example{label="2 型糖尿病是 PPI 变弱的临床账"}
$2$ 型糖尿病患者体细胞胰岛素受体数量降低，或胰岛素信号不敏感，使胰岛素与受体亲和力下降，蛋白质–蛋白质相互作用变弱。同样数量的胰岛素不能发挥应有的降血糖作用，血糖处于较高水平。病不在“没有胰岛素分子”，而在互作这一环变弱。
:::

:::pitfall{label="人胰岛素和牛胰岛素差 3 个残基，不是两种激素"}
人、牛胰岛素氨基酸序列高度相似，$51$ 个残基中只差 $3$ 个，种族差异落在 $\mathrm{A}$ 链或 $\mathrm{B}$ 链的个别位点。后文表 1-2 还要展开种属差异。不要把“序列不完全相同”听成“功能已经不是胰岛素”。
:::

:::concept{term="先问胰岛素绑的是 α 还是 β，再问磷酸化写在谁身上"}
看见“胰岛素受体”，先分亚基：$\alpha$ 在膜外绑胰岛素，$\beta$ 在膜内当激酶。结合发生在 $\alpha$，自身磷酸化和磷酸化 $\mathrm{IRS}$ 发生在 $\beta$ 这一侧。把受体听成“一个口袋把胰岛素吃进去”，酪氨酸激酶家族、自身磷酸化和 $2$ 型糖尿病的亲和力下降都没有地方可放。
:::

#### 2. 抗原与抗体的特异性结合

免疫球蛋白（immunoglobulin，$\mathrm{Ig}$）指具有抗体活性的蛋白质。主要存在于血浆中，也见于其他体液、组织和一些分泌液中。抗体是机体免疫细胞被抗原激活后，由 $\mathrm{B}$ 淋巴细胞分化成熟为浆细胞后所合成、分泌的一类能与相应抗原特异性结合的具有免疫功能的球蛋白。在电泳时主要出现于 $\gamma$ 球蛋白区域，占血浆蛋白质的 $20\%$；某些 $\beta$ 球蛋白和 $\alpha_2$ 球蛋白也含有免疫球蛋白。$\mathrm{Ig}$ 能识别、结合特异抗原，形成抗原-抗体复合物，激活补体系统从而解除抗原对机体的损伤。

:::definition{label="免疫球蛋白"}
免疫球蛋白（immunoglobulin，$\mathrm{Ig}$）指具有抗体活性的蛋白质。主要存在于血浆中，也见于其他体液、组织和一些分泌液中。
:::

:::definition{label="抗体"}
抗体是机体免疫细胞被抗原激活后，由 $\mathrm{B}$ 淋巴细胞分化成熟为浆细胞后所合成、分泌的一类能与相应抗原特异性结合的具有免疫功能的球蛋白。电泳时主要出现于 $\gamma$ 球蛋白区域，占血浆蛋白质的 $20\%$；某些 $\beta$ 球蛋白和 $\alpha_2$ 球蛋白也含有免疫球蛋白。
:::

:::definition{label="抗原-抗体复合物"}
$\mathrm{Ig}$ 能识别、结合特异抗原，形成抗原-抗体复合物，激活补体系统，从而解除抗原对机体的损伤。
:::

##### （1）免疫球蛋白的结构特点

免疫球蛋白可分为 $\mathrm{IgG}$、$\mathrm{IgA}$、$\mathrm{IgM}$、$\mathrm{IgD}$、$\mathrm{IgE}$，结构相类似，均由两条相同的重链（heavy chain，$\mathrm{H}$ 链）和两条相同的轻链（light chain，$\mathrm{L}$ 链）组成。其中 $\mathrm{IgG}$、$\mathrm{IgD}$、$\mathrm{IgE}$ 为四聚体，$\mathrm{IgA}$ 为二聚体，$\mathrm{IgM}$ 是五聚体（图 1-19）。$\mathrm{IgM}$ 的 $\mathrm{H}$ 链由 $450\sim 550$ 个氨基酸残基组成，$\mathrm{L}$ 链由 $212\sim 230$ 个氨基酸残基组成，两条链由二硫键相连。$\mathrm{IgM}$ 的分子量在免疫球蛋白中最大，为 $970\,\mathrm{kD}$，称为巨球蛋白（macroglobulin）。$\mathrm{IgM}$ 分子所特有的重链是 $\mu$ 链；$\mathrm{J}$ 链是由 $124$ 个氨基酸组成的酸性糖蛋白，通过二硫键连接到 $\mu$ 链的羧基端的半胱氨酸。

图 1-20 显示 $\mathrm{IgG}$ 的分子结构。每条 $\mathrm{L}$ 链由可变区（$\mathrm{V_L}$）和恒定区（$\mathrm{C_L}$）组成。每条 $\mathrm{H}$ 链也可由可变区（$\mathrm{V_H}$）和恒定区（$\mathrm{C_H}$）组成，其中恒定区分为三个结构域（$\mathrm{C_H}1$、$\mathrm{C_H}2$、$\mathrm{C_H}3$），$\mathrm{C_H}2$ 结构域含有补体结合部位。$\mathrm{C_H}3$ 结构域含有与中性粒细胞和巨噬细胞受体接触的部位。由 $\mathrm{L}$ 链和 $\mathrm{H}$ 链可变区形成的高变区是抗原结合的部位。$\mathrm{L}$ 链和 $\mathrm{H}$ 链之间由二硫键连接，$\mathrm{H}$ 链之间也由二硫键连接。

从 $\mathrm{N}$-端起，$\mathrm{H}$ 链的 $1/4$ 肽段及 $\mathrm{L}$ 链的 $1/2$ 肽段在各类 $\mathrm{Ig}$ 的排列顺序可变性大，称可变区（variable region，$\mathrm{V}$ 区），其功能是决定不同 $\mathrm{Ig}$ 与抗原结合的特异性。$\mathrm{H}$ 及 $\mathrm{L}$ 链的其余肽段称为恒定区（constant region，$\mathrm{C}$ 区）。$\mathrm{C}$ 区的功能是决定 $\mathrm{Ig}$ 的效应作用，也是 $\mathrm{Ig}$ 的分类基础（$\alpha$、$\gamma$、$\delta$、$\varepsilon$、$\mu$ 五大类）。$\mathrm{L}$ 链有两个基本型，即 $\kappa$ 和 $\lambda$ 型。一个特异的免疫球蛋白通常只含有两条 $\kappa$ 链或两条 $\lambda$ 链，不存在 $\kappa$ 和 $\lambda$ 的混合型。根据 $\mathrm{H}$ 链抗原性的差异可将其分为 $5$ 类：$\mu$ 链、$\gamma$ 链、$\alpha$ 链、$\delta$ 链和 $\varepsilon$ 链，不同 $\mathrm{H}$ 链与 $\mathrm{L}$ 链（$\kappa$ 或 $\lambda$ 链）组成完整免疫球蛋白的分子，分别称之为免疫球蛋白 $\mathrm{M}$、免疫球蛋白 $\mathrm{G}$、免疫球蛋白 $\mathrm{A}$、免疫球蛋白 $\mathrm{D}$ 和免疫球蛋白 $\mathrm{E}$。

:::definition{label="Ig 的四链基本结构"}
五类免疫球蛋白结构相类似，均由两条相同重链（$\mathrm{H}$ 链）和两条相同轻链（$\mathrm{L}$ 链）组成。$\mathrm{IgG}$、$\mathrm{IgD}$、$\mathrm{IgE}$ 为四聚体，$\mathrm{IgA}$ 为二聚体，$\mathrm{IgM}$ 是五聚体。
:::

:::definition{label="巨球蛋白"}
$\mathrm{IgM}$ 的 $\mathrm{H}$ 链 $450\sim 550$ 个残基，$\mathrm{L}$ 链 $212\sim 230$ 个残基，两链以二硫键相连。分子量在免疫球蛋白中最大，为 $970\,\mathrm{kD}$，称为巨球蛋白（macroglobulin）。特有重链为 $\mu$ 链；$\mathrm{J}$ 链是 $124$ 个氨基酸的酸性糖蛋白，经二硫键连到 $\mu$ 链羧基端的半胱氨酸。
:::

:::definition{label="IgG 的结构域分工"}
每条 $\mathrm{L}$ 链：可变区 $\mathrm{V_L}$ + 恒定区 $\mathrm{C_L}$。每条 $\mathrm{H}$ 链：可变区 $\mathrm{V_H}$ + 恒定区 $\mathrm{C_H}1$、$\mathrm{C_H}2$、$\mathrm{C_H}3$。$\mathrm{C_H}2$ 含补体结合部位；$\mathrm{C_H}3$ 含与中性粒细胞和巨噬细胞受体接触的部位；$\mathrm{L}$ 与 $\mathrm{H}$ 可变区形成的高变区是抗原结合部位。$\mathrm{L}$–$\mathrm{H}$ 之间、$\mathrm{H}$–$\mathrm{H}$ 之间均有二硫键。
:::

:::definition{label="可变区与恒定区"}
从 $\mathrm{N}$-端起，$\mathrm{H}$ 链的 $1/4$ 肽段及 $\mathrm{L}$ 链的 $1/2$ 肽段排列顺序可变性大，称可变区（$\mathrm{V}$ 区），决定不同 $\mathrm{Ig}$ 与抗原结合的特异性。其余肽段为恒定区（$\mathrm{C}$ 区），决定 $\mathrm{Ig}$ 的效应作用，也是分类基础（$\alpha$、$\gamma$、$\delta$、$\varepsilon$、$\mu$ 五大类）。
:::

:::definition{label="轻链型与重链类"}
$\mathrm{L}$ 链有 $\kappa$ 和 $\lambda$ 两个基本型；一个特异免疫球蛋白通常只含两条 $\kappa$ 或两条 $\lambda$，不存在混合型。$\mathrm{H}$ 链按抗原性分为 $\mu$、$\gamma$、$\alpha$、$\delta$、$\varepsilon$ 五类，分别与 $\mathrm{L}$ 链组成 $\mathrm{IgM}$、$\mathrm{IgG}$、$\mathrm{IgA}$、$\mathrm{IgD}$、$\mathrm{IgE}$。
:::

:::compare{title="五类免疫球蛋白"}
| 项目 | $\mathrm{IgG}$ | $\mathrm{IgA}$ | $\mathrm{IgM}$ | $\mathrm{IgD}$ | $\mathrm{IgE}$ |
|------|---------------|---------------|----------------|---------------|---------------|
| 重链 | $\gamma$ | $\alpha$ | $\mu$ | $\delta$ | $\varepsilon$ |
| 聚合 | 四聚体 | 二聚体 | 五聚体 | 四聚体 | 四聚体 |
| 轻链 | $\kappa$ 或 $\lambda$（不混合） | 同左 | 同左 | 同左 | 同左 |
| 其他 | 教材用其分子结构说明 $\mathrm{V}/\mathrm{C}$ 区 | — | 分子量最大（$970\,\mathrm{kD}$），称巨球蛋白；有 $\mathrm{J}$ 链 | — | — |
:::

:::pitfall{label="可变区认抗原，恒定区做效应和分类，不要并成“抗体头”"}
$\mathrm{V}$ 区（$\mathrm{H}$ 链 $\mathrm{N}$-端 $1/4$，$\mathrm{L}$ 链 $\mathrm{N}$-端 $1/2$）决定与抗原结合的特异性；高变区才是抗原结合部位。$\mathrm{C}$ 区决定效应作用，也是按 $\alpha$、$\gamma$、$\delta$、$\varepsilon$、$\mu$ 分类的基础；$\mathrm{C_H}2$ 绑补体，$\mathrm{C_H}3$ 接触中性粒细胞和巨噬细胞受体。把整条 $\mathrm{Ig}$ 听成“一个抗原口袋”，补体和吞噬细胞那两笔会丢。
:::

##### （2）抗原-抗体的特异性结合反应

由于抗原、抗体在结构上具有互相识别互相嵌合的构象，抗原分子的抗原决定簇（抗原表位）与抗体分子的超变区中沟槽分子表面的抗原结合点之间在化学结构和空间结构上是互补关系（图 1-21），所以抗原-抗体结合反应是特异性的。如果抗原抗体结合处的结构有很小的不匹配就会阻止两者的特异性结合。高亲和性的抗原抗体结合位点在空间构型上非常合适，两者结合牢固，不易解离；低亲和性抗体与抗原形成的复合物较易解离。在一定的外界环境下，如低 $\mathrm{pH}$、高浓度盐、反复冻融，抗原抗体复合物也可被解离，解离后的抗原抗体仍保持原有的结构、活性及特异性。天然抗原表面常常带有多种抗原表位，每种表位均能刺激机体产生一种特异性抗体，即一个抗原分子会刺激机体产生多种特异性抗体。

:::definition{label="抗原决定簇与超变区互补"}
抗原决定簇（抗原表位）与抗体分子超变区沟槽表面的抗原结合点，在化学结构和空间结构上是互补关系。结合反应因此是特异性的：很小的不匹配就会阻止特异性结合。
:::

:::definition{label="亲和性"}
高亲和性结合位点空间构型非常合适，结合牢固、不易解离；低亲和性复合物较易解离。
:::

:::note{label="复合物可解离，特异性和活性还在"}
低 $\mathrm{pH}$、高浓度盐、反复冻融可使抗原抗体复合物解离；解离后的抗原、抗体仍保持原有的结构、活性及特异性。第五节免疫沉淀还要用到“能结合也能再拆开”这一笔。
:::

:::insight{label="一个抗原不是只对应一种抗体"}
天然抗原表面常常带有多种抗原表位，每种表位都能刺激产生一种特异性抗体。所以一个抗原分子会刺激机体产生多种特异性抗体。不要把“特异性结合”听成“一种抗原全身只有一个表位、只诱生一种抗体”。
:::

|----------|----------|-------------|----------|

## 三、蛋白质一级结构是高级结构与功能的基础

### （一）一级结构是空间构象的基础

$20$ 世纪 $60$ 年代，$\mathrm{Anfinsen\ C.B.}$ 在研究核糖核酸酶 $\mathrm{A}$ 时发现，蛋白质的功能与其三级结构密切相关，而特定三级结构是以氨基酸顺序为基础的。核糖核酸酶 $\mathrm{A}$ 由 $124$ 个氨基酸残基组成，有 $4$ 对二硫键（$\mathrm{Cys}26$ 和 $\mathrm{Cys}84$，$\mathrm{Cys}40$ 和 $\mathrm{Cys}95$，$\mathrm{Cys}58$ 和 $\mathrm{Cys}110$，$\mathrm{Cys}65$ 和 $\mathrm{Cys}72$）（图 1-22a）。用尿素（或盐酸胍）和 $\beta$-巯基乙醇处理该酶溶液，分别破坏次级键和二硫键，使其二、三级结构遭到破坏，但肽键不受影响，故一级结构仍存在，此时该酶活性丧失殆尽。核糖核酸酶 $\mathrm{A}$ 中的 $4$ 对二硫键被 $\beta$-巯基乙醇还原成 —$\mathrm{SH}$ 后，若要再形成 $4$ 对二硫键，从理论上推算有 $105$ 种不同配对方式，唯有与天然核糖核酸酶 $\mathrm{A}$ 完全相同的配对方式，才能呈现酶活性。当用透析方法去除尿素和 $\beta$-巯基乙醇后，松散的多肽链，循其特定的氨基酸序列，卷曲折叠成天然酶的空间构象，$4$ 对二硫键也正确配对，这时酶活性又逐渐恢复至原来水平（图 1-22b）。这充分证明空间构象遭破坏的核糖核酸酶 $\mathrm{A}$ 只要其一级结构（氨基酸序列）未被破坏，就有可能回复到原来的三级结构，功能依然存在。

:::definition{label="Anfinsen 实验要证明的命题"}
蛋白质的功能与其三级结构密切相关，而特定三级结构是以氨基酸顺序为基础的。空间构象被破坏后，只要一级结构（氨基酸序列）未被破坏，就有可能回复到原来的三级结构，功能依然存在。
:::

:::definition{label="核糖核酸酶 A 的共价结构"}
核糖核酸酶 $\mathrm{A}$ 由 $124$ 个氨基酸残基组成，有 $4$ 对二硫键：$\mathrm{Cys}26$–$\mathrm{Cys}84$，$\mathrm{Cys}40$–$\mathrm{Cys}95$，$\mathrm{Cys}58$–$\mathrm{Cys}110$，$\mathrm{Cys}65$–$\mathrm{Cys}72$。
:::

:::definition{label="尿素（或盐酸胍）与 β-巯基乙醇的分工"}
尿素（或盐酸胍）破坏次级键，$\beta$-巯基乙醇破坏二硫键，二、三级结构被拆掉；肽键不受影响，一级结构仍在。此时酶活性丧失殆尽。
:::

:::note{label="105 种配对里只有一种有活性"}
$4$ 对二硫键被还原成巯基后，再氧化成 $4$ 对二硫键，理论上有 $105$ 种不同配对方式，唯有与天然酶完全相同的配对才呈现酶活性。透析去掉尿素和 $\beta$-巯基乙醇后，松散肽链循特定氨基酸序列卷曲折叠，二硫键正确配对，活性逐渐恢复至原来水平。
:::

:::timeline{period="Anfinsen 核糖核酸酶 A 实验"}
- **天然酶** 124 个氨基酸残基，4 对二硫键按 Cys26–Cys84、Cys40–Cys95、Cys58–Cys110、Cys65–Cys72 配对，具有三级结构和酶活性
- **加入尿素（或盐酸胍）和 β-巯基乙醇** 次级键与二硫键被破坏，二、三级结构解开，肽键和一级结构仍在，活性丧失殆尽
- **理论上的再配对** 4 对二硫键重形成有 105 种方式，只有天然配对才有活性
- **透析去除尿素和 β-巯基乙醇** 肽链按氨基酸序列重新折叠，4 对二硫键正确配对，活性逐渐恢复到原来水平
- **结论** 一级结构未被破坏，空间构象和功能就有可能回复
:::

:::derivation{title="为什么这个实验把“一级结构决定空间构象”写死"}
- 拆的是次级键和二硫键，不是肽键 → 一级结构还在，二、三级结构没了，活性也没了。
- 重折叠不是随机碰对 $105$ 种二硫键配对，而是循氨基酸序列回到天然构象。
- 活性随正确三级结构重现而恢复 → 功能依赖三级结构，三级结构以序列为基础。
- 第四节讲复性时还要再引用同一套实验，户头不要另起。
:::

:::pitfall{label="Anfinsen 证明的是“序列还在就能折回去”，不是“变性从不伤一级结构”"}
变性因素拆的是二硫键和非共价键，不涉及氨基酸序列。若一级结构被水解掉，就不是这个实验的复性，而是不可逆的降解。后文凝固是变性后再加热的不可逆结果，不要和这里的透析复性并成一句。
:::

### （二）一级结构相似的蛋白质具有相似的高级结构与功能

蛋白质一级结构的比较，常被用来预测蛋白质之间结构与功能的相似性。同源性较高的蛋白质之间，可能具有相类似的功能。值得指出的是，同源蛋白质是指由同一基因进化而来的相关基因所表达的一类蛋白质。已有大量的实验结果证明，一级结构相似的多肽或蛋白质，其空间构象以及功能也相似。例如不同哺乳类动物的胰岛素分子都是由 $\mathrm{A}$ 和 $\mathrm{B}$ 两条肽链组成，且二硫键的配对位置和空间构象也极相似，一级结构中仅个别氨基酸有差异，因而它们都执行着相同的调节糖代谢等的生理功能（表 1-2）。

:::definition{label="同源蛋白质"}
同源蛋白质是指由同一基因进化而来的相关基因所表达的一类蛋白质。同源性较高的蛋白质之间，可能具有相类似的功能。
:::

:::definition{label="一级结构相似则构象与功能相似"}
大量实验证明：一级结构相似的多肽或蛋白质，其空间构象以及功能也相似。比较一级结构，常被用来预测结构与功能的相似性。
:::

|--------|--------------|---------------|----------------|----------------|
| 人 | $\mathrm{Thr}$ | $\mathrm{Ser}$ | $\mathrm{Ile}$ | $\mathrm{Thr}$ |
| 猪 | $\mathrm{Thr}$ | $\mathrm{Ser}$ | $\mathrm{Ile}$ | $\mathrm{Ala}$ |
| 狗 | $\mathrm{Thr}$ | $\mathrm{Ser}$ | $\mathrm{Ile}$ | $\mathrm{Ala}$ |
| 兔 | $\mathrm{Thr}$ | $\mathrm{Ser}$ | $\mathrm{Ile}$ | $\mathrm{Ser}$ |

:::example{label="哺乳类胰岛素：骨架相同，个别残基可换"}
不同哺乳类胰岛素都是 $\mathrm{A}$、$\mathrm{B}$ 两条肽链，二硫键配对位置和空间构象极相似，一级结构仅个别氨基酸有差异，因而都执行相同的调节糖代谢等生理功能。人与猪、狗只差 $\mathrm{B}30$（$\mathrm{Thr}$ 对 $\mathrm{Ala}$）；牛在 $\mathrm{A}8$、$\mathrm{A}10$、$\mathrm{B}30$ 与人不同。
:::

在对不同物种中具有相同功能的蛋白质进行结构分析时，发现它们具有相似的氨基酸序列。例如，泛素是一个含 $76$ 个氨基酸残基的调节其他蛋白质降解的多肽，物种相差甚远的果蝇与人类的泛素蛋白却含有完全相同的一级结构。当然，在相隔甚远的两种物种中，执行相似功能的蛋白质，其氨基酸序列、分子量大小等也可有很大的差异。

:::definition{label="泛素"}
泛素是含 $76$ 个氨基酸残基、调节其他蛋白质降解的多肽。果蝇与人类的泛素一级结构完全相同。教材用它说明：功能相同的蛋白质，在远缘物种中也可以序列高度保守。
:::

:::note{label="相似不是绝对"}
相隔甚远的两种物种中，执行相似功能的蛋白质，其氨基酸序列、分子量大小等也可有很大的差异。比较一级结构可以预测，但不能把“功能相似”写成“序列必须逐个相同”。
:::

然而，有些蛋白质的氨基酸序列也不是绝对固定不变的，而是有一定的可塑性。据估算，人类有 $20\%\sim 30\%$ 的蛋白质具有多态性（polymorphism），即在人类群体中的不同个体间，这些蛋白质存在着氨基酸序列的多样性，但几乎不影响蛋白质的功能。

:::definition{label="蛋白质多态性"}
人类约 $20\%\sim 30\%$ 的蛋白质具有多态性（polymorphism）：群体中不同个体间氨基酸序列存在多样性，但几乎不影响蛋白质的功能。序列有可塑性，不等于关键残基可以随便换。
:::

### （三）某些蛋白质氨基酸序列可反映生物进化信息

通过比较一些广泛存在于生物界不同种系间的蛋白质的一级结构，可以帮助了解物种进化间的关系。如细胞色素 $\mathrm{c}$（图 1-23），物种间越接近，则一级结构越相似，其空间构象和功能也相似。猕猴与人类很接近，两者一级结构只相差 $1$ 个氨基酸残基，即第 $102$ 位氨基酸猕猴为精氨酸，人类为酪氨酸；人类和黑猩猩的 $\mathrm{Cyt\ c}$ 一级结构完全相同；面包酵母与人类从物种进化距离极远，所以两者 $\mathrm{Cyt\ c}$ 一级结构相差达 $51$ 个氨基酸。灰鲸是哺乳类动物，是由陆上动物演化而来，所以它与猪、牛及羊等的 $\mathrm{Cyt\ c}$ 只有 $2$ 个氨基酸的差异。

:::definition{label="细胞色素 c 作为分子钟"}
广泛存在于不同种系间的蛋白质，比较其一级结构可帮助了解物种进化关系。物种间越接近，细胞色素 $\mathrm{c}$ 一级结构越相似，空间构象和功能也相似。
:::

:::compare{title="细胞色素 c 一级结构差异与进化距离"}
| 比较双方 | 一级结构差异 | 教材要说明的关系 |
|----------|--------------|------------------|
| 人类与黑猩猩 | 完全相同 | 种系极近 |
| 人类与猕猴 | 只差 $1$ 个残基：第 $102$ 位人类为酪氨酸，猕猴为精氨酸 | 很接近 |
| 灰鲸与猪、牛、羊 | 只差 $2$ 个氨基酸 | 灰鲸是哺乳类，由陆上动物演化而来 |
| 面包酵母与人类 | 相差达 $51$ 个氨基酸 | 进化距离极远 |
:::

:::insight{label="灰鲸那一笔写的是“陆生哺乳类亲戚”，不是“鱼”"}
灰鲸与猪、牛、羊的 $\mathrm{Cyt\ c}$ 只差 $2$ 个氨基酸，教材用来支持：它是哺乳类、由陆上动物演化而来。不要凭外形把它放到与酵母同一档的“远缘”。
:::

### （四）重要蛋白质的氨基酸序列改变可引起疾病

通过大量蛋白质的结构与功能相关性的研究，发现具有不同生物学功能的蛋白质，含有不同的氨基酸序列即不同的一级结构。同样，从大量人类遗传性疾病的基因与相关蛋白质分析结果，获知这些疾病的病因可以是基因点突变引起 $1$ 个氨基酸的改变，如镰状细胞贫血（sickle-cell anemia）；也可以是基因大片段碱基缺失导致大片段肽链的缺失，如肌营养不良症（muscular dystrophy），这说明蛋白质一级结构的变化，可导致其功能的改变。

蛋白质分子中起关键作用的氨基酸残基缺失或被替代，都会严重影响空间构象乃至生理功能，甚至导致疾病产生。例如，正常人血红蛋白 $\beta$ 亚基的第 $6$ 位氨基酸是谷氨酸，而镰状细胞贫血患者的血红蛋白中，谷氨酸变成了缬氨酸，即酸性氨基酸被中性氨基酸替代，仅此一个氨基酸之差，原是水溶性的血红蛋白，就聚集成丝，相互黏着，导致红细胞变形成为镰刀状而极易破碎，产生贫血。这种蛋白质分子发生变异所导致的疾病，被称为“分子病（molecular disease）”，其病因为基因突变所致。

但并非一级结构中的每个氨基酸都很重要，如 $\mathrm{Cyt\ c}$，这个蛋白质分子中在某些位点即使置换数十个氨基酸残基，其功能依然不变。

:::definition{label="分子病"}
蛋白质分子发生变异所导致的疾病称为分子病（molecular disease），病因为基因突变。可以是点突变引起 $1$ 个氨基酸改变（如镰状细胞贫血），也可以是大片段碱基缺失导致大片段肽链缺失（如肌营养不良症）。
:::

:::definition{label="镰状细胞贫血的分子机制"}
正常人血红蛋白 $\beta$ 亚基第 $6$ 位是谷氨酸；患者该位变成缬氨酸，酸性氨基酸被中性氨基酸替代。仅此一个氨基酸之差，原水溶性的血红蛋白聚集成丝、相互黏着，红细胞变成镰刀状而极易破碎，产生贫血。后文成人 $\mathrm{Hb}$ 组成里，患者红细胞中的 $\mathrm{Hb}$ 记为 $\alpha_2\mathrm{S}_2$。
:::

:::pitfall{label="关键残基不能换，不等于每个残基都不能换"}
起关键作用的残基缺失或被替代，会严重影响构象和功能，甚至致病。但并非每个氨基酸都很重要：$\mathrm{Cyt\ c}$ 在某些位点即使置换数十个残基，功能依然不变；多态性也可以几乎不影响功能。不要把镰状细胞贫血听成“任何一位氨基酸变了都是分子病”。
:::

:::cause-effect{title="β6 谷氨酸变成缬氨酸怎样变成贫血"}
- **因** $\beta$ 亚基第 $6$ 位酸性的谷氨酸被中性的缬氨酸替代，血红蛋白水溶性下降，聚集成丝、相互黏着
- **果** 红细胞变形成镰刀状，极易破碎，产生镰状细胞贫血（分子病）
:::

:::concept{term="先问一级结构还在不在，再问换的是不是关键残基"}
空间构象和功能的基础是一级结构：Anfinsen 证明序列在、构象就能折回来；种属间相似序列给出相似功能；进化距离写在 $\mathrm{Cyt\ c}$ 的残基差上。致病这一笔要再问：换的是不是关键残基——$\beta 6\ \mathrm{Glu}\to\mathrm{Val}$ 是分子病，$\mathrm{Cyt\ c}$ 某些位点换数十个仍可工作。把“一级结构决定功能”听成“每个氨基酸同等重要”，多态性和分子病会对错户头。
:::

## 四、蛋白质的功能依赖特定空间结构

体内蛋白质所具有的特定空间构象都与其发挥特殊的生理功能有着密切的关系。例如角蛋白含有大量 $\alpha$-螺旋结构，与富含角蛋白组织的坚韧性并富有弹性直接相关；而丝心蛋白分子中含有大量 $\beta$-折叠结构，致使蚕丝具有伸展和柔软的特性。以下阐述肌红蛋白和血红蛋白与蛋白质空间结构和功能的关系。

:::example{label="二级结构含量直接写成组织力学"}
角蛋白含大量 $\alpha$-螺旋，对应富含角蛋白组织的坚韧并富有弹性；丝心蛋白含大量 $\beta$-折叠，致使蚕丝伸展而柔软。空间构象不是装饰，力学性质已经写在二级结构里。
:::

### （一）血红蛋白亚基与肌红蛋白结构相似

肌红蛋白（myoglobin，$\mathrm{Mb}$）与血红蛋白都是含有血红素辅基的蛋白质。血红素是铁卟啉化合物（图 1-24），它由 $4$ 个吡咯环通过 $4$ 个次甲基相连成为一个环形，$\mathrm{Fe}^{2+}$ 居于环中。$\mathrm{Fe}^{2+}$ 有 $6$ 个配位键，其中 $4$ 个与吡咯环的 $\mathrm{N}$ 配位结合，$1$ 个配位键和肌红蛋白的第 $93$ 位（$\mathrm{F}8$）组氨酸残基结合，氧则与 $\mathrm{Fe}^{2+}$ 形成第 $6$ 个配位键，接近第 $64$ 位（$\mathrm{E}7$）组氨酸。

:::definition{label="血红素"}
血红素是铁卟啉化合物： $4$ 个吡咯环经 $4$ 个次甲基连成环形，$\mathrm{Fe}^{2+}$ 居于环中。$\mathrm{Fe}^{2+}$ 有 $6$ 个配位键： $4$ 个与吡咯环 $\mathrm{N}$ 配位；$1$ 个与肌红蛋白第 $93$ 位（$\mathrm{F}8$）组氨酸结合；氧与 $\mathrm{Fe}^{2+}$ 形成第 $6$ 个配位键，接近第 $64$ 位（$\mathrm{E}7$）组氨酸。
:::

::figure{src="/images/biochemistry/textbook/p0055_01.png" caption="图1-24 血红素结构。四个吡咯环经次甲基连成铁卟啉，Fe 居于环中，上方两个丙酸侧链带负电。" alt="铁卟啉环结构式：中央 Fe 与四个吡咯氮配位，环上有甲基、乙烯基和两个丙酸侧链"}

从 $\mathrm{X}$ 射线衍射法分析获得的肌红蛋白的三维结构（见图 1-13）中，可见它是一个只有三级结构的单链蛋白质，有 $8$ 个 $\alpha$-螺旋结构肽段，分别用字母 $\mathrm{A}\sim\mathrm{H}$ 命名。整条多肽链折叠成紧密球状分子，氨基酸残基上的疏水侧链大都在分子内部，而含极性及电荷的侧链则大多在分子表面，因此其水溶性较好。$\mathrm{Mb}$ 分子内部有一个袋形空穴，血红素居于其中。血红素分子中的两个丙酸侧链以离子键形式与肽链中的两个碱性氨基酸侧链上的正电荷相连，加之肽链中的 $\mathrm{F}8$ 组氨酸残基还与 $\mathrm{Fe}^{2+}$ 形成配位结合，所以血红素辅基可与蛋白质部分稳定结合。

:::definition{label="肌红蛋白"}
肌红蛋白（$\mathrm{Mb}$）是只有三级结构的单链蛋白质，含血红素辅基。有 $8$ 个 $\alpha$-螺旋肽段，命名为 $\mathrm{A}\sim\mathrm{H}$。整条链折叠成紧密球状：疏水侧链多在内部，极性及带电侧链多在表面，水溶性较好。分子内部袋形空穴容纳血红素。
:::

:::note{label="血红素怎样稳在口袋里"}
血红素的两个丙酸侧链以离子键与肽链中两个碱性氨基酸侧链的正电荷相连，再加上 $\mathrm{F}8$ 组氨酸与 $\mathrm{Fe}^{2+}$ 配位，辅基便与蛋白质部分稳定结合。
:::

血红蛋白（hemoglobin，$\mathrm{Hb}$）是由 $4$ 个亚基组成的四级结构（见图 1-17）蛋白质，每个亚基结构中间有一个疏水局部，可结合 $1$ 个血红素并携带 $1$ 分子氧，因此一分子 $\mathrm{Hb}$ 共结合 $4$ 个氧分子。成年人红细胞中的 $\mathrm{Hb}$ 主要由 $2$ 条 $\alpha$ 肽链和 $2$ 条 $\beta$ 肽链（$\alpha_2\beta_2$）组成，$\alpha$ 链含 $141$ 个氨基酸残基，$\beta$ 链含 $146$ 个氨基酸残基。胎儿期的 $\mathrm{Hb}$ 主要为 $\alpha_2\gamma_2$，胚胎期为 $\alpha_2\varepsilon_2$。此外，在成人 $\mathrm{Hb}$ 中存在较少的 $\alpha_2\delta_2$ 型，而镰状细胞贫血患者红细胞中的 $\mathrm{Hb}$ 为 $\alpha_2\mathrm{S}_2$。$\mathrm{Hb}$ 的 $\beta$、$\gamma$ 和 $\delta$ 亚基的一级结构高度保守。$\mathrm{Hb}$ 各亚基的三级结构与 $\mathrm{Mb}$ 极为相似。$\mathrm{Hb}$ 亚基之间通过 $8$ 对盐键（图 1-25），使 $4$ 个亚基紧密结合而形成亲水的球状蛋白质。

:::definition{label="血红蛋白"}
血红蛋白（$\mathrm{Hb}$）是由 $4$ 个亚基组成的四级结构蛋白质。每个亚基中间有一个疏水局部，结合 $1$ 个血红素并携带 $1$ 分子氧，故一分子 $\mathrm{Hb}$ 共结合 $4$ 个氧分子。各亚基的三级结构与 $\mathrm{Mb}$ 极为相似；亚基之间通过 $8$ 对盐键紧密结合，形成亲水的球状蛋白质。
:::

:::definition{label="人血红蛋白的组成型"}
成人红细胞中主要为 $\alpha_2\beta_2$（$\alpha$ 链 $141$ 残基，$\beta$ 链 $146$ 残基）；胎儿期主要为 $\alpha_2\gamma_2$；胚胎期为 $\alpha_2\varepsilon_2$；成人尚有较少的 $\alpha_2\delta_2$；镰状细胞贫血患者为 $\alpha_2\mathrm{S}_2$。$\beta$、$\gamma$、$\delta$ 亚基一级结构高度保守。
:::

::figure{src="/images/biochemistry/textbook/p0055_02.png" caption="图1-25 脱氧 Hb 亚基间和亚基内的盐键。α1 与 α2、α 与 β 之间以及 β 链内部的 His146–Asp94 等盐键，把四聚体锁在紧密的脱氧状态。" alt="四条肽链示意图：β2、α1、α2、β1 以盐键相连，标出 Arg、Asp、Lys、His 等成盐残基序号"}

:::compare{title="肌红蛋白与血红蛋白"}
| 项目 | 肌红蛋白 $\mathrm{Mb}$ | 血红蛋白 $\mathrm{Hb}$ |
|------|----------------------|----------------------|
| 结构层次 | 只有三级结构的单链 | $4$ 个亚基的四级结构 |
| 螺旋 | $8$ 段 $\alpha$-螺旋（$\mathrm{A}\sim\mathrm{H}$） | 各亚基三级结构与 $\mathrm{Mb}$ 极为相似 |
| 辅基 | $1$ 个血红素 | 每个亚基 $1$ 个血红素，共 $4$ 个 |
| 结合氧 | $1$ 分子氧 | $4$ 分子氧 |
| 亚基联系 | 无四级结构 | $8$ 对盐键使四亚基紧密结合成亲水球状蛋白 |
| 成人体内主要形式 | 肌组织中的贮氧蛋白 | 红细胞中 $\alpha_2\beta_2$ |
:::

### （二）血红蛋白亚基构象变化可影响亚基与氧结合

$\mathrm{Hb}$ 与 $\mathrm{Mb}$ 一样可逆地与 $\mathrm{O}_2$ 结合，氧合 $\mathrm{Hb}$ 占总 $\mathrm{Hb}$ 的百分数（称百分饱和度）随 $\mathrm{O}_2$ 浓度变化而变化。图 1-26 为 $\mathrm{Hb}$ 和 $\mathrm{Mb}$ 的氧解离曲线，前者为 $\mathrm{S}$ 状曲线，后者为直角双曲线。可见，$\mathrm{Mb}$ 易与 $\mathrm{O}_2$ 结合，而 $\mathrm{Hb}$ 与 $\mathrm{O}_2$ 的结合在 $\mathrm{O}_2$ 分压较低时较难。$\mathrm{Hb}$ 与 $\mathrm{O}_2$ 结合的“$\mathrm{S}$”形曲线提示 $\mathrm{Hb}$ 的 $4$ 个亚基与 $4$ 个 $\mathrm{O}_2$ 结合时有 $4$ 个不同的平衡常数。$\mathrm{Hb}$ 最后一个亚基与 $\mathrm{O}_2$ 结合时其常数最大，从“$\mathrm{S}$”形曲线的后半部呈直线上升可证明此点。根据“$\mathrm{S}$”形曲线的特征可知，$\mathrm{Hb}$ 中第一个亚基与 $\mathrm{O}_2$ 结合以后，促进第二及第三个亚基与 $\mathrm{O}_2$ 的结合，当前 $3$ 个亚基与 $\mathrm{O}_2$ 结合后，又大大促进第四个亚基与 $\mathrm{O}_2$ 结合，这种效应称为正协同效应（positive cooperativity）。协同效应的定义是指一个亚基与其配体（$\mathrm{Hb}$ 中的配体为 $\mathrm{O}_2$）结合后，能影响此寡聚体中另一亚基与配体的结合能力。如果是促进作用则称为正协同效应；反之则为负协同效应。

:::definition{label="百分饱和度"}
氧合 $\mathrm{Hb}$ 占总 $\mathrm{Hb}$ 的百分数称为百分饱和度，随 $\mathrm{O}_2$ 浓度（分压）变化而变化。
:::

:::definition{label="氧解离曲线"}
$\mathrm{Mb}$ 的氧解离曲线为直角双曲线，易与 $\mathrm{O}_2$ 结合。$\mathrm{Hb}$ 的氧解离曲线为 $\mathrm{S}$ 状（sigmoid）曲线：在 $\mathrm{O}_2$ 分压较低时较难结合；曲线后半部直线上升，显示最后一个亚基与 $\mathrm{O}_2$ 结合的平衡常数最大。
:::

::figure{src="/images/biochemistry/textbook/p0055_03.png" caption="图1-26 Hb 和 Mb 的氧解离曲线。Mb 为直角双曲线，低分压即可高饱和；Hb 为 S 形曲线，P50 约在静脉血氧分压附近，动脉血处接近饱和。" alt="氧解离曲线：横轴氧分压，纵轴氧饱和度；浅色 Mb 双曲线在上，深色 Hb S 形曲线过 P50，左侧标静脉血、右侧标动脉血"}

:::definition{label="协同效应"}
一个亚基与其配体结合后，能影响此寡聚体中另一亚基与配体的结合能力。促进作用称为正协同效应（positive cooperativity）；反之则为负协同效应。$\mathrm{Hb}$ 中配体为 $\mathrm{O}_2$。
:::

:::definition{label="血红蛋白的正协同效应"}
$\mathrm{Hb}$ 第一个亚基与 $\mathrm{O}_2$ 结合以后，促进第二及第三个亚基与 $\mathrm{O}_2$ 结合；前 $3$ 个亚基结合后，又大大促进第四个亚基与 $\mathrm{O}_2$ 结合。$4$ 个亚基对应 $4$ 个不同的平衡常数，末一个最大。这就是 $\mathrm{S}$ 形曲线的来历。
:::

:::pitfall{label="不要把 Mb 的双曲线和 Hb 的 S 形并成“都能运氧”"}
$\mathrm{Mb}$ 易结合 $\mathrm{O}_2$，曲线是直角双曲线，适合在组织中把氧接住、贮存。$\mathrm{Hb}$ 在低分压时结合较难，靠正协同在肺里快速饱和、在组织里快速放氧。第二节已写过：亚基单独存在时与氧亲和力增强，但在组织中难于释放氧，失去血红蛋白原有的运氧作用。没有四级结构和协同，运氧这本账做不成。
:::

$\mathrm{Perutz\ M.}$ 等利用 $\mathrm{X}$ 射线衍射技术，分析 $\mathrm{Hb}$ 和氧合 $\mathrm{Hb}$ 晶体的三维结构图谱，提出了解释 $\mathrm{O}_2$ 与 $\mathrm{Hb}$ 结合的正协同效应的理论。

未结合 $\mathrm{O}_2$ 时，$\mathrm{Hb}$ 的 $\alpha_1/\beta_1$ 和 $\alpha_2/\beta_2$ 呈对角排列，结构较为紧密，称为紧张态（tense state，$\mathrm{T}$ 态），$\mathrm{T}$ 态 $\mathrm{Hb}$ 与 $\mathrm{O}_2$ 的亲和力小。随着 $\mathrm{O}_2$ 的结合，$4$ 个亚基的羧基末端之间的盐键断裂，其二级、三级和四级结构也发生变化，使 $\alpha_1/\beta_1$ 和 $\alpha_2/\beta_2$ 的长轴形成 $15^{\circ}$ 的夹角（图 1-27），结构显得相对松弛，称为松弛态（relaxed state，$\mathrm{R}$ 态）。图 1-28 显示了 $\mathrm{Hb}$ 氧合与脱氧时 $\mathrm{T}$ 态和 $\mathrm{R}$ 态相互转换的可能方式。$\mathrm{T}$ 态转变成 $\mathrm{R}$ 态是逐个结合 $\mathrm{O}_2$ 而完成的。在脱氧 $\mathrm{Hb}$ 中，$\mathrm{Fe}^{2+}$ 半径比卟啉环中间的孔大，因此 $\mathrm{Fe}^{2+}$ 高出卟啉环平面 $0.04\,\mathrm{nm}$（$0.4\,\text{Å}$），而靠近 $\mathrm{F}8$ 位组氨酸残基。当第 $1$ 个 $\mathrm{O}_2$ 与血红素 $\mathrm{Fe}^{2+}$ 结合后，使 $\mathrm{Fe}^{2+}$ 的半径变小，进入到卟啉环中间的小孔中（图 1-29），引起 $\mathrm{F}$ 肽段等一系列微小的移动，同时影响附近肽段的构象，造成两个 $\alpha$ 亚基间盐键断裂，使亚基间结合松弛，可促进第二个亚基与 $\mathrm{O}_2$ 结合，依此方式可影响第三、四个亚基与 $\mathrm{O}_2$ 结合，最后使 $4$ 个亚基全处于 $\mathrm{R}$ 态。

:::definition{label="紧张态（T 态）"}
未结合 $\mathrm{O}_2$ 时，$\mathrm{Hb}$ 的 $\alpha_1/\beta_1$ 和 $\alpha_2/\beta_2$ 呈对角排列，结构较为紧密，称为紧张态（tense state，$\mathrm{T}$ 态）。$\mathrm{T}$ 态 $\mathrm{Hb}$ 与 $\mathrm{O}_2$ 的亲和力小。
:::

:::definition{label="松弛态（R 态）"}
随着 $\mathrm{O}_2$ 结合，$4$ 个亚基羧基末端之间的盐键断裂，二、三、四级结构发生变化，$\alpha_1/\beta_1$ 和 $\alpha_2/\beta_2$ 的长轴形成 $15^{\circ}$ 夹角，结构相对松弛，称为松弛态（relaxed state，$\mathrm{R}$ 态）。与 $\mathrm{O}_2$ 亲和力增大。
:::

::figure{src="/images/biochemistry/textbook/p0056_01.png" caption="图1-27 Hb T 态和 R 态互变。T 态四亚基十字紧密排列；R 态 α1/β1 与 α2/β2 长轴形成 15° 夹角，结构松弛。" alt="左侧 T 态：α1、β2、α2、β1 十字排列；右侧 R 态亚基相对转动，标出轴和 15° 夹角"}

::figure{src="/images/biochemistry/textbook/p0056_02.png" caption="图1-28 Hb 氧合与脱氧构象转换示意。上排 T 态逐步结合 O2，盐键逐个打开；下排 R 态亚基分离、氧合；2,3-BPG 把右侧结构拉回并阻止完全转向高亲和 R 态。" alt="上下两排四亚基模型：T 态有连接盐键，结合氧后过渡到 R 态，右侧标注 2,3-BPG 的双向箭头与叉号"}

:::derivation{title="第一个氧分子怎样把 T 态推向 R 态"}
- 脱氧 $\mathrm{Hb}$ 中 $\mathrm{Fe}^{2+}$ 半径大于卟啉环中间的孔，高出平面 $0.04\,\mathrm{nm}$（$0.4\,\text{Å}$），靠近 $\mathrm{F}8$ 组氨酸。
- 第 $1$ 个 $\mathrm{O}_2$ 与血红素 $\mathrm{Fe}^{2+}$ 结合，$\mathrm{Fe}^{2+}$ 半径变小，落入卟啉环小孔（图 1-29）。
- $\mathrm{F}$ 肽段发生一系列微小移动，附近肽段构象被牵动。
- 两个 $\alpha$ 亚基间盐键断裂，亚基间结合松弛，促进第二个亚基与 $\mathrm{O}_2$ 结合。
- 依此影响第三、四个亚基，最后 $4$ 个亚基全处于 $\mathrm{R}$ 态。$\mathrm{T}\to\mathrm{R}$ 是逐个结合 $\mathrm{O}_2$ 完成的，不是四分子氧同时到位。
:::

此种一个氧分子与 $\mathrm{Hb}$ 亚基结合后引起其他亚基构象变化，称为别构效应（allosteric effect）。小分子 $\mathrm{O}_2$ 称为别构剂或效应剂，$\mathrm{Hb}$ 则被称为别构蛋白。别构效应不仅发生在 $\mathrm{Hb}$ 与 $\mathrm{O}_2$ 之间，一些酶与别构剂的结合，配体与受体结合也存在着别构效应，所以它具有普遍生物学意义。

:::definition{label="别构效应"}
一个氧分子与 $\mathrm{Hb}$ 亚基结合后引起其他亚基构象变化，称为别构效应（allosteric effect）。小分子 $\mathrm{O}_2$ 是别构剂或效应剂，$\mathrm{Hb}$ 是别构蛋白。酶与别构剂、配体与受体的结合也存在别构效应，具有普遍生物学意义。
:::

为了适应高海拔氧气稀薄的状态，人体内可通过多种调控，如增加红细胞数量、$\mathrm{Hb}$ 浓度和甘油酸-2,3-二磷酸（$2,3\text{-BPG}$）浓度等，提供充足的氧，以保障正常新陈代谢。$2,3\text{-BPG}$ 是调节 $\mathrm{Hb}$ 运氧功能的重要因素。$2,3\text{-BPG}$ 的负电基团可与血红蛋白 $\beta$ 亚基的带正电基团形成盐键从而使血红蛋白分子的 $\mathrm{T}$ 态更趋稳定（图 1-28），使组织中氧的释放量增加。

:::definition{label="2,3-BPG"}
甘油酸-2,3-二磷酸（$2,3\text{-BPG}$）是调节 $\mathrm{Hb}$ 运氧功能的重要因素。其负电基团与血红蛋白 $\beta$ 亚基的带正电基团形成盐键，使 $\mathrm{T}$ 态更趋稳定，组织中氧的释放量增加。高海拔时人体可增加红细胞数量、$\mathrm{Hb}$ 浓度和 $2,3\text{-BPG}$ 浓度，以保障供氧。
:::

:::compare{title="T 态与 R 态"}
| 项目 | $\mathrm{T}$ 态（紧张态） | $\mathrm{R}$ 态（松弛态） |
|------|--------------------------|--------------------------|
| 氧合情况 | 未结合或低氧合 | 随 $\mathrm{O}_2$ 结合而形成 |
| 亚基排列 | $\alpha_1/\beta_1$ 与 $\alpha_2/\beta_2$ 对角、紧密 | 二者长轴成 $15^{\circ}$ 夹角，相对松弛 |
| 盐键 | 亚基羧基末端之间盐键存在 | 盐键断裂 |
| 与 $\mathrm{O}_2$ 亲和力 | 小 | 大 |
| $\mathrm{Fe}^{2+}$ 位置 | 高出卟啉环平面 $0.04\,\mathrm{nm}$ | 落入卟啉环小孔 |
| $2,3\text{-BPG}$ | 负电基团与 $\beta$ 亚基正电基团成盐，使 $\mathrm{T}$ 态更稳定 | 转向 $\mathrm{R}$ 时放出氧增加（组织中） |
:::

:::cause-effect{title="2,3-BPG 怎样增加组织放氧"}
- **因** $2,3\text{-BPG}$ 的负电基团与 $\mathrm{Hb}$ $\beta$ 亚基带正电基团形成盐键，稳定 $\mathrm{T}$ 态（低亲和）
- **果** 氧更不容易被“抓死”，组织中氧的释放量增加；高海拔时提高其浓度，与增加红细胞、$\mathrm{Hb}$ 浓度一起保障供氧
:::

:::pitfall{label="2,3-BPG 稳定的是 T 态，不是让 Hb 更爱氧"}
正协同是 $\mathrm{O}_2$ 自己当别构剂，把 $\mathrm{T}$ 推向 $\mathrm{R}$，亲和力越来越大。$2,3\text{-BPG}$ 反向拉住 $\mathrm{T}$ 态，促进在组织中放氧。把 $2,3\text{-BPG}$ 听成“帮助结合氧”，高原适应那一笔会写反。
:::

:::concept{term="先问曲线是 S 形还是双曲线，再问此刻是 T 还是 R"}
看见“Hb 与 Mb 都能绑氧”，先看氧解离曲线：$\mathrm{Mb}$ 直角双曲线，$\mathrm{Hb}$ 是 $\mathrm{S}$ 形，因为 $4$ 个亚基 $4$ 个平衡常数、正协同。再问构象：没氧时 $\mathrm{T}$ 态紧密、亲和力小；第一个 $\mathrm{O}_2$ 让 $\mathrm{Fe}^{2+}$ 落入卟啉孔，$\mathrm{F}$ 肽段牵动盐键断裂，逐步到 $\mathrm{R}$ 态。$2,3\text{-BPG}$ 把 $\mathrm{T}$ 态稳住，组织才能拿到氧。把 $\mathrm{S}$ 形只背成“形状像 S”，别构、盐键和高原适应都不会算。
:::

:::insight{label="别构把“一个亚基的小事”写成“整个四聚体的功能开关”"}
教材强调：一个氧分子结合引起其他亚基构象变化。酶与别构剂、配体与受体也走这条路，所以别构有普遍生物学意义。血红蛋白这一节既是运氧的专论，也是后文别构酶的样板。
:::

### （三）蛋白质构象改变可引起疾病

生物体内蛋白质的合成、加工和成熟是一个复杂的过程，其中多肽链的正确折叠对其正确构象形成和功能至关重要。若蛋白质的折叠发生错误，尽管其一级结构不变，但蛋白质的构象发生改变，仍可影响其功能，严重时可导致疾病发生，有人将此类疾病称为蛋白质构象疾病。有些蛋白质错误折叠后相互聚集，常形成抗蛋白水解酶的淀粉样纤维沉淀，产生毒性而致病，这类疾病包括人纹状体脊髓变性病、阿尔茨海默病（Alzheimer disease）、亨廷顿病（Huntington disease）、疯牛病等。

:::definition{label="蛋白质构象疾病"}
多肽链正确折叠对正确构象和功能至关重要。若折叠错误，尽管一级结构不变，构象改变仍可影响功能，严重时致病，此类疾病称为蛋白质构象疾病。
:::

:::definition{label="淀粉样纤维沉淀"}
有些蛋白质错误折叠后相互聚集，常形成抗蛋白水解酶的淀粉样纤维沉淀，产生毒性而致病。教材点名：人纹状体脊髓变性病、阿尔茨海默病、亨廷顿病、疯牛病等。
:::

:::pitfall{label="构象病与分子病不要并户"}
分子病（如镰状细胞贫血）是一级结构变了（基因突变导致残基替换或片段缺失）。构象病是一级结构可以不变，折叠错了、构象变了。Anfinsen 说“序列在就能折对”；构象病说“序列在也可能折错”。两本账都要留。
:::

疯牛病是由朊病毒蛋白（prion protein，$\mathrm{PrP}$）引起的一组人和动物神经退行性病变，这类疾病具有传染性、遗传性或散在发病的特点，其在动物间的传播是由 $\mathrm{PrP}$ 组成的传染性蛋白质颗粒（不含核酸）完成的。$\mathrm{PrP}$ 是染色体基因编码的蛋白质。正常动物和人 $\mathrm{PrP}$ 为分子量 $33\sim 35\,\mathrm{kD}$ 的蛋白质，其水溶性强、对蛋白酶敏感，二级结构为多个 $\alpha$-螺旋，称为 $\mathrm{PrP}^{\mathrm{C}}$。富含 $\alpha$-螺旋的 $\mathrm{PrP}^{\mathrm{C}}$ 在某种未知因素（分子）的作用下可转变成大多数为 $\beta$-折叠的 $\mathrm{PrP}$ 蛋白质，称为 $\mathrm{PrP}^{\mathrm{Sc}}$。但 $\mathrm{PrP}^{\mathrm{C}}$ 和 $\mathrm{PrP}^{\mathrm{Sc}}$ 两者的一级结构完全相同，可见 $\mathrm{PrP}^{\mathrm{C}}$ 转变成 $\mathrm{PrP}^{\mathrm{Sc}}$ 涉及蛋白质分子 $\alpha$-螺旋重新折叠成 $\beta$-折叠的过程。外源或新生的 $\mathrm{PrP}^{\mathrm{Sc}}$ 可以作为模板，通过复杂的机制诱导含 $\alpha$-螺旋的 $\mathrm{PrP}^{\mathrm{C}}$ 重新折叠成为富含 $\beta$-折叠的 $\mathrm{PrP}^{\mathrm{Sc}}$，并可形成聚合体（图 1-30）。$\mathrm{PrP}^{\mathrm{Sc}}$ 对蛋白酶不敏感，水溶性差，而且对热稳定，可以相互聚集，最终形成淀粉样纤维沉淀而致病。

:::definition{label="朊病毒蛋白"}
朊病毒蛋白（prion protein，$\mathrm{PrP}$）引起一组人和动物神经退行性病变（疯牛病等），可传染、遗传或散在发病。动物间传播由 $\mathrm{PrP}$ 组成的传染性蛋白质颗粒完成，不含核酸。$\mathrm{PrP}$ 是染色体基因编码的蛋白质。
:::

:::definition{label="PrP^C"}
正常动物和人的 $\mathrm{PrP}$ 分子量 $33\sim 35\,\mathrm{kD}$，水溶性强、对蛋白酶敏感，二级结构为多个 $\alpha$-螺旋，称为 $\mathrm{PrP}^{\mathrm{C}}$。
:::

:::definition{label="PrP^Sc"}
$\mathrm{PrP}^{\mathrm{C}}$ 在某种未知因素作用下转变成大多数为 $\beta$-折叠的蛋白质，称为 $\mathrm{PrP}^{\mathrm{Sc}}$。它与 $\mathrm{PrP}^{\mathrm{C}}$ 一级结构完全相同，但对蛋白酶不敏感，水溶性差，对热稳定，可相互聚集形成淀粉样纤维沉淀而致病。
:::

:::compare{title="PrP^C 与 PrP^Sc"}
| 项目 | $\mathrm{PrP}^{\mathrm{C}}$ | $\mathrm{PrP}^{\mathrm{Sc}}$ |
|------|----------------------------|------------------------------|
| 一级结构 | 与 $\mathrm{PrP}^{\mathrm{Sc}}$ 完全相同 | 与 $\mathrm{PrP}^{\mathrm{C}}$ 完全相同 |
| 二级结构 | 多个 $\alpha$-螺旋 | 大多数为 $\beta$-折叠 |
| 水溶性 | 强 | 差 |
| 对蛋白酶 | 敏感 | 不敏感 |
| 对热 | — | 稳定 |
| 病理 | 正常构象 | 可作为模板诱导 $\mathrm{PrP}^{\mathrm{C}}$ 重折叠，聚合为淀粉样纤维而致病 |
:::

:::cause-effect{title="不含核酸的蛋白质颗粒怎样“传染”"}
- **因** 外源或新生的 $\mathrm{PrP}^{\mathrm{Sc}}$ 作为模板，诱导 $\mathrm{PrP}^{\mathrm{C}}$ 由 $\alpha$-螺旋重新折叠为富含 $\beta$-折叠的 $\mathrm{PrP}^{\mathrm{Sc}}$ 并形成聚合体
- **果** 传染性不必携带核酸；$\mathrm{PrP}^{\mathrm{Sc}}$ 耐蛋白酶、耐热、水溶性差，最终淀粉样纤维沉淀，导致神经退行性病变
:::

:::insight{label="同一条序列，两种折叠，两种命运"}
$\mathrm{PrP}^{\mathrm{C}}$ 与 $\mathrm{PrP}^{\mathrm{Sc}}$ 一级结构完全相同，差别在 $\alpha$-螺旋重折成 $\beta$-折叠。Anfinsen 证明序列通常指向天然构象；朊蛋白证明错误构象可以当模板，把正确构象带跑。第四节的变性/复性要接这一笔：构象毁了功能就毁，一级结构未毁才谈得上复性。
:::

:::keypoint{label="结构与功能这一节的四条主链"}
- 蛋白质是生命活动的主要执行分子：结构、运输、催化、信息、免疫、供能、酸碱平衡、血浆渗透压。
- 功能靠互作：与小分子、与核酸、与蛋白质（PPI，非共价；胰岛素受体、抗原–抗体）。
- 一级结构是高级结构与功能的基础：Anfinsen 复性、$105$ 种二硫键配对、胰岛素种属差异、$\mathrm{Cyt\ c}$ 进化、分子病（$\beta 6\ \mathrm{Glu}\to\mathrm{Val}$）。
- 功能依赖特定空间结构：$\mathrm{Mb}$ 双曲线 vs $\mathrm{Hb}$ 的 $\mathrm{S}$ 形；$\mathrm{T}/\mathrm{R}$、正协同、别构、$2,3\text{-BPG}$ 稳定 $\mathrm{T}$ 态；构象病与 $\mathrm{PrP}^{\mathrm{C}}\to\mathrm{PrP}^{\mathrm{Sc}}$。
:::

:::memory{label="本节必背要点"}
- [ ] 蛋白质是生命活动的执行者，几乎无处不发挥特有功能；有的一身多职，有的功能尚未阐明。
- [ ] 结构功能：膜蛋白、细胞器蛋白、染色体蛋白等；组织细胞每天更新，需每日摄入蛋白质。
- [ ] 运输：血红蛋白运氧；载脂蛋白运脂质并调节其代谢；清蛋白结合脂肪酸、$\mathrm{Ca}^{2+}$、胆红素、磺胺等。
- [ ] 酶绝大多数是蛋白质；没有酶就没有生命。
- [ ] 膜受体是蛋白质；衔接蛋白靠结构域形成信号复合体，经 PPI 激活下游。
- [ ] 抗体、淋巴因子等免疫分子都是蛋白质。
- [ ] 蛋白质可彻底氧化为水、$\mathrm{CO}_2$ 并释能；正常先用糖，饥饿时蛋白分解增加。
- [ ] 蛋白质缓冲体系是血液缓冲系统的重要组成部分。
- [ ] 血浆清蛋白分子量小、数目多，决定胶体渗透压；降低则营养不良性水肿。
- [ ] 蛋白质与小分子代谢物互作，参与催化、转运、信息传递。
- [ ] 结合 $\mathrm{DNA}$ 的模体：锌指、亮氨酸拉链、螺旋-转角-螺旋。
- [ ] 少部分 $\mathrm{RNA}$ 为核酶；绝大部分 $\mathrm{RNA}$ 与蛋白质形成复合物。
- [ ] 核糖体两亚基 = 蛋白质 + $\mathrm{rRNA}$；端粒酶 = 催化蛋白 + $\mathrm{RNA}$ 模板；剪接体 = 小分子核 $\mathrm{RNA}$ + 蛋白质。
- [ ] $\mathrm{PPI}$：两个或以上蛋白质经非共价键互作并发挥功能；可改变酶动力学、产生新结合位点、改变底物亲和力。
- [ ] 人、牛胰岛素 $51$ 个残基中 $3$ 个不同；胰岛素受体是 $\mathrm{RTK}$ 糖蛋白，$\alpha_2\beta_2$，二硫键相连。
- [ ] 胰岛素绑 $\alpha$ 亚基 → $\beta$ 亚基激酶激活、自身磷酸化 → 磷酸化 $\mathrm{IRS}$ 十几个重要酪氨酸 → 促葡萄糖吸收，增强糖原、脂肪、蛋白质合成。
- [ ] $2$ 型糖尿病：受体数量降低或信号不敏感，亲和力下降，PPI 变弱，同样量胰岛素不能有效降糖。
- [ ] $\mathrm{Ig}$ 即具抗体活性的蛋白质；抗体由抗原激活后 $\mathrm{B}$ 细胞分化的浆细胞合成，电泳主要在 $\gamma$ 区，约占血浆蛋白 $20\%$。
- [ ] 五类 $\mathrm{Ig}$ 均 $2\mathrm{H}+2\mathrm{L}$；$\mathrm{IgG}/\mathrm{D}/\mathrm{E}$ 四聚体，$\mathrm{IgA}$ 二聚体，$\mathrm{IgM}$ 五聚体（巨球蛋白 $970\,\mathrm{kD}$）。
- [ ] $\mathrm{V}$ 区（$\mathrm{H}$ 链 $\mathrm{N}$-端 $1/4$，$\mathrm{L}$ 链 $\mathrm{N}$-端 $1/2$）决定抗原结合特异性；$\mathrm{C}$ 区决定效应并作为分类基础。
- [ ] $\mathrm{C_H}2$ 结合补体，$\mathrm{C_H}3$ 接触中性粒细胞和巨噬细胞受体；高变区是抗原结合部位。
- [ ] 轻链 $\kappa$ 或 $\lambda$ 不混合；重链 $\mu/\gamma/\alpha/\delta/\varepsilon$ 对应 $\mathrm{IgM}/\mathrm{G}/\mathrm{A}/\mathrm{D}/\mathrm{E}$。
- [ ] 抗原表位与抗体超变区沟槽互补；高亲和不易解离；低 $\mathrm{pH}$、高盐、反复冻融可解离且活性仍在。
- [ ] 一个抗原可有多种表位，诱生多种特异性抗体。
- [ ] Anfinsen：核糖核酸酶 $\mathrm{A}$ 共 $124$ 残基、$4$ 对二硫键（$26$–$84$，$40$–$95$，$58$–$110$，$65$–$72$）。
- [ ] 尿素（或盐酸胍）破次级键，$\beta$-巯基乙醇破二硫键；肽键和一级结构仍在，活性丧失。
- [ ] $4$ 对二硫键重配对理论上 $105$ 种，唯天然配对有活性；透析去除变性剂后可复性。
- [ ] 同源蛋白质由同一基因进化而来的相关基因表达；一级结构相似则构象与功能常相似。
- [ ] 哺乳类胰岛素均为 $\mathrm{A}$、$\mathrm{B}$ 链，二硫键配对和构象极似，仅个别残基不同，都调节糖代谢。
- [ ] 泛素 $76$ 残基，果蝇与人序列完全相同；人类 $20\%\sim 30\%$ 蛋白质有多态性，几乎不影响功能。
- [ ] $\mathrm{Cyt\ c}$：人与黑猩猩全同；人与猕猴差第 $102$ 位（Tyr vs Arg）；人与面包酵母差 $51$ 个；灰鲸与猪牛羊差 $2$ 个。
- [ ] 分子病因基因突变；镰状细胞贫血：$\beta 6$ 谷氨酸→缬氨酸，Hb 聚集成丝，红细胞呈镰刀状。
- [ ] 肌营养不良症：基因大片段缺失导致大片段肽链缺失。
- [ ] 角蛋白多 $\alpha$-螺旋→坚韧有弹性；丝心蛋白多 $\beta$-折叠→伸展柔软。
- [ ] 血红素：铁卟啉，$\mathrm{Fe}^{2+}$ 六配位（$4$ 个吡咯 $\mathrm{N}$，$\mathrm{F}8\ \mathrm{His}93$，第 $6$ 位给氧，近 $\mathrm{E}7\ \mathrm{His}64$）。
- [ ] $\mathrm{Mb}$：单链、仅三级结构、$8$ 段 $\alpha$-螺旋 $\mathrm{A}\sim\mathrm{H}$，袋中血红素。
- [ ] $\mathrm{Hb}$：四亚基四级结构，一分子结合 $4$ 个 $\mathrm{O}_2$；成人 $\alpha_2\beta_2$（$141+146$），胎儿 $\alpha_2\gamma_2$，胚胎 $\alpha_2\varepsilon_2$，另有 $\alpha_2\delta_2$，镰贫 $\alpha_2\mathrm{S}_2$。
- [ ] 亚基间 $8$ 对盐键，形成亲水球状蛋白；各亚基三级结构与 $\mathrm{Mb}$ 极相似。
- [ ] $\mathrm{Mb}$ 氧解离曲线为直角双曲线；$\mathrm{Hb}$ 为 $\mathrm{S}$ 形曲线。
- [ ] 正协同：第一亚基结合 $\mathrm{O}_2$ 促进第二、三亚基，前三个结合后大大促进第四个；末个平衡常数最大。
- [ ] $\mathrm{T}$ 态：紧密、对角排列、亲和力小；$\mathrm{R}$ 态：盐键断裂、长轴 $15^{\circ}$ 夹角、亲和力大。
- [ ] 脱氧时 $\mathrm{Fe}^{2+}$ 高出卟啉平面 $0.04\,\mathrm{nm}$（$0.4\,\text{Å}$）；氧合后落入孔中，牵动 $\mathrm{F}$ 肽段，盐键断裂。
- [ ] 别构效应：一分子氧结合引起其他亚基构象变化；$\mathrm{O}_2$ 是别构剂，$\mathrm{Hb}$ 是别构蛋白。
- [ ] $2,3\text{-BPG}$ 与 $\beta$ 亚基正电基团成盐，稳定 $\mathrm{T}$ 态，增加组织放氧；高原可升高红细胞、$\mathrm{Hb}$ 和 $2,3\text{-BPG}$。
- [ ] 构象病：一级结构不变但折叠错误；可形成抗蛋白酶淀粉样纤维。
- [ ] $\mathrm{PrP}$ 由染色体基因编码，传染颗粒不含核酸；$\mathrm{PrP}^{\mathrm{C}}$（$\alpha$-螺旋、水溶、蛋白酶敏感）→ $\mathrm{PrP}^{\mathrm{Sc}}$（$\beta$-折叠、耐酶、耐热），一级结构完全相同。
:::
