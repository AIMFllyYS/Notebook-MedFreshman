# 第一节　DNA损伤

第二十一章把「$\mathrm{DNA}$ 怎样被改坏」和「细胞怎样把坏处修回去」分成两户。本节只立损伤：体内因素与体外因素、损伤类型，以及碱基置换落到密码子上的错义／无义／同义。修复途径（光复活、烷基化直接修复、碱基切除、核苷酸切除、重组修复、$\mathrm{SOS}$）交给第二节；损伤的双重效应和修复缺陷病交给第三节。错义突变的记法（如 $\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$）写在本节末，不要拖到第二节开头。

:::concept{term="先问 DNA 被改成什么样、会不会还当模板，再问怎样修"}
看见“$\mathrm{DNA}$ 损伤”，先不要默写切除酶名单。户头是：体内外因素把 $\mathrm{DNA}$ 的组成与结构改掉。两种后果必须分开：一是结构发生永久性改变，即突变；二是失去作为复制和／或转录模板的功能。损伤发生的同时修复系统就启动。修对了，细胞维持正常；修不了，可走凋亡；修不全，突变、畸变、衰老、恶性转化。绝对稳定则没有进化。多样性依赖损伤与修复之间的平衡。
:::

生物遗传物质之一，$\mathrm{DNA}$ 的遗传保守性是维持生物物种相对稳定的最主要因素。然而，在长期的生物进化过程中，生物体时时刻刻受到来自内、外环境中多种因素的影响，$\mathrm{DNA}$ 的改变不可避免。各种体内体外因素所导致的 $\mathrm{DNA}$ 组成与结构的变化称之为 $\mathrm{DNA}$ 损伤（DNA damage）。$\mathrm{DNA}$ 损伤可产生两种后果：一是损伤导致 $\mathrm{DNA}$ 的结构发生永久性改变，即突变；二是损伤导致 $\mathrm{DNA}$ 失去作为复制和／或转录的模板的功能。

:::definition{label="DNA 损伤"}
$\mathrm{DNA}$ 损伤（DNA damage）：各种体内体外因素所导致的 $\mathrm{DNA}$ 组成与结构的变化。户头落在「组成与结构被改掉」，还不是「已经变成可遗传的等位基因」。后一句的两种后果才决定它走突变还是走「不能当模板」。
:::

:::definition{label="DNA 损伤的两种后果"}
①损伤导致 $\mathrm{DNA}$ 的结构发生永久性改变，即突变。②损伤导致 $\mathrm{DNA}$ 失去作为复制和／或转录的模板的功能。两句并列，不是「损伤等于突变」。
:::

:::compare{title="永久性改变 vs 失去模板功能"}
| | 本版原句 | 细胞立刻看见什么 | 后文落点 |
|--|---------|-----------------|----------|
| 永久性改变 | 结构发生永久性改变，即突变 | 序列或结构被改写，复制后可传下去 | 本节末的转换／颠换、错义／无义／同义；第三节「突变是进化的分子基础」 |
| 失去模板功能 | 不能再当复制和／或转录的模板 | 复制、转录受阻，功能可明显障碍，重则死亡 | 嘧啶二聚体弯曲扭结、双链断裂、交联；第二节才问怎样修 |

问「损伤有什么后果」必须两句都答。只答突变，模板功能那一户空了；只答「复制停了」，突变和进化那一户空了。
:::

:::pitfall{label="不要把 DNA 损伤直接写成突变"}
损伤是组成与结构的变化。其中一部分被正确修复，一部分走凋亡，一部分不完全修复才变成突变或染色体畸变。写成「损伤就是突变」，第二节的修复途径就没有对象。
:::

在长期的生物进化中，无论是低等生物还是高等生物均形成了自己的 $\mathrm{DNA}$ 损伤修复系统，可随时修复被损伤的 $\mathrm{DNA}$，恢复 $\mathrm{DNA}$ 的正常结构，保持生物细胞的正常功能。实际上，$\mathrm{DNA}$ 损伤的同时即伴有 $\mathrm{DNA}$ 损伤修复系统的启动。生物受损细胞的转归，在很大程度上，取决于 $\mathrm{DNA}$ 损伤的修复效果：如损伤被正确修复，细胞的 $\mathrm{DNA}$ 结构恢复正常，细胞就能够维持其正常状态；如损伤严重，$\mathrm{DNA}$ 不能被有效修复，则可能通过凋亡的方式，清除这些 $\mathrm{DNA}$ 受损的细胞，降低 $\mathrm{DNA}$ 损伤对生物遗传信息稳定性的影响。另外，当 $\mathrm{DNA}$ 的损伤发生不完全修复时，$\mathrm{DNA}$ 发生突变，染色体发生畸变，可诱导生物细胞出现功能改变，甚至出现衰老与细胞恶性转化等生理病理变化。当然，如果遗传物质具有绝对的稳定性，那么生物将失去其进化的基础，就不会呈现大千世界、万物生辉的自然景象。因此，总体而言，自然界生物的多样性依赖于 $\mathrm{DNA}$ 损伤与 $\mathrm{DNA}$ 损伤修复之间保持良好的平衡。

:::definition{label="损伤的同时修复就启动"}
$\mathrm{DNA}$ 损伤的同时即伴有 $\mathrm{DNA}$ 损伤修复系统的启动。不是「先损伤完、再另开一轮修复」。低等生物和高等生物都有自己的修复系统。
:::

:::cause-effect{title="修复效果怎样决定受损细胞转归"}
- **因** 损伤被正确修复
- **果** $\mathrm{DNA}$ 结构恢复正常，细胞维持正常状态
- **因** 损伤严重，不能被有效修复
- **果** 可通过凋亡清除受损细胞，降低对遗传信息稳定性的影响
- **因** 不完全修复
- **果** 突变、染色体畸变，可致功能改变，甚至衰老与细胞恶性转化
:::

:::insight{label="凋亡在这里是保护遗传稳定性，不是损伤的必经结局"}
教材写「可能通过凋亡的方式清除」。修对了就活；修不全才突变、畸变。写成「$\mathrm{DNA}$ 一损伤细胞就凋亡」，不完全修复通向衰老和恶性转化那一户就没有对象。
:::

:::pitfall{label="绝对稳定不是好事"}
如果遗传物质具有绝对的稳定性，生物将失去进化的基础。多样性依赖于损伤与修复之间的良好平衡。把「修复」答成「必须把一切变化抹掉」，第三节「突变是进化的分子基础」就接不上。
:::

:::keypoint{label="开篇先立三句"}
- 损伤：体内外因素导致 $\mathrm{DNA}$ 组成与结构变化。
- 两种后果：永久性改变（突变），或失去复制／转录模板功能。
- 转归看修复：修对、凋亡清除、不完全修复（突变／畸变／衰老／恶性转化）；绝对稳定则没有进化。
:::

导致 $\mathrm{DNA}$ 损伤的因素众多，一般可分为体内因素与体外因素。体内因素主要包括机体代谢过程中产生的某些活性代谢物、$\mathrm{DNA}$ 复制过程中发生的碱基错配，以及 $\mathrm{DNA}$ 本身的热不稳定性等，均可导致 $\mathrm{DNA}$「自发」损伤。体外因素则主要包括辐射、化学毒物、药物、病毒感染、植物以及微生物的活性代谢产物等。值得注意的是，体内因素与体外因素的作用，往往是不能截然被分开的。通常，体外因素是通过体内因素导致 $\mathrm{DNA}$ 损伤的。然而，不同因素所导致的 $\mathrm{DNA}$ 损伤的机制往往是不相同的。

:::definition{label="体内因素导致自发损伤"}
机体代谢产生的某些活性代谢物、复制中的碱基错配、$\mathrm{DNA}$ 本身的热不稳定性等，均可导致 $\mathrm{DNA}$「自发」损伤。引号在「自发」上：看起来像自己坏的，来源仍是体内过程。
:::

:::definition{label="体外因素"}
主要包括辐射、化学毒物、药物、病毒感染、植物以及微生物的活性代谢产物等。后文按物理、化学、生物三类摊开。
:::

:::pitfall{label="体内与体外不能截然分开"}
通常，体外因素是通过体内因素导致 $\mathrm{DNA}$ 损伤的。电离辐射激发细胞内自由基，就是体外因素走体内自由基这一户。写成「体外因素直接改 $\mathrm{DNA}$、体内因素另算」，后文羟自由基、活性氧会对不上。
:::

:::compare{title="体内因素 vs 体外因素"}
| | 本版名单 | 「自发」二字 | 后文机制 |
|--|---------|------------|---------|
| 体内 | 活性代谢物、复制错配、热不稳定性 | 可称「自发」损伤 | 复制错误、糖苷键水解、脱氨基、活性氧 |
| 体外 | 辐射、化学毒物、药物、病毒、植物及微生物活性代谢产物 | 不称自发 | 电离辐射、紫外线、自由基、碱基类似物、烷化剂、嵌入染料、黄曲霉毒素等 |
| 关系 | 往往不能截然分开 | 体外常通过体内起作用 | 不同因素的机制往往不相同 |

问「哪些算自发」看体内三户；问「紫外线和氮芥」看体外。
:::

## 一、多种因素通过不同机制导致DNA损伤

### （一）体内因素导致DNA自发损伤

**1. $\mathrm{DNA}$ 复制错误**　在 $\mathrm{DNA}$ 复制过程中，碱基的异构互变、$4$ 种 $\mathrm{dNTP}$ 之间浓度的不平衡等，均可能引起碱基的错配，即产生非 Watson-Crick 碱基对。尽管绝大多数错配的碱基会被 $\mathrm{DNA}$ 聚合酶的即时校读所纠正，但依然不可避免地有极少数的碱基错配被保留下来。$\mathrm{DNA}$ 复制的错配率约 $1/10^{10}$。

此外，复制错误还表现为片段的缺失或插入。特别是 $\mathrm{DNA}$ 上短片段的重复序列，在真核细胞基因组上广泛分布，导致 $\mathrm{DNA}$ 复制系统工作时可能出现「打滑」现象，使得新生 $\mathrm{DNA}$ 上的重复序列的拷贝数发生变化。$\mathrm{DNA}$ 重复片段在长度方面表现出的高度的多态性，在遗传性疾病的研究上有重大价值。亨廷顿病（Huntington disease）、脆性 $\mathrm{X}$ 综合征（fragile X syndrome）、肌强直性营养不良（myotonic dystrophy）等神经退行性疾病均属于此类。

:::definition{label="复制中的碱基错配"}
碱基的异构互变、$4$ 种 $\mathrm{dNTP}$ 浓度不平衡等，可引起非 Watson-Crick 碱基对。绝大多数被 $\mathrm{DNA}$ 聚合酶即时校读纠正，极少数被保留。本版给出的错配率约 $1/10^{10}$。
:::

:::definition{label="复制打滑"}
短片段重复序列在真核基因组上广泛分布。复制系统工作时可能「打滑」，使新生链上重复序列的拷贝数变化。这是片段缺失或插入这一类复制错误，不是单碱基错配。
:::

:::definition{label="重复片段长度多态性的疾病例子"}
亨廷顿病、脆性 $\mathrm{X}$ 综合征、肌强直性营养不良等神经退行性疾病，属于重复序列拷贝数变化这一类。教材把它们写成遗传性疾病研究上的重大价值，不是另开一种化学诱变。
:::

:::insight{label="校读把绝大多数错配挡住，剩下的才叫保留下来的错配"}
「绝大多数会被即时校读纠正」和「约 $1/10^{10}$」是同一句话的两半。默写「复制一定错」而不提校读，错配率就没有着落；默写「聚合酶从不犯错」，打滑和三病就没有户头。
:::

:::pitfall{label="打滑不是碱基类似物掺入"}
打滑改的是短重复的拷贝数，落在缺失／插入。碱基类似物（后文 $5$-溴尿嘧啶）改的是配对身份。两户都叫「复制错误」，机制不要并。
:::

:::compare{title="单碱基错配 vs 打滑造成的缺失插入"}
| | 直接原因 | 产物 | 本版数字或例子 |
|--|---------|------|--------------|
| 单碱基错配 | 异构互变、$\mathrm{dNTP}$ 不平衡；校读漏网 | 非 Watson-Crick 碱基对被保留 | 错配率约 $1/10^{10}$ |
| 打滑 | 短重复上复制系统打滑 | 新生链重复拷贝数变，表现为缺失或插入 | 亨廷顿病、脆性 $\mathrm{X}$ 综合征、肌强直性营养不良 |

问「复制错误有哪两种表现」先分单碱基和片段；问神经退行性疾病看打滑。
:::

**2. $\mathrm{DNA}$ 自身的不稳定性**　在 $\mathrm{DNA}$ 自发性损伤中，$\mathrm{DNA}$ 结构自身的不稳定性是最主要的因素。当 $\mathrm{DNA}$ 受热或所处环境的 $\mathrm{pH}$ 发生改变时，$\mathrm{DNA}$ 分子上连接碱基和核糖之间的糖苷键可自发水解，导致碱基的脱落丢失，其中以脱嘌呤最为普遍。另外，含有氨基的碱基可能自发发生脱氨基反应，转变为另一种碱基，如 $\mathrm{C}$ 转变为 $\mathrm{U}$，$\mathrm{A}$ 转变为 $\mathrm{I}$（次黄嘌呤）等。

:::definition{label="自身不稳定性是自发损伤的最主要因素"}
受热或 $\mathrm{pH}$ 改变时，连接碱基和核糖的糖苷键可自发水解，碱基脱落丢失，其中以脱嘌呤最为普遍。这是结构自己水解，不是外来烷化剂把鸟嘌呤「打下来」——后文烷化剂也可以造成鸟嘌呤脱落，那是体外化学因素。
:::

:::definition{label="自发脱氨基"}
含氨基的碱基可自发脱氨基，转变为另一种碱基。本版点名：$\mathrm{C}\rightarrow\mathrm{U}$，$\mathrm{A}\rightarrow\mathrm{I}$（次黄嘌呤）。后文亚硝酸也做脱氨基，那是化学因素，产物名单可以相同，户头不同。
:::

:::pitfall{label="脱嘌呤最普遍，不要写成四种碱基一视同仁脱落"}
教材写「其中以脱嘌呤最为普遍」。答成「$\mathrm{A}$、$\mathrm{T}$、$\mathrm{G}$、$\mathrm{C}$ 同等水解」，糖苷键这一户的重点就丢了。
:::

:::compare{title="糖苷键水解 vs 自发脱氨基"}
| | 键或基团 | 产物 | 后文怎么接 |
|--|---------|------|-----------|
| 糖苷键水解 | 碱基—核糖之间 | 碱基脱落，脱嘌呤最普遍 | 无碱基位点（$\mathrm{AP}$ 位点）在第二节碱基切除修复里出现 |
| 脱氨基 | 碱基上的氨基 | $\mathrm{C}\rightarrow\mathrm{U}$，$\mathrm{A}\rightarrow\mathrm{I}$ | 图21-2 把 $\mathrm{C}\rightarrow\mathrm{U}$、$\mathrm{A}\rightarrow\mathrm{I}$ 标在「碱基交换」下 |

脱落是「位子空了」；脱氨基是「还在位子上但身份变了」。
:::

**3. 机体代谢过程中产生的活性氧**　机体代谢过程中产生的活性氧（reactive oxygen species，$\mathrm{ROS}$）可以直接作用，修饰碱基，如修饰鸟嘌呤，产生 $8$-羟基脱氧鸟嘌呤，等等。

:::definition{label="活性氧修饰碱基"}
活性氧（reactive oxygen species，$\mathrm{ROS}$）可直接修饰碱基。本版点名的产物是 $8$-羟基脱氧鸟嘌呤。后文氧化产物还出现 $8$-羟基脱氧鸟苷、$6$-甲基尿嘧啶，那是损伤类型那一小节的名单。
:::

:::insight{label="ROS 是体内代谢账，羟自由基也可以由电离辐射在体内做出来"}
这一条写在体内因素。后文化学因素里的自由基，点名电离辐射产生 $\cdot\mathrm{OH}$ 和 $\cdot\mathrm{H}$，生物体内代谢也可产生活性氧自由基。同一类活性分子，来源可以是体内代谢，也可以是体外辐射走体内。
:::

:::keypoint{label="体内自发损伤三户"}
- 复制错误：错配（约 $1/10^{10}$）和打滑（重复拷贝数变）。
- 自身不稳定：糖苷键水解（脱嘌呤最普遍），自发脱氨基（$\mathrm{C}\rightarrow\mathrm{U}$，$\mathrm{A}\rightarrow\mathrm{I}$）。
- 活性氧：直接修饰碱基，点名 $8$-羟基脱氧鸟嘌呤。
:::

### （二）多种体外因素导致DNA损伤

最常见的导致 $\mathrm{DNA}$ 损伤的体外因素，主要包括物理因素、化学因素和生物因素等。这些因素导致 $\mathrm{DNA}$ 损伤的机制各有其特点。

:::definition{label="体外因素三类"}
物理因素、化学因素和生物因素。机制各有特点，不要并成「都是把碱基改掉」。
:::

#### 1. 物理因素

物理因素中最常见的是电磁辐射。电磁辐射可导致接受电磁辐射的组织细胞的 $\mathrm{DNA}$ 受损。根据作用原理的不同，通常将电磁辐射分为电离辐射和非电离辐射。$\alpha$ 粒子、$\beta$ 粒子、$\mathrm{X}$ 射线、$\gamma$ 射线等，能直接或间接引起被穿透的组织发生电离，损伤 $\mathrm{DNA}$，属电离辐射；而紫外线和波长长于紫外线的电磁辐射属非电离辐射。

:::definition{label="电离辐射 vs 非电离辐射"}
电离辐射：$\alpha$ 粒子、$\beta$ 粒子、$\mathrm{X}$ 射线、$\gamma$ 射线等，能直接或间接引起被穿透的组织发生电离。非电离辐射：紫外线和波长长于紫外线的电磁辐射。分类钥匙是「能不能使组织电离」，不是「有没有能量」这一句空话。
:::

:::compare{title="电离辐射 vs 非电离辐射"}
| | 本版例子 | 作用原理 | 后文损伤形态 |
|--|---------|---------|------------|
| 电离辐射 | $\alpha$、$\beta$、$\mathrm{X}$、$\gamma$ | 直接或间接引起组织电离 | 链断裂或交联；间接走自由基，碱基氧化修饰、碱基环破坏脱落 |
| 非电离辐射 | 紫外线，以及波长长于紫外线的电磁辐射 | 不按电离来定义 | 低波长紫外线主要做嘧啶二聚体，也可链间交联或链断裂 |

$\mathrm{UVA}$ 能量较低、一般不造成生物大分子损伤，仍属非电离辐射，不要因为它「较弱」就划去电离那一列。
:::

**（1）电离辐射导致的 $\mathrm{DNA}$ 损伤**　电离辐射既可直接作用于 $\mathrm{DNA}$ 等生物大分子，破坏其分子结构，如断裂 $\mathrm{DNA}$ 分子的化学键等，使 $\mathrm{DNA}$ 链断裂或发生交联。与此同时，电离辐射还可激发细胞内的自由基反应，发挥间接作用，导致 $\mathrm{DNA}$ 分子发生碱基氧化修饰，破坏碱基环结构，使其脱落。

:::definition{label="电离辐射的直接作用与间接作用"}
直接：作用于 $\mathrm{DNA}$ 等生物大分子，断化学键，使链断裂或交联。间接：激发细胞内自由基反应，碱基氧化修饰，破坏碱基环并使其脱落。两路都要答。
:::

:::pitfall{label="电离辐射不要只答「把链打断」"}
直接作用里已经写了断裂或交联；间接作用走的是自由基和碱基氧化。后文「$\mathrm{DNA}$ 链断裂是电离辐射致损伤的主要形式」指主要形式，不是唯一形式。
:::

**（2）紫外线照射导致的 $\mathrm{DNA}$ 损伤**　紫外线（ultraviolet，$\mathrm{UV}$）属于非电离辐射。按波长的不同，紫外线可分为 $\mathrm{UVA}$（$321\sim 400\,\mathrm{nm}$）、$\mathrm{UVB}$（$291\sim 320\,\mathrm{nm}$）和 $\mathrm{UVC}$（$100\sim 290\,\mathrm{nm}$）$3$ 种。$\mathrm{UVA}$ 的能量较低，一般不造成 $\mathrm{DNA}$ 等生物大分子的损伤。$260\,\mathrm{nm}$ 左右的紫外线，其波长正好在 $\mathrm{DNA}$ 和蛋白质的吸收峰附近，容易导致 $\mathrm{DNA}$ 等生物大分子的损伤。大气臭氧层可吸收 $320\,\mathrm{nm}$ 以下的大部分紫外线，一般不会造成地球上生物的损害。然而，近年来，由于环境污染，臭氧层的破坏日趋严重，来自大气层外的 $\mathrm{UV}$ 对地球生物的影响越来越被关注。

低波长紫外线的吸收，可使 $\mathrm{DNA}$ 分子中同一条链上相邻的两个胸腺嘧啶碱基（$\mathrm{T}$），以共价键连接形成胸腺嘧啶二聚体结构（$\mathrm{TT}$），也称为环丁烷型嘧啶二聚体，见图21-1。另外，紫外线也可导致其他嘧啶间形成类似的嘧啶二聚体，如 $\mathrm{CT}$ 二聚体和 $\mathrm{CC}$ 二聚体等。嘧啶二聚体的形成可使 $\mathrm{DNA}$ 产生弯曲和扭结，影响 $\mathrm{DNA}$ 的双螺旋结构，使复制与转录受阻。再者，紫外线还会导致 $\mathrm{DNA}$ 链间的其他交联或 $\mathrm{DNA}$ 链的断裂等损伤。

:::note{label="图21-1 电子版缺失"}
图21-1　胸腺嘧啶二聚体的形成。电子版无独立非空图文件，不嵌入。过程以本段为准：同一条链上相邻两个 $\mathrm{T}$ 以共价键连成 $\mathrm{TT}$（环丁烷型嘧啶二聚体）。图21-2 左上插图给出的是二聚体结构式，那是图21-2 的局部，不要改标成图21-1。
:::

:::definition{label="紫外线三段波长"}
$\mathrm{UVA}$：$321\sim 400\,\mathrm{nm}$，能量较低，一般不造成 $\mathrm{DNA}$ 等生物大分子损伤。$\mathrm{UVB}$：$291\sim 320\,\mathrm{nm}$。$\mathrm{UVC}$：$100\sim 290\,\mathrm{nm}$。$260\,\mathrm{nm}$ 左右正好在 $\mathrm{DNA}$ 和蛋白质吸收峰附近，容易致损伤。臭氧层吸收 $320\,\mathrm{nm}$ 以下的大部分紫外线。
:::

:::definition{label="胸腺嘧啶二聚体"}
低波长紫外线使同一条链上相邻两个胸腺嘧啶以共价键连接，形成胸腺嘧啶二聚体（$\mathrm{TT}$），也称环丁烷型嘧啶二聚体。紫外线也可形成 $\mathrm{CT}$、$\mathrm{CC}$ 等嘧啶二聚体。这是链内交联的最典型例子，后文交联分类还要再点一次。
:::

:::definition{label="嘧啶二聚体怎样挡住复制转录"}
二聚体使 $\mathrm{DNA}$ 产生弯曲和扭结，影响双螺旋结构，使复制与转录受阻。这是「失去模板功能」那一户的具体形态，不是已经写成错义突变。
:::

:::insight{label="臭氧层挡住的是 320 nm 以下，不是全部紫外线"}
$\mathrm{UVA}$ 在 $321\sim 400\,\mathrm{nm}$，本来就不在臭氧层「大部分吸收」的那一段里。关注臭氧层破坏，针对的是本来被挡住的更短波长。不要写成「臭氧层一破，所有紫外线都从零开始」。
:::

:::pitfall{label="TT 二聚体不是两条链之间的氢键"}
教材写「同一条链上相邻的两个胸腺嘧啶」「以共价键连接」。写成「两条链上的 $\mathrm{A}$-$\mathrm{T}$ 变成共价」，链内交联和链间交联就并户了。
:::

:::pitfall{label="紫外线不只做二聚体"}
「再者，紫外线还会导致 $\mathrm{DNA}$ 链间的其他交联或 $\mathrm{DNA}$ 链的断裂」。主账是嘧啶二聚体，不要把后半句删掉。
:::

:::keypoint{label="物理因素先分能不能电离"}
- 电离：$\alpha$、$\beta$、$\mathrm{X}$、$\gamma$；直接断键（断裂或交联）＋间接自由基。
- 非电离：紫外线为主；低波长主要做链内嘧啶二聚体（$\mathrm{TT}$、$\mathrm{CT}$、$\mathrm{CC}$），也可链间交联或断裂。
- 图21-1 电子版缺失；结构式在图21-2 左上，不要整张改标。
:::

#### 2. 化学因素

能引起 $\mathrm{DNA}$ 损伤的化学因素的种类繁多，主要包括自由基、碱基类似物、碱基修饰物和嵌入染料等。值得注意的是，许多肿瘤化疗药物通过诱导 $\mathrm{DNA}$ 损伤，包括碱基改变、单链或双链 $\mathrm{DNA}$ 断裂等，阻断 $\mathrm{DNA}$ 复制或 $\mathrm{RNA}$ 转录，进而抑制肿瘤细胞的增殖。因此，对 $\mathrm{DNA}$ 损伤，以及后继的肿瘤细胞死亡机制的认识，将十分有助于指导抗肿瘤化疗药物的研发。

:::definition{label="化学因素四类"}
自由基、碱基类似物、碱基修饰物（含烷化剂）和嵌入染料。化疗药物走的是「诱导损伤→阻断复制或转录→抑制肿瘤细胞增殖」，不是另开第五类诱变剂。
:::

:::insight{label="化疗在本节只立「故意把肿瘤细胞的 DNA 打伤」"}
后继死亡机制、耐药（癌细胞修复功能升高）是第三节的账。本节只承认：认识损伤有助于指导抗肿瘤化疗药物研发。
:::

**（1）自由基导致的 $\mathrm{DNA}$ 损伤**　自由基是指能够独立存在，外层轨道带有未配对电子的原子、原子团或分子。自由基的化学性质异常活跃，可引发多种化学反应，破坏生物大分子的结构，影响细胞的功能。自由基的产生可以是体外因素与体内因素相互作用的结果，如电离辐射产生羟自由基（$\cdot\mathrm{OH}$）和氢自由基（$\cdot\mathrm{H}$），而生物体内的代谢过程可产生活性氧自由基。$\cdot\mathrm{OH}$ 具有极强的氧化性质，而 $\cdot\mathrm{H}$ 则具有极强的还原性质。这些自由基可与 $\mathrm{DNA}$ 分子发生反应，导致碱基、核糖和磷酸基损伤，引发 $\mathrm{DNA}$ 的结构与功能异常。

:::definition{label="自由基"}
能够独立存在、外层轨道带有未配对电子的原子、原子团或分子。化学性质异常活跃。本版点名：电离辐射产生 $\cdot\mathrm{OH}$ 和 $\cdot\mathrm{H}$；体内代谢产生活性氧自由基。$\cdot\mathrm{OH}$ 极强氧化，$\cdot\mathrm{H}$ 极强还原。靶点是碱基、核糖和磷酸基。
:::

:::pitfall{label="自由基不要写成纯体外或纯体内"}
「自由基的产生可以是体外因素与体内因素相互作用的结果」。电离辐射是体外，$\cdot\mathrm{OH}$／$\cdot\mathrm{H}$ 在细胞内做出来。并成「自由基＝体外化学毒物」，体内 $\mathrm{ROS}$ 那一户就重复矛盾。
:::

**（2）碱基类似物导致的 $\mathrm{DNA}$ 损伤**　碱基类似物是人工合成的一类与 $\mathrm{DNA}$ 正常碱基结构类似的化合物，通常被用作抗肿瘤药物或促突变剂。在 $\mathrm{DNA}$ 复制时，因结构类似，碱基类似物可取代正常碱基掺入到 $\mathrm{DNA}$ 链中，并与互补链上的碱基配对，引发碱基对的置换。比如，$5$-溴尿嘧啶（$5$-$\mathrm{BU}$）是胸腺嘧啶的类似物，有酮式和烯醇式两种结构，可以互变。前者与腺嘌呤配对，后者与鸟嘌呤配对，可导致 $\mathrm{AT}$ 配对与 $\mathrm{GC}$ 配对间的相互转变。

:::definition{label="碱基类似物"}
人工合成、与正常碱基结构类似的化合物，常用作抗肿瘤药物或促突变剂。复制时取代正常碱基掺入，再按自己的配对规则配对，引发碱基对置换。
:::

:::definition{label="5-溴尿嘧啶"}
$5$-溴尿嘧啶（$5$-$\mathrm{BU}$）是胸腺嘧啶类似物，酮式与烯醇式可互变：酮式与腺嘌呤配对，烯醇式与鸟嘌呤配对，导致 $\mathrm{AT}$ 配对与 $\mathrm{GC}$ 配对相互转变。
:::

:::compare{title="酮式 5-BU vs 烯醇式 5-BU"}
| | 配对对象 | 效果 |
|--|---------|------|
| 酮式 | 腺嘌呤 | 按 $\mathrm{T}$ 的身份走 |
| 烯醇式 | 鸟嘌呤 | 换成 $\mathrm{C}$ 的身份 |
| 互变 | — | $\mathrm{AT}\leftrightarrow\mathrm{GC}$ |

先问这一次掺进去时是酮式还是烯醇式，再问下一代变成什么配对。不要只背「$5$-$\mathrm{BU}$ 致突变」。
:::

:::pitfall{label="碱基类似物是掺进去，不是把原有碱基的氨基切掉"}
掺入发生在复制；脱氨基（亚硝酸、自发）发生在已经写好的碱基上。两户都能改配对，机制不要并。
:::

**（3）碱基修饰剂和烷化剂导致的 $\mathrm{DNA}$ 损伤**　这是一类通过对 $\mathrm{DNA}$ 链中碱基的某些基团进行修饰，改变被修饰碱基的配对，进而改变 $\mathrm{DNA}$ 结构的化合物。例如亚硝酸能脱去碱基上的氨基，腺嘌呤脱氨后成为次黄嘌呤，不能与原来的胸腺嘧啶配对，转而与胞嘧啶配对；胞嘧啶脱氨基成为尿嘧啶，不能与原来的鸟嘌呤配对，转而与腺嘌呤配对。这些均能改变碱基的序列。此外，众多的烷化剂如氮芥、硫芥、二乙基亚硝胺等可导致 $\mathrm{DNA}$ 碱基上的氮原子烷基化，引起 $\mathrm{DNA}$ 分子电荷变化，也可改变碱基配对，或烷基化的鸟嘌呤脱落形成无碱基位点，或引起 $\mathrm{DNA}$ 链中的鸟嘌呤连接成二聚体，或导致 $\mathrm{DNA}$ 链交联与断裂。这些变化均可以引起 $\mathrm{DNA}$ 的序列或结构异常，阻止正常的修复过程。

:::definition{label="碱基修饰剂"}
对 $\mathrm{DNA}$ 链中碱基的某些基团进行修饰，改变被修饰碱基的配对，进而改变 $\mathrm{DNA}$ 结构。亚硝酸是本版点名的脱氨基例子。
:::

:::definition{label="亚硝酸脱氨基改配对"}
腺嘌呤脱氨 $\rightarrow$ 次黄嘌呤，不再与 $\mathrm{T}$ 配对，转而与 $\mathrm{C}$ 配对。胞嘧啶脱氨 $\rightarrow$ 尿嘧啶，不再与 $\mathrm{G}$ 配对，转而与 $\mathrm{A}$ 配对。序列被改写。
:::

:::definition{label="烷化剂"}
本版点名氮芥、硫芥、二乙基亚硝胺等。使碱基上的氮原子烷基化。后果可以是：电荷变化、改变碱基配对、烷基化鸟嘌呤脱落成无碱基位点、链中鸟嘌呤连成二聚体、链交联与断裂。这些变化还可阻止正常的修复过程。
:::

:::compare{title="亚硝酸脱氨基 vs 烷化剂"}
| | 本版例子 | 直接化学反应 | 配对或结构后果 |
|--|---------|-------------|----------------|
| 脱氨基修饰 | 亚硝酸 | 去掉碱基氨基 | $\mathrm{A}\rightarrow\mathrm{I}$ 改与 $\mathrm{C}$ 配；$\mathrm{C}\rightarrow\mathrm{U}$ 改与 $\mathrm{A}$ 配 |
| 烷化 | 氮芥、硫芥、二乙基亚硝胺 | 碱基氮原子烷基化 | 电荷变、配对变、鸟嘌呤脱落成 $\mathrm{AP}$ 位点、$\mathrm{G}$ 二聚体、交联与断裂；并可阻止正常修复 |

都叫「碱基修饰」，一把刀切氨基，一把刀加烷基。
:::

:::pitfall{label="烷化剂不要只答「加了一个甲基」"}
本版并列了电荷、配对、脱落成无碱基位点、鸟嘌呤二聚体、交联与断裂，以及阻止正常修复。写成「就是 $\mathrm{O}^{6}$-甲基鸟嘌呤」，第二节烷基转移酶那一户会变成唯一后果，本节的名单就被缩掉了。
:::

**（4）嵌入性染料导致的 $\mathrm{DNA}$ 损伤**　溴化乙锭、吖啶橙等染料可直接插入到 $\mathrm{DNA}$ 碱基对中，导致碱基对间的距离增大一倍，极易造成 $\mathrm{DNA}$ 两条链的错位，在 $\mathrm{DNA}$ 复制过程中往往引发核苷酸的缺失、移码或插入。

:::definition{label="嵌入性染料"}
溴化乙锭、吖啶橙等直接插入碱基对中，碱基对间距增大一倍，两条链易错位，复制时引发核苷酸缺失、移码或插入。
:::

:::pitfall{label="嵌入染料不是碱基类似物"}
类似物是「假冒某个碱基，按模板掺入」；嵌入染料是「插进碱基对之间，把梯子的横档间距拉开」。一个改配对身份，一个改间距和读框。
:::

:::compare{title="四种化学因素各自改什么"}
| 因素 | 本版例子 | 关键动作 | 典型后果 |
|------|---------|---------|---------|
| 自由基 | $\cdot\mathrm{OH}$、$\cdot\mathrm{H}$、活性氧 | 打碱基、核糖、磷酸基 | 结构与功能异常 |
| 碱基类似物 | $5$-$\mathrm{BU}$ | 掺入后按酮式／烯醇式配对 | $\mathrm{AT}\leftrightarrow\mathrm{GC}$ |
| 碱基修饰剂／烷化剂 | 亚硝酸；氮芥、硫芥、二乙基亚硝胺 | 脱氨基或烷基化 | 改配对、$\mathrm{AP}$ 位点、交联、断裂 |
| 嵌入染料 | 溴化乙锭、吖啶橙 | 插入碱基对，间距加倍 | 缺失、移码或插入 |

问「化学因素有哪些」按这一表；问「哪一种拉开碱基对距离」只答嵌入染料。
:::

#### 3. 生物因素

生物因素主要指病毒和霉菌，如麻疹病毒、风疹病毒、疱疹病毒、黄曲霉、寄生曲霉等，其蛋白表达产物或产生的毒素和活性代谢产物，如黄曲霉素等有诱变作用。

黄曲霉素主要由黄曲霉产生。在湿热地区的食品和饲料中出现黄曲霉毒素的概率很高。黄曲霉存在于土壤、动植物和各种坚果中，特别容易污染花生、玉米、稻米、大豆和小麦等粮油产品，是霉菌毒素中毒性最大、对人类健康危害极为突出的一类霉菌毒素。

:::definition{label="生物因素"}
主要指病毒和霉菌。本版点名：麻疹病毒、风疹病毒、疱疹病毒、黄曲霉、寄生曲霉。起作用的是其蛋白表达产物，或产生的毒素和活性代谢产物（如黄曲霉素），有诱变作用。
:::

:::definition{label="黄曲霉素"}
主要由黄曲霉产生。湿热地区食品和饲料中出现概率高。黄曲霉存在于土壤、动植物和各种坚果中，特别容易污染花生、玉米、稻米、大豆和小麦等粮油产品。本版把它写成霉菌毒素中毒性最大、对人类健康危害极为突出的一类。
:::

:::pitfall{label="生物因素不是「病毒把一段基因插进宿主就算本章的 DNA 损伤」"}
本节户头是诱变：蛋白产物、毒素、活性代谢产物改 $\mathrm{DNA}$ 组成与结构。病毒介导的基因转移是第十九章横向转移的账。不要把黄曲霉写成噬菌体转导。
:::

:::keypoint{label="体外因素三块"}
- 物理：电离（直接＋自由基）与紫外线（嘧啶二聚体为主）。
- 化学：自由基、类似物、修饰剂／烷化剂、嵌入染料；图上还有苯并芘。
- 生物：病毒和霉菌，点名黄曲霉素。
:::

## 二、DNA损伤有多种类型

$\mathrm{DNA}$ 分子中的碱基、核糖与磷酸二酯键均是 $\mathrm{DNA}$ 损伤因素作用的靶点。根据 $\mathrm{DNA}$ 分子结构改变的不同，$\mathrm{DNA}$ 损伤有碱基脱落、碱基结构破坏、嘧啶二聚体形成、$\mathrm{DNA}$ 单链或双链断裂、$\mathrm{DNA}$ 交联等多种类型。

:::definition{label="三个靶点"}
碱基、核糖与磷酸二酯键都是损伤因素的靶点。类型按结构改变分，不按「体内还是体外」分——同一类型可以由不同因素做出来。
:::

:::definition{label="本版列出的损伤类型"}
碱基脱落、碱基结构破坏、嘧啶二聚体形成、$\mathrm{DNA}$ 单链或双链断裂、$\mathrm{DNA}$ 交联等。后文按四条展开，并补上错配和局部多样性损伤部位。
:::

**1. 碱基的损伤与糖基的破坏**　化学毒性分子通过对碱基的某些基团进行修饰，改变碱基的理化性质，破坏碱基的结构。比如，①亚硝酸等可导致碱基脱氨；②在羟自由基的攻击下，嘧啶碱基易发生加成、脱氢等反应，导致碱基环破裂；③具有氧化活性的物质可造成 $\mathrm{DNA}$ 中嘌呤或嘧啶碱基的氧化修饰，形成 $8$-羟基脱氧鸟苷或 $6$-甲基尿嘧啶等氧化产物。$\mathrm{DNA}$ 分子中的戊糖基的碳原子和羟基上的氢可以与自由基反应，由此戊糖基的正常结构被破坏。

由于碱基的损伤或糖基的破坏，在 $\mathrm{DNA}$ 链上可能形成一些不稳定点，最终导致 $\mathrm{DNA}$ 链断裂。

:::definition{label="碱基损伤的三条化学反应"}
①亚硝酸等：脱氨。②羟自由基：嘧啶易加成、脱氢，碱基环破裂。③氧化活性物质：嘌呤或嘧啶氧化修饰，本版点名 $8$-羟基脱氧鸟苷、$6$-甲基尿嘧啶。
:::

:::definition{label="糖基破坏"}
戊糖基的碳原子和羟基上的氢可与自由基反应，戊糖基正常结构被破坏。碱基损伤或糖基破坏可在链上形成不稳定点，最终导致链断裂。
:::

:::insight{label="8-羟基脱氧鸟嘌呤和 8-羟基脱氧鸟苷是同一氧化账的两种写法"}
体内因素写 $8$-羟基脱氧鸟嘌呤，此处写 $8$-羟基脱氧鸟苷。一个强调碱基，一个强调核苷。不要当成两种无关产物，也不要另编一套编号。
:::

**2. 碱基之间发生错配**　如前所述，碱基类似物的掺入、碱基修饰剂的作用可改变碱基的性质，导致 $\mathrm{DNA}$ 序列中的错误配对。在正常的 $\mathrm{DNA}$ 复制过程中，存在着一定比例的自发的碱基错配发生，最常见的是组成 $\mathrm{RNA}$ 的尿嘧啶替代胸腺嘧啶掺入到 $\mathrm{DNA}$ 分子中。

:::definition{label="错配"}
非正确的碱基配对。来源可以是类似物掺入、修饰剂改性质，也可以是复制中一定比例的自发错配。本版点名最常见的自发情形：尿嘧啶替代胸腺嘧啶掺入 $\mathrm{DNA}$。
:::

:::pitfall{label="U 掺进 DNA 是错配账，不是转录"}
「组成 $\mathrm{RNA}$ 的尿嘧啶替代胸腺嘧啶掺入到 $\mathrm{DNA}$」发生在复制。写成「转录把 $\mathrm{U}$ 写进 $\mathrm{DNA}$」，模板那一户就反了。
:::

**3. $\mathrm{DNA}$ 链发生断裂**　$\mathrm{DNA}$ 链断裂是电离辐射致 $\mathrm{DNA}$ 损伤的主要形式。某些化学毒剂也可导致 $\mathrm{DNA}$ 链断裂。戊糖环的破坏、碱基的损伤和脱落都是引起 $\mathrm{DNA}$ 断裂的原因。碱基的损伤或糖基的破坏可引起 $\mathrm{DNA}$ 双螺旋局部变性，形成酶敏感性位点，特异的核酸内切酶能识别并切割这些位点，造成 $\mathrm{DNA}$ 链断裂。$\mathrm{DNA}$ 链上受损碱基也可以被另一种特异的 $\mathrm{DNA}$-糖苷酶除去，形成无嘌呤或无嘧啶位点（apurinic/apyrimidinic site，$\mathrm{AP}$ 位点），或称无碱基位点，这些位点在内切酶等的作用下可造成 $\mathrm{DNA}$ 链的断裂。$\mathrm{DNA}$ 链断裂可以发生在单链或双链上。$\mathrm{DNA}$ 单链断裂能迅速在细胞中以另一条互补链为模板重新合成，完成修复；而 $\mathrm{DNA}$ 双链断裂不能在原位修复，需依赖其他修复方式修复双链断裂的 $\mathrm{DNA}$。这些修复方式导致染色体畸变的可能性很大。因此，一般认为双链断裂的 $\mathrm{DNA}$ 损伤与细胞的致死性效应直接联系。

:::definition{label="AP 位点"}
无嘌呤或无嘧啶位点（apurinic/apyrimidinic site，$\mathrm{AP}$ 位点），或称无碱基位点。受损碱基被特异的 $\mathrm{DNA}$-糖苷酶除去后形成。内切酶等可在此造成链断裂。第二节碱基切除修复从识别水解到切磷酸核糖，就是围着 $\mathrm{AP}$ 位点做。
:::

:::definition{label="酶敏感性位点"}
碱基损伤或糖基破坏引起双螺旋局部变性，形成可被特异核酸内切酶识别并切割的位点，造成链断裂。这是「损伤自己招来酶切」这一路，与电离辐射直接断键并列。
:::

:::definition{label="单链断裂 vs 双链断裂"}
单链断裂（$\mathrm{SSB}$）：能迅速以另一条互补链为模板重新合成完成修复。双链断裂（$\mathrm{DSB}$）：不能在原位修复，需依赖其他修复方式；这些方式导致染色体畸变的可能性很大。一般认为双链断裂与细胞的致死性效应直接联系。
:::

:::compare{title="单链断裂 vs 双链断裂"}
| | 模板还在不在 | 本版原句 | 第二节走哪条 |
|--|------------|---------|------------|
| 单链断裂 | 另一条互补链还在 | 可迅速以互补链为模板重新合成 | 连接酶可直接封口；切除修复也用互补链 |
| 双链断裂 | 没有互补链可言 | 不能原位修复；畸变可能性大；与致死性效应直接联系 | 同源重组或非同源末端连接 |

「主要形式」是电离辐射；「致死性」点名的是双链断裂。不要把所有断裂都写成致死。
:::

:::pitfall{label="AP 位点还不是链断裂本身"}
糖苷酶去掉碱基，位子空了，叫 $\mathrm{AP}$ 位点。内切酶再切，才造成链断裂。写成「脱嘌呤就是断链」，第二节「先切碱基、再切磷酸核糖」的顺序就乱了。
:::

**4. $\mathrm{DNA}$ 链的共价交联**　被损伤的 $\mathrm{DNA}$ 分子中有多种 $\mathrm{DNA}$ 交联形式。$\mathrm{DNA}$ 分子中同一条链中的两个碱基以共价键结合，称之为 $\mathrm{DNA}$ 链内交联（DNA intrastrand cross-linking）。低波长紫外线照射后形成的嘧啶二聚体是 $\mathrm{DNA}$ 链内交联的最典型的例子。$\mathrm{DNA}$ 分子一条链上的碱基与另一条链上的碱基以共价键结合，称之为 $\mathrm{DNA}$ 链间交联（DNA interstrand cross-linking）。$\mathrm{DNA}$ 分子还可与蛋白质分子以共价键结合，称为 $\mathrm{DNA}$-蛋白质交联（DNA protein cross-linking）。

:::definition{label="链内交联"}
同一条链中的两个碱基以共价键结合（DNA intrastrand cross-linking）。最典型：低波长紫外线形成的嘧啶二聚体。
:::

:::definition{label="链间交联"}
一条链上的碱基与另一条链上的碱基以共价键结合（DNA interstrand cross-linking）。
:::

:::definition{label="DNA-蛋白质交联"}
$\mathrm{DNA}$ 分子与蛋白质分子以共价键结合（DNA protein cross-linking）。交联不限于核酸自己。
:::

:::compare{title="三种共价交联"}
| | 谁和谁共价 | 本版典型例子 |
|--|-----------|------------|
| 链内 | 同一条链上两个碱基 | 嘧啶二聚体（$\mathrm{TT}$、$\mathrm{CT}$、$\mathrm{CC}$） |
| 链间 | 两条链上的碱基 | 正文立名；紫外线「链间的其他交联」也落这里 |
| $\mathrm{DNA}$-蛋白质 | $\mathrm{DNA}$ 与蛋白质 | 正文立名 |

先问「共价连的是同一条链、对面那条链，还是蛋白质」。
:::

:::pitfall{label="交联不是氢键配对"}
三种交联都写「以共价键结合」。$\mathrm{A}$-$\mathrm{T}$、$\mathrm{G}$-$\mathrm{C}$ 的氢键不是交联。把 $\mathrm{TT}$ 二聚体答成「两条链上的 $\mathrm{T}$ 氢粘结起来」，链内／链间就反了。
:::

以上对各种类型的 $\mathrm{DNA}$ 损伤进行了系统阐述。实际上，$\mathrm{DNA}$ 损伤是相当复杂的。当 $\mathrm{DNA}$ 受到严重损伤时，在其局部范围所发生的损伤常常不止一种，而是多种类型的损伤复合存在。最常见的是碱基损伤、糖基破坏和链断裂可能同时存在。这样的损伤部位被称为局部多样性损伤部位。

:::definition{label="局部多样性损伤部位"}
严重损伤时，局部常常不止一种类型，而是多种损伤复合存在。最常见：碱基损伤、糖基破坏和链断裂同时存在。
:::

:::insight{label="类型是为了分户，真实病灶可以叠在一起"}
前四条是账本。局部多样性损伤部位提醒：电离辐射、严重化学损伤往往不是「只断链」或「只改一个碱基」。第二节「一种损伤可通过多种途径修复」对着这一句。
:::

上述 $\mathrm{DNA}$ 损伤可导致 $\mathrm{DNA}$ 模板发生碱基置换、插入、缺失和链的断裂等变化，并可能影响到染色体的高级结构。就碱基置换来讲，$\mathrm{DNA}$ 链中的一种嘌呤被另一种嘌呤取代，或一种嘧啶被另一种嘧啶取代，称为转换；而嘌呤被嘧啶取代或反之，则被称为颠换。转换和颠换在 $\mathrm{DNA}$ 复制时可引起碱基错配，导致基因突变。碱基的插入和缺失可引起移码突变。$\mathrm{DNA}$ 断裂可阻止 $\mathrm{RNA}$ 合成过程中链的延伸。而 $\mathrm{DNA}$ 损伤所引起的染色质结构变化也可以造成转录的异常。所有这些变化均可造成某种或某些基因信息发生异常或丢失，进而导致其表达产物的量与质的变化，对细胞的功能造成不同程度的影响。

:::definition{label="转换"}
一种嘌呤被另一种嘌呤取代，或一种嘧啶被另一种嘧啶取代。复制时可引起错配，导致基因突变。
:::

:::definition{label="颠换"}
嘌呤被嘧啶取代，或嘧啶被嘌呤取代。同样可在复制时引起错配，导致基因突变。
:::

:::definition{label="移码突变"}
碱基的插入和缺失可引起移码突变。嵌入染料拉开间距，复制打滑改变重复拷贝数，都可以走到插入／缺失这一户。
:::

:::compare{title="转换 vs 颠换 vs 插入缺失"}
| | 序列上发生了什么 | 密码子读框 | 本版接着说 |
|--|-----------------|-----------|-----------|
| 转换 | 嘌呤$\leftrightarrow$嘌呤，或嘧啶$\leftrightarrow$嘧啶 | 一般仍是三联体对齐 | 复制时错配 $\rightarrow$ 基因突变 |
| 颠换 | 嘌呤$\leftrightarrow$嘧啶 | 一般仍对齐 | 同上 |
| 插入／缺失 | 多了或少了碱基 | 可引起移码 | 表达产物的量与质都可能变 |

断裂挡住的是 $\mathrm{RNA}$ 合成中链的延伸；染色质高级结构变化也可造成转录异常。信息异常或丢失 $\rightarrow$ 产物量与质变化 $\rightarrow$ 细胞功能受影响。
:::

:::pitfall{label="转换颠换是碱基置换的分类，还不是错义无义同义"}
转换／颠换问的是嘌呤嘧啶怎么换。错义／无义／同义问的是密码子编不编同一个氨基酸。先有置换，再因简并性决定氨基酸变不变。两套词不要并成一句。
:::

需要特别指出的是，由于密码子的简并性（见第十六章），上述的碱基置换并非一定相应地发生氨基酸编码的改变。碱基置换可以造成改变氨基酸编码的错义突变（missense mutation）、变为终止密码子的无义突变（nonsense mutation）和不改变氨基酸编码的同义突变（same sense mutation）。教科书和文献中对于错义突变用氨基酸的单字母符号和位置注明，如 $\mathrm{B}$-$\mathrm{Raf}$ 的第 $600$ 位的缬氨酸突变为谷氨酸则写为 $\mathrm{V600E}$，具体标示为 $\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$。

:::definition{label="错义突变"}
错义突变（missense mutation）：碱基置换造成氨基酸编码改变。记法用氨基酸单字母符号和位置，如第 $600$ 位缬氨酸变为谷氨酸写为 $\mathrm{V600E}$，具体标示为 $\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$。
:::

:::definition{label="无义突变"}
无义突变（nonsense mutation）：碱基置换把密码子变成终止密码子。肽链提前终止。
:::

:::definition{label="同义突变"}
同义突变（same sense mutation）：碱基置换不改变氨基酸编码。本版用 same sense mutation 这一写法，户头是「氨基酸没变」，不是「什么都没发生」——基因型可以变，表型可以不变。
:::

:::definition{label="B-Raf V600E 记法"}
$\mathrm{B}$-$\mathrm{Raf}$ 第 $600$ 位缬氨酸（$\mathrm{V}$）突变为谷氨酸（$\mathrm{E}$），写成 $\mathrm{V600E}$，标示为 $\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$。这是错义突变的教科书／文献记法，不是无义突变。
:::

:::compare{title="错义 vs 无义 vs 同义"}
| | 英文 | 密码子变成什么 | 氨基酸 |
|--|------|--------------|--------|
| 错义 | missense mutation | 另一种氨基酸密码子 | 变了（$\mathrm{V600E}$ 这一类） |
| 无义 | nonsense mutation | 终止密码子 | 肽链提前结束 |
| 同义 | same sense mutation | 仍编码同一氨基酸 | 不变（简并性） |

三户都来自碱基置换，差在翻译读出来的是什么。简并性解释的是「置换不一定改氨基酸」，不是「置换一定无害」。
:::

:::pitfall{label="同义突变不要写成「没有突变」"}
同义是氨基酸编码不变。$\mathrm{DNA}$ 序列已经变了。第三节还写：突变可能只改变基因型而不影响表型。把同义答成「没发生损伤」，多态性和亲子鉴定那一户就空了。
:::

:::pitfall{label="V600E 不要写成无义突变"}
$\mathrm{V}$ 变成 $\mathrm{E}$ 是氨基酸替换，是错义。无义是变成终止密码子。把 $\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$ 答成「第 $600$ 位变成终止」，记法这一户就用错了。
:::

:::memory{label="本节必背分户"}
- 损伤＝组成与结构变化。两种后果：永久性改变（突变）／失去复制或转录模板功能。
- 修复同时启动。修对、凋亡、不完全修复（突变、畸变、衰老、恶性转化）。绝对稳定则无进化。
- 体内自发：复制错配约 $1/10^{10}$、打滑（亨廷顿病／脆性 $\mathrm{X}$／肌强直性营养不良）、脱嘌呤最普遍、$\mathrm{C}\rightarrow\mathrm{U}$、$\mathrm{A}\rightarrow\mathrm{I}$、$\mathrm{ROS}\rightarrow 8$-羟基脱氧鸟嘌呤。
- 体外：电离（直接＋自由基）／紫外线（$\mathrm{TT}$ 二聚体，图21-1 缺失）／自由基／$5$-$\mathrm{BU}$／亚硝酸与氮芥硫芥二乙基亚硝胺／溴化乙锭吖啶橙／黄曲霉素。图21-2 含苯并芘，左上不要标成图21-1。
- 类型：碱基与糖基破坏、错配、单／双链断裂（双链与致死相关）、链内／链间／$\mathrm{DNA}$-蛋白质交联、局部多样性损伤部位。
- 转换 vs 颠换；插入缺失 $\rightarrow$ 移码。错义／无义／同义；$\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$。
:::

:::keypoint{label="本节不写修复酶名单"}
光复活酶、烷基转移酶、$\mathrm{DNA}$ 糖苷酶、$\mathrm{Uvr}$、$\mathrm{XP}$、$\mathrm{MRN}$、$\mathrm{RAD}51$、$\mathrm{LexA}$-$\mathrm{RecA}$ 都是第二节的账。本节只把损伤立住，并在末尾把错义／无义／同义和 $\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$ 记法写完，避免第二节开头再挂一截突变分类。
:::
