# 第二节　DNA的空间结构与功能

本节写 $\mathrm{DNA}$ 的空间结构与功能。先把 Chargaff 规则和 Franklin 的 $\mathrm{X}$ 线衍射摊开，再落到 Watson-Crick 反向平行右手双螺旋：$\mathrm{A}$-$\mathrm{T}$ 两对氢键、$\mathrm{G}$-$\mathrm{C}$ 三对氢键、大沟小沟、碱基堆积；$\mathrm{A}/\mathrm{B}/\mathrm{Z}$ 型按教材表3-4 记参数。然后写三链与 $\mathrm{G}$-四链、原核负超螺旋、真核核小体到染色体，以及 $\mathrm{DNA}$ 作为主要遗传物质。

在特定的环境条件下（$\mathrm{pH}$、离子特性、离子浓度等），$\mathrm{DNA}$ 链上的功能基团可以产生特殊的氢键、离子键、疏水相互作用以及空间位阻效应等，从而使得 $\mathrm{DNA}$ 分子的各个原子在三维空间里具有了确定的相对位置关系，这称为 $\mathrm{DNA}$ 的空间结构（spatial structure）。$\mathrm{DNA}$ 的空间结构可分为二级结构（secondary structure）和高级结构。

:::definition{label="DNA 的空间结构"}
在特定环境条件（$\mathrm{pH}$、离子特性、离子浓度等）下，$\mathrm{DNA}$ 链上的功能基团产生氢键、离子键、疏水相互作用以及空间位阻效应等，使各个原子在三维空间里具有确定的相对位置关系，称为 $\mathrm{DNA}$ 的空间结构（spatial structure）。可分为二级结构（secondary structure）和高级结构。
:::

:::concept{term="先问二级还是高级，再问螺旋参数还是折叠压缩"}
二级结构首先是双螺旋；高级结构是双链再盘绕折叠成超螺旋、核小体、染色质、染色体。把核小体听成“还是二级结构”，压缩倍数那一笔会没有台阶。
:::

## 一、DNA 的二级结构是双螺旋结构

### （一）一些经典实验为 DNA 双螺旋结构的提出奠定了基础

$20$ 世纪 $40$ 年代末，美国生物化学家 Chargaff E. 利用层析和紫外吸收光谱等技术研究了 $\mathrm{DNA}$ 的化学组分，并在 $1950$ 年提出了有关 $\mathrm{DNA}$ 中四种碱基的 Chargaff 规则。它们是：①不同生物个体的 $\mathrm{DNA}$，其碱基组成不同；②同一个体的不同器官或不同组织的 $\mathrm{DNA}$ 具有相同的碱基组成；③对于一个特定组织的 $\mathrm{DNA}$，其碱基组分不随其年龄、营养状态和环境而变化；④对于一个特定的生物体，$\mathrm{A}$ 的摩尔数与 $\mathrm{T}$ 的摩尔数相等，$\mathrm{G}$ 的摩尔数与 $\mathrm{C}$ 的摩尔数相等。表3-3 列举了几种生物体的 $\mathrm{DNA}$ 碱基组分的相对比例。Chargaff 规则揭示了 $\mathrm{DNA}$ 的碱基之间存在着某种对应的关系，为碱基之间的互补配对关系奠定了基础。

$20$ 世纪 $50$ 年代初，英国帝国学院的 Franklin R. 和 Wilkins M. 进行了大量的工作，利用 $\mathrm{X}$ 射线衍射技术来解析 $\mathrm{DNA}$ 分子空间结构。凭借丰富的经验和细致耐心的工作，Franklin R. 取得了突破性的进展。$1951$ 年 $11$ 月，Franklin R. 获得了高质量的 $\mathrm{DNA}$ 分子 $\mathrm{X}$ 线衍射照片，并从衍射图像得出 $\mathrm{DNA}$ 分子呈螺旋状的推论。当时开展 $\mathrm{DNA}$ 分子空间结构研究工作的还有英国剑桥大学的 Watson J.D. 和 Crick F.H.。他们综合了前人的研究结果，提出了 $\mathrm{DNA}$ 双螺旋结构（the double helix structure）的模型，并在 $1953$ 年 $4$ 月 $25$ 日将该模型发表在 Nature 杂志上。这一发现不仅解释了当时已知的 $\mathrm{DNA}$ 的理化性质，而且还将 $\mathrm{DNA}$ 的功能与结构联系起来，它诠释了生物界遗传性状得以世代相传的分子机制，奠定了现代生命科学的基础。$\mathrm{DNA}$ 双螺旋结构揭示了 $\mathrm{DNA}$ 作为遗传信息载体的物质本质，为 $\mathrm{DNA}$ 作为复制模板和基因转录模板提供了结构基础。$\mathrm{DNA}$ 双螺旋结构的发现被认为是现代生物学和医学发展史的一个里程碑。

:::definition{label="Chargaff 规则"}
Chargaff E. 于 $1950$ 年提出的关于 $\mathrm{DNA}$ 中四种碱基的规则：①不同生物个体的 $\mathrm{DNA}$，碱基组成不同；②同一个体不同器官或不同组织的 $\mathrm{DNA}$ 具有相同的碱基组成；③特定组织的 $\mathrm{DNA}$，碱基组分不随年龄、营养状态和环境而变化；④特定生物体中，$\mathrm{A}$ 的摩尔数与 $\mathrm{T}$ 的摩尔数相等，$\mathrm{G}$ 的摩尔数与 $\mathrm{C}$ 的摩尔数相等。
:::

:::definition{label="DNA 双螺旋结构"}
Watson J.D. 和 Crick F.H. 综合前人结果提出的 $\mathrm{DNA}$ 双螺旋结构（the double helix structure）模型，$1953$ 年 $4$ 月 $25$ 日发表于 Nature。它揭示了 $\mathrm{DNA}$ 作为遗传信息载体的物质本质，为 $\mathrm{DNA}$ 作为复制模板和基因转录模板提供了结构基础。
:::

:::pitfall{label="Chargaff 不是 A 等于 G，也不是所有生物 GC 含量都一样"}
第四条是 $\mathrm{A}=\mathrm{T}$、$\mathrm{G}=\mathrm{C}$，不是嘌呤内部相等。第一条明确：不同生物个体碱基组成不同——表3-3 的 $\mathrm{G}+\mathrm{C}$ 从酵母 $35.7\%$ 到结核分枝杆菌 $70.3\%$。把 Chargaff 听成“四种碱基各 $25\%$”，人的那一行（$\mathrm{A}$ $30.4\%$，$\mathrm{G}$ $19.9\%$）会对不上。
:::

### （二）DNA 呈现反向平行的右手双螺旋结构

Watson J.D. 和 Crick F.H. 提出的 $\mathrm{DNA}$ 双螺旋结构具有下列特征：

**1. DNA 由两条多聚脱氧核苷酸链组成**　两条多聚脱氧核苷酸链围绕着同一个螺旋轴形成反平行的右手螺旋（right-handed helix）的结构（图3-8）。两条链中一条链的 $5'\rightarrow 3'$ 方向是自上而下，而另一条链的 $5'\rightarrow 3'$ 方向是自下而上，呈现出反向平行（anti-parallel）的特征。$\mathrm{DNA}$ 双螺旋结构的直径为 $2.37\,\mathrm{nm}$，螺距为 $3.54\,\mathrm{nm}$。

**2. DNA 的两条多聚脱氧核苷酸链之间形成了互补碱基对**　碱基的化学结构特征决定了两条链之间的特有相互作用方式：一条链上的腺嘌呤与另一条链上的胸腺嘧啶形成了两对氢键；一条链上的鸟嘌呤与另一条链上的胞嘧啶形成了三对氢键（图3-9）。这种特定的碱基之间的作用关系称为互补碱基对（complementary base pair），$\mathrm{DNA}$ 的两条链则称为互补链（complementary strand）。碱基对平面与双螺旋结构的螺旋轴近乎垂直。平均而言，每一个螺旋有 $10.5$ 个碱基对，碱基对平面之间的垂直距离为 $0.34\,\mathrm{nm}$。

**3. 两条多聚脱氧核苷酸链的亲水性骨架将互补碱基对包埋在 DNA 双螺旋结构内部**　多聚脱氧核苷酸链的脱氧核糖和磷酸基团构成了亲水性骨架（backbone），该骨架位于双螺旋结构的外侧，而疏水性的碱基对包埋在双螺旋结构的内侧（图3-10）。$\mathrm{DNA}$ 双链的反向平行走向使得碱基对与磷酸骨架的连接呈现非对称性，从而在 $\mathrm{DNA}$ 双螺旋结构的表面上产生一个大沟（major groove）和一个小沟（minor groove）。

**4. 两个碱基对平面重叠产生了碱基堆积作用**　在 $\mathrm{DNA}$ 双螺旋结构的旋转过程中，相邻的两个碱基对平面彼此重叠（overlapping），由此产生了疏水性的碱基堆积力（base stacking force）（图3-11）。这种碱基堆积作用十分重要，它和互补链之间碱基对的氢键共同维系着 $\mathrm{DNA}$ 双螺旋结构的稳定。

:::definition{label="右手双螺旋与反向平行"}
两条多聚脱氧核苷酸链围绕同一螺旋轴形成反平行的右手螺旋（right-handed helix）。一条链 $5'\rightarrow 3'$ 自上而下，另一条 $5'\rightarrow 3'$ 自下而上，称为反向平行（anti-parallel）。直径 $2.37\,\mathrm{nm}$，螺距 $3.54\,\mathrm{nm}$。
:::

:::definition{label="互补碱基对"}
一条链上的腺嘌呤与另一条链上的胸腺嘧啶形成两对氢键；一条链上的鸟嘌呤与另一条链上的胞嘧啶形成三对氢键。这种特定作用关系称为互补碱基对（complementary base pair），两条链称为互补链（complementary strand）。
:::

:::definition{label="大沟与小沟"}
亲水性骨架（脱氧核糖和磷酸）在外侧，疏水性碱基对包埋在内侧。反向平行使碱基对与磷酸骨架的连接呈非对称性，从而在双螺旋表面产生一个大沟（major groove）和一个小沟（minor groove）。
:::

:::definition{label="碱基堆积力"}
相邻两个碱基对平面彼此重叠（overlapping），产生疏水性的碱基堆积力（base stacking force）。它和互补链之间碱基对的氢键共同维系双螺旋稳定。
:::

:::

### （三）DNA 双螺旋结构具有多样性

Watson J.D. 和 Crick F.H. 提出的 $\mathrm{DNA}$ 双螺旋结构模型是基于在 $92\%$ 相对湿度下得到的 $\mathrm{DNA}$ 纤维 $\mathrm{X}$ 射线衍射图像的分析结果，这是 $\mathrm{DNA}$ 在水性环境和生理条件下最稳定的结构。由于历史原因，人们将 Watson J.D. 和 Crick F.H. 提出的双螺旋结构称为 $\mathrm{B}$ 型 $\mathrm{DNA}$。随着研究的深入，人们发现 $\mathrm{DNA}$ 的结构不是一成不变的，溶液的离子强度或相对湿度的变化可以使 $\mathrm{DNA}$ 双螺旋结构的沟槽、螺距、旋转角度、碱基对倾角等发生变化。当环境的相对湿度降低后，$\mathrm{DNA}$ 仍然保持着稳定的右手双螺旋结构，但是它的空间结构参数不同于 $\mathrm{B}$ 型 $\mathrm{DNA}$，人们将其称为 $\mathrm{A}$ 型 $\mathrm{DNA}$（图3-12）。$1979$ 年，美国科学家 Rich A. 等科学家在研究人工合成的寡核酸链 $\mathrm{CGCGCG}$ 的晶体结构时，意外发现这种 $\mathrm{DNA}$ 具有左手双螺旋（left-handed helix）的结构特征（图3-12）。后来证明这种结构在天然 $\mathrm{DNA}$ 分子中同样存在，并称为 $\mathrm{Z}$ 型 $\mathrm{DNA}$。三种不同类型 $\mathrm{DNA}$ 双螺旋结构的结构参数见表3-4。因此，$\mathrm{DNA}$ 的右手双螺旋结构不是 $\mathrm{DNA}$ 在自然界中唯一存在方式，存在多样性。在体内，不同的 $\mathrm{DNA}$ 双螺旋结构是与基因表达的调节和控制相适应的。

:::definition{label="B 型 DNA"}
Watson-Crick 模型所依据的是 $92\%$ 相对湿度下 $\mathrm{DNA}$ 纤维的 $\mathrm{X}$ 射线衍射结果，这是水性环境和生理条件下最稳定的结构。由于历史原因，该双螺旋称为 $\mathrm{B}$ 型 $\mathrm{DNA}$。
:::

:::definition{label="A 型 DNA"}
相对湿度降低后，$\mathrm{DNA}$ 仍保持稳定的右手双螺旋，但空间结构参数不同于 $\mathrm{B}$ 型，称为 $\mathrm{A}$ 型 $\mathrm{DNA}$。使构象稳定的相对环境湿度为 $75\%$。
:::

:::definition{label="Z 型 DNA"}
$1979$ 年 Rich A. 等在人工合成寡核酸链 $\mathrm{CGCGCG}$ 的晶体中发现左手双螺旋；后来证明天然 $\mathrm{DNA}$ 中同样存在，称为 $\mathrm{Z}$ 型 $\mathrm{DNA}$。
:::

### （四）特殊序列的 DNA 能够形成多链结构

Watson J.D. 和 Crick F.H. 提出的碱基互补配对，即 Watson-Crick 配对（Watson-Crick pairing），是 $\mathrm{DNA}$ 双链结构中最常见的现象。然而随着对 $\mathrm{DNA}$ 研究的不断深入，科学家发现，自然界中还存在着多条链结合在一起的 $\mathrm{DNA}$ 结构。在酸性的溶液中，胞嘧啶 $\mathrm{N}$-$3$ 原子可以被质子化，这使得它可以在 $\mathrm{DNA}$ 双链的大沟一侧与已有的 $\mathrm{GC}$ 碱基对中的鸟嘌呤 $\mathrm{N}$-$7$ 原子形成新的氢键，同时，胞嘧啶的 $\mathrm{C}$-$4$ 位氨基的氢原子也可以与鸟嘌呤的 $\mathrm{C}$-$6$ 位氧形成新的氢键（图3-13）。这种氢键最早是生物学家 Hoogsteen K. 于 $1959$ 年在研究碱基对时发现的，故命名为 Hoogsteen 氢键。Hoogsteen 氢键的形成并不破坏原有碱基对中的 Watson-Crick 氢键，这样就形成了含有三个碱基的 $\mathrm{C}^{+}:\mathrm{G}:\mathrm{C}$ 平面，其中 $\mathrm{GC}$ 之间是以 Watson-Crick 氢键结合，而 $\mathrm{C}^{+}\mathrm{G}$ 之间是以 Hoogsteen 氢键结合的。同理，$\mathrm{DNA}$ 也可以形成 $\mathrm{T}:\mathrm{A}:\mathrm{T}$ 的三碱基平面（图3-13）。

当 $\mathrm{DNA}$ 双链中一条链的核苷酸序列富含嘌呤时，对应的互补链必然是富含嘧啶，它们形成了正常的 $\mathrm{DNA}$ 双链。如果还有一条富含嘧啶的单链（其序列与富含嘧啶链具有极高的相似度），并且环境条件为酸性时，这条链上的嘧啶就会与双链中的嘌呤形成 Hoogsteen 氢键，从而生成了 $\mathrm{DNA}$ 的三链结构（triplex）。人们曾经利用这样的三链结构来尝试着调控基因的表达。根据某些基因的序列特征（例如富含嘌呤的序列），人们设计了富含嘧啶的寡核苷酸链。由于这条寡核苷酸链与这一段双链 $\mathrm{DNA}$ 的序列有着碱基互补关系，它可以嵌入在双链 $\mathrm{DNA}$ 的大沟中形成三链结构，以此干扰调控因子的结合，影响该基因的复制或转录。

真核生物染色体 $3'$-端是一段高度重复的富含 $\mathrm{GT}$ 的单链，被称为端粒（telomere），例如人端粒区的碱基序列是 $(\mathrm{TTAGGG})_{n}$，其重复度可达数百乃至上千。作为单链结构的端粒，具有较大的柔韧度，可以自身回折形成一个称为 $\mathrm{G}$-四链（$\mathrm{G}$-quadruplex）的特殊结构。这个 $\mathrm{G}$-四链结构的核心是由 $4$ 个鸟嘌呤通过 $8$ 对 Hoogsteen 氢键形成的 $\mathrm{G}$-平面（tetrad 或 quartet）（图3-13）。若干个 $\mathrm{G}$-平面的堆积使富含鸟嘌呤的重复序列形成 $\mathrm{G}$ 四链结构。人们推测这种 $\mathrm{G}$-四链结构是用来保护端粒的完整性。近来，人们还发现某些癌基因的启动子和 $\mathrm{mRNA}$ 的 $3'$ 非翻译区都有一些富含鸟嘌呤的序列。这些序列可以通过形成特定的 $\mathrm{G}$-四链结构对基因转录和蛋白质合成进行适度的调控。受离子类型、离子浓度、鸟嘌呤 $\mathrm{G}$ 排列顺序的影响，富含鸟嘌呤的序列可以形成具有不同拓扑构象的 $\mathrm{G}$-四链体。

:::definition{label="Watson-Crick 配对"}
Watson-Crick 配对（Watson-Crick pairing）是 $\mathrm{DNA}$ 双链结构中最常见的碱基互补配对：$\mathrm{A}$-$\mathrm{T}$ 两对氢键，$\mathrm{G}$-$\mathrm{C}$ 三对氢键。
:::

:::definition{label="Hoogsteen 氢键"}
Hoogsteen K. 于 $1959$ 年发现的氢键。酸性溶液中胞嘧啶 $\mathrm{N}$-$3$ 质子化后，可在双链大沟一侧与已有 $\mathrm{GC}$ 对中鸟嘌呤 $\mathrm{N}$-$7$ 形成新氢键，其 $\mathrm{C}$-$4$ 氨基氢还可与鸟嘌呤 $\mathrm{C}$-$6$ 氧形成新氢键。Hoogsteen 氢键不破坏原有 Watson-Crick 氢键。
:::

:::definition{label="DNA 三链结构"}
含三个碱基的 $\mathrm{C}^{+}:\mathrm{G}:\mathrm{C}$ 平面（$\mathrm{GC}$ 为 Watson-Crick，$\mathrm{C}^{+}\mathrm{G}$ 为 Hoogsteen）或 $\mathrm{T}:\mathrm{A}:\mathrm{T}$ 三碱基平面。当双链一条富含嘌呤、互补链富含嘧啶，再有一条与嘧啶链高度相似的富含嘧啶单链，且环境为酸性时，第三条链的嘧啶与双链中的嘌呤形成 Hoogsteen 氢键，生成三链结构（triplex）。第三条链嵌入大沟，可干扰调控因子结合，影响复制或转录。
:::

:::definition{label="端粒与 G-四链"}
真核生物染色体 $3'$-端高度重复、富含 $\mathrm{GT}$ 的单链称为端粒（telomere）。人端粒序列为 $(\mathrm{TTAGGG})_{n}$，重复度可达数百乃至上千。单链端粒可自身回折形成 $\mathrm{G}$-四链（$\mathrm{G}$-quadruplex）：$4$ 个鸟嘌呤通过 $8$ 对 Hoogsteen 氢键形成 $\mathrm{G}$-平面（tetrad 或 quartet），若干平面堆积成 $\mathrm{G}$ 四链。推测用于保护端粒完整性；癌基因启动子和 $\mathrm{mRNA}$ 的 $3'$-非翻译区富 $\mathrm{G}$ 序列也可借此调控转录与蛋白质合成。
:::

::figure{src="/images/biochemistry/textbook/p0090_01.png" caption="图3-13　DNA 的多链螺旋结构。（a）由 Watson-Crick 氢键和 Hoogsteen 氢键共同构成的三链结构：C⁺:G:C 与 T:A:T，第三链走大沟一侧。（b）由 Hoogsteen 氢键构成的四链结构：G-四链体的 G-平面，以及人端粒碱基序列 5′-(TTAGGG)₄-3′ 的回折示意。" alt="上半：三链螺旋旁画出 C+GC 与 TAT 氢键；下半：四个鸟嘌呤围成 G-平面，右侧端粒序列回折成四层平面"}

:::compare{title="Watson-Crick 氢键与 Hoogsteen 氢键"}
| 项目 | Watson-Crick | Hoogsteen |
|------|----------------|-----------|
| 出现场合 | 双链中最常见的互补配对 | 第三链走大沟；$\mathrm{G}$-四链的 $\mathrm{G}$-平面 |

三链：原有双链仍在，第三条链走进大沟，Watson-Crick 氢键保留。$\mathrm{G}$-四链：一条富 $\mathrm{G}$ 单链自身回折，四个 $\mathrm{G}$ 围成平面。人端粒是 $(\mathrm{TTAGGG})_{n}$，不要写成 $(\mathrm{CCCTAA})_{n}$ 去配成普通双链就算端粒结构。
:::

## 二、DNA 双链经过盘绕折叠形成致密的高级结构

自然界的 $\mathrm{DNA}$ 分子是巨大的信息高分子，储存着庞大的遗传信息。而进化程度越高的生物体其 $\mathrm{DNA}$ 的分子构成越大，越复杂；而 $\mathrm{DNA}$ 必须通过紧密折叠后储存于细胞内。

线性的 $\mathrm{DNA}$ 双链不是一条刚性分子，具有一定程度的柔韧性。一旦发生弯曲，$\mathrm{DNA}$ 双链就会在其内部产生一定的应力。$\mathrm{DNA}$ 双链需要形成一种超螺旋结构（superhelix 或 supercoil），释放出这些应力使 $\mathrm{DNA}$ 处在一个低能量的稳定状态。当盘绕方向与 $\mathrm{DNA}$ 双螺旋方向相同时，其超螺旋结构为正超螺旋（positive supercoil）；反之则为负超螺旋（negative supercoil）。在生物体内，$\mathrm{DNA}$ 的超螺旋结构是在拓扑异构酶参与下形成的。拓扑异构酶可以改变超螺旋结构的数量和类型。

自然条件下的 $\mathrm{DNA}$ 双链主要是以负超螺旋形式存在的，经过一系列的盘绕、折叠和压缩后，形成了高度致密的高级结构。自然状态下的环状 $\mathrm{DNA}$ 分子表现出松弛的双链结构，在拓扑异构酶作用下形成超螺旋结构。两种结构处在动态平衡之中。

:::definition{label="超螺旋"}
$\mathrm{DNA}$ 双链弯曲产生应力后，形成超螺旋结构（superhelix 或 supercoil）以释放应力，使 $\mathrm{DNA}$ 处在低能量稳定状态。盘绕方向与双螺旋方向相同为正超螺旋（positive supercoil）；相反为负超螺旋（negative supercoil）。体内由拓扑异构酶形成，并可改变超螺旋的数量和类型。
:::

:::definition{label="负超螺旋是体内主要形式"}
自然条件下 $\mathrm{DNA}$ 双链主要以负超螺旋形式存在。环状 $\mathrm{DNA}$ 的松弛双链与超螺旋在拓扑异构酶作用下处于动态平衡。
:::

:::compare{title="正超螺旋与负超螺旋"}
| 项目 | 正超螺旋 | 负超螺旋 |
|------|----------|----------|
| 盘绕方向 | 与双螺旋方向相同 | 与双螺旋方向相反 |
| 体内是否主要 | 不是教材说的主要形式 | 自然条件下主要形式 |
| 功能相关 | — | 局部解链效应，有助于复制、转录 |
| 存在条件（原核） | — | 封闭环状，或与蛋白质结合，以免相互纠缠 |
:::

:::pitfall{label="超螺旋不是二级结构，拓扑异构酶也不是把双螺旋拆成单链就算完"}
二级结构是双螺旋；超螺旋是双链再盘绕的高级结构。拓扑异构酶改的是超螺旋的数量和类型。把“负超螺旋”听成“左手 Z-DNA”，户头就错了。
:::

### （一）原核生物封闭环状的 DNA 具有超螺旋结构

绝大部分原核生物的 $\mathrm{DNA}$ 是环状的双螺旋分子。在细胞内经过进一步盘绕后，形成了类核（nucleoid）结构。类核占据了细胞的大部分空间，并通过与蛋白质的相互作用黏附在细胞内壁。在细菌 $\mathrm{DNA}$ 中，不同的 $\mathrm{DNA}$ 区域可以有不同程度的超螺旋结构，超螺旋结构可以相互独立存在（图3-14）。分析表明，在大肠埃希菌的环状 $\mathrm{DNA}$ 中，平均每 $200$ 个碱基就有一个负超螺旋形成。负超螺旋的 $\mathrm{DNA}$ 双链只能以封闭环状的形式或者在与蛋白质结合的条件下存在，以避免它们之间的相互纠缠。这种负超螺旋形式产生了 $\mathrm{DNA}$ 双链的局部解链效应，有助于诸如复制、转录等生物过程的进行。

:::definition{label="类核"}
绝大部分原核生物的 $\mathrm{DNA}$ 是环状双螺旋分子，在细胞内进一步盘绕形成类核（nucleoid）。类核占据细胞大部分空间，并通过与蛋白质相互作用黏附在细胞内壁。
:::

:::definition{label="大肠埃希菌的负超螺旋密度"}
大肠埃希菌环状 $\mathrm{DNA}$ 中，平均每 $200$ 个碱基就有一个负超螺旋形成。不同 $\mathrm{DNA}$ 区域可有不同程度的超螺旋，且可相互独立存在。
:::

::figure{src="/images/biochemistry/textbook/p0091_01.png" caption="图3-14　原核生物的超螺旋结构。左侧为较松弛的环状双链，右侧为盘绕生成的超螺旋；双向箭头标明盘绕生成超螺旋与解螺旋的动态平衡。" alt="环形双螺旋经盘绕生成超螺旋、经解螺旋回到松弛环，中间为双向箭头"}

:::cause-effect{title="负超螺旋为什么有助于复制和转录"}
- **因** 负超螺旋使 $\mathrm{DNA}$ 双链产生局部解链效应
- **果** 有助于复制、转录等需要把双链打开的过程
:::

:::insight{label="负超螺旋必须“闭成环”或“绑在蛋白上”"}
教材写：负超螺旋的双链只能以封闭环状形式或与蛋白质结合的条件下存在，以避免相互纠缠。开链的线性分子若没有约束，超螺旋应力会转掉。这为真核线性 $\mathrm{DNA}$ 必须靠核小体等蛋白质约束留下伏笔。
:::

### （二）真核生物基因组 DNA 被逐级有序地组装成高级结构

人类基因组大约有 $3\times 10^{9}$ 个碱基对，这是一条长度约为 $1.7\,\mathrm{m}$ 的线性大分子。将这样的一条 $\mathrm{DNA}$ 双链组装在细胞核内，$\mathrm{DNA}$ 双链需要进行一系列的盘绕、折叠和压缩。在细胞周期的大部分时间里，细胞核内的 $\mathrm{DNA}$ 以松散的染色质（chromatin）形式存在，只有在细胞分裂期间，细胞核内的 $\mathrm{DNA}$ 才形成高度致密的染色体（chromosome）。

在电子显微镜下观察到的染色质具有串珠样的结构（图3-15a）。染色质基本组成单位是核小体（nucleosome），它是由一段双链 $\mathrm{DNA}$ 和 $4$ 种碱性的组蛋白（histone，$\mathrm{H}$）共同构成的。八个组蛋白分子（$\mathrm{H2A}\times 2$，$\mathrm{H2B}\times 2$，$\mathrm{H3}\times 2$ 和 $\mathrm{H4}\times 2$）共同形成八聚体的核心组蛋白，长度约 $146\,\mathrm{bp}$ 的 $\mathrm{DNA}$ 双链在核心组蛋白上盘绕 $1.75$ 圈，形成核小体的核心颗粒（core particle）（图3-15b）。核心颗粒是尺寸约 $11\,\mathrm{nm}\times 6\,\mathrm{nm}$ 的盘状颗粒。连接相邻核小体之间的一段 $\mathrm{DNA}$ 称为连接段 $\mathrm{DNA}$（linker $\mathrm{DNA}$），其长度在 $0\sim 50\,\mathrm{bp}$ 之间不等，是非组蛋白结合的区域。组蛋白 $\mathrm{H1}$ 结合在盘绕在核心组蛋白上的 $\mathrm{DNA}$ 双链的进出口处，发挥稳定核小体结构的作用（图3-15c）。至此，核小体核心颗粒和 $\mathrm{DNA}$ 双链形成了 $10\,\mathrm{nm}$ 的串珠状结构，也称为染色质纤维。这是 $\mathrm{DNA}$ 在核内形成致密结构的第一次折叠，使 $\mathrm{DNA}$ 的长度压缩了约 $7$ 倍。

染色质纤维按照左手螺旋方式进一步盘绕卷曲，在组蛋白 $\mathrm{H1}$ 的参与下形成外径为 $30\,\mathrm{nm}$、内径为 $10\,\mathrm{nm}$ 的中空状螺线管（solenoid）。每个螺旋有 $6$ 个核小体，组蛋白 $\mathrm{H1}$ 位于螺线管的内侧，继续发挥稳定螺线管的作用。染色质纤维中空状螺线管的形成与 $\mathrm{DNA}$ 特定区间的转录活性相关：正在进行转录的区间处在一种明显的无序状态之中，组蛋白 $\mathrm{H1}$ 的数量也较少。染色质纤维中空状螺线管的形成是 $\mathrm{DNA}$ 在细胞内的第二次折叠，使 $\mathrm{DNA}$ 的压缩程度达到 $40\sim 60$ 倍。

关于 $30\,\mathrm{nm}$ 中空状螺线管如何压缩成染色体，尚存争议。目前得到较为广泛认可的是多级螺线化模型（multiple coiling model）。染色质纤维螺线管的进一步卷曲和折叠形成了直径为 $400\,\mathrm{nm}$ 的超螺线管（supersolenoid），这一过程将 $\mathrm{DNA}$ 的长度又压缩了 $40$ 倍。之后，超螺线管的再度盘绕和压缩形成染色单体，在核内组装成染色体，使 $\mathrm{DNA}$ 长度又压缩了 $5\sim 6$ 倍（图3-16）。这样，在染色体形成的过程中，$\mathrm{DNA}$ 的长度总共被压缩了 $8000\sim 10000$ 倍，从而将近 $2\,\mathrm{m}$ 长的 $\mathrm{DNA}$ 有效地组装在直径只有几微米的细胞核中。

真核生物染色体有端粒（telomere）和着丝粒（centromere）两个功能区。端粒是染色体端膨大的粒状结构，由染色体端 $\mathrm{DNA}$（也称端粒 $\mathrm{DNA}$）与 $\mathrm{DNA}$ 结合蛋白共同构成。端粒 $\mathrm{DNA}$ 由简单重复序列构成，人的端粒 $\mathrm{DNA}$ 的重复序列是 $\mathrm{TTAGGG}$，以 $\mathrm{G}$-四链体的结构存在。端粒在维持染色体结构的稳定性和维持复制过程中的 $\mathrm{DNA}$ 的完整性方面具有重要作用，此外，端粒 $\mathrm{DNA}$ 的结构和稳定性还与衰老及肿瘤的发生发展密切有关。着丝粒是两个染色单体的连接位点，富含 $\mathrm{AT}$ 序列。细胞分裂时，着丝粒可分开使染色体均等有序地进入子代细胞。

:::definition{label="染色质与染色体"}
细胞周期大部分时间里，核内 $\mathrm{DNA}$ 以松散的染色质（chromatin）形式存在；只有细胞分裂期间才形成高度致密的染色体（chromosome）。
:::

:::definition{label="核小体"}
染色质的基本组成单位是核小体（nucleosome），由一段双链 $\mathrm{DNA}$ 和 $4$ 种碱性组蛋白（histone，$\mathrm{H}$）构成。八个组蛋白（$\mathrm{H2A}\times 2$，$\mathrm{H2B}\times 2$，$\mathrm{H3}\times 2$，$\mathrm{H4}\times 2$）形成八聚体核心组蛋白；约 $146\,\mathrm{bp}$ 的 $\mathrm{DNA}$ 双链在其上盘绕 $1.75$ 圈，形成核心颗粒（core particle）。核心颗粒约 $11\,\mathrm{nm}\times 6\,\mathrm{nm}$ 的盘状颗粒。
:::

:::definition{label="连接段 DNA 与组蛋白 H1"}
连接相邻核小体的 $\mathrm{DNA}$ 称为连接段 $\mathrm{DNA}$（linker $\mathrm{DNA}$），长度 $0\sim 50\,\mathrm{bp}$，是非组蛋白结合区域。组蛋白 $\mathrm{H1}$ 结合在盘绕于核心组蛋白上的 $\mathrm{DNA}$ 双链进出口处，稳定核小体结构。
:::

:::definition{label="10 nm 染色质纤维"}
核小体核心颗粒和 $\mathrm{DNA}$ 双链形成 $10\,\mathrm{nm}$ 串珠状结构，称为染色质纤维。这是核内第一次折叠，使 $\mathrm{DNA}$ 长度压缩约 $7$ 倍。
:::

:::definition{label="30 nm 螺线管"}
染色质纤维按左手螺旋进一步盘绕，在 $\mathrm{H1}$ 参与下形成外径 $30\,\mathrm{nm}$、内径 $10\,\mathrm{nm}$ 的中空状螺线管（solenoid）。每个螺旋 $6$ 个核小体，$\mathrm{H1}$ 位于内侧。这是第二次折叠，压缩程度达 $40\sim 60$ 倍。正在转录的区间明显无序，$\mathrm{H1}$ 数量也较少。
:::

:::definition{label="多级螺线化模型"}
$30\,\mathrm{nm}$ 螺线管如何压成染色体尚存争议。较广泛认可的是多级螺线化模型（multiple coiling model）：螺线管进一步卷曲折叠成直径 $400\,\mathrm{nm}$ 的超螺线管（supersolenoid），再压缩 $40$ 倍；超螺线管再度盘绕形成染色单体并组装成染色体，又压缩 $5\sim 6$ 倍。染色体形成过程中 $\mathrm{DNA}$ 长度总共压缩 $8000\sim 10000$ 倍。
:::

:::definition{label="端粒（染色体功能区）"}
端粒是染色体端膨大的粒状结构，由端粒 $\mathrm{DNA}$ 与 $\mathrm{DNA}$ 结合蛋白共同构成。人的端粒 $\mathrm{DNA}$ 重复序列是 $\mathrm{TTAGGG}$，以 $\mathrm{G}$-四链体存在。功能：维持染色体结构稳定性，维持复制过程中 $\mathrm{DNA}$ 完整性；其结构与稳定性还与衰老及肿瘤发生发展密切相关。
:::

:::definition{label="着丝粒"}
着丝粒（centromere）是两个染色单体的连接位点，富含 $\mathrm{AT}$ 序列。细胞分裂时着丝粒可分开，使染色体均等有序地进入子代细胞。
:::

### （三）真核生物中存在环形结构的线粒体 DNA

真核生物细胞内，还存在细胞核外的遗传物质，线粒体 $\mathrm{DNA}$（mitochondrial $\mathrm{DNA}$，$\mathrm{mtDNA}$）。$\mathrm{mtDNA}$ 是一个裸露的、环状的双链 $\mathrm{DNA}$ 分子。与核 $\mathrm{DNA}$ 不同的是，$\mathrm{mtDNA}$ 没有任何蛋白质的结合和吸附。人线粒体 $\mathrm{DNA}$ 位于线粒体基质中，全长 $16569\,\mathrm{bp}$，为闭合双链环状分子，含有编码区和非编码区。$\mathrm{mtDNA}$ 可编码 $2$ 种 $\mathrm{rRNA}$（$12\mathrm{S}$ 和 $16\mathrm{S}$）、$22$ 种 $\mathrm{tRNA}$ 和 $13$ 种多肽（每种约含 $50$ 个氨基酸残基）。$\mathrm{mtDNA}$ 具有自己的遗传密码子，结构基因主要编码线粒体内膜呼吸链的组分，参与细胞的氧化磷酸化过程，并且呈母系遗传。

:::definition{label="线粒体 DNA"}
线粒体 $\mathrm{DNA}$（mitochondrial $\mathrm{DNA}$，$\mathrm{mtDNA}$）是真核细胞核外的遗传物质：裸露的、环状的双链 $\mathrm{DNA}$，没有任何蛋白质的结合和吸附。人 $\mathrm{mtDNA}$ 位于线粒体基质，全长 $16569\,\mathrm{bp}$，闭合双链环状，含编码区和非编码区。
:::

:::definition{label="mtDNA 编码什么"}
编码 $2$ 种 $\mathrm{rRNA}$（$12\mathrm{S}$ 和 $16\mathrm{S}$）、$22$ 种 $\mathrm{tRNA}$ 和 $13$ 种多肽（每种约 $50$ 个氨基酸残基）。有自己的遗传密码子；结构基因主要编码线粒体内膜呼吸链组分，参与氧化磷酸化；呈母系遗传。
:::

|------|------------------|-----------------|
| 部位 | 细胞核 | 线粒体基质 |
| 形状 | 线性；组装成染色质/染色体 | 闭合双链环状 |
| 是否结合蛋白质 | 组蛋白等，逐级折叠 | 裸露，无蛋白质结合和吸附 |
| 人的大小 | 约 $3\times 10^{9}\,\mathrm{bp}$ | $16569\,\mathrm{bp}$ |
| 遗传方式 | 双亲核基因 | 母系遗传 |
| 编码 | 绝大部分细胞蛋白质 | $2$ 种 $\mathrm{rRNA}$、$22$ 种 $\mathrm{tRNA}$、$13$ 种多肽（呼吸链组分） |
| 密码子 | 核密码 | 自己的遗传密码子 |
:::

:::pitfall{label="mtDNA 是环状裸露双链，不要把它写成核小体"}
与核 $\mathrm{DNA}$ 不同：没有任何蛋白质结合和吸附。环状这一点更接近原核类核里的封闭环状 $\mathrm{DNA}$，但教材没有把 $\mathrm{mtDNA}$ 写成类核。母系遗传和“自己的遗传密码子”是独立两笔，不要并成“因为在线粒体所以密码子不同就算母系”。
:::

### （四）DNA 是主要的遗传物质

早在 $20$ 世纪 $30$ 年代，人们就已经知道了染色体是遗传物质，也知道了 $\mathrm{DNA}$ 是染色体的组成部分。但是直到 $1944$ 年，美国细菌学家 Avery O. 才首次证明了 $\mathrm{DNA}$ 是细菌性状的遗传物质。他们从有荚膜的致病的Ⅲ型肺炎球菌中提取出 $\mathrm{DNA}$，它可以使另一种无荚膜的非致病性的Ⅱ型肺炎球菌细胞转变成了致病菌，而蛋白质和多糖物质没有这种功能。如果 $\mathrm{DNA}$ 被脱氧核糖核酸酶降解后，则失去转化功能。但是已经转化了的细菌，其后代仍保留了合成Ⅲ型荚膜的能力。这些实验结果证明了 $\mathrm{DNA}$ 是携带生物体遗传信息的物质基础。$1952$ 年，Hershey A. 和 Chase M. 用大肠埃希菌噬菌体的 $\mathrm{DNA}$ 进行的性状表达实验，进一步确认了 $\mathrm{DNA}$ 是遗传信息的载体。

生物体的遗传信息是以基因的形式存在的。基因（gene）是一段含有特定遗传信息的核苷酸序列（大多数生物中是 $\mathrm{DNA}$ 序列，少数是 $\mathrm{RNA}$ 序列），能够编码蛋白质或 $\mathrm{RNA}$ 等具有特定功能产物、负载遗传信息的基本单位。$\mathrm{DNA}$ 的核苷酸序列以遗传密码的方式决定了蛋白质的氨基酸排列顺序。依据这一原理，$\mathrm{DNA}$ 利用四种碱基的不同排列编码了生物体的遗传信息，并通过复制的方式遗传给子代。此外，$\mathrm{DNA}$ 还利用转录过程，合成出各种 $\mathrm{RNA}$。后者将参与蛋白质的合成，确保细胞内的生命活动的有序进行和遗传信息的世代相传。

一个生物体的基因组（genome）是指生物体或细胞中一套完整单体具有的遗传信息的总和。各种生物体基因组的大小、所包含的基因数量和种类都有所不同。一般来讲，进化程度越高的生物体，其基因组越大越复杂。简单生物的基因组仅含有几千个碱基对，而高等动物的基因组可高达 $10^{9}$ 碱基对，使可编码的信息量大大增加。病毒颗粒的基因组可以由 $\mathrm{DNA}$ 组成，也可以由 $\mathrm{RNA}$ 组成，两者一般不共存。病毒基因组的 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 可以是单链的，也可以是双链的，可以是环形分子，也可以是线性分子。

$\mathrm{DNA}$ 是生物体遗传信息的载体，并为基因复制和转录提供了模板。它是生命遗传的物质基础，也是个体生命活动的信息基础。$\mathrm{DNA}$ 具有高度稳定性的特点，用来保持生物体系遗传特征的相对稳定性。同时，$\mathrm{DNA}$ 又表现出高度复杂性的特点，它可以发生各种重组和突变，适应环境的变迁，为自然选择提供机会，使大自然表现出丰富的生物多样性。

:::definition{label="基因"}
基因（gene）是一段含有特定遗传信息的核苷酸序列（大多数生物中是 $\mathrm{DNA}$ 序列，少数是 $\mathrm{RNA}$ 序列），能够编码蛋白质或 $\mathrm{RNA}$ 等具有特定功能产物、负载遗传信息的基本单位。
:::

:::definition{label="基因组"}
一个生物体的基因组（genome）是指生物体或细胞中一套完整单体具有的遗传信息的总和。进化程度越高，基因组一般越大越复杂：简单生物仅几千碱基对，高等动物可高达 $10^{9}$ 碱基对。
:::

:::definition{label="病毒基因组的多样性"}
病毒颗粒的基因组可以由 $\mathrm{DNA}$ 组成，也可以由 $\mathrm{RNA}$ 组成，两者一般不共存。可以是单链或双链，可以是环形或线性。
:::

:::timeline{period="证明 DNA 是遗传物质"}
- **20 世纪 30 年代** 已知染色体是遗传物质，也知 DNA 是染色体的组成部分，但尚未证明 DNA 就是遗传物质
- **1944** Avery 用Ⅲ型有荚膜致病肺炎球菌的 DNA 转化Ⅱ型无荚膜非致病菌；蛋白质和多糖无此功能；DNA 被脱氧核糖核酸酶降解后转化功能消失；转化菌后代仍能合成Ⅲ型荚膜
- **1952** Hershey 与 Chase 用大肠埃希菌噬菌体 DNA 的性状表达实验，进一步确认 DNA 是遗传信息的载体
:::

:::example{label="Avery 转化实验三句话"}
- 有效成分是 $\mathrm{DNA}$，不是蛋白质，也不是多糖。
- $\mathrm{DNA}$ 被脱氧核糖核酸酶降解后，转化功能消失。
- 已经转化的细菌，后代仍保留合成Ⅲ型荚膜的能力——信息可以传代。
:::

:::compare{title="DNA 作为遗传物质的两本账"}
| 项目 | 稳定性 | 复杂性 |
|------|--------|--------|
| 表现 | 保持生物体系遗传特征的相对稳定 | 可发生重组和突变 |
| 用途 | 复制把信息传给子代；转录合成各种 $\mathrm{RNA}$ | 适应环境变迁，为自然选择提供机会，形成生物多样性 |
| 编码方式 | 四种碱基的不同排列；核苷酸序列以遗传密码决定蛋白质氨基酸顺序 | 排列可变，因而信息可变 |
:::

:::cause-effect{title="四种碱基排列如何既决定蛋白质又传给子代"}
- **因** $\mathrm{DNA}$ 核苷酸序列以遗传密码方式决定蛋白质氨基酸排列；双螺旋又为复制和转录提供模板
- **果** 遗传信息可编码功能产物，并经复制遗传给子代；转录出的 $\mathrm{RNA}$ 参与蛋白质合成，保证生命活动有序进行和信息世代相传
:::

:::pitfall{label="基因大多是 DNA 序列，少数是 RNA 序列；病毒可以只有 RNA 基因组"}
教材写“大多数生物中是 $\mathrm{DNA}$ 序列，少数是 $\mathrm{RNA}$ 序列”。病毒基因组 $\mathrm{DNA}$ 与 $\mathrm{RNA}$ 一般不共存，但可以是单链或双链、环或线。把“遗传物质等于双链 $\mathrm{DNA}$”写成绝对句，第一节“$\mathrm{RNA}$ 也可以作为遗传信息的载体”会对空。
:::

:::keypoint{label="本节结构与功能收口"}
- 二级结构：反向平行右手双螺旋；$\mathrm{B}$ 型是生理最稳；$\mathrm{A}$、$\mathrm{Z}$ 为多样性；三链与 $\mathrm{G}$-四链是特殊序列。
- 稳定力：碱基对氢键 $+$ 碱基堆积力。
- 高级结构：体内主负超螺旋；原核环状 $\mathrm{DNA}$ 成类核；真核核小体 → $10\,\mathrm{nm}$ 纤维 → $30\,\mathrm{nm}$ 螺线管 → 超螺线管 → 染色体，总压缩 $8000\sim 10000$ 倍。
- 功能：$\mathrm{DNA}$ 是主要遗传物质，基因的载体，复制与转录的模板；稳定与可变并存。
:::

:::memory{label="本节必背要点"}
- [ ] $\mathrm{DNA}$ 空间结构分二级结构与高级结构。
- [ ] Chargaff 规则（$1950$）：种间不同；同一个体各组织相同；不随年龄营养环境变；$\mathrm{A}=\mathrm{T}$，$\mathrm{G}=\mathrm{C}$。
- [ ] $1951$ 年 $11$ 月 Franklin 高质量 $\mathrm{X}$ 线衍射，推论螺旋状；$1953$ 年 $4$ 月 $25$ 日 Watson-Crick 模型发表于 Nature。
- [ ] 双螺旋：两条链、右手、反向平行；直径 $2.37\,\mathrm{nm}$，螺距 $3.54\,\mathrm{nm}$。
- [ ] $\mathrm{A}$-$\mathrm{T}$ 两对氢键，$\mathrm{G}$-$\mathrm{C}$ 三对氢键；碱基对平面近乎垂直于轴。
- [ ] 每螺旋 $10.5$ 个碱基对，间距 $0.34\,\mathrm{nm}$。
- [ ] 亲水骨架在外，疏水碱基对在内；反向平行造成大沟和小沟。
- [ ] 稳定力：碱基对氢键 $+$ 疏水性碱基堆积力。
- [ ] $\mathrm{B}$ 型：水性环境和生理条件下最稳定，$92\%$ 相对湿度。
- [ ] $\mathrm{A}$ 型：湿度降低仍为右手，直径 $2.55\,\mathrm{nm}$，$11\,\mathrm{bp}$/圈，螺距 $2.53\,\mathrm{nm}$，间距 $0.23\,\mathrm{nm}$，湿度 $75\%$，夹角 $19^{\circ}$，大沟窄深、小沟宽浅。
- [ ] $\mathrm{Z}$ 型：左手；$1979$ 年 Rich 等由 $\mathrm{CGCGCG}$ 晶体发现；直径 $1.84\,\mathrm{nm}$，$12\,\mathrm{bp}$/圈，螺距 $4.56\,\mathrm{nm}$，间距 $0.38\,\mathrm{nm}$；嘧啶反式、嘌呤顺式交替；大沟平坦、小沟窄深。
- [ ] 体内不同双螺旋与基因表达的调节控制相适应。
- [ ] Hoogsteen 氢键（$1959$）不破坏 Watson-Crick 氢键；可形成 $\mathrm{C}^{+}:\mathrm{G}:\mathrm{C}$ 与 $\mathrm{T}:\mathrm{A}:\mathrm{T}$ 三碱基平面。
- [ ] 酸性条件下富嘧啶第三链走大沟，形成 triplex，可干扰调控因子。
- [ ] 人端粒 $(\mathrm{TTAGGG})_{n}$；$\mathrm{G}$-四链由 $4$ 个 $\mathrm{G}$、$8$ 对 Hoogsteen 氢键形成 tetrad。
- [ ] 正超螺旋与双螺旋同向，负超螺旋反向；体内主要是负超螺旋；拓扑异构酶参与。
- [ ] 原核 $\mathrm{DNA}$ 多为环状，盘绕成类核；大肠埃希菌平均每 $200$ 碱基一个负超螺旋；利于局部解链、复制和转录。
- [ ] 人类基因组约 $3\times 10^{9}\,\mathrm{bp}$，长约 $1.7\,\mathrm{m}$；平时为染色质，分裂期为染色体。
- [ ] 核小体：$\mathrm{H2A}/\mathrm{H2B}/\mathrm{H3}/\mathrm{H4}$ 各二成八聚体；$146\,\mathrm{bp}$ 盘绕 $1.75$ 圈；核心颗粒约 $11\,\mathrm{nm}\times 6\,\mathrm{nm}$；linker $0\sim 50\,\mathrm{bp}$；$\mathrm{H1}$ 在进出口。
- [ ] 第一次折叠：$10\,\mathrm{nm}$ 串珠，压缩约 $7$ 倍。
- [ ] 第二次折叠：$30\,\mathrm{nm}$ 螺线管（外径 $30\,\mathrm{nm}$、内径 $10\,\mathrm{nm}$，每圈 $6$ 个核小体），压缩 $40\sim 60$ 倍；转录区无序、$\mathrm{H1}$ 少。
- [ ] 多级螺线化：$400\,\mathrm{nm}$ 超螺线管再 $\times 40$，染色体再 $\times 5\sim 6$，总共 $8000\sim 10000$ 倍。
- [ ] 端粒：$\mathrm{TTAGGG}$，$\mathrm{G}$-四链体；维持染色体稳定与复制完整性，关乎衰老和肿瘤。着丝粒富 $\mathrm{AT}$，分裂时分开。
- [ ] 人 $\mathrm{mtDNA}$：$16569\,\mathrm{bp}$，裸露闭合双链环状；编码 $2$ 种 $\mathrm{rRNA}$、$22$ 种 $\mathrm{tRNA}$、$13$ 种多肽；自己的遗传密码子；母系遗传；呼吸链组分。
- [ ] $1944$ Avery、$1952$ Hershey-Chase 证明 $\mathrm{DNA}$ 是遗传物质。
- [ ] 基因是负载遗传信息的基本单位；基因组是一套完整单体遗传信息的总和。
- [ ] $\mathrm{DNA}$ 既高度稳定又可通过重组突变提供生物多样性；为复制和转录提供模板。
:::
