# 第一节　疾病相关基因及其鉴定原则

第二十二章把「疾病相关基因是什么、按什么原则鉴定」和「具体用哪些方法鉴定」分成两户。本节只立户头：影响疾病发生发展的基因统称疾病相关基因；按变异作用分成致病基因与疾病易感基因；遗传标记（$\mathrm{CNV}$、$\mathrm{STR}$、$\mathrm{SNP}$、罕见变异）怎样当尺子；鉴定原则是表型—基因实质联系、多途径互补、交汇到候选基因。不依赖染色体定位的策略（功能克隆、表型克隆、动物模型、半克隆小鼠、计算机模拟克隆／$\mathrm{EST}$）写在本节。定位克隆、连锁分析、细胞遗传学、$\mathrm{GWAS}$、$\mathrm{RNA}$-$\mathrm{seq}$、全外显子组／全基因组测序和基因—疾病数据库交给第二节。分子医学、精准医学、转化医学交给第三节，开篇只承认它们在加速，不要提前写完。

:::concept{term="先问这个基因是直接致病还是只增加易感性，再问鉴定走哪几路"}
看见“疾病相关基因”，先不要默写 $\mathrm{GWAS}$ 一张曼哈顿图。户头是：影响疾病发生发展的基因。表型和某个基因型直接对应、该基因异常就是病因，叫致病基因，主要落在单基因病／孟德尔遗传病。复杂疾病里两个以上基因微效相加或基因间互作，单一变异只增加易感性，叫疾病易感基因。早期定位克隆对单基因病；现在 $\mathrm{SNP}$ 的 $\mathrm{GWAS}$、全外显子组测序加关联／连锁，是后文方法账。本节先把标记、原则和「不靠染色体位置也能克隆」的几路立住。
:::

人类几乎所有的疾病都是遗传因素（基因）和环境因素相互作用的结果。要解析疾病发生发展过程中遗传因素的作用及其分子机制，开展精准的诊断、治疗和预防以及个性化医疗，加速基础医学研究成果向临床与预防的转化应用，首先需要鉴定引起疾病发生的疾病相关基因。鉴定疾病相关基因不但可以详尽地了解疾病的病因和发病机制、开发新的诊断和干预技术，而且有利于了解基因的功能，因而一直是生物医学工作者研究的重点。早期，基于连锁分析的定位克隆技术在单基因病致病基因的发现和鉴定中取得了很大成功；现在，基于 $\mathrm{SNP}$ 分析的全基因组关联研究、全外显子组测序加关联／连锁分析在疾病相关基因发现和鉴定中发挥着越来越重要的作用。随着基因和疾病研究数据的快速累计，多个专门收集和整理疾病相关基因信息的数据库应运而生，为研究人员和临床医生深入了解基因与疾病之间的关系、揭示疾病的遗传基础和发病机制提供了方便和高效的资源，为疾病的诊断和治疗提供科学依据。随着人类基因组计划的完成以及各种组学的不断发展，分子医学、精准医学以及转化医学加速发展，人们有望从分子水平突破对疾病的传统认识，彻底改变和革新现有的临床诊疗模式。

:::definition{label="本章开篇三句时代账"}
早期：连锁分析的定位克隆，在单基因病致病基因上取得很大成功。现在：基于 $\mathrm{SNP}$ 的全基因组关联研究、全外显子组测序加关联／连锁分析，作用越来越重要。数据库随数据累计而生。分子医学／精准医学／转化医学只在这里点到「加速发展」，展开是第三节。
:::

:::pitfall{label="不要把现在的方法写成只有 GWAS"}
本版并列的是「基于 $\mathrm{SNP}$ 分析的全基因组关联研究」和「全外显子组测序加关联／连锁分析」。图22-1 还画了家系连锁／关联、细胞遗传学、功能克隆、表型克隆、动物模型同源基因、$\mathrm{EST}$。写成「鉴定疾病基因就是做 $\mathrm{GWAS}$」，定位克隆和全外显子组那两户就空了。
:::

:::insight{label="鉴定基因同时服务病因、干预和基因功能"}
教材把「了解病因和发病机制、开发诊断和干预技术」和「有利于了解基因的功能」写在同一句。克隆到一个疾病基因，不只是给临床一张诊断清单，也是给基因功能研究一个入口。
:::

人们将影响疾病发生发展的基因统称为疾病相关基因（disease related gene）。依据基因变异在疾病发生、发展中的作用，可将疾病相关基因区分为致病基因和疾病易感基因。如果一种疾病的表型和某个基因型呈直接对应的因果关系，即该基因异常是导致该疾病发生的直接原因，那么该基因就属于致病基因（causative gene）。这类疾病主要是单基因病，即传统的遗传病，也称为孟德尔遗传病。

:::definition{label="疾病相关基因"}
疾病相关基因（disease related gene）：影响疾病发生发展的基因。户头落在「影响发生发展」，还没有分成「直接致病」还是「只增加易感性」。
:::

:::definition{label="致病基因"}
致病基因（causative gene）：疾病表型和某个基因型呈直接对应的因果关系，该基因异常是导致该疾病发生的直接原因。这类疾病主要是单基因病，即传统的遗传病，也称为孟德尔遗传病。
:::

人类疾病的发生发展既受疾病相关基因的影响，也受环境因素的影响。基因与疾病的关系，并非总是一个基因导致一种疾病这样简单的一一对应关系。在肿瘤、心血管疾病、代谢性疾病、自身免疫性疾病等复杂疾病中遗传因素和环境因素均起一定作用，表现为 $2$ 个以上基因的「微效作用」相加，或多个基因间的相互作用，故此类疾病也称为多基因病。单一基因变异仅增加对疾病的易感性，故此类基因被称为疾病易感基因（disease susceptibility genes）。对疾病要开展精准诊断、治疗和预防，实现个体化精准医疗，首先就要鉴定疾病发生相关的基因，明确其与疾病间的确切关系。鉴定疾病发生相关基因需遵循一定的原则。

:::definition{label="疾病易感基因"}
疾病易感基因（disease susceptibility genes）：单一基因变异仅增加对疾病的易感性。落在复杂疾病／多基因病：肿瘤、心血管疾病、代谢性疾病、自身免疫性疾病等；遗传与环境都起作用；$2$ 个以上基因微效相加，或基因间相互作用。
:::

:::compare{title="致病基因 vs 疾病易感基因"}
| | 本版原句 | 疾病类型 | 基因—疾病关系 |
|--|---------|---------|--------------|
| 致病基因 | 表型与基因型直接对应，该基因异常是直接原因 | 单基因病／孟德尔遗传病 | 一对一的因果关系 |
| 疾病易感基因 | 单一变异仅增加易感性 | 复杂疾病／多基因病 | 微效相加或基因间互作，还叠加环境 |

问「什么叫疾病相关基因」先答总称；问「镰状细胞贫血那种」走致病基因；问「冠心病、糖尿病那种」走易感基因。不要把两户并成「都是致病基因」。
:::

:::pitfall{label="复杂疾病不要写成没有遗传因素"}
教材写「遗传因素和环境因素均起一定作用」，不是「环境病就没有基因」。微效、互作、易感性都还在遗传这一侧。写成「多基因病等于环境病」，后文 $\mathrm{GWAS}$ 鉴定易感基因就没有对象。
:::

:::keypoint{label="开篇先立三户"}
- 疾病相关基因：影响发生发展的基因总称。
- 致病基因：表型—基因型直接对应，主要是单基因病。
- 易感基因：只增加易感性，复杂疾病里微效或多基因互作。
- 早期定位克隆对单基因病；现在 $\mathrm{GWAS}$ 与全外显子组测序加关联／连锁并重。
:::

## 一、遗传标记在疾病相关基因鉴定中发挥重要作用

大的 $\mathrm{DNA}$ 变异会产生显著的遗传学效应，导致突变个体的表型发生严重改变甚至使突变个体死亡。这些大的 $\mathrm{DNA}$ 变异包括染色体数目的变异（如染色体组成倍地增加或减少、单条染色体的增加或减少），以及染色体结构的变异（如染色体片段的重复、缺失、倒位和易位等）。而更小的 $\mathrm{DNA}$ 变异（包括拷贝数目变异、短串联重复序列和单核苷酸多态性等）则可用作遗传标记（genetic marker），在疾病相关基因的发现和鉴定中发挥重要作用。

:::definition{label="大的 DNA 变异"}
染色体数目变异（组成倍增加或减少、单条染色体增加或减少）和染色体结构变异（片段的重复、缺失、倒位和易位等）。效应显著，可严重改变表型甚至使突变个体死亡。这一户是「看得见的大改动」，还不是遗传标记。
:::

:::definition{label="遗传标记"}
遗传标记（genetic marker）：更小的 $\mathrm{DNA}$ 变异，本版点名拷贝数目变异、短串联重复序列和单核苷酸多态性等。用来在疾病相关基因的发现和鉴定中当尺子，不是疾病本身的必致病因。
:::

:::compare{title="大变异 vs 用作标记的小变异"}
| | 本版名单 | 遗传学效应 | 在鉴定里干什么 |
|--|---------|-----------|---------------|
| 大的 $\mathrm{DNA}$ 变异 | 数目（整倍或单条增减）；结构（重复、缺失、倒位、易位） | 表型严重改变甚至死亡 | 本身就可以是致病改变；第二节染色体异常还可当定位线索 |
| 较小变异 | $\mathrm{CNV}$、$\mathrm{STR}$、$\mathrm{SNP}$ 等 | 不一定致病 | 当作遗传标记，用来发现和鉴定疾病相关基因 |

大变异问「核型看见了什么」；小变异问「用什么当路标去找基因」。
:::

:::pitfall{label="遗传标记不是「都是中性的」"}
标记这一户强调「更小、可用来定位」。后文 $\mathrm{CNV}$ 与疾病的相关性被陆续报道，罕见变异还是单基因病的原因。不要把「用作标记」写成「一定不致病」。
:::

拷贝数目变异（copy number variation，$\mathrm{CNV}$）是一种大小介于 $1\,\mathrm{KB}$ 至 $3\,\mathrm{MB}$ 的 $\mathrm{DNA}$ 片段的变异，在人类基因组中广泛分布，其覆盖的核苷酸总数大大超过单核苷酸多态性，极大地丰富了基因组遗传变异的多样性。$\mathrm{CNV}$ 对于物种特异的基因组构成、物种的演化和系统发育及基因组某些特定区域基因的表达和调控具有非常重要的生物学意义。存在于自然群体中 $\mathrm{DNA}$ 片段的 $\mathrm{CNV}$ 是基因组结构性差异的常见形式，人们建立多种实验方法对其进行检测和量化，随着实验技术的进步，人群 $\mathrm{CNV}$ 图谱被不断完善、细化；许多 $\mathrm{CNV}$s 和疾病的相关性被陆续报道，对复杂疾病的 $\mathrm{CNV}$ 关联研究已成为当前医学遗传学研究的重要内容。

:::definition{label="拷贝数目变异"}
拷贝数目变异（copy number variation，$\mathrm{CNV}$）：大小介于 $1\,\mathrm{KB}$ 至 $3\,\mathrm{MB}$ 的 $\mathrm{DNA}$ 片段变异。本版数字就是 $1\,\mathrm{KB}$～$3\,\mathrm{MB}$，不要改成口诀里的别的区间。广泛分布；覆盖的核苷酸总数大大超过 $\mathrm{SNP}$。
:::

:::definition{label="CNV 的生物学意义"}
对物种特异的基因组构成、物种演化与系统发育、以及基因组某些特定区域基因的表达和调控都有重要意义。自然群体中的 $\mathrm{CNV}$ 是结构性差异的常见形式。
:::

:::insight{label="覆盖核苷酸总数超过 SNP，不等于标记密度超过 SNP"}
教材比较的是「覆盖的核苷酸总数」，因为每一段 $\mathrm{CNV}$ 可以跨很多碱基。$\mathrm{SNP}$ 后文写平均每 $300\,\mathrm{bp}$ 一个、约占人类基因组多态性的 $90\%$，那是位点密度和多态性形式的账。两句不要并成「$\mathrm{CNV}$ 比 $\mathrm{SNP}$ 更常用」。
:::

:::pitfall{label="CNV 关联研究是复杂疾病的重要内容，不是可选项"}
「许多 $\mathrm{CNV}$s 和疾病的相关性被陆续报道，对复杂疾病的 $\mathrm{CNV}$ 关联研究已成为当前医学遗传学研究的重要内容。」只背 $\mathrm{SNP}$ 的 $\mathrm{GWAS}$，把 $\mathrm{CNV}$ 从标记名单里删掉，这一段就没有着落。
:::

短串联重复序列（short tandem repeat，$\mathrm{STR}$）又称为微卫星 $\mathrm{DNA}$，主要是指染色体上重复单位仅 $2\sim 6\,\mathrm{bp}$、重复次数为 $10\sim 60$ 多次、基因片段在 $400\,\mathrm{bp}$ 以下的重复序列。$\mathrm{STR}$ 主要是在 $\mathrm{DNA}$ 复制（或修复）过程中滑动链与互补链碱基错配，导致一个或几个重复单位的缺失或插入而产生的，重复的次数可以出现个体差异，形成片段长度等位基因。

:::definition{label="短串联重复序列"}
短串联重复序列（short tandem repeat，$\mathrm{STR}$）又称微卫星 $\mathrm{DNA}$。重复单位仅 $2\sim 6\,\mathrm{bp}$，重复次数 $10\sim 60$ 多次，基因片段在 $400\,\mathrm{bp}$ 以下。本版三个数字要一起答。
:::

:::definition{label="STR 怎样形成片段长度等位基因"}
复制或修复时滑动链与互补链碱基错配，造成一个或几个重复单位的缺失或插入。重复次数的个体差异，形成片段长度等位基因。户头是「拷贝数变了，片段长短不同」，不是单碱基换了身份。
:::

:::compare{title="CNV vs STR"}
| | 尺度 | 变的是什么 | 本版用途 |
|--|------|-----------|---------|
| $\mathrm{CNV}$ | $1\,\mathrm{KB}$～$3\,\mathrm{MB}$ 片段 | 较大片段的拷贝数 | 结构性差异；复杂疾病的 $\mathrm{CNV}$ 关联 |
| $\mathrm{STR}$ | 单位 $2\sim 6\,\mathrm{bp}$，总片段 $<400\,\mathrm{bp}$ | 短重复的次数 | 片段长度等位基因，当遗传标记 |

都和「拷贝数」有关，$\mathrm{CNV}$ 是大片段，$\mathrm{STR}$ 是短串联。不要把微卫星答成 $1\,\mathrm{KB}$ 以上的缺失。
:::

单核苷酸多态性（single nucleotide polymorphism，$\mathrm{SNP}$）是指在基因组中因单个核苷酸改变（颠换／置换）而引起的多态性，人口中的分布频率在 $1\%$ 以上；$\mathrm{SNP}$ 在基因组中广泛分布，平均每 $300\,\mathrm{bp}$ 就出现 $1$ 个，人类基因组大约 $90\%$ 的多态性是以 $\mathrm{SNP}$s 形式出现，因此它被认为是第三代遗传标志。由于 $\mathrm{SNP}$s 密度高，通过对 $\mathrm{SNP}$s 的关联分析使得在全基因组范围精确定位疾病相关基因成为可能。

:::definition{label="单核苷酸多态性"}
单核苷酸多态性（single nucleotide polymorphism，$\mathrm{SNP}$）：基因组中因单个核苷酸改变（颠换／置换）引起的多态性，人口中分布频率在 $1\%$ 以上。广泛分布，平均每 $300\,\mathrm{bp}$ 出现 $1$ 个；人类基因组大约 $90\%$ 的多态性以 $\mathrm{SNP}$s 形式出现，第三代遗传标志。
:::

:::definition{label="SNP 密度使全基因组定位成为可能"}
$\mathrm{SNP}$s 密度高，通过对 $\mathrm{SNP}$s 的关联分析，可在全基因组范围精确定位疾病相关基因。这是后文 $\mathrm{GWAS}$ 的前置句，不是已经把 $\mathrm{GWAS}$ 写完。
:::

:::keypoint{label="SNP 四个数字和一句话身份"}
- 频率：$1\%$ 以上。
- 密度：平均每 $300\,\mathrm{bp}$ 一个。
- 占比：约占人类基因组多态性的 $90\%$。
- 身份：第三代遗传标志。
- 用途：关联分析 → 全基因组精确定位疾病相关基因。
:::

:::pitfall{label="SNP 的 1% 门槛不要和罕见变异并户"}
$\mathrm{SNP}$ 写的是人口中分布频率 $1\%$ 以上。罕见变异后文写频率在 $1/1\,000$ 以下。一个当常见多态标记，一个常是单基因病的原因。把所有单碱基改变都叫 $\mathrm{SNP}$，两户的频率账就乱了。
:::

罕见变异（rare variant）通常是指频率在 $1/1\,000$ 以下，新发或者存在于人口中某些特定族群的变异，这些变异是单基因疾病的原因。可以通过家系连锁分析或外显子测序等发现。

:::definition{label="罕见变异"}
罕见变异（rare variant）：频率通常在 $1/1\,000$ 以下，新发或者存在于某些特定族群。是单基因疾病的原因。发现途径：家系连锁分析或外显子测序等。
:::

:::compare{title="SNP vs 罕见变异"}
| | 频率 | 常见角色 | 本版点名的发现途径 |
|--|------|---------|------------------|
| $\mathrm{SNP}$ | $1\%$ 以上 | 第三代标记；关联分析定位 | 全基因组关联（第二节 $\mathrm{GWAS}$） |
| 罕见变异 | $1/1\,000$ 以下 | 单基因疾病的原因 | 家系连锁分析或外显子测序 |

问「常见多态当尺子」看 $\mathrm{SNP}$；问「某个家族单基因病的新发突变」看罕见变异。
:::

基因和基因组异常可导致截然不同的表型和生物学效应。有一些异常不影响或基本不影响蛋白质活性，不表现明显的性状变化，与遗传病无直接联系，称为中性突变（neutral mutation）。有些异常的发生则可严重影响蛋白质活性，从而直接影响生命的维系，这种突变称为致死突变（lethal mutation）。

:::definition{label="中性突变"}
中性突变（neutral mutation）：不影响或基本不影响蛋白质活性，不表现明显的性状变化，与遗传病无直接联系。
:::

:::definition{label="致死突变"}
致死突变（lethal mutation）：严重影响蛋白质活性，从而直接影响生命的维系。
:::

:::compare{title="中性突变 vs 致死突变"}
| | 对蛋白质活性 | 性状 | 与遗传病 |
|--|------------|------|---------|
| 中性突变 | 不影响或基本不影响 | 无明显变化 | 无直接联系 |
| 致死突变 | 严重影响 | 可危及生命维系 | 效应走到极端 |

两户都是「基因和基因组异常」的表型谱两端。中间还有致病基因、易感基因，不要把异常只分成中性和致死。
:::

:::keypoint{label="遗传标记这一节的尺子"}
- 大变异：数目和结构，效应显著甚至致死。
- 标记：$\mathrm{CNV}$（$1\,\mathrm{KB}$～$3\,\mathrm{MB}$）、$\mathrm{STR}$（$2\sim 6\,\mathrm{bp}$ 单位，$10\sim 60$ 多次，$<400\,\mathrm{bp}$）、$\mathrm{SNP}$（$>1\%$，每 $300\,\mathrm{bp}$，约占多态性 $90\%$，第三代）。
- 罕见变异：$<1/1\,000$，单基因病原因，连锁或外显子测序。
- 效应两端：中性突变／致死突变。
:::

## 二、疾病相关基因鉴定应遵循一定的原则

确定疾病相关基因是一个艰巨复杂的系统工程，耗时耗钱，有的疾病基因的最终鉴定历时数十年。尽管人类基因组计划的完成，为疾病相关基因的鉴定提供了诸多的便利，但明确地解析疾病和某种基因的关系仍非易事，掌握疾病相关基因鉴定的原则，无疑将起到事半功倍作用，有助于鉴定疾病相关基因研究工作高效有序开展。首先，确定疾病表型和基因实质联系是关键；其次，采用多途径、多种方法鉴定疾病相关基因是手段；最终，确定候选基因，明晰基因序列的改变和疾病表型的关系，以了解基因致病的本质，是鉴定和确定疾病相关基因的核心。

:::definition{label="鉴定原则的三句话"}
①关键：确定疾病表型和基因间的实质联系。②手段：多途径、多种方法。③核心：确定候选基因，明晰序列改变和表型的关系，了解致病本质。三句按「关键—手段—核心」排，不要只背手段里的某一种技术。
:::

:::insight{label="人类基因组计划提供便利，不等于关系已经解析完"}
「提供了诸多的便利，但明确地解析疾病和某种基因的关系仍非易事。」有的鉴定历时数十年。写成「基因组计划一完成基因就找齐了」，后文「从 $2$ 万个降到 $10\sim 30$ 个还要逐个排除」就没有对象。
:::

### （一）鉴定疾病相关基因的关键是确定疾病表型和基因间的实质联系

疾病作为一种遗传性状，要确保其专一性和同质性。正确的疾病诊断非常重要。在一些复杂性疾病中，对疾病表型有必要进行进一步的分类，确保疾病的同质性，以减少临床的异质性。其次，需要确定疾病的遗传因素，即通过家系分析、孪生子分析、领养分析和同胞罹患率分析等，确定遗传因素是否在疾病发病中的作用及其作用程度（遗传度）。在遗传因素作用较小的疾病中，鉴定并最终克隆疾病相关基因成功的可能性很小。一旦确定了遗传因素在疾病中的重要作用，就可进而确定存在于人类基因组中决定疾病表型的基因，确定该基因在基因组中的位置（位点）以及该位点和基因组其他位点的联系。

:::definition{label="表型要专一、同质"}
疾病作为遗传性状，要确保专一性和同质性。正确诊断非常重要。复杂疾病要对表型进一步分类，减少临床异质性。户头是「先把病认准、认成同一类」，再谈找基因。
:::

:::definition{label="先确定遗传因素及其遗传度"}
途径：家系分析、孪生子分析、领养分析、同胞罹患率分析等。要回答两问：遗传因素是否起作用，以及作用程度（遗传度）。遗传因素作用较小的疾病，克隆成功的可能性很小。
:::

:::cause-effect{title="遗传因素大小怎样决定要不要往下克隆"}
- **因** 遗传因素作用较小
- **果** 鉴定并最终克隆疾病相关基因成功的可能性很小
- **因** 确定了遗传因素的重要作用
- **果** 进而确定决定表型的基因、它在基因组中的位置（位点），以及该位点与其他位点的联系
:::

:::pitfall{label="不要跳过遗传度直接上测序"}
教材把家系／孪生子／领养／同胞罹患率写在「确定位点」之前。遗传贡献很小，后面连锁、$\mathrm{GWAS}$、全外显子组都缺少前提。写成「有病人就测序」，关键那一句「实质联系」就空了。
:::

:::keypoint{label="实质联系这一小节的顺序"}
- 诊断准、表型同质（复杂疾病要再分类）。
- 用家系、孪生子、领养、同胞罹患率看遗传因素和遗传度。
- 遗传贡献足够大，才去找基因、定位点、看位点之间的联系。
:::

### （二）鉴定疾病相关基因需要多学科多途径的综合策略

鉴定疾病相关基因是一项艰巨的系统工程，需要多学科的紧密配合，针对不同疾病采用不同的策略。如图22-1 所示，这些不同策略和方法互为补充，方可达到最终确定疾病基因的目的。首先通过对不同疾病家系的连锁分析，可粗略地将疾病的基因定位于某个染色体上，这些位点被称为疾病的位点（locus），位点内存在数个到数十个基因，需要通过测序发现突变基因。随着对某些疾病发病机制的了解，可进一步阐明疾病相关的蛋白质的生物化学和细胞生物学特征，以此为切入点，寻找基因结构的异常，确定基因 $\mathrm{DNA}$ 碱基序列突变及其导致蛋白质结构或表达异常的分子机制，最终确定引发疾病的相关基因。疾病动物模型对于疾病相关基因的鉴定具有重要帮助。对不同的疾病动物模型的研究，可以确定导致实验动物异常表型的基因，进而鉴定人类的同源基因在疾病中的作用。借助生物信息数据库中有关待定基因的信息，也可极大地促进疾病相关基因鉴定的效率。

:::definition{label="多途径互为补充"}
针对不同疾病采用不同策略，如图22-1，方法和策略互为补充，才能最终确定疾病基因。不是只选 $\mathrm{GWAS}$ 一条路。
:::

:::definition{label="疾病位点"}
通过家系连锁分析，可粗略地把疾病基因定位于某个染色体上，这些位点称为疾病的位点（locus）。位点内存在数个到数十个基因，需要通过测序发现突变基因。户头是「一段染色体区域」，还不是已经钉死哪一个转录本。
:::

:::definition{label="从蛋白质特征切入"}
阐明疾病相关蛋白质的生物化学和细胞生物学特征，以此寻找基因结构异常，确定 $\mathrm{DNA}$ 碱基序列突变及其导致蛋白质结构或表达异常的分子机制。这是后文功能克隆的前置。
:::

:::definition{label="动物模型与数据库在策略里的位置"}
动物模型：先确定导致实验动物异常表型的基因，再鉴定人类同源基因的作用。数据库：待定基因的信息可极大提高鉴定效率。两路都画在图22-1 左侧。
:::

::figure{src="/images/biochemistry/textbook/p0448_01.png" caption="图22-1　疾病相关基因鉴定策略示意图" alt="上方三路入口：数据库、动物模型、病例家系（表型与 DNA 样本获取）。数据库向下为 EST 序列；动物模型向下为同源基因。病例家系分出功能克隆、表型克隆、家系连锁或关联分析、细胞遗传学分析、全基因组关联分析、全外显子组或全基因组测序。同源基因与表型克隆之间以比较基因组学相连。连锁或关联与细胞遗传学先到确定候选染色体区域，再与各路汇合到确定候选基因；随后突变筛查与鉴定，分基因突变功能分析与结构分析，最终确定致病基因"}

:::insight{label="图22-1 先认三路入口，再认是否经过候选染色体区域"}
画面上方是数据库、动物模型、病例家系。$\mathrm{EST}$、功能克隆、同源基因、表型克隆可以不经过「候选染色体区域」这一格；家系连锁／关联和细胞遗传学先到候选区域再汇到候选基因；$\mathrm{GWAS}$ 和全外显子组／全基因组测序从病例家系较直接通向候选基因。最后共同经过突变筛查与鉴定，功能分析与结构分析并列，才「确定致病基因」。
:::

:::keypoint{label="图22-1 与正文策略对齐"}
- 病例家系：表型、$\mathrm{DNA}$ 样本。
- 连锁／关联、细胞遗传学 $\rightarrow$ 候选染色体区域 $\rightarrow$ 候选基因。
- 功能克隆、表型克隆、动物同源基因、$\mathrm{EST}$：可从功能、表型、同源或序列信息进入。
- $\mathrm{GWAS}$、全外显子组／全基因组测序：图上从家系通向候选基因。
- 交汇点是候选基因；出口是突变筛查后的致病基因。
:::

:::pitfall{label="位点里已经有数个到数十个基因，不是找到染色体就结束"}
「粗略定位于某个染色体上」之后，位点内还有数个到数十个基因，要测序才能发现突变。写成「连锁分析已经鉴定出致病基因」，候选基因交汇那一小节就没有工作可做。
:::

:::compare{title="图22-1 几条路各自先问什么"}
| 入口 | 先得到什么 | 是否必经候选染色体区域 |
|------|-----------|---------------------|
| 家系连锁／关联、细胞遗传学 | 候选染色体区域 | 是 |
| 功能克隆 | 已知蛋白质功能／结构 | 否（可不依赖位置） |
| 表型克隆 | 表型与 $\mathrm{DNA}$／$\mathrm{mRNA}$ 差异 | 否 |
| 动物模型同源基因 | 动物突变基因，再找人的同源 | 比较基因组学相连 |
| 数据库 $\mathrm{EST}$ | 序列与注释 | 否 |
| $\mathrm{GWAS}$、全外显子组／全基因组测序 | 变异与表型关联或编码区变异 | 图上不经过「候选区域」那一格 |

问「策略」必须能指出互为补充；问「哪一条先缩小到染色体区段」看连锁和细胞遗传学。
:::

### （三）确定候选基因是多种鉴定疾病相关基因方法的交汇

有许多途径能够达到最终鉴定疾病相关基因的目的，这些方法最终将交汇在候选基因上。一旦候选基因被鉴定，即可筛检患者中该基因的突变。候选基因可不依赖其在染色体位置而予以鉴定，但常用的策略仍然是首先找出候选染色体区域，然后在此区域内鉴定候选基因。人类基因组计划的完成提供了人类所有基因的信息。尽管从众多的候选基因中寻找基因突变，仍然是一项耗时的工作，但鉴定候选基因较以往还是相对容易。这是由于位置信息从 $2$ 万个的基因降低到候选区域的 $10\sim 30$ 个基因。在候选区域内预测可能的候选基因并非易事，目前仍然缺乏这样的能力。需要的是大量重复、逐个排除，最终确定候选基因的突变以及这种突变和疾病的联系。

:::definition{label="候选基因是交汇点"}
许多途径最终交汇在候选基因上。一旦候选基因被鉴定，即筛检患者中该基因的突变。可以不依赖染色体位置鉴定，但常用策略仍是先找候选染色体区域，再在区域内鉴定。
:::

:::definition{label="从两万到十至三十"}
人类基因组计划提供了所有基因的信息。位置信息从 $2$ 万个基因降低到候选区域的 $10\sim 30$ 个基因，鉴定较以往相对容易，但从中找突变仍然耗时。本版数字是 $2$ 万和 $10\sim 30$，不要改成别的基因组基因数口诀。
:::

:::insight{label="目前仍缺乏在候选区域内『预测出那一个』的能力"}
「预测可能的候选基因并非易事，目前仍然缺乏这样的能力。需要的是大量重复、逐个排除。」基因组计划降低的是搜索空间，不是已经替你指出致病基因。写成「区域内剩下十几个基因就等于找到了」，逐个排除和突变—疾病联系那一户就空了。
:::

:::pitfall{label="不依赖位置可以鉴定，不等于常用策略已经抛弃位置"}
教材先承认可不依赖染色体位置，紧接着说常用策略仍然是先找出候选染色体区域。功能克隆、表型克隆是「可以不靠位置」；定位克隆是「常用仍靠位置」。两句都要留。
:::

:::keypoint{label="原则三句收回来"}
- 关键：表型同质 + 遗传度够，再谈实质联系。
- 手段：图22-1 多路互补，不是只有 $\mathrm{GWAS}$。
- 核心：交汇到候选基因；从 $2$ 万降到 $10\sim 30$ 仍要逐个排除，钉死突变和表型的关系。
:::

## 三、疾病相关基因鉴定的策略

鉴定疾病相关基因的策略和方法主要包括：不依赖染色体定位的疾病相关基因克隆策略、定位克隆、全基因组关联分析、全外显子组测序法等。不依赖染色体定位的疾病相关基因克隆策略主要包括：功能克隆、表型克隆，以及采用位点非依赖的 $\mathrm{DNA}$ 序列信息和动物模型来鉴定和克隆疾病基因。

:::definition{label="策略总名单"}
不依赖染色体定位的克隆、定位克隆、全基因组关联分析、全外显子组测序法。不依赖定位的一支里再分：功能克隆、表型克隆、位点非依赖的 $\mathrm{DNA}$ 序列信息和动物模型。定位克隆、$\mathrm{GWAS}$、全外显子组测序的操作细节是第二节的账；本节把「不靠位置」的几路写完，并把动物模型和 $\mathrm{EST}$ 留在本节，避免拖到第二节开头。
:::

:::compare{title="不依赖定位 vs 依赖定位（本节先立前者）"}
| | 本版包括 | 本节写到哪 | 第二节再写什么 |
|--|---------|-----------|---------------|
| 不依赖染色体定位 | 功能克隆、表型克隆、序列信息、动物模型 | 蛋白质→$\mathrm{DNA}$、表型差异、瘦素同源、半克隆小鼠、计算机模拟克隆／$\mathrm{EST}$ | $\mathrm{RNA}$-$\mathrm{seq}$ 五步流程图 |
| 依赖或不完全依赖位置 | 定位克隆、$\mathrm{GWAS}$、全外显子组测序 | 只在总名单里点名 | 基因定位四法、定位克隆三步、$\mathrm{GWAS}$、$\mathrm{WES}$／$\mathrm{WGS}$ |

问「策略有哪些」四类都要答；问「从已知蛋白质出发」只走功能克隆。
:::

### （一）从已知蛋白质的功能和结构出发克隆疾病基因

在掌握或部分了解基因功能产物蛋白质的基础上，鉴定蛋白质编码基因的方法，称之为功能克隆（functional cloning）。这是相对于利用基因位置克隆基因的定位克隆而言的。该方法采用的是从蛋白质到 $\mathrm{DNA}$ 的研究路线，针对的是一些对影响疾病的功能蛋白具有一定了解的疾病，如血红蛋白病、苯丙酮尿症等出生缺陷引起的分子病可以采用这个方法定位和克隆疾病基因。

:::definition{label="功能克隆"}
功能克隆（functional cloning）：在掌握或部分了解基因功能产物蛋白质的基础上，鉴定蛋白质编码基因。相对于利用基因位置的定位克隆。路线是从蛋白质到 $\mathrm{DNA}$。
:::

:::definition{label="功能克隆针对哪类病"}
对影响疾病的功能蛋白已有一定了解的疾病。本版点名：血红蛋白病、苯丙酮尿症等出生缺陷引起的分子病。
:::

:::pitfall{label="功能克隆不是定位克隆的别名"}
一个从蛋白质到 $\mathrm{DNA}$，一个从染色体位置到基因。写成「功能克隆就是先定位再克隆」，后文「现在已经基本被全外显子组测序取代」会和第二节定位克隆经典方法并户。
:::

**1. 依据蛋白质的氨基酸序列信息鉴定克隆疾病相关基因**　如果疾病相关的蛋白质在体内表达丰富，可分离纯化得到一定纯度的足量蛋白质，就可用质谱或化学方法进行氨基酸序列分析，获得全部或部分氨基酸序列信息。在此基础上设计寡核苷酸探针，用于筛查 $\mathrm{cDNA}$ 文库，可筛选出目的基因。使用这种策略时，必须考虑到密码子的简并性特点，即除了甲硫氨酸和色氨酸仅有 $1$ 个密码子外，其余氨基酸均有 $2$ 个或 $2$ 个以上的密码子。设计探针时应尽量避开有简并密码子的区域，但实际上往往难以做到。为此可以设计 $1$ 套可能含有全部简并密码子信息的寡核苷酸探针，用此混合探针去筛查 $\mathrm{cDNA}$ 文库，「钓出」目的基因克隆。除 $\mathrm{cDNA}$ 文库筛查技术外，目前还可采用部分简并混合寡核苷酸作为 $\mathrm{PCR}$ 引物，采用多种的 $\mathrm{PCR}$ 引物组合，以获得候选基因的 $\mathrm{PCR}$ 产物。

:::definition{label="从氨基酸序列到 cDNA"}
表达丰富 → 纯化足量 → 质谱或化学法测氨基酸序列 → 设计寡核苷酸探针筛查 $\mathrm{cDNA}$ 文库。前提是体内表达丰富、能纯化到一定纯度的足量蛋白质。
:::

:::definition{label="简并性对探针设计的约束"}
除甲硫氨酸和色氨酸仅有 $1$ 个密码子外，其余氨基酸均有 $2$ 个或 $2$ 个以上密码子。应尽量避开简并区域，往往难以做到；可设计一套含全部简并信息的混合探针去「钓」克隆。也可用部分简并混合寡核苷酸作 $\mathrm{PCR}$ 引物，多种引物组合得到候选基因 $\mathrm{PCR}$ 产物。
:::

:::insight{label="混合探针是为了对付简并，不是因为序列测错了"}
「一套可能含有全部简并密码子信息的寡核苷酸探针」承认：同一氨基酸对应多种密码子，探针必须覆盖可能性。不要写成「测出氨基酸就能写出唯一的 $\mathrm{DNA}$ 探针」。
:::

上述方法曾成功地用于镰状细胞贫血的基因克隆。首先，免疫电泳等方法已经显示出镰状细胞贫血患者的珠蛋白异常，获得部分氨基酸残基序列后，设计了简并寡核苷酸探针，筛选有核红细胞系的 $\mathrm{cDNA}$ 文库，得到了 $\alpha$ 珠蛋白基因的 $\mathrm{cDNA}$，与正常人的 $\mathrm{cDNA}$ 比较，发现了 $\alpha$ 珠蛋白基因变异。进而找出 $\mathrm{cDNA}$ 探针与染色体 $\mathrm{DNA}$ 序列间的同源互补关系，将人的 $\alpha$ 珠蛋白基因定位于第 $16$ 号染色体上，并在此基础上，提出了分子病（molecular disease）的概念。

:::definition{label="镰状细胞贫血的功能克隆路径（本版）"}
免疫电泳显示珠蛋白异常 → 部分氨基酸序列 → 简并寡核苷酸探针 → 筛有核红细胞系 $\mathrm{cDNA}$ 文库 → $\alpha$ 珠蛋白基因 $\mathrm{cDNA}$ → 与正常人比较发现变异 → $\mathrm{cDNA}$ 探针与染色体 $\mathrm{DNA}$ 同源互补 → 人 $\alpha$ 珠蛋白基因定位于第 $16$ 号染色体 → 提出分子病概念。数字和基因名称以本版句子为准，不要用其他教材的珠蛋白分户改写这一段。
:::

:::definition{label="分子病"}
分子病（molecular disease）：本版在克隆并定位人 $\alpha$ 珠蛋白基因之后提出。户头是「蛋白质异常落到基因变异」这一认识，不是第三节「分子医学」的同义词。
:::

:::pitfall{label="本版镰状细胞贫血写的是 α 珠蛋白和第 16 号染色体"}
教材原句是「$\alpha$ 珠蛋白基因的 $\mathrm{cDNA}$」「定位于第 $16$ 号染色体」。不要在本节改写成其他染色体或其他珠蛋白基因。第二节原位杂交会另写：$1978$ 年用 $\alpha$ 及 $\beta$ 珠蛋白基因 $\mathrm{cDNA}$ 为探针，将人 $\alpha$ 及 $\beta$ 珠蛋白基因分别定位于第 $16$ 号和第 $11$ 号染色体——那是定位方法的例子，两处各按本版句子记。
:::

**2. 用蛋白质的特异性抗体鉴定疾病基因**　有些疾病相关的蛋白质在体内含量很低，难以纯化得到足够纯度的蛋白质用于氨基酸序列测定。但是少量低纯度的蛋白质仍可用于免疫动物获得特异性抗体，用以鉴定基因。获得的抗体一方面可用于直接结合正在翻译过程中的新生肽链，此时会获得同时结合在核糖体上的 $\mathrm{mRNA}$ 分子，最终克隆未知基因；另外，特异性抗体也可用来筛查可表达的 $\mathrm{cDNA}$ 文库，筛选出可与该抗体反应的表达蛋白质的阳性克隆，进而可获得候选基因。

:::definition{label="抗体路线的两种用法"}
低丰度、难以测序时，少量低纯度蛋白质免疫动物得特异性抗体。①结合正在翻译的新生肽链，带出核糖体上的 $\mathrm{mRNA}$，克隆未知基因。②筛查可表达的 $\mathrm{cDNA}$ 文库，找出与抗体反应的表达蛋白质阳性克隆，获得候选基因。
:::

:::compare{title="氨基酸序列路线 vs 抗体路线"}
| | 蛋白质前提 | 关键试剂 | 钓到什么 |
|--|-----------|---------|---------|
| 序列信息 | 表达丰富，能纯化足量、一定纯度 | 寡核苷酸探针或简并 $\mathrm{PCR}$ 引物 | $\mathrm{cDNA}$ 克隆或 $\mathrm{PCR}$ 产物 |
| 特异性抗体 | 含量低，测序不够，但还能免疫 | 抗体 | 核糖体 $\mathrm{mRNA}$，或表达文库阳性克隆 |

问「珠蛋白那种量够」走序列；问「纯化不到测序纯度」走抗体。
:::

功能克隆早期是单基因疾病基因克隆的常用策略，其缺点是特异功能蛋白质的确认、鉴定及其纯化都相当困难，微量表达的基因产物在研究中难以获得。现在已经基本被全外显子组测序取代了。

:::definition{label="功能克隆的缺点与现状"}
缺点：特异功能蛋白质的确认、鉴定和纯化都相当困难，微量表达产物难以获得。现状：现在已经基本被全外显子组测序取代。取代的是「从蛋白质到 $\mathrm{DNA}$」这一常用地位，不是把功能信息从鉴定策略里删掉。
:::

:::pitfall{label="被全外显子组测序取代，不等于功能克隆从未成功"}
前面刚写了镰状细胞贫血和分子病。『基本被取代』说的是当前策略优先级。写成「功能克隆没用」，血红蛋白病、苯丙酮尿症那一条例子就自相矛盾。
:::

### （二）从疾病的表型差异出发发现疾病相关基因

表型克隆（phenotype cloning）是疾病相关基因克隆领域中一个新的策略。该策略的原理是基于对疾病表型和基因结构或基因表达的特征联系已经有所认识的基础上来分离鉴定疾病相关基因。依据 $\mathrm{DNA}$ 或 $\mathrm{mRNA}$ 的改变与疾病表型的关系，可有三种策略。

:::definition{label="表型克隆"}
表型克隆（phenotype cloning）：在已经认识疾病表型与基因结构或基因表达的特征联系的基础上，分离鉴定疾病相关基因。依据 $\mathrm{DNA}$ 或 $\mathrm{mRNA}$ 改变与表型的关系，本版给出三种策略。
:::

第一种策略是从疾病的表型出发。比较患者基因组 $\mathrm{DNA}$ 与正常人基因组 $\mathrm{DNA}$ 的不同，直接对产生变异的 $\mathrm{DNA}$ 片段进行克隆，而不需要基因的染色体位置或基因产物的其他信息。例如，在一些遗传性神经系统疾病中，患者基因组中含有的三联重复序列的拷贝数可发生改变，并随世代的传递而扩大，称为基因的动态突变。此时，采用基因组错配筛选（genome mismatch scanning）、代表性差异分析（representative difference analysis，$\mathrm{RDA}$）等技术即可检测患者的 $\mathrm{DNA}$ 是否有三联重复序列的拷贝数增加，从而确定患病原因。

:::definition{label="表型克隆第一种：直接比较基因组 DNA"}
比较患者与正常人基因组 $\mathrm{DNA}$，直接克隆变异片段。不需要染色体位置，也不需要基因产物的其他信息。
:::

:::definition{label="动态突变"}
一些遗传性神经系统疾病中，三联重复序列的拷贝数发生改变，并随世代传递而扩大，称为基因的动态突变。检测：基因组错配筛选、代表性差异分析（$\mathrm{RDA}$）等，看三联重复拷贝数是否增加。
:::

:::pitfall{label="动态突变的「扩大」是世代传递中的拷贝数增加"}
户头是三联重复随世代扩大，不是一次 $\mathrm{SNP}$ 置换。写成「动态突变就是点突变」，$\mathrm{RDA}$ 和错配筛选就没有对象。
:::

第二种策略是针对已知基因。如果高度怀疑某种疾病是由于某个特殊的已知基因所致，可通过比较患者和正常对照间该基因表达的差异，来确定该基因是否为该疾病相关基因。常用分析方法有 Northern 印迹法、$\mathrm{RNA}$ 酶保护试验、$\mathrm{RT}$-$\mathrm{PCR}$ 及实时定量 $\mathrm{RT}$-$\mathrm{PCR}$ 等。

:::definition{label="表型克隆第二种：已知基因比表达"}
高度怀疑某个特殊的已知基因时，比较患者与正常对照该基因的表达差异。方法：Northern 印迹、$\mathrm{RNA}$ 酶保护试验、$\mathrm{RT}$-$\mathrm{PCR}$、实时定量 $\mathrm{RT}$-$\mathrm{PCR}$ 等。
:::

第三种策略是针对未知基因的。可通过比较疾病和正常组织中的所有 $\mathrm{mRNA}$ 的表达种类和含量间的差异，从而克隆疾病相关基因。这种差异可能源于基因结构改变，也可能源于表达调控机制的改变。早前常用的技术有 $\mathrm{mRNA}$ 差异显示（$\mathrm{mRNA}$ differential display，$\mathrm{mRNA}$-$\mathrm{DD}$）、抑制消减杂交（suppressive subtractive hybridization，$\mathrm{SSH}$）、基因表达系列分析（$\mathrm{SAGE}$）等；目前常用的主要是 $\mathrm{cDNA}$ 微阵列（$\mathrm{cDNA}$ microarray）、转录组测序（$\mathrm{RNA}$ sequencing，$\mathrm{RNA}$-$\mathrm{seq}$）。$\mathrm{RNA}$-$\mathrm{seq}$ 的样本准备、文库、测序、分析和验证五步流程见第二节图22-2，本节只立「比较全部 $\mathrm{mRNA}$ 的种类和含量」。

:::definition{label="表型克隆第三种：未知基因比全部 mRNA"}
比较疾病和正常组织中所有 $\mathrm{mRNA}$ 的表达种类和含量。差异可能来自基因结构改变，也可能来自表达调控机制改变。早前：$\mathrm{mRNA}$-$\mathrm{DD}$、$\mathrm{SSH}$、$\mathrm{SAGE}$；目前主要：$\mathrm{cDNA}$ 微阵列、$\mathrm{RNA}$-$\mathrm{seq}$。
:::

:::compare{title="表型克隆三种策略"}
| | 对象 | 比什么 | 本版技术 |
|--|------|--------|---------|
| 第一种 | 表型 → 基因组 $\mathrm{DNA}$ | 患者 vs 正常人的 $\mathrm{DNA}$ 片段 | 错配筛选、$\mathrm{RDA}$；动态突变（三联重复扩大） |
| 第二种 | 已知基因 | 该基因表达差异 | Northern、$\mathrm{RNA}$ 酶保护、$\mathrm{RT}$-$\mathrm{PCR}$、实时定量 $\mathrm{RT}$-$\mathrm{PCR}$ |
| 第三种 | 未知基因 | 全部 $\mathrm{mRNA}$ 种类和含量 | 早前 $\mathrm{mRNA}$-$\mathrm{DD}$／$\mathrm{SSH}$／$\mathrm{SAGE}$；目前芯片和 $\mathrm{RNA}$-$\mathrm{seq}$ |

第一种不需要位置和产物信息；第二种已经有候选基因名字；第三种在转录组层面撒网。图22-2 的五步不要在本节嵌入。
:::

:::pitfall{label="第三种差异不一定是基因结构变了"}
「可能源于基因结构改变，也可能源于表达调控机制的改变。」只答「找到了突变」，调控改变那一户就丢了。
:::

### （三）采用动物模型鉴定克隆疾病相关基因

人类的部分疾病，已经有相应的动物模型。如果动物某种表型的突变基因定位于染色体的某一部位，而具有相似人类疾病表型的基因很有可能存在于人染色体的同源部位。另外，当疾病基因在动物模型上已完成鉴定，还可以采用荧光原位杂交来定位分离人的同源基因。肥胖相关的瘦素（leptin）基因的克隆就是一个成功例证。利用突变的肥胖近交系小鼠通过定位克隆分离得到了位于小鼠 $6$ 号染色体的瘦蛋白基因，依据小鼠瘦蛋白基因侧翼标记，将人的瘦蛋白基因定位于人染色体 $7\mathrm{q}31$ 区。小鼠和人的瘦蛋白基因有 $84\%$ 的同源性，编码 $167$ 个氨基酸残基的分泌性蛋白——瘦蛋白，其主要功能是控制食物的摄入，促进能量的消耗。肥胖小鼠和一些遗传性肥胖症患者均带有该基因的缺损，导致基因功能丧失。

:::definition{label="动物模型同源定位"}
动物某种表型的突变基因若定位于染色体某一部位，相似人类疾病表型的基因很可能在人染色体的同源部位。动物模型上已完成鉴定时，还可用荧光原位杂交定位分离人的同源基因。
:::

:::definition{label="瘦素基因克隆（本版数字）"}
突变的肥胖近交系小鼠，定位克隆得到位于小鼠 $6$ 号染色体的瘦蛋白基因；依据小鼠基因侧翼标记，人的瘦蛋白基因定位于 $7\mathrm{q}31$。小鼠与人同源性 $84\%$，编码 $167$ 个氨基酸残基的分泌性蛋白——瘦蛋白。功能：控制食物摄入，促进能量消耗。肥胖小鼠和一些遗传性肥胖症患者均有该基因缺损，功能丧失。
:::

:::keypoint{label="瘦素例必须钉死的四个数字"}
- 小鼠：$6$ 号染色体。
- 人：$7\mathrm{q}31$。
- 同源性：$84\%$。
- 蛋白质：$167$ 个氨基酸残基的分泌蛋白。
:::

:::pitfall{label="瘦素是本节动物模型例，不要留在第二节文首"}
同源部位、荧光原位杂交、小鼠 $6$ 号、人 $7\mathrm{q}31$、$84\%$、$167$ 氨基酸都写在「采用动物模型鉴定」这一小节。第二节从定位克隆方法起笔，不再重复这段。
:::

:::insight{label="先有小鼠定位克隆，再靠侧翼标记落到人的 7q31"}
人的定位依据的是「小鼠瘦蛋白基因侧翼标记」，不是先在人染色体上做完连锁再回头命名瘦素。问「人的瘦蛋白基因在哪」答 $7\mathrm{q}31$；问「怎么到那儿的」答小鼠 $6$ 号染色体的侧翼标记。
:::

### （四）利用半克隆技术获得的复杂疾病小鼠模型鉴定疾病相关基因

类精子干细胞（sperm-like stem cells），即孤雄单倍体胚胎干细胞（androgenetic haploid embryonic stem cells，$\mathrm{AG}$-$\mathrm{haESCs}$），是一种来源于小鼠孤雄囊胚、仅含有父源遗传物质、性染色体为 $\mathrm{X}$ 染色体的新型单倍体胚胎干细胞。它不但能在体外长期自我更新、增殖或诱导分化，还能替代精子使卵母细胞受精产生半克隆小鼠。类精子干细胞与 $\mathrm{CRISPR}$ 系统结合可以开展单基因或多基因的编辑，通过将基因编辑后的类精子干细胞注射到卵母细胞中，可以高效稳定地一步获得基因型确定的半克隆小鼠（无嵌合现象），原代小鼠即可用于研究。基于类精子干细胞获得的单基因或多基因精准编辑的小鼠模型，通过模型的各种病理特征，可进一步在生物个体水平上明确单基因病的致病基因或复杂疾病的易感基因。利用该技术获得的复杂疾病小鼠模型，可以在生物个体水平上阐述多个基因协同互作的效应，进而更充分地模拟复杂的、可能受多个基因影响的人类疾病的各种病理特征，以挖掘新的诊断和治疗方法。

:::definition{label="类精子干细胞"}
类精子干细胞（sperm-like stem cells）即孤雄单倍体胚胎干细胞（$\mathrm{AG}$-$\mathrm{haESCs}$）：来源于小鼠孤雄囊胚，仅含父源遗传物质，性染色体为 $\mathrm{X}$ 染色体的新型单倍体胚胎干细胞。能在体外长期自我更新、增殖或诱导分化，并能替代精子使卵母细胞受精，产生半克隆小鼠。
:::

:::definition{label="半克隆小鼠（无嵌合）"}
类精子干细胞与 $\mathrm{CRISPR}$ 结合，做单基因或多基因编辑，注射到卵母细胞，一步获得基因型确定的半克隆小鼠，无嵌合现象，原代小鼠即可用于研究。
:::

:::definition{label="半克隆模型在鉴定上的用处"}
在生物个体水平上明确单基因病的致病基因或复杂疾病的易感基因；阐述多个基因协同互作的效应，更充分模拟可能受多个基因影响的人类疾病病理特征，以挖掘新的诊断和治疗方法。
:::

:::compare{title="瘦素近交系小鼠 vs 半克隆编辑小鼠"}
| | 起点 | 编辑方式 | 用来鉴定什么 |
|--|------|---------|-------------|
| 瘦素例 | 已有突变肥胖近交系 | 定位克隆已有突变 | 同源到人的瘦蛋白基因 |
| 半克隆 | $\mathrm{AG}$-$\mathrm{haESCs}$ 替代精子 | $\mathrm{CRISPR}$ 单基因或多基因，一步无嵌合 | 个体水平上的致病基因或易感基因，以及多基因协同 |

一个是「动物身上已经有病，再找基因」；一个是「按基因型把模型做出来，再看病理」。
:::

:::pitfall{label="性染色体为 X，不要写成 XY 精子"}
教材写「仅含有父源遗传物质、性染色体为 $\mathrm{X}$ 染色体」。这是孤雄单倍体胚胎干细胞，不是正常精子的性染色体组成。写成「就是精子」，半克隆和「无嵌合、原代即可用」就说不清。
:::

### （五）生物信息数据库贮藏丰富的疾病相关基因信息

借助于人类基因组计划和多种模式生物基因组测序的完成，生物信息学的发展，计算机软件的开发应用和互联网的普及，人们通过已获得的序列与数据库中核酸序列及蛋白质序列进行同源性比较，或对数据库中不同物种间的序列比较分析、拼接，预测新的全长基因等，进而通过实验证实，从组织细胞中克隆该基因，这就是所谓的计算机模拟克隆（in silico cloning）。计算机模拟克隆充分利用网络资源，可大大提高克隆新基因的速度和效率；但因数据库的不完善、错误信息的存在及分析软件的缺陷，往往它难以真正地克隆基因，而是一种电子辅助克隆。

:::definition{label="计算机模拟克隆"}
计算机模拟克隆（in silico cloning）：把已获得的序列与数据库中核酸及蛋白质序列做同源比较，或对不同物种间序列比较分析、拼接，预测新的全长基因，再经实验证实，从组织细胞中克隆该基因。
:::

:::definition{label="电子辅助克隆"}
计算机模拟克隆可大大提高速度和效率，但因数据库不完善、错误信息及分析软件缺陷，往往难以真正地克隆基因，而是一种电子辅助克隆。网上比完不等于实验室里已经拿到克隆。
:::

:::pitfall{label="in silico 不是已经完成克隆"}
教材把「难以真正地克隆基因」「电子辅助克隆」写在效率后面。答成「数据库里搜到就是鉴定完毕」，后文「从组织细胞中克隆该基因」的实验证实就没有了。
:::

人类新基因克隆大都是从同源表达序列标签（expressed sequence tag，$\mathrm{EST}$）分析开始的。$\mathrm{EST}$ 是指从不同组织构建的 $\mathrm{cDNA}$ 文库中，随机挑选不同的克隆，进行克隆部分测序所产生的 $\mathrm{cDNA}$ 序列，在新基因资源中扩展最为迅速。在人类 $\mathrm{EST}$ 数据库中，应用同源比较，识别和拼接与已知基因高度同源的人类新基因。

:::definition{label="表达序列标签"}
表达序列标签（expressed sequence tag，$\mathrm{EST}$）：从不同组织构建的 $\mathrm{cDNA}$ 文库中，随机挑选克隆，进行部分测序所产生的 $\mathrm{cDNA}$ 序列。新基因资源中扩展最为迅速。人类新基因克隆大都从同源 $\mathrm{EST}$ 分析开始。
:::

:::definition{label="EST 怎样变成新基因"}
在人类 $\mathrm{EST}$ 数据库中做同源比较，识别和拼接与已知基因高度同源的人类新基因。
:::

$\mathrm{EST}$ 主要用于新基因克隆、人类基因组图谱绘制、基因组序列编码区的确定等，是注释基因组序列的宝贵资源，在功能基因组学研究中发挥了重要作用。早期，$\mathrm{EST}$ 数据库在确定疾病相关基因方面也发挥了重要作用，如确定家族性阿尔茨海默病相关基因。事实上，通过阳性克隆发现的 $45$ 种人类疾病的基因，其中 $78\%$ 都可与 $\mathrm{EST}$ 数据库中的序列相匹配（至 $1995$ 年），国际组织将 $\mathrm{EST}$ 转变为基因依赖的序列标签位点（sequence-tagged site，$\mathrm{STS}$）数据库，以扩展人基因组的「转录图谱」。

:::definition{label="EST 的用途"}
新基因克隆、人类基因组图谱绘制、基因组序列编码区的确定；注释基因组的宝贵资源；功能基因组学中发挥重要作用。早期也用于确定疾病相关基因，本版点名家族性阿尔茨海默病相关基因。
:::

:::definition{label="1995 年的 45 种与 78%"}
通过阳性克隆发现的 $45$ 种人类疾病基因，其中 $78\%$ 可与 $\mathrm{EST}$ 数据库序列相匹配（至 $1995$ 年）。随后国际组织将 $\mathrm{EST}$ 转变为基因依赖的 $\mathrm{STS}$ 数据库，扩展人基因组的「转录图谱」。数字停在 $1995$ 年这一句，不要改成当前数据库条目数。
:::

:::memory{label="本节必背分户"}
- 疾病相关基因：影响发生发展。致病基因＝表型与基因型直接对应（单基因／孟德尔）；易感基因＝只增加易感性（复杂病，微效或互作）。
- 早期定位克隆对单基因病；现在 $\mathrm{SNP}$ 的 $\mathrm{GWAS}$、全外显子组测序加关联／连锁。不是只有 $\mathrm{GWAS}$。
- 标记：$\mathrm{CNV}$ $1\,\mathrm{KB}$～$3\,\mathrm{MB}$；$\mathrm{STR}$ 单位 $2\sim 6\,\mathrm{bp}$、$10\sim 60$ 多次、$<400\,\mathrm{bp}$；$\mathrm{SNP}$ $>1\%$、每 $300\,\mathrm{bp}$、约占多态性 $90\%$、第三代；罕见变异 $<1/1\,000$，单基因病，连锁或外显子测序。中性突变／致死突变。
- 原则：表型同质＋遗传度；图22-1 多路互补；交汇候选基因（$2$ 万 $\rightarrow$ $10\sim 30$，仍要逐个排除）。
- 功能克隆：蛋白质→$\mathrm{DNA}$；简并混合探针；本版镰状细胞贫血 → $\alpha$ 珠蛋白、$16$ 号染色体、分子病；现基本被全外显子组测序取代。
- 表型克隆三路：直接比 $\mathrm{DNA}$（动态突变、$\mathrm{RDA}$）；已知基因比表达；未知基因比全部 $\mathrm{mRNA}$（目前芯片和 $\mathrm{RNA}$-$\mathrm{seq}$，图22-2 在第二节）。
- 瘦素：小鼠 $6$ 号 → 人 $7\mathrm{q}31$，$84\%$ 同源，$167$ 氨基酸分泌蛋白，控摄食、促耗能。
- 半克隆：$\mathrm{AG}$-$\mathrm{haESCs}$（父源、$\mathrm{X}$）＋$\mathrm{CRISPR}$，一步无嵌合。
- in silico 是电子辅助；$\mathrm{EST}$ 部分测序的 $\mathrm{cDNA}$；$1995$ 年 $45$ 种里 $78\%$ 可匹配，转为 $\mathrm{STS}$ 转录图谱。
:::
