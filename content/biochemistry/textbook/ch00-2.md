# 第二节　当代生物化学与分子生物学研究的主要内容

本节把当代研究收成四块：生物大分子的结构与功能、物质代谢及其调节、基因信息传递及其调控、前沿技术。学科可以按应用领域或研究对象再分，但核心仍绕着中心法则上的基本生物大分子及其相互关系。

生物化学与分子生物学因其应用领域不同，可分为工业、农业、海洋、医学生物化学与分子生物学等。又可因研究对象不同，分为动物、植物、微生物生物化学与分子生物学等。生物化学与分子生物学的研究内容十分广泛，包括生物个体的物质结构、化学组成、化学变化、生物合成及其调节，以及这些物质组成、变化、调节与功能的关系等。生物化学与分子生物学自学科建立至今，其基本使命一直是从分子水平阐明生物体生命活动的本质和规律。尽管其已经成为生命科学和医学研究的工具和“语言”学科，涉及多领域并与其他学科发生广泛交叉，但其核心内容仍是围绕中心法则的基本生物大分子及其相互关系开展研究，破译生命及其疾病的基本规律。因此，当代生物化学与分子生物学的研究聚焦以下几个方面。

:::definition{label="学科的基本使命"}
自学科建立至今，生物化学与分子生物学的基本使命一直是从分子水平阐明生物体生命活动的本质和规律。应用领域和研究对象可以再分，使命不换。
:::

:::definition{label="工具和“语言”学科"}
它已经成为生命科学和医学研究的工具和“语言”学科，涉及多领域并与其他学科广泛交叉。即便如此，核心内容仍是围绕中心法则的基本生物大分子及其相互关系，破译生命及其疾病的基本规律。
:::

:::note{label="可以按领域分，也可以按对象分"}
按应用领域：工业、农业、海洋、医学生物化学与分子生物学等。按研究对象：动物、植物、微生物生物化学与分子生物学等。医学生用的是其中“医学”这一支，但四大聚焦对其他分支同样成立。
:::

:::concept{term="先问四大聚焦落在哪一块，再问是不是已经离开中心法则"}
看见“当代研究内容”，先把它收成四块：大分子结构与功能、物质代谢及其调节、基因信息传递及其调控、前沿技术。再问核心有没有换——教材写明：尽管已是工具和“语言”学科，核心仍围绕中心法则上的基本生物大分子及其相互关系。把当代研究听成“已经不做代谢、只做测序”，或把前沿技术听成可以离开中心法则另起炉灶，后面三节的医学转化会对错户头。
:::

:::compare{title="当代研究的四大聚焦"}
| 聚焦 | 主要对象 | 要回答的问题 | 不要听成 |
|------|----------|--------------|----------|
| 生物大分子的结构与功能 | 核酸、蛋白质、多糖、蛋白聚糖、复合脂质等生物信息分子 | 一级结构、空间结构与功能的关系；分子识别与相互作用 | 只测序列、不问空间结构和互作 |
| 物质代谢及其调节 | 新陈代谢、酶、细胞信息传递、疾病状态下的代谢紊乱 | 途径如何被有序调节；紊乱如何致病并转化到临床 | 途径已经画完，调节和疾病可以不写 |
| 基因信息传递及其调控 | DNA 结构与功能，复制、转录、蛋白质生物合成，表达的时空规律 | 信号转导、转录因子、RNA 剪辑如何调控基因表达 | 只背中心法则箭头，不问时空调控 |
| 前沿技术 | 从四大基本技术到组学、单细胞、基因编辑、人工智能生物技术等 | 如何对体内分子做定性、定量、定位和动态分析 | 技术清单可以离开理论核心另成一门课 |
:::

## 一、生物大分子的结构与功能

核酸、蛋白质、多糖、蛋白聚糖和复合脂质等是体内重要的生物大分子，生物大分子的重要特征之一是具有信息功能，由此也称之为生物信息分子。对生物大分子的研究，除了确定其一级结构（基本组成单位的种类、排列顺序和方式）外，更重要的是研究其空间结构及其与功能的关系。分子结构是功能的基础，而功能则是结构的体现。生物大分子的功能还需通过分子之间的相互识别和相互作用而实现。例如，蛋白质与蛋白质的相互作用在细胞信号转导中起重要作用；蛋白质与蛋白质、蛋白质与核酸、核酸与核酸的相互作用在基因表达调控中发挥着决定性作用。由此可见，分子结构、分子识别和分子的相互作用是执行生物信息分子功能的基本要素，而这一领域的研究是当今生物化学的热点之一。

:::definition{label="生物大分子"}
体内重要的生物大分子包括核酸、蛋白质、多糖、蛋白聚糖和复合脂质等。它们的重要特征之一是具有信息功能。
:::

:::definition{label="生物信息分子"}
因为生物大分子具有信息功能，故亦称之为生物信息分子。后文糖组学把聚糖称为第三类生物信息大分子，与这里的“信息功能”是同一套语言。
:::

:::definition{label="一级结构"}
一级结构指基本组成单位的种类、排列顺序和方式。确定一级结构是研究生物大分子的起点，但不是终点。
:::

:::definition{label="结构与功能的关系"}
分子结构是功能的基础，而功能则是结构的体现。更重要的是研究空间结构及其与功能的关系，而不是停在一级结构。
:::

:::definition{label="分子识别与相互作用"}
生物大分子的功能还需通过分子之间的相互识别和相互作用而实现。分子结构、分子识别和分子的相互作用，是执行生物信息分子功能的基本要素。
:::

:::example{label="互作落在两条生理账上"}
蛋白质与蛋白质的相互作用在细胞信号转导中起重要作用；蛋白质与蛋白质、蛋白质与核酸、核酸与核酸的相互作用在基因表达调控中发挥着决定性作用。两条账都不是“单个分子自己完成功能”。
:::

:::insight{label="先有结构，再有识别，功能才站得住"}
教材把执行功能的基本要素写成三件套：分子结构、分子识别、分子的相互作用。只背“结构决定功能”，会漏掉识别和互作；只背互作网络，又会忘掉结构是功能的基础。信号转导和基因表达调控，都是这三件套的现场。
:::

:::pitfall{label="一级结构测完不等于功能已经阐明"}
对生物大分子的研究，除了确定一级结构，更重要的是空间结构及其与功能的关系。把“测序完成”听成“结构与功能已经做完”，与第一节“基因组揭晓仅是序幕”是同一类错账。
:::

## 二、物质代谢及其调节

生命体不同于无生命体的基本特征是新陈代谢。据估计，以 $60$ 岁年龄计算，一个人在一生中与环境进行着大量的物质交换，约相当于 $60\,000\,\mathrm{kg}$ 水、$10\,000\,\mathrm{kg}$ 糖类、$600\,\mathrm{kg}$ 蛋白质以及 $1\,000\,\mathrm{kg}$ 脂质。因此，正常的物质代谢是正常生命过程的必要条件，若物质代谢发生紊乱则可引起疾病。目前对生物体内的主要物质代谢途径已基本清楚，但仍有众多的问题有待探讨。例如，物质代谢中的绝大多数化学反应是由酶催化的，酶的结构和酶量的变化对物质代谢的调节起着重要作用。物质代谢有序性调节的分子机制尚需进一步阐明。此外，细胞信息传递参与多种物质代谢及与其相关的生长、增殖、分化等生命过程的调节。细胞信息传递的机制及网络也是现代生物化学研究的重要课题。疾病状态下的物质代谢紊乱及其发生机制是当前物质代谢研究的热点，也是促进代谢机制研究及其向临床医学转化的新增长点。例如，肿瘤细胞的代谢特点和发生机制的研究成果已经在临床诊断和治疗中得以体现。

:::definition{label="新陈代谢"}
生命体不同于无生命体的基本特征是新陈代谢。正常的物质代谢是正常生命过程的必要条件，若物质代谢发生紊乱则可引起疾病。
:::

:::definition{label="一生中的物质交换量"}
以 $60$ 岁计，人一生与环境交换约相当于 $60\,000\,\mathrm{kg}$ 水、$10\,000\,\mathrm{kg}$ 糖类、$600\,\mathrm{kg}$ 蛋白质以及 $1\,000\,\mathrm{kg}$ 脂质。教材用这组数量级说明代谢不是“体内自己转一圈”，而是持续的物质交换。
:::

:::definition{label="酶对代谢调节的作用"}
物质代谢中的绝大多数化学反应是由酶催化的，酶的结构和酶量的变化对物质代谢的调节起着重要作用。途径已经基本清楚，不等于酶结构和酶量如何改变、有序性如何维持已经清楚。
:::

:::definition{label="细胞信息传递（代谢调节）"}
细胞信息传递参与多种物质代谢及与其相关的生长、增殖、分化等生命过程的调节。其机制及网络是现代生物化学研究的重要课题。
:::

:::cause-effect{title="代谢紊乱通向疾病，也通向转化"}
- **因** 正常物质代谢是正常生命过程的必要条件
- **果** 物质代谢紊乱可引起疾病；疾病状态下的代谢紊乱及其机制，成为向临床医学转化的新增长点
:::

:::example{label="肿瘤细胞代谢已经进入临床"}
肿瘤细胞的代谢特点和发生机制的研究成果，已经在临床诊断和治疗中得以体现。这是教材为“代谢研究向临床转化”写下的例子，不是说只有肿瘤才有代谢紊乱。
:::

:::pitfall{label="途径基本清楚，不等于调节机制和疾病机制已经清楚"}
主要物质代谢途径已基本清楚，但仍有众多问题有待探讨：酶的结构与酶量如何调节代谢、有序性调节的分子机制、细胞信息传递网络，以及疾病状态下的紊乱。把动态阶段“途径基本确定”听成当代已经无事可做，肿瘤代谢走进诊断治疗那一笔会被写没。
:::

## 三、基因信息传递及其调控

基因信息传递涉及遗传、变异、生长、分化等诸多生命过程，也与遗传病、恶性肿瘤、心血管病等多种疾病的发病机制有关。因此，基因信息的研究在生命科学中的作用越显重要。关于基因信息的研究，不仅包括 DNA 的结构与功能，更重要的是对 DNA 复制、基因转录、蛋白质生物合成等基因信息传递过程的机制及基因表达的时空规律进行研究。目前基因表达调控主要集中在细胞信号转导研究、转录因子研究和 RNA 剪辑研究三个方面。DNA 重组、转基因、基因敲除、新基因克隆、人类基因组及功能基因组研究等的发展，将大大推动这一领域的研究进程。

:::definition{label="基因信息传递"}
基因信息传递涉及遗传、变异、生长、分化等诸多生命过程，也与遗传病、恶性肿瘤、心血管病等多种疾病的发病机制有关。它不是只写在遗传学课本里的箭头。
:::

:::definition{label="基因表达的时空规律"}
对基因信息的研究，不仅包括 DNA 的结构与功能，更重要的是 DNA 复制、基因转录、蛋白质生物合成等传递过程的机制，以及基因表达的时空规律。
:::

:::definition{label="当代基因表达调控的三个方面"}
目前基因表达调控主要集中在三个方面：细胞信号转导研究、转录因子研究、RNA 剪辑研究。
:::

:::note{label="推动这一领域的技术与计划"}
DNA 重组、转基因、基因敲除、新基因克隆、人类基因组及功能基因组研究等的发展，将大大推动基因信息传递及其调控的研究进程。这些名字在第一节机能阶段已经立过户头，这里是把它们接到“当代如何往前推”。
:::

:::pitfall{label="中心法则不是基因表达调控的全部"}
复制、转录、蛋白质生物合成是传递过程；调控还要问何时何地表达、信号如何转、转录因子做什么、RNA 如何剪辑。把这一节听成把中心法则再背一遍，三个方面和功能基因组都会落空。
:::

## 四、前沿技术领域频现突破性进展

科学和技术相辅相成，曾经电泳，层析，分光光度和离心技术成为生物化学的四大基本技术，推动了生物化学的理论研究；后来以基因工程技术为核心的分子克隆技术的出现推动了分子生物学理论和应用的发展。当今，随着组学研究的深入开展，出现了各种高通量核酸和氨基酸测序及分析技术，更为精准定位的单细胞测序技术、空间转录组学技术，以质谱、色谱等联用为基础的中间代谢物测定技术等，实现对体内各种分子进行定性定量定位和动态分析，使得疾病的精准防治成为可能；表观遗传调控修饰和调控因子的研究促进了包括 DNA 修饰、RNA 修饰、组蛋白修饰等技术的出现，并应用于控制基因表达、核酸疫苗研制等领域；以 CRISPR/Cas9 为代表的基因编辑技术可针对具体基因进行精确的靶向编辑，在构建疾病动物模型、疾病基因治疗中发挥重要作用。

此外，大分子合成、组装和定向插入技术，冷冻电镜技术，细胞治疗，类器官研究，超分辨成像技术，人工智能生物技术等的不断发展也将从整体上推动生物化学与分子生物学学科的发展。新技术的开放和应用，特别是人工智能生物技术的潜在风险如生物武器的制造等受到全球范围的高度关注，人工智能生物技术的规范与管理成为世界各国和地区亟待解决的问题。

:::definition{label="生物化学四大基本技术"}
电泳、层析、分光光度和离心技术曾经是生物化学的四大基本技术，推动了生物化学的理论研究。
:::

:::definition{label="分子克隆技术"}
后来以基因工程技术为核心的分子克隆技术出现，推动了分子生物学理论和应用的发展。它接的是第一节重组 DNA 那一笔，不是四大基本技术的别名。
:::

:::definition{label="组学时代的高通量与定位技术"}
随着组学深入开展，出现各种高通量核酸和氨基酸测序及分析技术，更为精准定位的单细胞测序技术、空间转录组学技术，以及以质谱、色谱等联用为基础的中间代谢物测定技术等，从而对体内各种分子进行定性、定量、定位和动态分析，使疾病的精准防治成为可能。
:::

:::definition{label="表观遗传修饰技术"}
表观遗传调控修饰和调控因子的研究，促进了包括 DNA 修饰、RNA 修饰、组蛋白修饰等技术的出现，并应用于控制基因表达、核酸疫苗研制等领域。
:::

:::definition{label="CRISPR/Cas9 基因编辑"}
以 CRISPR/Cas9 为代表的基因编辑技术可针对具体基因进行精确的靶向编辑，在构建疾病动物模型、疾病基因治疗中发挥重要作用。
:::

:::compare{title="技术如何一层层推理论"}
| 层 | 技术 | 主要推动了什么 |
|----|------|----------------|
| 经典四大基本技术 | 电泳、层析、分光光度、离心 | 生物化学的理论研究 |

| 表观遗传与编辑 | DNA/RNA/组蛋白修饰；CRISPR/Cas9 等基因编辑 | 控制基因表达、核酸疫苗；疾病动物模型与基因治疗 |
| 仍在扩展 | 大分子合成组装与定向插入、冷冻电镜、细胞治疗、类器官、超分辨成像、人工智能生物技术 | 从整体上推动学科发展；同时提出规范与管理问题 |
:::

:::note{label="还有一组正在整体推动学科的技术"}
大分子合成、组装和定向插入技术，冷冻电镜技术，细胞治疗，类器官研究，超分辨成像技术，人工智能生物技术等，也将从整体上推动学科发展。冷冻电镜在第一节解析烟草花叶病病毒时已经露过面，这里是把它放进当代技术清单。
:::

:::pitfall{label="人工智能生物技术不是只写“很前沿”，教材同时写下了风险与治理"}
新技术的开放和应用，特别是人工智能生物技术的潜在风险如生物武器的制造等，受到全球范围高度关注；其规范与管理成为世界各国和地区亟待解决的问题。只记技术清单、不记风险与治理，这一段的收口会被写丢。
:::

:::keypoint{label="当代四块都还围着中心法则上的大分子转"}
- 应用领域可分工业、农业、海洋、医学；研究对象可分动物、植物、微生物；使命仍是从分子水平阐明生命活动的本质和规律。
- 核心内容围绕中心法则的基本生物大分子及其相互关系，破译生命及其疾病的基本规律。
- 大分子：核酸、蛋白质、多糖、蛋白聚糖、复合脂质是生物信息分子；结构是功能基础，功能是结构体现，还靠识别与互作。
- 代谢：新陈代谢是生命体区别于无生命体的基本特征；途径基本清楚，调节、信号网络和疾病紊乱仍是热点。
- 基因信息：复制、转录、蛋白质合成及表达的时空规律；调控集中在信号转导、转录因子、RNA 剪辑。
- 技术：四大基本技术 → 分子克隆 → 组学/单细胞/基因编辑/人工智能；精准防治成为可能，风险与规范必须同时写。
:::

:::memory{label="本节必背要点"}
- [ ] 按应用领域可分为工业、农业、海洋、医学生物化学与分子生物学等。
- [ ] 按研究对象可分为动物、植物、微生物生物化学与分子生物学等。
- [ ] 研究内容包括物质结构、化学组成、化学变化、生物合成及其调节，以及组成、变化、调节与功能的关系。
- [ ] 基本使命一直是从分子水平阐明生物体生命活动的本质和规律。
- [ ] 它已成为生命科学和医学研究的工具和“语言”学科，但核心仍围绕中心法则的基本生物大分子及其相互关系。
- [ ] 当代研究聚焦：生物大分子的结构与功能；物质代谢及其调节；基因信息传递及其调控；前沿技术。
- [ ] 重要生物大分子包括核酸、蛋白质、多糖、蛋白聚糖和复合脂质等，因具有信息功能而称为生物信息分子。
- [ ] 一级结构是基本组成单位的种类、排列顺序和方式；更重要的是空间结构及其与功能的关系。
- [ ] 分子结构是功能的基础，功能是结构的体现。
- [ ] 功能还需通过分子之间的相互识别和相互作用实现。
- [ ] 蛋白质–蛋白质互作在细胞信号转导中起重要作用。
- [ ] 蛋白质–蛋白质、蛋白质–核酸、核酸–核酸互作在基因表达调控中起决定性作用。
- [ ] 分子结构、分子识别和分子相互作用是执行生物信息分子功能的基本要素。
- [ ] 生命体不同于无生命体的基本特征是新陈代谢。
- [ ] 以 $60$ 岁计，一生约交换 $60\,000\,\mathrm{kg}$ 水、$10\,000\,\mathrm{kg}$ 糖类、$600\,\mathrm{kg}$ 蛋白质、$1\,000\,\mathrm{kg}$ 脂质。
- [ ] 正常物质代谢是正常生命过程的必要条件，代谢紊乱可引起疾病。
- [ ] 主要代谢途径已基本清楚，但酶的结构与酶量变化对调节很重要，有序性调节的分子机制尚需阐明。
- [ ] 细胞信息传递参与代谢及生长、增殖、分化等调节，其机制及网络是重要课题。
- [ ] 疾病状态下的代谢紊乱及其机制是当前热点和向临床转化的新增长点；肿瘤代谢研究已体现在诊断和治疗中。
- [ ] 基因信息传递涉及遗传、变异、生长、分化，也与遗传病、恶性肿瘤、心血管病等发病机制有关。
- [ ] 研究不仅包括 DNA 结构与功能，更重要的是复制、转录、蛋白质生物合成的机制及表达的时空规律。
- [ ] 基因表达调控主要集中在细胞信号转导、转录因子和 RNA 剪辑三个方面。
- [ ] DNA 重组、转基因、基因敲除、新基因克隆、人类基因组及功能基因组研究将推动这一领域。
- [ ] 电泳、层析、分光光度和离心技术是生物化学四大基本技术。
- [ ] 以基因工程技术为核心的分子克隆技术推动了分子生物学理论和应用。
- [ ] 组学带来高通量核酸和氨基酸测序、单细胞测序、空间转录组学、质谱色谱联用的中间代谢物测定。
- [ ] 这些技术实现对体内分子的定性、定量、定位和动态分析，使疾病精准防治成为可能。
- [ ] 表观遗传研究促进 DNA 修饰、RNA 修饰、组蛋白修饰等技术，用于控制基因表达和核酸疫苗研制。
- [ ] CRISPR/Cas9 等基因编辑可精确靶向编辑，用于疾病动物模型和基因治疗。
- [ ] 大分子合成组装与定向插入、冷冻电镜、细胞治疗、类器官、超分辨成像、人工智能生物技术从整体上推动学科。
- [ ] 人工智能生物技术的潜在风险（如生物武器制造）受全球关注，规范与管理亟待解决。
:::
