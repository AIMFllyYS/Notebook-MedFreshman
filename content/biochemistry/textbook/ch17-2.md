# 第二节　原核基因表达调控

第一节把调控写成组成性、诱导、阻遏和协同，并把转录起始定为基本控制点。本节落到原核：基因组以操纵子为转录调控基本单位；启动子 $-10$ 区 $\mathrm{TATAAT}$（Pribnow 盒）与 $-35$ 区 $\mathrm{TTGACA}$；乳糖操纵子由 $\mathrm{Lac}$ 阻遏蛋白负性调节与 $\mathrm{CAP}$ 正性调节协同，真正的诱导剂是别乳糖而不是乳糖本身；色氨酸操纵子用色氨酸作辅阻遏物关闭，再用衰减子精调。翻译水平的自我控制、$\mathrm{S}8/\mathrm{L}5$、反义 $\mathrm{RNA}$ 和稀有密码子仍属本节。真核单顺反子和染色质交给第三节。

:::concept{term="先问操纵子三块（结构基因、调控序列、调节基因），再问 lac 是阻遏还是 CAP，trp 是阻遏还是衰减"}
看见“原核基因表达调控”，先不要默写真核增强子。户头是：多数基因按操纵子转录成多顺反子 $\mathrm{mRNA}$；$\sigma$ 认启动子，共有序列在 $-10$ 和 $-35$；阻遏蛋白占操纵元件做负性调节，激活蛋白（如 $\mathrm{CAP}$）做正性调节。乳糖：无乳糖则阻遏，有乳糖（别乳糖／$\mathrm{IPTG}$）去阻遏，还要缺葡萄糖才有 $\mathrm{cAMP}$-$\mathrm{CAP}$ 的强诱导。色氨酸：高浓度时辅阻遏物关闭操纵序列，衰减则靠前导肽第 $10/11$ 位色氨酸密码子和 $2/3$ 或 $3/4$ 发夹。
:::

原核生物基因组是具有超螺旋结构的闭合环状 $\mathrm{DNA}$ 分子，在结构上有以下特点：①基因组中很少有重复序列；②编码蛋白质的结构基因为连续编码，且多为单拷贝基因，但编码 $\mathrm{rRNA}$ 的基因仍然是多拷贝基因；③结构基因在基因组中所占的比例（约占 $50\%$）远远大于真核基因组；④许多结构基因在基因组中以操纵子为单位排列。此外，原核生物的细胞结构也比较简单，其基因组的转录和翻译可以在同一空间内完成，并且时间上的差异不大。在转录过程终止之前 $\mathrm{mRNA}$ 就已经结合在核糖体上，开始蛋白质的生物合成。

:::definition{label="原核基因组四条结构特点"}
①很少有重复序列；②蛋白质结构基因连续编码、多为单拷贝，$\mathrm{rRNA}$ 基因仍为多拷贝；③结构基因约占基因组 $50\%$，远大于真核；④许多结构基因以操纵子为单位排列。
:::

:::definition{label="原核转录与翻译同空间、近乎同时"}
无核膜分隔：转录和翻译在同一空间完成，时间差异不大。转录尚未终止，$\mathrm{mRNA}$ 已结合核糖体开始蛋白质合成。色氨酸衰减正是利用这一偶联。
:::

:::pitfall{label="连续编码、单拷贝不要写成「全部基因都是一份」"}
「多为单拷贝」管的是蛋白质结构基因；教材立刻补了一句：编码 $\mathrm{rRNA}$ 的基因仍然是多拷贝。把全部基因答成单拷贝，$\mathrm{rRNA}$ 那条例外就丢了。
:::

:::pitfall{label="约 50% 是结构基因占比，不是重复序列占比"}
原核很少重复序列，结构基因约占 $50\%$。真核对比在第三节：哺乳类约 $10\%$ 序列编码蛋白质、$\mathrm{rRNA}$、$\mathrm{tRNA}$ 等。两个百分数不要对调。
:::

:::compare{title="原核基因组为操纵子准备的条件"}
| 特点 | 对调控意味着什么 |
|------|-------------------|
| 很少重复序列 | 编码区密集，调控序列紧挨结构基因 |
| 蛋白质基因连续、多单拷贝 | 没有内含子要剪；剂量主要靠转录起始而不是拷贝数 |
| 结构基因约占 $50\%$ | 远大于真核，操纵子里一串结构基因占得起位置 |
| 以操纵子为单位 | 功能相关基因共用启动子和终止信号 |
| 转录翻译偶联 | 前导肽翻译状态可以直接改变下游是否继续转录 |

第三节真核单顺反子、染色质、核膜分隔，都是对着这张表反着写。
:::

## 一、操纵子是原核基因转录调控的基本单位

前已述及，大肠埃希菌的 $\mathrm{RNA}$ 聚合酶由 $\sigma$ 亚基（或称 $\sigma$ 因子）和核心酶构成，其中 $\sigma$ 亚基的作用是识别和结合 $\mathrm{DNA}$ 模板上的启动序列，启动转录过程。原核生物在转录水平的调控主要取决于转录起始速度，即主要调节的是转录起始复合物形成的速度。

:::definition{label="σ 识别启动序列"}
大肠埃希菌 $\mathrm{RNA}$ 聚合酶 $=\sigma$ 亚基（$\sigma$ 因子）$+$ 核心酶。$\sigma$ 识别并结合 $\mathrm{DNA}$ 模板上的启动序列，启动转录。全酶组成的细节见第十五章，本节只用「谁认启动子」。
:::

:::definition{label="原核转录调控主要调起始速度"}
转录水平的调控主要取决于转录起始速度，即主要调节转录起始复合物形成的速度。这是第一节「转录起始是基本控制点」在原核的落实。
:::

:::insight{label="调起始复合物形成速度，不是另做一种 RNA 聚合酶"}
阻遏蛋白挡启动子、激活蛋白帮聚合酶结合，都是改「复合物出得快不快」。不要把正性、负性调节理解成换了一台聚合酶。
:::

:::pitfall{label="σ 脱落是第十五章延长的账，不要在本节重写成调控机制"}
本节关心 $\sigma$ 能不能结合启动序列。$\sigma$ 在延长时脱落、核心酶走转录泡，已经在转录章写过，不要拿来当操纵子开关。
:::

原核生物大多数基因表达调控是通过操纵子机制实现的。操纵子由结构基因、调控序列和调节基因组成。

:::definition{label="操纵子三组成"}
操纵子由结构基因、调控序列和调节基因组成。原核大多数基因表达调控通过操纵子机制实现。
:::

:::keypoint{label="三块缺一不叫完整操纵子"}
- 结构基因：被转录成蛋白质（或功能 $\mathrm{RNA}$）的编码区。
- 调控序列：启动子、操纵元件，以及可结合激活蛋白的序列。
- 调节基因：编码阻遏蛋白等调节分子；乳糖操纵子的 $\mathrm{I}$ 还有自己的 $\mathrm{PI}$。

只答「一串结构基因」，启动子和阻遏蛋白没有座位。
:::

结构基因通常包括数个功能上有关联的基因，它们串联排列，共同构成编码区。这些结构基因共用一个启动子和一个转录终止信号序列，因此转录合成时仅产生一条 $\mathrm{mRNA}$ 长链，为几种不同的蛋白质编码。这样的 $\mathrm{mRNA}$ 分子携带了几条多肽链的编码信息，被称为多顺反子（polycistron）$\mathrm{mRNA}$。

:::definition{label="结构基因串联、共用启动子和终止信号"}
数个功能关联的结构基因串联构成编码区，共用一个启动子和一个转录终止信号序列，转录只产生一条 $\mathrm{mRNA}$ 长链，为几种不同蛋白质编码。
:::

:::definition{label="多顺反子 mRNA"}
多顺反子（polycistron）$\mathrm{mRNA}$：一条 $\mathrm{mRNA}$ 携带几条多肽链的编码信息。这是原核协同表达的转录实现。
:::

:::pitfall{label="多顺反子不是「一条 mRNA 上挂多个核糖体」"}
一条 $\mathrm{mRNA}$ 编码几种蛋白质，是顺反子数目；一条 $\mathrm{mRNA}$ 上同时有多个核糖体，是第十六章的多聚核糖体。两者可同时存在，定义不要并成一句。
:::

:::insight{label="共用启动子所以能协同"}
第一节要求功能相关基因协调表达。原核把它们串在同一转录单位里，一次决定起始，几个酶一起出现。真核改成单顺反子之后，协同就要另做一套（第三节）。
:::

调控序列主要包括启动子和操纵元件（operator）。启动子是 $\mathrm{RNA}$ 聚合酶结合的部位，是决定基因表达效率的关键元件。各种原核基因启动序列特定区域内，通常在转录起始点上游 $-10$ 区及 $-35$ 区域存在一些相似序列（见第十五章），称为共有序列。$E.\ coli$ 及一些细菌启动序列的共有序列在 $-10$ 区域是 $\mathrm{TATAAT}$，又称 Pribnow 盒，在 $-35$ 区域为 $\mathrm{TTGACA}$（图17-1）。这些共有序列中的任一碱基突变或变异都会影响 $\mathrm{RNA}$ 聚合酶与启动子的结合及转录起始。因此，共有序列决定启动子的转录活性大小。

:::definition{label="调控序列的两个主角"}
调控序列主要包括启动子和操纵元件（operator）。启动子是 $\mathrm{RNA}$ 聚合酶结合部位，是决定基因表达效率的关键元件。
:::

:::definition{label="共有序列"}
原核启动序列在转录起始点上游 $-10$ 区及 $-35$ 区存在相似序列，称为共有序列。$E.\ coli$ 及一些细菌：$-10$ 为 $\mathrm{TATAAT}$，又称 Pribnow 盒；$-35$ 为 $\mathrm{TTGACA}$。
:::

:::definition{label="共有序列决定启动子活性"}
共有序列中任一碱基突变或变异，都会影响 $\mathrm{RNA}$ 聚合酶与启动子的结合及转录起始。因此共有序列决定启动子的转录活性大小。
:::

:::definition{label="Pribnow 盒就是原核 -10 的 TATAAT"}
Pribnow 盒 $= -10$ 区共有序列 $\mathrm{TATAAT}$。不要与真核 $\mathrm{TATA}$ 盒（Hognest 盒，第十五章第三节）混名。
:::

底行把共有序列钉成 $-35$ $\mathrm{TTGACA}$、$-10$ $\mathrm{TATAAT}$。五行里 $\mathrm{recA}$ 的 $-10$ 正好是 $\mathrm{TATAAT}$，$\mathrm{trp}$ 的 $-35$ 正好是 $\mathrm{TTGACA}$；$\mathrm{Ara}\,\mathrm{BAD}$ 的 $-35$ 是 $\mathrm{CTGACG}$，离共有序列最远。间隔写成 $\mathrm{N}16/\mathrm{N}17$、$\mathrm{N}6/\mathrm{N}7$，与第十五章 $-35$ 与 $-10$ 相隔 $16\sim 18$、$-10$ 与起点相距 $6$ 或 $7$ 一致。

- $\mathrm{tRNA}^{\mathrm{tyr}}$：$\mathrm{TTTACA}$—$\mathrm{N}16$—$\mathrm{TATGAT}$—$\mathrm{N}7$—$\mathrm{A}$。
- $\mathrm{lac}$：$\mathrm{TTTACA}$—$\mathrm{N}17$—$\mathrm{TATGTT}$—$\mathrm{N}6$—$\mathrm{A}$。

考试常问共有序列本身（$\mathrm{TTGACA}$、$\mathrm{TATAAT}$），不一定默写全部五行。
:::

:::pitfall{label="lac 的 -10 不是 TATAAT"}
图上 $\mathrm{lac}$ 的 $-10$ 是 $\mathrm{TATGTT}$。共有序列 $\mathrm{TATAAT}$ 是底行归纳，不是每一条启动子的原文。把 $\mathrm{lac}$ 写成标准 Pribnow 盒，后文「野生型 $\mathrm{lac}$ 启动子作用很弱」就不好理解。
:::

:::pitfall{label="间隔 N 不要当成编码氨基酸"}
$\mathrm{N}16$、$\mathrm{N}17$ 是任意核苷酸的间隔长度，不是天冬酰胺密码子。转录起点在图上标为 $\mathrm{A}$，是 $\mathrm{RNA}$ 第一位，不是操纵元件。
:::

操纵元件并非结构基因，而是一段能被特异的阻遏蛋白识别和结合的 $\mathrm{DNA}$ 序列。操纵序列与启动序列毗邻或接近，其 $\mathrm{DNA}$ 序列常与启动子交错、重叠，它是原核阻遏蛋白（repressor）的结合位点。当操纵序列结合有阻遏蛋白时会阻碍 $\mathrm{RNA}$ 聚合酶与启动子的结合，或使 $\mathrm{RNA}$ 聚合酶不能沿 $\mathrm{DNA}$ 向前移动，阻遏转录，介导负性调节（negative regulation）。原核操纵子调控序列中还有一种特异的 $\mathrm{DNA}$ 序列可结合激活蛋白（activator），结合后 $\mathrm{RNA}$ 聚合酶活性增强，使转录激活，介导正性调节（positive regulation）。

:::definition{label="操纵元件"}
操纵元件不是结构基因，而是能被特异阻遏蛋白识别和结合的 $\mathrm{DNA}$ 序列。它与启动序列毗邻或接近，常与启动子交错、重叠，是原核阻遏蛋白（repressor）的结合位点。
:::

:::definition{label="负性调节"}
操纵序列结合阻遏蛋白时：阻碍 $\mathrm{RNA}$ 聚合酶与启动子结合，或使聚合酶不能沿 $\mathrm{DNA}$ 前移，从而阻遏转录。这种调节是负性调节（negative regulation）。
:::

:::definition{label="正性调节"}
调控序列中另有特异 $\mathrm{DNA}$ 序列可结合激活蛋白（activator）。结合后 $\mathrm{RNA}$ 聚合酶活性增强，转录激活。这种调节是正性调节（positive regulation）。
:::

:::insight{label="图17-2 把「交错、重叠」画成 O 压在 P 右侧"}
后文乳糖操纵子图里，斜线阴影的 $\mathrm{O}$ 紧贴点状阴影的 $\mathrm{P}$，阻遏蛋白圆圈压在 $\mathrm{O}$ 上。这就是「毗邻、交错、重叠」的画面，不必另发明一段间隔序列。
:::

:::pitfall{label="操纵元件不要答成「编码阻遏蛋白的基因」"}
编码阻遏蛋白的是调节基因。操纵元件是被结合的 $\mathrm{DNA}$ 位点。$\mathrm{I}$ 和 $\mathrm{O}$ 弄反，乳糖操纵子结构表会整行错位。
:::

:::pitfall{label="负性调节不是「没有蛋白质去管」"}
负性调节的执行者是阻遏蛋白结合 $\mathrm{O}$。没有阻遏蛋白时转录可以发生（色氨酸操纵子无色氨酸即开放）。把负性理解成「不调控」，诱导和去阻遏都没有反义词。
:::

:::compare{title="启动子 vs 操纵元件 vs 激活蛋白结合序列"}
| | 结合谁 | 直接效果 |
|--|--------|----------|
| 启动子 | $\mathrm{RNA}$ 聚合酶（$\sigma$ 识别） | 决定能不能起始、起始效率 |
| 操纵元件 | 阻遏蛋白 | 挡住聚合酶结合或前移 $\rightarrow$ 负性调节 |
| 激活蛋白结合序列 | 激活蛋白（如 $\mathrm{CAP}$） | 增强聚合酶活性 $\rightarrow$ 正性调节 |

三块都可以叫调控序列，功能不要并成「都是启动子」。
:::

调节基因（regulatory gene）编码能够与操纵元件结合的阻遏蛋白。阻遏蛋白可以识别、结合特异的操纵元件，抑制基因转录，所以阻遏蛋白介导负性调节。阻遏蛋白介导的负性调节机制在原核生物中普遍存在。

:::definition{label="调节基因"}
调节基因（regulatory gene）编码能够与操纵元件结合的阻遏蛋白。阻遏蛋白识别、结合特异操纵元件，抑制转录，介导负性调节；该机制在原核中普遍存在。
:::

:::pitfall{label="调节基因本身也可以有独立启动子"}
乳糖操纵子 $\mathrm{I}$ 的启动子是 $\mathrm{PI}$，与结构基因的 $\mathrm{P}$ 不是同一个。把调节基因画进 $\mathrm{Z}$-$\mathrm{Y}$-$\mathrm{A}$ 那条多顺反子，阻遏蛋白会随乳糖诱导一起暴增，模型就自毁。
:::

此外，还有一些调控蛋白质对原核基因转录调控起着重要的作用，如特异因子和激活蛋白。这些调控蛋白质的作用分别是：①特异因子决定 $\mathrm{RNA}$ 聚合酶对一个或一套启动序列的特异性识别和结合能力。②激活蛋白可结合启动子邻近的 $\mathrm{DNA}$ 序列，提高 $\mathrm{RNA}$ 聚合酶与启动序列的结合能力，从而增强 $\mathrm{RNA}$ 聚合酶的转录活性，是一种正性调节。分解（代谢）物基因激活蛋白质（catabolite gene activator protein，$\mathrm{CAP}$）就是一种典型的激活蛋白。有些基因在没有激活蛋白存在时，$\mathrm{RNA}$ 聚合酶很少或根本不能结合启动子，所以基因不能转录。

:::definition{label="特异因子"}
特异因子决定 $\mathrm{RNA}$ 聚合酶对一个或一套启动序列的特异性识别和结合能力。它改变的是「这台酶认哪一套启动子」，与阻遏蛋白占 $\mathrm{O}$ 不是同一件事。
:::

:::definition{label="激活蛋白"}
激活蛋白结合启动子邻近的 $\mathrm{DNA}$ 序列，提高 $\mathrm{RNA}$ 聚合酶与启动序列的结合能力，增强转录活性，属正性调节。
:::

:::definition{label="CAP"}
分解（代谢）物基因激活蛋白质（catabolite gene activator protein，$\mathrm{CAP}$）是一种典型的激活蛋白。
:::

:::definition{label="没有激活蛋白可以等于不能转录"}
有些基因在没有激活蛋白时，$\mathrm{RNA}$ 聚合酶很少或根本不能结合启动子，基因不能转录。后文野生型 $\mathrm{lac}$ 启动子很弱、去阻遏后若无 $\mathrm{CAP}$ 仍几无转录活性，就是这句的实例。
:::

:::compare{title="三类原核调控蛋白质"}
| | 认什么 | 效果 |
|--|--------|------|
| 阻遏蛋白 | 操纵元件 | 抑制转录，负性调节 |
| 特异因子 | 决定聚合酶认哪一套启动子 | 改变起始特异性 |
| 激活蛋白（如 $\mathrm{CAP}$） | 启动子邻近序列 | 提高聚合酶结合／活性，正性调节 |

三者都是 $\mathrm{DNA}$ 结合蛋白质。
:::

阻遏蛋白、特异因子和激活蛋白等原核调控蛋白质都是一些 $\mathrm{DNA}$ 结合蛋白质。凡是能够诱导基因表达的分子称为诱导剂，而凡是能够阻遏基因表达的分子称为阻遏剂。

:::definition{label="原核调控蛋白质是 DNA 结合蛋白质"}
阻遏蛋白、特异因子和激活蛋白都是 $\mathrm{DNA}$ 结合蛋白质。第一节「蛋白质-$\mathrm{DNA}$ 相互作用是分子基础」在原核落到这三类分子上。
:::

:::definition{label="诱导剂与阻遏剂"}
能够诱导基因表达的分子称为诱导剂；能够阻遏基因表达的分子称为阻遏剂。后文别乳糖、$\mathrm{IPTG}$ 是诱导剂；色氨酸作为辅阻遏物参加阻遏，不要把色氨酸叫成诱导剂。
:::

:::pitfall{label="诱导剂不是激活蛋白的别名"}
诱导剂是小分子（别乳糖、$\mathrm{IPTG}$）；激活蛋白是蛋白质（$\mathrm{CAP}$）。一个结合阻遏蛋白使其离开 $\mathrm{O}$，一个结合 $\mathrm{DNA}$ 帮聚合酶。两类角色不要互换。
:::

## 二、乳糖操纵子是典型的诱导型调控

操纵子在原核基因表达调控中具有普遍意义。大多数原核生物的多个功能相关基因串联在一起，依赖同一调控序列对其转录进行调节，使这些相关基因实现协调表达。以大肠埃希菌的乳糖操纵子（lac operon）为例介绍原核生物的操纵子调控模式。乳糖代谢酶基因的表达特点是：在环境中没有乳糖时，这些基因处于关闭状态；当环境中只有乳糖时，这些基因才被诱导开放，合成代谢乳糖所需要的酶。乳糖操纵子是最早发现的原核生物转录调控模式。

:::definition{label="乳糖操纵子是诱导型、也是最早发现的模式"}
乳糖操纵子（lac operon）：无乳糖时基因关闭；环境中只有乳糖时才被诱导开放，合成代谢乳糖所需的酶。它是最早发现的原核生物转录调控模式，也是第一节点名的诱导和阻遏经典模型。
:::

:::insight{label="「只有乳糖」已经为葡萄糖的分解代谢阻遏留了位子"}
开篇写的是「只有乳糖时才被诱导开放」。后面会证明：乳糖加上葡萄糖时去阻遏仍几乎不转录。读到这里先记住生理目标——能不用乳糖就不用。
:::

:::pitfall{label="关闭不是基因丢失"}
无乳糖时处于关闭状态，是阻遏蛋白占 $\mathrm{O}$。$\mathrm{Z}$、$\mathrm{Y}$、$\mathrm{A}$ 仍在基因组上。把关闭答成缺失，诱导剂结合阻遏蛋白就没有靶。
:::

### （一）乳糖操纵子具备诱导型调控的完整结构

$E.\ coli$ 的乳糖操纵子含 $\mathrm{Z}$、$\mathrm{Y}$ 及 $\mathrm{A}$ 三个结构基因，分别编码 $\beta$-半乳糖苷酶（$\beta$-galactosidase）、通透酶（permease）和乙酰基转移酶（transacetylase），此外还有一个操纵元件 $\mathrm{O}$（operator，$\mathrm{O}$）、一个启动子 $\mathrm{P}$（promoter，$\mathrm{P}$）及一个调节基因 $\mathrm{I}$。$\mathrm{I}$ 基因具有独立的启动子（$\mathrm{PI}$），编码一种阻遏蛋白，后者与操纵元件 $\mathrm{O}$ 结合，使操纵子受阻遏而处于关闭状态。在启动子 $\mathrm{P}$ 上游还有一个 $\mathrm{CAP}$ 结合位点。由 $\mathrm{P}$ 序列、$\mathrm{O}$ 序列和 $\mathrm{CAP}$ 结合位点共同构成乳糖操纵子的调控区，三个酶的编码基因即由同一调控区调节，实现基因表达产物的协同表达（图17-2）。

:::definition{label="lac 三个结构基因"}
$\mathrm{Z}$ 编码 $\beta$-半乳糖苷酶（$\beta$-galactosidase）；$\mathrm{Y}$ 编码通透酶（permease）；$\mathrm{A}$ 编码乙酰基转移酶（transacetylase）。
:::

:::definition{label="I、O、P 和 CAP 位点"}
调节基因 $\mathrm{I}$ 有独立启动子 $\mathrm{PI}$，编码阻遏蛋白；阻遏蛋白结合操纵元件 $\mathrm{O}$，使操纵子关闭。启动子为 $\mathrm{P}$。$\mathrm{P}$ 上游还有 $\mathrm{CAP}$ 结合位点。
:::

:::definition{label="lac 调控区"}
调控区由 $\mathrm{P}$ 序列、$\mathrm{O}$ 序列和 $\mathrm{CAP}$ 结合位点共同构成。三个酶的编码基因由同一调控区调节，实现协同表达。
:::

:::keypoint{label="从左到右先能默写图17-2 上排"}
$\mathrm{PI}$-$\mathrm{I}$-$\mathrm{CAP}$-$\mathrm{P}$-$\mathrm{O}$-$\mathrm{Z}$-$\mathrm{Y}$-$\mathrm{A}$。$\mathrm{I}$ 单独转录；$\mathrm{Z}$-$\mathrm{Y}$-$\mathrm{A}$ 才是那条多顺反子。
:::

:::pitfall{label="Z、Y、A 不要和酶对错行"}
$\mathrm{Z}$ 不是通透酶，$\mathrm{Y}$ 不是乙酰基转移酶。对错行之后，「少数 $\beta$-半乳糖苷酶把乳糖变成别乳糖」会变成通透酶的催化，诱导剂来源就错了。
:::

:::pitfall{label="CAP 位点在 P 上游，不要画进 O 里"}
调控区三块：$\mathrm{P}$、$\mathrm{O}$、$\mathrm{CAP}$ 位点。$\mathrm{CAP}$ 位点不是操纵元件的别名。图画在 $\mathrm{P}$ 左侧短竖线处。
:::

### （二）乳糖操纵子受到阻遏蛋白和 CAP 的双重调节

#### 1. 阻遏蛋白的负性调节

在没有乳糖存在时，$\mathrm{lac}$ 操纵子处于阻遏状态。此时，$\mathrm{I}$ 序列在 $\mathrm{PI}$ 启动序列作用下表达的 $\mathrm{Lac}$ 阻遏蛋白与 $\mathrm{O}$ 序列结合，阻碍 $\mathrm{RNA}$ 聚合酶与 $\mathrm{P}$ 序列结合，抑制转录启动。阻遏蛋白的阻遏作用并非绝对，偶有阻遏蛋白与 $\mathrm{O}$ 序列解聚。因此，每个细胞中可能会有寥寥数个分子的 $\beta$-半乳糖苷酶、通透酶生成。

当有乳糖存在时，$\mathrm{lac}$ 操纵子即可被诱导。在这个操纵子体系中，真正的诱导剂并非乳糖本身。乳糖经通透酶催化、转运进入细胞，再经原先存在于细胞中的少数 $\beta$-半乳糖苷酶催化，转变为别乳糖（allolactose）。后者作为一种诱导剂分子结合阻遏蛋白，使蛋白质构象变化，导致阻遏蛋白与 $\mathrm{O}$ 序列解离而发生转录，可使 $\beta$-半乳糖苷酶分子增加达 $1\,000$ 倍。别乳糖的类似物异丙基硫代-$\beta$-D-半乳糖苷（isopropylthio-$\beta$-D-galactoside，$\mathrm{IPTG}$）是一种作用极强的诱导剂，不被细菌代谢而十分稳定，因此在基因工程领域和分子生物学实验中被广泛应用。

:::definition{label="无乳糖时的阻遏状态"}
无乳糖：$\mathrm{I}$ 在 $\mathrm{PI}$ 作用下表达 $\mathrm{Lac}$ 阻遏蛋白，阻遏蛋白结合 $\mathrm{O}$，阻碍 $\mathrm{RNA}$ 聚合酶与 $\mathrm{P}$ 结合，抑制转录启动。
:::

:::definition{label="阻遏并非绝对"}
偶有阻遏蛋白与 $\mathrm{O}$ 解聚，每个细胞中可能有寥寥数个分子的 $\beta$-半乳糖苷酶、通透酶。这几个分子是后文「乳糖能被变成别乳糖」的前提。
:::

:::definition{label="真正的诱导剂是别乳糖"}
有乳糖时可被诱导，但真正的诱导剂并非乳糖本身。乳糖经通透酶转运入细胞，再经原已存在的少数 $\beta$-半乳糖苷酶转变为别乳糖（allolactose）。别乳糖结合阻遏蛋白，使其构象变化，与 $\mathrm{O}$ 解离而发生转录，$\beta$-半乳糖苷酶分子可增加达 $1\,000$ 倍。
:::

:::definition{label="IPTG"}
异丙基硫代-$\beta$-D-半乳糖苷（isopropylthio-$\beta$-D-galactoside，$\mathrm{IPTG}$）是别乳糖的类似物，作用极强的诱导剂，不被细菌代谢而十分稳定，故在基因工程和分子生物学实验中被广泛应用。
:::

:::cause-effect{title="为什么必须先有寥寥数个酶分子"}
- **因** 乳糖要靠通透酶进细胞，再靠 $\beta$-半乳糖苷酶变成别乳糖，才能当诱导剂
- **果** 阻遏不能绝对为零；偶发解聚留下数个分子，诱导才能启动，随后放大到约 $1\,000$ 倍
:::

:::pitfall{label="不要答「乳糖直接结合阻遏蛋白」"}
教材写明真正的诱导剂并非乳糖本身。答成乳糖结合阻遏蛋白，别乳糖和那几个先存酶分子都没有功能。
:::

:::pitfall{label="IPTG 不是乳糖，也不被代谢"}
$\mathrm{IPTG}$ 稳定、不被细菌代谢，所以实验上好用。把它写成「另一种碳源」，分解代谢阻遏那一套会和诱导剂搅在一起。
:::

:::pitfall{label="1 000 倍是 β-半乳糖苷酶分子数，不是 CAP 的 50 倍"}
去阻遏可使 $\beta$-半乳糖苷酶增加达 $1\,000$ 倍；$\mathrm{cAMP}$-$\mathrm{CAP}$ 使转录活性提高 $50$ 倍。两个数字分属负性解除和正性加强，不要对调。
:::

:::compare{title="别乳糖 vs IPTG"}
| | 别乳糖 | $\mathrm{IPTG}$ |
|--|--------|----------------|
| 来源 | 乳糖经通透酶 $+$ 少数 $\beta$-半乳糖苷酶转变 | 别乳糖的类似物，实验加入 |
| 作用 | 结合阻遏蛋白，构象变化，离开 $\mathrm{O}$ | 同左，作用极强 |
| 是否被代谢 | 细胞内乳糖代谢路径上的中间物 | 不被细菌代谢，十分稳定 |
| 用途 | 生理诱导 | 基因工程／分子生物学实验 |

二者都画在图17-2 下排同一条箭头上。
:::

#### 2. CAP 的正性调节

$\mathrm{CAP}$ 是同二聚体，在其分子内有 $\mathrm{DNA}$ 结合区及 $\mathrm{cAMP}$ 结合位点。当培养基中缺乏葡萄糖时，$\mathrm{cAMP}$ 浓度增高，$\mathrm{cAMP}$ 与 $\mathrm{CAP}$ 结合，这时 $\mathrm{CAP}$ 结合在 $\mathrm{lac}$ 启动序列附近的 $\mathrm{CAP}$ 位点，可刺激 $\mathrm{RNA}$ 聚合酶转录活性，使之提高 $50$ 倍；当有葡萄糖存在时，$\mathrm{cAMP}$ 浓度降低，$\mathrm{cAMP}$ 与 $\mathrm{CAP}$ 结合受阻，因此 $\mathrm{lac}$ 操纵子表达下降。

由此可见，对 $\mathrm{lac}$ 操纵子来说 $\mathrm{CAP}$ 是正性调节因素，$\mathrm{Lac}$ 阻遏蛋白是负性调节因素。两种调节机制根据存在的碳源性质及水平协调调节 $\mathrm{lac}$ 操纵子的表达。

:::definition{label="CAP 的分子结构要点"}
$\mathrm{CAP}$ 是同二聚体，分子内有 $\mathrm{DNA}$ 结合区及 $\mathrm{cAMP}$ 结合位点。
:::

:::definition{label="缺葡萄糖时 cAMP-CAP 激活"}
培养基缺乏葡萄糖：$\mathrm{cAMP}$ 浓度增高，$\mathrm{cAMP}$ 与 $\mathrm{CAP}$ 结合，$\mathrm{CAP}$ 结合在 $\mathrm{lac}$ 启动序列附近的 $\mathrm{CAP}$ 位点，刺激 $\mathrm{RNA}$ 聚合酶转录活性，提高 $50$ 倍。
:::

:::definition{label="有葡萄糖时 CAP 正性调节受阻"}
有葡萄糖：$\mathrm{cAMP}$ 浓度降低，$\mathrm{cAMP}$ 与 $\mathrm{CAP}$ 结合受阻，$\mathrm{lac}$ 操纵子表达下降。
:::

:::definition{label="双重调节的角色分配"}
$\mathrm{CAP}$ 是正性调节因素，$\mathrm{Lac}$ 阻遏蛋白是负性调节因素。二者根据碳源性质及水平协调调节 $\mathrm{lac}$ 表达。
:::

:::cause-effect{title="葡萄糖怎样压低 lac"}
- **因** 有葡萄糖则 cAMP 浓度降低，cAMP 与 CAP 结合受阻，CAP 不能占 CAP 位点
- **果** 即使后面会讨论去阻遏，聚合酶也得不到 50 倍刺激，lac 表达下降
:::

:::pitfall{label="CAP 不直接「吃葡萄糖」"}
葡萄糖通过降低 $\mathrm{cAMP}$ 浓度起作用。把 $\mathrm{CAP}$ 写成葡萄糖受体，同二聚体上的 $\mathrm{cAMP}$ 结合位点就没有底物。
:::

:::pitfall{label="50 倍不要写成必须有乳糖才能测到的那 1 000 倍"}
$50$ 倍是 $\mathrm{CAP}$ 刺激聚合酶转录活性的倍数。$1\,000$ 倍是去阻遏后 $\beta$-半乳糖苷酶分子数的增加。机制不同、分子不同。
:::

:::compare{title="Lac 阻遏蛋白 vs CAP"}
| | $\mathrm{Lac}$ 阻遏蛋白 | $\mathrm{CAP}$ |
|--|----------------------|--------------|
| 调节方向 | 负性 | 正性 |
| 结合部位 | $\mathrm{O}$ | $\mathrm{P}$ 附近的 $\mathrm{CAP}$ 位点 |
| 小分子 | 别乳糖／$\mathrm{IPTG}$ 使其离开 $\mathrm{O}$ | $\mathrm{cAMP}$ 使其能结合 $\mathrm{DNA}$ |
| 葡萄糖／乳糖 | 乳糖 $\rightarrow$ 别乳糖 $\rightarrow$ 去阻遏 | 葡萄糖低 $\rightarrow$ $\mathrm{cAMP}$ 高 $\rightarrow$ 激活 |

缺任何一侧，后文三种碳源组合都画不出来。
:::

#### 3. 协同调节

$\mathrm{Lac}$ 阻遏蛋白负性调节与 $\mathrm{CAP}$ 正性调节两种机制协同合作：当 $\mathrm{Lac}$ 阻遏蛋白阻遏转录时，$\mathrm{CAP}$ 对该系统不能发挥作用；但是如果没有 $\mathrm{CAP}$ 存在来加强转录活性，即使阻遏蛋白从操纵序列上解离仍几无转录活性。可见，两种机制相辅相成、互相协调、相互制约。由于野生型 $\mathrm{lac}$ 启动子作用很弱，所以 $\mathrm{CAP}$ 是必不可少的。

$\mathrm{lac}$ 操纵子的负调节能很好地解释在单纯乳糖存在时，细菌是如何利用乳糖作为碳源的。然而，细菌生长环境是复杂的，倘若有葡萄糖或葡萄糖／乳糖共同存在时，细菌首先利用葡萄糖才是最节能的。这时，葡萄糖通过降低 $\mathrm{cAMP}$ 浓度，阻碍 $\mathrm{cAMP}$ 与 $\mathrm{CAP}$ 结合而抑制 $\mathrm{lac}$ 操纵子转录，使细菌只能利用葡萄糖。葡萄糖对 $\mathrm{lac}$ 操纵子的阻遏作用称分解代谢阻遏（catabolic repression）。$\mathrm{lac}$ 操纵子强的诱导作用既需要乳糖存在又需要缺乏葡萄糖。$\mathrm{lac}$ 操纵子协同调节机制如图17-3 所示。

:::definition{label="两种机制必须同时满足才有强转录"}
阻遏蛋白占 $\mathrm{O}$ 时，$\mathrm{CAP}$ 不能发挥作用。无 $\mathrm{CAP}$ 加强时，即使阻遏蛋白已从 $\mathrm{O}$ 解离，仍几无转录活性。二者相辅相成、互相协调、相互制约。
:::

:::definition{label="野生型 lac 启动子很弱，所以 CAP 必不可少"}
野生型 $\mathrm{lac}$ 启动子作用很弱，$\mathrm{CAP}$ 是必不可少的。图17-1 里 $\mathrm{lac}$ 的 $-10$ 是 $\mathrm{TATGTT}$ 而不是标准 $\mathrm{TATAAT}$，与「很弱」同一方向。
:::

:::definition{label="分解代谢阻遏"}
葡萄糖对 $\mathrm{lac}$ 操纵子的阻遏作用称分解代谢阻遏（catabolic repression）：葡萄糖降低 $\mathrm{cAMP}$，阻碍 $\mathrm{cAMP}$ 与 $\mathrm{CAP}$ 结合，抑制 $\mathrm{lac}$ 转录，细菌只能利用葡萄糖。有葡萄糖或葡萄糖／乳糖共同存在时，首先利用葡萄糖最节能。
:::

:::definition{label="强诱导的两个必要条件"}
$\mathrm{lac}$ 操纵子强的诱导作用既需要乳糖存在，又需要缺乏葡萄糖。
:::

| （b） | 有（去阻遏） | 有 | 离开 $\mathrm{O}$ | 不能发挥作用 | 几无 |
| （c） | 有 | 无 | 离开 $\mathrm{O}$ | 发挥作用 | 强诱导 |

「节能」落在（a）（b）：能用葡萄糖就不开乳糖酶系统。
:::

:::pitfall{label="去阻遏不等于强表达"}
（b）已经去阻遏，仍因葡萄糖存在而几乎不转录。把「有乳糖」直接答成「lac 全开」，分解代谢阻遏和 $\mathrm{CAP}$ 必不可少两句都作废。
:::

:::pitfall{label="分解代谢阻遏不要写成 Lac 阻遏蛋白的别名"}
分解代谢阻遏走的是葡萄糖 $\rightarrow$ $\mathrm{cAMP}$ $\downarrow$ $\rightarrow$ $\mathrm{CAP}$ 不能结合。$\mathrm{Lac}$ 阻遏蛋白走的是 $\mathrm{O}$ 位点。两条负性路径，执行分子不同。
:::

:::timeline{period="lac 从关闭到强诱导要经过的分子事件"}
- **无乳糖** Lac 阻遏蛋白占 O，聚合酶不能有效结合 P
- **乳糖进入** 先靠寥寥数个通透酶和 β-半乳糖苷酶变成别乳糖（或实验加入 IPTG）
- **去阻遏** 别乳糖或 IPTG 改变阻遏蛋白构象，O 空出
- **还要缺葡萄糖** cAMP 升高，cAMP-CAP 占 CAP 位点，转录活性提高 50 倍，酶分子可达 1 000 倍量级
:::

## 三、色氨酸操纵子通过阻遏作用和衰减作用抑制基因表达

原核生物体积小，受环境影响大，在生存过程中需要最大限度减少能源消耗，对非必需氨基酸都尽量关闭其编码基因。例如，只要环境中有相应的氨基酸供应，大肠埃希菌就不会自己去合成，而会将相应氨基酸的合成代谢酶编码基因全部关闭。大肠埃希菌色氨酸操纵子（trp operon）就是一个可阻遏操纵子。在细胞内无色氨酸时，阻遏蛋白不能与操纵序列结合，因此色氨酸操纵子处于开放状态，结构基因得以表达。当细胞内色氨酸的浓度较高时，色氨酸作为辅阻遏物与阻遏蛋白形成复合物并结合到操纵序列上，关闭色氨酸操纵子，停止表达用于合成色氨酸的各种酶。

:::definition{label="色氨酸操纵子是可阻遏操纵子"}
色氨酸操纵子（trp operon）：细胞内无色氨酸时，阻遏蛋白不能与操纵序列结合，操纵子开放，结构基因表达；色氨酸浓度较高时，色氨酸作为辅阻遏物与阻遏蛋白形成复合物，结合操纵序列，关闭操纵子，停止表达色氨酸合成酶系。
:::

:::definition{label="为何要关氨基酸合成基因"}
原核体积小、受环境影响大，需最大限度减少能源消耗。环境中已有相应氨基酸供应时，大肠埃希菌不自己合成，把该氨基酸合成代谢酶编码基因全部关闭。
:::

:::compare{title="lac 诱导型 vs trp 可阻遏型"}
| | 乳糖操纵子 | 色氨酸操纵子 |
|--|------------|--------------|
| 类型 | 诱导型 | 可阻遏型 |
| 无信号小分子时 | 阻遏蛋白占 $\mathrm{O}$，关 | 阻遏蛋白不能占 $\mathrm{O}$，开 |
| 有信号小分子时 | 别乳糖使阻遏蛋白离开 $\mathrm{O}$，开（还要 $\mathrm{CAP}$） | 色氨酸作辅阻遏物，复合物占 $\mathrm{O}$，关 |
| 生理逻辑 | 有底物才开分解酶 | 有产物就关合成酶 |

不要把色氨酸也写成「诱导剂」。
:::

:::pitfall{label="无色氨酸时不是「没有阻遏蛋白」"}
教材写的是阻遏蛋白不能与操纵序列结合。蛋白可以在，只是没有辅阻遏物时绑不上 $\mathrm{O}$。把「不能结合」听成「I 基因不表达」，和乳糖操纵子 $\mathrm{I}$ 持续产生阻遏蛋白的写法会对乱。
:::

:::pitfall{label="色氨酸是辅阻遏物，不是阻遏蛋白"}
关闭 $\mathrm{O}$ 的是「色氨酸 $+$ 阻遏蛋白」复合物。色氨酸单独不是 $\mathrm{DNA}$ 结合蛋白质。
:::

色氨酸操纵子的有效关闭还有一种属于促进已经开始转录的 $\mathrm{mRNA}$ 合成终止的方式来进一步加强，这种方式称为转录衰减（transcription attenuation），即色氨酸操纵子还可通过转录衰减的方式抑制基因表达。这种作用是利用原核生物中转录与翻译过程偶联进行，转录时先合成的一段前导序列 $\mathrm{L}$ 来实现的。

:::definition{label="转录衰减"}
转录衰减（transcription attenuation）：促进已经开始转录的 $\mathrm{mRNA}$ 合成终止，从而进一步加强关闭。色氨酸操纵子用这种方式抑制基因表达。
:::

:::definition{label="衰减利用转录翻译偶联和前导序列 L"}
原核转录与翻译偶联。转录时先合成一段前导序列 $\mathrm{L}$，衰减作用通过这段前导序列实现。
:::

:::insight{label="阻遏挡起始，衰减挡已经开始的转录"}
阻遏蛋白－辅阻遏物复合物作用在操纵序列，属于起始水平。衰减让已经开工的 $\mathrm{RNA}$ 聚合酶中途停下。两道闸门一前一后，才叫「有效关闭」。
:::

:::pitfall{label="衰减不是阻遏蛋白的别名"}
衰减不要求再做一份阻遏蛋白。它读的是前导肽翻译走到哪、发夹在 $2/3$ 还是 $3/4$。把衰减答成「又一种阻遏蛋白」，$162\,\mathrm{nt}$ 前导 $\mathrm{mRNA}$ 没有用处。
:::

前导序列的结构特点及其发挥衰减作用的机制如图17-4 所示。前导序列 $\mathrm{L}$ 的结构特点是：①它可以转录生成一段长度为 $162\,\mathrm{nt}$、内含 $4$ 个特殊短序列的前导 $\mathrm{mRNA}$；②其中序列 $1$ 有独立的起始和终止密码子，可翻译成为一个有 $14$ 个氨基酸残基的前导肽，它的第 $10$ 位和第 $11$ 位都是色氨酸残基；③序列 $1$ 和序列 $2$ 间、序列 $2$ 和序列 $3$ 间、序列 $3$ 和序列 $4$ 间存在一些互补序列，可分别形成发夹结构，形成发卡结构的能力依次是 $1/2$ 发夹 $>2/3$ 发夹 $>3/4$ 发夹；④序列 $4$ 的下游有一个连续的 $\mathrm{U}$ 序列，是一个不依赖于 $\rho$ 因子的转录终止信号。

:::definition{label="前导 mRNA 162 nt、四个短序列"}
前导序列 $\mathrm{L}$ 转录生成 $162\,\mathrm{nt}$ 前导 $\mathrm{mRNA}$，内含 $4$ 个特殊短序列。
:::

:::definition{label="前导肽 14 肽、第 10 和 11 位都是色氨酸"}
序列 $1$ 有独立的起始和终止密码子，翻译成 $14$ 个氨基酸残基的前导肽；第 $10$ 位和第 $11$ 位都是色氨酸残基。这是「细胞内色氨酸够不够」被核糖体读出来的位点。
:::

:::definition{label="三对发夹及强弱顺序"}
序列 $1$ 与 $2$、$2$ 与 $3$、$3$ 与 $4$ 之间有互补序列，可分别形成发夹。形成发卡结构的能力：$1/2$ 发夹 $>2/3$ 发夹 $>3/4$ 发夹。
:::

:::definition{label="序列 4 下游的多聚 U 是 ρ 非依赖终止"}
序列 $4$ 下游有连续 $\mathrm{U}$ 序列，是不依赖于 $\rho$ 因子的转录终止信号。第十五章非依赖 $\rho$ 终止（茎环 $+$ 一串 $\mathrm{U}$）在这里被衰减子征用。
:::

:::note{label="电子版缺失"}
图17-4「色氨酸操纵子的结构及其关闭机制」电子版图源 `p0351_01.png`、`p0351_02.png`、`p0351_03.png` 为 $0$ 字节，不嵌入 `src`。三面板以教材图注为准：（a）前导序列的结构特征；（b）$\mathrm{Trp}$ 低浓度时，核糖体停滞在序列 $1$ 上，$2/3$ 发卡形成，转录继续；（c）$\mathrm{Trp}$ 高浓度时，$3/4$ 发卡和多聚 $\mathrm{U}$ 使转录提前终止。同页动画占位亦不嵌入。
:::

:::keypoint{label="四个序列只允许两种「有用」发夹在衰减里出场"}
能力上 $1/2$ 最强，但衰减机制正文用的是：核糖体占序列 $1$ $\rightarrow$ 被迫走 $2/3$（继续转录）；核糖体进到序列 $2$ $\rightarrow$ 走 $3/4+$ 多聚 $\mathrm{U}$（终止）。$1/2$ 最强说明「没有核糖体打扰时序列 $1$、$2$ 会优先配对」，不要把它写成低色氨酸时的终止结构。
:::

:::pitfall{label="14 肽不要记成 162 个氨基酸"}
$162$ 是核苷酸数，$14$ 是前导肽残基数。两个数字对调，第 $10/11$ 位色氨酸会落到不存在的位置。
:::

:::pitfall{label="第 10 和 11 位都是色氨酸，不是只有一位"}
连续两个色氨酸密码子让核糖体在缺 $\mathrm{Trp}$ 时更容易停在序列 $1$。写成「只有第 $10$ 位是色氨酸」，停顿的设计意图会变弱。
:::

转录衰减的机制是：①色氨酸浓度较低时，前导肽的翻译因色氨酸量的不足而停滞在第 $10/11$ 的色氨酸密码子部位，核糖体结合在序列 $1$ 上，因此前导 $\mathrm{mRNA}$ 倾向于形成 $2/3$ 发夹结构，转录继续进行；②色氨酸浓度较高时，前导肽的翻译顺利完成，核糖体可以前进到序列 $2$，因此发夹结构在序列 $3$ 和序列 $4$ 形成，连同其下游的多聚 $\mathrm{U}$ 使得转录中途终止，表现出转录的衰减。原核生物这种在色氨酸浓度高时通过阻遏作用和转录衰减机制共同关闭基因表达的方式，保证了营养物质和能量的合理利用。

:::definition{label="低色氨酸：2/3 发夹，转录继续"}
色氨酸浓度低：前导肽翻译停滞在第 $10/11$ 位色氨酸密码子，核糖体占序列 $1$，前导 $\mathrm{mRNA}$ 倾向形成 $2/3$ 发夹，转录继续进行。
:::

:::definition{label="高色氨酸：3/4 发夹加多聚 U，转录衰减"}
色氨酸浓度高：前导肽翻译顺利完成，核糖体前进到序列 $2$，序列 $3$ 与 $4$ 形成发夹，加上下游多聚 $\mathrm{U}$，转录中途终止。
:::

:::definition{label="阻遏加衰减共同关闭"}
色氨酸浓度高时，阻遏作用和转录衰减共同关闭基因表达，保证营养物质和能量的合理利用。
:::

:::cause-effect{title="核糖体停在序列 1 为什么让转录继续"}
- **因** 核糖体占住序列 1，1/2 发夹做不成，前导 mRNA 改走 2/3 发夹
- **果** 3/4 终止发夹做不成，ρ 非依赖终止信号装配不起来，聚合酶继续抄结构基因
:::

:::cause-effect{title="核糖体走到序列 2 为什么让转录停"}
- **因** 前导肽译完，核糖体进入序列 2，2/3 发夹做不成
- **果** 3 与 4 配对成终止发夹，下游连续 U 生效，转录中途终止
:::

:::compare{title="低 Trp vs 高 Trp（衰减这一层）"}
| | 低色氨酸 | 高色氨酸 |
|--|----------|----------|
| 前导肽 | 停在第 $10/11$ 位 | 顺利译完 |
| 核糖体 | 占序列 $1$ | 前进到序列 $2$ |
| 发夹 | $2/3$ | $3/4$ |
| 多聚 $\mathrm{U}$ | 不作为终止用 | 与 $3/4$ 一起终止 |
| 结构基因 | 继续转录 | 中途终止（衰减） |

阻遏层仍是：高 $\mathrm{Trp}$ 时辅阻遏物复合物占 $\mathrm{O}$。衰减是第二道。
:::

:::pitfall{label="2/3 发夹不是终止结构"}
$2/3$ 对应「转录继续」；$3/4+$ 多聚 $\mathrm{U}$ 才是终止。把 $2/3$ 答成衰减态，低色氨酸时结构基因反而会被写成关掉。
:::

:::pitfall{label="不要把衰减写成依赖 ρ"}
教材写明序列 $4$ 下游连续 $\mathrm{U}$ 是不依赖于 $\rho$ 因子的终止信号。答成 $\rho$ 依赖，第十五章两类终止会在衰减子上缠在一起。
:::

前导序列发挥了随色氨酸浓度升高而降低转录的作用，故将这段序列称为衰减子（attenuator）。在 $\mathrm{trp}$ 操纵子中，阻遏蛋白对结构基因转录的负调节起到粗调的作用，而衰减子起到精调的作用。细菌中其他氨基酸合成系统的操纵子（如 $\mathrm{phe}$、$\mathrm{his}$、$\mathrm{leu}$、$\mathrm{thr}$ 等）中也有类似的衰减调控机制。

:::definition{label="衰减子"}
衰减子（attenuator）：发挥随色氨酸浓度升高而降低转录作用的那段前导序列。
:::

:::definition{label="阻遏粗调、衰减子精调"}
$\mathrm{trp}$ 操纵子中，阻遏蛋白对结构基因转录的负调节是粗调，衰减子是精调。
:::

:::definition{label="其他氨基酸操纵子也有衰减"}
$\mathrm{phe}$、$\mathrm{his}$、$\mathrm{leu}$、$\mathrm{thr}$ 等氨基酸合成系统的操纵子中也有类似的衰减调控机制。不要把衰减写成 $\mathrm{trp}$ 私有。
:::

:::keypoint{label="粗调 vs 精调落在哪一步"}
- 粗调：有没有辅阻遏物复合物占 $\mathrm{O}$，决定起始能不能发生。
- 精调：已经起始的转录，按前导肽翻译状态决定中途停不停。

高色氨酸时两道一起关；低色氨酸时 $\mathrm{O}$ 不被占，且 $2/3$ 发夹让转录继续。
:::

:::memory{label="衰减四句话"}
- 前导 $\mathrm{mRNA}$ $162\,\mathrm{nt}$，四个序列；前导肽 $14$ 残基，第 $10$、$11$ 位都是 $\mathrm{Trp}$。
- 发夹能力 $1/2>2/3>3/4$；终止靠 $3/4+$ 多聚 $\mathrm{U}$（不依赖 $\rho$）。
- 低 $\mathrm{Trp}$：核糖体停在序列 $1$，$2/3$ 发夹，继续转录。
- 高 $\mathrm{Trp}$：核糖体到序列 $2$，$3/4$ 发夹，衰减终止；再加阻遏蛋白粗调。
:::

## 四、原核基因表达在翻译水平受到精细调控

与转录类似，翻译一般在起始和终止阶段受到调节，尤其是起始阶段。翻译起始的调节主要靠调节分子，调节分子可直接或间接决定翻译起始位点能否为核糖体所利用。调节分子可以是蛋白质，也可以是 $\mathrm{RNA}$。

:::definition{label="翻译水平主要调起始"}
翻译一般在起始和终止阶段受调节，尤其是起始。调节分子直接或间接决定翻译起始位点能否为核糖体所利用；调节分子可以是蛋白质，也可以是 $\mathrm{RNA}$。
:::

:::insight{label="第一节「翻译是快速反应」在这里兑现"}
不必先改启动子，蛋白质或 $\mathrm{RNA}$ 挡住起始位点就能立刻少做肽链。下面四种方式都还在原核。
:::

:::pitfall{label="不要把翻译调控写成真核帽结合专属"}
本节四条都是原核实例：自我控制、$\mathrm{S}8$ 阻遏 $\mathrm{L}5$、反义 $\mathrm{RNA}$、稀有密码子。真核帽、扫描是第十六章的账，不要倒灌进来顶替 $\mathrm{SD}$ 序列。
:::

### （一）调节蛋白质作用于自身 mRNA 起始密码子上游序列进行自我调节

无论是单顺反子还是多顺反子 $\mathrm{mRNA}$，许多体系应用了类似的机制，即调节蛋白质结合 $\mathrm{mRNA}$ 靶位点，阻止核糖体识别翻译起始区，从而阻断翻译的机制。调节蛋白质一般作用于自身 $\mathrm{mRNA}$，抑制自身的合成，因而这种调节方式称为自我控制（autogenous control）。细菌 $\mathrm{mRNA}$ 起始密码子上游约 $10$ 个核苷酸之前的 $\mathrm{SD}$ 序列与 $16\mathrm{S}$ $\mathrm{rRNA}$ 序列互补的程度，以及从 $\mathrm{SD}$ 序列到起始密码子 $\mathrm{AUG}$ 之间富含嘌呤片段的长短，也都强烈地影响翻译起始的效率（详见第十六章）。不同基因的 $\mathrm{mRNA}$ 有不同的 $\mathrm{SD}$ 序列，它们与 $16\mathrm{S}$ $\mathrm{rRNA}$ 的结合能力也不同，从而控制着单位时间内翻译过程中起始复合物形成的数目，最终控制着翻译的速度。

:::definition{label="自我控制"}
自我控制（autogenous control）：调节蛋白质结合 $\mathrm{mRNA}$ 靶位点，阻止核糖体识别翻译起始区，从而阻断翻译；调节蛋白质一般作用于自身 $\mathrm{mRNA}$，抑制自身的合成。单顺反子和多顺反子 $\mathrm{mRNA}$ 都可用类似机制。
:::

:::definition{label="SD 序列影响翻译起始效率"}
细菌 $\mathrm{mRNA}$ 起始密码子上游约 $10$ 个核苷酸之前的 $\mathrm{SD}$ 序列，与 $16\mathrm{S}$ $\mathrm{rRNA}$ 互补的程度，以及 $\mathrm{SD}$ 到 $\mathrm{AUG}$ 之间富含嘌呤片段的长短，强烈影响翻译起始效率。不同 $\mathrm{mRNA}$ 的 $\mathrm{SD}$ 不同，与 $16\mathrm{S}$ $\mathrm{rRNA}$ 结合能力不同，从而控制单位时间内起始复合物数目，最终控制翻译速度。
:::

:::pitfall{label="自我控制的靶是 mRNA，不是操纵元件 O"}
转录负性调节结合 $\mathrm{O}$；翻译自我控制结合自身 $\mathrm{mRNA}$ 起始区。把自我控制答成「阻遏蛋白再占一次 $\mathrm{O}$」，层次就退回转录。
:::

:::keypoint{label="SD 这一段只调用第十六章，不新造序列"}
上游约 $10$ 个核苷酸之前、与 $16\mathrm{S}$ $\mathrm{rRNA}$ 互补、嘌呤片段长短影响效率。具体 $-\mathrm{AGGAGG}$- 写法以第十六章为准，本节强调「不同基因不同 $\mathrm{SD}$ $\rightarrow$ 不同翻译速度」。
:::

### （二）翻译阻遏利用蛋白质与 mRNA 起始密码子的结合实现对翻译起始的调控

翻译起始与转录起始相类似，也受调节蛋白质的作用，但与转录不同，$\mathrm{RNA}$ 在翻译起始过程中有重要的作用。编码区的起始点可与调节分子（蛋白质或 $\mathrm{RNA}$）直接或间接地结合来决定翻译起始。在此调控机制中，调节蛋白质可以结合到起始密码子上，阻断与核糖体的结合。例如，$\mathrm{S}8$ 是组成核糖体小亚基的一个蛋白质，可以与 $16\mathrm{S}$ $\mathrm{rRNA}$ 的茎环结构结合；$\mathrm{L}5$ 是组成核糖体大亚基的一个蛋白质，它的 $\mathrm{mRNA}$ 的 $5'$ 末端也能形成一个与 $16\mathrm{S}$ $\mathrm{rRNA}$ 的茎环结构相类似的结构。因此 $\mathrm{S}8$ 也能与 $\mathrm{L}5$ 的 $\mathrm{mRNA}$ 结合。当 $16\mathrm{S}$ $\mathrm{rRNA}$ 含量充足时，可以与所有的 $\mathrm{S}8$ 蛋白结合，不影响 $\mathrm{L}5$ 蛋白质的合成；而当 $16\mathrm{S}$ $\mathrm{rRNA}$ 含量不足时，多余的 $\mathrm{S}8$ 则与 $\mathrm{L}5$ $\mathrm{mRNA}$ 结合，阻遏 $\mathrm{L}5$ 蛋白质的合成，防止 $\mathrm{L}5$ 合成过量。

:::definition{label="翻译阻遏可结合起始密码子"}
调节蛋白质可以结合到起始密码子上，阻断与核糖体的结合。翻译起始也受调节蛋白质作用；与转录不同的是，$\mathrm{RNA}$ 在翻译起始中有重要作用。
:::

:::definition{label="S8 对 L5 mRNA 的翻译阻遏"}
$\mathrm{S}8$：小亚基蛋白质，本职结合 $16\mathrm{S}$ $\mathrm{rRNA}$ 茎环。$\mathrm{L}5$：大亚基蛋白质，其 $\mathrm{mRNA}$ 的 $5'$ 末端可形成类似茎环，故 $\mathrm{S}8$ 也能结合 $\mathrm{L}5$ $\mathrm{mRNA}$。$16\mathrm{S}$ $\mathrm{rRNA}$ 充足时吸走全部 $\mathrm{S}8$，$\mathrm{L}5$ 照常合成；$16\mathrm{S}$ $\mathrm{rRNA}$ 不足时多余 $\mathrm{S}8$ 结合 $\mathrm{L}5$ $\mathrm{mRNA}$，阻遏 $\mathrm{L}5$，防止过量。
:::

:::cause-effect{title="16S rRNA 不足为什么要停 L5"}
- **因** 没有足够 16S rRNA 装配小亚基，继续做大亚基蛋白 L5 会造成组分不配
- **果** 多余 S8 改结合 L5 mRNA，翻译阻遏，L5 不再过量
:::

:::pitfall{label="S8 不是 L5，16S 不是 23S"}
$\mathrm{S}8$ 属小亚基、认 $16\mathrm{S}$ $\mathrm{rRNA}$；$\mathrm{L}5$ 属大亚基。把 $\mathrm{S}8$ 写成大亚基蛋白，茎环模拟就失去「假装 $16\mathrm{S}$」的逻辑。
:::

:::compare{title="16S rRNA 充足 vs 不足"}
| | $16\mathrm{S}$ $\mathrm{rRNA}$ 充足 | $16\mathrm{S}$ $\mathrm{rRNA}$ 不足 |
|--|-------------------------------|--------------------------------|
| $\mathrm{S}8$ 去向 | 与 $16\mathrm{S}$ 茎环结合 | 多余的 $\mathrm{S}8$ 结合 $\mathrm{L}5$ $\mathrm{mRNA}$ |
| $\mathrm{L}5$ 合成 | 不受影响 | 被阻遏，防止过量 |

这是翻译阻遏，不是转录衰减。
:::

### （三）反义 RNA 利用结合 mRNA 翻译起始部位的互补序列调节翻译起始

此外，在一些细菌和病毒中还存在一类调节基因，能够转录产生反义 $\mathrm{RNA}$（antisense RNA）。反义 $\mathrm{RNA}$ 含有与特定 $\mathrm{mRNA}$ 翻译起始部位互补的序列，通过与 $\mathrm{mRNA}$ 杂交阻断 $30\mathrm{S}$ 小亚基对起始密码子的识别及与 $\mathrm{SD}$ 序列的结合，抑制翻译起始。这种调节称为反义控制（antisense control）。反义 $\mathrm{RNA}$ 的调节作用具有非常重要的理论意义和实际意义。

:::definition{label="反义 RNA 与反义控制"}
反义 $\mathrm{RNA}$（antisense RNA）：由一些细菌和病毒的调节基因转录产生，含与特定 $\mathrm{mRNA}$ 翻译起始部位互补的序列，与 $\mathrm{mRNA}$ 杂交，阻断 $30\mathrm{S}$ 小亚基对起始密码子的识别及与 $\mathrm{SD}$ 序列的结合，抑制翻译起始。这种调节称为反义控制（antisense control）。
:::

:::keypoint{label="反义 RNA 挡的是 30S 认 AUG 和 SD"}
杂交位点在翻译起始部位。效果是 $30\mathrm{S}$ 既认不了起始密码子，也结合不了 $\mathrm{SD}$。不要写成「切掉结构基因」或「占操纵元件」。
:::

:::pitfall{label="反义 RNA 不是 miRNA 的原核别名"}
第一节、第五节点名的 $\mathrm{miRNA}$ 是非编码 $\mathrm{RNA}$ 的真核代表。本节反义控制是细菌和病毒里与起始部位互补的 $\mathrm{RNA}$。机制都是 $\mathrm{RNA}$ 调表达，分子不要换牌。
:::

:::compare{title="自我控制 vs 翻译阻遏（S8）vs 反义控制"}
| | 调节分子 | 结合何处 | 结果 |
|--|----------|----------|------|
| 自我控制 | 蛋白质（常为自身产物） | 自身 $\mathrm{mRNA}$ 靶位点／起始区 | 少做自己 |
| $\mathrm{S}8$ 阻遏 $\mathrm{L}5$ | 蛋白质 $\mathrm{S}8$ | $\mathrm{L}5$ $\mathrm{mRNA}$ 上模拟 $16\mathrm{S}$ 的茎环 | $16\mathrm{S}$ 不足时停 $\mathrm{L}5$ |
| 反义控制 | 反义 $\mathrm{RNA}$ | $\mathrm{mRNA}$ 翻译起始部位（杂交） | $30\mathrm{S}$ 不能认 $\mathrm{AUG}$、不能结合 $\mathrm{SD}$ |

蛋白质或 $\mathrm{RNA}$ 都可以当调节分子，靶都是翻译起始能不能被核糖体用。
:::

### （四）mRNA 密码子的编码频率影响翻译速度

遗传密码表显示，除色氨酸和甲硫氨酸外，其他的氨基酸都有 $2$ 个或 $2$ 个以上的遗传密码子。有些是使用频率较高的常用密码子，而有些则是使用频率较低的稀有密码子。当基因中的密码子是常用密码子时，$\mathrm{mRNA}$ 的翻译速度快，反之，$\mathrm{mRNA}$ 的翻译速度慢。大肠埃希菌 $\mathrm{dnaG}$ 基因是引物酶的编码基因，含有较多的稀有密码子，使得 $\mathrm{mRNA}$ 的翻译速度缓慢，防止引物酶合成过多。

:::definition{label="常用密码子快、稀有密码子慢"}
除色氨酸和甲硫氨酸外，其余氨基酸都有 $2$ 个或 $2$ 个以上密码子。常用密码子使翻译快，稀有密码子使翻译慢。
:::

:::definition{label="dnaG 用稀有密码子限制引物酶"}
大肠埃希菌 $\mathrm{dnaG}$ 基因编码引物酶，含较多稀有密码子，$\mathrm{mRNA}$ 翻译缓慢，防止引物酶合成过多。
:::

:::insight{label="这一层不需要额外调节蛋白质"}
编码频率写在 $\mathrm{mRNA}$ 序列里，翻译速度跟着密码子使用习惯走。与阻遏蛋白、反义 $\mathrm{RNA}$ 不同，这是「模板自己限速」。
:::

:::pitfall{label="色氨酸、甲硫氨酸各只有一个密码子，不要写进「2 个或以上」"}
例外写在 $\mathrm{Trp}$ 和 $\mathrm{Met}$。第十六章遗传密码表同一事实。把 $\mathrm{UGG}$、$\mathrm{AUG}$ 也说成简并家族，本节「除……外」就错了。
:::

:::pitfall{label="dnaG 是引物酶基因，不是 DNA 聚合酶全酶"}
教材写明 $\mathrm{dnaG}$ 编码引物酶。稀有密码子限制的是引物酶剂量，不要改成限制整台复制体。
:::

:::compare{title="转录起始控制点 vs 翻译水平四条"}
| 层次 | 本节省下的机制 |
|------|----------------|
| 转录起始（基本控制点） | 操纵子；阻遏蛋白／激活蛋白；$\mathrm{lac}$ 双重调节；$\mathrm{trp}$ 辅阻遏物 |
| 已经起始的转录 | $\mathrm{trp}$ 衰减子（$3/4+$ 多聚 $\mathrm{U}$） |
| 翻译起始 | 自我控制；$\mathrm{S}8$ 阻遏 $\mathrm{L}5$；反义 $\mathrm{RNA}$ |
| 翻译速度 | 常用／稀有密码子（$\mathrm{dnaG}$） |

改变其中任何环节都会改变表达，但原核最重的杠杆仍是转录起始复合物形成的速度。
:::

:::memory{label="本节原核调控一张清单"}
- 基因组：少重复、蛋白质基因连续多单拷贝、结构基因约占 $50\%$、以操纵子排列；转录翻译偶联。
- 操纵子 $=$ 结构基因 $+$ 调控序列 $+$ 调节基因；多顺反子 $\mathrm{mRNA}$。
- 启动子：$-10$ $\mathrm{TATAAT}$（Pribnow），$-35$ $\mathrm{TTGACA}$；共有序列决定活性。
- $\mathrm{O}$ 结合阻遏蛋白 $\rightarrow$ 负性；激活蛋白（$\mathrm{CAP}$）$\rightarrow$ 正性。
- $\mathrm{lac}$：$\mathrm{PI}$-$\mathrm{I}$-$\mathrm{CAP}$-$\mathrm{P}$-$\mathrm{O}$-$\mathrm{Z}$-$\mathrm{Y}$-$\mathrm{A}$；别乳糖／$\mathrm{IPTG}$ 去阻遏（可达 $1\,000$ 倍）；缺葡萄糖时 $\mathrm{cAMP}$-$\mathrm{CAP}$ 提高 $50$ 倍；强诱导要乳糖 $+$ 无葡萄糖；分解代谢阻遏。
- $\mathrm{trp}$：辅阻遏物粗调；衰减子精调；$162\,\mathrm{nt}$、$14$ 肽、第 $10/11$ 位 $\mathrm{Trp}$；低 $\mathrm{Trp}$ 走 $2/3$，高 $\mathrm{Trp}$ 走 $3/4+$ $\mathrm{U}$。
- 翻译：自我控制、$\mathrm{S}8/\mathrm{L}5$、反义控制、$\mathrm{dnaG}$ 稀有密码子。
:::

:::memory{label="两个倍数、两个小分子不要混"}
- $1\,000$ 倍：去阻遏后 $\beta$-半乳糖苷酶分子。
- $50$ 倍：$\mathrm{cAMP}$-$\mathrm{CAP}$ 刺激转录活性。
- 别乳糖／$\mathrm{IPTG}$：诱导剂，针对阻遏蛋白。
- $\mathrm{cAMP}$：针对 $\mathrm{CAP}$；葡萄糖高则 $\mathrm{cAMP}$ 低。
:::
