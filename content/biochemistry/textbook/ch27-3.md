# 第三节　肾的生物化学

第二节把心肌写成以有氧氧化为主、燃料可切换的代谢杂食者，心衰时底物偏好转向、$\mathrm{PCr}/\mathrm{ATP}$ 下降。本节只立「肾的生物化学」：滤过加重吸收维持水电解质和酸碱；空腹可糖异生和生酮；内分泌三条主户是促红细胞生成素、肾素／$\mathrm{RAAS}$ 和 $1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$。$\beta$-羟丁酸抑制组蛋白脱乙酰酶、促心肌肥大基因是第二节的账，不在这里展开。骨骼肌运动供能曲线是第四节。

:::concept{term="先问滤过重吸收和空腹能不能造糖造酮，再问 EPO、肾素、活性维生素 D3"}
看见「肾的生物化学」，先不要默写肾小球旁细胞的氨基酸残基数。户头是：肾通过滤过和重吸收维持水电解质平衡、酸碱平衡并产生尿液；肾小球滤出的葡萄糖和其他可利用代谢物可被重吸收；空腹条件下肾可生成葡萄糖和酮体；肾还分泌激素调节自身和其他器官。把「肾＝只排尿」或「糖异生只有肝」写成开篇，后文近端小管 $\mathrm{SGLT}$、$40\,\mathrm{g}$ 糖异生和 $406\to 340$ 氨基酸都没有底板。
:::

:::note{label="电子版缺失"}
图27-6（近端小管葡萄糖的重吸收过程）电子版缺失，正文保留图号，用散文把顶端侧 $\mathrm{SGLT}$、基底侧 $\mathrm{GLUT}1/\mathrm{GLUT}2$ 写清，不嵌入空图。本节使用的插图是图27-7（肾代谢物与影响肾的身体代谢物间的相互作用示意图：$\mathrm{PTH}$、$1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$、促红细胞生成素、$\mathrm{RAAS}$、$\mathrm{ANP}$、$\mathrm{ADH}$）。图27-5 在第二节；图27-8 起在第四节。
:::

肾属于泌尿系统，是重要的排泄器官。肾通过过滤和重吸收维持机体的水电解质平衡、酸碱平衡并产生尿液。肾还调节全身的物质代谢平衡：一些外源毒物和内源代谢物经肾排出，肾小球滤出的葡萄糖和其他可利用代谢物可被重吸收；空腹条件下肾可生成葡萄糖和酮体等供能物质。肾也是活跃的内分泌器官，通过分泌激素来调节自身和其他器官的功能。

:::definition{label="肾的三本账同时立"}
排泄：滤过加重吸收，维持水电解质、酸碱，产生尿液。代谢：排出毒物和内源代谢物，重吸收可利用底物，空腹可造葡萄糖和酮体。内分泌：分泌激素调节自身和其他器官。三本账不要并成「肾只会形成尿」。
:::

:::keypoint{label="开篇先钉死的四句"}
- 滤过＋重吸收：水电解质、酸碱、尿液。
- 可利用代谢物：葡萄糖等可被重吸收，不是滤出就丢掉。
- 空腹：可糖异生、可生酮。
- 内分泌：肾素／前列腺素／激肽、促红细胞生成素、活性维生素 $\mathrm{D}_{3}$。
:::

:::pitfall{label="不要把第二节的 β-羟丁酸信号写进肾开篇"}
$\beta$-羟丁酸抑制组蛋白脱乙酰酶、抑制促心肌肥大相关基因转录，是心肌节的信号分子账。本节酮体出现在「皮质近端小管饥饿时氧化酮体」和「肾自己诱导 $\mathrm{HMGCS}2$ 生酮」。户头不同，不要把表观遗传那一句抄到文首。
:::

:::compare{title="本章前三节的器官户头"}
| | 主燃料／主功能 | 本节不要写成 |
|--|--------------|-------------|
| 脑（第一节） | 主要利用葡萄糖和酮体；缺糖缺氧降脑功能 | 「肾也主要靠葡萄糖」 |
| 心肌（第二节） | 代谢杂食者；脂肪酸 $40\%\sim 60\%$，葡萄糖约 $20\%\sim 40\%$ | 「肾＝心肌，都叫杂食者」——本版这个名字给成人心肌 |
| 肾（本节） | 皮质近端小管主要氧化脂肪酸（饥饿用酮体）；远端更多糖无氧氧化；空腹可造糖造酮 | 「肾不供能、只滤尿」 |

问「空腹谁还能造糖」才进本节糖异生；问「心衰底物怎么转」回第二节。
:::

## 一、肾利用脂肪酸和葡萄糖供能

肾可利用葡萄糖和脂肪酸作为自身能量来源。生理条件下，皮质近端小管细胞不表达己糖激酶、磷酸果糖激酶和丙酮酸激酶，而髓质的肾单位远端细胞缺乏线粒体，并表达这些糖酵解等糖代谢的关键酶。同时，从肾皮质到髓质的氧供应逐渐减少，因此皮质的近端小管主要利用脂肪酸（饥饿状态下利用酮体）氧化和氧化磷酸化生成 $\mathrm{ATP}$。肾单位远端部分更多地通过糖无氧氧化生成 $\mathrm{ATP}$，导致乳酸生成。

:::definition{label="皮质近端小管不走糖酵解关键酶"}
生理条件下不表达己糖激酶、磷酸果糖激酶和丙酮酸激酶。这三户正是糖酵解的限速酶。写成「近端小管靠糖酵解过日子」，后文「主要氧化脂肪酸」就自相矛盾。
:::

:::definition{label="髓质远端细胞缺线粒体、表达糖酵解酶"}
髓质的肾单位远端细胞缺乏线粒体，却表达己糖激酶、磷酸果糖激酶、丙酮酸激酶。燃料路线被迫偏向糖无氧氧化，产物是乳酸。
:::

:::definition{label="皮质到髓质的氧梯度"}
从肾皮质到髓质，氧供应逐渐减少。皮质近端小管有氧氧化说得通；髓质远端更容易走无氧。氧分压和酶谱是同一条轴上的两面。
:::

:::definition{label="皮质近端小管的燃料"}
主要利用脂肪酸氧化和氧化磷酸化生成 $\mathrm{ATP}$。饥饿状态下改用酮体。户头是「有氧、脂／酮」，不是「皮质也大量产乳酸」。
:::

:::definition{label="远端肾单位产乳酸"}
更多地通过糖无氧氧化生成 $\mathrm{ATP}$，导致乳酸生成。后文糖异生的乳酸可以来自肾自身，底板在这里。
:::

:::compare{title="皮质近端小管 vs 髓质远端"}
| | 线粒体／氧 | 糖酵解关键酶 | 主路 | 不要写成 |
|--|-----------|-------------|------|---------|
| 皮质近端小管 | 氧相对充足 | 不表达己糖激酶、磷酸果糖激酶、丙酮酸激酶 | 脂肪酸（饥饿用酮体）氧化＋氧化磷酸化 | 「近端小管糖酵解产乳酸」 |
| 髓质远端 | 缺线粒体，氧更少 | 表达上述关键酶 | 糖无氧氧化 → 乳酸 | 「远端靠脂肪酸 $\beta$-氧化」 |

小结原句「皮层利用脂肪酸或酮体，肾单位远端部分更多地使用糖酵解」就是这张表。皮层和皮质是同一解剖户，不要另立「脑皮层」。
:::

:::cause-effect{title="氧递减 + 酶谱分区 → 皮质氧化脂／酮，远端产乳酸"}
皮质到髓质氧供应逐渐减少 → 近端小管不表达糖酵解限速酶、走脂肪酸／酮体氧化磷酸化 → 远端缺线粒体、表达糖酵解酶 → 无氧氧化产乳酸。问「为什么近端小管不跟远端抢糖酵解」走酶谱这一户。
:::

:::pitfall{label="肾能用葡萄糖，不等于皮质近端小管靠糖酵解供能"}
开篇「肾可利用葡萄糖和脂肪酸」说的是器官水平。具体到皮质近端小管，生理条件下恰恰不表达三套糖酵解限速酶。葡萄糖进近端小管细胞，主业是重吸收回血，不是就地无氧酵解。
:::

:::insight{label="远端产的乳酸可以成为近端糖异生的原料"}
后文生理条件下肾糖异生主要前体里乳酸占 $50\%$，并写明乳酸可以来自肾自身。远端无氧氧化和皮质近端糖异生是内循环，不是两套无关的代谢。
:::

:::keypoint{label="自身供能三句"}
- 器官：葡萄糖＋脂肪酸都能用。
- 皮质近端：脂肪酸；饥饿改酮体；氧化磷酸化。
- 远端：糖无氧氧化，出乳酸。
:::

## 二、肾具有糖异生和酮体生成的功能

除肝外，肾是糖异生的器官之一。一般情况下肾的糖异生作用较弱，仅占肝糖异生葡萄糖产量的 $10\%$。在应激压力、酸中毒或长期禁食情况下，肾负责约 $40\%\sim 50\%$ 的糖异生。例如饥饿 $5\sim 6$ 周后，肾的糖异生作用大大加强，每天产生葡萄糖约 $40\,\mathrm{g}$，几乎与肝糖异生的量相等。肾糖异生发生在皮质近端小管，糖异生关键酶仅在其 $\mathrm{S}3\sim \mathrm{S}11$ 段表达。生理条件下肾糖异生的主要前体是乳酸（$50\%$）、谷氨酰胺（$20\%$）和甘油（$10\%$）。乳酸可以来自肾自身所产生，还可来自近端小管重吸收清除的血液乳酸。在代谢性酸中毒期间，谷氨酰胺成为糖异生的最重要前体。

肾也可进行酮体合成。在禁食、饥饿或不受控制的糖尿病情况下，肾酮体合成的关键酶线粒体 $\beta$-羟基-$\beta$-甲基戊二酰 $\mathrm{CoA}$ 合成酶 2（3-hydroxy-3-methylglutaryl-CoA synthase 2，$\mathrm{HMGCS}2$）可被诱导表达，生成酮体。

:::definition{label="肾是肝外糖异生器官"}
一般情况下较弱，仅占肝糖异生葡萄糖产量的 $10\%$。户头是「有，但平时份额小」，不是「肾糖异生可以忽略」。
:::

:::definition{label="应激、酸中毒、长期禁食时肾可占糖异生 40%～50%"}
这三种情况把肾从配角抬到约一半。问「长期饥饿谁在维持血糖」不要只答肝。
:::

:::definition{label="饥饿 5～6 周后肾每天约 40 g 葡萄糖"}
几乎与肝糖异生的量相等。本版把「几乎相等」钉在饥饿 $5\sim 6$ 周、每天约 $40\,\mathrm{g}$ 这一笔，不要改成「一饥饿立刻和肝打平」。
:::

:::definition{label="糖异生地点是皮质近端小管"}
发生在皮质近端小管。本版写糖异生关键酶仅在其 $\mathrm{S}3\sim \mathrm{S}11$ 段表达。后文葡萄糖重吸收把近端小管写成 $\mathrm{S}1$、$\mathrm{S}2$、$\mathrm{S}3$ 三段，两套分段用词不要并成一句。
:::

:::definition{label="生理条件下三大前体"}
乳酸 $50\%$、谷氨酰胺 $20\%$、甘油 $10\%$。乳酸来源有二：肾自身产生，以及近端小管重吸收清除的血液乳酸。
:::

:::definition{label="代谢性酸中毒时谷氨酰胺升为最重要前体"}
平时乳酸第一；酸中毒时谷氨酰胺变成最重要。酸碱状态改的是前体排序，不是「酸中毒肾就不会糖异生」。
:::

:::definition{label="肾可生酮，关键酶是 HMGCS2"}
禁食、饥饿或不受控制的糖尿病：线粒体 $\mathrm{HMGCS}2$ 被诱导表达，生成酮体。平时不是肾的主业。
:::

:::compare{title="10%、40%～50%、40 g 三笔不要并"}
| 情境 | 本版数字 | 问的是什么 | 不要写成 |
|------|---------|-----------|---------|
| 一般情况 | 约占肝糖异生产量的 $10\%$ | 平时份额 | 「肾从来只贡献 $10\%$」 |
| 应激／酸中毒／长期禁食 | 约 $40\%\sim 50\%$ | 加压后的份额 | 「一禁食就每天 $40\,\mathrm{g}$」 |
| 饥饿 $5\sim 6$ 周 | 每天约 $40\,\mathrm{g}$，几乎与肝相等 | 极长期饥饿的绝对量 | 「$40\%$ 就是 $40\,\mathrm{g}$」 |

百分数是相对肝或相对全身糖异生的份额，克数是极长期饥饿的日产量。分母不同。
:::

:::compare{title="三大前体 vs 酸中毒"}
| | 乳酸 | 谷氨酰胺 | 甘油 |
|--|------|---------|------|
| 生理条件 | $50\%$，第一 | $20\%$ | $10\%$ |
| 代谢性酸中毒 | 仍可用 | 升为最重要前体 | 仍是甘油，不是主角 |
| 来源提醒 | 自身无氧氧化＋从血重吸收 | 氨基酸／氨代谢那一户 | 脂解来的碳骨架 |

$50\%+20\%+10\%$ 不到 $100\%$，其余前体本版未点名，不要补写成「只这三种」。
:::

:::cause-effect{title="远端产乳酸 / 血乳酸被重吸收 → 皮质近端糖异生"}
远端糖无氧氧化产乳酸，或血液乳酸经近端小管重吸收 → 皮质近端小管以乳酸为主要前体（生理条件下 $50\%$）→ 生成葡萄糖。酸中毒则把谷氨酰胺抬到最前。
:::

:::cause-effect{title="禁食／饥饿／未控制糖尿病 → 诱导 HMGCS2 → 肾生酮"}
葡萄糖来源不足、脂解增强 → 肾诱导线粒体 $\mathrm{HMGCS}2$ → 生成酮体。脑和心肌在特殊情况下吃酮体（第一、二节），原料可以有肾这一户，不要写成「酮体只由肝造」。
:::

:::pitfall{label="10% 不是饥饿 5～6 周的数字"}
$10\%$ 是一般情况下相对肝的份额；$40\%\sim 50\%$ 是应激／酸中毒／长期禁食；$40\,\mathrm{g}$ 是饥饿 $5\sim 6$ 周的日产量。三笔不要对调，也不要和近端小管每天重吸收 $160\sim 180\,\mathrm{g}$ 葡萄糖并成一笔。
:::

:::pitfall{label="S3～S11 不要和 SGLT 的 S1／S2／S3 并户"}
葡萄糖重吸收明确写：$\mathrm{S}1$ 和 $\mathrm{S}2$ 节段 $\mathrm{SGLT}2$ 约 $90\%$，$\mathrm{S}3$ 节段 $\mathrm{SGLT}1$ 约 $10\%$。糖异生关键酶本版另写「$\mathrm{S}3\sim \mathrm{S}11$ 段」。记「发生在皮质近端小管」这一句最稳；不要发明近端小管有十一段，也不要用别的书的分段表覆盖本版用词。
:::

:::insight{label="酸中毒时走谷氨酰胺，同时在排酸"}
谷氨酰胺既是碳骨架，也连着产氨。教材把「代谢性酸中毒期间谷氨酰胺成为最重要前体」写在糖异生段，不是随手换底物。问「酸中毒肾糖异生为何加强」先答前体切换，不要跳到促红细胞生成素。
:::

:::keypoint{label="糖异生和生酮各记三句"}
- 糖异生：平时相对肝 $10\%$；加压后 $40\%\sim 50\%$；极长期饥饿每天约 $40\,\mathrm{g}$。
- 地点：皮质近端小管；前体乳酸／谷氨酰胺／甘油。
- 生酮：禁食、饥饿、未控制糖尿病，诱导 $\mathrm{HMGCS}2$。
:::

## 三、肾可重吸收与排出代谢物

肾可以重吸收部分代谢物，包括葡萄糖和氨基酸。近端小管小管液中的葡萄糖是通过其上皮细胞顶端侧质膜中的 $\mathrm{Na}^{+}$-葡萄糖同向转运体（sodium-glucose transport protein，$\mathrm{SGLT}$）重吸收（图27-6），其中近端小管 $\mathrm{S}1$ 和 $\mathrm{S}2$ 节段的 $\mathrm{SGLT}2$ 负责约 $90\%$ 的葡萄糖重吸收，$\mathrm{S}3$ 节段的 $\mathrm{SGLT}1$ 负责 $10\%$ 的重吸收。随后细胞内葡萄糖依赖细胞内外浓度梯度差异以易化扩散的方式，通过基底侧质膜中的葡萄糖转运蛋白 $\mathrm{GLUT}1$ 和 $\mathrm{GLUT}2$ 转运进入细胞间液或血液中。近端小管每天共吸收 $160\sim 180\,\mathrm{g}$ 过滤后的葡萄糖。

:::note{label="图27-6 电子版缺失"}
近端小管葡萄糖重吸收过程的插图电子版缺失，不嵌入空图。读图应抓住的结构仍按教材正文：顶端侧 $\mathrm{SGLT}$（$\mathrm{S}1/\mathrm{S}2$ 的 $\mathrm{SGLT}2$ 约 $90\%$，$\mathrm{S}3$ 的 $\mathrm{SGLT}1$ 约 $10\%$）把小管液葡萄糖同向运进上皮细胞；基底侧 $\mathrm{GLUT}1$ 和 $\mathrm{GLUT}2$ 按浓度梯度易化扩散送回细胞间液或血液。
:::

:::definition{label="顶端侧靠 SGLT 重吸收葡萄糖"}
$\mathrm{Na}^{+}$-葡萄糖同向转运体在近端小管上皮细胞顶端侧质膜。葡萄糖跟着钠的电化学梯度进细胞，是继发性主动转运，不是「葡萄糖自己漏回去」。
:::

:::definition{label="SGLT2 约 90%，SGLT1 约 10%"}
$\mathrm{S}1$ 和 $\mathrm{S}2$ 节段的 $\mathrm{SGLT}2$ 负责约 $90\%$；$\mathrm{S}3$ 节段的 $\mathrm{SGLT}1$ 负责 $10\%$。主力和收尾不要对调。
:::

:::definition{label="基底侧 GLUT1 和 GLUT2 是易化扩散"}
细胞内葡萄糖依赖细胞内外浓度梯度，经基底侧 $\mathrm{GLUT}1$ 和 $\mathrm{GLUT}2$ 进入细胞间液或血液。顶端是同向主动，基底侧是易化扩散，不要两膜都写成 $\mathrm{SGLT}$。
:::

:::definition{label="每天重吸收 160～180 g 过滤后的葡萄糖"}
近端小管每天共吸收 $160\sim 180\,\mathrm{g}$ 过滤后的葡萄糖。这是滤过负荷被收回的量，不是肾糖异生每天造出来的 $40\,\mathrm{g}$。
:::

和葡萄糖类似，由肾小球滤过的氨基酸和维生素也主要在近端小管被重吸收，利用 $\mathrm{Na}^{+}$ 的电化学梯度差异通过继发性主动方式重吸收，需要多种类型氨基酸转运体等的参与。此外，在低血浆浓度下，滤过后的酮体在近端小管通过 $\mathrm{Na}^{+}$ 偶联单羧酸转运蛋白 1 和 2（$\mathrm{SMCT}$）完全重吸收，如果超过其转运能力会发生酮尿症。在长期饥饿中，肾对酮体的重吸收能力增强，可节省约 $225\,\mathrm{kcal/d}$ 的热量。

:::definition{label="氨基酸和维生素也走近端小管继发性主动转运"}
利用 $\mathrm{Na}^{+}$ 电化学梯度，多种氨基酸转运体参与。户头与葡萄糖相同：「滤过之后再收回」，不是「氨基酸不被滤过」。
:::

:::definition{label="低血浆浓度下酮体经 SMCT 完全重吸收"}
近端小管 $\mathrm{Na}^{+}$ 偶联单羧酸转运蛋白 1 和 2（$\mathrm{SMCT}$）。超过转运能力才酮尿。长期饥饿时重吸收能力增强，可节省约 $225\,\mathrm{kcal/d}$。
:::

:::pitfall{label="酮尿不等于肾不会重吸收酮体"}
低浓度时完全重吸收；超过 $\mathrm{SMCT}$ 能力才出现酮尿。未控制糖尿病血酮升高，才容易打穿这道阈值。写成「酮体一律从尿丢掉」，长期饥饿节省 $225\,\mathrm{kcal/d}$ 那一句就没了。
:::

:::insight{label="225 kcal/d 是饥饿时把酮体收回来的热量账"}
第一节成人饥饿时脑重新用酮体，第二节心肌也能用酮体。肾在长期饥饿中加强对酮体的重吸收，等于少丢燃料。数字按本版 $225\,\mathrm{kcal/d}$，不要改成别的教材的估算。
:::

肾还可以滤过并重吸收体内产生的一些其他代谢物，包括碳酸氢盐（$\mathrm{HCO}_{3}^{-}$）、$\mathrm{NH}_{3}$、尿素、乳酸、尿酸。肌酐可通过肾小球滤过，少量被肾小管和集合管分泌和重吸收。一些药物或代谢物如青霉素、酚红、部分利尿剂、有机碱、胆碱和组胺等不能被肾小球滤过，但可在近端小管被主动分泌进入小管液中而被排出体外。

:::definition{label="还可重吸收的内源代谢物"}
碳酸氢盐、$\mathrm{NH}_{3}$、尿素、乳酸、尿酸。乳酸既是糖异生前体，也是可以被重吸收的滤过物，两本账不要并成「乳酸只供糖异生」。
:::

:::definition{label="肌酐：滤过为主，分泌和重吸收都少量"}
肾小球滤过；肾小管和集合管有少量分泌和重吸收。临床把血肌酐近似当成滤过标志，教材仍写了「少量分泌和重吸收」，不要绝对化成「完全不被肾小管处理」。
:::

:::definition{label="不能滤过的药物可被近端小管主动分泌"}
青霉素、酚红、部分利尿剂、有机碱、胆碱和组胺等不能被肾小球滤过，但可在近端小管被主动分泌进入小管液排出。排出不等于「先滤过再丢掉」。
:::

:::compare{title="葡萄糖重吸收的两膜"}
| 膜 | 蛋白 | 方式 | 本版份额／去向 | 不要写成 |
|--|------|------|--------------|---------|
| 顶端侧（管腔面） | $\mathrm{SGLT}2$（$\mathrm{S}1/\mathrm{S}2$）、$\mathrm{SGLT}1$（$\mathrm{S}3$） | $\mathrm{Na}^{+}$ 同向，继发性主动 | 约 $90\%$ vs $10\%$ | 「基底侧也是 SGLT」 |
| 基底侧 | $\mathrm{GLUT}1$、$\mathrm{GLUT}2$ | 易化扩散，靠浓度梯度 | 进入细胞间液或血液 | 「GLUT 在管腔面把糖泵进去」 |

每天 $160\sim 180\,\mathrm{g}$ 是两膜接力之后的回收总量。
:::

:::compare{title="滤过、重吸收、分泌三户"}
| | 本版例子 | 不要写成 |
|--|---------|---------|
| 滤过后再重吸收 | 葡萄糖、氨基酸、维生素、低浓度酮体、$\mathrm{HCO}_{3}^{-}$、尿素、乳酸、尿酸 | 「滤过＝排出」 |
| 滤过，少量分泌和重吸收 | 肌酐 | 「肌酐完全不被肾小管碰」 |
| 不能滤过、近端小管主动分泌 | 青霉素、酚红、部分利尿剂、有机碱、胆碱、组胺 | 「这些分子先被肾小球滤出」 |

问「青霉素怎么进尿」走分泌；问「血糖为什么平时没有糖尿」走 $\mathrm{SGLT}$ 重吸收。
:::

:::timeline{period="近端小管收回葡萄糖的顺序"}
- **肾小球滤过** 葡萄糖进入小管液
- **S1／S2 顶端 SGLT2** 收回约 90%
- **S3 顶端 SGLT1** 再收回约 10%
- **基底侧 GLUT1／GLUT2** 易化扩散回细胞间液或血液
- **全日合计** 吸收 160～180 g 过滤后的葡萄糖
:::

:::cause-effect{title="超过 SGLT 或 SMCT 能力 → 糖尿或酮尿"}
滤过负荷过大或转运体饱和 → 葡萄糖留在小管液成为糖尿，酮体留在小管液成为酮尿。阈值在转运能力，不在「肾不认识这两种分子」。
:::

:::pitfall{label="160～180 g 不是糖异生 40 g"}
$160\sim 180\,\mathrm{g}$ 是每天从滤液收回的葡萄糖；$40\,\mathrm{g}$ 是饥饿 $5\sim 6$ 周时肾糖异生的日产量。一个是重吸收，一个是新生成。
:::

:::pitfall{label="不要把脑的 GLUT 表抄进近端小管"}
第一节 $\mathrm{GLUT}1$ 的 $55\,\mathrm{kDa}/45\,\mathrm{kDa}$、$\mathrm{GLUT}3$、$\mathrm{GLUT}4$ 是脑的户。本节基底侧是 $\mathrm{GLUT}1$ 和 $\mathrm{GLUT}2$，顶端是 $\mathrm{SGLT}$。写成「肾靠 GLUT3 重吸收葡萄糖」就串章了。
:::

:::keypoint{label="重吸收先记葡萄糖，再记酮体和分泌"}
- 顶端 $\mathrm{SGLT}2$ 约 $90\%$、$\mathrm{SGLT}1$ 约 $10\%$；基底侧 $\mathrm{GLUT}1/\mathrm{GLUT}2$。
- 每天 $160\sim 180\,\mathrm{g}$；图27-6 电子版缺失。
- 酮体走 $\mathrm{SMCT}$；超能力酮尿；长期饥饿增强重吸收，约 $225\,\mathrm{kcal/d}$。
- 青霉素等靠近端小管主动分泌，不靠滤过。
:::

## 四、肾代谢物对其他器官的功能具有广泛影响

肾通过分泌肾素、前列腺素、激肽调节血压和体液，通过分泌促红细胞生成素调节红细胞生成，通过生成 $1,25$-二羟维生素 $\mathrm{D}_{3}$ 调节矿物代谢（图27-7）。

:::definition{label="肾的内分泌三块"}
体液和血压：肾素、前列腺素、激肽。红细胞：促红细胞生成素。矿物代谢：活性维生素 $\mathrm{D}_{3}$。后文身体其他器官的 $\mathrm{ANP}$、$\mathrm{ADH}$、醛固酮是「别人来调肾」，和这三块「肾对外分泌」不要并成一张箭头。
:::

### （一）肾素、激肽、前列腺素调节体液和血压

肾素的合成由三种机制诱导：①传入小动脉中的压力感受器感知到动脉血压下降；②致密斑感知原尿中氯化钠浓度降低；以及③增加的儿茶酚胺激活肾小球旁细胞上的 $\beta$-肾上腺素能受体。受到刺激后，肾小球旁细胞首先合成肾素的前体肾素原，含 $406$ 个氨基酸残基的肾素原可在肾中被神经内分泌转化酶 1（neuroendocrine convertase 1）或组织蛋白酶 $\mathrm{B}$ 水解激活，生成含有 $340$ 个氨基酸残基活性形式的肾素。

:::definition{label="诱导肾素合成的三种机制"}
传入小动脉压力感受器感知动脉血压下降；致密斑感知原尿氯化钠浓度降低；儿茶酚胺激活肾小球旁细胞 $\beta$-肾上腺素能受体。三户都指向「要保压、保钠」，不要只记血压那一户。
:::

:::definition{label="肾素原 406 氨基酸，活性肾素 340 氨基酸"}
肾小球旁细胞先合成前体肾素原，含 $406$ 个氨基酸残基；在肾中被神经内分泌转化酶 1 或组织蛋白酶 $\mathrm{B}$ 水解激活，生成含 $340$ 个氨基酸残基的活性肾素。本版就用这两个数字，不要换成别的残基数。
:::

:::timeline{period="从刺激到活性肾素"}
- **三种刺激** 入球小动脉低压、致密斑低氯化钠、儿茶酚胺激动 β 受体
- **肾小球旁细胞** 先合成肾素原（406 个氨基酸残基）
- **神经内分泌转化酶 1 或组织蛋白酶 B** 在肾内水解激活
- **活性肾素** 340 个氨基酸残基，进入 RAAS
:::

:::pitfall{label="406 是前体，340 是活性形式，不要对调"}
残基少的是切过的活性肾素，不是「活性形式更长」。酶是神经内分泌转化酶 1 或组织蛋白酶 $\mathrm{B}$，不要写成肾自己用血管紧张素转换酶去切肾素原。
:::

:::pitfall{label="三种诱导不要并成「只看血压」"}
血压下降、原尿氯化钠下降、儿茶酚胺，是并列的三套感受。写成「只有低血压才分泌肾素」，致密斑和 $\beta$ 受体两户就被删了。
:::

肾素（renin）是肾素–血管紧张素–醛固酮系统（renin-angiotensin-aldosterone system，$\mathrm{RAAS}$）的关键激活剂。肾素将血管紧张素原切割为血管紧张素 $\mathrm{I}$，然后血管紧张素 $\mathrm{I}$ 在血管紧张素转换酶作用下转化为血管紧张素Ⅱ。血管紧张素Ⅱ是一种多功能效应分子，具有内分泌／自分泌／旁分泌作用，调节几乎所有系统，是盐、细胞外液容量和血压的基本控制器。血管紧张素Ⅱ引起小动脉血管收缩，促进肾上腺皮质合成和分泌醛固酮，导致抗利尿激素（$\mathrm{ADH}$）生成，增加钠的重吸收和水潴留，从而升高血压。

:::definition{label="肾素是 RAAS 的关键激活剂"}
把血管紧张素原切割为血管紧张素 $\mathrm{I}$。后续血管紧张素转换酶把血管紧张素 $\mathrm{I}$ 变成血管紧张素Ⅱ。肾素不直接收缩血管。
:::

:::definition{label="血管紧张素Ⅱ是盐、细胞外液容量和血压的基本控制器"}
多功能效应分子，内分泌／自分泌／旁分泌都有，调节几乎所有系统。本版用「基本控制器」这句，不要缩成「只收缩入球小动脉」。
:::

:::definition{label="血管紧张素Ⅱ升压的四步"}
小动脉血管收缩；促进肾上腺皮质合成和分泌醛固酮；导致 $\mathrm{ADH}$ 生成；增加钠重吸收和水潴留。四步一起升高血压。
:::

:::cause-effect{title="肾素 → 血管紧张素 I → 血管紧张素Ⅱ → 升压"}
活性肾素切割血管紧张素原 → 血管紧张素 $\mathrm{I}$ → 血管紧张素转换酶 → 血管紧张素Ⅱ → 缩血管、醛固酮、$\mathrm{ADH}$、保钠保水 → 血压升高。问「$\mathrm{ACE}$ 抑制剂挡的是哪一步」走中间那一刀，不是挡肾素原的水解。
:::

:::compare{title="RAAS 链条上谁切谁"}
| 分子 | 残基／角色 | 下一刀 | 不要写成 |
|------|-----------|--------|---------|
| 肾素原 | $406$ 个氨基酸残基，前体 | 神经内分泌转化酶 1 或组织蛋白酶 $\mathrm{B}$ | 「血管紧张素转换酶激活肾素原」 |
| 活性肾素 | $340$ 个氨基酸残基 | 切血管紧张素原 → 血管紧张素 $\mathrm{I}$ | 「肾素直接生成醛固酮」 |
| 血管紧张素 $\mathrm{I}$ | 十肽级中间物（本版不写残基数） | 血管紧张素转换酶 → 血管紧张素Ⅱ | 「血管紧张素Ⅰ已经缩血管」 |
| 血管紧张素Ⅱ | 多功能效应分子 | 缩血管、促醛固酮、促 $\mathrm{ADH}$、保钠保水 | 「血管紧张素Ⅱ就是肾素」 |

第二节心衰适应性改变点名 $\mathrm{RAAS}$，那是心肌节的病理名单；本节才把肾自己怎么生成肾素写全。
:::

肾存在活跃的激肽释放酶–激肽系统（kallikrein-kinin system，$\mathrm{KKS}$）。激肽释放酶是丝氨酸蛋白酶，可将激肽原（kininogen）水解为激肽（kinin）。肾的激肽释放酶具备活性，而其他组织的激肽释放酶需要激活才能发挥作用。激肽原是血浆中的一种 $\alpha_{2}$ 球蛋白，主要由肝和肾产生。激肽是一组多肽，是在缓激肽（bradykinin，$\mathrm{BK}$）的 9 肽结构基础上的系列修饰物，包括缓激肽（$\mathrm{BK}$）、赖氨酸缓激肽（$\mathrm{Lys}$-$\mathrm{BK}$）和蛋氨酰赖氨酰缓激肽（$\mathrm{Met}$-$\mathrm{Lys}$-$\mathrm{BK}$）。激肽通过结合靶细胞上的激肽受体（bradykinin receptor，$\mathrm{BR}$）发挥作用，结合激肽 $\mathrm{B}1$ 受体后促进靶细胞合成释放前列环素（$\mathrm{PGI}_{2}$），引起血管平滑肌细胞舒张，激活激肽 $\mathrm{B}2$ 受体刺激 $\mathrm{PGI}_{2}$ 和 $\mathrm{NO}$ 释放，引起血管强烈舒张，参与局部组织血流的调节。此外，激肽还与凝血系统、纤维蛋白溶解系统和补体系统等相互作用，参与炎症和疼痛的产生。

:::definition{label="肾的 KKS 处于已激活状态"}
激肽释放酶是丝氨酸蛋白酶，切激肽原得到激肽。肾的激肽释放酶本身具备活性；其他组织的激肽释放酶需要先激活。户头是「肾这一套随时能用」。
:::

:::definition{label="激肽原是 α2 球蛋白"}
血浆中的 $\alpha_{2}$ 球蛋白，主要由肝和肾产生。不要写成「只由肝造、肾只负责酶」。
:::

:::definition{label="激肽以缓激肽 9 肽为骨架"}
包括缓激肽（$\mathrm{BK}$）、赖氨酸缓激肽（$\mathrm{Lys}$-$\mathrm{BK}$）、蛋氨酰赖氨酰缓激肽（$\mathrm{Met}$-$\mathrm{Lys}$-$\mathrm{BK}$）。本版三种都记名字，不要只留 $\mathrm{BK}$。
:::

:::definition{label="B1 出 PGI2，B2 出 PGI2 和 NO"}
$\mathrm{B}1$ 受体：促进靶细胞合成释放前列环素，血管平滑肌舒张。$\mathrm{B}2$ 受体：刺激 $\mathrm{PGI}_{2}$ 和 $\mathrm{NO}$ 释放，血管强烈舒张，参与局部血流调节。开篇「前列腺素」主要落在这一户的 $\mathrm{PGI}_{2}$，不是另写一条独立的前列腺素合成长路。
:::

:::definition{label="激肽还参与炎症和疼痛"}
与凝血、纤维蛋白溶解、补体系统相互作用。舒张血管不是激肽的唯一账。
:::

:::compare{title="RAAS 升压 vs KKS 舒张"}
| | 关键酶 | 活性肽 | 血管 | 不要写成 |
|--|--------|--------|------|---------|
| $\mathrm{RAAS}$ | 肾素（再加血管紧张素转换酶） | 血管紧张素Ⅱ | 小动脉收缩，保钠保水升压 | 「激肽也升压」 |
| $\mathrm{KKS}$ | 激肽释放酶 | 缓激肽及其修饰物 | $\mathrm{PGI}_{2}/\mathrm{NO}$ 介导舒张 | 「肾素直接出前列环素」 |

问「肾怎么既保压又调局部血流」——全身盐压走 $\mathrm{RAAS}$，局部舒张走 $\mathrm{KKS}$。两套并存，不是互相替代。
:::

:::pitfall{label="肾的激肽释放酶不要写成「也需要激活」"}
教材特意对比：肾的酶具备活性，其他组织的酶需要激活。写成「全身激肽释放酶都要先激活」，肾作为活跃 $\mathrm{KKS}$ 器官的特殊性就没了。
:::

:::insight{label="B1 和 B2 都出 PGI2，B2 多一个 NO"}
前列环素是两受体的交集；强烈舒张和局部血流调节点名 $\mathrm{B}2$ 的 $\mathrm{NO}$。不要把 $\mathrm{NO}$ 写到 $\mathrm{B}1$ 头上，也不要把第二节心肌局部调节的 $\mathrm{NO}$／腺苷和本节激肽 $\mathrm{B}2$ 并成一句。
:::

### （二）促红细胞生成素调节红细胞生成

促红细胞生成素（$\mathrm{EPO}$）是一种 $34\,\mathrm{kDa}$ 大小的多肽激素，肾是合成 $\mathrm{EPO}$ 的主要器官，缺氧诱导 $\mathrm{EPO}$ 合成。$\mathrm{EPO}$ 作用于骨髓中的干细胞并增加血红蛋白和红细胞的生成。慢性肾衰竭时 $\mathrm{EPO}$ 生成减少，导致正常红细胞数量减少。注射人工合成的 $\mathrm{EPO}$ 可纠正慢性肾病患者的贫血并减少输血。

:::definition{label="EPO 是 34 kDa 多肽，肾是主要合成器官"}
缺氧诱导合成。主要器官不是唯一器官，但本版把肾写成主户。
:::

:::definition{label="EPO 的靶细胞是骨髓干细胞"}
增加血红蛋白和红细胞生成。户头在造血，不在近端小管重吸收葡萄糖。
:::

:::definition{label="慢性肾衰竭贫血可补人工 EPO"}
慢性肾衰竭时 $\mathrm{EPO}$ 生成减少 → 正常红细胞数量减少。注射人工合成的 $\mathrm{EPO}$ 可纠正慢性肾病患者的贫血并减少输血。
:::

:::cause-effect{title="缺氧 → 肾合成 EPO → 骨髓造血"}
氧不足 → 肾诱导 $\mathrm{EPO}$ → 骨髓干细胞增加血红蛋白和红细胞 → 携氧能力回升。慢性肾衰竭把中间这一步砍掉，贫血就来了。
:::

:::pitfall{label="慢性肾病贫血不要先写成缺铁"}
本版这一户的机制是 $\mathrm{EPO}$ 生成减少。缺铁可以并存，但教材在这里点名的治疗是人工 $\mathrm{EPO}$、减少输血，不是先补铁。
:::

:::compare{title="EPO vs 肾素：都是肾分泌，靶完全不同"}
| | 诱导 | 靶 | 临床 | 不要写成 |
|--|------|----|------|---------|
| $\mathrm{EPO}$（$34\,\mathrm{kDa}$） | 缺氧 | 骨髓干细胞，造红细胞 | 慢性肾衰贫血，人工 $\mathrm{EPO}$ | 「$\mathrm{EPO}$ 升血压」 |
| 肾素（活性 $340$ 氨基酸） | 低压、低氯化钠、儿茶酚胺 | $\mathrm{RAAS}$，管盐和血压 | 心衰适应性改变在第二节点名 | 「肾素刺激骨髓」 |

图27-7 右侧上角是促红细胞生成素 → 红细胞生成，和肾素 → $\mathrm{RAAS}$ 是两条箭。
:::

### （三）活化维生素 D3 调节钙磷代谢

维生素 $\mathrm{D}_{3}$ 是一种激素原，由皮肤中的 $7$-脱氢胆固醇经阳光中的紫外线照射后合成。维生素 $\mathrm{D}_{3}$ 经羟化修饰后活化，首先在肝中被羟化产生 $25$-羟维生素 $\mathrm{D}_{3}$（$25\textrm{-}\mathrm{OH}\textrm{-}\mathrm{D}_{3}$），$25$-羟维生素 $\mathrm{D}_{3}$ 进一步在肾近端小管被 $1\alpha$-羟化酶羟化修饰生成 $1,25$-二羟维生素 $\mathrm{D}_{3}$（$1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$）。活化的维生素 $\mathrm{D}_{3}$ 在肠、甲状旁腺、骨骼和肾等器官调节钙磷代谢稳态。甲状旁腺激素（$\mathrm{PTH}$）可激活 $1\alpha$-羟化酶产生活性 $1,25$-二羟维生素 $\mathrm{D}_{3}$，同时 $1,25$-二羟维生素 $\mathrm{D}_{3}$ 与甲状旁腺中的特定受体结合抑制 $\mathrm{PTH}$ 释放，形成负反馈调节。在慢性肾病患者中，肾羟化 $25$-羟维生素 $\mathrm{D}_{3}$ 的活性降低，导致继发性甲状旁腺功能亢进，通过刺激甲状旁腺激素分泌促进肾远曲小管和集合管对钙的重吸收，活化肾 $1\alpha$-羟化酶，来维持钙磷代谢稳态。

:::definition{label="维生素 D3 是激素原"}
皮肤 $7$-脱氢胆固醇经紫外线照射合成。本身还不是活性激素，要经两步羟化。
:::

:::definition{label="先肝 25-羟化，再肾 1α-羟化"}
肝：维生素 $\mathrm{D}_{3}$ → $25\textrm{-}\mathrm{OH}\textrm{-}\mathrm{D}_{3}$。肾近端小管 $1\alpha$-羟化酶：$25\textrm{-}\mathrm{OH}\textrm{-}\mathrm{D}_{3}$ → $1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$。活性形式是 $1,25$，不是 $25$。
:::

:::definition{label="活性维生素 D3 的靶器官"}
肠、甲状旁腺、骨骼和肾，调节钙磷代谢稳态。不要写成「只作用于骨」。
:::

:::definition{label="PTH 与 1,25-(OH)2-D3 负反馈"}
$\mathrm{PTH}$ 激活 $1\alpha$-羟化酶，增加活性 $1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$；活性维生素 $\mathrm{D}_{3}$ 结合甲状旁腺受体抑制 $\mathrm{PTH}$ 释放。图27-7 左侧 $\mathrm{PTH}$、$25\textrm{-}\mathrm{OH}\textrm{-}\mathrm{D}_{3}$、$1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$、钙和磷酸盐重吸收就是这一圈。
:::

:::definition{label="慢性肾病继发性甲状旁腺功能亢进"}
肾羟化 $25\textrm{-}\mathrm{OH}\textrm{-}\mathrm{D}_{3}$ 的活性降低 → 继发性甲状旁腺功能亢进 → $\mathrm{PTH}$ 促进远曲小管和集合管钙重吸收，并活化肾 $1\alpha$-羟化酶，试图维持钙磷稳态。
:::

:::timeline{period="维生素 D3 活化和反馈"}
- **皮肤** 7-脱氢胆固醇经紫外线生成维生素 D3（激素原）
- **肝** 羟化成 25-OH-D3
- **肾近端小管 1α-羟化酶** 生成 1,25-(OH)2-D3
- **肠、甲状旁腺、骨骼、肾** 调节钙磷
- **负反馈** 活性形式抑制 PTH；PTH 反过来激活 1α-羟化酶
:::

:::cause-effect{title="肾 1α-羟化下降 → 继发性甲旁亢"}
慢性肾病 → 肾羟化 $25\textrm{-}\mathrm{OH}\textrm{-}\mathrm{D}_{3}$ 活性降低 → 活性维生素 $\mathrm{D}_{3}$ 不足 → $\mathrm{PTH}$ 代偿性升高 → 远曲小管和集合管多收钙、再尝试活化 $1\alpha$-羟化酶。和慢性肾病 $\mathrm{EPO}$ 减少致贫血是两条并发症，不要并成「肾衰就是缺维生素 $\mathrm{D}$」。
:::

:::compare{title="25-OH-D3 vs 1,25-(OH)2-D3"}
| | 哪里做 | 是不是活性形式 | 不要写成 |
|--|--------|--------------|---------|
| $25\textrm{-}\mathrm{OH}\textrm{-}\mathrm{D}_{3}$ | 肝 | 中间物 | 「肝已经做出活性维生素 D」 |
| $1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$ | 肾近端小管 $1\alpha$-羟化酶 | 活性形式 | 「皮肤紫外线直接生成 1,25」 |

图27-7 在肾轮廓里画了 $25\textrm{-}\mathrm{OH}\textrm{-}\mathrm{D}_{3}$ 向下变成 $1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$，蓝箭回骨骼。
:::

:::compare{title="慢性肾病两户：贫血 vs 矿物"}
| | 缺的是 | 下游 | 教材点名的代偿／治疗 |
|--|--------|------|------------------|
| 造血 | $\mathrm{EPO}$ 减少 | 红细胞减少 | 人工 $\mathrm{EPO}$，减少输血 |
| 矿物 | $1\alpha$-羟化下降 | 继发性甲旁亢 | $\mathrm{PTH}$ 促远曲小管／集合管收钙，活化 $1\alpha$-羟化酶 |

都是「肾这个内分泌器官坏了」，激素完全不同。
:::

:::pitfall{label="钙重吸收增加不要写成近端小管 SGLT 那一户"}
继发性甲旁亢时，$\mathrm{PTH}$ 促进的是远曲小管和集合管对钙的重吸收。葡萄糖走近端小管 $\mathrm{SGLT}$。节段和底物都不同。
:::

:::insight{label="图27-7 左侧 PTH 还有磷酸盐重吸收下降"}
$\mathrm{PTH}$ 在肾侧：钙重吸收↑、磷酸盐重吸收↓。只记「保钙」会漏掉排磷。骨骼代谢那支蓝箭是活性维生素 $\mathrm{D}_{3}$ 和 $\mathrm{PTH}$ 共同指向的外周。
:::

此外，肾也受到身体其他器官产生的代谢物或激素的调控（图27-7）。例如，心房利尿钠肽（atrial natriuretic peptide，$\mathrm{ANP}$）由心房肌细胞合成并释放，使血管平滑肌舒张和促进肾排钠、排水。抗利尿激素（antidiuretic hormone，$\mathrm{ADH}$）又称升压素（vasopressin），是下丘脑–垂体控制释放的 9 肽激素，其主要作用是提高肾集合管对水的通透性，促进水的吸收，是尿液浓缩和稀释的关键调节激素。肾素–血管紧张素–醛固酮系统激活产生的醛固酮（aldosterone）主要作用于肾，促进水和 $\mathrm{Na}^{+}$ 的重吸收，同时排出 $\mathrm{K}^{+}$，调节水盐平衡。

:::definition{label="ANP 来自心房肌，促肾排钠排水"}
心房肌细胞合成并释放。效应：血管平滑肌舒张，肾排钠、排水。图27-7 右侧 $\mathrm{ANP}$ 指向「尿钠排出」，和醛固酮保钠相反。
:::

:::definition{label="ADH 是下丘脑-垂体释放的 9 肽"}
又称升压素。主要作用：提高集合管对水的通透性，促进水吸收，是尿液浓缩和稀释的关键调节激素。图27-7 左侧 $\mathrm{ADH}$ 指向水重吸收↑，并连到血压↑。
:::

:::definition{label="醛固酮促水钠重吸收、排钾"}
$\mathrm{RAAS}$ 的下游，主要作用于肾。保 $\mathrm{Na}^{+}$、保水、排 $\mathrm{K}^{+}$。图27-7 醛固酮指向 $\mathrm{Na}^{+}$ 重吸收↑、$\mathrm{K}^{+}$ 分泌↑，再回到血压↑。
:::

:::compare{title="三种外来／下游激素怎么动肾"}
| | 来源 | 肾上做什么 | 对血压／容量 | 不要写成 |
|--|------|-----------|-------------|---------|
| $\mathrm{ANP}$ | 心房肌 | 排钠、排水；外周还舒张血管 | 减容、减压方向 | 「$\mathrm{ANP}$ 保钠」 |
| $\mathrm{ADH}$ | 下丘脑–垂体，9 肽 | 集合管加水通透性 | 保水，连到升压 | 「$\mathrm{ADH}$ 就是醛固酮」 |
| 醛固酮 | $\mathrm{RAAS}$ 下游，肾上腺皮质 | 水、$\mathrm{Na}^{+}$ 重吸收，$\mathrm{K}^{+}$ 排出 | 保盐保水升压 | 「醛固酮主要造红细胞」 |

$\mathrm{ANP}$ 是「别人来让肾丢钠」；醛固酮和 $\mathrm{ADH}$ 是「让肾留住水和盐」。图27-7 把三支箭都画在肾轮廓和外周之间。
:::

:::pitfall{label="ADH 的 9 肽不要和缓激肽的 9 肽并成一种激素"}
$\mathrm{ADH}$ 是下丘脑–垂体控制释放的 9 肽；缓激肽也是 9 肽骨架。残基数相同，来源、受体、效应都不同。
:::

:::pitfall{label="不要把脂肪组织的瘦素、弓状核写进肾"}
瘦素和弓状核是第五节脂肪组织的账。本节外周来的调控是 $\mathrm{PTH}$、$\mathrm{ANP}$、$\mathrm{ADH}$、醛固酮。写成「肾靠瘦素调节水盐」，图27-7 就读错了。
:::

:::memory{label="本节必背分户"}
- 滤过＋重吸收维持水电解质和酸碱；空腹可糖异生和生酮；内分泌：$\mathrm{EPO}$、肾素／$\mathrm{RAAS}$、$1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$。
- 皮质近端小管不表达己糖激酶、磷酸果糖激酶、丙酮酸激酶，主要氧化脂肪酸（饥饿用酮体）；远端缺线粒体，糖无氧氧化产乳酸。
- 糖异生：平时相对肝 $10\%$；应激／酸中毒／长期禁食约 $40\%\sim 50\%$；饥饿 $5\sim 6$ 周每天约 $40\,\mathrm{g}$。前体乳酸 $50\%$、谷氨酰胺 $20\%$、甘油 $10\%$；酸中毒时谷氨酰胺最重要。生酮诱导 $\mathrm{HMGCS}2$。
- 葡萄糖：顶端 $\mathrm{SGLT}2$ 约 $90\%$（$\mathrm{S}1/\mathrm{S}2$）、$\mathrm{SGLT}1$ 约 $10\%$（$\mathrm{S}3$）；基底侧 $\mathrm{GLUT}1/\mathrm{GLUT}2$；每天 $160\sim 180\,\mathrm{g}$。图27-6 电子版缺失。
- 酮体经 $\mathrm{SMCT}$ 重吸收；超能力酮尿；长期饥饿增强重吸收，约 $225\,\mathrm{kcal/d}$。青霉素等靠近端小管主动分泌。
- 肾素原 $406$ 氨基酸 → 活性肾素 $340$ 氨基酸（神经内分泌转化酶 1 或组织蛋白酶 $\mathrm{B}$）。三种诱导：入球低压、致密斑低氯化钠、儿茶酚胺 $\beta$ 受体。
- $\mathrm{RAAS}$：肾素切血管紧张素原 → 血管紧张素 $\mathrm{I}$ → 转换酶 → 血管紧张素Ⅱ → 缩血管、醛固酮、$\mathrm{ADH}$、保钠保水。$\mathrm{KKS}$：肾激肽释放酶已有活性；$\mathrm{B}1$ 出 $\mathrm{PGI}_{2}$，$\mathrm{B}2$ 出 $\mathrm{PGI}_{2}$ 和 $\mathrm{NO}$。
- $\mathrm{EPO}$：$34\,\mathrm{kDa}$，缺氧诱导，慢性肾衰贫血可补人工 $\mathrm{EPO}$。维生素 $\mathrm{D}_{3}$：皮肤激素原 → 肝 $25\textrm{-}\mathrm{OH}$ → 肾 $1\alpha$-羟化成 $1,25$；$\mathrm{PTH}$ 与之负反馈。
- 图27-7：$\mathrm{PTH}$／活性维生素 $\mathrm{D}_{3}$、$\mathrm{EPO}$、$\mathrm{RAAS}$、$\mathrm{ANP}$、$\mathrm{ADH}$。$\mathrm{ANP}$ 排钠排水；$\mathrm{ADH}$ 是集合管 9 肽；醛固酮保水钠、排钾。
:::

:::keypoint{label="本节不写的三本账"}
脑的葡萄糖／酮体、递质四户和阿尔茨海默病在第一节。心肌代谢杂食者、优势效应和心衰 $\mathrm{PCr}/\mathrm{ATP}$ 在第二节，$\beta$-羟丁酸抑制组蛋白脱乙酰酶也在那里。骨骼肌随运动时间磷酸原 → 糖无氧 → 糖有氧 → 脂肪有氧，以及肌肉因子，是第四节。脂肪组织瘦素、弓状核是第五节。本节只把肾的供能分区、空腹造糖造酮、重吸收和内分泌三块立住。
:::
