# 第五节　蛋白质的分离、纯化与结构分析

本节把第四节的电荷、水化膜、$A_{280}$ 和沉淀行为，写成不损伤空间构象的分离手段：沉淀浓缩、透析与超滤、电泳、层析、超速离心；再写一级结构的化学分析（氨基酸组成、末端、肽段与 Edman 降解）和空间结构的物理／生物信息测定。末端测定按教材写全。章末收本章小结。

蛋白质是生物大分子，具有胶体性质、沉淀、变性和凝固等特点。人体的细胞和体液中存在成千上万种蛋白质，要分析其中某种蛋白质的结构和功能，需要从混合物分离纯化出单一蛋白质。蛋白质分离通常是利用其特殊理化性质，采取盐析、透析、电泳、层析及超速离心等不损伤蛋白质空间构象的物理方法，以满足研究蛋白质结构与功能的需要。

:::definition{label="蛋白质分离纯化的原则"}
细胞和体液中有成千上万种蛋白质，分析某一种的结构与功能，必须先从混合物中分离纯化出单一蛋白质。通常利用其特殊理化性质，采取盐析、透析、电泳、层析及超速离心等不损伤空间构象的物理方法。
:::

:::concept{term="先问这一步伤不伤构象，再问它拆的是电荷、大小还是亲和力"}
看见“分离纯化”，先确认教材用的是不损伤空间构象的物理方法，不是把蛋白煮变性再分析。然后问这一招靠什么差别：盐析靠电荷和水化膜，透析靠分子量截留，电泳靠净电荷和大小，离子交换靠电荷，凝胶过滤靠大小，亲和层析靠特异结合，超速离心靠密度与形态。把所有方法听成“都是沉淀”，一级结构和三维结构测定会没有样品。
:::

## 一、蛋白质沉淀用于蛋白质浓缩及分离

蛋白质在溶液中一般含量较低，需要经沉淀浓缩，以利进一步分离纯化。

### 1. 有机溶剂沉淀蛋白质

丙酮、乙醇等有机溶剂可以使蛋白质沉淀，再将其溶解在小体积溶剂中即可获得浓缩的蛋白质溶液。为保持蛋白质的结构和生物活性，需要在 $0\sim 4^{\circ}\mathrm{C}$ 低温下进行丙酮或乙醇沉淀，沉淀后应立即分离，否则蛋白质会发生变性。

:::definition{label="有机溶剂沉淀"}
丙酮、乙醇等有机溶剂可使蛋白质沉淀，再溶于小体积溶剂即得浓缩溶液。为保持结构和生物活性，须在 $0\sim 4^{\circ}\mathrm{C}$ 进行，沉淀后立即分离，否则会发生变性。
:::

:::pitfall{label="有机溶剂既能沉淀也能变性，低温和立即分离不是细节"}
第四节把乙醇列为变性因素。这里用丙酮、乙醇沉淀浓缩，靠的是破坏水化膜让蛋白析出来，但必须低温、马上分开，否则沉淀会变成变性。不要把“能用乙醇沉淀”听成“室温泡着也没关系”。
:::

### 2. 盐析分离蛋白质

盐析（salt precipitation）是将硫酸铵、硫酸钠或氯化钠等加入蛋白质溶液，使蛋白质表面电荷被中和以及水化膜被破坏，导致蛋白质在水溶液中的稳定性因素去除而沉淀。各种蛋白质盐析时所需的盐浓度及 $\mathrm{pH}$ 均不同，可据此将不同的蛋白质予以分离。例如血清中的清蛋白和球蛋白，前者可溶于 $\mathrm{pH}\,7.0$ 左右的半饱和硫酸铵溶液中，而后者在此溶液中则发生沉淀。当硫酸铵溶液达到饱和时，清蛋白也随之析出。所以盐析法可将蛋白质初步分离，但欲得纯品，尚需用其他方法。许多蛋白质经纯化后，在盐溶液中长期放置逐渐析出，成为整齐的结晶。

:::definition{label="盐析"}
盐析（salt precipitation）是将硫酸铵、硫酸钠或氯化钠等加入蛋白质溶液，中和表面电荷并破坏水化膜，去除胶体稳定因素而沉淀。各种蛋白质所需盐浓度及 $\mathrm{pH}$ 不同，可据此初步分离。
:::

:::example{label="半饱和硫酸铵分开清蛋白和球蛋白"}
血清清蛋白可溶于 $\mathrm{pH}\,7.0$ 左右的半饱和硫酸铵溶液，球蛋白在此溶液中沉淀。硫酸铵达饱和时，清蛋白也随之析出。盐析只能初步分离，纯品还需其他方法。
:::

:::note{label="盐溶液里可以结晶"}
许多蛋白质经纯化后，在盐溶液中长期放置逐渐析出，成为整齐的结晶。沉淀在这里不但不是变性，还是得到有序晶体的路——$\mathrm{X}$ 射线衍射后面要用晶体。
:::

### 3. 免疫沉淀分离蛋白质

蛋白质具有抗原性，将某种纯化蛋白质免疫动物可获得抗该蛋白质的特异抗体。利用特异抗体识别相应抗原并形成抗原抗体复合物的性质，可从蛋白质混合溶液中分离获得抗原蛋白。这就是可用于特定蛋白质定性和定量分析的免疫沉淀法。在具体实验中，常将抗体交联至固相化的琼脂糖珠上，易于获得抗原抗体复合物。进一步将抗原抗体复合物溶于含十二烷基硫酸钠和二巯丙醇的缓冲液后加热，使抗原从抗原抗体复合物分离而得以纯化，并用于分析。

:::definition{label="免疫沉淀"}
蛋白质具有抗原性。用纯化蛋白质免疫动物得到特异抗体，利用抗体识别相应抗原并形成抗原抗体复合物，从混合溶液中分离抗原蛋白。可用于特定蛋白质的定性和定量分析。
:::

:::note{label="固相抗体和拆开复合物"}
实验中常把抗体交联到固相化琼脂糖珠上，便于拿到复合物。再将复合物溶于含十二烷基硫酸钠和二巯丙醇的缓冲液后加热，使抗原从复合物上分离、纯化并用于分析。第三节写过：低 $\mathrm{pH}$、高盐、反复冻融也可解离复合物且活性仍在；这里用 SDS 和二巯丙醇加热，是为了拆开后做分析。
:::

:::compare{title="三种沉淀浓缩"}
| 方法 | 靠什么析出 | 活性／构象 | 分辨率 |
|------|------------|------------|--------|
| 有机溶剂（丙酮、乙醇） | 破坏水化膜等 | 须 $0\sim 4^{\circ}\mathrm{C}$ 并立即分离，否则变性 | 浓缩为主 |
| 盐析（硫酸铵等） | 中和电荷 + 破坏水化膜 | 一般不变性；可结晶 | 初步分离（如清蛋白／球蛋白） |
| 免疫沉淀 | 特异抗原–抗体复合物 | 结合特异；拆开时常加 SDS、二巯丙醇并加热 | 针对某一种抗原蛋白，可定性定量 |
:::

## 二、透析和超滤法去除蛋白质溶液中的小分子化合物

利用透析袋将大分子蛋白质与小分子化合物分开的方法称为透析（dialysis）。透析袋是用具有超小微孔的膜，如硝酸纤维素膜制成，一般只允许分子量 $10\,\mathrm{kD}$ 以下的化合物通过。将蛋白质溶液装在透析袋内，置于水中，硫酸铵、氯化钠等小分子物质可透过薄膜进入水溶液，由此可对盐析浓缩后的蛋白质溶液进行除盐。如果透析袋外放置吸水剂如聚乙二醇，则袋内水分伴同小分子物质透出袋外，高分子量的蛋白质留在袋内，可达到浓缩目的。同样，应用正压或离心力使蛋白质溶液透过有一定截留分子量的超滤膜，达到浓缩蛋白质溶液的目的，称为超滤法。此法简便且回收率高，是常用的浓缩蛋白质溶液方法。

:::definition{label="透析"}
利用透析袋将大分子蛋白质与小分子化合物分开的方法称为透析（dialysis）。透析袋如硝酸纤维素膜，一般只允许分子量 $10\,\mathrm{kD}$ 以下的化合物通过。袋内蛋白质溶液置于水中，硫酸铵、氯化钠等小分子透出，用于盐析后除盐。
:::

:::definition{label="透析浓缩"}
透析袋外放置吸水剂如聚乙二醇，袋内水分伴同小分子透出，高分子量蛋白质留在袋内，达到浓缩目的。
:::

:::definition{label="超滤法"}
应用正压或离心力使蛋白质溶液透过有一定截留分子量的超滤膜，从而浓缩蛋白质溶液，称为超滤法。简便且回收率高，是常用的浓缩方法。
:::

:::tip{label="盐析之后通常要透析"}
盐析把蛋白连同高浓度硫酸铵一起沉下来。下一步分析或层析前，要用透析把盐拿走，蛋白质留在袋里。Anfinsen 复性同样靠透析去掉尿素和 $\beta$-巯基乙醇。
:::

## 三、电泳是分离蛋白质的常用方法

蛋白质在高于或低于其 $\mathrm{pI}$ 的溶液中成为带电颗粒，在电场中能向正极或负极方向移动。这种通过蛋白质在电场中泳动而达到分离各种蛋白质的技术称为电泳（electrophoresis）。根据支撑物的不同，有纤维薄膜电泳、凝胶电泳等。薄膜电泳是将蛋白质溶液点样于薄膜上，薄膜两端分别加正、负电极，此时带正电荷的蛋白质向负极泳动；带负电荷的蛋白质向正极泳动；带电多，分子量小的蛋白质泳动速率快；带电少，分子量大的则泳动慢，于是蛋白质被分离。凝胶电泳的支撑物为琼脂糖、淀粉或聚丙烯酰胺凝胶。凝胶置于玻璃板上或玻璃管中，凝胶两端分别加上正、负电极，蛋白质混合液即在凝胶中泳动。电泳结束后，用蛋白质显色剂显色，即可看到多条已被分离的蛋白质色带。

:::definition{label="电泳"}
蛋白质在高于或低于其 $\mathrm{pI}$ 的溶液中成为带电颗粒，在电场中向正极或负极移动。通过这种泳动分离各种蛋白质的技术称为电泳（electrophoresis）。支撑物不同则有纤维薄膜电泳、凝胶电泳等。
:::

:::definition{label="薄膜电泳的泳动规则"}
带正电荷的蛋白质向负极泳动；带负电荷的向正极泳动。带电多、分子量小的泳动快；带电少、分子量大的泳动慢。
:::

:::definition{label="凝胶电泳"}
支撑物为琼脂糖、淀粉或聚丙烯酰胺凝胶，置于玻璃板或玻璃管中，两端加正、负电极。电泳结束后用蛋白质显色剂显色，可见多条已被分离的蛋白质色带。
:::

### 1. SDS-聚丙烯酰胺凝胶电泳分离蛋白质

若蛋白质样品和聚丙烯酰胺凝胶系统中加入带负电荷较多的十二烷基硫酸钠（sodium dodecylsulfate，$\mathrm{SDS}$），使所有蛋白质颗粒表面覆盖一层 $\mathrm{SDS}$ 分子，导致蛋白质分子间的电荷差异消失，此时蛋白质在电场中的泳动速率仅与蛋白质颗粒大小有关，加之聚丙烯酰胺凝胶具有分子筛效应，因而此种电泳称为 $\mathrm{SDS}$-聚丙烯酰胺凝胶电泳（SDS-polyacrylamide gel electrophoresis，$\mathrm{SDS}$-$\mathrm{PAGE}$）。

:::definition{label="SDS-PAGE"}
在样品和聚丙烯酰胺凝胶系统中加入带负电荷较多的十二烷基硫酸钠（$\mathrm{SDS}$），使所有蛋白质表面覆盖一层 $\mathrm{SDS}$，分子间电荷差异消失。泳动速率仅与颗粒大小有关，加上凝胶的分子筛效应，称为 $\mathrm{SDS}$-聚丙烯酰胺凝胶电泳（$\mathrm{SDS}$-$\mathrm{PAGE}$）。
:::

:::pitfall{label="SDS-PAGE 不再按原有 pI 分，按的是大小"}
普通电泳同时看电荷和分子量。加了 $\mathrm{SDS}$，电荷差异被抹平，剩下分子筛效应，主要按颗粒大小分开。不要把 $\mathrm{SDS}$-$\mathrm{PAGE}$ 的条带位置当成“还在按等电点排队”。
:::

### 2. 等电聚焦电泳分离蛋白质

如果在聚丙烯酰胺凝胶中加入系列两性电解质载体，在电场中可形成一个连续而稳定的线性 $\mathrm{pH}$ 梯度，即 $\mathrm{pH}$ 从凝胶的正极向负极依次递增。在这种介质中电泳时，被分离的蛋白质处在偏离其等电点的 $\mathrm{pH}$ 位置时带有电荷而移动，当蛋白质泳动至与其自身的 $\mathrm{pI}$ 相等的 $\mathrm{pH}$ 区域时，其净电荷为零而不再移动，这种通过蛋白质等电点的差异而分离蛋白质的电泳方法称为等电聚焦电泳（isoelectric equilibrium electrophoresis，$\mathrm{IEE}$）。

:::definition{label="等电聚焦电泳"}
在聚丙烯酰胺凝胶中加入系列两性电解质载体，电场中形成连续稳定的线性 $\mathrm{pH}$ 梯度：$\mathrm{pH}$ 从正极向负极依次递增。蛋白质在偏离自身 $\mathrm{pI}$ 的位置带电而移动，到达 $\mathrm{pH}=\mathrm{pI}$ 处净电荷为零、不再移动。按等电点差异分离，称为等电聚焦电泳（isoelectric equilibrium electrophoresis，$\mathrm{IEE}$）。
:::

:::cause-effect{title="为什么聚焦在 pI 处停住"}
- **因** $\mathrm{pH}$ 梯度连续稳定；蛋白质只有在 $\mathrm{pH}=\mathrm{pI}$ 时净电荷为零
- **果** 偏离 $\mathrm{pI}$ 就带电、继续泳动，到达 $\mathrm{pI}$ 处停下，混合物按 $\mathrm{pI}$ 被分开
:::

### 3. 双向凝胶电泳分离蛋白质

人类基因组计划完成后迎来了后基因组时代，其中蛋白质组学的研究颇受重视。双向凝胶电泳（two-dimensional gel electrophoresis，$2$-$\mathrm{DE}$）是蛋白质组学研究的重要技术之一。双向凝胶电泳的第一向是蛋白质的 $\mathrm{IEE}$，第二向为 $\mathrm{SDS}$-$\mathrm{PAGE}$，利用被分离蛋白质等电点和分子量的差异，将复杂蛋白质混合物在二维平面上分离。

:::definition{label="双向凝胶电泳"}
双向凝胶电泳（two-dimensional gel electrophoresis，$2$-$\mathrm{DE}$）是蛋白质组学的重要技术。第一向为等电聚焦（$\mathrm{IEE}$），第二向为 $\mathrm{SDS}$-$\mathrm{PAGE}$，按等电点和分子量的差异，将复杂混合物在二维平面上分离。
:::

:::compare{title="三种凝胶电泳"}
| 方法 | 分开的依据 | 电荷还在起作用吗 | 典型用途 |
|------|------------|-------------------|----------|
| 普通凝胶电泳 | 净电荷 + 分子量 | 是：正→负极，负→正极 | 血清蛋白区带等 |
| $\mathrm{SDS}$-$\mathrm{PAGE}$ | 颗粒大小（分子筛） | $\mathrm{SDS}$ 抹平电荷差异 | 分子量比较、纯度鉴定 |
| 等电聚焦（$\mathrm{IEE}$） | $\mathrm{pI}$ | 只在到达 $\mathrm{pI}$ 前带电 | 按等电点聚焦 |
| 双向电泳（$2$-$\mathrm{DE}$） | 第一向 $\mathrm{pI}$，第二向分子量 | 两向分别用 $\mathrm{IEE}$ 和 $\mathrm{SDS}$-$\mathrm{PAGE}$ | 蛋白质组学，复杂混合物 |
:::

## 四、层析是分离和纯化蛋白质的重要手段

层析（chromatography）是分离、纯化蛋白质的重要手段之一。一般而言，待分离蛋白质溶液（流动相）经过一个固态物质（固定相）时，根据溶液中待分离的蛋白质颗粒大小、电荷多少及亲和力等，使待分离的蛋白质组分在两相中反复分配，并以不同速度流经固定相而达到分离蛋白质的目的。层析种类很多，有离子交换层析、凝胶过滤和亲和层析等。其中离子交换层析和凝胶过滤应用最广。

:::definition{label="层析"}
层析（chromatography）是分离、纯化蛋白质的重要手段。待分离蛋白质溶液（流动相）经过固态物质（固定相），按颗粒大小、电荷多少及亲和力等在两相中反复分配，以不同速度流经固定相而分离。种类包括离子交换层析、凝胶过滤和亲和层析等，前两者应用最广。
:::

蛋白质和氨基酸一样，是两性电解质，在某一特定 $\mathrm{pH}$ 时，各蛋白质的电荷量及性质不同，故可以通过离子交换层析得以分离。图 1-31 介绍的是阴离子交换层析，将阴离子交换树脂颗粒填充在层析管内，由于阴离子交换树脂颗粒上带正电荷，能吸引溶液中的阴离子（图 1-31a）。然后再用含阴离子（如 $\mathrm{Cl}^{-}$）的溶液洗柱。含负电量小的蛋白质首先被洗脱下来（图 1-31b）；增加 $\mathrm{Cl}^{-}$ 浓度，含负电量多的蛋白质也被洗脱下来（图 1-31c），于是两种蛋白质被分开。洗脱图中 $A_{280}$ 表示 $280\,\mathrm{nm}$ 的吸光度（图 1-31d）。

:::definition{label="离子交换层析（阴离子交换）"}
蛋白质是两性电解质，某一特定 $\mathrm{pH}$ 下各蛋白质电荷量及性质不同，可用离子交换层析分离。阴离子交换树脂颗粒带正电荷，吸引溶液中的阴离子。用含 $\mathrm{Cl}^{-}$ 等阴离子的溶液洗柱：负电量小的蛋白质先被洗脱；增加 $\mathrm{Cl}^{-}$ 浓度后，负电量多的随后洗脱。
:::

::figure{src="/images/biochemistry/textbook/p0060_02.png" caption="图1-31 离子交换层析分离蛋白质。（a）样品全部交换并吸附到带正电的阴离子交换树脂上；（b）负电荷较少的分子用较稀的 Cl⁻ 或其他负离子溶液洗脱；（c）电荷多的分子随 Cl⁻ 浓度增加依次洗脱；（d）洗脱图 A280 为 280 nm 吸光度，虚线为 [Cl⁻] 梯度。" alt="阴离子交换树脂带正电，依次洗下带负电较少和较多的蛋白质，下方 A280 出现两个峰，Cl⁻ 浓度虚线上升"}

凝胶过滤（gel filtration）又称分子筛层析。层析柱内填满带有小孔的颗粒，一般由葡聚糖制成。蛋白质溶液加于柱之顶部，任其往下渗漏，小分子蛋白质进入孔内，因而在柱中滞留时间较长，大分子蛋白质不能进入孔内而径直流出，因此不同大小的蛋白质得以分离（图 1-32）。

:::definition{label="凝胶过滤"}
凝胶过滤（gel filtration）又称分子筛层析。柱内填满带小孔的颗粒，一般由葡聚糖制成。小分子蛋白质进入孔内，滞留时间较长；大分子蛋白质不能进入孔内而径直流出，故按大小分离。
:::

::figure{src="/images/biochemistry/textbook/p0060_01.png" caption="图1-32 凝胶过滤分离蛋白质。（a）大球为葡聚糖凝胶颗粒，上样后小分子蛋白与大分子蛋白同在柱顶；（b）小分子进入凝胶微孔，大分子不能进入，故洗脱时大分子先流出；（c）小分子后洗脱出来。下方 A280 先出现大分子峰，后出现小分子峰。" alt="三根层析柱：葡聚糖空心大球，蓝色小分子进入孔内，大分子先从柱底流出，对应 A280 峰先后不同"}

:::compare{title="离子交换层析与凝胶过滤"}
| 项目 | 离子交换层析 | 凝胶过滤（分子筛层析） |
|------|--------------|------------------------|
| 固定相 | 离子交换树脂（如图 1-31 的阴离子树脂带正电） | 带小孔的葡聚糖颗粒 |
| 分离依据 | 特定 $\mathrm{pH}$ 下电荷量及性质 | 分子大小 |
| 先出来的 | 与树脂结合弱的（负电量小的阴离子蛋白先被稀 $\mathrm{Cl}^{-}$ 洗下） | 大分子（不进孔，径直流出） |
| 后出来的 | 结合强的（提高 $\mathrm{Cl}^{-}$ 后洗下负电量多的） | 小分子（进孔，滞留久） |
| 监测 | 洗脱液 $A_{280}$ | 洗脱液 $A_{280}$ |
:::

:::pitfall{label="凝胶过滤是大分子先出来，不要做成“小的跑得快”"}
电泳里常常是分子量小的跑得快；凝胶过滤恰好相反：小的进孔被拖住，大的不进孔先流出。把分子筛层析听成 SDS-PAGE 的同一套快慢，峰的顺序会写反。
:::

:::insight{label="层析在两相里反复分配，不是“滤纸漏一下”"}
流动相带着蛋白走过固定相，按大小、电荷、亲和力反复分配、速度不同。亲和层析教材点名但未展开：靠的是特异结合，与免疫沉淀是同一类识别逻辑。
:::

## 五、利用蛋白质颗粒沉降行为差异可进行超速离心分离

超速离心法（ultracentrifugation）既可以用来分离纯化蛋白质也可以用作测定蛋白质的分子量。蛋白质在高达 $500\,000\,g$（$g$ 为 gravity，即地心引力单位）的重力作用下，在溶液中逐渐沉降，直至其浮力（buoyant force）与离心所产生的力相等，此时沉降停止。不同蛋白质其密度与形态各不相同，因此用上述方法可将它们分开。蛋白质在离心力场中的沉降行为用沉降系数（sedimentation coefficient，$\mathrm{S}$）表示，沉降系数（$\mathrm{S}$）使用 Svedberg 单位（$1\,\mathrm{S}=10^{-13}$ 秒）。$\mathrm{S}$ 与蛋白质的密度和形状相关（表 1-3）。

:::definition{label="超速离心法"}
超速离心法（ultracentrifugation）既可分离纯化蛋白质，也可测定分子量。蛋白质在高达 $500\,000\,g$ 的重力作用下逐渐沉降，直至浮力与离心力相等，沉降停止。密度与形态不同的蛋白质可被分开。
:::

:::definition{label="沉降系数"}
蛋白质在离心力场中的沉降行为用沉降系数（sedimentation coefficient，$\mathrm{S}$）表示，单位为 Svedberg 单位（$1\,\mathrm{S}=10^{-13}$ 秒）。$\mathrm{S}$ 与蛋白质的密度和形状相关。
:::

**表 1-3**　蛋白质的分子量和沉降系数

| 蛋白质 | 分子量／$\mathrm{D}$ | $\mathrm{S}$ |
|--------|----------------------|-------------|
| 细胞色素 $\mathrm{c}$（牛心） | $13\,370$ | $1.17$ |
| 肌红蛋白（马心） | $16\,900$ | $2.04$ |
| 糜蛋白酶原（牛胰） | $23\,240$ | $2.54$ |
| $\beta$-乳球蛋白（羊奶） | $37\,100$ | $2.90$ |
| 血红蛋白（人） | $64\,500$ | $4.50$ |
| 血清清蛋白（人） | $68\,500$ | $4.60$ |
| 过氧化氢酶（马肝） | $247\,500$ | $11.30$ |
| 纤维蛋白原 | $339\,700$ | $7.60$ |
| 脲酶（刀豆） | $482\,700$ | $18.60$ |

:::note{label="S 不与分子量严格成正比"}
表 1-3 里纤维蛋白原分子量 $339\,700$，大于过氧化氢酶的 $247\,500$，但 $\mathrm{S}$ 为 $7.60$，小于过氧化氢酶的 $11.30$。教材写明 $\mathrm{S}$ 与密度和形状相关，不是单纯的“越大沉得越快”。纤维蛋白原形状细长，沉降行为与球状的过氧化氢酶不同。
:::

:::pitfall{label="超速离心停下来不是“沉到管底就结束”"}
沉降进行到浮力与离心力相等时停止。分开靠的是密度与形态的差别，并用 $\mathrm{S}$ 描述，不是所有蛋白都会在同一转速下拍到管底成一团。
:::

## 六、利用化学方法可分析蛋白质的一级结构

$\mathrm{Sanger\ F.}$ 耗时多年才在 $1953$ 年基本完成了胰岛素的一级结构测定，现今由于方法学改进及自动化分析仪器的产生，已有越来越多蛋白质的氨基酸序列问世。

:::timeline{period="一级结构测定从 Sanger 到核酸推演"}
- **1953** Sanger 基本完成胰岛素一级结构测定（耗时多年）
- **化学分析三步** 氨基酸组分 → 氨基端与羧基端 → 肽段切割后 Edman 降解，再拼接全序列
- **肽图** 层析、电泳及质谱分离鉴定肽段
- **基因组之后** 氨基酸序列已可通过核酸序列推演；蛋白质组学和生物制药鉴定仍需直接分析一级结构
:::

### 1. 离子交换层析分析蛋白质的氨基酸组分

首先分析已纯化蛋白质的氨基酸残基组成。蛋白质经盐酸水解后成为个别氨基酸，用离子交换树脂将各种氨基酸分开，测定它们的量，算出各氨基酸在蛋白质中的百分组成或个数（图 1-33）。

:::definition{label="氨基酸组成分析"}
纯化蛋白质经盐酸水解成为个别氨基酸，用离子交换树脂将各种氨基酸分开，测定其量，算出各氨基酸在蛋白质中的百分组成或个数。
:::

::figure{src="/images/biochemistry/textbook/p0061_02.png" caption="图1-33 离子交换层析分析蛋白质的氨基酸组分。盐酸水解后的氨基酸在不同 pH 的柠檬酸钠缓冲液中依次被洗脱，吸光度出峰顺序包括天冬、苏、丝、谷、脯、甘、丙、半胱、缬、甲硫、异亮、亮、酪、苯丙等。" alt="氨基酸分析洗脱图：横轴洗脱体积，纵轴吸光度，pH 3.5 与 pH 4.25 两段柠檬酸钠梯度下出现多个氨基酸峰"}

### 2. 测定多肽链的氨基端和羧基端的氨基酸残基

第二步测定多肽链的氨基端与羧基端为何种氨基酸残基。$\mathrm{Sanger\ F.}$ 最初用二硝基氟苯与多肽链的 $\alpha$-氨基作用生成二硝基苯氨基酸，然后将多肽水解，分离出带有二硝基苯基的氨基酸。目前多用丹酰氯使之生成丹酰衍生物，该物质具强烈荧光，更易鉴别。羧基端氨基酸残基可用羧肽酶将其水解下来进行鉴定。

:::definition{label="氨基端测定"}
$\mathrm{Sanger}$ 最初用二硝基氟苯与多肽链 $\alpha$-氨基作用生成二硝基苯氨基酸，水解后分离带二硝基苯基的氨基酸。目前多用丹酰氯生成具强烈荧光的丹酰衍生物，更易鉴别。
:::

:::definition{label="羧基端测定"}
羧基端氨基酸残基可用羧肽酶将其水解下来进行鉴定。
:::

### 3. 肽链序列的测定

第三步是将肽链水解成片段，分别进行分析。常用胰蛋白酶法、胰凝乳蛋白酶法、溴化氰法等。胰蛋白酶能水解赖氨酸或精氨酸的羧基所形成的肽键。所以如果蛋白质分子中有 $4$ 个精氨酸及赖氨酸残基，则可得 $5$ 个片段。胰凝乳蛋白酶水解芳香族氨基酸（苯丙氨酸、酪氨酸及色氨酸）羧基侧的肽键，溴化氰水解甲硫氨酸羧基侧的肽键。

蛋白质水解生成的肽段，可通过层析和电泳及质谱将其分离纯化并鉴定，得到的图谱称为肽图（peptide map），由此可明确肽段的大小和数量。各肽段的氨基酸排列顺序一般采用 Edman 降解法进行分析。将待测肽段先与异硫氰酸苯酯反应，该试剂只与氨基端氨基酸的游离 $\alpha$-氨基作用。再用冷稀酸处理，氨基端残基即自肽链脱落下来，成为异硫氰酸苯酯衍生物，用层析可鉴定为何种氨基酸衍生物。残留的肽链可继续与异硫氰酸苯酯作用，依次逐个鉴定出氨基酸的排列顺序（图 1-34）。对分析出的各肽段中的氨基酸顺序，进行组合排列对比，最终得出完整肽链中的氨基酸排列顺序。

:::definition{label="专一断裂肽键"}
胰蛋白酶水解赖氨酸或精氨酸羧基所形成的肽键：分子中有 $4$ 个精氨酸及赖氨酸残基，则可得 $5$ 个片段。胰凝乳蛋白酶水解芳香族氨基酸（苯丙氨酸、酪氨酸及色氨酸）羧基侧的肽键。溴化氰水解甲硫氨酸羧基侧的肽键。
:::

:::definition{label="肽图"}
蛋白质水解生成的肽段，经层析、电泳及质谱分离纯化并鉴定，得到的图谱称为肽图（peptide map），可明确肽段的大小和数量。
:::

:::definition{label="Edman 降解法"}
待测肽段先与异硫氰酸苯酯反应，该试剂只与氨基端氨基酸的游离 $\alpha$-氨基作用；再用冷稀酸处理，氨基端残基自肽链脱落，成为异硫氰酸苯酯衍生物，层析鉴定。残留肽链可继续反应，依次逐个鉴定氨基酸排列顺序。各肽段顺序再组合排列对比，得出完整肽链序列。
:::

:::derivation{title="从组成、两端到全序列"}
- 盐酸水解 + 离子交换 → 各氨基酸的个数／百分组成，还没有顺序。
- 二硝基氟苯或丹酰氯定 $\mathrm{N}$ 端，羧肽酶定 $\mathrm{C}$ 端 → 两条肽链的“头尾”。
- 胰蛋白酶／胰凝乳蛋白酶／溴化氰把长链切成可测的片段 → 肽图给出片段大小和数量。
- Edman 降解从每个片段的 $\mathrm{N}$ 端逐个往下剥 → 片段内顺序。
- 不同酶切片段交叉对比 → 拼出完整肽链的氨基酸排列顺序。
:::

:::compare{title="三种断裂试剂切在哪里"}
| 试剂 | 识别的残基 | 切断的键 |
|------|------------|----------|
| 胰蛋白酶 | 赖氨酸或精氨酸 | 其羧基所形成的肽键 |
| 胰凝乳蛋白酶 | 苯丙氨酸、酪氨酸、色氨酸 | 芳香族氨基酸羧基侧的肽键 |
| 溴化氰 | 甲硫氨酸 | 甲硫氨酸羧基侧的肽键 |
:::

:::example{label="4 个 Arg/Lys 切成 5 段"}
胰蛋白酶只切赖氨酸或精氨酸的羧基侧肽键。若分子中这类残基一共 $4$ 个，则得到 $5$ 个片段。片段数 = 切点数目 $+1$（两端完整时）。
:::

近年来，由于核酸研究在理论上及技术上的迅猛发展，尤其是人全基因组测序的完成，各种蛋白质的氨基酸序列已经可以通过核酸序列来推演。然而，蛋白质组学研究、生物制药产品的鉴定等仍需要进行高效而准确的蛋白质一级结构的分析。

:::pitfall{label="核酸序列能推氨基酸序列，并不等于可以不再测蛋白质"}
基因组完成后，序列可以按遗传密码从核酸推演。教材紧接着写：蛋白质组学、生物制药产品鉴定仍需高效、准确的蛋白质一级结构分析——翻译后修饰、剪接异构、制剂鉴定，核酸推演替不了。
:::

## 七、利用物理学或生物信息方法可测定或预测蛋白质的空间结构

大量生物体内存在的蛋白质空间结构的解析，对于研究蛋白质结构与功能的内在关系至关重要，也为蛋白质或多肽药物的结构改造增强功效减弱副作用提供了理论依据。由于蛋白质的空间结构十分复杂，因而其测定的难度也较大，而且还需昂贵的仪器设备和先进的技术。随着结构生物学的发展，蛋白质二级结构和三维空间结构的测定得到普遍开展。

:::note{label="为什么要测空间结构"}
解析空间结构，是为了研究结构与功能的内在关系，并为蛋白质或多肽药物的结构改造（增强功效、减弱副作用）提供理论依据。难度大，需要昂贵仪器和先进技术。
:::

### 1. 圆二色光谱法测定蛋白质二级结构

通常采用圆二色光谱（circular dichroism，$\mathrm{CD}$）测定溶液状态下的蛋白质二级结构。$\mathrm{CD}$ 谱对二级结构非常敏感，$\alpha$-螺旋的 $\mathrm{CD}$ 峰有 $222\,\mathrm{nm}$ 处的负峰、$208\,\mathrm{nm}$ 处的负峰和 $198\,\mathrm{nm}$ 处的正峰 $3$ 个成分；而 $\beta$-折叠的 $\mathrm{CD}$ 谱不太固定。可见测定含 $\alpha$-螺旋较多的蛋白质，所得结果更为准确。

:::definition{label="圆二色光谱"}
圆二色光谱（circular dichroism，$\mathrm{CD}$）用于测定溶液状态下的蛋白质二级结构，对二级结构非常敏感。
:::

:::definition{label="α-螺旋的 CD 峰"}
$\alpha$-螺旋的 $\mathrm{CD}$ 峰有三个成分：$222\,\mathrm{nm}$ 负峰、$208\,\mathrm{nm}$ 负峰、$198\,\mathrm{nm}$ 正峰。$\beta$-折叠的 $\mathrm{CD}$ 谱不太固定。因此含 $\alpha$-螺旋较多的蛋白质，测定结果更为准确。
:::

### 2. 蛋白质三维空间结构解析

$\mathrm{X}$ 射线衍射（X-ray diffraction）和核磁共振（nuclear magnetic resonance，$\mathrm{NMR}$）技术是研究蛋白质三维空间结构的经典方法。$\mathrm{X}$ 射线衍射法需要首先将蛋白质制备成晶体，$\mathrm{X}$ 射线射至蛋白质晶体上，产生不同方向的衍射，收集衍射光束所产生的电子密度图，可计算出空间结构。核磁共振技术主要用于测定蛋白质的液相三维空间结构。

冷冻电镜（cryo-electron microscopy）技术的发明极大提高了蛋白质三维结构的解析速度和分辨率，而且可以分析蛋白质在相对天然状态下的结构，当前已经成为结构生物学的主要研究手段。

:::definition{label="X 射线衍射解析蛋白质晶体"}
$\mathrm{X}$ 射线衍射法需先将蛋白质制成晶体。$\mathrm{X}$ 射线射至晶体，产生不同方向的衍射，收集衍射光束的电子密度图，计算空间结构。盐析后长期放置得到的整齐结晶，正是这条路的样品。
:::

:::definition{label="核磁共振"}
核磁共振（$\mathrm{NMR}$）技术主要用于测定蛋白质的液相三维空间结构。经典方法中，$\mathrm{X}$ 射线看晶体，$\mathrm{NMR}$ 看溶液。
:::

:::definition{label="冷冻电镜"}
冷冻电镜（cryo-electron microscopy）极大提高了三维结构的解析速度和分辨率，并可分析蛋白质在相对天然状态下的结构，当前已成为结构生物学的主要研究手段。
:::

### 3. 生物信息学预测蛋白质空间结构

由于蛋白质空间结构的基础是一级结构，参照已经完成的各种蛋白质的三维结构数据库，可以初步预测各种蛋白质的三维空间结构。

:::definition{label="生物信息学预测空间结构"}
空间结构的基础是一级结构。参照已完成的三维结构数据库，可以初步预测蛋白质的三维空间结构。Anfinsen 的结论在这里变成可计算的预测：序列在，构象就有被推出来的根据。
:::

:::compare{title="空间结构：测定与预测"}
| 方法 | 对象层次 | 样品状态 | 教材要点 |
|------|----------|----------|----------|
| 圆二色（$\mathrm{CD}$） | 二级结构 | 溶液 | $\alpha$-螺旋：$222\,\mathrm{nm}$ 负、$208\,\mathrm{nm}$ 负、$198\,\mathrm{nm}$ 正；$\beta$-折叠谱不太固定 |
| $\mathrm{X}$ 射线衍射 | 三维 | 晶体 | 衍射 → 电子密度图 → 计算空间结构 |
| $\mathrm{NMR}$ | 三维 | 液相 | 经典方法之一 |
| 冷冻电镜 | 三维 | 相对天然状态 | 速度和分辨率大幅提高，现为主要手段 |
| 生物信息学 | 三维（预测） | 序列 + 结构数据库 | 一级结构是基础，结果是初步预测 |
:::

:::keypoint{label="分离纯化到结构分析的工作顺序"}
- 先浓缩、除盐、按电荷／大小／亲和力分开，得到单一蛋白质，且尽量不伤构象。
- 一级结构：组成 → 两端 → 专一断裂 + 肽图 → Edman 逐个降解 → 拼接；核酸序列可推演，但组学和制药仍要直接测。
- 空间结构：$\mathrm{CD}$ 看二级，$\mathrm{X}$ 射线／$\mathrm{NMR}$／冷冻电镜看三维，数据库预测作补充。
:::

## 本章小结

蛋白质是重要的生物大分子，其组成的基本单位为 $\mathrm{L}$-$\alpha$-氨基酸（除甘氨酸外）。氨基酸通过肽键相连而成肽。

蛋白质一级结构是指蛋白质分子中氨基酸自 $\mathrm{N}$-端至 $\mathrm{C}$-端的排列顺序，即氨基酸序列。二级结构是指蛋白质主链局部的空间结构，不涉及氨基酸残基侧链构象，主要为 $\alpha$-螺旋、$\beta$-折叠、$\beta$-转角和 $\Omega$-环。三级结构是指多肽链主链和侧链的全部原子的空间排布位置。四级结构是指蛋白质亚基之间的聚合。

体内存在数万种蛋白质，各有其特定的结构和特殊的生物学功能。一级结构是空间构象的基础，也是功能的基础。

体内有一些肽可直接以肽的形式发挥生物学作用，称为生物活性肽。

蛋白质空间构象与功能有着密切关系。血红蛋白亚基与 $\mathrm{O}_2$ 结合可引起另一亚基构象变化，使之更易与 $\mathrm{O}_2$ 结合，所以血红蛋白的氧解离曲线呈“$\mathrm{S}$”形。这种别构效应是蛋白质中普遍存在的功能调节方式之一。

蛋白质的空间构象发生改变，可导致其理化性质变化和生物活性的丧失。蛋白质发生变性后，只要其一级结构未遭破坏，可在一定条件下复性，恢复原有的空间构象和功能。

人体的细胞和体液中存在多种蛋白质，要分析其中某种蛋白质的结构和功能，需要从混合物中分离纯化该蛋白质。通常可采取盐析、透析、电泳、层析及超速离心等不损伤蛋白质结构和功能的物理方法来纯化蛋白质。通过肽图分析和肽段的 Edman 降解法可以获得蛋白质的一级结构。$\mathrm{X}$ 射线衍射、核磁共振和冷冻电镜是解析蛋白质三维结构的主要技术。

:::definition{label="本章小结里的四级结构"}
一级结构：氨基酸自 $\mathrm{N}$-端至 $\mathrm{C}$-端的排列顺序。二级结构：主链局部空间结构，不涉及侧链构象，主要为 $\alpha$-螺旋、$\beta$-折叠、$\beta$-转角和 $\Omega$-环。三级结构：主链和侧链全部原子的空间排布。四级结构：亚基之间的聚合。
:::

:::insight{label="小结把全章收成三句话"}
组成单位是 $\mathrm{L}$-$\alpha$-氨基酸（甘氨酸除外），肽键成肽；一级结构是构象和功能的基础，$\mathrm{Hb}$ 的 $\mathrm{S}$ 形曲线是别构的样板；变性不毁一级结构就可复性，纯化走不伤构象的物理方法，测序走肽图和 Edman，三维走衍射、$\mathrm{NMR}$ 和冷冻电镜。
:::

:::memory{label="本节必背要点"}
- [ ] 分离纯化用盐析、透析、电泳、层析及超速离心等不损伤空间构象的物理方法。
- [ ] 有机溶剂（丙酮、乙醇）沉淀须 $0\sim 4^{\circ}\mathrm{C}$，沉淀后立即分离，否则变性。
- [ ] 盐析：硫酸铵、硫酸钠或氯化钠中和电荷并破坏水化膜；不同蛋白所需盐浓度及 $\mathrm{pH}$ 不同。
- [ ] $\mathrm{pH}\,7.0$ 左右半饱和硫酸铵：球蛋白沉淀，清蛋白仍溶；饱和时清蛋白也析出。
- [ ] 纯化后在盐溶液中长期放置可析出整齐结晶。
- [ ] 免疫沉淀：特异抗体形成抗原抗体复合物；抗体可交联琼脂糖珠；SDS + 二巯丙醇加热拆开。
- [ ] 透析袋一般只允许 $10\,\mathrm{kD}$ 以下通过，用于盐析后除盐；袋外聚乙二醇可浓缩。
- [ ] 超滤：正压或离心力透过截留分子量膜，简便、回收率高。
- [ ] 电泳：$\mathrm{pH}\neq\mathrm{pI}$ 时带电，正→负极，负→正极；带电多、分子量小则快。
- [ ] 凝胶电泳支撑物：琼脂糖、淀粉或聚丙烯酰胺；显色后见多条色带。
- [ ] $\mathrm{SDS}$-$\mathrm{PAGE}$：$\mathrm{SDS}$ 覆盖后电荷差异消失，按大小 + 分子筛分离。
- [ ] 等电聚焦：两性电解质形成正极→负极递增的 $\mathrm{pH}$ 梯度，蛋白在 $\mathrm{pH}=\mathrm{pI}$ 处净电荷为零而停下。
- [ ] $2$-$\mathrm{DE}$：第一向 $\mathrm{IEE}$，第二向 $\mathrm{SDS}$-$\mathrm{PAGE}$，蛋白质组学重要技术。
- [ ] 层析：流动相／固定相，按大小、电荷、亲和力分配；离子交换与凝胶过滤应用最广。
- [ ] 阴离子交换：树脂带正电；负电量小的先被稀 $\mathrm{Cl}^{-}$ 洗下，提高 $\mathrm{Cl}^{-}$ 后洗下负电量多的；$A_{280}$ 监测。
- [ ] 凝胶过滤：葡聚糖小孔；大分子不进孔先流出，小分子进孔后流出。
- [ ] 超速离心：高达 $500\,000\,g$，沉至浮力与离心力相等；可分离并可测分子量。
- [ ] 沉降系数 $\mathrm{S}$，Svedberg 单位 $1\,\mathrm{S}=10^{-13}$ 秒，与密度和形状相关。
- [ ] $1953$ 年 Sanger 基本完成胰岛素一级结构测定。
- [ ] 组成分析：盐酸水解 → 离子交换分开氨基酸 → 百分组成或个数。
- [ ] $\mathrm{N}$ 端：二硝基氟苯（Sanger）或丹酰氯（荧光）；$\mathrm{C}$ 端：羧肽酶。
- [ ] 胰蛋白酶切 $\mathrm{Lys}/\mathrm{Arg}$ 羧基侧；胰凝乳蛋白酶切 $\mathrm{Phe}/\mathrm{Tyr}/\mathrm{Trp}$ 羧基侧；溴化氰切 $\mathrm{Met}$ 羧基侧。
- [ ] $4$ 个 $\mathrm{Arg}+\mathrm{Lys}$ → 胰蛋白酶切出 $5$ 个片段。
- [ ] 肽图：层析、电泳及质谱鉴定肽段大小和数量。
- [ ] Edman：异硫氰酸苯酯只与 $\mathrm{N}$ 端游离 $\alpha$-氨基反应，冷稀酸使该残基脱落，逐个测序后拼接。
- [ ] 核酸序列可推演氨基酸序列；蛋白质组学和生物制药鉴定仍需直接分析一级结构。
- [ ] $\mathrm{CD}$：溶液态二级结构；$\alpha$-螺旋 $222\,\mathrm{nm}$ 负、$208\,\mathrm{nm}$ 负、$198\,\mathrm{nm}$ 正；$\beta$-折叠谱不固定。
- [ ] $\mathrm{X}$ 射线衍射需晶体，由电子密度图计算空间结构；$\mathrm{NMR}$ 测液相三维结构。
- [ ] 冷冻电镜提高速度与分辨率，可看相对天然状态，现为主要手段。
- [ ] 生物信息学参照三维结构数据库，由一级结构初步预测空间结构。
- [ ] 本章小结：$\mathrm{L}$-$\alpha$-氨基酸（除甘氨酸）经肽键成肽；一级结构是构象与功能基础；$\mathrm{Hb}$ 氧解离曲线呈 $\mathrm{S}$ 形，别构是普遍调节方式；变性不毁一级结构可复性。
:::
