# 第五节　酶的分类与命名

本节按国际系统把酶分成七大类，并写出每一类催化的反应类型和教材例子。分类编号落在 $\mathrm{EC}$ 四组数字上；命名分系统名称与推荐名称（从习惯名称里选定）。合酶与合成酶最初按是否需要核苷三磷酸供能来区分，生物化学命名联合委员会后来规定合酶可用于催化合成反应的任何一种酶，因此合酶属于连接酶类。

目前已发现 $4000$ 多种酶，为了研究和使用方便，$1961$ 年国际生物化学与分子生物学会酶学专业委员会推荐一套系统命名法及分类方法。

:::definition{label="系统命名法及分类方法的来源"}
$1961$ 年，国际生物化学与分子生物学会酶学专业委员会推荐一套系统命名法及分类方法。当时已发现 $4000$ 多种酶，习惯名称容易混乱，才需要这一套。
:::

:::timeline{period="酶的系统分类与命名"}
- **早期** 酶的名称多由发现者确定，习惯名称常出现混乱（如心肌黄酶、触酶）
- **1961** 国际生物化学与分子生物学会酶学专业委员会推荐系统命名法及分类方法；IUBMB 以酶的分类为依据提出系统名称
- **其后** 国际酶学委员会从每种酶的数个习惯名称中选定一个推荐名称
- **2018** 新增第七大类：易位酶类（转位酶）
:::

:::pitfall{label="本节按教材写 7 大类，不要只背到连接酶就停"}
氧化还原、转移、水解、裂合、异构、连接是传统六类。本版教材明确写“可以分为 7 大类”，第 7 类易位酶是 $2018$ 年新增加的。考试若仍问“六大类”，对应的是未计入易位酶的旧表；按本章正文应能数到易位酶。
:::

## 一、酶可根据其催化的反应类型予以分类

根据酶催化的反应类型，酶可以分为 $7$ 大类。

:::definition{label="酶的七大类"}
根据酶催化的反应类型，酶可以分为 $7$ 大类：氧化还原酶类、转移酶类、水解酶类、裂合酶类、异构酶类、连接酶类、易位酶类。
:::

:::concept{term="先问反应类型是哪一类，再问 EC 第一位数字"}
分类的钥匙是催化的反应类型，不是酶从哪个器官来、也不先看习惯名。第一位 $\mathrm{EC}$ 数字就对应这一大类：$1$ 氧化还原、$2$ 转移、$3$ 水解、$4$ 裂合、$5$ 异构、$6$ 连接、$7$ 易位。把乳酸脱氢酶听成“水解酶”、把激酶听成“连接酶”，表2-10 会对错行。
:::

### 1. 氧化还原酶类

催化氧化还原反应的酶属于氧化还原酶类（oxidoreductases），包括催化传递电子、氢以及需氧参加反应的酶。例如乳酸脱氢酶、琥珀酸脱氢酶、细胞色素氧化酶、过氧化氢酶、过氧化物酶等。

:::definition{label="氧化还原酶类"}
催化氧化还原反应的酶属于氧化还原酶类（oxidoreductases），包括催化传递电子、氢以及需氧参加反应的酶。例如乳酸脱氢酶、琥珀酸脱氢酶、细胞色素氧化酶、过氧化氢酶、过氧化物酶等。$\mathrm{EC}$ 第一位数字为 $1$。
:::

### 2. 转移酶类

催化底物之间基团转移或交换的酶属于转移酶类（transferases）。例如甲基转移酶、氨基转移酶、乙酰转移酶、转硫酶、激酶和多聚酶等。

:::definition{label="转移酶类"}
催化底物之间基团转移或交换的酶属于转移酶类（transferases）。例如甲基转移酶、氨基转移酶、乙酰转移酶、转硫酶、激酶和多聚酶等。$\mathrm{EC}$ 第一位数字为 $2$。
:::

:::pitfall{label="激酶是转移酶，不是连接酶"}
激酶把 $\mathrm{ATP}$ 上的磷酸基转移到另一底物，本质是基团转移，落在转移酶类。连接酶要同时偶联高能键水解、把两分子连成一分子。把己糖激酶、蛋白质激酶写成第六类，表2-10 的谷氨酰胺合成酶会没有对立面。
:::

### 3. 水解酶类

催化底物发生水解反应的酶属于水解酶类（hydrolases）。按其所水解的底物不同可分为蛋白酶、核酸酶、脂肪酶和脲酶等。根据蛋白酶对底物蛋白的作用部位，可进一步分为内肽酶和外肽酶。同样，核酸酶也可分为外切核酸酶和内切核酸酶。

:::definition{label="水解酶类"}
催化底物发生水解反应的酶属于水解酶类（hydrolases）。按水解的底物不同可分为蛋白酶、核酸酶、脂肪酶和脲酶等。$\mathrm{EC}$ 第一位数字为 $3$。
:::

:::definition{label="内肽酶与外肽酶"}
根据蛋白酶对底物蛋白的作用部位，可进一步分为内肽酶和外肽酶。核酸酶同样可分为外切核酸酶和内切核酸酶。
:::

:::note{label="第四节的消化酶原多半是水解酶"}
胃蛋白酶、胰蛋白酶、胰凝乳蛋白酶、弹性蛋白酶、羧基肽酶，激活之后都是水解肽键。酶原激活本身也是水解掉肽段，但“酶属于哪一类”问的是成熟酶催化的反应类型。
:::

### 4. 裂合酶类

催化从底物移去一个基团并形成双键的反应或其逆反应的酶属于裂合酶类（lyases）。例如脱水酶、脱羧酶、醛缩酶、水化酶等。

:::definition{label="裂合酶类"}
催化从底物移去一个基团并形成双键的反应或其逆反应的酶属于裂合酶类（lyases）。例如脱水酶、脱羧酶、醛缩酶、水化酶等。$\mathrm{EC}$ 第一位数字为 $4$。
:::

:::insight{label="裂合可以正向切、也可以逆向加成"}
定义里写了“或其逆反应”。醛缩酶把果糖-1,6-二磷酸裂成两分子三碳糖，逆反应则是加成。不要把裂合听成“只能单向分解、永远不合成”。
:::

### 5. 异构酶类

催化分子内部基团的位置互变，几何或光学异构体互变，以及醛酮互变的酶属于异构酶类（isomerases）。例如变位酶、表异构酶、异构酶、消旋酶等。

:::definition{label="异构酶类"}
催化分子内部基团的位置互变、几何或光学异构体互变、以及醛酮互变的酶属于异构酶类（isomerases）。例如变位酶、表异构酶、异构酶、消旋酶等。$\mathrm{EC}$ 第一位数字为 $5$。
:::

:::pitfall{label="异构是分子内部改位置，不是把基团转到另一分子"}
转移酶在两分子之间交换基团；异构酶只在同一分子内部互变。磷酸丙糖异构酶让甘油醛-3-磷酸与磷酸二羟丙酮互变，底物还是那三个碳，没有第二分子来接基团。
:::

### 6. 连接酶类

催化两种底物形成一种产物并同时偶联有高能键水解和释能的酶属于连接酶类（ligases）。此类酶催化分子间的缩合反应，或同一分子两个末端的连接反应；在催化反应时需核苷三磷酸（$\mathrm{NTP}$）水解释能。例如 $\mathrm{DNA}$ 连接酶、氨酰 $\mathrm{tRNA}$ 合成酶、谷氨酰胺合成酶等。

:::definition{label="连接酶类"}
催化两种底物形成一种产物并同时偶联有高能键水解和释能的酶属于连接酶类（ligases）。催化分子间的缩合，或同一分子两个末端的连接；反应需核苷三磷酸（$\mathrm{NTP}$）水解释能。例如 $\mathrm{DNA}$ 连接酶、氨酰 $\mathrm{tRNA}$ 合成酶、谷氨酰胺合成酶等。$\mathrm{EC}$ 第一位数字为 $6$。
:::

### 7. 易位酶类

将离子或分子从膜的一面易位到另一面的酶属于易位酶类（translocase），又称“转位酶”，是 $2018$ 年新增加的一类。例如 $\mathrm{ABC}$ 型硫酸转运体、线粒体蛋白质转运 $\mathrm{ATP}$ 酶等。

:::definition{label="易位酶类"}
将离子或分子从膜的一面易位到另一面的酶属于易位酶类（translocase），又称转位酶，是 $2018$ 年新增加的一类。例如 $\mathrm{ABC}$ 型硫酸转运体、线粒体蛋白质转运 $\mathrm{ATP}$ 酶等。$\mathrm{EC}$ 第一位数字为 $7$。
:::

系统命名法最初对合酶（synthase）和合成酶（synthetase）进行了区分，合酶催化反应时不需要 $\mathrm{NTP}$ 供能，而合成酶需要。生物化学命名联合委员会（$\mathrm{JCBN}$）规定：无论利用 $\mathrm{NTP}$ 与否，合酶能够被用于催化合成反应的任何一种酶。因此合酶属于连接酶类。

:::definition{label="合酶与合成酶的旧区分"}
系统命名法最初区分合酶（synthase）和合成酶（synthetase）：合酶催化反应时不需要 $\mathrm{NTP}$ 供能，合成酶需要。
:::

:::definition{label="JCBN 对合酶的规定"}
生物化学命名联合委员会（$\mathrm{JCBN}$）规定：无论利用 $\mathrm{NTP}$ 与否，合酶能够被用于催化合成反应的任何一种酶。因此合酶属于连接酶类。
:::

:::pitfall{label="合酶现在按教材归连接酶，不要再按“要不要 ATP”一刀切"}
旧账：synthetase 要 $\mathrm{NTP}$，synthase 不要。新账：$\mathrm{JCBN}$ 允许合酶用于任何合成反应，教材据此写“合酶属于连接酶类”。看见“合酶”不要立刻改写成裂合酶或转移酶；按本节，户头在第六类。
:::

国际系统分类法除按上述 $7$ 类将酶依次编号外，还根据酶所催化的化学键的特点和参加反应的基团不同，将每一大类又进一步分类。每种酶的分类编号均由 $4$ 组数字组成，数字前冠以 $\mathrm{EC}$（enzyme classification）。编号中第 $1$ 个数字表示该酶属于 $7$ 大类中的哪一类；第 $2$ 个数字表示该酶属于哪一亚类；第 $3$ 个数字表示亚-亚类；第 $4$ 个数字是该酶在亚-亚类中的排序（表2-10）。

:::definition{label="EC 编号"}
每种酶的分类编号均由 $4$ 组数字组成，数字前冠以 $\mathrm{EC}$（enzyme classification）。第 $1$ 个数字：$7$ 大类中的哪一类；第 $2$ 个数字：亚类；第 $3$ 个数字：亚-亚类；第 $4$ 个数字：该酶在亚-亚类中的排序。亚类和亚-亚类按所催化化学键的特点和参加反应的基团进一步划分。
:::

:::derivation{title="EC 四组数字怎么读"}
以表2-10 的 $\mathrm{L}$-乳酸脱氢酶为例：

$$
\mathrm{EC}.1.1.1.27
$$

- 第 $1$ 位 $1$：氧化还原酶类
- 第 $2$ 位 $1$：该大类中的亚类
- 第 $3$ 位 $1$：亚-亚类
- 第 $4$ 位 $27$：该亚-亚类中的排序

同理，$\mathrm{EC}.2.6.1.2$ 是谷丙转氨酶，$\mathrm{EC}.3.2.1.1$ 是 $\alpha$-淀粉酶，$\mathrm{EC}.4.1.2.13$ 是果糖双磷酸醛缩酶，$\mathrm{EC}.5.3.1.1$ 是磷酸丙糖异构酶，$\mathrm{EC}.6.3.1.2$ 是谷氨酰胺合成酶，$\mathrm{EC}.7.4.2.3$ 是线粒体蛋白质转运 $\mathrm{ATP}$ 酶。
:::

## 二、每一种酶均有其系统名称和推荐名称

在酶学研究早期，酶的命名缺乏系统的规则，酶的名称多由发现者确定。虽然这些习惯名称多是根据酶所催化的底物、反应的性质以及酶的来源而定的，但常出现混乱。有的名称（如心肌黄酶、触酶等）完全不能说明酶促反应的本质。为了克服习惯名称的弊端，国际生物化学与分子生物学会（$\mathrm{IUBMB}$）以酶的分类为依据，于 $1961$ 年提出系统命名法。系统命名法规定每一个酶都有一个系统名称（systematic name），它标明酶的所有底物与反应性质。底物名称之间以“：”分隔。由于许多酶促反应是双底物或多底物反应，且许多底物的化学名称太长，这使许多酶的系统名称过长和过于复杂。为了应用方便，国际酶学委员会又从每种酶的数个习惯名称中选定一个简便实用的推荐名称（recommended name）（表2-10）。

:::definition{label="习惯名称"}
酶学研究早期，酶的名称多由发现者确定。习惯名称多根据所催化的底物、反应的性质以及酶的来源而定，但常出现混乱。有的名称如心肌黄酶、触酶等，完全不能说明酶促反应的本质。
:::

:::definition{label="系统名称"}
系统命名法规定每一个酶都有一个系统名称（systematic name），标明酶的所有底物与反应性质。底物名称之间以“：”分隔。$\mathrm{IUBMB}$ 于 $1961$ 年以酶的分类为依据提出。
:::

:::definition{label="推荐名称"}
由于双底物或多底物反应、以及底物化学名称太长，系统名称往往过长、过于复杂。国际酶学委员会从每种酶的数个习惯名称中选定一个简便实用的推荐名称（recommended name）。表2-10 右列即推荐名称。
:::

:::example{label="系统名称怎么读“：”"}
$\mathrm{L}$-乳酸：$\mathrm{NAD}^{+}$-氧化还原酶——底物是 $\mathrm{L}$-乳酸和 $\mathrm{NAD}^{+}$，反应性质是氧化还原，推荐名称是 $\mathrm{L}$-乳酸脱氢酶。$\mathrm{L}$-丙氨酸：$\alpha$-酮戊二酸氨基转移酶——两底物之间转移氨基，推荐名称是谷丙转氨酶。$\mathrm{L}$-谷氨酸：氨连接酶（生成 $\mathrm{ADP}$）——连接谷氨酸与氨，并生成 $\mathrm{ADP}$，推荐名称是谷氨酰胺合成酶。
:::

| 项目 | 习惯名称 | 系统名称 | 推荐名称 |
|------|----------|----------|----------|
| 谁起的 | 发现者，早期无统一规则 | $1961$ 年 $\mathrm{IUBMB}$ 系统命名法 | 国际酶学委员会从习惯名中选定 |
| 依据 | 底物、反应性质、来源，有时完全不说明本质 | 所有底物 $+$ 反应性质；底物之间以“：”分隔 | 简便实用 |
| 问题 | 混乱，如心肌黄酶、触酶 | 双底物／多底物时过长、过于复杂 | 日常使用 |
| 表2-10 例子 | — | $\mathrm{L}$-乳酸：$\mathrm{NAD}^{+}$-氧化还原酶 | $\mathrm{L}$-乳酸脱氢酶 |
:::

:::pitfall{label="推荐名称不是另起一套与系统名称无关的名字"}
推荐名称是从数个习惯名称里选定的那一个，仍然对应同一个 $\mathrm{EC}$ 编号、同一个系统名称。不要把“乳酸脱氢酶”和“$\mathrm{L}$-乳酸：$\mathrm{NAD}^{+}$-氧化还原酶”听成两种酶。心肌黄酶、触酶这类完全不说明反应本质的习惯名，才是系统命名要克服的对象。
:::

:::keypoint{label="分类与命名收口"}
- 按反应类型分 $7$ 大类，不是按器官、也不是按习惯名。
- $\mathrm{EC}$ 四组数字：类、亚类、亚-亚类、排序。
- 每个酶：系统名称（底物：底物-反应性质）$+$ 推荐名称（简便习惯名）。
- 合酶按 $\mathrm{JCBN}$ 规定属于连接酶类；易位酶是 $2018$ 年新增第七类。
:::

:::memory{label="本节必背要点"}
- [ ] 已发现 $4000$ 多种酶；$1961$ 年推荐系统命名法及分类方法。
- [ ] 按催化反应类型分为 $7$ 大类。
- [ ] 氧化还原酶类（oxidoreductases）：传电子、氢，需氧参加；乳酸脱氢酶、琥珀酸脱氢酶、细胞色素氧化酶、过氧化氢酶、过氧化物酶。
- [ ] 转移酶类（transferases）：基团转移或交换；甲基／氨基／乙酰转移酶、转硫酶、激酶、多聚酶。
- [ ] 水解酶类（hydrolases）：水解；蛋白酶、核酸酶、脂肪酶、脲酶；蛋白酶分内肽酶／外肽酶，核酸酶分外切／内切。
- [ ] 裂合酶类（lyases）：移去基团并形成双键或其逆反应；脱水酶、脱羧酶、醛缩酶、水化酶。
- [ ] 异构酶类（isomerases）：分子内位置、几何或光学异构、醛酮互变；变位酶、表异构酶、异构酶、消旋酶。
- [ ] 连接酶类（ligases）：两底物成一产物并偶联高能键水解，需 $\mathrm{NTP}$；$\mathrm{DNA}$ 连接酶、氨酰 $\mathrm{tRNA}$ 合成酶、谷氨酰胺合成酶。
- [ ] 易位酶类（translocase，转位酶）：$2018$ 年新增；离子或分子跨膜易位；$\mathrm{ABC}$ 型硫酸转运体、线粒体蛋白质转运 $\mathrm{ATP}$ 酶。
- [ ] 旧区分：合酶不需 $\mathrm{NTP}$，合成酶需要；$\mathrm{JCBN}$ 规定合酶可用于任何合成反应，故合酶属于连接酶类。
- [ ] $\mathrm{EC}$ 四组数字：类、亚类、亚-亚类、排序。
- [ ] 表2-10：$\mathrm{EC}.1.1.1.27$ 乳酸脱氢酶；$\mathrm{EC}.2.6.1.2$ 谷丙转氨酶；$\mathrm{EC}.3.2.1.1$ $\alpha$-淀粉酶；$\mathrm{EC}.4.1.2.13$ 果糖双磷酸醛缩酶；$\mathrm{EC}.5.3.1.1$ 磷酸丙糖异构酶；$\mathrm{EC}.6.3.1.2$ 谷氨酰胺合成酶；$\mathrm{EC}.7.4.2.3$ 线粒体蛋白质转运 $\mathrm{ATP}$ 酶。
- [ ] 习惯名常混乱（心肌黄酶、触酶）；系统名称标明所有底物与反应性质，底物之间以“：”分隔。
- [ ] 系统名称往往过长，故从习惯名中选定推荐名称。
:::
