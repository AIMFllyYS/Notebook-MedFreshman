# 第一节　肝在物质代谢中的作用

第二十五章把肝写成人体最大的实质性器官、最大的腺体和代谢器官。本节只立「肝在物质代谢中的作用」：四条结构特点（图25-1）先给血供、输出、血窦和酶体系；再按糖、脂质、蛋白质、维生素、激素五本账摊开；图25-2 把肝糖原、糖异生、尿素、酮体、胆固醇和胆汁酸收成一张网。成人肝约重 $1\,500\,\mathrm{g}$、占体重 $2\%\sim 2.5\%$、血流量约占心输出量 $1/4$、每日胆汁 $600\sim 1\,000\,\mathrm{ml}$、胆固醇肝合成约 $75\%$、约 $50\%$ 在肝内转化成胆汁酸——这些数字按本版记，不要换成别的教材。生物转化的两相反应交给第二节；胆汁酸分类、肠肝循环和胆色素是第三、四节的账，本节只点名。

:::concept{term="先问肝凭什么能当化工厂，再问糖脂蛋白各走哪条路"}
看见「肝的生物化学」，先不要默写胆汁酸结构式。户头是：独特结构赋予复杂功能。双重血供、双重输出、肝血窦慢流、丰富细胞器与酶（有的肝独有）四条先立住。糖问血糖能不能稳住，脂质问消化、酮体和胆固醇，蛋白质问血浆蛋白和尿素，维生素和激素问储存、转化和灭活。图25-2 再把「肝特有」和「肝脏为主」分开认。把「肝＝解毒」写成全章标题，第二节的生物转化和第三节的胆汁就没有户头。
:::

:::note{label="电子版缺失"}
本章开篇章题图电子版缺失，正文不嵌入该图。本节使用的插图是图25-1（肝脏的结构特点：肝动脉与门静脉双重供血，肝静脉与胆道双重输出）和图25-2（肝中主要代谢途径及联系：深色为肝脏特有，浅色为肝脏为主）。图25-3 起的反应式在第二节。
:::

肝是人体最大的实质性器官，也是体内最大的腺体和代谢器官。成人肝组织约重 $1\,500\,\mathrm{g}$，约占体重的 $2\%\sim 2.5\%$。独特的结构特点，赋予肝复杂多样的生物化学功能。

:::definition{label="肝的体量和身份"}
人体最大的实质性器官，也是体内最大的腺体和代谢器官。本版数字：成人约重 $1\,500\,\mathrm{g}$，约占体重 $2\%\sim 2.5\%$。户头先落在「大」和「代谢」，还不是「只解毒」。
:::

:::keypoint{label="开篇四个数字先钉死"}
- 体重：$1\,500\,\mathrm{g}$。
- 占比：$2\%\sim 2.5\%$。
- 血流量：约占心输出量 $1/4$（写在双重血供那一条里）。
- 胆汁：每天排出 $600\sim 1\,000\,\mathrm{ml}$（写在双重输出那一条里）。
:::

:::pitfall{label="不要用别的教材替换本版数字"}
有的书把肝重写成 $1.2\sim 1.5\,\mathrm{kg}$，把血流量写成 $1/3$，把日分泌胆汁写成 $800\sim 1\,000\,\mathrm{ml}$。本版是 $1\,500\,\mathrm{g}$、$2\%\sim 2.5\%$、$1/4$、$600\sim 1\,000\,\mathrm{ml}$。胆固醇肝合成约 $75\%$、约 $50\%$ 在肝内转化成胆汁酸，同样按本版，不要改成「几乎全部」或「三分之一」。
:::

## 肝的结构特点是物质代谢的解剖学前提

肝的结构特点见图25-1，包括四条。四条要一起答：缺一条，后文糖、脂、蛋白、生物转化都会少一块底板。

:::definition{label="双重血液供应"}
肝具有肝动脉和门静脉双重血液供应。肝脏血流量约占心输出量的 $1/4$。肝动脉运来肺及其他组织的氧和代谢物；门静脉运来肠道吸收的各种营养物质。两路都进肝，才为各种物质在肝的代谢奠定物质基础。
:::

:::definition{label="双重输出通道"}
存在肝静脉和胆道系统双重输出通道。肝静脉把肝内代谢中间物或代谢产物运到其他组织利用或排出体外；胆道系统与肠道相通，把肝分泌的胆汁排入肠道，同时排出一些代谢废物。肝脏每天排出 $600\sim 1\,000\,\mathrm{ml}$ 胆汁。
:::

:::definition{label="肝血窦血流慢"}
肝脏内有上百万个肝小叶。相邻肝小叶之间分布小叶间动脉和小叶间静脉，均进入肝血窦。血窦血流速率慢，为肝细胞与血液进行充分的物质交换提供了时间保证。
:::

:::definition{label="丰富的细胞器与酶"}
肝细胞含有丰富的细胞器（如内质网、线粒体、溶酶体等）和丰富的酶体系，有些甚至是肝所独有的。因此肝细胞除存在一般细胞所具有的代谢途径外，还具有一些特殊的代谢功能。尿素合成所需的氨基甲酰磷酸合成酶Ⅰ和鸟氨酸氨基甲酰转移酶只存在于肝细胞线粒体，就是后文「肝独有」的例子。
:::

:::compare{title="双重血供 vs 双重输出"}
| | 本版原句 | 进／出什么 | 不要写成 |
|--|---------|-----------|---------|
| 肝动脉 | 肺及其他组织运来的氧和代谢物 | 进：$\mathrm{O}_2$、肝外代谢物 | 「肝只吃门静脉的营养」 |
| 门静脉 | 肠道吸收的各种营养物质 | 进：营养 | 「门静脉等于肝静脉」 |
| 肝静脉 | 代谢中间物或产物到其他组织利用或排出 | 出：入体循环 | 「肝静脉也排胆汁」 |
| 胆道 | 胆汁入肠，并排出代谢废物 | 出：每日 $600\sim 1\,000\,\mathrm{ml}$ 胆汁 | 「胆汁只是消化液、不含排泄」 |

问「肝为什么代谢旺盛」先答双重血供加血窦慢流；问「代谢产物怎么走」再分肝静脉和胆道两户。
:::

:::pitfall{label="四条结构不要并成「肝血多」一句"}
血供、输出、血窦、酶体系是四户。写成「肝血多所以功能多」，门静脉的营养、胆道的排泄、肝独有的酶都会被吞掉。图25-1 画面上也是左边「双重输出通道」、右边「双重血液供应」，不是一张「血流量示意图」。
:::

::figure{src="/images/biochemistry/textbook/p0488_02.png" caption="图25-1　肝脏的结构特点" alt="肝脏示意图。右上肝动脉：肺来源的氧气及其他组织的代谢物，标双重血液供应；右下肝门静脉：消化道吸收的营养。左上肝静脉与体循环相接，输出代谢中间物或产物；左下胆道系统分泌胆汁、胆红素等代谢物，标双重输出通道"}

:::insight{label="图25-1 先认右边进去、左边出去"}
画面右侧是双重血液供应：肝动脉带肺来源的 $\mathrm{O}_2$ 和其他组织的代谢物，门静脉带消化道吸收的营养。左侧是双重输出通道：肝静脉与体循环相接，输出代谢中间物或产物；胆道系统分泌胆汁、胆红素等代谢物。胆红素在这里只是输出名单里的一个词，展开是第四节。不要把这张图认成「只有门静脉进、只有肝静脉出」。
:::

:::keypoint{label="结构四条对应后文功能"}
- 双重血供：氧＋营养都进肝，糖脂蛋白才有原料。
- 双重输出：中间物走肝静脉，胆汁和部分废物走胆道。
- 血窦慢流：交换时间够，不是「流速快才高效」。
- 细胞器与酶：一般途径之外还有肝独有功能（尿素、酮体生成、生物转化主场）。
:::

肝脏的主要生理功能是进行糖的分解、储存糖原和糖异生；参与蛋白质、脂肪、维生素、激素的代谢；解毒；分泌胆汁；吞噬、防御机能；制造凝血因子；调节血容量及水电解质平衡；胚胎时期肝脏还有造血功能。因此，肝脏被比喻为人体内的“化工厂”。

:::definition{label="化工厂这一句的职分名单"}
糖的分解、储存糖原和糖异生；蛋白质、脂肪、维生素、激素代谢；解毒；分泌胆汁；吞噬、防御；制造凝血因子；调节血容量及水电解质平衡；胚胎期造血。名单要整份记，不要只留「解毒」。
:::

:::pitfall{label="解毒和分泌胆汁在本节只点名"}
开篇把解毒、分泌胆汁写进化工厂名单，不等于本节展开两相反应或胆汁酸分类。生物转化是第二节；胆汁与胆汁酸是第三节；胆色素是第四节。本节后文脂质段会再碰到胆汁酸，蛋白质段会再碰到胆红素作为清蛋白的配基——都只当点名。
:::

:::insight{label="胚胎期造血不要写成成人肝还造血"}
教材把造血功能限定在胚胎时期。成人肝的主账是代谢、分泌、防御和凝血因子，不是重新当骨髓用。
:::

## 一、肝是维持血糖水平相对稳定的重要器官

肝脏是调节血糖的重要器官，主要通过糖原合成与分解、糖异生以及其他单糖的转化来维持血糖水平的相对恒定，以保障全身各组织，尤其是大脑和红细胞的能量供应。

:::definition{label="肝调节血糖的三条路"}
糖原合成与分解、糖异生、其他单糖转化为葡萄糖。目的是维持血糖相对恒定，保障全身各组织，尤其是大脑和红细胞的能量供应。
:::

:::keypoint{label="血糖这一小节先问给谁供能"}
- 对象：全身，尤其大脑和红细胞。
- 手段：肝糖原、糖异生、果糖／半乳糖转葡萄糖。
- 后文肌糖原补不了血糖，因为肌组织没有葡萄糖-6-磷酸酶。
:::

肝细胞膜葡萄糖转运蛋白2（glucose transporter 2，$\mathrm{GLUT2}$）能有效转运葡萄糖，可使肝细胞内的葡萄糖浓度与血糖浓度保持一致。肝细胞含有特异的己糖激酶同工酶Ⅳ，即葡萄糖激酶。其 $K_{\mathrm{m}}$（$10\,\mathrm{mmol/L}$）较肝外组织的己糖激酶（$0.1\,\mathrm{mmol/L}$）高得多，且不被其产物葡萄糖-6-磷酸所抑制。这利于肝在饱食状态下血糖浓度很高时，仍可持续将葡萄糖磷酸化成葡萄糖-6-磷酸，并将其合成肝糖原贮存，成人肝糖原总量可达 $75\sim 100\,\mathrm{g}$。血糖高时，葡萄糖-6-磷酸除氧化供能以及合成糖原储存外，还可在肝内转变成脂肪，并以极低密度脂蛋白（$\mathrm{VLDL}$）的形式运出肝外，贮存于脂肪组织。

:::definition{label="GLUT2"}
肝细胞膜葡萄糖转运蛋白2（$\mathrm{GLUT2}$）能有效转运葡萄糖，使肝细胞内葡萄糖浓度与血糖浓度保持一致。户头是「跟着血糖走」，不是另设一套与血糖无关的肝内池。
:::

:::definition{label="葡萄糖激酶"}
肝细胞特异的己糖激酶同工酶Ⅳ，即葡萄糖激酶。$K_{\mathrm{m}}$ 为 $10\,\mathrm{mmol/L}$，肝外组织己糖激酶为 $0.1\,\mathrm{mmol/L}$，且不被产物葡萄糖-6-磷酸抑制。饱食血糖很高时仍可持续磷酸化葡萄糖，供肝糖原贮存。
:::

:::definition{label="成人肝糖原总量"}
可达 $75\sim 100\,\mathrm{g}$。这是短期饥饿补血糖的储备，不是「够饿好几天」。后文写：较长时间禁食时，肝糖原在 $12\sim 18$ 小时内几乎耗尽。
:::

:::compare{title="葡萄糖激酶 vs 肝外己糖激酶"}
| | 葡萄糖激酶（同工酶Ⅳ） | 肝外己糖激酶 |
|--|---------------------|------------|
| 所在 | 肝细胞 | 肝外组织 |
| $K_{\mathrm{m}}$ | $10\,\mathrm{mmol/L}$ | $0.1\,\mathrm{mmol/L}$ |
| 产物抑制 | 不被葡萄糖-6-磷酸抑制 | 本版用「较……高得多，且不被抑制」对照肝这户 |
| 生理意义 | 血糖很高时仍能持续磷酸化、合成肝糖原 | $K_{\mathrm{m}}$ 低，低血糖时组织仍能摄取 |

问「为什么餐后肝还能继续吃糖」看 $K_{\mathrm{m}}$ 高且不受 $\mathrm{G}$-6-$\mathrm{P}$ 抑制；问「肌糖原为什么不直接补血糖」看后文葡萄糖-6-磷酸酶。
:::

:::insight{label="餐后多余的糖可以变成 VLDL 里的脂肪"}
血糖高时，葡萄糖-6-磷酸除氧化供能、合成糖原外，还可在肝内转变成脂肪，以 $\mathrm{VLDL}$ 运出肝外、贮存于脂肪组织。这一句已经接到脂质段：肝是内源性甘油三酯的主要来源。
:::

:::pitfall{label="GLUT2 不是胰岛素依赖的那一户"}
本版只写 $\mathrm{GLUT2}$ 使肝细胞内葡萄糖浓度与血糖一致。不要把肌、脂肪的胰岛素依赖转运蛋白写进这一句，也不要把 $K_{\mathrm{m}}$ $10\,\mathrm{mmol/L}$ 安到 $\mathrm{GLUT2}$ 头上——那是葡萄糖激酶的数字。
:::

肝细胞内含有葡萄糖-6-磷酸酶（该酶不存在于肌组织）。在空腹状态下，可将肝糖原分解生成的葡萄糖-6-磷酸直接转化成葡萄糖以补充血糖。肝细胞还存在一套完整的糖异生酶系，是糖异生最重要的器官。较长时间禁食时，储存有限的肝糖原在 $12\sim 18$ 小时内几乎耗尽，糖异生则成为产糖的唯一来源。此时，肝通过糖异生将生糖氨基酸、乳酸及甘油等非糖物质转变成葡萄糖，维持血糖相对恒定。肝还能将小肠吸收的其他单糖如果糖及半乳糖转化为葡萄糖，作为血糖的补充来源。因此肝细胞严重损伤时，易造成糖代谢紊乱。

:::definition{label="葡萄糖-6-磷酸酶"}
存在于肝细胞，不存在于肌组织。空腹时把肝糖原分解生成的葡萄糖-6-磷酸直接转化成葡萄糖以补充血糖。肌糖原分解停在葡萄糖-6-磷酸，补不了血糖。
:::

:::definition{label="肝是糖异生最重要的器官"}
肝细胞有一套完整的糖异生酶系。较长时间禁食时，肝糖原 $12\sim 18$ 小时内几乎耗尽，糖异生成为产糖的唯一来源。原料：生糖氨基酸、乳酸、甘油等非糖物质。
:::

:::definition{label="其他单糖转化为葡萄糖"}
小肠吸收的果糖及半乳糖可在肝转化为葡萄糖，作为血糖的补充来源。不是「果糖自己维持血糖」。
:::

:::compare{title="饱食 vs 空腹 vs 较长时间禁食"}
| | 肝怎么处理糖 | 本版数字／酶 |
|--|------------|-------------|
| 饱食 | 持续磷酸化，合成肝糖原；多余的走脂肪／$\mathrm{VLDL}$ | 葡萄糖激酶 $K_{\mathrm{m}}$ $10\,\mathrm{mmol/L}$；肝糖原 $75\sim 100\,\mathrm{g}$ |
| 空腹 | 肝糖原分解，葡萄糖-6-磷酸酶放葡萄糖入血 | 肌组织无此酶 |
| 较长时间禁食 | 肝糖原 $12\sim 18$ 小时耗尽，糖异生成为唯一产糖来源 | 生糖氨基酸、乳酸、甘油 |

问「饿一夜靠什么」先答肝糖原；问「再饿下去」才答糖异生。不要把肌糖原写成血糖来源。
:::

:::pitfall{label="12～18 小时耗尽的是肝糖原，不是全身能源"}
「储存有限的肝糖原在 $12\sim 18$ 小时内几乎耗尽」这一句只管肝糖原。脂质段还写饥饿时酮体可占大脑供能的 $60\%\sim 70\%$。写成「18 小时后人体没有能源」，酮体那一户就没了。
:::

:::cause-effect{title="肝细胞严重损伤 → 糖代谢紊乱"}
肝细胞严重损伤时，糖原合成／分解、糖异生和其他单糖转化都受影响，易造成糖代谢紊乱。临床见到的低血糖或糖耐量异常，户头先问肝还能不能当调节器官，不要先改写成「胰岛素一项」。
:::

肝细胞的磷酸戊糖途径也很活跃，为肝的生物转化作用提供足够的 $\mathrm{NADPH}$。此外，肝细胞中的葡萄糖还可通过糖醛酸途径生成 $\mathrm{UDP}$-葡萄糖醛酸（$\mathrm{UDPGA}$），作为肝生物转化结合反应中最重要的结合物质。

:::definition{label="磷酸戊糖途径给生物转化提供 NADPH"}
肝细胞磷酸戊糖途径活跃，为肝的生物转化作用提供足够的 $\mathrm{NADPH}$。第二节单加氧酶系的辅酶就是 $\mathrm{NADPH}+\mathrm{H}^{+}$、$\mathrm{O}_2$ 和细胞色素 $\mathrm{P}450$。
:::

:::definition{label="糖醛酸途径生成 UDPGA"}
肝细胞中的葡萄糖可通过糖醛酸途径生成 $\mathrm{UDPGA}$，这是肝生物转化结合反应中最重要的结合物质。展开葡萄糖醛酸结合是第二节；本节只把原料立住。
:::

:::insight{label="糖这一节已经给第二节留了两样东西"}
$\mathrm{NADPH}$ 和 $\mathrm{UDPGA}$ 都从葡萄糖代谢来。写成「糖代谢与解毒无关」，第一相氧化和第二相葡萄糖醛酸结合都会缺辅因子。
:::

## 二、肝在脂质代谢中占据中心地位

肝在脂质的消化、吸收、分解、合成及运输等代谢过程中均具有重要作用。肝细胞合成并分泌胆汁酸，为脂质（包括脂溶性维生素）的消化、吸收所必需。肝损伤时，肝分泌胆汁能力下降；胆管阻塞时，胆汁排出障碍，均可导致脂质的消化吸收不良，产生厌油腻和脂肪泻等临床症状。

:::definition{label="胆汁酸在本节的职分"}
肝细胞合成并分泌胆汁酸，为脂质（包括脂溶性维生素）的消化、吸收所必需。厌油腻、脂肪泻可以是肝损伤分泌下降，也可以是胆管阻塞排出障碍。分类、初级／次级、肠肝循环是第三节，本节点名即可。
:::

:::pitfall{label="厌油腻不要只答「肝炎」"}
教材并写两户：肝损伤→分泌胆汁能力下降；胆管阻塞→胆汁排出障碍。都可以消化吸收不良。写成「只有肝炎才厌油」，阻塞性黄疸那一户会对不上第三节。
:::

肝可有效协调脂肪酸氧化供能和酯化合成甘油三酯两条途径。饱食状态下，肝将过剩的葡萄糖分解为乙酰 $\mathrm{CoA}$ 并转变成脂肪酸，并进一步合成甘油三酯，这是内源性甘油三酯的主要来源。肝也可将某些氨基酸经乙酰 $\mathrm{CoA}$ 转变成脂肪酸和甘油三酯。肝还可摄取来自消化道的外源性脂肪酸，部分经 $\beta$-氧化彻底分解，释放能量供肝利用，剩余部分用于合成甘油三酯。肝合成的内源性甘油三酯与来自消化道的外源性和肝自身合成的胆固醇、磷脂一起，组装成 $\mathrm{VLDL}$ 分泌入血，经血液运输至肝外组织摄取和利用。饥饿状态下，机体脂库的脂肪动员增加，释放出脂肪酸和甘油，经血液运输至肝代谢。肝细胞可将脂肪酸 $\beta$-氧化产生的乙酰 $\mathrm{CoA}$，部分经三羧酸循环彻底氧化释放能量供肝利用；其余大部分则在肝细胞内合成酮体。肝是体内产生酮体的重要器官。酮体则是肝向肝外组织输出脂质能源的一种形式，供肝外组织尤其脑和肌肉氧化利用。饥饿时酮体可占大脑供能的 $60\%\sim 70\%$。

:::definition{label="内源性甘油三酯的主要来源"}
饱食时，肝将过剩葡萄糖分解为乙酰 $\mathrm{CoA}$ → 脂肪酸 → 甘油三酯。某些氨基酸也可经乙酰 $\mathrm{CoA}$ 走同一条路。外源性脂肪酸被肝摄取后，一部分 $\beta$-氧化供能，剩余部分也合成甘油三酯。
:::

:::definition{label="VLDL 从肝运出脂肪"}
肝合成的内源性甘油三酯，与来自消化道的外源性和肝自身合成的胆固醇、磷脂一起，组装成 $\mathrm{VLDL}$ 分泌入血，供肝外组织摄取利用。磷脂合成障碍会影响 $\mathrm{VLDL}$ 的合成和分泌，后文脂肪肝机制就落在这里。
:::

:::definition{label="肝是产生酮体的重要器官"}
饥饿时脂库动员，脂肪酸和甘油运至肝。$\beta$-氧化产生的乙酰 $\mathrm{CoA}$，一部分经三羧酸循环彻底氧化供肝自己用，其余大部分在肝细胞内合成酮体。酮体是肝向肝外输出脂质能源的形式，尤其供脑和肌肉。饥饿时酮体可占大脑供能的 $60\%\sim 70\%$。图25-2 把这一条标成「长期饥饿或高脂」。
:::

:::compare{title="饱食合成甘油三酯 vs 饥饿生成酮体"}
| | 乙酰 $\mathrm{CoA}$ 的去向 | 运出肝的形式 | 本版原句 |
|--|----------------------|------------|---------|
| 饱食 | 脂肪酸 → 甘油三酯 | $\mathrm{VLDL}$ | 内源性甘油三酯的主要来源 |
| 饥饿 | 大部分合成酮体 | 酮体（水溶性储能小分子） | 肝外尤其脑和肌肉利用；$60\%\sim 70\%$ 大脑供能 |

两条都从乙酰 $\mathrm{CoA}$ 出发，不要写成「肝不能氧化脂肪酸」或「酮体在肝内被氧化利用」。肝生成酮体，利用在肝外。
:::

:::pitfall{label="酮体不是肝给自己留的燃料"}
教材写：酮体是肝向肝外组织输出脂质能源的一种形式。肝自己用的是 $\beta$-氧化和三羧酸循环那一部分乙酰 $\mathrm{CoA}$。写成「饥饿时肝靠酮体供能」，输出方向就反了。
:::

:::insight{label="甘油也能糖异生"}
饥饿动员出来的不只有脂肪酸，还有甘油。糖那一节已经把甘油列为糖异生原料。脂质段和糖段在甘油这里会合，不是两套无关的账。
:::

肝在调节机体胆固醇代谢平衡上起中心作用。肝是合成胆固醇的主要器官，其合成量占全身合成总量的 $3/4$ 以上。肝又是转化及排出胆固醇的主要器官。胆汁酸的生成是肝降解胆固醇的最重要途径。肝能通过 apo E 受体、$\mathrm{LDL}$ 受体和 $\mathrm{HDL}$ 受体，从血液中摄取外源性胆固醇、内源性胆固醇和肝外组织细胞多余胆固醇，以直接形式或转化成胆汁酸，随胆汁排出。肝对胆固醇的酯化也具有重要作用。肝合成的卵磷脂：胆固醇脂酰基转移酶（$\mathrm{LCAT}$）可将胆固醇转化为胆固醇酯以利运输。严重肝损伤时，胆固醇合成和 $\mathrm{LCAT}$ 的生成均受影响，故除血浆胆固醇含量减少外，血浆胆固醇酯的降低往往出现得更早、更明显。

:::definition{label="胆固醇肝合成约 75%"}
肝是合成胆固醇的主要器官，合成量占全身合成总量的 $3/4$ 以上。第六小节和图25-2 把同一笔写成「大约 $75\%$ 的胆固醇在肝脏内生成」。两句是同一本账，不要改成别的百分比。
:::

:::definition{label="约 50% 胆固醇在肝内转化成胆汁酸"}
胆汁酸的生成是肝降解胆固醇的最重要途径。第六小节写：肝将体内约 $50\%$ 的胆固醇转化为胆汁酸，这是胆固醇排出的主要形式。展开初级／次级胆汁酸是第三节。
:::

:::definition{label="肝摄取胆固醇的三条受体"}
apo E 受体、$\mathrm{LDL}$ 受体、$\mathrm{HDL}$ 受体。分别对应外源性胆固醇、内源性胆固醇和肝外组织细胞多余胆固醇。摄取之后以直接形式或转化成胆汁酸，随胆汁排出。
:::

:::definition{label="LCAT"}
卵磷脂：胆固醇脂酰基转移酶（$\mathrm{LCAT}$）由肝合成，将胆固醇转化为胆固醇酯以利运输。严重肝损伤时，胆固醇合成和 $\mathrm{LCAT}$ 生成均受影响；血浆胆固醇酯降低往往比血浆胆固醇含量减少出现得更早、更明显。
:::

:::compare{title="胆固醇：合成、转化、酯化、摄取"}
| 职分 | 本版原句 | 临床／后文 |
|------|---------|-----------|
| 合成 | 占全身 $3/4$ 以上（约 $75\%$） | 严重肝损伤时血浆胆固醇可减少 |
| 转化排出 | 约 $50\%$ 转成胆汁酸 | 第三节展开；本节只点名 |
| 酯化 | 肝合成 $\mathrm{LCAT}$ | 胆固醇酯降低更早、更明显 |
| 摄取 | apo E／$\mathrm{LDL}$／$\mathrm{HDL}$ 受体 | 图25-2：约 $50\%$ 经 $\mathrm{LDLR}$ 摄入肝 |

问「肝是不是只合成胆固醇」——合成、转化、酯化、摄取四句都要答。
:::

:::pitfall{label="胆固醇酯降低不要等到总胆固醇已经很低才想起来"}
教材特意写：血浆胆固醇酯的降低往往出现得更早、更明显。这是 $\mathrm{LCAT}$ 生成受影响的窗口，不是「总胆固醇正常就说明肝脂代谢没事」。
:::

肝在血浆脂蛋白代谢中亦起重要作用。肝脏合成的载脂蛋白（如 apo AI，apo B100，apo CI 等）对脂蛋白运输发挥重要作用。肝细胞膜上特异性分布 $\mathrm{LDL}$ 受体，可识别 $\mathrm{LDL}$ 并将其内吞入肝细胞降解。$\mathrm{HDL}$ 也主要在肝合成，将肝外的胆固醇转移到肝内处理。肝细胞合成的 apo CⅡ 可激活肝外组织毛细血管内皮细胞表面的 $\mathrm{LPL}$，在血浆 $\mathrm{CM}$ 和 $\mathrm{VLDL}$ 的甘油三酯分解代谢中具有不可或缺的作用。

:::definition{label="肝合成的载脂蛋白"}
本版点名 apo AI、apo B100、apo CI 等；后文蛋白质段还写 apo A、B、C、E 等。apo CⅡ 激活肝外毛细血管内皮表面的 $\mathrm{LPL}$，对 $\mathrm{CM}$ 和 $\mathrm{VLDL}$ 的甘油三酯分解不可或缺。
:::

:::definition{label="LDL 受体与 HDL 的胆固醇逆转运"}
肝细胞膜特异分布 $\mathrm{LDL}$ 受体，识别 $\mathrm{LDL}$ 并内吞降解。图25-2 旁注「约 $50\%$ 经 $\mathrm{LDLR}$ 摄入肝」。$\mathrm{HDL}$ 主要在肝合成，把肝外胆固醇转移到肝内处理。
:::

:::pitfall{label="LPL 不在肝细胞内切甘油三酯"}
apo CⅡ 在肝合成，但激活的是肝外组织毛细血管内皮细胞表面的 $\mathrm{LPL}$。写成「肝脂蛋白脂酶在肝细胞里水解 $\mathrm{VLDL}$」，$\mathrm{CM}$／$\mathrm{VLDL}$ 外周分解那一户就搬错地方。
:::

肝内磷脂的合成非常活跃，尤其是卵磷脂的合成。磷脂合成障碍可影响 $\mathrm{VLDL}$ 的合成和分泌，导致肝内脂肪运出障碍而在肝中堆积，成为脂肪肝发生的机制之一。

:::definition{label="磷脂与脂肪肝"}
肝内磷脂合成活跃，尤其是卵磷脂。磷脂合成障碍 → $\mathrm{VLDL}$ 合成和分泌受影响 → 肝内脂肪运出障碍而堆积 → 脂肪肝发生机制之一。不是「吃油多就等于这一机制」。
:::

:::cause-effect{title="磷脂合成障碍 → 脂肪肝"}
卵磷脂等磷脂是组装 $\mathrm{VLDL}$ 所必需的。没有足够磷脂，$\mathrm{VLDL}$ 出不去，甘油三酯留在肝里。这一句把脂质段的合成账和运输账锁在一起。
:::

## 三、肝内存在活跃的蛋白质合成及分解代谢

肝在人体蛋白质合成、分解和氨基酸代谢中起重要作用。

肝脏的蛋白质合成代谢十分活跃，除满足自身结构和功能的需要，还合成大量蛋白质输出肝，以满足机体的需要。如肝合成与分泌 $90\%$ 以上的血浆蛋白质（表25-1）。除 $\gamma$ 球蛋白外，几乎所有的血浆蛋白均来自肝，如清蛋白（albumin）（临床上也叫白蛋白）、凝血酶原、纤维蛋白原、铜蓝蛋白、凝血因子Ⅰ、Ⅱ、Ⅴ、Ⅵ、Ⅸ和Ⅹ等。血浆脂蛋白中的多种载脂蛋白（apo A、B、C、E 等）及部分脂蛋白代谢酶也是在肝合成的，执行脂质运输和脂蛋白代谢功能。由于凝血因子大部分由肝合成，因此严重肝细胞损伤时，可出现凝血时间延长及出血倾向。

:::definition{label="肝合成 90% 以上血浆蛋白质"}
除满足自身需要外，肝还合成大量蛋白质输出。除 $\gamma$ 球蛋白外，几乎所有血浆蛋白均来自肝。名单要含清蛋白、凝血酶原、纤维蛋白原、铜蓝蛋白，以及凝血因子Ⅰ、Ⅱ、Ⅴ、Ⅵ、Ⅸ和Ⅹ。
:::

:::definition{label="γ 球蛋白不是肝合成的"}
「除 $\gamma$ 球蛋白外」是本版原句。$\gamma$ 球蛋白主要来自浆细胞，不要写进肝合成名单。$\mathrm{A}/\mathrm{G}$ 比值下降甚至倒置，后文正是清蛋白减少而球蛋白相对突出。
:::

:::definition{label="凝血因子与出血倾向"}
凝血因子大部分由肝合成。严重肝细胞损伤时，可出现凝血时间延长及出血倾向。维生素段还会写：维生素 $\mathrm{K}$ 是肝合成凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ不可缺少的物质。两句都要留，不要并成「只有维生素 $\mathrm{K}$ 缺乏才出血」。
:::

:::pitfall{label="清蛋白和白蛋白是同一户"}
教材写清蛋白（albumin），并注明临床上也叫白蛋白。不要当成两种血浆蛋白。后文 $\mathrm{A}/\mathrm{G}$ 的 $\mathrm{A}$ 就是这一户。
:::

肝脏对于清除血浆蛋白质起着重要作用。肝细胞膜上的唾液酸酶可水解血浆蛋白质糖链末端的唾液酸，剩下的糖蛋白部分经胞饮作用进入肝细胞，进一步被溶酶体清除。

:::definition{label="肝清除血浆糖蛋白"}
肝细胞膜唾液酸酶水解糖链末端唾液酸，剩余糖蛋白经胞饮进入肝细胞，由溶酶体清除。合成和清除都是肝的蛋白质账，不是只合成不分解。
:::

血浆清蛋白几乎均由肝实质细胞合成，是血浆中的主要蛋白质成分。成人肝每日约合成 $12\,\mathrm{g}$ 清蛋白，几乎占肝合成蛋白质总量的 $25\%$。血浆清蛋白除了作为许多脂溶性物质（如游离脂肪酸、胆红素等）的非特异性运输载体外，在维持血浆胶体渗透压方面亦起重要作用。若血浆清蛋白低于 $30\,\mathrm{g/L}$，约有半数病人出现水肿或腹水。正常人空腹血浆清蛋白（$\mathrm{A}$）与球蛋白（$\mathrm{G}$）的比值（$\mathrm{A}/\mathrm{G}$）为 $1.2\sim 2.4:1$。肝功能严重受损时，血浆清蛋白合成减少，可致 $\mathrm{A}/\mathrm{G}$ 比值下降，甚至倒置。此种变化临床上可作为严重慢性肝细胞损伤的辅助诊断指标。

:::definition{label="清蛋白合成量"}
几乎均由肝实质细胞合成。成人肝每日约合成 $12\,\mathrm{g}$，几乎占肝合成蛋白质总量的 $25\%$。
:::

:::definition{label="清蛋白的两项功能"}
①许多脂溶性物质（游离脂肪酸、胆红素等）的非特异性运输载体；②维持血浆胶体渗透压。胆红素在这里只是配基名单，代谢展开是第四节。
:::

:::definition{label="清蛋白低于 30 g/L"}
约有半数病人出现水肿或腹水。数字按本版 $30\,\mathrm{g/L}$，不要改成别的临界值。
:::

:::definition{label="A/G 比值"}
正常人空腹 $\mathrm{A}/\mathrm{G}$ 为 $1.2\sim 2.4:1$。肝功能严重受损时清蛋白合成减少，比值下降甚至倒置，作为严重慢性肝细胞损伤的辅助诊断指标。
:::

:::compare{title="清蛋白数字三笔不要混"}
| 本版数字 | 说的是什么 | 不要写成 |
|---------|-----------|---------|
| 每日约 $12\,\mathrm{g}$ | 成人肝合成清蛋白的量 | 「血浆浓度是 $12\,\mathrm{g/L}$」 |
| 约占肝合成蛋白质 $25\%$ | 合成份额 | 「血浆蛋白里清蛋白只占 $25\%$」 |
| 低于 $30\,\mathrm{g/L}$ | 约半数出现水肿或腹水 | 「正常值下限就是 $30$」 |
| $\mathrm{A}/\mathrm{G}$ $1.2\sim 2.4:1$ | 空腹正常比值 | 「倒置是急性肝炎的特异指标」 |

表25-1 里清蛋白血浆浓度是 $40\sim 55\,\mathrm{g/L}$，和「低于 $30\,\mathrm{g/L}$ 出水肿」是两笔。
:::

:::pitfall{label="A/G 倒置不是急性肝损伤的专利"}
教材把这一变化写成严重慢性肝细胞损伤的辅助诊断指标。急性损伤更常先看到转氨酶、凝血时间；清蛋白半衰期较长，慢性损伤才容易把 $\mathrm{A}/\mathrm{G}$ 拉倒。
:::

| 血色素结合蛋白 | $57$（$1$） | 与血红素 $1:1$ 结合 | $0.5\sim 1.15\,\mathrm{g/L}$ |
| 转铁蛋白 | $80$（$1$） | $2$ 原子铁／分子，转运铁 | $2.0\sim 3.6\,\mathrm{g/L}$ |
:::

正常人血浆甲胎蛋白（$\alpha$-fetoprotein，$\alpha$-$\mathrm{AFP}$）很低，原发肝癌细胞中 $\mathrm{AFP}$ 基因的表达失去阻遏，血浆浓度上升，因此 $\mathrm{AFP}$ 是原发性肝癌的重要肿瘤标志物。但胚胎期肝可合成 $\mathrm{AFP}$，因此孕妇血中可见 $\mathrm{AFP}$ 升高，这是正常现象。

:::definition{label="AFP"}
甲胎蛋白。正常人血浆很低（表25-1：$\le 25.0\,\mu\mathrm{g/L}$）。原发肝癌细胞中 $\mathrm{AFP}$ 基因表达失去阻遏，血浆浓度上升，是原发性肝癌的重要肿瘤标志物。胚胎期肝可合成 $\mathrm{AFP}$，孕妇血中升高是正常现象。
:::

:::pitfall{label="孕妇 AFP 升高不要直接写成肝癌"}
教材把孕妇升高写成正常现象。$\mathrm{AFP}$ 是肝癌标志物，但不是「升高＝肝癌」。胚胎期肝本来就合成它。
:::

肝内含有丰富的与氨基酸分解代谢相关的酶类，肝中转氨基、脱氨基、脱羧基、转甲基等反应均很活跃。除支链氨基酸（亮氨酸、异亮氨酸、缬氨酸）主要在肌肉组织降解外，其余氨基酸特别是苯丙氨酸、酪氨酸与色氨酸等芳香族氨基酸主要在肝内进行代谢。故患严重肝病时，血浆中支链氨基酸与芳香族氨基酸的比值下降。

:::definition{label="支链氨基酸不在肝降解"}
亮氨酸、异亮氨酸、缬氨酸主要在肌肉组织降解。其余氨基酸，特别是苯丙氨酸、酪氨酸与色氨酸等芳香族氨基酸，主要在肝内代谢。严重肝病时，血浆支链氨基酸与芳香族氨基酸的比值下降。
:::

:::compare{title="支链氨基酸 vs 芳香族氨基酸"}
| | 主要代谢器官 | 严重肝病时 |
|--|------------|-----------|
| 支链（亮、异亮、缬） | 肌肉 | 相对不降或可升高，比值的分子侧 |
| 芳香（苯丙、酪、色） | 肝 | 肝代谢差则堆积，比值的分母侧 |

比值下降是「肝病时芳香氨基酸相对升高」这一户，不是「肌肉也坏了」。后文假神经递质还要从芳香族胺走。
:::

肝是代谢氨的主要解毒器官。肝通过鸟氨酸循环将有毒的氨合成无毒的尿素，也可以将氨转变成谷氨酰胺解毒。合成中所需的氨基甲酰磷酸合成酶Ⅰ及鸟氨酸氨基甲酰转移酶只存在于肝细胞线粒体，因此肝是机体合成尿素的特异器官。在尿素合成中消耗了呼吸性 $\mathrm{H}^{+}$ 和 $\mathrm{CO}_2$，故肝对维持机体酸碱平衡也有重要作用。严重肝病病人，肝解氨毒能力下降，导致血氨升高和氨中毒，是导致肝性脑病发生的重要生化机制之一。

:::definition{label="尿素合成是肝特有"}
氨基甲酰磷酸合成酶Ⅰ及鸟氨酸氨基甲酰转移酶只存在于肝细胞线粒体，因此肝是机体合成尿素的特异器官。图25-2 把尿素画成深色「肝脏特有」。氨也可转变成谷氨酰胺解毒，但尿素循环这一户是肝独有。
:::

:::definition{label="尿素合成与酸碱平衡"}
尿素合成消耗呼吸性 $\mathrm{H}^{+}$ 和 $\mathrm{CO}_2$，故肝对维持机体酸碱平衡也有重要作用。不要把尿素循环只写成「排氨」。
:::

:::definition{label="血氨与肝性脑病"}
严重肝病时肝解氨毒能力下降，血氨升高和氨中毒，是肝性脑病的重要生化机制之一。后文假神经递质是另一条机制，不要并户。
:::

:::pitfall{label="氨和胺不要并成一个字"}
氨走鸟氨酸循环成尿素，是这一小节的主账。胺（苯乙胺、酪胺等）走单胺氧化酶，是下一句和第二节生物转化的账。写成「血氨就是假神经递质」，两条肝性脑病机制就并了。
:::

肝也是胺类物质的重要生物转化器官。正常人体经肝单胺氧化酶作用，可将芳香族氨基酸脱羧基作用产生的苯乙胺、酪胺等芳香族胺加以氧化而清除。严重肝病病人，这些芳香族胺类得不到及时清除，可通过血脑屏障进入脑组织，经羟化后生成苯乙醇胺和 $\beta$-羟酪胺，其结构与儿茶酚胺相似并抑制后者功能，属于假神经递质（false neurotransmitter），与肝性脑病的发生也有一定关系。

:::definition{label="假神经递质"}
严重肝病时，苯乙胺、酪胺等芳香族胺不能被肝单胺氧化酶及时清除，入脑后羟化生成苯乙醇胺和 $\beta$-羟酪胺。结构与儿茶酚胺相似并抑制后者功能，称为假神经递质。与肝性脑病的发生也有一定关系。
:::

:::compare{title="肝性脑病的两条生化机制（本节先立住）"}
| | 原料 | 肝的职分 | 后果 |
|--|------|---------|------|
| 氨中毒 | 氨 | 尿素循环／谷氨酰胺 | 血氨升高 |
| 假神经递质 | 苯乙胺、酪胺等芳香族胺 | 单胺氧化酶氧化清除 | 苯乙醇胺、$\beta$-羟酪胺入脑，抑制儿茶酚胺 |

两户都与严重肝病有关，不要写成只有血氨。单胺氧化酶的展开在第二节。
:::

:::insight{label="清蛋白携带胆红素，不等于本节讲完胆色素"}
清蛋白的配基名单里有胆红素，开篇胆道输出也写了胆红素。这些只是点名。胆红素来源、结合、黄疸分型是第四节。
:::

## 四、肝参与多种维生素和辅酶的代谢

肝在维生素的吸收、储存、运输及转化等方面起重要作用。

肝合成和分泌胆汁酸，可促进脂溶性维生素 $\mathrm{A}$、维生素 $\mathrm{D}$、维生素 $\mathrm{E}$ 和维生素 $\mathrm{K}$ 的吸收。肝是机体含维生素 $\mathrm{A}$、维生素 $\mathrm{K}$、维生素 $\mathrm{B}_1$、维生素 $\mathrm{B}_2$、维生素 $\mathrm{B}_6$、维生素 $\mathrm{B}_{12}$、泛酸和叶酸较多的器官。人体内维生素 $\mathrm{A}$、维生素 $\mathrm{E}$、维生素 $\mathrm{K}$ 及维生素 $\mathrm{B}_{12}$ 主要储存于肝，肝中维生素 $\mathrm{A}$ 的含量占体内总量的 $95\%$。肝合成和分泌视黄醇结合蛋白，它能与视黄醇结合，在血液中运输视黄醇。肝几乎不储存维生素 $\mathrm{D}$，但可合成和分泌维生素 $\mathrm{D}$ 结合蛋白，血浆中 $85\%$ 的维生素 $\mathrm{D}$ 代谢产物与维生素 $\mathrm{D}$ 结合蛋白结合而运输。

:::definition{label="胆汁酸促进脂溶性维生素吸收"}
维生素 $\mathrm{A}$、$\mathrm{D}$、$\mathrm{E}$、$\mathrm{K}$ 的吸收依赖胆汁酸。脂质段的厌油腻、脂肪泻，可以同时伤到这四种维生素。
:::

:::definition{label="主要储存于肝的维生素"}
维生素 $\mathrm{A}$、$\mathrm{E}$、$\mathrm{K}$ 及维生素 $\mathrm{B}_{12}$ 主要储存于肝。肝中维生素 $\mathrm{A}$ 占体内总量的 $95\%$。肝含维生素较多的名单还要加上 $\mathrm{K}$、$\mathrm{B}_1$、$\mathrm{B}_2$、$\mathrm{B}_6$、$\mathrm{B}_{12}$、泛酸和叶酸——「含较多」和「主要储存」不是同一句话。
:::

:::definition{label="视黄醇结合蛋白"}
肝合成和分泌视黄醇结合蛋白，与视黄醇结合，在血液中运输视黄醇。储存是肝里的维生素 $\mathrm{A}$；运输是入血时的结合蛋白。
:::

:::definition{label="维生素 D 几乎不储存在肝"}
肝几乎不储存维生素 $\mathrm{D}$，但合成和分泌维生素 $\mathrm{D}$ 结合蛋白；血浆中 $85\%$ 的维生素 $\mathrm{D}$ 代谢产物与之结合而运输。后文转化账里，肝把维生素 $\mathrm{D}_3$ 变成 $25$-羟维生素 $\mathrm{D}_3$。
:::

:::compare{title="维生素 A vs 维生素 D 在肝里的待遇"}
| | 储存 | 运输蛋白 | 转化 |
|--|------|---------|------|
| 维生素 $\mathrm{A}$ | 肝中占体内 $95\%$ | 视黄醇结合蛋白（肝合成） | 胡萝卜素 → 维生素 $\mathrm{A}$ |
| 维生素 $\mathrm{D}$ | 肝几乎不储存 | 维生素 $\mathrm{D}$ 结合蛋白（肝合成）；$85\%$ 代谢产物与之结合 | 维生素 $\mathrm{D}_3$ → $25$-羟维生素 $\mathrm{D}_3$ |

问「肝是不是维生素仓库」——$\mathrm{A}$ 是，$\mathrm{D}$ 几乎不是。问「运输靠谁」两户都靠肝合成的结合蛋白。
:::

:::pitfall{label="不要把「含较多」写成「全部储存在肝」"}
含较多的名单有 $\mathrm{A}$、$\mathrm{K}$、$\mathrm{B}_1$、$\mathrm{B}_2$、$\mathrm{B}_6$、$\mathrm{B}_{12}$、泛酸、叶酸。主要储存于肝的是 $\mathrm{A}$、$\mathrm{E}$、$\mathrm{K}$、$\mathrm{B}_{12}$。维生素 $\mathrm{D}$ 明确写「几乎不储存」。三句话并成一句会把 $\mathrm{D}$ 和 $\mathrm{B}_1$ 都塞进仓库。
:::

肝还参与多种维生素的转化。肝可将胡萝卜素转化为维生素 $\mathrm{A}$，将维生素 $\mathrm{PP}$ 转变为辅酶Ⅰ（$\mathrm{NAD}^{+}$）和辅酶Ⅱ（$\mathrm{NADP}^{+}$），将泛酸转变为辅酶 $\mathrm{A}$（$\mathrm{CoA}$），将维生素 $\mathrm{B}_1$ 转变为焦磷酸硫胺素（$\mathrm{TPP}$），将维生素 $\mathrm{D}_3$ 转化为 $25$-羟维生素 $\mathrm{D}_3$ 等。维生素 $\mathrm{K}$ 还是肝参与合成凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ不可缺少的物质。

:::definition{label="肝对维生素的转化名单"}
胡萝卜素 → 维生素 $\mathrm{A}$；维生素 $\mathrm{PP}$ → $\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$；泛酸 → $\mathrm{CoA}$；维生素 $\mathrm{B}_1$ → $\mathrm{TPP}$；维生素 $\mathrm{D}_3$ → $25$-羟维生素 $\mathrm{D}_3$。
:::

:::definition{label="维生素 K 与凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ"}
维生素 $\mathrm{K}$ 是肝合成这些凝血因子不可缺少的物质。蛋白质段已经写过凝血因子大部分由肝合成；这里补的是辅因子。严重肝病出血，可以是合成器官坏了，也可以是维生素 $\mathrm{K}$ 吸收／利用不够。
:::

:::keypoint{label="维生素这一小节四件事"}
- 吸收：脂溶性 $\mathrm{A}$、$\mathrm{D}$、$\mathrm{E}$、$\mathrm{K}$ 靠胆汁酸。
- 储存：$\mathrm{A}$、$\mathrm{E}$、$\mathrm{K}$、$\mathrm{B}_{12}$ 主要在肝；$\mathrm{A}$ 占 $95\%$；$\mathrm{D}$ 几乎不存。
- 运输：视黄醇结合蛋白；维生素 $\mathrm{D}$ 结合蛋白（$85\%$）。
- 转化：胡萝卜素、$\mathrm{PP}$、泛酸、$\mathrm{B}_1$、$\mathrm{D}_3$；维生素 $\mathrm{K}$ 参与Ⅱ、Ⅶ、Ⅸ、Ⅹ。
:::

## 五、肝参与多种激素的灭活

多种激素在发挥其调节作用后，主要在肝中代谢转化，从而降低或失去其活性，此过程称为激素的灭活（inactivation）。一些水溶性激素能与肝细胞膜上特异受体结合，通过内吞作用，将激素吞入肝细胞内进行代谢转化。一些类固醇激素则通过扩散作用进入肝细胞，与肝内的葡萄糖醛酸或活性硫酸等结合后灭活。肝细胞严重损伤时，激素的灭活功能降低，体内的雌激素、醛固酮、抗利尿激素等水平升高，可出现男性乳房女性化、蜘蛛痣、肝掌（雌激素使局部小动脉扩张）及水钠潴留等。胰岛素也在肝内灭活，严重肝病可导致灭活减弱，血中胰岛素升高。

:::definition{label="激素的灭活"}
激素发挥调节作用后，主要在肝中代谢转化，从而降低或失去其活性。英文 inactivation。户头是「用完之后关掉」，不是「肝分泌这些激素」。
:::

:::definition{label="两类激素进肝的方式"}
水溶性激素：与肝细胞膜特异受体结合，内吞入肝细胞再代谢转化。类固醇激素：扩散进入肝细胞，与葡萄糖醛酸或活性硫酸等结合后灭活。结合反应的展开是第二节。
:::

:::definition{label="灭活减弱的临床表现"}
肝细胞严重损伤 → 雌激素、醛固酮、抗利尿激素水平升高 → 男性乳房女性化、蜘蛛痣、肝掌（雌激素使局部小动脉扩张）及水钠潴留。胰岛素也在肝内灭活，严重肝病时血中胰岛素可升高。
:::

:::compare{title="水溶性激素 vs 类固醇激素的灭活入口"}
| | 进肝 | 随后 |
|--|------|------|
| 水溶性激素 | 膜受体结合，内吞 | 细胞内代谢转化 |
| 类固醇激素 | 扩散 | 与葡萄糖醛酸或活性硫酸结合 |

蜘蛛痣、肝掌走雌激素；水钠潴留走醛固酮和抗利尿激素。不要把四个体征都写成「雌激素」。
:::

:::pitfall{label="肝掌、蜘蛛痣不要写成维生素缺乏"}
本版把肝掌、蜘蛛痣明确写在雌激素使局部小动脉扩张这一句里。维生素段是另一本账。写成「肝掌＝维生素 $\mathrm{B}$ 缺乏」，灭活这一节就空了。
:::

:::insight{label="灭活已经预告第二相结合"}
类固醇激素与葡萄糖醛酸或活性硫酸结合，正是第二节最常见的两种结合反应。本节只写「灭活」，不写 $\mathrm{UGT}$、$\mathrm{PAPS}$ 的酶表。
:::

## 六、肝中主要代谢途径及联系

肝为糖、脂质、蛋白质、核酸等生物大分子代谢的中心。正常饮食状态下，肝合成肝糖原，储备能量供短期饥饿时补充血糖。肝可以利用氨基酸、乳酸、甘油等小分子进行糖异生，维持血糖水平。脂代谢与肝细胞功能紧密相关，肝将体内约 $50\%$ 的胆固醇转化为胆汁酸，这是胆固醇排出的主要形式。胆汁酸进入肠道，对食糜中的脂质进行乳化，助于消化和吸收。肝细胞特异性表达清蛋白，它可作为载体在血液中转运脂肪酸。肝是甘油三酯合成的主要场所，糖代谢产生的乙酰 $\mathrm{CoA}$ 可在肝脏内合成甘油三酯，后者可通过 $\mathrm{VLDL}$ 形式转运至其他组织；肝细胞也是载脂蛋白的表达场所，对血浆脂蛋白转运和代谢发挥重要作用，大约 $50\%$ 的血浆 $\mathrm{LDL}$ 是被肝摄取并代谢分解。绝大多数酮体和大约 $75\%$ 的胆固醇在肝脏内生成，酮体是水溶性较高的储能小分子，可供肝外组织供能。

体内氨基酸代谢产生的胺和氨均在肝内代谢转化，其中胺经生物转化作用解毒，氨转变为尿素，肝细胞受损导致血氨升高，可引起肝性脑病。嘌呤和嘧啶核苷酸的从头合成主要发生在肝细胞内，它们利用磷酸戊糖途径产生的 $5'$-磷酸核糖和甘氨酸、谷氨酰胺、天冬氨酸及氨基酸代谢产生的一碳单位等为原料进行合成。肝中主要代谢途径及联系见图25-2。

:::definition{label="肝是生物大分子代谢的中心"}
糖、脂质、蛋白质、核酸都在肝交汇。图25-2 不是另开一章，而是把前面五小节收成一张网。
:::

:::definition{label="图25-2 必须钉死的几笔"}
肝糖原（短期饥饿补血糖）；糖异生（氨基酸、乳酸、甘油）；尿素（肝特有）；酮体（长期饥饿或高脂，肝特有，供肝外）；胆固醇肝合成约 $75\%$；约 $50\%$ 在肝内转化成胆汁酸；约 $50\%$ 血浆 $\mathrm{LDL}$ 经 $\mathrm{LDLR}$ 摄入肝；清蛋白转运脂肪酸；嘌呤／嘧啶核苷酸从头合成主要在肝。
:::

:::compare{title="图25-2 深色「肝脏特有」vs 浅色「肝脏为主」"}
| | 画面 | 不要写成 |
|--|------|---------|
| 肝脏特有（深色） | 尿素；酮体；胆固醇；胆汁酸；肝糖原一侧 | 「这些途径肝外完全没有原料」——特有的是成尿素、成酮、成胆汁酸等关键步骤 |
| 肝脏为主（浅色） | 糖异生、有氧氧化、甘油三酯／脂肪酸、$\mathrm{VLDL}$、核苷酸从头合成等 | 「为主＝只有肝能做」 |
| 旁注数字 | 胆固醇肝合成 $75\%$；约 $50\%$ 在肝内转化；约 $50\%$ 经 $\mathrm{LDLR}$ 摄入 | 用别的教材改百分比 |

问「哪一条是肝独有」先找深色框：尿素、酮体、胆固醇／胆汁酸这条降解排出链。
:::

:::keypoint{label="胺走生物转化，氨走尿素"}
- 胺：经生物转化解毒（第二节展开单胺氧化酶、结合反应）。
- 氨：转变为尿素（本节已写，肝特有）。
- 肝细胞受损 → 血氨升高 → 肝性脑病：这一句留在第一节，第二节不再把尿素循环重写一遍。
:::

:::definition{label="核苷酸从头合成主要在肝"}
嘌呤和嘧啶核苷酸的从头合成主要发生在肝细胞。原料：磷酸戊糖途径产生的 $5'$-磷酸核糖，加上甘氨酸、谷氨酰胺、天冬氨酸及一碳单位。图25-2 左下角把这一户画出来，不是另开核酸章。
:::

:::memory{label="本节必背分户"}
- 成人肝约 $1\,500\,\mathrm{g}$，占体重 $2\%\sim 2.5\%$；血流量约占心输出量 $1/4$；每日胆汁 $600\sim 1\,000\,\mathrm{ml}$。
- 结构四条：双重血供、双重输出、肝血窦慢流、丰富细胞器与酶（有的肝独有）。图25-1。
- 血糖：$\mathrm{GLUT2}$；葡萄糖激酶 $K_{\mathrm{m}}$ $10\,\mathrm{mmol/L}$（肝外己糖激酶 $0.1\,\mathrm{mmol/L}$）；肝糖原 $75\sim 100\,\mathrm{g}$；$12\sim 18$ 小时耗尽后糖异生成为唯一产糖来源；肌组织无葡萄糖-6-磷酸酶。
- 脂质：内源性甘油三酯主要来自肝；酮体肝生成、肝外利用，饥饿时占大脑供能 $60\%\sim 70\%$；胆固醇肝合成约 $75\%$（$3/4$ 以上），约 $50\%$ 转成胆汁酸；$\mathrm{LCAT}$；磷脂障碍 → 脂肪肝。
- 蛋白质：除 $\gamma$ 球蛋白外几乎都来自肝；清蛋白每日约 $12\,\mathrm{g}$，低于 $30\,\mathrm{g/L}$ 约半数水肿腹水；$\mathrm{A}/\mathrm{G}$ $1.2\sim 2.4:1$；$\mathrm{AFP}$ 是原发性肝癌标志物，孕妇升高可以是正常。
- 尿素肝特有（氨基甲酰磷酸合成酶Ⅰ、鸟氨酸氨基甲酰转移酶只在肝线粒体）。假神经递质：苯乙醇胺、$\beta$-羟酪胺。
- 维生素 $\mathrm{A}$ 占体内 $95\%$；维生素 $\mathrm{D}$ 几乎不储存。激素灭活减弱：肝掌、蜘蛛痣、男性乳房女性化、水钠潴留。
- 图25-2：深色肝特有（尿素、酮体、胆固醇／胆汁酸）；浅色肝脏为主。
:::

:::keypoint{label="本节不写的两本账"}
生物转化的第一相（氧化、还原、水解）和第二相（葡萄糖醛酸、硫酸、谷胱甘肽、乙酰化、甲基化、甘氨酸等）是第二节。胆汁酸分类与肠肝循环是第三节，胆色素是第四节。本节只把胆汁酸、胆红素、解毒当作点名。
:::
