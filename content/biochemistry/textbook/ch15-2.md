# 第二节　原核生物的转录

第一节把转录写成选择性、不需引物、四种 $\mathrm{NTP}$。本节落到大肠埃希菌：全酶靠 $\sigma$ 认启动子，核心酶做延长；$-35$ 的 $\mathrm{TTGACA}$、$-10$ 的 Pribnow 盒（$\mathrm{TATAAT}$）；闭合复合体变成开放复合体，解开约 $17\,\mathrm{bp}$；转录泡里有 $8\,\mathrm{bp}$ 的 $\mathrm{RNA}$-$\mathrm{DNA}$ 杂合双链；原核转录与翻译同步；终止分依赖 $\rho$ 与非依赖 $\rho$ 两类。真核三种 $\mathrm{RNA}\,\mathrm{pol}$ 和转录因子是第三节的账。

:::concept{term="先问全酶还是核心酶，再问终止要不要 ρ"}
看见“原核转录”，先不要默写真核 $\mathrm{TF}\,\mathrm{II}$。起始必须全酶（$\sigma$ 辨认起点），延长只留核心酶；启动子坐标从 $+1$ 往上数到 $-10$、$-35$；泡只有约 $17\,\mathrm{bp}$，比复制叉小得多。终止：部分基因靠 $\rho$，多数靠茎环加一串 $\mathrm{U}$。
:::

原核生物的转录过程可分为转录起始、转录延长和转录终止三个阶段。

:::definition{label="原核转录的三个阶段"}
起始、延长、终止。起始：全酶结合启动子、开链、形成第一个磷酸二酯键。延长：$\sigma$ 脱落，核心酶催化 $\mathrm{RNA}$ 链生长。终止：$\mathrm{RNA}\,\mathrm{pol}$ 停顿，$\mathrm{RNA}$ 从复合物上脱落。
:::

:::keypoint{label="三个阶段各用哪一套分子"}
- 起始：全酶（核心酶 $+\sigma$）、启动子、$\mathrm{NTP}$。
- 延长：核心酶、转录泡、模板 $3'\rightarrow 5'$ 阅读。
- 终止：依赖 $\rho$，或非依赖 $\rho$ 的茎环 $+$ 多聚 $\mathrm{U}$。
:::

:::pitfall{label="不要把三个阶段写成三种不同的聚合酶"}
全程都是同一套大肠埃希菌 $\mathrm{RNA}\,\mathrm{pol}$。变的是 $\sigma$ 在不在、要不要 $\rho$，不是换酶。
:::

## 一、RNA 聚合酶结合到 DNA 的启动子上起始转录

原核生物的 $\mathrm{RNA}\,\mathrm{pol}$ 可以直接识别并结合到 $\mathrm{DNA}$ 上的特定结构区域，从而启动转录。

:::definition{label="原核 RNA pol 可直接结合 DNA"}
原核 $\mathrm{RNA}\,\mathrm{pol}$ 自己识别并结合 $\mathrm{DNA}$ 上的特定结构区域（启动子）。真核 $\mathrm{RNA}\,\mathrm{pol}$ 需与辅因子结合后才结合模板，是第三节的对比句，不要提前把转录因子表搬进大肠埃希菌。
:::

:::insight{label="“直接结合”并不取消 σ"}
直接结合的是全酶。辨认启动子的是 $\sigma$ 亚基，其他亚基配合。没有 $\sigma$ 的核心酶也能聚合，但没有固定起点——下一小节的试管实验。
:::

### （一）转录起始需要 RNA 聚合酶全酶

大肠埃希菌（$E.\ coli$）的 $\mathrm{RNA}\,\mathrm{pol}$ 是目前研究得比较透彻的分子。这是一个分子量达 $450\,\mathrm{kD}$，由 $5$ 种亚基 $\alpha_2$（$2$ 个 $\alpha$）、$\beta$、$\beta'$、$\omega$ 和 $\sigma$ 组成的六聚体蛋白质。各主要亚基及功能见表15-1。

:::definition{label="大肠埃希菌 RNA 聚合酶"}
分子量 $450\,\mathrm{kD}$ 的六聚体：五种亚基为 $2$ 个 $\alpha$、以及 $\beta$、$\beta'$、$\omega$、$\sigma$。种类是 $5$，分子数是 $6$。
:::

**表15-1　大肠埃希菌 RNA 聚合酶组分**

| 亚基 | 分子量 $/\mathrm{kD}$ | 亚基数目 | 功能 |
|------|----------------------|----------|------|
| $\alpha$ | $36.5$ | $2$ | 决定哪些基因被转录 |
| $\beta$ | $150.6$ | $1$ | 与转录全过程有关（催化） |
| $\beta'$ | $155.6$ | $1$ | 结合 $\mathrm{DNA}$ 模板（开链） |
| $\omega$ | $11.0$ | $1$ | $\beta'$ 折叠和稳定性；$\sigma$ 募集 |
| $\sigma$ | $70.2$ | $1$ | 辨认起始点 |

:::definition{label="α 亚基"}
分子量 $36.5\,\mathrm{kD}$，全酶里有 $2$ 个。功能：决定哪些基因被转录。
:::

:::definition{label="β 亚基"}
分子量 $150.6\,\mathrm{kD}$，一个。与转录全过程有关，承担催化。
:::

:::definition{label="β′ 亚基"}
分子量 $155.6\,\mathrm{kD}$，一个。结合 $\mathrm{DNA}$ 模板并开链。符号是 $\beta'$，不要写成第二个 $\beta$。
:::

:::definition{label="ω 亚基"}
分子量 $11.0\,\mathrm{kD}$，一个。帮助 $\beta'$ 折叠和稳定，并募集 $\sigma$。
:::

:::definition{label="σ 亚基"}
分子量 $70.2\,\mathrm{kD}$（最常见的 $\sigma^{70}$ 按分子量约 $70\,\mathrm{kD}$ 命名），一个。功能：辨认起始点。
:::

:::pitfall{label="五种亚基不是五个亚基分子"}
$\alpha$ 有两个，所以是六聚体。写成五聚体，表15-1 的「亚基数目」列对不上。
:::

:::pitfall{label="β 和 β′ 不要对调"}
催化在 $\beta$，开链、结合模板在 $\beta'$。对调之后，「全过程催化」和「开链」两句都会错。
:::

:::insight{label="ω 不是可有可无的装饰"}
教材给它的功能是 $\beta'$ 折叠／稳定和 $\sigma$ 募集。没有 $\omega$，$\sigma$ 进全酶、$\beta'$ 站稳都会受影响。默写时不要只背 $\alpha_2\beta\beta'\sigma$ 而漏掉 $\omega$。
:::

核心酶（core enzyme）由 $\alpha_2\beta\beta'\omega$ 亚基组成。试管内的转录实验（含有模板、酶和底物 $\mathrm{NTP}$ 等）证明，核心酶能够催化 $\mathrm{NTP}$ 按模板的指引合成 $\mathrm{RNA}$。但合成的 $\mathrm{RNA}$ 没有固定的起始位点。加有 $\sigma$（sigma）亚基的酶能在特定的起始点上开始转录，可见 $\sigma$ 亚基的功能是辨认转录起始点。$\sigma$ 亚基加上核心酶称为全酶（holoenzyme）。原核生物的转录起始需要全酶。转录延长阶段则仅需核心酶。图15-3 显示 $\mathrm{RNA}\,\mathrm{pol}$ 全酶在转录起始区的结合。

:::definition{label="核心酶"}
核心酶（core enzyme）$=\alpha_2\beta\beta'\omega$。能按模板把 $\mathrm{NTP}$ 聚合成 $\mathrm{RNA}$，但没有固定的起始位点。延长阶段只留核心酶在模板上。
:::

:::definition{label="全酶"}
全酶（holoenzyme）$=$ 核心酶 $+\sigma$。原核转录起始需要全酶。$\sigma$ 的功能是辨认转录起始点。
:::

:::definition{label="试管实验把 σ 的功能钉死"}
体系里有模板、酶、$\mathrm{NTP}$：只有核心酶时，$\mathrm{RNA}$ 能合成，但起点不固定；加上 $\sigma$，才能在特定起点开始。这是「辨认起始点」的实验依据，不是推论。
:::

与图15-3 同页的电子版图源 `p0303_01.png` 为 $0$ 字节，不嵌入 `src`。非空文件 `p0303_02.png` 即图15-3 全酶，不要把空文件配进正文。
:::

:::insight{label="图15-3 已经把第二节后文的启动子画进全酶"}
酶覆盖从 $-35$ 的 $\mathrm{TTGACA}$ 到下游 $+20$。$\mathrm{TATAAT}$ 和 $+1$ 都在酶体内。读图时先认序列坐标，再认亚基：$\beta$ 偏上游，$\beta'$ 偏上，两个 $\alpha$ 和 $\sigma$、$\omega$ 聚在下游一侧。
:::

:::compare{title="全酶 vs 核心酶"}
| | 全酶 | 核心酶 |
|--|------|--------|
| 组成 | $\alpha_2\beta\beta'\omega\sigma$ | $\alpha_2\beta\beta'\omega$ |
| 阶段 | 起始必需 | 延长必需 |
| 起点 | 能在特定起点开始 | 能聚合，但起点不固定 |
| $\sigma$ | 在 | 已脱落，可再循环装配下一轮全酶 |

起始用全酶，延长用核心酶。不要答成「两种不同的聚合酶」。
:::

大肠埃希菌内有一些不同的 $\mathrm{RNA}\,\mathrm{pol}$ 全酶，其差异是 $\sigma$ 亚基的不同。目前已发现多种 $\sigma$ 亚基，并用其分子量命名区别，最常见的是 $\sigma^{70}$（分子量 $70\,\mathrm{kD}$）。$\sigma^{70}$ 是辨认典型转录起始点的蛋白质，大肠埃希菌中的绝大多数启动子可被含有 $\sigma^{70}$ 因子的全酶所识别并激活。

:::definition{label="σ70"}
最常见的 $\sigma$ 亚基，按分子量命名，$\sigma^{70}$ 约 $70\,\mathrm{kD}$（表15-1 中 $\sigma$ 为 $70.2\,\mathrm{kD}$）。辨认典型转录起始点；大肠埃希菌绝大多数启动子由含 $\sigma^{70}$ 的全酶识别并激活。
:::

:::definition{label="不同全酶的差别在 σ 不在核心"}
大肠埃希菌可以有多种全酶，差异是 $\sigma$ 不同。核心酶 $\alpha_2\beta\beta'\omega$ 共用；换 $\sigma$ 就换所认的启动子类型。
:::

:::pitfall{label="σ70 不是“分子量必须恰好 70.2 的唯一 σ”"}
表15-1 给的是常见 $\sigma$ 的 $70.2\,\mathrm{kD}$；正文说已发现多种 $\sigma$，用分子量命名。把「多种 $\sigma$」答成只有 $\sigma^{70}$，应激、热激那类换 $\sigma$ 的调控就没入口（第十七章再展开）。
:::

:::insight{label="绝大多数启动子认 σ70，不等于全部"}
教材用「绝大多数」。少数启动子换别的 $\sigma$，正是「不同全酶」那句话的着落。考试默写典型启动子，默认 $\sigma^{70}$。
:::

转录全过程均需 $\mathrm{RNA}\,\mathrm{pol}$ 催化，起始过程需全酶，由 $\sigma$ 亚基辨认起始点，延长过程的核苷酸聚合仅需核心酶催化。简言之，转录起始就是 $\mathrm{RNA}\,\mathrm{pol}$ 在 $\mathrm{DNA}$ 模板的转录起始区装配形成转录起始复合体，打开 $\mathrm{DNA}$ 双链，并完成第一和第二个核苷酸间聚合反应的过程。转录起始复合物中包含有 $\mathrm{RNA}\,\mathrm{pol}$ 全酶、$\mathrm{DNA}$ 模板以及 $\mathrm{NTP}$。

:::definition{label="转录起始"}
$\mathrm{RNA}\,\mathrm{pol}$ 在转录起始区装配成转录起始复合体，打开 $\mathrm{DNA}$ 双链，并完成第一和第二个核苷酸之间的聚合。起始复合物：全酶 $+\mathrm{DNA}$ 模板 $+\mathrm{NTP}$。
:::

:::keypoint{label="起始定义里已经有三步的萌芽"}
- 装配（全酶落到起始区）→ 后文闭合复合体。
- 打开双链 → 后文开放复合体，约 $17\,\mathrm{bp}$。
- 第一、第二个核苷酸成键 → 后文 $5'$-$\mathrm{pppGpN}$-$\mathrm{OH}$-$3'$，不需引物。
:::

### （二）RNA 聚合酶识别模板的特殊碱基序列——启动子

对于整个基因组来讲，转录是分区段进行的。每一转录区段可视为一个转录单位，称为操纵子（operon）（见第十七章）。操纵子包括了若干个基因的编码区及其调控序列。调控序列中的启动子（promoter）是 $\mathrm{RNA}\,\mathrm{pol}$ 结合模板 $\mathrm{DNA}$ 的部位，也是决定转录起始点的关键部位。原核生物是以 $\mathrm{RNA}\,\mathrm{pol}$ 全酶结合到启动子上而启动转录的，其中由 $\sigma$ 亚基辨认启动子，其他亚基相互配合。

:::definition{label="操纵子"}
操纵子（operon）：基因组上的一个转录单位，包括若干个基因的编码区及其调控序列。详见第十七章。本节只借用它给启动子安家：启动子是调控序列里让 $\mathrm{RNA}\,\mathrm{pol}$ 结合的那一段。
:::

:::definition{label="启动子"}
启动子（promoter）是 $\mathrm{RNA}\,\mathrm{pol}$ 结合模板 $\mathrm{DNA}$ 的部位，也是决定转录起始点的关键部位。原核：全酶结合启动子而启动转录，$\sigma$ 辨认启动子，其他亚基配合。
:::

:::pitfall{label="启动子不是结构基因本身"}
它在调控序列里，决定从哪里开始抄。把启动子答成“被转录成蛋白质的那段 $\mathrm{DNA}$”，图15-4 里「结构基因」和「$\mathrm{RNA}$ 聚合酶保护区」就会并成一块。
:::

:::insight{label="分区段转录就是第一节“选择性”的基因组层"}
第一节写一个基因只抄一股链；这里写基因组分区段、每一区段是一个操纵子。两层合在一起才是选择性转录。
:::

启动子结构的阐明回答了转录从哪里起始这一问题，是转录机制研究的重要发现。为了确认 $\mathrm{RNA}\,\mathrm{pol}$ 在基因组的结合位点，研究中采用了一种巧妙的方法，即 $\mathrm{RNA}\,\mathrm{pol}$ 保护法。在实验中，先将提取的 $\mathrm{DNA}$ 与提纯的 $\mathrm{RNA}\,\mathrm{pol}$ 混合温育一定时间，再加入核酸外切酶进行反应。结果显示，大部分 $\mathrm{DNA}$ 链被核酸酶水解为核苷酸，但一个 $40\sim 60\,\mathrm{bp}$ 的 $\mathrm{DNA}$ 片段被保留下来。这段 $\mathrm{DNA}$ 没有被水解，是因为 $\mathrm{RNA}\,\mathrm{pol}$ 结合在上面，因而受到保护。受保护的 $\mathrm{DNA}$ 位于转录起始点的上游，并最终被确认为是被 $\mathrm{RNA}\,\mathrm{pol}$ 辨认和紧密结合的区域，是转录起始调节区（图15-4）。

:::definition{label="RNA pol 保护法"}
把提取的 $\mathrm{DNA}$ 与提纯的 $\mathrm{RNA}\,\mathrm{pol}$ 混合温育，再加核酸外切酶。酶结合部位的 $\mathrm{DNA}$ 不被水解，留下 $40\sim 60\,\mathrm{bp}$ 片段。该片段在转录起点上游，即 $\mathrm{RNA}\,\mathrm{pol}$ 辨认并紧密结合的转录起始调节区。
:::

:::definition{label="保护区长度"}
受保护片段 $40\sim 60\,\mathrm{bp}$。后文核心酶覆盖 $40\,\mathrm{bp}$ 以上、开链却只有约 $17\,\mathrm{bp}$，两套长度不要混：覆盖宽度大于解链宽度。
:::

::figure{src="/images/biochemistry/textbook/p0304_01.png" caption="图15-4　RNA pol 保护法研究转录起始区。上方：RNA 聚合酶保护区在结构基因上游，下游有终止点；下方：-50 至 +10 标尺，-35 为 TTGACA／AACTGT，-10 为 TATAATPu／ATATTAPy，+1 处转录开始掺入 pppG，更下游标翻译开始。" alt="启动子标尺：-35 TTGACA，-10 TATAATPu，+1 转录开始 pppG，翻译开始在下游"}

:::insight{label="图15-4 上排把操纵子画成三段"}
左：$\mathrm{RNA}$ 聚合酶保护区（启动子）；中：结构基因；右：终止点。保护法找到的是左段，不是结构基因。下排把左段放大成 $-50$ 到 $+10$ 的标尺。
:::

:::keypoint{label="保护法三步不要写反"}
- 先温育：$\mathrm{DNA}+\mathrm{RNA}\,\mathrm{pol}$ 结合。
- 再加外切酶：未结合的 $\mathrm{DNA}$ 被水解。
- 留下的 $40\sim 60\,\mathrm{bp}$ 在起点**上游**，是起始调节区。
:::

对数百个原核生物基因操纵子转录上游区段进行的碱基序列分析，证明 $\mathrm{RNA}\,\mathrm{pol}$ 保护区存在共有序列。以模板链上对应于转录产物 $5'$ 端第一位核苷酸的位置为转录起点（transcription start site，$\mathrm{TSS}$；或 initiator）记为 $+1$，用负数表示其上游的碱基序号，发现 $-35$ 和 $-10$ 区 $\mathrm{A}$-$\mathrm{T}$ 配对比较集中。$-35$ 区的一致性序列是 $\mathrm{TTGACA}$。$-10$ 区的一致性序列 $\mathrm{TATAAT}$，是在 $1975$ 年由 Pribnow D. 发现的，故被称为 Pribnow 盒（Pribnow box）。$-35$ 区与 $-10$ 区相隔 $16\sim 18$ 个核苷酸，$-10$ 区与转录起点相距 $6$ 或 $7$ 个核苷酸。

$\mathrm{A}$-$\mathrm{T}$ 配对相对集中，表明该区段的 $\mathrm{DNA}$ 容易解链，因为 $\mathrm{A}$-$\mathrm{T}$ 配对只有两个氢键维系。比较 $\mathrm{RNA}\,\mathrm{pol}$ 结合不同区段测得的平衡常数，发现 $\mathrm{RNA}\,\mathrm{pol}$ 结合在 $-10$ 区比结合在 $-35$ 区更为牢固。把 $\mathrm{RNA}\,\mathrm{pol}$ 分子大小与 $\mathrm{DNA}$ 链长度进行比较，可确定其结合 $\mathrm{DNA}$ 链时分子的跨度。从这些结果推论出：$-35$ 区是 $\mathrm{RNA}\,\mathrm{pol}$ 对转录起始的识别序列（recognition sequence）。结合识别序列后，$\mathrm{RNA}\,\mathrm{pol}$ 向下游移动，达到 Pribnow 盒，与 $\mathrm{DNA}$ 形成相对稳定的 $\mathrm{RNA}\,\mathrm{pol}$-$\mathrm{DNA}$ 复合物，就可以开始转录。

:::definition{label="转录起点 +1"}
转录起点（transcription start site，$\mathrm{TSS}$；或 initiator）定为 $+1$，上游用负数编号。图15-4 在 $+1$ 处标「转录开始」并画出 $\mathrm{pppG}$。编号习惯与编码链 $5'\rightarrow 3'$ 那一行一致（图中 $-35$、$-10$、$+1$ 都在同一条 $5'$ 标尺上），不要把模板链的阅读方向 $3'\rightarrow 5'$ 理解成「$+1$ 在模板链的 $5'$ 末端」。
:::

:::definition{label="-35 区"}
一致性序列 $\mathrm{TTGACA}$。$\mathrm{A}$-$\mathrm{T}$ 较集中。是 $\mathrm{RNA}\,\mathrm{pol}$ 对转录起始的识别序列（recognition sequence）。酶在这一区段与模板结合松弛。
:::

:::definition{label="-10 区（Pribnow 盒）"}
一致性序列 $\mathrm{TATAAT}$。$1975$ 年 Pribnow D. 发现，称 Pribnow 盒（Pribnow box）。$\mathrm{RNA}\,\mathrm{pol}$ 结合 $-10$ 比结合 $-35$ 更牢固，形成相对稳定的复合物后即可开始转录。
:::

:::definition{label="启动子内部距离"}
$-35$ 与 $-10$ 相隔 $16\sim 18$ 个核苷酸；$-10$ 与转录起点相距 $6$ 或 $7$ 个核苷酸。图15-4 把 $-10$ 区写成 $\mathrm{TATAATPu}$（下游常接一个嘌呤）。
:::

:::timeline{period="启动子共有序列怎样被钉住"}
- **RNA pol 保护法** 留下上游 40 至 60 bp 的结合片段
- **数百个操纵子上游序列比较** 保护区出现共有序列，-35 为 TTGACA，-10 为 TATAAT
- **1975** Pribnow 发现 -10 区一致性序列，后称 Pribnow 盒
- **结合平衡常数** 酶在 -10 区比在 -35 区结合更牢固，推论 -35 是识别序列，随后移向 Pribnow 盒稳定结合
:::

:::cause-effect{title="为什么 -10、-35 容易开链"}
- **因** 两区 $\mathrm{A}$-$\mathrm{T}$ 配对集中，$\mathrm{A}$-$\mathrm{T}$ 只有两个氢键
- **果** 该区段 $\mathrm{DNA}$ 容易解链，开放复合体可以在接近 $-10$ 的区域把双螺旋打开
:::

:::compare{title="-35 识别 vs -10 稳定结合"}
| | $-35$（$\mathrm{TTGACA}$） | $-10$（$\mathrm{TATAAT}$，Pribnow 盒） |
|--|---------------------------|----------------------------------------|
| 功能 | 识别序列 | 紧密结合，随后开链、开始转录 |
| 结合 | 松弛 | 更牢固（平衡常数） |
| 顺序 | 先被辨认 | 酶向下游移动后到达 |
| 与 $+1$ 的距离 | 更远 | $6$ 或 $7$ 个核苷酸 |

先认 $-35$，再落到 $-10$，不是同时「抓死」两段。
:::

:::pitfall{label="-10 不要写成真核 TATA 盒"}
Pribnow 盒是原核 $-10$ 的 $\mathrm{TATAAT}$。真核 $\mathrm{TATA}$ 盒（Hognest 盒）是第三节的账，位置和配套因子都不同。看见 $\mathrm{TATA}$ 四个字母就答真核，本节图15-4 对不上。
:::

:::pitfall{label="间隔 16～18 不要记成 -35 到 +1"}
$16\sim 18$ 是 $-35$ 与 $-10$ 之间；$6$ 或 $7$ 是 $-10$ 到起点。把 $16\sim 18$ 安到 $-10$ 与 $+1$ 之间，Pribnow 盒就会被画到 $-20$ 附近。
:::

:::pitfall{label="识别序列不是结合最牢的那段"}
$-35$ 叫 recognition sequence，结合却更松；更牢的是 $-10$。名称和亲和力不要按「识别＝抓得最紧」去猜。
:::

:::keypoint{label="图15-4 下排必须能默写"}
- 标尺：$-50$ 到 $+10$，$+1$ 为转录开始。
- $-35$：$\mathrm{TTGACA}/\mathrm{AACTGT}$。
- $-10$：$\mathrm{TATAATPu}/\mathrm{ATATTAPy}$。
- $+1$：$\mathrm{pppG}$ 开始延长；翻译开始更在下游，不是同一点。
:::

### （三）基因转录起始经历了闭合转录复合体向开放转录复合体的转变

起始阶段的第一步是由 $\mathrm{RNA}\,\mathrm{pol}$ 识别并结合启动子，形成闭合转录复合体（closed transcription complex），其中的 $\mathrm{DNA}$ 仍保持完整的双链结构。原核生物需要靠 $\mathrm{RNA}\,\mathrm{pol}$ 中的 $\sigma$ 亚基辨认转录起始区和转录起点。首先被辨认的 $\mathrm{DNA}$ 区段是 $-35$ 区的 $\mathrm{TTGACA}$ 序列，在这一区段，酶与模板的结合松弛；接着酶移向 $-10$ 区的 $\mathrm{TATAAT}$ 序列并跨过了转录起点，形成与模板的稳定结合。

起始的第二步是 $\mathrm{DNA}$ 双链打开，闭合转录复合体成为开放转录复合体（open transcription complex）。开放转录复合体中 $\mathrm{DNA}$ 分子接近 $-10$ 区域的部分双螺旋解开后转录开始。无论是转录起始或延长中，$\mathrm{DNA}$ 双链解开的范围都只在 $17\,\mathrm{bp}$ 左右，这比复制中形成的复制叉小得多。

起始的第三步是第一个磷酸二酯键的形成。转录起始不需引物，两个与模板配对的相邻核苷酸，在 $\mathrm{RNA}\,\mathrm{pol}$ 催化下生成磷酸二酯键。转录起点配对生成的 $\mathrm{RNA}$ 的第一位核苷酸，也是新合成的 $\mathrm{RNA}$ 分子的 $5'$ 端，以 $\mathrm{GTP}$ 或 $\mathrm{ATP}$ 较为常见。当 $5'$ 端第一位核苷酸 $\mathrm{GTP}$ 与第二位的 $\mathrm{NTP}$ 聚合生成磷酸二酯键后，仍保留其 $5'$ 端 $3$ 个磷酸基团，生成聚合物是 $5'$-$\mathrm{pppGpN}$-$\mathrm{OH}$-$3'$，其 $3'$ 端的游离羟基，可以接收新的 $\mathrm{NTP}$ 并与之聚合，使 $\mathrm{RNA}$ 链延长下去。$\mathrm{RNA}$ 链的 $5'$ 端结构在转录延长中一直保留，至转录完成。

:::definition{label="闭合转录复合体"}
闭合转录复合体（closed transcription complex）：$\mathrm{RNA}\,\mathrm{pol}$ 已识别并结合启动子，$\mathrm{DNA}$ 仍保持完整双链。$\sigma$ 先认 $-35$ 的 $\mathrm{TTGACA}$（结合松弛），再移向 $-10$ 的 $\mathrm{TATAAT}$ 并跨过起点，形成稳定结合。
:::

:::definition{label="开放转录复合体"}
开放转录复合体（open transcription complex）：接近 $-10$ 区域的部分双螺旋解开后形成。无论起始还是延长，解开范围都只在约 $17\,\mathrm{bp}$，比复制叉小得多。
:::

:::definition{label="第一个磷酸二酯键"}
不需引物。两个与模板配对的相邻核苷酸由 $\mathrm{RNA}\,\mathrm{pol}$ 连成磷酸二酯键。第一位核苷酸即 $\mathrm{RNA}$ 的 $5'$ 端，以 $\mathrm{GTP}$ 或 $\mathrm{ATP}$ 较常见；与第二位 $\mathrm{NTP}$ 聚合后保留 $5'$ 端三个磷酸，产物 $5'$-$\mathrm{pppGpN}$-$\mathrm{OH}$-$3'$。这条 $5'$ 端结构一直保留到转录完成。
:::

:::compare{title="起始三步"}
| 步 | 复合体 / 产物 | DNA 是否开链 | 要点 |
|----|----------------|--------------|------|
| 一 | 闭合转录复合体 | 否，双链完整 | $\sigma$ 先 $-35$ 后 $-10$，跨过 $+1$ |
| 二 | 开放转录复合体 | 是，约 $17\,\mathrm{bp}$，近 $-10$ | 比复制叉小得多 |
| 三 | 第一个磷酸二酯键 | 开链区仍在 | 不需引物；$5'$-$\mathrm{pppGpN}$-$\mathrm{OH}$-$3'$ |

三步都还在起始里。$\sigma$ 脱落、进入延长，是下一节的账。
:::

:::pitfall{label="闭合复合体不是“酶还没碰到 DNA”"}
闭合指 $\mathrm{DNA}$ 双链还没打开，酶已经结合启动子。把 closed 听成未结合，识别序列那一步就没处放。
:::

:::pitfall{label="17 bp 不是复制叉的尺寸"}
教材对比：转录解开范围约 $17\,\mathrm{bp}$，「比复制中形成的复制叉小得多」。把转录泡画成复制叉那样的大 $\mathrm{Y}$，延长节的 $8\,\mathrm{bp}$ 杂合双链会对不上。
:::

:::pitfall{label="第一位核苷酸不是任意 NTP 机会均等"}
四种 $\mathrm{NTP}$ 都是延长原料，第一位「以 $\mathrm{GTP}$ 或 $\mathrm{ATP}$ 较为常见」。图15-4 画的是 $\mathrm{pppG}$。写成「第一位必须是 $\mathrm{G}$」过死；写成「四种机会相同」又忽略教材的偏好。
:::

:::insight{label="5′ 端三个磷酸一直留着"}
$5'$-$\mathrm{pppGpN}$-$\mathrm{OH}$-$3'$ 的 $5'$ 三磷酸在延长全程保留，直到转录完成。原核 $\mathrm{mRNA}$ 的 $5'$ 端不像真核那样在第三节里加帽——这是后文对比的伏笔，本节先把基团留下。
:::

:::keypoint{label="pppGpN 这一行在卷面上怎么写"}
- $5'$ 端：三个磷酸还在，常见 $\mathrm{pppG}$ 或 $\mathrm{pppA}$。
- 中间：第一个磷酸二酯键。
- $3'$ 端：游离羟基，准备接下一个 $\mathrm{NTP}$。
:::

$\mathrm{RNA}$ 合成开始时会发生流产式起始（abortive initiation）的现象。发生流产式起始的时候，$\mathrm{RNA}\,\mathrm{pol}$ 在完全进入延伸阶段前不从启动子上脱离，而是合成长度小于 $10$ 个核苷酸的 $\mathrm{RNA}$ 分子，并将这些短片段 $\mathrm{RNA}$ 从聚合酶上释放而终止转录。这个过程可在进入转录延长阶段前重复多次，从而产生多个短片段 $\mathrm{RNA}$。流产式起始被认为是启动子校对（promoter proofreading）的过程，其发生可能与 $\mathrm{RNA}$ 聚合酶和启动子的结合强度有关。

当一个聚合酶成功合成一条超过 $10$ 个核苷酸的 $\mathrm{RNA}$ 时，便形成一个稳定的包含有 $\mathrm{DNA}$ 模板、$\mathrm{RNA}\,\mathrm{pol}$ 和 $\mathrm{RNA}$ 片段的三重复合体，从而进入延长阶段。当 $\mathrm{RNA}$ 合成起始成功后，$\mathrm{RNA}\,\mathrm{pol}$ 离开启动子，称为启动子解脱（promoter escape），也叫启动子清除（promoter clearance）。启动子清除发生后，转录进入延长阶段。

:::definition{label="流产式起始"}
流产式起始（abortive initiation）：进入延长前，$\mathrm{RNA}\,\mathrm{pol}$ 仍不离开启动子，合成小于 $10$ 个核苷酸的短 $\mathrm{RNA}$ 并释放，转录在这一轮终止。可重复多次。被视为启动子校对（promoter proofreading），可能与酶和启动子的结合强度有关。
:::

:::definition{label="启动子解脱（启动子清除）"}
启动子解脱（promoter escape）又称启动子清除（promoter clearance）：成功合成超过 $10$ 个核苷酸的 $\mathrm{RNA}$ 后，形成稳定的 $\mathrm{DNA}$ 模板–$\mathrm{RNA}\,\mathrm{pol}$–$\mathrm{RNA}$ 三重复合体，$\mathrm{RNA}\,\mathrm{pol}$ 离开启动子，进入延长。
:::

:::compare{title="短于 10 nt vs 超过 10 nt"}
| | $<10$ 个核苷酸 | $>10$ 个核苷酸 |
|--|----------------|----------------|
| 名称 | 流产式起始 | 起始成功，启动子清除 |
| 酶与启动子 | 仍不脱离 | 离开启动子 |
| 短 RNA | 释放，该轮终止 | 留在三重复合体里继续长 |
| 功能理解 | 启动子校对 | 进入延长 |

$10$ 个核苷酸是教材给的分界，不要改成「几个碱基」含糊带过。
:::

:::pitfall{label="流产式起始不是转录终止的两种方式之一"}
终止的两种方式是依赖 $\rho$ 与非依赖 $\rho$，发生在基因下游。流产发生在启动子上、进入延长之前。把 abortive initiation 答进第三节「终止」，户头错了。
:::

:::insight{label="结合太牢也可能流产"}
教材说流产「可能与 $\mathrm{RNA}$ 聚合酶和启动子的结合强度有关」。结合不是越牢越好：太牢不利于启动子清除。这和前面「$-10$ 结合更牢固」不矛盾——牢固是为了开链，清除还要把酶从启动子上放走。
:::

## 二、RNA 聚合酶的核心酶催化 RNA 链的延长

### （一）基因转录延长阶段形成特殊的转录泡结构

转录过程中，第一个磷酸二酯键生成后，转录复合体的构象发生改变，$\sigma$ 亚基从转录起始复合物上脱落，并离开启动子，$\mathrm{RNA}$ 合成进入延长阶段。此时，仅有 $\mathrm{RNA}\,\mathrm{pol}$ 的核心酶留在 $\mathrm{DNA}$ 模板上，并沿 $\mathrm{DNA}$ 链不断前移，催化 $\mathrm{RNA}$ 链的延长。实验证明，$\sigma$ 亚基若不脱落，$\mathrm{RNA}\,\mathrm{pol}$ 则停留在起始位置，转录不继续进行。化学计量又证明，每个原核细胞，$\mathrm{RNA}\,\mathrm{pol}$ 各亚基比例为 $\alpha:\beta:\beta':\sigma=4\,000:2\,000:2\,000:600$，$\sigma$ 因子的量在细胞内明显比核心酶少。在体外进行的 $\mathrm{RNA}$ 合成实验也证明，$\mathrm{RNA}$ 的生成量与核心酶的加入量成正比；开始转录后，产物量与 $\sigma$ 亚基加入与否无关。脱落后的 $\sigma$ 因子又可再形成另一全酶，反复使用。

:::definition{label="σ 脱落是进入延长的标志"}
第一个磷酸二酯键生成后，复合体构象改变，$\sigma$ 脱落并离开启动子，只留核心酶沿模板前移。$\sigma$ 若不脱落，酶停在起始位置，转录不继续。
:::

:::definition{label="σ 比核心酶少，可以循环使用"}
细胞内亚基比例 $\alpha:\beta:\beta':\sigma=4\,000:2\,000:2\,000:600$。按 $\alpha_2\beta\beta'$ 去配核心酶，$\sigma$ 明显不够「一人一酶」。体外：产物量与核心酶加入量成正比，开始转录后与是否再加 $\sigma$ 无关。脱落的 $\sigma$ 可再装配另一全酶。
:::

:::cause-effect{title="为什么 σ 必须脱落"}
- **因** $\sigma$ 的职责是辨认起点并把全酶按在启动子上；不脱落则酶停留在起始位置
- **果** 构象改变后 $\sigma$ 离开，核心酶才能沿模板前移；细胞内 $\sigma$ 偏少，也要求它循环去启动下一轮
:::

:::pitfall{label="延长阶段不是“加上另一种酶”"}
还是原来那台 $\mathrm{RNA}\,\mathrm{pol}$，只是去掉 $\sigma$。写成换 $\mathrm{RNA}\,\mathrm{pol}\,\mathrm{II}$，已经跳进真核第三节。
:::

:::pitfall{label="比例 4000∶2000∶2000∶600 不要看成全酶里的化学计量"}
这是「每个原核细胞」里各亚基的分子数之比，用来证明 $\sigma$ 比核心酶少。全酶本身仍是 $\alpha_2\beta\beta'\omega\sigma$ 各就各位。把 $4\,000:2\,000$ 答成「一个全酶里有两千个 $\alpha$」，表15-1 就废了。
:::

:::insight{label="体外“开始转录后与 σ 无关”对应体内循环"}
起始已经完成，$\sigma$ 的辨认任务结束。再加 $\sigma$ 不增加产物量；产物量跟核心酶走。这和「脱落的 $\sigma$ 再形成另一全酶」是同一套逻辑的两面。
:::

$\mathrm{RNA}$ 链延长时，核心酶会沿着模板 $\mathrm{DNA}$ 不断向下游前移。聚合反应局部前方的 $\mathrm{DNA}$ 双链不断解链，合成完成后的部分又重新恢复双螺旋结构。核心酶可以覆盖 $40\,\mathrm{bp}$ 以上的 $\mathrm{DNA}$ 分子段落，但转录解链范围约 $17\,\mathrm{bp}$。$\mathrm{RNA}$ 链延长过程中的解链和再聚合可视为这一 $17\,\mathrm{bp}$ 左右的开链区在 $\mathrm{DNA}$ 上的动态移动，其外观类似泡状，被称为「转录泡」（transcription bubble）。

在解链区局部（图15-5），$\mathrm{RNA}\,\mathrm{pol}$ 的核心酶催化着模板指导的 $\mathrm{RNA}$ 链延长，转录产物 $3'$ 端会有一小段暂时与模板 $\mathrm{DNA}$ 保持结合状态，形成一段 $8\,\mathrm{bp}$ 的 $\mathrm{RNA}$-$\mathrm{DNA}$ 杂合双链（hybrid duplex）。随着 $\mathrm{RNA}$ 链不断生长，$5'$ 端脱离模板向空泡外伸展。从化学结构看，$\mathrm{DNA}/\mathrm{DNA}$ 双链结构比 $\mathrm{DNA}/\mathrm{RNA}$ 形成的杂化双链稳定。核酸的碱基之间有 $3$ 种配对方式，其稳定性是：$\mathrm{G}\equiv\mathrm{C}>\mathrm{A}=\mathrm{T}>\mathrm{A}=\mathrm{U}$。$\mathrm{GC}$ 配对有 $3$ 个氢键，是最稳定的；$\mathrm{AT}$ 配对只在 $\mathrm{DNA}$ 双链形成；$\mathrm{AU}$ 配对可在 $\mathrm{RNA}$ 分子或 $\mathrm{DNA}/\mathrm{RNA}$ 杂化双链上形成，是 $3$ 种配对中稳定性最低的。所以已转录完毕的局部 $\mathrm{DNA}$ 双链，就必然会复合而不再打开。根据这些道理，也就易于理解空泡为什么会形成，而转录产物又是为什么可以向外伸出了。

:::definition{label="转录泡"}
转录泡（transcription bubble）：约 $17\,\mathrm{bp}$ 的开链区随核心酶在 $\mathrm{DNA}$ 上动态移动，外观像泡。前方不断解链，后方恢复双螺旋。核心酶覆盖 $40\,\mathrm{bp}$ 以上，但解开的只有约 $17\,\mathrm{bp}$。
:::

:::definition{label="RNA-DNA 杂合双链"}
转录产物 $3'$ 端暂时与模板结合，形成约 $8\,\mathrm{bp}$ 的 $\mathrm{RNA}$-$\mathrm{DNA}$ 杂合双链（hybrid duplex）。$\mathrm{RNA}$ 的 $5'$ 端脱离模板，伸到泡外。
:::

:::definition{label="三种碱基配对的稳定性"}
$\mathrm{G}\equiv\mathrm{C}>\mathrm{A}=\mathrm{T}>\mathrm{A}=\mathrm{U}$。$\mathrm{GC}$ 三个氢键最稳；$\mathrm{AT}$ 只在 $\mathrm{DNA}$ 双链；$\mathrm{AU}$ 可在 $\mathrm{RNA}$ 或 $\mathrm{DNA}/\mathrm{RNA}$ 杂合体上，三者中最不稳。因此已转录完毕的 $\mathrm{DNA}$ 局部必然重新配对，产物 $\mathrm{RNA}$ 被「挤」出泡外。
:::

:::note{label="电子版缺失"}
教材图15-5「大肠埃希菌的转录泡局部结构示意图」电子版图源 `p0305_01.png` 为 $0$ 字节，不嵌入 `src`。正文以覆盖 $>40\,\mathrm{bp}$、开链约 $17\,\mathrm{bp}$、杂合双链 $8\,\mathrm{bp}$、以及 $\mathrm{G}\equiv\mathrm{C}>\mathrm{A}=\mathrm{T}>\mathrm{A}=\mathrm{U}$ 为准。
:::

观察图15-5 中的「转录泡」局部，可概括出转录延长以下特点：①核心酶负责 $\mathrm{RNA}$ 链延长反应；②$\mathrm{RNA}$ 链从 $5'$ 端向 $3'$ 端延长，新的核苷酸都是加到 $3'$-$\mathrm{OH}$ 上；③对 $\mathrm{DNA}$ 模板链的阅读方向是 $3'$ 端向 $5'$ 端，合成的 $\mathrm{RNA}$ 链与之呈反向互补，即酶是沿着模板链的 $3'\rightarrow 5'$ 方向或沿着编码链的 $5'\rightarrow 3'$ 方向前进的；④合成区域存在着动态变化的 $8\,\mathrm{bp}$ 的 $\mathrm{RNA}$-$\mathrm{DNA}$ 杂合双链；⑤模板 $\mathrm{DNA}$ 的双螺旋结构随着核心酶的移动发生解链和再复合的动态变化。

:::keypoint{label="转录延长五条（教材对图15-5 的概括）"}
- 核心酶负责延长。
- $\mathrm{RNA}$ $5'\rightarrow 3'$ 长，核苷酸加在 $3'$-$\mathrm{OH}$。
- 阅读模板 $3'\rightarrow 5'$，产物反向互补；酶沿模板 $3'\rightarrow 5'$，或沿编码链 $5'\rightarrow 3'$ 前进。
- 动态的 $8\,\mathrm{bp}$ $\mathrm{RNA}$-$\mathrm{DNA}$ 杂合双链。
- 双螺旋随酶移动而解链、再复合。
:::

:::compare{title="三个长度不要背串"}
| 长度 | 指什么 |
|------|--------|
| $40\sim 60\,\mathrm{bp}$ | 保护法留下的结合片段 |
| $40\,\mathrm{bp}$ 以上 | 核心酶覆盖的 $\mathrm{DNA}$ 段落 |
| 约 $17\,\mathrm{bp}$ | 真正解开的转录泡 |
| $8\,\mathrm{bp}$ | $\mathrm{RNA}$-$\mathrm{DNA}$ 杂合双链 |

覆盖 $>$ 开链 $>$ 杂合。把 $17$ 和 $8$ 对调，泡里那一小段杂合体就比开链区还长，几何上不可能。
:::

:::cause-effect{title="为什么 RNA 的 5′ 端会伸到泡外"}
- **因** $\mathrm{DNA}/\mathrm{DNA}$ 比 $\mathrm{DNA}/\mathrm{RNA}$ 稳，$\mathrm{A}=\mathrm{U}$ 又是三种配对里最弱的；已转录过的 $\mathrm{DNA}$ 两股必然重新配对
- **果** 杂合双链只能维持约 $8\,\mathrm{bp}$，$\mathrm{RNA}$ 的 $5'$ 端被置换出来，伸到泡外；这也为原核 $\mathrm{mRNA}$ 边合成边翻译准备了游离的 $5'$ 端
:::

:::pitfall{label="酶沿编码链 5′→3′ 前进，不是以编码链为模板"}
教材有两句等价描述：沿模板 $3'\rightarrow 5'$，或沿编码链 $5'\rightarrow 3'$。模板仍是那股与 $\mathrm{mRNA}$ 互补的链。把第二句听成「以编码链为模板」，第一节图15-1 就反了。
:::

:::pitfall{label="AU 配对不是“不存在于 DNA”那么简单"}
教材：$\mathrm{AT}$ 只在 $\mathrm{DNA}$ 双链；$\mathrm{AU}$ 在 $\mathrm{RNA}$ 分子或 $\mathrm{DNA}/\mathrm{RNA}$ 杂合体上，稳定性最低。终止节非依赖 $\rho$ 还要靠一串 $\mathrm{A}$-$\mathrm{U}$ 把 $\mathrm{RNA}$ 从模板上拉开——稳定性最低是后文的伏笔。
:::

### （二）转录与翻译同时进行

在电子显微镜下观察原核生物的转录产物，可看到像羽毛状的图形（图15-6）。进一步分析表明，在同一个 $\mathrm{DNA}$ 模板分子上，有多个转录复合体同时在进行着 $\mathrm{RNA}$ 的合成；在新合成的 $\mathrm{mRNA}$ 链上还可观察到结合在上面的多个核糖体，即多聚核糖体。这是因为在原核生物，$\mathrm{RNA}$ 链的转录合成尚未完成，蛋白质的合成已经将其作为模板开始进行翻译了。转录和翻译的同步进行在原核生物是较为普遍的现象，保证了转录和翻译都以高效率运行，满足它们快速增殖的需要。

:::definition{label="原核转录与翻译同步"}
$\mathrm{RNA}$ 尚未合成完毕，核糖体已结合新生 $\mathrm{mRNA}$ 开始翻译。电镜下呈羽毛状（图15-6）：同一 $\mathrm{DNA}$ 上多个转录复合体同时工作，每条新生 $\mathrm{mRNA}$ 上又有多个核糖体（多聚核糖体）。
:::

:::definition{label="同步的生理意义"}
原核较为普遍。保证转录和翻译都以高效率运行，满足快速增殖的需要。
:::

:::note{label="电子版缺失"}
教材图15-6「原核生物转录和翻译同步现象示意图」电子版图源 `p0306_01.png` 为 $0$ 字节，不嵌入 `src`。同页非空图 `p0306_02.png` 是图15-7（依赖 $\rho$ 的终止），不要把羽毛状图形错配到 $\rho$ 六聚体上。
:::

:::insight{label="泡外伸出的 5′ 端正好给核糖体用"}
延长节刚写 $\mathrm{RNA}$ 的 $5'$ 端伸到泡外。原核没有核膜把转录和翻译隔开，核糖体可以立刻挂上这截游离 $5'$ 端。真核 $\mathrm{mRNA}$ 要加工、出核，同步翻译不是默认选项——对比留给第三节。
:::

:::pitfall{label="羽毛状不是“一个酶同时抄两股链”"}
同一 $\mathrm{DNA}$ 上是**多个**转录复合体；每条 $\mathrm{mRNA}$ 上是**多个**核糖体。把羽毛听成双链同时转录，又退回第一节的选择性错误。
:::

:::pitfall{label="同步不是真核的普遍现象"}
教材把这句话限定在原核，并解释为满足快速增殖。真核有细胞核、有加工，不能把羽毛图搬过去。
:::

:::keypoint{label="图15-6 缺图时仍要能默写的两层“多个”"}
- 同一 $\mathrm{DNA}$：多个转录复合体。
- 同一新生 $\mathrm{mRNA}$：多个核糖体（多聚核糖体）。
- 外观：羽毛状。
:::

## 三、转录终止有 ρ 因子依赖和 ρ 因子非依赖两种方式

$\mathrm{RNA}\,\mathrm{pol}$ 在 $\mathrm{DNA}$ 模板上停顿下来不再前进，转录产物 $\mathrm{RNA}$ 链从转录复合物上脱落下来，就是转录终止。依据是否需要蛋白质因子的参与，原核生物的转录终止分为依赖 $\rho$（Rho）因子与非依赖 $\rho$ 因子两大类。

:::definition{label="转录终止"}
$\mathrm{RNA}\,\mathrm{pol}$ 在模板上停顿不再前进，产物 $\mathrm{RNA}$ 从转录复合物上脱落。
:::

:::definition{label="原核终止的两大类"}
按是否需要蛋白质因子：依赖 $\rho$（Rho）因子；非依赖 $\rho$ 因子。教材：部分基因依赖 $\rho$，**多数**基因非依赖 $\rho$。
:::

:::compare{title="依赖 ρ vs 非依赖 ρ"}
| | 依赖 $\rho$ | 非依赖 $\rho$ |
|--|------------|--------------|
| 蛋白质因子 | 需要 $\rho$ 六聚体 | 不需要蛋白因子 |
| 信号主要在 | 产物 $\mathrm{RNA}$ $3'$ 端富含、有规律的 $\mathrm{C}$ | 产物 $3'$ 端多聚 $\mathrm{U}$ $+$ 上游茎环／发夹 |
| 教材用量 | 部分原核基因 | 多数原核基因 |
| 图 | 图15-7 | 图15-8 |

分类标准是「要不要蛋白质因子」，不是「有没有 $\mathrm{RNA}$ 二级结构」。
:::

:::pitfall{label="终止不是聚合酶在细胞里被降解"}
定义是停顿 $+$ $\mathrm{RNA}$ 脱落。酶还可以去下一轮；$\sigma$ 循环、核心酶循环都还在。写成「全酶分解」，化学计量那组比例就没意义了。
:::

### （一）部分原核基因的转录终止依赖 ρ 因子

用 $\mathrm{T4}$ 噬菌体 $\mathrm{DNA}$ 作体外转录实验，发现其转录产物比在细胞内转录出的产物要长。这一方面说明转录终止点是可以被跨越而继续转录的；还说明细胞内的某些因子有执行转录终止的功能。根据这些线索，$1969$ 年，Roberts J. 在 $\mathrm{T4}$ 噬菌体感染的大肠埃希菌中发现了能控制转录终止的蛋白质，命名为 $\rho$ 因子。体外转录体系中加入了 $\rho$ 因子后，转录产物长于细胞内的现象不复存在。$\rho$ 因子是由相同亚基组成的六聚体蛋白质，亚基分子量为 $46\,\mathrm{kD}$。$\rho$ 因子能结合 $\mathrm{RNA}$，又以对 $\mathrm{polyC}$ 的结合力最强，但对 $\mathrm{polydC}/\mathrm{dG}$ 组成的 $\mathrm{DNA}$ 的结合能力就低得多。

在依赖 $\rho$ 因子终止的转录中，产物 $\mathrm{RNA}$ 的 $3'$ 端会依照 $\mathrm{DNA}$ 模板，产生较丰富而且有规律的 $\mathrm{C}$ 碱基。$\rho$ 因子正是识别产物 $\mathrm{RNA}$ 上这些终止信号序列，并与之结合。结合 $\mathrm{RNA}$ 后的 $\rho$ 因子和 $\mathrm{RNA}\,\mathrm{pol}$ 都可发生构象变化，从而使 $\mathrm{RNA}\,\mathrm{pol}$ 的移动停顿，$\rho$ 因子中的解旋酶活性使 $\mathrm{DNA}/\mathrm{RNA}$ 杂化双链拆离，$\mathrm{RNA}$ 产物从转录复合物中释放（图15-7），转录终止。

:::definition{label="ρ 因子"}
$\rho$（Rho）因子：$1969$ 年 Roberts J. 在 $\mathrm{T4}$ 噬菌体感染的大肠埃希菌中发现的控制转录终止的蛋白质。相同亚基组成的六聚体，亚基分子量 $46\,\mathrm{kD}$。结合 $\mathrm{RNA}$，对 $\mathrm{polyC}$ 最强；对 $\mathrm{polydC}/\mathrm{dG}$ 的 $\mathrm{DNA}$ 结合能力低得多。含解旋酶活性。
:::

:::definition{label="ρ 的发现实验"}
$\mathrm{T4}$ $\mathrm{DNA}$ 体外转录产物比细胞内的长 → 终止点可被跨越，细胞内必有终止因子。加入 $\rho$ 后，产物不再偏长。
:::

:::definition{label="依赖 ρ 的终止过程"}
产物 $\mathrm{RNA}$ $3'$ 端有较丰富、有规律的 $\mathrm{C}$；$\rho$ 识别并结合这些终止信号。$\rho$ 与 $\mathrm{RNA}\,\mathrm{pol}$ 构象都变，酶停顿；$\rho$ 的解旋酶活性拆开 $\mathrm{DNA}/\mathrm{RNA}$ 杂合双链，$\mathrm{RNA}$ 释放。
:::

:::timeline{period="ρ 因子从现象到分子"}
- **体外 T4 DNA 转录** 产物比细胞内的长，说明终止点可被跨越，细胞内应有终止因子
- **1969** Roberts 在 T4 噬菌体感染的大肠埃希菌中发现控制终止的蛋白质，命名为 ρ 因子
- **补回实验** 体外体系加入 ρ 后，产物偏长的现象消失
- **分子性质** 相同亚基的六聚体，亚基 46 kD；结合 RNA（polyC 最强），有解旋酶活性
:::

::figure{src="/images/biochemistry/textbook/p0306_02.png" caption="图15-7　依赖 ρ 因子的转录终止。左：ρ 六聚体结合在新生 RNA 上，聚合酶转录泡内可见 RNA-DNA 杂合；中：消耗 ATP；右：ρ 沿 RNA 追上聚合酶，杂合双链被拆开，RNA 5′ 端被拉离。" alt="两幅：ρ 六聚体先结合 RNA，加 ATP 后缠绕并拆离 RNA-DNA 杂合体"}

:::note{label="电子版缺失"}
与图15-7 同页的 `p0306_03.png` 为 $0$ 字节（教材「动画」占位），不嵌入 `src`。`p0306_01.png` 为空的图15-6，见上一小节。
:::

:::insight{label="图15-7 读图：ρ 结合的是 RNA 不是 DNA"}
左图 $\rho$ 六聚体在泡外的 $\mathrm{RNA}$ 上；箭头写 $+ \mathrm{ATP}$；右图 $\rho$ 把 $\mathrm{RNA}$ 缠进去，泡内杂合段变短。这与「对 $\mathrm{polyC}$ 的 $\mathrm{RNA}$ 结合力强、对 $\mathrm{polydC}/\mathrm{dG}$ 的 $\mathrm{DNA}$ 结合力低」一致：信号在产物上，不在模板 $\mathrm{DNA}$ 上另做一套蛋白质结合位点。
:::

:::compare{title="ρ 对 RNA 和对 DNA 的结合差在哪"}
| 配体 | 结合 |
|------|------|
| $\mathrm{RNA}$，尤其 $\mathrm{polyC}$ | 强 |
| $\mathrm{polydC}/\mathrm{dG}$ 的 $\mathrm{DNA}$ | 低得多 |

所以依赖 $\rho$ 的终止信号写在产物 $\mathrm{RNA}$ 的 $3'$ 端 $\mathrm{C}$ 碱基上，不是写在 $\mathrm{DNA}$ 的 $\mathrm{dC}/\mathrm{dG}$ 上让 $\rho$ 去认双螺旋。
:::

:::cause-effect{title="为什么体外产物会更长"}
- **因** 纯酶体系没有 $\rho$，终止点可以被跨越，聚合酶继续往下游走
- **果** 得到比细胞内更长的 $\mathrm{RNA}$；加回 $\rho$，长度恢复

这句话同时证明：终止不是模板「走完了」自动发生，而是可被执行、也可被忽略的一步。
:::

:::pitfall{label="ρ 是六聚体，亚基 46 kD，不要和全酶 450 kD 混"}
全酶 $450\,\mathrm{kD}$ 是 $\mathrm{RNA}\,\mathrm{pol}$；$\rho$ 每个亚基 $46\,\mathrm{kD}$，六个相同亚基。写成「$\rho$ 分子量 $450\,\mathrm{kD}$」是把聚合酶的数字安到终止因子上。
:::

:::pitfall{label="ρ 不是 σ 的别名"}
$\sigma$ 辨认起点，起始用；$\rho$ 执行部分基因的终止。把 Rho 答成 sigma，表15-1 和本节终止分类一起错。
:::

:::pitfall{label="解旋酶活性拆的是 DNA/RNA 杂合体，不是把整个基因组解开"}
$\rho$ 让产物从转录复合物释放。写成「$\rho$ 取代解旋酶去开复制叉」，第十四章和本节都会乱。
:::

### （二）多数原核基因的转录终止需要特殊的碱基序列而非依赖 ρ 因子

$\mathrm{DNA}$ 模板上靠近转录终止处有些特殊碱基序列，转录出 $\mathrm{RNA}$ 后，$\mathrm{RNA}$ 产物可以形成特殊的结构来终止转录，不需要蛋白因子的协助，即非依赖 $\rho$ 因子的转录终止。可导致终止的转录产物的 $3'$ 端常有多个连续的 $\mathrm{U}$，其上游的一段特殊碱基序列又可形成鼓槌状的茎环或发夹形式的二级结构，这些结构的形成是非依赖 $\rho$ 因子终止的信号。

如图15-8 所示，$\mathrm{RNA}$ 链延长至接近终止区时，转录出的 $\mathrm{RNA}$ 片段随即形成茎-环结构。这种二级结构是阻止转录继续向下游推进的关键。其机制可从两方面理解：一是 $\mathrm{RNA}$ 分子形成的茎环结构可能改变 $\mathrm{RNA}\,\mathrm{pol}$ 的构象。注意 $\mathrm{RNA}\,\mathrm{pol}$ 的分子量大，它不但覆盖转录延长区，也覆盖部分 $3'$ 端新合成的 $\mathrm{RNA}$ 链，包括刚形成的 $\mathrm{RNA}$ 茎环结构。$\mathrm{RNA}$ 茎环结构可影响 $\mathrm{RNA}\,\mathrm{pol}$ 的结构而使其构象改变，从而使 $\mathrm{RNA}\,\mathrm{pol}$-$\mathrm{DNA}$ 模板的结合方式发生改变。$\mathrm{RNA}\,\mathrm{pol}$ 不再向下游移动，于是转录停止。其二，转录复合物（$\mathrm{RNA}\,\mathrm{pol}$-$\mathrm{DNA}$-$\mathrm{RNA}$）上形成的局部 $\mathrm{RNA}/\mathrm{DNA}$ 杂化短链的碱基配对是不稳定的，随着 $\mathrm{RNA}$ 茎环结构的形成，$\mathrm{RNA}$ 从 $\mathrm{DNA}$ 模板链上脱离，单链 $\mathrm{DNA}$ 复原为双链，转录泡关闭，转录终止。另外，$\mathrm{RNA}$ 链上的多聚 $\mathrm{U}$ 也是促使 $\mathrm{RNA}$ 链从模板上脱落的重要因素。

:::definition{label="非依赖 ρ 的转录终止"}
不需要蛋白因子。模板近终止处有特殊序列，转录出的 $\mathrm{RNA}$ 自己形成终止结构：产物 $3'$ 端多个连续 $\mathrm{U}$，其上游形成鼓槌状茎环或发夹。多数原核基因走这一条。
:::

:::definition{label="茎环改变 RNA pol 构象"}
$\mathrm{RNA}\,\mathrm{pol}$ 分子量大，覆盖延长区以及部分新合成的 $3'$ 端 $\mathrm{RNA}$（包括刚形成的茎环）。茎环改变酶的构象，从而改变酶与模板的结合方式，酶不再向下游移动。
:::

:::definition{label="杂合短链不稳定加多聚 U"}
复合物上局部 $\mathrm{RNA}/\mathrm{DNA}$ 杂合短链配对不稳定；茎环形成后 $\mathrm{RNA}$ 脱离模板，$\mathrm{DNA}$ 复原为双链，转录泡关闭。多聚 $\mathrm{U}$ 也促使 $\mathrm{RNA}$ 从模板脱落——对应延长节 $\mathrm{A}=\mathrm{U}$ 稳定性最低。
:::

::figure{src="/images/biochemistry/textbook/p0307_01.png" caption="图15-8　非依赖 ρ 因子的转录终止模式。RNA 聚合酶内模板与新生 RNA 以一串 A-U 配对；酶后方 RNA 形成富含 GC 的茎环。右：酶释放后的 RNA 带茎环，3′ 端为 UUUUUU。" alt="RNA 聚合酶覆盖 DNA，新生 RNA 形成 GC 茎环，泡内为 A 与 U 配对，释放产物 3′ 端一串 U"}

图15-8 同页「动画」图源 `p0307_02.png`、`p0307_03.png` 为 $0$ 字节，不嵌入 `src`。`p0308_01.png` 亦为 $0$ 字节，属第三节图15-9（真核启动子共有序列），不在本节嵌入。
:::

:::insight{label="图15-8 把延长节的 AU 最弱用在终止上"}
酶体内标着一串 $\mathrm{U}$ 对 $\mathrm{A}$：这正是杂合双链里最不稳的配对。茎环标「富含 $\mathrm{GC}$」——$\mathrm{G}\equiv\mathrm{C}$ 最稳，发夹一旦形成就不容易拆。一弱一强：弱的是 $\mathrm{RNA}$-模板连接，强的是产物自己的发夹。
:::

:::compare{title="非依赖 ρ：两个机制加一个多聚 U"}
| 机制 | 教材原句要点 |
|------|----------------|
| 茎环改酶构象 | 大分子聚合酶覆盖到新 $\mathrm{RNA}$ 的茎环，结合方式变，不再向下游移动 |
| 杂合短链不稳 | $\mathrm{RNA}$ 脱离模板，$\mathrm{DNA}$ 恢复双链，转录泡关闭 |
| 多聚 $\mathrm{U}$ | 促使 $\mathrm{RNA}$ 从模板脱落的重要因素 |

问「为什么不需要 $\rho$」：信号和动力都在 $\mathrm{RNA}$ 自己的序列／结构里。
:::

:::cause-effect{title="为什么是“鼓槌状”而不是任意发夹"}
- **因** 终止产物 $3'$ 端先有一段能配对的序列（常富 $\mathrm{GC}$）形成茎，环在顶部，再接一串 $\mathrm{U}$，整体像鼓槌
- **果** 茎环足够稳定去改酶构象，随后那串 $\mathrm{A}$-$\mathrm{U}$ 又足够弱，RNA 被拉离

缺茎环只剩多聚 $\mathrm{U}$，或有发夹没有一串 $\mathrm{U}$，都不是教材写全的非依赖 $\rho$ 信号。
:::

:::pitfall{label="非依赖 ρ 不是“没有终止信号”"}
不需要蛋白因子，但需要 $\mathrm{RNA}$ 上的茎环 $+$ 多聚 $\mathrm{U}$。写成「聚合酶走到基因末尾自然停下」，和依赖 $\rho$ 那侧「终止点可被跨越」矛盾。
:::

:::pitfall{label="茎环在 RNA 上，不要画到 DNA 模板去形成发夹才终止"}
教材：转录出 $\mathrm{RNA}$ 后，**产物**形成特殊结构。模板上有特殊碱基序列，那是为了让产物能配对成茎环。把终止画成 $\mathrm{DNA}$ 自己打结，酶覆盖「新合成 $\mathrm{RNA}$ 的茎环」那句就没着落。
:::

:::pitfall{label="多数基因走非依赖 ρ，不要答成“原核终止都要 ρ”"}
标题已经写「部分」依赖、「多数」非依赖。只背 $1969$ 年 Roberts，会把多数基因的茎环漏掉。
:::

:::keypoint{label="图15-8 读图三件事"}
- 酶覆盖 $\mathrm{DNA}$，内部是一串 $\mathrm{A}$（模板）对 $\mathrm{U}$（$\mathrm{RNA}$）。
- 酶后方 $\mathrm{RNA}$：富含 $\mathrm{GC}$ 的茎环。
- 释放后的分子：$5'$ 端在前，茎环在中，$3'$ 端 $\mathrm{UUUUUU}$。
:::

:::memory{label="全酶、启动子、泡、终止四张名片"}
- 全酶 $=\alpha_2\beta\beta'\omega\sigma$，起始用；核心酶延长，$\sigma$ 循环。
- 启动子：$-35$ $\mathrm{TTGACA}$ 识别（松），$-10$ $\mathrm{TATAAT}$ 牢固结合；间距 $16\sim 18$；$+1$ 常见 $\mathrm{pppG}/\mathrm{pppA}$。
- 转录泡：覆盖 $>40\,\mathrm{bp}$，开链 $\sim 17\,\mathrm{bp}$，杂合 $8\,\mathrm{bp}$；$\mathrm{G}\equiv\mathrm{C}>\mathrm{A}=\mathrm{T}>\mathrm{A}=\mathrm{U}$。
- 终止：部分靠 $\rho$ 六聚体（认 $\mathrm{RNA}$ 上的 $\mathrm{C}$，解旋酶 $+\mathrm{ATP}$）；多数靠茎环 $+$ 多聚 $\mathrm{U}$。原核转录翻译同步。
:::

:::memory{label="σ 和 ρ 谁管哪一头"}
$\sigma$：全酶的亚基，辨认起点，延长前脱落。$\rho$：另外的六聚体蛋白，只管部分基因的终止，结合 $\mathrm{RNA}$ 不结合那类 $\mathrm{dC}/\mathrm{dG}$ $\mathrm{DNA}$。二者都不是真核转录因子。
:::
