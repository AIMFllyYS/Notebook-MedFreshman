# 第一节　酶的分子结构与功能

本章打开酶与酶促反应。先把酶写成生物催化剂：降低活化能、加快反应速率、不改变平衡点；化学本质是蛋白质（核酶除外）。再落在分子结构：单体酶、寡聚酶、多酶复合物与多功能酶，单纯酶与缀合酶，辅酶／辅基和维生素，活性中心，同工酶以乳酸脱氢酶五型为标本。第二节写工作原理，第三节写酶促反应动力学。

生物体内的新陈代谢过程是通过有条不紊、连续不断的化学反应来体现的。这些化学反应如果在体外进行，通常需要在高温、高压、强酸、强碱等剧烈条件下才能发生。而生物体内这些反应是在极为温和的条件下就能高效、特异地进行，其原因是生物体内存在着一类极为重要的生物催化剂（biocatalyst）——酶。

:::definition{label="生物催化剂"}
生物催化剂（biocatalyst）是生物体内使化学反应能在极为温和的条件下高效、特异进行的一类分子。本节首先落到酶。
:::

:::definition{label="酶"}
酶（enzyme）是自然界存在的或人工合成的、具有催化特定化学反应的生物分子，如催化性的蛋白质和 $\mathrm{RNA}$ 等。酶能通过降低反应的活化能加快反应速度，但不改变反应的平衡点，具有催化效率高、专一性强、作用条件温和等特点。
:::

:::definition{label="酶学"}
酶学（enzymology）是研究酶的化学本质、结构、作用机制、分类、辅因子及酶促反应动力学的学科领域。
:::

酶学与医学的关系十分密切，人体的许多疾病与酶的异常密切相关，许多酶还被用于疾病的诊断和治疗。酶学研究不仅在医学领域具有重要意义，亦对科学实践、工农业生产实践影响深远。

:::tip{label="医学生为什么先把酶写成催化剂再写成蛋白质"}
教材先写“温和条件下高效、特异”，再写酶的定义、酶学的范围，最后才点医学：疾病与酶异常相关，酶可用于诊断和治疗。不要一上来就把酶听成“化验单上的那几个字母”，分子结构和动力学会没有户头。
:::

酶的化学本质是蛋白质（核酶除外）。由一条多肽链组成的酶称为单体酶（monomeric enzyme），如牛胰核糖核酸酶 $\mathrm{A}$、溶菌酶、羧肽酶 $\mathrm{A}$ 等。由多个相同或不同的亚基以非共价键连接组成的酶称为寡聚酶（oligomeric enzyme），如蛋白质激酶 $\mathrm{A}$、磷酸果糖激酶。此外，几种具有不同催化功能的酶可彼此聚合形成多酶复合物（multienzyme complex）或称多酶体系（multienzyme system），其催化底物反应的过程如同流水线，上一个酶的产物即成为下一个酶的底物，形成连锁反应，如哺乳类动物丙酮酸脱氢酶复合物含有 $3$ 种酶和 $5$ 种辅因子。还有在一条肽链上同时具有多种不同的催化功能及／或结合功能的酶称为多功能酶（multifunctional enzyme）或串联酶（tandem enzyme），如氨基甲酰磷酸合成酶Ⅱ、天冬氨酸氨基甲酰转移酶和二氢乳清酸酶。

:::definition{label="酶的化学本质"}
酶的化学本质是蛋白质（核酶除外）。核酶是催化性 $\mathrm{RNA}$，是对“生物催化剂都是蛋白质”的补充，不要把它算进本节的酶蛋白、辅因子账里。
:::

:::definition{label="单体酶"}
由一条多肽链组成的酶称为单体酶（monomeric enzyme），如牛胰核糖核酸酶 $\mathrm{A}$、溶菌酶、羧肽酶 $\mathrm{A}$ 等。
:::

:::definition{label="寡聚酶"}
由多个相同或不同的亚基以非共价键连接组成的酶称为寡聚酶（oligomeric enzyme），如蛋白质激酶 $\mathrm{A}$、磷酸果糖激酶。亚基之间不是共价串成一条链。
:::

:::definition{label="多酶复合物"}
几种具有不同催化功能的酶彼此聚合形成多酶复合物（multienzyme complex），亦称多酶体系（multienzyme system）。催化过程如同流水线：上一个酶的产物即成为下一个酶的底物，形成连锁反应。教材例：哺乳类动物丙酮酸脱氢酶复合物含有 $3$ 种酶和 $5$ 种辅因子。
:::

:::definition{label="多功能酶"}
在一条肽链上同时具有多种不同的催化功能及／或结合功能的酶称为多功能酶（multifunctional enzyme）或串联酶（tandem enzyme），如氨基甲酰磷酸合成酶Ⅱ、天冬氨酸氨基甲酰转移酶和二氢乳清酸酶。
:::

:::compare{title="单体酶、寡聚酶、多酶复合物、多功能酶"}
| 项目 | 单体酶 | 寡聚酶 | 多酶复合物（多酶体系） | 多功能酶（串联酶） |
|------|--------|--------|------------------------|--------------------|
| 分子怎么组织 | 一条多肽链 | 多个相同或不同亚基，非共价连接 | 几种不同催化功能的酶彼此聚合 | 一条肽链上同时有多种催化及／或结合功能 |
| 催化怎么走 | 一个活性中心做一件事 | 亚基协作，仍是同一种酶 | 流水线：上一酶的产物是下一酶的底物 | 多种功能写在同一条肽链上 |
| 教材例子 | 牛胰核糖核酸酶 $\mathrm{A}$、溶菌酶、羧肽酶 $\mathrm{A}$ | 蛋白质激酶 $\mathrm{A}$、磷酸果糖激酶 | 哺乳类丙酮酸脱氢酶复合物（$3$ 种酶、$5$ 种辅因子） | 氨基甲酰磷酸合成酶Ⅱ、天冬氨酸氨基甲酰转移酶、二氢乳清酸酶 |
| 不要听成 | 一定没有辅因子 | 亚基之间以肽键串成一条链 | 就是多功能酶 | 就是多酶复合物 |
:::

:::pitfall{label="多酶复合物不是多功能酶，寡聚酶也不是把几条肽键焊死"}
多酶复合物是几种酶聚合，流水线交接产物；多功能酶是一条肽链上写了多种功能。寡聚酶的亚基以非共价键相连。把丙酮酸脱氢酶复合物听成“一条肽链上的三个活性中心”，或把串联酶听成“几种酶聚在一起”，后面的调节和区室化都会对错组织层次。
:::

:::concept{term="先问是不是蛋白质，再问有几条链、几个活性中心、几种辅因子"}
看见“酶”，先不要从 $K_\mathrm{m}$ 起笔。化学本质是蛋白质（核酶除外）；一条链是单体酶，多亚基非共价是寡聚酶；几种酶聚合是多酶复合物；一条链多种功能是多功能酶。然后再问要不要辅因子、活性中心在哪里。把核酶漏掉，或把四种组织方式并成“都是蛋白质聚合”，分子组成那一节会没有台阶。
:::

## 一、酶的分子组成中常含有辅因子

酶按其分子组成可分为单纯酶和缀合酶。水解后仅有蛋白质的酶称为单纯酶（simple enzyme），如脲酶、某些蛋白酶、淀粉酶、脂酶、核酸酶等；缀合酶（conjugated enzyme）（亦称结合酶）是除了蛋白质部分外还含有非蛋白质部分的酶，其中蛋白质部分称为酶蛋白（apoenzyme），非蛋白质部分称为酶的辅因子（cofactor）。酶蛋白主要决定酶促反应的特异性及其催化机制；辅因子主要决定酶促反应的类型。酶蛋白与辅因子结合在一起的一种结合酶，或含有表达全部酶活性和调节活性所需的所有亚基的一种全寡聚酶称为全酶（holoenzyme），全酶的酶蛋白和辅因子单独存在时均无催化活性。

:::definition{label="单纯酶"}
水解后仅有蛋白质的酶称为单纯酶（simple enzyme），如脲酶、某些蛋白酶、淀粉酶、脂酶、核酸酶等。
:::

:::definition{label="缀合酶"}
缀合酶（conjugated enzyme）亦称结合酶，除蛋白质部分外还含有非蛋白质部分。蛋白质部分是酶蛋白（apoenzyme），非蛋白质部分是辅因子（cofactor）。
:::

:::definition{label="酶蛋白"}
酶蛋白（apoenzyme）是缀合酶的蛋白质部分。它主要决定酶促反应的特异性及其催化机制。单独存在时无催化活性。
:::

:::definition{label="辅因子"}
辅因子（cofactor）是缀合酶的非蛋白质部分，主要决定酶促反应的类型。单独存在时无催化活性。
:::

:::definition{label="全酶"}
酶蛋白与辅因子结合在一起的一种结合酶，或含有表达全部酶活性和调节活性所需的所有亚基的一种全寡聚酶，称为全酶（holoenzyme）。酶蛋白和辅因子单独存在时均无催化活性。
:::

:::compare{title="酶蛋白定专一性，辅因子定反应类型"}
| 项目 | 酶蛋白 | 辅因子 | 全酶 |
|------|--------|--------|------|
| 是什么 | 缀合酶的蛋白质部分 | 非蛋白质部分 | 二者结合，或含全部活性／调节亚基的全寡聚酶 |
| 主要决定 | 酶促反应的特异性及其催化机制 | 酶促反应的类型 | 完整催化活性 |
| 单独拿出来 | 无催化活性 | 无催化活性 | 才有活性 |
:::

:::pitfall{label="全酶拆开两边都没有活性，不要把辅因子听成“自己就能催化”"}
教材写明：酶蛋白和辅因子单独存在时均无催化活性。后面说辅酶“本身无催化作用、只传递电子／质子／基团”，正是从这里长出来的。把 $\mathrm{NAD}^{+}$ 听成“一种酶”，类型和专一性两本账会对调。
:::

辅因子按其与酶蛋白结合的紧密程度与作用特点不同可分为辅酶（coenzyme）和辅基（prosthetic group）。辅酶是与脱辅基酶结合的有机辅因子。这种结合比较疏松，可以用透析或超滤的方法除去。如辅酶Ⅰ和辅酶Ⅱ等。但在酶促反应中，辅酶本身无催化作用，一般在酶促反应中有传递电子、质子或某些功能基团等的作用。辅基则与酶蛋白形成共价键，结合较为紧密，不易通过透析或超滤将其除去。在酶促反应中，辅基不能离开酶蛋白。

:::definition{label="辅酶"}
辅酶（coenzyme）是与脱辅基酶结合的有机辅因子。结合比较疏松，可以用透析或超滤除去，如辅酶Ⅰ、辅酶Ⅱ。酶促反应中辅酶本身无催化作用，一般传递电子、质子或某些功能基团。
:::

:::definition{label="辅基"}
辅基（prosthetic group）与酶蛋白形成共价键，结合较为紧密，不易通过透析或超滤除去。在酶促反应中，辅基不能离开酶蛋白。
:::

:::compare{title="辅酶和辅基：松紧不同，能不能离开酶蛋白不同"}
| 项目 | 辅酶 | 辅基 |
|------|------|------|
| 英文 | coenzyme | prosthetic group |
| 结合 | 比较疏松 | 共价、较为紧密 |
| 透析／超滤 | 可以除去 | 不易除去 |
| 反应中 | 传递电子、质子或功能基团；本身无催化作用 | 不能离开酶蛋白 |
| 教材例子 | 辅酶Ⅰ、辅酶Ⅱ | 与酶蛋白共价相连的那一类有机辅因子 |
:::

:::concept{term="先问能不能透析掉，再问它传递的是氢还是酰基"}
看见“辅因子”，先不要直接背维生素表。先问结合松不松：能透析／超滤去掉的是辅酶，共价绑死、反应中不能离开的是辅基。然后再问它是有机分子还是金属离子、传递哪一种基团。把 $\mathrm{FAD}$ 和 $\mathrm{NAD}^{+}$ 都写成“都能透析掉”，黄素蛋白和脱氢酶的存在形式会对错。
:::

辅因子多为小分子的有机化合物或金属离子。作为辅因子的有机化合物多为 $\mathrm{B}$ 族维生素的衍生物或卟啉化合物，它们在酶促反应中主要参与传递电子、质子（或基团）或起运载体作用（表2-1）。

:::definition{label="有机辅因子多为 B 族维生素衍生物或卟啉"}
作为辅因子的有机化合物多为 $\mathrm{B}$ 族维生素的衍生物或卟啉化合物，主要参与传递电子、质子（或基团）或起运载体作用。
:::

金属酶（metalloenzyme）是以一个或几个金属离子作为辅因子的酶。金属离子是最常见的辅因子，可能直接参加催化作用或是对保持酶的活性构象起稳定作用，约 $2/3$ 的酶含有金属离子（表2-2）。金属离子作为酶的辅因子的主要作用是：①作为酶活性中心的组成部分参加催化反应，使底物与酶活性中心的必需基团形成正确的空间排列，有利于酶促反应的发生；②作为连接酶与底物的桥梁，形成三元复合物；③金属离子可以中和电荷，减小静电斥力，有利于底物与酶的结合；④金属离子与酶的结合可以稳定酶的空间构象。

:::definition{label="金属酶"}
金属酶（metalloenzyme）是以一个或几个金属离子作为辅因子的酶。金属离子可能直接参加催化，或对保持酶的活性构象起稳定作用。约 $2/3$ 的酶含有金属离子。
:::

:::keypoint{label="金属离子作为辅因子的四件事"}
- 作为活性中心组成部分参加催化，使底物与必需基团形成正确空间排列。
- 作为连接酶与底物的桥梁，形成三元复合物。
- 中和电荷，减小静电斥力，利于底物与酶结合。
- 与酶结合，稳定酶的空间构象。
:::

|------|--------|------------|
| 离子与酶 | 结合紧密，提取不易丢失 | 结合不牢固，纯化易丢失 |
| 要不要外加离子 | 提取后往往仍在酶上 | 需加入金属离子才有酶活性 |
| 教材例 | 过氧化氢酶（$\mathrm{Fe}^{2+}$）、碳酸酐酶（$\mathrm{Zn}^{2+}$）、羧基肽酶（$\mathrm{Zn}^{2+}$） | 丙酮酸激酶（$\mathrm{K}^{+}$、$\mathrm{Mg}^{2+}$）、己糖激酶（$\mathrm{Mg}^{2+}$）、脲酶（$\mathrm{Ni}^{2+}$） |
:::

有些酶可以同时含有多种不同类型的辅因子，如细胞色素氧化酶既含有血红素又含有 $\mathrm{Cu}^{+}/\mathrm{Cu}^{2+}$，琥珀酸脱氢酶同时含有 $\mathrm{Fe}^{2+}$ 和 $\mathrm{FAD}$。

:::example{label="一种酶可以同时有金属和有机辅因子"}
细胞色素氧化酶既含血红素又含 $\mathrm{Cu}^{+}/\mathrm{Cu}^{2+}$；琥珀酸脱氢酶同时含 $\mathrm{Fe}^{2+}$ 和 $\mathrm{FAD}$。表2-1 的有机辅因子和表2-2 的金属离子不是互斥的两本账。
:::

:::insight{label="辅因子不是“可有可无的小配角”"}
约 $2/3$ 的酶含金属离子；有机辅因子多为 $\mathrm{B}$ 族维生素衍生物或卟啉。酶蛋白定专一性，辅因子定反应类型，全酶才有活性。后面动力学里的抑制剂、激活剂，很多就是在这本辅因子账上动手。
:::

## 二、酶的活性中心是酶分子执行其催化功能的部位

酶分子中能与底物特异结合并催化底物转变为产物的区域称为酶的活性中心（active center）或活性部位（active site）（图2-1）。辅酶和辅基往往是酶活性中心的组成成分。酶分子中与酶活性密切相关的化学基团称为酶的必需基团（essential group）。常见的酶的必需基团有丝氨酸残基的羟基、组氨酸残基的咪唑基、半胱氨酸残基的巯基以及酸性氨基酸残基的羧基等。有些必需基团位于酶的活性中心内，有些必需基团位于酶的活性中心外。酶活性中心内的必需基团可有结合基团（binding group）和催化基团（catalytic group）之分。结合基团是识别底物并与之专一性结合，形成酶-底物复合物，决定酶专一性的基团；催化基团是负责催化底物中的某些化学键的断裂和形成新键，催化底物发生化学反应转变成产物的基团。酶活性中心外的必需基团虽然不直接参与催化作用，却为维持酶活性中心的空间构象和／或作为调节剂的结合部位所必需。

:::definition{label="活性中心"}
酶分子中能与底物特异结合并催化底物转变为产物的区域称为酶的活性中心（active center）或活性部位（active site）。辅酶和辅基往往是活性中心的组成成分。
:::

:::definition{label="必需基团"}
酶分子中与酶活性密切相关的化学基团称为必需基团（essential group）。常见的有丝氨酸残基的羟基、组氨酸残基的咪唑基、半胱氨酸残基的巯基以及酸性氨基酸残基的羧基等。有的在活性中心内，有的在活性中心外。
:::

:::definition{label="结合基团"}
结合基团（binding group）是活性中心内识别底物并与之专一性结合、形成酶-底物复合物、决定酶专一性的基团。
:::

:::definition{label="催化基团"}
催化基团（catalytic group）是活性中心内负责催化底物中某些化学键断裂、形成新键，使底物转变成产物的基团。
:::

:::definition{label="活性中心外的必需基团"}
活性中心外的必需基团不直接参与催化作用，却为维持酶活性中心的空间构象和／或作为调节剂的结合部位所必需。
:::

:::compare{title="活性中心内结合、催化；中心外维持构象或结合调节剂"}
| 基团位置 | 再分类 | 干什么 | 不干什么 |
|----------|--------|--------|----------|
| 活性中心内 | 结合基团 | 识别底物、专一性结合、形成 $\mathrm{ES}$，决定专一性 | 不一定自己去断键 |
| 活性中心内 | 催化基团 | 断旧键、成新键，把底物变成产物 | 不一定负责“认人” |
| 活性中心外 | 必需基团 | 维持活性中心空间构象；和／或作为调节剂结合部位 | 不直接催化 |
:::

:::note{label="图2-1 电子版缺失"}
教材图2-1 为酶的活性中心示意图：多肽链折叠成裂缝，标出底物分子、活性中心、活性中心内的结合基团与催化基团、活性中心外的必需基团。数字切片 `p0065_01.png`、`p0065_02.png` 为 $0$ 字节，本节不引用该文件。正文中结合基团、催化基团和中心外必需基团的划分仍按教材保留。

酶的活性中心具有三维结构，往往形成裂缝或凹陷。这些裂缝或凹陷由酶的特定空间构象所维持，深入到酶分子内部，且多由氨基酸残基的疏水基团组成，形成疏水“口袋”。例如，溶菌酶的活性中心是一裂隙结构，可以容纳 $6$ 个 $N$-乙酰氨基葡萄糖环（$\mathrm{A}$、$\mathrm{B}$、$\mathrm{C}$、$\mathrm{D}$、$\mathrm{E}$、$\mathrm{F}$）。溶菌酶的催化基团是 $35$ 位 $\mathrm{Glu}$ 和 $52$ 位 $\mathrm{Asp}$，催化 $\mathrm{D}$ 环的糖苷键断裂。$101$ 位 $\mathrm{Asp}$ 和 $108$ 位 $\mathrm{Trp}$ 是该酶的结合基团（图2-2）。

:::definition{label="活性中心的疏水口袋"}
活性中心具有三维结构，往往形成裂缝或凹陷，由特定空间构象维持，深入分子内部，多由疏水基团组成，形成疏水“口袋”。
:::

:::example{label="溶菌酶：裂隙容纳六糖，Glu35 和 Asp52 催化"}
溶菌酶催化肽多糖中糖苷键水解。活性中心是一裂隙，可容纳肽多糖的 $6$ 个 $N$-乙酰氨基葡萄糖环（$\mathrm{A}$、$\mathrm{B}$、$\mathrm{C}$、$\mathrm{D}$、$\mathrm{E}$、$\mathrm{F}$）。必需基团有 $\mathrm{Glu}35$、$\mathrm{Asp}52$、$\mathrm{Asp}101$ 和 $\mathrm{Trp}108$，其中前两个是催化基团，水解 $\mathrm{D}$、$\mathrm{E}$ 之间的糖苷键；$101$ 位 $\mathrm{Asp}$ 和 $108$ 位 $\mathrm{Trp}$ 是结合基团。
:::

:::note{label="图2-2 电子版缺失"}
教材图2-2 为溶菌酶的活性中心：裂隙内容纳 $\mathrm{A}$—$\mathrm{F}$ 六个单糖基，标出 $\mathrm{Glu}35$、$\mathrm{Asp}52$、$\mathrm{Asp}101$、$\mathrm{Trp}108$。数字切片 `p0065_01.png`、`p0065_02.png` 为 $0$ 字节，本节不引用这些文件。六个环的位置、催化基团水解 $\mathrm{D}$、$\mathrm{E}$ 之间糖苷键的正文仍按教材保留。

:::pitfall{label="必需基团不等于都在活性中心，活性中心内也不等于都去催化"}
必需基团有的在中心内、有的在中心外。中心内还要再分成结合基团和催化基团。把溶菌酶的 $\mathrm{Asp}101$、$\mathrm{Trp}108$ 写成催化残基，或把中心外必需基团听成“可有可无”，专一性和构象稳定两笔都会错位。
:::

:::cause-effect{title="疏水口袋怎样把催化做在分子内部"}
- **因** 裂缝或凹陷深入酶分子内部，多由疏水基团组成
- **果** 形成疏水“口袋”，底物在此被识别并结合；第二节的表面效应、去溶剂化要从这一笔长出来
:::

## 三、同工酶催化相同的化学反应

同工酶（isoenzyme）是指催化相同的化学反应，但酶蛋白的分子结构、理化性质和免疫学特性各不相同的一组酶。同工酶是一种酶具有的不同形式，存在于同一种属的不同个体、同一个体的不同组织、同一细胞的不同亚细胞结构或细胞的不同发育阶段。同工酶虽然在一级结构上存在差异，但其活性中心的三维结构相同或相似，故可以催化相同的化学反应。由同一基因转录的 $\mathrm{mRNA}$ 前体经过不同的剪接过程，生成的多种不同 $\mathrm{mRNA}$ 的翻译产物（一系列酶）也属于同工酶。

:::definition{label="同工酶"}
同工酶（isoenzyme）是催化相同的化学反应，但酶蛋白的分子结构、理化性质和免疫学特性各不相同的一组酶。它是一种酶的不同形式，可存在于同一种属的不同个体、同一个体的不同组织、同一细胞的不同亚细胞结构或细胞的不同发育阶段。
:::

:::definition{label="同工酶为什么能催化同一反应"}
同工酶虽然一级结构存在差异，但活性中心的三维结构相同或相似，故可以催化相同的化学反应。
:::

:::definition{label="剪接来的同工酶"}
由同一基因转录的 $\mathrm{mRNA}$ 前体经过不同剪接，生成多种不同 $\mathrm{mRNA}$ 的翻译产物（一系列酶），也属于同工酶。
:::

:::concept{term="先问催化的是不是同一反应，再问一级结构、组织和发育阶段差在哪里"}
看见“同工酶”，先不要写成“不同的酶碰巧做一件事”。教材口径是：同一化学反应，酶蛋白结构、理化性质、免疫学特性不同；活性中心三维相同或相似。来源可以是不同基因的亚基组合，也可以是同一基因的不同剪接。把 $\mathrm{LDH}_1$ 和 $\mathrm{LDH}_5$ 听成两种无关的脱氢酶，心肌谱和骨骼肌谱就对不上。
:::

动物的乳酸脱氢酶（lactate dehydrogenase，$\mathrm{LDH}$）是一种含锌的四聚体酶。$\mathrm{LDH}$ 由骨骼肌型（$\mathrm{M}$ 型）和心肌型（$\mathrm{H}$ 型）两种类型的亚基以不同的比例组成 $5$ 种同工酶，即 $\mathrm{LDH}_1$（$\mathrm{H}_4$）、$\mathrm{LDH}_2$（$\mathrm{H}_3\mathrm{M}$）、$\mathrm{LDH}_3$（$\mathrm{H}_2\mathrm{M}_2$）、$\mathrm{LDH}_4$（$\mathrm{HM}_3$）、$\mathrm{LDH}_5$（$\mathrm{M}_4$）（图2-3），它们均能催化 $\mathrm{L}$-乳酸与丙酮酸之间的氧化还原反应。

:::definition{label="乳酸脱氢酶同工酶"}
动物乳酸脱氢酶（lactate dehydrogenase，$\mathrm{LDH}$）是含锌的四聚体酶，由骨骼肌型（$\mathrm{M}$ 型）和心肌型（$\mathrm{H}$ 型）两种亚基按不同比例组成五种同工酶：$\mathrm{LDH}_1$（$\mathrm{H}_4$）、$\mathrm{LDH}_2$（$\mathrm{H}_3\mathrm{M}$）、$\mathrm{LDH}_3$（$\mathrm{H}_2\mathrm{M}_2$）、$\mathrm{LDH}_4$（$\mathrm{HM}_3$）、$\mathrm{LDH}_5$（$\mathrm{M}_4$）。五种均催化 $\mathrm{L}$-乳酸与丙酮酸之间的氧化还原反应。
:::

:::compare{title="LDH 五型：两个亚基，五种四聚体"}
| 同工酶 | 亚基组成 | 习惯称呼 | 催化的反应 |
|--------|----------|----------|------------|
| $\mathrm{LDH}_1$ | $\mathrm{H}_4$ | 心肌型为主 | $\mathrm{L}$-乳酸 $\rightleftharpoons$ 丙酮酸 |
| $\mathrm{LDH}_2$ | $\mathrm{H}_3\mathrm{M}$ | — | 同上 |
| $\mathrm{LDH}_3$ | $\mathrm{H}_2\mathrm{M}_2$ | — | 同上 |
| $\mathrm{LDH}_4$ | $\mathrm{HM}_3$ | — | 同上 |
| $\mathrm{LDH}_5$ | $\mathrm{M}_4$ | 骨骼肌型为主 | 同上 |
:::

在 $\mathrm{LDH}$ 的活性中心附近，两种亚基之间有极少数的氨基酸残基不同，如 $\mathrm{M}$ 型亚基的 $30$ 位为丙氨酸残基，$\mathrm{H}$ 亚基则为谷氨酰胺残基，且 $\mathrm{H}$ 亚基中的酸性氨基酸残基较多。这些微小差别引起 $\mathrm{LDH}$ 同工酶解离程度不同、分子表面电荷不同，在 $\mathrm{pH}\,8.6$ 的缓冲液中电泳的速率不同，自负极向正极泳动排列的次序为 $\mathrm{LDH}_5$、$\mathrm{LDH}_4$、$\mathrm{LDH}_3$、$\mathrm{LDH}_2$ 和 $\mathrm{LDH}_1$。两种亚基氨基酸序列和构象差异，表现出对底物的亲和力不同。如 $\mathrm{LDH}_1$ 对乳酸的亲和力较大（$K_\mathrm{m}=4.1\times 10^{-3}\,\mathrm{mol/L}$），而 $\mathrm{LDH}_5$ 对乳酸的亲和力较小（$K_\mathrm{m}=14.3\times 10^{-3}\,\mathrm{mol/L}$），这主要是由于 $\mathrm{H}$ 型亚基对乳酸的 $K_\mathrm{m}$ 小于 $\mathrm{M}$ 亚基的缘故。

:::definition{label="H 亚基和 M 亚基的微小差别"}
活性中心附近，两种亚基只有极少数氨基酸残基不同：$\mathrm{M}$ 型 $30$ 位为丙氨酸，$\mathrm{H}$ 亚基为谷氨酰胺；$\mathrm{H}$ 亚基中酸性氨基酸残基较多。差别引起解离程度、表面电荷不同，因而电泳行为和对底物的亲和力不同。
:::

:::keypoint{label="pH 8.6 电泳：自负极向正极是 LDH5 到 LDH1"}
- 缓冲液 $\mathrm{pH}\,8.6$。
- 自负极向正极：$\mathrm{LDH}_5$、$\mathrm{LDH}_4$、$\mathrm{LDH}_3$、$\mathrm{LDH}_2$、$\mathrm{LDH}_1$。
- $\mathrm{H}$ 亚基酸性残基较多，向正极泳动更快，所以 $\mathrm{H}_4$（$\mathrm{LDH}_1$）走在最前（正极侧）。
:::

:::pitfall{label="Km 大是亲和力小；LDH1 对乳酸的 Km 小于 LDH5"}
$\mathrm{LDH}_1$ 对乳酸 $K_\mathrm{m}=4.1\times 10^{-3}\,\mathrm{mol/L}$，亲和力较大；$\mathrm{LDH}_5$ 的 $K_\mathrm{m}=14.3\times 10^{-3}\,\mathrm{mol/L}$，亲和力较小。根子是 $\mathrm{H}$ 亚基对乳酸的 $K_\mathrm{m}$ 小于 $\mathrm{M}$ 亚基。把 $K_\mathrm{m}$ 听成“越大越亲”，第三节米氏常数的意义会先错一笔。第三节还要写清：只有 $k_3\ll k_2$ 时 $K_\mathrm{m}$ 才代表亲和力。
:::

当组织细胞存在病变时，该组织细胞特异的同工酶可释放入血。因此，临床上检测血清中同工酶活性、分析同工酶谱有助于疾病的诊断和预后判定。例如，肌酸激酶（creatine kinase，$\mathrm{CK}$）是由 $\mathrm{M}$ 型（肌型）和 $\mathrm{B}$ 型（脑型）亚基组成的二聚体酶。脑中含 $\mathrm{CK}_1$（$\mathrm{BB}$ 型），心肌中含 $\mathrm{CK}_2$（$\mathrm{MB}$ 型），骨骼肌中含 $\mathrm{CK}_3$（$\mathrm{MM}$ 型）。$\mathrm{CK}_2$ 仅见于心肌，且含量很高，约占人体 $\mathrm{CK}$ 总量的 $14\%\sim 42\%$。正常血液中的 $\mathrm{CK}$ 主要是 $\mathrm{CK}_3$，几乎不含 $\mathrm{CK}_2$；心肌梗死后 $3\sim 6$ 小时血中 $\mathrm{CK}_2$ 活性升高，$12\sim 24$ 小时达峰值（升高近 $6$ 倍），$3\sim 4$ 天恢复正常。因此，$\mathrm{CK}_2$ 常作为临床早期诊断心肌梗死的指标之一。

:::definition{label="肌酸激酶同工酶"}

:::

:::definition{label="CK2 与心肌梗死"}
$\mathrm{CK}_2$ 仅见于心肌，约占人体 $\mathrm{CK}$ 总量的 $14\%\sim 42\%$。正常血液中 $\mathrm{CK}$ 主要是 $\mathrm{CK}_3$，几乎不含 $\mathrm{CK}_2$。心肌梗死后 $3\sim 6$ 小时血中 $\mathrm{CK}_2$ 活性升高，$12\sim 24$ 小时达峰值（升高近 $6$ 倍），$3\sim 4$ 天恢复正常。故 $\mathrm{CK}_2$ 常作为临床早期诊断心肌梗死的指标之一。
:::

:::

:::cause-effect{title="组织坏死为什么能在血清里读到同工酶谱"}
- **因** 组织细胞病变时，该组织特异的同工酶可释放入血
- **果** 检测血清同工酶活性、分析同工酶谱，有助于疾病的诊断和预后判定
:::

:::timeline{period="心肌梗死后血清 CK2"}
- **正常** 血中 CK 主要是 CK3，几乎不含 CK2
- **梗死后 3～6 小时** 血中 CK2 活性升高
- **12～24 小时** 达峰值，升高近 6 倍
- **3～4 天** 恢复正常
- **临床用途** CK2 作为早期诊断心肌梗死的指标之一
:::

:::pitfall{label="CK2 只在心肌，不要把 CK3 升高写成心梗特有"}
$\mathrm{CK}_2$（$\mathrm{MB}$）仅见于心肌；正常血液几乎不含 $\mathrm{CK}_2$。骨骼肌里是 $\mathrm{CK}_3$（$\mathrm{MM}$）。把总 $\mathrm{CK}$ 升高或 $\mathrm{CK}_3$ 升高直接写成心梗，脑型和肌型那两本账会并成一句。
:::

:::memory{label="本节必背要点"}
- [ ] 酶是生物催化剂：降低活化能、加快反应速率、不改变平衡点；催化效率高、专一性强、作用条件温和。
- [ ] 酶的化学本质是蛋白质（核酶除外）。
- [ ] 单体酶一条肽链；寡聚酶多亚基非共价；多酶复合物是几种酶聚合的流水线；多功能酶（串联酶）是一条肽链多种功能。
- [ ] 单纯酶水解后只有蛋白质；缀合酶＝酶蛋白＋辅因子；二者单独均无活性，合在一起才是全酶。
- [ ] 酶蛋白决定特异性和催化机制，辅因子决定反应类型。
- [ ] 辅酶结合疏松、可透析／超滤除去，本身无催化作用，传递电子、质子或基团；辅基共价结合、反应中不能离开酶蛋白。
- [ ] 有机辅因子多为 $\mathrm{B}$ 族维生素衍生物或卟啉；表2-1 的基团与维生素要能对上。
- [ ] 约 $2/3$ 的酶含金属离子；金属酶结合紧，金属激活酶纯化易丢失、需外加离子才有活性。
- [ ] 活性中心是与底物特异结合并催化底物变产物的区域；辅酶／辅基常是其组成成分。
- [ ] 必需基团可在中心内或中心外；中心内分结合基团（专一性）和催化基团（断键成键）；中心外维持构象或结合调节剂。
- [ ] 溶菌酶：裂隙容纳 $6$ 个 $N$-乙酰氨基葡萄糖环；$\mathrm{Glu}35$、$\mathrm{Asp}52$ 催化 $\mathrm{D}$、$\mathrm{E}$ 之间糖苷键；$\mathrm{Asp}101$、$\mathrm{Trp}108$ 为结合基团。
- [ ] 同工酶催化同一反应，结构、理化、免疫学特性不同；活性中心三维相同或相似。
- [ ] $\mathrm{LDH}$ 含锌四聚体，五型 $\mathrm{H}_4$ 到 $\mathrm{M}_4$；$\mathrm{pH}\,8.6$ 自负极向正极为 $\mathrm{LDH}_5\to\mathrm{LDH}_1$；$\mathrm{LDH}_1$ 对乳酸 $K_\mathrm{m}$ 较小。
- [ ] 心肌 $\mathrm{LDH}_1$ 为主，骨骼肌／肝 $\mathrm{LDH}_5$ 为主；$\mathrm{CK}_2$（$\mathrm{MB}$）用于早期诊断心肌梗死。
:::
