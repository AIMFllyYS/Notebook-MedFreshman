# 第一节　营养必需氨基酸与氨基酸代谢概述

本章打开氨基酸代谢。氨基酸是蛋白质的基本组成单位，组织蛋白质先分解成氨基酸再往下走，所以氨基酸代谢是蛋白质分解代谢的中心内容。本节先把营养账摊开：氮平衡、九种营养必需氨基酸、食物蛋白质的互补作用；再写外源蛋白质在胃和小肠被切成寡肽与氨基酸、七种转运蛋白主动吸收，以及结肠下段的腐败和假神经递质。内源性蛋白质走溶酶体或泛素–蛋白酶体，外源与内源氨基酸合成氨基酸代谢库。脱氨基和尿素循环交给第二节、第三节。

氨基酸是蛋白质的基本组成单位，其重要生理功能之一是作为原料参与细胞内蛋白质的合成。体内的蛋白质处于不断合成与分解的动态平衡。组织蛋白质首先分解成为氨基酸，然后再进一步代谢，所以氨基酸代谢是蛋白质分解代谢的中心内容。氨基酸代谢包括合成代谢和分解代谢两方面，本章重点论述分解代谢。体内蛋白质的更新与氨基酸的分解均需要食物蛋白质来补充。为此，在讨论氨基酸代谢之前，首先叙述蛋白质的营养价值及蛋白质的消化、吸收问题。

看见“氨基酸代谢”，先不要跳到尿素循环。户头是：蛋白质不断更新，更新和分解都要食物蛋白质来补。补得够不够看氮平衡；补的蛋白质好不好看九种营养必需氨基酸的种类和比例。外源蛋白质在消化道切成寡肽和氨基酸后进代谢库；内源蛋白质在溶酶体或蛋白酶体拆开。氨基怎么脱、氨怎么排，是第二节、第三节的账。

教材开章就写：氨基酸代谢有合成也有分解，本章重点论述分解代谢。营养非必需氨基酸可以在体内合成，本节只把它写成“不必由食物供给”；碳骨架怎么再氨基化，放到第二节 $\alpha$-酮酸那一本账。不要在本节补一套细菌才有的必需氨基酸合成途径。
:::

## 一、蛋白质具有营养价值

### （一）蛋白质的需要量可用氮平衡描述

氮平衡（nitrogen balance）是指每日氮的摄入量与排出量之间的代谢状态。摄入氮基本上来源于食物中的蛋白质，经机体消化吸收后主要用于体内蛋白质的合成；排出氮主要来自粪便和尿液中的含氮化合物，绝大部分是蛋白质在体内分解代谢的终产物。由于蛋白质的平均含氮量为 $16\%$，通过测定摄入食物中的含氮量和排泄物中的含氮量可以间接了解体内蛋白质合成与分解代谢的状况。人体氮平衡有三种情况，即氮的总平衡、氮的正平衡及氮的负平衡。

:::definition{label="氮平衡"}
氮平衡（nitrogen balance）是每日氮的摄入量与排出量之间的代谢状态。摄入氮基本上来源于食物蛋白质；排出氮主要来自粪便和尿液中的含氮化合物，绝大部分是蛋白质分解代谢的终产物。蛋白质平均含氮量 $16\%$，测摄入氮和排出氮可间接反映体内蛋白质合成与分解。
:::

:::insight{label="测的是氮，读的是蛋白质合成与分解"}
直接称“体内蛋白质克数”做不到，但蛋白质平均含氮 $16\%$。摄入氮对上合成原料，排出氮对上分解终产物。氮的“收支”平衡，就是蛋白质合成与分解的动态平衡。把氮平衡听成“血尿素一项化验”，户头会缩到肝排氨，而不是整日蛋白质更新。
:::

氮的总平衡，即摄入氮量等于排出氮量，反映体内蛋白质的合成与分解处于动态平衡，即氮的“收支”平衡，通常见于正常成人；氮的正平衡，即摄入氮量大于排出氮量，反映体内蛋白质的合成大于分解，儿童、孕妇及恢复期的病人属于此种情况；氮的负平衡，即摄入氮量小于排出氮量，反映体内蛋白质的合成小于分解，见于饥饿、严重烧伤、出血及消耗性疾病的病人。

:::definition{label="氮的总平衡"}
摄入氮量等于排出氮量。反映体内蛋白质合成与分解处于动态平衡，通常见于正常成人。
:::

:::definition{label="氮的正平衡"}
摄入氮量大于排出氮量。反映体内蛋白质合成大于分解。儿童、孕妇及恢复期的病人属于此种情况。
:::

:::definition{label="氮的负平衡"}
摄入氮量小于排出氮量。反映体内蛋白质合成小于分解。见于饥饿、严重烧伤、出血及消耗性疾病的病人。
:::

:::compare{title="三种氮平衡不要记反谁大谁小"}
| 类型 | 摄入氮与排出氮 | 蛋白质合成与分解 | 教材点名 |
|------|----------------|-------------------|----------|
| 总平衡 | 摄入 $=$ 排出 | 合成与分解动态平衡 | 正常成人 |
| 正平衡 | 摄入 $>$ 排出 | 合成 $>$ 分解 | 儿童、孕妇、恢复期病人 |
| 负平衡 | 摄入 $<$ 排出 | 合成 $<$ 分解 | 饥饿、严重烧伤、出血、消耗性疾病 |
:::

:::pitfall{label="正平衡不是“营养过剩”，负平衡不是“吃素”"}
正平衡的户头是合成大于分解：生长发育、妊娠、病后修复都要净存氮。负平衡的户头是分解大于合成：饥饿、烧伤、出血、消耗性疾病。素食只要必需氨基酸种类和比例够、总量够，仍可总平衡；反过来，热量不够或创伤分解亢进，即使吃肉也可以负平衡。
:::

根据氮平衡实验计算，当正常成人食用不含蛋白质膳食约 $8$ 天后，每天的排出氮量逐渐趋于恒定。此时，每千克体重每天排出的氮量约为 $53\,\mathrm{mg}$，故一位 $60\,\mathrm{kg}$ 体重的正常成人每天蛋白质的最低分解量约为 $20\,\mathrm{g}$。由于食物蛋白质与人体蛋白质组成的差异，消化吸收后不可能全部被利用，因此，为了维持氮的总平衡，正常成人每天蛋白质的最低生理需要量为 $30\sim 50\,\mathrm{g}$。要长期保持氮的总平衡，我国营养学会推荐正常成人每天蛋白质的需要量为 $80\,\mathrm{g}$。

:::definition{label="蛋白质最低分解量与最低生理需要量"}
不含蛋白质膳食约 $8$ 天后，排出氮趋于恒定：约 $53\,\mathrm{mg}$ 氮／千克体重／天。$60\,\mathrm{kg}$ 成人每天蛋白质最低分解量约 $20\,\mathrm{g}$。因食物蛋白质不可能全部被利用，维持总平衡的最低生理需要量为 $30\sim 50\,\mathrm{g}$。我国营养学会推荐正常成人每天 $80\,\mathrm{g}$。
:::

:::keypoint{label="20 g、30～50 g、80 g 三本账不要并户"}
- $20\,\mathrm{g}$：内源蛋白质最低分解量（按 $53\,\mathrm{mg}$ 氮／千克，$\times 60\,\mathrm{kg}$，再按含氮 $16\%$ 折算）。
- $30\sim 50\,\mathrm{g}$：为维持氮的总平衡，每天蛋白质的最低生理需要量。
- $80\,\mathrm{g}$：要长期保持总平衡，我国营养学会的推荐量。
:::

:::pitfall{label="最低分解量不是推荐摄入量"}
$20\,\mathrm{g}$ 是“不吃蛋白质时身体仍在拆多少”，不是“每天吃 $20\,\mathrm{g}$ 就够”。食物蛋白质与人体组成有差异，吸收后也不能全部利用，所以生理需要量抬到 $30\sim 50\,\mathrm{g}$，推荐量再抬到 $80\,\mathrm{g}$。把三笔都记成 $80\,\mathrm{g}$，氮平衡实验那一页就没有了。
:::

### （二）营养必需氨基酸决定蛋白质的营养价值

氮平衡实验证明，人体内有 $9$ 种氨基酸不能合成。这些体内需要而不能自身合成、必须由食物提供的氨基酸，在营养学上称为必需氨基酸（essential amino acid），包括亮氨酸、异亮氨酸、苏氨酸、缬氨酸、赖氨酸、甲硫氨酸、苯丙氨酸、色氨酸和组氨酸。其余 $11$ 种氨基酸体内可以合成，不必由食物供给，在营养学上称为非必需氨基酸（non essential amino acid）。精氨酸虽然能够在人体内合成，但合成量不多，若长期供应不足或需要量增加也可造成负氮平衡。因此，有人将精氨酸归为营养半必需氨基酸。

:::definition{label="营养必需氨基酸"}
必需氨基酸（essential amino acid）是体内需要而不能自身合成、必须由食物提供的氨基酸。本版名单为 $9$ 种：亮氨酸、异亮氨酸、苏氨酸、缬氨酸、赖氨酸、甲硫氨酸、苯丙氨酸、色氨酸和组氨酸。
:::

:::definition{label="营养非必需氨基酸"}
非必需氨基酸（non essential amino acid）是体内可以合成、不必由食物供给的氨基酸。本版为其余 $11$ 种。
:::

:::definition{label="营养半必需氨基酸"}
精氨酸虽能在人体内合成，但合成量不多，长期供应不足或需要量增加也可造成负氮平衡。有人将精氨酸归为营养半必需氨基酸。
:::

:::memory{label="九种营养必需氨基酸"}
亮氨酸、异亮氨酸、苏氨酸、缬氨酸、赖氨酸、甲硫氨酸、苯丙氨酸、色氨酸、组氨酸。本版是 $9$ 种，组氨酸在名单内。不要用只写八种、不写组氨酸的旧口诀替换。
:::

:::pitfall{label="非必需不是“不需要”，半必需不是第十种必需"}
非必需的户头是“体内能合成、不必由食物供给”，不是生理上可有可无。精氨酸仍算能合成的那 $11$ 种里的一员；“有人归为半必需”是因为合成量不够应付长期缺乏或需要量增加，不要把它加成第 $10$ 种必需氨基酸，把九种名单改掉。
:::

:::compare{title="必需、非必需、半必需怎么分户"}
| 项目 | 必需氨基酸 | 非必需氨基酸 | 半必需（有人这样归） |
|------|------------|--------------|----------------------|
| 能否自身合成 | 不能，必须由食物提供 | 能，不必由食物供给 | 能合成，但量不多 |
| 本版成员 | $9$ 种：亮、异亮、苏、缬、赖、甲硫、苯丙、色、组 | 其余 $11$ 种 | 精氨酸 |
| 营养学后果 | 缺哪一种，食物蛋白质利用率就受限制 | 碳骨架可来自糖代谢等，第二节再写氨基化 | 长期供应不足或需要量增加可造成负氮平衡 |
:::

蛋白质的营养价值（nutrition value）是指食物蛋白质在体内的利用率。蛋白质营养价值的高低主要取决于食物蛋白质中必需氨基酸的种类和比例。一般来说，含必需氨基酸种类多、比例高的蛋白质，其营养价值高，反之营养价值低。由于动物性蛋白质所含必需氨基酸的种类和比例与人体需要相近，故营养价值相对较高。多种营养价值较低的蛋白质混合食用，彼此间必需氨基酸可以得到互相补充，从而提高蛋白质的营养价值，这种作用称为食物蛋白质的互补作用。例如谷类蛋白质含赖氨酸较少含色氨酸较多，而豆类蛋白质含赖氨酸较多含色氨酸较少，将两者混合食用即可提高蛋白质的营养价值。在某些疾病情况下，为保证病人氨基酸的需要，可输入氨基酸混合液，以防止病情恶化。

:::definition{label="蛋白质的营养价值"}
蛋白质的营养价值（nutrition value）是食物蛋白质在体内的利用率。高低主要取决于食物蛋白质中必需氨基酸的种类和比例：种类多、比例高则营养价值高。
:::

:::definition{label="食物蛋白质的互补作用"}
多种营养价值较低的蛋白质混合食用，彼此间必需氨基酸互相补充，从而提高蛋白质营养价值，称为食物蛋白质的互补作用。教材例子：谷类赖氨酸较少、色氨酸较多；豆类赖氨酸较多、色氨酸较少，混合食用即可提高营养价值。
:::

:::insight{label="营养价值看的是九种必需氨基酸的种类和比例，不是“动物蛋白天生高级”"}
动物性蛋白质营养价值相对较高，原因写在“种类和比例与人体需要相近”，不是“动物来源”四个字本身。谷类和豆类单独都有短板，混在一起把赖氨酸、色氨酸互相补上，营养价值就能抬上去。疾病时输入氨基酸混合液，户头同样是把种类和比例补齐。
:::

:::example{label="谷类加豆类：互补的是赖氨酸和色氨酸"}
谷类：赖氨酸较少、色氨酸较多。豆类：赖氨酸较多、色氨酸较少。两样混吃，短的那一种被对方补上，利用率提高。不要记成“豆类补的是蛋氨酸”或另造教材没点名的氨基酸。
:::

## 二、外源性蛋白质消化成寡肽和氨基酸后被吸收

食物蛋白质的消化、吸收是体内氨基酸的主要来源。同时，消化过程还可消除食物蛋白质的抗原性，避免引起机体的过敏和毒性反应。食物蛋白质的消化由胃开始，但主要在小肠进行。

:::definition{label="外源性蛋白质消化的意义"}
消化、吸收是体内氨基酸的主要来源；同时消除食物蛋白质的抗原性，避免过敏和毒性反应。消化由胃开始，主要在小肠进行。
:::

:::pitfall{label="消化主场在小肠，不是在胃里一次切成游离氨基酸"}
胃停留时间短，对蛋白质的消化很不完全。胃蛋白酶只把食物蛋白质水解成多肽及少量氨基酸；约 $1/3$ 氨基酸、$2/3$ 寡肽要到胰液和肠黏膜酶原激活之后才收尾。把“蛋白质消化”听成“胃酸把蛋白质变成二十种氨基酸”，酶原级联和七种转运蛋白都没有户头。
:::

### （一）蛋白质在胃和小肠被消化成寡肽和氨基酸

**1. 蛋白质在胃中被水解成多肽和氨基酸**　食物蛋白质进入胃后经胃蛋白酶（pepsin）作用水解生成多肽及少量氨基酸。胃蛋白酶原（pepsinogen）由胃黏膜主细胞分泌，经盐酸激活后转变成为有活性的胃蛋白酶。胃蛋白酶也能激活胃蛋白酶原转变成胃蛋白酶，称为自身催化作用（autocatalysis）。胃蛋白酶的最适 $\mathrm{pH}$ 为 $1.5\sim 2.5$。酸性的胃液可使蛋白质变性，有利于蛋白质的水解。胃蛋白酶对肽键的特异性较差，主要水解由芳香族氨基酸、甲硫氨酸和亮氨酸等氨基酸残基形成的肽键。胃蛋白酶还具有凝乳作用，可使乳汁中的酪蛋白（casein）与 $\mathrm{Ca}^{2+}$ 形成乳凝块，使乳汁在胃中的停留时间延长，有利于乳汁中蛋白质的消化。

:::definition{label="胃蛋白酶原与胃蛋白酶"}
胃蛋白酶原（pepsinogen）由胃黏膜主细胞分泌，经盐酸激活成为胃蛋白酶（pepsin）。胃蛋白酶水解食物蛋白质，生成多肽及少量氨基酸。最适 $\mathrm{pH}$ $1.5\sim 2.5$。
:::

:::definition{label="自身催化作用"}
胃蛋白酶也能激活胃蛋白酶原转变成胃蛋白酶，称为自身催化作用（autocatalysis）。盐酸启动之后，酶可以自己扩大激活。
:::

:::definition{label="胃蛋白酶的凝乳作用"}
胃蛋白酶可使乳汁中的酪蛋白（casein）与 $\mathrm{Ca}^{2+}$ 形成乳凝块，延长乳汁在胃中的停留时间，有利于乳汁中蛋白质的消化。
:::

:::keypoint{label="胃蛋白酶这一笔要同时记住四件事"}
- 主细胞分泌酶原，盐酸激活；随后自身催化。
- 最适 $\mathrm{pH}$ $1.5\sim 2.5$；酸性胃液使蛋白质变性，利于水解。
- 肽键特异性较差，主要切芳香族氨基酸、甲硫氨酸、亮氨酸等残基形成的肽键。
- 凝乳：酪蛋白 $+\mathrm{Ca}^{2+}$ → 乳凝块。
:::

**2. 蛋白质在小肠被水解成寡肽和氨基酸**　食物在胃中的停留时间较短，因此对蛋白质的消化很不完全。蛋白质的消化主要在小肠进行。在小肠中，未经消化或消化不完全的蛋白质受胰液及肠黏膜细胞分泌的多种蛋白酶及肽酶的共同作用，进一步水解成寡肽和氨基酸。

小肠内发挥作用的蛋白酶基本上分为两大类，即内肽酶（endopeptidase）和外肽酶（exopeptidase）。内肽酶可以特异地水解蛋白质内部的一些肽键，而外肽酶则特异地水解蛋白质或多肽末端的肽键。内肽酶包括胰蛋白酶（trypsin）、胰凝乳蛋白酶（chymotrypsin）和弹性蛋白酶（elastase），这些酶对不同氨基酸残基组成的肽键有一定的专一性。胰蛋白酶水解由碱性氨基酸残基组成的肽键，胰凝乳蛋白酶水解由芳香族氨基酸残基组成的肽键，而弹性蛋白酶主要水解由脂肪族氨基酸残基组成的肽键。外肽酶主要包括羧肽酶和氨肽酶。胰液中的外肽酶主要是羧肽酶，又可分为羧肽酶 $\mathrm{A}$（carboxyl peptidase $\mathrm{A}$）和羧肽酶 $\mathrm{B}$（carboxyl peptidase $\mathrm{B}$），它们自肽链的羧基末端开始，每次水解脱去一个氨基酸。羧肽酶 $\mathrm{A}$ 和羧肽酶 $\mathrm{B}$ 对不同氨基酸残基组成的肽键也有一定的专一性，前者主要水解除脯氨酸、精氨酸、赖氨酸以外的多种氨基酸残基组成的末端肽键，而后者主要水解由碱性氨基酸残基组成的末端肽键（图9-1）。

:::definition{label="内肽酶"}
内肽酶（endopeptidase）特异水解蛋白质内部的一些肽键。小肠内的内肽酶包括胰蛋白酶、胰凝乳蛋白酶（糜蛋白酶）和弹性蛋白酶。
:::

:::definition{label="外肽酶"}
外肽酶（exopeptidase）特异水解蛋白质或多肽末端的肽键。主要包括羧肽酶和氨肽酶。胰液中的外肽酶主要是羧肽酶。
:::

:::definition{label="胰蛋白酶、胰凝乳蛋白酶与弹性蛋白酶"}
三者都是内肽酶，肽键专一性不同：胰蛋白酶（trypsin）切碱性氨基酸残基组成的肽键；胰凝乳蛋白酶（chymotrypsin，又称糜蛋白酶）切芳香族氨基酸残基组成的肽键；弹性蛋白酶（elastase）主要切脂肪族氨基酸残基组成的肽键。
:::

:::definition{label="羧肽酶 A 与羧肽酶 B"}
羧肽酶自肽链羧基末端开始，每次水解脱去一个氨基酸。羧肽酶 $\mathrm{A}$ 主要水解除脯氨酸、精氨酸、赖氨酸以外的多种氨基酸残基组成的末端肽键；羧肽酶 $\mathrm{B}$ 主要水解由碱性氨基酸残基组成的末端肽键。
:::

:::compare{title="小肠蛋白酶按切点和专一性认人"}
| 酶 | 内／外 | 切哪里 | 专一性（本版） |
|----|--------|--------|----------------|
| 胰蛋白酶 | 内肽酶 | 蛋白质内部 | 碱性氨基酸残基组成的肽键 |
| 胰凝乳蛋白酶（糜蛋白酶） | 内肽酶 | 蛋白质内部 | 芳香族氨基酸残基组成的肽键 |
| 弹性蛋白酶 | 内肽酶 | 蛋白质内部 | 主要是脂肪族氨基酸残基组成的肽键 |
| 羧肽酶 $\mathrm{A}$ | 外肽酶 | 羧基末端，一次一个 | 除脯氨酸、精氨酸、赖氨酸以外的多种末端残基 |
| 羧肽酶 $\mathrm{B}$ | 外肽酶 | 羧基末端，一次一个 | 碱性氨基酸残基组成的末端肽键 |
| 氨肽酶 | 外肽酶 | 氨基末端 | 肠黏膜细胞内切寡肽，直至二肽 |
:::

:::pitfall{label="羧肽酶 A 不切脯、精、赖；碱性末端交给羧肽酶 B"}
碱性残基在链内由胰蛋白酶切，在羧基末端由羧肽酶 $\mathrm{B}$ 切。羧肽酶 $\mathrm{A}$ 明确排除脯氨酸、精氨酸、赖氨酸。把 $\mathrm{A}$/$\mathrm{B}$ 记成“$\mathrm{A}$ 切中性、$\mathrm{B}$ 切一切末端”，碱性残基会并户。
:::

::figure{src="/images/biochemistry/textbook/p0201_01.png" caption="图9-1　蛋白酶作用示意图。肽链氨基端由氨肽酶切，内部肽键由内肽酶切，羧基端由羧肽酶切；内肽酶产物中的二肽再由二肽酶水解为氨基酸。" alt="肽链示意：左侧 H2N 端标氨肽酶，中段内部肽键标内肽酶，右侧 COOH 端标羧肽酶；下方内肽酶产物为氨基酸加二肽，二肽由二肽酶切成氨基酸"}

内肽酶和羧肽酶都是以酶原的形式由胰腺细胞分泌，进入十二指肠后被激活。胰蛋白酶原由肠激酶（enterokinase）激活。肠激酶是十二指肠黏膜细胞分泌的一种蛋白水解酶，能特异地作用于胰蛋白酶原，从其氨基末端水解掉 $1$ 分子的六肽，生成有活性的胰蛋白酶。然后胰蛋白酶又将胰凝乳蛋白酶原（又称为糜蛋白酶原）、弹性蛋白酶原和羧肽酶原激活。胰蛋白酶的自身激活作用较弱（图9-2）。由于胰液中各种蛋白酶均以酶原的形式存在，同时胰液中又存在胰蛋白酶抑制剂，可以保护胰腺组织免受蛋白酶的自身消化。

:::definition{label="肠激酶"}
肠激酶（enterokinase）是十二指肠黏膜细胞分泌的蛋白水解酶，特异作用于胰蛋白酶原：从其氨基末端水解掉 $1$ 分子六肽，生成有活性的胰蛋白酶。
:::

:::definition{label="胰液蛋白酶原的激活级联"}
胰腺细胞分泌内肽酶和羧肽酶的酶原，入十二指肠后被激活。肠激酶激活胰蛋白酶原；胰蛋白酶再激活胰凝乳蛋白酶原（糜蛋白酶原）、弹性蛋白酶原和羧肽酶原。胰蛋白酶自身激活作用较弱。
:::

:::definition{label="胰蛋白酶抑制剂"}
胰液中存在胰蛋白酶抑制剂，与酶原形式一起，保护胰腺组织免受蛋白酶的自身消化。
:::

:::timeline{period="胰液蛋白酶原在十二指肠的激活顺序"}
- **肠激酶** 十二指肠黏膜分泌，切胰蛋白酶原氨基末端的一分子六肽
- **胰蛋白酶** 级联的枢纽：激活糜蛋白酶原、弹性蛋白酶原、羧肽酶原（A 或 B）
- **自身激活** 胰蛋白酶也能激活胰蛋白酶原，但作用较弱
- **抑制剂** 胰液中的胰蛋白酶抑制剂，防止胰腺被自己的蛋白酶消化
:::

:::insight{label="级联的钥匙在肠激酶，不在胰蛋白酶自己"}
胰蛋白酶原在胰腺里已经做好，但不能在腺泡里打开。十二指肠黏膜的肠激酶切掉氨基末端六肽，钥匙才转。之后胰蛋白酶去开糜蛋白酶、弹性蛋白酶、羧肽酶。自身激活写明“较弱”，所以启动步不能改记成“胰蛋白酶原自己激活自己”。
:::

:::pitfall{label="胃蛋白酶原和胰蛋白酶原的第一把钥匙不是同一种"}
胃蛋白酶原的第一激活剂是盐酸，随后自身催化。胰蛋白酶原的第一激活剂是肠激酶，随后胰蛋白酶再去激活其他酶原。不要把“酶原激活”一律写成自身催化。
:::

::figure{src="/images/biochemistry/textbook/p0202_01.png" caption="图9-2　胰液中各种蛋白酶原的激活过程。肠激酶激活胰蛋白酶原成为胰蛋白酶；胰蛋白酶再激活糜蛋白酶原、弹性蛋白酶原和羧肽酶原（A 或 B）；胰蛋白酶对胰蛋白酶原的自身激活较弱。" alt="流程图：顶部胰蛋白酶原，肠激酶从旁切入，向下生成胰蛋白酶并有较弱自身反馈；胰蛋白酶向下分别激活糜蛋白酶原、羧肽酶原（A或B）、弹性蛋白酶原"}

蛋白质经胃液和胰液中蛋白酶的消化，产物中约有 $1/3$ 为氨基酸，其余 $2/3$ 为寡肽。寡肽的水解主要在小肠黏膜细胞内进行。小肠黏膜细胞内存在两种寡肽酶（oligopeptidase），即氨肽酶（aminopeptidase）和二肽酶（dipeptidase）。氨肽酶从氨基末端逐步水解寡肽获得氨基酸，直至生成二肽，二肽再经二肽酶水解，最终生成氨基酸。

:::definition{label="寡肽酶"}
寡肽酶（oligopeptidase）在小肠黏膜细胞内水解寡肽。两种：氨肽酶（aminopeptidase）从氨基末端逐步水解，直至生成二肽；二肽酶（dipeptidase）把二肽水解为氨基酸。
:::

:::keypoint{label="胃加胰液之后，仍有三分之二是寡肽"}
- 胃液 $+$ 胰液蛋白酶：约 $1/3$ 氨基酸，$2/3$ 寡肽。
- 寡肽主场改到小肠黏膜细胞内：氨肽酶 → 二肽 → 二肽酶 → 氨基酸。
- 图9-1 把氨肽酶、内肽酶、羧肽酶、二肽酶画在同一条肽链上，切点不要对调。
:::

### （二）氨基酸和寡肽通过主动转运机制被吸收

食物蛋白质被消化成氨基酸和寡肽后，主要在小肠通过主动转运机制被吸收。小肠黏膜细胞膜上存在转运氨基酸和寡肽的载体蛋白（carrier protein），能与氨基酸或寡肽以及 $\mathrm{Na}^{+}$ 形成三联体，将氨基酸或寡肽和 $\mathrm{Na}^{+}$ 转运入细胞，之后 $\mathrm{Na}^{+}$ 借助钠泵被排出细胞外，此过程需要消耗 $\mathrm{ATP}$。由于氨基酸结构的差异，转运氨基酸或寡肽的载体蛋白也不相同。目前已知体内至少有 $7$ 种载体蛋白参与氨基酸和寡肽的吸收。这些载体蛋白又被称为转运蛋白（transporter），包括中性氨基酸转运蛋白、酸性氨基酸转运蛋白、碱性氨基酸转运蛋白、亚氨基酸转运蛋白、$\beta$-氨基酸转运蛋白、二肽转运蛋白及三肽转运蛋白。当某些氨基酸共用同一载体时，由于在结构上有一定的相似性，这些氨基酸在吸收过程中将彼此竞争。氨基酸通过转运蛋白的吸收过程不仅存在于小肠黏膜细胞，也存在于肾小管细胞和肌细胞等细胞膜上。

:::definition{label="氨基酸和寡肽的主动转运"}
消化产物主要在小肠经主动转运吸收。载体蛋白与氨基酸或寡肽以及 $\mathrm{Na}^{+}$ 形成三联体，同向转入细胞；$\mathrm{Na}^{+}$ 再由钠泵排出，消耗 $\mathrm{ATP}$。
:::

:::definition{label="七种氨基酸与寡肽转运蛋白"}
体内至少有 $7$ 种载体蛋白（转运蛋白，transporter）参与吸收：中性氨基酸转运蛋白、酸性氨基酸转运蛋白、碱性氨基酸转运蛋白、亚氨基酸转运蛋白、$\beta$-氨基酸转运蛋白、二肽转运蛋白及三肽转运蛋白。
:::

:::keypoint{label="七种转运蛋白按底物分户"}
- 氨基酸侧：中性、酸性、碱性、亚氨基酸、$\beta$-氨基酸。
- 寡肽侧：二肽转运蛋白、三肽转运蛋白。
- 共用同一载体的氨基酸因结构相似而彼此竞争。
- 同一套主动转运也出现在肾小管细胞和肌细胞等细胞膜上，不只小肠。
:::

:::insight{label="三联体里有钠，钠泵把钠打出去，这一笔才耗 ATP"}
载体本身是把氨基酸（或寡肽）和 $\mathrm{Na}^{+}$ 一起拖进细胞；耗能发生在随后钠泵把 $\mathrm{Na}^{+}$ 泵出。不要写成“载体直接水解 $\mathrm{ATP}$ 夹一个氨基酸”。糖吸收那一笔 $\mathrm{SGLT}$ 也是伴钠、耗能，户头相似，但本章名单是氨基酸／寡肽的七种转运蛋白，不要改挂 $\mathrm{SGLT}$。
:::

:::pitfall{label="二肽、三肽可以整段进黏膜，不是必须先在肠腔切成氨基酸"}
七种名单里明确有二肽转运蛋白和三肽转运蛋白。寡肽的彻底水解主要在黏膜细胞内由氨肽酶、二肽酶完成。把吸收听成“肠腔里必须全部变成游离氨基酸才能进细胞”，和 $2/3$ 寡肽那一笔会对不上。
:::

## 三、未消化吸收的蛋白质在结肠下段发生腐败

食物中的蛋白质绝大部分都被彻底消化并吸收。未被消化的蛋白质及未被吸收的消化产物在结肠下部受到肠道细菌的分解，称为蛋白质的腐败作用（putrefaction）。实际上，腐败作用是肠道细菌本身的代谢过程，以无氧分解为主。腐败作用的某些产物对人体具有一定的营养作用，如维生素及脂肪酸等。但大多数产物对人体是有害的，例如胺类（amine）、氨（ammonia）、酚类（phenol）、吲哚（indole）及硫化氢等。生成的腐败产物主要随粪便排出体外，也有少量经门静脉吸收进入体内，大多在肝经过生物转化作用后排出体外。

:::definition{label="蛋白质的腐败作用"}
蛋白质的腐败作用（putrefaction）是未被消化的蛋白质及未被吸收的消化产物，在结肠下部受肠道细菌分解。它是肠道细菌本身的代谢过程，以无氧分解为主。
:::

:::compare{title="腐败产物不全是毒物"}
| 对人体 | 教材点名 |
|--------|----------|
| 有一定营养作用 | 维生素、脂肪酸等 |
| 大多数有害 | 胺类、氨、酚类、吲哚、硫化氢等 |
| 去路 | 主要随粪便排出；少量经门静脉入体内，大多在肝生物转化后排出 |
:::

### （一）肠道细菌通过脱羧基作用产生胺类

未被消化的蛋白质经肠道细菌蛋白酶的作用可水解生成氨基酸，然后在细菌氨基酸脱羧酶的作用下，氨基酸脱去羧基生成胺类物质。例如组氨酸、赖氨酸、色氨酸、酪氨酸及苯丙氨酸通过脱羧基作用分别生成组胺、尸胺、色胺、酪胺及苯乙胺。这些腐败产物大多具有毒性，如组胺和尸胺具有降低血压的作用，酪胺具有升高血压的作用。这些毒性物质如果经门静脉进入体内，通常经肝代谢转化为无毒形式排出体外。但在肝功能受损时，酪胺和苯乙胺不能在肝内及时转化，极易进入脑组织，经 $\beta$-羟化酶作用，分别转化为 $\beta$-羟酪胺和苯乙醇胺。因其结构类似于儿茶酚胺，故被称为假神经递质（false neurotransmitter）。假神经递质增多时，可竞争性地干扰儿茶酚胺的正常功能，阻碍神经冲动传递，使大脑发生异常抑制，这可能是肝性脑病发生的原因之一。

:::definition{label="细菌脱羧产胺"}
肠道细菌的氨基酸脱羧酶使氨基酸脱去羧基生成胺类。本版对应：组氨酸 → 组胺，赖氨酸 → 尸胺，色氨酸 → 色胺，酪氨酸 → 酪胺，苯丙氨酸 → 苯乙胺。
:::

:::definition{label="假神经递质"}
肝功能受损时，酪胺和苯乙胺不能在肝内及时转化，进入脑组织后经 $\beta$-羟化酶分别变为 $\beta$-羟酪胺和苯乙醇胺。二者结构类似于儿茶酚胺，称为假神经递质（false neurotransmitter）。增多时可竞争性抑制儿茶酚胺，阻碍神经冲动传递，使大脑异常抑制，可能是肝性脑病发生的原因之一。
:::

:::compare{title="五种脱羧产物不要对错氨基酸"}
| 氨基酸 | 胺 | 教材点到的作用 |
|--------|----|----------------|
| 组氨酸 | 组胺 | 降低血压 |
| 赖氨酸 | 尸胺 | 降低血压 |
| 色氨酸 | 色胺 | 有害胺类之一 |
| 酪氨酸 | 酪胺 | 升高血压；肝损时可变成 $\beta$-羟酪胺 |
| 苯丙氨酸 | 苯乙胺 | 肝损时可变成苯乙醇胺 |
:::

:::cause-effect{title="肝功能受损时假神经递质为什么能抑制大脑"}
- **因** 酪胺、苯乙胺未经肝及时转化，入脑后被 $\beta$-羟化酶变成 $\beta$-羟酪胺、苯乙醇胺，结构像儿茶酚胺
- **果** 竞争性抑制真递质，神经冲动传递受阻，大脑异常抑制，可能参与肝性脑病
:::

:::pitfall{label="假神经递质的前体是酪胺和苯乙胺，不是组胺和尸胺"}
组胺、尸胺的毒性写在降血压；酪胺写在升血压。能变成假神经递质的是酪胺 → $\beta$-羟酪胺、苯乙胺 → 苯乙醇胺。不要把五种胺都写成肝性脑病的递质替代物。
:::

### （二）肠道细菌通过脱氨基作用产生氨

未被吸收的氨基酸在肠道细菌的作用下，通过脱氨基作用可以生成氨，这是肠道氨的重要来源之一。另一来源是血液中的尿素渗入肠道，经肠菌尿素酶的水解而生成氨。这些氨均可被吸收进入血液，最终在肝中合成尿素。降低肠道的 $\mathrm{pH}$，可减少氨的吸收。

:::definition{label="肠道氨的两个来源"}
其一：未被吸收的氨基酸经肠菌脱氨基生成氨。其二：血液中的尿素渗入肠道，经肠菌尿素酶水解生成氨。两路氨都可吸收入血，最终在肝合成尿素。
:::

:::insight{label="肠道偏酸则少吸收氨"}
降低肠道 $\mathrm{pH}$ 可减少氨的吸收。第三节还把这一笔写成：碱性环境中 $\mathrm{NH}_4^{+}$ 易变成 $\mathrm{NH}_3$，$\mathrm{NH}_3$ 更易穿过细胞膜。本节先记下“降 $\mathrm{pH}$、少吸收”，临床灌肠用酸不用碱的理由在后面展开。
:::

### （三）腐败作用产生其他有害物质

除了胺类和氨以外，蛋白质的腐败作用还可产生其他有害物质，例如苯酚、吲哚、甲基吲哚及硫化氢等。正常情况下，上述有害物质大部分随粪便排出，只有小部分被吸收，并经肝的代谢转变消除毒性，故不会发生中毒现象。

:::definition{label="腐败产生的其他有害物质"}
除胺类和氨外，还可产生苯酚、吲哚、甲基吲哚及硫化氢等。正常时大部分随粪便排出，小部分经肝解毒，不发生中毒。
:::

:::pitfall{label="腐败不是“大肠的正常消化”"}
消化吸收的主场在胃和小肠；腐败是结肠下段细菌自己的无氧代谢。维生素、脂肪酸可以顺便有营养作用，但不能把腐败写成人体蛋白质消化的第四步。
:::

## 四、氨基酸的来源与去路

### （一）按照来源氨基酸分为外源性氨基酸和内源性氨基酸

**1. 外源性氨基酸**　外源性氨基酸即食物中蛋白质经消化、吸收的氨基酸。食物蛋白质在消化道经多种酶的催化，最终水解为各种氨基酸，由小肠吸收进入体内，构成人体氨基酸的主要来源。氨基酸的吸收主要在小肠进行。关于吸收机制，目前尚未完全阐明，一般认为它主要是一个耗能的主动吸收过程。

:::definition{label="外源性氨基酸"}
外源性氨基酸是食物蛋白质经消化、吸收进入体内的氨基酸，构成人体氨基酸的主要来源。吸收主要在小肠，主要为耗能的主动吸收。
:::

**2. 内源性氨基酸**　体内组织蛋白质降解产生的氨基酸及体内合成的非必需氨基酸属于内源性氨基酸。

体内蛋白质分解生成氨基酸：成人体内的蛋白质每天约有 $1\%\sim 2\%$ 被降解，其中主要是骨骼肌中的蛋白质。蛋白质降解所产生的氨基酸，大约 $70\%\sim 80\%$ 又被重新利用合成新的蛋白质。

:::definition{label="内源性氨基酸"}
内源性氨基酸包括体内组织蛋白质降解产生的氨基酸，以及体内合成的非必需氨基酸。
:::

:::keypoint{label="成人蛋白质每天拆 1%～2%，拆下来的大部分还要装回去"}
- 每天约 $1\%\sim 2\%$ 的体蛋白被降解，主要是骨骼肌蛋白质。
- 降解产生的氨基酸约 $70\%\sim 80\%$ 再用于合成新蛋白质。
- 外源氨基酸补的是净消耗和不能自身合成的那九种。
:::

**（1）蛋白质以不同的速率进行降解**　不同蛋白质的降解速率不同。蛋白质的降解速率是随生理需要而不断变化的，若以高的平均速率降解，标志着该组织正在进行主要结构的重建，例如妊娠中的子宫组织或严重饥饿造成的骨骼肌蛋白质的降解。蛋白质降解的速率用半衰期（half-life，$t_{1/2}$）表示，半衰期是指将其浓度减少到开始值 $50\%$ 所需要的时间。肝中蛋白质的 $t_{1/2}$ 短的低于 $30$ 分钟，长的超过 $150$ 小时，但肝中大部分蛋白质的 $t_{1/2}$ 为 $1\sim 8$ 天。人血浆蛋白质的 $t_{1/2}$ 约为 $10$ 天，结缔组织中一些蛋白质的 $t_{1/2}$ 可达 $180$ 天以上，眼晶体蛋白质的 $t_{1/2}$ 更长。体内许多关键酶的 $t_{1/2}$ 都很短，例如胆固醇合成关键酶 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶的 $t_{1/2}$ 为 $0.5\sim 2$ 小时。为了满足生理需要，关键酶的降解既可加速亦可滞后，从而改变酶的含量，进一步改变代谢产物的流量和浓度。

:::definition{label="蛋白质半衰期"}
蛋白质降解速率用半衰期（half-life，$t_{1/2}$）表示：将其浓度减少到开始值 $50\%$ 所需的时间。降解速率随生理需要变化；高平均速率标志着该组织正在进行主要结构重建，如妊娠子宫或严重饥饿时的骨骼肌。
:::

:::compare{title="本版点名的半衰期（不要换成别的版本的数字）"}
| 蛋白质 | $t_{1/2}$（教材） |
|--------|------------------|
| 肝中蛋白质 | 短的低于 $30$ 分钟，长的超过 $150$ 小时；大部分为 $1\sim 8$ 天 |
| 人血浆蛋白质 | 约 $10$ 天 |
| 结缔组织中一些蛋白质 | 可达 $180$ 天以上 |
| 眼晶体蛋白质 | 更长 |
| $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶 | $0.5\sim 2$ 小时（关键酶短寿命的例子） |
:::

:::insight{label="关键酶短寿命，是为了能靠降解快慢改流量"}
$\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶 $t_{1/2}$ 只有 $0.5\sim 2$ 小时。降解加速或滞后，酶含量跟着变，代谢产物的流量和浓度就能调。长寿命的晶体蛋白、结缔组织蛋白不走这条“快调开关”。
:::

**（2）真核细胞内蛋白质的降解有两条重要途径**　细胞内蛋白质的降解也是通过一系列蛋白酶和肽酶催化完成的。蛋白质首先被蛋白酶水解成肽，然后肽被肽酶降解成游离氨基酸。

① **蛋白质在溶酶体通过 $\mathrm{ATP}$ 非依赖途径被降解**　溶酶体的主要功能是消化作用，是细胞内的消化器官。溶酶体含有多种蛋白酶，称为组织蛋白酶（cathepsin）。这些蛋白酶能够降解进入溶酶体的蛋白质，但对蛋白质的选择性较差，主要降解细胞外来的蛋白质、膜蛋白和胞内长寿命蛋白质。蛋白质通过此途径降解，不需要消耗 $\mathrm{ATP}$。

:::definition{label="溶酶体蛋白质降解"}
溶酶体是细胞内的消化器官，含多种组织蛋白酶（cathepsin）。此途径不消耗 $\mathrm{ATP}$（$\mathrm{ATP}$ 非依赖），选择性较差，主要降解细胞外来的蛋白质、膜蛋白和胞内长寿命蛋白质。
:::

② **蛋白质在蛋白酶体通过 $\mathrm{ATP}$ 依赖途径被降解**　蛋白质通过此途径降解需泛素（ubiquitin）的参与。泛素是一种由 $76$ 个氨基酸组成的小分子蛋白质，因其广泛存在于真核细胞而得名。泛素介导的蛋白质降解过程是一个复杂的过程。首先泛素与被选择降解的蛋白质形成共价连接，使后者得以标记，然后蛋白酶体（proteasome）将其降解。泛素的这种标记作用称为泛素化（ubiquitination），是由三种酶参与的催化反应完成的，同时需消耗 $\mathrm{ATP}$（图9-3）。一种蛋白质的降解需多次泛素化反应，形成泛素链（ubiquitin chain）。然后，泛素化的蛋白质在蛋白酶体降解，产生一些约 $7\sim 9$ 个氨基酸残基组成的肽链，肽链进一步经寡肽酶水解生成氨基酸。

:::definition{label="泛素"}
泛素（ubiquitin）是由 $76$ 个氨基酸组成的小分子蛋白质，因广泛存在于真核细胞而得名。
:::

:::definition{label="泛素化"}
泛素化（ubiquitination）是泛素与被选择降解的蛋白质形成共价连接、将其标记的过程。由三种酶催化，同时消耗 $\mathrm{ATP}$。一种蛋白质需多次泛素化，形成泛素链（ubiquitin chain）。
:::

:::definition{label="泛素化的三种酶"}
$\mathrm{E}_1$ 泛素激活酶：在 $\mathrm{ATP}$ 参与下，泛素羧基与 $\mathrm{E}_1$ 的巯基形成硫酯（$\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$ 放出）。$\mathrm{E}_2$ 泛素结合酶：泛素从 $\mathrm{E}_1$ 转到 $\mathrm{E}_2$ 的巯基。$\mathrm{E}_3$ 泛素蛋白连接酶：把泛素转到被降解蛋白质（$\mathrm{Pr}$）上，形成酰胺连接。图9-3 的缩写：$\mathrm{UB}$ 泛素，$\mathrm{Pr}$ 被降解蛋白质。
:::

:::timeline{period="ATP 依赖的泛素–蛋白酶体降解"}
- **标记** 泛素经 E1、E2、E3 接到待降解蛋白质上，多次连接成泛素链，消耗 ATP
- **降解** 蛋白酶体把泛素化蛋白质切成约 7～9 个氨基酸残基的肽
- **收尾** 肽再经寡肽酶水解生成氨基酸；泛素释放后再利用
:::

::figure{src="/images/biochemistry/textbook/p0204_01.png" caption="图9-3　蛋白质降解的泛素化过程。UB：泛素；E1：泛素激活酶；E2：泛素结合酶；E3：泛素蛋白连接酶；Pr：被降解蛋白质。第一步 ATP → AMP+PPi，UB 与 E1 成硫酯；第二步转到 E2；第三步在 E3 催化下以酰胺键接到 Pr。" alt="三步反应式：UB羧基与E1巯基在ATP参与下成硫酯并放出AMP和PPi；硫酯转到E2；E3把UB以酰胺键连到底物蛋白质Pr"}

蛋白酶体存在于细胞核和胞质内，主要降解异常蛋白质和短寿命蛋白质。蛋白酶体是一个 $26\mathrm{S}$ 的蛋白质复合物（图9-4），由 $20\mathrm{S}$ 的核心颗粒（core particle，$\mathrm{CP}$）和 $19\mathrm{S}$ 的调节颗粒（regulatory particle，$\mathrm{RP}$）组成。$\mathrm{CP}$ 是由 $2$ 个 $\alpha$ 环和 $2$ 个 $\beta$ 环组成的圆柱体，$2$ 个 $\alpha$ 环分别位于圆柱体的上下两端，而 $2$ 个 $\beta$ 环则夹在 $2$ 个 $\alpha$ 环之间。每个 $\alpha$ 环由 $7$ 个 $\alpha$ 亚基组成，而每个 $\beta$ 环由 $7$ 个 $\beta$ 亚基组成，$\mathrm{CP}$ 中心形成空腔。$\mathrm{CP}$ 是蛋白酶体的水解核心，活性位点位于 $2$ 个 $\beta$ 环上，每个 $\beta$ 环的 $7$ 个 $\beta$ 亚基中有 $3$ 个亚基具有蛋白酶活性，可催化不同的蛋白质降解。$2$ 个 $19\mathrm{S}$ 的 $\mathrm{RP}$ 分别位于柱形核心颗粒的两端，形成空心圆柱的盖子。每个 $\mathrm{RP}$ 都由 $18$ 个亚基组成，其中某些亚基能够识别、结合待降解的泛素化蛋白质，有 $6$ 个亚基具有 $\mathrm{ATP}$ 酶活性，与蛋白质的去折叠以及使蛋白质定位于 $\mathrm{CP}$ 有关。

:::definition{label="蛋白酶体"}
蛋白酶体（proteasome）存在于细胞核和胞质内，主要降解异常蛋白质和短寿命蛋白质。$26\mathrm{S}$ 复合物由 $20\mathrm{S}$ 核心颗粒（$\mathrm{CP}$）和 $19\mathrm{S}$ 调节颗粒（$\mathrm{RP}$）组成。
:::

:::definition{label="20S 核心颗粒"}
$\mathrm{CP}$ 是 $2$ 个 $\alpha$ 环加 $2$ 个 $\beta$ 环的圆柱体：$\alpha$ 环在上下两端，$\beta$ 环夹在中间。每个 $\alpha$ 环 $7$ 个 $\alpha$ 亚基，每个 $\beta$ 环 $7$ 个 $\beta$ 亚基，中心为空腔。水解活性位点在 $\beta$ 环：每个 $\beta$ 环 $7$ 个亚基中有 $3$ 个具有蛋白酶活性。
:::

:::definition{label="19S 调节颗粒"}
两个 $19\mathrm{S}$ 的 $\mathrm{RP}$ 盖在 $\mathrm{CP}$ 两端。每个 $\mathrm{RP}$ 由 $18$ 个亚基组成：某些亚基识别、结合待降解的泛素化蛋白质；$6$ 个亚基有 $\mathrm{ATP}$ 酶活性，负责蛋白质去折叠并使其定位于 $\mathrm{CP}$。
:::

:::compare{title="溶酶体途径和蛋白酶体途径不要并户"}
| 项目 | 溶酶体（$\mathrm{ATP}$ 非依赖） | 蛋白酶体（$\mathrm{ATP}$ 依赖） |
|------|--------------------------------|--------------------------------|
| 标记 | 无泛素化 | 需泛素化，形成泛素链 |
| 能量 | 不消耗 $\mathrm{ATP}$ | 泛素化消耗 $\mathrm{ATP}$；$\mathrm{RP}$ 的 $\mathrm{ATP}$ 酶还用于去折叠和定位 |
| 选择性 | 较差 | 选择被泛素标记的蛋白质 |
| 主要底物 | 细胞外来的蛋白质、膜蛋白、胞内长寿命蛋白质 | 异常蛋白质、短寿命蛋白质 |
| 产物 | 蛋白酶切成肽，再经肽酶成氨基酸 | 约 $7\sim 9$ 残基肽，再经寡肽酶成氨基酸 |
:::

:::pitfall{label="26S 不是 26 个亚基；20S 也不是 20 个亚基"}
$26\mathrm{S}$、$20\mathrm{S}$、$19\mathrm{S}$ 是沉降系数。$\mathrm{CP}$ 的环是 $7+7+7+7$ 个亚基；每个 $\mathrm{RP}$ 是 $18$ 个亚基。把 $26\mathrm{S}$ 听成“二十六聚体”，环的数目会对不上。
:::

**3. 外源性氨基酸与内源性氨基酸组成氨基酸代谢库**　体内组织蛋白质降解产生的氨基酸及体内合成的非必需氨基酸属于内源性氨基酸，与食物蛋白质经消化吸收的氨基酸（外源性氨基酸）共同分布于体内各处，参与代谢，称为氨基酸代谢库（amino acid metabolic pool）。氨基酸代谢库通常以游离氨基酸总量计算。由于氨基酸不能自由通过细胞膜，所以在体内的分布是不均一的。骨骼肌中的氨基酸占总代谢库的 $50\%$ 以上，肝约占 $10\%$，肾约占 $4\%$，血浆占 $1\%\sim 6\%$。

:::definition{label="氨基酸代谢库"}
氨基酸代谢库（amino acid metabolic pool）是内源性氨基酸与外源性氨基酸共同分布于体内各处、参与代谢的游离氨基酸总体。通常以游离氨基酸总量计算。氨基酸不能自由通过细胞膜，分布不均一。
:::

:::compare{title="代谢库的分布（本版）"}
| 部位 | 占总代谢库 |
|------|------------|
| 骨骼肌 | $50\%$ 以上 |
| 肝 | 约 $10\%$ |
| 肾 | 约 $4\%$ |
| 血浆 | $1\%\sim 6\%$ |
:::

:::pitfall{label="血浆氨基酸不是代谢库的大头"}
血浆只占 $1\%\sim 6\%$。骨骼肌占一半以上，肝约一成。化验看到的是血浆那一薄层，不要把它听成“全身游离氨基酸都在血里”。
:::

### （二）组织细胞中氨基酸具有不同的代谢去路

体内氨基酸的主要功能是合成多肽和蛋白质，也可转变成其他含氮化合物。由于各种氨基酸具有共同的基本结构，因此分解代谢途径有相同之处；但各种氨基酸在侧链结构上存在一定的差异，又导致了各自独特的代谢方式。大多数氨基酸主要在肝中进行分解代谢，有些氨基酸如支链氨基酸则主要在骨骼肌中进行。

:::insight{label="共同结构走一般代谢，侧链不同走个别代谢"}
$\alpha$-氨基和 $\alpha$-羧基是大家共有的，脱氨基、$\alpha$-酮酸去路是第二节的一般代谢。侧链不同，个别氨基酸另有独特方式，那是后面几节的账。大多数在肝分解，支链氨基酸主要在骨骼肌分解，两本账不要并到“全部在肝”。
:::

**1. 合成蛋白质或多肽**　这是氨基酸最主要的生理功能。各组织细胞摄取的氨基酸除合成它们的结构蛋白质，满足其蛋白质的更新、修复及细胞生长增殖的需要外，有些组织细胞还合成某些分泌性蛋白质或多肽，如肝细胞合成血浆清蛋白、胰腺分泌各种消化酶、胰岛 $\beta$ 细胞分泌胰岛素等。

:::definition{label="氨基酸合成蛋白质或多肽"}
合成蛋白质或多肽是氨基酸最主要的生理功能：结构蛋白质的更新、修复和细胞生长增殖；以及分泌性蛋白质或多肽，如肝细胞的血浆清蛋白、胰腺的消化酶、胰岛 $\beta$ 细胞的胰岛素。
:::

**2. 转变为其他含氮的生理活性物质**　从数量上看，虽然不是氨基酸的主要代谢去路，其代谢转变过程也不是氨基酸代谢普遍性方式。但是，这些含氮化合物只有氨基酸可以生成，而且具有特殊的生物学活性。例如：核酸的重要组成成分嘌呤和嘧啶；肌肉中储能物质肌酸；重要的信使物质 $\mathrm{NO}$ 等均可由氨基酸转变而成。

:::definition{label="氨基酸转变为其他含氮化合物"}
数量上不是主要去路，也不是普遍方式，但这些含氮化合物只有氨基酸可以生成。教材点名：嘌呤、嘧啶，肌酸，$\mathrm{NO}$。
:::

**3. 氧化分解或转变为糖和脂肪**　氨基酸经脱氨基后的碳骨架 $\alpha$-酮酸，可转变成糖或脂肪或进一步氧化分解，供给能量。成人每天约有 $1/5$ 的能量由氨基酸分解提供。正常情况下，人类活动所需能量主要由糖和脂肪提供，因此氨基酸氧化分解所产生的能量不占主要地位。

:::definition{label="氨基酸氧化分解供能"}
脱氨基后的 $\alpha$-酮酸可转变成糖或脂肪，或彻底氧化供能。成人每天约 $1/5$ 的能量来自氨基酸分解；正常时主能源仍是糖和脂肪，氨基酸供能不占主要地位。
:::

:::pitfall{label="五分之一供能，不等于氨基酸是主能源"}
教材同时写了两句：成人每天约 $1/5$ 能量来自氨基酸分解；正常活动所需能量主要由糖和脂肪提供。不要只记 $1/5$ 就说“氨基酸是三大供能物质里排第一”。碳骨架怎么生糖、生酮，第二节表9-2 再分户。
:::
