# 第三节　蛋白质合成后的加工和靶向输送

第二节把肽链写成起始、延长、终止，并在同一条 $\mathrm{mRNA}$ 上挂上 $10\sim 100$ 个核糖体。本节换账：刚离开核糖体的新生肽链还没有生物活性。先靠分子伴侣和异构酶折出三维结构，再按需要切末端、切内部、改侧链、聚亚基；有活性之后，还要按一级结构里的分拣信号送到细胞质、细胞器、质膜或细胞外。Hsp70、GroEL/GroES、POMC 的七个水解位点、信号肽三段式、分泌通路六步和核定位序列是本版要钉死的事实。

:::concept{term="先问有没有活性，再问要不要切、要不要改、最后问送到哪里"}
看见“翻译后”，不要先背抗生素。户头是：新生肽链不等于成熟蛋白质。折叠（分子伴侣、PDI、PPI）→ 水解（N- 端甲硫氨酸／信号肽／前体／POMC）→ 侧链修饰（表16-4）→ 亚基聚合（血红蛋白 $\alpha_2\beta_2$）→ 靶向输送（表16-5 的五种信号）。送错地方和折错构象，都还不是“合成失败”，而是本节的账。
:::

电子版第三节页首仍印着释放因子 $\mathrm{RF}1$／$\mathrm{RF}2$／$\mathrm{RF}3$／$\mathrm{eRF}$、肽酰转移酶转变为酯酶。那段属于第二节终止，本节不再展开。多聚核糖体印在同一页，本版接到本节开头，避免图16-9 从两节之间掉出去。图16-15 核蛋白靶向原印在第四节页首，已移回本节（六）（五）。

无论原核还是真核，一条 $\mathrm{mRNA}$ 模板上都可以附着 $10\sim 100$ 个核糖体。这些核糖体依次结合起始密码子，沿 $\mathrm{mRNA}$ 的 $5'\rightarrow 3'$ 方向移动，同时各做同一条肽链的合成。多个核糖体结合在一条 $\mathrm{mRNA}$ 上所形成的聚合物称为多聚核糖体（polyribosome 或 polysome）。多聚核糖体让肽链合成高速度、高效率进行（图16-9）。原核生物转录和翻译紧密偶联：转录尚未完成，已有核糖体结合于 $\mathrm{mRNA}$ 的 $5'$ 端开始翻译。真核生物转录在细胞核、翻译在细胞质，两个过程分隔进行。

:::definition{label="多聚核糖体"}
多聚核糖体（polyribosome 或 polysome）：多个核糖体结合在一条 $\mathrm{mRNA}$ 上形成的聚合物。一条模板可挂 $10\sim 100$ 个核糖体；它们依次认起始密码子，沿 $5'\rightarrow 3'$ 移动，同时合成同一条肽链。意义：高速度、高效率。
:::

:::definition{label="原核偶联，真核分隔"}
原核：转录未完成即可在 $\mathrm{mRNA}$ 的 $5'$ 端开始翻译。真核：转录在核、翻译在细胞质，两个过程分隔。第十五章羽毛状图形是原核同步的电镜像，不要搬进真核核内。
:::

:::pitfall{label="10～100 个核糖体不是 10～100 种蛋白质"}
挂的是同一条 $\mathrm{mRNA}$，读的是同一套密码子，产物是同一条肽链的多个拷贝。把多聚核糖体答成“一条 $\mathrm{mRNA}$ 编码几十种蛋白质”，和第一节可读框会对不上。
:::

新生肽链并不具有生物活性。它们必须正确折叠，形成具有生物活性的三维空间结构；有的还需形成二硫键，有的需通过亚基聚合形成具有四级结构的蛋白质。此外，许多蛋白质在翻译后还要经过水解作用切除一些肽段或氨基酸，或对某些氨基酸残基的侧链基团进行化学修饰，才能成为有活性的成熟蛋白质。这一过程称为翻译后加工（post-translational processing）。

蛋白质合成后还需要被输送到合适的亚细胞部位才能行使各自的生物学功能。有的驻留于细胞质，有的被运输到细胞器或镶嵌入细胞膜，还有的被分泌到细胞外。蛋白质合成后在细胞内被定向输送到其发挥作用部位的过程称为蛋白质靶向输送（protein targeting）或蛋白质分选（protein sorting）。

:::definition{label="翻译后加工"}
翻译后加工（post-translational processing）：新生肽链成为有活性成熟蛋白质所经历的折叠、二硫键形成、亚基聚合、水解切除肽段或氨基酸、侧链化学修饰等过程。新生肽链本身没有生物活性。
:::

:::definition{label="蛋白质靶向输送（蛋白质分选）"}
蛋白质靶向输送（protein targeting）又称蛋白质分选（protein sorting）：合成后在细胞内被定向输送到发挥作用部位。去向包括细胞质驻留、进入细胞器、镶嵌细胞膜、分泌到细胞外。
:::

:::keypoint{label="加工和分选是两本账，常常叠在一起做"}
- 加工：有没有活性（构象、切、改、聚）。
- 分选：在不在对的地方（信号序列）。
- 分泌蛋白质：合成与靶向输送同时发生，信号肽边合成边被 $\mathrm{SRP}$ 抓走。
- 核蛋白、多数线粒体蛋白质：从核糖体释放后才开始输送。
:::

:::pitfall{label="离开核糖体不等于已经成熟"}
终止节释放的是新生肽链。活性要等本节的折叠、水解、修饰、聚合。把“肽链释放”答成“蛋白质已经有功能”，胰岛素原、胰蛋白酶原、血红蛋白 $\alpha\beta$ 二聚体都没有户头。
:::

## 一、新生肽链折叠需要分子伴侣

蛋白质在合成时，尚未折叠的肽段有许多疏水基团暴露在外，具有分子内或分子间聚集的倾向，使蛋白质不能形成正确空间构象。这种结构混乱的肽链聚集体产生过多，会对细胞有致命影响。实际上，细胞中大多数天然蛋白质折叠并不是自发完成的，其折叠过程需要其他酶或蛋白质的辅助。这些辅助性蛋白质可以指导新生肽链按特定方式正确折叠，它们被称为分子伴侣（molecular chaperone）。

:::definition{label="分子伴侣"}
分子伴侣（molecular chaperone）：指导新生肽链按特定方式正确折叠的辅助性蛋白质。细胞中大多数天然蛋白质折叠不是自发完成的。
:::

:::cause-effect{title="为什么新生肽链容易聚成一团"}
- **因** 尚未折叠的肽段疏水基团暴露在外，分子内或分子间都有聚集倾向
- **果** 不能形成正确空间构象；结构混乱的聚集体过多可致命，必须有分子伴侣把疏水区暂时捂住
:::

:::pitfall{label="分子伴侣不是把氨基酸连成肽的酶"}
成肽是第二节核糖体上的肽酰转移酶（核酶）。分子伴侣管折叠，不管肽键。写成“催化肽键形成的辅助蛋白”，户头错到延长循环。
:::

原核生物和真核生物都存在多种类型的分子伴侣。目前研究得较为清楚的是热激蛋白 $70$（heat shock protein $70$，$\mathrm{Hsp}70$）家族和伴侣蛋白（chaperonin）。

### （一）Hsp70 家族结合疏水区，靠 ATP 循环帮助折叠

$\mathrm{Hsp}70$ 因其分子量接近 $70\,\mathrm{kD}$ 而得名，高温刺激可诱导其合成。在蛋白质翻译后加工过程中，$\mathrm{Hsp}70$ 与未折叠蛋白质的疏水区结合，既可避免蛋白质因高温而变性，又可防止新生肽链过早折叠。$\mathrm{Hsp}70$ 也可以使一些跨膜蛋白质在转位至膜前保持非折叠状态。

有些 $\mathrm{Hsp}70$ 通过与多肽链结合、释放的循环过程，使多肽链发生正确折叠。这个过程需要 $\mathrm{ATP}$ 水解供能，并需要其他伴侣蛋白如 $\mathrm{Hsp}40$ 的共同作用。未折叠多肽链与 $\mathrm{Hsp}70$ 结合，还可以解开多肽链之间的聚集或防止新聚集的产生。多肽链从 $\mathrm{Hsp}70$ 释放后，可以重新折叠成天然构象。如果多肽链折叠不充分，上述过程可重复进行直至天然构象形成（图16-10）。

:::definition{label="Hsp70"}
热激蛋白 $70$（heat shock protein $70$，$\mathrm{Hsp}70$）：分子量接近 $70\,\mathrm{kD}$，高温刺激可诱导合成。结合未折叠蛋白质的疏水区：避免高温变性，防止新生肽链过早折叠，并使一些跨膜蛋白质在转位至膜前保持非折叠状态。
:::

:::definition{label="Hsp70 的结合–释放循环"}
结合与释放循环使多肽链正确折叠。需要 $\mathrm{ATP}$ 水解供能，并需要 $\mathrm{Hsp}40$ 等其他伴侣蛋白共同作用。结合还可以解开已有聚集或防止新聚集。释放后重新折叠成天然构象；折叠不充分则重复，直至天然构象形成。
:::

:::timeline{period="Hsp70 从抓住疏水区到放出天然构象"}
- **结合疏水区** 未折叠肽链的疏水基团被捂住，避免变性、过早折叠或膜转位前折叠
- **ATP 水解 + Hsp40** 结合与释放循环进行
- **解开或防止聚集** 已聚在一起的肽链可被拆开，新的聚集被挡住
- **释放后折叠** 肽链离开 Hsp70，折成天然构象；不够则再进下一轮
:::

人热激蛋白家族可存在于细胞质、内质网腔、线粒体、细胞核等部位，发挥多种细胞保护功能，例如：使线粒体和内质网蛋白质以未折叠状态转运和跨膜；避免蛋白质变性后因疏水基团暴露而发生不可逆聚集；清除变性或错误折叠的肽链中间物等。

:::definition{label="人热激蛋白家族的分布与保护功能"}
可存在于细胞质、内质网腔、线粒体、细胞核。功能包括：线粒体和内质网蛋白质以未折叠状态转运和跨膜；避免变性后疏水基团暴露所致不可逆聚集；清除变性或错误折叠的肽链中间物。
:::

:::insight{label="未折叠有时是必须的，不是失败"}
跨膜蛋白质、线粒体蛋白质、内质网蛋白质在进膜或进细胞器之前要保持非折叠状态，这正是 $\mathrm{Hsp}70$ 的一户。把“未折叠”一律写成病理聚集，后文线粒体前导肽那一段会对不上。
:::

:::pitfall{label="Hsp70 不是只在发烧时才出现"}
高温可诱导其合成，所以叫热激蛋白；翻译后加工里它日常结合疏水区。答成“只有热休克才需要”，正常折叠和跨膜转位就没有伴侣。
:::

### （二）伴侣蛋白 GroEL/GroES 提供折叠微环境

有些肽链的正确折叠还需要伴侣蛋白发挥辅助作用。伴侣蛋白的主要作用是为非自发性折叠肽链提供正确折叠的微环境。例如，在大肠埃希菌，约有 $10\%\sim 15\%$ 的细胞内蛋白质的正确折叠依赖伴侣系统 $\mathrm{GroEL}/\mathrm{GroES}$，热激条件下依赖该系统的蛋白质则高达 $30\%$。在真核细胞，与 $\mathrm{GroEL}/\mathrm{GroES}$ 功能类似的伴侣蛋白是 $\mathrm{Hsp}60$。

$\mathrm{GroEL}$ 是由 $14$ 个相同亚基组成的多聚体，可形成一桶状空腔，顶部是空腔的出口。$\mathrm{GroES}$ 是由 $7$ 个相同亚基组成的圆顶状复合物，可作为 $\mathrm{GroEL}$ 桶的盖子。需要折叠的肽链进入 $\mathrm{GroEL}$ 的桶状空腔后，$\mathrm{GroES}$ 可作为盖子瞬时封闭 $\mathrm{GroEL}$ 出口。封闭后的桶状空腔为肽链折叠提供微环境，折叠过程需消耗大量 $\mathrm{ATP}$。折叠完成后，形成天然构象的多肽链被释放；尚未完全折叠的肽链可进入下一轮循环，重复以上过程，直至天然构象形成（图16-11）。

:::definition{label="伴侣蛋白（chaperonin）"}
主要为非自发性折叠肽链提供正确折叠的微环境。大肠埃希菌的代表是 $\mathrm{GroEL}/\mathrm{GroES}$；真核类似物是 $\mathrm{Hsp}60$。
:::

:::definition{label="GroEL"}
$14$ 个相同亚基组成的多聚体，形成桶状空腔，顶部是出口。肽链进入空腔后在盖子封闭下折叠。
:::

:::definition{label="GroES"}
$7$ 个相同亚基组成的圆顶状复合物，作为 $\mathrm{GroEL}$ 桶的盖子，瞬时封闭出口。
:::

:::definition{label="GroEL/GroES 的负荷"}
大肠埃希菌约 $10\%\sim 15\%$ 的细胞内蛋白质依赖该系统正确折叠；热激条件下高达 $30\%$。折叠消耗大量 $\mathrm{ATP}$；未完全折叠可再进下一轮。
:::

| | $\mathrm{Hsp}70$ 家族 | $\mathrm{GroEL}/\mathrm{GroES}$（伴侣蛋白） |
|--|----------------------|------------------------------------------|
| 分子量／组成 | 接近 $70\,\mathrm{kD}$；循环还需 $\mathrm{Hsp}40$ | $\mathrm{GroEL}$：$14$ 亚基桶；$\mathrm{GroES}$：$7$ 亚基盖 |

:::

:::pitfall{label="14 和 7 不要对调，也不要写成 14 种亚基"}
$\mathrm{GroEL}$ 是 $14$ 个**相同**亚基，$\mathrm{GroES}$ 是 $7$ 个**相同**亚基。写成 $14$ 种不同亚基，桶就不是同一套零件围成的空腔。
:::

:::pitfall{label="Hsp60 不是 GroEL 的另一个名字在大肠埃希菌里"}
$\mathrm{GroEL}/\mathrm{GroES}$ 是大肠埃希菌的系统；$\mathrm{Hsp}60$ 是真核细胞中功能类似的伴侣蛋白。把 $\mathrm{Hsp}60$ 写进大肠埃希菌，百分数 $10\%\sim 15\%$／$30\%$ 就没有原核户头。
:::

:::insight{label="盖子是瞬时封闭，不是把蛋白质永远关在桶里"}
$\mathrm{GroES}$「瞬时」封闭出口。折好了要释放；没折好再进下一轮。把伴侣蛋白听成“永久隔离错误肽链”，清除变性中间物那一户是人热激蛋白家族的，不是 $\mathrm{GroEL}$ 的盖子。
:::

### （三）二硫键异构酶和脯氨酰顺反异构酶参与正确构象

除了需要分子伴侣协助肽链折叠外，一些蛋白质形成正确空间构象还需要异构酶（isomerase）的参与。已发现两种异构酶可以帮助细胞内新生肽链折叠为功能蛋白质：一种是蛋白质二硫键异构酶（protein disulfide isomerase，$\mathrm{PDI}$），另一种是肽脯氨酰基顺-反异构酶（peptide prolyl cis-trans isomerase，$\mathrm{PPI}$）。前者帮助肽链内或肽链间二硫键的正确形成，后者可使肽链在各脯氨酸残基弯折处形成正确折叠。这些都是蛋白质形成正确空间构象和发挥功能的必要条件。

:::definition{label="蛋白质二硫键异构酶 PDI"}
蛋白质二硫键异构酶（protein disulfide isomerase，$\mathrm{PDI}$）：帮助肽链内或肽链间二硫键正确形成。
:::

:::definition{label="肽脯氨酰基顺-反异构酶 PPI"}
肽脯氨酰基顺-反异构酶（peptide prolyl cis-trans isomerase，$\mathrm{PPI}$）：使肽链在各脯氨酸残基弯折处形成正确折叠。
:::

:::compare{title="分子伴侣 vs 两种异构酶"}
| | 分子伴侣 | $\mathrm{PDI}$ | $\mathrm{PPI}$ |
|--|----------|---------------|---------------|
| 管什么 | 疏水区、微环境、防聚集 | 二硫键对不对 | 脯氨酸处顺反、弯折 |
| 典型分子 | $\mathrm{Hsp}70$、$\mathrm{GroEL}/\mathrm{GroES}$、$\mathrm{Hsp}60$ | 异构酶 | 异构酶 |
| 没有它 | 聚集体、过早折叠 | 二硫键错配 | 脯氨酸弯折处折不对 |

折叠这一节是三户：伴侣捂疏水区／提供空腔，PDI 管 S–S，PPI 管脯氨酸。
:::

:::pitfall{label="PDI 不是把肽链水解成片段的酶"}
水解是下一部分的蛋白水解酶、信号肽酶。PDI 改的是二硫键配对，不断肽键。看见“异构酶”不要写成水解酶。
:::

:::pitfall{label="PPI 不是脯氨酸羟化酶"}
羟化是表16-4 的化学修饰，底物是脯氨酸、赖氨酸。PPI 改的是脯氨酸处肽键的顺反异构。把两笔并成“改脯氨酸侧链”，弯折处那一户就丢了。
:::

## 二、肽链水解加工产生具有活性的蛋白质或多肽

新生肽链的水解是肽链加工的重要形式。新生肽链 N- 端的甲硫氨酸残基，在肽链离开核糖体后，大部分即由特异的蛋白水解酶切除。原核细胞中约半数成熟蛋白质的 N- 端经脱甲酰基酶切除 N- 甲酰基而保留甲硫氨酸，另一部分被氨基肽酶水解而去除 N- 甲酰甲硫氨酸。真核细胞分泌蛋白质和跨膜蛋白质的前体分子的 N- 端都含有信号肽（signal peptide）序列，由 $13\sim 36$ 个氨基酸残基组成，在蛋白质成熟过程中需要被切除。有些情况下，C- 端的氨基酸残基也需要被酶切除，从而使蛋白质呈现特定功能。

另外，还有许多蛋白质在初合成时是分子量较大的没有活性的前体分子，如胰岛素原、胰蛋白酶原等。这些前体分子也需经过水解作用切除部分肽段，才能成为有活性的蛋白质分子或功能肽。

:::definition{label="N- 端甲硫氨酸多数要切"}
肽链离开核糖体后，N- 端甲硫氨酸残基大部分由特异蛋白水解酶切除。
:::

:::definition{label="原核 N- 端两种切法"}
约半数成熟蛋白质：脱甲酰基酶只切 N- 甲酰基，保留甲硫氨酸。另一部分：氨基肽酶水解，去除整个 N- 甲酰甲硫氨酸。
:::

:::definition{label="信号肽在成熟时被切除"}
真核分泌蛋白质和跨膜蛋白质前体的 N- 端含信号肽（signal peptide），$13\sim 36$ 个氨基酸残基，成熟过程中需要被切除。后文靶向输送还要把信号肽的三段式写全；这里先钉死：它是要切掉的。
:::

:::definition{label="无活性前体靠水解激活"}
胰岛素原、胰蛋白酶原等初合成时分子量较大、没有活性，需水解切除部分肽段才成为有活性的蛋白质或功能肽。C- 端残基有时也要切，使蛋白质呈现特定功能。
:::

:::compare{title="原核切 N- 端：只切甲酰基 vs 连甲硫氨酸一起切"}
| | 脱甲酰基酶 | 氨基肽酶 |
|--|------------|----------|
| 切什么 | N- 甲酰基 | N- 甲酰甲硫氨酸 |
| 留下什么 | 甲硫氨酸 | 甲硫氨酸也去掉 |
| 比例 | 约半数成熟蛋白质 | 另一部分 |

不要把两笔都答成“原核蛋白质 N- 端一定没有甲硫氨酸”。
:::

:::pitfall{label="起始用的甲硫氨酸不是永远留在成熟蛋白质上"}
第二节起始氨酰 $\mathrm{tRNA}$ 带甲硫氨酸（原核还甲酰化）。本节说离开核糖体后大部分要切。把“起始密码子编码甲硫氨酸”理解成“成熟蛋白质 N- 端都是甲硫氨酸”，原核那半数保留 Met 的例外会变成全部。
:::

:::pitfall{label="胰岛素原、胰蛋白酶原不是分子伴侣没折好"}
它们是分子量较大的无活性前体，要靠水解切肽段才有活性。不是折叠失败，也不是表16-4 的磷酸化没加上。
:::

有些多肽链经水解可以产生数种小分子活性肽。如阿黑皮素原（pro-opiomelanocortin，$\mathrm{POMC}$）可被水解而生成促肾上腺皮质激素、$\beta$- 促脂解素、$\alpha$- 促黑激素、促皮质素样中叶肽、$\gamma$- 促脂解素、$\beta$- 内啡肽、$\beta$- 促黑激素、$\gamma$- 内啡肽及 $\alpha$- 内啡肽等 $9$ 种活性物质（图16-12）。

$\mathrm{POMC}$ 的水解位点由 $\mathrm{Arg}$-$\mathrm{Lys}$、$\mathrm{Lys}$-$\mathrm{Arg}$ 或 $\mathrm{Lys}$-$\mathrm{Lys}$ 序列构成，用数字 $1\sim 7$ 表示。各活性物质下方括号内的数字为其在 $\mathrm{POMC}$ 中对应的氨基酸编号（将 $\mathrm{ACTH}$ 的 N 端第一位氨基酸残基编为 $1$ 号）。

::figure{src="/images/biochemistry/textbook/p0337_02.png" caption="图16-12　POMC 的水解修饰。N 端先是信号肽，水解位点 1～7 为 Arg-Lys、Lys-Arg 或 Lys-Lys。切点 4 分出 ACTH 与 β-促脂解素（42～134）；ACTH 再分为 α-MSH（1～13）与 CLIP（18～39）；β-促脂解素再分为 γ-促脂解素（42～101）与 β-内啡肽（104～134）；γ-促脂解素得 β-MSH（84～101）；β-内啡肽得 γ-内啡肽（104～118），再得 α-内啡肽（104～117）。编号以 ACTH 的 N 端第一位为 1 号。" alt="POMC 从 N 到 C：信号肽后七个切点；ACTH 灰段与 β-促脂解素黑加蓝段平行分出 α-MSH、CLIP、γ-促脂解素、β-内啡肽、β-MSH 及两种更短内啡肽"}

:::definition{label="阿黑皮素原 POMC"}
阿黑皮素原（pro-opiomelanocortin，$\mathrm{POMC}$）：一条多肽链经水解产生多种小分子活性肽。本版列出 $9$ 种：促肾上腺皮质激素（$\mathrm{ACTH}$）、$\beta$- 促脂解素、$\alpha$- 促黑激素（$\alpha$-$\mathrm{MSH}$）、促皮质素样中叶肽（$\mathrm{CLIP}$）、$\gamma$- 促脂解素、$\beta$- 内啡肽、$\beta$- 促黑激素（$\beta$-$\mathrm{MSH}$）、$\gamma$- 内啡肽、$\alpha$- 内啡肽。
:::

:::definition{label="POMC 的切点和编号习惯"}
水解位点由 $\mathrm{Arg}$-$\mathrm{Lys}$、$\mathrm{Lys}$-$\mathrm{Arg}$ 或 $\mathrm{Lys}$-$\mathrm{Lys}$ 构成，图中标 $1\sim 7$。氨基酸编号把 $\mathrm{ACTH}$ 的 N 端第一位编为 $1$ 号；图中括号内数字是各活性片段在这条编号尺上的起止。
:::

:::keypoint{label="图16-12 必须能顺着箭头默写"}
- N 端先切掉信号肽，不要把信号肽算进 $9$ 种活性物质。
- 切点 $4$：$\mathrm{ACTH}$ 与 $\beta$- 促脂解素（$42\sim 134$）分开。
- $\mathrm{ACTH}\rightarrow\alpha$-$\mathrm{MSH}$（$1\sim 13$）$+\mathrm{CLIP}$（$18\sim 39$）。
- $\beta$- 促脂解素 $\rightarrow\gamma$- 促脂解素（$42\sim 101$）$+\beta$- 内啡肽（$104\sim 134$）。
- $\gamma$- 促脂解素 $\rightarrow\beta$-$\mathrm{MSH}$（$84\sim 101$）。
- $\beta$- 内啡肽 $\rightarrow\gamma$- 内啡肽（$104\sim 118$）$\rightarrow\alpha$- 内啡肽（$104\sim 117$）。
:::

:::insight{label="一条前体切出九种活性肽，是水解加工的极端例子"}
胰岛素原切成一条胰岛素；POMC 切成一组激素和内啡肽。共同点：初产物没有这些小分子的活性，活性在切点之后。切点都是成对碱性残基，不是随机切开。
:::

:::pitfall{label="编号 1 不是 POMC 全长的第一位残基"}
教材规定：将 $\mathrm{ACTH}$ 的 N 端第一位编为 $1$ 号。信号肽在更 N 端，图上是空白框，不要把 $1$ 号安到信号肽上。$\beta$- 促脂解素从 $42$ 起，说明 $\mathrm{ACTH}$ 大约占 $1\sim 39$。
:::

:::pitfall{label="α-MSH 不要写成教材没有的“α-激素”"}
电子版正文有一处把 $\alpha$- 促黑激素印成「$\alpha$- 激素」。图16-12 标的是 $\alpha$-$\mathrm{MSH}$（$1\sim 13$）。九种活性物质按图和全称写，不要另编一种 $\alpha$- 激素。
:::

## 三、氨基酸残基的化学修饰改变蛋白质的活性

直接参与肽链合成的氨基酸约有 $20$ 种，合成后某些氨基酸残基的侧链基团发生化学修饰，这样就显著增加了肽链中的氨基酸种类。已发现蛋白质中存在 $100$ 多种修饰性氨基酸。这些修饰可改变蛋白质的溶解度、稳定性、亚细胞定位以及与细胞中其他蛋白质的相互作用等，从而使蛋白质的功能具有多样性。体内常见的蛋白质化学修饰见表16-4。

**表16-4　体内常见的蛋白质化学修饰**

| 化学修饰类型 | 被修饰的氨基酸残基 |
|--------------|--------------------|
| 磷酸化 | 丝氨酸、苏氨酸、酪氨酸 |
| N- 糖基化 | 天冬酰胺 |
| O- 糖基化 | 丝氨酸、苏氨酸 |
| 羟基化 | 脯氨酸、赖氨酸 |
| 甲基化 | 赖氨酸、精氨酸、组氨酸、天冬酰胺、天冬氨酸、谷氨酸 |
| 乙酰化 | 赖氨酸、丝氨酸 |

上述化学修饰均为酶促反应，蛋白激酶、糖基转移酶、羟化酶、甲基转移酶等都在这一过程中发挥重要作用。

:::definition{label="侧链化学修饰增加氨基酸种类"}
直接参与合成的氨基酸约 $20$ 种；合成后侧链修饰使肽链中出现 $100$ 多种修饰性氨基酸。可改变溶解度、稳定性、亚细胞定位及与其他蛋白质的相互作用，功能因而多样。
:::

:::definition{label="磷酸化的三个残基"}
丝氨酸、苏氨酸、酪氨酸。酶是蛋白激酶。不要把天冬氨酸、谷氨酸写进这一格——那两格在甲基化。
:::

:::definition{label="N- 糖基化 vs O- 糖基化"}
N- 糖基化：天冬酰胺。O- 糖基化：丝氨酸、苏氨酸。酶是糖基转移酶。N 连在酰胺氮上，O 连在羟基上，残基名单不要对调。
:::

:::definition{label="羟基化、甲基化、乙酰化各改谁"}
羟基化：脯氨酸、赖氨酸（羟化酶）。甲基化：赖氨酸、精氨酸、组氨酸、天冬酰胺、天冬氨酸、谷氨酸（甲基转移酶）。乙酰化：赖氨酸、丝氨酸。
:::

:::keypoint{label="表16-4 六行不要串格"}
- 磷酸化：$\mathrm{Ser}$、$\mathrm{Thr}$、$\mathrm{Tyr}$。
- N- 糖基化：只有 $\mathrm{Asn}$。
- O- 糖基化：$\mathrm{Ser}$、$\mathrm{Thr}$（与磷酸化的前两个残基相同，修饰基团不同）。
- 羟基化：$\mathrm{Pro}$、$\mathrm{Lys}$。
- 甲基化：名单最长，碱性残基加 $\mathrm{Asn}$／$\mathrm{Asp}$／$\mathrm{Glu}$。
- 乙酰化：$\mathrm{Lys}$、$\mathrm{Ser}$。
:::

:::pitfall{label="丝氨酸同时出现在磷酸化、O- 糖基化和乙酰化，不是印重了"}
同一残基可接受不同修饰。看见丝氨酸不要只答磷酸化。定位到哪一种修饰，要看酶和基团，不能只看残基名字。
:::

:::pitfall{label="约 20 种原料氨基酸不是“蛋白质里只有 20 种残基”"}
原料约 $20$ 种；修饰后出现 $100$ 多种修饰性氨基酸。把两句话并成“蛋白质只有 $20$ 种氨基酸”，表16-4 整张表没有意义。
:::

需要注意的是，此前硒化也被认为是一种蛋白质化学修饰方式。但随着研究深入，现明确硒半胱氨酸本身就是第 $21$ 种氨基酸。在遗传密码中，硒半胱氨酸的编码是 $\mathrm{UGA}$，通常用作终止密码子。但如果在 $\mathrm{mRNA}$ 中有一个硒半胱氨酸插入序列（SEleno Cysteine Insertion Sequence，$\mathrm{SECIS}$），$\mathrm{UGA}$ 就用作硒半胱氨酸的编码。和细胞中的其他氨基酸一样，硒半胱氨酸也有特异对应的 $\mathrm{tRNA}$。当细胞生长缺乏硒时，硒蛋白的翻译会在 $\mathrm{UGA}$ 密码子处中止，成为不完整而没有功能的蛋白。

:::definition{label="硒半胱氨酸是第 21 种氨基酸"}
硒半胱氨酸本身就是第 $21$ 种氨基酸，不再把它写成“硒化”这种翻译后修饰。有特异对应的 $\mathrm{tRNA}$。
:::

:::definition{label="SECIS 把 UGA 从终止改成硒半胱氨酸"}
$\mathrm{UGA}$ 通常是终止密码子。若 $\mathrm{mRNA}$ 中有硒半胱氨酸插入序列（SEleno Cysteine Insertion Sequence，$\mathrm{SECIS}$），$\mathrm{UGA}$ 编码硒半胱氨酸。
:::

:::definition{label="缺硒时硒蛋白在 UGA 处中止"}
细胞生长缺乏硒时，硒蛋白的翻译在 $\mathrm{UGA}$ 处中止，产物不完整、没有功能。
:::

:::cause-effect{title="为什么缺硒会得到没有功能的硒蛋白"}
- **因** 没有硒就装不上硒半胱氨酸，$\mathrm{UGA}$ 按终止密码子执行
- **果** 翻译在 $\mathrm{UGA}$ 处中止，肽链不完整、没有功能
:::

:::pitfall{label="UGA 在本章有两户，不要只记终止"}
第一节：$\mathrm{UAA}$、$\mathrm{UAG}$、$\mathrm{UGA}$ 是终止密码子。本节：有 $\mathrm{SECIS}$ 时 $\mathrm{UGA}$ 编码第 $21$ 种氨基酸。答题先问有没有 $\mathrm{SECIS}$，不要一看见 $\mathrm{UGA}$ 就停笔。
:::

:::pitfall{label="硒半胱氨酸不是表16-4 的第七行修饰"}
本版明确：以前把硒化当修饰，现在它是第 $21$ 种氨基酸，有自己的 $\mathrm{tRNA}$。写进磷酸化那张表，SECIS 和缺硒中止都没有入口。
:::

## 四、亚基聚合形成具有四级结构的活性蛋白质

在生物体内，许多具有特定功能的蛋白质由 $2$ 条以上肽链构成，各肽链之间通过非共价键或二硫键维持一定空间构象，有些还需与辅基聚合才能形成具有活性的蛋白质。由 $2$ 条以上肽链构成的蛋白质，其亚基相互聚合时所需要的信息蕴藏在肽链的氨基酸序列之中，而且这种聚合过程往往又有一定顺序，前一步骤的聚合往往促进后一步骤的进行。

例如，成人血红蛋白由 $2$ 条 $\alpha$ 链、$2$ 条 $\beta$ 链及 $4$ 个血红素分子组成。$\alpha$ 链合成后从核糖体自行脱离，与尚未从核糖体释放的 $\beta$ 链相结合，将 $\beta$ 链带离核糖体，形成游离的 $\alpha\beta$ 二聚体。此二聚体再与线粒体内生成的两个血红素相结合，最后才形成一个由 $4$ 条肽链（$\alpha_2\beta_2$）和 $4$ 个血红素构成的有功能的血红蛋白分子。

:::definition{label="四级结构靠亚基按顺序聚合"}
两条以上肽链构成的蛋白质，亚基之间用非共价键或二硫键维持构象，有些还需与辅基聚合才有活性。聚合所需信息蕴藏在氨基酸序列中；聚合往往有一定顺序，前一步促进后一步。
:::

:::definition{label="成人血红蛋白的装配顺序"}
组成：$2$ 条 $\alpha$、$2$ 条 $\beta$、$4$ 个血红素。顺序：$\alpha$ 链合成后自行脱离核糖体 $\rightarrow$ 结合尚未释放的 $\beta$ 链并把 $\beta$ 带离核糖体 $\rightarrow$ 游离 $\alpha\beta$ 二聚体 $\rightarrow$ 再结合线粒体内生成的两个血红素 $\rightarrow$ $\alpha_2\beta_2$ 加上 $4$ 个血红素，成为有功能的血红蛋白。
:::

:::timeline{period="成人血红蛋白从核糖体走到 α2β2"}
- **α 链先脱离核糖体** 自行释放
- **α 结合还在核糖体上的 β** 把 β 链带离核糖体，得到游离 αβ 二聚体
- **结合两个血红素** 血红素在线粒体内生成
- **四聚体完成** 4 条肽链 α2β2 加 4 个血红素，才有功能
:::

:::insight{label="α 链去“接”还没下机的 β，是顺序聚合的具体画面"}
不是四条链在溶液里随机碰上。$\alpha$ 先好，$\beta$ 还挂在核糖体上，$\alpha$ 把它拽下来。前一步（$\alpha$ 合成完毕）促进后一步（$\beta$ 释放并成二聚体）。
:::

:::pitfall{label="αβ 二聚体还不是有功能的血红蛋白"}
游离 $\alpha\beta$ 二聚体之后还要结合血红素，最后才是 $\alpha_2\beta_2$ 加 $4$ 个血红素。写到二聚体就停笔，辅基那一户丢了。血红素在线粒体生成，不要写成核糖体上带出来的。
:::

:::pitfall{label="四级结构的二硫键不要和 PDI 的二硫键并成一句"}
PDI 帮助肽链内或肽链间二硫键正确形成，属于折叠。亚基聚合可以用非共价键或二硫键，属于装配顺序。血红蛋白教材点名的是 $\alpha$、$\beta$ 和血红素，没有把 Hb 写成靠 PDI 焊起来。
:::

## 五、内质网及高尔基体是蛋白质合成后加工及分选的主要场所

内质网（endoplasmic reticulum，$\mathrm{ER}$）是一个连续的膜系统，在真核细胞的细胞质内形成一系列扁平的囊，具有多种功能，尤其在蛋白质的合成、折叠、修饰和运输方面非常重要。所有真核细胞都含有内质网。在动物细胞中，$\mathrm{ER}$ 通常占细胞膜含量的一半以上。按某些物理和功能特征的差异，内质网区分为粗糙内质网和平滑内质网两种类型。

高尔基体（Golgi apparatus）把蛋白质导向溶酶体或细胞膜；还有一些蛋白质被导向细胞外分泌。靶向运输到高尔基体的蛋白质从粗糙 $\mathrm{ER}$ 上的核糖体转移到粗糙 $\mathrm{ER}$ 腔中，粗糙 $\mathrm{ER}$ 腔是蛋白质折叠、修饰和组装的位点。高尔基体负责将蛋白质修饰和包装成囊泡，以便运输到目的地。因此，内质网及高尔基体是蛋白质合成后加工及分选的主要场所。

:::definition{label="内质网 ER"}
内质网（endoplasmic reticulum，$\mathrm{ER}$）：连续的膜系统，在真核细胞质内形成一系列扁平囊。功能尤其在蛋白质的合成、折叠、修饰和运输。所有真核细胞都有内质网；动物细胞中 $\mathrm{ER}$ 通常占细胞膜含量的一半以上。分粗糙内质网和平滑内质网。
:::

:::definition{label="高尔基体在分选里做什么"}
高尔基体（Golgi apparatus）：把蛋白质导向溶酶体或细胞膜，或导向细胞外分泌。蛋白质先从粗糙 $\mathrm{ER}$ 核糖体进入粗糙 $\mathrm{ER}$ 腔（折叠、修饰、组装），再由高尔基体修饰并包装成囊泡运走。
:::

:::compare{title="粗糙 ER 腔 vs 高尔基体"}
| | 粗糙 $\mathrm{ER}$ 腔 | 高尔基体 |
|--|---------------------|----------|
| 蛋白质从哪来 | 粗糙 $\mathrm{ER}$ 上的核糖体 | 由 $\mathrm{ER}$ 出芽囊泡送来 |
| 本节给的工作 | 折叠、修饰、组装 | 再修饰、包装成囊泡 |
| 去向 | 送到高尔基体 | 溶酶体、细胞膜、细胞外 |

加工和分选的主场是这两处，不是核糖体本身。
:::

:::pitfall{label="不是所有蛋白质都进内质网"}
驻留细胞质的蛋白质不必走 $\mathrm{ER}$。后文核蛋白、大部分线粒体蛋白质在细胞质游离核糖体上合成后再输送。把“加工分选主场是 ER／高尔基体”听成“一切蛋白质都在 ER 上合成”，表16-5 的核定位序列和线粒体前导肽会没有游离核糖体。
:::

## 六、蛋白质合成后被靶向输送至细胞特定部位

蛋白质在细胞质合成后，还必须被靶向输送至其发挥功能的亚细胞区域，或分泌到细胞外。所有需靶向输送的蛋白质，其一级结构都存在分选信号，可引导蛋白质转移到细胞的特定部位。这类分拣信号又称信号序列（signal sequence），是决定蛋白质靶向输送特性的最重要结构。有的信号序列存在于肽链的 N- 端，有的在 C- 端，有的在肽链内部；有的输送完成后切除，有的保留。现代生物信息学技术可通过基因的结构推测其编码蛋白质在细胞内的可能定位（表16-5）。

有的蛋白质在合成过程中已开始靶向输送，而另有一些蛋白质的靶向输送是从核糖体上释放后才开始的。

**表16-5　蛋白质的亚细胞定位分拣信号**

| 蛋白质种类 | 信号序列 | 结构特点 |
|------------|----------|----------|
| 分泌蛋白质和膜蛋白质 | 信号肽 | $13\sim 36$ 个氨基酸残基，位于新生肽链 N- 端 |
| 核蛋白 | 核定位序列 | $4\sim 8$ 个氨基酸残基，通常包含连续的碱性氨基酸（$\mathrm{Arg}$ 或 $\mathrm{Lys}$），在肽链的位置不固定 |
| 内质网蛋白质 | 内质网滞留信号 | 肽链 C- 端的 $\mathrm{Lys}$-$\mathrm{Asp}$-$\mathrm{Glu}$-$\mathrm{Leu}$ 序列 |
| 核基因组编码的线粒体蛋白质 | 线粒体前导肽 | $20\sim 35$ 个氨基酸残基，位于新生肽链 N- 端 |
| 溶酶体蛋白质 | 溶酶体靶向信号 | 甘露糖-$6$-磷酸（$\mathrm{Man}$-$6$-$\mathrm{P}$） |

:::definition{label="信号序列（分拣信号）"}
信号序列（signal sequence）：需靶向输送的蛋白质一级结构中的分选信号，是决定靶向输送特性的最重要结构。位置可在 N- 端、C- 端或内部；输送完成后可切除或保留。
:::

:::definition{label="共翻译输送 vs 释放后输送"}
有的蛋白质在合成过程中已开始靶向输送（分泌蛋白质是代表）。另一些从核糖体释放后才开始（核蛋白、大部分线粒体蛋白质）。
:::

:::keypoint{label="表16-5 五户对照"}
- 分泌／膜：N- 端信号肽，$13\sim 36$ 残基，要切。
- 核：NLS，$4\sim 8$ 残基，连续 $\mathrm{Arg}$／$\mathrm{Lys}$，位置不固定，**保留不切**。
- 内质网驻留：C- 端 $\mathrm{Lys}$-$\mathrm{Asp}$-$\mathrm{Glu}$-$\mathrm{Leu}$。
- 线粒体（核编码）：N- 端前导肽，$20\sim 35$ 残基。
- 溶酶体：$\mathrm{Man}$-$6$-$\mathrm{P}$，不是一段肽。
:::

:::pitfall{label="信号序列不是都在 N- 端，也不是都切掉"}
核定位序列位置不固定、定位后保留。内质网滞留信号在 C- 端。溶酶体信号是甘露糖-$6$-磷酸。一律答“N- 端肽段、成熟时切除”，五户只剩分泌蛋白质一户。
:::

:::pitfall{label="13～36 和 20～35 不要对调"}
$13\sim 36$ 是分泌／膜蛋白质的信号肽；$20\sim 35$ 是线粒体前导肽。长度接近，户头不同：一个进内质网，一个进线粒体。
:::

### （一）分泌蛋白质在内质网加工及靶向输送

细胞内分泌蛋白质的合成与靶向输送同时发生，其 N- 端存在由数十个氨基酸残基组成的信号序列，又称信号肽（signal peptide）。已发现有数百种信号肽存在，它们的共同特点是：① N- 端含一个或多个碱性氨基酸残基；② 中段含 $10\sim 15$ 个疏水性氨基酸残基；③ C- 端由一些极性较大、侧链较短的氨基酸残基组成，与信号肽裂解位点（cleavage site）邻近（图16-13）。

::figure{src="/images/biochemistry/textbook/p0339_01.png" caption="图16-13　信号肽结构特点。蓝色框为碱性氨基酸，黑色框为疏水性氨基酸区域；右侧箭头为信号肽酶裂解位点。例：人前胰岛素原（Arg 后接疏水 Leu 段，Ala-Ala-Ala 之后切）；牛生长激素（Arg 后接疏水 Leu 段，Gly 处切）；蜜蜂蜂毒肽原（Lys 后接疏水 Asn 段，Ala 处切）；果蝇胶蛋白（Lys 紧接疏水 Leu 段，Gly 处切）。" alt="四条前体 N 端序列：蓝色碱性残基框、灰色疏水核心、箭头标信号肽酶切点"}

:::definition{label="信号肽的三段式"}
信号肽（signal peptide）：分泌蛋白质 N- 端的信号序列，已发现数百种。共同特点：N- 端一个或多个碱性残基；中段 $10\sim 15$ 个疏水性残基；C- 端极性较大、侧链较短，邻近裂解位点（cleavage site）。
:::

:::insight{label="图16-13 四条例子都是先碱、再疏水、再切"}
人前胰岛素原、牛生长激素的蓝色框是 $\mathrm{Arg}$；蜜蜂蜂毒肽原、果蝇胶蛋白是 $\mathrm{Lys}$。灰色长框是疏水核。箭头在疏水核下游、成熟肽之前。读图先认三色／三区，不要背四条全序列。
:::

:::pitfall{label="13～36 是整段信号肽长度，10～15 只是中段疏水区"}
表16-5 的 $13\sim 36$ 是整条信号肽。三段式里中段疏水区才是 $10\sim 15$ 个残基。把 $10\sim 15$ 答成整条信号肽，碱性 N- 端和裂解位点那两段就没地方放。
:::

分泌蛋白质的合成及转运机制为：① 在游离核糖体上，信号肽因位于肽链 N- 端而首先被合成，随后被信号识别颗粒（signal recognition particle，$\mathrm{SRP}$）识别并结合，$\mathrm{SRP}$ 随即结合到核糖体上；② 内质网膜上有 $\mathrm{SRP}$ 的受体（亦称为 $\mathrm{SRP}$ 对接蛋白），借此受体，$\mathrm{SRP}$- 核糖体复合物被引导至内质网膜上；③ 在内质网膜上，肽转位复合物（peptide translocation complex）形成跨内质网膜的蛋白质通道，合成中的肽链穿过内质网膜孔进入内质网；④ $\mathrm{SRP}$ 脱离信号肽和核糖体，肽链继续延长直至完成；⑤ 信号肽在内质网内被信号肽酶（signal peptidase）切除；⑥ 肽链在内质网中折叠形成最终构象，随内质网膜“出芽”形成的囊泡转移至高尔基复合体，最后在高尔基复合体中被包装进分泌小泡，转运至细胞膜，再分泌到细胞外（图16-14）。

::figure{src="/images/biochemistry/textbook/p0340_01.png" caption="图16-14　分泌蛋白质的加工与靶向输送。细胞质中 mRNA 带 5′-帽子与 3′ polyA 尾；核糖体上延伸的多肽 N 端为信号肽，SRP 结合并水解 GTP；内质网膜上有核糖体受体与 SRP 受体，肽转位复合物成孔；腔内信号肽酶切下信号肽，成熟分泌蛋白质留在内质网腔。释放 GDP+Pi。" alt="mRNA 折成 V 形跨在核糖体上，SRP 箭头指向信号肽，内质网膜上通道把肽链送入腔，信号肽酶切开信号肽"}

:::definition{label="信号识别颗粒 SRP"}
信号识别颗粒（signal recognition particle，$\mathrm{SRP}$）：识别并结合刚合成的 N- 端信号肽，随即结合核糖体。内质网膜上有其受体，又称 $\mathrm{SRP}$ 对接蛋白。
:::

:::definition{label="肽转位复合物"}
肽转位复合物（peptide translocation complex）：在内质网膜上形成跨膜蛋白质通道，让合成中的肽链穿过膜孔进入内质网。
:::

:::definition{label="信号肽酶"}
信号肽酶（signal peptidase）：在内质网内切除信号肽。图16-14 把酶画在腔面，切下的信号肽与分泌蛋白质分开。
:::

:::timeline{period="分泌蛋白质从游离核糖体走到细胞外"}
- **游离核糖体先做出 N 端信号肽** SRP 识别结合信号肽，再结合核糖体
- **SRP 受体对接** SRP-核糖体复合物被引导到内质网膜
- **肽转位复合物成孔** 合成中的肽链穿过内质网膜孔进入腔
- **SRP 脱离** 肽链继续延长直至完成
- **信号肽酶切除信号肽** 切在内质网内
- **折叠、出芽、高尔基、分泌小泡** 到细胞膜，分泌到细胞外
:::

非空文件 `p0340_01.png` 即图16-14。同页 `p0340_page.png` 是第 $340$ 页整页扫描，混有线粒体／质膜／核定位正文，不嵌入 `src`。
:::

:::keypoint{label="图16-14 画面上要能指认的零件"}
- $\mathrm{mRNA}$：$5'$ 帽子、$3'$ $\mathrm{polyA}$ 尾，说明这是真核分泌蛋白质。
- 延伸多肽的 N 端：信号肽；$\mathrm{SRP}$ 旁标 $\mathrm{GTP}$，释放侧标 $\mathrm{GDP}+\mathrm{P}_{\mathrm{i}}$。
- 内质网膜：核糖体受体、$\mathrm{SRP}$ 受体、肽转位复合物。
- 腔面：信号肽酶、被切下的信号肽、分泌蛋白质。
:::

:::pitfall{label="分泌蛋白质不是在内质网上才开始合成"}
第一步明确写在**游离核糖体**上。信号肽一露头，$\mathrm{SRP}$ 才把核糖体拖到内质网膜。答成“分泌蛋白质的核糖体一开始就在 ER 上”，游离核糖体那一步和 $\mathrm{SRP}$ 对接都没了。
:::

:::pitfall{label="SRP 脱离之后肽链还要继续延长"}
第④步：$\mathrm{SRP}$ 脱离信号肽和核糖体，肽链继续延长直至完成。把 $\mathrm{SRP}$ 写成全程扶着肽链，信号肽酶和出芽囊泡会对不上。
:::

:::insight{label="合成与靶向同时发生，所以叫共翻译输送"}
信号肽位于 N- 端，最先被合成，$\mathrm{SRP}$ 在肽链尚未完成时就把核糖体接到膜上。这和核蛋白、线粒体蛋白质“释放后才送”形成对照。
:::

### （二）内质网蛋白质的 C- 端含有滞留信号序列

内质网中含有多种帮助新生肽链折叠成天然构型的蛋白质，如分子伴侣等。这些需要停留在内质网中执行功能的蛋白质，先经粗面内质网上附着的核糖体合成并进入内质网腔，然后随囊泡输送至高尔基复合体。内质网蛋白肽链的 C- 端含有内质网滞留信号序列，它们被输送到高尔基复合体后，可通过这一滞留信号与内质网上相应受体结合，随囊泡输送回内质网。

:::definition{label="内质网滞留信号"}
肽链 C- 端的 $\mathrm{Lys}$-$\mathrm{Asp}$-$\mathrm{Glu}$-$\mathrm{Leu}$ 序列（表16-5）。内质网驻留蛋白先进入 $\mathrm{ER}$ 腔，随囊泡到高尔基复合体，再靠这段序列与内质网上相应受体结合，随囊泡返回内质网。
:::

:::cause-effect{title="为什么驻留蛋白还要先去一趟高尔基体"}
- **因** 它们也走粗面 ER → 囊泡 → 高尔基这条外运通路
- **果** 必须在 C- 端带着滞留信号，到高尔基体后被受体认出来，再装回程囊泡送回 ER；不是“从来不出 ER”
:::

:::pitfall{label="滞留信号在 C- 端，信号肽在 N- 端"}
进 $\mathrm{ER}$ 靠 N- 端信号肽；留在 $\mathrm{ER}$ 靠 C- 端 $\mathrm{Lys}$-$\mathrm{Asp}$-$\mathrm{Glu}$-$\mathrm{Leu}$。两段可以出现在同一条蛋白质上，功能不是同一件事。
:::

### （三）大部分线粒体蛋白质在细胞质合成后靶向输入线粒体

线粒体虽然自身含有 $\mathrm{DNA}$、$\mathrm{mRNA}$、$\mathrm{tRNA}$ 和核糖体等，可以进行蛋白质的合成，但绝大部分线粒体蛋白质（超过 $95\%$，约 $1\,100$ 种）是由细胞核基因组的基因编码，它们在细胞质中的游离核糖体中合成后靶向输送到线粒体，其中大部分定位于线粒体基质，其他定位于内膜、外膜或膜间腔。

定位于线粒体基质的蛋白质，其前体分子的 N- 端包含前导肽序列，由 $20\sim 35$ 个氨基酸残基组成，富含丝氨酸、苏氨酸及碱性氨基酸。这类蛋白质的靶向输送过程是：① 新合成的线粒体蛋白质与热激蛋白或线粒体输入刺激因子结合，以稳定的未折叠形式转运至线粒体外膜；② 通过前导肽序列识别，与线粒体外膜的受体复合物结合；③ 在热激蛋白水解 $\mathrm{ATP}$ 和跨内膜电化学梯度的动力共同作用下，蛋白质穿过由外膜转运体和内膜转运体共同构成的跨膜蛋白质通道，进入线粒体基质；④ 蛋白质前体被蛋白酶切除前导肽序列，在分子伴侣作用下折叠成有功能构象的蛋白质。

输送到线粒体内膜和膜间隙的蛋白质除了上述前导肽外，还另有一段信号序列，其作用是引导蛋白质从基质输送到线粒体内膜或穿过内膜进入膜间隙。

:::definition{label="核编码的线粒体蛋白质占绝大多数"}
线粒体自己能合成蛋白质，但绝大部分线粒体蛋白质（超过 $95\%$，约 $1\,100$ 种）由核基因组编码，在细胞质游离核糖体上合成后再输入线粒体。多数定位基质，其余在内膜、外膜或膜间腔。
:::

:::definition{label="线粒体前导肽"}
定位基质的前体 N- 端前导肽：$20\sim 35$ 个氨基酸残基，富含丝氨酸、苏氨酸及碱性氨基酸。
:::

:::definition{label="基质蛋白输入四步"}
与热激蛋白或线粒体输入刺激因子结合，以稳定未折叠形式到外膜 $\rightarrow$ 前导肽识别并结合外膜受体复合物 $\rightarrow$ 热激蛋白水解 $\mathrm{ATP}$ 加上跨内膜电化学梯度，穿过外膜转运体与内膜转运体共同构成的通道入基质 $\rightarrow$ 蛋白酶切前导肽，分子伴侣折叠成有功能构象。
:::

:::definition{label="内膜和膜间隙还要第二段信号"}
除前导肽外另有一段信号序列，引导蛋白质从基质到内膜，或穿过内膜进入膜间隙。
:::

:::timeline{period="核编码基质蛋白怎样进线粒体"}
- **保持未折叠** 热激蛋白或线粒体输入刺激因子结合，运到外膜
- **前导肽对接** 结合线粒体外膜受体复合物
- **双膜通道** 外膜转运体加内膜转运体；动力来自 ATP 水解和跨内膜电化学梯度
- **切前导肽再折叠** 蛋白酶切除，分子伴侣折出功能构象
:::

:::insight{label="Hsp70“保持未折叠”在这里兑现"}
本节开头写：$\mathrm{Hsp}70$ 使一些跨膜蛋白质在转位至膜前保持非折叠状态；人热激蛋白使线粒体蛋白质以未折叠状态转运和跨膜。线粒体输入把那句话变成四步里的第一步。
:::

:::pitfall{label="超过 95%、约 1100 种，不是线粒体基因组编码的"}
线粒体有自己的 $\mathrm{DNA}$／核糖体，但教材把“绝大部分”写给核基因组。把 $1\,100$ 种答成线粒体自己翻译，核编码前导肽整段消失。
:::

:::pitfall{label="进线粒体不是走 SRP–内质网"}
游离核糖体合成 → 未折叠保送 → 外膜受体 → 双膜转运体。不要把 $\mathrm{SRP}$、信号肽酶、高尔基囊泡搬进线粒体。前导肽富含 $\mathrm{Ser}$、$\mathrm{Thr}$ 和碱性残基，与分泌信号肽“碱性 + 疏水核”不是同一张图。
:::

:::pitfall{label="切前导肽在基质里，不是在细胞质里先切"}
第④步：进入基质之后才被蛋白酶切除前导肽。先切掉再进膜，外膜受体就认不到前导肽。
:::

### （四）质膜蛋白质由囊泡靶向输送至细胞膜

定位于细胞质膜的蛋白质，其靶向跨膜机制与分泌蛋白质相似。不过，跨膜蛋白质的肽链并不完全进入内质网腔，而是锚定在内质网膜上，通过内质网膜“出芽”方式形成囊泡。随后，跨膜蛋白质随囊泡转移至高尔基复合体进行加工，再随囊泡转运至细胞膜，最终与细胞膜融合而构成新的质膜。

不同类型的跨膜蛋白质以不同形式锚定于膜上。例如，单次跨膜蛋白质的肽链中除 N- 端含信号序列外，还有一段由疏水性氨基酸残基构成的跨膜序列，即停止转移序列（stop transfer sequence），是跨膜蛋白质在膜上的嵌入区域。当合成中的多肽链向内质网腔导入时，疏水的停止转移序列可与内质网膜的脂双层结合，从而使导入中的肽链不再向内质网腔内转移，形成一次性跨膜的锚定蛋白质。多次跨膜蛋白质的肽链中因有多个信号序列和多个停止转移序列，可在内质网膜上形成多次跨膜。

:::definition{label="质膜蛋白质走囊泡，但不完全进入 ER 腔"}
靶向跨膜机制与分泌蛋白质相似，但肽链锚定在内质网膜上，随出芽囊泡 → 高尔基复合体加工 → 再随囊泡到细胞膜，融合构成新的质膜。
:::

:::definition{label="停止转移序列"}
停止转移序列（stop transfer sequence）：单次跨膜蛋白质中除 N- 端信号序列外，由疏水性氨基酸残基构成的跨膜序列，是嵌入膜的区域。它与内质网膜脂双层结合后，肽链不再向腔内转移，形成一次性跨膜的锚定蛋白质。
:::

:::definition{label="多次跨膜靠多段信号加多段停止转移"}
多次跨膜蛋白质有多个信号序列和多个停止转移序列，在内质网膜上形成多次跨膜。
:::

:::compare{title="分泌蛋白质 vs 单次跨膜 vs 多次跨膜"}
| | 分泌蛋白质 | 单次跨膜 | 多次跨膜 |
|--|------------|----------|----------|
| N- 端信号肽 | 有，引导进 $\mathrm{ER}$ | 有 | 有，且可有多段信号 |
| 是否完全进腔 | 是，切信号肽后可溶在腔里 | 否，停止转移序列把链锚在脂双层 | 否，多段停止转移 |
| 随后 | 出芽 → 高尔基 → 分泌小泡 → 细胞外 | 出芽 → 高尔基 → 囊泡 → 与质膜融合 | 同左，只是跨膜次数多 |

相似的是囊泡路径；不同的是链有没有被停止转移序列卡住。
:::

:::pitfall{label="停止转移序列不是信号肽酶的切点"}
裂解位点属于信号肽 C- 端，把信号肽切掉。停止转移序列是疏水跨膜段，把后半条链留在膜里。把“停止”听成“在这里切断”，跨膜蛋白会变成可溶的分泌蛋白。
:::

:::pitfall{label="质膜蛋白质最后一步是与细胞膜融合，不是分泌到细胞外"}
囊泡与细胞膜融合，跨膜蛋白成为新质膜的一部分。分泌蛋白质才被释放到细胞外。路径前半段很像，终点不要写错。
:::

### （五）核蛋白由核输入因子运载经核孔入核

细胞核内含有多种蛋白质，如参与 $\mathrm{DNA}$ 复制和转录的各种酶及蛋白质因子、组蛋白、调节基因表达的转录因子等，它们都是在细胞质中合成后经核孔进入细胞核的，其靶向输送由特异的核定位序列（nuclear localization sequence，$\mathrm{NLS}$）引导。$\mathrm{NLS}$ 由 $4\sim 8$ 个氨基酸残基组成，通常包含连续的碱性氨基酸（$\mathrm{Arg}$ 或 $\mathrm{Lys}$），在肽链的位置不固定，定位完成后保留于肽链而不被切除。

核蛋白的靶向输送还需要多种蛋白质的参与，如核输入因子（nuclear importin）$\alpha$ 和 $\beta$、Ras 相关核蛋白（Ras-related nuclear protein，$\mathrm{Ran}$）等。核输入因子 $\alpha$ 和 $\beta$ 形成异二聚体，识别并结合核蛋白的 $\mathrm{NLS}$ 序列。核蛋白的靶向输送基本过程是：① 在细胞质合成的核蛋白与核输入因子结合形成复合物后被导向核孔；② 具有 $\mathrm{GTPase}$ 活性的 $\mathrm{Ran}$ 蛋白水解 $\mathrm{GTP}$ 释能，核蛋白–核输入因子复合物通过耗能机制经核孔进入细胞核基质；③ 核输入因子 $\beta$ 和 $\alpha$ 先后从上述复合物中解离，移出核孔后可被再利用，核蛋白定位于细胞核内（图16-15）。

:::definition{label="核定位序列 NLS"}
核定位序列（nuclear localization sequence，$\mathrm{NLS}$）：引导核蛋白入核。$4\sim 8$ 个氨基酸残基，通常含连续碱性氨基酸（$\mathrm{Arg}$ 或 $\mathrm{Lys}$），在肽链上位置不固定，定位完成后保留、不被切除。
:::

:::definition{label="核输入因子 α/β 与 Ran"}
核输入因子（nuclear importin）$\alpha$ 和 $\beta$ 形成异二聚体，识别并结合 $\mathrm{NLS}$。Ras 相关核蛋白（Ras-related nuclear protein，$\mathrm{Ran}$）具有 $\mathrm{GTPase}$ 活性，水解 $\mathrm{GTP}$ 释能，驱动复合物经核孔入核。
:::

:::definition{label="核蛋白入核三步"}
细胞质中核蛋白与核输入因子结合，导向核孔 $\rightarrow$ $\mathrm{Ran}$ 水解 $\mathrm{GTP}$，复合物耗能经核孔进入核基质 $\rightarrow$ 核输入因子 $\beta$ 和 $\alpha$ **先后**解离，移出核孔再利用，核蛋白留在核内。
:::

:::timeline{period="核蛋白从细胞质到核基质"}
- **识别 NLS** 核输入因子 α 和 β 异二聚体结合核蛋白，导向核孔
- **Ran 水解 GTP** 复合物耗能穿过核孔，进入核基质
- **β 先解离、α 后解离** 两个核输入因子移出核孔再循环，核蛋白留在核内
:::

:::pitfall{label="NLS 不切，不要按信号肽的习惯切掉"}
定位完成后保留于肽链。核蛋白要反复经过核孔或长期留在核内，信号必须还在。写成“入核后切除 NLS”，和表16-5「位置不固定、保留」对着干。
:::

:::pitfall{label="入核耗的是 GTP，不是把核糖体拖到核膜"}
核蛋白在细胞质合成完毕，经核孔进去。没有 $\mathrm{SRP}$，也没有核膜上的肽转位复合物把正在延长的肽链穿进核。能量来自 $\mathrm{Ran}$ 的 $\mathrm{GTPase}$。
:::

:::pitfall{label="核输入因子解离顺序是 β 然后 α"}
教材：核输入因子 $\beta$ 和 $\alpha$ **先后**从复合物中解离。写成同时脱落或 $\alpha$ 先掉，三步的第③步对不上。
:::

生物体内的蛋白质历经肽链合成的起始、延长、终止，以及加工和靶向输送后发挥生物学功能。其后，蛋白质在特定的时空条件下被降解。蛋白质的生物合成及其降解是几乎所有生命活动的基础。

:::insight{label="本节接到降解，但降解不是本章的展开"}
起始–延长–终止–加工–靶向之后才有功能；功能之后还要在特定时空被降解。合成与降解共同构成生命活动的基础。降解机制留给其他章，不要在本节补蛋白酶体步骤。
:::
