# 第一节　血浆蛋白质

第二十六章把血液写成流动于心血管系统内的液体组织。本节只立「血浆蛋白质」：先钉死血浆≠血清、本版数字和醋酸纤维素薄膜电泳五条区带（图26-1、表26-1）；再写分泌蛋白质的六条性质；功能八段里胶体渗透压、运输、血清酶三类和疾病谱必须分户。血红素合成交给第二节；成熟红细胞和白细胞代谢是第三节。

:::concept{term="先问血浆和血清是不是同一管液体，再问清蛋白跑向哪一极"}
看见「血液的生物化学」，先不要默写血红素结构式。户头是：血液由血浆、血细胞和血小板组成；凝固后析出的才叫血清。电泳在 $\mathrm{pH}\,8.6$ 把血浆蛋白质分成清蛋白、$\alpha_1$、$\alpha_2$、$\beta$、$\gamma$ 五条，正极侧是清蛋白，负极侧是 $\gamma$。功能先问胶体渗透压和运输，血清酶再分成血浆功能酶、外分泌酶、细胞酶三户。把「血浆＝血清」「$\gamma$ 在正极」写成开篇，后文 $\mathrm{A}/\mathrm{G}$ 和酶学诊断都没有底板。
:::

:::note{label="电子版缺失"}
本章开篇章题图电子版缺失，正文不嵌入该图。本节使用的插图是图26-1（血浆蛋白质的醋酸纤维素薄膜电泳图谱：染色区带与光密度扫描峰）。图26-2 起的血红素反应式在第二节。
:::

血液（blood）是流动于心血管系统内的液体组织，主要发挥运输物质的作用。正常人体的血液总量约占体重的 $8\%$，由血浆（plasma）、血细胞和血小板组成。血浆占全血容积的 $55\%\sim 60\%$。血液凝固后析出淡黄色透明液体，称作血清（serum）。

:::definition{label="血液"}
流动于心血管系统内的液体组织，主要发挥运输物质的作用。本版数字：总量约占体重 $8\%$，由血浆、血细胞和血小板组成。户头先落在「运输」和「三组分」，还不是「只有红细胞」。
:::

:::definition{label="血浆"}
全血去掉血细胞和血小板后剩下的液体部分。血浆占全血容积的 $55\%\sim 60\%$。抗凝后离心得到的就是这一户，里面还留着纤维蛋白原等凝血因子。
:::

:::definition{label="血清"}
血液凝固后析出的淡黄色透明液体。凝固过程消耗了纤维蛋白原等凝血成分，所以血清≠血浆。临床生化常测「血清酶」，名字沿用血清，并不等于标本里没有过血浆。
:::

:::compare{title="血浆 vs 血清"}
| | 怎么得到 | 还在不在的东西 | 不要写成 |
|--|---------|--------------|---------|
| 血浆 | 抗凝后离心 | 纤维蛋白原、多数凝血因子仍在 | 「血浆就是血清的另一个名字」 |
| 血清 | 血液凝固后析出 | 纤维蛋白原已变成纤维蛋白凝块，析出液里没有这一户 | 「血清里还有全部凝血因子」 |

问「抽血化验的黄水」先问这管血有没有让它凝固。凝固过的叫血清，抗凝离心的叫血浆。
:::

:::pitfall{label="血浆和血清不要并成一管"}
教材连着写两句：血浆占全血容积 $55\%\sim 60\%$；血液凝固后析出淡黄色透明液体称作血清。并成「血浆就是血清」，纤维蛋白原、凝血因子和后文「血浆蛋白质具有凝血作用」都会对不上。
:::

正常人血液的含水量约为 $77\%\sim 81\%$，比重为 $1.050\sim 1.060$，它主要取决于血液内的血细胞数和蛋白质的浓度。血液的 $\mathrm{pH}$ 为 $7.40\pm 0.05$，血浆渗透压在 $37\,^{\circ}\mathrm{C}$ 时接近 $7.70\times 10^{2}\,\mathrm{kPa}$，即 $300\,\mathrm{mOsm/kg\cdot H_2O}$。

:::keypoint{label="开篇六个数字先钉死"}
- 总量：约占体重 $8\%$。
- 血浆容积：占全血 $55\%\sim 60\%$。
- 含水量：$77\%\sim 81\%$。
- 比重：$1.050\sim 1.060$（主要取决于血细胞数和蛋白质浓度）。
- $\mathrm{pH}$：$7.40\pm 0.05$。
- 血浆渗透压：$37\,^{\circ}\mathrm{C}$ 接近 $7.70\times 10^{2}\,\mathrm{kPa}$，即 $300\,\mathrm{mOsm/kg\cdot H_2O}$。
:::

:::pitfall{label="不要用别的教材替换本版数字"}
有的书把血液占体重写成 $7\%\sim 8\%$，把血浆容积写成「约一半」，把渗透压只留 $300\,\mathrm{mOsm/L}$ 一个单位。本版是 $8\%$、$55\%\sim 60\%$、$77\%\sim 81\%$、$1.050\sim 1.060$、$7.40\pm 0.05$、$7.70\times 10^{2}\,\mathrm{kPa}$（$300\,\mathrm{mOsm/kg\cdot H_2O}$）。$\mathrm{pH}$ 的 $\pm 0.05$ 也不要改成 $\pm 0.1$。
:::

:::insight{label="比重先问血细胞和蛋白质，不要先问盐"}
教材写：比重主要取决于血液内的血细胞数和蛋白质的浓度。晶体离子决定的是晶体渗透压，那是后一句固体成分的账，不要把比重和渗透压并成「盐多就沉」。
:::

血浆的固体成分可分为无机物和有机物两大类。无机物主要以电解质为主，重要的阳离子有 $\mathrm{Na}^{+}$、$\mathrm{K}^{+}$、$\mathrm{Ca}^{2+}$、$\mathrm{Mg}^{2+}$，重要的阴离子有 $\mathrm{Cl}^{-}$、$\mathrm{HCO}_3^{-}$、$\mathrm{HPO}_4^{2-}$ 等，它们在维持血浆晶体渗透压、酸碱平衡以及神经肌肉的正常兴奋性等方面起重要作用。有机物包括蛋白质、非蛋白质类含氮化合物、糖类和脂质等。非蛋白质类含氮化合物主要有尿素、肌酸、肌酸酐、尿酸、胆红素和氨等，它们中的氮总量称为非蛋白质氮（non-protein nitrogen，$\mathrm{NPN}$）。正常人血中 $\mathrm{NPN}$ 含量为 $14.28\sim 24.99\,\mathrm{mmol/L}$。其中血尿素氮（blood urea nitrogen，$\mathrm{BUN}$）约占 $\mathrm{NPN}$ 的 $1/2$。

:::definition{label="血浆固体成分两户"}
无机物以电解质为主：阳离子 $\mathrm{Na}^{+}$、$\mathrm{K}^{+}$、$\mathrm{Ca}^{2+}$、$\mathrm{Mg}^{2+}$；阴离子 $\mathrm{Cl}^{-}$、$\mathrm{HCO}_3^{-}$、$\mathrm{HPO}_4^{2-}$。有机物包括蛋白质、非蛋白质类含氮化合物、糖类和脂质。电解质的职分是晶体渗透压、酸碱平衡和神经肌肉兴奋性，不是胶体渗透压。
:::

:::definition{label="非蛋白质氮 NPN"}
尿素、肌酸、肌酸酐、尿酸、胆红素和氨等非蛋白质类含氮化合物中的氮总量。正常人血中 $\mathrm{NPN}$ 为 $14.28\sim 24.99\,\mathrm{mmol/L}$。血尿素氮（$\mathrm{BUN}$）约占 $\mathrm{NPN}$ 的 $1/2$。户头是「蛋白质以外的氮」，不是「血液里全部的氮」。
:::

:::compare{title="晶体渗透压 vs 胶体渗透压（开篇先分户）"}
| | 主要贡献者 | 管什么 | 后文落点 |
|--|----------|------|---------|
| 晶体渗透压 | $\mathrm{Na}^{+}$、$\mathrm{Cl}^{-}$ 等电解质 | 细胞内外水的分布、神经肌肉兴奋性 | 开篇无机物那一句 |
| 胶体渗透压 | 血浆蛋白质，尤其是清蛋白 | 血管内外水的分布 | 功能第（一）小节；只占血浆总渗透压的 $1/230$ |

问「水肿为什么先查清蛋白」走胶体这一户；问「神经肌肉兴奋性」走晶体那一户。两户都叫渗透压，不要并。
:::

:::pitfall{label="BUN 约占 NPN 的 1/2，不是 NPN 的别名"}
$\mathrm{NPN}$ 名单里还有肌酸、肌酸酐、尿酸、胆红素和氨。写成「$\mathrm{NPN}$ 就是尿素氮」，后文肝病、痛风、黄疸各自的含氮小分子就没了户头。
:::

## 一、血浆蛋白质是血浆的主要固体成分

人血浆中蛋白质总浓度为 $60\sim 80\,\mathrm{g/L}$，它们是血浆主要的固体成分。血浆蛋白质种类很多，目前已知的血浆蛋白质有 $200$ 多种，其中既有单纯蛋白质又有结合蛋白质，如糖蛋白和脂蛋白，血浆中还有几千种抗体。血浆内各种蛋白质的含量差异很大，多者每升达数十克，少的仅为毫克水平。

:::definition{label="血浆蛋白质总浓度"}
$60\sim 80\,\mathrm{g/L}$，是血浆主要的固体成分。已知 $200$ 多种，外加几千种抗体。含量从每升数十克到毫克水平，不要把「种类多」写成「每一种都很多」。
:::

:::keypoint{label="固体成分里蛋白质是大户，但不是唯一户"}
- 总量：$60\sim 80\,\mathrm{g/L}$。
- 种类：单纯蛋白质、糖蛋白、脂蛋白；还有几千种抗体。
- 后文清蛋白 $40\sim 55\,\mathrm{g/L}$、球蛋白 $20\sim 30\,\mathrm{g/L}$，是把这一笔切开，不是另开一套单位。
:::

### （一）血浆蛋白质种类繁多

目前尚有多种血浆中的蛋白质的结构和功能尚不明确，故难以对血浆的全部蛋白质作出十分恰当的分类。通常按来源、分离方法和生理功能将血浆蛋白质进行分类。

血浆蛋白质依据功能，可分为以下 $8$ 类：①凝血系统蛋白质，包括 $12$ 种凝血因子（除 $\mathrm{Ca}^{2+}$ 外）；②纤溶系统蛋白质，包括纤溶酶原、纤溶酶、激活剂及抑制剂等；③补体系统蛋白质；④免疫球蛋白；⑤脂蛋白；⑥血浆蛋白酶抑制剂，包括酶原激活抑制剂、血液凝固抑制剂、纤溶酶抑制剂、激肽释放抑制剂、内源性蛋白酶及其他蛋白酶抑制剂；⑦载体蛋白；⑧未知功能的血浆蛋白质。

:::definition{label="按功能分的八类血浆蛋白质"}
凝血系统、纤溶系统、补体、免疫球蛋白、脂蛋白、血浆蛋白酶抑制剂、载体蛋白、未知功能。凝血因子写「$12$ 种（除 $\mathrm{Ca}^{2+}$ 外）」——$\mathrm{Ca}^{2+}$ 是因子Ⅳ，但不是蛋白质，不要塞进蛋白质名单。
:::

:::pitfall{label="八类是功能分类，不是电泳五条"}
功能八类和后文电泳五条区带是两套尺子。免疫球蛋白大部分落在 $\gamma$，但脂蛋白、补体、抑制剂会散在 $\alpha$、$\beta$。写成「$\gamma$＝八类里的抗体、其他四条各管一类」，表26-1 对不上。
:::

:::insight{label="未知功能这一类也要留着"}
教材把第八类写成「未知功能的血浆蛋白质」。分类写不完，不等于血浆里只有前七类。电泳、超速离心能分开的峰，功能不一定已经叫得出名字。
:::

电泳是最常用的分离蛋白质的方法。以 $\mathrm{pH}\,8.6$ 的巴比妥溶液作缓冲液，可将血浆蛋白质分成 $5$ 条区带：清蛋白（albumin，又称白蛋白）、$\alpha_1$ 球蛋白、$\alpha_2$ 球蛋白、$\beta$ 球蛋白和 $\gamma$ 球蛋白（图26-1、表26-1）。清蛋白是人体血浆中最主要的蛋白质，浓度达 $40\sim 55\,\mathrm{g/L}$，约占血浆总蛋白的 $60\%$。肝每天约合成 $12\,\mathrm{g}$ 清蛋白。清蛋白以前清蛋白（prealbumin）的形式合成，成熟的清蛋白是含 $585$ 个氨基酸残基的单一多肽链，分子形状呈椭圆形。球蛋白（globulin）的浓度为 $20\sim 30\,\mathrm{g/L}$。正常的清蛋白与球蛋白的比例（$\mathrm{A}/\mathrm{G}$）为 $1.5\sim 2.5$。血浆蛋白质电泳是临床常用的辅助诊断方法。

聚丙烯酰胺凝胶电泳是分辨率更高的电泳方法，可将血清中的蛋白质分成数十条区带。超速离心法则是根据蛋白质的密度将其分离，例如血浆脂蛋白的分离。

:::definition{label="醋酸纤维素薄膜电泳五条区带"}
缓冲液：$\mathrm{pH}\,8.6$ 的巴比妥溶液。从正极到负极依次为清蛋白、$\alpha_1$ 球蛋白、$\alpha_2$ 球蛋白、$\beta$ 球蛋白、$\gamma$ 球蛋白。图26-1（a）是染色图谱，（b）是光密度扫描峰。清蛋白在正极侧，负极侧是 $\gamma$。
:::

:::definition{label="清蛋白"}
又称白蛋白（albumin）。人体血浆中最主要的蛋白质，浓度 $40\sim 55\,\mathrm{g/L}$，约占血浆总蛋白的 $60\%$。肝每天约合成 $12\,\mathrm{g}$。以前清蛋白形式合成；成熟分子是 $585$ 个氨基酸残基的单一多肽链，椭圆形。临床上叫白蛋白，不要当成两种蛋白。
:::

:::definition{label="球蛋白与 A/G"}
球蛋白浓度 $20\sim 30\,\mathrm{g/L}$。本版表：正常 $\mathrm{A}/\mathrm{G}$ 为 $1.5\sim 2.5$。表26-1 的百分含量是醋酸纤维素薄膜电泳的参考区间，和「浓度 $\mathrm{g/L}$」是两本账，不要把 $62\%\sim 71\%$ 直接改写成 $62\sim 71\,\mathrm{g/L}$。
:::

:::pitfall{label="正极是清蛋白，负极侧才是 γ"}
$\mathrm{pH}\,8.6$ 高于多数血浆蛋白质的等电点（后文 $4.0\sim 7.3$），蛋白质带负电，向正极（阳极）泳动。清蛋白净负电荷多、分子量相对小，跑得最快，落在正极侧。$\gamma$ 球蛋白跑得最慢，靠近负极侧。写成「蛋白质带正电所以清蛋白在负极」，图26-1 左右就反了。
:::

:::pitfall{label="合成形式上的前清蛋白 ≠ 运输段的前清蛋白"}
「清蛋白以前清蛋白的形式合成」说的是清蛋白前体。后文维生素 $\mathrm{A}$ 运输里，视黄醇结合蛋白再与前清蛋白缔合成复合物，那一户是血浆里已经存在的前清蛋白（临床也叫前白蛋白）。肝病段「前清蛋白是肝功能损害的敏感指标」走的是后一户。三句话不要并成「清蛋白＝前清蛋白」。
:::

:::

### （二）血浆蛋白质是由不同种类细胞产生的分泌蛋白质

尽管血浆蛋白质的种类繁多，但由于血浆蛋白质较易获得，且许多编码血浆蛋白质的基因序列已知，故对这些蛋白质的结构、功能、合成和更新等已有较深入的了解。血浆蛋白质的性质可归纳为六条。

**1. 绝大多数血浆蛋白质在肝合成**　如清蛋白、纤维蛋白原和纤维粘连蛋白等血浆蛋白质都是在肝合成，还有少量的蛋白质是由其他组织细胞合成，如 $\gamma$ 球蛋白是由浆细胞合成。

:::definition{label="绝大多数血浆蛋白质在肝合成"}
清蛋白、纤维蛋白原、纤维粘连蛋白是肝合成的例子。$\gamma$ 球蛋白由浆细胞合成，是「少量由其他组织细胞合成」的代表。表26-1 把 $\gamma$ 的生成部位写成「主要在肝外」，与这一句是同一本账。
:::

:::pitfall{label="γ 球蛋白不要写进肝合成名单"}
「绝大多数」不是「全部」。肝硬化时球蛋白增加、$\mathrm{A}/\mathrm{G}$ 倒置，正是肝合成清蛋白减少、而浆细胞来的免疫球蛋白相对突出。写成「血浆蛋白都是肝做的」，后文肝疾病谱对不上。
:::

**2. 血浆蛋白质的合成场所一般位于膜结合的多核糖体上**　血浆蛋白质在进入血浆前，在肝细胞内经历了从粗面内质网到高尔基复合体再抵达质膜而分泌入血液的途径。即合成的蛋白质转移入内质网池，然后被酶切去信号肽，蛋白质前体成为成熟蛋白质。血浆蛋白质自肝细胞内合成部位到血浆的时间为 $30$ 分钟至数小时不等。

:::definition{label="分泌路径与信号肽"}
膜结合的多核糖体合成 → 转入内质网池 → 切去信号肽，前体变成熟 → 高尔基复合体 → 质膜 → 入血。从合成部位到血浆需 $30$ 分钟至数小时。户头是分泌蛋白，不是胞质游离核糖体做完就地使用的那一户。
:::

:::timeline{period="肝细胞把血浆蛋白送出血浆的路径"}
- **膜结合多核糖体** 合成进入分泌途径的多肽
- **内质网池** 转入后切去信号肽，前体成为成熟蛋白质
- **高尔基复合体** 加工（多数还要接糖链）
- **质膜** 分泌入血液
- **时间** 自合成部位到血浆约 30 分钟至数小时
:::

**3. 除清蛋白外，几乎所有的血浆蛋白质均为糖蛋白**　血浆蛋白质的糖链部分包含许多生物信息。例如，血浆蛋白质合成后需要定向输送，此过程需要 $\mathrm{N}$- 或 $\mathrm{O}$-连接的糖链。此外，红细胞的血型物质含糖达 $80\%\sim 90\%$，$\mathrm{ABO}$ 系统中血型物质 $\mathrm{A}$、$\mathrm{B}$ 均是在血型物质 $\mathrm{O}$ 的糖链非还原端各加上 $N$-乙酰半乳糖胺（$N$-acetylgalactosamine，$\mathrm{GalNAc}$）或半乳糖（galactose，$\mathrm{Gal}$）。正是一个糖基的差别，使红细胞能分别识别不同的抗体。某些血浆蛋白质糖链末端的唾液酸残基如被唾液酸酶（neuraminidase）切除，常可使这些血浆蛋白质的半衰期缩短。

:::definition{label="除清蛋白外几乎都是糖蛋白"}
清蛋白是少数不含糖链的血浆蛋白质。其余几乎都是糖蛋白。糖链承担定向输送等信息，需要 $\mathrm{N}$- 或 $\mathrm{O}$-连接。
:::

:::definition{label="ABO 血型物质差在一个糖基"}
红细胞血型物质含糖达 $80\%\sim 90\%$。物质 $\mathrm{A}$：在物质 $\mathrm{O}$ 糖链非还原端加上 $\mathrm{GalNAc}$；物质 $\mathrm{B}$：加上 $\mathrm{Gal}$。一个糖基的差别，使红细胞能分别识别不同的抗体。
:::

:::definition{label="切去唾液酸则半衰期缩短"}
糖链末端唾液酸被唾液酸酶切除后，这些血浆蛋白质的半衰期常缩短。肝细胞膜唾液酸酶和随后的溶酶体清除，第二十五章蛋白质段已经写过；本节只把「糖链末端唾液酸保寿命」立住。
:::

:::pitfall{label="清蛋白不是糖蛋白，不要把糖链功能安到清蛋白头上"}
定向输送、唾液酸、血型物质都是糖链的账。清蛋白维持胶体渗透压靠的是分子量和电负性，不是靠 $\mathrm{N}$-糖链。写成「血浆蛋白都靠糖链维持渗透压」，清蛋白这一户就空了。
:::

**4. 血浆蛋白质呈现多态性**　多态性是孟德尔式或单基因遗传的性状。在人群中，如果某一蛋白质具有多态性说明它至少有两种表型，每一种表型的发生率不少于 $1\%\sim 2\%$。$\mathrm{ABO}$ 血型抗原是广为人知的多态性，$\mathrm{ABO}$ 血型基因位于人类染色体 $9\mathrm{q}34$，有三个最主要的等位基因：$I^{\mathrm{A}}$（$\mathrm{A}$）、$I^{\mathrm{B}}$（$\mathrm{B}$）和 $i$（$\mathrm{O}$），这些等位基因的原初产物是糖基转移酶。$\mathrm{A}$ 基因编码 $N$-乙酰半乳糖胺转移酶，$\mathrm{B}$ 基因编码半乳糖转移酶，$\mathrm{O}$ 基因由于碱基缺失形成移码突变，表达产物无酶活性。$\mathrm{ABO}$ 基因单核苷酸多态性使糖基转移酶的催化结构域改变，其血型抗原呈多样性。另外 $\alpha_1$-抗胰蛋白酶、结合珠蛋白、运铁蛋白、铜蓝蛋白和免疫球蛋白等均具有多态性。研究血浆蛋白质的多态性对遗传学、人类学和临床医学均有重要意义。

:::definition{label="血浆蛋白质多态性"}
孟德尔式或单基因遗传性状。至少两种表型，每种发生率不少于 $1\%\sim 2\%$。例子：$\mathrm{ABO}$ 血型抗原、$\alpha_1$-抗胰蛋白酶、结合珠蛋白、运铁蛋白、铜蓝蛋白、免疫球蛋白。
:::

:::definition{label="ABO 三个等位基因编码的是糖基转移酶"}
基因位点 $9\mathrm{q}34$。$I^{\mathrm{A}}$ 编码 $N$-乙酰半乳糖胺转移酶，$I^{\mathrm{B}}$ 编码半乳糖转移酶，$i$（$\mathrm{O}$）碱基缺失导致移码，产物无酶活性。抗原多样性来自糖基转移酶催化结构域的改变，不是「直接编码血型多糖」。
:::

:::compare{title="血型物质 vs ABO 基因产物"}
| | 本版原句 | 差在哪里 |
|--|---------|---------|
| 血型物质 $\mathrm{A}/\mathrm{B}/\mathrm{O}$ | 多糖，含糖 $80\%\sim 90\%$ | 非还原端有没有 $\mathrm{GalNAc}$ 或 $\mathrm{Gal}$ |
| $\mathrm{A}/\mathrm{B}/\mathrm{O}$ 基因 | 原初产物是糖基转移酶 | 有没有酶、加哪一种糖 |

问「$\mathrm{O}$ 型为什么没有 A、B 抗原」——$\mathrm{O}$ 基因产物无酶活性，糖链停在物质 $\mathrm{O}$。不要答成「$\mathrm{O}$ 基因编码一种特殊的 O 糖」。
:::

**5. 每种血浆蛋白质均有自己特异的半衰期**　各种血浆蛋白质具有差异较大的半衰期，如正常成人的清蛋白和结合珠蛋白的半衰期分别为 $20$ 天和 $5$ 天左右。

:::definition{label="清蛋白与结合珠蛋白的半衰期"}
正常成人清蛋白约 $20$ 天，结合珠蛋白约 $5$ 天。半衰期短的变化出现得早，这是后文「前清蛋白是肝功能损害敏感指标」的底板之一。
:::

:::insight{label="清蛋白掉得慢，急性肝损伤先不要等 A/G"}
清蛋白半衰期约 $20$ 天，急性损伤时浓度往往还来不及掉到位。急性肝炎段写的是非典型急性时相和前清蛋白；$\mathrm{A}/\mathrm{G}$ 倒置更常出现在肝硬化等慢性过程。
:::

**6. 血浆蛋白质水平的改变往往与疾病紧密相关**　在急性炎症或组织损伤（如广泛性心肌梗死）等情况下，某些血浆蛋白质的水平会增高，它们被称为急性期蛋白（acute phase protein，$\mathrm{APP}$）。增高的蛋白质包括 $\mathrm{C}$ 反应蛋白（$\mathrm{C}$-reactive protein，$\mathrm{CRP}$）、$\alpha_1$-抗胰蛋白酶、结合珠蛋白、$\alpha_1$-酸性糖蛋白和纤维蛋白原等。这些蛋白质水平的增高，少则增加 $50\%$，多则可增加上千倍。患慢性炎症或肿瘤时，也会出现这种升高，提示急性期蛋白在人体炎症反应中起一定作用。例如，$\alpha_1$-抗胰蛋白酶能使急性炎症期释放的某些蛋白酶失效；白细胞介素 $1$（$\mathrm{IL}$-$1$）是单核巨噬细胞释放的一种多肽，它能刺激肝细胞合成许多急性期反应物（acute phase reactant，$\mathrm{APR}$）。急性期亦有些蛋白质浓度出现降低，如清蛋白和运铁蛋白等。

:::definition{label="急性期蛋白 APP"}
急性炎症或组织损伤（如广泛性心肌梗死）时水平增高的血浆蛋白质。名单：$\mathrm{CRP}$、$\alpha_1$-抗胰蛋白酶、结合珠蛋白、$\alpha_1$-酸性糖蛋白、纤维蛋白原。少则增加 $50\%$，多则可增加上千倍。慢性炎症或肿瘤也可升高。
:::

:::definition{label="IL-1 刺激肝合成急性期反应物"}
白细胞介素 $1$ 是单核巨噬细胞释放的多肽，能刺激肝细胞合成许多急性期反应物（$\mathrm{APR}$）。$\alpha_1$-抗胰蛋白酶则使急性炎症期释放的某些蛋白酶失效。升高不是「随便涨」，有的是在灭活过量蛋白酶。
:::

:::definition{label="负性急性期蛋白"}
急性期有些蛋白质浓度降低，如清蛋白和运铁蛋白。只记 $\mathrm{CRP}$ 升高，会漏掉「有的蛋白在急性期是下降的」。
:::

:::compare{title="急性期升高 vs 急性期降低"}
| | 本版点名 | 不要写成 |
|--|---------|---------|
| 升高（$\mathrm{APP}$） | $\mathrm{CRP}$、$\alpha_1$-抗胰蛋白酶、结合珠蛋白、$\alpha_1$-酸性糖蛋白、纤维蛋白原 | 「急性期所有血浆蛋白都升高」 |
| 降低 | 清蛋白、运铁蛋白 | 「清蛋白下降只见于肝硬化，与急性期无关」 |

风湿病活动期会再碰到 $\alpha_1$-酸性糖蛋白、触珠蛋白、补体 $\mathrm{C}3$。触珠蛋白与结合珠蛋白是同一类结合血红蛋白的蛋白在不同段落的用名，不要拆成两种无关的球蛋白。
:::

:::cause-effect{title="组织损伤 → 肝被 IL-1 叫醒 → APP 升高"}
广泛性心肌梗死等组织损伤 → 单核巨噬细胞释放 $\mathrm{IL}$-$1$ → 肝细胞合成 $\mathrm{APR}$ → 血浆 $\mathrm{CRP}$ 等升高。户头在肝的合成被诱导，不是损伤组织自己把 $\mathrm{CRP}$ 漏进血。
:::

## 二、血浆蛋白质具有重要功能

血浆蛋白质种类繁多，虽然其中不少蛋白质的功能尚未完全阐明，但对血浆蛋白质的一些重要功能已有较深入的了解。下面按八项摊开。

### （一）血浆蛋白质维持血浆胶体渗透压

虽然血浆胶体渗透压仅占血浆总渗透压的极小部分（$1/230$），但它对水在血管内外的分布具有决定性的作用。正常人血浆胶体渗透压的大小，取决于血浆蛋白质的摩尔浓度。由于清蛋白的分子量小（$66\,\mathrm{kDa}$），在血浆内的总含量大、摩尔浓度高，加之在生理 $\mathrm{pH}$ 条件下，其电负性高，能使水分子聚集其分子表面，故清蛋白能最有效地维持胶体渗透压。清蛋白所产生的胶体渗透压占血浆胶体总渗透压的 $75\%\sim 80\%$。当血浆蛋白质浓度，尤其是清蛋白浓度过低时，血浆胶体渗透压下降，导致水分在组织间隙潴留，出现水肿。

:::definition{label="胶体渗透压占血浆总渗透压的 1/230"}
比例极小，但对水在血管内外的分布具有决定性作用。大小取决于血浆蛋白质的摩尔浓度，不是「克数越大贡献越大」一句话能代替的——还要看分子量。
:::

:::definition{label="清蛋白最有效地维持胶体渗透压"}
三条理由一起答：分子量小（$66\,\mathrm{kDa}$）；总含量大、摩尔浓度高；生理 $\mathrm{pH}$ 下电负性高，水分子聚集其表面。贡献占血浆胶体总渗透压的 $75\%\sim 80\%$。清蛋白过低 → 胶体渗透压下降 → 组织间隙潴留水分 → 水肿。
:::

:::keypoint{label="清蛋白为什么「最有效」"}
- 分子小 → 同样质量下摩尔数多。
- 含量高 → 摩尔浓度再乘一个大系数。
- 电负性高 → 表面聚水，有效渗透粒子更多。
- 结果：$75\%\sim 80\%$ 的胶体渗透压来自清蛋白，不是来自「球蛋白总量也不少」。
:::

:::pitfall{label="1/230 不是说胶体渗透压可以忽略"}
教材先写「极小部分（$1/230$）」，紧接着写「对水在血管内外的分布具有决定性的作用」。晶体渗透压管细胞内外，胶体管血管内外。写成「只占 $1/230$ 所以水肿与蛋白无关」，后文肝硬化腹水就没有生化机制。
:::

:::cause-effect{title="清蛋白过低 → 水肿"}
清蛋白浓度过低 → 血浆胶体渗透压下降 → 水分在组织间隙潴留 → 水肿。第二十五章还给出低于 $30\,\mathrm{g/L}$ 约半数出现水肿或腹水；本章把机制落在胶体渗透压这一户。
:::

### （二）血浆蛋白质维持血浆正常的 pH

正常血浆的 $\mathrm{pH}$ 为 $7.40\pm 0.05$。蛋白质是两性电解质，血浆蛋白质的等电点大部分在 $\mathrm{pH}\,4.0\sim 7.3$ 之间，血浆蛋白盐与相应蛋白质形成缓冲对，参与维持血浆正常的 $\mathrm{pH}$，如蛋白质钠盐／蛋白质是血浆中的主要缓冲对之一。

:::definition{label="血浆蛋白缓冲对"}
等电点大部分在 $\mathrm{pH}\,4.0\sim 7.3$，生理 $\mathrm{pH}\,7.40\pm 0.05$ 下蛋白质带净负电荷，与蛋白质钠盐组成缓冲对。蛋白质钠盐／蛋白质是血浆主要缓冲对之一。开篇 $\mathrm{HCO}_3^{-}$ 那一户是另一套缓冲，不要并成「只有碳酸氢盐」。
:::

:::insight{label="等电点 4.0～7.3 同时解释了电泳方向"}
生理 $\mathrm{pH}$ 和电泳用的 $\mathrm{pH}\,8.6$ 都高于这一等电点区间，所以血浆蛋白质带负电、向正极泳动。缓冲能力和电泳图谱是同一条带电性质的两面。
:::

### （三）血浆蛋白质具有运输作用

血浆蛋白质分子的表面上分布有众多的亲脂性结合位点，脂溶性物质可与其结合而被运输。血浆蛋白质还能与易被细胞摄取和易随尿液排出的一些小分子物质结合，防止它们从肾丢失。例如，脂溶性维生素 $\mathrm{A}$ 以视黄醇形式存在于血浆中，它先与视黄醇结合蛋白形成复合物，再与前清蛋白以非共价键缔合成视黄醇–视黄醇结合蛋白–前清蛋白复合物。这种复合物一方面可防止视黄醇的氧化，另一方面防止小分子量的视黄醇–视黄醇结合蛋白复合物从肾丢失。血浆中的清蛋白能与脂肪酸、$\mathrm{Ca}^{2+}$、胆红素、磺胺等多种物质结合。此外血浆中还有皮质激素传递蛋白、运铁蛋白、铜蓝蛋白、载脂蛋白等。这些载体蛋白除结合运输血浆中某种物质外，还具有调节被运输物质代谢的作用。

:::definition{label="运输的两层意思"}
①亲脂性结合位点运脂溶性物质；②与易被细胞摄取、易随尿排出的小分子结合，防止从肾丢失。不是「只运脂肪」。
:::

:::definition{label="视黄醇的三重复合物"}
维生素 $\mathrm{A}$ 以视黄醇形式在血浆中，先与视黄醇结合蛋白结合，再与前清蛋白非共价缔合成视黄醇–视黄醇结合蛋白–前清蛋白复合物。作用两条：防氧化；防小分子复合物从肾丢失。视黄醇结合蛋白由肝合成，第二十五章维生素段已经点名。
:::

:::definition{label="清蛋白的配基名单"}
脂肪酸、$\mathrm{Ca}^{2+}$、胆红素、磺胺等多种物质。胆红素在这里只是配基，代谢展开不在本章。清蛋白是非特异性载体；皮质激素传递蛋白、运铁蛋白、铜蓝蛋白、载脂蛋白是相对特异的载体，还调节被运物质的代谢。
:::

:::compare{title="非特异载体 vs 特异载体"}
| | 本版点名 | 还干什么 |
|--|---------|---------|
| 清蛋白 | 脂肪酸、$\mathrm{Ca}^{2+}$、胆红素、磺胺 | 同时维持胶体渗透压 |
| 视黄醇结合蛋白＋前清蛋白 | 视黄醇 | 防氧化、防肾丢失 |
| 皮质激素传递蛋白、运铁蛋白、铜蓝蛋白、载脂蛋白 | 各自的配基 | 调节被运输物质代谢 |

问「胆红素靠谁运」先答清蛋白；问「铁靠谁运」答运铁蛋白。不要把所有配基都塞给清蛋白。
:::

:::pitfall{label="三重复合物的前清蛋白不是清蛋白前体"}
这一句里的前清蛋白是血浆里已经存在、与视黄醇结合蛋白缔合的那一户。写成「视黄醇必须先变成清蛋白才能运输」，维生素 $\mathrm{A}$ 和清蛋白两本账就绞在一起。
:::

### （四）抗体和补体具有免疫作用

血浆中的免疫球蛋白，$\mathrm{IgG}$、$\mathrm{IgA}$、$\mathrm{IgM}$、$\mathrm{IgD}$ 和 $\mathrm{IgE}$，又称为抗体，在体液免疫中起至关重要的作用。此外，血浆中还有一组协助抗体完成免疫功能的蛋白酶——补体。免疫球蛋白能识别特异性抗原并与之结合，形成的抗原抗体复合物能激活补体系统，产生溶菌和溶细胞现象。

:::definition{label="免疫球蛋白五类"}
$\mathrm{IgG}$、$\mathrm{IgA}$、$\mathrm{IgM}$、$\mathrm{IgD}$、$\mathrm{IgE}$，又称为抗体。电泳上主要落在 $\gamma$ 区带，由浆细胞合成。体液免疫的户头在这一户，细胞免疫不是本节的账。
:::

:::definition{label="补体"}
一组协助抗体完成免疫功能的蛋白酶。抗原抗体复合物激活补体系统，产生溶菌和溶细胞现象。补体是蛋白酶，不是另一种抗体。
:::

:::cause-effect{title="抗原抗体复合物 → 激活补体 → 溶菌溶细胞"}
免疫球蛋白识别并结合特异性抗原 → 复合物激活补体 → 溶菌和溶细胞。抗体负责识别，补体负责把识别变成裂解。写成「抗体自己把细菌溶解」，补体这一户就没了。
:::

### （五）血清酶具有催化作用

血浆中的酶称作血清酶。根据血清酶的来源和功能，可分为以下三类。

**1. 血浆功能酶**　这类酶主要在血浆发挥催化功能，如凝血及纤溶系统的多种蛋白水解酶，它们都以酶原的形式存在于血浆内，在一定条件下被激活后发挥作用。此外血浆中还有生理性抗凝物质、假性胆碱酯酶、卵磷脂：胆固醇酰基转移酶、脂蛋白脂肪酶和肾素等。血浆功能酶绝大多数由肝合成后分泌入血，并在血浆中发挥催化作用。

:::definition{label="血清酶"}
血浆中的酶称作血清酶。名字沿用血清，分类按来源和功能分成血浆功能酶、外分泌酶、细胞酶三类。三类不要并成「转氨酶」一项。
:::

:::definition{label="血浆功能酶"}
主要在血浆发挥催化功能。凝血及纤溶系统的多种蛋白水解酶以酶原形式存在，激活后才工作。还包括生理性抗凝物质、假性胆碱酯酶、卵磷脂：胆固醇酰基转移酶（$\mathrm{LCAT}$）、脂蛋白脂肪酶和肾素等。绝大多数由肝合成后分泌入血，就在血浆中催化。
:::

:::pitfall{label="血浆功能酶绝大多数由肝合成，不是「酶都从损伤细胞漏出来」"}
功能酶的户头是「本来就该在血浆里干活」。肝合成、入血、在血浆催化。写成「酶活性升高＝细胞坏死」，凝血酶原、$\mathrm{LCAT}$、脂蛋白脂肪酶就没有正常生理位置。
:::

**2. 外分泌酶**　外分泌腺分泌的酶类包括胃蛋白酶、胰蛋白酶、胰淀粉酶、胰脂肪酶和唾液淀粉酶等。在生理条件下这些酶少量逸入血浆，它们的催化活性与血浆的正常生理功能无直接的关系。但当这些脏器受损时，逸入血浆的酶量增加，血浆内相关酶的活性增高，在临床上有诊断价值。

:::definition{label="外分泌酶"}
外分泌腺分泌的酶：胃蛋白酶、胰蛋白酶、胰淀粉酶、胰脂肪酶、唾液淀粉酶等。生理条件下少量逸入血浆，催化活性与血浆的正常生理功能无直接关系。脏器受损时逸入量增加，才有诊断价值。
:::

:::pitfall{label="逸入血浆的外分泌酶不是血浆的正常功能"}
教材原句：催化活性与血浆的正常生理功能无直接的关系。胰淀粉酶升高说明胰腺可能受损，不说明血浆需要靠胰淀粉酶消化淀粉。把外分泌酶写成血浆功能酶，三类就并了。
:::

**3. 细胞酶**　细胞酶存在于细胞和组织内，参与物质代谢。随着细胞的不断更新，这些酶可释放至血。正常时它们在血浆中含量甚微。这类酶大部分无器官特异性；小部分来源于特定的组织，表现为器官特异性。当特定的器官有病变时，血浆内相应的酶活性增高，可用于临床酶学检验。如肝功能严重受损时，血浆中谷丙转氨酶与谷草转氨酶的活性会显著升高。

:::definition{label="细胞酶"}
存在于细胞和组织内，参与物质代谢。细胞更新时可释放入血，正常时血浆中含量甚微。大部分无器官特异性；小部分有器官特异性。特定器官病变时相应酶活性增高，用于临床酶学检验。本版例子：肝功能严重受损时谷丙转氨酶与谷草转氨酶显著升高。
:::

:::compare{title="血清酶三类"}
| | 本来在哪干活 | 与血浆正常功能 | 升高常常说明什么 |
|--|------------|--------------|----------------|
| 血浆功能酶 | 就在血浆（多为酶原） | 直接有关；绝大多数肝合成后入血 | 合成／激活／消耗失衡；不是「细胞漏出来」这一户 |
| 外分泌酶 | 外分泌腺（胃、胰、唾液腺） | 无直接关系，生理时少量逸入 | 相应脏器受损 |
| 细胞酶 | 细胞内代谢 | 正常时甚微 | 细胞更新或器官病变；部分有器官特异性（如转氨酶与肝） |

问「转氨酶为什么能反映肝损伤」走细胞酶；问「$\mathrm{LCAT}$ 是谁做的」走血浆功能酶；问「血淀粉酶」走外分泌酶。
:::

:::insight{label="假性胆碱酯酶、LCAT、脂蛋白脂肪酶、肾素都算血浆功能酶"}
这四户容易被误记成「组织漏出酶」。教材把它们和凝血纤溶酶原并列，写在血浆功能酶里。$\mathrm{LCAT}$ 由肝合成、在血浆酯化胆固醇，第二十五章脂质段已经用过；本节把它的身份钉成血浆功能酶。
:::

### （六）血浆蛋白质为组织提供营养

每个成人 $3\,\mathrm{L}$ 左右的血浆中约有 $200\,\mathrm{g}$ 蛋白质。体内的某些细胞，如单核–吞噬细胞系统，吞噬血浆蛋白质，然后由细胞内的酶类将吞入细胞的蛋白质分解为氨基酸进入氨基酸池，用于组织蛋白质的合成，或转变成其他含氮化合物。此外，蛋白质还能分解供能。

:::definition{label="成人血浆蛋白库"}
约 $3\,\mathrm{L}$ 血浆中约有 $200\,\mathrm{g}$ 蛋白质。单核–吞噬细胞系统吞噬后分解为氨基酸，进入氨基酸池，用于合成组织蛋白质或转变成其他含氮化合物，也能分解供能。
:::

:::pitfall{label="200 g 不是每天从饮食直接灌进血浆的量"}
这是循环中的蛋白存量。清蛋白每天肝合成约 $12\,\mathrm{g}$，是更新量。存量、日合成量、电泳百分数三笔不要并。
:::

### （七）血浆蛋白质具有凝血、抗凝血和纤溶作用

血浆中存在众多的凝血因子、抗凝血及纤溶物质，它们在血液中相互作用、相互制约，保持循环血流通畅。但当血管损伤、血液流出血管时，即发生凝血反应，封堵损伤部位，以防止血液的大量流失。

:::definition{label="凝血、抗凝、纤溶相互制约"}
正常时保持循环血流通畅；血管损伤、血液流出血管时启动凝血，封堵损伤部位。功能酶里的酶原激活，落在这一句的「一定条件」。抗凝和纤溶不是「多余的反面教材」，是通畅循环的另一半。
:::

:::compare{title="通畅 vs 封堵"}
| 状态 | 血浆蛋白在干什么 | 缺了会怎样 |
|------|----------------|-----------|
| 血管完整 | 抗凝、纤溶与凝血因子相互制约，血流通畅 | 血栓 |
| 血管损伤、血流出管 | 凝血反应封堵 | 出血 |

严重肝细胞损伤时凝血因子合成减少，第二十五章写成凝血时间延长及出血倾向。本节只把「多数凝血因子是血浆蛋白质」立住。
:::

### （八）多种疾病可导致血浆蛋白质异常

血浆蛋白质在维持人体正常代谢中有重要功能，血浆蛋白质异常可见于多种临床疾病，如风湿病、肝疾病和多发性骨髓瘤等。

**1. 风湿病**　风湿病血浆蛋白质的异常改变主要包括急性炎症反应和由于抗原刺激引起的免疫系统增强的反应。其特征为：①免疫球蛋白升高，特别是 $\mathrm{IgA}$，并可有 $\mathrm{IgG}$ 及 $\mathrm{IgM}$ 的升高；②炎症活动期可有 $\alpha_1$-酸性糖蛋白、触珠蛋白、补体 $\mathrm{C}3$ 蛋白成分升高。

:::definition{label="风湿病的血浆蛋白改变"}
两本账：急性炎症反应；抗原刺激引起的免疫增强。免疫球蛋白升高，特别是 $\mathrm{IgA}$，也可有 $\mathrm{IgG}$、$\mathrm{IgM}$。活动期 $\alpha_1$-酸性糖蛋白、触珠蛋白、补体 $\mathrm{C}3$ 升高。
:::

**2. 肝疾病**　急性肝炎时，出现非典型的急性时相反应，前清蛋白是肝功能损害的敏感指标。肝硬化时，血浆蛋白质含量呈现特征性改变，如清蛋白减少、球蛋白增加，清蛋白／球蛋白（$\mathrm{A}/\mathrm{G}$）倒置等。

:::definition{label="肝疾病的血浆蛋白改变"}
急性肝炎：非典型急性时相反应，前清蛋白是肝功能损害的敏感指标。肝硬化：清蛋白减少、球蛋白增加，$\mathrm{A}/\mathrm{G}$ 倒置。急性看前清蛋白，慢性看清蛋白和 $\mathrm{A}/\mathrm{G}$，不要并成「肝病都是 $\mathrm{A}/\mathrm{G}$ 倒置」。
:::

**3. 多发性骨髓瘤**　多发性骨髓瘤是由浆细胞恶性增生所致的一种肿瘤。总的蛋白质电泳图谱表现为：①在原 $\gamma$ 区带外出现一特征性的 $\mathrm{M}$ 蛋白峰；②清蛋白区带下降。

:::definition{label="多发性骨髓瘤的电泳"}
浆细胞恶性增生。电泳：原 $\gamma$ 区带外出现特征性 $\mathrm{M}$ 蛋白峰；清蛋白区带下降。$\mathrm{M}$ 峰是单克隆免疫球蛋白或其片段，不是「$\gamma$ 区带整体均匀升高」。
:::

:::compare{title="三种病怎么改电泳和 A/G"}
| | 免疫球蛋白／球蛋白 | 清蛋白／前清蛋白 | 画面要点 |
|--|------------------|----------------|---------|
| 风湿病 | $\mathrm{IgA}$ 为主，可有 $\mathrm{IgG}$、$\mathrm{IgM}$ 升高 | 活动期还有 $\mathrm{APP}$ 升高 | 免疫增强＋急性炎症 |
| 急性肝炎 | 非典型急性时相 | 前清蛋白敏感下降 | 不要等 $\mathrm{A}/\mathrm{G}$ 倒置才想到肝 |
| 肝硬化 | 球蛋白增加 | 清蛋白减少，$\mathrm{A}/\mathrm{G}$ 倒置 | 肝合成清蛋白少，浆细胞来的球蛋白相对多 |
| 多发性骨髓瘤 | 原 $\gamma$ 区带外 $\mathrm{M}$ 蛋白峰 | 清蛋白区带下降 | 单克隆峰，不是多克隆弥漫升高 |

问「$\mathrm{M}$ 蛋白」必须答浆细胞恶性增生和 $\gamma$ 区带外的特征峰。
:::

:::pitfall{label="M 蛋白峰不要画进正常 γ 的位置就算完"}
教材写「在原 $\gamma$ 区带外出现」。可以紧挨着 $\gamma$，但是特征是多出一窄而高的单克隆峰，再加清蛋白区带下降。把正常 $\gamma$ 峰画高一点，风湿病的多克隆升高和骨髓瘤就分不开。
:::

:::memory{label="本节必背分户"}
- 血液约占体重 $8\%$；血浆占全血容积 $55\%\sim 60\%$；含水量 $77\%\sim 81\%$；比重 $1.050\sim 1.060$；$\mathrm{pH}\,7.40\pm 0.05$；$37\,^{\circ}\mathrm{C}$ 血浆渗透压接近 $7.70\times 10^{2}\,\mathrm{kPa}$（$300\,\mathrm{mOsm/kg\cdot H_2O}$）。
- 血浆≠血清：血清是凝固后析出的淡黄色透明液体。
- $\mathrm{NPN}$ $14.28\sim 24.99\,\mathrm{mmol/L}$，$\mathrm{BUN}$ 约占 $1/2$。
- 血浆蛋白 $60\sim 80\,\mathrm{g/L}$；清蛋白 $40\sim 55\,\mathrm{g/L}$（约 $60\%$，肝每天约 $12\,\mathrm{g}$，$585$ 残基，$66\,\mathrm{kDa}$）；球蛋白 $20\sim 30\,\mathrm{g/L}$；$\mathrm{A}/\mathrm{G}$ $1.5\sim 2.5$。
- 电泳 $\mathrm{pH}\,8.6$ 巴比妥：正极清蛋白 → $\alpha_1$ → $\alpha_2$ → $\beta$ → 负极侧 $\gamma$。图26-1、表26-1。
- $\gamma$ 球蛋白主要由浆细胞合成；除清蛋白外几乎都是糖蛋白。
- $\mathrm{ABO}$：基因 $9\mathrm{q}34$，产物是糖基转移酶；$\mathrm{O}$ 基因移码，无酶活性。
- 清蛋白半衰期约 $20$ 天，结合珠蛋白约 $5$ 天。$\mathrm{APP}$：$\mathrm{CRP}$ 等升高；清蛋白、运铁蛋白可降。
- 胶体渗透压仅占血浆总渗透压 $1/230$，清蛋白贡献其中 $75\%\sim 80\%$。
- 血清酶三类：血浆功能酶绝大多数由肝合成，就在血浆催化；外分泌酶逸入与血浆正常功能无直接关系；细胞酶正常甚微，损伤时升高。
- 肝硬化 $\mathrm{A}/\mathrm{G}$ 倒置；骨髓瘤原 $\gamma$ 区带外 $\mathrm{M}$ 蛋白峰。
:::

:::keypoint{label="本节不写的两本账"}
血红素的原料、线粒体／胞质分工和 $\mathrm{ALA}$ 合酶是第二节。成熟红细胞只靠糖无氧氧化获能、$2,3$-$\mathrm{BPG}$ 和谷胱甘肽是第三节。本节只把血浆蛋白质的种类、电泳和功能立住。
:::
