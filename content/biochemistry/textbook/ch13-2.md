# 第二节　真核基因组的结构与功能

第一节把单个真核基因写成断裂的编码区加调控区。本节把镜头拉到一整套基因组：原核与真核怎么不同、人基因组编码序列只占 $1.5\%$、重复序列占一半以上、多基因家族和假基因、独立于染色体外的 $\mathrm{mtDNA}$ 与叶绿体 $\mathrm{DNA}$、人染色体上基因如何非均匀分布。染色体大小示意图（图13-6）属于本节，电子版裁图缺失，不把第三节开头的这段正文留在基因组学里。作图、鸟枪法和组学仍交给第三节。

:::concept{term="先问编码序列占多少、再问重复序列、基因家族和核外基因组"}
看见“基因组”，先不要跳到 $\mathrm{HGP}$ 四张图。户头是：一套完整单体的遗传信息怎么排。真核编码区比例远小于原核；人编码序列约占全基因组 $1.5\%$，一个基因里编码序列约占 $5\%$。重复序列、多基因家族、假基因、$\mathrm{mtDNA}$ $16\,569\,\mathrm{bp}$／$37$ 个基因、染色体非均匀分布，都是本节的账。
:::

病毒、原核生物以及真核生物所贮存的遗传信息量有着巨大的差别，其基因组的结构与组织形式上也各有特点，包括基因组中基因的组织排列方式以及基因的种类、数目和分布等。

原核生物的基因组结构相对简单，其结构特点如下：①通常仅由一条环状双链 $\mathrm{DNA}$ 组成；②基因组中只有一个复制起点，具有操纵子结构（见第十七章）；③基因通常是连续的，没有内含子；④基因组中重复序列很少，编码蛋白质的结构基因多为单拷贝基因；⑤基因组中具有多种功能的识别区域，如复制起始区、复制终止区、转录启动区和终止区等；⑥基因组中存在可移动的 $\mathrm{DNA}$ 序列，包括插入序列和转座子等。

真核生物基因组较复杂，其结构基因的数量远多于原核生物基因组中的数量，但编码区在基因组中所占的比例远小于原核生物基因组中的比例。人类基因组中，编码序列仅占全基因组的 $1.5\%$；在一个基因的全部序列中，编码序列仅占 $5\%$。大约 $60\%$ 的人基因转录后发生可变剪接，$80\%$ 的可变剪接会使蛋白质的序列发生改变。真核基因组 $\mathrm{DNA}$ 与蛋白质结合形成染色体，储存于细胞核内，除配子细胞外，体细胞的基因组为二倍体（diploid），即有两份同源的基因组。人类基因组包含了细胞核染色体 $\mathrm{DNA}$（常染色体和性染色体）及线粒体 $\mathrm{DNA}$ 所携带的所有遗传信息，其组成如图13-4 所示。

:::definition{label="原核基因组的六条"}
①通常一条环状双链 $\mathrm{DNA}$；②一个复制起点，有操纵子；③基因通常连续、无内含子；④重复序列很少，编码蛋白质的结构基因多为单拷贝；⑤有复制起止、转录起止等多种识别区；⑥有可移动 $\mathrm{DNA}$（插入序列、转座子等）。
:::

:::definition{label="真核基因组相对于原核的反差"}
结构基因数量远多于原核，但编码区在基因组中所占比例远小于原核。人：编码序列占全基因组 $1.5\%$；占一个基因全部序列的 $5\%$。$\mathrm{DNA}$ 与蛋白质结合成染色体，储于细胞核；体细胞（除配子外）为二倍体。
:::

:::definition{label="二倍体"}
二倍体（diploid）即有两份同源的基因组。教材限定：除配子细胞外，体细胞的基因组为二倍体。
:::

:::definition{label="人基因的可变剪接比例"}
大约 $60\%$ 的人基因转录后发生可变剪接；$80\%$ 的可变剪接会使蛋白质的序列发生改变。第一节“同一基因可编码不同多肽”在这里落成两个人类基因组数字。
:::

:::compare{title="原核基因组 vs 真核基因组"}
| 项目 | 原核 | 真核（人） |
|------|------|------------|
| $\mathrm{DNA}$ 形态 | 通常一条环状双链 | 线性染色体 $+$ 环状 $\mathrm{mtDNA}$ |
| 复制起点 | 一个 | 多个（本节不展开机制） |
| 操纵子 | 有 | 典型真核基因单独转录 |
| 内含子 | 通常无 | 绝大多数编码蛋白基因有（组蛋白例外） |
| 重复序列 | 很少 | 人基因组 $50\%$ 以上 |
| 编码区比例 | 相对高 | 全基因组仅 $1.5\%$；单基因内约 $5\%$ |
| 储存 | 拟核 | 与蛋白质结合成染色体，在细胞核 |
| 倍性 | — | 体细胞二倍体（配子除外） |

结构基因数量真核更多，编码区比例真核更小。复杂不是靠“把基因组填满编码序列”。
:::

:::pitfall{label="基因多不等于编码序列占比高"}
真核结构基因数量远多于原核，但编码区比例更小。把“更复杂”听成“编码序列占得更多”，图13-4 的 $1.5\%$ 外显子和后面的重复序列、内含子都变成累赘。思考题第 $4$ 问专门挡这条。
:::

:::insight{label="1.5% 和 5% 不是同一分母"}
$1.5\%$：编码序列占**全基因组**。$5\%$：编码序列占**一个基因的全部序列**（该基因自己的外显子／内含子账）。图13-4 把核基因组里“编码蛋白基因序列”写成约 $27.4\%$（外显子约 $1.5\%$ $+$ 内含子约 $25.9\%$），$1.5/(1.5+25.9)$ 约合教材所说单基因编码序列约占 $5\%$。分母一换，百分比不能直接比。
:::

::figure{src="/images/biochemistry/textbook/p0276_01.png" caption="图13-4　人的基因组构成。人类基因组分为细胞核基因组（3 100 Mb）和线粒体基因组（16.6 kb）。核基因组中编码蛋白基因序列约 27.4%（外显子约 1.5%，内含子约 25.9%），基因外序列约 72.6%（基因间序列与中度至高度重复序列）。线粒体基因组含 2 个 rRNA 基因、22 个 tRNA 基因、13 个蛋白编码基因。" alt="人基因组树状图：核 3100 Mb 分编码基因序列与基因外序列，线粒体 16.6 kb 含 2 个 rRNA、22 个 tRNA、13 个蛋白基因"}

:::keypoint{label="图13-4 必须能默写的分户"}
- 人基因组 $=$ 核基因组 $3\,100\,\mathrm{Mb}$ $+$ 线粒体基因组 $16.6\,\mathrm{kb}$。
- 核：编码蛋白基因序列约 $27.4\%$ ＝ 外显子约 $1.5\%$ $+$ 内含子约 $25.9\%$；基因外约 $72.6\%$。
- 线粒体：$2$ 个 $\mathrm{rRNA}$ 基因、$22$ 个 $\mathrm{tRNA}$ 基因、$13$ 个蛋白编码基因（与后文 $37$ 个基因、$16\,569\,\mathrm{bp}$ 同账）。
:::

:::pitfall{label="3100 Mb 不要和 16.6 kb 当成同一数量级"}
核基因组 $3\,100\,\mathrm{Mb}$，线粒体 $16.6\,\mathrm{kb}$。后者就是 $16\,569\,\mathrm{bp}$ 的另一种写法。把 $\mathrm{mtDNA}$ 听成“也有几千兆碱基”，核外基因组的“小而独立”就丢了。
:::

## 一、真核基因组中存在大量重复序列

真核细胞基因组存在着大量重复序列，人基因组中，重复序列占基因组长度的 $50\%$ 以上。重复序列的长度不等，短的仅含两个碱基，长的多达数百乃至上千个碱基。重复序列的重复频率也不尽相同，可以分为高度重复序列（highly repetitive sequence）、中度重复序列（moderately repetitive sequence）和单拷贝序列（single copy sequence）或低度重复序列等 $3$ 种。

:::definition{label="重复序列占人基因组一半以上"}
人基因组中重复序列占基因组长度的 $50\%$ 以上。长度从两个碱基到数百乃至上千个碱基不等。按重复频率分为高度重复、中度重复、单拷贝（低度重复）三类。
:::

:::compare{title="三类按重复频率分，不要按“有没有功能”先分"}
| 类型 | 重复频率（本版） | 人基因组中的大致份额 |
|------|------------------|------------------------|
| 高度重复序列 | $10^{3}\sim 10^{7}$ | 约占 $20\%$ |
| 中度重复序列 | $10\sim 10^{4}$ | 人约 $20\%$；种属间 $10\%\sim 40\%$ |
| 单拷贝／低度重复 | 单拷贝或很低 | 大多数编码蛋白质的基因在这里 |

高度重复正文另写拷贝数为数千到几百万，与 $10^{3}\sim 10^{7}$ 一致。中度是数十至数千次，与 $10\sim 10^{4}$ 一致。
:::

### （一）高度重复序列的重复频率为 $10^{3}\sim 10^{7}$

高度重复序列是真核基因组中存在的有数千到几百万个拷贝的 $\mathrm{DNA}$ 重复序列。这些重复序列的长度为 $5\sim 500\,\mathrm{bp}$，不编码蛋白质或 $\mathrm{RNA}$。在人基因组中，高度重复序列约占基因组长度的 $20\%$。高度重复序列按其结构特点分为反向重复序列（inverted repeat sequence）和卫星 $\mathrm{DNA}$（satellite $\mathrm{DNA}$）。

前者由两个相同顺序的互补拷贝在同一 $\mathrm{DNA}$ 链上反向排列而成，反向重复的单位长度约为 $300\,\mathrm{bp}$ 或略短，其总长度约占人基因组的 $5\%$，多数是散在，而非群集于基因组中。卫星 $\mathrm{DNA}$ 是真核细胞染色体具有的高度重复核苷酸序列，主要存在于染色体的着丝粒区，通常不被转录，在人基因组中可占 $10\%$ 以上。由于其碱基组成中 $\mathrm{GC}$ 含量少，具有不同的浮力密度，在氯化铯密度梯度离心后呈现出与大多数 $\mathrm{DNA}$ 有差别的“卫星”条带而得名。

高度重复序列的功能主要是：①参与复制水平的调节。反向重复序列常存在于 $\mathrm{DNA}$ 复制起点区的附近，是一些蛋白质（包括酶）的结合位点。②参与基因表达的调控。高度重复序列可以转录到核内不均一 $\mathrm{RNA}$ 分子中，而有些反向重复序列可以形成发夹结构，有助于稳定 $\mathrm{RNA}$ 分子。③参与染色体配对。如 $\alpha$ 卫星 $\mathrm{DNA}$ 成簇样分布在染色体着丝粒附近，可能与染色体减数分裂时染色体配对有关。

:::definition{label="高度重复序列"}
真核基因组中有数千到几百万个拷贝（重复频率 $10^{3}\sim 10^{7}$）的 $\mathrm{DNA}$ 重复序列。长度 $5\sim 500\,\mathrm{bp}$，不编码蛋白质或 $\mathrm{RNA}$。人基因组中约占 $20\%$。按结构分为反向重复序列和卫星 $\mathrm{DNA}$。
:::

:::definition{label="反向重复序列"}
由两个相同顺序的互补拷贝在同一 $\mathrm{DNA}$ 链上反向排列而成。单位长度约 $300\,\mathrm{bp}$ 或略短，总长度约占人基因组 $5\%$，多数散在而非群集。可在复制起点附近作为蛋白质（包括酶）的结合位点；有些可形成发夹，有助于稳定 $\mathrm{RNA}$。
:::

:::definition{label="卫星 DNA"}
真核细胞染色体上的高度重复核苷酸序列，主要在着丝粒区，通常不被转录，人基因组中可占 $10\%$ 以上。因 $\mathrm{GC}$ 含量少、浮力密度不同，氯化铯密度梯度离心时出现与大多数 $\mathrm{DNA}$ 有差别的“卫星”条带而得名。$\alpha$ 卫星 $\mathrm{DNA}$ 成簇分布在着丝粒附近，可能与减数分裂时染色体配对有关。
:::

:::keypoint{label="高度重复序列的三项功能"}
- 复制水平调节：反向重复常在复制起点附近，是蛋白质／酶的结合位点。
- 基因表达调控：可转录进核内不均一 $\mathrm{RNA}$；反向重复可成发夹，稳定 $\mathrm{RNA}$。
- 染色体配对：$\alpha$ 卫星 $\mathrm{DNA}$ 在着丝粒附近成簇。
:::

:::pitfall{label="卫星 DNA 的“卫星”不是染色体卫星"}
名字来自氯化铯离心时多出来的条带，因为 $\mathrm{GC}$ 少、浮力密度不同。不要把它听成细胞生物学里那根“染色体卫星／随体”。位置在着丝粒区，通常不转录，占人基因组 $10\%$ 以上。
:::

:::pitfall{label="高度重复序列不是“垃圾，所以没有功能”"}
教材明确不编码蛋白质或 $\mathrm{RNA}$，但立刻写了复制调节、表达调控、染色体配对三条功能。把“不编码”等同于“无功能”，这三条会没处放。
:::

:::compare{title="反向重复 vs 卫星 DNA"}
| | 反向重复序列 | 卫星 $\mathrm{DNA}$ |
|--|----------------|-------------------|
| 排列 | 同一链上反向的互补拷贝；多数散在 | 着丝粒区成簇 |
| 单位长度 | 约 $300\,\mathrm{bp}$ 或略短 | 高度重复，本段未另给单位长度 |
| 占人基因组 | 约 $5\%$ | $10\%$ 以上 |
| 转录 | 可进核内不均一 $\mathrm{RNA}$；可成发夹 | 通常不被转录 |
| 功能侧重 | 复制起点附近结合蛋白；稳定 $\mathrm{RNA}$ | 着丝粒、减数分裂配对 |

二者合计约合高度重复约占 $20\%$ 这一档，不要把 $5\%$ 和 $10\%$ 以上当成中度重复的数字。
:::

### （二）中度重复序列的重复频率为 $10\sim 10^{4}$

中度重复序列指在真核基因组中重复数十至数千次的核苷酸序列，通常占整个单倍体基因组的 $1\%\sim 30\%$。少数在基因组中成串排列在一个区域，大多数与单拷贝基因间隔排列。依据重复序列的长度，中度重复序列可分为以下两种类型。

:::definition{label="中度重复序列"}
重复数十至数千次（频率 $10\sim 10^{4}$）的核苷酸序列，通常占单倍体基因组 $1\%\sim 30\%$。少数成串排在一个区域，大多数与单拷贝基因间隔排列。人基因组中约占 $20\%$；不同种属一般约占 $10\%\sim 40\%$。大多不编码蛋白质，功能可能类似于高度重复序列。
:::

**1. 短散在核元件**　短散在核元件（short interspersed nuclear elements，$\mathrm{SINEs}$）又称为短散在重复序列（short interspersed repeat sequence），是以散在方式分布于基因组中的较短重复序列，平均长度约为 $70\sim 300\,\mathrm{bp}$，与平均长度约为 $1\,000\,\mathrm{bp}$ 的单拷贝序列间隔排列，拷贝数可达数十万。

$\mathrm{Alu}$ 家族是哺乳类动物，包括人基因组中含量最丰富的短散在重复序列，平均每 $6\,\mathrm{kb}\,\mathrm{DNA}$ 就有一个 $\mathrm{Alu}$ 序列，在单倍体人基因组中重复约 $50$ 万次，约占人基因组的 $10\%$。$\mathrm{Alu}$ 家族每个成员的长度约 $300\,\mathrm{bp}$，由于每个单位长度中有一个限制性核酸内切酶 $\mathrm{Alu}$ 的切点（$\mathrm{AG}{\downarrow}\mathrm{CT}$），将其切成长 $130\,\mathrm{bp}$ 和 $170\,\mathrm{bp}$ 的两段，因而命名为 $\mathrm{Alu}$ 序列（或 $\mathrm{Alu}$ 家族）。

:::definition{label="SINEs"}
短散在核元件（$\mathrm{SINEs}$）又称短散在重复序列：以散在方式分布的较短重复序列，平均长度约 $70\sim 300\,\mathrm{bp}$，与平均约 $1\,000\,\mathrm{bp}$ 的单拷贝序列间隔排列，拷贝数可达数十万。
:::

:::definition{label="Alu 家族"}
哺乳类（包括人）基因组中含量最丰富的短散在重复序列。平均每 $6\,\mathrm{kb}\,\mathrm{DNA}$ 一个 $\mathrm{Alu}$ 序列；单倍体人基因组重复约 $50$ 万次，约占人基因组 $10\%$。每个成员约 $300\,\mathrm{bp}$，因有限制酶 $\mathrm{Alu}$ 切点 $\mathrm{AG}{\downarrow}\mathrm{CT}$，切成 $130\,\mathrm{bp}$ 和 $170\,\mathrm{bp}$ 两段而得名。
:::

**2. 长散在核元件**　长散在核元件（long interspersed nuclear elements，$\mathrm{LINEs}$）又称为长散在重复序列（long interspersed repeat sequence），以散在方式分布于基因组中的较长的重复序列，重复序列长度约为 $6\,000\sim 7\,000\,\mathrm{bp}$，常具有转座活性。

:::definition{label="LINEs"}
长散在核元件（$\mathrm{LINEs}$）又称长散在重复序列：散在分布的较长重复序列，长度约 $6\,000\sim 7\,000\,\mathrm{bp}$，常具有转座活性。
:::

中度重复序列在基因组中所占比例在不同种属之间差异很大，一般约占 $10\%\sim 40\%$，在人的基因组中约为 $20\%$。这些序列大多不编码蛋白质，其功能可能类似于高度重复序列。

真核生物基因组中的 $\mathrm{rRNA}$ 基因也属于中度重复序列。与其他中度重复序列不同，各重复单位中的 $\mathrm{rRNA}$ 基因都是相同的。$\mathrm{rRNA}$ 基因通常集中成簇存在，而不是分散于基因组中，这样的区域称为 $\mathrm{rDNA}$ 区，如染色体的核仁组织区（nucleolus organizer region）即为 $\mathrm{rDNA}$ 区。人类的 $\mathrm{rRNA}$ 基因位于 $13$、$14$、$15$、$21$ 和 $22$ 号染色体的核仁组织区，每个核仁组织区平均含有 $50$ 个 $\mathrm{rRNA}$ 基因的重复单位；$5\mathrm{S}\,\mathrm{rRNA}$ 基因几乎全部位于 $1$ 号染色体（$1\mathrm{q}42$-$43$）上，每个单倍体基因组约有 $1\,000$ 个 $5\mathrm{S}\,\mathrm{rRNA}$ 基因。此外，真核生物基因组中的 $\mathrm{tRNA}$ 基因也属于中度重复序列。

:::definition{label="rRNA 基因属于中度重复序列"}
各重复单位中的 $\mathrm{rRNA}$ 基因都相同，通常成簇而非分散，该区域称为 $\mathrm{rDNA}$ 区。染色体的核仁组织区即为 $\mathrm{rDNA}$ 区。人：$\mathrm{rRNA}$ 基因在 $13$、$14$、$15$、$21$、$22$ 号染色体核仁组织区，每区平均 $50$ 个重复单位；$5\mathrm{S}\,\mathrm{rRNA}$ 几乎全在 $1\mathrm{q}42$-$43$，单倍体约 $1\,000$ 个。$\mathrm{tRNA}$ 基因也属中度重复序列。
:::

:::compare{title="SINEs、LINEs、rRNA 基因：同属中度重复，排法不同"}
| | 长度／拷贝 | 排列 | 人基因组要点 |
|--|------------|------|----------------|
| $\mathrm{SINEs}$ | $70\sim 300\,\mathrm{bp}$，可达数十万拷贝 | 散在，与约 $1\,000\,\mathrm{bp}$ 单拷贝间隔 | $\mathrm{Alu}$：每 $6\,\mathrm{kb}$ 一个，约 $50$ 万次，约 $10\%$；$300\,\mathrm{bp}$，切成 $130+170$ |
| $\mathrm{LINEs}$ | $6\,000\sim 7\,000\,\mathrm{bp}$ | 散在 | 常有转座活性 |
| $\mathrm{rRNA}$ 基因 | 中度重复，各单位相同 | 成簇，在 $\mathrm{rDNA}$／核仁组织区 | $13/14/15/21/22$ 号，每区平均 $50$ 个；$5\mathrm{S}$ 在 $1\mathrm{q}42$-$43$，约 $1\,000$ 个 |

“散在”对 $\mathrm{SINEs}/\mathrm{LINEs}$；“成簇”对 $\mathrm{rRNA}$ 基因。不要把 $\mathrm{Alu}$ 写成核仁组织区里的基因。
:::

:::pitfall{label="Alu 因酶得名，不是“编码 Alu 酶的基因”"}
限制酶 $\mathrm{Alu}$ 识别 $\mathrm{AG}{\downarrow}\mathrm{CT}$，把约 $300\,\mathrm{bp}$ 的单位切成 $130\,\mathrm{bp}$ 和 $170\,\mathrm{bp}$，所以叫 $\mathrm{Alu}$ 序列。它是短散在重复，不按编码蛋白质的结构基因来背。每 $6\,\mathrm{kb}$ 一个、$50$ 万拷贝、$10\%$ 基因组，是本版必须留下的三个数。
:::

:::pitfall{label="5S rRNA 不要和 18S/28S 写在同一串染色体上"}
$13$、$14$、$15$、$21$、$22$ 号核仁组织区是（成簇的）$\mathrm{rRNA}$ 基因；$5\mathrm{S}\,\mathrm{rRNA}$ 几乎全部在 $1$ 号染色体 $1\mathrm{q}42$-$43$。第一节Ⅲ类启动子已经把 $5\mathrm{S}$ 从Ⅰ类 $\mathrm{rRNA}$ 里分开，本节染色体定位再分一次。
:::

:::insight{label="中度重复大多不编码，但 rRNA/tRNA 基因是例外性的“相同重复”"}
一般中度重复大多不编码蛋白质，功能可能像高度重复。$\mathrm{rRNA}$、$\mathrm{tRNA}$ 基因也归中度重复，但各单位相同、成簇、明确编码 $\mathrm{RNA}$。分类按拷贝数，不按“有没有基因产物”。
:::

### （三）单拷贝序列属于低度重复序列

单拷贝序列又称低度重复序列，大多数编码蛋白质的基因属于这一类。在基因组中，单拷贝序列的两侧往往为散在分布的重复序列。单拷贝序列编码的蛋白质在很大程度上体现了生物的各种功能，因此针对这些序列的研究对医学实践有特别重要的意义。近年来，人们发现微 $\mathrm{RNA}$（microRNA，$\mathrm{miRNA}$）和长非编码 $\mathrm{RNA}$（long non-coding $\mathrm{RNA}$，$\mathrm{lncRNA}$）的序列也是单一序列。此外，单一序列还包括一些无（或未知）功能的序列，以及突变的基因或假基因。

:::definition{label="单拷贝序列"}
单拷贝序列又称低度重复序列。大多数编码蛋白质的基因属于这一类；两侧往往是散在重复序列。所编码的蛋白质在很大程度上体现生物的各种功能，对医学实践特别重要。
:::

:::definition{label="也落在单一序列里的非蛋白质基因"}
$\mathrm{miRNA}$ 和 $\mathrm{lncRNA}$ 的序列也是单一序列。此外还包括一些无（或未知）功能的序列，以及突变的基因或假基因。
:::

:::pitfall{label="单拷贝不是“全是编码蛋白质的基因”"}
大多数编码蛋白质的基因在这一类，但单一序列还包括 $\mathrm{miRNA}$、$\mathrm{lncRNA}$、无／未知功能序列、突变基因或假基因。把单拷贝听成“结构基因名单”，假基因会和下一节冲突。
:::

:::keypoint{label="重复序列这一节的人基因组份额"}
- 重复序列合计：$50\%$ 以上。
- 高度重复：约 $20\%$（反向重复约 $5\%$；卫星 $\mathrm{DNA}$ $10\%$ 以上）。
- 中度重复：人约 $20\%$（$\mathrm{Alu}$ 约占 $10\%$）。
- 其余才轮到单拷贝／低度重复和基因外其他序列。
:::

## 二、真核基因组中存在大量的多基因家族与假基因

基因组中存在的许多来源于同一个祖先，结构和功能均相似的一组基因。这一组基因就构成了一个基因家族。同一家族的这些基因的外显子具有相关性。多基因家族（multigene family）是真核基因组的另一结构特点，是指由某一祖先基因经过重复和变异所产生的一组在结构上相似、功能上相关的基因。在细菌或病毒基因组中，$80\%$ 以上的基因是具有独特结构或功能的基因，但在人的基因组中，这类基因不足 $20\%$。

:::definition{label="基因家族"}
来源于同一个祖先、结构和功能均相似的一组基因。同一家族的外显子具有相关性。
:::

:::definition{label="多基因家族"}
多基因家族（multigene family）由某一祖先基因经过重复和变异产生，一组在结构上相似、功能上相关的基因。这是真核基因组的另一结构特点。
:::

:::insight{label="人基因组里“独特基因”不足 20%"}
细菌或病毒：$80\%$ 以上的基因具有独特结构或功能。人：这类基因不足 $20\%$。也就是说，人基因组更多是家族、重复、相似模块，而不是“每个基因都独一无二”。这和编码序列只占 $1.5\%$、重复序列过半是同一张图的不同切面。
:::

多基因家族大致可分为两类：一类是基因家族成簇地分布在某一条染色体上，它们可同时发挥作用，合成某些蛋白质，如组蛋白基因家族就成簇地集中在第 $7$ 号染色体长臂 $3$ 区 $2$ 带到 $3$ 区 $6$ 带区域内。另一类是一个基因家族的不同成员成簇地分布于不同染色体上，这些不同成员编码一组功能上紧密相关的蛋白质，如人类珠蛋白基因家族分为 $\alpha$ 珠蛋白和 $\beta$ 珠蛋白两个基因簇，$\alpha$ 珠蛋白基因簇、$\beta$ 珠蛋白基因簇分别位于第 $16$ 号和第 $11$ 号染色体。

一些 $\mathrm{DNA}$ 序列相似，但功能不一定相关的若干个单拷贝基因或若干组基因家族可以被归为基因超家族（superfamily gene），例如免疫球蛋白基因超家族、$\mathrm{ras}$ 基因超家族。一个多基因家族中可有多个基因，根据结构与功能的不同又可以分为亚家族（subfamily），例如 $\mathrm{G}$ 蛋白中属 $\mathrm{ras}$ 超家族约有 $50$ 多个成员，根据其序列同源性程度又可进一步分为 $\mathrm{Ras}$、$\mathrm{Rho}$ 和 $\mathrm{Rab}$ 三个主要的亚家族。

:::definition{label="两类多基因家族的染色体分布"}
一类成簇分布在某一条染色体上，可同时发挥作用，如组蛋白基因家族集中在 $7\mathrm{q}32$-$7\mathrm{q}36$。另一类不同成员成簇分布于不同染色体，编码功能紧密相关的蛋白质，如人 $\alpha$ 珠蛋白基因簇在第 $16$ 号染色体、$\beta$ 珠蛋白基因簇在第 $11$ 号染色体。
:::

:::definition{label="基因超家族与亚家族"}
基因超家族（superfamily gene）：$\mathrm{DNA}$ 序列相似、功能不一定相关的若干单拷贝基因或若干组基因家族，如免疫球蛋白基因超家族、$\mathrm{ras}$ 基因超家族。亚家族（subfamily）按结构与功能再分：$\mathrm{ras}$ 超家族约 $50$ 多个成员，按序列同源性分为 $\mathrm{Ras}$、$\mathrm{Rho}$、$\mathrm{Rab}$ 三个主要亚家族。
:::

:::compare{title="家族、超家族、亚家族一层套一层"}
| 层级 | 关系 | 本版例子 |
|------|------|----------|
| 多基因家族 | 共同祖先，结构相似、功能相关 | 组蛋白（成簇在 $7\mathrm{q}32$-$36$）；珠蛋白（$\alpha$ 在 $16$ 号、$\beta$ 在 $11$ 号） |
| 超家族 | 序列相似，功能不一定相关 | 免疫球蛋白；$\mathrm{ras}$ |
| 亚家族 | 超家族／家族内再按同源性分 | $\mathrm{ras}$ 超家族 $\rightarrow\mathrm{Ras}$、$\mathrm{Rho}$、$\mathrm{Rab}$（约 $50$ 多个成员） |
:::

:::pitfall{label="超家族不是“功能一定相同的更大家庭”"}
教材写明：序列相似，**功能不一定相关**。免疫球蛋白和 $\mathrm{ras}$ 只是两个例子，不要把超家族答成“功能更相关的多基因家族”。多基因家族强调功能相关；超家族强调序列相似。
:::

:::pitfall{label="珠蛋白两个簇不要写到同一条染色体"}
$\alpha$ 在 $16$ 号，$\beta$ 在 $11$ 号。组蛋白才是“一条染色体上成簇”。两类分布是分类标准，不是同一家族的两种画法可以随便换。
:::

人的基因组中存在假基因（pseudogene），以 $\psi$ 来表示。假基因是基因组中存在的一段与正常基因非常相似但一般不能表达的 $\mathrm{DNA}$ 序列。假基因根据其来源分为已加工假基因和非加工假基因 $2$ 种类型，前者没有内含子，后者含有内含子。这类基因可能曾经有过功能，但在进化中获得一个或几个突变，造成了序列上的细微改变从而阻碍了正常的转录和翻译功能，使它们不能再编码 $\mathrm{RNA}$ 和蛋白质产物。

人们推测，已加工假基因的来源可能是基因转录生成的成熟 $\mathrm{mRNA}$ 经逆转录生成 $\mathrm{cDNA}$，再整合到染色体 $\mathrm{DNA}$ 中去，便有可能成为假基因。已加工假基因通常缺少正常基因表达所需的调节序列，没有内含子，可能有 $\mathrm{poly}(\mathrm{A})$ 尾。非加工假基因来源于基因组 $\mathrm{DNA}$ 复制时基因 $\mathrm{DNA}$ 序列重复或染色体发生交叉互换过程产生的假基因，是基因组进化过程中功能基因发生突变产生的失活产物。非加工假基因常位于有功能的相同基因拷贝附近，与其具有类似的结构，含有内含子。人基因组中大约有 $2$ 万个假基因，其中约 $2\,000$ 个为核糖体蛋白的假基因。近些年发现，假基因也表达有功能的非编码 $\mathrm{RNA}$（non-coding $\mathrm{RNA}$，$\mathrm{ncRNA}$）。

:::definition{label="假基因"}
假基因（pseudogene）以 $\psi$ 表示，是与正常基因非常相似但一般不能表达的 $\mathrm{DNA}$ 序列。可能曾经有功能，进化中获得突变，阻碍正常转录和翻译，不能再编码 $\mathrm{RNA}$ 和蛋白质。人基因组大约 $2$ 万个，其中约 $2\,000$ 个为核糖体蛋白假基因。近些年发现假基因也表达有功能的 $\mathrm{ncRNA}$。
:::

:::definition{label="已加工假基因"}
没有内含子。来源推测：成熟 $\mathrm{mRNA}$ 逆转录成 $\mathrm{cDNA}$，再整合到染色体。通常缺少正常表达所需调节序列，可能有 $\mathrm{poly}(\mathrm{A})$ 尾。
:::

:::definition{label="非加工假基因"}
含有内含子。来源于 $\mathrm{DNA}$ 复制时的基因重复，或染色体交叉互换；是功能基因突变失活的产物。常位于有功能的相同基因拷贝附近，结构类似。
:::

:::compare{title="两种假基因"}
| | 已加工 | 非加工 |
|--|--------|--------|
| 内含子 | 无 | 有 |
| 来源 | 成熟 $\mathrm{mRNA}\rightarrow\mathrm{cDNA}\rightarrow$ 整合 | 基因重复或交叉互换后突变失活 |
| 调节序列 | 通常缺 | 结构类似附近的功能拷贝 |
| 其他痕迹 | 可能有 $\mathrm{poly}(\mathrm{A})$ 尾 | 常在有功能拷贝附近 |
:::

:::pitfall{label="“一般不能表达”不是“永远没有任何转录物”"}
定义写一般不能表达、不能再编码 $\mathrm{RNA}$ 和蛋白质产物。同一段后文又写：近些年发现假基因也表达有功能的 $\mathrm{ncRNA}$。考试默写仍先答“与正常基因相似、一般不能表达”；不要据此把 $2$ 万个假基因全部改写成蛋白质编码基因。
:::

:::insight{label="已加工假基因没有内含子，因为它来自已经剪过的 mRNA"}
成熟 $\mathrm{mRNA}$ 已经没有内含子，逆转录得到的 $\mathrm{cDNA}$ 整合回去，自然也不带内含子，还可能带着 $\mathrm{poly}(\mathrm{A})$ 尾巴。这是用第一节断裂基因反过来读进化痕迹：假基因的“连续”，恰恰证明祖先基因曾经被剪接过。
:::

## 三、真核基因组存在独立于染色体外的基因组

线粒体普遍存在于植物细胞和动物细胞的细胞质中，是细胞内的一种重要细胞器，是生物氧化的场所，一个细胞可拥有数百至上千个线粒体。线粒体 $\mathrm{DNA}$（mitochondrial $\mathrm{DNA}$，$\mathrm{mtDNA}$）的结构与原核生物 $\mathrm{DNA}$ 的结构类似，是环状分子。并不是所有的真核细胞均有线粒体，如蛔虫成虫阶段体细胞内没有线粒体；植物根系根部顶端的根冠细胞，是一层高度木质化的细胞，其细胞内没有线粒体，只有少部分根冠细胞会有少量的线粒体。线粒体基因组能够单独进行复制、转录及合成蛋白质，但这并不意味着线粒体基因组的遗传完全不受核基因的控制。线粒体自身结构和生命活动都需要核基因的参与并受其控制。

人的线粒体基因组全长 $16\,569\,\mathrm{bp}$，共编码 $37$ 个基因（图13-5），包括 $13$ 个编码构成呼吸链多酶体系的一些多肽的基因、$22$ 个编码 $\mathrm{mt}$-$\mathrm{tRNA}$ 的基因、$2$ 个编码 $\mathrm{mt}$-$\mathrm{rRNA}$（$16\mathrm{S}$ 和 $12\mathrm{S}$）的基因。

:::definition{label="线粒体 DNA"}
线粒体 $\mathrm{DNA}$（$\mathrm{mtDNA}$）结构与原核生物 $\mathrm{DNA}$ 类似，为环状分子。线粒体是生物氧化的场所，一个细胞可有数百至上千个线粒体。$\mathrm{mtDNA}$ 能单独复制、转录及合成蛋白质，但自身结构和生命活动仍需核基因参与并受其控制。
:::

:::definition{label="人线粒体基因组"}
全长 $16\,569\,\mathrm{bp}$，共编码 $37$ 个基因：$13$ 个呼吸链多酶体系多肽、$22$ 个 $\mathrm{mt}$-$\mathrm{tRNA}$、$2$ 个 $\mathrm{mt}$-$\mathrm{rRNA}$（$16\mathrm{S}$ 和 $12\mathrm{S}$）。图13-4 写成 $16.6\,\mathrm{kb}$，与此同账。
:::

- $13$：呼吸链多酶体系的多肽。
- $22$：$\mathrm{mt}$-$\mathrm{tRNA}$。
- $2$：$\mathrm{mt}$-$\mathrm{rRNA}$，明确是 $16\mathrm{S}$ 和 $12\mathrm{S}$。
- 全长 $16\,569\,\mathrm{bp}$。不要把核基因组的两万基因抄到线粒体上。
:::

:::pitfall{label="mtDNA 能独立复制不等于“不受核基因控制”"}
教材连续两句：能够单独复制、转录及合成蛋白质；**并不意味着**遗传完全不受核基因控制。线粒体自身结构和生命活动都需要核基因参与并受其控制。把内共生残留听成“完全独立的第二套基因组”，核编码的呼吸链亚基会没处放。
:::

:::pitfall{label="不是所有真核细胞都有线粒体"}
点名例外：蛔虫成虫阶段体细胞没有线粒体；植物根冠高度木质化细胞没有线粒体，只有少部分根冠细胞会有少量线粒体。不要把“普遍存在于植物和动物细胞”写成“每一个真核细胞必有”。
:::

:::insight{label="mtDNA 像原核：环状、编码密度高"}
与核基因组 $1.5\%$ 编码序列相反，人 $\mathrm{mtDNA}$ $16\,569\,\mathrm{bp}$ 就装下 $37$ 个基因，而且是环状。这和“结构与原核生物 $\mathrm{DNA}$ 类似”一致。第十章呼吸链的若干多肽，户头有一部分写在这 $13$ 个基因上。
:::

叶绿体是植物细胞中由双层膜围成且含有叶绿素能进行光合作用的细胞器。叶绿体间质中悬浮有由膜囊构成的类囊体，内含叶绿体 $\mathrm{DNA}$（chloroplast $\mathrm{DNA}$，$\mathrm{cpDNA}$）。高等植物叶绿体的 $\mathrm{DNA}$ 为双链闭合环状分子，其长度随生物种类的不同而不同，约为 $120\sim 217\,\mathrm{kb}$，相当于噬菌体基因组的大小，每个叶绿体中通常有十几个拷贝。叶绿体具有独立基因组，被认为是内共生起源的细胞器。叶绿体基因组 $\mathrm{DNA}$ 主要用于编码与光合作用密切相关的一些蛋白质和一些核糖体蛋白。叶绿体基因组同线粒体基因组一样，都是细胞里相对独立的一个遗传系统。叶绿体基因组可以自主地进行复制，但同时需要细胞核遗传系统提供遗传信息。并不是所有的植物细胞中都含有叶绿体。

:::definition{label="叶绿体 DNA"}
叶绿体 $\mathrm{DNA}$（$\mathrm{cpDNA}$）在类囊体内。高等植物为双链闭合环状，长约 $120\sim 217\,\mathrm{kb}$（相当于噬菌体基因组大小），每个叶绿体通常十几个拷贝。主要编码与光合作用密切相关的蛋白质和一些核糖体蛋白。可自主复制，同时需要细胞核遗传系统提供遗传信息。被认为是内共生起源。
:::

:::compare{title="mtDNA 和 cpDNA 都是相对独立的核外基因组"}
| | 人 $\mathrm{mtDNA}$ | 高等植物 $\mathrm{cpDNA}$ |
|--|-------------------|--------------------------|
| 形态 | 环状 | 双链闭合环状 |
| 大小 | $16\,569\,\mathrm{bp}$（$16.6\,\mathrm{kb}$） | $120\sim 217\,\mathrm{kb}$ |
| 拷贝 | 每细胞数百至上千个线粒体 | 每个叶绿体通常十几个拷贝 |
| 编码侧重 | $13$ 个呼吸链多肽 $+22\,\mathrm{tRNA}+2\,\mathrm{rRNA}$ | 光合作用相关蛋白、一些核糖体蛋白 |
| 与核的关系 | 能单独复制／转录／翻译，但受核基因控制 | 可自主复制，需核遗传系统提供信息 |
| 并非人人／细胞都有 | 蛔虫成虫、部分根冠细胞可无线粒体 | 并非所有植物细胞都含叶绿体 |
:::

## 四、人的染色体基因组包含绝大多数基因

真核生物基因组 $\mathrm{DNA}$ 与蛋白质结合，以染色体的方式存在于细胞核内。不同的真核生物具有不同的染色体数目（表13-1）。

:::definition{label="染色体是核基因组的存在方式"}
真核基因组 $\mathrm{DNA}$ 与蛋白质结合，以染色体方式存在于细胞核内。人的绝大多数基因在这些染色体上，但不是均匀分布。
:::

:::note{label="表13-1　不同生物体基因组的比较"}

### 1. 人的绝大多数基因在染色体上非均匀分布

人类基因组的染色体包括 $22$ 对常染色体及 $1$ 对性染色体，不同染色体的大小在 $46\sim 249\,\mathrm{Mb}$ 之间（图13-6）。其中，最长的染色体是第 $1$ 号染色体，约 $248.96\,\mathrm{Mb}$，含有 $5\,485$ 个确定的基因；最小的是第 $21$ 号染色体，约 $46.71\,\mathrm{Mb}$，含有 $679$ 个基因（资料来源：$\mathrm{NCBI}$ 基因组数据库，截至 $2023.09.10$）。一些遗传性疾病如阿尔茨海默病、肌萎缩性侧索硬化症和唐氏综合征等的相关基因，均位于第 $21$ 号染色体。

:::note{label="电子版缺失"}
图13-6　人染色体大小示意图：电子版图源 `p0280_01.png` 为 $0$ 字节，不嵌入 `src`。正文保留图号。数字以教材为准：各染色体 $46\sim 249\,\mathrm{Mb}$；第 $1$ 号约 $248.96\,\mathrm{Mb}$、$5\,485$ 个确定基因；第 $21$ 号约 $46.71\,\mathrm{Mb}$、$679$ 个基因。
:::

人基因在染色体上并不是均匀分布。其中基因密度最大的是第 $19$ 号染色体，平均每百万碱基有 $42$ 个基因；密度最小的是 $\mathrm{Y}$ 染色体，平均每百万碱基只有将近 $10$ 个基因。人基因组中存在无基因的“沙漠区”，即在 $500\,\mathrm{kb}$ 区域内，没有任何蛋白质编码基因的序列。这种“沙漠区”约占人基因组的 $20\%$。这种基因分布是如何形成的、有何意义，目前尚不清楚。

:::definition{label="人染色体组成与大小"}
$22$ 对常染色体 $+1$ 对性染色体。大小 $46\sim 249\,\mathrm{Mb}$。最长：第 $1$ 号，约 $248.96\,\mathrm{Mb}$，$5\,485$ 个确定基因。最小：第 $21$ 号，约 $46.71\,\mathrm{Mb}$，$679$ 个基因。阿尔茨海默病、肌萎缩性侧索硬化症、唐氏综合征等相关基因位于 $21$ 号。
:::

:::definition{label="基因密度与基因沙漠"}
基因密度（gene density）是每 $\mathrm{Mb}$ 长度序列中的平均基因数。人：第 $19$ 号最大，平均每百万碱基 $42$ 个基因；$\mathrm{Y}$ 染色体最小，将近 $10$ 个基因。沙漠区：连续 $500\,\mathrm{kb}$ 内没有任何蛋白质编码基因，约占人基因组 $20\%$。如何形成、有何意义，目前尚不清楚。
:::

:::compare{title="最长、最小、最密、最疏不要并到同一条染色体"}
| 指标 | 本版 |
|------|------|
| 最长 | 第 $1$ 号，$248.96\,\mathrm{Mb}$，$5\,485$ 基因 |
| 最小 | 第 $21$ 号，$46.71\,\mathrm{Mb}$，$679$ 基因 |
| 密度最大 | 第 $19$ 号，$42$ 个基因／$\mathrm{Mb}$ |
| 密度最小 | $\mathrm{Y}$ 染色体，将近 $10$ 个基因／$\mathrm{Mb}$ |
| 沙漠区 | $500\,\mathrm{kb}$ 无蛋白质编码基因，约占基因组 $20\%$ |

$21$ 号最小，不是密度最小；密度最小是 $\mathrm{Y}$。唐氏综合征相关基因在 $21$ 号，不要抄到 $1$ 号或 $\mathrm{Y}$。
:::

:::pitfall{label="Y 染色体密度最小，不是“最小的染色体”"}
最小（最短）是 $21$ 号。$\mathrm{Y}$ 是基因密度最小。把两条并成“$\mathrm{Y}$ 又短又空”，表13-1 和 $46\sim 249\,\mathrm{Mb}$ 区间都会对不上。
:::

### 2. 人染色体基因组约含 2 万个蛋白质编码基因

通过基因组测序，人们对数种生物的基因组大小和所含有的基因数量已有所了解。一般而言，在进化过程中随着生物体复杂程度的增加，基因组大小或基因的数量也会随之增加。但是决定生物复杂性的因素较多，除了基因组大小和基因数以外，基因密度对生物复杂性的影响也不容忽视。例如，人的基因组最大，复杂程度也最高，但所含的基因数量并不是最多。

根据美国国家生物技术信息中心（The National Center for Biotechnology Information）$2023$ 年 $3$ 月公布的数据，人类染色体基因组的大小为 $3.1\times 10^{9}\,\mathrm{bp}$，基因和假基因 $59\,444$ 个，其中蛋白质编码基因 $20\,080$ 个，非蛋白质编码基因 $21\,954$ 个；$\mathrm{mRNA}$ $136\,180$ 条，非编码 $\mathrm{RNA}$ $48\,562$ 条（资料来源：$\mathrm{NCBI}$ 基因组数据库）。人类基因组的基因密度较低，因为基因组中存在大量调控序列、转座子和内含子等，这些序列使人类基因能够更为有效地发挥功能。

:::definition{label="人染色体基因组的 NCBI 2023 年 3 月数据"}
大小 $3.1\times 10^{9}\,\mathrm{bp}$（与表13-1 的 $3\,100\,\mathrm{Mb}$、图13-4 的 $3\,100\,\mathrm{Mb}$ 同账）。基因和假基因 $59\,444$ 个：蛋白质编码基因 $20\,080$ 个，非蛋白质编码基因 $21\,954$ 个。$\mathrm{mRNA}$ $136\,180$ 条，非编码 $\mathrm{RNA}$ $48\,562$ 条。
:::

:::definition{label="基因密度"}
基因密度是每 $\mathrm{Mb}$ 长度的序列中所有的平均基因数。人基因组基因密度较低，因为存在大量调控序列、转座子和内含子等；教材认为这些序列使人类基因能够更为有效地发挥功能。
:::

:::keypoint{label="约两万蛋白质编码基因，不要和 59444 并户"}
- $59\,444$：基因和假基因合计（表13-1「基因数」同一数字）。
- $20\,080$：蛋白质编码基因 $\approx$ 小结所说「约有两万个基因」。
- $21\,954$：非蛋白质编码基因。
- $\mathrm{mRNA}$ $136\,180$ 条远多于蛋白质编码基因数，与 $60\%$ 可变剪接、一个基因多种转录物一致。
:::

:::compare{title="复杂度不能只看基因组大小或基因数"}
| 观察 | 教材数字 |
|------|----------|
| 人基因组最大 | $3\,100\,\mathrm{Mb}$／$3.1\times 10^{9}\,\mathrm{bp}$ |
| 人最复杂 | 教材原句 |
| 人蛋白质编码基因不是最多 | $20\,080$；表中线虫 $46\,927$、小鼠 $50\,562$ 都高于此 |
| 线虫基因组小于果蝇 | $100.30\,\mathrm{Mb}$ vs $143.70\,\mathrm{Mb}$，基因数却更多 |
| 人基因密度低 | 大量调控序列、转座子、内含子 |

思考题第 $4$ 问：不能只根据基因组大小或基因数量判断生物体复杂程度。
:::

:::pitfall{label="不要把 20080、21954、59444 加成另一种基因组"}
$20\,080+21\,954=41\,034$，再加上假基因才到教材的 $59\,444$ 量级（假基因约 $2$ 万，本节第二部分）。不要另造“人有六万蛋白质基因”的旧口诀，也不要把 $\mathrm{mRNA}$ $136\,180$ 条当成基因个数。
:::

:::insight{label="低密度不是缺陷，是调控空间"}
教材把大量调控序列、转座子和内含子写成使人基因更为有效地发挥功能的原因，而不是“浪费的碱基”。第一节的增强子、绝缘子、可变剪接，本节的重复序列和基因沙漠，都占用空间、降低密度，也正是真核表达精细调节的结构基础。
:::
