# 第一节　代谢的特点

第十二章把前面各章已经分开写过的糖、脂质、氨基酸、核苷酸和生物氧化，收成一张可以调节的网。本节只立代谢本身的五条共性：过程互相联系成整体、处于动态平衡、内源外源进入共同代谢库、有些途径两用、分解产生的还原当量有多种用途。$\mathrm{ATP}$、乙酰 $\mathrm{CoA}$ 枢纽和三大营养物质交叉是第二节的户头；关键酶、激素和整体调节放到第三节。

:::concept{term="先问是不是同一张网，再问库里的分子从哪来、往哪走"}
看见“代谢”，先不要跳到某一条途径的酶名单。本节五条共性要能分开背：同时进行、动态更新、内源外源进同一库、三羧酸循环两用、$\mathrm{NADH}/\mathrm{FADH}_2/\mathrm{NADPH}$ 三种还原当量。交叉转变和调节方式是后两节的账。
:::

教材第 $229$ 页章首附件电子版图源 `p0258_01.png` 为 $0$ 字节，不嵌入 `src`。正文以代谢定义和五条共性为准。
:::

代谢（metabolism）即新陈代谢，是机体内所有的化学反应，是生命活动的物质基础。它主要包括物质的消化、吸收、合成、分解、转化，能量的生成与利用，以及将自身原有组成成分转变为废物排出而不断更新的过程。代谢包含物质代谢和能量代谢，二者密切联系，不可分割。

经消化、吸收获得的营养物质（如糖类、脂质和蛋白质等）在体内进行各种代谢过程：一方面将营养物质分解氧化、释出能量，以满足生命活动的需求；另一方面机体进行各种合成代谢，以提供自身所需的结构和功能成分。因此，代谢分为分解代谢和合成代谢，由许多代谢途径组成，每一条代谢途径又包含一系列前后关联的酶促化学反应。有些不同的代谢途径还会共享某些化学反应步骤。所以，各种代谢途径相互联系、相互作用、相互协调和相互制约，形成一个动态的网状整体，即代谢具有动态性和整体性。

为了适应不断变化的内、外环境，机体需要不断调节各种物质的代谢方向、流量和速率，从而使体内物质的代谢有条不紊地进行，即代谢具有可调节性。

:::definition{label="代谢"}
代谢（metabolism）即新陈代谢，是机体内所有的化学反应，是生命活动的物质基础。主要包括物质的消化、吸收、合成、分解、转化，能量的生成与利用，以及将自身原有组成成分转变为废物排出而不断更新。代谢包含物质代谢和能量代谢，二者密切联系、不可分割。
:::

:::definition{label="分解代谢与合成代谢"}
分解代谢把营养物质氧化分解、释出能量；合成代谢提供自身所需的结构和功能成分。二者都由许多代谢途径组成，每条途径是一系列前后关联的酶促反应。有些不同途径会共享某些步骤。
:::

:::definition{label="代谢的动态性与整体性"}
各种代谢途径相互联系、相互作用、相互协调和相互制约，形成一个动态的网状整体。这就是教材所说的动态性和整体性。
:::

:::definition{label="代谢的可调节性"}
机体不断调节各种物质的代谢方向、流量和速率，使代谢有条不紊，以适应不断变化的内、外环境。
:::

:::compare{title="物质代谢和能量代谢不要拆成两本无关的账"}
| | 教材原句要抓住的点 |
|--|---------------------|
| 物质代谢 | 消化、吸收、合成、分解、转化，以及自身成分更新并排出废物 |
| 能量代谢 | 能量的生成与利用 |
| 关系 | 密切联系，不可分割；分解氧化释能，合成消耗能量并提供结构／功能成分 |
:::

:::keypoint{label="开篇先背三条共性"}
- 整体性：许多途径成网，有的还共享步骤。
- 动态性：网是在动的，不是一张静止路线图。
- 可调节性：方向、流量、速率都可调，为的是适应内、外环境。
:::

:::insight{label="本章是代谢各章的收口，不是另开一条途径"}
第七至十一章把糖、脂质、生物氧化、氨基酸、核苷酸分开写。本章不问“这一条途径有几步”，而问这些途径怎样同时进行、怎样共用中间物、怎样被关键酶和激素拧在一起。本节只把共性立住。
:::

:::pitfall{label="代谢不是“消化吸收”这一段，也不是只有分解产热"}
定义里消化、吸收、合成、分解、转化、能量生成与利用、自身成分更新排出都在。只把代谢听成“把饭氧化成 $\mathrm{ATP}$”，合成代谢和废物更新就没有户头。
:::

## 一、体内代谢过程互相联系形成一个整体

在体内进行代谢的物质各种各样，不仅有糖、脂质、蛋白质这样的大分子营养物质，也有维生素这样的小分子物质，还有无机盐和水。它们的代谢不是孤立进行的。同一时间机体有多种物质的代谢在进行，需要彼此间相互协调，以确保细胞乃至机体的正常功能。

事实上，人类摄取的食物，无论动物性或植物性食物，均含有蛋白质、脂质、糖类、水、无机盐及维生素等。从消化吸收开始、经过中间代谢、到代谢废物排出体外，这些物质的代谢都是同时进行的，且互有联系、相互依存，各种物质的代谢之间构成统一的整体。例如，糖、脂肪在体内氧化释出的能量可用于核酸、蛋白质等的生物合成；各种酶合成后，又催化糖、脂质、蛋白质等物质代谢按机体的需要顺利进行。

:::definition{label="代谢的整体性"}
同一时间有多种物质的代谢在进行。从消化吸收、中间代谢到废物排出，这些过程同时发生、互有联系、相互依存，构成统一的整体。
:::

:::compare{title="同一时间在代谢的不只是三大营养素"}
| 类别 | 教材点名 |
|------|----------|
| 大分子营养物质 | 糖、脂质、蛋白质 |
| 小分子 | 维生素 |
| 其他 | 无机盐和水 |

动物性食物和植物性食物都含蛋白质、脂质、糖类、水、无机盐及维生素。代谢从进口到出口同时进行，不是“先做完糖再做脂”。
:::

:::cause-effect{title="糖脂氧化和酶蛋白合成为什么必须写在同一张网上"}
- **因** 糖、脂肪氧化释出能量，可供核酸、蛋白质等生物合成；新合成的酶又催化糖、脂质、蛋白质按需要运行
- **果** 产能与合成互相依存。切断能量供应，合成停；酶合成不足，糖脂蛋白代谢也按不成机体需要的节奏
:::

:::pitfall{label="整体性不是“所有物质走同一条途径”"}
教材说的是同时进行、互有联系、相互依存。糖、脂、蛋白质各有途径，只是共享某些步骤和中间物（第二节展开），并且靠能量和酶把彼此拴在一起。不要写成“三大营养素可以完全互相转变”。
:::

:::insight{label="维生素、无机盐和水在这一节就要入账"}
后面各节会把笔墨放在糖、脂、氨基酸。本节开篇已经点名维生素、无机盐和水也在同一时间代谢。第三节写“要保证正常功能，就必须确保糖、脂质、蛋白质、水、无机盐、维生素等营养物质”的调节，户头从这里接。
:::

:::timeline{period="从进口到出口都是同时进行"}
- **消化吸收** 食物中的蛋白质、脂质、糖类、水、无机盐及维生素一起进来
- **中间代谢** 多种物质的合成、分解、转化在同一时间进行
- **废物排出** 自身原有成分转变为废物排出，不断更新
- **互相依存** 糖脂氧化供能给核酸、蛋白质合成；酶合成后再催化糖脂蛋白代谢
:::

## 二、体内代谢处于动态平衡

体内各种营养物质的代谢总是处于一种动态的平衡之中。在正常生理状态下，体内糖、脂质、蛋白质等物质面临多条代谢途径，或合成或分解：有获取则随之被转变（消耗），有消耗则适时获得补充，使其中间代谢物不会出现堆积或匮乏的现象。

例如，血糖浓度虽然维持在一定浓度范围，但其成分每分钟都在不断更新。体内其他物质也均处于如此动态平衡之中。我国著名的生物化学家刘思职院士曾将代谢的动态平衡高度哲理性地概括为：“生者化，化又生，生化即化生；新必陈，陈乃谢，新陈恒代谢”。

:::definition{label="代谢的动态平衡"}
正常生理状态下，糖、脂质、蛋白质等面临多条途径，或合成或分解。有获取则随之转变（消耗），有消耗则适时补充，中间代谢物既不堆积也不匮乏。
:::

:::definition{label="血糖的动态更新"}
血糖浓度维持在一定范围，但其成分每分钟都在不断更新。浓度稳定不等于分子静止。
:::

:::memory{label="刘思职对动态平衡的概括"}
生者化，化又生，生化即化生；新必陈，陈乃谢，新陈恒代谢。
:::

:::pitfall{label="浓度稳定不是分子不动"}
把“血糖维持一定范围”听成“这些葡萄糖一直停在血里”，就和“每分钟都在不断更新”对着干。动态平衡管的是来路与去路匹配，不是冻结中间物。
:::

:::compare{title="动态平衡要同时挡住两头"}
| 如果只开一头 | 教材说的后果 |
|--------------|--------------|
| 只合成、不消耗 | 中间代谢物堆积 |
| 只消耗、不补充 | 中间代谢物匮乏 |
| 获取与消耗匹配 | 浓度可维持在范围之内，成分仍在更新 |
:::

:::cause-effect{title="有获取就要转变，有消耗就要补充"}
- **因** 营养物质同时面对合成和分解等多条途径
- **果** 进来的物质被转变掉，消耗掉的物质被补充上，中间物不堆也不缺；血糖是最直观的例子
:::

:::insight{label="动态平衡为第三节的调节留下开关"}
中间物不堆不缺，靠的是方向、流量、速率可调。别构、化学修饰和酶含量（第三节）就是把“有获取则消耗、有消耗则补充”落实到关键酶上。
:::

:::timeline{period="血糖这本账每分钟都在改写"}
- **浓度** 维持在一定范围
- **成分** 每分钟更新：消化吸收、肝糖原分解、氨基酸转变、甘油转化都可以进血糖
- **去路** 各组织有氧氧化或无氧氧化，释放能量
- **印象** 稳的是范围，动的是分子
:::

## 三、各种代谢物具有各自共同的代谢库

人体主要营养物质如糖、脂质、蛋白质，既可以从食物中摄取，多数也可以在体内自身合成。在进行中间代谢时，机体不分彼此：无论自身合成的内源性营养物质，还是食物中摄取的外源性营养物质，均组成为共同的代谢库（metabolic pool），根据机体的营养状态和需要，同样地进入各种代谢途径进行代谢。

如血液中的葡萄糖，无论是从食物中消化吸收的、肝糖原分解产生的、氨基酸转变产生的，或是由甘油转化生成的，都参与组成血糖；在机体需要能量时，均可在各组织进行有氧氧化或无氧氧化，释放出能量供机体利用，机会均等。

:::definition{label="代谢库"}
代谢库（metabolic pool）是内源性（自身合成）和外源性（食物摄取）营养物质共同组成的中间代谢集合。机体不分彼此，按营养状态和需要同样进入各种代谢途径。
:::

:::definition{label="血糖作为葡萄糖代谢库"}
食物消化吸收的葡萄糖、肝糖原分解产生的葡萄糖、氨基酸转变产生的葡萄糖、甘油转化生成的葡萄糖，都参与组成血糖。需要能量时，均可在各组织进行有氧或无氧氧化，机会均等。
:::

:::compare{title="血糖这一个库的四条来路"}
| 来路 | 是否进血糖 | 需能时能否被氧化 |
|------|------------|-------------------|
| 食物消化吸收 | 是 | 是，机会均等 |
| 肝糖原分解 | 是 | 是 |
| 氨基酸转变 | 是 | 是 |
| 甘油转化 | 是 | 是 |

中间代谢不问“这分子昨天是饭还是肝糖原”，只问库里有没有、机体需不需要。
:::

:::pitfall{label="内源外源进同一库，不是“外源优先用完再动内源”"}
教材写的是不分彼此、同样进入各种途径。饥饿时先动糖原、再动脂肪（第三节），那是整体调节改变了流量，不是代谢库给外源分子发了优先通行证。
:::

:::insight{label="多数可自身合成，不是全部可自身合成"}
糖、脂质、蛋白质“多数也可以在体内自身合成”。必需氨基酸、必需脂肪酸这类不能自身合成的成员，仍要靠食物进入同一个库。不要把“共同代谢库”听成“全部都能自己造”。
:::

:::keypoint{label="代谢库三句话"}
- 内源 $+$ 外源 $=$ 共同的库。
- 按营养状态和需要进入途径，机会均等。
- 血糖是样板：四条来路，有氧无氧都可以走。
:::

:::note{label="库是分类的，不是把所有物质倒进一个桶"}
标题是“各种代谢物具有各自共同的代谢库”。葡萄糖有血糖这个库，氨基酸、脂酰基等另有各自的库。共同指内源与外源合并，不是糖、脂、蛋白质分子混成一种中间物。
:::

## 四、有些代谢途径是两用代谢途径

一般情况下，机体内的合成代谢和分解代谢的途径并不相同，以便于调节。但机体存在着既可用于代谢物分解、又可用于合成的代谢途径，称为两用代谢途径（amphibolic pathway），发挥着连通合成与分解代谢的核心桥梁作用。

最具代表性的例子就是三羧酸循环：糖、脂肪酸、氨基酸完全氧化分解必须经历三羧酸循环；同时，三羧酸循环中的一些中间代谢物也是合成许多其他重要生物分子的前体。

:::definition{label="两用代谢途径"}
两用代谢途径（amphibolic pathway）既可用于代谢物分解，又可用于合成，是连通合成与分解代谢的核心桥梁。
:::

:::definition{label="三羧酸循环是两用途径的代表"}
糖、脂肪酸、氨基酸完全氧化分解必须经历三羧酸循环；循环中的一些中间代谢物又是合成许多其他重要生物分子的前体。
:::

:::compare{title="分解和合成一般分道，两用途径是桥梁"}
| | 途径是否相同 | 便于什么 |
|--|--------------|----------|
| 一般情况下 | 合成途径与分解途径并不相同 | 便于分别调节，避免对开空转 |
| 两用途径 | 同一条途径既分解又提供前体 | 把分解网和合成网接起来 |

不要一看见三羧酸循环就只背“彻底氧化产 $\mathrm{CO}_2$”。前体这一头同样是教材原句。
:::

:::pitfall{label="两用不是“合成等于分解的倒放”"}
一般情况恰恰是合成与分解途径不同，才好调节。两用途径共享的是这一段中间步骤和中间物，不是把糖异生写成糖酵解倒着走的全部反应。单向关键酶仍然在（第三节表12-2）。
:::

:::insight{label="前体这一头在图12-1才展开"}
本节只点到“一些中间代谢物是合成许多其他重要生物分子的前体”。草酰乙酸、$\alpha$-酮戊二酸、琥珀酰 $\mathrm{CoA}$、乙酰 $\mathrm{CoA}$ 怎样连到氨基酸、卟啉、酮体、脂肪酸，是第二节图12-1 的户头。
:::

:::keypoint{label="两用途径先背三羧酸循环"}
- 定义：既分解又合成。
- 代表：三羧酸循环。
- 分解头：糖、脂肪酸、氨基酸彻底氧化必经。
- 合成头：中间物当其他分子的前体。
:::

## 五、分解代谢产生的还原当量具有多种用途

体内的还原当量通常是指 $\mathrm{NADH}$、$\mathrm{FADH}_2$ 和 $\mathrm{NADPH}$，均来自体内营养物质的分解代谢。有氧时，$\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 可进入呼吸链，通过氧化磷酸化产生大量 $\mathrm{ATP}$。体内许多生物合成反应是还原性合成，需要还原当量才能顺利进行。如脂肪酸和胆固醇的体内合成代谢所需的还原当量，其主要提供者是 $\mathrm{NADPH}$，它主要来源于葡萄糖的戊糖磷酸途径。此外，体内的还原当量还可以在自由基清除、生物转化、$\mathrm{DNA}$ 修复等过程中发挥功能。所以，还原当量将氧化反应和还原反应联系起来，将物质的氧化分解与还原性合成联系起来，将不同的还原性反应联系起来。

:::definition{label="还原当量"}
体内的还原当量通常指 $\mathrm{NADH}$、$\mathrm{FADH}_2$ 和 $\mathrm{NADPH}$，均来自营养物质的分解代谢。
:::

:::definition{label="NADH 和 FADH2 的主要去路"}
有氧时，$\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 进入呼吸链，通过氧化磷酸化产生大量 $\mathrm{ATP}$。
:::

:::definition{label="NADPH"}
脂肪酸和胆固醇体内合成所需还原当量的主要提供者是 $\mathrm{NADPH}$，主要来源于葡萄糖的戊糖磷酸途径。还原当量还参与自由基清除、生物转化、$\mathrm{DNA}$ 修复等。
:::

:::compare{title="三种还原当量不要并户"}
| 还原当量 | 主要来源（本节） | 主要用途（本节） |
|----------|------------------|------------------|
| $\mathrm{NADH}$ | 营养物质分解 | 有氧时进呼吸链，氧化磷酸化产 $\mathrm{ATP}$ |
| $\mathrm{FADH}_2$ | 营养物质分解 | 同上 |
| $\mathrm{NADPH}$ | 主要来自葡萄糖的戊糖磷酸途径 | 脂肪酸、胆固醇等还原性合成；自由基清除、生物转化、$\mathrm{DNA}$ 修复 |
:::

:::pitfall{label="NADPH 不是呼吸链产 ATP 的主账"}
有氧时进呼吸链的是 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$。$\mathrm{NADPH}$ 这一笔写的是还原性合成和防护／转化／修复。把三种还原当量都写成“去氧化磷酸化”，脂肪酸和胆固醇合成就没有氢源。
:::

:::cause-effect{title="为什么高糖膳食能给脂肪酸、胆固醇合成提供氢"}
- **因** $\mathrm{NADPH}$ 主要来源于葡萄糖的戊糖磷酸途径
- **果** 葡萄糖分解不仅提供乙酰 $\mathrm{CoA}$ 碳骨架（第二节），还提供还原性合成所需的氢；还原当量把氧化分解和还原性合成连在同一张网上
:::

:::insight{label="还原当量是三条连线，不只是产 ATP"}
教材收成三句：把氧化反应和还原反应联系起来；把物质的氧化分解与还原性合成联系起来；把不同的还原性反应联系起来。$\mathrm{ATP}$ 只是 $\mathrm{NADH}/\mathrm{FADH}_2$ 有氧去路中的一笔。
:::

:::keypoint{label="还原当量三句话"}
- 名单：$\mathrm{NADH}$、$\mathrm{FADH}_2$、$\mathrm{NADPH}$，都来自分解。
- 产能：有氧时 $\mathrm{NADH}/\mathrm{FADH}_2$ $\rightarrow$ 呼吸链 $\rightarrow$ $\mathrm{ATP}$。
- 合成与防护：$\mathrm{NADPH}$ 主供脂肪酸、胆固醇合成，并参与自由基清除、生物转化、$\mathrm{DNA}$ 修复。
:::

:::memory{label="本节必背要点"}
- [ ] 代谢 $=$ 体内所有化学反应，是生命活动的物质基础；含物质代谢和能量代谢，不可分割。
- [ ] 分解氧化释能，合成提供结构／功能成分；途径成网，可共享步骤。
- [ ] 三条共性：整体性、动态性、可调节性（方向、流量、速率）。
- [ ] 同时代谢的不只是糖、脂、蛋白质，还有维生素、无机盐和水。
- [ ] 糖、脂肪氧化供能给核酸、蛋白质合成；酶合成后再催化糖脂蛋白代谢。
- [ ] 动态平衡：有获取则消耗，有消耗则补充，中间物不堆不缺。
- [ ] 血糖浓度维持在范围之内，成分每分钟更新。
- [ ] 刘思职：生者化，化又生，生化即化生；新必陈，陈乃谢，新陈恒代谢。
- [ ] 代谢库：内源 $+$ 外源，不分彼此，按营养状态和需要进入途径。
- [ ] 血糖来路：食物吸收、肝糖原分解、氨基酸转变、甘油转化；需能时有氧或无氧氧化，机会均等。
- [ ] 合成与分解途径一般不同，便于调节。
- [ ] 两用代谢途径（amphibolic pathway）连通合成与分解；代表是三羧酸循环。
- [ ] 还原当量：$\mathrm{NADH}$、$\mathrm{FADH}_2$、$\mathrm{NADPH}$。
- [ ] 有氧时 $\mathrm{NADH}/\mathrm{FADH}_2$ 进呼吸链产大量 $\mathrm{ATP}$。
- [ ] $\mathrm{NADPH}$ 主要来自戊糖磷酸途径，主供脂肪酸、胆固醇合成。
- [ ] 还原当量还用于自由基清除、生物转化、DNA 修复。
:::
