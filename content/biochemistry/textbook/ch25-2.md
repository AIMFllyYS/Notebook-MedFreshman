## 一、肝的生物转化作用是机体重要的保护机制

### （一）生物转化的概念

机体将一些内源性或外源性非营养物质进行化学转变，增加其水溶性和极性，使其易于通过胆汁或尿排出，这一过程称为生物转化（biotransformation）。肝是机体内生物转化最重要的器官，胃肠道、皮肤、肺及肾等亦有一定的生物转化作用。

:::definition{label="生物转化"}
生物转化（biotransformation）：机体将内源性或外源性非营养物质进行化学转变，增加其水溶性和极性，使其易于通过胆汁或尿排出。户头落在「非营养物质」和「增加水溶性／极性」，还不是「一定变成无毒」。
:::

:::definition{label="肝是生物转化最重要的器官"}
胃肠道、皮肤、肺及肾等亦有一定作用。问「只有肝能做吗」——主场在肝，不是独家。
:::

:::pitfall{label="不要把生物转化写成营养物质分解"}
糖、脂、蛋白质的分解供能是第一节。本节对象是胺类、胆红素、激素、药物、毒物、食品添加剂、环境化学污染物和肠道腐败产物等非营养物质。写成「葡萄糖氧化也是生物转化」，两节户头就并了。
:::

按被转化物质来源可分为两大类。

**1. 内源性物质**　如体内物质代谢的产物或中间物（如胺类、胆红素等），以及发挥生理作用后有待灭活的各种生物活性物质（如激素、神经递质等）。

**2. 外源性物质**　系人体在日常生活和／或生产过程中不可避免接触的异源物（xenobiotics），如药物、毒物、食品添加剂、环境化学污染物等和从肠道吸收的腐败产物。大约超过 $20$ 万种环境化学物存在，除个别因系水溶性可直接由胆汁或尿排出外，绝大部分因系脂溶性需经生物转化作用才能排出体外。生物转化的生理意义主要是增加异源物水溶性，促进排出；以及发挥解毒作用。

:::definition{label="内源性待转化物质"}
代谢产物或中间物（胺类、胆红素等），以及发挥生理作用后有待灭活的生物活性物质（激素、神经递质等）。胆红素在这里只是内源物例子，代谢展开是第四节。
:::

:::definition{label="异源物"}
异源物（xenobiotics）：药物、毒物、食品添加剂、环境化学污染物等和从肠道吸收的腐败产物。大约超过 $20$ 万种环境化学物；个别水溶性可直接由胆汁或尿排出，绝大部分脂溶性需经生物转化才能排出。
:::

:::definition{label="生物转化的生理意义"}
主要是增加异源物水溶性，促进排出；以及发挥解毒作用。「以及」后面那半句不是全部意义——下一小节马上写解毒与致毒的双重性。
:::

:::compare{title="内源 vs 外源（异源物）"}
| | 本版例子 | 去向 |
|--|---------|------|
| 内源 | 胺类、胆红素；激素、神经递质 | 灭活或排出 |
| 外源（xenobiotics） | 药物、毒物、食品添加剂、环境化学污染物、肠道腐败产物 | 绝大部分先转化再经胆汁或尿排出 |

问「胆红素算不算生物转化对象」——算内源非营养物质。问「要不要在本节写黄疸分型」——不要，那是第四节。
:::

### （二）生物转化的特点

**1. 反应的连续性**　一种非营养物质往往需要经多种连续进行的反应才能排出体外。如乙酰水杨酸进入人体首先被水解为水杨酸，水杨酸在肝内进行结合反应排出体外。

**2. 类型的多样性**　由于非营养物质含有各种各样的基团，而各类基团能进行不同的化学反应，这就导致了生物转化反应类型的多样性。

**3. 解毒和致毒的双重性**　一种物质经过一定生物转化后，其毒性可能减弱（解毒），也可能增强（致毒）。如烟草中含有一种多环芳烃类化合物——苯并（α）芘［benzo(a)pyrene，$\mathrm{BaP}$］，其本身没有直接致癌作用，但经过生物转化后反而成为直接致癌物。有的药物如环磷酰胺、百浪多息、水合氯醛和中药大黄等需经生物转化后才能成为有活性的药物。因此，不能将肝的生物转化作用简单地称为“解毒作用（detoxification）”，这显示了肝生物转化作用的解毒与致毒双重性的特点。

:::definition{label="连续性"}
一种非营养物质往往需要经多种连续进行的反应才能排出。本版例：乙酰水杨酸先水解为水杨酸，再在肝内结合后排出。后文图25-6 把水解、氧化及结合画在一张流程里。
:::

:::definition{label="多样性"}
非营养物质含各种各样的基团，各类基团能进行不同的化学反应。后文阿司匹林：水杨酸既可与葡萄糖醛酸结合成 $\beta$-葡萄糖醛酸苷，又可与甘氨酸结合成水杨酰甘氨酸，还可先氧化成羟基水杨酸再结合。
:::

:::definition{label="解毒与致毒的双重性"}
转化后毒性可能减弱，也可能增强。苯并（α）芘本身没有直接致癌作用，转化后反而成为直接致癌物。环磷酰胺、百浪多息、水合氯醛和中药大黄等需经转化才成为有活性的药物。
:::

:::pitfall{label="不能把生物转化简单地称为解毒作用"}
这是本版原句。英文 detoxification 不能当本节标题。黄曲霉素经单加氧酶生成环氧化物更毒；苯并芘转化后才直接致癌。写成「肝把所有毒物都变成无毒」，双重性这一条就删了。
:::

:::compare{title="转化后更毒 vs 转化后才有药效"}
| | 本版例子 | 说明 |
|--|---------|------|
| 致毒／致癌 | 苯并（α）芘；黄曲霉素 $\mathrm{B}_1$ 经单加氧酶 | 本身不一定直接致癌，转化后可以是 |
| 前药变活性药 | 环磷酰胺、百浪多息、水合氯醛、中药大黄 | 百浪多息还原成氨苯磺胺是图25-5 |

两户都证明「转化 ≠ 解毒」，不要并成同一张反应式。
:::

:::keypoint{label="概念三句"}
- 对象：内／外源非营养物质（异源物 xenobiotics）。
- 目的：增加水溶性和极性，经胆汁或尿排出。
- 特点：连续、多样、解毒与致毒双重性。不能叫「解毒作用」。
:::

## 二、肝的生物转化作用包括两相反应

肝的生物转化涉及多种酶促反应，但总体上可分为两相反应。第一相反应包括氧化（oxidation）、还原（reduction）和水解（hydrolysis）。许多物质通过第一相反应，其分子中的某些非极性基团转变为极性基团，水溶性增加，即可排出体外。但有些物质经过第一相反应后水溶性和极性改变不明显，还需要结合极性更强的物质或基团，以进一步增加其水溶性而促进排泄，这些结合反应（conjugation）属于第二相反应。实际上，许多物质的生物转化过程非常复杂。一种物质有时需要连续进行几种反应类型才能实现生物转化目的，这反映了肝生物转化作用的连续性特点。如阿司匹林常先水解成水杨酸后再经与葡萄糖醛酸的结合反应才能排出体外。此外同一种物质可以进行不同类型的生物转化反应，产生不同的转化产物，这体现了肝生物转化反应类型的多样性特点。例如，阿司匹林先水解生成水杨酸，后者既可与葡萄糖醛酸结合转化成 $\beta$-葡萄糖醛酸苷，又可与甘氨酸结合成水杨酰甘氨酸，还可水解后先氧化成羟基水杨酸，再进行多种结合反应。肝内参与生物转化的主要酶类列于表25-2。

:::definition{label="第一相反应"}
氧化、还原、水解。许多物质经第一相后，非极性基团变为极性基团，水溶性增加，即可排出。英文 oxidation、reduction、hydrolysis。
:::

:::definition{label="第二相反应"}
结合反应（conjugation）。第一相后水溶性和极性仍不够，再结合极性更强的物质或基团。有些物质也可不经过第一相而直接进入第二相。
:::

:::definition{label="阿司匹林把连续性和多样性写在同一条药上"}
连续性：常先水解成水杨酸，再与葡萄糖醛酸结合后排出。多样性：水杨酸可成 $\beta$-葡萄糖醛酸苷，可成水杨酰甘氨酸，也可先氧化成羟基水杨酸再结合。一药三户，不要只记「水解」。
:::

### （一）氧化反应是最多见的第一相反应

#### 1. 单加氧酶系是氧化异源物最重要的酶

肝细胞中存在多种氧化酶系，最重要的是定位于肝细胞内质网的细胞色素 $\mathrm{P}450$ 单加氧酶（cytochrome P450 monooxygenase，$\mathrm{CYP}$）系。单加氧酶系是一个复合物，至少包括两种组分：一种是细胞色素 $\mathrm{P}450$（以血红素为辅基的蛋白）；另一种是 $\mathrm{NADPH}$-细胞色素 $\mathrm{P}450$ 还原酶（以 $\mathrm{FAD}$ 为辅基的黄酶）。该酶催化氧分子中的一个氧原子加到许多脂溶性底物中形成羟化物或环氧化物，另一个氧原子则被 $\mathrm{NADPH}$ 还原成水，故该酶又称羟化酶或称混合功能氧化酶。该酶是目前已知底物最广泛的生物转化酶类。

单加氧酶系催化的基本反应如下：

$$
\mathrm{RH}+\mathrm{O}_2+\mathrm{NADPH}+\mathrm{H}^{+}\longrightarrow\mathrm{ROH}+\mathrm{H}_2\mathrm{O}+\mathrm{NADP}^{+}
$$

一个氧原子进入底物（羟化物或环氧化物），另一个氧原子还原成水。

:::definition{label="细胞色素 P450 单加氧酶"}
定位于肝细胞内质网。复合物至少两种组分：细胞色素 $\mathrm{P}450$（血红素为辅基）和 $\mathrm{NADPH}$-细胞色素 $\mathrm{P}450$ 还原酶（$\mathrm{FAD}$ 为辅基的黄酶）。一个氧加到脂溶性底物成羟化物或环氧化物，另一个氧被 $\mathrm{NADPH}$ 还原成水。又称羟化酶或混合功能氧化酶。目前已知底物最广泛的生物转化酶类。
:::

:::pitfall{label="单加氧不是两个氧都加到底物上"}
「单加氧」说的是分子氧里只有一个氧原子进入底物。另一个成水。写成「两个氧都羟化底物」或漏掉 $\mathrm{NADPH}$，混合功能氧化酶这个别名就没有着落。
:::

迄今已鉴定出 $57$ 种人类编码 $\mathrm{CYP}$ 的基因，它们的同源性为 $40\%$ 以上。人 $\mathrm{CYP}$ 可以分为 $9$ 个亚家族，对异源物进行生物转化的 $\mathrm{CYP}$ 主要是 $\mathrm{CYP}1$、$\mathrm{CYP}2$ 和 $\mathrm{CYP}3$ 家族，其中又以 $\mathrm{CYP}3\mathrm{A}4$、$\mathrm{CYP}2\mathrm{C}9$、$\mathrm{CYP}1\mathrm{A}2$ 和 $\mathrm{CYP}2\mathrm{E}1$ 的含量最多。$\mathrm{CYP}3\mathrm{A}4$ 占据整个肝脏 $\mathrm{CYP}$ 酶系的 $30\%\sim 40\%$，是负责药物代谢的主要酶。$\mathrm{CYP}2\mathrm{E}1$ 负责将乙醇转化为乙醛，其中 $2$ 表示亚家族，$\mathrm{E}$ 表示乙醇，$1$ 表示同工酶 $1$。奥美拉唑是 $\mathrm{Cyt}\ \mathrm{P}450$ 强抑制剂，可导致肝损伤，因此长期服用奥美拉唑可见血中转氨酶升高。利福平是 $\mathrm{CYP}2\mathrm{C}9$、$\mathrm{CYP}2\mathrm{C}19$、$\mathrm{CYP}3\mathrm{A}4$ 等诱导剂。

:::definition{label="人 CYP 的本版数字"}
$57$ 种人类编码基因，同源性 $40\%$ 以上；可分为 $9$ 个亚家族。异源物转化主要是 $\mathrm{CYP}1$、$\mathrm{CYP}2$、$\mathrm{CYP}3$ 家族；含量最多的是 $\mathrm{CYP}3\mathrm{A}4$、$\mathrm{CYP}2\mathrm{C}9$、$\mathrm{CYP}1\mathrm{A}2$、$\mathrm{CYP}2\mathrm{E}1$。
:::

:::definition{label="CYP3A4"}
占据整个肝脏 $\mathrm{CYP}$ 酶系的 $30\%\sim 40\%$，是负责药物代谢的主要酶。
:::

:::definition{label="CYP2E1"}
负责将乙醇转化为乙醛。命名：$2$＝亚家族，$\mathrm{E}$＝乙醇，$1$＝同工酶 $1$。后文与醇脱氢酶对照（表25-3）：内质网定位，$\mathrm{NADPH}$ 和 $\mathrm{O}_2$ 为辅，$K_{\mathrm{m}}$ $8.6\,\mathrm{mmol/L}$，可被乙醇诱导。
:::

:::definition{label="奥美拉唑与利福平"}
奥美拉唑是 $\mathrm{Cyt}\ \mathrm{P}450$ 强抑制剂，可导致肝损伤，长期服用可见血中转氨酶升高。利福平是 $\mathrm{CYP}2\mathrm{C}9$、$\mathrm{CYP}2\mathrm{C}19$、$\mathrm{CYP}3\mathrm{A}4$ 等诱导剂。一抑一诱，不要写反。

问「药物代谢主要靠谁」先答 $\mathrm{CYP}3\mathrm{A}4$；问「喝酒还诱导谁」答 $\mathrm{CYP}2\mathrm{E}1$。
:::

单加氧酶系的羟化作用不仅增加药物或毒物的水溶性而利于排出，而且还参与体内许多重要物质的羟化过程，如维生素 $\mathrm{D}_3$ 的羟化、胆汁酸和类固醇激素合成过程中的羟化等。然而应该指出的是，有些致癌物质经氧化后丧失其活性，而有些本来无活性的物质经氧化后却生成有毒或致癌物质。例如，发霉的谷物、花生等常含有黄曲霉素 $\mathrm{B}_1$，经单加氧酶系作用生成的黄曲霉素 $2,3$ 环氧化物，可与 $\mathrm{DNA}$ 分子中的鸟嘌呤结合引起 $\mathrm{DNA}$ 突变，成为导致原发性肝癌的重要危险因素（图25-3）。

:::definition{label="单加氧酶不只转化异源物"}
还参与维生素 $\mathrm{D}_3$ 的羟化、胆汁酸和类固醇激素合成过程中的羟化。第一节维生素 $\mathrm{D}_3$ → $25$-羟维生素 $\mathrm{D}_3$ 与这里会合。胆汁酸合成的羟化展开是第三节。
:::

:::definition{label="黄曲霉素 B1 经单加氧酶致癌"}
发霉谷物、花生中的黄曲霉素 $\mathrm{B}_1$，经单加氧酶系生成黄曲霉素 $2,3$ 环氧化物，与 $\mathrm{DNA}$ 鸟嘌呤结合引起突变，是原发性肝癌的重要危险因素。图25-3 电子版缺失，图号保留。后文图25-10 是同一类环氧化物与谷胱甘肽结合的解毒出口。
:::

#### 2. 单胺氧化酶类氧化脂肪族和芳香族胺类

存在于肝细胞线粒体内的单胺氧化酶（monoamine oxidase，$\mathrm{MAO}$）是另一类参与生物转化的氧化酶类。属于黄素酶类，可催化蛋白质腐败作用等产生的脂肪族和芳香族胺类物质（如组胺、酪胺、色胺、尸胺、腐胺等）以及一些肾上腺素能药物如 $5$-羟色胺、儿茶酚胺类等的氧化脱氨基作用生成相应的醛类，后者进一步在胞质中醛脱氢酶催化下进一步氧化成酸，使之丧失生物活性。

:::definition{label="单胺氧化酶"}
$\mathrm{MAO}$，肝细胞线粒体，黄素酶类。催化组胺、酪胺、色胺、尸胺、腐胺等，以及 $5$-羟色胺、儿茶酚胺类的氧化脱氨基，生成相应醛类；胞质醛脱氢酶再氧化成酸，丧失生物活性。
:::

:::insight{label="第一节的假神经递质从这里断掉"}
苯乙胺、酪胺正常被 $\mathrm{MAO}$ 氧化清除。严重肝病时清不掉，入脑羟化成假神经递质。本节把酶立住，不必把肝性脑病重写一遍。
:::

:::compare{title="单加氧酶 vs 单胺氧化酶"}
| | 定位 | 辅基／辅酶 | 典型产物 |
|--|------|-----------|---------|
| $\mathrm{CYP}$ 单加氧酶 | 内质网 | 血红素＋$\mathrm{FAD}$ 黄酶；$\mathrm{NADPH}$、$\mathrm{O}_2$ | 羟化物或环氧化物 |
| $\mathrm{MAO}$ | 线粒体 | 黄素辅酶 | 胺 → 醛 → 酸 |

一个改脂溶性异源物，一个改胺。不要把 $\mathrm{MAO}$ 写成 $\mathrm{P}450$ 的同工酶。
:::

#### 3. 醇脱氢酶与醛脱氢酶将乙醇最终氧化成乙酸

肝细胞的细胞质存在非常活跃的以 $\mathrm{NAD}^{+}$ 为辅酶的醇脱氢酶（alcohol dehydrogenase，$\mathrm{ADH}$），可催化醇类氧化成醛，后者再由线粒体或细胞质中醛脱氢酶（aldehyde dehydrogenase，$\mathrm{ALDH}$）催化生成相应的酸类。

乙醇（ethanol）作为饮料和调味剂被广为利用。进入体内的乙醇主要在肝进行生物转化，人平均每天通过肠道产生 $3\,\mathrm{g}$ 乙醇。$70\,\mathrm{kg}$ 体重的成年人每小时可代谢 $7\sim 14\,\mathrm{g}$ 乙醇，由 $\mathrm{ADH}$ 与 $\mathrm{ALDH}$ 将乙醇最终氧化成乙酸。长期饮酒或慢性乙醇中毒除经 $\mathrm{ADH}$ 与 $\mathrm{ALDH}$ 氧化外，还可使肝内质网增殖，稳定内质网内 $\mathrm{CYP}2\mathrm{E}1$ 的活性并诱导其合成。胎儿肝脏尚未表达 $\mathrm{ADH}$，即使出生后，也需要很久 $\mathrm{ADH}$ 才能达到成年人水平，这期间主要依靠 $\mathrm{CYP}2\mathrm{E}1$ 分解乙醇，但分解能力较慢，因此孕妇和儿童不应饮酒。$\mathrm{CYP}2\mathrm{E}1$ 仅在血中乙醇浓度很高时起催化作用。值得注意的是，乙醇诱导 $\mathrm{CYP}2\mathrm{E}1$ 可增加肝对氧和 $\mathrm{NADPH}$ 的消耗，且还可催化脂质过氧化产生羟乙基自由基，后者可进一步促进脂质过氧化，产生大量脂质过氧化物，引发肝细胞氧化损伤。$\mathrm{ADH}$ 与 $\mathrm{CYP}2\mathrm{E}1$ 的细胞定位及特性见表25-3。

:::definition{label="ADH 与 ALDH"}
醇脱氢酶（$\mathrm{ADH}$）：肝细胞胞质，辅酶 $\mathrm{NAD}^{+}$，醇 → 醛。醛脱氢酶（$\mathrm{ALDH}$）：线粒体或细胞质，醛 → 酸。乙醇最终氧化成乙酸。
:::

:::definition{label="乙醇代谢的本版数字"}
肠道每天约产生 $3\,\mathrm{g}$ 乙醇。$70\,\mathrm{kg}$ 成人每小时可代谢 $7\sim 14\,\mathrm{g}$。主要在肝，主路是 $\mathrm{ADH}$＋$\mathrm{ALDH}$。
:::

:::definition{label="慢性饮酒诱导 CYP2E1"}
长期饮酒或慢性乙醇中毒除经 $\mathrm{ADH}$ 与 $\mathrm{ALDH}$ 外，还使肝内质网增殖，稳定并诱导 $\mathrm{CYP}2\mathrm{E}1$。$\mathrm{CYP}2\mathrm{E}1$ 仅在血中乙醇浓度很高时起催化作用。
:::

:::definition{label="胎儿和儿童主要靠 CYP2E1"}
胎儿肝脏尚未表达 $\mathrm{ADH}$，出生后很久才达成人水平。这期间主要靠 $\mathrm{CYP}2\mathrm{E}1$，但分解较慢，因此孕妇和儿童不应饮酒。
:::

:::cause-effect{title="诱导 CYP2E1 → 肝细胞氧化损伤"}
乙醇诱导 $\mathrm{CYP}2\mathrm{E}1$ → 增加肝对氧和 $\mathrm{NADPH}$ 的消耗 → 催化脂质过氧化产生羟乙基自由基 → 进一步脂质过氧化 → 大量脂质过氧化物 → 肝细胞氧化损伤。这是「能代谢乙醇」不等于「对肝无害」。
:::

:::compare{title="表25-3　ADH 与 CYP2E1 之间的比较"}
| 区别 | 醇脱氢酶（$\mathrm{ADH}$） | $\mathrm{CYP}2\mathrm{E}1$ |
|------|---------------------------|---------------------------|
| 肝细胞内定位 | 胞质 | 内质网 |
| 底物与辅酶 | 乙醇、$\mathrm{NAD}^{+}$ | 乙醇、$\mathrm{NADPH}$、$\mathrm{O}_2$ |
| 对乙醇的 $K_{\mathrm{m}}$ | $2\,\mathrm{mmol/L}$ | $8.6\,\mathrm{mmol/L}$ |
| 乙醇的诱导作用 | 无 | 有 |
| 与乙醇氧化相关的能量变化 | 氧化磷酸化释能 | 耗能 |
:::

:::pitfall{label="Km 低的是 ADH，高的是 CYP2E1"}
$\mathrm{ADH}$ 的 $K_{\mathrm{m}}$ $2\,\mathrm{mmol/L}$，低浓度就能干活；$\mathrm{CYP}2\mathrm{E}1$ 的 $K_{\mathrm{m}}$ $8.6\,\mathrm{mmol/L}$，且仅在血中乙醇浓度很高时起催化。写成「平时靠 $\mathrm{P}450$ 解酒」，表25-3 就反了。
:::

乙醇经上述两种代谢途径氧化均生成乙醛，后者在 $\mathrm{ALDH}$ 的催化下氧化成乙酸。人体肝内 $\mathrm{ALDH}$ 活性最高。$\mathrm{ALDH}$ 的基因型有正常纯合子、无活性型纯合子和两者的杂合子三型。东方人这三种基因型的分布比例是 $45:10:45$。无活性型纯合子完全缺乏 $\mathrm{ALDH}$ 活性，杂合子型部分缺乏 $\mathrm{ALDH}$ 活性。东方人群大约有 $30\%\sim 40\%$ 的人 $\mathrm{ALDH}$ 基因有变异，部分 $\mathrm{ALDH}$ 活性低下，此乃该人群饮酒后乙醛在体内堆积，引起血管扩张、面部潮红、心动过速、脉搏加快等反应的重要原因。值得注意的是，头孢类、咪唑类等抗菌药能够抑制 $\mathrm{ALDH}$，如果饮酒会引起“双硫仑反应”，重则有生命危险，因此服用抗生素药不能饮酒。此外，乙醇的氧化使肝细胞内细胞质 $\mathrm{NADH}/\mathrm{NAD}^{+}$ 比值升高，过多的 $\mathrm{NADH}$ 可将细胞质中丙酮酸还原成乳酸。严重酒精中毒导致乳酸和乙酸堆积，可引起酸中毒和电解质平衡紊乱，还可使糖异生受阻引起低血糖。

:::definition{label="ALDH 三种基因型"}
正常纯合子、无活性型纯合子、杂合子。东方人分布比例 $45:10:45$。无活性型完全缺乏活性，杂合子部分缺乏。东方人群约 $30\%\sim 40\%$ 的人 $\mathrm{ALDH}$ 基因有变异。
:::

:::definition{label="饮酒后面部潮红"}
$\mathrm{ALDH}$ 活性低下 → 乙醛堆积 → 血管扩张、面部潮红、心动过速、脉搏加快。这是乙醛的账，不是「酒精直接扩血管」一句能代替的。
:::

:::definition{label="双硫仑反应"}
头孢类、咪唑类等抗菌药能抑制 $\mathrm{ALDH}$，饮酒会引起双硫仑反应，重则有生命危险。本版原句：服用抗生素药不能饮酒。
:::

:::definition{label="严重酒精中毒的代谢后果"}
胞质 $\mathrm{NADH}/\mathrm{NAD}^{+}$ 升高 → 丙酮酸还原成乳酸；乳酸和乙酸堆积 → 酸中毒和电解质紊乱；糖异生受阻 → 低血糖。第一节说肝维持血糖，这里给出酒精把它打断的一种方式。
:::

:::timeline{period="乙醇在肝里怎么走"}
- **日常低浓度** 胞质 ADH（NAD+，Km 2 mmol/L）氧化成乙醛，ALDH 再成乙酸
- **高浓度或慢性诱导** 内质网 CYP2E1（NADPH、O2，Km 8.6 mmol/L）也氧化成乙醛，耗能并产自由基
- **东方人约 30%～40%** ALDH 变异，乙醛堆积，面红、心动过速
- **头孢类、咪唑类** 抑制 ALDH，饮酒可致双硫仑反应
- **严重中毒** NADH/NAD+ 升高，乳酸和乙酸堆积，酸中毒、低血糖
:::

:::insight{label="营养段还会再碰到 NADH/NAD+"}
大量饮酒使 $\mathrm{NAD}^{+}/\mathrm{NADH}$ 比值降低，减少 $\mathrm{UDP}$-葡萄糖转变成 $\mathrm{UDPGA}$，影响葡萄糖醛酸结合。乙醇这一小节和后文「营养状况」是同一本还原当量账。
:::

### （二）还原反应主要依靠硝基还原酶和偶氮还原酶

硝基化合物多见于食品防腐剂、工业试剂等。偶氮化合物常见于食品色素、化妆品、纺织与印刷工业等，有些可能是前致癌物。这些化合物可分别在肝硝基还原酶（nitroreductase）和偶氮还原酶（azoreductase）的催化下，以 $\mathrm{NADH}$ 或 $\mathrm{NADPH}$ 为供氢载体，还原生成相应的胺类，从而失去其致癌作用。例如，硝基苯和偶氮苯经还原反应均可生成苯胺，后者再在单胺氧化酶的作用下，生成相应的酸（图25-4）。

:::definition{label="硝基还原酶与偶氮还原酶"}
定位内质网，辅酶 $\mathrm{NADH}$ 或 $\mathrm{NADPH}$。硝基化合物（食品防腐剂、工业试剂）和偶氮化合物（食品色素、化妆品、纺织印刷，有些可能是前致癌物）还原成相应胺类，从而失去致癌作用。例：硝基苯、偶氮苯 → 苯胺 → $\mathrm{MAO}$ → 酸。
:::

### （三）水解反应主要依靠酯酶、酰胺酶和糖苷酶

肝细胞溶酶体和细胞质中含有多种水解酶类，主要有酯酶（esterases）、酰胺酶（amidase）和糖苷酶（glucosidase），可分别催化脂质、酰胺类及糖苷类化合物中酯键、酰胺键和糖苷键的水解反应，以减低或消除其生物活性。应该指出的是，这些水解产物通常还需进一步转化反应才能排出体外。例如，阿司匹林（乙酰水杨酸）的生物转化过程中，首先是水解反应生成水杨酸或水解后先氧化成羟基水杨酸，然后是与葡萄糖醛酸的结合转化反应（图25-6）。

:::definition{label="第一相水解酶"}
酯酶、酰胺酶、糖苷酶。表25-2 定位写内质网或细胞质；正文还写肝细胞溶酶体和细胞质。分别水解酯键、酰胺键、糖苷键，减低或消除生物活性。水解产物通常还需进一步转化才能排出。
:::

:::definition{label="乙酰水杨酸的水解是第一相的开头"}
阿司匹林先水解生成水杨酸，或水解后先氧化成羟基水杨酸，然后与葡萄糖醛酸结合。图25-6 把水解、氧化及结合画在一起，正是连续性。

### （四）结合反应是生物转化的第二相反应

第一相反应生成的产物可直接排出体外。如果其水溶性仍不够大，则需再进行第二相反应，生成极性更强的化合物。有些被转化的物质也可不经过第一相反应而直接进入第二相反应。肝细胞内质网、细胞质或线粒体含有许多催化结合反应的酶类。含有羟基、羧基或氨基的化合物，可在肝细胞内与某些内源物质结合，从而增加水溶性，使其失去生物学活性（或毒性），并促进其排出，称为结合反应。常见的结合物或基团有葡萄糖醛酸、硫酸、乙酰基、甲基、谷胱甘肽及氨基酸等，尤以与葡萄糖醛酸的结合最为普遍（表25-4）。

:::definition{label="结合反应"}
含羟基、羧基或氨基的化合物在肝细胞内与某些内源物质结合，增加水溶性，失去生物学活性（或毒性），并促进排出。最普遍的是葡萄糖醛酸结合。
:::

:::keypoint{label="六种结合不要并户"}
葡萄糖醛酸（$\mathrm{UDPGA}$，$\mathrm{UGT}$，内质网）、硫酸（$\mathrm{PAPS}$，$\mathrm{SULT}$，胞质）、乙酰化（乙酰 $\mathrm{CoA}$，乙酰基转移酶，胞质）、谷胱甘肽（$\mathrm{GSH}$，$\mathrm{GST}$，胞质）、甲基化（$\mathrm{SAM}$，甲基转移酶，胞质）、甘氨酰基（$\mathrm{Gly}$，酰基转移酶，线粒体）。供体、酶、定位、底物四格按表25-4 记。
:::

:::

:::pitfall{label="胆红素出现在葡萄糖醛酸底物名单里，不是让本节写黄疸"}
表25-4 底物类型有胆红素。新生儿高胆红素血症与缺乏葡萄糖醛酸基转移酶有关——后文「年龄」那一条会再点名。分型、结合胆红素与游离胆红素是第四节。
:::

#### 1. 葡萄糖醛酸结合是最重要和最普遍的结合反应

糖醛酸循环代谢途径产生的尿苷二磷酸葡萄糖（$\mathrm{UDPG}$）可由 $\mathrm{UDPG}$ 脱氢酶催化生成尿苷二磷酸葡萄糖醛酸（$\mathrm{UDPGA}$）。

$\mathrm{UDPGA}$ 作为葡萄糖醛酸的活性供体，在肝内质网的 $\mathrm{UDP}$-葡萄糖醛酸基转移酶（UDP-glucuronosyltransferase，$\mathrm{UGT}$）催化下，可将具有多个羟基和可解离羧基的葡萄糖醛酸基转移到反应底物的羟基、氨基及羧基上形成相应的 $\beta$-$\mathrm{D}$-葡萄糖醛酸苷（图25-7），使其极性增加易排出体外。据研究，有数千种亲脂的内源物和异源物可与葡萄糖醛酸结合，如胆红素、类固醇激素、吗啡和苯巴比妥类药物等均可在肝与葡萄糖醛酸结合而进行生物转化，进而排出体外。临床上采用葡萄糖醛内酯治疗肝病，就是为了增加肝脏的生物转化功能。

:::definition{label="UDPGA"}
尿苷二磷酸葡萄糖醛酸。由糖醛酸途径的 $\mathrm{UDPG}$ 经 $\mathrm{UDPG}$ 脱氢酶生成。第一节已经写：肝细胞葡萄糖经糖醛酸途径生成 $\mathrm{UDPGA}$，是结合反应中最重要的结合物质。
:::

:::definition{label="UGT"}
$\mathrm{UDP}$-葡萄糖醛酸基转移酶，肝内质网。把葡萄糖醛酸基转到底物的羟基、氨基及羧基上，形成 $\beta$-$\mathrm{D}$-葡萄糖醛酸苷。数千种亲脂内源物和异源物可走这一户，本版点名胆红素、类固醇激素、吗啡和苯巴比妥类。
:::

:::definition{label="葡萄糖醛内酯"}
临床上采用葡萄糖醛内酯治疗肝病，是为了增加肝脏的生物转化功能。户头是补结合能力，不是另开一种保肝机制。
:::

教材图25-7 为葡萄糖醛酸结合反应。对应裁切为空文件，不嵌入。正文保留：$\mathrm{UDPGA}$ 为供体，$\mathrm{UGT}$ 催化，产物为 $\beta$-$\mathrm{D}$-葡萄糖醛酸苷。

#### 2. 硫酸结合也是常见的结合反应

肝细胞胞质存在硫酸基转移酶（sulfotransferase，$\mathrm{SULT}$），以 $3'$-磷酸腺苷 $5'$-磷酰硫酸（$\mathrm{PAPS}$）作为活性硫酸供体，可催化硫酸基转移到类固醇、酚或芳香胺类等内、外源待转化物质的羟基上生成硫酸酯，既可增加其水溶性易于排出，又可促进其失活。如雌酮与 $\mathrm{PAPS}$ 结合形成硫酸酯而灭活（图25-8）。

:::definition{label="PAPS 与 SULT"}
活性硫酸供体是 $3'$-磷酸腺苷 $5'$-磷酰硫酸（$\mathrm{PAPS}$）。酶是胞质硫酸基转移酶（$\mathrm{SULT}$）。底物：类固醇、酚或芳香胺的羟基 → 硫酸酯。增加水溶性并促进失活。
:::

:::definition{label="图25-8 雌酮的硫酸结合"}
雌酮 $+\ \mathrm{PAPS}$ → 雌酮硫酸酯 $+\ \mathrm{PAP}$。第一节激素灭活写类固醇与活性硫酸结合，这里给出具体反应。
:::

::figure{src="/images/biochemistry/textbook/p0497_01.png" caption="图25-8　雌酮的硫酸结合反应" alt="左侧雌酮甾体骨架，A 环酚羟基为 HO；加 PAPS 后右侧变为雌酮硫酸酯，该羟基改为 HOS3O，并释放 PAP"}

:::insight{label="图25-8 只改 A 环羟基"}
画面左边雌酮 A 环带酚羟基，右边变成硫酸酯（$\mathrm{HOS}_3\mathrm{O}$），供体写 $\mathrm{PAPS}$，离去基团写 $\mathrm{PAP}$。不要把这张图认成葡萄糖醛酸苷，也不要认成乙酰化。
:::

#### 3. 乙酰化是某些含胺类异源物的重要转化反应

肝细胞细胞质富含乙酰基转移酶（acetyltransferase），以乙酰 $\mathrm{CoA}$ 为乙酰基的直接供体，催化乙酰基转移到含氨基或肼的内、外源待转化物质（如异烟肼、磺胺、苯胺等），形成相应的乙酰化衍生物。例如，抗结核病药物异烟肼经乙酰化而失去活性（图25-9）。

此外，大部分磺胺类药物在肝内也通过这种形式灭活。但应指出，磺胺类药物经乙酰化后，其溶解度反而降低，在酸性尿中易于析出，故在服用磺胺类药物时应服用适量的碳酸氢钠，以提高其溶解度，利于随尿排出。

:::definition{label="乙酰化"}
胞质乙酰基转移酶，供体乙酰 $\mathrm{CoA}$。底物含氨基或肼：异烟肼、磺胺、苯胺等。抗结核药异烟肼经乙酰化失去活性。
:::

:::definition{label="磺胺乙酰化后溶解度下降"}
大部分磺胺药在肝内也经乙酰化灭活，但溶解度反而降低，酸性尿中易于析出。服药时应服用适量碳酸氢钠，提高溶解度，利于随尿排出。
:::

:::note{label="图25-9 电子版缺失"}
教材图25-9 为异烟肼及磺胺药乙酰化反应。对应裁切为空文件，不嵌入。正文保留：乙酰 $\mathrm{CoA}$ 供乙酰基；异烟肼失活；磺胺乙酰化后溶解度降低。
:::

:::pitfall{label="结合不一定增加溶解度"}
多数结合增加水溶性。磺胺乙酰化是反例：灭活了，但更易在酸性尿中析出。不要把「第二相＝一定更好排」写成绝对句，这一户要单记碳酸氢钠。
:::

#### 4. 谷胱甘肽结合是细胞应对亲电子性异源物的重要防御反应

肝细胞的细胞质富含谷胱甘肽 $\mathrm{S}$-转移酶（glutathione S-transferase，$\mathrm{GST}$），可催化谷胱甘肽（$\mathrm{GSH}$）与含有亲电子中心的环氧化物和卤代化合物等异源物结合，生成谷胱甘肽结合产物。主要参与对致癌物、环境污染物、抗肿瘤药物以及内源性活性物质的生物转化（图25-10）。亲电子性异源物若不与 $\mathrm{GSH}$ 结合，则可自由地共价结合 $\mathrm{DNA}$、$\mathrm{RNA}$ 或蛋白质，导致细胞严重损伤。此外，谷胱甘肽结合反应也是细胞自我保护的重要反应。很多内源性底物受活性氧（$\mathrm{ROS}$）修饰后形成具有细胞毒作用的氧化修饰产物。所以，$\mathrm{GSH}$ 不仅具有抗氧化作用，还可结合氧化修饰产物，减低其细胞毒性，增加其水溶性易于排出体外。

:::definition{label="GST 与 GSH"}
胞质谷胱甘肽 $\mathrm{S}$-转移酶催化 $\mathrm{GSH}$ 与亲电子中心的环氧化物、卤代化合物结合。对象：致癌物、环境污染物、抗肿瘤药物及内源性活性物质。不结合则可共价结合 $\mathrm{DNA}$、$\mathrm{RNA}$ 或蛋白质。
:::

:::definition{label="GSH 的两句话"}
不仅抗氧化，还可结合 $\mathrm{ROS}$ 造成的氧化修饰产物，减低细胞毒性并增加水溶性。饥饿数天 $\mathrm{GST}$ 受影响——后文营养因素会再写。
:::

::figure{src="/images/biochemistry/textbook/p0497_03.png" caption="图25-10　黄曲霉素谷胱甘肽结合反应" alt="左侧黄曲霉素B1-8,9-环氧化物，末端呋喃环上有环氧；加 GSH，GST 催化后右侧开环，出现 OH 与 SG 取代，产物为谷胱甘肽结合产物"}

:::insight{label="图25-10 对着图25-3 的环氧化物"}
第一相单加氧酶把黄曲霉素 $\mathrm{B}_1$ 做成环氧化物（图25-3 正文写 $2,3$ 环氧化物；本图画面标 $\mathrm{B}_1$-$8,9$-环氧化物）。第二相 $\mathrm{GST}$ 把 $\mathrm{GSH}$ 接上去，环氧开环，生成谷胱甘肽结合产物。没有这一步，环氧化物就去打鸟嘌呤。两相不要并成「黄曲霉素直接结合 $\mathrm{GSH}$」。

#### 5. 甲基化反应是代谢内源化合物的重要反应

肝细胞中含有多种甲基转移酶，以 $\mathrm{S}$-腺苷甲硫氨酸（$\mathrm{SAM}$）为活性甲基供体，催化含有氧、氮、硫等亲核基团化合物的甲基化反应。其中，细胞质中可溶性儿茶酚-$\mathrm{O}$-甲基转移酶（catechol-O-methyltransferase，$\mathrm{COMT}$）具有重要的生理功能。$\mathrm{COMT}$ 催化儿茶酚和儿茶酚胺的羟基甲基化，生成有活性的儿茶酚化合物（图25-11）。同时，$\mathrm{COMT}$ 也参与生物活性胺如多巴胺类的灭活等。

:::definition{label="SAM 与甲基化"}
活性甲基供体是 $\mathrm{S}$-腺苷甲硫氨酸（$\mathrm{SAM}$）。酶是多种甲基转移酶，胞质。对象：含氧、氮、硫等亲核基团的化合物。
:::

:::definition{label="COMT"}
儿茶酚-$\mathrm{O}$-甲基转移酶，胞质可溶性。催化儿茶酚和儿茶酚胺的羟基甲基化；也参与多巴胺类等生物活性胺的灭活。图25-11 电子版缺失。
:::

教材图25-11 为儿茶酚甲基化反应。对应裁切为空文件，不嵌入。正文保留：$\mathrm{SAM}$ 供甲基，$\mathrm{COMT}$ 催化儿茶酚／儿茶酚胺羟基甲基化，并参与多巴胺类灭活。
:::

#### 6. 甘氨酸主要参与含羧基异源物的生物转化

含羧基的药物、毒物等异源物首先在酰基 $\mathrm{CoA}$ 连接酶催化下生成活泼的酰基 $\mathrm{CoA}$，再在肝线粒体基质酰基 $\mathrm{CoA}$：氨基酸 $\mathrm{N}$-酰基转移酶（acyl CoA: amino acid N-acyltransferase）的催化下与甘氨酸、牛磺酸结合生成相应的结合产物。如马尿酸、甘氨胆酸、牛磺胆酸的生成等（图25-12）。

:::definition{label="甘氨酸／牛磺酸结合"}

## 三、生物转化作用受许多因素的调节和影响

肝的生物转化作用受年龄、性别、营养、疾病、遗传和诱导物等体内、外诸多因素的影响。

### （一）多种体内因素影响生物转化效率

**1. 年龄对生物转化作用的影响很明显**　人肝的生物转化酶有一个发育的过程。新生儿肝生物转化酶系发育尚不完善，对药物及毒物的转化能力较弱，容易发生中毒。新生儿的高胆红素血症与缺乏葡萄糖醛酸基转移酶有关，此酶活性在出生 $5\sim 6$ 天后才开始升高，$1\sim 3$ 个月后接近成人水平。老年人肝的生物转化能力和肝生物转化酶的诱导作用仍属正常，但老年人肝血流量及肾的廓清速率下降，导致老年人血浆药物的清除率降低，药物在体内的半衰期延长。例如，安替匹林和消炎镇痛药保泰松的半衰期在青年人分别为 $12$ 小时和 $81$ 小时，老年人则分别为 $17$ 小时和 $105$ 小时。因此，临床上对新生儿及老年人的药物用量应较成人为低，许多药物使用时都要求儿童和老人慎用或禁用。

:::definition{label="新生儿 UGT 发育晚"}
新生儿高胆红素血症与缺乏葡萄糖醛酸基转移酶有关。此酶活性出生 $5\sim 6$ 天后才开始升高，$1\sim 3$ 个月后接近成人水平。新生儿对药物及毒物转化能力弱，容易中毒。
:::

:::definition{label="老年人清除慢在血流和肾，不在酶诱导"}
老年人肝的生物转化能力和酶的诱导作用仍属正常，但肝血流量及肾的廓清速率下降，血浆药物清除率降低，半衰期延长。安替匹林：$12$ 小时 → $17$ 小时；保泰松：$81$ 小时 → $105$ 小时。
:::

:::timeline{period="UGT 与药物剂量随年龄"}
- **新生儿** 酶系不完善，UGT 生后 5～6 天才开始升高，1～3 个月接近成人；高胆红素血症与此有关
- **儿童** 许多药物慎用或禁用
- **青年** 安替匹林半衰期 12 小时，保泰松 81 小时
- **老年** 酶诱导仍正常，但肝血流量和肾廓清下降；安替匹林 17 小时，保泰松 105 小时；用量应较成人为低
:::

:::pitfall{label="不要把老年人写成「肝酶已经坏了」"}
教材把老年人的酶诱导写成仍属正常。慢的是血流量和肾廓清。写成「老人 $\mathrm{P}450$ 都没有了」，和后文「诱导作用仍正常」冲突。
:::

**2. 某些生物转化反应存在明显的性别差异**　一般女性的生物转化能力更强，例如女性体内醇脱氢酶活性高于男性，对乙醇的代谢处理能力比男性强。氨基比林在男性体内的半衰期约 $13.4$ 小时，而女性则为 $10.3$ 小时，说明女性对氨基比林的转化能力比男性强。妊娠期妇女肝清除抗癫痫药的能力升高，但晚期妊娠妇女的生物转化能力普遍降低。

:::definition{label="性别差异"}
一般女性更强：醇脱氢酶活性高于男性；氨基比林半衰期男性约 $13.4$ 小时、女性 $10.3$ 小时。妊娠期清除抗癫痫药能力升高；晚期妊娠则普遍降低。
:::

:::pitfall{label="妊娠不要写成全程转化都增强"}
「妊娠期妇女肝清除抗癫痫药的能力升高」和「晚期妊娠妇女的生物转化能力普遍降低」是两句。不要并成「孕妇一律加强」或「孕妇一律减弱」。
:::

**3. 营养状况对生物转化作用亦产生影响**　蛋白质的摄入可以增加肝细胞整体生物转化酶的活性，提高生物转化的效率。饥饿数天，肝谷胱甘肽 $\mathrm{S}$ 转移酶（$\mathrm{GST}$）作用受到明显影响，其参加的生物转化反应水平降低。大量饮酒，因乙醇氧化为乙醛及乙酸，再进一步氧化成乙酰 $\mathrm{CoA}$，产生 $\mathrm{NADH}$，可使细胞内 $\mathrm{NAD}^{+}/\mathrm{NADH}$ 比值降低，从而减少 $\mathrm{UDP}$-葡萄糖转变成 $\mathrm{UDPGA}$，影响了肝内葡萄糖醛酸结合转化反应。

:::definition{label="蛋白质与饥饿"}
蛋白质摄入增加整体生物转化酶活性。饥饿数天，$\mathrm{GST}$ 明显受影响，谷胱甘肽结合水平降低。
:::

:::definition{label="大量饮酒削弱葡萄糖醛酸结合"}
乙醇氧化推高 $\mathrm{NADH}$，$\mathrm{NAD}^{+}/\mathrm{NADH}$ 下降，减少 $\mathrm{UDPG}$ → $\mathrm{UDPGA}$，葡萄糖醛酸结合受影响。第一相在「解酒」，第二相最普遍的结合反而被拖累。
:::

**4. 疾病尤其严重肝病可明显影响生物转化作用**　肝实质损伤直接影响肝生物转化酶类的合成。例如严重肝病时单加氧酶系活性可降低 $50\%$。肝细胞损害导致 $\mathrm{NADPH}$ 合成减少也影响肝对血浆药物的清除率。肝功能低下对包括药物或毒物在内的许多异源物的摄取及灭活速度下降，药物的治疗剂量与毒性剂量之间的差距减小，容易造成肝损害，故对肝病病人用药应特别慎重。

:::definition{label="严重肝病时单加氧酶可降 50%"}
肝实质损伤直接影响酶合成；$\mathrm{NADPH}$ 合成减少也影响血浆药物清除率。治疗剂量与毒性剂量差距减小，肝病病人用药应特别慎重。
:::

:::cause-effect{title="肝病 → 治疗窗变窄"}
酶少、$\mathrm{NADPH}$ 少 → 摄取及灭活变慢 → 治疗剂量与毒性剂量靠近 → 更容易造成肝损害。这是「保肝同时更要慎用药」，不是「肝病就加大解毒药」。
:::

**5. 遗传因素亦可显著影响生物转化酶的活性**　遗传变异可引起个体之间生物转化酶分子结构的差异或酶合成量的差异。变异产生的低活性酶可因影响药物代谢而造成药物在体内的蓄积。相反，变异导致的高活性酶则可缩短药物的作用时间或造成药物代谢毒性产物的增多。目前已知，许多肝生物转化的酶类存在酶活性异常的多态性，如醛脱氢酶、葡萄糖醛酸基转移酶、谷胱甘肽 $\mathrm{S}$-转移酶等。

:::definition{label="遗传多态性"}
低活性 → 药物蓄积；高活性 → 作用时间缩短或毒性产物增多。本版点名：醛脱氢酶、葡萄糖醛酸基转移酶、谷胱甘肽 $\mathrm{S}$-转移酶。东方人 $\mathrm{ALDH}$ $45:10:45$ 已经是这一户的数字。
:::

### （二）体外因素通过诱导或抑制生物转化酶影响生物转化

许多异源物可以诱导相关生物转化酶的合成，长期服用该药物时容易产生耐药性。例如长期服用苯巴比妥、降糖药甲苯磺丁脲可诱导肝单加氧酶系的合成，使机体对苯巴比妥类催眠药和甲苯磺丁脲的转化能力增强，是耐药性产生的重要因素之一。因为单加氧酶特异性较差，因此可利用其诱导作用增强对其他药物的代谢以达到解毒的效果，如用苯巴比妥减低地高辛中毒。苯巴比妥还可诱导肝 $\mathrm{UDPGA}$ 转移酶的合成，临床上用其增加机体对游离胆红素的结合转化反应，治疗新生儿黄疸。有些毒物，如烟草中的苯并芘可诱导肺泡吞噬细胞中芳香烃羟化酶的合成，故吸烟者羟化酶的活性明显高于非吸烟者。

由于多种物质在体内转化常由同一酶系催化，因此同时服用多种药物时可出现药物之间对同一转化酶系的竞争性抑制作用，使药物的生物转化作用相互抑制，导致某些药物药理作用强度的改变。例如保泰松可抑制双香豆素类药物的代谢，两者同时服用时保泰松可增强双香豆素的抗凝作用，但易发生出血现象，因此同时服用多种药物时应予注意。

此外，食物中亦常含有诱导或抑制生物转化酶的物质。例如烧烤食物、甘蓝、萝卜等含有肝单加氧酶系的诱导物，而水田芥则含有该酶的抑制剂。食物中的黄酮类可抑制单加氧酶系的活性。

:::definition{label="酶诱导与耐药"}
长期服用苯巴比妥、甲苯磺丁脲可诱导肝单加氧酶系，转化增强，是耐药性产生的重要因素之一。
:::

:::definition{label="苯巴比妥的两件临床用途"}
①单加氧酶特异性较差，可用其诱导增强对其他药物的代谢，如减低地高辛中毒。②诱导肝 $\mathrm{UDPGA}$ 转移酶，增加游离胆红素的结合，治疗新生儿黄疸。游离胆红素结合只点到这一句，黄疸分型是第四节。
:::

:::definition{label="苯并芘诱导芳香烃羟化酶"}
烟草中的苯并芘可诱导肺泡吞噬细胞中芳香烃羟化酶的合成，吸烟者该酶活性明显高于非吸烟者。开篇苯并芘转化后成直接致癌物，与这一诱导不要并成「吸烟等于解毒」。
:::

:::definition{label="保泰松与双香豆素"}
保泰松抑制双香豆素类药物的代谢，同时服用可增强抗凝作用，但易出血。同一酶系的竞争性抑制是「多药合用」的生化机制。
:::

:::definition{label="食物里的诱导物和抑制剂"}
诱导：烧烤食物、甘蓝、萝卜等（肝单加氧酶系）。抑制：水田芥；食物中的黄酮类。
:::

:::compare{title="诱导 vs 抑制"}
| | 本版例子 | 后果 |
|--|---------|------|
| 诱导单加氧酶 | 苯巴比妥、甲苯磺丁脲；烧烤、甘蓝、萝卜；苯并芘 → 芳香烃羟化酶 | 耐药；也可用来加速地高辛代谢；吸烟者酶活性高 |
| 诱导 $\mathrm{UGT}$ | 苯巴比妥 | 治疗新生儿黄疸 |
| 抑制 | 保泰松抑制双香豆素代谢；水田芥、黄酮类抑制单加氧酶；奥美拉唑强抑制 $\mathrm{P}450$ | 出血；转化变慢；转氨酶升高 |

问「苯巴比妥为什么能治新生儿黄疸」看 $\mathrm{UGT}$，不是看它催眠。
:::

:::pitfall{label="诱导不是无害的「酶变多」"}
苯并芘本身经转化成为直接致癌物，又能诱导芳香烃羟化酶。酶多了可以耐药、可以解毒地高辛，也可以把前致癌物推得更快。双重性从开篇一直管到这一小节。
:::

:::memory{label="本节必背分户"}
- 生物转化：内／外源非营养物质化学转变，增加水溶性和极性，经胆汁或尿排出。不能简单称为解毒。
- 特点：连续、多样、解毒与致毒双重性。苯并芘、黄曲霉素可更毒；环磷酰胺、百浪多息、水合氯醛、大黄需转化才有活性。
- 第一相：氧化、还原、水解。$\mathrm{CYP}$ 在内质网，一个氧进底物、一个成水；$57$ 种基因，$\mathrm{CYP}3\mathrm{A}4$ 占 $30\%\sim 40\%$。$\mathrm{MAO}$ 在线粒体。$\mathrm{ADH}$ $K_{\mathrm{m}}$ $2\,\mathrm{mmol/L}$，$\mathrm{CYP}2\mathrm{E}1$ $K_{\mathrm{m}}$ $8.6\,\mathrm{mmol/L}$。
- 第二相：葡萄糖醛酸最普遍（$\mathrm{UDPGA}$／$\mathrm{UGT}$）；硫酸（图25-8 雌酮）；乙酰化（异烟肼、磺胺＋碳酸氢钠）；$\mathrm{GSH}$（图25-10）；甲基化（$\mathrm{SAM}$／$\mathrm{COMT}$）；甘氨酸（图25-12 马尿酸）。
- 年龄：新生儿 $\mathrm{UGT}$ 生后 $5\sim 6$ 天升，$1\sim 3$ 月近成人；老人酶诱导正常但血流和肾廓清下降。
- 苯巴比妥诱导单加氧酶（耐药、解地高辛毒）并诱导 $\mathrm{UGT}$（新生儿黄疸）。保泰松＋双香豆素易出血。
:::
