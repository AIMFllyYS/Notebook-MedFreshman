# 第一节　核苷酸代谢概述

核苷酸是核酸的基本结构单位，也是细胞里随时可花的能量货币和辅酶构件。人体内的核苷酸主要由自身合成，因此不属于营养必需物质。本节先把户头摊开：细胞内以 $5'$-核苷酸为主、$\mathrm{ATP}$ 最多；五种生物学功能；核酸酶把食物核酸切成可吸收的核苷和碱基；合成有从头与补救两条，分解则嘌呤走尿酸、嘧啶走易溶的 $\beta$-氨基酸。第二节写嘌呤，第三节写嘧啶和抗代谢物。

核苷酸在体内分布广泛，发挥多种重要的生物学功能。核苷酸可由核酸酶水解核酸产生，也可利用体内原料合成。本章主要从代谢角度介绍人体细胞合成嘌呤和嘧啶核苷酸的过程，以及二者的分解。合成及分解过程异常与某些疾病的发生及治疗密切相关；一些嘌呤、嘧啶、氨基酸或叶酸类似物可通过竞争性机制抑制核苷酸的合成，称为抗代谢物，在肿瘤的治疗中发挥重要作用。

:::definition{label="核苷酸"}
核苷酸是核酸的基本结构单位。人体内的核苷酸主要由自身合成，因此不属于营养必需物质。
:::

:::concept{term="先问是不是营养必需，再问从头还是补救"}
看见“核苷酸代谢”，不要先默写 $\mathrm{IMP}$ 的 $11$ 步。户头是：食物里的嘌呤、嘧啶碱很少被机体利用，细胞必须自己写核苷酸。自己写有两条路——简单原料拼杂环（从头），或把现成碱基、核苷拣回来（补救）。分解账另立：嘌呤终产物是水溶性较差的尿酸，嘧啶终产物易溶于水。
:::

:::pitfall{label="核苷酸不是营养必需物质，不等于细胞不需要核苷酸"}
“不属于营养必需”说的是膳食里不必专门供给现成核苷酸。核酸合成、$\mathrm{ATP}$ 供能、辅酶和活化中间物仍然每时每刻要用。缺的是“食物碱基直接装进核酸”这一笔，不是细胞内没有核苷酸。
:::

核苷酸在细胞中主要以 $5'$-核苷酸形式存在，其中 $5'$-$\mathrm{ATP}$ 含量最多。通常情况下，细胞中核苷酸的浓度远远超过脱氧核苷酸，前者约在毫摩尔（$\mathrm{mmol}$）范围，而后者只在微摩尔（$\mu\mathrm{mol}$）水平。在细胞分裂周期中，细胞内脱氧核苷酸含量波动范围较大，核苷酸浓度则相对稳定。不同类型细胞中各种核苷酸含量差异很大。而在同一种细胞中，各种核苷酸含量虽也有差异，但核苷酸总含量变化不大。

:::definition{label="细胞内的核苷酸库"}
细胞中的核苷酸主要以 $5'$-核苷酸形式存在，$5'$-$\mathrm{ATP}$ 含量最多。核糖核苷酸浓度约在毫摩尔范围，脱氧核苷酸只在微摩尔水平。
:::

:::compare{title="核糖核苷酸与脱氧核苷酸的浓度档"}
| 项目 | 核糖核苷酸 | 脱氧核苷酸 |
|------|------------|------------|
| 数量级 | 约毫摩尔（$\mathrm{mmol}$） | 微摩尔（$\mu\mathrm{mol}$） |
| 细胞周期中的波动 | 浓度相对稳定 | 波动范围较大 |
| 同一种细胞内 | 各分子含量有差异，但核苷酸总含量变化不大 | 增殖旺盛时明显增加（第二节） |

不同类型细胞之间，各种核苷酸含量可以差得很开；比较的是“同一细胞内总量相对稳定”，不是“所有细胞都一样”。
:::

:::insight{label="dNTP 少、而且会随周期涨落，是因为 DNA 只在复制时大量要"}
$\mathrm{NTP}$ 还要供能、写辅酶、当活化载体，所以库容大、相对稳。$\mathrm{dNTP}$ 几乎只给 $\mathrm{DNA}$ 用，平时压在微摩尔，分裂时再抬。第二节把脱氧核糖的生成写在核苷二磷酸水平，就是给这一笔涨落准备开关。
:::

:::pitfall{label="不要把 mmol 档的 NTP 听成 dNTP"}
教材把数量级差三个档写死了。把“细胞里到处是核苷酸”直接抄到 $\mathrm{dTTP}/\mathrm{dATP}$，后面核糖核苷酸还原酶的别构调节就没有对立面：正是因为 $\mathrm{dNTP}$ 少，才必须按比例精调。
:::

## 一、核苷酸具有多种生物学功能

核苷酸具有多种生物学功能。教材按五条立户，第一条是最主要的。

**① 作为核酸合成的原料**　这是核苷酸最主要的功能。$\mathrm{DNA}$ 的基本组成单位是脱氧核糖核苷酸，$\mathrm{RNA}$ 的基本组成单位是核糖核苷酸（第三章）。没有足够的 $\mathrm{NTP}$ 和 $\mathrm{dNTP}$，复制、转录都会停。抗代谢物正是卡在这一条上：挡住核苷酸合成，核酸和蛋白质的生物合成随后一起停，肿瘤细胞因合成旺盛而对这一刀更敏感。

**② 作为体内能量的利用形式**　$\mathrm{ATP}$ 是细胞的主要能量形式。此外 $\mathrm{GTP}$ 等也可以提供能量。第十章已经把 $\mathrm{ATP}$ 写成能量代谢的核心：高能磷酸键、基团转移、与 $\mathrm{GTP}$、$\mathrm{UTP}$、$\mathrm{CTP}$ 互转。本章不重写呼吸链，只强调：核苷酸既是物质代谢的产物，也是能量货币本身。

**③ 参与代谢和生理调节**　某些核苷酸或其衍生物是重要的调节分子。例如 $\mathrm{cAMP}$ 是多种细胞膜受体经激素等激活后产生的第二信使；$\mathrm{cGMP}$ 可参与代谢调节。

**④ 组成辅酶**　腺苷酸可作为多种辅酶（$\mathrm{NAD}^{+}$、$\mathrm{FAD}$、$\mathrm{CoA}$ 等）的组成成分。没有腺苷酸这一截，脱氢酶和酰基转移都会缺构件。

**⑤ 活化中间代谢物**　核苷酸可以作为多种活化中间代谢物的载体。例如 $\mathrm{UDP}$-葡萄糖是合成糖原、糖蛋白的活性原料，$\mathrm{CDP}$-甘油二酯是合成磷脂的活性原料，$S$-腺苷甲硫氨酸是活性甲基的载体等。$\mathrm{ATP}$ 还可作为蛋白激酶反应中磷酸基团的供体。

:::definition{label="核苷酸最主要的功能"}
作为核酸合成的原料，是核苷酸最主要的功能。
:::

:::definition{label="ATP 作为能量形式"}
$\mathrm{ATP}$ 是细胞的主要能量形式。此外 $\mathrm{GTP}$ 等也可以提供能量。
:::

:::definition{label="cAMP 与 cGMP"}
$\mathrm{cAMP}$ 是多种细胞膜受体经激素等激活后产生的第二信使。$\mathrm{cGMP}$ 可参与代谢调节。二者都是核苷酸衍生物充当调节分子的例子。
:::

:::definition{label="腺苷酸组成辅酶"}
腺苷酸是多种辅酶的组成成分，教材点名 $\mathrm{NAD}^{+}$、$\mathrm{FAD}$、$\mathrm{CoA}$。
:::

:::definition{label="核苷酸作为活化中间物载体"}
$\mathrm{UDP}$-葡萄糖是合成糖原、糖蛋白的活性原料；$\mathrm{CDP}$-甘油二酯是合成磷脂的活性原料；$S$-腺苷甲硫氨酸是活性甲基的载体。$\mathrm{ATP}$ 还作为蛋白激酶反应中磷酸基团的供体。
:::

:::compare{title="核苷酸的五种功能"}
| 序号 | 功能 | 教材例子 | 不要并到哪一本账 |
|------|------|----------|------------------|
| ① | 核酸原料（最主要） | $\mathrm{NTP}$、$\mathrm{dNTP}$ 写 $\mathrm{RNA}$、$\mathrm{DNA}$ | 不是“有 $\mathrm{ATP}$ 就等于有核酸” |
| ② | 能量利用形式 | $\mathrm{ATP}$ 为主，$\mathrm{GTP}$ 等也可供能 | 第十章呼吸链产 $\mathrm{ATP}$，本章用 $\mathrm{ATP}$ |
| ③ | 代谢和生理调节 | $\mathrm{cAMP}$ 第二信使，$\mathrm{cGMP}$ 参与调节 | 不是把所有核苷酸都写成激素 |
| ④ | 组成辅酶 | 腺苷酸进入 $\mathrm{NAD}^{+}$、$\mathrm{FAD}$、$\mathrm{CoA}$ | 辅酶功能在维生素／脱氢酶章，构件在本章 |
| ⑤ | 活化中间代谢物 | $\mathrm{UDP}$-葡萄糖、$\mathrm{CDP}$-甘油二酯、$\mathrm{SAM}$；蛋白激酶的磷酸供体 | 糖原、磷脂、甲基化各走各章，载体都是核苷酸 |
:::

:::keypoint{label="五种功能先记‘原料第一’"}
- 最主要：写核酸。
- 其次才是能量、信使、辅酶构件、活化载体。
- 抗代谢物、痛风、补救缺陷，临床账都从“细胞必须不断写核苷酸”来。
:::

:::insight{label="UDP、CDP、SAM 把本章接到糖、脂质和氨基酸"}
第七章糖原用 $\mathrm{UDP}$-葡萄糖，第八章磷脂用 $\mathrm{CDP}$-甘油二酯，第九章活性甲基用 $S$-腺苷甲硫氨酸。载体都是核苷酸，底物却分属三章。把“活化中间物”只记成 $\mathrm{ATP}$ 供磷酸，会漏掉尿苷和胞苷这一笔。
:::

:::pitfall{label="GTP 可以供能，但不替代 ATP 当‘主要能量形式’"}
教材写“$\mathrm{ATP}$ 是细胞的主要能量形式。此外 $\mathrm{GTP}$ 等也可以提供能量”。蛋白合成、糖异生的某些步骤花 $\mathrm{GTP}$，那是指定反应的能量货币，不是另立一套与 $\mathrm{ATP}$ 平行的“主账”。第二节 $\mathrm{IMP}\rightarrow\mathrm{AMP}$ 要 $\mathrm{GTP}$、$\mathrm{IMP}\rightarrow\mathrm{GMP}$ 要 $\mathrm{ATP}$，交叉调节维持的就是这两本货币的平衡。
:::

:::memory{label="五种功能口诀"}
- [ ] 原料、能量、调节、辅酶、活化载体。
- [ ] 原料最主要；能量 $\mathrm{ATP}$ 为主。
- [ ] 调节：$\mathrm{cAMP}$、$\mathrm{cGMP}$。
- [ ] 辅酶：腺苷酸 $\rightarrow\mathrm{NAD}^{+}$、$\mathrm{FAD}$、$\mathrm{CoA}$。
- [ ] 载体：$\mathrm{UDP}$-葡萄糖、$\mathrm{CDP}$-甘油二酯、$\mathrm{SAM}$；蛋白激酶的磷酸来自 $\mathrm{ATP}$。
:::

## 二、核酸经水解后被吸收

食物核酸很少以游离核苷酸进细胞。先要被核酸酶逐步切开，核苷和碱基再被吸收；吸收之后，绝大部分还要在肠黏膜里继续分解。这一节把“吃进去的核酸”和“细胞自己写的核苷酸”拆成两本账。

### （一）核酸酶是可以水解 DNA 和 RNA 的酶

核酸酶是水解核酸的酶。可根据底物、作用方式等进行分类。

依据核酸酶作用的底物不同，可以将其分为 $\mathrm{DNA}$ 酶（deoxyribonuclease，$\mathrm{DNase}$）和 $\mathrm{RNA}$ 酶（ribonuclease，$\mathrm{RNase}$）两类。$\mathrm{DNA}$ 酶能够专一性地催化脱氧核糖核酸的水解，而 $\mathrm{RNA}$ 酶能专一性地催化核糖核酸的水解。按照对底物二级结构的专一性，核酸酶还有单链酶和双链酶之分。

依据对底物的作用方式，可将核酸酶分为核酸外切酶（exonuclease）和核酸内切酶（endonuclease）。核酸外切酶只能水解位于核酸分子链末端的磷酸二酯键。根据其作用的方向性，又有 $5'\rightarrow 3'$ 核酸外切酶和 $3'\rightarrow 5'$ 核酸外切酶之分：从 $5'$ 端切除核苷酸的酶称为 $5'\rightarrow 3'$ 核酸外切酶；从 $3'$ 端切除核苷酸的酶称为 $3'\rightarrow 5'$ 核酸外切酶。核酸内切酶只可以在 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 链的内部切断磷酸二酯键。有些核酸内切酶的酶切位点具有核酸序列特异性，称为限制性核酸内切酶（restriction endonuclease）。一般而言，限制性核酸内切酶的酶切位点的核酸序列具有回文结构，识别长度为 $4\sim 8\,\mathrm{bp}$。有些核酸内切酶则没有序列特异性的要求。

:::definition{label="核酸酶"}
核酸酶是水解核酸的酶。可按底物分为 $\mathrm{DNA}$ 酶和 $\mathrm{RNA}$ 酶，按作用方式分为核酸外切酶和核酸内切酶，按底物二级结构还可分为单链酶和双链酶。
:::

:::definition{label="DNA 酶与 RNA 酶"}
$\mathrm{DNA}$ 酶（deoxyribonuclease，$\mathrm{DNase}$）专一催化脱氧核糖核酸水解。$\mathrm{RNA}$ 酶（ribonuclease，$\mathrm{RNase}$）专一催化核糖核酸水解。
:::

:::definition{label="核酸外切酶"}
核酸外切酶（exonuclease）只能水解位于核酸分子链末端的磷酸二酯键。按方向分为 $5'\rightarrow 3'$ 核酸外切酶和 $3'\rightarrow 5'$ 核酸外切酶。
:::

:::definition{label="核酸内切酶"}
核酸内切酶（endonuclease）只可以在 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 链的内部切断磷酸二酯键。有的有序列特异性，有的没有。
:::

:::definition{label="限制性核酸内切酶"}
限制性核酸内切酶（restriction endonuclease）是酶切位点具有核酸序列特异性的核酸内切酶。一般而言，识别序列具有回文结构，识别长度为 $4\sim 8\,\mathrm{bp}$。
:::

:::compare{title="核酸酶的三种分法"}
| 分类依据 | 类别 | 要点 |
|----------|------|------|
| 底物 | $\mathrm{DNase}$ / $\mathrm{RNase}$ | 分别切 $\mathrm{DNA}$、$\mathrm{RNA}$ |
| 二级结构 | 单链酶 / 双链酶 | 对单链或双链核酸的专一性 |
| 作用方式 | 外切酶 / 内切酶 | 末端磷酸二酯键 vs 链内部；外切还要分 $5'\rightarrow 3'$ 与 $3'\rightarrow 5'$ |
:::

:::pitfall{label="限制酶是内切酶里的一类，不是所有内切酶都认回文"}
教材先写“内切酶切内部”，再写“有些具有序列特异性，称为限制性核酸内切酶”，紧接着补“有些核酸内切酶则没有序列特异性的要求”。把内切酶全部听成限制酶，消化液里的 $\mathrm{DNase}/\mathrm{RNase}$ 会对不上号。
:::

:::insight{label="回文和 4～8 bp 是工具酶的识别习惯，不是消化酶的要求"}
食物核酸在小肠被切开，不需要读序列。限制酶成为分子生物学工具，靠的正是“认一段回文再切”。两本账都叫核酸酶，底物可以都是 $\mathrm{DNA}$，专一性完全不同。
:::

细胞内的核酸酶一方面参与 $\mathrm{DNA}$ 的合成与修复、$\mathrm{RNA}$ 合成后的剪接等 $\mathrm{DNA}$ 复制和基因表达过程；另一方面负责清除多余的、结构和功能异常的核酸，同时也可以清除侵入细胞的外源性核酸。这些作用对于维持细胞的正常活动具有重要意义。核酸酶还可以分泌到细胞外，例如在人体消化液中的核酸酶可以降解食物中的核酸以利吸收。特别是限制性核酸内切酶，由于它能够特异性地识别酶切位点，已经成为分子生物学中的重要工具酶，目前已发现的有 $3\,000$ 余种。

有些核酸酶属于多功能酶。例如，原核生物 $\mathrm{DNA}$ 聚合酶同时具有核酸外切酶活性，在 $\mathrm{DNA}$ 复制过程中可以切除错配的碱基，保证 $\mathrm{DNA}$ 生物合成的精确性。

:::definition{label="细胞内核酸酶的两类工作"}
细胞内核酸酶既参与 $\mathrm{DNA}$ 合成与修复、$\mathrm{RNA}$ 剪接等复制和表达过程，也负责清除多余的、异常的核酸以及侵入的外源核酸。
:::

:::definition{label="消化液中的核酸酶"}
核酸酶可以分泌到细胞外。人体消化液中的核酸酶降解食物核酸，以利吸收。
:::

:::definition{label="多功能核酸酶"}
有些核酸酶属于多功能酶。原核生物 $\mathrm{DNA}$ 聚合酶同时具有核酸外切酶活性，复制时可切除错配碱基，保证 $\mathrm{DNA}$ 生物合成的精确性。
:::

:::keypoint{label="核酸酶不只是‘消化酶’"}
- 核内／胞内：复制、修复、剪接、清垃圾、清外源核酸。
- 胞外：消化液，切开食物核酸。
- 工具：限制酶，已发现 $3\,000$ 余种。
- 校对：原核 $\mathrm{DNA}$ 聚合酶带外切活性，切错配。
:::

:::pitfall{label="原核 DNA 聚合酶的外切活性是校对，不是把基因组嚼碎"}
多功能酶这一笔，外切发生在复制叉上、针对错配。不要把它和小肠里的 $\mathrm{DNase}$ 并成“聚合酶也能消化食物核酸”。
:::

### （二）核苷酸的分解产物部分可被重新利用

食物中的核酸多以核蛋白的形式存在。核蛋白在胃中受胃酸的作用，分解成核酸与蛋白质。核酸进入小肠后，受胰液和肠液中各种水解酶的作用逐步水解（图11-1）。

::figure{src="/images/biochemistry/textbook/p0247_01.png" caption="图11-1　核酸的消化。食物核蛋白经胃酸分成蛋白质与核酸（RNA及DNA）；胰核酸酶把核酸水解为核苷酸；胰、肠核苷酸酶把核苷酸切成核苷与磷酸；核苷酶再把核苷切成碱基与戊糖。" alt="核酸消化流程：核蛋白经胃酸分开，胰核酸酶、核苷酸酶、核苷酶依次切到碱基和戊糖"}

在小肠内，胰腺分泌的 $\mathrm{DNA}$ 酶和 $\mathrm{RNA}$ 酶可水解 $\mathrm{DNA}$ 和 $\mathrm{RNA}$，生成寡核苷酸和部分单核苷酸。小肠黏膜细胞可分泌对底物有一定特异性的二酯酶和核苷酸酶。二酯酶水解寡核苷酸生成单核苷酸，核苷酸酶则可水解核苷酸生成核苷和磷酸。核苷可通过被动扩散方式吸收。但嘧啶核苷可以被肠黏膜细胞内的嘧啶核苷酶水解生成嘧啶碱基，通过扩散方式吸收。因此，核苷酸及其水解产物均可被细胞吸收，并且绝大部分在肠黏膜细胞中被进一步分解。分解产生的戊糖被吸收后可参加体内的戊糖代谢；嘌呤和嘧啶碱则主要被分解后排出体外，所以食物来源的嘌呤和嘧啶碱很少被机体利用。

:::definition{label="食物核酸的存在形式"}
食物中的核酸多以核蛋白的形式存在。胃酸把核蛋白分解成核酸与蛋白质。
:::

:::definition{label="小肠内核酸的逐步水解"}
胰腺分泌的 $\mathrm{DNA}$ 酶和 $\mathrm{RNA}$ 酶把 $\mathrm{DNA}$、$\mathrm{RNA}$ 水解成寡核苷酸和部分单核苷酸。小肠黏膜的二酯酶把寡核苷酸切成单核苷酸，核苷酸酶把核苷酸切成核苷和磷酸。
:::

:::definition{label="核苷与嘧啶碱基的吸收"}
核苷可通过被动扩散方式吸收。嘧啶核苷可被肠黏膜细胞内的嘧啶核苷酶水解生成嘧啶碱基，再通过扩散吸收。
:::

:::definition{label="食物嘌呤嘧啶很少被利用"}
核苷酸及其水解产物均可被吸收，但绝大部分在肠黏膜细胞中被进一步分解。戊糖可参加体内戊糖代谢；嘌呤和嘧啶碱则主要被分解后排出体外。食物来源的嘌呤和嘧啶碱很少被机体利用。
:::

:::timeline{period="食物核酸从胃到肠"}
- **胃** 核蛋白被胃酸分成核酸与蛋白质
- **胰酶** DNA 酶、RNA 酶把核酸切成寡核苷酸和部分单核苷酸
- **黏膜酶** 二酯酶：寡核苷酸 → 单核苷酸；核苷酸酶：核苷酸 → 核苷 + 磷酸
- **吸收** 核苷被动扩散；嘧啶核苷可先被嘧啶核苷酶切成碱基再扩散
- **黏膜内继续分解** 戊糖进戊糖代谢；嘌呤、嘧啶碱主要分解后排出，很少被机体再利用
:::

| 图上的箭头 | 正文对应 |
|------------|----------|
| 胃酸 | 核蛋白 $\rightarrow$ 蛋白质 $+$ 核酸 |
| 胰核酸酶 | 胰 $\mathrm{DNA}$ 酶、$\mathrm{RNA}$ 酶；产物是寡核苷酸和部分单核苷酸 |
| 胰、肠核苷酸酶 | 黏膜二酯酶（寡 $\rightarrow$ 单）$+$ 核苷酸酶（核苷酸 $\rightarrow$ 核苷 $+$ 磷酸） |
| 核苷酶 | 核苷 $\rightarrow$ 碱基 $+$ 戊糖；嘧啶核苷还可走嘧啶核苷酶 |

图是简化流程，答题按正文把“寡核苷酸”这一层写上，不要从图上只看到“核酸直接变核苷酸”。
:::

:::insight{label="‘部分可被重新利用’指的是戊糖，不是膳食碱基装进人体核酸"}
标题写“分解产物部分可被重新利用”。能进代谢的主要是戊糖。嘌呤、嘧啶碱“主要被分解后排出体外”——这正是“核苷酸不是营养必需物质”的实验根据：膳食碱基几乎不进人体核酸。细胞要写核酸，必须走第二节、第三节的从头或补救。
:::

:::pitfall{label="补救途径用的不是刚吃进去的食物碱基"}
补救的原料是“体内游离的碱基或核苷”（下一小节），来自细胞自己周转下来的核苷酸，不是餐桌上的核蛋白。把消化吸收听成“吃核酸就能补救”，肝、脑、骨髓那本组织分工会乱。
:::

:::cause-effect{title="为何食物核酸几乎不构成人体核酸"}
- **因** 吸收的核苷酸绝大部分在肠黏膜进一步分解；嘌呤、嘧啶碱主要分解后排出
- **果** 食物来源的嘌呤和嘧啶碱很少被机体利用；人体核苷酸靠自身合成
:::

## 三、核苷酸代谢包括合成代谢和分解代谢

核苷酸根据碱基组成不同分为嘌呤核苷酸和嘧啶核苷酸两大类，这两种核苷酸的代谢均包括合成和分解代谢。核苷酸合成代谢根据方式的不同包括从头合成和补救合成两种途径。从头合成的碱基来源是利用氨基酸、一碳单位及 $\mathrm{CO}_2$ 等新合成含 $\mathrm{N}$ 的杂环；补救合成的碱基来源于体内游离碱基或核苷。在分解代谢中，嘌呤核苷酸的分解产物主要是水溶性较差的尿酸；嘧啶核苷酸的分解产物是易溶于水的 $\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸和 $\beta$-氨基异丁酸。

:::definition{label="从头合成途径"}
从头合成途径（de novo pathway）利用氨基酸、一碳单位及 $\mathrm{CO}_2$ 等简单物质，新合成含氮杂环，再写成核苷酸。
:::

:::definition{label="补救合成途径"}
补救合成途径（salvage pathway）又称重新利用途径：利用体内游离的碱基或核苷，经过简单反应写成核苷酸。
:::

:::definition{label="嘌呤与嘧啶分解产物"}
嘌呤核苷酸分解的主要终产物是水溶性较差的尿酸。嘧啶核苷酸分解产物是易溶于水的 $\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸和 $\beta$-氨基异丁酸。
:::

:::compare{title="从头合成与补救合成（全章总账）"}
| 项目 | 从头合成 | 补救合成 |
|------|----------|----------|
| 英文 | de novo pathway | salvage pathway（重新利用途径） |
| 碱基来源 | 氨基酸、一碳单位、$\mathrm{CO}_2$ 等，新写含 $\mathrm{N}$ 杂环 | 体内游离碱基或核苷 |
| 过程 | 步骤多，耗氨基酸和大量 $\mathrm{ATP}$ | 反应简单，耗能少 |
| 一般地位 | 合成的主要途径 | 含量少，但对缺从头酶的组织关键 |
| 嘌呤主要器官（第二节） | 肝，其次小肠黏膜和胸腺 | 脑、骨髓等 |
| 嘧啶（第三节） | 主要在肝；先写嘧啶环再接 $\mathrm{PRPP}$ | 嘧啶磷酸核糖转移酶、尿苷激酶、胸苷激酶 |

两条路都要 $\mathrm{PRPP}$ 提供磷酸核糖（补救的磷酸核糖转移酶、嘧啶补救同此）。$\mathrm{PRPP}$ 是两类核苷酸、两条途径的共同节点。
:::

:::compare{title="嘌呤分解 vs 嘧啶分解"}
| 项目 | 嘌呤核苷酸 | 嘧啶核苷酸 |
|------|------------|------------|
| 终产物 | 尿酸（uric acid） | $\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸、$\beta$-氨基异丁酸 |
| 水溶性 | 较差 | 均易溶于水 |
| 临床影 | 高尿酸、痛风；别嘌呤醇（第二节） | 高 $\mathrm{DNA}$ 饮食或放化疗后尿中 $\beta$-氨基异丁酸增多（第三节） |
:::

:::compare{title="嘌呤环与嘧啶环怎么长出来（预告）"}
| 项目 | 嘌呤核苷酸（第二节） | 嘧啶核苷酸（第三节） |
|------|----------------------|----------------------|
| 起点 | 核糖-$5$-磷酸 $\rightarrow\mathrm{PRPP}$，环在核糖上逐步写成 | 先写含嘧啶六元环的乳清酸，再与 $\mathrm{PRPP}$ 相连 |
| 共同中间物 | $\mathrm{IMP}$，再分出 $\mathrm{AMP}$、$\mathrm{GMP}$ | $\mathrm{UMP}$，再写出 $\mathrm{UTP}/\mathrm{CTP}$；$\mathrm{dTMP}$ 由 $\mathrm{dUMP}$ 甲基化 |
| 关键氮源 | 谷氨酰胺、甘氨酸、天冬氨酸 | 谷氨酰胺（$\mathrm{CPS}$ Ⅱ）、天冬氨酸 |
:::

:::insight{label="一碳单位在本章出现两次，位置不同"}
第九章：一碳单位由 $\mathrm{FH}_4$ 携带，用于嘌呤和嘧啶核苷酸合成。本章把位置写死：嘌呤环的 $\mathrm{C}$-$8$、$\mathrm{C}$-$2$ 来自甲酰基（$N^{10}$-甲酰四氢叶酸）；$\mathrm{dTMP}$ 的甲基来自 $N^{5},N^{10}$-亚甲四氢叶酸。叶酸类似物（甲氨蝶呤）两头都卡，所以既能抑嘌呤，也能抑 $\mathrm{dTMP}$。
:::

:::pitfall{label="不要把‘从头’听成‘先写游离碱基再接核糖’"}
嘌呤的从头合成是在核糖-$5$-磷酸上逐步拼环，中间物一直带着磷酸核糖。嘧啶才是先写成乳清酸（游离嘧啶酸），再磷酸核糖化。把两套合成都画成“碱基 $+\mathrm{PRPP}$”，等于把从头画成了补救。
:::

:::keypoint{label="本节三句话把全章钉住"}
- 核苷酸不是营养必需：膳食碱基很少用，细胞自己合成。
- 合成两条：从头（简单原料写杂环）和补救（拣体内游离碱基／核苷）。
- 分解两样：嘌呤 $\rightarrow$ 尿酸（难溶）；嘧啶 $\rightarrow\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸、$\beta$-氨基异丁酸（易溶）。
:::

:::memory{label="本节必背要点"}
- [ ] 核苷酸主要由自身合成，不是营养必需物质。
- [ ] 细胞内以 $5'$-核苷酸为主，$5'$-$\mathrm{ATP}$ 最多；$\mathrm{NTP}$ 约 $\mathrm{mmol}$，$\mathrm{dNTP}$ 约 $\mu\mathrm{mol}$。
- [ ] 五种功能：核酸原料（最主要）、能量（$\mathrm{ATP}$ 为主）、调节（$\mathrm{cAMP}/\mathrm{cGMP}$）、辅酶构件（$\mathrm{NAD}^{+}$、$\mathrm{FAD}$、$\mathrm{CoA}$）、活化载体（$\mathrm{UDP}$-葡萄糖、$\mathrm{CDP}$-甘油二酯、$\mathrm{SAM}$）。
- [ ] 核酸酶：$\mathrm{DNase}/\mathrm{RNase}$；外切（$5'\rightarrow 3'$、$3'\rightarrow 5'$）／内切；限制酶认回文、$4\sim 8\,\mathrm{bp}$，已发现 $3\,000$ 余种。
- [ ] 原核 $\mathrm{DNA}$ 聚合酶兼外切，切错配。
- [ ] 食物核蛋白：胃酸分开 $\rightarrow$ 胰 $\mathrm{DNase}/\mathrm{RNase}$ $\rightarrow$ 寡核苷酸 $\rightarrow$ 二酯酶／核苷酸酶 $\rightarrow$ 核苷 $+$ 磷酸。
- [ ] 核苷被动扩散；嘧啶核苷可被嘧啶核苷酶切成碱基再吸收。
- [ ] 戊糖可再利用；食物嘌呤、嘧啶碱很少被机体利用。
- [ ] 从头：氨基酸、一碳单位、$\mathrm{CO}_2$ 写含 $\mathrm{N}$ 杂环。补救：体内游离碱基或核苷。
- [ ] 嘌呤分解：尿酸（难溶）。嘧啶分解：$\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸、$\beta$-氨基异丁酸（易溶）。
:::
