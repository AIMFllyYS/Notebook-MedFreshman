# 第二节　基因治疗

第一节把基因诊断立完，包括「不能取代其他临床诊断、病原体只判外源基因有无和拷贝数、假阳性须综合评估」。本节从基因治疗真正开始：把正常或有治疗作用的基因导入靶细胞，修正、替代或补偿缺陷，或干扰致病基因异常表达。基因修复是原位、不引入外源序列的理想策略；基因增强是异位替代，目前临床主要方式。直接体内与间接体内不要并。逆转录病毒载体的优势要对照图24-4 的生活周期。不要把教材没有写的已上市药名补进来。

:::concept{term="先问原位修复还是异位补上一个正常基因，再问载体怎么把基因送进去"}
看见“基因治疗”，先不要默写病毒科名录。户头是：改变人的遗传物质，用基因转移把正常基因或治疗基因导入人体靶细胞。基因修复（修正＋置换）在原位改，不引入外源序列；基因增强把正常基因放到别处，缺陷基因还在，是目前临床主要策略。干扰走反义 $\mathrm{RNA}$、核酶、$\mathrm{miRNA}$、$\mathrm{siRNA}$；自杀基因把前药变成毒物。送进去要选载体、选体细胞、选直接体内或间接体内。图24-4 只解释逆转录病毒为什么能长期整合。
:::

:::note{label="电子版缺失"}
本节使用的插图是图24-4（逆转录病毒的生活周期示意图）：融合、逆转录、整合、转录、出芽。图24-1 至图24-3 属于第一节的 $\mathrm{PCR}$-$\mathrm{ASO}$、$\mathrm{PCR}$-$\mathrm{RFLP}$ 和 $\mathrm{STR}$。章末装饰性插图电子版缺失，不嵌入。
:::

基因治疗是以改变人遗传物质为基础的，通过基因转移的方式将正常基因或有治疗作用的基因导入人体靶细胞，以修正、替代或补偿缺陷基因的功能，或干扰致病基因的异常表达，从而在基因水平上治疗疾病的方法。目前基因治疗的概念不断扩展，凡是利用分子生物学等技术，在核酸水平上开展的疾病治疗均可纳入基因治疗的范畴。基因治疗范围也从单基因遗传病拓展到恶性肿瘤、心脑血管疾病、神经系统疾病、代谢性疾病等。

:::definition{label="基因治疗"}
以改变人遗传物质为基础，通过基因转移将正常基因或有治疗作用的基因导入人体靶细胞，以修正、替代或补偿缺陷基因的功能，或干扰致病基因的异常表达，从而在基因水平上治疗疾病。英文 gene therapy。
:::

:::definition{label="概念扩展后的范围"}
凡是利用分子生物学等技术，在核酸水平上开展的疾病治疗，均可纳入基因治疗。范围已从单基因遗传病拓展到恶性肿瘤、心脑血管疾病、神经系统疾病、代谢性疾病等。
:::

:::keypoint{label="定义里两件可以做的事"}
- 修正／替代／补偿缺陷基因的功能。
- 干扰致病基因的异常表达。
两件都是「在基因水平上治疗」，不要只答「补一个正常基因」。
:::

:::pitfall{label="不要从「假阳性须综合评估」起笔"}
那是第一节的尾巴。本节第一句是「以改变人遗传物质为基础」。把诊断局限再抄一遍，基因治疗的户头就被占掉。
:::

## 一、基因治疗的基本策略聚焦异常基因的纠正

基因治疗针对的是疾病的根源，即致病基因本身。被导入靶细胞中的基因或与宿主细胞染色体整合成为宿主遗传物质的一部分，或不发生整合而独立于染色体外，但均可在宿主细胞内表达基因产物蛋白质，发挥生物学效应。需要根据不同疾病的发病机制，选择合适的基因治疗策略。基因治疗的基本策略主要包括基因修正、基因置换、基因增强、基因干扰、自杀基因治疗等。

:::definition{label="导入基因的两种存在方式"}
或与宿主染色体整合，成为宿主遗传物质的一部分；或不整合，独立于染色体外。两条路都可以在宿主细胞内表达蛋白质、发挥生物学效应。后文逆转录病毒强调整合，腺病毒强调不整合。
:::

:::definition{label="基本策略名单"}
基因修正、基因置换、基因增强、基因干扰、自杀基因治疗等。修正和置换合称基因修复；增强是目前临床主要策略。
:::

:::insight{label="针对的是致病基因本身"}
「疾病的根源」这一句把治疗和第一节的病因诊断接起来：诊断查因，治疗改因。策略仍要按发病机制选，不是一种载体包打天下。
:::

### （一）基因修复是基因治疗的理想策略

基因修复（gene repair）是针对致病基因进行精确的原位修复，不引入外源序列，不破坏整个基因组的结构，又可达到治疗目的，被认为是理想的基因治疗策略，但目前相关技术尚不成熟。基因修复策略包括对患者体内致病基因的突变碱基直接进行纠正的基因修正（gene correction）和以正常基因原位替换致病基因的基因置换（gene replacement）。在体外细胞实验研究中，可基于基因同源重组技术实现基因置换。近年来，基因编辑（gene editing）技术发展迅速，可对基因组的特定基因进行靶向编辑等，有助于实现基因修正。

:::definition{label="基因修复"}
基因修复（gene repair）：针对致病基因进行精确的原位修复，不引入外源序列，不破坏整个基因组结构，又可达到治疗目的。理想策略，但目前相关技术尚不成熟。
:::

:::definition{label="基因修正"}
基因修正（gene correction）：对患者体内致病基因的突变碱基直接进行纠正。户头是「改那几个碱基」，仍在原位。
:::

:::definition{label="基因置换"}
基因置换（gene replacement）：以正常基因原位替换致病基因。体外细胞实验可基于同源重组实现。
:::

:::definition{label="基因编辑有助于基因修正"}
基因编辑（gene editing）可对基因组特定基因进行靶向编辑，有助于实现基因修正。它是修复策略的工具，不是另开一种「已经成熟的临床主策略」。
:::

:::pitfall{label="理想不等于目前临床主要方式"}
教材把基因修复写成理想策略，紧接着写「目前相关技术尚不成熟」。目前临床上使用的主要策略是后文基因增强。写成「现在主要靠 CRISPR 原位修好」，增强那一户就没有对象。
:::

目前已存在多种基于不同核酸酶的基因编辑系统，如巨型核酸酶、锌指核酸酶（zinc finger nuclease，$\mathrm{ZFN}$）、转录激活因子样效应物核酸酶（transcription activator-like effector nuclease，$\mathrm{TALEN}$）和成簇规律间隔短回文重复（clustered regularly interspaced short palindromic repeat，$\mathrm{CRISPR}$）等。这里以目前应用较为广泛的 $\mathrm{CRISPR}$-$\mathrm{Cas9}$ 系统进行简要机制介绍。$\mathrm{CRISPR}$-$\mathrm{Cas9}$ 系统主要包括可以切断靶基因的 $\mathrm{Cas9}$ 核酸酶和引导 $\mathrm{Cas9}$ 核酸酶靶向特定位点的单链导向 $\mathrm{RNA}$（single guide $\mathrm{RNA}$，$\mathrm{sgRNA}$）分子。$\mathrm{sgRNA}$ 是基于细菌中 $\mathrm{CRISPR}$ 序列改造而成的高效靶基因识别序列，可结合 $\mathrm{Cas9}$ 核酸酶，又可与靶基因组间隔序列邻近基序（protospacer adjacent motif，$\mathrm{PAM}$）附近的目标序列形成碱基互补配对。在 $\mathrm{Cas9}$ 核酸酶的 $\mathrm{DNA}$ 切割作用下，靶基因外显子区基因序列发生双链断裂（double-strand break，$\mathrm{DSB}$）。基于供体 $\mathrm{DNA}$ 模板分子，通过同源重组（homologous recombination，$\mathrm{HR}$）修复机制实现对于特定位点的基因修饰。基因编辑系统在降低脱靶效应、提高编辑效率及精准度、拓展适应范围等方面不断优化，具备治疗单基因遗传病、血液病、肿瘤等疾病的良好应用前景。

:::definition{label="四种核酸酶编辑系统"}
巨型核酸酶、锌指核酸酶（$\mathrm{ZFN}$）、转录激活因子样效应物核酸酶（$\mathrm{TALEN}$）、成簇规律间隔短回文重复（$\mathrm{CRISPR}$）。本版以 $\mathrm{CRISPR}$-$\mathrm{Cas9}$ 作机制介绍。
:::

:::definition{label="CRISPR-Cas9 两件零件"}
①切断靶基因的 $\mathrm{Cas9}$ 核酸酶；②引导 $\mathrm{Cas9}$ 靶向特定位点的单链导向 $\mathrm{RNA}$（$\mathrm{sgRNA}$）。$\mathrm{sgRNA}$ 来自细菌 $\mathrm{CRISPR}$ 序列改造，既结合 $\mathrm{Cas9}$，又与 $\mathrm{PAM}$ 附近目标序列碱基互补。
:::

:::definition{label="PAM、DSB、HR"}
基因组间隔序列邻近基序（$\mathrm{PAM}$）附近才是 $\mathrm{sgRNA}$ 配对的目标。$\mathrm{Cas9}$ 切割使靶基因外显子区发生双链断裂（$\mathrm{DSB}$）。再基于供体 $\mathrm{DNA}$ 模板，经同源重组（$\mathrm{HR}$）完成特定位点修饰。
:::

:::timeline{period="CRISPR-Cas9 怎样改一个位点"}
- **零件** Cas9 核酸酶 + sgRNA
- **寻址** sgRNA 与 PAM 附近目标序列互补
- **切断** 靶基因外显子区发生双链断裂 DSB
- **改写** 供体 DNA 模板，经同源重组 HR 修饰该位点
- **还在优化** 降低脱靶、提高效率与精准度、拓展适应范围
:::

:::insight{label="前景写的是单基因遗传病、血液病、肿瘤"}
教材用「良好应用前景」，没有在这里点名任何已上市基因治疗药物。不要把体外编辑系统直接写成「已经批准的一线疗法」。
:::

:::pitfall{label="不要把 CRISPR 写成「引入一段外源治疗基因就算修复」"}
修复的定义是原位、不引入外源序列。把一段正常基因随机插进基因组，那是后文基因增强。$\mathrm{CRISPR}$-$\mathrm{Cas9}$ 在本版里服务于基因修正。
:::

### （二）基因增强是基因治疗的主要策略

基因增强（gene augmentation）是一种对基因进行异位替代的方法，为目前临床上使用的主要基因治疗策略。基因增强可以针对特定的缺陷基因导入相应的正常基因，使导入的正常基因整合到存在基因缺陷的细胞基因组中，而细胞内的缺陷基因并未被删除，通过在体内表达出功能正常的蛋白质，以补偿缺陷基因的功能。例如，在血友病患者体内导入凝血因子Ⅸ的基因，恢复其凝血功能。需要注意的是导入基因的整合位置是随机的，可能引起基因组正常结构的改变，导致新疾病的发生。此外，还可以向靶细胞中导入本来不表达或表达量低的基因，利用其表达产物达到治疗疾病的目的。例如，将编码干扰素和白介素 $2$ 等分子的基因导入恶性肿瘤患者体内，激活机体免疫细胞的活力，作为抗肿瘤治疗中的辅助治疗。

:::definition{label="基因增强"}
基因增强（gene augmentation）：对基因进行异位替代，为目前临床上使用的主要基因治疗策略。导入相应的正常基因并整合到缺陷细胞基因组中，缺陷基因并未被删除，靠表达出功能正常的蛋白质来补偿。
:::

:::definition{label="血友病：导入凝血因子Ⅸ基因"}
在血友病患者体内导入凝血因子Ⅸ的基因，恢复凝血功能。这是「补上正常蛋白」的本版例子，不是原位把突变碱基改回去。
:::

:::definition{label="导入本来不表达或低表达的基因"}
不一定是「对应的那个缺陷基因」。也可以导入本来不表达或表达量低的基因，用其产物治病。本版例子：把编码干扰素和白介素 $2$ 的基因导入恶性肿瘤患者，激活免疫细胞，作为抗肿瘤辅助治疗。
:::

:::pitfall{label="增强的整合位置是随机的"}
导入基因整合位置随机，可能改变基因组正常结构，导致新疾病。这是增强的代价，也是后文逆转录病毒「插入突变、激活癌基因或破坏抑癌基因」那一户的前置。
:::

:::compare{title="基因修复 vs 基因增强"}
| | 改在哪里 | 外源序列 | 缺陷基因还在不在 | 本版地位 |
|--|---------|---------|----------------|---------|
| 基因修复 | 原位 | 不引入外源序列 | 被纠正或被原位替换 | 理想，技术尚不成熟 |
| 基因增强 | 异位替代 | 导入正常或治疗基因 | 缺陷基因并未被删除 | 目前临床主要策略 |

问「理想」看修复；问「现在临床上主要用哪一种」看增强。两户不要并成「都是把正常基因放进去」。
:::

:::compare{title="增强的两种导入目的"}
| | 导入什么 | 本版例子 |
|--|---------|---------|
| 补偿缺陷 | 与缺陷基因对应的正常基因 | 血友病 $\leftarrow$ 凝血因子Ⅸ基因 |
| 借用产物 | 本来不表达或低表达的基因 | 肿瘤 $\leftarrow$ 干扰素、白介素 $2$ 基因 |

后一种已经不是「修好那个病基因」，而是让细胞多生产有治疗作用的蛋白。
:::

### （三）基因干扰降解特定RNA序列

针对靶基因过度表达的疾病，可向患者体内导入具有抑制基因表达作用的核酸，如反义 $\mathrm{RNA}$（antisense $\mathrm{RNA}$）、核酶（ribozyme）、$\mathrm{miRNA}$ 和 $\mathrm{siRNA}$ 等，阻断致病基因的异常表达，达到治疗目的，这一策略称为基因干扰（gene interference）。需要干扰的靶基因常是过度表达的癌基因或者病毒复制周期中的关键基因。反义 $\mathrm{RNA}$ 可与细胞中 $\mathrm{mRNA}$ 特异结合而调控其翻译，具有安全性高、设计和制备方便、存在剂量调节效应等特点，并能直接作用于一些 $\mathrm{RNA}$ 病毒。核酶分子可结合到靶 $\mathrm{RNA}$ 分子中的适当部位，形成锤头状核酶结构，切断靶 $\mathrm{RNA}$ 分子，通过破坏靶 $\mathrm{RNA}$ 分子达到治疗疾病的目的。$\mathrm{miRNA}$ 和 $\mathrm{siRNA}$ 通过与互补序列结合，降解 $\mathrm{mRNA}$，导致靶基因沉默。

:::definition{label="基因干扰"}
基因干扰（gene interference）：导入能抑制基因表达的核酸，阻断致病基因异常表达。名单：反义 $\mathrm{RNA}$、核酶、$\mathrm{miRNA}$、$\mathrm{siRNA}$。对象常是过度表达的癌基因，或病毒复制周期中的关键基因。
:::

:::definition{label="反义 RNA"}
与细胞中 $\mathrm{mRNA}$ 特异结合而调控其翻译。特点：安全性高、设计和制备方便、存在剂量调节效应；并能直接作用于一些 $\mathrm{RNA}$ 病毒。
:::

:::definition{label="核酶"}
结合到靶 $\mathrm{RNA}$ 适当部位，形成锤头状核酶结构，切断靶 $\mathrm{RNA}$，靠破坏靶 $\mathrm{RNA}$ 治病。户头是「切断」，不是「只挡住翻译」。
:::

:::definition{label="miRNA 和 siRNA"}
与互补序列结合，降解 $\mathrm{mRNA}$，导致靶基因沉默。本版把二者写在同一机制句下。
:::

:::compare{title="干扰用的四种核酸"}
| | 本版机制 | 不要写成 |
|--|---------|---------|
| 反义 $\mathrm{RNA}$ | 与 $\mathrm{mRNA}$ 结合，调控翻译 | 「切基因组 $\mathrm{DNA}$」 |
| 核酶 | 锤头结构切断靶 $\mathrm{RNA}$ | 「只是另一种反义寡核苷酸」 |
| $\mathrm{miRNA}$、$\mathrm{siRNA}$ | 结合互补序列，降解 $\mathrm{mRNA}$，基因沉默 | 「原位修复突变碱基」 |

干扰的是 $\mathrm{RNA}$ 层面的表达，不是基因修复那一户的原位改 $\mathrm{DNA}$。
:::

:::pitfall{label="干扰针对的是过度表达，不是所有缺陷"}
教材把干扰写在「靶基因过度表达的疾病」。血友病那种「缺一个凝血因子」走增强；癌基因或病毒关键基因过度表达才走干扰。
:::

### （四）自杀基因用于治疗恶性肿瘤

在肿瘤的治疗中，通过导入基因诱发细胞「自杀」死亡也是一种重要的策略。自杀基因治疗恶性肿瘤的原理是将编码某些特殊酶类的基因导入肿瘤细胞，其编码的酶能够使无毒或低毒的药物前体转化为细胞毒性代谢物，诱导细胞产生「自杀」效应，达到清除肿瘤细胞的目的。胸苷激酶／丙氧鸟苷（thymidine kinase/ganciclovir，$\mathrm{TK}/\mathrm{GCV}$）是目前研究最多的自杀基因系统。自杀基因还可利用肿瘤细胞特异性启动子序列（如肝癌的甲胎蛋白启动子序列），激活细胞内抑癌基因等细胞毒性基因，发挥杀伤肿瘤的作用。此外，导入自杀基因的肿瘤细胞可影响周边的肿瘤细胞，增强自杀基因对肿瘤细胞的杀伤作用。这种效应被称为旁观者效应（bystander effect）。

:::definition{label="自杀基因治疗"}
把编码某些特殊酶类的基因导入肿瘤细胞，酶把无毒或低毒的药物前体转化为细胞毒性代谢物，诱导「自杀」，清除肿瘤细胞。
:::

:::definition{label="TK/GCV"}
胸苷激酶／丙氧鸟苷（thymidine kinase/ganciclovir，$\mathrm{TK}/\mathrm{GCV}$）是目前研究最多的自杀基因系统。本版没有把它写成已经全面替代手术和化疗。
:::

:::definition{label="肿瘤特异性启动子"}
可利用肿瘤细胞特异性启动子序列，激活细胞内抑癌基因等细胞毒性基因。本版例子：肝癌的甲胎蛋白启动子序列。第一节的甲胎蛋白是肝癌标志物；这里是用它的启动子把杀伤基因限制在肝癌细胞里。
:::

:::definition{label="旁观者效应"}
导入自杀基因的肿瘤细胞可影响周边肿瘤细胞，增强杀伤。英文 bystander effect。杀伤不限于被转入基因的那一个细胞。
:::

:::compare{title="增强导入细胞因子 vs 自杀基因"}
| | 导入什么 | 怎样杀肿瘤 |
|--|---------|-----------|
| 增强（辅助） | 干扰素、白介素 $2$ 等基因 | 激活机体免疫细胞活力 |
| 自杀基因 | 特殊酶基因（如 $\mathrm{TK}$） | 前药变毒物；或特异性启动子驱动细胞毒性基因 |
| 旁观者 | —— | 被转入的细胞连累周边肿瘤细胞 |

问「前药」走自杀基因；问「白介素 $2$」走增强。
:::

:::keypoint{label="策略四户先分原位还是异位"}
- 修复（修正＋置换）：原位，不引入外源序列，理想但不成熟；编辑（$\mathrm{ZFN}$、$\mathrm{TALEN}$、$\mathrm{CRISPR}$-$\mathrm{Cas9}$）服务于修正。
- 增强：异位，缺陷基因还在，目前临床主要方式。
- 干扰：反义 $\mathrm{RNA}$、核酶、$\mathrm{miRNA}$、$\mathrm{siRNA}$，对着过度表达的 $\mathrm{RNA}$。
- 自杀基因：酶激活前药；$\mathrm{TK}/\mathrm{GCV}$；旁观者效应。
:::

## 二、基因治疗程序涉及多个环节

基因治疗的基本程序主要包括治疗基因的确定、基因转移载体的选择、基因治疗靶细胞的选择、治疗基因导入以及治疗基因表达的检测。

:::definition{label="五步程序"}
①治疗基因的确定；②基因转移载体的选择；③基因治疗靶细胞的选择；④治疗基因导入；⑤治疗基因表达的检测。缺一步都不叫把方案走完。
:::

:::timeline{period="基因治疗程序"}
- **基因** 先确定致病基因，再选正常基因或改造基因
- **载体** 病毒或非病毒，决定能不能送进去、会不会整合
- **靶细胞** 目前只做体细胞
- **导入** 生物学（病毒感染）或非生物学（物理化学）；途径分直接体内和间接体内
- **检测** PCR、RNA 印迹、蛋白质印迹；还可用标记基因筛选
:::

### （一）治疗基因的确定是基因治疗的关键

基因治疗的首要问题是确定与疾病相关的致病基因。基于致病基因，可选择对应的正常基因或经改造的基因作为治疗基因。对于基因缺陷导致的遗传性疾病，一般采用野生型的正常基因作为靶基因；对于非遗传性疾病，则有多种治疗策略可供选择，不同的策略又可以选择不同的靶基因。

:::definition{label="首要问题是致病基因"}
先确定与疾病相关的致病基因，再选对应的正常基因或经改造的基因作为治疗基因。
:::

:::compare{title="遗传病 vs 非遗传病：靶基因怎么选"}
| | 本版原句 | 常常对应的策略 |
|--|---------|--------------|
| 基因缺陷导致的遗传病 | 一般采用野生型的正常基因作为靶基因 | 增强（如凝血因子Ⅸ）；理想情况下修复 |
| 非遗传病 | 多种策略，不同策略选不同靶基因 | 干扰癌基因、导入细胞因子、自杀基因等 |

「靶基因」在这一小节里指被选来治疗的那个基因，不要和「致病基因」混成一个词。
:::

### （二）病毒和非病毒载体可介导基因转移

大分子 $\mathrm{DNA}$ 不能主动进入细胞，即使进入也会被细胞内的核酸酶水解。因此，在选定治疗基因后，需要选择可介导治疗基因转移至靶细胞中并稳定表达的基因工程转移载体。基因转移载体包括病毒载体和非病毒载体（如脂质体、细菌载体、磷酸钙等）两大类。基因治疗的临床实施一般多选用转移效率较高的病毒载体。

目前可用作基因转移载体的病毒有逆转录病毒、慢病毒、腺病毒、腺相关病毒、疱疹病毒等。不同类型的病毒载体具有不同的优缺点，可依据基因转移和表达的不同要求加以选择。

:::definition{label="为什么必须有载体"}
大分子 $\mathrm{DNA}$ 不能主动进细胞，进去也会被核酸酶水解。载体的任务：把治疗基因转到靶细胞并稳定表达。
:::

:::definition{label="载体两大类"}
病毒载体；非病毒载体（脂质体、细菌载体、磷酸钙等）。临床实施一般多选转移效率较高的病毒载体。
:::

:::definition{label="可用的病毒名单"}
逆转录病毒、慢病毒、腺病毒、腺相关病毒、疱疹病毒等。各有优缺点，按转移和表达要求选。疱疹病毒点名即止，后文展开前四种。
:::

**1. 逆转录病毒载体介导基因转移**　逆转录病毒属于 $\mathrm{RNA}$ 病毒，可编码逆转录酶和整合酶。感染细胞后，病毒基因组 $\mathrm{RNA}$ 被逆转录成双链 $\mathrm{DNA}$，随机整合至宿主细胞的染色体 $\mathrm{DNA}$ 上，因此可长期存在于宿主细胞基因组中（图24-4），这是逆转录病毒作为载体的主要优势。逆转录病毒载体具有基因转移效率高、细胞宿主范围广泛、$\mathrm{DNA}$ 整合效率高等优点。主要缺点在于随机整合有插入突变、激活癌基因或破坏抑癌基因正常表达的潜在危险；载体容量较小。

:::definition{label="逆转录病毒载体"}
$\mathrm{RNA}$ 病毒，编码逆转录酶和整合酶。感染后基因组 $\mathrm{RNA}$ 逆转录成双链 $\mathrm{DNA}$，随机整合到宿主染色体，从而长期存在于宿主基因组。这是作为载体的主要优势。优点：转移效率高、宿主范围广、整合效率高。缺点：随机整合有插入突变、激活癌基因或破坏抑癌基因的潜在危险；容量较小。
:::

::figure{src="/images/biochemistry/textbook/p0484_01.png" caption="图24-4　逆转录病毒的生活周期示意图" alt="环形生活周期：①病毒与细胞融合；②在胞内逆转录；③整合入宿主染色体 DNA，形成前病毒；④转录并合成逆转录病毒蛋白质；⑤出芽释放新病毒。游离病毒颗粒上标出逆转录酶"}

:::insight{label="图24-4 按 ① 到 ⑤ 读一圈"}
①融合：病毒进入细胞。②逆转录：$\mathrm{RNA}$ 变成双链 $\mathrm{DNA}$。③整合：进入宿主染色体 $\mathrm{DNA}$，此时称前病毒。④转录：以整合序列为模板，合成病毒蛋白质。⑤出芽：新病毒离开细胞。游离颗粒上标了逆转录酶。载体要的是②③这一段「变成 $\mathrm{DNA}$ 并整合」，所以能长期存在；也正是③的随机整合带来插入突变风险。
:::

:::timeline{period="逆转录病毒生活周期"}
- **① 融合** 病毒进入宿主细胞
- **② 逆转录** 基因组 RNA 在逆转录酶作用下变成双链 DNA
- **③ 整合** 随机插入宿主染色体，形成前病毒
- **④ 转录** 表达逆转录病毒蛋白质
- **⑤ 出芽** 新病毒颗粒离开细胞
:::

:::pitfall{label="「长期存在」和「随机整合危险」是同一件事的两面"}
优势来自整合进宿主基因组；危险也来自整合是随机的。不要只背优点，把激活癌基因那一句删掉。
:::

**2. 慢病毒载体介导基因转移**　慢病毒载体是在人类免疫缺陷 $1$ 型病毒基础上构建的整合型基因转移载体。与一般的逆转录病毒载体相比，其对分裂细胞和非分裂细胞均具有感染能力，但病毒载体的容量仍然有限。

:::definition{label="慢病毒载体"}
在人类免疫缺陷 $1$ 型病毒基础上构建的整合型载体。与一般逆转录病毒载体相比，对分裂细胞和非分裂细胞均能感染；容量仍然有限。
:::

:::insight{label="慢病毒仍是整合型，只是宿主细胞周期更宽"}
「整合型」三个字不要丢。它不是腺病毒那种不整合。差别在能不能感染非分裂细胞。
:::

**3. 腺病毒载体介导基因转移**　腺病毒属于 $\mathrm{DNA}$ 病毒，共包含 $50$ 多个血清型，其中 $\mathrm{C}$ 亚类的 $2$ 型和 $5$ 型腺病毒在人体内为非致病病毒，适合作为基因治疗用载体。腺病毒载体并不整合到染色体基因组，不会破坏染色体结构，安全性较高；且对 $\mathrm{DNA}$ 包被量大、基因转染效率高，适用细胞范围广，可感染静止或慢分裂细胞。腺病毒载体的缺点是基因组较大，载体构建过程较复杂；由于治疗基因不整合到染色体基因组，故易随着细胞分裂或死亡而丢失，不能长期表达。此外，该病毒载体的免疫原性较强，注射到机体后可能会被机体的免疫系统排斥。

:::definition{label="腺病毒载体"}
$\mathrm{DNA}$ 病毒，$50$ 多个血清型；$\mathrm{C}$ 亚类 $2$ 型和 $5$ 型在人体内非致病，适合做载体。不整合到染色体，不破坏染色体结构，安全性较高；包被量大、转染效率高、适用细胞广，可感染静止或慢分裂细胞。缺点：基因组大、构建复杂；不整合故易随细胞分裂或死亡丢失，不能长期表达；免疫原性较强，可能被排斥。
:::

**4. 腺相关病毒载体介导基因转移**　腺相关病毒（adeno-associated virus，$\mathrm{AAV}$）属于单链线状 $\mathrm{DNA}$ 缺陷型病毒，不能独立复制，只有在辅助病毒如腺病毒、单纯疱疹病毒等存在的条件下才能进行复制。腺相关病毒载体安全性高，可实现靶向整合，避免随机整合带来的潜在危险性，还可实现外源基因的持续稳定表达，兼具逆转录病毒载体和腺病毒载体两者的优点。主要缺点是容量小、感染效率低、可能引起免疫排斥。

:::definition{label="腺相关病毒载体"}
$\mathrm{AAV}$：单链线状 $\mathrm{DNA}$ 缺陷型病毒，不能独立复制，需腺病毒、单纯疱疹病毒等辅助病毒才能复制。优点：安全性高，可靶向整合（避免随机整合危险），外源基因持续稳定表达，兼具逆转录病毒与腺病毒两者的优点。缺点：容量小、感染效率低、可能免疫排斥。
:::

:::compare{title="四种病毒载体不要并成「都是病毒就能长期表达」"}
| | 基因组 | 整合 | 本版点名的长处 | 本版点名的短处 |
|--|--------|------|--------------|--------------|
| 逆转录病毒 | $\mathrm{RNA}$ | 随机整合，故能长期存在 | 转移效率高、宿主广、整合效率高 | 插入突变／激活癌基因或破坏抑癌基因；容量小 |
| 慢病毒 | 在 $\mathrm{HIV}$-$1$ 基础上构建 | 整合型 | 分裂与非分裂细胞都能感染 | 容量仍有限 |
| 腺病毒 | $\mathrm{DNA}$（点名 $\mathrm{C}$ 亚类 $2$、$5$ 型） | 不整合 | 较安全、包被量大、转染高、可感染静止或慢分裂细胞 | 构建复杂；易丢失、不能长期表达；免疫原性强 |
| $\mathrm{AAV}$ | 单链线状 $\mathrm{DNA}$，缺陷型 | 可靶向整合 | 安全、避免随机整合危险、持续稳定表达 | 容量小、感染效率低、可能免疫排斥 |

问「为什么能长期」看整合（逆转录病毒、慢病毒、$\mathrm{AAV}$）；问「为什么相对不破坏染色体」看腺病毒不整合，或 $\mathrm{AAV}$ 靶向整合。
:::

:::pitfall{label="AAV 不能独立复制，不是「自己就能当完整病原体」"}
缺陷型：只有辅助病毒存在才能复制。写成「$\mathrm{AAV}$ 和腺病毒一样会自己在人体里传代」，缺陷型这一户就空了。
:::

### （三）基因治疗的靶细胞仅限为体细胞

根据治疗靶细胞的不同，基因治疗可分为生殖细胞（germ line）治疗和体细胞（somatic cell）治疗。由于生殖细胞基因治疗涉及伦理、遗传等诸多问题，国际上严格限制采用人生殖细胞进行基因治疗实验。目前人类基因治疗研究与应用的重点是体细胞治疗。适合作为基因治疗的靶细胞应具备如下特点：易于从人体内获取，生命周期较长，基因治疗效应持久；易于在体外培养及易受外源性遗传物质转化；离体细胞经转染和培养后回植体内易成活；最好具有组织特异性，或治疗基因在某种组织细胞中表达后能够以分泌小泡等形式进入靶细胞。目前成功用于基因治疗的靶细胞有限，主要包括造血干细胞、淋巴细胞、皮肤成纤维细胞、肌细胞和肿瘤细胞等。

:::definition{label="生殖细胞治疗 vs 体细胞治疗"}
按靶细胞分：生殖细胞（germ line）治疗和体细胞（somatic cell）治疗。生殖细胞涉及伦理、遗传等诸多问题，国际上严格限制用人的生殖细胞做基因治疗实验。目前研究与应用的重点是体细胞治疗。
:::

:::definition{label="适合作为靶细胞的特点"}
①易从人体获取，生命周期较长，效应持久；②易体外培养，易受外源遗传物质转化；③转染培养后回植易成活；④最好有组织特异性，或表达产物能以分泌小泡等形式进入靶细胞。
:::

:::definition{label="目前成功的靶细胞名单"}
有限。主要包括造血干细胞、淋巴细胞、皮肤成纤维细胞、肌细胞和肿瘤细胞等。后文还补血管内皮细胞、肝细胞，以及其他仍限实验研究的细胞。
:::

:::pitfall{label="人类目前不做生殖细胞基因治疗"}
「严格限制」是本版原句。后文还写：针对人类生殖细胞的基因治疗被不同国家的法律所禁止。不要把小鼠生殖系改造的例子直接写成临床方案。
:::

**1. 造血干细胞是基因治疗的重要靶细胞**　造血干细胞是基因治疗最有前途的靶细胞之一。骨髓造血干细胞具有高度自我更新能力，可进一步分化为其他血细胞，并保持基因组 $\mathrm{DNA}$ 的稳定性。由于造血干细胞在骨髓中含量很低，难以获得足够的数量用于基因治疗。人脐带血细胞是造血干细胞的丰富来源，在体外增殖能力强，移植后抗宿主反应发生率低，是替代骨髓造血干细胞的理想靶细胞。目前已有脐带血基因治疗的成功案例。

:::definition{label="造血干细胞"}
最有前途的靶细胞之一。骨髓造血干细胞：高度自我更新，可分化为其他血细胞，并保持基因组 $\mathrm{DNA}$ 稳定性。短板：骨髓中含量很低，难以获得足够数量。
:::

:::definition{label="脐带血细胞"}
造血干细胞的丰富来源；体外增殖能力强；移植后抗宿主反应发生率低；是替代骨髓造血干细胞的理想靶细胞。目前已有脐带血基因治疗的成功案例。本版没有点名该案例的药名。
:::

**2. 淋巴细胞是基因治疗的有效靶细胞**　淋巴细胞参与机体的免疫反应，有较长的寿命，且容易从血液中分离和回输，对目前常用的基因转移方法都具备一定的敏感性，适合作为基因治疗的靶细胞。目前，已将一些细胞因子、功能蛋白质的编码基因导入外周血淋巴细胞并获得稳定高效的表达，应用于黑色素瘤、免疫缺陷性疾病、血液系统单基因遗传病的基因治疗。

:::definition{label="淋巴细胞作靶细胞"}
参与免疫，寿命较长，易从血液分离和回输，对常用基因转移方法敏感。已将细胞因子、功能蛋白质编码基因导入外周血淋巴细胞并稳定高效表达。应用：黑色素瘤、免疫缺陷性疾病、血液系统单基因遗传病。
:::

**3. 皮肤成纤维细胞可作为基因转移的靶细胞**　皮肤成纤维细胞具有易采集、可在体外扩增培养、易于移植等优点，具备良好的基因治疗应用前景。逆转录病毒载体能高效感染原代培养的成纤维细胞，将其移植回受体动物时，治疗基因可以稳定表达一段时间，并通过血液循环将表达的蛋白质送至其他组织。

:::definition{label="皮肤成纤维细胞"}
易采集、可体外扩增、易于移植。逆转录病毒载体能高效感染原代培养的成纤维细胞；移植回受体动物后，治疗基因可稳定表达一段时间，蛋白质经血液循环送至其他组织。后文血友病导入凝血因子Ⅸ，用的就是自体皮肤成纤维细胞。
:::

**4. 肌细胞可通过直接注射法导入靶基因**　骨骼肌细胞是基因治疗的良好靶细胞。肌细胞具有特殊的 $\mathrm{T}$ 管系统，与细胞外直接相通，利于注射的质粒 $\mathrm{DNA}$ 经内吞作用进入细胞。肌细胞内的溶酶体和 $\mathrm{DNA}$ 酶含量很低，环状质粒可在胞内保留较长时间，且并不整合至基因组 $\mathrm{DNA}$ 中。

:::definition{label="骨骼肌细胞"}
良好靶细胞。特殊 $\mathrm{T}$ 管系统与细胞外相通，利于注射的质粒 $\mathrm{DNA}$ 经内吞进入。溶酶体和 $\mathrm{DNA}$ 酶含量很低，环状质粒可保留较长时间，且不整合至基因组 $\mathrm{DNA}$。这是后文「直接注射法仅限于肌组织」的结构基础。
:::

**5. 肿瘤细胞便于外源基因的高效转移**　肿瘤细胞是肿瘤基因治疗中极为重要的靶细胞。由于肿瘤细胞分裂旺盛，对大多数的基因转移方法都比较敏感，可实现外源基因的高效转移。

:::definition{label="肿瘤细胞作靶细胞"}
肿瘤基因治疗中极为重要。分裂旺盛，对大多数基因转移方法敏感，外源基因可高效转移。自杀基因、细胞因子基因都落在这一户。
:::

**6. 血管内皮细胞便于基因表达产物的分泌**　血管内皮细胞的优势在于可以将导入的治疗基因产物直接分泌至血液中。

:::definition{label="血管内皮细胞"}
优势：导入的治疗基因产物直接分泌至血液。问「怎样让蛋白进循环」可以答这一户，也可以答成纤维细胞经血循环运送。
:::

**7. 肝细胞是基因治疗的重要细胞**　肝脏是人体最大的实质代谢器官。许多肝脏特异性基因的突变可导致遗传病的发生。肝细胞具有一定的分裂能力，便于在体外进行扩增培养。

:::definition{label="肝细胞"}
肝是最大实质代谢器官；许多肝脏特异性基因突变可致遗传病。肝细胞有一定分裂能力，便于体外扩增。后文苯丙酮尿症的苯丙氨酸羟化酶就在肝内——治疗策略可以想到肝细胞，但本版写明目前尚无获批实施方案。
:::

**8. 其他细胞是基因治疗的潜在靶细胞**　骨髓基质细胞、角质细胞、胶质细胞、心肌细胞及脾细胞等也可作为靶细胞，但由于受到取材及导入外源基因困难等因素的影响，还仅限于实验研究。

:::definition{label="仅限实验研究的靶细胞"}
骨髓基质细胞、角质细胞、胶质细胞、心肌细胞及脾细胞等。取材难、导入外源基因难，还仅限实验研究。不要和「目前成功用于基因治疗」那份短名单并户。
:::

### （四）治疗基因可通过生物学或非生物学法导入细胞

在确定基因治疗的靶基因、靶细胞及基因转移载体后，需将治疗基因导入细胞，主要存在生物学和非生物学两大类方法。生物学方法是指由病毒载体介导的基因导入，通过病毒感染细胞实现，特点是基因转移效率高，但安全性问题需要重视。非生物学方法则是基于各种非病毒载体，通过物理、化学等方法将治疗基因导入细胞或直接导入人体内，操作简单、安全，但是转移效率低。常用的基因导入方法见表24-1。

:::definition{label="生物学导入"}
病毒载体介导，靠病毒感染细胞。转移效率高，安全性问题需要重视。
:::

:::definition{label="非生物学导入"}
基于非病毒载体，用物理、化学方法把治疗基因导入细胞或直接导入人体。操作简单、安全，转移效率低。
:::

**表24-1　基因治疗的常用基因导入方法**

| 名称 | 操作方法 | 特点 |
|------|---------|------|
| 直接注射法 | 将携带治疗基因的非病毒真核表达载体（多为质粒）溶液直接注射入肌组织 | 无毒无害、操作简便、目的基因表达时间长；仅限于在肌组织中表达，导入效率低，需注射大量 $\mathrm{DNA}$ |
| 基因枪法 | 采用微粒加速装置，使携带治疗基因的微米级金或钨颗粒获得足够能量，直接进入靶细胞 | 操作简便、$\mathrm{DNA}$ 用量少、效率高、无痛苦、适宜在体操作，尤其适于将 $\mathrm{DNA}$ 疫苗导入表皮细胞，获得理想的免疫反应；但目前不宜用于内脏器官的在体操作 |
| 电穿孔法 | 在直流脉冲电场下细胞膜出现微孔，维持几毫秒到几秒，便于质粒 $\mathrm{DNA}$ 进入细胞 | 可将外源基因选择性地导入靶组织或器官，效率较高；但外源基因表达持续时间短 |
| 脂质体 | 利用人工合成的兼性脂质膜包裹极性大分子 $\mathrm{DNA}$ 或 $\mathrm{RNA}$，形成的微囊泡穿透细胞膜，进入细胞 | 操作简单、重复性好，脂质体可被降解，对细胞无毒，可反复给药；$\mathrm{DNA}$ 或 $\mathrm{RNA}$ 得到有效保护，不易被核酸酶降解；但体内基因转染效率低，表达时间短，易被血液中的网状内皮细胞吞噬 |
| 受体 | 基于细胞表面受体能特异性识别相应配体并将其内吞的机制，将治疗基因转移至特定类型的细胞中 | 具备细胞靶向性。受体介导的基因转移在基因治疗中具有较好的优势和发展前景 |

:::keypoint{label="读表24-1 先看「限在哪」再看效率"}
- 直接注射：只限肌组织，效率低，要大量 $\mathrm{DNA}$；但无毒、表达时间长。
- 基因枪：金或钨微粒，适于表皮 $\mathrm{DNA}$ 疫苗；不宜内脏在体操作。
- 电穿孔：脉冲电场开几毫秒到几秒的微孔；效率较高，表达持续短。
- 脂质体：保护核酸、可反复给；体内转染低、表达短、易被网状内皮细胞吞噬。
- 受体：靠配体内吞，有细胞靶向性，前景好。
:::

:::pitfall{label="直接注射不要写成可以打进任意器官"}
「仅限于在肌组织中表达」是表里的限制，对应前文骨骼肌 $\mathrm{T}$ 管。写成「裸 $\mathrm{DNA}$ 注射到肝脏也一样」，肌细胞那一户就没有结构依据。
:::

| 方法 | 效率／方便 | 本版短板 |
|------|----------|---------|
| 直接注射 | 简便、表达时间长 | 只限肌组织，需大量 $\mathrm{DNA}$ |
| 基因枪 | 用量少、效率高、在体、无痛苦 | 不宜内脏在体 |
| 电穿孔 | 可选择组织器官，效率较高 | 表达持续时间短 |
| 脂质体 | 可降解、无毒、可反复、保护核酸 | 体内转染低、表达短、网状内皮吞噬 |
| 受体 | 有靶向性 | 写的是前景，不是已经万能 |

非生物学法总体「简单、安全、效率低」；表里每一行还有自己的附加条件。
:::

目前临床基因治疗实施方案中，根据外源基因导入人体的途径，基因治疗可分为直接体内（in vivo）和间接体内（ex vivo）两种疗法。直接体内疗法是利用病毒或非病毒载体将外源基因直接导入患者体内的治疗方法。例如，将无复制能力的、含外源基因的腺相关病毒直接应用于患者体内；或将脂质体包埋或裸露 $\mathrm{DNA}$ 直接注射到患者体内。间接体内疗法则是首先提取患者的特定靶细胞，在体外利用逆转录病毒载体等方式导入外源基因，经体外增殖、筛选、药物处理等操作后，再将经过基因修饰的阳性细胞输回患者体内的治疗方法。例如：嵌合抗原受体 $\mathrm{T}$ 细胞免疫疗法（chimeric antigen receptor $\mathrm{T}$-cell immunotherapy，$\mathrm{CAR}$-$\mathrm{T}$）即先提取患者 $\mathrm{T}$ 细胞，在体外利用基因编辑等技术使 $\mathrm{T}$ 细胞表达嵌合抗原受体，经细胞培养扩增及相应筛选后重新输回患者体内，靶向攻击特定肿瘤细胞。直接体内的方法操作简便，容易推广。虽然直接体内方法目前尚不成熟，未能彻底解决疗效短、免疫排斥以及安全性等问题，但仍是基因转移方法的重要研究方向。间接体内的方法则比较安全，同时治疗效果比较容易控制，但操作步骤多、技术较复杂。

:::definition{label="直接体内"}
in vivo：利用病毒或非病毒载体把外源基因直接导入患者体内。例子：无复制能力、含外源基因的腺相关病毒直接应用；脂质体包埋或裸露 $\mathrm{DNA}$ 直接注射。操作简便，易推广；目前尚不成熟，疗效短、免疫排斥、安全性等问题未彻底解决，仍是重要研究方向。
:::

:::definition{label="间接体内"}
ex vivo：先提取患者特定靶细胞，体外用逆转录病毒载体等导入外源基因，经增殖、筛选、药物处理后，把基因修饰的阳性细胞输回患者体内。比较安全，疗效较易控制；步骤多、技术较复杂。
:::

:::definition{label="CAR-T 是间接体内的本版例子"}
嵌合抗原受体 $\mathrm{T}$ 细胞免疫疗法（chimeric antigen receptor $\mathrm{T}$-cell immunotherapy，$\mathrm{CAR}$-$\mathrm{T}$）：提取患者 $\mathrm{T}$ 细胞 $\rightarrow$ 体外用基因编辑等技术使其表达嵌合抗原受体 $\rightarrow$ 培养扩增及筛选 $\rightarrow$ 输回体内，靶向攻击特定肿瘤细胞。不要把它写成直接把病毒打进肿瘤。
:::

:::compare{title="直接体内 vs 间接体内"}
| | 基因在哪转入 | 本版例子 | 长处 | 短处 |
|--|------------|---------|------|------|
| 直接体内 in vivo | 直接进患者体内 | $\mathrm{AAV}$ 直接应用；脂质体或裸 $\mathrm{DNA}$ 注射 | 简便，易推广 | 尚不成熟；疗效短、免疫排斥、安全性 |
| 间接体内 ex vivo | 先体外改细胞，再输回 | $\mathrm{CAR}$-$\mathrm{T}$；逆转录病毒改自体细胞 | 较安全，疗效较易控制 | 步骤多、技术复杂 |

问「抽自己的 $\mathrm{T}$ 细胞出来改」走间接体内；问「载体直接打进去」走直接体内。
:::

:::pitfall{label="不要发明教材没有的已上市药名"}
本版点名的是策略、载体、$\mathrm{CAR}$-$\mathrm{T}$ 流程、以及后文 $1990$ 年 $\mathrm{Blaese\ RM}$ 的 $\mathrm{ADA}$ 试验。没有点名其他商品名。不要把课外药名写进正文当「教材原句」。
:::

:::insight{label="直接体内不成熟，仍是重要研究方向"}
教材并没有把直接体内判死刑。简便、易推广是吸引力；疗效短、排斥、安全是未决问题。间接体内更可控，但走不了「一针打进去」那条路。
:::

### （五）多种技术可用于检测治疗基因在细胞内的表达

当将治疗基因导入靶细胞后，需要利用 $\mathrm{PCR}$、$\mathrm{RNA}$ 印迹、蛋白质印迹等多种技术检测这些基因是否能被正确表达；还可利用核酸分子杂交技术分析导入基因是否整合至基因组以及整合的部位。治疗基因导入靶细胞的转染效率通常较低，可通过载体上的标记基因（如新霉素磷酸转移酶基因、潮霉素抗性基因等）筛选细胞，获得可稳定表达治疗基因的细胞。

:::definition{label="表达与整合都要查"}
$\mathrm{PCR}$、$\mathrm{RNA}$ 印迹、蛋白质印迹：问基因是否被正确表达。核酸分子杂交：问是否整合、整合在哪。表达和整合是两问。
:::

:::definition{label="标记基因筛选"}
转染效率通常较低。载体上的标记基因（如新霉素磷酸转移酶基因、潮霉素抗性基因）用于筛选，获得可稳定表达治疗基因的细胞。
:::

:::pitfall{label="导入了不等于已经表达、也不等于整合对了"}
五步的最后一步单独立项，就是因为转进去还要验证。写成「病毒感染成功＝治疗完成」，检测这一户就没有工作。
:::

## 三、基因治疗的前景良好但也面临挑战

作为一种新兴的具有极大潜力的治疗手段，基因治疗在遗传性疾病、恶性肿瘤、感染性疾病等方面具有广泛应用前景，但也存在尚待解决的安全性、技术、社会和伦理等一系列问题。

:::keypoint{label="前景和问题要两句一起答"}
前景：遗传病、恶性肿瘤、感染性疾病等。问题：安全性、技术、社会、伦理。不要只背「潜力极大」。
:::

### （一）基因治疗应用于单基因遗传病

单基因遗传病只受一对等位基因影响，致病基因清楚，基因治疗方案相对容易确定。基本方案是通过一定的方法将正常的基因导入至患者体内，表达出正常的功能蛋白质。例如，腺苷脱氨酶（adenosine deaminase，$\mathrm{ADA}$）缺乏症是常染色体隐性遗传性代谢缺陷性疾病，患者体内 $\mathrm{T}$ 和 $\mathrm{B}$ 淋巴细胞代谢产物累积，$\mathrm{DNA}$ 合成受抑，$\mathrm{T}$ 和 $\mathrm{B}$ 细胞功能缺陷。$1990$ 年美国 $\mathrm{Blaese\ RM}$ 博士成功地将正常的人腺苷脱氨酶基因植入 $\mathrm{ADA}$ 缺乏症患者的淋巴结内，完成世界上首例基因治疗试验。

此外，将携带凝血因子Ⅸ的基因导入血友病患者自体的皮肤成纤维细胞中，可提高血浆中凝血Ⅸ因子浓度，从而降低出血次数，减轻出血症状。苯丙酮尿症（phenylketonuria，$\mathrm{PKU}$）主要是由于苯丙氨酸羟化酶（phenylalanine hydroxylase，$\mathrm{PAH}$）基因突变导致肝内苯丙氨酸羟化酶缺乏，进而使苯丙氨酸不能转变为酪氨酸而产生的疾病。针对发生特定突变的 $\mathrm{PAH}$ 致病基因，可采用基因置换或基因增强策略校正基因缺陷，也可采用基因编辑技术纠正基因异常结构，但目前尚无获批的基因治疗实施方案。

:::definition{label="单基因病为什么相对容易定方案"}
只受一对等位基因影响，致病基因清楚。基本方案：把正常基因导入患者体内，表达出正常功能蛋白质。
:::

:::definition{label="ADA 缺乏症与首例基因治疗试验"}
腺苷脱氨酶（adenosine deaminase，$\mathrm{ADA}$）缺乏症：常染色体隐性遗传性代谢缺陷。$\mathrm{T}$ 和 $\mathrm{B}$ 淋巴细胞代谢产物累积，$\mathrm{DNA}$ 合成受抑，细胞功能缺陷。$1990$ 年美国 $\mathrm{Blaese\ RM}$ 将正常人腺苷脱氨酶基因植入患者淋巴结内，完成世界上首例基因治疗试验。
:::

:::definition{label="血友病成纤维细胞方案"}
携带凝血因子Ⅸ的基因导入患者自体皮肤成纤维细胞，提高血浆凝血Ⅸ因子浓度，降低出血次数、减轻出血症状。这是增强 $+$ 成纤维细胞 $+$ 蛋白入血的合写。
:::

:::definition{label="PKU：有策略，无获批方案"}
苯丙酮尿症（$\mathrm{PKU}$）：苯丙氨酸羟化酶（$\mathrm{PAH}$）突变 $\rightarrow$ 肝内酶缺乏 $\rightarrow$ 苯丙氨酸不能转变为酪氨酸。可采用基因置换或基因增强校正缺陷，也可用基因编辑纠正异常结构，但目前尚无获批的基因治疗实施方案。
:::

:::timeline{period="本版点名的单基因病治疗账"}
- **原则** 一对等位基因、致病基因清楚，导入正常基因并表达蛋白质
- **1990** Blaese RM：ADA 基因植入患者淋巴结，世界首例基因治疗试验
- **血友病** 凝血因子Ⅸ基因 → 自体皮肤成纤维细胞 → 血浆因子浓度上升
- **PKU** 可置换、增强或编辑 PAH，目前尚无获批实施方案
:::

:::pitfall{label="PKU 不要写成已经批准的基因治疗"}
教材把策略列全，最后一句是「目前尚无获批的基因治疗实施方案」。写成「苯丙酮尿症已经用基因治疗常规替代饮食控制」，就把「尚无获批」删了。
:::

:::compare{title="ADA / 血友病 / PKU"}
| | 缺陷 | 本版写到哪一步 |
|--|------|--------------|
| $\mathrm{ADA}$ 缺乏症 | 腺苷脱氨酶，$\mathrm{T}/\mathrm{B}$ 细胞功能缺陷 | $1990$ 年首例试验：正常 $\mathrm{ADA}$ 基因植入淋巴结 |
| 血友病 | 凝血因子Ⅸ | 自体皮肤成纤维细胞导入，血浆浓度上升、出血减轻 |
| $\mathrm{PKU}$ | 肝内 $\mathrm{PAH}$ | 置换／增强／编辑都可设想，尚无获批方案 |

:::

### （二）基因治疗应用于多基因常见病

基因治疗最早是针对一些单基因遗传病进行的，但随着人们对恶性肿瘤、心血管疾病、糖尿病等分子机制的深入了解，越来越多的疾病相关基因被成功鉴定，基因治疗在这些多基因常见病中表现出良好的应用前景。目前已被克隆的恶性肿瘤相关基因较多，动物模型证据较充足，肿瘤患者及亲属对基因治疗的接受度相对较高，恶性肿瘤的基因治疗研究日趋活跃，并取得显著成果。常见的针对恶性肿瘤的基因治疗策略包括：针对癌基因或肿瘤血管生成相关基因的基因干扰、针对抑癌基因的基因增强、调节肿瘤免疫反应的细胞因子基因导入、自杀基因的导入等。

:::definition{label="从单基因走到多基因常见病"}
最早针对单基因遗传病。随着恶性肿瘤、心血管疾病、糖尿病等分子机制阐明、相关基因鉴定，多基因常见病也出现良好应用前景。
:::

:::definition{label="为什么肿瘤走在前面"}
已克隆的恶性肿瘤相关基因较多；动物模型证据较充足；患者及亲属接受度相对较高。研究日趋活跃，并取得显著成果。
:::

:::keypoint{label="恶性肿瘤基因治疗四条策略"}
- 基因干扰：对着癌基因或肿瘤血管生成相关基因。
- 基因增强：对着抑癌基因。
- 细胞因子基因导入：调节肿瘤免疫反应。
- 自杀基因导入。
这四条都能在本节策略部分找到对应户头，不要另造药名。
:::

:::insight{label="肿瘤策略是前面四户的组合，不是第五种"}
干扰、增强、细胞因子（增强里「本来不表达的基因」）、自杀基因，都已经立过。这里是把它们接到恶性肿瘤这一应用场景。
:::

### （三）基因治疗存在尚待解决的问题

科学家们在基因治疗领域取得了很大的进步，但在基因调控元件选择、靶细胞确定、安全高效载体的构建和转移手段、疗效评价等环节仍存在很多亟待解决的问题。例如，对于多种疾病的相关基因认识有限，缺乏切实有效的治疗靶基因，缺乏安全、高效、靶向性的基因转移系统。很多基因治疗手段尽管在细胞及动物实验中获得较为理想的测试结果，但应用于具有明显异质性的不同个体时，还应考虑这种基因治疗的有效性及可能的副作用。对于不同的疾病而言，其主要累及的细胞类型是不同的，治疗基因在不同类型细胞中的表达水平也存在明显差异。只有选择合适的细胞作为靶细胞，才能取得良好的效果。另外，目前的基因治疗临床试验中，多选择常规治疗失败或晚期肿瘤患者，尚难以客观地评价治疗效果。

:::definition{label="技术上还卡住的环节"}
基因调控元件选择、靶细胞确定、安全高效载体的构建和转移手段、疗效评价。具体表现：相关基因认识有限，缺切实有效的治疗靶基因，缺安全、高效、靶向性的转移系统。
:::

:::pitfall{label="细胞和动物实验成功不等于人体有效、无副作用"}
教材写：应用于具有明显异质性的不同个体时，还应考虑有效性及可能的副作用。不要把「动物模型证据较充足」直接等同于「临床已经可客观评价疗效」。
:::

:::insight{label="靶细胞选错，表达水平可以对不上"}
不同疾病累及的细胞类型不同，治疗基因在不同类型细胞中的表达水平有明显差异。只有选合适的细胞作靶细胞，才能取得良好效果。这是前面「靶细胞仅限体细胞」名单存在的理由。
:::

:::pitfall{label="晚期或常规治疗失败的受试者让疗效评价变难"}
目前临床试验多选择常规治疗失败或晚期肿瘤患者，尚难以客观评价治疗效果。不是「做了试验就等于已经证明优于常规治疗」。
:::

理论上，生殖细胞和体细胞均可作为基因治疗的实施对象，但纠正生殖细胞的遗传缺陷面临极大的伦理学问题，故针对人类生殖细胞的基因治疗被不同国家的法律所禁止。基于体细胞的基因治疗也必须在严格的专业监管和法律约束下谨慎进行，还须获得受试者的知情同意，保护受试者的权益，注重隐私保护，同时做好科普宣传，消除公众疑虑。

把基因治疗方案用于人体必须经过严格的审批程序。世界各国对基因治疗产品、方法的安全性与质量控制都采取了严格的措施和周密的临床前研究与评估。美国是最早开展基因治疗的国家，每个临床基因治疗方案的实施均须通过地方伦理小组、生物安全小组、人类基因治疗分委会等多个机构的严格审批。我国的基因治疗方案监管和审批制度不断完善。任何基因治疗方案的实施均须接受国家药品监督管理局等部门的审批和监督。

:::definition{label="生殖细胞基因治疗被法律禁止"}
理论上生殖细胞和体细胞都可以做。纠正生殖细胞遗传缺陷面临极大伦理学问题，针对人类生殖细胞的基因治疗被不同国家的法律所禁止。
:::

:::definition{label="体细胞治疗也不是随便做"}
必须在严格的专业监管和法律约束下谨慎进行；须获得受试者知情同意；保护权益与隐私；做好科普，消除公众疑虑。
:::

:::definition{label="用于人体必须严格审批"}
安全性与质量控制、周密的临床前研究与评估。美国：地方伦理小组、生物安全小组、人类基因治疗分委会等多个机构审批。我国：须接受国家药品监督管理局等部门的审批和监督。
:::

:::compare{title="伦理和法律两道门"}
| | 本版态度 | 还要满足什么 |
|--|---------|------------|
| 人生殖细胞 | 法律禁止 | 不是「技术上做得到就可以」 |
| 人体细胞 | 可研究、可应用，但是重点且须监管 | 知情同意、隐私、科普；多机构审批 |
| 上人体 | 必须严格审批 | 美国多机构；我国国家药品监督管理局等 |

第一节产前诊断里「由受试者决定是否终止妊娠」是诊断／咨询；这里是治疗能不能改生殖系。两件事不要并。
:::

:::memory{label="本节必背分户"}
- 基因治疗：导入正常或治疗基因，修正／替代／补偿缺陷，或干扰致病基因表达。核酸水平上的治疗都可纳入。
- 修复＝原位、不引入外源序列（修正＋置换），理想但不成熟；编辑（$\mathrm{ZFN}$、$\mathrm{TALEN}$、$\mathrm{CRISPR}$-$\mathrm{Cas9}$：$\mathrm{sgRNA}$＋$\mathrm{Cas9}$，$\mathrm{PAM}$，$\mathrm{DSB}$，$\mathrm{HR}$）服务于修正。
- 增强＝异位替代，缺陷基因还在，目前临床主要策略。例子：凝血因子Ⅸ；也可导入干扰素、白介素 $2$。整合位置随机，可能致新病。
- 干扰：反义 $\mathrm{RNA}$、核酶（锤头切断）、$\mathrm{miRNA}/\mathrm{siRNA}$ 降解 $\mathrm{mRNA}$。
- 自杀基因：酶激活前药；$\mathrm{TK}/\mathrm{GCV}$；甲胎蛋白启动子；旁观者效应。
- 图24-4：逆转录病毒 融合→逆转录→整合（前病毒）→转录→出芽。优势是长期整合，代价是随机插入。
- 腺病毒不整合、易丢失、免疫原性强；$\mathrm{AAV}$ 缺陷型、可靶向整合、兼具两者优点，容量小。
- 只做体细胞；人生殖细胞法律禁止。脐带血可补骨髓造血干细胞数量不足。
- 直接体内 in vivo（$\mathrm{AAV}$、脂质体／裸 $\mathrm{DNA}$）简便尚不成熟；间接体内 ex vivo（$\mathrm{CAR}$-$\mathrm{T}$）较安全、步骤多。
- $1990$ $\mathrm{Blaese\ RM}$、$\mathrm{ADA}$ 为首例试验；$\mathrm{PKU}$ 尚无获批方案。不要编教材没有的药名。
:::
