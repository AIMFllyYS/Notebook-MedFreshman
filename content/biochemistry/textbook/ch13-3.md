# 第三节　基因组学

前两节把单个基因写成断裂结构，把人基因组写成核 $\mathrm{DNA}$ 加 $\mathrm{mtDNA}$、编码序列只占 $1.5\%$、重复序列过半、蛋白质编码基因约两万。本节问：怎样把这套基因组读出来、怎样给每个基因做功能注释、怎样在物种之间和人群内部做比较。结构基因组学靠人类基因组计划的四张图；功能基因组学从扫描可读框走到转录物组和蛋白质组；比较基因组学分种间与种内。表观基因组学和宏基因组学是衍生概念。章末收本章小结和思考题。

:::concept{term="先问是作图测序、功能注释还是物种／个体比较"}
看见“基因组学”，先不要把测序流程、$\mathrm{BLAST}$ 和 $\mathrm{SNP}$ 并成一步。结构基因组学揭示全部 $\mathrm{DNA}$ 序列及其组成；功能基因组学鉴定所有基因（含非编码）的功能；比较基因组学找同源或差异，为预测功能和进化提供依据。四张图、鸟枪法、$\mathrm{EST}$ 是结构的账；全基因组扫描、实验验证、转录物组／蛋白质组是功能的账。
:::

基因组学是阐明整个基因组结构、结构与功能关系以及基因之间相互作用的科学。根据研究目的不同而分为结构基因组学（structural genomics）、功能基因组学（functional genomics）和比较基因组学（comparative genomics）。结构基因组学通过基因组作图和序列测定，揭示基因组全部 $\mathrm{DNA}$ 序列及其组成；功能基因组学则利用结构基因组学所提供的信息，分析和鉴定基因组中所有基因（包括编码和非编码序列）的功能；比较基因组学通过模式生物基因组之间或模式生物与人类基因组之间的比较与鉴定，发现同源基因或差异基因，为预测新基因的功能和研究生物进化提供依据。

近年来，基因组学还衍生出表观基因组学（epigenomics）、宏基因组学（metagenomics）等概念。表观基因组学研究细胞遗传物质的所有表观遗传修饰（epigenetic modification）以及对基因表达和功能的影响，$\mathrm{DNA}$ 甲基化修饰和组蛋白修饰是两个研究重点。而宏观基因组学则是一种以环境样品中微生物群体基因组结构与功能为研究对象，以微生物多样性、种群结构、进化关系、功能活性、相互协作关系及与环境之间的关系为研究目的的新的微生物研究方法。

:::definition{label="基因组学"}
基因组学（genomics）阐明整个基因组的结构、结构与功能关系以及基因之间的相互作用。按目的分为结构、功能、比较三类。
:::

:::definition{label="结构基因组学"}
通过基因组作图和序列测定，揭示基因组全部 $\mathrm{DNA}$ 序列及其组成。人类基因组计划（$\mathrm{HGP}$）是其主要实施途径。
:::

:::definition{label="功能基因组学"}
利用结构基因组学提供的信息，分析和鉴定基因组中所有基因（包括编码和非编码序列）的功能。
:::

:::definition{label="比较基因组学"}
通过模式生物基因组之间，或模式生物与人类基因组之间的比较与鉴定，发现同源基因或差异基因，为预测新基因功能和研究生物进化提供依据。
:::

:::definition{label="表观基因组学"}
表观基因组学（epigenomics）研究细胞遗传物质的所有表观遗传修饰以及对基因表达和功能的影响。两个研究重点：$\mathrm{DNA}$ 甲基化修饰和组蛋白修饰。
:::

:::definition{label="宏基因组学"}
宏基因组学（metagenomics）以环境样品中微生物群体基因组的结构与功能为对象，研究微生物多样性、种群结构、进化关系、功能活性、相互协作关系及与环境之间的关系。教材也称宏观基因组学。
:::

:::compare{title="三户基因组学加两个衍生概念"}
| | 问的是什么 | 本节点名的手段 |
|--|------------|----------------|
| 结构 | 全部 $\mathrm{DNA}$ 序列及其组成 | 作图、大规模测序；遗传／物理／转录／序列四张图 |
| 功能 | 所有基因（含非编码）做什么 | 全基因组扫描、$\mathrm{BLAST}$、转基因／敲除等、转录物组与蛋白质组 |
| 比较 | 物种间或群体内异同 | 种间比结构，种内比变异／$\mathrm{SNP}$ |
| 表观基因组学 | 修饰如何影响表达 | $\mathrm{DNA}$ 甲基化、组蛋白修饰 |
| 宏基因组学 | 环境微生物群体基因组 | 多样性、种群、进化、功能、协作与环境 |

结构提供信息，功能用这些信息，比较在已有图谱和序列上做。顺序不要倒。
:::

:::pitfall{label="功能基因组学不是“只研究编码蛋白质的基因”"}
教材括号写明：包括编码和非编码序列。第二节非蛋白质编码基因 $21\,954$ 个、$\mathrm{ncRNA}$ $48\,562$ 条、假基因也可表达 $\mathrm{ncRNA}$，都在功能基因组学的对象里。
:::

:::pitfall{label="宏基因组学不是把人的宏基因组再测一遍"}
对象是环境样品中的**微生物群体**基因组，不是人体细胞的核基因组。表观基因组学才是同一套遗传物质上的修饰。两个衍生概念不要并户。
:::

:::insight{label="比较基因组学的两端：模式生物和人"}
定义里写的是模式生物之间，或模式生物与人类之间。种内比较（人群 $\mathrm{SNP}$、疾病易感性、个体化用药）在本节第三部分另立。开篇这句不要理解成“只跟人比”。
:::

## 一、结构基因组学揭示基因组序列信息

结构基因组学主要通过人类基因组计划（human genome project，$\mathrm{HGP}$）的实施，解析人类自身 $\mathrm{DNA}$ 的序列和结构。研究内容就是通过基因组作图和大规模序列测定等方法，构建人类基因组图谱，即遗传图谱（genetic map）、物理图谱（physical map）、序列图谱（sequence map）和转录图谱（transcription map）。

:::definition{label="人类基因组计划"}
人类基因组计划（$\mathrm{HGP}$）是结构基因组学解析人类自身 $\mathrm{DNA}$ 序列和结构的主要实施途径。产出四张图：遗传图谱、物理图谱、序列图谱、转录图谱。
:::

:::keypoint{label="四张图一次分户"}
- 遗传图谱：连锁，单位 $\mathrm{cM}$。
- 物理图谱：实际距离，单位 $\mathrm{bp}$ 或 $\mathrm{kb}$；含 $\mathrm{FISH}$、限制酶切、克隆重叠群。
- 转录图谱：以 $\mathrm{EST}$ 为位标的表达图／$\mathrm{cDNA}$ 图。
- 序列图谱：$\mathrm{BAC}$ 文库 $+$ 鸟枪法测序后的全基因组序列。
:::

### （一）通过遗传作图和物理作图绘制人类基因组草图

人染色体 $\mathrm{DNA}$ 很长，不能直接进行测序，必须先将基因组 $\mathrm{DNA}$ 进行分解、标记，使之成为可操作的较小结构区域，这一过程称为作图。$\mathrm{HGP}$ 实施过程采用了遗传作图和物理作图的策略。

:::definition{label="作图"}
将很长的染色体 $\mathrm{DNA}$ 分解、标记，使之成为可操作的较小结构区域。$\mathrm{HGP}$ 采用遗传作图和物理作图。不能直接对整条人染色体测序，是作图的理由。
:::

**1. 遗传作图就是绘制连锁图**　遗传图谱又称连锁图谱（linkage map）。遗传作图（genetic mapping）就是确定连锁的遗传标志（genetic marker）或分子标志（molecular marker）位点在一条染色体上的排列顺序以及它们之间的相对遗传距离，用厘摩尔根（centi-Morgan，$\mathrm{cM}$）表示，当两个遗传标记之间的重组值为 $1\%$ 时，图距即为 $1\,\mathrm{cM}$（约为 $1\,000\,\mathrm{kb}$）。

常用的遗传标志有限制性片段长度多态性（restriction fragment length polymorphism，$\mathrm{RFLP}$）、可变数目串联重复序列（variable number of tandem repeat，$\mathrm{VNTR}$）和单核苷酸多态性（single nucleotide polymorphism，$\mathrm{SNP}$），其中 $\mathrm{SNP}$ 的精确度最高（$0.5\sim 1.0\,\mathrm{kb}$）。

:::definition{label="遗传图谱"}
遗传图谱又称连锁图谱（linkage map）。遗传作图确定连锁的遗传标志或分子标志在一条染色体上的排列顺序及相对遗传距离，单位是厘摩尔根（$\mathrm{cM}$）。重组值 $1\%$ 对应 $1\,\mathrm{cM}$，约为 $1\,000\,\mathrm{kb}$。
:::

:::definition{label="三种常用遗传标志"}
$\mathrm{RFLP}$：限制性片段长度多态性。$\mathrm{VNTR}$：可变数目串联重复序列。$\mathrm{SNP}$：单核苷酸多态性，精确度最高（$0.5\sim 1.0\,\mathrm{kb}$）。
:::

:::compare{title="遗传距离和物理距离不是同一把尺子"}
| | 遗传图谱 | 物理图谱 |
|--|----------|----------|
| 距离含义 | 相对遗传距离（重组率） | 染色体上的实际位置和距离 |
| 单位 | $\mathrm{cM}$（$1\%$、$1\,\mathrm{cM}\approx 1\,000\,\mathrm{kb}$） | $\mathrm{bp}$ 或 $\mathrm{kb}$ |
| 标志 | $\mathrm{RFLP}$、$\mathrm{VNTR}$、$\mathrm{SNP}$ | $\mathrm{FISH}$ 探针、限制酶切位点、$\mathrm{STS}$／克隆重叠群 |

$1\,\mathrm{cM}$ 约 $1\,000\,\mathrm{kb}$ 是教材给的换算，不是说重组率处处均匀。物理图在遗传图基础上更详细。
:::

:::pitfall{label="1 cM 不是 1 bp，SNP 也不是“最粗”的标志"}
$1\,\mathrm{cM}\approx 1\,000\,\mathrm{kb}$。$\mathrm{SNP}$ 精确度最高（$0.5\sim 1.0\,\mathrm{kb}$），不是 $\mathrm{RFLP}$ 最高。把连锁图的 $\mathrm{cM}$ 直接当成测序读长，后面的 $\mathrm{STS}$ 每隔 $100\,\mathrm{kb}$ 会失去意义。
:::

**2. 物理作图就是描绘杂交图、限制性酶切图及克隆系图**　物理作图（physical mapping）以物理尺度（$\mathrm{bp}$ 或 $\mathrm{kb}$）标示遗传标志在染色体上的实际位置和它们之间的距离，是在遗传作图基础上绘制的更为详细的基因组图谱。物理作图包括荧光原位杂交图（fluorescent in situ hybridization map，$\mathrm{FISH}$ map）、限制性酶切图（restriction map）及克隆重叠群图（clone contig map）等。

荧光原位杂交图是将荧光标记探针与染色体杂交确定分子标记所在的位置；限制性酶切图是将限制性酶切位点标定在 $\mathrm{DNA}$ 分子的相对位置。构建克隆重叠群图是最重要的一种物理作图，它是在采用酶切位点稀有的限制性内切酶或高频超声破碎技术将 $\mathrm{DNA}$ 分解成大片段后，再通过构建酵母人工染色体（yeast artificial chromosome，$\mathrm{YAC}$）或细菌人工染色体（bacterial artificial chromosome，$\mathrm{BAC}$），获取含已知基因组序列标签位点（sequence tagged site，$\mathrm{STS}$）的 $\mathrm{DNA}$ 大片段。$\mathrm{STS}$ 是指在染色体上定位明确、并且可用 $\mathrm{PCR}$ 扩增的单拷贝序列，每隔 $100\,\mathrm{kb}$ 距离就有一个标志。在 $\mathrm{STS}$ 基础上构建覆盖每条染色体的大片段 $\mathrm{DNA}$ 连续克隆系就可绘制精细物理图。可以说，通过克隆重叠群作图就可以知晓特异 $\mathrm{DNA}$ 大片段在特异染色体上的定位，这就为大规模 $\mathrm{DNA}$ 测序做好了准备。

:::definition{label="物理图谱"}
以 $\mathrm{bp}$ 或 $\mathrm{kb}$ 标示遗传标志在染色体上的实际位置和距离，是遗传作图基础上更详细的基因组图谱。包括 $\mathrm{FISH}$ 图、限制性酶切图及克隆重叠群图等。
:::

:::definition{label="FISH 图"}
荧光原位杂交图：荧光标记探针与染色体杂交，确定分子标记所在的位置。
:::

:::definition{label="限制性酶切图"}
将限制性酶切位点标定在 $\mathrm{DNA}$ 分子的相对位置。
:::

:::definition{label="克隆重叠群图"}
最重要的一种物理作图。用酶切位点稀有的限制酶或高频超声把 $\mathrm{DNA}$ 打成大片段，构建 $\mathrm{YAC}$ 或 $\mathrm{BAC}$，获取含已知 $\mathrm{STS}$ 的 $\mathrm{DNA}$ 大片段，再连成覆盖每条染色体的连续克隆系。由此可知特异大片段在特异染色体上的定位，为大规模测序做准备。
:::

:::definition{label="STS"}
序列标签位点（sequence tagged site）：在染色体上定位明确、并且可用 $\mathrm{PCR}$ 扩增的单拷贝序列。每隔 $100\,\mathrm{kb}$ 距离就有一个标志。
:::

:::definition{label="YAC 与 BAC"}
酵母人工染色体（$\mathrm{YAC}$）和细菌人工染色体（$\mathrm{BAC}$）用于装载基因组大片段。后文序列图谱明确：$\mathrm{BAC}$ 载体是装载较大片段 $\mathrm{DNA}$ 的克隆载体系统，用于基因组文库构建。
:::

:::keypoint{label="物理作图三张子图"}
- $\mathrm{FISH}$：探针在染色体上的位置。
- 限制酶切图：酶切位点相对位置。
- 克隆重叠群：$\mathrm{YAC}/\mathrm{BAC}+\mathrm{STS}$（每 $100\,\mathrm{kb}$ 一个）$\rightarrow$ 连续克隆系 $\rightarrow$ 精细物理图。
:::

:::pitfall{label="STS 是单拷贝、能 PCR，不是一段重复序列"}
定义强调：定位明确、可用 $\mathrm{PCR}$ 扩增的**单拷贝**序列。第二节的 $\mathrm{Alu}$、$50$ 万拷贝不能拿来当 $\mathrm{STS}$。每隔 $100\,\mathrm{kb}$ 一个标志，是物理图的路标密度。
:::

:::insight{label="克隆重叠群是测序前的骨架"}
人染色体 $\mathrm{DNA}$ 太长，不能直接测。先切大片段、装进 $\mathrm{YAC}/\mathrm{BAC}$、用 $\mathrm{STS}$ 把大片段在染色体上排好，才知道“这一段来自哪条染色体的哪一块”。没有这张物理骨架，后文鸟枪法拼出来的读段就对不回染色体。
:::

### （二）通过 EST 文库绘制转录图谱

人类基因组 $\mathrm{DNA}$ 中只有约 $1.5\%$ 的序列为蛋白质编码序列，对于一个特定的个体来讲，其体内所有类型的细胞均含有同样的一套基因组，但成年个体每一特定组织中，细胞内一般只有 $10\%$ 的基因是表达的；即使是同一种细胞，在其发育的不同阶段，基因表达谱亦是不一样的。因此，了解每一组织细胞及其在不同发育阶段、不同生理和病理情况下 $\mathrm{mRNA}$ 转录情况，可以帮助我们了解不同状态下细胞基因表达情况，推断基因的生物学功能。

转录图谱又称为 $\mathrm{cDNA}$ 图或表达图（expression map），是一种以表达序列标签（expressed sequence tag，$\mathrm{EST}$）为位标绘制的分子遗传图谱。通过从 $\mathrm{cDNA}$ 文库中随机挑取的克隆进行测序所获得的部分 $\mathrm{cDNA}$ 的 $5'$ 或 $3'$ 端序列称为 $\mathrm{EST}$，一般长 $300\sim 500\,\mathrm{bp}$ 左右。将 $\mathrm{mRNA}$ 逆转录合成的 $\mathrm{cDNA}$ 片段作为探针与基因组 $\mathrm{DNA}$ 进行分子杂交，标记转录基因在基因组 $\mathrm{DNA}$ 上的位置，就可以绘制出可表达基因的转录图谱。

:::definition{label="同一套基因组，不同的表达谱"}
一个特定个体的所有类型细胞含同样一套基因组；成年个体每一特定组织中一般只有 $10\%$ 的基因表达；同一种细胞在发育不同阶段表达谱也不一样。因此要按组织、发育、生理和病理去看 $\mathrm{mRNA}$。
:::

:::definition{label="转录图谱"}
转录图谱又称 $\mathrm{cDNA}$ 图或表达图（expression map），以 $\mathrm{EST}$ 为位标。用 $\mathrm{mRNA}$ 逆转录的 $\mathrm{cDNA}$ 片段作探针与基因组 $\mathrm{DNA}$ 杂交，标记可表达基因在基因组上的位置。
:::

:::definition{label="EST"}
表达序列标签（expressed sequence tag）：从 $\mathrm{cDNA}$ 文库随机挑克隆测序，得到的部分 $\mathrm{cDNA}$ 的 $5'$ 或 $3'$ 端序列，一般长 $300\sim 500\,\mathrm{bp}$。
:::

:::compare{title="序列图谱看全部 DNA，转录图谱看谁在表达"}
| | 对象 | 覆盖 |
|--|------|------|
| 序列图谱 | 基因组 $\mathrm{DNA}$ 全序列 | 含 $98.5\%$ 非蛋白质编码序列 |
| 转录图谱 | 可表达基因的位置 | 成年特定组织大约只有 $10\%$ 基因表达 |

$1.5\%$ 编码序列是第二节的数，本节再引用一次，用来说明为什么必须另画一张表达图。
:::

:::pitfall{label="EST 不是全长 cDNA，也不是基因组测序读段"}
它是 $\mathrm{cDNA}$ 的 $5'$ 或 $3'$ 端一部分，一般 $300\sim 500\,\mathrm{bp}$。不要把 $\mathrm{EST}$ 写成整条 $\mathrm{mRNA}$，也不要写成染色体 $\mathrm{DNA}$ 的鸟枪法片段。来源是 $\mathrm{cDNA}$ 文库，已经过逆转录，反映的是表达过的基因。
:::

:::insight{label="10% 在表达，所以转录图比全基因组“稀”"}
所有细胞基因组相同，是功能差异来自表达谱而不是“各组织各有一套基因”的结构基础。转录图谱回答的是：在这个组织、这个阶段，哪些基因的 $\mathrm{mRNA}$ 出现了、它们在染色体上落在哪。
:::

### （三）通过 BAC 克隆系和鸟枪法测序等构建序列图谱

在基因作图的基础上，通过 $\mathrm{BAC}$ 克隆系的构建和鸟枪法测序（shotgun sequencing），就可完成全基因组的测序工作，再通过生物信息学手段，即可构建基因组的序列图谱。

$\mathrm{BAC}$ 载体是一种装载较大片段 $\mathrm{DNA}$ 的克隆载体系统，用于基因组文库构建。全基因组鸟枪法测序是直接将整个基因组打成不同大小的 $\mathrm{DNA}$ 片段，构建 $\mathrm{BAC}$ 文库，然后对文库进行随机测序，最后运用生物信息学方法将测序片段拼接成全基因组序列（图13-7），此称为基因组组装（genome assembly）。

:::definition{label="序列图谱"}
在作图基础上，经 $\mathrm{BAC}$ 克隆系构建和鸟枪法测序完成全基因组测序，再用生物信息学构建的基因组序列图。
:::

:::definition{label="BAC 载体"}
装载较大片段 $\mathrm{DNA}$ 的克隆载体系统，用于基因组文库构建。
:::

:::definition{label="全基因组鸟枪法测序"}
直接将整个基因组打成不同大小的 $\mathrm{DNA}$ 片段，构建 $\mathrm{BAC}$ 文库，对文库随机测序，再用生物信息学把测序片段拼接成全基因组序列。这一拼接称为基因组组装（genome assembly）。
:::

:::note{label="电子版缺失"}

- 把整个基因组打成不同大小片段。
- 构建 $\mathrm{BAC}$ 文库。
- 对文库随机测序。
- 生物信息学拼接 $=$ 基因组组装。
:::

:::cause-effect{title="为什么必须先作图再鸟枪法拼序列"}
- **因** 人染色体 $\mathrm{DNA}$ 太长，随机打断后的读段本身不知道来自哪条染色体
- **果** 先有遗传／物理骨架（尤其 $\mathrm{STS}$ 克隆重叠群），再把组装结果贴回染色体，才得到可用的序列图谱
:::

:::pitfall{label="鸟枪法不是“对着染色体逐碱基从头读到尾”"}
教材写的是随机测序再拼接。$\mathrm{BAC}$ 负责把较大片段克隆出来，组装负责把随机读段拼回去。把它听成 Sanger 一条引物走完整条染色体，图13-7 的流程和“不能直接测序所以要作图”都会矛盾。
:::

:::timeline{period="结构基因组学四张图的逻辑顺序"}
- **作图** 把超长染色体 DNA 分解、标记成可操作区域
- **遗传图谱** 用 RFLP、VNTR、SNP 排连锁顺序，单位 cM
- **物理图谱** 用 FISH、酶切位点、STS 克隆重叠群标实际 kb／bp
- **转录图谱** 用 EST（300～500 bp 的 cDNA 端序列）标记可表达基因
- **序列图谱** BAC 文库加鸟枪法随机测序，再组装成全基因组序列
:::

## 二、功能基因组学系统探讨基因的活动规律

功能基因组学的主要研究内容包括基因组的表达、基因组功能注释、基因组表达调控网络及机制的研究等。它从整体水平上研究一种组织或细胞在同一时间或同一条件下所表达基因的种类、数量、功能，或同一细胞在不同状态下基因表达的差异。它可以同时对多个表达基因或蛋白质进行研究，使得生物学研究从以往的单一基因或单一蛋白质分子研究转向多个基因或蛋白质的系统研究。

:::definition{label="功能基因组学的研究内容"}
基因组的表达、基因组功能注释、基因组表达调控网络及机制。整体水平看：同一时间／条件下一种组织或细胞表达哪些基因、数量和功能如何；或同一细胞不同状态下的表达差异。
:::

:::insight{label="从单基因转向系统"}
可以同时对多个表达基因或蛋白质进行研究。这是功能基因组学相对经典“一次一个基因”的转向。第二节已经写过：人蛋白质编码基因约两万，成年特定组织大约只有 $10\%$ 在表达——系统研究面对的是这个集合，不是某一个外显子。
:::

### （一）通过全基因组扫描鉴定 DNA 序列中的基因

这项工作以基因组 $\mathrm{DNA}$ 序列数据库为基础，加工和注释人类基因组的 $\mathrm{DNA}$ 序列，进行新基因预测、蛋白质功能预测及疾病基因的发现。主要采用计算机技术进行全基因组扫描，鉴定内含子与外显子之间的衔接，寻找全长可读框（open reading frame，$\mathrm{ORF}$），确定多肽链编码序列。

:::definition{label="全基因组扫描注释基因"}
以基因组 $\mathrm{DNA}$ 序列数据库为基础，加工和注释序列：预测新基因、预测蛋白质功能、发现疾病基因。计算机扫描鉴定内含子与外显子衔接，寻找全长可读框（$\mathrm{ORF}$），确定多肽链编码序列。
:::

:::definition{label="可读框"}
可读框（open reading frame，$\mathrm{ORF}$）是全基因组扫描时寻找的全长编码框架，用于确定多肽链编码序列。衔接内含子／外显子是扫描的另一步，因为真核基因是断裂的。
:::

:::pitfall{label="找到 ORF 不等于已经证明功能"}
扫描给出的是编码序列预测。后文还要同源搜索和实验验证。把计算机注释直接当成“这个基因在体内一定这样工作”，功能基因组学会停在第一小节。
:::

### （二）通过 BLAST 等程序搜索同源基因

同源基因在进化过程中来自共同的祖先，因此通过核苷酸或氨基酸序列的同源性比较，就可以推测基因组内相似基因的功能。这种同源搜索涉及序列比较分析，$\mathrm{NCBI}$ 的 $\mathrm{BLAST}$ 程序是基因同源性搜索和比对的有效工具。每一个基因在 $\mathrm{GenBank}$ 中都有一个序列访问号（accession number），在 $\mathrm{BLAST}$ 界面上输入 $2$ 条或多条访问号，就可实现一对或多对序列的比对。

:::definition{label="同源基因"}
在进化过程中来自共同祖先的基因。核苷酸或氨基酸序列的同源性比较，可用来推测基因组内相似基因的功能。
:::

:::definition{label="BLAST"}
$\mathrm{NCBI}$ 的 $\mathrm{BLAST}$ 程序是基因同源性搜索和比对的有效工具。$\mathrm{GenBank}$ 中每个基因有一个序列访问号（accession number）；在界面输入 $2$ 条或多条访问号，即可一对或多对序列比对。
:::

:::insight{label="同源搜索把第二节的基因家族用起来"}
多基因家族来自祖先基因的重复和变异，外显子相关。$\mathrm{BLAST}$ 比的就是这类序列相似性。比较基因组学种间、种内也都采用 $\mathrm{BLAST}$ 等工具——同一把尺子，问的问题从“这个基因像谁”变成“这个物种／这个个体和谁不同”。
:::

:::pitfall{label="同源不是“功能一定相同”"}
来自共同祖先、序列可对齐，可以**推测**功能。第二节超家族已经警告：序列相似，功能不一定相关。$\mathrm{BLAST}$ 给出的是比较结果，不是体内验证。
:::

### （三）通过实验验证基因功能

可设计一系列的实验来验证基因的功能，包括转基因、基因过表达、基因敲除、基因敲减或基因沉默等方法，结合所观察到的表型变化即可验证基因功能。由于生命活动的重要功能基因在进化上是保守的，因此可以采用合适的模式生物进行实验。

:::definition{label="实验验证基因功能"}
转基因、基因过表达、基因敲除、基因敲减或基因沉默，结合表型变化验证功能。重要功能基因进化上保守，可用合适的模式生物。
:::

:::compare{title="预测、同源、实验三步不要互相替代"}
| 步骤 | 做什么 | 能证明什么 |
|------|--------|------------|
| 全基因组扫描 | 找外显子／内含子衔接和 $\mathrm{ORF}$ | 这段序列**像**基因 |
| $\mathrm{BLAST}$ | 与已知基因比同源 | 功能**可能**类似祖先／旁系 |
| 实验 | 转基因、过表达、敲除、敲减、沉默 | 表型变化支持功能 |

第一节开篇的研究手段（比对、相互作用、细胞水平高表达／沉默、整体转基因／敲除）在这里收成功能基因组学的实验清单。
:::

### （四）通过转录物组和蛋白质组描述基因表达模式

基因的表达包括转录和翻译过程，研究基因的表达模式及调控可借助转录物组学和蛋白质组学相关技术与方法（见第十八章）进行。

:::definition{label="转录物组与蛋白质组描述表达模式"}
表达包括转录和翻译。表达模式及调控可借助转录物组学和蛋白质组学研究。具体技术见第十八章，本节只立户头。
:::

:::pitfall{label="转录物组不等于蛋白质组"}
转录看 $\mathrm{RNA}$，翻译看蛋白质。成年组织只有约 $10\%$ 基因表达，而且可变剪接、翻译后事件都会让两条组学的名单对不齐。不要把 $\mathrm{EST}$ 转录图谱直接当成蛋白质清单。
:::

:::keypoint{label="功能基因组学四条路径"}
- 扫描：内含子／外显子衔接 $+\mathrm{ORF}$。
- 同源：$\mathrm{BLAST}$、访问号。
- 实验：转基因／过表达／敲除／敲减／沉默 $+$ 表型；可用模式生物。
- 组学：转录物组 $+$ 蛋白质组（第十八章）。
:::

## 三、比较基因组学鉴别基因组的相似性和差异性

比较基因组学是在基因组图谱和序列的基础上，通过与已知基因和基因组结构的比较来了解基因的功能、表达机制和物种进化的学科领域。比较基因组学可在物种间和物种内进行，前者称为种间比较基因组学，后者则称为种内比较基因组学，两者均可采用 $\mathrm{BLAST}$ 等序列比对工具。

:::definition{label="比较基因组学的工作基础"}
在基因组图谱和序列的基础上，与已知基因和基因组结构比较，了解基因功能、表达机制和物种进化。分种间、种内，都可用 $\mathrm{BLAST}$ 等工具。
:::

### （一）种间比较基因组学阐明物种间基因组结构的异同

种间比较基因组学通过比较不同亲缘关系物种的基因组序列，可以鉴别出编码序列、非编码（调控）序列及特定物种独有的基因序列。而对基因组序列的比对，可以了解不同物种在基因构成、基因顺序和核苷酸组成等方面的异同，从而用于基因定位和基因功能的预测，并为阐明生物系统中的进化关系提供数据。

:::definition{label="种间比较基因组学"}
比较不同亲缘关系物种的基因组序列，鉴别编码序列、非编码（调控）序列及特定物种独有的基因序列。比对可显示基因构成、基因顺序和核苷酸组成的异同，用于基因定位、功能预测和进化关系。
:::

:::insight{label="种间比较为什么能把编码区和调控区分开"}
第一节写过：不同种属中外显子通常较保守，内含子变异较大。种间能对齐的区段更像编码序列或重要调控元件；对不齐又为某物种独有的，可能是物种特异基因。表13-1 那些基因组大小和基因数，只有放到序列比对里才变成进化证据。
:::

### （二）种内比较基因组学阐明群体内基因组结构的变异和多态性

同种群体内个体基因组存在大量的变异和多态性，这种基因组序列的差异构成了不同个体与群体对疾病的易感性和对药物、环境因素等不同反应的分子遗传学基础。例如，$\mathrm{SNP}$ 最大限度地代表了不同个体之间的遗传差异，鉴别个体间 $\mathrm{SNP}$ 差异可揭示不同个体的疾病易感性和对药物的反应性，有利于判定不同人群对疾病的易感程度并指导个体化用药。

:::definition{label="种内比较基因组学"}
阐明群体内基因组结构的变异和多态性。这些差异构成不同个体与群体对疾病易感性、对药物和环境因素不同反应的分子遗传学基础。
:::

:::definition{label="SNP 代表个体遗传差异"}
$\mathrm{SNP}$ 最大限度地代表不同个体之间的遗传差异。鉴别个体间 $\mathrm{SNP}$ 差异，可揭示疾病易感性和药物反应性，有利于判定人群易感程度并指导个体化用药。遗传作图里 $\mathrm{SNP}$ 精确度最高（$0.5\sim 1.0\,\mathrm{kb}$），种内比较把它从“作图标志”用成“个体差异的分子基础”。
:::

:::compare{title="种间 vs 种内"}
| | 种间 | 种内 |
|--|------|------|
| 比较对象 | 不同亲缘关系的物种 | 同种群体的不同个体 |
| 主要收获 | 编码／非编码／物种独有序列；基因构成、顺序、核苷酸组成；定位、功能预测、进化 | 变异和多态性；疾病易感性；药物和环境反应 |
| 标志性工具／位点 | $\mathrm{BLAST}$ 等 | $\mathrm{BLAST}$ 等；尤其 $\mathrm{SNP}$ |

两户都建立在已经有的图谱和序列上，所以比较基因组学排在结构、功能之后。
:::

:::pitfall{label="SNP 在本节出现两次，一次是作图精度，一次是个体化用药"}
遗传作图：$\mathrm{SNP}$ 精确度最高（$0.5\sim 1.0\,\mathrm{kb}$）。种内比较：$\mathrm{SNP}$ 最大限度代表个体遗传差异，连到疾病易感性和用药。不要只背其中一句。也不要把种内比较写成“人和小鼠比”——那是种间。
:::

:::cause-effect{title="为什么个体化用药要落到 SNP"}
- **因** 同种群体内序列差异构成对疾病、药物、环境不同反应的分子基础，$\mathrm{SNP}$ 最大限度代表这些差异
- **果** 鉴别个体间 $\mathrm{SNP}$，有助于判断人群易感程度并指导个体化用药
:::

## 本章小结

基因是能够编码蛋白质或 $\mathrm{RNA}$ 等具有特定功能产物的、负载遗传信息的基本单位，除了某些以 $\mathrm{RNA}$ 为基因组的 $\mathrm{RNA}$ 病毒外，通常是指染色体或基因组的一段 $\mathrm{DNA}$ 序列。基因的基本结构包含编码蛋白质或 $\mathrm{RNA}$ 的编码序列及其与之相关的非编码序列。真核基因结构最突出的特点是其不连续性，被称为断裂基因。

基因组是指生物体或细胞中一套完整单体具有的遗传信息的总和。真核基因组具有基因编码序列在基因组中所占比例小于非编码序列，高等真核生物基因组含有大量的重复序列，存在多基因家族和假基因，具有可变剪接，以及真核基因组 $\mathrm{DNA}$ 与蛋白质结合形成染色体、储存于细胞核内等特点。线粒体 $\mathrm{DNA}$ 是核外遗传物质，可以独立编码线粒体中的一些蛋白质。人的线粒体基因组全长 $16\,569\,\mathrm{bp}$，共编码 $37$ 个基因。人基因组中约有两万个基因，分布在 $22$ 条常染色体及 $2$ 条性染色体上，但并不是均匀分布。

基因组学是阐明整个基因组结构、功能以及基因之间相互作用的科学。主要研究内容包括结构基因组学、功能基因组学和比较基因组学。结构基因组学的主要任务是基因组作图和序列测定；功能基因组学利用结构基因组所提供的信息，分析基因组中所有基因（包括编码和非编码序列）的功能；比较基因组学通过不同生物基因及基因组之间的比较，研究基因的功能、表达机制及其进化关系。

:::definition{label="本章小结里的基因"}
编码蛋白质或 $\mathrm{RNA}$ 等产物、负载遗传信息的基本单位。除 $\mathrm{RNA}$ 病毒外，通常是染色体或基因组的一段 $\mathrm{DNA}$。基本结构＝编码序列 $+$ 相关非编码序列。真核最突出特点：不连续，即断裂基因。
:::

:::definition{label="本章小结里的基因组"}
一套完整单体的遗传信息总和。真核特点：编码序列比例小于非编码；大量重复序列；多基因家族和假基因；可变剪接；$\mathrm{DNA}$ 与蛋白质结合成染色体，储于核内。$\mathrm{mtDNA}$ 为核外遗传物质，人 $16\,569\,\mathrm{bp}$、$37$ 个基因。人约两万个基因，在 $22$ 条常染色体及 $2$ 条性染色体上非均匀分布。
:::

:::definition{label="本章小结里的基因组学"}
阐明整个基因组结构、功能以及基因之间相互作用。结构：作图和序列测定。功能：分析所有基因（含非编码）的功能。比较：不同生物基因及基因组之间，研究功能、表达机制和进化关系。
:::

:::keypoint{label="本章小结按节收口"}
- 第一节：基因＝编码产物 $+$ 表达所需序列；断裂基因；三类启动子；增强子／沉默子／绝缘子。
- 第二节：编码序列占全基因组 $1.5\%$；重复序列过半；家族与假基因；$\mathrm{mtDNA}$ $16\,569\,\mathrm{bp}$／$37$ 基因；约两万蛋白质编码基因，染色体上非均匀分布。
- 第三节：结构（四张图、鸟枪法）、功能（扫描、$\mathrm{BLAST}$、实验、组学）、比较（种间／种内，$\mathrm{SNP}$）。
:::

:::insight{label="小结把“约两万个基因”钉在蛋白质编码这一档"}
章末写人基因组中约有两万个基因，与第二节 $\mathrm{NCBI}$ $2023$ 年 $3$ 月蛋白质编码基因 $20\,080$ 对齐，而不是表13-1 的基因和假基因 $59\,444$。分布写成 $22$ 条常染色体及 $2$ 条性染色体，与 $22$ 对常染色体 $+1$ 对性染色体同一套染色体，只是按条数说。
:::

:::pitfall{label="小结的“独立编码”不要盖过“受核控制”"}
章末：线粒体 $\mathrm{DNA}$ 可以独立编码线粒体中的一些蛋白质。第二节正文紧接着写：并不意味着完全不受核基因控制。两句一起背。
:::

## 思考题

1. 如何理解断裂基因及其意义？
2. 何谓启动子、增强子、沉默子、绝缘子？
3. 真核基因组的结构特点是什么？
4. 举例说明是否可以根据基因组大小或基因数量判断生物体的复杂程度。
5. 何谓基因组学？基因组学的研究内容有哪些？

:::tip{label="五道思考题在正文里的户头"}
- 断裂基因：真核最突出的不连续性；外显子出现在成熟 $\mathrm{mRNA}$，内含子被剪接去除；内含子数比外显子少 $1$；鸡卵清蛋白 $7.7\,\mathrm{kb}$／$8$ 外显子 $7$ 内含子 $\rightarrow$ 成熟 $\mathrm{mRNA}$ $1.2\,\mathrm{kb}$。意义：使同一基因经可变剪接编码不同多肽（人约 $60\%$ 基因可变剪接，$80\%$ 改蛋白质序列），并以有限基因数支撑更高复杂性。
- 四元件：启动子提供起始信号，三类对应三种 $\mathrm{RNA}$ 聚合酶；增强子增强表达，方向位置不限、大部分上游；沉默子结合反式因子后阻遏；绝缘子挡增强子或挡异染色质（$\mathrm{RAP1}$、$\mathrm{CTCF}$）。
- 真核基因组特点：编码序列比例小于非编码（人全基因组 $1.5\%$、单基因内约 $5\%$）；大量重复序列（人 $50\%$ 以上）；多基因家族和假基因；可变剪接；$\mathrm{DNA}$ 与蛋白质结合成染色体储于核内；另有 $\mathrm{mtDNA}$ 等核外基因组；体细胞二倍体（配子除外）。
- 不能只根据大小或基因数判断复杂性。人基因组最大、最复杂，蛋白质编码基因 $20\,080$ 并不是最多（表13-1 线虫 $46\,927$、小鼠 $50\,562$）；果蝇基因组大于线虫，基因数却更少。还要看基因密度、调控序列、转座子、内含子和可变剪接。
- 基因组学：阐明整个基因组结构、功能及基因相互作用。内容：结构（作图和测序，四张图）、功能（注释所有基因含非编码）、比较（种间／种内）。可提及表观基因组学与宏基因组学为衍生概念。
:::
