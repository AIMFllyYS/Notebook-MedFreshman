# 第四节　酶的调节

本节写酶的调节。先把对现有酶活性的快速调节摊开：别构（可逆非共价、多亚基协同，底物本身作调节物时速率–底物浓度曲线呈 $\mathrm{S}$ 形）和共价修饰（最常见的是磷酸化与去磷酸化）；再写酶原激活（胰蛋白酶原切掉六肽，实质是活性中心形成或暴露）以及消化酶、凝血因子的级联放大；最后写通过诱导、阻遏和降解改变酶含量的缓慢调节。细胞按内外环境调整代谢时，主要落在催化限速反应的调节酶（关键酶）上（见第十章）。

细胞内许多酶的活性是可以受调节的。通过调节，有些酶可在有活性和无活性、高活性和低活性两种状态之间转变。此外，某些酶在细胞内的含量也可以发生改变，从而改变酶在细胞内的总活性。细胞根据内外环境的变化而调整细胞内代谢时，主要是通过对催化限速反应的调节酶（亦称为关键酶）的活性进行调节而实现的（见第十章）。

:::definition{label="调节酶（关键酶）"}
催化限速反应的酶称为调节酶，亦称为关键酶。细胞根据内外环境变化调整代谢时，主要通过对这类酶的活性进行调节而实现（见第十章）。
:::

:::definition{label="酶的调节的两本账"}
一本是酶活性：有活性和无活性、高活性和低活性两种状态之间的转变。一本是酶含量：细胞内酶蛋白多少改变，从而改变总活性。活性账走快速调节，含量账走缓慢调节。
:::

:::concept{term="先问调的是现有酶的活性，还是酶蛋白的多少"}
看见“酶的调节”，先分户头。别构、磷酸化、酶原激活，调的都是已经在细胞里的那批酶分子；诱导、阻遏、降解，调的是酶蛋白合成与破坏的速率，改变的是含量。把两本账并成“酶活高了或低了”，第十章的限速酶会没有台阶。
:::

:::compare{title="快速调节与缓慢调节"}
| 项目 | 快速调节 | 缓慢调节 |
|------|----------|----------|
| 调什么 | 现有酶的活性 | 酶蛋白的含量 |
| 主要方式 | 别构调节、化学修饰（共价修饰）；酶原激活也改变现有分子是否有活性 | 合成的诱导与阻遏；酶蛋白降解 |
| 时间尺度 | 已有分子上立刻改构象或改共价状态 | 诱导表达后还要转录、翻译加工，一般需几小时以上 |
| 去除信号后 | 别构可逆解离即恢复；磷酸基可被磷酸酶脱掉 | 一旦酶被诱导合成，即使去除诱导因素，活性仍持续到该酶被降解或抑制 |
| 教材落点 | 本节“一” | 本节“二” |
:::

## 一、酶活性的调节是对酶促反应速率的快速调节

细胞对现有酶活性的调节包括酶的别构调节和酶的化学修饰调节，它们属于对酶促反应速率的快速调节。

:::definition{label="酶活性的快速调节"}
细胞对现有酶活性的调节包括酶的别构调节和酶的化学修饰调节，属于对酶促反应速率的快速调节。调的是已经合成好的酶分子，不是再去转录一条新的肽链。
:::

:::note{label="酶原激活也落在“现有分子”这一本账"}
酶原激活改的是已经合成或初分泌的无活性前体，同样不经过新的转录。它以水解肽键的方式让活性中心形成或暴露，常写成级联。教材把它放在“酶活性的调节”下第三小节。
:::

### （一）别构调节物通过改变酶的构象而调节酶活性

酶分子的非催化部位与某些化合物可逆地非共价结合后发生构象改变，进而改变酶活性状态的现象，称为酶的别构调节（allosteric regulation），亦曾称变构调节。

受别构调节的酶称为别构酶（allosteric enzyme），曾称变构酶。结合在别构酶的调节部位调节酶催化活性的生物分子称为别构调节物（allosteric modulator）。别构酶上结合效应物的部位称为别构部位（allosteric site）。能使酶发生别构作用，导致酶活性增强的物质称为别构激活剂（allosteric activator）。能够与酶的非催化部分结合，导致酶发生构象变化抑制酶活性的物质称为别构抑制剂（allosteric inhibitor）。别构调节物可以是代谢途径的终产物、中间产物、酶的底物或其他物质。

:::definition{label="别构调节"}
酶分子的非催化部位与某些化合物可逆地非共价结合后发生构象改变，进而改变酶活性状态的现象，称为酶的别构调节（allosteric regulation），亦曾称变构调节。
:::

:::definition{label="别构酶"}
受别构调节的酶称为别构酶（allosteric enzyme），曾称变构酶。分子中常含有多个（偶数）亚基。
:::

:::definition{label="别构调节物"}
结合在别构酶的调节部位、调节酶催化活性的生物分子称为别构调节物（allosteric modulator）。可以是代谢途径的终产物、中间产物、酶的底物或其他物质。
:::

:::definition{label="别构部位"}
别构酶上结合效应物的部位称为别构部位（allosteric site）。它不是催化部位；结合是可逆的非共价结合。
:::

:::definition{label="别构激活剂"}
能使酶发生别构作用，导致酶活性增强的物质称为别构激活剂（allosteric activator）。
:::

:::definition{label="别构抑制剂"}
能够与酶的非催化部分结合，导致酶发生构象变化、抑制酶活性的物质称为别构抑制剂（allosteric inhibitor）。
:::

:::pitfall{label="别构结合不在活性中心，也不是共价键"}
教材写的是非催化部位、可逆地非共价结合。把它听成“抑制剂占住底物口袋”，会和第三节的竞争性抑制剂并成一本账；把它听成磷酸化那样接上磷酸基，化学修饰那一小节会没有对立面。
:::

别构酶分子中常含有多个（偶数）亚基，具有多亚基的别构酶存在着协同效应，包括正协同效应和负协同效应。如果调节物与酶的一个亚基结合，此亚基的别构效应使相邻亚基也发生构象改变，并增加对此调节物的亲和力，这种协同效应称为正协同效应；如果后续亚基的构象改变降低对此调节物的亲和力，则称为负协同效应。如果调节物是底物本身，正协同效应的反应速率–底物浓度曲线呈 $\mathrm{S}$ 形（图2-20）。

:::definition{label="正协同效应"}
调节物与酶的一个亚基结合后，此亚基的别构效应使相邻亚基也发生构象改变，并增加对此调节物的亲和力，称为正协同效应。
:::

:::definition{label="负协同效应"}
后续亚基的构象改变降低对此调节物的亲和力，称为负协同效应。
:::

:::definition{label="别构酶的 S 形曲线"}
如果调节物是底物本身，正协同效应的反应速率–底物浓度曲线呈 $\mathrm{S}$ 形。别构激活剂使该 $\mathrm{S}$ 形曲线左移，别构抑制剂使 $\mathrm{S}$ 形曲线右移。
:::

::figure{src="/images/biochemistry/textbook/p0078_02.png" caption="图2-20　别构酶的正协同效应速率–底物浓度作图。横轴为底物浓度［S］，纵轴为反应速率 v；实线为别构酶本身的 S 形曲线。别构激活剂使 S 形曲线左移，别构抑制剂使 S 形曲线右移。" alt="速率对底物浓度作图：黑色 S 形曲线居中，左侧虚线为别构激活并标左移箭头，右侧虚线为别构抑制并标右移箭头"}

:::compare{title="正协同与负协同"}
| 项目 | 正协同效应 | 负协同效应 |
|------|------------|------------|
| 第一个亚基结合调节物之后 | 相邻亚基构象改变，亲和力增加 | 后续亚基构象改变，亲和力降低 |
| 调节物是底物本身时 | $v$-$[\mathrm{S}]$ 呈 $\mathrm{S}$ 形 | 教材未把负协同画成 $\mathrm{S}$ 形 |
| 图2-20 | 别构酶的 $\mathrm{S}$ 形；激活剂左移、抑制剂右移 | 本图不画 |
:::

:::compare{title="别构酶的 S 形曲线与米氏矩形双曲线"}
| 项目 | 第三节米氏酶 | 本节别构酶（底物本身作调节物、正协同） |
|------|--------------|------------------------------------------|
| $v$-$[\mathrm{S}]$ 形状 | 矩形双曲线 | $\mathrm{S}$ 形 |
| 低 $[\mathrm{S}]$ | 近一级反应，上升较快 | 曲线起步平缓，随后变陡 |
| 结合部位 | 活性中心结合底物 | 另有别构部位；亚基之间还有协同 |
| 调节物 | 不写别构激活／抑制 | 别构激活剂使曲线左移，别构抑制剂使曲线右移 |
:::

:::insight{label="左移是更容易被底物饱和，右移是更难"}
同一条 $\mathrm{S}$ 形曲线，激活剂把它推向低 $[\mathrm{S}]$ 一侧（左移），较低底物浓度就能达到较高速率；抑制剂推向高 $[\mathrm{S}]$ 一侧（右移）。不要把左移听成“最大速率变了”——图2-20 画的是整条曲线沿横轴平移，不是把 $v$ 轴截距单独抬高。
:::

:::pitfall{label="S 形曲线是正协同的底物效应，不是所有别构都长这样"}
教材的条件写得很紧：调节物是底物本身，并且是正协同。终产物反馈抑制走别构抑制剂，曲线右移，不一定再把横轴叫“该终产物浓度”。把所有别构酶都默写成一条 $\mathrm{S}$ 形米氏曲线的“变形”，协同效应的正负两本账会并掉。
:::

:::example{label="如何读图2-20"}
先找黑色实线：那是别构酶本身的 $\mathrm{S}$ 形。再看“别构激活”箭头指向左侧虚线，同一 $v$ 出现在更低 $[\mathrm{S}]$；“别构抑制”箭头指向右侧虚线，同一 $v$ 要更高 $[\mathrm{S}]$ 才到。纵轴从原点升起，高 $[\mathrm{S}]$ 时接近平台，这是协同饱和，不是第三节那条从一开始就较陡的矩形双曲线。
:::

### （二）酶的化学修饰调节是通过某些化学基团与酶的共价可逆结合来实现

酶蛋白肽链上的某些小分子基团可以共价结合到被修饰酶的特定氨基酸残基上，引起酶分子构象变化，从而调节酶活性变化，这种调节方式称为酶的化学修饰（chemical modification）或称酶的共价修饰（covalent modification）。酶的化学修饰有多种形式，其中最常见的形式是磷酸化和去磷酸化。酶蛋白的磷酸化是在蛋白质激酶的催化下，来自 $\mathrm{ATP}$ 的 $\gamma$-磷酸基共价地结合在酶蛋白的 $\mathrm{Ser}$、$\mathrm{Thr}$ 或 $\mathrm{Tyr}$ 残基的侧链羟基上。反之，磷酸化的酶蛋白在磷蛋白磷酸酶催化下，磷酸酯键被水解而脱去磷酸基（图2-21）。

:::definition{label="酶的化学修饰（共价修饰）"}
酶蛋白肽链上的某些小分子基团共价结合到被修饰酶的特定氨基酸残基上，引起酶分子构象变化，从而调节酶活性，称为酶的化学修饰（chemical modification），或称酶的共价修饰（covalent modification）。
:::

:::definition{label="磷酸化"}
在蛋白质激酶催化下，来自 $\mathrm{ATP}$ 的 $\gamma$-磷酸基共价结合在酶蛋白的 $\mathrm{Ser}$、$\mathrm{Thr}$ 或 $\mathrm{Tyr}$ 残基的侧链羟基上。
:::

:::definition{label="去磷酸化"}
磷酸化的酶蛋白在磷蛋白磷酸酶催化下，磷酸酯键被水解而脱去磷酸基。
:::

:::note{label="图2-21 电子版缺失"}
教材图2-21 为酶的磷酸化和去磷酸化调节：蛋白质激酶把 $\mathrm{ATP}$ 的 $\gamma$-磷酸基转到 $\mathrm{Ser}$、$\mathrm{Thr}$ 或 $\mathrm{Tyr}$ 侧链羟基上；磷蛋白磷酸酶水解磷酸酯键而脱磷酸。数字切片 `p0079_02.png` 为 $0$ 字节，本节不引用该文件。正文仍按教材保留。
:::

:::keypoint{label="磷酸化这一笔只记三件事"}
- 催化剂：蛋白质激酶（加磷酸）、磷蛋白磷酸酶（脱磷酸）。
- 磷酸来源：$\mathrm{ATP}$ 的 $\gamma$-磷酸基。
- 落点：$\mathrm{Ser}$、$\mathrm{Thr}$ 或 $\mathrm{Tyr}$ 的侧链羟基，形成磷酸酯键。
:::

:::compare{title="别构调节与化学修饰调节"}
| 项目 | 别构调节 | 化学修饰（以磷酸化为例） |
|------|----------|--------------------------|
| 键的性质 | 可逆非共价 | 共价（磷酸酯键），可被磷酸酶水解，故仍可逆 |
| 结合部位 | 别构部位（非催化部位） | 特定 $\mathrm{Ser}/\mathrm{Thr}/\mathrm{Tyr}$ 侧链羟基 |
| 是否另要酶来催化这次调节 | 不需要；调节物自己结合 | 需要：蛋白质激酶、磷蛋白磷酸酶 |
| 构象 | 改变，从而改活性 | 同样引起构象变化，从而改活性 |
| 曲线 | 底物为正协同时呈 $\mathrm{S}$ 形 | 本节不画 $v$-$[\mathrm{S}]$ |
| 最常见形式 | 终产物、中间产物、底物等作调节物 | 磷酸化／去磷酸化（还有其他形式） |
:::

:::pitfall{label="共价修饰的“可逆”靠的是另一套酶，不是磷酸基自己掉下来"}
别构的可逆是调节物解离。磷酸化的可逆是磷蛋白磷酸酶把磷酸酯键水解掉。不要把“共价”听成“一旦接上就永远改不回来”——那是下一小节酶原激活切肽的账。也不要把 $\mathrm{Tyr}$ 漏掉：教材写的是 $\mathrm{Ser}$、$\mathrm{Thr}$ 或 $\mathrm{Tyr}$ 三种羟基。
:::

:::insight{label="化学修饰有多种形式，考试第一反应仍是磷酸化"}
教材先说“有多种形式”，紧接着写“最常见的形式是磷酸化和去磷酸化”。乙酰化、甲基化等可以出现在蛋白质翻译后修饰里（第一章），但本节酶活性快速调节的样板是激酶／磷酸酶这一对。
:::

### （三）酶原需要通过激活过程才能转变为有活性的酶

有些酶在细胞内合成或初分泌，或在其发挥催化功能前处于无活性状态，这种无活性的酶的前体称作酶原（zymogen）。在一定条件下，酶原向有催化活性的酶的转变过程称为酶原的激活。酶原的激活大多是经过蛋白酶的水解作用，去除一个或几个肽段后，导致分子构象改变，从而表现出催化活性。酶原激活的实质是酶的活性中心形成或暴露。例如，胰蛋白酶原进入小肠后，在 $\mathrm{Ca}^{2+}$ 存在下受肠激酶的作用，第 $6$ 位赖氨酸残基与第 $7$ 位异亮氨酸残基之间的肽键断裂，水解掉一个六肽，分子构象发生改变，形成酶的活性中心，从而成为有催化活性的胰蛋白酶（图2-22）。

:::definition{label="酶原"}
有些酶在细胞内合成或初分泌，或在其发挥催化功能前处于无活性状态，这种无活性的酶的前体称作酶原（zymogen）。
:::

:::definition{label="酶原的激活"}
在一定条件下，酶原向有催化活性的酶的转变过程称为酶原的激活。大多经过蛋白酶水解，去除一个或几个肽段，分子构象改变，从而表现出催化活性。
:::

:::definition{label="酶原激活的实质"}
酶原激活的实质是酶的活性中心形成或暴露。
:::

:::example{label="胰蛋白酶原怎样变成胰蛋白酶"}

| 胃蛋白酶原 | $\mathrm{H}^{+}$ 或胃蛋白酶 | 胃蛋白酶 $+$ 六肽 | 胃腔 |
| 胰凝乳蛋白酶原 | 胰蛋白酶 | 胰凝乳蛋白酶 $+$ 两个二肽 | 小肠腔 |
| 弹性蛋白酶原 | 胰蛋白酶 | 弹性蛋白酶 $+$ 几个肽段 | 小肠腔 |
| 羧基肽酶原A | 胰蛋白酶 | 羧基肽酶A $+$ 几个肽段 | 小肠腔 |

:::compare{title="几种消化道酶原怎么被激活"}
| 酶原 | 谁来切 | 切掉什么 | 在哪激活 |
|------|--------|----------|----------|
| 胰蛋白酶原 | 肠激酶（$\mathrm{Ca}^{2+}$ 存在下）；胰蛋白酶自身也可切 | 一个六肽（第 $6$–$7$ 位之间） | 小肠 |

酶原的存在和酶原激活具有重要的生理意义。消化道蛋白酶以酶原形式分泌可避免胰腺的自身消化和细胞外基质蛋白遭受蛋白酶的水解破坏，同时还能保证酶在特定环境和部位发挥其催化作用。生理情况下，血管内的凝血因子以酶原形式存在，不发生血液凝固，可保证血流畅通。一旦血管破损，一系列凝血因子被激活，凝血酶原被激活生成凝血酶，后者催化纤维蛋白原转变成纤维蛋白，产生血凝块以阻止大量失血，对机体起保护作用。

:::definition{label="酶原存在的生理意义"}
消化道蛋白酶以酶原形式分泌，可避免胰腺自身消化和细胞外基质蛋白被水解破坏，并保证酶在特定环境和部位才发挥催化作用。血管内凝血因子以酶原形式存在，则避免正常时血液凝固，保证血流畅通。
:::

:::cause-effect{title="胰蛋白酶原激活怎样带动下游消化酶原"}
- **因** 肠激酶在 $\mathrm{Ca}^{2+}$ 存在下切掉胰蛋白酶原的六肽，活性中心形成，生成胰蛋白酶；胰蛋白酶还可再激活胰蛋白酶原
- **果** 胰蛋白酶作为共同的激活因素，把胰凝乳蛋白酶原、弹性蛋白酶原、羧基肽酶原A 依次切开，在小肠腔形成消化蛋白质的级联
:::

:::timeline{period="血管破损后的凝血酶原激活级联"}
- **生理** 血管内凝血因子以酶原形式存在，不发生血液凝固，血流畅通
- **破损** 一系列凝血因子被激活
- **凝血酶原** 被激活生成凝血酶
- **纤维蛋白原** 在凝血酶催化下转变成纤维蛋白
- **结局** 产生血凝块，阻止大量失血，对机体起保护作用
:::

:::insight{label="级联的要点是“一分子激活一串”"}
消化侧：肠激酶激活胰蛋白酶原，胰蛋白酶再激活多种下游酶原。凝血侧：一系列凝血因子被激活，最后凝血酶原 → 凝血酶 → 纤维蛋白。两套都是酶原激活的级联，不是别构，也不是磷酸化。把“级联”听成 $\mathrm{S}$ 形曲线上的协同，户头就错了。
:::

:::compare{title="三种改现有酶分子的方式"}
| 项目 | 别构 | 磷酸化／去磷酸化 | 酶原激活 |
|------|------|------------------|----------|
| 化学本质 | 可逆非共价结合 | 共价接上或水解掉磷酸基 | 水解掉一个或几个肽段 |
| 是否要另一酶来完成这次改变 | 否 | 是（激酶、磷酸酶） | 是（肠激酶、胰蛋白酶等） |
| 可否再变回去 | 调节物解离即恢复 | 磷酸酶脱磷酸即恢复 | 肽段已经切掉，活性中心形成或暴露，按教材不写成可逆循环 |
| 生理样板 | 代谢途径终产物、中间产物、底物 | $\mathrm{Ser}/\mathrm{Thr}/\mathrm{Tyr}$ 磷酸化 | 胰蛋白酶原；凝血因子 |
:::

:::pitfall{label="酶原激活的实质不是“酶量增加”，而是活性中心形成或暴露"}
切掉六肽之后，分子数没有变多，变的是构象，让活性中心形成或暴露。下游级联才会让“有活性的酶”在短时间内增多。把酶原激活听成诱导合成，缓慢调节那一节会没有对立面。急性胰腺炎时胰蛋白酶原在胰腺中被提前激活（第六节），正是这套保护机制被打破。
:::

## 二、酶含量的调节是对酶促反应速率的缓慢调节

酶是机体的组成成分，各种酶都处于不断合成与降解的动态平衡过程中。因此，除改变酶的活性外，细胞也可通过改变酶蛋白合成与降解的速率来调节酶的含量，进而影响酶促反应速率。

:::definition{label="酶含量的缓慢调节"}
各种酶都处于不断合成与降解的动态平衡中。细胞通过改变酶蛋白合成与降解的速率来调节酶的含量，进而影响酶促反应速率。与酶活性调节相比，这是缓慢调节。
:::

:::concept{term="先问合成加快了还是降解加快了"}
含量 $=$ 合成与降解的差额。诱导、阻遏走转录水平，改的是合成；溶酶体途径和泛素途径改的是降解。只说“酶多了”而不问是诱导出来的还是没被拆掉的，半衰期那一笔会没有用处。
:::

### （一）酶蛋白合成可被诱导或阻遏

某些底物、产物、激素、生长因子及某些药物等可以在转录水平上影响酶蛋白的生物合成。一般在转录水平上能促进酶合成的物质称之为诱导物（inducer），诱导物诱发酶蛋白合成的作用称为诱导作用（induction）。反之，在转录水平上能减少酶蛋白合成的物质称为辅阻遏物（co-repressor），辅阻遏物与无活性的阻遏蛋白结合而影响基因的转录，这种作用称为阻遏作用（repression）。酶基因被诱导表达后，尚需经过转录水平和翻译水平的加工修饰才能发挥效应，一般需要几小时以上。但是，一旦酶被诱导合成后，即使去除诱导因素，酶的活性仍然持续存在，直到该酶被降解或抑制。因此，与酶活性的调节相比，酶合成的诱导与阻遏是一种缓慢而长效的调节。例如，胰岛素可诱导合成 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶，促进体内胆固醇合成，而胆固醇则阻遏 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶的合成；糖皮质激素可诱导磷酸烯醇式丙酮酸羧激酶的合成，促进糖异生。镇静催眠类药物苯巴比妥可诱导肝微粒体单加氧酶合成。

:::definition{label="诱导物与诱导作用"}
在转录水平上能促进酶合成的物质称为诱导物（inducer）。诱导物诱发酶蛋白合成的作用称为诱导作用（induction）。底物、产物、激素、生长因子及某些药物等都可在转录水平影响酶蛋白的生物合成。
:::

:::definition{label="辅阻遏物与阻遏作用"}
在转录水平上能减少酶蛋白合成的物质称为辅阻遏物（co-repressor）。辅阻遏物与无活性的阻遏蛋白结合而影响基因的转录，这种作用称为阻遏作用（repression）。
:::

:::definition{label="缓慢而长效"}
酶基因被诱导表达后，尚需经过转录水平和翻译水平的加工修饰才能发挥效应，一般需要几小时以上。一旦酶被诱导合成，即使去除诱导因素，酶的活性仍然持续存在，直到该酶被降解或抑制。故与酶活性调节相比，诱导与阻遏是缓慢而长效的调节。
:::

:::example{label="教材写的三组诱导／阻遏"}
- 胰岛素诱导 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶合成，促进胆固醇合成；胆固醇则阻遏该酶的合成。
- 糖皮质激素诱导磷酸烯醇式丙酮酸羧激酶合成，促进糖异生。
- 镇静催眠药苯巴比妥诱导肝微粒体单加氧酶合成。
:::

:::compare{title="诱导与阻遏"}
| 项目 | 诱导 | 阻遏 |
|------|------|------|
| 转录水平的效果 | 促进酶蛋白合成 | 减少酶蛋白合成 |
| 关键分子 | 诱导物（inducer） | 辅阻遏物（co-repressor）与无活性的阻遏蛋白结合 |
| 教材例子 | 胰岛素 → $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶；糖皮质激素 → 磷酸烯醇式丙酮酸羧激酶；苯巴比妥 → 肝微粒体单加氧酶 | 胆固醇阻遏 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶 |
| 时间 | 一般需几小时以上才发挥效应 | 同样走转录，不是瞬时 |
| 去除信号后 | 已合成的酶仍在，直到被降解或抑制 | 合成减少；已有酶分子仍按自身半衰期消失 |
:::

:::cause-effect{title="为什么说诱导是长效而不是快调"}
- **因** 从基因诱导到成熟酶，要经过转录水平和翻译水平的加工修饰，一般需几小时以上；合成之后即使撤走诱导物，酶分子还在
- **果** 酶促反应速率的这一改变来得慢、去得也慢，教材把它和别构、磷酸化的快速调节对起来写
:::

:::pitfall{label="辅阻遏物不是自己去当抑制剂，而是绑住阻遏蛋白改转录"}
阻遏作用发生在转录水平：辅阻遏物与无活性的阻遏蛋白结合，影响基因转录。不要把它写成别构抑制剂或竞争性抑制剂。胆固醇阻遏 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶合成，和洛伐他汀竞争性抑制该酶活性（第六节），是两本账。
:::

### （二）酶的降解与一般蛋白质降解途径相同

细胞内各种酶的半衰期相差很大。如鸟氨酸脱羧酶的半衰期很短，仅 $30$ 分钟，而乳酸脱氢酶的半衰期可长达 $130$ 小时。组织蛋白的降解途径有：①组织蛋白降解的溶酶体途径（非 $\mathrm{ATP}$ 依赖性蛋白质降解途径），由溶酶体内的组织蛋白酶非选择性催化分解一些膜结合蛋白、长半衰期蛋白和细胞外的蛋白；②组织蛋白降解的胞质途径（$\mathrm{ATP}$ 依赖性泛素介导的蛋白质降解途径），主要降解异常或损伤的蛋白质，以及几乎所有短半衰期（$10$ 分钟至 $2$ 小时）的蛋白质。

:::definition{label="酶的半衰期可以差两个数量级"}
鸟氨酸脱羧酶半衰期仅 $30$ 分钟，乳酸脱氢酶可长达 $130$ 小时。含量调节必须把降解这条腿写上，不能只写诱导。
:::

:::definition{label="溶酶体降解途径"}
组织蛋白降解的溶酶体途径是非 $\mathrm{ATP}$ 依赖性蛋白质降解途径。由溶酶体内的组织蛋白酶非选择性催化分解一些膜结合蛋白、长半衰期蛋白和细胞外的蛋白。
:::

:::definition{label="胞质泛素降解途径"}
组织蛋白降解的胞质途径是 $\mathrm{ATP}$ 依赖性、泛素介导的蛋白质降解途径。主要降解异常或损伤的蛋白质，以及几乎所有短半衰期（$10$ 分钟至 $2$ 小时）的蛋白质。
:::

:::compare{title="两条蛋白质降解途径"}
| 项目 | 溶酶体途径 | 胞质途径 |
|------|------------|----------|
| 是否依赖 $\mathrm{ATP}$ | 非 $\mathrm{ATP}$ 依赖 | $\mathrm{ATP}$ 依赖 |
| 标记 | 不走泛素 | 泛素介导 |
| 催化者 | 溶酶体内的组织蛋白酶 | 胞质中的蛋白酶体系统（教材称胞质途径） |
| 选择性 | 非选择性 | 针对异常或损伤蛋白，以及短半衰期蛋白 |
| 底物类型 | 膜结合蛋白、长半衰期蛋白、细胞外蛋白 | 几乎所有短半衰期（$10$ 分钟至 $2$ 小时）的蛋白质 |
| 与本节例子 | 乳酸脱氢酶这类长半衰期酶更靠近这一侧 | 鸟氨酸脱羧酶（$30$ 分钟）落在短半衰期一侧 |
:::

:::pitfall{label="短半衰期不等于溶酶体快，教材把短半衰期写在泛素途径上"}
$10$ 分钟至 $2$ 小时的短半衰期蛋白，教材明确写在 $\mathrm{ATP}$ 依赖性泛素介导的胞质途径。溶酶体那边是膜结合、长半衰期和细胞外蛋白。把鸟氨酸脱羧酶默写成“被溶酶体非选择性吃掉”，两条途径会对调。
:::

:::keypoint{label="本节调节方式收口"}
- 快速、改活性：别构（非共价、协同、$\mathrm{S}$ 形）、化学修饰（磷酸化最常见）。
- 快速、改现有分子是否有活性：酶原激活（切肽，活性中心形成或暴露；消化与凝血都是级联）。
- 缓慢、改含量：转录水平的诱导与阻遏（几小时以上、长效）；降解走溶酶体或泛素两条路。
- 代谢调节的落点：限速酶／关键酶（第十章）。
:::

:::memory{label="本节必背要点"}
- [ ] 细胞主要通过调节限速酶（关键酶）的活性来调整代谢（见第十章）。
- [ ] 快速调节：别构调节、化学修饰调节（改现有酶活性）。
- [ ] 别构：非催化部位可逆非共价结合 → 构象改变 → 活性改变；曾称变构。
- [ ] 别构调节物：终产物、中间产物、底物或其他物质；部位叫别构部位。
- [ ] 别构激活剂增强活性，别构抑制剂抑制活性。
- [ ] 别构酶常含多个（偶数）亚基，有正协同与负协同。
- [ ] 正协同：一亚基结合后相邻亚基亲和力增加；负协同则降低。
- [ ] 调节物是底物本身时，正协同的 $v$-$[\mathrm{S}]$ 呈 $\mathrm{S}$ 形（图2-20）。
- [ ] 别构激活剂使 $\mathrm{S}$ 形曲线左移，别构抑制剂使曲线右移。
- [ ] 化学修饰＝共价修饰；最常见为磷酸化／去磷酸化。
- [ ] 蛋白质激酶：$\mathrm{ATP}$ 的 $\gamma$-磷酸基接到 $\mathrm{Ser}$、$\mathrm{Thr}$ 或 $\mathrm{Tyr}$ 侧链羟基。
- [ ] 磷蛋白磷酸酶水解磷酸酯键而脱磷酸。
- [ ] 酶原：无活性的酶前体；激活实质是活性中心形成或暴露。
- [ ] 胰蛋白酶原：小肠内、$\mathrm{Ca}^{2+}$、肠激酶，切第 $6$ 位赖氨酸与第 $7$ 位异亮氨酸之间，水解掉一个六肽。
- [ ] 胃蛋白酶原：$\mathrm{H}^{+}$ 或胃蛋白酶，胃腔，切掉六肽。
- [ ] 胰凝乳蛋白酶原、弹性蛋白酶原、羧基肽酶原A：均由胰蛋白酶在小肠腔激活。
- [ ] 酶原可避免胰腺自身消化，并保证在特定部位才有活性。
- [ ] 凝血因子以酶原存在保证血流畅通；破损后级联激活，凝血酶原 → 凝血酶 → 纤维蛋白。
- [ ] 缓慢调节：改变酶蛋白合成与降解的速率，从而改变含量。
- [ ] 诱导物在转录水平促进合成；辅阻遏物与阻遏蛋白结合而减少转录。
- [ ] 诱导需几小时以上；去除诱导因素后酶活性仍持续到被降解或抑制。
- [ ] 胰岛素诱导、胆固醇阻遏 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶；糖皮质激素诱导磷酸烯醇式丙酮酸羧激酶；苯巴比妥诱导肝微粒体单加氧酶。
- [ ] 鸟氨酸脱羧酶半衰期 $30$ 分钟，乳酸脱氢酶 $130$ 小时。
- [ ] 溶酶体途径：非 $\mathrm{ATP}$ 依赖，组织蛋白酶，膜结合／长半衰期／细胞外蛋白。
- [ ] 胞质途径：$\mathrm{ATP}$ 依赖、泛素介导；异常或损伤蛋白，以及短半衰期（$10$ 分钟至 $2$ 小时）蛋白。
:::
