# 第三节　甘油三酯代谢

第二节把食物脂质送进血循环：长链走乳糜微粒，短中链走门静脉。本节写体内甘油三酯的进出账。分解从白色脂肪动员开始，激素敏感性脂肪酶催化第二步而不是第一步；游离脂肪酸活化后经肉碱穿梭进线粒体，$\mathrm{CPT}$-$\mathrm{I}$ 限速，β-氧化四步生成乙酰 $\mathrm{CoA}$。肝把部分乙酰 $\mathrm{CoA}$ 做成酮体输给肝外，自己不能利用。合成侧：肝、脂肪组织和小肠用不同途径做成甘油三酯；内源性脂肪酸先在胞质溶胶合成软脂酸，乙酰 $\mathrm{CoA}$ 走柠檬酸-丙酮酸循环。本版 $1$ 分子软脂酸彻底氧化净生成 $106$ 分子 $\mathrm{ATP}$。

:::concept{term="先问动员三步是谁切，再问脂肪酸进没进线粒体"}
看见甘油三酯分解，先不要默写“$\mathrm{HSL}$ 水解第一步”。本版第一步是 $\mathrm{ATGL}$，第二步 $\mathrm{HSL}$ 切甘油二酯 $\mathrm{sn}$-$3$，第三步 $\mathrm{MGL}$。游离脂肪酸活化后，长链必须经肉碱穿梭，$\mathrm{CPT}$-Ⅰ是 β-氧化限速关键酶；基质里才是脱氢、加水、再脱氢、硫解。肝把部分乙酰 $\mathrm{CoA}$ 做成酮体输出，自己缺利用酶系。
:::

## 一、甘油三酯氧化分解产生大量 ATP

### （一）甘油三酯分解代谢从脂肪动员开始

脂肪动员（fat mobilization）指储存在白色脂肪细胞内的脂肪在脂肪酶作用下，逐步水解，释放游离脂肪酸和甘油供其他组织细胞氧化利用的过程（图8-1）。

:::definition{label="脂肪动员"}
脂肪动员（fat mobilization）是储存在白色脂肪细胞内的脂肪在脂肪酶作用下逐步水解，释放游离脂肪酸和甘油，供其他组织细胞氧化利用的过程。
:::

:::note{label="电子版缺失"}
教材第 $174$ 页图8-1　脂肪动员电子版图源 `p0174_01.png` 为 $0$ 字节，不嵌入 `src$。图注点名：AC 腺苷酸环化酶，ATGL 脂肪组织甘油三酯脂肪酶，ATP，cAMP，HSL 激素敏感性脂肪酶，MGL 甘油一酯脂肪酶，Gs 兴奋性 G 蛋白，PKA 蛋白激酶 A。正文以 ATGL、HSL、MGL 三步及激素级联为准。
:::

曾经认为，脂肪动员由激素敏感性甘油三酯脂肪酶（hormone-sensitive triglyceride lipase，$\mathrm{HSL}$）、也称激素敏感性脂肪酶（hormone sensitive lipase，$\mathrm{HSL}$）调控，$\mathrm{HSL}$ 催化甘油三酯水解的第一步，是脂肪动员的关键酶。但后来发现 $\mathrm{HSL}$ 并不主要催化甘油三酯水解的第一步，而是催化下面所描述的第二步反应。脂肪动员也还需多种酶和蛋白质参与，如脂肪组织甘油三酯脂肪酶（adipose triglyceride lipase，$\mathrm{ATGL}$）和 $\mathrm{Perilipin}$-$1$。

脂肪动员由多种内外刺激通过激素触发。当禁食、饥饿或交感神经兴奋时，肾上腺素、去甲肾上腺素、胰高血糖素等分泌增加，作用于白色脂肪细胞膜受体，激活腺苷酸环化酶，使腺苷酸环化成 $\mathrm{cAMP}$，激活 $\mathrm{cAMP}$ 依赖蛋白激酶，使胞质溶胶内脂滴包被蛋白-$1$（$\mathrm{Perilipin}$-$1$）和 $\mathrm{HSL}$ 磷酸化。磷酸化的 $\mathrm{Perilipin}$-$1$ 一方面激活 $\mathrm{ATGL}$，另一方面使因磷酸化而激活的 $\mathrm{HSL}$ 从胞质溶胶转移至脂滴表面。脂肪在脂肪细胞内分解的第一步主要由 $\mathrm{ATGL}$ 催化，生成 $1,3$-甘油二酯和 $2,3$-甘油二酯及脂肪酸。第二步主要由 $\mathrm{HSL}$ 催化，主要水解甘油二酯 $\mathrm{sn}$-$3$ 位酯键，生成甘油一酯和脂肪酸。最后，在甘油一酯脂肪酶（monoacylglycerol lipase，$\mathrm{MGL}$）的催化下，生成甘油和脂肪酸。所以，上述激素能够启动脂肪动员、促进脂肪水解为游离脂肪酸和甘油，称为脂解激素。而胰岛素、前列腺素 $\mathrm{E}_2$ 等能对抗脂解激素的作用，抑制脂肪动员，称为抗脂解激素。

游离脂肪酸不溶于水，不能直接在血浆中运输。血浆清蛋白具有结合游离脂肪酸的能力（每分子清蛋白可结合 $7$ 分子游离脂肪酸），能将脂肪酸运送至全身，主要由心、肝、骨骼肌等摄取利用。

:::definition{label="ATGL"}
脂肪组织甘油三酯脂肪酶（adipose triglyceride lipase，$\mathrm{ATGL}$）催化脂肪动员的第一步，水解甘油三酯，生成 $1,3$-甘油二酯和 $2,3$-甘油二酯及脂肪酸。磷酸化的 $\mathrm{Perilipin}$-$1$ 激活它。
:::

:::definition{label="HSL"}
激素敏感性脂肪酶（hormone sensitive lipase，$\mathrm{HSL}$；亦称激素敏感性甘油三酯脂肪酶）并不主要催化甘油三酯水解的第一步。它催化第二步：主要水解甘油二酯 $\mathrm{sn}$-$3$ 位酯键，生成甘油一酯和脂肪酸。$\mathrm{cAMP}$ 依赖蛋白激酶使之磷酸化后，由磷酸化的 $\mathrm{Perilipin}$-$1$ 帮助从胞质溶胶转到脂滴表面。
:::

:::definition{label="MGL"}
甘油一酯脂肪酶（monoacylglycerol lipase，$\mathrm{MGL}$）催化第三步，把甘油一酯水解成甘油和脂肪酸。
:::

:::definition{label="脂解激素与抗脂解激素"}
脂解激素能启动脂肪动员：禁食、饥饿或交感神经兴奋时，肾上腺素、去甲肾上腺素、胰高血糖素等。抗脂解激素对抗脂解、抑制动员：胰岛素、前列腺素 $\mathrm{E}_2$ 等。
:::

:::pitfall{label="HSL 不是第一步，也不是唯一的关键酶"}
旧说法把 $\mathrm{HSL}$ 写成甘油三酯水解第一步、脂肪动员关键酶。本版明确：第一步主要是 $\mathrm{ATGL}$，第二步才是 $\mathrm{HSL}$（切甘油二酯 $\mathrm{sn}$-$3$），第三步 $\mathrm{MGL}$；还要 $\mathrm{Perilipin}$-$1$。考试若仍默写“$\mathrm{HSL}$ 水解甘油三酯”，和本版对不上。
:::

:::timeline{period="白色脂肪动员三步"}
- **激素到膜** 肾上腺素、去甲肾上腺素、胰高血糖素 → 受体 → 腺苷酸环化酶 → cAMP → PKA
- **磷酸化** Perilipin-1 和 HSL 被磷酸化；磷酸化 Perilipin-1 激活 ATGL，并把活化的 HSL 转到脂滴表面
- **第一步 ATGL** 甘油三酯 → 1,3-甘油二酯和 2,3-甘油二酯 + 脂肪酸
- **第二步 HSL** 主要切甘油二酯 sn-3 → 甘油一酯 + 脂肪酸
- **第三步 MGL** 甘油一酯 → 甘油 + 脂肪酸
:::

:::insight{label="游离脂肪酸靠清蛋白捎带，不是自己溶在血浆里"}
第一节强调脂质不溶于水。动员出来的游离脂肪酸每分子清蛋白可结合 $7$ 分子，运到心、肝、骨骼肌。短中链在第二节可以走门静脉，那是消化吸收的另一本账，不要和动员出的长链游离脂肪酸并户。
:::

:::compare{title="脂解与抗脂解"}
| 项目 | 脂解激素 | 抗脂解激素 |
|------|----------|------------|
| 成员 | 肾上腺素、去甲肾上腺素、胰高血糖素 | 胰岛素、前列腺素 $\mathrm{E}_2$ |
| 场合 | 禁食、饥饿、交感神经兴奋 | 对抗脂解 |
| 级联印象 | 膜受体 → $\mathrm{cAMP}$ → $\mathrm{PKA}$ → $\mathrm{Perilipin}$-$1$／$\mathrm{HSL}$ 磷酸化 | 抑制脂肪动员 |
:::

### （二）甘油转变为甘油-3-磷酸后被利用

甘油可直接经血液运输至肝、肾、肠等组织利用。在甘油激酶（glycerokinase）作用下，甘油转变为甘油-3-磷酸；然后脱氢生成磷酸二羟丙酮，循糖代谢途径分解，或转变为葡萄糖。肝的甘油激酶活性最高，脂肪动员产生的甘油主要被肝摄取利用，而脂肪及骨骼肌因甘油激酶活性很低，对甘油的摄取利用很有限。

:::definition{label="甘油激酶"}
甘油激酶（glycerokinase）催化甘油磷酸化为甘油-3-磷酸，消耗 $\mathrm{ATP}$。肝活性最高；脂肪及骨骼肌活性很低。
:::

$$
\text{甘油}+\mathrm{ATP}\xrightarrow{\text{甘油激酶}}\text{甘油-3-磷酸}+\mathrm{ADP}
$$

$$
\text{甘油-3-磷酸}+\mathrm{NAD}^{+}\rightarrow\text{磷酸二羟丙酮}+\mathrm{NADH}+\mathrm{H}^{+}
$$

:::insight{label="甘油回糖代谢，脂肪酸才进 β-氧化"}
动员产物拆成两本账：甘油经甘油-3-磷酸、磷酸二羟丙酮进糖分解或糖异生；脂肪酸活化后进线粒体。肝把甘油这本账几乎包圆，脂肪细胞自己动员出的甘油很难就地再利用。
:::

:::pitfall{label="脂肪细胞甘油激酶很低"}
动员在白色脂肪里发生，甘油却主要被肝用。后面合成甘油三酯时，脂肪细胞也不能直接利用游离甘油，必须从糖酵解的磷酸二羟丙酮还原做甘油-3-磷酸。两处是同一酶活性低。
:::

### （三）β-氧化是脂肪酸分解的核心过程

除脑外，机体大多数组织均能氧化脂肪酸，以肝、心肌、骨骼肌能力最强。在 $\mathrm{O}_2$ 供充足时，脂肪酸可经脂肪酸活化、转移至线粒体内、β-氧化（$\beta$-oxidation）生成乙酰 $\mathrm{CoA}$ 及乙酰 $\mathrm{CoA}$ 进入三羧酸循环彻底氧化 $4$ 个阶段，释放大量 $\mathrm{ATP}$。

:::definition{label="脂肪酸氧化的四个阶段"}
$\mathrm{O}_2$ 充足时：①脂肪酸活化为脂肪酰 $\mathrm{CoA}$；②转移进入线粒体；③β-氧化生成乙酰 $\mathrm{CoA}$；④乙酰 $\mathrm{CoA}$ 进入三羧酸循环彻底氧化。除脑外大多数组织都能做，肝、心肌、骨骼肌最强。
:::

:::pitfall{label="脑不能氧化脂肪酸，但能用酮体"}
“除脑外”只限制脂肪酸 β-氧化。本节后面写：脑不能氧化分解脂肪酸，却能有效利用酮体。葡萄糖不足时，酮体是脑的主要能源。不要写成“脑既不能用脂肪酸也不能用酮体”。
:::

**1. 脂肪酸活化为脂肪酰 CoA**　脂肪酸被氧化前必须先活化，由内质网、线粒体外膜上的脂肪酰 $\mathrm{CoA}$ 合成酶（acyl-$\mathrm{CoA}$ synthetase）催化生成脂肪酰 $\mathrm{CoA}$，需 $\mathrm{ATP}$、$\mathrm{CoA}$-$\mathrm{SH}$ 及 $\mathrm{Mg}^{2+}$ 参与。

$$
\text{脂肪酸}+\mathrm{CoA\text{-}SH}+\mathrm{ATP}\xrightarrow[\mathrm{Mg}^{2+}]{\text{脂肪酰CoA合成酶}}\text{脂肪酰CoA}+\mathrm{AMP}+\mathrm{PP}_\mathrm{i}
$$

脂肪酰 $\mathrm{CoA}$ 含高能硫酯键，不仅可提高反应活性，还可增加脂肪酸的水溶性，因而提高脂肪酸代谢活性。活化反应生成的焦磷酸（$\mathrm{PP}_\mathrm{i}$）立即被细胞内焦磷酸酶水解，可阻止逆向反应进行，故 $1$ 分子脂肪酸活化实际上消耗 $2$ 个高能磷酸键。

$$
\mathrm{PP}_\mathrm{i}+\mathrm{H}_2\mathrm{O}\xrightarrow{\text{焦磷酸酶}}2\,\mathrm{P}_\mathrm{i}
$$

:::definition{label="脂肪酰 CoA 合成酶"}
脂肪酰 $\mathrm{CoA}$ 合成酶（acyl-$\mathrm{CoA}$ synthetase）位于内质网和线粒体外膜，催化脂肪酸 $+$ $\mathrm{CoA}$-$\mathrm{SH}$ $+$ $\mathrm{ATP}$ 生成脂肪酰 $\mathrm{CoA}$、$\mathrm{AMP}$ 和 $\mathrm{PP}_\mathrm{i}$，需 $\mathrm{Mg}^{2+}$。
:::

:::keypoint{label="活化消耗 2 个高能磷酸键"}
- $\mathrm{ATP}\rightarrow\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$，已经相当于花掉 $2$ 个高能磷酸键的计量位置之一。
- $\mathrm{PP}_\mathrm{i}$ 立即被焦磷酸酶水解，阻止逆行，把这一笔钉死。
- 后面软脂酸净 $\mathrm{ATP}$ 要从毛产额里减 $2$。
:::

:::insight{label="硫酯键既提高反应活性，又增加水溶性"}
游离脂肪酸疏水。做成脂肪酰 $\mathrm{CoA}$ 才好代谢。不要只记“活化要 $\mathrm{ATP}$”，漏掉水溶性这一笔。
:::

**2. 脂肪酰 CoA 进入线粒体**　催化脂肪酸氧化的酶系存在于线粒体基质，活化的脂肪酰 $\mathrm{CoA}$ 必须进入线粒体才能被氧化。长链脂肪酰 $\mathrm{CoA}$ 不能直接透过线粒体内膜，需要经肉碱穿梭途径（carnitine shuttle），由肉碱（carnitine，或称 $\mathrm{L}$-$\beta$ 羟-$\gamma$-三甲氨基丁酸）协助其转运。存在于线粒体外膜的肉碱脂肪酰转移酶Ⅰ（carnitine acyl transferase Ⅰ）催化长链脂肪酰 $\mathrm{CoA}$ 与肉碱合成脂肪酰肉碱（acyl carnitine），后者在线粒体内膜肉碱-脂肪酰肉碱转位酶（carnitine-acylcarnitine translocase）作用下，通过内膜进入线粒体基质，同时将等分子肉碱转运出线粒体。进入线粒体的脂肪酰肉碱，在线粒体内膜内侧肉碱脂肪酰转移酶Ⅱ作用下，转变为脂肪酰 $\mathrm{CoA}$ 并释出肉碱（图8-2）。

脂肪酰 $\mathrm{CoA}$ 进入线粒体是脂肪酸 β-氧化的限速步骤，肉碱脂肪酰转移酶Ⅰ是脂肪酸 β-氧化的关键酶。当饥饿、高脂低糖膳食或糖尿病时，机体没有充足的糖供应，或不能有效利用糖，需脂肪酸供能，肉碱脂肪酰转移酶Ⅰ活性增加，脂肪酸氧化增强。相反，饱食后脂肪酸合成加强，丙二酸单酰 $\mathrm{CoA}$ 含量增加，抑制肉碱脂肪酰转移酶Ⅰ活性，使脂肪酸的氧化被抑制。

教材第 $175$ 页图8-2　脂肪酰 $\mathrm{CoA}$ 进入线粒体的机制电子版图源 `p0175_01.png` 为 $0$ 字节，不嵌入 `src`。正文以线粒体外膜 $\mathrm{CPT}$-Ⅰ、内膜转位酶、内膜内侧 $\mathrm{CPT}$-Ⅱ三件套为准。图8-3 画面中线粒体内膜处标有带圈的肉碱转运载体，可与此对照。
:::

:::definition{label="肉碱"}
肉碱（carnitine）即 $\mathrm{L}$-$\beta$ 羟-$\gamma$-三甲氨基丁酸，协助长链脂肪酰 $\mathrm{CoA}$ 经肉碱穿梭进入线粒体。
:::

:::definition{label="肉碱脂肪酰转移酶Ⅰ"}
肉碱脂肪酰转移酶Ⅰ（carnitine acyl transferase Ⅰ，$\mathrm{CPT}$-Ⅰ）位于线粒体外膜，催化长链脂肪酰 $\mathrm{CoA}$ 与肉碱合成脂肪酰肉碱。它是脂肪酸 β-氧化的关键酶；脂肪酰 $\mathrm{CoA}$ 进入线粒体是 β-氧化的限速步骤。丙二酸单酰 $\mathrm{CoA}$ 抑制它。
:::

:::definition{label="肉碱穿梭"}
长链脂肪酰 $\mathrm{CoA}$ 不能直接透过线粒体内膜。$\mathrm{CPT}$-Ⅰ（外膜）做成脂肪酰肉碱；肉碱-脂肪酰肉碱转位酶把脂肪酰肉碱运入基质、等分子肉碱运出；内膜内侧肉碱脂肪酰转移酶Ⅱ再把脂肪酰肉碱变回脂肪酰 $\mathrm{CoA}$，释出肉碱。
:::

:::timeline{period="肉碱穿梭"}
- **外膜 CPT-I** 长链脂肪酰 CoA + 肉碱 → 脂肪酰肉碱
- **转位酶** 脂肪酰肉碱进基质，等分子肉碱出线粒体
- **内膜内侧 CPT-II** 脂肪酰肉碱 → 脂肪酰 CoA + 肉碱
:::

:::compare{title="饥饿开 CPT-I，饱食关 CPT-I"}
| 状态 | $\mathrm{CPT}$-Ⅰ | 脂肪酸氧化 |
|------|-----------------|------------|
| 饥饿、高脂低糖膳食、糖尿病 | 活性增加（糖不足或不能有效利用，需脂肪酸供能） | 增强 |
| 饱食 | 脂肪酸合成加强，丙二酸单酰 $\mathrm{CoA}$ 增多，抑制 $\mathrm{CPT}$-Ⅰ | 被抑制 |
:::

:::pitfall{label="限速的是进线粒体，关键酶是 CPT-I，不是 β-氧化四步里的某一个"}
β-氧化四步在基质里循环缩短碳链。门在膜上：$\mathrm{CPT}$-Ⅰ。把“限速”安到脂肪酰 $\mathrm{CoA}$ 脱氢酶上，丙二酸单酰 $\mathrm{CoA}$ 抑制这一笔就没有落点。
:::

**3. 脂肪酰 CoA 分解产生乙酰 CoA、FADH2 和 NADH**　线粒体基质中存在由多个酶结合在一起形成的脂肪酸 β-氧化酶系，在该酶系多个酶顺序催化下，从脂肪酰基 β-碳原子开始，进行脱氢、加水、再脱氢及硫解四步反应（图8-3），完成一次 β-氧化。

::figure{src="/images/biochemistry/textbook/p0176_01.png" caption="图8-3　脂肪酸的 β-氧化。上方：脂肪酸经脂肪酰 CoA 合成酶（ATP、CoASH → AMP、PPi）活化为脂肪酰 CoA，再经线粒体内膜上带圈的肉碱转运载体进入基质。基质内四步循环：①脂肪酰 CoA 脱氢酶（FAD → FADH2，呼吸链 1.5 ATP）生成反式-Δ²-烯脂肪酰 CoA；②烯酰 CoA 水化酶加水生成 L-β-羟脂肪酰 CoA；③β-羟脂肪酰 CoA 脱氢酶（NAD⁺ → NADH+H⁺，呼吸链 2.5 ATP）生成 β-酮脂肪酰 CoA；④酮脂肪酰 CoA 硫解酶加 CoASH，生成少两个碳的脂肪酰 CoA（回接到循环）和乙酰 CoA。乙酰 CoA 进入三羧酸循环，产 2 CO2、4 H2O、10 ATP。" alt="脂肪酸活化后经肉碱载体进入线粒体，β-氧化四步脱氢、加水、再脱氢、硫解，乙酰 CoA 进入三羧酸循环"}

（1）脱氢生成烯脂肪酰 $\mathrm{CoA}$：脂肪酰 $\mathrm{CoA}$ 在脂肪酰 $\mathrm{CoA}$ 脱氢酶（acyl $\mathrm{CoA}$ dehydrogenase）催化下，从 $\alpha$、$\beta$ 碳原子各脱下一个氢原子，由 $\mathrm{FAD}$ 接受生成 $\mathrm{FADH}_2$，同时生成反式-$\Delta^{2}$-烯脂肪酰 $\mathrm{CoA}$。

（2）加水生成羟脂肪酰 $\mathrm{CoA}$：反式-$\Delta^{2}$-烯脂肪酰 $\mathrm{CoA}$ 在烯脂肪酰 $\mathrm{CoA}$ 水化酶（enoyl $\mathrm{CoA}$ hydratase）催化下，加水生成 $\mathrm{L}$-$\beta$-羟脂肪酰 $\mathrm{CoA}$。

（3）再脱氢生成 $\beta$-酮脂肪酰 $\mathrm{CoA}$：$\mathrm{L}$-$\beta$-羟脂肪酰 $\mathrm{CoA}$ 在 $\beta$-羟脂肪酰 $\mathrm{CoA}$ 脱氢酶（$\beta$-hydroxyacyl $\mathrm{CoA}$ dehydrogenase）催化下，脱下 $2\mathrm{H}$，由 $\mathrm{NAD}^{+}$ 接受生成 $\mathrm{NADH}$，同时生成 $\beta$-酮脂肪酰 $\mathrm{CoA}$。

（4）硫解产生乙酰 $\mathrm{CoA}$：$\beta$-酮脂肪酰 $\mathrm{CoA}$ 在酮脂肪酰 $\mathrm{CoA}$ 硫解酶（ketoacyl-$\mathrm{CoA}$-thiolase）催化下，加 $\mathrm{CoASH}$ 使碳链在 $\beta$ 位断裂，生成 $1$ 分子乙酰 $\mathrm{CoA}$ 和少 $2$ 个碳原子的脂肪酰 $\mathrm{CoA}$。

经过上述四步反应，脂肪酰 $\mathrm{CoA}$ 的碳链被缩短 $2$ 个碳原子。脱氢、加水、再脱氢及硫解反复进行，最终完成脂肪酸 β-氧化。生成的 $\mathrm{FADH}_2$、$\mathrm{NADH}$ 经呼吸链氧化，与 $\mathrm{ADP}$ 磷酸化偶联，产生 $\mathrm{ATP}$。生成的乙酰 $\mathrm{CoA}$ 主要在线粒体通过三羧酸循环彻底氧化；在肝，部分乙酰 $\mathrm{CoA}$ 转变成酮体，通过血液运送至肝外组织氧化利用。

:::definition{label="β-氧化"}
β-氧化（$\beta$-oxidation）在线粒体基质，从脂肪酰基 β-碳原子开始，按脱氢、加水、再脱氢、硫解四步，每次使碳链缩短 $2$ 个碳，放出 $1$ 分子乙酰 $\mathrm{CoA}$、$1$ 分子 $\mathrm{FADH}_2$ 和 $1$ 分子 $\mathrm{NADH}$。
:::

:::timeline{period="一次 β-氧化四步"}
- **脱氢** 脂肪酰 CoA 脱氢酶，FAD 受氢，得反式-Δ2-烯脂肪酰 CoA
- **加水** 烯脂肪酰 CoA 水化酶，得 L-β-羟脂肪酰 CoA
- **再脱氢** β-羟脂肪酰 CoA 脱氢酶，NAD+ 受氢，得 β-酮脂肪酰 CoA
- **硫解** 酮脂肪酰 CoA 硫解酶加 CoASH，得乙酰 CoA 和少两个碳的脂肪酰 CoA
:::

:::compare{title="β-氧化四步的辅因子与产物"}
| 步 | 酶 | 辅因子／加入物 | 产物 |
|----|----|----------------|------|
| ①脱氢 | 脂肪酰 $\mathrm{CoA}$ 脱氢酶 | $\mathrm{FAD}\rightarrow\mathrm{FADH}_2$（呼吸链 $1.5\,\mathrm{ATP}$） | 反式-$\Delta^{2}$-烯脂肪酰 $\mathrm{CoA}$ |
| ②加水 | 烯脂肪酰 $\mathrm{CoA}$ 水化酶 | $\mathrm{H}_2\mathrm{O}$ | $\mathrm{L}$-$\beta$-羟脂肪酰 $\mathrm{CoA}$ |
| ③再脱氢 | $\beta$-羟脂肪酰 $\mathrm{CoA}$ 脱氢酶 | $\mathrm{NAD}^{+}\rightarrow\mathrm{NADH}$（呼吸链 $2.5\,\mathrm{ATP}$） | $\beta$-酮脂肪酰 $\mathrm{CoA}$ |
| ④硫解 | 酮脂肪酰 $\mathrm{CoA}$ 硫解酶 | $\mathrm{CoASH}$ | 乙酰 $\mathrm{CoA}$ $+$ 缩短 $2$ 碳的脂肪酰 $\mathrm{CoA}$ |
:::

:::pitfall{label="烯中间体是反式-Δ2，不是天然顺式双键"}
饱和脂肪酸 β-氧化做出的是反式-$\Delta^{2}$-烯脂肪酰 $\mathrm{CoA}$。天然不饱和脂肪酸的双键是顺式，后面要异构酶或表异构酶才能续上四步。把“脱氢就得到天然双键”听成一回事，不饱和脂肪酸那一小节会没有户头。
:::

**4. 脂肪酸氧化是机体 ATP 的重要来源**　脂肪酸彻底氧化生成大量 $\mathrm{ATP}$。以软脂酸为例，$1$ 分子软脂酸彻底氧化需进行 $7$ 次 β-氧化，生成 $7$ 分子 $\mathrm{FADH}_2$、$7$ 分子 $\mathrm{NADH}$ 及 $8$ 分子乙酰 $\mathrm{CoA}$。在 $\mathrm{pH}\,7.0$，$25^{\circ}\mathrm{C}$ 的标准条件下氧化磷酸化，每分子 $\mathrm{FADH}_2$ 产生 $1.5$ 分子 $\mathrm{ATP}$，每分子 $\mathrm{NADH}$ 产生 $2.5$ 分子 $\mathrm{ATP}$；每分子乙酰 $\mathrm{CoA}$ 经三羧酸循环彻底氧化产生 $10$ 分子 $\mathrm{ATP}$。因此 $1$ 分子软脂酸彻底氧化共生成 $(7\times 1.5)+(7\times 2.5)+(8\times 10)=108$ 分子 $\mathrm{ATP}$。因为脂肪酸活化消耗 $2$ 个高能磷酸键，相当于 $2$ 分子 $\mathrm{ATP}$，所以 $1$ 分子软脂酸彻底氧化净生成 $106$ 分子 $\mathrm{ATP}$。

:::derivation{title="1 分子软脂酸净 106 分子 ATP（本版）"}
1. 软脂酸 $16$ 碳，每次切 $2$ 碳，需 $7$ 次 β-氧化，得 $8$ 分子乙酰 $\mathrm{CoA}$。
2. $7\,\mathrm{FADH}_2\times 1.5=10.5$
3. $7\,\mathrm{NADH}\times 2.5=17.5$
4. $8$ 乙酰 $\mathrm{CoA}\times 10=80$
5. 毛产额 $10.5+17.5+80=108$
6. 活化 $\mathrm{ATP}\rightarrow\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$ 且 $\mathrm{PP}_\mathrm{i}$ 水解，减 $2$
7. 净得 $106$
:::

:::pitfall{label="本版是 106，不要默写成 129 或 131"}
$\mathrm{NADH}$ 按 $2.5$、$\mathrm{FADH}_2$ 按 $1.5$、乙酰 $\mathrm{CoA}$ 按 $10$ 计，与第七章有氧氧化同一套标准条件。旧口诀 $3$ 和 $2$、毛产 $131$ 再减 $2$ 得 $129$，与本版 $108-2=106$ 对不上。图8-3 也把呼吸链标成 $1.5$／$2.5$、三羧酸循环标成 $10\,\mathrm{ATP}$。
:::

:::keypoint{label="软脂酸账怎么记"}
- 次数：碳数 $/2-1=7$ 次 β-氧化；$8$ 个乙酰 $\mathrm{CoA}$。
- 每次 β-氧化：$1\,\mathrm{FADH}_2+1\,\mathrm{NADH}$。
- 活化永远减 $2$，与碳链长度无关。
:::

### （四）不同的脂肪酸还有不同的氧化方式

**1. 不饱和脂肪酸 β-氧化需转变构型**　不饱和脂肪酸也在线粒体进行 β-氧化。不同的是，饱和脂肪酸 β-氧化产生的烯脂肪酰 $\mathrm{CoA}$ 是反式-$\Delta^{2}$ 烯脂肪酰 $\mathrm{CoA}$，而天然不饱和脂肪酸中的双键为顺式。因双键位置不同，不饱和脂肪酸 β-氧化产生的顺式 $\Delta^{3}$ 烯脂肪酰 $\mathrm{CoA}$ 或顺式 $\Delta^{2}$ 烯脂肪酰 $\mathrm{CoA}$ 不能继续 β-氧化。顺式 $\Delta^{3}$ 烯脂肪酰 $\mathrm{CoA}$ 在线粒体特异 $\Delta^{3}$ 顺 $\rightarrow\Delta^{2}$ 反烯脂肪酰 $\mathrm{CoA}$ 异构酶（$\Delta^{3}$-cis $\rightarrow\Delta^{2}$-trans enoyl-$\mathrm{CoA}$ isomerase）催化下转变为 β-氧化酶系能识别的 $\Delta^{2}$ 反式构型，继续 β-氧化。顺式 $\Delta^{2}$ 烯脂肪酰 $\mathrm{CoA}$ 虽然也能水化，但形成的 $\mathrm{D}(-)$-$\beta$-羟脂肪酰 $\mathrm{CoA}$ 不能被线粒体 β-氧化酶系识别。在 $\mathrm{D}(-)$-$\beta$-羟脂肪酰 $\mathrm{CoA}$ 表异构酶（epimerase，又称差向异构酶）催化下，右旋异构体［$\mathrm{D}(-)$ 型］转变为 β-氧化酶系能识别的左旋异构体［$\mathrm{L}(+)$ 型］，继续 β-氧化。

:::definition{label="Δ3 顺→Δ2 反异构酶"}
线粒体特异 $\Delta^{3}$-cis $\rightarrow\Delta^{2}$-trans enoyl-$\mathrm{CoA}$ isomerase 把顺式 $\Delta^{3}$ 烯脂肪酰 $\mathrm{CoA}$ 变成反式 $\Delta^{2}$，供 β-氧化酶系识别。
:::

:::definition{label="D(-)-β-羟脂肪酰 CoA 表异构酶"}
表异构酶（epimerase，差向异构酶）把顺式 $\Delta^{2}$ 水化得到的 $\mathrm{D}(-)$-$\beta$-羟脂肪酰 $\mathrm{CoA}$ 转为 $\mathrm{L}(+)$ 型。β-氧化酶系只认 $\mathrm{L}$ 型。
:::

:::compare{title="不饱和脂肪酸两条补丁"}
| 碰到的中间体 | 问题 | 补丁 |
|--------------|------|------|
| 顺式 $\Delta^{3}$ 烯脂肪酰 $\mathrm{CoA}$ | 酶系不认 | 异构酶 → 反式 $\Delta^{2}$ |
| 顺式 $\Delta^{2}$ 烯脂肪酰 $\mathrm{CoA}$ | 能水化，但得到 $\mathrm{D}(-)$ | 表异构酶 $\mathrm{D}(-)\rightarrow\mathrm{L}(+)$ |
:::

**2. 超长碳链脂肪酸需先在过氧化酶体氧化成较短碳链脂肪酸**　过氧化酶体（peroxisomes）存在脂肪酸 β-氧化的同工酶系，能将超长碳链脂肪酸（如 $\mathrm{C}20$、$\mathrm{C}22$）氧化成较短碳链脂肪酸。氧化第一步反应在以 $\mathrm{FAD}$ 为辅基的脂肪酸氧化酶作用下脱氢，脱下的氢与 $\mathrm{O}_2$ 结合成 $\mathrm{H}_2\mathrm{O}_2$，而不是进行氧化磷酸化；进一步反应释出较短链脂肪酸，在线粒体内 β-氧化。

:::definition{label="过氧化酶体 β-氧化"}
过氧化酶体有 β-氧化同工酶系，把超长碳链脂肪酸（如 $\mathrm{C}20$、$\mathrm{C}22$）氧化成较短链。第一步以 $\mathrm{FAD}$ 为辅基的脂肪酸氧化酶脱氢，氢交给 $\mathrm{O}_2$ 成 $\mathrm{H}_2\mathrm{O}_2$，不走氧化磷酸化；短链再交线粒体。
:::

:::pitfall{label="过氧化酶体第一步不产 ATP"}
同样脱氢、同样 $\mathrm{FAD}$，氢去向是 $\mathrm{H}_2\mathrm{O}_2$ 不是呼吸链。把超长链的缩短过程按 $1.5\,\mathrm{ATP}/\mathrm{FADH}_2$ 计，会虚高。
:::

**3. 丙酰 CoA 转变为琥珀酰 CoA 进行氧化**　人体含有极少量奇数碳原子脂肪酸，经 β-氧化生成丙酰 $\mathrm{CoA}$；支链氨基酸氧化分解亦可产生丙酰 $\mathrm{CoA}$。丙酰 $\mathrm{CoA}$ 彻底氧化需经 β-羧化酶及异构酶作用，转变为琥珀酰 $\mathrm{CoA}$（succinyl $\mathrm{CoA}$），进入三羧酸循环彻底氧化。

:::definition{label="丙酰 CoA 的去路"}
奇数碳脂肪酸 β-氧化末端、以及支链氨基酸氧化，可产生丙酰 $\mathrm{CoA}$。经 β-羧化酶及异构酶转变为琥珀酰 $\mathrm{CoA}$，进入三羧酸循环。
:::

**4. 脂肪酸氧化还可从远侧甲基端进行**　即 $\omega$-氧化（$\omega$-oxidation）。与内质网紧密结合的脂肪酸 $\omega$-氧化酶系由羧化酶、脱氢酶、$\mathrm{NADP}^{+}$、$\mathrm{NAD}^{+}$ 及细胞色素 $\mathrm{P}450$（cytochrome $\mathrm{P}450$，$\mathrm{Cyt}\ \mathrm{P}450$）等组成。脂肪酸 $\omega$-甲基碳原子在脂肪酸 $\omega$-氧化酶系作用下，经 $\omega$-羟基脂肪酸、$\omega$-醛基脂肪酸等中间产物，形成 $\alpha,\omega$-二羧酸。这样，脂肪酸就能从任一端活化并进行 β-氧化。

:::definition{label="ω-氧化"}
$\omega$-氧化（$\omega$-oxidation）从远侧甲基端开始。酶系与内质网紧密结合，含羧化酶、脱氢酶、$\mathrm{NADP}^{+}$、$\mathrm{NAD}^{+}$ 及 $\mathrm{Cyt}\ \mathrm{P}450$。$\omega$-甲基经 $\omega$-羟基、$\omega$-醛基，做成 $\alpha,\omega$-二羧酸，然后可从任一端活化并 β-氧化。
:::

:::compare{title="线粒体、过氧化酶体、内质网三条氧化"}
| 场所 | 对象 | 特点 |
|------|------|------|
| 线粒体基质 | 常规脂肪酸（脑除外） | 肉碱穿梭限速；四步 β-氧化；$\mathrm{FADH}_2$／$\mathrm{NADH}$ 走呼吸链 |
| 过氧化酶体 | 超长链如 $\mathrm{C}20$、$\mathrm{C}22$ | 同工酶系缩短碳链；第一步氢给 $\mathrm{O}_2$ 成 $\mathrm{H}_2\mathrm{O}_2$ |
| 内质网 | $\omega$-氧化 | 甲基端做成二羧酸，两端都能 β-氧化 |
:::

### （五）脂肪酸在肝分解可产生酮体

脂肪酸在肝内 β-氧化产生的大量乙酰 $\mathrm{CoA}$，部分被转变成酮体（ketone bodies），向肝外输出。酮体包括乙酰乙酸（acetoacetate）（$30\%$）、$\beta$-羟丁酸（$\beta$-hydroxybutyrate）（$70\%$）和丙酮（acetone）（微量）。

:::definition{label="酮体"}
酮体（ketone bodies）包括乙酰乙酸（$30\%$）、$\beta$-羟丁酸（$70\%$）和丙酮（微量）。由肝内脂肪酸 β-氧化产生的乙酰 $\mathrm{CoA}$ 部分转变而来，向肝外输出。
:::

**1. 酮体在肝生成**　酮体生成以脂肪酸 β-氧化生成的乙酰 $\mathrm{CoA}$ 为原料，在肝线粒体由酮体合成酶系催化完成（图8-4）。

:::note{label="电子版缺失"}
教材第 $177$ 页图8-4　酮体的生成电子版图源 `p0177_01.png` 为 $0$ 字节，不嵌入 `src`。正文以硫解酶、$\mathrm{HMG}$-$\mathrm{CoA}$ 合酶、$\mathrm{HMG}$-$\mathrm{CoA}$ 裂解酶、$\beta$-羟丁酸脱氢酶四步为准。
:::

（1）$2$ 分子乙酰 $\mathrm{CoA}$ 缩合成乙酰乙酰 $\mathrm{CoA}$：由乙酰乙酰 $\mathrm{CoA}$ 硫解酶（thiolase）催化，释放 $1$ 分子 $\mathrm{CoASH}$。

（2）乙酰乙酰 $\mathrm{CoA}$ 与乙酰 $\mathrm{CoA}$ 缩合成羟基甲基戊二酸单酰 $\mathrm{CoA}$（$3$-hydroxy-$3$-methyl glutaryl $\mathrm{CoA}$，$\mathrm{HMG}$-$\mathrm{CoA}$）：由 $\mathrm{HMG}$-$\mathrm{CoA}$ 合酶（$\mathrm{HMG}$-$\mathrm{CoA}$ synthase）催化，生成 $\mathrm{HMG}$-$\mathrm{CoA}$，释放出 $1$ 分子 $\mathrm{CoASH}$。

（3）$\mathrm{HMG}$-$\mathrm{CoA}$ 裂解产生乙酰乙酸：在 $\mathrm{HMG}$-$\mathrm{CoA}$ 裂解酶（$\mathrm{HMG}$-$\mathrm{CoA}$ lyase）作用下完成，生成乙酰乙酸和乙酰 $\mathrm{CoA}$。

（4）乙酰乙酸还原成 $\beta$-羟丁酸：由 $\mathrm{NADH}$ 供氢，在 $\beta$-羟丁酸脱氢酶（$\beta$-hydroxybutyrate dehydrogenase）催化下完成。少量乙酰乙酸转变成丙酮。

:::definition{label="HMG-CoA"}
羟基甲基戊二酸单酰 $\mathrm{CoA}$（$3$-hydroxy-$3$-methyl glutaryl $\mathrm{CoA}$，$\mathrm{HMG}$-$\mathrm{CoA}$）由 $\mathrm{HMG}$-$\mathrm{CoA}$ 合酶催化乙酰乙酰 $\mathrm{CoA}$ 与乙酰 $\mathrm{CoA}$ 缩合生成。裂解酶再把它裂成乙酰乙酸和乙酰 $\mathrm{CoA}$。胆固醇合成也经过 $\mathrm{HMG}$-$\mathrm{CoA}$，那是后文的户，本节只写酮体生成。
:::

:::timeline{period="肝线粒体生成酮体"}
- **硫解酶** 2 分子乙酰 CoA → 乙酰乙酰 CoA，放出 CoASH
- **HMG-CoA 合酶** 再缩合 1 分子乙酰 CoA → HMG-CoA，放出 CoASH
- **HMG-CoA 裂解酶** → 乙酰乙酸 + 乙酰 CoA
- **β-羟丁酸脱氢酶** NADH 供氢，乙酰乙酸 → β-羟丁酸；少量乙酰乙酸变丙酮
:::

**2. 酮体在肝外组织氧化利用**　肝组织有活性较强的酮体合成酶系，但缺乏利用酮体的酶系。肝外许多组织具有活性很强的酮体利用酶，能将酮体重新分解成乙酰 $\mathrm{CoA}$，通过三羧酸循环彻底氧化。所以肝内生成的酮体需经血液运输至肝外组织氧化利用。

（1）乙酰乙酸的利用需先活化：有两条途径。在心、肾、脑及骨骼肌线粒体，由琥珀酰 $\mathrm{CoA}$ 转硫酶（succinyl $\mathrm{CoA}$ thiophorase）催化生成乙酰乙酰 $\mathrm{CoA}$。在肾、心和脑线粒体，由乙酰乙酸硫激酶（acetoacetate thiokinase）催化，直接活化生成乙酰乙酰 $\mathrm{CoA}$。

（2）乙酰乙酰 $\mathrm{CoA}$ 硫解生成乙酰 $\mathrm{CoA}$：由乙酰乙酰 $\mathrm{CoA}$ 硫解酶（acetoacetyl $\mathrm{CoA}$ thiolase）催化。

$\beta$-羟基丁酸的利用是先在 $\beta$-羟丁酸脱氢酶催化下，脱氢生成乙酰乙酸，再转变成乙酰 $\mathrm{CoA}$ 被氧化。正常情况下，丙酮生成量很少，可经肺呼出。

:::definition{label="肝有生成、无能利用"}
肝有活性较强的酮体合成酶系，但缺乏利用酮体的酶系。酮体必须经血液运到肝外，再分解成乙酰 $\mathrm{CoA}$ 进三羧酸循环。
:::

:::compare{title="乙酰乙酸两条活化途径"}
| 酶 | 部位（线粒体） | 方式 |
|----|----------------|------|
| 琥珀酰 $\mathrm{CoA}$ 转硫酶 | 心、肾、脑及骨骼肌 | 借琥珀酰 $\mathrm{CoA}$ 的硫，生成乙酰乙酰 $\mathrm{CoA}$ |
| 乙酰乙酸硫激酶 | 肾、心和脑 | 直接活化生成乙酰乙酰 $\mathrm{CoA}$ |
:::

:::pitfall{label="骨骼肌有转硫酶，教材没把硫激酶写给骨骼肌"}
转硫酶名单：心、肾、脑及骨骼肌。硫激酶名单：肾、心和脑。不要把两条途径的组织写成完全同一张表。
:::

:::insight{label="β-羟丁酸先变回乙酰乙酸"}
$\beta$-羟丁酸脱氢酶在生成侧用 $\mathrm{NADH}$ 把乙酰乙酸还原；利用侧再脱氢变回乙酰乙酸。丙酮不走这条活化，正常量少，经肺呼出。
:::

**3. 酮体是肝向肝外组织输出能量的重要形式**　酮体分子小，溶于水，能在血液中运输，还能通过血脑屏障、肌组织的毛细血管壁，很容易被运输到肝外组织利用。心肌和肾皮质利用酮体能力大于利用葡萄糖能力。脑组织虽然不能氧化分解脂肪酸，却能有效利用酮体。当葡萄糖供应充足时，脑组织优先利用葡萄糖氧化供能；但在葡萄糖供应不足或利用障碍时，酮体是脑组织的主要能源物质。

正常情况下，血中仅含少量酮体，为 $0.03\sim 0.5\,\mathrm{mmol/L}$（$0.3\sim 5\,\mathrm{mg/dl}$）。在饥饿或糖尿病时，由于脂肪动员加强，酮体生成增加。严重糖尿病患者血中酮体含量可高出正常人数十倍，导致酮症酸中毒（ketoacidosis）。血酮体超过肾阈值，便可随尿排出，引起酮尿（ketonuria）。此时，血丙酮含量也大大增加，通过呼吸道排出，产生特殊的“烂苹果气味”。

:::keypoint{label="酮体为什么适合输出"}
- 分子小、溶于水，能走血液。
- 能过血脑屏障和肌组织毛细血管壁。
- 心肌、肾皮质：用酮体能力大于用葡萄糖。
- 脑：不能氧化脂肪酸，能用酮体；糖足时优先用糖，糖不足或利用障碍时酮体是主要能源。
:::

:::definition{label="酮症酸中毒与酮尿"}
正常血酮体 $0.03\sim 0.5\,\mathrm{mmol/L}$（$0.3\sim 5\,\mathrm{mg/dl}$）。饥饿或糖尿病时动员加强，生成增加。严重糖尿病可高出正常人数十倍，致酮症酸中毒（ketoacidosis）；超过肾阈值随尿排出为酮尿（ketonuria）；丙酮经呼吸道，有“烂苹果气味”。
:::

**4. 酮体生成受多种因素调节**

（1）餐食状态影响酮体生成　饱食后胰岛素分泌增加，脂解作用受抑制、脂肪动员减少，酮体生成减少。饥饿时，胰高血糖素等脂解激素分泌增多，脂肪动员加强，脂肪酸 β-氧化及酮体生成增多。

（2）糖代谢影响酮体生成　餐后或糖供给充分时，糖分解代谢旺盛、供能充分，肝内脂肪酸氧化分解减少，酮体生成被抑制。相反，饥饿或糖利用障碍时，脂肪酸氧化分解增强，生成乙酰 $\mathrm{CoA}$ 增加；同时因糖来源不足或糖代谢障碍，草酰乙酸减少，乙酰 $\mathrm{CoA}$ 进入三羧酸循环受阻，导致乙酰 $\mathrm{CoA}$ 大量堆积，酮体生成增多。

（3）丙二酸单酰 $\mathrm{CoA}$ 抑制酮体生成。糖代谢旺盛时，乙酰 $\mathrm{CoA}$ 及柠檬酸增多，别构激活乙酰 $\mathrm{CoA}$ 羧化酶，促进丙二酸单酰 $\mathrm{CoA}$ 合成，后者竞争性抑制肉碱脂肪酰转移酶Ⅰ，阻止脂肪酰 $\mathrm{CoA}$ 进入线粒体进行 β-氧化，从而抑制酮体生成。

:::cause-effect{title="糖不足时乙酰 CoA 为什么堆成酮体"}
- **因** 脂肪酸氧化增强，乙酰 $\mathrm{CoA}$ 增多；同时草酰乙酸因糖来源不足或糖代谢障碍而减少，乙酰 $\mathrm{CoA}$ 进不了三羧酸循环
- **果** 乙酰 $\mathrm{CoA}$ 堆积，肝线粒体走酮体生成
:::

:::insight{label="丙二酸单酰 CoA 同时关 β-氧化和酮体"}
饱食、糖旺 → 乙酰 $\mathrm{CoA}$ 羧化酶被柠檬酸等激活 → 丙二酸单酰 $\mathrm{CoA}$ ↑ → 竞争性抑制 $\mathrm{CPT}$-Ⅰ → 脂肪酰 $\mathrm{CoA}$ 进不了线粒体 → β-氧化和酮体一起被掐。合成脂肪酸的第一步，正好关掉分解的大门。
:::

:::compare{title="酮体生成的三层调节"}
| 层次 | 减少生成 | 增多生成 |
|------|----------|----------|
| 餐食／激素 | 饱食，胰岛素，脂解受抑 | 饥饿，胰高血糖素等，动员加强 |
| 糖代谢 | 糖旺，肝脂肪酸氧化减少 | 饥饿或糖利用障碍，乙酰 $\mathrm{CoA}$ 堆积且草酰乙酸少 |
| $\mathrm{CPT}$-Ⅰ | 丙二酸单酰 $\mathrm{CoA}$ 竞争性抑制 | 糖不足时这道闸打开 |
:::

## 二、不同来源脂肪酸在不同器官以不同的途径合成甘油三酯

### （一）肝、脂肪组织及小肠是甘油三酯合成的主要场所

甘油三酯（triglycerides，$\mathrm{TG}$）合成在胞质溶胶中完成，以肝合成能力最强。但肝细胞不能储存甘油三酯，需与载脂蛋白 $\mathrm{B}100$、$\mathrm{C}$ 等载脂蛋白及磷脂、胆固醇组装成极低密度脂蛋白（very low density lipoprotein，$\mathrm{VLDL}$），分泌入血，运输至肝外组织。营养不良、中毒，以及必需脂肪酸（essential fatty acids）、胆碱或蛋白质缺乏等可引起肝细胞 $\mathrm{VLDL}$ 生成障碍，导致甘油三酯在肝细胞蓄积，发生脂肪肝。脂肪细胞可大量储存甘油三酯，是机体储存甘油三酯的“脂库”。

:::definition{label="肝合成甘油三酯后必须输出"}
甘油三酯合成在胞质溶胶，肝能力最强，但不能储存。需与 $\mathrm{apo}\ \mathrm{B}100$、$\mathrm{C}$ 等及磷脂、胆固醇组装成 $\mathrm{VLDL}$ 入血。$\mathrm{VLDL}$ 生成障碍（营养不良、中毒、必需脂肪酸／胆碱／蛋白质缺乏）则蓄积为脂肪肝。
:::

:::compare{title="三个合成场所的下场"}
| 器官 | 合成能力 | 储存 | 输出形式 |
|------|----------|------|----------|
| 肝 | 最强 | 不能储存 | $\mathrm{VLDL}$（$\mathrm{apo}\ \mathrm{B}100$、$\mathrm{C}$ 等） |
| 脂肪组织 | 可大量储存 | “脂库” | 动员时再水解 |
| 小肠 | 再合成消化产物 | 不作为脂库 | 乳糜微粒（第二节 $\mathrm{apo}\ \mathrm{B}48$ 等） |
:::

:::pitfall{label="脂肪肝不是“肝合成太强”这一笔这么简单"}
教材点名的是 $\mathrm{VLDL}$ 生成障碍：营养不良、中毒、必需脂肪酸、胆碱或蛋白质缺乏。合成得出、装不走，甘油三酯才堆在肝细胞里。
:::

### （二）甘油和脂肪酸是合成甘油三酯的基本原料

机体能将葡萄糖分解产生的中间产物转变成甘油-3-磷酸，也能利用葡萄糖分解代谢中间产物乙酰 $\mathrm{CoA}$（acetyl $\mathrm{CoA}$）合成脂肪酸，人和动物即使完全不摄取，亦可由糖转化合成大量甘油三酯。小肠黏膜细胞主要利用摄取的甘油三酯消化产物重新合成甘油三酯，当其以乳糜微粒形式运送至脂肪组织、肝等组织／器官后，脂肪酸亦可作为这些组织细胞合成甘油三酯的原料。脂肪组织还可水解极低密度脂蛋白甘油三酯，释放脂肪酸用于合成甘油三酯。

:::insight{label="可以完全不吃脂肪，仍由糖做成大量甘油三酯"}
甘油骨架来自糖酵解中间物（甘油-3-磷酸）；脂肪酸来自乙酰 $\mathrm{CoA}$。小肠那一本是外源性再合成；肝和脂肪组织还可以吃 $\mathrm{CM}$／$\mathrm{VLDL}$ 释放的脂肪酸。
:::

### （三）甘油三酯合成有甘油一酯和甘油二酯两条途径

**1. 脂肪酸活化成脂肪酰 CoA**　脂肪酸作为甘油三酯合成的基本原料，必须活化成脂肪酰 $\mathrm{CoA}$（acyl $\mathrm{CoA}$）才能参与甘油三酯合成。反应同分解侧：$\mathrm{ATP}$、$\mathrm{CoA}$-$\mathrm{SH}$、$\mathrm{Mg}^{2+}$，生成 $\mathrm{AMP}$ 与 $\mathrm{PP}_\mathrm{i}$。

**2. 小肠黏膜细胞以甘油一酯途径合成甘油三酯**　由脂肪酰 $\mathrm{CoA}$ 转移酶催化、$\mathrm{ATP}$ 供能，将脂肪酰 $\mathrm{CoA}$ 的脂肪酰基转移至 $2$-甘油一酯羟基上合成甘油三酯。

**3. 肝和脂肪组织细胞以甘油二酯途径合成甘油三酯**　以糖酵解中间代谢产物磷酸二羟丙酮还原生成的甘油-3-磷酸为起始物，先合成 $1,2$-甘油二酯，最后通过酯化甘油二酯羟基生成甘油三酯。

合成甘油三酯的三分子脂肪酸可为同一种脂肪酸，也可是 $3$ 种不同脂肪酸。肝、肾等组织含有甘油激酶，可催化游离甘油磷酸化生成甘油-3-磷酸，供甘油三酯合成。脂肪细胞甘油激酶很低，不能直接利用甘油合成甘油三酯。甘油二酯途径的骨架反应是：甘油-3-磷酸先后接受两分子脂肪酰 $\mathrm{CoA}$，生成磷脂酸；磷脂酸脱去磷酸得到 $1,2$-甘油二酯；再接受第三分子脂肪酰 $\mathrm{CoA}$，酯化剩余羟基，生成甘油三酯。

:::definition{label="甘油一酯途径"}
小肠黏膜细胞的途径：脂肪酰 $\mathrm{CoA}$ 转移酶把脂肪酰基转到 $2$-甘油一酯羟基上，合成甘油三酯。起点是第二节胰脂酶留下的 $2$-甘油一酯。
:::

:::definition{label="甘油二酯途径"}
肝和脂肪组织的途径：磷酸二羟丙酮还原成甘油-3-磷酸，先合成 $1,2$-甘油二酯，再酯化剩余羟基成甘油三酯。
:::

:::compare{title="两条合成途径"}
| 项目 | 甘油一酯途径 | 甘油二酯途径 |
|------|--------------|--------------|
| 场所 | 小肠黏膜 | 肝、脂肪组织 |
| 甘油骨架来源 | $2$-甘油一酯（消化产物） | 磷酸二羟丙酮 → 甘油-3-磷酸 |
| 能否用游离甘油 | 不靠这一笔 | 肝、肾有甘油激酶可以用；脂肪细胞甘油激酶很低，不能直接用甘油 |
:::

:::pitfall{label="脂肪细胞不能靠游离甘油做甘油三酯"}
肝、肾有甘油激酶。脂肪细胞甘油激酶很低，骨架必须来自糖酵解的磷酸二羟丙酮。动员时放出的甘油主要回肝，不能在脂肪细胞就地再酯化。
:::

## 三、内源性脂肪酸的合成需先合成软脂酸

### （一）软脂酸由乙酰 CoA 在脂肪酸合酶复合体催化下合成

**1. 软脂酸在胞质溶胶中合成**　脂肪酸合成由多个酶催化完成，这些酶组成了脂肪酸合成的酶体系，即脂肪酸合酶复合体（fatty acid synthase complex），存在于肝、肾、脑、肺、乳腺及脂肪等多种组织的胞质溶胶，肝的脂肪酸合酶复合体活性最高（合成能力较脂肪组织大 $8\sim 9$ 倍），是人体合成脂肪酸的主要场所。虽然脂肪组织能以葡萄糖代谢的中间产物为原料合成脂肪酸，但脂肪组织的脂肪酸来源主要是小肠消化吸收的外源性脂肪酸和肝合成的内源性脂肪酸。

:::definition{label="脂肪酸合酶复合体"}
脂肪酸合酶复合体（fatty acid synthase complex）在胞质溶胶催化软脂酸合成。分布于肝、肾、脑、肺、乳腺及脂肪等；肝活性最高，较脂肪组织大 $8\sim 9$ 倍，是人体合成脂肪酸的主要场所。
:::

:::insight{label="脂库不等于脂肪酸合成工厂"}
脂肪组织能用糖中间物做脂肪酸，但主要原料仍是肠来的外源性和肝来的内源性脂肪酸。合成主场在肝。
:::

**2. 乙酰 CoA 是软脂酸合成的基本原料**　用于软脂酸（palmitic acid）合成的乙酰 $\mathrm{CoA}$（acetyl $\mathrm{CoA}$）主要由葡萄糖分解供给，在线粒体内产生，不能自由透过线粒体内膜，需通过柠檬酸-丙酮酸循环（citrate pyruvate cycle）（图8-5）进入胞质溶胶。在此循环中，乙酰 $\mathrm{CoA}$ 首先在线粒体内柠檬酸合酶催化下，与草酰乙酸缩合生成柠檬酸；后者通过线粒体内膜载体转运进入胞质溶胶，被 $\mathrm{ATP}$-柠檬酸裂解酶裂解，重新生成乙酰 $\mathrm{CoA}$ 及草酰乙酸。进入胞质溶胶的草酰乙酸在苹果酸脱氢酶作用下，由 $\mathrm{NADH}$ 供氢，还原成苹果酸，再经线粒体内膜载体转运至线粒体内。苹果酸也可在苹果酸酶作用下氧化脱羧、产生 $\mathrm{CO}_2$ 和丙酮酸，脱下的氢将 $\mathrm{NADP}^{+}$ 还原成 $\mathrm{NADPH}$；丙酮酸可通过线粒体内膜上载体转运至线粒体内，重新生成线粒体内草酰乙酸，可继续与乙酰 $\mathrm{CoA}$ 缩合，将乙酰 $\mathrm{CoA}$ 运转至胞质溶胶，用于软脂酸合成。

:::note{label="电子版缺失"}
教材第 $180$ 页图8-5　柠檬酸-丙酮酸循环电子版图源 `p0180_01.png` 为 $0$ 字节，不嵌入 `src`。教材图注：乙酰 $\mathrm{CoA}$ 在线粒体内与草酰乙酸缩合生成柠檬酸，经内膜载体入胞质溶胶；$\mathrm{ATP}$-柠檬酸裂解酶裂出乙酰 $\mathrm{CoA}$ 及草酰乙酸。乙酰 $\mathrm{CoA}$ 用以合成脂肪酸；草酰乙酸经苹果酸脱氢酶还原成苹果酸，也可经苹果酸酶分解为丙酮酸再入线粒体，最终均形成线粒体内草酰乙酸，再参与转运乙酰 $\mathrm{CoA}$。
:::

:::definition{label="柠檬酸-丙酮酸循环"}
柠檬酸-丙酮酸循环（citrate pyruvate cycle）把线粒体内的乙酰 $\mathrm{CoA}$ 转运到胞质溶胶：乙酰 $\mathrm{CoA}$ $+$ 草酰乙酸 → 柠檬酸（出线粒体）→ $\mathrm{ATP}$-柠檬酸裂解酶裂成乙酰 $\mathrm{CoA}$ 和草酰乙酸。草酰乙酸可经苹果酸回线粒体，或经苹果酸酶变成丙酮酸（伴随 $\mathrm{NADPH}$）再回线粒体重新生成草酰乙酸。
:::

:::timeline{period="乙酰 CoA 出线粒体"}
- **线粒体** 柠檬酸合酶：乙酰 CoA + 草酰乙酸 → 柠檬酸
- **载体** 柠檬酸出线粒体入胞质溶胶
- **ATP-柠檬酸裂解酶** 柠檬酸 → 乙酰 CoA + 草酰乙酸
- **回补** 草酰乙酸经苹果酸脱氢酶成苹果酸回线粒体；或苹果酸酶氧化脱羧成丙酮酸（NADPH），丙酮酸回线粒体再成草酰乙酸
:::

软脂酸合成还需 $\mathrm{ATP}$、$\mathrm{NADPH}$、$\mathrm{HCO}_3^{-}$（$\mathrm{CO}_2$）及 $\mathrm{Mn}^{2+}$ 等原料。$\mathrm{NADPH}$ 主要来自戊糖磷酸途径（pentose phosphate pathway），在上述乙酰 $\mathrm{CoA}$ 转运过程中，胞质溶胶苹果酸酶催化苹果酸氧化脱羧也可提供少量 $\mathrm{NADPH}$。

:::keypoint{label="软脂酸合成的原料清单"}
- 碳：乙酰 $\mathrm{CoA}$（主要来自葡萄糖分解，经柠檬酸-丙酮酸循环出线粒体）。
- 还原力：$\mathrm{NADPH}$（主要戊糖磷酸途径，少量苹果酸酶）。
- 还有：$\mathrm{ATP}$、$\mathrm{HCO}_3^{-}$（$\mathrm{CO}_2$）、$\mathrm{Mn}^{2+}$。
:::

**3. 一分子软脂酸由 1 分子乙酰 CoA 与 7 分子丙二酸单酰 CoA 缩合而成**

（1）乙酰 $\mathrm{CoA}$ 转化成丙二酸单酰 $\mathrm{CoA}$：是软脂酸合成的第一步反应，催化此反应的乙酰 $\mathrm{CoA}$ 羧化酶（acetyl $\mathrm{CoA}$ carboxylase）是脂肪酸合成的关键酶，以 $\mathrm{Mn}^{2+}$ 为激活剂，含生物素辅基，起转移羧基作用。该羧化反应为不可逆反应，过程如下：

$$
\text{酶-生物素}+\mathrm{HCO}_3^{-}+\mathrm{ATP}\rightarrow\text{酶-生物素-}\mathrm{CO}_2+\mathrm{ADP}+\mathrm{P}_\mathrm{i}
$$

$$
\text{酶-生物素-}\mathrm{CO}_2+\text{乙酰CoA}\rightarrow\text{酶-生物素}+\text{丙二酸单酰CoA}
$$

总反应：

$$
\mathrm{ATP}+\mathrm{HCO}_3^{-}+\text{乙酰CoA}\rightarrow\text{丙二酸单酰CoA}+\mathrm{ADP}+\mathrm{P}_\mathrm{i}
$$

乙酰 $\mathrm{CoA}$ 羧化酶活性受别构调节及化学修饰调节。该酶有两种存在形式，即无活性原聚体和有活性多聚体。柠檬酸、异柠檬酸可使此酶发生别构激活——由原聚体聚合成多聚体；软脂肪酰 $\mathrm{CoA}$ 及其他长链脂肪酰 $\mathrm{CoA}$ 可使多聚体解聚成原聚体，别构抑制该酶活性。乙酰 $\mathrm{CoA}$ 羧化酶还可在一种 $\mathrm{AMP}$ 激活的蛋白质激酶（$\mathrm{AMP}$-activated protein kinase，$\mathrm{AMPK}$）催化下发生酶蛋白（$79$、$1\,200$ 及 $1\,215$ 位丝氨酸残基）磷酸化而失活。胰高血糖素能激活该蛋白质激酶，抑制乙酰 $\mathrm{CoA}$ 羧化酶活性；胰岛素能通过蛋白磷酸酶的去磷酸化作用，使磷酸化的乙酰 $\mathrm{CoA}$ 羧化酶去磷酸化恢复活性。高糖膳食可促进乙酰 $\mathrm{CoA}$ 羧化酶蛋白合成，增加酶活性。

:::definition{label="乙酰 CoA 羧化酶"}
乙酰 $\mathrm{CoA}$ 羧化酶（acetyl $\mathrm{CoA}$ carboxylase）是脂肪酸合成的关键酶，催化乙酰 $\mathrm{CoA}$ → 丙二酸单酰 $\mathrm{CoA}$，不可逆。$\mathrm{Mn}^{2+}$ 为激活剂，含生物素辅基转移羧基。
:::

:::compare{title="乙酰 CoA 羧化酶的别构与磷酸化"}
| 方式 | 激活（合成开） | 抑制（合成关） |
|------|----------------|----------------|
| 聚合状态 | 柠檬酸、异柠檬酸：原聚体 → 有活性多聚体 | 软脂肪酰 $\mathrm{CoA}$ 及其他长链脂肪酰 $\mathrm{CoA}$：多聚体解聚成无活性原聚体 |
| 化学修饰 | 胰岛素经蛋白磷酸酶去磷酸化，恢复活性 | $\mathrm{AMPK}$ 磷酸化 $79$、$1\,200$、$1\,215$ 位丝氨酸而失活；胰高血糖素激活该激酶 |
| 酶量 | 高糖膳食促进蛋白合成 | — |
:::

:::pitfall{label="羧化酶是合成关键酶，CPT-I 是分解关键酶，丙二酸单酰 CoA 把二者拴在一起"}
乙酰 $\mathrm{CoA}$ 羧化酶做出丙二酸单酰 $\mathrm{CoA}$，既是软脂酸合成的二碳供体前体，又竞争性抑制 $\mathrm{CPT}$-Ⅰ。不要把“脂肪酸代谢关键酶”笼统写成一个。
:::

（2）软脂酸经 $7$ 次缩合—还原—脱水—再还原基本反应循环合成：各种脂肪酸生物合成过程基本相似，均以乙酰 $\mathrm{CoA}$ 为基本原料。除第一个乙酰 $\mathrm{CoA}$ 分子外，其余的乙酰 $\mathrm{CoA}$ 均需转变为丙二酸单酰 $\mathrm{CoA}$ 后进入脂肪酸合成反应，经反复加成反应完成，每次（缩合—还原—脱水—再还原）循环延长 $2$ 个碳原子。$16$ 碳软脂酸合成需经 $7$ 次循环反应。

大肠埃希菌脂肪酸合酶复合体的核心由 $7$ 种独立的酶／多肽组成；这 $7$ 种多肽包括脂肪酰基载体蛋白（acyl carrier protein，$\mathrm{ACP}$）、丙二酸单酰／乙酰 $\mathrm{CoA}$-$\mathrm{ACP}$ 转移酶（malonyl/acetyl-$\mathrm{CoA}$-$\mathrm{ACP}$ transferase，$\mathrm{MAT}$；以下简称丙二酸单酰／乙酰转移酶）、$\beta$-酮脂肪酰-$\mathrm{ACP}$ 合酶（$\beta$-ketoacyl-$\mathrm{ACP}$ synthase，$\mathrm{KS}$；$\beta$-酮脂肪酰合酶）、$\beta$-酮脂肪酰-$\mathrm{ACP}$ 还原酶（$\beta$-ketoacyl-$\mathrm{ACP}$ reductase，$\mathrm{KR}$；$\beta$-酮脂肪酰还原酶）、$\beta$-羟脂肪酰-$\mathrm{ACP}$ 脱水酶（$\beta$-hydroxyacyl-$\mathrm{ACP}$ dehydratase，$\mathrm{HD}$；脱水酶）、烯脂肪酰-$\mathrm{ACP}$ 还原酶（enoyl-$\mathrm{ACP}$ reductase，$\mathrm{ER}$；烯脂肪酰还原酶）及硫酯酶（thioesterase，$\mathrm{TE}$）。细菌酰基载体蛋白是一种小分子蛋白质（$M_\mathrm{r}$，$8\,860$），以 $4'$-磷酸泛酰巯基乙胺（$4'$-phosphopantetheine）为辅基，是脂肪酰基载体。此外，细菌脂肪酸合酶体系还有至少另外 $3$ 种成分。

哺乳动物脂肪酸合酶是由两个相同亚基（$M_\mathrm{r}$，$240\,\mathrm{kDa}$）首尾相连形成的二聚体（$M_\mathrm{r}$，$480\,\mathrm{kDa}$）。每个亚基含有 $3$ 个结构域（domain）。结构域 $1$ 含有乙酰基转移酶（$\mathrm{AT}$）、丙二酸单酰转移酶（$\mathrm{MT}$）及 $\beta$-酮脂肪酰合酶（$\mathrm{KS}$），与底物的“进入”、缩合反应相关。结构域 $2$ 含有 $\beta$-酮脂肪酰还原酶（$\mathrm{KR}$）、$\beta$-羟脂肪酰脱水酶（$\mathrm{HD}$）及烯脂肪酰还原酶（$\mathrm{ER}$），催化还原反应；该结构域还含有一个肽段，具有与细菌脂肪酰基载体蛋白（$\mathrm{ACP}$）相同的辅基（含酶-泛-$\mathrm{SH}$）和类似的作用。结构域 $3$ 含有硫酯酶（thioesterase，$\mathrm{TE}$），与脂肪酸的释放有关。$3$ 个结构域之间由柔性的区域连接，使结构域可以移动，利于几个酶之间的协调、连续作用。

:::compare{title="细菌与哺乳动物脂肪酸合酶"}
| 项目 | 大肠埃希菌 | 哺乳动物 |
|------|------------|----------|
| 组织方式 | $7$ 种独立酶／多肽为核心，另有至少 $3$ 种成分 | 两个相同亚基首尾相连的二聚体（$2\times 240\,\mathrm{kDa}=480\,\mathrm{kDa}$） |
| 载体 | $\mathrm{ACP}$（$M_\mathrm{r}\ 8\,860$），辅基 $4'$-磷酸泛酰巯基乙胺 | 结构域 $2$ 中一段肽，辅基同样是酶-泛-$\mathrm{SH}$ |
| 进入／缩合 | $\mathrm{MAT}$、$\mathrm{KS}$ | 结构域 $1$：$\mathrm{AT}$、$\mathrm{MT}$、$\mathrm{KS}$ |
| 还原 | $\mathrm{KR}$、$\mathrm{HD}$、$\mathrm{ER}$ | 结构域 $2$：$\mathrm{KR}$、$\mathrm{HD}$、$\mathrm{ER}$ |
| 释放 | $\mathrm{TE}$ | 结构域 $3$：$\mathrm{TE}$ |
:::

细菌、动物脂肪酸合成过程类似。细菌软脂酸合成步骤（图8-6）包括：①乙酰 $\mathrm{CoA}$ 在丙二酸单酰／乙酰转移酶作用下被转移至 $\mathrm{ACP}$ 的巯基（$-\mathrm{SH}$），再从 $\mathrm{ACP}$ 转移至 $\beta$-酮脂肪酰合酶的半胱氨酸巯基上。②丙二酸单酰 $\mathrm{CoA}$ 在丙二酸单酰／乙酰转移酶作用下，先脱去 $\mathrm{HSCoA}$，与 $\mathrm{ACP}$ 的 $-\mathrm{SH}$ 连接。③缩合，$\beta$-酮脂肪酰合酶上连接的乙酰基与 $\mathrm{ACP}$ 上的丙二酸单酰基缩合、生成 $\beta$-酮丁酰 $\mathrm{ACP}$，释放 $\mathrm{CO}_2$。④加氢，由 $\mathrm{NADPH}$ 供氢，$\beta$-酮丁酰 $\mathrm{ACP}$ 在 $\beta$-酮脂肪酰还原酶作用下加氢、还原成 $\mathrm{D}(-)$-$\beta$-羟丁酰 $\mathrm{ACP}$。⑤脱水，$\mathrm{D}(-)$-$\beta$-羟丁酰 $\mathrm{ACP}$ 在 $\beta$-羟脂肪酰脱水酶作用下，脱水生成反式 $\Delta^{2}$ 烯丁酰 $\mathrm{ACP}$。⑥再加氢，$\mathrm{NADPH}$ 供氢，反式 $\Delta^{2}$ 烯丁酰 $\mathrm{ACP}$ 在烯脂肪酰还原酶作用下，再加氢生成丁酰 $\mathrm{ACP}$。

:::note{label="电子版缺失"}
教材第 $182$ 页图8-6　软脂酸的生物合成电子版图源 `p0182_01.png` 为 $0$ 字节，不嵌入 `src`。正文以酰基转移、缩合、还原、脱水、再还原，$7$ 次循环后硫酯酶水解释放软脂酸为准。
:::

丁酰-$\mathrm{ACP}$ 是脂肪酸合酶复合体催化合成的第一轮产物。通过这一轮反应，即酰基转移、缩合、还原、脱水、再还原等步骤，产物碳原子由 $2$ 个增加至 $4$ 个。然后，丁酰由 $\mathrm{E}_2$-泛-$\mathrm{SH}$（即 $\mathrm{ACP}$ 的 $-\mathrm{SH}$）转移至 $\mathrm{E}_1$-半胱-$\mathrm{SH}$，$\mathrm{E}_2$-泛-$\mathrm{SH}$ 又可与另一丙二酸单酰基结合，进行缩合、还原、脱水、再还原等步骤的第二轮循环。经 $7$ 次循环后，生成 $16$ 碳软脂酰-$\mathrm{E}_2$；由硫酯酶水解，软脂酸从脂肪酸合酶复合体释放。软脂酸合成的总反应式为：

$$
\mathrm{CH}_3\mathrm{COSCoA}+7\,\mathrm{HOOCCH}_2\mathrm{COSCoA}+14\,\mathrm{NADPH}+14\,\mathrm{H}^{+}\rightarrow\mathrm{CH}_3(\mathrm{CH}_2)_{14}\mathrm{COOH}+7\,\mathrm{CO}_2+6\,\mathrm{H}_2\mathrm{O}+8\,\mathrm{HSCoA}+14\,\mathrm{NADP}^{+}
$$

:::timeline{period="第一轮做到丁酰-ACP"}
- **乙酰基就位** 乙酰 CoA → ACP-SH → KS 的半胱氨酸巯基（E1-半胱-SH）
- **丙二酸单酰基就位** 丙二酸单酰 CoA 脱 HSCoA，接到 ACP-SH（E2-泛-SH）
- **缩合** 放出 CO2，得 β-酮丁酰 ACP
- **还原** NADPH，KR，得 D(-)-β-羟丁酰 ACP
- **脱水** HD，得反式 Δ2 烯丁酰 ACP
- **再还原** NADPH，ER，得丁酰 ACP（2 碳变成 4 碳）
:::

:::keypoint{label="7 次循环，不是 8 次"}
第一个乙酰 $\mathrm{CoA}$ 提供起始 $2$ 碳，其余 $14$ 碳来自 $7$ 分子丙二酸单酰 $\mathrm{CoA}$（每次延长 $2$ 碳并放出 $\mathrm{CO}_2$）。总反应式水是 $6\,\mathrm{H}_2\mathrm{O}$、$\mathrm{HSCoA}$ 是 $8$，不要改成 $7$。
:::

:::compare{title="β-氧化四步 vs 软脂酸合成一轮"}
| 项目 | β-氧化（线粒体） | 软脂酸合成（胞质溶胶） |
|------|------------------|------------------------|
| 方向 | 缩短 $2$ 碳 | 延长 $2$ 碳 |
| 顺序 | 脱氢、加水、再脱氢、硫解 | 缩合、还原、脱水、再还原 |
| 氢载体 | $\mathrm{FAD}$、$\mathrm{NAD}^{+}$ | $2\times\mathrm{NADPH}$ |
| 羟中间体构型 | $\mathrm{L}$-$\beta$-羟脂肪酰 $\mathrm{CoA}$ | $\mathrm{D}(-)$-$\beta$-羟丁酰 $\mathrm{ACP}$ |
| 烯中间体 | 反式-$\Delta^{2}$ | 反式 $\Delta^{2}$ |
| 载体 | $\mathrm{CoA}$ | $\mathrm{ACP}$（或酶-泛-$\mathrm{SH}$） |
:::

:::pitfall{label="合成的羟中间体是 D 型，氧化的是 L 型"}
β-氧化加水得 $\mathrm{L}$ 型；合成还原得 $\mathrm{D}(-)$ 型。不饱和脂肪酸氧化时，顺式 $\Delta^{2}$ 水化出 $\mathrm{D}$ 型还得表异构酶转成 $\mathrm{L}$。构型不要对调。
:::

### （二）软脂酸延长在内质网和线粒体内进行

脂肪酸合酶复合体催化合成软脂酸，更长碳链脂肪酸的合成通过对软脂酸加工、延长完成。

**1. 内质网脂肪酸延长途径以丙二酸单酰 CoA 为二碳单位供体**　该途径由脂肪酸延长酶体系催化，$\mathrm{NADPH}$ 供氢，每通过缩合、加氢、脱水及再加氢等反应延长 $2$ 个碳原子。过程与软脂酸合成相似，但脂肪酰基不是以 $\mathrm{ACP}$ 为载体，而是连接在 $\mathrm{CoASH}$ 上进行。该酶体系可将脂肪酸延长至 $24$ 碳，但以 $18$ 碳硬脂肪酸为主。

**2. 线粒体脂肪酸延长途径以乙酰 CoA 为二碳单位供体**　该途径在脂肪酸延长酶体系作用下，软脂酰 $\mathrm{CoA}$ 与乙酰 $\mathrm{CoA}$ 缩合，生成 $\beta$-酮硬脂酰 $\mathrm{CoA}$；再由 $\mathrm{NADPH}$ 供氢，还原为 $\beta$-羟硬脂酰 $\mathrm{CoA}$；接着脱水生成 $\alpha,\beta$-烯硬脂酰 $\mathrm{CoA}$。最后，烯硬脂酰 $\mathrm{CoA}$ 由 $\mathrm{NADPH}$ 供氢，还原为硬脂酰 $\mathrm{CoA}$。通过缩合、加氢、脱水和再加氢等反应，每轮循环延长 $2$ 个碳原子；一般可延长至 $24$ 或 $26$ 个碳原子，但仍以 $18$ 碳硬脂肪酸为最多。

:::compare{title="两条延长途径"}
| 项目 | 内质网 | 线粒体 |
|------|--------|--------|
| 二碳供体 | 丙二酸单酰 $\mathrm{CoA}$ | 乙酰 $\mathrm{CoA}$ |
| 载体 | $\mathrm{CoASH}$，不是 $\mathrm{ACP}$ | 脂肪酰 $\mathrm{CoA}$ |
| 还原力 | $\mathrm{NADPH}$ | $\mathrm{NADPH}$ |
| 上限 | 可至 $24$ 碳 | 一般至 $24$ 或 $26$ 碳 |
| 主产物 | $18$ 碳硬脂肪酸 | 仍以 $18$ 碳硬脂肪酸为最多 |
:::

:::pitfall{label="延长不是再走一遍脂肪酸合酶复合体"}
合酶复合体停在软脂酸。再往上加碳，内质网用丙二酸单酰 $\mathrm{CoA}$ 且挂在 $\mathrm{CoA}$ 上；线粒体直接用乙酰 $\mathrm{CoA}$。都主要做成硬脂肪酸（$18{:}0$）。
:::

### （三）不饱和脂肪酸的合成需多种去饱和酶催化

上述脂肪酸合成途径合成的均为饱和脂肪酸（saturated fatty acid），人体含不饱和脂肪酸（unsaturated fatty acid），主要有软油酸（$16{:}1$，$\Delta^{9}$）、油酸（$18{:}1$，$\Delta^{9}$）、亚油酸（$18{:}2$，$\Delta^{9,12}$），$\alpha$-亚麻酸（$18{:}3$，$\Delta^{9,12,15}$）及花生四烯酸（$20{:}4$，$\Delta^{5,8,11,14}$）等。由于只含 $\Delta^{4}$、$\Delta^{5}$、$\Delta^{8}$ 及 $\Delta^{9}$ 去饱和酶（desaturase），缺乏 $\Delta^{9}$ 以上去饱和酶，人体只能合成软油酸和油酸等单不饱和脂肪酸（monounsaturated fatty acids），不能合成亚油酸、$\alpha$-亚麻酸及花生四烯酸等多不饱和脂肪酸（polyunsaturated fatty acids）。植物因含有 $\Delta^{9}$、$\Delta^{12}$ 及 $\Delta^{15}$ 去饱和酶，能合成 $\Delta^{9}$ 以上多不饱和脂肪酸。人体所需多不饱和脂肪酸必须从食物（主要是植物油脂）中摄取。

:::definition{label="人体去饱和酶"}
人体只含 $\Delta^{4}$、$\Delta^{5}$、$\Delta^{8}$ 及 $\Delta^{9}$ 去饱和酶，缺乏 $\Delta^{9}$ 以上去饱和酶。故能合成软油酸（$16{:}1$，$\Delta^{9}$）和油酸（$18{:}1$，$\Delta^{9}$），不能合成亚油酸、$\alpha$-亚麻酸及花生四烯酸。
:::

:::compare{title="谁能在 Δ9 以上再插双键"}
| | 人体 | 植物 |
|--|------|------|
| 去饱和酶 | $\Delta^{4}$、$\Delta^{5}$、$\Delta^{8}$、$\Delta^{9}$ | $\Delta^{9}$、$\Delta^{12}$、$\Delta^{15}$ |
| 能合成 | 软油酸、油酸等单不饱和 | $\Delta^{9}$ 以上多不饱和 |
| 不能合成 | 亚油酸、$\alpha$-亚麻酸、花生四烯酸 | — |
:::

:::pitfall{label="第一节“缺乏 Δ9 及以上”要和这里的酶名单一起读"}
第一节把亚油酸、$\alpha$-亚麻酸写成必需，因为人体缺乏 $\Delta^{9}$ 及以上去饱和酶、必须从植物食物获得。本节名单表明人体有 $\Delta^{9}$，能做油酸、软油酸；缺的是 $\Delta^{9}$ 以上（$\Delta^{12}$、$\Delta^{15}$）。花生四烯酸在第一节可自亚油酸合成，本节把它列入“不能合成的多不饱和”——两处都承认它依赖必需脂肪酸／植物来源，不要另造第三条去饱和酶表。
:::

### （四）脂肪酸合成受代谢物和激素调节

**1. 代谢物通过改变原料供应量和乙酰 CoA 羧化酶活性调节脂肪酸合成**　$\mathrm{ATP}$、$\mathrm{NADPH}$ 及乙酰 $\mathrm{CoA}$ 是脂肪酸合成原料，可促进脂肪酸合成；长链脂肪酰 $\mathrm{CoA}$ 是乙酰 $\mathrm{CoA}$ 羧化酶的别构抑制剂，抑制脂肪酸合成。凡能引起这些代谢物水平有效改变的因素均可调节脂肪酸合成。例如，高脂膳食和脂肪动员可使细胞内脂肪酰 $\mathrm{CoA}$ 增多，别构抑制乙酰 $\mathrm{CoA}$ 羧化酶活性，抑制脂肪酸合成。进食糖类食物后，糖代谢加强，$\mathrm{NADPH}$、乙酰 $\mathrm{CoA}$ 供应增多，有利于脂肪酸合成；糖代谢加强还使细胞内 $\mathrm{ATP}$ 增多，抑制异柠檬酸脱氢酶，导致柠檬酸和异柠檬酸蓄积并从线粒体渗至胞质溶胶，别构激活乙酰 $\mathrm{CoA}$ 羧化酶，促进脂肪酸合成。

**2. 胰岛素是调节脂肪酸合成的主要激素**　胰岛素（insulin）可通过刺激一种蛋白磷酸酶活性，使乙酰 $\mathrm{CoA}$ 羧化酶脱磷酸而激活，促进脂肪酸合成。此外，胰岛素可促进脂肪酸合成磷脂酸，增加脂肪合成。胰岛素还能增加脂肪组织脂蛋白脂肪酶活性，增加脂肪组织对血液甘油三酯脂肪酸摄取，促使脂肪组织合成脂肪贮存。该过程长期持续，与脂肪动员之间失去平衡，会导致肥胖。

胰高血糖素（glucagon）能增加蛋白质激酶活性，使乙酰 $\mathrm{CoA}$ 羧化酶磷酸化而降低活性，抑制脂肪酸合成。胰高血糖素也能抑制甘油三酯合成，甚至减少肝细胞向血液释放脂肪。肾上腺素、生长素能抑制乙酰 $\mathrm{CoA}$ 羧化酶，调节脂肪酸合成。

**3. 脂肪酸合酶可作为药物治疗的靶点**　脂肪酸合酶（复合体组分）在很多肿瘤高表达（overexpression）。动物研究证明，脂肪酸合酶抑制剂可明显减缓肿瘤生长，减轻体重，是极有潜力的抗肿瘤和抗肥胖的候选药物。

:::definition{label="胰岛素对脂肪酸合成的三笔"}
胰岛素是调节脂肪酸合成的主要激素：①刺激蛋白磷酸酶，乙酰 $\mathrm{CoA}$ 羧化酶脱磷酸而激活；②促进脂肪酸合成磷脂酸，增加脂肪合成；③增加脂肪组织脂蛋白脂肪酶活性，增加对血液甘油三酯脂肪酸的摄取、贮存。长期与动员失衡会导致肥胖。
:::

:::compare{title="胰岛素开合成，胰高血糖素关合成"}
| | 胰岛素 | 胰高血糖素 |
|--|--------|------------|
| 乙酰 $\mathrm{CoA}$ 羧化酶 | 去磷酸化，激活 | 经蛋白质激酶磷酸化，活性降低 |
| 甘油三酯 | 促磷脂酸／脂肪合成；促脂肪组织摄取贮存 | 抑制甘油三酯合成，甚至减少肝向血释放脂肪 |
| 其他 | 脂蛋白脂肪酶↑ | 肾上腺素、生长素也抑制羧化酶 |
:::

:::cause-effect{title="吃糖为什么能促进脂肪酸合成"}
- **因** 糖代谢加强 → $\mathrm{NADPH}$、乙酰 $\mathrm{CoA}$ 增多；$\mathrm{ATP}$ 增多抑制异柠檬酸脱氢酶 → 柠檬酸、异柠檬酸蓄积并渗至胞质溶胶
- **果** 原料充足，且柠檬酸／异柠檬酸别构激活乙酰 $\mathrm{CoA}$ 羧化酶，脂肪酸合成加快

:::pitfall{label="高脂膳食抑制的是合成，不是动员本身"}
高脂膳食和脂肪动员使细胞内脂肪酰 $\mathrm{CoA}$ 增多，别构抑制乙酰 $\mathrm{CoA}$ 羧化酶，脂肪酸合成被关。动员开、合成关，才不会一边水解一边再合成空转。
:::

:::memory{label="本节必背要点"}
- [ ] 动员三步：$\mathrm{ATGL}$（第一步）→ $\mathrm{HSL}$ 切甘油二酯 $\mathrm{sn}$-$3$（第二步）→ $\mathrm{MGL}$；$\mathrm{HSL}$ 不是第一步
- [ ] 脂解激素：肾上腺素、去甲肾上腺素、胰高血糖素；抗脂解：胰岛素、$\mathrm{PGE}_2$
- [ ] 清蛋白每分子结合 $7$ 分子游离脂肪酸；甘油主要被肝的甘油激酶利用
- [ ] 活化：脂肪酰 $\mathrm{CoA}$ 合成酶，$\mathrm{ATP}\rightarrow\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$，实际耗 $2$ 个高能磷酸键
- [ ] 肉碱穿梭：$\mathrm{CPT}$-Ⅰ（外膜，关键酶／限速）→ 转位酶 → $\mathrm{CPT}$-Ⅱ；丙二酸单酰 $\mathrm{CoA}$ 抑制 $\mathrm{CPT}$-Ⅰ
- [ ] β-氧化四步：脱氢（$\mathrm{FAD}$）、加水、再脱氢（$\mathrm{NAD}^{+}$）、硫解；产物反式-$\Delta^{2}$
- [ ] 本版软脂酸：$7$ 次 β-氧化，$7\,\mathrm{FADH}_2+7\,\mathrm{NADH}+8$ 乙酰 $\mathrm{CoA}$，毛 $108$、净 $106\,\mathrm{ATP}$（$1.5$／$2.5$／$10$）
- [ ] 不饱和：顺 $\Delta^{3}$ 用异构酶，顺 $\Delta^{2}$ 水化得 $\mathrm{D}$ 型用表异构酶；过氧化酶体超长链第一步产 $\mathrm{H}_2\mathrm{O}_2$；奇数碳 → 丙酰 $\mathrm{CoA}$ → 琥珀酰 $\mathrm{CoA}$；$\omega$-氧化在内质网
- [ ] 酮体：乙酰乙酸 $30\%$、$\beta$-羟丁酸 $70\%$、丙酮微量；肝有生成无能利用
- [ ] 利用：转硫酶（心、肾、脑、骨骼肌）；硫激酶（肾、心、脑）；正常血酮 $0.03\sim 0.5\,\mathrm{mmol/L}$
- [ ] 脑不能氧化脂肪酸，能用酮体；心肌、肾皮质用酮体强于用糖
- [ ] 肝 $\mathrm{TG}$ 装 $\mathrm{VLDL}$（$\mathrm{apo}\ \mathrm{B}100$）；肠走 $\mathrm{CM}$（$\mathrm{apo}\ \mathrm{B}48$）；脂肪肝来自 $\mathrm{VLDL}$ 装不走
- [ ] 小肠甘油一酯途径；肝和脂肪甘油二酯途径；脂肪细胞不能直接用游离甘油
- [ ] 乙酰 $\mathrm{CoA}$ 经柠檬酸-丙酮酸循环出线粒体；$\mathrm{NADPH}$ 主要来自戊糖磷酸途径
- [ ] 乙酰 $\mathrm{CoA}$ 羧化酶是合成关键酶，生物素、$\mathrm{Mn}^{2+}$；柠檬酸促聚合，长链脂肪酰 $\mathrm{CoA}$ 促解聚；$\mathrm{AMPK}$ 磷酸化失活
- [ ] $1$ 乙酰 $\mathrm{CoA}+7$ 丙二酸单酰 $\mathrm{CoA}$，$7$ 轮缩合-还原-脱水-再还原；总反应 $6\,\mathrm{H}_2\mathrm{O}$、$8\,\mathrm{HSCoA}$
- [ ] 哺乳动物合酶 $2\times 240\,\mathrm{kDa}$ 二聚体；延长：内质网用丙二酸单酰 $\mathrm{CoA}$，线粒体用乙酰 $\mathrm{CoA}$，主产物硬脂肪酸
- [ ] 人体去饱和酶 $\Delta^{4}$、$\Delta^{5}$、$\Delta^{8}$、$\Delta^{9}$，缺 $\Delta^{9}$ 以上；多不饱和必须从植物油脂摄取
- [ ] 胰岛素是合成主激素；胰高血糖素、肾上腺素、生长素关羧化酶
