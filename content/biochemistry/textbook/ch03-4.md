# 第四节　核酸的理化性质

本节把核酸的分子组成及空间结构写成可操作的理化性质：紫外 $260\,\mathrm{nm}$ 定量与纯度，$A_{260}/A_{280}$；多元酸与黏滞度、机械断裂、超速离心。再写变性解链、增色效应、解链曲线与 $T_\mathrm{m}$（及 $\mathrm{G}+\mathrm{C}$、离子强度），最后写复性、退火和分子杂交。章末收本章小结，把第一至四节的核酸收成一段。

核酸的分子组成及空间结构使得核酸具有一些特殊的理化性质，这些理化性质已被广泛应用到科学研究及临床疾病诊断等工作中。

:::definition{label="核酸的理化性质"}
核酸的分子组成及空间结构使得核酸具有一些特殊的理化性质，这些理化性质已被广泛应用到科学研究及临床疾病诊断等工作中。
:::

:::concept{term="先问读的是 260 nm 还是解链，再问能不能复性、能不能杂交"}
看见“核酸的性质”，先不要跳到 Southern。先问共轭双键给出的 $A_{260}$；再问氢键和碱基堆积力断了没有（变性、增色、$T_\mathrm{m}$）；最后问缓慢降温能不能配对回去（复性），以及不同来源的单链有没有足够互补（杂交）。把变性听成“序列也毁了”，杂交和 $\mathrm{PCR}$ 会没有模板。
:::

## 一、核酸具有紫外吸收特性

嘌呤和嘧啶是含有共轭双键的杂环分子。因此，碱基、核苷、核苷酸和核酸在紫外波段都有较强烈的吸收。在中性条件下，它们的最大吸收值在 $260\,\mathrm{nm}$ 附近（图3-26）。根据 $260\,\mathrm{nm}$ 处的吸光度（absorbance at $260\,\mathrm{nm}$，$A_{260}$），可以判断出溶液中的 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 的含量。实验中常以 $A_{260}=1.0$ 对应于 $50\,\mu\mathrm{g}/\mathrm{ml}$ 双链 $\mathrm{DNA}$，或 $40\,\mu\mathrm{g}/\mathrm{ml}$ 单链 $\mathrm{DNA}$ 或者 $\mathrm{RNA}$，或 $20\,\mu\mathrm{g}/\mathrm{ml}$ 寡核苷酸为标准定量溶液中的核酸含量。利用 $260\,\mathrm{nm}$ 与 $280\,\mathrm{nm}$ 的吸光度比值（$A_{260}/A_{280}$）还可以判断从生物样品中提取的核酸样品的纯度。$\mathrm{DNA}$ 纯品的 $A_{260}/A_{280}$ 的比值应为 $1.8$；而 $\mathrm{RNA}$ 纯品的 $A_{260}/A_{280}$ 的比值应为 $2.0$。

核酸为多元酸，具有较强的酸性。$\mathrm{DNA}$ 和 $\mathrm{RNA}$ 都是线性高分子，因此它们溶液的黏滞度极大，但是，$\mathrm{RNA}$ 的长度远小于 $\mathrm{DNA}$，含有 $\mathrm{RNA}$ 的溶液的黏滞度也小得多。$\mathrm{DNA}$ 大分子在机械力的作用下易发生断裂，因此在提取基因组 $\mathrm{DNA}$ 时应该格外小心，避免破坏基因组 $\mathrm{DNA}$ 的完整性。

溶液中的核酸分子在引力场中可以沉淀。在超速离心形成的引力场中，不同构象的核酸分子（如环状、超螺旋和线性等）的沉降速率有很大差异。这是超速离心法提取和纯化不同构象核酸的理论基础。

:::definition{label="核酸的紫外吸收"}
嘌呤和嘧啶是含有共轭双键的杂环分子，故碱基、核苷、核苷酸和核酸在紫外波段都有较强烈的吸收。中性条件下最大吸收值在 $260\,\mathrm{nm}$ 附近。
:::

:::definition{label="A260"}
$A_{260}$ 是 $260\,\mathrm{nm}$ 处的吸光度（absorbance at $260\,\mathrm{nm}$），可判断溶液中 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 的含量。
:::

:::definition{label="A260/A280"}
$A_{260}/A_{280}$ 用于判断从生物样品中提取的核酸样品的纯度。$\mathrm{DNA}$ 纯品应为 $1.8$；$\mathrm{RNA}$ 纯品应为 $2.0$。
:::

::figure{src="/images/biochemistry/textbook/p0101_01.png" caption="图3-26　五种碱基的紫外吸收光谱（pH 7.0）。中性条件下腺嘌呤、鸟嘌呤、胞嘧啶、胸腺嘧啶、尿嘧啶均在 260 nm 附近有较强吸收。" alt="紫外吸收光谱：横轴波长约 210 至 300 纳米，纵轴消光系数；五条曲线在 260 纳米附近出现吸收峰，腺嘌呤峰最高"}

:::derivation{title="用 A260=1.0 定量核酸"}
实验中常以 $A_{260}=1.0$ 作为标准：

$$
\begin{aligned}
A_{260}=1.0 &\leftrightarrow 50\,\mu\mathrm{g}/\mathrm{ml}\ \text{双链 }\mathrm{DNA}\\
A_{260}=1.0 &\leftrightarrow 40\,\mu\mathrm{g}/\mathrm{ml}\ \text{单链 }\mathrm{DNA}\ \text{或 }\mathrm{RNA}\\
A_{260}=1.0 &\leftrightarrow 20\,\mu\mathrm{g}/\mathrm{ml}\ \text{寡核苷酸}
\end{aligned}
$$

同一 $A_{260}$，双链 $\mathrm{DNA}$ 对应的质量浓度最高，寡核苷酸最低。这是经验换算，不是某一种纯核酸的精确摩尔消光。
:::

:::compare{title="A260 定量与 A260/A280 纯度"}
| 项目 | 读什么 | 教材标准 |
|------|--------|----------|
| 含量 | $A_{260}$ | $1.0$ 对应 $50\,\mu\mathrm{g}/\mathrm{ml}$ 双链 $\mathrm{DNA}$；$40\,\mu\mathrm{g}/\mathrm{ml}$ 单链 $\mathrm{DNA}$ 或 $\mathrm{RNA}$；$20\,\mu\mathrm{g}/\mathrm{ml}$ 寡核苷酸 |
| 纯度 | $A_{260}/A_{280}$ | $\mathrm{DNA}$ 纯品 $1.8$；$\mathrm{RNA}$ 纯品 $2.0$ |
| 光谱落点 | 中性、最大吸收 | $260\,\mathrm{nm}$ 附近（图3-26） |
:::

:::keypoint{label="紫外之外还有酸、黏滞度和离心三笔"}
- 核酸为多元酸，酸性较强。
- $\mathrm{DNA}$、$\mathrm{RNA}$ 都是线性高分子，溶液黏滞度极大；$\mathrm{RNA}$ 短得多，黏滞度也小得多。
- $\mathrm{DNA}$ 大分子在机械力下易断裂，提取基因组 $\mathrm{DNA}$ 须格外小心。
- 超速离心引力场中，环状、超螺旋、线性等构象的沉降速率差异很大，是按构象提取纯化的理论基础。
:::

:::pitfall{label="A260/A280：DNA 记 1.8，RNA 记 2.0，不要对调"}
蛋白质最大吸收在 $280\,\mathrm{nm}$ 附近，核酸在 $260\,\mathrm{nm}$。比值偏离 $1.8$／$2.0$，首先想的是蛋白污染或 $\mathrm{DNA}/\mathrm{RNA}$ 互混，不是“换了一根比色皿波长就变了”。把 $\mathrm{DNA}$ 纯品听成 $2.0$，提取质量会判反。
:::

:::pitfall{label="基因组 DNA 怕剪切，黏滞度大不是“越黏越纯”的考试点"}
线性高分子黏滞度极大，机械力就能把 $\mathrm{DNA}$ 打断。提取时小心是为了完整性，不是为了把溶液搅稠。$\mathrm{RNA}$ 短、黏滞度小，不要用同一套手法理解。
:::

:::insight{label="蛋白质看 280 nm，核酸看 260 nm，共轭体系不是同一套残基"}
第一章芳香族氨基酸（Tyr、Trp）走 $280\,\mathrm{nm}$；这里嘌呤、嘧啶走 $260\,\mathrm{nm}$。$A_{260}/A_{280}$ 能判纯度，正是因为两套吸收峰错开。
:::

## 二、DNA 双链解离发生变性

某些极端的理化条件（温度、$\mathrm{pH}$、离子强度等）可以断裂 $\mathrm{DNA}$ 双链互补碱基对之间的氢键以及破坏碱基堆积力，使一条 $\mathrm{DNA}$ 双链解离成为两条单链。这种现象称为 $\mathrm{DNA}$ 变性（$\mathrm{DNA}$ denaturation）。虽然 $\mathrm{DNA}$ 变性破坏了 $\mathrm{DNA}$ 的空间结构，但是没有改变 $\mathrm{DNA}$ 的核苷酸序列（图3-27）。

在变性条件下，一条 $\mathrm{DNA}$ 双链经历部分解离，大部解离，直到全部解离为两条 $\mathrm{DNA}$ 单链的过程。在 $\mathrm{DNA}$ 解链过程中，有更多的包埋在双螺旋结构内部的碱基得以暴露，因此含有 $\mathrm{DNA}$ 的溶液在 $260\,\mathrm{nm}$ 处的吸光度随之增加。这种现象称为 $\mathrm{DNA}$ 的增色效应（hyperchromic effect）。监测 $\mathrm{DNA}$ 在 $260\,\mathrm{nm}$ 吸光度的变化是判断 $\mathrm{DNA}$ 双链是否发生变性的一个常用的方法（图3-28a）。在实验室条件下，使 $\mathrm{DNA}$ 变性的最简单和最直接的方法是加热。如果以温度相对于 $A_{260}$ 值作图，所得的曲线称为 $\mathrm{DNA}$ 解链曲线（melting curve，或熔解曲线）（图3-28b）。从曲线中可以看出，随着温度的升高，$A_{260}$ 缓慢上升，表明 $\mathrm{DNA}$ 双链开始解链。当接近某个温度时，$A_{260}$ 发生了急剧的增加，并到达饱和，表明一条 $\mathrm{DNA}$ 双链解离成了两条 $\mathrm{DNA}$ 单链。解链后，温度的进一步升高并没有导致 $A_{260}$ 发生太大的变化。解链曲线显示解链过程是在一个相对较窄的温度范围内完成的。在解链曲线上，紫外吸光度的变化（$\Delta A_{260}$）达到最大变化值的一半时所对应的温度被定义为 $\mathrm{DNA}$ 的解链温度（melting temperature，$T_\mathrm{m}$ 称熔解温度）。在此温度时，$50\%$ 的 $\mathrm{DNA}$ 双链解离成为单链。$\mathrm{DNA}$ 的 $T_\mathrm{m}$ 值与 $\mathrm{DNA}$ 长短以及碱基的 $\mathrm{GC}$ 含量相关。$\mathrm{GC}$ 的含量越高，$T_\mathrm{m}$ 值越高；离子强度越高，$T_\mathrm{m}$ 值也越高。$T_\mathrm{m}$ 值可以根据 $\mathrm{DNA}$ 的长度、$\mathrm{GC}$ 含量以及离子浓度来简单地估算出来。小于 $20\,\mathrm{bp}$ 的寡核苷酸片段的 $T_\mathrm{m}$ 值可用公式 $T_\mathrm{m}=4(G+C)+2(A+T)$ 来估算，其中 $G$、$C$、$A$ 和 $T$ 是寡核苷酸片段中所含有的碱基个数。

:::definition{label="DNA 变性"}
某些极端理化条件（温度、$\mathrm{pH}$、离子强度等）断裂 $\mathrm{DNA}$ 双链互补碱基对之间的氢键并破坏碱基堆积力，使一条 $\mathrm{DNA}$ 双链解离成为两条单链，称为 $\mathrm{DNA}$ 变性（$\mathrm{DNA}$ denaturation）。变性破坏空间结构，但不改变核苷酸序列。
:::

:::definition{label="增色效应"}
$\mathrm{DNA}$ 解链过程中，更多包埋在双螺旋内部的碱基得以暴露，溶液在 $260\,\mathrm{nm}$ 处的吸光度随之增加，称为 $\mathrm{DNA}$ 的增色效应（hyperchromic effect）。监测 $A_{260}$ 变化是判断双链是否变性的常用方法。
:::

:::definition{label="解链曲线"}
实验室最简单、最直接的变性方法是加热。以温度相对于 $A_{260}$ 作图，所得曲线称为 $\mathrm{DNA}$ 解链曲线（melting curve，或熔解曲线）。解链过程在一个相对较窄的温度范围内完成：先缓慢上升，接近某温度时 $A_{260}$ 急剧增加并饱和，此后温度再升高 $A_{260}$ 变化不大。
:::

:::definition{label="解链温度 Tm"}
在解链曲线上，紫外吸光度的变化（$\Delta A_{260}$）达到最大变化值的一半时所对应的温度，定义为 $\mathrm{DNA}$ 的解链温度（melting temperature，$T_\mathrm{m}$，亦称熔解温度）。此温度时，$50\%$ 的 $\mathrm{DNA}$ 双链解离成为单链。
:::

教材图3-27 为 $\mathrm{DNA}$ 解链过程的示意图：双链经历部分解离、大部解离，直到全部解离为两条单链，核苷酸序列不变。数字切片 `p0102_01.png` 为 $0$ 字节，本节不引用该文件。变性破坏空间结构、不改变序列的正文仍按教材保留。
:::

::figure{src="/images/biochemistry/textbook/p0102_02.png" caption="图3-28　DNA 解链过程中的增色效应和对应的解链曲线。（a）同一波长下 DNA 单链的 A260 高于双链；（b）温度–A260 解链曲线，ΔA260 一半处对应解链温度 Tm。" alt="左图紫外光谱：单链曲线在 260 纳米高于双链；右图熔解曲线呈 S 形，中点标注 50% 和 Tm"}

:::cause-effect{title="碱基暴露所以 A260 升高"}
- **因** 解链使原先包埋在双螺旋内部的碱基暴露
- **果** $A_{260}$ 增加，即增色效应；故可用 $A_{260}$ 监测变性
:::

:::cause-effect{title="GC 含量高、离子强度高，则 Tm 高"}
- **因** $\mathrm{G}\equiv\mathrm{C}$ 有三对氢键，比 $\mathrm{A}=\mathrm{T}$ 的两对更难拆；离子强度高有利于双链稳定
- **果** $\mathrm{GC}$ 含量越高，$T_\mathrm{m}$ 越高；离子强度越高，$T_\mathrm{m}$ 也越高。$T_\mathrm{m}$ 还与 $\mathrm{DNA}$ 长短相关
:::

:::derivation{title="小于 20 bp 寡核苷酸的 Tm 估算"}
$T_\mathrm{m}$ 可根据 $\mathrm{DNA}$ 的长度、$\mathrm{GC}$ 含量以及离子浓度简单估算。小于 $20\,\mathrm{bp}$ 的寡核苷酸：

$$
T_\mathrm{m}=4(G+C)+2(A+T)
$$

其中 $G$、$C$、$A$ 和 $T$ 是片段中所含有的碱基个数。$\mathrm{GC}$ 一对按 $4$， $\mathrm{AT}$ 一对按 $2$，与“$\mathrm{GC}$ 含量越高 $T_\mathrm{m}$ 越高”同一方向。此式只用于小于 $20\,\mathrm{bp}$ 的寡核苷酸，不是基因组 $\mathrm{DNA}$ 的通式。
:::

:::example{label="读解链曲线上的 Tm"}
图3-28b 横轴是温度，纵轴是 $A_{260}$。曲线呈 $\mathrm{S}$ 形：低温双链、$A_{260}$ 低；高温单链、$A_{260}$ 高并饱和。$\Delta A_{260}$ 最大变化的一半处作垂直线，与横轴相交的温度就是 $T_\mathrm{m}$，此时 $50\%$ 双链已解离为单链。
:::

:::keypoint{label="变性三句"}
- 断的是氢键和碱基堆积力，不是磷酸二酯键，序列不变。
- 增色：碱基暴露，$A_{260}$ 升高。
- $T_\mathrm{m}$：$\Delta A_{260}$ 一半对应的温度；$50\%$ 解离；随长度、$\mathrm{GC}$、离子强度变。
:::

:::pitfall{label="变性不是水解，一级结构还在"}
教材写明：破坏空间结构，没有改变核苷酸序列。把加热听成“把 $\mathrm{DNA}$ 煮成核苷酸”，复性和杂交会没有互补链可退火。
:::

:::pitfall{label="Tm 不是开始解链的温度，是 50% 解离的温度"}
曲线先缓慢上升（开始解链），再急剧增加并饱和（全部成单链）。$T_\mathrm{m}$ 落在 $\Delta A_{260}$ 一半，不是脚、也不是肩。把 $T_\mathrm{m}$ 听成“刚开始冒泡的温度”，$\mathrm{GC}$ 含量那一笔会对错刻度。
:::

## 三、变性的核酸可以复性或形成杂交双链

把变性条件缓慢地除去后，两条解离的 $\mathrm{DNA}$ 互补链可重新互补配对形成 $\mathrm{DNA}$ 双链，恢复原来的双螺旋结构。这一现象称为复性（renaturation）。例如，热变性的 $\mathrm{DNA}$ 经缓慢冷却后可以复性，这一过程也称为退火（annealing）。但是，将热变性的 $\mathrm{DNA}$ 迅速冷却至 $4^{\circ}\mathrm{C}$ 时，两条解离的互补链还来不及形成双链，所以 $\mathrm{DNA}$ 不能发生复性。这一特性被用来保持解链后的 $\mathrm{DNA}$ 单链处在变性状态。

如果将不同种类的 $\mathrm{DNA}$ 单链或 $\mathrm{RNA}$ 单链混合在同一溶液中，只要这两种核酸单链之间存在着一定程度的碱基互补关系，它们就有可能形成杂化双链（heteroduplex）。这种双链可以在两条不同的 $\mathrm{DNA}$ 单链之间形成，也可以在两条 $\mathrm{RNA}$ 单链之间形成，甚至还可以在一条 $\mathrm{DNA}$ 单链和一条 $\mathrm{RNA}$ 单链之间形成（图3-29）。这种现象称为核酸分子杂交（hybridization）。核酸分子杂交是一项被广泛地应用在分子生物学和医学中的技术，Southern 印迹、Northern 印迹、斑点印迹、原位杂交、$\mathrm{PCR}$ 扩增、基因芯片等核酸检测方法都利用了核酸分子杂交的原理。这一技术被广泛地用来研究 $\mathrm{DNA}$ 片段在基因组中的定位、鉴定核酸分子间的序列同源性、检测靶基因在待检样品中存在与否等。

:::definition{label="复性"}
把变性条件缓慢除去后，两条解离的 $\mathrm{DNA}$ 互补链重新互补配对形成 $\mathrm{DNA}$ 双链，恢复原来的双螺旋结构，称为复性（renaturation）。
:::

:::definition{label="退火"}
热变性的 $\mathrm{DNA}$ 经缓慢冷却后可以复性，这一过程也称为退火（annealing）。
:::

:::definition{label="杂化双链与分子杂交"}
不同种类的 $\mathrm{DNA}$ 单链或 $\mathrm{RNA}$ 单链只要存在一定程度的碱基互补，就有可能形成杂化双链（heteroduplex）。可在两条不同 $\mathrm{DNA}$ 单链之间、两条 $\mathrm{RNA}$ 单链之间、或一条 $\mathrm{DNA}$ 单链与一条 $\mathrm{RNA}$ 单链之间形成。这种现象称为核酸分子杂交（hybridization）。
:::

::figure{src="/images/biochemistry/textbook/p0103_01.png" caption="图3-29　核酸分子复性和杂交的示意图。来自不同样品的双链 DNA1 和双链 DNA2 解离后，若序列具有互补性，温度缓慢降低时，单链 DNA1 可以和单链 DNA2 形成互补的杂化双链；同时也可各自复性成原来的双链。" alt="三步图：黑色 DNA1 与蓝色 DNA2 双链加温解离成单链，缓慢降温后出现杂交双链以及各自复性的双链 DNA1、DNA2"}

:::cause-effect{title="慢冷才能退火，速冷到 4°C 保持单链"}
- **因** 热变性后缓慢冷却，互补链来得及重新配对
- **果** 复性／退火，恢复双螺旋
- **因** 迅速冷却至 $4^{\circ}\mathrm{C}$，互补链来不及形成双链
- **果** 不能复性，单链保持变性状态
:::

:::keypoint{label="杂交三对组合、六种技术"}
- 组合：$\mathrm{DNA}$–$\mathrm{DNA}$，$\mathrm{RNA}$–$\mathrm{RNA}$，$\mathrm{DNA}$–$\mathrm{RNA}$。
- 技术：Southern 印迹、Northern 印迹、斑点印迹、原位杂交、$\mathrm{PCR}$ 扩增、基因芯片。
- 用途：$\mathrm{DNA}$ 片段在基因组中定位；鉴定序列同源性；检测靶基因在待检样品中存在与否。
:::

:::compare{title="变性、复性、杂交"}
| 项目 | 变性 | 复性（退火） | 杂交 |
|------|------|--------------|------|
| 链从哪来 | 同一条双链拆成两条单链 | 原来的互补链重新配对 | 不同种类的 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 单链 |
| 条件 | 高温、极端 $\mathrm{pH}$、离子强度等 | 缓慢除去变性条件；热变性后缓慢冷却 | 有一定程度碱基互补 |
| 产物 | 两条单链；序列不变 | 原来的双螺旋 | 杂化双链（heteroduplex） |
| 不要听成 | 磷酸二酯键水解 | 迅速冷却到 $4^{\circ}\mathrm{C}$ 也能配对 | 必须 $100\%$ 相同才能结合 |
:::

:::example{label="图3-29 里三种产物同时出现"}
双链 $\mathrm{DNA}1$ 和双链 $\mathrm{DNA}2$ 加温解离成单链；缓慢降温后：序列互补的单链 $\mathrm{DNA}1$ 与单链 $\mathrm{DNA}2$ 形成杂交双链；同时各自也可复性成双链 $\mathrm{DNA}1$、双链 $\mathrm{DNA}2$。杂交不是“只准异源、不准同源”。
:::

:::pitfall{label="迅速冷却到 4°C 是为了保持单链，不是加速复性"}
来不及配对，所以不能复性。探针杂交、$\mathrm{PCR}$ 变性后若一下子冰浴，走的是“锁在单链”这一笔。把冰浴听成“快速退火”，后面的复性曲线会对反。
:::

:::pitfall{label="杂交只要求一定程度互补，不是必须全长完全一样"}
教材写的是“一定程度的碱基互补关系”。Southern、基因芯片正是靠部分互补去定位、去看同源。把杂交听成“两条链必须完全相同”，杂化双链这个词会没有意义。
:::

:::tip{label="Southern 探 DNA，Northern 探 RNA，都是杂交原理"}
印迹、斑点、原位、$\mathrm{PCR}$、芯片，户头都在变性和复性。先会解链和退火，再记各技术的样品是 $\mathrm{DNA}$ 还是 $\mathrm{RNA}$。
:::

## 本章小结

核酸有 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 之分，它们是由脱氧核糖核苷酸或核糖核苷酸为基本单位，通过 $3',5'$-磷酸二酯键聚合而成的生物信息大分子。

$\mathrm{DNA}$ 的一级结构是脱氧核糖核苷酸的排列顺序。$\mathrm{DNA}$ 携带的遗传信息来自碱基排列的方式。$\mathrm{DNA}$ 是由两条反向平行的多聚核苷酸链组成，其二级结构是双螺旋。两条链上的碱基满足互补关系，即腺嘌呤与胸腺嘧啶形成两对氢键的碱基对；鸟嘌呤与胞嘧啶形成三对氢键的碱基对。具有双螺旋结构的 $\mathrm{DNA}$ 在细胞内还将进一步折叠成为超螺旋结构。$\mathrm{DNA}$ 的生物功能是作为生物遗传信息复制的模板和基因转录的模板。

$\mathrm{RNA}$ 一般是 $\mathrm{DNA}$ 的转录产物。编码 $\mathrm{RNA}$ 是指 $\mathrm{mRNA}$，它是细胞质中蛋白质合成的模板。真核细胞核中的 $\mathrm{hnRNA}$ 经过一系列的修饰后成为成熟的 $\mathrm{mRNA}$。真核成熟 $\mathrm{mRNA}$ 含有 $5'$-帽结构、编码区和 $3'$-多聚（$\mathrm{A}$）尾结构。$\mathrm{mRNA}$ 编码区中的每 $3$ 个核苷酸构成了一个密码子，决定了对应多肽链上的一个氨基酸。

非编码 $\mathrm{RNA}$ 包括直接参与蛋白质合成的 $\mathrm{tRNA}$、$\mathrm{rRNA}$ 和一些其他 $\mathrm{RNA}$ 分子。$\mathrm{tRNA}$ 在蛋白质合成过程中作为氨基酸的载体，为新生多肽链提供合成底物。$\mathrm{mRNA}$ 密码子与 $\mathrm{tRNA}$ 的反密码子通过碱基互补关系相互识别。$\mathrm{rRNA}$ 与核糖体蛋白共同构成了核糖体，核糖体是蛋白质合成的场所。核糖体为 $\mathrm{mRNA}$、$\mathrm{tRNA}$ 和肽链合成所需要的多种蛋白质因子提供结合位点和相互作用所需要的空间环境。其他非编码 $\mathrm{RNA}$ 包括 $\mathrm{snRNA}$、$\mathrm{snoRNA}$、$\mathrm{scRNA}$、$\mathrm{miRNA}$、$\mathrm{lncRNA}$ 等，它们的主要生物学功能是参与基因表达调控。核酶是一类具有生物催化功能的 $\mathrm{RNA}$ 分子，是生物催化剂。

核酸有紫外吸收的特性，其最大吸收峰在 $260\,\mathrm{nm}$。核酸在酸、碱或加热情况下可发生变性，即一条双链解离成为两条单链。在适当的条件下，热变性的两条互补单链可以重新结合成为双链，称为复性。基于核酸变性和复性的核酸分子杂交是一种分子生物学常用技术。

:::definition{label="本章小结里的核酸"}
核酸有 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 之分，由脱氧核糖核苷酸或核糖核苷酸为基本单位，通过 $3',5'$-磷酸二酯键聚合而成的生物信息大分子。
:::

:::definition{label="本章小结里的 DNA 双螺旋"}
$\mathrm{DNA}$ 由两条反向平行的多聚核苷酸链组成，二级结构是双螺旋。腺嘌呤与胸腺嘧啶两对氢键，鸟嘌呤与胞嘧啶三对氢键。细胞内进一步折叠为超螺旋。功能：遗传信息复制的模板和基因转录的模板。
:::

:::definition{label="本章小结里的成熟 mRNA"}
真核成熟 $\mathrm{mRNA}$ 含 $5'$-帽结构、编码区和 $3'$-多聚（$\mathrm{A}$）尾。编码区每 $3$ 个核苷酸构成一个密码子，决定多肽链上一个氨基酸。$\mathrm{hnRNA}$ 经一系列修饰成为成熟 $\mathrm{mRNA}$。
:::

:::compare{title="本章小结：tRNA、rRNA 和其他非编码 RNA"}
| 种类 | 在蛋白质合成中的角色 | 其他 |
|------|------------------------|------|
| $\mathrm{tRNA}$ | 氨基酸的载体；反密码子与 $\mathrm{mRNA}$ 密码子碱基互补识别 | 为新生多肽提供合成底物 |
| $\mathrm{rRNA}$ | 与核糖体蛋白构成核糖体（合成场所） | 为 $\mathrm{mRNA}$、$\mathrm{tRNA}$ 和多种蛋白质因子提供结合位点与空间 |
| $\mathrm{snRNA}$、$\mathrm{snoRNA}$、$\mathrm{scRNA}$、$\mathrm{miRNA}$、$\mathrm{lncRNA}$ 等 | 不直接充当模板或氨基酸载体 | 主要参与基因表达调控 |
| 核酶 | — | 具有生物催化功能的 $\mathrm{RNA}$，是生物催化剂 |
:::

:::insight{label="小结把全章收成三句话"}
组成账：核苷酸经 $3',5'$-磷酸二酯键成链，$\mathrm{DNA}$ 双螺旋（$\mathrm{A}$–$\mathrm{T}$ 两氢键、$\mathrm{G}$–$\mathrm{C}$ 三氢键）再折成超螺旋，$\mathrm{RNA}$ 是转录产物。信息账：$\mathrm{mRNA}$ 是模板（真核帽、编码区、尾），$\mathrm{tRNA}$ 是氨基酸载体，$\mathrm{rRNA}$ 搭核糖体，其他非编码 $\mathrm{RNA}$ 调控，核酶能催化。性质账：最大吸收 $260\,\mathrm{nm}$；变性拆双链、序列仍在；复性重新配对；杂交是变性和复性的应用。
:::

:::memory{label="本节必背要点"}
- [ ] 嘌呤、嘧啶含共轭双键；碱基、核苷、核苷酸和核酸在中性条件下最大吸收在 $260\,\mathrm{nm}$ 附近。
- [ ] $A_{260}=1.0$ 对应 $50\,\mu\mathrm{g}/\mathrm{ml}$ 双链 $\mathrm{DNA}$，或 $40\,\mu\mathrm{g}/\mathrm{ml}$ 单链 $\mathrm{DNA}$／$\mathrm{RNA}$，或 $20\,\mu\mathrm{g}/\mathrm{ml}$ 寡核苷酸。
- [ ] 纯度：$A_{260}/A_{280}$，$\mathrm{DNA}$ 纯品 $1.8$，$\mathrm{RNA}$ 纯品 $2.0$。
- [ ] 核酸是多元酸；线性高分子黏滞度极大，$\mathrm{RNA}$ 较短故黏滞度小；基因组 $\mathrm{DNA}$ 怕机械断裂。
- [ ] 超速离心中环状、超螺旋、线性沉降速率差异大，可按构象纯化。
- [ ] 变性：温度、$\mathrm{pH}$、离子强度等断开氢键、破坏碱基堆积力，双链 → 两条单链；空间结构破坏，核苷酸序列不变。
- [ ] 增色效应：内部碱基暴露，$A_{260}$ 升高；是判断变性的常用方法。
- [ ] 加热最简单；温度对 $A_{260}$ 作图得解链曲线（熔解曲线）；解链发生在较窄温度范围。
- [ ] $T_\mathrm{m}$：$\Delta A_{260}$ 达最大变化一半时的温度；$50\%$ 双链解离为单链。
- [ ] $\mathrm{GC}$ 越高 $T_\mathrm{m}$ 越高；离子强度越高 $T_\mathrm{m}$ 越高；还与 $\mathrm{DNA}$ 长短相关。
- [ ] 小于 $20\,\mathrm{bp}$：$T_\mathrm{m}=4(G+C)+2(A+T)$，$G$、$C$、$A$、$T$ 为碱基个数。
- [ ] 复性：缓慢除去变性条件，互补链重新配对；热变性后缓慢冷却也称退火。
- [ ] 迅速冷却至 $4^{\circ}\mathrm{C}$ 不能复性，用来保持单链变性状态。
- [ ] 杂交：不同来源 $\mathrm{DNA}/\mathrm{RNA}$ 单链只要有一定程度互补即可形成杂化双链（$\mathrm{DNA}$–$\mathrm{DNA}$、$\mathrm{RNA}$–$\mathrm{RNA}$、$\mathrm{DNA}$–$\mathrm{RNA}$）。
- [ ] 应用：Southern、Northern、斑点印迹、原位杂交、$\mathrm{PCR}$、基因芯片；定位、同源性、检测靶基因。
- [ ] 本章小结：$\mathrm{DNA}/\mathrm{RNA}$ 经 $3',5'$-磷酸二酯键聚合；$\mathrm{DNA}$ 双螺旋 $\mathrm{A}$–$\mathrm{T}$ 两氢键、$\mathrm{G}$–$\mathrm{C}$ 三氢键，功能是复制与转录模板。
- [ ] 真核成熟 $\mathrm{mRNA}$：$5'$-帽、编码区、$3'$-多聚（$\mathrm{A}$）尾；密码子决定氨基酸。
- [ ] $\mathrm{tRNA}$ 运氨基酸，反密码子识别密码子；核糖体是合成场所；$\mathrm{snRNA}$ 等参与表达调控；核酶是生物催化剂。
- [ ] 紫外峰 $260\,\mathrm{nm}$；酸、碱或加热可变性；适当条件下可复性；杂交基于变性和复性。
:::
