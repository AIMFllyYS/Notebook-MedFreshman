# 第一节　印迹法和探针技术

第十八章打开「常用的分子生物学技术」。基因的结构与功能研究要靠 $\mathrm{DNA}$ 操作、生物大分子相互作用和基因表达分析；高通量测序拿到的海量信息还要靠生物信息学收、处理、呈现。本节只立印迹与探针：核酸靠变性－复性做分子杂交，蛋白质靠抗原－抗体等特异识别。聚合酶链反应交给第二节，测序交给第三节；分子相互作用、重组与基因编辑是第四、五节的账。

:::concept{term="先问分子是 DNA、RNA 还是蛋白质，再问探针认的是碱基互补还是抗原抗体"}
看见“印迹法和探针”，先不要默写 $\mathrm{PCR}$ 三步。户头是：把大分子从胶转移到膜上固相化，再用带示踪物的探针去认。$\mathrm{DNA}$ 印迹是 Southern，$\mathrm{RNA}$ 印迹是 Northern，蛋白质印迹是 Western。核酸探针按碱基互补杂交；Western 用的是抗体，不是核酸杂交。基因芯片是印迹法微型化、集成化之后的微阵列，不要写成另一套与膜无关的理论。
:::

:::note{label="电子版缺失"}
教材第 $337$ 页章首「本章数字资源」及节题图源 `p0366_01.png`、`p0366_02.png` 为 $0$ 字节，不嵌入 `src`。正文以印迹、探针和三类印迹法为准。
:::

分子生物学理论研究的突破，无一不与分子生物学技术的创建和发展息息相关，可以说两者是科学与技术相互促进的最好例证：理论上的发现为新技术的产生提供思路，而新技术的发明又为证实原有理论和发展新理论提供有力工具。基因研究是分子医学的核心领域，围绕基因的结构与功能的各种研究中，都需要利用 $\mathrm{DNA}$ 操作、生物大分子之间相互作用和基因表达分析等研究技术；高通量测序等分子组学技术获取的海量生物医学信息，依赖生物信息学技术收集、处理、呈现和运用这些大数据。因此，了解分子生物学技术的原理及其用途，对于加深理解现代分子生物学的基本理论和研究现状，深入认识生命运作的分子过程、疾病发生和发展的分子机制，理解和应用新的基于分子生物学而发展起来的诊断治疗策略和药物研发具有极为重要的意义。为此，本章概括介绍一些常用的分子生物学技术及其在生物医学中的应用。

:::definition{label="理论与技术相互促进"}
理论上的发现为新技术提供思路，新技术又为证实原有理论、发展新理论提供工具。本章不是另开一门「仪器学」，而是把前面各章已经用过的分子过程写成可操作的检测手段。
:::

:::keypoint{label="本章技术为分子医学服务的三条线"}
- 基因结构与功能：$\mathrm{DNA}$ 操作、大分子相互作用、基因表达分析。
- 分子组学数据：高通量测序产生海量信息，靠生物信息学收集、处理、呈现和运用。
- 应用落点：认识生命过程与疾病机制，理解诊断治疗策略和药物研发。

第一条线的「看见某条核酸或蛋白质」从本节的印迹和探针开始。
:::

:::insight{label="高通量测序在章首出现，不等于本节就会测序"}
章首把高通量测序写成分子组学的数据来源，测序原理在第三节。本节只解决「样品里有没有这条核酸／蛋白质、大致多少」。把芯片、印迹直接答成测序，第三节的双脱氧和循环芯片就没有前置。
:::

$\mathrm{DNA}$ 和 $\mathrm{RNA}$ 的定性或定量分析，可以利用核酸变性与复性这一基本理化性质，进行分子杂交（hybridization），结合印迹法（blotting）和探针（probe）技术进行。印迹法还能够利用抗原－抗体等相互特异识别结合的特点，检测特定蛋白质分子。

:::definition{label="分子杂交"}
分子杂交（hybridization）：利用核酸变性与复性这一基本理化性质，让序列互补的核酸单链重新配对结合。定性、定量检测 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 时，杂交是识别步骤，印迹是把分子搬到膜上的步骤，探针是带示踪物的已知序列。
:::

:::definition{label="印迹法兼管核酸和蛋白质"}
核酸走变性－复性杂交；蛋白质走抗原－抗体等相互特异识别。两种识别原理不同，都叫印迹，是因为都要把待测分子从一种介质转移到另一种介质并固相化。
:::

:::pitfall{label="蛋白质印迹不是核酸杂交的一种"}
开篇两句话不要并成「印迹=杂交」。杂交管 $\mathrm{DNA}/\mathrm{RNA}$；检测蛋白质时教材写的是抗原－抗体等特异识别。后文 Western 的一抗、二抗，基因芯片的荧光杂交，户头从这里就要分开。
:::

:::compare{title="本节三种识别不要并成一次结合"}
| | 待测分子 | 识别原理 | 常用示踪 |
|--|----------|----------|----------|
| 核酸印迹 | $\mathrm{DNA}$ 或 $\mathrm{RNA}$ | 碱基互补杂交 | 放射性核素、生物素、荧光物质标记的核酸探针 |
| 蛋白质印迹 | 蛋白质 | 抗原－抗体等特异结合 | 酶或核素标记的第二抗体 |
| 基因芯片 | 荧光标记的核酸样品 | 与芯片上固定的 $\mathrm{DNA}$ 探针杂交 | $\mathrm{Cy}3$、$\mathrm{Cy}5$ 等荧光 |

膜上的 Southern／Northern 和芯片上的微阵列，识别都还是杂交；Western 已经换成抗体。
:::

## 一、印迹法是生物大分子定性定量分析的基本技术

印迹法是通过接触吸附的方式，将 $\mathrm{DNA}$、$\mathrm{RNA}$ 或蛋白质等大分子从一种介质转移至另一种介质的过程。转移常用毛细管作用或电泳等技术。

:::definition{label="印迹法"}
印迹法：通过接触吸附，把 $\mathrm{DNA}$、$\mathrm{RNA}$ 或蛋白质等大分子从一种介质转移到另一种介质。转移常用毛细管作用或电泳。名称来自吸墨纸接触吸附纸张上的墨迹。
:::

:::insight{label="先聚集、再转移、再固相，探针才找得到区带"}
胶里的分子按大小排开是「聚集」；转到 $\mathrm{NC}$ 膜或 $\mathrm{PVDF}$ 膜是「转移」；烘烤或紫外交联是「固相化」。三者缺一，溶液里的探针只能看到一团混合物，看不到区带。
:::

### （一）印迹法的关键是将待测分子聚集并转移至膜上

$1975$ 年，$\mathrm{Southern}\ \mathrm{E}.$ 将经琼脂糖凝胶电泳分离的 $\mathrm{DNA}$ 片段在胶中变性使其成为单链，然后将硝酸纤维素膜（nitrocellulose membrane，$\mathrm{NC}$ 膜）平铺在胶上，膜上放置一定厚度的吸水纸巾，利用毛细作用将胶中的 $\mathrm{DNA}$ 分子转移到 $\mathrm{NC}$ 膜上，通过 $80^\circ\mathrm{C}$ 烘烤或经紫外线照射交联而使之固相化。将载有 $\mathrm{DNA}$ 单链分子的 $\mathrm{NC}$ 膜放在核酸杂交反应溶液中，溶液中具有互补序列的 $\mathrm{DNA}$ 单链或 $\mathrm{RNA}$ 分子就可以结合到存在于 $\mathrm{NC}$ 膜上的 $\mathrm{DNA}$ 分子上。这一技术类似于用吸墨纸接触吸附纸张上的墨迹，因此译为印迹法。目前印迹法已广泛用于 $\mathrm{DNA}$、$\mathrm{RNA}$ 和蛋白质的检测。除靠毛细作用将待测分子转移固定至膜上外，又建立了真空吸引转移和适用于蛋白质固定的电泳转移技术。这些方法缩短了转移所需的时间。另外亦有聚偏二氟乙烯（polyvinylidene fluoride，$\mathrm{PVDF}$）膜等一些新材料作为转移膜，改善了待测分子的转移效率和样品承载能力。

:::definition{label="Southern 1975 年的原型操作"}
琼脂糖凝胶电泳分离 $\mathrm{DNA}$ 片段 $\rightarrow$ 胶中变性成单链 $\rightarrow$ $\mathrm{NC}$ 膜平铺在胶上，膜上放吸水纸巾，靠毛细作用把 $\mathrm{DNA}$ 转到膜上 $\rightarrow$ $80^\circ\mathrm{C}$ 烘烤或紫外照射交联固相化 $\rightarrow$ 膜浸入杂交液，互补的 $\mathrm{DNA}$ 单链或 $\mathrm{RNA}$ 结合到膜上的 $\mathrm{DNA}$。
:::

:::definition{label="NC 膜"}
硝酸纤维素膜（nitrocellulose membrane，$\mathrm{NC}$ 膜）是经典转移膜。后文 $\mathrm{DNA}$ 印迹把含 $\mathrm{DNA}$ 的 $\mathrm{NC}$ 膜在 $80^\circ\mathrm{C}$ 真空加热或紫外交联仪内处理，使 $\mathrm{DNA}$ 固定于膜上。
:::

:::definition{label="PVDF 膜"}
聚偏二氟乙烯（polyvinylidene fluoride，$\mathrm{PVDF}$）膜是较新的转移材料，改善待测分子的转移效率和样品承载能力。蛋白质印迹中与 $\mathrm{NC}$ 膜并列出现。
:::

:::definition{label="三种转移方式"}
①毛细作用：经典 Southern，吸水纸巾拉动液体，把胶中分子带到膜上；②真空吸引转移：缩短时间；③电泳转移：适用于蛋白质固定，同样缩短时间。
:::

:::definition{label="固相化的两种办法"}
$80^\circ\mathrm{C}$ 烘烤（后文 $\mathrm{DNA}$ 印迹写明真空条件下加热）或紫外线照射交联。固相化之后，膜上的单链核酸才能在杂交液里被探针找到，而不会重新溶回溶液。
:::

:::insight{label="译名印迹法来自吸墨纸，不是来自「复印」"}
教材把毛细转移比作吸墨纸吸墨迹。英文 blotting 的这个意象决定了中文译名。不要写成「把胶影印到膜上」或「把条带拍照」。
:::

:::pitfall{label="1975 年这一套只写了 DNA，不要直接当成 Western"}
原型是 $\mathrm{DNA}$、琼脂糖、毛细、$\mathrm{NC}$ 膜。蛋白质改用聚丙烯酰胺凝胶电泳和电转移，识别改用抗体。把 $1975$ 年操作原样套到蛋白质上，$\mathrm{PVDF}$ 和二抗都没有位置。
:::

:::pitfall{label="变性在胶里做，不是转到膜上才变"}
$\mathrm{Southern}\ \mathrm{E}.$ 的流程是电泳分离后「在胶中变性使其成为单链」，再转移。双链 $\mathrm{DNA}$ 若不先变成单链，探针按碱基互补是结合不上去的。
:::

:::compare{title="毛细转移 vs 真空吸引 vs 电泳转移"}
| | 动力 | 教材点名的用途 |
|--|------|----------------|
| 毛细作用 | 吸水纸巾形成的液体流动 | 经典 $\mathrm{DNA}$ 印迹 |
| 真空吸引 | 负压把液体和分子抽向膜 | 缩短转移时间 |
| 电泳转移 | 电场把带电大分子赶向膜 | 适用于蛋白质固定，同样缩短时间 |

三种都是「从胶到膜」。后文斑点印迹可以不经电泳，直接把样品点在 $\mathrm{NC}$ 膜上，那是衍生法，不是这三种转移的第四种动力。
:::

### （二）探针技术是利用特异识别待测分子的示踪物开展检测分析

探针是分子生物学和生物化学实验中用于指示特定物质（如核酸、蛋白质、细胞结构等）性质或物理状态的一类标记分子。核酸探针是最常见的一类探针，另外还有有机小分子探针和金属离子探针等。

核酸探针是常用放射性核素、生物素或荧光物质等可检测示踪物标记的已知序列核酸片段，能与待测的核酸片段依据碱基互补原理杂交，可检测样品中存在的特定核酸分子。核酸探针既可以是人工合成的寡核苷酸片段，也可以是基因组 $\mathrm{DNA}$ 片段、$\mathrm{cDNA}$ 全长或片段，还可以是 $\mathrm{RNA}$ 片段。在 $\mathrm{NC}$ 膜杂交反应中，探针序列如果与 $\mathrm{NC}$ 膜上的核酸存在碱基序列互补，就可以结合到膜上的相应 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 区带，经放射自显影或其他与标记相应的检测技术，就可以判定膜上是否有互补序列的核酸分子存在。

:::definition{label="探针"}
探针：用于指示特定物质（如核酸、蛋白质、细胞结构等）性质或物理状态的一类标记分子。核酸探针最常见，另有有机小分子探针和金属离子探针。
:::

:::definition{label="核酸探针"}
用放射性核素、生物素或荧光物质等可检测示踪物标记的已知序列核酸片段。与待测核酸按碱基互补杂交，检测样品中是否存在特定核酸分子。
:::

:::definition{label="核酸探针的三种来源"}
①人工合成的寡核苷酸片段；②基因组 $\mathrm{DNA}$ 片段；③ $\mathrm{cDNA}$ 全长或片段；也可以是 $\mathrm{RNA}$ 片段。来源不同，识别规则仍是碱基互补。
:::

:::definition{label="膜上杂交怎样读出有没有"}
探针与 $\mathrm{NC}$ 膜上核酸互补 $\rightarrow$ 结合到相应 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 区带 $\rightarrow$ 放射自显影，或其他与标记相应的检测 $\rightarrow$ 判定膜上是否有互补序列的核酸。
:::

:::keypoint{label="探针三句话：已知序列、带示踪、按互补杂交"}
- 序列必须已知，否则「特异」没有参照。
- 必须带可检测示踪物，否则结合了也看不见。
- 识别靠碱基互补，不是靠分子量和电荷。

Western 的抗体满足「已知特异性、带示踪」，但不走碱基互补，不要塞进核酸探针的定义。
:::

:::pitfall{label="探针不是「任何带荧光的分子」"}
教材把探针限定为指示特定物质性质或物理状态的标记分子，核酸探针还要求已知序列。把溴化乙啶染整胶的荧光、或 $\mathrm{SYBR\ Green}$ 非特异插入双链，都叫做本节的核酸探针，后文基因芯片的位点信息和实时 $\mathrm{PCR}$ 的探针类／非探针类就分不开。
:::

:::pitfall{label="示踪物三种并列，不要只答放射性核素"}
放射性核素、生物素、荧光物质是教材并列的三类可检测示踪物。只答同位素，后文 $\mathrm{FISH}$、基因芯片的 $\mathrm{Cy}3/\mathrm{Cy}5$、化学发光增强的 Western 都会变成「不算探针检测」。
:::

:::compare{title="核酸探针 vs 抗体（Western 用）"}
| | 核酸探针 | Western 的抗体 |
|--|----------|----------------|
| 认什么 | 互补核酸序列 | 特异蛋白质表位 |
| 标记 | 核素、生物素、荧光 | 一抗本身常不直接显色；二抗用碱性磷酸酶、辣根过氧化物酶或核素 |
| 读出 | 自显影或与标记相应的检测 | 底物显色、自显影，底物亦可结合化学发光剂 |

二者都是「带示踪的特异识别物」，化学本质不同。
:::

- $\mathrm{RNA}$ 印迹：样品直接电泳，转 $\mathrm{NC}$ 或尼龙膜，探针杂交；图上没有酶切这一枪。
- 蛋白质印迹：电泳后转 $\mathrm{NC}$ 或 $\mathrm{PVDF}$，与抗体反应，不是与核酸探针杂交。

### （一）DNA 印迹法主要用于基因组 DNA 的定性和定量分析

$\mathrm{DNA}$ 印迹法（Southern blotting）为 $\mathrm{Southern}\ \mathrm{E}.$ 首次应用，因而又称 Southern 印迹法。$\mathrm{DNA}$ 样品经限制性核酸内切酶消化后，进行琼脂糖凝胶电泳分离 $\mathrm{DNA}$ 片段，将已按不同大小聚集 $\mathrm{DNA}$ 片段的凝胶在变性溶液中处理，然后将胶中的变性 $\mathrm{DNA}$ 分子转移到 $\mathrm{NC}$ 膜上，再将含 $\mathrm{DNA}$ 片段的 $\mathrm{NC}$ 膜在 $80^\circ\mathrm{C}$ 真空条件下加热或在紫外交联仪内处理，使 $\mathrm{DNA}$ 固定于 $\mathrm{NC}$ 膜上，即可用于杂交反应。$\mathrm{DNA}$ 印迹法主要用于基因组 $\mathrm{DNA}$ 的定性和定量分析，例如对基因组中特异基因的定位及检测、转基因和基因剔除等基因编辑的分析，亦可用于分析重组构建的质粒和噬菌体等。

:::definition{label="DNA 印迹法即 Southern 印迹法"}
$\mathrm{DNA}$ 印迹法（Southern blotting）因 $\mathrm{Southern}\ \mathrm{E}.$ 首次应用而得名，又称 Southern 印迹法。
:::

:::definition{label="Southern 的操作顺序"}
限制性核酸内切酶消化 $\rightarrow$ 琼脂糖凝胶电泳按大小分离 $\rightarrow$ 变性溶液处理凝胶 $\rightarrow$ 变性 $\mathrm{DNA}$ 转移到 $\mathrm{NC}$ 膜 $\rightarrow$ $80^\circ\mathrm{C}$ 真空加热或紫外交联仪固定 $\rightarrow$ 杂交。
:::

:::definition{label="Southern 的主要用途"}
基因组 $\mathrm{DNA}$ 的定性、定量分析。教材举例：基因组中特异基因的定位及检测；转基因和基因剔除等基因编辑的分析；重组构建的质粒和噬菌体等。
:::

:::insight{label="限制酶先把基因组切成可电泳的片段"}
基因组 $\mathrm{DNA}$ 太长，不切就进不了「按大小聚集」这一步。酶切位点变了，区带位置跟着变，所以转基因、基因剔除和重组质粒都能用 Southern 看。
:::

:::pitfall{label="Southern 用琼脂糖，不要写成 PAGE"}
$\mathrm{DNA}$ 片段走琼脂糖凝胶电泳；蛋白质印迹才改用聚丙烯酰胺凝胶电泳。胶选错，后文「电转移蛋白质」和「毛细转 $\mathrm{DNA}$」会对不上。
:::

:::pitfall{label="80℃ 真空加热是固定 DNA，不是变性"}
变性在胶里用变性溶液完成；膜上 $80^\circ\mathrm{C}$ 真空加热或紫外交联是固相化。把烘烤答成变性，毛细转移之前那一步就丢了。
:::

### （二）RNA 印迹法用于特定组织或细胞目的基因的转录水平分析

利用与 $\mathrm{DNA}$ 印迹法相类似的技术来分析 $\mathrm{RNA}$ 就称为 $\mathrm{RNA}$ 印迹法（Northern blotting）。$\mathrm{RNA}$ 分子较小，在转移前无须进行限制性核酸内切酶切割，而且变性 $\mathrm{RNA}$ 的转移效率也比较高。$\mathrm{RNA}$ 印迹法主要用于检测特定组织或细胞中已知的特异 $\mathrm{mRNA}$ 和非编码 $\mathrm{RNA}$ 的表达及丰度，也可以比较不同组织和细胞中的同一基因的转录情况。尽管用 $\mathrm{RNA}$ 印迹法检测 $\mathrm{RNA}$ 的敏感性较 $\mathrm{PCR}$ 技术低，但是由于其特异性强，假阳性率低，仍然被认为是最可靠的 $\mathrm{RNA}$ 定量分析方法之一。

:::definition{label="RNA 印迹法即 Northern 印迹法"}
$\mathrm{RNA}$ 印迹法（Northern blotting）：用与 $\mathrm{DNA}$ 印迹法相类似的技术分析 $\mathrm{RNA}$。Northern 是对应 Southern 的命名，不是另一位发现者的姓。
:::

:::definition{label="Northern 不必先酶切"}
$\mathrm{RNA}$ 分子较小，转移前无须限制性核酸内切酶切割；变性 $\mathrm{RNA}$ 的转移效率也比较高。
:::

:::definition{label="Northern 看转录水平和丰度"}
检测特定组织或细胞中已知的特异 $\mathrm{mRNA}$ 和非编码 $\mathrm{RNA}$ 的表达及丰度；也可比较不同组织、细胞中同一基因的转录情况。
:::

:::definition{label="Northern 敏感性低于 PCR，仍是可靠定量之一"}
检测 $\mathrm{RNA}$ 的敏感性较 $\mathrm{PCR}$ 低，但特异性强、假阳性率低，仍被认为是最可靠的 $\mathrm{RNA}$ 定量分析方法之一。第二节实时 $\mathrm{PCR}$ 写「已逐渐替代 $\mathrm{RNA}$ 印迹法」，替代的是通量与速度，不是把「可靠」这一句作废。
:::

:::pitfall{label="Northern 不是 Southern 的 RNA 版酶切"}
教材特地写「无须进行限制性核酸内切酶切割」。把限制酶画进 Northern，图18-1 中间一列的「$\mathrm{RNA}$ 样品」就变成了「酶切 $\mathrm{RNA}$」。
:::

:::pitfall{label="看的是已知特异 RNA，不是把转录组从头测一遍"}
用途写明「已知的特异 $\mathrm{mRNA}$ 和非编码 $\mathrm{RNA}$」。全转录物组定量是第三节 $\mathrm{RNA}$-$\mathrm{seq}$ 的账。Northern 一次认的是探针互补的那一条。
:::

:::compare{title="Southern vs Northern"}
| | Southern（$\mathrm{DNA}$ 印迹） | Northern（$\mathrm{RNA}$ 印迹） |
|--|------------------------------|------------------------------|
| 样品 | $\mathrm{DNA}$（常为基因组或重组载体） | $\mathrm{RNA}$ |
| 酶切 | 限制性核酸内切酶消化 | 无须切割 |
| 电泳 | 琼脂糖凝胶 | 与 $\mathrm{DNA}$ 印迹类似 |
| 膜与识别 | $\mathrm{NC}$ 膜，核酸探针杂交 | $\mathrm{NC}$ 膜或尼龙膜，核酸探针杂交 |
| 主要问题 | 基因组中有没有这条基因、编辑后条带是否改变 | 这个组织／细胞里这条 $\mathrm{RNA}$ 有没有、丰度如何 |
| 相对 $\mathrm{PCR}$ | — | 敏感性较低，特异强、假阳性低 |

名字上 Northern 对 Southern，流程上少的是酶切，问的是转录而不是基因本身。
:::

### （三）蛋白质印迹法用于蛋白质表达及相互作用研究

印迹法不仅可用于核酸的分子杂交，而且也可用于蛋白质的分析。蛋白质通过电泳也可以从胶中转移并固定到膜型材料上，再依靠与溶液中相应的蛋白质分子相互结合来进行定性定量分析，即判断特定蛋白质的存在与否和分子量大小等。其中最常用的是用抗体来检测，因此亦被称为免疫印迹法（immunoblotting）。相对应于 $\mathrm{DNA}$ 的 Southern 印迹法和 $\mathrm{RNA}$ 的 Northern 印迹法，蛋白质印迹法（Western blotting）又被称为 Western 印迹法。

蛋白质印迹法需先将样品中混杂的蛋白质用聚丙烯酰胺凝胶电泳按分子大小聚集，再通过电转移将蛋白质固定到 $\mathrm{NC}$ 膜或 $\mathrm{PVDF}$ 膜上。蛋白质的分析主要靠抗体来进行。特异性抗体（称为第一抗体）首先与转移膜上相应的蛋白质分子结合，然后用碱性磷酸酶、辣根过氧化物酶标记或放射性核素等标记的第二抗体与之结合。反应之后用底物显色或放射自显影来检测蛋白质区带的信号，底物亦可与化学发光剂相结合以提高敏感度。蛋白质印迹法用于检测样品中特异性蛋白质的存在、细胞中特异蛋白质的半定量分析以及蛋白质分子的相互作用研究等。

:::definition{label="蛋白质印迹法即 Western 印迹法、免疫印迹法"}
蛋白质印迹法（Western blotting）又称 Western 印迹法。最常用抗体检测，故亦称免疫印迹法（immunoblotting）。
:::

:::definition{label="Western 的聚集与转移"}
样品中混杂的蛋白质先用聚丙烯酰胺凝胶电泳按分子大小聚集，再电转移到 $\mathrm{NC}$ 膜或 $\mathrm{PVDF}$ 膜上固定。
:::

:::definition{label="一抗与二抗"}
第一抗体：特异性抗体，直接结合膜上相应蛋白质。第二抗体：碱性磷酸酶、辣根过氧化物酶或放射性核素等标记，结合一抗。显色用底物，或放射自显影；底物亦可与化学发光剂结合以提高敏感度。
:::

:::definition{label="Western 的用途"}
检测样品中特异性蛋白质是否存在；细胞中特异蛋白质的半定量分析；蛋白质分子的相互作用研究。
:::

:::insight{label="Western 读出的是「有没有、大约多大、大约多少」"}
电泳按分子大小聚集，所以能判断分子量大小；抗体决定「是不是这个蛋白质」；信号强弱只到半定量。精确拷贝数不是这一节的账。
:::

:::pitfall{label="Western 不要答成核酸杂交"}
教材写「依靠与溶液中相应的蛋白质分子相互结合」，最常用的是抗体。把 Western 写成「蛋白质探针按碱基互补杂交」，免疫印迹这个别名就没有着落。
:::

:::pitfall{label="一抗通常不直接带酶，显色在二抗上"}
第一抗体负责识别；第二抗体才是碱性磷酸酶、辣根过氧化物酶或核素标记。把酶画在一抗上，放大和通用检测这一层就没了。
:::

:::pitfall{label="化学发光是提高敏感度，不是另一种印迹法"}
底物可与化学发光剂结合以提高敏感度。仍是 Western 的读出方式，不要另立「发光印迹」。
:::

:::compare{title="三类基本印迹法"}
| | Southern | Northern | Western |
|--|----------|----------|---------|
| 英文 | Southern blotting | Northern blotting | Western blotting |
| 待测 | $\mathrm{DNA}$ | $\mathrm{RNA}$ | 蛋白质 |
| 电泳 | 琼脂糖（先限制酶切） | 类似 $\mathrm{DNA}$ 印迹（不酶切） | 聚丙烯酰胺凝胶电泳 |
| 转移 | 毛细等，至 $\mathrm{NC}$ 膜 | $\mathrm{NC}$ 或尼龙膜 | 电转移至 $\mathrm{NC}$ 或 $\mathrm{PVDF}$ |
| 识别 | 核酸探针 | 核酸探针 | 一抗 $+$ 标记二抗 |
| 典型问题 | 基因组定性定量、基因编辑、重组载体 | 转录水平与丰度 | 蛋白质有无、半定量、相互作用 |

Southern 是人名；Northern、Western 是后来按方位词对齐的叫法，不要编造 Northern 氏、Western 氏。
:::

在上述三类基本印迹法基础上，已衍生出许多分析核酸或蛋白质的方法。例如，可以不经电泳分离、直接将样品聚集在 $\mathrm{NC}$ 膜上用于杂交分析，即斑点杂交（dot hybridization），或称斑点印迹法（dot blotting）、点渍法；组织切片或细胞涂片可以直接用于杂交分析，称为原位杂交（in situ hybridization，$\mathrm{ISH}$），如探针以荧光物质为标志物，就称为荧光原位杂交（fluorescence in situ hybridization，$\mathrm{FISH}$）；研究蛋白质与 $\mathrm{DNA}$ 特异结合的 $\mathrm{DNA}$－蛋白质印迹法（Southwestern blotting）；研究蛋白质与 $\mathrm{RNA}$ 特异结合的 $\mathrm{RNA}$－蛋白质印迹法（Northwestern blotting）；检测体外蛋白质与蛋白质的相互作用的蛋白质－蛋白质印迹法（Farwestern blotting）；以及与高通量的芯片技术结合，衍生出了生物芯片（biochip）技术。

:::definition{label="斑点杂交"}
斑点杂交（dot hybridization）：不经电泳分离，直接将样品聚集在 $\mathrm{NC}$ 膜上做杂交。又称斑点印迹法（dot blotting）、点渍法。问的是「有没有这条序列」，不问分子量区带。
:::

:::definition{label="原位杂交与 FISH"}
原位杂交（in situ hybridization，$\mathrm{ISH}$）：组织切片或细胞涂片直接用于杂交，保留形态位置。探针以荧光物质为标志物时，称为荧光原位杂交（fluorescence in situ hybridization，$\mathrm{FISH}$）。
:::

:::definition{label="Southwestern、Northwestern、Farwestern"}
Southwestern blotting：蛋白质与 $\mathrm{DNA}$ 特异结合。Northwestern blotting：蛋白质与 $\mathrm{RNA}$ 特异结合。Farwestern blotting：体外蛋白质与蛋白质的相互作用。三个名字都从三类基本印迹法拼出来，认的已经是「蛋白质结合核酸或蛋白质」，不是基因组分型本身。
:::

:::definition{label="生物芯片由印迹法衍生"}
三类基本印迹法与高通量芯片技术结合，衍生出生物芯片（biochip）技术。下一节把芯片写成印迹法的微型化、集成化，户头在这里已经钉上。
:::

:::keypoint{label="衍生法先问「还电不电泳、还在不在膜上」"}
- 斑点印迹：还在 $\mathrm{NC}$ 膜上，但跳过电泳。
- 原位杂交／$\mathrm{FISH}$：跳过转膜，分子留在切片或涂片原来的位置。
- Southwestern／Northwestern／Farwestern：转膜逻辑还在，识别对换成蛋白－核酸或蛋白－蛋白。
- 生物芯片：把「许多探针点在支持物上」做成微阵列。
:::

:::pitfall{label="FISH 是 ISH 的荧光版，不是另一种印迹膜"}
$\mathrm{FISH}$ 的标志物是荧光，场景仍是组织切片或细胞涂片。不要把 $\mathrm{FISH}$ 答成「荧光 Southern」。
:::

:::pitfall{label="Southwestern 不是 Southern 加 Western 各做一次"}
它研究的是蛋白质与 $\mathrm{DNA}$ 的特异结合，不是先做一张 Southern 再做一张 Western。Northwestern、Farwestern 同样是「一种结合」，不是两种印迹的串联。
:::

:::compare{title="基本印迹 vs 衍生法"}
| 方法 | 还走电泳吗 | 支持物 | 识别 |
|------|------------|--------|------|
| Southern／Northern／Western | 走 | 膜 | 探针或抗体 |
| 斑点杂交 | 不走 | $\mathrm{NC}$ 膜 | 核酸杂交 |
| $\mathrm{ISH}/\mathrm{FISH}$ | 不走转膜 | 切片、涂片 | 核酸杂交（$\mathrm{FISH}$ 用荧光） |
| Southwestern | 蛋白质一侧常仍电泳 | 膜 | 蛋白－$\mathrm{DNA}$ |
| Northwestern | 同上 | 膜 | 蛋白－$\mathrm{RNA}$ |
| Farwestern | 同上 | 膜 | 蛋白－蛋白（体外） |
| 基因／蛋白质芯片 | 样品侧另做标记 | 硅片、玻片等微阵列 | 杂交或亲和 |

衍生不是把三类基本法作废，而是改「聚在哪里、认什么」。
:::

## 三、生物芯片技术源于印迹法的微型化和集成化

生物芯片技术是 $20$ 世纪末发展起来的一项新的规模化生物分子分析技术。广义的生物芯片指一切采用生物技术制备或应用于生物技术的微处理器。包括用于研制生物计算机的生物芯片、将细胞与电子集成电路结合起来的仿生芯片、缩微化的实验室即芯片实验室，以及利用生物分子相互间的特异识别作用进行生物信号处理的各种微阵列（microarray），如基因芯片、蛋白质芯片、细胞／组织／器官芯片等。生物芯片技术已广泛应用于生命科学的众多领域，包括基因表达与突变检测、基因诊断、功能基因组研究等。

:::definition{label="生物芯片技术"}
$20$ 世纪末发展起来的规模化生物分子分析技术，源于印迹法的微型化和集成化。
:::

:::definition{label="广义生物芯片"}
一切采用生物技术制备或应用于生物技术的微处理器。教材列出：研制生物计算机的生物芯片；细胞与电子集成电路结合的仿生芯片；缩微化的实验室即芯片实验室；以及利用分子特异识别做生物信号处理的各种微阵列（microarray）。
:::

:::definition{label="微阵列的几类芯片"}
基因芯片、蛋白质芯片、细胞／组织／器官芯片等，都属于利用分子相互特异识别进行生物信号处理的微阵列。
:::

:::definition{label="生物芯片的应用领域"}
已广泛应用于生命科学众多领域，包括基因表达与突变检测、基因诊断、功能基因组研究等。后文细胞／组织／类器官芯片再补分化、再生医学、疾病模型和药物筛选。
:::

:::pitfall{label="广义生物芯片不等于基因芯片"}
基因芯片只是微阵列里的一种。仿生芯片、芯片实验室、蛋白质芯片、类器官芯片都在广义名单里。考「生物芯片」却只答 $\mathrm{DNA}$ 微阵列，后文蛋白质芯片和类器官芯片会没有上级概念。
:::

:::insight{label="微型化的是印迹，不是另起一套识别化学"}
基因芯片仍是杂交，蛋白质芯片仍是抗原－抗体或受体－配体。变的是把「一张膜上少数区带」做成「支持物上高密度位点」，用荧光扫描和计算机读出。
:::

### （一）基因芯片特别适用于规模化差异表达分析

基因芯片（gene chip）又称 $\mathrm{DNA}$ 微阵列（DNA microarray），是指将大量不同的特定 $\mathrm{DNA}$ 片段有规律地微量点样于硅片或其他支持物上制作成芯片，也可用光导原位合成等微纳加工技术制造芯片，然后与待测的荧光标记样品进行杂交，再用检测系统扫描荧光，通过计算机系统检测每一位点的信号，并比较和分析，从而迅速得出定性和定量的结果。高密度基因芯片可以在 $1\,\mathrm{cm}^{2}$ 面积内有序排列超过百万种不同序列的寡核苷酸探针用于分析，实现了基因信息的大规模并行检测，甚至全基因组分析。

基因芯片特别适用于分析不同组织细胞或同一细胞不同状态下的基因差异表达情况，其原理是基于双色或多色荧光标记样品杂交。例如，将两个不同来源样品的 $\mathrm{mRNA}$ 逆转录合成 $\mathrm{cDNA}$ 时用不同的荧光分子（如正常细胞的用红色的 $\mathrm{Cy}3$、肿瘤细胞的用绿色的 $\mathrm{Cy}5$）标记（图18-2），然后等量混合，再与基因芯片杂交，在两组不同的激发光下检测，根据杂交的荧光信号强度量化比较分析。呈现 $\mathrm{Cy}5$ 荧光的位点代表该基因只在肿瘤组织表达，呈现 $\mathrm{Cy}3$ 信号的位点代表该基因只在正常组织表达，呈现两种荧光互补色的位点则提示该基因在两种组织中均有表达，其他互补色则提示表达差异。

::figure{src="/images/biochemistry/textbook/p0369_01.png" caption="图18-2　基因芯片工作流程示意图。正常细胞 mRNA 经 RT-PCR 荧光标记为红色荧光（Cy3）标记的 cDNA 片段，肿瘤细胞 mRNA 标记为绿色荧光（Cy5）标记的 cDNA 片段；等量混合后与基因芯片杂交，激光扫描后计算机读取。显示器同时给出 Cy5 图像（绿色）、重叠图像（黄色）和 Cy3 图像（红色）。" alt="双色基因芯片流程：正常细胞Cy3红、肿瘤细胞Cy5绿，等量混合后芯片杂交，扫描得绿、黄、红三幅图像"}

:::definition{label="基因芯片"}
基因芯片（gene chip）又称 $\mathrm{DNA}$ 微阵列（DNA microarray）：将大量不同的特定 $\mathrm{DNA}$ 片段有规律地微量点样于硅片或其他支持物上；也可用光导原位合成等微纳加工技术制造。与待测荧光标记样品杂交，扫描荧光，计算机比较各位点信号，迅速得到定性、定量结果。
:::

:::definition{label="高密度基因芯片"}
可在 $1\,\mathrm{cm}^{2}$ 面积内有序排列超过百万种不同序列的寡核苷酸探针，实现大规模并行检测，甚至全基因组分析。
:::

:::definition{label="双色荧光差异表达"}
两个来源的 $\mathrm{mRNA}$ 逆转录合成 $\mathrm{cDNA}$ 时用不同荧光标记，等量混合后与同一张芯片杂交，两组激发光分别检测，按信号强度量化比较。教材例：正常细胞用红色 $\mathrm{Cy}3$，肿瘤细胞用绿色 $\mathrm{Cy}5$。
:::

:::definition{label="Cy3 与 Cy5 位点怎样读"}
呈现 $\mathrm{Cy}5$ 荧光：该基因只在肿瘤组织表达。呈现 $\mathrm{Cy}3$ 信号：该基因只在正常组织表达。两种荧光互补色：两种组织均有表达。其他互补色：提示表达差异。
:::

:::insight{label="图18-2 从两管 mRNA 读到屏幕上的绿、黄、红"}
上排：正常细胞 $\mathrm{mRNA}$ 与肿瘤细胞 $\mathrm{mRNA}$ 分两侧。中间：$\mathrm{RT}$-$\mathrm{PCR}$ 荧光标记，左侧 $\mathrm{cDNA}$ 标「红色荧光（$\mathrm{Cy}3$）」，右侧标「绿色荧光（$\mathrm{Cy}5$）」。等量混合后「芯片杂交」，芯片画成点阵并标注「基因芯片」。下排激光扫描：屏幕三条引出线分别是 $\mathrm{Cy}5$ 图像（绿色）、重叠图像（黄色）、$\mathrm{Cy}3$ 图像（红色），再标「计算机读取」。黄色是红绿重叠，对应正文「两种荧光互补色」「均有表达」。
:::

:::keypoint{label="图18-2 不要把两种颜色对调"}
本版教材把 $\mathrm{Cy}3$ 写成红色、$\mathrm{Cy}5$ 写成绿色，图注与正文一致。读位点时：只绿 $\rightarrow$ 只在肿瘤；只红 $\rightarrow$ 只在正常；黄／互补色 $\rightarrow$ 两边都有。不要按「别的书上 $\mathrm{Cy}5$ 是红」改写本版。
:::

:::pitfall{label="芯片上固定的是已知 DNA，荧光在样品一侧"}
点样或光导原位合成的是特定 $\mathrm{DNA}$ 片段／寡核苷酸探针；$\mathrm{Cy}3/\mathrm{Cy}5$ 标在由 $\mathrm{mRNA}$ 做成的 $\mathrm{cDNA}$ 样品上。把荧光画在芯片探针上，双色比较就没有「两个来源」这一层。
:::

:::pitfall{label="等量混合是和同一张芯片杂交，不是做两张芯片再相减"}
教材写等量混合，再与基因芯片杂交，两组激发光下检测。一张芯片、两种荧光，才能在同一位点上读互补色。
:::

:::pitfall{label="RT-PCR 在图18-2 里只是给 mRNA 变成带荧光的 cDNA"}
图上写「$\mathrm{RT}$-$\mathrm{PCR}$ 荧光标记」。这是为芯片准备样品，不是第二节用来定量 $\mathrm{RNA}$ 的 $\mathrm{RT}$-$\mathrm{PCR}$ 终点产物检测。两种用途都叫逆转录加扩增，本节只取「标记 $\mathrm{cDNA}$」这一段。
:::

:::compare{title="膜上 Northern vs 基因芯片"}
| | Northern | 基因芯片 |
|--|----------|----------|
| 探针／待测谁固定 | 样品 $\mathrm{RNA}$ 在膜上，探针在溶液里 | 大量已知 $\mathrm{DNA}$ 在芯片上，荧光样品在溶液里 |
| 一次看几条 | 探针互补的那一条（或少数几条） | $1\,\mathrm{cm}^{2}$ 可超过百万种寡核苷酸 |
| 比较两个样品 | 常做两张膜或内参半定量 | 双色等量混合，同一张芯片上比 |
| 问的问题 | 这条已知 $\mathrm{RNA}$ 的丰度 | 规模化差异表达，甚至全基因组 |

芯片不是把 Northern 做得很小一张，而是把「谁固定、一次看多少」倒过来。
:::

### （二）蛋白质芯片可用于分析大量蛋白质的表达水平和相互作用

蛋白质芯片（protein chip）是将不同蛋白质分子高度密集、有序排列地固定于固相支持物（如玻璃、塑料或石英片等）上，当与待测样品反应时，可捕获样品中的靶蛋白质等，再经检测系统对捕获的分子进行定性和定量分析。蛋白质芯片的基本原理是分子间的亲和反应，例如抗原－抗体或受体－配体之间等的特异性结合。在用蛋白质芯片检测时，最常见的是将样品中的待测分子标记上荧光，经过荧光标记的待测分子一旦与芯片上的蛋白质结合，就可通过荧光扫描系统获取产生的荧光信号信息，再用计算机系统处理分析。

蛋白质芯片技术具有快速和高通量等特点，它可以对样品中的上千种蛋白质同时进行分析，是蛋白质组学研究的重要手段之一，已广泛应用于蛋白质表达谱、蛋白质功能、蛋白质间相互作用等的研究，在疾病诊断和药物筛选上也已有应用。但由于蛋白质纯化、抗体制备等原因，尚不能像基因芯片那样分析覆盖整个基因组所表达的蛋白质。

:::definition{label="蛋白质芯片"}
蛋白质芯片（protein chip）：把不同蛋白质分子高度密集、有序排列地固定于固相支持物（玻璃、塑料或石英片等）上，捕获样品中的靶蛋白质等，再定性、定量分析。
:::

:::definition{label="蛋白质芯片的识别原理"}
分子间的亲和反应，例如抗原－抗体或受体－配体等特异性结合。不是碱基互补。
:::

:::definition{label="蛋白质芯片最常见的读出"}
样品中待测分子标记荧光；结合芯片上的蛋白质后，荧光扫描取信号，计算机处理分析。
:::

:::definition{label="蛋白质芯片的能力与限度"}
快速、高通量，可对样品中上千种蛋白质同时分析，是蛋白质组学重要手段之一。应用：表达谱、功能、蛋白质间相互作用，以及疾病诊断、药物筛选。限度：因蛋白质纯化、抗体制备等原因，尚不能像基因芯片那样覆盖整个基因组所表达的蛋白质。
:::

:::pitfall{label="上千种不是全蛋白质组"}
教材写「上千种」的同时立刻限制：还不能覆盖整个基因组所表达的蛋白质。把蛋白质芯片答成「蛋白质版全基因组芯片」，纯化与抗体制备那条例外就丢了。
:::

:::pitfall{label="芯片上固定的是蛋白质，荧光仍常在样品一侧"}
与基因芯片对称：支持物上是已知蛋白质，样品待测分子带荧光。不要画成「芯片上的蛋白质自己发光」。
:::

:::compare{title="基因芯片 vs 蛋白质芯片"}
| | 基因芯片 | 蛋白质芯片 |
|--|----------|------------|
| 固定在支持物上的 | 特定 $\mathrm{DNA}$ 片段／寡核苷酸 | 不同蛋白质分子 |
| 支持物举例 | 硅片或其他 | 玻璃、塑料或石英片等 |
| 识别 | 碱基互补杂交 | 抗原－抗体、受体－配体等亲和 |
| 样品标记 | 荧光 $\mathrm{cDNA}$（如 $\mathrm{Cy}3/\mathrm{Cy}5$） | 最常见也是荧光标记待测分子 |
| 规模 | $1\,\mathrm{cm}^{2}$ 可超过百万种探针，可全基因组 | 上千种蛋白质同时分析，尚不能覆盖全基因组表达产物 |
| 特别适合 | 规模化差异表达 | 表达水平与相互作用、蛋白质组学 |

微型化逻辑相同，识别化学从杂交换成亲和，覆盖范围目前也不对等。
:::

### （三）细胞／组织／类器官芯片广泛用于生命科学、医学与药学研究

将一种甚至多种细胞种植于芯片，结合生物反应器、微流控等技术，可以将芯片上的细胞处于模拟组织环境、器官结构、生理活动和疾病状态。将细胞按照特定的方式固定在载体上，即为细胞芯片（cell chip）。若固定的是干细胞，并在化学小分子抑制剂／激动剂、细胞因子、培养基添加剂等作用下得到与相应器官类似组织结构的类器官，则称类器官芯片（organoid-on-a-chip）。而组织芯片（tissue chip）一般是将正常或病理组织切片等按照特定的方式固定在载体上。

细胞／组织／类器官生物芯片将生物学、化学和信息学相结合，已经成为生命科学与医学领域重要工具，广泛应用于细胞分化与代谢、发育与再生医学、建立疾病与损伤模型、药物毒性与功效测试和筛选等多个方面研究。

:::definition{label="细胞芯片"}
细胞芯片（cell chip）：将细胞按特定方式固定在载体上。可种植一种甚至多种细胞，结合生物反应器、微流控等，使芯片上的细胞处于模拟组织环境、器官结构、生理活动和疾病状态。
:::

:::definition{label="类器官芯片"}
类器官芯片（organoid-on-a-chip）：固定的是干细胞，并在化学小分子抑制剂／激动剂、细胞因子、培养基添加剂等作用下，得到与相应器官类似组织结构的类器官。
:::

:::definition{label="组织芯片"}
组织芯片（tissue chip）：一般将正常或病理组织切片等按特定方式固定在载体上。
:::

:::definition{label="细胞／组织／类器官芯片的应用"}
把生物学、化学和信息学相结合，用于细胞分化与代谢、发育与再生医学、建立疾病与损伤模型、药物毒性与功效测试和筛选等。
:::

:::insight{label="这一类芯片上已经是活的体系或切片，不是一条核酸探针"}
基因芯片、蛋白质芯片认的是分子；细胞芯片和类器官芯片要把细胞放进模拟的组织／器官／疾病状态。问「哪条基因表达差异」走基因芯片；问「这块病理切片上有没有」走组织芯片；问「干细胞能不能长出类似器官的结构」走类器官芯片。
:::

:::pitfall{label="类器官芯片不是把器官切片贴到芯片上"}
类器官芯片的起点是干细胞，要加抑制剂／激动剂、细胞因子、培养基添加剂，长出类似器官的组织结构。把器官切片固定在载体上的是组织芯片。两个英文（organoid-on-a-chip vs tissue chip）不要对调。
:::

:::pitfall{label="组织芯片一般是切片，不是培养中的活细胞阵列"}
教材对组织芯片写的是「正常或病理组织切片等」。活细胞种植、微流控模拟生理和疾病状态，是细胞芯片那一句。
:::

:::compare{title="三种「非分子」芯片"}
| | 固定什么 | 还要什么条件 | 典型用途 |
|--|----------|----------------|----------|
| 细胞芯片 | 一种或多种细胞 | 生物反应器、微流控，模拟组织环境／器官结构／生理／疾病 | 分化与代谢、疾病模型、药物测试 |
| 类器官芯片 | 干细胞 | 小分子抑制剂／激动剂、细胞因子、培养基添加剂 $\rightarrow$ 类器官 | 与器官类似结构上的医学、药学研究 |
| 组织芯片 | 正常或病理组织切片 | 按特定方式排列固定 | 病理对照、高通量切片分析 |

与基因／蛋白质芯片合在一起，才是广义微阵列里教材点名的几类。
:::

:::compare{title="本节从膜走到芯片的一条线"}
| 层级 | 支持物 | 一次看多少 | 识别 |
|------|--------|------------|------|
| 三类基本印迹 | $\mathrm{NC}/\mathrm{PVDF}/$尼龙膜 | 少数区带 | 探针或抗体 |
| 斑点／原位 | 膜或切片 | 仍是少量靶 | 杂交 |
| 基因芯片 | 硅片等 | 可达百万探针 | 杂交 |
| 蛋白质芯片 | 玻片等 | 上千种蛋白质 | 亲和 |
| 细胞／组织／类器官芯片 | 载体上的细胞或切片 | 模拟体系或阵列切片 | 不再是单分子杂交 |

规模变大，识别规则按分子类型换，不要全部叫「杂交芯片」。
:::

:::memory{label="本节印迹与探针一张清单"}
- 印迹：接触吸附，大分子从一种介质到另一种介质；毛细、真空吸引、电泳转移；$\mathrm{NC}$、$\mathrm{PVDF}$，固相化用 $80^\circ\mathrm{C}$ 或紫外。
- 核酸探针：已知序列 $+$ 核素／生物素／荧光；寡核苷酸、基因组 $\mathrm{DNA}$、$\mathrm{cDNA}$、$\mathrm{RNA}$ 都可；膜上按互补杂交。
- Southern：限制酶 $+$ 琼脂糖 $+$ 变性 $+$ $\mathrm{NC}$；基因组定性定量、基因编辑、质粒噬菌体。
- Northern：不酶切；$\mathrm{mRNA}$ 和 $\mathrm{ncRNA}$ 丰度；敏感性低于 $\mathrm{PCR}$，特异强、假阳性低。
- Western：$\mathrm{PAGE}$ $+$ 电转 $\mathrm{NC}/\mathrm{PVDF}$；一抗、酶或核素二抗；存在、半定量、相互作用。
- 衍生：斑点、$\mathrm{ISH}/\mathrm{FISH}$、Southwestern、Northwestern、Farwestern、生物芯片。
- 基因芯片：点样或光导原位合成；本版 $\mathrm{Cy}3$ 红（正常）、$\mathrm{Cy}5$ 绿（肿瘤）；等量混合；只红／只绿／互补色。
- 蛋白质芯片：亲和反应，上千种，不能覆盖全基因组表达产物。
- 细胞芯片／类器官芯片（干细胞 $+$ 诱导）／组织芯片（切片）。
:::

:::memory{label="三个英文方位词不要编造发现者"}
- Southern blotting：$\mathrm{Southern}\ \mathrm{E}.$，$1975$ 年。
- Northern blotting：分析 $\mathrm{RNA}$ 的类似技术，不是 Northern 氏。
- Western blotting：蛋白质／免疫印迹，不是 Western 氏。
- Southwestern／Northwestern／Farwestern：蛋白－$\mathrm{DNA}$、蛋白－$\mathrm{RNA}$、体外蛋白－蛋白。
:::
