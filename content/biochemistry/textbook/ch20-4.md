# 第四节　细胞信号转导的基本规律

第三节已经按受体类型把典型途径走完：胞内受体迁移、离子通道改膜电位、$\mathrm{GPCR}$ 的 $\mathrm{G}$ 蛋白循环和小分子信使、蛋白质激酶偶联受体的 $\mathrm{MAPK}$ 级联。本节不再开新的完整受体途径，只立这些途径共用的四条规律：传递与终止是双向反应；转导过程中信号被逐级放大；途径既有通用性又有专一性；途径具有多样性。疾病例子（$\mathrm{TSH}$ 抗体、$\mathrm{RAS}$ 突变、霍乱毒素）留给第五节。

:::concept{term="先问分子怎样把信号传下去又怎样关掉，再问途径为什么既共用又专一"}
看见“细胞信号转导的基本规律”，先不要默写 $\mathrm{EGFR}$ 六步或整章疾病。户头是：每一条途径都由多种信号转导分子组成，不同分子间有序地依次相互作用，上游分子引起下游分子的数量、分布或活性状态变化，从而使信号向下游传递。分子之间的相互作用构成转导的基本机制。小分子以浓度或分布变化为主，蛋白质靠结合／解离或可逆修饰。在这个机制上，再谈级联放大、通用与专一、多样性网络。
:::

每一条信号转导途径都是由多种信号转导分子组成，不同分子间有序地依次进行相互作用，上游分子引起下游分子的数量、分布或活性状态变化，从而使信号向下游传递。信号转导分子之间的相互作用构成了信号转导的基本机制。

:::definition{label="信号转导的基本机制"}
上游分子引起下游分子的数量、分布或活性状态变化，从而使信号向下游传递。途径是多种分子有序依次相互作用，不是单一分子一次反应。
:::

:::keypoint{label="下游变化只有三类账"}
- 数量变化：如 $\mathrm{cAMP}$ 被催化生成而增多。
- 分布变化：如 $\mathrm{Ca}^{2+}$ 从钙库释放到细胞质。
- 活性状态变化：如蛋白质磷酸化，或 $\mathrm{G}$ 蛋白换上 $\mathrm{GTP}$。

问「信号怎样传下去」，先答这三类，再举具体分子。
:::

:::insight{label="规律是从已有途径里抽出来的，不是另开一套分子"}
后文双向反应用的是 $\mathrm{AC}$／磷酸二酯酶、钙泵、$\mathrm{PLC}$／$\mathrm{DAG}$ 激酶；级联用的是 $\mathrm{GPCR}$ 和 $\mathrm{MAPK}$；多样性用的是 $\mathrm{IL}$-$1\beta$、$\mathrm{PDGF}$、趋化因子。分子都在第二、三节出现过，本节问的是「它们怎样组织成规律」。
:::

## 一、信号的传递和终止涉及许多双向反应

信号的传递和终止实际上就是信号转导分子的数量、分布、活性转换的双向反应。如 $\mathrm{AC}$ 催化生成 $\mathrm{cAMP}$ 而传递信号，磷酸二酯酶则将 $\mathrm{cAMP}$ 迅速水解为 $5'$-$\mathrm{AMP}$ 而终止信号传递。以 $\mathrm{Ca}^{2+}$ 为细胞内信使时，$\mathrm{Ca}^{2+}$ 可以从其贮存部位迅速释放，然后又通过细胞 $\mathrm{Ca}^{2+}$ 泵作用迅速恢复初始状态。$\mathrm{PLC}$ 催化 $\mathrm{PIP}_2$ 分解成 $\mathrm{DAG}$ 和 $\mathrm{IP}_3$ 而传递信号，$\mathrm{DAG}$ 激酶和磷酸酶分别催化 $\mathrm{DAG}$ 和 $\mathrm{IP}_3$ 转化而重新合成 $\mathrm{PIP}_2$。对于蛋白质信号转导分子，则是通过与上、下游分子的迅速结合与解离而传递信号或终止信号传递，或者通过磷酸化作用和去磷酸化作用在活性状态和无活性状态之间转换而传递信号或终止信号传递。

:::definition{label="双向反应"}
信号的传递和终止，就是信号转导分子的数量、分布、活性转换的双向反应。有正向把信号写出来，就有反向把信号擦掉。
:::

:::compare{title="小分子的三对开关"}
| 正向（传递） | 反向（终止） | 改的是什么 |
|------------|------------|-----------|
| $\mathrm{AC}$ 催化生成 $\mathrm{cAMP}$ | 磷酸二酯酶水解为 $5'$-$\mathrm{AMP}$ | 数量（浓度） |
| $\mathrm{Ca}^{2+}$ 从贮存部位迅速释放 | $\mathrm{Ca}^{2+}$ 泵迅速恢复初始状态 | 分布 |
| $\mathrm{PLC}$ 把 $\mathrm{PIP}_2$ 切成 $\mathrm{DAG}+\mathrm{IP}_3$ | $\mathrm{DAG}$ 激酶和磷酸酶再合成 $\mathrm{PIP}_2$ | 数量（两种信使）与膜组分再生 |

小分子以浓度或分布的迅速变化为主。正向酶一直开着，反向才能被压住；反向酶一直在，信号才能终止。
:::

:::definition{label="蛋白质转导分子的两种双向"}
①与上、下游分子迅速结合与解离：结合传递，解离终止。②磷酸化与去磷酸化：在活性状态和无活性状态之间转换。蛋白质靠相互作用或可逆修饰，不是靠自己变成小分子。
:::

:::keypoint{label="小分子走浓度／分布，蛋白质走结合或修饰"}
- 小分子信使：浓度升高或分布改变发声，水解酶或泵把它擦掉。
- 蛋白质：结合／解离，或磷酸化／去磷酸化。
- 两条都是双向，不是「只开不关」。
:::

:::cause-effect{title="为什么终止必须写进同一条规律"}
- **因** 细胞内存在相应的反向反应（水解、泵回、再合成、解离、去磷酸化）
- **果** 信号能迅速终止，细胞回到初始状态，才能再接受新的信号

第二节已经写过「只有上游酶持续被激活，小分子信使才能维持在一定浓度」。本节把这句话提升为规律。
:::

:::pitfall{label="不要把双向理解成「先全部传完再全部关掉」"}
传递和终止是同一套分子上的正反向反应，可以同时存在。思考题第 $2$ 问就是在问这件事。写成「刺激来了只传递、刺激撤了才终止」，磷酸二酯酶和蛋白质磷酸酶在刺激期间就没有位置。
:::

:::insight{label="G 蛋白循环也是双向反应的一种写法"}
结合 $\mathrm{GTP}$ 是传递，水解成 $\mathrm{GDP}$、重新装配三聚体是终止。第三节图20-8 左侧括号「可再次接受受体信号」，对的就是回到初始状态。本节不把循环步骤再抄一遍。
:::

:::compare{title="数量、分布、活性：各拿什么当例子"}
| 变化类型 | 小分子例子 | 蛋白质例子 |
|---------|-----------|-----------|
| 数量 | $\mathrm{cAMP}$ 生成／水解；$\mathrm{DAG}$、$\mathrm{IP}_3$ 生成／再合成 $\mathrm{PIP}_2$ | 本节未把「蛋白质数量」当主账，受体数量改变是第五节的病 |
| 分布 | $\mathrm{Ca}^{2+}$ 释放／泵回 | 结合后定位改变（如 $\mathrm{PKC}$ 聚集至质膜）属于活性被打开的前置 |
| 活性 | 小分子本身一般不当「活性蛋白质」 | 磷酸化／去磷酸化；$\mathrm{GTP}/\mathrm{GDP}$ 状态 |

问规律先分这三格，再填分子。
:::

## 二、细胞信号在转导过程中被逐级放大

细胞在对外源信号进行转换和传递时，大都具有信号逐级放大的效应。$\mathrm{G}$ 蛋白偶联受体介导的信号转导过程和蛋白质激酶偶联受体介导的 $\mathrm{MAPK}$ 途径都是典型的级联反应过程。

:::definition{label="逐级放大"}
细胞对外源信号进行转换和传递时，大都具有信号逐级放大的效应。一个上游分子可以激活多个下游分子，信号在传递中被放大。
:::

:::definition{label="本版点名的两套级联"}
①$\mathrm{G}$ 蛋白偶联受体介导的信号转导过程；②蛋白质激酶偶联受体介导的 $\mathrm{MAPK}$ 途径。都是典型的级联反应。不要把级联只记成 $\mathrm{MAPK}$ 三级激酶。
:::

:::insight{label="级联是放大的装置，不是另开一类受体"}
$\mathrm{GPCR}$：一个活化受体可激活多个 $\mathrm{G}$ 蛋白，一个活化 $\mathrm{AC}$ 可生成许多 $\mathrm{cAMP}$，一个 $\mathrm{PKA}$ 催化亚基可磷酸化许多底物。$\mathrm{MAPK}$：$\mathrm{MAPKKK}$ 磷酸化许多 $\mathrm{MAPKK}$，$\mathrm{MAPKK}$ 再磷酸化许多 $\mathrm{MAPK}$。数字不必编造，机制是「上游催化或激活多个下游」。
:::

:::compare{title="GPCR 级联 vs MAPK 级联"}
| | 放大写在哪几级 | 第三节对应画面 |
|--|--------------|--------------|
| $\mathrm{GPCR}$ | 受体 → 多个 $\mathrm{G}$ 蛋白 → 效应酶造出许多小分子信使 → 激酶磷酸化许多底物 | 图20-8 循环可反复；图20-9 左中右三路 |
| $\mathrm{MAPK}$ | $\mathrm{Ras}$-$\mathrm{GTP}$ 启动 $\mathrm{MAPKKK}$ → $\mathrm{MAPKK}$ → $\mathrm{MAPK}$，每一级激酶可磷酸化多个下游 | 图20-10 三大家族 |

两套都是级联，中间信使不一样：$\mathrm{GPCR}$ 常经过小分子，$\mathrm{MAPK}$ 主要是激酶磷酸化激酶。
:::

:::pitfall{label="「大都」不是「全部」"}
教材写「大都具有信号逐级放大的效应」。离子通道型受体把化学信号变成电信号，不是靠三级激酶放大。不要把逐级放大写成所有受体的必经步骤。
:::

:::cause-effect{title="级联怎样接到「快速生理反应」"}
- **因** 每一级都可以作用于多个下游分子
- **果** 少量外源配体就能在细胞内变成大量活化的效应分子，引起快速、明显的细胞应答

第一节开篇把通信写成「通过放大机制引起快速的细胞生理反应」。本节把放大落成级联。
:::

## 三、细胞信号转导途径既有通用性又有专一性

细胞内许多信号转导分子和信号转导途径常常被不同的受体共用，而不是每一个受体都有专用的分子和途径。换言之，细胞的信号转导系统对不同的受体具有通用性。信号转导途径的通用性使得细胞内有限的信号转导分子可以满足多种受体信号转导的需求。另一方面，不同的细胞具有不同的受体，而同样的受体在不同的细胞又可利用不同的信号转导途径，同一信号转导途径在不同细胞中的最终效应蛋白又有所不同。因此，配体－受体－信号转导途径－效应蛋白可以有多种不同组合，而一种特定组合决定了一种细胞对特定的细胞外信号分子产生专一性应答。

:::definition{label="通用性"}
许多信号转导分子和途径常常被不同的受体共用，不是每一个受体都有专用的分子和途径。细胞的信号转导系统对不同的受体具有通用性。有限的分子可以满足多种受体的需求。
:::

:::definition{label="专一性应答"}
配体－受体－信号转导途径－效应蛋白可以有多种不同组合；一种特定组合，决定一种细胞对特定细胞外信号分子产生专一性应答。通用的是零件，专一的是组合。
:::

:::keypoint{label="专一性来自三种「不同」"}
- 不同的细胞具有不同的受体。
- 同样的受体在不同的细胞可利用不同的信号转导途径。
- 同一信号转导途径在不同细胞中的最终效应蛋白又有所不同。

三句都在，专一性才立得住。只背「受体不同所以专一」，后两句就空了。
:::

:::compare{title="通用性 vs 专一性"}
| | 问的是什么 | 本版原句 |
|--|-----------|---------|
| 通用性 | 零件能不能共用 | 分子和途径常常被不同受体共用；有限分子满足多种受体 |
| 专一性 | 某一细胞为什么只给出某一种应答 | 配体－受体－途径－效应蛋白的特定组合 |

不要把通用性答成「所有细胞对同一配体反应相同」——那正好把专一性删掉。第一节受体的「特定的作用模式」是专一性这一边。
:::

:::insight{label="第三节已经给过通用性的例子"}
许多单次跨膜受体可以激活 $\mathrm{Ras}/\mathrm{MAPK}$；甚至 $\mathrm{GPCR}$ 也可以通过调节分子汇入这一途径。$\mathrm{cAMP}$-$\mathrm{PKA}$ 也被胰高血糖素、肾上腺素、促肾上腺皮质激素等不同受体使用。本节把这些现象写成规律。
:::

:::pitfall{label="不要把「有限分子」写成「细胞只有一条途径」"}
通用性是共用，不是只剩一条。后文多样性会立刻说：一种受体可以同时激活几条途径。写成「为了节省所以每人一条」，两小节打架。
:::

:::cause-effect{title="有限分子怎样既够用又专一"}
- **因** 分子和途径可被不同受体共用；受体种类、途径选择、最终效应蛋白又可按细胞而不同
- **果** 有限的转导分子够多种受体使用，而特定组合仍能给出专一性应答
:::

## 四、细胞信号转导途径具有多样性

配体－受体－信号转导分子－效应蛋白并不是以一成不变的固定组合构成信号转导途径，细胞信号转导是复杂的，且具有多样性。这种复杂性和多样性反映在以下几个方面。

:::definition{label="多样性"}
配体－受体－信号转导分子－效应蛋白并不是一成不变的固定组合。途径是复杂的，且具有多样性。下面分五个方面写开。
:::

:::pitfall{label="多样性不是把第三节四类受体再背一遍"}
四类受体是「有哪些典型途径」。多样性问的是：同一信号分子能不能走不同途径、一种受体能不能同时开几条、一个分子能不能参与多条、途径之间能不能互相调节、不同途径能不能落到同一生物学效应。
:::

### （一）一种细胞外信号分子可通过不同信号转导途径影响不同的细胞

一种信号分子在不同靶细胞往往有不同效应。白介素 $1\beta$（$\mathrm{IL}$-$1\beta$）是在局部和全身炎症反应中起核心作用的细胞因子。然而，由于其受体分布广泛，$\mathrm{IL}$-$1\beta$ 的作用并不仅限于炎症。$\mathrm{IL}$-$1\beta$ 可以通过 $\mathrm{G}$ 蛋白偶联受体（涉及 $\mathrm{cAMP}$ 途径、$\mathrm{cGMP}$ 途径、$\mathrm{PKC}$ 途径等）和蛋白质激酶偶联受体介导的 $\mathrm{MAPK}$ 途径传递信号。近年又发现 $\mathrm{IL}$-$1\beta$ 可通过其他几条重要途径介导信号转导，包括：$\mathrm{IL}$-$1$ 受体相关激酶途径、$\mathrm{PI3K}$ 途径、$\mathrm{JAK}$-$\mathrm{STAT}$ 途径、离子通道。$\mathrm{IL}$-$1\beta$ 受体在多种细胞表面存在，受体可通过不同信号转导途径传递信号，它不仅可以作用于各种炎症相关细胞，还可以通过 $\mathrm{JAK}$-$\mathrm{STAT}$ 途径作用于胰岛 $\mathrm{B}$ 细胞，通过激活离子通道影响神经细胞、血管平滑肌细胞、成纤维细胞、骨髓基质细胞等多种细胞的功能。

:::definition{label="一种信号分子可走不同途径"}
一种信号分子在不同靶细胞往往有不同效应。原因可以是受体分布广泛，也可以是同一分子接到不同途径。
:::

:::definition{label="IL-1β 本版点名的途径"}
①经 $\mathrm{GPCR}$：涉及 $\mathrm{cAMP}$ 途径、$\mathrm{cGMP}$ 途径、$\mathrm{PKC}$ 途径等；②经蛋白质激酶偶联受体介导的 $\mathrm{MAPK}$ 途径；③其他：$\mathrm{IL}$-$1$ 受体相关激酶途径、$\mathrm{PI3K}$ 途径、$\mathrm{JAK}$-$\mathrm{STAT}$ 途径、离子通道。名单以本版为准。
:::

:::keypoint{label="IL-1β 不只是炎症因子"}
- 核心作用：局部和全身炎症反应。
- 因受体分布广泛，作用不仅限于炎症。
- 经 $\mathrm{JAK}$-$\mathrm{STAT}$ 作用于胰岛 $\mathrm{B}$ 细胞。
- 经离子通道影响神经细胞、血管平滑肌细胞、成纤维细胞、骨髓基质细胞等。

问「一种胞外信号分子怎样影响不同细胞」，用这一例，不要改写成第五节的肿瘤。
:::

:::compare{title="同一 IL-1β，不同细胞拿走不同途径"}
| 途径 | 本版落到哪些细胞／效应 |
|------|---------------------|
| $\mathrm{GPCR}$（$\mathrm{cAMP}$、$\mathrm{cGMP}$、$\mathrm{PKC}$ 等） | 作为炎症核心作用的通路之一 |
| $\mathrm{MAPK}$ | 蛋白质激酶偶联这一侧 |
| $\mathrm{JAK}$-$\mathrm{STAT}$ | 胰岛 $\mathrm{B}$ 细胞 |
| 离子通道 | 神经细胞、血管平滑肌细胞、成纤维细胞、骨髓基质细胞等 |
| $\mathrm{IL}$-$1$ 受体相关激酶、$\mathrm{PI3K}$ | 点名为其他重要途径 |

「受体分布广泛」和「途径不同」两句话都要有。
:::

:::pitfall{label="不要把 IL-1β 全部画成只走 MAPK"}
教材先写 $\mathrm{GPCR}$ 和 $\mathrm{MAPK}$，再补 $\mathrm{IL}$-$1$ 受体相关激酶、$\mathrm{PI3K}$、$\mathrm{JAK}$-$\mathrm{STAT}$、离子通道。缩成一条途径，本小节的标题就空了。
:::

### （二）受体与信号转导途径有多样性组合

一种受体并非只能激活一条信号转导途径。有些受体自身磷酸化后产生多个与其他蛋白相互作用的位点，可以激活几条信号转导途径。如血小板衍生生长因子（$\mathrm{PDGF}$）的受体激活后，可激活 $\mathrm{Src}$ 激酶活性、结合 $\mathrm{Grb2}$ 并激活 $\mathrm{Ras}$、激活 $\mathrm{PI3K}$、激活 $\mathrm{PLC}\gamma$，因而同时激活多条信号转导途径而引起复杂的细胞应答反应。另一方面，一条信号转导途径也不是只能由一种受体激活，例如，有多种受体可以激活 $\mathrm{PI3K}$ 途径。

:::definition{label="一种受体可同时激活几条途径"}
并非只能激活一条。有些受体自身磷酸化后产生多个与其他蛋白相互作用的位点，可以同时激活几条途径，引起复杂的细胞应答。
:::

:::definition{label="PDGF 受体同时打开的几条"}
激活后可：①激活 $\mathrm{Src}$ 激酶活性；②结合 $\mathrm{Grb2}$ 并激活 $\mathrm{Ras}$；③激活 $\mathrm{PI3K}$；④激活 $\mathrm{PLC}\gamma$。因而同时激活多条途径。
:::

:::definition{label="一条途径也可被多种受体激活"}
例如多种受体可以激活 $\mathrm{PI3K}$ 途径。组合是双向的：一对多，也对多对一。
:::

:::insight{label="EGFR 胞内段多个酪氨酸位点就是这一条的前置"}
第三节已写：$\mathrm{EGFR}$ 除 $\mathrm{Grb2}$ 外还可募集其他含 $\mathrm{SH2}$ 的分子，走 $\mathrm{PLC}$-$\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$ 和 $\mathrm{PI3K}$。本节用 $\mathrm{PDGF}$ 受体把「多个相互作用位点 → 同时几条途径」写成规律。思考题第 $1$ 问对着这一小节。
:::

:::compare{title="一对多 vs 多对一"}
| | 教材例子 | 多样性写在哪一侧 |
|--|---------|----------------|
| 一种受体 → 多条途径 | $\mathrm{PDGF}$ 受体同时开 $\mathrm{Src}$、$\mathrm{Ras}$、$\mathrm{PI3K}$、$\mathrm{PLC}\gamma$ | 受体这一侧分叉 |
| 多种受体 → 一条途径 | 多种受体可激活 $\mathrm{PI3K}$ | 途径这一侧汇合 |

只记分叉不记汇合，通用性那一节也对不上。
:::

:::pitfall{label="不要把 PDGF 四条写成必须按固定顺序逐个开"}
教材是「同时激活多条信号转导途径而引起复杂的细胞应答」。问的是组合多样性，不是再排一条新的六步级联。
:::

### （三）一种信号转导分子可参与多条信号转导途径

$\mathrm{GPCR}$ 主要是促进第二信使产生而调节代谢，因而 $\mathrm{GPCR}$ 一般是在分化成熟的组织细胞参与信号转导。但 $\mathrm{GPCR}$ 在某些增殖细胞中也可表达，在这些细胞中，$\mathrm{G}$ 蛋白的 $\beta\gamma$ 二聚体可激活 $\mathrm{Src}$ 激酶家族（如 $\mathrm{Src}$、$\mathrm{Fyn}$、$\mathrm{Lyn}$ 和 $\mathrm{Yes}$ 蛋白质酪氨酸激酶），后者使 $\mathrm{Shc}$ 的酪氨酸残基磷酸化，形成 $\mathrm{SH2}$ 结合位点，从而与 $\mathrm{Grb2}$ 结合形成 $\mathrm{Shc}$-$\mathrm{Grb2}$ 复合物，通过 $\mathrm{SOS}$、$\mathrm{Ras}$ 蛋白激活 $\mathrm{MAPK}$ 途径，调控细胞增殖所需基因的转录。

:::definition{label="一种分子可参与多条途径"}
同一类信号转导分子不必锁在一条途径里。$\mathrm{GPCR}$ 在成熟组织主要走第二信使调节代谢；在某些增殖细胞里，$\beta\gamma$ 可以接到 $\mathrm{MAPK}$，调控增殖相关基因转录。
:::

:::keypoint{label="GPCR 接到 MAPK 的本版分子顺序"}
$\mathrm{G}$ 蛋白 $\beta\gamma$ 二聚体 → $\mathrm{Src}$ 激酶家族（$\mathrm{Src}$、$\mathrm{Fyn}$、$\mathrm{Lyn}$、$\mathrm{Yes}$）→ $\mathrm{Shc}$ 酪氨酸磷酸化，形成 $\mathrm{SH2}$ 结合位点 → $\mathrm{Shc}$-$\mathrm{Grb2}$ 复合物 → $\mathrm{SOS}$、$\mathrm{Ras}$ → $\mathrm{MAPK}$ 途径。

第三节只说「甚至 $\mathrm{GPCR}$ 也可以通过一些调节分子作用在这一途径」。本节把调节分子写成 $\beta\gamma$ 和 $\mathrm{Src}$ 家族。
:::

:::compare{title="成熟组织里的 GPCR vs 增殖细胞里的 GPCR"}
| | 主要做什么 | 关键分子 |
|--|-----------|---------|
| 分化成熟的组织细胞 | 促进第二信使产生，调节代谢 | $\alpha$ 亚基 → $\mathrm{AC}$／$\mathrm{PLC}$ 等 |
| 某些增殖细胞 | 接到 $\mathrm{MAPK}$，调控增殖所需基因转录 | $\beta\gamma$ → $\mathrm{Src}$ 家族 → $\mathrm{Shc}$-$\mathrm{Grb2}$ → $\mathrm{SOS}$／$\mathrm{Ras}$ |

$\alpha$ 和 $\beta\gamma$ 都可以传信号，不要把 $\beta\gamma$ 只当成定位亚基。
:::

:::pitfall{label="Src 家族四个名字不要用其他书替换"}
本版点名 $\mathrm{Src}$、$\mathrm{Fyn}$、$\mathrm{Lyn}$ 和 $\mathrm{Yes}$。接头是 $\mathrm{Shc}$ 再找 $\mathrm{Grb2}$，不是把第三节 $\mathrm{EGFR}$ 的 $\mathrm{Grb2}$ 直接接到 $\mathrm{GPCR}$ 上而不提 $\mathrm{Shc}$。
:::

:::insight{label="这是「一种分子参与多条途径」，不是新开一类受体"}
$\mathrm{GPCR}$ 还是七次跨膜受体。变的是：在增殖细胞里它使用了 $\beta\gamma$ 和酪氨酸激酶这一套零件，汇入原来属于酶偶联受体的 $\mathrm{MAPK}$ 途径。通用性和多样性在这里叠在一起。
:::

### （四）一条信号转导途径中的功能分子可影响和调节其他途径

细胞内的信号转导途径并不是各自独立存在，不同途径之间存在着多种交互的联系。当一条途径中的信号转导分子对另一条途径中的信号转导分子发挥调节作用时，可对该途径发挥调控作用。下面两个例子可使我们对此有一个初步了解。

:::definition{label="途径之间的交互调节"}
途径并不是各自独立存在，不同途径之间存在着多种交互的联系。一条途径中的分子可以对另一条途径中的分子发挥调节作用。第一节的 cross talking 在这里落到具体例子。
:::

#### 1. Ras/MAPK 途径可调节 Smad 途径

$\mathrm{Ras}/\mathrm{ERK}$ 途径转导的信号可促进细胞增殖，而 $\mathrm{Smad}$ 途径转导的信号则抑制细胞增殖。对于正常上皮细胞，作为维持细胞稳态的 $\mathrm{TGF}$-$\beta$ 占主导地位，并对抗由生长因子经 $\mathrm{Ras}$ 途径激活的增殖反应。然而，当大量的生长因子（如 $\mathrm{EGF}$、$\mathrm{HGF}$）刺激细胞或 $RAS$ 基因激活后，使 $\mathrm{Ras}/\mathrm{ERK}$ 途径激活，活化的 $\mathrm{ERK1/2}$ 蛋白质激酶将 $\mathrm{Smad2/3}$ 等分子的特定位点磷酸化，使 $\mathrm{Smad2/3}$ 向核内聚集的能力减弱，从而削弱了 $\mathrm{Smad}$ 传递信号的作用。此时增殖成为细胞的主要反应。

:::definition{label="Ras/ERK 调节 Smad"}
$\mathrm{Ras}/\mathrm{ERK}$ 促增殖，$\mathrm{Smad}$ 抑增殖。正常上皮细胞以 $\mathrm{TGF}$-$\beta$ 维持稳态，对抗生长因子经 $\mathrm{Ras}$ 途径的增殖。大量 $\mathrm{EGF}$、$\mathrm{HGF}$ 或 $RAS$ 基因激活后，$\mathrm{ERK1/2}$ 磷酸化 $\mathrm{Smad2/3}$ 的特定位点，减弱其向核内聚集，削弱 $\mathrm{Smad}$ 信号，增殖成为主要反应。
:::

:::cause-effect{title="ERK 怎样把 Smad 关掉"}
- **因** 活化的 $\mathrm{ERK1/2}$ 将 $\mathrm{Smad2/3}$ 特定位点磷酸化，使其向核内聚集的能力减弱
- **果** $\mathrm{Smad}$ 传递抑制增殖的信号被削弱，细胞主要表现增殖
:::

:::compare{title="正常上皮 vs 生长因子过强或 RAS 激活"}
| | 占主导的途径 | 细胞主要反应 |
|--|------------|-------------|
| 正常上皮 | $\mathrm{TGF}$-$\beta$／$\mathrm{Smad}$ 对抗 $\mathrm{Ras}$ 增殖 | 维持稳态 |
| 大量 $\mathrm{EGF}$、$\mathrm{HGF}$ 或 $RAS$ 激活 | $\mathrm{Ras}/\mathrm{ERK}$ 压住 $\mathrm{Smad}$ 入核 | 增殖 |

这是途径交叉，不是第五节的肿瘤专论。$RAS$ 激活在这里只作为「使 $\mathrm{Ras}/\mathrm{ERK}$ 途径激活」的条件。
:::

:::pitfall{label="磷酸化 Smad2/3 在这里是削弱，不是激活"}
$\mathrm{ERK1/2}$ 磷酸化的是「特定位点」，效果是减弱向核内聚集。不要写成「磷酸化就一定激活 $\mathrm{Smad}$」。第二节已经立过：磷酸化可激活也可抑制。
:::

#### 2. 蛋白质激酶 C 可调节蛋白质酪氨酸激酶系统

$\mathrm{PKC}$ 是肌醇磷脂系统的重要酶，但它可对蛋白质酪氨酸激酶系统产生调节作用。$\mathrm{PKC}$ 通过磷酸化修饰 $\mathrm{EGF}$ 受体、$\mathrm{Ras}$、$\mathrm{Raf}$-$1$ 等，对 $\mathrm{Ras}/\mathrm{MAPK}$ 途径产生调节作用。

:::definition{label="PKC 调节 Ras/MAPK"}
$\mathrm{PKC}$ 属于肌醇磷脂系统，但可通过磷酸化修饰 $\mathrm{EGF}$ 受体、$\mathrm{Ras}$、$\mathrm{Raf}$-$1$ 等，调节 $\mathrm{Ras}/\mathrm{MAPK}$ 途径。交互作用的方向是「脂类信使那一侧的激酶，改酪氨酸激酶那一侧的分子」。
:::

:::insight{label="两个例子方向不一样"}
- $\mathrm{Ras}/\mathrm{ERK}$ → $\mathrm{Smad}$：生长因子／$\mathrm{MAPK}$ 一侧去压转录因子途径。
- $\mathrm{PKC}$ → $\mathrm{EGF}$ 受体／$\mathrm{Ras}$／$\mathrm{Raf}$-$1$：$\mathrm{GPCR}$ 或 $\mathrm{PLC}$ 一侧去改酶偶联／$\mathrm{MAPK}$ 一侧。

都是「一条途径的功能分子调节另一条」，不要只记一个方向。
:::

:::pitfall{label="不要在这里展开霍乱、TSH 抗体、肢端肥大症"}
交互作用的例子停在 $\mathrm{Smad}$ 和 $\mathrm{PKC}$。受体抗体、细菌毒素、肿瘤增殖是第五节两个层次和疾病表型的账。
:::

### （五）不同信号转导途径可参与调控相同的生物学效应

趋化因子是体内一类能够诱导特定细胞趋化运动的分子。趋化因子受体是一类表达于不同类型细胞上的 $\mathrm{GPCR}$。然而趋化因子可以通过不同的信号转导途径传递信号，如激活 $\mathrm{PKA}$ 途径、调节细胞内 $\mathrm{Ca}^{2+}$ 浓度、$\mathrm{G}$ 蛋白 $\beta\gamma$ 亚单位和磷酸酪氨酰肽协同作用可激活 $\mathrm{PI3K}$ 途径、$\mathrm{MAPK}$ 途径，还可以激活 $\mathrm{JAK}$-$\mathrm{STAT}$ 途径。这些信号途径不同，但都参与调控细胞趋化运动。

:::definition{label="不同途径可落到同一效应"}
途径不同，生物学效应可以相同。趋化因子受体是 $\mathrm{GPCR}$，却可走 $\mathrm{PKA}$、$\mathrm{Ca}^{2+}$、$\mathrm{PI3K}$、$\mathrm{MAPK}$、$\mathrm{JAK}$-$\mathrm{STAT}$ 等，都参与调控细胞趋化运动。
:::

:::keypoint{label="趋化因子本版点名的几条途径"}
- 激活 $\mathrm{PKA}$ 途径。
- 调节细胞内 $\mathrm{Ca}^{2+}$ 浓度。
- $\mathrm{G}$ 蛋白 $\beta\gamma$ 亚单位和磷酸酪氨酰肽协同作用，激活 $\mathrm{PI3K}$ 途径。
- $\mathrm{MAPK}$ 途径。
- $\mathrm{JAK}$-$\mathrm{STAT}$ 途径。

途径不同，效应都是趋化运动。
:::

:::compare{title="（一）与（五）不要并成一句"}
| | 同一的是什么 | 不同的是什么 |
|--|------------|------------|
| （一）一种胞外信号分子 | 信号分子（如 $\mathrm{IL}$-$1\beta$） | 途径和靶细胞、效应都可以不同 |
| （五）不同途径同一效应 | 生物学效应（趋化运动） | 途径不同 |

一个是「一因多果」，一个是「多因一果」。并成「信号转导很复杂」就没有分户。
:::

:::insight{label="βγ 在趋化这条里再次出现"}
（三）里 $\beta\gamma$ 去激活 $\mathrm{Src}$ 家族接 $\mathrm{MAPK}$；（五）里 $\beta\gamma$ 和磷酸酪氨酰肽协同激活 $\mathrm{PI3K}$。都说明 $\beta\gamma$ 不是只能陪 $\alpha$ 亚基坐在膜上。
:::

:::pitfall{label="趋化因子受体不要改写成酶偶联受体"}
教材写明是一类表达于不同类型细胞上的 $\mathrm{GPCR}$。它走 $\mathrm{MAPK}$、$\mathrm{JAK}$-$\mathrm{STAT}$，是多样性，不是把受体类型改掉。
:::

:::compare{title="本节四条规律各自管什么"}
| 规律 | 一句话 | 不要答成 |
|------|--------|---------|
| 双向反应 | 数量／分布／活性都有正反向 | 「刺激来了只开不关」 |
| 逐级放大 | $\mathrm{GPCR}$ 与 $\mathrm{MAPK}$ 都是级联 | 「只有 $\mathrm{MAPK}$ 才放大」 |
| 通用性又有专一性 | 零件共用，组合专一 | 「每个受体一条专用途径」或「所有细胞反应相同」 |
| 多样性 | 组合不固定，五方面展开 | 把整章疾病例子提前写完 |

四条都要能还原，不要只背「网络」一个字。
:::

:::memory{label="本节必背要点"}
- 上游引起下游数量、分布或活性变化，这是转导的基本机制。
- 双向反应：$\mathrm{AC}$／磷酸二酯酶，$\mathrm{Ca}^{2+}$ 释放／泵，$\mathrm{PLC}$ 切 $\mathrm{PIP}_2$／再合成；蛋白质则结合／解离或磷酸化／去磷酸化。小分子以浓度、分布为主，蛋白质靠结合或修饰。
- 逐级放大：$\mathrm{GPCR}$ 过程和 $\mathrm{MAPK}$ 途径都是典型级联。
- 通用性：有限分子被不同受体共用。专一性：配体－受体－途径－效应蛋白的特定组合。
- 多样性五方面：①一种信号分子可走不同途径（$\mathrm{IL}$-$1\beta$）；②一种受体可同时开几条（$\mathrm{PDGF}$），一条途径也可被多种受体激活（$\mathrm{PI3K}$）；③一种分子可参与多条（$\mathrm{GPCR}$ 的 $\beta\gamma$ 接 $\mathrm{MAPK}$）；④途径互相调节（$\mathrm{ERK}$ 压 $\mathrm{Smad}$；$\mathrm{PKC}$ 改 $\mathrm{EGFR}/\mathrm{Ras}/\mathrm{Raf}$-$1$）；⑤不同途径可调控同一效应（趋化因子 → 趋化运动）。
:::
