# 第三节　抑癌基因

第二节把癌基因写成功能获得：原癌基因活化，图23-2 四种机制，生长因子四类产物和四个靶点。本节只写抑癌基因这一户：防止或阻止癌症发生；对增殖起负性调控；失活与原癌基因激活同样重要，但癌基因作用往往是显性，抑癌基因作用往往是隐性。二次打击、单倍体不足、显性负效三户不要并。失活常见三种：基因突变（功能失去）、杂合性丢失、启动子区甲基化。$\mathrm{RB}$ 低磷酸化结合 $\mathrm{E2F}$-$1$ 负调节周期（图23-3）；野生型 $\mathrm{p}53$ 走 $\mathrm{p}21$ 与 $\mathrm{Bax}$（图23-4）；$\mathrm{PTEN}$ 水解 $\mathrm{PIP}_3$ 抑制 $\mathrm{PI3K}$／$\mathrm{AKT}$。结肠癌多步以图23-5 为准：$\mathrm{APC}$ 双拷贝失活 $\rightarrow$ $\mathrm{K}$-$\mathrm{RAS}$ $\rightarrow$ $\mathrm{DCC}$ 双拷贝丢失 $\rightarrow$ $\mathrm{TP}53$ 丢失 $\rightarrow$ 转移；正文六阶段的 $\mathrm{FAP}$／$\mathrm{MCC}$、低甲基化、$\mathrm{NM}23$ 另记，不要改成别的综述顺序。基因诊断和基因治疗是第二十四章，本节不写。

:::concept{term="先问抑癌基因怎样负调控，再问两个等位基因怎样一起失活"}
看见「抑癌基因」，先不要默写靶向药。户头是：防止或阻止癌症发生的基因。部分或全部失活显著增加癌症风险。功能包括抑制增殖、调控细胞周期检查点、促进凋亡、参与 $\mathrm{DNA}$ 损伤修复。原癌基因两个等位基因激活一个就够；抑癌基因往往两个都失活才完全丧失功能——这是二次打击。$\mathrm{p}27^{\mathrm{Kip}1}$ 那种一个拷贝不够用，叫单倍体不足；$\mathrm{TP}53$ 突变蛋白还能压住另一个野生型，叫显性负效。三户机制不同。
:::

抑癌基因也称肿瘤抑制基因（tumor suppressor gene），是防止或阻止癌症发生的基因。与原癌基因活化诱发癌变的作用相反，抑癌基因的部分或全部失活可显著增加癌症的发生风险。抑癌基因对细胞增殖起负性调控作用，包括抑制细胞增殖、调控细胞周期检查点、促进凋亡和参与 $\mathrm{DNA}$ 损伤修复等。

:::definition{label="抑癌基因"}
抑癌基因，也称肿瘤抑制基因（tumor suppressor gene）：防止或阻止癌症发生的基因。部分或全部失活可显著增加癌症发生风险。对增殖起负性调控：抑制增殖、调控细胞周期检查点、促进凋亡、参与 $\mathrm{DNA}$ 损伤修复。
:::

|--|---------|--------|----------------|
| 原癌基因 | 促增殖、抗分化、抗凋亡 | 活化成癌基因 | 功能获得（第二节） |
| 抑癌基因 | 抑增殖、促分化、促凋亡、修 $\mathrm{DNA}$ | 部分或全部失活 | 功能失去；往往要两个等位基因都失活 |

## 一、抑癌基因对细胞增殖起负性调控作用

抑癌基因的发现源于 $20$ 世纪 $60$ 年代 Harris H. 的杂合细胞致癌性研究。他将癌细胞株与正常细胞融合得到的杂合细胞接种动物，发现并不产生肿瘤，提示正常细胞中有能抑制肿瘤发生的基因，即抑癌基因。用化学物质诱发的肿瘤或自发发生的肿瘤的细胞与正常细胞制备杂合细胞也可重复出上述结果，并且与肿瘤的组织起源无关，表明上述结果有普遍意义。将不具致癌性的杂合细胞体外培养传代，可从中分离出具有致癌性的子代细胞。比较两种杂合细胞，发现致癌性的子代杂合细胞丢失了来自正常细胞的一条或几条染色体。将正常人类细胞的单条染色体逐一融合在肿瘤细胞中，也可分离到无致癌性的杂合细胞。这些结果说明细胞中含有各种不同的抑癌基因，分布在不同的染色体上，可以分别抑制不同组织起源的癌细胞的致癌作用。

:::definition{label="杂合细胞实验"}
癌细胞与正常细胞融合得到的杂合细胞接种动物不产生肿瘤，提示正常细胞中有抑癌基因。化学诱发或自发肿瘤与正常细胞融合可重复，且与组织起源无关，有普遍意义。
:::

:::definition{label="致癌性随正常染色体丢失而回来"}
不具致癌性的杂合细胞传代后可分离出致癌性子代；致癌性子代丢失了来自正常细胞的一条或几条染色体。把正常人类细胞的单条染色体逐一融合进肿瘤细胞，也可得到无致癌性杂合细胞。结论：不同抑癌基因分布在不同染色体上，可分别抑制不同组织起源的癌细胞。
:::

:::cause-effect{title="Harris 实验怎样推出抑癌基因"}
- **因** 癌细胞＋正常细胞的杂合子不致瘤
- **果** 正常细胞基因组里有抑制肿瘤发生的基因
- **因** 后来丢掉来自正常细胞的染色体
- **果** 致癌性重新出现
- **因** 单条正常染色体融进去
- **果** 又可分离到无致癌性杂合细胞
:::

:::insight{label="抑癌基因不是只有一个"}
「各种不同的抑癌基因，分布在不同的染色体上，可以分别抑制不同组织起源的癌细胞」。后文表23-3 才把 $\mathrm{TP}53$、$\mathrm{RB}$、$\mathrm{PTEN}$ 等摊开。写成「抑癌基因就是 $\mathrm{p}53$」，杂合细胞实验的普遍意义就丢了。
:::

随着 $20$ 世纪 $70$ 年代基因克隆技术的建立，$\mathrm{RB}$ 和 $\mathrm{TP}53$ 等一系列抑癌基因得以克隆和鉴定。必须指出，最初在某种肿瘤中发现的抑癌基因，并不意味其与别的肿瘤无关；恰恰相反，在多种组织来源的肿瘤细胞中往往可检测出同一抑癌基因的突变、缺失、重排、表达异常等，这正说明抑癌基因的变异构成某些共同的致癌途径。抑癌基因产物的功能多种多样，目前已鉴定的一些抑癌基因产物及其功能如表23-3。总体来说，抑癌基因对细胞增殖起负性调控作用，其编码产物的功能有：抑制细胞增殖；抑制细胞周期进程；调控细胞周期检查点；促进凋亡；参与 $\mathrm{DNA}$ 损伤修复。

:::definition{label="同一抑癌基因可出现在多种肿瘤"}
最初在某种肿瘤中发现，并不意味与别的肿瘤无关。多种组织来源的肿瘤细胞中往往可检出同一抑癌基因的突变、缺失、重排、表达异常。变异构成某些共同的致癌途径。

## 二、抑癌基因有多种失活机制

抑癌基因的失活与原癌基因的激活一样，在肿瘤发生中起着非常重要的作用。但癌基因的作用是显性的，而抑癌基因的作用往往是隐性的。原癌基因的两个等位基因只要激活一个就能发挥促癌作用，而抑癌基因则往往需要两个等位基因都失活才会导致其抑癌功能完全丧失。$1971$ 年，Knudson A. 以视网膜母细胞瘤（retinoblastoma）为模型进行统计学分析研究，发现散发性单侧视网膜母细胞瘤的发病需要抑癌基因（即后来命名为 $\mathrm{RB}$ 的基因）的两次体细胞突变，从而提出二次打击假说（two-hit hypothesis）。

:::definition{label="癌基因显性、抑癌基因往往隐性"}
原癌基因两个等位基因激活一个就能促癌。抑癌基因往往需要两个等位基因都失活，功能才完全丧失。显性／隐性说的是这一层，不是孟德尔遗传病分类课。
:::

:::definition{label="二次打击假说"}
$1971$ 年 Knudson 以视网膜母细胞瘤为模型：散发性单侧视网膜母细胞瘤的发病需要后来命名为 $\mathrm{RB}$ 的基因的两次体细胞突变。两次打击都落在同一个抑癌基因的两个等位基因上。
:::

:::pitfall{label="二次打击不要写成「任意两个基因各打一次」"}
打的是同一抑癌基因的两个拷贝。写成「一个原癌基因加一个抑癌基因」，和后文杂合性丢失、遗传性视网膜母细胞瘤「生来已经挨了一次」就对不上。
:::

但也有一些抑癌基因只失活其等位基因中的一个拷贝就会引起肿瘤发生，也就是说，一个正常的等位基因拷贝不足以完全发挥其抑癌功能，故称为单倍体不足型抑癌基因（haploinsufficient tumor suppressor gene），如 $\mathrm{p}27^{\mathrm{Kip}1}$ 基因。还有一些抑癌基因，如 $\mathrm{TP}53$ 基因，当其一个等位基因突变失活后，其表达的 $\mathrm{p}53$ 突变蛋白能抑制另一个正常等位基因产生的野生型即正常 $\mathrm{p}53$ 蛋白的功能，这种基因突变称为显性负效突变（dominant negative mutation）。

:::definition{label="单倍体不足型抑癌基因"}
只失活一个拷贝就会引起肿瘤发生；一个正常拷贝不足以完全发挥抑癌功能。本版点名 $\mathrm{p}27^{\mathrm{Kip}1}$。这是二次打击的例外，不要并回「必须两个都失活」。
:::

:::definition{label="显性负效突变"}
一个等位基因突变失活后，突变蛋白抑制另一个正常等位基因产生的野生型蛋白的功能。本版点名 $\mathrm{TP}53$。因为 $\mathrm{p}53$ 以四聚体存在，突变亚基可以带坏寡聚体——后文结构那一小节会接到寡聚结构域。
:::

:::compare{title="二次打击 vs 单倍体不足 vs 显性负效"}
| | 一个拷贝失活够不够 | 本版例子 | 和「隐性」那句的关系 |
|--|-------------------|---------|-------------------|
| 二次打击 | 不够，要两个等位基因都失活 | 散发性单侧视网膜母细胞瘤的 $\mathrm{RB}$ | 正例：往往是隐性 |
| 单倍体不足 | 够，一个正常拷贝不足以完全工作 | $\mathrm{p}27^{\mathrm{Kip}1}$ | 例外 |
| 显性负效 | 突变蛋白主动压住野生型 | $\mathrm{TP}53$ | 看起来像「一个就出事」，机制是干扰四聚体，不是剂量不够 |

三户不要并成「抑癌基因都要两次突变」。
:::

抑癌基因失活的方式常见有以下三种。

### （一）基因突变常导致抑癌基因编码的蛋白质功能丧失或降低

抑癌基因发生突变后，会造成其编码的蛋白质功能或活性丧失或降低，进而导致癌变。这种突变属于功能失去突变（loss-of-function mutation）。最典型的例子就是抑癌基因 $\mathrm{TP}53$ 的突变，目前已经发现 $\mathrm{TP}53$ 基因在超过一半以上的人类肿瘤中发生了突变。

:::definition{label="功能失去突变"}
抑癌基因突变后，编码蛋白质功能或活性丧失或降低，属于功能失去突变（loss-of-function mutation）。典型例子 $\mathrm{TP}53$，超过一半以上人类肿瘤中发生突变。后文「$50\%\sim 60\%$ 各系统肿瘤」是同一基因的另一句频率，不要另造数字。
:::

:::compare{title="功能获得 vs 功能失去"}
| | 落在哪一类基因 | 本版典型 |
|--|--------------|---------|
| 功能获得突变 | 原癌基因活化 | $\mathrm{RAS}$ 失 $\mathrm{GTP}$ 酶而持续开；扩增、易位、$\mathrm{LTR}$ |
| 功能失去突变 | 抑癌基因失活 | $\mathrm{TP}53$ 突变后不能再守基因组 |

问「点突变一定是获得还是失去」——看打在哪一类基因上。$\mathrm{RAS}$ 点突变是获得；$\mathrm{TP}53$ 点突变是失去。
:::

### （二）杂合性丢失导致抑癌基因彻底失活

杂合性（heterozygosity）是指同源染色体在一个或一个以上基因座存在不同的等位基因的状态。杂合性丢失（loss of heterozygosity，$\mathrm{LOH}$）则是指一对杂合的等位基因变成纯合状态的现象。杂合性丢失是肿瘤细胞中常见的异常遗传学现象，发生杂合性丢失的区域也往往就是抑癌基因所在的区域。

:::definition{label="杂合性"}
杂合性（heterozygosity）：同源染色体在一个或一个以上基因座存在不同的等位基因。
:::

:::definition{label="杂合性丢失"}
杂合性丢失（loss of heterozygosity，$\mathrm{LOH}$）：一对杂合的等位基因变成纯合状态。肿瘤细胞中常见；发生 $\mathrm{LOH}$ 的区域往往就是抑癌基因所在的区域。
:::

杂合性丢失导致抑癌基因失活的经典实例就是抑癌基因 $\mathrm{RB}$ 的失活。$1986$ 年，将视网膜母细胞瘤的 $\mathrm{RB}$ 基因成功克隆后就发现，$\mathrm{RB}$ 等位基因的一个拷贝往往是通过生殖细胞突变遗传给后代，也就是说，此时后代的体细胞中 $\mathrm{RB}$ 等位基因就呈现为杂合子状态，即：一个为突变失活的不具有抑癌功能的 $\mathrm{RB}$ 等位基因，另一个为仍具有抑癌功能的正常的 $\mathrm{RB}$ 等位基因。而当因为某些原因导致正常的 $\mathrm{RB}$ 等位基因丢失即杂合性丢失时，抑癌基因 $\mathrm{RB}$ 则彻底失活，失去其抑癌作用，从而导致视网膜母细胞瘤发生。

:::definition{label="遗传性视网膜母细胞瘤的 LOH"}
一个 $\mathrm{RB}$ 拷贝经生殖细胞突变遗传，体细胞一开始就是杂合（一坏一好）。随后正常拷贝丢失（$\mathrm{LOH}$），$\mathrm{RB}$ 彻底失活。这是「生来已经挨了一次打击，体细胞再丢一次」。
:::

:::compare{title="散发性二次打击 vs 遗传性 LOH"}
| | 第一次 | 第二次 |
|--|--------|--------|
| 散发性单侧（Knudson 原句） | 体细胞突变 | 再一次体细胞突变 |
| 遗传性（$1986$ 克隆后） | 生殖细胞突变，全身细胞开始即杂合 | 正常等位基因丢失（$\mathrm{LOH}$） |

都是同一基因的两个拷贝。遗传性把第一次提前到种系，对着第一节「种系突变 → 遗传性肿瘤综合征」。
:::

### （三）启动子区甲基化导致抑癌基因表达抑制

真核生物基因启动子区域 $\mathrm{CpG}$ 岛的甲基化修饰对于调节基因转录活性至关重要，甲基化程度与基因表达呈负相关。很多抑癌基因的启动子区 $\mathrm{CpG}$ 岛呈高度甲基化（hypermethylation）状态，从而导致相应的抑癌基因不表达或低表达。例如，约 $70\%$ 的散发性肾癌患者中存在抑癌基因 $\mathrm{VHL}$ 启动子区甲基化失活现象；在家族性腺瘤息肉所致的结肠癌中，$\mathrm{APC}$ 基因启动子区因高度甲基化使转录受到抑制，导致 $\mathrm{APC}$ 基因失活，进而引起 $\beta$-连环蛋白在细胞内的积累，从而促进癌变发生。

:::definition{label="启动子区高度甲基化"}
启动子 $\mathrm{CpG}$ 岛甲基化程度与基因表达呈负相关。高度甲基化（hypermethylation）使抑癌基因不表达或低表达。序列可以还在，转录被关掉。
:::

:::definition{label="VHL 与 APC 的甲基化例子"}
约 $70\%$ 散发性肾癌：$\mathrm{VHL}$ 启动子区甲基化失活。家族性腺瘤息肉所致结肠癌：$\mathrm{APC}$ 启动子高度甲基化 → 转录抑制 → $\mathrm{APC}$ 失活 → $\beta$-连环蛋白积累 → 促进癌变。图23-5 画的是 $\mathrm{APC}$ 双拷贝失活，甲基化是失活方式之一，不要用甲基化替换双拷贝失活那一格。
:::

:::compare{title="三种失活方式"}
| 方式 | 分子上改了什么 | 本版例子 |
|------|--------------|---------|
| 基因突变 | 蛋白质功能或活性丧失／降低（功能失去） | $\mathrm{TP}53$，超过一半以上人类肿瘤 |
| 杂合性丢失 | 杂合变成纯合，剩下的好拷贝没了 | 遗传性 $\mathrm{RB}$ |
| 启动子甲基化 | 基因还在，转录被关掉 | $\mathrm{VHL}$ 约 $70\%$ 散发性肾癌；$\mathrm{APC}$ 家族性腺瘤息肉结肠癌 |

问「失活有哪些方式」答这三种。问「二次打击、单倍体不足、显性负效」那是等位基因剂量／干涉的账，不要和这三种方式并成一张表。
:::

:::keypoint{label="失活机制收回来"}
- 癌基因显性（一个等位基因够）；抑癌基因往往隐性（两个都要失活）。
- 二次打击：散发性单侧视网膜母细胞瘤，两次体细胞突变。
- 例外：单倍体不足（$\mathrm{p}27^{\mathrm{Kip}1}$）；显性负效（$\mathrm{TP}53$）。
- 三种方式：功能失去突变、$\mathrm{LOH}$、启动子高度甲基化。
:::

## 三、抑癌基因在癌症发生发展中具有重要作用

抑癌基因的失活在肿瘤发生发展中发挥着重要作用，此处以 $\mathrm{TP}53$、$\mathrm{RB}$、$\mathrm{PTEN}$ 三个抑癌基因为例，简要介绍抑癌基因的作用机制。本版先写 $\mathrm{RB}$ 的周期关卡，再写 $\mathrm{TP}53$ 的损伤应答与凋亡，再写 $\mathrm{PTEN}$ 的磷酸酶；不要改成外部综述的另一种顺序。

### （一）RB 主要通过调控细胞周期检查点而发挥其抑癌功能

$\mathrm{RB}$ 基因失活不仅与视网膜母细胞瘤及骨肉瘤有关，在许多散发性肿瘤，如 $50\%\sim 85\%$ 的小细胞性肺癌、$10\%\sim 30\%$ 乳腺癌、膀胱癌和前列腺癌中都发现有 $\mathrm{RB}$ 基因失活。

:::definition{label="RB 失活的肿瘤谱"}
不仅视网膜母细胞瘤及骨肉瘤。散发性：$50\%\sim 85\%$ 小细胞性肺癌；$10\%\sim 30\%$ 乳腺癌、膀胱癌和前列腺癌。
:::

$\mathrm{RB}$ 基因位于染色体 $13\mathrm{q}14$，有 $27$ 个外显子，$\mathrm{mRNA}$ 长 $4.7\,\mathrm{kb}$，编码的蛋白质为 $105\,\mathrm{kDa}$。$\mathrm{RB}$ 蛋白的磷酸化状态及其与其他蛋白质结合，与它的功能密切相关。去磷酸化（或低磷酸化）形式为活性型，能促进细胞分化，抑制细胞增殖。实验表明，将 $\mathrm{RB}$ 基因导入视网膜母细胞瘤细胞或成骨肉瘤细胞，这些恶性细胞的生长受到抑制。

:::definition{label="RB 基因与蛋白的本版参数"}
定位 $13\mathrm{q}14$；$27$ 个外显子；$\mathrm{mRNA}$ $4.7\,\mathrm{kb}$；蛋白质 $105\,\mathrm{kDa}$（表23-3 写作转录因子 $\mathrm{p}105\mathrm{RB}$）。低磷酸化／去磷酸化为活性型：促分化、抑增殖。导入视网膜母细胞瘤或成骨肉瘤细胞可抑制其生长。
:::

:::pitfall{label="低磷酸化才是活性型，不要写成磷酸化越多越抑癌"}
活性型是去磷酸化或低磷酸化。后文高磷酸化的 $\mathrm{RB}$ 不能结合 $\mathrm{E2F}$-$1$，关卡放开。把「磷酸化的 $\mathrm{RB}$」答成抑癌活性形式，图23-3 下半的释放 $\mathrm{E2F}$ 就画反了。
:::

$\mathrm{RB}$ 的磷酸化程度受细胞周期中增殖调控蛋白质的直接控制，包括随着细胞周期不同时相的转换，其浓度也随之发生变化的细胞周期蛋白（cyclin），以及受到这些蛋白质调节的蛋白激酶。这些蛋白激酶被称为细胞周期蛋白依赖性激酶（cyclin-dependent kinase，$\mathrm{CDK}$）。细胞进入 $\mathrm{G}_1$ 期时 $\mathrm{RB}$ 处于低磷酸化状态，而低磷酸化的 $\mathrm{RB}$ 使得细胞不能通过 $\mathrm{G}_1/\mathrm{S}$ 期检查点（checkpoint）。该检查点是哺乳动物细胞周期的重要检查点，只有通过该检查点后，细胞周期才能进入下一步运转，进行 $\mathrm{DNA}$ 合成和细胞分裂，故又称为限制点（restriction point），以符号「$\mathrm{R}$」表示。只有在细胞增殖信号通过依赖于 cyclin $\mathrm{D}1$ 的激酶 $\mathrm{CDK}4$ 的活化导致 $\mathrm{RB}$ 磷酸化后，高磷酸化的 $\mathrm{RB}$ 方允许细胞跨过 $\mathrm{G}_1/\mathrm{S}$ 期检查点。因此，低磷酸化的 $\mathrm{RB}$ 在 $\mathrm{G}_1$ 期特异的磷酸化是细胞从 $\mathrm{G}_1$ 期进入 $\mathrm{S}$ 期的关键。

:::definition{label="G1/S 检查点即限制点 R"}
低磷酸化 $\mathrm{RB}$ 使细胞不能通过 $\mathrm{G}_1/\mathrm{S}$ 检查点。该检查点又称限制点（restriction point），符号「$\mathrm{R}$」。只有增殖信号经 cyclin $\mathrm{D}1$-$\mathrm{CDK}4$ 把 $\mathrm{RB}$ 磷酸化后，高磷酸化 $\mathrm{RB}$ 才允许跨过。低磷酸化 $\mathrm{RB}$ 在 $\mathrm{G}_1$ 期被特异磷酸化，是 $\mathrm{G}_1\rightarrow\mathrm{S}$ 的关键。
:::

低磷酸化的 $\mathrm{RB}$ 对细胞周期的负调节作用是通过与转录因子 $\mathrm{E2F}$-$1$ 的结合而实现的（图23-3）。低磷酸化 $\mathrm{RB}$ 的口袋结构域能结合 $\mathrm{E2F}$-$1$ 并使之失活，$\mathrm{S}$ 期必需的基因产物如二氢叶酸还原酶、胸苷激酶、$\mathrm{DNA}$ 聚合酶 $\alpha$ 等的合成因而受限，细胞周期的进展受到抑制。而高磷酸化的 $\mathrm{RB}$ 不能与 $\mathrm{E2F}$-$1$ 结合，将导致这些基因的开放，促进细胞通过 $\mathrm{G}_1$-$\mathrm{S}$ 关卡。$\mathrm{RB}$ 基因的缺失使得细胞丧失了该关卡的「守卫」，细胞周期进程失控，细胞异常增殖。

:::definition{label="低磷酸化 RB 结合 E2F-1"}
负调节通过与转录因子 $\mathrm{E2F}$-$1$ 结合实现。低磷酸化 $\mathrm{RB}$ 的口袋结构域结合 $\mathrm{E2F}$-$1$ 并使之失活；$\mathrm{S}$ 期必需产物（二氢叶酸还原酶、胸苷激酶、$\mathrm{DNA}$ 聚合酶 $\alpha$ 等）合成受限。高磷酸化 $\mathrm{RB}$ 不能结合 $\mathrm{E2F}$-$1$，基因开放，通过 $\mathrm{G}_1$-$\mathrm{S}$。$\mathrm{RB}$ 缺失＝关卡守卫丢失。
:::

### （二）TP53 主要通过调控 DNA 损伤应答和诱发细胞凋亡而发挥其抑癌功能

$\mathrm{TP}53$ 基因是目前研究最多，也是迄今发现在人类肿瘤中发生突变最广泛的抑癌基因。$50\%\sim 60\%$ 的人类各系统肿瘤中发现有 $\mathrm{TP}53$ 基因突变。

人的 $\mathrm{TP}53$ 基因定位于 $17\mathrm{p}13$，全长 $16\sim 20\,\mathrm{kb}$，含有 $11$ 个外显子，转录 $2.8\,\mathrm{kb}$ 的 $\mathrm{mRNA}$，编码蛋白为 $\mathrm{p}53$，具有转录因子活性。$\mathrm{TP}53$ 基因是迄今为止发现的与人类肿瘤相关性最高的基因。过去一直把它当成一种癌基因，直至 $1989$ 年才知道起癌基因作用的是突变的 $\mathrm{p}53$，后来证实野生型 $\mathrm{p}53$ 是一种抑癌基因。

:::definition{label="TP53 基因本版参数"}
定位 $17\mathrm{p}13$；全长 $16\sim 20\,\mathrm{kb}$；$11$ 个外显子；$2.8\,\mathrm{kb}$ $\mathrm{mRNA}$。$50\%\sim 60\%$ 各系统肿瘤有突变；超过一半以上人类肿瘤——与「功能失去」那一句是同一基因。与人类肿瘤相关性最高。
:::

:::definition{label="1989 年才分清突变型与野生型"}
过去当成癌基因；直到 $1989$ 年才知道起癌基因作用的是突变的 $\mathrm{p}53$，野生型 $\mathrm{p}53$ 是抑癌基因。显性负效那一户解释为什么突变体可以「看起来像癌基因」。
:::

$\mathrm{TP}53$ 基因的表达产物 $\mathrm{p}53$ 蛋白由 $393$ 个氨基酸残基构成，在体内以四聚体形式存在。$\mathrm{p}53$ 蛋白属于转录因子，包含有典型的转录激活结构域、$\mathrm{DNA}$ 结合结构域、寡聚结构域、富含脯氨酸区和核定位序列等多个结构域或序列，这也是 $\mathrm{p}53$ 发挥其生物学功能的分子结构基础。多数 $\mathrm{TP}53$ 基因突变都发生在编码其 $\mathrm{DNA}$ 结合结构域的序列中。

:::definition{label="p53 的结构域"}
$393$ 个氨基酸；体内四聚体。结构域：转录激活结构域、$\mathrm{DNA}$ 结合结构域、寡聚结构域、富含脯氨酸区、核定位序列。多数突变落在 $\mathrm{DNA}$ 结合结构域。图23-4 上沿画的是转录激活、$\mathrm{DNA}$ 结合、寡聚三块。
:::

:::insight{label="四聚体解释显性负效"}
一个突变亚基可以掺进四聚体，干扰野生型功能。这就是前面「显性负效突变」的结构基础。寡聚结构域不是装饰。
:::

正常情况下，细胞中 $\mathrm{p}53$ 蛋白含量很低，因其半衰期只有 $20\sim 30\,\mathrm{min}$，所以很难检测出来，但在细胞增殖与生长时，可升高 $5\sim 100$ 倍以上。野生型 $\mathrm{p}53$ 蛋白在维持细胞正常生长、抑制恶性增殖中起着重要作用，因而被冠以「基因组卫士」称号。当细胞受电离辐射或化学试剂等作用导致 $\mathrm{DNA}$ 损伤时，$\mathrm{p}53$ 表达水平迅速升高，同时 $\mathrm{p}53$ 蛋白中包含的一些丝氨酸残基被磷酸化修饰而被活化。活化的 $\mathrm{p}53$ 从细胞质移位至细胞核内，调控大量下游靶基因的转录而发挥其生物学功能。例如，$\mathrm{p}53$ 的靶基因之一 $\mathrm{p}21$ 可阻止细胞通过 $\mathrm{G}_1/\mathrm{S}$ 期检查点，使其停滞于 $\mathrm{G}_1$ 期；另一靶基因 $\mathrm{GADD}45$ 的产物是 $\mathrm{DNA}$ 修复蛋白。这就使 $\mathrm{DNA}$ 受损的细胞不再分裂，并且修复损伤以维持基因组的稳定性。如果修复失败，$\mathrm{p}53$ 蛋白就会通过激活一些靶基因如 $\mathrm{BAX}$ 的转录而启动细胞凋亡，阻止有癌变倾向的突变细胞的生成。$\mathrm{p}53$ 突变后，则 $\mathrm{DNA}$ 损伤不能得到有效修复并不断累积，导致基因组不稳定，进而导致肿瘤发生（图23-4）。

:::definition{label="基因组卫士"}
野生型 $\mathrm{p}53$ 维持正常生长、抑制恶性增殖。正常含量很低，半衰期仅 $20\sim 30\,\mathrm{min}$；增殖与生长时可升高 $5\sim 100$ 倍以上。$\mathrm{DNA}$ 损伤时水平迅速升高，丝氨酸磷酸化而活化，从胞质入核。
:::

:::definition{label="野生型 p53 的三条下游"}
①$\mathrm{p}21$：阻止通过 $\mathrm{G}_1/\mathrm{S}$，停滞于 $\mathrm{G}_1$。②$\mathrm{GADD}45$：$\mathrm{DNA}$ 修复蛋白。③修复失败则激活 $\mathrm{BAX}$ 等，启动凋亡。图23-4 画了 $\mathrm{p}21$ 与 $\mathrm{Bax}$ 两路；$\mathrm{GADD}45$ 是正文补上的修复支路，不要因为图上没画就删掉。
:::

:::definition{label="突变型 p53"}
$\mathrm{DNA}$ 损伤不能有效修复并不断累积 → 基因组不稳定 → 肿瘤发生。图23-4 右侧：功能失活 → 损伤累积 → 基因组不稳定 → 细胞癌变。
:::

::figure{src="/images/biochemistry/textbook/p0473_01.png" caption="图23-4　p53 的结构与功能" alt="上方结构条：转录激活结构域、DNA结合结构域、寡聚结构域。左侧野生型p53在DNA损伤后经p21使细胞周期阻滞并修复后重启，经Bax诱导细胞凋亡。中间箭头为基因突变到突变型p53。右侧突变型p53功能失活，DNA损伤不断累积，基因组不稳定，细胞癌变"}

:::compare{title="图23-4 野生型 vs 突变型"}
| | $\mathrm{DNA}$ 损伤之后 | 出口 |
|--|-------------------|------|
| 野生型 $\mathrm{p}53$ | $\mathrm{p}21$ → 周期阻滞 → 修复 → 周期重启；$\mathrm{Bax}$ → 凋亡 | 基因组被守住 |
| 突变型 $\mathrm{p}53$ | 功能失活 | 损伤累积 → 基因组不稳定 → 细胞癌变 |

问「野生型走哪两条」答 $\mathrm{p}21$ 与 $\mathrm{Bax}$（正文再加 $\mathrm{GADD}45$）。问「多数突变打在哪」答 $\mathrm{DNA}$ 结合结构域。
:::

:::pitfall{label="不要把 p53 只答成促凋亡"}
先阻滞（$\mathrm{p}21$）、再修复（$\mathrm{GADD}45$），修失败才凋亡（$\mathrm{BAX}$）。写成「$\mathrm{p}53$ 就是自杀开关」，$\mathrm{G}_1$ 停滞和修复那两户就没有了。
:::

### （三）PTEN 主要通过抑制 PI3K/AKT 信号通路而发挥其抑癌功能

$\mathrm{PTEN}$ 基因（phosphatase and tensin homolog deleted on chromosome ten，第 $10$ 号染色体缺失的磷酸酶及张力蛋白同源基因）是继 $\mathrm{TP}53$ 基因后发现的另一个与肿瘤发生关系密切的抑癌基因。人的 $\mathrm{PTEN}$ 基因定位于 $10\mathrm{q}23.3$，共有 $9$ 个外显子和 $8$ 个内含子，编码 $5.15\,\mathrm{kb}$ 的 $\mathrm{mRNA}$，$\mathrm{PTEN}$ 蛋白由 $403$ 个氨基酸残基组成，分子量约 $56\,\mathrm{kDa}$。$\mathrm{PTEN}$ 主要包括如下 $3$ 个结构功能域：

:::definition{label="PTEN 基因本版参数"}
全称：第 $10$ 号染色体缺失的磷酸酶及张力蛋白同源基因。定位 $10\mathrm{q}23.3$；$9$ 外显子、$8$ 内含子；$5.15\,\mathrm{kb}$ $\mathrm{mRNA}$；$403$ 氨基酸，约 $56\,\mathrm{kDa}$。继 $\mathrm{TP}53$ 后另一个与肿瘤发生关系密切的抑癌基因。
:::

**（1）N 端磷酸酶结构区（$1\sim 185$）**　由第 $5$ 外显子编码，与蛋白酪氨酸磷酸酶及蛋白质丝／苏氨酸磷酸酶催化区的核心模体（$\mathrm{HCXXGXGRXG}$）同源，是 $\mathrm{PTEN}$ 发挥肿瘤抑制活性的主要功能区。$\mathrm{PTEN}$ 的 $\mathrm{N}$ 端 $175$ 个氨基酸序列可与整联蛋白（integrin）、酪氨酸激酶、黏着斑激酶（focal adhesion kinase，$\mathrm{FAK}$）等形成复合物，共同参与细胞生长的调节。此外，$\mathrm{PTEN}$ 还能与肌动蛋白纤维细丝局部黏附，在肿瘤浸润、转移、血管生成中也起一定的作用。

:::definition{label="N 端磷酸酶区"}
残基 $1\sim 185$，第 $5$ 外显子编码。核心模体 $\mathrm{HCXXGXGRXG}$，肿瘤抑制活性的主要功能区。$\mathrm{N}$ 端 $175$ 氨基酸可与整联蛋白、酪氨酸激酶、$\mathrm{FAK}$ 成复合物；并能与肌动蛋白纤维细丝局部黏附，参与浸润、转移、血管生成。
:::

**（2）C2 区（$186\sim 351$）**　介导蛋白质与脂类的结合。$\mathrm{PTEN}$ 通过 $\mathrm{C}2$ 区结合于膜磷脂，参与 $\mathrm{PTEN}$ 在胞膜的有效定位和胞内的细胞信号转导。与其他信号蛋白不同，这一结合过程不需要 $\mathrm{Ca}^{2+}$ 参与。磷酸酶区和 $\mathrm{C}2$ 区之间有广泛的相互作用界面，提示 $\mathrm{C}2$ 区可能同样具有催化作用。已有实验证实，对 $\mathrm{C}2$ 区进行诱变，可导致 $\mathrm{PTEN}$ 的肿瘤抑制活性降低。

:::definition{label="C2 区"}
残基 $186\sim 351$，结合膜磷脂，参与膜定位和信号转导。不需要 $\mathrm{Ca}^{2+}$。与磷酸酶区有广泛界面；诱变可降低肿瘤抑制活性。
:::

**（3）C 端区**　由羧基端的 $50$ 个氨基酸残基组成，包括 $\mathrm{PDZ}$（$\mathrm{PSD}$-$95$/$\mathrm{Dlg}$/$\mathrm{ZOI}$ 同源区）结合序列（$\mathrm{Thr}$/$\mathrm{Ser}$-$\mathrm{X}$-$\mathrm{Val}$-$\mathrm{COOH}$）和 $2$ 个 $\mathrm{PEST}$ 序列（$350\sim 375$，$376\sim 396$），对于调节自身的稳定性和酶活性具有重要作用。研究表明 $\mathrm{PEST}$ 序列与蛋白质降解有关，$\mathrm{PDZ}$ 结合位点与细胞生长调控有关。$\mathrm{PDZ}$ 区在肿瘤的发生中也可以缺失突变，虽不影响磷酸酶功能，但对肿瘤细胞锚定非依赖性生长的抑制作用显著降低。

:::definition{label="C 端 PDZ 与 PEST"}
羧基端 $50$ 氨基酸。$\mathrm{PDZ}$ 结合序列：$\mathrm{Thr}$/$\mathrm{Ser}$-$\mathrm{X}$-$\mathrm{Val}$-$\mathrm{COOH}$。两个 $\mathrm{PEST}$：$350\sim 375$，$376\sim 396$。$\mathrm{PEST}$ 管降解，$\mathrm{PDZ}$ 管生长调控。$\mathrm{PDZ}$ 缺失突变可不影响磷酸酶功能，但显著降低对锚定非依赖性生长的抑制。
:::

$\mathrm{PTEN}$ 是迄今发现的第一个具有双特异（dual specificity）磷酸酶活性的抑癌基因，其编码产物 $\mathrm{PTEN}$ 具有磷脂酰肌醇-$3,4,5$-三磷酸 $3$-磷酸酶活性，催化水解磷脂酰肌醇-$3,4,5$-三磷酸（$\mathrm{PIP}_3$）的 $3$-磷酸成为 $\mathrm{PIP}_2$，而 $\mathrm{PIP}_3$ 是胰岛素、表皮生长因子等细胞生长因子的信号转导分子，从而抑制 $\mathrm{PI3K}$/$\mathrm{Akt}$ 信号通路，起到负性调节细胞生长增殖的作用。$\mathrm{PTEN}$ 也能催化黏着斑激酶（$\mathrm{FAK}$）的去磷酸化反应，而抑制由整联蛋白介导的细胞铺展和迁移，因而 $\mathrm{PTEN}$ 的失活也与肿瘤细胞的转移密切相关。

:::definition{label="双特异磷酸酶：水解 PIP3 抑制 PI3K/AKT"}
第一个具有双特异磷酸酶活性的抑癌基因。把 $\mathrm{PIP}_3$ 的 $3$-磷酸水解成 $\mathrm{PIP}_2$，从而抑制 $\mathrm{PI3K}$/$\mathrm{Akt}$，负调节生长增殖。图23-1 通路格子里的 $\mathrm{PI3K}$／$\mathrm{AKT}$ 对着这一句。
:::

:::definition{label="FAK 去磷酸化抑制迁移"}
催化 $\mathrm{FAK}$ 去磷酸化，抑制整联蛋白介导的铺展和迁移。失活与肿瘤细胞转移密切相关。脂质底物和蛋白底物是两户，不要只背 $\mathrm{PIP}_3$。
:::

:::compare{title="RB vs p53 vs PTEN"}
| | 本版主职 | 关键分子动作 | 失活后 |
|--|---------|-------------|--------|
| $\mathrm{RB}$ | $\mathrm{G}_1/\mathrm{S}$ 关卡 | 低磷酸化结合 $\mathrm{E2F}$-$1$ | 关卡无守卫，周期失控 |
| $\mathrm{p}53$ | 损伤应答与凋亡 | 野生型走 $\mathrm{p}21$、$\mathrm{GADD}45$、$\mathrm{Bax}$ | 损伤累积，基因组不稳定 |
| $\mathrm{PTEN}$ | 负调节 $\mathrm{PI3K}$／$\mathrm{AKT}$ | $\mathrm{PIP}_3\rightarrow\mathrm{PIP}_2$；$\mathrm{FAK}$ 去磷酸化 | 增殖失控；迁移／转移增强 |

问「周期关卡」看 $\mathrm{RB}$；问「基因组卫士」看 $\mathrm{p}53$；问「$\mathrm{PIP}_3$」看 $\mathrm{PTEN}$。
:::

:::keypoint{label="三个抑癌基因机制"}
- $\mathrm{RB}$：$13\mathrm{q}14$，$105\,\mathrm{kDa}$；低磷酸化活性型结合 $\mathrm{E2F}$-$1$；$\mathrm{D}1$-$\mathrm{CDK}4$ 磷酸后过 $\mathrm{R}$ 点。
- $\mathrm{p}53$：$17\mathrm{p}13$，$393$ 氨基酸，四聚体；结构域含转录激活／$\mathrm{DNA}$ 结合／寡聚；野生型 $\mathrm{p}21$ 与 $\mathrm{Bax}$（加 $\mathrm{GADD}45$）；多数突变在 $\mathrm{DNA}$ 结合域。
- $\mathrm{PTEN}$：$10\mathrm{q}23.3$，双特异磷酸酶；$\mathrm{PIP}_3\rightarrow\mathrm{PIP}_2$ 抑 $\mathrm{PI3K}$／$\mathrm{AKT}$；去磷酸 $\mathrm{FAK}$ 抑迁移。
:::

## 四、癌症发生发展涉及癌基因和抑癌基因的共同参与

目前普遍认为肿瘤的发生与发展是多个原癌基因和抑癌基因突变累积的结果，经过起始、启动、促进和癌变几个阶段逐步演化而产生。

:::definition{label="多基因突变累积、四阶段演化"}
多个原癌基因和抑癌基因突变累积。阶段：起始、启动、促进和癌变。对着开篇「多病因、多基因、多阶段」，不是单基因一步癌变。
:::

### （一）肿瘤发生发展涉及多种相关基因的改变

在基因水平上，或通过外界致癌因素，或由于细胞内环境的恶化，突变基因数目增多，基因组变异逐步扩大；在细胞水平上则要经过永生化、分化逆转、转化等多个阶段，细胞周期失控的生长特性逐步得到强化。结果是相关组织从增生、异型变、良性肿瘤、原位癌发展到浸润癌和转移癌。例如，结肠癌的发生发展过程涉及数种基因的变化（图23-5）。

:::definition{label="基因水平与细胞水平并行"}
基因水平：突变基因数目增多，基因组变异扩大。细胞水平：永生化、分化逆转、转化，周期失控被强化。组织结局：增生 → 异型变 → 良性肿瘤 → 原位癌 → 浸润癌 → 转移癌。
:::

### （二）细胞周期和细胞凋亡的调控异常是肿瘤进展的关键

**1. 原癌基因和抑癌基因是调控细胞周期进程的重要基因**　细胞周期调控体现在细胞周期驱动和细胞周期监控两个方面，后者的失控与肿瘤发生发展的关系最为密切。细胞周期监控机制由 $\mathrm{DNA}$ 损伤感应机制、细胞生长停滞机制、$\mathrm{DNA}$ 修复机制和细胞命运决定机制等构成。细胞一旦发生 $\mathrm{DNA}$ 损伤或复制错误，将会启动 $\mathrm{DNA}$ 损伤应激机制（见第二十一章），经由各种信号转导途径使细胞停止生长，修复损伤的 $\mathrm{DNA}$。如果 $\mathrm{DNA}$ 损伤得到完全修复，细胞周期可进入下一个时相，正常完成一个细胞分裂周期；倘若 $\mathrm{DNA}$ 损伤修复失败，细胞凋亡机制将被启动，损伤细胞进入凋亡，从而避免 $\mathrm{DNA}$ 损伤带到子代细胞，维持了组织细胞基因组的稳定性，避免肿瘤发生的潜在可能。

:::definition{label="周期调控的驱动与监控"}
驱动和监控两方面。与肿瘤关系最密切的是监控失控。监控由损伤感应、生长停滞、$\mathrm{DNA}$ 修复、细胞命运决定构成。
:::

:::cause-effect{title="损伤之后监控怎样分流"}
- **因** 损伤被完全修复
- **果** 进入下一时相，完成分裂周期
- **因** 修复失败
- **果** 启动凋亡，避免把损伤带到子代，维持基因组稳定
:::

肿瘤细胞的最基本特征是细胞的失控性增殖，而失控性增殖的根本原因就是细胞周期调控机制的破坏，包括驱动机制和监控机制的破坏。监控机制破坏可发生在损伤感应、生长停滞、$\mathrm{DNA}$ 修复和凋亡机制的任何一个环节上，结果将导致细胞基因组不稳定，突变基因数量增加，这些突变的基因往往就是癌基因和抑癌基因。同时，很大一部分的原癌基因和抑癌基因又是细胞周期调控机制的组成部分。

因此，在肿瘤发展过程中，监控机制的异常会使细胞周期调控机制进一步恶化，并导致细胞周期驱动机制的破坏，细胞周期的驱动能力异常强化，细胞进入失控性生长状态，从而细胞出现癌变性生长。

:::insight{label="监控坏了既制造突变，突变又落在调控基因上"}
监控破坏 → 基因组不稳定 → 癌基因和抑癌基因突变增多；而这些基因很大一部分本身就是周期调控的零件。恶性循环：监控异常 → 驱动被强化 → 失控性生长。$\mathrm{RB}$ 是关卡零件，$\mathrm{p}53$ 是监控零件，不要把它们写成周期外面的旁观者。
:::

**2. 原癌基因和抑癌基因还是调控细胞凋亡的重要基因**　细胞除了生长、增殖和分化等之外，还存在细胞死亡现象，如程序性细胞死亡或凋亡。有些抑癌基因的过量表达可诱导细胞发生凋亡，而与细胞生存相关的原癌基因的激活则可抑制凋亡，细胞凋亡异常与肿瘤的发生发展密切相关。现已明确，细胞凋亡在肿瘤发生、胚胎发育、免疫反应、肿瘤免疫逃逸、神经系统发育、组织细胞代谢等过程中起重要作用。

:::definition{label="凋亡这一户的正反"}
有些抑癌基因过量表达可诱导凋亡；与生存相关的原癌基因激活可抑制凋亡。野生型 $\mathrm{p}53$ 走 $\mathrm{Bax}$ 是前一路；第一节原癌基因「抵抗凋亡」是后一路。
:::

:::pitfall{label="凋亡异常不是只有「该死的不死」"}
教材把凋亡写进肿瘤发生、胚胎发育、免疫、肿瘤免疫逃逸、神经系统发育、组织细胞代谢。写成「凋亡＝抗癌」，免疫逃逸和发育那几户就没有对象。
:::

值得注意的是，近年来的研究也发现，一些非编码 $\mathrm{RNA}$ 在肿瘤发生过程中也具有重要作用。总之，肿瘤分子生物学的进展已经深刻地改变了人们对肿瘤发生和生命现象的认识，并使肿瘤研究从以揭示肿瘤病因和寻找肿瘤治疗方法为目的的单项研究，转变为以研究整个生命现象和全面揭示生命分子机制为目的的综合性系统研究。肿瘤分子生物学必将在整个生命医学研究中发挥越来越重要的作用。

:::memory{label="本节必背分户"}
- 抑癌基因防止或阻止癌症；负性调控（抑增殖、管检查点、促凋亡、修 $\mathrm{DNA}$）。癌基因显性（一个等位基因够），抑癌基因往往隐性（两个都要失活）。
- 二次打击：散发性单侧视网膜母细胞瘤，同一 $\mathrm{RB}$ 两次体细胞突变。单倍体不足：$\mathrm{p}27^{\mathrm{Kip}1}$。显性负效：突变 $\mathrm{p}53$ 压住野生型。
- 失活三种：功能失去突变（$\mathrm{TP}53$ 过半）、$\mathrm{LOH}$（遗传性 $\mathrm{RB}$）、启动子高度甲基化（$\mathrm{VHL}$ 约 $70\%$ 散发性肾癌；$\mathrm{APC}$ → $\beta$-连环蛋白积累）。
- $\mathrm{RB}$：低磷酸化结合 $\mathrm{E2F}$-$1$ 负调节；$\mathrm{D}1$-$\mathrm{CDK}4$ 磷酸后过限制点 $\mathrm{R}$。图23-3 还有 $\mathrm{E}$-$\mathrm{CDK}2$。
- $\mathrm{p}53$：转录激活／$\mathrm{DNA}$ 结合／寡聚结构域；野生型走 $\mathrm{p}21$ 与 $\mathrm{Bax}$（正文加 $\mathrm{GADD}45$）；突变型功能失活 → 癌变。图23-4。
- $\mathrm{PTEN}$：双特异磷酸酶，$\mathrm{PIP}_3\rightarrow\mathrm{PIP}_2$ 抑 $\mathrm{PI3K}$／$\mathrm{AKT}$；去磷酸 $\mathrm{FAK}$ 抑迁移。
- 图23-5：$\mathrm{APC}$ 双拷贝失活 → $\mathrm{K}$-$\mathrm{RAS}$ → $\mathrm{DCC}$ 双拷贝丢失 → $\mathrm{TP}53$ 丢失 → 转移。正文六阶段另记 $\mathrm{FAP}$／$\mathrm{MCC}$、低甲基化、$\mathrm{NM}23$，不要改图序。

:::memory{label="本章小结"}
- 癌症泛指一切恶性肿瘤。外因始动、内因基础。癌细胞有与正常细胞显著不同的多种生物学特征（遗传组成、增殖失控、Warburg、接触抑制与微环境、血管生成、侵袭转移）。
- 癌基因导致恶性转化。绝大多数由原癌基因突变或过表达而来，某些病毒也携带。活化是功能获得：基因突变、基因扩增、染色体易位、获得启动子或增强子。图23-2 四格为 $\mathrm{K}$-$\mathrm{Ras}$ 失 $\mathrm{GTP}$ 酶、$\mathrm{N}$-$\mathrm{MYC}$ 扩增、$\mathrm{BCR}$-$\mathrm{ABL}$、$\mathrm{LTR}$-$\mathrm{C}$-$\mathrm{MYC}$。
- 生长因子多为肽或蛋白质，经受体跨膜信号转导调节生长分化；原癌基因产物涉及因子、受体、胞内分子、核内转录因子。
- 抑癌基因防止癌症，失活增加风险。失活方式包括基因突变、杂合性丢失和启动子甲基化。肿瘤发生发展是多个原癌基因和抑癌基因突变累积的结果，经起始、启动、促进和癌变逐步演化。结肠癌以图23-5 的 $\mathrm{APC}\rightarrow\mathrm{K}$-$\mathrm{RAS}\rightarrow\mathrm{DCC}\rightarrow\mathrm{TP}53\rightarrow$ 转移为序。
:::
