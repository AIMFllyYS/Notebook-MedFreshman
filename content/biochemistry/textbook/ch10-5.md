# 第五节　其他氧化与抗氧化体系

前四节把线粒体呼吸链写成产能机器：电子交给氧生成水，质子梯度写成 $\mathrm{ATP}$。本节写同一条链的另一面：单电子漏给氧，得到反应活性氧（$\mathrm{ROS}$）；再写超氧化物歧化酶、过氧化氢酶和谷胱甘肽把 $\mathrm{ROS}$ 清掉。线粒体以外，需氧脱氢酶、不需氧脱氢酶和细胞色素 $\mathrm{P}450$ 单加氧酶另做氧化修饰，不走氧化磷酸化这本账。章末收全章小结和思考题。

:::concept{term="先问电子是漏给氧还是交给复合体Ⅳ，再问清的是超氧、H2O2 还是羟自由基"}
呼吸链末端本应 $4$ 步把 $\mathrm{O}_2$ 写成 $\mathrm{H}_2\mathrm{O}$。漏出的单电子先写成超氧阴离子，再写成过氧化氢和羟自由基，合称 $\mathrm{ROS}$。清除顺序：$\mathrm{SOD}$ 处理超氧，过氧化氢酶和 $\mathrm{GPx}$ 处理 $\mathrm{H}_2\mathrm{O}_2$。过氧化物酶体、内质网的氧化是改底物，不是另做一套 $\mathrm{ATP}$。
:::

线粒体呼吸链存在单电子传递过程，单电子也有机会“漏出”直接传递给氧而生成活性氧组分，而不是通过呼吸链传递给氧生成水。因此呼吸链也是产生活性氧、引起细胞氧化损伤的原因之一，机体也有相应的保护防御机制。除了线粒体氧化体系外，细胞内也存在其他的氧化体系，主要参与物质的生物氧化。

:::definition{label="呼吸链漏电子"}
呼吸链有单电子传递。漏出的电子可直接交给氧，生成活性氧，而不是经复合体Ⅳ把氧彻底还原成水。呼吸链因此既是产能装置，也是氧化损伤的来源之一。
:::

:::insight{label="产能和产 ROS 是同一条链的两本账"}
第四节 $\mathrm{mtDNA}$ 脆弱，部分原因就在旁边不断有漏电子。第五节把“副产物”立户，再写抗氧化酶把账抹平。不要把 $\mathrm{ROS}$ 写成与呼吸链无关的外源毒物。
:::

## 一、线粒体氧化呼吸链可产生反应活性氧

呼吸链在传递电子的过程中，由于将漏出的电子直接交给氧，产生部分被还原的氧，产生了反应活性氧类（reactive oxygen species，$\mathrm{ROS}$）（图10-19）这样的“副产物”。$\mathrm{O}_2$ 得到单电子产生超氧阴离子（$\cdot\mathrm{O}_2^{-}$），再逐步接受电子而生成过氧化氢 $\mathrm{H}_2\mathrm{O}_2$、羟自由基（$\cdot\mathrm{OH}$），这些未被完全还原的含氧分子，合称为 $\mathrm{ROS}$。

:::note{label="电子版缺失"}
教材第 $213$ 页图10-19　$\mathrm{ROS}$ 的主要类型电子版图源 `p0242_01.png` 为 $0$ 字节，不嵌入 `src`。全页扫描 `p0242_page.png` 混有第四节正文，不作本图。图注顺序：$\mathrm{O}_2$ 得单电子 $\rightarrow\cdot\mathrm{O}_2^{-}$；再得电子加 $2\mathrm{H}^{+}\rightarrow\mathrm{H}_2\mathrm{O}_2$；再得电子加 $\mathrm{H}^{+}\rightarrow\cdot\mathrm{OH}$（同时可放出 $\mathrm{H}_2\mathrm{O}$）；再得电子加 $\mathrm{H}^{+}\rightarrow\mathrm{H}_2\mathrm{O}$。
:::

:::definition{label="ROS"}
反应活性氧类（reactive oxygen species，$\mathrm{ROS}$）是未被完全还原的含氧分子，为呼吸链漏电子的“副产物”。主要包括超氧阴离子（$\cdot\mathrm{O}_2^{-}$）、过氧化氢（$\mathrm{H}_2\mathrm{O}_2$）和羟自由基（$\cdot\mathrm{OH}$）。
:::

$$
\mathrm{O}_2\xrightarrow{e^{-}}\cdot\mathrm{O}_2^{-}\xrightarrow{e^{-}+2\mathrm{H}^{+}}\mathrm{H}_2\mathrm{O}_2\xrightarrow{e^{-}+\mathrm{H}^{+}}\cdot\mathrm{OH}\xrightarrow{e^{-}+\mathrm{H}^{+}}\mathrm{H}_2\mathrm{O}
$$

:::timeline{period="氧逐步被还原"}
- **超氧** O2 得 1 个电子 → 超氧阴离子
- **过氧化氢** 再得电子并加 2 个质子 → H2O2
- **羟自由基** 再得电子并加质子 → 羟自由基（可同时放出水）
- **水** 再得电子并加质子 → H2O（呼吸链正常终点）
:::

:::pitfall{label="ROS 不是分子氧本身，也不是呼吸链正常产物水"}
$\mathrm{O}_2$ 在复合体Ⅳ被彻底还原成 $\mathrm{H}_2\mathrm{O}$，那是产能账。$\mathrm{ROS}$ 是半路上漏出来的部分还原产物，氧化性远大于 $\mathrm{O}_2$。把“用氧”和“活性氧损伤”并成一句，抗氧化体系就没有对立面。
:::

### （一）电子传递过程也产生反应活性氧

**1. 线粒体的呼吸链是产生 ROS 的主要部位**　呼吸链在传递电子的过程中，由于将漏出的电子直接交给氧，产生部分被还原的氧，所以得到 $\mathrm{ROS}$ 这样的“副产物”，特别是 $\cdot\mathrm{O}_2^{-}$ 的产生主要源自呼吸链。例如，复合体Ⅲ中通过 $\mathrm{Q}$ 循环传递电子，接受单电子的 $\mathrm{QH}\cdot$ 在内膜中自由移动，通过非酶促反应直接将单电子泄漏给 $\mathrm{O}_2$ 而生成 $\cdot\mathrm{O}_2^{-}$。呼吸链末端的细胞色素 $c$ 氧化酶从金属离子每次转移 $1$ 个电子、通过 $4$ 步单电子转移将氧彻底还原生成水，也会有少量氧接受单电子或双电子而生成 $\cdot\mathrm{O}_2^{-}$ 和 $\mathrm{H}_2\mathrm{O}_2$。另外，复合体Ⅱ等也可产生 $\mathrm{ROS}$。

:::definition{label="呼吸链是 ROS 的主要来源"}
$\cdot\mathrm{O}_2^{-}$ 主要源自呼吸链漏电子。复合体Ⅲ的 $\mathrm{Q}$ 循环中，半醌 $\mathrm{QH}\cdot$ 可在内膜自由移动，非酶促把单电子漏给 $\mathrm{O}_2$。复合体Ⅳ虽按 $4$ 步单电子把氧写成水，仍有少量氧只接到 $1$ 或 $2$ 个电子。复合体Ⅱ等也可产生 $\mathrm{ROS}$。
:::

:::compare{title="哪些复合体容易漏"}
| 部位 | 机制印象 | 主要产物 |
|------|----------|----------|
| 复合体Ⅲ（$\mathrm{Q}$ 循环） | 单电子载体 $\mathrm{QH}\cdot$ 在内膜移动，非酶促漏给 $\mathrm{O}_2$ | $\cdot\mathrm{O}_2^{-}$ |
| 复合体Ⅳ（细胞色素 $c$ 氧化酶） | 金属离子每次 $1$ 个电子，$4$ 步才把氧写成水；少量氧中途脱离 | $\cdot\mathrm{O}_2^{-}$、$\mathrm{H}_2\mathrm{O}_2$ |
| 复合体Ⅱ等 | 亦可产生 $\mathrm{ROS}$ | 教材点名，不另开清单 |
:::

:::insight{label="Q 既能传双电子也能传单电子，漏就发生在单电子态"}
第二节：泛醌可经半醌 $\cdot\mathrm{QH}$ 做单、双电子传递。本节：正是这个半醌在内膜里乱跑时把电子交给氧。$\mathrm{Q}$ 循环的灵活，是漏超氧的结构原因。
:::

:::pitfall{label="复合体Ⅳ不是“绝对不漏”"}
教材写它“通常”把强氧化性中间物绑在双核中心上（第二节），本节补：仍有少量氧只接到单电子或双电子。思考题问“哪些复合体容易产生 $\mathrm{ROS}$”，答案至少包括Ⅲ，并写Ⅳ和Ⅱ，不要只背一个位点。
:::

**2. 某些氧化酶也产生 ROS**　除呼吸链外，细胞质中的黄嘌呤氧化酶（xanthine oxidase）需要氧为底物，能催化次黄嘌呤氧化为黄嘌呤和 $\mathrm{H}_2\mathrm{O}_2$；位于线粒体外膜的单胺氧化酶（monoamine oxidase，$\mathrm{MAO}$）催化多种胺类进行氧化脱氨产生 $\mathrm{H}_2\mathrm{O}_2$ 等，但这些酶催化产生的 $\mathrm{ROS}$ 远低于线粒体呼吸链。另外，细菌感染、组织缺氧等病理过程，电离辐射、吸烟、药物等外源因素也可导致细胞产生大量的 $\mathrm{ROS}$。

:::definition{label="黄嘌呤氧化酶与单胺氧化酶"}
黄嘌呤氧化酶（xanthine oxidase）在细胞质，以氧为底物，催化次黄嘌呤氧化为黄嘌呤并产生 $\mathrm{H}_2\mathrm{O}_2$。单胺氧化酶（monoamine oxidase，$\mathrm{MAO}$）在线粒体外膜，催化胺类氧化脱氨产生 $\mathrm{H}_2\mathrm{O}_2$。二者产 $\mathrm{ROS}$ 远低于呼吸链。
:::

:::compare{title="ROS 的来源分层"}
| 层次 | 例子 | 相对贡献 |
|------|------|----------|
| 主要 | 线粒体呼吸链（尤其 $\cdot\mathrm{O}_2^{-}$） | 远高于下面两行 |
| 酶 | 黄嘌呤氧化酶、单胺氧化酶 | 远低于呼吸链 |
| 病理／外源 | 细菌感染、组织缺氧；电离辐射、吸烟、药物 | 可导致大量 $\mathrm{ROS}$ |
:::

:::note{label="第九章胺氧化酶在这里会合"}
第九章：胺氧化酶把胺写成醛、$\mathrm{NH}_3$ 和 $\mathrm{H}_2\mathrm{O}_2$，肝活性最高。本节点名的是线粒体外膜 $\mathrm{MAO}$。产物 $\mathrm{H}_2\mathrm{O}_2$ 进抗氧化账，不是呼吸链漏电子那一笔。
:::

### （二）反应活性氧的蓄积会引发细胞损伤或死亡

$\mathrm{ROS}$ 是未被完全还原的含氧分子，化学性质活泼，氧化性远远大于 $\mathrm{O}_2$，因此 $\mathrm{ROS}$ 水平升高会导致细胞功能受损。$\mathrm{ROS}$ 通过线粒体内膜的离子通道等方式释放到细胞质等，对细胞的功能产生广泛的影响。少量的 $\mathrm{ROS}$ 能够促进细胞增殖等，但 $\mathrm{ROS}$ 的大量累积会损伤细胞功能，甚至会导致细胞死亡。

例如，线粒体基质中的顺乌头酸酶，其 $\mathrm{Fe}$-$\mathrm{S}$ 易被 $\cdot\mathrm{O}_2^{-}$ 氧化而丧失功能，直接影响柠檬酸循环的功能。$\cdot\mathrm{O}_2^{-}$ 可迅速氧化一氧化氮（$\mathrm{NO}$）产生过氧亚硝酸盐（$\mathrm{ONOO}^{-}$，也属于 $\mathrm{ROS}$），后者能使脂质氧化、蛋白质硝基化而损伤细胞膜和膜蛋白质。羟自由基等可直接氧化蛋白质、核酸，进而破坏细胞的正常结构和功能。线粒体一方面通过消耗氧用于产生 $\mathrm{ATP}$ 供能，另一方面也会产生 $\mathrm{ROS}$ 而损伤自身及细胞等。因此，生物进化已使机体发展了有效的抗氧化体系及时清除 $\mathrm{ROS}$，防止其累积产生有害影响。

:::definition{label="ROS 的双重作用"}
少量 $\mathrm{ROS}$ 能促进细胞增殖等；大量累积则损伤细胞功能，甚至导致死亡。氧化性远大于 $\mathrm{O}_2$，可经内膜离子通道等到细胞质。
:::

:::compare{title="教材点名的几条损伤"}
| 分子 | 靶 | 后果 |
|------|----|------|
| $\cdot\mathrm{O}_2^{-}$ | 顺乌头酸酶的 $\mathrm{Fe}$-$\mathrm{S}$ | 酶失活，柠檬酸循环受阻 |
| $\cdot\mathrm{O}_2^{-}$ | $\mathrm{NO}$ | 生成 $\mathrm{ONOO}^{-}$（也属 $\mathrm{ROS}$） |
| $\mathrm{ONOO}^{-}$ | 脂质、蛋白质 | 脂质氧化、蛋白质硝基化，伤膜和膜蛋白 |
| $\cdot\mathrm{OH}$ 等 | 蛋白质、核酸 | 破坏正常结构与功能 |
:::

:::definition{label="过氧亚硝酸盐"}
过氧亚硝酸盐（$\mathrm{ONOO}^{-}$）由 $\cdot\mathrm{O}_2^{-}$ 迅速氧化一氧化氮（$\mathrm{NO}$）生成，属于 $\mathrm{ROS}$。能使脂质氧化、蛋白质硝基化，损伤细胞膜和膜蛋白质。
:::

:::pitfall{label="少量 ROS 不是“有益就可以不管”"}
教材承认少量促进增殖，紧接着写大量累积损伤甚至死亡。抗氧化体系的存在本身说明稳态要的是清除，不是堆积。思考题“$\mathrm{ROS}$ 有哪些作用”应两面都写。
:::

:::insight{label="顺乌头酸酶被打，三羧酸循环先停"}
第七章：顺乌头酸酶把柠檬酸经顺乌头酸写成异柠檬酸，含 $\mathrm{Fe}$-$\mathrm{S}$。超氧专打这个铁硫中心，等于在循环内部断电。线粒体既产 $\mathrm{ATP}$ 又产 $\mathrm{ROS}$ 伤自己，所以必须有下一节的酶。
:::

:::cause-effect{title="为什么必须有抗氧化体系"}
- **因** 呼吸链边耗氧产 $\mathrm{ATP}$，边漏电子产 $\mathrm{ROS}$；$\mathrm{ROS}$ 可伤循环酶、膜脂、蛋白质和核酸
- **果** 进化出抗氧化酶和小分子清除剂，及时清除，防止累积
:::

## 二、抗氧化体系清除反应活性氧

体内存在的各种抗氧化酶、小分子抗氧化剂等，形成了重要的防御体系以对抗 $\mathrm{ROS}$ 的副作用。

### （一）抗氧化酶清除超氧阴离子

广泛分布的超氧化物歧化酶（superoxide dismutase，$\mathrm{SOD}$），可催化 $1$ 分子 $\cdot\mathrm{O}_2^{-}$ 氧化生成 $\mathrm{O}_2$，另一分子 $\cdot\mathrm{O}_2^{-}$ 还原生成 $\mathrm{H}_2\mathrm{O}_2$，$2$ 个相同的底物歧化产生了 $2$ 个不同的产物：

$$
2\cdot\mathrm{O}_2^{-}+2\mathrm{H}^{+}\rightarrow\mathrm{H}_2\mathrm{O}_2+\mathrm{O}_2
$$

哺乳动物细胞有 $3$ 种 $\mathrm{SOD}$ 同工酶，在细胞质中的 $\mathrm{SOD}$，其活性中心含 $\mathrm{Cu}/\mathrm{Zn}$ 离子，称 $\mathrm{Cu}/\mathrm{Zn}$-$\mathrm{SOD}$；线粒体中的 $\mathrm{SOD}$ 活性中心含 $\mathrm{Mn}^{2+}$，称 $\mathrm{Mn}$-$\mathrm{SOD}$。$\mathrm{SOD}$ 是人体防御内、外环境中超氧离子损伤的重要酶。$\mathrm{Cu}/\mathrm{Zn}$-$\mathrm{SOD}$ 基因缺陷使 $\cdot\mathrm{O}_2^{-}$ 不能及时清除而损伤神经元，可引起肌萎缩性侧索硬化症等疾病。

:::definition{label="SOD"}
超氧化物歧化酶（superoxide dismutase，$\mathrm{SOD}$）催化两分子 $\cdot\mathrm{O}_2^{-}$ 歧化：一分子被氧化成 $\mathrm{O}_2$，一分子被还原成 $\mathrm{H}_2\mathrm{O}_2$。是防御超氧损伤的重要酶。
:::

:::compare{title="哺乳动物 SOD 同工酶"}
| 同工酶 | 部位 | 活性中心 |
|--------|------|----------|
| $\mathrm{Cu}/\mathrm{Zn}$-$\mathrm{SOD}$ | 细胞质 | $\mathrm{Cu}/\mathrm{Zn}$ |
| $\mathrm{Mn}$-$\mathrm{SOD}$ | 线粒体 | $\mathrm{Mn}^{2+}$ |
| 第三种 | 教材写共 $3$ 种，上两行点名部位与金属 | — |
:::

:::definition{label="Cu/Zn-SOD 与肌萎缩性侧索硬化症"}
$\mathrm{Cu}/\mathrm{Zn}$-$\mathrm{SOD}$ 基因缺陷使 $\cdot\mathrm{O}_2^{-}$ 不能及时清除而损伤神经元，可引起肌萎缩性侧索硬化症等疾病。
:::

:::pitfall{label="SOD 的产物仍是 ROS，不是终点"}
歧化把超氧写成 $\mathrm{H}_2\mathrm{O}_2$ 和 $\mathrm{O}_2$。$\mathrm{H}_2\mathrm{O}_2$ 还要过氧化氢酶或谷胱甘肽过氧化物酶接着拆。把 $\mathrm{SOD}$ 写成“彻底解毒”，后面两小节没有户头。
:::

:::insight{label="歧化是两个相同底物变成两个不同产物"}
不是“超氧加氢就变水”。一分子被氧化、一分子被还原，这才叫歧化。记反应式时左右都是两分子超氧。
:::

### （二）抗氧化酶分解过氧化氢

过氧化氢酶（catalase）分解 $\mathrm{H}_2\mathrm{O}_2$ 产生 $\mathrm{H}_2\mathrm{O}$ 和 $\mathrm{O}_2$。过氧化氢酶主要存在于过氧化酶体中，含有 $4$ 个血红素辅基，催化活性强，每秒可催化超过 $40\,000$ 底物分子转变为产物。其催化反应如下：

$$
2\mathrm{H}_2\mathrm{O}_2\rightarrow 2\mathrm{H}_2\mathrm{O}+\mathrm{O}_2
$$

$\mathrm{H}_2\mathrm{O}_2$ 有一定的生理作用，如在粒细胞和吞噬细胞中，$\mathrm{H}_2\mathrm{O}_2$ 可氧化杀死入侵的细菌；甲状腺细胞中产生的 $\mathrm{H}_2\mathrm{O}_2$ 可使 $2\mathrm{I}^{-}$ 氧化为 $\mathrm{I}_2$，进而使酪氨酸碘化生成甲状腺激素。

:::definition{label="过氧化氢酶"}
过氧化氢酶（catalase）主要在过氧化酶体，含 $4$ 个血红素辅基，把 $2\mathrm{H}_2\mathrm{O}_2$ 写成 $2\mathrm{H}_2\mathrm{O}+\mathrm{O}_2$。每秒可催化超过 $40\,000$ 个底物分子。
:::

:::keypoint{label="H2O2 不全是毒物"}
- 粒细胞、吞噬细胞：氧化杀死入侵细菌。
- 甲状腺细胞：把 $2\mathrm{I}^{-}$ 氧化为 $\mathrm{I}_2$，供酪氨酸碘化生成甲状腺激素。
- 其余场所：及时被过氧化氢酶或 $\mathrm{GPx}$ 拆掉，避免累积。
:::

:::pitfall{label="过氧化酶体既产 H2O2 也拆 H2O2"}
第八章：超长链脂肪酸在过氧化酶体第一步把氢交给氧成 $\mathrm{H}_2\mathrm{O}_2$。本节：过氧化氢酶就在过氧化酶体里把 $\mathrm{H}_2\mathrm{O}_2$ 拆成水和氧。产和清是同一细胞器的两本账。
:::

### （三）谷胱甘肽参与清除 ROS

谷胱甘肽过氧化物酶（glutathione peroxidase，$\mathrm{GPx}$）也是体内防止 $\mathrm{ROS}$ 损伤不可缺少的酶，可去除 $\mathrm{H}_2\mathrm{O}_2$ 和其他过氧化物类（$\mathrm{ROOH}$）。在细胞胞质、线粒体以及过氧化酶体中，$\mathrm{GPx}$ 通过还原型的谷胱甘肽将 $\mathrm{H}_2\mathrm{O}_2$ 还原为 $\mathrm{H}_2\mathrm{O}$、$\mathrm{ROOH}$ 转变为醇，同时产生氧化型的谷胱甘肽。其反应如下：

$$
\mathrm{H}_2\mathrm{O}_2+2\mathrm{GSH}\rightarrow 2\mathrm{H}_2\mathrm{O}+\mathrm{GS{-}SG}
$$

$$
2\mathrm{GSH}+\mathrm{ROOH}\rightarrow\mathrm{GS{-}SG}+\mathrm{H}_2\mathrm{O}+\mathrm{ROH}
$$

氧化型 $\mathrm{GS{-}SG}$ 经谷胱甘肽还原酶催化，由 $\mathrm{NADPH}+\mathrm{H}^{+}$ 提供 $2\mathrm{H}$，再转变为还原型的 $\mathrm{GSH}$。还原型的 $\mathrm{GSH}$ 也发挥抗氧化作用，抵抗 $\mathrm{ROS}$ 对蛋白质 $\mathrm{SH}$ 的氧化。

体内其他小分子自由基清除剂有维生素 $\mathrm{C}$、维生素 $\mathrm{E}$、$\beta$-胡萝卜素等，它们与体内的抗氧化酶共同组成人体抗氧化体系。

:::definition{label="谷胱甘肽过氧化物酶"}
谷胱甘肽过氧化物酶（glutathione peroxidase，$\mathrm{GPx}$）分布于胞质、线粒体和过氧化酶体，用还原型谷胱甘肽（$\mathrm{GSH}$）把 $\mathrm{H}_2\mathrm{O}_2$ 还原为 $\mathrm{H}_2\mathrm{O}$，把 $\mathrm{ROOH}$ 变成醇，自身生成氧化型 $\mathrm{GS{-}SG}$。
:::

:::definition{label="谷胱甘肽还原酶"}
谷胱甘肽还原酶以 $\mathrm{NADPH}+\mathrm{H}^{+}$ 供 $2\mathrm{H}$，把 $\mathrm{GS{-}SG}$ 还原回 $\mathrm{GSH}$，使谷胱甘肽循环使用。
:::

:::timeline{period="GSH 循环清过氧化物"}
- **GPx** 2 分子 GSH 把 H2O2 写成水（或把 ROOH 写成醇），得到 GS-SG
- **还原酶** NADPH 供氢，GS-SG 变回 GSH
- **GSH 本身** 还可保护蛋白质 SH，抵抗 ROS 氧化
:::

:::insight{label="戊糖磷酸途径的 NADPH 在这里接到抗氧化"}
第七章：戊糖磷酸途径不产能，产核糖磷酸和 $\mathrm{NADPH}$。本节：$\mathrm{NADPH}$ 把 $\mathrm{GS{-}SG}$ 还原回 $\mathrm{GSH}$。糖代谢那条“不走呼吸链”的还原力，正是抗氧化的燃料。
:::

:::compare{title="三套酶怎么分工"}
| 酶 | 底物 | 产物 | 印象 |
|----|------|------|------|
| $\mathrm{SOD}$ | $2\cdot\mathrm{O}_2^{-}$ | $\mathrm{H}_2\mathrm{O}_2+\mathrm{O}_2$ | 先把超氧歧化 |
| 过氧化氢酶 | $2\mathrm{H}_2\mathrm{O}_2$ | $2\mathrm{H}_2\mathrm{O}+\mathrm{O}_2$ | 过氧化酶体，极快 |
| $\mathrm{GPx}$ | $\mathrm{H}_2\mathrm{O}_2$ 或 $\mathrm{ROOH}$ $+$ $\mathrm{GSH}$ | 水或醇 $+$ $\mathrm{GS{-}SG}$ | 胞质、线粒体、过氧化酶体 |
:::

:::keypoint{label="小分子清除剂"}
维生素 $\mathrm{C}$、维生素 $\mathrm{E}$、$\beta$-胡萝卜素等与抗氧化酶共同组成人体抗氧化体系。第六章维生素的抗氧化账在此会合，不必另开新名单。
:::

## 三、非线粒体氧化体系产生各种产物

除了线粒体氧化体系外，过氧化物酶体、内质网等也存在其他的氧化体系，主要参与物质的氧化修饰、非营养物质的生物转化（见第二十五章）等。

:::definition{label="非线粒体氧化体系"}
过氧化物酶体、内质网等处的氧化体系，主要对底物做氧化修饰，并参与非营养物质的生物转化，不作为 $\mathrm{ATP}$ 的主来源。
:::

:::pitfall{label="生物氧化不等于氧化磷酸化"}
第一章就把过氧化物酶体、内质网的氧化还原写成“对底物氧化修饰，并无 $\mathrm{ATP}$ 生成”。本节三类酶落实那句话。不要看见“脱氢酶”就自动乘 $2.5$ 或 $1.5$。
:::

### （一）需氧脱氢酶可产生过氧化氢

需氧脱氢酶多为黄素酶类（flavoenzymes），其辅基是 $\mathrm{FMN}$、$\mathrm{FAD}$，酶蛋白与 $\mathrm{FMN}$ 与 $\mathrm{FAD}$ 结合紧密，因而称为黄素酶。黄素酶种类多，如醛脱氢酶、黄嘌呤氧化酶、$\mathrm{L}$-氨基酸氧化酶等，它们催化的脱氢反应以 $\mathrm{O}_2$ 为直接受氢体，产物为 $\mathrm{H}_2\mathrm{O}_2$。

:::definition{label="需氧脱氢酶"}
需氧脱氢酶多为黄素酶类（flavoenzymes），辅基 $\mathrm{FMN}$ 或 $\mathrm{FAD}$，与酶蛋白结合紧密。以 $\mathrm{O}_2$ 为直接受氢体，产物为 $\mathrm{H}_2\mathrm{O}_2$。例：醛脱氢酶、黄嘌呤氧化酶、$\mathrm{L}$-氨基酸氧化酶。
:::

:::insight{label="黄嘌呤氧化酶在 ROS 节和需氧脱氢酶节是同一类酶"}
前面作为 $\mathrm{H}_2\mathrm{O}_2$ 来源，这里归入需氧脱氢酶：氧直接接氢。两处不要记成两种无关的酶。
:::

### （二）不需氧脱氢酶可产生还原性代谢物

催化底物脱氢而又不以氧作为直接受氢体的酶称之为不需氧脱氢酶（anaerobic dehydrogenases）。这类酶催化的反应并不将氢直接传递给 $\mathrm{O}_2$，而是传递给辅酶或辅基，产生的还原型辅酶或辅基再进行氢／电子的传递。不需氧脱氢酶主要参与三类反应：①作为氢或电子载体，间接将氢或电子传递给 $\mathrm{O}_2$ 生成 $\mathrm{H}_2\mathrm{O}$ 并释放能量，可产生 $\mathrm{ATP}$；②催化代谢物之间氢的交换；③通过催化的可逆反应，促进还原当量在细胞内的转运或穿梭。

在糖酵解、柠檬酸循环、脂肪酸 $\beta$-氧化等代谢途径中催化氧化还原反应的酶，有许多不需氧脱氢酶，它们以辅酶 $\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$、$\mathrm{FAD}$ 为受氢体参加反应。而泛醌-细胞色素 $c$ 还原酶是以血红素结合的 $\mathrm{Fe}$ 离子进行电子传递，间接将电子传递给氧，参与能量代谢、产生 $\mathrm{ATP}$。

:::definition{label="不需氧脱氢酶"}
不需氧脱氢酶（anaerobic dehydrogenases）催化底物脱氢，但不以氧为直接受氢体，而是把氢交给辅酶或辅基，再往下传。
:::

:::compare{title="不需氧脱氢酶的三类反应"}
| | 做什么 | 和本章的关系 |
|--|--------|--------------|
| ① | 间接把氢／电子传给 $\mathrm{O}_2$ 生成 $\mathrm{H}_2\mathrm{O}$ 并释能，可产 $\mathrm{ATP}$ | 呼吸链上游的脱氢酶 |
| ② | 催化代谢物之间氢的交换 | 不走氧 |
| ③ | 可逆反应，促进还原当量在细胞内转运或穿梭 | 第二节甘油-3-磷酸穿梭、苹果酸-天冬氨酸穿梭 |
:::

:::keypoint{label="糖脂分解里的脱氢酶多半是不需氧的"}
糖酵解、柠檬酸循环、脂肪酸 $\beta$-氧化中许多氧化还原酶以 $\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$、$\mathrm{FAD}$ 为受氢体。泛醌-细胞色素 $c$ 还原酶（复合体Ⅲ）用血红素铁传电子，间接把电子交给氧，参与产能。
:::

:::pitfall{label="不需氧脱氢酶不是“厌氧才有的酶”"}
英文 anaerobic 容易听成“只在无氧时工作”。教材定义是“不以氧为直接受氢体”。有氧氧化里的乳酸脱氢酶以外的那些 $\mathrm{NAD}^{+}$ 脱氢酶，正是这类酶。
:::

### （三）单加氧酶催化底物分子羟基化

单加氧酶可以直接将氧原子加到底物分子上，参与体内某些代谢物、药物及毒物的转化或清除。例如，细胞色素 $\mathrm{P}450$ 单加氧酶（cytochrome $\mathrm{P}450$ monooxygenase，$\mathrm{Cyt}\ \mathrm{P}450$）催化氧分子中的一个氧原子加到底物分子上（羟化），另一个氧原子被 $\mathrm{NADPH}+\mathrm{H}^{+}$ 还原成水，故又称混合功能氧化酶（mixed function oxidase）或羟化酶（hydroxylase），参与类固醇激素等的生成以及药物、毒物的生物转化过程（见第二十五章），其反应式如下：

$$
\mathrm{RH}+\mathrm{NADPH}+\mathrm{H}^{+}+\mathrm{O}_2\rightarrow\mathrm{ROH}+\mathrm{NADP}^{+}+\mathrm{H}_2\mathrm{O}
$$

单加氧酶类含 $\mathrm{Cyt}\ \mathrm{P}450$，通过血红素中的 $\mathrm{Fe}$ 离子进行单电子传递。$\mathrm{Cyt}\ \mathrm{P}450$ 在生物体中广泛分布，人 $\mathrm{Cyt}\ \mathrm{P}450$ 有几百种同工酶，识别各自特异性底物。

:::definition{label="细胞色素 P450 单加氧酶"}
细胞色素 $\mathrm{P}450$ 单加氧酶（cytochrome $\mathrm{P}450$ monooxygenase，$\mathrm{Cyt}\ \mathrm{P}450$）把 $\mathrm{O}_2$ 中一个氧原子加到底物上（羟化），另一个氧原子被 $\mathrm{NADPH}+\mathrm{H}^{+}$ 还原成水。又称混合功能氧化酶（mixed function oxidase）或羟化酶（hydroxylase）。
:::

:::keypoint{label="P450 三个别名同一反应"}
- 单加氧酶：只把一个 $\mathrm{O}$ 加到底物。
- 混合功能氧化酶：一个氧写底物，一个氧写水。
- 羟化酶：产物是 $\mathrm{ROH}$。
:::

:::insight{label="一个氧进底物，一个氧进水，NADPH 付账"}
与呼吸链“$4$ 个电子把 $\mathrm{O}_2$ 写成 $2\mathrm{H}_2\mathrm{O}$”不同。这里 $\mathrm{O}_2$ 拆开用：一半做羟化，一半做水，$\mathrm{NADPH}$ 提供还原力。类固醇激素生成、药物毒物转化（第二十五章）走这条。
:::

:::note{label="人有几百种 P450 同工酶"}
广泛分布，各自识别特异性底物。不必背同工酶名单；记住“几百种、底物特异、血红素铁做单电子传递”即可。
:::

:::compare{title="线粒体呼吸链 vs 非线粒体氧化"}
| | 线粒体呼吸链 | 需氧脱氢酶 | 不需氧脱氢酶 | $\mathrm{P}450$ 单加氧酶 |
|--|--------------|------------|--------------|------------------------|
| 氧的角色 | 终受体，写成 $\mathrm{H}_2\mathrm{O}$ | 直接受氢体，写成 $\mathrm{H}_2\mathrm{O}_2$ | 不是直接受体 | 一个 $\mathrm{O}$ 羟化，一个 $\mathrm{O}$ 成水 |
| $\mathrm{ATP}$ | 主来源（氧化磷酸化） | 不作为产能主路 | ①类可间接产能 | 不产能，做修饰／转化 |
| 辅因子印象 | $\mathrm{NADH}/\mathrm{FADH}_2$、$\mathrm{Q}$、$\mathrm{Cyt}$ | $\mathrm{FMN}/\mathrm{FAD}$ | $\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$、$\mathrm{FAD}$ | 血红素铁 $+$ $\mathrm{NADPH}$ |
:::

:::memory{label="本节必背要点"}
- [ ] 呼吸链漏单电子给氧 $\rightarrow\mathrm{ROS}$：$\cdot\mathrm{O}_2^{-}$、$\mathrm{H}_2\mathrm{O}_2$、$\cdot\mathrm{OH}$。
- [ ] 主要来源是呼吸链，尤其复合体Ⅲ的 $\mathrm{QH}\cdot$；复合体Ⅳ、Ⅱ也可漏。
- [ ] 黄嘌呤氧化酶、$\mathrm{MAO}$ 也产 $\mathrm{H}_2\mathrm{O}_2$，远低于呼吸链。感染、缺氧、辐射、吸烟、药物可大量产 $\mathrm{ROS}$。
- [ ] 少量 $\mathrm{ROS}$ 促增殖；大量伤细胞。顺乌头酸酶 $\mathrm{Fe}$-$\mathrm{S}$ 怕超氧；$\cdot\mathrm{O}_2^{-}$ 与 $\mathrm{NO}$ 生成 $\mathrm{ONOO}^{-}$。
- [ ] $\mathrm{SOD}$：$2\cdot\mathrm{O}_2^{-}+2\mathrm{H}^{+}\rightarrow\mathrm{H}_2\mathrm{O}_2+\mathrm{O}_2$。胞质 $\mathrm{Cu}/\mathrm{Zn}$-$\mathrm{SOD}$，线粒体 $\mathrm{Mn}$-$\mathrm{SOD}$。$\mathrm{Cu}/\mathrm{Zn}$-$\mathrm{SOD}$ 缺陷可致肌萎缩性侧索硬化症。
- [ ] 过氧化氢酶：过氧化酶体，$4$ 血红素，$>40\,000$ 底物／秒，$2\mathrm{H}_2\mathrm{O}_2\rightarrow 2\mathrm{H}_2\mathrm{O}+\mathrm{O}_2$。
- [ ] $\mathrm{H}_2\mathrm{O}_2$ 可用于杀细菌、甲状腺碘化。
- [ ] $\mathrm{GPx}$：$\mathrm{GSH}$ 还原 $\mathrm{H}_2\mathrm{O}_2$ 和 $\mathrm{ROOH}$；还原酶用 $\mathrm{NADPH}$ 再生 $\mathrm{GSH}$。
- [ ] 小分子：维生素 $\mathrm{C}$、$\mathrm{E}$、$\beta$-胡萝卜素。
- [ ] 需氧脱氢酶：黄素酶，氧直接受氢，产 $\mathrm{H}_2\mathrm{O}_2$。
- [ ] 不需氧脱氢酶：氢给辅酶／辅基；三类反应含穿梭和间接产能。
- [ ] $\mathrm{Cyt}\ \mathrm{P}450$：$\mathrm{RH}+\mathrm{NADPH}+\mathrm{H}^{+}+\mathrm{O}_2\rightarrow\mathrm{ROH}+\mathrm{NADP}^{+}+\mathrm{H}_2\mathrm{O}$；混合功能氧化酶／羟化酶；人有几百种同工酶。
:::

## 本章小结

生物氧化是有机物质在生物体内的氧化过程，是需氧细胞物质代谢过程中发生的一系列氧化还原反应。其中营养物质在线粒体内氧化分解生成 $\mathrm{CO}_2$ 和 $\mathrm{H}_2\mathrm{O}$ 的过程中释放能量，用于驱动 $\mathrm{ADP}$ 磷酸化生成 $\mathrm{ATP}$，是生物氧化的核心内容，即营养物质的彻底氧化是产生能量的重要途径，其释放的能量被 $\mathrm{ATP}$ 捕获和储存。$\mathrm{ATP}$ 是能被机体各种代谢反应直接利用的主要能量形式，在能量的生成、储存和利用中处于中心地位，是能量代谢的核心。细胞过氧化物酶体、内质网等部位发生的生物氧化反应主要对底物进行氧化修饰，不产生 $\mathrm{ATP}$。

线粒体氧化体系主要将营养物质氧化分解产生的还原性辅酶 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 彻底氧化并释放能量，此氧化过程通过呼吸链（电子传递链）完成。呼吸链是由 $4$ 种蛋白质复合体和泛醌、细胞色素 $c$ 组成，这些组分具有传递电子／氢的功能，按照一定的顺序排列于线粒体内膜上，其功能是催化一系列连续的氧化还原反应，将 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 彻底氧化，所以 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 是线粒体呼吸链的底物、提供还原当量。由于 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 进入呼吸链的路径不同，形成了两条呼吸链。

$\mathrm{NADH}$ 呼吸链的组成及电子传递顺序是：$\mathrm{NADH}\rightarrow$复合体Ⅰ$\rightarrow\mathrm{Q}\rightarrow$复合体Ⅲ$\rightarrow\mathrm{Cyt}\ c\rightarrow$复合体Ⅳ$\rightarrow\mathrm{O}_2$，传递一对电子可生成 $2.5$ 分子 $\mathrm{ATP}$。$\mathrm{FADH}_2$ 呼吸链的组成及电子传递顺序是：琥珀酸$\rightarrow$复合体Ⅱ$\rightarrow\mathrm{Q}\rightarrow$复合体Ⅲ$\rightarrow\mathrm{Cyt}\ c\rightarrow$复合体Ⅳ$\rightarrow\mathrm{O}_2$，传递一对电子可生成 $1.5$ 分子 $\mathrm{ATP}$。细胞质中生成的 $\mathrm{NADH}$ 须通过甘油-3-磷酸穿梭或苹果酸-天冬氨酸穿梭机制进入线粒体，再进入呼吸链被彻底氧化并释放能量。即营养物质在体内分阶段、逐步进行氧化分解，产生 $\mathrm{CO}_2$ 的同时，将产生的 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 中的氢（$\mathrm{H}^{+}+e^{-}$）通过线粒体呼吸链进行彻底氧化，最后由氧接受电子和质子，生成水和 $\mathrm{ATP}$。

呼吸链中蛋白质复合体Ⅰ、Ⅲ、Ⅳ有质子泵功能，在进行电子传递时，分别向膜间隙侧泵出 $4\mathrm{H}^{+}$、$4\mathrm{H}^{+}$ 和 $2\mathrm{H}^{+}$，形成线粒体内膜两侧的质子浓度的差异，由此形成质子的电化学梯度（电荷和浓度梯度），储存电子传递过程释放的能量。

还原当量的氧化伴随 $\mathrm{ADP}$ 的磷酸化是机体产生 $\mathrm{ATP}$ 的主要方式。其过程是将 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的氧化过程与 $\mathrm{ADP}$ 的磷酸化过程相偶联而产生 $\mathrm{ATP}$。磷酸化过程是质子顺梯度释放势能时促使质子返回基质，驱动 $\mathrm{ATP}$ 合酶结合 $\mathrm{ADP}$ 和 $\mathrm{P}_\mathrm{i}$、催化 $\mathrm{ADP}$ 磷酸化产生 $\mathrm{ATP}$。

多种因素可以影响氧化磷酸化作用。$\mathrm{ADP}/\mathrm{ATP}$ 的比值升高可促进氧化磷酸化；而氰化物等呼吸链抑制剂、$\mathrm{ATP}$ 合酶抑制剂以及内源解偶联蛋白、外源的解偶联剂等都可通过不同的机制抑制氧化磷酸化，阻断 $\mathrm{ATP}$ 的生成。

呼吸链也是体内 $\mathrm{ROS}$ 的主要来源。$\mathrm{ROS}$ 产生过多会对机体产生危害，体内的各种抗氧化酶类及小分子抗氧化物质能及时清除 $\mathrm{ROS}$，维护机体的正常功能。

:::definition{label="本章小结里的两条呼吸链"}
$\mathrm{NADH}$ 呼吸链：$\mathrm{NADH}\rightarrow$Ⅰ$\rightarrow\mathrm{Q}\rightarrow$Ⅲ$\rightarrow\mathrm{Cyt}\ c\rightarrow$Ⅳ$\rightarrow\mathrm{O}_2$，一对电子约 $2.5\,\mathrm{ATP}$。$\mathrm{FADH}_2$ 呼吸链：琥珀酸$\rightarrow$Ⅱ$\rightarrow\mathrm{Q}\rightarrow$Ⅲ$\rightarrow\mathrm{Cyt}\ c\rightarrow$Ⅳ$\rightarrow\mathrm{O}_2$，一对电子约 $1.5\,\mathrm{ATP}$。细胞质 $\mathrm{NADH}$ 经甘油-3-磷酸穿梭（$1.5$）或苹果酸-天冬氨酸穿梭（$2.5$）进线粒体。
:::

:::keypoint{label="本章小结按节收口"}
- 生物氧化：体内氧化还原；线粒体彻底氧化产 $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$、$\mathrm{ATP}$；过氧化物酶体／内质网只修饰、不产 $\mathrm{ATP}$。
- 呼吸链：$4$ 个复合体 $+\mathrm{Q}+\mathrm{Cyt}\ c$；$\mathrm{NADH}$、$\mathrm{FADH}_2$ 为底物。
- 质子泵：Ⅰ、Ⅲ、Ⅳ分别泵 $4$、$4$、$2$ 个 $\mathrm{H}^{+}$，形成电化学梯度。
- 氧化磷酸化：氧化与磷酸化偶联；质子回流驱动 $\mathrm{ATP}$ 合酶。
- 调节与抑制：$\mathrm{ADP}/\mathrm{ATP}$ 升高促进；氰化物等、合酶抑制剂、解偶联剂／蛋白阻断 $\mathrm{ATP}$。
- $\mathrm{ROS}$：呼吸链为主来源；抗氧化酶和小分子及时清除。
:::

:::insight{label="小结把 2.5／1.5 再钉一次"}
章末仍写传递一对电子生成 $2.5$ 或 $1.5$ 分子 $\mathrm{ATP}$，与第三节 $\mathrm{P/O}$、质子账 $10/4$、$6/4$ 一致。穿梭两种分别对应这两档，第七章葡萄糖净 $30$ 或 $32$ 从这里来。
:::

3. 利用呼吸链的抑制剂，是否可以分析细胞的耗氧量来分析其代谢的变化？
4. 解偶联剂与白色脂肪、棕色脂肪的关系是什么？解偶联剂有助于减肥吗？

:::tip{label="四道思考题在正文里的户头"}
- 神经退行性变／肿瘤：第四节 $\mathrm{mtDNA}$ 突变累积见于脑、骨骼肌，可与帕金森病、阿尔茨海默病等并提；氧化磷酸化供能障碍是共同背景。肿瘤处教材未单列机制，不要离开本章另写瓦尔堡综述；能落到 $\mathrm{ATP}$、$\mathrm{ROS}$、抑制剂即可。
- 易产 $\mathrm{ROS}$ 的复合体：Ⅲ（$\mathrm{Q}$ 循环 $\mathrm{QH}\cdot$）、Ⅳ（$4$ 步单电子）、Ⅱ等。作用：少量促增殖，大量伤酶、膜、核酸。定量方法教材未给出操作步骤，题干超出正文的部分标明“教材未展开”。
- 抑制剂与耗氧：呼吸链或合酶抑制剂使耗氧下降；解偶联使耗氧上升而 $\mathrm{ATP}$ 下降。用耗氧曲线可以区分卡在传递、卡在合酶，还是梯度被短路。
- 白脂 vs 棕脂：白脂是储脂动员库（第八章）；棕脂富含线粒体和 $\mathrm{UCP}1$，质子漏回产热。外源解偶联剂（$\mathrm{DNP}$）也能产热、降 $\mathrm{ATP}$，但教材把它写成破坏梯度的毒物样工具，没有给出“可以用来减肥”的治疗结论。
:::
