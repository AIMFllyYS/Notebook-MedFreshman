# 第三节　DNA损伤和损伤修复的意义

第一节立损伤的因素、类型和错义／无义／同义；第二节立光复活、直接修复、碱基切除、核苷酸切除、重组修复和 $\mathrm{SOS}$。本节只问意义：损伤的双重效应（有害 vs 进化的分子基础），以及修复系统缺陷与肿瘤、遗传病、免疫性疾病、衰老的关联。不要把后续专章的「疾病相关基因及其鉴定原则」写进来。

:::concept{term="先问损伤是有害还是进化的分子基础，再问修不好会得什么病"}
看见“损伤和修复的意义”，先不要默写定位克隆和全基因组关联。户头是：遗传物质要相对稳定才能维持物种，但不能绝对一成不变，否则没有新物种。双重效应必须两句都答：永久改变（突变）可以不立刻要细胞的命；失去模板功能可以让细胞明显障碍甚至死亡。修复缺陷对着表21-4，不是对着后续专章的致病基因／易感基因鉴定流程。
:::

遗传物质稳定性的世代相传是维持物种稳定的主要因素。然而，如果遗传物质是绝对一成不变的话，自然界也就失去了进化的基础，也就不会有新的物种出现。因此，生物多样性依赖于 $\mathrm{DNA}$ 损伤与损伤修复之间的良好的动态平衡。

:::definition{label="多样性依赖损伤与修复的动态平衡"}
稳定性世代相传，维持物种；绝对一成不变，则失去进化基础、不会有新物种。生物多样性依赖于 $\mathrm{DNA}$ 损伤与损伤修复之间良好的动态平衡。与章首同一句，本节把它展开成双重效应和疾病。
:::

:::pitfall{label="不要把本节写成「修复越彻底越好」"}
开篇已经写：绝对稳定则没有进化。本节第一句再钉一次。把意义答成「修复系统的唯一价值是消灭一切突变」，双重效应的「进化分子基础」那一半就空了。
:::

## 一、DNA损伤具有双重效应

一般认为 $\mathrm{DNA}$ 损伤是有害的；然而，就损伤的结果而言，$\mathrm{DNA}$ 损伤具有双重效应，$\mathrm{DNA}$ 损伤是基因突变的基础。通常，$\mathrm{DNA}$ 损伤有两种生物学后果。一是给 $\mathrm{DNA}$ 带来永久性的改变，即突变，可能仅改变基因的编码序列或基因的调控序列，细胞尚未产生明显可见的功能性障碍，细胞依然存活。二是 $\mathrm{DNA}$ 的这些改变使得 $\mathrm{DNA}$ 不能用作复制和转录的模板，使细胞的功能出现明显可见的障碍，重则甚至死亡。

:::definition{label="DNA 损伤的双重效应"}
一般认为损伤有害；就结果而言具有双重效应，并且损伤是基因突变的基础。两种生物学后果：①永久性改变即突变——可能只改编码序列或调控序列，细胞尚无明显可见的功能障碍，依然存活；②不能再当复制和转录的模板——功能出现明显可见障碍，重则死亡。
:::

:::compare{title="两种生物学后果（与章首对齐）"}
| | 本版原句 | 细胞立刻怎样 | 和「有害」的关系 |
|--|---------|-------------|----------------|
| 永久性改变（突变） | 可只改编码或调控序列 | 可无明显功能障碍，细胞存活 | 不一定立刻有害；是基因突变的基础，也是进化的分子基础 |
| 失去模板功能 | 不能用作复制和转录的模板 | 明显障碍，重则死亡 | 这一面更接近「有害」 |

章首两种后果和这里两种生物学后果是同一本账。不要另编第三种。
:::

:::insight{label="「尚未明显可见的功能障碍」不是「没有改变」"}
突变已经写进编码或调控序列。细胞可以还活着、看起来正常。第三节后文的基因多态性、亲子鉴定，就落在「改了基因型、表型可以不变」。
:::

从久远的生物史来看，进化是遗传物质不断突变的过程。可以说没有突变就没有生物物种的多样性。当然在短暂的某一段历史时期，我们往往无法看到一个物种的自然演变，只能见到长期突变的累积结果，适者生存。因此突变是进化的分子基础。

:::definition{label="突变是进化的分子基础"}
进化是遗传物质不断突变的过程。没有突变就没有物种多样性。短暂历史时期往往看不见一个物种的自然演变，只能见到长期累积、适者生存。
:::

:::pitfall{label="不要要求在一学期里看见一个物种变成另一个物种"}
教材自己写了：短暂时期内往往无法看到自然演变。考试答「突变是进化的分子基础」，证据是长期累积，不是课堂里观察物种形成。
:::

$\mathrm{DNA}$ 突变可能只改变基因型，而不影响其表型，并表现出个体差异。目前，基因的多态性已被广泛应用于亲子鉴定、个体识别、器官移植，以及疾病易感性分析等。$\mathrm{DNA}$ 损伤若发生在与生命活动密切相关的基因上，可能导致细胞，甚至是个体的死亡。人类常利用此性质杀死某些病原微生物。

$\mathrm{DNA}$ 突变还是某些遗传性疾病发病的基础。有遗传倾向的疾病，如高血压和糖尿病，尤其是肿瘤，均是多种基因与环境因素共同作用的结果。

:::definition{label="只改基因型不改表型"}
突变可能只改变基因型，不影响表型，并表现出个体差异。基因多态性已用于亲子鉴定、个体识别、器官移植、疾病易感性分析。这和第一节同义突变（same sense mutation）是同一方向：序列变了，氨基酸或表型可以不变。
:::

:::definition{label="打在关键基因上可以致死"}
损伤若发生在与生命活动密切相关的基因上，可导致细胞甚至个体死亡。人类常利用此性质杀死某些病原微生物。化疗药物在第一节已经点过「故意打伤肿瘤细胞的 $\mathrm{DNA}$」，和这里是同一逻辑。
:::

:::definition{label="突变也是遗传病和常见病的基础"}
某些遗传性疾病以 $\mathrm{DNA}$ 突变为发病基础。有遗传倾向的疾病，如高血压和糖尿病，尤其是肿瘤，是多种基因与环境因素共同作用的结果。不要把高血压、糖尿病写成单基因病——致病基因／易感基因的分户是后续专章的账。
:::

:::compare{title="双重效应落到三件实事"}
| 效应 | 本版实事 | 不要写成 |
|------|---------|---------|
| 中性／多样性 | 多态性用于亲子鉴定、个体识别、器官移植、易感性分析 | 「突变都致病」 |
| 致死／可利用 | 关键基因被打 → 细胞或个体死亡；可用来杀病原微生物 | 「损伤只对真核有害」 |
| 疾病 | 遗传病的基础；高血压、糖尿病、尤其肿瘤是多基因与环境 | 「一种突变对应一种病」的鉴定流程（后续专章） |
:::

:::keypoint{label="双重效应两句话"}
- 有害：失去模板功能可致明显障碍甚至死亡；打在关键基因上可致死；也是遗传病和肿瘤的基础。
- 不只有害：突变是进化的分子基础；可只改基因型；多态性已被应用。
:::

## 二、DNA损伤修复系统缺陷可能引发多种疾病

细胞中 $\mathrm{DNA}$ 损伤的生物学后果，主要取决于 $\mathrm{DNA}$ 损伤的程度和细胞的修复能力。如果损伤得不到及时正确的修复，就可能导致细胞功能的异常。$\mathrm{DNA}$ 碱基的损伤将可能导致遗传密码子的变化，经转录和翻译产生功能异常的 $\mathrm{RNA}$ 与蛋白，引起细胞功能的衰退、凋亡，甚至发生恶性转化。双链 $\mathrm{DNA}$ 的断裂可通过同源或非同源重组修复途径加以修复，但非同源重组修复的忠实性差，修复过程中可能丧失或获得核苷酸，造成染色体畸变，导致严重后果。$\mathrm{DNA}$ 交联影响染色体的高级结构，妨碍基因的正常表达，对细胞的功能同样产生明显影响。因此，$\mathrm{DNA}$ 损伤修复系统缺陷与肿瘤、遗传性疾病、免疫性疾病以及衰老等多种疾病的发生有着非常密切的关联（表21-4）。

:::definition{label="后果取决于损伤程度和修复能力"}
与第二节开篇同一把尺子。修不及时、修不正确 → 细胞功能异常。
:::

:::cause-effect{title="三类损伤修不好会怎样"}
- **因** 碱基损伤改变遗传密码子
- **果** 转录翻译出功能异常的 $\mathrm{RNA}$ 与蛋白 → 衰退、凋亡、甚至恶性转化
- **因** 双链断裂走非同源重组，忠实性差，可丧失或获得核苷酸
- **果** 染色体畸变，严重后果
- **因** $\mathrm{DNA}$ 交联影响染色体高级结构
- **果** 妨碍基因正常表达，细胞功能明显受影响
:::

:::insight{label="同源重组能修 DSB，但本节特意点名非同源这一路的忠实性差"}
第二节已经把 $\mathrm{NHEJ}$ 写成容易出错、又是全周期主要途径。这里把「丧失或获得核苷酸 → 畸变」写进疾病机制。不要把所有 $\mathrm{DSB}$ 修复都写成高保真。
:::

### （一）DNA损伤修复系统缺陷可能引发肿瘤

先天性 $\mathrm{DNA}$ 损伤修复系统缺陷患者容易发生肿瘤。肿瘤发生是 $\mathrm{DNA}$ 损伤对机体的远期效应之一。众多研究表明，$\mathrm{DNA}$ 损伤 $\rightarrow$ $\mathrm{DNA}$ 损伤修复异常 $\rightarrow$ 基因突变 $\rightarrow$ 肿瘤发生，是贯穿肿瘤发生发展过程的主要环节。$\mathrm{DNA}$ 损伤可导致原癌基因的激活，也可使抑癌基因失活。癌基因与抑癌基因的表达失衡是细胞恶变的重要机制。参与 $\mathrm{DNA}$ 损伤修复的多种基因具有抑癌基因的功能，目前已发现这些基因在多种肿瘤中发生突变而失活。$1993$ 年，有研究发现，人类遗传性非息肉性结肠癌（hereditary non-polyposis colorectal cancer，$\mathrm{HNPCC}$）细胞存在错配修复与转录偶联修复缺陷，造成细胞基因组的不稳定性，进而引起调控细胞生长的基因发生突变，引发细胞恶变。在 $\mathrm{HNPCC}$ 中 $\mathrm{MLH}1$ 和 $\mathrm{MSH}2$ 基因的突变时有发生。$\mathrm{MLH}1$ 基因的突变形式主要有错义突变、无义突变、缺失和移码突变等。而 $\mathrm{MSH}2$ 基因的突变形式主要有移码突变、无义突变、错义突变以及缺失或插入等；其中以第 $622$ 位密码子发生 $\mathrm{C}/\mathrm{T}$ 转换，导致脯氨酸突变为亮氨酸最为常见，结果使 $\mathrm{MSH}2$ 蛋白的功能受损。

$\mathrm{BRCA}$ 基因（breast cancer gene）参与 $\mathrm{DNA}$ 损伤修复的启动与细胞周期的调控。$\mathrm{BRCA}$ 基因的失活可增加细胞对辐射的敏感性，导致细胞对双链 $\mathrm{DNA}$ 断裂修复能力的下降。现已发现 $\mathrm{BRCA}1$ 基因在 $70\%$ 的家族遗传性乳腺癌和卵巢癌病例中发生突变而失活。

值得注意的是，$\mathrm{DNA}$ 修复功能缺陷虽可引起肿瘤的发生，但已癌变的细胞本身 $\mathrm{DNA}$ 修复功能往往并不低下，相反会显著升高，使得癌细胞能够充分修复化疗药物引起的 $\mathrm{DNA}$ 的损伤，这也是大多数抗肿瘤药物不能奏效的直接原因之一，所以关于 $\mathrm{DNA}$ 损伤修复的研究可为肿瘤化疗药物开发提供理论指导。

:::timeline{period="修复缺陷通向肿瘤"}
- **环节** DNA 损伤 → 损伤修复异常 → 基因突变 → 肿瘤发生
- **机制** 原癌基因激活，或抑癌基因失活；二者表达失衡是恶变的重要机制
- **修复基因本身** 多种参与损伤修复的基因具有抑癌基因功能，可在肿瘤中突变失活
- **1993** HNPCC 细胞被发现存在错配修复与转录偶联修复缺陷
:::

:::definition{label="HNPCC 与错配修复"}
遗传性非息肉性结肠癌（hereditary non-polyposis colorectal cancer，$\mathrm{HNPCC}$）：错配修复与转录偶联修复缺陷 → 基因组不稳定 → 调控细胞生长的基因突变 → 恶变。$\mathrm{MLH}1$、$\mathrm{MSH}2$ 突变时有发生。
:::

:::definition{label="MLH1 与 MSH2 的突变形式"}
$\mathrm{MLH}1$：错义、无义、缺失和移码等。$\mathrm{MSH}2$：移码、无义、错义以及缺失或插入等；其中以第 $622$ 位密码子 $\mathrm{C}/\mathrm{T}$ 转换、脯氨酸突变为亮氨酸最为常见，使 $\mathrm{MSH}2$ 蛋白功能受损。错义／无义／移码的定义在第一节，这里是把记法用到具体基因上。
:::

:::definition{label="BRCA 与双链断裂修复"}
$\mathrm{BRCA}$ 基因（breast cancer gene）参与损伤修复的启动与细胞周期调控。失活：细胞对辐射敏感性增加，对双链 $\mathrm{DNA}$ 断裂修复能力下降。$\mathrm{BRCA}1$ 在 $70\%$ 的家族遗传性乳腺癌和卵巢癌病例中突变失活。
:::

:::compare{title="HNPCC vs 遗传性乳腺癌：坏的是哪条修复"}
| | 修复系统 | 本版点名的基因 | 表21-4 易患 |
|--|---------|--------------|-----------|
| $\mathrm{HNPCC}$ | 错配修复、转录偶联修复 | $\mathrm{MLH}1$、$\mathrm{MSH}2$（$622$ 位 $\mathrm{C}/\mathrm{T}$，Pro$\rightarrow$Leu 最常见） | 结肠癌、卵巢癌 |
| 遗传性乳腺癌／卵巢癌 | 同源重组修复 | $\mathrm{BRCA}1$（家族性病例中约 $70\%$ 失活）；第二节还有 $\mathrm{BRCA}2$ | 乳腺癌、卵巢癌 |

都易患卵巢癌，修复途径不是同一条。不要并成「都是切除修复缺陷」。
:::

:::pitfall{label="癌细胞的修复功能往往升高，不是低下"}
先天性修复缺陷容易发生肿瘤；一旦已经癌变，细胞本身的修复功能往往并不低下，相反显著升高，能充分修复化疗药物引起的 $\mathrm{DNA}$ 损伤——这是多数抗肿瘤药物不能奏效的直接原因之一。写成「肿瘤细胞都不会修 $\mathrm{DNA}$」，第一节「认识损伤有助于指导化疗研发」和这里的理论指导就接反了。
:::

:::insight{label="同一套修复，正常组织缺了会癌变，癌细胞多了会耐药"}
缺陷：突变累积、恶变。升高：把化疗打出来的损伤修掉。研究修复既解释肿瘤发生，也解释为什么药不灵。
:::

:::keypoint{label="肿瘤这一小节三句"}
- 主环节：损伤 $\rightarrow$ 修复异常 $\rightarrow$ 基因突变 $\rightarrow$ 肿瘤；原癌激活或抑癌失活。
- 例子：$\mathrm{HNPCC}$ 的 $\mathrm{MLH}1/\mathrm{MSH}2$；家族性乳腺／卵巢癌的 $\mathrm{BRCA}1$（约 $70\%$）。
- 已癌变细胞修复常升高 → 化疗耐药的原因之一。
:::

### （二）DNA损伤修复缺陷可能引发遗传性疾病

着色性干皮病 $\mathrm{XP}$，患者的皮肤对阳光敏感，照射后出现红斑、水肿，继而出现色素沉着、干燥和角化过度等病变发生。具有不同临床表现的 $\mathrm{XP}$ 患者存在明显的遗传异质性，表现为不同程度的核酸内切酶缺乏引发的切除修复功能缺陷，所以患者的肺、胃肠道等器官在受到有害环境因素刺激时，会有较高的肿瘤发生率。然而，在对 $\mathrm{XP}$ 的进一步研究中发现，一些患者虽具有明显的临床症状，但在 $\mathrm{UV}$ 辐射后的核苷酸切除修复中却未见明显的缺陷表型，故将其定名为「$\mathrm{XP}$ 变种」（XP variant，$\mathrm{XPV}$）。这类患者的细胞在培养中表现出对 $\mathrm{UV}$ 辐射的轻微增高的敏感性，变种的切除修复功能正常，而复制后修复的功能有缺陷。最新的研究发现，某些 $\mathrm{XP}$ 变种的分子病理学机制是由于其对 $\mathrm{DNA}$ 碱基损伤耐受的缺陷所致，而不是修复方面的缺陷。

共济失调-毛细血管扩张症（ataxia telangiectasia，$\mathrm{AT}$），是一种常染色体隐性遗传病，主要影响机体的神经系统、免疫系统与皮肤。$\mathrm{AT}$ 患者的细胞对射线以及拟辐射的化学因子，如博来霉素等敏感，具有极高的染色体自发畸变率，以及对辐射所致的 $\mathrm{DNA}$ 损伤的修复缺陷。患者的肿瘤发病率相当高。$\mathrm{AT}$ 的发生与在 $\mathrm{DNA}$ 损伤信号转导网络中发挥关键作用的 $\mathrm{ATM}$ 蛋白分子的突变有关。

此外，$\mathrm{DNA}$ 损伤核苷酸切除修复的缺陷可以导致人毛发硫营养不良症（trichothiodystrophy，$\mathrm{TTD}$）、科凯恩综合征（Cockayne syndrome，$\mathrm{CS}$）和范科尼贫血（Fanconi anemia）等遗传病。

:::definition{label="着色性干皮病的临床表现与遗传异质性"}
皮肤对阳光敏感：红斑、水肿，继而色素沉着、干燥和角化过度。不同临床表现对应明显遗传异质性，表现为不同程度核酸内切酶缺乏引发的切除修复缺陷。肺、胃肠道等受有害环境因素刺激时肿瘤发生率较高。
:::

:::definition{label="XP 变种"}
$\mathrm{XP}$ 变种（XP variant，$\mathrm{XPV}$）：有明显临床症状，但 $\mathrm{UV}$ 辐射后核苷酸切除修复未见明显缺陷表型。培养细胞对 $\mathrm{UV}$ 敏感性仅轻微增高；切除修复功能正常，复制后修复功能有缺陷。某些 $\mathrm{XPV}$ 的分子病理学是碱基损伤耐受缺陷，而不是修复缺陷。
:::

:::definition{label="共济失调-毛细血管扩张症"}
共济失调-毛细血管扩张症（ataxia telangiectasia，$\mathrm{AT}$）：常染色体隐性遗传，主要影响神经系统、免疫系统与皮肤。细胞对射线及拟辐射化学因子（如博来霉素）敏感，染色体自发畸变率极高，辐射所致 $\mathrm{DNA}$ 损伤修复缺陷，肿瘤发病率相当高。发生与 $\mathrm{ATM}$ 蛋白分子突变有关，$\mathrm{ATM}$ 在 $\mathrm{DNA}$ 损伤信号转导网络中发挥关键作用。
:::

:::definition{label="NER 缺陷的另外三种遗传病"}
人毛发硫营养不良症（trichothiodystrophy，$\mathrm{TTD}$）、科凯恩综合征（Cockayne syndrome，$\mathrm{CS}$）、范科尼贫血（Fanconi anemia）。第二节在 $\mathrm{NER}$ 处已点过 Cockyne 综合征和人毛发二硫键营养不良症；表21-4 把范科尼贫血写在「重组跨越损伤修复」下。本版两处都保留，不要用外校分类表把范科尼从这一句删掉。
:::

:::compare{title="经典 XP vs XP 变种"}
| | 核苷酸切除修复 | 其他 | 对 UV |
|--|--------------|------|------|
| 经典 $\mathrm{XP}$ | 核酸内切酶缺乏，切除修复缺陷（表21-2 的 $\mathrm{XPA}$–$\mathrm{XPG}$） | 肺、胃肠道等肿瘤发生率高 | 皮肤对阳光敏感 |
| $\mathrm{XP}$ 变种 | 切除修复功能正常 | 复制后修复缺陷；某些是损伤耐受缺陷而非修复缺陷 | 培养中对 $\mathrm{UV}$ 敏感性仅轻微增高 |

有临床症状不等于表21-2 那一行 $\mathrm{NER}$ 基因坏了。变种不要塞进表21-2 去「补全」外校的 $\mathrm{XP}$ 名单。
:::

:::pitfall{label="ATM 是损伤信号转导，不是表21-1 的六种修复酶之一"}
$\mathrm{AT}$ 写的是 $\mathrm{ATM}$ 在损伤信号转导网络中的关键作用。第二节末的检查点、凋亡，和这里的信号转导是同一方向。写成「$\mathrm{ATM}$ 就是光复活酶」或「就是 $\mathrm{MutS}$」，表21-4 也没有 $\mathrm{AT}$ 这一行——本版把 $\mathrm{AT}$ 放在遗传病叙述里，没有单独列入表21-4。
:::

:::pitfall{label="科凯恩综合征的英文在表内是 Cockyne，后文是 Cockayne"}
表21-4 写 Cockyne 综合征；本段写科凯恩综合征（Cockayne syndrome，$\mathrm{CS}$）。同一病，本版两种拼法都出现。答题认病，不要抓住一个拼法说另一个是另一种病。
:::

### （三）DNA损伤修复缺陷可能引发免疫性疾病

$\mathrm{DNA}$ 损伤修复功能先天性缺陷患者，其免疫系统常有缺陷，主要是 $\mathrm{T}$ 淋巴细胞功能缺陷。随着年龄的增长，细胞中的 $\mathrm{DNA}$ 修复功能逐渐衰退，如果同时发生免疫监视机能的障碍，便不能及时清除癌变细胞，从而导致发生肿瘤。因此，$\mathrm{DNA}$ 损伤修复与免疫以及肿瘤等均是紧密关联的。

:::definition{label="修复缺陷与免疫"}
先天性修复缺陷患者免疫系统常有缺陷，主要是 $\mathrm{T}$ 淋巴细胞功能缺陷。年龄增长使修复功能衰退，若同时免疫监视障碍，不能及时清除癌变细胞，导致肿瘤。修复、免疫、肿瘤三户关联。
:::

:::insight{label="第二节 NHEJ 参与淋巴细胞受体基因重排，和这里的免疫缺陷是同一方向"}
$\mathrm{NHEJ}$ 既修 $\mathrm{DSB}$，也参与 $\mathrm{B}$／$\mathrm{T}$ 受体和免疫球蛋白基因构建。先天性修复缺陷出现 $\mathrm{T}$ 细胞功能缺陷，不是外加的一句临床点缀。
:::

:::cause-effect{title="年龄、修复、免疫怎样叠成肿瘤"}
- **因** 年龄增长，$\mathrm{DNA}$ 修复功能逐渐衰退
- **因** 同时免疫监视障碍，不能及时清除癌变细胞
- **果** 发生肿瘤

两因要一起答。只答「老了就会癌」而不提修复衰退和免疫监视，本节的关联就没了。
:::

### （四）DNA损伤修复缺陷可能引发衰老

有关 $\mathrm{DNA}$ 损伤修复能力比较研究发现，寿命长的动物如象和牛等，其 $\mathrm{DNA}$ 损伤的修复能力较强；相对而言，寿命短的动物如小鼠和仓鼠等，其 $\mathrm{DNA}$ 损伤的修复能力较弱。人的 $\mathrm{DNA}$ 损伤修复能力也很强，但到一定年龄后会逐渐减弱，突变细胞数与染色体畸变率相应增加。如人类常染色体隐性遗传的早老症和韦尔纳氏综合征患者，其体细胞极易衰老，一般早年死于心血管疾病或恶性肿瘤。

:::definition{label="修复能力与寿命"}
寿命长的动物（象、牛等）修复能力较强；寿命短的动物（小鼠、仓鼠等）修复能力较弱。人的修复能力也很强，但到一定年龄后逐渐减弱，突变细胞数与染色体畸变率相应增加。
:::

:::definition{label="早老症和韦尔纳氏综合征"}
常染色体隐性遗传。体细胞极易衰老，一般早年死于心血管疾病或恶性肿瘤。本版把它们写在「修复缺陷可能引发衰老」下。
:::

:::compare{title="衰老这一小节的两层证据"}
| | 比较对象 | 修复能力 | 本版接着说 |
|--|---------|---------|-----------|
| 种间 | 象、牛 vs 小鼠、仓鼠 | 寿命长则较强，寿命短则较弱 | 相关，不是把人的寿命写成由象的酶决定 |
| 个体年龄 | 人到一定年龄后 | 逐渐减弱 | 突变细胞数、染色体畸变率增加 |
| 遗传病 | 早老症、韦尔纳氏综合征 | 体细胞极易衰老 | 早年死于心血管病或恶性肿瘤 |

Cockyne 综合征表内已写早衰；这里另有早老症和韦尔纳氏综合征。不要并成一个病名。
:::

:::pitfall{label="种间比较不要外推成「人应该活得和象一样长」"}
教材只写修复能力与寿命的相关。人自己的账是：本来很强，年龄大了减弱。早老症是遗传病，不是普通老化的同义词。
:::

:::keypoint{label="修复缺陷四类疾病"}
- 肿瘤：损伤 $\rightarrow$ 修复异常 $\rightarrow$ 突变 $\rightarrow$ 肿瘤；$\mathrm{HNPCC}$、$\mathrm{BRCA}1$；癌细胞修复可升高而耐药。
- 遗传病：$\mathrm{XP}$／$\mathrm{XPV}$、$\mathrm{AT}$（$\mathrm{ATM}$）、$\mathrm{TTD}$、$\mathrm{CS}$、范科尼贫血。
- 免疫：主要 $\mathrm{T}$ 细胞功能缺陷；修复衰退叠加免疫监视障碍 $\rightarrow$ 肿瘤。
- 衰老：种间相关；人随年龄减弱；早老症、韦尔纳氏综合征。
:::

## 本章小结

$\mathrm{DNA}$ 损伤是指各种体内外因素导致的 $\mathrm{DNA}$ 组成与结构上的变化，主要有碱基或戊糖基的破坏、碱基错配、$\mathrm{DNA}$ 单链或双链断裂、$\mathrm{DNA}$ 链共价交联等多种表现形式。

细胞内在因素，如 $\mathrm{DNA}$ 复制中的错配、$\mathrm{DNA}$ 结构本身的不稳定性、机体代谢中产生的有害活性分子等，均可诱发 $\mathrm{DNA}$ 的「自发」损伤。外环境中的物理因素（电离辐射和紫外线）、化学因素（自由基、碱基类似物、碱基修饰剂、嵌入性染料）和生物因素等也均可损伤 $\mathrm{DNA}$。

$\mathrm{DNA}$ 损伤具有双重生物学效应。各种因素诱发的 $\mathrm{DNA}$ 结构改变是生物进化的基础；同时 $\mathrm{DNA}$ 的损伤也可使细胞功能出现障碍，与多种疾病，如肿瘤等密切相关。

细胞拥有 $\mathrm{DNA}$ 损伤修复机制，可以修复 $\mathrm{DNA}$ 的损伤，恢复 $\mathrm{DNA}$ 的正常结构。这一机制对于维持 $\mathrm{DNA}$ 结构的完整性与稳定性，保证生命延续和物种稳定至关重要。细胞有直接修复、切除修复、重组修复和跨越损伤修复等多种 $\mathrm{DNA}$ 损伤修复途径。一种 $\mathrm{DNA}$ 损伤可通过多种途径修复，一种修复途径也可参与多种 $\mathrm{DNA}$ 损伤的修复。$\mathrm{DNA}$ 损伤修复的缺陷与肿瘤、遗传性疾病、免疫性疾病以及衰老等密切相关。

:::definition{label="本章小结里的损伤"}
组成与结构上的变化。形式：碱基或戊糖基破坏、错配、单链或双链断裂、共价交联。体内自发：复制错配、自身不稳定、有害活性分子。体外：电离辐射和紫外线；自由基、碱基类似物、碱基修饰剂、嵌入性染料；生物因素。
:::

:::definition{label="本章小结里的双重效应"}
结构改变是进化的基础；也可使细胞功能障碍，与肿瘤等多种疾病相关。
:::

:::definition{label="本章小结里的修复"}
直接修复、切除修复、重组修复和跨越损伤修复。一种损伤多种途径，一种途径多种损伤。缺陷与肿瘤、遗传病、免疫性疾病、衰老密切相关。小结把光复活归在直接修复里，表21-1 仍单独列出光复活——两处都要认。
:::

:::keypoint{label="本章小结按三节收口"}
- 第一节：体内外因素；类型；转换／颠换；错义／无义／同义（$\mathrm{B}$-$\mathrm{Raf}^{\mathrm{V600E}}$）。
- 第二节：光复活、烷基直接修复、$\mathrm{BER}$、$\mathrm{NER}$、错配、同源重组／$\mathrm{NHEJ}$、跨越／$\mathrm{SOS}$。
- 第三节：双重效应；表21-4；肿瘤、遗传病、免疫、衰老。不收疾病相关基因鉴定流程。
:::

## 思考题

1. 有很多突变，对于野生型基因是隐性的，也就是说，在一个含有野生型与突变型基因的二倍体细胞中，只有野生型的特性才能够得到表达。请根据基因突变的理论，解释这一事实。
2. $\mathrm{RecA}$ 蛋白是如何调节 $\mathrm{SOS}$ 的？
3. 为什么 $\mathrm{DNA}$ 的甲基化状态可以被 $\mathrm{DNA}$ 损伤修复系统所利用？
4. 突变可能影响高等真核生物结构基因表达的几个水平？
5. 假如发生了碱基对的错配，如何被有效修复？

:::tip{label="五道思考题在正文里的户头"}
- 隐性：第一节错义／无义／同义。二倍体里野生型等位基因仍可提供功能产物；无义或功能丧失的突变等位往往显不出自己的表型。同义可以表型不变。不要把「隐性」答成「没有发生突变」。
- $\mathrm{RecA}$ 调节 $\mathrm{SOS}$：第二节 $\mathrm{LexA}$ 结合 $5'$-$\mathrm{CTG}$-$\mathrm{N}_{10}$-$\mathrm{CAG}$-$3'$ 阻遏；严重损伤时 $\mathrm{RecA}$ 激活 $\mathrm{LexA}$ 自水解，阻遏解除；修完 $\mathrm{LexA}$ 再合成、基因再关。图21-7 电子版缺失，用这段散文。不要答成 $\mathrm{RAD}51$ 入侵 $\mathrm{D}$-loop。
- 甲基化：第二节细菌错配修复。母链 $\mathrm{A}$ 已甲基化，子链尚未甲基化，提示在子链上切除错配。不要答成烷基化碱基的直接修复（那是把甲基从 $\mathrm{O}^{6}$-甲基鸟嘌呤转移到酶自己身上）。
- 结构基因表达的几个水平：第一节已写编码序列、调控序列、染色质高级结构、转录延伸被断裂挡住、产物的量与质。高等真核还可以落到转录、加工、翻译等层次——答题扣本版已经写出的模板、调控、染色质、产物，不要另编教材没有的表观遗传全表。
- 碱基对错配：第二节错配修复。细菌 $\mathrm{MutS}$ 识别，$\mathrm{MutL}/\mathrm{MutH}$ 协同外切酶切含子链一小段，再补连；人 $\mathrm{MSH}2/\mathrm{MSH}6$ 认错配、插入、缺失，$\mathrm{MSH}2/\mathrm{MSH}3$ 主要认插入缺失。也可看作 $\mathrm{BER}$ 的特殊形式，但酶系统不是图21-5 那一套糖苷酶。
:::

:::memory{label="本节必背"}
- 双重效应：突变（可存活、可进化、可只改基因型）vs 失去模板功能（障碍甚至死亡）。
- 多态性应用：亲子鉴定、个体识别、器官移植、易感性分析。
- 表21-4 七行按修复途径记，范科尼走重组跨越，不要改成外校分法。
- $\mathrm{HNPCC}$：$\mathrm{MLH}1/\mathrm{MSH}2$；$622$ 位 $\mathrm{C}/\mathrm{T}$，Pro$\rightarrow$Leu。
- $\mathrm{BRCA}1$：约 $70\%$ 家族性乳腺／卵巢癌失活；辐射敏感、$\mathrm{DSB}$ 修复下降。
- 癌细胞修复常升高 → 化疗耐药。
- $\mathrm{XP}$ vs $\mathrm{XPV}$（复制后修复／耐受缺陷）；$\mathrm{AT}$ 与 $\mathrm{ATM}$。
- 免疫：主要 $\mathrm{T}$ 细胞缺陷。衰老：象牛 vs 小鼠仓鼠；早老症、韦尔纳氏综合征。
