# 第三节　细胞受体介导的细胞内信号转导

第二节已经把细胞内传信号的分子分完户：小分子第二信使、酶、调节蛋白质；$\mathrm{G}$ 蛋白只立到 $\mathrm{GTP}/\mathrm{GDP}$ 开关，$\mathrm{Grb2}$ 只立到衔接蛋白质的接头。本节只立受体之后的完整途径：不同信号转导分子怎样特定组合、有序相互作用，把信号交到细胞应答。细胞内受体走分子迁移；膜受体再分成离子通道型、$\mathrm{G}$ 蛋白偶联和酶偶联／蛋白质激酶偶联三类。衔接蛋白质的 $\mathrm{SH2}$／$\mathrm{SH3}$ 结构域课不要在本节当主线再讲一遍。

:::concept{term="先问受体按本版怎么分户，再问每一类怎样把信号交到下游"}
看见“细胞受体介导的细胞内信号转导”，先不要默写七次跨膜和三级激酶。户头是：不同信号转导分子的特定组合及有序相互作用，构成不同的信号转导途径。对信号转导的了解，关键是各条途径里分子的基本组成、相互作用及引起的细胞应答。目前将各种细胞内受体归为一类；膜受体则依据结构、接收信号的种类、转换信号方式等差异，分成离子通道受体、$\mathrm{GPCR}$（七次跨膜受体）和酶偶联受体（单次跨膜受体）。同一类型受体介导的转导具有共同特点。本节用几类典型受体所介导的途径，把这些共同特点写开。
:::

:::definition{label="信号转导途径（本节）"}
不同信号转导分子的特定组合及有序的相互作用，构成不同的信号转导途径。问途径，先问「哪些分子、按什么顺序、引起什么细胞应答」，不要只背受体的中文名。
:::

:::definition{label="本版受体分类"}
各种细胞内受体归为一类。膜受体分成三种类型：①离子通道受体；②$\mathrm{GPCR}$（七次跨膜受体）；③酶偶联受体（单次跨膜受体）。章末小结把膜受体三个亚类写成离子通道型受体、$\mathrm{G}$ 蛋白偶联型受体和蛋白质激酶偶联受体。酶偶联与蛋白质激酶偶联在本版是同一类膜受体的两种叫法，不要再拆成第四大类。
:::

:::compare{title="细胞内受体 vs 三类膜受体"}
| | 本版位置 | 跨膜 | 转换之后立刻做什么 | 本节后文 |
|--|---------|------|-------------------|----------|
| 细胞内受体 | 细胞质或胞核 | 不跨膜 | 分子迁移，结合激素反应元件，调转录 | 一、图20-6 |
| 离子通道受体 | 质膜 | $4$ 个跨膜区段（表20-5） | 开闭孔道，化学信号变电信号 | 二、图20-7（电子版缺失） |
| $\mathrm{G}$ 蛋白偶联受体 | 质膜 | $7$ 次跨膜 | 激活 $\mathrm{G}$ 蛋白，再出小分子信使 | 三、图20-8、图20-9 |
| 酶偶联／蛋白质激酶偶联受体 | 质膜 | $1$ 次跨膜 | 激活蛋白质激酶，常见走 $\mathrm{MAPK}$ | 四、图20-10、图20-11（电子版缺失） |

先问「受体在哪、跨几次膜」，再问「交给谁」。不要把四条途径并成一句「都进核调基因」。
:::

**表20-5　三类膜受体的结构和功能特点**

| 特性 | 离子通道受体 | $\mathrm{G}$ 蛋白偶联受体 | 酶偶联受体 |
|------|------------|----------------------|-----------|
| 配体 | 神经递质 | 神经递质，激素，趋化因子，外源刺激（味、光） | 生长因子，细胞因子 |
| 结构 | 寡聚体形成的孔道 | 单体 | 具有或不具有催化活性的单体 |

| 功能 | 离子通道 | 激活 $\mathrm{G}$ 蛋白 | 激活蛋白质激酶 |
| 细胞应答 | 去极化与超极化 | 去极化与超极化，调节蛋白质功能和表达水平 | 调节蛋白质的功能和表达水平，调节细胞分化和增殖 |

:::keypoint{label="读表20-5 先看跨膜再看功能"}
- 离子通道：寡聚体孔道，$4$ 次跨膜，配体主要是神经递质，应答是去极化与超极化。
- $\mathrm{GPCR}$：单体，$7$ 次跨膜，配体最杂（神经递质、激素、趋化因子，以及味、光），功能是激活 $\mathrm{G}$ 蛋白。
- 酶偶联：单体，可有或没有自身催化活性，$1$ 次跨膜，功能是激活蛋白质激酶；应答落到蛋白质功能和表达、细胞分化和增殖。

「具有或不具有催化活性」这一句，就是后文「偶联有两种形式」的伏笔：自身带激酶，或靠蛋白质相互作用去激活别的激酶。
:::

:::pitfall{label="表20-5 不要加成第四列细胞内受体"}
表20-5 的标题是「三类膜受体」。细胞内受体不在这张表里，另立第一小节。把核受体也填进「跨膜区段数」，表就废了。
:::

:::insight{label="同一类型有共同特点，不是每一种受体一条专用途径"}
每种类型的受体都有许多种，各种受体激活的途径由不同分子组成，但同一类型受体介导的转导具有共同的特点。后文 $\mathrm{GPCR}$ 六步、蛋白质激酶偶联受体三阶段，写的就是「共同模式」。个性组合（$\mathrm{Gs}$ 还是 $\mathrm{Gq}$，$\mathrm{ERK}$ 还是 $\mathrm{JNK}$）在共同模式之后再分户。
:::

## 一、细胞内受体通过分子迁移传递信号

位于细胞内的受体多为转录因子。当与相应配体结合后，能与 $\mathrm{DNA}$ 的顺式作用元件结合，在转录水平调节基因表达。在没有信号分子存在时，受体往往与具有抑制作用的蛋白质分子（如热激蛋白）形成复合物，阻止受体与 $\mathrm{DNA}$ 的结合。没有结合信号分子的胞内受体主要位于细胞质中，有一些则在细胞核内。

:::definition{label="细胞内受体多为转录因子"}
位于细胞内的受体多为转录因子。结合配体后，能与 $\mathrm{DNA}$ 的顺式作用元件结合，在转录水平调节基因表达。户头落在「分子迁移 + 调转录」，不是磷酸化级联。
:::

:::definition{label="未结合配体时与热激蛋白成复合物"}
没有信号分子时，受体往往与具有抑制作用的蛋白质（如热激蛋白）形成复合物，阻止受体与 $\mathrm{DNA}$ 结合。图20-6 把这个抑制蛋白画成 $\mathrm{Hsp90}$。
:::

:::compare{title="未结合配体时受体可以在哪"}
| 位置 | 教材原句 | 激素进来之后 |
|------|---------|-------------|
| 主要在细胞质 | 没有结合信号分子的胞内受体主要位于细胞质中 | 在细胞质中结合，与热激蛋白分离，暴露核内转移部位及 $\mathrm{DNA}$ 结合部位，再迁入核 |
| 有一些在细胞核内 | 有一些则在细胞核内 | 激素被运输到核内，与受体形成激素－受体复合物 |

不要写成「全部都在细胞质里等着」。核内那一户少了，甲状腺激素一类就对不上。
:::

能与该型受体结合的信号分子有类固醇激素、甲状腺激素、维甲酸和维生素 $\mathrm{D}$ 等。当激素进入细胞后，如果其受体是位于细胞核内，激素被运输到核内，与受体形成激素－受体复合物。如果受体是位于细胞质中，激素则在细胞质中结合受体，导致受体的构象变化，与热激蛋白分离，并暴露出受体的核内转移部位及 $\mathrm{DNA}$ 结合部位，激素－受体复合物向细胞核内转移，穿过核孔，迁移进入细胞核内，并结合于其靶基因邻近的激素反应元件上。结合于激素反应元件的激素－受体复合物再与位于启动子区域的基本转录因子及其他的特异转录调节分子作用，从而开放或关闭其靶基因，进而改变细胞的基因表达谱（图20-6）。不同的激素－受体复合物结合于不同的激素反应元件（表20-6）。

:::definition{label="本版胞内受体的配体"}
类固醇激素、甲状腺激素、维甲酸和维生素 $\mathrm{D}$ 等。脂溶性，能进细胞。名单以本版句子为准，不要用其他书删掉维甲酸或维生素 $\mathrm{D}$。
:::

:::definition{label="激素反应元件"}
激素反应元件：靶基因邻近的、供激素－受体复合物结合的 $\mathrm{DNA}$ 顺式作用元件。不同的激素－受体复合物结合于不同的激素反应元件。表20-6 给出肾上腺皮质激素、雌激素、甲状腺激素三条例子。
:::

:::keypoint{label="胞内受体两条入核路径"}
- 受体已在核内：激素运到核内，形成激素－受体复合物。
- 受体在细胞质：激素在细胞质结合受体 → 构象变化 → 与热激蛋白分离 → 暴露核内转移部位及 $\mathrm{DNA}$ 结合部位 → 穿过核孔迁入核 → 结合激素反应元件。
- 之后都要再与启动子区的基本转录因子及其他特异转录调节分子作用，开放或关闭靶基因，改变基因表达谱。
:::

:::cause-effect{title="热激蛋白解离怎样接到基因表达"}
- **因** 激素结合使受体构象变化，热激蛋白解聚，核内转移部位和 $\mathrm{DNA}$ 结合部位暴露
- **果** 复合物能迁入核、结合激素反应元件，再与基本转录因子作用，开放或关闭靶基因
:::

:::pitfall{label="不要把胞内受体写成「激素一进细胞基因就开」"}
中间还有：与抑制蛋白分离、暴露定位和 $\mathrm{DNA}$ 结合部位、穿过核孔、结合特定激素反应元件、再与启动子区转录机器作用。跳过这些步骤，表20-6 的特征序列就没有落点。
:::

:::insight{label="锌指是图注里的 DNA 结合区，不是另开一类受体"}
图20-6 图注写：脂溶性激素受体通常都是转录因子，分子中具有锌指结构作为其 $\mathrm{DNA}$ 结合区。锌指是结构特征，不要据此在表20-5 外面再立「锌指受体」这一型。
:::

画面细胞质里：未结合时受体与 $\mathrm{Hsp90}$ 相连，$\mathrm{COOH}$ 端是脂溶性信号结合区，中段是 $\mathrm{DNA}$ 结合区，蓝色块是转录激活结构域。脂溶性信号从下方进入后，$\mathrm{DNA}$ 结合区及核定位区暴露。细胞核里：受体结合在 $\mathrm{ENHANCER}$ 上，并与 $\mathrm{TATA}$ 区那一团转录机器作用。看图先认「谁挡住入核」，再认「入核后落在哪一段 $\mathrm{DNA}$」。

:::

## 二、离子通道型受体将化学信号转变为电信号

离子通道型受体是一类自身为离子通道的受体。离子通道是由蛋白质寡聚体形成的孔道，其中部分单体具有配体结合部位。通道的开放或关闭直接受化学配体的控制，称为配体门控受体型离子通道，其配体主要为神经递质。

:::definition{label="离子通道型受体"}
自身为离子通道的受体。由蛋白质寡聚体形成孔道，部分单体具有配体结合部位。开放或关闭直接受化学配体控制，称为配体门控受体型离子通道。配体主要为神经递质。
:::

:::definition{label="配体门控"}
通道开闭直接受化学配体控制，不是先经 $\mathrm{G}$ 蛋白或蛋白质激酶再去开通道。问「化学信号怎样变成电信号」，先答这一句。
:::

离子通道受体的典型代表是 $\mathrm{N}$ 型乙酰胆碱受体，由 $\beta$、$\gamma$、$\delta$ 亚基以及 $2$ 个 $\alpha$ 亚基组成。$\alpha$ 亚基具有配体结合部位。两分子乙酰胆碱的结合可使通道开放，但即使有乙酰胆碱的结合，该受体处于通道开放构象状态的时限仍十分短暂，在几十毫微秒内又回到关闭状态。然后乙酰胆碱与之解离，受体恢复到初始状态，做好重新接受配体的准备（图20-7）。

:::definition{label="N 型乙酰胆碱受体"}
离子通道受体的典型代表。组成：$2$ 个 $\alpha$ 亚基，$1$ 个 $\beta$ 亚基，$1$ 个 $\gamma$ 亚基，$1$ 个 $\delta$ 亚基。$\alpha$ 亚基具有配体结合部位。两分子乙酰胆碱结合使通道开放。
:::

:::keypoint{label="图20-7 图注里的结构和三种构象"}
- 五个亚基同源性很高；每一个亚基都是四次跨膜蛋白，跨膜部分为四个 $\alpha$-螺旋，其中一个是亲水性 $\alpha$-螺旋（含较多极性氨基酸）。
- 五个亚基的亲水性 $\alpha$-螺旋共同在膜中形成一个亲水性通道。
- 乙酰胆碱结合部位在 $\alpha$ 亚基上。
- 受体可以三种构象存在。两分子乙酰胆碱结合可使之处于通道开放构象，但开放时限十分短暂，几十毫微秒内回到关闭，然后配体解离，恢复初始状态。
:::

:::insight{label="开着不等于一直开"}
「即使有乙酰胆碱的结合」，开放构象仍只维持几十毫微秒。配体还在，通道已经关。不要把「结合」写成「通道持续开放直到配体被水解」。
:::

:::pitfall{label="N 型乙酰胆碱受体不要写成七次跨膜单体"}
表20-5：离子通道受体是寡聚体孔道、跨膜区段数 $4$ 个。$\mathrm{GPCR}$ 才是单体、$7$ 次跨膜。把 $\mathrm{N}$ 型乙酰胆碱受体画成七次跨膜，$\mathrm{G}$ 蛋白循环就没有对象。
:::

:::note{label="电子版缺失"}
教材图20-7　$\mathrm{N}$ 型乙酰胆碱受体的结构与功能模式图，电子版缺失，不嵌入插图。正文保留图号；结构和三种构象以本节图注转写为准。
:::

离子通道受体信号转导的最终效应是细胞膜电位改变。这类受体引起的细胞应答主要是去极化与超极化。可以认为，离子通道受体是通过将化学信号转变成为电信号而影响细胞功能的。离子通道型受体可以是阳离子通道，如乙酰胆碱、谷氨酸和 $5$-羟色胺的受体；也可以是阴离子通道，如甘氨酸和 $\gamma$-氨基丁酸的受体。阳离子通道和阴离子通道的差异是由于构成亲水性通道的氨基酸组成不同，因而通道表面携带有不同电荷所致。

:::definition{label="化学信号转变为电信号"}
离子通道受体信号转导的最终效应是细胞膜电位改变。细胞应答主要是去极化与超极化。把化学配体写成膜电位变化，是这一型的户头。
:::

:::compare{title="阳离子通道 vs 阴离子通道"}
| | 本版配体例子 | 差别来自哪里 |
|--|------------|-------------|
| 阳离子通道 | 乙酰胆碱、谷氨酸、$5$-羟色胺的受体 | 构成亲水性通道的氨基酸组成不同，通道表面电荷不同 |
| 阴离子通道 | 甘氨酸、$\gamma$-氨基丁酸的受体 | 同上，不是另做一套「酶偶联」 |

不要把谷氨酸受体答成 $\mathrm{GPCR}$ 才有的代谢型，本句名单落在离子通道这一型。
:::

:::pitfall{label="去极化与超极化不要写成基因表达"}
表20-5 给离子通道受体的细胞应答只写「去极化与超极化」。$\mathrm{GPCR}$ 和酶偶联才写调节蛋白质功能和表达水平。把 $\mathrm{N}$ 型乙酰胆碱受体的结局答成「入核调转录」，化学信号变电信号这一户就丢了。
:::

## 三、G 蛋白偶联受体通过 G 蛋白和小分子信使介导信号转导

$\mathrm{G}$ 蛋白偶联受体（$\mathrm{GPCR}$）在结构上为单体蛋白，氨基端位于细胞膜外表面，羧基端在胞膜内侧，其肽链反复跨膜七次，因此又称为七次跨膜受体。由于肽链反复跨膜，在膜外侧和膜内侧形成了几个环状结构，分别负责接受外源信号（化学、物理信号）的刺激和细胞内的信号传递，受体的胞内部分可与三聚体 $\mathrm{G}$ 蛋白相互作用。此类受体通过 $\mathrm{G}$ 蛋白向下游传递信号，因此称为 $\mathrm{G}$ 蛋白偶联受体。

:::definition{label="G 蛋白偶联受体"}
$\mathrm{G}$ 蛋白偶联受体（$\mathrm{G}$ protein-coupled receptor，$\mathrm{GPCR}$）：单体蛋白，氨基端在膜外，羧基端在膜内，肽链反复跨膜七次，又称七次跨膜受体。胞内部分与三聚体 $\mathrm{G}$ 蛋白相互作用，通过 $\mathrm{G}$ 蛋白向下游传递信号。
:::

:::keypoint{label="七次跨膜形成的环各管一侧"}
膜外侧的环负责接受外源信号（化学、物理信号）的刺激；膜内侧的环负责细胞内的信号传递。表20-5 的配体列写了神经递质、激素、趋化因子和外源刺激（味、光），物理信号（味、光）不要删掉。
:::

:::pitfall{label="GPCR 是单体七次跨膜，不是寡聚体四次跨膜"}
和离子通道受体对调结构，表20-5 两列全错。$\mathrm{N}$ 型乙酰胆碱受体才是五个亚基、每个四次跨膜。
:::

:::insight{label="第二节只立了 G 蛋白开关，本节才写受体怎样换核苷酸"}
第二节：结合 $\mathrm{GTP}$ 活化、水解成 $\mathrm{GDP}$ 失活。本节：受体如何别构激活 $\mathrm{G}$ 蛋白、$\alpha$ 亚基如何与 $\beta\gamma$ 解离再装配，这叫 $\mathrm{G}$ 蛋白循环，见图20-8。
:::

### （一）G 蛋白偶联受体介导的信号转导途径具有相同的基本模式

不同的 $\mathrm{G}$ 蛋白（不同的 $\alpha\beta\gamma$ 组合）可与不同的下游分子组成信号转导途径。$\mathrm{GPCR}$ 介导的信号传递可通过不同的途径产生不同的效应，但信号转导途径的基本模式大致相同，主要包括以下几个步骤或阶段：①细胞外信号分子结合受体，通过别构效应将其激活。②受体激活 $\mathrm{G}$ 蛋白，$\mathrm{G}$ 蛋白在有活性和无活性状态之间连续转换，称为 $\mathrm{G}$ 蛋白循环（$\mathrm{G}$ protein cycle）（图20-8）。③活化的 $\mathrm{G}$ 蛋白激活下游效应分子。不同的 $\alpha$ 亚基激活不同的效应分子，如 $\mathrm{AC}$、$\mathrm{PLC}$ 等效应分子都是由不同的 $\mathrm{G}$ 蛋白所激活（表20-7）。有的 $\alpha$ 亚基可以激活 $\mathrm{AC}$，称为 $\alpha_{\mathrm{s}}$（$\mathrm{s}$ 代表 stimulate）；有的 $\alpha$ 亚基可以抑制 $\mathrm{AC}$，称为 $\alpha_{\mathrm{i}}$（$\mathrm{i}$ 代表 inhibit）。④$\mathrm{G}$ 蛋白的效应分子向下游传递信号的主要方式是催化产生小分子信使，如 $\mathrm{AC}$ 催化产生 $\mathrm{cAMP}$，$\mathrm{PLC}$ 催化产生 $\mathrm{DAG}$ 和 $\mathrm{IP}_3$。有些效应分子可以通过对离子通道的调节改变 $\mathrm{Ca}^{2+}$ 在细胞内的分布，其效应与 $\mathrm{IP}_3$ 的效应相似。⑤小分子信使作用于相应的靶分子（主要是蛋白质激酶），使之构象改变而激活。⑥蛋白质激酶通过磷酸化作用激活一些与代谢相关的酶、与基因表达相关的转录因子以及一些与细胞运动相关的蛋白质，从而产生各种细胞应答反应。

:::definition{label="GPCR 途径的共同基本模式"}
六步：①配体结合，别构激活受体；②受体激活 $\mathrm{G}$ 蛋白，进入 $\mathrm{G}$ 蛋白循环；③活化的 $\mathrm{G}$ 蛋白激活下游效应分子；④效应分子催化产生小分子信使，或调节离子通道改变 $\mathrm{Ca}^{2+}$ 分布；⑤小分子信使别构激活靶分子（主要是蛋白质激酶）；⑥蛋白质激酶磷酸化代谢酶、转录因子、运动相关蛋白质，产生细胞应答。
:::

:::definition{label="αs 与 αi"}
$\alpha_{\mathrm{s}}$：激活腺苷酸环化酶（stimulate）。$\alpha_{\mathrm{i}}$：抑制腺苷酸环化酶（inhibit）。都对着 $\mathrm{AC}$，方向相反，不要并成「$\mathrm{G}$ 蛋白都升 $\mathrm{cAMP}$」。
:::

:::keypoint{label="六步里谁干什么"}
- 受体：别构被激活，再去激活 $\mathrm{G}$ 蛋白。
- $\mathrm{G}$ 蛋白：循环于活性／无活性，活化后激活 $\mathrm{AC}$、$\mathrm{PLC}$ 等效应分子。
- 效应分子：主要催化出 $\mathrm{cAMP}$ 或 $\mathrm{DAG}+\mathrm{IP}_3$；也可以调离子通道改 $\mathrm{Ca}^{2+}$ 分布。
- 小分子信使：别构激活蛋白质激酶。
- 蛋白质激酶：磷酸化代谢酶、转录因子、运动蛋白。

共同模式先立完，再分 $\mathrm{cAMP}$-$\mathrm{PKA}$、$\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$、$\mathrm{Ca}^{2+}$／钙调蛋白三条途径。
:::

:::pitfall{label="不要把 Gs 和 Gq 写进同一条途径"}
$\alpha_{\mathrm{s}}$ 走 $\mathrm{AC}$-$\mathrm{cAMP}$-$\mathrm{PKA}$；$\alpha_{\mathrm{q}}$ 走 $\mathrm{PLC}$-$\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$。图20-9 左右两路不要并户。共同模式是「都经过 $\mathrm{G}$ 蛋白和小分子信使」，不是「下游效应分子都一样」。
:::

:::insight{label="改 Ca2+ 分布可以不经过 IP3"}
第四步写了两条：催化产生小分子信使；或对离子通道调节，改变 $\mathrm{Ca}^{2+}$ 分布，效应与 $\mathrm{IP}_3$ 相似。后文 $\mathrm{Ca}^{2+}$／钙调蛋白途径会再写「某些 $\mathrm{G}$ 蛋白可以直接激活质膜钙通道」。不要把所有 $\mathrm{Ca}^{2+}$ 升高都写成必须先切 $\mathrm{PIP}_2$。
:::

::figure{src="/images/biochemistry/textbook/p0424_01.png" caption="图20-8　G 蛋白循环" alt="自上而下四态：静止时 Gα 结合 GDP 并与 βγ 成三聚体，效应分子 E 未激活；配体结合激活受体；活化受体结合 G 蛋白，促进 GTP-GDP 交换；活化 Gα-GTP 结合并激活效应分子 E，βγ 解离；Gα 水解 GTP 后恢复无活性三聚体，可再次接受受体信号"}

:::definition{label="G 蛋白循环"}
$\mathrm{G}$ 蛋白循环（$\mathrm{G}$ protein cycle）：$\mathrm{G}$ 蛋白在有活性和无活性状态之间连续转换。配体激活的受体与 $\mathrm{G}$ 蛋白结合，使之构象改变，$\alpha$ 亚基与 $\mathrm{GDP}$ 亲和力下降，释放 $\mathrm{GDP}$，随即结合 $\mathrm{GTP}$。$\alpha$ 亚基结合 $\mathrm{GTP}$ 后与 $\beta\gamma$ 解离，成为活化状态，结合并激活下游效应分子。下游分子可激活 $\alpha$ 亚基的 $\mathrm{GTP}$ 酶活性，将 $\mathrm{GTP}$ 水解成 $\mathrm{GDP}$，$\alpha$ 亚基恢复原来构象，与效应分子解离，重新与 $\beta\gamma$ 结合形成三聚体，回到静止状态。
:::

:::keypoint{label="图20-8 四态对得上循环"}
- 静止：受体 $\mathrm{R}$ 空着，$\mathrm{G}\alpha$ 结合 $\mathrm{GDP}$，与 $\beta\gamma$ 成三聚体，效应分子 $\mathrm{E}$ 未结合。
- 配体结合后激活受体。
- 活化受体结合 $\mathrm{G}$ 蛋白，促进 $\mathrm{GTP}$-$\mathrm{GDP}$ 交换：$\mathrm{GDP}$ 出去，$\mathrm{GTP}$ 进来。
- 活化 $\alpha$ 亚基（$\mathrm{G}\alpha$-$\mathrm{GTP}$）结合并激活效应分子 $\mathrm{E}$，$\beta\gamma$ 解离在一旁。
- $\alpha$ 亚基水解 $\mathrm{GTP}$ 后恢复初始构象，重新形成无活性的三聚体 $\mathrm{G}$ 蛋白。画面左侧括号标明：恢复了三聚体的 $\mathrm{G}$ 蛋白可再次接受受体信号。
:::

:::cause-effect{title="为什么必须有 GTP 酶才能关掉"}
- **因** $\alpha$ 亚基结合 $\mathrm{GTP}$ 才是活化形式；下游分子激活其 $\mathrm{GTP}$ 酶，把 $\mathrm{GTP}$ 水解成 $\mathrm{GDP}$
- **果** $\alpha$ 亚基恢复构象，与效应分子解离，重新与 $\beta\gamma$ 装配，信号终止，并可再次接受受体信号

第五节霍乱毒素、$\mathrm{G}\alpha$ 突变失去 $\mathrm{GTP}$ 酶，就是这一步关不上。
:::

:::pitfall{label="βγ 解离不是被扔掉"}
图上 $\beta\gamma$ 在活化时与 $\mathrm{G}\alpha$-$\mathrm{GTP}$ 分开，静止时重新结合。第四节还会写：某些增殖细胞里 $\beta\gamma$ 二聚体可激活 $\mathrm{Src}$ 家族。把 $\beta\gamma$ 写成「没有功能的支架」，后文那一条就没有户头。本节共同模式的主账仍是 $\alpha$ 亚基激活效应分子。
:::

### （二）不同 G 蛋白偶联受体可通过不同途径传递信号

不同的细胞外信号分子与相应受体结合后，通过 $\mathrm{G}$ 蛋白传递信号，但传入细胞内的信号并不一样。这是因为不同的 $\mathrm{G}$ 蛋白与不同的下游分子组成了不同的信号转导途径。有几条途径是较常见的，本节主要介绍其中 $3$ 条途径（图20-9）。

:::definition{label="GPCR 常见三条途径"}
本版主要介绍：①$\mathrm{cAMP}$-$\mathrm{PKA}$ 途径；②$\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$ 途径；③$\mathrm{Ca}^{2+}$／钙调蛋白依赖的蛋白激酶途径。图20-9 把前两条画成 $\mathrm{G}_{\mathrm{s}}$ 与 $\mathrm{G}_{\mathrm{q}}$ 左右两路，第三条画在右侧由 $\mathrm{Ca}^{2+}$ 浓度和分布改变引出。三条不要并户。
:::

:::insight{label="传入细胞内的信号并不一样"}
都经过 $\mathrm{GPCR}$ 和 $\mathrm{G}$ 蛋白，不等于胞内第二信使相同。差别来自「不同的 $\mathrm{G}$ 蛋白与不同的下游分子」。问「为什么同一类受体效应不同」，先答这一句。
:::

#### 1. cAMP-PKA 途径

该途径以靶细胞内 $\mathrm{cAMP}$ 浓度改变和 $\mathrm{PKA}$ 激活为主要特征（图20-9）。胰高血糖素、肾上腺素、促肾上腺皮质激素等可激活此途径。$\mathrm{PKA}$ 活化后，可使多种蛋白质底物的丝氨酸／苏氨酸残基发生磷酸化，改变其活性状态，底物分子包括一些糖代谢和脂代谢相关的酶类、离子通道和某些转录因子。

:::definition{label="cAMP-PKA 途径"}
以靶细胞内 $\mathrm{cAMP}$ 浓度改变和 $\mathrm{PKA}$ 激活为主要特征。本版举例：胰高血糖素、肾上腺素、促肾上腺皮质激素。对应表20-7 的 $\alpha_{\mathrm{s}}$ 一路。
:::

:::pitfall{label="cAMP-PKA 不要写成 PLC 切 PIP2"}
升 $\mathrm{cAMP}$ 的是 $\mathrm{AC}$，不是磷脂酶 $\mathrm{C}$。$\mathrm{PLC}$ 属于 $\mathrm{G}_{\mathrm{q}}$ 那一户。图20-9 左路是 $\mathrm{G}$ 蛋白（$\mathrm{G}_{\mathrm{s}}$）→ $\mathrm{AC}$ → $\mathrm{cAMP}$ → $\mathrm{PKA}$。
:::

（1）调节代谢：$\mathrm{PKA}$ 可通过调节关键酶的活性，对不同的代谢途径发挥调节作用，如激活糖原磷酸化酶 $\mathrm{b}$ 激酶、激素敏感脂肪酶、胆固醇酯酶，促进糖原、脂肪、胆固醇的分解代谢；抑制乙酰 $\mathrm{CoA}$ 羧化酶、糖原合酶，抑制脂肪合成和糖原合成。

:::definition{label="PKA 调节代谢的关键酶"}
激活：糖原磷酸化酶 $\mathrm{b}$ 激酶、激素敏感脂肪酶、胆固醇酯酶 → 促进糖原、脂肪、胆固醇分解。抑制：乙酰 $\mathrm{CoA}$ 羧化酶、糖原合酶 → 抑制脂肪合成和糖原合成。分解开、合成关，方向不要记反。
:::

（2）调节基因表达：$\mathrm{PKA}$ 可修饰激活转录调控因子，调控基因表达。如激活后进入细胞核的 $\mathrm{PKA}$ 可使 $\mathrm{cAMP}$ 反应元件结合蛋白（$\mathrm{CREB}$）磷酸化。磷酸化的 $\mathrm{CREB}$ 结合于 $\mathrm{cAMP}$ 反应元件（$\mathrm{CRE}$），并与 $\mathrm{CREB}$ 结合蛋白（$\mathrm{CBP}$）结合。与 $\mathrm{CREB}$ 结合后的 $\mathrm{CBP}$ 作用于通用转录因子（包括 $\mathrm{TF}$Ⅱ$\mathrm{B}$），促进通用转录因子与启动子结合，激活基因的表达。

:::definition{label="CREB 通路"}
入核的 $\mathrm{PKA}$ 磷酸化 $\mathrm{CREB}$；磷酸化 $\mathrm{CREB}$ 结合 $\mathrm{CRE}$，并与 $\mathrm{CBP}$ 结合；$\mathrm{CBP}$ 再作用于通用转录因子（包括 $\mathrm{TF}$Ⅱ$\mathrm{B}$），促进其与启动子结合，激活基因表达。
:::

:::keypoint{label="CREB 四个缩写不要并成一个蛋白质"}
- $\mathrm{PKA}$：激酶，入核后磷酸化 $\mathrm{CREB}$。
- $\mathrm{CREB}$：$\mathrm{cAMP}$ 反应元件结合蛋白，被磷酸化后结合 $\mathrm{DNA}$。
- $\mathrm{CRE}$：$\mathrm{cAMP}$ 反应元件，是 $\mathrm{DNA}$ 序列，不是蛋白质。
- $\mathrm{CBP}$：$\mathrm{CREB}$ 结合蛋白，接到通用转录因子（含 $\mathrm{TF}$Ⅱ$\mathrm{B}$）。
:::

:::pitfall{label="CRE 是 DNA，CREB 是蛋白质"}
把 $\mathrm{CRE}$ 答成转录因子，或把 $\mathrm{CBP}$ 答成 $\mathrm{cAMP}$ 本身，四个缩写就搅在一起。
:::

（3）调节细胞极性：$\mathrm{PKA}$ 亦可通过磷酸化作用激活离子通道，调节细胞膜电位。

:::definition{label="PKA 调节细胞极性"}
通过磷酸化激活离子通道，调节细胞膜电位。表20-5 里 $\mathrm{GPCR}$ 的应答既有去极化与超极化，也有调节蛋白质功能和表达水平，这一条对得上「去极化与超极化」。
:::

:::compare{title="cAMP-PKA 三件下游"}
| | 改什么 | 本版点名 |
|--|--------|---------|
| 代谢 | 关键酶活性 | 开磷酸化酶 $\mathrm{b}$ 激酶、激素敏感脂肪酶、胆固醇酯酶；关乙酰 $\mathrm{CoA}$ 羧化酶、糖原合酶 |
| 基因表达 | 转录调控因子 | $\mathrm{PKA}$ → $\mathrm{CREB}$-$\mathrm{P}$ → $\mathrm{CRE}$ + $\mathrm{CBP}$ → $\mathrm{TF}$Ⅱ$\mathrm{B}$ |
| 细胞极性 | 离子通道、膜电位 | 磷酸化激活离子通道 |

问「$\mathrm{PKA}$ 只调代谢吗」，答案不是。
:::

#### 2. IP3/DAG-PKC 途径

促甲状腺素释放激素、去甲肾上腺素、抗利尿激素与受体结合后所激活的 $\mathrm{G}$ 蛋白可激活 $\mathrm{PLC}$。$\mathrm{PLC}$ 水解膜组分 $\mathrm{PIP}_2$，生成 $\mathrm{DAG}$ 和 $\mathrm{IP}_3$。$\mathrm{IP}_3$ 促进细胞钙库内的 $\mathrm{Ca}^{2+}$ 迅速释放，使细胞质内的 $\mathrm{Ca}^{2+}$ 浓度升高。$\mathrm{Ca}^{2+}$ 与细胞质内的 $\mathrm{PKC}$ 结合并聚集至质膜。质膜上的 $\mathrm{DAG}$、磷脂酰丝氨酸与 $\mathrm{Ca}^{2+}$ 共同作用于 $\mathrm{PKC}$ 的调节结构域，使 $\mathrm{PKC}$ 变构而暴露出活性中心。

:::definition{label="IP3/DAG-PKC 途径"}
促甲状腺素释放激素、去甲肾上腺素、抗利尿激素等激活的 $\mathrm{G}$ 蛋白可激活 $\mathrm{PLC}$。$\mathrm{PLC}$ 水解 $\mathrm{PIP}_2$ 得 $\mathrm{DAG}$ 和 $\mathrm{IP}_3$。对应表20-7 的 $\alpha_{\mathrm{q}}$ 一路、图20-9 中路。
:::

:::definition{label="PKC 怎样被打开"}
$\mathrm{IP}_3$ 让钙库释放 $\mathrm{Ca}^{2+}$；$\mathrm{Ca}^{2+}$ 结合细胞质内的 $\mathrm{PKC}$ 并使之聚集至质膜；质膜上的 $\mathrm{DAG}$、磷脂酰丝氨酸与 $\mathrm{Ca}^{2+}$ 共同作用于 $\mathrm{PKC}$ 的调节结构域，变构暴露活性中心。三者缺一，不要写成「只有 $\mathrm{DAG}$ 就能激活 $\mathrm{PKC}$」。
:::

:::compare{title="Gs 的 cAMP-PKA vs Gq 的 IP3/DAG-PKC"}
| | $\mathrm{G}$ 蛋白 | 效应分子 | 第二信使 | 激酶 |
|--|----------------|---------|---------|--------|
| 左路 | $\mathrm{G}_{\mathrm{s}}$ | $\mathrm{AC}$ | $\mathrm{cAMP}$ | $\mathrm{PKA}$ |
| 中路 | $\mathrm{G}_{\mathrm{q}}$ | $\mathrm{PLC}$ | $\mathrm{DAG}+\mathrm{IP}_3$（$\mathrm{IP}_3$ 再升 $\mathrm{Ca}^{2+}$） | $\mathrm{PKC}$ |

配体名单也不一样：胰高血糖素／肾上腺素／促肾上腺皮质激素走左路；促甲状腺素释放激素／去甲肾上腺素／抗利尿激素走中路。不要并户。
:::

:::pitfall{label="DAG 和 IP3 不要写反落点"}
第二节已立：$\mathrm{DAG}$ 留在质膜，$\mathrm{IP}_3$ 开钙库。本节激活 $\mathrm{PKC}$ 时，$\mathrm{DAG}$ 在质膜上参与，$\mathrm{IP}_3$ 的贡献是把 $\mathrm{Ca}^{2+}$ 放出来。写成「$\mathrm{IP}_3$ 留在膜上激活 $\mathrm{PKC}$」，两户对调。
:::

受 $\mathrm{PKC}$ 磷酸化修饰的蛋白质包括一些质膜受体、膜蛋白质及多种酶，因此，$\mathrm{PKC}$ 可参与多种生理功能的调节。此外，$\mathrm{PKC}$ 能使立早基因（immediate-early gene）的转录调控因子磷酸化，加速立早基因的表达。立早基因多数为细胞原癌基因（如 $\mathrm{c}$-$\mathrm{fos}$），其表达产物经磷酸化修饰后，进一步活化晚期反应基因并促进细胞增殖。

:::definition{label="立早基因"}
立早基因（immediate-early gene）：$\mathrm{PKC}$ 磷酸化其转录调控因子后加速表达。多数为细胞原癌基因（如 $\mathrm{c}$-$\mathrm{fos}$）。表达产物再经磷酸化修饰，活化晚期反应基因并促进细胞增殖。
:::

:::insight{label="PKC 既改膜上蛋白质，也改基因表达"}
底物包括质膜受体、膜蛋白质及多种酶；另外还能加速立早基因表达。问「$\mathrm{PKC}$ 只留在膜上做代谢」不够。立早基因多数是原癌基因这一句，为第五节增殖异常留了接口，本节只立到促进细胞增殖。
:::

:::pitfall{label="c-fos 不要写成 MAPK 才有的专属基因"}
本版在 $\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$ 这一条里点名 $\mathrm{c}$-$\mathrm{fos}$。后文 $\mathrm{MAPK}$ 入核也磷酸化转录因子，但不要把 $\mathrm{c}$-$\mathrm{fos}$ 从 $\mathrm{PKC}$ 这一户删掉。
:::

#### 3. $\mathrm{Ca}^{2+}$／钙调蛋白依赖的蛋白激酶途径

$\mathrm{G}$ 蛋白偶联受体至少可通过三种方式引起细胞内 $\mathrm{Ca}^{2+}$ 浓度升高：某些 $\mathrm{G}$ 蛋白可以直接激活细胞质膜上的钙通道，或通过 $\mathrm{PKA}$ 激活细胞质膜的钙通道，促进 $\mathrm{Ca}^{2+}$ 流入细胞质；或通过 $\mathrm{IP}_3$ 促使细胞质钙库释放 $\mathrm{Ca}^{2+}$。

细胞质中的 $\mathrm{Ca}^{2+}$ 浓度升高后，通过结合钙调蛋白传递信号。$\mathrm{Ca}^{2+}/\mathrm{CaM}$ 复合物的下游信号转导分子是一些蛋白质激酶，它们的共同特点是可被 $\mathrm{Ca}^{2+}/\mathrm{CaM}$ 复合物激活，因而统称为钙调蛋白依赖性蛋白质激酶。钙调蛋白依赖性激酶属于蛋白质丝氨酸／苏氨酸激酶，如肌球蛋白轻链激酶（$\mathrm{MLCK}$）、磷酸化酶激酶（$\mathrm{PhK}$）、钙调蛋白依赖性激酶（$\mathrm{Cal}$-$\mathrm{PK}$）Ⅰ、Ⅱ、Ⅲ等。这些激酶可激活各种效应蛋白质，可在收缩和运动、物质代谢、神经递质的合成、细胞分泌和分裂等多种生理过程中起作用。如 $\mathrm{Cal}$-$\mathrm{PK}$ Ⅱ可修饰激活突触蛋白Ⅰ、酪氨酸羟化酶、色氨酸羟化酶、骨骼肌糖原合酶等，参与神经递质的合成与释放以及糖代谢等多种细胞功能的调节。

:::definition{label="GPCR 升高 Ca2+ 的三种方式"}
①某些 $\mathrm{G}$ 蛋白直接激活质膜钙通道；②通过 $\mathrm{PKA}$ 激活质膜钙通道，促进 $\mathrm{Ca}^{2+}$ 流入细胞质；③通过 $\mathrm{IP}_3$ 促使细胞质钙库释放 $\mathrm{Ca}^{2+}$。至少这三种，不要只留 $\mathrm{IP}_3$ 一条。
:::

:::definition{label="钙调蛋白依赖性蛋白质激酶"}
可被 $\mathrm{Ca}^{2+}/\mathrm{CaM}$ 复合物激活的蛋白质激酶的统称，属于蛋白质丝氨酸／苏氨酸激酶。本版举例：$\mathrm{MLCK}$、$\mathrm{PhK}$、$\mathrm{Cal}$-$\mathrm{PK}$ Ⅰ、Ⅱ、Ⅲ等。
:::

:::definition{label="Cal-PK Ⅱ 的底物举例"}
突触蛋白Ⅰ、酪氨酸羟化酶、色氨酸羟化酶、骨骼肌糖原合酶等。功能落到神经递质的合成与释放以及糖代谢。
:::

:::keypoint{label="Ca2+/CaM 途径和前两条的交接"}
- 方式②借用了 $\mathrm{cAMP}$-$\mathrm{PKA}$ 途径的 $\mathrm{PKA}$。
- 方式③借用了 $\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$ 途径的 $\mathrm{IP}_3$。
- 方式①是 $\mathrm{G}$ 蛋白直接开质膜钙通道，不经过 $\mathrm{AC}$ 或 $\mathrm{PLC}$。

图20-9 右侧把 $\mathrm{Ca}^{2+}$ 通道画成还受 $\mathrm{PKC}$、$\mathrm{PKA}$ 影响，再写出 $\mathrm{Ca}^{2+}$ 浓度和分布改变 → $\mathrm{Ca}^{2+}/\mathrm{CaM}$ → $\mathrm{CaM}$ 依赖性蛋白质激酶。三条途径有交接，户头仍要分开。
:::

:::compare{title="三种升钙方式差在钙从哪来"}
| 方式 | 通道／来源 | 要不要借前两条的酶 |
|------|----------|------------------|
| 某些 $\mathrm{G}$ 蛋白直接激活 | 质膜钙通道，胞外 $\mathrm{Ca}^{2+}$ 内流 | 不借 $\mathrm{AC}$、不借 $\mathrm{PLC}$ |
| 经 $\mathrm{PKA}$ | 质膜钙通道 | 借 $\mathrm{cAMP}$-$\mathrm{PKA}$ |
| 经 $\mathrm{IP}_3$ | 细胞质钙库释放 | 借 $\mathrm{PLC}$-$\mathrm{IP}_3$ |

问「$\mathrm{GPCR}$ 怎样升钙」，答出三种，不要只背 $\mathrm{IP}_3$。
:::

:::pitfall{label="钙调蛋白依赖性激酶不要写成酪氨酸激酶"}
教材写明属于蛋白质丝氨酸／苏氨酸激酶。$\mathrm{MLCK}$、$\mathrm{PhK}$、$\mathrm{Cal}$-$\mathrm{PK}$ Ⅰ／Ⅱ／Ⅲ都在这一类。酪氨酸激酶是酶偶联受体那一户的主账。
:::

- 中：$\mathrm{G}$ 蛋白（$\mathrm{G}_{\mathrm{q}}$）→ $\mathrm{PLC}$ 切 $\mathrm{PIP}_2$ → $\mathrm{DAG}+\mathrm{IP}_3$ → $\mathrm{PKC}$。
- 右：$\mathrm{IP}_3$ 指向 $\mathrm{Ca}^{2+}$ 通道；$\mathrm{PKC}$、$\mathrm{PKA}$ 也可作用于该通道；$\mathrm{Ca}^{2+}$ 浓度和分布改变 → $\mathrm{Ca}^{2+}/\mathrm{CaM}$ → $\mathrm{CaM}$ 依赖性蛋白质激酶。

三路末端都写「效应蛋白质 → 生物学效应」。看图先分 $\mathrm{G}_{\mathrm{s}}$ 与 $\mathrm{G}_{\mathrm{q}}$，再认右侧升钙。

画面明确标了 $\mathrm{G}_{\mathrm{s}}$ 和 $\mathrm{G}_{\mathrm{q}}$。把整张图答成「$\mathrm{cAMP}$ 途径」，$\mathrm{PLC}$ 和 $\mathrm{CaM}$ 两路就没了。

## 四、酶偶联受体主要通过蛋白质修饰或相互作用传递信号

酶偶联受体主要是生长因子和细胞因子的受体。此类受体介导的信号转导主要是调节蛋白质的功能和表达水平、调节细胞增殖和分化。

:::definition{label="酶偶联受体"}
主要是生长因子和细胞因子的受体。表20-5：单次跨膜，单体可有或没有催化活性，功能是激活蛋白质激酶。介导的转导主要调节蛋白质的功能和表达水平，调节细胞增殖和分化。
:::

:::insight{label="酶偶联和蛋白质激酶偶联是同一类的两种叫法"}
小节标题用「酶偶联受体」，下一小节标题用「蛋白质激酶偶联受体」。章末小结把膜受体第三亚类写成蛋白质激酶偶联受体。本版没有在二者之间再拆一型。
:::

:::compare{title="GPCR vs 酶偶联：主账差在哪"}
| | 跨膜 | 立刻交给谁 | 主要细胞应答（表20-5） |
|--|------|-----------|---------------------|
| $\mathrm{GPCR}$ | $7$ 次 | $\mathrm{G}$ 蛋白 → 小分子信使 | 去极化与超极化，调节蛋白质功能和表达水平 |
| 酶偶联 | $1$ 次 | 蛋白质激酶（自身或偶联） | 调节蛋白质功能和表达水平，调节细胞分化和增殖 |

$\mathrm{GPCR}$ 一般在分化成熟组织里调节代谢（第四节还会补一句）；酶偶联更常落到增殖和分化。不要把表皮生长因子受体画成七次跨膜。
:::

### （一）蛋白质激酶偶联受体介导的信号转导途径具有相同的基本模式

蛋白质激酶偶联受体介导的信号转导途径较复杂。细胞内的蛋白质激酶有许多种，不同蛋白质激酶组合成不同的信号转导途径。各种途径的具体作用模式虽有差别，但基本模式大致相同，主要包括以下几个阶段：①胞外信号分子与受体结合，导致第一个蛋白质激酶被激活。这一步反应是「蛋白质激酶偶联受体」名称的由来。「偶联」有两种形式。有的受体自身具有蛋白质激酶活性，此步骤是激活受体胞内结构域的蛋白质激酶活性。有些受体自身没有蛋白质激酶活性，此步骤是受体通过蛋白质－蛋白质相互作用激活某种蛋白质激酶。②通过蛋白质－蛋白质相互作用或蛋白质激酶的磷酸化修饰作用激活下游信号转导分子，从而传递信号，最终仍是激活一些特定的蛋白质激酶。③蛋白质激酶通过磷酸化修饰激活代谢途径中的关键酶、转录调控因子等，影响代谢途径、基因表达、细胞运动、细胞增殖等。

:::definition{label="蛋白质激酶偶联受体的基本模式"}
三阶段：①配体结合，激活第一个蛋白质激酶；②蛋白质相互作用或磷酸化修饰，把信号传下去，最终仍激活特定蛋白质激酶；③这些激酶磷酸化关键酶、转录调控因子等，影响代谢、基因表达、细胞运动、细胞增殖。
:::

:::definition{label="偶联的两种形式"}
①受体自身具有蛋白质激酶活性：激活受体胞内结构域的激酶活性。②受体自身没有蛋白质激酶活性：通过蛋白质－蛋白质相互作用激活某种蛋白质激酶。表20-5「具有或不具有催化活性的单体」对的就是这一句。
:::

:::keypoint{label="名称里的「偶联」指的是第一步"}
「蛋白质激酶偶联受体」这个名字，来自「胞外信号分子与受体结合，导致第一个蛋白质激酶被激活」。第一个激酶可以是受体自己，也可以是被受体叫来的那一个。不要把「偶联」理解成必须有 $\mathrm{G}$ 蛋白。
:::

:::pitfall{label="自身没有激酶活性不等于不是这一型"}
细胞因子受体一类可以自身没有催化活性，仍通过蛋白质相互作用激活激酶，仍叫酶偶联／蛋白质激酶偶联受体。写成「没有激酶就只能是 $\mathrm{GPCR}$」，表20-5 的「或不具有催化活性」就废了。
:::

:::insight{label="最终仍是激活特定的蛋白质激酶"}
第二阶段无论走相互作用还是走磷酸化，落点还是激酶。这和 $\mathrm{GPCR}$「最终常落到小分子信使 → 激酶」不同：这里可以不经过 $\mathrm{cAMP}$、$\mathrm{IP}_3$。后文 $\mathrm{MAPK}$ 级联就是这一句的展开。
:::

### （二）MAPK 途径是最常见的蛋白质激酶偶联受体介导的信号转导途径

目前已发现的蛋白质激酶偶联受体介导的信号转导途径有十几条，如 $\mathrm{JAK}$-$\mathrm{STAT}$ 途径、$\mathrm{Smad}$ 途径、$\mathrm{PI3K}$ 途径、$\mathrm{NF}$-$\kappa\mathrm{B}$ 途径等，本节介绍最常见的 $\mathrm{MAPK}$ 途径。以丝裂原激活的蛋白质激酶（$\mathrm{MAPK}$）为代表的信号转导途径称为 $\mathrm{MAPK}$ 途径，其主要特点是具有 $\mathrm{MAPK}$ 级联反应。$\mathrm{MAPK}$ 至少有 $12$ 种，分属于 $\mathrm{ERK}$ 家族、$\mathrm{p38}$ 家族、$\mathrm{JNK}$ 家族。这 $3$ 条信号转导途径的组成和信号转导的细胞内效应见图20-10。

:::definition{label="MAPK 途径"}
以丝裂原激活的蛋白质激酶（$\mathrm{MAPK}$）为代表的信号转导途径。主要特点是具有 $\mathrm{MAPK}$ 级联反应。是最常见的蛋白质激酶偶联受体介导的途径。
:::

:::definition{label="本版 MAPK 的家族和数目"}
$\mathrm{MAPK}$ 至少有 $12$ 种，分属于 $\mathrm{ERK}$ 家族、$\mathrm{p38}$ 家族、$\mathrm{JNK}$ 家族。三条途径的组成和细胞内效应见图20-10。数目和分家以本版为准，不要用其他书的级数名单替换。
:::

:::insight{label="十几条途径里本节只把 MAPK 走完"}
点名过 $\mathrm{JAK}$-$\mathrm{STAT}$、$\mathrm{Smad}$、$\mathrm{PI3K}$、$\mathrm{NF}$-$\kappa\mathrm{B}$，但「本节介绍最常见的 $\mathrm{MAPK}$ 途径」。第四节交互作用会再借用 $\mathrm{Smad}$、$\mathrm{PI3K}$，不要在本节把那几条也当主账写完。
:::

:::pitfall{label="不要把 MAPK 写成只有 ERK 一条"}
至少 $12$ 种，三大家族。图20-10 明确画出 $\mathrm{P38}$、$\mathrm{JNK}$、$\mathrm{ERK}$ 三路入核。把 $\mathrm{MAPK}$ 等同于 $\mathrm{ERK1/2}$，应激和凋亡那一户就没有激酶。
:::

在不同的细胞中，$\mathrm{MAPK}$ 途径的成员组成及诱导的细胞应答有所不同。其中了解最清楚的是 $\mathrm{Ras}/\mathrm{MAPK}$ 途径（图20-11）。$\mathrm{Ras}/\mathrm{MAPK}$ 途径转导生长因子，如表皮生长因子（$\mathrm{EGF}$）信号，其基本过程是：①受体与配体结合后形成二聚体，激活受体的蛋白质激酶活性；②受体自身酪氨酸残基磷酸化，形成 $\mathrm{SH2}$ 结合位点，从而能够结合含有 $\mathrm{SH2}$ 结构域的接头蛋白 $\mathrm{Grb2}$；③$\mathrm{Grb2}$ 的两个 $\mathrm{SH3}$ 结构域与 $\mathrm{SOS}$ 分子中的富含脯氨酸序列结合，将 $\mathrm{SOS}$ 活化；④活化的 $\mathrm{SOS}$ 结合 $\mathrm{Ras}$ 蛋白，促进 $\mathrm{Ras}$ 释放 $\mathrm{GDP}$、结合 $\mathrm{GTP}$；⑤活化的 $\mathrm{Ras}$ 蛋白（$\mathrm{Ras}$-$\mathrm{GTP}$）可激活 $\mathrm{MAPKKK}$，活化的 $\mathrm{MAPKKK}$ 可磷酸化 $\mathrm{MAPKK}$ 而将其激活，活化的 $\mathrm{MAPKK}$ 将 $\mathrm{MAPK}$ 磷酸化而激活；⑥活化的 $\mathrm{MAPK}$ 可以转位至细胞核内，通过磷酸化作用激活多种效应蛋白质，从而使细胞对外来信号产生生物学应答。

:::definition{label="Ras/MAPK 途径"}
了解最清楚的 $\mathrm{MAPK}$ 途径。转导生长因子如表皮生长因子（$\mathrm{EGF}$）信号。$\mathrm{Ras}$-$\mathrm{GTP}$ 启动下游 $\mathrm{MAPK}$ 级联。完整图为图20-11。
:::

:::definition{label="EGFR 途径六步"}
①配体结合，受体二聚化，激活受体蛋白质激酶活性；②自身酪氨酸残基磷酸化，形成 $\mathrm{SH2}$ 结合位点，结合 $\mathrm{Grb2}$；③$\mathrm{Grb2}$ 的两个 $\mathrm{SH3}$ 结合 $\mathrm{SOS}$ 的富含脯氨酸序列，活化 $\mathrm{SOS}$；④$\mathrm{SOS}$ 结合 $\mathrm{Ras}$，促进释放 $\mathrm{GDP}$、结合 $\mathrm{GTP}$；⑤$\mathrm{Ras}$-$\mathrm{GTP}$ 激活 $\mathrm{MAPKKK}$，$\mathrm{MAPKKK}$ 磷酸化激活 $\mathrm{MAPKK}$，$\mathrm{MAPKK}$ 磷酸化激活 $\mathrm{MAPK}$；⑥$\mathrm{MAPK}$ 转位入核，磷酸化多种效应蛋白质。
:::

:::definition{label="Ras-GTP 启动 MAPK 级联"}
活化的 $\mathrm{Ras}$ 蛋白（$\mathrm{Ras}$-$\mathrm{GTP}$）可激活 $\mathrm{MAPKKK}$，再经 $\mathrm{MAPKK}$ 到 $\mathrm{MAPK}$。第二节只立「$\mathrm{Ras}$-$\mathrm{GTP}$ 可启动 $\mathrm{MAPK}$ 级联」这一句；三级激酶的名字和六步顺序是本节的账。
:::

:::keypoint{label="六步里接头只为接通 SOS 和 Ras"}
$\mathrm{Grb2}$ 在这里的用处是：$\mathrm{SH2}$ 认受体上的磷酸酪氨酸，$\mathrm{SH3}$ 认 $\mathrm{SOS}$ 的脯氨酸序列，把 $\mathrm{SOS}$ 接到已磷酸化的受体旁边，让 $\mathrm{SOS}$ 去给 $\mathrm{Ras}$ 换核苷酸。结构域表、$\mathrm{PH}$、$\mathrm{PTB}$ 不要在这一段当主线重讲。
:::

:::cause-effect{title="二聚化怎样接到 Ras-GTP"}
- **因** 配体使受体二聚化并自身磷酸化，制造 $\mathrm{SH2}$ 结合位点，募集 $\mathrm{Grb2}$-$\mathrm{SOS}$
- **果** $\mathrm{SOS}$ 促进 $\mathrm{Ras}$ 释放 $\mathrm{GDP}$、结合 $\mathrm{GTP}$，得到 $\mathrm{Ras}$-$\mathrm{GTP}$，从而启动 $\mathrm{MAPKKK}$→$\mathrm{MAPKK}$→$\mathrm{MAPK}$
:::

:::pitfall{label="MAPK 级联不要换成其他书的口诀级数"}
本版正文写的是 $\mathrm{MAPKKK}$、$\mathrm{MAPKK}$、$\mathrm{MAPK}$ 三级。图20-10 给出各家族的具体成员。不要用莱宁格或其他教材的级数名单替换这三级，也不要把「至少 $12$ 种」改成别的数字。
:::

:::pitfall{label="自身磷酸化的是酪氨酸，下游 MAPK 不要写成同一件事"}
第②步是受体自身酪氨酸残基磷酸化，为的是造 $\mathrm{SH2}$ 结合位点。第⑤步 $\mathrm{MAPKK}$ 磷酸化 $\mathrm{MAPK}$，那是级联里的激酶磷酸化激酶。两步不要并成「受体直接磷酸化 $\mathrm{MAPK}$」。
:::

:::note{label="电子版缺失"}
教材图20-11　$\mathrm{EGFR}$ 介导的信号转导途径电子版缺失，不嵌入插图。正文保留图号；六步以本节文字为准。
:::

上述 $\mathrm{Ras}/\mathrm{MAPK}$ 途径是 $\mathrm{EGFR}$ 的主要信号途径之一。此外，许多单次跨膜受体也可以激活这一信号途径，甚至 $\mathrm{G}$ 蛋白偶联受体也可以通过一些调节分子作用在这一途径。由于 $\mathrm{EGFR}$ 的胞内段存在着多个酪氨酸磷酸化位点，因此除 $\mathrm{Grb2}$ 外，还可募集其他含有 $\mathrm{SH2}$ 结构域的信号转导分子，激活 $\mathrm{PLC}$-$\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$ 途径、$\mathrm{PI3K}$ 等其他信号途径。

:::definition{label="EGFR 不止 Ras/MAPK 一条"}
$\mathrm{Ras}/\mathrm{MAPK}$ 是 $\mathrm{EGFR}$ 的主要信号途径之一，不是唯一。胞内段有多个酪氨酸磷酸化位点，除 $\mathrm{Grb2}$ 外还可募集其他含 $\mathrm{SH2}$ 的分子，激活 $\mathrm{PLC}$-$\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$ 途径、$\mathrm{PI3K}$ 等。
:::

:::keypoint{label="谁还可以汇入 Ras/MAPK"}
- 许多单次跨膜受体可以激活这一途径。
- 甚至 $\mathrm{GPCR}$ 也可以通过一些调节分子作用在这一途径。

第四节会把「一种受体同时激活几条途径」「$\mathrm{GPCR}$ 的 $\beta\gamma$ 接到 $\mathrm{MAPK}$」展开。本节只立到：途径可以共用，不要把 $\mathrm{EGFR}$ 锁死成只有 $\mathrm{Grb2}$-$\mathrm{SOS}$-$\mathrm{Ras}$。
:::

:::pitfall{label="不要在这里把疾病例子写完"}
$\mathrm{ERB}$-$\mathrm{B}$ 截短型 $\mathrm{EGF}$ 受体、$\mathrm{RAS}$ 突变使细胞持续增殖，是第五节的账。本节只把正常六步和「还可走 $\mathrm{PLC}$、$\mathrm{PI3K}$」立住。
:::

:::compare{title="本节四类受体各把信号写成什么"}
| 受体 | 转换的关键动作 | 典型结局 |
|------|--------------|---------|
| 细胞内受体 | 与热激蛋白分离，迁入核，结合激素反应元件 | 开放或关闭靶基因 |
| 离子通道型 | 配体门控开闭孔道 | 膜电位：去极化与超极化 |
| $\mathrm{GPCR}$ | $\mathrm{G}$ 蛋白循环 → 小分子信使 → 激酶 | 代谢、基因表达、膜电位、运动 |
| 酶偶联／蛋白质激酶偶联 | 激活第一个激酶，常见 $\mathrm{MAPK}$ 级联 | 蛋白质功能和表达，增殖、分化 |

问「受体介导的细胞内信号转导」，先分这四户，再答具体分子。
:::

:::memory{label="本节必背要点"}
- 细胞内受体归为一类；膜受体三类：离子通道（寡聚体、$4$ 次跨膜）、$\mathrm{GPCR}$（单体、$7$ 次跨膜）、酶偶联／蛋白质激酶偶联（单体、$1$ 次跨膜）。
- 胞内受体多为转录因子；未结合时与热激蛋白（图上 $\mathrm{Hsp90}$）成复合物；配体：类固醇激素、甲状腺激素、维甲酸、维生素 $\mathrm{D}$；迁入核结合激素反应元件（图20-6、表20-6）。
- $\mathrm{N}$ 型乙酰胆碱受体：$2\alpha+\beta+\gamma+\delta$，两分子乙酰胆碱开放通道，几十毫微秒关闭；化学信号变电信号。图20-7 电子版缺失。
- $\mathrm{GPCR}$ 六步 + $\mathrm{G}$ 蛋白循环（图20-8）。表20-7：$\alpha_{\mathrm{s}}$、$\alpha_{\mathrm{i}}$、$\alpha_{\mathrm{q}}$、$\alpha_{\mathrm{t}}$。三条途径：$\mathrm{cAMP}$-$\mathrm{PKA}$（$\mathrm{G}_{\mathrm{s}}$）、$\mathrm{IP}_3/\mathrm{DAG}$-$\mathrm{PKC}$（$\mathrm{G}_{\mathrm{q}}$）、$\mathrm{Ca}^{2+}/\mathrm{CaM}$，不要并户（图20-9）。
- 「偶联」两种形式：自身有激酶，或蛋白质相互作用激活激酶。$\mathrm{MAPK}$ 至少 $12$ 种，分 $\mathrm{ERK}$、$\mathrm{p38}$、$\mathrm{JNK}$（图20-10）。
- $\mathrm{EGFR}$ 六步：二聚化 → 自身 $\mathrm{Tyr}$ 磷酸化 → $\mathrm{Grb2}$ → $\mathrm{SOS}$ → $\mathrm{Ras}$-$\mathrm{GTP}$ → $\mathrm{MAPKKK}$→$\mathrm{MAPKK}$→$\mathrm{MAPK}$ 入核。图20-11 电子版缺失。$\mathrm{EGFR}$ 还可走 $\mathrm{PLC}$、$\mathrm{PI3K}$。
:::
