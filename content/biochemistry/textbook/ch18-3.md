# 第三节　DNA测序技术

第二节把 $\mathrm{PCR}$ 写成高通量测序的基础之一，但没有解释碱基顺序怎样读出来。本节的目的是确定一段 $\mathrm{DNA}$ 中 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{T}$ 的排列：经典方法是桑格－库森双脱氧法与化学降解法；$1986$ 年以后的高通量测序大多源于桑格策略的循环芯片；第三代则对单分子测序，不必先 $\mathrm{PCR}$ 扩增模板。医学上的全基因组、转录物组、外显子组和 $\mathrm{ChIP}$-$\mathrm{seq}$ 是读序之后的应用，不是另一种化学反应。

:::concept{term="先问终止的是 ddNTP 还是化学切断，再问高通量是不是还在边合成边读"}
看见“$\mathrm{DNA}$ 测序”，先不要默写芯片杂交。户头是：读出 $4$ 种碱基的排列。桑格法用 $\mathrm{ddNTP}$ 造成 $3'$ 端不能成磷酸二酯键，一管一种终止碱基，变性聚丙烯酰胺凝胶按差 $1$ 个核苷酸分开。高通量把这个「合成时读信号」做成微阵列循环；焦磷酸读的是焦磷酸，离子半导体读的是 $\mathrm{H}^{+}$，$\mathrm{SOLiD}$ 换成连接酶。$\mathrm{SMRT}$、纳米孔才取消模板扩增，直接看单分子。
:::

$\mathrm{DNA}$ 测序（DNA sequencing）的目的是确定一段 $\mathrm{DNA}$ 分子中 $4$ 种碱基（$\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{T}$）的排列顺序。$\mathrm{DNA}$ 测序技术是阐明和理解基因结构、功能、变异、表达调控的基础，也是实现在分子层次预测、预防、诊断和治疗疾病的个体化医学的最重要的支撑技术。

:::definition{label="DNA 测序"}
$\mathrm{DNA}$ 测序（DNA sequencing）：确定一段 $\mathrm{DNA}$ 分子中 $4$ 种碱基（$\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{T}$）的排列顺序。
:::

:::definition{label="测序在分子医学里的位置"}
阐明和理解基因结构、功能、变异、表达调控的基础；也是在分子层次预测、预防、诊断和治疗疾病的个体化医学最重要的支撑技术。
:::

:::insight{label="测的是排列顺序，不是「有没有这条基因」"}
Southern 问基因组里有没有、区带在哪；$\mathrm{PCR}$ 问能不能扩出来。测序问每一个位置是 $\mathrm{A}$ 还是 $\mathrm{G}$。$\mathrm{SNP}$、突变位点、融合基因，都要先有这本顺序账。
:::

分子生物学发展初期，采用部分酶解等方法仅能测定 $\mathrm{RNA}$ 的序列，且费时费力。$1977$ 年，$\mathrm{Maxam}\ \mathrm{A}.$ 和 $\mathrm{Gilbert}\ \mathrm{W}.$ 合作发明了化学降解法（chemical degradation method），又称马克萨姆－吉尔伯特法；同期，$\mathrm{Sanger}\ \mathrm{F}.$ 和 $\mathrm{Coulson}\ \mathrm{A}.$ 创建了桑格－库森法（Sanger-Coulson method）。这两种方法的建立实现了 $\mathrm{DNA}$ 测序技术的第一次飞跃，也因此分享了 $1980$ 年的诺贝尔化学奖。$40$ 余年来，$\mathrm{DNA}$ 测序技术发展迅速，从手工操作到自动化仪器分析、从单一短片段到高通量并行分析，尤其是在人类基因组计划的推动下，实现了高速和低价的目标，人全基因组测序已成为常规技术。快速测序技术极大推动了生物学和医学多个领域的理论突破和应用研究。

:::definition{label="测序第一次飞跃的两套方法"}
$1977$ 年：化学降解法（马克萨姆－吉尔伯特法）；桑格－库森法。二者实现 $\mathrm{DNA}$ 测序第一次飞跃，分享 $1980$ 年诺贝尔化学奖。在此之前只能用部分酶解等方法测 $\mathrm{RNA}$，费时费力。
:::

## 一、桑格－库森法和化学降解法是经典 DNA 测序方法

早期的 $\mathrm{DNA}$ 测序只能在实验室内手工完成，故基本上是用于分子生物学研究工作，采用的是桑格－库森法或化学降解法。

:::definition{label="经典测序的使用场景"}
早期只能手工完成，基本上用于分子生物学研究，方法就是这两套。普及到临床和人群全基因组，要等后文自动化和高通量。
:::

### （一）桑格－库森法的原理是基于 ddNTP 底物终止 DNA 合成

桑格－库森法又称双脱氧法（dideoxy termination method）、链终止法（chain termination method），其技术原理如图18-5 所示。用 $\mathrm{DNA}$ 聚合酶延伸结合在待测序列的单链 $\mathrm{DNA}$ 模板上的反应底物——$5'$－末端放射性核素标记的寡脱氧核苷酸引物，当新合成的 $\mathrm{DNA}$ 链的 $3'$－末端聚合的是 $2',3'$－双脱氧核苷三磷酸（$\mathrm{ddNTP}$）反应底物时，由于 $\mathrm{ddNTP}$ 的 $3'$－位碳原子上缺少羟基而不能与下一位脱氧核苷酸的 $5'$－位磷酸基之间形成 $3',5'$－磷酸二酯键，从而使得正在延伸的产物 $\mathrm{DNA}$ 链在该 $\mathrm{ddNTP}$ 处终止。因此，在 $4$ 个独立的 $\mathrm{DNA}$ 合成反应体系中分别掺入适量 $4$ 种不同的 $\mathrm{ddNTP}$ 底物，就可得到终止于相应特定碱基的一系列不同长度 $\mathrm{DNA}$ 片段的产物。这些产物具有共同的起点（即引物的 $5'$－末端），而有不同的终点（即 $\mathrm{ddNTP}$ 掺入的位置），其长度取决于 $\mathrm{ddNTP}$ 掺入的位置与引物 $5'$－末端之间的距离。经可分辨 $1$ 个核苷酸差别的变性聚丙烯酰胺凝胶电泳分离这些 $\mathrm{DNA}$ 聚合酶催化合成的产物，再借助片段 $5'$－末端标记的放射性核素自显影，即可读出一段 $\mathrm{DNA}$ 序列。而放射性核素标记在底物 $\mathrm{ddNTP}$ 或用荧光分子标记，可以达到同样的测序效果。

::figure{src="/images/biochemistry/textbook/p0374_01.png" caption="图18-5　双脱氧法测序原理。双链 DNA 变成单链模板，5′ 标记引物结合；DNA 聚合酶、引物与 dNTP 存在下，掺入 ddNTP（糖环 2′、3′ 均为 H）即终止。四个反应管分加四种 ddNTP，产物经电泳按 A、C、G、T 泳道分离；负极在上、正极在下，按差 1 个核苷酸的区带读序。" alt="桑格双脱氧测序：标记引物延伸，ddNTP终止，四泳道凝胶自下而上读碱基"}

:::definition{label="桑格－库森法的三个名字"}
桑格－库森法（Sanger-Coulson method）又称双脱氧法（dideoxy termination method）、链终止法（chain termination method）。三个名字说的是同一件事：$\mathrm{ddNTP}$ 让链在特定碱基处停住。
:::

:::definition{label="ddNTP 为什么能终止"}
$2',3'$－双脱氧核苷三磷酸（$\mathrm{ddNTP}$）的 $3'$－位碳原子上缺少羟基，不能与下一位脱氧核苷酸的 $5'$－位磷酸基形成 $3',5'$－磷酸二酯键。新链 $3'$ 端一旦装上 $\mathrm{ddNTP}$，延伸停止。
:::

:::definition{label="四管反应得到共起点、不同终点的片段"}
$4$ 个独立体系分别掺入适量 $4$ 种不同 $\mathrm{ddNTP}$，得到终止于相应特定碱基、一系列不同长度的产物。共同起点：引物的 $5'$－末端。不同终点：$\mathrm{ddNTP}$ 掺入位置。长度 $=$ 该位置与引物 $5'$ 端之间的距离。
:::

:::definition{label="差 1 个核苷酸的胶就能读序"}
变性聚丙烯酰胺凝胶电泳可分辨 $1$ 个核苷酸差别。借助片段 $5'$－末端放射性核素自显影读出序列。核素标在底物 $\mathrm{ddNTP}$ 上，或改用荧光分子标记，效果相同。
:::

:::insight{label="图18-5 左栏是反应组分，右栏是一管终止片段怎样变成四道条带"}
左：双链 $\mathrm{DNA}$ 片段变为单链模板（印刷图有处将「$\mathrm{DNA}$」印成「$\mathrm{DMA}$」，正文仍是单链 $\mathrm{DNA}$ 模板），引物 $5'$ 端黑点为标记，序列示例 $\mathrm{CATTA}$ 与模板 $3'$ 侧配对。下方列出 $\mathrm{DNA}$ 聚合酶、引物、$\mathrm{dNTP}$，以及 $2',3'$ 均为 $\mathrm{H}$ 的 $\mathrm{ddNTP}$ 结构（三磷酸连到糖的 $\mathrm{CH}_{2}\mathrm{O}$，碱基为 $\mathrm{A}.\mathrm{C}.\mathrm{G}.\mathrm{T}$）。右：四管反应后电泳，泳道标 $\mathrm{A}$、$\mathrm{C}$、$\mathrm{G}$、$\mathrm{T}$，负极在上、正极在下，旁注可读序列。较短片段更靠近正极。
:::

:::keypoint{label="读胶方向跟着「共起点」"}
所有产物的 $5'$ 都是同一条标记引物，所以最短的带离引物最近，对应新链 $5'$ 端附近第一个被终止的碱基。胶上差 $1$ 个核苷酸一档，从短到长就是从引物往 $3'$ 读。
:::

:::pitfall{label="缺的是 3′-OH，不是 5′ 磷酸"}
终止理由是 $3'$－位碳上没有羟基，形不成 $3',5'$－磷酸二酯键。不要答成「$\mathrm{ddNTP}$ 没有磷酸所以不能接」。图中 $\mathrm{ddNTP}$ 仍带三磷酸。
:::

:::pitfall{label="dNTP 和 ddNTP 要同时在管里"}
适量 $\mathrm{ddNTP}$ 掺入，才能在该种碱基的各个出现位置随机终止，得到「一系列不同长度」。若只加 $\mathrm{ddNTP}$、不加 $\mathrm{dNTP}$，链在第一个该碱基处全部停死，没有阶梯。
:::

:::pitfall{label="分辨 1 个核苷酸的是变性 PAGE，不是琼脂糖"}
第一节 Southern 用琼脂糖分基因组大片段；这里要差 $1$ 个核苷酸，教材指定变性聚丙烯酰胺凝胶电泳。胶选错，四管产物分不开。
:::

:::pitfall{label="标记可以在引物 5′，也可以在 ddNTP 或改成荧光"}
经典图是引物 $5'$ 核素。正文补充：核素标在底物 $\mathrm{ddNTP}$，或用荧光分子，同样可读序。后文第一代自动测序就是四色荧光标在四种 $\mathrm{ddNTP}$ 上，不再靠放射自显影。
:::

:::compare{title="PCR 延伸 vs 桑格延伸"}
| | $\mathrm{PCR}$ | 桑格双脱氧 |
|--|-------------|------------|
| 底物 | $\mathrm{dNTP}$ | $\mathrm{dNTP}$ $+$ 适量某一种 $\mathrm{ddNTP}$ |
| $3'$ 端 | 一直有 $\mathrm{OH}$，可继续成磷酸二酯键 | 一旦装上 $\mathrm{ddNTP}$ 即终止 |
| 产物 | 两端由引物限定的大量等长短产物 | 共 $5'$ 起点、不同终止点的长度阶梯 |
| 读出 | 看有没有这条带／多少 | 按差 $1$ nt 的阶梯读碱基顺序 |

都用 $\mathrm{DNA}$ 聚合酶和引物，桑格多的是「故意在特定碱基停住」。
:::

### （二）化学降解法的原理是基于碱基专一性化学切断 DNA

化学降解法，又称 $\mathrm{DNA}$ 化学测序法（chemical method of DNA sequencing）、碱基特异性裂解法（base-specific cleavage method）。首先对待测序的单链 $\mathrm{DNA}$ 片段的末端进行放射性核素标记，然后用几组专一性化学试剂修饰该片段 $\mathrm{DNA}$ 的碱基，并在修饰处随机断裂，从而产生 $4$ 套含有长短不一 $\mathrm{DNA}$ 片段的混合物，凝胶电泳分离、放射自显影后读出序列。这一方法的建立在分子生物学发展早期发挥了重要作用，但因对待测 $\mathrm{DNA}$ 要求较高、试剂毒性和自动化较难实现等原因，并未得到广泛应用。

:::definition{label="化学降解法"}
又称 $\mathrm{DNA}$ 化学测序法、碱基特异性裂解法。单链 $\mathrm{DNA}$ 末端核素标记 $\rightarrow$ 几组专一性化学试剂修饰碱基并在修饰处随机断裂 $\rightarrow$ $4$ 套长短不一的片段混合物 $\rightarrow$ 凝胶电泳、自显影读序。
:::

:::definition{label="化学法为什么没铺开"}
对待测 $\mathrm{DNA}$ 要求较高，试剂有毒性，自动化较难实现，故未得到广泛应用。早期有重要作用，后文高通量几乎都从桑格策略长出来。
:::

:::pitfall{label="化学法切断的是已有的 DNA，不是边合成边终止"}
桑格：聚合酶合成时掺入 $\mathrm{ddNTP}$ 停住。化学法：先有一条待测单链，化学修饰后再断开。不要把「$4$ 套片段」都写成 $\mathrm{ddNTP}$ 产物。
:::

:::compare{title="桑格双脱氧 vs 化学降解"}
| | 桑格－库森 | 马克萨姆－吉尔伯特 |
|--|------------|---------------------|
| 关键化学 | $\mathrm{ddNTP}$ 缺 $3'$-$\mathrm{OH}$，合成终止 | 碱基专一性化学修饰 $+$ 断裂 |
| 标记 | 引物 $5'$ 核素，或标在 $\mathrm{ddNTP}$／荧光 | 待测单链末端核素 |
| 四套产物 | 四管各掺一种 $\mathrm{ddNTP}$ | 几组试剂得到四套断裂混合物 |
| 读出 | 变性 $\mathrm{PAGE}$，差 $1$ nt | 凝胶电泳 $+$ 自显影 |
| 后来命运 | 自动化、四色荧光、循环芯片的源头 | 毒性、难自动化，未广泛使用 |

第一次飞跃是两法并列；后面几乎只沿着左边走。
:::

## 二、高通量测序技术大多源于桑格－库森法的测序策略

桑格－库森法和化学降解法的手工操作对经验和技术熟练程度要求很高，失败概率高，难以在普通实验室推广普及，更难以满足分子生物学的迅速发展，及其在医学实践中需要对人群及个体进行全基因组序列分析的需求，因而催生了快速低成本的系列高通量测序（high-throughput sequencing，$\mathrm{HTS}$）技术和自动化测序仪的发明。$1986$ 年推出的第一代平板电泳全自动 $\mathrm{DNA}$ 序列分析仪，基于桑格－库森法策略，采用四色荧光试剂分别标记 $4$ 种 $\mathrm{ddNTP}$，替代引物的放射性核素标记。由于第一代测序仪高成本和通量的限制，应运而生了系列大规模矩阵结构的微阵列分析技术。例如，循环芯片测序（cyclic-array sequencing）策略，使用 $\mathrm{DNA}$ 聚合酶或连接酶，将引物在高通量的 $\mathrm{DNA}$ 样品芯片上对模板循环进行并行延伸反应，通过显微设备观察并记录连续测序循环中的光学等信号，可快速读取所有序列，再经生物信息学整合分析，得出样本中所有 $\mathrm{DNA}$ 序列。这些测序技术大多与桑格－库森法的策略类似，充分利用 $\mathrm{DNA}$ 合成过程中的各组分，如产物或 $\mathrm{DNA}$ 聚合酶等的变化而实现序列分析。

:::definition{label="高通量测序"}
高通量测序（high-throughput sequencing，$\mathrm{HTS}$）：对着手工两法难普及、又要做人群及个体全基因组分析的需求，出现的快速低成本系列技术及自动化测序仪。
:::

:::definition{label="1986 年第一代自动测序仪"}
平板电泳全自动 $\mathrm{DNA}$ 序列分析仪，基于桑格－库森策略，四色荧光分别标记 $4$ 种 $\mathrm{ddNTP}$，替代引物上的放射性核素。
:::

:::definition{label="循环芯片测序"}
循环芯片测序（cyclic-array sequencing）：用 $\mathrm{DNA}$ 聚合酶或连接酶，在高通量 $\mathrm{DNA}$ 样品芯片上对模板循环并行延伸；显微设备记录连续循环中的光学等信号，快速读取全部序列，再经生物信息学整合，得到样本中所有 $\mathrm{DNA}$ 序列。
:::

:::insight{label="「源于桑格策略」指的是合成过程里读变化，不一定还用 ddNTP"}
教材写：大多与桑格－库森法策略类似，充分利用 $\mathrm{DNA}$ 合成过程中各组分（产物或聚合酶等）的变化。第一代仍用荧光 $\mathrm{ddNTP}$；Illumina 改成可逆终止的 $\mathrm{dNTP}$；焦磷酸读产物焦磷酸；$\mathrm{SOLiD}$ 连连接酶都换了。共同处是「一边合成（或连接），一边读这一位」。
:::

:::pitfall{label="循环芯片不是第一节的基因芯片"}
基因芯片：已知探针固定，荧光样品杂交，问表达差异。循环芯片测序：样品 $\mathrm{DNA}$ 在芯片上当模板，引物循环延伸，问碱基顺序。支持物都可以叫芯片，化学反应不是杂交那一张。
:::

:::keypoint{label="从第一代到循环芯片的催生原因"}
- 手工两法：经验要求高，失败率高，普通实验室难普及。
- 医学需求：人群及个体全基因组。
- 第一代自动仪：四色荧光 $\mathrm{ddNTP}$，仍受高成本和通量限制。
- 于是：大规模矩阵微阵列 $+$ 循环并行延伸。
:::

### （一）自动激光荧光测序是利用荧光标记的 ddNTP 为底物的桑格－库森法

自动激光荧光 $\mathrm{DNA}$ 测序仪（第一代测序）的应用已十分普遍，它可实现制胶、进样、电泳、检测、数据分析全自动化，读长可以超过 $1\,000\,\mathrm{bp}$，原始数据的准确率可高达 $99.999\%$。

在四色荧光法分析中，采用可终止 $\mathrm{DNA}$ 延伸反应的 $4$ 种荧光染料分别标记的底物 $\mathrm{ddNTP}$，经双脱氧法反应后，赋予所合成的 $\mathrm{DNA}$ 片段 $4$ 种不同的颜色。待测 $\mathrm{DNA}$ 样品的 $4$ 个反应产物在 $1986$ 年推出的平板电泳全自动测序仪的同一个泳道内，或 $1998$ 年推出的毛细管测序仪上，依据片段大小分离，由仪器自动连续采集荧光数据并完成分析，直接显示出待测 $\mathrm{DNA}$ 的碱基序列。

人类基因组计划的第一个人类基因组草图的绘制，采用的就是自动激光荧光测序。中国、美国、英国、日本、法国、德国、加拿大等 $7$ 个国家的科学家合作，用了数以千计的自动激光荧光测序仪，以集成式工厂化运行模式，在 $2003$ 年发布了人类基因组草图，标志着正式进入基因组学时代。

$2006$ 年推出的 Illumina 测序平台（被认为是第二代测序的 $3$ 大平台之一），策略与自动激光荧光测序类似，其技术核心是四色荧光物质分别连接在 $\mathrm{dNTP}$ 的 $3'$-$\mathrm{OH}$ 的可逆修饰基团上。当其掺入合成的 $\mathrm{DNA}$ 链后 $\mathrm{DNA}$ 合成反应被终止，根据所标记的荧光读出所添加的碱基。然后去修饰，恢复 $3'$-$\mathrm{OH}$，进行下一轮测序反应。

:::definition{label="自动激光荧光测序仪（第一代）"}
制胶、进样、电泳、检测、数据分析全自动化。读长可超过 $1\,000\,\mathrm{bp}$，原始数据准确率可高达 $99.999\%$。
:::

:::definition{label="四色荧光 ddNTP 把四管合成一管读"}
$4$ 种荧光染料分别标记可终止延伸的 $\mathrm{ddNTP}$，产物带 $4$ 种颜色。$1986$ 年平板电泳仪：四个反应产物在同一个泳道内按大小分离。$1998$ 年毛细管测序仪：同样按片段大小分离。仪器连续采集荧光，直接显示碱基序列。
:::

:::definition{label="人类基因组草图用的就是这一代"}
中国、美国、英国、日本、法国、德国、加拿大 $7$ 国，数以千计自动激光荧光测序仪，集成式工厂化运行，$2003$ 年发布人类基因组草图，正式进入基因组学时代。
:::

:::definition{label="Illumina：可逆终止的四色 dNTP"}
$2006$ 年推出，第二代 $3$ 大平台之一。策略类似自动激光荧光测序。四色荧光连在 $\mathrm{dNTP}$ 的 $3'$-$\mathrm{OH}$ 的可逆修饰基团上：掺入后合成终止，读荧光得知该位碱基；去修饰，恢复 $3'$-$\mathrm{OH}$，进入下一轮。
:::

:::insight{label="Illumina 相对桑格：终止变成可逆，才能一位一位循环"}
桑格 $\mathrm{ddNTP}$ 的 $3'$ 永远没有羟基，那根链就此结束，靠长度阶梯一次读出。Illumina 让 $3'$-$\mathrm{OH}$ 先堵住再打开，同一条链上循环加下一个碱基。这就是循环芯片测序里「循环」二字在合成化学上的着落。
:::

:::pitfall{label="读长超过 1000 bp 和准确率 99.999% 是第一代自动仪的数字"}
不要安到焦磷酸、$\mathrm{SOLiD}$ 或纳米孔上。第二、三代的长短、准不准，教材另有定性描述（如 $\mathrm{SOLiD}$ 读长短、$\mathrm{SMRT}$ 读长较长）。
:::

:::pitfall{label="Illumina 标在 dNTP 的可逆 3′-OH 上，不是 ddNTP"}
第一代：荧光 $\mathrm{ddNTP}$，不可逆终止。Illumina：荧光在 $\mathrm{dNTP}$ 的可逆修饰基团上。底物名字差一个 $\mathrm{d}$，循环能不能继续差在「去修饰」。
:::

:::pitfall{label="七国名单不要漏中国或改成美英两国"}
教材按中国、美国、英国、日本、法国、德国、加拿大排列。草图年份是 $2003$ 年。
:::

:::compare{title="手工桑格 vs 第一代四色 vs Illumina"}
| | 手工双脱氧 | 自动激光荧光（第一代） | Illumina（第二代之一） |
|--|------------|------------------------|------------------------|
| 终止物 | $\mathrm{ddNTP}$ | 四色荧光 $\mathrm{ddNTP}$ | 可逆修饰的四色 $\mathrm{dNTP}$ |
| 几管／几道 | 四管四道胶 | 同泳道或毛细管，四色一次读 | 芯片上循环，每位一色 |
| 标记 | 引物核素或 $\mathrm{ddNTP}$ 核素 | 荧光替代核素 | 荧光在可逆 $3'$-$\mathrm{OH}$ 修饰基团 |
| 下一步 | 自显影读胶 | 仪器采集荧光 | 去修饰，恢复 $3'$-$\mathrm{OH}$，下一轮 |
| 代表数字 | 手工、难普及 | 读长 $>1\,000\,\mathrm{bp}$，准确率 $99.999\%$；$2003$ 草图 | $2006$ 年平台 |

三代都还在「合成时看这一位是哪种碱基」。
:::

### （二）焦磷酸测序是基于检测 DNA 合成的产物焦磷酸

$2005$ 年推出的焦磷酸测序（pyrosequencing）平台（也称 $454$ 测序，第二代测序的 $3$ 大平台之一），综合运用了微乳滴 $\mathrm{PCR}$、微流控芯片、焦磷酸检测等技术。该技术将引物固化在微球上，与单链 $\mathrm{DNA}$ 相结合，构建成 $\mathrm{DNA}$ 模板文库，利用微乳滴 $\mathrm{PCR}$ 扩增，由此每个微球表面都结合了大量相同的 $\mathrm{DNA}$ 片段。然后将微球转移到带有数以百千万计的规则排列微孔的芯片上，每个微孔只能容纳 $1$ 个微球，即每微孔为 $1$ 个测序的反应器。采用各微孔不同步的序贯边合成边测序方式，即测序时一次仅加入一种 $\mathrm{dNTP}$，该 $\mathrm{dNTP}$ 在能与模板碱基互补的微孔中，被 $\mathrm{DNA}$ 聚合酶添加到 $\mathrm{DNA}$ 链上，同时释放出产物焦磷酸，触发微孔中的 $\mathrm{ATP}$ 硫酸化酶和荧光素酶等产生级联反应而释放出光信号，该光学信号被与微孔接触的 $\mathrm{CCD}$ 光学检测系统检测到，即实时读取了模板 $\mathrm{DNA}$ 序列。关键过程如图18-6A。

$2011$ 年推出的离子半导体测序（ion semiconductor sequencing）平台，策略与焦磷酸测序类似。焦磷酸测序是利用 $\mathrm{DNA}$ 合成的产物焦磷酸触发荧光级联反应，而离子半导体测序是通过芯片上的每个微孔接入的微型 $\mathrm{pH}$ 计，测定 $\mathrm{DNA}$ 合成时释放出的氢离子（短暂的 $\mathrm{pH}$ 变化），转为读出 $\mathrm{DNA}$ 序列的数字信号。

:::definition{label="焦磷酸测序（454）"}
$2005$ 年推出，第二代 $3$ 大平台之一。综合微乳滴 $\mathrm{PCR}$、微流控芯片、焦磷酸检测。引物固在微球上与单链 $\mathrm{DNA}$ 结合，微乳滴 $\mathrm{PCR}$ 使每个微球表面布满相同片段；微球进入只能容 $1$ 个微球的微孔，每孔一个反应器。
:::

:::definition{label="序贯边合成边测序"}
各微孔不同步。一次只加一种 $\mathrm{dNTP}$；能互补的孔里聚合酶把它接到链上，释放焦磷酸 $\rightarrow$ $\mathrm{ATP}$ 硫酸化酶和荧光素酶等级联发光 $\rightarrow$ $\mathrm{CCD}$ 检测 $\rightarrow$ 实时读取该孔模板序列。
:::

:::definition{label="离子半导体测序"}
$2011$ 年推出，策略类似焦磷酸测序。不走焦磷酸－荧光级联，而用微孔上的微型 $\mathrm{pH}$ 计测定合成时释放的氢离子（短暂 $\mathrm{pH}$ 变化），转为序列的数字信号。
:::

:::insight{label="图18-6A 要记住的不是胶，是「一孔一球、一次一种 dNTP、光一闪就是一位」"}
没有 $\mathrm{ddNTP}$ 长度阶梯。这一位加进去没有，靠焦磷酸能不能触发发光来判断。一次只加一种 $\mathrm{dNTP}$，四色不是同时在管里，而是时间上序贯。
:::

:::cause-effect{title="焦磷酸和氢离子为什么都能代表「这一位加上了」"}
- **因** 聚合反应把 $\mathrm{dNTP}$ 接到链上时，释放焦磷酸，同时有氢离子变化
- **果** $454$ 用焦磷酸驱动发光；离子半导体用微型 $\mathrm{pH}$ 计读 $\mathrm{H}^{+}$；二者都是「合成产物／副产物」当信号，不必再跑胶
:::

:::pitfall{label="一次只加一种 dNTP，不是四种荧光 ddNTP 同时终止"}
与第一代四色同泳道相反：焦磷酸是序贯加碱基。把 $454$ 答成「还是四色 $\mathrm{ddNTP}$」，级联发光就没有化学。
:::

:::pitfall{label="每个微孔只能 1 个微球，微乳滴 PCR 已经在球上扩过"}
文库先在微球上做成「大量相同片段」，再一球一孔。不要把微乳滴 $\mathrm{PCR}$ 理解成测序循环本身；它是给每个反应器准备足够模板。
:::

:::compare{title="焦磷酸 vs 离子半导体"}
| | 焦磷酸测序（$454$，$2005$） | 离子半导体（$2011$） |
|--|---------------------------|----------------------|
| 合成时释放什么 | 焦磷酸 | 氢离子（短暂 $\mathrm{pH}$ 变化） |
| 怎样变成可读信号 | $\mathrm{ATP}$ 硫酸化酶 $+$ 荧光素酶级联发光，$\mathrm{CCD}$ 检测 | 微孔微型 $\mathrm{pH}$ 计 $\rightarrow$ 数字信号 |
| 加 dNTP 的方式 | 一次一种，序贯 | 策略类似 |
| 还要不要荧光 | 要（级联光） | 教材写的是 $\mathrm{pH}$，不是荧光 |

「类似」在合成化学，「不同」在读哪一种副产物。
:::

### （三）SOLiD 测序是利用 DNA 连接酶代替 DNA 聚合酶

$2007$ 年推出的 $\mathrm{SOLiD}$ 测序（Sequencing by Oligo Ligation Detection，$\mathrm{SOLiD}$）平台（第二代测序的 $3$ 大平台之一）基于寡核苷酸连接反应，利用乳液 $\mathrm{PCR}$、微流控芯片，检测 $\mathrm{DNA}$ 连接酶催化的四色荧光标记的 $8$ 碱基测序探针连接到 $\mathrm{DNA}$ 链过程中释放出的光学信号。其中 $8$ 碱基探针的前 $2$ 个碱基是测序用的碱基，即双碱基编码；中间 $3$ 个通用碱基可以与任何碱基配对；后 $3$ 个是测序时会被剪切掉的荧光标记碱基。这样组合排列就有 $16$ 种探针，四色荧光标记时每种颜色对应 $4$ 种排列。测序时 $\mathrm{DNA}$ 连接酶将测序引物与利用前 $2$ 个碱基与模板特异配对的测序探针连接，测定荧光信号后，化学剪切后 $3$ 个碱基，加入第 $2$ 个探针连接，再测定荧光信号，如此循环测定，直到合成整条链。接着，偏移 $1$ 个、$2$ 个、$3$ 个、$4$ 个碱基重复上述过程，也就是会测 $5$ 轮，最后通过 $16$ 种荧光探针的双碱基编码矩阵得到序列。可见每个碱基将被读 $2$ 遍，所以准确度高。$\mathrm{SOLiD}$ 测序由于读长较短，拼接复杂，运行速度较慢等原因，已较少使用。

:::definition{label="SOLiD"}
Sequencing by Oligo Ligation Detection，$2007$ 年推出，第二代 $3$ 大平台之一。基于寡核苷酸连接反应，用乳液 $\mathrm{PCR}$、微流控芯片，检测连接酶把四色荧光标记的 $8$ 碱基探针连到 $\mathrm{DNA}$ 链时的光学信号。
:::

:::definition{label="8 碱基探针的三段"}
前 $2$ 个：测序用的碱基，即双碱基编码。中间 $3$ 个：通用碱基，可与任何碱基配对。后 $3$ 个：带荧光，测序时被剪切掉。组合得 $16$ 种探针；四色标记时每种颜色对应 $4$ 种排列。
:::

:::definition{label="五轮偏移，每个碱基读两遍"}
连接酶把引物与前 $2$ 碱基配对的探针连上 $\rightarrow$ 测荧光 $\rightarrow$ 化学剪切后 $3$ 个碱基 $\rightarrow$ 接下一个探针，循环至整条链。再偏移 $1$、$2$、$3$、$4$ 个碱基各做一轮，共 $5$ 轮，用 $16$ 种探针的双碱基编码矩阵还原序列。每个碱基被读 $2$ 遍，准确度高。
:::

:::definition{label="SOLiD 为何已较少使用"}
读长较短，拼接复杂，运行速度较慢。
:::

:::keypoint{label="第二代三大平台在教材里的分工"}
- $2005$ 焦磷酸（$454$）：聚合酶 $+$ 焦磷酸发光。
- $2006$ Illumina：聚合酶 $+$ 可逆荧光 $\mathrm{dNTP}$。
- $2007$ $\mathrm{SOLiD}$：连接酶 $+$ 双碱基编码探针。

问「哪一个不用 $\mathrm{DNA}$ 聚合酶延伸」，答 $\mathrm{SOLiD}$。
:::

:::pitfall{label="代替的是聚合酶，不是取消模板扩增"}
$\mathrm{SOLiD}$ 仍用乳液 $\mathrm{PCR}$。第三代「无须 $\mathrm{PCR}$ 扩增模板」还没开始。把 $\mathrm{SOLiD}$ 答成单分子测序，HeliScope／$\mathrm{SMRT}$／纳米孔就没有分界。
:::

:::pitfall{label="前 2 个碱基编码，后 3 个带荧光并被剪掉"}
读序信息在前 $2$ 位；荧光在后 $3$ 位，读完要化学剪切掉才能接下一个探针。不要把荧光画在前 $2$ 个测序碱基上，也不要把中间 $3$ 个通用碱基当成序列本身。
:::

:::pitfall{label="5 轮不是 25～30 次 PCR 循环"}
$5$ 轮是偏移 $0$ 再加偏移 $1\sim 4$。$\mathrm{PCR}$ 的 $25\sim 30$ 是扩增倍数那本账。
:::

:::compare{title="第二代三大平台"}
| | Illumina（$2006$） | 焦磷酸／$454$（$2005$） | $\mathrm{SOLiD}$（$2007$） |
|--|-------------------|------------------------|------------------------|
| 酶 | $\mathrm{DNA}$ 聚合酶 | $\mathrm{DNA}$ 聚合酶 | $\mathrm{DNA}$ 连接酶 |
| 信号 | 可逆四色荧光 $\mathrm{dNTP}$ | 焦磷酸 $\rightarrow$ 发光 | $8$ 碱基探针的四色荧光 |
| 一位怎么定 | 读掺入的那一种荧光，再去修饰 | 哪一种 $\mathrm{dNTP}$ 能发光 | 前 $2$ 碱基双编码，矩阵还原 |
| 模板准备 | 循环芯片策略 | 微乳滴 $\mathrm{PCR}$ $+$ 一球一孔 | 乳液 $\mathrm{PCR}$ $+$ 微流控 |
| 教材补充 | — | 离子半导体改读 $\mathrm{H}^{+}$ | 每碱基读 $2$ 遍；后因读短、拼接慢而少用 |

三家都还在第二代：先扩增，再在阵列上循环读。
:::

### （四）纳米技术的发展促成多种单分子测序技术

随着纳米技术的发展，如纳米的效应、材料、微加工和超灵敏检测等，更新一代的测序技术则无须 $\mathrm{PCR}$ 扩增模板，直接针对 $\mathrm{DNA}$ 单分子测序（single-molecule sequencing），又称第三代测序技术。这些技术包括 HeliScope 单分子测序技术、单分子实时测序（single molecule real time sequencing，$\mathrm{SMRT}$）和纳米孔测序（nanopore sequencing）等，从而实现了单细胞测序（single cell sequencing），即在单个细胞水平上对基因序列、结构及表达状态进行分析。单细胞测序结果不仅能够以高分辨率显示单个细胞的基因组结构和基因表达差异信息，而且可以在单细胞尺度展示组织器官，甚至个体不同细胞及其相互作用，已成为空间组学（spatial omics）和时空组学（spatiotemporal omics）的主要技术之一，应用于复杂组织微环境和动态生物过程、细胞分化及组织发育和疾病发生发展等研究。

:::definition{label="第三代：单分子测序"}
无须 $\mathrm{PCR}$ 扩增模板，直接对 $\mathrm{DNA}$ 单分子测序（single-molecule sequencing）。依赖纳米效应、材料、微加工和超灵敏检测。教材点名 HeliScope、$\mathrm{SMRT}$、纳米孔测序。
:::

:::definition{label="单细胞测序"}
在单个细胞水平上对基因序列、结构及表达状态进行分析。高分辨率显示单个细胞的基因组结构和基因表达差异；在单细胞尺度展示组织器官、甚至个体不同细胞及其相互作用。是空间组学、时空组学的主要技术之一，用于复杂组织微环境、动态过程、分化发育和疾病发生发展。
:::

:::insight{label="「无须 PCR」对着第二代的微乳滴／乳液扩增"}
$454$、$\mathrm{SOLiD}$ 都先在微球上扩出大量相同片段。第三代把检测灵敏度做到单分子，扩增这一步可以拿掉，也避免扩增引入的偏差。单细胞测序能成立，前提常常就是单分子水平的读序。
:::

:::pitfall{label="第三代不是「循环芯片的第四个平台」"}
循环芯片测序写在第二代策略下；单分子测序另起「更新一代」「无须 $\mathrm{PCR}$」。不要把 $\mathrm{SMRT}$ 填进「第二代三大平台」那一格（三大是焦磷酸、Illumina、$\mathrm{SOLiD}$）。
:::

**1. HeliScope 单分子测序**　$2008$ 年推出，是利用超灵敏度的荧光探测仪，直接以单个固定在纳米材料上的单链 $\mathrm{DNA}$ 模板上进行边合成边测序，检测的还是 $\mathrm{DNA}$ 合成时荧光物质标记的 $\mathrm{dNTP}$ 所释放的荧光。由于读长较短、仪器售价高，目前应用并不多。

:::definition{label="HeliScope"}
$2008$ 年推出。超灵敏荧光探测仪，对固定在纳米材料上的单个单链 $\mathrm{DNA}$ 模板边合成边测序，读的仍是荧光标记 $\mathrm{dNTP}$ 释放的荧光。读长短、仪器贵，目前应用不多。
:::

**2. SMRT**　单分子实时测序技术是利用纳米尺度的零模波导（zero-mode waveguide，$\mathrm{ZMW}$）效应，通过激光共聚焦测得芯片上每个微纳米孔中仅固定的 $1$ 个 $\mathrm{DNA}$ 聚合酶分子添加荧光物质标记的 $\mathrm{dNTP}$ 时所释放的荧光，实现单分子的实时测序，关键过程如图18-6B。$\mathrm{SMRT}$ 测序具有较长的读长和较高的准确性，广泛应用于基因组组装、基因组结构变异分析、表观基因组学等领域。

:::definition{label="SMRT"}
单分子实时测序（single molecule real time sequencing）：零模波导（$\mathrm{ZMW}$）效应；激光共聚焦读取每个微纳米孔中仅固定的 $1$ 个 $\mathrm{DNA}$ 聚合酶分子在添加荧光 $\mathrm{dNTP}$ 时释放的荧光。读长较长、准确性较高；用于基因组组装、结构变异、表观基因组学等。
:::

:::insight{label="图18-6B：一孔一酶，荧光在掺入的那一瞬"}
与 $454$「一孔一球（球上已是扩增过的许多分子）」不同：$\mathrm{SMRT}$ 孔里是 $1$ 个聚合酶分子对着一条模板。实时二字来自掺入当时就读荧光，不必等一轮终止再去修饰。
:::

**3. 纳米孔测序**　是将 $\mathrm{DNA}$ 单链或 $\mathrm{RNA}$ 单个分子穿过加上电压的蛋白质纳米孔时，不同碱基所产生的电流信号不同，从而测得序列，关键过程如图18-6C。纳米孔测序具有较长的读长，可以分析修饰的碱基，直接进行 $\mathrm{RNA}$ 测序，和无须 $\mathrm{PCR}$ 扩增等优势，为检测大型的基因组结构变异、解析高度重复序列、表观基因组学和转录物组学等研究提供了有力工具。

:::definition{label="纳米孔测序"}
$\mathrm{DNA}$ 单链或 $\mathrm{RNA}$ 单个分子穿过加电压的蛋白质纳米孔，不同碱基产生不同电流信号，从而测得序列。优势：读长较长；可分析修饰的碱基；可直接 $\mathrm{RNA}$ 测序；无须 $\mathrm{PCR}$ 扩增。用于大型结构变异、高度重复序列、表观基因组学和转录物组学等。
:::

:::pitfall{label="纳米孔读的是电流，不是荧光"}
HeliScope 和 $\mathrm{SMRT}$ 仍看荧光 $\mathrm{dNTP}$。纳米孔改看过孔电流，所以能直接对 $\mathrm{RNA}$、能看修饰碱基，而不必先把它们变成标准 $\mathrm{dNTP}$ 荧光反应。
:::

:::pitfall{label="直接 RNA 测序是纳米孔的优势，不是所有第三代的共同写法"}
教材把「直接进行 $\mathrm{RNA}$ 测序」写在纳米孔条下。HeliScope／$\mathrm{SMRT}$ 正文仍是 $\mathrm{DNA}$ 模板 $+$ 荧光 $\mathrm{dNTP}$。不要给三种单分子技术统一抄「直接测 $\mathrm{RNA}$」。
:::

:::compare{title="三种单分子测序"}
| | HeliScope（$2008$） | $\mathrm{SMRT}$ | 纳米孔 |
|--|-------------------|--------------|--------|
| 模板 | 固定在纳米材料上的单个单链 $\mathrm{DNA}$ | 微纳米孔中 $1$ 个聚合酶对着单分子 | 单链 $\mathrm{DNA}$ 或单个 $\mathrm{RNA}$ 过孔 |
| 信号 | 荧光标记 $\mathrm{dNTP}$ 的荧光 | 荧光 $\mathrm{dNTP}$ 的荧光（$\mathrm{ZMW}$ $+$ 共聚焦） | 不同碱基的电流差别 |
| 读长／现状 | 较短；仪器贵，应用不多 | 较长、准确性较高 | 较长 |
| 额外能力 | — | 组装、结构变异、表观基因组 | 修饰碱基、直接 $\mathrm{RNA}$ 测序、大结构变异、高度重复序列 |

共同处：无须 $\mathrm{PCR}$ 扩增模板。差别处：荧光合成 vs 过孔电流。
:::

## 三、DNA 测序在医学领域具有广泛应用价值

高通量 $\mathrm{DNA}$ 测序技术的快速进步，极大促进了全基因组测序（whole genome sequencing，$\mathrm{WGS}$）、转录物组测序（transcriptome sequencing）［即 $\mathrm{RNA}$ 测序（$\mathrm{RNA}$-seq）］、外显子组测序（exome sequencing）、染色质免疫沉淀测序（$\mathrm{ChIP}$-seq）等在医学研究和实践中的应用，为分子医学进入大数据时代提供了核心技术支撑。

:::definition{label="测序支撑的四种组学读法"}
全基因组测序（$\mathrm{WGS}$）；转录物组测序（即 $\mathrm{RNA}$-seq）；外显子组测序；染色质免疫沉淀测序（$\mathrm{ChIP}$-seq）。高通量进步使它们进入医学研究和实践，支撑分子医学进入大数据时代。
:::

:::pitfall{label="RNA-seq 是转录物组测序的别名，不是纳米孔「直接 RNA 测序」的唯一写法"}
教材在应用段把转录物组测序与 $\mathrm{RNA}$-seq 等同。纳米孔条另写「直接进行 $\mathrm{RNA}$ 测序」是第三代的一种实现。应用名单不要缩成只有纳米孔。
:::

:::compare{title="四种测序应用的对象"}
| | 读什么 |
|--|--------|
| $\mathrm{WGS}$ | 全基因组 $\mathrm{DNA}$ |
| 外显子组测序 | 编码外显子 |
| $\mathrm{RNA}$-seq（转录物组） | 表达出来的 $\mathrm{RNA}$ |
| $\mathrm{ChIP}$-seq | 与特定蛋白质（经免疫沉淀）结合的 $\mathrm{DNA}$ |

后两者已经跨到「表达」和「蛋白质－$\mathrm{DNA}$ 相互作用」，化学上仍是把拿到的核酸测序。
:::

$\mathrm{DNA}$ 测序在医学研究和临床实践中的主要用途有：①通过人群大样本分析，确定单基因遗传病和多基因变异相关疾病的 $\mathrm{SNP}$ 位点、基因结构变异、基因拷贝数变异等，鉴定出可用于复杂性疾病易感性预警或早期诊断的疾病标志物，并将这些单一基因或多个基因的变异检测用于临床诊断，这些变异的发现还将指导治疗靶点的确认和药物研发；②检测肿瘤组织的染色体畸变、癌基因和抑癌基因突变位点、融合基因、染色体拷贝数变化等，为肿瘤分子分型和治疗敏感性监测提供依据；③进行个人基因组分析，在大数据平台发展的基础上，建立个人 $\mathrm{SNP}$ 位点与疾病易感性、药物敏感性和耐受性以及其他诸多表型之间的联系；④用于病原微生物检测，确定病原微生物的分子分型，为抗病毒或细菌感染治疗提供依据。

$\mathrm{DNA}$ 测序在法医学领域也具有特殊意义。极大提高了 $\mathrm{DNA}$ 鉴定的敏感性和准确性，在各类案件中作为司法证据的重要性愈加凸显。$\mathrm{DNA}$ 测序在亲子鉴定中亦具有重要价值。

:::definition{label="测序医学用途四条"}
①人群大样本：单基因遗传病和多基因相关疾病的 $\mathrm{SNP}$、结构变异、拷贝数变异；复杂性疾病预警或早期诊断标志物；变异检测用于临床诊断，并指导靶点和药物研发。②肿瘤：染色体畸变、癌基因和抑癌基因突变、融合基因、染色体拷贝数变化；分子分型与治疗敏感性监测。③个人基因组：个人 $\mathrm{SNP}$ 与易感性、药物敏感／耐受及其他表型的联系。④病原微生物：分子分型，为抗病毒或细菌感染治疗提供依据。
:::

:::definition{label="测序在法医学"}
提高 $\mathrm{DNA}$ 鉴定的敏感性和准确性，司法证据意义凸显；亲子鉴定亦有重要价值。
:::

:::keypoint{label="四条用途分别问谁的基因组"}
- 人群：找病的标志物和靶点。
- 肿瘤组织：找这个瘤的畸变和敏感性。
- 个人：把 $\mathrm{SNP}$ 连到这个人的表型和用药。
- 病原体：分型，决定抗感染策略。

法医学是另一场景：身份和亲子，不是疾病机制。
:::

:::pitfall{label="融合基因、拷贝数变化是肿瘤条的账，不要全部叫 SNP"}
①里已有 $\mathrm{SNP}$、结构变异、拷贝数变异；②另列染色体畸变、融合基因等。个人基因组条又回到个人 $\mathrm{SNP}$ 与表型。三处「变异」层级不同，默写按条对号。
:::

:::compare{title="实时 PCR 定量 vs 测序读顺序"}
| | 第二节实时 $\mathrm{PCR}$ | 本节测序 |
|--|----------------------|----------|
| 主要问题 | 这段核酸有多少拷贝 | 这段核酸每一位是什么碱基 |
| $\mathrm{HBV}$ 例 | 血液拷贝数，监测治疗 | 病原体分子分型（用途④） |
| 肿瘤 | 突变／表达量（探针、熔解曲线） | 畸变、突变位点、融合基因、拷贝数（用途②） |
| $\mathrm{SNP}$ | 多态性与用药（实时 $\mathrm{PCR}$ 前景） | 人群标志物 $+$ 个人基因组联系 |

定量和读序经常联用，考试先看问的是「多少」还是「什么顺序」。
:::

:::memory{label="本节测序一张清单"}
- 目的：$\mathrm{A}/\mathrm{G}/\mathrm{C}/\mathrm{T}$ 排列。$1977$ 两法，$1980$ 化学奖。
- 桑格：$\mathrm{ddNTP}$ 缺 $3'$-$\mathrm{OH}$ $\rightarrow$ 不能成 $3',5'$－磷酸二酯键；四管共 $5'$ 起点、不同终点；变性 $\mathrm{PAGE}$ 差 $1$ nt。
- 化学降解：末端标记 $+$ 碱基专一切断；毒性、难自动化，未广泛用。
- 第一代：$1986$ 四色荧光 $\mathrm{ddNTP}$；读长 $>1\,000\,\mathrm{bp}$，准确率 $99.999\%$；$1998$ 毛细管；$2003$ 七国草图。
- 循环芯片：聚合酶或连接酶，芯片上并行循环，光学等信号 $+$ 生物信息学。
- 第二代三大：Illumina 可逆 $3'$-$\mathrm{OH}$；$454$ 焦磷酸发光；$\mathrm{SOLiD}$ 连接酶 $+$ 双碱基，$5$ 轮每碱基读 $2$ 遍。离子半导体读 $\mathrm{H}^{+}$。
- 第三代无须 $\mathrm{PCR}$：HeliScope；$\mathrm{SMRT}$（$\mathrm{ZMW}$，一孔一酶）；纳米孔（电流，可直接 $\mathrm{RNA}$、看修饰）。
- 应用：$\mathrm{WGS}$、$\mathrm{RNA}$-seq、外显子组、$\mathrm{ChIP}$-seq；人群／肿瘤／个人／病原体四条 $+$ 法医亲子。
:::

:::memory{label="三个「读什么信号」不要混"}
- 桑格／第一代／Illumina：荧光（或核素）在终止或可逆终止的核苷酸上。
- $454$：焦磷酸 $\rightarrow$ 发光；离子半导体：$\mathrm{H}^{+}$／$\mathrm{pH}$。
- 纳米孔：过孔电流。$\mathrm{SOLiD}$：连接上 $8$ 碱基探针时的荧光。
:::
