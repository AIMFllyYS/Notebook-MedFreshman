# 第一节　糖蛋白分子中的聚糖

本章打开糖蛋白和蛋白聚糖的结构与功能。先把细胞里糖与蛋白质、脂质共价相连的复合糖类立户，再落到糖蛋白分子中的聚糖：$N$-连接走 $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$，$O$-连接走丝／苏氨酸羟基，三型 $N$-连接共享五糖核心，内质网以长萜醇为载体、高尔基体继续加工。第二节才写蛋白聚糖里的糖胺聚糖，第三节把聚糖写成信息分子。

细胞中存在着种类各异的由糖基分子与蛋白质或脂以共价键连接而形成的复合生物大分子，如糖蛋白、蛋白聚糖和糖脂等，统称为复合糖类（complex carbohydrate），又称为糖缀合物（glycoconjugate）。组成复合糖类中的糖组分是由单糖通过糖苷键聚合而成的寡糖或多糖，称为聚糖（glycan）。就结构而言，糖蛋白和蛋白聚糖均由共价连接的蛋白质和聚糖两部分组成，而糖脂则由聚糖与脂质组成。体内也存在着蛋白质、糖与脂质三位一体的复合物，主要利用糖基磷脂酰肌醇（glycosylphosphatidyl inositol，$\mathrm{GPI}$）将蛋白质锚定于细胞膜中。

:::definition{label="复合糖类（糖缀合物）"}
复合糖类（complex carbohydrate）又称糖缀合物（glycoconjugate），是糖基分子与蛋白质或脂以共价键连接形成的复合生物大分子，如糖蛋白、蛋白聚糖和糖脂等。
:::

:::definition{label="聚糖"}
聚糖（glycan）是组成复合糖类中的糖组分：由单糖通过糖苷键聚合而成的寡糖或多糖。
:::

:::definition{label="糖基磷脂酰肌醇（GPI）"}
体内也存在蛋白质、糖与脂质三位一体的复合物，主要利用糖基磷脂酰肌醇（glycosylphosphatidyl inositol，$\mathrm{GPI}$）将蛋白质锚定于细胞膜中。
:::

:::compare{title="糖蛋白、蛋白聚糖、糖脂先立三本账"}
| 项目 | 糖蛋白 | 蛋白聚糖 | 糖脂 |
|------|--------|----------|------|
| 两部分怎么连 | 蛋白质 $+$ 聚糖，共价 | 蛋白质 $+$ 聚糖，共价 | 聚糖 $+$ 脂质 |
| 重量比 | 蛋白质重量百分比大于聚糖 | 聚糖所占重量在一半以上，甚至高达 $95\%$ | — |
| 聚糖分子质量 | 相对较小 | 大多数可达 $10$ 万以上 | — |
| 合成与功能 | 聚糖结构迥然不同，合成途径和功能有显著差异 | 同左，第二节展开 | 本节点名，不展开 |

三位一体那一笔另立：$\mathrm{GPI}$ 把蛋白质锚定在细胞膜上。
:::

大多数真核细胞都能合成一定数量和类型的糖蛋白和蛋白聚糖，分布于细胞表面、细胞内分泌颗粒和细胞核内；也可被分泌出细胞，构成细胞外基质成分。糖蛋白分子中蛋白质重量百分比大于聚糖，而蛋白聚糖中聚糖所占重量在一半以上，甚至高达 $95\%$，以致大多数蛋白聚糖中聚糖分子质量高达 $10$ 万以上。由于组成糖蛋白和蛋白聚糖的聚糖结构迥然不同，因此两者在合成途径和功能上存在显著差异。

:::concept{term="先问是糖蛋白还是蛋白聚糖，再问聚糖怎么连到肽链上"}
看见“糖和蛋白质在一起”，先不要立刻写成同一种分子。糖蛋白是蛋白比重大、聚糖结构多样的那一本；蛋白聚糖是聚糖可占一半以上、甚至 $95\%$ 的那一本。本节只写糖蛋白分子中的聚糖；糖胺聚糖重复二糖是第二节。
:::

:::pitfall{label="蛋白聚糖不是“含糖特别多的糖蛋白”的别名"}
教材把两者分开立户：聚糖结构迥然不同，合成途径和功能也有显著差异。把蛋白聚糖听成糖蛋白的一个亚类，第二节的糖胺聚糖、核心蛋白质和瓶刷状聚合体会没有户头。
:::

糖蛋白（glycoprotein）由糖类分子与蛋白质分子共价结合而成。其分子中的含糖量因蛋白质不同而异，有的可达 $20\%$，有的仅为 $5\%$ 以下。此外，糖蛋白分子中的单糖种类、组成比和聚糖的结构也存在显著差异。组成糖蛋白分子中聚糖的单糖有 $7$ 种：葡萄糖（glucose，$\mathrm{Glc}$）、半乳糖（galactose，$\mathrm{Gal}$）、甘露糖（mannose，$\mathrm{Man}$）、$N$-乙酰半乳糖胺（$N$-acetylgalactosamine，$\mathrm{GalNAc}$）、$N$-乙酰葡萄糖胺（$N$-acetylglucosamine，$\mathrm{GlcNAc}$）、岩藻糖（fucose，$\mathrm{Fuc}$）和 $N$-乙酰神经氨酸（$N$-acetylneuraminic acid，$\mathrm{NeuAc}$）。

:::definition{label="糖蛋白"}
糖蛋白（glycoprotein）由糖类分子与蛋白质分子共价结合而成。含糖量因蛋白质而异，有的可达 $20\%$，有的仅为 $5\%$ 以下。单糖种类、组成比和聚糖结构也存在显著差异。
:::

:::definition{label="组成糖蛋白聚糖的七种单糖"}
葡萄糖（$\mathrm{Glc}$）、半乳糖（$\mathrm{Gal}$）、甘露糖（$\mathrm{Man}$）、$N$-乙酰半乳糖胺（$\mathrm{GalNAc}$）、$N$-乙酰葡萄糖胺（$\mathrm{GlcNAc}$）、岩藻糖（$\mathrm{Fuc}$）和 $N$-乙酰神经氨酸（$\mathrm{NeuAc}$）。
:::

:::memory{label="七种单糖先记缩写"}
- [ ] $\mathrm{Glc}$：葡萄糖
- [ ] $\mathrm{Gal}$：半乳糖
- [ ] $\mathrm{Man}$：甘露糖
- [ ] $\mathrm{GalNAc}$：$N$-乙酰半乳糖胺
- [ ] $\mathrm{GlcNAc}$：$N$-乙酰葡萄糖胺
- [ ] $\mathrm{Fuc}$：岩藻糖
- [ ] $\mathrm{NeuAc}$：$N$-乙酰神经氨酸（图中也写成 $\mathrm{SA}$，唾液酸）
:::

由上述单糖构成结构各异的聚糖可经两种方式与糖蛋白的蛋白质部分连接，由此，根据连接方式不同将糖蛋白聚糖分为 $N$-连接型聚糖（$N$-linked glycan）和 $O$-连接型聚糖（$O$-linked glycan）。$N$-连接型聚糖是指与蛋白质分子中天冬酰胺残基的酰胺氮相连的聚糖；$O$-连接型聚糖是指与蛋白质分子中丝氨酸或苏氨酸羟基相连的聚糖（图4-1）。所以，糖蛋白也相应分成 $N$-连接糖蛋白和 $O$-连接糖蛋白。图中 $X$ 为脯氨酸以外的任何氨基酸。

:::definition{label="N-连接型聚糖"}
$N$-连接型聚糖（$N$-linked glycan）是与蛋白质分子中天冬酰胺残基的酰胺氮相连的聚糖。连接糖基首先是 $N$-乙酰葡萄糖胺。
:::

:::definition{label="O-连接型聚糖"}
$O$-连接型聚糖（$O$-linked glycan）是与蛋白质分子中丝氨酸或苏氨酸羟基相连的聚糖。连接糖基首先常是 $N$-乙酰半乳糖胺。
:::

:::compare{title="N-连接与 O-连接（本节先立键）"}
| 项目 | $N$-连接型 | $O$-连接型 |
|------|------------|------------|
| 接到哪 | 天冬酰胺残基的酰胺氮 | 丝氨酸或苏氨酸的羟基 |
| 第一个糖 | $N$-乙酰葡萄糖胺（$\mathrm{GlcNAc}$） | 常为 $N$-乙酰半乳糖胺（$\mathrm{GalNAc}$） |
| 位点序列 | $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$（$X$ 不是脯氨酸） | 确切序列子尚不清楚 |
| 糖蛋白也跟着叫 | $N$-连接糖蛋白 | $O$-连接糖蛋白 |
:::

本页另有切片 `p0105_01.png` 为 $0$ 字节，不引用。可用图即本图 $N$-连接与 $O$-连接对照。$X$ 为脯氨酸以外的任何氨基酸。
:::

不同种属、组织的同一种糖蛋白的 $N$-连接型聚糖结合位置、糖基数目、糖基序列不同，可以产生不同的糖蛋白分子形式。即使是同一组织中的某种糖蛋白，不同分子的同一糖基化位点的 $N$-连接型聚糖结构也可以不同，这种糖蛋白聚糖结构的不均一性称为糖形（glycoform）。

:::definition{label="糖形"}
糖形（glycoform）指糖蛋白聚糖结构的不均一性：即使同一组织中的某种糖蛋白，不同分子的同一糖基化位点的 $N$-连接型聚糖结构也可以不同。不同种属、组织的同一种糖蛋白，$N$-连接型聚糖的结合位置、糖基数目、糖基序列不同，也可产生不同分子形式。
:::

:::insight{label="同一条肽、同一个位点，聚糖仍可以不一样"}
糖形不是“测错了”，而是教材写明的微观不均一性。后文加工一节把它接到不完全糖基化、以及糖苷酶和糖基转移酶缺乏绝对专一性。
:::

## 一、N-连接型糖蛋白的糖基化位点为 Asn-X-Ser/Thr

聚糖中的 $N$-乙酰葡萄糖胺与蛋白质中天冬酰胺残基的酰胺氮以共价键连接，形成 $N$-连接型糖蛋白，这种蛋白质等非糖生物分子与糖形成共价结合的反应过程称为糖基化。但是并非糖蛋白分子中所有天冬酰胺残基都可连接聚糖，只有糖蛋白分子中与糖形成共价结合的特定氨基酸序列，即 $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$（其中 $X$ 为脯氨酸以外的任何氨基酸）$3$ 个氨基酸残基组成的序列子（sequon）才有可能，这一序列子被称为糖基化位点。一个糖蛋白分子可存在若干个 $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$ 序列子，这些序列子只能视为潜在糖基化位点，能否连接上聚糖还取决于周围的立体结构等。

:::definition{label="糖基化"}
糖基化是蛋白质等非糖生物分子与糖形成共价结合的反应过程。
:::

:::definition{label="N-连接的糖基化位点（序列子）"}
只有 $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$（$X$ 为脯氨酸以外的任何氨基酸）这 $3$ 个氨基酸残基组成的序列子（sequon）才有可能连接聚糖。这一序列子被称为糖基化位点。
:::

:::pitfall{label="Asn-X-Ser/Thr 只是潜在位点，不是看见三个残基就一定连上糖"}
一个糖蛋白可以有若干个这样的序列子，教材写明“只能视为潜在糖基化位点”，能否连上还取决于周围的立体结构等。把 $X$ 写成任意氨基酸、漏掉“脯氨酸除外”，图4-1 的注释会对不上。
:::

:::keypoint{label="N-连接先记三件事"}
- 键：$\mathrm{GlcNAc}$ 接到 $\mathrm{Asn}$ 的酰胺氮。
- 序列子：$\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$，$X\neq\mathrm{Pro}$。
- 序列子 $=$ 潜在糖基化位点，立体结构说了才算。
:::

## 二、N-连接型聚糖结构具有五糖核心

根据结构可将 $N$-连接型聚糖分为 $3$ 型：高甘露糖型、复杂型和杂合型。这 $3$ 型 $N$-连接型聚糖都有一个由 $2$ 个 $N$-$\mathrm{GlcNAc}$ 和 $3$ 个 $\mathrm{Man}$ 形成的五糖核心（图4-2）。高甘露糖型在核心五糖上连接了 $2\sim 9$ 个甘露糖；复杂型在核心五糖上可连接 $2$、$3$、$4$ 或 $5$ 个分支聚糖，宛如天线状，天线末端常连有 $N$-乙酰神经氨酸；杂合型则兼有两者的结构。

:::definition{label="五糖核心"}
$3$ 型 $N$-连接型聚糖都有一个由 $2$ 个 $N$-$\mathrm{GlcNAc}$ 和 $3$ 个 $\mathrm{Man}$ 形成的五糖核心。
:::

:::definition{label="高甘露糖型"}
高甘露糖型在核心五糖上连接了 $2\sim 9$ 个甘露糖。
:::

:::definition{label="复杂型"}
复杂型在核心五糖上可连接 $2$、$3$、$4$ 或 $5$ 个分支聚糖，宛如天线状，天线末端常连有 $N$-乙酰神经氨酸。
:::

:::definition{label="杂合型"}
杂合型兼有高甘露糖型和复杂型两者的结构。
:::

::figure{src="/images/biochemistry/textbook/p0106_01.png" caption="图4-2　N-连接型聚糖的分型。（a）高甘露糖型：核心五糖上继续连多个 Man。（b）复杂型：天线经 GlcNAc、Gal 接到 SA（唾液酸，α2,3 或 α2,6），核心可有 ±GlcNAc、±Fuc。（c）杂合型：一侧保留 Man 分支，一侧出现 GlcNAc–Gal 天线。Man：甘露糖；GlcNAc：N-乙酰葡萄糖胺；SA：唾液酸；Gal：半乳糖；Fuc：岩藻糖；Asn：天冬酰胺。" alt="三种树状聚糖均从 Asn 向上经两层 GlcNAc 和分支 Man：左为全 Man 的高甘露糖型，中为带唾液酸天线的复杂型，右为混合的杂合型"}

:::compare{title="三型 N-连接都先认五糖核心"}
| 分型 | 核心五糖之上还接什么 | 教材形象 |
|------|------------------------|----------|
| 高甘露糖型 | $2\sim 9$ 个甘露糖 | 几乎全是 $\mathrm{Man}$ |
| 复杂型 | $2$、$3$、$4$ 或 $5$ 个分支聚糖；末端常连 $N$-乙酰神经氨酸 | 天线状 |
| 杂合型 | 兼有高甘露糖与复杂型 | 一侧 $\mathrm{Man}$，一侧天线 |
:::

:::tip{label="先数 2 个 GlcNAc 加 3 个 Man，再看天线还是甘露糖"}
三型不是三套完全不同的骨架。骨架先共用五糖核心，分型看核心之外：全是 $\mathrm{Man}$、天线末端唾液酸、还是两边各来一套。
:::

## 三、N-连接型聚糖以长萜醇为载体合成

$N$-连接型聚糖的合成场所是粗面内质网和高尔基体，可与蛋白质肽链的合成同时进行。在内质网内以长萜醇（dolichol，$\mathrm{dol}$）作为聚糖载体，在糖基转移酶（一种催化糖基从糖基供体转移到受体化合物的酶）的作用下先将 $\mathrm{UDP}$-$\mathrm{GlcNAc}$ 分子中的 $\mathrm{GlcNAc}$ 转移至长萜醇，然后再逐个加上糖基。糖基必须活化成 $\mathrm{UDP}$ 或 $\mathrm{GDP}$ 的衍生物，才能作为糖基供体底物参与反应，直至形成含有 $14$ 个糖基的长萜醇焦磷酸聚糖结构，后者作为一个整体被转移至肽链的糖基化位点中的天冬酰胺的酰胺氮上。聚糖链依次在内质网和高尔基体进行加工，先由糖苷水解酶除去葡萄糖和部分甘露糖，再加上不同的单糖，最终形成成熟的各型 $N$-连接型聚糖。图4-3 显示从内质网到高尔基体，三种不同类型聚糖逐步加工的过程。

:::definition{label="长萜醇"}
长萜醇（dolichol，$\mathrm{dol}$）是内质网内 $N$-连接型聚糖合成的聚糖载体。先把 $\mathrm{UDP}$-$\mathrm{GlcNAc}$ 中的 $\mathrm{GlcNAc}$ 转到长萜醇上，再逐个加糖基，形成含 $14$ 个糖基的长萜醇焦磷酸聚糖，再整体转移到肽链 $\mathrm{Asn}$ 的酰胺氮上。
:::

:::definition{label="糖基转移酶"}
糖基转移酶是催化糖基从糖基供体转移到受体化合物的酶。糖基必须活化成 $\mathrm{UDP}$ 或 $\mathrm{GDP}$ 的衍生物，才能作为糖基供体底物。
:::

::figure{src="/images/biochemistry/textbook/p0107_01.png" caption="图4-3　三种不同类型 N-连接型聚糖的加工过程。左上：长萜醇-PP-寡糖把前体整体转到多肽链 Asn-X-Ser/Thr（步骤 1），在内质网（步骤 2–4）先切去葡萄糖（图中标 Glu）、再切部分甘露糖，可形成高甘露糖型。右下进入高尔基体（步骤 5 起）继续加工，途经杂合型，再装上天线和岩藻糖（五角星）成为复杂型。" alt="流程图：长萜醇焦磷酸寡糖转移到肽链后，内质网修剪葡萄糖和甘露糖得到高甘露糖型，高尔基体继续修剪并添加单糖，分别标出杂合型与复杂型"}

:::timeline{period="N-连接型聚糖从内质网到高尔基体"}
- **同时合成** 场所是粗面内质网和高尔基体，可与肽链合成同时进行
- **长萜醇作载体** 糖基先活化成 UDP 或 GDP 衍生物；GlcNAc 转到长萜醇，再逐个加糖，直至 14 个糖基的长萜醇焦磷酸聚糖
- **整体转移** 14 糖作为一个整体转到肽链糖基化位点天冬酰胺的酰胺氮上
- **内质网加工** 糖苷水解酶先除去葡萄糖和部分甘露糖，可形成较为单一的高甘露糖型
- **高尔基体加工** 再加上不同单糖；有些停在杂合型，有些形成复杂型
:::

在生物体内，有些糖蛋白的加工比较简单，仅形成较为单一的高甘露糖型聚糖，有些形成杂合型，而有些糖蛋白则通过多种加工形成复杂型的聚糖。不同组织的同一种糖蛋白分子中的聚糖结构可以不同，说明 $N$-连接型聚糖存在极大的多样性。即使同一种糖蛋白，其相同糖基化位点的聚糖结构也可不同，显示出相当大的微观不均一性，这可能与不完全糖基化以及糖苷酶和糖基转移酶缺乏绝对的专一性相关。

:::cause-effect{title="为什么同一位点还会出现糖形"}
- **因** 不完全糖基化；糖苷酶和糖基转移酶缺乏绝对的专一性
- **果** 即使同一种糖蛋白，相同糖基化位点的聚糖结构也可不同，显示出相当大的微观不均一性
:::

:::insight{label="14 糖先作为整体转移，成熟三型是切完再补上去的"}
教材把“载体上合成 → 整体转到 $\mathrm{Asn}$ → 先水解切糖、再转移加糖”写成一条通路。不要把高甘露糖型、杂合型、复杂型听成三条互不相干的合成路线。图4-3 从左上到右下就是这一条加工链。
:::

:::pitfall{label="糖基供体必须先活化成 UDP 或 GDP 衍生物"}
游离单糖不能直接接到长萜醇或肽链上。先活化，再给糖基转移酶当底物。$O$-连接那一节同样走 $\mathrm{UDP}$-$\mathrm{GalNAc}$，不要两套账混成“谁爱用谁”。
:::

## 四、O-连接型聚糖合成不需载体

聚糖中的 $N$-乙酰半乳糖胺与多肽链的丝氨酸或苏氨酸残基的羟基以共价键相连而形成 $O$-连接糖蛋白。其糖基化位点的确切序列子尚不清楚，但通常存在于糖蛋白分子表面丝氨酸和苏氨酸比较集中且周围常有脯氨酸的序列中，提示 $O$-连接糖蛋白的糖基化位点由多肽链的二、三级结构决定。

$O$-连接型聚糖常由 $N$-乙酰半乳糖胺与半乳糖构成核心二糖，核心二糖可重复延长及分支，再连接上岩藻糖、$N$-乙酰葡萄糖胺等单糖。与 $N$-连接型聚糖合成不同，$O$-连接型聚糖合成是在多肽链合成后进行的，且不需要聚糖载体。在 $\mathrm{GalNAc}$ 转移酶作用下，将 $\mathrm{UDP}$-$\mathrm{GalNAc}$ 中的 $\mathrm{GalNAc}$ 基转移至多肽链的丝／苏氨酸的羟基上，形成 $O$-连接，然后逐个加上糖基。每一种糖基都有其相应的专一性糖基转移酶。整个过程在内质网开始，到高尔基体内完成。

:::definition{label="O-连接糖蛋白的形成"}
聚糖中的 $N$-乙酰半乳糖胺与多肽链丝氨酸或苏氨酸残基的羟基以共价键相连，形成 $O$-连接糖蛋白。
:::

:::definition{label="O-连接的核心二糖"}
$O$-连接型聚糖常由 $N$-乙酰半乳糖胺与半乳糖构成核心二糖。核心二糖可重复延长及分支，再连上岩藻糖、$N$-乙酰葡萄糖胺等单糖。图4-1 下半画的就是 $\beta$-半乳糖基-（$1\rightarrow 3$）-$\alpha$-$N$-乙酰半乳糖胺-丝氨酸／苏氨酸。
:::

:::compare{title="N-连接合成与 O-连接合成"}
| 项目 | $N$-连接型 | $O$-连接型 |
|------|------------|------------|
| 与肽链合成的时序 | 可与肽链合成同时进行 | 在多肽链合成后进行 |
| 是否需要聚糖载体 | 需要长萜醇 | 不需要聚糖载体 |
| 第一个糖怎么上 | 先在长萜醇上装到 $14$ 糖，再整体转到 $\mathrm{Asn}$ | $\mathrm{GalNAc}$ 转移酶把 $\mathrm{UDP}$-$\mathrm{GalNAc}$ 中的 $\mathrm{GalNAc}$ 转到丝／苏氨酸羟基 |
| 以后怎么延长 | 糖苷水解酶先切，再加不同单糖 | 逐个加上糖基；每一种糖基有相应的专一性糖基转移酶 |
| 场所 | 粗面内质网和高尔基体 | 内质网开始，高尔基体内完成 |
| 位点决定 | 序列子 $\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$，仍受立体结构限制 | 确切序列子尚不清楚；常在表面 $\mathrm{Ser}/\mathrm{Thr}$ 集中、周围常有脯氨酸的序列，由二、三级结构决定 |
:::

:::pitfall{label="O-连接位点不要硬套 Asn-X-Ser/Thr"}
那条序列子是 $N$-连接的。$O$-连接教材写明“确切序列子尚不清楚”，只提示表面丝／苏氨酸成簇、周围常有脯氨酸，由二、三级结构决定。把脯氨酸听成“$O$-连接也禁止脯氨酸”，会和图4-1 的 $X\neq\mathrm{Pro}$（那是 $N$-连接）打架。
:::

:::insight{label="O-连接不走长萜醇，是肽链合成后再逐个加糖"}
这是和 $N$-连接最容易考反的一笔：没有 $14$ 糖整体转移，没有长萜醇载体。先 $\mathrm{GalNAc}$，再一颗一颗加。
:::

## 五、蛋白质 β-N-乙酰葡萄糖胺的单糖基修饰可逆

蛋白质糖基化修饰除 $N$-连接型聚糖修饰和 $O$-连接型聚糖修饰外，还有 $\beta$-$N$-乙酰葡萄糖胺的单糖基修饰（$O$-$\mathrm{GlcNAc}$），主要发生于膜蛋白和分泌蛋白。蛋白质的 $O$-$\mathrm{GlcNAc}$ 糖基化修饰是在 $O$-$\mathrm{GlcNAc}$ 糖基转移酶（$O$-$\mathrm{GlcNAc}$ transferase，$\mathrm{OGT}$）作用下，将 $\beta$-$N$-乙酰葡萄糖胺以共价键方式结合于蛋白质的丝／苏氨酸残基上。与 $N$- 或 $O$-连接型聚糖修饰不同，这种糖基化修饰不在内膜（如内质网、高尔基体）系统中进行，主要存在于细胞质或细胞核中。

蛋白质在 $O$-$\mathrm{GlcNAc}$ 糖基化后，其解离需要特异性的 $\beta$-$N$-乙酰葡萄糖胺酶（$O$-$\mathrm{GlcNAcase}$）作用。$O$-$\mathrm{GlcNAc}$ 糖基化与去糖基化是个动态平衡的过程。糖基化后，蛋白质肽链的构象将发生改变，从而影响蛋白质功能。可见，蛋白质在 $\mathrm{OGT}$ 与 $O$-$\mathrm{GlcNAcase}$ 作用下的这种糖基化过程与蛋白质磷酸化调节具有相似特性。此外，$O$-$\mathrm{GlcNAc}$ 糖基化位点也经常位于蛋白质丝／苏氨酸磷酸化位点处或其邻近部位，糖基化后即会影响磷酸化的进行，反之亦然。因此，$O$-$\mathrm{GlcNAc}$ 糖基化与蛋白质磷酸化可能是一种相互拮抗的修饰行为，共同参与信号通路调节过程。

:::definition{label="O-GlcNAc"}
$\beta$-$N$-乙酰葡萄糖胺的单糖基修饰（$O$-$\mathrm{GlcNAc}$）是除 $N$-连接、$O$-连接聚糖之外的第三种糖基化修饰，主要发生于膜蛋白和分泌蛋白。由 $O$-$\mathrm{GlcNAc}$ 糖基转移酶（$\mathrm{OGT}$）把 $\beta$-$N$-乙酰葡萄糖胺共价结合到丝／苏氨酸残基上。
:::

:::definition{label="OGT 与 O-GlcNAcase"}
$\mathrm{OGT}$ 催化加上 $O$-$\mathrm{GlcNAc}$；特异性 $\beta$-$N$-乙酰葡萄糖胺酶（$O$-$\mathrm{GlcNAcase}$）催化其解离。二者构成糖基化与去糖基化的动态平衡。
:::

:::compare{title="O-GlcNAc 不是内膜里那条 O-连接聚糖"}
| 项目 | $N$-／$O$-连接型聚糖 | $O$-$\mathrm{GlcNAc}$ |
|------|----------------------|------------------------|
| 产物 | 寡糖／多糖链 | 单糖基 |
| 场所 | 内质网、高尔基体等内膜系统 | 主要在细胞质或细胞核；不在内膜系统 |
| 可否可逆地拆掉 | 成熟聚糖不是这对酶的动态开关 | $\mathrm{OGT}$ 加上、$O$-$\mathrm{GlcNAcase}$ 拆掉，动态平衡 |
| 与磷酸化 | — | 位点常在 $\mathrm{Ser}/\mathrm{Thr}$ 磷酸化位点或其邻近；相互影响，可能相互拮抗，共同参与信号通路调节 |
:::

:::cause-effect{title="O-GlcNAc 怎样接到信号通路上"}
- **因** 糖基化改变肽链构象；位点又常与磷酸化位点重叠或相邻，加上糖就会挡磷酸化，反之亦然
- **果** 这种修饰与磷酸化可能相互拮抗，共同参与信号通路调节；特性上像磷酸化那样可逆
:::

:::pitfall{label="O-GlcNAc 虽也接到 Ser/Thr，但不要并进 O-连接聚糖那本账"}
$O$-连接聚糖走内膜、从 $\mathrm{GalNAc}$ 开始延长；$O$-$\mathrm{GlcNAc}$ 是细胞质／细胞核里的单糖基可逆开关。把 $\mathrm{OGT}$ 听成高尔基体里的 $\mathrm{GalNAc}$ 转移酶，信号通路那一笔会没有地方放。
:::

## 六、聚糖影响蛋白质的半衰期、结构和功能

人体细胞内的蛋白质约三分之一为糖蛋白，执行不同的功能。糖蛋白分子中聚糖不但能影响蛋白部分的构象、聚合、溶解及降解，还参与糖蛋白的相互识别、结合等过程。

:::keypoint{label="聚糖对蛋白部分的四本账"}
- 构象、聚合、溶解及降解。
- 相互识别、结合。
- 人体细胞内蛋白质约三分之一为糖蛋白。
- 下面按稳固与半衰期、折叠或聚合、靶向运输、分子识别四小节摊开。
:::

### （一）聚糖可稳固多肽链的结构并延长半衰期

糖蛋白的聚糖通常存在于蛋白质表面环或转角的序列处，并突出于蛋白质的表面。有些聚糖可能通过限制与它们连接的多肽链的构象自由度而发挥结构性作用。$O$-连接型聚糖常成簇地分布在蛋白质高度糖基化的区段上，有助于稳固多肽链的结构。一般来说，去除聚糖的糖蛋白，容易受蛋白酶水解，说明聚糖可保护肽链，延长半衰期。有些酶的活性依赖其聚糖，如羟甲基戊二酸单酰辅酶 $\mathrm{A}$（$\mathrm{HMG}$-$\mathrm{CoA}$）还原酶去聚糖后其活性降低 $90\%$ 以上；脂蛋白脂肪酶 $N$-连接型聚糖的核心五糖为酶活性所必需。当然，蛋白质的聚糖也可起屏障作用，抑制糖蛋白的作用。

:::definition{label="聚糖的结构性作用"}
聚糖通常在蛋白质表面环或转角，并突出于表面。有些通过限制所连多肽链的构象自由度而发挥结构性作用。$O$-连接型聚糖常成簇分布在高度糖基化区段，有助于稳固多肽链。
:::

:::example{label="去聚糖以后酶活掉下来"}
羟甲基戊二酸单酰辅酶 $\mathrm{A}$（$\mathrm{HMG}$-$\mathrm{CoA}$）还原酶去聚糖后活性降低 $90\%$ 以上。脂蛋白脂肪酶 $N$-连接型聚糖的核心五糖为酶活性所必需。这两笔说明：有些酶的活性依赖其聚糖，不是“糖只是装饰”。
:::

:::pitfall{label="聚糖也可以当屏障，抑制糖蛋白的作用"}
教材在“保护肽链、延长半衰期、维持酶活”之后立刻补：聚糖也可起屏障作用，抑制糖蛋白的作用。不要写成“有糖就一定更好、更活”。
:::

:::cause-effect{title="去掉聚糖为什么半衰期变短"}
- **因** 去除聚糖的糖蛋白容易受蛋白酶水解
- **果** 聚糖可保护肽链，延长半衰期
:::

### （二）聚糖参与糖蛋白新生肽链的折叠或聚合

不少糖蛋白的 $N$-连接型聚糖参与新生肽链的折叠，维持蛋白质正确的空间构象。如用 $\mathrm{DNA}$ 定点突变方法去除某一病毒 $\mathrm{G}$ 蛋白的两个糖基化位点，此 $\mathrm{G}$ 蛋白就不能形成正确的链内二硫键而错配成链间二硫键，空间构象也会发生改变。运铁蛋白受体有 $3$ 个 $N$-连接型聚糖，分别位于 $\mathrm{Asn}251$、$\mathrm{Asn}317$ 和 $\mathrm{Asn}727$。已发现 $\mathrm{Asn}727$ 与肽链的折叠和运输密切相关；$\mathrm{Asn}251$ 连接有三天线复杂型聚糖，此聚糖对于形成正常二聚体起重要作用，可见聚糖能影响亚基聚合。在哺乳类动物新生蛋白质折叠过程中，具有凝集素活性的分子伴侣——钙连蛋白（calnexin）和／或钙网蛋白（calreticulin）等，通过识别并结合折叠中的蛋白质（聚糖）部分，帮助蛋白质进行准确折叠，同样也能使错误折叠的蛋白质进入降解系统。

:::definition{label="钙连蛋白与钙网蛋白"}
钙连蛋白（calnexin）和／或钙网蛋白（calreticulin）是具有凝集素活性的分子伴侣。它们识别并结合折叠中的蛋白质（聚糖）部分，帮助准确折叠，也能使错误折叠的蛋白质进入降解系统。
:::

:::example{label="病毒 G 蛋白和运铁蛋白受体"}
定点突变去掉某一病毒 $\mathrm{G}$ 蛋白的两个糖基化位点后，链内二硫键错配成链间二硫键，构象改变。运铁蛋白受体三个 $N$-连接位点：$\mathrm{Asn}727$ 与折叠和运输密切相关；$\mathrm{Asn}251$ 上的三天线复杂型聚糖对正常二聚体形成起重要作用。
:::

:::insight{label="聚糖既帮折叠，也把折错的送去降解"}
钙连蛋白／钙网蛋白读的是聚糖，不是只读肽。折叠账和降解账是同一对分子伴侣的两面。
:::

### （三）聚糖可影响糖蛋白在细胞内的靶向运输

糖蛋白的聚糖可影响糖蛋白在细胞内靶向运输的典型例子是溶酶体酶合成后向溶酶体的靶向运输。溶酶体酶在内质网合成后，其聚糖末端的甘露糖在高尔基体被磷酸化成 $6$-磷酸甘露糖，然后与溶酶体膜上的 $6$-磷酸甘露糖受体识别、结合，定向转送至溶酶体内。若聚糖末端甘露糖不被磷酸化，那么溶酶体酶只能被分泌至血浆，而溶酶体内几乎没有酶，可导致疾病产生。

:::definition{label="6-磷酸甘露糖导向溶酶体"}
溶酶体酶在内质网合成后，聚糖末端的甘露糖在高尔基体被磷酸化成 $6$-磷酸甘露糖，与溶酶体膜上的 $6$-磷酸甘露糖受体识别、结合，定向转送至溶酶体。
:::

:::cause-effect{title="甘露糖不被磷酸化会怎样"}
- **因** 聚糖末端甘露糖不被磷酸化，无法被 $6$-磷酸甘露糖受体识别
- **果** 溶酶体酶只能被分泌至血浆，溶酶体内几乎没有酶，可导致疾病产生
:::

:::pitfall{label="导向信号写在聚糖末端的甘露糖上，不是写在肽链的信号肽里"}
这一笔的钥匙是高尔基体把末端 $\mathrm{Man}$ 做成 $6$-磷酸甘露糖。把溶酶体酶听成“只要内质网合成过就会自动进溶酶体”，疾病那一句会没有机制。
:::

### （四）聚糖参与分子间的相互识别

聚糖中单糖间的连接方式有 $1,2$ 连接、$1,3$ 连接、$1,4$ 连接和 $1,6$ 连接；这些连接又有 $\alpha$ 和 $\beta$ 之分。这种结构的多样性是聚糖分子识别作用的基础。

猪卵细胞透明带中分子质量为 $5.5$ 万的 $\mathrm{ZP}$-$3$ 蛋白，含有 $O$-连接型聚糖，能识别精子并与之结合。受体与配体识别、结合也需聚糖的参与。如整合素（integrin）与其配体纤连蛋白结合，依赖完整的整合素 $N$-连接型聚糖；若用聚糖加工酶抑制剂处理白血病 $\mathrm{K}562$ 细胞，使整合素聚糖改变成高甘露糖型或杂合型，均可降低与纤连蛋白识别和结合的能力。

红细胞的血型物质含糖达 $80\%\sim 90\%$。$\mathrm{ABO}$ 血型物质是存在于细胞表面糖脂中的聚糖组分。$\mathrm{ABO}$ 系统中血型物质 $\mathrm{A}$ 和 $\mathrm{B}$ 均是在血型物质 $\mathrm{O}$ 的聚糖非还原端各加上 $\mathrm{GalNAc}$ 或 $\mathrm{Gal}$，仅一个糖基之差，使红细胞能分别识别不同的抗体，产生不同的血型。细菌表面存在各种凝集素样蛋白，可识别人体细胞表面的聚糖结构，进而侵袭细胞。

细胞表面复合糖类的聚糖还能介导细胞–细胞的结合。血液循环中的白细胞需通过沿血管壁排列的内皮细胞，才能出血管至炎症组织。白细胞表面存在一类黏附分子称选凝素（selectin），能识别并结合内皮细胞表面糖蛋白分子中的特异聚糖结构。白细胞以此与内皮细胞黏附，再通过其他黏附分子的作用，完成细胞移动及出血管的过程。

免疫球蛋白 $\mathrm{G}$（$\mathrm{IgG}$）属于 $N$-连接糖蛋白，其聚糖主要存在于 $\mathrm{Fc}$ 段。$\mathrm{IgG}$ 的聚糖可结合单核细胞或巨噬细胞上的 $\mathrm{Fc}$ 受体，并与补体 $\mathrm{C}1\mathrm{q}$ 的结合和激活以及诱导细胞毒等过程有关。若 $\mathrm{IgG}$ 去除聚糖，其铰链区的空间构象遭到破坏，上述与 $\mathrm{Fc}$ 受体和补体的结合功能将会丢失。

:::definition{label="聚糖识别的结构基础"}
单糖间可有 $1,2$、$1,3$、$1,4$、$1,6$ 连接，又分 $\alpha$ 与 $\beta$。这种结构多样性是聚糖分子识别作用的基础。
:::

:::definition{label="选凝素"}
选凝素（selectin）是白细胞表面的一类黏附分子，能识别并结合内皮细胞表面糖蛋白分子中的特异聚糖结构，使白细胞与内皮黏附，再经其他黏附分子完成移动及出血管。
:::

:::example{label="识别账上的几条例子按教材记"}
- $\mathrm{ZP}$-$3$（分子质量 $5.5$ 万）含 $O$-连接型聚糖，识别并结合精子。
- 整合素与纤连蛋白：依赖完整的整合素 $N$-连接型聚糖；加工成高甘露糖型或杂合型后结合能力下降。
- $\mathrm{ABO}$ 血型：物质 $\mathrm{A}$、$\mathrm{B}$ 只是在物质 $\mathrm{O}$ 的非还原端分别加上 $\mathrm{GalNAc}$ 或 $\mathrm{Gal}$。
- 细菌凝集素样蛋白识别人体细胞表面聚糖，进而侵袭细胞。
- 选凝素介导白细胞沿内皮黏附、出血管至炎症组织。
- $\mathrm{IgG}$ 的 $\mathrm{Fc}$ 段 $N$-连接聚糖参与结合 $\mathrm{Fc}$ 受体、补体 $\mathrm{C}1\mathrm{q}$ 及诱导细胞毒；去聚糖则铰链区构象破坏，这些功能丢失。
:::

:::compare{title="ABO 只差非还原端一个糖基"}
| 血型物质 | 在物质 O 的聚糖非还原端加上 | 结果 |
|----------|------------------------------|------|
| $\mathrm{O}$ | （不另加） | 本底聚糖 |
| $\mathrm{A}$ | $\mathrm{GalNAc}$ | 识别不同抗体，表现为 $\mathrm{A}$ 型 |
| $\mathrm{B}$ | $\mathrm{Gal}$ | 识别不同抗体，表现为 $\mathrm{B}$ 型 |

血型物质含糖达 $80\%\sim 90\%$，是细胞表面糖脂中的聚糖组分。仅一个糖基之差即可产生不同血型。
:::

:::insight{label="识别读的是聚糖结构，不是只读肽"}
精子认 $\mathrm{ZP}$-$3$ 的 $O$-聚糖，整合素认完整 $N$-聚糖，选凝素认内皮糖蛋白上的特异聚糖，$\mathrm{IgG}$ 去糖就丢 $\mathrm{Fc}$ 功能。第三节把这件事提升为“聚糖结构蕴藏大量生物信息”；本节先把例子写全。
:::

:::concept{term="先问连接方式，再问是识别、导向还是稳构象"}
看见“聚糖有什么用”，先回到 $1,2$／$1,3$／$1,4$／$1,6$ 和 $\alpha$／$\beta$。多样性是识别的基础；稳构象、抗水解、帮折叠、打 $6$-磷酸甘露糖标签，是同一套结构的不同读法。
:::

:::memory{label="本节必背要点"}
- [ ] 复合糖类（糖缀合物）：糖基与蛋白质或脂共价相连，如糖蛋白、蛋白聚糖、糖脂。
- [ ] 聚糖：单糖经糖苷键聚成的寡糖或多糖。
- [ ] $\mathrm{GPI}$ 把蛋白质锚定于细胞膜（蛋白质、糖、脂质三位一体）。
- [ ] 糖蛋白：蛋白重量百分比大于聚糖；含糖量有的 $20\%$，有的 $5\%$ 以下。
- [ ] 蛋白聚糖：聚糖重量一半以上甚至 $95\%$，聚糖分子质量常达 $10$ 万以上；与糖蛋白合成途径和功能显著不同。
- [ ] 七种单糖：$\mathrm{Glc}$、$\mathrm{Gal}$、$\mathrm{Man}$、$\mathrm{GalNAc}$、$\mathrm{GlcNAc}$、$\mathrm{Fuc}$、$\mathrm{NeuAc}$。
- [ ] $N$-连接：$\mathrm{GlcNAc}$ 接 $\mathrm{Asn}$ 酰胺氮；$O$-连接：接 $\mathrm{Ser}/\mathrm{Thr}$ 羟基。
- [ ] 糖形：同一组织、同一糖蛋白、同一位点，$N$-聚糖结构仍可不均一。
- [ ] 糖基化位点序列子：$\mathrm{Asn}$-$\mathrm{X}$-$\mathrm{Ser}/\mathrm{Thr}$（$X\neq\mathrm{Pro}$），只是潜在位点。
- [ ] 五糖核心：$2$ 个 $N$-$\mathrm{GlcNAc}$ $+\,3$ 个 $\mathrm{Man}$；三型都有。
- [ ] 高甘露糖型：核心上再连 $2\sim 9$ 个 $\mathrm{Man}$。
- [ ] 复杂型：$2$、$3$、$4$ 或 $5$ 条天线，末端常连 $N$-乙酰神经氨酸。
- [ ] 杂合型：兼有两者。
- [ ] $N$-连接合成：粗面内质网 $+$ 高尔基体，可与肽链同时进行；长萜醇为载体。
- [ ] 糖基须活化成 $\mathrm{UDP}$ 或 $\mathrm{GDP}$ 衍生物；$14$ 糖整体转到 $\mathrm{Asn}$。
- [ ] 加工：先由糖苷水解酶去葡萄糖和部分甘露糖，再加不同单糖。
- [ ] 微观不均一性与不完全糖基化、酶缺乏绝对专一性有关。
- [ ] $O$-连接：肽链合成后、不需载体；$\mathrm{GalNAc}$ 先上，再逐个加糖；内质网开始、高尔基体完成。
- [ ] $O$-连接位点由二、三级结构决定；表面 $\mathrm{Ser}/\mathrm{Thr}$ 成簇，周围常有脯氨酸。
- [ ] $O$-$\mathrm{GlcNAc}$：$\mathrm{OGT}$ 加上、$O$-$\mathrm{GlcNAcase}$ 拆掉；主要在胞质／核，不在内膜系统。
- [ ] $O$-$\mathrm{GlcNAc}$ 与磷酸化可能相互拮抗，共同参与信号通路。
- [ ] 人体细胞内约三分之一蛋白质为糖蛋白。
- [ ] 聚糖稳构象、抗水解、延半衰期；也可作屏障抑制功能。
- [ ] $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶去聚糖后活性降 $90\%$ 以上；脂蛋白脂肪酶需要核心五糖。
- [ ] 钙连蛋白／钙网蛋白识别聚糖，助折叠或送降解。
- [ ] 溶酶体酶靠 $6$-磷酸甘露糖受体导向；末端 $\mathrm{Man}$ 不磷酸化则分泌入血。
- [ ] $\mathrm{ABO}$：物质 $\mathrm{A}$／$\mathrm{B}$ 只在物质 $\mathrm{O}$ 非还原端加 $\mathrm{GalNAc}$ 或 $\mathrm{Gal}$。
- [ ] 选凝素识别内皮特异聚糖，介导白细胞出血管。
- [ ] $\mathrm{IgG}$ 的 $\mathrm{Fc}$ 段 $N$-聚糖参与 $\mathrm{Fc}$ 受体和补体结合；去聚糖则功能丢失。
:::
