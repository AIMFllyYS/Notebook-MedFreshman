# 第一节　糖的摄取与利用

本章打开糖代谢。先把糖写成体内被优先利用的能源和碳源：$1\,\mathrm{mol}$ 葡萄糖完全氧化释放 $2840\,\mathrm{kJ}$，约 $34\%$ 转入 $\mathrm{ATP}$。本节只写摄取与利用：食物糖消化成单糖、小肠靠 $\mathrm{SGLT}$ 吸收、组织细胞靠 $\mathrm{GLUT}$ 摄入，肝按餐后／空腹调节血糖。第二节才把进入细胞后的葡萄糖写成无氧氧化。

糖是人体所需的一类重要营养物质，为生命活动提供能源和碳源。糖是体内被优先利用的主要供能物质，$1\,\mathrm{mol}$ 葡萄糖（glucose）完全氧化生成二氧化碳和水可释放 $2840\,\mathrm{kJ}$ 的能量，其中约 $34\%$ 转化储存于 $\mathrm{ATP}$，以供应机体生理活动所需的能量。糖也是体内的重要碳源，糖代谢的中间产物可转变成其他的含碳化合物，如非必需氨基酸、非必需脂肪酸、核苷酸等。此外，糖还参与组成糖蛋白、蛋白聚糖和糖脂，调节细胞信息传递，参与构成细胞外基质等组织结构，形成 $\mathrm{NAD}^+$、$\mathrm{FAD}$、$\mathrm{ATP}$ 等多种生物活性物质。除葡萄糖外，其他单糖如果糖、半乳糖、甘露糖等所占比例很小，且主要转变为葡萄糖代谢的中间产物，故本章重点介绍葡萄糖在体内的代谢。

:::definition{label="糖作为能源和碳源"}
糖是体内被优先利用的主要供能物质，也是重要碳源。$1\,\mathrm{mol}$ 葡萄糖完全氧化生成 $\mathrm{CO}_2$ 和 $\mathrm{H}_2\mathrm{O}$ 释放 $2840\,\mathrm{kJ}$，其中约 $34\%$ 转化储存于 $\mathrm{ATP}$。中间产物可转变成非必需氨基酸、非必需脂肪酸、核苷酸等；糖还参与组成糖蛋白、蛋白聚糖和糖脂，并形成 $\mathrm{NAD}^+$、$\mathrm{FAD}$、$\mathrm{ATP}$ 等。
:::

:::keypoint{label="本章为什么以葡萄糖为主账"}
- 能源：优先利用；$2840\,\mathrm{kJ}/\mathrm{mol}$，约 $34\%$ 进 $\mathrm{ATP}$。
- 碳源：中间产物改写成其他含碳化合物。
- 结构与信息：糖蛋白、蛋白聚糖、糖脂、细胞外基质。
- 其他单糖（果糖、半乳糖、甘露糖）比例很小，主要汇入葡萄糖代谢中间产物，第二节末再立户。
:::

:::pitfall{label="2840 kJ 不是全部变成 ATP"}
完全氧化释放的是 $2840\,\mathrm{kJ}$；转入 $\mathrm{ATP}$ 的大约只有 $34\%$。不要把“完全氧化的自由能”听成“全部装进 $\mathrm{ATP}$”。第三节按本版把有氧氧化净得写成 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$，与这一笔能量账分开记。
:::

机体主要从食物中获取糖类物质，经消化吸收后的糖转运进入组织细胞，发生一系列复杂的连锁化学反应，满足多种生理活动的需要。

## 一、糖消化后以单体形式吸收

食物中能被人体分解利用的糖类，主要有植物淀粉、动物糖原以及麦芽糖、蔗糖、乳糖、葡萄糖等。人体缺少 $\beta$-葡萄糖苷酶，不能消化食物中的纤维素，但纤维素有刺激肠蠕动等作用，也是维持健康所必需的糖类。

:::definition{label="可被人体分解利用的食物糖类"}
主要有植物淀粉、动物糖原以及麦芽糖、蔗糖、乳糖、葡萄糖等。它们必须先被消化成单糖，才能在小肠被吸收。
:::

:::pitfall{label="人体没有 β-葡萄糖苷酶，纤维素不消化但并非无用"}
纤维素含 $\beta$-糖苷键，人体缺 $\beta$-葡萄糖苷酶，不能把它水解成葡萄糖供能。教材紧接着写：纤维素有刺激肠蠕动等作用，也是维持健康所必需的糖类。不要把“不能消化”听成“膳食纤维可以删掉”。
:::

:::concept{term="先问消化成没成单糖，再问用哪一类载体进黏膜"}
看见“吃进去的糖”，先不要跳到糖酵解。口腔停留时间短，淀粉消化主场在小肠；刷状缘把寡糖切成单糖；单糖进黏膜靠 $\mathrm{SGLT}$（耗能、伴 $\mathrm{Na}^{+}$）。血里的葡萄糖再进组织细胞，才换 $\mathrm{GLUT}$ 那一本账。
:::

**1. 淀粉在小肠内消化为葡萄糖**　小麦、稻米和谷薯等食物中的糖类以淀粉（starch）为主。唾液和胰液中都有 $\alpha$-淀粉酶（$\alpha$-amylase），可水解淀粉分子内的 $\alpha$-$1,4$-糖苷键。由于食物在口腔停留的时间很短，所以淀粉消化的主要场所是小肠。在胰液 $\alpha$-淀粉酶作用下，淀粉被水解的主要产物为仅含有 $\alpha$-$1,4$-糖苷键的麦芽糖、麦芽三糖，还生成少量含有 $\alpha$-$1,6$-糖苷键的异麦芽糖、带分支的寡聚葡萄糖混合物（称为 $\alpha$-极限糊精，$\alpha$-limit dextrin）。寡糖在小肠黏膜刷状缘进一步消化：$\alpha$-葡萄糖苷酶（包括麦芽糖酶）水解麦芽糖和麦芽三糖；$\alpha$-极限糊精酶（包括异麦芽糖酶）可水解 $\alpha$-$1,4$-糖苷键和 $\alpha$-$1,6$-糖苷键，将 $\alpha$-极限糊精和异麦芽糖水解为葡萄糖。

:::definition{label="α-淀粉酶"}
$\alpha$-淀粉酶（$\alpha$-amylase）存在于唾液和胰液，水解淀粉分子内的 $\alpha$-$1,4$-糖苷键。口腔停留时间短，淀粉消化的主要场所是小肠。
:::

:::definition{label="α-极限糊精"}
$\alpha$-极限糊精（$\alpha$-limit dextrin）是胰液 $\alpha$-淀粉酶水解淀粉后生成的、带分支的寡聚葡萄糖混合物，含 $\alpha$-$1,6$-糖苷键。需刷状缘 $\alpha$-极限糊精酶（包括异麦芽糖酶）继续水解为葡萄糖。
:::

:::compare{title="淀粉消化：先切直链，再在刷状缘收尾"}
| 场所／酶 | 键 | 产物 |
|----------|----|------|
| 唾液、胰液 $\alpha$-淀粉酶 | $\alpha$-$1,4$-糖苷键 | 麦芽糖、麦芽三糖；少量异麦芽糖、$\alpha$-极限糊精 |
| 刷状缘 $\alpha$-葡萄糖苷酶（含麦芽糖酶） | 麦芽糖、麦芽三糖 | 葡萄糖 |
| 刷状缘 $\alpha$-极限糊精酶（含异麦芽糖酶） | $\alpha$-$1,4$ 与 $\alpha$-$1,6$ | 把 $\alpha$-极限糊精和异麦芽糖水解为葡萄糖 |

主场在小肠，不在口腔。
:::

**2. 小肠吸收葡萄糖依赖于 SGLT 转运蛋白**　糖类被消化成单糖后，才能在小肠被吸收。葡萄糖进入小肠黏膜细胞依赖于特定载体，这是一个耗能的主动转运过程，同时伴有 $\mathrm{Na}^{+}$ 的转运。这类转运葡萄糖的载体称为 $\mathrm{Na}^{+}$ 依赖型葡萄糖转运蛋白（sodium-dependent glucose transporter，$\mathrm{SGLT}$），它们主要存在于小肠黏膜和肾小管上皮细胞。

:::definition{label="SGLT"}
$\mathrm{Na}^{+}$ 依赖型葡萄糖转运蛋白（sodium-dependent glucose transporter，$\mathrm{SGLT}$）介导葡萄糖进入小肠黏膜细胞：耗能的主动转运，同时伴有 $\mathrm{Na}^{+}$ 的转运。主要存在于小肠黏膜和肾小管上皮细胞。
:::

:::insight{label="小肠进黏膜是 SGLT，组织进细胞是 GLUT"}
$\mathrm{SGLT}$ 这一笔写的是“单糖怎么进小肠黏膜／肾小管上皮”：耗能、伴 $\mathrm{Na}^{+}$。血糖随后进入肝、肌、脂肪等组织细胞，换成下面 $\mathrm{GLUT}$ 家族。两套载体不要并成“肠道吸收＝全身摄取”。
:::

**3. 乳糖不耐受由缺乏乳糖酶所致**　肠黏膜细胞还含有乳糖酶和蔗糖酶等，分别水解乳糖和蔗糖。有些人由于缺乏乳糖酶，在食用牛奶后发生乳糖消化吸收障碍，引起腹胀、腹泻等症状，称为乳糖不耐受（lactose intolerance）。

:::definition{label="乳糖不耐受"}
乳糖不耐受（lactose intolerance）由肠黏膜缺乏乳糖酶所致。食用牛奶后乳糖消化吸收障碍，引起腹胀、腹泻等症状。
:::

:::pitfall{label="乳糖不耐受不是“对牛奶蛋白质过敏”"}
缺的是乳糖酶，户头在双糖水解。蔗糖酶水解蔗糖是另一本账。不要把腹胀腹泻直接写成免疫反应。
:::

## 二、细胞摄取葡萄糖需要葡萄糖转运蛋白

葡萄糖吸收入血后，在体内代谢首先需进入组织细胞。这是依赖一类葡萄糖转运蛋白（glucose transporter，$\mathrm{GLUT}$）实现的。

:::definition{label="GLUT"}
葡萄糖转运蛋白（glucose transporter，$\mathrm{GLUT}$）介导血中葡萄糖进入组织细胞。人体内现已发现 $12$ 种 $\mathrm{GLUT}$，分别在不同的组织细胞中起作用，其中 $\mathrm{GLUT}1\sim 5$ 的功能较为明确。
:::

**1. GLUT 家族成员的组织分布和功能有所差异**　人体内现已发现 $12$ 种 $\mathrm{GLUT}$，分别在不同的组织细胞中起作用，其中 $\mathrm{GLUT}1\sim 5$ 的功能较为明确。$\mathrm{GLUT}1$ 和 $\mathrm{GLUT}3$ 广泛分布于全身各组织，与葡萄糖的亲和力较高，是细胞摄取葡萄糖的基本转运载体。$\mathrm{GLUT}2$ 主要存在于肝和胰 $\beta$ 细胞中，与葡萄糖的亲和力较低，使肝从餐后血中摄取过量的葡萄糖，并调节胰岛素分泌。$\mathrm{GLUT}4$ 主要存在于肌和脂肪组织中，以胰岛素依赖方式摄取葡萄糖，耐力训练可以使肌组织细胞膜上的 $\mathrm{GLUT}4$ 数量增加。$\mathrm{GLUT}5$ 主要分布于小肠，是果糖进入细胞的重要转运载体。

:::compare{title="SGLT 与 GLUT1～5（本版名单）"}
| 载体 | 主要部位 | 教材落点 |
|------|----------|----------|
| $\mathrm{SGLT}$ | 小肠黏膜、肾小管上皮 | 耗能主动转运，伴 $\mathrm{Na}^{+}$；单糖吸收进黏膜 |
| $\mathrm{GLUT}1$、$\mathrm{GLUT}3$ | 广泛分布于全身各组织 | 与葡萄糖亲和力较高，基本转运载体 |
| $\mathrm{GLUT}2$ | 肝和胰 $\beta$ 细胞 | 亲和力较低；餐后肝摄取过量葡萄糖，并调节胰岛素分泌 |
| $\mathrm{GLUT}4$ | 肌和脂肪组织 | 胰岛素依赖；耐力训练使肌细胞膜 $\mathrm{GLUT}4$ 数量增加 |
| $\mathrm{GLUT}5$ | 小肠 | 果糖进入细胞的重要转运载体 |

本版写“已发现 $12$ 种”，功能讲清楚的是 $1\sim 5$。不要改成其他版本的成员数。
:::

:::insight{label="GLUT2 亲和力低，正好赶上餐后高峰"}
亲和力低不是“肝不爱要糖”。餐后血糖显著升高时，$\mathrm{GLUT}2$ 才大量摄取，缓冲血糖并让胰 $\beta$ 细胞感知葡萄糖、调节胰岛素分泌。基本摄取走 $\mathrm{GLUT}1/3$；餐后过量走 $\mathrm{GLUT}2$；胰岛素调控的肌／脂肪走 $\mathrm{GLUT}4$。
:::

**2. 依赖 GLUT4 的糖摄取障碍可能诱发高血糖**　$\mathrm{GLUT}4$ 摄取葡萄糖依赖于胰岛素，这对于餐后机体利用糖尤为重要。进食糖类后血糖快速升高，引起胰岛素分泌。当胰岛素与其受体发生相互作用时，能够使原先储存在脂肪细胞和肌细胞内囊泡中的 $\mathrm{GLUT}4$，转位至细胞膜从而发挥功能，将血糖转运入这些组织细胞中，降低餐后血糖。$1$ 型糖尿病患者由于胰岛素分泌不足，无法触发 $\mathrm{GLUT}4$ 向细胞膜转位，阻碍了血中葡萄糖的摄取利用，是引起高血糖的可能原因之一。

:::definition{label="GLUT4 的胰岛素转位"}
进食糖类 → 血糖升高 → 胰岛素分泌 → 胰岛素与受体作用 → 肌和脂肪细胞内囊泡中的 $\mathrm{GLUT}4$ 转位至细胞膜 → 摄取血糖、降低餐后血糖。
:::

:::cause-effect{title="1 型糖尿病与 GLUT4 转位"}
- **因** 胰岛素分泌不足，无法触发肌／脂肪细胞内囊泡中的 $\mathrm{GLUT}4$ 向细胞膜转位
- **果** 血中葡萄糖摄取利用受阻，是引起高血糖的可能原因之一
:::

:::pitfall{label="GLUT4 不是“胰岛素把通道打开”那么简单"}
教材写的是转位：原先存在囊泡里，胰岛素来了才搬到膜上。$1$ 型糖尿病这一笔落在“分泌不足 → 转位触发不了”，不是本节展开胰岛素受体后全部信号通路。耐力训练增加的是肌细胞膜上 $\mathrm{GLUT}4$ 的数量，与胰岛素转位是两句。
:::

:::example{label="餐后血糖怎么被肌和脂肪“收走”"}
糖类入血 → 胰岛素 ↑ → 囊泡 $\mathrm{GLUT}4$ 搬到肌／脂肪细胞膜 → 葡萄糖进这些组织。$\mathrm{GLUT}1/3$ 管基本摄取，$\mathrm{GLUT}2$ 管肝和胰 $\beta$ 细胞感知高峰，不能替代 $\mathrm{GLUT}4$ 这一条胰岛素依赖通路。
:::

## 三、体内糖代谢处于分解、储存与合成的动态平衡

转运进入组织细胞内的葡萄糖，经历一系列复杂的连锁化学反应，涉及分解、储存、合成的动态平衡。

**1. 肝是调节血糖的主要器官**　葡萄糖被小肠黏膜细胞吸收后，先经门静脉入肝。肝发挥调节血糖的关键作用。餐后，肝通过分解葡萄糖、合成糖原和脂质而降低血糖；空腹或饥饿时，肝通过糖原分解、糖异生而输出葡萄糖，补充血糖。

:::definition{label="肝调节血糖"}
葡萄糖经小肠黏膜吸收后，先经门静脉入肝。餐后，肝通过分解葡萄糖、合成糖原和脂质而降低血糖；空腹或饥饿时，肝通过糖原分解、糖异生而输出葡萄糖，补充血糖。
:::

:::keypoint{label="肝调节血糖三句话"}
- 吸收后先经门静脉入肝。
- 餐后：分解葡萄糖、合成糖原和脂质，降低血糖。
- 空腹或饥饿：糖原分解、糖异生，输出葡萄糖，补充血糖。
:::

**2. 糖代谢涉及分解、储存与合成三方面**　①餐后葡萄糖优先分解，涉及糖的无氧氧化、有氧氧化和戊糖磷酸途径，其分解方式取决于不同组织细胞的代谢特点和供氧状况。例如，机体绝大多数组织在供氧充足时，葡萄糖有氧氧化生成 $\mathrm{CO}_2$ 和 $\mathrm{H}_2\mathrm{O}$；肌组织在缺氧时，葡萄糖无氧氧化生成乳酸；饱食后肝内由于合成脂质的需要，葡萄糖通过戊糖磷酸途径提供 $\mathrm{NADPH}$。②葡萄糖的储存仅在餐后活跃进行：以糖原形式储存于肝和肌组织中，以便在空腹时补充血糖或不利用氧快速供能。③葡萄糖的合成在饥饿时尤为活跃：某些非糖物质如甘油、氨基酸等，经糖异生转变成葡萄糖，以补充血糖。总之，糖的分解、储存、合成代谢途径，在多种激素调控下相互协调和制约，使血中葡萄糖的来源与去路相对平衡，血糖水平趋于稳定。

:::compare{title="分解、储存、合成三本账（本节先立，后文展开）"}
| 方面 | 何时活跃 | 教材例子 | 后文 |
|------|----------|----------|------|
| 分解 | 餐后优先 | 供氧充足 → 有氧氧化生成 $\mathrm{CO}_2$ 和 $\mathrm{H}_2\mathrm{O}$；肌缺氧 → 无氧氧化生成乳酸；饱食肝合成脂质 → 戊糖磷酸途径提供 $\mathrm{NADPH}$ | 第二～四节 |
| 储存 | 仅在餐后活跃 | 糖原储存于肝和肌；空腹补血糖，或不利用氧快速供能 | 第五节 |
| 合成 | 饥饿时尤为活跃 | 甘油、氨基酸等经糖异生转变成葡萄糖 | 第六节 |

激素把三本账协调到“来源与去路相对平衡”。
:::

:::concept{term="先问进没进细胞，再问这条糖走分解、储存还是合成"}
本节只把糖送到细胞内并立三本去路。无氧氧化、有氧氧化、戊糖磷酸途径是分解的三条；糖原是储存；糖异生是合成。不要在第一节把十步酵解写完。
:::

- [ ] 人体无 $\beta$-葡萄糖苷酶，不能消化纤维素；纤维素仍刺激肠蠕动
- [ ] 淀粉消化主场在小肠：$\alpha$-淀粉酶切 $\alpha$-$1,4$，刷状缘再切到葡萄糖
