# 第一节　蛋白质合成体系

第十六章把遗传信息从 $\mathrm{mRNA}$ 落到氨基酸顺序。本节只立翻译的分子清单：$\mathrm{mRNA}$ 上的三联体密码（方向性、连续性、简并性、摆动性、通用性）和移码；$\mathrm{tRNA}$ 作为氨基酸与密码子之间的接头；核糖体 $\mathrm{A}/\mathrm{P}/\mathrm{E}$ 三个功能部位；原核 $\mathrm{IF}/\mathrm{EF}/\mathrm{RF}$ 与真核 $\mathrm{eIF}/\mathrm{eEF}/\mathrm{eRF}$ 的名单。氨酰化反应、$\mathrm{SD}$ 序列、起始复合物装配、进位—成肽—转位和终止是第二节的账；折叠、加工和靶向输送是第三节。

:::concept{term="先问谁带密码、谁对号入座、在哪条装配线上成肽"}
看见“蛋白质合成体系”，先不要默写进位、成肽、转位。户头是：$\mathrm{mRNA}$ 可读框里每三个核苷酸一个密码子；$64$ 个密码子里 $61$ 个编码 $20$ 种原料氨基酸，$3$ 个是终止信号，$\mathrm{AUG}$ 兼起始；$\mathrm{tRNA}$ 一端挂氨基酸、一端用反密码子认密码子；核糖体是装配厂，原核、真核都有 $\mathrm{A}$ 位、$\mathrm{P}$ 位、$\mathrm{E}$ 位。密码子怎么被连续读、怎么摆动，是本节的账；氨基酸怎样活化、起始 $\mathrm{tRNA}$ 怎样进 $\mathrm{P}$ 位，交给第二节。
:::

教材第 $297$ 页章首「本章数字资源」及章题图源 `p0326_01.png` 为 $0$ 字节，不嵌入 `src`。本节非空插图从下一页的图16-1 开始。
:::

蛋白质具有多种生物学功能，参与生命的几乎所有过程，是生命活动的物质基础。通常在某一特定时刻，一个细胞的生存及活动约需数千种结构蛋白质和功能蛋白质的参与。蛋白质具有高度的种属特异性，不同种属间蛋白质不能互相替代，因此各种生物的蛋白质均由机体自身合成。

:::definition{label="蛋白质由机体自身合成"}
蛋白质有高度种属特异性，不同种属间不能互相替代。因此各种生物的蛋白质均由机体自身合成，不能指望“借来”别的种属现成的肽链。
:::

:::insight{label="约数千种是某一时刻的需求，不是基因组编码总数"}
教材写的是「某一特定时刻……约需数千种结构蛋白质和功能蛋白质」。这是当时细胞正在用的那一套，不要改写成「一个细胞终身只合成几千种蛋白质」。
:::

蛋白质由基因编码，是遗传信息表达的主要终产物。$\mathrm{mRNA}$ 带有蛋白质合成的编码信息，是蛋白质合成的模板。蛋白质在机体内的合成过程，实际上就是遗传信息从 $\mathrm{DNA}$ 经 $\mathrm{mRNA}$ 传递到蛋白质的过程，此时 $\mathrm{mRNA}$ 分子中的遗传信息被具体地翻译成蛋白质的氨基酸排列顺序，因此这一过程也被形象地称为翻译（translation）。从低等生物细菌到高等哺乳动物，蛋白质合成机制高度保守。

:::definition{label="翻译"}
翻译（translation）：$\mathrm{mRNA}$ 分子中的遗传信息被具体地翻译成蛋白质的氨基酸排列顺序。遗传信息从 $\mathrm{DNA}$ 经 $\mathrm{mRNA}$ 传到蛋白质，蛋白质是基因表达的主要终产物，$\mathrm{mRNA}$ 是模板。
:::

:::definition{label="蛋白质合成机制高度保守"}
从细菌到哺乳动物，蛋白质合成机制高度保守。后文遗传密码的通用性、核糖体都有 $\mathrm{A}/\mathrm{P}/\mathrm{E}$ 位，都是这句的着落；少数例外（如哺乳动物线粒体密码）不要拿来推翻「高度保守」。
:::

:::pitfall{label="翻译的模板是 mRNA，不是 DNA"}
转录以 $\mathrm{DNA}$ 为模板抄 $\mathrm{RNA}$（第十五章）；翻译以 $\mathrm{mRNA}$ 为模板排氨基酸。把模板答成基因组 $\mathrm{DNA}$，密码子表和反密码子配对都没有落点。
:::

:::compare{title="中心法则里本节管哪一段"}
| | 模板 | 产物 | 本章位置 |
|--|------|------|----------|
| 转录 | $\mathrm{DNA}$ | $\mathrm{RNA}$ | 第十五章 |
| 翻译 | $\mathrm{mRNA}$ | 蛋白质（氨基酸顺序） | 第十六章；本节立体系，第二节写过程 |
| 翻译后加工与靶向 | 已合成的肽链 | 有活性、到位点的蛋白质 | 第三节 |

本节到第二节都还在「氨基酸顺序怎么按密码子排出来」；折叠、切除、定位是肽链合成之后的账。
:::

新合成的蛋白质多肽链通常并不具备生物学活性，需经过各种修饰、加工并折叠为正确构象，然后靶向运输至合适的亚细胞部位才能行使其功能。

:::insight{label="本章开篇已经预告第三节"}
「通常并不具备生物学活性」是给第三节的伏笔：核糖体上走完的是多肽链，不是成熟蛋白质。本节先把合成体系立住，不要把分子伴侣、信号肽提前搬进来。
:::

蛋白质合成是细胞最为复杂的活动之一。参与细胞内蛋白质生物合成的物质除原料氨基酸外，还需要 $\mathrm{mRNA}$ 作为模板，$\mathrm{tRNA}$ 作为特异的氨基酸「搬运工具」，核糖体作为蛋白质合成的装配场所，有关的酶与蛋白质因子参与反应，并且需要 $\mathrm{ATP}$ 或 $\mathrm{GTP}$ 提供能量。

:::definition{label="蛋白质合成体系的五类角色"}
①原料：氨基酸；②模板：$\mathrm{mRNA}$；③搬运工具：$\mathrm{tRNA}$；④装配场所：核糖体；⑤酶、蛋白质因子，以及 $\mathrm{ATP}$ 或 $\mathrm{GTP}$ 供能。缺任何一类都装配不成肽链。
:::

:::keypoint{label="能量分子先记 ATP 或 GTP，不要提前拆成 4 个高能磷酸键"}
本节只说需要 $\mathrm{ATP}$ 或 $\mathrm{GTP}$。每个肽键至少消耗 $4$ 个高能磷酸键（活化 $2$ 个 $+$ 延长进位、转位各 $1$ 个 $\mathrm{GTP}$）是第二节成肽账末的句子，不要提前写进「体系」这一节。
:::

:::memory{label="体系四个名词对四件事"}
- $\mathrm{mRNA}$：密码写在可读框里。
- $\mathrm{tRNA}$：一边挂氨基酸，一边用反密码子对号。
- 核糖体：$\mathrm{A}$ 位进新的氨酰 $\mathrm{tRNA}$，$\mathrm{P}$ 位留肽酰-$\mathrm{tRNA}$，$\mathrm{E}$ 位出空载 $\mathrm{tRNA}$。
- 因子：起始 $\mathrm{IF}/\mathrm{eIF}$，延长 $\mathrm{EF}/\mathrm{eEF}$，释放 $\mathrm{RF}/\mathrm{eRF}$。
:::

## 一、mRNA 是蛋白质合成的模板

$\mathrm{mRNA}$ 的发现回答了细胞核内基因组的遗传信息如何编码蛋白质这一重要问题。由 $\mathrm{DNA}$ 转录而来的 $\mathrm{mRNA}$ 在细胞质内作为蛋白质合成的模板，$\mathrm{mRNA}$ 编码区（可读框）中的核苷酸序列作为遗传密码（genetic code），在蛋白质合成过程中被翻译为蛋白质的氨基酸序列。

:::definition{label="遗传密码"}
遗传密码（genetic code）：$\mathrm{mRNA}$ 编码区（可读框）中的核苷酸序列，在蛋白质合成过程中被翻译为蛋白质的氨基酸序列。密码写在 $\mathrm{mRNA}$ 上，不是直接写在 $\mathrm{DNA}$ 双螺旋上让核糖体去读。
:::

:::definition{label="可读框是编码区"}
教材把「编码区」与「可读框」并写：核糖体连续阅读的那段核苷酸，才是密码子表作用的范围。$5'$ 端非翻译区、$3'$ 端非翻译区不在这张表里。
:::

:::insight{label="mRNA 在细胞质里当模板"}
由 $\mathrm{DNA}$ 转录而来，到细胞质内指导合成。原核没有核膜，转录与翻译可同步（第二节末）；真核转录在核、翻译在细胞质，两个过程分隔。本节先把模板的空间位置钉在细胞质。
:::

### （一）遗传密码决定氨基酸种类和序列

$\mathrm{mRNA}$ 分子中核苷酸序列的翻译以 $3$ 个相邻核苷酸为单位进行。在 $\mathrm{mRNA}$ 的可读框区域，每 $3$ 个相邻的核苷酸为一组，编码一种氨基酸或肽链合成的起始／终止信息，称为密码子（codon），又称三联体密码（triplet code）。例如，$\mathrm{UUU}$ 是苯丙氨酸的密码子，$\mathrm{UCU}$ 是丝氨酸的密码子，$\mathrm{GCA}$ 是丙氨酸的密码子。构成 $\mathrm{mRNA}$ 的 $4$ 种核苷酸经排列组合可产生 $64$ 个密码子，其中的 $61$ 个编码 $20$ 种在蛋白质合成中作为原料的氨基酸，另有 $3$ 个（$\mathrm{UAA}$、$\mathrm{UAG}$、$\mathrm{UGA}$）不编码任何氨基酸，而是作为肽链合成的终止密码子（termination codon）。需要注意的是，$\mathrm{AUG}$ 具有特殊性，不仅代表甲硫氨酸，如果位于 $\mathrm{mRNA}$ 的翻译起始部位，它还代表肽链合成的起始密码子（initiation codon）（表16-1）。

:::definition{label="密码子（三联体密码）"}
密码子（codon）又称三联体密码（triplet code）：$\mathrm{mRNA}$ 可读框里每 $3$ 个相邻核苷酸为一组，编码一种氨基酸，或给出肽链合成的起始／终止信息。阅读单位是三个，不是一个或两个。
:::

:::definition{label="64、61、20、3"}
$4$ 种核苷酸排列组合得 $64$ 个密码子。$61$ 个编码 $20$ 种原料氨基酸；$3$ 个终止密码子 $\mathrm{UAA}$、$\mathrm{UAG}$、$\mathrm{UGA}$ 不编码任何氨基酸。$\mathrm{AUG}$ 额外兼任起始密码子。
:::

:::definition{label="终止密码子"}
终止密码子（termination codon）：$\mathrm{UAA}$、$\mathrm{UAG}$、$\mathrm{UGA}$。不编码氨基酸，不与任何氨酰 $\mathrm{tRNA}$ 配对；第二节里由释放因子 $\mathrm{RF}/\mathrm{eRF}$ 识别。
:::

:::definition{label="起始密码子 AUG"}
$\mathrm{AUG}$ 代表甲硫氨酸；若位于 $\mathrm{mRNA}$ 的翻译起始部位，它还是起始密码子（initiation codon）。表16-1 注：作为起始信号的 $\mathrm{AUG}$，在原核生物中代表甲酰甲硫氨酸，在真核生物中代表甲硫氨酸。
:::

:::definition{label="教材给的三个例子先能对上表"}
$\mathrm{UUU}$＝苯丙氨酸，$\mathrm{UCU}$＝丝氨酸，$\mathrm{GCA}$＝丙氨酸。默写密码子定义时，用这三个例子比凭空写「三联体」更不容易把表16-1 的行列读反。
:::

:::pitfall{label="不要把 64 个密码子都写成编码氨基酸"}
$64=61+3$。把终止密码子也算进「编码氨基酸」，表16-1 里三处「终止密码子」就没有户头，$\mathrm{RF}$ 进 $\mathrm{A}$ 位那一步也会被写成「空密码子对应空 $\mathrm{tRNA}$」。
:::

:::pitfall{label="AUG 不是「只当起始、不当甲硫氨酸」"}
内部的 $\mathrm{AUG}$ 编码甲硫氨酸；位于翻译起始部位时才兼作起始信号。原核起始用的是甲酰甲硫氨酸，真核起始用的是甲硫氨酸——差别在起始氨酰 $\mathrm{tRNA}$，不是另造一个密码子。
:::

:::pitfall{label="终止密码子不要外号记成「无意义密码子就没有功能」"}
「不编码任何氨基酸」不等于「没有生物学功能」。它们的功能是给出终止信息。写成「无意义所以核糖体跳过」，肽链会一直延长到 $\mathrm{mRNA}$ 尽头。
:::

### （二）遗传密码具有五个重要特点

遗传密码的五个特点是方向性、连续性、简并性、摆动性和通用性。前两个决定核糖体怎么读；简并和摆动解释「$61$ 个密码子对 $20$ 种氨基酸、一种 $\mathrm{tRNA}$ 可认多种密码子」；通用性把这张表从细菌用到人，并留下线粒体例外。

:::definition{label="遗传密码的五个特点"}
方向性、连续性、简并性、摆动性、通用性。五个都要能各用一句话还原，不要只背名词。
:::

:::timeline{period="五个特点各自管什么"}
- **方向性** 只能从 mRNA 的 5 端读到 3 端，对应肽链从 N 端到 C 端
- **连续性** 密码子之间没有间隔；非 3 倍数插入或缺失造成移码
- **简并性** 一种氨基酸可有多个密码子，特异性主要由前两位决定
- **摆动性** 反密码子第 1 位与密码子第 3 位配对有时不严格
- **通用性** 细菌到人都用同一套，哺乳类线粒体有少数例外
:::

#### 1. 方向性

组成密码子的核苷酸在 $\mathrm{mRNA}$ 中的排列具有方向性。翻译时的阅读方向只能从 $5'$ 至 $3'$，即从 $\mathrm{mRNA}$ 的起始密码子 $\mathrm{AUG}$ 开始，按 $5'\rightarrow 3'$ 的方向逐一阅读，直至终止密码子。$\mathrm{mRNA}$ 可读框中从 $5'$ 端到 $3'$ 端排列的核苷酸顺序决定了肽链中从 $\mathrm{N}$ 端到 $\mathrm{C}$ 端的氨基酸排列顺序（图16-1a）。

:::definition{label="遗传密码的方向性"}
阅读方向只能 $5'\rightarrow 3'$：从起始密码子 $\mathrm{AUG}$ 开始，逐一读到终止密码子。$\mathrm{mRNA}$ 的 $5'\rightarrow 3'$ 决定肽链的 $\mathrm{N}$ 端 $\rightarrow\mathrm{C}$ 端。
:::

:::definition{label="N 端对应 mRNA 的 5′ 端"}
第一位被翻译的密码子是起始 $\mathrm{AUG}$，掺入的是肽链 $\mathrm{N}$ 端的甲硫氨酸（原核为甲酰甲硫氨酸）。不要把 $\mathrm{C}$ 端画在 $5'$ 一侧。
:::

:::pitfall{label="不要把翻译阅读方向写成 3′→5′"}
模板 $\mathrm{DNA}$ 被转录时 $\mathrm{RNA}\,\mathrm{pol}$ 沿模板链 $3'\rightarrow 5'$ 阅读（第十五章），那是转录的账。翻译读的是 $\mathrm{mRNA}$ 本身，方向 $5'\rightarrow 3'$。两套方向不要并成一句。
:::

#### 2. 连续性

$\mathrm{mRNA}$ 中密码子之间没有间隔核苷酸，即从起始密码子开始，密码子被连续阅读，直至终止密码子出现。因密码子具有连续性，若可读框中插入或缺失了非 $3$ 倍数的核苷酸，将会引起 $\mathrm{mRNA}$ 可读框发生移动，称为移码（frame shift）。移码导致后续氨基酸编码序列改变，使得其编码的蛋白质彻底丧失或改变原有功能，称为移码突变（frameshift mutation）（图16-1b）。若连续插入或缺失 $3$ 个核苷酸，则只会在多肽链产物中增加或缺失 $1$ 个氨基酸残基，但不会导致可读框移位。

:::definition{label="遗传密码的连续性"}
密码子之间没有间隔核苷酸。从起始密码子开始连续阅读，直到终止密码子。没有「跳过一个碱基再读」的合法方式。
:::

:::definition{label="移码"}
移码（frame shift）：可读框中插入或缺失非 $3$ 倍数的核苷酸，引起后续密码子分组全部改组。
:::

:::definition{label="移码突变"}
移码突变（frameshift mutation）：移码导致后续氨基酸编码序列改变，编码的蛋白质彻底丧失或改变原有功能。
:::

:::definition{label="连续插入或缺失 3 个核苷酸不是移码"}
连续插入或缺失 $3$ 个核苷酸，只在多肽链中增加或缺失 $1$ 个氨基酸残基，可读框不移位。判断「是不是移码」先看插入／缺失数是否为 $3$ 的倍数。
:::

:::cause-effect{title="为什么非 3 倍数插入会毁掉整条下游肽"}
- **因** 密码子按三个一组连续阅读，中间没有逗号
- **果** 插入或缺失 $1$ 或 $2$ 个核苷酸后，插入点之后的每一组三个碱基都重新划分，氨基酸序列从那一点起全部改写，常在下游出现新的终止或读穿原终止
:::

:::insight{label="图16-1b 插入的是一个 C，不是三个"}
野生型 $\mathrm{AAU}$（Asn）所在分组被插入的 $\mathrm{C}$ 打断：图中蓝框标「插入的核苷酸」。插入点之前 $\mathrm{Met}$-$\mathrm{Gly}$-$\mathrm{Leu}$ 仍与（a）相同；从蓝底开始变成 $\mathrm{Thr}$-$\mathrm{Cys}$-$\mathrm{Asp}$，末端变成 $\mathrm{Ala}$-$\mathrm{Met}$，原 $\mathrm{UGA}$ 终止分组被拆掉。这是「彻底改变原有功能」的画面，不是点突变换一个残基。
:::

:::pitfall{label="点突变换一个碱基通常不是移码"}
三联体内部换一个核苷酸，多数仍按原框阅读，最多换一个氨基酸或变成终止（错义／无义）。移码专指插入或缺失造成的框移动。把所有突变都叫移码，图16-1b 的「插入」就没有特殊性。
:::

:::pitfall{label="插入 3 个核苷酸不要答成移码突变"}
教材把「非 $3$ 倍数」和「连续 $3$ 个」对举。插入一个氨基酸不等于框移。考试若写「插入三个碱基＝移码」，连续性这一条的例外就被抹掉。
:::

:::compare{title="插入 1 个 vs 插入 3 个"}
| | 非 $3$ 倍数插入／缺失 | 连续 $3$ 个核苷酸插入／缺失 |
|--|------------------------|------------------------------|
| 可读框 | 移动（移码） | 不移位 |
| 下游氨基酸 | 全部改写 | 原顺序基本保留 |
| 产物 | 蛋白质彻底丧失或改变原有功能 | 增加或缺失 $1$ 个氨基酸残基 |
| 图16-1 | （b）插入一个 $\mathrm{C}$ | 正文叙述，图未另画 |

先数核苷酸个数，再决定用哪一列。
:::

#### 3. 简并性

$64$ 个密码子中有 $61$ 个编码氨基酸，而氨基酸只有 $20$ 种，因此有的氨基酸可由多个密码子编码，这种现象称为简并性（degeneracy）。例如，$\mathrm{UUU}$ 和 $\mathrm{UUC}$ 都是苯丙氨酸的密码子，$\mathrm{UCU}$、$\mathrm{UCC}$、$\mathrm{UCA}$、$\mathrm{UCG}$、$\mathrm{AGU}$ 和 $\mathrm{AGC}$ 都是丝氨酸的密码子。

为同一种氨基酸编码的各个密码子称为简并性密码子，也称同义密码子。多数情况下，同义密码子的前两位碱基相同，仅第三位碱基有差异，即密码子的特异性主要由前两位核苷酸决定，如苏氨酸的密码子是 $\mathrm{ACU}$、$\mathrm{ACC}$、$\mathrm{ACA}$、$\mathrm{ACG}$。这意味着密码子第三位核苷酸的改变往往不改变其编码的氨基酸，合成的蛋白质具有相同的一级结构。因此，遗传密码的简并性可减少基因突变所带来的生物学效应。

:::definition{label="简并性"}
简并性（degeneracy）：有的氨基酸可由多个密码子编码。$61$ 个有义密码子对应 $20$ 种氨基酸，不是一一对应。
:::

:::definition{label="简并性密码子（同义密码子）"}
为同一种氨基酸编码的各个密码子互称简并性密码子，也称同义密码子。
:::

:::definition{label="特异性主要由前两位决定"}
多数同义密码子前两位相同，仅第三位不同。密码子的特异性主要由前两位核苷酸决定。第三位改变往往不改氨基酸，一级结构不变，从而减少基因突变的生物学效应。
:::

:::keypoint{label="教材三个简并例子必须能默写"}
- 苯丙氨酸：$2$ 个——$\mathrm{UUU}$、$\mathrm{UUC}$。
- 丝氨酸：$6$ 个——$\mathrm{UCU}$、$\mathrm{UCC}$、$\mathrm{UCA}$、$\mathrm{UCG}$、$\mathrm{AGU}$、$\mathrm{AGC}$（后两个前两位不是 $\mathrm{UC}$，是「多数情况下」的例外）。
- 苏氨酸：$4$ 个——$\mathrm{ACU}$、$\mathrm{ACC}$、$\mathrm{ACA}$、$\mathrm{ACG}$（典型的前两位锁定）。
:::

:::insight{label="丝氨酸提醒你：简并不总是「第三位自由」"}
丝氨酸六个密码子里，四个以 $\mathrm{UC}$ 开头，两个是 $\mathrm{AGU}/\mathrm{AGC}$。教材先举这个例子，紧接着才说「多数情况下前两位相同」。默写时不要把「多数」改成「全部」。
:::

:::pitfall{label="简并性不是「一个密码子编码多种氨基酸」"}
方向写反是常见错：一个氨基酸可有多个密码子；一个密码子在通用密码里只对应一种氨基酸（或终止）。把简并理解成「密码有歧义」，翻译就无法忠实。
:::

:::pitfall{label="不要说「第三位怎么变都不改氨基酸」"}
教材用「往往」。$\mathrm{UAU}$（Tyr）第三位变成 $\mathrm{A}$ 就是终止 $\mathrm{UAA}$；$\mathrm{UGU}$（Cys）第三位变成 $\mathrm{G}$ 就是 $\mathrm{Trp}$。简并降低突变效应，不是取消突变效应。
:::

:::cause-effect{title="简并性怎样减少基因突变的效应"}
- **因** 同义密码子多在第三位不同，第三位突变常仍编码同一氨基酸
- **果** 蛋白质一级结构不变，该突变在表型上被「静默」

这是密码结构对突变的缓冲，不是修复系统把突变改回去。
:::

#### 4. 摆动性

密码子通过与 $\mathrm{tRNA}$ 的反密码子配对而发挥翻译作用，但这种配对有时并不严格遵循 Watson-Crick 碱基配对原则，出现摆动（wobble）。此时 $\mathrm{mRNA}$ 密码子的第 $1$ 位和第 $2$ 位碱基（$5'\rightarrow 3'$）与 $\mathrm{tRNA}$ 反密码子的第 $3$ 位和第 $2$ 位碱基（$5'\rightarrow 3'$）之间仍为 Watson-Crick 配对，而反密码子的第 $1$ 位碱基与密码子的第 $3$ 位碱基配对有时存在摆动现象。例如，反密码子第 $1$ 位碱基为次黄嘌呤（inosine，$\mathrm{I}$），可与密码子第 $3$ 位的 $\mathrm{A}$、$\mathrm{C}$ 或 $\mathrm{U}$ 配对；反密码子第 $1$ 位的 $\mathrm{U}$ 可与密码子第 $3$ 位的 $\mathrm{A}$ 或 $\mathrm{G}$ 配对；反密码子第 $1$ 位的 $\mathrm{G}$ 可与密码子第 $3$ 位的 $\mathrm{C}$ 或 $\mathrm{U}$ 配对（图16-2）。由此可见，密码子的摆动性能使一种 $\mathrm{tRNA}$ 识别 $\mathrm{mRNA}$ 中的多种简并性密码子。

:::definition{label="摆动"}
摆动（wobble）：密码子与反密码子配对有时不严格遵循 Watson-Crick 原则。发生在反密码子第 $1$ 位（$5'$ 端）与密码子第 $3$ 位（$3'$ 端）之间。
:::

:::definition{label="前两对仍是 Watson-Crick"}
密码子第 $1$、$2$ 位（$5'\rightarrow 3'$）与反密码子第 $3$、$2$ 位（$5'\rightarrow 3'$）仍严格配对。只有最末一对允许摆动。不要把整段反密码子都写成「可以不配对」。
:::

:::definition{label="三种教材写明的摆动"}
- 反密码子第 $1$ 位 $\mathrm{I}$（次黄嘌呤）$\leftrightarrow$ 密码子第 $3$ 位 $\mathrm{A}$、$\mathrm{C}$ 或 $\mathrm{U}$。
- 反密码子第 $1$ 位 $\mathrm{U}$ $\leftrightarrow$ 密码子第 $3$ 位 $\mathrm{A}$ 或 $\mathrm{G}$。
- 反密码子第 $1$ 位 $\mathrm{G}$ $\leftrightarrow$ 密码子第 $3$ 位 $\mathrm{C}$ 或 $\mathrm{U}$。
:::

:::definition{label="摆动的功能"}
一种 $\mathrm{tRNA}$ 可以识别 $\mathrm{mRNA}$ 中的多种简并性密码子。简并写在密码表上，摆动写在 $\mathrm{tRNA}$ 识别上，两层合在一起才解释「不必每种密码子各备一种 $\mathrm{tRNA}$」。
:::

::figure{src="/images/biochemistry/textbook/p0328_01.png" caption="图16-2　反密码子与密码子的识别方式与摆动配对。携带异亮氨酸的 tRNA 氨基酸臂在 3′ 端；反密码环中反密码子按与 mRNA 反向平行排成 U·A·G（对应反密码子 5′-GAU-3′），摆动位点在反密码子 5′ 端的 G；mRNA 密码子为 5′-AU(C/U)-3′。" alt="tRNA 反密码环 UAG 对准 mRNA 的 AU(C/U)，摆动位点标在 G 与 C/U 一对"}

:::insight{label="图16-2 把反密码子画成与 mRNA 反向平行"}
$\mathrm{mRNA}$ 左 $5'$ 右 $3'$，密码子 $\mathrm{A}$、$\mathrm{U}$、$\mathrm{C}/\mathrm{U}$。$\mathrm{tRNA}$ 左侧是 $3'$（挂异亮氨酸），右侧是 $5'$，所以环上从左到右写 $\mathrm{U}$、$\mathrm{A}$、$\mathrm{G}$，实际反密码子 $5'\rightarrow 3'$ 是 $\mathrm{GAU}$。摆动位点标在最右侧那个 $\mathrm{G}$——正是反密码子第 $1$ 位。密码子 $\mathrm{AUC}/\mathrm{AUU}$ 都是异亮氨酸，对应正文「$\mathrm{G}$ 可与 $\mathrm{C}$ 或 $\mathrm{U}$ 配对」。
:::

:::compare{title="密码子三位 vs 反密码子三位"}
| 密码子（$\mathrm{mRNA}$，$5'\rightarrow 3'$） | 反密码子（$\mathrm{tRNA}$，$5'\rightarrow 3'$） | 配对规则 |
|-----------------------------------------------|-----------------------------------------------|----------|
| 第 $1$ 位 | 第 $3$ 位 | Watson-Crick |
| 第 $2$ 位 | 第 $2$ 位 | Watson-Crick |
| 第 $3$ 位 | 第 $1$ 位 | 可摆动 |

编号都按各自的 $5'\rightarrow 3'$。把「第 $1$ 位」混成同一侧，摆动位点会标错。
:::

:::pitfall{label="摆动不是简并的别名"}
简并：密码表上一种氨基酸对多个密码子。摆动：一种 $\mathrm{tRNA}$ 的反密码子第 $1$ 位可以认密码子第 $3$ 位的几种碱基。没有摆动也可以有简并（多种 $\mathrm{tRNA}$ 认同一种氨基酸的不同密码子）；有摆动则一种 $\mathrm{tRNA}$ 就能覆盖多个同义密码子。
:::

:::pitfall{label="I 不与 G 配对"}
教材写 $\mathrm{I}$ 对 $\mathrm{A}$、$\mathrm{C}$ 或 $\mathrm{U}$，名单里没有 $\mathrm{G}$。把次黄嘌呤写成「可以配四种碱基」，$\mathrm{AUG}$ 甲硫氨酸那种「第三位是 $\mathrm{G}$」的密码子会被错误地并进 $\mathrm{I}$ 识别。
:::

:::pitfall{label="不要把摆动画在密码子第 1 位"}
方向性已经规定密码子从 $5'$ 读。摆动发生在密码子的 $3'$ 末位。画在起始的 $\mathrm{A}$ 上，图16-2 的 $\mathrm{AU}(\mathrm{C}/\mathrm{U})$ 对不上。
:::

#### 5. 通用性

遗传密码具有通用性（universal），即从低等生物如细菌到人类都使用着同一套遗传密码，这为地球上的生物来自同一起源的进化论提供了有力证据，另外也使得利用细菌等生物来制造人类蛋白质成为可能。但遗传密码的通用性并不是绝对的，也有少数例外。例如，在哺乳类动物线粒体内，$\mathrm{UGA}$ 除了代表终止信号，也代表色氨酸；$\mathrm{AUA}$ 不再代表异亮氨酸，而是作为甲硫氨酸的密码子。

:::definition{label="通用性"}
通用性（universal）：从细菌到人类使用同一套遗传密码。证据意义：支持生物同一起源；应用意义：可用细菌制造人类蛋白质。
:::

:::definition{label="通用性不是绝对的"}
少数例外。教材点名的是哺乳类动物线粒体：$\mathrm{UGA}$ 除终止外也代表色氨酸；$\mathrm{AUA}$ 不再是异亮氨酸，而是甲硫氨酸。
:::

:::compare{title="通用密码 vs 哺乳类线粒体例外"}
| 密码子 | 通用密码（表16-1） | 哺乳类线粒体 |
|--------|-------------------|--------------|
| $\mathrm{UGA}$ | 终止 | 终止，也代表色氨酸 |
| $\mathrm{AUA}$ | 异亮氨酸 | 甲硫氨酸 |
| 其余 | 同一套 | 教材未再列例外 |

例外写在线粒体，不要改细胞质那张表16-1。
:::

:::pitfall{label="不要把线粒体例外推广到细胞质翻译"}
重组表达「用细菌制造人类蛋白质」靠的是细胞质通用密码。把 $\mathrm{UGA}$ 在大肠埃希菌里按色氨酸翻译，表达出的肽链会读穿终止。
:::

:::insight{label="线粒体密码例外与后文线粒体核糖体是同一户"}
本节后文哺乳动物线粒体核糖体 $55\mathrm{S}$，翻译只覆盖氧化磷酸化复合物的几个关键亚基。$\mathrm{UGA}/\mathrm{AUA}$ 的读法只在这套体系里改，不要和细胞质 $80\mathrm{S}$ 混用。
:::

:::memory{label="五个特点各记一句反例或边界"}
- 方向性：不能 $3'\rightarrow 5'$ 读 $\mathrm{mRNA}$。
- 连续性：非 $3$ 倍数插入才移码；$3$ 个核苷酸只加减一个残基。
- 简并性：一个氨基酸对多个密码子，不是一个密码子对多个氨基酸。
- 摆动性：只在反密码子第 $1$ 位。
- 通用性：线粒体 $\mathrm{UGA}$、$\mathrm{AUA}$ 是例外。
:::

## 二、tRNA 是氨基酸和密码子之间的特异连接物

作为蛋白质合成原料的 $20$ 种氨基酸，翻译时由其各自特定的 $\mathrm{tRNA}$ 负责转运至核糖体。$\mathrm{tRNA}$ 通过其特异的反密码子与 $\mathrm{mRNA}$ 上的密码子相互配对，将其携带的氨基酸在核糖体上准确对号入座。虽然已发现的 $\mathrm{tRNA}$ 多达数十种，一种氨基酸通常与多种 $\mathrm{tRNA}$ 特异结合（与密码子的简并性相适应），但是一种 $\mathrm{tRNA}$ 只能转运一种特定的氨基酸。通常在 $\mathrm{tRNA}$ 的右上角标注氨基酸的三字母符号，以代表其特异转运的氨基酸，如 $\mathrm{tRNA}^{\mathrm{Tyr}}$ 表示这是一种特异转运酪氨酸的 $\mathrm{tRNA}$。

:::definition{label="tRNA 是接头"}
$\mathrm{tRNA}$ 是氨基酸和密码子之间的特异连接物：一端转运特定氨基酸，另一端用反密码子与 $\mathrm{mRNA}$ 密码子配对，使氨基酸在核糖体上对号入座。
:::

:::definition{label="一种 tRNA 只转运一种氨基酸"}
已发现的 $\mathrm{tRNA}$ 有数十种。一种氨基酸通常对应多种 $\mathrm{tRNA}$（适应简并性）；一种 $\mathrm{tRNA}$ 只能转运一种特定氨基酸。
:::

:::definition{label="tRNA 的上标写法"}
右上角标注氨基酸三字母符号，表示其特异转运的氨基酸。例如 $\mathrm{tRNA}^{\mathrm{Tyr}}$ 专运酪氨酸。第二节写成 $\mathrm{Tyr}$-$\mathrm{tRNA}^{\mathrm{Tyr}}$ 时，前缀表示氨基酸已经挂上。
:::

:::compare{title="一种氨基酸 vs 一种 tRNA"}
| | 一种氨基酸 | 一种 $\mathrm{tRNA}$ |
|--|------------|---------------------|
| 对应 $\mathrm{tRNA}$ 数 | 通常多种 | —— |
| 对应氨基酸数 | —— | 只能一种 |
| 原因 | 密码子简并 | 反密码子与活化酶的特异性 |

「多对一」只允许出现在氨基酸 $\rightarrow\mathrm{tRNA}$ 这一侧。
:::

:::pitfall{label="不要写成一种 tRNA 可挂多种氨基酸"}
那会把接头的特异性取消。第二节「搭错车」实验要强调的正是：一旦挂错，核糖体仍按 $\mathrm{tRNA}$ 的反密码子把错的氨基酸送进去。
:::

$\mathrm{tRNA}$ 上有两个重要的功能部位：一个是氨基酸结合部位，另一个是 $\mathrm{mRNA}$ 结合部位。与氨基酸结合的部位是 $\mathrm{tRNA}$ 的氨基酸臂的 $-\mathrm{CCA}$ 末端的腺苷酸 $3'$-$\mathrm{OH}$；与 $\mathrm{mRNA}$ 结合的部位是 $\mathrm{tRNA}$ 反密码环中的反密码子。参与肽链合成的氨基酸需要与相应 $\mathrm{tRNA}$ 结合，形成各种氨酰 $\mathrm{tRNA}$（aminoacyl-tRNA），再运载至核糖体，通过其反密码子与 $\mathrm{mRNA}$ 中对应的密码子互补结合（图16-2），从而按照 $\mathrm{mRNA}$ 的密码子顺序依次加入氨基酸。

:::definition{label="tRNA 的两个功能部位"}
- 氨基酸结合部位：氨基酸臂 $-\mathrm{CCA}$ 末端腺苷酸的 $3'$-$\mathrm{OH}$。
- $\mathrm{mRNA}$ 结合部位：反密码环中的反密码子。
:::

:::definition{label="氨酰 tRNA"}
氨酰 $\mathrm{tRNA}$（aminoacyl-tRNA）：氨基酸与相应 $\mathrm{tRNA}$ 结合后的产物，再被运到核糖体。挂载反应的酶、耗能和校对是第二节「氨基酸活化」的账，本节只立「必须先形成氨酰 $\mathrm{tRNA}$」这一句。
:::

:::insight{label="图16-2 同时展示两个部位"}
上端 $3'$ 挂异亮氨酸，就是氨基酸臂；下端反密码环对准 $\mathrm{mRNA}$，就是 $\mathrm{mRNA}$ 结合部位。同一张图既讲摆动，也讲接头如何把氨基酸和密码子连在一起。
:::

:::pitfall{label="氨基酸不是结合在反密码子上"}
反密码子只认 $\mathrm{mRNA}$。氨基酸的共价连接在 $3'$-$\mathrm{CCA}$ 的腺苷酸羟基上。画成「氨基酸贴在三个碱基上」，氨酰化反应式和校对活性都没有底物位点。
:::

:::pitfall{label="本节写 3′-OH，第二节会补充 2′ 或 3′"}
本节功能部位写的是氨基酸臂末端腺苷酸 $3'$-$\mathrm{OH}$。第二节氨酰 $\mathrm{tRNA}$ 合成酶催化时，酯键可以连在核糖 $2'$ 或 $3'$ 位游离羟基。两处不打架：功能叙述取 $3'$，化学反应允许 $2'/3'$。
:::

:::keypoint{label="接头模型三句话"}
- 氨基酸不直接认密码子。
- $\mathrm{tRNA}$ 用反密码子认密码子。
- 氨基酸必须先成为氨酰 $\mathrm{tRNA}$ 才能进核糖体。
:::

## 三、核糖体是蛋白质合成的场所

### （一）核糖体是细胞蛋白质初始合成的主要场所

游离核糖体与附着核糖体均可以合成蛋白质。蛋白质的初始合成从合成肽链开始。合成肽链时 $\mathrm{mRNA}$ 与 $\mathrm{tRNA}$ 的相互识别、肽键形成、肽链延长等过程全部在核糖体上完成。核糖体类似于一个移动的多肽链「装配厂」，沿着模板 $\mathrm{mRNA}$ 链从 $5'$ 端向 $3'$ 端移动。在此期间，携带着各种氨基酸的 $\mathrm{tRNA}$ 分子依据密码子与反密码子配对关系快速进出其中，为延长肽链提供氨基酸原料。肽链合成完毕，核糖体立刻离开 $\mathrm{mRNA}$ 分子。

:::definition{label="核糖体是装配厂"}
游离核糖体与附着核糖体均可合成蛋白质。$\mathrm{mRNA}$ 与 $\mathrm{tRNA}$ 相互识别、肽键形成、肽链延长全部在核糖体上完成。核糖体沿 $\mathrm{mRNA}$ $5'\rightarrow 3'$ 移动；合成完毕立刻离开。
:::

:::definition{label="初始合成从肽链开始"}
蛋白质的初始合成从合成肽链开始。核糖体交出的是多肽链；有活性的成熟蛋白质还要第三节的加工与靶向。
:::

:::insight{label="游离与附着都能合成，差别不在能不能成肽"}
本节不区分两类核糖体的产物去向（分泌蛋白、膜蛋白多在附着核糖体上继续走靶向，是第三节）。这里只强调：两类都是肽链装配场所。
:::

:::pitfall{label="核糖体移动方向不要写成 3′→5′"}
与密码方向性一致：沿模板 $\mathrm{mRNA}$ 从 $5'$ 端向 $3'$ 端。图16-3 底部箭头「核糖体移动方向」指向 $\mathrm{mRNA}$ 的 $3'$。
:::

原核生物和真核生物的核糖体上均存在 $\mathrm{A}$ 位、$\mathrm{P}$ 位和 $\mathrm{E}$ 位这 $3$ 个重要的功能部位。$\mathrm{A}$ 位结合氨酰 $\mathrm{tRNA}$，称氨酰位（aminoacyl site）；$\mathrm{P}$ 位结合肽酰-$\mathrm{tRNA}$，称肽酰位（peptidyl site）；$\mathrm{E}$ 位释放已经卸载了氨基酸的 $\mathrm{tRNA}$，称排出位（exit site）（图16-3）。

:::definition{label="A 位（氨酰位）"}
$\mathrm{A}$ 位（aminoacyl site）结合氨酰 $\mathrm{tRNA}$。延长时新的氨酰 $\mathrm{tRNA}$ 先进入这里。起始时 $\mathrm{A}$ 位空留（或被 $\mathrm{IF}1$ 占据），起始氨酰 $\mathrm{tRNA}$ 不进 $\mathrm{A}$ 位。
:::

:::definition{label="P 位（肽酰位）"}
$\mathrm{P}$ 位（peptidyl site）结合肽酰-$\mathrm{tRNA}$。起始氨酰 $\mathrm{tRNA}$ 直接结合于 $\mathrm{P}$ 位；成肽后肽酰-$\mathrm{tRNA}$ 经转位从 $\mathrm{A}$ 位移到 $\mathrm{P}$ 位。
:::

:::definition{label="E 位（排出位）"}
$\mathrm{E}$ 位（exit site）释放已经卸载了氨基酸的 $\mathrm{tRNA}$。空载 $\mathrm{tRNA}$ 经 $\mathrm{E}$ 位离开核糖体。
:::

::figure{src="/images/biochemistry/textbook/p0329_01.png" caption="图16-3　核糖体在翻译中的功能部位。mRNA 5′→3′ 穿过 E、P、A 三位：E 位空载 tRNA（反密码子 CCC 对密码子 GGG）；P 位肽酰-tRNA（AAA 对 UUU）连着延伸中的多肽链，N 端为 NH3+，上方为转肽酶中心；A 位氨酰-tRNA（UCG 对 AGC）。底部箭头标核糖体向 mRNA 3′ 端移动。" alt="核糖体剖面：E 位空载 tRNA、P 位肽酰 tRNA 连多肽、A 位氨酰 tRNA，转肽酶中心在 P/A 上方"}

:::insight{label="图16-3 三位从 5′ 到 3′ 正好是 E、P、A"}
$\mathrm{mRNA}$ 左侧 $5'$、右侧 $3'$。先经过 $\mathrm{E}$ 位，再 $\mathrm{P}$ 位，最后 $\mathrm{A}$ 位——与「核糖体向 $3'$ 移动、新的密码子在 $\mathrm{A}$ 位被阅读」一致。多肽链从 $\mathrm{P}$ 位 $\mathrm{tRNA}$ 向上长出，$\mathrm{N}$ 端 $\mathrm{NH}_3^{+}$ 在最远端，符合方向性：先合成的是 $\mathrm{N}$ 端。
:::

:::keypoint{label="图16-3 三位上的密码子"}
- $\mathrm{E}$：密码子 $\mathrm{GGG}$，空载 $\mathrm{tRNA}$ 反密码子 $\mathrm{CCC}$（已卸氨基酸）。
- $\mathrm{P}$：密码子 $\mathrm{UUU}$，肽酰-$\mathrm{tRNA}$ 反密码子 $\mathrm{AAA}$，连着延伸中的多肽。
- $\mathrm{A}$：密码子 $\mathrm{AGC}$，氨酰-$\mathrm{tRNA}$ 反密码子按反向平行写成 $\mathrm{UCG}$。
- 转肽酶中心画在 $\mathrm{P}$ 位与 $\mathrm{A}$ 位上方，成肽在大亚基这一侧发生（酶的化学本质是第二节的 $23\mathrm{S}/28\mathrm{S}$ $\mathrm{rRNA}$）。
:::

:::compare{title="A、P、E 各留什么"}
| 部位 | 英文 | 结合／释放 | 延长循环里的角色 |
|------|------|------------|------------------|
| $\mathrm{A}$ | aminoacyl site | 氨酰 $\mathrm{tRNA}$ | 进位入口 |
| $\mathrm{P}$ | peptidyl site | 肽酰-$\mathrm{tRNA}$ | 成肽后肽链所在 |
| $\mathrm{E}$ | exit site | 空载 $\mathrm{tRNA}$ | 排出 |

三位原核、真核都有。线粒体核糖体是下一小节的另一套。
:::

:::pitfall{label="起始氨酰 tRNA 不进 A 位"}
图16-3 画的是延长中的核糖体：$\mathrm{A}$ 位已有氨酰-$\mathrm{tRNA}$。装配起始复合物时，$\mathrm{fMet}$-$\mathrm{tRNA}^{\mathrm{fMet}}$ 直接进 $\mathrm{P}$ 位，$\mathrm{A}$ 位空着对准第二个密码子。用这张图去答「起始」，会把 $\mathrm{IF}1$ 占据 $\mathrm{A}$ 位那一步写丢。
:::

:::pitfall{label="E 位不是肽链出口"}
$\mathrm{E}$ 是 exit site，排出的是空载 $\mathrm{tRNA}$。新生肽链从大亚基的肽酰转移酶中心长出（图16-3 向上的珠串），不是从 $\mathrm{E}$ 位钻出去。
:::

### （二）线粒体核糖体主要负责线粒体内的蛋白质合成

线粒体核糖体（mitoribosomes）在线粒体内进行蛋白质合成，哺乳动物线粒体核糖体 $55\mathrm{S}$ 包含了 $39\mathrm{S}$ 和 $28\mathrm{S}$ 大小两个亚基，共有 $82$ 个蛋白质，其中 $36$ 个是线粒体特异性的，大亚基包含了 $22$ 个，小亚基包含了 $14$ 个。由于线粒体核糖体中的 $\mathrm{rRNA}$ 比例是显著低于游离核糖体和附着核糖体的，因此这些特异性的蛋白质则可代替 $\mathrm{rRNA}$ 的功能，不仅在维持线粒体核糖体的结构上发挥重要作用，而且具备 $\mathrm{mRNA}$ 识别、引导 $\mathrm{tRNA}$ 的进入等功能。线粒体内的翻译仅限于由线粒体核糖体合成的氧化磷酸化复合物的几个关键亚基。因此，线粒体核糖体负责完成线粒体内的蛋白合成。

:::definition{label="线粒体核糖体"}
线粒体核糖体（mitoribosomes）在线粒体内合成蛋白质。哺乳动物为 $55\mathrm{S}$，大亚基 $39\mathrm{S}$、小亚基 $28\mathrm{S}$。
:::

:::definition{label="55S 的蛋白质组成"}
共 $82$ 个蛋白质，其中 $36$ 个线粒体特异性：$22$ 个在大亚基，$14$ 个在小亚基。
:::

:::definition{label="特异性蛋白质代替部分 rRNA 功能"}
线粒体核糖体的 $\mathrm{rRNA}$ 比例显著低于游离核糖体和附着核糖体。特异性蛋白质不仅维持结构，还具备 $\mathrm{mRNA}$ 识别、引导 $\mathrm{tRNA}$ 进入等功能。
:::

:::definition{label="线粒体翻译的范围"}
仅限于氧化磷酸化复合物的几个关键亚基。线粒体核糖体负责完成线粒体内的蛋白合成，不是细胞质蛋白质的另一条通用生产线。
:::

:::compare{title="细胞质核糖体 vs 哺乳动物线粒体核糖体"}
| | 游离／附着核糖体 | 哺乳动物线粒体核糖体 |
|--|-------------------|------------------------|
| 场所 | 细胞质（附着者在粗面内质网） | 线粒体内 |
| 沉降 | 原核 $70\mathrm{S}$、真核 $80\mathrm{S}$（本章用 $\mathrm{A}/\mathrm{P}/\mathrm{E}$ 叙述，不在此表重开亚基账） | $55\mathrm{S}$（$39\mathrm{S}+28\mathrm{S}$） |
| $\mathrm{rRNA}$ 比例 | 相对高 | 显著偏低，蛋白质代偿 |
| 产物范围 | 细胞蛋白质初始合成的主要场所 | 氧化磷酸化复合物的几个关键亚基 |
| 密码 | 表16-1 通用密码 | $\mathrm{UGA}$、$\mathrm{AUA}$ 等例外 |

两套体系不要共用同一张密码子表和同一套 $\mathrm{IF}$。
:::

:::pitfall{label="55S 不要记成 70S 或 80S 的别名"}
$39\mathrm{S}+28\mathrm{S}=55\mathrm{S}$ 是线粒体这套数字。写成「线粒体也是 $70\mathrm{S}$ 所以按原核翻译」，密码例外和 $82$ 个蛋白质都会对不上。
:::

:::pitfall{label="36 个特异性蛋白质不要写成 82 个全是线粒体特有"}
$82$ 个蛋白质里 $36$ 个是线粒体特异性的。大亚基 $22$、小亚基 $14$，相加必须是 $36$。
:::

:::insight{label="rRNA 少、蛋白质补，是结构事实不是「没有 rRNA」"}
教材说比例显著低于，特异性蛋白质「代替 $\mathrm{rRNA}$ 的功能」。肽酰转移酶在细胞质里是 $\mathrm{rRNA}$（第二节核酶），线粒体这套的催化细节教材未在本节展开，不要据此断言线粒体成肽不需要 $\mathrm{RNA}$。
:::

## 四、蛋白质合成需要多种酶类和蛋白质因子

蛋白质合成需要由 $\mathrm{ATP}$ 或 $\mathrm{GTP}$ 供能，需要 $\mathrm{Mg}^{2+}$、肽酰转移酶、氨酰 $\mathrm{tRNA}$ 合成酶等多种分子参与反应。此外，起始、延长及终止各阶段还需要多种因子参与：①起始因子（initiation factor，$\mathrm{IF}$），原核生物和真核生物的起始因子分别以 $\mathrm{IF}$ 和 $\mathrm{eIF}$ 表示；②延长因子（elongation factor，$\mathrm{EF}$），原核生物与真核生物的延长因子分别以 $\mathrm{EF}$ 和 $\mathrm{eEF}$ 表示；③终止因子（termination factor），又称释放因子（release factor，$\mathrm{RF}$），原核生物与真核生物的释放因子分别以 $\mathrm{RF}$ 和 $\mathrm{eRF}$ 表示。各类因子的种类及其生物学功能见表16-2（原核生物）及表16-3（真核生物）。

:::definition{label="合成体系里的酶和离子"}
需要 $\mathrm{ATP}$ 或 $\mathrm{GTP}$ 供能；需要 $\mathrm{Mg}^{2+}$；酶类包括肽酰转移酶、氨酰 $\mathrm{tRNA}$ 合成酶等。氨酰化机制和肽酰转移酶是核酶，细节在第二节。
:::

:::definition{label="三类蛋白质因子的命名"}
起始因子 $\mathrm{IF}$（真核 $\mathrm{eIF}$）；延长因子 $\mathrm{EF}$（真核 $\mathrm{eEF}$）；终止因子又称释放因子 $\mathrm{RF}$（真核 $\mathrm{eRF}$）。前缀 $\mathrm{e}$ 只表示真核，不要另造一套功能分类。
:::

:::pitfall{label="IF 不是 eIF 的简称"}
原核写 $\mathrm{IF}1/2/3$，真核写 $\mathrm{eIF}1$、$\mathrm{eIF}2$、$\mathrm{eIF}4\mathrm{F}$ 等。把真核帽结合说成 $\mathrm{IF}4\mathrm{E}$，表16-3 对不上。
:::

:::pitfall{label="终止因子和释放因子是同一类"}
教材：终止因子（termination factor）又称释放因子（release factor，$\mathrm{RF}$）。不要答成两种不同的蛋白质。
:::

**表16-2　原核生物肽链合成所需要的蛋白质因子**

| 种类 | 因子 | 生物学功能 |
|------|------|------------|
| 起始因子 | $\mathrm{IF}1$ | 占据核糖体 $\mathrm{A}$ 位，防止 $\mathrm{tRNA}$ 过早结合于 $\mathrm{A}$ 位 |
| 起始因子 | $\mathrm{IF}2$ | 促进 $\mathrm{fMet}$-$\mathrm{tRNA}^{\mathrm{fMet}}$ 与小亚基结合 |
| 起始因子 | $\mathrm{IF}3$ | 防止大、小亚基过早结合；增强 $\mathrm{P}$ 位结合 $\mathrm{fMet}$-$\mathrm{tRNA}^{\mathrm{fMet}}$ 的特异性 |
| 延长因子 | $\mathrm{EF}$-$\mathrm{Tu}$ | 促进氨酰 $\mathrm{tRNA}$ 进入 $\mathrm{A}$ 位，结合并分解 $\mathrm{GTP}$ |
| 延长因子 | $\mathrm{EF}$-$\mathrm{Ts}$ | $\mathrm{EF}$-$\mathrm{Tu}$ 的调节亚基 |
| 延长因子 | $\mathrm{EF}$-$\mathrm{G}$ | 有转位酶活性，促进 $\mathrm{mRNA}$-肽酰-$\mathrm{tRNA}$ 由 $\mathrm{A}$ 位移至 $\mathrm{P}$ 位；促进 $\mathrm{tRNA}$ 卸载与释放 |
| 释放因子 | $\mathrm{RF}1$ | 特异识别终止密码 $\mathrm{UAA}$ 或 $\mathrm{UAG}$；诱导肽酰转移酶转变为酯酶 |
| 释放因子 | $\mathrm{RF}2$ | 特异识别终止密码 $\mathrm{UAA}$ 或 $\mathrm{UGA}$；诱导肽酰转移酶转变为酯酶 |
| 释放因子 | $\mathrm{RF}3$ | 具有 $\mathrm{GTPase}$ 活性，当新合成肽链从核糖体释放后，促进 $\mathrm{RF}1$ 或 $\mathrm{RF}2$ 与核糖体分离 |

:::definition{label="原核三种 IF"}
$\mathrm{IF}1$ 堵 $\mathrm{A}$ 位；$\mathrm{IF}2$ 送 $\mathrm{fMet}$-$\mathrm{tRNA}^{\mathrm{fMet}}$；$\mathrm{IF}3$ 保持亚基分离并让 $\mathrm{P}$ 位认起始 $\mathrm{tRNA}$ 更准。三条都是为起始复合物服务，延长时要释放。
:::

:::definition{label="原核三种 EF"}
$\mathrm{EF}$-$\mathrm{Tu}$ 送氨酰 $\mathrm{tRNA}$ 进 $\mathrm{A}$ 位并水解 $\mathrm{GTP}$；$\mathrm{EF}$-$\mathrm{Ts}$ 是 $\mathrm{EF}$-$\mathrm{Tu}$ 的调节亚基；$\mathrm{EF}$-$\mathrm{G}$ 是转位酶，把肽酰-$\mathrm{tRNA}$ 从 $\mathrm{A}$ 位移到 $\mathrm{P}$ 位，并促进空载 $\mathrm{tRNA}$ 卸载释放。
:::

:::definition{label="原核三种 RF 认终止密码子的分工"}
$\mathrm{RF}1$：$\mathrm{UAA}$ 或 $\mathrm{UAG}$。$\mathrm{RF}2$：$\mathrm{UAA}$ 或 $\mathrm{UGA}$。二者都能诱导肽酰转移酶变为酯酶。$\mathrm{RF}3$ 是 $\mathrm{GTPase}$，肽链释放后让 $\mathrm{RF}1$ 或 $\mathrm{RF}2$ 离开。$\mathrm{UAA}$ 可被 $\mathrm{RF}1$ 或 $\mathrm{RF}2$ 识别。
:::

:::compare{title="RF1 vs RF2"}
| | $\mathrm{RF}1$ | $\mathrm{RF}2$ |
|--|---------------|---------------|
| $\mathrm{UAA}$ | 识别 | 识别 |
| $\mathrm{UAG}$ | 识别 | 否 |
| $\mathrm{UGA}$ | 否 | 识别 |
| 共同 | 诱导肽酰转移酶 $\rightarrow$ 酯酶 | 同左 |

只记住「三个终止密码子三种 $\mathrm{RF}$」会把 $\mathrm{UAA}$ 的共享和 $\mathrm{RF}3$ 不认密码子这两点写错。
:::

:::pitfall{label="EF-G 不要写成进位因子"}
进位是 $\mathrm{EF}$-$\mathrm{Tu}$；转位是 $\mathrm{EF}$-$\mathrm{G}$。对调之后，第二节「进位—成肽—转位」的 $\mathrm{GTP}$ 水解位点会全部错位。
:::

:::pitfall{label="IF2 送的是 fMet-tRNA，不是任意甲硫氨酰 tRNA"}
原核起始 $\mathrm{tRNA}$ 的甲硫氨酸已被甲酰化。内部 $\mathrm{AUG}$ 用的 $\mathrm{Met}$-$\mathrm{tRNA}^{\mathrm{Met}}$ 走延长通路，不走 $\mathrm{IF}2$。
:::

| 种类 | 因子 | 生物学功能 |
|------|------|------------|
| 起始因子 | $\mathrm{eIF}1$ | 结合于小亚基的 $\mathrm{E}$ 位，促进 $\mathrm{eIF}2$-$\mathrm{tRNA}$-$\mathrm{GTP}$ 复合物与小亚基相互作用 |
| 起始因子 | $\mathrm{eIF}1\mathrm{A}$ | 原核 $\mathrm{IF}1$ 的同源物，防止 $\mathrm{tRNA}$ 过早结合于 $\mathrm{A}$ 位 |
| 起始因子 | $\mathrm{eIF}2$ | 具有 $\mathrm{GTPase}$ 活性，促进起始 $\mathrm{Met}$-$\mathrm{tRNA}^{\mathrm{Met}}$ 与小亚基结合 |
| 起始因子 | $\mathrm{eIF}2\mathrm{B}$，$\mathrm{eIF}3$ | 最先与小亚基结合的起始因子；促进后续步骤的进行 |
| 起始因子 | $\mathrm{eIF}4\mathrm{A}$ | $\mathrm{eIF}4\mathrm{F}$ 复合物成分，具有 $\mathrm{RNA}$ 解旋酶活性，解开 $\mathrm{mRNA}$ 二级结构，使其与小亚基结合 |
| 起始因子 | $\mathrm{eIF}4\mathrm{B}$ | 结合 $\mathrm{mRNA}$，促进 $\mathrm{mRNA}$ 扫描定位起始密码 $\mathrm{AUG}$ |
| 起始因子 | $\mathrm{eIF}4\mathrm{E}$ | $\mathrm{eIF}4\mathrm{F}$ 复合物成分，结合于 $\mathrm{mRNA}$ 的 $5'$ 帽结构 |
| 起始因子 | $\mathrm{eIF}4\mathrm{G}$ | $\mathrm{eIF}4\mathrm{F}$ 复合物成分，结合 $\mathrm{eIF}4\mathrm{E}$ 和 $\mathrm{poly}(\mathrm{A})$ 结合蛋白质（$\mathrm{PABP}$） |
| 起始因子 | $\mathrm{eIF}4\mathrm{F}$ | 包含 $\mathrm{eIF}4\mathrm{A}$、$\mathrm{eIF}4\mathrm{E}$、$\mathrm{eIF}4\mathrm{G}$ 的复合物 |

| 起始因子 | $\mathrm{eIF}5\mathrm{B}$ | 具有 $\mathrm{GTPase}$ 活性，促进各种起始因子从小亚基解离，从而使大、小亚基结合 |

:::definition{label="eIF4F 三组分"}
$\mathrm{eIF}4\mathrm{F}=\mathrm{eIF}4\mathrm{A}+\mathrm{eIF}4\mathrm{E}+\mathrm{eIF}4\mathrm{G}$。$\mathrm{eIF}4\mathrm{E}$ 认 $5'$ 帽；$\mathrm{eIF}4\mathrm{A}$ 是 $\mathrm{RNA}$ 解旋酶；$\mathrm{eIF}4\mathrm{G}$ 搭桥结合 $\mathrm{eIF}4\mathrm{E}$ 和 $\mathrm{PABP}$。帽和多聚 $\mathrm{A}$ 尾都进入起始，是第二节真核装配的分子基础。
:::

:::definition{label="真核延长因子与原核一一对应"}
$\mathrm{eEF}1\alpha\sim\mathrm{EF}$-$\mathrm{Tu}$（进位）；$\mathrm{eEF}1\beta\gamma\sim\mathrm{EF}$-$\mathrm{Ts}$（调节 $\mathrm{Tu}$ 一侧）；$\mathrm{eEF}2\sim\mathrm{EF}$-$\mathrm{G}$（转位）。功能对应，名称不要混用。
:::

:::definition{label="真核只有一种 eRF"}
$\mathrm{eRF}$ 识别所有终止密码子。不要把原核 $\mathrm{RF}1/\mathrm{RF}2$ 的分工抄到真核。
:::

:::compare{title="原核 IF1/2/3 在真核的同源关系（教材写明的）"}
| 原核 | 真核 | 教材给出的对应 |
|------|------|----------------|
| $\mathrm{IF}1$ | $\mathrm{eIF}1\mathrm{A}$ | 同源物，防 $\mathrm{tRNA}$ 过早进 $\mathrm{A}$ 位 |
| $\mathrm{IF}2$ | $\mathrm{eIF}5\mathrm{B}$（第二节还写 $\mathrm{eIF}2$ 送起始 $\mathrm{tRNA}$） | 表16-3：$\mathrm{eIF}2$ 促进起始 $\mathrm{Met}$-$\mathrm{tRNA}$ 结合；第二节：$\mathrm{eIF}5\mathrm{B}$ 是原核 $\mathrm{IF}2$ 的同源物 |
| $\mathrm{IF}3$ | $\mathrm{eIF}3$（第二节与 $\mathrm{eIF}1\mathrm{A}$ 一并对照） | 防大、小亚基过早结合 |

表16-3 与第二节叙述互补，不要在本节把同源关系答成「名字数字相同就一对一」。
:::

:::insight{label="eIF1 在 E 位，eIF1A 在 A 位"}
真核小亚基上：$\mathrm{eIF}1$ 结合 $\mathrm{E}$ 位，促进 $\mathrm{eIF}2$-$\mathrm{tRNA}$-$\mathrm{GTP}$ 与小亚基相互作用；$\mathrm{eIF}1\mathrm{A}$ 防 $\mathrm{A}$ 位过早结合 $\mathrm{tRNA}$。两位同时被因子占着，起始 $\mathrm{tRNA}$ 才能正确落到 $\mathrm{P}$ 位——与原核 $\mathrm{IF}1$ 占 $\mathrm{A}$ 位是同一逻辑。
:::

:::pitfall{label="eIF4E 不是解旋酶"}
认帽的是 $\mathrm{eIF}4\mathrm{E}$；解旋的是 $\mathrm{eIF}4\mathrm{A}$。对调后，$5'$ 帽依赖起始和扫描解开二级结构会并成一步。
:::

:::pitfall{label="eIF4F 不要漏掉 eIF4G"}
三组分缺 $\mathrm{eIF}4\mathrm{G}$，$\mathrm{PABP}$ 和帽结合就连不上，第二节「$5'$ 帽和 $3'$ 多聚 $\mathrm{A}$ 尾均为正确起始所必需」没有桥梁。
:::

:::keypoint{label="表16-2、表16-3 考试先问这几对"}
- 占 $\mathrm{A}$ 位：原核 $\mathrm{IF}1$，真核 $\mathrm{eIF}1\mathrm{A}$。
- 送起始 $\mathrm{tRNA}$：原核 $\mathrm{IF}2$，真核 $\mathrm{eIF}2$。
- 进位：$\mathrm{EF}$-$\mathrm{Tu}$／$\mathrm{eEF}1\alpha$。
- 转位：$\mathrm{EF}$-$\mathrm{G}$／$\mathrm{eEF}2$。
- 终止：原核 $\mathrm{RF}1+\mathrm{RF}2+\mathrm{RF}3$，真核一种 $\mathrm{eRF}$。
:::

:::memory{label="本节体系一张清单"}
- 密码：$64=61+3$，$\mathrm{AUG}$ 兼起始；五特点；移码是非 $3$ 倍数插入／缺失。
- $\mathrm{tRNA}$：一种 $\mathrm{tRNA}$ 一种氨基酸；$3'$-$\mathrm{CCA}$ 挂氨基酸，反密码子认密码子。
- 核糖体：沿 $\mathrm{mRNA}$ $5'\rightarrow 3'$；$\mathrm{A}$ 氨酰、$\mathrm{P}$ 肽酰、$\mathrm{E}$ 排出；线粒体 $55\mathrm{S}$。
- 因子：原核 $\mathrm{IF}/\mathrm{EF}/\mathrm{RF}$，真核加 $\mathrm{e}$；供能 $\mathrm{ATP}$ 或 $\mathrm{GTP}$，还要 $\mathrm{Mg}^{2+}$。
:::

:::memory{label="摆动三对不要背反"}
反密码子第 $1$ 位 $\rightarrow$ 密码子第 $3$ 位：$\mathrm{I}$ 对 $\mathrm{A}/\mathrm{C}/\mathrm{U}$；$\mathrm{U}$ 对 $\mathrm{A}/\mathrm{G}$；$\mathrm{G}$ 对 $\mathrm{C}/\mathrm{U}$。图16-2 的异亮氨酸密码子是 $\mathrm{AU}(\mathrm{C}/\mathrm{U})$。
:::
