# 第四节　骨骼肌的生物化学

第三节把肾写成滤过加重吸收、空腹可糖异生和生酮，内分泌三条是 $\mathrm{EPO}$、肾素／$\mathrm{RAAS}$ 和 $1,25\textrm{-}(\mathrm{OH})_{2}\textrm{-}\mathrm{D}_{3}$。本节只立「骨骼肌的生物化学」：约占体重 $40\%$；燃料来自肌糖原、血糖、肌内和脂肪组织甘油三酯；随运动时间，主要 $\mathrm{ATP}$ 来源从磷酸原系统转到糖无氧氧化、糖有氧氧化，再转到脂肪有氧氧化。心肌「代谢杂食者」是第二节的名字，不要写进本节。瘦素和弓状核是第五节。

:::concept{term="先问运动时间轴上谁在供 ATP，再问 AMP 怎么调、肌肉因子怎么对外说话"}
看见「骨骼肌的生物化学」，先不要默写心肌的脂肪酸 $40\%\sim 60\%$。户头是：骨骼肌是正常成人含量最多的器官；静息以肌糖原、脂肪酸、酮体有氧氧化为主；运动时按时间和强度改分解代谢。图27-8 的横轴是运动时间：磷酸原 → 糖无氧 → 糖有氧 → 脂肪有氧。把「骨骼肌＝心肌」或「一直靠糖酵解」写成开篇，后文 $\mathrm{AMPK}$、$\mathrm{IMTG}$ 和肌肉因子都没有底板。
:::

骨骼肌是正常成人含量最多的器官，约占身体总质量的 $40\%$。生理学上骨骼肌纤维可分为慢肌纤维和快肌纤维两种，不同类型的骨骼肌具有不同代谢特征。骨骼肌组织的主要能量物质来源于细胞内储存的肌糖原、血糖、骨骼肌和脂肪组织储存的甘油三酯。静息状态下主要从肌糖原有氧氧化、脂肪酸氧化和酮体氧化获取能量；人体运动状态下肌组织对能量的不同需求是通过改变分解代谢途径实现的，剧烈运动时糖无氧氧化供能则大大增加，长时间运动时脂肪酸氧化供能增多。运动可以通过调节代谢预防肥胖和糖尿病。

:::definition{label="骨骼肌约占体重 40%"}
正常成人含量最多的器官。户头先落在「体量大」，和心肌只占 $0.5\%$、脑约占 $2\%$ 不是同一把尺子。
:::

:::definition{label="主要能量物质三来源"}
细胞内储存的肌糖原、血糖、骨骼肌和脂肪组织储存的甘油三酯。小结还加了一句「骨骼肌的脂肪酸」。不要写成「只吃血糖」。
:::

:::definition{label="静息 vs 运动的燃料切换"}
静息：肌糖原有氧氧化、脂肪酸氧化、酮体氧化。剧烈运动：糖无氧氧化大大增加。长时间运动：脂肪酸氧化供能增多。切换靠改分解代谢途径，不是另造一套 $\mathrm{ATP}$。
:::

:::keypoint{label="开篇四句"}
- 体量：约 $40\%$。
- 纤维：慢肌／快肌，代谢特征不同。
- 时间轴：磷酸原 → 糖无氧 → 糖有氧 → 脂肪有氧（图27-8）。
- 功能外账：运动调节代谢，预防肥胖和糖尿病；骨骼肌还分泌肌肉因子。
:::

:::pitfall{label="不要把心肌的代谢杂食者写进骨骼肌"}
「代谢杂食者」是第二节给成人心肌的名字：脂肪酸 $40\%\sim 60\%$、葡萄糖约 $20\%\sim 40\%$、酮体 $10\%\sim 15\%$、氨基酸 $1\%\sim 2\%$。骨骼肌也可以用多种底物，但本版用「多种能量来源」和运动时间轴来立户，不套这个名字。
:::

:::compare{title="脑、心肌、骨骼肌开篇不要并"}
| | 本版开篇 | 本节不要写成 |
|--|---------|-------------|
| 脑 | 主要葡萄糖和酮体；日耗约 $100\,\mathrm{g}$ 葡萄糖 | 「骨骼肌也主要靠酮体」 |
| 心肌 | 代谢杂食者；质量 $0.5\%$，耗氧 $10\%$ | 「骨骼肌 $95\%$ $\mathrm{ATP}$ 来自氧化磷酸化、不能无氧」 |
| 骨骼肌 | 约 $40\%$ 体重；运动可把无氧糖氧化抬起来 | 「骨骼肌静息也主要靠无氧酵解」 |

问「百米冲刺靠什么」走本节磷酸原和糖无氧；问「心脏高负荷氧从哪来」回第二节冠脉流量。
:::

## 一、骨骼肌利用多种能量来源产生 ATP 供能

骨骼肌收缩所需能量的直接来源是 $\mathrm{ATP}$，但其细胞中 $\mathrm{ATP}$ 含量有限，不足以维持持续剧烈的收缩。骨骼肌有一定糖原储备，静息状态下肌组织获取能量通常以有氧氧化肌糖原、脂肪酸、酮体为主。短暂的骨骼肌收缩后，储存于肌内的高能物质肌酸磷酸在肌酸激酶催化下开始分解，生成 $\mathrm{ATP}$。在不同运动状态下，骨骼肌的不同能量物质的供能比例会发生转变。

:::definition{label="直接能源是 ATP，储量不够用"}
收缩直接消耗 $\mathrm{ATP}$，但细胞内 $\mathrm{ATP}$ 含量有限，撑不住持续剧烈收缩。后面磷酸原、糖无氧、有氧氧化都是为了再生 $\mathrm{ATP}$。
:::

:::definition{label="静息以有氧氧化肌糖原、脂肪酸、酮体为主"}
有糖原储备，但静息不靠无氧酵解过日子。短暂收缩后，肌酸磷酸经肌酸激酶分解生成 $\mathrm{ATP}$。
:::

:::insight{label="肌酸磷酸在心肌节已经出现过，角色不同"}
第二节肌酸磷酸是心衰早期就下降 $50\%\sim 70\%$ 的储备，用来解释 $\mathrm{PCr}/\mathrm{ATP}$。本节肌酸磷酸是运动最初几秒到几十秒的磷酸原。分子相同，问的是「短时再生 $\mathrm{ATP}$」，不是心衰能量危机。
:::

### （一）不同类型的骨骼肌具有不同代谢特征

生理学上肌纤维可分为红色或慢肌纤维和白色或快肌纤维两种。慢肌纤维适应长时间的工作，非常耐受疲劳，富含氧亲和力高的肌红蛋白，并有大量血管的分布，使红色肌有特征性的红色。快肌纤维适应低氧工作，含有相对较少的线粒体和血管分布，收缩快速而有力，但会迅速发生疲劳。

:::definition{label="慢肌纤维是红肌"}
适应长时间工作，非常耐疲劳。富含氧亲和力高的肌红蛋白，血管丰富，所以呈红色。颜色来自肌红蛋白和血供，不是「染了别的色素」。
:::

:::definition{label="快肌纤维是白肌"}
适应低氧工作，线粒体和血管相对较少，收缩快速有力，迅速疲劳。白色是肌红蛋白和血供都少，不是「没有代谢」。
:::

不同骨骼肌的肌球蛋白重链亚型不同，慢肌纤维主要表达Ⅰ型肌球蛋白重链，也称为Ⅰ型肌纤维，而快肌纤维主要表达Ⅱa 型和Ⅱb 等型肌球蛋白重链而被称为Ⅱ型肌纤维。Ⅰ型和Ⅱ型肌纤维的收缩速度不同，Ⅱ型肌纤维分解 $\mathrm{ATP}$ 的速度较Ⅰ型肌纤维快，有发达的肌质网，在受到刺激时钙离子更容易进入肌细胞，收缩速度是Ⅰ型肌纤维的 $5\sim 6$ 倍，功率为Ⅰ型肌纤维的 $3\sim 5$ 倍。运动单位是指一个运动神经元及其所支配的所有肌纤维。Ⅰ型肌纤维内的运动神经元胞体较小，支配的肌纤维数不多于 $300$ 条，而Ⅱ型肌纤维内的运动神经元胞体较大，支配的肌纤维数不少于 $300$ 条。运动单位的大小不同，导致Ⅱ型肌纤维达到最大收缩力的速度快于Ⅰ型肌纤维，且产生的力量也较大。

:::definition{label="Ⅰ型表达Ⅰ型肌球蛋白重链，Ⅱ型表达 Ⅱa／Ⅱb"}
慢肌＝Ⅰ型；快肌＝Ⅱ型（Ⅱa、Ⅱb 等）。分型先落在肌球蛋白重链，再落到代谢。
:::

:::definition{label="Ⅱ型收缩更快、功率更大"}
分解 $\mathrm{ATP}$ 更快，肌质网发达，刺激时钙更容易进细胞。收缩速度是Ⅰ型的 $5\sim 6$ 倍，功率是Ⅰ型的 $3\sim 5$ 倍。
:::

:::definition{label="运动单位：一个运动神经元加它所支配的全部肌纤维"}
Ⅰ型：神经元胞体较小，支配不多于 $300$ 条肌纤维。Ⅱ型：胞体较大，支配不少于 $300$ 条。单位更大，达到最大收缩力更快、力量也更大。
:::

:::pitfall{label="不多于 300 和不少于 300 不要写反"}
Ⅰ型 $\leqslant 300$ 条，Ⅱ型 $\geqslant 300$ 条。写成「慢肌运动单位更大」，后面「Ⅱ型力量更大」就对不上。
:::

:::pitfall{label="5～6 倍是收缩速度，3～5 倍是功率"}
两笔倍数都是Ⅱ型相对Ⅰ型。不要写成「Ⅱ型 $\mathrm{ATP}$ 储量是Ⅰ型的 $5\sim 6$ 倍」。
:::

不同肌纤维通过不同的途径获得 $\mathrm{ATP}$。在Ⅰ型肌纤维中，氧化磷酸化是 $\mathrm{ATP}$ 合成的主要机制，脂肪酸是主要的代谢底物，也可以使用酮体、肌糖原和葡萄糖。在Ⅱ型肌纤维中，大部分合成的 $\mathrm{ATP}$ 来自糖酵解中的底物水平磷酸化，肌糖原是葡萄糖-$6$-磷酸的主要来源，并且乳酸是主要终产物。

:::definition{label="Ⅰ型主要靠氧化磷酸化，脂肪酸是主底物"}
也可以用酮体、肌糖原和葡萄糖。耐疲劳的底板是有氧氧化，不是「Ⅰ型不用糖」。
:::

:::definition{label="Ⅱ型大部分 ATP 来自糖酵解底物水平磷酸化"}
肌糖原是葡萄糖-$6$-磷酸的主要来源，乳酸是主要终产物。快速有力、迅速疲劳的底板在这里。
:::

:::compare{title="Ⅰ型 vs Ⅱ型"}
| | Ⅰ型（慢／红） | Ⅱ型（快／白） | 不要写成 |
|--|-------------|-------------|---------|
| 肌球蛋白重链 | Ⅰ型 | Ⅱa、Ⅱb 等 | 「颜色决定重链」 |
| 血供／肌红蛋白／线粒体 | 多，红，耐疲劳 | 少，白，易疲劳 | 「白肌没有线粒体」 |
| 收缩速度／功率 | 基准 | 速度 $5\sim 6$ 倍，功率 $3\sim 5$ 倍 | 「Ⅰ型更有爆发力」 |
| 运动单位 | 胞体小，$\leqslant 300$ 条 | 胞体大，$\geqslant 300$ 条 | 「慢肌单位更大」 |
| $\mathrm{ATP}$ 主路 | 氧化磷酸化；脂肪酸为主，也可用酮体、糖原、葡萄糖 | 糖酵解底物水平磷酸化；肌糖原 → 乳酸 | 「Ⅰ型只吃脂肪、Ⅱ型只吃血糖」 |

后文肌肉因子 $\mathrm{IL}$-$6$ 在Ⅰ型肌纤维中高表达，分型在这里先立住。
:::

### （二）骨骼肌中有多个 ATP 合成途径来供能

$\mathrm{ATP}$ 主要用于骨骼肌收缩过程中所需要的神经冲动传递、离子稳态维持以及机械能的消耗。其中，①肌球蛋白 $\mathrm{ATP}$ 酶活性提供机械能，直接参与收缩；②$\mathrm{Na}^{+}/\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶维持 $\mathrm{Na}^{+}$ 和 $\mathrm{K}^{+}$ 梯度，使神经冲动传递停止后膜电位得以恢复；③肌质网 $\mathrm{Ca}^{2+}$-$\mathrm{ATP}$ 酶负责将 $\mathrm{Ca}^{2+}$ 逆浓度梯度从肌浆泵入肌质网内腔。

:::definition{label="ATP 的三个去向"}
肌球蛋白 $\mathrm{ATP}$ 酶：机械能，直接收缩。$\mathrm{Na}^{+}/\mathrm{K}^{+}$-$\mathrm{ATP}$ 酶：恢复膜电位。肌质网 $\mathrm{Ca}^{2+}$-$\mathrm{ATP}$ 酶：把钙泵回肌质网。三户都要 $\mathrm{ATP}$，不是只有横桥。
:::

:::compare{title="离子泵：脑、心肌、骨骼肌各记各的"}
| | 教材点名的泵 | 不要写成 |
|--|------------|---------|
| 脑 | $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-$\mathrm{ATPase}$ 约占葡萄糖氧化产能 $50\%$ | 「骨骼肌也是钠钾泵占一半」 |
| 心肌 | 机械力拿走 $60\%\sim 70\%$，其余主要给肌浆网 $\mathrm{Ca}^{2+}$-$\mathrm{ATPase}$ | 「骨骼肌 $60\%\sim 70\%$ 给钙泵」 |
| 骨骼肌 | 肌球蛋白 $\mathrm{ATP}$ 酶、钠钾泵、肌质网钙泵三户并列 | 「只有横桥耗 ATP」 |

本节没有把三户写成百分数，不要把第一、二节的百分数搬过来。
:::

骨骼肌中 $\mathrm{ATP}$ 的生成主要有 3 个来源。①磷酸原系统，其中肌酸激酶降解肌酸磷酸，催化 $\mathrm{ADP}$ 快速生成 $\mathrm{ATP}$。此外，腺苷酸激酶催化两个 $\mathrm{ADP}$ 分子生成 $\mathrm{ATP}$ 和 $\mathrm{AMP}$，$\mathrm{AMP}$ 再脱氨生成次黄嘌呤核苷酸 $\mathrm{IMP}$；②葡萄糖的无氧氧化，由糖原磷酸化酶分解肌糖原或己糖激酶催化循环血糖产生葡萄糖-$6$-磷酸后，进一步被氧化为丙酮酸，丙酮酸通过乳酸脱氢酶还原为乳酸，并通过底物水平磷酸化产生 $\mathrm{ATP}$；③有氧氧化，包括葡萄糖经糖酵解途径和脂肪酸通过 $\beta$-氧化产生乙酰辅酶 $\mathrm{A}$，经三羧酸循环氧化分解，通过氧化磷酸化产生 $\mathrm{ATP}$。

:::definition{label="磷酸原系统：肌酸激酶和腺苷酸激酶"}
肌酸激酶：肌酸磷酸 + $\mathrm{ADP}$ → $\mathrm{ATP}$（快速）。腺苷酸激酶：两分子 $\mathrm{ADP}$ → $\mathrm{ATP}$ + $\mathrm{AMP}$；$\mathrm{AMP}$ 再脱氨生成 $\mathrm{IMP}$。后文「收缩时 $\mathrm{AMP}$ 可升超过 $100$ 倍」的 $\mathrm{AMP}$，有一笔就来自腺苷酸激酶。
:::

:::definition{label="糖无氧氧化：肌糖原或血糖 → 乳酸"}
糖原磷酸化酶分解肌糖原，或己糖激酶把循环血糖变成葡萄糖-$6$-磷酸 → 丙酮酸 → 乳酸脱氢酶还原为乳酸，底物水平磷酸化出 $\mathrm{ATP}$。
:::

:::definition{label="有氧氧化：糖和脂肪酸都进乙酰辅酶 A"}
葡萄糖经糖酵解、脂肪酸经 $\beta$-氧化，都生成乙酰辅酶 $\mathrm{A}$，再经三羧酸循环和氧化磷酸化。图27-8 后半段的「葡萄糖有氧氧化」和「脂肪有氧氧化」都落在这一户，只是底物不同。
:::

:::compare{title="三条 ATP 来源"}
| | 关键反应 | 快慢 | 图27-8 上的位置 |
|--|---------|------|----------------|
| 磷酸原 | 肌酸激酶；腺苷酸激酶 | 最快，储量小 | 运动一开始就占满，很快掉到零 |
| 糖无氧氧化 | 肌糖原／血糖 → 乳酸 | 快，产乳酸 | 约 $0.5\,\mathrm{min}$ 附近出峰 |
| 有氧氧化 | 乙酰辅酶 $\mathrm{A}$ → 氧化磷酸化 | 可持续 | 先糖有氧占优，再脂肪有氧占优 |

运动中三条都活跃，变的是份额，不是「前一条关掉后一条才开」。
:::

:::pitfall{label="腺苷酸激酶那一笔不要漏掉 AMP"}
磷酸原不只是肌酸磷酸。两分子 $\mathrm{ADP}$ 出一分子 $\mathrm{ATP}$ 的同时出 $\mathrm{AMP}$，$\mathrm{AMP}$ 才是后文变构激活糖原磷酸化酶 $\mathrm{b}$、磷酸果糖激酶并激活 $\mathrm{AMPK}$ 的敏感指标。
:::

:::keypoint{label="供能三条 + 分型一条"}
- 磷酸原、糖无氧、有氧氧化。
- Ⅰ型有氧、脂肪酸为主；Ⅱ型糖酵解、乳酸为主。
- $\mathrm{ATP}$ 去向：横桥、钠钾泵、钙泵。
:::

## 二、运动状态下骨骼肌收缩对能量需求的差异通过调节分解代谢实现

在不同运动状态下，骨骼肌的不同能量物质的供能比例会发生转变。在运动过程中，所有 $\mathrm{ATP}$ 的生成途径都处于活跃状态。

:::definition{label="运动中三条途径都活跃"}
变的是比例。不要把图27-8 读成「某一时刻只有一条曲线非零」。
:::

### （一）不同运动类型具有不同的能量物质分解比例

从休息到剧烈活动，骨骼肌细胞的 $\mathrm{ATP}$ 消耗可增加 $100$ 倍，必须同时激活氧化脂肪和葡萄糖的分解代谢途径。骨骼肌收缩时能量需求和供给之间建立「稳态」，需要调节葡萄糖和脂肪分解供能的比例，由细胞外能量物质的可用性、运动持续时间以及强度调控。

:::definition{label="ATP 消耗可增加 100 倍"}
从休息到剧烈活动。必须同时激活脂肪氧化和葡萄糖分解。稳态靠调糖／脂比例，调控因素是细胞外底物可用性、持续时间、强度。
:::

:::pitfall{label="100 倍是 ATP 消耗，不是 AMP 的 100 倍"}
后文收缩时 $\mathrm{AMP}$ 浓度可能上升超过 $100$ 倍，那是另一笔。开篇这一句是「耗能可增加 $100$ 倍」。
:::

如图27-8 所示，随着运动时间的延长，骨骼肌主要 $\mathrm{ATP}$ 生成途径从磷酸原系统、葡萄糖的无氧氧化、葡萄糖的有氧氧化到脂肪酸的有氧氧化逐步转变。运动初期，$\mathrm{ATP}$ 供给来自储存的 $\mathrm{ATP}$ 和肌酸磷酸。随着运动时间的延长，例如投掷、跳跃、$100\sim 400\,\mathrm{m}$ 冲刺或间歇性活动，大多数 $\mathrm{ATP}$ 来自肌酸磷酸和肌糖原的分解，并且葡萄糖通过无氧氧化产生乳酸。运动持续时间超过 $1$ 分钟后（例如在 $800\,\mathrm{m}$ 的田径比赛中），线粒体内的氧化磷酸化是主要的 $\mathrm{ATP}$ 生成途径，肌糖原成为有氧氧化的主要能量物质。随着运动时间的进一步延长，例如在持续 $2$ 小时以上的马拉松和铁人三项比赛中，肌糖原分解的同时也逐步增加从血液循环中摄取葡萄糖，同时脂肪酸的有氧氧化比例上升。和肌糖原分解比较，血糖的利用比例相对较少，后者受到胰岛素水平的调控，保证脑细胞或红细胞等优先利用。长时间运动通过不依赖于胰岛素的途径，例如激活 $\mathrm{AMPK}$ 信号增加骨骼肌细胞的葡萄糖摄取，同时肝葡萄糖输出量和糖异生增加。

::figure{src="/images/biochemistry/textbook/p0534_01.png" caption="图27-8　不同时长的运动中不同供能系统对 ATP 合成的贡献" alt="横轴为运动时间（分钟），近对数刻度：0、0.5、1、10、100、1000。纵轴为所产生的 ATP 占比（%）。黑色点线「肌酸磷酸分解」在时间零点接近 100%，约 0.5 分钟内降到接近 0。浅蓝色虚线「葡萄糖无氧氧化」在约 0.5 分钟出峰后下降，约 10 分钟后接近 0。蓝色实线「葡萄糖有氧氧化」逐渐上升，约 10 分钟附近最高，此后缓慢下降。黑色虚线「脂肪有氧氧化」在数分钟后才抬头，约 100 分钟后超过糖有氧，向 1000 分钟趋近高位。"}

:::insight{label="图27-8 按横轴从左到右读四条曲线"}

:::

:::definition{label="运动初期：储存 ATP 和肌酸磷酸"}
磷酸原。对应图27-8 最左的点线。
:::

:::definition{label="投掷、跳跃、100～400 m：磷酸原加糖无氧"}
大多数 $\mathrm{ATP}$ 来自肌酸磷酸和肌糖原分解，葡萄糖无氧氧化产乳酸。时间短、强度高，还来不及把有氧氧化抬成主户。
:::

:::definition{label="超过 1 分钟（如 800 m）：氧化磷酸化为主，肌糖原有氧氧化"}
线粒体氧化磷酸化成为主要 $\mathrm{ATP}$ 生成途径，肌糖原是有氧氧化的主要能量物质。对应图上蓝色实线抬头。
:::

:::definition{label="2 小时以上马拉松、铁人三项：血糖加脂肪酸"}
肌糖原仍在分解，同时逐步增加从循环摄取葡萄糖，脂肪酸有氧氧化比例上升。血糖利用比例相对肌糖原较少，受胰岛素水平调控，保证脑和红细胞优先。长时间运动另走不依赖胰岛素的途径：激活 $\mathrm{AMPK}$ 增加肌细胞葡萄糖摄取，同时肝葡萄糖输出和糖异生增加。
:::

:::timeline{period="随运动时间的供能主户"}
- **一开始** 储存的 ATP 和肌酸磷酸（磷酸原）
- **投掷、跳跃、100～400 m、间歇** 肌酸磷酸加肌糖原无氧氧化，产乳酸
- **超过 1 分钟（如 800 m）** 氧化磷酸化为主，肌糖原有氧氧化
- **持续 2 小时以上** 肌糖原仍分解，循环葡萄糖跟上，脂肪酸有氧氧化比例上升
- **长时间不依赖胰岛素的摄糖** AMPK 增加 GLUT4 上膜，肝输出和糖异生增加
:::

:::compare{title="时间轴上的四个例子"}
| 例子 | 主户 | 图27-8 | 不要写成 |
|------|------|--------|---------|
| 运动初期 | 储存 $\mathrm{ATP}$＋肌酸磷酸 | 点线近 $100\%$ | 「一开始就脂肪供能」 |
| $100\sim 400\,\mathrm{m}$、投掷跳跃 | 磷酸原＋肌糖原无氧 | 点线下降，浅蓝虚线出峰 | 「四百米已经是脂肪有氧」 |
| $800\,\mathrm{m}$（$>1\,\mathrm{min}$） | 氧化磷酸化，肌糖原有氧 | 蓝实线抬头 | 「超过一分钟还主要靠乳酸」 |
| 马拉松、铁人三项（$>2\,\mathrm{h}$） | 糖原＋血糖＋脂肪酸有氧 | 黑虚线走高 | 「马拉松只靠血糖、不动脂肪」 |

血糖份额相对肌糖原较少，是为了给脑和红细胞留糖，不是「骨骼肌不吃血糖」。
:::

:::cause-effect{title="长时间运动：AMPK 不依赖胰岛素增加摄糖，肝同时输出"}
运动持续延长 → $\mathrm{AMPK}$ 激活 → 肌细胞增加葡萄糖摄取（不依赖胰岛素）→ 同时肝葡萄糖输出和糖异生增加。既给肌肉燃料，又守住血糖，避免和脑抢。
:::

:::pitfall{label="图27-8 是时间轴，不是强度轴"}
横轴写的是运动时间。强度另有图27-9，电子版缺失。把「脂肪有氧在右侧抬头」读成「强度越高越靠脂肪」，正好和强度轴相反。
:::

此外，不同能量物质供能比例随运动强度发生变化（图27-9）。随运动强度的增加，葡萄糖氧化特别是肌糖原的无氧氧化增加，而脂肪酸的有氧氧化下降。在较低运动强度时脂肪酸有氧氧化供应较多的骨骼肌能量，当运动强度达到个体最大摄氧量的 $60\%\sim 65\%$ 时其贡献最大。

:::note{label="图27-9 电子版缺失"}
不同强度运动中各供能系统对 $\mathrm{ATP}$ 合成的贡献，插图电子版缺失，不嵌入空图。正文保留图号。读强度轴只靠教材句子：强度升高 → 葡萄糖氧化、尤其肌糖原无氧氧化增加，脂肪酸有氧氧化下降；脂肪酸有氧氧化在较低强度供应较多，达个体最大摄氧量 $60\%\sim 65\%$ 时贡献最大。
:::

:::definition{label="强度升高：糖（尤其肌糖原无氧）上，脂肪有氧下"}
和持续时间轴方向不同。高强度不是把图27-8 往右推，而是把脂肪曲线压下去。
:::

:::definition{label="脂肪有氧氧化在 60%～65% 最大摄氧量时贡献最大"}
较低强度时脂肪有氧供应较多；贡献峰值在个体最大摄氧量的 $60\%\sim 65\%$。不是「强度越高脂肪贡献越大」。
:::

:::compare{title="时间轴 vs 强度轴"}
| 轴 | 图 | 脂肪有氧 | 糖无氧 | 不要写成 |
|--|----|---------|--------|---------|
| 持续时间 | 图27-8，有图 | 越长越抬头，马拉松主户 | 早期出峰后下降 | 「时间越长越靠乳酸」 |
| 强度 | 图27-9，电子版缺失 | 较低强度较多，$60\%\sim 65\%$ 最大摄氧量时贡献最大，再高强度下降 | 随强度增加而增加 | 「高强度主要靠脂肪」 |

两张图问的不是同一句话。
:::

:::pitfall{label="60%～65% 是强度轴脂肪贡献峰值，60%～70% 是后文长时间中等强度"}
后文「超过 $30$ 分钟的长时间中等强度（达到个体最大携氧量的 $60\%\sim 70\%$）」说的是持续时间加中等强度时血浆脂肪酸供能约占一半。最大摄氧量和最大携氧量用词不同，百分数区间也不同，不要并成一个 $60\%$。
:::

在葡萄糖利用受限（如糖原耗竭等）或者长时间运动（超过 $30$ 分钟）情况下，会增加骨骼肌蛋白质分解提供能量（占比 $5\%\sim 15\%$）。亮氨酸、缬氨酸和异亮氨酸等支链氨基酸可用于供能，减少糖原消耗，抑制蛋白质降解，且可抑制自由基和乳酸的产生并加快其清除，减缓抑制性神经递质的生成与集聚，可对抗运动性疲劳、提高运动能力和削弱延迟性肌肉酸痛，但也可能增加血氨的水平。

:::definition{label="蛋白质供能占 5%～15% 的条件"}
葡萄糖利用受限（如糖原耗竭）或长时间运动（超过 $30$ 分钟）。不是静息的主户。
:::

:::definition{label="支链氨基酸可对抗运动性疲劳，也可能升血氨"}
亮氨酸、缬氨酸、异亮氨酸：供能、减少糖原消耗、抑制蛋白质降解、抑制自由基和乳酸的产生并加快清除、减缓抑制性神经递质生成与集聚 → 抗疲劳、提高运动能力、削弱延迟性肌肉酸痛；副作用是可能增加血氨。
:::

:::pitfall{label="5%～15% 不是支链氨基酸占心肌 ATP 的 2%"}
第二节支链氨基酸分解只占心肌 $\mathrm{ATP}$ 的 $2\%$。本节 $5\%\sim 15\%$ 是糖原受限或长时间运动时骨骼肌蛋白质分解供能的占比。器官和分母都不同。
:::

运动过程中骨骼肌产生的乳酸，可用作红肌纤维、心肌、肝和脑的能量物质，是糖异生和肌糖原合成的底物，也是运动适应以及器官之间交流的信号分子。此外，肌肉中释放的甘油、丙氨酸也是肝糖异生的原料。

:::definition{label="运动中的乳酸不只是废物"}
红肌纤维、心肌、肝和脑可以当燃料；也是糖异生和肌糖原合成的底物；还是运动适应和器官交流的信号分子。第一节脑在剧烈运动时乳酸可供能达 $20\%\sim 25\%$，原料很大一块来自本节骨骼肌。
:::

:::definition{label="甘油和丙氨酸是肝糖异生原料"}
肌肉释放。乳酸、甘油、丙氨酸是三条外送碳骨架，不要只记乳酸。
:::

:::insight{label="红肌可以吃白肌产的乳酸"}
Ⅱ型主产乳酸，Ⅰ型（红肌）可把乳酸当燃料。肌纤维分型不是「各吃各的、互不往来」。
:::

### （二）AMP 等关键调节分子和激素调节骨骼肌的能量代谢

骨骼肌的代谢受到细胞水平以及激素的多重调节。

静止时骨骼肌的能量消耗主要是由底物的可用性和血中葡萄糖、胰岛素、脂肪酸和胰高血糖素等分子的浓度驱动调控。在收缩过程中 $\mathrm{AMP}$ 浓度可能上升超过 $100$ 倍，$\mathrm{ADP}$ 浓度变化幅度仅为 $10$ 倍左右，而 $\mathrm{ATP}$ 含量变化在 $20\%\sim 30\%$ 幅度内，因此 $\mathrm{AMP}$ 或 $\mathrm{ADP}$ 是代谢状态的一个非常敏感的指标。$\mathrm{AMP}$ 是骨骼肌细胞中 $\mathrm{ATP}$ 合成途径的重要激活剂，变构激活糖原磷酸化酶 $\mathrm{b}$ 和磷酸果糖激酶，并抑制果糖-$1,6$-二磷酸酶，分别增强糖原分解和糖酵解途径。在受到神经冲动的刺激后，肌质网释放 $\mathrm{Ca}^{2+}$ 至肌浆，可激活糖原磷酸化酶激酶和 $\mathrm{AMPK}$。除受到 $\mathrm{Ca}^{2+}$ 的调节，浓度上升的 $\mathrm{AMP}$ 或 $\mathrm{ADP}$ 结合 $\mathrm{AMPK}$ 的 $\gamma$ 调节亚基后，促进 $\mathrm{AMPK}$ 磷酸化并抑制其去磷酸化，从而激活 $\mathrm{AMPK}$，而 $\mathrm{ATP}$ 拮抗这种效应。骨骼肌细胞 $\mathrm{AMPK}$ 的激活促进脂肪酸的 $\beta$ 氧化，并且即使在没有胰岛素信号情况下促进 $\mathrm{GLUT}4$ 细胞膜的迁移，在剧烈运动期间增加从血液中摄取葡萄糖。

:::definition{label="静止时靠底物和激素浓度驱动"}
葡萄糖、胰岛素、脂肪酸、胰高血糖素。收缩开始后，细胞内腺苷酸和钙接管灵敏度。
:::

:::definition{label="AMP 可升超过 100 倍，ADP 约 10 倍，ATP 只变 20%～30%"}
所以 $\mathrm{AMP}$ 或 $\mathrm{ADP}$ 是敏感指标，$\mathrm{ATP}$ 绝对值几乎看不出「正在拼命收缩」。第二节心衰早期 $\mathrm{ATP}$ 也几乎不变，逻辑相似：先看更敏感的储备或单磷酸。
:::

:::definition{label="AMP 变构激活糖原分解和糖酵解"}
激活糖原磷酸化酶 $\mathrm{b}$ 和磷酸果糖激酶，抑制果糖-$1,6$-二磷酸酶。分解开、异生那一刀关上。
:::

:::definition{label="钙激活磷酸化酶激酶和 AMPK"}
神经冲动 → 肌质网释 $\mathrm{Ca}^{2+}$ 至肌浆 → 糖原磷酸化酶激酶和 $\mathrm{AMPK}$。收缩本身就是代谢信号。
:::

:::definition{label="AMP／ADP 结合 AMPK 的 γ 亚基"}
促进 $\mathrm{AMPK}$ 磷酸化、抑制去磷酸化从而激活；$\mathrm{ATP}$ 拮抗。$\mathrm{AMPK}$ 促进脂肪酸 $\beta$ 氧化，并在没有胰岛素时促进 $\mathrm{GLUT}4$ 上膜，剧烈运动中增加从血摄糖。
:::

:::compare{title="三种腺苷酸谁最敏感"}
| | 收缩时变化 | 角色 | 不要写成 |
|--|-----------|------|---------|
| $\mathrm{AMP}$ | 可升超过 $100$ 倍 | 最敏感；变构开糖原分解／糖酵解；激活 $\mathrm{AMPK}$ | 「ATP 掉光了才开始调节」 |
| $\mathrm{ADP}$ | 约 $10$ 倍 | 也敏感；同样可结合 $\mathrm{AMPK}$ 的 $\gamma$ 亚基 | 「只有 AMP 能激活 AMPK」 |
| $\mathrm{ATP}$ | 变 $20\%\sim 30\%$ | 直接能源；拮抗 $\mathrm{AMPK}$ 激活 | 「ATP 下降 100 倍」 |

开篇 $\mathrm{ATP}$ 消耗可增加 $100$ 倍，说的是通量；这里 $\mathrm{ATP}$ 含量只变 $20\%\sim 30\%$，说的是池大小。通量不是池。
:::

:::cause-effect{title="收缩 → AMP／Ca2+ → AMPK → 脂肪酸氧化和 GLUT4 上膜"}
神经冲动释钙、腺苷酸激酶出 $\mathrm{AMP}$ → $\mathrm{AMPK}$ 激活 → 脂肪酸 $\beta$ 氧化增加，同时不依赖胰岛素的 $\mathrm{GLUT}4$ 迁移 → 剧烈运动中从血摄糖增加。这就是长时间运动「不依赖胰岛素摄糖」的分子句。
:::

:::pitfall{label="没有胰岛素也能 GLUT4 上膜，是 AMPK 这一户"}
第二节心肌 $\mathrm{GLUT}4$ 可被胰岛素或 $\mathrm{AMPK}$ 上膜。本节把「即使没有胰岛素信号」写死，是为了解释运动降血糖不必等胰岛素升高。不要写成「运动摄糖必须靠胰岛素」。
:::

骨骼肌收缩期间脂肪的消耗来自脂肪、骨骼肌细胞中的甘油三酯（intramuscular fat，$\mathrm{IMTG}$）和血中的脂蛋白，其中脂蛋白中的脂肪分解供能作用较小，在长时间有氧运动过程中占总脂肪氧化的 $10\%$ 以下。运动最初的 $30$ 分钟，骨骼肌氧化的脂肪酸总量约 $48\%$ 来自骨骼肌细胞内甘油三酯的分解。运动 $30$ 分钟后脂肪组织的脂肪动员迅速增加，甘油部分释放进入血液进行糖异生，所产生的脂肪酸只有一部分释放进入血液，约三分之二会被重新酯化储存起来，可减轻运动期间血浆升高的游离脂肪酸对机体的毒性作用。超过 $30$ 分钟的长时间中等强度（达到个体最大携氧量的 $60\%\sim 70\%$）运动期间，血中脂肪酸浓度缓慢上升，肌细胞摄取血浆脂肪酸占供能比例约一半。肌肉收缩过程中，升高的 $\mathrm{ADP}$、$\mathrm{AMP}$ 和钙离子水平激活 $\mathrm{AMPK}$，后者磷酸化乙酰辅酶 $\mathrm{A}$ 羧化酶，抑制乙酰辅酶 $\mathrm{A}$ 羧化为丙二酰辅酶 $\mathrm{A}$，从而抑制脂肪酸的合成并促进脂肪酸氧化。此外，血中游离脂肪酸的增加，加速骨骼肌细胞中的脂肪酸氧化，使得乙酰辅酶 $\mathrm{A}$、柠檬酸盐和葡萄糖-$6$-磷酸的含量增加，抑制葡萄糖的有氧氧化，节约葡萄糖保障脑等重要器官的供应。

:::definition{label="收缩期脂肪的三个来源"}
脂肪组织、肌细胞内甘油三酯（$\mathrm{IMTG}$）、血中脂蛋白。脂蛋白这一户在长时间有氧运动中占总脂肪氧化的 $10\%$ 以下，不是主户。
:::

:::definition{label="最初 30 分钟约 48% 的氧化脂肪酸来自 IMTG"}
先烧肌内储备。$30$ 分钟是分界，不是「脂肪从一开始就不参与」。
:::

:::definition{label="30 分钟后脂肪动员加速，约三分之二脂肪酸再酯化"}
甘油入血供糖异生；脂肪酸只有一部分入血，约三分之二重新酯化，减轻游离脂肪酸毒性。不是「动员多少就氧化多少」。
:::

:::definition{label="超过 30 分钟、中等强度 60%～70% 最大携氧量：血浆脂肪酸约占一半"}
血中脂肪酸浓度缓慢上升，肌细胞摄取血浆脂肪酸占供能比例约一半。和强度轴上脂肪贡献峰值 $60\%\sim 65\%$ 最大摄氧量是两句话。
:::

:::definition{label="AMPK 磷酸化 ACC，丙二酰辅酶 A 下降"}
抑制脂肪酸合成、促进脂肪酸氧化。血中游离脂肪酸增加还会抬高乙酰辅酶 $\mathrm{A}$、柠檬酸盐和葡萄糖-$6$-磷酸，抑制葡萄糖有氧氧化，把糖省给脑。
:::

:::compare{title="运动脂肪账的三个时间窗"}
| 时间 | 主来源／去向 | 本版数字 | 不要写成 |
|------|------------|---------|---------|
| 最初 $30\,\mathrm{min}$ | $\mathrm{IMTG}$ | 氧化脂肪酸总量约 $48\%$ 来自肌内甘油三酯 | 「一开始主要靠血浆脂肪酸」 |
| $30\,\mathrm{min}$ 后 | 脂肪组织动员 | 约三分之二脂肪酸再酯化 | 「动员的脂肪酸全部供肌氧化」 |
| 长时间中等强度（$>30\,\mathrm{min}$，$60\%\sim 70\%$ 最大携氧量） | 血浆脂肪酸 | 肌摄取血浆脂肪酸约占供能一半 | 「脂蛋白供能是主力」——那一户 $<10\%$ |

脂蛋白始终是小户。
:::

:::cause-effect{title="AMPK → 磷酸化 ACC → 丙二酰辅酶 A 下降 → 开脂肪酸氧化"}
$\mathrm{ADP}/\mathrm{AMP}/\mathrm{Ca}^{2+}$ 激活 $\mathrm{AMPK}$ → 磷酸化乙酰辅酶 $\mathrm{A}$ 羧化酶 → 少生成丙二酰辅酶 $\mathrm{A}$ → 脂肪酸合成关、氧化开。第二节心肌空腹也走「$\mathrm{AMPK}$ → 丙二酸单酰辅酶 $\mathrm{A}$ 下降 → 肉碱穿梭开」，分子逻辑同类，器官不同。
:::

:::cause-effect{title="血浆游离脂肪酸升高 → 抑糖有氧氧化 → 省糖给脑"}
脂肪酸氧化加快 → 乙酰辅酶 $\mathrm{A}$、柠檬酸盐、葡萄糖-$6$-磷酸升高 → 葡萄糖有氧氧化被抑制 → 葡萄糖留给脑等器官。长时间运动图27-8 右侧脂肪抬头、糖有氧下降，和这一句对得上。
:::

:::pitfall{label="48% 是最初 30 分钟 IMTG 占氧化脂肪酸的份额"}
不是「脂肪占总 ATP 的 $48\%$」，也不是「蛋白质 $5\%\sim 15\%$」那一户。分母是当时氧化的脂肪酸总量。
:::

肾上腺素等激素参与运动期间的代谢调控。肾上腺素对脂肪组织的主要作用是促进脂肪分解，激活的 $\mathrm{PKA}$ 磷酸化脂周蛋白（Perilipin-1）和激素敏感性脂肪酶（$\mathrm{HSL}$），在血液中释放脂肪酸。同时肾上腺素还会抑制脂肪细胞的脂蛋白脂肪酶（$\mathrm{LPL}$）的活性，抑制脂肪细胞对乳糜微粒和极低密度脂蛋白的储存，从而增加它们对骨骼肌的可用性。此外 $\mathrm{PKA}$ 还抑制乙酰辅酶 $\mathrm{A}$ 羧化酶，导致丙二酸单酰辅酶 $\mathrm{A}$ 浓度降低，从而抑制脂肪酸合成并促进其 $\beta$-氧化。

:::definition{label="肾上腺素促脂解：PKA 磷酸化脂周蛋白和 HSL"}
脂肪酸入血。同时抑制脂肪细胞 $\mathrm{LPL}$，少让脂肪细胞把乳糜微粒和 $\mathrm{VLDL}$ 存起来，把这些脂蛋白留给骨骼肌。
:::

:::definition{label="PKA 也抑制 ACC"}
丙二酸单酰辅酶 $\mathrm{A}$ 下降 → 脂肪酸合成关、$\beta$-氧化开。和 $\mathrm{AMPK}$ 磷酸化 $\mathrm{ACC}$ 是两条路落到同一扇门。
:::

肾上腺素还通过 $\mathrm{PKA}$ 的磷酸化修饰作用调节糖代谢。$\mathrm{PKA}$ 磷酸化修饰磷酸化酶激酶，磷酸化酶激酶进一步磷酸化并激活磷酸化酶 $\mathrm{b}$，并使得糖原合酶磷酸化失活，抑制肝糖原和肌糖原的合成并促进其降解。$\mathrm{PKA}$ 还通过抑制肝 $6$-磷酸果糖-$2$-激酶／果糖-$2,6$-二磷酸酶这个双功能酶促进糖异生。但在骨骼肌有不同于肝的 $6$-磷酸果糖-$2$-激酶／果糖-$2,6$-二磷酸酶亚型，同时骨骼肌缺乏葡萄糖-$6$-磷酸酶，肾上腺素介导的 $\mathrm{PKA}$ 激活促进了骨骼肌糖酵解，而不是进行糖异生。肾上腺素在骨骼肌细胞中的作用导致糖原降解和糖酵解的强烈激活，这种适应对于Ⅱ型纤维的无氧代谢尤其重要。

:::definition{label="PKA 开糖原降解、关糖原合成"}
磷酸化酶激酶 → 磷酸化并激活磷酸化酶 $\mathrm{b}$；糖原合酶磷酸化失活。肝糖原和肌糖原都走这套，但下游命运不同。
:::

:::definition{label="同一套肾上腺素，肝走糖异生，骨骼肌走糖酵解"}
肝：$\mathrm{PKA}$ 抑制 $6$-磷酸果糖-$2$-激酶／果糖-$2,6$-二磷酸酶，促进糖异生。骨骼肌：双功能酶亚型不同，又缺乏葡萄糖-$6$-磷酸酶，所以 $\mathrm{PKA}$ 促进糖酵解而不是糖异生。Ⅱ型纤维的无氧代谢尤其靠这一适应。
:::

:::compare{title="肾上腺素：脂肪组织 vs 肝 vs 骨骼肌"}
| 组织 | $\mathrm{PKA}$ 落到哪 | 净效应 | 不要写成 |
|------|-----------------|--------|---------|
| 脂肪组织 | 脂周蛋白、$\mathrm{HSL}$；抑 $\mathrm{LPL}$；抑 $\mathrm{ACC}$ | 脂肪酸入血，少让脂肪细胞存脂蛋白 | 「肾上腺素让脂肪细胞多储存 VLDL」 |
| 肝 | 糖原降解；抑双功能酶促糖异生 | 向外输出葡萄糖 | 「肝和肌一样走糖酵解」 |
| 骨骼肌 | 糖原降解；亚型不同且无葡萄糖-$6$-磷酸酶 | 糖酵解，尤其Ⅱ型无氧 | 「骨骼肌肾上腺素促糖异生」 |

缺葡萄糖-$6$-磷酸酶这一句，是肌糖原不能直接补血糖的旧账，这里用来解释为什么同一激素在肌内不走糖异生。
:::

:::pitfall{label="不要把骨骼肌写成能做糖异生的器官"}
糖异生器官在第三节是肝和肾。骨骼肌缺葡萄糖-$6$-磷酸酶，肾上腺素再怎么激活 $\mathrm{PKA}$ 也是糖酵解。写成「运动时肌糖异生供脑」，碳骨架其实是乳酸、甘油、丙氨酸送到肝。
:::

:::keypoint{label="调节分子先记 AMP 和肾上腺素"}
- $\mathrm{AMP}$ 可升 $>100$ 倍，变构开糖原分解／糖酵解，激活 $\mathrm{AMPK}$。
- $\mathrm{AMPK}$：脂肪酸氧化 + 无胰岛素时 $\mathrm{GLUT}4$ 上膜。
- 最初 $30\,\mathrm{min}$ $\mathrm{IMTG}$ 约 $48\%$；其后约三分之二脂肪酸再酯化。
- 肾上腺素：脂肪动员；肌内促糖酵解（尤其Ⅱ型），肝才促糖异生。
:::

## 三、运动可以预防肥胖和糖尿病

肥胖定义为体重指数（$\mathrm{BMI}$）$\geqslant 30\,\mathrm{kg/m}^{2}$，是一种体内脂肪或脂肪组织过度堆积引起的复杂的慢性疾病，极大增加了 2 型糖尿病（$\mathrm{T}2\mathrm{D}$）、心血管疾病、高血压、非酒精性脂肪性肝、痛风和癌症等疾病的风险。糖尿病是以慢性高血糖为特征的代谢性疾病，其发生发展与遗传、环境及行为三大因素密切相关。肥胖和糖尿病紧密关联，已经成为重要的公共卫生问题。

运动可以增加能量消耗，降低肥胖和糖尿病的发病风险，对身体有多重益处。活跃的生活方式能维持健康的体重，超重的成人每天进行 $45\sim 60$ 分钟中等强度的运动能有效预防由超重进展为肥胖。降低并维持 $\mathrm{BMI}$ 可以降低糖尿病发病的危险，而运动能显著改善空腹血糖水平的控制和降低糖尿病的发病率。

:::definition{label="肥胖：BMI ≥ 30 kg/m2"}
体内脂肪或脂肪组织过度堆积引起的复杂慢性病。连带风险：$\mathrm{T}2\mathrm{D}$、心血管病、高血压、非酒精性脂肪性肝、痛风、癌症。
:::

:::definition{label="糖尿病：慢性高血糖，遗传、环境、行为三因素"}
与肥胖紧密关联。本节不把糖尿病写成「只是胰岛素绝对缺乏」。
:::

:::definition{label="超重成人每天 45～60 分钟中等强度运动"}
有效预防由超重进展为肥胖。降低并维持 $\mathrm{BMI}$ 降低糖尿病发病危险；运动改善空腹血糖控制、降低发病率。
:::

:::pitfall{label="45～60 分钟不要和运动最初 30 分钟 IMTG 并成一笔"}
$45\sim 60$ 分钟是预防超重变肥胖的每日运动处方；$30$ 分钟是燃料来源从 $\mathrm{IMTG}$ 转向脂肪组织动员的分界。问的不是同一件事。
:::

### （一）运动通过调节糖代谢产生效应

运动对糖代谢有重要调节作用，显著降低 2 型糖尿病患者空腹血糖、餐后血糖和糖化血红蛋白与血糖波动。

运动可改善 2 型糖尿病个体胰岛素敏感性。在整体水平上，运动可以通过增加机体能量的消耗，减少脂质在骨骼肌细胞、胰腺细胞及肝细胞中的堆积，减少脂质的毒性作用。运动激活 $\mathrm{AMPK}$，增加骨骼肌细胞膜上 $\mathrm{GLUT}4$ 的数量，增加骨骼肌细胞的葡萄糖摄取。

运动还可改善 2 型糖尿病患者的骨骼肌功能。糖尿病患者骨骼肌功能下降，严重者会出现糖尿病肌病，表现为骨骼肌的机械收缩功能和代谢功能下降，运动能够明显改善这些病变。长期运动能诱导在糖尿病患者骨骼肌中显著下调的过氧化物酶体增殖物激活受体 $\gamma$ 共激活剂-$1\alpha$（peroxisome proliferator-activated receptor $\gamma$ coactivator-$1\alpha$，$\mathrm{PGC}$-$1\alpha$）和热休克蛋白表达，从而增加线粒体生物合成；同时运动能使糖尿病患者的骨骼肌线粒体中 $\mathrm{UCP}3$ 表达上升，能够诱导骨骼肌细胞线粒体适应，从而修复糖尿病骨骼肌线粒体损伤。

:::definition{label="运动降低 T2D 的空腹、餐后血糖、糖化血红蛋白和波动"}
糖代谢账不只降一个空腹点。
:::

:::definition{label="改善胰岛素敏感性的两层"}
整体：增加能耗，减少脂质在骨骼肌、胰腺、肝堆积，减轻脂毒性。细胞：激活 $\mathrm{AMPK}$，增加膜上 $\mathrm{GLUT}4$，增加摄糖。
:::

:::definition{label="糖尿病肌病：机械收缩和代谢功能都下降"}
严重者出现。运动能明显改善。不要把糖尿病骨骼肌病变只写成「血糖高」。
:::

:::definition{label="长期运动诱导 PGC-1α、热休克蛋白和 UCP3"}
糖尿病患者骨骼肌中 $\mathrm{PGC}$-$1\alpha$ 和热休克蛋白显著下调；运动把它们诱导回来，增加线粒体生物合成。$\mathrm{UCP}3$ 上升，诱导线粒体适应，修复糖尿病骨骼肌线粒体损伤。
:::

:::cause-effect{title="运动 → AMPK → GLUT4 上膜 → 摄糖增加"}
这一条在急性收缩和长期改善胰岛素敏感性里反复出现。分子是同一户 $\mathrm{AMPK}$，时间尺度不同。
:::

:::cause-effect{title="运动 → PGC-1α／热休克蛋白／UCP3 → 修线粒体"}
长期运动诱导被下调的 $\mathrm{PGC}$-$1\alpha$ 和热休克蛋白 → 线粒体生物合成增加；$\mathrm{UCP}3$ 上升 → 线粒体适应 → 修复糖尿病肌病的代谢侧。机械收缩功能的改善和代谢修复是并列的。
:::

:::pitfall{label="PGC-1α 下调是糖尿病骨骼肌的本底，运动是把它诱导回来"}
不要写成「运动抑制 $\mathrm{PGC}$-$1\alpha$」。教材原句是患者中显著下调，运动诱导其表达。
:::

### （二）运动通过调节脂代谢产生效应

运动对血脂也有重要影响。运动对血浆甘油三酯的影响取决于运动强度、运动量和时长，强度较高的运动可降低血浆甘油三酯的水平并维持较长时间。长期有氧运动显著降低血浆总胆固醇和甘油三酯。运动提高脂蛋白脂肪酶活性，促进甘油三酯的分解；有氧运动刺激肌细胞线粒体体积增大、数目增加，有利于脂肪酸的有氧氧化；此外，运动增加骨骼肌毛细血管数量与密度，增加血管内皮表面积从而增加氧气与血浆脂肪酸的摄取和利用。

:::definition{label="血浆甘油三酯：强度、量、时长都算"}
强度较高的运动可降低血浆甘油三酯并维持较长时间。长期有氧运动显著降低总胆固醇和甘油三酯。
:::

:::definition{label="LPL、线粒体、毛细血管三条脂代谢通路"}
提高脂蛋白脂肪酶活性，促甘油三酯分解；线粒体体积和数目增加，利脂肪酸有氧氧化；毛细血管数量与密度增加，内皮表面积增加，氧和血浆脂肪酸更好摄取。
:::

单次运动对血浆胆固醇影响不大，长期耐力训练后升高血浆 $\mathrm{HDL}$-$\mathrm{C}$ 约 $12\%\sim 20\%$，但是停止运动并不能保持升高，需要长期坚持。长期有氧运动升高 $\mathrm{LPL}$ 以及卵磷脂–胆固醇酰基转移酶（$\mathrm{LCAT}$）的活性，加速乳糜微粒和 $\mathrm{VLDL}$ 中甘油三酯的分解，促使其残存的胆固醇、磷脂和载脂蛋白转移进入肝，并与新生的 $\mathrm{HDL}_{3}$ 生成 $\mathrm{HDL}_{2}$。此外，上升的 $\mathrm{LCAT}$ 活性促进 $\mathrm{HDL}_{3}$ 不断酯化生成富含胆固醇酯的 $\mathrm{HDL}_{2}$，利于胆固醇逆向转运。

:::definition{label="HDL-C 升高 12%～20% 要长期耐力训练"}
单次运动对血浆胆固醇影响不大。停训不能保持，必须长期坚持。
:::

:::definition{label="LPL 和 LCAT 把 HDL3 做成 HDL2"}
$\mathrm{LPL}$ 加速乳糜微粒和 $\mathrm{VLDL}$ 中甘油三酯分解，残存的胆固醇、磷脂、载脂蛋白转移入肝，与新生 $\mathrm{HDL}_{3}$ 生成 $\mathrm{HDL}_{2}$。$\mathrm{LCAT}$ 促进 $\mathrm{HDL}_{3}$ 酯化成富含胆固醇酯的 $\mathrm{HDL}_{2}$，利于胆固醇逆向转运。
:::

:::compare{title="单次运动 vs 长期有氧"}
| | 胆固醇／HDL | 甘油三酯 | 不要写成 |
|--|------------|---------|---------|
| 单次 | 对血浆胆固醇影响不大 | 强度高可降低并维持较长时间 | 「练一次 HDL 就升 $12\%\sim 20\%$」 |
| 长期有氧／耐力 | $\mathrm{HDL}$-$\mathrm{C}$ 升约 $12\%\sim 20\%$；总胆固醇下降 | 显著降低 | 「停训后 HDL 仍保持」 |

$12\%\sim 20\%$ 是长期耐力训练的 $\mathrm{HDL}$-$\mathrm{C}$，不是单次课的即时化验。
:::

:::pitfall{label="肾上腺素抑制脂肪细胞 LPL，运动训练提高的是整体／肌侧 LPL 活性"}
急性肾上腺素让脂肪细胞少存乳糜微粒和 $\mathrm{VLDL}$，把底物推向骨骼肌。长期运动提高脂蛋白脂肪酶活性、促甘油三酯分解，是训练适应。组织对象和时间尺度不同，不要写成「运动抑制 LPL」。
:::

:::insight{label="HDL3 → HDL2 是逆向转运的成型步骤"}
残粒成分进肝、$\mathrm{LCAT}$ 酯化，两步都把 $\mathrm{HDL}_{3}$ 推向 $\mathrm{HDL}_{2}$。问「为什么要长期坚持」——停训这条成型链就回不去。
:::

### （三）运动通过调节内分泌激素和肌肉因子产生效应

运动对内分泌激素有不同影响。应激激素水平在急性运动过程中升高，且升高幅度与运动强度和运动持续时间相关。例如，交感神经系统通过节前神经纤维将刺激传播到肾上腺释放肾上腺素，血液中的肾上腺素浓度可增加 $50$ 倍以上，但其半衰期仅约 $2$ 分钟，引起应激性短期反应。肾上腺素的分泌取决于运动的持续时间或强度。肾上腺素作用于身体的很多组织，促进小支气管的扩张增加 $\mathrm{O}_{2}$ 的摄取，增加心率和血压，收缩血管，减弱胃肠道蠕动，这些作用保证 $\mathrm{O}_{2}$ 输送到脑等不同的器官。此外，肾上腺素促进糖原分解、脂肪动员以及蛋白质降解，促进 $\mathrm{ATP}$ 的生成。

:::definition{label="急性运动时肾上腺素可升 50 倍以上，半衰期约 2 分钟"}
幅度与强度和持续时间相关。短半衰期决定这是应激性短期反应，不是「血里一直维持 50 倍」。
:::

:::definition{label="肾上腺素保证氧送到脑等器官"}
小支气管扩张增加摄氧，心率和血压增加，收缩血管，减弱胃肠蠕动。同时促糖原分解、脂肪动员、蛋白质降解，促 $\mathrm{ATP}$ 生成。
:::

:::pitfall{label="50 倍是肾上腺素，100 倍是 AMP 或 ATP 消耗"}
肾上腺素血液浓度可增加 $50$ 倍以上；$\mathrm{AMP}$ 可升超过 $100$ 倍；$\mathrm{ATP}$ 消耗可增加 $100$ 倍。三笔「很多倍」分母全不同。
:::

骨骼肌还是一种分泌器官，骨骼肌收缩诱导肌肉因子（myokine）的分泌（图27-10）。肌肉因子是由肌纤维表达、产生和释放的蛋白质或多肽，通过自分泌、旁分泌或内分泌方式发挥作用。肌肉因子参与骨骼肌生长或脂质代谢等生理调节，适应运动训练。通过肌肉因子的内分泌作用，骨骼肌与脑、脂肪组织、骨骼、肝、肠道、胰腺、血管和皮肤等其他组织器官进行信息交流。目前已经发现 $650$ 多种肌肉因子，影响认知、脂质和葡萄糖代谢、白色脂肪褐变、骨形成、内皮细胞功能、皮肤结构和肿瘤生长等生理病理过程。

:::note{label="图27-10 电子版缺失"}
骨骼肌通过肌肉因子与其他器官交流信息的插图电子版缺失，不嵌入空图。正文保留图号。交流对象按教材点名：脑、脂肪组织、骨骼、肝、肠道、胰腺、血管和皮肤。不要因为缺图就省略这一户，也不要把第五节瘦素弓状核图27-11 挪过来充数。
:::

:::definition{label="肌肉因子由肌纤维表达、产生和释放"}
蛋白质或多肽。自分泌、旁分泌或内分泌。收缩诱导分泌。骨骼肌因此是分泌器官，不只是收缩机器。
:::

:::definition{label="已发现 650 多种肌肉因子"}
影响认知、脂质和葡萄糖代谢、白色脂肪褐变、骨形成、内皮细胞功能、皮肤结构和肿瘤生长。内分泌对象包括脑、脂肪组织、骨骼、肝、肠道、胰腺、血管和皮肤。
:::

:::pitfall{label="不要把瘦素写成肌肉因子"}
瘦素是第五节脂肪组织的脂肪因子，走弓状核。本节是肌纤维来的肌肉因子。图27-10 缺图也不许用图27-11 顶上。
:::

白细胞介素-$6$（$\mathrm{IL}$-$6$）是第一个被发现的肌肉因子。运动时血液中 $\mathrm{IL}$-$6$ 浓度以指数形式增加，与运动时间长短以及参与运动的骨骼肌量成正比，并且在Ⅰ型肌纤维中高表达。$\mathrm{IL}$-$6$ 促进胰岛 $\mathrm{B}$ 细胞的增殖，刺激肠道 $\mathrm{L}$ 细胞分泌胰高血糖素样肽 1（glucagon-like peptide-1，$\mathrm{GLP}$-$1$），同时通过 $\mathrm{AMPK}$ 和 $\mathrm{PI}3\mathrm{K}/\mathrm{Akt}$ 信号通路增强胰岛素的分泌，提高葡萄糖的摄取和脂肪酸的氧化。与常见的 $\mathrm{IL}$-$6$ 促炎作用不同，骨骼肌分泌的 $\mathrm{IL}$-$6$ 减少 $\mathrm{TNF}$ 和 $\mathrm{IL}$-$1$ 等炎性因子的产生，同时诱导抗炎细胞因子（如 $\mathrm{IL}$-$10$、$\mathrm{IL}$-$1$ 受体拮抗剂和可溶性 $\mathrm{TNF}$ 受体）的释放，减少全身性炎症反应。$\mathrm{IL}$-$6$ 还诱导皮质醇的产生，从而刺激中性粒细胞增多和淋巴细胞的减少。

:::definition{label="IL-6 是第一个被发现的肌肉因子"}
血中浓度指数增加，与运动时间和参与的骨骼肌量成正比，Ⅰ型肌纤维高表达。慢肌不是「不分泌」。
:::

:::definition{label="肌源 IL-6 促 GLP-1 和胰岛素，还抗炎"}
促胰岛 $\mathrm{B}$ 细胞增殖；刺激肠道 $\mathrm{L}$ 细胞分泌 $\mathrm{GLP}$-$1$；经 $\mathrm{AMPK}$ 和 $\mathrm{PI}3\mathrm{K}/\mathrm{Akt}$ 增强胰岛素分泌，提高摄糖和脂肪酸氧化。与常见 $\mathrm{IL}$-$6$ 促炎不同：减少 $\mathrm{TNF}$、$\mathrm{IL}$-$1$，诱导 $\mathrm{IL}$-$10$、$\mathrm{IL}$-$1$ 受体拮抗剂、可溶性 $\mathrm{TNF}$ 受体，减少全身炎症。还诱导皮质醇，中性粒细胞增多、淋巴细胞减少。
:::

:::pitfall{label="肌源 IL-6 不要写成促炎细胞因子就结束"}
教材对比：常见 $\mathrm{IL}$-$6$ 促炎；骨骼肌分泌的 $\mathrm{IL}$-$6$ 走抗炎。写成「运动升 IL-6 所以更炎」，把这一户写反了。
:::

:::compare{title="肌源 IL-6 的代谢账和炎症账"}
| | 做什么 | 不要写成 |
|--|--------|---------|
| 胰岛 $\mathrm{B}$ 细胞 | 促增殖，经 $\mathrm{AMPK}$、$\mathrm{PI}3\mathrm{K}/\mathrm{Akt}$ 增强胰岛素分泌 | 「IL-6 抑制胰岛素」 |
| 肠道 $\mathrm{L}$ 细胞 | 分泌 $\mathrm{GLP}$-$1$ | 「GLP-1 来自脂肪组织瘦素」 |
| 炎症 | 减 $\mathrm{TNF}$、$\mathrm{IL}$-$1$，诱抗炎因子 | 「和感染时的 IL-6 同一张脸」 |
| 血细胞 | 经皮质醇：中性粒细胞↑、淋巴细胞↓ | 「只调糖不调血象」 |

指数增加和运动时间、肌肉量成正比，是定量句，不是「有就行」。
:::

一些肌肉因子参与骨骼肌组织的生长，包括白血病抑制因子（leukemia inhibitory factor，$\mathrm{LIF}$）、$\mathrm{IL}$-$4$、$6$、$7$ 和 $\mathrm{IL}$-$15$。肌生长抑制素（myostatin）抑制骨骼肌的生长，而运动可诱导肝释放卵泡抑素（follistatin），后者是肌生长抑制素的抑制剂。

:::definition{label="促生长的肌肉因子"}
$\mathrm{LIF}$、$\mathrm{IL}$-$4$、$6$、$7$、$\mathrm{IL}$-$15$。$\mathrm{IL}$-$6$ 在这里又出现一次，身份是生长相关名单中的一员。
:::

:::definition{label="肌生长抑制素抑制生长，卵泡抑素抑制它"}
运动诱导肝释放卵泡抑素，卵泡抑素是肌生长抑制素的抑制剂。生长开关在「肌自己的抑制素 vs 肝来的抑制剂」。
:::

:::insight{label="肝在运动适应里不只输出葡萄糖"}
长时间运动肝糖异生增加，是燃料账；运动诱导肝释放卵泡抑素，是肌肉生长账。同一器官两本账，不要并成「肝只管血糖」。
:::

除对炎症和骨骼肌生长的调节，肌肉因子还调节多个组织器官代谢等生理过程。脑源性神经营养因子（$\mathrm{BDNF}$）和 $\mathrm{IL}$-$6$ 参与 $\mathrm{AMPK}$ 介导的脂肪氧化，$\mathrm{IL}$-$6$ 刺激脂肪分解，而 $\mathrm{IL}$-$15$ 特异性诱导内脏脂肪的分解。$\mathrm{IL}$-$8$ 和 $\mathrm{CXCL}1$ 促进血管生成。胰岛素样生长因子 1（$\mathrm{IGF}1$）、成纤维细胞生长因子 2（$\mathrm{FGF}2$）和转化生长因子-$\beta$（$\mathrm{TGF}$-$\beta$）与骨形成有关。卵泡菌素相关蛋白 1（follistatin-related protein 1）可促进缺血血管的内皮功能和血运重建。鸢尾素（irisin）和镍纹样蛋白（meteorin-like，$\mathrm{METRNL}$）参与白色脂肪组织向棕色或米色脂肪组织的转变，以热量的形式消耗能量。

:::definition{label="脂肪氧化和脂解的肌肉因子"}
$\mathrm{BDNF}$ 和 $\mathrm{IL}$-$6$ 参与 $\mathrm{AMPK}$ 介导的脂肪氧化；$\mathrm{IL}$-$6$ 刺激脂肪分解；$\mathrm{IL}$-$15$ 特异性诱导内脏脂肪分解。内脏脂肪这一刀点名 $\mathrm{IL}$-$15$，不要写成「所有 IL 都一样」。
:::

:::definition{label="血管、骨、褐变各有名单"}
血管生成：$\mathrm{IL}$-$8$、$\mathrm{CXCL}1$。骨形成：$\mathrm{IGF}1$、$\mathrm{FGF}2$、$\mathrm{TGF}$-$\beta$。缺血血管内皮和血运重建：卵泡菌素相关蛋白 1。白脂转棕／米色、以热量消耗能量：鸢尾素、镍纹样蛋白（$\mathrm{METRNL}$）。
:::

:::compare{title="肌肉因子按靶器官分户"}
| 靶 | 本版点名 | 不要写成 |
|--|---------|---------|
| 糖／胰岛素轴 | $\mathrm{IL}$-$6$ → $\mathrm{B}$ 细胞、$\mathrm{L}$ 细胞 $\mathrm{GLP}$-$1$、$\mathrm{AMPK}/\mathrm{PI}3\mathrm{K}/\mathrm{Akt}$ | 「瘦素抑制食欲」——那是第五节 |
| 炎症 | 肌源 $\mathrm{IL}$-$6$ 抗炎 | 「运动升 IL-6＝全身炎」 |

| 脂肪 | $\mathrm{IL}$-$6$ 脂解；$\mathrm{IL}$-$15$ 内脏脂肪；鸢尾素、$\mathrm{METRNL}$ 褐变 | 「褐变是瘦素的功能」 |

图27-10 缺图，就靠这张表把交流对象立住。
:::

:::pitfall{label="卵泡抑素和卵泡菌素相关蛋白 1 不是同一个分子"}
卵泡抑素（follistatin）由运动诱导肝释放，抑制肌生长抑制素。卵泡菌素相关蛋白 1（follistatin-related protein 1）促缺血血管内皮功能和血运重建。名字像，靶不同。
:::

:::pitfall{label="白色脂肪褐变写在肌肉因子，机制细节留给第五节"}
本节只记鸢尾素和镍纹样蛋白参与白脂向棕色或米色转变、以热量消耗能量。棕色脂肪 $\mathrm{UCP}1$、瘦素走弓状核，是第五节的账，这里点到为止。
:::

:::memory{label="本节必背分户"}
- 骨骼肌约占体重 $40\%$。Ⅰ型红肌：氧化磷酸化，脂肪酸为主，耐疲劳，运动单位 $\leqslant 300$ 条。Ⅱ型白肌：糖酵解产乳酸，速度 $5\sim 6$ 倍、功率 $3\sim 5$ 倍，运动单位 $\geqslant 300$ 条。
- $\mathrm{ATP}$ 去向：肌球蛋白 $\mathrm{ATP}$ 酶、钠钾泵、肌质网钙泵。来源三条：磷酸原（肌酸激酶、腺苷酸激酶）、糖无氧、有氧氧化。
- 图27-8 时间轴：磷酸原 → 糖无氧 → 糖有氧 → 脂肪有氧。初期储存 $\mathrm{ATP}$＋肌酸磷酸；$100\sim 400\,\mathrm{m}$ 磷酸原＋糖无氧；$>1\,\mathrm{min}$（$800\,\mathrm{m}$）氧化磷酸化＋肌糖原有氧；$>2\,\mathrm{h}$ 血糖跟上、脂肪有氧抬头。
- 图27-9 电子版缺失。强度升：糖（尤其肌糖原无氧）上、脂肪有氧下；脂肪贡献峰值在最大摄氧量 $60\%\sim 65\%$。
- $\mathrm{AMP}$ 可升 $>100$ 倍，$\mathrm{ADP}$ 约 $10$ 倍，$\mathrm{ATP}$ 只变 $20\%\sim 30\%$。$\mathrm{AMPK}$：脂肪酸氧化＋无胰岛素时 $\mathrm{GLUT}4$ 上膜。最初 $30\,\mathrm{min}$ $\mathrm{IMTG}$ 约 $48\%$；其后约三分之二脂肪酸再酯化。
- 肾上腺素可升 $50$ 倍、半衰期约 $2$ 分钟；肌内促糖酵解（缺葡萄糖-$6$-磷酸酶），肝才促糖异生。蛋白质供能 $5\%\sim 15\%$ 见于糖原受限或 $>30\,\mathrm{min}$。
- 运动预防肥胖（$\mathrm{BMI}\geqslant 30$）和 $\mathrm{T}2\mathrm{D}$：超重成人每天 $45\sim 60$ 分钟中等强度。长期耐力训练 $\mathrm{HDL}$-$\mathrm{C}$ 升约 $12\%\sim 20\%$，停训不保持。$\mathrm{PGC}$-$1\alpha$、热休克蛋白、$\mathrm{UCP}3$ 修线粒体。
- 肌肉因子 $650$ 多种（图27-10 电子版缺失）。$\mathrm{IL}$-$6$ 第一个被发现，Ⅰ型高表达，肌源抗炎并促 $\mathrm{GLP}$-$1$。肌生长抑制素 vs 肝卵泡抑素。鸢尾素、$\mathrm{METRNL}$ 参与褐变。瘦素、弓状核不在本节。
:::

:::keypoint{label="本节不写的三本账"}
脑的葡萄糖／酮体和递质四户在第一节。心肌代谢杂食者、优势效应、心衰 $\mathrm{PCr}/\mathrm{ATP}$ 和 $\beta$-羟丁酸抑制组蛋白脱乙酰酶在第二节。肾的滤过重吸收、空腹糖异生／生酮、$\mathrm{EPO}$、肾素原 $406\to 340$ 氨基酸和活性维生素 $\mathrm{D}_{3}$ 在第三节。脂肪组织瘦素、弓状核、图27-11 在第五节。本节只把纤维分型、运动时间轴、$\mathrm{AMP}$／肾上腺素调节和肌肉因子立住。
:::
