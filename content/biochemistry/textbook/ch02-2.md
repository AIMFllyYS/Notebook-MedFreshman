# 第二节　酶的工作原理

第一节把酶写成蛋白质（核酶除外），摊开辅因子、活性中心和同工酶。本节先把酶与一般催化剂的共同点写清，再写酶独有的四条：催化效率极高、对底物高度特异、可调节、不稳定；然后用过渡态、活化能、诱导契合、邻近定向、表面效应和多元催化（酸碱催化、共价催化）说明它怎样干活。专一性按教材分成绝对特异性、立体异构特异性和相对特异性。第三节才写米氏方程和抑制。

酶与一般催化剂一样，在化学反应前后都没有质和量的改变。它们都只能催化热力学允许的化学反应；只能加速反应的进程，而不改变反应的平衡点，即不改变反应的平衡常数。作为生物催化剂的酶，其化学本质是蛋白质，因此酶促反应又具有不同于一般催化剂催化反应的特点和反应机制。

:::definition{label="酶与一般催化剂的共同点"}
酶与一般催化剂一样：反应前后都没有质和量的改变；只能催化热力学允许的化学反应；只加速进程，不改变平衡点，即不改变平衡常数。
:::

:::pitfall{label="酶不改平衡常数，也不做热力学不允许的反应"}
“高效”不是“能把不会发生的反应做出来”。平衡点和平衡常数都不改；只能催化热力学允许的反应。把酶听成“改写 $\Delta G$”，第三节的 $V_{\max}$、$K_\mathrm{m}$ 会接到错误的能量账上。
:::

## 一、酶具有不同于一般催化剂的显著特点

### （一）酶对底物具有极高的催化效率

酶的催化效率通常比非催化反应高 $10^{8}\sim 10^{20}$ 倍，比一般催化剂高 $10^{7}\sim 10^{13}$ 倍。例如，在 $\mathrm{H}_2\mathrm{O}_2$ 分解成 $\mathrm{H}_2\mathrm{O}$ 和 $\mathrm{O}_2$ 的反应中，无催化剂时反应的活化能为 $75\,312\,\mathrm{J/mol}$，用胶体钯作催化剂时，反应的活化能降至 $48\,953\,\mathrm{J/mol}$，用过氧化氢酶催化时，反应的活化能降至 $8\,368\,\mathrm{J/mol}$（表2-4）。

:::definition{label="酶的催化效率"}
酶的催化效率通常比非催化反应高 $10^{8}\sim 10^{20}$ 倍，比一般催化剂高 $10^{7}\sim 10^{13}$ 倍。
:::

:::example{label="过氧化氢分解：无催化剂、胶体钯、过氧化氢酶"}
$\mathrm{H}_2\mathrm{O}_2\to\mathrm{H}_2\mathrm{O}+\mathrm{O}_2$。无催化剂时活化能 $75\,312\,\mathrm{J/mol}$；胶体钯降至 $48\,953\,\mathrm{J/mol}$；过氧化氢酶降至 $8\,368\,\mathrm{J/mol}$。酶比一般催化剂更有效地降低活化能，这一笔在本节第二部分展开。
:::

**表2-4　某些酶与一般催化剂催化效率的比较**

| 底物 | 催化剂 | 反应温度／℃ | 速率常数 |
|------|--------|-------------|----------|
| 苯酰胺 | $\mathrm{H}^{+}$ | $52$ | $2.4\times 10^{-6}$ |
| 苯酰胺 | $\mathrm{OH}^{-}$ | $53$ | $8.5\times 10^{-6}$ |
| 苯酰胺 | $\alpha$-胰凝乳蛋白酶 | $25$ | $14.9$ |
| 尿素 | $\mathrm{H}^{+}$ | $62$ | $7.4\times 10^{-7}$ |
| 尿素 | 脲酶 | $21$ | $5.0\times 10^{6}$ |
| $\mathrm{H}_2\mathrm{O}_2$ | $\mathrm{Fe}^{2+}$ | $56$ | $22$ |

:::insight{label="表2-4 看数量级，不要只看温度"}
苯酰胺在 $52\sim 53\,^{\circ}\mathrm{C}$ 用酸、碱，速率常数 $10^{-6}$ 量级；$\alpha$-胰凝乳蛋白酶在 $25\,^{\circ}\mathrm{C}$ 已是 $14.9$。尿素用 $\mathrm{H}^{+}$ 为 $7.4\times 10^{-7}$，脲酶在 $21\,^{\circ}\mathrm{C}$ 达到 $5.0\times 10^{6}$。酶在更温和的温度下把速率抬了多个数量级。
:::

### （二）酶对底物具有高度的特异性

与一般催化剂不同，酶对其所催化的底物具有较严格的选择性。即一种酶只作用于一种或一类化合物，或一定的化学键，催化特定的化学反应生成特定的产物，称为酶特异性（enzyme specificity）或专一性。根据酶对底物选择的严格程度，酶特异性可分为绝对特异性和相对特异性。

:::definition{label="酶特异性"}
酶特异性（enzyme specificity）或专一性：一种酶只作用于一种或一类化合物，或一定的化学键，催化特定的化学反应生成特定的产物。按对底物选择的严格程度，分为绝对特异性和相对特异性。
:::

#### 1. 绝对特异性

某种酶只能作用于特定结构的底物，进行一种专一的反应，生成一种特定结构产物的现象，称为绝对特异性（absolute specificity）。例如，脲酶仅能催化尿素水解生成 $\mathrm{CO}_2$ 和 $\mathrm{NH}_3$，而不能催化甲基尿素水解；琥珀酸脱氢酶仅催化琥珀酸与延胡索酸之间的氧化还原反应。

:::definition{label="绝对特异性"}
某种酶只能作用于特定结构的底物，进行一种专一的反应，生成一种特定结构产物，称为绝对特异性（absolute specificity）。
:::

:::example{label="脲酶和琥珀酸脱氢酶是绝对特异性"}
脲酶只水解尿素生成 $\mathrm{CO}_2$ 和 $\mathrm{NH}_3$，不水解甲基尿素。琥珀酸脱氢酶只做琥珀酸与延胡索酸之间的氧化还原。底物结构稍改，酶就不认。
:::

某些具有绝对特异性的酶对底物的立体异构体具有严格的选择性，只能与立体异构体中的一种类型发生反应的现象，称为立体异构特异性（stereospecificity）。例如，体内代谢氨基酸的酶绝大多数只能作用于 $\mathrm{L}$-氨基酸，而不能作用于 $\mathrm{D}$-氨基酸；乳酸脱氢酶仅催化 $\mathrm{L}$-乳酸脱氢生成丙酮酸，而对 $\mathrm{D}$-乳酸无作用（图2-4）；延胡索酸酶仅催化反-丁烯二酸（延胡索酸）加水产生苹果酸，而对顺-丁烯二酸（马来酸）无作用。

:::definition{label="立体异构特异性"}
某些具有绝对特异性的酶对底物的立体异构体具有严格选择性，只能与其中一种类型发生反应，称为立体异构特异性（stereospecificity）。
:::

:::example{label="L 与 D、反式与顺式都算立体异构特异性"}
代谢氨基酸的酶绝大多数只作用于 $\mathrm{L}$-氨基酸，不作用于 $\mathrm{D}$-氨基酸。乳酸脱氢酶只催化 $\mathrm{L}$-乳酸脱氢生成丙酮酸，对 $\mathrm{D}$-乳酸无作用。延胡索酸酶只催化反-丁烯二酸（延胡索酸）加水产生苹果酸，对顺-丁烯二酸（马来酸）无作用。
:::

:::note{label="图2-4 电子版缺失"}
教材图2-4 为乳酸脱氢酶对乳酸立体异构体的选择性催化：$\mathrm{L}$-乳酸可被脱氢生成丙酮酸，$\mathrm{D}$-乳酸不被作用。数字切片 `p0067_01.png` 为 $0$ 字节，本节不引用该文件。正文中“只认 $\mathrm{L}$-乳酸”仍按教材保留。
:::

#### 2. 相对特异性

某种酶可以作用于一类化合物或一种化学键催化一类化学反应的现象，称为相对特异性（relative specificity）。例如，磷酸酶对一般的磷酸酯键都有水解作用，可水解甘油或酚与磷酸形成的酯键；脂肪酶不仅水解脂肪，也水解简单的酯类；蔗糖酶不仅水解蔗糖，也水解棉子糖中的同一种糖苷键；消化系统中的蛋白酶仅对蛋白质中肽键的氨基酸残基种类有选择性，而对具体的底物蛋白质种类无严格要求（图2-5）。

:::definition{label="相对特异性"}
某种酶可以作用于一类化合物或一种化学键、催化一类化学反应，称为相对特异性（relative specificity）。
:::

:::example{label="磷酸酶、脂肪酶、蔗糖酶、消化道蛋白酶"}
磷酸酶水解一般的磷酸酯键，甘油或酚与磷酸形成的酯键都可以。脂肪酶既水解脂肪，也水解简单酯类。蔗糖酶既水解蔗糖，也水解棉子糖中的同一种糖苷键。消化道蛋白酶只对肽键两侧氨基酸残基种类有选择，对蛋白质是哪一种没有严格要求。
:::

:::note{label="图2-5 电子版缺失"}
教材图2-5 为消化道中各种蛋白酶对肽键的专一性：在多肽链上标出胰蛋白酶、胰凝乳蛋白酶、弹性蛋白酶等各自偏好的断裂位点。数字切片 `p0067_02.png` 为 $0$ 字节，本节不引用该文件。正文中“对残基种类有选择、对蛋白质种类无严格要求”仍按教材保留。下一节图2-9 的口袋形状，正是这一专一性的结构注脚。
:::

:::compare{title="绝对特异性、立体异构特异性、相对特异性"}
| 项目 | 绝对特异性 | 立体异构特异性 | 相对特异性 |
|------|------------|----------------|------------|
| 选择严格程度 | 只认特定结构的底物，做一种专一反应 | 绝对特异性里对立体异构体再加一刀 | 认一类化合物或一种化学键 |
| 教材例子 | 脲酶只水解尿素；琥珀酸脱氢酶只做琥珀酸 $\rightleftharpoons$ 延胡索酸 | 乳酸脱氢酶只认 $\mathrm{L}$-乳酸；延胡索酸酶只认反-丁烯二酸 | 磷酸酶、脂肪酶、蔗糖酶、消化道蛋白酶 |
| 不认什么 | 甲基尿素等结构类似物 | $\mathrm{D}$-乳酸、马来酸 | 不是“什么键都切”，仍有化学键或残基种类的选择 |
:::

:::concept{term="先问认的是一种分子还是一类键，再问要不要立体构型"}
看见“专一性”，先不要只背“酶很专一”。绝对特异性是一种底物、一种反应；其中再对 $\mathrm{L}/\mathrm{D}$、顺／反加限制，叫立体异构特异性。相对特异性是一类化合物或一种化学键。把胰蛋白酶听成绝对特异性，或把脲酶听成“所有酰胺都能水解”，图2-5 和图2-9 会对错口袋。
:::

### （三）酶具有可调节性

体内许多酶的酶活性和酶的含量受体内代谢物或激素的调节。例如，磷酸果糖激酶-1 的活性受 $\mathrm{AMP}$ 的别构激活，而受 $\mathrm{ATP}$ 的别构抑制。有些酶的合成受物质的诱导或阻遏，从而改变细胞内的酶量。例如，胰岛素诱导 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶的合成，而胆固醇则阻遏该酶合成。机体通过对酶的活性与酶量的调节使得体内代谢过程受到精确调控，以使机体适应内外环境的不断变化。

:::definition{label="酶的可调节性"}
体内许多酶的活性和含量受代谢物或激素调节。活性侧如别构激活／抑制；含量侧如诱导或阻遏合成。通过对活性与酶量的调节，代谢过程受到精确调控，以适应内外环境变化。
:::

:::example{label="活性调节与酶量调节各举一例"}
磷酸果糖激酶-1：$\mathrm{AMP}$ 别构激活，$\mathrm{ATP}$ 别构抑制——改的是现有酶的活性。$\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶：胰岛素诱导其合成，胆固醇阻遏其合成——改的是酶量。第四节才把别构、化学修饰、酶原展开；本节先立“可调节”这一特点。
:::

:::pitfall{label="可调节性先分活性和酶量，不要并成一句别构"}
教材这里写了两本账：活性（别构等）和酶量（诱导／阻遏）。把胆固醇阻遏 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶合成听成别构抑制，第四节的快速调节与慢速调节会对错时间尺度。
:::

### （四）酶具有不稳定性

酶的化学本质是蛋白质。在某些理化因素（如高温、强酸、强碱等）的作用下，酶会发生变性而失去催化活性。因此，酶促反应往往都是在常温、常压和接近中性的条件下进行的。

:::definition{label="酶的不稳定性"}
酶的化学本质是蛋白质。高温、强酸、强碱等理化因素可使酶变性而失去催化活性。酶促反应往往在常温、常压和接近中性的条件下进行。
:::

:::cause-effect{title="为什么酶促反应条件温和"}
- **因** 酶是蛋白质，高温、强酸、强碱会使其变性失活
- **果** 酶促反应往往在常温、常压、接近中性的条件下进行；第三节的最适温度、最适 $\mathrm{pH}$ 都从这里长出来
:::

:::compare{title="酶不同于一般催化剂的四条"}
| 特点 | 教材落点 | 一般催化剂做不到或不必这样 |
|------|----------|------------------------------|
| 催化效率极高 | 比非催化高 $10^{8}\sim 10^{20}$ 倍，比一般催化剂高 $10^{7}\sim 10^{13}$ 倍 | 同反应、同温度下远达不到这个数量级 |
| 高度特异性 | 绝对、立体异构、相对三级 | 酸、碱、金属离子往往一类反应都能做 |
| 可调节性 | 活性（别构等）与酶量（诱导／阻遏） | 一般催化剂没有代谢物／激素这套调节 |
| 不稳定性 | 变性即失活，条件必须温和 | 常在高温、强酸、强碱下工作 |
:::

## 二、酶通过促进底物形成过渡态而提高反应速率

### （一）酶比一般催化剂更有效地降低反应的活化能

化学反应中，由于反应物分子所含的能量高低不一，所含自由能较低的反应物分子，很难发生化学反应。只有那些达到或超过一定能量水平的分子，才有可能发生相互碰撞并进入化学反应过程，这样的分子称为活化分子。在酶催化反应中，酶与底物或底物类似物间，将低自由能的反应物分子（基态）瞬时生成具有高自由能的不稳定状态复合物，称为过渡态（transition state）分子。活化能（activation energy）是指在一定温度下，$1\,\mathrm{mol}$ 反应物从基态转变成过渡态所需要的自由能，即过渡态中间物与基态反应物间的能量差。活化能是决定化学反应速率的内因，是化学反应的能障（energy barrier）。欲使反应速率加快，给予反应物活化能（如加热）或降低反应的活化能，均能使基态反应物转化为过渡态。酶与一般催化剂一样，通过降低反应的活化能，从而提高反应速率。但酶能使其底物分子获得更少的能量便可进入过渡态（图2-6）。据计算，在 $25\,^{\circ}\mathrm{C}$ 时活化能每减少 $4.184\,\mathrm{kJ/mol}$，反应速率可增高 $5.4$ 倍。衍生于酶与底物相互作用的能量叫做结合能（binding energy），这种结合能的释放是酶降低反应活化能所利用的自由能的主要来源。

:::definition{label="活化分子"}
只有达到或超过一定能量水平、才有可能相互碰撞并进入化学反应过程的分子，称为活化分子。自由能较低的反应物分子很难发生反应。
:::

:::definition{label="过渡态"}
在酶催化反应中，酶与底物或底物类似物把低自由能的反应物分子（基态）瞬时生成具有高自由能的不稳定状态复合物，称为过渡态（transition state）分子。
:::

:::definition{label="活化能"}
活化能（activation energy）是一定温度下，$1\,\mathrm{mol}$ 反应物从基态转变成过渡态所需要的自由能，即过渡态中间物与基态反应物间的能量差。它是决定化学反应速率的内因，是化学反应的能障（energy barrier）。
:::

:::definition{label="结合能"}
衍生于酶与底物相互作用的能量叫做结合能（binding energy）。结合能的释放是酶降低反应活化能所利用的自由能的主要来源。
:::

:::keypoint{label="加快反应的两条路：给活化能，或降低活化能"}
- 加热等：给反应物活化能，让更多分子达到过渡态。
- 催化剂／酶：降低活化能。酶比一般催化剂降得更多，底物获得更少能量即可进入过渡态。
- $25\,^{\circ}\mathrm{C}$ 时活化能每减少 $4.184\,\mathrm{kJ/mol}$，反应速率增高 $5.4$ 倍。
:::

::figure{src="/images/biochemistry/textbook/p0068_02.png" caption="图2-6　酶促反应活化能的变化。纵轴为能量，横轴为反应过程；酶与底物结合生成过渡态时释放结合能，使酶促反应活化能低于一般催化反应和非催化反应，反应总能量改变不变。" alt="能量对反应过程曲线：最高峰标过渡态；三条下降曲线分别对应非催化、一般催化和酶促反应活化能；左侧标结合能，右侧标反应总能量改变"}

:::insight{label="图2-6 三条峰，平衡点那一头一样高"}
非催化反应活化能最高，一般催化剂居中，酶促反应最低。峰降低的那截，教材写成酶与底物结合生成过渡态时释放的结合能。产物平均能量相对底物平均能量的差——反应总能量改变——三条曲线共用，呼应“不改变平衡点”。
:::

:::pitfall{label="结合能是降活化能的自由能来源，不是把反应变成放热更多"}
结合能来自酶与底物相互作用，用来支付降低活化能。$\Delta G$ 那一头（反应总能量改变）不变。把结合能听成“酶另外提供一份能量把平衡推向产物”，共同点那一句就被改写了。
:::

### （二）酶与底物结合形成中间复合物

酶催化底物反应中，酶首先与底物结合形成的过渡态中间物，即酶-底物复合物（enzyme-substrate complex），可转化成产物和酶。酶与底物结合的过程释放结合能，是降低反应活化能的主要能量来源。酶活性部位的结合基团能否有效地与底物结合，并将底物转化为过渡态，是酶能否发挥其催化作用的关键。

:::definition{label="酶-底物复合物"}
酶首先与底物结合形成过渡态中间物，即酶-底物复合物（enzyme-substrate complex），再转化成产物和酶。结合过程释放结合能，是降低活化能的主要能量来源。
:::

:::concept{term="先问结合基团能不能把底物送进过渡态，再问后面怎么断键"}
活性部位的结合基团能否有效结合底物、并将底物转化为过渡态，是催化能不能发生的关键。第一节的结合基团、催化基团在这里会合：先形成 $\mathrm{ES}$，再谈酸碱催化和共价催化。把“中间复合物”听成已经是产物，米氏方程里的 $[\mathrm{ES}]$ 会没有物理图像。
:::

$1958$ 年，Koshland D.E. 提出酶-底物结合的诱导契合学说（induced-fit theory），认为酶分子的构象与其所催化的底物结构并非完全吻合，与底物分子结合时，酶与底物的结构相互诱导、相互形变、相互适应，进而使酶活性中心与底物紧密结合形成酶-底物复合物（图2-7），从而发挥催化功能。此假说后来得到 $\mathrm{X}$ 射线衍射分析的有力支持。诱导契合作用使得具有相对特异性的酶能够结合一组结构并不完全相同的底物分子，酶构象的变化有利于其与底物结合，并使底物转变为不稳定的过渡态，易受酶的催化攻击而转化为产物。

:::definition{label="诱导契合学说"}
$1958$ 年 Koshland D.E. 提出诱导契合学说（induced-fit theory）：酶分子的构象与其所催化的底物结构并非完全吻合；结合时酶与底物相互诱导、相互形变、相互适应，使活性中心与底物紧密结合形成酶-底物复合物，从而发挥催化功能。该假说后来得到 $\mathrm{X}$ 射线衍射分析的有力支持。
:::

::figure{src="/images/biochemistry/textbook/p0068_01.png" caption="图2-7　酶与底物结合的诱导契合作用。底物与酶的裂缝并非事先完全吻合；结合后双方形变，形成紧密的酶-底物复合物。" alt="左侧灰色酶分子带不规则裂缝，上方蓝色底物形状不完全匹配；箭头指向右侧酶-底物复合物，底物嵌入裂缝并相互贴合"}

:::insight{label="诱导契合解释相对特异性：口袋可以迁就一组不完全相同的底物"}
酶构象变化既利于结合，也使底物变成不稳定过渡态，易受催化攻击。相对特异性那一组“一类键、一类化合物”，靠的不是锁和钥匙事先铸死，而是相互形变。把诱导契合听成“酶完全被动被底物揉圆”，催化基团那一笔会丢。
:::

:::timeline{period="中间复合物与诱导契合"}
- **1958** Koshland 提出诱导契合：酶与底物并非事先完全吻合，结合时相互诱导、形变、适应
- **随后** X 射线衍射分析给予有力支持
- **落到催化** 构象变化利于结合，并把底物推进过渡态
:::

### （三）酶催化机制有邻近效应、定向排列、表面效应，并呈现多元催化

#### 1. 邻近效应与定向排列使诸底物正确定位于酶的活性中心

在两个以上底物参加的反应中，酶将诸底物结合到酶的活性中心，使它们相互接近并形成有利于反应的正确定向关系（图2-8）。这种邻近效应（proximity effect）与定向排列（orientation arrangement）实际上是将分子间的反应变成类似于分子内的反应，从而提高反应速率。

:::definition{label="邻近效应与定向排列"}
在两个以上底物参加的反应中，酶将诸底物结合到活性中心，使它们相互接近并形成有利于反应的正确定向关系。邻近效应（proximity effect）与定向排列（orientation arrangement）把分子间反应变成类似于分子内的反应，从而提高反应速率。
:::

:::note{label="图2-8 电子版缺失"}
教材图2-8 为酶与底物的邻近效应与定向排列：两个底物被拉进活性中心，相互靠近并按反应所需取向排列。数字切片 `p0069_01.png` 为 $0$ 字节，本节不引用该文件。正文中“分子间变成类似于分子内”仍按教材保留。
:::

:::cause-effect{title="邻近加定向为什么能加速"}
- **因** 酶把两个以上底物拉到活性中心，既靠近又取向正确
- **果** 分子间反应变成类似于分子内反应，碰撞的有效性和频率提高，反应速率提高
:::

#### 2. 表面效应使底物分子去溶剂化

酶的活性中心多形成疏水“口袋”（图2-9），酶促反应在此疏水环境中进行，使底物分子去溶剂化（desolvation），排除周围大量水分子对酶和底物分子中功能基团的干扰性吸引和排斥，防止水化膜的形成，利于底物与酶分子的密切接触和结合，这种现象称为表面效应（surface effect）。

:::definition{label="表面效应"}
酶促反应在活性中心的疏水环境中进行，使底物分子去溶剂化（desolvation）：排除周围大量水分子对酶和底物功能基团的干扰性吸引和排斥，防止水化膜形成，利于底物与酶密切接触和结合。这种现象称为表面效应（surface effect）。
:::

::figure{src="/images/biochemistry/textbook/p0069_02.png" caption="图2-9　胰蛋白酶、胰凝乳蛋白酶和弹性蛋白酶与底物结合时的“口袋”状活性中心。胰蛋白酶口袋底部 Asp189 吸引带正电侧链；胰凝乳蛋白酶口袋宽而疏水，容纳芳香环；弹性蛋白酶入口被 Val216、Val190 等堵塞，只容小侧链。" alt="三个口袋剖面：左为胰蛋白酶，Asp189 带负电对正电侧链；中为胰凝乳蛋白酶，Ser189 配芳香环；右为弹性蛋白酶，Val190、Ser189 等限制小侧链进入"}

:::insight{label="图2-9 三个丝氨酸蛋白酶，口袋形状就是相对特异性"}
三者都是水解肽键，但口袋不同：胰蛋白酶底部有 $\mathrm{Asp}189$，认带正电的赖氨酸、精氨酸侧链；胰凝乳蛋白酶口袋宽而疏水，认芳香侧链；弹性蛋白酶入口被较大残基挡住，只容小侧链。图2-5 的“对残基种类有选择”在这里看见结构。疏水口袋同时提供表面效应的环境。
:::

#### 3. 多元催化可提高催化效率

酶具有两性解离性质，酶分子含有多种功能基团，具有各不相同的解离常数。酶活性中心上有些基团是质子供体（酸），有些基团是质子受体（碱）（表2-5），因此兼有酸、碱双重催化作用。这种多功能基团的协同作用，可实现多元催化（multielement catalysts）。

:::definition{label="多元催化"}
酶具有两性解离性质，活性中心上有些基团是质子供体（酸），有些是质子受体（碱），兼有酸、碱双重催化作用。多功能基团的协同作用，可实现多元催化（multielement catalysts）。
:::

**表2-5　酶分子中具有酸-碱催化作用的基团**

| 氨基酸残基 | 酸（质子供体） | 碱（质子受体） |
|------------|----------------|----------------|
| 天冬氨酸、谷氨酸 | $\mathrm{R}$-$\mathrm{COOH}$ | $\mathrm{R}$-$\mathrm{COO}^{-}$ |
| 赖氨酸 | $\mathrm{R}$-$\mathrm{NH}_3^{+}$ | $\mathrm{R}$-$\mathrm{NH}_2$ |
| 精氨酸 | 质子化胍基 | 去质子胍基 |
| 半胱氨酸 | $\mathrm{R}$-$\mathrm{SH}$ | $\mathrm{R}$-$\mathrm{S}^{-}$ |
| 组氨酸 | 质子化咪唑 | 去质子咪唑 |
| 丝氨酸 | $\mathrm{R}$-$\mathrm{OH}$ | $\mathrm{R}$-$\mathrm{O}^{-}$ |
| 酪氨酸 | 酚羟基 | 酚氧负离子 |

:::note{label="酸碱催化看的是同一基团的两种解离态"}
表2-5 每一行是同一残基：多一个质子是酸，少一个质子是碱。组氨酸咪唑的 $\mathrm{p}K_\mathrm{a}$ 接近生理 $\mathrm{pH}$，最常兼做酸和碱。第三节最适 $\mathrm{pH}$ 正是在问：这些基团处在哪一种解离态。
:::

当酶分子催化底物反应时，它可通过其活性中心上的亲核催化基团给底物中具有部分正电性的原子提供一对电子形成共价中间物（亲核催化），或通过其酶活性中心上的亲电子催化基团与底物分子的亲核原子形成共价中间物（亲电子催化），使底物上被转移基团传递给其辅酶或另外一个底物。许多酶催化的基团转移反应都是通过共价催化方式进行的。例如，胰凝乳蛋白酶 $195$ 位丝氨酸残基的 $-\mathrm{OH}$ 是该酶活性中心的催化基团，当底物结合在酶上后，由于此 $-\mathrm{OH}$ 基团中 $\mathrm{O}$ 原子含有孤对电子，在 $57$ 位组氨酸残基碱催化的帮助下，能对底物蛋白肽键中羰基 $\mathrm{C}$（具有部分正电性）进行亲核攻击，导致肽键的断裂，形成一个不稳定的中间产物——酰基化酶，后者易将酰基转移给水完成水解作用（图2-10）。

:::definition{label="共价催化"}
酶可通过活性中心上的亲核催化基团，给底物中具有部分正电性的原子提供一对电子形成共价中间物（亲核催化）；或通过亲电子催化基团与底物的亲核原子形成共价中间物（亲电子催化），使被转移基团传递给辅酶或另一个底物。许多基团转移反应都走共价催化。
:::

:::definition{label="亲核催化与亲电子催化"}
亲核催化：酶的亲核基团向底物部分正电性原子提供电子对，成共价中间物。亲电子催化：酶的亲电子基团与底物亲核原子成共价中间物。
:::

:::example{label="胰凝乳蛋白酶：Ser195 亲核，His57 做碱"}
$\mathrm{Ser}195$ 的 $-\mathrm{OH}$ 是催化基团。$\mathrm{O}$ 上有孤对电子，在 $\mathrm{His}57$ 碱催化帮助下，对底物肽键羰基 $\mathrm{C}$（部分正电性）亲核攻击，肽键断裂，生成不稳定的酰基化酶；酰基再转移给水，完成水解。这是酸碱催化与共价催化写在同一次反应里。
:::

::figure{src="/images/biochemistry/textbook/p0070_01.png" caption="图2-10　胰凝乳蛋白酶的催化机制。His57 作为碱协助 Ser195 的氧对肽键羰基碳亲核攻击，生成酰基化酶中间物，再经水解释放羧酸，酶恢复。" alt="三步示意图：左为 His57、Ser195 对底物肽键协同进攻；中为酰基化酶，羰基碳连在 Ser195 的氧上，胺离去；右为水解后羧酸释放，His57 和 Ser195 复原"}

:::derivation{title="胰凝乳蛋白酶把肽键水解拆成两步"}
底物结合后：

1. $\mathrm{His}57$ 作为碱，从 $\mathrm{Ser}195$ 的羟基取质子；$\mathrm{Ser}195$ 的氧对肽键羰基碳亲核攻击，肽键断裂，胺离去，酶被酰基化。
2. 水在 $\mathrm{His}57$ 协助下进攻酰基化酶，酰基转移到水上，羧酸释放，酶恢复。

第一步是共价催化（酰基化中间物），两步都有酸碱催化。图2-10 从左到右就是这两步。
:::

:::compare{title="邻近定向、表面效应、酸碱催化、共价催化"}
| 机制 | 干什么 | 教材落点 |
|------|--------|----------|
| 邻近效应与定向排列 | 把两个以上底物拉到活性中心，靠近并取向正确 | 分子间反应变成类似于分子内反应 |
| 表面效应 | 疏水口袋里去溶剂化 | 排除水分子干扰，防止水化膜，利于密切结合 |
| 酸碱催化（多元催化的一部分） | 活性中心兼有质子供体和受体 | 表2-5 各残基的两种解离态协同 |
| 共价催化 | 形成共价中间物再完成基团转移 | 胰凝乳蛋白酶 $\mathrm{Ser}195$ 酰基化酶 |
:::

:::pitfall{label="多元催化不是“很多种酶一起催化”，共价中间物也不是产物"}
多元催化指同一酶活性中心上多种功能基团协同，兼有酸碱双重催化。共价催化的酰基化酶是中间物，还要把酰基交给水或另一个受体。把图2-10 的中间帧听成“酶被消耗了”，共同点“反应前后质和量不变”会被推翻。
:::

:::memory{label="本节必背要点"}
- [ ] 酶与一般催化剂相同：反应前后质和量不变；只催化热力学允许的反应；不改变平衡点和平衡常数。
- [ ] 酶的四条特点：催化效率极高、高度特异、可调节、不稳定。
- [ ] 效率：比非催化高 $10^{8}\sim 10^{20}$ 倍，比一般催化剂高 $10^{7}\sim 10^{13}$ 倍；$\mathrm{H}_2\mathrm{O}_2$ 分解活化能无催化剂 $75\,312$、胶体钯 $48\,953$、过氧化氢酶 $8\,368\,\mathrm{J/mol}$。
- [ ] 绝对特异性：脲酶只水解尿素；琥珀酸脱氢酶只做琥珀酸 $\rightleftharpoons$ 延胡索酸。
- [ ] 立体异构特异性：只认 $\mathrm{L}$-氨基酸、$\mathrm{L}$-乳酸、反-丁烯二酸。
- [ ] 相对特异性：一类化合物或一种化学键；消化道蛋白酶认残基种类、不认蛋白质种类。
- [ ] 可调节：活性（如 $\mathrm{PFK}$-1 的 $\mathrm{AMP}$／$\mathrm{ATP}$ 别构）与酶量（如 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶的诱导／阻遏）。
- [ ] 不稳定：蛋白质变性即失活，故常温、常压、近中性。
- [ ] 过渡态是高自由能不稳定复合物；活化能是基态到过渡态的自由能差，是能障。
- [ ] 酶比一般催化剂更有效降低活化能；$25\,^{\circ}\mathrm{C}$ 活化能每少 $4.184\,\mathrm{kJ/mol}$，速率高 $5.4$ 倍；结合能是降活化能的主要自由能来源。
- [ ] 先形成酶-底物复合物；结合基团能否把底物送进过渡态是关键。
- [ ] $1958$ 年 Koshland 诱导契合：相互诱导、形变、适应；解释相对特异性。
- [ ] 邻近效应与定向排列：分子间变成类似于分子内。
- [ ] 表面效应：疏水口袋去溶剂化。
- [ ] 多元催化：酸碱双重；共价催化走共价中间物；胰凝乳蛋白酶 $\mathrm{Ser}195$ 亲核、$\mathrm{His}57$ 做碱，经酰基化酶水解肽键。
:::
