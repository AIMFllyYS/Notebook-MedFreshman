# 第四节　真核生物DNA复制过程

前三节把复制写成半保留、双向、半不连续，并把原核的 $\mathrm{oriC}$、$\mathrm{DnaA}/\mathrm{DnaB}/\mathrm{DnaC}$、$\mathrm{DNA}\ \mathrm{pol}$ Ⅲ 和连接酶立成一套机器。本节换到真核：复制只在细胞周期的 $\mathrm{DNA}$ 合成期（$\mathrm{S}$ 期）进行，染色体是线性的、核小体挡路、复制起点成千、末端还要端粒酶。基本机制仍是解开双链、$\mathrm{RNA}$ 引物、前导链与后随链，但基因组庞大、有核小体，反应体系、过程和调节都更复杂。线粒体 $\mathrm{DNA}$ 不走核染色体这本账，按 $\mathrm{D}$ 环复制，放在本节第六部分。逆转录留给第五节。

:::concept{term="先问是不是 S 期、有几个复制子，再问末端谁来补、每个周期复制几次"}
看见“真核复制”，不要先背端粒酶。户头是：$\mathrm{S}$ 期、多染色体、每条染色体上千个复制子、分组激活而不是同步启动。延长要聚合酶转换，合成后立刻装核小体。线性末端的空隙交给端粒酶的爬行模型。每个细胞周期只复制一次，靠 $\mathrm{G}_1$ 装配 $\mathrm{pre}$-$\mathrm{RC}$、$\mathrm{S}$ 期 $\mathrm{CDK}2$ 再激活。$\mathrm{mtDNA}$ 是另一套 $\mathrm{D}$ 环。
:::

真核生物的基因组复制在细胞分裂周期的 $\mathrm{DNA}$ 合成期（$\mathrm{S}$ 期）进行。细胞周期进程在体内受到微环境中的增殖信号、营养条件等诸多因素影响，多种蛋白质因子和酶控制细胞进入 $\mathrm{S}$ 期的时机和 $\mathrm{DNA}$ 合成的速度。真核生物 $\mathrm{DNA}$ 合成的基本机制和特征与原核生物相似，但是由于基因组庞大及核小体的存在，反应体系、反应过程和调节均更为复杂。

:::definition{label="S 期"}
真核生物基因组复制发生在细胞分裂周期的 $\mathrm{DNA}$ 合成期（$\mathrm{S}$ 期）。进入 $\mathrm{S}$ 期的时机和合成速度，由增殖信号、营养条件以及多种蛋白质因子和酶共同控制。
:::

:::definition{label="真核复制与原核相似但不等于同一套机器"}
基本机制和特征相似：仍要解开双链、形成复制叉、合成 $\mathrm{RNA}$ 引物、前导链连续、后随链不连续。更复杂的原因教材点了两句：基因组庞大，以及核小体的存在。第三节的 $\mathrm{oriC}$、$\mathrm{DnaA}$ 和 $\mathrm{DNA}\ \mathrm{pol}$ Ⅲ 不能原样搬过来。
:::

:::insight{label="S 期不是“复制速度由聚合酶单独决定”"}
教材把增殖信号和营养条件写在酶的前面。原核培养条件改变复制速度，真核还要加上器官组织、发育时期和生理状况。后文“酶的催化速率约 $50$ 个 $\mathrm{dNTP}/\mathrm{s}$、总体却不慢”，靠的是多复制子，不是把单个酶写成原核那么快。
:::

:::pitfall{label="不要把真核复制听成“整个细胞周期都在合成 DNA”"}
复制仅仅出现在 $\mathrm{S}$ 期，而且每个细胞周期只能复制一次。这是本节第五部分的主题。$\mathrm{G}_1$ 装配的是尚未激活的前复制复合物，$\mathrm{G}_2$ 到 $\mathrm{M}$ 期是复制完成后组装染色体、准备分裂。把“细胞周期里一直在复制”当成常识，许可复制和端粒问题都会没户头。
:::

:::compare{title="本节六块各自问什么"}
| 部分 | 教材原句要抓住的点 |
|------|---------------------|
| 一、起始 | 多染色体、上千复制子、时序性；酵母 $\mathrm{ARS}$；$11\,\mathrm{bp}$ 富 $\mathrm{AT}$；$\mathrm{pol}\ \alpha/\varepsilon/\delta$、复制因子、$\mathrm{PCNA}$ |
| 二、延长 | 聚合酶转换：$\alpha$ 做引物，$\delta$ 后随链，$\varepsilon$ 前导链；冈崎片段约一个核小体 $135\,\mathrm{bp}$ |
| 三、核小体 | 合成后立即组装；破坏只在复制叉紧邻短区；旧组蛋白大部分可重新装上 |
| 四、端粒 | 末端引物去掉留下空隙；端粒 $\mathrm{TxGy}$；端粒酶 $\mathrm{hTR}/\mathrm{hTP}1/\mathrm{hTRT}$；爬行模型 |
| 五、一次复制 | $\mathrm{G}_1$ 选择复制基因、装 $\mathrm{pre}$-$\mathrm{RC}$；$\mathrm{S}$ 期 $\mathrm{CDK}2$ 激活起点 |
| 六、$\mathrm{D}$ 环 | $\mathrm{mtDNA}$ 闭合环状；内外环起点不在同一位点；$\mathrm{DNA}\ \mathrm{pol}\ \gamma$ |

逆转录、前病毒、$\mathrm{cDNA}$ 是第五节的账，不要并进核染色体复制。
:::

## 一、真核生物DNA复制的起始与原核生物不同

真核生物 $\mathrm{DNA}$ 分布在许多染色体上，各自进行复制。每个染色体有上千个复制子，复制的起点很多。复制有时序性，即复制子以分组方式激活而不是同步启动。转录活性高的 $\mathrm{DNA}$ 在 $\mathrm{S}$ 期早期就进行复制。高度重复的序列如卫星 $\mathrm{DNA}$、连接染色体双倍体的部位即着丝粒（centromere）和线性染色体两端即端粒（telomere）都是在 $\mathrm{S}$ 期的最后阶段才复制的。

:::definition{label="多起点、多复制子"}
真核 $\mathrm{DNA}$ 分布在许多染色体上，各自复制。每个染色体有上千个复制子，复制起点很多。这是相对大肠埃希氏杆菌一个 $\mathrm{oriC}$ 的反差，也是后文“酶慢、总体不慢”的结构基础。
:::

:::definition{label="复制的时序性"}
复制子以分组方式激活，而不是同步启动。转录活性高的 $\mathrm{DNA}$ 在 $\mathrm{S}$ 期早期复制；卫星 $\mathrm{DNA}$、着丝粒和端粒在 $\mathrm{S}$ 期最后阶段才复制。
:::

:::definition{label="着丝粒"}
着丝粒（centromere）是连接染色体双倍体的部位。本节只把它写成“高度重复、$\mathrm{S}$ 期末才复制”的区段，不展开动粒结构。
:::

:::definition{label="端粒（作为晚复制区）"}
端粒（telomere）是线性染色体两端。在起始这一段，教材先把它和卫星 $\mathrm{DNA}$、着丝粒并列：都是高度重复、$\mathrm{S}$ 期末才复制。形态、$\mathrm{TxGy}$ 重复和端粒酶，第四部分再立户。
:::

:::keypoint{label="谁早复制、谁晚复制"}
- 早：转录活性高的 $\mathrm{DNA}$。
- 晚：卫星 $\mathrm{DNA}$、着丝粒、端粒。
- 中间：其余复制子分组激活，不是全基因组同时开火。
:::

:::pitfall{label="上千个复制子不是“一条染色体一个起点乘以染色体数”"}
教材写的是每个染色体有上千个复制子。人有多条染色体，起点总数是“染色体数 $\times$ 每条上千”，不是“ haploid 染色体条数个起点”。把真核起点听成“每条染色体一个 $\mathrm{oriC}$”，多复制子补速度、半个复制子限制前导链长度，都对不上。
:::

:::insight{label="转录活性高的区段早复制，是时序性的具体例子"}
不是“重要的基因先复制”这种口语。教材的判据是转录活性。高度重复、着丝粒、端粒这些结构区放到 $\mathrm{S}$ 期末。复习时把“早／晚”和第五部分“每个起点每个周期只用一次”分开：时序解决的是先后，许可复制解决的是次数。
:::

真核生物复制起点序列较大肠埃希氏杆菌 $\mathrm{oriC}$ 复杂。酵母 $\mathrm{DNA}$ 复制起点含 $11\,\mathrm{bp}$ 富含 $\mathrm{AT}$ 的核心序列：$\mathrm{A}(\mathrm{T})\mathrm{TTTATA}(\mathrm{G})\mathrm{TTTA}(\mathrm{T})$，称为自主复制序列（autonomous replication sequence，$\mathrm{ARS}$）。也发现比 $E.\ coli$ 的 $\mathrm{oriC}$ 序列长的真核生物复制起点。

:::definition{label="自主复制序列 ARS"}
酵母 $\mathrm{DNA}$ 复制起点含 $11\,\mathrm{bp}$ 富含 $\mathrm{AT}$ 的核心序列 $\mathrm{A}(\mathrm{T})\mathrm{TTTATA}(\mathrm{G})\mathrm{TTTA}(\mathrm{T})$，称为自主复制序列（$\mathrm{ARS}$）。这是本版给出的真核起点序列实例。
:::

:::compare{title="oriC 与真核起点不要并成一个词"}
| | 大肠埃希氏杆菌 $\mathrm{oriC}$（第三节） | 真核起点（本节） |
|--|------------------------------------------|------------------|
| 数量 | 基因组上一个固定起点 | 每条染色体上千个复制子 |
| 序列 | 跨度 $245\,\mathrm{bp}$；含 $3$ 个 $13\,\mathrm{bp}$ 串联重复（$\mathrm{DUE}$，富 $\mathrm{AT}$）和 $5$ 个 $9\,\mathrm{bp}$ 重复（$\mathrm{R}$ 位点） | 较 $\mathrm{oriC}$ 复杂；酵母核心仅 $11\,\mathrm{bp}$ 富 $\mathrm{AT}$ 的 $\mathrm{ARS}$；也有比 $\mathrm{oriC}$ 更长的起点 |
| 辨认蛋白 | $\mathrm{DnaA}$ | 第五部分的 $\mathrm{ORC}$（功能类似 $\mathrm{DnaA}$） |

富 $\mathrm{AT}$ 容易解链这一条两边都成立。不要把酵母 $11\,\mathrm{bp}$ 核心写成“真核起点只有 $11\,\mathrm{bp}$”。
:::

:::pitfall{label="ARS 是酵母核心，不是所有真核起点的长度"}
教材紧接着写：也发现比 $E.\ coli$ 的 $\mathrm{oriC}$ 序列长的真核生物复制起点。$\mathrm{oriC}$ 已经是 $245\,\mathrm{bp}$。把 $\mathrm{ARS}$ 听成“人的复制起点就是 $11\,\mathrm{bp}$”，和“较大肠埃希氏杆菌 $\mathrm{oriC}$ 复杂”那句会打架。
:::

真核生物复制起始也是打开双链形成复制叉，形成引发体和合成 $\mathrm{RNA}$ 引物。但详细的机制，包括酶及各种辅助蛋白质起作用的先后顺序，尚未完全明了。

复制的起始需要 $\mathrm{DNA}\ \mathrm{pol}\ \alpha$、$\mathrm{pol}\ \varepsilon$ 和 $\mathrm{pol}\ \delta$ 的参与（表14-3）。此外还需解旋酶、拓扑酶和复制因子（replication factor，$\mathrm{RF}$），如 $\mathrm{RFA}$、$\mathrm{RFC}$ 等。

:::definition{label="真核复制起始仍要复制叉和 RNA 引物"}
打开双链形成复制叉，形成引发体，合成 $\mathrm{RNA}$ 引物。与原核相同的是这三件事；不同的是酶和辅助蛋白的先后顺序，教材写明尚未完全明了。
:::

:::definition{label="起始需要的三类 DNA 聚合酶"}
起始需要 $\mathrm{DNA}\ \mathrm{pol}\ \alpha$、$\mathrm{pol}\ \varepsilon$ 和 $\mathrm{pol}\ \delta$（表14-3）。第二节把它们的分工写成：$\alpha$ 是引发酶，$\varepsilon$ 合成前导链，$\delta$ 合成后随链。本节第二部分用“聚合酶转换”把这三户接起来。
:::

:::definition{label="复制因子 RF"}
除聚合酶外，起始还需解旋酶、拓扑酶和复制因子（$\mathrm{RF}$），教材点名 $\mathrm{RFA}$、$\mathrm{RFC}$ 等。$\mathrm{RFC}$ 的具体动作在 $\mathrm{PCNA}$ 那一段：把 $\mathrm{PCNA}$ 加载到引物－模板链上。
:::

:::insight{label="“尚未完全明了”不是“没有酶名单”"}
教材先承认先后顺序未完全清楚，紧接着仍列出 $\mathrm{pol}\ \alpha/\varepsilon/\delta$、解旋酶、拓扑酶、$\mathrm{RFA}$、$\mathrm{RFC}$、$\mathrm{PCNA}$。考试默写按已点名的分子走，不要把“尚未明了”答成“真核起始机制未知、无法作答”。
:::

:::compare{title="表14-3 里本节真正用到的真核聚合酶"}
| 酶 | 表14-3 的功能栏 | 本节怎么用 |
|----|-----------------|------------|
| $\mathrm{DNA}\ \mathrm{pol}\ \alpha$ | 引发酶 | 主要催化合成引物；后随链到核小体单位之末时再引发下游引物 |
| $\mathrm{DNA}\ \mathrm{pol}\ \varepsilon$ | 前导链合成 | 聚合酶转换后负责前导链 |
| $\mathrm{DNA}\ \mathrm{pol}\ \delta$ | 后随链合成 | 聚合酶转换后负责后随链；$\mathrm{PCNA}$ 使它获得持续合成能力 |
| $\mathrm{DNA}\ \mathrm{pol}\ \gamma$ | 线粒体 $\mathrm{DNA}$ 合成 | 第六部分 $\mathrm{D}$ 环复制的聚合酶 |
| $\mathrm{DNA}\ \mathrm{pol}\ \beta$ | $\mathrm{DNA}$ 修复 | 本节复制过程不调用；第二节写它保真度低、参与应急修复 |

原核对照：$\mathrm{I}$ 去除引物并填空隙，$\mathrm{II}$ 校对和修复，$\mathrm{III}$ 前导链／延长。真核去掉引物的是 $\mathrm{FEN}1$ 和 $\mathrm{RNase}\ \mathrm{H}$，不要把 $\mathrm{pol}\ \mathrm{I}$ 的活直接安在 $\mathrm{pol}\ \alpha$ 上。
:::

增殖细胞核抗原（proliferation cell nuclear antigen，$\mathrm{PCNA}$）在复制起始和延长中发挥关键作用。$\mathrm{PCNA}$ 为同源三聚体，具有与 $E.\ coli$ $\mathrm{DNA}\ \mathrm{pol}$ Ⅲ 的 $\beta$ 亚基相同的功能和相似的构象，即形成闭合环形的可滑动的 $\mathrm{DNA}$ 夹子，在 $\mathrm{RFC}$ 的作用下 $\mathrm{PCNA}$ 结合于引物－模板链；并且 $\mathrm{PCNA}$ 使 $\mathrm{pol}\ \delta$ 获得持续合成的能力。$\mathrm{PCNA}$ 尚具有促进核小体生成的作用。$\mathrm{PCNA}$ 的蛋白质水平也是检验细胞增殖能力的重要指标。

:::definition{label="PCNA"}
增殖细胞核抗原（proliferation cell nuclear antigen，$\mathrm{PCNA}$）是同源三聚体，形成闭合环形、可滑动的 $\mathrm{DNA}$ 夹子。功能与构象都类似大肠埃希氏杆菌 $\mathrm{DNA}\ \mathrm{pol}$ Ⅲ 的 $\beta$ 亚基。在起始和延长中都关键。
:::

:::definition{label="RFC 把 PCNA 装到引物-模板上"}
在 $\mathrm{RFC}$ 作用下，$\mathrm{PCNA}$ 结合于引物－模板链。没有 $\mathrm{RFC}$ 这次加载，$\mathrm{PCNA}$ 夹子到不了工作位置。
:::

:::definition{label="PCNA 使 pol δ 获得持续合成能力"}
$\mathrm{pol}\ \delta$ 负责后随链。夹子把酶留在模板上，才谈得上“连续合成能力”，也才谈得上替换只能做引物的 $\mathrm{pol}\ \alpha$。
:::

:::definition{label="PCNA 还促进核小体生成"}
除夹稳模板外，$\mathrm{PCNA}$ 尚具有促进核小体生成的作用。第三部分“合成后立即组装成核小体”，分子上有这一笔。
:::

:::definition{label="PCNA 是增殖指标"}
$\mathrm{PCNA}$ 的蛋白质水平是检验细胞增殖能力的重要指标。它出现在复制机器里，所以能反映细胞是否在 $\mathrm{S}$ 期干活，不是另做一套肿瘤标志物定义。
:::

:::compare{title="原核 β 夹子和真核 PCNA"}
| | $E.\ coli$ $\mathrm{DNA}\ \mathrm{pol}$ Ⅲ 的 $\beta$ 亚基 | $\mathrm{PCNA}$ |
|--|------------------------------------------------------|-------------|
| 结构 | 滑动夹（sliding clamp）；一对 $\beta$ 构成闭合环 | 同源三聚体，闭合环形可滑动 $\mathrm{DNA}$ 夹子 |
| 加载 | $\gamma$-复合物（夹子加载复合体） | $\mathrm{RFC}$ |
| 效果 | 夹稳模板，使酶沿模板滑动 | 使 $\mathrm{pol}\ \delta$ 获得持续合成能力 |
| 额外 | 第三节不写它装核小体 | 促进核小体生成；蛋白水平作增殖指标 |

功能“相同”、构象“相似”，不是把亚基组成写成一样。原核是一对 $\beta$，真核是同源三聚体。
:::

:::pitfall{label="PCNA 不是又一种 DNA 聚合酶"}
它是夹子和增殖抗原，不催化 $\mathrm{dNTP}$ 聚合。把 $\mathrm{PCNA}$ 答成“真核的 $\mathrm{DNA}\ \mathrm{pol}$ Ⅲ”，表14-3 的 $\alpha/\delta/\varepsilon$ 就没地方放。持续合成能力是它赋给 $\mathrm{pol}\ \delta$ 的，不是它自己聚合。
:::

:::cause-effect{title="没有 PCNA 夹子，后随链为什么续不上"}
- **因** $\mathrm{pol}\ \alpha$ 只能合成引物、延长长度有限；后随链要靠 $\mathrm{pol}\ \delta$ 连续合成到下一个核小体单位之末
- **果** 必须先由 $\mathrm{RFC}$ 把 $\mathrm{PCNA}$ 加载到引物－模板上，$\mathrm{pol}\ \delta$ 才获得持续合成能力，聚合酶转换才站得住
:::

## 二、真核生物DNA复制的延长发生DNA聚合酶转换

现在认为 $\mathrm{DNA}\ \mathrm{pol}\ \alpha$ 主要催化合成引物，然后迅速被具有连续合成能力的 $\mathrm{DNA}\ \mathrm{pol}\ \delta$ 和 $\mathrm{DNA}\ \mathrm{pol}\ \varepsilon$ 所替换，这一过程称为聚合酶转换。$\mathrm{DNA}\ \mathrm{pol}\ \delta$ 负责合成后随链，$\mathrm{DNA}\ \mathrm{pol}\ \varepsilon$ 负责合成前导链。真核生物是以复制子为单位各自进行复制的，所以引物和后随链的冈崎片段都比原核生物的短。

:::definition{label="聚合酶转换"}
聚合酶转换（polymerase switching）：$\mathrm{DNA}\ \mathrm{pol}\ \alpha$ 主要催化合成引物，然后迅速被具有连续合成能力的 $\mathrm{DNA}\ \mathrm{pol}\ \delta$ 和 $\mathrm{DNA}\ \mathrm{pol}\ \varepsilon$ 所替换。第二节已经立过这个词，本节把它写成延长阶段的核心动作。
:::

:::definition{label="三条链对应三台酶"}
$\mathrm{pol}\ \alpha$：引物。$\mathrm{pol}\ \delta$：后随链。$\mathrm{pol}\ \varepsilon$：前导链。前导链也不是“从染色体一端连到另一端”，连续复制只限于半个复制子的长度。
:::

:::definition{label="真核引物和冈崎片段都比原核短"}
因为以复制子为单位各自复制。第一节给出的数量级：真核冈崎片段约 $100\sim 200$ 核苷酸，原核约 $1\,000\sim 2\,000$ 核苷酸。本节进一步钉到核小体尺子上。
:::

:::pitfall{label="不要把 pol α 写成“真核的 DNA pol Ⅲ”"}
$\mathrm{pol}\ \alpha$ 能催化 $\mathrm{RNA}$ 链合成，具有引物酶活性，但催化新链延长的长度有限。真正把链拉长的是转换之后的 $\delta$ 和 $\varepsilon$。把 $\alpha$ 听成延长的主力，转换、$\mathrm{PCNA}$、核小体单位之末 $\delta$ 脱落，全变成多余步骤。
:::

:::compare{title="原核延长 vs 真核延长"}
| | 原核（第三节） | 真核（本节） |
|--|----------------|--------------|
| 引物 | 引发酶，$\mathrm{RNA}$ 约 $5\sim 10$ 核苷酸 | $\mathrm{pol}\ \alpha$ 催化合成；比原核短 |
| 延长主力 | $\mathrm{DNA}\ \mathrm{pol}$ Ⅲ（同一复制叉上前导链和后随链由相同的 $\mathrm{DNA}\ \mathrm{pol}$ 催化） | 转换后 $\varepsilon$ 前导、$\delta$ 后随 |
| 冈崎片段 | 约 $1\,000\sim 2\,000$ 核苷酸 | 约一个核小体 $135\,\mathrm{bp}$ 或其若干倍；约 $100\sim 200$ 核苷酸 |
| 去掉引物 | $\mathrm{DNA}\ \mathrm{pol}$ Ⅰ 水解并填空隙 | $\mathrm{FEN}1$ 和 $\mathrm{RNase}\ \mathrm{H}$ 等 |

“半不连续”两边都成立。短在复制子和核小体，不在“真核不走冈崎片段”。
:::

实验证明，真核生物的冈崎片段长度大致与一个核小体（nucleosome）所含 $\mathrm{DNA}$ 碱基数（$135\,\mathrm{bp}$）或其若干倍相等。当后随链的合成到核小体单位之末时，$\mathrm{DNA}\ \mathrm{pol}\ \delta$ 会脱落，$\mathrm{DNA}\ \mathrm{pol}\ \alpha$ 再引发下游引物合成，引物的引发频率是相当高的。$\mathrm{pol}\ \alpha$ 与 $\mathrm{pol}\ \delta$ 之间的转换频率高，$\mathrm{PCNA}$ 在全过程也要发挥重要作用。以上描述是真核生物复制子内后随链的起始和延长交错进行的复制过程。前导链的连续复制，亦只限于半个复制子的长度。$\mathrm{FEN}1$ 和 $\mathrm{RNase}\ \mathrm{H}$ 等负责去除真核复制 $\mathrm{RNA}$ 引物。

:::definition{label="真核冈崎片段约 135 bp"}
长度大致与一个核小体所含 $\mathrm{DNA}$ 碱基数（$135\,\mathrm{bp}$）或其若干倍相等。这是本版给出的实验尺度，不要改成核小体核心颗粒的其他口诀数字。
:::

:::definition{label="后随链在核小体单位之末重新引发"}
合成到核小体单位之末时，$\mathrm{pol}\ \delta$ 脱落，$\mathrm{pol}\ \alpha$ 再引发下游引物。引发频率高，$\alpha$ 与 $\delta$ 转换频率高，$\mathrm{PCNA}$ 全程参与。复制子内后随链的起始和延长是交错进行的。
:::

:::definition{label="前导链只连续半个复制子"}
前导链的连续复制亦只限于半个复制子的长度。多复制子意味着前导链会在复制子交界处停下来，再与相邻复制子的产物连接。
:::

:::definition{label="FEN1 和 RNase H 去除真核 RNA 引物"}
真核复制的 $\mathrm{RNA}$ 引物由 $\mathrm{FEN}1$ 和 $\mathrm{RNase}\ \mathrm{H}$ 等负责去除。不要把原核 $\mathrm{DNA}\ \mathrm{pol}$ Ⅰ 的 $5'\rightarrow 3'$ 外切直接写成真核的引物水解酶。
:::

:::timeline{period="复制子内后随链交错进行"}
- **引物** pol α 合成 RNA 引物，提供 3′-OH
- **转换** PCNA 在 RFC 帮助下就位，pol δ 替换 pol α
- **延长** pol δ 合成到核小体单位之末（约 135 bp 或其若干倍）
- **脱落再引发** pol δ 脱落，pol α 在下游再引发；转换频率高
- **去引物** FEN1 和 RNase H 等去除 RNA 引物，再填补、连接
:::

:::pitfall{label="前导链“连续”不是“整条染色体一根到底”"}
教材专门加了一句：亦只限于半个复制子的长度。真核有上千复制子，两个方向各走半个复制子就会面。把前导链听成“从端粒连到另一个端粒”，复制子之间的连接和时序性激活都变成多余。
:::

:::insight{label="135 bp 把延长和核小体装配钉在同一把尺子上"}
冈崎片段不是随便“比原核短一点”。它大约一个核小体 $\mathrm{DNA}$ 那么长，所以 $\delta$ 跑到核小体单位之末就脱落。第三部分“核小体破坏仅局限在紧邻复制叉的短区、子链上迅速形成”，和这里的单位长度是同一套结构。
:::

:::cause-effect{title="为什么真核引物引发频率相当高"}
- **因** 每个冈崎片段只有约一个核小体 $\mathrm{DNA}$ 那么长，$\delta$ 到单位之末必须脱落，$\alpha$ 立刻在下游再引发
- **果** $\alpha$ 与 $\delta$ 转换频率高，$\mathrm{PCNA}$ 全过程都要在；不是“起始时装一次夹子就够用到复制终止”
:::

真核生物 $\mathrm{DNA}$ 合成，就酶的催化速率而言，远比原核生物慢，估算为 $50$ 个 $\mathrm{dNTP}/\mathrm{s}$。但真核生物是多复制子复制，总体速度是不慢的。原核生物复制速度与其培养（营养）条件有关。真核生物在不同器官组织、不同发育时期和不同生理状况下，复制速度也不一样。

:::definition{label="真核聚合酶约 50 个 dNTP/s"}
就酶的催化速率而言，远比原核慢，估算为 $50$ 个 $\mathrm{dNTP}/\mathrm{s}$。表14-2 里大肠埃希氏杆菌 $\mathrm{DNA}\ \mathrm{pol}$ Ⅲ 的聚合速率是 $250\sim 1\,000$ 核苷酸 $/\mathrm{s}$，对照的是这一档，不是把真核写成“更快”。
:::

:::definition{label="多复制子把总体速度补回来"}
单个酶慢，但上千个复制子分组同时干活，总体速度不慢。这是“高速”的真核答案，思考题第 $2$ 问要落到这一句，而不是改写 $50$ 这个数字。
:::

:::compare{title="速度受什么影响"}
| | 原核 | 真核 |
|--|------|------|
| 酶催化速率 | $\mathrm{pol}$ Ⅲ 可达数百至约 $1\,000$ 核苷酸 $/\mathrm{s}$ | 约 $50$ 个 $\mathrm{dNTP}/\mathrm{s}$ |
| 总体策略 | 一个 $\mathrm{oriC}$、双向；营养好可再起始 | 多复制子并行 |
| 生理调节 | 与培养（营养）条件有关 | 器官组织、发育时期、生理状况都可不同 |

“高速”问的是基因组复制完的墙钟时间，不是单分子 $k_{\mathrm{cat}}$。
:::

:::pitfall{label="不要用原核 pol Ⅲ 的速率去改写真核的 50"}
教材估算就是 $50$ 个 $\mathrm{dNTP}/\mathrm{s}$。用口诀“真核更快”或把表14-2 的 $250\sim 1\,000$ 安到 $\mathrm{pol}\ \delta$ 上，都和本版相反。保真性另走碱基选择、校读和修复，也不靠把酶写快。
:::

:::keypoint{label="延长三句话"}
- 转换：$\alpha$ 引物 $\rightarrow\delta$ 后随、$\varepsilon$ 前导。
- 尺子：冈崎片段 $\approx 135\,\mathrm{bp}$ 或其若干倍；前导链只连续半个复制子。
- 速度：酶约 $50$ 个 $\mathrm{dNTP}/\mathrm{s}$，多复制子所以总体不慢。
:::

## 三、真核生物DNA合成后立即组装成核小体

复制后的 $\mathrm{DNA}$ 需要重新装配。原有的组蛋白及新合成的组蛋白结合到复制叉后的 $\mathrm{DNA}$ 链上，真核生物 $\mathrm{DNA}$ 合成后立即组装成核小体。生化分析和复制叉的图像均表明，核小体的破坏仅局限在紧邻复制叉的一段短的区域内，复制叉的移动使核小体破坏，但是复制叉向前移动时，核小体在子链上迅速形成。

:::note{label="电子版缺失"}
教材此处有“动画”占位。电子版未提供可嵌入的非空图源，不写 `::figure`，也不引用第十五章页码。核小体破坏局限在复制叉紧邻短区、子链上迅速重建，以正文为准。
:::

:::definition{label="合成后立即组装成核小体"}
原有组蛋白及新合成的组蛋白结合到复制叉后的 $\mathrm{DNA}$ 链上。真核 $\mathrm{DNA}$ 合成后立即组装成核小体，不是等整条染色体复制完再包装。
:::

:::definition{label="核小体破坏只在复制叉紧邻短区"}
生化分析和复制叉图像均表明：破坏仅局限在紧邻复制叉的一段短区域。复制叉移动使核小体破坏；叉向前时，核小体在子链上迅速形成。
:::

:::insight{label="“立即”解释为什么冈崎片段可以按核小体单位切"}
如果子链上核小体要等很久才装，后随链按 $135\,\mathrm{bp}$ 单位脱落就没有结构依据。教材把装配写成与复制叉推进同步：前面拆一小段，后面马上装回去。$\mathrm{PCNA}$ 促进核小体生成，把延长机器和装配机器接在同一位置。
:::

:::pitfall{label="核小体不是整条染色体先拆光再复制"}
破坏范围是“紧邻复制叉的一段短区”。把染色质听成“$\mathrm{S}$ 期全部解成裸 $\mathrm{DNA}$”，组蛋白八聚体数量、旧组蛋白重新组装、着丝粒／端粒晚复制，都失去空间限制。
:::

核小体组蛋白八聚体的数量是同期合成的一个核小体 $\mathrm{DNA}$ 长度的两倍，核素标记实验证明，原有组蛋白大部分可重新组装至 $\mathrm{DNA}$ 链上。在 $\mathrm{S}$ 期，细胞能大量、迅速地合成新的组蛋白。

:::definition{label="组蛋白八聚体数量是同期核小体 DNA 的两倍"}
复制一次，$\mathrm{DNA}$ 从一份变成两份。同期合成一个核小体 $\mathrm{DNA}$ 长度，需要两套组蛋白八聚体去装两条子链。数量关系按“两倍”记，不要改成“和新 $\mathrm{DNA}$ 等摩尔就算完”。
:::

:::definition{label="旧组蛋白大部分可重新组装"}
核素标记实验证明，原有组蛋白大部分可重新组装至 $\mathrm{DNA}$ 链上。新组蛋白在 $\mathrm{S}$ 期大量、迅速合成，补上另一半需求。
:::

:::cause-effect{title="S 期为什么必须大量合成组蛋白"}
- **因** 子链立刻要装核小体；八聚体数量是同期核小体 $\mathrm{DNA}$ 长度的两倍；旧组蛋白大部分可重装，但仍不够装两条子链
- **果** $\mathrm{S}$ 期细胞大量、迅速合成新组蛋白，与 $\mathrm{DNA}$ 合成同期，而不是 $\mathrm{G}_1$ 提前囤积一整套
:::

:::compare{title="旧组蛋白和新组蛋白"}
| | 来源 | 教材原句 |
|--|------|----------|
| 旧 | 亲代核小体拆开后 | 大部分可重新组装至 $\mathrm{DNA}$ 链上 |
| 新 | $\mathrm{S}$ 期大量迅速合成 | 与原有组蛋白一起结合到复制叉后的链上 |

两条子链都要装。不要写成“旧组蛋白只回一条链、新组蛋白只去另一条”——本版没有把分配写成那种绝对模型，只保证数量和“大部分可重装”。
:::

:::keypoint{label="核小体装配三句"}
- 破坏：只在复制叉紧邻短区。
- 重建：叉向前，子链上迅速形成。
- 材料：旧组蛋白大部分重装 $+$ $\mathrm{S}$ 期新合成；八聚体数量是同期核小体 $\mathrm{DNA}$ 的两倍。
:::

## 四、端粒酶参与解决染色体末端复制问题

真核生物 $\mathrm{DNA}$ 复制与核小体装配同步进行，复制完成后随即组合成染色体，并从 $\mathrm{G}_2$ 期过渡到 $\mathrm{M}$ 期。染色体 $\mathrm{DNA}$ 是线性结构。复制中冈崎片段的连接，复制子之间的连接，都易于理解，因为均在线性 $\mathrm{DNA}$ 的内部完成。

:::definition{label="复制完成进入 G2 到 M"}
复制与核小体装配同步；完成后随即组合成染色体，从 $\mathrm{G}_2$ 过渡到 $\mathrm{M}$。本节不展开有丝分裂纺锤体，只把线性末端这件事从“内部连接”里单独拿出来。
:::

:::insight{label="内部好连，末端不好连"}
冈崎片段之间、复制子之间，两边都有 $\mathrm{DNA}$，去掉引物后可以用上游片段的 $3'$-$\mathrm{OH}$ 填空隙，再由连接酶封口。线性分子的两端：最后一段引物去掉以后，前面没有“更外侧的 $\mathrm{DNA}$ 片段”提供 $3'$-$\mathrm{OH}$。这才是末端复制问题。
:::

染色体两端 $\mathrm{DNA}$ 子链上最后复制的 $\mathrm{RNA}$ 引物，去除后留下空隙。剩下的 $\mathrm{DNA}$ 单链母链如果不填补成双链，就会被核内 $\mathrm{DNase}$ 酶解。某些低等生物作为少数特例，染色体经多次复制会变得越来越短（图14-15）。事实上，染色体虽经过多次复制，却不会越来越短，因为真核生物染色体线性 $\mathrm{DNA}$ 的末端有一特殊的端粒（telomere）结构。

:::note{label="电子版缺失"}
教材第 $268$ 页图14-15　线性 $\mathrm{DNA}$ 复制一次端粒缩短，电子版图源 `p0297_01.png` 为 $0$ 字节，不嵌入 `src`。全页扫描 `p0297_page.png` 同时含图14-15、图14-16 及第五部分正文，混有页眉页码，不作本图。`p0296_page.png` 为第 $267$ 页纯正文，不是插图。图注顺序：亲代线性双链经一轮复制，新链 $5'$ 端引物去除后留下空隙（图中以三角标出）；再复制，带空隙的分子继续缩短。正文强调：这是某些低等生物的少数特例；有端粒的真核染色体不会这样越来越短。
:::

:::definition{label="末端引物空隙"}
染色体两端，子链上最后复制的 $\mathrm{RNA}$ 引物去除后留下空隙。若剩下的单链母链不填补成双链，会被核内 $\mathrm{DNase}$ 酶解。
:::

:::definition{label="低等生物末端缩短是特例"}
某些低等生物作为少数特例，染色体经多次复制会变得越来越短（图14-15）。不要把这张图听成“人的染色体每复制一次必然缩短到消失”——教材马上用端粒把这句话挡住。
:::

:::definition{label="端粒阻止染色体越来越短"}
事实上，染色体虽经过多次复制，却不会越来越短，因为线性 $\mathrm{DNA}$ 末端有特殊的端粒结构。端粒酶用爬行模型主动延长母链 $3'$ 端，再补子链。
:::

:::pitfall{label="图14-15 不是“真核都没有端粒酶”"}
图的标题是“线性 $\mathrm{DNA}$ 复制一次端粒缩短”，画的是没有补偿时的逻辑后果。正文用“少数特例／事实上不会越来越短”把一般真核和这张示意图分开。成纤维细胞传代中端粒逐渐缩短，是第四部分后半的细胞老化实验，不是否定端粒结构本身。
:::

形态学上，端粒在染色体 $\mathrm{DNA}$ 末端膨大成粒状，这是因为 $\mathrm{DNA}$ 和它的结合蛋白质紧密结合，像两顶帽子那样盖在染色体两端，因而得名。在某些情况下，染色体可以断裂，这时，染色体断端之间会发生融合或断端被 $\mathrm{DNA}$ 酶降解。但正常染色体不会整体地互相融合，也不会在末端出现遗传信息的丢失。可见，端粒在维持染色体的稳定性和 $\mathrm{DNA}$ 复制的完整性中有着重要作用。$\mathrm{DNA}$ 测序发现端粒结构的共同特点是富含 $\mathrm{T}$-$\mathrm{G}$ 短序列的多次重复。如仓鼠和人类端粒 $\mathrm{DNA}$ 都有 $\mathrm{TxGy}$ 的重复序列，重复达数十至上百次，并能反折成二级结构。

:::definition{label="端粒"}
端粒（telomere）在染色体 $\mathrm{DNA}$ 末端膨大成粒状：$\mathrm{DNA}$ 与结合蛋白质紧密结合，像两顶帽子盖在两端。功能：维持染色体稳定性，维持 $\mathrm{DNA}$ 复制的完整性。
:::

:::definition{label="端粒的 TxGy 重复"}
共同特点是富含 $\mathrm{T}$-$\mathrm{G}$ 短序列的多次重复。仓鼠和人类都有 $\mathrm{TxGy}$ 重复，达数十至上百次，并能反折成二级结构。本版没有另写一套“人的六核苷酸口诀”，复习按 $\mathrm{TxGy}$ 记。
:::

:::definition{label="端粒挡住融合和末端降解"}
染色体一旦断裂，断端之间会融合，或被 $\mathrm{DNA}$ 酶降解。正常染色体不会整体互相融合，也不会在末端丢失遗传信息。帽子挡住的就是这两件事。
:::

:::compare{title="内部连接 vs 末端帽子"}
| | 线性 DNA 内部 | 线性 DNA 末端 |
|--|---------------|----------------|
| 冈崎片段／复制子连接 | 有相邻 $3'$-$\mathrm{OH}$ 可填引物空隙 | 最后一段引物外侧没有片段 |
| 若不处理 | 留下缺口，连接酶可封 | 单链母链被核内 $\mathrm{DNase}$ 酶解；多次复制可变短 |
| 本版对策 | $\mathrm{FEN}1$、$\mathrm{RNase}\ \mathrm{H}$、聚合酶填补、连接酶 | 端粒 $\mathrm{TxGy}$ $+$ 端粒酶爬行模型 |

帽子是蛋白质和 $\mathrm{DNA}$ 的复合结构，不是单纯“多一段重复序列”就自动稳定。
:::

:::pitfall{label="端粒不是着丝粒的别名"}
着丝粒：连接染色体双倍体的部位，高度重复，$\mathrm{S}$ 期末复制。端粒：线性两端的帽子，$\mathrm{TxGy}$，同样 $\mathrm{S}$ 期末复制。晚复制是共同点，位置和功能不是同一户。把“染色体两端膨大成粒”答成着丝粒，帽子和爬行模型都会写到错误的位置。
:::

:::insight{label="反折成二级结构，是重复序列的结构后果"}
数十至上百次 $\mathrm{TxGy}$ 不是只为了“多备份一点遗传信息”。教材写它能反折成二级结构，和形态学上的粒状膨大、结合蛋白帽子是同一套末端。具体折成什么拓扑，本版没有再命名，不要外补术语。
:::

$20$ 世纪 $80$ 年代中期发现了端粒酶（telomerase）。$1997$ 年，人类端粒酶基因被成功克隆并鉴定了该酶由三部分组成：约 $150\,\mathrm{nt}$ 的端粒酶 $\mathrm{RNA}$（human telomerase RNA，$\mathrm{hTR}$）、端粒酶协同蛋白 $1$（human telomerase associated protein $1$，$\mathrm{hTP}1$）和端粒酶逆转录酶（human telomerase reverse transcriptase，$\mathrm{hTRT}$）。该酶兼有提供 $\mathrm{RNA}$ 模板和催化逆转录的功能。

:::definition{label="端粒酶"}
端粒酶（telomerase）兼有提供 $\mathrm{RNA}$ 模板和催化逆转录的功能。人类端粒酶三部分：约 $150\,\mathrm{nt}$ 的 $\mathrm{hTR}$、$\mathrm{hTP}1$、$\mathrm{hTRT}$。$20$ 世纪 $80$ 年代中期发现酶，$1997$ 年克隆并鉴定组成。
:::

:::definition{label="hTR"}
人端粒酶 $\mathrm{RNA}$（$\mathrm{hTR}$）约 $150\,\mathrm{nt}$。爬行模型里用它的 $\mathrm{CyAx}$ 辨认并结合母链 $\mathrm{TxGy}$，再作为逆转录模板延长母链 $3'$ 端。
:::

:::definition{label="hTP1"}
端粒酶协同蛋白 $1$（$\mathrm{hTP}1$）。三部分之一，和 $\mathrm{hTR}$、$\mathrm{hTRT}$ 一起构成人端粒酶，不要漏记成“只有 $\mathrm{RNA}$ 加逆转录酶两件套”。
:::

:::definition{label="hTRT"}
人端粒酶逆转录酶（$\mathrm{hTRT}$）。催化以 $\mathrm{hTR}$ 为模板、把脱氧核苷酸加到母链 $3'$ 端的反应。第五节的逆转录酶是 $\mathrm{RNA}$ 病毒那一户；端粒酶是细胞自己的逆转录，两本账不要并。
:::

:::compare{title="端粒酶三部分"}
| 组分 | 教材名称 | 本节职分 |
|------|----------|----------|
| $\mathrm{hTR}$ | 端粒酶 $\mathrm{RNA}$，约 $150\,\mathrm{nt}$ | 模板；$\mathrm{CyAx}$ 辨认 $\mathrm{TxGy}$ |
| $\mathrm{hTP}1$ | 端粒酶协同蛋白 $1$ | 蛋白组分，协同 |
| $\mathrm{hTRT}$ | 端粒酶逆转录酶 | 催化逆转录 |

兼有“提供模板”和“催化逆转录”，缺一就不能爬行。
:::

:::pitfall{label="端粒酶不是普通 DNA 聚合酶"}
它用自己的 $\mathrm{RNA}$ 当模板，逆转录延长 $\mathrm{DNA}$。普通 $\mathrm{DNA}\ \mathrm{pol}$ 不能在没有模板的末端凭空补 $5'$ 空隙。把端粒酶答成“又一种 $\mathrm{pol}\ \delta$”，爬行移位和 $\mathrm{hTR}$ 都没有着落。
:::

复制终止时，染色体端粒区域的 $\mathrm{DNA}$ 确有可能缩短或断裂。端粒酶通过一种称为爬行模型（inchworm model）（图14-16）的机制合成端粒 $\mathrm{DNA}$。端粒酶依靠 $\mathrm{hTR}$ 的 $\mathrm{CyAx}$ 辨认及结合母链 $\mathrm{DNA}$ 的 $\mathrm{TxGy}$ 重复序列并移至其 $3'$ 端，开始以逆转录的方式复制；复制一段后，$\mathrm{hTR}$ 的 $\mathrm{CyAx}$ 爬行移位至新合成的母链 $3'$ 端，再以逆转录的方式复制延伸母链；延伸至足够长度后，端粒酶脱离母链，随后 $\mathrm{RNA}$ 引物酶以母链为模板合成引物，招募 $\mathrm{DNA}\ \mathrm{pol}$，以母链为模板，在 $\mathrm{DNA}\ \mathrm{pol}$ 催化下填充子链，最后引物被去除。

教材第 $268$ 页图14-16　端粒酶催化作用的爬行模型，电子版图源 `p0297_02.png` 为 $0$ 字节，不嵌入 `src`。全页扫描 `p0297_page.png` 混有图14-15、本图及 $\mathrm{pre}$-$\mathrm{RC}$ 正文，不作本图。图中步骤：①端粒酶延长 $\mathrm{DNA}\ 3'$ 末端（$\mathrm{RNA}$ 模板为端粒酶组成成分）；②引物酶合成 $\mathrm{RNA}$ 引物；③ $\mathrm{DNA}$ 聚合酶填充后去除 $\mathrm{RNA}$ 引物。正文机制按 $\mathrm{hTR}$ 的 $\mathrm{CyAx}$ 辨认母链 $\mathrm{TxGy}$、逆转录、爬行移位再逆转录来默写。本节动态过程（端粒酶爬行）不落 `::video`。
:::

:::definition{label="爬行模型"}
爬行模型（inchworm model）是端粒酶合成端粒 $\mathrm{DNA}$ 的机制：$\mathrm{hTR}$ 的 $\mathrm{CyAx}$ 辨认结合母链 $\mathrm{TxGy}$ 并移至 $3'$ 端，逆转录一段；$\mathrm{CyAx}$ 再爬行移位到新的母链 $3'$ 端，再逆转录；足够长后酶脱落，引物酶合成引物，$\mathrm{DNA}\ \mathrm{pol}$ 填子链，最后去引物。
:::

:::timeline{period="爬行模型把母链 3′ 端补长再填子链"}
- **辨认** hTR 的 CyAx 结合母链 TxGy，移到 3′ 端
- **逆转录** 以 hTR 为模板延长母链
- **爬行** CyAx 移位到新合成的母链 3′ 端，再逆转录；可重复
- **脱落** 延伸至足够长度，端粒酶离开
- **填子链** RNA 引物酶以母链为模板合成引物，DNA pol 填充，去除引物
:::

:::keypoint{label="爬行模型要按“先延长母链、再补子链”记"}
- 先动的是母链 $3'$ 端，不是子链 $5'$ 空隙直接被 $\mathrm{DNA}\ \mathrm{pol}$ 填上。
- 模板是 $\mathrm{hTR}$，不是另一条染色体 $\mathrm{DNA}$。
- 爬行 $=$ $\mathrm{CyAx}$ 换到新的 $3'$ 端，不是酶在 $\mathrm{DNA}$ 上蠕动一次就结束。
- 子链仍要引物：$\mathrm{RNA}$ 引物酶 $+$ $\mathrm{DNA}\ \mathrm{pol}$，最后引物还是要去掉。
:::

:::pitfall{label="CyAx 配的是 TxGy，不要写反"}
母链重复是 $\mathrm{TxGy}$（富 $\mathrm{T}$、$\mathrm{G}$），$\mathrm{hTR}$ 上辨认序列是 $\mathrm{CyAx}$（富 $\mathrm{C}$、$\mathrm{A}$）。写反以后碱基配对和“逆转录以 $\mathrm{RNA}$ 为模板”都对不齐。图14-16 用短重复示意，正文符号以 $\mathrm{TxGy}/\mathrm{CyAx}$ 为准。
:::

:::pitfall{label="端粒酶填的不是“引物留下的空隙本身”"}
空隙在子链 $5'$ 端。端粒酶先把母链 $3'$ 突出端加长，使内侧出现新的模板，再另做 $\mathrm{RNA}$ 引物去填子链。把机制答成“端粒酶直接把 $\mathrm{dNTP}$ 填进引物空隙”，会绕过 $\mathrm{hTR}$ 和爬行移位。
:::

:::insight{label="最后引物仍要去掉，所以末端可以仍有短突出"}
教材写到“最后引物被去除”为止，没有承诺填成完全平末端。形态学上的粒状帽子、反折二级结构，允许末端继续以重复序列和蛋白结合的形式存在。不要把“解决末端复制问题”听成“染色体变成闭合环”。
:::

研究发现，培养的人成纤维细胞随着培养传代次数增加，端粒长度逐渐缩短。生殖细胞中端粒长于体细胞，成年人细胞中端粒比胚胎细胞中端粒短。据上述的实验结果，至少可以认为在细胞水平，老化是和端粒酶活性下降有关的。生物个体的老化，受多种环境因素和体内生理条件的影响，不能简单地归结为某单一因素的作用。

此外，在增殖活跃的肿瘤细胞中发现端粒酶活性增高。但在临床研究中也发现某些肿瘤细胞的端粒比正常同类细胞显著缩短。可见，端粒酶活性不一定与端粒的长度成正比。端粒和端粒酶的研究，在肿瘤学发病机制、寻找治疗靶点上，已经成为一个重要领域。

:::definition{label="细胞水平老化与端粒酶活性下降有关"}
成纤维细胞传代次数增加，端粒缩短；生殖细胞端粒长于体细胞；成年人短于胚胎。据这些结果，至少在细胞水平，老化与端粒酶活性下降有关。
:::

:::definition{label="个体老化不能只归为端粒酶"}
生物个体的老化受多种环境因素和体内生理条件影响，不能简单归结为某单一因素。细胞水平的那句话，不要直接写成“人老就是因为没有端粒酶”。
:::

:::definition{label="肿瘤里端粒酶活性增高但不一定端粒更长"}
增殖活跃的肿瘤细胞中端粒酶活性增高；某些肿瘤细胞的端粒比正常同类细胞显著缩短。活性不一定与长度成正比。
:::

:::compare{title="端粒长度的几组对照"}
| 对照 | 教材事实 |
|------|----------|
| 培养传代 | 人成纤维细胞传代↑，端粒↓ |
| 生殖 vs 体细胞 | 生殖细胞端粒更长 |
| 成年 vs 胚胎 | 成年人细胞端粒更短 |
| 肿瘤 vs 正常 | 酶活性常增高；长度却可显著更短 |

思考题第 $3$ 问“为何有些肿瘤的发生与端粒酶有关”，要同时答：活性增高支持增殖；长度不一定成正比，仍是发病机制和治疗靶点的研究领域。
:::

:::pitfall{label="不要把“酶活性增高”写成“端粒一定更长”"}
教材用临床观察把这两件事拆开。增殖需要端粒酶维持末端，但测量到的端粒长度可以比正常同类细胞短。只答“肿瘤端粒酶高所以端粒长”，和“显著缩短”那句直接冲突。
:::

:::insight{label="生殖细胞端粒更长，说明酶活性不是体细胞默认状态"}
如果所有细胞端粒酶都充分工作，成纤维传代缩短、成年短于胚胎都不会出现。教材把酶活性下降放在体细胞老化这一侧，把酶活性增高放在增殖活跃的肿瘤这一侧。体细胞默认不是“端粒酶开到最大”。
:::

:::keypoint{label="端粒与端粒酶必背"}
- 帽子：$\mathrm{DNA}+$ 结合蛋白，防融合、防末端降解、维持复制完整性。
- 序列：$\mathrm{TxGy}$，数十至上百次，可反折。
- 酶：$\mathrm{hTR}$（$\sim 150\,\mathrm{nt}$）$+\mathrm{hTP}1+\mathrm{hTRT}$；模板 $+$ 逆转录。
- 爬行：$\mathrm{CyAx}$ 认 $\mathrm{TxGy}$ $\rightarrow$ 逆转录 $\rightarrow$ 移位再逆转录 $\rightarrow$ 引物酶 $+$ $\mathrm{DNA}\ \mathrm{pol}$ 填子链。
- 老化：细胞水平与酶活性下降有关；个体老化不是单因素。
- 肿瘤：酶活性常增高，长度不一定成正比。
:::

## 五、真核生物染色体DNA在每个细胞周期中只能复制一次

真核染色体 $\mathrm{DNA}$ 复制的一个重要特征是复制仅仅出现在细胞周期的 $\mathrm{S}$ 期，而且只能复制一次。染色体的任何一部分的不完全复制，均可能导致子代染色体分离时发生断裂和丢失。不适当的 $\mathrm{DNA}$ 复制也可能产生严重后果，如增加基因组中基因调控区的拷贝数，从而可能在基因表达、细胞分裂、对环境信号的应答等方面产生灾难性后果。

:::definition{label="每个细胞周期只复制一次"}
复制仅仅出现在 $\mathrm{S}$ 期，而且只能复制一次。这是真核染色体 $\mathrm{DNA}$ 复制的一个重要特征，不是“营养好可以再起一轮”的原核图像。
:::

:::definition{label="复制少了会断，复制多了会乱"}
任何一部分不完全复制 $\rightarrow$ 子代染色体分离时断裂和丢失。不适当的复制 $\rightarrow$ 基因调控区拷贝数增加 $\rightarrow$ 表达、分裂、环境应答灾难性后果。次数被管住，既防少也防多。
:::

:::pitfall{label="“只能一次”不是“只能有一个复制起点”"}
一次指每个复制基因位点在一个细胞周期里只被激活一轮。起点仍然有上千个。把“一次”听成“一条染色体一个叉”，第一部分的多复制子和时序性就作废。
:::

:::cause-effect{title="为什么不完全复制和过度复制都不能忍"}
- **因** 有丝分裂要把两套完整染色体分给子细胞；调控区多拷贝会扰动表达和分裂
- **果** 必须保证：$\mathrm{S}$ 期之内每个区段不多不少正好复制一次；$\mathrm{G}_1$ 只装许可复合物，不开火
:::

真核细胞 $\mathrm{DNA}$ 复制的起始分两步进行，即复制基因的选择和复制起点的激活，这两步分别出现于细胞周期的特定阶段。复制基因（replicator）是指 $\mathrm{DNA}$ 复制起始所必需的全部 $\mathrm{DNA}$ 序列。

:::definition{label="复制起始分两步"}
第一步：复制基因的选择。第二步：复制起点的激活。两步分别出现于细胞周期的特定阶段——选择在 $\mathrm{G}_1$，激活在 $\mathrm{S}$。
:::

:::definition{label="复制基因"}
复制基因（replicator）指 $\mathrm{DNA}$ 复制起始所必需的全部 $\mathrm{DNA}$ 序列。它是 $\mathrm{DNA}$ 上的位点，不是“编码复制酶的那个基因”。$\mathrm{ORC}$、$\mathrm{CDC}6$ 识别结合的就是它。
:::

:::pitfall{label="replicator 不要译成“负责复制的蛋白质基因”"}
教材定义写明：是 $\mathrm{DNA}$ 复制起始所必需的全部 $\mathrm{DNA}$ 序列。蛋白质那边是 $\mathrm{ORC}$、$\mathrm{CDC}6$、$\mathrm{CDT}1$、$\mathrm{MCM}2$-$7$。把复制基因听成 $\mathrm{MCM}$ 的结构基因，图14-17 顶部那条双线就没了。
:::

复制基因的选择出现于 $\mathrm{G}_1$ 期，在这一阶段，基因组的每个复制基因位点均组装前复制复合物（pre-replicative complex，$\mathrm{pre}$-$\mathrm{RC}$），又称复制许可因子（replication licensing factor，$\mathrm{RLF}$）。$\mathrm{pre}$-$\mathrm{RC}$ 由四种类型的蛋白质组成，按顺序在每个复制基因位点进行组装。首先由复制起始识别复合物（origin recognition complex，$\mathrm{ORC}$）和 $\mathrm{CDC}6$ 先后识别并结合复制基因，$\mathrm{CDC}6$ 随后招募 $\mathrm{CDC}$-$10$ 依赖转录因子 $1$（$\mathrm{CDC}10$-dependent transcript $1$，$\mathrm{CDT}1$），$\mathrm{ORC}$、$\mathrm{CDC}6$ 和 $\mathrm{CDT}1$ 共同促进两个真核细胞解旋酶 $\mathrm{MCM}2$-$7$ 复合物装载，形成 $\mathrm{pre}$-$\mathrm{RC}$。此时的 $\mathrm{pre}$-$\mathrm{RC}$ 还未被激活（图14-17）。$\mathrm{ORC}$ 含有五个 $\mathrm{ATP}$ 酶的结构域，其功能类似于细菌的 $\mathrm{DnaA}$。解旋酶复合物 $\mathrm{MCM}2$-$7$ 是一个由微小染色体维持（minichromosome maintenance，$\mathrm{MCM}$）蛋白组成的环状异源六聚体，其功能类似于细菌的 $\mathrm{DnaB}$。

:::note{label="电子版缺失"}
教材第 $269$ 页图14-17　前复制复合物（$\mathrm{pre}$-$\mathrm{RC}$）的形成，电子版图源 `p0298_01.png` 为 $0$ 字节，不嵌入 `src`。全页扫描 `p0298_page.png` 同时含图14-17、图14-18 及 $\mathrm{D}$ 环／逆转录正文，混有章名页码，不作本图。图注自上而下：复制基因双链上先结合 $\mathrm{ORC}$，再结合 $\mathrm{CDC}6$ 与 $\mathrm{CDT}1$，最后装载两套 $\mathrm{MCM}2$-$7$ 环。此图属于本节第五部分，不留在第五节 dump 里。
:::

:::definition{label="pre-RC"}
前复制复合物（pre-replicative complex，$\mathrm{pre}$-$\mathrm{RC}$）在 $\mathrm{G}_1$ 期组装于每个复制基因位点，又称复制许可因子（replication licensing factor，$\mathrm{RLF}$）。由四种类型蛋白质按顺序组装，此时尚未被激活。
:::

:::definition{label="ORC"}
复制起始识别复合物（origin recognition complex，$\mathrm{ORC}$）与 $\mathrm{CDC}6$ 先后识别并结合复制基因。$\mathrm{ORC}$ 含五个 $\mathrm{ATP}$ 酶结构域，功能类似于细菌的 $\mathrm{DnaA}$。
:::

:::definition{label="CDC6 和 CDT1"}
$\mathrm{CDC}6$ 随后招募 $\mathrm{CDC}10$-dependent transcript $1$（$\mathrm{CDT}1$）。$\mathrm{ORC}$、$\mathrm{CDC}6$ 和 $\mathrm{CDT}1$ 共同促进两个 $\mathrm{MCM}2$-$7$ 装载。$\mathrm{CDT}1$ 全称按教材：$\mathrm{CDC}$-$10$ 依赖转录因子 $1$。
:::

:::definition{label="MCM2-7"}
微小染色体维持（minichromosome maintenance，$\mathrm{MCM}$）蛋白组成的环状异源六聚体，即真核细胞解旋酶 $\mathrm{MCM}2$-$7$。每个复制基因位点装载两个复合物。功能类似于细菌的 $\mathrm{DnaB}$。
:::

:::timeline{period="G1 按顺序装配尚未激活的 pre-RC"}
- **识别** ORC 结合复制基因，随后 CDC6 结合
- **招募** CDC6 招募 CDT1
- **装载解旋酶** ORC、CDC6、CDT1 共同促进两套 MCM2-7 装载
- **许可但未激活** 形成 pre-RC / RLF，此时还不能起始 DNA 合成
:::

:::compare{title="ORC / MCM 对 DnaA / DnaB"}
| 真核 | 类似的细菌蛋白 | 教材点出的共同点 |
|------|----------------|-------------------|
| $\mathrm{ORC}$（五个 $\mathrm{ATP}$ 酶结构域） | $\mathrm{DnaA}$ | 识别结合起点／复制基因 |
| $\mathrm{MCM}2$-$7$（环状异源六聚体解旋酶） | $\mathrm{DnaB}$ | 解开双链 |

类似不是相同。细菌 $\mathrm{DnaA}$ 结合后很快解链并募集聚合酶；真核把识别和激活拆到 $\mathrm{G}_1$ 与 $\mathrm{S}$。
:::

:::pitfall{label="pre-RC 装好不等于复制已经开始"}
教材反复写：此时还未被激活。$\mathrm{G}_1$ 完成的是许可（licensing），$\mathrm{S}$ 期磷酸化后才募集聚合酶。把图14-17 答成“复制叉已经打开”，和“只能一次”的调控就脱节。
:::

:::pitfall{label="两个 MCM2-7 不要写成一个六聚体了事"}
教材写“两个真核细胞解旋酶 $\mathrm{MCM}2$-$7$ 复合物装载”。双向复制、两条链各要解旋，图14-17 也是两套环。漏掉“两个”，和后文双向、半个复制子对不齐。
:::

:::insight{label="每个复制基因位点都装一套，是“只复制一次”的物质基础"}
$\mathrm{G}_1$ 把基因组的每个复制基因位点都许可一遍。$\mathrm{S}$ 期激活后，这套 $\mathrm{pre}$-$\mathrm{RC}$ 被磷酸化拆用，不能在同一周期里再装一套去复制第二轮。原核营养充足可以再起始，真核用选择／激活分离把这扇门关上。
:::

复制起点的激活发生在 $\mathrm{S}$ 期，受到 $\mathrm{CDK}2$ 严格调控。细胞进入 $\mathrm{S}$ 期后，细胞周期蛋白 $\mathrm{A}$ 和 $\mathrm{CDK}2$ 结合，使 $\mathrm{pre}$-$\mathrm{RC}$ 的多个亚基发生磷酸化，磷酸化的 $\mathrm{pre}$-$\mathrm{RC}$ 进一步募集若干复制基因结合蛋白和 $\mathrm{DNA}$ 聚合酶，并起始 $\mathrm{DNA}$ 复制。

在原核细胞中，复制基因的识别与 $\mathrm{DNA}$ 解旋、募集 $\mathrm{DNA}$ 聚合酶偶联进行。在真核细胞中，复制基因的选择和复制起点的激活相分离，可以确保每个染色体在每个细胞周期中仅复制一次。

:::definition{label="S 期 CDK2 激活复制起点"}
激活发生在 $\mathrm{S}$ 期，受 $\mathrm{CDK}2$ 严格调控。细胞周期蛋白 $\mathrm{A}$ 与 $\mathrm{CDK}2$ 结合，磷酸化 $\mathrm{pre}$-$\mathrm{RC}$ 的多个亚基；磷酸化后再募集复制基因结合蛋白和 $\mathrm{DNA}$ 聚合酶，起始复制。
:::

:::definition{label="选择与激活相分离保证只复制一次"}
原核：识别、解旋、募集聚合酶偶联进行。真核：选择（$\mathrm{G}_1$）和激活（$\mathrm{S}$）相分离，从而每个染色体每个细胞周期仅复制一次。
:::

:::compare{title="原核偶联 vs 真核两步"}
| | 原核 | 真核 |
|--|------|------|
| 识别复制基因／$\mathrm{oriC}$ | 与解旋、募集聚合酶偶联 | $\mathrm{G}_1$ 先识别、装配 $\mathrm{pre}$-$\mathrm{RC}$ |
| 解旋与聚合酶 | 几乎同时 | $\mathrm{S}$ 期 $\mathrm{CDK}2$ 磷酸化后才募集聚合酶 |
| 一轮细胞周期里再起始 | 营养条件允许时可再起始 | 选择与激活分离，确保仅一次 |

“精致”在这一段具体化为两步分离，不是形容词。
:::

:::cause-effect{title="细胞周期蛋白 A–CDK2 磷酸化之后才能聚合"}
- **因** $\mathrm{G}_1$ 的 $\mathrm{pre}$-$\mathrm{RC}$ 未激活，不能募集 $\mathrm{DNA}$ 聚合酶
- **果** 必须等进入 $\mathrm{S}$ 期，细胞周期蛋白 $\mathrm{A}$ 结合 $\mathrm{CDK}2$，磷酸化多个亚基，才起始 $\mathrm{DNA}$ 复制；同一周期里不能回头再许可一次
:::

:::keypoint{label="只复制一次的分子顺序"}
- $\mathrm{G}_1$：$\mathrm{ORC}\rightarrow\mathrm{CDC}6\rightarrow\mathrm{CDT}1\rightarrow$ 两套 $\mathrm{MCM}2$-$7$ $\Rightarrow\mathrm{pre}$-$\mathrm{RC}$（$\mathrm{RLF}$），未激活。
- $\mathrm{S}$：细胞周期蛋白 $\mathrm{A}$–$\mathrm{CDK}2$ 磷酸化 $\rightarrow$ 募集结合蛋白和聚合酶 $\rightarrow$ 起始。
- 原核偶联，真核分离。
:::

## 六、真核生物线粒体DNA按D环方式复制

$\mathrm{D}$-环复制（$\mathrm{D}$-loop replication）是线粒体 $\mathrm{DNA}$ 的复制方式。复制时需合成引物。$\mathrm{mtDNA}$ 为闭合环状双链结构，第一个引物以内环为模板延伸。至第二个复制起点时，又合成另一个反向引物，以外环为模板进行反向的延伸。最后完成两个双链环状 $\mathrm{DNA}$ 的复制（图14-18）。复制中呈字母 $\mathrm{D}$ 形状而得名。$\mathrm{D}$ 环复制的特点是复制起点不在双链 $\mathrm{DNA}$ 同一位点，内、外环复制有时序差别。

:::

:::definition{label="D 环复制"}
$\mathrm{D}$-环复制（$\mathrm{D}$-loop replication）是线粒体 $\mathrm{DNA}$ 的复制方式。复制中呈字母 $\mathrm{D}$ 形状而得名。需要合成引物。
:::

:::definition{label="内外环起点不同、有时序差别"}
$\mathrm{mtDNA}$ 为闭合环状双链。第一个引物以内环为模板延伸；至第二个复制起点，再合成反向引物，以外环为模板反向延伸；最后得到两个双链环状 $\mathrm{DNA}$。复制起点不在双链同一位点，内、外环复制有时序差别。
:::

:::timeline{period="D 环复制的两个起点"}
- **第一起点** 合成第一个引物，以内环为模板延伸，出现 D 形置换环
- **第二起点** 到达后合成反向引物，以外环为模板反向延伸
- **完成** 两个闭合双链环状 mtDNA
:::

:::compare{title="核染色体复制 vs mtDNA 的 D 环"}
| | 核染色体（本节一至五） | $\mathrm{mtDNA}$（本节六） |
|--|------------------------|-------------------------|
| 分子形状 | 线性，有端粒 | 闭合环状双链 |
| 起点 | 每条染色体上千复制子 | 两个起点，不在双链同一位点 |
| 聚合酶 | $\alpha/\delta/\varepsilon$ | $\mathrm{DNA}\ \mathrm{pol}\ \gamma$ |
| 时序 | $\mathrm{S}$ 期；复制子分组激活 | 内、外环有时序差别 |
| 末端问题 | 端粒酶 | 环状，无端粒这本账 |

都需要引物。不要把 $\mathrm{D}$ 环写成“线粒体也按端粒酶复制”。
:::

:::pitfall{label="D 环不是“只有一条链复制”"}
先内环、后外环，最后是两个双链环。时序差别不等于只复制一股。把 $\mathrm{D}$ 环听成“永远停在置换环中间态”，图14-18 右侧的第二引物就没了。
:::

:::insight{label="环状所以不必请端粒酶"}
核染色体的末端问题来自线性。$\mathrm{mtDNA}$ 闭合环状，内部同样要引物、同样要填空隙，但不需要 $\mathrm{TxGy}$ 帽子。特殊之处是两个起点错开，复制中看起来像字母 $\mathrm{D}$。
:::

真核生物的 $\mathrm{DNA}\ \mathrm{pol}\ \gamma$ 是线粒体催化 $\mathrm{DNA}$ 复制的 $\mathrm{DNA}$ 聚合酶。$20$ 世纪 $50$ 年代以前，只知道 $\mathrm{DNA}$ 存在于细胞核染色体中。后来在细菌染色体外也发现能进行自我复制的 $\mathrm{DNA}$，例如质粒，以后就利用质粒作为基因工程的常用载体。真核生物细胞器——线粒体，也发现存在 $\mathrm{mtDNA}$。线粒体的功能是进行生物氧化和氧化磷酸化。人类的 $\mathrm{mtDNA}$ 已知有 $37$ 个基因，其中 $13$ 个 $\mathrm{mtDNA}$ 基因编码 $\mathrm{ATP}$ 合成有关的蛋白质和酶，其余 $24$ 个基因转录为 $\mathrm{tRNA}$（$22$ 个）和 $\mathrm{rRNA}$（$2$ 个），参与线粒体蛋白质的合成。

:::definition{label="DNA pol γ"}
真核生物的 $\mathrm{DNA}\ \mathrm{pol}\ \gamma$ 是线粒体催化 $\mathrm{DNA}$ 复制的聚合酶。表14-3 功能栏写“线粒体 $\mathrm{DNA}$ 合成”，和核内的 $\alpha/\delta/\varepsilon$ 分户。
:::

:::definition{label="染色体外可自我复制的 DNA"}
$20$ 世纪 $50$ 年代以前只知道核染色体 $\mathrm{DNA}$。随后：细菌质粒（基因工程常用载体）；真核细胞器线粒体的 $\mathrm{mtDNA}$。第五节会再写：某些病毒的遗传物质是 $\mathrm{RNA}$，复制走逆转录。
:::

:::definition{label="人类 mtDNA 的 37 个基因"}
已知 $37$ 个基因：$13$ 个编码与 $\mathrm{ATP}$ 合成有关的蛋白质和酶；其余 $24$ 个转录为 $\mathrm{tRNA}$（$22$ 个）和 $\mathrm{rRNA}$（$2$ 个），参与线粒体蛋白质合成。线粒体功能是生物氧化和氧化磷酸化。
:::

:::keypoint{label="37 = 13 + 22 + 2"}
- $13$：$\mathrm{ATP}$ 合成有关的蛋白质和酶。
- $22$：$\mathrm{tRNA}$。
- $2$：$\mathrm{rRNA}$。
- 合计 $37$。第十三章还给出全长 $16\,569\,\mathrm{bp}$；本节没有重复写全长，基因数按 $37$ 记。
:::

:::pitfall{label="24 不是 24 种蛋白质"}
其余 $24$ 个基因转录为 $\mathrm{tRNA}$ 和 $\mathrm{rRNA}$，不是再编码 $24$ 条多肽。$13$ 才是蛋白质／酶。把 $37$ 全听成呼吸链亚基，第十三章的 $\mathrm{rRNA}/\mathrm{tRNA}$ 基因和本节“参与线粒体蛋白质的合成”对不上。
:::

:::compare{title="质粒、mtDNA、逆转录病毒基因组"}
| | 质粒 | $\mathrm{mtDNA}$ | 逆转录病毒（第五节） |
|--|------|----------------|----------------------|
| 遗传物质 | $\mathrm{DNA}$（染色体外） | $\mathrm{DNA}$（细胞器） | $\mathrm{RNA}$ |
| 复制 | 自我复制；常用作载体 | $\mathrm{D}$ 环；$\mathrm{pol}\ \gamma$ | 逆转录成双链 $\mathrm{DNA}$ 前病毒 |
| 本节深度 | 点名来历 | 专节 | 只在过渡句里露面 |

教材把这三类都写成“非染色体基因组／特殊复制”，但机制不是同一张图。
:::

$\mathrm{mtDNA}$ 容易发生突变，损伤后的修复较困难。$\mathrm{mtDNA}$ 的突变与衰老和一些疾病的发生有关。所以 $\mathrm{mtDNA}$ 的突变与修复，成为医学研究上引起广泛兴趣的科学问题。线粒体内蛋白质翻译时，使用的遗传密码和通用的遗传密码有一些差别。

:::definition{label="mtDNA 易突变、修复难"}
容易发生突变，损伤后的修复较困难。突变与衰老和一些疾病有关，是医学研究上引起广泛兴趣的问题。
:::

:::definition{label="线粒体遗传密码与通用密码有差别"}
线粒体内蛋白质翻译时，使用的遗传密码和通用遗传密码有一些差别。本节只立到这一句，不展开对照表。
:::

:::insight{label="易突变和核 DNA 的高保真不在同一套防护里"}
第一节写核复制错配约 $10^{-10}$，靠碱基选择、校读和修复。$\mathrm{mtDNA}$ 教材明确：易突变、修复较困难。不要把 $\mathrm{pol}\ \gamma$ 写成和 $\mathrm{pol}\ \varepsilon$ 同一档保真叙事。衰老在端粒那一段走酶活性，在线粒体这一段走 $\mathrm{mtDNA}$ 突变，两本账可以并存。
:::

:::pitfall{label="D 环复制仍需要引物，不是“环状就可以无引物起始”"}
教材第一句就写：复制时需合成引物。环状只免除端粒问题，不免除 $3'$-$\mathrm{OH}$。把 $\mathrm{D}$ 环答成“线粒体 $\mathrm{DNA}$ 不需要引物”，和“第一个引物／第二个反向引物”直接冲突。
:::

:::memory{label="本节必背要点"}
- [ ] 真核基因组复制在 $\mathrm{S}$ 期；增殖信号、营养、蛋白质因子和酶控制进入时机和速度。
- [ ] 基本机制与原核相似；更复杂因为基因组庞大 $+$ 核小体。
- [ ] 多染色体各自复制；每条染色体上千个复制子；分组激活，不同步。
- [ ] 早复制：转录活性高的 $\mathrm{DNA}$。晚复制：卫星 $\mathrm{DNA}$、着丝粒、端粒。
- [ ] 酵母 $\mathrm{ARS}$：$11\,\mathrm{bp}$ 富 $\mathrm{AT}$，$\mathrm{A}(\mathrm{T})\mathrm{TTTATA}(\mathrm{G})\mathrm{TTTA}(\mathrm{T})$；也有比 $\mathrm{oriC}$ 更长的真核起点。
- [ ] 起始仍要复制叉、引发体、$\mathrm{RNA}$ 引物；酶和辅助蛋白顺序尚未完全明了。
- [ ] 起始用 $\mathrm{pol}\ \alpha$、$\varepsilon$、$\delta$，加解旋酶、拓扑酶、$\mathrm{RFA}$、$\mathrm{RFC}$。
- [ ] $\mathrm{PCNA}$：同源三聚体滑动夹，类似 $\mathrm{pol}$ Ⅲ 的 $\beta$ 亚基；$\mathrm{RFC}$ 加载；使 $\mathrm{pol}\ \delta$ 持续合成；促核小体生成；增殖指标。
- [ ] 聚合酶转换：$\alpha$ 引物 $\rightarrow\delta$ 后随、$\varepsilon$ 前导。
- [ ] 真核引物和冈崎片段比原核短；冈崎片段 $\approx$ 核小体 $\mathrm{DNA}$ $135\,\mathrm{bp}$ 或其若干倍。
- [ ] 到核小体单位之末 $\delta$ 脱落，$\alpha$ 再引发；转换频率高；前导链只连续半个复制子。
- [ ] $\mathrm{FEN}1$、$\mathrm{RNase}\ \mathrm{H}$ 等去除真核 $\mathrm{RNA}$ 引物。
- [ ] 酶速率约 $50$ 个 $\mathrm{dNTP}/\mathrm{s}$，多复制子故总体不慢。
- [ ] 合成后立即装核小体；破坏只在叉旁短区；旧组蛋白大部分重装；$\mathrm{S}$ 期大量新组蛋白；八聚体数量是同期核小体 $\mathrm{DNA}$ 的两倍。
- [ ] 末端最后引物去除留空隙，单链母链可被 $\mathrm{DNase}$ 酶解；低等生物可越来越短；有端粒则不会。
- [ ] 端粒：粒状帽子，$\mathrm{TxGy}$ 数十至上百次，可反折；防融合、防末端信息丢失。
- [ ] 端粒酶：$80$ 年代中期发现；$1997$ 年鉴定 $\mathrm{hTR}$（$\sim 150\,\mathrm{nt}$）、$\mathrm{hTP}1$、$\mathrm{hTRT}$；模板 $+$ 逆转录。
- [ ] 爬行模型：$\mathrm{CyAx}$ 认 $\mathrm{TxGy}$ $\rightarrow$ 逆转录 $\rightarrow$ 爬行再逆转录 $\rightarrow$ 引物酶 $+$ $\mathrm{DNA}\ \mathrm{pol}$ 填子链。
- [ ] 细胞老化与端粒酶活性下降有关；个体老化非单因素。肿瘤酶活性常增高，长度不一定成正比。
- [ ] 每个细胞周期只在 $\mathrm{S}$ 期复制一次。$\mathrm{G}_1$ 选复制基因、装 $\mathrm{pre}$-$\mathrm{RC}$（$\mathrm{RLF}$）；$\mathrm{S}$ 期细胞周期蛋白 $\mathrm{A}$–$\mathrm{CDK}2$ 磷酸化后激活。
- [ ] $\mathrm{pre}$-$\mathrm{RC}$ 顺序：$\mathrm{ORC}$（似 $\mathrm{DnaA}$）$\rightarrow\mathrm{CDC}6\rightarrow\mathrm{CDT}1\rightarrow$ 两套 $\mathrm{MCM}2$-$7$（似 $\mathrm{DnaB}$），未激活。
- [ ] 原核识别与解旋、募集聚合酶偶联；真核选择与激活分离。
- [ ] $\mathrm{mtDNA}$：$\mathrm{D}$ 环；两起点不在同一位点；$\mathrm{pol}\ \gamma$；$37$ 基因 $=13$ 蛋白／酶 $+22\,\mathrm{tRNA}+2\,\mathrm{rRNA}$；易突变、修复难；遗传密码有差别。
:::
