# 第一节　基因诊断

第二十四章把「从基因水平把病认出来」和「从基因水平把病改回去」分成两户。本节只立基因诊断：它属于分子诊断，通常针对 $\mathrm{DNA}$ 和 $\mathrm{RNA}$；广义分子诊断还可定量蛋白质。$\mathrm{Kan\ Y.W.}$ 开创的是 $\alpha$ 地中海贫血基因缺失和镰状细胞贫血 $\mathrm{RFLP}$。$\mathrm{PCR}$-$\mathrm{ASO}$（图24-1）、$\mathrm{PCR}$-$\mathrm{RFLP}$（图24-2）、$\mathrm{STR}$ 亲权（图24-3）三户不要并。基因诊断不能取代其他临床诊断；针对病原体时只判外源基因有无和拷贝数。基因治疗、载体、体细胞靶细胞交给第二节。

:::concept{term="先问查的是内源基因异常还是外源病原体基因，再问用哪一种核酸技术"}
看见“基因诊断”，先不要默写测序仪名单。户头是：针对 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 的分子诊断。分析内源性基因及其表达产物是否异常，或检测特定外源基因是否存在。表型改变往往晚且不特异；基因诊断不依赖表型，可以早期、特异、灵敏。技术是杂交、$\mathrm{PCR}$ 及衍生、$\mathrm{SSCP}$、$\mathrm{RFLP}$、测序、芯片。应用落在遗传病、法医学 $\mathrm{STR}$、感染、多基因常见病预测、疗效和用药。假阳性必须和临床、影像、生化、病理一起评——这一句写在本节末，不要掉到第二节文首。
:::

本章开篇的章题图电子版缺失，正文不嵌入该图。本节使用的插图是图24-1（针对 $\beta$ 地中海贫血的 $\mathrm{PCR}$-$\mathrm{ASO}$ 分析示意图）、图24-2（针对镰状细胞贫血的 $\mathrm{PCR}$-$\mathrm{RFLP}$ 分析示意图）和图24-3（$\mathrm{STR}$ 等位基因在家族中遗传示意图，位点 $\mathrm{D13S317}$）。图24-4（逆转录病毒的生活周期示意图）在第二节。

人类大多数疾病与自身基因结构与功能发生异常，以及外源性细菌、病毒等病原体致病基因的体内异常表达相关。利用多种分子生物学技术，从基因水平探讨疾病发生、发展的分子机制，评估个体对疾病的易感性，进而采用针对性的手段矫正疾病的紊乱状态，是现代医学发展的重要方向。基因诊断（gene diagnosis）和基因治疗（gene therapy）已成为现代分子医学的重要内容之一。

:::definition{label="基因诊断"}
基因诊断（gene diagnosis）：通常将针对 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 的分子诊断称为基因诊断。户头落在核酸，还不是「把蛋白质定量也算进来」——蛋白质定量属于广义分子诊断。
:::

:::definition{label="基因治疗（开篇只点名）"}
基因治疗（gene therapy）：与基因诊断并列，同属现代分子医学。展开、策略、载体和生活周期是第二节的账。本节只承认它存在。
:::

:::keypoint{label="开篇两句不要并户"}
- 多数疾病：自身基因结构／功能异常，或外源病原体致病基因在体内异常表达。
- 分子医学两件事：先在基因水平诊断，再在基因水平治疗。诊断是本节，治疗是第二节。
:::

早在 $20$ 世纪 $70$ 年代，美国加州大学旧金山分校华裔科学家 $\mathrm{Kan\ Y.W.}$ 首次检测了 $\alpha$ 地中海贫血的基因缺失状态，发现了镰状细胞贫血的限制性核酸内切酶片段长度多态性，开创了基因诊断的历史先河。伴随相关检测手段的不断进步，基因诊断技术已从实验室研究逐步进入临床应用阶段。作为一种新的诊断模式，基因诊断在许多重大疾病的早期诊断、分期分型、疗效判断、预后评估、用药指导等方面显示出独特优势，已应用于遗传性疾病、感染性疾病、恶性肿瘤以及法医学等多个方面。

:::definition{label="Kan Y.W. 开创的两件事"}
$20$ 世纪 $70$ 年代，$\mathrm{Kan\ Y.W.}$（美国加州大学旧金山分校）①首次检测 $\alpha$ 地中海贫血的基因缺失状态；②发现镰状细胞贫血的限制性核酸内切酶片段长度多态性（$\mathrm{RFLP}$）。本版把这两件事写成「开创基因诊断的历史先河」。
:::

:::timeline{period="基因诊断开创"}
- **年代** 20 世纪 70 年代
- **人物** 美国加州大学旧金山分校华裔科学家 Kan Y.W.
- **α 地贫** 首次检测 α 地中海贫血的基因缺失状态
- **镰贫** 发现镰状细胞贫血的限制性核酸内切酶片段长度多态性
- **其后** 从实验室研究进入临床：早期诊断、分期分型、疗效判断、预后评估、用药指导
:::

:::pitfall{label="Kan Y.W. 的两件事不要并成一种病、一种技术"}
$\alpha$ 地中海贫血查的是基因缺失；镰状细胞贫血查的是 $\mathrm{RFLP}$。后文图24-1 是 $\beta$ 地贫的 $\mathrm{PCR}$-$\mathrm{ASO}$，图24-2 才是镰贫的 $\mathrm{PCR}$-$\mathrm{RFLP}$。写成「地贫就是 $\mathrm{RFLP}$」或「镰贫就是 $\mathrm{ASO}$」，三张图的户头就乱了。
:::

:::insight{label="应用名单先记四类，技术后文再拆"}
本版点名：遗传性疾病、感染性疾病、恶性肿瘤、法医学。优势写在早期诊断、分期分型、疗效判断、预后评估、用药指导。不要把「已经能治」写进诊断这一节。
:::

## 一、基因诊断是针对DNA和RNA的分子诊断

基因诊断属于分子诊断。从广义上讲，凡是利用分子生物学技术对生物体 $\mathrm{DNA}$ 序列及其产物（如 $\mathrm{mRNA}$ 和蛋白质）进行的定性、定量分析，均可称为分子诊断（molecular diagnosis）。从技术角度来讲，目前的分子诊断方法主要针对 $\mathrm{DNA}$，涉及功能分析时，还可定量检测 $\mathrm{RNA}$（主要是 $\mathrm{mRNA}$）和蛋白质等分子。通常将针对 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 的分子诊断称为基因诊断。

:::definition{label="分子诊断"}
分子诊断（molecular diagnosis）：利用分子生物学技术，对生物体 $\mathrm{DNA}$ 序列及其产物（如 $\mathrm{mRNA}$ 和蛋白质）进行定性、定量分析。广义户头包含蛋白质。
:::

:::definition{label="通常所说的基因诊断"}
针对 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 的分子诊断。技术上目前主要针对 $\mathrm{DNA}$；涉及功能分析时，还可定量检测 $\mathrm{RNA}$（主要是 $\mathrm{mRNA}$）和蛋白质。后一句的蛋白质仍写在分子诊断里，不要把基因诊断的「通常」范围扩成蛋白质定量。
:::

:::compare{title="分子诊断 vs 基因诊断"}
| | 本版原句 | 对象 | 不要写成 |
|--|---------|------|---------|
| 分子诊断（广义） | $\mathrm{DNA}$ 序列及其产物（$\mathrm{mRNA}$ 和蛋白质）的定性、定量 | 核酸＋蛋白质 | 「分子诊断＝只测 $\mathrm{DNA}$」 |
| 目前技术主账 | 主要针对 $\mathrm{DNA}$；功能分析时可定量 $\mathrm{RNA}$（主要 $\mathrm{mRNA}$）和蛋白质 | $\mathrm{DNA}$ 为主，功能才扩 | 「从来不能测蛋白质」 |
| 基因诊断 | 通常针对 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ | 核酸 | 「基因诊断包含所有蛋白组学」 |

问「基因诊断属于什么」先答分子诊断；问「蛋白质算不算」看广义分子诊断，不看「通常」那一句。
:::

:::pitfall{label="不要把蛋白质定量直接写成基因诊断"}
教材把蛋白质写进广义分子诊断，又把基因诊断收成「针对 $\mathrm{DNA}$ 和 $\mathrm{RNA}$」。后文甲胎蛋白是肝癌标志物之一，那是表达产物，不是把蛋白质组学整章搬进本节。
:::

大部分疾病表型是由自身基因结构及功能异常或外源性病原体基因的异常表达所致。例如，肿瘤的发生和发展具有多因素性和多阶段性，在各阶段均可能涉及内源性基因结构与功能的改变；感染性疾病的发生与病原体侵入相关，患者体内存在外源性病原体的遗传物质。基因诊断即分析内源性基因及其表达产物是否异常，或检测特定外源基因是否存在，进而对临床疾病作出诊断。

:::definition{label="基因诊断分析的两类对象"}
①内源性基因及其表达产物是否异常；②特定外源基因是否存在。两句都要答，才落到临床诊断。
:::

:::compare{title="内源异常 vs 外源基因存在"}
| | 本版例子 | 查什么 | 后文落点 |
|--|---------|--------|---------|
| 内源 | 肿瘤多因素、多阶段，各阶段都可能改内源基因结构与功能 | 自身基因及其表达产物是否异常 | 遗传病分型、多基因病预测、疗效和用药 |
| 外源 | 感染：体内有病原体遗传物质 | 特定外源基因在不在 | 感染性疾病；本节末还强调「只能判有无和拷贝数」 |

肿瘤走内源；感染走外源。不要把「查出病毒 $\mathrm{DNA}$」答成「患者自己的基因突变」。
:::

:::insight{label="表型是果，基因诊断问的是因"}
大部分疾病表型由基因结构／功能异常或外源病原体基因表达而来。基因诊断不从症状倒推，而是直接问核酸。
:::

### （一）基因诊断的样品来源广泛

临床上可用于基因诊断的样品包括血液、组织块、精液、唾液、尿液、羊水、绒毛、毛发（含毛囊）、细胞、微生物等。进行基因诊断的前提是疾病表型与基因型的关系已被阐明。根据疾病特点和诊断目的，选择合适的待检样品，提取 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 进行目标分子的检测。在开展胎儿 $\mathrm{DNA}$ 诊断时，还可直接从母亲外周血中提取胎儿细胞或胎儿 $\mathrm{DNA}$ 进行检测。分析 $\mathrm{RNA}$ 时需确保一定的样品新鲜度。

:::definition{label="样品名单"}
血液、组织块、精液、唾液、尿液、羊水、绒毛、毛发（含毛囊）、细胞、微生物等。名单要含毛囊这一句：光有毛干不够。
:::

:::definition{label="前提是表型与基因型关系已阐明"}
不是「有核酸就能诊」。疾病表型与基因型的关系已经清楚，才选样品、抽 $\mathrm{DNA}$ 或 $\mathrm{RNA}$、打目标分子。
:::

:::definition{label="胎儿 DNA 诊断的样品"}
除羊水、绒毛外，还可直接从母亲外周血中提取胎儿细胞或胎儿 $\mathrm{DNA}$。这是产前诊断的样品账，不是另开一种疾病。
:::

:::pitfall{label="分析 RNA 必须顾新鲜度"}
教材单独立了「分析 $\mathrm{RNA}$ 时需确保一定的样品新鲜度」。$\mathrm{DNA}$ 相对稳定，$\mathrm{RNA}$ 易降解。写成「血样放到第二天再抽 $\mathrm{mRNA}$ 也一样」，Northern、表达定量都没有对象。
:::

:::keypoint{label="样品这一小节三句话"}
- 来源广：体液、组织、毛发（含毛囊）、微生物都可。
- 先有表型—基因型关系，再选样品。
- 胎儿可走母血中的胎儿细胞或胎儿 $\mathrm{DNA}$；$\mathrm{RNA}$ 要新鲜。
:::

### （二）基因诊断具有独特的优势

大部分疾病的表型改变缺乏特异性，往往是在疾病的中晚期才出现。基于疾病的表型改变、患者的临床症状和体征进行的医学诊断常常不能作出及时准确的诊断。基因诊断不依赖疾病的表型改变，具有特异性强、灵敏度高、早期诊断、快速诊断、适用性强、诊断范围广的独特优势。

:::definition{label="不依赖表型改变"}
表型往往晚、且缺乏特异性。基因诊断直接以遗传物质为对象，不靠症状和体征才开口。六句优势：特异、灵敏、早期、快速、适用性强、范围广。
:::

:::compare{title="表型诊断 vs 基因诊断"}
| | 依据 | 时间 | 本版原句 |
|--|------|------|---------|
| 表型／症状体征 | 疾病表型改变 | 常到中晚期 | 常常不能及时准确 |
| 基因诊断 | 遗传物质本身 | 症状出现前即可 | 不依赖表型改变 |

问「为什么能早期」看「直接以遗传物质为对象」；问「为什么传统诊断容易晚」看表型缺乏特异、出现晚。
:::

**1. 基因诊断具有较强的特异性**　基因诊断属于病因诊断，具有较强的特异性。基因的突变及功能异常、外源性病原体基因的存在是疾病发生的原因，采用分子生物学技术检测这些特异基因序列，可作出特异性诊断。

:::definition{label="病因诊断"}
基因诊断属于病因诊断。查的是突变及功能异常，或外源病原体基因存在，所以特异。不是「任何核酸探针都特异」——后文斑点印迹就写了易假阳性。
:::

**2. 基因诊断具有较高的灵敏度**　核酸分子杂交技术与 $\mathrm{PCR}$ 技术的联合使用可检测微量病原体基因及拷贝数极少的基因突变，表现出较高的灵敏度。核酸分子杂交技术可采用具有生物催化活性的酶、放射性核素或荧光素标记的高灵敏度探针来检测；$\mathrm{PCR}$ 技术可对几个细胞、一根头发、一滴血迹、组织切片和石蜡包埋组织块中的微量 $\mathrm{DNA}$ 进行高效扩增。

:::definition{label="灵敏度来自杂交加 PCR"}
杂交：酶、放射性核素或荧光素标记的高灵敏度探针。$\mathrm{PCR}$：几个细胞、一根头发、一滴血迹、组织切片和石蜡包埋组织块中的微量 $\mathrm{DNA}$ 都能扩增。两路联合，才能查微量病原体基因和拷贝数极少的突变。
:::

:::insight{label="石蜡包埋组织块也在灵敏度这一句里"}
临床病理存档材料可以拿来做基因诊断，前提仍是抽得出微量 $\mathrm{DNA}$。这不是另开一种杂交方法。
:::

**3. 基因诊断可实现早期和快速诊断**　基因诊断直接以遗传物质作为诊断对象，可在临床症状或表型改变出现前作出早期诊断。与传统的医学诊断相比，基因诊断的过程往往更直接、快速。例如，采用细菌培养技术对感染性疾病作出诊断通常需要数天时间，而采用基因诊断技术仅需数小时。基因诊断还可快速检测不易在体外培养或培养安全风险较大的病原体，如人类免疫缺陷病毒、肝炎病毒等。

:::definition{label="早期：症状前就能查"}
对象是遗传物质，所以不必等表型出现。早期和「灵敏」不是同一句话：早期问的是时间点，灵敏问的是拷贝数。
:::

:::definition{label="快速：小时级，且能查难培养病原体"}
细菌培养常需数天，基因诊断仅需数小时。还适用于不易体外培养、或培养安全风险较大的病原体。本版点名：人类免疫缺陷病毒、肝炎病毒。
:::

:::pitfall{label="不要把「数小时」写成已经替代培养的全部意义"}
教材用培养对照的是速度。本节末还写：针对病原体的基因诊断难以检测病原体进入体内后机体的反应，也不能取代其他临床诊断。速度优势不等于「培养可以不作」。
:::

**4. 基因诊断的适用性强、诊断范围广**　随着更多疾病基因和疾病相关基因的成功鉴定，基因诊断的理论基础不断丰富，诊断范围不断拓展，表现出较强的适用性。基因诊断技术可对有遗传病家族史的致病基因携带者作出预警诊断，还可评估个体对肿瘤、心血管疾病、高血压等多基因病的易感性，并进行疾病分期分型、发展阶段、抗药性等方面的分析。

:::definition{label="适用性跟着疾病基因鉴定走"}
更多疾病基因和疾病相关基因被鉴定，理论基础才丰富，范围才拓展。没有「表型—基因型关系」，前面样品那一小节的前提就不成立。
:::

:::keypoint{label="优势四条对应后文应用"}
- 特异：病因序列。
- 灵敏：杂交标记 $+$ $\mathrm{PCR}$ 微量扩增。
- 早期／快速：症状前；培养数天 vs 基因诊断数小时；难培养病原体。
- 范围广：携带者预警，多基因病易感性，分期分型、发展阶段、抗药性。
:::

## 二、基因诊断的基本技术日益成熟

基因诊断技术可用于定性与定量分析。检测基因分型和基因突变属于定性分析，而测定基因拷贝数及基因表达产物量属于定量分析。针对病原体基因进行基因诊断时，定性分析可诊断其在人体存在与否，而定量分析则可确定其含量多少。常用的基因诊断技术包括核酸分子杂交、聚合酶链反应（polymerase chain reaction，$\mathrm{PCR}$）及衍生技术、单链构象多态性（single-strand conformation polymorphism，$\mathrm{SSCP}$）分析、限制性片段长度多态性（restriction fragment length polymorphism，$\mathrm{RFLP}$）分析、基因测序、基因芯片等。这些技术可单独或者联合应用。

:::definition{label="定性分析"}
检测基因分型和基因突变。针对病原体：判断其在人体存在与否。
:::

:::definition{label="定量分析"}
测定基因拷贝数及基因表达产物量。针对病原体：确定含量多少。
:::

:::compare{title="定性 vs 定量（含病原体）"}
| | 一般对象 | 落到病原体 |
|--|---------|-----------|
| 定性 | 基因分型、基因突变 | 外源基因有还是无 |
| 定量 | 拷贝数、表达产物量 | 含量多少 |

后文局限还要补一句：即使定量了拷贝数，也难以检测机体对病原体的反应。
:::

:::definition{label="常用技术名单"}
核酸分子杂交、$\mathrm{PCR}$ 及衍生、$\mathrm{SSCP}$、$\mathrm{RFLP}$、基因测序、基因芯片。可单独或联合。名单里的 $\mathrm{RFLP}$、$\mathrm{SSCP}$ 后文常与 $\mathrm{PCR}$ 联用，不要看成六种互斥流水线。
:::

### （一）核酸分子杂交技术是基因诊断的基本方法

核酸分子杂交技术是基因诊断最基本的方法之一。不同来源的 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 在一定的条件下，通过变性和复性可形成杂化双链。选择一段已知序列的核酸片段作为探针，进行放射性核素、生物素或荧光染料的标记，再与目的核酸进行杂交反应，通过检测标记信号便可对未知的目的核酸进行定性或定量分析。

:::definition{label="核酸分子杂交"}
不同来源的 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 经变性、复性形成杂化双链。已知序列片段作探针，标记放射性核素、生物素或荧光染料，与目的核酸杂交，凭标记信号做定性或定量。
:::

:::insight{label="探针身份必须已知，未知的是样品"}
「选择一段已知序列」是探针；未知的是目的核酸。写成「用病人样品去标记未知探针」，杂交这一户就反了。
:::

**1. $\mathrm{DNA}$ 印迹检测 $\mathrm{DNA}$ 异常**　$\mathrm{DNA}$ 印迹又称为 Southern 印迹（Southern blotting），是最为经典的基因诊断方法。$\mathrm{DNA}$ 印迹一般可显示 $50\sim 20\,000\,\mathrm{bp}$ 的 $\mathrm{DNA}$ 片段，片段大小的信息是其诊断基因异常的重要依据。$\mathrm{DNA}$ 印迹实验结果可靠，用于特异 $\mathrm{DNA}$ 序列检测、限制性核酸内切酶图谱和基因定位、正常和突变样品的基因型鉴定、基因缺失或插入片段大小等信息的获取等；但其操作流程烦琐、费时费力，常需使用放射性核素，难以成为一种常规的临床诊断手段。

:::definition{label="Southern 印迹"}
$\mathrm{DNA}$ 印迹，又称 Southern blotting。显示范围一般 $50\sim 20\,000\,\mathrm{bp}$。片段大小是诊断基因异常的重要依据。用途：特异序列、限制酶图谱和基因定位、正常／突变基因型、缺失或插入片段大小。缺点：烦琐、费时、常需核素，难以作为常规临床手段。
:::

**2. $\mathrm{RNA}$ 印迹分析 $\mathrm{RNA}$ 特点**　$\mathrm{RNA}$ 印迹又称为 Northern 印迹法（Northern blotting），是通过标记的核酸探针与待测样本 $\mathrm{RNA}$ 杂交，对组织或细胞中的 $\mathrm{RNA}$ 进行定性或定量分析。$\mathrm{RNA}$ 印迹对 $\mathrm{RNA}$ 样品纯度要求高，限制了其在临床诊断中的应用。

:::definition{label="Northern 印迹"}
$\mathrm{RNA}$ 印迹，又称 Northern blotting。标记探针与样品 $\mathrm{RNA}$ 杂交，对组织或细胞中的 $\mathrm{RNA}$ 定性或定量。对样品纯度要求高，限制了临床应用。
:::

**3. 斑点印迹检测固相载体上的核酸**　斑点印迹又称为斑点杂交（dot blot hybridization），是制备标记的核酸探针，将 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 样品固定至特定载体上，两者进行杂交，检测样品中是否存在特异的基因或表达产物。斑点印迹具有简便、快速、灵敏和样品用量少的优点，可用于基因组中特定基因及其表达产物的定性与定量分析；但其无法测定目的基因的大小，特异性低，易出现假阳性结果。另外，等位基因特异性寡核苷酸（allele specific oligonucleotide，$\mathrm{ASO}$）分子杂交是检测点突变的有效技术。可人工设计并合成针对正常和突变位点的 $\mathrm{ASO}$ 探针，再与固相载体上的样品进行杂交，根据杂交结果判断特定基因的突变状态。

:::definition{label="斑点印迹"}
又称斑点杂交（dot blot hybridization）。样品 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 固定在载体上，与标记探针杂交，问有没有特异基因或表达产物。优点：简便、快速、灵敏、用量少。缺点：无法测定目的基因大小，特异性低，易假阳性。
:::

:::definition{label="ASO 分子杂交"}
等位基因特异性寡核苷酸（allele specific oligonucleotide，$\mathrm{ASO}$）杂交是检测点突变的有效技术。分别合成针对正常位点和突变位点的探针，与固相载体上的样品杂交，判断突变状态。后文 $\mathrm{PCR}$-$\mathrm{ASO}$ 是先扩增再杂交，图24-1 就是这一户。
:::

**4. 反向斑点印迹检测基因点突变**　反向斑点印迹（reverse dot blotting，$\mathrm{RDB}$）是将多种特异性寡核苷酸探针固定至特定载体上，针对基因多个位点进行样品的 $\mathrm{PCR}$ 扩增并进行生物素等标记，再将两者杂交，一次杂交可同时筛查出样品 $\mathrm{DNA}$ 中的多种突变。反向斑点印迹常与 $\mathrm{ASO}$ 分子杂交联用，可提高检测点突变结果的可靠性，应用于遗传性疾病的基因诊断、病原微生物的鉴定分型、乙型肝炎病毒耐药、癌基因的点突变分析等方面。

:::definition{label="反向斑点印迹"}
$\mathrm{RDB}$（reverse dot blotting）：多种特异性寡核苷酸探针固定在载体上，样品经多位点 $\mathrm{PCR}$ 扩增并标记（如生物素），一次杂交同时筛多种突变。常与 $\mathrm{ASO}$ 联用。应用：遗传病诊断、病原微生物鉴定分型、乙型肝炎病毒耐药、癌基因点突变。
:::

:::compare{title="正斑点 vs 反向斑点"}
| | 固定在载体上的是谁 | 一次能看什么 |
|--|------------------|------------|
| 斑点印迹／$\mathrm{ASO}$ | 样品核酸 | 该样品与某探针是否杂交 |
| $\mathrm{RDB}$ | 多种探针 | 同一样品的多种突变 |

「反向」说的是探针先铺在膜上，不是「杂交方向反了就不特异」。
:::

:::pitfall{label="斑点印迹不要写成能读片段大小"}
Southern 靠片段大小；斑点印迹「无法测定目的基因的大小」，还易假阳性。写成「点在膜上就等于做了 Southern」，缺失／插入长度那一户就空了。
:::

**5. 原位杂交直接检测细胞或组织中的核酸**　原位杂交（in situ hybridization，$\mathrm{ISH}$）是针对已知位点设计特定标记的核酸探针，直接与细胞或组织标本中的 $\mathrm{DNA}/\mathrm{RNA}$ 杂交，再通过杂交信号的检测对特定核酸序列进行定位、定性和定量分析。利用原位杂交技术能够显示目的核酸序列的空间定位特点，获得含有特定核酸序列的具体细胞在样品中的位置、数量及类型信息；分析目的 $\mathrm{DNA}$ 在细胞核或染色体上的分布；检测组织或细胞是否感染细菌或病毒等病原体。通过与细胞内 $\mathrm{RNA}$ 进行杂交还可检测样本组织细胞中特定基因的表达状态。

以荧光素或生物素作为探针标记的原位杂交，即为荧光原位杂交（fluorescence in situ hybridization，$\mathrm{FISH}$）技术。$\mathrm{FISH}$ 可对任何给定的基因组区域进行特异性杂交，对中期分裂相染色体及间期细胞核进行分析，获得传统技术所无法检测到的染色体信息。$\mathrm{FISH}$ 还可用于鉴别染色体数目和结构的异常，特别是能够对染色体的异常改变进行原位显示和定量分析，适用于新鲜、冷冻、石蜡包埋标本及穿刺物和脱落细胞等样品的检测。

:::definition{label="原位杂交"}
$\mathrm{ISH}$（in situ hybridization）：标记探针直接与细胞或组织中的 $\mathrm{DNA}/\mathrm{RNA}$ 杂交。能做定位、定性、定量；显示空间定位、细胞位置／数量／类型；看目的 $\mathrm{DNA}$ 在核或染色体上的分布；查细菌或病毒感染；与胞内 $\mathrm{RNA}$ 杂交还可看表达状态。
:::

:::definition{label="FISH"}
荧光原位杂交（fluorescence in situ hybridization）：以荧光素或生物素标记探针的原位杂交。可对给定基因组区域特异杂交，分析中期染色体和间期核；鉴别染色体数目和结构异常，原位显示并定量。样品：新鲜、冷冻、石蜡包埋、穿刺物、脱落细胞。
:::

:::compare{title="Southern / Northern / 斑点 / ISH"}
| | 对象 | 还能看见什么 | 临床短板 |
|--|------|------------|---------|
| Southern | $\mathrm{DNA}$ | 片段大小（$50\sim 20\,000\,\mathrm{bp}$） | 烦琐、常需核素，难常规 |
| Northern | $\mathrm{RNA}$ | 表达的定性定量 | 纯度要求高 |
| 斑点／$\mathrm{ASO}$ | 固相上的 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ | 有无特异序列；$\mathrm{ASO}$ 可看点突变 | 无大小信息，易假阳性 |
| $\mathrm{ISH}$／$\mathrm{FISH}$ | 细胞或组织原位的 $\mathrm{DNA}/\mathrm{RNA}$ | 空间定位、染色体数目／结构 | 不是用来替代 $\mathrm{PCR}$ 分型的 |

问「缺了多大一段」看 Southern；问「这个点突没突」看 $\mathrm{ASO}$；问「哪条染色体、哪个细胞」看 $\mathrm{FISH}$。
:::

:::keypoint{label="杂交这一小节的标记三种、方法五户"}
- 标记：放射性核素、生物素、荧光染料（$\mathrm{FISH}$ 还点名荧光素）。
- Southern、Northern、斑点（含 $\mathrm{ASO}$）、$\mathrm{RDB}$、$\mathrm{ISH}$（含 $\mathrm{FISH}$）。
- $\mathrm{RDB}$ 常与 $\mathrm{ASO}$ 联用，后文乙肝耐药还要再出场。
:::

### （二）PCR技术是特异且快速的基因诊断方法

$\mathrm{PCR}$ 技术能够快速、特异性地进行基因扩增，具有较高的灵敏度。以 $\mathrm{PCR}$ 为基础的相关衍生技术发展迅速，常与其他技术联合使用，广泛应用于致病基因鉴定、核酸序列分析、$\mathrm{DNA}$ 多态性检测、遗传性及感染性疾病诊断、法医鉴定及个体识别等领域。

:::definition{label="PCR 在基因诊断里的位置"}
快速、特异扩增，灵敏度高。衍生技术常与其他方法联用。应用：致病基因鉴定、核酸序列分析、$\mathrm{DNA}$ 多态性、遗传病和感染病诊断、法医鉴定及个体识别。
:::

**1. $\mathrm{PCR}$ 技术特异性检测疾病相关基因的表达及突变**　$\mathrm{PCR}$ 技术可直接检测样品中疾病相关基因的存在、缺失或突变，简便灵敏，适用于临床诊断。例如，裂口 $\mathrm{PCR}$（gap $\mathrm{PCR}$）是一种跨越基因缺失或插入部位的 $\mathrm{PCR}$ 技术，基本原理是首先设计并合成一组序列上跨越突变（缺失或插入）断裂点的引物，再将待测 $\mathrm{DNA}$ 样本进行 $\mathrm{PCR}$ 扩增，然后进行琼脂糖凝胶电泳，以扩增片段的大小直接判断是否存在缺失或插入突变。多重 $\mathrm{PCR}$（multiplex $\mathrm{PCR}$）则是另一种检测 $\mathrm{DNA}$ 异常的方法，基本原理是在一次 $\mathrm{PCR}$ 反应中加入多种引物，对一份 $\mathrm{DNA}$ 样本中的不同系列片段进行扩增，根据电泳图谱上不同长度 $\mathrm{DNA}$ 片段存在与否来判断基因片段的缺失或突变情况。

:::definition{label="裂口 PCR"}
gap $\mathrm{PCR}$：引物序列跨越缺失或插入的断裂点，扩增后电泳，以片段大小判断有无缺失或插入。户头是「跨越断裂点」，不是点突变探针。
:::

:::definition{label="多重 PCR"}
multiplex $\mathrm{PCR}$：一次反应加多种引物，扩增不同系列片段，看电泳上哪些长度的片段在、哪些不在，以判断缺失或突变。户头是「一份样品、多种引物」。
:::

:::compare{title="裂口 PCR vs 多重 PCR"}
| | 引物怎么设计 | 读什么 |
|--|------------|--------|
| 裂口 $\mathrm{PCR}$ | 一组引物跨越缺失／插入断裂点 | 扩增片段大小 |
| 多重 $\mathrm{PCR}$ | 一次加入多种引物 | 不同长度片段存在与否 |

两户都走电泳，都不是图24-1 的 $\mathrm{ASO}$ 点杂交。
:::

**2. $\mathrm{PCR}$-$\mathrm{ASO}$ 技术基于突变探针检测基因突变**　$\mathrm{PCR}$-$\mathrm{ASO}$ 杂交技术可检测基因上已知的点突变、微小的缺失或插入，适用于突变类型较少的遗传病诊断。首先设计并合成包含突变位点在内的 $\mathrm{ASO}$ 探针（突变探针）和包含未突变位点的正常探针，再对样品进行 $\mathrm{PCR}$ 扩增并固定于特定载体上，两者进行杂交。根据杂交信号判断受检者是否存在基因突变，还可进行已知突变的基因分型。如图24-1 所示，针对 $\beta$ 地中海贫血珠蛋白基因第 $17$ 密码子的点突变位点设计相应的突变及正常探针。正常人样本仅与正常探针杂交产生信号，突变纯合子患者也只能被突变探针所识别，而突变杂合子则能同时与两种探针产生杂交信号。

:::definition{label="PCR-ASO"}
先 $\mathrm{PCR}$ 扩增样品并固定，再用正常探针和突变探针分别杂交。检测已知点突变、微小缺失或插入，适用于突变类型较少的遗传病。可做已知突变的基因分型。
:::

:::definition{label="图24-1 的 β 地贫第 17 密码子"}
针对 $\beta$ 地中海贫血珠蛋白基因第 $17$ 密码子点突变：正常人只与正常探针杂交；突变纯合子只被突变探针识别；突变杂合子与两种探针都杂交。
:::

:::timeline{period="PCR-ASO 读图24-1"}
- **位点** β 地中海贫血珠蛋白基因第 17 密码子点突变
- **探针** 正常探针含未突变位点，突变探针含突变位点
- **样品** PCR 扩增后固定于载体
- **A 正常人** 只与正常探针显信号（第 1 行检测孔）
- **B 突变纯合子** 只与突变探针显信号（第 2 行检测孔）
- **C 突变杂合子** 两行都显信号
:::

:::insight{label="图24-1 先认两行探针，再认 A/B/C 三列"}
画面上方把基因组 $\mathrm{DNA}$ 分成正常和突变，差异落在一个 $\mathrm{A}/\mathrm{T}$。正常探针走左边，突变探针走右边，一起打到下方孔板。第 $1$ 行是正常探针检测孔，第 $2$ 行是突变探针检测孔。$\mathrm{A}$ 只有上行实心点，$\mathrm{B}$ 只有下行实心点，$\mathrm{C}$ 上下都有。不要把 $\mathrm{A}/\mathrm{B}/\mathrm{C}$ 认成三种探针。
:::

:::pitfall{label="PCR-ASO 不要写成酶切"}
这一户认的是探针能不能配对。酶切位点丢没丢是图24-2 的 $\mathrm{PCR}$-$\mathrm{RFLP}$。写成「$\beta$ 地贫第 $17$ 密码子用 $\mathrm{Mst}$Ⅱ 切」，两张图就并户了。
:::

**3. $\mathrm{PCR}$-$\mathrm{RFLP}$ 基于限制性核酸内切酶识别位点检测基因突变**　利用一种或几种限制性核酸内切酶对某一段 $\mathrm{DNA}$ 序列进行消化，会产生大小不同的 $\mathrm{DNA}$ 片段，称为限制性片段。在不同个体中出现的不同长度限制性片段类型被称为限制性片段长度多态性（restriction fragment length polymorphism，$\mathrm{RFLP}$）。有的基因突变可使某种限制性核酸内切酶识别位点发生改变，导致原有酶切位点的消失或新酶切位点的产生。

$\mathrm{PCR}$-$\mathrm{RFLP}$ 是将 $\mathrm{PCR}$ 与限制性片段长度多态性相结合，可快速、简便地对已知突变进行基因诊断的技术。首先是针对相应位点进行 $\mathrm{PCR}$ 扩增，经过限制性核酸内切酶消化后进行电泳分离，可在紫外线灯下分辨各种限制性片段的大小或位置，也可基于核素标记探针进行放射自显影，从而区分各种片段，判断是否发生相应的基因突变。例如，镰状细胞贫血是一种遗传性异常血红蛋白病，为 $\beta$-珠蛋白基因第 $6$ 密码子发生 $\mathrm{A}$-$\mathrm{T}$ 的单点突变，从而导致血红蛋白 $\beta$ 亚基发生 $\mathrm{Glu}$-$\mathrm{Val}$ 的氨基酸突变。利用 $\mathrm{PCR}$-$\mathrm{RFLP}$ 可用于镰状细胞贫血的基因诊断。如图24-2 所示，针对致病性 $\beta$-珠蛋白基因第 $6$ 密码子区域的 $110\,\mathrm{bp}$ 片段进行 $\mathrm{PCR}$ 扩增，然后经限制性核酸内切酶 $\mathrm{Mst}$Ⅱ 消化后进行凝胶电泳分析。正常人的扩增产物经 $\mathrm{Mst}$Ⅱ 消化可产成 $54\,\mathrm{bp}$ 与 $56\,\mathrm{bp}$ 两个片段，检测到两条电泳条带；镰状细胞贫血患者的扩增片段不被酶切，仅检测到一条 $110\,\mathrm{bp}$ 的条带；杂合子则可检测到 $54\,\mathrm{bp}$、$56\,\mathrm{bp}$ 和 $110\,\mathrm{bp}$ 三条带。

:::definition{label="RFLP"}
限制性片段：一种或几种限制酶消化一段 $\mathrm{DNA}$ 产生的不同大小片段。不同个体出现不同长度限制性片段类型，称为限制性片段长度多态性（$\mathrm{RFLP}$）。有的突变使酶切位点消失或新位点产生。
:::

:::definition{label="PCR-RFLP"}
先针对位点 $\mathrm{PCR}$ 扩增，再用限制酶消化、电泳。紫外下看片段大小或位置，也可用核素探针放射自显影。用于已知突变的快速基因诊断。
:::

:::definition{label="镰状细胞贫血的本版分子账"}
遗传性异常血红蛋白病。$\beta$-珠蛋白基因第 $6$ 密码子 $\mathrm{A}$-$\mathrm{T}$ 单点突变，血红蛋白 $\beta$ 亚基 $\mathrm{Glu}$-$\mathrm{Val}$。诊断走 $\mathrm{PCR}$-$\mathrm{RFLP}$，不是图24-1 的 $\mathrm{ASO}$。
:::

:::definition{label="图24-2 的 MstⅡ 三带型"}

:::

$\mathrm{PCR}$-引物介导的限制性分析（$\mathrm{PCR}$-primer introduced restriction analysis，$\mathrm{PCR}$-$\mathrm{PIRA}$）是 $\mathrm{PCR}$-$\mathrm{RFLP}$ 技术的延伸。基本原理是在设计引物时引入错配碱基，消除或产生新的酶切位点，该错配的结果最终表现为酶解的限制性片段长度差异性。主要分析对象是已知基因，利用相应的计算机软件可以分析基因上可能产生的酶切位点的错配。$\mathrm{PCR}$-$\mathrm{RFLP}$ 和 $\mathrm{PCR}$-$\mathrm{PIRA}$ 的主要区别在于后者需要人工引入酶切位点。另外，巢式 $\mathrm{PCR}$-限制性片段长度多态性（nested $\mathrm{PCR}$-$\mathrm{RFLP}$）是将 $\mathrm{RFLP}$ 与巢式 $\mathrm{PCR}$ 技术相结合，通过设计针对高度保守序列的引物对待测物种 $\mathrm{DNA}$ 进行 $\mathrm{PCR}$ 扩增，再对 $\mathrm{PCR}$ 产物进行 $\mathrm{RFLP}$ 分析。该方法省时，可应用于流行病学调查和临床常规检测。

:::definition{label="PCR-PIRA"}
引物设计时引入错配碱基，消除或产生新的酶切位点，最终表现为限制性片段长度差异。与 $\mathrm{PCR}$-$\mathrm{RFLP}$ 的主要区别：后者用天然酶切位点，前者要人工引入。对象主要是已知基因。
:::

:::definition{label="巢式 PCR-RFLP"}
针对高度保守序列做巢式 $\mathrm{PCR}$，再对产物做 $\mathrm{RFLP}$。省时，用于流行病学调查和临床常规检测。
:::

:::compare{title="RFLP 三户：天然位点、人工位点、先巢式再酶切"}
| | 酶切位点从哪来 | 本版用途 |
|--|--------------|---------|
| $\mathrm{PCR}$-$\mathrm{RFLP}$ | 突变本身改变天然识别位点 | 如镰贫 $\mathrm{Mst}$Ⅱ |
| $\mathrm{PCR}$-$\mathrm{PIRA}$ | 引物错配人工引入或消除位点 | 已知基因、靠软件找可能的错配 |
| 巢式 $\mathrm{PCR}$-$\mathrm{RFLP}$ | 先用保守序列引物扩增，再 $\mathrm{RFLP}$ | 流行病学、常规检测 |

问「镰贫第 $6$ 密码子」走天然 $\mathrm{Mst}$Ⅱ；问「本来没有酶切位点怎么办」走 $\mathrm{PIRA}$。
:::

**4. $\mathrm{PCR}$-$\mathrm{SSCP}$ 基于 $\mathrm{DNA}$ 空间构象检测基因突变**　$\mathrm{PCR}$-单链构象多态性（$\mathrm{PCR}$-single strand conformation polymorphism，$\mathrm{PCR}$-$\mathrm{SSCP}$）分析是一种基于单链 $\mathrm{DNA}$ 空间构象的差异性来检测基因点突变的方法。在非变性条件下，单链 $\mathrm{DNA}$ 分子内碱基之间存在相互作用，形成由碱基序列所决定的空间构象。$\mathrm{DNA}$ 分子中一个或多个特定碱基发生变异，可导致其构象改变。对于相同长度的单链 $\mathrm{DNA}$，因其碱基组成或排列顺序不同，形成各异的空间构象类型，表现出不同的电泳迁移率，即称为单链构象多态性（$\mathrm{SSCP}$）。$\mathrm{PCR}$-$\mathrm{SSCP}$ 技术首先是以 $\mathrm{PCR}$ 扩增待测 $\mathrm{DNA}$ 片段，再将扩增产物变性为单链 $\mathrm{DNA}$，非变性聚丙烯酰胺凝胶电泳后通过检测电泳迁移率分析基因突变情况。$\mathrm{PCR}$-$\mathrm{SSCP}$ 的灵敏度取决于突变对单链 $\mathrm{DNA}$ 的构象及电泳迁移率的影响程度，适用于较小 $\mathrm{DNA}$ 片段的突变分析。

:::definition{label="SSCP"}
相同长度的单链 $\mathrm{DNA}$，因碱基组成或排列不同，非变性条件下形成不同空间构象，电泳迁移率不同，称为单链构象多态性（$\mathrm{SSCP}$）。
:::

:::definition{label="PCR-SSCP"}
先 $\mathrm{PCR}$，再变性成单链，非变性聚丙烯酰胺凝胶电泳，看迁移率。灵敏度取决于突变对构象和迁移率的影响，适用于较小片段。
:::

:::pitfall{label="SSCP 不是测序，也不是酶切"}
它读的是单链构象导致的迁移率，不直接给出突变碱基是什么，也不要求酶切位点。写成「$\mathrm{SSCP}$ 就是 $\mathrm{RFLP}$」，图24-2 的 $\mathrm{Mst}$Ⅱ 就没有独特地位。
:::

**5. $\mathrm{PCR}$-$\mathrm{DHPLC}$ 基于异源双链检测基因突变**　$\mathrm{PCR}$-变性高效液相色谱（$\mathrm{PCR}$-denature high performance liquid chromatography，$\mathrm{PCR}$-$\mathrm{DHPLC}$）是一种筛查点突变的技术，可对目的基因进行基因序列扫描，有助于发现新的突变类型。基本原理是利用待测样品 $\mathrm{DNA}$ 在 $\mathrm{PCR}$ 扩增过程的单链产物可与互补链随机结合而形成双链的特性，依据最终产物中是否出现异源双链来判断样品中是否存在点突变。如果不存在点突变，在 $\mathrm{PCR}$ 反应中产生的双链 $\mathrm{DNA}$ 都是一致的，即只产生一种同源双链。如果存在点突变，就会产生 $4$ 种不同的 $\mathrm{DNA}$ 双链分子，包括 $2$ 种异源双链和 $2$ 种同源双链。在部分变性洗脱条件下，这些异源双链 $\mathrm{DNA}$ 片段可以在液相色谱柱中呈现出不同的滞留时间，出现「变异」洗脱峰的样品可进一步通过 $\mathrm{DNA}$ 直接测序确定样品的突变位点和性质。$\mathrm{PCR}$-$\mathrm{DHPLC}$ 技术需借助自动化操作的分析仪，已成为临床遗传学诊断的重要工具。

:::definition{label="PCR-DHPLC"}
$\mathrm{PCR}$-变性高效液相色谱，本版英文写作 $\mathrm{PCR}$-denature high performance liquid chromatography。筛查点突变，可做序列扫描、发现新突变。无突变：只一种同源双链。有点突变：$2$ 种异源双链 $+2$ 种同源双链，共 $4$ 种双链。部分变性洗脱时滞留时间不同；「变异」洗脱峰再测序定点。需自动化分析仪。
:::

:::cause-effect{title="有没有点突变怎样变成色谱峰"}
- **因** 无点突变
- **果** 只产生一种同源双链，没有异源双链峰
- **因** 有点突变
- **果** $4$ 种双链（$2$ 同源 $+2$ 异源），部分变性条件下滞留时间不同，出现「变异」洗脱峰，再测序确定位点和性质
:::

:::insight{label="DHPLC 是筛查，测序才钉死位点和性质"}
教材写「出现变异洗脱峰的样品可进一步通过 $\mathrm{DNA}$ 直接测序」。不要把色谱峰直接答成「已经知道是哪一个碱基换成了什么」。
:::

:::compare{title="PCR 衍生技术不要只背缩写"}
| 技术 | 认的是什么 | 本版典型用途 |
|------|----------|------------|
| 裂口 $\mathrm{PCR}$ | 跨越断裂点的片段大小 | 缺失／插入 |
| 多重 $\mathrm{PCR}$ | 一次多种引物，片段在不在 | 缺失或突变 |
| $\mathrm{PCR}$-$\mathrm{ASO}$ | 正常／突变探针杂交 | 图24-1 $\beta$ 地贫第 $17$ 密码子 |
| $\mathrm{PCR}$-$\mathrm{RFLP}$ | 酶切位点在不在 | 图24-2 镰贫 $\mathrm{Mst}$Ⅱ |
| $\mathrm{PCR}$-$\mathrm{PIRA}$ | 引物错配造出或消去酶切位点 | 已知基因 |
| $\mathrm{PCR}$-$\mathrm{SSCP}$ | 单链构象→迁移率 | 较小片段点突变 |
| $\mathrm{PCR}$-$\mathrm{DHPLC}$ | 异源双链的洗脱峰 | 筛查、发现新突变，再测序 |

问「点在膜上的 A/B/C」走 $\mathrm{ASO}$；问「$54/56/110$」走 $\mathrm{RFLP}$；问「构象」走 $\mathrm{SSCP}$；问「四种双链」走 $\mathrm{DHPLC}$。
:::

### （三）基因测序是最直接的基因诊断方法

$\mathrm{PCR}$ 技术和基因测序技术发展迅速，传统的限制性核酸内切酶酶谱分析法基本被替代。针对致病基因进行 $\mathrm{PCR}$ 扩增后，通过基因测序技术找出变异所在是最为直接和确切的基因诊断方法。基因测序除了用于突变类型已经明确的遗传病诊断及产前诊断，还可通过全基因组测序（whole genome sequencing，$\mathrm{WGS}$）和全外显子组测序（whole exome sequencing，$\mathrm{WES}$）等方法进行复杂疾病的致病基因筛选与鉴定。

:::definition{label="测序是最直接、确切的方法"}
致病基因 $\mathrm{PCR}$ 扩增后测序，找出变异所在。传统限制酶酶谱分析法基本被替代——「基本被替代」说的是酶谱作为常规手段，不是图24-2 的 $\mathrm{PCR}$-$\mathrm{RFLP}$ 从教材里消失。
:::

:::definition{label="WGS 与 WES"}
全基因组测序（$\mathrm{WGS}$）和全外显子组测序（$\mathrm{WES}$）用于复杂疾病的致病基因筛选与鉴定。已知突变的遗传病诊断及产前诊断也可以测序，不必先上全基因组。
:::

:::pitfall{label="不要写成测序已经淘汰 PCR-RFLP"}
教材说传统酶谱分析法基本被替代。图24-2 仍把 $\mathrm{PCR}$-$\mathrm{RFLP}$ 写成镰贫诊断的本版例子。测序是「最直接确切」，$\mathrm{RFLP}$、$\mathrm{ASO}$ 仍是已知突变的快速分型手段。
:::

### （四）基因芯片技术可用于大规模基因诊断

基因芯片技术本质上是一种核酸分子杂交技术，可以进行微量化、大规模、自动化处理样品，同时检测多个基因、多个位点，精确研究多种状态下的分子结构变异，了解组织或细胞中的基因表达情况。基因芯片可提供从整体观念研究有机体的全新技术，将给复杂疾病的诊断与治疗带来革命性的变化。目前基因芯片技术可以实现地中海贫血、异常血红蛋白病、苯丙酮尿症、血友病等常见遗传性疾病的早期、快速诊断，也广泛地应用于肿瘤表达谱、甲基化分析、比较基因组杂交分析等领域。

:::definition{label="基因芯片"}
本质是核酸分子杂交，但微量化、大规模、自动化，同时检测多个基因、多个位点。既看分子结构变异，也看组织或细胞中的基因表达。
:::

:::keypoint{label="芯片本版点名的病和领域"}
- 常见遗传病早期、快速诊断：地中海贫血、异常血红蛋白病、苯丙酮尿症、血友病。
- 还用于肿瘤表达谱、甲基化分析、比较基因组杂交分析。
- 「革命性变化」是教材对复杂疾病诊断与治疗的展望，不是已经替代测序和 $\mathrm{PCR}$。
:::

## 三、基因诊断的医学应用广泛

当人类基因组的信息与疾病的相关机制阐明后，基因诊断从理论上可实现所有直接或间接涉及基因结构／功能改变的诊断、预警和疗效评估。目前，基因诊断可以实现针对特定疾病的相关基因分型鉴定、基因突变检测，以及基因拷贝数或表达产物的定量分析等，已在许多重大疾病（如遗传病、传染病、肿瘤等）的早期诊断、产前筛查、疗效判断、预后评估、用药指导，以及法医学鉴定、分子流行病学分析、器官移植等多方面得到广泛应用。

:::definition{label="理论上能覆盖的三件事"}
所有直接或间接涉及基因结构／功能改变的诊断、预警和疗效评估。前提仍是基因组信息与疾病机制已经阐明。
:::

:::keypoint{label="目前已经在做的清单"}
分型鉴定、突变检测、拷贝数或表达产物定量；遗传病、传染病、肿瘤的早期诊断、产前筛查、疗效、预后、用药；法医学、分子流行病学、器官移植。
:::

### （一）基因诊断可用于遗传性疾病的诊断和风险预测

人类遗传性疾病的表型是由个体基因型决定的，故对遗传性疾病的诊断也可理解为进行个体的基因分型。遗传性疾病的发生常与体内一个或多个特定基因突变导致的蛋白质结构异常及功能丧失相关。例如，地中海贫血是由于珠蛋白基因突变，不能正常表达珠蛋白，导致红细胞的数量和质量发生变化，表现出贫血症。遗传性疾病的诊断性检测和风险预测是基因诊断的主要应用领域。与以往的细胞学和生化检查相比，基因诊断耗时少、准确性高。

单基因遗传病的发生主要与特定基因突变导致编码的蛋白质生物学功能异常相关。基因诊断可为单基因遗传病提供最终确诊依据。例如，通过限制性核酸内切酶图谱分析、$\mathrm{PCR}$-$\mathrm{RFLP}$、基因测序技术可以实现镰状细胞贫血的基因诊断。我国的基因诊断研究和应用始于 $20$ 世纪 $80$ 年代中期，已开展针对地中海贫血、血友病、苯丙酮尿症等一些常见单基因遗传病的诊断性检测。

基因诊断还可用于遗传筛查和产前诊断。通过遗传筛查检测出的高风险夫妇需给予遗传咨询和婚育指导，在知情同意原则下开展产前诊断。若胎儿为某种严重遗传病的受累者，可在遗传咨询的基础上由受试者决定是否终止妊娠，从而在人群水平实现遗传性疾病预防的目标。

:::definition{label="遗传病诊断就是基因分型"}
遗传病表型由个体基因型决定，诊断可理解为个体的基因分型。常与一个或多个特定突变导致蛋白质结构异常、功能丧失相关。
:::

:::definition{label="地中海贫血在应用里怎么写"}
珠蛋白基因突变，不能正常表达珠蛋白，红细胞数量和质量变化，表现为贫血。这是「蛋白质结构／功能异常」的例子，具体技术仍要回到缺失、$\mathrm{ASO}$ 或芯片，不要一律写成 $\mathrm{RFLP}$。
:::

:::definition{label="单基因病：基因诊断可提供最终确诊"}
特定突变导致编码蛋白质功能异常。本版点名镰状细胞贫血可用限制酶图谱、$\mathrm{PCR}$-$\mathrm{RFLP}$、基因测序。我国自 $20$ 世纪 $80$ 年代中期起，已开展地中海贫血、血友病、苯丙酮尿症等常见单基因病的诊断性检测。
:::

:::definition{label="遗传筛查与产前诊断"}
筛出高风险夫妇 $\rightarrow$ 遗传咨询和婚育指导 $\rightarrow$ 知情同意下产前诊断。胎儿为严重遗传病受累者时，在咨询基础上由受试者决定是否终止妊娠，以在人群水平预防。
:::

:::pitfall{label="产前诊断不要写成强制终止妊娠"}
教材写「由受试者决定是否终止妊娠」，前面还有知情同意和遗传咨询。写成「查出突变就必须引产」，伦理那一户在第二节生殖细胞治疗里还要再立，这里先不要把决定权删掉。
:::

:::compare{title="地贫 vs 镰贫：应用段和技术段要对上"}
| | 本版病因一句话 | 本节技术落点 |
|--|--------------|------------|
| 地中海贫血 | 珠蛋白基因突变，珠蛋白不能正常表达 | $\mathrm{Kan\ Y.W.}$ 的 $\alpha$ 地贫缺失；图24-1 $\beta$ 地贫第 $17$ 密码子 $\mathrm{PCR}$-$\mathrm{ASO}$；芯片也可做早期诊断 |
| 镰状细胞贫血 | 第 $6$ 密码子 $\mathrm{A}$-$\mathrm{T}$，$\mathrm{Glu}$-$\mathrm{Val}$ | $\mathrm{Kan\ Y.W.}$ 的 $\mathrm{RFLP}$；图24-2 $\mathrm{PCR}$-$\mathrm{RFLP}$（$\mathrm{Mst}$Ⅱ）；也可酶谱、测序 |

两病都是珠蛋白，技术不是同一张图。
:::

### （二）DNA指纹分析是法医学个体识别的核心技术

除了部分同卵双生子外，人与人之间的某些 $\mathrm{DNA}$ 序列特征具有高度的个体特异性和终生稳定性。利用限制性核酸内切酶消化个体染色体 $\mathrm{DNA}$ 后，分离得到不同大小的 $\mathrm{DNA}$ 片段，再利用核酸分子杂交技术获得不同生物个体 $\mathrm{DNA}$ 片段的带型图谱；这些图谱就如同人类指纹一样具有高度的个体特异性，故称为 $\mathrm{DNA}$ 指纹分析（$\mathrm{DNA}$ fingerprinting），可分析生物个体间关系的密切程度。

正常人群中有一类约 $2\sim 6\,\mathrm{bp}$ 的较短核心序列，常以 $10\sim 50$ 次重复串联的方式存在于相应结构基因的侧翼区或非编码区，称为短串联重复序列（short tandem repeat，$\mathrm{STR}$）。$\mathrm{STR}$ 是 $\mathrm{RFLP}$ 之后的第二代遗传标记。基于 $\mathrm{PCR}$-$\mathrm{STR}$ 的 $\mathrm{DNA}$ 指纹分析技术已取代传统的核酸分子杂交图谱分析，可有效地进行生物个体认定，成为刑侦样品鉴定、犯罪嫌疑人排查、亲子关系或个体间亲缘关系确定的重要手段。选择特定 $\mathrm{STR}$ 位点，设计相应的 $\mathrm{PCR}$ 引物，对微量血痕、精液、唾液和毛发等样品中的 $\mathrm{DNA}$ 进行 $\mathrm{PCR}$ 扩增和带型比较，从而实现快速、灵敏的个体鉴定。如图24-3 所示，针对 $\mathrm{STR}$ 位点 $\mathrm{D13S317}$ 的 $\mathrm{PCR}$ 扩增产物带型分析，发现 $3$ 个子女基因型的一个等位基因来自父亲，另外一个等位基因来自母亲。

:::definition{label="DNA 指纹分析"}
除部分同卵双生子外，某些 $\mathrm{DNA}$ 序列特征高度个体特异、终生稳定。经典做法：限制酶消化染色体 $\mathrm{DNA}$，分离不同大小片段，杂交得到带型图谱，如同指纹，可分析个体间关系密切程度。英文 $\mathrm{DNA}$ fingerprinting。
:::

:::definition{label="STR"}
短串联重复序列（short tandem repeat）：约 $2\sim 6\,\mathrm{bp}$ 的较短核心序列，常以 $10\sim 50$ 次重复串联，位于结构基因侧翼区或非编码区。是 $\mathrm{RFLP}$ 之后的第二代遗传标记。
:::

:::definition{label="PCR-STR 取代传统杂交图谱"}
基于 $\mathrm{PCR}$-$\mathrm{STR}$ 的 $\mathrm{DNA}$ 指纹已取代传统核酸分子杂交图谱分析。用途：刑侦样品鉴定、犯罪嫌疑人排查、亲子或亲缘关系确定。样品可以是微量血痕、精液、唾液和毛发。
:::

:::definition{label="图24-3 的孟德尔分配"}
位点 $\mathrm{D13S317}$。$3$ 个子女的基因型：一个等位基因来自父亲，另一个来自母亲。这是亲权认定的读图钥匙，不是突变诊断。
:::

::figure{src="/images/biochemistry/textbook/p0481_01.png" caption="图24-3　STR 等位基因在家族中遗传示意图" alt="五条 STR 峰图，横轴片段大小约 180 至 250。父亲等位基因 11 与 14；母亲 8 与 12；女儿 12 与 14；长子 8 与 14；次子 11 与 12。每个子女的一个等位基因来自父亲、另一个来自母亲"}

:::insight{label="图24-3 先读父母峰，再核对三个子女"}
父亲 $11/14$，母亲 $8/12$。女儿 $12/14$（$12$ 来自母，$14$ 来自父）；长子 $8/14$（$8$ 来自母，$14$ 来自父）；次子 $11/12$（$11$ 来自父，$12$ 来自母）。横轴是片段大小，峰上的数字是重复次数等位基因命名，不要把 $11$ 读成「第 $11$ 号染色体疾病」。
:::

:::pitfall{label="STR 不是 PCR-ASO，也不是镰贫 RFLP"}
$\mathrm{STR}$ 问的是「这段短重复你有几拷、父母能不能对上」。$\mathrm{ASO}$ 问点突变探针；$\mathrm{RFLP}$ 问酶切位点。写成「亲子鉴定就是切 $\mathrm{Mst}$Ⅱ」，图24-3 的峰就没有意义。
:::

:::compare{title="第一代标记 vs 第二代标记"}
| | 本版说法 | 经典读出方式 | 现在法医主账 |
|--|---------|------------|------------|
| $\mathrm{RFLP}$ | 第一代遗传标记（相对 $\mathrm{STR}$ 而言） | 酶切 $+$ 杂交带型 | 遗传病已知突变仍可用 $\mathrm{PCR}$-$\mathrm{RFLP}$ |
| $\mathrm{STR}$ | $\mathrm{RFLP}$ 之后的第二代遗传标记 | $\mathrm{PCR}$ 扩增后比较带型／峰型 | 已取代传统杂交图谱做个体认定 |

「第二代」说的是遗传标记世代，不是「$\mathrm{RFLP}$ 已经从镰贫诊断里消失」。
:::

### （三）针对外源基因的检测有助于感染性疾病的诊断

针对病原体自身特异性 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 序列，通过基因扩增、核酸分子杂交等手段，判断这些外源性基因在人体组织中是否存在，从而实现感染性疾病的基因诊断。基因诊断主要适用于下列情况：①病原微生物的现场快速检测，确定感染源；②病毒或致病菌的快速分型，明确致病性或药物敏感性；③需要复杂的分离培养条件，或目前尚不能进行体外培养的病原微生物鉴定。针对病原体的基因诊断主要依赖于 $\mathrm{PCR}$ 及衍生技术，可快速检测出样品中微量的、基因序列已知的病原微生物，如组织和血液中的 $\mathrm{SARS}$ 病毒、各型肝炎病毒等。利用反向斑点印迹（$\mathrm{RDB}$）技术可用于检测耐药相关的基因突变，例如 $\mathrm{RDB}$ 可以检测乙型肝炎病毒拉米夫定耐药相关的酪氨酸-甲硫氨酸-天冬氨酸-天冬氨酸位点突变。样品中痕量病原微生物的迅速检测、分类及分型还可采用 $\mathrm{DNA}$ 芯片技术。与传统诊断方法相比，基因诊断具有更高的特异性和敏感性，有利于感染性疾病的早期诊治、隔离和人群预防。

:::definition{label="感染性疾病的基因诊断"}
针对病原体自身特异 $\mathrm{DNA}$ 或 $\mathrm{RNA}$，用扩增、杂交等判断这些外源基因在人体组织中是否存在。查的是外源序列，不是患者自己的遗传病突变。
:::

:::keypoint{label="三种特别适用的情况"}
- 现场快速检测，确定感染源。
- 病毒或致病菌快速分型，明确致病性或药物敏感性。
- 需要复杂分离培养，或目前尚不能体外培养的病原微生物鉴定。
:::

:::definition{label="病原体基因诊断主要靠 PCR 及衍生"}
可快速检出样品中微量、序列已知的病原微生物。本版点名：组织与血液中的 $\mathrm{SARS}$ 病毒、各型肝炎病毒。痕量检测、分类分型还可走 $\mathrm{DNA}$ 芯片。
:::

:::definition{label="RDB 查乙肝拉米夫定耐药"}
反向斑点印迹可检测耐药相关基因突变。例子：乙型肝炎病毒拉米夫定耐药相关的酪氨酸-甲硫氨酸-天冬氨酸-天冬氨酸位点突变。这是前文 $\mathrm{RDB}$ 应用名单里「乙型肝炎病毒耐药」的落点。
:::

:::pitfall{label="感染基因诊断只回答外源基因在不在、有多少"}
本节末还要写：针对病原体的基因诊断只能判断外源基因的有无和拷贝数的多少，难以检测病原体进入体内后机体的反应。写成「查出病毒核酸就等于已经知道病情和免疫状态」，综合评估那一户就空了。
:::

### （四）基因诊断可用于多基因常见病的预测性诊断

肿瘤、心血管疾病、糖尿病、高血压、阿尔茨海默病等疾病不具备典型的孟德尔遗传模式，但常存在多个易感基因结构和功能的改变，与某些遗传标记关联，部分具有家族遗传倾向，致病原因可能与基因组多个较微弱的基因效能累加相关，即为多基因病。对于多基因常见病，基于 $\mathrm{DNA}$ 分析的预测性诊断可为被测者提供某些疾病发生风险的评估意见，是开展临床遗传咨询最重要的依据。在一些有明显遗传倾向的肿瘤中，肿瘤抑制基因和突变的癌基因是基因诊断的重要靶点。大多数人类肿瘤组织中都可检测到癌基因或抑癌基因的缺失或点突变，且有些基因或相关表达产物的改变可作为特定肿瘤的标志物。例如，甲胎蛋白可视为原发性肝癌诊断的标志物之一。乳腺癌易感基因（breast cancer susceptibility gene，$\mathrm{BRCA}$）突变可提高个体的乳腺癌发病风险。基于 $\mathrm{BRCA}$ 突变的基因诊断已成为一些国家人群健康监测的项目之一。随着基因变异和疾病发生相关研究的知识积累，针对肿瘤和其他一些多基因常见病的预测性诊断正在逐渐进入临床应用阶段。

:::definition{label="多基因病"}
不具备典型孟德尔遗传模式；多个易感基因结构与功能改变，与某些遗传标记关联，部分有家族倾向；可能是多个较微弱基因效能累加。本版例子：肿瘤、心血管疾病、糖尿病、高血压、阿尔茨海默病。
:::

:::definition{label="预测性诊断"}
基于 $\mathrm{DNA}$ 分析，给被测者提供某些疾病发生风险的评估意见，是临床遗传咨询最重要的依据。户头是「风险」，不是「已经确诊该病」。
:::

:::definition{label="肿瘤基因诊断的靶点"}
有明显遗传倾向的肿瘤：肿瘤抑制基因和突变的癌基因是重要靶点。大多数人类肿瘤组织可检测到癌基因或抑癌基因的缺失或点突变。有些基因或相关表达产物的改变可作为特定肿瘤标志物。
:::

:::definition{label="甲胎蛋白在本版中的位置"}
甲胎蛋白可视为原发性肝癌诊断的标志物之一。它写在「基因或相关表达产物」这一句下，是表达产物标志物，不是把肝癌诊断等同于 $\mathrm{PCR}$-$\mathrm{ASO}$。
:::

:::definition{label="BRCA"}
乳腺癌易感基因（breast cancer susceptibility gene，$\mathrm{BRCA}$）突变可提高个体乳腺癌发病风险。基于 $\mathrm{BRCA}$ 突变的基因诊断已成为一些国家人群健康监测项目之一。
:::

:::pitfall{label="多基因病不要写成单基因病那种「最终确诊」"}
单基因病：基因诊断可提供最终确诊依据。多基因病：预测性诊断提供风险意见，是遗传咨询依据。写成「查出一个易感位点就确诊冠心病」，孟德尔模式那一户就丢了。
:::

:::insight{label="预测性诊断正在进入临床，不是已经覆盖所有常见病"}
教材用「正在逐渐进入临床应用阶段」。知识积累仍在进行。不要把后文基因治疗里尚未获批的方案提前写成诊断已经完成。
:::

### （五）基因诊断可用于疾病的疗效评价和用药指导

遗传诊断还可应用于临床药物疗效的评价，提供指导用药的信息。例如，急性淋巴细胞白血病经化疗等综合治疗后，部分患者可获得缓解，但由于患者体内仍残留少数的白血病细胞，而容易复发。利用 $\mathrm{PCR}$ 等多种基因诊断技术可检测和跟踪这些微小残留病灶，有助于预测白血病复发、判断化疗效果和制定相应的治疗方案。人群中对药物的反应性存在个体差异，致使药物的不良反应难以避免。例如，氨基糖苷类抗生素的致聋副作用的发生与线粒体 $\mathrm{DNA}$ $12\mathrm{S}\ \mathrm{rRNA}$ 基因第 $1\,555$ 位点突变相关。在人群中通过基因诊断技术筛查发现携带此突变的个体，可指导医生用药，有效防止儿童药物中毒性耳聋的发生。通过测定人体的药物代谢酶类（如细胞色素 $\mathrm{P}450$）的基因多态性可预测药物代谢情况或治疗效果，从而制订针对不同个体的药物治疗方案。

:::definition{label="微小残留病灶"}
急性淋巴细胞白血病经化疗等综合治疗可获缓解，但体内仍可残留少数白血病细胞，容易复发。用 $\mathrm{PCR}$ 等多种基因诊断技术检测、跟踪这些微小残留病灶，以预测复发、判断化疗效果、制定方案。
:::

:::definition{label="mtDNA 12S rRNA 第 1555 位点"}
氨基糖苷类抗生素致聋副作用与线粒体 $\mathrm{DNA}$ $12\mathrm{S}\ \mathrm{rRNA}$ 基因第 $1\,555$ 位点突变相关。筛出携带者，指导用药，防止儿童药物中毒性耳聋。
:::

:::definition{label="药物代谢酶基因多态性"}
测定如细胞色素 $\mathrm{P}450$ 等药物代谢酶类的基因多态性，可预测药物代谢或治疗效果，制订个体化药物治疗方案。
:::

:::compare{title="疗效跟踪 vs 用药前筛查"}
| | 本版例子 | 问的是什么 |
|--|---------|-----------|
| 疗效／复发 | 急淋微小残留病灶 | 治疗后还剩多少肿瘤细胞 |
| 避免不良反应 | $12\mathrm{S}\ \mathrm{rRNA}$ 第 $1\,555$ 位点 | 能不能用氨基糖苷类 |
| 个体化方案 | 细胞色素 $\mathrm{P}450$ 多态性 | 代谢快慢、效果如何 |

三户都叫「用药指导」，样品和基因不是同一个。
:::

尽管基因诊断已在多个领域获得重大进展，但在具体实施和推广过程中仍然存在很多问题或难点。由于很多临床疾病的发病机制复杂，尚未找到可供基因诊断的有效切入点。针对同一疾病的不同基因诊断技术各有利弊。基因诊断并不能取代其他临床医学诊断。针对病原体的基因诊断只能判断外源基因的有无和拷贝数的多少，难以检测病原体进入体内后机体的反应。有的基因诊断结果假阳性较高，须结合临床症状、影像检查、生化诊断、病理检测等信息进行综合评估。

:::definition{label="基因诊断不能取代其他临床诊断"}
这是本版原句。再强的特异和灵敏，也不把症状、影像、生化、病理从诊断里删掉。
:::

:::definition{label="病原体基因诊断的边界"}
只能判断外源基因的有无和拷贝数的多少，难以检测病原体进入体内后机体的反应。有无／拷贝数是核酸账；炎症、免疫、组织损伤是机体反应账。
:::

:::pitfall{label="假阳性必须综合评估"}
有的结果假阳性较高，须结合临床症状、影像检查、生化诊断、病理检测等综合评估。斑点印迹已经写过「特异性低、易假阳性」。写成「核酸阳性＝确诊」，这一段就白写了。
:::

:::keypoint{label="局限四句必须留在第一节末"}
- 不少疾病还没有有效切入点。
- 同一疾病的不同技术各有利弊。
- 不能取代其他临床医学诊断。
- 病原体只判外源基因有无和拷贝数；假阳性须综合评估。
:::

:::pitfall{label="这一段不要复制进第二节文首"}
教材把局限写在第一节末、第二节「基因治疗」标题之前。第二节从「以改变人遗传物质为基础」起笔。不要把「不能取代其他诊断」再当基因治疗的开场。
:::

:::memory{label="本节必背分户"}
- 基因诊断属于分子诊断；通常针对 $\mathrm{DNA}$ 和 $\mathrm{RNA}$。广义分子诊断还可定量蛋白质。
- $\mathrm{Kan\ Y.W.}$：$20$ 世纪 $70$ 年代，$\alpha$ 地贫基因缺失、镰贫 $\mathrm{RFLP}$。
- 不依赖表型：特异、灵敏、早期、快速、适用广。培养数天 vs 基因诊断数小时。
- 杂交：Southern（$50\sim 20\,000\,\mathrm{bp}$，难常规）、Northern（纯度高）、斑点（易假阳性）、$\mathrm{ASO}$、$\mathrm{RDB}$、$\mathrm{ISH}/\mathrm{FISH}$。
- 图24-1 $\mathrm{PCR}$-$\mathrm{ASO}$：$\beta$ 地贫第 $17$ 密码子；$\mathrm{A}$ 正常人、$\mathrm{B}$ 纯合子、$\mathrm{C}$ 杂合子。
- 图24-2 $\mathrm{PCR}$-$\mathrm{RFLP}$：镰贫第 $6$ 密码子 $\mathrm{A}$-$\mathrm{T}$、$\mathrm{Glu}$-$\mathrm{Val}$；$\mathrm{Mst}$Ⅱ 切成 $54+56$，患者 $110$，杂合子三条带。
- 图24-3 $\mathrm{STR}$（$\mathrm{D13S317}$）：父 $11/14$、母 $8/12$，子女各从父母得一个等位基因。
- 测序最直接；芯片本质是杂交，可做地贫、异常血红蛋白病、苯丙酮尿症、血友病等。
- 应用：单基因病确诊与产前诊断；法医 $\mathrm{STR}$；感染外源基因；多基因病风险（$\mathrm{BRCA}$）；急淋微小残留、$\mathrm{mtDNA}$ $12\mathrm{S}\ \mathrm{rRNA}$ $1\,555$、细胞色素 $\mathrm{P}450$。
- 不能取代其他诊断；病原体只判有无和拷贝数；假阳性须综合评估。
:::

:::keypoint{label="本节不写基因治疗"}
导入正常或治疗基因、基因修复与基因增强、直接体内与间接体内、逆转录病毒生活周期（图24-4）都是第二节的账。本节只把「查什么、用哪张图、局限在哪」立住。
:::
