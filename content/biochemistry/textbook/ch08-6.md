# 第六节　血浆脂蛋白及其代谢

第五节把胆固醇写成肝内合成、胆汁酸为主去路。脂质本身不溶于水，进入血浆必须装进脂蛋白。本节先把血脂立户，再用电泳和超速离心把乳糜微粒（$\mathrm{CM}$）、极低密度脂蛋白（$\mathrm{VLDL}$）、低密度脂蛋白（$\mathrm{LDL}$）、高密度脂蛋白（$\mathrm{HDL}$）分开；载脂蛋白、脂蛋白脂肪酶（$\mathrm{LPL}$）、卵磷脂－胆固醇脂肪酰转移酶（$\mathrm{LCAT}$）和 $\mathrm{LDL}$ 受体把外源途径、内源途径和胆固醇逆向转运写成三条代谢。章末收全章小结和思考题。

## 一、血脂是血浆所含脂质的统称

血浆脂质包括甘油三酯、磷脂、胆固醇及其酯，以及游离脂肪酸等。磷脂主要有卵磷脂（约 $70\%$）、神经鞘磷脂（约 $20\%$）及脑磷脂（约 $10\%$）。血脂有两种来源：外源性脂质从食物摄取入血，内源性脂质由肝细胞、脂肪细胞及其他组织细胞合成后释放入血。血脂不如血糖恒定，受膳食、年龄、性别、职业以及代谢等影响，波动范围较大（表8-4）。

:::definition{label="血脂"}
血脂是血浆所含脂质的统称，包括甘油三酯、磷脂、胆固醇及其酯，以及游离脂肪酸等。
:::

:::definition{label="血浆磷脂的组成"}
血浆磷脂主要有卵磷脂（约 $70\%$）、神经鞘磷脂（约 $20\%$）及脑磷脂（约 $10\%$）。
:::

:::compare{title="血脂的两种来源"}
| 来源 | 教材原句 |
|------|----------|
| 外源性 | 从食物摄取入血 |
| 内源性 | 由肝细胞、脂肪细胞及其他组织细胞合成后释放入血 |

血脂波动大，不如血糖恒定；空腹 $12\sim 14$ 小时的组成及含量以表8-4 为准。
:::

:::pitfall{label="血脂不是“只有胆固醇”"}
名单里甘油三酯、磷脂、胆固醇及其酯、游离脂肪酸都在。只盯总胆固醇，甘油三酯升高的Ⅰ、Ⅳ、Ⅴ型脂蛋白异常血症会对不上。
:::

:::

:::

## 二、血浆脂蛋白是血脂的运输形式及代谢形式

脂质不溶于水。血浆把它们写成脂蛋白（lipoprotein），既是运输形式，也是代谢形式：颗粒在血液里一边走，一边被脂酶改写、被受体摄取。

:::definition{label="血浆脂蛋白"}
血浆脂蛋白是血脂的运输形式及代谢形式：脂质与载脂蛋白组成的复合体，使不溶于水的脂质能在水相血浆中运输，并按颗粒种类走不同代谢途径。
:::

### （一）血浆脂蛋白可用电泳法和超速离心法分类

不同脂蛋白所含脂质和蛋白质不一样，其理化性质如密度、颗粒大小、表面电荷、电泳行为、免疫学性质及生理功能均有不同，可将脂蛋白分为不同种类。分类有两把尺子：电场中的迁移率和超速离心中的密度。

**1. 电泳法按电场中的迁移率对血浆脂蛋白分类**　不同脂蛋白的质量和表面电荷不同，在同一电场中移动的快慢不一样。$\alpha$-脂蛋白（$\alpha$-lipoprotein）泳动最快，相当于 $\alpha_{1}$-球蛋白位置；$\beta$-脂蛋白（$\beta$-lipoprotein）相当于 $\beta$-球蛋白位置；前 $\beta$-脂蛋白（pre-$\beta$-lipoprotein）位于 $\beta$-脂蛋白之前，相当于 $\alpha_{2}$-球蛋白位置；乳糜微粒（chylomicron，$\mathrm{CM}$）不泳动，留在原点（点样处）（图8-9）。

::figure{src="/images/biochemistry/textbook/p0191_01.png" caption="图8-9　血浆脂蛋白琼脂糖凝胶电泳谱。阴极（−）在左、阳极（+）在右：乳糜微粒（CM）留在上样处原点，依次为 β、前 β、α。" alt="琼脂糖凝胶电泳条带：左侧阴极，CM 留在上样处，向阳极依次出现 β、前β、α 四条带"}

:::definition{label="电泳法分类"}
按电场中迁移率：$\alpha$-脂蛋白（$\alpha_{1}$-球蛋白位置，最快）、前 $\beta$-脂蛋白（$\alpha_{2}$-球蛋白位置）、$\beta$-脂蛋白（$\beta$-球蛋白位置）、乳糜微粒（留在原点）。
:::

:::keypoint{label="从原点到阳极的顺序"}
上样处：$\mathrm{CM}$ 不泳动。向阳极：$\beta$ → 前 $\beta$ → $\alpha$。前 $\beta$ 是“在 $\beta$ 之前”，指它比 $\beta$ 泳得更远，不是插在原点和 $\beta$ 之间。
:::

:::pitfall{label="前 β 不是“比 β 更靠近原点”"}
图8-9 从左（原点／阴极）到右（阳极）是 $\mathrm{CM}$、$\beta$、前 $\beta$、$\alpha$。前 $\beta$ 相当于 $\alpha_{2}$-球蛋白，夹在 $\beta$ 与 $\alpha$ 之间。把“前”听成“更靠前、还没离开原点”，会和 $\mathrm{CM}$ 弄混。
:::

**2. 超速离心法按密度对血浆脂蛋白分类**　不同脂蛋白因含脂质和蛋白质种类和数量不同，密度不一样（表8-5）。将血浆在一定密度盐溶液中超速离心，脂蛋白会因密度不同而漂浮或沉降，通常用 Svedberg 漂浮率（$S_\mathrm{f}$）表示脂蛋白上浮特性。在 $26^{\circ}\mathrm{C}$、密度为 $1.063$ 的 $\mathrm{NaCl}$ 溶液及离心力为 $1$ 达因／克的力场中，上浮 $10^{-13}\,\mathrm{cm}$ 为 $1\,S_\mathrm{f}$ 单位，即 $1\,S_\mathrm{f}=10^{-13}\,\mathrm{cm}/(\mathrm{s}\cdot\mathrm{dyn}\cdot\mathrm{g})$。乳糜微粒含脂最多，密度最小，易上浮；其余脂蛋白按密度由小到大依次为极低密度脂蛋白（very low density lipoprotein，$\mathrm{VLDL}$）、低密度脂蛋白（low density lipoprotein，$\mathrm{LDL}$）和高密度脂蛋白（high density lipoprotein，$\mathrm{HDL}$）；分别相当于电泳分类中的 $\mathrm{CM}$、前 $\beta$-脂蛋白、$\beta$-脂蛋白及 $\alpha$-脂蛋白。

:::definition{label="Svedberg 漂浮率"}
Svedberg 漂浮率（$S_\mathrm{f}$）表示脂蛋白上浮特性。在 $26^{\circ}\mathrm{C}$、密度 $1.063$ 的 $\mathrm{NaCl}$ 溶液及离心力为 $1$ 达因／克的力场中，上浮 $10^{-13}\,\mathrm{cm}$ 为 $1\,S_\mathrm{f}$ 单位，$1\,S_\mathrm{f}=10^{-13}\,\mathrm{cm}/(\mathrm{s}\cdot\mathrm{dyn}\cdot\mathrm{g})$。
:::

:::definition{label="超速离心法四类脂蛋白"}
按密度由小到大：乳糜微粒（$\mathrm{CM}$）→ 极低密度脂蛋白（$\mathrm{VLDL}$）→ 低密度脂蛋白（$\mathrm{LDL}$）→ 高密度脂蛋白（$\mathrm{HDL}$）。分别相当于电泳的 $\mathrm{CM}$、前 $\beta$-脂蛋白、$\beta$-脂蛋白、$\alpha$-脂蛋白。
:::

:::compare{title="密度法与电泳法对照"}
| 密度法 | 密度 | $S_\mathrm{f}$ | 电泳法 | 电泳位置 |
|--------|------|----------------|--------|----------|
| 乳糜微粒 $\mathrm{CM}$ | $<0.95$ | $>400$ | 乳糜微粒 | 原点 |
| 极低密度脂蛋白 $\mathrm{VLDL}$ | $0.95\sim 1.006$ | $20\sim 400$ | 前 $\beta$-脂蛋白 | $\alpha_{2}$-球蛋白 |
| 低密度脂蛋白 $\mathrm{LDL}$ | $1.006\sim 1.063$ | $0\sim 20$ | $\beta$-脂蛋白 | $\beta$-球蛋白 |
| 高密度脂蛋白 $\mathrm{HDL}$ | $1.063\sim 1.210$ | 沉降（不上浮） | $\alpha$-脂蛋白 | $\alpha_{1}$-球蛋白 |
:::

人血浆还有中密度脂蛋白（intermediate density lipoprotein，$\mathrm{IDL}$）和脂蛋白（a）［lipoprotein (a)，$\mathrm{Lp}(\mathrm{a})$］。$\mathrm{IDL}$ 是 $\mathrm{VLDL}$ 在血浆中向 $\mathrm{LDL}$ 转化的中间产物，组成及密度介于 $\mathrm{VLDL}$ 及 $\mathrm{LDL}$ 之间。$\mathrm{Lp}(\mathrm{a})$ 的脂质成分与 $\mathrm{LDL}$ 类似，蛋白质成分中，除含一分子载脂蛋白 $\mathrm{B}100$ 外，还含一分子载脂蛋白（a）［apolipoprotein (a)］，是一类独立脂蛋白，由肝产生，不转化成其他脂蛋白。因蛋白质及脂质含量不同，$\mathrm{HDL}$ 还可分成亚类，主要有 $\mathrm{HDL}_{2}$ 及 $\mathrm{HDL}_{3}$。

:::definition{label="IDL"}
中密度脂蛋白（intermediate density lipoprotein，$\mathrm{IDL}$）是 $\mathrm{VLDL}$ 在血浆中向 $\mathrm{LDL}$ 转化的中间产物，组成及密度介于 $\mathrm{VLDL}$ 与 $\mathrm{LDL}$ 之间。
:::

:::definition{label="Lp(a)"}
脂蛋白（a）［$\mathrm{Lp}(\mathrm{a})$］脂质成分与 $\mathrm{LDL}$ 类似；蛋白质除一分子载脂蛋白 $\mathrm{B}100$ 外，还含一分子载脂蛋白（a）。由肝产生，是独立脂蛋白，不转化成其他脂蛋白。
:::

:::pitfall{label="Lp(a) 不是 LDL 的亚类，HDL2/HDL3 才是 HDL 的亚类"}
$\mathrm{Lp}(\mathrm{a})$ 虽像 $\mathrm{LDL}$ 并含 $\mathrm{apo\,B}100$，但多了一分子 $\mathrm{apo}(\mathrm{a})$，肝直接产生，不转化。$\mathrm{HDL}_{2}$、$\mathrm{HDL}_{3}$ 才是同一类颗粒因蛋白质及脂质含量不同分成的亚类。后文还有 $\mathrm{HDL}_{1}$（$\mathrm{HDL}_\mathrm{c}$），仅出现在高胆固醇膳食后。
:::

### （二）血浆脂蛋白是脂质与蛋白质的复合体

**1. 血浆脂蛋白中的蛋白质主要为载脂蛋白**　迄今已从人血浆脂蛋白分离出 $20$ 多种载脂蛋白（apolipoprotein，$\mathrm{apo}$），主要有 $\mathrm{apo\,A}$、$\mathrm{B}$、$\mathrm{C}$、$\mathrm{D}$ 及 $\mathrm{E}$ 等五大类（表8-6）。载脂蛋白在不同脂蛋白的分布及含量不同：$\mathrm{apo\,B}48$ 是 $\mathrm{CM}$ 特征载脂蛋白，$\mathrm{LDL}$ 几乎只含 $\mathrm{apo\,B}100$，$\mathrm{HDL}$ 主要含 $\mathrm{apo\,A\,I}$ 及 $\mathrm{apo\,A\,II}$。

:::definition{label="载脂蛋白"}
载脂蛋白（apolipoprotein，$\mathrm{apo}$）是血浆脂蛋白中的蛋白质组分。人血浆已分离出 $20$ 多种，主要分 $\mathrm{A}$、$\mathrm{B}$、$\mathrm{C}$、$\mathrm{D}$、$\mathrm{E}$ 五大类。
:::

:::keypoint{label="三种特征 apo"}
- $\mathrm{apo\,B}48$：$\mathrm{CM}$ 的特征载脂蛋白。
- $\mathrm{apo\,B}100$：$\mathrm{LDL}$ 几乎只含这一种；也是 $\mathrm{VLDL}$ 的主要 apo 之一。
- $\mathrm{apo\,A\,I}$、$\mathrm{A\,II}$：$\mathrm{HDL}$ 的主要载脂蛋白；$\mathrm{A\,I}$ 激活 $\mathrm{LCAT}$。
:::

$\mathrm{CETP}$：胆固醇酯转运蛋白；$\mathrm{LPL}$：脂蛋白脂肪酶；$\mathrm{PTP}$：磷脂转运蛋白。
:::

:::compare{title="激活还是抑制：LPL 与 LCAT 的 apo 开关"}
| 酶 | 激活 | 抑制 |
|----|------|------|
| $\mathrm{LPL}$ | $\mathrm{apo\,C\,II}$（不可缺少）；$\mathrm{apo\,A\,IV}$ 辅助 | $\mathrm{apo\,C\,III}$ |
| $\mathrm{LCAT}$ | $\mathrm{apo\,A\,I}$；$\mathrm{apo\,C\,I}$ 教材标“？” | $\mathrm{apo\,A\,II}$ |
:::

:::pitfall{label="apo B48 不是把 apo B100 切成 48% 的碎片那么简单，但数字确实约一半"}
$\mathrm{B}100$：$4\,536$ 个氨基酸，分子质量 $512\,723$；$\mathrm{B}48$：$2\,152$ 个氨基酸，分子质量 $264\,000$，大约是前者的一半，只出现在 $\mathrm{CM}$，功能是促进 $\mathrm{CM}$ 合成。$\mathrm{LDL}$ 受体认的是 $\mathrm{B}100$ 或 $\mathrm{E}$，不认 $\mathrm{B}48$。$\mathrm{CM}$ 残粒入肝靠的是 $\mathrm{apo\,E}$ 被 $\mathrm{LRP}$ 识别，不是 $\mathrm{B}48$ 走 $\mathrm{LDL}$ 受体。
:::

**2. 不同脂蛋白具有相似基本结构**　大多数载脂蛋白如 $\mathrm{apo\,A\,I}$、$\mathrm{A\,II}$、$\mathrm{C\,I}$、$\mathrm{C\,II}$、$\mathrm{C\,III}$ 及 $\mathrm{E}$ 等均具双性 $\alpha$-螺旋（amphipathic $\alpha$ helix）结构：不带电荷的疏水氨基酸残基构成 $\alpha$-螺旋非极性面，带电荷的亲水氨基酸残基构成 $\alpha$-螺旋极性面。在脂蛋白表面，非极性面借其非极性疏水氨基酸残基与脂蛋白内核疏水性较强的甘油三酯（triglycerides，$\mathrm{TG}$）及胆固醇酯（cholesterol ester，$\mathrm{CE}$）以疏水键相连，极性面则朝外，与血浆的水相接触。磷脂及游离胆固醇具有极性及非极性基团，可以借非极性疏水基团与脂蛋白内核疏水性较强的 $\mathrm{TG}$ 及 $\mathrm{CE}$ 以疏水键相连，极性基团朝外，与血浆的水相接触。所以，脂蛋白是以 $\mathrm{TG}$ 及 $\mathrm{CE}$ 为内核，载脂蛋白、磷脂及游离胆固醇单分子层覆盖于表面的复合体，保证不溶于水的脂质能在水相的血浆中正常运输。脂蛋白一般呈球状，$\mathrm{CM}$ 及 $\mathrm{VLDL}$ 主要以 $\mathrm{TG}$ 为内核，$\mathrm{LDL}$ 及 $\mathrm{HDL}$ 则主要以 $\mathrm{CE}$ 为内核。

:::definition{label="脂蛋白的基本结构"}
脂蛋白以甘油三酯（$\mathrm{TG}$）及胆固醇酯（$\mathrm{CE}$）为内核，载脂蛋白、磷脂及游离胆固醇单分子层覆盖于表面，一般呈球状。不溶于水的脂质因此能在水相血浆中运输。
:::

:::definition{label="双性 α-螺旋"}
大多数载脂蛋白（$\mathrm{apo\,A\,I}$、$\mathrm{A\,II}$、$\mathrm{C\,I}$、$\mathrm{C\,II}$、$\mathrm{C\,III}$、$\mathrm{E}$ 等）具双性 $\alpha$-螺旋（amphipathic $\alpha$ helix）：疏水氨基酸构成非极性面，朝向内核 $\mathrm{TG}/\mathrm{CE}$；亲水氨基酸构成极性面，朝向血浆水相。
:::

:::compare{title="内核以 TG 为主还是以 CE 为主"}
| 颗粒 | 主要内核 | 功能方向 |
|------|----------|----------|
| $\mathrm{CM}$、$\mathrm{VLDL}$ | $\mathrm{TG}$ | 运甘油三酯（外源／内源） |
| $\mathrm{LDL}$、$\mathrm{HDL}$ | $\mathrm{CE}$ | 运胆固醇（内源前向／逆向） |
:::

:::insight{label="表面那一层是单分子层，不是细胞膜那样的双层"}
内核是疏水的 $\mathrm{TG}+\mathrm{CE}$；表面是 apo、磷脂、游离胆固醇的单分子层。新生 $\mathrm{HDL}$ 例外，后文写成双脂层盘状，成熟后才膨胀成单脂层球状。不要把所有脂蛋白都画成双层膜小泡。
:::

## 三、不同来源脂蛋白具有不同功能和不同代谢途径

### （一）乳糜微粒主要转运外源性甘油三酯及胆固醇

乳糜微粒（chylomicron，$\mathrm{CM}$）代谢途径又称外源性脂质转运途径或外源性脂质代谢途径（图8-10）。食物脂肪消化后，小肠黏膜细胞用摄取的中长链脂肪酸再合成甘油三酯（triglycerides，$\mathrm{TG}$），并与合成及吸收的磷脂和胆固醇，加上 $\mathrm{apo\,B}48$、$\mathrm{A\,I}$、$\mathrm{A\,II}$、$\mathrm{A\,IV}$ 等组装成新生 $\mathrm{CM}$，经淋巴道入血，从高密度脂蛋白（high density lipoprotein，$\mathrm{HDL}$）获得 $\mathrm{apo\,C}$ 及 $\mathrm{E}$，并将部分 $\mathrm{apo\,A\,I}$、$\mathrm{A\,II}$、$\mathrm{A\,IV}$ 转移给 $\mathrm{HDL}$，形成成熟 $\mathrm{CM}$。

:::note{label="电子版缺失"}
教材图8-10（乳糜微粒的代谢）电子版图源 `p0193_01.png` 为 $0$ 字节，不嵌入 `src`。图注原列：$\mathrm{A}$ 载脂蛋白 $\mathrm{A}$；$\mathrm{B}48$ 载脂蛋白 $\mathrm{B}48$；$\mathrm{C}$ 载脂蛋白 $\mathrm{C}$；$\mathrm{Ch}$ 胆固醇；$\mathrm{CM}$ 乳糜微粒；$\mathrm{E}$ 载脂蛋白 $\mathrm{E}$；$\mathrm{HDL}$ 高密度脂蛋白；$\mathrm{LCAT}$ 卵磷脂－胆固醇酰基转移酶；$\mathrm{LDLR}$ 低密度脂蛋白受体；$\mathrm{LPL}$ 脂蛋白脂肪酶；$\mathrm{LRP}$ 低密度脂蛋白受体相关蛋白；$\mathrm{TG}$ 甘油三酯。正文按下述外源性途径保留。
:::

:::definition{label="外源性脂质转运途径"}
乳糜微粒代谢途径又称外源性脂质转运途径或外源性脂质代谢途径：把食物来源的甘油三酯及胆固醇从小肠经淋巴入血，交给外周组织，残粒回肝。
:::

:::definition{label="新生 CM 与成熟 CM"}
新生 $\mathrm{CM}$ 在小肠黏膜组装，含 $\mathrm{apo\,B}48$、$\mathrm{A\,I}$、$\mathrm{A\,II}$、$\mathrm{A\,IV}$，经淋巴入血。从 $\mathrm{HDL}$ 获得 $\mathrm{apo\,C}$ 及 $\mathrm{E}$，并把部分 $\mathrm{A\,I}$、$\mathrm{A\,II}$、$\mathrm{A\,IV}$ 转移给 $\mathrm{HDL}$，成为成熟 $\mathrm{CM}$。
:::

$\mathrm{Apo\,C\,II}$ 激活骨骼肌、心肌及脂肪等组织毛细血管内皮细胞表面脂蛋白脂肪酶（lipoprotein lipase，$\mathrm{LPL}$），使 $\mathrm{CM}$ 中 $\mathrm{TG}$ 及磷脂逐步水解，产生甘油、脂肪酸及溶血磷脂。随着 $\mathrm{CM}$ 内核 $\mathrm{TG}$ 不断被水解，释出大量脂肪酸被心肌、骨骼肌、脂肪组织及肝组织摄取利用，$\mathrm{CM}$ 颗粒不断变小，表面过多的 $\mathrm{apo\,A\,I}$、$\mathrm{A\,II}$、$\mathrm{A\,IV}$、$\mathrm{C}$、磷脂及胆固醇离开 $\mathrm{CM}$ 颗粒，形成新生 $\mathrm{HDL}$。$\mathrm{CM}$ 最后转变成富含胆固醇酯（cholesterol ester，$\mathrm{CE}$）、$\mathrm{apo\,B}48$ 及 $\mathrm{apo\,E}$ 的 $\mathrm{CM}$ 残粒（remnant），被细胞膜 $\mathrm{LDL}$ 受体相关蛋白（$\mathrm{LDL}$ receptor related protein，$\mathrm{LRP}$）识别、结合并被肝细胞摄取后彻底降解。

:::definition{label="脂蛋白脂肪酶"}
脂蛋白脂肪酶（lipoprotein lipase，$\mathrm{LPL}$）位于骨骼肌、心肌及脂肪等组织毛细血管内皮细胞表面，水解 $\mathrm{CM}$、$\mathrm{VLDL}$ 中的甘油三酯及磷脂，产生甘油、脂肪酸及溶血磷脂。
:::

:::definition{label="apo CII 是 LPL 不可缺少的激活剂"}
无 $\mathrm{apo\,C\,II}$ 时，$\mathrm{LPL}$ 活性很低；加入 $\mathrm{apo\,C\,II}$ 后，$\mathrm{LPL}$ 活性可增加 $10\sim 50$ 倍。
:::

:::definition{label="CM 残粒"}
$\mathrm{CM}$ 残粒（remnant）富含胆固醇酯、$\mathrm{apo\,B}48$ 及 $\mathrm{apo\,E}$，被肝细胞膜 $\mathrm{LRP}$（$\mathrm{LDL}$ 受体相关蛋白）识别、结合，入肝彻底降解。
:::

:::timeline{period="CM 从新生到残粒"}
- **小肠黏膜** 中长链脂肪酸再合成 TG，与磷脂、胆固醇及 apo B48、A I、A II、A IV 组装新生 CM，经淋巴入血
- **血浆成熟** 从 HDL 获得 apo C 及 E，部分 apo A 转给 HDL
- **LPL 水解** apo C II 激活毛细血管内皮 LPL，TG 及磷脂水解，脂肪酸被心肌、骨骼肌、脂肪及肝摄取
- **表面脱落** 过多 apo A、C、磷脂及胆固醇离开颗粒，形成新生 HDL
- **残粒入肝** 富含 CE、apo B48 及 apo E 的残粒经 LRP 被肝摄取降解
:::

正常人 $\mathrm{CM}$ 在血浆中代谢迅速，半衰期为 $5\sim 15$ 分钟，因此正常人空腹 $12\sim 14$ 小时血浆中不含 $\mathrm{CM}$。

:::pitfall{label="空腹 12～14 小时血浆不应检出 CM"}
半衰期只有 $5\sim 15$ 分钟。空腹仍有乳糜微粒，是Ⅰ型或Ⅴ型脂蛋白异常血症的线索，不是“正常人血脂波动”。
:::

:::insight{label="apo C 是从 HDL 借来的，用完要还"}
新生 $\mathrm{CM}$ 自己不带够 $\mathrm{C\,II}$。成熟时向 $\mathrm{HDL}$ 借 $\mathrm{apo\,C}$ 和 $\mathrm{E}$；$\mathrm{TG}$ 水解完，表面 $\mathrm{apo\,C}$ 又离开。$\mathrm{HDL}$ 因此是 $\mathrm{apo\,C\,II}$ 贮存库，后文会再写一次。
:::

### （二）极低密度脂蛋白主要转运内源性甘油三酯

极低密度脂蛋白（very low density lipoprotein，$\mathrm{VLDL}$）是运输内源性 $\mathrm{TG}$ 的主要形式，其血浆代谢产物低密度脂蛋白（low density lipoprotein，$\mathrm{LDL}$）是运输内源性胆固醇的主要形式。$\mathrm{VLDL}$ 及 $\mathrm{LDL}$ 代谢途径又称内源性脂质转运途径或内源性脂质代谢途径。

:::definition{label="内源性脂质转运途径"}
$\mathrm{VLDL}$ 及 $\mathrm{LDL}$ 代谢途径又称内源性脂质转运途径或内源性脂质代谢途径：$\mathrm{VLDL}$ 运内源甘油三酯，$\mathrm{LDL}$ 运内源胆固醇。
:::

:::definition{label="极低密度脂蛋白"}
极低密度脂蛋白（very low density lipoprotein，$\mathrm{VLDL}$）是运输内源性甘油三酯的主要形式。肝细胞以葡萄糖分解中间产物、食物来源脂肪酸和机体脂肪酸库中的脂肪酸合成 $\mathrm{TG}$，再与 $\mathrm{apo\,B}100$、$\mathrm{E}$ 以及磷脂、胆固醇等组装成 $\mathrm{VLDL}$。小肠黏膜细胞亦可合成少量 $\mathrm{VLDL}$。
:::

:::note{label="电子版缺失"}
教材图8-11（极低密度脂蛋白的代谢及低密度脂蛋白的形成）电子版图源 `p0195_01.png` 为 $0$ 字节，不嵌入 `src`。图注原列：$\mathrm{A}$、$\mathrm{A\,I}$、$\mathrm{B}100$、$\mathrm{C}$、$\mathrm{CE}$、$\mathrm{Ch}$、$\mathrm{E}$、$\mathrm{HDL}$、$\mathrm{IDL}$、$\mathrm{LCAT}$、$\mathrm{LDL}$、$\mathrm{LDLR}$、$\mathrm{LPL}$、$\mathrm{LRP}$、$\mathrm{TG}$、$\mathrm{VLDL}$。正文按 $\mathrm{VLDL}\to\mathrm{IDL}\to\mathrm{LDL}$ 的文字账保留。
:::

$\mathrm{VLDL}$ 分泌入血后，从高密度脂蛋白（$\mathrm{HDL}$）获得 $\mathrm{apo\,C}$，其中 $\mathrm{apo\,C\,II}$ 激活肝外组织毛细血管内皮细胞表面的脂蛋白脂肪酶（$\mathrm{LPL}$）。和 $\mathrm{CM}$ 代谢一样，$\mathrm{VLDL}$ 中 $\mathrm{TG}$ 在 $\mathrm{LPL}$ 作用下，水解释出脂肪酸和甘油供肝外组织利用。同时，$\mathrm{VLDL}$ 表面的 $\mathrm{apo\,C}$、磷脂及胆固醇向 $\mathrm{HDL}$ 转移，而 $\mathrm{HDL}$ 胆固醇酯又转移到 $\mathrm{VLDL}$。该过程不断进行，$\mathrm{VLDL}$ 中 $\mathrm{TG}$ 不断减少，$\mathrm{CE}$ 逐渐增加，$\mathrm{apo\,B}100$ 及 $\mathrm{E}$ 相对增加，颗粒逐渐变小，密度逐渐增加，转变为中密度脂蛋白（intermediate density lipoprotein，$\mathrm{IDL}$）。

:::definition{label="IDL 的组成"}
$\mathrm{IDL}$ 中胆固醇及甘油三酯含量大致相等，载脂蛋白则主要是 $\mathrm{apo\,B}100$ 及 $\mathrm{E}$。
:::

肝细胞膜 $\mathrm{LRP}$ 可识别和结合 $\mathrm{IDL}$，因此部分 $\mathrm{IDL}$ 被肝细胞摄取、降解。未被肝细胞摄取的 $\mathrm{IDL}$（在人约占总 $\mathrm{IDL}$ 的 $50\%$，在大鼠约占 $10\%$），其 $\mathrm{TG}$ 被 $\mathrm{LPL}$ 及肝脂肪酶（hepatic lipase，$\mathrm{HL}$）进一步水解，表面 $\mathrm{apo\,E}$ 转移至 $\mathrm{HDL}$。这样，$\mathrm{IDL}$ 中剩下的脂质主要是 $\mathrm{CE}$，剩下的载脂蛋白只有 $\mathrm{apo\,B}100$，转变为 $\mathrm{LDL}$（图8-11）。$\mathrm{VLDL}$ 在血液中的半衰期为 $6\sim 12$ 小时。

:::definition{label="肝脂肪酶"}
肝脂肪酶（hepatic lipase，$\mathrm{HL}$）与 $\mathrm{LPL}$ 一起进一步水解未被肝摄取的 $\mathrm{IDL}$ 中的甘油三酯，帮助 $\mathrm{IDL}$ 转变成 $\mathrm{LDL}$。
:::

:::timeline{period="VLDL 变成 LDL"}
- **肝（少量小肠）组装** TG + apo B100、E + 磷脂、胆固醇 → VLDL 入血
- **向 HDL 借 apo C** apo C II 激活肝外 LPL，水解 TG
- **脂质对向转移** 表面 apo C、磷脂、胆固醇给 HDL；HDL 的 CE 转入 VLDL
- **变成 IDL** TG 减少、CE 增加，apo B100 及 E 相对增加；约一半（人）被肝 LRP 摄取
- **剩下的 IDL** LPL 及肝脂肪酶再水解 TG，apo E 回 HDL → 只剩 CE 和 apo B100，即 LDL
:::

:::compare{title="CM 与 VLDL：都靠 LPL，户头不同"}
| 项目 | $\mathrm{CM}$ | $\mathrm{VLDL}$ |
|------|--------------|----------------|
| 脂质来源 | 外源（食物） | 内源（肝合成为主） |
| 特征 apo | $\mathrm{B}48$ | $\mathrm{B}100$ |
| 入血通路 | 淋巴 | 肝直接入血 |
| $\mathrm{LPL}$ | 要，由 $\mathrm{apo\,C\,II}$ 激活 | 同样要 |
| 终局 | 残粒经 $\mathrm{LRP}$ 入肝 | 部分 $\mathrm{IDL}$ 入肝；其余变成 $\mathrm{LDL}$ |
| 半衰期 | $5\sim 15$ 分钟 | $6\sim 12$ 小时 |
:::

:::pitfall{label="人约 50% 的 IDL 变成 LDL，大鼠只有约 10%"}
教材把两个数字写在一起。人血浆 $\mathrm{LDL}$ 多，正因为一半 $\mathrm{IDL}$ 没有被肝直接吃掉。不要用人的 $50\%$ 去说大鼠，也不要把全部 $\mathrm{VLDL}$ 听成都会变成 $\mathrm{LDL}$。
:::

### （三）低密度脂蛋白主要转运内源性胆固醇

人体多种组织器官能摄取、降解低密度脂蛋白（low density lipoprotein，$\mathrm{LDL}$），肝是主要器官，约 $50\%$ $\mathrm{LDL}$ 在肝降解。肾上腺皮质、卵巢、睾丸等组织摄取及降解 $\mathrm{LDL}$ 能力亦较强。血浆 $\mathrm{LDL}$ 降解既可通过 $\mathrm{LDL}$ 受体（$\mathrm{LDL}$ receptor）途径（图8-12）完成，也可通过单核－吞噬细胞系统完成。正常人血浆 $\mathrm{LDL}$，每天约 $45\%$ 被清除，其中 $2/3$ 经 $\mathrm{LDL}$ 受体途径，$1/3$ 经单核－吞噬细胞系统。血浆 $\mathrm{LDL}$ 半衰期为 $2\sim 4$ 天。

:::definition{label="低密度脂蛋白"}
低密度脂蛋白（low density lipoprotein，$\mathrm{LDL}$）是运输内源性胆固醇的主要形式，由 $\mathrm{VLDL}$ 经 $\mathrm{IDL}$ 在血浆中转变而来。约 $50\%$ 在肝降解。
:::

:::keypoint{label="正常人每天清除约 45% 的血浆 LDL"}
- $2/3$ 走 $\mathrm{LDL}$ 受体途径。
- $1/3$ 走单核－吞噬细胞系统。
- 半衰期 $2\sim 4$ 天。
:::

:::note{label="电子版缺失"}
教材图8-12（低密度脂蛋白受体代谢途径）电子版图源 `p0195_02.png` 为 $0$ 字节，不嵌入 `src`。图注：$\mathrm{ACAT}$ 为脂肪酰 $\mathrm{CoA}$：胆固醇脂肪酰转移酶。正文按 Brown、Goldstein 的受体途径保留。
:::

$1974$ 年，Brown MS 及 Goldstein JL 首先在人成纤维细胞膜表面发现了能特异结合 $\mathrm{LDL}$ 的 $\mathrm{LDL}$ 受体。他们纯化了该受体，证明它是 $839$ 个氨基酸残基构成的糖蛋白，分子质量 $160\,000$。后来发现，$\mathrm{LDL}$ 受体广泛分布于全身，特别是肝、肾上腺皮质、卵巢、睾丸、动脉壁等组织的细胞膜表面，能特异识别、结合含 $\mathrm{apo\,B}100$ 或 $\mathrm{apo\,E}$ 的脂蛋白，故又称 $\mathrm{apo\,B/E}$ 受体（$\mathrm{apo\,B/E}$ receptor）。

:::definition{label="LDL 受体"}
$\mathrm{LDL}$ 受体是 $839$ 个氨基酸残基构成的糖蛋白，分子质量 $160\,000$，能特异识别、结合含 $\mathrm{apo\,B}100$ 或 $\mathrm{apo\,E}$ 的脂蛋白，又称 $\mathrm{apo\,B/E}$ 受体。广泛分布于肝、肾上腺皮质、卵巢、睾丸、动脉壁等细胞膜表面。
:::

当血浆 $\mathrm{LDL}$ 与 $\mathrm{LDL}$ 受体结合后，形成受体－配体复合物在细胞膜表面聚集成簇，经内吞作用进入细胞，与溶酶体融合。在溶酶体蛋白水解酶作用下，$\mathrm{apo\,B}100$ 被水解成氨基酸；胆固醇酯则被胆固醇酯酶水解成游离胆固醇和脂肪酸。游离胆固醇在调节细胞胆固醇代谢上具有重要作用：①抑制内质网 $\mathrm{HMG\text{-}CoA}$ 还原酶（$\mathrm{HMG\text{-}CoA}$ reductase），从而抑制细胞自身胆固醇合成；②从转录水平抑制 $\mathrm{LDL}$ 受体基因表达，抑制受体蛋白合成，减少细胞对 $\mathrm{LDL}$ 进一步摄取；③激活内质网脂肪酰 $\mathrm{CoA}$：胆固醇脂肪酰转移酶（acyl $\mathrm{CoA}$：cholesterol acyl transferase，$\mathrm{ACAT}$），将游离胆固醇酯化成胆固醇酯在胞质溶胶贮存。同时，游离胆固醇还有重要生理功能：①被细胞膜摄取，构成重要的膜成分；②在肾上腺、卵巢及睾丸等固醇激素合成细胞，可作为类固醇激素合成原料。$\mathrm{LDL}$ 被该途径摄取、代谢多少，取决于细胞膜上受体多少。肝、肾上腺皮质、性腺等组织 $\mathrm{LDL}$ 受体数目较多，故摄取 $\mathrm{LDL}$ 亦较多。

:::timeline{period="LDL 受体途径"}
- **结合** 血浆 LDL 与膜 LDL 受体（apo B/E 受体）结合，复合物聚集成簇
- **内吞** 入胞，与溶酶体融合
- **水解** apo B100 → 氨基酸；CE → 游离胆固醇 + 脂肪酸
- **游离胆固醇三件事** 关 HMG-CoA 还原酶；关 LDL 受体基因转录；开 ACAT 把胆固醇酯化贮存
- **生理用途** 进细胞膜；在肾上腺、卵巢、睾丸作类固醇激素原料
:::

:::cause-effect{title="游离胆固醇把三扇门一起关上或改写"}
溶酶体释放游离胆固醇 → ①抑制内质网 $\mathrm{HMG\text{-}CoA}$ 还原酶，少自己写胆固醇；②转录水平减少 $\mathrm{LDL}$ 受体，少再摄取；③激活 $\mathrm{ACAT}$，把多余游离胆固醇写成 $\mathrm{CE}$ 贮存。
:::

:::pitfall{label="apo B/E 受体认 B100 和 E，不认 B48"}
$\mathrm{CM}$ 残粒靠 $\mathrm{LRP}$ 认 $\mathrm{apo\,E}$ 入肝；$\mathrm{LDL}$ 靠 $\mathrm{LDL}$ 受体认 $\mathrm{apo\,B}100$。不要把两种受体并成“肝上一个吃脂蛋白的受体”。$\mathrm{IDL}$ 因含 $\mathrm{apo\,E}$，也可被 $\mathrm{LRP}$ 结合。
:::

:::insight{label="第五节的还原酶开关，在这里接到 LDL 入胞"}
细胞胆固醇升高抑制 $\mathrm{HMG\text{-}CoA}$ 还原酶合成——第六节把来源写清楚：$\mathrm{LDL}$ 送来的胆固醇酯水解出游离胆固醇。外源／内源只要提高了细胞胆固醇，都关合成。这和本章小结那一句是同一把钥匙。
:::

血浆 $\mathrm{LDL}$ 还可被修饰成如氧化修饰 $\mathrm{LDL}$（oxidized $\mathrm{LDL}$，$\mathrm{ox\text{-}LDL}$），被清除细胞即单核－吞噬细胞系统中的巨噬细胞及血管内皮细胞清除。这两类细胞膜表面有清道夫受体（scavenger receptor，$\mathrm{SR}$），可与修饰 $\mathrm{LDL}$ 结合而清除血浆修饰 $\mathrm{LDL}$。

:::definition{label="清道夫受体"}
清道夫受体（scavenger receptor，$\mathrm{SR}$）位于巨噬细胞及血管内皮细胞表面，结合氧化修饰 $\mathrm{LDL}$（$\mathrm{ox\text{-}LDL}$）等修饰 $\mathrm{LDL}$，经单核－吞噬细胞系统清除。
:::

:::compare{title="LDL 的两条清除途径"}
| 途径 | 识别 | 占正常人每日清除 |
|------|------|-------------------|
| $\mathrm{LDL}$ 受体（$\mathrm{apo\,B/E}$ 受体） | 未修饰 $\mathrm{LDL}$ 的 $\mathrm{apo\,B}100$ | $2/3$ |
| 清道夫受体 | 修饰 $\mathrm{LDL}$（如 $\mathrm{ox\text{-}LDL}$） | $1/3$（单核－吞噬细胞系统） |
:::

### （四）高密度脂蛋白主要逆向转运胆固醇

新生高密度脂蛋白（high density lipoprotein，$\mathrm{HDL}$）主要由肝合成，小肠可合成部分。在 $\mathrm{CM}$ 及 $\mathrm{VLDL}$ 代谢过程中，其表面 $\mathrm{apo\,A\,I}$、$\mathrm{A\,II}$、$\mathrm{A\,IV}$、$\mathrm{C}$ 以及磷脂、胆固醇等脱离亦可形成。$\mathrm{HDL}$ 可按密度分为 $\mathrm{HDL}_{1}$、$\mathrm{HDL}_{2}$ 及 $\mathrm{HDL}_{3}$。$\mathrm{HDL}_{1}$ 也称作 $\mathrm{HDL}_\mathrm{c}$，仅存在于摄取高胆固醇膳食后血浆，正常人血浆主要含 $\mathrm{HDL}_{2}$ 及 $\mathrm{HDL}_{3}$。新生 $\mathrm{HDL}$ 的代谢过程实际上就是胆固醇逆向转运（reverse cholesterol transport，$\mathrm{RCT}$）过程（图8-13），它将肝外组织细胞胆固醇，通过血循环转运到肝，转化为胆汁酸排出，部分胆固醇也可直接随胆汁排入肠腔。

:::definition{label="高密度脂蛋白"}
高密度脂蛋白（high density lipoprotein，$\mathrm{HDL}$）主要逆向转运胆固醇。新生 $\mathrm{HDL}$ 主要由肝合成，小肠可合成部分；$\mathrm{CM}$、$\mathrm{VLDL}$ 代谢时表面成分脱落亦可形成。
:::

:::definition{label="胆固醇逆向转运"}
胆固醇逆向转运（reverse cholesterol transport，$\mathrm{RCT}$）是新生 $\mathrm{HDL}$ 的代谢过程：将肝外组织细胞胆固醇经血循环转运到肝，转化为胆汁酸排出，部分胆固醇也可直接随胆汁排入肠腔。
:::

:::compare{title="HDL 亚类"}
| 亚类 | 教材落点 |
|------|----------|
| $\mathrm{HDL}_{1}$（$\mathrm{HDL}_\mathrm{c}$） | 仅存在于摄取高胆固醇膳食后血浆 |
| $\mathrm{HDL}_{2}$、$\mathrm{HDL}_{3}$ | 正常人血浆主要含这两类；$\mathrm{RCT}$ 中由盘状新生 $\mathrm{HDL}$ 经 $\mathrm{HDL}_{3}$ 成熟为富含胆固醇的 $\mathrm{HDL}_{2}$ |
:::

:::note{label="电子版缺失"}
教材图8-13（胆固醇逆向转运途径）电子版图源 `p0196_01.png` 为 $0$ 字节，不嵌入 `src`。图注原列：$\mathrm{A}$、$\mathrm{A\,I}$、$\mathrm{B}48$、$\mathrm{B}100$、$\mathrm{C}$、$\mathrm{CE}$、$\mathrm{Ch}$、$\mathrm{CM}$、$\mathrm{E}$、$\mathrm{HDL}$、$\mathrm{LCAT}$（卵磷脂－胆固醇脂肪酰转移酶）、$\mathrm{LDL}$、$\mathrm{SR\text{-}BI}$（B 族Ⅰ型清道夫受体）、$\mathrm{TG}$、$\mathrm{VLDL}$。正文按 $\mathrm{RCT}$ 三步保留。
:::

$\mathrm{RCT}$ 第一步是胆固醇自肝外细胞包括动脉平滑肌细胞及巨噬细胞等移出至 $\mathrm{HDL}$。大量研究证明，$\mathrm{HDL}$ 是细胞胆固醇移出不可缺少的接受体（acceptor）。存在于细胞间液中富含磷脂及 $\mathrm{apo\,A\,I}$、含较少游离胆固醇（free cholesterol，$\mathrm{FC}$）的新生 $\mathrm{HDL}$，呈盘状，根据电泳位置将其称为前 $\beta_{1}$-$\mathrm{HDL}$。能与肝外细胞表面的 B 族Ⅰ型清道夫受体（scavenger receptor class B type I，$\mathrm{SR\text{-}BI}$）结合，在 $\mathrm{ATP}$ 结合盒转运蛋白 $\mathrm{A}1$（$\mathrm{ATP}$-binding cassette transporter $\mathrm{A}1$，$\mathrm{ABCA}1$）和 $\mathrm{G}1$ 的作用下，将细胞内的胆固醇转移至新生 $\mathrm{HDL}$ 上。$\mathrm{ABCA}1$ 主要将胆固醇转移至小颗粒 $\mathrm{HDL}$ 甚至未结合脂质的 $\mathrm{apo\,A\,I}$ 分子上，$\mathrm{ABCG}1$ 主要将胆固醇转移至较大颗粒的 $\mathrm{HDL}$ 上。可见，新生 $\mathrm{HDL}$ 是细胞胆固醇移出不可缺少的接受体（acceptor）。

:::definition{label="前β1-HDL"}
细胞间液中富含磷脂及 $\mathrm{apo\,A\,I}$、含较少游离胆固醇的新生 $\mathrm{HDL}$，呈盘状，电泳位置称为前 $\beta_{1}$-$\mathrm{HDL}$。它是细胞胆固醇移出不可缺少的接受体。
:::

:::compare{title="ABCA1 与 ABCG1"}
| 转运蛋白 | 胆固醇交给谁 |
|----------|----------------|
| $\mathrm{ABCA}1$ | 小颗粒 $\mathrm{HDL}$，甚至未结合脂质的 $\mathrm{apo\,A\,I}$ |
| $\mathrm{ABCG}1$ | 较大颗粒的 $\mathrm{HDL}$ |
:::

:::pitfall{label="清道夫受体有两本账：SR 清 ox-LDL，SR-BI 接 HDL"}
巨噬细胞／内皮上的清道夫受体（$\mathrm{SR}$）结合修饰 $\mathrm{LDL}$。肝外细胞及肝细胞膜上的 B 族Ⅰ型清道夫受体（$\mathrm{SR\text{-}BI}$）结合新生或成熟 $\mathrm{HDL}$，参与胆固醇移出和肝选择性摄取 $\mathrm{CE}$。不要把 $\mathrm{SR\text{-}BI}$ 写成“又一条吃 $\mathrm{ox\text{-}LDL}$ 的受体”。
:::

$\mathrm{RCT}$ 第二步是 $\mathrm{HDL}$ 所运载的胆固醇的酯化及胆固醇酯的转运。新生 $\mathrm{HDL}$ 从肝外细胞接受的 $\mathrm{FC}$，分布在 $\mathrm{HDL}$ 表面。在血浆卵磷脂－胆固醇脂肪酰转移酶（lecithin-cholesterol acyl transferase，$\mathrm{LCAT}$）作用下，$\mathrm{HDL}$ 表面卵磷脂的 $2$ 位脂肪酰基转移至胆固醇 $3$ 位羟基，生成溶血卵磷脂及胆固醇酯（cholesterol ester，$\mathrm{CE}$）。$\mathrm{CE}$ 在生成后即转入 $\mathrm{HDL}$ 内核，表面则可继续接受肝外细胞 $\mathrm{FC}$，消耗的卵磷脂也可从肝外细胞补充。该过程反复进行，$\mathrm{HDL}$ 内核 $\mathrm{CE}$ 不断增加，双脂层盘状 $\mathrm{HDL}$ 逐步膨胀为单脂层球状，颗粒逐步增大、密度逐渐减小，形成 $\mathrm{HDL}_{3}$，最终转变为成熟的富含胆固醇的 $\mathrm{HDL}_{2}$。$\mathrm{LCAT}$ 由肝实质细胞合成和分泌，在血浆中发挥作用，$\mathrm{HDL}$ 表面的 $\mathrm{apo\,A\,I}$ 是 $\mathrm{LCAT}$ 激活剂。

:::definition{label="LCAT"}
卵磷脂－胆固醇脂肪酰转移酶（lecithin-cholesterol acyl transferase，$\mathrm{LCAT}$）由肝实质细胞合成和分泌，在血浆中发挥作用：把 $\mathrm{HDL}$ 表面卵磷脂 $2$ 位脂肪酰基转到胆固醇 $3$ 位羟基，生成溶血卵磷脂和胆固醇酯。$\mathrm{apo\,A\,I}$ 是其激活剂。
:::

:::insight{label="酯化是为了把表面腾出来继续接游离胆固醇"}
$\mathrm{FC}$ 在表面，$\mathrm{CE}$ 进内核。不酯化，表面很快饱和，肝外细胞的胆固醇移不出。$\mathrm{LCAT}$ 每转一次脂肪酰，接受体就恢复一次。盘状双脂层因此胀成球状单脂层。
:::

:::compare{title="ACAT 与 LCAT"}
| 酶 | 场所 | 脂肪酰供体 | 产物去向 |
|----|------|------------|----------|
| $\mathrm{ACAT}$ | 细胞内内质网 | 脂肪酰 $\mathrm{CoA}$ | 细胞 $\mathrm{CE}$ 贮存 |
| $\mathrm{LCAT}$ | 血浆（酶来自肝） | $\mathrm{HDL}$ 表面卵磷脂 $2$ 位 | $\mathrm{HDL}$ 内核 $\mathrm{CE}$，$\mathrm{RCT}$ |
:::

在 $\mathrm{HDL}$ 成熟过程中，酯化后形成的 $\mathrm{CE}$ 可在胆固醇酯转运蛋白（cholesterol ester transfer protein，$\mathrm{CETP}$）的作用下，与 $\mathrm{VLDL}$ 中的 $\mathrm{TG}$ 交换，将 $\mathrm{TG}$ 由 $\mathrm{VLDL}$ 转移至 $\mathrm{HDL}$、将 $\mathrm{CE}$ 由 $\mathrm{HDL}$ 转移至 $\mathrm{VLDL}$。

:::definition{label="CETP"}
胆固醇酯转运蛋白（cholesterol ester transfer protein，$\mathrm{CETP}$）催化 $\mathrm{HDL}$ 的 $\mathrm{CE}$ 与 $\mathrm{VLDL}$ 的 $\mathrm{TG}$ 交换：$\mathrm{TG}$ 从 $\mathrm{VLDL}$ 到 $\mathrm{HDL}$，$\mathrm{CE}$ 从 $\mathrm{HDL}$ 到 $\mathrm{VLDL}$。
:::

$\mathrm{RCT}$ 最后一步在肝进行。成熟 $\mathrm{HDL}$ 经血液运输至肝，被肝细胞膜 $\mathrm{SR\text{-}BI}$ 识别、结合，$\mathrm{CE}$ 被肝细胞选择性摄取。被 $\mathrm{CETP}$ 从 $\mathrm{HDL}$ 转移至 $\mathrm{VLDL}$ 的 $\mathrm{CE}$，在 $\mathrm{VLDL}$ 被转变成 $\mathrm{LDL}$ 后，通过 $\mathrm{LDL}$ 受体被肝细胞摄取。$\mathrm{CE}$ 通过这两条途径进入肝细胞后，被水解释放出胆固醇，转化成胆汁酸或直接以胆固醇通过胆汁排出。机体通过这种机制，还可将外周组织衰老细胞膜中的胆固醇转运至肝代谢并排出。$\mathrm{HDL}$ 的血浆半衰期为 $3\sim 5$ 天。

:::keypoint{label="RCT 三步"}
- 移出：肝外细胞（含动脉平滑肌、巨噬细胞）→ 新生盘状前 $\beta_{1}$-$\mathrm{HDL}$（$\mathrm{SR\text{-}BI}$、$\mathrm{ABCA}1$、$\mathrm{ABCG}1$）。
- 酯化与交换：血浆 $\mathrm{LCAT}$（$\mathrm{apo\,A\,I}$ 激活）写 $\mathrm{CE}$；$\mathrm{CETP}$ 把部分 $\mathrm{CE}$ 换成 $\mathrm{VLDL}$ 的 $\mathrm{TG}$；颗粒经 $\mathrm{HDL}_{3}$ 成熟为 $\mathrm{HDL}_{2}$。
- 入肝：成熟 $\mathrm{HDL}$ 经肝 $\mathrm{SR\text{-}BI}$ 选择性摄取 $\mathrm{CE}$；或 $\mathrm{CE}$ 随 $\mathrm{VLDL}\to\mathrm{LDL}$ 走 $\mathrm{LDL}$ 受体。入肝后水解，转胆汁酸或随胆汁排出。
:::

:::compare{title="胆固醇入肝的两条 RCT 终路"}
| 路径 | 识别 | 胆固醇形式 |
|------|------|------------|
| 成熟 $\mathrm{HDL}$ | 肝细胞膜 $\mathrm{SR\text{-}BI}$ | $\mathrm{CE}$ 被选择性摄取 |
| $\mathrm{HDL}\xrightarrow{\mathrm{CETP}}\mathrm{VLDL}\to\mathrm{LDL}$ | $\mathrm{LDL}$ 受体 | $\mathrm{CE}$ 随 $\mathrm{LDL}$ 入肝 |
:::

除参与 $\mathrm{RCT}$ 外，$\mathrm{HDL}$ 还是 $\mathrm{apo\,C\,II}$ 贮存库。$\mathrm{CM}$ 及 $\mathrm{VLDL}$ 进入血液后，需从 $\mathrm{HDL}$ 获得 $\mathrm{apo\,C\,II}$ 才能激活 $\mathrm{LPL}$，水解其 $\mathrm{TG}$。$\mathrm{CM}$ 及 $\mathrm{VLDL}$ 中 $\mathrm{TG}$ 水解完成后，$\mathrm{apo\,C\,II}$ 又回到 $\mathrm{HDL}$。

:::insight{label="HDL 同时干两件事：逆向运胆固醇，向外源／内源颗粒出借 CII"}
没有 $\mathrm{HDL}$ 这个贮存库，$\mathrm{LPL}$ 打不开，$\mathrm{CM}$ 和 $\mathrm{VLDL}$ 的甘油三酯水解都会慢。$\mathrm{RCT}$ 和 $\mathrm{LPL}$ 激活不是两套无关的 $\mathrm{HDL}$ 功能。
:::

:::compare{title="四类颗粒半衰期"}
| 颗粒 | 半衰期 |
|------|--------|
| $\mathrm{CM}$ | $5\sim 15$ 分钟 |
| $\mathrm{VLDL}$ | $6\sim 12$ 小时 |
| $\mathrm{LDL}$ | $2\sim 4$ 天 |
| $\mathrm{HDL}$ | $3\sim 5$ 天 |
:::

## 四、血浆脂蛋白代谢紊乱导致脂蛋白异常血症

### （一）不同脂蛋白的异常改变引起不同类型高脂血症

血浆脂质水平异常升高，超过正常范围上限称为高脂血症（hyperlipidemia）。在目前临床实践中，高脂血症指血浆胆固醇或／和甘油三酯超过正常范围上限，一般以成人空腹 $12\sim 14$ 小时血浆甘油三酯超过 $2.26\,\mathrm{mmol/L}$（$200\,\mathrm{mg/dl}$），胆固醇超过 $6.21\,\mathrm{mmol/L}$（$240\,\mathrm{mg/dl}$），儿童胆固醇超过 $4.14\,\mathrm{mmol/L}$（$160\,\mathrm{mg/dl}$）为高脂血症诊断标准。事实上，在高脂血症血浆中，一些脂蛋白脂质含量升高，而另外脂蛋白脂质含量可能降低。因此，有人认为将高脂血症称为脂蛋白异常血症（dyslipoproteinemia）更为合理。传统的分类方法将脂蛋白异常血症分为六型（表8-7）。随着研究的不断深入和临床工作的需要，发展形成了非高密度脂蛋白胆固醇（non-high density lipoprotein cholesterol，$\mathrm{non\text{-}HDL\text{-}C}$）概念，并与 $\mathrm{TG}$、$\mathrm{TC}$、高密度脂蛋白胆固醇（high density lipoprotein cholesterol，$\mathrm{HDL\text{-}C}$）和低密度脂蛋白胆固醇（low density lipoprotein cholesterol，$\mathrm{LDL\text{-}C}$）一起，按理想水平、合适水平、边缘升高、升高和降低等层次，制定了与世界各国人群相适应的血脂分层标准。

:::definition{label="高脂血症"}
高脂血症（hyperlipidemia）指血浆脂质水平异常升高、超过正常范围上限。临床实践中指血浆胆固醇或／和甘油三酯超过正常范围上限。
:::

:::definition{label="脂蛋白异常血症"}
脂蛋白异常血症（dyslipoproteinemia）：高脂血症血浆中，一些脂蛋白脂质升高，另一些可能降低，故有人认为此名称更合理。
:::

:::keypoint{label="本版诊断切点（空腹 12～14 小时）"}
- 成人甘油三酯超过 $2.26\,\mathrm{mmol/L}$（$200\,\mathrm{mg/dl}$）。
- 成人胆固醇超过 $6.21\,\mathrm{mmol/L}$（$240\,\mathrm{mg/dl}$）。
- 儿童胆固醇超过 $4.14\,\mathrm{mmol/L}$（$160\,\mathrm{mg/dl}$）。
:::

:::compare{title="表8-7　脂蛋白异常血症分型"}
| 分型 | 血浆脂蛋白变化 | 血脂变化 |
|------|----------------|----------|
| Ⅰ | 乳糜微粒升高 | 甘油三酯 $\uparrow\uparrow\uparrow$，胆固醇 $\uparrow$ |
| Ⅱa | 低密度脂蛋白升高 | 胆固醇 $\uparrow\uparrow$ |
| Ⅱb | 低密度及极低密度脂蛋白同时升高 | 胆固醇 $\uparrow\uparrow$，甘油三酯 $\uparrow\uparrow$ |
| Ⅲ | 中间密度脂蛋白升高（电泳出现宽 $\beta$ 带） | 胆固醇 $\uparrow\uparrow$，甘油三酯 $\uparrow\uparrow$ |
| Ⅳ | 极低密度脂蛋白升高 | 甘油三酯 $\uparrow\uparrow$ |
| Ⅴ | 极低密度脂蛋白及乳糜微粒同时升高 | 甘油三酯 $\uparrow\uparrow\uparrow$，胆固醇 $\uparrow$ |
:::

:::pitfall{label="六型不是“胆固醇高就是 IIa”"}
先问哪一种颗粒升高：只有 $\mathrm{CM}$ 是Ⅰ；只有 $\mathrm{LDL}$ 是Ⅱa；$\mathrm{LDL}+\mathrm{VLDL}$ 是Ⅱb；宽 $\beta$（$\mathrm{IDL}$）是Ⅲ；只有 $\mathrm{VLDL}$ 是Ⅳ；$\mathrm{VLDL}+\mathrm{CM}$ 是Ⅴ。甘油三酯明显升高时要先想 $\mathrm{CM}$ 或 $\mathrm{VLDL}$，不要只开一张总胆固醇化验单。
:::

:::note{label="分层标准教材点名但不列表"}
$\mathrm{non\text{-}HDL\text{-}C}$ 与 $\mathrm{TG}$、$\mathrm{TC}$、$\mathrm{HDL\text{-}C}$、$\mathrm{LDL\text{-}C}$ 一起，按理想水平、合适水平、边缘升高、升高和降低分层。具体数字本版未列表，不要用其他指南的切点填进来。
:::

脂蛋白异常血症还可分为原发性和继发性两大类。原发性脂蛋白异常血症发病原因不明，已证明有些是遗传性缺陷。继发性脂蛋白异常血症是继发于其他疾病如糖尿病、肾病和甲状腺功能减退等。

:::compare{title="原发性与继发性"}
| 类别 | 教材原句 |
|------|----------|
| 原发性 | 发病原因不明，已证明有些是遗传性缺陷 |
| 继发性 | 继发于其他疾病，如糖尿病、肾病和甲状腺功能减退 |
:::

:::insight{label="甲减可以继发脂蛋白异常，甲亢血清胆固醇反而低"}
第五节：甲状腺素促进胆固醇转变为胆汁酸，甲亢血清胆固醇降低。本节：甲状腺功能减退是继发性脂蛋白异常血症的原因之一。同一腺体，亢进和减退把胆固醇账推向相反方向。
:::

### （二）血浆脂蛋白代谢相关基因遗传性缺陷引起脂蛋白异常血症

现已发现，参与脂蛋白代谢的关键酶如 $\mathrm{LPL}$ 及 $\mathrm{LCAT}$，载脂蛋白如 $\mathrm{A\,I}$、$\mathrm{B}$、$\mathrm{C\,II}$、$\mathrm{C\,III}$ 和 $\mathrm{E}$，以及脂蛋白受体如 $\mathrm{LDL}$ 受体等的遗传性缺陷，都能导致血浆脂蛋白代谢异常，引起脂蛋白异常血症。在这些已经阐明发病分子机制的遗传性缺陷中，Brown MS 及 Goldstein JL 对 $\mathrm{LDL}$ 受体研究取得的成就最为重大，他们不仅阐明了 $\mathrm{LDL}$ 受体的结构和功能，而且证明了 $\mathrm{LDL}$ 受体缺陷是引起家族性高胆固醇血症的重要原因。$\mathrm{LDL}$ 受体缺陷是常染色体显性遗传，纯合子携带者细胞膜 $\mathrm{LDL}$ 受体完全缺乏，杂合子携带者 $\mathrm{LDL}$ 受体数目减少一半，其 $\mathrm{LDL}$ 都不能正常代谢，血浆胆固醇分别高达 $15.6\sim 20.8\,\mathrm{mmol/L}$（$600\sim 800\,\mathrm{mg/dl}$）及 $7.8\sim 10.4\,\mathrm{mmol/L}$（$300\sim 400\,\mathrm{mg/dl}$），携带者在 $20$ 岁前就发生典型的冠心病症状。

:::definition{label="家族性高胆固醇血症（LDL 受体缺陷）"}
$\mathrm{LDL}$ 受体缺陷是引起家族性高胆固醇血症的重要原因，常染色体显性遗传。纯合子细胞膜受体完全缺乏，血浆胆固醇 $15.6\sim 20.8\,\mathrm{mmol/L}$（$600\sim 800\,\mathrm{mg/dl}$）；杂合子受体数目减少一半，血浆胆固醇 $7.8\sim 10.4\,\mathrm{mmol/L}$（$300\sim 400\,\mathrm{mg/dl}$）。携带者在 $20$ 岁前发生典型冠心病症状。
:::

:::keypoint{label="已点名的遗传性缺陷名单"}
- 关键酶：$\mathrm{LPL}$、$\mathrm{LCAT}$。
- 载脂蛋白：$\mathrm{A\,I}$、$\mathrm{B}$、$\mathrm{C\,II}$、$\mathrm{C\,III}$、$\mathrm{E}$。
- 受体：$\mathrm{LDL}$ 受体。
:::

:::example{label="纯合子与杂合子的胆固醇数字不要记反"}
杂合子还有一半受体，胆固醇 $300\sim 400\,\mathrm{mg/dl}$；纯合子完全缺乏，$600\sim 800\,\mathrm{mg/dl}$。两档都远高于诊断切点 $240\,\mathrm{mg/dl}$，都会在 $20$ 岁前出现典型冠心病——受体途径占正常人清除的 $2/3$，这条路断了，$\mathrm{LDL}$ 只能走剩下的单核－吞噬细胞系统。
:::

:::pitfall{label="LPL 或 apo CII 缺陷首先抬高的是甘油三酯，不是先写成家族性高胆固醇血症"}
$\mathrm{LPL}$／$\mathrm{apo\,C\,II}$ 打不开，$\mathrm{CM}$ 和 $\mathrm{VLDL}$ 的 $\mathrm{TG}$ 水解不了，对应Ⅰ型或Ⅴ型思路。家族性高胆固醇血症这一段专写 $\mathrm{LDL}$ 受体。缺陷名单可以很长，分型要回到哪一种颗粒堆积。
:::

## 本章小结

脂质能溶于有机溶剂但不溶于水，分子中含脂肪酰基或能与脂肪酸起酯化反应。脂肪（甘油三酯）是机体重要的能量物质，胆固醇、磷脂及糖脂是生物膜的重要组分，参与细胞识别及信号传递，还是多种生物活性物质的前体。多不饱和脂肪酸衍生物具有重要生理功能。

肝、脂肪组织及小肠是合成甘油三酯的主要场所，肝合成能力最强；基本原料为甘油和脂肪酸，主要分别由糖代谢提供和糖转化形成。小肠黏膜细胞以脂肪酰 $\mathrm{CoA}$ 酯化甘油一酯合成甘油三酯，肝细胞及脂肪细胞以脂肪酰 $\mathrm{CoA}$ 先后酯化甘油-$3$-磷酸及甘油二酯合成甘油三酯。

甘油三酯水解生成甘油和脂肪酸。甘油经活化、脱氢、转化成磷酸二羟丙酮后，循糖代谢途径代谢。脂肪酸活化后进入线粒体，经脱氢、加水、再脱氢及硫解 $4$ 步反应的重复循环完成 $\beta$-氧化，生成乙酰 $\mathrm{CoA}$，并最终彻底氧化，释放大量能量。肝 $\beta$-氧化生成的乙酰 $\mathrm{CoA}$ 还能转化成酮体，经血液运输至肝外组织利用。

人体脂肪酸合成的主要场所是肝，基本原料乙酰 $\mathrm{CoA}$ 需先羧化为丙二酸单酰 $\mathrm{CoA}$。在胞质溶胶脂肪酸合酶体系催化下，由 $\mathrm{NADPH}$ 供氢，通过缩合、还原、脱水、再还原 $4$ 步反应的 $7$ 次循环合成 $16$ 碳软脂酸。更长碳链脂肪酸的合成在肝细胞内质网和线粒体中通过对软脂酸加工、延长完成。脂肪酸脱氢可生成不饱和脂肪酸，但人体不能合成多不饱和脂肪酸，只能从食物摄取。

甘油磷脂合成以磷脂酸为重要中间产物，需 $\mathrm{CTP}$ 参与。甘油磷脂的降解由磷脂酶 $\mathrm{A}$、$\mathrm{B}$、$\mathrm{C}$ 和 $\mathrm{D}$ 催化完成。神经鞘磷脂的合成以软脂酰 $\mathrm{CoA}$、丝氨酸和胆碱为基本原料，先合成鞘氨醇，再与脂肪酰 $\mathrm{CoA}$、$\mathrm{CDP}$-胆碱合成神经鞘磷脂。

胆固醇合成以乙酰 $\mathrm{CoA}$ 为基本原料，先合成 $\mathrm{HMG\text{-}CoA}$，再逐步合成胆固醇。$\mathrm{HMG\text{-}CoA}$ 还原酶是胆固醇合成的关键酶。细胞内胆固醇含量是胆固醇合成的重要调节因素，无论是外源性还是自身合成，只要升高了细胞胆固醇含量，都能抑制胆固醇合成。胆固醇在体内可转化成胆汁酸、类固醇激素和维生素 $\mathrm{D}_{3}$。

脂质以脂蛋白形式在血中运输和代谢。超速离心法将血浆脂蛋白分为乳糜微粒、极低密度脂蛋白、低密度脂蛋白和高密度脂蛋白。$\mathrm{CM}$ 主要转运外源性甘油三酯及胆固醇，$\mathrm{VLDL}$ 主要转运内源性甘油三酯，$\mathrm{LDL}$ 主要转运内源性胆固醇，$\mathrm{HDL}$ 主要逆向转运胆固醇。

:::definition{label="本章小结里的脂质"}
脂质能溶于有机溶剂但不溶于水，分子中含脂肪酰基或能与脂肪酸起酯化反应。甘油三酯是重要能量物质；胆固醇、磷脂及糖脂是生物膜组分，并参与识别、信号传递，还是多种活性物质的前体。
:::

:::definition{label="本章小结里的 HMG-CoA 还原酶"}
胆固醇以乙酰 $\mathrm{CoA}$ 为基本原料，经 $\mathrm{HMG\text{-}CoA}$ 逐步合成。$\mathrm{HMG\text{-}CoA}$ 还原酶是关键酶。细胞内胆固醇升高——不论外源还是自身合成——都抑制胆固醇合成。
:::

:::compare{title="本章小结：四类血浆脂蛋白"}
| 颗粒 | 主要转运 |
|------|----------|
| $\mathrm{CM}$ | 外源性甘油三酯及胆固醇 |
| $\mathrm{VLDL}$ | 内源性甘油三酯 |
| $\mathrm{LDL}$ | 内源性胆固醇 |
| $\mathrm{HDL}$ | 逆向转运胆固醇 |
:::

:::keypoint{label="本章小结按节收口"}
- 甘油三酯：肝合成最强；小肠走甘油一酯途径，肝／脂肪走甘油-$3$-磷酸途径。
- 水解与 $\beta$-氧化：甘油进糖代谢；脂肪酸 $4$ 步循环；肝酮体供肝外。
- 脂肪酸合成：乙酰 $\mathrm{CoA}$ 先羧化；合酶 $7$ 次循环得软脂酸；多不饱和脂肪酸只能食物摄取。
- 磷脂：磷脂酸 $+$ $\mathrm{CTP}$；磷脂酶 $\mathrm{A}/\mathrm{B}/\mathrm{C}/\mathrm{D}$；神经鞘磷脂经鞘氨醇。
- 胆固醇：关键酶 $\mathrm{HMG\text{-}CoA}$ 还原酶；去路胆汁酸、类固醇激素、维生素 $\mathrm{D}_{3}$。
- 脂蛋白：$\mathrm{CM}$ 外源 $\mathrm{TG}$，$\mathrm{VLDL}$ 内源 $\mathrm{TG}$，$\mathrm{LDL}$ 内源胆固醇，$\mathrm{HDL}$ 逆向转运。
:::

## 思考题

1. 血浆甘油三酯异常升高的病人是否需要控制淀粉类食物的摄入？为什么？
2. 血浆胆固醇异常升高的病人应怎样调整自己的膳食结构？理论根据是什么？
3. 治疗血浆胆固醇异常升高有哪些可能的措施？理论根据是什么？
4. 一个肥胖者希望减肥，可以从哪些方面着手？可以采取哪些可能的措施？理论根据是什么？

:::tip{label="四道思考题在正文里的户头"}
- 甘油三酯与淀粉：肝用糖写内源 $\mathrm{TG}$ 并组装 $\mathrm{VLDL}$；高糖膳食还增加 $\mathrm{HMG\text{-}CoA}$ 还原酶活性和乙酰 $\mathrm{CoA}$、$\mathrm{NADPH}$。控淀粉是在砍内源 $\mathrm{VLDL}$ 的原料，不是只砍餐桌上的油。
- 胆固醇膳食：细胞胆固醇升高抑制还原酶；高糖、高饱和脂肪使肝还原酶活性增加。调整结构：少饱和脂肪、少多余糖，并记住胆汁酸是主要去路。
- 治疗措施的理论根据：关 $\mathrm{HMG\text{-}CoA}$ 还原酶（少写）；促肝把胆固醇写成胆汁酸或随胆汁排出（多排）；开 $\mathrm{LDL}$ 受体／减少 $\mathrm{LDL}$ 生成（加快清除）；$\mathrm{RCT}$ 把外周胆固醇送回肝。
- 肥胖：第一节／第二节的脂肪动员与合成平衡；胰岛素促进脂肪组织摄取和贮存；减少摄入、增加动员和氧化、恢复合成与动员的平衡。
:::

- [ ] 电泳：$\mathrm{CM}$ 原点，$\beta$，$\text{前}\beta$，$\alpha$（最快）。
- [ ] 密度：$\mathrm{CM}<\mathrm{VLDL}<\mathrm{LDL}<\mathrm{HDL}$；$S_\mathrm{f}$ 定义在 $26^{\circ}\mathrm{C}$、密度 $1.063$。
