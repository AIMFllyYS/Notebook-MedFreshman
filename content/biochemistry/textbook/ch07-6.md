# 第六节　糖异生

第五节把肝糖原写成空腹补血糖的快储备。肝糖原有限，禁食 $16\sim 24$ 小时即将耗尽，更长时间仍能维持血糖，靠的是非糖物质在肝（饥饿时也在肾）改写成葡萄糖或糖原。本节只写这一笔：四步绕过糖酵解不可逆反应，两个底物循环把酵解和异生反向拨开，生理意义落在补血糖、三碳途径恢复肝糖原、肾排氢保钠，以及肌乳酸经肝完成乳酸循环。

体内糖原的储备有限，禁食 $16\sim 24$ 小时肝糖原即将耗尽。但禁食更长时间，血糖仍能保持在正常范围。此时除了减少周围组织利用葡萄糖以外，机体主要依赖肝将氨基酸、乳酸等转变成葡萄糖，不断补充血糖。这种由非糖化合物（乳酸、甘油、生糖氨基酸等）转变为葡萄糖或糖原的过程，称为糖异生（gluconeogenesis）。糖异生的主要器官是肝，饥饿时向肝外持续供应葡萄糖。肾皮质和小肠上皮细胞虽也可糖异生，但生成的糖多被肾髓质和小肠在局部利用，较少净输出葡萄糖。

:::definition{label="糖异生"}
糖异生（gluconeogenesis）是由非糖化合物（乳酸、甘油、生糖氨基酸等）转变为葡萄糖或糖原的过程。主要器官是肝，饥饿时向肝外持续供应葡萄糖。肾皮质和小肠上皮也可糖异生，但生成的糖多在肾髓质和小肠局部利用，较少净输出。
:::

:::concept{term="先问肝糖原耗尽没有，再问非糖碳架从哪条绕道变成葡萄糖"}
禁食 $16\sim 24$ 小时肝糖原耗尽之后，血糖仍在，靠的不是再挖肌糖原入血（肌没有葡萄糖-6-磷酸酶），而是肝把乳酸、甘油、生糖氨基酸改写成糖。糖酵解三步不可逆，异生用四个关键酶绕过去，不是把酵解酶倒着开。
:::

:::pitfall{label="肾和小肠能异生，不等于饿的时候靠它们对外供糖"}
教材把“主要器官”写成肝。肾皮质、小肠上皮可以做，但禁食 $18\sim 24$ 小时肾皮质大约只占 $10\%$，而且当时生成的糖被肾髓质就地用掉。长期饥饿约 $7$ 天肾才净输出葡萄糖。不要把三处器官写成“平分补血糖”。
:::

## 一、糖异生不完全是糖酵解的逆反应

乳酸和一些生糖氨基酸（见第九章）经由丙酮酸进行糖异生。丙酮酸的糖异生过程，与糖酵解方向互逆。二者共用多步可逆反应，仅糖酵解中 $3$ 个不可逆的限速步骤，其逆反应需要由糖异生特有的关键酶来催化。

:::insight{label="共用可逆段，只改三处不可逆"}
糖酵解十步里，己糖激酶／葡萄糖激酶、磷酸果糖激酶-1、丙酮酸激酶三步不可逆。异生在丙酮酸→磷酸烯醇式丙酮酸用两步（羧化再脱羧）绕过丙酮酸激酶，其余两处各用一个磷酸酶水解。所以关键酶是四个，不是三个。
:::

:::compare{title="糖酵解三步不可逆与糖异生四个关键酶"}
| 糖酵解不可逆步骤 | 异生如何绕过 | 异生关键酶 |
|------------------|--------------|------------|
| 丙酮酸激酶：磷酸烯醇式丙酮酸 → 丙酮酸 | 羧化支路两步 | 丙酮酸羧化酶；磷酸烯醇式丙酮酸羧激酶 |
| 磷酸果糖激酶-1：果糖-6-磷酸 → 果糖-1,6-二磷酸 | $\mathrm{C}1$ 磷酸酯水解 | 果糖二磷酸酶-1 |
| 己糖激酶／葡萄糖激酶：葡萄糖 → 葡萄糖-6-磷酸 | 磷酸酯水解 | 葡萄糖-6-磷酸酶 |
:::

### （一）丙酮酸经丙酮酸羧化支路生成磷酸烯醇式丙酮酸

丙酮酸羧化支路包含丙酮酸的羧化、再脱羧两步序贯反应，先在线粒体内启动，随后将反应产物转运到细胞质。

:::definition{label="丙酮酸羧化支路"}
丙酮酸羧化支路：丙酮酸先羧化成草酰乙酸，再脱羧生成磷酸烯醇式丙酮酸。羧化在线粒体内启动，随后把产物转到细胞质。两步共消耗 $2$ 个 $\mathrm{ATP}$（羧化用 $\mathrm{ATP}$，脱羧用 $\mathrm{GTP}$）。
:::

**1. 线粒体内丙酮酸羧化**　细胞质中的丙酮酸必须进入线粒体，才能羧化生成草酰乙酸。催化此羧化反应的酶是丙酮酸羧化酶（pyruvate carboxylase），仅存在于线粒体内，其辅因子为生物素。$\mathrm{CO}_2$ 先与生物素结合，需消耗 $\mathrm{ATP}$；然后活化的 $\mathrm{CO}_2$ 再转移给丙酮酸，生成草酰乙酸。

:::definition{label="丙酮酸羧化酶"}
丙酮酸羧化酶（pyruvate carboxylase）仅存在于线粒体，辅因子为生物素。$\mathrm{CO}_2$ 先与生物素结合（耗 $\mathrm{ATP}$），再转移给丙酮酸生成草酰乙酸。细胞质丙酮酸必须进线粒体才能走这一步。
:::

$$
\text{丙酮酸}+\mathrm{CO}_2+\mathrm{ATP}\xrightarrow{\text{丙酮酸羧化酶，生物素}}\text{草酰乙酸}+\mathrm{ADP}+\mathrm{P}_\mathrm{i}
$$

:::pitfall{label="丙酮酸羧化酶不在细胞质"}
酶只在线粒体。把羧化画在胞质里，草酰乙酸如何出线粒体、$\mathrm{NADH}$ 要不要跟着走，后面两套转运都会没有起点。
:::

**2. 线粒体或细胞质中草酰乙酸脱羧**　草酰乙酸脱羧生成磷酸烯醇式丙酮酸，反应消耗 $\mathrm{GTP}$，由磷酸烯醇式丙酮酸羧激酶催化。该酶是同工酶，分布于线粒体和细胞质。其线粒体同工酶，可在线粒体内催化生成磷酸烯醇式丙酮酸，再转运入细胞质。而其细胞质同工酶，前提是先将草酰乙酸从线粒体运出，然后在细胞质中催化生成磷酸烯醇式丙酮酸，这就涉及较为复杂的草酰乙酸转运机制。

$$
\text{草酰乙酸}+\mathrm{GTP}\xrightarrow{\text{磷酸烯醇式丙酮酸羧激酶}}\text{磷酸烯醇式丙酮酸}+\mathrm{GDP}+\mathrm{CO}_2
$$

:::definition{label="磷酸烯醇式丙酮酸羧激酶"}
磷酸烯醇式丙酮酸羧激酶催化草酰乙酸脱羧生成磷酸烯醇式丙酮酸，消耗 $\mathrm{GTP}$。同工酶分布在线粒体和细胞质：线粒体同工酶就地生成磷酸烯醇式丙酮酸再运出；细胞质同工酶要求草酰乙酸先出线粒体。
:::

**3. 草酰乙酸经由苹果酸或天冬氨酸运出线粒体**　草酰乙酸不能直接透过线粒体内膜，通过两种方式从线粒体转运到细胞质（图7-15）：①经苹果酸转运：由线粒体内苹果酸脱氢酶催化，草酰乙酸还原成苹果酸后运出线粒体，再经细胞质中苹果酸脱氢酶催化，苹果酸氧化而重新生成草酰乙酸。在此过程中，同时还将线粒体内的 $\mathrm{NADH}$ 运到了细胞质。②经天冬氨酸转运：由线粒体内谷草转氨酶催化，草酰乙酸转变成天冬氨酸后运出线粒体，再经细胞质中谷草转氨酶催化，天冬氨酸再恢复生成草酰乙酸。此过程中，并无 $\mathrm{NADH}$ 的伴随转运。

:::definition{label="草酰乙酸不能直接出线粒体"}
草酰乙酸不能直接透过线粒体内膜。苹果酸途径：还原成苹果酸运出，胞质再氧化回草酰乙酸，顺带把线粒体 $\mathrm{NADH}$ 送到细胞质。天冬氨酸途径：转氨成天冬氨酸运出，再转回草酰乙酸，不伴随 $\mathrm{NADH}$ 转运。
:::

**4. 不同糖异生原料对氢的需求决定草酰乙酸的转运方式**　糖异生在细胞质中的后续反应有一步还原反应，从甘油酸-1,3-二磷酸还原成甘油醛-3-磷酸，需 $\mathrm{NADH}$ 供氢。对于不同糖异生原料，此供氢体的来源不同：①乳酸糖异生时，所需的 $\mathrm{NADH}$ 来源于细胞质，从乳酸生成丙酮酸的脱氢反应提供，已经在细胞质中产生了 $\mathrm{NADH}$ 以供利用。此时草酰乙酸经由天冬氨酸运出线粒体。②丙酮酸或生糖氨基酸进行糖异生时，所需的 $\mathrm{NADH}$ 来源于线粒体，可以从脂肪酸 $\beta$-氧化或三羧酸循环提供。此时草酰乙酸经由苹果酸运出线粒体，以便同时将线粒体内的 $\mathrm{NADH}$ 运到细胞质以供利用。

总之，无论何种原料进入丙酮酸羧化支路，终将在细胞质中产生磷酸烯醇式丙酮酸。上述羧化和脱羧反应共消耗 $2$ 个 $\mathrm{ATP}$。

:::compare{title="苹果酸途径与天冬氨酸途径"}
| 项目 | 经苹果酸运出 | 经天冬氨酸运出 |
|------|--------------|----------------|
| 线粒体反应 | 草酰乙酸 $\xrightarrow{\mathrm{NADH}}$ 苹果酸 | 草酰乙酸 $\xrightarrow{\text{谷草转氨酶}}$ 天冬氨酸 |
| 是否伴随 $\mathrm{NADH}$ 出线粒体 | 是 | 否 |
| 适用原料 | 丙酮酸或生糖氨基酸（胞质还缺 $\mathrm{NADH}$） | 乳酸（乳酸 → 丙酮酸已在胞质生成 $\mathrm{NADH}$） |
| 胞质 $\mathrm{NADH}$ 用途 | 甘油酸-1,3-二磷酸 → 甘油醛-3-磷酸 | 同左，但氢已在胞质备好 |
:::

:::pitfall{label="不是所有糖异生都走苹果酸"}
乳酸脱氢已经在细胞质留下 $\mathrm{NADH}$，再走苹果酸会重复运氢。丙酮酸、生糖氨基酸在胞质没有这一笔氢，必须走苹果酸把线粒体的 $\mathrm{NADH}$ 带出来。原料决定转运，不要背成“草酰乙酸一律经苹果酸”。
:::

:::keypoint{label="羧化支路的 ATP 账"}
- 丙酮酸羧化酶：$1\,\mathrm{ATP}/$丙酮酸。
- 磷酸烯醇式丙酮酸羧激酶：$1\,\mathrm{GTP}/$丙酮酸（按 $1\,\mathrm{ATP}$ 当量计）。
- 合计：$2\,\mathrm{ATP}/$丙酮酸；两分子丙酮酸走到磷酸烯醇式丙酮酸已花 $4\,\mathrm{ATP}$ 当量。
:::

### （二）果糖-1,6-二磷酸水解为果糖-6-磷酸

此反应由果糖二磷酸酶-1 催化（见图7-15）。$\mathrm{C}1$ 位的磷酸酯水解是放能反应，并不生成 $\mathrm{ATP}$，所以反应易于进行。

:::definition{label="果糖二磷酸酶-1"}
果糖二磷酸酶-1 水解果糖-1,6-二磷酸的 $\mathrm{C}1$ 磷酸酯，生成果糖-6-磷酸。不生成 $\mathrm{ATP}$，放能，易于进行。它不是磷酸果糖激酶-1 的逆反应。
:::

### （三）葡萄糖-6-磷酸水解为葡萄糖

此反应由葡萄糖-6-磷酸酶催化（见图7-15），也是磷酸酯水解反应，而不是葡萄糖激酶催化反应的逆反应，热力学上是可行的。

:::definition{label="葡萄糖-6-磷酸酶（糖异生）"}
葡萄糖-6-磷酸酶水解葡萄糖-6-磷酸生成葡萄糖。与第五节肝糖原补血糖是同一酶：没有它，异生停在葡萄糖-6-磷酸，出不成血糖。肌缺此酶，故肌内不能把乳酸异生成葡萄糖。
:::

综上，糖异生的 $4$ 个关键酶是丙酮酸羧化酶、磷酸烯醇式丙酮酸羧激酶、果糖二磷酸酶-1 和葡萄糖-6-磷酸酶，其催化反应逆糖酵解方向，$2$ 分子丙酮酸异生成葡萄糖需消耗 $6$ 分子 $\mathrm{ATP}$。

::figure{src="/images/biochemistry/textbook/p0158_01.png" caption="图7-15　糖异生。左侧糖酵解向下，右侧糖异生向上。胞质：葡萄糖-6-磷酸酶、果糖二磷酸酶-1 绕过两个激酶；甘油经甘油-3-磷酸汇入磷酸二羟丙酮。线粒体内丙酮酸羧化酶生成草酰乙酸，经苹果酸或天冬氨酸出线粒体，磷酸烯醇式丙酮酸羧激酶生成磷酸烯醇式丙酮酸。乳酸、丙氨酸等生糖氨基酸从下方汇入丙酮酸。" alt="糖酵解与糖异生对照图：线粒体丙酮酸羧化及苹果酸、天冬氨酸转运，胞质两个磷酸酶"}

:::keypoint{label="2 分子丙酮酸 → 1 分子葡萄糖消耗 6 ATP"}
- 羧化支路：$2$ 丙酮酸 $\times 2\,\mathrm{ATP}=4\,\mathrm{ATP}$。
- 甘油酸-3-磷酸 → 甘油酸-1,3-二磷酸：$2\,\mathrm{ATP}$。
- 两个磷酸酶水解不生成 $\mathrm{ATP}$，所以没有把酵解那两笔底物水平磷酸化赚回来。
- 合计 $6\,\mathrm{ATP}$。乳酸循环在肝里走的就是这本耗能账。
:::

:::pitfall{label="水解不生成 ATP，不能当成激酶的逆反应"}
果糖二磷酸酶-1、葡萄糖-6-磷酸酶切的是磷酸酯，放出无机磷酸，不偶联 $\mathrm{ADP}$ 磷酸化。把它们画成 $\mathrm{PFK}$-$1$、葡萄糖激酶的逆反应，热力学和 $6\,\mathrm{ATP}$ 的账都会错。
:::

## 二、糖异生和糖酵解的反向调节主要针对两个底物循环

糖异生与糖酵解是方向相反的两条代谢途径，其中 $3$ 个限速步骤分别由不同的酶催化底物互变，称为底物循环（substrate cycle）。要有效推进糖异生，就必须抑制糖酵解；反之亦然。这种协调主要依赖对 $2$ 个底物循环的调节。维持底物循环虽然损失一些 $\mathrm{ATP}$，但却使代谢调节更为灵敏、精细。

:::definition{label="底物循环"}
底物循环（substrate cycle）指糖酵解与糖异生在限速步骤由不同酶催化的底物互变。三处限速都可以成循环，协调主要针对其中 $2$ 个：果糖-6-磷酸 $\rightleftharpoons$ 果糖-1,6-二磷酸，以及磷酸烯醇式丙酮酸 $\rightleftharpoons$ 丙酮酸。空转会损失 $\mathrm{ATP}$，换来调节更灵敏。
:::

:::pitfall{label="三处限速，调节主攻两处"}
己糖激酶／葡萄糖-6-磷酸酶那一处也是底物循环，但教材把“反向调节主要针对两个底物循环”写在果糖磷酸和丙酮酸这两户。不要自行把三处平均用力。
:::

### （一）第一个底物循环调节果糖-6-磷酸与果糖-1,6-二磷酸的互变

糖酵解时，果糖-6-磷酸被磷酸化而生成果糖-1,6-二磷酸，反应耗能；糖异生时，果糖-1,6-二磷酸水解去磷酸而生成果糖-6-磷酸，反应并无产能，由此构成第一个底物循环。催化这两个反应的酶活性常呈相反的变化。

**1. 果糖-2,6-二磷酸和 AMP 反向调节第一个底物循环**　果糖-2,6-二磷酸和 $\mathrm{AMP}$ 既是磷酸果糖激酶-1 的别构激活剂，又是果糖二磷酸酶-1 的别构抑制剂。这一底物循环的调控最重要，通过能量与果糖二磷酸这两个共同的别构剂，同步反向调节互逆反应的两个关键酶，促进糖酵解、抑制糖异生。

:::definition{label="第一个底物循环的共同别构剂"}
果糖-2,6-二磷酸和 $\mathrm{AMP}$：激活磷酸果糖激酶-1，同时抑制果糖二磷酸酶-1。一个信号把酵解开、异生关，避免对开空转。第二节已把果糖-2,6-二磷酸写成 $\mathrm{PFK}$-$1$ 最强别构激活剂，本节补上它对果糖二磷酸酶-1 的抑制。
:::

**2. 果糖-2,6-二磷酸是肝内糖异生与糖酵解的主要调节信号**　果糖-2,6-二磷酸的生成量可受激素调节。胰高血糖素降低果糖-2,6-二磷酸水平，这是因为胰高血糖素通过 $\mathrm{cAMP}$ 和蛋白质激酶 $\mathrm{A}$，引起磷酸果糖激酶-2 磷酸化而失活，进而使果糖-2,6-二磷酸生成减少，所以饥饿时肝糖异生增强而糖酵解减弱。相反，胰岛素升高果糖-2,6-二磷酸水平，所以进食后肝糖酵解增强而糖异生减弱。

:::cause-effect{title="胰高血糖素如何压低果糖-2,6-二磷酸"}
- **因** 胰高血糖素 → $\mathrm{cAMP}$ → 蛋白质激酶 $\mathrm{A}$ → 磷酸果糖激酶-2 磷酸化失活 → 果糖-2,6-二磷酸生成减少
- **果** $\mathrm{PFK}$-$1$ 失去最强激活剂，果糖二磷酸酶-1 解除抑制：饥饿时肝糖异生增强、糖酵解减弱
:::

:::compare{title="果糖-2,6-二磷酸在肝内的激素方向"}
| 激素 | 果糖-2,6-二磷酸 | 糖酵解 | 糖异生 |
|------|-----------------|--------|--------|
| 胰高血糖素（饥饿） | 降低 | 减弱 | 增强 |
| 胰岛素（进食） | 升高 | 增强 | 减弱 |
:::

### （二）第二个底物循环调节磷酸烯醇式丙酮酸与丙酮酸的互变

糖酵解时，磷酸烯醇式丙酮酸转变为丙酮酸并产生能量；糖异生时，丙酮酸消耗能量生成磷酸烯醇式丙酮酸，由此构成第二个底物循环。其中所涉及的 $3$ 个关键酶调节方式有所差异。

**1. 丙酮酸激酶受别构调节和磷酸化修饰调节**　丙酮酸激酶的活性受到别构调节：①果糖-1,6-二磷酸是其别构激活剂，可促进糖酵解。而在饥饿时，胰高血糖素下调果糖-2,6-二磷酸水平，从而使果糖-1,6-二磷酸生成减少，引起丙酮酸激酶活性减弱。②丙氨酸是肝内丙酮酸激酶的别构抑制剂。饥饿时，丙氨酸是主要的糖异生原料，所以丙氨酸抑制糖酵解有利于肝内糖异生。

丙酮酸激酶的活性还可受化学修饰调节。胰高血糖素通过 $\mathrm{cAMP}$，使丙酮酸激酶磷酸化，从而抑制其活性，减弱糖酵解。

:::definition{label="肝丙酮酸激酶的双重调节"}
别构：果糖-1,6-二磷酸激活；丙氨酸抑制（饥饿时丙氨酸是主要糖异生原料）。化学修饰：胰高血糖素经 $\mathrm{cAMP}$ 使丙酮酸激酶磷酸化而抑制。饥饿时既少了果糖-1,6-二磷酸的激活，又被丙氨酸和磷酸化关掉，酵解让路给异生。
:::

**2. 磷酸烯醇式丙酮酸羧激酶受激素诱导的含量调节**　胰高血糖素通过 $\mathrm{cAMP}$，快速诱导磷酸烯醇式丙酮酸羧激酶基因的表达，促进合成酶蛋白，加强糖异生。胰岛素则作用相反，显著减少磷酸烯醇式丙酮酸羧激酶的蛋白合成，使糖异生减弱。

:::definition{label="磷酸烯醇式丙酮酸羧激酶的含量调节"}
这是酶量调节，不是别构秒开关。胰高血糖素经 $\mathrm{cAMP}$ 诱导基因表达，酶蛋白增多；胰岛素显著减少其合成。第八节胰岛素降糖也写到“磷酸烯醇式丙酮酸羧激酶的合成减少”，与此处同一本账。
:::

**3. 丙酮酸羧化酶受乙酰 CoA 的别构激活**　乙酰 $\mathrm{CoA}$ 是丙酮酸羧化酶的别构激活剂，也是丙酮酸脱氢酶复合体的别构抑制剂。这对于饥饿时机体改用脂肪供能、减少利用糖并同时补给血糖具有重要意义。此时大量脂肪酰 $\mathrm{CoA}$ 在线粒体内 $\beta$-氧化（第八章），生成大量乙酰 $\mathrm{CoA}$，一方面激活丙酮酸羧化酶，促进糖异生；另一方面抑制丙酮酸脱氢酶复合体，减少糖的有氧氧化。

:::cause-effect{title="饥饿时乙酰 CoA 同时开异生、关有氧氧化"}
- **因** 脂肪酰 $\mathrm{CoA}$ $\beta$-氧化产生大量乙酰 $\mathrm{CoA}$：激活丙酮酸羧化酶，抑制丙酮酸脱氢酶复合体
- **果** 丙酮酸改走羧化支路补血糖，而不是氧化脱羧进三羧酸循环；机体改用脂肪供能、节约葡萄糖
:::

:::pitfall{label="乙酰 CoA 不能异生成糖"}
乙酰 $\mathrm{CoA}$ 激活丙酮酸羧化酶，本身并不能经三羧酸循环净生成糖（丙酮酸脱氢不可逆）。饥饿时它是开关，不是碳源。碳源是乳酸、甘油、生糖氨基酸。
:::

### （三）两个底物循环的调节相互联系和协调

两个底物循环的调节并非彼此孤立，而是相互联系和协调：①通过细胞内能量状态协同调节。能量充足时，$\mathrm{ATP}$ 抑制两个底物循环中的糖酵解关键酶。而能量匮乏时，$\mathrm{AMP}$ 或 $\mathrm{ADP}$ 则抑制两个底物循环中的糖异生关键酶。②通过激素协同调节。例如，胰高血糖素通过降低果糖-2,6-二磷酸的水平，反向调节第一个底物循环中的互逆反应；同时还作用于第二个底物循环，使丙酮酸激酶磷酸化而失活，从而协同抑制糖酵解、促进糖异生。

:::compare{title="能量状态与激素如何同时拨两个循环"}
| 信号 | 第一个循环（果糖磷酸） | 第二个循环（丙酮酸） |
|------|------------------------|----------------------|
| $\mathrm{ATP}$ 充足 | 抑制糖酵解关键酶 | 抑制糖酵解关键酶 |
| $\mathrm{AMP}/\mathrm{ADP}$ 匮乏 | 抑制糖异生关键酶 | 抑制糖异生关键酶 |
| 胰高血糖素 | 降低果糖-2,6-二磷酸：关 $\mathrm{PFK}$-$1$、开果糖二磷酸酶-1 | 磷酸化丙酮酸激酶使之失活 |
:::

:::insight{label="空转换灵敏"}
两个循环同时开会烧 $\mathrm{ATP}$。教材承认“维持底物循环虽然损失一些 $\mathrm{ATP}$”，换来的是共同别构剂和激素可以把互逆酶同步反向拨，调节比单酶开关更精细。
:::

## 三、糖异生的主要生理意义是维持血糖恒定

机体通过肝的糖异生补充血糖及恢复肝糖原储备，也可通过加强肾的糖异生维持酸碱平衡。

### （一）饥饿或剧烈运动时肝糖异生补给血糖

**1. 糖异生主要在肝糖原耗竭后补给血糖**　饥饿导致肝糖原耗尽后，机体仍需持续消耗一定量的葡萄糖。例如，脑主要依赖葡萄糖供能，其己糖激酶的 $K_\mathrm{m}$ 低于其他组织，即使血糖水平较低时也能利用葡萄糖；红细胞只能通过糖的无氧氧化获得能量；骨髓、视网膜、神经等组织常由糖的无氧氧化提供部分能量。此时这些葡萄糖全部依赖糖异生生成，但糖异生补给的血糖有限，所以其他大多数组织均改用脂肪供能，以节约葡萄糖。

:::keypoint{label="肝糖原耗尽后仍要糖的组织"}
- 脑：主要依赖葡萄糖；己糖激酶 $K_\mathrm{m}$ 低于其他组织，血糖偏低仍能用。
- 红细胞：只能无氧氧化。
- 骨髓、视网膜、神经：常由无氧氧化提供部分能量。
- 这些葡萄糖全部依赖糖异生；大多数其他组织改用脂肪，节约葡萄糖。
:::

**2. 饥饿时糖异生的主要原料是生糖氨基酸和甘油**　饥饿时，肌组织蛋白质分解提供丰富的糖异生原料，产生大量的生糖氨基酸，再以丙氨酸和谷氨酰胺的形式运入肝内糖异生，这是血糖补给的主要来源；同时脂肪组织中脂肪分解增强，释出甘油运入肝内，也可经糖异生补充少量葡萄糖。但需要注意，长期饥饿时，如果持续大量消耗蛋白质用于糖异生，将无法维持生命。经过适应，脑每天消耗的葡萄糖可减少，其余依赖酮体供能；此时甘油仍可经糖异生持续供应少量葡萄糖，这样可使机体对蛋白质的消耗量显著降低。

:::compare{title="饥饿时的异生原料"}
| 原料 | 来路 | 地位 |
|------|------|------|
| 生糖氨基酸（以丙氨酸、谷氨酰胺运入肝） | 肌蛋白质分解 | 血糖补给的主要来源 |
| 甘油 | 脂肪分解 | 补充少量葡萄糖；长期饥饿时仍持续供应，减轻对蛋白质的消耗 |
| 乳酸 | 本节第 $3$ 点：剧烈运动时的主原料 | 饥饿主账不靠它 |
:::

:::pitfall{label="长期饥饿不能靠持续拆蛋白质活下去"}
教材写明：持续大量消耗蛋白质用于糖异生将无法维持生命。适应之后脑少用糖、改用酮体，甘油继续异生少量葡萄糖，蛋白质消耗显著降低。不要把“饥饿＝一直拆肌蛋白补糖”写成长期策略。
:::

**3. 剧烈运动时糖异生的主要原料是乳酸**　剧烈运动时，肌糖原分解生成乳酸。肌内糖异生活性低，乳酸不能在肌内重新合成糖，需经血液转运入肝内才能糖异生，从而完成对乳酸的回收再利用，既输出血糖，又避免酸中毒。

:::insight{label="饥饿看氨基酸和甘油，短跑看乳酸"}
同一条异生通路，原料随场合换。空腹／饥饿：丙氨酸、谷氨酰胺、甘油。剧烈运动：肌糖原来的乳酸。肌自己做不了异生，必须出肝。
:::

### （二）饥饿后进食经肝糖异生补充或恢复肝糖原储备

饥饿后进餐时，肝糖原的合成还存在一条三碳途径，并不完全是利用肝细胞直接摄入的葡萄糖。这是因为，肝内葡萄糖激酶的 $K_\mathrm{m}$ 很高，即：对葡萄糖的亲和力低，虽然在进食初期血糖有所升高，但尚不足以达到葡萄糖激酶催化所需的有效底物浓度。此时进行糖异生，就可经由丙酮酸等生成葡萄糖-6-磷酸，再进入糖原合成途径，从而绕开葡萄糖激酶催化的瓶颈反应。这条依赖于糖异生的糖原合成途径称为三碳途径。

饥饿后进食可通过三碳途径快速恢复肝糖原储备，这既解释了刚进餐时肝摄取葡萄糖的能力低，但仍可合成糖原；又解释了为什么餐后 $2\sim 3$ 小时内，肝仍要保持较高的糖异生活性。支持三碳途径的实验证据有：①向肝灌注液中加入一些可异生成糖的甘油、谷氨酸、丙酮酸和乳酸，可使肝糖原迅速增加。②以放射性核素标记葡萄糖的不同碳原子后输入动物，分析其肝糖原中葡萄糖标记的情况，结果表明相当一部分摄入的葡萄糖先分解成丙酮酸、乳酸等三碳化合物，后者再糖异生进而合成糖原。

:::definition{label="三碳途径"}
三碳途径是依赖于糖异生的肝糖原合成途径：饥饿后进食初期，葡萄糖激酶 $K_\mathrm{m}$ 高、亲和力低，血糖虽升仍达不到其有效底物浓度；丙酮酸等经异生生成葡萄糖-6-磷酸，再进入糖原合成，绕开葡萄糖激酶瓶颈。
:::

:::cause-effect{title="为什么刚进餐肝摄取葡萄糖能力低，却仍能合成糖原"}
- **因** 葡萄糖激酶 $K_\mathrm{m}$ 很高，进食初期血糖还够不上它；异生可把丙酮酸等做成葡萄糖-6-磷酸
- **果** 不经葡萄糖激酶也能合成肝糖原；餐后 $2\sim 3$ 小时肝仍保持较高糖异生活性
:::

:::example{label="两笔实验证据"}
肝灌注液加入甘油、谷氨酸、丙酮酸和乳酸，肝糖原迅速增加——异生碳架能直接变成糖原。放射性核素标记葡萄糖不同碳原子后，肝糖原上的标记表明相当一部分摄入的葡萄糖先裂成丙酮酸、乳酸等三碳化合物，再异生合成糖原。不要把餐后肝糖原一律写成“血糖直接进肝、经葡萄糖激酶活化”。
:::

:::pitfall{label="三碳途径不是第五节的 UDPG 直链延伸"}
第五节的直接途径是六碳糖活化后接到引物。三碳途径的“三碳”指丙酮酸、乳酸等，先异生成葡萄糖-6-磷酸再进糖原。两条都能做肝糖原，开关场合不同。
:::

### （三）长期饥饿时肾糖异生增强有利于维持酸碱平衡

**1. 长期饥饿使肾糖异生显著增强**　长期禁食导致酮体代谢旺盛，此时体液 $\mathrm{pH}$ 降低，使肾小管中磷酸烯醇式丙酮酸羧激酶的合成增多，促进糖异生。当禁食 $18\sim 24$ 小时，肾皮质糖异生的能力较弱，约占 $10\%$，此时生成的糖被肾髓质消耗利用。当长期饥饿约 $7$ 天时，由于肾糖异生能力大为增强，此时肾净输出葡萄糖，有助于维持机体的血糖稳态。

:::timeline{period="肾糖异生随禁食时间增强"}
- **禁食 18～24 小时** 肾皮质糖异生约占 10%，生成的糖被肾髓质就地消耗，较少净输出
- **长期饥饿约 7 天** 酮体代谢旺盛，体液 pH 降低，肾小管磷酸烯醇式丙酮酸羧激酶合成增多，肾净输出葡萄糖
:::

**2. 肾糖异生增强可维持酸碱平衡**　肾中 $\alpha$-酮戊二酸因异生成糖而减少，故可促进谷氨酰胺脱氨、脱氨产物谷氨酸再脱氨。肾小管细胞将脱下的 $\mathrm{NH}_3$ 分泌入管腔，与原尿中 $\mathrm{H}^{+}$ 结合，从而降低原尿的 $\mathrm{H}^{+}$ 浓度，利于排氢保钠，对防止酸中毒有重要作用。

:::cause-effect{title="肾异生如何排氢保钠"}
- **因** $\alpha$-酮戊二酸被异生成糖而减少 → 拉动谷氨酰胺脱氨、谷氨酸再脱氨 → $\mathrm{NH}_3$ 分泌入管腔，与原尿 $\mathrm{H}^{+}$ 结合
- **果** 原尿 $\mathrm{H}^{+}$ 浓度降低，排氢保钠，防止酸中毒
:::

:::insight{label="长期饥饿肾不只是第二供糖器官"}
约 $7$ 天时肾开始净输出葡萄糖，是血糖账。同一过程消耗 $\alpha$-酮戊二酸、促进产氨，是酸碱账。酮症酸中毒背景下，后一笔与补糖同样重要。
:::

## 四、肌收缩产生的乳酸在肝内糖异生形成乳酸循环

肌收缩（尤其是氧供应不足时）通过糖的无氧氧化生成乳酸，乳酸通过细胞膜弥散进入血液后再入肝，在肝内异生为葡萄糖。葡萄糖释入血液后，又可被肌摄取，由此构成了一个循环，称为乳酸循环，又称 $\mathrm{Cori}$ 循环，是耗能的过程（图7-16）。乳酸循环的形成，取决于肝和肌组织中酶的特点：肝内糖异生活跃，又有葡萄糖-6-磷酸酶，可将葡萄糖-6-磷酸水解为葡萄糖；而肌内糖异生活性低，且没有葡萄糖-6-磷酸酶，因此肌内生成的乳酸不能异生为葡萄糖。乳酸循环的生理意义在于，既回收乳酸中的能量，又避免乳酸堆积而引起酸中毒。

:::definition{label="乳酸循环"}
乳酸循环又称 $\mathrm{Cori}$ 循环：肌（尤其缺氧）无氧氧化生成乳酸 → 入血 → 肝异生成葡萄糖 → 释入血液再被肌摄取。这是耗能过程。肌缺葡萄糖-6-磷酸酶且异生活性低，乳酸不能在肌内重新成糖。
:::

::figure{src="/images/biochemistry/textbook/p0161_01.png" caption="图7-16　乳酸循环。右侧肌：葡萄糖经糖酵解得 2 ATP，丙酮酸还原为乳酸（NADH→NAD+）。乳酸经血液到左侧肝：乳酸氧化为丙酮酸（NAD+→NADH），再经糖异生（耗 6 ATP）生成葡萄糖，释入血液供肌摄取。" alt="肝、血液、肌三室：肌产乳酸，肝耗 6 ATP 异生成葡萄糖"}

:::compare{title="肝与肌为什么能做成循环"}
| 项目 | 肌 | 肝 |
|------|----|----|
| 糖异生活性 | 低 | 活跃 |
| 葡萄糖-6-磷酸酶 | 无 | 有，葡萄糖-6-磷酸可水解为葡萄糖 |
| 乳酸去向 | 不能就地成糖，只能出细胞入血 | 异生成葡萄糖再输出 |
| 能量 | 糖酵解净 $2\,\mathrm{ATP}/$葡萄糖 | 异生耗 $6\,\mathrm{ATP}/$葡萄糖，故循环整体耗能 |
:::

:::keypoint{label="乳酸循环两笔意义"}
- 回收乳酸中的能量（碳架回到葡萄糖，肌以后还能用）。
- 避免乳酸堆积引起酸中毒。
- 代价：肝用 $6\,\mathrm{ATP}$ 换肌那 $2\,\mathrm{ATP}$，教材点名“是耗能的过程”。
:::

:::pitfall{label="肌乳酸不能在肌内糖异生"}
空间位阻不是这一笔的原因。原因是酶：肌异生活性低，又没有葡萄糖-6-磷酸酶。肾上腺素分解肌糖原升高的乳酸，要升血糖必须绕这一圈到肝。把 $\mathrm{Cori}$ 循环听成“肌自己把乳酸变回糖原”，和第五节肌糖原账冲突。
:::

:::example{label="百米后乳酸去哪"}
短跑时肌糖原无氧氧化产乳酸。乳酸入血到肝，按本节羧化支路和两个磷酸酶做成葡萄糖，再入血。部分葡萄糖可被肌摄取重新合成糖原或氧化。心肌等组织也可直接有氧氧化乳酸（第三节）。组织差别取决于有没有葡萄糖-6-磷酸酶、异生活性高不高、能不能有氧氧化乳酸。
:::

:::memory{label="本节必背要点"}
- [ ] 非糖（乳酸、甘油、生糖氨基酸）→ 葡萄糖或糖原；主器官是肝
- [ ] 禁食 $16\sim 24$ 小时肝糖原耗尽后靠异生补血糖
- [ ] 四个关键酶：丙酮酸羧化酶（线粒体、生物素）、磷酸烯醇式丙酮酸羧激酶、果糖二磷酸酶-1、葡萄糖-6-磷酸酶
- [ ] $2$ 丙酮酸 → $1$ 葡萄糖耗 $6\,\mathrm{ATP}$
- [ ] 乳酸走天冬氨酸出线粒体；丙酮酸／生糖氨基酸走苹果酸（顺带运 $\mathrm{NADH}$）
- [ ] 两个底物循环：$\mathrm{F}$-$2,6$-$\mathrm{BP}$ 和 $\mathrm{AMP}$ 开酵解、关异生；胰高血糖素降 $\mathrm{F}$-$2,6$-$\mathrm{BP}$、磷酸化丙酮酸激酶
- [ ] 乙酰 $\mathrm{CoA}$ 激活丙酮酸羧化酶、抑制丙酮酸脱氢酶复合体
- [ ] 饥饿原料：丙氨酸、谷氨酰胺、甘油；运动原料：乳酸
- [ ] 三碳途径：绕开葡萄糖激酶，餐后 $2\sim 3$ 小时肝仍保持较高异生活性
- [ ] 禁食 $18\sim 24$ 小时肾约占 $10\%$；约 $7$ 天肾净输出；排氢保钠
- [ ] 乳酸循环（Cori）耗能；肌不能就地异生
:::
