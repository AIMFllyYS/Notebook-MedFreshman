# 第一节　基因表达调控的基本概念与特点

第十七章问的是遗传信息「何时、何地、多少」被表达成有功能的分子。$20$ 世纪 $50$ 年代末，中心法则把传递方向钉在 $\mathrm{DNA}\rightarrow\mathrm{RNA}\rightarrow$蛋白质之后，科学家接着追问调控机制。$1961$ 年 Jacob F. 和 Monod J.L. 提出操纵子学说，开创了基因表达调控研究。本节只立原核、真核共用的基本规律：基因表达是什么、时间与空间特异性、组成性相对诱导／阻遏、顺式元件与反式因子、以及多层次里转录起始才是基本控制点。乳糖操纵子的阻遏／$\mathrm{CAP}$ 和色氨酸衰减是第二节的账；真核染色质与转录因子是第三节。

:::concept{term="先问这个基因产不产生蛋白质、何时何地开、开多大，再问顺式还是反式"}
看见“基因表达调控”，先不要默写 $\mathrm{lac}\,Z$ 和衰减子。户头是：基因表达把遗传信息表现为表型，产物可以是蛋白质，也可以只是 $\mathrm{rRNA}$、$\mathrm{tRNA}$；时间特异性按顺序开闭，空间特异性按组织细胞开闭；管家基因走组成性表达，另一类随环境诱导或阻遏；调控序列在同一条 $\mathrm{DNA}$ 上叫顺式作用元件，调节蛋白质跨分子起作用叫反式作用因子。操纵子结构、Pribnow 盒和 $\mathrm{cAMP}$-$\mathrm{CAP}$ 交给第二节。
:::

教材第 $315$ 页章首「本章数字资源」及章题图源 `p0344_01.png` 为 $0$ 字节，不嵌入 `src`。本节无非空插图；图17-1 启动子共有序列从第二节第 $319$ 页起。
:::

基因表达调控的研究，使人们了解到多细胞生物如何从一个受精卵及所具有的一套遗传基因组，最终形成具有不同形态和功能的多组织、多器官的个体；也使人们初步知晓，为何同一个体中不同的组织细胞拥有基本相同的遗传信息，却可以产生各自专一的蛋白质产物，因而具有完全不同的生物学功能。因此，了解基因表达调控是认识生命体和疾病不可或缺的重要内容。

:::definition{label="为何要研究基因表达调控"}
同一套基因组如何长成多组织个体，以及同一套遗传信息如何在不同细胞里给出不同蛋白质，都靠调控来回答。认识生命和疾病都少不了这一户。
:::

:::insight{label="细胞差别首先是表达模式差别，不是基因组有两套"}
「拥有基本相同的遗传信息，却产生各自专一的蛋白质」是后文基因表达谱、基因表达模式的伏笔。不要把组织差别先答成「胰岛细胞丢掉了胰蛋白酶基因」。
:::

:::pitfall{label="不要把本章写成中心法则的重复"}
第十三至十六章已经把 $\mathrm{DNA}\rightarrow\mathrm{RNA}\rightarrow$蛋白质的传递方向立住。本章问的是开闭、时机、地点和剂量。把调控答成「遗传信息从 $\mathrm{DNA}$ 抄到蛋白质」，操纵子和管家基因都没有户头。
:::

原核生物体系和真核生物体系在基因组结构以及细胞结构上的差异，使得它们的基因表达方式有所不同。原核细胞没有细胞核，遗传信息的转录和翻译发生在同一空间，并以偶联的方式进行。真核细胞具有细胞核，使得转录和翻译不仅具有空间分布的特征，而且还有时间特异性。尽管如此，原核生物体系和真核生物体系的基因表达调控遵循一些共同的基本规律。本节先写这些共同规律。

:::definition{label="原核与真核表达方式不同，调控规律有交集"}
原核：无细胞核，转录和翻译在同一空间偶联。真核：有细胞核，转录与翻译有空间分布，也有时间特异性。共同规律（时间／空间特异性、组成性与诱导阻遏、顺式与反式、多层次而以转录起始为基本控制点）是本节的账；偶联和操纵子细节是第二节，核膜分隔和染色质是第三节。
:::

:::compare{title="原核偶联 vs 真核分隔（本节只立对比）"}
| | 细胞核 | 转录与翻译 | 本节怎么用 |
|--|--------|------------|------------|
| 原核 | 无 | 同一空间，偶联进行 | 为第二节衰减、多顺反子预留 |
| 真核 | 有 | 空间分布 $+$ 时间特异性 | 为第三节染色质、加工、转运预留 |

对比只为说明「方式不同、规律可共用」，不要在本节展开 $\mathrm{lac}$ 或活性染色质。
:::

:::timeline{period="本章开篇两件史实"}
- **20 世纪 50 年代末** 遗传信息从 DNA 传到蛋白质的规律被揭示，即中心法则
- **1961** Jacob F. 和 Monod J.L. 提出操纵子学说，开创基因表达调控研究
- **本节范围** 只立原核、真核共用的基本概念；操纵子机制详见第二节
:::

## 一、基因表达产生有功能的蛋白质和 RNA

基因表达（gene expression）就是基因转录及翻译的过程，也是基因所携带的遗传信息表现为表型的过程。它包括基因转录成互补的 $\mathrm{RNA}$ 序列；对于蛋白质编码基因，$\mathrm{mRNA}$ 继而翻译成多肽链，并装配加工成最终的蛋白质产物。在一定调节机制控制下，基因表达通常经历转录和翻译过程，产生具有特异生物学功能的蛋白质分子，赋予细胞或个体一定的功能或形态表型。但并非所有基因表达过程都产生蛋白质。$\mathrm{rRNA}$、$\mathrm{tRNA}$ 编码基因转录产生 $\mathrm{RNA}$ 的过程也属于基因表达。

:::definition{label="基因表达"}
基因表达（gene expression）：基因转录及翻译的过程，也是基因所携带的遗传信息表现为表型的过程。包括转录成互补 $\mathrm{RNA}$；蛋白质编码基因的 $\mathrm{mRNA}$ 再翻译成多肽链，并装配加工成最终蛋白质产物。
:::

:::definition{label="通常产物是有功能的蛋白质"}
在调节机制控制下，基因表达通常经历转录和翻译，产生具有特异生物学功能的蛋白质分子，赋予细胞或个体一定的功能或形态表型。
:::

:::definition{label="并非所有基因表达都产生蛋白质"}
$\mathrm{rRNA}$、$\mathrm{tRNA}$ 编码基因转录产生 $\mathrm{RNA}$ 的过程也属于基因表达。把「表达」等同于「合成蛋白质」，核糖体 $\mathrm{RNA}$ 和转运 $\mathrm{RNA}$ 的基因就从调控名单里消失。
:::

:::pitfall{label="不要把装配加工从「蛋白质编码基因的表达」里删掉"}
教材写的是 $\mathrm{mRNA}$ 翻译成多肽链，并装配加工成最终的蛋白质产物。核糖体上走完的是多肽链；有功能的蛋白质还要加工。第十六章第三节是加工的账，本节只要求承认「表达」包含这一段。
:::

:::insight{label="表型落在有功能的分子上，不落在「有过转录」上"}
「表现为表型」要求产物能干活。只检测到一条无功能的转录物，还不能说该基因已经按生理需要表达。
:::

不同生物的基因组含有不同数量的基因。细菌的基因组一般约含 $4\,000$ 个基因；多细胞生物的基因达数万个，人类基因组含约 $2$ 万个蛋白质编码基因（见第十三章）。在某一特定时期或生长阶段，基因组中只有小部分基因处于表达状态。例如，大肠埃希菌通常只有约 $5\%$ 的基因处于高水平转录活性状态，其余大多数基因不表达或表达水平极低，即生成很少的 $\mathrm{RNA}$ 或蛋白质。

:::definition{label="基因组基因数（本版）"}
细菌基因组一般约含 $4\,000$ 个基因；多细胞生物达数万个；人类基因组含约 $2$ 万个蛋白质编码基因。数字以本版第十三章为准，不要改成别的汇编本的估计。
:::

:::definition{label="同一时刻只有小部分基因表达"}
某一特定时期或生长阶段，基因组中只有小部分基因处于表达状态。大肠埃希菌通常只有约 $5\%$ 的基因处于高水平转录活性状态，其余大多数不表达或表达水平极低。
:::

:::keypoint{label="5% 是高水平转录，不是「只有 5% 基因存在」"}
$5\%$ 描述的是某一时刻的转录活性状态。其余基因仍在基因组里，只是关闭或极低表达。把 $5\%$ 听成「大肠埃希菌只有两百个基因」，$4\,000$ 那个约数就对不上。
:::

:::pitfall{label="人类约 2 万是蛋白质编码基因，不是全部转录物"}
教材写明「约 $2$ 万个蛋白质编码基因」。$\mathrm{rRNA}$、$\mathrm{tRNA}$ 以及后文非编码 $\mathrm{RNA}$ 不在这个约数里。用「人类两万个基因所以不会有 $\mathrm{miRNA}$」去顶第五节的层次，本节的定义会先裂开。
:::

基因表达水平的高低不是固定不变的。例如，平时与细菌蛋白质生物合成有关的延长因子编码基因表达十分活跃，而参与 $\mathrm{DNA}$ 损伤修复有关的酶分子编码基因却极少表达；当有紫外线照射引起 $\mathrm{DNA}$ 损伤时，这些修复酶编码基因的表达就变得异常活跃。可见，生物体中具有某种功能的基因产物在细胞中的数量会随时间、环境而变化。

:::definition{label="表达水平随时间、环境而变"}
基因产物在细胞中的数量不是常数。平时延长因子编码基因表达活跃，修复酶编码基因极少表达；紫外线造成 $\mathrm{DNA}$ 损伤时，修复酶基因变得异常活跃。
:::

:::compare{title="同一细菌里两种「平时」与「损伤时」"}
| | 平时 | 紫外线引起 DNA 损伤时 |
|--|------|------------------------|
| 延长因子编码基因 | 十分活跃 | 教材未把关闭写进此例 |
| 修复酶编码基因 | 极少表达 | 异常活跃 |

例子用来说明「高低不是固定不变」，不是给延长因子和修复酶各写一张完整的诱导表。修复酶被激活也是后文「可诱导基因」的预告。
:::

:::insight{label="不表达或极低表达仍是调控的结果"}
大多数基因生成很少的 $\mathrm{RNA}$ 或蛋白质，本身就是调控。把「不表达」理解成「基因组里没有这个基因」，诱导、阻遏和时间特异性都没有对象。
:::

## 二、基因表达具有时间特异性和空间特异性

所有生物的基因表达都具有严格的规律性，即表现为时间特异性和空间特异性。生物物种愈高级，基因表达规律愈复杂、愈精细，这是生物进化的需要。基因表达的时间、空间特异性由特异基因的启动子和／或调节元件的状态，以及调节序列与调节因子（蛋白质或 $\mathrm{RNA}$ 等）相互作用决定。

:::definition{label="时间特异性与空间特异性是普遍规律"}
所有生物的基因表达都表现为时间特异性和空间特异性。物种愈高级，规律愈复杂、愈精细，这是进化的需要。
:::

:::definition{label="时间、空间特异性由谁决定"}
由特异基因的启动子和／或调节元件的状态，以及调节序列与调节因子（蛋白质或 $\mathrm{RNA}$ 等）相互作用决定。后文顺式作用元件、反式作用因子、调节 $\mathrm{RNA}$ 都落在这句上。
:::

:::pitfall{label="不要把特异性写成「高级生物才有、细菌没有」"}
教材第一句是「所有生物」。细菌感染阶段的基因开闭、霍乱弧菌的上调与抑制，都是时间特异性的例子。把时间特异性专属于胚胎发育，原核感染模型会丢。
:::

:::keypoint{label="启动子状态 + 调节因子，两者都要"}
只答「有没有这个基因」不够；只答「有没有转录因子」也不够。元件状态和因子相互作用合在一起，才给出何时、何地表达。
:::

### （一）时间特异性是指基因表达按一定的时间顺序发生

按功能需要，某一特定基因的表达严格按一定的时间顺序发生，这就是基因表达的时间特异性（temporal specificity）。如噬菌体、病毒或细菌侵入宿主后，呈现一定的感染阶段。随感染阶段发展、生长环境变化，这些病原体以及宿主的基因表达都有可能发生改变。有些基因开启，有些基因关闭。例如，霍乱弧菌在感染宿主后，$44$ 种基因的表达上调，$193$ 种基因的表达受到抑制，而相伴随的是这些细菌呈现出高传染状态。

:::definition{label="时间特异性"}
时间特异性（temporal specificity）：按功能需要，某一特定基因的表达严格按一定的时间顺序发生。
:::

:::definition{label="感染阶段也是时间特异性"}
噬菌体、病毒或细菌侵入宿主后呈现一定的感染阶段。随感染阶段发展和生长环境变化，病原体以及宿主的基因都可能开或关。
:::

:::definition{label="霍乱弧菌感染后的表达账"}
感染宿主后：$44$ 种基因上调，$193$ 种基因受抑制，细菌呈现高传染状态。数字成对记，不要记成「大约两百个基因变化」。
:::

:::pitfall{label="44 和 193 不要对调"}
上调 $44$，抑制 $193$。对调以后「高传染状态伴随多数基因被压下来」这层意思就反了。
:::

编码甲胎蛋白（alpha fetal protein，$\mathrm{AFP}$）的基因在胎儿肝细胞中活跃表达，因此合成大量的甲胎蛋白；在成年后这一基因的表达水平很低，故几乎检测不到 $\mathrm{AFP}$。但是，当肝细胞发生转化形成肝癌细胞时，编码 $\mathrm{AFP}$ 的基因又重新被激活，大量的 $\mathrm{AFP}$ 被合成。因此，血浆中 $\mathrm{AFP}$ 的水平可以作为肝癌早期诊断的一个重要指标。

:::definition{label="甲胎蛋白基因的时间特异性"}
$\mathrm{AFP}$ 基因：胎儿肝细胞中活跃表达；成年后水平很低，几乎检测不到；肝细胞转化成肝癌细胞时重新被激活，大量合成 $\mathrm{AFP}$。血浆 $\mathrm{AFP}$ 水平可作为肝癌早期诊断的重要指标。
:::

:::timeline{period="AFP 基因三阶段"}
- **胎儿肝细胞** 活跃表达，合成大量甲胎蛋白
- **成年** 表达水平很低，几乎检测不到 AFP
- **肝癌细胞** 基因重新被激活，血浆 AFP 可作为早期诊断指标
:::

:::insight{label="成年后关掉，不等于基因从基因组消失"}
肝癌时「重新被激活」，说明基因一直在。时间特异性是开闭顺序，不是基因得而复失。
:::

:::pitfall{label="AFP 不要写成空间特异性的代表"}
教材把 $\mathrm{AFP}$ 放在时间特异性：胎儿 $\rightarrow$ 成年 $\rightarrow$ 肝癌。空间特异性的例子是胰岛素和胰蛋白酶。用 $\mathrm{AFP}$ 去答「只在肝脏表达」，时间顺序那一条就空了。
:::

多细胞生物从受精卵发育成为一个成熟个体，经历很多不同的发育阶段。在每个不同的发育阶段，都会有不同的基因严格按照自己特定的时间顺序开启或关闭，表现为与分化、发育阶段一致的时间性。因此，多细胞生物基因表达的时间特异性又称阶段特异性（stage specificity）。

:::definition{label="阶段特异性"}
阶段特异性（stage specificity）：多细胞生物基因表达的时间特异性的另一名称。它强调与分化、发育阶段一致的开闭顺序，从受精卵到成熟个体，每一阶段都有自己该开、该关的基因。
:::

:::compare{title="时间特异性的两个落点"}
| | 感染／环境时间轴 | 发育时间轴 |
|--|-------------------|------------|
| 例子 | 噬菌体、病毒、细菌感染阶段；霍乱弧菌 $44$ 上调／$193$ 抑制；$\mathrm{AFP}$ 的胎儿—成年—肝癌 | 受精卵到成熟个体各发育阶段的基因开闭 |
| 别名 | 仍称时间特异性 | 又称阶段特异性 |
| 共同点 | 都是按一定时间顺序发生 | 都由启动子／调节元件状态及调节因子决定 |

「阶段特异性」不要推广成细菌感染的正式别名。
:::

### （二）空间特异性是指同一基因在不同的组织器官表达不同

在多细胞生物个体某一发育、生长阶段，同一基因产物在不同的组织器官表达水平也可能不同。在个体生长、发育过程中，一种基因产物在个体的不同组织或器官表达，即在个体的不同空间出现，这就是基因表达的空间特异性（spatial specificity）。如编码胰岛素的基因只在胰岛的 $\beta$ 细胞中表达，从而指导生成胰岛素；编码胰蛋白酶的基因在胰岛细胞中几乎不表达，而在胰腺腺泡细胞中有高水平的表达。

:::definition{label="空间特异性"}
空间特异性（spatial specificity）：一种基因产物在个体的不同组织或器官表达，即在个体的不同空间出现。同一发育、生长阶段，同一基因产物在不同组织器官的表达水平也可以不同。
:::

:::definition{label="胰岛素基因与胰蛋白酶基因"}
胰岛素基因只在胰岛 $\beta$ 细胞中表达。胰蛋白酶基因在胰岛细胞中几乎不表达，在胰腺腺泡细胞中高水平表达。两个基因都在胰腺相关组织里讨论，空间差在细胞类型。
:::

:::pitfall{label="不要写成「胰岛素基因只在胰腺、胰蛋白酶基因只在肠道」"}
教材的对比落在胰岛 $\beta$ 细胞 vs 胰腺腺泡细胞。把胰蛋白酶挪到消化道别的器官，细胞特异性的定义就对不上「由细胞在器官的分布所决定」。
:::

基因表达伴随时间或阶段顺序所表现出的这种空间分布差异，实际上是由细胞在器官的分布所决定的，因此基因表达的空间特异性又称细胞特异性（cell specificity）或组织特异性（tissue specificity）。

:::definition{label="细胞特异性、组织特异性"}
空间特异性又称细胞特异性（cell specificity）或组织特异性（tissue specificity）。空间差的本质是细胞在器官中的分布，不是抽象的「上下游解剖位置」。
:::

:::keypoint{label="三个英文名对同一类现象"}
空间特异性 $=$ 细胞特异性 $=$ 组织特异性。时间特异性另有阶段特异性这一别名。两组别名不要交叉背。
:::

同一个体内不同器官、组织、细胞的差异性的基础是特异的基因表达，或称为差异基因表达（differential gene expression）。细胞的基因表达谱（gene expression profile），即基因表达的种类和强度，决定了细胞的分化状态和功能。换言之，在个体内决定细胞类型的不是基因本身，而是基因表达模式（gene expression pattern）。

:::definition{label="差异基因表达"}
差异基因表达（differential gene expression）：同一个体内不同器官、组织、细胞差异性的基础，即特异的基因表达。
:::

:::definition{label="基因表达谱"}
基因表达谱（gene expression profile）：基因表达的种类和强度。它决定细胞的分化状态和功能。
:::

:::definition{label="基因表达模式决定细胞类型"}
在个体内决定细胞类型的不是基因本身，而是基因表达模式（gene expression pattern）。基因组可以基本相同，模式不同则细胞不同。
:::

:::insight{label="谱是种类加强度，不是只开一张有无清单"}
「种类和强度」两个维度都要。只说「表达了胰岛素基因」，不定量，和「胰岛 $\beta$ 细胞高水平、其他细胞几乎不表达」对不上。
:::

:::pitfall{label="不要答「胰岛细胞的基因组没有胰蛋白酶基因」"}
决定细胞类型的不是基因本身。胰蛋白酶基因可以在胰岛细胞的基因组里，只是几乎不表达。把空间特异性理解成基因缺失，差异基因表达和表达谱都没有对象。
:::

:::compare{title="时间特异性 vs 空间特异性"}
| | 时间特异性 | 空间特异性 |
|--|------------|------------|
| 问什么 | 何时开、何时关 | 在哪一类细胞开 |
| 别名 | 多细胞又称阶段特异性 | 又称细胞特异性、组织特异性 |
| 本版例子 | 感染阶段；霍乱 $44/193$；$\mathrm{AFP}$；发育阶段开闭 | 胰岛素只在胰岛 $\beta$ 细胞；胰蛋白酶在腺泡细胞 |
| 分子基础 | 启动子／调节元件状态 $+$ 调节因子 | 同左；落到细胞在器官中的分布 |

考试若只给「胰岛素基因」，先答空间／细胞／组织特异性，不要改答阶段特异性。
:::

## 三、基因表达的方式存在多样性

不同种类的生物遗传背景不同，同种生物不同个体生活环境不完全相同，不同的基因功能和性质也不相同。因此，不同的基因对生物体内、外环境信号刺激的反应性不同。有些基因在生命全过程中持续表达，有些基因的表达则受环境影响。基因表达调控（regulation of gene expression）就是指细胞或生物体在接受内、外环境信号刺激时或适应环境变化的过程中，在基因表达水平上作出应答的分子机制，即位于基因组内的基因如何被表达成为有功能的蛋白质（或 $\mathrm{RNA}$），在什么组织表达，什么时候表达，表达多少等。按照对刺激的反应性，基因表达的方式或调节类型存在很大差异。

:::definition{label="基因表达调控"}
基因表达调控（regulation of gene expression）：细胞或生物体在接受内、外环境信号刺激时或适应环境变化的过程中，在基因表达水平上作出应答的分子机制。它回答基因如何被表达成为有功能的蛋白质（或 $\mathrm{RNA}$），在什么组织表达，什么时候表达，表达多少。
:::

:::definition{label="反应性不同所以方式多样"}
物种遗传背景、个体生活环境、基因本身的功能和性质都不相同，故不同基因对内、外环境信号的反应性不同。有的全过程持续表达，有的受环境影响。
:::

:::keypoint{label="调控四个问题"}
如何成为有功能产物、在什么组织、什么时候、表达多少。前两个对应空间，第三个对应时间，第四个对应诱导／阻遏和协同调节的剂量。
:::

:::pitfall{label="调控不是「有基因就会有产物」"}
基因组内的基因还要被问「表达不表达、表达多少」。把调控理解成基因有无，组成性、诱导、阻遏三种方式就并成一句空话。
:::

### （一）有些基因几乎在所有细胞中持续表达

有些基因产物对生命全过程都是必需的或必不可少的。这类基因在一个生物个体的几乎所有细胞中持续表达，不易受环境条件的影响，或称基本表达。这些基因通常被称为管家基因（house-keeping gene）。例如，柠檬酸循环是一中枢性代谢途径，催化该途径各阶段反应的酶的编码基因就属这类基因。管家基因的表达水平受环境因素影响较小，而是在生物体各个生长阶段的大多数或几乎全部组织中持续表达，或变化很小。我们将这类基因表达称为基本（或组成性）基因表达（constitutive gene expression）。基本基因表达只受启动子和 $\mathrm{RNA}$ 聚合酶等因素的影响，而基本不受其他机制调节。但实际上，基本基因表达水平并非绝对「一成不变」，所谓「不变」是相对的。

:::definition{label="管家基因"}
管家基因（house-keeping gene）：产物对生命全过程必需或必不可少，在一个生物个体的几乎所有细胞中持续表达，不易受环境条件影响，或称基本表达。本版例子：柠檬酸循环各阶段反应酶的编码基因。
:::

:::definition{label="基本（组成性）基因表达"}
基本（或组成性）基因表达（constitutive gene expression）：管家基因在各个生长阶段的大多数或几乎全部组织中持续表达，或变化很小。表达水平受环境因素影响较小。
:::

:::definition{label="组成性表达主要受谁影响"}
基本基因表达只受启动子和 $\mathrm{RNA}$ 聚合酶等因素的影响，而基本不受其他机制调节。第二节里操纵元件、阻遏蛋白、激活蛋白是「其他机制」的典型，不要安到柠檬酸循环酶基因头上。
:::

:::insight{label="「不变」是相对的"}
教材写明：基本基因表达水平并非绝对「一成不变」。组成性不是剂量计上的一条水平直线，只是相对诱导／阻遏而言变化很小。
:::

:::pitfall{label="管家基因不是「永远不被调节」"}
「基本不受其他机制调节」不等于「绝对不受调节」。把组成性写成零调节，后文「不变是相对的」没有着落，真核管家基因可以没有 $\mathrm{TATA}$ 盒（第十五章）也会被误读成「没有启动子」。
:::

:::pitfall{label="柠檬酸循环酶基因不要拿去当诱导酶的例子"}
中枢代谢途径的酶编码基因在本节是管家基因。$\mathrm{DNA}$ 损伤时的修复酶、培养基有色氨酸时的色氨酸合成酶，才是诱导／阻遏。户头弄反，组成性 vs 诱导这一对就塌了。
:::

:::compare{title="组成性表达 vs 「完全不调节」"}
| | 组成性（基本）表达 | 教材明确否定的读法 |
|--|--------------------|----------------------|
| 环境 | 不易受影响，变化很小 | 绝对一成不变 |
| 机制 | 主要受启动子和 $\mathrm{RNA}$ 聚合酶影响 | 不受任何因素影响 |
| 分布 | 几乎所有细胞、各生长阶段 | 可随便关掉 |

考试若出现「管家基因绝对恒定」，按本节应判相对恒定。
:::

### （二）有些基因的表达受到环境变化的诱导和阻遏

与管家基因不同，另有一些基因表达很容易受环境变化的影响。随外环境信号变化，这类基因的表达水平可以出现升高或降低的现象。

在特定环境信号刺激下，相应的基因被激活，基因表达产物增加，即这种基因表达是可诱导的。可诱导基因（inducible gene）在一定的环境中表达增强的过程称为诱导（induction）。例如，在有 $\mathrm{DNA}$ 损伤时，修复酶基因就会在细菌体内被激活，导致修复酶反应性地增加。

相反，如果基因对环境信号应答时被抑制，这种基因称为可阻遏基因（repressible gene）。可阻遏基因表达产物水平降低的过程称为阻遏（repression）。例如，当培养基中色氨酸供应充分时，细菌体内与色氨酸合成有关的酶编码基因表达就会被抑制。这类基因的调控序列通常含有针对特异刺激的反应元件。

诱导和阻遏是同一事物的两种表现形式，在生物界普遍存在，也是生物体适应环境的基本途径。乳糖操纵子机制是认识诱导和阻遏表达的经典模型（详见本章第二节）。

:::definition{label="可诱导基因与诱导"}
可诱导基因（inducible gene）在特定环境信号刺激下被激活，产物增加。表达增强的过程称为诱导（induction）。本版例子：$\mathrm{DNA}$ 损伤时细菌修复酶基因被激活，修复酶反应性增加。
:::

:::definition{label="可阻遏基因与阻遏"}
可阻遏基因（repressible gene）对环境信号应答时被抑制。产物水平降低的过程称为阻遏（repression）。本版例子：培养基色氨酸供应充分时，色氨酸合成有关酶的编码基因被抑制。
:::

:::definition{label="反应元件"}
这类（可诱导／可阻遏）基因的调控序列通常含有针对特异刺激的反应元件。元件本身是顺式序列，要等第四节的名称来命名；本节先承认「有一段对着刺激的 $\mathrm{DNA}$」。
:::

:::definition{label="诱导和阻遏是同一事物的两种形式"}
诱导使产物升高，阻遏使产物降低，都是对环境信号的应答，是生物体适应环境的基本途径。不要把二者写成互不相干的两套遗传学。
:::

:::insight{label="乳糖操纵子是经典模型，细节在第二节"}
本节只点名：乳糖操纵子机制用来认识诱导和阻遏。$\mathrm{Z}$、$\mathrm{Y}$、$\mathrm{A}$、别乳糖、$\mathrm{IPTG}$、$\mathrm{CAP}$ 都还没有进本节的账。
:::

:::pitfall{label="诱导不是「从无到有创造出一个新基因」"}
被激活的是已经存在的基因，产物增加。修复酶基因平时极少表达（第一节第一段的例子），损伤时活跃，正是诱导。不要答成基因组扩增才叫诱导——扩增是第五节遗传信息水平的另一层次。
:::

:::pitfall{label="阻遏不是基因缺失"}
色氨酸充足时合成酶基因表达被抑制，基因还在。第二节里色氨酸作为辅阻遏物结合阻遏蛋白、关掉操纵序列，才是机制；本节先把「产物水平降低」立住。
:::

:::compare{title="组成性 vs 诱导 vs 阻遏"}
| | 组成性（管家基因） | 诱导 | 阻遏 |
|--|-------------------|------|------|
| 环境 | 不易受影响 | 特定信号使表达增强 | 特定信号使表达降低 |
| 产物 | 持续、变化很小 | 增加（如修复酶） | 减少（如色氨酸合成酶） |
| 本版例子 | 柠檬酸循环酶基因 | $\mathrm{DNA}$ 损伤 $\rightarrow$ 修复酶基因 | 色氨酸充足 $\rightarrow$ 合成酶基因关闭 |
| 经典模型 | — | 乳糖操纵子（第二节） | 乳糖操纵子亦可演示阻遏状态；色氨酸操纵子是可阻遏操纵子（第二节） |

「乳糖操纵子认识诱导和阻遏」指同一模型的两种状态，不要理解成乳糖操纵子不能阻遏。
:::

:::cause-effect{title="为什么修复酶基因平时极少表达、损伤时活跃"}
- **因** 平时细胞不需要大量修复酶；紫外线等造成 $\mathrm{DNA}$ 损伤后，修复成为功能需要
- **果** 修复酶基因被诱导，产物反应性增加；这是时间特异性与诱导方式叠在同一基因上
:::

### （三）生物体内不同基因的表达受到协同调节

在生物体内，一个代谢途径通常是由一系列化学反应组成，需要多种酶参与；此外，还需要很多其他蛋白质参与作用物在细胞内、外区间的转运。这些酶及转运蛋白等的编码基因被统一调节，使参与同一代谢途径的所有蛋白质（包括酶）分子比例适当，以确保代谢途径有条不紊地进行。在一定机制控制下，功能上相关的一组基因，无论其为何种表达方式，均需协调一致、共同表达，即为协同表达（coordinate expression）。这种调节称为协同调节（coordinate regulation）。基因的协调表达体现在生物体的生长发育全过程。

:::definition{label="协同表达与协同调节"}
协同表达（coordinate expression）：功能上相关的一组基因，无论其为何种表达方式，均需协调一致、共同表达。这种调节称为协同调节（coordinate regulation）。
:::

:::definition{label="协同的生理学目的"}
同一代谢途径的酶以及转运蛋白等被统一调节，使分子比例适当，代谢途径才能有条不紊。协调表达贯穿生长发育全过程。
:::

:::insight{label="「无论何种表达方式」把组成性、诱导、阻遏都收进来"}
协同调节不是第四种与前三种并列的「开关类型」，而是一组相关基因要一起开、一起关、剂量匹配。第二节乳糖操纵子三个结构基因共用调控区，就是协同表达的原核实现。
:::

:::pitfall{label="协同不是「所有基因同一水平」"}
教材要的是比例适当、协调一致，不是三个酶分子数绝对相等。后文多顺反子 $\mathrm{mRNA}$ 可以一条链编码几种蛋白质，翻译水平仍可再调（第二节第四段），不要在本节把协同写成「一条 $\mathrm{mRNA}$ 必须给出等摩尔蛋白质」。
:::

生物体通过协调调节不同基因的表达以适应环境、维持生长和增殖。生物体所处的内、外环境是在不断变化的。所有生物的所有活细胞都必须对内、外环境的变化作出适当反应，以使生物体能更好地适应变化着的环境状态。生物体这种适应环境的能力总是与某种或某些蛋白质分子的功能有关。细胞内某种功能蛋白质分子的有或无、多或少的变化，则由编码这些蛋白质分子的基因表达与否、表达水平高低等状况决定。通过一定的程序调控基因的表达，可使生物体表达出合适的蛋白质分子，以便更好地适应环境，维持其生长。

:::definition{label="调控的适应意义"}
协调调节不同基因表达 $\rightarrow$ 合适的蛋白质有或无、多或少 $\rightarrow$ 适应环境、维持生长和增殖。所有活细胞都要对内、外环境变化作出适当反应。
:::

:::cause-effect{title="蛋白质有无多少由什么决定"}
- **因** 适应环境的能力总与某种或某些蛋白质的功能有关
- **果** 这些蛋白质的有无、多少由相应基因表达与否、水平高低决定；调控程序给出「合适的蛋白质分子」
:::

原核生物、单细胞生物调节基因的表达就是为适应环境、维持生长和细胞分裂。例如，当葡萄糖供应充足时，细菌中与葡萄糖代谢有关的酶编码基因表达增强，其他糖类代谢有关的酶基因关闭；当葡萄糖耗尽而有乳糖存在时，与乳糖代谢有关的酶编码基因则表达，此时细菌可利用乳糖作为碳源，维持生长和增殖。高等生物也普遍存在适应性表达方式。经常饮酒者体内醇氧化酶活性较高即与相应基因表达水平升高有关。

:::definition{label="原核调控的直接目的"}
原核生物、单细胞生物调节基因表达就是为适应环境、维持生长和细胞分裂。
:::

:::definition{label="葡萄糖优先、乳糖在后（本节定性）"}
葡萄糖充足：葡萄糖代谢酶基因表达增强，其他糖类代谢酶基因关闭。葡萄糖耗尽而有乳糖：乳糖代谢酶基因表达，细菌用乳糖作碳源。定量的 $\mathrm{cAMP}$、$\mathrm{CAP}$、$50$ 倍和分解代谢阻遏是第二节的账。
:::

:::definition{label="高等生物也有适应性表达"}
经常饮酒者体内醇氧化酶活性较高，与相应基因表达水平升高有关。不要把适应性表达写成原核专利。
:::

:::pitfall{label="本节不要提前写 CAP 同二聚体"}
这里只给出碳源选择的生理结果。$\mathrm{CAP}$、$\mathrm{cAMP}$、野生型 $\mathrm{lac}$ 启动子很弱，全部在第二节「协同调节」段才出现。提前搬机制，本节「方式多样性」会被写成操纵子各论。
:::

在多细胞生物，基因表达调控的意义还在于维持细胞分化与个体发育。在多细胞个体生长、发育的不同阶段，细胞中的蛋白质分子种类和含量变化很大；即使在同一生长发育阶段，不同组织器官内蛋白质分子分布也存在很大差异，这些差异是调节细胞表型的关键。例如，果蝇幼虫（蛹）最早期只有一组「母本效应基因（maternal effect gene）」表达，使受精卵发生头尾轴和背腹轴固定，以后有三组「分节基因」顺序表达，控制蛹的「分节」发育过程，最后这些「节」分别发育为成虫的头、胸、翅膀、肢体、腹及尾等。高等哺乳类动物的细胞分化，各种组织、器官的发育都是由一些特定基因控制的。当某种基因缺陷或表达异常时，则会出现相应组织或器官的发育异常。

:::definition{label="多细胞调控还管分化与发育"}
除适应环境外，多细胞生物的基因表达调控还维持细胞分化与个体发育。不同发育阶段蛋白质种类和含量变化很大；同一阶段不同组织器官分布也差异很大，这些差异是调节细胞表型的关键。
:::

:::definition{label="果蝇早期三步基因开闭"}
最早期：一组母本效应基因（maternal effect gene）表达，固定头尾轴和背腹轴。随后：三组分节基因顺序表达，控制蛹的分节。最后：这些节发育为成虫的头、胸、翅膀、肢体、腹及尾。
:::

:::definition{label="特定基因控制哺乳类分化发育"}
高等哺乳类动物的细胞分化、组织器官发育由一些特定基因控制。基因缺陷或表达异常，会出现相应组织或器官发育异常。
:::

:::timeline{period="果蝇幼虫（蛹）基因表达顺序"}
- **最早期** 一组母本效应基因表达，受精卵头尾轴和背腹轴固定
- **随后** 三组分节基因顺序表达，控制蛹的分节发育
- **最后** 各节发育为成虫头、胸、翅膀、肢体、腹及尾
:::

:::pitfall{label="母本效应基因不要写成三组"}
教材写「一组」母本效应基因，然后才是「三组」分节基因。把母本效应也记成三组，轴固定和分节两步会并成一步。
:::

:::compare{title="原核调控意义 vs 多细胞额外意义"}
| | 原核／单细胞 | 多细胞另加 |
|--|--------------|------------|
| 目的 | 适应环境、维持生长和细胞分裂 | 还要维持细胞分化与个体发育 |
| 例子 | 先用葡萄糖，再开乳糖代谢酶基因 | 果蝇母本效应基因 $\rightarrow$ 分节基因；哺乳类特定基因控制器官发育 |
| 失败后果 | 不能换碳源、生长受阻 | 组织或器官发育异常 |

适应性表达在高等生物同样存在（醇氧化酶），不要把「分化发育」理解成高等生物取消了适应。
:::

## 四、基因表达受调控序列和调节分子共同调节

一个生物体的基因组中既有携带遗传信息的基因编码序列，也有能够影响基因表达的调控序列（regulatory sequence）。一般说来，调控序列与被调控的编码序列位于同一条 $\mathrm{DNA}$ 链上，也被称为顺式作用元件（cis-acting element）或顺式调节元件（cis-regulator element，$\mathrm{CRE}$）。还有一些调控基因远离被调控的编码序列，实际上是其他分子的编码基因，只能通过其表达产物来发挥作用。这类调控基因产物称为调节蛋白质（regulatory protein）。调节蛋白质不仅能对处于同一条 $\mathrm{DNA}$ 链上的结构基因的表达进行调控，而且还能对不在一条 $\mathrm{DNA}$ 链上的结构基因的表达起到同样的作用。因此，这些蛋白质分子又被称为反式作用因子（trans-acting factor）。这些反式作用因子以特定的方式识别和结合在顺式作用元件上，实施精确的基因表达调控。还有一类调控基因的产物为调节 $\mathrm{RNA}$，这些 $\mathrm{RNA}$ 分子以不同的作用方式对基因表达进行精细调节。

:::definition{label="调控序列"}
调控序列（regulatory sequence）：基因组中能够影响基因表达的序列，与携带遗传信息的编码序列相对。
:::

:::definition{label="顺式作用元件"}
顺式作用元件（cis-acting element）又称顺式调节元件（cis-regulator element，$\mathrm{CRE}$）：一般与被调控的编码序列位于同一条 $\mathrm{DNA}$ 链上的调控序列。
:::

:::definition{label="调节蛋白质与反式作用因子"}
远离被调控编码序列的调控基因，只能通过其表达产物发挥作用。产物为调节蛋白质（regulatory protein）。它既能调同一条 $\mathrm{DNA}$ 链上的结构基因，也能调不在一条 $\mathrm{DNA}$ 链上的结构基因，故又称反式作用因子（trans-acting factor）。
:::

:::definition{label="反式因子怎样工作"}
反式作用因子以特定方式识别和结合顺式作用元件，实施精确的基因表达调控。
:::

:::definition{label="调节 RNA"}
还有一类调控基因的产物为调节 $\mathrm{RNA}$，以不同作用方式对基因表达进行精细调节。第五节会点到以 $\mathrm{miRNA}$ 为代表的非编码 $\mathrm{RNA}$；本节先承认「调节分子不只有蛋白质」。
:::

:::keypoint{label="顺式在同一条 DNA 上，反式靠产物跨分子"}
顺式：序列本身，与靶基因同链。反式：先表达出蛋白质（或 $\mathrm{RNA}$），再去认元件。把阻遏蛋白编码基因 $\mathrm{I}$ 答成顺式元件，第二节 $\mathrm{PI}$ 独立启动子就没有意义。
:::

:::pitfall{label="CRE 不要读成 cAMP 反应元件的缩写来顶替本节"}
本版在这里把 $\mathrm{CRE}$ 定义为 cis-regulator element。不要用别的书里「$\mathrm{cAMP}$ response element」的用法来替换。$\mathrm{cAMP}$ 在第二节里结合的是 $\mathrm{CAP}$，不是把 $\mathrm{CRE}$ 改名。
:::

:::pitfall{label="反式因子不是只能调另一条染色体"}
教材写明：同一条 $\mathrm{DNA}$ 链上的结构基因，以及不在一条 $\mathrm{DNA}$ 链上的结构基因，调节蛋白质都能调。「反式」强调通过产物、可跨分子，不是「必须不在同一分子上」。
:::

:::compare{title="编码序列 vs 调控序列 vs 调节基因产物"}
| | 在基因组上的身份 | 怎样影响表达 |
|--|-------------------|--------------|
| 结构基因编码序列 | 携带遗传信息 | 被转录／翻译 |
| 顺式作用元件 | 与靶编码序列一般同链的调控序列 | 被反式因子识别结合 |
| 调节蛋白质（反式作用因子） | 由远离靶序列的调控基因表达 | 蛋白质去结合元件 |
| 调节 $\mathrm{RNA}$ | 调控基因的 $\mathrm{RNA}$ 产物 | 以不同方式精细调节 |

三套角色缺一，精确调控就不完整。
:::

作为反式作用因子的调节蛋白质具有特定的空间结构，通过特异性地识别某些 $\mathrm{DNA}$ 序列与顺式作用元件发生相互作用。例如，$\mathrm{DNA}$ 双螺旋结构的大沟是调节蛋白质最容易与 $\mathrm{DNA}$ 序列发生相互作用的部位。真核生物基因组结构比较复杂，使得有些调节蛋白质不能直接与 $\mathrm{DNA}$ 相互作用，而是首先形成蛋白质复合物，然后再与 $\mathrm{DNA}$ 结合参与基因表达的调控。蛋白质-$\mathrm{DNA}$ 以及蛋白质-蛋白质的相互作用是基因表达调控的分子基础。

:::definition{label="调节蛋白质认 DNA 的结构条件"}
调节蛋白质有特定空间结构，特异性识别某些 $\mathrm{DNA}$ 序列，与顺式作用元件相互作用。$\mathrm{DNA}$ 双螺旋的大沟是最容易发生这种相互作用的部位。
:::

:::definition{label="真核有时先形成蛋白质复合物"}
真核基因组较复杂，有些调节蛋白质不能直接与 $\mathrm{DNA}$ 相互作用，而是先形成蛋白质复合物，再与 $\mathrm{DNA}$ 结合。原核操纵子里阻遏蛋白、$\mathrm{CAP}$ 直接结合 $\mathrm{DNA}$ 的写法不要无差别搬到所有真核因子上。
:::

:::definition{label="调控的分子基础"}
蛋白质-$\mathrm{DNA}$ 以及蛋白质-蛋白质的相互作用是基因表达调控的分子基础。
:::

:::insight{label="大沟是接触面，不是又一类元件"}
大沟是双螺旋上调节蛋白质好下手的部位。考试若问「顺式作用元件是大沟吗」，元件仍是那段 $\mathrm{DNA}$ 序列，大沟是结构通路。
:::

:::pitfall{label="不要把蛋白质-蛋白质相互作用写成可有可无"}
真核「先形成复合物再结合 $\mathrm{DNA}$」把蛋白质-蛋白质相互作用放到和蛋白质-$\mathrm{DNA}$ 同等的基础位置。只答「转录因子结合启动子」，复合物这一层会丢。
:::

:::compare{title="原核直接结合 vs 真核可先成复合物（本节程度）"}
| | 与 DNA 的关系 | 额外一层 |
|--|---------------|----------|
| 一般叙述 | 调节蛋白质特异识别 $\mathrm{DNA}$ 序列，大沟最易作用 | — |
| 真核部分因子 | 不能直接与 $\mathrm{DNA}$ 作用 | 先形成蛋白质复合物，再结合 $\mathrm{DNA}$ |

细节（$\mathrm{CAP}$ 同二聚体、真核转录因子表）分别是第二、三节的账。
:::

## 五、基因表达调控呈现多层次和复杂性

无论是原核生物还是真核生物，基因表达调控体现在基因表达的全过程中，即在 $\mathrm{RNA}$ 转录合成和蛋白质翻译两个阶段都有控制其表达的机制。因此基因表达的调控是多层次的复杂过程，改变其中任何环节均会导致基因表达的变化。

:::definition{label="调控是多层次的全过程"}
原核、真核都在转录合成和蛋白质翻译两个阶段有控制机制。调控是多层次的复杂过程，改变其中任何环节均会导致基因表达变化。
:::

:::pitfall{label="不要把调控写成「只有转录起始」"}
后文会强调转录起始是基本控制点，但不是唯一环节。$\mathrm{DNA}$ 扩增、甲基化、剪接、转运、翻译及翻译后加工都在本段名单里。把「基本控制点」听成「只有这一处」，多层次就名存实亡。
:::

首先，遗传信息以基因的形式贮存于 $\mathrm{DNA}$ 分子中，基因拷贝数越多，其表达产物也会越多，因此基因组 $\mathrm{DNA}$ 的扩增（amplification）可影响基因表达。在多细胞生物，某一特定类型细胞的选择性扩增可能就是通过这种机制使某种或某些蛋白质分子高表达的结果。为适应某种特定需要而进行的 $\mathrm{DNA}$ 重排（DNA rearrangement）以及 $\mathrm{DNA}$ 甲基化（DNA methylation）等均可在遗传信息水平上影响基因表达。

:::definition{label="遗传信息水平上的调控"}
基因组 $\mathrm{DNA}$ 扩增（amplification）：拷贝数越多，表达产物越多；多细胞中特定类型细胞的选择性扩增可使某些蛋白质高表达。$\mathrm{DNA}$ 重排（DNA rearrangement）和 $\mathrm{DNA}$ 甲基化（DNA methylation）也在遗传信息水平上影响表达。
:::

:::insight{label="扩增改的是基因剂量，不是诱导剂结合阻遏蛋白"}
拷贝数增加 $\rightarrow$ 产物增加，发生在 $\mathrm{DNA}$ 水平。不要和第二节乳糖诱导（阻遏蛋白构象变化、去阻遏）混成同一步。
:::

:::pitfall{label="选择性扩增不要写成「所有细胞基因组一起加倍」"}
教材写的是多细胞中某一特定类型细胞的选择性扩增。全基因组复制是另一回事，不能拿来解释「某种蛋白质高表达」。
:::

其次，遗传信息经转录由 $\mathrm{DNA}$ 传递给 $\mathrm{RNA}$ 的过程，是基因表达调控最重要、最复杂的一个层次。在真核细胞，初始转录产物需经转录后加工修饰才能成为有功能的成熟 $\mathrm{RNA}$，并由细胞核转运至细胞质。对这些转录后加工修饰以及转运过程的控制也是调节某些基因表达的重要方式，如对 $\mathrm{mRNA}$ 的选择性剪接、$\mathrm{RNA}$ 编辑等。近年来，以 $\mathrm{miRNA}$ 为代表的非编码 $\mathrm{RNA}$ 对基因表达调控的作用也日益受到重视，使我们可以在一个新的层面上理解基因表达调控。

:::definition{label="转录是最重要、最复杂的层次"}
遗传信息经转录由 $\mathrm{DNA}$ 传给 $\mathrm{RNA}$，是基因表达调控最重要、最复杂的一个层次。
:::

:::definition{label="转录后加工、转运也是调控"}
真核初始转录产物需加工成成熟 $\mathrm{RNA}$，再由核转运至细胞质。选择性剪接、$\mathrm{RNA}$ 编辑等对加工和转运的控制，是调节某些基因表达的重要方式。
:::

:::definition{label="非编码 RNA 是新的层面"}
以 $\mathrm{miRNA}$ 为代表的非编码 $\mathrm{RNA}$ 对表达调控的作用日益受到重视，提供新的理解层面。与第四节「调节 $\mathrm{RNA}$」呼应。
:::

:::pitfall{label="选择性剪接不要写成原核操纵子的步骤"}
「初始转录产物需加工、由核到细胞质」明确落在真核细胞。原核偶联转录翻译、多顺反子，是第二节结构特点，不要把内含子剪接安进去。
:::

蛋白质生物合成即翻译是基因表达的重要环节，影响蛋白质合成的因素同样也能调节基因表达，并且翻译与翻译后加工可直接、快速地改变蛋白质的结构与功能，因而对此过程的调控是细胞对外环境变化或某些特异刺激应答时的快速反应机制。总之，在遗传信息传递的各个水平上均可进行基因表达调控。

:::definition{label="翻译及翻译后调控是快速反应"}
影响蛋白质合成的因素也能调节基因表达。翻译与翻译后加工可直接、快速改变蛋白质结构与功能，是细胞对外环境变化或特异刺激应答时的快速反应机制。
:::

:::compare{title="三个水平各管什么"}
| 水平 | 本版点名的方式 | 时间尺度（教材用语） |
|------|-----------------|----------------------|
| 遗传信息（$\mathrm{DNA}$） | 扩增、重排、甲基化 | 改拷贝数或模板状态 |
| 转录及转录后 | 转录本身；真核加工、转运、选择性剪接、$\mathrm{RNA}$ 编辑；$\mathrm{miRNA}$ 等 | 最重要、最复杂 |
| 翻译及翻译后 | 影响合成的因素；加工改变结构与功能 | 直接、快速 |

「各个水平上均可进行」是总结句；下一句再把基本控制点收束到转录起始。
:::

:::cause-effect{title="为什么翻译水平适合快速应答"}
- **因** 翻译与翻译后加工直接、快速改变蛋白质结构与功能，不必先从 $\mathrm{DNA}$ 重新抄一条 $\mathrm{mRNA}$
- **果** 对外环境变化或特异刺激可作快速反应；第二节原核翻译的自我控制、反义 $\mathrm{RNA}$ 是这一层的实例
:::

尽管基因表达调控可发生在遗传信息传递过程的任何环节，但发生在转录水平，尤其是转录起始水平的调节，对基因表达起着至关重要的作用，即转录起始是基因表达的基本控制点。

:::definition{label="转录起始是基本控制点"}
调控可发生在任何环节，但转录水平、尤其是转录起始水平的调节至关重要。转录起始是基因表达的基本控制点。
:::

:::keypoint{label="「基本控制点」与「多层次」必须同卷出现"}
- 多层次：$\mathrm{DNA}$、转录（含加工转运）、翻译（含加工）都可以调。
- 基本控制点：转录起始。
- 原核落实：第二节写明，转录水平调控主要取决于转录起始速度，即起始复合物形成的速度。

只背其中一句，另一句就会在选择题里被用来当干扰。
:::

:::insight{label="为什么起始值得当基本控制点"}
基因一旦开始大量转录，$\mathrm{mRNA}$ 和蛋白质就会按模板往下做；在起始处决定「开不开、开多大」，对剂量的杠杆最大。这不是否定加工和翻译，而是给后文操纵子、启动子共有序列排座位。
:::

:::memory{label="本节共用规律一张清单"}
- 表达：转录 $+$ 翻译表现为表型；$\mathrm{rRNA}$、$\mathrm{tRNA}$ 只转录也算表达。
- 数量：细菌约 $4\,000$ 基因，人约 $2$ 万蛋白质编码基因；大肠埃希菌约 $5\%$ 高水平转录。
- 时间特异性（多细胞又称阶段特异性）：感染阶段；霍乱 $44$ 上调／$193$ 抑制；$\mathrm{AFP}$ 胎儿高、成年低、肝癌再激活。
- 空间特异性 $=$ 细胞／组织特异性：胰岛素只在胰岛 $\beta$ 细胞；胰蛋白酶在腺泡细胞；决定细胞类型的是表达模式不是基因本身。
- 组成性：管家基因，柠檬酸循环酶；相对恒定，主要受启动子和 $\mathrm{RNA}$ 聚合酶影响。
- 诱导／阻遏：修复酶增加；色氨酸合成酶减少；乳糖操纵子是经典模型。
- 协同：功能相关基因协调表达。
- 顺式元件（$\mathrm{CRE}$）同链；反式因子是调节蛋白质，认大沟；还有调节 $\mathrm{RNA}$。
- 多层次，但转录起始是基本控制点。
:::

:::memory{label="三个不要对调的数字"}
- 细菌基因约 $4\,000$，不是约 $5\%$。
- 高水平转录约 $5\%$，不是人类蛋白质编码基因比例。
- 霍乱：上调 $44$，抑制 $193$。
:::
