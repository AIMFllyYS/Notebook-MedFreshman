# 第二节　聚合酶链反应技术

第一节把「看见某条核酸」写成印迹和芯片。本节解决「微量模板怎样在体外变成大量拷贝」：$1983$ 年 $\mathrm{Mullis}\ \mathrm{K}.$ 发明聚合酶链反应，试管里模拟 $\mathrm{DNA}$ 复制，变性－退火－延伸循环 $25\sim 30$ 次即可扩增百万倍以上。逆转录 $\mathrm{PCR}$、原位 $\mathrm{PCR}$ 和实时 $\mathrm{PCR}$（含 $\mathrm{SYBR\ Green}$）是衍生；测序简化只点到用途，原理交给第三节。

:::concept{term="先问模板、引物和耐热酶，再问这一轮是变性、退火还是延伸"}
看见“$\mathrm{PCR}$”，先不要默写芯片或测序。户头是：两条寡核苷酸引物分别结合拟扩增片段两侧，提供 $3'$-$\mathrm{OH}$；耐热 $\mathrm{DNA}$ 聚合酶按半保留机制沿模板延伸。特异性在引物，体系里还有模板、$\mathrm{dNTP}$ 和含 $\mathrm{Mg}^{2+}$ 的缓冲液。终点法只能半定量；要准确拷贝数，走实时荧光，看指数期而不是产物堆积。
:::

$20$ 世纪 $70$ 年代末，随着 $\mathrm{DNA}$ 重组技术的产生和发展，如何快速获得目的基因（待检测或待研究的特定基因）片段成为瓶颈问题。传奇的诺贝尔化学奖得主 $\mathrm{Mullis}\ \mathrm{K}.$ 在 $1983$ 年发明了聚合酶链反应（polymerase chain reaction，$\mathrm{PCR}$）技术，可将微量 $\mathrm{DNA}$ 片段大量扩增，使微量 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 的操作变得简单易行。

:::definition{label="目的基因"}
目的基因：待检测或待研究的特定基因。重组技术起来之后，快速拿到它的片段曾是瓶颈；$\mathrm{PCR}$ 就是对着这个瓶颈来的。
:::

:::definition{label="聚合酶链反应"}
聚合酶链反应（polymerase chain reaction，$\mathrm{PCR}$）：$1983$ 年由 $\mathrm{Mullis}\ \mathrm{K}.$ 发明，可将微量 $\mathrm{DNA}$ 片段大量扩增，使微量 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 的操作变得简单易行。$\mathrm{Mullis}$ 因此获诺贝尔化学奖。
:::

:::insight{label="RNA 也能用 PCR，是因为先能变成 DNA"}
开篇写「微量 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 的操作」。$\mathrm{PCR}$ 本身的模板是 $\mathrm{DNA}$；$\mathrm{RNA}$ 要先逆转录成 $\mathrm{cDNA}$，才是后文 $\mathrm{RT}$-$\mathrm{PCR}$。不要把 $\mathrm{PCR}$ 直接写成「扩增 $\mathrm{RNA}$」。
:::

:::pitfall{label="1983 是发明年，不要和 1977 测序、1980 诺贝尔化学奖并成同一件事"}
第三节 $\mathrm{Maxam}$-$\mathrm{Gilbert}$ 与 $\mathrm{Sanger}$-$\mathrm{Coulson}$ 是 $1977$ 年，二人因测序分享 $1980$ 年诺贝尔化学奖。$\mathrm{PCR}$ 是 $1983$ 年，$\mathrm{Mullis}$ 另一次化学奖。年份和奖项不要捆成「同一年发明测序和 $\mathrm{PCR}$」。
:::

## 一、PCR 技术的工作原理就是体外 DNA 复制

$\mathrm{PCR}$ 的基本工作原理是在试管中模拟 $\mathrm{DNA}$ 复制过程。以待扩增的 $\mathrm{DNA}$ 分子为模板，用两条寡核苷酸片段作为引物，分别在拟扩增片段的 $\mathrm{DNA}$ 两侧与模板 $\mathrm{DNA}$ 链互补结合，提供 $3'$-$\mathrm{OH}$ 末端；在耐热的 $\mathrm{DNA}$ 聚合酶作用下，按照半保留复制的机制沿着模板链延伸直至完成两条新链的合成。不断重复这一过程，即可使目的 $\mathrm{DNA}$ 片段得到扩增（图18-3）。$\mathrm{PCR}$ 反应的特异性依赖于与模板 $\mathrm{DNA}$ 两端互补的寡核苷酸引物。组成 $\mathrm{PCR}$ 反应体系的基本成分包括模板 $\mathrm{DNA}$、特异引物、耐热的 $\mathrm{DNA}$ 聚合酶（如 $\mathrm{Taq}\ \mathrm{DNA}$ 聚合酶）、$\mathrm{dNTP}$ 以及含有 $\mathrm{Mg}^{2+}$ 的缓冲液。

:::definition{label="PCR 是体外模拟 DNA 复制"}
试管中以待扩增 $\mathrm{DNA}$ 为模板，两条寡核苷酸引物分别在拟扩增片段两侧与模板互补结合，提供 $3'$-$\mathrm{OH}$；耐热 $\mathrm{DNA}$ 聚合酶按半保留机制沿模板延伸，合成两条新链。重复此过程即扩增目的片段。
:::

:::definition{label="引物提供 3′-OH，并决定特异性"}
两条引物分别结合拟扩增片段两侧。反应特异性依赖于与模板 $\mathrm{DNA}$ 两端互补的寡核苷酸引物。没有配对的引物，$3'$-$\mathrm{OH}$ 就没有落点，酶不能凭空起始。
:::

:::definition{label="PCR 反应体系五类基本成分"}
①模板 $\mathrm{DNA}$；②特异引物；③耐热的 $\mathrm{DNA}$ 聚合酶（如 $\mathrm{Taq}\ \mathrm{DNA}$ 聚合酶）；④ $\mathrm{dNTP}$；⑤含有 $\mathrm{Mg}^{2+}$ 的缓冲液。
:::

:::insight{label="耐热是为了让同一管酶熬过一轮轮 95℃"}
体内复制不会把体系加热到变性温度。$\mathrm{PCR}$ 每一轮都要把双链拆开，所以酶必须耐热，才不必每轮补加聚合酶。$\mathrm{Taq}\ \mathrm{DNA}$ 聚合酶是教材点名的例子。
:::

:::pitfall{label="引物在两侧，不是一条引物从中间随便起始"}
「分别在拟扩增片段的 $\mathrm{DNA}$ 两侧」决定了产物两端。后文短产物的长度严格限定在两个引物链 $5'$ 端之间，就是这句话的几何结果。只写一条引物，扩增片段没有第二端。
:::

:::pitfall{label="Mg2+ 在缓冲液里，不是第四种 dNTP"}
体系写的是「含有 $\mathrm{Mg}^{2+}$ 的缓冲液」。$\mathrm{dNTP}$ 是底物， $\mathrm{Mg}^{2+}$ 是缓冲体系的成分。漏掉 $\mathrm{Mg}^{2+}$ 或把它写成一种碱基，五类成分就少一项。
:::

:::compare{title="体内复制 vs PCR"}
| | 细胞内 $\mathrm{DNA}$ 复制 | $\mathrm{PCR}$ |
|--|------------------------|-------------|
| 场所 | 复制叉、多种复制蛋白 | 试管 |
| 引物 | $\mathrm{RNA}$ 引物等（第十四章） | 两条外加的寡核苷酸 |
| 解链 | 解旋酶等 | 加热变性 |
| 酶 | 复制体上的 $\mathrm{DNA}$ 聚合酶 | 耐热 $\mathrm{DNA}$ 聚合酶（如 $\mathrm{Taq}$） |
| 方向 | 半保留，前导／后随 | 同样按半保留沿模板延伸 |
| 目的 | 复制整个基因组 | 只扩增两个引物之间的片段 |

原理借用复制，范围被引物剪成「目的片段」。
:::

$\mathrm{PCR}$ 的基本反应步骤包括：①变性：将反应体系加热至 $95^\circ\mathrm{C}$，使模板 $\mathrm{DNA}$ 完全变性成为单链，同时引物自身以及引物之间存在的局部双链也得以消除；②退火：将温度下降至适宜温度（一般较 $T_\mathrm{m}$ 低 $5^\circ\mathrm{C}$），使引物与模板 $\mathrm{DNA}$ 结合；③延伸：将温度升至 $72^\circ\mathrm{C}$，$\mathrm{DNA}$ 聚合酶以 $\mathrm{dNTP}$ 为底物催化 $\mathrm{DNA}$ 的合成反应。上述 $3$ 个步骤称为 $1$ 个循环，新合成的 $\mathrm{DNA}$ 分子继续作为下一轮合成的模板，经多次循环（$25\sim 30$ 次）后，即可达到扩增百万倍以上 $\mathrm{DNA}$ 片段的目的。

:::definition{label="变性"}
加热至 $95^\circ\mathrm{C}$，使模板 $\mathrm{DNA}$ 完全变性成为单链；同时消除引物自身以及引物之间存在的局部双链。
:::

:::definition{label="退火"}
温度下降至适宜温度（一般较 $T_\mathrm{m}$ 低 $5^\circ\mathrm{C}$），使引物与模板 $\mathrm{DNA}$ 结合。
:::

:::definition{label="延伸"}
温度升至 $72^\circ\mathrm{C}$，$\mathrm{DNA}$ 聚合酶以 $\mathrm{dNTP}$ 为底物催化 $\mathrm{DNA}$ 合成。
:::

:::definition{label="一个循环与扩增倍数"}
变性、退火、延伸 $3$ 步称为 $1$ 个循环。新链作为下一轮模板。$25\sim 30$ 次循环后，目的片段可扩增百万倍以上。
:::

:::keypoint{label="三步的温度不要记串"}
- 变性：$95^\circ\mathrm{C}$（图18-3 标 $94^\circ\mathrm{C}$，见该图说明）。
- 退火：较 $T_\mathrm{m}$ 低约 $5^\circ\mathrm{C}$（图18-3 示例 $55^\circ\mathrm{C}$）。
- 延伸：$72^\circ\mathrm{C}$。

循环次数 $25\sim 30$，倍数「百万倍以上」。温度、次数、倍数是三本账。
:::

:::pitfall{label="变性不只拆模板，也拆引物自己形成的局部双链"}
$95^\circ\mathrm{C}$ 的两个作用教材都写了：模板成单链；引物自身及引物之间的局部双链消除。只答「模板变单链」，引物二聚体、发夹没有处理。
:::

:::pitfall{label="退火温度不是固定 55℃"}
正文规则是「一般较 $T_\mathrm{m}$ 低 $5^\circ\mathrm{C}$」。图18-3 把示例画成 $55^\circ\mathrm{C}$，那是示意图，不是所有引物的法定温度。
:::

:::cause-effect{title="为什么新链必须当下一轮模板"}
- **因** 每一轮产物两端由引物决定，本身也是 $\mathrm{DNA}$
- **果** 下一轮它们继续当模板，短产物按指数增加；只靠最初那两条基因组链，到不了百万倍
:::

::figure{src="/images/biochemistry/textbook/p0370_01.png" caption="图18-3　PCR 技术原理示意图。左：94℃ 使 DNA 模板变性；55℃ 单链模板与正向引物、反向引物退火，Taq pol 结合；72℃ 引物延伸。进入第二轮循环时再次 94℃ 变性。右：第二轮起，新链两端逐渐被引物限定，出现短产物片段；数十次循环产生大量短片段 DNA 终产物。" alt="PCR两轮示意图：左为第一轮变性退火延伸，右为第二轮产生两端由引物限定的短产物"}

:::insight{label="图18-3 左栏是第一轮，右栏才画出短产物"}
左上双链解成两条单链，标「需要扩增的特定片段」。$55^\circ\mathrm{C}$ 时正向引物结合下方蓝链、反向引物结合上方灰链，$\mathrm{Taq\ pol}$ 沿箭头延伸。$72^\circ\mathrm{C}$ 后新链的 $5'$ 端停在引物处，$3'$ 端还没有对侧引物挡住，这就是正文说的长产物。蓝箭头把产物送进第二轮：$94^\circ\mathrm{C}$ 再变性后，右栏在 $55^\circ\mathrm{C}$、$72^\circ\mathrm{C}$ 画出两端都限定的短产物，底注「数十次反应步骤的循环产生大量短片段 $\mathrm{DNA}$ 终产物」。
:::

:::definition{label="长产物片段"}
第一轮以两条互补 $\mathrm{DNA}$ 为模板，引物附上模板的 $3'$ 端，即新生链的 $5'$ 端是固定的，其 $3'$ 端没有固定止点，产生「长产物片段」。
:::

:::definition{label="短产物片段"}
进入第二轮循环，新延伸片段的起点和终点都限定于引物扩增序列以内，形成长短一致的「短产物片段」。其长度严格限定在两个引物链 $5'$ 端之间，是需要扩增的特定片段。短产物按指数倍数增加，长产物几乎可以忽略不计。
:::

:::keypoint{label="短产物从第二轮才出现，指数增长的是它"}
- 第一轮：只有长产物，$5'$ 固定、$3'$ 不固定。
- 第二轮：出现两端都在引物 $5'$ 端之间的短产物。
- 以后各轮：短产物当模板，按指数增加；长产物相对可忽略。

问「为什么产物是一条齐的带」，答短产物的两端被引物 $5'$ 端卡住，不要答「第一轮就已经等长」。
:::

:::pitfall{label="图上 94℃ 与正文 95℃ 并存，默写跟正文，读图跟图"}
正文变性写 $95^\circ\mathrm{C}$；图18-3 标 $94^\circ\mathrm{C}$。本版两处温度不同，不要擅自改成一致。循环次数正文是 $25\sim 30$ 次，图注写「数十次」，同一关系。
:::

:::pitfall{label="Taq pol 画在引物 3′ 一侧，不是从 5′ 往回走"}
图上 $\mathrm{Taq\ pol}$ 的箭头沿引物 $3'$ 方向延伸。$\mathrm{DNA}$ 合成 $5'\rightarrow 3'$，引物提供的就是这个 $3'$-$\mathrm{OH}$。把酶画成从标记引物的 $5'$ 端往回聚合，短产物的定义就反了。
:::

:::compare{title="长产物 vs 短产物"}
| | 长产物 | 短产物 |
|--|--------|--------|
| 出现轮次 | 第一轮起 | 第二轮起 |
| $5'$ 端 | 固定在引物 | 固定在引物 |
| $3'$ 端 | 无固定止点 | 也限定在对侧引物以内 |
| 长度 | 不齐 | 严格等于两引物 $5'$ 端之间 |
| 以后数量 | 几乎可忽略 | 指数增加，是要的特异片段 |

扩增「百万倍以上」的是短产物这一本账。
:::

## 二、PCR 技术是基因研究的最基本技术

$\mathrm{PCR}$ 技术的高敏感、高特异、高产率、可重复、快速简便等优点，使其迅速成为分子生物学研究中应用最为广泛的方法，许多以往无法解决的分子生物学研究难题得以解决。$\mathrm{PCR}$ 技术的发明是分子生物学的一项革命，极大地推动了分子生物学以及生物技术产业的发展，成为分子生物学与医学研究的支撑技术。

:::definition{label="PCR 作为支撑技术的优点"}
高敏感、高特异、高产率、可重复、快速简便。教材把它写成分子生物学的一项革命，是分子生物学与医学研究的支撑技术。
:::

:::insight{label="「最基本」指用途铺得最开，不是取代印迹的全部优点"}
Northern 仍强调特异强、假阳性低；$\mathrm{PCR}$ 强调敏感和微量。后文实时 $\mathrm{PCR}$「逐渐替代 $\mathrm{RNA}$ 印迹法」，替代的是定量场景，不是把印迹从教材里删掉。
:::

### （一）PCR 技术可以简便快速地大量获得目的基因片段

$\mathrm{PCR}$ 技术为在重组 $\mathrm{DNA}$ 过程中获得目的基因片段提供了简便快速的方法。在人类基因组计划完成之前，$\mathrm{PCR}$ 是从 $\mathrm{cDNA}$ 文库或基因组文库中获得序列相似的新基因片段或新基因的主要方法。目前，该技术是从各种生物标本或基因工程载体中快速获得已知序列目的基因片段的主要方法。

而且，在 $\mathrm{PCR}$ 技术建立以前，在体外对基因进行各种突变是一项费时费力的工作。现在，利用 $\mathrm{PCR}$ 技术可以随意设计引物，在体外对目的基因片段进行插入、嵌合、缺失、点突变等改造。

:::definition{label="PCR 获取目的基因：基因组计划前后不一样"}
计划完成前：从 $\mathrm{cDNA}$ 文库或基因组文库中获得序列相似的新基因片段或新基因的主要方法。目前：从各种生物标本或基因工程载体中快速获得已知序列目的基因片段的主要方法。
:::

:::definition{label="用引物在体外改造基因"}
可随意设计引物，对目的基因片段做插入、嵌合、缺失、点突变等改造。建立 $\mathrm{PCR}$ 以前，体外突变费时费力。
:::

:::pitfall{label="「新基因」是计划完成前的主要用途，现在默认已知序列"}
两句话不要并成「$\mathrm{PCR}$ 专门钓未知基因」。现在教材把它写成已知序列片段的主要获取法。未知全序列的发现更多交给第三节高通量测序。
:::

:::keypoint{label="改造基因靠的是引物设计，不是另加一套诱变剂"}
插入、嵌合、缺失、点突变都写在「随意设计引物」后面。引物序列里带上突变或限制位点，扩增产物就是改过的片段。不要把这一条改写成化学诱变。
:::

### （二）PCR 技术可以定性定量分析微量 DNA 和 RNA

$\mathrm{PCR}$ 技术敏感性高，对模板 $\mathrm{DNA}$ 的量要求很低，是 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 微量定性和定量分析的最好方法。理论上讲，只要存在 $1$ 分子的模板 $\mathrm{DNA}$，就可以获得目的片段。实际工作中，$1$ 滴血液、$1$ 根毛发或 $1$ 个细胞已足以满足 $\mathrm{PCR}$ 的检测需要，因此在基因诊断方面具有极广阔的应用。

:::definition{label="微量检测的理论与实际"}
理论上：$1$ 分子模板 $\mathrm{DNA}$ 即可获得目的片段。实际：$1$ 滴血液、$1$ 根毛发或 $1$ 个细胞已足以检测。故在基因诊断上应用极广阔。
:::

:::definition{label="PCR 是微量核酸定性定量的最好方法"}
敏感性高，对模板量要求很低，是 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 微量定性、定量分析的最好方法。$\mathrm{RNA}$ 定量的「准确」还要靠后文实时 $\mathrm{PCR}$；此处先立「微量也能做」。
:::

:::pitfall{label="1 分子是理论上讲，不要答成日常都能稳拿到"}
教材用「理论上讲」限定 $1$ 分子。日常例子是 $1$ 滴血、$1$ 根毛发、$1$ 个细胞。把理论极限当成操作保证，敏感性会被说成没有失败。
:::

### （三）PCR 技术简化了 DNA 序列分析

将 $\mathrm{PCR}$ 技术引入 $\mathrm{DNA}$ 序列测定，使测序工作大为简化，也提高了测序的速度，是实现高通量 $\mathrm{DNA}$ 序列分析的基础。待测 $\mathrm{DNA}$ 片段既可克隆到特定的载体后进行序列测定，也可直接测定。

:::definition{label="PCR 是高通量测序的基础之一"}
引入测序后工作简化、速度提高，是实现高通量 $\mathrm{DNA}$ 序列分析的基础。待测片段可先克隆到特定载体再测，也可直接测定。
:::

:::insight{label="本节只说「简化测序」，双脱氧和循环芯片仍在第三节"}
克隆后测或直接测，都还没有解释 $\mathrm{ddNTP}$。不要在这里提前写桑格法四管反应。
:::

:::pitfall{label="可以直接测，不等于必须不克隆"}
「既可……也可……」是两条路。文库、载体在计划完成前获取新基因时仍然在用。
:::

### （四）PCR 技术提高基因突变检测的敏感性

$\mathrm{PCR}$ 与其他技术的结合可以大大提高基因突变检测的敏感性，例如单链构象多态性分析、等位基因特异的寡核苷酸探针分析、基因芯片技术、$\mathrm{DNA}$ 序列分析等。

:::definition{label="PCR 提高突变检测敏感性靠的是组合"}
与单链构象多态性分析、等位基因特异的寡核苷酸探针分析、基因芯片技术、$\mathrm{DNA}$ 序列分析等结合，大大提高基因突变检测的敏感性。
:::

:::pitfall{label="PCR 本身不等于突变检测的全部方法"}
教材列举的是「与其他技术结合」。$\mathrm{PCR}$ 负责把微量模板放大；构象、特异探针、芯片、测序才是看见哪一种突变。后文实时 $\mathrm{PCR}$ 用熔解曲线或双色探针检测突变，仍是这种组合思路。
:::

:::compare{title="PCR 四条基本用途"}
| | 做什么 | 教材限定 |
|--|--------|----------|
| 获目的片段 | 重组时拿到基因；计划前从文库钓相似新基因；现在从标本或载体拿已知序列 | 也可靠引物做插入／嵌合／缺失／点突变 |
| 微量定性定量 | $\mathrm{DNA}$ 和 $\mathrm{RNA}$ | 理论 $1$ 分子；实际 $1$ 滴血／$1$ 根毛发／$1$ 个细胞 |
| 简化测序 | 克隆后测或直接测 | 高通量测序的基础 |
| 突变检测 | 与 $\mathrm{SSCP}$、等位基因特异寡核苷酸探针、芯片、测序等结合 | 提高的是敏感性 |

四条都建立在「引物决定特异、循环决定产量」上。
:::

## 三、几种重要的 PCR 衍生技术已广泛用于生命科学研究

近年来，$\mathrm{PCR}$ 技术不断改进，从手工操作发展到自动化仪器，从定性分析发展到定量测定。该方法与其他分子生物学技术相结合，其用途日益拓展。$\mathrm{PCR}$ 技术自身的发展及其与已有分子生物学技术的结合形成了多种 $\mathrm{PCR}$ 衍生技术，提高了 $\mathrm{PCR}$ 反应的特异性和应用的广泛性。这里仅举例介绍部分与医学研究密切相关的 $\mathrm{PCR}$ 衍生技术。

:::definition{label="衍生技术从两条线来"}
自身发展：手工到自动化，定性到定量。与其他技术结合：提高特异性、拓宽应用。本节只举与医学密切相关的部分。
:::

:::keypoint{label="本节省下的三种衍生"}
- 逆转录 $\mathrm{PCR}$：$\mathrm{RNA}\rightarrow\mathrm{cDNA}$ 再扩增；获基因，定性／半定量 $\mathrm{RNA}$。
- 原位 $\mathrm{PCR}$：在固定细胞里扩，再原位杂交，扩增 $+$ 定位。
- 实时 $\mathrm{PCR}$：每轮看产物量，准确量化；$\mathrm{SYBR\ Green}$ 与探针类。
:::

### （一）逆转录 PCR 技术可以获得目的基因和定性与半定量分析 RNA

逆转录聚合酶链反应（reverse transcription $\mathrm{PCR}$，$\mathrm{RT}$-$\mathrm{PCR}$）简称逆转录 $\mathrm{PCR}$，又称反转录 $\mathrm{PCR}$，是将 $\mathrm{RNA}$ 的逆转录反应和 $\mathrm{PCR}$ 反应联合应用的一种技术。首先以 $\mathrm{RNA}$ 为模板，在逆转录酶的作用下合成 $\mathrm{cDNA}$，再以 $\mathrm{cDNA}$ 为模板通过 $\mathrm{PCR}$ 反应来扩增目的基因。$\mathrm{RT}$-$\mathrm{PCR}$ 可检测到单个细胞中少于 $10$ 个拷贝的特异的 $\mathrm{RNA}$，是目前从组织或细胞中获得目的基因，以及对已知序列的 $\mathrm{RNA}$ 进行定性和半定量分析的最有效方法，也是最广泛使用的 $\mathrm{PCR}$ 衍生技术。

:::definition{label="RT-PCR"}
逆转录聚合酶链反应（reverse transcription $\mathrm{PCR}$，$\mathrm{RT}$-$\mathrm{PCR}$），又称反转录 $\mathrm{PCR}$：先以 $\mathrm{RNA}$ 为模板，逆转录酶合成 $\mathrm{cDNA}$，再以 $\mathrm{cDNA}$ 为模板做 $\mathrm{PCR}$ 扩增目的基因。
:::

:::definition{label="RT-PCR 的灵敏度与地位"}
可检测到单个细胞中少于 $10$ 个拷贝的特异 $\mathrm{RNA}$。是从组织或细胞获得目的基因、对已知序列 $\mathrm{RNA}$ 做定性与半定量分析的最有效方法，也是最广泛使用的 $\mathrm{PCR}$ 衍生技术。
:::

:::insight{label="半定量三个字已经给实时 PCR 留了位子"}
$\mathrm{RT}$-$\mathrm{PCR}$ 写的是定性与半定量。后文常规 $\mathrm{PCR}$ 因终点产物堆积只能半定量，准确量化要实时 $\mathrm{PCR}$。不要把 $\mathrm{RT}$-$\mathrm{PCR}$ 直接写成「最准确的 $\mathrm{RNA}$ 定量」。
:::

:::pitfall{label="少于 10 个拷贝是单个细胞里的检测限，不是反应管里只能有 10 个分子"}
「单个细胞中少于 $10$ 个拷贝的特异的 $\mathrm{RNA}$」。与上一节理论 $1$ 分子模板 $\mathrm{DNA}$ 不是同一句话。
:::

:::pitfall{label="逆转录酶在第一段，Taq 在第二段"}
$\mathrm{RNA}\rightarrow\mathrm{cDNA}$ 靠逆转录酶；以后扩增 $\mathrm{cDNA}$ 才是耐热 $\mathrm{DNA}$ 聚合酶。不要写成 $\mathrm{Taq}$ 直接以 $\mathrm{RNA}$ 为模板。
:::

:::compare{title="普通 PCR vs RT-PCR"}
| | 普通 $\mathrm{PCR}$ | $\mathrm{RT}$-$\mathrm{PCR}$ |
|--|----------------|----------------|
| 起始模板 | $\mathrm{DNA}$ | $\mathrm{RNA}$（先成 $\mathrm{cDNA}$） |
| 关键额外酶 | 无逆转录酶 | 逆转录酶 $+$ 随后的 $\mathrm{PCR}$ 酶 |
| 典型问题 | 有没有这段 $\mathrm{DNA}$ | 组织／细胞里这条 $\mathrm{RNA}$ 有没有、半定量多少；顺便拿到编码序列 |
| 定量精度 | 终点法半定量 | 同样是半定量，除非再做成实时 |

基因芯片图18-2 里的「$\mathrm{RT}$-$\mathrm{PCR}$ 荧光标记」是给 $\mathrm{cDNA}$ 贴荧光，用途不同。
:::

### （二）原位 PCR 技术可以扩增与定位目的基因

原位聚合酶链反应（in situ $\mathrm{PCR}$）简称原位 $\mathrm{PCR}$。是利用完整的细胞作为一个微小的反应体系来扩增细胞内的目的基因片段。$\mathrm{PCR}$ 反应在甲醛溶液（福尔马林）固定、石蜡包埋的组织切片或细胞涂片上的单个细胞内进行。在 $\mathrm{DNA}$ 模板分子原来所在的位置处进行 $\mathrm{PCR}$ 反应后，再用特异性探针进行原位杂交，即可检出待测 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 是否在该组织或细胞中存在。

由于常规 $\mathrm{PCR}$ 或 $\mathrm{RT}$-$\mathrm{PCR}$ 技术的产物不能在组织细胞中直接定位，因而不能与特定的组织细胞特征表型相联系，而原位杂交技术虽有良好的定位效果，但灵敏度不高。原位 $\mathrm{PCR}$ 方法弥补了 $\mathrm{PCR}$ 技术和原位杂交技术的不足，将目的基因的扩增与定位相结合，既能分辨鉴定带有靶序列的细胞，又能标出靶序列在细胞内的位置，在分子和细胞水平上研究疾病的发病机制和临床过程有重大的实用价值。

:::definition{label="原位 PCR"}
原位聚合酶链反应（in situ $\mathrm{PCR}$）：以完整细胞为微小反应体系，扩增细胞内目的基因片段。反应在甲醛溶液（福尔马林）固定、石蜡包埋的组织切片或细胞涂片上的单个细胞内进行。在模板原来所在位置扩增后，再用特异探针原位杂交，检出待测 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 是否存在于该组织或细胞。
:::

:::definition{label="原位 PCR 补的是「能扩不能看位置、能看位置不够敏」"}
常规 $\mathrm{PCR}/\mathrm{RT}$-$\mathrm{PCR}$：产物不能在组织细胞中直接定位，无法与特征表型联系。原位杂交：定位好，灵敏度不高。原位 $\mathrm{PCR}$：扩增 $+$ 定位，既能鉴定带靶序列的细胞，又能标出靶序列在细胞内的位置。
:::

:::insight{label="固定切片上的单个细胞就是反应管"}
福尔马林固定、石蜡包埋不是把模板抽出来，而是把细胞变成微反应器，模板仍在原位。这与第一节 $\mathrm{ISH}$ 留在切片上是同一空间逻辑，只是先在原位扩增再杂交。
:::

:::pitfall{label="原位 PCR 后面仍要原位杂交，不是扩完用溴化乙啶看胶"}
教材写明扩增后「再用特异性探针进行原位杂交」。产物不抽到试管里跑电泳。把原位 $\mathrm{PCR}$ 答成「在切片旁边做普通 $\mathrm{PCR}$」，定位这一半就没了。
:::

:::pitfall{label="ISH 灵敏度不高，原位 PCR 不是把 ISH 作废"}
原位杂交仍有良好定位效果。原位 $\mathrm{PCR}$ 是补灵敏度，并与表型联系。第一节的 $\mathrm{FISH}$ 仍是荧光原位杂交，不要全部改名成原位 $\mathrm{PCR}$。
:::

:::compare{title="常规 PCR、ISH、原位 PCR"}
| | 扩增？ | 定位？ | 灵敏度 |
|--|--------|--------|--------|
| 常规 $\mathrm{PCR}/\mathrm{RT}$-$\mathrm{PCR}$ | 有 | 无（产物离开细胞） | 高 |
| 原位杂交（$\mathrm{ISH}/\mathrm{FISH}$） | 无 | 有 | 不高 |
| 原位 $\mathrm{PCR}$ | 在原位有 | 有（再加原位杂交） | 补上扩增 |

疾病机制要同时问「哪一种细胞、分子在哪里」，走原位 $\mathrm{PCR}$ 这一列。
:::

### （三）实时 PCR 技术实现 RNA 快速而准确的定量分析

常规 $\mathrm{PCR}$ 反应是在反应终点检测产物含量，然而在反应过程中产物是以指数形式增加的，多次循环反应后的产物堆积将影响对原有模板含量差异的准确判断，故常规 $\mathrm{PCR}$ 反应只能作为半定量手段。实时聚合酶链反应（real-time $\mathrm{PCR}$），简称实时 $\mathrm{PCR}$，是通过动态监测反应过程中的产物量，消除产物堆积对定量分析的干扰，亦被称为定量聚合酶链反应（quantitative $\mathrm{PCR}$，$\mathrm{qPCR}$），简称定量 $\mathrm{PCR}$。定量 $\mathrm{PCR}$ 技术实现了 $\mathrm{mRNA}$、$\mathrm{miRNA}$ 及其他非编码的 $\mathrm{RNA}$ 快速而准确的定量分析，已在临床应用于基因诊断。

:::definition{label="常规 PCR 只能半定量"}
在反应终点检测产物含量。过程中产物指数增加，多次循环后产物堆积，影响对原有模板含量差异的准确判断。
:::

:::definition{label="实时 PCR 即 qPCR"}
实时聚合酶链反应（real-time $\mathrm{PCR}$）：动态监测反应过程中的产物量，消除产物堆积对定量的干扰。亦称定量聚合酶链反应（quantitative $\mathrm{PCR}$，$\mathrm{qPCR}$）。
:::

:::definition{label="定量 PCR 看哪些 RNA"}
实现 $\mathrm{mRNA}$、$\mathrm{miRNA}$ 及其他非编码 $\mathrm{RNA}$ 快速而准确的定量分析，已在临床用于基因诊断。
:::

:::cause-effect{title="终点法为什么不准"}
- **因** 指数增长之后产物堆积，平台期把起始差异抹平
- **果** 终点含量不能准确代表原模板差；必须在过程中（指数期）读产物量
:::

:::pitfall{label="实时 PCR 和 qPCR 是同一技术的两个名字"}
教材用「亦被称为」连接。不要把 real-time 答成「只看曲线不定量」、把 $\mathrm{qPCR}$ 答成另一种酶反应。
:::

:::pitfall{label="准确量化的是过程，不是把酶换成一种定量酶"}
消除干扰靠「动态监测产物量」。酶仍是 $\mathrm{PCR}$ 那一套，多的是荧光和专用仪器。
:::

#### 1. 实时 PCR 的定量关键是检测每一轮 PCR 的产物量

实时 $\mathrm{PCR}$ 的基本原理是在 $\mathrm{PCR}$ 反应体系中加入荧光染料或荧光探针，利用荧光信号积累实时监测整个 $\mathrm{PCR}$ 进程，故也称为实时荧光 $\mathrm{PCR}$（real-time fluorescence $\mathrm{PCR}$）。实时荧光 $\mathrm{PCR}$ 需要采用专用 $\mathrm{PCR}$ 仪，自动在每个循环的特定阶段对反应体系的荧光强度进行采集，实时记录荧光强度的改变，可以做到 $\mathrm{PCR}$ 每循环一次就收集一个数据，建立实时扩增曲线。由于反应起始的模板 $\mathrm{DNA}$ 量与循环过程的指数期的扩增产物量之间存在着定量关系，利用荧光信号的实时监测和计算，可以准确地确定起始 $\mathrm{DNA}$ 拷贝数，实现精确定量分析。

:::definition{label="实时荧光 PCR"}
体系中加入荧光染料或荧光探针，用荧光信号积累实时监测整个进程。需要专用 $\mathrm{PCR}$ 仪，每个循环特定阶段采集荧光，每循环一次收集一个数据，建立实时扩增曲线。
:::

:::definition{label="定量关系落在指数期"}
起始模板 $\mathrm{DNA}$ 量与循环过程指数期的扩增产物量之间存在定量关系。据此准确确定起始 $\mathrm{DNA}$ 拷贝数。
:::

:::keypoint{label="每一轮收集一个点，连成扩增曲线"}
不是反应结束后看一条带，而是每循环一次记一次荧光。曲线的指数段对应起始拷贝数；平台段正是常规 $\mathrm{PCR}$ 被产物堆积骗到的地方。
:::

:::pitfall{label="专用仪器不是普通恒温水浴三个温度"}
「自动在每个循环的特定阶段采集荧光」要求专用实时荧光 $\mathrm{PCR}$ 仪。普通三温循环仪可以做终点 $\mathrm{PCR}$，做不了这一句里的实时曲线。
:::

教材第 $342$ 页实时荧光 $\mathrm{PCR}$ 相关动画占位对应图源 `p0371_01.png` 为 $0$ 字节，不嵌入 `src`。定量关键以「每一轮采集荧光、指数期对应起始拷贝数」的正文为准。
:::

#### 2. 实时荧光 PCR 技术可分为两大类

荧光标记是实现 $\mathrm{PCR}$ 实时定量的化学基础，根据荧光标记可将实时 $\mathrm{PCR}$ 分为非引物探针类和引物探针类。

非引物探针类是利用非特异性的插入双链 $\mathrm{DNA}$ 的荧光染料，如最常用的是能结合到 $\mathrm{DNA}$ 双螺旋小沟区域的荧光染料 $\mathrm{SYBR\ Green}$，来指示扩增产物的增加（图18-4）。由于非引物探针类实时 $\mathrm{PCR}$ 成本低廉，简便易行，在基因表达的定量分析方面应用广泛。

:::note{label="电子版缺失"}
图18-4　荧光染料 $\mathrm{SYBR\ Green}$ 用于实时 $\mathrm{PCR}$ 的原理示意图：电子版图源 `p0372_01.png` 为 $0$ 字节，不嵌入 `src`。图注原文：$\mathrm{SYBR\ Green}$ 只可以结合在双链 $\mathrm{DNA}$ 上，结合后产生荧光（约为游离状态 $\mathrm{SYBR\ Green}$ 的 $1\,000$ 倍）。荧光信号强度与双链 $\mathrm{DNA}$，即 $\mathrm{PCR}$ 产物量正相关。在 $\mathrm{PCR}$ 反应过程中，实时测定荧光强度即可得知产物量，并据此计算出样本中的初始模板含量。
:::

引物探针类则是利用标记荧光报告基团的引物为探针，但仅在与靶 $\mathrm{DNA}$ 序列杂交或引导扩增时才产生荧光，来指示扩增产物的增加。常用的包括 $\mathrm{TaqMan}$ 探针法、分子信标（molecular beacon）和荧光共振能量转移（fluorescence resonance energy transfer，$\mathrm{FRET}$）探针法等。由于增加了探针的互补识别步骤，特异性更高，且可采用多色荧光探针，即在一个反应中实现对数种不同基因表达水平的同时检测。

:::definition{label="两大类按荧光标记分"}
荧光标记是实时定量的化学基础。非引物探针类：非特异插入双链 $\mathrm{DNA}$ 的荧光染料。引物探针类：带荧光报告基团的引物／探针，仅在与靶序列杂交或引导扩增时才发荧光。
:::

:::definition{label="SYBR Green"}
最常用的非引物探针类染料，结合到 $\mathrm{DNA}$ 双螺旋小沟。只结合双链 $\mathrm{DNA}$，结合后荧光约为游离状态的 $1\,000$ 倍。荧光强度与双链 $\mathrm{DNA}$（即 $\mathrm{PCR}$ 产物量）正相关，据此算初始模板含量。成本低、简便，广泛用于基因表达定量。
:::

:::definition{label="引物探针类三例"}
$\mathrm{TaqMan}$ 探针法、分子信标（molecular beacon）、荧光共振能量转移（$\mathrm{FRET}$）探针法。仅在与靶 $\mathrm{DNA}$ 杂交或引导扩增时发荧光。
:::

:::definition{label="探针类为什么更特异、还能多色"}
增加了探针的互补识别步骤，特异性更高；可采用多色荧光探针，一个反应同时检测数种不同基因的表达水平。
:::

:::insight{label="SYBR 认的是「有没有双链」，探针认的是「是不是这条序列」"}
小沟染料只要是双链就亮，引物二聚体、非特异扩增也会贡献荧光。探针还要与靶杂交才亮，所以特异性更高。这与第一节核酸探针「已知序列」是同一逻辑。
:::

:::pitfall{label="1000 倍是结合后相对游离染料，不是扩增倍数"}
$\mathrm{SYBR\ Green}$ 结合双链后荧光约为游离状态的 $1\,000$ 倍。$\mathrm{PCR}$ 扩增「百万倍以上」是循环产量。两个 $10^{3}$ 量级不要并成一句。
:::

:::pitfall{label="非引物探针类不是「没有引物的 PCR」"}
分类名说的是荧光那一侧不用序列特异探针，引物仍然是 $\mathrm{PCR}$ 必需的那两条。不要理解成反应体系里取消引物。
:::

:::pitfall{label="TaqMan、分子信标、FRET 是探针类举例，不是三种新的循环温度"}
循环仍是变性－退火－延伸。多的是探针怎么亮。不要为每一种探针另编一套 $95/55/72$。
:::

:::compare{title="SYBR Green vs 引物探针类"}
| | 非引物探针类（$\mathrm{SYBR\ Green}$） | 引物探针类（$\mathrm{TaqMan}$／分子信标／$\mathrm{FRET}$） |
|--|--------------------------------------|--------------------------------------------------------|
| 荧光何时亮 | 插入／结合双链 $\mathrm{DNA}$（小沟） | 与靶杂交或引导扩增时 |
| 序列特异？ | 染料本身不认序列 | 多一步互补识别，特异更高 |
| 倍数关系 | 结合后荧光约 $1\,000$ 倍于游离染料；强度 $\propto$ 产物量 | 荧光指示特异产物增加 |
| 多色 | 教材未把多色写在这一类 | 可多色，一管同时看数种基因 |
| 成本与场景 | 低廉简便，基因表达定量常用 | 更高特异，适合突变、分型、多靶 |

两类都是实时荧光，差别在「亮的是不是这条序列」。
:::

#### 3. 实时 PCR 具有广泛的应用场景

实时荧光 $\mathrm{PCR}$ 技术具有定量、特异、灵敏和快速等特点，是检测目的核酸及拷贝数的可靠方法，是核酸定量技术的一次飞跃，已逐渐替代 $\mathrm{RNA}$ 印迹法等技术。目前实时荧光 $\mathrm{PCR}$ 技术已经被广泛应用于基础科学研究、临床诊断、疾病研究及药物研发等领域。

:::definition{label="实时 PCR 相对 Northern 的位置"}
定量、特异、灵敏、快速，是检测目的核酸及拷贝数的可靠方法，核酸定量的一次飞跃，已逐渐替代 $\mathrm{RNA}$ 印迹法等技术。
:::

:::insight{label="「逐渐替代」对着的是定量，第一节仍承认 Northern 可靠"}
Northern：敏感性较低，但特异强、假阳性低，仍是最可靠 $\mathrm{RNA}$ 定量方法之一。实时 $\mathrm{PCR}$：更快更准，逐渐替代。两句话都要留：考试问「最可靠之一」走 Northern，问「临床基因诊断常用准确定量」走 $\mathrm{qPCR}$。
:::

**（1）实时 PCR 用于肿瘤早期诊断、鉴别、分型、分期、治疗及预后评估**　实时定量 $\mathrm{PCR}$ 不但能有效地检测基因的突变、重排、易位等，而且能准确检测肿瘤相关基因表达量。实时荧光定量 $\mathrm{PCR}$ 检测基因突变，可通过设计跨越疑似突变位点的特异性荧光探针，然后进行基因扩增，再对扩增产物进行缓慢加热获得熔解曲线，根据熔解曲线特征判断有无突变。也可使用双色或多色标记探针，检测野生型和不同突变体。

:::definition{label="实时 PCR 在肿瘤"}
用于早期诊断、鉴别、分型、分期、治疗及预后评估。既能检测突变、重排、易位，又能准确检测肿瘤相关基因表达量。
:::

:::definition{label="熔解曲线判断突变"}
设计跨越疑似突变位点的特异性荧光探针 $\rightarrow$ 扩增 $\rightarrow$ 对产物缓慢加热得熔解曲线 $\rightarrow$ 按曲线特征判断有无突变。也可用双色或多色探针检测野生型与不同突变体。
:::

:::pitfall{label="熔解曲线是扩增之后缓慢加热，不是第四步循环温度"}
循环仍是三步。熔解是对扩增产物另外做的升温分析。不要写成「变性、退火、延伸、熔解」四步 $\mathrm{PCR}$。
:::

**（2）实时 PCR 用于基因多态性分析**　实时定量 $\mathrm{PCR}$ 技术在单核苷酸多态性（single nucleotide polymorphism，$\mathrm{SNP}$）分析方面亦有很好的应用前景，例如用于预测药物在同一疾病不同个体内的效应差异所致的治疗反应性不同，按照基因多态性的特点用药，将会使临床治疗符合精准化和个体化的要求。

:::definition{label="实时 PCR 分析 SNP"}
用于单核苷酸多态性（$\mathrm{SNP}$）分析。例：预测同一疾病不同个体因药物效应差异导致的治疗反应性不同，按多态性特点用药，走向精准化和个体化。
:::

:::pitfall{label="SNP 不是肿瘤突变的别名"}
肿瘤条写突变、重排、易位；本条写群体／个体间的单核苷酸多态性与用药。两本账都可以用实时 $\mathrm{PCR}$，问题不同。
:::

**（3）实时 PCR 用于病原体的检测**　实时定量 $\mathrm{PCR}$ 技术还可用于细菌、病毒、支原体、衣原体等病原体的检测，不仅能对病原体定性，而且由于其检测的批间和批内差异小，重复性好，因此能方便、快速、灵敏、准确地定量病原体的特征 $\mathrm{DNA}$ 或 $\mathrm{RNA}$ 序列，动态观测病程中潜在病原体数量。与传统的检测方法相比，具有灵敏度高、取样少、快速简便等优点。例如，在乙型肝炎病毒（$\mathrm{HBV}$）感染中，乙肝表面抗原（$\mathrm{HBsAg}$）很难判断患者体内的 $\mathrm{HBV}$ 是否处于复制期，病毒复制的量又如何，以及是否具有传染性。而利用实时荧光 $\mathrm{PCR}$ 技术，可准确地检测出患者血液中 $\mathrm{HBV}$ 的拷贝数，实时监测感染者的药物治疗效果和临床状态。

:::definition{label="实时 PCR 检测病原体"}
用于细菌、病毒、支原体、衣原体等。既能定性，又能因批间、批内差异小、重复性好，定量特征 $\mathrm{DNA}$ 或 $\mathrm{RNA}$，动态观测病程中潜在病原体数量。相对传统方法：灵敏度高、取样少、快速简便。
:::

:::definition{label="HBV 拷贝数是 HBsAg 做不到的那一问"}
$\mathrm{HBsAg}$ 很难判断 $\mathrm{HBV}$ 是否处于复制期、复制量如何、是否具有传染性。实时荧光 $\mathrm{PCR}$ 可准确检测血液中 $\mathrm{HBV}$ 拷贝数，监测药物治疗效果和临床状态。
:::

:::insight{label="病原体这条把「特征 DNA 或 RNA」写在一起"}
$\mathrm{DNA}$ 病毒可以直接 $\mathrm{PCR}$；$\mathrm{RNA}$ 病毒要先走逆转录再实时定量。教材在病原体应用里并写特征 $\mathrm{DNA}$ 或 $\mathrm{RNA}$，原理上仍是本节的 $\mathrm{PCR}$ 或 $\mathrm{RT}$-$\mathrm{PCR}$ $+$ 实时荧光。
:::

:::pitfall{label="HBsAg 阳性不等于知道拷贝数"}
表面抗原解决不了「在不在复制、有多少、传不传」。拷贝数是核酸定量，不是抗原定性。把两项等同，实时 $\mathrm{PCR}$ 在肝炎监测里就没有独立地位。
:::

:::compare{title="实时 PCR 三条应用"}
| | 看什么 | 教材手法 |
|--|--------|----------|
| 肿瘤 | 突变／重排／易位；相关基因表达量 | 跨突变位点探针；熔解曲线；双色／多色分野生型与突变体 |
| 多态性 | $\mathrm{SNP}$ | 预测药物反应差异，个体化用药 |
| 病原体 | 细菌、病毒、支原体、衣原体的特征核酸 | 定性 $+$ 定量拷贝数；$\mathrm{HBV}$ 例对照 $\mathrm{HBsAg}$ |

三条都用「指数期荧光 $\rightarrow$ 起始拷贝数」，靶不同。
:::

:::memory{label="本节 PCR 一张清单"}
- 发明：$\mathrm{Mullis}\ \mathrm{K}.$，$1983$，体外模拟复制。
- 体系：模板、特异引物、耐热酶（$\mathrm{Taq}$）、$\mathrm{dNTP}$、含 $\mathrm{Mg}^{2+}$ 缓冲液。
- 三步：变性 $95^\circ\mathrm{C}$（图 $94^\circ\mathrm{C}$）；退火约 $T_\mathrm{m}-5^\circ\mathrm{C}$（图 $55^\circ\mathrm{C}$）；延伸 $72^\circ\mathrm{C}$。$25\sim 30$ 循环，百万倍以上。
- 第一轮长产物（$3'$ 无止点）；第二轮起短产物（两引物 $5'$ 端之间）指数增加。
- 用途：获目的片段／体外改造；微量定性定量（理论 $1$ 分子；一滴血、一根毛发、一个细胞）；简化测序；与其他技术结合查突变。
- $\mathrm{RT}$-$\mathrm{PCR}$：$\mathrm{RNA}\rightarrow\mathrm{cDNA}$；单细胞少于 $10$ 拷贝；定性／半定量；最广泛衍生。
- 原位 $\mathrm{PCR}$：固定切片或涂片的单个细胞内扩增 $+$ 原位杂交。
- 实时／$\mathrm{qPCR}$：每轮荧光；指数期定量。$\mathrm{SYBR\ Green}$ 结合双链，荧光约 $1\,000$ 倍；探针类更特异、可多色。
- 应用：肿瘤、$\mathrm{SNP}$、病原体（$\mathrm{HBV}$ 拷贝数 vs $\mathrm{HBsAg}$）。
:::

:::memory{label="三个不要对调的数字"}
- $25\sim 30$ 次循环 $\rightarrow$ 扩增百万倍以上。
- $\mathrm{SYBR\ Green}$ 结合双链后荧光约为游离的 $1\,000$ 倍。
- $\mathrm{RT}$-$\mathrm{PCR}$ 可检出单个细胞中少于 $10$ 个拷贝的特异 $\mathrm{RNA}$。
:::
