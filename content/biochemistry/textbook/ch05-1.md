# 第一节　水

本章打开水和无机元素。先把液态水写成生命存在的基础：形态、溶剂、结合水与自由水、氢键与非共价键、两性电离与缓冲、脱水。无机元素按人体每日需要量分成常量元素与微量元素；钠、钾、氯、镁放到病理生理学，钙、磷和铁、锌、铜、锰、硒、碘、钴、氟、铬在第二节按教材职分摊开。

组成人体的元素和物质很多，其中无机元素对维持人体正常生理功能必不可少，而液态水是生命存在的基础。水是人体的基本组成成分，在维持组织、细胞的形态、物质在体内的运输、调节体温、润滑关节以及参与物质代谢等方面具有十分重要的作用。无机元素按人体每日需要量的多少可分为微量元素（trace element / microelement）和常量元素（macroelement）。微量元素指人体每日需要量在 $100\,\mathrm{mg}$ 以下的化学元素，主要包括铁、碘、铜、锌、锰、硒、氟、钼、钴、铬等。常量元素主要有钠、钾、氯、钙、磷、镁等。钠、钾、氯、镁的代谢和生理功能将在病理生理学中详细介绍。

:::definition{label="微量元素"}
微量元素（trace element / microelement）指人体每日需要量在 $100\,\mathrm{mg}$ 以下的化学元素，主要包括铁、碘、铜、锌、锰、硒、氟、钼、钴、铬等。名词对照亦作 microelement；章末名词解释把界限定为“小于 $100\,\mathrm{mg}$”，与此处“在 $100\,\mathrm{mg}$ 以下”同一本账。
:::

:::definition{label="常量元素"}
常量元素（macroelement）按人体每日需要量划分，主要有钠、钾、氯、钙、磷、镁等。英文 macroelement 也常被说成宏量元素，户头仍是每日需要量，不是“体内存量最大”。
:::

:::compare{title="常量元素与微量元素（按教材名单写全）"}
| 项目 | 常量元素（macroelement） | 微量元素（trace element / microelement） |
|------|--------------------------|------------------------------------------|
| 划分钥匙 | 人体每日需要量 | 每日需要量在 $100\,\mathrm{mg}$ 以下 |
| 教材列出的成员 | 钠、钾、氯、钙、磷、镁等 | 铁、碘、铜、锌、锰、硒、氟、钼、钴、铬等 |
| 本章展开 | 钙、磷（第二节专节） | 铁、锌、铜、锰、硒、碘、钴、氟、铬（第二节专节） |
| 本章不展开 | 钠、钾、氯、镁：代谢和生理功能在病理生理学中详细介绍 | 钼：列入名单，未设专节，不要另造职分 |
:::

:::pitfall{label="常量不是“体内最多”，微量也不是“可有可无”"}
划分标准是每日需要量，不是体内总存量。铁是体内含量最多的微量元素，仍走微量那一本账。钠、钾、氯、镁是常量元素，但本章明确交给病理生理学，不要在本节补一套离子泵。钼写在微量名单里，没有专节就不要发明缺乏症。
:::

:::concept{term="先问液态水在不在，再问无机元素是常量还是微量"}
看见“水和无机元素”，先不要跳到铁和锌。液态水是生命存在的基础，也是最好的溶剂；无机元素再按每日需要量分户。把水听成“只是溶剂、不算组成”，结合水和体温调节会没有户头；把常量听成宏量再把钠钾写进本节，病理生理学那一笔会对不上。
:::

地球上的生命经历了被称为“化学演变”复杂的分子形成过程。这一过程涉及许多不同物质的混合和反应。反应需要溶剂，液态水是最好的溶剂，尤其适合溶解生命世界中的许多物质，提供相互碰撞和反应的介质。生命在进入陆地之前已在海洋中产生并生存了数亿年，这一事实充分地证明了水的重要性。如果没有液态水，生命无法进化。水具有十分重要的生理功能，因生理或病理原因导致体内缺水时，机体多种功能受到影响，并随缺水程度的不同，引起相应的病理生理变化，甚至危及生命。

:::definition{label="液态水作为生命溶剂"}
反应需要溶剂。液态水是最好的溶剂，尤其适合溶解生命世界中的许多物质，提供相互碰撞和反应的介质。没有液态水，生命无法进化。
:::

:::insight{label="先有液态水，才有化学演变里的碰撞和反应"}
教材把生命写成在海洋里产生并生存了数亿年，再登上陆地。缺的不是“有没有 $\mathrm{H}_2\mathrm{O}$ 这个分子式”，而是液态这个相：气态、固态都不能当那种溶剂。后面结合水、缓冲、脱水，户头都在液态水。
:::

## 一、水是生命之源

### （一）水以多种形态存在于自然界

水分子以液、气、固等多种形态存在。常温常压液态的被称为水；气态的水被称为水蒸气；固态的水被称为冰。冰的熔点是 $0^{\circ}\mathrm{C}$，其密度为 $0.9\,\mathrm{g}/\mathrm{cm}^{3}$。水体积最小时为 $4^{\circ}\mathrm{C}$，当水冻结成冰时，体积可增大约 $1/9$。水蒸气冷凝后成为液态小水滴。当在临界温度及压力（$647\,\mathrm{K}$ 及 $22.064\,\mathrm{MPa}$）时，水分子为一种“超临界”状态，液态般的水滴漂浮于气态之中。水具有反常的热胀冷缩特性，当水低于 $4^{\circ}\mathrm{C}$ 时热缩冷胀，导致密度下降，而高于 $4^{\circ}\mathrm{C}$ 时，则恢复热胀冷缩。普通水中的氢原子被其核素氘所取代而形成的水被称为重水，其化学性质和普通水基本一致，常用于核反应堆中减速中子。标准大气压下，水的冰点为 $0^{\circ}\mathrm{C}$，沸点为 $100^{\circ}\mathrm{C}$。重水的冰点是 $3.8^{\circ}\mathrm{C}$。许多物质加入水中都可以降低水的冰点，如甲醇、乙醇、甘油、氯化钙等。水的这种特性是设计抗冻物质的基础。

:::definition{label="水的三相"}
水分子以液、气、固等多种形态存在。常温常压液态称为水；气态称为水蒸气；固态称为冰。
:::

:::definition{label="冰的熔点与密度"}
冰的熔点是 $0^{\circ}\mathrm{C}$，密度为 $0.9\,\mathrm{g}/\mathrm{cm}^{3}$。水体积最小时为 $4^{\circ}\mathrm{C}$；冻结成冰时体积可增大约 $1/9$。
:::

:::definition{label="超临界水"}
临界温度及压力为 $647\,\mathrm{K}$ 及 $22.064\,\mathrm{MPa}$ 时，水分子处于“超临界”状态：液态般的水滴漂浮于气态之中。
:::

:::definition{label="重水"}
普通水中的氢原子被其核素氘所取代而形成的水称为重水。化学性质与普通水基本一致，常用于核反应堆中减速中子。标准大气压下普通水冰点 $0^{\circ}\mathrm{C}$、沸点 $100^{\circ}\mathrm{C}$；重水冰点 $3.8^{\circ}\mathrm{C}$。
:::

:::keypoint{label="水的反常热胀冷缩与抗冻"}
- 低于 $4^{\circ}\mathrm{C}$：热缩冷胀，密度下降。
- 高于 $4^{\circ}\mathrm{C}$：恢复热胀冷缩。
- 体积最小在 $4^{\circ}\mathrm{C}$；成冰体积约增 $1/9$，故冰密度小于液态水。
- 甲醇、乙醇、甘油、氯化钙等加入水中可降低冰点，是设计抗冻物质的基础。
:::

:::pitfall{label="4℃ 是体积最小，不是冰的熔点"}
熔点、冰点在标准大气压下仍是 $0^{\circ}\mathrm{C}$。$4^{\circ}\mathrm{C}$ 是液态水密度最大、体积最小。把两笔并成“水在 $4^{\circ}\mathrm{C}$ 结冰”，热胀冷缩和“冰能浮在水面”都会讲反。
:::

### （二）水在人体内具有十分重要的生理功能

水是人体的基础组成成分之一。人体含有大量水，水在人体的比重随年龄的增长不断减少。胎儿时约占 $90\%$，婴儿时约为 $80\%$，青壮年时约占 $70\%$，老年时仅为 $60\%\sim 50\%$。人的老化过程也包含了水丢失的过程。人体内不同组织器官含水比重不同，以成年人为例，含水最多的是脑脊髓组织，约占 $99\%$；血液约有 $83\%$ 的水；肌肉含水约为 $77\%$；骨骼虽硬，但也含约 $20\%$ 的水。

:::timeline{period="人体含水量随年龄减少"}
- **胎儿** 约占 90%
- **婴儿** 约为 80%
- **青壮年** 约占 70%
- **老年** 仅为 60%～50%；老化过程也包含水丢失
:::

:::compare{title="成年不同组织的含水比重"}
| 组织 | 含水比重（教材） |
|------|------------------|
| 脑脊髓组织 | 约占 $99\%$，成年含水最多 |
| 血液 | 约 $83\%$ |
| 肌肉 | 约 $77\%$ |
| 骨骼 | 约 $20\%$，虽硬仍含水 |
:::

:::definition{label="水作为媒介和载体"}
水是生物大分子（蛋白质、核酸、酶、糖复合物等）的组成之一。没有水，体现生命现象的功能就不能实现。水是媒介和载体，与生物大分子共同完成能量产生与利用、物质代谢和信息传递。
:::

**1. 维持组织、细胞的形态**　体内的水以自由水的形式分布于细胞内液和细胞外液之中，此外，还有一部分水与蛋白质、核酸和蛋白多糖等物质结合，以结合水的形式存在。结合水参与构成细胞的原生质，维持组织器官的特殊形态、硬度和弹性，是某些特殊生理功能正常发挥的物质基础。例如心肌和血液均含 $80\%$ 左右的水，血液中结合水较少，而心肌含较多的结合水，使得心肌呈坚实形态。

:::definition{label="自由水"}
自由水以自由水的形式分布于细胞内液和细胞外液之中，是体内水的一种存在形式。
:::

:::definition{label="结合水"}
结合水与蛋白质、核酸和蛋白多糖等物质结合而存在。它参与构成细胞的原生质，维持组织器官的特殊形态、硬度和弹性，是某些特殊生理功能正常发挥的物质基础。
:::

:::compare{title="自由水与结合水"}
| 项目 | 自由水 | 结合水 |
|------|--------|--------|
| 存在方式 | 分布于细胞内液和细胞外液 | 与蛋白质、核酸和蛋白多糖等结合 |
| 功能落点 | 流动、溶剂、运输的底子 | 构成原生质；维持形态、硬度和弹性 |
| 教材对照 | 血液含水量高、结合水较少，易流动 | 心肌含较多结合水，呈坚实形态 |
| 共同点 | 心肌和血液均含约 $80\%$ 的水，差别在结合水多少，不在总含水 | 同左 |
:::

:::example{label="心肌和血液都含水约 80%，形态却不同"}
心肌和血液均含 $80\%$ 左右的水。血液结合水较少，能流动；心肌结合水较多，呈坚实形态。总含水百分比相同，不能推出“组织软硬一样”。
:::

**2. 运输物质**　水是良好的溶剂，因其黏度小而易流动，有利于营养物质和代谢产物在体内的运输。人体血液含水量较高，是血液循环的基础，具有载体和流通作用。水溶性物质可溶解在水中进行运输，而一些不溶于水的物质如脂质，可通过与亲水的蛋白质分子结合而稳定地存在于水中，通过血液循环被输送至身体各个部位。水在血管、细胞之间进行流动，将氧和营养物质运送到组织细胞，再把代谢废物排出体外。

:::definition{label="水的运输作用"}
水黏度小而易流动，是良好溶剂，利于营养物质和代谢产物运输。血液含水量高，是循环的基础。水溶性物质直接溶于水中运输；脂质等不溶物可与亲水蛋白质结合后稳定存在于水中，随血液循环运送。水在血管与细胞之间流动，送氧和营养，运出代谢废物。
:::

**3. 参与物质代谢**　人的各种生理活动都需要水。水可以溶解各种营养物质，脂肪和蛋白质等需要成为悬浮于水中的胶体状态才能被吸收；许多代谢反应需要水的直接参与，如水解反应、加水反应和加水脱氢反应等。

:::definition{label="水参与物质代谢"}
水溶解各种营养物质；脂肪和蛋白质等需成为悬浮于水中的胶体状态才能被吸收。许多代谢反应需要水直接参与，如水解反应、加水反应和加水脱氢反应等。
:::

**4. 润滑作用**　水是体内的润滑剂，具有良好的润滑作用。皮肤缺水就会变得干燥而失去弹性；泪液可以防止眼球干燥，有利于眼球的转动；唾液湿润咽部，有利于食物吞咽；胸腔和腹腔的浆液以及呼吸道和消化道的黏液可以减少摩擦，有利于呼吸和消化功能的发挥；关节液能滑润关节，使关节灵活运动。

:::definition{label="水的润滑作用"}
水是体内的润滑剂。教材点名：皮肤弹性、泪液润滑眼球、唾液助吞咽、胸腹腔浆液及呼吸道消化道黏液减摩擦、关节液滑润关节。
:::

**5. 调节体温**　水参与体温的调节与其特性密切相关。

（1）水的比热容高：体内因含有大量的水，在代谢过程中所产生的热能多被水吸收，保持体温相对恒定。

（2）水的蒸发热大：当机体在 $37^{\circ}\mathrm{C}$ 时，每毫升水的蒸发热为 $2424.6\,\mathrm{J}$，蒸发少量水即可散发体内贮存的大量热。

（3）水的导热性强：水为非金属导热体，虽各组织代谢强度、产热量不一样，但可通过水的导热作用来保证机体各组织和器官间的温度趋于一致。

环境温度高于体温时，通过出汗，使水蒸发并带走一部分热量而降低体温；环境温度低于体温时，水因其有较大的贮备热量能力，使得人体不致因外界温度低而导致体温发生明显的波动。

:::compare{title="水调节体温的三项特性"}
| 特性 | 教材落点 | 生理后果 |
|------|----------|----------|
| 比热容高 | 代谢产热多被水吸收 | 体温相对恒定 |
| 蒸发热大 | $37^{\circ}\mathrm{C}$ 时每毫升水蒸发热 $2424.6\,\mathrm{J}$ | 蒸发少量水即可散热；环境温度高于体温时出汗蒸发降温 |
| 导热性强 | 非金属导热体 | 各组织产热不同，器官间温度仍趋于一致；环境温度低于体温时，贮备热量能力使体温不致明显波动 |
:::

:::keypoint{label="水的五项生理功能"}
- 维持组织、细胞形态：自由水在细胞内、外液；结合水维持形态、硬度和弹性。
- 运输物质：溶剂、黏度小；脂质靠亲水蛋白质捎带。
- 参与物质代谢：溶解、胶体吸收；水解、加水、加水脱氢。
- 润滑：皮肤、泪液、唾液、浆液黏液、关节液。
- 调节体温：比热容高、蒸发热大、导热性强。
:::

:::tip{label="五项功能先问水在哪一种形态干活"}
形态靠结合水，运输靠自由水流动，代谢要水当反应物，润滑看局部液体，体温看比热、蒸发热和导热。不要把五项都写成“因为水是溶剂”。
:::

## 二、水溶液中的非共价键是稳定生物大分子结构和功能的重要因素之一

### （一）水分子由两个氢原子与一个氧原子以单键结合而成

由于水分子氧的电负性很高，共用电子强烈地偏向于氧原子的一边，而使氢原子显示出较大的电正性，即氧原子带有部分负电荷，而氢原子带有部分正电荷，导致水分子具有明显的极性（图5-1）。游离状态下的水分子因电性吸引由氢键而形成二个至几十个水分子的结合体（图5-2）。

:::definition{label="水分子"}
水分子由两个氢原子与一个氧原子以单键结合而成。氧电负性高，共用电子偏向氧，氧带部分负电荷（$\delta^{-}$），氢带部分正电荷（$\delta^{+}$），水分子具有明显极性。
:::

:::note{label="图5-1、图5-2 与教材对齐"}
图5-1 落极性：$\delta^{+}$、$\delta^{-}$ 和氧上的孤对电子。图5-2 落氢键把两个水分子连成结合体；图中给出键角、氢键长度和共价键长度，正文强调游离水分子可因电性吸引由氢键形成二个至几十个水分子的结合体。
:::

### （二）氢键是水分子之间形成的非共价键

水分子中的氧原子和氢原子电子云分布不均匀，使其成为一个强偶极子。水分子发生电荷的共用及再分配，一个水分子中的氢原子能够与附近另一水分子中的氧原子发生正负电荷相吸现象，从而在邻近水分子之间形成一种相互连接的作用力，即在电子供体与受体之间形成了“氢键”。一个水分子可以形成 $4$ 个氢键，与 $4$ 个水分子结合，形成四面体。水分子亦可进入四面体中，形成配位数大于 $4$ 的水结构。氢键属于非共价键，在自身热运动和外环境的影响下易断裂与重建。水结构的易变性及氢键网络把水分子聚集在一起的集团作用，赋予水对生命具有重要意义的特性。

氢键具有方向性和饱和性。形成氢键的原子只能大致处于一条直线上且仅能形成一个氢键。生物大分子间的互相识别是一个结构域构象互补的识别过程。只有两个分子相互结合的结构域内的每一个成氢键原子都能在另一分子上找到对位的原子，才能形成稳定的氢键。

:::definition{label="氢键"}
氢键是水分子之间形成的非共价键：一个水分子中的氢原子与附近另一水分子中的氧原子正负相吸，在电子供体与受体之间形成相互连接的作用力。一个水分子可形成 $4$ 个氢键，与 $4$ 个水分子结合成四面体；水分子亦可进入四面体，配位数可大于 $4$。
:::

:::definition{label="氢键的方向性和饱和性"}
形成氢键的原子只能大致处于一条直线上，且仅能形成一个氢键。这就是方向性和饱和性。
:::

:::cause-effect{title="氢键网络为什么对生命重要"}
- **因** 氢键属非共价键，热运动和外环境影响下易断裂与重建；四面体网络又把水分子聚集在一起
- **果** 水结构易变，又有集团作用，赋予水对生命具有重要意义的特性（溶剂、比热、蒸发热、冰密度小于液态水等）
:::

:::insight{label="大分子识别不是“有几个氢键就行”，要对上每一个成氢键原子"}
生物大分子互相识别是结构域构象互补。只有结合界面上每一个成氢键原子都能在对方找到对位原子，氢键才稳定。把氢键听成“随便靠近就能拉住”，酶–底物、激素–受体后面那一笔会对错精度。
:::

### （三）水溶液中的非共价键影响大分子物质的结构与功能

水溶液中除氢键外，还存在离子键、疏水键和范德瓦耳斯力（又称范德华力）等非共价键。这四种非共价键各自单独与共价键相比其键能均较弱，但多个非共价键共同作用后的累积效应对稳定大分子物质的结构十分重要。大分子物质（$\mathrm{DNA}$、蛋白质等）的空间结构的稳定需多种非共价键，如 $\mathrm{DNA}$ 的双螺旋结构、蛋白质的 $\alpha$-螺旋、$\beta$-折叠等均需要氢键等非共价键的存在。当一些因素影响这些非共价键的稳定性，大分子物质的空间结构将受影响，若溶液 $\mathrm{pH}$ 的改变将影响蛋白质分子中氢键的形成，从而改变蛋白质的空间结构，使其生物学性质发生变化。如酸、碱溶液引起蛋白质的变性等。

大分子物质的空间结构的正确是其功能的保证。大分子之间相互作用也需要非共价键的参与。如激素或神经递质与细胞膜受体的结合是多种非共价键相互作用的结果。在分子水平上，生物大分子之间的相互作用反映了分子表面的极性、带电和疏水基团之间的互补性和弱相互作用。当任何改变分子表面基团的极性和非共价键形成的因素均影响大分子之间的相互作用，其功能将部分或全部丧失。酶与底物的结合也遵循上述原则，如图5-3 所示。

:::definition{label="水溶液中的四种非共价键"}
水溶液中除氢键外，还有离子键、疏水键和范德瓦耳斯力（范德华力）。四种各自单独比共价键弱，多个共同作用的累积效应对稳定大分子结构十分重要。
:::

:::compare{title="四种非共价键：弱，但要靠累积"}
| 种类 | 教材落点 | 不要听成 |
|------|----------|----------|
| 氢键 | 水分子之间；$\mathrm{DNA}$ 双螺旋、蛋白质 $\alpha$-螺旋、$\beta$-折叠都需要 | 和共价键一样牢固、不会断 |

:::

## 三、水是一种既能释放质子也能接受质子的两性物质

### （一）水可电离为 H₃O⁺ 离子和 OH⁻ 离子

水是一种酸碱两性物质，在水分子之间可以发生质子的传递，$1$ 个水分子能从另 $1$ 个水分子中得到质子而形成 $\mathrm{H}_3\mathrm{O}^{+}$ 离子（水合氢离子，hydronium ion），而失去质子的水分子则成为 $\mathrm{OH}^{-}$ 离子，即水分子既能释放质子也能接受质子。也可理解为 $1$ 分子水可电离成 $\mathrm{H}^{+}$ 和 $\mathrm{OH}^{-}$。这类发生在同种溶剂分子之间的质子传递作用称为质子自递反应（也称水的电离反应）。

:::definition{label="水的两性"}
水是酸碱两性物质：既能释放质子也能接受质子。$1$ 个水分子从另 $1$ 个水分子得到质子形成 $\mathrm{H}_3\mathrm{O}^{+}$（水合氢离子，hydronium ion），失去质子的成为 $\mathrm{OH}^{-}$。也可理解为 $1$ 分子水电离成 $\mathrm{H}^{+}$ 和 $\mathrm{OH}^{-}$。
:::

:::definition{label="质子自递反应"}
发生在同种溶剂分子之间的质子传递作用称为质子自递反应，也称水的电离反应。
:::

$$
2\mathrm{H}_2\mathrm{O}\rightleftharpoons\mathrm{H}_3\mathrm{O}^{+}+\mathrm{OH}^{-}
$$

也可写成：

$$
\mathrm{H}_2\mathrm{O}\rightleftharpoons\mathrm{H}^{+}+\mathrm{OH}^{-}
$$

:::note{label="两式是同一本账"}
教材先写水合氢离子 $\mathrm{H}_3\mathrm{O}^{+}$，再写“也可理解为”电离成 $\mathrm{H}^{+}$ 和 $\mathrm{OH}^{-}$。后面离子积用 $[\mathrm{H}_3\mathrm{O}^{+}][\mathrm{OH}^{-}]$，酸碱度又写可用 $\mathrm{H}_3\mathrm{O}^{+}$（$\mathrm{H}^{+}$）或 $\mathrm{OH}^{-}$ 的浓度表示。不要把 $\mathrm{H}^{+}$ 听成溶液里真有裸质子在飞。
:::

### （二）水溶液的酸碱度可用 pH 来表示

在一定温度下水的电离反应达到平衡时，存在如下关系：

$$
[\mathrm{H}_3\mathrm{O}^{+}][\mathrm{OH}^{-}]=K[\mathrm{H}_2\mathrm{O}]^{2}=K_{\mathrm{W}}
$$

公式中 $K_{\mathrm{W}}$ 称为水的离子积常数。在一定温度下，纯水中 $\mathrm{H}_3\mathrm{O}^{+}$ 离子的平衡浓度与 $\mathrm{OH}^{-}$ 离子的平衡浓度的乘积为一定值（室温下一般为 $K_{\mathrm{W}}=1.0\times 10^{-14}$）。此关系也适用于任何水溶液，若已知溶液中 $\mathrm{H}_3\mathrm{O}^{+}$ 离子浓度，利用该公式可计算出溶液中 $\mathrm{OH}^{-}$ 离子浓度。因此，水溶液的酸度或碱度均可用 $\mathrm{H}_3\mathrm{O}^{+}$（$\mathrm{H}^{+}$）或 $\mathrm{OH}^{-}$ 的浓度来表示。

:::definition{label="水的离子积常数"}
$K_{\mathrm{W}}$ 称为水的离子积常数。一定温度下，纯水中 $[\mathrm{H}_3\mathrm{O}^{+}]$ 与 $[\mathrm{OH}^{-}]$ 的乘积为定值；室温下一般为 $K_{\mathrm{W}}=1.0\times 10^{-14}$。该关系也适用于任何水溶液。
:::

:::derivation{title="由离子积互算 [H3O+] 与 [OH−]"}
平衡时

$$
[\mathrm{H}_3\mathrm{O}^{+}][\mathrm{OH}^{-}]=K_{\mathrm{W}}
$$

室温 $K_{\mathrm{W}}=1.0\times 10^{-14}$。已知 $[\mathrm{H}_3\mathrm{O}^{+}]$ 即可算 $[\mathrm{OH}^{-}]$，反之亦然。酸碱度都落在这两种浓度上；本节标题所说的 $\mathrm{pH}$，教材是用 $\mathrm{H}_3\mathrm{O}^{+}$（$\mathrm{H}^{+}$）或 $\mathrm{OH}^{-}$ 的浓度来表示水溶液的酸度或碱度。
:::

:::pitfall{label="Kw 是乘积为定值，不是 [H3O+] 永远等于 [OH−]"}
纯水里两者相等；任何水溶液里乘积仍为 $K_{\mathrm{W}}$，但酸溶液 $[\mathrm{H}_3\mathrm{O}^{+}]$ 升高则 $[\mathrm{OH}^{-}]$ 下降。把离子积听成“任何溶液都中性”，缓冲和血液 $\mathrm{pH}$ 会没有台阶。
:::

### （三）水分子参与缓冲体系的形成

缓冲溶液是一种特殊的水溶液系统，能在一定程度上抵消或减轻外加强酸或强碱对溶液酸碱度的影响，从而保持溶液的 $\mathrm{pH}$ 相对稳定，与维持人体正常的血液 $\mathrm{pH}$、肺的呼吸功能、肾的排泄和重吸收功能以及物质代谢产生的酸碱性代谢产物清除等密切相关。缓冲体系主要由弱酸（$\mathrm{H}^{+}$ 供体）和它的共轭碱（$\mathrm{H}^{+}$ 受体）组成。在缓冲溶液中发生的质子反应，使得水分子产生 $\mathrm{H}_3\mathrm{O}^{+}$ 和 $\mathrm{OH}^{-}$，水合氢离子浓度取决于弱酸与其共轭碱的浓度比。当加入少量强碱时，酸被中和，导致溶液中 $\mathrm{OH}^{-}$ 的累积很少，$\mathrm{H}_3\mathrm{O}^{+}$ 浓度变化也很小；反之加入少量弱酸则是相似的结果。因此，由于水分子参与缓冲体系的形成和对外来酸、碱物质引起质子变化的缓冲，维持了体系内 $\mathrm{H}_3\mathrm{O}^{+}$ 和 $\mathrm{OH}^{-}$ 浓度的平衡而导致溶液 $\mathrm{pH}$ 的相对恒定。

:::definition{label="缓冲溶液"}
缓冲溶液是一种特殊的水溶液系统，能在一定程度上抵消或减轻外加强酸或强碱对溶液酸碱度的影响，从而保持溶液的 $\mathrm{pH}$ 相对稳定。
:::

:::definition{label="缓冲体系的组成"}
缓冲体系主要由弱酸（$\mathrm{H}^{+}$ 供体）和它的共轭碱（$\mathrm{H}^{+}$ 受体）组成。水合氢离子浓度取决于弱酸与其共轭碱的浓度比。
:::

:::cause-effect{title="水分子如何参与缓冲"}
- **因** 缓冲溶液中的质子反应使水分子产生 $\mathrm{H}_3\mathrm{O}^{+}$ 和 $\mathrm{OH}^{-}$；加入少量强碱时酸被中和，$\mathrm{OH}^{-}$ 累积很少，$[\mathrm{H}_3\mathrm{O}^{+}]$ 变化很小；加入少量酸则是相似结果
- **果** 水分子参与缓冲体系的形成，并对外来酸、碱引起的质子变化起缓冲，维持 $[\mathrm{H}_3\mathrm{O}^{+}]$ 与 $[\mathrm{OH}^{-}]$ 平衡，溶液 $\mathrm{pH}$ 相对恒定
:::

:::keypoint{label="缓冲跟哪些生理过程相关"}
- 维持人体正常的血液 $\mathrm{pH}$。
- 肺的呼吸功能。
- 肾的排泄和重吸收功能。
- 物质代谢产生的酸碱性代谢产物清除。
:::

:::tip{label="缓冲先找弱酸–共轭碱这一对，再问水从哪边补质子"}
没有弱酸（$\mathrm{H}^{+}$ 供体）和共轭碱（$\mathrm{H}^{+}$ 受体），水自己电离挡不住强酸强碱。第二节磷酸氢盐缓冲体系、钙磷代谢，户头都在这一对。
:::

## 四、水摄入不足或丢失过多可引起脱水

水以细胞外液和细胞内液形式存在于机体内。细胞外液占体重的 $20\%$，细胞内液占体重的 $40\%\sim 50\%$。总体液百分含量超过或低于正常范围均可发生生理性改变，机体可通过许多机制进行调节。下丘脑是水调节的神经中枢，控制口渴和排尿。随着缺水程度的不断增加，机体出现不同的症状。当机体失水量为体重的 $2\%$ 左右时，以细胞外液水丢失为主。此时下丘脑的口渴中枢受到刺激，出现摄水需求，同时排尿减少。若失水量达体重的 $4\%$ 左右，细胞内外液水的丢失量大致相等，导致脱水综合征的出现，表现为严重口渴感、心率加快、体温升高、疲劳及体温下降等症状。当失水量为体重的 $6\%\sim 10\%$ 时，细胞内液水丢失的比例增加，表现呼吸频率增加、血容量减少、恶心、厌食、易激怒、肌肉抽搐、精神活动减弱，甚至发生幻觉、谵语和昏迷等。

水摄入不足或水丢失过多，引起体内失水的现象被称为脱水。根据水与电解质丧失比例的不同可分为高渗性脱水、低渗性脱水和等渗性脱水三种类型，其发病机制将在病理生理学等课程介绍。

:::definition{label="体液分布"}
水以细胞外液和细胞内液形式存在。细胞外液占体重的 $20\%$，细胞内液占体重的 $40\%\sim 50\%$。
:::

:::definition{label="脱水"}
水摄入不足或水丢失过多，引起体内失水的现象称为脱水。按水与电解质丧失比例不同，分为高渗性脱水、低渗性脱水和等渗性脱水；发病机制在病理生理学等课程介绍。
:::

:::timeline{period="失水量增加时的表现"}
- **体重的 2% 左右** 以细胞外液水丢失为主；下丘脑口渴中枢受刺激，出现摄水需求，同时排尿减少
- **体重的 4% 左右** 细胞内外液水的丢失量大致相等；脱水综合征：严重口渴感、心率加快、体温升高、疲劳及体温下降
- **体重的 6%～10%** 细胞内液水丢失比例增加；呼吸频率增加、血容量减少、恶心、厌食、易激怒、肌肉抽搐、精神活动减弱，甚至幻觉、谵语和昏迷
:::

- [ ] 四种非共价键：氢键、离子键、疏水键、范德华力；单独弱，累积稳定 $\mathrm{DNA}$ 双螺旋、蛋白质 $\alpha$-螺旋和 $\beta$-折叠。
- [ ] $\mathrm{pH}$ 改变影响蛋白质氢键，可致变性；酶–底物结合伴随表面水分子脱离并形成氢键。
- [ ] 水是两性物质；质子自递：$2\mathrm{H}_2\mathrm{O}\rightleftharpoons\mathrm{H}_3\mathrm{O}^{+}+\mathrm{OH}^{-}$。
- [ ] $K_{\mathrm{W}}=[\mathrm{H}_3\mathrm{O}^{+}][\mathrm{OH}^{-}]$，室温一般为 $1.0\times 10^{-14}$；酸碱度用 $\mathrm{H}_3\mathrm{O}^{+}$（$\mathrm{H}^{+}$）或 $\mathrm{OH}^{-}$ 浓度表示。
- [ ] 缓冲：弱酸（$\mathrm{H}^{+}$ 供体）+ 共轭碱（$\mathrm{H}^{+}$ 受体）；与血液 $\mathrm{pH}$、肺、肾及酸性碱性代谢产物清除相关。
- [ ] 细胞外液占体重 $20\%$，细胞内液 $40\%\sim 50\%$；下丘脑控制口渴和排尿。
- [ ] 失水约 $2\%$：细胞外液为主，口渴、少尿；约 $4\%$：内外液大致相等，脱水综合征； $6\%\sim 10\%$：细胞内液比例增加，可至幻觉、谵语、昏迷。
- [ ] 脱水分高渗、低渗、等渗三类，机制在病理生理学介绍。
