# 第一节　核酸的化学组成及其一级结构

本章打开核酸的结构与功能。先把核酸分成 $\mathrm{DNA}$ 与 $\mathrm{RNA}$ 两本账，再落到基本组成：碱基、戊糖、磷酸；核苷、核苷酸；生物体内游离核苷酸多是 $5'$-核苷酸。第二节才写双螺旋。本节先把 $3',5'$-磷酸二酯键把核苷酸连成链、一级结构按 $5'\rightarrow 3'$ 书写摊开。

核酸（nucleic acid）是以核苷酸为基本组成单位的生物大分子，具有复杂的空间结构和重要的生物学功能。核酸可以分为脱氧核糖核酸（deoxyribonucleic acid，$\mathrm{DNA}$）和核糖核酸（ribonucleic acid，$\mathrm{RNA}$）两类。$\mathrm{DNA}$ 存在于细胞核和线粒体内，携带遗传信息，并通过复制的方式将遗传信息进行传代。细胞以及生物体的性状是由这种遗传信息决定的。一般而言，$\mathrm{RNA}$ 是 $\mathrm{DNA}$ 的转录产物，参与遗传信息的复制和表达。$\mathrm{RNA}$ 存在于细胞质、细胞核和线粒体内。在某些情况下，$\mathrm{RNA}$ 也可以作为遗传信息的载体。

:::definition{label="核酸"}
核酸（nucleic acid）是以核苷酸为基本组成单位的生物大分子，具有复杂的空间结构和重要的生物学功能。可以分为脱氧核糖核酸（deoxyribonucleic acid，$\mathrm{DNA}$）和核糖核酸（ribonucleic acid，$\mathrm{RNA}$）两类。
:::

:::definition{label="DNA"}
脱氧核糖核酸（deoxyribonucleic acid，$\mathrm{DNA}$）存在于细胞核和线粒体内，携带遗传信息，并通过复制的方式将遗传信息进行传代。细胞以及生物体的性状由这种遗传信息决定。
:::

:::definition{label="RNA"}
核糖核酸（ribonucleic acid，$\mathrm{RNA}$）一般而言是 $\mathrm{DNA}$ 的转录产物，参与遗传信息的复制和表达。存在于细胞质、细胞核和线粒体内。在某些情况下，$\mathrm{RNA}$ 也可以作为遗传信息的载体。
:::

:::compare{title="DNA 与 RNA（本节先立户头）"}
| 项目 | $\mathrm{DNA}$ | $\mathrm{RNA}$ |
|------|---------------|---------------|
| 全称 | 脱氧核糖核酸（deoxyribonucleic acid） | 核糖核酸（ribonucleic acid） |
| 基本组成单位 | 脱氧核糖核苷酸（deoxyribonucleotide） | 核糖核苷酸（ribonucleotide） |
| 细胞内部位 | 细胞核和线粒体 | 细胞质、细胞核和线粒体 |
| 教材先写的功能 | 携带遗传信息，通过复制传代；决定细胞及生物体性状 | 一般是转录产物，参与遗传信息的复制和表达；某些情况下也可作遗传信息载体 |
| 戊糖、嘧啶的差别 | 本节“一、二”展开：脱氧核糖；碱基为 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{T}$ | 核糖；碱基为 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{U}$ |
:::

:::concept{term="先问是 DNA 还是 RNA，再问碱基、戊糖还是磷酸"}
看见“核酸”，先不要跳到双螺旋。本章先写成以核苷酸为基本组成单位的生物大分子；核苷酸完全水解后放出等摩尔的碱基、戊糖和磷酸。把 $\mathrm{DNA}$ 听成“只有核里才有”，会漏掉线粒体 $\mathrm{DNA}$；把 $\mathrm{RNA}$ 听成“绝不能当遗传物质”，某些病毒基因组那一笔（第二节）会没有台阶。
:::

:::pitfall{label="RNA 也可以作为遗传信息的载体，不要写成绝对句"}
教材写的是“一般而言，$\mathrm{RNA}$ 是 $\mathrm{DNA}$ 的转录产物”，紧接着补“在某些情况下，$\mathrm{RNA}$ 也可以作为遗传信息的载体”。把这句话漏掉，第二节病毒基因组“可以由 $\mathrm{DNA}$ 组成，也可以由 $\mathrm{RNA}$ 组成”会对不上。
:::

核酸在核酸酶作用下水解成核苷酸（nucleotide），而核苷酸完全水解后可释放出等摩尔的碱基、戊糖和磷酸。这表明构成核酸的基本组分之间具有一定的比例关系。$\mathrm{DNA}$ 的基本组成单位是脱氧核糖核苷酸（deoxyribonucleotide），而 $\mathrm{RNA}$ 的基本组成单位是核糖核苷酸（ribonucleotide）。

:::definition{label="核苷酸"}
核酸在核酸酶作用下水解得到核苷酸（nucleotide）。核苷酸完全水解后可释放出等摩尔的碱基、戊糖和磷酸。
:::

:::definition{label="脱氧核糖核苷酸"}
脱氧核糖核苷酸（deoxyribonucleotide）是 $\mathrm{DNA}$ 的基本组成单位。
:::

:::definition{label="核糖核苷酸"}
核糖核苷酸（ribonucleotide）是 $\mathrm{RNA}$ 的基本组成单位。
:::

:::keypoint{label="水解这一笔只记两层"}
- 核酸酶把核酸切成核苷酸。
- 核苷酸再完全水解：碱基、戊糖、磷酸等摩尔放出。比例关系从这里来，不是从双螺旋来。
:::

## 一、脱氧核糖核苷酸和核糖核苷酸是构成核酸的基本组成单位

### （一）碱基是含氮杂环化合物

碱基（base）是构成核苷酸的基本组分之一。碱基是含氮的杂环化合物，可分为嘌呤（purine）和嘧啶（pyrimidine）两类（图3-1）。常见的嘌呤包括腺嘌呤（adenine，$\mathrm{A}$）和鸟嘌呤（guanine，$\mathrm{G}$），常见的嘧啶包括尿嘧啶（uracil，$\mathrm{U}$）、胸腺嘧啶（thymine，$\mathrm{T}$）和胞嘧啶（cytosine，$\mathrm{C}$）。$\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$ 和 $\mathrm{T}$ 是构成 $\mathrm{DNA}$ 的碱基，$\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$ 和 $\mathrm{U}$ 是构成 $\mathrm{RNA}$ 的碱基。碱基的各个原子分别加以编号以便于区分。受到所处环境 $\mathrm{pH}$ 的影响，碱基的酮基和氨基可以形成酮式–烯醇式（keto-enol）互变异构体或氨基–亚氨基（amino-imino）互变异构体（图3-2），这为碱基之间以及碱基与其他化学功能基团之间形成氢键提供了结构基础。

自然界还存在一些碱基衍生物，常见的碱基衍生物有次黄嘌呤、黄嘌呤、尿酸、茶碱、可可碱、咖啡碱等。

:::definition{label="碱基"}
碱基（base）是构成核苷酸的基本组分之一。它是含氮的杂环化合物，分为嘌呤（purine）和嘧啶（pyrimidine）两类。
:::

:::definition{label="嘌呤"}
常见的嘌呤包括腺嘌呤（adenine，$\mathrm{A}$）和鸟嘌呤（guanine，$\mathrm{G}$）。嘌呤母环按教材编号：六元环 $\mathrm{N}$-$1$、$2$、$3$、$\mathrm{C}$-$4$、$5$、$\mathrm{C}$-$6$，五元环 $\mathrm{N}$-$7$、$8$、$\mathrm{N}$-$9$（图3-1）。
:::

:::definition{label="嘧啶"}
常见的嘧啶包括尿嘧啶（uracil，$\mathrm{U}$）、胸腺嘧啶（thymine，$\mathrm{T}$）和胞嘧啶（cytosine，$\mathrm{C}$）。嘧啶母环编号：$\mathrm{N}$-$1$、$2$、$\mathrm{N}$-$3$、$4$、$5$、$6$（图3-1）。
:::

:::definition{label="DNA 与 RNA 的碱基组成"}
$\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$ 和 $\mathrm{T}$ 是构成 $\mathrm{DNA}$ 的碱基；$\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$ 和 $\mathrm{U}$ 是构成 $\mathrm{RNA}$ 的碱基。差别落在嘧啶：$\mathrm{DNA}$ 用 $\mathrm{T}$，$\mathrm{RNA}$ 用 $\mathrm{U}$。嘌呤两边都是 $\mathrm{A}$ 和 $\mathrm{G}$。
:::

:::definition{label="碱基的互变异构"}
受环境 $\mathrm{pH}$ 影响，碱基的酮基和氨基可以形成酮式–烯醇式（keto-enol）互变异构体或氨基–亚氨基（amino-imino）互变异构体。这为碱基之间以及碱基与其他化学功能基团之间形成氢键提供了结构基础。
:::

### （二）核苷是由戊糖和碱基缩合而成的一种糖苷

核苷（nucleoside）是碱基与核糖的缩合反应的产物。核糖（ribose）是构成核苷酸的一个基本组分。为了有别于碱基的原子，核糖的碳原子标以 $\mathrm{C}$-$1'$、$\mathrm{C}$-$2'$、$\ldots$、$\mathrm{C}$-$5'$（图3-3）。核糖有 $\beta$-$\mathrm{D}$-核糖（$\beta$-$\mathrm{D}$-ribose）和 $\beta$-$\mathrm{D}$-$2'$-脱氧核糖（$\beta$-$\mathrm{D}$-$2'$-deoxyribose）之分。两者的差别仅在于 $\mathrm{C}$-$2'$ 原子所连接的基团。核糖存在于 $\mathrm{RNA}$ 中，而脱氧核糖存在于 $\mathrm{DNA}$ 中；脱氧核糖的化学稳定性优于核糖。

核糖的第一位碳原子（$\mathrm{C}$-$1'$）和嘌呤碱基的第九位氮原子（$\mathrm{N}$-$9$）或者嘧啶碱基的第一位氮原子（$\mathrm{N}$-$1$）通过缩合反应形成了 $\mathrm{N}$-$\mathrm{C}$ 糖苷键，一般称为 $\beta$-$\mathrm{N}$-糖苷键（$\beta$-$\mathrm{N}$-glycosidic bond）。由于糖苷键是饱和共价键，可以自由旋转，核苷可以形成不同的空间构象；在天然条件下，由于空间位阻效应，核糖和碱基处在反式构象（trans conformation）。同理，碱基与脱氧核糖的反应可以生成脱氧核苷（deoxynucleoside）（图3-4）。

:::definition{label="核苷"}
核苷（nucleoside）是碱基与核糖缩合反应的产物，是一种糖苷。碱基与脱氧核糖缩合则生成脱氧核苷（deoxynucleoside）。
:::

:::definition{label="核糖与脱氧核糖"}
核糖（ribose）是构成核苷酸的基本组分之一。有 $\beta$-$\mathrm{D}$-核糖和 $\beta$-$\mathrm{D}$-$2'$-脱氧核糖之分，差别仅在 $\mathrm{C}$-$2'$ 所连基团：核糖为羟基，脱氧核糖为氢。核糖存在于 $\mathrm{RNA}$ 中，脱氧核糖存在于 $\mathrm{DNA}$ 中；脱氧核糖的化学稳定性优于核糖。
:::

:::definition{label="β-N-糖苷键"}
戊糖 $\mathrm{C}$-$1'$ 与嘌呤 $\mathrm{N}$-$9$ 或嘧啶 $\mathrm{N}$-$1$ 缩合形成 $\mathrm{N}$-$\mathrm{C}$ 糖苷键，一般称为 $\beta$-$\mathrm{N}$-糖苷键（$\beta$-$\mathrm{N}$-glycosidic bond）。它是饱和共价键，可以自由旋转。
:::

:::definition{label="反式构象"}
糖苷键可旋转，核苷可形成不同空间构象。天然条件下因空间位阻效应，核糖（或脱氧核糖）和碱基处在反式构象（trans conformation）。
:::

:::

### （三）核苷酸是核苷与磷酸通过酯键连接形成

尽管核糖环上的所有游离羟基（核糖的 $\mathrm{C}$-$2'$、$\mathrm{C}$-$3'$、$\mathrm{C}$-$5'$ 及脱氧核糖的 $\mathrm{C}$-$3'$、$\mathrm{C}$-$5'$）都能够与磷酸发生酯化反应，而生物体内游离存在的核苷酸多是 $5'$-核苷酸，即核苷或脱氧核苷 $\mathrm{C}$-$5'$ 原子上的羟基与磷酸反应，脱水后形成一个磷酯键，生成相应的核苷酸（nucleotide）或脱氧核苷酸（deoxynucleotide）。根据连接的磷酸基团的数目多少，核苷酸可分为核苷一磷酸（nucleoside $5'$-monophosphate，$\mathrm{NMP}$）、核苷二磷酸（nucleoside $5'$-diphosphate，$\mathrm{NDP}$）和核苷三磷酸（nucleoside $5'$-triphosphate，$\mathrm{NTP}$）。核苷三磷酸的磷原子分别命名为 $\alpha$-、$\beta$- 和 $\gamma$-磷原子（图3-5）。构成核酸的碱基、核苷（或脱氧核苷）以及核苷酸（或脱氧核苷酸）的中英文名称见表3-1 和表3-2。表中核苷和核苷酸名称均采用缩写，如腺苷代表腺嘌呤核苷。

:::definition{label="核苷酸"}
核苷酸（nucleotide）是核苷与磷酸通过酯键连接形成的分子。脱氧核苷酸（deoxynucleotide）则由脱氧核苷与磷酸形成。生物体内游离存在的核苷酸多是 $5'$-核苷酸：$\mathrm{C}$-$5'$ 羟基与磷酸脱水形成一个磷酯键。
:::

:::definition{label="NMP、NDP、NTP"}
按连接的磷酸基团数目：核苷一磷酸（nucleoside $5'$-monophosphate，$\mathrm{NMP}$）、核苷二磷酸（nucleoside $5'$-diphosphate，$\mathrm{NDP}$）、核苷三磷酸（nucleoside $5'$-triphosphate，$\mathrm{NTP}$）。脱氧系列对应写成 $\mathrm{dNMP}$、$\mathrm{dNDP}$、$\mathrm{dNTP}$。
:::

:::definition{label="α、β、γ 磷原子"}
核苷三磷酸的磷原子分别命名为 $\alpha$-、$\beta$- 和 $\gamma$-磷原子。$\alpha$-磷原子最靠近核苷，$\gamma$-磷原子在最外侧（图3-5）。
:::

::figure{src="/images/biochemistry/textbook/p0085_04.png" caption="图3-5　核苷酸的化学结构。（a）脱氧腺苷一磷酸、脱氧腺苷二磷酸和脱氧腺苷三磷酸：5′-磷酯键把磷酸连在脱氧腺苷的 C-5′；三磷酸的磷原子由内到外为 α、β、γ。（b）3′，5′-环腺苷酸（3′，5′-cAMP）。" alt="左侧 dAMP、dADP、dATP 逐级标出磷酸范围和 αβγ 磷原子；右侧 cAMP 的 3′ 与 5′ 被同一磷酸连成环"}

在生物体内，核苷酸还会以其他衍生物的形式存在，并参与各种物质代谢的调控和蛋白质功能的调节。首先，核苷酸是细胞内化学能的载体。核苷三磷酸的 $\alpha$-磷原子和 $\beta$-磷原子之间、$\beta$-磷原子和 $\gamma$-磷原子之间是通过酸酐键连接的。在标准条件下，酸酐键水解所释放的能量可达 $30\,\mathrm{kJ/mol}$，比酯键水解所释放的能量高出一倍还多。因此，核苷二磷酸和核苷三磷酸均属于高能有机磷酸化合物。细胞活动所需的化学能主要来自核苷三磷酸，其中 $\mathrm{ATP}$ 是最重要的能量载体。其次，核苷三磷酸 $\mathrm{ATP}$ 和 $\mathrm{GTP}$ 可以环化形成环腺苷酸（cyclic $\mathrm{AMP}$，$\mathrm{cAMP}$）和环鸟苷酸（cyclic $\mathrm{GMP}$，$\mathrm{cGMP}$），它们都是细胞信号转导过程中的第二信使，具有调控基因表达的作用（图3-5）。此外，细胞内一些参与物质代谢的酶分子的辅酶结构中都含有腺苷酸，如辅酶Ⅰ（烟酰胺腺嘌呤二核苷酸，nicotinamide adenine dinucleotide，$\mathrm{NAD}^{+}$）、辅酶Ⅱ（烟酰胺腺嘌呤二核苷酸磷酸，nicotinamide adenine dinucleotide phosphate，$\mathrm{NADP}^{+}$）、黄素腺嘌呤二核苷酸（flavin adenine dinucleotide，$\mathrm{FAD}$）及辅酶 $\mathrm{A}$（coenzyme $\mathrm{A}$，$\mathrm{CoA}$）等，它们是生物氧化体系的重要成分，在传递质子或电子的过程中发挥重要的作用。最后，核苷酸及核苷酸组分的衍生物具有临床药用价值。$6$-巯基嘌呤（$6$-mercaptopurine，$6$-$\mathrm{MP}$）、阿糖胞苷（cytosine arabinoside，$\mathrm{araC}$）和 $5$-氟尿嘧啶（$5$-fluorouracil，$5$-$\mathrm{FU}$）都是碱基的衍生物，可以通过干扰肿瘤细胞的核苷酸代谢、抑制核酸合成来发挥抗肿瘤作用。

:::definition{label="高能有机磷酸化合物（NDP 与 NTP）"}
核苷三磷酸的 $\alpha$-$\beta$、$\beta$-$\gamma$ 磷原子之间以酸酐键连接。标准条件下酸酐键水解所释放的能量可达 $30\,\mathrm{kJ/mol}$，比酯键水解高出一倍还多。因此 $\mathrm{NDP}$ 和 $\mathrm{NTP}$ 均属高能有机磷酸化合物。细胞活动所需化学能主要来自核苷三磷酸，其中 $\mathrm{ATP}$ 是最重要的能量载体。
:::

:::definition{label="cAMP 与 cGMP"}
$\mathrm{ATP}$ 和 $\mathrm{GTP}$ 可以环化形成环腺苷酸（cyclic $\mathrm{AMP}$，$\mathrm{cAMP}$）和环鸟苷酸（cyclic $\mathrm{GMP}$，$\mathrm{cGMP}$）。它们是细胞信号转导过程中的第二信使，具有调控基因表达的作用。图3-5b 画出 $3',5'$-$\mathrm{cAMP}$。
:::

:::definition{label="含腺苷酸的辅酶"}
参与物质代谢的酶分子的辅酶结构中常含腺苷酸，如辅酶Ⅰ（$\mathrm{NAD}^{+}$）、辅酶Ⅱ（$\mathrm{NADP}^{+}$）、黄素腺嘌呤二核苷酸（$\mathrm{FAD}$）及辅酶 $\mathrm{A}$（$\mathrm{CoA}$）。它们是生物氧化体系的重要成分，在传递质子或电子的过程中发挥作用。
:::

:::definition{label="抗肿瘤的碱基衍生物"}
$6$-巯基嘌呤（$6$-$\mathrm{MP}$）、阿糖胞苷（$\mathrm{araC}$）和 $5$-氟尿嘧啶（$5$-$\mathrm{FU}$）都是碱基的衍生物，可通过干扰肿瘤细胞的核苷酸代谢、抑制核酸合成发挥抗肿瘤作用。
:::

:::

:::

## 二、核酸的一级结构是核苷酸的排列顺序

### （一）DNA 是脱氧核糖核苷酸通过 3′，5′-磷酸二酯键聚合形成的线性大分子

$\mathrm{DNA}$ 是多个脱氧核糖核苷酸聚合而成的线性大分子，脱氧核糖核苷酸之间是通过 $3',5'$-磷酸二酯键（phosphodiester bond）共价连接的。这条多聚脱氧核糖核苷酸分子的一端是连接在 $\mathrm{C}$-$5'$ 原子上的磷酸基团，另一端是 $\mathrm{C}$-$3'$ 原子上的羟基，它们分别称为 $5'$-端（$5'$-end）和 $3'$-端（$3'$-end）。这条多聚脱氧核糖核苷酸链的 $3'$-羟基可以与另一个游离的脱氧核苷三磷酸的 $\alpha$-磷酸基团发生缩合反应，生成了一个新的 $3',5'$-磷酸二酯键，并将原来的多聚脱氧核糖核苷酸链在 $3'$-端增加一个脱氧核糖核苷酸。这个延长的多聚脱氧核糖核苷酸链的 $3'$-端保留一个羟基，它可以继续与游离的脱氧核苷三磷酸 $\alpha$-磷酸基团反应，继续生成一个新的 $3',5'$-磷酸二酯键。这样的反应可以反复进行下去生成一条多聚脱氧核苷酸链（polydeoxyribonucleotides），即 $\mathrm{DNA}$ 链（图3-6）。多聚脱氧核苷酸链只能从它的 $3'$-端得以延长，由此，$\mathrm{DNA}$ 链有了 $5'\rightarrow 3'$ 的方向性。

:::definition{label="3′，5′-磷酸二酯键"}
$3',5'$-磷酸二酯键（phosphodiester bond）是连接相邻脱氧核糖核苷酸（或核糖核苷酸）的共价键：上一核苷酸的 $\mathrm{C}$-$3'$ 羟基与下一核苷酸的 $\mathrm{C}$-$5'$ 磷酸之间形成磷酸二酯。
:::

:::definition{label="5′-端与 3′-端"}
多聚脱氧核糖核苷酸分子一端是连接在 $\mathrm{C}$-$5'$ 上的磷酸基团，称为 $5'$-端（$5'$-end）；另一端是 $\mathrm{C}$-$3'$ 上的羟基，称为 $3'$-端（$3'$-end）。
:::

:::definition{label="DNA 链的方向性"}
多聚脱氧核苷酸链只能从它的 $3'$-端得以延长，因此 $\mathrm{DNA}$ 链有 $5'\rightarrow 3'$ 的方向性。延长时，$3'$-羟基与游离 $\mathrm{dNTP}$ 的 $\alpha$-磷酸基团缩合，生成新的 $3',5'$-磷酸二酯键，并释放出原来的 $\beta$、$\gamma$ 磷酸部分（教材此处强调 $\alpha$-磷酸参与成键）。
:::

::figure{src="/images/biochemistry/textbook/p0086_01.png" caption="图3-6　多聚核苷酸的化学结构式。5′-端为磷酸基团，3′-端为羟基；相邻核苷酸以 3′，5′-磷酸二酯键相连；箭头标出核酸方向为 5′→3′。" alt="四核苷酸链：左上 5′ 磷酸色块，中间标 3′，5′-磷酸二酯键，右下 3′ 羟基色块，斜向箭头写核酸方向"}

:::cause-effect{title="为什么 DNA 链规定写成 5′→3′"}
- **因** 新的 $3',5'$-磷酸二酯键只能由链的 $3'$-羟基去打游离 $\mathrm{dNTP}$ 的 $\alpha$-磷酸；延长永远发生在 $3'$-端
- **果** 多聚脱氧核苷酸链具有 $5'\rightarrow 3'$ 的方向性；一级结构也按 $5'$-端至 $3'$-端书写
:::

:::pitfall{label="磷酸二酯键是 3′ 对 5′，不要写成 5′ 对 5′ 或 2′ 对 5′"}
图3-6 标的是 $3',5'$-磷酸二酯键。$\mathrm{cAMP}$ 的 $3',5'$-环磷酸是分子内成环，不是把核酸链焊成环状单体。$\mathrm{RNA}$ 虽有 $2'$-羟基，下一小节写明磷酸二酯键一般仍只在 $\mathrm{C}$-$3'$ 与 $\mathrm{C}$-$5'$ 之间形成。
:::

:::example{label="延长一次链发生了什么"}
已有链的 $3'$-羟基 $+$ 游离 $\mathrm{dNTP}$ 的 $\alpha$-磷酸 $\rightarrow$ 新的 $3',5'$-磷酸二酯键，链在 $3'$-端多一个脱氧核糖核苷酸，新的 $3'$-端仍留着羟基，可以再接下一个 $\mathrm{dNTP}$。这不是在 $5'$-端加帽子。
:::

### （二）RNA 是核糖核苷酸通过 3′，5′-磷酸二酯键聚合形成的线性大分子

与 $\mathrm{DNA}$ 相似，$\mathrm{RNA}$ 是多个核苷酸分子在 $\mathrm{RNA}$ 聚合酶催化下通过 $3',5'$-磷酸二酯键连接形成的线性大分子，并且也具有 $5'\rightarrow 3'$ 的方向性。虽然核糖核苷酸的 $\mathrm{C}$-$2'$ 原子也有一个羟基，但是多聚核糖核苷酸分子的磷酸二酯键一般只能在 $\mathrm{C}$-$3'$ 原子和 $\mathrm{C}$-$5'$ 原子之间形成。$\mathrm{RNA}$ 与 $\mathrm{DNA}$ 的差别仅在于：①$\mathrm{RNA}$ 的戊糖环是核糖而不是脱氧核糖；②$\mathrm{RNA}$ 的嘧啶是胞嘧啶和尿嘧啶，一般没有胸腺嘧啶，所以构成 $\mathrm{RNA}$ 的 $4$ 种基本核苷酸是 $\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$ 和 $\mathrm{UMP}$。

:::definition{label="RNA 链"}
$\mathrm{RNA}$ 是多个核苷酸分子在 $\mathrm{RNA}$ 聚合酶催化下通过 $3',5'$-磷酸二酯键连接形成的线性大分子，同样具有 $5'\rightarrow 3'$ 的方向性。
:::

:::definition{label="RNA 与 DNA 的两点差别"}
教材把差别写成仅两点：①戊糖环是核糖而不是脱氧核糖；②嘧啶是胞嘧啶和尿嘧啶，一般没有胸腺嘧啶。构成 $\mathrm{RNA}$ 的 $4$ 种基本核苷酸是 $\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$ 和 $\mathrm{UMP}$。
:::

|------|---------------|---------------|
| 单体 | 脱氧核糖核苷酸 | 核糖核苷酸 |

| 方向 | $5'\rightarrow 3'$ | $5'\rightarrow 3'$ |
| 四种基本（脱氧）核苷酸 | $\mathrm{dAMP}$、$\mathrm{dGMP}$、$\mathrm{dCMP}$、$\mathrm{dTMP}$ | $\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$、$\mathrm{UMP}$ |
:::

:::pitfall{label="RNA 有 2′-OH，不等于磷酸二酯键改走 2′，5′"}
教材写得很紧：虽然 $\mathrm{C}$-$2'$ 也有羟基，多聚核糖核苷酸的磷酸二酯键一般只能在 $\mathrm{C}$-$3'$ 与 $\mathrm{C}$-$5'$ 之间形成。把 $\mathrm{RNA}$ 骨架听成 $2',5'$，和 $\mathrm{DNA}$ 的一级结构书写会并成两套规则。
:::

:::insight{label="“差别仅在于”两条，后面的二级结构差要从这里长出来"}
戊糖差一个 $2'$-氧，嘧啶 $\mathrm{T}/\mathrm{U}$ 差一个甲基。本节先把化学组成立住；双螺旋、超螺旋、核小体是第二节的 $\mathrm{DNA}$ 账，$\mathrm{RNA}$ 的空间结构是第三节，不要提前并户。
:::

### （三）核酸的一级结构蕴藏遗传信息

基于 $\mathrm{DNA}$ 链和 $\mathrm{RNA}$ 链的方向性，人们把 $\mathrm{RNA}$ 的核苷酸和 $\mathrm{DNA}$ 的脱氧核苷酸从 $5'$-端至 $3'$-端的排列顺序定义为核酸的一级结构（primary structure）。核苷酸之间的差异仅在于碱基的不同，因此核酸的一级结构也就是它的碱基序列（base sequence）。核酸一级结构的书写方式如图3-7 所示。

核酸分子的大小常用核苷酸数目（nucleotide 或 $\mathrm{nt}$，用于单链 $\mathrm{DNA}$ 和 $\mathrm{RNA}$）或碱基对数目（base pair，$\mathrm{bp}$ 或 kilobase pair，$\mathrm{kb}$，用于双链 $\mathrm{DNA}$）来表示。长度短于 $50$ 个核苷酸的核酸的片段常被称为寡核苷酸（oligonucleotide）。自然界中的 $\mathrm{DNA}$ 的长度可以高达几十万个碱基对。$\mathrm{DNA}$ 携带的遗传信息完全依靠碱基排列顺序变化。可以想象，一个由 $n$ 个脱氧核苷酸组成的 $\mathrm{DNA}$ 会有 $4^{n}$ 种不同的排列组合，从而提供了巨大的遗传信息编码潜力。

:::definition{label="核酸的一级结构"}
把 $\mathrm{RNA}$ 的核苷酸和 $\mathrm{DNA}$ 的脱氧核苷酸从 $5'$-端至 $3'$-端的排列顺序定义为核酸的一级结构（primary structure）。核苷酸之间的差异仅在于碱基的不同，因此一级结构也就是碱基序列（base sequence）。
:::

:::definition{label="寡核苷酸"}
长度短于 $50$ 个核苷酸的核酸片段常被称为寡核苷酸（oligonucleotide）。
:::

:::definition{label="nt、bp 与 kb"}
单链 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 的大小用核苷酸数目（nucleotide 或 $\mathrm{nt}$）表示；双链 $\mathrm{DNA}$ 用碱基对数目（base pair，$\mathrm{bp}$ 或 kilobase pair，$\mathrm{kb}$）表示。
:::

::figure{src="/images/biochemistry/textbook/p0087_01.png" caption="图3-7　核酸的一级结构以及书写法。自上而下：骨架式（5′P 至 OH 3′，碱基写在上方）；含磷酸的字母式 5′ p-ApGpGpTpCpApApTpCpCpApG-OH 3′；只写碱基并标明方向 5′ AGGTCAATCCAG 3′；最简只写碱基 AGGTCAATCCAG（默认 5′→3′）。" alt="一条 12 聚体 DNA 的四种书写：锯齿骨架带 5′P 与 3′OH，再逐步简化为字母序列"}

:::example{label="如何按图3-7 写一条链"}
图中序列从 $5'$ 到 $3'$ 为 $\mathrm{AGGTCAATCCAG}$。完整写法可保留 $5'$-磷酸和 $3'$-羟基，并把磷酸写成字母间的 $\mathrm{p}$；习惯上默认从左到右即 $5'\rightarrow 3'$，最简可只写碱基序列。不要从 $3'$ 往回念。
:::

:::derivation{title="n 个脱氧核苷酸有多少种排列"}
每种位置有 $4$ 种碱基（$\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{T}$），$n$ 个位置独立排列：

$$
4^{n}
$$

这就是教材说的“巨大的遗传信息编码潜力”。遗传信息完全依靠碱基排列顺序变化，不依靠磷酸骨架的花样——骨架都是 $3',5'$-磷酸二酯键。
:::

:::concept{term="先问 5′→3′ 的碱基序列，再问双螺旋怎么配对"}
一级结构是方向性的核苷酸排列，也就是碱基序列。双螺旋、大沟小沟、超螺旋都还没出场。把一级结构听成“已经是双螺旋”，Chargaff 规则和 Watson-Crick 配对会没有需要解释的对象。
:::

:::pitfall{label="nt 用于单链，bp 用于双链，不要混着数"}
一条 $100$ 个核苷酸的单链 $\mathrm{RNA}$ 是 $100\,\mathrm{nt}$；一段 $100$ 个碱基对的双链 $\mathrm{DNA}$ 是 $100\,\mathrm{bp}$，对应 $200$ 个核苷酸。把人类基因组 $3\times 10^{9}\,\mathrm{bp}$（第二节）听成 $3\times 10^{9}$ 个核苷酸，长度会差一倍。
:::

:::keypoint{label="本节化学组成收口"}
- 核酸 $=$ 核苷酸的多聚体；完全水解得等摩尔碱基、戊糖、磷酸。
- 碱基：嘌呤 $\mathrm{A}$、$\mathrm{G}$；嘧啶 $\mathrm{C}$、$\mathrm{T}$、$\mathrm{U}$。$\mathrm{DNA}$ 用 $\mathrm{A}/\mathrm{G}/\mathrm{C}/\mathrm{T}$，$\mathrm{RNA}$ 用 $\mathrm{A}/\mathrm{G}/\mathrm{C}/\mathrm{U}$。
- 戊糖：$\mathrm{RNA}$ 为核糖，$\mathrm{DNA}$ 为 $2'$-脱氧核糖；$\mathrm{C}$-$2'$ 差一个氧。
- 核苷 $=$ 碱基 $+$ 戊糖（$\beta$-$\mathrm{N}$-糖苷键）；核苷酸 $=$ 核苷 $+$ 磷酸（体内多是 $5'$-核苷酸）。
- 链：$\mathrm{DNA}/\mathrm{RNA}$ 都靠 $3',5'$-磷酸二酯键，都从 $3'$-端延长，一级结构 $5'\rightarrow 3'$ 书写。
:::

:::memory{label="本节必背要点"}
- [ ] 核酸以核苷酸为基本组成单位，分 $\mathrm{DNA}$ 和 $\mathrm{RNA}$。
- [ ] $\mathrm{DNA}$ 在细胞核和线粒体，携带遗传信息并通过复制传代。
- [ ] $\mathrm{RNA}$ 一般是转录产物，在细胞质、细胞核和线粒体；某些情况下也可作遗传信息载体。
- [ ] 核酸酶水解得核苷酸；核苷酸完全水解得等摩尔碱基、戊糖和磷酸。
- [ ] $\mathrm{DNA}$ 的基本单位是脱氧核糖核苷酸，$\mathrm{RNA}$ 的基本单位是核糖核苷酸。
- [ ] 碱基是含氮杂环，分嘌呤（$\mathrm{A}$、$\mathrm{G}$）和嘧啶（$\mathrm{U}$、$\mathrm{T}$、$\mathrm{C}$）。
- [ ] $\mathrm{DNA}$ 碱基为 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{T}$；$\mathrm{RNA}$ 碱基为 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{U}$。
- [ ] 酮–烯醇、氨基–亚氨基互变异构为氢键提供结构基础。
- [ ] 常见碱基衍生物：次黄嘌呤、黄嘌呤、尿酸、茶碱、可可碱、咖啡碱。
- [ ] 核苷是碱基与戊糖缩合的糖苷；碳原子标 $\mathrm{C}$-$1'$ 至 $\mathrm{C}$-$5'$。
- [ ] $\beta$-$\mathrm{D}$-核糖与 $\beta$-$\mathrm{D}$-$2'$-脱氧核糖仅差 $\mathrm{C}$-$2'$ 所连基团；核糖在 $\mathrm{RNA}$，脱氧核糖在 $\mathrm{DNA}$；脱氧核糖更稳定。
- [ ] $\beta$-$\mathrm{N}$-糖苷键：戊糖 $\mathrm{C}$-$1'$ 对嘌呤 $\mathrm{N}$-$9$ 或嘧啶 $\mathrm{N}$-$1$；天然构象为反式。
- [ ] 体内游离核苷酸多是 $5'$-核苷酸（$\mathrm{NMP}/\mathrm{NDP}/\mathrm{NTP}$；脱氧系列 $\mathrm{dNMP}$ 等）。
- [ ] $\mathrm{NTP}$ 磷原子分 $\alpha$、$\beta$、$\gamma$；$\alpha$-$\beta$、$\beta$-$\gamma$ 为酸酐键，水解约 $30\,\mathrm{kJ/mol}$，$\mathrm{NDP}$ 和 $\mathrm{NTP}$ 属高能磷酸化合物；$\mathrm{ATP}$ 是最重要的能量载体。
- [ ] $\mathrm{cAMP}$、$\mathrm{cGMP}$ 是第二信使；$\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$、$\mathrm{FAD}$、$\mathrm{CoA}$ 含腺苷酸。
- [ ] $6$-$\mathrm{MP}$、$\mathrm{araC}$、$5$-$\mathrm{FU}$ 干扰肿瘤细胞核苷酸代谢、抑制核酸合成。
- [ ] 表3-1：$\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$、$\mathrm{UMP}$；表3-2：$\mathrm{dAMP}$、$\mathrm{dGMP}$、$\mathrm{dCMP}$、$\mathrm{dTMP}$。
- [ ] $\mathrm{DNA}/\mathrm{RNA}$ 链均以 $3',5'$-磷酸二酯键连接；有 $5'$-端（磷酸）和 $3'$-端（羟基）。
- [ ] 链只能从 $3'$-端延长，故方向为 $5'\rightarrow 3'$。
- [ ] $\mathrm{RNA}$ 虽有 $2'$-$\mathrm{OH}$，磷酸二酯键一般仍在 $\mathrm{C}$-$3'$ 与 $\mathrm{C}$-$5'$ 之间。
- [ ] $\mathrm{RNA}$ 与 $\mathrm{DNA}$ 差别：戊糖为核糖；嘧啶为 $\mathrm{C}$ 和 $\mathrm{U}$，一般无 $\mathrm{T}$。
- [ ] 一级结构 $=$ 从 $5'$ 至 $3'$ 的核苷酸排列 $=$ 碱基序列。
- [ ] 单链用 $\mathrm{nt}$，双链用 $\mathrm{bp}$ 或 $\mathrm{kb}$；短于 $50$ 个核苷酸常称寡核苷酸。
- [ ] $n$ 个脱氧核苷酸有 $4^{n}$ 种排列，遗传信息完全靠碱基顺序。
:::
