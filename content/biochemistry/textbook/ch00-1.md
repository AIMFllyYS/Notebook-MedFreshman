# 第一节　生物化学与分子生物学发展简史

本章打开生物化学与分子生物学。先把学科定义、它与生理化学的关系、近 $70$ 年分子生物学的崛起写清，再按叙述、动态、机能三阶段摊开发展简史，并收中国科学家的贡献。第二节写当代四大研究内容，第三节写它作为生物学、医学基础与前沿、以及分子医学三件事。

生物化学与分子生物学（biochemistry and molecular biology）是在分子水平研究和阐明生命现象的本质和规律的基础学科，既是生物学和医学各学科的共同基础，又是自然科学领域中发展最为迅速的前沿学科。

:::definition{label="生物化学与分子生物学"}
生物化学与分子生物学（biochemistry and molecular biology）是在分子水平研究和阐明生命现象的本质和规律的基础学科。它既是生物学和医学各学科的共同基础，又是自然科学领域中发展最为迅速的前沿学科。
:::

生物化学（biochemistry）早期是生理学的分支学科，曾被称为生理化学（physiological chemistry）。生物化学主要利用化学、物理学和数学的原理和方法，通过研究生物的化学组成、化学结构及其在生理过程中的变化，诠释生命体结构与功能形成的基本机制和规律。在过去的 $70$ 年里，随着学科的发展和研究的深入，生物大分子的结构与功能成为生物化学研究的热点和前沿，因而形成了分子生物学（molecular biology）这一新兴领域，将生物化学带入了一个新时代。

:::definition{label="生物化学"}
生物化学（biochemistry）主要利用化学、物理学和数学的原理和方法，通过研究生物的化学组成、化学结构及其在生理过程中的变化，诠释生命体结构与功能形成的基本机制和规律。
:::

:::definition{label="生理化学"}
生理化学（physiological chemistry）是生物化学早期作为生理学分支学科时的名称。今天不要把它听成一门与生物化学并列、仍然独立的课程。
:::

:::definition{label="分子生物学"}
分子生物学（molecular biology）是近 $70$ 年来，生物大分子的结构与功能成为生物化学研究的热点和前沿之后形成的新兴领域，把生物化学带入了一个新时代。它不是另起炉灶的第四门课，而是从生物化学内部长出来的。
:::

:::compare{title="生物化学与分子生物学"}
| 项目 | 生物化学 | 分子生物学 |
|------|----------|------------|
| 英文 | biochemistry | molecular biology |
| 早期身份 | 生理学的分支，曾称生理化学 | 近 $70$ 年才形成的新兴领域 |
| 主要方法 | 化学、物理学和数学的原理和方法 | 在生物化学基础上深入到生物大分子 |
| 主要对象 | 生物的化学组成、化学结构及其在生理过程中的变化 | 生物大分子的结构与功能，以及遗传信息的传递与调控 |
| 要回答的问题 | 生命体结构与功能形成的基本机制和规律 | 把遗传信息、中心法则、基因组写进同一套分子语言 |
| 二者关系 | 母体学科 | 由生物化学热点前沿形成，将生物化学带入新时代；第三阶段（机能生物化学）亦称分子生物学阶段 |
:::

:::concept{term="先问这还是生理化学分支，再问分子生物学从哪一笔账独立出来"}
看见“生物化学与分子生物学”，先不要写成两门从一开始就并列的课。早期它是生理学的分支，户头叫生理化学；正业是用化学、物理学和数学去看组成、结构和生理过程中的变化。近 $70$ 年，生物大分子的结构与功能成为热点，才形成分子生物学，把原来的学科带进新时代。把今天的课听成“还是生理化学”，或把分子生物学听成与生物化学无关的另一套，后面的三阶段和中心法则都会对错户头。
:::

生物化学与分子生物学相关理论与技术的诸多突破性进展正在迅速而广泛地渗透到包括医学在内的生命科学各个领域，其理论体系和前沿技术，对于临床医学生的专业学习、临床实践和科学研究及未来的创新发展具有毋庸置疑的重要地位。因此，学习和掌握生物化学与分子生物学知识，除理解生命现象的本质与人体正常生理过程的分子机制外，也为进一步学习基础医学和临床医学课程打下扎实的基础。

:::tip{label="医学生为什么先读这一门"}
教材把地位写成两笔账：一是理解生命现象的本质与人体正常生理过程的分子机制；二是为后续基础医学和临床医学课程打基础。理论和技术已经渗进医学各领域，不是“只在实验室里有用”。
:::

生物化学一词出自德国的 Felix H.，他于 $1877$ 年提出“biochemie”一词，译成英语为“biochemistry”，即生物化学。生物化学直到 $19$ 世纪末才真正发展成为一门独立的学科，并在 $20$ 世纪初期蓬勃发展起来，近 $50$ 年来又有许多重大的进展和突破，成为生命科学领域重要的前沿学科之一。$20$ 世纪 $50$ 年代，苏联生物化学家提出，生物化学的发展可分为叙述生物化学、动态生物化学和机能生物化学三个阶段。第三个阶段正是分子生物学崛起并迅速发展成为一门独立学科的阶段，故亦称为分子生物学阶段。

:::definition{label="biochemie"}
$1877$ 年，德国的 Felix H. 提出“biochemie”一词，英语为 biochemistry，即生物化学。学科名称落在这一年；真正成为独立学科要等到 $19$ 世纪末。
:::

:::definition{label="叙述生物化学"}
叙述生物化学是三个发展阶段的第一阶段，主要研究生物体的化学组成，并对其进行分离、纯化、合成、结构测定及理化性质的研究。时间上对应 $18$ 世纪中叶至 $20$ 世纪初，即生物化学的初期阶段。
:::

:::definition{label="动态生物化学"}
动态生物化学是第二阶段，从 $20$ 世纪 $20$ 年代开始，主要研究生物体内物质代谢规律，认识体内各种分子的代谢变化。
:::

:::definition{label="机能生物化学"}
机能生物化学是第三阶段，$20$ 世纪后半叶以来以建立分子生物学为主要标志。苏联生物化学家在 $20$ 世纪 $50$ 年代作出这一划分。此阶段正是分子生物学崛起并迅速发展成为独立学科的阶段，故亦称为分子生物学阶段。
:::

:::pitfall{label="三个阶段不是四门课，分子生物学也不是另立的第四阶段"}
教材写的是叙述、动态、机能三阶段。第三阶段就是分子生物学崛起并独立的阶段，所以也叫分子生物学阶段。不要把分子生物学再加成“第四阶段”，也不要把 $1877$ 年提出 biochemie 听成那一年学科已经独立——独立要到 $19$ 世纪末，蓬勃发展在 $20$ 世纪初期。
:::

:::compare{title="叙述、动态、机能三阶段"}
| 项目 | 叙述生物化学 | 动态生物化学 | 机能生物化学（分子生物学阶段） |
|------|--------------|--------------|--------------------------------|
| 大致时间 | $18$ 世纪中叶至 $20$ 世纪初 | $20$ 世纪 $20$ 年代起 | $20$ 世纪后半叶以来 |
| 主要问题 | 生物体由什么组成，组分如何分离、纯化、合成和测结构 | 体内各种分子怎样代谢、能量怎样转 | 遗传信息是什么、如何传递，大分子结构如何执行功能 |
| 标志性内容 | 组成、分离纯化、肽键与多肽学说、可溶性催化剂 | 必需氨基酸/脂肪酸/维生素、激素、酶是蛋白质、$\beta$ 氧化、三羧酸循环、$\mathrm{ATP}$ 循环 | DNA 双螺旋、中心法则、重组 DNA、基因组与其他组学 |
| 技术侧 | 色谱等分析方法逐步成熟 | 放射性核素标记、电泳、X 射线晶体学 | 重组 DNA、PCR、测序、冷冻电镜等 |
| 还不是 | 系统的代谢途径与能量循环 | 以核酸为中心的遗传信息传递 | 基因组序列揭晓就等于生命本质已经阐明 |
:::

## 一、生物化学的开创依赖其他学科的发展和先辈科学家们的不懈努力

科学技术在 $18$—$19$ 世纪逐步得到发展，到 $20$ 世纪初，化学、物理学和数学已经发展成为比较成熟的学科，随后生理学、细胞生物学、遗传学也得到了迅速发展，这些学科的理论和技术为生物化学学科的出现和发展奠定了基础。

今天看来，生物化学融合化学、生物学、物理学等科学的原理和方法研究生命，是一件理所当然的事情。但在近代生物化学发展的初期，生物化学专家却需要很大的努力去说服其他学科的专家，发挥其学科的特点和优势，采用其原理和方法与生物化学融合，从而研究生命。生物化学家 Hopkins F.G. 在这方面作出了巨大的努力，不仅极力倡导用化学的方法研究生命物质及生物化学反应，大力主张学术思想的交叉融合，还坚定地坚持生物化学应该主要研究所有生物最根本的生命规律，有力地推进了生物化学的发展，他的学术研究也在多个领域取得了优异的成果。

:::definition{label="Hopkins F.G. 的主张"}
Hopkins F.G. 极力倡导用化学的方法研究生命物质及生物化学反应，主张学术思想交叉融合，并坚持生物化学应该主要研究所有生物最根本的生命规律。教材把他写成开创期说服其他学科、推进融合的关键人物。
:::

:::insight{label="交叉不是今天才有的口号，开创期就要去说服别的学科"}
化学、物理学、数学先成熟，生理学、细胞生物学、遗传学随后发展，生物化学才有土壤。Hopkins 的工作说明：用化学方法研究生命，在当时不是“理所当然”，而是要去争来的融合。把开创史听成“化学家自己在实验室里发明了一门课”，会漏掉学科交叉这一笔。
:::

$18$ 世纪中叶，瑞典化学家 Scheele C.W. 研究生物体（植物及动物）各种组织的化学组成，分离得到甘油、柠檬酸、苹果酸、乳酸、尿酸、酒石酸等，被认为是奠定现代生物化学基础的工作。$1785$ 年，法国化学家 Lavoisier A.L. 首先提出了呼吸的本质，认为生物体呼吸过程的本质与燃烧过程一样，均需要消耗氧气，释放二氧化碳和水，同时产生热能，这是生物氧化及能代谢研究的开端。$1828$ 年，德国化学家 Wöhler F. 采用化学方法，在体外合成了尿素，打破了化学方法不适合生命物质研究的观念，突破了无机化合物和有机化合物之间的研究界限。$1896$ 年，德国化学家 Buchner E. 发现酵母的提取液仍然具有发酵作用，表明细胞的一些水溶性成分发挥作用不依赖完整的活细胞。随着一批化学家、医生和药剂师不断加入生命体的化学研究，特别是色谱技术等分析方法的成熟和运用，逐渐阐明了生命体的主要成分。$1921$ 年，加拿大外科医生 Banting F.G. 从狗胰腺提取了胰岛素，并成功用于糖尿病治疗。$20$ 世纪 $30$ 年代前后，先后有一批化学家和物理学家意识到，生物学家研究的生物是由元素周期表里的化学元素组成的，应该可以用化学反应和物理的原子结构解释“生命是什么”这个科学史上最古老的问题。

:::definition{label="Scheele 的组成工作"}
$18$ 世纪中叶，瑞典化学家 Scheele C.W. 研究植物及动物各种组织的化学组成，分离得到甘油、柠檬酸、苹果酸、乳酸、尿酸、酒石酸等。教材称之为奠定现代生物化学基础的工作。
:::

:::definition{label="Lavoisier 与呼吸的本质"}
$1785$ 年，法国化学家 Lavoisier A.L. 提出：生物体呼吸过程的本质与燃烧过程一样，均需消耗氧气，释放二氧化碳和水，同时产生热能。这是生物氧化及能代谢研究的开端。
:::

:::definition{label="Wöhler 体外合成尿素"}
$1828$ 年，德国化学家 Wöhler F. 用化学方法在体外合成尿素，打破了“化学方法不适合生命物质研究”的观念，突破了无机化合物和有机化合物之间的研究界限。
:::

:::definition{label="Buchner 的无细胞发酵"}
$1896$ 年，德国化学家 Buchner E. 发现酵母的提取液仍然具有发酵作用，表明细胞的一些水溶性成分发挥作用不依赖完整的活细胞。后面叙述阶段里的“可溶性催化剂”正是从这里长出来的。
:::

:::definition{label="Banting 提取胰岛素"}
$1921$ 年，加拿大外科医生 Banting F.G. 从狗胰腺提取了胰岛素，并成功用于糖尿病治疗。这是开创期写到临床应用的一笔。
:::

:::cause-effect{title="呼吸与燃烧被写成同一类氧化"}
- **因** Lavoisier 指出呼吸与燃烧一样，耗氧、放出二氧化碳和水，并产热
- **果** 生物氧化及能代谢研究从此有了开端，动态阶段的 $\mathrm{ATP}$ 循环才能接到这本账上
:::

:::pitfall{label="尿素合成打破的是“生命物质不能用化学做”的界限，不是已经阐明蛋白质生物合成"}
Wöhler $1828$ 年体外合成尿素，突破的是无机物与有机物、以及“化学方法不适合生命物质”的观念。Buchner $1896$ 年证明发酵可以离开完整活细胞。这两笔都还不是胰岛素序列、更不是中心法则。把它们听成“分子生物学已经开始”，机能阶段会没有台阶。
:::

自此至 $20$ 世纪初期，通过众多科学家的努力、学科合作与交叉，对脂质、糖类及氨基酸等各种生物体有机物的性质开始了较为系统的研究，生物体内的一些重要物质也相继被发现。初步揭示了生命体的基本成分、变化特点和功能，于是形成了解释生命现象本质的新学科即生物化学学科。

:::note{label="学科成立的收口"}
开创期的终点不是某一项单一发现，而是：脂质、糖类及氨基酸等有机物性质开始被系统研究，重要物质相继被发现，生命体的基本成分、变化特点和功能被初步揭示，解释生命现象本质的新学科——生物化学——才成立。
:::

## 二、叙述生物化学阶段主要研究生物体的化学组成

$18$ 世纪中叶至 $20$ 世纪初是生物化学的初期阶段，也称为叙述生物化学阶段，主要研究生物体的化学组成，并对其进行分离、纯化、合成、结构测定及理化性质的研究。期间的重要贡献有：发现了生物氧化作用的本质；对脂质、糖类及氨基酸的性质进行了较为系统的研究；发现并分离了核酸；发现了维生素对人体的作用；从血液中分离了血红蛋白；证实了连接相邻氨基酸的肽键的形成，提出了蛋白质分子结构的多肽学说；体外合成了尿素、嘌呤和简单的多肽；发现酵母发酵可产生醇并产生 $\mathrm{CO}_2$，酵母发酵过程中存在“可溶性催化剂”，奠定了酶学的基础等。

:::definition{label="肽键与多肽学说"}
叙述阶段证实了连接相邻氨基酸的肽键的形成，并提出了蛋白质分子结构的多肽学说。此时写的是“氨基酸如何连成肽”，还不是 $\alpha$-螺旋，更不是胰岛素全序列。
:::

:::definition{label="可溶性催化剂"}
酵母发酵可产生醇并产生 $\mathrm{CO}_2$，发酵过程中存在“可溶性催化剂”——这是酶学的基础。它与 Buchner 的无细胞发酵相接：催化不必绑在完整活细胞上。
:::

:::keypoint{label="叙述阶段记“组成、分离、肽键、可溶性催化剂”"}
- 对象是化学组成：分离、纯化、合成、结构测定、理化性质。
- 组成侧：脂质、糖类、氨基酸；核酸被发现并分离；血红蛋白从血液中分出。
- 功能侧的萌芽：生物氧化本质、维生素对人体的作用。
- 蛋白质：肽键 + 多肽学说；体外合成尿素、嘌呤和简单多肽。
- 酶学：酵母发酵中的“可溶性催化剂”。
:::

## 三、动态生物化学阶段主要研究生物体内物质代谢规律

从 $20$ 世纪 $20$ 年代开始，生物化学学科蓬勃发展，开始认识体内各种分子的代谢变化，进入了动态生物化学阶段。例如：在营养方面，发现了人类必需氨基酸、必需脂肪酸及多种维生素；在内分泌方面，发现了多种激素，并将其分离、合成；在酶学方面，认识到酶的化学本质是蛋白质，酶晶体制备获得成功；在物质代谢方面，由于化学分析及核素示踪技术的发展与应用，对生物体内主要物质的代谢途径已基本确定，包括糖代谢途径的酶促反应过程、脂肪酸 $\beta$ 氧化、尿素合成途径及三羧酸循环等。在生物能研究中，提出了生物能产生过程中的 $\mathrm{ATP}$ 循环学说。在这一阶段，一些技术方法在生物化学研究中的应用，如放射性核素标记、电泳和 X 射线晶体学等，极大推动了学科发展。

:::definition{label="必需营养素（动态阶段）"}
动态阶段在营养方面发现了人类必需氨基酸、必需脂肪酸及多种维生素。户头是“人体自己不能充分合成、必须从外界获得的分子”，不是把所有氨基酸、脂肪酸、维生素都叫必需。
:::

:::definition{label="酶的化学本质是蛋白质"}
动态阶段认识到酶的化学本质是蛋白质，并且酶晶体制备获得成功。叙述阶段只写到“可溶性催化剂”；到这里才把催化剂收成蛋白质。
:::

:::definition{label="ATP 循环学说"}
在生物能研究中，提出了生物能产生过程中的 $\mathrm{ATP}$ 循环学说。它把 Lavoisier 开辟的生物氧化及能代谢，写成体内可周转的能量通货。
:::

:::note{label="动态阶段已经基本确定的代谢途径"}
教材点名的途径包括：糖代谢途径的酶促反应过程、脂肪酸 $\beta$ 氧化、尿素合成途径及三羧酸循环。技术条件是化学分析及核素示踪。途径“基本确定”不等于调节机制已经阐明——调节要留到机能阶段和当代研究内容。
:::

:::pitfall{label="酶在叙述阶段是可溶性催化剂，到动态阶段才被写成蛋白质"}
不要把“酶”在三阶段里写成同一句话。叙述阶段：酵母发酵中存在可溶性催化剂，奠定酶学基础。动态阶段：酶的化学本质是蛋白质，酶晶体可以制备。机能阶段还会补上一笔：核酶是对“生物催化剂都是蛋白质”的补充。三句话并成一句，核酶就没有地方可放。
:::

## 四、机能生物化学阶段以建立分子生物学为主要标志

$20$ 世纪后半叶以来，生物化学发展的显著特征是分子生物学的崛起。其间，物质代谢途径的研究继续发展，并进入合成代谢与代谢调节的研究。其主要领域和重要成就如下。

:::note{label="第三阶段并没有丢掉代谢"}
机能阶段的标志是分子生物学崛起，但教材同时写明：物质代谢途径的研究继续发展，并进入合成代谢与代谢调节。核酸那本账和代谢那本账是并行的，不是前者取代后者。
:::

### DNA 双螺旋结构和中心法则

关于遗传物质 DNA 的研究可以看作是第三阶段的标志性研究。著名的肺炎球菌实验证明 DNA 是细胞遗传信息的基本物质；$1953$ 年，Watson J.D. 和 Crick F.H. 提出 DNA 双螺旋结构模型，为揭示遗传信息传递规律奠定了基础，这是生物化学进入分子生物学时代的重要标志；$1958$ 年 Crick F.H. 提出了遗传信息传递的“中心法则”，为分子生物学奠定了基础；同年，Brenner S. 提出信使 RNA 的概念，并证实了其在指导合成蛋白质中的作用；随后，tRNA 的序列和结构被确立，核苷酸结构被确定并合成了低分子的核苷酸，遗传密码被破译。此后，对 DNA 的复制机制、RNA 的转录过程以及蛋白质合成过程进行了深入研究；通过对大肠埃希菌乳糖代谢的研究，阐明了基因通过控制酶的生物合成调节细胞代谢的模式，提出了操纵子学说。这些成果深化了人们对核酸与蛋白质的关系及其在生命活动中作用的认识。

:::definition{label="肺炎球菌实验"}
著名的肺炎球菌实验证明 DNA 是细胞遗传信息的基本物质。教材把它放在第三阶段标志性研究的开头：先确认“遗传物质是 DNA”，才谈得上双螺旋和中心法则。
:::

:::definition{label="DNA 双螺旋结构模型"}
$1953$ 年，Watson J.D. 和 Crick F.H. 提出 DNA 双螺旋结构模型，为揭示遗传信息传递规律奠定了基础。教材明确：这是生物化学进入分子生物学时代的重要标志。
:::

:::definition{label="中心法则"}
$1958$ 年 Crick F.H. 提出遗传信息传递的“中心法则”，为分子生物学奠定了基础。它写的是遗传信息在 DNA、RNA 与蛋白质之间的传递方向，不是某一条具体代谢途径。
:::

:::definition{label="信使 RNA"}
$1958$ 年，Brenner S. 提出信使 RNA 的概念，并证实了其在指导合成蛋白质中的作用。中心法则里“DNA → 蛋白质”中间必须有这一本账。
:::

:::definition{label="操纵子学说"}
通过对大肠埃希菌乳糖代谢的研究，阐明了基因通过控制酶的生物合成调节细胞代谢的模式，提出了操纵子学说。它把“基因—酶—代谢”连成一条调节链。
:::

:::concept{term="先问遗传物质是不是 DNA，再问信息按什么方向传"}
机能阶段不要从双螺旋直接跳到基因组。先有肺炎球菌实验把遗传物质写成 DNA；$1953$ 年双螺旋给出结构，这是进入分子生物学时代的标志；$1958$ 年中心法则给出信息传递方向，同年 mRNA 被提出并证实指导蛋白质合成；随后才是 tRNA、遗传密码、复制、转录、蛋白质合成，以及乳糖代谢上的操纵子。把 $1953$ 年听成中心法则已经提出，或把操纵子听成人类基因组计划，中间几十年会被并成一句。
:::

:::cause-effect{title="双螺旋怎样把生物化学推进分子生物学时代"}
- **因** Watson 与 Crick 在 $1953$ 年提出 DNA 双螺旋结构模型
- **果** 遗传信息传递规律有了结构基础；教材把这一年写成生物化学进入分子生物学时代的重要标志
:::

### 蛋白质结构与生物合成

$20$ 世纪 $50$ 年代初期发现了蛋白质的 $\alpha$-螺旋的二级结构形式；完成了胰岛素和核糖核酸酶的氨基酸序列分析；发现了转运 RNA 和氨酰 tRNA 合成酶以及它们在蛋白质合成中的作用，阐明了氨基酸参与蛋白质合成的活化机制；利用 X 射线衍射和冷冻电镜技术解析了烟草花叶病病毒的结构等。

:::definition{label="α-螺旋"}
$20$ 世纪 $50$ 年代初期发现了蛋白质的 $\alpha$-螺旋的二级结构形式。叙述阶段的多肽学说只写到氨基酸如何连接；二级结构是机能阶段蛋白质结构那本账的起点。
:::

:::definition{label="氨基酸的活化"}
发现转运 RNA 和氨酰 tRNA 合成酶以及它们在蛋白质合成中的作用，阐明了氨基酸参与蛋白质合成的活化机制。蛋白质合成不是氨基酸自己“碰上就连”，必须先被活化并挂到 tRNA 上。
:::

:::note{label="胰岛素序列在机能阶段，人工合成牛胰岛素在中国贡献里"}
教材在此写的是完成胰岛素和核糖核酸酶的氨基酸序列分析。我国 $1965$ 年人工合成有生物活性的牛胰岛素，以及解出猪胰岛素晶体结构，放在第五节中国贡献，不要两笔并成一次发现。
:::

### 重组 DNA 技术得到广泛应用

$20$ 世纪 $70$ 年代，由于 DNA 连接酶、限制性内切核酸酶、逆转录酶以及各种载体的发现和应用，使得重组 DNA 技术取得了极大的突破。重组 DNA 技术的建立不仅促进了对基因表达调控机制的研究，而且使人们主动改造生物体成为可能。由此，相继获得了多种基因工程产品，极大地推动了医药工业和农业的发展。转基因动植物和基因敲除（gene knock out）动物模型的成功是重组 DNA 技术发展的结果。基因诊断与基因治疗也是重组 DNA 技术在医学领域应用的重要方面。$20$ 世纪 $80$ 年代，核酶（ribozyme）的发现是人们对生物催化剂认识的补充。聚合酶链反应技术的发明，使人们有可能在体外高效率扩增 DNA。这些成果都是分子生物学发展的重大事件。

:::definition{label="重组 DNA 技术"}
$20$ 世纪 $70$ 年代，DNA 连接酶、限制性内切核酸酶、逆转录酶以及各种载体的发现和应用，使重组 DNA 技术取得极大突破。它既推动基因表达调控研究，也使主动改造生物体成为可能。
:::

:::definition{label="基因敲除"}
基因敲除（gene knock out）动物模型的成功是重组 DNA 技术发展的结果，与转基因动植物并列。后面当代内容和分子治疗还会用到“敲除／敲入／编辑”，此处先立户头。
:::

:::definition{label="核酶"}
$20$ 世纪 $80$ 年代发现核酶（ribozyme），是对生物催化剂认识的补充：催化剂不都是蛋白质。
:::

:::definition{label="聚合酶链反应"}
聚合酶链反应技术的发明，使人们有可能在体外高效率扩增 DNA。教材把它与核酶一并列为 $20$ 世纪 $80$ 年代分子生物学的重大事件。
:::

:::insight{label="重组 DNA 同时打开三扇门：机理、产品、医学"}
教材写明三条去向：促进基因表达调控机制研究；获得基因工程产品，推动医药工业和农业；在医学上落到基因诊断与基因治疗，以及转基因、基因敲除模型。只记“能把 DNA 接到一起”，后面的分子诊断和分子治疗会少掉技术源头。
:::

### 基因组学及其他组学的研究

$20$ 世纪末启动的人类基因组计划（human genome project）是人类生命科学中的伟大创举。人类基因组计划是描述人类基因组特征，包括物理图谱、遗传图谱、基因组 DNA 序列测定。$2001$ 年 $2$ 月，人类基因组草图公布；$2003$ 年 $4$ 月，覆盖人常染色体基因组 $99\%$ 序列的人类基因组图绘制完成。

$2003$ 年 $9$ 月，DNA 元件百科全书（the Encyclopedia of DNA Elements，ENCODE）计划正式启动，其目的在于鉴定人类基因组中所有的功能片段。

蛋白质组学（proteomics）研究包括阐明蛋白质的定位、结构与功能、相互作用以及特定时空的蛋白质表达谱等，已成为生物化学的又一研究热点。由于蛋白质具有更为复杂的三维结构，无疑确定人类所有蛋白质的结构比测定人类基因组序列更具挑战性。

转录物组学（transcriptomics）研究细胞在某一功能状态下基因组转录产生的全部转录物的种类、结构和功能。RNA 组学（RNomics）主要研究 snmRNA 的种类、结构、功能等，探讨同一生物不同组织细胞或同一细胞在不同时空状态下 snmRNA 的表达谱及其功能的变化及其与蛋白质的相互作用。

代谢组学（metabonomics）研究的是生物体对外源性物质的刺激、环境变化或遗传修饰所作出的所有代谢应答的全貌和动态变化过程，其研究对象为完整的多细胞生物系统，包括了生命个体与环境的相互作用。

糖组学（glycomics）主要研究单个生物体所包含的所有聚糖的结构、功能（包括与蛋白质的相互作用）等生物学作用，糖组学的出现使人类可以更深刻理解第三类生物信息大分子——聚糖在生命活动中的作用。

总之，阐明人类基因组功能是一项多学科的任务，正吸引着生物学、医学、化学、物理、数学、工程和计算机等领域的学者共同参与，从中整合所有基因组信息，分析各种数据并提取其生物学意义，因而产生了一门前景广阔的新兴学科——生物信息学（bioinformatics）。尽管生物化学与分子生物学的发展异常迅速，但人类基因组序列的揭晓仅是序幕而已，生命本质的阐明任重而道远。

:::definition{label="人类基因组计划"}
人类基因组计划（human genome project）描述人类基因组特征，包括物理图谱、遗传图谱、基因组 DNA 序列测定。$2001$ 年 $2$ 月公布草图；$2003$ 年 $4$ 月绘制完成覆盖人常染色体基因组 $99\%$ 序列的人类基因组图。
:::

:::definition{label="ENCODE 计划"}
$2003$ 年 $9$ 月启动的 DNA 元件百科全书（the Encyclopedia of DNA Elements，ENCODE）计划，目的在于鉴定人类基因组中所有的功能片段。序列测完不等于功能片段已经鉴定。
:::

:::definition{label="蛋白质组学"}
蛋白质组学（proteomics）阐明蛋白质的定位、结构与功能、相互作用以及特定时空的蛋白质表达谱。蛋白质三维结构更复杂，确定人类所有蛋白质的结构比测定基因组序列更具挑战性。
:::

:::definition{label="转录物组学"}
转录物组学（transcriptomics）研究细胞在某一功能状态下基因组转录产生的全部转录物的种类、结构和功能。
:::

:::definition{label="RNA 组学"}
RNA 组学（RNomics）主要研究 snmRNA 的种类、结构、功能等，并探讨同一生物不同组织细胞或同一细胞在不同时空状态下 snmRNA 的表达谱、功能变化及其与蛋白质的相互作用。
:::

:::definition{label="代谢组学"}
代谢组学（metabonomics）研究生物体对外源性物质的刺激、环境变化或遗传修饰所作出的所有代谢应答的全貌和动态变化过程。对象是完整的多细胞生物系统，包括生命个体与环境的相互作用。
:::

:::definition{label="糖组学"}
糖组学（glycomics）研究单个生物体所包含的所有聚糖的结构、功能（包括与蛋白质的相互作用）等生物学作用。聚糖被教材称为第三类生物信息大分子。
:::

:::definition{label="生物信息学"}
生物信息学（bioinformatics）在多学科参与下整合基因组信息，分析各种数据并提取其生物学意义。它是阐明人类基因组功能这项任务中长出来的新兴学科。
:::

:::compare{title="基因组之后的几门组学"}
| 组学 | 英文 | 主要对象 | 要回答的问题 |
|------|------|----------|--------------|
| 人类基因组计划 | human genome project | 物理图谱、遗传图谱、基因组 DNA 序列 | 人的基因组长什么样、序列是什么 |
| ENCODE | Encyclopedia of DNA Elements | 基因组中的功能片段 | 序列里哪些片段有功能 |
| 蛋白质组学 | proteomics | 蛋白质定位、结构与功能、相互作用、时空表达谱 | 基因产物在何时何地做什么 |
| 转录物组学 | transcriptomics | 某一功能状态下全部转录物的种类、结构、功能 | 基因组当时转录出了什么 |
| RNA 组学 | RNomics | snmRNA 的种类、结构、功能、时空表达谱及与蛋白质的相互作用 | 非编码小 RNA 怎样参与调控 |
| 代谢组学 | metabonomics | 完整多细胞系统的全部代谢应答及动态 | 刺激、环境或遗传修饰引起哪些代谢变化 |
| 糖组学 | glycomics | 一个生物体的全部聚糖及其与蛋白质的相互作用 | 第三类生物信息大分子如何工作 |
:::

:::insight{label="基因组揭晓只是序幕，不是生命本质的句号"}
教材把 $2001$ 草图、$2003$ 完成写成伟大创举，紧接着就写 ENCODE、蛋白质组、转录物组、RNA 组、代谢组、糖组和生物信息学，并收束为：人类基因组序列的揭晓仅是序幕，生命本质的阐明任重而道远。把“测完全序列”听成“生物化学已经做完”，当代四大研究内容会变成多余的章节。
:::

:::pitfall{label="2003 年完成的是常染色体基因组 99% 序列，不是“全部染色体 100%”"}
教材的原句是：覆盖人常染色体基因组 $99\%$ 序列的人类基因组图绘制完成。不要改写成“人类全部基因组 $100\%$ 完成”。ENCODE 启动于同年 $9$ 月，户头是功能片段，不是再测一遍序列。
:::

## 五、中国科学家对生物化学发展作出了重要贡献

早在西方生物化学诞生之前，我们的祖先就已在生产、饮食及医疗等方面积累了丰富的经验，其中许多成为现代生物化学的发展源头。

公元前 $22$ 世纪，我国人民已能酿酒，这是我国古代用“曲”作“媒”（即酶）催化谷物淀粉发酵的实践。《周礼》中有造酱、制饴的记载，《伤寒论》中用豆豉作为健胃剂；《黄帝内经素问》中有关于糖的营养价值的记载，并记载了完全膳食必备的条件，且区分了谷、畜、果、蔬四类食物的营养性质。我们现在也已知道，古人用于治疗预防“脚气病”“夜盲症”的药品或食品富含维生素 $\mathrm{B}_1$ 或维生素 A。《本草纲目》中不仅记录了上千种的药物，并且对人体的代谢物及分泌物进行了比较详细的记载。

:::definition{label="曲作媒"}
公元前 $22$ 世纪的酿酒，是用“曲”作“媒”（即酶）催化谷物淀粉发酵的实践。教材把“媒”明确对应为酶，这是中国古代酶学实践的源头，不是近代酶晶体那一笔。
:::

:::note{label="古籍里已经写下的营养与代谢经验"}
- 《周礼》：造酱、制饴。
- 《伤寒论》：豆豉作为健胃剂。
- 《黄帝内经素问》：糖的营养价值、完全膳食的条件、谷畜果蔬四类食物的营养性质。
- 脚气病、夜盲症的防治对应富含维生素 $\mathrm{B}_1$ 或维生素 A 的药品或食品。
- 《本草纲目》：上千种药物，并对人体代谢物及分泌物有比较详细的记载。
:::

近代生物化学发展时期，我国生物化学家吴宪等在血液化学分析方面，创立了血滤液的制备和血糖测定法；在蛋白质研究中提出了蛋白质变性学说。我国生物化学家刘思职在免疫化学领域，用定量分析方法研究抗原抗体反应机制，成为免疫化学的创始人之一。$1965$ 年，我国科学家首先采用人工方法合成了具有生物活性的牛胰岛素，解出了猪胰岛素的晶体结构；$1981$ 年，采用了有机合成和酶促相结合的方法成功地合成了酵母丙氨酰 tRNA。此外，在酶学、蛋白质结构、生物膜结构与功能方面的研究都有举世瞩目的成就。近年来，我国科学家在基因工程、蛋白质工程、新基因的克隆与功能、疾病相关基因的定位克隆及其功能研究、蛋白质结构研究、基因编辑研究等领域均取得了重要成果。特别要指出的是，人类基因组序列草图的完成也有我国科学家的一份贡献。

:::definition{label="吴宪的工作"}
吴宪等创立血滤液的制备和血糖测定法，并在蛋白质研究中提出蛋白质变性学说。
:::

:::definition{label="刘思职与免疫化学"}
刘思职用定量分析方法研究抗原抗体反应机制，成为免疫化学的创始人之一。
:::

:::definition{label="人工合成牛胰岛素"}
$1965$ 年，我国科学家首先采用人工方法合成了具有生物活性的牛胰岛素，并解出了猪胰岛素的晶体结构。教材强调的是“具有生物活性”，不是只连出一条肽。
:::

:::definition{label="酵母丙氨酰 tRNA 的合成"}
$1981$ 年，采用有机合成和酶促相结合的方法成功地合成了酵母丙氨酰 tRNA。
:::

- **叙述阶段（18世纪中叶至20世纪初）** 组成、分离纯化、肽键与多肽学说、可溶性催化剂
- **1921** Banting 从狗胰腺提取胰岛素并用于糖尿病治疗
- **动态阶段（20世纪20年代起）** 必需氨基酸/脂肪酸/维生素、激素、酶是蛋白质、β氧化、三羧酸循环、ATP 循环；核素标记、电泳、X 射线晶体学

:::memory{label="本节必背要点"}
- [ ] 生物化学与分子生物学是在分子水平研究和阐明生命现象本质和规律的基础学科，既是生物学和医学的共同基础，又是发展最为迅速的前沿学科。
- [ ] 生物化学早期是生理学的分支，曾被称为生理化学（physiological chemistry）。
- [ ] 生物化学利用化学、物理学和数学的原理和方法，研究生物的化学组成、化学结构及其在生理过程中的变化。
- [ ] 过去 $70$ 年，生物大分子的结构与功能成为热点，形成分子生物学，将生物化学带入新时代。
- [ ] $1877$ 年德国 Felix H. 提出 biochemie，英语为 biochemistry。
- [ ] 生物化学直到 $19$ 世纪末才真正成为独立学科，并在 $20$ 世纪初期蓬勃发展。
- [ ] $20$ 世纪 $50$ 年代苏联生物化学家划分为叙述、动态、机能三个阶段；第三阶段亦称分子生物学阶段。
- [ ] Hopkins F.G. 倡导用化学方法研究生命物质及生物化学反应，主张交叉融合，坚持研究所有生物最根本的生命规律。
- [ ] $18$ 世纪中叶 Scheele C.W. 分离甘油、柠檬酸、苹果酸、乳酸、尿酸、酒石酸等，奠定现代生物化学基础。
- [ ] $1785$ 年 Lavoisier A.L. 提出呼吸本质与燃烧一样，是生物氧化及能代谢研究的开端。
- [ ] $1828$ 年 Wöhler F. 体外合成尿素，打破化学方法不适合生命物质研究的观念。
- [ ] $1896$ 年 Buchner E. 发现酵母提取液仍能发酵，水溶性成分不依赖完整活细胞。
- [ ] $1921$ 年 Banting F.G. 从狗胰腺提取胰岛素并成功用于糖尿病治疗。
- [ ] 叙述阶段（$18$ 世纪中叶至 $20$ 世纪初）主要研究化学组成，以及分离、纯化、合成、结构测定和理化性质。
- [ ] 叙述阶段提出蛋白质分子结构的多肽学说，证实肽键形成；酵母发酵中的“可溶性催化剂”奠定酶学基础。
- [ ] 动态阶段从 $20$ 世纪 $20$ 年代开始，主要研究体内物质代谢规律。
- [ ] 动态阶段发现必需氨基酸、必需脂肪酸及多种维生素；分离并合成多种激素。
- [ ] 动态阶段认识到酶的化学本质是蛋白质，酶晶体制备成功。
- [ ] 动态阶段基本确定糖代谢酶促过程、脂肪酸 $\beta$ 氧化、尿素合成途径及三羧酸循环，并提出 $\mathrm{ATP}$ 循环学说。
- [ ] 动态阶段的关键技术包括放射性核素标记、电泳和 X 射线晶体学。
- [ ] 机能阶段以建立分子生物学为主要标志；代谢研究同时进入合成代谢与代谢调节。
- [ ] 肺炎球菌实验证明 DNA 是细胞遗传信息的基本物质。
- [ ] $1953$ 年 Watson 与 Crick 提出 DNA 双螺旋结构模型，是进入分子生物学时代的重要标志。
- [ ] $1958$ 年 Crick 提出中心法则；同年 Brenner 提出信使 RNA 并证实其指导蛋白质合成。
- [ ] 随后 tRNA 序列与结构被确立，遗传密码被破译；复制、转录、蛋白质合成被深入研究。
- [ ] 大肠埃希菌乳糖代谢研究提出操纵子学说：基因通过控制酶的生物合成调节细胞代谢。
- [ ] $20$ 世纪 $50$ 年代初期发现蛋白质 $\alpha$-螺旋；完成胰岛素和核糖核酸酶氨基酸序列分析。
- [ ] $20$ 世纪 $70$ 年代重组 DNA 技术因连接酶、限制性内切核酸酶、逆转录酶和载体而突破。
- [ ] 转基因动植物和基因敲除（gene knock out）动物模型、基因诊断与基因治疗是重组 DNA 的重要应用。
- [ ] $20$ 世纪 $80$ 年代发现核酶（ribozyme）；发明聚合酶链反应，可体外高效率扩增 DNA。
- [ ] 人类基因组计划包括物理图谱、遗传图谱、基因组 DNA 序列测定。
- [ ] $2001$ 年 $2$ 月公布人类基因组草图；$2003$ 年 $4$ 月完成覆盖人常染色体基因组 $99\%$ 序列的基因组图。
- [ ] $2003$ 年 $9$ 月 ENCODE 计划启动，旨在鉴定人类基因组中所有功能片段。
- [ ] 组学还包括蛋白质组学、转录物组学、RNA 组学、代谢组学、糖组学；并产生生物信息学。
- [ ] 人类基因组序列揭晓仅是序幕，生命本质的阐明任重而道远。
- [ ] 公元前 $22$ 世纪我国以曲作媒（酶）酿酒；《本草纲目》记载药物及人体代谢物、分泌物。
- [ ] 吴宪创立血滤液制备和血糖测定法，提出蛋白质变性学说；刘思职是免疫化学创始人之一。
- [ ] $1965$ 年我国首先人工合成有生物活性的牛胰岛素，解出猪胰岛素晶体结构。
- [ ] $1981$ 年用有机合成和酶促相结合的方法合成酵母丙氨酰 tRNA。
- [ ] 人类基因组序列草图的完成有我国科学家的贡献。
