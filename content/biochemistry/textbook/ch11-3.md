# 第三节　嘧啶核苷酸的合成与分解代谢

第二节把嘌呤环写在磷酸核糖上，分解停在尿酸。本节换一套顺序：先在胞质写成嘧啶六元环（乳清酸），再与 $\mathrm{PRPP}$ 相连得到 $\mathrm{UMP}$；$\mathrm{CPS}$ Ⅱ是哺乳类的调节酶，和第九章尿素的 $\mathrm{CPS}$ Ⅰ不要并户。$\mathrm{dTMP}$ 由胸苷酸合酶给 $\mathrm{dUMP}$ 加甲基，$5$-氟尿嘧啶和甲氨蝶呤都卡在这里。分解产物是易溶的 $\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸和 $\beta$-氨基异丁酸。章末收全章小结和思考题。

与嘌呤核苷酸一样，体内嘧啶核苷酸的合成也有两条途径，即从头合成途径和补救合成途径。

:::concept{term="先问嘧啶环是不是先写好再接核糖，再问 CPS Ⅱ 还是 CPS Ⅰ"}
嘧啶从头合成的特点：先合成含嘧啶六元环的乳清酸，再与 $\mathrm{PRPP}$ 连到核糖-$5$-磷酸上。氨基甲酰磷酸这一笔，尿素走线粒体 $\mathrm{CPS}$ Ⅰ、氮源是 $\mathrm{NH}_3$；嘧啶走细胞质 $\mathrm{CPS}$ Ⅱ、氮源是谷氨酰胺。两酶同名不同户。
:::

:::definition{label="嘧啶核苷酸的两条合成途径"}
体内嘧啶核苷酸的合成同样有从头合成途径和补救合成途径。
:::

## 一、嘧啶核苷酸的合成也有从头合成与补救合成两条途径

### （一）嘧啶核苷酸的从头合成先合成嘧啶环

#### 1. 从头合成途径

放射性核素示踪实验证明，嘧啶核苷酸中嘧啶碱合成的原料来自谷氨酰胺、$\mathrm{CO}_2$ 和天冬氨酸等（图11-10）。嘧啶核苷酸的合成主要发生在肝组织，反应过程在细胞质和线粒体中进行。

与嘌呤核苷酸的从头合成途径不同，嘧啶核苷酸的合成是先合成含有嘧啶六元环的乳清酸，然后再与 $\mathrm{PRPP}$ 反应连接到核糖-$5$-磷酸上。

::figure{src="/images/biochemistry/textbook/p0254_01.png" caption="图11-10　嘧啶碱合成的元素来源。N-3 与 C-2 来自氨基甲酰磷酸；N-1、C-4、C-5、C-6 来自天冬氨酸。" alt="嘧啶环原子来源：氨基甲酰磷酸贡献 N-3 和 C-2，天冬氨酸贡献其余四原子"}

:::definition{label="嘧啶碱的元素来源"}
嘧啶碱的原料来自谷氨酰胺、$\mathrm{CO}_2$ 和天冬氨酸等。图11-10：氨基甲酰磷酸贡献 $\mathrm{N}$-$3$ 与 $\mathrm{C}$-$2$（氨基甲酰磷酸本身由谷氨酰胺、$\mathrm{CO}_2$ 经 $\mathrm{CPS}$ Ⅱ写成）；天冬氨酸贡献 $\mathrm{N}$-$1$、$\mathrm{C}$-$4$、$\mathrm{C}$-$5$、$\mathrm{C}$-$6$。
:::

:::definition{label="嘧啶从头合成的顺序特点"}
先合成含嘧啶六元环的乳清酸，再与 $\mathrm{PRPP}$ 反应连接到核糖-$5$-磷酸上。这与嘌呤“环在磷酸核糖上逐步写成”相反。
:::

:::compare{title="嘌呤环 vs 嘧啶环的原子来源"}
| 来源 | 嘌呤（图11-2） | 嘧啶（图11-10） |
|------|----------------|-----------------|
| 天冬氨酸 | $\mathrm{N}$-$1$ | $\mathrm{N}$-$1$、$\mathrm{C}$-$4$、$\mathrm{C}$-$5$、$\mathrm{C}$-$6$（几乎半个环） |
| 谷氨酰胺 | $\mathrm{N}$-$3$、$\mathrm{N}$-$9$ | 经氨基甲酰磷酸写入 $\mathrm{N}$-$3$（及 $\mathrm{C}$-$2$ 的碳来自 $\mathrm{CO}_2$） |
| $\mathrm{CO}_2$ | $\mathrm{C}$-$6$ | 氨基甲酰磷酸的 $\mathrm{C}$-$2$ |
| 甘氨酸 | $\mathrm{C}$-$4$、$\mathrm{C}$-$5$、$\mathrm{N}$-$7$ | 不参与嘧啶环 |
| 一碳单位 | $\mathrm{C}$-$2$、$\mathrm{C}$-$8$ | 环本身不用；$\mathrm{dTMP}$ 的甲基另算 |

嘧啶环更“省”：三样原料（谷氨酰胺、$\mathrm{CO}_2$、天冬氨酸）写完六元环。一碳单位留给胸苷酸。
:::

:::pitfall{label="嘧啶合成主要在肝，但反应跨细胞质和线粒体"}
不要写成“全部在胞质”或“全部在线粒体”。氨基甲酰磷酸在细胞质由 $\mathrm{CPS}$ Ⅱ生成；教材写明过程在细胞质和线粒体中进行。和尿素循环“线粒体两步、胞质三步”不是同一张定位图。
:::

**（1）尿嘧啶核苷酸的合成**　嘧啶环的合成始于氨基甲酰磷酸的生成。正如氨基酸代谢一章所讨论的，氨基甲酰磷酸也是尿素合成的中间产物。但是，尿素合成中所需的氨基甲酰磷酸是在肝线粒体中由氨基甲酰磷酸合成酶（carbamoyl phosphate synthetase，$\mathrm{CPS}$）Ⅰ催化生成的；而嘧啶合成所用的氨基甲酰磷酸则是在细胞质中以谷氨酰胺为氮源，由 $\mathrm{CPS}$ Ⅱ催化生成。这两种合成酶的性质不同。

上述生成的氨基甲酰磷酸在细胞质中的天冬氨酸氨基甲酰转移酶（aspartate transcarbamoylase）催化下，与天冬氨酸化合生成氨甲酰天冬氨酸。后者经二氢乳清酸酶催化脱水，形成具有嘧啶环的二氢乳清酸，再经二氢乳清酸脱氢酶作用，脱氢成为乳清酸（orotic acid，$\mathrm{OA}$）。乳清酸不是构成核酸的嘧啶碱，但它在乳清酸磷酸核糖转移酶催化下可与 $\mathrm{PRPP}$ 结合，生成乳清酸核苷酸（orotidine-$5'$-monophosphate，$\mathrm{OMP}$），后者再由乳清酸核苷酸脱羧酶催化脱去羧基，即生成尿嘧啶核苷酸（uridine monophosphate，$\mathrm{UMP}$）。$\mathrm{UMP}$ 由激酶催化被磷酸化生成 $\mathrm{UTP}$；$\mathrm{UTP}$ 可由胞苷酸合成酶催化进一步生成 $\mathrm{CTP}$（图11-11）。

::figure{src="/images/biochemistry/textbook/p0254_02.png" caption="图11-11　嘧啶核苷酸的合成代谢。CPS Ⅱ 消耗 2 ATP，由 CO2 与谷氨酰胺生成氨基甲酰磷酸；天冬氨酸氨基甲酰转移酶写入天冬氨酸；二氢乳清酸酶脱水成环；脱氢酶生成乳清酸；磷酸核糖转移酶接 PRPP 得 OMP；脱羧酶放出 CO2 得 UMP。UMP 经 UDP、UTP 到 CTP；UDP 还原得 dUDP，再经 dUMP 由胸苷酸合酶写成 dTMP。" alt="嘧啶从头合成：氨基甲酰磷酸到乳清酸、OMP、UMP，并分出 CTP 与 dTMP"}

在真核细胞中嘧啶核苷酸合成的前三个酶，即氨基甲酰磷酸合成酶Ⅱ、天冬氨酸氨基甲酰转移酶和二氢乳清酸酶，位于分子量约为 $200\,\mathrm{kD}$ 的同一条多肽链上，因此是一种多功能酶；后两个酶也是位于同一条多肽链上的多功能酶。这种方式更有利于以均匀的速度参与嘧啶核苷酸的合成。

:::definition{label="CPS Ⅱ"}
氨基甲酰磷酸合成酶Ⅱ（carbamoyl phosphate synthetase Ⅱ，$\mathrm{CPS}$ Ⅱ）在细胞质中以谷氨酰胺为氮源，催化嘧啶合成所用的氨基甲酰磷酸生成。与尿素循环的 $\mathrm{CPS}$ Ⅰ性质不同。
:::

:::definition{label="CPS Ⅰ（对照第九章）"}
尿素合成中的氨基甲酰磷酸在肝线粒体由 $\mathrm{CPS}$ Ⅰ催化生成。氮源账走游离 $\mathrm{NH}_3$，不走谷氨酰胺。本节只借用这一笔对照，不重写鸟氨酸循环。
:::

:::definition{label="天冬氨酸氨基甲酰转移酶"}
天冬氨酸氨基甲酰转移酶（aspartate transcarbamoylase）在细胞质催化氨基甲酰磷酸与天冬氨酸生成氨甲酰天冬氨酸。
:::

:::definition{label="乳清酸"}
乳清酸（orotic acid，$\mathrm{OA}$）由氨甲酰天冬氨酸经二氢乳清酸酶脱水成二氢乳清酸，再经二氢乳清酸脱氢酶脱氢而成。它具有嘧啶六元环，但不是构成核酸的嘧啶碱。
:::

:::definition{label="OMP 与 UMP"}
乳清酸磷酸核糖转移酶催化乳清酸 $+\mathrm{PRPP}\rightarrow$ 乳清酸核苷酸（orotidine-$5'$-monophosphate，$\mathrm{OMP}$）。乳清酸核苷酸脱羧酶使 $\mathrm{OMP}$ 脱羧，生成尿嘧啶核苷酸（uridine monophosphate，$\mathrm{UMP}$）。
:::

:::timeline{period="UMP 从头合成"}
- **氨基甲酰磷酸** 细胞质 CPS Ⅱ：谷氨酰胺 + CO2（图11-11 消耗 2 ATP）
- **氨甲酰天冬氨酸** 天冬氨酸氨基甲酰转移酶写入天冬氨酸，放出 Pi
- **二氢乳清酸** 二氢乳清酸酶脱水，六元环出现
- **乳清酸** 二氢乳清酸脱氢酶脱氢（图上 NAD+）
- **OMP** 乳清酸磷酸核糖转移酶接 PRPP
- **UMP** 乳清酸核苷酸脱羧酶脱去羧基（放出 CO2）
:::

:::compare{title="CPS Ⅰ 与 CPS Ⅱ"}
| 项目 | $\mathrm{CPS}$ Ⅰ | $\mathrm{CPS}$ Ⅱ |
|------|------------------|------------------|
| 代谢账 | 尿素循环（第九章） | 嘧啶核苷酸合成（本节） |
| 部位 | 肝线粒体 | 细胞质 |
| 氮源 | $\mathrm{NH}_3$ | 谷氨酰胺 |
| 调节（后文） | 需 $N$-乙酰谷氨酸 | 哺乳类受 $\mathrm{UMP}$ 抑制 |

同叫氨基甲酰磷酸合成酶，产物都是氨基甲酰磷酸，后续去向完全不同：Ⅰ交给鸟氨酸写瓜氨酸，Ⅱ交给天冬氨酸写嘧啶环。
:::

:::keypoint{label="真核多功能酶两段"}
- 前三个酶（$\mathrm{CPS}$ Ⅱ、天冬氨酸氨基甲酰转移酶、二氢乳清酸酶）在同一条约 $200\,\mathrm{kD}$ 多肽上。
- 后两个酶（乳清酸磷酸核糖转移酶、乳清酸核苷酸脱羧酶）也在同一条多肽上。
- 好处：以均匀的速度参与嘧啶核苷酸合成。
:::

:::pitfall{label="乳清酸不是 U、C、T 中的任何一种"}
教材写明：乳清酸不是构成核酸的嘧啶碱。它只是带羧基的中间物，$\mathrm{OMP}$ 脱羧以后才是 $\mathrm{UMP}$。补救途径的嘧啶磷酸核糖转移酶可以利用乳清酸，那是把这条中间物拣回去，不等于乳清酸出现在 $\mathrm{RNA}/\mathrm{DNA}$ 里。
:::

:::insight{label="接 PRPP 的这一步才把嘧啶环装上核糖"}
嘌呤从第①步起就带着磷酸核糖。嘧啶直到乳清酸磷酸核糖转移酶才第一次见到 $\mathrm{PRPP}$。$\mathrm{PRPP}$ 不够时，嘌呤补救和嘧啶从头的这一步会一起受影响——这也是 $\mathrm{PRPP}$ 合成酶同时接受两类核苷酸反馈抑制的结构原因。
:::

**（2）$\mathrm{CTP}$ 的合成**　$\mathrm{UMP}$ 通过尿苷酸激酶和核苷二磷酸激酶的连续作用，生成尿苷三磷酸（$\mathrm{UTP}$），并在 $\mathrm{CTP}$ 合成酶催化下，消耗一分子 $\mathrm{ATP}$，从谷氨酰胺接受氨基而成为胞苷三磷酸（$\mathrm{CTP}$）。

:::definition{label="CTP 合成酶"}
$\mathrm{UMP}$ 经尿苷酸激酶和核苷二磷酸激酶生成 $\mathrm{UTP}$。$\mathrm{CTP}$ 合成酶消耗 $1$ 分子 $\mathrm{ATP}$，从谷氨酰胺接受氨基，把 $\mathrm{UTP}$ 写成 $\mathrm{CTP}$。
:::

:::pitfall{label="胞嘧啶不是在 UMP 水平上氨基化"}
氨基加在 $\mathrm{UTP}$ 上，产物是 $\mathrm{CTP}$。不要画成 $\mathrm{UMP}\rightarrow\mathrm{CMP}$ 再磷酸化。氮杂丝氨酸类似谷氨酰胺，可以抑制 $\mathrm{CTP}$ 的生成，卡的就是这一步。
:::

**（3）脱氧胸腺嘧啶核苷酸（$\mathrm{dTMP}$）的生成**　胸腺嘧啶的从头合成只涉及脱氧核苷酸。$\mathrm{dTMP}$ 的直接前体是 $\mathrm{dUMP}$，由脱氧尿嘧啶核苷酸（$\mathrm{dUMP}$）经甲基化而生成；该反应由胸苷酸合酶（thymidylate synthase）催化，$N^{5},N^{10}$-亚甲四氢叶酸作为甲基供体。$N^{5},N^{10}$-亚甲四氢叶酸提供甲基后生成的二氢叶酸又可在二氢叶酸还原酶的作用下，重新生成四氢叶酸。$\mathrm{dUMP}$ 可来自两个途径：一是 $\mathrm{dUDP}$ 的水解去磷酸化，另一个是 $\mathrm{dCMP}$ 的脱氨基，以后一种为主。

:::definition{label="胸苷酸合酶"}
胸苷酸合酶（thymidylate synthase）催化 $\mathrm{dUMP}$ 甲基化生成 $\mathrm{dTMP}$。甲基供体是 $N^{5},N^{10}$-亚甲四氢叶酸。
:::

:::definition{label="dUMP 的两个来源"}
$\mathrm{dUMP}$ 可来自 $\mathrm{dUDP}$ 水解去磷酸化，或 $\mathrm{dCMP}$ 脱氨基，以后一种为主。
:::

:::definition{label="胸苷酸合成中的叶酸再生"}
$N^{5},N^{10}$-亚甲四氢叶酸给出甲基后变成二氢叶酸，再经二氢叶酸还原酶重新生成四氢叶酸。甲氨蝶呤抑制该还原酶，则 $\mathrm{dUMP}$ 不能利用一碳单位甲基化生成 $\mathrm{dTMP}$。
:::

:::keypoint{label="dTMP 三句话"}
- 胸腺嘧啶的从头合成只涉及脱氧核苷酸（没有“核糖型 TMP 再还原”）。
- 直接前体是 $\mathrm{dUMP}$，不是 $\mathrm{dTTP}$ 的还原。
- 甲基来自 $N^{5},N^{10}$-亚甲四氢叶酸；$\mathrm{dUMP}$ 主要来自 $\mathrm{dCMP}$ 脱氨基。
:::

:::pitfall{label="不要把 dTMP 写成 NDP 水平还原的产物"}
第二节：除 $\mathrm{dTMP}$ 外，其他脱氧核糖核苷酸都在 $\mathrm{NDP}$ 水平还原。本节把例外写死：$\mathrm{dTMP}$ 是 $\mathrm{dUMP}$ 甲基化。$5$-$\mathrm{FU}$ 的 $\mathrm{FdUMP}$ 模仿 $\mathrm{dUMP}$ 去抑制胸苷酸合酶，不是去抑制核糖核苷酸还原酶。
:::

:::insight{label="同一把二氢叶酸还原酶，嘌呤和 dTMP 都要"}
第二节 $\mathrm{MTX}$ 卡嘌呤的 $\mathrm{C}$-$8$、$\mathrm{C}$-$2$；本节 $\mathrm{MTX}$ 卡 $\mathrm{dTMP}$ 的甲基。白血病治疗这一笔，两套核苷酸合成一起停，$\mathrm{DNA}$ 复制缺 $\mathrm{dTTP}$ 尤其明显。
:::

#### 2. 从头合成的调节

在细菌中，天冬氨酸氨基甲酰转移酶是嘧啶核苷酸从头合成的主要调节酶。但是，哺乳类动物细胞中，嘧啶核苷酸合成的调节酶则主要是 $\mathrm{CPS}$ Ⅱ，它受 $\mathrm{UMP}$ 抑制。这两种酶都受反馈机制的调节。此外，在哺乳类动物细胞中，上述 $\mathrm{UMP}$ 合成起始和终末的两种多功能酶还可受到阻遏或去阻遏的调节。核素掺入实验表明，嘧啶与嘌呤的合成有着协调控制关系，两者的合成速度通常是平行的。

由于 $\mathrm{PRPP}$ 合成酶是嘧啶与嘌呤两类核苷酸合成过程中共同需要的酶，所以它可同时接受嘧啶核苷酸及嘌呤核苷酸的反馈抑制。嘧啶核苷酸合成的调节如图所示（图11-12）。

::figure{src="/images/biochemistry/textbook/p0255_01.png" caption="图11-12　嘧啶核苷酸合成的调节部位。UMP 反馈抑制氨基甲酰磷酸生成及氨基甲酰天冬氨酸生成；嘌呤核苷酸和嘧啶核苷酸都反馈抑制 PRPP 合成（ATP+核糖-5-磷酸）。CTP 由 UTP 生成。" alt="UMP 反馈抑制 CPS Ⅱ 等早期步骤，PRPP 合成受嘌呤和嘧啶核苷酸抑制"}

:::definition{label="细菌与哺乳类的嘧啶调节酶"}
细菌：天冬氨酸氨基甲酰转移酶是嘧啶从头合成的主要调节酶。哺乳类：主要调节酶是 $\mathrm{CPS}$ Ⅱ，受 $\mathrm{UMP}$ 抑制。二者都受反馈调节。
:::

:::definition{label="嘧啶与嘌呤的协调控制"}
核素掺入实验表明，嘧啶与嘌呤的合成有协调控制关系，两者的合成速度通常是平行的。$\mathrm{PRPP}$ 合成酶可同时接受嘧啶核苷酸及嘌呤核苷酸的反馈抑制。
:::

:::compare{title="嘌呤调节 vs 嘧啶调节"}
| 项目 | 嘌呤（第二节） | 嘧啶（本节） |
|------|----------------|--------------|
| 入口酶 | $\mathrm{PRPP}$ 合成酶、酰胺转移酶 | 细菌：天冬氨酸氨基甲酰转移酶；哺乳类：$\mathrm{CPS}$ Ⅱ |
| 反馈物 | $\mathrm{IMP}$、$\mathrm{AMP}$、$\mathrm{GMP}$ | 哺乳类 $\mathrm{UMP}$ 抑制 $\mathrm{CPS}$ Ⅱ |
| 共同节点 | $\mathrm{PRPP}$ 合成酶同时受两类核苷酸反馈抑制 | 同左 |
| 额外 | $\mathrm{AMP}/\mathrm{GMP}$ 交叉调节 | 两种多功能酶可受阻遏／去阻遏 |

平行合成：核酸要 $\mathrm{A}$、$\mathrm{G}$、$\mathrm{C}$、$\mathrm{U}/\mathrm{T}$ 配齐，$\mathrm{PRPP}$ 这道闸门两边一起拧。
:::

:::pitfall{label="不要把细菌的 ATCase 主调节抄到人体"}
应试若问“哺乳类嘧啶合成的调节酶”，答案是 $\mathrm{CPS}$ Ⅱ（$\mathrm{UMP}$ 抑制），不是天冬氨酸氨基甲酰转移酶。后者是细菌的主要调节酶；图11-12 虽也标了 $\mathrm{UMP}$ 对氨基甲酰天冬氨酸生成的抑制，正文把哺乳类的“主要”写在 $\mathrm{CPS}$ Ⅱ上。
:::

### （二）嘧啶核苷酸的补救合成途径与嘌呤核苷酸类似

嘧啶磷酸核糖转移酶是嘧啶核苷酸补救合成的主要酶，它能利用尿嘧啶、胸腺嘧啶及乳清酸作为底物合成嘧啶核苷酸，催化反应的通式如下：

$$
\text{嘧啶}+\mathrm{PRPP}\xrightarrow{\text{嘧啶磷酸核糖转移酶}}\text{嘧啶核苷一磷酸}+\mathrm{PP}_\mathrm{i}
$$

嘧啶磷酸核糖转移酶已经从人红细胞中被纯化，但对胞嘧啶不起作用。

尿苷激酶也是一种补救合成酶，催化尿苷生成尿苷酸。

脱氧胸苷可通过胸苷激酶催化生成 $\mathrm{dTMP}$。此酶在正常肝中活性很低，而再生肝中酶活性升高，在恶性肿瘤中该酶活性也明显升高并与恶性程度有关。

:::definition{label="嘧啶磷酸核糖转移酶"}
嘧啶核苷酸补救合成的主要酶。利用尿嘧啶、胸腺嘧啶及乳清酸 $+\mathrm{PRPP}$ 生成相应核苷一磷酸。已从人红细胞纯化，对胞嘧啶不起作用。
:::

:::definition{label="尿苷激酶"}
补救合成酶，催化尿苷生成尿苷酸。
:::

:::definition{label="胸苷激酶"}
催化脱氧胸苷生成 $\mathrm{dTMP}$。正常肝中活性很低，再生肝中升高；恶性肿瘤中明显升高并与恶性程度有关。
:::

:::compare{title="嘌呤补救 vs 嘧啶补救"}
| 项目 | 嘌呤 | 嘧啶 |
|------|------|------|
| 磷酸核糖转移酶 | $\mathrm{APRT}$（腺嘌呤）、$\mathrm{HGPRT}$（次黄嘌呤、鸟嘌呤） | 嘧啶磷酸核糖转移酶（尿嘧啶、胸腺嘧啶、乳清酸；**不作用胞嘧啶**） |
| 核苷激酶 | 仅腺苷激酶，无其他嘌呤核苷激酶 | 尿苷激酶；另有胸苷激酶写 $\mathrm{dTMP}$ |
| 临床影 | $\mathrm{HGPRT}$ 缺失 $\rightarrow$ Lesch-Nyhan | 胸苷激酶升高与肿瘤恶性程度有关 |
:::

:::pitfall{label="胞嘧啶不能走嘧啶磷酸核糖转移酶"}
酶能用 $\mathrm{U}$、$\mathrm{T}$、乳清酸，偏偏不用胞嘧啶。胞嘧啶核苷酸主要靠 $\mathrm{UTP}\rightarrow\mathrm{CTP}$ 那一笔氨基化来，不是靠游离胞嘧啶 $+\mathrm{PRPP}$。
:::

:::insight{label="胸苷激酶升高是‘要写 DNA’的信号"}
再生肝和恶性肿瘤都在大量复制，$\mathrm{dTMP}$ 需求高，胸苷激酶活性抬上去。它把现成的脱氧胸苷拣成 $\mathrm{dTMP}$，绕过胸苷酸合酶那条甲基化。恶性程度相关，是因为增殖越旺这条补救越忙。
:::

### （三）嘧啶核苷酸的抗代谢物是嘧啶、氨基酸或叶酸等的类似物

与嘌呤核苷酸一样，嘧啶核苷酸的抗代谢物也是一些嘧啶、氨基酸或叶酸等的类似物。它们对代谢的影响及抗肿瘤作用与嘌呤抗代谢物相似。

**1. 嘧啶的类似物**　主要有 $5$-氟尿嘧啶（$5$-fluorouracil，$5$-$\mathrm{FU}$），它的结构与胸腺嘧啶相似。$5$-$\mathrm{FU}$ 本身并无生物学活性，必须在体内转变成脱氧氟尿嘧啶核苷一磷酸（$\mathrm{FdUMP}$）及氟尿嘧啶核苷三磷酸（$\mathrm{FUTP}$）后，才能发挥作用。$\mathrm{FdUMP}$ 与 $\mathrm{dUMP}$ 有相似的结构，是胸苷酸合酶的抑制剂，可以阻断 $\mathrm{dTMP}$ 的合成。$\mathrm{FUTP}$ 可以 $\mathrm{FUMP}$ 的形式掺入 $\mathrm{RNA}$ 分子，异常核苷酸的掺入破坏了 $\mathrm{RNA}$ 的结构与功能。

**2. 核苷类似物**　某些改变了核糖结构的核苷类似物，例如阿糖胞苷和安西他滨也是重要的抗肿瘤药物。阿糖胞苷能抑制 $\mathrm{CDP}$ 还原成 $\mathrm{dCDP}$，也能影响 $\mathrm{DNA}$ 的合成。

**3. 氨基酸类似物、叶酸类似物**　已在嘌呤抗代谢物中介绍。例如，由于氮杂丝氨酸类似谷氨酰胺，可以抑制 $\mathrm{CTP}$ 的生成；甲氨蝶呤干扰叶酸代谢，使 $\mathrm{dUMP}$ 不能利用一碳单位甲基化而生成 $\mathrm{dTMP}$，进而影响 $\mathrm{DNA}$ 合成。

教材第 $256$ 页图11-13　嘧啶核苷酸抗代谢物的作用电子版图源 `p0256_01.png` 为 $0$ 字节，不嵌入 `src`。图注“‖ 表示抑制”。正文已给出 $5$-$\mathrm{FU}$（$\mathrm{FdUMP}$ 抑胸苷酸合酶，$\mathrm{FUTP}/\mathrm{FUMP}$ 掺入 $\mathrm{RNA}$）、阿糖胞苷（抑 $\mathrm{CDP}\rightarrow\mathrm{dCDP}$）、氮杂丝氨酸（抑 $\mathrm{CTP}$ 生成）和甲氨蝶呤（抑 $\mathrm{dTMP}$ 甲基化）。结构式以教材印刷图为准，不引用空文件。
:::

:::definition{label="5-FU"}
$5$-氟尿嘧啶（$5$-fluorouracil，$5$-$\mathrm{FU}$）结构与胸腺嘧啶相似。本身无生物学活性，须在体内转变成 $\mathrm{FdUMP}$ 及 $\mathrm{FUTP}$。$\mathrm{FdUMP}$ 类似 $\mathrm{dUMP}$，抑制胸苷酸合酶，阻断 $\mathrm{dTMP}$ 合成；$\mathrm{FUTP}$ 可以 $\mathrm{FUMP}$ 形式掺入 $\mathrm{RNA}$，破坏 $\mathrm{RNA}$ 结构与功能。
:::

:::definition{label="阿糖胞苷与安西他滨"}
改变了核糖结构的核苷类似物，是重要的抗肿瘤药物。阿糖胞苷能抑制 $\mathrm{CDP}$ 还原成 $\mathrm{dCDP}$，也能影响 $\mathrm{DNA}$ 的合成。
:::

:::compare{title="嘧啶抗代谢物的刀口"}
| 类型 | 代表 | 模仿／改变 | 作用 |
|------|------|------------|------|
| 嘧啶类似物 | $5$-$\mathrm{FU}$ | 胸腺嘧啶 | $\mathrm{FdUMP}$ 抑胸苷酸合酶；$\mathrm{FUMP}$ 掺入 $\mathrm{RNA}$ |
| 核苷类似物 | 阿糖胞苷、安西他滨 | 核糖结构改变 | 阿糖胞苷抑 $\mathrm{CDP}\rightarrow\mathrm{dCDP}$，影响 $\mathrm{DNA}$ 合成 |
| 氨基酸类似物 | 氮杂丝氨酸 | 谷氨酰胺 | 抑制 $\mathrm{CTP}$ 生成 |
| 叶酸类似物 | 甲氨蝶呤 | 叶酸 | $\mathrm{dUMP}$ 不能甲基化成 $\mathrm{dTMP}$ |

:::pitfall{label="5-FU 本身没有活性"}

:::

:::insight{label="抗代谢物按‘像谁’分类，刀口按合成步骤对号"}
嘌呤类似物像次黄嘌呤／$\mathrm{IMP}$，嘧啶类似物像胸腺嘧啶，叶酸类似物像叶酸，氨基酸类似物像谷氨酰胺。思考题第 $4$ 题按类型答，再各举一两个作用位点，不要只背药名。

## 二、嘧啶核苷酸分解生成 $\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸及 $\beta$-氨基异丁酸

嘧啶核苷酸首先通过核苷酸酶及核苷磷酸化酶的作用，除去磷酸及核糖，产生的嘧啶碱再进一步分解。胞嘧啶脱氨基转变成尿嘧啶。尿嘧啶还原成二氢尿嘧啶，并水解开环，最终生成 $\mathrm{NH}_3$、$\mathrm{CO}_2$ 及 $\beta$-丙氨酸。胸腺嘧啶分解成 $\beta$-氨基异丁酸（$\beta$-aminoisobutyric acid）（图11-14），其可直接随尿排出或进一步分解。摄入 $\mathrm{DNA}$ 丰富的食物的人、经放射线治疗或化学治疗后的肿瘤病人等，其尿液中 $\beta$-氨基异丁酸排出量增多。嘧啶碱的分解代谢主要在肝进行。

与嘌呤碱的分解产生尿酸不同，嘧啶碱的分解产物均易溶于水。

::figure{src="/images/biochemistry/textbook/p0256_02.png" caption="图11-14　嘧啶碱的分解代谢。胞嘧啶脱氨基成尿嘧啶，经二氢尿嘧啶开环得 β-丙氨酸，再经丙二酸单酰 CoA、乙酰 CoA 进入柠檬酸循环；胸腺嘧啶经 β-脲基异丁酸开环得 β-氨基异丁酸，再经甲基丙二酸单酰 CoA、琥珀酰 CoA 进入柠檬酸循环或糖异生。开环放出的 CO2 与 NH3 在肝可写成尿素。" alt="尿嘧啶分解为 β-丙氨酸，胸腺嘧啶分解为 β-氨基异丁酸"}

:::definition{label="嘧啶分解的终产物"}
嘧啶核苷酸经核苷酸酶及核苷磷酸化酶除去磷酸及核糖后，嘧啶碱再分解。终产物为 $\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸及 $\beta$-氨基异丁酸。均易溶于水。主要在肝进行。
:::

:::definition{label="β-丙氨酸与 β-氨基异丁酸"}
尿嘧啶（胞嘧啶先脱氨基成尿嘧啶）最终生成 $\mathrm{NH}_3$、$\mathrm{CO}_2$ 及 $\beta$-丙氨酸。胸腺嘧啶分解成 $\beta$-氨基异丁酸，可随尿排出或进一步分解。
:::

:::compare{title="胞嘧啶／尿嘧啶 vs 胸腺嘧啶的分解"}
| 起点 | 关键中间物 | 特征产物 | 图11-14 的后续 |
|------|------------|----------|----------------|
| 胞嘧啶 $\rightarrow$ 尿嘧啶 | 二氢尿嘧啶，水解开环 | $\beta$-丙氨酸 | 丙二酸单酰 $\mathrm{CoA}$ $\rightarrow$ 乙酰 $\mathrm{CoA}$ $\rightarrow$ 柠檬酸循环 |
| 胸腺嘧啶 | $\beta$-脲基异丁酸，水解开环 | $\beta$-氨基异丁酸 | 甲基丙二酸单酰 $\mathrm{CoA}$ $\rightarrow$ 琥珀酰 $\mathrm{CoA}$ $\rightarrow$ 柠檬酸循环或糖异生 |
| 开环放出的 $\mathrm{CO}_2+\mathrm{NH}_3$ | — | — | 肝可写成尿素 |
:::

:::insight{label="尿中 β-氨基异丁酸是‘胸腺嘧啶被大量拆掉’的信号"}
高 $\mathrm{DNA}$ 饮食、放疗、化疗使核酸分解增加，胸腺嘧啶多，尿中 $\beta$-氨基异丁酸增多。它不像尿酸那样难溶，一般不写成结晶病；临床意义是反映核酸分解加快。
:::

:::pitfall{label="嘧啶分解不产生尿酸"}
尿酸只属于嘌呤。嘧啶开环以后是小分子 $\beta$-氨基酸、氨和二氧化碳，易溶。把痛风和 $\beta$-氨基异丁酸绑在一起，第二道思考题会答反。
:::

|------|------|------|

| 终产物 | 尿酸 | $\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸、$\beta$-氨基异丁酸 |
| 水溶性 | 尿酸较差 | 均易溶 |
| 关键酶 | 黄嘌呤氧化酶 | 开环／还原（图11-14） |
| 主要器官 | 肝、小肠、肾 | 肝 |
| 临床 | 高尿酸、痛风；别嘌呤醇 | 尿中 $\beta$-氨基异丁酸增多（高 $\mathrm{DNA}$、放化疗） |

## 本章小结

核苷酸具有多种重要的生理功能，其中最主要的是作为合成核酸分子的基本组成单位。除此，还参与能量代谢、代谢调节等过程。体内核苷酸的来源主要由机体细胞自身合成，食物来源的嘌呤和嘧啶极少被机体利用。食物中或机体细胞中的核酸可被核酸酶降解。核酸酶是能够水解核酸的酶，根据作用底物的不同分为 $\mathrm{DNA}$ 酶及 $\mathrm{RNA}$ 酶。根据作用位点的不同分为核酸外切酶及核酸内切酶。食物中的 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 在小肠被核酸酶水解为寡核苷酸和部分单核苷酸。核苷酸被核苷酸酶进一步水解生成核苷和磷酸。核苷及碱基可通过扩散等方式被吸收。

核苷酸在体内的代谢主要包括合成代谢和分解代谢。体内嘌呤核苷酸的合成有两条途径：从头合成和补救合成途径。从头合成途径的原料是核糖-$5$-磷酸、氨基酸、一碳单位和 $\mathrm{CO}_2$ 等简单物质，在 $\mathrm{PRPP}$ 的基础上经过一系列酶促反应，逐步形成嘌呤环。首先生成 $\mathrm{IMP}$，然后再分别转变成 $\mathrm{AMP}$ 和 $\mathrm{GMP}$。从头合成过程受着精确的反馈调节。补救合成途径实际上是现成嘌呤或嘌呤核苷的重新利用，虽然合成含量极少，但对于那些不能进行从头合成的组织器官，补救合成具有重要的生理意义。

机体也可以从头合成嘧啶核苷酸，但不同的是先合成嘧啶环，再磷酸核糖化而生成核苷酸。嘧啶核苷酸的从头合成途径也受反馈调控。

体内脱氧核苷酸由各自相应的核苷二磷酸被还原生成。核苷酸还原酶催化此反应。四氢叶酸携带的一碳单位是合成胸苷酸时甲基的必要来源。

根据嘌呤核苷酸和嘧啶核苷酸的合成过程，可以设计多种抗代谢物，包括嘌呤类似物、嘧啶类似物、叶酸类似物和氨基酸类似物等。这些抗代谢物在抗肿瘤治疗中有重要作用。

嘌呤在人体内分解代谢的终产物是尿酸，黄嘌呤氧化酶是这个代谢过程的关键酶。痛风症主要是由于嘌呤代谢异常，尿酸生成过多而引起的。嘧啶分解后产生的 $\beta$-氨基酸可随尿排出或进一步代谢。

:::definition{label="本章小结里的核苷酸来源"}
体内核苷酸主要由机体细胞自身合成，食物来源的嘌呤和嘧啶极少被机体利用。因此核苷酸不是营养必需物质。
:::

:::definition{label="本章小结里的两条合成顺序"}
嘌呤：在 $\mathrm{PRPP}$ 基础上逐步形成嘌呤环，先 $\mathrm{IMP}$ 再 $\mathrm{AMP}/\mathrm{GMP}$。嘧啶：先合成嘧啶环，再磷酸核糖化。
:::

:::keypoint{label="本章小结按节收口"}
- 功能：核酸原料最主要；兼能量、调节。
- 消化：核酸酶分 $\mathrm{DNase}/\mathrm{RNase}$、外切／内切；小肠切到核苷、碱基，扩散吸收。
- 嘌呤从头：核糖-$5$-磷酸、氨基酸、一碳单位、$\mathrm{CO}_2$；$\mathrm{PRPP}\rightarrow\mathrm{IMP}\rightarrow\mathrm{AMP}/\mathrm{GMP}$；反馈精确。
- 嘌呤补救：现成嘌呤／核苷重新利用；对不能从头的组织重要。
- 嘧啶从头：先环后磷酸核糖化；亦反馈。
- 脱氧：$\mathrm{NDP}$ 水平，核糖核苷酸还原酶；胸苷酸甲基来自四氢叶酸一碳单位。
- 抗代谢物：嘌呤、嘧啶、叶酸、氨基酸类似物；抗肿瘤。
- 分解：嘌呤 $\rightarrow$ 尿酸（黄嘌呤氧化酶；痛风）；嘧啶 $\rightarrow\beta$-氨基酸等。
:::

:::insight{label="小结把痛风钉在‘尿酸生成过多’"}
章末原句：痛风症主要是由于嘌呤代谢异常，尿酸生成过多而引起。别嘌呤醇的教材机制是少生成尿酸，并顺带少写嘌呤核苷酸。排泄障碍在第二节是高尿酸的原因之一，小结把痛风的主因写在生成过多这一侧。
:::

4. 试述核苷酸抗代谢物的类型及其应用。

:::tip{label="四道思考题在正文里的户头"}
- 是否营养必需：否。人体核苷酸主要由自身合成；食物来源的嘌呤和嘧啶极少被机体利用（第一节消化；本章小结第一段）。
- 分解产物：嘌呤 $\rightarrow$ 尿酸（难溶）；嘧啶 $\rightarrow\mathrm{NH}_3$、$\mathrm{CO}_2$、$\beta$-丙氨酸、$\beta$-氨基异丁酸（易溶）。痛风相关产物是尿酸。
- 痛风治疗：本版点名别嘌呤醇。机制三笔——抑制黄嘌呤氧化酶、与 $\mathrm{PRPP}$ 生成别嘌呤核苷酸而消耗 $\mathrm{PRPP}$、别嘌呤核苷酸反馈抑制从头合成酶。不要离开本章另开未出现的药名。
- 抗代谢物类型：嘌呤类似物（$6$-$\mathrm{MP}$ 等，抑从头、补救和 $\mathrm{IMP}$ 分支）、嘧啶类似物（$5$-$\mathrm{FU}$，抑 $\mathrm{dTMP}$、掺入 $\mathrm{RNA}$）、核苷类似物（阿糖胞苷，抑 $\mathrm{CDP}\rightarrow\mathrm{dCDP}$）、叶酸类似物（$\mathrm{MTX}$，抑二氢叶酸还原酶，嘌呤一碳单位和 $\mathrm{dTMP}$ 都停）、氨基酸类似物（氮杂丝氨酸等，干扰谷氨酰胺，抑嘌呤合成和 $\mathrm{CTP}$ 生成）。应用：抗肿瘤；缺乏肿瘤选择性，毒副作用较大。
:::
