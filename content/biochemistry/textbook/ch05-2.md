# 第二节　无机元素

本节把无机元素写成化合物或络合物，广泛分布于各组织、含量较恒定。先立三项生理作用：酶的辅因子、参与物质运输、参与激素和维生素形成。常量元素在本章展开钙和磷；微量元素按教材职分写全铁、锌、铜、锰、硒、碘、钴、氟、铬。钠、钾、氯、镁仍交给病理生理学；钼列入微量名单但未设专节。章末收本章小结。

无机元素绝大多数为金属元素，在体内一般结合成化合物或络合物，广泛分布于各组织中，含量较恒定。无机元素主要来自食物，动物性食物含量较高，种类也较植物性食物多。无机元素通过与酶、其他蛋白质、激素和维生素等结合而在体内发挥多种多样作用。其主要生理作用为：①酶的辅因子。人体内一半以上酶的活性部位含有无机元素。许多酶需要金属离子才有活性或高活性（见第二章）。②参与体内物质运输。如血红蛋白含 $\mathrm{Fe}^{2+}$ 参与 $\mathrm{O}_2$ 的运输，碳酸酐酶含锌参与 $\mathrm{CO}_2$ 的运输。③参与激素和维生素的形成。如碘是甲状腺素合成的必需成分，钴是维生素 $\mathrm{B}_{12}$ 的组成成分等。

:::definition{label="无机元素"}
无机元素绝大多数为金属元素，在体内一般结合成化合物或络合物，广泛分布于各组织中，含量较恒定。主要来自食物，动物性食物含量较高、种类也较植物性食物多。通过与酶、其他蛋白质、激素和维生素等结合而发挥作用。
:::

:::keypoint{label="无机元素的三项生理作用"}
- 酶的辅因子：一半以上酶的活性部位含无机元素；许多酶需要金属离子才有活性或高活性。
- 参与体内物质运输：血红蛋白含 $\mathrm{Fe}^{2+}$ 运 $\mathrm{O}_2$，碳酸酐酶含锌运 $\mathrm{CO}_2$。
- 参与激素和维生素的形成：碘是甲状腺素合成的必需成分，钴是维生素 $\mathrm{B}_{12}$ 的组成成分。
:::

:::concept{term="先问是酶辅因子、运输还是构成激素维生素，再问哪一种元素"}
看见无机元素，不要先背缺乏症。三项作用是户头：多数走酶的活性部位，一部分写进运氧、运二氧化碳，碘和钴写进甲状腺素和维生素 $\mathrm{B}_{12}$。钙、磷还要另开骨盐和第二信使两本账。
:::

## 一、钙既是骨的主要成分又具有重要的调节作用

### （一）钙在体内分布广泛

成人血浆（或血清）中的钙含量为 $2.25\sim 2.75\,\mathrm{mmol}/\mathrm{L}$，不到人体总量的 $0.1\%$，约一半是游离 $\mathrm{Ca}^{2+}$；另一半为蛋白结合钙，主要与清蛋白结合，少量与球蛋白结合。游离钙与蛋白结合钙在血浆中呈动态平衡状态。血浆 $\mathrm{pH}$ 可影响它们的平衡，当血浆偏酸时，蛋白结合钙解离，血浆游离钙增多；当 $\mathrm{pH}$ 升高时，蛋白结合钙增多，而游离钙减少。平均每增减 $1$ 个 $\mathrm{pH}$ 单位，每 $100\,\mathrm{ml}$ 血浆游离钙浓度相应改变 $0.42\,\mathrm{mmol}$（$1.68\,\mathrm{mg}$）。分布于体液和其他组织中的钙不足总钙量的 $1\%$。细胞外液游离钙的浓度为 $1.12\sim 1.23\,\mathrm{mmol}/\mathrm{L}$。人体内 $99\%$ 以上的钙分布于骨中，以羟基磷灰石［hydroxyapatite，$\mathrm{Ca}_{10}(\mathrm{PO}_4)_{6}(\mathrm{OH})_{2}$］的形式构成骨和牙的主要成分，起着支持和保护作用。

:::definition{label="血浆钙"}
成人血浆（或血清）钙为 $2.25\sim 2.75\,\mathrm{mmol}/\mathrm{L}$，不到人体总量的 $0.1\%$。约一半是游离 $\mathrm{Ca}^{2+}$，另一半为蛋白结合钙（主要与清蛋白结合，少量与球蛋白结合）。两者呈动态平衡。
:::

:::definition{label="羟基磷灰石"}
人体内 $99\%$ 以上的钙分布于骨中，以羟基磷灰石（hydroxyapatite，$\mathrm{Ca}_{10}(\mathrm{PO}_4)_{6}(\mathrm{OH})_{2}$）的形式构成骨和牙的主要成分，起支持和保护作用。体液和其他组织中的钙不足总钙量的 $1\%$。
:::

:::cause-effect{title="血浆 pH 怎样改游离钙"}
- **因** 游离钙与蛋白结合钙动态平衡；血浆偏酸时蛋白结合钙解离， $\mathrm{pH}$ 升高时蛋白结合钙增多
- **果** 偏酸：游离钙增多；$\mathrm{pH}$ 升高：游离钙减少。平均每增减 $1$ 个 $\mathrm{pH}$ 单位，每 $100\,\mathrm{ml}$ 血浆游离钙相应改变 $0.42\,\mathrm{mmol}$（$1.68\,\mathrm{mg}$）
:::

:::compare{title="钙在体内三处怎么记账"}
| 部位 | 教材数量 | 形式 |
|------|----------|------|
| 骨和牙 | $99\%$ 以上 | 羟基磷灰石 $\mathrm{Ca}_{10}(\mathrm{PO}_4)_{6}(\mathrm{OH})_{2}$ |
| 血浆（或血清） | 不到总量 $0.1\%$；$2.25\sim 2.75\,\mathrm{mmol}/\mathrm{L}$ | 约一半游离 $\mathrm{Ca}^{2+}$，一半蛋白结合钙 |
| 体液和其他组织 | 不足总钙量 $1\%$ | 细胞外液游离钙 $1.12\sim 1.23\,\mathrm{mmol}/\mathrm{L}$ |
:::

### （二）钙离子具有重要的调节功能

细胞内钙浓度极低，且 $90\%$ 以上储存于内质网和线粒体内，胞质钙浓度仅 $0.01\sim 0.1\,\mathrm{mol}/\mathrm{L}$。胞钙作为第二信使在信号转导中发挥许多重要的生理作用。胞质钙对许多参与细胞代谢的酶具有重要的调节作用，如鸟苷酸环化酶、磷酸二酯酶等。

钙离子可与细胞膜的蛋白和各种阴离子基团结合，具有调节细胞受体结合、离子通道通透性及神经递质释放等作用，从而维持神经肌肉的正常生理功能，包括神经肌肉的兴奋性、神经冲动的传导和心脏的波动等。钙可参与血液凝固、激素分泌、维持体液酸碱平衡以及调节细胞正常生理功能等作用，如对血液中的酶复活作用、调整细胞或血管的渗透作用、促进细胞再生、旺盛其活力、提高人体免疫力等。

:::definition{label="胞钙作为第二信使"}
细胞内钙浓度极低，$90\%$ 以上储于内质网和线粒体，胞质钙浓度仅 $0.01\sim 0.1\,\mathrm{mol}/\mathrm{L}$（教材原文）。胞钙作为第二信使参与信号转导；胞质钙调节鸟苷酸环化酶、磷酸二酯酶等代谢酶。
:::

:::keypoint{label="Ca2+ 的调节清单"}
- 与细胞膜蛋白和各种阴离子基团结合：调节受体结合、离子通道通透性、神经递质释放。
- 维持神经肌肉兴奋性、神经冲动传导和心脏波动。
- 参与血液凝固、激素分泌、体液酸碱平衡。
- 对血液中酶的复活、调整细胞或血管渗透、促进细胞再生、提高免疫力等。
:::

### （三）钙代谢紊乱可引起多种疾病

维生素 $\mathrm{D}$ 缺乏可引起钙吸收障碍，导致儿童佝偻病（rickets）和成人骨软化症（osteomalacia）。骨基质丧失和进行性骨骼脱盐可导致中、老年人骨质疏松（osteoporosis）。甲状旁腺功能亢进与维生素 $\mathrm{D}$ 中毒可引起高钙血症（hypercalcemia）、尿路结石等。甲状旁腺功能减退可引起低钙血症（hypocalcemia）。

:::compare{title="钙代谢紊乱与疾病"}
| 原因 | 结果 | 英文 |
|------|------|------|
| 维生素 $\mathrm{D}$ 缺乏 → 钙吸收障碍 | 儿童佝偻病；成人骨软化症 | rickets；osteomalacia |
| 骨基质丧失和进行性骨骼脱盐 | 中、老年人骨质疏松 | osteoporosis |
| 甲状旁腺功能亢进、维生素 $\mathrm{D}$ 中毒 | 高钙血症、尿路结石 | hypercalcemia |
| 甲状旁腺功能减退 | 低钙血症 | hypocalcemia |
:::

:::pitfall{label="佝偻病、骨软化症、骨质疏松不要并成“缺钙”一个词"}
佝偻病和骨软化症的教材链条是维生素 $\mathrm{D}$ 缺乏 → 钙吸收障碍，分儿童和成人。骨质疏松是骨基质丧失和进行性脱盐，落到中、老年人。高钙血症走甲旁亢和维生素 $\mathrm{D}$ 中毒，不是“补钙补多了”这一句就能代替。
:::

## 二、磷是体内许多重要生物分子的组成成分

### （一）磷主要分布于骨

磷主要分布于骨（约占 $85.7\%$），其次为各组织细胞（约 $14\%$），仅少量（约 $0.03\%$）分布于体液。成人血浆中无机磷的含量为 $1.1\sim 1.3\,\mathrm{mmol}/\mathrm{L}$。正常人血液中钙和磷的浓度相当恒定，每 $100\,\mathrm{ml}$ 血液中钙与磷含量之积为一常数，即 $[\mathrm{Ca}]\times[\mathrm{P}]=35\sim 40$。因此，血钙降低时，血磷会略有增加。

:::definition{label="磷的分布"}
磷主要分布于骨（约占 $85.7\%$），其次为各组织细胞（约 $14\%$），仅少量（约 $0.03\%$）分布于体液。成人血浆无机磷 $1.1\sim 1.3\,\mathrm{mmol}/\mathrm{L}$。
:::

:::definition{label="血钙与血磷乘积"}
正常人每 $100\,\mathrm{ml}$ 血液中 $[\mathrm{Ca}]\times[\mathrm{P}]=35\sim 40$，为一常数。血钙降低时，血磷会略有增加。
:::

### （二）磷主要以磷酸根的形式构成高分子化合物

磷除了构成骨盐成分、参与成骨作用外，主要以磷酸根的形式构成许多重要的高分子化合物，如核酸、核苷酸、磷脂、辅酶等，发挥各自重要的生理功能；还可形成 $\mathrm{ATP}$ 提供生理活动所需的能量。许多生化反应和代谢的调节均需要磷酸根的参与。此外，磷还是体液中磷酸氢盐缓冲体系的组成成分，参与调节酸碱平衡。

:::definition{label="磷酸根的功能"}
磷除构成骨盐、参与成骨外，主要以磷酸根形式构成核酸、核苷酸、磷脂、辅酶等；可形成 $\mathrm{ATP}$ 供能；参与许多生化反应和代谢调节；也是磷酸氢盐缓冲体系的组成成分，调节酸碱平衡。
:::

:::compare{title="钙和磷：骨盐之外还干什么"}
| 项目 | 钙 | 磷 |
|------|----|----|
| 骨中比例 | $99\%$ 以上，羟基磷灰石 | 约 $85.7\%$ 在骨 |
| 血浆浓度 | $2.25\sim 2.75\,\mathrm{mmol}/\mathrm{L}$ | 无机磷 $1.1\sim 1.3\,\mathrm{mmol}/\mathrm{L}$ |
| 关系 | $[\mathrm{Ca}]\times[\mathrm{P}]=35\sim 40$（每 $100\,\mathrm{ml}$ 血液） | 血钙降则血磷略增 |
| 骨外职分 | 第二信使、神经肌肉、凝血、激素分泌 | 核酸、核苷酸、磷脂、辅酶、$\mathrm{ATP}$、磷酸氢盐缓冲 |
:::

### （三）磷代谢紊乱可引起多种疾病

高磷血症常见于慢性肾病患者，与冠状动脉、心瓣膜钙化等严重心血管并发症密切相关；是引起继发性甲状旁腺功能亢进、维生素 $\mathrm{D}$ 代谢障碍、肾性骨病等的重要因素。维生素 $\mathrm{D}$ 缺乏也可减少肠腔磷酸盐的吸收，是引起低磷血症的原因之一。

:::cause-effect{title="高磷血症为什么牵出一串骨和心血管问题"}
- **因** 高磷血症常见于慢性肾病
- **果** 与冠状动脉、心瓣膜钙化密切相关；并引起继发性甲状旁腺功能亢进、维生素 $\mathrm{D}$ 代谢障碍、肾性骨病
:::

:::note{label="低磷血症也可以走维生素 D 缺乏"}
维生素 $\mathrm{D}$ 缺乏减少肠腔磷酸盐吸收，是低磷血症原因之一。钙吸收障碍和磷吸收障碍可以是同一条维生素 $\mathrm{D}$ 链上的两笔。
:::

## 三、铁是体内含量最多的微量元素

### （一）运铁蛋白和铁蛋白分别运输和储存铁

铁（iron）是体内含量最多的一种微量元素，成年男性平均含铁量约为 $50\,\mathrm{mg}/\mathrm{kg}$ 体重，女性约为体重 $30\,\mathrm{mg}/\mathrm{kg}$ 体重。

铁的吸收部位主要在十二指肠及空肠上段。无机铁只有 $\mathrm{Fe}^{2+}$ 可以通过小肠黏膜细胞。酸性 $\mathrm{pH}$、维生素 $\mathrm{C}$ 和谷胱甘肽可将 $\mathrm{Fe}^{3+}$ 还原为 $\mathrm{Fe}^{2+}$，有利于铁的吸收。鞣酸、草酸、植酸、大量无机磷酸、含磷酸的抗酸药等可与铁形成不溶性或不能吸收的铁复合物，从而影响铁的吸收。络合物中铁的吸收率大于无机铁，氨基酸、柠檬酸、苹果酸等能与铁离子形成络合物，有利于铁的吸收。

吸收的 $\mathrm{Fe}^{2+}$ 在小肠黏膜上皮细胞中氧化为 $\mathrm{Fe}^{3+}$，并与铁蛋白（ferritin）结合。铁（$\mathrm{Fe}^{3+}$）在血液中与运铁蛋白（transferrin）结合而运输。正常人血清运铁蛋白浓度为 $200\sim 300\,\mathrm{mg}/\mathrm{dl}$。

体内多余的铁通过结合铁蛋白而储存，主要储存于肝、脾、骨髓、小肠黏膜、胰等器官。铁蛋白是由 $24$ 个亚基组成的中空分子，其内可结合多达 $4500$ 个铁离子。

小肠黏膜上皮细胞的生命周期为 $2\sim 6$ 天，细胞内铁蛋白中的铁随着细胞的脱落而排泄于肠腔。这几乎是体内铁的唯一排泄途径。

:::definition{label="铁"}
铁（iron）是体内含量最多的一种微量元素。成年男性平均含铁量约为 $50\,\mathrm{mg}/\mathrm{kg}$ 体重，女性约为体重 $30\,\mathrm{mg}/\mathrm{kg}$ 体重。
:::

:::definition{label="铁蛋白"}
铁蛋白（ferritin）储存铁。由 $24$ 个亚基组成的中空分子，其内可结合多达 $4500$ 个铁离子。主要储存于肝、脾、骨髓、小肠黏膜、胰等。吸收的 $\mathrm{Fe}^{2+}$ 在小肠黏膜上皮细胞中氧化为 $\mathrm{Fe}^{3+}$ 后与铁蛋白结合。
:::

:::definition{label="运铁蛋白"}
运铁蛋白（transferrin）在血液中运输 $\mathrm{Fe}^{3+}$。正常人血清运铁蛋白浓度 $200\sim 300\,\mathrm{mg}/\mathrm{dl}$。
:::

:::compare{title="铁的吸收、运输、储存、排泄"}
| 环节 | 教材要点 |
|------|----------|
| 吸收部位 | 十二指肠及空肠上段 |
| 可吸收形式 | 无机铁只有 $\mathrm{Fe}^{2+}$ 可通过小肠黏膜细胞 |
| 促进吸收 | 酸性 $\mathrm{pH}$、维生素 $\mathrm{C}$、谷胱甘肽把 $\mathrm{Fe}^{3+}$ 还原为 $\mathrm{Fe}^{2+}$；氨基酸、柠檬酸、苹果酸等成络合物，络合物吸收率大于无机铁 |
| 抑制吸收 | 鞣酸、草酸、植酸、大量无机磷酸、含磷酸的抗酸药 → 不溶性或不能吸收的铁复合物 |
| 黏膜内 | $\mathrm{Fe}^{2+}$ 氧化为 $\mathrm{Fe}^{3+}$，结合铁蛋白 |
| 血液运输 | $\mathrm{Fe}^{3+}$ 结合运铁蛋白 |
| 储存 | 多余的铁结合铁蛋白；$24$ 亚基中空，最多约 $4500$ 个铁离子 |
| 排泄 | 小肠黏膜上皮 $2\sim 6$ 天脱落，铁蛋白中的铁随细胞入肠腔；几乎是体内铁的唯一排泄途径 |
:::

:::pitfall{label="肠道只让 Fe2+ 进黏膜，血里运的却是 Fe3+"}
吸收要还原成 $\mathrm{Fe}^{2+}$，进细胞后再氧化成 $\mathrm{Fe}^{3+}$ 交给铁蛋白和运铁蛋白。把“三价铁不能吸收”听成“体内不能有三价铁”，储存和运输那一笔会写反。
:::

### （二）体内铁主要存在于含铁卟啉和非铁卟啉的蛋白质中

铁是血红蛋白、肌红蛋白、细胞色素系统、铁硫蛋白、过氧化物酶及过氧化氢酶等的重要组成部分，在气体运输、生物氧化和酶促反应中均发挥重要作用。体内铁约 $75\%$ 存在于铁卟啉化合物中，$25\%$ 存在于非铁卟啉类含铁化合物（如含铁的黄素蛋白、铁硫蛋白、运铁蛋白等）中。成年男性及绝经后的妇女每日约需铁 $10\,\mathrm{mg}$，生育期妇女每日约需铁 $15\,\mathrm{mg}$，儿童在生长发育期、妇女在妊娠哺乳期对铁的需要量增加。

:::compare{title="铁卟啉与非铁卟啉"}
| 项目 | 铁卟啉化合物（约 $75\%$） | 非铁卟啉类含铁化合物（约 $25\%$） |
|------|---------------------------|-----------------------------------|
| 教材例子 | 血红蛋白、肌红蛋白、细胞色素系统、过氧化物酶、过氧化氢酶等 | 含铁的黄素蛋白、铁硫蛋白、运铁蛋白等 |
| 功能落点 | 气体运输、生物氧化、酶促反应 | 储存/运输及生物氧化相关蛋白 |
:::

:::keypoint{label="铁的每日需要量"}
- 成年男性及绝经后妇女：约 $10\,\mathrm{mg}$。
- 生育期妇女：约 $15\,\mathrm{mg}$。
- 儿童生长发育期、妇女妊娠哺乳期：需要量增加。
:::

### （三）铁的缺乏与中毒均可引起严重的疾病

铁的缺乏可引起小细胞低色素性贫血。引起缺铁性贫血的原因不限于铁摄入的不足，急性大量出血、慢性小量出血（如消化道溃疡、妇女月经失调出血等）以及儿童生长期和妇女妊娠、哺乳期得不到铁的额外补充等均可引起缺铁性贫血。

$\mathrm{Fe}^{2+}$ 非常活泼，可与氧反应产生羟自由基和过氧化自由基。$\mathrm{Fe}^{2+}$ 还像重金属离子那样，与体内蛋白质结合，破坏其结构。在 $\mathrm{Fe}^{2+}$ 或酯氧合酶的作用下，细胞膜上高表达的不饱和脂肪酸，发生脂质过氧化可诱导铁死亡。所以体内铁在储存与运输过程中均为 $\mathrm{Fe}^{3+}$，并与特异的蛋白相结合。铁摄入过剩，部分铁蛋白变性生成血铁黄素（hemosiderin），体内铁沉积过多时可出现血色素沉着病（hemochromatosis），引起器官损伤，可出现肝硬化、肝癌、糖尿病、心肌病、皮肤色素沉着、内分泌紊乱、关节痛等。

:::definition{label="缺铁性贫血"}
铁缺乏可引起小细胞低色素性贫血。原因不限于摄入不足：急性大量出血、慢性小量出血（消化道溃疡、妇女月经失调出血等），以及儿童生长期和妇女妊娠、哺乳期得不到额外补充，均可引起。
:::

:::definition{label="血铁黄素与血色素沉着病"}
铁摄入过剩，部分铁蛋白变性生成血铁黄素（hemosiderin）。体内铁沉积过多可出现血色素沉着病（hemochromatosis），引起器官损伤：肝硬化、肝癌、糖尿病、心肌病、皮肤色素沉着、内分泌紊乱、关节痛等。
:::

:::definition{label="铁死亡（本节教材表述）"}
在 $\mathrm{Fe}^{2+}$ 或酯氧合酶作用下，细胞膜上高表达的不饱和脂肪酸发生脂质过氧化，可诱导铁死亡。$\mathrm{Fe}^{2+}$ 还可与氧反应产生羟自由基和过氧化自由基，并可像重金属离子那样结合蛋白质、破坏其结构。故储存与运输中的铁均为 $\mathrm{Fe}^{3+}$，并与特异蛋白结合。
:::

:::insight{label="缺铁走小细胞低色素，铜缺乏也可以是小细胞低色素"}
本节铁缺乏写小细胞低色素性贫血；铜缺乏的特征性表现同样包括小细胞低色素性贫血。考试问“缺乏哪些无机元素可能导致贫血”，至少要能点到铁、铜，再加上钴（维生素 $\mathrm{B}_{12}$ → 巨幼细胞贫血）。不要把贫血都写成缺铁。
:::

## 四、锌是含锌金属酶和锌指蛋白的组成成分

### （一）清蛋白和金属硫蛋白分别参与锌的运输和储存

锌（zinc）在人体内的含量仅次于铁，为 $1.5\sim 2.5\,\mathrm{g}$。成人每日需锌 $15\sim 20\,\mathrm{mg}$。肉类、豆类、坚果、麦胚等含锌丰富。锌主要在小肠吸收，但不完全。某些地区的谷物中含有较多的能与锌形成不溶性复合物的 $6$-磷酸肌醇，从而影响锌的吸收。血中锌与清蛋白或运铁蛋白结合而运输。血锌浓度为 $0.1\sim 0.15\,\mathrm{mmol}/\mathrm{L}$。体内储存的锌主要与金属硫蛋白（metallothionein）结合。锌主要经粪排泄，其次为尿、汗、乳汁等。

:::definition{label="锌"}
锌（zinc）在人体内含量仅次于铁，为 $1.5\sim 2.5\,\mathrm{g}$。成人每日需锌 $15\sim 20\,\mathrm{mg}$。肉类、豆类、坚果、麦胚等含锌丰富。
:::

:::definition{label="金属硫蛋白"}
体内储存的锌主要与金属硫蛋白（metallothionein）结合。血中锌与清蛋白或运铁蛋白结合而运输；血锌 $0.1\sim 0.15\,\mathrm{mmol}/\mathrm{L}$。
:::

:::compare{title="锌的吸收、运输、储存、排泄"}
| 环节 | 教材要点 |
|------|----------|
| 吸收 | 主要在小肠，不完全；$6$-磷酸肌醇与锌形成不溶性复合物，影响吸收 |
| 运输 | 清蛋白或运铁蛋白；血锌 $0.1\sim 0.15\,\mathrm{mmol}/\mathrm{L}$ |
| 储存 | 金属硫蛋白 |
| 排泄 | 主要经粪，其次尿、汗、乳汁 |
:::

### （二）锌参与体内的多种生理作用

锌是含锌金属酶的组成成分，与 $80$ 多种酶的活性有关，如碳酸酐酶、铜-锌-超氧化物歧化酶、醇脱氢酶、羧基肽酶 $\mathrm{A}$ 和 $\mathrm{B}$、$\mathrm{DNA}$ 和 $\mathrm{RNA}$ 聚合酶等。许多蛋白质，如反式作用因子、类固醇激素和甲状腺素受体的 $\mathrm{DNA}$ 结合区，都有锌参与形成的锌指结构。锌指结构在转录调控中起重要作用。锌是重要的免疫调节剂、生长辅因子，在抗氧化、抗细胞凋亡和抗炎症中均起重要作用。锌也是合成胰岛素所必需的元素。

:::definition{label="锌指结构"}
反式作用因子、类固醇激素和甲状腺素受体的 $\mathrm{DNA}$ 结合区，都有锌参与形成的锌指结构。锌指结构在转录调控中起重要作用。
:::

:::keypoint{label="含锌金属酶（教材点名）"}
- 碳酸酐酶（含锌参与 $\mathrm{CO}_2$ 运输，章首已点）。
- 铜-锌-超氧化物歧化酶。
- 醇脱氢酶。
- 羧基肽酶 $\mathrm{A}$ 和 $\mathrm{B}$。
- $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 聚合酶。
- 与 $80$ 多种酶的活性有关。
:::

:::tip{label="锌既进酶，也进锌指，还要合成胰岛素"}
三本账不要并成“缺锌就是长不高”。转录调控走锌指；免疫、生长、抗氧化、抗凋亡、抗炎是另一笔；胰岛素合成又是一笔。
:::

### （三）锌缺乏可引起多种疾病

锌的补充依赖体外摄入，如果各种原因引起锌的摄入不足或吸收困难，均可引起锌的缺乏。锌缺乏可引起消化功能紊乱、生长发育滞后、智力发育不良、皮肤炎、伤口愈合缓慢、脱发、神经精神障碍等；儿童可出现发育不良和睾丸萎缩。

:::definition{label="锌缺乏"}
锌的补充依赖体外摄入。摄入不足或吸收困难均可缺乏。表现：消化功能紊乱、生长发育滞后、智力发育不良、皮肤炎、伤口愈合缓慢、脱发、神经精神障碍等；儿童可发育不良和睾丸萎缩。
:::

## 五、铜主要与铜蓝蛋白结合和构成酶的辅因子

### （一）铜在血液中主要与铜蓝蛋白结合而运输

成人体内铜（copper）的含量为 $80\sim 110\,\mathrm{mg}$，肌肉中约占 $50\%$，$10\%$ 存在于肝。成人每日需铜 $1\sim 3\,\mathrm{mg}$，孕妇和成长期的青少年可略有增加。铜主要在十二指肠吸收。血液中约 $60\%$ 的铜与铜蓝蛋白（ceruloplasmin）紧密结合，其余的与清蛋白疏松结合或与组氨酸形成复合物。铜主要随胆汁排泄。

:::definition{label="铜蓝蛋白"}
血液中约 $60\%$ 的铜与铜蓝蛋白（ceruloplasmin）紧密结合；其余与清蛋白疏松结合或与组氨酸形成复合物。成人体内铜 $80\sim 110\,\mathrm{mg}$，肌肉约占 $50\%$，$10\%$ 在肝。成人每日需铜 $1\sim 3\,\mathrm{mg}$。
:::

### （二）铜是多种含铜酶的辅基

铜是体内多种酶的辅基，含铜的酶多以氧分子或氧的衍生物为底物。如细胞色素氧化酶、多巴胺 $\beta$-羟化酶、单胺氧化酶、酪氨酸酶、胞质超氧化物歧化酶等。铜蓝蛋白可催化 $\mathrm{Fe}^{2+}$ 氧化成 $\mathrm{Fe}^{3+}$，后者结合运铁蛋白，有利于铁的运输。

:::definition{label="含铜酶"}
铜是多种酶的辅基，含铜酶多以氧分子或氧的衍生物为底物。教材点名：细胞色素氧化酶、多巴胺 $\beta$-羟化酶、单胺氧化酶、酪氨酸酶、胞质超氧化物歧化酶等。
:::

:::cause-effect{title="铜蓝蛋白如何帮铁运输"}
- **因** 铜蓝蛋白催化 $\mathrm{Fe}^{2+}$ 氧化成 $\mathrm{Fe}^{3+}$
- **果** $\mathrm{Fe}^{3+}$ 才能结合运铁蛋白，有利于铁的运输；铜缺乏可以表现为小细胞低色素性贫血，户头有一部分在这里
:::

### （三）铜缺乏可导致小细胞低色素性贫血等疾病

铜缺乏的特征性表现为小细胞低色素性贫血、白细胞减少、出血性血管改变、骨脱盐、高胆固醇血症和神经疾患等。铜摄入过多也会引起中毒现象，如蓝绿粪便、唾液及行动障碍等。

:::compare{title="铜缺乏与铜中毒"}
| | 表现 |
|--|------|
| 缺乏（特征性） | 小细胞低色素性贫血、白细胞减少、出血性血管改变、骨脱盐、高胆固醇血症、神经疾患等 |
| 摄入过多 | 蓝绿粪便、唾液及行动障碍等 |
:::

## 六、锰主要为多种酶的组成成分或活性剂

### （一）大部分锰与血浆中 γ-球蛋白和清蛋白结合而运输

正常人体内含锰（manganese）$12\sim 20\,\mathrm{mg}$。成人每日需 $2\sim 5\,\mathrm{mg}$。锰主要从小肠吸收，入血后大部分与血浆中 $\gamma$-球蛋白和清蛋白结合而运输。少量与运铁蛋白结合。锰在体内主要储存于骨、肝、胰和肾。锰主要从胆汁排泄，少量随胰液排出，尿中排泄很少。

:::definition{label="锰的运输与储存"}
正常人体内含锰 $12\sim 20\,\mathrm{mg}$，成人每日需 $2\sim 5\,\mathrm{mg}$。小肠吸收后大部分与血浆 $\gamma$-球蛋白和清蛋白结合运输，少量与运铁蛋白结合。储存于骨、肝、胰和肾。主要从胆汁排泄，少量随胰液，尿中很少。
:::

### （二）体内锰对多种酶具有激活作用

锰金属酶有精氨酸酶、谷氨酰胺合成酶、磷酸烯醇式丙酮酸脱羧酶、$\mathrm{Mn}$-超氧化物歧化酶、$\mathrm{RNA}$ 聚合酶等。体内锰对多种酶的激活作用可被镁所代替。体内正常免疫功能、血糖与细胞能量调节、生殖、消化、骨骼生长、抗自由基等均需要锰。缺锰时生长发育会受到影响。

:::definition{label="锰金属酶"}
锰金属酶包括精氨酸酶、谷氨酰胺合成酶、磷酸烯醇式丙酮酸脱羧酶、$\mathrm{Mn}$-超氧化物歧化酶、$\mathrm{RNA}$ 聚合酶等。锰对多种酶的激活作用可被镁代替。
:::

:::pitfall{label="锰的激活可被镁代替，不是锰金属酶都可以不要锰"}
教材写的是“体内锰对多种酶的激活作用可被镁所代替”。不要把精氨酸酶、$\mathrm{Mn}$-SOD 听成“有镁就行”。缺锰仍影响生长发育。
:::

### （三）过量摄入锰可引起中毒

过量摄入锰可引起中毒。锰可抑制呼吸链中复合物Ⅰ和 $\mathrm{ATP}$ 酶的活性，造成氧自由基的过量产生。锰干扰多巴胺的代谢，导致精神病和帕金森病等神经功能障碍（锰狂症）。

:::definition{label="锰狂症"}
过量锰抑制呼吸链复合物Ⅰ和 $\mathrm{ATP}$ 酶，氧自由基过量产生；干扰多巴胺代谢，导致精神病和帕金森病等神经功能障碍，称为锰狂症。
:::

## 七、硒主要作为谷胱甘肽过氧化物酶活性中心的组成成分

### （一）大部分硒与 α 和 β 球蛋白结合而运输

人体含硒（selenium）为 $14\sim 21\,\mathrm{mg}$。成人日需要量在 $30\sim 50\,\mu\mathrm{g}$。硒在十二指肠吸收。入血后与 $\alpha$ 和 $\beta$ 球蛋白结合，小部分与 $\mathrm{VLDL}$ 结合而运输，主要随尿及汗液排泄。

:::definition{label="硒的吸收与运输"}
人体含硒 $14\sim 21\,\mathrm{mg}$，成人日需要量 $30\sim 50\,\mu\mathrm{g}$。十二指肠吸收；入血后与 $\alpha$ 和 $\beta$ 球蛋白结合，小部分与 $\mathrm{VLDL}$ 结合。主要随尿及汗液排泄。
:::

### （二）硒以硒半胱氨酸形式参与多种重要硒蛋白的组成

硒在体内以硒半胱氨酸（selenocysteine）的形式存在于近 $30$ 种蛋白质中。这些含硒半胱氨酸的蛋白质称为硒蛋白（selenoprotein）。谷胱甘肽过氧化物酶、硒蛋白 $\mathrm{P}$、硫氧还蛋白还原酶、碘甲腺原氨酸脱碘酶均属硒蛋白。谷胱甘肽过氧化物酶是重要的含硒抗氧化蛋白，通过氧化谷胱甘肽来降低细胞内 $\mathrm{H}_2\mathrm{O}_2$ 的含量，防止细胞遭受破坏。碘甲腺原氨酸脱碘酶可激活或去激活甲状腺激素，这是硒通过调节甲状腺激素水平来维持机体生长、发育与代谢的重要途径。此外，硒还参与辅酶 $\mathrm{Q}$ 和辅酶 $\mathrm{A}$ 的合成。

:::definition{label="硒蛋白"}
含硒半胱氨酸（selenocysteine）的蛋白质称为硒蛋白（selenoprotein）。硒以硒半胱氨酸形式存在于近 $30$ 种蛋白质中。教材点名：谷胱甘肽过氧化物酶、硒蛋白 $\mathrm{P}$、硫氧还蛋白还原酶、碘甲腺原氨酸脱碘酶。
:::

:::cause-effect{title="硒怎样既抗氧化又管甲状腺激素"}
- **因** 谷胱甘肽过氧化物酶氧化谷胱甘肽，降低细胞内 $\mathrm{H}_2\mathrm{O}_2$；碘甲腺原氨酸脱碘酶激活或去激活甲状腺激素
- **果** 防止细胞被过氧化破坏；通过甲状腺激素水平维持生长、发育与代谢。硒还参与辅酶 $\mathrm{Q}$ 和辅酶 $\mathrm{A}$ 的合成
:::

:::insight{label="硒半胱氨酸在第一章就出现过，这里才落到酶的活性中心"}
第一章把硒半胱氨酸写成少数天然蛋白质中可以出现、不是表1-1 的 $20$ 种。本节把它写成谷胱甘肽过氧化物酶等硒蛋白的组成。两处是同一残基，不要听成两种东西。
:::

### （三）硒缺乏可引发多种疾病

缺硒可引发很多疾病，如糖尿病、心血管疾病、神经变性疾病、某些癌症等。世界上不同地区的土壤中含硒量不同，影响食用植物中硒的含量，从而影响人类硒的摄取量。克山病便是由于地域性生长的庄稼中含硒量低引起的地方性心肌病。

由于硒的抗氧化作用，服用硒（如 $200\,\mu\mathrm{g}/\mathrm{d}$）或含硒制剂可以明显降低某些癌症（如前列腺癌、肺癌、大肠癌）的危险性。硒过多也会引起中毒症状。

:::definition{label="克山病"}
克山病是由于地域性生长的庄稼中含硒量低引起的地方性心肌病。土壤含硒量不同 → 植物含硒量不同 → 人类摄取量不同。
:::

:::note{label="硒的防治剂量与中毒"}
教材写服用硒（如 $200\,\mu\mathrm{g}/\mathrm{d}$）或含硒制剂可明显降低前列腺癌、肺癌、大肠癌等的危险性。硒过多也会引起中毒。成人日需要量是 $30\sim 50\,\mu\mathrm{g}$，不要把防治剂量听成生理需要量。
:::

## 八、碘是甲状腺素合成的必需成分

### （一）碘在甲状腺中富集

成人体内含碘（iodine）$30\sim 50\,\mathrm{mg}$，其中约 $30\%$ 集中在甲状腺内，用于合成甲状腺激素。$60\%\sim 80\%$ 以非激素的形式分散于甲状腺外。成人每日需碘 $100\sim 300\,\mathrm{mg}$。碘的吸收部位主要在小肠。碘主要随尿排出，尿碘约占总排泄量的 $85\%$，其他由汗腺排出。

:::definition{label="碘的分布"}
成人体内含碘 $30\sim 50\,\mathrm{mg}$。约 $30\%$ 集中在甲状腺内，用于合成甲状腺激素；$60\%\sim 80\%$ 以非激素形式分散于甲状腺外。成人每日需碘 $100\sim 300\,\mathrm{mg}$（教材原文）。吸收主要在小肠；尿碘约占总排泄量 $85\%$，其余由汗腺排出。
:::

### （二）碘参与甲状腺激素的组成同时具有抗氧化作用

碘在人体内的一个主要作用是参与甲状腺激素的合成。碘的另一重要功能是抗氧化作用。在含碘细胞中有 $\mathrm{H}_2\mathrm{O}_2$ 和过氧脂质存在时，碘可作为电子供体发挥作用。碘可与活性氧竞争细胞成分和中和羟自由基，防止细胞遭受破坏。碘还可以与细胞膜多不饱和脂肪酸的双键接触，使之不易产生自由基。因此，碘在预防癌症方面有一定的积极作用。

:::keypoint{label="碘的两本账"}
- 主要作用：参与甲状腺激素的合成。
- 另一功能：抗氧化——作电子供体，与活性氧竞争细胞成分、中和羟自由基；与膜多不饱和脂肪酸双键接触，使之不易产生自由基。教材写其在预防癌症方面有一定积极作用。
:::

### （三）碘缺乏可引起地方性甲状腺肿

缺碘可引起地方性甲状腺肿，严重可致发育停滞、痴呆，如胎儿期缺碘可致呆小病。若摄入碘过多又可致高碘性甲状腺肿，表现为甲状腺功能亢进及一些中毒症状。

:::compare{title="缺碘与高碘都可以肿甲状腺"}
| | 表现 |
|--|------|
| 缺碘 | 地方性甲状腺肿；严重：发育停滞、痴呆；胎儿期缺碘 → 呆小病 |
| 摄入过多 | 高碘性甲状腺肿；甲状腺功能亢进及一些中毒症状 |
:::

:::pitfall{label="甲状腺肿不等于都是缺碘"}
缺碘和地方性甲状腺肿是一条链；摄入过多可致高碘性甲状腺肿和甲亢。看见“甲状腺肿”先问碘是少了还是多了，再问是不是呆小病那一笔（胎儿期缺碘）。
:::

## 九、钴是维生素 B12 的组成成分

### （一）钴参与合成维生素 B12

人体对钴（cobalt）的最小需要量为 $1\,\mu\mathrm{g}$。来自食物中的钴必须在肠内经细菌合成维生素 $\mathrm{B}_{12}$ 后才能被吸收利用。钴主要从尿中排泄。体内的钴主要以维生素 $\mathrm{B}_{12}$ 的形式发挥作用（见第六章）。

:::definition{label="钴"}
人体对钴（cobalt）的最小需要量为 $1\,\mu\mathrm{g}$。食物中的钴必须在肠内经细菌合成维生素 $\mathrm{B}_{12}$ 后才能被吸收利用。主要从尿排泄。体内主要以维生素 $\mathrm{B}_{12}$ 的形式发挥作用。
:::

:::concept{term="先问钴有没有被肠菌写成维生素 B12，再问缺不缺"}
钴不是“吃进去的离子直接当辅因子”。必须经肠内细菌合成维生素 $\mathrm{B}_{12}$ 后才能吸收利用。第六章再展开维生素 $\mathrm{B}_{12}$；本节只把户头立在钴。
:::

### （二）钴缺乏可引起巨幼细胞贫血等疾病

钴的缺乏可使维生素 $\mathrm{B}_{12}$ 缺乏，而维生素 $\mathrm{B}_{12}$ 缺乏可引起巨幼细胞贫血等疾病。由于人体排钴能力强，很少有钴蓄积的现象发生。

:::definition{label="钴缺乏"}
钴缺乏 → 维生素 $\mathrm{B}_{12}$ 缺乏 → 巨幼细胞贫血等。人体排钴能力强，很少蓄积。
:::

| 元素 | 贫血类型（教材） | 机制要点 |
|------|------------------|----------|
| 铁 | 小细胞低色素性贫血 | 血红蛋白等铁卟啉合成原料不足；也见于失血、需要量增加未补 |
| 铜 | 小细胞低色素性贫血（特征性表现之一） | 铜蓝蛋白把 $\mathrm{Fe}^{2+}$ 氧化为 $\mathrm{Fe}^{3+}$ 才能交给运铁蛋白 |
| 钴 | 巨幼细胞贫血 | 钴 → 维生素 $\mathrm{B}_{12}$；$\mathrm{B}_{12}$ 缺乏 |
:::

## 十、氟与骨、牙的形成及钙磷代谢密切相关

### （一）氟主要与球蛋白结合而运输

成人体内含氟（fluorine）$2\sim 6\,\mathrm{g}$，其中 $90\%$ 分布于骨、牙中，少量存在于指甲、毛发及神经肌肉中。氟的生理需要量每日为 $0.5\sim 1.0\,\mathrm{mg}$。氟主要从胃肠和呼吸道吸收，入血后与球蛋白结合，小部分以氟化物形式运输。血中氟含量约为 $20\,\mu\mathrm{mol}/\mathrm{L}$。氟主要从尿中排泄。

:::definition{label="氟的分布与运输"}
成人体内含氟 $2\sim 6\,\mathrm{g}$，$90\%$ 在骨、牙，少量在指甲、毛发及神经肌肉。每日生理需要量 $0.5\sim 1.0\,\mathrm{mg}$。胃肠和呼吸道吸收；入血后与球蛋白结合，小部分以氟化物形式运输。血氟约 $20\,\mu\mathrm{mol}/\mathrm{L}$；主要从尿排泄。
:::

### （二）氟主要被羟基磷灰石吸附参与代谢

氟可被羟基磷灰石吸附，生成氟磷灰石，从而加强对龋牙的抵抗作用，与骨、牙的形成及钙磷代谢密切相关。

:::definition{label="氟磷灰石"}
氟被羟基磷灰石吸附，生成氟磷灰石，加强对龋牙的抵抗作用。氟与骨、牙的形成及钙磷代谢密切相关。
:::

### （三）氟缺乏可引起骨质疏松

缺氟可致骨质疏松，易发生骨折；牙釉质受损易碎。氟过多可引起骨脱钙和白内障，并可影响肾上腺、生殖腺等多种器官的功能。

:::compare{title="缺氟与氟过多"}
| | 表现 |
|--|------|
| 缺氟 | 骨质疏松，易骨折；牙釉质受损易碎 |
| 氟过多 | 骨脱钙、白内障；影响肾上腺、生殖腺等多种器官 |
:::

## 十一、铬与胰岛素的作用密切相关

### （一）铬的最好来源是肉类

整粒的谷类、豆类、海藻类、啤酒酵母、乳制品和肉类是铬（chromium）的最好来源，尤以肝脏和其他内脏，是生物有效性高的铬的来源。人体每日摄入铬 $30\sim 40\,\mu\mathrm{g}$ 便足以满足人体的需要。

:::definition{label="铬的来源与需要量"}
铬（chromium）最好来源：整粒谷类、豆类、海藻类、啤酒酵母、乳制品和肉类；尤以肝脏和其他内脏生物有效性高。每日摄入 $30\sim 40\,\mu\mathrm{g}$ 足以满足需要。
:::

### （二）铬与胰岛素的作用关系密切

铬是铬调素（chromodulin）的组成成分。铬调素通过促进胰岛素与细胞受体的结合，增强胰岛素的生物学效应。铬缺乏主要表现为胰岛素功效降低，导致葡萄糖耐量受损，血清胆固醇和血糖上升。动物实验证明，铬还具有预防动脉硬化和冠心病的作用，并为生长发育所需要。

:::definition{label="铬调素"}
铬是铬调素（chromodulin）的组成成分。铬调素促进胰岛素与细胞受体结合，增强胰岛素的生物学效应。
:::

:::cause-effect{title="缺铬如何碰到糖和脂"}
- **因** 铬调素减少 → 胰岛素与受体结合减弱，胰岛素功效降低
- **果** 葡萄糖耐量受损，血清胆固醇和血糖上升。动物实验还提示预防动脉硬化和冠心病，并为生长发育所需
:::

### （三）铬失调对人体具有危害

因膳食因素所致铬摄取不足而引起的缺乏症未见报道。但过量可出现铬中毒。六价铬的毒性比三价铬高约 $100$ 倍，但不同化合物毒性不同。临床上铬及其化合物主要侵害皮肤和呼吸道，出现皮肤黏膜的刺激和腐蚀作用，如皮炎、溃疡、咽炎、胃痛、胃肠道溃疡，伴有周身酸痛、乏力等，严重者发生急性肾衰竭。

:::definition{label="铬中毒"}
膳食因素所致铬缺乏症未见报道；过量可中毒。六价铬毒性约比三价铬高 $100$ 倍，不同化合物毒性不同。主要侵害皮肤和呼吸道：皮炎、溃疡、咽炎、胃痛、胃肠道溃疡，伴周身酸痛、乏力；严重者急性肾衰竭。
:::

:::pitfall{label="铬缺乏症“未见报道”不等于铬没有生理作用"}
教材一方面写铬调素增敏胰岛素，动物实验预防动脉硬化；一方面写因膳食因素所致缺乏症未见报道。不要把后一句听成“铬可以不记”，也不要把六价铬中毒听成三价铬营养缺乏。
:::

## 本章小结

水分子以液、气、固等多种形态存在于自然界。常温常压的液态我们称之为水，气态的水被称为水蒸气，固态的水被称为冰。冰的熔点是 $0^{\circ}\mathrm{C}$，其密度为 $0.9\,\mathrm{g}/\mathrm{cm}^{3}$。水体积最小时为 $4^{\circ}\mathrm{C}$，当水冻结成冰时，体积可增大约 $1/9$。普通水中的氢原子被其核素氘所取代而形成的水被称为重水，标准大气压下，水的冰点为 $0^{\circ}\mathrm{C}$，沸点为 $100^{\circ}\mathrm{C}$。重水的冰点是 $3.8^{\circ}\mathrm{C}$。水分子由两个氢原子与一个氧原子以单键结合而成；水分子之间可形成氢键，具有方向性和饱和性。水是人体的基础组成成分之一，也以结合水的形式参与生物大分子（蛋白质、核酸、酶、碳水化合物等）的组成。水是媒体和载体，水溶液中的非共价键影响大分子物质的结构与功能，与生物大分子共同完成生命的能量、物质和信息等生命活动。水的生理功能主要为维持组织、细胞的形态，运输物质，参与物质代谢，润滑作用，调节体温等。水是一种酸碱两性物质，可电离为 $\mathrm{H}_3\mathrm{O}^{+}$ 离子和 $\mathrm{OH}^{-}$ 离子。水分子参与缓冲体系的形成。水摄入不足或丢失过多可引起脱水。

无机元素绝大多数为金属元素。在体内一般结合成化合物或络合物，广泛分布于各组织中，含量较恒定。无机元素通过构成酶活性中心或辅酶、参与体内物质运输、参与激素和维生素的生成等形式在体内发挥重要作用。钙与磷除了作为骨的主要组成外，还具有重要的生理调节功能，血钙与血磷相对恒定，$\mathrm{PTH}$、$\mathrm{CT}$ 和 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 调节钙磷代谢。铁是血红蛋白、肌红蛋白、细胞色素系统、呼吸链复合物、过氧化物酶及过氧化氢酶等的重要组成部分，在气体运输、生物氧化和酶促反应中均发挥重要的作用。运铁蛋白和铁蛋白分别是铁的运输和储存形式。铁的缺乏可引起小细胞低色素性贫血。锌是含锌金属酶和许多锌指蛋白的组成成分。铜是体内多种酶的辅基。锰是多种酶的组成成分和激活剂。硒在体内以硒半胱氨酸的形式存在于硒蛋白中，具有抗氧化和维持机体生长、发育与代谢的重要功能。碘参与甲状腺激素的合成。钴主要以维生素 $\mathrm{B}_{12}$ 的形式发挥作用。氟与骨、牙的形成及钙磷代谢密切相关。铬作为铬调素的组成成分有增敏胰岛素的作用。

:::definition{label="本章小结里的水"}
水分子液、气、固三相；常温常压液态称水。冰熔点 $0^{\circ}\mathrm{C}$、密度 $0.9\,\mathrm{g}/\mathrm{cm}^{3}$；体积最小在 $4^{\circ}\mathrm{C}$，成冰体积约增 $1/9$。水分子由两个氢与一个氧以单键结合，分子间氢键有方向性和饱和性。结合水参与生物大分子组成；水是媒体和载体。生理功能：维持形态、运输、参与代谢、润滑、调节体温。两性电离为 $\mathrm{H}_3\mathrm{O}^{+}$ 和 $\mathrm{OH}^{-}$，参与缓冲；摄入不足或丢失过多引起脱水。
:::

:::definition{label="本章小结里的钙磷调节"}
钙与磷除作为骨的主要组成外，还具有重要生理调节功能。血钙与血磷相对恒定。小结点名 $\mathrm{PTH}$、$\mathrm{CT}$ 和 $1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 调节钙磷代谢（正文钙磷两节未展开这三种激素的细节，户头记在小结）。

- [ ] 胞钙是第二信使；$90\%$ 以上在内质网和线粒体。
- [ ] 维生素 $\mathrm{D}$ 缺乏：儿童佝偻病、成人骨软化症；脱盐：骨质疏松；甲旁亢/维生素 $\mathrm{D}$ 中毒：高钙血症；甲旁减：低钙血症。
- [ ] 磷：$85.7\%$ 在骨；$[\mathrm{Ca}]\times[\mathrm{P}]=35\sim 40$；磷酸根→核酸、核苷酸、磷脂、辅酶、$\mathrm{ATP}$、磷酸氢盐缓冲。
- [ ] 铁：微量元素中含量最多；只有 $\mathrm{Fe}^{2+}$ 经十二指肠及空肠上段吸收；血中运 $\mathrm{Fe}^{3+}$（运铁蛋白），储存铁蛋白（$24$ 亚基，最多约 $4500$ 个铁离子）。
- [ ] 黏膜脱落是铁几乎唯一的排泄途径。
- [ ] 铁约 $75\%$ 在铁卟啉，$25\%$ 在非铁卟啉；缺铁→小细胞低色素性贫血；过剩→血铁黄素、血色素沉着病；储存运输用 $\mathrm{Fe}^{3+}$ 防铁死亡。
- [ ] 锌含量次于铁；$6$-磷酸肌醇影响吸收；清蛋白/运铁蛋白运输，金属硫蛋白储存；锌指调控转录；缺锌儿童可睾丸萎缩。
- [ ] 铜约 $60\%$ 结合铜蓝蛋白；催化 $\mathrm{Fe}^{2+}\rightarrow\mathrm{Fe}^{3+}$；含铜酶多用 $\mathrm{O}_2$ 或其衍生物为底物。
- [ ] 锰金属酶可被镁代替激活；过量→锰狂症（复合物Ⅰ、$\mathrm{ATP}$ 酶、多巴胺）。
- [ ] 硒：硒半胱氨酸→硒蛋白；$\mathrm{GSH}$ 过氧化物酶降 $\mathrm{H}_2\mathrm{O}_2$；克山病是低硒地方性心肌病。
- [ ] 碘约 $30\%$ 在甲状腺；缺碘→地方性甲状腺肿、呆小病；过多→高碘性甲状腺肿。
- [ ] 钴须经肠菌合成维生素 $\mathrm{B}_{12}$ 才能吸收；缺乏→巨幼细胞贫血；很少蓄积。
- [ ] 氟→氟磷灰石抗龋；缺氟骨质疏松、釉质易碎。
- [ ] 铬：铬调素增敏胰岛素；膳食缺乏症未见报道；六价铬毒性约高 $100$ 倍。
- [ ] 小结：$\mathrm{PTH}$、$\mathrm{CT}$、$1,25\text{-}(\mathrm{OH})_{2}\text{-}\mathrm{D}_{3}$ 调节钙磷代谢。
- [ ] 贫血：铁、铜→小细胞低色素；钴（$\mathrm{B}_{12}$）→巨幼细胞。
