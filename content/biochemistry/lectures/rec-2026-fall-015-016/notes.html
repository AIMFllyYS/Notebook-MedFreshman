为什么代谢难

  1. 知识点密集：各种化学反应、关键酶多
  2. 通路复杂：糖、脂、氨基酸代谢之间有交叉互变
  3. 无高中铺垫：高中没学过代谢，突然接触有gap
  4. 动态调控：整体是一个平衡系统

老师的学习要求

  • 糖代谢通路要正背、倒背都滚瓜烂熟
  • 糖酵解（葡萄糖→丙酮酸）和糖异生（丙酮酸→葡萄糖）是互为相反路径
  • 复习前置知识：酶的命名、Km值、酶活性调节（别构调节、化学修饰）
  • 关键酶=限速酶=不可逆反应的酶，与酶对底物亲和力（Km值）有关
🔍 网络验证：代谢重编程（metabolic reprogramming）是当前肿瘤研究热点，瓦伯格效应（Warburg effect）指肿瘤细胞即使在有氧条件下也优先进行糖酵解。这些表述与教材一致。

一、新陈代谢的概念

1.1 定义

新陈代谢是生命个体与外界进行物质和能量交换，以及体内物质与能量转变的全过程。

  • 新：新合成——从外界摄取营养物质（一日三餐）
  • 陈：分解排出——将代谢废物排出体外
  • 遵循物质守恒、能量守恒

1.2 发生场所

  • 代谢发生在每个细胞内
  • 不同细胞有不同代谢特征（代谢特异性）：
  • 神经元：只能利用葡萄糖或酮体供能，不能直接利用游离脂肪酸
  • 心肌细胞：线粒体丰富，氧化代谢旺盛
  • 红细胞：无线粒体，只能进行糖酵解
  • 肿瘤细胞：瓦伯格效应（有氧状态下仍旺盛糖酵解）

1.3 代谢与疾病

  • 以前认为80-90%的病是基因病，现在认为80-90%的病是代谢病
  • 高血压、高血脂、高血糖、肿瘤、心梗脑梗都与代谢紊乱相关
  • 代谢重编程：疾病状态下代谢发生异常重编程，治疗目标是逆转回生理态

1.4 药物实例

  • 阿托伐他汀（第一代降脂药）：抑制HMG-CoA还原酶（胆固醇合成关键酶），经肝代谢
  • 瑞舒伐他汀（水溶性）：经肾代谢
  • 英克司兰（Inclisiran）：siRNA药物，knockdown肝脏PCSK9，促进胆固醇降解。老师本人8月28日因他汀副作用换用此药
🔍 网络验证：Inclisiran（英克司兰）是诺华公司开发的siRNA药物，靶向PCSK9 mRNA，降低LDL-C。每年仅需注射2次。HMG-CoA还原酶是胆固醇合成限速酶。

1.5 代谢的核心机制

  • 生物化学 = 有生命个体中的化学反应
  • 细胞内化学反应与体外化学实验不同——必须有酶催化
  • 酶催化的反应形成不同的代谢通路
  • 分两大类：合成代谢和分解代谢

二、合成代谢与分解代谢

2.1 合成代谢

  • 目的：将外界摄取的营养物质转化为自身所需物质
  • 食物中的糖、脂、蛋白质是"别人的东西"，不能直接用
  • 消化吸收→大分子变小分子→再合成自身物质
  • 包括：
  • 能量物质（ATP、糖原）
  • 结构物质（蛋白质、核酸、脂质、糖）
  • 维生素（大部分需从食物获取）

2.2 分解代谢

  • 目的：①供能 ②排出废物
  • 衰老细胞的蛋白质、核酸等大分子分解为小分子
  • 以葡萄糖为例的细胞呼吸：
  1. 糖酵解（glycolysis）：葡萄糖→丙酮酸（胞质）
  2. 丙酮酸进入线粒体→Krebs循环（三羧酸循环）
  3. 氧化磷酸化→呼吸链→ATP合酶工作
  4. 最终产物：CO₂ + H₂O + ATP
  • 其他物质也可分解：氨基酸→α-酮酸+氨基→尿素排出；脂类→CO₂+H₂O
老师举例心肌细胞培养：原代心肌细胞贴壁后各跳各的，增殖后成片同步跳动，能量来自ATP。

2.3 对立统一与动态平衡

  • 合成与分解相互依存，维持动态平衡
  • 平衡打破→生理态变病理态
  • 核心枢纽：线粒体（能量流动）
  • 线粒体不断融合、分裂（dynamic），异常→ATP产生异常→细胞功能紊乱
老师金句："从新陈代谢的概念来说，我们的生命在于代谢。"

三、生物大分子与代谢的关系

3.1 蛋白质——代谢的执行者

  • 蛋白质是细胞功能执行者
  • 一级结构决定空间构象，空间构象决定功能
  • 一级结构=氨基酸序列，唯一不同的是R基团
  • R基团排列决定了二级结构的氢键、三级结构的离子键/疏水键/范德华力
  • 酶是特殊蛋白质，最重要的功能域是活性中心（active center）
  • 🔴 名词解释考点：酶的活性中心
  • 酶活性调节的本质=活性中心的暴露或掩盖

酶活性的快速调节（两种）

调节方式机制特点
别构调节别构剂（游离化合物）结合酶活性中心外部位→构象改变→活性中心暴露/掩盖需要外来化合物结合；如阿托伐他汀结合HMG-CoA还原酶
化学修饰在另一种酶催化下，对R基团进行共价修饰不需要外来化合物；最常见的是磷酸化
🔥 单选题高频：体内最常见的化学修饰是磷酸化。 磷酸化位点：含有羟基的氨基酸——丝氨酸、苏氨酸、酪氨酸。

3.2 核酸——代谢的控制者

  • 所有酶都需经基因表达（DNA→RNA→蛋白质）合成
  • 核酸控制酶的表达量
  • 快速调节（毫秒级）：别构调节、化学修饰——改变已有酶的活性
  • 慢速调节：通过基因表达调控酶的合成量——改变酶总量

3.3 其他生物大分子

  • 糖原：血糖调节的储能物质，肝糖原饥饿时分解补充血糖
  • 脂类：高效储能+细胞膜结构成分+信号分子
  • 维生素：大部分需从食物获取

四、糖的化学

4.1 糖的定义

  • 糖 = 碳水化合物（carbohydrate）
  • 化学本质：多羟基醛或多羟基酮及其多聚体、衍生物
  • 与日常说的"糖"（蔗糖、麦芽糖）不同

4.2 糖的分类（按水解产物）

类别定义举例
单糖不能再水解葡萄糖（己醛糖）、果糖（己酮糖）、半乳糖（己醛糖，4号C不同）、核糖（五碳糖）
寡糖水解产生少数单糖麦芽糖（葡+葡）、蔗糖（葡+果）、乳糖（葡+半乳糖）、麦芽三糖
多糖水解产生大量单糖（生物大分子）淀粉、糖原、纤维素
结合糖糖与非糖物质结合糖脂、糖蛋白、蛋白多糖

4.3 重要多糖的结构区别

多糖来源糖苷键人体能否消化
淀粉植物储能α-1,4（直链）+ α-1,6（支链）✅ 有α-糖苷酶
糖原动物储能α-1,4（直链）+ α-1,6（支链）✅ 有α-糖苷酶
纤维素植物骨架β-1,4（无分支）❌ 无β-糖苷酶，仅促胃肠蠕动
🔍 网络验证：淀粉和糖原的α-1,4/α-1,6糖苷键结构、纤维素的β-1,4糖苷键，与生物化学教材一致。

4.4 结合糖

  • 糖脂：糖+脂（甘油糖脂、鞘糖脂）
  • 糖蛋白：蛋白为主+糖链（如受体、细胞因子）
  • 蛋白多糖：糖链为主+蛋白
  • 糖蛋白功能：受体-配体识别依赖胞外糖链的特异性（糖基化修饰）
  • 高糖环境→糖基化异常→受体功能异常→信号传导异常

五、糖的三大生理功能

  1. 氧化供能（最主要功能，多选题高频考点）——提供ATP
  2. 提供合成原料——为非必需氨基酸（α-酮酸）、脂肪（甘油+脂肪酸）、胆固醇、核苷酸（戊糖）提供碳源
老师举例："只吃米饭不吃油也减不了肥，因为米饭可以提供合成甘油三酯的全部原材料。"
  1. 机体组成成分——糖蛋白、蛋白聚糖、糖脂分布于细胞膜

六、糖的消化吸收

6.1 食物来源

  • 最主要：淀粉（主食）
  • 其他：糖原（肉类）、麦芽糖、蔗糖、乳糖、单糖（可直接吸收）

6.2 消化过程

  • 口腔：唾液淀粉酶（少量）
  • 小肠：胰液淀粉酶→寡糖（麦芽糖、麦芽三糖、异麦芽糖、α-糊精）
  • 小肠黏膜刷状缘：α-糖苷酶→最终水解为单糖（葡萄糖）

6.3 吸收——SGLT（★ 单选题考点）

  • 吸收部位：小肠上段
  • 转运体：SGLT（Sodium-Glucose Linked Transporter）
  • S = Sodium（钠离子）
  • 一分子葡萄糖 + 一分子Na⁺ 协同转运
  • 唯一需要耗能的葡萄糖转运体（继发性主动转运，钠泵排Na⁺消耗ATP）
  • 葡萄糖→小肠黏膜细胞→门静脉→肝脏→体循环

6.4 组织细胞的葡萄糖转运——GLUT家族

亚型主要分布特点
GLUT1红细胞、脑、肾、结肠
GLUT2肝脏、胰腺β细胞Km最大→亲和力最低→严格控制血糖进出
GLUT3脑、肾
GLUT4心肌、骨骼肌受胰岛素调控，膜转位
GLUT5小肠

GLUT4的胰岛素调控机制

  1. 生理状态下GLUT4储存在循环内体（cycling endosome）囊泡中
  2. 胰岛素→胰岛素受体→胞内段变构→信号级联→酪氨酸蛋白激酶活化
  3. 分选蛋白（sorting protein）磷酸化（化学修饰）→促进囊泡与细胞膜融合
  4. GLUT4转位到细胞膜→葡萄糖进入细胞→血糖降低
  5. 血糖恢复正常→胰岛素减少→GLUT4内化回内体
🔴 2型糖尿病机制：胰岛素分泌正常但受体/信号通路缺陷→分选蛋白不工作→GLUT4永远上不了膜→葡萄糖进不去细胞→高血糖。

6.5 乳糖不耐受

  • 乳糖酶缺乏（先天性或老年继发）→不能水解乳糖
  • 症状：腹胀、腹泻、脱水
  • 婴幼儿严重可致肠套叠、水电解质紊乱
  • 乳糖酶基因是可诱导基因，随饮食诱导可逐渐耐受
  • 缓解：喝舒化奶（已水解乳糖）、酸奶

七、血糖稳态调控

7.1 核心器官——肝脏

肝脏是维持血糖稳定的最主要器官。

7.2 进食状态

  • 血糖升高→肝脏：
  1. 自身氧化供能消耗葡萄糖
  2. 合成肝糖原储存
  3. 合成甘油三酯→运到脂肪细胞

7.3 饥饿状态

  • 血糖降低→肝脏：
  1. 短期饥饿：肝糖原分解→补充血糖（肝糖原约70g）
  2. 长期饥饿：糖原耗尽→糖异生
  • 生糖氨基酸（谷氨酸、天冬氨酸等）脱氨→α-酮酸→糖异生
  • 甘油（来自脂肪动员）→糖异生
⚠️ 肌糖原不能直接补充血糖，只能在肌肉应激（运动）时自身利用。

7.4 与健康运动的关系

  • 有氧运动需持续>45分钟才开始动员脂肪
  • 短时间运动先消耗糖原和肌肉氨基酸→肌萎缩
  • 建议：先增肌（无氧），再长时间有氧

八、糖分解代谢的概念区分

8.1 糖无氧氧化

  • 条件：缺氧状态
  • 场所：胞质
  • 过程：1分子葡萄糖→2分子乳酸+少量ATP
  • 产物：乳酸 + ATP

8.2 糖酵解

  • 条件：无缺氧限定
  • 过程：1分子葡萄糖→2分子丙酮酸
  • 产物：丙酮酸
  • 是糖有氧氧化和糖无氧氧化的共同通路

8.3 关系

`` 糖无氧氧化 = 糖酵解（葡萄糖→丙酮酸）+ 丙酮酸→乳酸（第二阶段） 糖有氧氧化 = 糖酵解（葡萄糖→丙酮酸）+ 丙酮酸→线粒体→三羧酸循环→氧化磷酸化 ``

🔥 名词解释高频：糖有氧氧化 vs 糖酵解 vs 糖无氧氧化的概念区分。 老师还提到巴斯德效应和瓦伯格效应是需要名词解释的考点（本次未展开，后续课程讲）。

主动回忆题

Q1：别构调节和化学修饰有什么异同？

A：共同点是都改变酶的构象从而调节活性中心。不同点：别构调节需要别构剂（外来化合物）结合酶活性中心外部位；化学修饰是在另一种酶催化下对氨基酸R基团进行共价修饰（最常见磷酸化），不需要外来游离化合物。

Q2：为什么SGLT是唯一需要耗能的葡萄糖转运体？

A：SGLT是Na⁺-葡萄糖协同转运，Na⁺顺浓度梯度内流驱动葡萄糖逆浓度转运；但细胞内Na⁺升高后需钠泵（Na⁺/K⁺-ATP酶）将Na⁺泵出，消耗ATP，因此是继发性主动转运。

Q3：GLUT4如何响应胰岛素？2型糖尿病时哪里出了问题？

A：胰岛素结合受体→信号级联→分选蛋白磷酸化→含GLUT4的内体囊泡与细胞膜融合→GLUT4上膜转运葡萄糖入胞。2型糖尿病时胰岛素受体/胞内信号通路缺陷，分选蛋白不激活，GLUT4无法上膜，葡萄糖进不去细胞导致高血糖。

Q4：糖无氧氧化和糖酵解有什么区别和联系？

A：糖酵解是葡萄糖→丙酮酸的过程（无缺氧条件限定），是两者共同通路；糖无氧氧化是缺氧条件下葡萄糖在胞质生成乳酸+少量ATP的过程，包含糖酵解+丙酮酸→乳酸两个阶段。

Q5：为什么只吃碳水低脂饮食也减不了肥？

A：糖的第二大生理功能是为非糖物质合成提供原料。葡萄糖可转化为甘油和脂肪酸，再合成甘油三酯储存。米饭等碳水化合物可提供合成脂肪的全部碳源。

Q6：长期饥饿时肝脏如何维持血糖？

A：短期饥饿靠肝糖原分解（约70g）；长期饥饿糖原耗尽后靠糖异生——生糖氨基酸脱氨生成α-酮酸、甘油（脂肪动员）等非糖物质异生为葡萄糖。肌糖原不能直接补充血糖。
