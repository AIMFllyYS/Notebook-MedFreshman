## 一、磷酸戊糖途径的意义与底层逻辑

### 1.1 为什么走这条旁路？

PPP的底物是6-磷酸葡萄糖（G6P），它不直接走糖酵解，而是走一条旁路。**走这条旁路的意义有二**：

1. **提供NADPH**（合成代谢的还原当量/供氢体）
2. **提供5-磷酸核糖**（核苷酸合成的原料）

> 🔑 **关键区分——NADPH ≠ NADH**：
> - **NADH**：还原当量进入**氧化呼吸链**生成ATP（产能）
> - **NADPH**：用于**合成代谢**的递氢体（供氢），如脂肪酸、胆固醇合成

### 1.2 为什么NADPH需求远大于5-磷酸核糖？

- 一个细胞形成后，DNA和RNA的量是**固定的**——不需要每天大量合成核酸
- 但新陈代谢**无时无刻不在进行**，合成途径持续需要NADPH
- 因此PPP**主要功能是提供NADPH**，核糖是副产品

### 1.3 多余的核糖怎么办？

- 通过第二阶段（基团转移阶段），把多余的五碳糖转变回糖酵解中间产物
- 最终返回糖酵解主途径，彻底氧化为CO₂和水

## 二、磷酸戊糖途径的反应过程

### 2.1 两大阶段总览

| 阶段 | 名称 | 关键反应 | 产物 |
|---|---|---|---|
| 第一阶段 | **氧化阶段** | 脱氢+脱羧 | 2 NADPH + CO₂ + 5-磷酸核酮糖 |
| 第二阶段 | **基团转移阶段** | 碳基团转移（3C/4C/6C/7C互变） | 3-磷酸甘油醛 + 6-磷酸果糖（返回糖酵解） |

> 陈教授强调："整个过程我不需要你记全过程，你要知道第一阶段氧化阶段在生成NADPH和五碳糖的时候，还有一分子CO₂，因为我脱掉了一个碳。第二阶段基团转移的目的，我要生成三碳化合物和六碳化合物。"

### 2.2 氧化阶段详细步骤

```
6-磷酸葡萄糖 → [G6PD脱氢酶] → 6-磷酸葡萄糖内酯 → 加水开环 → 6-磷酸葡萄糖酸
    → [6-磷酸葡萄糖酸脱氢酶] → 5-磷酸核酮糖 + NADPH + CO₂
```

- **第一步脱氢**：G6PD催化，生成第一个NADPH → 6-磷酸葡萄糖内酯
- **开环加水**：内酯开环生成6-磷酸葡萄糖酸
- **第二步脱氢+脱羧**：6-磷酸葡萄糖酸脱氢酶催化，生成第二个NADPH，脱下一个CO₂ → 5-磷酸核酮糖
- 5-磷酸核酮糖可转变为：**5-磷酸核糖**（核苷酸原料）或**5-磷酸木酮糖**

### 2.3 基团转移阶段

- 木酮糖（5C）与核糖（5C）进行碳基团转移
- 木酮糖上的2个碳转移给核糖 → 生成景天糖（7C）+ 3-磷酸甘油醛（3C）
- 景天糖（7C）再拿出3个碳转移给3-磷酸甘油醛 → 生成6-磷酸果糖（6C）+ 赤藓糖（4C）
- 赤藓糖（4C）继续与木酮糖进行基团转移 → 再生成3-磷酸甘油醛 + 6-磷酸果糖

> 🔑 **终产物**：**3-磷酸甘油醛**和**6-磷酸果糖**，返回糖酵解主途径。这些都可以在选择题里出。

### 2.4 考试要求

> "你给我把这一张片子给我记住，这就是我考试内容，都在这里。"

必记要点：
- **底物**：6-磷酸葡萄糖
- **关键酶**：6-磷酸葡萄糖脱氢酶（G6PD）——**限速酶/脱氢酶**
- **氧化阶段产物**：2 NADPH + 1 CO₂ + 5-磷酸核糖
- **终产物**：3-磷酸甘油醛 + 6-磷酸果糖（返回糖酵解）

## 三、磷酸戊糖途径的调节

- **调节因子**：受**NADPH/NADP⁺比值**调节
- NADPH多 → 别构抑制G6PD
- NADP⁺多（比值降低）→ 别构**激活**G6PD
- 🔑 单选题考点：PPP的关键酶受什么调节？答：**NADPH/NADP⁺比值**

### NADPH的生理功能

1. **参与脂类合成**（脂肪酸、胆固醇等合成代谢的供氢体）
2. **参与生物转化的羟化反应**（肝脏生化后续讲）
3. **维持谷胱甘肽（GSH）的还原态**（抗氧化）

## 四、蚕豆病 = G6PD缺乏症（考点）

### 4.1 病因

- 磷酸戊糖途径的关键酶**6-磷酸葡萄糖脱氢酶（G6PD）**发生突变或缺陷
- 导致NADPH生成不足 → 谷胱甘肽不能维持还原态 → 红细胞膜易受氧化损伤 → 溶血

### 4.2 科普插片要点

- **医学名称**：葡萄糖-6-磷酸脱氢酶（G6PD）缺乏症
- **地区分布**：我国西南、华南、华东、华北均有，尤其长江以南（广西、广东、四川、湖南、江西）
- **好发人群**：3岁以下患者占70%，男性患者占90%（X连锁隐性遗传）
- **诱因**：吃新鲜蚕豆后1~2天内发病（最短2小时，最长9天）
- **症状**：全身不适、疲倦乏力、畏寒发热、头晕头痛、恶心呕吐、腹痛、急性溶血
- **筛查方法**：G6PD活性定量测定；红细胞形态见水泡红细胞、咬唇红细胞
- **预防**：避免蚕豆及制品、樟脑丸、氧化类药物
- **遗传性疾病，无法根治，重在预防**

> 🔑 **考试要点**：蚕豆病的病因酶是什么？——**6-磷酸葡萄糖脱氢酶（G6PD）**。选择题A/B/C/D选项中选G6PD。

## 五、糖原合成与分解开篇

### 5.1 糖合成代谢的三条途径

1. **糖原合成**（Glycogenesis）——本节课主讲
2. **糖异生**——非糖物质合成糖（后续讲）
3. **葡萄糖的其他代谢通路**

> 整个糖的合成与分解以及储存的动态平衡，最终围绕**血糖水平**进行调节（第八节内容）。

### 5.2 糖原的结构

- **本质**：以葡萄糖单体聚合的**分支状多聚体**，是体内能量储备形式之一
- **直链**：**α-1,4糖苷键**相连
- **支链**：**α-1,6糖苷键**相连（1号碳与6号碳之间）
- **分支层级**：成熟糖原分子可达**12级分支**
- **分支的意义**：非还原端数量极多 → **动员起效快**，每个末端都可立即水解 → 快速补充血糖

### 5.3 糖原的组织分布与功能差异

| 组织 | 糖原类型 | 含量 | 功能 |
|---|---|---|---|
| **肌肉** | 肌糖原 | 180~300克（含量高） | 肌肉收缩**供能**，走糖酵解→乳酸 |
| **肝脏** | 肝糖原 | 70~100克（储备少） | **维持血糖水平恒定**，分解生成葡萄糖补充血糖 |

> ⚠️ **关键区别（选择题考点）**：
> - **肌糖原**分解 → 6-磷酸葡萄糖 → 糖酵解 → 丙酮酸 → **乳酸**（肌肉无葡萄糖-6-磷酸酶，不能释放葡萄糖）
> - **肝糖原**分解 → 6-磷酸葡萄糖 → **葡萄糖-6-磷酸酶**水解磷酸 → **游离葡萄糖** → 补充血糖

### 5.4 糖原合成（Glycogenesis）

**概念**：在肝脏或肌肉细胞中，通过**耗能**方式将葡萄糖连接形成糖原多聚体。

**合成步骤**：

1. **葡萄糖磷酸化**：己糖激酶催化 → 6-磷酸葡萄糖（耗能，糖酵解第一步）
2. **磷酸基团变位**：变位酶催化，6-磷酸葡萄糖 → **1-磷酸葡萄糖**（变位到1号碳，因为要形成α-1,4糖苷键）
3. **活化生成UDPG**：1-磷酸葡萄糖 + UTP →（UDPG焦磷酸化酶催化）→ **UDPG（尿苷二磷酸葡萄糖，活性葡萄糖供体）** + PPi
   - UTP水解两个磷酸基团，偶联形成磷氧酯键
4. **糖原引物合成**：糖原蛋白（glycogenin）自身催化，将第一个葡萄糖单体从UDPG转移到自身酪氨酸残基的羟基上，延伸至**8个葡萄糖** → 形成短麦芽寡糖链引物（primer）
5. **糖链延长**：**糖原合酶**（关键酶）催化，以UDPG为葡萄糖供体，在引物非还原端延伸，形成α-1,4糖苷键，延长至约15个葡萄糖单位
6. **形成分支**：**分支酶**（多功能酶）催化
   - 水解一段约7个葡萄糖的α-1,4糖苷键
   - 将这段转移到原链上，以**α-1,6糖苷键**连接 → 形成分支
   - 反复延长+分支 → 12级分支成熟糖原

> 🔑 **糖原合成关键酶**：**糖原合酶**（Km值大，亲和力最低）
> 🔑 **分支酶是多功能酶**：兼具水解α-1,4糖苷键和形成α-1,6糖苷键两种活性

### 5.5 糖原分解（Glycogenolysis）

**名词解释考点**：Glycogenolysis（lysis=裂解），指糖原从**非还原端**开始进行**磷酸解**（非水解），生成葡萄糖单体供机体快速利用。

**分解步骤**：

1. **磷酸解**：**糖原磷酸化酶**（关键酶）催化，从非还原端直接磷酸解α-1,4糖苷键，需要游离磷酸根 → 生成**1-磷酸葡萄糖** + 少一个糖单位的糖原（Gn）
2. **变位**：1-磷酸葡萄糖 → 6-磷酸葡萄糖（变位酶）
3. **组织差异**：
   - **肝脏**：有**葡萄糖-6-磷酸酶** → 6-磷酸葡萄糖脱磷酸 → **游离葡萄糖** → 补充血糖
   - **肌肉**：**无葡萄糖-6-磷酸酶** → 6-磷酸葡萄糖沿糖酵解 → 丙酮酸 → 无氧下→**乳酸**

**脱支酶（debranching enzyme）**：也是多功能酶，两种活性：
1. **葡聚糖转移酶活性**：将分支末端剩余4个葡萄糖中的3个转移到直链上
2. **α-1,6糖苷酶活性**：水解剩余的那个α-1,6糖苷键上的单个葡萄糖 → 游离葡萄糖

> 🔑 **糖原分解关键酶**：**糖原磷酸化酶**
> 🔑 **分支酶 vs 脱支酶**：分支酶=加分支（水解α-1,4+形成α-1,6）；脱支酶=去分支（转移3个+水解α-1,6）

### 5.6 合成与分解的调节——反向协同

> 陈教授："上游的激酶同时对两个关键酶进行化学修饰的时候，酶活性正好相反。"

| 关键酶 | 磷酸化修饰后 | 效果 |
|---|---|---|
| **糖原磷酸化酶** | 磷酸化酶b激酶催化磷酸化 → **激活** | 糖原分解↑ |
| **糖原合酶** | PKA催化磷酸化 → **抑制** | 糖原合成↓ |

- 激素调节：**胰高血糖素**、**肾上腺素** → 信号传递 → PKA活化
- PKA → 磷酸化酶b激酶活化 → 磷酸化酶活化（分解↑）
- PKA → 糖原合酶磷酸化 → 抑制（合成↓）
- 🔑 **结果**：糖原代谢只能走一个方向——要么合成，要么分解，不能同时进行

## 六、考试要点总结

### 必背考点

1. **PPP关键酶**：6-磷酸葡萄糖脱氢酶（G6PD），限速酶
2. **PPP调节**：NADPH/NADP⁺比值别构调节
3. **PPP产物**：2 NADPH + CO₂ + 5-磷酸核糖；终产物3-磷酸甘油醛+6-磷酸果糖
4. **NADPH ≠ NADH**：NADPH用于合成代谢/抗氧化，NADH用于呼吸链产ATP
5. **蚕豆病**：G6PD缺乏症 → 不能维持GSH还原态 → 溶血
6. **糖原结构**：α-1,4直链、α-1,6支链、12级分支、多非还原端快速动员
7. **肌糖原 vs 肝糖原**：肌糖原→乳酸（无6-磷酸酶）；肝糖原→葡萄糖（有6-磷酸酶）
8. **糖原合成关键酶**：糖原合酶；活性供体UDPG；引物8个葡萄糖
9. **糖原分解关键酶**：糖原磷酸化酶；磷酸解（非水解）生成1-磷酸葡萄糖
10. **分支酶/脱支酶**：都是多功能酶
11. **合成与分解反向调节**：磷酸化修饰→磷酸化酶激活+糖原合酶抑制

### 英文术语（英翻汉/汉翻英考点）

- **Glycogenesis**：糖原合成
- **Glycogenolysis**：糖原分解（lysis=裂解）
- **UDPG**：尿苷二磷酸葡萄糖（活性葡萄糖供体）
- **G6PD**：葡萄糖-6-磷酸脱氢酶

## 主动回忆题

1. **磷酸戊糖途径为什么被称为"弯道"？它的主要意义是什么？**
   > 答案要点：走旁路是为了提供NADPH（合成代谢还原当量）和5-磷酸核糖（核苷酸原料）。因机体对NADPH需求远大于核糖，多余核糖经基团转移回到糖酵解。

2. **蚕豆病的病因是什么酶？为什么吃蚕豆会诱发溶血？**
   > 答案要点：G6PD缺乏。G6PD是PPP限速酶，缺乏时NADPH生成不足，不能维持谷胱甘肽还原态，红细胞膜受氧化损伤而溶血。

3. **肌糖原和肝糖原分解的终产物为什么不同？**
   > 答案要点：肝脏有葡萄糖-6-磷酸酶，可将6-磷酸葡萄糖脱磷酸生成游离葡萄糖补充血糖；肌肉缺乏此酶，6-磷酸葡萄糖只能走糖酵解生成丙酮酸→乳酸。

4. **糖原合成中为什么需要UDPG？糖原合酶不能直接用葡萄糖合成吗？**
   > 答案要点：游离葡萄糖不能直接聚合，需先活化为UDPG（活性葡萄糖供体）。糖原合酶只能在已有引物（8个葡萄糖的短链）的非还原端延伸，不能从头合成。

5. **糖原合成和分解的两个关键酶是如何被反向调节的？**
   > 答案要点：PKA（受胰高血糖素/肾上腺素激活）使磷酸化酶b激酶磷酸化→激活磷酸化酶（分解↑）；同时PKA使糖原合酶磷酸化→抑制（合成↓）。磷酸化修饰对两酶效果相反，保证代谢单向进行。
