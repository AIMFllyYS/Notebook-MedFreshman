## 第一章 磷酸戊糖途径（PPP）

:::memory{label="1.1 PPP的意义与底层逻辑（高频）" mode="reveal"}

**直接结论**

- **走旁路的目的**：①提供NADPH（合成代谢还原当量）；②提供5-磷酸核糖（核苷酸合成原料）
- **主要功能是NADPH**：细胞形成后DNA/RNA量固定，不需每天大量合成核酸；但新陈代谢无时无刻不需要NADPH
- **多余核糖怎么办**：经基团转移阶段转变为3-磷酸甘油醛+6-磷酸果糖，返回糖酵解主途径

**深度解析**

- ⚠ NADPH ≠ NADH：NADPH用于**合成代谢**供氢（脂肪酸、胆固醇合成）；NADH/FADH₂用于**呼吸链**产ATP

**助记口诀**

> 弯道供氢又供核糖，NADPH是主要任务，多余碳源回正途

:::

:::memory{label="1.2 PPP关键酶与反应过程（高频）" mode="reveal"}

**直接结论**

- **限速酶**：6-磷酸葡萄糖脱氢酶（G6PD）——第一步脱氢
- **氧化阶段**：G6P → G6PD → 内酯 → 6-磷酸葡萄糖酸 → 5-磷酸核酮糖
- **产物**：2 NADPH + 1 CO₂ + 5-磷酸核糖（脱氢+脱羧）
- **终产物**：3-磷酸甘油醛 + 6-磷酸果糖（返回糖酵解）

**深度解析**

- 两步脱氢：第一步G6PD脱氢产NADPH；第二步6-磷酸葡萄糖酸脱氢酶脱氢+脱羧产第二个NADPH和CO₂
- 基团转移阶段：木酮糖(5C)+核糖(5C)→景天糖(7C)+3-PG(3C)→6-磷酸果糖(6C)+赤藓糖(4C)→再变回3-PG+6-PG

**助记口诀**

> G6PD脱氢产NADPH，脱羧放CO₂，基团转移回糖酵

:::

:::memory{label="1.3 PPP的调节" mode="reveal"}

**直接结论**

- **调节因子**：NADPH/NADP⁺比值
- NADPH多（比值高）→ 别构**抑制**G6PD
- NADP⁺多（比值低）→ 别构**激活**G6PD
- NADPH功能：脂类合成供氢、生物转化羟化反应、维持谷胱甘肽（GSH）还原态

:::

:::memory{label="1.4 蚕豆病=G6PD缺乏症（高频考点）" mode="reveal"}

**直接结论**

- **病因酶**：6-磷酸葡萄糖脱氢酶（G6PD）突变/缺陷
- **机制**：NADPH不足 → 不能维持GSH还原态 → 红细胞膜氧化损伤 → 急性溶血
- **诱因**：新鲜蚕豆（食用后1~2天发病）、樟脑丸、氧化类药物
- **分布**：长江以南多见（两广、四川、湖南、江西），男性患者占90%（X连锁隐性遗传）
- **筛查**：G6PD活性定量测定；红细胞见水泡红细胞、咬唇红细胞
- **遗传性疾病，无法根治，重在预防**

**助记口诀**

> 蚕豆病缺G6PD，NADPH不足溶血红

:::

## 第二章 糖原的结构与组织分布

:::memory{label="2.1 糖原分子结构（高频）" mode="reveal"}

**直接结论**

- **本质**：葡萄糖单体聚合的分支状多聚体，能量储备形式
- **直链**：α-1,4糖苷键
- **支链**：α-1,6糖苷键（1号碳与6号碳之间）
- **分支层级**：成熟糖原分子达**12级分支**
- **分支意义**：非还原端数量极多 → 每个末端可同时动员 → **起效快、快速补充血糖**

:::

:::memory{label="2.2 肌糖原 vs 肝糖原（高频选择考点）" mode="reveal"}

**直接结论**

| | 肌糖原 | 肝糖原 |
|---|---|---|
| 含量 | 180~300克（多） | 70~100克（少） |
| 功能 | 肌肉收缩**供能** | **维持血糖恒定** |
| 分解终产物 | **乳酸**（经糖酵解） | **葡萄糖**（补充血糖） |
| 关键区别 | 无葡萄糖-6-磷酸酶 | **有**葡萄糖-6-磷酸酶 |

**深度解析**

- 肌糖原分解→1-磷酸葡萄糖→6-磷酸葡萄糖→糖酵解→丙酮酸→乳酸（不能释放葡萄糖入血）
- 肝糖原分解→1-磷酸葡萄糖→6-磷酸葡萄糖→**葡萄糖-6-磷酸酶**脱磷酸→游离葡萄糖→入血补血糖

**助记口诀**

> 肌糖原供能变乳酸，肝糖原补糖靠6-磷酸酶

:::

## 第三章 糖原合成

:::memory{label="3.1 糖原合成流程与UDPG（高频）" mode="reveal"}

**直接结论**

- **英文**：Glycogenesis
- **概念**：肝脏/肌肉中耗能将葡萄糖聚合为糖原
- **活性供体**：UDPG（尿苷二磷酸葡萄糖）——游离葡萄糖不能直接聚合
- **合成步骤**：
  1. 己糖激酶：葡萄糖→6-磷酸葡萄糖（耗能）
  2. 变位酶：6-磷酸葡萄糖→1-磷酸葡萄糖
  3. UDPG焦磷酸化酶：1-磷酸葡萄糖+UTP→UDPG+PPi
  4. 糖原蛋白（glycogenin）自身催化合成**8个葡萄糖**引物
  5. **糖原合酶**（关键酶）：在引物非还原端以α-1,4糖苷键延长至15个
  6. **分支酶**（多功能酶）：水解α-1,4键切下7个→以α-1,6键连接成分支

**深度解析**

- 为什么磷酸要从6号位变位到1号位？因为要形成α-1,4糖苷键，必须在1号碳上活化
- 糖原蛋白自己就是糖基转移酶，催化自身酪氨酸残基羟基上加第一个葡萄糖

**助记口诀**

> 葡萄糖活化变UDPG，引物八碳糖原合酶延，分支酶来打1,6键

:::

:::memory{label="3.2 糖原合成关键酶与分支酶" mode="reveal"}

**直接结论**

- **关键酶**：**糖原合酶**（Km大，亲和力最低）
- **分支酶**：多功能酶，两种活性——①水解α-1,4糖苷键（切下约7个葡萄糖）；②形成α-1,6糖苷键（连接成分支）
- 反复延长+分支 → 12级分支成熟糖原

:::

## 第四章 糖原分解

:::memory{label="4.1 糖原分解流程与关键酶（高频）" mode="reveal"}

**直接结论**

- **英文**：Glycogenolysis（lysis=裂解）
- **概念**：糖原从非还原端开始**磷酸解**（注意：不是水解！），生成葡萄糖单体
- **关键酶**：**糖原磷酸化酶**——直接磷酸解α-1,4糖苷键
- **产物**：1-磷酸葡萄糖（主要）+ 少量游离葡萄糖
- **变位**：1-磷酸葡萄糖→6-磷酸葡萄糖（变位酶）
- **肝脏**：有葡萄糖-6-磷酸酶 → 生成游离葡萄糖补血糖
- **肌肉**：无此酶 → 走糖酵解→乳酸

**助记口诀**

> 磷酸化酶磷酸解，1-磷酸葡萄糖来，肝有6-磷酸酶变葡萄糖

:::

:::memory{label="4.2 脱支酶的双活性" mode="reveal"}

**直接结论**

- **脱支酶**也是多功能酶，两种活性：
  1. **葡聚糖转移酶活性**：将分支末端剩余4个葡萄糖中的**3个**转移到直链上
  2. **α-1,6糖苷酶活性**：水解剩余那个α-1,6糖苷键上的单个葡萄糖 → 游离葡萄糖
- 对比：**分支酶**=加分支（水解α-1,4+形成α-1,6）；**脱支酶**=去分支（转移3个+水解α-1,6）

:::

## 第五章 糖原代谢的反向调节

:::memory{label="5.1 合成与分解的反向化学修饰调节（高频）" mode="reveal"}

**直接结论**

- 两个关键酶：**糖原合酶**（合成）和**糖原磷酸化酶**（分解）
- **磷酸化修饰效果相反**：
  - 糖原磷酸化酶：磷酸化 → **激活**（分解↑）
  - 糖原合酶：磷酸化 → **抑制**（合成↓）
- **激素调节**：胰高血糖素、肾上腺素 → 信号传递 → **PKA活化**
- PKA → 磷酸化酶b激酶磷酸化激活 → 磷酸化酶激活
- PKA → 糖原合酶磷酸化 → 抑制
- **结果**：糖原代谢只能走一个方向（要么合成要么分解，不能同时进行）

**助记口诀**

> PABA一来两路反，磷酸化解糖原合酶断

:::
