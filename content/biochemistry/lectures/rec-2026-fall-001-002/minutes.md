## 二、案例一：硫胺素反应性巨幼细胞贫血

### 2.1 病例

- 1岁幼儿，突发咳嗽发烧
- 同时患有：肺炎、糖尿病、贫血、听力丧失
- 当地对症治疗半个月无好转
- 多种症状同时出现 → 大概率有共同病因

### 2.2 诊断路径

1. **全基因组测序**：发现 SLC19A2 基因缺陷
2. 该基因编码 **硫胺素转运蛋白1（ThTr1）**
3. 蛋白缺陷 → 硫胺素（维生素B1）转运障碍 → 硫胺素缺乏
4. 诊断：**硫胺素反应性巨幼细胞贫血**

### 2.3 分子机制

```
SLC19A2基因突变
  → 硫胺素转运蛋白1缺陷
    → 维生素B1（硫胺素）摄取不足
      → 焦磷酸硫胺素（TPP）生成减少
        → 丙酮酸脱氢酶复合体活性降低
          → 丙酮酸→乙酰CoA受阻
            → 三羧酸循环障碍
              → 能量代谢紊乱
                → 贫血/糖尿病/听力丧失等多系统症状
```

### 2.4 治疗

- **口服大剂量维生素B1**（每天口服）
- 转运蛋白效率降低，但增加底物浓度可部分代偿
- 反复症状缓解；耳聋因长期器质性损伤较难恢复
- 早发现可早期干预

## 三、案例二：CPS1缺陷与基因编辑治疗

### 3.1 病例

- 新生儿，手臂抬起僵硬、下降时颤抖（肌张力高/高氨血症表现）
- 血糖升高
- 基因测序发现 **CPS1（氨甲酰磷酸合成酶1）** 基因突变 → 蛋白缺乏

### 3.2 疾病

- CPS1是尿素循环关键酶，缺乏→高氨血症
- 治疗：严格低蛋白饮食（新生儿需高蛋白生长发育，非常困难）
- 最终需肝脏移植，否则高死亡率
- 即使存活，长期高氨→神经系统后遗症

### 3.3 基因编辑治疗

- 2023年5月报道：全世界第一例**个性化定制基因编辑疗法**
- 针对该患者自身基因突变进行定制
- 治疗后：恢复为健康正常儿童，随访无额外副作用
- 背后技术：CRISPR基因编辑等分子生物学技术

> ⚠️ 基因编辑仍有较高风险，国内也有患者冒险尝试，很多还在调查中。需关注技术和伦理问题。

| 时期 | 时间 | 费用 |

| 人类基因组计划（1990-2003） | 十几年 | 约30亿美元（多国合作） |

### 4.2 罕见病现状

- 全世界约 **7000种** 罕见病

- 约1/3医生不了解罕见病
- 每个罕见病患者平均：看 **8个医生**、**3次误诊**、**7年多**才能确诊

## 五、蛋白质功能概述

### 5.1 蛋白质的重要功能

| 功能类别 | 例子 |
|---|---|
| **物质运输** | 硫胺素转运蛋白1（SLC19A2编码）、血红蛋白、载体蛋白 |
| **酶催化** | CPS1（氨甲酰磷酸合成酶1）、丙酮酸脱氢酶复合体 |
| 结构支持 | 胶原蛋白、角蛋白 |
| 免疫防御 | 抗体、补体 |
| 信号传导 | 受体、激素蛋白 |
| 运动 | 肌动蛋白、肌球蛋白 |

### 5.2 关键概念

- **基因→蛋白质→功能**：基因编码蛋白质，蛋白质执行功能
- **辅因子**：很多酶需要辅因子才能发挥功能
  - 焦磷酸硫胺素（TPP）= 维生素B1的活性形式，是重要辅因子
  - TPP功能：**转移醛基**
- **丙酮酸脱氢酶复合体**：
  - 催化：丙酮酸 → 乙酰辅酶A（进入三羧酸循环的关键步骤）
  - 必需辅因子：TPP（焦磷酸硫胺素）
  - 是糖代谢的核心酶之一

## 六、教师强调与易错点

1. **生化是医学基础**：从分子机制理解疾病，从病因出发解决问题。
2. **基因→蛋白→功能→疾病**是核心逻辑链。
3. **维生素B1 = 硫胺素**，活性形式是焦磷酸硫胺素（TPP），功能是转移醛基。
4. **丙酮酸脱氢酶复合体**需要TPP，催化丙酮酸→乙酰CoA，是糖代谢关键步骤。
5. **SLC19A2**编码硫胺素转运蛋白1，缺陷导致硫胺素反应性巨幼细胞贫血，治疗是口服维生素B1。
6. **CPS1**是尿素循环关键酶，缺陷导致高氨血症，可通过基因编辑治疗。
7. **罕见病80%是遗传病**，全基因组测序可帮助确诊。
8. 基因编辑技术有前景但仍有风险，需关注伦理问题。

## 八、主动回忆题

**Q1. 为什么SLC19A2基因缺陷会导致贫血、糖尿病和听力丧失等多系统症状？**
SLC19A2编码硫胺素转运蛋白1，缺陷导致维生素B1（硫胺素）摄取不足。维生素B1的活性形式焦磷酸硫胺素（TPP）是丙酮酸脱氢酶复合体的必需辅因子，TPP不足使丙酮酸→乙酰CoA受阻，三羧酸循环障碍，能量代谢紊乱，影响多个高耗能系统（造血、胰岛、听觉神经），导致多系统症状。

**Q2. 硫胺素反应性巨幼细胞贫血为什么可以通过口服维生素B1治疗？**
转运蛋白缺陷使其效率降低，但并非完全失活。口服大剂量维生素B1提高底物浓度，可部分代偿转运效率的不足，使细胞获得足够的硫胺素，从而缓解症状。

**Q3. 基因→蛋白质→功能→疾病的逻辑链是什么？请用CPS1为例说明。**
CPS1基因突变→CPS1蛋白（氨甲酰磷酸合成酶1）缺乏→尿素循环障碍→血氨升高（高氨血症）→神经系统损伤。治疗思路：低蛋白饮食减少氨产生、肝移植替代缺陷酶、或基因编辑修复突变基因。
