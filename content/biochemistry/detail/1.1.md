# 1.1 医学生物化学学习指南：按分子与代谢主题摊开

人卫第 7 版《生物化学》配套学习指南不是另一本教材，而是把教学大纲拆成「掌握 / 熟悉 / 了解」三档，再配上每章必背英文词。本篇不按章目录扫描，而是把同一张账上的分子、代谢、遗传信息重新摊开：先问这门课在医学里站哪一层，再问蛋白质与核酸如何当信息分子，再问酶如何把反应变成开关，再问 ATP 与三大物质如何在乙酰 $\mathrm{CoA}$ 和三羧酸循环汇合，最后接到复制—转录—翻译、肝与信号。数字只采用学习指南写明的户头：葡萄糖彻底氧化净得 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}/\mathrm{mol}$，不要用口诀 $38$。

:::insight{label="为什么指南要分掌握、熟悉、了解"}
掌握是考试能默写、能比较、能接到临床上的那一档：定义、关键酶、生理意义、典型数字。熟悉是能说清机制和分类、不必逐步默写反应式。了解是背景、技术平台、少见途径。把三档听成「全都背」会爆仓；把掌握听成「只背名词」又会在简答里交白卷。
:::

:::definition{label="生物化学"}
生物化学（biochemistry）是研究生物体内化学分子与化学反应的基础生命科学，从分子水平探讨生命现象的本质。
:::

:::definition{label="分子生物学"}
人们通常把研究核酸、蛋白质等生物大分子的结构、功能及基因结构、表达与调控的内容称为分子生物学（molecular biology）。从广义上理解，它是生物化学的重要组成部分，也被视作生物化学的发展和延续。
:::

:::compare{title="当代生物化学三块研究内容"}
| 板块 | 学什么 | 医学落点 |
|------|--------|----------|
| 生物分子的结构与功能 | 无机物、有机小分子、生物大分子；大分子有信息功能，也称生物信息分子 | 结构是功能的基础；功能靠分子识别与相互作用实现 |
| 物质代谢及其调节 | 新陈代谢；正常代谢是正常生命过程的必要条件 | 代谢紊乱可引起疾病 |
| 基因信息传递及其调控 | $\mathrm{DNA}$ 复制、转录、蛋白质生物合成及表达的时空规律 | 遗传、分化，以及遗传病、恶性肿瘤、心血管病等发病机制 |
:::

:::keypoint{label="基因表达调控指南点名的三个方面"}
- 信号转导研究
- 转录因子研究
- $\mathrm{RNA}$ 剪辑研究
:::

:::pitfall{label="不要把分子生物学写成生物化学的门外学科"}
指南明确：分子生物学是生物化学的重要组成部分。把两门课听成互不隶属，后面中心法则、重组 $\mathrm{DNA}$、信号转导都会没有户头。人类基因组计划（human genome project, $\mathrm{HGP}$）是绪论要求掌握的英文词，不是选修阅读。
:::

## 一、蛋白质：从含氮量到四级结构

蛋白质是由多种氨基酸通过肽键联系起来的高分子含氮化合物，体内分布广、含量高，是生物体重要组成成分。元素组成的考试钥匙不是「含哪些元素」，而是**大多数蛋白质含氮量很接近，平均为 $16\%$**：测生物样品含氮量即可推算蛋白质大约含量。

:::definition{label="组成人体蛋白质的氨基酸"}
组成人体蛋白质的基本单位是氨基酸。组成人体蛋白质的氨基酸仅有 $20$ 种，且均属 $\mathrm{L}$-$\alpha$-氨基酸（除甘氨酸外）。含有氨基及羧基的有机化合物都可以叫做氨基酸，但并不都进入这 $20$ 种编码名单。
:::

:::definition{label="氨基酸等电点"}
在某一 $\mathrm{pH}$ 的溶液中，氨基酸解离成阳离子和阴离子的趋势及程度相等，成为兼性离子，呈电中性，此时溶液的 $\mathrm{pH}$ 称为该氨基酸的等电点（$\mathrm{pI}$）。
:::

:::compare{title="肽键、肽链、肽三户不要并"}
| 名词 | 指南落点 |
|------|----------|
| 肽键 | 氨基酸的 $\alpha$-羧基与相邻另一氨基酸的 $\alpha$-氨基脱水缩合起来的键 |
| 肽链 | 仅仅指一种结构，而不是化合物 |
| 肽 | 氨基酸通过肽键缩合形成的化合物，具有一定功能；二肽、三肽、多肽按氨基酸数目分 |
:::

生物活性肽以谷胱甘肽（glutathione, $\mathrm{GSH}$）为掌握代表。氨基酸分类按侧链结构和理化性质：非极性脂肪族、极性中性、芳香族、酸性、碱性。理化性质三条：两性解离；含共轭双键者有紫外吸收；与茚三酮反应生成蓝紫色化合物。

:::definition{label="蛋白质一级结构"}
蛋白质分子中，从 $\mathrm{N}$-端至 $\mathrm{C}$-端的氨基酸排列顺序称为蛋白质的一级结构。主要化学键是肽键，有些蛋白质还包括二硫键。
:::

:::definition{label="蛋白质二级结构"}
蛋白质分子中某一段肽链的局部的、往往具有一定规律的空间结构，也就是该肽链主链骨架原子的相对空间位置（不涉及 $\mathrm{R}$ 基团构象）。基本形式：$\alpha$ 螺旋、$\beta$-片层、$\beta$-转角、无规卷曲。维持二级结构的化学键主要是氢键。
:::

:::definition{label="蛋白质三级结构"}
整条肽链中全部氨基酸残基的相对空间位置，也就是整条肽链所有原子在三维空间的排布位置。稳定力主要靠疏水键、盐键、氢键和 Van der Waals 力。分子量较大的蛋白质常可折叠成多个结构较为紧密、各行其功能的区域，称为结构域（domain）。
:::

:::definition{label="蛋白质四级结构"}
含 $2$ 条或 $2$ 条以上多肽链才能全面执行功能时，每条多肽链都有其完整的三级结构，称为亚基（subunit）。各个亚基的空间排布及亚基接触部位的布局和相互作用，称为四级结构。亚基间结合力主要是氢键和离子键。
:::

:::keypoint{label="结构与功能：一级是基础，空间决定能否干活"}
- 一级结构是空间构象的基础；一级结构相似的蛋白质具有相似的高级结构与功能。
- 氨基酸序列提供生物进化信息；重要蛋白质氨基酸序列改变可引起疾病（分子病）。
- 功能依赖特定空间结构。血红蛋白是掌握例：协同效应指一个亚基与配体（$\mathrm{Hb}$ 结合 $\mathrm{O}_2$）结合后，能影响此寡聚体中另一亚基与配体的结合能力；促进作用为正协同，反之为负协同。
- 变构效应：蛋白质与配体（或其他蛋白质）结合后构象变化，使它更适合于功能需要。
:::

:::definition{label="蛋白质变性"}
在某些物理和化学因素作用下，蛋白质特定的空间构象被破坏，即有序的空间结构变成无序的空间结构，从而导致其理化性质的改变和生物活性的丧失。变性主要发生二硫键和非共价键的破坏，**不涉及一级结构中氨基酸序列的改变**。变性因素常被用来消毒灭菌；防止变性是保存疫苗等蛋白质制剂的必要条件。程度较轻、去除变性因素后仍可恢复或部分恢复原有构象和功能，称为复性。
:::

:::compare{title="蛋白质理化性质考试分户"}
| 性质 | 掌握/熟悉点 |
|------|-------------|
| 两性电离与等电点 | 净电荷等于零时溶液的 $\mathrm{pH}$ 为该蛋白质 $\mathrm{pI}$，可用来分离蛋白质 |
| 胶体 | 水化膜和表面电荷是维持胶体稳定的两个重要因素 |
| 紫外 | $280\,\mathrm{nm}$ 处有特征性吸收峰 |
| 呈色 | 茚三酮反应、双缩脲反应可测含量 |
| 分离纯化 | 透析及超滤；丙酮沉淀、盐析及免疫沉淀；电泳；层析；超速离心 |
:::

:::pitfall{label="变性不是水解，沉淀也不等于变性"}
变性破的是空间构象，一级序列还在。把变性写成肽键断裂，后面复性、消毒灭菌、疫苗保存都会讲反。沉淀可以是去除水化膜或表面电荷后的胶体破坏，变性者易沉淀，沉淀者不一定变性。
:::

:::memory{label="蛋白质掌握清单"}
- [ ] 平均含氮量 $16\%$，用来推算蛋白含量
- [ ] $20$ 种编码氨基酸，均为 $\mathrm{L}$-$\alpha$-氨基酸（甘氨酸除外）
- [ ] $\mathrm{pI}$：兼性离子、净电荷为零时的 $\mathrm{pH}$
- [ ] 一级肽键（可含二硫键）；二级氢键；三级疏水键/盐键/氢键/Van der Waals；四级氢键和离子键
- [ ] 二级四种：$\alpha$ 螺旋、$\beta$-片层、$\beta$-转角、无规卷曲
- [ ] 变性不改氨基酸序列；复性是可逆或部分可逆
- [ ] $\mathrm{Hb}$ 正协同与变构是空间结构决定功能的例
:::

## 二、核酸：信息分子的化学

核酸分 $\mathrm{DNA}$ 和 $\mathrm{RNA}$。核苷酸是基本组成单位：嘌呤碱为腺嘌呤、鸟嘌呤；嘧啶碱为胞嘧啶、尿嘧啶、胸腺嘧啶。构成 $\mathrm{RNA}$ 的戊糖是 $\beta$-$\mathrm{D}$-核糖，构成 $\mathrm{DNA}$ 的是 $\beta$-$\mathrm{D}$-$2'$-脱氧核糖。核苷由戊糖 $\mathrm{C}$-$1'$-$\mathrm{OH}$ 与嘌呤 $\mathrm{N}$-$9$ 或嘧啶 $\mathrm{N}$-$1$ 脱水缩合。生物体内游离核苷酸主要是 $5'$-核苷酸。组成 $\mathrm{RNA}$ 的是 $\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$、$\mathrm{UMP}$；组成 $\mathrm{DNA}$ 的是 $\mathrm{dAMP}$、$\mathrm{dGMP}$、$\mathrm{dCMP}$、$\mathrm{dTMP}$。

:::definition{label="核酸一级结构"}
多核苷酸链中核苷酸的排列顺序（或碱基排列顺序）。相邻核苷酸之间形成 $3',5'$-磷酸二酯键；链的走向为 $5'$-端 $\rightarrow$ $3'$-端。
:::

:::definition{label="DNA 双螺旋结构模型要点"}
$\mathrm{DNA}$ 是反向平行、右手螺旋的双链结构。两链间碱基严格按 $\mathrm{A}$-$\mathrm{T}$（两对氢键）、$\mathrm{G}$-$\mathrm{C}$（三对氢键）配对。疏水作用力和氢键共同维持双螺旋稳定。
:::

高级结构是超螺旋：绝大部分原核生物 $\mathrm{DNA}$ 是共价封闭的环状双螺旋；真核 $\mathrm{DNA}$ 以染色体形式存在于细胞核内，染色体的基本单位是核小体。$\mathrm{DNA}$ 是遗传的物质基础，遗传信息以基因的形式存在。基因是 $\mathrm{DNA}$ 中的特定区段；基因组是一个生物体的全部遗传信息，即 $\mathrm{DNA}$ 的全部核苷酸序列。

:::compare{title="三类 RNA 的考试落点"}
| 种类 | 结构要点 | 功能 |
|------|----------|------|
| $\mathrm{mRNA}$ | 真核由编码区和非编码区构成；$5'$-端 $\mathrm{m}^{7}\mathrm{GpppN}$ 帽子；$3'$-端 $80\sim 250$ 个腺苷酸的 $\mathrm{poly}(\mathrm{A})$ 尾；成熟过程是 $\mathrm{hnRNA}$ 的剪接 | 翻译的直接模板 |
| $\mathrm{tRNA}$ | 多种稀有碱基；二级三叶草、三级倒 $\mathrm{L}$；$3'$-末端 $\mathrm{CCA}$，氨基酸酯连在 $\mathrm{A}$ 上；反密码子识别密码子 | 氨基酸的活化与转运 |
| $\mathrm{rRNA}$ | 与核糖体蛋白共同构成核糖体 | 蛋白质生物合成的场所 |
:::

:::definition{label="核酶"}
具有催化作用的小 $\mathrm{RNA}$ 亦被称为核酶（ribozyme）。酶「对其特异底物起高效催化作用的蛋白质和核糖核酸」这一句，核酶就是核糖核酸那一半。
:::

:::definition{label="DNA 变性、Tm、复性与杂交"}
某些理化因素会导致 $\mathrm{DNA}$ 双链互补碱基对之间的氢键断裂，使双链解离为单链，称为 $\mathrm{DNA}$ 变性。变性只改变二级结构，不改变核苷酸序列。解链过程中紫外吸光度变化 $\Delta A_{260}$ 达到最大变化值一半时所对应的温度称为解链温度或融解温度（$T_\mathrm{m}$）。$T_\mathrm{m}$ 与 $\mathrm{DNA}$ 长短以及碱基 $\mathrm{GC}$ 含量相关。变性条件缓慢除去后，互补链重新配对恢复双螺旋，称为复性；热变性后缓慢冷却复性称为退火。不同来源的单链只要存在一定程度碱基配对，可形成杂化双链，称为核酸分子杂交。核酸最大吸收在 $260\,\mathrm{nm}$ 附近。
:::

:::pitfall{label="蛋白质变性与 DNA 变性不要并户"}
蛋白质变性破的是空间构象（二硫键和非共价键），一级氨基酸序列仍在。$\mathrm{DNA}$ 变性破的是碱基对氢键，核苷酸序列仍在。两者都「不改一级序列」，但监测指标不同：蛋白看活性和溶解度，$\mathrm{DNA}$ 看 $A_{260}$ 增色效应和 $T_\mathrm{m}$。
:::

:::memory{label="核酸掌握清单"}
- [ ] 游离核苷酸多为 $5'$-核苷酸；$3',5'$-磷酸二酯键；$5'\rightarrow 3'$
- [ ] $\mathrm{DNA}$：$\mathrm{A}/\mathrm{G}/\mathrm{C}/\mathrm{T}$ + 脱氧核糖；$\mathrm{RNA}$：$\mathrm{A}/\mathrm{G}/\mathrm{C}/\mathrm{U}$ + 核糖
- [ ] $\mathrm{A}$-$\mathrm{T}$ 两对氢键，$\mathrm{G}$-$\mathrm{C}$ 三对氢键；反向平行右手螺旋
- [ ] 真核 $\mathrm{mRNA}$：帽、$\mathrm{poly}(\mathrm{A})$、剪接；$\mathrm{tRNA}$：三叶草 / 倒 $\mathrm{L}$ / $\mathrm{CCA}$
- [ ] $T_\mathrm{m}$ 与 $\mathrm{GC}$ 含量正相关；紫外 $260\,\mathrm{nm}$
- [ ] 核酶是有催化作用的 $\mathrm{RNA}$
:::

## 三、酶：把反应变成可调节的开关

:::definition{label="酶"}
酶（enzyme）是对其特异底物起高效催化作用的蛋白质和核糖核酸，前者是机体内催化各种代谢反应最主要的催化剂。
:::

:::definition{label="全酶、酶蛋白、辅酶与辅基"}
全酶是结合酶的酶蛋白和辅助因子结合后形成的复合物。辅酶与蛋白质结合较疏松；辅基与酶蛋白结合较牢固，不能用透析或超滤除去。酶促反应的特异性及高效率取决于酶蛋白；辅助因子起传递电子、原子或某些化学基团的作用。
:::

:::definition{label="活性中心与必需基团"}
与酶活性有关的必需基团在一级结构上可能相距很远，但在空间结构上彼此靠近，组成具有特定空间结构的区域，能和底物特异结合并将底物转化为产物，这个区域叫做酶的活性中心。辅酶或辅基参与活性中心组成。必需基团包括活性中心内的结合基团、催化基团，以及活性中心以外、维持构象或作为调节剂结合部位所必需的基团。
:::

:::definition{label="同工酶"}
催化相同化学反应，但酶蛋白的分子结构、理化性质乃至免疫学性质不同的一组酶。由不同基因或等位基因编码，或由同一基因不同 $\mathrm{mRNA}$ 翻译的不同多肽链组成。乳酸脱氢酶同工酶的种类、分布、功能及临床意义是熟悉档。
:::

酶促反应特点：极高的催化效率；高度的特异性（绝对、相对、立体异构）；可调节性。动力学研究反应速率及其影响因素：酶浓度、底物浓度、$\mathrm{pH}$、温度、抑制剂、激活剂。

:::definition{label="米氏常数 Km"}
米氏方程

$$
v = \frac{V_{\max}[S]}{K_\mathrm{m}+[S]}
$$

$K_\mathrm{m}$ 值等于酶促反应速率为最大速率一半时的底物浓度。
:::

:::definition{label="酶的抑制剂"}
凡能使酶催化活性下降而不引起酶蛋白变性的物质统称酶的抑制剂。不可逆性抑制：抑制剂与酶的必需基团以共价键结合，不能用透析、超滤除去。可逆性抑制：非共价结合，可用透析等除去。
:::

:::compare{title="三种可逆抑制的动力学"}
| 类型 | 结合对象 | $K_\mathrm{m}$ | $V_{\max}$ |
|------|----------|----------------|------------|
| 竞争性抑制 | 与底物竞争活性中心 | 增大 | 不变 |
| 非竞争性抑制 | 活性中心外必需基团；$\mathrm{ESI}$ 不能出产物 | 不变 | 降低 |
| 反竞争性抑制 | 只与 $\mathrm{ES}$ 结合成 $\mathrm{EIS}$，不与游离酶结合 | 降低 | 降低 |
:::

:::definition{label="变构调节"}
一些代谢物与关键酶分子活性中心外的某个部位可逆地结合，使酶发生变构而改变其催化活性。该结合部位称为变构部位或调节部位；受变构调节的酶称作变构酶或别构酶；导致变构效应的代谢物称作变构效应剂。
:::

:::definition{label="共价修饰"}
有些酶，尤其是一些限速酶，在其它酶的作用下，酶蛋白肽链上的一些基团可与某种化学基团发生可逆的共价结合，从而改变酶活性。最常见的是磷酸化修饰。
:::

:::definition{label="酶原激活"}
无活性的酶的前身称为酶原。酶原在一定条件下转化成有活性的酶：分子内肽键一处或多处断裂，构象改变，形成或暴露活性中心。消化管内蛋白酶以酶原形式分泌，既保护消化器官本身，又保证酶在特定部位发挥作用；酶原也是酶的贮存形式。
:::

:::pitfall{label="抑制剂不是变性剂"}
抑制剂降低催化活性但不引起酶蛋白变性。把重金属、强酸写成「竞争性抑制」，或把煮沸灭菌写成「不可逆抑制」，户头就错了。竞争性抑制的经典例子在熟悉档，动力学标志是 $K_\mathrm{m}$ 增大、$V_{\max}$ 不变。
:::

:::memory{label="酶掌握清单"}
- [ ] 酶主要是蛋白质，核酶是例外
- [ ] 特异性取决于酶蛋白；辅酶/辅基传递基团
- [ ] 活性中心 = 空间上靠近的必需基团
- [ ] $K_\mathrm{m}$ = $\frac{1}{2}V_{\max}$ 时的 $[S]$
- [ ] 竞争：$K_\mathrm{m}\uparrow$、$V_{\max}$ 不变；非竞争：$K_\mathrm{m}$ 不变、$V_{\max}\downarrow$；反竞争：两者都降
- [ ] 变构快调节、磷酸化共价修饰、酶原激活、酶含量慢调节
- [ ] 同工酶：同反应，不同结构/理化/免疫
:::

## 四、能量账：呼吸链只承认 30 或 32

:::definition{label="生物氧化"}
物质在生物体内进行氧化分解的过程。特点：反应条件温和；能量逐步释放；以脱氢为主，脱下的氢与氧结合生成水；$\mathrm{CO}_2$ 以有机酸脱羧形式产生。
:::

:::definition{label="呼吸链"}
线粒体内膜上由递氢体和递电子体按序排列的、能将代谢物脱下的氢传递给氧生成水的氧化还原体系。由四种能传递电子的酶与辅酶复合体组成。
:::

:::compare{title="两条氧化呼吸链"}
| 呼吸链 | 复合体组成 |
|--------|------------|
| $\mathrm{NADH}$ 氧化呼吸链 | 复合体 $\mathrm{I}$、$\mathrm{III}$、$\mathrm{IV}$ |
| 琥珀酸氧化呼吸链 | 复合体 $\mathrm{II}$、$\mathrm{III}$、$\mathrm{IV}$ |
:::

:::definition{label="氧化磷酸化"}
呼吸链电子传递过程中偶联的 $\mathrm{ADP}$ 磷酸化生成 $\mathrm{ATP}$ 的过程，是 $\mathrm{ATP}$ 生成的主要方式，又称偶联磷酸化。三个偶联部位：$\mathrm{NADH}\rightarrow\mathrm{CoQ}$，$\mathrm{CoQ}\rightarrow\mathrm{Cyt}\,c$，$\mathrm{Cyt}\,aa_3\rightarrow\mathrm{O}_2$。
:::

生物体内能量的储存和利用都以 $\mathrm{ATP}$ 为中心；磷酸肌酸是肌肉和脑组织中能量的一种储存形式。胞液 $\mathrm{NADH}$ 进入线粒体氧化靠两种穿梭：$\alpha$-磷酸甘油穿梭、苹果酸-天冬氨酸穿梭。正是穿梭不同，才有下面这句掌握句：

:::keypoint{label="葡萄糖有氧氧化的 ATP 数字"}
$1\,\mathrm{mol}$ 葡萄糖彻底氧化可净生成 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$。学习指南写的是这个户头。口诀 $38$ 不在本指南账上，考试不要默写。
:::

:::pitfall{label="不要发明指南没有的 ATP 口诀"}
有氧氧化净得只写 $30$ 或 $32$。脂酸 $\beta$-氧化指南要求掌握「每轮生成 $1$ 分子乙酰 $\mathrm{CoA}$、$\mathrm{FADH}_2$ 和 $\mathrm{NADH}+\mathrm{H}^{+}$ 及少了两个碳原子的脂酰 $\mathrm{CoA}$」，没有给出软脂酸净 $\mathrm{ATP}$ 的口诀数字，本篇不补 $129$ 或其它口诀。
:::

抑制剂三档要分开：呼吸链抑制剂阻断电子传递；解偶联剂使氧化与磷酸化脱离；氧化磷酸化抑制剂对电子传递及 $\mathrm{ADP}$ 磷酸化均有抑制。$\mathrm{ADP}$ 浓度升高加快氧化磷酸化；甲状腺素促进 $\mathrm{ATP}$ 分解为 $\mathrm{ADP}$ 和 $\mathrm{Pi}$，间接加快氧化磷酸化。不生成 $\mathrm{ATP}$ 的氧化体系包括抗氧化酶（$\mathrm{SOD}$、过氧化氢酶、过氧化物酶）和微粒体加单氧酶。

:::memory{label="生物氧化掌握清单"}
- [ ] 呼吸链在线粒体内膜；$\mathrm{NADH}$ 链走 $\mathrm{I}$-$\mathrm{III}$-$\mathrm{IV}$，琥珀酸链走 $\mathrm{II}$-$\mathrm{III}$-$\mathrm{IV}$
- [ ] 氧化磷酸化三个偶联部位
- [ ] 能量中心是 $\mathrm{ATP}$；磷酸肌酸是肌和脑的储存形式
- [ ] 胞液 $\mathrm{NADH}$ 靠两种穿梭进线粒体
- [ ] 葡萄糖彻底氧化净 $30$ 或 $32\,\mathrm{ATP}$，不是 $38$
:::

## 五、糖、脂、氨基酸在乙酰 CoA 汇合

糖的主要生理功能是氧化供能，也是机体重要碳源和组织结构成分。吸收后的葡萄糖可走无氧分解、有氧氧化、磷酸戊糖途径或聚合成糖原；非糖物质可异生为葡萄糖或糖原。

:::definition{label="糖酵解（第 7 版指南用语）"}
在缺氧情况下，葡萄糖生成乳酸的过程称为糖酵解，在胞浆中进行。第一阶段称糖酵解途径：由 $1$ 分子葡萄糖分解成 $2$ 分子丙酮酸；第二阶段丙酮酸转变成乳酸。
:::

:::compare{title="糖代谢三条产能/供氢账"}
| 途径 | 部位 | 关键掌握点 |
|------|------|------------|
| 糖酵解途径 | 胞浆 | 三步不可逆：己糖激酶、$6$-磷酸果糖激酶-$1$、丙酮酸激酶；底物水平磷酸化在磷酸甘油酸激酶和丙酮酸激酶；$\mathrm{NADH}$ 来自 $3$-磷酸甘油醛脱氢酶 |
| 有氧氧化 | 胞浆 + 线粒体 | 酵解途径 → 丙酮酸氧化脱羧 → 三羧酸循环 + 氧化磷酸化；净 $30$ 或 $32\,\mathrm{ATP}$ |
| 磷酸戊糖途径 | 胞浆 | 提供核糖和 $\mathrm{NADPH}$；$6$-磷酸葡萄糖脱氢酶受 $\mathrm{NADPH}/\mathrm{NADP}^{+}$ 调节 |
:::

:::definition{label="三羧酸循环"}
以形成柠檬酸为起始物的循环反应系统。掌握概念、线粒体定位、三个不可逆反应、脱氢部位、底物水平磷酸化部位及生理意义。乙酰 $\mathrm{CoA}$ 与草酰乙酸缩合成柠檬酸，经反复脱氢、脱羧再生成草酰乙酸。
:::

:::definition{label="糖原"}
动物体内糖的储存形式。肝和肌是储存的主要组织器官。肌糖原主要供肌收缩急需；肝糖原是血糖的重要来源。合成关键酶是糖原合酶；肝糖原分解关键酶是糖原磷酸化酶。肌糖原分解与肝糖原不同：肌不能把葡萄糖释放入血。
:::

:::definition{label="糖异生"}
非糖化合物转变为葡萄糖或糖原的过程。原料为乳酸、甘油、生糖氨基酸等。基本上沿糖酵解途径逆行，但须绕过三步不可逆反应，分别由丙酮酸羧化酶、磷酸烯醇式丙酮酸羧激酶、果糖双磷酸酶-$1$、葡萄糖-$6$-磷酸酶催化。生理意义：维持血糖浓度恒定；补充肝糖原；调节酸碱平衡。肌中乳酸运至肝异生，形成乳酸循环。
:::

:::keypoint{label="血糖调节两把钥匙"}
掌握血糖概念、空腹水平、来源与去路。胰岛素降低血糖；胰高血糖素升高血糖。高血糖、糖尿、低血糖的危害在熟悉/掌握档。巴斯德效应：糖有氧氧化抑制糖酵解。
:::

脂类不溶于水而易溶于有机溶剂，并能被机体利用，分为脂肪（甘油三酯）和类脂（胆固醇及其酯、磷脂、糖脂）。脂肪主职储存能量及氧化供能；类脂构成膜、参与识别与信息传递、作生理活性物质前体。营养必需脂酸是动物自身不能合成、需从食物摄取的不饱和脂酸。

:::definition{label="脂肪动员"}
储存在脂肪细胞中的甘油三酯被脂肪酶逐步水解为游离脂酸和甘油并释放入血，运输至其他组织氧化利用。激素敏感性甘油三酯脂酶是掌握概念。游离脂酸在血中与清蛋白结合运输。甘油走糖代谢途径。
:::

:::keypoint{label="脂酸 β-氧化四步与限速"}
脂酸在胞液活化为脂酰 $\mathrm{CoA}$（消耗 $2$ 个高能磷酸键），经肉碱脂酰转移酶 $\mathrm{I}$、$\mathrm{II}$ 及转位酶进入线粒体。肉碱脂酰转移酶 $\mathrm{I}$ 是 $\beta$-氧化限速酶。四步：脱氢、加水、再脱氢、硫解。肝是人体合成脂酸的主要场所，在胞液进行；乙酰 $\mathrm{CoA}$ 经柠檬酸-丙酮酸循环出线粒体；乙酰 $\mathrm{CoA}$ 羧化酶是脂酸合成关键酶。
:::

:::definition{label="酮体"}
乙酰乙酸、$\beta$-羟丁酸和丙酮三者统称酮体。原料是肝细胞线粒体 $\beta$-氧化生成的大量乙酰 $\mathrm{CoA}$，合成部位为肝细胞线粒体。意义：肝输出能量的一种形式；糖供应不足或利用障碍时可代替葡萄糖成为脑及肌肉的主要能源。生成过多可致酮血症、酮尿症及酮症酸中毒。
:::

胆固醇合成原料为乙酰 $\mathrm{CoA}$、$\mathrm{NADPH}+\mathrm{H}^{+}$ 和 $\mathrm{ATP}$，关键酶 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶。人体胆固醇可转化成胆汁酸、类固醇激素及维生素 $\mathrm{D}_3$。血浆脂蛋白电泳法分乳糜微粒、$\beta$-脂蛋白、前 $\beta$-脂蛋白及 $\alpha$-脂蛋白；超速离心法分 $\mathrm{CM}$、$\mathrm{VLDL}$、$\mathrm{LDL}$、$\mathrm{HDL}$。

氨基酸侧，成人 $8$ 种营养必需氨基酸：赖氨酸、色氨酸、蛋（甲硫）氨酸、苏氨酸、缬氨酸、亮氨酸、异亮氨酸、苯丙氨酸。蛋白质营养价值取决于必需氨基酸的种类和数量；不同蛋白质混合食用可互补。

:::definition{label="氨基酸代谢库"}
分布于体内各处、参与代谢的所有游离氨基酸的总称。来源：食物、组织蛋白质分解、体内合成的非必需氨基酸。去路：合成组织蛋白质、分解代谢、参与其他含氮化合物的合成。
:::

:::keypoint{label="脱氨基、血氨与尿素"}
体内主要脱氨基途径是联合脱氨基。转氨基除赖、苏、脯及羟脯氨酸外大多数氨基酸都可参加；最重要的转氨酶是 $\mathrm{ALT}$ 和 $\mathrm{AST}$，辅酶为磷酸吡哆醛/磷酸吡哆胺。血氨来源：氨基酸脱氨基、肠道吸收、肾小管上皮分泌。转运：丙氨酸-葡萄糖循环（肌→肝）、谷氨酰胺（脑和肌→肝和肾）。主要去路是肝内合成尿素。注意体内催化氨基甲酰磷酸生成的酶有两种，要比较。
:::

:::definition{label="一碳单位"}
某些氨基酸分解代谢过程中产生的含有一个碳原子的基团，包括甲基、甲烯基、甲炔基、甲酰基及亚氨甲基。运载体是四氢叶酸。主要参与嘌呤、嘧啶的合成。$\mathrm{SAM}$（$S$-腺苷甲硫氨酸）是体内最重要的甲基供体。
:::

:::definition{label="嘌呤核苷酸从头合成"}
利用磷酸核糖、氨基酸、一碳单位及 $\mathrm{CO}_2$ 等简单物质为原料，经过一系列酶促反应合成嘌呤核苷酸。主要在肝，其次小肠黏膜及胸腺的胞浆。特点：在 $5'$-磷酸核糖分子上逐步加上小分子合成。关键酶：$\mathrm{PRPP}$ 合成酶、$\mathrm{PRPP}$ 酰胺转移酶。补救合成主要在脑、骨髓。人体嘌呤分解终产物是尿酸。嘧啶从头合成先成环再与 $\mathrm{PRPP}$ 成 $\mathrm{UMP}$，关键酶氨甲酰磷酸合成酶 $\mathrm{II}$。脱氧核糖核苷酸在 $\mathrm{NDP}$ 水平由核糖核苷酸还原酶催化生成。抗代谢物掌握 $6$-$\mathrm{MP}$、熟悉 $5$-$\mathrm{FU}$。
:::

:::compare{title="三大营养素互相转变的硬边界"}
| 方向 | 指南结论 |
|------|----------|
| 糖 → 脂肪 | 可以：提供乙酰 $\mathrm{CoA}$、$\mathrm{NADPH}$ |
| 偶数脂酸 → 糖 | 不能：$\beta$-氧化产生的乙酰 $\mathrm{CoA}$ 不能生成丙酮酸；只有甘油可异生成糖 |
| 糖 ↔ 大部分氨基酸碳架 | 大部分生糖氨基酸的 $\alpha$-酮酸可成糖；糖代谢中间体只能合成非必需氨基酸碳架 |
| 脂 → 氨基酸 | 不能（甘油例外） |
| 蛋白质营养 | 不能被糖、脂替代；蛋白质却能替代糖和脂肪供能 |
:::

:::compare{title="器官代谢特色（掌握/熟悉）"}
| 器官 | 特色 |
|------|------|
| 肝 | 物质代谢枢纽，人体中心生化工厂 |
| 心 | 有氧氧化为主；酮体、乳酸、脂酸及葡萄糖都可用 |
| 脑 | 静息耗 $\mathrm{O}_2$ 可占全身 $20\%$；几乎以葡萄糖为唯一供能物质 |
| 肌 | 通常氧化脂酸为主；强烈运动产大量乳酸 |
| 成熟红细胞 | 无线粒体，能量主要来自糖酵解 |
| 肾 | 可进行糖异生和生成酮体 |
:::

$\mathrm{NADPH}$ 提供合成代谢所需还原当量；磷酸戊糖途径产生的 $\mathrm{NADPH}$ 为脂酸、胆固醇等合成提供还原当量。分解代谢脱氢酶常以 $\mathrm{NAD}^{+}$ 为辅酶，还原性合成多用 $\mathrm{NADPH}$。代谢调节：细胞水平改关键酶活性（变构、化学修饰、酶含量）；激素经膜受体或胞内受体；整体经神经—体液。化学修饰主要形式是磷酸化与脱磷酸。

:::memory{label="三大物质与枢纽掌握清单"}
- [ ] 糖酵解三关键酶；有氧氧化净 $30$ 或 $32\,\mathrm{ATP}$
- [ ] 磷酸戊糖：核糖 + $\mathrm{NADPH}$
- [ ] 糖原合酶 vs 磷酸化酶；肝糖原补血糖，肌糖原不补
- [ ] 糖异生四酶绕过三步不可逆；乳酸循环
- [ ] $\beta$-氧化限速酶是肉碱脂酰转移酶 $\mathrm{I}$；酮体肝内生成、过多致酮症
- [ ] 胆固醇关键酶 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶
- [ ] 成人 $8$ 种必需氨基酸；联合脱氨基；尿素在肝
- [ ] 一碳单位载体是 $\mathrm{FH}_4$；$\mathrm{SAM}$ 是活性甲基
- [ ] 偶数脂酸不能成糖；嘌呤终产物尿酸
- [ ] 脑几乎只用葡萄糖；红细胞只靠酵解
:::

## 六、遗传信息流：复制、转录、翻译、调控

:::definition{label="复制"}
遗传物质的传代，以母链 $\mathrm{DNA}$ 为模板合成子链 $\mathrm{DNA}$ 的过程。
:::

:::definition{label="半保留复制"}
母链 $\mathrm{DNA}$ 解开为两股单链，各自作为模板按碱基配对合成互补子链。子代 $\mathrm{DNA}$ 一股单链从亲代完整接受，另一股完全重新合成，两个子细胞的 $\mathrm{DNA}$ 都和亲代碱基序列一致。
:::

:::definition{label="半不连续复制"}
子链合成延伸方向是 $5'\rightarrow 3'$。顺着解链方向连续生成的子链称为领头链；与解链方向相反、不连续复制的称为随从链。不连续片段称为冈崎片段。
:::

复制需要 $4$ 种 $\mathrm{dNTP}$、模板、$\mathrm{RNA}$ 引物、$\mathrm{DNA}$ 聚合酶、解螺旋酶、引物酶、拓扑异构酶、连接酶等。原核 $\mathrm{DNA}$-$\mathrm{pol}\,\mathrm{III}$ 是延长中真正起催化作用的酶；$\mathrm{DNA}$-$\mathrm{pol}\,\mathrm{I}$ 主职校读、填补空隙。连接酶连接一链 $3'$-$\mathrm{OH}$ 与另一链 $5'$-$\mathrm{P}$，生成磷酸二酯键。

:::definition{label="逆转录"}
信息流动方向（$\mathrm{RNA}\rightarrow\mathrm{DNA}$）与转录（$\mathrm{DNA}\rightarrow\mathrm{RNA}$）相反，是一种特殊的复制方式。催化以 $\mathrm{RNA}$ 为模板合成双链 $\mathrm{DNA}$ 的酶称为逆转录酶（依赖 $\mathrm{RNA}$ 的 $\mathrm{DNA}$ 聚合酶）。逆转录的发现发展了中心法则。
:::

$\mathrm{DNA}$ 突变即损伤：错配（点突变）、缺失、插入、重排；缺失或插入可导致框移突变。修复掌握切除修复：去除损伤、填补空隙、连接。

:::definition{label="转录"}
以 $\mathrm{DNA}$ 为模板合成 $\mathrm{RNA}$ 的过程。
:::

:::definition{label="启动子"}
$\mathrm{RNA}$ 聚合酶在转录起始上游的结合序列。
:::

:::definition{label="翻译 / 蛋白质的生物合成"}
由 $\mathrm{mRNA}$ 碱基序列所组成的密码指导蛋白质生物合成的过程：细胞内以 $\mathrm{mRNA}$ 为模板，按照核苷酸组成的密码信息合成蛋白质。
:::

:::definition{label="基因表达"}
基因转录及翻译的过程。
:::

:::compare{title="顺式元件、反式因子、操纵子"}
| 名词 | 指南落点 |
|------|----------|
| 顺式作用元件 | 可影响自身基因表达活性的真核 $\mathrm{DNA}$ 序列 |
| 反式作用因子 | 可通过与特异顺式作用元件相互作用、反式调节另一基因转录的蛋白质因子（部分考卷写作「反式作用元件」，化学本质仍是蛋白质） |
| 操纵子 | 原核生物的基本转录单位，由结构基因加上其上游的启动子和操纵基因构成 |
:::

:::definition{label="质粒与 DNA 克隆"}
质粒是存在于细菌染色体外的小型环状双链 $\mathrm{DNA}$ 分子。$\mathrm{DNA}$ 克隆：应用酶学方法，在体外将各种来源的遗传物质与载体 $\mathrm{DNA}$ 接合成具有自我复制功能的复制子，经转化或转染宿主，筛选含目的基因的转化子再扩增，获得大量同一 $\mathrm{DNA}$ 分子，也称基因克隆或重组 $\mathrm{DNA}$。
:::

:::definition{label="信号转导与第二信使"}
信号转导是细胞针对外源信息所发生的细胞内生物化学变化及效应的全过程。第二信使包括 $\mathrm{cAMP}$、$\mathrm{cGMP}$、$\mathrm{DAG}$、$\mathrm{IP}_3$、$\mathrm{Ca}^{2+}$、$\mathrm{NO}$、$\mathrm{CO}$、$\mathrm{H}_2\mathrm{S}$ 等在细胞内传递信息的小分子化合物。
:::

:::definition{label="癌基因"}
基因组内存在的正常基因，其表达产物多为正调控信号，促进细胞生长增殖，编码生长因子、生长因子受体、细胞内信号转导分子、与生长有关的转录调节因子。
:::

## 七、接到临床上的几张账

:::definition{label="生物转化"}
非营养物质在体内进行代谢转变，使其水溶性提高、极性增强，易于通过胆汁或尿液排出体外的过程。肝是最重要的生物转化器官。
:::

:::definition{label="胆色素"}
体内铁卟啉化合物分解代谢的主要产物，包括胆绿素、胆红素、胆素原和胆素。
:::

维生素本身不是组织砖块也不是主要供能物质，但多种 B 族维生素是辅酶前体：丙酮酸脱氢酶复合体需要 $\mathrm{TPP}$、硫辛酸、$\mathrm{CoA}$、$\mathrm{FAD}$、$\mathrm{NAD}^{+}$，把糖有氧氧化和维生素账焊在一起。叶酸相关的 $\mathrm{FH}_4$ 运一碳单位；维生素 $\mathrm{B}_{12}$ 是 $N^5$-甲基四氢叶酸转甲基酶的辅酶，不足可致巨幼红细胞性贫血。

:::keypoint{label="抗代谢物两例"}
- $6$-巯基嘌呤干扰嘌呤核苷酸合成。
- $5$-氟尿嘧啶干扰嘧啶核苷酸代谢（$\mathrm{dUMP}\rightarrow\mathrm{TMP}$ 这一步是掌握点）。
痛风与尿酸、别嘌呤醇抑制黄嘌呤氧化酶，在熟悉档。
:::
