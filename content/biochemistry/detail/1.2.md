# 1.2 名词解释：往年名解按代谢与分子主题摊开

名词解释是医学生化卷面上最稳定的题型。本篇合并两份常考名解源：`名解.txt` 与往年试题《名词解释》。每个词先给可默写的定义，再用一张记忆卡把易漏构件挖出来。表述以名解原文为准，不另造口诀数字；糖酵解名解写「胞质中裂解为两分子丙酮酸」，与学习指南把「缺氧生成乳酸」叫糖酵解的用语并户时，见文中易错点。

:::insight{label="名解怎么写才像采分点"}
阅卷看的是构件是否齐全：部位、原料、产物、生理意义，缺一块就扣一块。三羧酸循环要写出「乙酰 $\mathrm{CoA}$ + 草酰乙酸 → 柠檬酸」和「再生成草酰乙酸」；酮体要列出三成员并点出「肝内生成」；生物转化要写出「水溶性提高、极性增强、易经胆汁或尿排出」。背「大概是什么循环」拿不满。
:::

## 一、蛋白质与酶

:::definition{label="氨基酸等电点"}
在某一 $\mathrm{pH}$ 溶液中，氨基酸解离成阴离子和阳离子的趋势和程度相等，成为兼性离子，呈电中性，此时溶液的 $\mathrm{pH}$ 为氨基酸等电点。
:::

:::memory{label="氨基酸等电点" mode="cloze"}
兼性离子、净电荷为零时的 **pH** 才叫 $\mathrm{pI}$，不是「中性氨基酸的 $\mathrm{pH}=7$」。
:::

:::definition{label="蛋白质的一级结构"}
从 $\mathrm{N}$ 端到 $\mathrm{C}$ 端的氨基酸排列顺序，包括二硫键的位置。
:::

:::memory{label="蛋白质一级结构" mode="cloze"}
一级结构 = **N 端到 C 端**顺序 + **二硫键位置**；主要化学键是肽键。
:::

:::definition{label="蛋白质的三级结构"}
整条肽链中全部氨基酸残基的相对空间位置，也就是所有原子在三维空间的排布位置，是在二级结构的基础上进一步卷曲、折叠形成的状态。
:::

:::memory{label="蛋白质三级结构" mode="cloze"}
三级看的是 **整条肽链全部原子** 的三维排布，不是某一局部主链，也还不是亚基与亚基的排布。
:::

:::definition{label="蛋白质变性"}
在某些理化因素作用下，蛋白质空间结构改变，从而使其理化性质和生物学活性改变的过程。
:::

:::memory{label="蛋白质变性" mode="cloze"}
破的是 **空间结构**，不改氨基酸序列；活性丧失、理化性质改变。消毒灭菌用变性，疫苗保存要防变性。
:::

:::definition{label="酶的活性中心"}
酶分子中能与底物特异性结合并催化底物转变为产物的具有特定三维结构的区域。
:::

:::memory{label="酶的活性中心" mode="cloze"}
活性中心是 **三维结构区域**：既要特异结合，又要催化转变。结合基团和催化基团都在这里会合。
:::

:::definition{label="同工酶"}
催化相同反应，但是酶的结构、理化性质乃至免疫学性质都不同的一组酶。
:::

:::memory{label="同工酶" mode="cloze"}
同工酶：**同反应，不同结构 / 理化 / 免疫**。乳酸脱氢酶同工酶是临床常用例，不要写成「同一个酶分子」。
:::

:::pitfall{label="一级结构漏写二硫键"}
名解原文把二硫键位置算进一级结构。只答「$\mathrm{N}\rightarrow\mathrm{C}$ 氨基酸顺序」会丢构件。三级结构不要写成「局部主链构象」——那是二级。
:::

## 二、糖、脂、氨基酸代谢

:::definition{label="糖酵解"}
一分子葡萄糖在胞质中裂解为两分子丙酮酸的过程，是葡萄糖有氧氧化和无氧氧化的共同起始途径。
:::

:::memory{label="糖酵解" mode="cloze"}
部位在 **胞质**；产物是两分子 **丙酮酸**；它是有氧、无氧的 **共同起始**，不等于一定生成乳酸。
:::

:::definition{label="糖异生"}
由非糖物质转变为葡萄糖或糖原的过程。
:::

:::memory{label="糖异生" mode="cloze"}
原料是乳酸、甘油、生糖氨基酸等 **非糖物质**；产物是 **葡萄糖或糖原**。要绕过酵解三步不可逆。
:::

:::definition{label="三羧酸循环"}
由乙酰 $\mathrm{CoA}$ 与草酰乙酸缩合成柠檬酸开始，经反复脱氢、脱羧再生成草酰乙酸的循环反应过程。
:::

:::memory{label="三羧酸循环" mode="cloze"}
起始缩合：**乙酰 CoA + 草酰乙酸 → 柠檬酸**；中间反复 **脱氢、脱羧**；终点再生成 **草酰乙酸**。
:::

:::definition{label="脂肪动员"}
储存在脂肪细胞中的甘油三酯，被脂解酶逐步水解为游离脂酸及甘油并释放入血液，通过血液运输至其他组织氧化利用的过程。
:::

:::memory{label="脂肪动员" mode="cloze"}
对象是脂肪细胞里的 **甘油三酯**；产物是 **游离脂酸 + 甘油**；必须 **入血运到其他组织** 才叫动员。
:::

:::definition{label="酮体"}
包括乙酰乙酸、$\beta$-羟丁酸和丙酮，是脂酸在肝细胞 $\beta$-氧化时产生的特有中间产物，经血液运输至肝外组织氧化利用，是肝向肝外输出能量的一种方式。
:::

:::memory{label="酮体三成员与肝外利用" mode="cloze"}
三成员：**乙酰乙酸、β-羟丁酸、丙酮**。生成在 **肝细胞线粒体**，利用在 **肝外**。过多致酮血症 / 酮尿 / 酮症酸中毒。
:::

:::definition{label="必需脂酸"}
维持人体正常功能所必需的，体内不能合成而需由食物供给的多不饱和脂酸，包括亚油酸、$\alpha$-亚麻酸、花生四烯酸。
:::

:::memory{label="必需脂酸三名" mode="cloze"}
名单写全：**亚油酸、α-亚麻酸、花生四烯酸**。关键词是体内不能合成、必须食物供给。
:::

:::definition{label="必需氨基酸"}
体内需要又不能合成的、必须由食物供给的氨基酸。成人八种：赖氨酸、色氨酸、蛋（甲硫）氨酸、苏氨酸、缬氨酸、亮氨酸、异亮氨酸、苯丙氨酸。
:::

:::memory{label="成人八种必需氨基酸" mode="cloze"}
口诀构件来自学习指南：**赖、色、甲硫、苏、缬、亮、异亮、苯丙**。不要把「营养价值高」写成定义本身。
:::

:::definition{label="一碳单位"}
在某些氨基酸分解代谢中产生的含有一个碳原子的有机基团。
:::

:::memory{label="一碳单位" mode="cloze"}
来源是 **某些氨基酸分解**；本质是含 **一个碳原子** 的基团（甲基、甲烯基、甲炔基、甲酰基、亚氨甲基）。载体是 **四氢叶酸**。
:::

:::compare{title="糖酵解名解与第 7 版指南用语"}
| 来源 | 糖酵解指什么 |
|------|----------------|
| 本篇名解 | 一分子葡萄糖在胞质裂解为两分子丙酮酸；有氧、无氧共同起始 |
| 学习指南（第 7 版） | 缺氧下葡萄糖生成乳酸的过程叫糖酵解；「糖酵解途径」才是葡萄糖 → $2$ 丙酮酸 |
:::

:::pitfall{label="酮体漏成员或写成肝内利用"}
三成员少写丙酮、或把 $\beta$-羟丁酸写成 $\gamma$-羟丁酸，都是常见扣分。肝有生成酮体的酶系，缺乏利用酮体的酶系，所以是「肝内生成、肝外利用」，不能写成肝自己把酮体氧化供能。
:::

:::pitfall{label="偶数脂酸不要偷偷写进糖异生原料"}
糖异生原料是乳酸、甘油、生糖氨基酸。乙酰 $\mathrm{CoA}$ 不能净生成丙酮酸，偶数碳脂酸不能转变为葡萄糖。把「脂肪」笼统写成糖异生原料，会和 $1.4$ 的硬边界冲突。
:::

## 三、生物氧化与核苷酸

:::definition{label="呼吸链"}
在线粒体内膜上由递氢体或递电子体组成的按序排列的、能将 $\mathrm{NADH}+\mathrm{H}^{+}$ 和 $\mathrm{FADH}_2$ 的氢传递给氧生成水并释放能量的氧化还原体系。
:::

:::memory{label="呼吸链" mode="cloze"}
部位：**线粒体内膜**。成员：按序的 **递氢体 / 递电子体**。任务：把 **NADH 和 FADH₂** 的氢交给氧生成水。
:::

:::definition{label="氧化磷酸化"}
代谢物脱下的氢，经线粒体氧化呼吸链电子传递释放能量，偶联驱动 $\mathrm{ADP}$ 磷酸化成 $\mathrm{ATP}$ 的过程，又称偶联磷酸化。
:::

:::memory{label="氧化磷酸化" mode="cloze"}
氧化（电子传递释能）**偶联**磷酸化（$\mathrm{ADP}\rightarrow\mathrm{ATP}$）。不要写成底物水平磷酸化，也不要漏「偶联」。
:::

:::definition{label="嘌呤核苷酸的从头合成途径"}
以磷酸核糖、甘氨酸、天冬氨酸、谷氨酰胺、一碳单位及 $\mathrm{CO}_2$ 等简单物质为原料，经过多步酶促反应合成嘌呤核苷酸的过程。
:::

:::memory{label="嘌呤从头合成原料" mode="cloze"}
原料要写得出：**磷酸核糖、Gly、Asp、Gln、一碳单位、CO₂**。特点是在核糖上装配嘌呤环。补救合成不是从头。
:::

:::keypoint{label="氧化磷酸化与底物水平磷酸化先分户"}
氧化磷酸化必须经过呼吸链。底物水平磷酸化是底物高能键直接转移给 $\mathrm{ADP}$，如糖酵解的磷酸甘油酸激酶、丙酮酸激酶，以及三羧酸循环中的底物水平磷酸化部位。名解问氧化磷酸化时不要把这两本账并成一句「都能生成 $\mathrm{ATP}$」。
:::

## 四、遗传信息：复制、转录、翻译、调控

:::definition{label="基因组"}
一个生物体内所有遗传信息的总和。
:::

:::memory{label="基因组" mode="cloze"}
基因组 = 该生物 **全部遗传信息**，分子意义上是全部 $\mathrm{DNA}$ 序列（$\mathrm{RNA}$ 病毒基因组例外，名解本条按 $\mathrm{DNA}$ 生物体答）。
:::

:::definition{label="基因家族"}
来源相同、结构相似、功能相关的一组基因。
:::

:::memory{label="基因家族" mode="cloze"}
三个构件：**来源相同、结构相似、功能相关**。不要写成「一个基因的全部碱基」。
:::

:::definition{label="癌基因"}
基因组内存在的正常基因，其表达产物多为正调控信号，促进细胞生长增殖，编码生长因子 / 生长因子受体 / 细胞内信号转导分子 / 与生长有关的转录调节因子。
:::

:::memory{label="癌基因" mode="cloze"}
先是基因组内的 **正常基因**（细胞癌基因 / 原癌基因），产物是 **促生长的正调控信号**，不是「外来的病毒毒素」一句就能代替。
:::

:::definition{label="半保留复制"}
$\mathrm{DNA}$ 复制时，解开的双链各自作为模板，用以合成新的互补链。在子代 $\mathrm{DNA}$ 中，一股链来自亲代，另一股是新合成的，这种复制方式称为半保留复制。
:::

:::memory{label="半保留复制" mode="cloze"}
子代每一分子 $\mathrm{DNA}$：**一股亲代 + 一股新链**。不是「把亲代双链完整留给一个子细胞」。
:::

:::definition{label="启动子"}
$\mathrm{DNA}$ 上能够介导 $\mathrm{RNA}$ 聚合酶结合并形成转录起始复合体的序列。大多数在转录起始上游，不能转录。
:::

:::memory{label="启动子" mode="cloze"}
启动子是 **DNA 序列**，多数在起始 **上游**，本身 **不转录**。不要写成蛋白质，也不要写成操纵子的全部。
:::

:::definition{label="转录"}
以 $\mathrm{DNA}$ 为模板合成 $\mathrm{RNA}$ 的过程。
:::

:::memory{label="转录" mode="cloze"}
模板是 **DNA**，产物是 **RNA**。逆转录方向相反，不能并进这一句。
:::

:::definition{label="逆转录"}
以 $\mathrm{RNA}$ 为模板，按照 $\mathrm{RNA}$ 中核苷酸顺序合成 $\mathrm{DNA}$，这与通常转录过程中遗传信息从 $\mathrm{DNA}$ 到 $\mathrm{RNA}$ 的方向相反，称为逆转录。
:::

:::memory{label="逆转录" mode="cloze"}
模板 **RNA** → 产物 **DNA**；发现它发展了中心法则。酶是逆转录酶（依赖 RNA 的 DNA 聚合酶）。
:::

:::definition{label="翻译"}
由 $\mathrm{mRNA}$ 碱基序列所组成的密码指导蛋白质生物合成的过程。
:::

:::memory{label="翻译" mode="cloze"}
模板是 **mRNA**，读的是 **遗传密码**，产物是 **蛋白质**。
:::

:::definition{label="蛋白质的生物合成"}
即翻译：细胞内以 $\mathrm{mRNA}$ 为模板，按照 $\mathrm{mRNA}$ 中核苷酸组成的密码信息合成蛋白质的过程。
:::

:::memory{label="蛋白质的生物合成" mode="cloze"}
与翻译同一本账： **mRNA 模板 + 密码信息 → 蛋白质**。不要把复制写进定义。
:::

:::definition{label="基因表达"}
基因转录及翻译的过程。
:::

:::memory{label="基因表达" mode="cloze"}
表达 = **转录 + 翻译**。只答转录或只答「基因打开」构件不全。
:::

:::definition{label="顺式作用元件"}
可影响自身基因表达活性的真核 $\mathrm{DNA}$ 序列。
:::

:::memory{label="顺式作用元件" mode="cloze"}
化学本质是 **DNA 序列**，作用对象是 **自身基因**。启动子、增强子、沉默子都落在这一类。
:::

:::definition{label="反式作用因子"}
一类可通过与特异的顺式作用元件相互作用，反式调节另一基因转录的蛋白质因子。部分考卷写作「反式作用元件」，采分点仍是蛋白质因子。
:::

:::memory{label="反式作用因子" mode="cloze"}
化学本质是 **蛋白质**（转录因子），作用方式是结合 **顺式元件** 去调节 **另一基因**。
:::

:::definition{label="操纵子"}
原核生物的基本转录单位，它由结构基因加上其上游的启动子和操纵基因构成。
:::

:::memory{label="操纵子" mode="cloze"}
原核基本转录单位 = **结构基因 + 启动子 + 操纵基因**（调控序列还可含其他调节元件）。真核不这样整包。
:::

:::definition{label="质粒"}
存在于细菌染色体外的小型环状双链 $\mathrm{DNA}$ 分子。
:::

:::memory{label="质粒" mode="cloze"}
位置在 **染色体外**；形态是 **小型环状双链 DNA**。基因工程常用作载体。
:::

:::definition{label="DNA 克隆"}
应用酶学方法，在体外将各种来源的遗传物质与载体 $\mathrm{DNA}$ 接合成一具有自我复制功能的 $\mathrm{DNA}$ 分子——复制子，继而通过转化或转染宿主细胞，筛选出含有目的基因的转化子细胞，再进行扩增，提取获得大量同一 $\mathrm{DNA}$ 分子，也称基因克隆或重组 $\mathrm{DNA}$。
:::

:::memory{label="DNA 克隆步骤构件" mode="cloze"}
体外接成 **复制子** → **转化 / 转染** → 筛 **转化子** → **扩增提取**。也叫基因克隆或重组 DNA。
:::

:::definition{label="DNA 变性"}
在某些理化作用下，$\mathrm{DNA}$ 双链互补碱基对之间的氢键断裂，使 $\mathrm{DNA}$ 双链解开为两条单链的过程。
:::

:::memory{label="DNA 变性" mode="cloze"}
断的是碱基对 **氢键**，双链 → 两条单链； **不改变核苷酸序列**。监测常用 $A_{260}$ 增色和 $T_\mathrm{m}$。
:::

:::compare{title="元件是 DNA，因子是蛋白质"}
| 名词 | 化学本质 | 作用方式 |
|------|----------|----------|
| 顺式作用元件 | $\mathrm{DNA}$ 序列 | 影响自身基因表达 |
| 反式作用因子 | 蛋白质 | 结合顺式元件，调节另一基因 |
| 启动子 | $\mathrm{DNA}$ 序列 | 介导 $\mathrm{RNA}$ 聚合酶结合，多数不转录 |
| 操纵子 | 原核 $\mathrm{DNA}$ 功能单位 | 结构基因 + 上游调控序列 |
:::

:::pitfall{label="顺式 / 反式写反是名解高频错"}
元件（element）落在 $\mathrm{DNA}$ 上，因子（factor）落在蛋白质上。把反式作用因子答成「一段 $\mathrm{DNA}$」，或把启动子答成转录因子，整题容易零分。考卷若印刷成「反式作用元件」而定义写的是蛋白质因子，按蛋白质因子答。
:::

## 五、信号、肝与胆色素

:::definition{label="信号转导"}
细胞针对外源信息所发生的细胞内生物化学变化及效应的全过程。
:::

:::memory{label="信号转导" mode="cloze"}
从 **外源信息** 到细胞内的 **生化变化及效应**，全过程都算。不要只答「来了个第二信使」。
:::

:::definition{label="第二信使"}
$\mathrm{cAMP}$、$\mathrm{cGMP}$、$\mathrm{DAG}$、$\mathrm{IP}_3$、$\mathrm{Ca}^{2+}$、$\mathrm{NO}$、$\mathrm{CO}$、$\mathrm{H}_2\mathrm{S}$ 等在细胞内传递信息的小分子化合物。
:::

:::memory{label="第二信使名单" mode="cloze"}
小分子名单要能默：**cAMP、cGMP、DAG、IP₃、Ca²⁺、NO、CO、H₂S**。激素本身是第一信使，不要把胰岛素写进第二信使。
:::

:::definition{label="生物转化"}
非营养物质在体内进行代谢转变，使其水溶性提高，极性增强，易于通过胆汁或尿液排出体外的过程。
:::

:::memory{label="生物转化" mode="cloze"}
对象是 **非营养物质**；目的是 **水溶性↑、极性↑**，经 **胆汁或尿** 排出。不等于「一定解毒」——有时反而活化毒性。
:::

:::definition{label="胆色素"}
体内铁卟啉化合物分解代谢的主要产物，包括胆绿素、胆红素、胆素原和胆素。
:::

:::memory{label="胆色素四成员" mode="cloze"}
来源是 **铁卟啉分解**；成员：**胆绿素、胆红素、胆素原、胆素**。不要把胆汁酸写进胆色素。
:::

:::pitfall{label="生物转化不等于解毒"}
定义的核心是极性、水溶性、易排泄，不是「把毒物变成无毒物」。有的物质经转化后毒性增强。胆色素与胆汁酸是两本账：前者来自铁卟啉，后者来自胆固醇。
:::
