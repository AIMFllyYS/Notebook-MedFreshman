# 1.4 三大物质代谢知识模块：乙酰 CoA 与三羧酸循环如何当枢纽

糖、脂、氨基酸不是三本互不往来的账。学习指南第九章把它们写成：同时进行、相互转变、共一个代谢池；乙酰 $\mathrm{CoA}$ 是共同中间代谢物；三羧酸循环和氧化磷酸化是最后分解的共同途径；释放的能量都以 $\mathrm{ATP}$ 形式储存。本篇用三张总图把舱室、枢纽和器官特色摊开。$\mathrm{ATP}$ 数字只采用指南写明的葡萄糖净 $30$ 或 $32$，不补软脂酸口诀。

:::insight{label="先分舱，再找交叉点"}
看总图不要从左上角挨个酶扫。先问反应在胞质还是线粒体：糖酵解、磷酸戊糖、脂酸合成在胞质；$\beta$-氧化、三羧酸循环、氧化磷酸化、酮体生成在线粒体。交叉点只有少数几个：葡萄糖-6-磷酸、磷酸二羟丙酮、丙酮酸、乙酰 $\mathrm{CoA}$、$\alpha$-酮戊二酸、草酰乙酸。把交叉点记熟，转变方向才不会写反。
:::

## 一、总图：胞质、膜间隙与线粒体基质

::figure{src="/images/biochemistry/detail/metabolism-1.jpg" caption="图 1　三大物质代谢总图。胞质基质走糖酵解、磷酸戊糖、糖原、脂酸合成与尿素循环外围；线粒体基质走三羧酸循环、β-氧化、酮体生成；内膜上呼吸链与肉碱穿梭把两舱焊住。" alt="三大物质代谢总图：胞质糖酵解与磷酸戊糖，线粒体三羧酸循环与β-氧化，尿素循环与呼吸链"}

图 1 把学习指南里分散在第四至第七章的途径画进同一张舱室。上缘是葡萄糖、糖原、甘油三酯、磷脂、胆固醇；中部粉红色「三羧酸循环」落在线粒体基质；右侧「线粒体膜间隙」标出酮体和脂酰肉碱穿梭；下缘氨基酸汇入 $\alpha$-酮酸，再接到尿素循环。胞质 $\mathrm{NADH}$ 不能直接进线粒体，要靠穿梭，这正是葡萄糖彻底氧化净得 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$ 而不是单一数字的原因。

:::definition{label="共同代谢池"}
同一代谢物无论体外摄入还是体内产生，进行中间代谢时不分彼此，混为一体，参与到共同的代谢池中。乙酰 $\mathrm{CoA}$、丙酮酸、葡萄糖-6-磷酸都是这种池里的枢纽分子。
:::

:::keypoint{label="图 1 上必须先锁的舱室"}
- 胞质：糖酵解、磷酸戊糖、糖原合成与分解的起始、脂酸合成、尿素循环的部分反应。
- 线粒体基质：丙酮酸氧化脱羧、三羧酸循环、$\beta$-氧化、酮体生成、氧化磷酸化的基质侧底物。
- 内膜：呼吸链复合体、肉碱脂酰转移酶系统、$\mathrm{ATP}$ 合酶。
- 糖异生是跨舱的：丙酮酸羧化在线粒体，后续关键酶回到胞质，肝（和肾）才能把非糖物质变成葡萄糖。
:::

:::pitfall{label="不要把糖酵解画进线粒体"}
糖酵解途径在胞浆。丙酮酸有氧时才进线粒体氧化脱羧成乙酰 $\mathrm{CoA}$。把己糖激酶画到基质里，后面「成熟红细胞无线粒体仍能酵解供能」就讲不通。
:::

## 二、联系图：糖、脂、氨基酸如何互相接

::figure{src="/images/biochemistry/detail/metabolism-2.jpg" caption="图 2　三大物质代谢联系图。左侧糖酵解 / 糖异生与磷酸戊糖；中上脂肪动员与甘油三酯；中下三羧酸循环与酮体；右侧联合脱氨基、氨的转运与鸟氨酸循环。红线把丙酮酸和乙酰 CoA 焊成枢纽。" alt="三大物质代谢联系图：糖酵解糖异生、脂肪动员β-氧化酮体、联合脱氨基与尿素循环"}

图 2 比图 1 更强调「箭头方向」。左侧垂直轴是糖酵解向下、糖异生向上，中间经过磷酸烯醇式丙酮酸（$\mathrm{PEP}$）和丙酮酸。脂侧：脂肪动员给出甘油和脂酸；脂酸活化、$\beta$-氧化四步（脱氢、加水、再脱氢、硫解）汇入乙酰 $\mathrm{CoA}$；两分子乙酰 $\mathrm{CoA}$ 可经 $\mathrm{HMG}$-$\mathrm{CoA}$ 生成酮体。氨基酸侧：转氨基得到 $\alpha$-酮酸，联合脱氨基放出 $\mathrm{NH}_3$，经丙氨酸或谷氨酰胺转运，在肝走鸟氨酸循环成尿素。

:::definition{label="ATP 是产能与耗能的偶联分子"}
营养物质产生的能量均储存在 $\mathrm{ATP}$ 中。$\mathrm{ATP}$ 作为能量载体，使产能的分解代谢与耗能的合成代谢相互偶联。指南掌握句：$\mathrm{ATP}$ 是生物体内的主要供能方式。
:::

:::definition{label="NADPH 提供合成所需还原当量"}
参与氧化分解的脱氢酶常以 $\mathrm{NAD}^{+}$ 为辅酶；参与还原性合成的还原酶多以 $\mathrm{NADPH}$ 为辅酶。磷酸戊糖途径产生的 $\mathrm{NADPH}$ 为脂酸、胆固醇等合成提供还原当量。
:::

:::compare{title="糖、脂、蛋白质互相转变（指南硬边界）"}
| 方向 | 能不能 | 理由（按学习指南） |
|------|--------|--------------------|
| 糖 → 脂肪 | 能 | 糖代谢提供乙酰 $\mathrm{CoA}$ 和 $\mathrm{NADPH}$ |
| 偶数碳脂酸 → 糖 | 不能 | $\beta$-氧化产生的乙酰 $\mathrm{CoA}$ 不能生成丙酮酸 |
| 甘油 → 糖 | 能 | 甘油成磷酸甘油，再异生成糖 |
| 大部分氨基酸碳架 ↔ 糖 | 能（生糖氨基酸） | $\alpha$-酮酸可成糖；糖中间体只能合成非必需氨基酸碳架 |
| 脂 → 氨基酸 | 不能（甘油例外） | 缺少从乙酰 $\mathrm{CoA}$ 净合成 $\alpha$-酮酸再氨基化的通路 |
| 蛋白质供能替代糖脂 | 能 | 氨基酸可氧化；但蛋白质营养不能被糖、脂替代 |
:::

:::pitfall{label="减肥只停主食却猛吃脂肪，指南怎么解释"}
指南点名：脂肪分解代谢的强度及顺利进行有赖于糖代谢正常进行。糖不足时乙酰 $\mathrm{CoA}$ 不能顺利进入三羧酸循环（草酰乙酸来源不足），酮体生成增加。偶数脂酸又不能净转变成糖，所以「完全不吃碳水只吃脂肪」会把图 2 的红线枢纽堵在酮体那一侧。
:::

## 三、TCA 枢纽：哪些分子能进循环，哪些能出循环

::figure{src="/images/biochemistry/detail/tca-hub.jpg" caption="图 3　三羧酸循环作为三大物质枢纽。葡萄糖经 6-磷酸葡萄糖、磷酸丙糖到丙酮酸和乙酰辅酶 A；脂酸 β-氧化、生酮氨基酸汇入乙酰辅酶 A；生糖氨基酸从丙酮酸、α-酮戊二酸、琥珀酸、延胡索酸、草酰乙酸进入。偶数脂酸到乙酰辅酶 A 后不能箭头向上变成糖。" alt="三羧酸循环枢纽图：糖、脂酸、氨基酸汇入乙酰辅酶A和循环中间物"}

图 3 是名解「三羧酸循环」的图解版：乙酰 $\mathrm{CoA}$ 与草酰乙酸缩合成柠檬酸，经 $\alpha$-酮戊二酸、琥珀酸、延胡索酸回到草酰乙酸，两处标出 $\mathrm{CO}_2$。读这张图时按「进口」分类，比背全部反应式更接近考试。

:::definition{label="三羧酸循环（枢纽版）"}
由乙酰 $\mathrm{CoA}$ 与草酰乙酸缩合成柠檬酸开始，经反复脱氢、脱羧再生成草酰乙酸的循环反应过程。亚细胞定位在线粒体。生理意义：彻底氧化乙酰 $\mathrm{CoA}$；为其他合成提供中间产物；与氧化磷酸化偶联生成 $\mathrm{ATP}$。
:::

:::compare{title="图 3 上的进口分类"}
| 进口 | 谁能进来 | 能不能再变成葡萄糖 |
|------|----------|--------------------|
| 丙酮酸 | 糖酵解；丙氨酸、色氨酸、丝氨酸、甘氨酸、苏氨酸、半胱氨酸 | 能（羧化成草酰乙酸后异生） |
| 乙酰 $\mathrm{CoA}$ | 丙酮酸氧化脱羧；脂酸 $\beta$-氧化；酮体利用；亮氨酸、赖氨酸（生酮） | 偶数脂酸来的乙酰 $\mathrm{CoA}$ 不能净成糖 |
| $\alpha$-酮戊二酸 | 谷氨酸、谷氨酰胺；精氨酸、组氨酸、脯氨酸 | 能（经草酰乙酸异生） |
| 琥珀酰 $\mathrm{CoA}$ / 琥珀酸 | 缬氨酸、甲硫氨酸、异亮氨酸、苏氨酸；血红素相关 | 能 |
| 延胡索酸 | 酪氨酸、苯丙氨酸 | 能 |
| 草酰乙酸 | 天冬氨酸 | 能 |
:::

:::keypoint{label="生糖、生酮、生糖兼生酮"}
指南掌握：$\alpha$-酮酸可氧化供能、生成非必需氨基酸、转变成糖和脂类。名解与学习指南都把亮氨酸、赖氨酸写成典型生酮氨基酸——图 3 把它们画在乙酰 $\mathrm{CoA}$ 旁。其余多数氨基酸是生糖或兼生酮。写「所有氨基酸都能成糖」是错的。
:::

:::pitfall{label="乙酰 CoA 进了 TCA 不等于脂酸能成糖"}
循环每转一圈进来的两个碳又以两分子 $\mathrm{CO}_2$ 出去，没有净增加草酰乙酸。所以脂酸 $\beta$-氧化生成的乙酰 $\mathrm{CoA}$ 不能净转变成糖。图 3 从乙酰辅酶 $\mathrm{A}$ 指向胆固醇、酮体、嘌呤、血红素是合成去路，不是糖异生去路。
:::

## 四、糖模块：三关键酶、四异生酶、两条 NADPH 账

:::definition{label="糖酵解途径"}
$1$ 分子葡萄糖分解成 $2$ 分子丙酮酸的过程，在胞浆进行。三步不可逆、三个关键酶：己糖激酶（肝为葡萄糖激酶）、$6$-磷酸果糖激酶-$1$、丙酮酸激酶。底物水平磷酸化：磷酸甘油酸激酶、丙酮酸激酶。$\mathrm{NADH}$ 来自 $3$-磷酸甘油醛脱氢酶。
:::

:::compare{title="有氧氧化三阶段与指南 ATP"}
| 阶段 | 部位 | 掌握点 |
|------|------|--------|
| 糖酵解途径 | 胞浆 | 葡萄糖 → $2$ 丙酮酸 |
| 丙酮酸氧化脱羧 | 线粒体 | 丙酮酸脱氢酶复合体 |
| 三羧酸循环 + 氧化磷酸化 | 线粒体 | $1\,\mathrm{mol}$ 葡萄糖彻底氧化净生成 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$ |
:::

:::definition{label="磷酸戊糖途径"}
在胞浆进行。生理意义：为核酸合成提供核糖；提供 $\mathrm{NADPH}$ 作为供氢体，参与合成反应、羟化反应、维持谷胱甘肽还原状态。关键调节：$6$-磷酸葡萄糖脱氢酶主要受 $\mathrm{NADPH}/\mathrm{NADP}^{+}$ 比值调节。
:::

:::compare{title="糖原两组织不要并户"}
| | 肝糖原 | 肌糖原 |
|--|--------|--------|
| 合成关键酶 | 糖原合酶 | 糖原合酶 |
| 分解关键酶 | 糖原磷酸化酶 | 糖原磷酸化酶 |
| 生理意义 | 血糖的重要来源 | 主要供肌收缩急需 |
| 能否直接补血糖 | 能（有葡萄糖-6-磷酸酶） | 不能 |
:::

:::definition{label="糖异生四酶"}
绕过酵解三步不可逆：丙酮酸羧化酶、磷酸烯醇式丙酮酸羧激酶、果糖双磷酸酶-$1$、葡萄糖-$6$-磷酸酶。原料：乳酸、甘油、生糖氨基酸。生理意义：维持血糖恒定；补充肝糖原；调节酸碱平衡。肌乳酸运至肝异生，形成乳酸循环。
:::

:::memory{label="糖模块必背"}
- [ ] 三关键酶：己糖激酶 / 葡萄糖激酶、$\mathrm{PFK}$-$1$、丙酮酸激酶
- [ ] 有氧氧化净 $30$ 或 $32\,\mathrm{ATP}$，不是口诀 $38$
- [ ] 磷酸戊糖：核糖 + $\mathrm{NADPH}$，不主职产能
- [ ] 肝糖原补血糖，肌糖原不补
- [ ] 糖异生四酶；乳酸循环耗能、保证乳酸再利用
- [ ] 胰岛素降血糖，胰高血糖素升血糖
:::

## 五、脂模块：动员、β-氧化、酮体、胆固醇、脂蛋白

:::definition{label="脂肪动员"}
储存在脂肪细胞中的甘油三酯被脂解酶逐步水解为游离脂酸及甘油并释放入血，运输至其他组织氧化利用。游离脂酸与清蛋白结合运输。甘油走糖代谢。
:::

:::keypoint{label="β-氧化四步与限速酶"}
胞液活化为脂酰 $\mathrm{CoA}$（消耗 $2$ 个高能磷酸键）→ 肉碱系统进线粒体 → 脱氢、加水、再脱氢、硫解。肉碱脂酰转移酶 $\mathrm{I}$ 是限速酶。每轮少两个碳，生成 $1$ 乙酰 $\mathrm{CoA}$、$1\,\mathrm{FADH}_2$、$1\,\mathrm{NADH}+\mathrm{H}^{+}$。指南未给出软脂酸净 $\mathrm{ATP}$ 口诀，本篇不补。
:::

:::definition{label="酮体"}
乙酰乙酸、$\beta$-羟丁酸和丙酮。原料是肝线粒体 $\beta$-氧化产生的乙酰 $\mathrm{CoA}$。意义：肝向肝外输出能量；糖不足时可代替葡萄糖作为脑和肌的主要能源。过多：酮血症、酮尿症、酮症酸中毒。肝能生成不能利用。
:::

:::compare{title="脂酸合成与分解不要画在同一舱"}
| | 分解（$\beta$-氧化） | 合成（软脂酸） |
|--|-------------------|----------------|
| 部位 | 线粒体 | 胞液（肝是主要场所） |
| 限速 / 关键酶 | 肉碱脂酰转移酶 $\mathrm{I}$ | 乙酰 $\mathrm{CoA}$ 羧化酶 |
| 氢载体 | $\mathrm{NAD}^{+}$、$\mathrm{FAD}$ | $\mathrm{NADPH}$ |
| 乙酰 $\mathrm{CoA}$ 过膜 | 肉碱穿梭（进） | 柠檬酸-丙酮酸循环（出） |
:::

胆固醇合成原料：乙酰 $\mathrm{CoA}$、$\mathrm{NADPH}+\mathrm{H}^{+}$、$\mathrm{ATP}$；关键酶 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶。去路：胆汁酸、类固醇激素、维生素 $\mathrm{D}_3$。血浆脂蛋白超速离心四类：$\mathrm{CM}$ 转运外源性甘油三酯；$\mathrm{VLDL}$ 转运内源性甘油三酯；$\mathrm{LDL}$ 转运胆固醇至外周；$\mathrm{HDL}$ 做胆固醇逆向转运。

:::memory{label="脂模块必背"}
- [ ] 动员：甘油三酯 → $\mathrm{FFA}$ + 甘油，入血
- [ ] $\beta$-氧化四步；限速酶肉碱脂酰转移酶 $\mathrm{I}$
- [ ] 酮体三成员；肝内生成、肝外利用
- [ ] 脂酸合成在胞液，乙酰 $\mathrm{CoA}$ 羧化酶是关键酶
- [ ] 胆固醇关键酶 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶
- [ ] $\mathrm{CM}$、$\mathrm{VLDL}$、$\mathrm{LDL}$、$\mathrm{HDL}$ 四类功能分户
- [ ] 偶数脂酸不能转变成葡萄糖
:::

## 六、氨基酸模块：代谢库、脱氨基、尿素、一碳单位

:::definition{label="氨基酸代谢库"}
分布于体内各处、参与代谢的所有游离氨基酸。来源：食物、组织蛋白分解、合成非必需氨基酸。去路：合成组织蛋白、分解代谢、合成其他含氮化合物。
:::

:::compare{title="脱氨基三本账"}
| 方式 | 要点 |
|------|------|
| 转氨基 | 大多数氨基酸可参加（赖、苏、脯、羟脯除外）；$\mathrm{ALT}$、$\mathrm{AST}$ 最重要；辅酶磷酸吡哆醛 |
| 氧化脱氨基 | 主酶 $\mathrm{L}$-谷氨酸脱氢酶 |
| 联合脱氨基 | 肝、肾：转氨基 + 谷氨酸氧化脱氨基；骨骼肌、心肌：转氨基 + 嘌呤核苷酸循环 |
:::

:::keypoint{label="血氨来源、转运、去路"}
来源：氨基酸脱氨基、肠道吸收、肾小管上皮分泌。转运：丙氨酸-葡萄糖循环（肌→肝）；谷氨酰胺（脑和肌→肝和肾）。去路：肝合成尿素（主要）；铵盐随尿排出；合成谷氨酰胺；合成非必需氨基酸。体内催化氨基甲酰磷酸生成的酶有两种，尿素循环用的是线粒体 $\mathrm{CPS}$-$\mathrm{I}$（需 $N$-乙酰谷氨酸），嘧啶合成用胞液 $\mathrm{CPS}$-$\mathrm{II}$。
:::

:::definition{label="一碳单位"}
某些氨基酸分解产生的含一个碳原子的基团：甲基、甲烯基、甲炔基、甲酰基、亚氨甲基。运载体四氢叶酸。功用：参与嘌呤、嘧啶合成。$\mathrm{SAM}$ 是最重要的甲基供体。
:::

:::memory{label="氨基酸模块必背"}
- [ ] 成人 $8$ 种必需氨基酸：赖、色、甲硫、苏、缬、亮、异亮、苯丙
- [ ] 联合脱氨基是体内主要脱氨基途径
- [ ] $\mathrm{ALT}$、$\mathrm{AST}$ 升高有临床意义
- [ ] 尿素在肝合成；氨的转运靠丙氨酸和谷氨酰胺
- [ ] $\mathrm{CPS}$-$\mathrm{I}$（线粒体，尿素）对 $\mathrm{CPS}$-$\mathrm{II}$（胞液，嘧啶）
- [ ] 一碳单位载体 $\mathrm{FH}_4$；活性甲基 $\mathrm{SAM}$
- [ ] 亮氨酸、赖氨酸是典型生酮氨基酸
:::

## 七、器官特色与调节层次

:::compare{title="器官代谢特色"}
| 器官 | 指南掌握 / 熟悉点 |
|------|-------------------|
| 肝 | 物质代谢枢纽，中心生化工厂；糖异生、酮体生成、尿素合成、生物转化都在此会合 |
| 心 | 有氧氧化为主；酮体、乳酸、脂酸、葡萄糖都可用 |
| 脑 | 静息耗氧可占全身 $20\%$；几乎以葡萄糖为唯一供能物质 |
| 肌 | 通常氧化脂酸；强烈运动产生大量乳酸 |
| 成熟红细胞 | 无线粒体，不能有氧氧化，也不能利用脂酸，能量主要来自糖酵解 |
| 脂肪组织 | 合成并储存脂肪 |
| 肾 | 可进行糖异生和生成酮体；髓质酵解、皮质氧化脂酸及酮体 |
:::

:::compare{title="代谢调节三层"}
| 层次 | 方式 | 速度 |
|------|------|------|
| 细胞 | 关键酶变构；化学修饰（磷酸化 / 脱磷酸）；酶含量（合成与降解） | 变构、修饰快；含量慢 |
| 激素 | 膜受体（肽类、儿茶酚胺）；胞内受体（类固醇、甲状腺素等） | 中 |
| 整体 | 神经—体液；饥饿、应激、肥胖相关 | 适应内外环境 |
:::

:::keypoint{label="关键酶的共同面孔"}
调节酶或关键酶：催化代谢途径中速度最慢的一步，常是不可逆反应，决定整条途径通量。变构：小分子与非催化部位非共价结合改构象。化学修饰：另一组酶催化可逆共价修饰，主要形式磷酸化与脱磷酸。酶系还有亚细胞隔离，这正是图 1 分舱的意义。
:::

:::pitfall{label="脑和红细胞不要写成「也能烧脂酸」"}
脑几乎以葡萄糖为唯一供能（饥饿较久才明显利用酮体，仍不是平时主账）。成熟红细胞无线粒体，脂酸 $\beta$-氧化和三羧酸循环都走不了。心和肾皮质才是「多种能源、有氧为主」的典型。
:::

:::memory{label="三大物质枢纽总卡"}
- [ ] 乙酰 $\mathrm{CoA}$ 是共同中间代谢物；$\mathrm{TCA}$ + 氧化磷酸化是共同末端
- [ ] 糖能成脂，偶数脂酸不能成糖；甘油和生糖氨基酸能成糖
- [ ] $\mathrm{NADH}$ 走分解氧化，$\mathrm{NADPH}$ 走还原合成
- [ ] 葡萄糖净 $30$ 或 $32\,\mathrm{ATP}$；不要默写 $38$
- [ ] 酮体肝内生成肝外用；尿素肝内合成
- [ ] 脑靠葡萄糖，红细胞靠酵解，肝是枢纽
- [ ] 关键酶：变构快、磷酸化快、酶含量慢
:::
