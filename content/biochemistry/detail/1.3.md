# 1.3 专业英语与常考单词：按词族和考卷摊开

英汉互译在临床、八年制、英护、检验卷面上反复出现。本篇只收学习指南各章「要求掌握的英文专业词汇」、小书单词、2018 术语表，以及往年互译真题；不收误放的医学英语试卷。写法是词族推导平铺：先拆词根，再落到中文户头。定义、易错、比较都放在推导块外面，避免指令嵌套。

:::insight{label="互译题怎么拿满"}
往年题不是难词竞赛，而是高频户头：biochemistry、amino acid、enzyme、$K_\mathrm{m}$、plasmid、transcription、translation、glycogen、lipoprotein、$\mathrm{PCR}$、biotransformation、bile pigment、oncogene、cis-acting element。中译英要写得出规范拼写；英译中要落到教材用名，不要把 glycolysis 写成「糖分解」、把 transformation 写成「变形」。
:::

:::definition{label="biochemistry"}
biochemistry，生物化学：研究生物体内化学分子与化学反应的基础生命科学，从分子水平探讨生命现象的本质。绪论与往年互译几乎年年出现。
:::

:::definition{label="glycolysis"}
glycolysis，糖酵解。规范拼写是 glycolysis；个别试卷写作 glucolysis，答卷仍按 glycolysis。不要译成「糖分解」或糖原分解（glycogenolysis）。
:::


## 一、往年互译真题先 Lock 高频

:::derivation{label="07 临床 / 法医 / 影像等互译"}
1. amino acid → 氨基酸
2. $K_\mathrm{m}$ → 米氏常数
3. transformation → 转化
4. glycogen → 糖原
5. plasmid → 质粒
6. 脂蛋白 → lipoprotein
7. 转录 → transcription
8. 生物化学 → biochemistry
9. 基因工程 → genetic engineering
10. 聚合酶链式反应 → polymerase chain reaction（$\mathrm{PCR}$）
:::

:::derivation{label="2004 八年制 A 卷互译"}
1. genome → 基因组
2. active center of enzyme → 酶的活性中心
3. oncogene → 癌基因
4. biotransformation → 生物转化
5. cis-acting element → 顺式作用元件
6. $\mathrm{DNA}$ denaturation → $\mathrm{DNA}$ 变性
7. gene therapy → 基因治疗
8. bile pigment → 胆色素
:::

:::derivation{label="2007 八年制与中德班互译"}
八年制：gene therapy；replication（复制）；蛋白质的三级结构 → tertiary structure of protein；同工酶 → isoenzyme；oncogene；cellular signal transduction（细胞信号转导）。中德班另见：peptide（肽）；酶的活性中心；transcription；secondary messenger（第二信使）；vector（载体）；$\mathrm{DNA}$ denaturation；cis-acting element。
:::

:::derivation{label="08 英护互译十词"}
1. $\mathrm{pI}$ of protein → 蛋白质等电点
2. biotransformation → 生物转化
3. glucolysis / glycolysis → 糖酵解（试卷出现过 glucolysis 拼法，规范词是 glycolysis）
4. reverse transcription → 逆转录
5. $\mathrm{DNA}$ denaturation → $\mathrm{DNA}$ 变性
6. essential amino acids → 必需氨基酸
7. oxidative phosphorylation → 氧化磷酸化
8. trans-acting factor → 反式作用因子
9. gene engineering → 基因工程
10. bile pigment → 胆色素
:::

:::derivation{label="09 五年制 / 检验及散见高频"}
protein（蛋白质）、translation（翻译）、biochemistry、plasmid、replication、氨基酸 → amino acid、葡萄糖 → glucose、核酸 → nucleic acid、酶 → enzyme、基因表达 → gene expression、关键酶 → key enzyme、脂蛋白 → lipoprotein、insulin（胰岛素）、fat（脂肪）。检验卷再加基因工程、$\mathrm{PCR}$、复制。
:::

:::pitfall{label="transformation 不是变形，vector 不是向量"}
生化卷的 transformation 是把外源 $\mathrm{DNA}$ 导入细菌的转化；vector 是克隆载体。glucolysis 是个别试卷拼写，标准英文是 glycolysis。secondary messenger 与 second messenger 都指向第二信使，2018 术语表用 second messenger。
:::

:::compare{title="往年互译最容易写错的几对"}
| 英文 | 应译 | 不要写成 |
|------|------|----------|
| transcription | 转录 | 翻译、复制 |
| translation | 翻译 | 转录、转运 |
| replication | 复制 | 转录 |
| transformation | 转化 | 转染、转导、变形 |
| transfection | 转染 | 转化（真核常用转染） |
| cis-acting element | 顺式作用元件 | 反式作用因子 |
| trans-acting factor | 反式作用因子 | 顺式作用元件 |
| biotransformation | 生物转化 | 生物氧化 |
:::

## 二、大分子词族：蛋白、肽、核酸

:::derivation{label="protein / peptide 词族"}
- protein 蛋白质；biomacromolecule 生物大分子
- amino acid 氨基酸；residue 氨基酸残基（进了肽链就叫残基）
- peptide 肽；peptide bond 肽键；oligopeptide 寡肽；polypeptide 多肽；polypeptide chain 多肽链
- glutathione, $\mathrm{GSH}$ 谷胱甘肽
- conformation 空间构象
- primary / secondary / tertiary / quaternary structure 一 / 二 / 三 / 四级结构
- peptide unit 肽单元；motif 模体；domain 结构域；chaperon 分子伴侣；subunit 亚基
- isoelectric point, $\mathrm{pI}$ 等电点
- denaturation 变性；renaturation 复性
- heme 血红素；proteomics 蛋白质组学
:::

:::derivation{label="nucleic acid 词族"}
- nucleic acid 核酸；nucleotide 核苷酸；nucleoside 核苷；base 碱基
- deoxyribonucleic acid, $\mathrm{DNA}$；ribonucleic acid, $\mathrm{RNA}$
- purine 嘌呤；pyrimidine 嘧啶
- double helix 双螺旋；major groove 大沟；minor groove 小沟；superhelix / supercoil 超螺旋
- base pair, $\mathrm{bp}$ 碱基对
- gene 基因；genome 基因组；nucleosome 核小体；ribosome 核糖体
- messenger $\mathrm{RNA}$, $\mathrm{mRNA}$；transfer $\mathrm{RNA}$, $\mathrm{tRNA}$；ribosomal $\mathrm{RNA}$, $\mathrm{rRNA}$
- heterogeneous nuclear $\mathrm{RNA}$, $\mathrm{hnRNA}$ 不均一核 $\mathrm{RNA}$
- ribozyme 核酶
- melting temperature, $T_\mathrm{m}$ 解链温度 / 融解温度
- annealing 退火；hybridization 核酸分子杂交
- exonuclease 核酸外切酶；endonuclease 核酸内切酶
- ribonuclease, $\mathrm{RNase}$；deoxyribonuclease, $\mathrm{DNase}$
:::

:::keypoint{label="残基、核苷、核苷酸三步不要跳"}
游离氨基酸进肽链后改叫 residue。碱基 + 戊糖 = nucleoside；再加磷酸 = nucleotide。$\mathrm{DNA}$ 与 $\mathrm{RNA}$ 的字母差在胸腺嘧啶 $\mathrm{T}$ / 尿嘧啶 $\mathrm{U}$，戊糖差在 $2'$-脱氧。核酶 ribozyme 是有催化活性的 $\mathrm{RNA}$，不要写成蛋白质酶的别名。
:::

## 三、酶学与维生素词族

:::derivation{label="enzyme 词族"}
- enzyme 酶；biocatalyst 生物催化剂
- holoenzyme 全酶；apoenzyme 酶蛋白
- coenzyme 辅酶；prosthetic group 辅基
- active center 活性中心；essential group 必需基团
- binding group 结合基团；catalytic group 催化基团
- Michaelis constant, $K_\mathrm{m}$ 米氏常数（2018 表误植为 Kichaelis，规范拼写是 Michaelis）
- inhibitor 抑制剂；irreversible / reversible inhibition 不可逆 / 可逆抑制
- competitive / non-competitive / uncompetitive inhibition 竞争 / 非竞争 / 反竞争性抑制
- activator 激活剂；zymogen 酶原；isoenzyme 同工酶
- allosteric enzyme 别构酶；allosteric site 变构部位；allosteric regulation 变构调节
- covalent modification 共价修饰
:::

:::derivation{label="vitamin 作辅酶前体"}
- vitamin 维生素；lipid-soluble / water-soluble vitamin 脂溶 / 水溶性维生素
- thiamine 硫胺素（维生素 $\mathrm{B}_1$）；riboflavin 核黄素（维生素 $\mathrm{B}_2$）
- $\mathrm{FAD}$ 黄素腺嘌呤二核苷酸；$\mathrm{FMN}$ 黄素单核苷酸
- nicotinic acid 尼克酸；$\mathrm{NAD}^{+}$ 烟酰胺腺嘌呤二核苷酸；$\mathrm{NADP}^{+}$ 烟酰胺腺嘌呤二核苷酸磷酸
- biotin 生物素；folic acid 叶酸；ascorbic acid 抗坏血酸；retinol 视黄醇
:::

:::pitfall{label="holoenzyme 与 apoenzyme 写反"}
全酶 holoenzyme = 酶蛋白 + 辅助因子。apoenzyme 只是酶蛋白部分。辅基 prosthetic group 结合牢固，辅酶 coenzyme 结合疏松。$K_\mathrm{m}$ 不要译成「最大速率」。
:::

:::compare{title="glyco- 三个易混动词"}
| 英文 | 中文 | 方向 |
|------|------|------|
| glycolysis | 糖酵解 | 葡萄糖裂解 |
| glycogenesis | 糖原合成 | 葡萄糖 → 糖原 |

:::pitfall{label="glycogenolysis 不要写成糖异生"}
lysis 是裂解，genesis 是生成。gluconeo- 才是「新生成葡萄糖」。$\mathrm{CM}/\mathrm{VLDL}/\mathrm{LDL}/\mathrm{HDL}$ 按密度从低到高记，不要把 $\mathrm{LDL}$ 写成「好胆固醇」的英文名——逆向转运的主角是 $\mathrm{HDL}$。
:::

## 六、留学生重点里的英文名解方向

国际班复习提纲把名解和简答直接出成英文，和五年制中文卷考查的是同一批户头。下面只列提纲里反复出现的英文指令，中文定义见 $1.2$，机制见 $1.1$ 与 $1.4$。

:::derivation{label="国际班提纲高频英文名解"}
蛋白质：peptide bond；amino acid residues；primary / secondary / tertiary / quaternary structure；isoelectric point；domain；protein denaturation。
核酸：primary structure of nucleic acids；$\mathrm{DNA}$ denaturation；$T_\mathrm{m}$；$\mathrm{DNA}$ renaturation；nucleic acid hybridization。
酶：enzyme；enzyme active center；competitive inhibition；$K_\mathrm{m}$；isoenzyme；zymogen activation。
糖：glycolysis；glycolytic pathway；tricarboxylic acid cycle；gluconeogenesis；blood sugar。
脂：fat mobilization；ketone body；plasma lipoprotein；apolipoprotein；essential fatty acid；blood lipids。
生物氧化：biological oxidation；respiratory chain；oxidative phosphorylation；substrate level phosphorylation。
氨基酸：essential amino acid；deamination；transamination；one carbon unit；hyperammonemia。
核苷酸：de novo synthesis pathway of purine nucleotide；nucleotide antimetabolite。
:::

:::pitfall{label="不要用医学英语课的单词顶替生化互译"}
本课互译范围是生物化学专业词。医学英语 2021 试卷里的临床对话词汇不在本篇。拼写以学习指南和小书为准：Michaelis 不要写成 Kichaelis；glycolysis 不要写成 glucolysis（除非试卷原文如此，答卷仍建议规范拼写）。
:::
