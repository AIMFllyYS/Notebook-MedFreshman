## 一、单项选择题（每题 1 分，共 35 分）

### 第1题

:::callout{kind=note label="题目"}
蛋白质的空间构象主要取决于（　　）

A. $\alpha$-螺旋和 $\beta$-折叠

B. 肽链中肽键的构象

C. 肽链氨基酸的排列顺序

D. 肽链中的二硫键

E. 肽链氨基酸的数量
:::

:::callout{kind=insight label="解析"}
**【答案】C**

一级结构（氨基酸排列顺序）决定空间构象。$\alpha$-螺旋、$\beta$-折叠是二级结构本身；肽键构象、二硫键、残基数目都参与稳定或限制构象，但「主要取决于」是序列。
:::

:::callout{kind=note label="知识卡片：Anfinsen"}
变性后再折叠，信息在一级结构里。二硫键是稳定因素，不是决定因素。
:::

:::callout{kind=tip label="结论速记"}
空间构象主要取决于 **氨基酸排列顺序**。
:::

### 第2题

:::callout{kind=note label="题目"}
用凝胶过滤层析柱分离蛋白质时，下列哪项是正确的？（　　）

A. 分子体积最大的蛋白质最先洗脱下来

B. 分子体积最小的蛋白质最先洗脱下来

C. 不带电荷的蛋白质最先洗脱下来

D. 带电荷的蛋白质最先洗脱下来

E. 以上都不对
:::

:::callout{kind=insight label="解析"}
**【答案】A**

凝胶过滤（分子筛）：大分子进不了凝胶孔，走颗粒间隙，**先**洗脱；小分子钻进孔道，路程长，后洗脱。电荷不是这根柱子的分离依据（那是离子交换）。
:::

:::callout{kind=note label="知识卡片：三种层析"}
| 方法 | 先下来的 |
|------|----------|
| 凝胶过滤 | 大分子 |
| 离子交换 | 与介质结合弱的 |
| 亲和层析 | 不结合的杂蛋白先被洗掉 |
:::

:::callout{kind=tip label="结论速记"}
分子筛：**大的先出来**。
:::

下列哪种碱基只存在于 $\mathrm{DNA}$ 而不存在于 $\mathrm{RNA}$ 中？（　　）

:::

:::callout{kind=tip label="结论速记"}
只在 $\mathrm{DNA}$：**胸腺嘧啶**。
:::

### 第5题

:::callout{kind=note label="题目"}
同工酶是指：（　　）

A. 催化的化学反应相同

B. 酶的理化性质相同

C. 电泳行为相同

D. 酶的分子结构相同

E. 降低反应活化能相同
:::

:::callout{kind=insight label="解析"}
**【答案】A**

同工酶催化**相同反应**，但分子结构、理化性质、电泳行为、免疫学性质不同。E 是酶的共性，不是同工酶定义。完整定义还要补「蛋白结构不同」；在本选项里只有 A 抓住分户。
:::

:::callout{kind=note label="知识卡片："}
$\mathrm{LDH}$、$\mathrm{CK}$ 是临床常考同工酶。一级结构有差异，活性中心三维结构相似。
:::

:::callout{kind=tip label="结论速记"}
同工酶：**反应相同，蛋白不同**。
:::

### 第6题

:::callout{kind=note label="题目"}
磺胺对二氢叶酸合成酶的抑制效应的动力学特点是：（　　）

A. $V_{\max}$ 不变，表观 $K_\mathrm{m}$ 值增加

B. $V_{\max}$ 不变，表观 $K_\mathrm{m}$ 值降低

C. $V_{\max}$ 降低，表观 $K_\mathrm{m}$ 值增加

D. $V_{\max}$ 降低，表观 $K_\mathrm{m}$ 值降低

E. $V_{\max}$ 降低，表观 $K_\mathrm{m}$ 值不变
:::

:::callout{kind=insight label="解析"}
**【答案】A**

磺胺是对氨基苯甲酸（$\mathrm{PABA}$）类似物，竞争性抑制二氢叶酸合成酶：与底物争活性中心，$V_{\max}$ 可被高底物拉回，表观 $K_\mathrm{m}$ 增大。
:::

:::callout{kind=note label="知识卡片：三类抑制"}
| | $K_\mathrm{m}$ | $V_{\max}$ |
|--|------|-----------|
| 竞争性 | ↑ | 不变 |
| 非竞争性 | 不变 | ↓ |
| 反竞争性 | ↓ | ↓ |
:::

:::callout{kind=tip label="结论速记"}
磺胺 $=$ 竞争性抑制：$V_{\max}$ 不变，表观 $K_\mathrm{m}$ **增大**。
:::

### 第7题

:::callout{kind=note label="题目"}
维生素 D 缺乏时可能会发生：（　　）

A. 佝偻病　B. 呆小症　C. 痛风症　D. 夜盲症　E. 脚气病

:::callout{kind=insight label="解析"}
**【答案】A**

维生素 D 缺乏：儿童佝偻病、成人骨软化症。呆小症缺碘／甲状腺素；痛风是尿酸；夜盲缺维生素 A；脚气病缺 $\mathrm{B}_1$。

:::

:::callout{kind=tip label="结论速记"}
缺维生素 D $\rightarrow$ **佝偻病**。
:::

### 第8题

:::callout{kind=note label="题目"}
丙酮酸不参与下列哪种代谢过程？（　　）

A. 转变为丙氨酸

B. 经异构酶催化生成丙酮

C. 异生成葡萄糖

D. 进入线粒体氧化供能

E. 还原为乳酸
:::

:::callout{kind=insight label="解析"}
**【答案】B**

丙酮酸可转氨成丙氨酸、羧化后糖异生、进线粒体经 $\mathrm{PDH}$ 成乙酰 $\mathrm{CoA}$、被 $\mathrm{LDH}$ 还原成乳酸。丙酮来自乙酰乙酸脱羧，**没有**「丙酮酸异构酶 $\rightarrow$ 丙酮」这条路。
:::

:::callout{kind=note label="知识卡片：丙酮属于酮体"}
酮体 $=$ 乙酰乙酸 $+\beta$-羟丁酸 $+$ 丙酮。不要把丙酮酸和丙酮并户。
:::

:::callout{kind=tip label="结论速记"}
丙酮酸**不能**经异构酶变成丙酮。
:::

### 第9题

:::callout{kind=note label="题目"}
合成糖原时，葡萄糖基的直接供体是：（　　）

A. $\mathrm{CDPG}$　B. $\mathrm{UDPG}$　C. 葡糖-1-磷酸　D. 葡糖-6-磷酸　E. 葡萄糖
:::

:::callout{kind=insight label="解析"}
**【答案】B**

糖原合酶只能用 $\mathrm{UDPG}$（UDP-葡萄糖）作为葡萄糖基直接供体。$\mathrm{G}$-$1$-$\mathrm{P}$ 先与 $\mathrm{UTP}$ 生成 $\mathrm{UDPG}$。动物糖原不用 $\mathrm{CDPG}$（细菌糖原／某些多糖才见 CDP 糖）。

:::callout{kind=note label="知识卡片：合成耗 UTP"}
糖原分解（磷酸化酶）不耗 $\mathrm{ATP}/\mathrm{UTP}$；合成耗 $\mathrm{UTP}$。
:::

:::callout{kind=tip label="结论速记"}
糖原合成直接供体 **UDPG**。
:::

### 第11题

:::callout{kind=note label="题目"}
脂酸 $\beta$-氧化的限速酶是（　　）

:::callout{kind=insight label="解析"}
**【答案】B**

:::callout{kind=tip label="结论速记"}
$\beta$-氧化限速酶 **CPT-Ⅰ**。

体内氨的储存及运输形式是（　　）

氨的储存运输：**谷氨酰胺**。

### 第19题

:::callout{kind=note label="题目"}
一个两岁患儿，频繁呕吐，发育不良，伴有白发。尿中苯丙氨酸、苯丙酮酸、苯乙酸含量明显增加。该患儿缺陷的酶是（　　）

A. 谷氨酸脱氢酶　B. 谷丙转氨酶　C. 苯丙氨酸羟化酶　D. 酪氨酸羟化酶　E. 谷草转氨酶
:::

:::callout{kind=insight label="解析"}
**【答案】C**

苯丙酮尿症（PKU）：苯丙氨酸羟化酶缺陷 $\rightarrow$ 苯丙氨酸堆积并走旁路成苯丙酮酸、苯乙酸；酪氨酸不足 $\rightarrow$ 黑色素少（白发）。

## 五、案例分析论述题（共 20 分）

案例：阿英身高 1.55 米，体重 68 公斤，喜欢吃甜食（糖果、蛋糕、薯条等），很少摄入食物脂肪，不喜欢运动。近期学校体检发现中度脂肪肝。阿英决定节食减肥，每日主食不超过 2 两，主要吃素，不用油炒。坚持了半个月，体重减轻两公斤，但上课精力不集中，经常出现头昏眼花。

### 第1题

:::callout{kind=note label="题目"}
阿英很少摄入食物脂肪，为什么发现患中度脂肪肝，请说明原因。（5 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**

1. **糖能变脂肪**：过量葡萄糖 $\rightarrow$ 丙酮酸 $\rightarrow$ 乙酰 $\mathrm{CoA}$；磷酸戊糖途径提供 $\mathrm{NADPH}$；乙酰 $\mathrm{CoA}$ 羧化酶（限速）生成丙二酸单酰 $\mathrm{CoA}$，胞质合成软脂酸，再酯化成甘油三酯。
2. **肝是合成脂肪的主力**：肝合成能力最强，以 $\mathrm{VLDL}$ 输出；合成过旺或 $\mathrm{VLDL}$ 组装／输出相对不足，甘油三酯堆积即脂肪肝。
3. **很少吃食物脂肪不等于能量负平衡**：甜食、蛋糕、薯条供能密度高，又少运动，过剩碳骨架在肝成脂。
4. 必需脂酸／载脂蛋白不足时可加重 $\mathrm{VLDL}$ 输出障碍。$\mathrm{BMI}=68/(1.55)^2\approx 28.3$，达肥胖。

本版葡萄糖彻底氧化净 **30 或 32 ATP**；过剩不走氧化就走合成。
:::

:::callout{kind=note label="知识卡片：糖变脂肪两件套"}
碳骨架：乙酰 $\mathrm{CoA}$（$\mathrm{PDH}$ 不可逆，脂不能净变糖）。还原力：$\mathrm{NADPH}$（PPP）。
:::

:::callout{kind=tip label="结论速记"}
不吃油也会脂肪肝：**糖 → 乙酰 CoA＋NADPH → 肝成脂**。
:::

### 第2题

:::callout{kind=note label="题目"}
阿英在节食减肥过程中，机体如何维持血糖水平恒定？（5 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**

节食半个月属短期饥饿。

1. **激素**：胰岛素↓，胰高血糖素、肾上腺素、糖皮质激素↑。
2. **肝糖原分解**（最早）：磷酸化酶活化；肝有葡萄糖-6-磷酸酶，释出游离葡萄糖。肝糖原约 $16\sim 24$ 小时耗尽。肌糖原不能补血糖。
3. **糖异生**：乳酸、甘油、生糖氨基酸在肝写成葡萄糖。关键酶：丙酮酸羧化酶、$\mathrm{PEP}$ 羧激酶、果糖-1,6-二磷酸酶、葡萄糖-6-磷酸酶。乙酰 $\mathrm{CoA}$ 不能净异生。
4. **省糖**：脂肪动员、$\beta$-氧化供能；肝生酮，脑逐渐用酮体。头昏眼花提示一过性血糖偏低、脑缺糖。
:::

:::callout{kind=note label="知识卡片：饿了谁补血糖"}
先肝糖原，再肝异生；更久酮体供脑。无氧酵解净 2 ATP；有氧净 30 或 32。
:::

:::callout{kind=tip label="结论速记"}
饿时血糖：先**肝糖原**，再**肝异生**；肌糖原补不了血。
:::

### 第3题

:::callout{kind=note label="题目"}
阿英在节食减肥过程中，其大多数器官的主要供能物质是哪种？请分析其供能的生化过程。（请写出关键步骤及关键酶）（10 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**

主要供能物质：**游离脂肪酸**（脂肪动员产物）。脑逐渐兼用酮体；红细胞仍只用葡萄糖。

**过程**

1. **脂肪动员**：脂肪组织甘油三酯逐步水解，激素敏感性脂肪酶（HSL）是关键调节酶（$\mathrm{cAMP}$-$\mathrm{PKA}$ 激活）。产物：游离脂酸 $+$ 甘油。
2. **活化**：脂酸 $+\mathrm{CoA}+\mathrm{ATP}\xrightarrow{\text{脂酰 CoA 合成酶}}$ 脂酰 $\mathrm{CoA}$（耗相当于 2 ATP）。
3. **进线粒体**：$\mathrm{CPT}$-Ⅰ（限速）肉碱穿梭。
4. **$\beta$-氧化**：脱氢（$\mathrm{FAD}$）→ 水化 → 再脱氢（$\mathrm{NAD}^+$）→ 硫解，反复切 2 碳，得乙酰 $\mathrm{CoA}$、$\mathrm{NADH}$、$\mathrm{FADH}_2$。
5. **乙酰 $\mathrm{CoA}$** 进三羧酸循环（柠檬酸合酶、异柠檬酸脱氢酶、$\alpha$-酮戊二酸脱氢酶等）。
6. **氧化磷酸化**：$\mathrm{NADH}$ 呼吸链 $2.5\,\mathrm{ATP}$，$\mathrm{FADH}_2$ 侧 $1.5\,\mathrm{ATP}$。

软脂酸净 **106 ATP**（本版）。肝把部分乙酰 $\mathrm{CoA}$ 做成酮体输给肝外。考后感想点名：论述考了脂肪酸分解代谢。
:::

:::callout{kind=note label="知识卡片：哪些组织例外"}
红细胞无线粒体，只能酵解葡萄糖。脑饥饿初期仍要糖，后期用酮体。肝自己不用酮体。
:::

:::callout{kind=tip label="结论速记"}
节食时多数器官烧 **脂酸**：动员 $\rightarrow$ 活化 $\rightarrow$ CPT-Ⅰ $\rightarrow\beta$-氧化 $\rightarrow$ TCA $+$ 氧化磷酸化。
:::

## 本卷必背

:::memory{label="13 级五年制 A 卷必背"}
- [ ] 构象取决于氨基酸顺序；分子筛大的先出；稀有碱基 tRNA
- [ ] 磺胺竞争性：Vmax 不变、Km 表观增大；蚕豆病 G6PD
- [ ] β-氧化限速 CPT-Ⅰ；酮体三成员；LDL 运内源胆固醇
- [ ] CN- 绑 Cyt a3；氨运输谷氨酰胺；PKU＝苯丙氨酸羟化酶
- [ ] MTX 抑二氢叶酸还原酶；次级胆汁酸石胆酸；结合胆红素＝葡糖醛酸
- [ ] 原核复制不是两条链都连续；NER：认→切→聚→连
- [ ] 核心酶 α2ββ′；注册进 A 位；氨基酸密码子 61；cAMP 先绑 CAP
- [ ] 磷酸化 Ser/Thr/Tyr；Ⅰ相氧化还原水解；mRNA 不加 CCA
- [ ] 名解 8 词＋insulin 等互译；必需基团三户；GPCR 六步
- [ ] 阿英：糖变脂肪致脂肪肝；饿时肝糖原→异生；多数器官烧脂酸
- [ ] 软脂酸净 106 ATP；有氧净 30 或 32 ATP
:::

:::memory{label="阿英脂肪肝机制" mode="cloze"}
很少吃食物脂肪仍可脂肪肝：过量糖在肝经乙酰 $\mathrm{CoA}$ 和 $\mathrm{NADPH}$ 合成脂酸、甘油三酯，$\mathrm{VLDL}$ 输出相对不足即堆积。
:::
