## 一、名词解释

### 第1题

:::callout{kind=note label="题目"}
分子克隆
:::

:::callout{kind=insight label="解析"}
**【答案】**

分子克隆（molecular cloning）即重组 $\mathrm{DNA}$ 技术（又称 $\mathrm{DNA}$ 克隆、基因工程）：通过体外操作将不同来源的两个或两个以上 $\mathrm{DNA}$ 分子重新组合，并在适当细胞中扩增形成新功能 $\mathrm{DNA}$ 分子。过程概括为 **分、选、连、转、筛**。
:::

:::callout{kind=note label="知识卡片：和自然界 DNA 重组分开"}
| | 场所 | 在做什么 |
|--|------|----------|
| $\mathrm{DNA}$ 重组 | 细胞内 | 同源／位点特异／转座 |
| 分子克隆 | 体外操作后放入细胞扩增 | 限制酶切、连接、载体、筛选 |
:::

:::callout{kind=tip label="结论速记"}
分子克隆 $=$ 体外把 $\mathrm{DNA}$ 连起来再扩增；口诀 **分选连转筛**。
:::

### 第2题

:::callout{kind=note label="题目"}
基因组
:::

:::callout{kind=insight label="解析"}
**【答案】**

基因组（genome）是生物体或细胞中一套完整单体具有的遗传信息的总和。人类基因组包括细胞核染色体 $\mathrm{DNA}$（常染色体和性染色体）及线粒体 $\mathrm{DNA}$ 所携带的全部遗传信息。不是「蛋白质编码基因名单」。
:::

:::callout{kind=note label="知识卡片：基因 vs 基因组"}
| 词 | 抓住的点 |
|----|----------|
| 基因 | 编码蛋白质或 $\mathrm{RNA}$ 的基本单位，含编码区 $+$ 调控区 |
| 基因组 | 一套完整遗传信息；人 $=$ 核 $\mathrm{DNA}+\mathrm{mtDNA}$ |
:::

:::callout{kind=tip label="结论速记"}
基因组 $=$ **一整套**遗传信息（核 $+$ 线粒体），不是两万个基因的目录。
:::

### 第3题

:::callout{kind=note label="题目"}
等电点
:::

:::callout{kind=insight label="解析"}
**【答案】**

蛋白质（或氨基酸）解离成正、负离子的趋势相等，成为兼性离子、净电荷为零时，溶液的 $\mathrm{pH}$ 称为等电点（isoelectric point，$\mathrm{pI}$）。$\mathrm{pH}>\mathrm{pI}$ 带负电，$\mathrm{pH}<\mathrm{pI}$ 带正电。大多数蛋白质 $\mathrm{pI}$ 接近 $5$，体液 $\mathrm{pH}\,7.4$ 时多带负电荷。
:::

:::callout{kind=note label="知识卡片：等电点不是不能电离"}
$\mathrm{pI}$ 时仍是兼性离子，只是净电荷为零，电泳不动、溶解度最低。不要写成「到了等电点侧链都不解离」。
:::

:::callout{kind=tip label="结论速记"}
等电点 $=$ 净电荷为零的 $\mathrm{pH}$；不是「不能电离」。
:::

### 第4题

:::callout{kind=note label="题目"}
脂肪动员
:::

:::callout{kind=insight label="解析"}
**【答案】**

脂肪动员（fat mobilization）是储存在白色脂肪细胞内的脂肪在脂肪酶作用下逐步水解，释放游离脂肪酸和甘油，供其他组织细胞氧化利用的过程。脂解激素（胰高血糖素、肾上腺素等）经 $\mathrm{cAMP}$-$\mathrm{PKA}$ 使 $\mathrm{Perilipin}$-$1$ 和激素敏感性脂肪酶磷酸化；$\mathrm{ATGL}$ 催化第一步，$\mathrm{HSL}$ 催化第二步，$\mathrm{MGL}$ 收尾。胰岛素抗脂解。
:::

:::callout{kind=note label="知识卡片：三步水解"}
| 酶 | 主要水解 |
|----|----------|
| $\mathrm{ATGL}$ | 甘油三酯 $\rightarrow$ 甘油二酯 $+$ $\mathrm{FFA}$ |
| $\mathrm{HSL}$ | 甘油二酯 $\rightarrow$ 甘油一酯 $+$ $\mathrm{FFA}$ |
| $\mathrm{MGL}$ | 甘油一酯 $\rightarrow$ 甘油 $+$ $\mathrm{FFA}$ |
:::

:::callout{kind=tip label="结论速记"}
脂肪动员 $=$ 脂库水解出 **FFA $+$ 甘油**；激素走 $\mathrm{cAMP}$-$\mathrm{PKA}$。
:::

### 第5题

:::callout{kind=note label="题目"}
核酸变性
:::

:::callout{kind=insight label="解析"}
**【答案】**

核酸变性指某些极端理化条件（温度、$\mathrm{pH}$、离子强度等）断裂双链互补碱基对之间的氢键并破坏碱基堆积力，使双链解离为单链。空间结构破坏，**核苷酸序列不变**。加热变性伴随 $260\,\mathrm{nm}$ 增色效应；$T_\mathrm{m}$ 是 $\Delta A_{260}$ 达最大变化一半、约 $50\%$ 双链解开时的温度。$\mathrm{GC}$ 含量越高 $T_\mathrm{m}$ 越高。
:::

:::callout{kind=note label="知识卡片：变性 vs 复性"}
变性：双链 $\rightarrow$ 单链，序列不变。复性（退火）：互补单链重新配对。$\mathrm{PCR}$ 的变性／退火就是这两步。
:::

:::callout{kind=tip label="结论速记"}
核酸变性 $=$ 拆双链氢键，**不改序列**；看 $A_{260}$ 升高。
:::

## 三、简答题

### 第1题

:::callout{kind=note label="题目"}
肝病患者为什么厌油？
:::

:::callout{kind=insight label="解析"}
**【答案】**

1. 肝细胞合成、分泌**胆汁酸（盐）**减少，排入肠道的胆汁不足。
2. 胆汁酸盐是脂类消化吸收所必需的乳化剂，协助形成混合微团，使胰脂酶能作用于甘油三酯。
3. 胆汁不足 $\rightarrow$ 膳食脂肪乳化差、微团形成障碍 $\rightarrow$ 脂肪消化吸收下降 $\rightarrow$ 油腻食物停留、腹胀、厌油。
4. 肝病时胰脂酶本身未必缺，缺的是**胆汁这一侧的乳化条件**；同时肝利用和转运脂质能力下降，也可加重油腻不适。
:::

:::callout{kind=note label="知识卡片：脂类消化三件套"}
乳化（胆汁酸盐）→ 胰脂酶水解 → 微团吸收。肝病先打第一件。脂溶性维生素（A、D、E、K）吸收也会受累。
:::

:::callout{kind=tip label="结论速记"}
肝病厌油：胆汁酸盐少 $\rightarrow$ **乳化差** $\rightarrow$ 吃油不化。
:::

### 第2题

:::callout{kind=note label="题目"}
列举并说明五个以上关于碱基互补配对的细胞事件或技术
:::

:::callout{kind=insight label="解析"}
**【答案】** 至少五条，事件和技术都算：

1. **$\mathrm{DNA}$ 复制**：以亲代链为模板，按 $\mathrm{A}$-$\mathrm{T}$、$\mathrm{G}$-$\mathrm{C}$ 合成子链（半保留）。
2. **转录**：以模板链为模板，$\mathrm{A}$-$\mathrm{U}$、$\mathrm{T}$-$\mathrm{A}$、$\mathrm{G}$-$\mathrm{C}$ 合成 $\mathrm{RNA}$。
3. **翻译**：$\mathrm{tRNA}$ 反密码子与 $\mathrm{mRNA}$ 密码子配对（第三位可有摆动）。
4. **$\mathrm{DNA}$ 损伤修复／同源重组**：以互补链或同源链为模板恢复序列。
5. **$\mathrm{PCR}$**：引物按互补结合模板后延伸。
6. **核酸杂交**（Southern / Northern、基因芯片、荧光原位杂交）：探针与靶序列互补。
7. **$\mathrm{cDNA}$ 合成**：逆转录酶按 $\mathrm{RNA}$ 模板互补写出 $\mathrm{DNA}$。
8. **RNA 干扰／miRNA**：小 $\mathrm{RNA}$ 与靶 $\mathrm{mRNA}$ 互补配对后沉默。
9. **剪接**：$\mathrm{snRNA}$ 与内含子边界互补识别。
10. **测序**（Sanger）：ddNTP 掺入仍遵守互补。
:::

:::callout{kind=note label="知识卡片：配对规则"}
$\mathrm{DNA}$：$\mathrm{A}=\mathrm{T}$（两氢键）、$\mathrm{G}\equiv\mathrm{C}$（三氢键）。$\mathrm{RNA}$ 以 $\mathrm{U}$ 代 $\mathrm{T}$。Chargaff：双链中 $\mathrm{A}=\mathrm{T}$、$\mathrm{G}=\mathrm{C}$，但 $\mathrm{A}+\mathrm{T}$ 不必等于 $\mathrm{G}+\mathrm{C}$。
:::

:::callout{kind=tip label="结论速记"}
互补配对：复制、转录、密码子–反密码子、修复、PCR／杂交——先写满五个。
:::

### 第3题

:::callout{kind=note label="题目"}
为什么肉碱缺乏的患者会发生低血糖
:::

:::callout{kind=insight label="解析"}
**【答案】**

长链脂肪酰 $\mathrm{CoA}$ 不能直接透过线粒体内膜，必须经**肉碱穿梭**（$\mathrm{CPT}$-Ⅰ 是 $\beta$-氧化关键酶）。肉碱缺乏 $\rightarrow$ 脂酰 $\mathrm{CoA}$ 进不了线粒体 $\rightarrow$ $\beta$-氧化受阻。

低血糖机制：

1. **外周与肝都不能靠脂肪酸氧化供 $\mathrm{ATP}$**，组织被迫加用葡萄糖。
2. **糖异生受抑制**：丙酮酸羧化酶需要乙酰 $\mathrm{CoA}$ 别构激活；$\beta$-氧化减少使线粒体内乙酰 $\mathrm{CoA}$、$\mathrm{NADH}$、$\mathrm{ATP}$ 不足，异生开不起来。
3. **不能生酮**：饥饿时本该用酮体省糖，肉碱缺乏时酮体也生成不足，脑更依赖葡萄糖。
4. 肝内脂酰 $\mathrm{CoA}$ 堆积，转向酯化，可伴脂肪肝，进一步损害肝异生。
:::

:::callout{kind=note label="知识卡片：肉碱穿梭"}
外膜 $\mathrm{CPT}$-Ⅰ：脂酰 $\mathrm{CoA}+$ 肉碱 $\rightarrow$ 脂酰肉碱；转位酶交换进基质；内膜内侧 $\mathrm{CPT}$-Ⅱ 变回脂酰 $\mathrm{CoA}$。丙二酸单酰 $\mathrm{CoA}$ 抑制 $\mathrm{CPT}$-Ⅰ。
:::

:::callout{kind=tip label="结论速记"}
缺肉碱 $=$ $\beta$-氧化停 $=$ **耗糖增加 $+$ 异生缺乙酰 CoA 激活** $\rightarrow$ 低血糖。
:::

### 第4题

:::callout{kind=note label="题目"}
以胰高血糖素为例说明膜受体型的信号转导通路的一般过程
:::

:::callout{kind=insight label="解析"}
**【答案】**

胰高血糖素受体是 $\mathrm{G}$ 蛋白偶联受体（七次跨膜），走 $\mathrm{G}_\mathrm{s}$-$\mathrm{cAMP}$-$\mathrm{PKA}$。对应本版 $\mathrm{GPCR}$ 共同模式：

1. 胰高血糖素结合肝（及脂肪等）细胞膜受体，别构激活受体。
2. 受体激活 $\mathrm{G}_\mathrm{s}$：$\alpha_{\mathrm{s}}$ 释放 $\mathrm{GDP}$、结合 $\mathrm{GTP}$，与 $\beta\gamma$ 解离（$\mathrm{G}$ 蛋白循环）。
3. $\alpha_{\mathrm{s}}$-$\mathrm{GTP}$ 激活腺苷酸环化酶（$\mathrm{AC}$）。
4. $\mathrm{AC}$ 催化 $\mathrm{ATP}\rightarrow\mathrm{cAMP}$（第二信使）。
5. $\mathrm{cAMP}$ 结合蛋白激酶 $\mathrm{A}$ 调节亚基，释放并激活催化亚基。
6. $\mathrm{PKA}$ 磷酸化下游：肝糖原磷酸化酶激酶 $\uparrow$、糖原合酶 $\downarrow$；诱导糖异生酶（如 $\mathrm{PEPCK}$）；脂肪组织促进脂肪动员。结果：**升血糖、促脂解**。
:::

:::callout{kind=note label="知识卡片：GPCR 六步（本版）"}
配体结合 $\rightarrow$ 激活 $\mathrm{G}$ 蛋白循环 $\rightarrow$ 效应分子（$\mathrm{AC}/\mathrm{PLC}$）$\rightarrow$ 小分子信使 $\rightarrow$ 激活蛋白质激酶 $\rightarrow$ 磷酸化产生应答。
:::

:::callout{kind=tip label="结论速记"}
胰高血糖素：膜受体 $\rightarrow\mathrm{G}_\mathrm{s}\rightarrow\mathrm{AC}\rightarrow\mathrm{cAMP}\rightarrow\mathrm{PKA}\rightarrow$ 磷酸化升糖。
:::

## 四、论述题

### 第1题

:::callout{kind=note label="题目"}
一个Ⅰ型糖原贮积症患者，材料中列举出了一系列不正常的指标，问为什么会发生低血糖、高脂血症、高尿酸血症、酸中毒？
:::

:::callout{kind=insight label="解析"}
**【答案】**

Ⅰ型糖原贮积症（von Gierke 病）为**葡萄糖-6-磷酸酶**缺陷。肝（肾）不能把 $\mathrm{G}$-$6$-$\mathrm{P}$ 水解成游离葡萄糖输出。

**低血糖**：空腹时肝糖原分解和糖异生都能写成 $\mathrm{G}$-$6$-$\mathrm{P}$，但最后一步出不去细胞，血糖无法补充。肌本就无此酶，不能代偿补血糖。

**高脂血症**：低血糖 $\rightarrow$ 胰高血糖素↑、胰岛素↓ $\rightarrow$ 脂肪动员，血 $\mathrm{FFA}$ 升高；肝内大量 $\mathrm{G}$-$6$-$\mathrm{P}$ 走糖酵解和磷酸戊糖途径，乙酰 $\mathrm{CoA}$ 与 $\mathrm{NADPH}$ 充足 $\rightarrow$ 脂肪酸、甘油三酯、胆固醇合成↑，并以 $\mathrm{VLDL}$ 输出 $\rightarrow$ 高甘油三酯、高胆固醇。

**高尿酸血症**：① $\mathrm{G}$-$6$-$\mathrm{P}$ 涌入磷酸戊糖途径 $\rightarrow$ 核糖-$5$-磷酸 $\rightarrow\mathrm{PRPP}$↑ $\rightarrow$ 嘌呤从头合成↑ $\rightarrow$ 尿酸生成↑；② 乳酸等有机酸增多，与尿酸竞争肾小管排泄 $\rightarrow$ 尿酸排出↓。

**酸中毒**：$\mathrm{G}$-$6$-$\mathrm{P}$ 只能在肝细胞内走酵解 $\rightarrow$ 乳酸堆积（乳酸性酸中毒）；脂肪动员和 $\beta$-氧化加强可伴酮体升高，加重代谢性酸中毒。回忆材料中的乳酸、甘油三酯、胆固醇、尿酸升高与上述机制一一对应。

葡萄糖彻底氧化净 $\mathrm{ATP}$ 按本版 **30 或 32**；本病卡在「游离葡萄糖出肝」，不是卡在有氧氧化计账。
:::

:::callout{kind=note label="知识卡片：G6Pase 这一刀"}
| 有酶（正常肝） | 无酶（Ⅰ型） |
|----------------|-------------|
| $\mathrm{G}$-$6$-$\mathrm{P}\rightarrow$ 葡萄糖入血 | $\mathrm{G}$-$6$-$\mathrm{P}$ 困在肝内 |
| 空腹能补血糖 | 空腹低血糖 $+$ 肝糖原堆积 |
| 异生可净输出葡萄糖 | 异生也卡在最后一步 |
:::

:::callout{kind=tip label="结论速记"}
Ⅰ型 $=$ 缺 $\mathrm{G6Pase}$：糖出不去 $\rightarrow$ **低血糖**；$\mathrm{G6P}$ 改走脂和 PPP $\rightarrow$ **高脂、高尿酸**；酵解产乳酸 $\rightarrow$ **酸中毒**。
:::
