## 一、名词解释

### 第1题

:::callout{kind=note label="题目"}
核酸的一级结构
:::

:::callout{kind=insight label="解析"}
**【答案】**

核酸的一级结构是指核苷酸在多核苷酸链中的**排列顺序**（碱基序列），相邻核苷酸以 $3',5'$-磷酸二酯键相连。$\mathrm{DNA}$、$\mathrm{RNA}$ 都谈一级结构；书写习惯从 $5'$ 端到 $3'$ 端。
:::

:::callout{kind=note label="知识卡片：四级不要并户"}
| 层次 | 指什么 |
|------|--------|
| 一级 | 核苷酸序列（磷酸二酯键） |
| 二级 | 双螺旋、发卡、茎环等 |
| 三级 | 超螺旋、拟核折叠、tRNA L 形等 |

一级被磷酸二酯键规定；氢键、碱基堆积是二级及以上。变性拆的是氢键，一级序列还在。
:::

:::callout{kind=tip label="结论速记"}
核酸一级结构 $=$ **碱基排列顺序**（$3',5'$-磷酸二酯键）。
:::

### 第2题

:::callout{kind=note label="题目"}
基因家族
:::

:::callout{kind=insight label="解析"}
**【答案】**

基因家族（gene family）是来源于同一个祖先、**结构和功能均相似**的一组基因；同一家族外显子具有相关性。多基因家族（multigene family）由某一祖先基因经重复和变异产生，是真核基因组的结构特点之一。
:::

:::callout{kind=note label="知识卡片：家族 vs 超家族"}
| | 结构 | 功能 |
|--|------|------|
| 多基因家族 | 相似 | **相关**（组蛋白成簇在 $7\mathrm{q}$；珠蛋白 $\alpha$ 在 16 号、$\beta$ 在 11 号） |
| 基因超家族 | 序列相似 | **不一定相关**（免疫球蛋白超家族、$\mathrm{ras}$ 超家族） |

原癌基因也可按结构／功能分成 $\mathrm{SRC}$、$\mathrm{RAS}$、$\mathrm{MYC}$ 等家族，那是肿瘤章的分户，名解先答基因组定义。
:::

:::callout{kind=tip label="结论速记"}
基因家族：共同祖先，**结构相似、功能相关**。
:::

### 第3题

:::callout{kind=note label="题目"}
复制
:::

:::callout{kind=insight label="解析"}
**【答案】**

复制（replication）是以亲代 $\mathrm{DNA}$ 为模板合成子代 $\mathrm{DNA}$ 的过程。基本特征：半保留、双向、半不连续；需要引物；链延长 $5'\rightarrow 3'$；有校读，忠实性高。
:::

:::callout{kind=note label="知识卡片：复制 vs 转录"}
复制：两股都做模板，原料 $\mathrm{dNTP}$，产物双链 $\mathrm{DNA}$，要引物。转录：一股模板链，原料 $\mathrm{NTP}$，不需引物。
:::

:::callout{kind=tip label="结论速记"}
复制 $=$ $\mathrm{DNA}\rightarrow\mathrm{DNA}$（replication）；不是 transcription。
:::

### 第4题

:::callout{kind=note label="题目"}
同工酶
:::

:::callout{kind=insight label="解析"}
**【答案】**

同工酶（isoenzyme）是催化**相同化学反应**，但酶蛋白分子结构、理化性质和免疫学特性各不相同的一组酶。可存在于同一种属不同个体、同一个体不同组织、同一细胞不同亚细胞结构或不同发育阶段。一级结构有差异，活性中心三维结构相同或相似。
:::

:::callout{kind=note label="知识卡片：临床最常考的一对"}
$\mathrm{LDH}$ 五型（$\mathrm{H}/\mathrm{M}$ 亚基组合）、$\mathrm{CK}$ 三型（$\mathrm{MM}/\mathrm{MB}/\mathrm{BB}$）。心肌损伤看 $\mathrm{CK}$-$\mathrm{MB}$、$\mathrm{LDH}_1$。同一 $\mathrm{mRNA}$ 前体不同剪接得到的酶也可算同工酶。
:::

:::callout{kind=tip label="结论速记"}
同工酶：**反应相同，蛋白不同**。
:::

### 第5题

:::callout{kind=note label="题目"}
氧化磷酸化
:::

:::callout{kind=insight label="解析"}
**【答案】**

氧化磷酸化（oxidative phosphorylation）是 $\mathrm{NADH}$、$\mathrm{FADH}_2$ 的氧化与 $\mathrm{ADP}$ 磷酸化相偶联、产生 $\mathrm{ATP}$ 的过程：电子经呼吸链传给氧生成水，释能驱动 $\mathrm{ADP}$ 磷酸化。人体约 $90\%$ 的 $\mathrm{ATP}$ 由此而来。
:::

:::callout{kind=note label="知识卡片：和底物水平磷酸化分开"}
| | 场所／机制 |
|--|-----------|
| 氧化磷酸化 | 线粒体内膜；质子回流 $+$ $\mathrm{ATP}$ 合酶 |
| 底物水平磷酸化 | 酵解两步、三羧酸循环琥珀酰 $\mathrm{CoA}$ 合成酶等 |

葡萄糖彻底氧化净 **30 或 32 ATP**，绝大部分来自氧化磷酸化。解偶联则呼吸还在、$\mathrm{ATP}$ 没了、能量变热。
:::

:::callout{kind=tip label="结论速记"}
氧化磷酸化 $=$ 呼吸链氧化 **偶联** $\mathrm{ADP}\rightarrow\mathrm{ATP}$。
:::

## 二、简答题

### 第1题

:::callout{kind=note label="题目"}
葡糖-6-磷酸的来源与去路
:::

:::callout{kind=insight label="解析"}
**【答案】**

葡萄糖-6-磷酸（$\mathrm{G}$-$6$-$\mathrm{P}$）是糖代谢枢纽中间产物。

**来源**

1. 游离葡萄糖磷酸化：己糖激酶（各组织，$K_\mathrm{m}$ 低）／葡糖激酶（肝，$K_\mathrm{m}$ 高），耗 $1\,\mathrm{ATP}$。
2. 糖原分解：糖原 $\rightarrow\mathrm{G}$-$1$-$\mathrm{P}\rightarrow\mathrm{G}$-$6$-$\mathrm{P}$（磷酸葡萄糖变位酶）。
3. 糖异生：果糖-6-磷酸经磷酸己糖异构酶 $\rightarrow\mathrm{G}$-$6$-$\mathrm{P}$。
4. 其他单糖：半乳糖、果糖等可汇入 $\mathrm{G}$-$6$-$\mathrm{P}$ 或其上游。

**去路**

1. **糖酵解／有氧氧化**：$\mathrm{G}$-$6$-$\mathrm{P}\rightarrow$ 果糖-6-磷酸 $\rightarrow\cdots$，彻底氧化净 **30 或 32 ATP**。
2. **磷酸戊糖途径**：$\mathrm{G}$-$6$-$\mathrm{P}$ 脱氢酶限速，产 $\mathrm{NADPH}$ 和核糖磷酸（本途径不产能）。
3. **糖原合成**：$\mathrm{G}$-$6$-$\mathrm{P}\rightarrow\mathrm{G}$-$1$-$\mathrm{P}\rightarrow\mathrm{UDPG}\rightarrow$ 糖原。
4. **释出游离葡萄糖**（肝、肾）：葡萄糖-6-磷酸酶水解 $\mathrm{G}$-$6$-$\mathrm{P}$。肌无此酶，肌糖原不能补血糖。
5. 其他：葡糖醛酸途径等。
:::

:::callout{kind=note label="知识卡片：肝特有的那一刀"}
葡萄糖-6-磷酸酶只在肝（及肾）丰富。缺它就是Ⅰ型糖原贮积症：$\mathrm{G}$-$6$-$\mathrm{P}$ 出不去 $\rightarrow$ 低血糖 $+$ 肝糖原堆积。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{G}$-$6$-$\mathrm{P}$：来自糖／糖原／异生；去向酵解、PPP、糖原、肝释糖。
:::

### 第2题

:::callout{kind=note label="题目"}
两条氧化呼吸链的组成
:::

:::callout{kind=insight label="解析"}
**【答案】**

呼吸链位于**线粒体内膜**，由 4 种蛋白质复合体 $+$ 泛醌（$\mathrm{Q}$）$+$ 细胞色素 $c$ 组成。按入口分成两条：

1. **$\mathrm{NADH}$ 呼吸链**（$\mathrm{NADH}$ 氧化呼吸链）

$$\mathrm{NADH}\rightarrow\text{复合体Ⅰ}\rightarrow\mathrm{Q}\rightarrow\text{复合体Ⅲ}\rightarrow\mathrm{Cyt}\,c\rightarrow\text{复合体Ⅳ}\rightarrow\mathrm{O}_2$$

传递一对电子生成 **$2.5\,\mathrm{ATP}$**。复合体Ⅰ、Ⅲ、Ⅳ泵质子。

2. **$\mathrm{FADH}_2$ 呼吸链**（琥珀酸氧化呼吸链）

$$\text{琥珀酸}\rightarrow\text{复合体Ⅱ}\rightarrow\mathrm{Q}\rightarrow\text{复合体Ⅲ}\rightarrow\mathrm{Cyt}\,c\rightarrow\text{复合体Ⅳ}\rightarrow\mathrm{O}_2$$

传递一对电子生成 **$1.5\,\mathrm{ATP}$**。复合体Ⅱ不泵质子。琥珀酸脱氢的氢不经 $\mathrm{NADH}$ 呼吸链。
:::

:::callout{kind=note label="知识卡片：抑制剂位点"}
| 位点 | 抑制剂 |
|------|--------|
| 复合体Ⅰ | 鱼藤酮、粉蝶霉素 A、异戊巴比妥 |
| 复合体Ⅲ | 抗霉素 A |
| 复合体Ⅳ | $\mathrm{CN}^-$、$\mathrm{CO}$、$\mathrm{N}_3^-$ |

$\mathrm{CN}^-$ 主要结合细胞色素 $a_3$。胞质 $\mathrm{NADH}$ 须经苹果酸–天冬氨酸穿梭（按 $2.5$ 计）或 3-磷酸甘油穿梭（按 $1.5$ 计）进线粒体，这是葡萄糖净 **30 或 32 ATP** 分叉的原因。
:::

:::callout{kind=tip label="结论速记"}
两条链在 $\mathrm{Q}$ 会合；$\mathrm{NADH}$ 走Ⅰ得 2.5，$\mathrm{FADH}_2$ 走Ⅱ得 1.5。
:::

### 第3题

:::callout{kind=note label="题目"}
复制的特征
:::

:::callout{kind=insight label="解析"}
**【答案】**

1. **半保留复制**：子代双链各保留一条亲代链。
2. **双向复制**：从起点向两侧推进（多数情况下）。
3. **半不连续复制**：前导链连续，后随链以岡崎片段不连续合成。
4. **需要引物**：$\mathrm{DNA}$ 聚合酶不能从头起始，先由引物酶合成 $\mathrm{RNA}$ 引物。
5. **方向性**：$5'\rightarrow 3'$ 聚合。
6. **高保真**：碱基选择 $+$ $3'\rightarrow 5'$ 校读 $+$ 错配修复。
7. 原核常一个起点（$\mathrm{oriC}$）；真核多复制子，只在 $\mathrm{S}$ 期、每个周期一次。
:::

:::callout{kind=note label="知识卡片：不要写成两条链都连续"}
「等点开始、两条链均连续复制」是错的。随从链必须岡崎片段。
:::

:::callout{kind=tip label="结论速记"}
复制三半：**半保留、双向、半不连续**；要引物、有校读。
:::

### 第4题

:::callout{kind=note label="题目"}
遗传密码的特点
:::

:::callout{kind=insight label="解析"}
**【答案】**

遗传密码（genetic code）是 $\mathrm{mRNA}$ 上决定氨基酸的三联体核苷酸。主要特点：

1. **三联体**：3 个连续碱基编码 1 个氨基酸。
2. **简并**：除甲硫氨酸、色氨酸外，多数氨基酸有多个密码子（同义密码子）。
3. **方向性**：从 $5'$ 向 $3'$ 阅读。
4. **连续性、不重叠、无逗号**：读框从起始密码子连续读下去。
5. **通用性**：从细菌到人基本共用同一套密码（线粒体等有少数例外）。
6. **摆动**：反密码子第一位（对应密码子第三位）配对可「松」，解释简并。
7. **起始与终止**：起始多为 $\mathrm{AUG}$（甲硫氨酸／甲酰甲硫氨酸）；终止 $\mathrm{UAA}$、$\mathrm{UAG}$、$\mathrm{UGA}$ 不编码氨基酸。编码 20 种氨基酸的密码子是 **61** 个（64 减 3 个终止）。
:::

:::callout{kind=note label="知识卡片：64、61、20"}
64 个三联体 $=$ 61 个氨基酸密码子 $+$ 3 个终止。不是「20 个密码子编 20 种氨基酸」。
:::

:::callout{kind=tip label="结论速记"}
密码：三联、简并、通用、连续不重叠；起始 $\mathrm{AUG}$，终止三兄弟。
:::

## 三、情景论述题

### 第1题

:::callout{kind=note label="题目"}
棕榈酸（即软脂酸）经静脉注射入血液如何彻底氧化供能？
:::

:::callout{kind=insight label="解析"}
**【答案】**

软脂酸（palmitic acid，$16$ 碳饱和脂酸）静脉入血后与清蛋白结合运输，被肝、肌等摄取。不走肠道乳糜微粒。彻底氧化分阶段：

**1. 活化（胞液）**

软脂酸 $+\ \mathrm{CoA}+\mathrm{ATP}\rightarrow$ 软脂酰 $\mathrm{CoA}+\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$（脂酰 $\mathrm{CoA}$ 合成酶）。$\mathrm{PP}_\mathrm{i}$ 被水解，相当于消耗 **2** 个高能磷酸键。

**2. 进线粒体（限速）**

长链脂酰 $\mathrm{CoA}$ 不能直接过内膜。肉碱穿梭：$\mathrm{CPT}$-Ⅰ（限速，线粒体外膜）生成脂酰肉碱 $\rightarrow$ 转位酶进基质 $\rightarrow\mathrm{CPT}$-Ⅱ 变回脂酰 $\mathrm{CoA}$。丙二酸单酰 $\mathrm{CoA}$ 抑制 $\mathrm{CPT}$-Ⅰ。

**3. $\beta$-氧化（线粒体基质）**

每次循环四步：脂酰 $\mathrm{CoA}$ 脱氢（$\mathrm{FAD}\rightarrow\mathrm{FADH}_2$）$\rightarrow$ 水化 $\rightarrow$ 再脱氢（$\mathrm{NAD}^+\rightarrow\mathrm{NADH}$）$\rightarrow$ 硫解，切下 1 分子乙酰 $\mathrm{CoA}$、碳链少 2。软脂酰 $\mathrm{CoA}$ 经 **7** 轮，得 **8** 分子乙酰 $\mathrm{CoA}$、$7\,\mathrm{NADH}$、$7\,\mathrm{FADH}_2$。

**4. 乙酰 $\mathrm{CoA}$ 进三羧酸循环**

每分子乙酰 $\mathrm{CoA}$ 彻底氧化按本版产 **10 ATP**。

**5. 氧化磷酸化**

$\mathrm{NADH}$ 走 $\mathrm{NADH}$ 呼吸链，$2.5\,\mathrm{ATP}$／对电子；$\mathrm{FADH}_2$ 走琥珀酸侧，$1.5\,\mathrm{ATP}$／对电子。

**净账（本版）**

$$(8\times 10)+(7\times 2.5)+(7\times 1.5)-2=106$$

$1$ 分子软脂酸彻底氧化净 **106 ATP**。不要写旧口诀 129／131。葡萄糖彻底氧化净 **30 或 32 ATP**，是同一套 $2.5/1.5$ 计账。偶数碳脂酸不能净糖异生（$\mathrm{PDH}$ 不可逆）。
:::

:::callout{kind=note label="知识卡片：静脉 vs 口服"}
静脉注射跳过小肠活化、再酯化、乳糜微粒。后面活化、肉碱、$\beta$-氧化、TCA、呼吸链与从脂肪动员来的游离脂酸相同。硬脂酸（$18$ 碳）是 8 轮 $\beta$-氧化、9 个乙酰 $\mathrm{CoA}$；本场考的是 $16$ 碳软脂酸。
:::

:::callout{kind=tip label="结论速记"}
软脂酸：活化 $-2$ $\rightarrow$ 肉碱（$\mathrm{CPT}$-Ⅰ）$\rightarrow$ 7 轮 $\beta$-氧化 $\rightarrow$ 8 个乙酰 $\mathrm{CoA}$ $\rightarrow$ 净 **106 ATP**。
:::
