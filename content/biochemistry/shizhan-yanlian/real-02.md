## 三、名词解释（每词 2 分，共 16 分）

### 第1题

:::callout{kind=note label="题目"}
癌基因
:::

:::callout{kind=insight label="解析"}
**【答案】**

癌基因（oncogene）是能导致细胞发生恶性转化和诱发癌症的基因。绝大多数由细胞内正常的原癌基因突变或表达水平异常升高转变而来；某些病毒也携带癌基因。原癌基因在正常条件下并不具致癌活性。
:::

:::callout{kind=note label="知识卡片：癌基因 vs 原癌基因 vs 抑癌基因"}
| | 正常功能 | 癌变时 |
|--|---------|--------|
| 原癌基因 | 促增殖、抗凋亡 | 活化（功能获得）→ 癌基因 |
| 癌基因 | — | 已具致癌活性 |
| 抑癌基因 | 抑增殖、促分化、诱发凋亡 | 失活 |
:::

:::callout{kind=tip label="结论速记"}
癌基因能致癌；正常细胞里先有的是**原癌基因**，不是「人体自带坏基因」。
:::

### 第2题

:::callout{kind=note label="题目"}
氧化磷酸化
:::

:::callout{kind=insight label="解析"}
**【答案】**

氧化磷酸化（oxidative phosphorylation）是 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的氧化与 $\mathrm{ADP}$ 磷酸化相偶联、产生 $\mathrm{ATP}$ 的过程：电子经呼吸链传给氧生成水，释能驱动 $\mathrm{ADP}$ 磷酸化。人体约 $90\%$ 的 $\mathrm{ATP}$ 由此而来。
:::

:::callout{kind=note label="知识卡片：两种磷酸化"}
| 方式 | 机制 | 产额 |
|------|------|------|
| 底物水平磷酸化 | 底物高能磷酸（或高能硫酯）直接转给 $\mathrm{ADP}/\mathrm{GDP}$ | 少量 |
| 氧化磷酸化 | 呼吸链 $+$ 质子回流 $+$ $\mathrm{ATP}$ 合酶 | 人体约 $90\%$ $\mathrm{ATP}$ |
:::

:::callout{kind=tip label="结论速记"}
氧化磷酸化 $=$ 呼吸链氧化 **偶联** $\mathrm{ADP}$ 磷酸化；不是底物水平磷酸化的别名。
:::

### 第3题

:::callout{kind=note label="题目"}
从头合成途径
:::

:::callout{kind=insight label="解析"}
**【答案】**

从头合成途径（de novo synthesis）指利用简单前体（氨基酸、一碳单位、$\mathrm{CO}_2$、$\mathrm{PRPP}$ 等）在细胞内逐步合成核苷酸（或其他化合物），而不是利用现成碱基／核苷的补救合成。嘌呤从头合成在细胞质从核糖-$5$-磷酸起，先写成 $\mathrm{IMP}$ 再分流为 $\mathrm{AMP}$、$\mathrm{GMP}$；嘧啶则先成环（乳清酸）再接到 $\mathrm{PRPP}$ 上。
:::

:::callout{kind=note label="知识卡片：嘌呤 vs 嘧啶从头合成"}
| | 嘌呤 | 嘧啶 |
|--|------|------|
| 环与核糖 | 在 $\mathrm{PRPP}$ 上逐步长环 | 先合成乳清酸环，再与 $\mathrm{PRPP}$ 连接 |
| 关键中间物 | $\mathrm{IMP}$ | $\mathrm{UMP}$（经乳清酸核苷酸） |
| 原料印象 | $\mathrm{Gln}$、Gly、$\mathrm{Asp}$、一碳单位、$\mathrm{CO}_2$ | $\mathrm{Gln}$、$\mathrm{Asp}$、$\mathrm{CO}_2$ |
:::

:::callout{kind=tip label="结论速记"}
从头合成 $=$ 简单前体 **新写** 核苷酸；嘌呤在 $\mathrm{PRPP}$ 上长环，嘧啶先成环再接糖。
:::

### 第4题

:::callout{kind=note label="题目"}
胆色素
:::

:::callout{kind=insight label="解析"}
**【答案】**

胆色素（bile pigment）是体内铁卟啉类化合物的主要分解代谢产物，包括胆绿素、胆红素、胆素原和胆素。主要随胆汁排出。胆红素居于代谢中心，呈橙黄色，是人体胆汁中的主要色素。血红素不是胆色素。
:::

:::callout{kind=note label="知识卡片：四户胆色素"}
血红素 $\rightarrow$ 胆绿素 $\rightarrow$ 胆红素 $\rightarrow$（肠菌）胆素原 $\rightarrow$ 胆素。

黄疸黄的是胆红素，不是血红素。
:::

:::callout{kind=tip label="结论速记"}
胆色素四户：**胆绿素、胆红素、胆素原、胆素**；中心是胆红素。
:::

### 第5题

:::callout{kind=note label="题目"}
基因表达
:::

:::callout{kind=insight label="解析"}
**【答案】**

基因表达（gene expression）即基因转录及翻译的过程，也是基因所携带的遗传信息表现为表型的过程。包括转录成互补 $\mathrm{RNA}$；蛋白质编码基因的 $\mathrm{mRNA}$ 再翻译成多肽链并装配加工。$\mathrm{rRNA}$、$\mathrm{tRNA}$ 基因只转录也属于表达。
:::

:::callout{kind=note label="知识卡片：表达不一定出蛋白质"}
- 蛋白质编码基因：转录 $+$ 翻译（ $+$ 加工）。
- $\mathrm{rRNA}/\mathrm{tRNA}$ 基因：转录出功能 $\mathrm{RNA}$ 即表达。
- 03 级原卷要点也写成「基因转录及翻译的过程」。
:::

:::callout{kind=tip label="结论速记"}
表达 $=$ 转录（及翻译）；不要把 $\mathrm{rRNA}/\mathrm{tRNA}$ 基因排除在外。
:::

### 第6题

:::callout{kind=note label="题目"}
必需氨基酸
:::

:::callout{kind=insight label="解析"}
**【答案】**

必需氨基酸（essential amino acid）是体内需要而不能自身合成、必须由食物提供的氨基酸。本版 $9$ 种：亮氨酸、异亮氨酸、苏氨酸、缬氨酸、赖氨酸、甲硫氨酸、苯丙氨酸、色氨酸、组氨酸。
:::

:::callout{kind=note label="知识卡片：九种必需氨基酸"}
亮、异亮、苏、缬、赖、甲硫、苯丙、色、组。组氨酸在本版名单内。精氨酸能合成但量不多，有人称为半必需，不要加成第 $10$ 种改掉九种名单。
:::

:::callout{kind=tip label="结论速记"}
必需 $=$ 人体**不能合成**、必须吃；本版 **9 种含组氨酸**。
:::

### 第7题

:::callout{kind=note label="题目"}
分子克隆
:::

:::callout{kind=insight label="解析"}
**【答案】**

分子克隆（molecular cloning）即重组 $\mathrm{DNA}$ 技术，又称 $\mathrm{DNA}$ 克隆或基因工程：通过体外操作将不同来源的两个或两个以上 $\mathrm{DNA}$ 分子重新组合，并在适当细胞中扩增形成新功能 $\mathrm{DNA}$ 分子。五步：**分、选、连、转、筛**。
:::

:::callout{kind=note label="知识卡片：克隆五步"}
1. 分：获取目的 $\mathrm{DNA}$
2. 选：选择并准备载体
3. 连：目的片段与载体连接成重组体
4. 转：转入受体细胞
5. 筛：筛选鉴定重组体
:::

:::callout{kind=tip label="结论速记"}
分子克隆 $=$ 体外重组 $+$ 细胞里扩增；口诀 **分选连转筛**。
:::

### 第8题

:::callout{kind=note label="题目"}
蛋白质变性
:::

:::callout{kind=insight label="解析"}
**【答案】**

蛋白质在某些物理和化学因素作用下，特定空间构象被破坏（有序变无序），导致理化性质改变和生物学活性丧失，称为蛋白质变性（denaturation）。一般破坏二硫键和非共价键，**不改变一级结构氨基酸序列**。
:::

:::callout{kind=note label="知识卡片：变性后看得见的改变"}
溶解度降低、黏度增加、结晶能力消失、生物学活性丧失、易被蛋白酶水解。常见因素：加热、有机溶剂、强酸强碱、重金属离子、生物碱试剂。
:::

:::callout{kind=tip label="结论速记"}
变性毁**构象**不毁肽键；活性丢了，一级序列还在。
:::

## 五、简答题（每题 5 分，共 20 分）

### 第1题

:::callout{kind=note label="题目"}
酶的基团有哪些？作用？
:::

:::callout{kind=insight label="解析"}
**【答案】**

酶分子中与活性密切相关的化学基团称为**必需基团**。

1. **活性中心内的结合基团**：识别底物并与之专一性结合，形成酶–底物复合物，决定专一性。
2. **活性中心内的催化基团**：催化底物中某些化学键断裂、形成新键，使底物变成产物。
3. **活性中心外的必需基团**：不直接催化，但维持活性中心空间构象，和／或作为调节剂结合部位。

常见化学类别：丝氨酸羟基、组氨酸咪唑基、半胱氨酸巯基、酸性氨基酸羧基等。辅酶／辅基常参与构成活性中心。
:::

:::callout{kind=note label="知识卡片：活性中心"}
活性中心（active center / active site）是酶分子中能与底物特异结合并催化底物转变为产物的区域。结合基团管「认谁」，催化基团管「怎么变」。
:::

:::callout{kind=tip label="结论速记"}
酶的基团分三户：**结合、催化、中心外维持构象**。
:::

### 第2题

:::callout{kind=note label="题目"}
原核生物复制和转录的不同点
:::

:::callout{kind=insight label="解析"}
**【答案】**

| 项目 | 复制 | 转录 |
|------|------|------|
| 模板 | 两股链都做模板 | 一股模板链（不对称） |
| 原料 | $\mathrm{dNTP}$ | $\mathrm{NTP}$ |
| 酶 | $\mathrm{DNA}$ 聚合酶（需引物，$5'\rightarrow 3'$） | $\mathrm{RNA}$ 聚合酶（不需引物） |
| 产物 | 子代双链 $\mathrm{DNA}$ | $\mathrm{RNA}$（m/t/r 等） |
| 配对 | $\mathrm{A}$-$\mathrm{T}$、$\mathrm{G}$-$\mathrm{C}$ | $\mathrm{A}$-$\mathrm{U}$、$\mathrm{T}$-$\mathrm{A}$、$\mathrm{G}$-$\mathrm{C}$ |
| 忠实性 | 有校读、错配修复 | 无校读，容错较高 |
| 范围 | 通常整基因组 | 选区段（操纵子／基因） |
| 引物 | 需要 $\mathrm{RNA}$ 引物 | 不需要 |
| 拓扑 | 半不连续（前导链连续、随从链岡崎片段） | 连续抄一条 $\mathrm{RNA}$ |
:::

:::callout{kind=note label="知识卡片：相同点不要漏"}
两者都：$5'\rightarrow 3'$ 聚合；都要解开双链；都遵守碱基互补；都消耗三磷酸核苷。问「不同点」按上表；问「异同」再补相同点。
:::

:::callout{kind=tip label="结论速记"}
复制抄**全基因组双链 $+$ 要引物 $+$ 有校读**；转录抄**一股、不需引物**。
:::

### 第3题

:::callout{kind=note label="题目"}
参与蛋白质合成的物质
:::

:::callout{kind=insight label="解析"}
**【答案】**

直接参与翻译的核酸与因子：

1. **$\mathrm{mRNA}$**：模板，提供密码子。
2. **$\mathrm{tRNA}$**：运载氨基酸，反密码子认密码子。
3. **核糖体（$\mathrm{rRNA}+$蛋白质）**：装配车间；肽酰转移酶活性在大亚基 $\mathrm{rRNA}$（核酶）。
4. **氨基酸** $+$ **氨基酰-$\mathrm{tRNA}$ 合成酶** $+$ $\mathrm{ATP}$：活化氨基酸。
5. **起始／延长／释放因子**，以及 $\mathrm{GTP}$、$\mathrm{Mg}^{2+}$ 等。
6. 原核起始 $\mathrm{fMet}$-$\mathrm{tRNA}^{\mathrm{fMet}}$；真核起始 $\mathrm{Met}$-$\mathrm{tRNA}_{\mathrm{i}}$ 及帽子结合复合体等。
:::

:::callout{kind=note label="知识卡片：三种 RNA 分工"}
| 核酸 | 功能 |
|------|------|
| $\mathrm{mRNA}$ | 模板 |
| $\mathrm{tRNA}$ | 适配器 |
| $\mathrm{rRNA}$ | 核糖体骨架 $+$ 肽键形成 |
:::

:::callout{kind=tip label="结论速记"}
蛋白质合成：**三种 $\mathrm{RNA}$ $+$ 氨基酸 $+$ 合成酶 $+$ 蛋白因子 $+$ $\mathrm{ATP}/\mathrm{GTP}$**。
:::

### 第4题

:::callout{kind=note label="题目"}
G 蛋白偶联受体介导的信号转导的基本模式
:::

:::callout{kind=insight label="解析"}
**【答案】**

本版六步：

1. 细胞外信号结合受体，别构激活受体。
2. 受体激活 $\mathrm{G}$ 蛋白，进入 $\mathrm{G}$ 蛋白循环（$\mathrm{GDP}\rightleftharpoons\mathrm{GTP}$，$\alpha$ 与 $\beta\gamma$ 解离／再装配）。
3. 活化 $\mathrm{G}$ 蛋白激活下游效应分子（$\mathrm{AC}$、$\mathrm{PLC}$ 等；$\alpha_{\mathrm{s}}$ 激活 $\mathrm{AC}$，$\alpha_{\mathrm{i}}$ 抑制 $\mathrm{AC}$）。
4. 效应分子产生小分子信使（$\mathrm{cAMP}$，或 $\mathrm{DAG}+\mathrm{IP}_3$），或调节离子通道改变 $\mathrm{Ca}^{2+}$ 分布。
5. 小分子信使别构激活靶分子（主要是蛋白质激酶，如 $\mathrm{PKA}$、$\mathrm{PKC}$）。
6. 蛋白质激酶磷酸化代谢酶、转录因子、运动相关蛋白，产生细胞应答。
:::

:::callout{kind=note label="知识卡片：两条最常考的下游"}
| $\mathrm{G}\alpha$ | 效应酶 | 信使 | 激酶 |
|------|--------|------|------|
| $\alpha_{\mathrm{s}}$ | 腺苷酸环化酶 | $\mathrm{cAMP}$ | $\mathrm{PKA}$ |
| $\alpha_{\mathrm{q}}$ | 磷脂酶 C | $\mathrm{IP}_3$、$\mathrm{DAG}$ | $\mathrm{PKC}$（需 $\mathrm{Ca}^{2+}$） |

胰高血糖素、肾上腺素 $\beta$ 受体走 $\mathrm{cAMP}$-$\mathrm{PKA}$。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{GPCR}$ 口诀：配体 $\rightarrow$ 受体 $\rightarrow$ $\mathrm{G}$ 蛋白循环 $\rightarrow$ 效应酶 $\rightarrow$ 第二信使 $\rightarrow$ 激酶磷酸化。
:::

## 六、论述题（20 分）

### 第1题

:::callout{kind=note label="题目"}
阿英身高 155 厘米，体重 68 公斤，喜欢吃甜食，如糖果、蛋糕、薯条等。很少摄入食物脂肪，不喜欢运动。近期学校体检发现中度脂肪肝。阿英决定节食减肥，每日主食不宜超过 2 两，主要吃素，不用油炒，以水煮和蒸为主。坚持了半个月，体重虽然轻了两公斤，但上课精力不集中，经常出现头晕眼花。

1. 阿英肥胖吗？为什么？阿英为什么会长胖？（12 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**

**是否肥胖**：$\mathrm{BMI}=$ 体重（kg）／身高（m）$^2=68/(1.55)^2\approx 28.3$。成人 $\mathrm{BMI}\ge 28$ 为肥胖（中国标准；$\ge 24$ 超重）。故阿英达到肥胖。

**为什么会长胖**：

1. **能量正平衡**：甜食、蛋糕、薯条供能密度高，又很少运动，摄入 $>$ 消耗，过剩能量以甘油三酯存于脂肪组织。
2. **糖也能变脂肪**：很少吃食物脂肪仍可胖。葡萄糖 $\rightarrow$ 丙酮酸 $\rightarrow$ 乙酰 $\mathrm{CoA}$；磷酸戊糖途径提供 $\mathrm{NADPH}$；乙酰 $\mathrm{CoA}$ 羧化酶（限速）生成丙二酸单酰 $\mathrm{CoA}$，在胞质合成软脂酸，再酯化成甘油三酯。肝合成脂肪能力最强，以 $\mathrm{VLDL}$ 输出；输出相对不足或合成过旺即脂肪肝。
3. **缺乏运动**：骨骼肌氧化脂肪酸和葡萄糖减少，更易堆积。

本版葡萄糖彻底氧化净 **30 或 32** $\mathrm{ATP}$（不要写 36/38）；节食后供能账见第 2 问。
:::

:::callout{kind=note label="知识卡片：糖变脂肪的两件套"}
- 碳骨架：糖 $\rightarrow$ 乙酰 $\mathrm{CoA}$（$\mathrm{PDH}$ 不可逆，脂不能净变成糖）。
- 还原力：磷酸戊糖途径的 $\mathrm{NADPH}$。
- 肝：合成甘油三酯最强，靠 $\mathrm{VLDL}$ 运出；蛋白或必需脂酸不足、$\mathrm{VLDL}$ 组装障碍会加重脂肪肝。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{BMI}\approx 28.3$ 达肥胖；**不吃油也会胖**——糖 $\rightarrow$ 乙酰 $\mathrm{CoA}+\mathrm{NADPH}\rightarrow$ 脂。
:::

### 第2题

:::callout{kind=note label="题目"}
2. 节食饥饿时如何维持血糖水平恒定的？（8 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**

节食半个月属短期饥饿。维持血糖靠肝，顺序如下：

1. **激素切换**：胰岛素下降，胰高血糖素、肾上腺素、糖皮质激素升高。
2. **肝糖原分解**（最早、最快）：磷酸化酶活化，$\mathrm{G}$-$1$-$\mathrm{P}\rightarrow\mathrm{G}$-$6$-$\mathrm{P}$，肝有葡萄糖-$6$-磷酸酶，释出游离葡萄糖入血。肝糖原约 $16\sim 24$ 小时耗尽。肌糖原**不能**补血糖（肌无此酶）。
3. **糖异生增强**：乳酸（乳酸循环）、甘油（脂肪动员）、生糖氨基酸（肌蛋白 $\rightarrow$ 丙氨酸–葡萄糖循环）在肝写成葡萄糖。关键酶：丙酮酸羧化酶、$\mathrm{PEP}$ 羧激酶、果糖-$1,6$-二磷酸酶、葡萄糖-$6$-磷酸酶。乙酰 $\mathrm{CoA}$ **不能**净糖异生。
4. **节省葡萄糖**：脂肪动员加强，$\beta$-氧化供能；肝生酮，脑等逐渐利用酮体，减少葡萄糖消耗。头晕眼花提示一过性血糖偏低、脑葡萄糖供应不足。
:::

:::callout{kind=note label="知识卡片：饿了谁补血糖"}
| 时间 | 主要手段 |
|------|----------|
| 餐后数小时 | 肝糖原分解 |
| 糖原耗尽后 | 肝糖异生（乳酸、甘油、生糖氨基酸） |
| 更久 | 酮体供脑，蛋白质分解相对受抑 |

葡萄糖有氧氧化净 **30 或 32 ATP**；无氧酵解净 2 ATP。
:::

:::callout{kind=tip label="结论速记"}
饿时血糖：先**肝糖原**，再**肝异生**；肌糖原补不了血；脂供能、酮体省糖。
:::
