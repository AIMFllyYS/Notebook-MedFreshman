## 一、单项选择题（每题 0.5 分，共 20 分）

### 第1题

:::callout{kind=note label="题目"}
下列描述血红蛋白概念正确的是（　　）

A. 血红蛋白氧解离曲线为 S 形

B. 血红蛋白不属于变构蛋白

C. 1 个血红蛋白可与 1 个氧分子可逆结合

D. 血红蛋白是单亚基球蛋白
:::

:::callout{kind=insight label="解析"}
**【答案】A**

Hb 是 $\alpha_2\beta_2$ 四聚体变构蛋白，可结合 4 分子 $\mathrm{O}_2$，氧解离曲线呈 S 形（正协同）。B、C、D 均错。
:::

:::callout{kind=note label="知识卡片：S 形的意义"}
肺泡端 $\mathrm{PO}_2$ 波动时饱和度几乎不变；组织端低氧分压时大量放氧。$\mathrm{H}^+$、$\mathrm{CO}_2$、2,3-BPG 使曲线右移。
:::

:::callout{kind=tip label="结论速记"}
Hb 氧解离曲线 **S 形**；四亚基、变构、结合 4 个 $\mathrm{O}_2$。
:::

### 第2题

:::callout{kind=note label="题目"}
有关蛋白质三级结构的描述，错误的是（　　）

A. 具有三级结构的多肽链都有生物学活性

B. 亲水基团多位于三级结构的表面

C. 三级结构的稳定性由次级键维持

D. 三级结构是单体蛋白质或亚基的空间结构
:::

:::callout{kind=insight label="解析"}
**【答案】A**

三级结构是一条多肽链的空间结构，但酶原、单独一条 Hb 亚基等可以没有完整生物学活性；有的蛋白还要四级结构。B、C、D 正确：疏水核、亲水表面；次级键（及可有二硫键）维持；单体或亚基的构象就是三级。
:::

:::callout{kind=note label="知识卡片：四级才谈亚基装配"}
有三级不一定有活性；有活性也不一定已经是四级。
:::

:::callout{kind=tip label="结论速记"}
「有三级就有活性」是错的。
:::

常出现于肽链转角结构中的氨基酸为（　　）

A. 半胱氨酸　B. 脯氨酸　C. 丙氨酸　D. 谷氨酸

Pro、Gly 常在转角；Pro 也是 $\alpha$-螺旋的中断者。

:::callout{kind=tip label="结论速记"}
转角认 **脯氨酸**。

### 第6题

:::callout{kind=note label="题目"}
磺胺类药物的类似物是（　　）

A. 四氢叶酸　B. 二氢叶酸　C. 对氨基苯甲酸　D. 叶酸
:::

:::callout{kind=insight label="解析"}
**【答案】C**

磺胺与对氨基苯甲酸（PABA）结构相似，竞争二氢蝶酸合酶，阻断细菌叶酸合成。人直接利用食物叶酸，不受磺胺干扰。甲氨蝶呤才是叶酸类似物。
:::

:::callout{kind=note label="知识卡片：两套「叶酸药」"}
磺胺：打细菌 PABA。MTX：打 DHFR（叶酸／二氢叶酸类似）。
:::

:::callout{kind=tip label="结论速记"}
磺胺类似物是 **PABA**，不是叶酸。
:::

### 第7题

:::callout{kind=note label="题目"}
已知某种酶的 $K_\mathrm{m}$ 值为 $0.05\,\mathrm{mol}/\mathrm{L}$，要使此酶所催化的反应速度达最大反应速度的 $80\%$ 时底物浓度应是多少？（　　）

A. $0.04\,\mathrm{mol}/\mathrm{L}$　B. $0.05\,\mathrm{mol}/\mathrm{L}$　C. $0.1\,\mathrm{mol}/\mathrm{L}$　D. $0.2\,\mathrm{mol}/\mathrm{L}$
:::

:::callout{kind=insight label="解析"}
**【答案】D**

米氏方程 $v=V_{\max}[S]/([S]+K_\mathrm{m})$。令 $v=0.8V_{\max}$：

$$0.8=\frac{[S]}{[S]+0.05}\implies 0.8\times 0.05=0.2[S]\implies [S]=0.2\,\mathrm{mol}/\mathrm{L}$$

$v=V_{\max}/2$ 时 $[S]=K_\mathrm{m}=0.05$。
:::

:::callout{kind=note label="知识卡片：Km 定义"}
$K_\mathrm{m}$ 是 $v=V_{\max}/2$ 时的底物浓度，近似反映亲和力，$K_\mathrm{m}$ 越小亲和力越大。
:::

:::callout{kind=tip label="结论速记"}
$80\%\,V_{\max}$ 时 $[S]=4K_\mathrm{m}=0.2$。
:::

### 第8题

:::callout{kind=note label="题目"}
在血糖偏低时，大脑仍可摄取葡萄糖而肝脏则不能，其原因是（　　）

A. 胰岛素的作用

B. 己糖激酶的 $K_\mathrm{m}$ 低

C. 葡萄糖激酶的 $K_\mathrm{m}$ 低

D. 血脑屏障在血糖低时不起作用
:::

:::callout{kind=insight label="解析"}
**【答案】B**

脑等组织己糖激酶 $K_\mathrm{m}$ 很低，低血糖仍能磷酸化截留葡萄糖。肝葡萄糖激酶 $K_\mathrm{m}$ 高，血糖低时几乎不工作。C 把肝酶 $K_\mathrm{m}$ 说反了。
:::

:::callout{kind=note label="知识卡片：HK vs 葡萄糖激酶"}
| | 己糖激酶 I–III | 葡萄糖激酶（IV） |
|--|----------------|------------------|
| 分布 | 脑、肌等 | 肝、胰岛 $\beta$ |
| $K_\mathrm{m}$ | 低 | 高 |
| $\mathrm{G}6\mathrm{P}$ | 反馈抑制 | 不直接抑制 |
:::

:::callout{kind=tip label="结论速记"}
低血糖脑还能摄糖：脑己糖激酶 **Km 低**。
:::

### 第9题

:::callout{kind=note label="题目"}
下列哪种物质缺乏可引起血液丙酮酸含量升高？（　　）

A. 硫胺素　B. 叶酸　C. 吡哆醛　D. 维生素 $\mathrm{B}_{12}$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

$\mathrm{TPP}$、硫辛酸、$\mathrm{CoA}$（泛酸）、$\mathrm{FAD}$（$\mathrm{B}_2$）、$\mathrm{NAD}^+$（$\mathrm{PP}$）。脚气病即缺 $\mathrm{B}_1$。
:::

:::callout{kind=tip label="结论速记"}
血丙酮酸升高先想 **硫胺素（B1／TPP）**。
:::

### 第10题

:::callout{kind=note label="题目"}
在糖酵解过程中，下列哪个酶催化的反应是不可逆的？（　　）

A. 醛缩酶　B. 烯醇化酶　C. 丙酮酸激酶　D. 磷酸甘油酸激酶
:::

:::callout{kind=insight label="解析"}
**【答案】C**

酵解三步不可逆：己糖激酶、磷酸果糖激酶-1、丙酮酸激酶。磷酸甘油酸激酶可逆（糖异生原路返回）。
:::

:::callout{kind=note label="知识卡片：异生绕行"}
PK 由丙酮酸羧化酶 $+\mathrm{PEPCK}$ 绕过；PGK 不是关键酶。
:::

:::callout{kind=tip label="结论速记"}
选项里酵解不可逆只认 **丙酮酸激酶**。
:::

### 第11题

:::callout{kind=note label="题目"}
下列哪种糖代谢途径既不生成 $\mathrm{ATP}$ 或 $\mathrm{UTP}$ 也不消耗 $\mathrm{ATP}$ 或 $\mathrm{UTP}$？（　　）

A. 糖酵解　B. 糖原合成　C. 糖异生　D. 糖原分解
:::

:::callout{kind=insight label="解析"}
**【答案】D**

糖原磷酸化酶用无机磷酸，不耗 $\mathrm{ATP}$；脱支酶也不耗 $\mathrm{ATP}/\mathrm{UTP}$。糖原合成耗 $\mathrm{UTP}$；酵解、异生都有 $\mathrm{ATP}$ 账。
:::

:::callout{kind=note label="知识卡片：肌糖原无氧"}
肌糖原葡萄糖基无氧氧化绕过己糖激酶，净 3 $\mathrm{ATP}$（游离葡萄糖净 2）。
:::

:::callout{kind=tip label="结论速记"}
糖原分解 **不耗 ATP／UTP**。
:::

### 第12题

:::callout{kind=note label="题目"}
不能使甘油磷酸化的组织器官是（　　）

A. 肝脏　B. 肾脏　C. 小肠　D. 脂肪组织
:::

:::callout{kind=insight label="解析"}
**【答案】D**

脂肪组织缺乏甘油激酶，动员出的甘油必须运到肝（肾、小肠也有此酶）磷酸化。这是脂肪细胞不能再利用甘油成糖／再酯化的关键。
:::

:::callout{kind=note label="知识卡片：甘油去路"}
甘油激酶：甘油 $\rightarrow\alpha$-磷酸甘油 $\rightarrow$ 磷酸二羟丙酮，可酵解或异生。
:::

:::callout{kind=tip label="结论速记"}
脂肪组织 **没有甘油激酶**。
:::

### 第13题

:::callout{kind=note label="题目"}
脂酸合成的限速酶是（　　）

A. $\mathrm{HMG}$-$\mathrm{CoA}$ 合成酶　B. $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶　C. 乙酰 $\mathrm{CoA}$ 羧化酶　D. 肉碱脂酰转移酶
:::

:::callout{kind=insight label="解析"}

乙酰 $\mathrm{CoA}$ 羧化酶生成丙二酸单酰 $\mathrm{CoA}$，是脂酸合成限速酶。B 是胆固醇合成限速酶；D（$\mathrm{CPT}$-Ⅰ）是 $\beta$-氧化限速酶；$\mathrm{HMG}$-$\mathrm{CoA}$ 合成酶参与酮体／胆固醇。

:::callout{kind=note label="知识卡片：三条限速酶"}
脂酸合成：乙酰 $\mathrm{CoA}$ 羧化酶。$\beta$-氧化：$\mathrm{CPT}$-Ⅰ。胆固醇：$\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶。
:::

:::callout{kind=tip label="结论速记"}
脂酸合成限速酶 **乙酰 CoA 羧化酶**。
:::

### 第16题

:::callout{kind=note label="题目"}
脂肪酸 $\beta$-氧化、酮体生成及胆固醇合成的共同中间产物是（　　）

A. 乙酰 $\mathrm{CoA}$　B. 乙酰乙酰 $\mathrm{CoA}$　C. $\mathrm{HMG}$-$\mathrm{CoA}$　D. 乙酰乙酸
:::

:::callout{kind=insight label="解析"}
**【答案】A**（源标准答案）

三条路都经过乙酰 $\mathrm{CoA}$。乙酰乙酰 $\mathrm{CoA}$、$\mathrm{HMG}$-$\mathrm{CoA}$ 是酮体与胆固醇更近的共同物，但 $\beta$-氧化的常规产物账记为乙酰 $\mathrm{CoA}$；$\mathrm{HMG}$-$\mathrm{CoA}$ 不是 $\beta$-氧化中间物。本卷选 A。
:::

:::callout{kind=note label="知识卡片：HMG-CoA 两户"}
酮体：$\mathrm{HMG}$-$\mathrm{CoA}$ 合酶／裂解酶（肝线粒体）。胆固醇：胞质 $\mathrm{HMG}$-$\mathrm{CoA}$ 还原酶限速。
:::

:::callout{kind=tip label="结论速记"}
本卷：$\beta$-氧化、生酮、胆固醇共同中间物 **乙酰 CoA**。
:::

### 第17题

生物体内 $\mathrm{ATP}$ 生成的方式有（　　）

A. 1 种　B. 2 种　C. 3 种　D. 4 种

:::callout{kind=insight label="解析"}

:::

:::callout{kind=tip label="结论速记"}
人体 ATP：**2 种**（底物水平 $+$ 氧化磷酸化）。
:::

有实验表明大量摄入高碳水化合物后，细胞内 6-磷酸葡萄糖脱氢酶的含量会升高。请分析原因。（6 分）

## 六、论述题（共 20 分）

### 第1题

:::callout{kind=note label="题目"}
试结合 $\mathrm{cAMP}$-蛋白激酶途径，阐明胰高血糖素调节糖原代谢的机制。（12 分）
:::

:::figure{src="/images/biochemistry/exam-03/dd2531793e3e0d02.jpeg" alt="糖原合成与分解的共价修饰调节" caption="原卷配图：胰高血糖素／肾上腺素经 cAMP-PKA 调节糖原合酶与磷酸化酶（教材图 5-12 同类）"}
:::

:::callout{kind=insight label="解析"}
**【答案】**（源要点，激素写胰高血糖素／肾上腺素 $\beta$ 受体同一条路）

胰高血糖素 $+$ 受体 $\rightarrow$ 活性 $\mathrm{G}_\mathrm{s}$ $\rightarrow$ 活性腺苷酸环化酶 $\rightarrow\mathrm{ATP}\rightarrow\mathrm{cAMP}$ $\rightarrow$ 活性 $\mathrm{PKA}$。

$\mathrm{PKA}$ 使磷酸化酶 $b$ 激酶磷酸化活化 $\rightarrow$ 磷酸化酶 $b\rightarrow a$ $\rightarrow$ 糖原分解为葡萄糖（肝经葡萄糖-6-磷酸酶入血）。

同时 $\mathrm{PKA}$ 使糖原合酶Ⅰ（活性）$\rightarrow$ 糖原合酶 D（无活性），停止合成。

还需考虑磷蛋白磷酸酶的调节。最好还有 $\mathrm{PKA}$ 通过 $\mathrm{CREB}$ 调节糖原代谢相关酶的基因表达。
:::

:::callout{kind=note label="知识卡片：开分解关合成"}
同一 $\mathrm{PKA}$：开磷酸化酶级联，关糖原合酶。磷蛋白磷酸酶-1 被抑制时分解占优。
:::

:::callout{kind=tip label="结论速记"}
胰高血糖素：$\mathrm{cAMP}$-$\mathrm{PKA}$ $\rightarrow$ **糖原分解开、合酶关**。
:::

### 第2题

:::callout{kind=note label="题目"}
试述脂肪动员生成的甘油彻底氧化分解的主要过程。（8 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**（源要点）甘油氧化供能分三阶段：

1. 甘油 $\rightarrow\alpha$-磷酸甘油 $\rightarrow$ 磷酸二羟丙酮，后者沿糖酵解途径分解为丙酮酸。
2. 丙酮酸进入线粒体氧化脱羧生成乙酰 $\mathrm{CoA}$。
3. 乙酰 $\mathrm{CoA}$ 进入三羧酸循环及氧化磷酸化彻底氧化生成 $\mathrm{CO}_2$、$\mathrm{H}_2\mathrm{O}$ 和 $\mathrm{ATP}$。

脂肪组织缺甘油激酶，甘油主要在肝磷酸化。彻底氧化的 $\mathrm{ATP}$ 按本版 $\mathrm{NADH}=2.5$、$\mathrm{FADH}_2=1.5$ 计，不要用旧口诀 36/38；葡萄糖彻底氧化净 **30 或 32 ATP** 是同一套计账。
:::

:::callout{kind=note label="知识卡片：甘油进酵解的接口"}
磷酸二羟丙酮 $\leftrightarrow$ 3-磷酸甘油醛，汇入酵解／异生。甘油可以糖异生；偶数碳脂酸不能。
:::

:::callout{kind=tip label="结论速记"}
甘油 $\rightarrow$ DHAP $\rightarrow$ 丙酮酸 $\rightarrow$ 乙酰 CoA $\rightarrow$ TCA $+$ 氧化磷酸化。
:::
