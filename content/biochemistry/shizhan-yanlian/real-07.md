## 二、名词解释（每词 2 分，共 10 分）

### 第1题

:::callout{kind=note label="题目"}
结构域
:::

:::callout{kind=insight label="解析"}
**【答案】**

结构域（domain）是一条多肽链在三级结构内部折叠成的、相对独立的球状区域。各结构域可有相对独立的功能（如结合底物、结合辅酶、调节）。它是**三级结构内部**的分户，不是四级结构的亚基。
:::

:::callout{kind=note label="知识卡片：结构域 vs 亚基 vs 模体"}
| | 层次 | 是什么 |
|--|------|--------|
| 模体（motif） | 二级／超二级 | 几个二级结构元件的组合 |
| 结构域 | 三级内部 | 同一条肽链上相对独立折叠的区段 |
| 亚基 | 四级 | 寡聚体里各有三级结构的多肽链 |
:::

:::callout{kind=tip label="结论速记"}
结构域 $=$ 一条肽链里**相对独立折叠**的功能区；不要答成亚基。
:::

---

### 第2题

:::callout{kind=note label="题目"}
必需氨基酸
:::

:::callout{kind=insight label="解析"}
**【答案】**

必需氨基酸（essential amino acid）是人体需要又不能自身合成（或合成不足）、必须由食物供给的氨基酸。本版营养必需氨基酸 **9 种**：亮氨酸、异亮氨酸、苏氨酸、缬氨酸、赖氨酸、甲硫氨酸、苯丙氨酸、色氨酸、**组氨酸**。
:::

:::callout{kind=note label="知识卡片：半必需不要抢户"}
酪氨酸可由苯丙氨酸生成，半胱氨酸可由甲硫氨酸生成，膳食里这两种够时对相应必需氨基酸的需求下降，但名解名单仍是 9 种。婴儿／儿童组氨酸必需，本版把组氨酸写进名单。
:::

:::callout{kind=tip label="结论速记"}
必需氨基酸 9 种：**亮异苏缬赖，甲硫苯丙色组**。
:::

### 第3题

:::callout{kind=note label="题目"}
转录因子
:::

:::callout{kind=insight label="解析"}
**【答案】**

转录因子（transcription factor）是能与基因的顺式作用元件结合、调节转录的蛋白质（反式作用因子的主体）。基本转录因子（如 $\mathrm{TFII}$ 家族）协助 $\mathrm{RNA}$ 聚合酶Ⅱ在启动子上装配起始前复合物；特异转录因子结合增强子／沉默子等，激活或阻遏转录。
:::

:::callout{kind=note label="知识卡片：顺式 vs 反式"}
顺式作用元件是 $\mathrm{DNA}$ 序列（启动子、增强子、沉默子、绝缘子）。反式作用因子是蛋白（转录因子）。转录因子常有 $\mathrm{DNA}$ 结合域 $+$ 转录激活／抑制域。
:::

:::callout{kind=tip label="结论速记"}
转录因子 $=$ 绑 $\mathrm{DNA}$ 调控元件的**蛋白质**，反式调节转录。
:::

### 第4题

:::callout{kind=note label="题目"}
PCR 技术
:::

:::callout{kind=insight label="解析"}
**【答案】**

聚合酶链式反应（polymerase chain reaction，$\mathrm{PCR}$）是体外酶促扩增特异 $\mathrm{DNA}$ 片段的技术。典型循环：变性（解开双链）$\rightarrow$ 退火（引物按碱基互补结合模板）$\rightarrow$ 延伸（耐热 $\mathrm{DNA}$ 聚合酶按 $5'\rightarrow 3'$ 合成）。反复循环使目的片段指数扩增。
:::

:::callout{kind=note label="知识卡片：PCR 三件套"}
模板 $\mathrm{DNA}$、一对引物、$\mathrm{dNTP}$、耐热聚合酶（如 $\mathrm{Taq}$）、合适离子与缓冲。已知一段序列时，获取目的 $\mathrm{DNA}$ 最常用的就是 $\mathrm{PCR}$。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{PCR}$：变性–退火–延伸，体外把特异 $\mathrm{DNA}$ **指数扩增**。
:::

### 第5题

:::callout{kind=note label="题目"}
初级胆汁酸
:::

:::callout{kind=insight label="解析"}
**【答案】**

初级胆汁酸（primary bile acid）是肝以胆固醇为原料直接合成的胆汁酸，人主要是**胆酸**和**鹅脱氧胆酸**，可与甘氨酸或牛磺酸结合成结合型初级胆汁酸（甘氨胆酸、牛磺胆酸等）。在肠道被细菌 $7\alpha$-脱羟基后变成次级胆汁酸（脱氧胆酸、石胆酸）。
:::

:::callout{kind=note label="知识卡片：初级 vs 次级 vs 结合"}
| | 代表 |
|--|------|
| 初级 | 胆酸、鹅脱氧胆酸（肝合成） |
| 次级 | 脱氧胆酸、石胆酸（肠菌改造） |
| 结合 | 与甘氨酸／牛磺酸结合（初级、次级都可以结合） |

结合胆红素是胆红素–葡糖醛酸，不要和结合胆汁酸并户。
:::

:::callout{kind=tip label="结论速记"}
初级胆汁酸 $=$ 肝从胆固醇写出的**胆酸、鹅脱氧胆酸**。
:::

## 四、简答题（每题 5 分，共 20 分）

### 第1题

:::callout{kind=note label="题目"}
血浆脂蛋白的来源与功能
:::

:::callout{kind=insight label="解析"}
**【答案】**

血浆脂蛋白是血脂的运输形式，使不溶于水的脂质能在血浆中转运。

| 脂蛋白 | 主要来源 | 主要功能 |
|--------|----------|----------|
| $\mathrm{CM}$ | 小肠（外源性脂） | 转运**外源性**甘油三酯及胆固醇 |
| $\mathrm{VLDL}$ | 肝 | 转运**内源性**甘油三酯（及部分胆固醇） |
| $\mathrm{LDL}$ | 血浆中由 $\mathrm{VLDL}$ 转变 | 转运内源性胆固醇至外周组织 |
| $\mathrm{HDL}$ | 肝、小肠 | 逆向转运胆固醇（外周 $\rightarrow$ 肝） |

载脂蛋白还激活酶（$\mathrm{apoC\,II}$ 激活 $\mathrm{LPL}$）和识别受体（$\mathrm{apoB100}$、$\mathrm{apoE}$、$\mathrm{apoA\,I}$）。
:::

:::callout{kind=note label="知识卡片：密度口诀"}
密度 $\mathrm{CM}<\mathrm{VLDL}<\mathrm{LDL}<\mathrm{HDL}$。$\mathrm{LDL}$ 不是肝直接分泌。内源性胆固醇主要靠 $\mathrm{LDL}$ 运到外周。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{CM}$ 外源 $\mathrm{TG}$；$\mathrm{VLDL}$ 内源 $\mathrm{TG}$；$\mathrm{LDL}$ 送胆固醇出去；$\mathrm{HDL}$ 运回肝。
:::

---

### 第2题

:::callout{kind=note label="题目"}
生物转化的定义与意义
:::

:::callout{kind=insight label="解析"}
**【答案】**

**定义**：生物转化（biotransformation）是非营养性物质在体内（主要在肝）经过氧化、还原、水解和结合等代谢转变，使其极性、水溶性改变以便排出的过程。对象包括药物、毒物、肠道腐败产物及体内激素、胆红素等。

**反应分相**：第一相为氧化、还原、水解（微粒体单加氧酶等）；第二相为结合（葡糖醛酸、硫酸、乙酰基、谷胱甘肽、甘氨酸等）。

**意义**

1. 多数情况下降低生物活性／毒性，增加水溶性，利于经肾或胆汁排出。
2. 有些物质经转化后活性或毒性反而增高（活化、致毒），故不是「一律解毒」。
3. 是药物代谢、激素灭活、胆红素处理的基础。
:::

:::callout{kind=note label="知识卡片：第一相不是结合"}
结合反应是第二相。单加氧酶（细胞色素 $\mathrm{P450}$）在**微粒体**（滑面内质网）。
:::

:::callout{kind=tip label="结论速记"}
生物转化：肝处理非营养物；**多数解毒，偶尔致毒**；Ⅰ相氧化还原水解，Ⅱ相结合。
:::

### 第3题

:::callout{kind=note label="题目"}
真核 $\mathrm{mRNA}$ 加工
:::

:::callout{kind=insight label="解析"}
**【答案】**

真核蛋白编码基因先转录出 $\mathrm{hnRNA}$（前体 $\mathrm{mRNA}$），在核内加工为成熟 $\mathrm{mRNA}$：

1. **$5'$ 端加帽**：7-甲基鸟苷帽（$\mathrm{m}^7\mathrm{GpppN}$），保护 $5'$ 端、协助输出与翻译起始。
2. **$3'$ 端加多聚 $\mathrm{A}$ 尾**：切在加尾信号下游，再加 $\mathrm{poly}(\mathrm{A})$，稳定 $\mathrm{mRNA}$、协助翻译。
3. **剪接**：切除内含子、连接外显子（可有可变剪接）。
4. 部分碱基修饰（甲基化等）。

加 $\mathrm{CCA}$ 是 $\mathrm{tRNA}$ 氨基酸臂的加工，**不是** $\mathrm{mRNA}$ 的步骤。
:::

:::callout{kind=note label="知识卡片：三种 RNA 加工不要串"}
| | 帽子 / polyA | 剪接 | $3'$-$\mathrm{CCA}$ |
|--|-------------|------|-------------------|
| $\mathrm{mRNA}$ | 有 | 有 | 无 |
| $\mathrm{tRNA}$ | 无 | 可有 | **有** |
| $\mathrm{rRNA}$ | 无 | 切割、修饰 | 无 |
:::

:::callout{kind=tip label="结论速记"}
真核 $\mathrm{mRNA}$：帽 $+$ polyA $+$ 剪接；**不要写 CCA**。
:::

### 第4题

:::callout{kind=note label="题目"}
$\mathrm{DNA}$ 重组的步骤
:::

:::callout{kind=insight label="解析"}
**【答案】**

本场与「分子克隆／基因工程」同一套步骤（分、选、连、转、筛）：

1. **分**：获取目的 $\mathrm{DNA}$（限制酶切、$\mathrm{PCR}$、$\mathrm{cDNA}$ 等）。
2. **选**：选择并准备载体（能自主复制、有筛选标记、有合适酶切位点）。
3. **连**：目的片段与载体在 $\mathrm{DNA}$ 连接酶作用下形成重组 $\mathrm{DNA}$。
4. **转**：将重组体转入受体细胞（转化、转染、转导等）。
5. **筛**：筛选、鉴定阳性重组体（抗性、蓝白斑、酶切、杂交、测序等）并扩增。

若按细胞内同源重组答：断裂 $\rightarrow$ 联会／链侵入 $\rightarrow$ 异源双链与霍利迪连接体 $\rightarrow$ 切开拆分。医学生化期末通常按克隆五步给分。
:::

:::callout{kind=note label="知识卡片：限制酶认回文"}
重组体外操作靠限制性核酸内切酶识别回文序列并切割。载体「自主复制」是选择标准之一。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{DNA}$ 重组（克隆）：**分、选、连、转、筛**。
:::

## 五、案例分析（12 分）

### 第1题

:::callout{kind=note label="题目"}
酮体定义？为什么肝内生成肝外利用？
:::

:::callout{kind=insight label="解析"}
**【答案】**

**定义**：酮体（ketone bodies）是脂酸在肝分解氧化时产生的中间产物，包括**乙酰乙酸、$\beta$-羟丁酸和丙酮**。

**肝内生成**：饥饿、糖供不足时，脂肪动员，$\beta$-氧化在肝线粒体产生大量乙酰 $\mathrm{CoA}$。草酰乙酸优先走糖异生，乙酰 $\mathrm{CoA}$ 与草酰乙酸缩合成柠檬酸受阻，乙酰 $\mathrm{CoA}$ 转向酮体：2 乙酰 $\mathrm{CoA}\rightarrow$ 乙酰乙酰 $\mathrm{CoA}\xrightarrow{+\text{乙酰 CoA}}$ $\mathrm{HMG}$-$\mathrm{CoA}$（$\mathrm{HMG}$-$\mathrm{CoA}$ 合酶）$\rightarrow$ 乙酰乙酸（$\mathrm{HMG}$-$\mathrm{CoA}$ 裂解酶）$\rightarrow\beta$-羟丁酸／丙酮。限速相关酶在**肝线粒体**丰富。

**肝外利用**：肝缺乏利用酮体的关键酶（琥珀酰 $\mathrm{CoA}$ 转硫酶／乙酰乙酸硫激酶等），不能把酮体变回乙酰 $\mathrm{CoA}$。心、肾、骨骼肌、脑（饥饿时）有这些酶：酮体 $\rightarrow$ 乙酰 $\mathrm{CoA}\rightarrow$ 三羧酸循环 $+$ 氧化磷酸化供能。丙酮主要经肺呼出。

因而：**肝是工厂，自己不用；肝外是用户。**
:::

:::callout{kind=note label="知识卡片：酮体 vs 胆固醇的交叉口"}
$\mathrm{HMG}$-$\mathrm{CoA}$ 既是酮体（线粒体）也是胆固醇合成（胞质）的中间物，分室。酮体不是草酰乙酸、不是丙酮酸。
:::

:::callout{kind=tip label="结论速记"}
酮体 $=$ 乙酰乙酸 $+\beta$-羟丁酸 $+$ 丙酮；**肝生成、肝外用**。
:::

### 第2题

:::callout{kind=note label="题目"}
生酮饮食对于健康的影响？你的看法？
:::

:::callout{kind=insight label="解析"}
**【答案】**（开放题，按生化机制答，不要空喊口号）

生酮饮食：极低碳水化合物、充足脂肪、适当蛋白质，迫使肝大量生酮，血酮体升高，脑等改用酮体省糖。

**可能的益处（机制）**

1. 降低对葡萄糖的依赖，减少胰岛素高峰，有助于减重、改善部分胰岛素抵抗。
2. 酮体可供脑，癫痫等神经疾病有临床应用传统。
3. 脂肪动员、$\beta$-氧化加强，甘油可糖异生，血糖在肝糖原耗尽后靠异生维持。

**风险与限度**

1. **酮症酸中毒**：糖尿病（尤其 1 型）胰岛素严重缺乏时，酮体生成失控，乙酰乙酸、$\beta$-羟丁酸是酸，可致命。健康人通常停在「生理性酮症」。
2. 高脂负荷：$\mathrm{LDL}$ 胆固醇、甘油三酯可能升高，动脉粥样硬化风险因人而异。
3. 糖异生耗成蛋白、电解质紊乱、便秘、微量营养素不足；孕妇、肝肾功能不全、脂代谢病不宜自行长期生酮。
4. 葡萄糖仍是红细胞等的必需燃料（无线粒体）；脑也不能零糖。本版葡萄糖彻底氧化净 **30 或 32 ATP**；酮体供能是「省糖」，不是「不需要糖」。

**看法**：生酮饮食是把脂质代谢推向「肝生酮、肝外用」的极端膳食，短期在医疗监护下可用于特定适应证；不能当成全民减肥特效，更不能与糖尿病酮症酸中毒混为一谈。
:::

:::callout{kind=note label="知识卡片：本场为什么不考阿英"}
源提纲强调：今年没出阿英减肥或 $\mathrm{GPCR}$，但酮体仍是脂代谢。三大代谢要串：糖不足 $\rightarrow$ 脂动员 $\rightarrow$ 肝生酮 $\rightarrow$ 省糖。
:::

:::callout{kind=tip label="结论速记"}
生酮饮食 $=$ 人为推高酮体；能省糖，但有酮症酸中毒和高脂风险。
:::
