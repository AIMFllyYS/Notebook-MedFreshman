## Ⅱ. Explain the following terms（每词 2 分，共 16 分）

### 第1题

:::callout{kind=note label="题目"}
genome
:::

:::callout{kind=insight label="解析"}
**【答案】**

Genome：生物体或细胞中一套完整单体具有的遗传信息的总和。人类基因组包括核染色体 $\mathrm{DNA}$ 和线粒体 $\mathrm{DNA}$。
:::

:::callout{kind=note label="知识卡片：genome vs gene"}
gene 是编码蛋白质或 $\mathrm{RNA}$ 的基本单位；genome 是整套信息（含重复序列、调控区、$\mathrm{mtDNA}$），不是基因名单。
:::

:::callout{kind=tip label="结论速记"}
genome $=$ **基因组** $=$ 一套完整遗传信息。
:::

---

### 第2题

:::callout{kind=note label="题目"}
active center of enzyme
:::

:::callout{kind=insight label="解析"}
**【答案】**

酶的活性中心（active center / active site）：酶分子中能与底物特异结合并催化底物转变为产物的区域。内有结合基团与催化基团；辅酶／辅基常参与构成。中心外还有维持构象的必需基团。
:::

:::callout{kind=note label="知识卡片：必需基团三户"}
结合基团认底物；催化基团改化学键；中心外必需基团维持构象或结合调节剂。常见：Ser-OH、His 咪唑、Cys-SH、酸性氨基酸羧基。
:::

:::callout{kind=tip label="结论速记"}
活性中心 $=$ 结合 $+$ 催化的那一块口袋。
:::

---

### 第3题

:::callout{kind=note label="题目"}
oncogene
:::

:::callout{kind=insight label="解析"}
**【答案】**

癌基因（oncogene）：能导致细胞恶性转化并诱发癌症的基因。绝大多数由细胞内正常原癌基因突变或过表达而来；某些病毒也携带。原癌基因在正常条件下无致癌活性。
:::

:::callout{kind=note label="知识卡片：三户基因"}
原癌基因促增殖；抑癌基因抑增殖；基因组维护基因修 $\mathrm{DNA}$。癌基因是原癌基因**活化之后**的名字。
:::

:::callout{kind=tip label="结论速记"}
oncogene $=$ 癌基因；正常细胞里先有的是 **proto-oncogene**。
:::

---

### 第4题

:::callout{kind=note label="题目"}
biotransformation
:::

:::callout{kind=insight label="解析"}
**【答案】**

生物转化（biotransformation）：机体将内源性或外源性非营养物质进行化学转变，增加其水溶性和极性，使之易于经胆汁或尿排出。肝是最重要器官。不一定「解毒」——有时反而活化。
:::

:::callout{kind=note label="知识卡片：两相"}
I 相：氧化、还原、水解（微粒体单加氧酶等）。II 相：结合（$\mathrm{UDPGA}$、$\mathrm{PAPS}$、$\mathrm{SAM}$、甘氨酸等活性供体）。
:::

:::callout{kind=tip label="结论速记"}
生物转化 $=$ 非营养物改变化学结构、**增加极性好排出**；主场在肝。
:::

---

### 第5题

:::callout{kind=note label="题目"}
cis-acting element
:::

:::callout{kind=insight label="解析"}
**【答案】**

顺式作用元件（cis-acting element）：与被调控编码序列位于同一条 $\mathrm{DNA}$ 分子上、能影响该基因表达活性的调控序列，如启动子、上游元件、增强子、绝缘子、加尾信号等。结合在这些序列上的蛋白质是反式作用因子。
:::

:::callout{kind=note label="知识卡片：顺式 vs 反式"}
顺式：$\mathrm{DNA}$ 序列本身，与靶基因同分子。反式：先表达出蛋白质（或调节 $\mathrm{RNA}$）再来认元件。
:::

:::callout{kind=tip label="结论速记"}
cis-acting element $=$ 同分子上的 **DNA 调控序列**，不是蛋白质。
:::

---

### 第6题

:::callout{kind=note label="题目"}
DNA denaturation
:::

:::callout{kind=insight label="解析"}
**【答案】**

$\mathrm{DNA}$ 变性：极端理化条件断裂互补碱基对氢键并破坏碱基堆积力，双链解离为单链。空间结构破坏，核苷酸序列不变。伴 $260\,\mathrm{nm}$ 增色效应；$T_\mathrm{m}$ 为约 $50\%$ 双链解开时的温度。
:::

:::callout{kind=note label="知识卡片：Tm"}
$\mathrm{GC}$ 越高、$T_\mathrm{m}$ 越高（三氢键）。离子强度升高 $T_\mathrm{m}$ 也升高。短寡核苷酸可用 $T_\mathrm{m}=4(G+C)+2(A+T)$ 估算。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{DNA}$ 变性 $=$ 拆双链，**不改序列**。
:::

---

### 第7题

:::callout{kind=note label="题目"}
gene therapy
:::

:::callout{kind=insight label="解析"}
**【答案】**

基因治疗（gene therapy）：以改变人遗传物质为基础，通过基因转移将正常基因或有治疗作用的基因导入人体靶细胞，以修正、替代或补偿缺陷基因功能，或干扰致病基因异常表达，从而在基因水平上治疗疾病。
:::

:::callout{kind=note label="知识卡片：两件事"}
① 补／改缺陷基因的功能；② 干扰致病基因的异常表达。范围已从单基因病扩展到肿瘤、心血管、神经、代谢病等。
:::

:::callout{kind=tip label="结论速记"}
gene therapy $=$ 在核酸水平上把基因送进去治病。
:::

### 第8题

:::callout{kind=note label="题目"}
bile pigment
:::

:::callout{kind=insight label="解析"}
**【答案】**

胆色素（bile pigment）：体内铁卟啉化合物的主要分解代谢产物，包括胆绿素、胆红素、胆素原和胆素。胆红素居中心，呈橙黄色，是胆汁主要色素。血红素不是胆色素。
:::

:::callout{kind=note label="知识卡片：生成顺序"}
血红素 $\rightarrow$ 胆绿素 $\rightarrow$ 胆红素 $\rightarrow$ 胆素原 $\rightarrow$ 胆素。黄疸看胆红素。
:::

:::callout{kind=tip label="结论速记"}
bile pigment $=$ 胆绿素、胆红素、胆素原、胆素；**中心是胆红素**。
:::

## Ⅳ. Answer the following questions briefly（共 30 分）

### 第1题

:::callout{kind=note label="题目"}
Describe briefly the physiological function of plasma lipoprotein.（4 scores）
:::

:::callout{kind=insight label="解析"}
**【答案】**

血浆脂蛋白是血脂的运输及代谢形式，使不溶于水的脂质能在血浆中转运。

| 脂蛋白 | 主要功能 |
|--------|----------|
| $\mathrm{CM}$ | 转运**外源性**甘油三酯及胆固醇 |
| $\mathrm{VLDL}$ | 转运**内源性**甘油三酯及胆固醇 |
| $\mathrm{LDL}$ | 转运内源性胆固醇至外周组织 |
| $\mathrm{HDL}$ | 逆向转运胆固醇（外周 $\rightarrow$ 肝） |

载脂蛋白还激活酶（如 $\mathrm{apoC\,II}$ 激活 $\mathrm{LPL}$）、识别受体（$\mathrm{apoB100}$、$\mathrm{apoE}$、$\mathrm{apoA\,I}$）。
:::

:::callout{kind=note label="知识卡片：密度与电泳"}
密度：$\mathrm{CM}<\mathrm{VLDL}<\mathrm{LDL}<\mathrm{HDL}$。电泳：$\mathrm{CM}$ 原点、$\mathrm{LDL}$ 为 $\beta$、$\mathrm{VLDL}$ 前 $\beta$、$\mathrm{HDL}$ 为 $\alpha$。$\mathrm{LDL}$ 在血浆由 $\mathrm{VLDL}$ 转变而来，不是肝直接分泌。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{CM}$ 外源 $\mathrm{TG}$；$\mathrm{VLDL}$ 内源 $\mathrm{TG}$；$\mathrm{LDL}$ 送胆固醇出去；$\mathrm{HDL}$ 把胆固醇运回肝。
:::

### 第2题

:::callout{kind=note label="题目"}
For someone’s opinion the decoupling agent is a better diet drug, please explain the biochemical reason.（5 scores）
:::

:::callout{kind=insight label="解析"}
**【答案】**

解偶联剂（uncoupler，如 $\mathrm{DNP}$）使氧化与磷酸化分离：电子仍沿呼吸链传递、氧仍被消耗，但质子电化学梯度被破坏，$\mathrm{ATP}$ 合酶不能合成 $\mathrm{ATP}$，能量以**热**释放。

「当作减肥药」的生化理由：细胞 $\mathrm{ATP}$ 下降 $\rightarrow$ 呼吸加快、燃料（尤其脂肪酸、糖）氧化加速，体重可下降。

反对／危险：① 生命活动缺 $\mathrm{ATP}$（肌肉无力、器官衰竭）；② 产热过度（高热）；③ 补偿性分解加强可损伤组织。故解偶联剂**不是**安全减肥药。本版葡萄糖彻底氧化净 **30 或 32 ATP** 的前提是偶联完整；解偶联后这笔账作废，能量变热。
:::

:::callout{kind=note label="知识卡片：解偶联不是抑制呼吸链"}
$\mathrm{DNP}$ 脂溶性，在内膜来回携带 $\mathrm{H}^{+}$，拆掉膜间隙质子梯度。复合体Ⅰ–Ⅳ仍可工作。棕色脂肪 $\mathrm{UCP}$-$1$ 是生理性解偶联（产热）。
:::

:::callout{kind=tip label="结论速记"}
解偶联：氧还在耗、**ATP 没了、变成热**——能「瘦」但不安全。
:::

### 第3题

:::callout{kind=note label="题目"}
The research indicates that there are relationships between the occurrence of harelip and the deficiency of folic acid in the forepart of pregnant, please explain it on the basis of biochemistry.（5 scores）
:::

:::callout{kind=insight label="解析"}
**【答案】**

叶酸在体内还原为四氢叶酸（$\mathrm{FH}_4$），是**一碳单位**的载体。一碳单位参与：

1. 嘌呤从头合成（$\mathrm{C}8$、$\mathrm{C}2$ 来自甲酰基）。
2. $\mathrm{dUMP}\rightarrow\mathrm{dTMP}$（胸苷酸合酶，需 $N^5,N^{10}$-亚甲基 $\mathrm{FH}_4$）。
3. 甲硫氨酸循环（与维生素 $\mathrm{B}_{12}$ 协同），提供甲基化（$\mathrm{SAM}$）供体，影响 $\mathrm{DNA}$／组蛋白甲基化。

胚胎早期（唇腭融合、神经管闭合）细胞增殖极快，需要大量核苷酸和甲基化调控。孕早期缺叶酸 $\rightarrow$ $\mathrm{DNA}$ 合成与甲基化不足 $\rightarrow$ 细胞增殖／分化障碍 $\rightarrow$ 唇裂（harelip）、腭裂及神经管畸形风险升高。故孕前及孕早期需补叶酸。
:::

:::callout{kind=note label="知识卡片：一碳单位不是 CO2"}
$\mathrm{CO}_2$ 不是一碳单位。一碳单位来自 Ser、Gly、His、Trp 等，载在 $\mathrm{FH}_4$ 上。磺胺抑菌是因为细菌要自己用 PABA 合成叶酸，人直接利用食物叶酸。
:::

:::callout{kind=tip label="结论速记"}
孕早期缺叶酸 $\rightarrow$ $\mathrm{FH}_4$ 一碳单位不够 $\rightarrow$ **核苷酸 $+$ 甲基化**跟不上 $\rightarrow$ 唇裂／神经管畸形。
:::

### 第4题

:::callout{kind=note label="题目"}
What is operon? Please explain the function of each part of operon.（5 scores）
:::

:::callout{kind=insight label="解析"}
**【答案】**

操纵子（operon）是原核生物的基本转录单位，由结构基因加上其上游的启动子和操纵序列（及相关调控位点）构成。

| 组成部分 | 作用 |
|----------|------|
| 启动序列（promoter） | $\mathrm{RNA}$ 聚合酶识别、结合并启动转录 |
| 操纵序列（operator） | 阻遏蛋白结合位点，控制 $\mathrm{RNA}$ 聚合酶能否通过 |
| 结构基因 | 编码多肽（乳糖操纵子为 $Z$、$Y$、$A$） |
| 调控基因（如 $I$） | 编码阻遏蛋白，本身可有独立启动子 |
| $\mathrm{CAP}$ 位点 | 正性调控：$\mathrm{cAMP}$-$\mathrm{CAP}$ 结合促进转录 |

乳糖操纵子：有乳糖时阻遏蛋白变构脱落（去阻遏）；无葡萄糖时 $\mathrm{cAMP}$ 高，$\mathrm{CAP}$ 正性激活。
:::

:::callout{kind=note label="知识卡片：03 级原卷要点"}
操纵子 $=$ 结构基因 $+$ 上游启动子 $+$ 操纵基因。启动序列：$\mathrm{RNA}$ 聚合酶结合；操纵序列：阻遏蛋白结合；结构基因：编码氨基酸信息。
:::

:::callout{kind=tip label="结论速记"}
操纵子 $=$ 原核一套共转录单位；**启动子结合 RNA 聚合酶，操纵序列结合阻遏蛋白**。
:::

### 第5题

:::callout{kind=note label="题目"}
叙述 Fas 介导的细胞凋亡过程（5 分）（中文作答）
:::

:::callout{kind=insight label="解析"}
**【答案】**

Fas（$\mathrm{CD}95$）是细胞膜死亡受体，其配体为 FasL。

1. FasL 与靶细胞表面 Fas 结合，Fas 胞内死亡结构域（$\mathrm{DD}$）募集衔接蛋白 $\mathrm{FADD}$。
2. $\mathrm{FADD}$ 通过死亡效应结构域（$\mathrm{DED}$）募集 procaspase-8，组装成死亡诱导信号复合体（$\mathrm{DISC}$）。
3. procaspase-8 邻近活化为 caspase-8。
4. caspase-8 直接激活下游执行者 caspase-3／-6／-7（外源性途径）；也可切割 Bid $\rightarrow$ tBid，引起线粒体释放细胞色素 $c$，衔接内源性途径。
5. 执行 caspase 降解核纤层、$\mathrm{ICAD}$ 等，出现 DNA 片段化、膜泡、凋亡小体，细胞程序化死亡。
:::

:::callout{kind=note label="知识卡片：外源 vs 内源凋亡"}
| | 起始 | 关键分子 |
|--|------|----------|
| 外源（死亡受体） | FasL-Fas、TNF 等 | FADD、caspase-8 |
| 内源（线粒体） | $\mathrm{DNA}$ 损伤、缺 $\mathrm{ATP}$ 等 | Cyt $c$、Apaf-1、caspase-9 |

两条路在 caspase-3 汇合。
:::

:::callout{kind=tip label="结论速记"}
FasL-Fas $\rightarrow$ FADD $\rightarrow$ caspase-8 $\rightarrow$ caspase-3 $\rightarrow$ 凋亡。
:::

### 第6题

:::callout{kind=note label="题目"}
结合所做的分子生物学实验，说明 DNA 克隆的基本过程（6 分）（中文作答）
:::

:::callout{kind=insight label="解析"}
**【答案】**

$\mathrm{DNA}$ 克隆（分子克隆）五步，对应实验课常用质粒克隆：

1. **分**：限制性核酸内切酶切取目的 $\mathrm{DNA}$（或 $\mathrm{PCR}$／$\mathrm{cDNA}$ 制备）。
2. **选**：选择能自主复制的载体（质粒），同样酶切，碱性磷酸酶可防自连。
3. **连**：$\mathrm{DNA}$ 连接酶把目的片段与载体连成重组 $\mathrm{DNA}$。
4. **转**：转化感受态大肠杆菌（$\mathrm{CaCl}_2$／电穿孔）。
5. **筛**：抗生素抗性、蓝白斑、酶切鉴定、杂交或测序，确认重组体并扩增。

工具酶：Ⅱ型限制酶、连接酶、$\mathrm{DNA}$ 聚合酶Ⅰ／Klenow、逆转录酶等。拓扑异构酶不是重组 $\mathrm{DNA}$ 常用工具酶名单里的主角。
:::

:::callout{kind=note label="知识卡片：蓝白筛选"}
载体 $lacZ'$ 编码 $\beta$-半乳糖苷酶 $\alpha$ 肽。插入失活 $\rightarrow$ 白斑；空载体 $\rightarrow$ 蓝斑（X-gal）。白斑仍要酶切／测序确认。
:::

:::callout{kind=tip label="结论速记"}
克隆实验口诀：**分、选、连、转、筛**。
:::

## Ⅴ. Discuss the following questions（每题 10 分，共 20 分）

### 第1题

:::callout{kind=note label="题目"}
How are the hydrolyzed products of proteins in muscle tissue during starvation converted into glucose in liver?
:::

:::callout{kind=insight label="解析"}
**【答案】**

饥饿时肌蛋白水解，氨基酸碳架在肝糖异生成葡萄糖（肌本身无葡萄糖-6-磷酸酶，不能直接输出葡萄糖）。

1. **肌内**：蛋白水解为氨基酸。支链氨基酸（Val、Leu、Ile）主要在肌转氨基；氨基交给丙酮酸生成**丙氨酸**，或合成谷氨酰胺。丙酮酸来自肌糖原／葡萄糖酵解。
2. **运输**：丙氨酸经血液到肝（丙氨酸–葡萄糖循环）；谷氨酰胺运氨至肠／肾／肝。
3. **肝内脱氨基**：丙氨酸转氨基（$\mathrm{ALT}$）$\rightarrow$ 丙酮酸 $+$ 谷氨酸；联合脱氨基把氨送入尿素循环。
4. **碳架糖异生**：
   - 丙酮酸 $\rightarrow$（丙酮酸羧化酶，需乙酰 $\mathrm{CoA}$ 激活、生物素）草酰乙酸 $\rightarrow$（$\mathrm{PEPCK}$）磷酸烯醇式丙酮酸 $\rightarrow$ ……绕过酵解不可逆步骤 $\rightarrow\mathrm{G}$-$6$-$\mathrm{P}$。
   - 生糖氨基酸分别汇入丙酮酸、草酰乙酸、$\alpha$-酮戊二酸、琥珀酰 $\mathrm{CoA}$、延胡索酸等，再异生。
   - 亮氨酸、赖氨酸为纯生酮氨基酸，**不能**净变成葡萄糖。
5. **输出**：肝葡萄糖-6-磷酸酶水解 $\mathrm{G}$-$6$-$\mathrm{P}$，葡萄糖入血，供脑、红细胞等。

脂肪动员提供的乙酰 $\mathrm{CoA}$ 不能净糖异生（$\mathrm{PDH}$ 不可逆，人无乙醛酸循环），但可激活丙酮酸羧化酶、并经 $\beta$-氧化供 $\mathrm{ATP}$／$\mathrm{NADH}$ 给异生。葡萄糖彻底氧化净 **30 或 32 ATP**；此时外周尽量少用糖、多用脂和酮体。
:::

:::callout{kind=note label="知识卡片：丙氨酸–葡萄糖循环"}
肌：葡萄糖 $\rightarrow$ 丙酮酸 $+$ 氨基 $\rightarrow$ 丙氨酸。肝：丙氨酸 $\rightarrow$ 丙酮酸 $\rightarrow$ 葡萄糖，氨合成尿素。等于把肌的碳和氨分开处理。
:::

:::callout{kind=tip label="结论速记"}
饿时肌蛋白 $\rightarrow$ **丙氨酸**到肝 $\rightarrow$ 糖异生出门；Leu、Lys 不净成糖。
:::

### 第2题

:::callout{kind=note label="题目"}
According to cAMP-protein kinase pathway, explain the mechanism of fat mobilization regulated by glucagon.
:::

:::callout{kind=insight label="解析"}
**【答案】**

1. 胰高血糖素结合白色脂肪细胞膜 $\mathrm{GPCR}$，别构激活受体。
2. 受体激活 $\mathrm{G}_\mathrm{s}$：$\alpha_{\mathrm{s}}$ 结合 $\mathrm{GTP}$，与 $\beta\gamma$ 解离。
3. $\alpha_{\mathrm{s}}$-$\mathrm{GTP}$ 激活腺苷酸环化酶，$\mathrm{ATP}\rightarrow\mathrm{cAMP}$。
4. $\mathrm{cAMP}$ 激活蛋白激酶 $\mathrm{A}$（$\mathrm{PKA}$）。
5. $\mathrm{PKA}$ 磷酸化脂滴包被蛋白 $\mathrm{Perilipin}$-$1$ 和激素敏感性脂肪酶（$\mathrm{HSL}$）：磷酸化的 Perilipin-1 激活 $\mathrm{ATGL}$，并帮助 $\mathrm{HSL}$ 转到脂滴表面。
6. $\mathrm{ATGL}$ 水解甘油三酯，$\mathrm{HSL}$ 水解甘油二酯，$\mathrm{MGL}$ 水解甘油一酯 $\rightarrow$ 游离脂肪酸 $+$ 甘油。
7. $\mathrm{FFA}$ 与清蛋白结合运输；甘油到肝磷酸化后可糖异生或酵解。

胰岛素通过降 $\mathrm{cAMP}$（激活磷酸二酯酶等）对抗脂解。这与胰高血糖素经同一 $\mathrm{cAMP}$-$\mathrm{PKA}$ 途径调节肝糖原（磷酸化酶↑、糖原合酶↓）是同一套信使、不同组织底物。
:::

:::callout{kind=note label="知识卡片：脂解激素 vs 抗脂解"}
脂解：胰高血糖素、肾上腺素、去甲肾上腺素。抗脂解：胰岛素、前列腺素 $\mathrm{E}_2$。限速印象：曾经把 $\mathrm{HSL}$ 当第一步，本版第一步主要是 $\mathrm{ATGL}$。
:::

:::callout{kind=tip label="结论速记"}
胰高血糖素促脂肪动员：$\mathrm{Gs}$-$\mathrm{cAMP}$-$\mathrm{PKA}$ 磷酸化 **Perilipin $+$ HSL**，ATGL 开第一刀。
:::
