### 第1题

:::callout{kind=note label="题目"}
下面关于亚基的说法，正确的是（　　）

A. 一条多肽链就是一个亚基

B. 每个亚基有其各自的三级结构

C. 由两个或两个以上的二级结构肽段组成

D. ？

E. ？
:::

:::callout{kind=insight label="解析"}
**【答案】B**（源 dump 标「A？B？」，按教材取 B）

四级结构里的亚基是具有独立三级结构的多肽链。单体蛋白虽有三级结构，通常不叫亚基。C 更像结构域（domain），不是亚基定义。
:::

:::callout{kind=note label="知识卡片：亚基 vs 结构域"}
| | 亚基 | 结构域 |
|--|------|--------|
| 层次 | 四级 | 三级内部 |
| 是什么 | 一条有独立三级结构的多肽 | 同一条肽链上折叠相对独立的区段 |
:::

:::callout{kind=tip label="结论速记"}
亚基 $=$ 寡聚体里**各有三级结构**的多肽链。
:::

### 第2题

:::callout{kind=note label="题目"}
关于 $\beta$-折叠，下面说法错误的是（　　）

A. 多肽链充分伸展

B. 折叠成锯齿状结构

C. 氨基酸残基交替地位于上下方

D. 肽链间没有任何化学键

E. 可以形成相同或相反走向
:::

:::callout{kind=insight label="解析"}
**【答案】D**

$\beta$-折叠靠肽链（或肽段）之间主链氢键维持。D 说「没有任何化学键」错误。顺式、反式走向都有（平行／反平行）。
:::

:::callout{kind=note label="知识卡片：二级结构作用力"}
$\alpha$-螺旋、$\beta$-折叠、$\beta$-转角的主要作用力都是**氢键**。疏水作用、离子键、二硫键主要稳三级／四级。
:::

:::callout{kind=tip label="结论速记"}
$\beta$-折叠一定有**链间（或链内肽段间）氢键**；D 是错的。
:::

### 第3题

:::callout{kind=note label="题目"}
下列关于核酸理化性质的说法，错误的是（　　）

A. 核酸是两性解离化合物

B. 与双缩脲试剂反应呈紫红色

C. 在乙醇中沉淀

D. ？

E. ？
:::

:::callout{kind=insight label="解析"}
**【答案】B**

双缩脲反应针对肽键，是蛋白质呈色，核酸没有。核酸两性解离（磷酸酸性、碱基弱碱性），可用乙醇沉淀，紫外 $260\,\mathrm{nm}$ 吸收。
:::

:::callout{kind=note label="知识卡片：呈色反应分户"}
| 反应 | 对象 |
|------|------|
| 双缩脲 | 肽键（蛋白质／多肽） |
| 茚三酮 | $\alpha$-氨基 |
| 核酸 $A_{260}$ | 碱基共轭双键 |
:::

:::callout{kind=tip label="结论速记"}
双缩脲是**蛋白质**的，不要安到核酸上。
:::

### 第4题

:::callout{kind=note label="题目"}
由维生素 $\mathrm{B}_2$ 组成的辅基是（　　）

A. $\mathrm{FAD}$、$\mathrm{FMN}$

B. $\mathrm{NAD}^+$、$\mathrm{NADP}^+$

C. ？

D. ？

E. ？
:::

:::callout{kind=insight label="解析"}
**【答案】A**

维生素 $\mathrm{B}_2$（核黄素）构成 $\mathrm{FMN}$、$\mathrm{FAD}$。$\mathrm{NAD}^+$／$\mathrm{NADP}^+$ 来自维生素 $\mathrm{PP}$（尼克酰胺）。

| 叶酸 | $\mathrm{FH}_4$ |

:::

:::callout{kind=tip label="结论速记"}

### 第5题

:::callout{kind=note label="题目"}
参与甲硫氨酸合成的维生素是（　　）

A. 维生素 $\mathrm{B}_6$

B. 维生素 $\mathrm{B}_{12}$

C. 维生素 A

D. 维生素 $\mathrm{PP}$

E. ？
:::

:::callout{kind=insight label="解析"}
**【答案】B**

同型半胱氨酸接受 $N^5$-甲基 $\mathrm{FH}_4$ 的甲基生成甲硫氨酸，甲硫氨酸合酶的辅酶是维生素 $\mathrm{B}_{12}$。叶酸也参与，但不在本题选项里。
:::

:::callout{kind=note label="知识卡片：甲硫氨酸循环两维生素"}
$\mathrm{B}_{12}$：甲硫氨酸合酶。叶酸：提供甲基。缺 $\mathrm{B}_{12}$ 时甲基 $\mathrm{FH}_4$ 堆积（甲基陷阱）。
:::

:::callout{kind=tip label="结论速记"}
同型半胱氨酸 $\rightarrow$ 甲硫氨酸，必记 **维生素 $\mathrm{B}_{12}$**。
:::

### 第6题

:::callout{kind=note label="题目"}
由 $\mathrm{RNA}$ 聚合酶Ⅰ合成的是（　　）

A. $16\mathrm{S}\,\mathrm{rRNA}$

B. $5.8\mathrm{S}\,\mathrm{rRNA}$

C. $5\mathrm{S}\,\mathrm{rRNA}$

D. $\mathrm{hnRNA}$

E. $\mathrm{mRNA}$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

真核：$\mathrm{RNA}$-pol Ⅰ 合成 $45\mathrm{S}$ 前体 $\rightarrow 18\mathrm{S}$、$5.8\mathrm{S}$、$28\mathrm{S}\,\mathrm{rRNA}$。$5\mathrm{S}\,\mathrm{rRNA}$ 和 $\mathrm{tRNA}$ 由 pol Ⅲ；$16\mathrm{S}$ 是原核小亚基 $\mathrm{rRNA}$；$\mathrm{hnRNA}/\mathrm{mRNA}$ 由 pol Ⅱ。
:::

:::callout{kind=note label="知识卡片：三台 RNA 聚合酶"}
| 酶 | 产物 |
|----|------|
| pol Ⅰ | $45\mathrm{S}\rightarrow 18\mathrm{S}+5.8\mathrm{S}+28\mathrm{S}$ |
| pol Ⅱ | $\mathrm{hnRNA}$（$\mathrm{mRNA}$ 前体）、多数 $\mathrm{snRNA}$、$\mathrm{miRNA}$ |
| pol Ⅲ | $\mathrm{tRNA}$、$5\mathrm{S}\,\mathrm{rRNA}$、$\mathrm{U}6$ |
:::

:::callout{kind=tip label="结论速记"}
pol Ⅰ 出 **5.8S**（随 45S）；5S 是 pol Ⅲ，16S 是原核。

### 第7题

:::callout{kind=note label="题目"}
关于肽酰转移酶，说法错误的是（　　）

A. 位于有活性的小亚基上

B. 位于有活性的大亚基上

C. 化学本质不是蛋白质

D. ？

E. ？

:::callout{kind=insight label="解析"}

成肽键在**大亚基 rRNA**，不在小亚基。

### 第8题

:::callout{kind=note label="题目"}
发生在同源序列间的重组称为（　　）

A. 基本重组

B. 位点特异的重组

C. 非位点特意重组

D. 人工重组

E. 随机重组
:::

:::callout{kind=insight label="解析"}
**【答案】A**

同源重组又称基本重组（一般性重组），发生在广泛同源序列之间。位点特异重组只在短特异位点（如 $\mathrm{attP}/\mathrm{attB}$）。
:::

:::callout{kind=note label="知识卡片：自然界三种重组"}
同源（基本）／位点特异／转座。体外把两段 $\mathrm{DNA}$ 连起来是重组 $\mathrm{DNA}$ 技术，不是本题。
:::

:::callout{kind=tip label="结论速记"}
同源序列之间 $=$ **基本重组（同源重组）**。
:::

:::callout{kind=note label="题目"}
下面关于酶原的激活，正确的是（　　）

A. 未改变一级结构

B. 去除一个或几个肽段后，酶的一级结构改变，暴露出活性中心

C. ？

D. ？

E. ？
:::

:::callout{kind=insight label="解析"}
**【答案】B**

酶原激活是切掉一个或几个肽段，一级结构改变，构象调整后暴露活性中心。这是不可逆的共价修饰，不是简单别构。

:::callout{kind=tip label="结论速记"}
酶原激活 $=$ **切肽段** $\rightarrow$ 一级结构变 $\rightarrow$ 露出活性中心。

### 第10题

:::callout{kind=note label="题目"}
体内 $\mathrm{ATP}$ 合成的最主要的方式是（　　）

A. 氧化磷酸化

B. 底物水平磷酸化

C. ？

D. ？

E. ？
:::

:::callout{kind=insight label="解析"}
**【答案】A**

人体约 $90\%$ 的 $\mathrm{ATP}$ 来自线粒体氧化磷酸化。底物水平磷酸化只在酵解两步和三羧酸循环琥珀酰 $\mathrm{CoA}$ 合成酶等处，量少。葡萄糖彻底氧化净 **30 或 32 ATP**（本版），其中绝大部分是氧化磷酸化。
:::

:::callout{kind=note label="知识卡片：不要写成 36/38"}
$\mathrm{NADH}=2.5$，$\mathrm{FADH}_2=1.5$，胞质 $\mathrm{NADH}$ 穿梭不同得 30 或 32。旧口诀 36/38 不用。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{ATP}$ 主角是**氧化磷酸化**；有氧净 30 或 32。
:::

以下参与卵磷脂组成的是（　　）

### 第12题

:::callout{kind=note label="题目"}
$1\,\mathrm{mol}$ 葡萄糖能产生几 $\mathrm{mol}$ 乙酰 $\mathrm{CoA}$（　　）

A. $1\,\mathrm{mol}$

B. $2\,\mathrm{mol}$

C. $3\,\mathrm{mol}$

D. $4\,\mathrm{mol}$

E. ？
:::

:::callout{kind=insight label="解析"}
**【答案】B**

葡萄糖 $\rightarrow$ 2 丙酮酸 $\rightarrow$ 2 乙酰 $\mathrm{CoA}$。此后每分子乙酰 $\mathrm{CoA}$ 进一次三羧酸循环。净 $\mathrm{ATP}$ 是 30 或 32，不是靠「乙酰 $\mathrm{CoA}$ 个数变成 36」。
:::

:::callout{kind=note label="知识卡片：从糖到乙酰 CoA"}
胞质酵解得 2 丙酮酸；丙酮酸进线粒体， $\mathrm{PDH}$ 不可逆变乙酰 $\mathrm{CoA}$。乙酰 $\mathrm{CoA}$ 不能净糖异生。
:::

:::callout{kind=tip label="结论速记"}
1 葡萄糖 $\rightarrow$ **2 乙酰 CoA**。
:::

脱下的 $\mathrm{H}$ 不进入 $\mathrm{NADH}$ 呼吸链的是（　　）

### 第15题

:::callout{kind=note label="题目"}
一女子和丈夫吵架，随后服有机磷农药敌百虫，被送往医院后进行抢救，进行洗胃等，服用解磷定。请问有机磷农药敌百虫抑制下面哪个酶的活性（　　）

A. 巯基酶

B. 羟基酶

C. 酸性磷酸酶

D. 碱性磷酸酶

E. 胆碱酯酶
:::

:::callout{kind=insight label="解析"}
**【答案】E**（源 dump 未标字母，按题干与选项）

有机磷磷酸化胆碱酯酶活性中心丝氨酸羟基，酶不可逆抑制 $\rightarrow$ 乙酰胆碱堆积。解磷定（肟类）使未老化的酶复能。B「羟基酶」不是标准分类名。

:::callout{kind=note label="知识卡片：不可逆抑制例子"}
有机磷 $\rightarrow$ 胆碱酯酶（Ser-OH）；砷／重金属 $\rightarrow$ 巯基酶。不可逆抑制 $K_\mathrm{m}$、$V_{\max}$ 都下降（酶分子被灭活）。
:::

:::callout{kind=tip label="结论速记"}
敌百虫／有机磷 $\rightarrow$ **胆碱酯酶**；解磷定复能。
:::

### 第17题

:::callout{kind=note label="题目"}
关于脂肪酸的合成，正确的是（　　）

A. 合成的是硬脂酸

B. 主要在线粒体中合成

C. 在丙二酸单酰 $\mathrm{CoA}$ 的基础上不断加碳

D. $\mathrm{NADH}$ 提供氢

E. 是脂肪酸 $\beta$ 氧化的逆反应
:::

:::callout{kind=insight label="解析"}
**【答案】C**

胞质脂肪酸合酶以丙二酸单酰 $\mathrm{CoA}$ 为二碳供体延长，人主要产物是**软脂酸**（$C_{16}$）不是硬脂酸。场所在胞质（不是线粒体）；供氢是 $\mathrm{NADPH}$ 不是 $\mathrm{NADH}$；与 $\beta$-氧化不是简单逆反应（酶、细胞器、辅酶、载体都不同）。
:::

:::callout{kind=note label="知识卡片：合成 vs β-氧化"}
| | 合成 | $\beta$-氧化 |
|--|------|-------------|
| 场所 | 胞质 | 线粒体 |
| 二碳单位 | 丙二酸单酰 $\mathrm{CoA}$ | 乙酰 $\mathrm{CoA}$ |
| 还原当量 | $\mathrm{NADPH}$ | $\mathrm{NAD}^+$、$\mathrm{FAD}$ |
| 载体 | ACP | $\mathrm{CoA}$ |
:::

:::callout{kind=tip label="结论速记"}
脂酸合成：胞质、**丙二酸单酰 CoA 加碳**、$\mathrm{NADPH}$、主产软脂酸。
:::

**【答案】A**（源 dump 标 A）

### 第70题

:::callout{kind=note label="题目"}
分析胰高血糖素升高其血糖的分子机制（10 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**

节食后胰岛素↓、胰高血糖素↑。肝细胞膜 $\mathrm{GPCR}\rightarrow\mathrm{G}_\mathrm{s}\rightarrow\mathrm{AC}\rightarrow\mathrm{cAMP}\rightarrow\mathrm{PKA}$：

1. **糖原分解**：$\mathrm{PKA}$ 磷酸化磷酸化酶激酶 $\rightarrow$ 糖原磷酸化酶 $b\rightarrow a$，糖原 $\rightarrow\mathrm{G}$-$1$-$\mathrm{P}\rightarrow\mathrm{G}$-$6$-$\mathrm{P}$，葡萄糖-6-磷酸酶释出葡萄糖。
2. **糖原合成关闭**：$\mathrm{PKA}$ 使糖原合酶磷酸化失活。
3. **糖异生打开**：诱导／激活丙酮酸羧化酶、$\mathrm{PEPCK}$、果糖-$1,6$-二磷酸酶等；同时抑制 PFK-1／丙酮酸激酶（经 F-2,6-BP 等）。
4. **脂肪动员**：脂肪细胞同样 $\mathrm{cAMP}$-$\mathrm{PKA}$，FFA 供能并提供甘油异生，节省葡萄糖。

头昏后「过一会儿好些」对应胰高血糖素把肝糖原／异生拉起来，血糖回升。肌糖原不能直接补血糖。
:::

:::callout{kind=note label="知识卡片：cAMP-PKA 升糖三板斧"}
开磷酸化酶、关糖原合酶、开异生。同一信使在脂肪组织开动员。
:::

:::callout{kind=tip label="结论速记"}
胰高血糖素升糖：$\mathrm{Gs}$-$\mathrm{cAMP}$-$\mathrm{PKA}$ $\rightarrow$ **分解糖原 $+$ 异生 $+$ 脂解**。
:::
