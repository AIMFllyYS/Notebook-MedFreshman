## 一、A1 型选择题

### 第1题

:::callout{kind=note label="题目"}
谷胱甘肽主要参与什么化学反应（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】氧化还原反应**（源回忆）

$\mathrm{GSH}$ 靠巯基还原过氧化物、维持蛋白质巯基、参与生物转化第二相结合。红细胞缺 $\mathrm{NADPH}$（G6PD 缺乏）时 $\mathrm{GSH}$ 不能再生，溶血。
:::

:::callout{kind=note label="知识卡片："}
$\mathrm{GSH}$ 是三肽（γ-Glu-Cys-Gly），不是运氨工具（运氨是谷氨酰胺）。
:::

:::callout{kind=tip label="结论速记"}
谷胱甘肽主场：**氧化还原**（及结合解毒）。
:::

---

### 第2题

:::callout{kind=note label="题目"}
单加氧酶位于（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】微粒体**（源回忆）

细胞色素 $\mathrm{P450}$ 单加氧酶在滑面内质网（微粒体），催化 $\mathrm{RH}+\mathrm{O}_2+\mathrm{NADPH}\rightarrow\mathrm{ROH}+\mathrm{H}_2\mathrm{O}+\mathrm{NADP}^+$，生物转化第一相的主角。
:::

:::callout{kind=note label="知识卡片："}
不要答成线粒体基质（那是 $\beta$-氧化、TCA）或线粒体内膜（呼吸链）。
:::

:::callout{kind=tip label="结论速记"}
单加氧酶在 **微粒体**。
:::

---

### 第3题

:::callout{kind=note label="题目"}
下列只能在肝脏中合成的（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】尿素**（源回忆）

尿素循环酶系完整只在肝。酮体也主要在肝生成，但题干「只能在肝脏中合成」的标准答案是尿素。
:::

:::callout{kind=note label="知识卡片："}
肌、脑不能把氨写成尿素。氨的运输储存靠谷氨酰胺。
:::

:::callout{kind=tip label="结论速记"}
尿素 **只在肝** 合成。
:::

### 第4题

:::callout{kind=note label="题目"}
饥饿 3 天，血液中什么含量明显变化（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】乙酰乙酸**（源回忆）

饥饿 3 天肝糖原早已耗尽，糖异生 $+$ 脂肪动员 $+$ 生酮，血酮体（乙酰乙酸、$\beta$-羟丁酸）明显升高。
:::

:::callout{kind=note label="知识卡片："}
红细胞仍只用葡萄糖。脑逐渐用酮体省糖。有氧净 30 或 32 ATP。
:::

:::callout{kind=tip label="结论速记"}
饿 3 天：血 **酮体（乙酰乙酸）** 明显升。
:::

### 第5题

:::callout{kind=note label="题目"}
高脂低糖低蛋白饮食什么酶活性高（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】肉碱脂酰转移酶-1**（源回忆）

低碳水、高脂 $\rightarrow$ 脂酸氧化供能，$\mathrm{CPT}$-Ⅰ 是 $\beta$-氧化限速酶，活性升高。丙二酸单酰 $\mathrm{CoA}$ 因糖少、脂酸合成关而下降，对 $\mathrm{CPT}$-Ⅰ 的抑制减弱。
:::

:::callout{kind=note label="知识卡片："}
葡糖激酶、乙酰 $\mathrm{CoA}$ 羧化酶在高糖时才高。
:::

:::callout{kind=tip label="结论速记"}
高脂低糖 $\rightarrow$ **CPT-Ⅰ** 活性高。
:::

### 第6题

:::callout{kind=note label="题目"}
RNA 聚合酶全酶催化转录延长（错）
:::

:::callout{kind=insight label="解析"}
**【答案】该叙述错误**（源回忆标「错」）

全酶 $=$ 核心酶 $+\sigma$，负责**起始**（认启动子）。延长阶段 $\sigma$ 脱落，由**核心酶**催化延长。
:::

:::callout{kind=note label="知识卡片："}
原核核心酶 $\alpha_2\beta\beta'$。真核三种 $\mathrm{RNA}$-pol 分工：Ⅰ  prerRNA，Ⅱ  mRNA，Ⅲ  tRNA／5S 等。
:::

:::callout{kind=tip label="结论速记"}
转录延长靠 **核心酶**，不是全酶。
:::

### 第7题

:::callout{kind=note label="题目"}
异烟肼拮抗的维生素（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】维生素 PP**（源回忆）

异烟肼与维生素 $\mathrm{PP}$（烟酸／烟酰胺）结构相关，可干扰 $\mathrm{NAD}^+/\mathrm{NADP}^+$ 相关代谢，临床上也注意 $\mathrm{B}_6$ 缺乏。本场回忆写的是 $\mathrm{PP}$。
:::

:::callout{kind=note label="知识卡片："}
$\mathrm{PP}$ 缺乏糙皮病。$\mathrm{NAD}^+$ 是多种脱氢酶辅酶。
:::

:::callout{kind=tip label="结论速记"}
异烟肼拮抗 **维生素 PP**（本场回忆）。
:::

### 第8题

:::callout{kind=note label="题目"}
鸟氨酸脱羧生成（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】腐胺**（源回忆写「精胺」，不准确）

鸟氨酸脱羧酶直接产物是**腐胺**（putrescine）。亚精胺、精胺是腐胺再加丙胺基后的下游多胺。名解／选择若写「生成精胺」跳过了直接产物。
:::

:::callout{kind=note label="知识卡片："}
鸟氨酸也是尿素循环成员。脱羧走多胺，不是直接变精氨酸。
:::

:::callout{kind=tip label="结论速记"}
鸟氨酸脱羧 $\rightarrow$ **腐胺**（精胺在下游）。
:::

### 第9题

:::callout{kind=note label="题目"}
什么的产物不能经过 NADH 呼吸链（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】琥珀酸**（源回忆）

琥珀酸脱氢酶是复合体Ⅱ，氢交给 $\mathrm{FAD}$，走 $\mathrm{FADH}_2$ 呼吸链（1.5 ATP），不经复合体Ⅰ。
:::

:::callout{kind=note label="知识卡片："}
$\mathrm{NADH}$ 链：Ⅰ→Q→Ⅲ→Cyt c→Ⅳ。琥珀酸从Ⅱ进 Q。
:::

:::callout{kind=tip label="结论速记"}
琥珀酸 **不走 NADH 呼吸链**。
:::

### 第10题

:::callout{kind=note label="题目"}
酶原的意义（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】防止胰腺自身消化**（源回忆）

消化酶以酶原形式合成、在肠道激活，避免胰组织被胰蛋白酶等水解。凝血因子酶原防止循环内凝血。
:::

:::callout{kind=note label="知识卡片："}
肠激酶激活胰蛋白酶原，胰蛋白酶再激活其他胰酶原（级联）。
:::

:::callout{kind=tip label="结论速记"}
酶原：保护自身不被消化／凝血失控。
:::

紫外吸收的原因（　　）

### 第12题

贝塔折叠错误的是（通过疏水键 xxx）（疏水键是三级结构）
:::

:::callout{kind=tip label="结论速记"}
$\beta$-折叠靠 **氢键**，不是疏水键。
:::

### 第13题

:::callout{kind=note label="题目"}
氮杂丝氨酸药物干扰核苷酸合成，是因为（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】结构类似谷氨酰胺，干扰了嘌呤的合成**（源回忆）

嘌呤从头合成有两步需要谷氨酰胺供氨。氮杂丝氨酸是谷氨酰胺类似物。

:::callout{kind=note label="知识卡片：抗代谢分户"}
$6$-$\mathrm{MP}$ 类似次黄嘌呤；甲氨蝶呤抑二氢叶酸还原酶；$5$-$\mathrm{FU}$ 抗嘧啶。
:::

:::callout{kind=tip label="结论速记"}
氮杂丝氨酸 $\approx$ **谷氨酰胺**，挡嘌呤从头合成。
:::

### 第14题

:::callout{kind=note label="题目"}
嘌呤从头合成过程中正确的是（不会产生自由嘌呤碱）
:::

:::callout{kind=insight label="解析"}
**【答案】不会产生自由嘌呤碱**（源回忆）

嘌呤环在 $\mathrm{PRPP}$ 上逐步建成，先得 $\mathrm{IMP}$，不是先做游离腺嘌呤／鸟嘌呤再接上核糖。游离碱是补救途径的底物。
:::

:::callout{kind=note label="知识卡片："}
补救：$\mathrm{HGPRT}$ 等。Lesch-Nyhan 缺 $\mathrm{HGPRT}$。
:::

:::callout{kind=tip label="结论速记"}
嘌呤从头合成 **不产生游离嘌呤碱**。
:::

### 第16题

:::callout{kind=note label="题目"}
Km 值（给了一个表，让计算 Km，注意 Km 的计算）
:::

:::callout{kind=insight label="解析"}
**【答案】** 源回忆未给出数据表，不编造数字。

### 第20题

:::callout{kind=note label="题目"}
糖有氧氧化、甘油氧化及磷酸戊糖途径的共同中间产物是（　　）

A. 3-磷酸甘油　B. 3-磷酸甘油酸　C. 磷酸二羟丙酮　D. 3-磷酸甘油醛　E. 丙酮酸
:::

:::callout{kind=insight label="解析"}
**【答案】D**（源回忆）

3-磷酸甘油醛：酵解／有氧氧化的中间物；甘油 $\rightarrow\alpha$-磷酸甘油 $\rightarrow$ 磷酸二羟丙酮 $\leftrightarrow$ 3-磷酸甘油醛；磷酸戊糖途径基团转移也回到 3-磷酸甘油醛／果糖-6-磷酸。丙酮酸不在 PPP 上；3-磷酸甘油不是有氧氧化必经。
:::

:::callout{kind=note label="知识卡片："}
甘油进酵解的接口是 DHAP／3-磷酸甘油醛。
:::

:::callout{kind=tip label="结论速记"}
三条路交叉：**3-磷酸甘油醛**。
:::

### 第22题

:::callout{kind=note label="题目"}
某个细胞可以自己合成的脂肪酸（　　）

A. 亚油酸　B. 亚麻酸　C. 软脂酸　D. 花生四烯酸
:::

:::callout{kind=insight label="解析"}
**【答案】C**（源回忆）

人可合成软脂酸（$16$ 碳）。亚油酸、$\alpha$-亚麻酸是必需脂酸；花生四烯酸虽可由亚油酸来，但消耗必需脂酸，且题干「自己合成」优先软脂酸。
:::

:::callout{kind=note label="知识卡片："}
软脂酸在胞质合酶复合体经 7 轮循环生成；彻底氧化净 106 ATP。
:::

:::callout{kind=tip label="结论速记"}
细胞能自己写的脂酸：**软脂酸**。
:::

### 第23题

:::callout{kind=note label="题目"}
酮体生成和胆固醇合成共同的中间产物（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】HMG-CoA**（源回忆）

线粒体 $\mathrm{HMG}$-$\mathrm{CoA}$ $\rightarrow$ 酮体；胞质 $\mathrm{HMG}$-$\mathrm{CoA}\rightarrow$ 甲羟戊酸 $\rightarrow$ 胆固醇。同分室。
:::

:::callout{kind=tip label="结论速记"}

### 第2题

:::callout{kind=note label="题目"}
大肠杆菌（DNA 同位素标记）三代后重链轻链的比例（类似高中生物题）
:::

:::callout{kind=insight label="解析"}
**【答案】** 半保留：全 $^{15}\mathrm{N}$ 转到 $^{14}\mathrm{N}$ 后，第 1 代全是杂合（HL）；第 2 代 HL:LL $=1:1$；第 3 代 **HL:LL $=1:3$**。

### 第3题

:::callout{kind=note label="题目"}
酗酒，昏迷。注射硫胺素、葡萄糖。清醒出院，此时血液中活性较低的酶是（葡糖激酶）
:::

:::callout{kind=insight label="解析"}
**【答案】葡糖激酶**（源回忆）

葡糖激酶（肝）受胰岛素／葡萄糖诱导。酗酒、摄食差时胰岛素低，该酶活性低。给硫胺素是因为 $\mathrm{B}_1$（$\mathrm{TPP}$）是丙酮酸脱氢酶等的辅酶，防 Wernicke。清醒出院时仍可处于低诱导状态。
:::

:::callout{kind=note label="知识卡片："}
己糖激酶 $K_\mathrm{m}$ 低，脑、红细胞一直能用糖；葡糖激酶 $K_\mathrm{m}$ 高，只在肝、餐后开工。
:::

:::callout{kind=tip label="结论速记"}
酗酒后肝 **葡糖激酶** 仍可偏低。
:::

### 第4题

:::callout{kind=note label="题目"}
战士长期饥饿，哪个细胞只利用葡萄糖（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】红细胞**（源回忆）

成熟红细胞无线粒体，只能无氧酵解葡萄糖（净 2 ATP）。脑饥饿后期可用酮体。
:::

:::callout{kind=note label="知识卡片："}
缺肉碱时低血糖，红细胞仍在抢糖。
:::

:::callout{kind=tip label="结论速记"}
长期饥饿仍只吃糖：**红细胞**。
:::

### 第5题

:::callout{kind=note label="题目"}
酒喝多了，乳酸少原因（乙醇和乳酸竞争 NAD+）
:::

:::callout{kind=insight label="解析"}
**【答案】** 源句「乳酸少」与常见题「乳酸升高」相反。乙醇氧化（醇脱氢酶、醛脱氢酶）大量消耗 $\mathrm{NAD}^+$、产生 $\mathrm{NADH}$。

按机制：$\mathrm{NADH}$ 高时丙酮酸被拉成乳酸，**血乳酸通常升高**（酒精性乳酸酸中毒）。若题干确为「乳酸少」，可能是回忆笔误，或问「乳酸脱氢的氧化方向受抑」。答题先写抢 $\mathrm{NAD}^+$ 这一核心。
:::

:::callout{kind=note label="知识卡片："}
高 $\mathrm{NADH}$ 还抑制 $\beta$-氧化、抑制糖异生，可低血糖。
:::

:::callout{kind=tip label="结论速记"}
乙醇抢 **NAD+**：通常乳酸升高、异生受抑。
:::

分子克隆即重组 $\mathrm{DNA}$ 技术：体外重组不同来源 $\mathrm{DNA}$ 并在细胞中扩增。五步：分、选、连、转、筛。

### 第2题

:::callout{kind=note label="题目"}
蛋白质等电点
:::

:::callout{kind=insight label="解析"}
**【答案】**

等电点（$\mathrm{pI}$）是蛋白质净电荷为零时的 $\mathrm{pH}$。此时溶解度最低，电场中不泳动。$\mathrm{pH}<\mathrm{pI}$ 带正电，向负极；$\mathrm{pH}>\mathrm{pI}$ 带负电，向正极。

:::callout{kind=note label="知识卡片："}
兼性离子。等电沉淀、电泳分离都靠 $\mathrm{pI}$。
:::

:::callout{kind=tip label="结论速记"}
$\mathrm{pI}$：净电荷为零的 $\mathrm{pH}$。
:::

:::callout{kind=note label="题目"}
核酸变性

核酸变性：双链氢键断开、螺旋解开，磷酸二酯键不断。$A_{260}$ 升高。$\mathrm{DNA}$、有二级结构的 $\mathrm{RNA}$ 都可谈变性。

$T_\mathrm{m}$；复性／杂交。不要写成 renaturation。
:::

:::callout{kind=tip label="结论速记"}
核酸变性拆氢键，一级序列还在。
:::

## 六、简答题

### 第1题

:::callout{kind=note label="题目"}
肝病患者厌油原因（慕课视频有讲）
:::

:::callout{kind=insight label="解析"}
**【答案】**

1. 肝合成、分泌胆汁酸（盐）减少。
2. 胆汁酸盐是脂类消化吸收的乳化剂，协助形成混合微团。
3. 乳化差 $\rightarrow$ 胰脂酶作用受限 $\rightarrow$ 吃油不化、腹胀厌油。
4. 肝利用和转运脂质能力下降可加重不适。缺的是胆汁这一侧，不是胰脂酶本身一定缺。
:::

:::callout{kind=note label="知识卡片："}
脂溶性维生素 A、D、E、K 吸收也会受累。
:::

:::callout{kind=tip label="结论速记"}
肝病厌油：胆汁酸盐少 $\rightarrow$ **乳化差**。
:::

### 第2题

:::callout{kind=note label="题目"}
肉碱不能合成，为什么会低血糖解释其生化原因
:::

:::callout{kind=insight label="解析"}
**【答案】**

长链脂酰 $\mathrm{CoA}$ 必须经肉碱穿梭（$\mathrm{CPT}$-Ⅰ 限速）进线粒体。缺肉碱 $\rightarrow\beta$-氧化停。

1. 组织不能靠脂酸氧化供 $\mathrm{ATP}$，被迫加用葡萄糖。
2. 糖异生缺乙酰 $\mathrm{CoA}$ 对丙酮酸羧化酶的别构激活，且 $\mathrm{NADH}$、$\mathrm{ATP}$ 不足。
3. 不能生酮，脑更依赖葡萄糖。
4. 脂酰 $\mathrm{CoA}$ 堆积可致脂肪肝，进一步伤异生。
:::

:::callout{kind=note label="知识卡片："}
丙二酸单酰 $\mathrm{CoA}$ 抑制 $\mathrm{CPT}$-Ⅰ。红细胞仍只吃糖。有氧净 30 或 32 ATP 的前提是偶联完整且燃料进得去。
:::

:::callout{kind=tip label="结论速记"}
缺肉碱 $=$ $\beta$-氧化停 $=$ 耗糖↑ $+$ 异生开不了 $\rightarrow$ 低血糖。
:::

### 第4题

:::callout{kind=note label="题目"}
胰高血糖素信号转导通路
:::

:::callout{kind=insight label="解析"}
**【答案】**

胰高血糖素受体是 $\mathrm{GPCR}$，走 $\mathrm{G}_\mathrm{s}$-$\mathrm{cAMP}$-$\mathrm{PKA}$：

1. 激素结合肝细胞膜受体。
2. 激活 $\mathrm{G}_\mathrm{s}$（$\alpha_\mathrm{s}$ 绑 $\mathrm{GTP}$）。
3. $\alpha_\mathrm{s}$ 激活腺苷酸环化酶。
4. $\mathrm{ATP}\rightarrow\mathrm{cAMP}$。
5. $\mathrm{cAMP}$ 激活 $\mathrm{PKA}$。
6. $\mathrm{PKA}$ 磷酸化：肝糖原分解开、合酶关；诱导异生酶；脂肪组织促动员。结果升血糖。
:::

:::callout{kind=note label="知识卡片：GPCR 六步"}
配体→受体→G 循环→效应酶→第二信使→激酶。
:::

:::callout{kind=tip label="结论速记"}
胰高血糖素：$\mathrm{G}_\mathrm{s}\rightarrow\mathrm{AC}\rightarrow\mathrm{cAMP}\rightarrow\mathrm{PKA}$。
:::

## 七、分析题

### 第1题

:::callout{kind=note label="题目"}
乳酸升高，甘油三酯、胆固醇升高，尿酸升高，葡糖-6-磷酸酶缺陷，导致糖原贮积症。分析为什么会低血糖，高尿酸，高血脂，酸中毒。
:::

:::callout{kind=insight label="解析"}
**【答案】**

Ⅰ型糖原贮积症（von Gierke）：**葡萄糖-6-磷酸酶**缺陷。肝不能把 $\mathrm{G}$-$6$-$\mathrm{P}$ 水解成游离葡萄糖输出。

**低血糖**：糖原分解和糖异生都能写成 $\mathrm{G}$-$6$-$\mathrm{P}$，最后一步出不去。肌无此酶，不能代偿。

**高脂血症**：低血糖 $\rightarrow$ 胰高血糖素↑、胰岛素↓ $\rightarrow$ 脂肪动员；肝内 $\mathrm{G}$-$6$-$\mathrm{P}$ 走酵解和 PPP，乙酰 $\mathrm{CoA}$ 与 $\mathrm{NADPH}$ 足 $\rightarrow$ 脂酸、甘油三酯、胆固醇合成↑，以 $\mathrm{VLDL}$ 输出。

**高尿酸**：$\mathrm{G}$-$6$-$\mathrm{P}$ 涌入 PPP $\rightarrow$ 核糖-5-磷酸 $\rightarrow\mathrm{PRPP}$↑ $\rightarrow$ 嘌呤从头合成↑ $\rightarrow$ 尿酸↑；乳酸等与尿酸竞争肾小管排泄。

**酸中毒**：$\mathrm{G}$-$6$-$\mathrm{P}$ 在肝内走酵解 $\rightarrow$ 乳酸堆积；脂肪动员可伴酮体升高。

葡萄糖彻底氧化净 **30 或 32 ATP**；本病卡在「游离葡萄糖出肝」。
:::

:::callout{kind=note label="知识卡片：G6Pase 这一刀"}
有酶：$\mathrm{G}$-$6$-$\mathrm{P}\rightarrow$ 葡萄糖入血。无酶：$\mathrm{G}$-$6$-$\mathrm{P}$ 困在肝 $\rightarrow$ 低血糖 $+$ 肝糖原堆积。
:::

:::callout{kind=tip label="结论速记"}
Ⅰ型 $=$ 缺 G6Pase：糖出不去 $\rightarrow$ 低血糖；改走脂和 PPP $\rightarrow$ 高脂、高尿酸；酵解 $\rightarrow$ 酸中毒。
:::

### 第5题

:::callout{kind=note label="题目"}
69. EGFR 信号转导通路。
:::

:::callout{kind=insight label="解析"}
**【答案】**

EGFR 是受体酪氨酸激酶（$\mathrm{RTK}$）：配体结合 $\rightarrow$ 二聚化 $\rightarrow$ 胞内激酶互磷酸化 $\rightarrow$ 接头蛋白／$\mathrm{Grb2}$-$\mathrm{Sos}$ 激活 Ras $\rightarrow$ Raf $\rightarrow$ MEK $\rightarrow$ ERK（MAPK），调控增殖、存活。还可走 $\mathrm{PI3K}$-Akt 等。照片提示「论述题可能是某节课堂讨论题的延伸」。

:::callout{kind=note label="知识卡片：RTK vs GPCR"}

:::

:::callout{kind=tip label="结论速记"}
EGFR：$\mathrm{RTK}$ 二聚磷酸化 $\rightarrow$ Ras-Raf-MEK-ERK。
:::
