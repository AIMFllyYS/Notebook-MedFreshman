# 五、　肾上腺

肾上腺坐在肾的上方，和肾一起包在肾筋膜里。本节写这一对：质软、淡黄色，左似半月形、右呈三角形，重 6.8～7.2 g；周边皮质、中央髓质，门在前面。胸腺是下一节的户头。

肾上腺（suprarenal gland）位于肾的上方（图6-5），质软，呈淡黄色，与肾共同包裹于肾筋膜内。左侧肾上腺似呈半月形，右侧肾上腺呈三角形，重 6.8～7.2 g。前面有不太明显的肾上腺门（suprarenal hilum），是血管、神经和淋巴管出入之处。肾上腺由周边的皮质和中央的髓质两部分构成。表面包裹结缔组织被膜，少量结缔组织伴随血管和神经伸入皮质内。

:::definition{label="肾上腺"}
位于**肾的上方**，质软，淡黄色，与肾共同包裹于**肾筋膜**内。左、右各一。职能按皮质和髓质分开写，不要并成「一个腺只出一种激素」。
:::

:::compare{title="左、右形态和重量（本版）"}
| | 本版 |
|--|------|
| 左侧 | 似呈**半月形** |
| 右侧 | 呈**三角形** |
| 重量 | **6.8～7.2 g** |

左半月、右三角。不要写成两侧都像小帽子同一形状，也不要把重量改成「约 10 g」。
:::

:::definition{label="肾上腺门"}
在**前面**，不太明显。血管、神经和淋巴管在此出入。不要把肾门的内侧缘凹陷直接套过来——肾上腺门不在「内侧缘中部」。
:::

:::definition{label="肾上腺皮质与髓质"}
周边是**皮质**，中央是**髓质**。表面结缔组织被膜，少量结缔组织伴随血管和神经伸入皮质。两部来源和激素都不同。
:::

:::pitfall{label="左半月形、右三角形，不要左右写反"}
本版原句：左侧似呈半月形，右侧呈三角形。写成「右半月、左三角」，和肾上方的外形对不上图6-5。
:::

:::pitfall{label="肾上腺门在前面，不要写成在内侧缘或后面"}
本版：前面有不太明显的肾上腺门。肾门在内侧缘中部凹陷，两套「门」不要抄在同一个位置上。
:::

:::pitfall{label="重量按 6.8～7.2 g，不要和甲状腺 26 g 或垂体 0.5 g 搞混"}
肾上腺这一对按 6.8～7.2 g 记。它和肾包在同一张肾筋膜里，但不是肾的一极「长出来的皮」。
:::

::figure{src="/images/anatomy/textbook/p0200_01.png" caption="图6-5　肾上腺" alt="左上为肾及上方的肾上腺整体观；右下为肾上腺剖面，周边黄色皮质，中央红色髓质"}

图6-5 左侧先认「肾上头那一顶」；右侧剖面把皮质围在外圈、髓质填在中央。门在前面，这张剖面图主要用来认皮质和髓质，不是用来数门上的管道。

肾上腺皮质分泌盐皮质激素、糖皮质激素和性激素，分别调节体内水盐代谢、调节碳水化合物代谢、影响第二性征等。肾上腺髓质可分泌肾上腺素和去甲肾上腺素：前者主要作用于心肌，使心跳加快、心肌收缩力加强；后者主要使小动脉平滑肌收缩，以维持血压稳定等。

:::definition{label="肾上腺皮质激素"}
三样：**盐皮质激素、糖皮质激素、性激素**。分别调节水盐代谢、碳水化合物代谢、影响第二性征。
:::

:::definition{label="肾上腺髓质激素"}
两样：**肾上腺素**和**去甲肾上腺素**。肾上腺素主要作用于心肌，使心跳加快、收缩力加强。去甲肾上腺素主要使小动脉平滑肌收缩，维持血压稳定。
:::

:::compare{title="皮质三激素、髓质两激素"}
| 部 | 激素 | 本版作用 |
|----|------|----------|
| 皮质 | 盐皮质激素 | 调节水盐代谢 |
| 皮质 | 糖皮质激素 | 调节碳水化合物代谢 |
| 皮质 | 性激素 | 影响第二性征 |
| 髓质 | 肾上腺素 | 作用于心肌：心跳加快，收缩力加强 |
| 髓质 | 去甲肾上腺素 | 小动脉平滑肌收缩，维持血压 |

盐对水盐，糖对糖类，性对第二性征。肾上腺素对心，去甲肾上腺素对小动脉。五笔不要并成「肾上腺激素管血压」。
:::

:::pitfall{label="肾上腺素主要对心，去甲肾上腺素主要对小动脉，不要写反"}
本版把「心跳加快、收缩力加强」写在肾上腺素下；把「小动脉平滑肌收缩、维持血压」写在去甲肾上腺素下。写反之后，心和血管的靶就对调。
:::

:::insight{label="外圈出三类固醇样激素，芯子出两类儿茶酚胺"}
图6-5 剖面上，黄的一圈是皮质，红的芯是髓质。认面：先外后内，激素名单跟着走。
:::

:::keypoint{label="肾上腺三句话"}
- 肾上方，与肾同包于肾筋膜；左半月形，右三角形；重 6.8～7.2 g。
- 门在前面。周边皮质、中央髓质。
- 皮质：盐、糖、性三类激素。髓质：肾上腺素对心，去甲肾上腺素对小动脉。
:::

:::note{label="本节止于肾上腺"}
胸腺在胸骨柄后方、上纵隔前部，是下一节的户头。肾本身的形态见泌尿系统，这里只认「腺在肾上、共包肾筋膜」。
:::
