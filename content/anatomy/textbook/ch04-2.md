# 第二节　输尿管

第一节把肾写完：肾盂出肾门后向下弯行，约在第 2 腰椎上缘变细，移行为输尿管。本节把「输尿管」这一户写完：腹膜外位的肌性管道，腹部、盆部和壁内部三段行程，以及全程三处狭窄。膀胱三角、尿道内口是下一节的户头；男性尿道归生殖系统，不在这里展开。

输尿管输送肾生成的尿液至膀胱。它不是肾窦里的一段肾盂，也不是膀胱壁上的皱襞：起自肾盂末端，终于膀胱。管道走在腹膜外，全程贴腹后壁和盆壁下行，最后斜穿膀胱壁开口。

:::definition{label="输尿管"}
腹膜外位的**肌性管道**。平第 2 腰椎上缘（L2 上缘）起自肾盂末端，终于膀胱。职能是把尿液从肾输送到膀胱。
:::

:::definition{label="输尿管的长度与管径"}
长约 **20～30 cm**。管径平均 **0.5～1.0 cm**，最窄处口径约 **0.2～0.3 cm**。长度按这一段记，不要改成「约 25 cm」一个定点；最窄口径是三处狭窄共用的数，不是全程管径。
:::

:::concept{term="先问这是不是腹膜外的输尿管道，再问三部和三狭窄切在哪"}
看见输尿管，先不要默写结石。先问：它是不是腹膜外位的肌性管道、是不是从 L2 上缘的肾盂末端接到膀胱——答案是。再问三部：腹、盆、壁内。然后才问三狭窄落在哪三个平面。把输尿管听成「肾的一段」，腹部在腰大肌前面的行程会丢掉；把膀胱三角整段写进本节，又是吞了下一户。
:::

:::compare{title="和上一节交界的那一刀"}
| | 落在哪一户 |
|--|-----------|
| 肾盂容积、出肾门后向下弯行 | 第一节肾 |
| 约 L2 上缘变细、移行为输尿管 | 交界：上一节收笔，本节开篇 |
| 腹部、盆部、壁内部的行程 | 本节 |
| 膀胱三角、输尿管口的黏膜形态 | 第三节膀胱 |

起点平面两边都要认，户头不要并成「肾盂输尿管一体」。
:::

:::pitfall{label="输尿管是腹膜外位，不要写成走在腹膜腔里"}
本版原句：位于腹膜外位的肌性管道。写成「腹腔内位」或「被腹膜完全包绕」，腰大肌前面、盆侧壁和壁内部的行程都会画错层。它贴腹后壁和盆壁走，不在肠管之间悬挂。
:::

## 一、输尿管的位置和分部

输尿管分为输尿管腹部、输尿管盆部和输尿管壁内部（图4-11～图4-13）。三部是按行程分段，不是按管径分段：管径的最窄处另立「三狭窄」户头。

:::definition{label="输尿管三部"}
**腹部、盆部、壁内部**。腹部从肾盂下端走到骨盆入口，盆部从小骨盆入口走到膀胱壁，壁内部是斜行在膀胱壁里的那一段。名单不要改成「上、中、下」三部，也不要把三狭窄的名字当成三部的名字。
:::

:::compare{title="三部先认起止，再认邻居"}
| 部 | 本版起止 | 先认哪条邻居 |
|----|----------|--------------|
| 腹部 | 肾盂下端 → 骨盆入口 | 腰大肌前面；性腺血管在其前方 |
| 盆部 | 小骨盆入口 → 穿入膀胱壁之前 | 盆侧壁、髂内血管；男女此后分道 |
| 壁内部 | 位于膀胱壁内的斜行段 | 长约 1.5 cm；开口于膀胱三角 |

三部连起来才是一条管道。只背「从肾到膀胱」而不分段，髂血管和子宫动脉两处交叉会并成一个「盆腔交叉」。
:::

::figure{src="/images/anatomy/textbook/p0168_02.png" caption="图4-11　肾与输尿管造影模式图" alt="造影模式：两侧肾轮廓内可见肾盏肾盂呈树状显影，输尿管沿腰部和骨盆下行汇入盆腔内膀胱，骨盆轮廓可见"}

图4-11 把肾盏、肾盂、两侧输尿管和膀胱画在同一张骨盆轮廓上，用来认整条管道的上下游。造影里看到的是腔，不是腰大肌和子宫动脉；腹、盆两部的邻居要转到图4-12、图4-13。

:::insight{label="造影先认一条从肾盂到膀胱的连续腔"}
图4-11 里两侧管道在腰部几乎平行下行，入盆后向中线靠拢，开口于膀胱。这是三部连在一起的全貌；狭窄处口径只有 0.2～0.3 cm，在模式图上不必逐毫米去量，但行程上那三处「变细的门槛」要心里有数。
:::

:::keypoint{label="开篇先钉这几句"}
- 腹膜外位肌性管道。平 **L2 上缘**起自肾盂末端，终于膀胱。
- 长 **20～30 cm**；管径平均 **0.5～1.0 cm**；最窄 **0.2～0.3 cm**。
- 三部：腹部、盆部、壁内部。壁内部长约 **1.5 cm**。
- 图4-11 认全貌；图4-12 认男性腹部和跨髂血管；图4-13 认女性子宫动脉后下。
:::

### （一）输尿管腹部

输尿管腹部（abdominal part of ureter）起自肾盂下端，经腰大肌前面下行，至腰大肌中点附近，走行于男性睾丸血管或女性卵巢血管后方，达骨盆入口处。在此处，左侧输尿管越过左髂总动脉末端前方；右侧输尿管则越过右髂外动脉起始部的前方。

:::definition{label="输尿管腹部"}
起自**肾盂下端**，经**腰大肌前面**下行，到骨盆入口为止。这一部在腹膜后、脊柱两侧，和第一节肾的腹膜外位是同一层。
:::

:::definition{label="腹部与性腺血管"}
至腰大肌中点附近，输尿管走在男性**睾丸血管**或女性**卵巢血管**的**后方**。性腺血管在前，输尿管在后——不要写成输尿管跨过性腺血管前方。
:::

:::definition{label="左、右输尿管跨髂血管"}
达骨盆入口处：左侧越过**左髂总动脉末端**前方；右侧越过**右髂外动脉起始部**前方。两侧用词不同，本版不要并成「都跨髂总」或「都跨髂外」。
:::

::figure{src="/images/anatomy/textbook/p0168_03.png" caption="图4-12　男性输尿管走行" alt="男性腹后壁：下腔静脉、腹主动脉、两肾和肾上腺，输尿管经腰大肌前面下行；睾丸动静脉在其前方，并可见左结肠动脉、乙状结肠动脉、直肠上动脉和髂总动脉"}

图4-12 是男性腹后壁。先认腰大肌把输尿管托在前面，再认睾丸动、静脉从内上向外下跨过输尿管前方，最后认髂总动脉——管道在骨盆入口处从其前方越过，转入盆部。左结肠动脉、乙状结肠动脉和直肠上动脉是画面上的结肠支，不是输尿管的伴行动脉。

:::compare{title="腹部两处『谁在前』不要并"}
| 交叉 | 本版前后 |
|------|----------|
| 与睾丸血管 / 卵巢血管 | **血管在前**，输尿管在后 |
| 与髂血管（骨盆入口） | **输尿管在前**，动脉在后 |

前一处是性腺血管跨过输尿管；后一处是输尿管跨过髂动脉。写成「输尿管一律在血管前方」或「一律在后方」，两处交叉会并错。
:::

:::compare{title="骨盆入口：左髂总末端，右髂外起始"}
| | 本版原句 |
|--|----------|
| 左侧 | 越过**左髂总动脉末端**前方 |
| 右侧 | 越过**右髂外动脉起始部**前方 |

髂总末端和髂外起始本来就挨在分叉处，但默写必须按左右分开写。不要改成「两侧都跨髂总动脉中点」。
:::

:::pitfall{label="腹部贴腰大肌前面走，不要写成穿腰大肌或走在肌后面"}
本版原句：经腰大肌前面下行。图4-12 里管道躺在腰大肌表面。写成「穿腰大肌」或「在腰大肌后方」，和腹膜外位、后面的跨髂血管都接不上。
:::

:::pitfall{label="性腺血管在输尿管前方，不要写成输尿管跨过睾丸动脉前方"}
「走行于睾丸血管或卵巢血管后方」= 输尿管在后。把前后写反，腹部的浅深关系就和骨盆入口那一处（输尿管在髂动脉前方）搅成同一套错的。
:::

:::insight{label="腰大肌是腹部的滑梯，骨盆入口是滑梯的尽头"}
肾盂在 L2 上缘交出管道，管道贴着腰大肌前面往下滑，滑到骨盆入口才改叫盆部。图4-12 认的就是这一段滑梯：肌在后，管在前，性腺血管再盖在管前面。
:::

### （二）输尿管盆部

输尿管盆部（pelvic part of ureter）自小骨盆入口处，经盆腔侧壁、髂内血管、腰骶干和骶髂关节前方下行，跨过闭孔神经血管束，达坐骨棘水平。此后男、女分道，但都从膀胱底进入壁内部。

:::definition{label="输尿管盆部"}
自**小骨盆入口**起，沿盆腔侧壁下行。先经髂内血管、腰骶干和骶髂关节前方，再跨过闭孔神经血管束，达**坐骨棘**水平。坐骨棘是盆部行程里的高度标志，不是狭窄的名字。
:::

:::keypoint{label="盆部在坐骨棘以前，两侧共用这串邻居"}
- 起点：小骨盆入口（接腹部跨髂血管处）。
- 侧壁：髂内血管、腰骶干、骶髂关节都在其**后方**（管道走它们前方）。
- 再跨过闭孔神经血管束。
- 到达坐骨棘水平后，男、女走向才分开。
:::

**1. 男性盆部**　男性输尿管走向前、内、下方，经直肠前外侧壁与膀胱后壁之间下行，在输精管后外方与之交叉，从膀胱底外上角向内下斜穿膀胱壁。两侧输尿管达膀胱后壁处相距约 5 cm。

:::definition{label="男性输尿管盆部"}
坐骨棘水平之后：走向**前、内、下**。走在直肠前外侧壁与膀胱后壁之间；在**输精管后外方**与之交叉；从膀胱底**外上角**向内下斜穿膀胱壁。
:::

:::definition{label="两侧输尿管达膀胱后壁的间距"}
约 **5 cm**。这是穿壁以前、两管在膀胱后壁外上角附近的距离，不是空虚时三角区两输尿管口的 2.5 cm。
:::

:::compare{title="男性盆部：输尿管和输精管谁在后外"}
| | 本版 |
|--|------|
| 交叉时输尿管的位置 | 在输精管的**后外方** |
| 穿壁起点 | 膀胱底外上角，向内下斜穿 |
| 两管在后壁处的间距 | 约 **5 cm** |

「后外方与之交叉」不要听成输尿管走在输精管前内。穿壁方向是内下，所以后壁上 5 cm 的间距，到三角区口会收成 2.5 cm。
:::

:::pitfall{label="5 cm 是后壁处两管间距，不要写成两输尿管口间距"}
空虚时膀胱三角区两输尿管口间距约 2.5 cm。把 5 cm 安到口上，或把 2.5 cm 安到后壁上，壁内部斜行这段的「由外上收到内下」就没了。
:::

**2. 女性盆部**　女性输尿管经子宫颈外侧约 2.5 cm 处，从子宫动脉后下方绕过，行向下内至膀胱底穿入膀胱壁内。

:::definition{label="女性输尿管盆部"}
经**子宫颈外侧约 2.5 cm**处，从**子宫动脉后下方**绕过，再向下内至膀胱底，穿入膀胱壁。和男性一样，最后一笔是斜穿膀胱壁；和男性不一样的是邻居换成了子宫颈和子宫动脉。
:::

:::definition{label="桥下流水"}
子宫动脉是「桥」，输尿管是「水」：水从桥的**后下方**流过。本版原句是「从子宫动脉后下方绕过」，不是从动脉上方跨过，也不是与动脉平行伴行。
:::

::figure{src="/images/anatomy/textbook/p0168_01.png" caption="图4-13　女性输尿管走行" alt="女性骨盆：输尿管沿盆侧壁下行，在子宫颈外侧从子宫动脉后下方绕过达膀胱；邻卵巢、子宫、直肠，并可见髂内动脉、臀上动脉、臀下动脉、阴部内动脉、闭孔动脉、髂外动静脉和阴道动脉"}

图4-13 把女性盆部摊开：输尿管贴盆侧壁下行，子宫动脉从髂内动脉分出后向内走向子宫，在子宫颈外侧跨过输尿管前方。画面上还有卵巢、膀胱、子宫和直肠，以及臀上、臀下、阴部内、闭孔、阴道、直肠下等髂内分支——认交叉时先抓住「子宫动脉在前上、输尿管在后下」这一对，不要把所有盆壁动脉都当成桥。

:::compare{title="盆部在坐骨棘以后：男、女邻居不同"}
| | 男性 | 女性 |
|--|------|------|
| 走向 | 前、内、下 | 下内至膀胱底 |
| 夹在谁之间 | 直肠前外侧壁与膀胱后壁 | 子宫颈外侧约 2.5 cm |
| 与之交叉的管道 | 输精管（输尿管在其**后外方**） | 子宫动脉（输尿管在其**后下方**） |
| 穿壁 | 膀胱底外上角向内下斜穿 | 至膀胱底穿入膀胱壁内 |

两性都要斜穿膀胱壁。默写时不要把「输精管后外」安到女性，也不要把「子宫动脉后下」安到男性。
:::

:::pitfall{label="女性是子宫动脉后下方，不要写成输尿管从动脉上方跨过"}
「桥下流水」的方向写反，子宫手术结扎子宫动脉时就会把输尿管当成动脉一起处理。本版数字是子宫颈**外侧约 2.5 cm**，不要改成 2 cm 或 5 cm。
:::

:::pitfall{label="2.5 cm 在本节出现两次，量的不是同一段"}
| 本版 2.5 cm | 量的是什么 |
|-------------|------------|
| 子宫颈外侧约 2.5 cm | 女性输尿管与子宫颈的距离 |
| 空虚时两输尿管口间距约 2.5 cm | 膀胱三角上两口的距离 |

前者在盆部、宫旁；后者在膀胱内面。并成「输尿管口在子宫颈旁 2.5 cm」，妇科和膀胱镜会找错层。
:::

:::insight{label="图4-13 认交叉，先找子宫和膀胱，再找从两者之间穿过的那根管"}
子宫在后内，膀胱在前，子宫动脉横过宫旁去子宫，输尿管从动脉后下绕向膀胱底。把这根管认成阴道动脉或闭孔动脉，桥下流水就接到错的桥上。
:::

### （三）输尿管壁内部

输尿管壁内部（intramural part of ureter）是位于膀胱壁内、长约 1.5 cm 斜行的输尿管部分。在膀胱空虚时，膀胱三角区的两输尿管口间距约 2.5 cm。当膀胱充盈时，膀胱内压的升高能使内部的管腔闭合，从而阻止尿液由膀胱向输尿管反流。

:::definition{label="输尿管壁内部"}
位于**膀胱壁内**的斜行段，长约 **1.5 cm**。不是盆部的末 1.5 cm 贴在膀胱外面，而是斜着穿进壁里的那一段。
:::

:::definition{label="空虚时两输尿管口间距"}
膀胱三角区，约 **2.5 cm**。口是壁内部的开口，间距是空虚时的数；充盈时膀胱展开，口的相对位置会变，本版只钉空虚这一笔。
:::

:::definition{label="壁内部的抗反流"}
膀胱充盈 → 内压升高 → 壁内斜行的管腔被压闭合 → 尿液不能从膀胱倒流回输尿管。斜行本身就是活瓣：充得越满，压得越紧。
:::

:::cause-effect{title="为什么充盈时尿液不向输尿管反流"}
- **因** 壁内部在膀胱壁内斜行约 1.5 cm；充盈时膀胱内压升高，把这段管腔压扁、闭合
- **果** 膀胱里的尿液不能倒灌回输尿管

不是另长了一块「阀门软骨」。管道斜着埋进壁里，压力越大越闭合。
:::

:::compare{title="5 cm、2.5 cm、1.5 cm（三个长度不要并）"}
| 本版数字 | 量的是什么 |
|----------|------------|
| 达膀胱后壁处相距约 5 cm | 穿壁以前，两侧管道在后壁的间距 |
| 空虚时两输尿管口间距约 2.5 cm | 穿壁以后，三角区两口的间距 |
| 壁内部长约 1.5 cm | **每一侧**斜行在壁内的长度 |

5 cm 收到 2.5 cm，靠的就是两侧各 1.5 cm 的内下斜行。把 1.5 cm 听成两口间距，壁内部会短到只剩一个开口。
:::

:::pitfall{label="壁内部长约 1.5 cm，不要写成 2.5 cm"}
2.5 cm 是两口之间的距离，1.5 cm 是单侧斜行段的长度。两个数都出现在「膀胱空虚 / 三角区」附近，最容易并户。
:::

:::insight{label="从后壁 5 cm 收到三角 2.5 cm，斜行段就是收口的那一笔"}
两管在膀胱外面还隔着约 5 cm，钻进壁里向内下走 1.5 cm，开口就靠到 2.5 cm。三角的形态归下一节，但口为什么这么近，要从壁内部这一笔看。
:::

## 二、输尿管的狭窄

输尿管全程有 3 处狭窄：①上狭窄位于肾盂输尿管移行处；②中狭窄位于小骨盆上口，输尿管跨过髂血管处；③下狭窄位于输尿管的壁内部。狭窄处口径只有 0.2～0.3 cm。结石等管腔内的内容物容易在这三处嵌顿；三处的名字按位置叫上、中、下，和三部的腹、盆、壁内大体对应，但默写要用本版的解剖定位，不要只写「上中下」三个字。

:::definition{label="输尿管三狭窄"}
全程 **3** 处。上狭窄：肾盂输尿管移行处。中狭窄：小骨盆上口、跨髂血管处。下狭窄：壁内部。狭窄处口径 **0.2～0.3 cm**。
:::

:::definition{label="上狭窄"}
位于**肾盂输尿管移行处**。平面约在 L2 上缘，就是本节开篇那一刀。不要写成肾门，也不要写成肾盏。
:::

:::definition{label="中狭窄"}
位于**小骨盆上口**，输尿管**跨过髂血管**处。左侧对应左髂总动脉末端前方，右侧对应右髂外动脉起始部前方。不要写成跨过性腺血管处。
:::

:::definition{label="下狭窄"}
位于输尿管的**壁内部**。不是「膀胱外面贴壁的末段」，就是那条长约 1.5 cm 的斜行段。
:::

:::compare{title="三狭窄对上三部（定位不要丢）"}
| 狭窄 | 本版定位 | 大致落在哪一部 |
|------|----------|----------------|
| 上狭窄 | 肾盂输尿管移行处 | 腹部起点 |
| 中狭窄 | 小骨盆上口，跨髂血管处 | 腹、盆交界 |
| 下狭窄 | 壁内部 | 壁内部全段都窄 |

口径都是 0.2～0.3 cm。三部是行程分段，三狭窄是管径最窄的三处门槛——名单不要互相替换。
:::

:::compare{title="几个『口』和『径』"}
| 本版数字 | 指什么 |
|----------|--------|
| 管径平均 0.5～1.0 cm | 全程平均口径 |
| 最窄 / 狭窄处 0.2～0.3 cm | 三狭窄共用 |
| 壁内部长 1.5 cm | 斜行段的**长度**，不是口径 |
| 长 20～30 cm | 整条输尿管的长度 |

把 0.2～0.3 cm 听成壁内部的长度，或把 1.5 cm 听成最窄口径，结石嵌顿的「门槛」和斜行段会并成一个数。
:::

:::cause-effect{title="为什么结石容易停在三狭窄"}
- **因** 三处口径只有 0.2～0.3 cm，明显窄于平均管径 0.5～1.0 cm
- **果** 结石随尿流下行时，容易在移行处、跨髂血管处或壁内部嵌顿

疼痛向腹股沟区放射、肾区叩痛，要先在这三处门槛上找，而不是把全程当成一样粗的管子。
:::

:::pitfall{label="中狭窄在小骨盆上口跨髂血管，不要写成跨过腰大肌中点"}
腰大肌中点附近是腹部与性腺血管的关系，不是狭窄。三狭窄的中点是骨盆入口、髂血管那一处。写成「腰大肌中点狭窄」，髂窝和盆部的嵌顿平面会整体上移。
:::

:::pitfall{label="下狭窄是壁内部，不要写成尿道内口"}
尿道内口是膀胱通向尿道的口，户头在下一节。输尿管的下狭窄是斜穿膀胱壁的那一段管腔。两口都在膀胱，一个进、一个出，不要并。
:::

:::insight{label="三狭窄是三个门槛，不是把管子均分成三段"}
上门槛交出肾盂，中门槛跨进骨盆，下门槛斜埋进膀胱壁。图4-11 的连续显影在这三处最容易「细一细」；图4-12、图4-13 则把中门槛的髂血管和女性宫旁交叉画出来。
:::

:::keypoint{label="三狭窄就记这三处加一个口径"}
- ①肾盂输尿管移行处；②小骨盆上口跨髂血管处；③壁内部。
- 狭窄处口径 **0.2～0.3 cm**。
- 上对应 L2 上缘起点，中对应左髂总末端 / 右髂外起始，下对应 1.5 cm 斜行段。
:::

:::note{label="本节止于三狭窄"}
壁内部开口于膀胱三角的输尿管口。口与口之间的黏膜、输尿管间襞，以及膀胱尖、体、底、颈，归下一节。不要在这里把膀胱三角写完。
:::
