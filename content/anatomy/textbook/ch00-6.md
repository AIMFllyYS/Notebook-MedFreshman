# 六、 人体器官的变异与畸形

第一节把人体解剖学钉在「正常」人体的形态结构上，并写出因果：只有掌握正常，才能判断异常。本节把「正常」落到统计学上：教材所写的形态、构造、位置、大小、血液供应和神经配布，指的是占**绝大多数**的状态。接近正常、差异不显著的，叫变异；超出变异范围、出现率极低、甚至影响功能的，叫异常或畸形。每个人高矮胖瘦和器官形态的综合表现，另立一户，叫体型。不要用课外发病率表替换本版定义。学习方法留给第七节。

人体解剖学中描述的器官形态、构造、位置、大小及其血液供应和神经配布均指正常状态，在统计学上为绝大多数。人体的有些结构与正常形态虽不完全相同，但与正常值比较接近，差异不显著，称为变异（variation）。如超出一般变异范围，统计学上出现率极低，甚至影响正常生理功能者，称为异常（abnormal）或畸形（deformation）。人体结构虽基本相同，但受到遗传因素、发育状况、营养、职业和锻炼等的影响，致使每个人的高矮、胖瘦及器官形态等均有各自的特点，这些特点在人体上的综合表现称为体型。通常人体可分为矮胖型、瘦长型和适中型。

:::note{label="本节无教学插图"}
变异、畸形和体型在本版绪论中无教学插图。绪图-1、绪图-2 属于第五节。后文各论的变异示意图，等写到那一章再嵌入，不要提前把第一章、第九章的图搬进绪论。
:::

:::concept{term="先问是不是统计学上的绝大多数，再问差异显不显著、功能在不在"}
看见一个「和书上不太一样」的结构，先不要判病。先问三句话：① 教材写的正常，是不是占绝大多数的那一种；② 眼前这个只是接近正常、差异不显著——那是变异；③ 已经超出一般变异、出现率极低，甚至功能受影响——那是异常或畸形。体型是另一把尺子，量的是高矮胖瘦的综合表现，不是把矮胖写成畸形。
:::

## 一、先有「正常」：统计学上的绝大多数

人体解剖学中描述的器官形态、构造、位置、大小及其血液供应和神经配布均指正常状态，在统计学上为绝大多数。这一句把第一节的「正常人体」说具体了：正常不是「每一个人都长成同一毫米」，而是群体里占绝大多数的那一种模板。

:::definition{label="正常状态"}
教材描述的器官形态、构造、位置、大小、血液供应和神经配布，均指正常状态。正常是模板，不是「绝无差别的唯一形状」。
:::

:::definition{label="统计学上为绝大多数"}
正常状态在统计学上占绝大多数。判断一个结构算不算「书上写的那种」，先问它在人群中是不是最常见的那一型。少数接近它的，走变异；极少数超出并影响功能的，走异常或畸形。
:::

:::definition{label="形态、构造、位置、大小"}
正常要覆盖的不止外形。构造（内部构筑）、位置（在哪一区、哪一层）、大小，都在模板里。只核对「叫什么名字」，核对不到变异。
:::

:::definition{label="血液供应和神经配布也有正常模板"}
动脉来源、静脉回流、神经走行同样以绝大多数为正常。后文肘正中静脉「变异较多」、坐骨神经出盆方式有多种，都是在血管神经配布这本账上用本节的尺子。
:::

:::pitfall{label="不要把「正常」听成「人人完全相同」"}
结构虽基本相同，每个人仍有特点——那是体型段的开口。把正常听成模具里倒出来的同一件，所有个体差异都会被误判成病；把正常听成「怎样都算正常」，畸形又会失去户头。
:::

:::insight{label="模板是为了判断偏离，不是为了否认个体"}
第一节写：只有掌握正常，才能判断正常与异常。本节补上如何判断：先有占绝大多数的模板，再量差异是否显著、功能是否受影响。没有模板，变异和畸形都没有刻度。
:::

:::compare{title="「正常」在绪论里的三层意思"}
| 出处 | 说的是 | 还不是 |
|------|--------|--------|
| 第一节定义 | 研究对象是正常人体，不是病灶 | 尚未给出统计标准 |
| 本节第一句 | 形态、构造、位置、大小、血供、神经配布以绝大多数为正常 | 尚未命名变异 / 畸形 |
| 体型段 | 基本相同的前提下，仍有高矮胖瘦等综合特点 | 不是把体型等于畸形 |

三层叠在一起：先有模板，再有变异/畸形，另有体型。
:::

:::cause-effect{title="为什么解剖学必须先写绝大多数"}
- **因** 位置、毗邻、血供、神经配布若不先钉死最常见的一种，手术入路、影像读片、体格检查就没有对照
- **果** 教材把「绝大多数」写成正常；变异和畸形都相对这个模板来定义，而不是另起一套与正常无关的名单
:::

## 二、变异 variation

人体的有些结构与正常形态虽不完全相同，但与正常值比较接近，差异不显著，称为变异（variation）。

:::definition{label="变异 variation"}
与正常形态虽不完全相同，但与正常值比较接近，差异不显著。户头落在「接近」和「不显著」，不是「没有差别」，也还不是「影响功能」。
:::

:::definition{label="与正常值比较接近"}
变异仍在正常值附近。可以量大小、位置、分支数目、融合与否，但偏离尚未走出一般范围。
:::

:::definition{label="差异不显著"}
统计学和功能两条线上都还站得住：出现不算极低，功能通常保持。差异一旦显著到影响正常生理功能，就不再留在变异里。
:::

:::keypoint{label="变异三句话"}
- 不完全相同。
- 接近正常值。
- 差异不显著。
:::

:::pitfall{label="变异不是疾病，也不等于「可以忽略」"}
变异本身不是按病来命名的。但后文会反复写：有的变异「易误认为病变」（如叉状肋、肋骨联合），有的变异改变手术或穿刺所遇到的层次（如静脉、神经走行）。写成「变异＝没事」，临床会把正常范围里的差异当成病灶，或在变异的管道上按教科书典型走行下刀。
:::

:::insight{label="变异是模板周围的一条带子，不是模板外面的另一国"}
绝大多数是中心，变异是带子，畸形才跨出带子。把变异画到畸形那边，会把常见的形态差异病理化；把畸形收进变异，又会把影响功能的异常说成「个体差异」。
:::

:::compare{title="正常与变异"}
| | 正常 | 变异 |
|--|------|------|
| 与模板 | 就是教材写的那种 | 不完全相同 |
| 与正常值 | 落在作为标准的绝大多数 | 比较接近 |
| 差异 | — | 不显著 |
| 功能 | 正常生理功能 | 通常不作为「影响功能」来定义 |
| 本版用词 | 正常状态 | variation |

变异仍属于「可以在正常人体课里被描述」的范围；它不是病理解剖学的户头。
:::

## 三、异常 abnormal 或畸形 deformation

如超出一般变异范围，统计学上出现率极低，甚至影响正常生理功能者，称为异常（abnormal）或畸形（deformation）。本版把异常和畸形写成同一户的两种叫法，判断用的是同一套条件。

:::definition{label="异常 abnormal"}
超出一般变异范围，统计学上出现率极低，甚至影响正常生理功能。与畸形在本版是并列称呼。
:::

:::definition{label="畸形 deformation"}
本版与异常并列。英文用 deformation。不要另找课外的 malformation 来替换本版用词，也不要按维基的发病率表重写这一定义。
:::

:::definition{label="超出一般变异范围"}
已经走出「接近正常值、差异不显著」那条带子。光是「和书上不一样」还不够，必须是超出一般变异。
:::

:::definition{label="统计学上出现率极低"}
第二把尺子：不仅偏离，而且很少见。出现率极低是本版原句，本节不改写成某个百分比。后文某条结构若给出国人统计，那是各论的数字，不能拿来当本节的定义。
:::

:::definition{label="甚至影响正常生理功能"}
第三把尺子，也是最重的一把。功能一旦受影响，即使有人想把它说成「差异」，本版也归入异常或畸形。「甚至」表示：出现率极低已经可以入户，影响到功能则更应当入户。
:::

:::keypoint{label="异常 / 畸形的入户条件（本版）"}
- 超出一般变异范围。
- 统计学上出现率极低。
- 甚至影响正常生理功能。
- 本版称异常或畸形，不要拆成两个定义互相打架。
:::

:::pitfall{label="不要用课外发病率替换本版定义"}
本节没有给出「变异百分之几、畸形万分之几」的总表。把维基或其它教科书的发生率写进绪论，会和本版后文各论自己的统计打架，也会把定义从「范围 + 出现率 + 功能」改成「只看百分数」。数字若出现，只出现在后文该器官自己的段落里。
:::

:::pitfall{label="不要把「看起来少见」单独判成畸形"}
少见只是条件之一。有的结构变异可以相当常见（后文坐骨神经、肘正中静脉都明写「变异较常见 / 较多」），它们仍叫变异，因为还在一般范围内、功能定义未跨出去。只凭「我没见过」判畸形，尺子就不是本版的。
:::

:::compare{title="变异 vs 异常 / 畸形（本版定义）"}
| | 变异 variation | 异常 abnormal / 畸形 deformation |
|--|----------------|----------------------------------|
| 与正常形态 | 不完全相同 | 超出一般变异范围 |
| 与正常值 | 比较接近 | 不再用「接近」来定义 |
| 差异 | 不显著 | 显著到跨出一般变异 |
| 出现率 | 未写成「极低」 | 统计学上出现率极低 |
| 功能 | 不以影响功能为入户条件 | 甚至影响正常生理功能 |
| 还是不是解剖学课要描述的对象 | 是，作为正常附近的差异 | 是，作为必须与正常模板对照的偏离 |

两户都相对「绝大多数的正常」来定义，不是两套互相无关的名词。
:::

:::cause-effect{title="功能一受影响，户头就要从变异挪走"}
- **因** 本版把「甚至影响正常生理功能」写进异常 / 畸形的定义
- **果** 同一类胚胎事件，轻者可以只表现为形态上的接近差异，重者脊膜、脊髓膨出、肢体缺如、管道闭锁——功能账一旦出现，就不能再只说「变异」
:::

## 四、两把半尺子怎么用

定义里其实是「范围 / 出现率 / 功能」三句话。教学上可以缩成两把半尺子：先量离模板远不远，再量功能在不在；出现率用来挡住把常见变异病理化。

:::concept{term="先量离模板的距离，再量功能，最后才问出现率"}
先问：还接不接近正常值？接近、不显著 → 变异。已经超出一般变异 → 再问功能有没有受影响、出现率是不是极低 → 异常或畸形。不要反过来：先查一张发病率表，再决定它叫什么。
:::

:::compare{title="三句话分别挡住哪种误判"}
| 本版原句 | 挡住什么 |
|----------|----------|
| 与正常值比较接近，差异不显著 | 把所有「和书上不一样」都叫畸形 |
| 超出一般变异范围，出现率极低 | 把很常见的分支差异叫畸形 |
| 甚至影响正常生理功能 | 把已经造成功能障碍的偏离仍叫「个体差异」 |
:::

:::insight{label="后文常把「变异和畸形」写在同一条标题下"}
第一章有「上肢骨常见的变异和畸形」「下肢骨常见的变异和畸形」。那是各论把两户并列表出，并不等于两户定义被取消。读那些名单时，仍用本节的尺子逐条量：这一条只是接近正常，还是已经缺如、多指并指到影响功能。绪论不代替各论去给每一条贴标签。
:::

:::note{label="后文会落到的例子（只点名，不写各论）"}
这些名字属于后面各章，本节只说明「尺子将在哪里被用到」，不把各论正文搬过来，也不补课外发生率。

- 椎骨：两侧椎弓后端融合不全形成脊柱裂；第 1 骶椎不融合称骶椎腰化，第 5 腰椎与骶骨融合称腰椎骶化。轻重不同，功能影响不同。
- 肋：颈肋、叉状肋（本版写为最常见的肋骨变异，易误认为病变）、肋骨联合（易误认为肺内病变）。
- 上肢骨：先天性锁骨缺如，滑车上孔、髁上突，桡骨部分或全部缺如，多指或并指等，后文标题即「变异和畸形」。
- 下肢骨：髂窝穿孔，二分髌骨，多趾等，同样并举。
- 肘正中静脉：变异较多；可缺如而由前臂正中静脉分叉代替。
- 坐骨神经：出盆与梨状肌的关系有多种形式；本版在各论给出国人统计，并指出某些形式可导致功能障碍（梨状肌综合征）。

点名是为了让尺子有落点。具体形态、手术意义，回到各章再读。
:::

:::pitfall{label="不要在绪论里把后文例子全部判成畸形或全部判成变异"}
脊柱裂、锁骨缺如、多指并指，功能账和出现率账并不相同。本节的任务是把定义立住；各论的任务是描述该结构。提前在绪论里替后文下判，两节会抢户头。
:::

:::tip{label="读各论「常见变异」条时回扣三问"}
1. 它和教材作为正常来写的那一种差在哪（形态、位置、数目、血供、神经）？
2. 还接不接近正常值？
3. 有没有写到功能受影响或易误诊为病变？
三问能答，变异和畸形就不会并成一句「长得奇怪」。
:::

## 五、体型：矮胖型、瘦长型、适中型

人体结构虽基本相同，但受到遗传因素、发育状况、营养、职业和锻炼等的影响，致使每个人的高矮、胖瘦及器官形态等均有各自的特点，这些特点在人体上的综合表现称为体型。通常人体可分为矮胖型、瘦长型和适中型。

:::definition{label="体型"}
每个人在高矮、胖瘦及器官形态上的特点，在人体上的综合表现。前提是「人体结构虽基本相同」——体型不是畸形，也不是把正常人分成「正常」和「不正常」两群。
:::

:::definition{label="影响体型的因素（本版）"}
遗传因素、发育状况、营养、职业和锻炼。名单是这五类，不要自行改成星座、气质或课外体型学说的英文三型来替换。
:::

:::definition{label="矮胖型、瘦长型、适中型"}
本版给出的三种通常划分。适中型是对照；矮胖、瘦长是相对适中而言的综合形态，不是疾病名。
:::

:::compare{title="变异 / 畸形 / 体型 三户不要并"}
| | 变异 | 异常或畸形 | 体型 |
|--|------|------------|------|
| 问的是 | 某一结构相对正常模板的轻度差异 | 超出变异、极低出现率、甚至影响功能 | 全身高矮胖瘦及器官形态的综合表现 |
| 对象 | 具体结构（骨、血管、神经等） | 具体结构的严重偏离 | 整个人 |
| 本版用语 | variation | abnormal / deformation | 矮胖型、瘦长型、适中型 |
| 不要写成 | 体型的一种 | 「胖就是畸形」 | 「瘦长是内脏反位」 |

体型解释的是：为什么在正常模板之下，人与人仍看起来不同。它不取代变异，更不把矮胖、瘦长送进畸形。
:::

:::pitfall{label="不要把矮胖型、瘦长型写成畸形"}
体型段的主语是「人体结构虽基本相同」的每个人。营养、职业、锻炼都可以改写胖瘦和部分器官形态（第七节「形态与功能相互影响」会回扣锻炼这一笔），这仍在正常人体的范围内。写成「体型＝轻度畸形」，定义就被用错户头。
:::

:::pitfall{label="不要用课外体型分类替换本版三型"}
本版只写矮胖型、瘦长型、适中型。不引入其它学派的分型名称，也不给三型补一套没有写在本版里的内脏比例表。
:::

:::insight{label="职业和锻炼写进体型，已经在为「形态与功能相互影响」铺垫"}
影响体型的因素里有职业和锻炼：长期的功能需求会反过来改写形态。第七节把「形态与功能相互影响」立为四个观点之一。本节先承认：正常模板之下，活体仍会因功能而长出各自的特点。
:::

:::cause-effect{title="为什么体型必须单独立户"}
- **因** 遗传、发育、营养、职业、锻炼使高矮胖瘦和器官形态有各自特点，但结构仍基本相同
- **果** 这些特点的综合表现叫体型，分矮胖、瘦长、适中；它解释个体差异，却不把个体差异送进畸形名单
:::

:::keypoint{label="体型四句话"}
- 结构基本相同。
- 影响因素：遗传、发育、营养、职业、锻炼。
- 综合表现称为体型。
- 通常三型：矮胖型、瘦长型、适中型。
:::

## 六、与前后节的分界

:::compare{title="本节在绪论中的位置"}

:::memory{label="本节必背要点"}
- [ ] 教材描述的形态、构造、位置、大小、血液供应和神经配布，均指正常状态，在统计学上为绝大多数。
- [ ] 变异 variation：与正常形态不完全相同，但与正常值比较接近，差异不显著。
- [ ] 异常 abnormal 或畸形 deformation：超出一般变异范围，统计学上出现率极低，甚至影响正常生理功能。
- [ ] 异常和畸形在本版是同一户的两种叫法。
- [ ] 不要用课外发病率表替换上述定义。
- [ ] 体型：高矮、胖瘦及器官形态特点在人体上的综合表现。
- [ ] 影响因素：遗传因素、发育状况、营养、职业和锻炼。
- [ ] 通常分为矮胖型、瘦长型和适中型。
- [ ] 体型 ≠ 变异 ≠ 畸形；矮胖、瘦长不是畸形。
- [ ] 后文各论的「常见变异」「变异和畸形」名单，仍用本节尺子逐条量，不在绪论里提前下判。
:::
