# 第一节　骨

运动系统由骨、骨连结和骨骼肌组成，约占成人体重的 60%～70%，执行支持、保护和运动功能。本节把「骨」这一户写完：先立骨作为器官的总论，再按躯干骨、颅骨、附肢骨把成人骨骼的形态钉死，最后收到体表骨性标志。骨连结和骨骼肌是第二、第三节，不要提前写成关节或肌学。

全身各骨以不同形式连结构成骨骼，支持体重，保护内脏，维持体姿，赋予人体基本形态，并为骨骼肌提供广阔的附着点。骨还是重要的造血器官，并储存体内的钙、磷等矿物质。骨骼肌是运动系统的动力装置，跨过一个或多个关节，在神经系统支配下收缩牵拉其所附着的骨，以骨连结为枢纽，产生杠杆运动。骨和骨连结是运动系统的**被动部分**，骨骼肌则是**主动部分**。

:::definition{label="运动系统"}
由骨、骨连结和骨骼肌组成，约占成人体重的 60%～70%，执行支持、保护和运动功能。三件套缺一不可：没有骨就没有杠杆和保护壳，没有骨连结就没有枢纽，没有骨骼肌就没有动力。
:::

:::definition{label="被动部分与主动部分"}
骨和骨连结是运动系统的被动部分，骨骼肌是主动部分。被动不是「不重要」，而是本身不产生收缩；主动部分跨过关节牵拉骨，运动才发生。
:::

:::concept{term="先问这是不是运动系统的三件套，再问骨这一户有没有被写成关节"}
先问组成是不是骨、骨连结、骨骼肌，体重份额是不是 60%～70%，被动/主动有没有分清。再问本节是不是只写骨。韧带、关节腔、肌起止属于后两节。
:::

:::compare{title="运动系统三件套（本章三节各守一户）"}
| | 本节 | 第二节 | 第三节 |
|--|------|--------|--------|
| 户头 | 骨（器官） | 骨连结（直接连结与关节） | 骨骼肌 |
| 角色 | 杠杆、保护、造血、钙库 | 枢纽 | 动力 |
| 被动/主动 | 被动部分之一 | 被动部分之一 | 主动部分 |

:::

## 一、概述

骨（bone）是以骨组织（包括骨细胞、胶原纤维和基质等）为主体构成的器官，在结缔组织或软骨的基础上发育（骨化）形成。骨具有一定的形态，表面有较厚的致密结缔组织膜即骨膜包被，骨髓腔及小梁间隙分布有骨髓。骨膜内含丰富的血管、淋巴管及神经，能不断进行新陈代谢和生长发育，并有修复、再生和改建的能力。经常锻炼可促进骨的良好发育，长期废用则出现骨质疏松。骨为体内最坚硬的结缔组织，体内 99% 的钙以羟基磷灰石形式贮存于骨内，因而骨为体内最大的钙库，与钙、磷代谢关系密切。骨髓具有造血功能。

:::definition{label="骨"}
以骨组织为主体构成的**器官**，在结缔组织或软骨基础上骨化形成。它有形态、有骨膜、有骨髓，能代谢、生长、修复和改建。户头落在器官，不是一块无生命的钙板，也还不是「骨组织」这一组织学名词。
:::

:::insight{label="骨组织是材料，骨是器官"}
绪论把骨组织收在结缔组织里；本节把骨写成器官。材料可以在镜下看细胞和基质；器官还要问形态分类、表面标志、血供神经、骨髓和发生。把骨听成「就是硬组织」，骺软骨、红骨髓和骨膜成骨都会从开篇丢掉。
:::

:::pitfall{label="不要把骨听成不能改建的成品"}
经常锻炼促进发育，长期废用出现骨质疏松——说明骨一直在改建。骨折后骨膜重新活跃，也是同一笔账。写成「成人骨不再变化」，化学成分随年龄改变、黄骨髓在失血时逆转，都会变成超纲。
:::

### （一）骨的分类

成人有 **206** 块骨，其中 **6** 块听小骨属于感觉器。骨按部位可分为颅骨、躯干骨和附肢骨，前二者合称为中轴骨。按形态，骨可分为 4 类，内部构造各有特点。

::figure{src="/images/anatomy/textbook/p0034_01.png" caption="图1-1　全身骨骼"}

::figure{src="/images/anatomy/textbook/p0034_02.png" caption="图1-2　骨的内部构造"}

:::definition{label="中轴骨"}
颅骨与躯干骨合称中轴骨。附肢骨不在这一户。部位三分法是颅骨、躯干骨、附肢骨；中轴骨只收前两户。
:::

:::compare{title="部位三分与中轴骨"}
| 部位 | 收哪些 | 是否中轴骨 |
|------|--------|------------|
| 颅骨 | 脑颅 + 面颅（23 块，不含听小骨） | 是 |
| 躯干骨 | 椎骨、骶骨、尾骨、胸骨、肋 | 是 |
| 附肢骨 | 上肢骨 64 + 下肢骨 62 | 否 |

听小骨 6 块计入 206，但记在感觉器，不进颅骨 23。
:::

:::pitfall{label="不要把 206 听成「全是运动系统的骨」"}
6 块听小骨已经划给感觉器。考试若问「运动系统的骨有多少」，不能想当然把 206 原样搬过去；本版原句是成人有 206 块骨，其中 6 块听小骨属于感觉器。
:::

**1. 长骨（long bone）**　分布于四肢，呈长管状，分为一体两端。体又称骨干（diaphysis, shaft），内有空腔称髓腔（medullary cavity），容纳骨髓。体表面可见血管出入的孔，称滋养孔。两端膨大称骺（epiphysis），表面有光滑的关节面，与相邻关节面构成关节。骨干与骺相邻的部分称干骺端（metaphysis），幼年时保留透明软骨成分，称骺软骨（epiphysial cartilage）。骺软骨细胞不断分裂增殖和骨化，使骨不断加长。成年后，骺软骨骨化，骨干与骺融为一体，遗留的痕迹称骺线（epiphysial line）。骺软骨损伤会导致儿童长骨骨骺与干骺端之间形成骨性连接即骨桥，使骺板全部或部分提前闭合，造成肢体短缩和/或成角畸形。

:::definition{label="长骨"}
分布于四肢，呈长管状，一体两端。一体是骨干，两端是骺，中间隔着干骺端。内部有髓腔，不是实心棍。
:::

:::definition{label="骺软骨"}
干骺端的透明软骨。细胞不断分裂增殖和骨化，使骨加长。损伤后可形成骨桥，骺板提前闭合，造成短缩或成角畸形——这是儿科骨科的形态学底板，不是超纲。
:::

:::definition{label="骺线"}
成年后骺软骨骨化、骨干与骺融合所遗留的痕迹。X 线下不显影，呈空节。它是「曾经有过骺软骨」的化石，不是还能加长的生长板。
:::

:::pitfall{label="不要把骺线听成儿童还能用的生长板"}
骺软骨在，骨才能加长；骺线在，加长已经结束。把成人 X 线上的骺线当成还可以损伤的骺板，年龄和预后都会说错。
:::

**2. 短骨（short bone）**　形似立方体，多成群分布于连结牢固且运动较灵活的部位，如腕骨和跗骨。

**3. 扁骨（flat bone）**　呈板状，参与构成颅腔、胸腔和盆腔壁，可保护脏器，如颅盖骨和肋骨。

**4. 不规则骨（irregular bone）**　形状不规则，如椎骨。有些不规则骨内有与外界相通的腔洞，称含气骨（pneumatic bone），如上颌骨。

位于肌腱内的扁圆形小骨称籽骨（sesamoid bone），在运动中起着减少摩擦和改变肌肉牵拉方向的作用。髌骨是人体最大的籽骨。

:::compare{title="形态四类（内部构造对照图1-2）"}
| 类型 | 外形 | 内部要点 | 本版例子 |
|------|------|----------|----------|
| 长骨 | 长管状，一体两端 | 骨干密质 + 髓腔；骺为薄层密质包大量松质；可见骺线 | 四肢长骨 |
| 短骨 | 立方体，成群 | 外周薄层密质，内部骨小梁 | 腕骨、跗骨 |
| 扁骨 | 板状 | 外板、板障、内板 | 颅盖骨、肋骨 |
| 不规则骨 | 不规则 | 可含气 | 椎骨；上颌骨为含气骨 |

:::

:::pitfall{label="不要把含气骨、籽骨加成第五、第六类"}
本版明文：按形态分为 4 类。含气骨是不规则骨的亚型；籽骨是肌腱内的小骨。分类题若选出「五类」，就是把后文专名误当成并列户头。
:::

### （三）骨的构造

骨由骨质、骨膜和骨髓构成。

::figure{src="/images/anatomy/textbook/p0035_02.png" caption="图1-3　长骨的构造"}

构造就是这三件。关节软骨盖在关节面上，图1-3 画出来是交代关节端，不是第四件。

**1. 骨质（osseous substance）**　由骨组织构成，按结构可分为密质和松质。骨密质（compact bone）结构致密，抗压、抗扭曲性强，分布于骨的表面。骨松质（spongy bone）呈海绵状，由相互交织的骨小梁（bone trabecula）排列而成，配布于骨的内部。骨小梁的排列方向与骨所承受的压力和张力的方向平行，因而骨能承受较大的重量。扁骨的骨密质配布于表层，称内板和外板。外板厚而坚韧，富有弹性，内板薄而松脆，故颅盖骨骨折多见于内板。骨松质配布于中间，称板障（diploë），有板障静脉经过。短骨和长骨的骨骺，外周是薄层的骨密质，内部为大量的骨松质。

:::definition{label="骨质"}
由骨组织构成，分密质与松质。密质在表面，抗压抗扭曲；松质在内部，骨小梁沿压力和张力方向排列。扁骨表层密质称外板、内板，中间松质称板障。
:::

:::definition{label="板障"}
扁骨中间的骨松质，有板障静脉经过。不要把板障听成一种独立的骨。
:::

:::pitfall{label="颅盖骨折为什么多见于内板"}
外板厚而坚韧、富有弹性，内板薄而松脆。外力先打在外板，内板反而先裂——这是本版原句，不是「内板更表浅」。
:::

**2. 骨膜（periosteum）**　主要由纤维结缔组织构成，被覆于关节面以外的骨表面，含有丰富的神经、血管和淋巴管，对骨的营养、再生和感觉有重要作用。骨膜可分内、外两层：外层致密，有许多胶原纤维束穿入骨质，使之固着于骨面；内层疏松。骨髓腔和骨松质的网眼也衬有一层菲薄的结缔组织膜，称骨内膜（endosteum）。骨膜的内层和骨内膜有分化成骨细胞和破骨细胞的能力，可产生新骨质、破坏原骨质以重塑骨。幼年期骨膜功能活跃，以促进骨的生长；成年时相对静止，维持骨的生理状态。骨损伤时，如骨折，骨膜成骨功能重新活跃，以促进骨折的修复愈合。如骨膜过度剥离或损伤，则骨折愈合困难。

:::definition{label="骨膜"}
被覆于**关节面以外**的骨表面的纤维结缔组织膜，分内外两层，管营养、再生和感觉。关节面上没有骨膜，那里是关节软骨。
:::

:::definition{label="骨内膜"}
衬于骨髓腔和骨松质网眼的菲薄结缔组织膜。与骨膜内层一样，有分化成骨细胞和破骨细胞的能力。
:::

:::cause-effect{title="骨膜剥离为什么妨碍骨折愈合"}
- **因** 骨膜内层能分化成骨细胞，骨折时成骨功能重新活跃
- **果** 过度剥离或损伤骨膜，修复来源被拿走，愈合困难
:::

:::pitfall{label="不要以为成年骨膜已经退休"}
成年相对静止，只是维持生理状态；骨折时重新活跃。写成「成人骨膜无成骨能力」，手术中保护骨膜就没有依据。
:::

**3. 骨髓（bone marrow）**　为充填于骨髓腔和骨松质间隙内的软组织，分为红骨髓和黄骨髓。红骨髓（red bone marrow）含有不同发育阶段的红细胞和其他幼稚型血细胞，呈红色，有造血和免疫功能。胎儿和幼儿的骨髓均为红骨髓。5 岁以后，长骨骨干内的红骨髓逐渐被脂肪组织代替，呈黄色，称黄骨髓（yellow bone marrow），失去造血能力。失血过多或重度贫血时，黄骨髓能转化为红骨髓，恢复造血功能。椎骨、髂骨、肋骨、胸骨，以及肱骨和股骨等长骨的骺内终身存在红骨髓，临床常选髂前上棘或髂后上棘等处进行骨髓穿刺，检查骨髓象。

:::definition{label="红骨髓"}
充填于骨髓腔和骨松质间隙、呈红色的造血组织，含不同发育阶段的红细胞和其他幼稚型血细胞，兼有免疫功能。胎儿和幼儿全身骨髓都是红骨髓。
:::

:::definition{label="黄骨髓"}
5 岁以后长骨骨干内的红骨髓被脂肪组织代替而成，呈黄色，失去造血能力。失血过多或重度贫血时可逆转为红骨髓。
:::

:::compare{title="红骨髓与黄骨髓"}
| | 红骨髓 | 黄骨髓 |
|--|--------|--------|
| 颜色与成分 | 红；幼稚血细胞 | 黄；脂肪组织 |
| 功能 | 造血 + 免疫 | 失去造血能力（可逆） |
| 出现 | 胎儿、幼儿全身；成人在椎骨、髂骨、肋、胸骨及肱骨/股骨骺 | 5 岁以后长骨骨干 |
| 穿刺 | 临床选髂前上棘或髂后上棘 | 不作为常规穿刺点 |

终身有红骨髓的名单要按本版记，不要自行加减。
:::

### （四）骨的血管、淋巴管和神经

**1. 血管**　长骨的动脉包括滋养动脉、干骺端动脉、骺动脉及骨膜动脉，可分为骨干营养系统、骨骺-干骺端系统、骨膜-骨皮质系统。滋养动脉是长骨的主要动脉，一般有 1～2 支，经骨干滋养孔进入骨髓腔，分升支和降支达骨端，分支分布于骨干密质的内层、骨髓和干骺端，在成年人可与干骺端动脉及骺动脉分支吻合。干骺端动脉和骺动脉均发自邻近动脉，从骺软骨附近穿入骨质。不规则骨、扁骨和短骨的动脉来自骨膜动脉或滋养动脉。大多数动脉有静脉伴行。

::figure{src="/images/anatomy/textbook/p0036_01.png" caption="图1-4　长骨血供示意图"}

:::definition{label="滋养动脉"}
长骨的主要动脉，一般 1～2 支，经骨干滋养孔入髓腔，分升降支达骨端。它是骨干营养系统的主干，不是骨膜动脉的别名。
:::

**2. 淋巴管**　骨膜有丰富的淋巴管，但骨髓内、骨皮质内是否存在淋巴管，尚有争论。本版到此为止，不要写成「肯定没有」或「肯定有」。

**3. 神经**　伴滋养血管进入骨内，分布至哈弗斯管的血管周隙中。以内脏传出纤维（无髓）居多，分布至血管壁；躯体传入纤维（有髓）则多分布于骨膜。骨膜对张力或撕扯的刺激较敏感，故骨脓肿和骨折常引起剧痛。

:::pitfall{label="骨折剧痛首先是骨膜被撕扯"}
传入纤维多在骨膜，骨膜对张力和撕扯敏感。写成「痛是因为骨髓神经丰富」，与本版「骨髓内淋巴管尚有争论、神经主要随滋养血管入哈弗斯管」对不上。
:::

### （五）骨的化学成分和物理性质

骨由有机质和无机质组成。有机质主要是胶原纤维束和黏多糖蛋白等，构成骨的支架，赋予骨弹性和韧性。无机质主要是碱性磷酸钙，使骨坚硬挺实。脱钙骨（去除无机质）仍具原骨形状，但柔软有弹性；煅烧骨（去除有机质）虽形状不变，但脆而易碎。两种成分的比例随年龄增长发生变化。幼儿时期骨的有机质和无机质各占一半，故弹性较大，柔软，易变形，在外力作用下不易骨折或折而不断，称青枝骨折。成年人骨有机质和无机质的比例约为 3∶7，最为合适，因而骨具有较大的硬度和一定的弹性。老年人的骨无机质所占比例更大，脆性增加，但因激素水平下降，影响钙、磷的吸收和沉积，骨质呈现多孔性，骨组织总量减少，出现骨质疏松，此时骨的脆性较大，易发生骨折。

:::definition{label="青枝骨折"}
幼儿有机质与无机质约各占一半，骨弹性大，外力下不易完全折断或折而不断。名称来自折青树枝的形态，不是一种独立的骨病。
:::

:::compare{title="成分比例随年龄（本版数字）"}
| | 有机质∶无机质 | 力学 | 临床形态 |
|--|----------------|------|----------|
| 幼儿 | 约各占一半 | 弹性大，易变形 | 青枝骨折 |
| 成人 | 约 3∶7 | 硬度与弹性最合适 | — |
| 老年 | 无机质比例更大，且骨质疏松 | 脆性大 | 易骨折 |

:::

### （六）骨的发育和生长及维持和重建

骨发生于中胚层间充质。自胚胎第 8 周开始，间充质呈膜状分布并逐渐骨化，称膜化骨；或首先发育为软骨，继续骨化，称软骨化骨。

**1. 膜化骨**　间充质膜内细胞分化为成骨细胞，初始化骨处称骨化点，向外放射状增生。骨膜下成骨使骨加厚，骨化点边缘成骨使骨加宽，同时破骨改建。颅顶骨和面颅骨走此型。

**2. 软骨化骨**　先成软骨雏形。软骨体中部形成骨领，软骨膜成为骨膜；血管侵入中央，出现原发骨化点（初级骨化中心），中心破坏成骨髓腔。出生前后骺处出现继发骨化点（次级骨化中心）。骨膜成骨使骨干加粗，髓腔重建使腔扩大，骺软骨使骨加长。近成年骺软骨骨化成骺线；关节软骨终身不骨化。四肢骨（锁骨除外）和颅底骨走此型。

::figure{src="/images/anatomy/textbook/p0037_01.png" caption="图1-5　软骨化骨"}

:::definition{label="膜化骨"}
间充质呈膜状直接骨化。颅顶骨和面颅骨走这一条。加厚靠骨膜下成骨，加宽靠骨化点边缘成骨，同时破骨改建。
:::

:::definition{label="软骨化骨"}
先成软骨雏形，再骨化。四肢骨（锁骨除外）和颅底骨走这一条。原发骨化点在骨干，继发骨化点在骺。
:::

:::definition{label="原发骨化点"}
初级骨化中心。血管侵入软骨体中央，间充质进入形成红骨髓，成骨与破骨在此启动。中心被破坏即成骨髓腔。
:::

:::definition{label="继发骨化点"}
次级骨化中心，婴儿出生前后出现于长骨骺，于骺部造骨。它与原发骨化点之间隔着骺软骨。
:::

:::

### （一）椎骨

幼年时为 32 或 33 块，分为颈椎 7 块、胸椎 12 块、腰椎 5 块、骶椎 5 块、尾椎 3～4 块。成年后 5 块骶椎融合成骶骨，3～4 块尾椎融合成尾骨。

:::definition{label="椎骨的节段数目"}
颈椎 7、胸椎 12、腰椎 5；骶骨由 5 块骶椎融合；尾骨由 3～4 块尾椎融合。幼年 32 或 33 块，差别出在尾椎是 3 还是 4。成年后骶、尾已融合，独立椎骨按 24 块计。
:::

**1. 椎骨的一般形态**　椎骨（vertebrae）由前方短圆柱形的椎体和后方板状的椎弓组成。

椎体（vertebral body）是椎骨负重的主要部分，内部充满松质，表面的密质较薄，上、下面粗糙，借椎间盘与邻近椎骨相接。椎体后面微凹陷，与椎弓共同围成椎孔（vertebral foramen）。各椎孔上下贯通，构成容纳脊髓的椎管（vertebral canal）。

椎弓（vertebral arch）为弓形骨板，其紧连椎体的缩窄部分称椎弓根（pedicle of vertebral arch），根的上、下缘分别称椎上、下切迹。相邻椎骨的上、下切迹共同围成椎间孔（intervertebral foramen），有脊神经和血管通过。椎弓根向后内扩展变宽，称椎弓板（lamina of vertebral arch），两侧椎弓板于中线会合。由椎弓发出 7 个突起：棘突（spinous process）1 个，由椎弓后面正中伸向后方或后下方，尖端可在体表扪到；横突（transverse process）1 对，伸向两侧，棘突和横突都是肌和韧带的附着处；关节突（articular process）2 对，在椎弓根与椎弓板结合处分别向上、下方突起，即上关节突和下关节突，相邻关节突构成关节突关节。

:::definition{label="椎孔与椎管"}
椎体后面与椎弓围成椎孔；各椎孔上下贯通成椎管，容纳脊髓。椎孔是一节的孔，椎管是一串孔连起来的管道。
:::

:::definition{label="椎间孔"}
相邻椎骨的椎上切迹与椎下切迹共同围成，有脊神经和血管通过。它不在椎弓正中，而在两侧根部上下缘。
:::

**2. 各部椎骨主要的形态特征**

**（1）胸椎（thoracic vertebrae）**　椎体自上向下逐渐增大，横断面呈心形，矢径较横径略长；上部胸椎椎体近似颈椎，下部则近似腰椎。椎体两侧面后份的上缘和下缘有半圆形浅凹，称上、下肋凹，与肋头相关节。横突末端前面有横突肋凹，与肋结节相关节。关节突的关节面呈冠状位，上关节突关节面朝向后，下关节突朝向前。棘突较长，向后下方倾斜，各相邻棘突呈叠瓦状排列。

第 1 胸椎棘突粗大并水平向后，椎体有一圆形的全肋凹和一半圆形的下肋凹。第 9 胸椎可能存在下半肋凹缺如，第 10 胸椎只有一个上肋凹，第 11、12 胸椎各有一个全肋凹，横突无肋凹。本版用「可能」写第 9 胸椎，不要改成确定的百分率。

::figure{src="/images/anatomy/textbook/p0039_01.png" caption="图1-6　胸椎"}

**（2）颈椎（cervical vertebrae）**　椎体较小，横断面呈椭圆形。上、下关节突的关节面呈水平位。第 3～7 颈椎椎体上面侧缘向上突起称椎体钩（uncus of vertebrate body）。椎体钩与上位椎体下面的两侧唇缘相接，形成钩椎关节，又称 Luschka 关节。如椎体钩过度增生肥大，可致椎间孔狭窄，压迫脊神经，产生颈椎病的症状和体征。颈椎椎孔较大，呈三角形。横突有孔，称横突孔（transverse foramen），有椎动脉（向上穿第 6 至第 1 颈椎横突孔）和椎静脉通过。第 6 颈椎横突末端前方有明显的隆起，称颈动脉结节，有颈总动脉经其前方；当头部出血时，用手指将颈总动脉压于此结节，可暂时止血。第 2～6 颈椎的棘突较短，末端分叉。

::figure{src="/images/anatomy/textbook/p0039_02.png" caption="图1-7　颈椎（上面）"}

第 1 颈椎又名寰椎（atlas），呈环状，无椎体、棘突和关节突，由前弓、后弓及侧块组成。前弓较短，后面正中有齿突凹（dental fovea），与枢椎的齿突相关节。侧块连接前后两弓，上面各有一椭圆形关节面，与枕髁相关节；下面有圆形关节面与枢椎上关节面相关节。后弓较长，上面可见横行的椎动脉沟，有椎动脉通过。

::figure{src="/images/anatomy/textbook/p0039_03.png" caption="图1-8　寰椎"}

第 2 颈椎又名枢椎（axis），椎体向上伸出齿突（dens），与寰椎齿突凹相关节。齿突原为寰椎椎体，发育过程中脱离寰椎而与枢椎椎体融合。

::figure{src="/images/anatomy/textbook/p0040_01.png" caption="图1-9　枢椎（上面）"}

第 7 颈椎又名隆椎（prominent vertebrae），棘突长，末端不分叉，活体易于触及，常作为计数椎骨序数的标志。

::figure{src="/images/anatomy/textbook/p0040_02.png" caption="图1-10　隆椎（上面）"}

:::definition{label="寰椎"}
第 1 颈椎。环状，**无椎体、棘突和关节突**，由前弓、后弓及侧块组成。前弓后面有齿突凹。
:::

:::definition{label="枢椎"}
第 2 颈椎。椎体向上伸出齿突。齿突原是寰椎的椎体，发育中归到枢椎。
:::

:::definition{label="隆椎"}
第 7 颈椎。棘突长、末端不分叉，活体易触及，是计数椎骨的体表标志。
:::

:::definition{label="钩椎关节"}
第 3～7 颈椎椎体钩与上位椎体下面两侧唇缘相接形成，又称 Luschka 关节。椎体钩增生可窄椎间孔、压脊神经，出现颈椎病表现。
:::

:::pitfall{label="椎动脉不是从第7颈椎横突孔穿上来"}
本版原句：椎动脉向上穿第 6 至第 1 颈椎横突孔。隆椎仍有横突孔，但不是椎动脉的常规入口。写成「七个颈椎横突孔都走椎动脉」，止血按压的颈动脉结节（第 6 颈椎）也会对错节段。
:::

**（3）腰椎（lumbar vertebrae）**　椎体粗壮，横断面呈肾形。椎孔呈卵圆形或三角形。上、下关节突粗大，关节面几呈矢状位。上关节突后缘的卵圆形隆起称乳突。棘突宽短呈板状，水平伸向后方。各棘突的间隙较宽，临床上可于此进行腰椎穿刺术。

::figure{src="/images/anatomy/textbook/p0040_03.png" caption="图1-11　腰椎"}

:::compare{title="颈、胸、腰椎怎么一眼分开"}
| | 椎体切面 | 关节面方向 | 棘突 | 特有结构 |
|--|----------|------------|------|----------|
| 颈椎 | 小，椭圆 | 水平位 | C2～C6 短、分叉；C7 长不分叉 | 横突孔；C3～C7 椎体钩 |
| 胸椎 | 心形 | 冠状位 | 长，后下倾斜，叠瓦状 | 椎体肋凹、横突肋凹 |
| 腰椎 | 粗壮，肾形 | 几呈矢状位 | 宽短板状，水平向后，间隙宽 | 乳突；利于腰穿 |

关节面方向决定运动优势，不要只背「腰椎最大」。
:::

**（4）骶骨（sacrum）**　由 5 块骶椎融合而成，呈三角形，底向上，尖朝下。盆面（前面）凹陷，上缘中份向前隆凸，称岬（promontory）。盆面中部可见 4 条横线，是椎体融合的痕迹，横线两端有 4 对骶前孔。背面粗糙隆凸，正中线处为骶正中嵴，嵴外侧有 4 对骶后孔。骶前、后孔分别有骶神经前、后支通过，均与骶管相通。骶管上端通连椎管，下端的裂孔称骶管裂孔（sacral hiatus），裂孔两侧有向下突出的骶角（sacral horn），骶管麻醉常以骶角作为标志。骶骨外侧部上宽下窄，上份有耳状面与髂骨的耳状面构成骶髂关节，耳状面后方骨面凹凸不平，称骶粗隆。骶骨参与构成骨盆后壁，上连第 5 腰椎，下接尾骨。

**（5）尾骨（coccyx）**　由 3～4 块退化的尾椎融合而成。上接骶骨，下端游离为尾骨尖。跌倒或撞击可能导致尾骨骨折。

::figure{src="/images/anatomy/textbook/p0041_01.png" caption="图1-12　骶骨和尾骨"}

**3. 椎骨的常见变异**　两侧椎弓后端融合不全则形成脊柱裂，常见于腰骶部。较轻者为隐性脊柱裂，常出现腰痛；重者则脊膜甚至脊髓和马尾经此膨出。椎骨数目也可变异：第 1 骶椎不与其他骶椎融合而成第 6 腰椎，称骶椎腰化；第 5 腰椎与骶骨融合，称腰椎骶化。本版没有给出发生率，不要补百分率。

:::pitfall{label="腰化、骶化是数目重新划分，不是多长出一块无关的骨"}
骶椎腰化：本该融合的 S1 变成 L6。腰椎骶化：本该独立的 L5 并进骶骨。计数椎骨和读片时，先问「这一块算腰还是算骶」。
:::

### （二）胸骨

胸骨（sternum）为长方形扁骨，位于胸前壁正中，前凸后凹，自上而下可分柄、体和剑突三部分。胸骨柄（manubrium sterni）上宽下窄，上缘中份为颈静脉切迹（jugular notch），两侧有锁切迹与锁骨连结。柄外侧缘上份接第 1 肋软骨。柄与体连接处微向前突，称胸骨角（sternal angle），可在体表扪及，两侧平对第 2 肋，是计数肋的重要标志。胸骨角部位又相当于左、右主支气管分叉处，主动脉弓下缘水平，心房上缘，上、下纵隔交界部；向后平对第 4 胸椎椎体下缘。胸骨体（body of sternum）呈长方形，外侧缘连接第 2～7 肋软骨。剑突（xiphoid process）扁而薄，形状变化较大，下端游离。

::figure{src="/images/anatomy/textbook/p0042_01.png" caption="图1-13　胸骨（前面）"}

:::definition{label="胸骨角"}
胸骨柄与胸骨体连接处微向前的隆起，体表可扪及，两侧平对第 2 肋，是计数肋的标志。平面还对：左右主支气管分叉、主动脉弓下缘、心房上缘、上下纵隔交界；向后平 T4 椎体下缘。
:::

### （三）肋

肋（rib）由肋骨与肋软骨组成，共 12 对。第 1～7 对肋前端直接与胸骨连结，称真肋。其中第 1 对肋与胸骨柄间为软骨结合，第 2～7 对肋与胸骨构成微动的胸肋关节。第 8～10 对肋不直接与胸骨相连，称假肋；肋前端借肋软骨与上位肋软骨连结，形成肋弓（costal arch）。第 11～12 对肋前端游离于腹壁肌层中，称浮肋。

:::definition{label="真肋、假肋、浮肋"}
真肋：第 1～7 对，前端直接连胸骨。假肋：第 8～10 对，借肋软骨连上位肋软骨成肋弓。浮肋：第 11～12 对，前端游离于腹壁肌。12 对都是肋，只是前端去向不同。
:::

**1. 肋骨（costal bone）**　属扁骨，分为体和前、后两端。后端膨大称肋头（costal head），有关节面与胸椎上、下肋凹相关节。肋头外侧稍细，称肋颈（costal neck）。颈外侧的粗糙突起称肋结节（costal tubercle），与相应胸椎横突肋凹相关节。肋体（shaft of rib）长而扁，分内、外两面和上、下两缘；内面近下缘处有肋沟（costal groove），肋间神经和血管走行其中。体的后份急转处称肋角（costal angle）。前端稍宽，与肋软骨相接。

第 1 肋骨扁宽而短，分上、下面和内、外缘，无肋角和肋沟。内缘前份有前斜角肌结节，其前、后方分别有锁骨下静脉和锁骨下动脉经过的压迹（沟）。第 2 肋骨为过渡型。第 11、12 肋骨无肋结节、肋颈及肋角。

::figure{src="/images/anatomy/textbook/p0042_02.png" caption="图1-14　肋骨"}

:::pitfall{label="肋沟在内面近下缘，血管神经走下缘"}
沿肋骨下缘进针或切开，容易伤肋间神经和血管。写成「沟在上缘」，胸腔穿刺的安全边界会反。
:::

**2. 肋软骨（costal cartilage）**　位于各肋骨前端，由透明软骨构成，终身不骨化。

**3. 肋的先天变异**　颈肋见于一侧或两侧，为短小较直的小肋骨，多自第 7 颈椎处伸出。叉状肋为最常见的肋骨变异，肋骨前端呈叉状，有时一支明显、另一支短小甚至仅为突起，易误认为病变。肋骨联合多见于第 5、6 肋的后端，相邻两条肋骨局部呈骨性联合，肋间隙变窄，易误认为肺内病变。本版只说叉状肋「最常见」，没有给出百分率。

## 三、颅骨

颅骨有 **23** 块（中耳的 3 对听小骨未计入）。除下颌骨和舌骨外，彼此借缝或软骨牢固连结形成颅（skull），保护并支持脑和感觉器，并构成消化和呼吸系统的起始部。以眶上缘、外耳门上缘和枕外隆凸的连线为界，颅分为后上部的脑颅与前下部的面颅。

:::definition{label="颅的分界"}
眶上缘、外耳门上缘和枕外隆凸的连线：后上为脑颅，前下为面颅。不要按「上面是脑、下面是脸」随便画一条水平线。
:::

:::compare{title="颅骨 23 块怎么分（不含听小骨）"}
| | 数目 | 不成对 | 成对 |
|--|------|--------|------|
| 脑颅 | 8 | 额骨、筛骨、蝶骨、枕骨 | 颞骨、顶骨 |
| 面颅 | 15 | 犁骨、下颌骨、舌骨 | 上颌骨、腭骨、颧骨、鼻骨、泪骨、下鼻甲 |

8 + 15 = 23。听小骨 6 块另属感觉器，计入成人 206，不进这张表。
:::

:::pitfall{label="不要把筛骨听成「纯脑颅」或「纯面颅」"}
筛骨计入脑颅 8 块，但仅一小部分参与脑颅，其余构成面颅。名单在脑颅，形态大部分在鼻腔和眶。
:::

### （一）脑颅骨

脑颅由 8 块骨组成，参与构成颅腔。颅腔的顶为穹窿形的颅盖（calvaria），由额骨、顶骨和枕骨构成。颅腔的底由中部的蝶骨、后方的枕骨、两侧的颞骨、前方的额骨和筛骨构成。

各骨形态用对照表加短述，不为每块骨单开一张定义。

:::compare{title="脑颅 8 块：位置与分部"}
| 骨 | 成对 | 关键分部或标志 |
|----|------|----------------|
| 额骨 | 否 | 额鳞（额结节、额窦）、眶部、鼻部（筛切迹） |
| 筛骨 | 否 | 「巾」字形：筛板（鸡冠、筛孔）、垂直板、筛骨迷路（上/中鼻甲、眶板） |
| 蝶骨 | 否 | 体（蝶鞍、垂体窝、蝶窦）、大翼、小翼、翼突 |
| 枕骨 | 否 | 枕骨大孔分四部：基底部、枕鳞、两侧部（枕髁） |
| 颞骨 | 是 | 以外耳门为中心：鳞部、鼓部、岩部（锥部） |
| 顶骨 | 是 | 四边形，矢状缝、冠状缝、人字缝 |
:::

**额骨（frontal bone）**　位于颅的前上方，分三部。额鳞是贝壳状扁骨，中央隆起称额结节，内含额窦，开口于鼻腔。眶部为后伸的水平薄骨板，构成眶上壁。鼻部位于两侧眶部之间，呈马蹄铁形，与筛骨和鼻骨连结，缺口处为筛切迹。

::figure{src="/images/anatomy/textbook/p0043_02.png" caption="图1-15　额骨（前面）"}

**筛骨（ethmoid bone）**　脆弱的含气骨，冠状切面呈「巾」字形：筛板（鸡冠、筛孔）构成鼻腔顶；垂直板构成骨性鼻中隔上部；迷路内侧附上、中鼻甲，外侧眶板极薄，构成眶内侧壁。

::figure{src="/images/anatomy/textbook/p0043_01.png" caption="图1-16　筛骨"}

**蝶骨（sphenoid bone）**　形似展翅的蝴蝶，居颅底中央，分体、大翼、小翼和翼突。体内含蝶窦，向前开口于蝶筛隐窝；体上面马鞍状为蝶鞍，中央为垂体窝（hypophysial fossa），两侧为颈动脉沟。大翼根部自前内向后外依次为圆孔、卵圆孔、棘孔。小翼与体交界处为视神经管，小翼与大翼之间为眶上裂。翼突分内、外侧板，根部有翼管通翼腭窝。

::figure{src="/images/anatomy/textbook/p0044_01.png" caption="图1-17　蝶骨（前面）"}

::figure{src="/images/anatomy/textbook/p0044_02.png" caption="图1-18　蝶骨（上面）"}

**颞骨（temporal bone）**　以外耳门为中心分鳞部、鼓部、岩部（锥部）。鳞部颧突与颧骨颞突构成颧弓，根部下面为下颌窝和关节结节。鼓部从前、下、后三面围绕外耳道。岩部尖朝前内：前面有弓状隆起、鼓室盖、三叉神经压迹；后面有内耳门通内耳道；下面有颈动脉管（外口→内口）、颈静脉窝、茎突；后份为乳突（含乳突小房），茎突根部后方为茎乳孔。岩部孔隙管道多，1/3 的颅底骨折发生于此。

::figure{src="/images/anatomy/textbook/p0044_03.png" caption="图1-19　颞骨（外面）"}

::figure{src="/images/anatomy/textbook/p0045_01.png" caption="图1-20　颞骨（内面）"}

**枕骨（occipital bone）**　位于颅的后下部，呈勺状。前下部有枕骨大孔（foramen magnum）。枕骨借此孔分为四部：前为基底部，后为枕鳞，两侧为侧部。侧部下方有椭圆形关节面，称枕髁。枕骨大孔后方有枕外嵴延伸至枕外隆凸，隆凸向两侧延伸为上项线，其下方有与之平行的下项线。

**顶骨（parietal bone）**　外隆内凹，呈四边形，居颅顶中部，左右各一。两块顶骨以矢状缝相连，前方经冠状缝同额骨相连，后方经人字缝与枕骨相连。

:::pitfall{label="1/3 的颅底骨折在岩部，不要改成别的分数"}
本版写颞骨岩部孔隙管道多、较脆弱，1/3 的颅底骨折发生于此。这是教材给出的比例，不要换成「最常见」却改掉数字，也不要发明其他部位的发生率。
:::

### （二）面颅骨

面颅有 15 块骨。成对的包括上颌骨、腭骨、颧骨、鼻骨、泪骨及下鼻甲，不成对的有犁骨、下颌骨和舌骨。面颅诸骨连结构成眼眶、鼻腔和口腔的骨性支架。

:::compare{title="面颅 15 块"}
| | 名单 |
|--|------|
| 成对（6×2） | 上颌骨、腭骨、颧骨、鼻骨、泪骨、下鼻甲 |
| 不成对（3） | 犁骨、下颌骨、舌骨 |
:::

**下颌骨（mandible）**　最大的面颅骨，一体两支。体上缘为牙槽弓，外面有颏隆凸和颏孔，内面有颏棘、二腹肌窝。下颌支末端前方冠突、后方髁突（下颌头、下颌颈），两突之间为下颌切迹；后缘与下颌底相交为下颌角。支内面有下颌孔及下颌小舌。

::figure{src="/images/anatomy/textbook/p0045_02.png" caption="图1-21　下颌骨"}

**舌骨（hyoid bone）**　居下颌骨下后方，呈马蹄铁形。中间部称体，向后外延伸的长突为大角，向上的短突为小角。大角和体都可在体表扪到。

::figure{src="/images/anatomy/textbook/p0046_01.png" caption="图1-22　舌骨"}

**犁骨（vomer）**　斜方形骨板，组成骨性鼻中隔后下份。

**上颌骨（maxilla）**　成对，1 体 4 突，体内含上颌窦。前面有眶下孔和尖牙窝；眶面构成眶下壁，有眶下沟连眶下管；鼻面有上颌窦裂孔。四突：额突、颧突、牙槽突、腭突（组成骨腭前份）。

::figure{src="/images/anatomy/textbook/p0046_02.png" caption="图1-23　上颌骨"}

**腭骨（palatine bone）**　成对，呈 L 形，位于上颌骨腭突与蝶骨翼突之间，分水平板和垂直板：水平板组成骨腭后份，垂直板构成鼻腔外侧壁后份。

::figure{src="/images/anatomy/textbook/p0047_01.png" caption="图1-24　腭骨"}

**鼻骨（nasal bone）**　成对的长条形小骨片，上窄下宽，构成鼻背的基础。

**泪骨（lacrimal bone）**　菲薄的方形小骨片，位于眶内侧壁前份，前接上颌骨额突，后连筛骨眶板。

**下鼻甲（inferior nasal concha）**　薄而卷曲的小骨片，附于上颌体和腭骨垂直板的鼻面。上、中鼻甲是筛骨迷路的一部分，下鼻甲是独立的面颅骨——三块鼻甲不要写成三块筛骨。

**颧骨（zygomatic bone）**　位于眶的外下方，呈菱形，形成面颊的骨性突起。颧骨的颞突向后接颞骨的颧突，构成颧弓。

:::pitfall{label="下鼻甲是一块独立的面颅骨"}
上鼻甲、中鼻甲长在筛骨迷路上；下鼻甲单独入面颅 15 块名单。写成「三对鼻甲都属筛骨」，面颅数目会对不上。
:::

### （三）颅的整体观

除下颌骨和舌骨外，颅骨借膜和软骨牢固结合成一整体。

**1. 颅顶面观**　呈卵圆形，前窄后宽，光滑隆凸。顶骨中央最隆凸处称顶结节。额骨与两侧顶骨连结构成冠状缝（coronal suture），两侧顶骨连结构成矢状缝（sagittal suture），两侧顶骨与枕骨连结构成人字缝（lambdoid suture）。矢状缝后份两侧常有顶孔。

**2. 颅后面观**　可见人字缝和枕鳞。枕鳞中央最突出部为枕外隆凸（external occipital protuberance）。隆凸向两侧的弓形骨嵴称上项线，其下方有与之平行的下项线。

**3. 颅内面观**　颅盖内面凹陷，有与脑沟回对应的压迹与骨嵴。两侧有树枝状动脉沟，是脑膜中动脉及其分支的压迹。正中线上为上矢状窦沟，沟两侧有颗粒小凹，为蛛网膜粒的压迹。

颅底内面凹凸不平，自前向后有三个呈阶梯状加深的陷窝，分别称颅前、中、后窝。窝中有诸多孔、裂，多数与颅底外面相通。

::figure{src="/images/anatomy/textbook/p0048_01.png" caption="图1-25　颅底内面观"}

**（1）颅前窝（anterior cranial fossa）**　位置最高，由额骨眶部、筛骨筛板和蝶骨小翼构成。自正中线由前至后有额嵴、盲孔、鸡冠等结构。筛板上有筛孔通鼻腔。

**（2）颅中窝（middle cranial fossa）**　中间狭窄、两侧宽广，以颞骨岩部上缘及鞍背与颅后窝分界。中央垂体窝与鞍背合称蝶鞍，两侧颈动脉沟通眶上裂，沟后端为破裂孔。蝶鞍两侧自前内向后外：圆孔、卵圆孔、棘孔；脑膜中动脉沟自棘孔走出。还有视神经管、前/后床突、鼓室盖和三叉神经压迹。

**（3）颅后窝（posterior cranial fossa）**　最深。中央枕骨大孔，前上为斜坡，前外缘为舌下神经管内口。枕内隆凸向上续上矢状窦沟，向下续枕内嵴，向两侧续横窦沟→乙状窦沟→颈静脉孔。岩部后面有内耳门。

:::compare{title="颅底内面三窝（阶梯加深）"}
| | 位置 | 主要构成 | 通眶或通外的关键孔裂 |
|--|------|----------|------------------------|
| 颅前窝 | 最高 | 额骨眶部、筛板、蝶骨小翼 | 筛孔 → 鼻腔 |
| 颅中窝 | 中间 | 蝶骨体及大翼、颞骨岩部 | 视神经管、眶上裂 → 眶；圆孔、卵圆孔、棘孔、破裂孔 |
| 颅后窝 | 最深 | 枕骨、颞骨岩部后部 | 枕骨大孔、舌下神经管内口、颈静脉孔、内耳门 |
:::

**4. 颅底外面观**　自前向后依次为：牙槽弓与骨腭（腭中缝、切牙孔通切牙管、腭大孔）；鼻后孔被犁骨分成左右，两侧为翼突内侧板；翼突外侧板根部后外方为卵圆孔和棘孔；后方中央为枕骨大孔，前方枕骨基底部与蝶骨体结合（25 岁以前借软骨结合），两侧枕髁，髁前外侧稍上为舌下神经管外口，髁后方有不恒定的髁管开口。枕髁外侧为颈静脉孔，前方为颈动脉管外口；后外侧为茎突和茎乳孔。颧弓根部后方为下颌窝及关节结节。蝶骨、枕骨基底部和颞骨岩部会合处为破裂孔，活体由软骨封闭。

::figure{src="/images/anatomy/textbook/p0048_02.png" caption="图1-26　颅底外面观"}

活体破裂孔为软骨封闭，干骨标本上的破洞不等于开放通道。

**5. 颅侧面观**　由额骨、蝶骨、顶骨、颞骨及枕骨构成，亦可见面颅的颧骨和上、下颌骨。侧面中部有外耳门，后方为乳突，前方为颧弓，二者均可在体表触及。颧弓将颅侧面分为上方的颞窝和下方的颞下窝。

::figure{src="/images/anatomy/textbook/p0049_01.png" caption="图1-27　颅侧面观"}

**（1）颞窝（temporal fossa）**　上界为颞线。颞窝前下部较薄，在额、顶、颞、蝶骨会合处最为薄弱，此处常构成 H 形的缝，称翼点（pterion），位于颧弓中点上方两横指（或 3.5～4.0 cm）处。其内面常有血管沟，脑膜中动脉前支由此沟通过。此处骨板薄弱，骨折时易伤及该动脉，形成硬膜外血肿。

:::definition{label="翼点"}
额、顶、颞、蝶四骨会合处，常成 H 形缝，位于颧弓中点上方两横指（或 3.5～4.0 cm）。深面有脑膜中动脉前支，骨折易致硬膜外血肿。
:::

**（2）颞下窝（infratemporal fossa）**　位于颧弓平面以下，是上颌骨体和颧骨后方的不规则间隙，容纳咀嚼肌和血管神经等，向上与颞窝通连。前壁为上颌骨体和颧骨，内壁为翼突外侧板，外壁为下颌支，下壁与后壁缺如。向上经卵圆孔和棘孔通颅中窝，向前经眶下裂通眶，向内经翼上颌裂通翼腭窝。

**（3）翼腭窝（pterygopalatine fossa）**　为上颌骨体、蝶骨翼突和腭骨之间的窄间隙，深藏于颞下窝内侧。源于口鼻腔、眶内、颅中窝、颞下窝和鼻旁窦的病变均可能蔓延至此窝。

::figure{src="/images/anatomy/textbook/p0050_01.png" caption="图1-28　翼腭窝"}

:::compare{title="翼腭窝六条出路"}
| 方向 | 经何结构 | 通到哪里 |
|------|----------|----------|
| 向外 | （直接） | 颞下窝 |
| 向前 | 眶下裂 | 眶 |
| 向内 | 蝶腭孔 | 鼻腔 |
| 向后 | 圆孔 | 颅中窝 |
| 向后 | 翼管 | 颅底外面 |
| 向下 | 腭大管 → 腭大孔 | 口腔 |
:::

**6. 颅前面观**　可见额骨和面颅诸骨。面部中央为梨状孔，向后通鼻腔；孔的外上方为眶，下方为上、下颌骨围成的骨性口腔。分为额区、眶、骨性鼻腔和骨性口腔。

::figure{src="/images/anatomy/textbook/p0050_02.png" caption="图1-29　颅前面观"}

**（1）额区**　眶以上的部分，由额鳞组成。两侧有额结节，结节下方有与眶上缘平行的眉弓，其内侧份深面有额窦。左右眉弓间的平坦部称眉间。眉弓与眉间都是重要的体表标志。

**（2）眶（orbit）**　为底朝前外、尖向后内的一对四棱锥形深腔，分上、下、内侧、外侧四壁，容纳眼球及附属结构。

::figure{src="/images/anatomy/textbook/p0051_01.png" caption="图1-30　眶"}

底即眶口，眶上缘中内 1/3 交界处有眶上孔或眶上切迹，眶下缘中份下方有眶下孔。尖向后内，视神经管通颅中窝。四壁见下表。眶下壁和内侧壁较薄弱，是眼眶骨折最常累及的部位。泪囊窝经鼻泪管通鼻腔；眶下裂通颞下窝和翼腭窝。

:::compare{title="眶四壁与相邻"}
| 壁 | 主要构成 | 相邻或交通 |
|----|----------|------------|
| 上壁 | 额骨眶部、蝶骨小翼 | 颅前窝；泪腺窝 |
| 内侧壁 | 上颌骨额突、泪骨、筛骨眶板、蝶骨体 | 最薄；筛窦、鼻腔；泪囊窝 → 鼻泪管 |
| 下壁 | 上颌骨为主 | 上颌窦；眶下裂 → 颞下窝、翼腭窝 |
| 外侧壁 | 颧骨、蝶骨大翼 | 较厚；眶上裂 → 颅中窝 |
:::

**（3）骨性鼻腔（bony nasal cavity）**　顶窄底宽，由犁骨和筛骨垂直板构成的骨性鼻中隔分为左右两半。顶为筛板，筛孔通颅前窝，筛板薄脆，是鼻部手术危险区。底为骨腭，前端切牙管通口腔。外侧壁自上而下为上、中、下鼻甲及相应鼻道，鼻甲与鼻中隔之间为总鼻道。上鼻甲后上方为蝶筛隐窝；中鼻甲后方蝶腭孔通翼腭窝；中鼻道有筛泡、钩突、半月裂孔和筛漏斗；下鼻道前上方有鼻泪管开口。前方梨状孔，后方鼻后孔通咽腔。

::figure{src="/images/anatomy/textbook/p0051_02.png" caption="图1-31　骨性鼻腔"}

**（4）鼻旁窦（paranasal sinus）**　是上颌骨、额骨、蝶骨及筛骨内的骨腔，位于鼻腔周围并开口于鼻腔，具有发音共鸣和减轻颅骨重量的作用。

::figure{src="/images/anatomy/textbook/p0052_01.png" caption="图1-32　鼻腔外侧壁（切除部分鼻甲）"}

**（5）骨性口腔（bony oral cavity）**　由上颌骨、腭骨及下颌骨围成。顶即骨腭，前方正中有切牙孔，后方两侧有腭大孔和腭小孔。前壁及外侧壁由上、下颌骨牙槽部及牙围成，向后通咽，底由软组织封闭。

### （四）新生儿颅的特征及生后变化

胎儿时期脑及感觉器官发育早，而咀嚼和呼吸器官、尤其是鼻旁窦尚不发达，因此脑颅远大于面颅。新生儿面颅占全颅的 1/8，成人为 1/4。额结节、顶结节和枕鳞都是骨化中心部位，发育明显，从颅顶观察呈五角形。额骨正中缝尚未愈合，额窦尚未发育，眉弓及眉间不明显。颅顶各骨尚未完全发育，骨缝间充满纤维组织膜，在多骨交接处间隙的膜较大，称颅囟（cranial fontanelle）。前囟（额囟，anterior fontanelle）最大，呈菱形，位于矢状缝与冠状缝相接处。后囟（枕囟，posterior fontanelle）位于矢状缝与人字缝会合处，呈三角形。另外还有位于顶骨前下角的蝶囟和顶骨后下角的乳突囟。前囟在 1～2 岁时闭合，其余各囟均于生后不久闭合。新生儿上、下颌骨不发达，下颌角呈钝角；鼻旁窦尚未发育，乳突不明显，口鼻显得较小。

::figure{src="/images/anatomy/textbook/p0053_01.png" caption="图1-34　新生儿颅"}

:::definition{label="颅囟"}
新生儿颅顶多骨交接处较大的膜性间隙。前囟菱形，矢状缝与冠状缝相接处，1～2 岁闭合；后囟三角形，矢状缝与人字缝会合处，生后不久闭合。另有蝶囟、乳突囟。
:::

:::compare{title="新生儿颅 vs 成人颅（本版数字）"}

|--|--------|------|
| 面颅占全颅 | 1/8 | 1/4 |
| 颅顶外形 | 五角形（结节明显） | 卵圆形 |
| 囟 | 前囟、后囟、蝶囟、乳突囟 | 已闭合 |
| 额窦、眉弓、乳突 | 未发育或不明显 | 已发育 |
:::

## 四、附肢骨

附肢骨包括上肢骨和下肢骨。上、下肢骨分别由与躯干相连接的肢带骨和游离的自由肢骨组成。上肢骨每侧 32 块，共 64 块；下肢骨每侧 31 块，共 62 块。人体直立后，上肢从支持功能中解放出来成为灵活的劳动器官，下肢起支持和移位作用，因而上肢骨纤细轻巧，下肢骨粗大坚固。

:::compare{title="表1-2　附肢骨的配布"}
| 分类 | 上肢骨 | 下肢骨 |
|------|--------|--------|
| 肢带骨 | 肩胛骨、锁骨 | 髋骨 |
| 自由肢骨近侧部 | 肱骨 | 股骨 |
| 自由肢骨中间部 | 桡骨、尺骨 | 胫骨、腓骨、髌骨 |
| 自由肢骨远侧部 | 腕骨 8、掌骨 5、指骨 14 | 跗骨 7、跖骨 5、趾骨 14 |
| 每侧块数 | 32 | 31 |
| 两侧合计 | 64 | 62 |
:::

下肢中间部多一块髌骨，所以每侧 31 对 32，不是少了一块趾骨。

### （一）上肢骨

**1. 上肢带骨**

**（1）锁骨（clavicle）**　呈「～」形弯曲，横架于胸廓前上方，全长可在体表扪到。内侧端粗大为胸骨端，有关节面与胸骨柄相关节；外侧端扁平为肩峰端，有小关节面与肩胛骨肩峰相关节。内侧 2/3 凸向前、呈三棱形，外侧 1/3 凸向后、呈扁平形。锁骨位置表浅，易发生骨折，骨折部位多为内、外侧交界处。上面光滑，下面粗糙，形似长骨，但无骨髓腔。锁骨是唯一直接与躯干相连的上肢骨，呈杠杆状支撑肩胛骨，使上肢远离胸壁以保证灵活运动，并将应力自上肢传给躯干。

::figure{src="/images/anatomy/textbook/p0053_02.png" caption="图1-35　锁骨"}

:::pitfall{label="锁骨形似长骨，却没有髓腔"}
不要按长骨的「一体两端+髓腔」去套。发生类型上，本版把锁骨排除在「四肢骨软骨化骨」之外；形态上又强调无骨髓腔。两笔是同一块骨头的特殊性。
:::

**（2）肩胛骨（scapula）**　三角形扁骨，介于第 2 至第 7 肋。肋面为肩胛下窝；背面有肩胛冈，分出冈上窝、冈下窝，外侧延伸为肩峰。上缘有肩胛切迹和喙突。上角平第 2 肋，下角平第 7 肋或第 7 肋间隙（背部计数肋），外侧角为关节盂。肩胛冈、肩峰、下角、内侧缘及喙突可在体表扪到。骨折以体部最常见。

::figure{src="/images/anatomy/textbook/p0054_01.png" caption="图1-36　肩胛骨（前面）"}

::figure{src="/images/anatomy/textbook/p0054_02.png" caption="图1-37　肩胛骨（后面）"}

**2. 自由上肢骨**

**（1）肱骨（humerus）**　上肢最大的管状骨。上端为肱骨头，周围环状浅沟为解剖颈；外侧和前方有大、小结节及结节间沟。上端与体交界处为外科颈，松质与皮质交界，较易骨折。体后面中部有桡神经沟，中部骨折可能伤及桡神经。下端外侧为肱骨小头，内侧为肱骨滑车；前有冠突窝、桡窝，后有鹰嘴窝；两侧为外上髁、内上髁，内上髁后方为尺神经沟。髁上骨质薄弱，可发生髁上骨折。

::figure{src="/images/anatomy/textbook/p0054_03.png" caption="图1-38　肱骨"}

:::compare{title="解剖颈 vs 外科颈"}
| | 位置 | 临床 |
|--|------|------|
| 解剖颈 | 肱骨头周围的环状浅沟 | 形态分界 |
| 外科颈 | 上端与体交界，松质与皮质交界 | 较易骨折 |

不要把两条颈当成一个部位的两个名字。
:::

:::pitfall{label="肱骨两处神经沟不要记混"}
体后面中部：桡神经沟，中部骨折伤桡神经。内上髁后方：尺神经沟，髁上区域的尺神经。写成「外科颈伤桡神经」，沟的位置就错了。
:::

**（2）桡骨（radius）**　居前臂外侧，一体两端。上端为桡骨头（head of radius），头上面的关节凹与肱骨小头相关节，环状关节面与尺骨相关节；头下方为桡骨颈（neck of radius），颈的内下侧为桡骨粗隆（radial tuberosity），是肱二头肌的抵止处。体呈三棱柱形，内侧缘为骨间缘。下端前凹后凸，外侧向下突出为茎突（styloid process）；内面有尺切迹，下面有腕关节面。体表可扪及桡骨茎突和桡骨头。

**（3）尺骨（ulna）**　居前臂内侧，一体两端。上端粗大，前面有滑车切迹（trochlear notch）与肱骨滑车相关节；切迹后上方为鹰嘴（olecranon），前下方为冠突（coronoid process）。冠突外侧面有桡切迹，下方为尺骨粗隆（ulnar tuberosity）。下端为尺骨头（head of ulna），下面借三角形关节盘与腕骨分隔；头后内侧的锥状突起为尺骨茎突。生理情况下，尺骨茎突较桡骨茎突高约 1 cm。鹰嘴、后缘全长、尺骨头和茎突均可在体表扪及。

::figure{src="/images/anatomy/textbook/p0055_01.png" caption="图1-39　桡骨和尺骨"}

:::pitfall{label="尺骨茎突比桡骨茎突高，不是齐平"}
本版：约高 1 cm。腕部外形上尺侧茎突并不更「低」；外踝低于内踝那一笔属于下肢，不要串过来。
:::

**（4）手骨**　包括腕骨、掌骨和指骨。

腕骨（carpal bone）属短骨，共 8 块，排成近、远二列。近侧列由桡侧向尺侧：手舟骨（scaphoid bone）、月骨（lunate bone）、三角骨（triquetral bone）、豌豆骨（pisiform bone）。远侧列：大多角骨（trapezium bone）、小多角骨（trapezoid bone）、头状骨（capitate bone）、钩骨（hamate bone）。8 块腕骨构成掌面凹陷的腕骨沟。手舟骨、月骨和三角骨近端的椭圆形关节面，与桡骨腕关节面及尺骨下端的关节盘构成桡腕关节。腕骨骨折多由间接暴力引起，以手舟骨骨折最为多见。

掌骨（metacarpal bone）共 5 块，近端为底、中间为体、远端为头。第 1 掌骨短而粗，底有鞍状关节面，与大多角骨相关节。

指骨（phalange of finger）属长骨，共 14 块。拇指 2 节（近节、远节），其余各指 3 节（近节、中节、远节）。远节指骨远端掌面粗糙，称远节指骨粗隆。

::figure{src="/images/anatomy/textbook/p0056_01.png" caption="图1-40　手骨"}

:::compare{title="腕骨八块（桡侧→尺侧）"}
| 列 | 四块 |
|----|------|
| 近侧列 | 手舟骨、月骨、三角骨、豌豆骨 |
| 远侧列 | 大多角骨、小多角骨、头状骨、钩骨 |
:::

**3. 上肢骨常见的变异和畸形**　锁骨可见先天性缺如。肱骨冠突窝与鹰嘴窝之间可出现滑车上孔；内上髁上方有时出现髁上突，韧带骨化则形成髁上孔。桡骨可部分或全部缺如。尺骨鹰嘴与尺骨干可不融合。腕骨可出现二分舟骨。掌骨、指骨可出现多指或并指。本版未给发生率。

### （二）下肢骨

**1. 下肢带骨**　髋骨（hip bone）为不规则骨，上部扁阔，中部窄厚，有朝向下外的髋臼，下部有闭孔。左右髋骨与骶、尾骨组成骨盆。髋骨由髂骨、坐骨和耻骨组成，三骨会合于髋臼，16 岁左右完全融合。

:::definition{label="髋骨"}
髂骨、坐骨、耻骨三骨合成的不规则骨，16 岁左右在髋臼处完全融合。上部扁阔为髂，中部髋臼，下部闭孔。
:::

**（1）髂骨（ilium）**　髂骨体构成髋臼上 2/5。翼上缘为髂嵴，最高点连线约平第 4 腰椎棘突。前端髂前上棘，后端髂后上棘；髂前上棘后方 5～7 cm 为髂结节。内面为髂窝，下界弓状线；后下方耳状面，外面为臀面。髂后下棘下方为坐骨大切迹。

**（2）坐骨（ischium）**　体组成髋臼后下 2/5，后缘有坐骨棘，棘下为坐骨小切迹。体与支移行处后部为坐骨结节，坐位承重，体表可扪及。

**（3）耻骨（pubis）**　体组成髋臼前下 1/5。耻骨梳向后续弓状线，向前终于耻骨结节；结节至中线为耻骨嵴。内侧为耻骨联合面。耻骨与坐骨围成闭孔，活体有闭孔膜封闭。

髋臼（acetabulum）由髂、坐、耻三骨的体合成。窝内半月形关节面称月状面（lunate surface），中央凹陷为髋臼窝，边缘下部缺口为髋臼切迹。因骨质疏松和骨质脆弱导致的髋骨骨折是常见的老年性骨折。

::figure{src="/images/anatomy/textbook/p0057_01.png" caption="图1-41　髋骨（外面）"}

::figure{src="/images/anatomy/textbook/p0057_02.png" caption="图1-42　髋骨（内面）"}

::figure{src="/images/anatomy/textbook/p0057_03.png" caption="图1-43　6岁幼儿髋骨"}

:::compare{title="髋臼由谁各出多少"}
| 骨 | 占髋臼 |
|----|--------|
| 髂骨体 | 上 2/5 |
| 坐骨体 | 后下 2/5 |
| 耻骨体 | 前下 1/5 |

2/5 + 2/5 + 1/5 = 1。幼儿三骨在髋臼处以软骨相连，约 16 岁骨性融合。
:::

**2. 自由下肢骨**

**（1）股骨（femur）**　人体最长最结实的长骨，长约体高的 1/4。上端为股骨头、股骨颈；颈干角男性平均 132°、女性平均 127°。大、小转子之间前面为转子间线、后面为转子间嵴，连成环线的股骨粗隆间是骨折多发处。体后面有粗线，下端为内、外侧髁，前方髌面，后方髁间窝；内上髁上方为收肌结节。大转子可在体表扪及。

::figure{src="/images/anatomy/textbook/p0058_01.png" caption="图1-44　股骨"}

:::definition{label="颈干角"}
股骨颈与体的夹角。本版：男性平均 132°，女性平均 127°。不要改成「约 130°」把性别差抹掉，也不要另引其他版本的角度。
:::

**（2）髌骨（patella）**　人体最大的籽骨，位于股骨下端前面、股四头肌腱内，上宽下尖，前面粗糙，后面为关节面，与股骨髌面相关节。功能：保护膝关节，避免股四头肌腱对股骨髁软骨面的摩擦，增加膝关节稳定性。体表可扪及。

::figure{src="/images/anatomy/textbook/p0058_02.png" caption="图1-45　髌骨（右侧）"}

**（3）胫骨（tibia）**　居小腿内侧，粗大长骨，为小腿主要承重骨。上端向两侧突出为内、外侧髁，上面各有上关节面，两关节面之间为髁间隆起（intercondylar eminence）。外侧髁后下方有腓关节面。上端前面为胫骨粗隆（tibial tuberosity）。体呈三棱柱形，前缘和内侧面直接位于皮下；外侧缘为骨间缘。后面上份有比目鱼肌线。下端内下方的突起为内踝（medial malleolus），外侧面有腓切迹。由于皮下组织和肌肉较薄弱、血供较差，胫骨骨折易出现愈合延迟。

**（4）腓骨（fibula）**　细长，位于胫骨外后方。上端为腓骨头（fibular head），头下方为腓骨颈（fibular neck）。下端膨大为外踝（lateral malleolus）。腓骨头和外踝可在体表扪及。

::figure{src="/images/anatomy/textbook/p0059_01.png" caption="图1-46　胫骨和腓骨（右侧）"}

:::pitfall{label="小腿承重的是胫骨，不是腓骨"}
胫骨粗大、前缘皮下、主要承重；腓骨细长、偏外后，下端参与踝穴。写成「两条一样承重」，骨折愈合差这一笔也缺少形态依据。
:::

**（5）足骨**　包括跗骨、跖骨和趾骨。

跗骨（tarsal bone）共 7 块，属短骨，分前、中、后三列。后列：上方距骨（talus）、下方跟骨（calcaneus）。中列：足舟骨（navicular bone）。前列：内侧楔骨、中间楔骨、外侧楔骨及跟骨前方的骰骨（cuboid bone）。跗骨几乎占据全足的一半，与支持和负重相适应。距骨上面有前宽后窄的距骨滑车，与内、外踝和胫骨下关节面相关节。跟骨后端隆凸为跟骨结节。足舟骨内下方为舟骨粗隆，是重要体表标志。跟骨骨折为常见的跗骨骨折，约占全部跗骨骨折的 60%，多由高处跌下、足跟垂直撞击所致。

跖骨（metatarsal bone）共 5 块。第 5 跖骨底向后突出为第 5 跖骨粗隆，体表可扪及。

趾骨（phalange of toe）共 14 块。拇趾为 2 节，其余各趾为 3 节，形态和命名与指骨相同。拇趾骨粗壮，其余趾骨细小；第 5 趾的远节趾骨甚小，往往与中节趾骨长合。

::figure{src="/images/anatomy/textbook/p0059_02.png" caption="图1-47　足骨"}

| 列 | 骨 |
|----|----|
| 后列 | 距骨（上）、跟骨（下） |

本版原句：跟骨骨折约占全部跗骨骨折的 60%。不要把这个比例推广到「全身骨折」或「足骨骨折」。
:::

**3. 下肢骨常见的变异和畸形**　髋骨可有髂窝穿孔、耻坐支不长合；股骨臀肌粗隆异常粗大形成第 3 转子；髌骨可缺如或为二分髌骨；距骨后下部和前上部可出现三角骨和距上骨；楔骨之间可出现楔间骨；第 1 与第 2 跖骨之间可出现跖间骨；趾骨可多趾。名单按本版，不补发生率。

## 五、体表的骨性标志

骨性标志是把前面各骨落到活体上的最后一笔。腰椎穿刺靠髂嵴，计数椎骨靠隆椎，止血靠颈动脉结节——都在这张表里合拢。下肢标志与头颈、躯干、上肢同属本节，不写进骨连结。

### （一）头颈部

1. **乳突**　位于外耳下方，其根部前缘的前内方有茎乳孔，面神经由此出颅。
2. **下颌角**　下颌支后缘与下颌体下缘转折处，骨质较薄，容易骨折。
3. **枕外隆凸**　枕部向后最突出的隆起。
4. **颧弓**　位于眶下缘和枕外隆凸之间连线的同一水平面上。
5. **翼点**　顶骨、额骨、蝶骨和颞骨四骨会合处，在颧弓中点上方 3.5～4.0 cm，颅骨薄弱部位，深面附近沟内有脑膜中动脉前支经过。
6. **第 7 颈椎棘突**　颈背部最突出的隆起，头部前屈时更容易触及，为计数椎骨的标志。
7. **颈动脉结节**　即第 6 颈椎横突前结节，位于胸锁乳突肌前缘深处，正对环状软骨平面。平环状软骨，在胸锁乳突肌前缘以拇指向后加压，可将颈总动脉压向颈动脉结节，阻断血流以达到止血目的。

### （二）躯干部

1. **胸骨颈静脉切迹**　胸骨上缘、两侧胸锁关节之间的凹陷，其上方为胸骨上窝。
2. **胸骨角**　胸骨柄与胸骨体连接处向前的横向突起。两侧平对第 2 肋软骨，为计数肋骨的标志；该平面是上、下纵隔的分界线。
3. **剑突**　胸骨下方的突出，位于两侧肋弓之间。
4. **骶角**　沿骶中嵴向下扪及骶管裂孔，裂孔两侧可扪及骶角。

### （三）上肢

1. **锁骨**　胸廓前上方，位于皮下，全长可扪及。
2. **肩峰、肩胛冈及肱骨大结节**　肩峰是肩部最高的骨性标志；沿肩峰向后可触及肩胛冈；肩峰下外方为肱骨大结节。
3. **肩胛下角**　平对第 7 肋，背部计数肋骨的标志。
4. **肱骨内、外上髁**　肘部内、外侧最突出的骨性突起。
5. **桡骨茎突和尺骨茎突**　腕桡侧和尺侧的骨性隆起，尺骨茎突较桡骨茎突高。
6. **尺骨鹰嘴**　肘后区最显著的隆起。
7. **尺神经沟**　肱骨内上髁与尺骨鹰嘴之间可触及的深沟，其深方为肱骨的尺神经沟。
8. **豌豆骨**　腕部远侧皮纹内侧的突起。

### （四）下肢

1. **髂嵴**　全长在体表均能扪及，前端为髂前上棘，后端为髂后上棘。髂嵴最高点平对第 4 腰椎棘突，腰椎穿刺可通过髂嵴定位。
2. **耻骨结节**　位于腹股沟内侧端。
3. **坐骨结节**　位于臀大肌下缘内侧，为屈大腿时在臀部扪到的骨性突出。
4. **股骨大转子**　大腿外侧上部的突出。
5. **胫骨粗隆**　位于髌骨下缘约四横指处。
6. **内踝和外踝**　踝部两侧的明显隆起，外踝低于内踝。
7. **髂结节**　在髂前上棘后方 5～7 cm 处，髂嵴向外侧的突起。
8. **跟骨结节**　足跟后方的骨性突起，是跟腱的附着部位。

:::compare{title="计数与穿刺最常用的几个平面"}
| 标志 | 平对或用途 |
|------|------------|
| 隆椎棘突 | 计数椎骨 |
| 肩胛骨上角 | 第 2 肋 |
| 肩胛下角 | 第 7 肋或第 7 肋间隙 |
| 胸骨角 | 第 2 肋；上、下纵隔分界 |
| 髂嵴最高点 | 第 4 腰椎棘突；腰穿定位 |
| 颈动脉结节 | 第 6 颈椎；压迫颈总动脉止血 |
:::

:::pitfall{label="外踝低于内踝，尺骨茎突却高于桡骨茎突"}
下肢踝：外踝低。上肢腕：尺骨茎突高约 1 cm。两侧「谁更高」方向相反，最容易串记。
:::
