# 第三节　膀胱

第二节把输尿管写到壁内部：斜穿膀胱壁，开口于膀胱三角的输尿管口。本节把「膀胱」这一户写完：空虚时的尖、体、底、颈，内面的三角和输尿管间襞，盆腔内的位置毗邻，以及把膀胱固定在盆腔的那几条结构。尿道内口是膀胱的出口，女性尿道的行程归下一节；男性尿道见男性生殖系统。

膀胱是储存尿液的肌性囊状器官。形状、大小、位置和壁的厚度都随充盈程度而变，不是一个固定的「梨」或固定的「球」。空虚时它是三棱锥，藏在盆里；充盈时腹膜返折上移，才出现耻骨联合上方的穿刺平面。

:::definition{label="膀胱"}
储存尿液的**肌性囊状器官**。形状、大小、位置和壁的厚度随尿液充盈程度而异。职能是储尿；产尿在肾，输尿在输尿管，排尿出尿道。
:::

:::definition{label="膀胱的容量"}
成年人平均 **350～500 ml**。容纳超过 **500 ml** 时，膀胱壁张力过大而产生疼痛。新生儿约为成人的 **1/10**；女性容量小于男性；老年人因膀胱肌张力低而容量增大。
:::

:::concept{term="先问这是不是储尿的囊，再问空虚时切成哪四部"}
看见膀胱，先不要默写肿瘤。先问：它是不是储存尿液的肌性囊、容量是不是 350～500 ml——答案是。再问空虚时的四部：尖、体、底、颈。然后才问三角为什么始终平滑。把膀胱听成「就是一个三角」，尖和脐正中韧带会丢掉；把女性尿道的外口、旁腺写进本节，又是吞了下一户。
:::

:::compare{title="容量三句话，不要并成一个数"}
| 谁 | 本版 |
|----|------|
| 成人 | 平均 **350～500 ml**；超过 **500 ml** 疼痛 |
| 新生儿 | 约成人的 **1/10** |
| 女性 / 老人 | 女小于男；老人因肌张力低而增大 |

350～500 ml 是平均容量，不是「到 500 ml 才开始有尿意」。疼痛阈是超过 500 ml。不要把新生儿写成与成人同容积。
:::

:::pitfall{label="超过 500 ml 才因张力过大而痛，不要把 350 ml 写成痛阈"}
本版原句：成年人容量平均 350～500 ml，超过 500 ml 时产生疼痛。把 350 ml 听成「一到 350 就痛」，平均容量和疼痛阈会并户。
:::

## 一、膀胱的形态和分部

空虚的膀胱呈三棱锥体形，分尖、体、底和颈四部（图4-14、图4-15）。充盈时锥体展开、壁变薄，外形不再保持这个三棱锥；分部的名字仍按空虚时的四部来认。

:::definition{label="空虚膀胱的外形"}
**三棱锥体形**，分**尖、体、底、颈**四部。不是卵圆形，也不是「只有底和颈」。充盈后外形改变，四部的名称仍用这一套。
:::

:::definition{label="膀胱尖"}
朝**前上方**。由此沿腹前壁至脐之间有一皱襞，为**脐正中韧带**。尖是锥体的前上角，不是尿道内口。
:::

:::definition{label="脐正中韧带"}
膀胱尖沿腹前壁连到脐的那一皱襞。图4-15 在剖开的膀胱尖上方标了它。它是固定结构之一，后面和脐外侧襞一起再写。
:::

:::definition{label="膀胱底"}
膀胱的后面，朝**后下方**，呈三角形。输尿管从底的外上角斜穿入壁。底朝后下，尖朝前上，不要把底听成「坐在盆底上的那一面」。
:::

:::definition{label="膀胱体"}
膀胱尖与底之间的部分。图4-14 侧面观上，体占锥体的大部分；图4-15 前面观剖开后，体的内面布满膀胱襞。
:::

:::definition{label="膀胱颈"}
膀胱的**最下部**。男性与**前列腺底**毗邻，女性与**盆膈**毗邻。颈下面接尿道内口，不是接输尿管。
:::

::figure{src="/images/anatomy/textbook/p0169_01.png" caption="图4-14　膀胱侧面观" alt="膀胱侧面：尖朝前上，体占中份，底朝后下，颈邻前列腺；两侧输尿管斜入底，后方可见输精管和精囊，尿道从颈下方走出"}

图4-14 用侧面把四部一次排开：尖在前上，体在中，底在后下，颈坐在前列腺上。输尿管从后上斜入底，输精管和精囊贴在底的后方，尿道从颈下方离开画面。这是男性空虚膀胱的侧面户口；女性颈的邻居换成盆膈，外形仍按这四部。

:::compare{title="四部朝向（空虚三棱锥）"}
| 部 | 朝向 / 位置 | 本版邻居或延续 |
|----|-------------|----------------|
| 尖 | 前上方 | 脐正中韧带连到脐 |
| 体 | 尖与底之间 | 内面有膀胱襞 |
| 底 | 后下方，呈三角形 | 输尿管从外上角斜入 |
| 颈 | 最下部 | 男邻前列腺底，女邻盆膈 |

尖朝前上、底朝后下，锥体是「躺着」的，不是尖朝上竖在盆里。
:::

:::compare{title="颈的邻居：男女不同"}
| | 膀胱颈毗邻 |
|--|-----------|
| 男性 | **前列腺底** |
| 女性 | **盆膈** |

图4-14 画的是男性，颈下方直接是前列腺。不要把前列腺安到女性颈上，也不要把盆膈写成男性颈的第一邻居。
:::

:::pitfall{label="底朝后下方，不要把底写成朝下坐在前列腺上"}
朝下、最下部的是颈。底是后面那块三角形，朝后下，输尿管和（男性）精囊、输精管壶腹都在这一面的后方。把底和颈对调，三角会画到前列腺顶上。
:::

:::insight{label="侧面观先认尖和颈，中间那一大块才是体"}
图4-14 像一只横放的漏斗：前上是尖，后下是底，最下是颈。漏斗嘴对着前列腺和尿道，漏斗底对着直肠方向。四部认完，内面结构才有墙可挂。
:::

:::keypoint{label="形态先钉四部"}
- 空虚：三棱锥，尖、体、底、颈。
- 尖朝前上，连脐正中韧带；底朝后下，呈三角形；颈在最下。
- 颈：男邻前列腺底，女邻盆膈。
- 容量 350～500 ml；>500 ml 痛；新生儿约 1/10。
:::

## 二、膀胱的内面结构

膀胱内面被覆黏膜。当膀胱壁收缩时，黏膜聚集成皱襞，称膀胱襞（vesical plica）。在膀胱底内面，有一个呈三角形的区域，位于左、右输尿管口（ureteric orifice）和尿道内口（internal orifice of urethra）之间，此处膀胱黏膜与肌层紧密连接，缺少黏膜下层组织，无论膀胱扩张还是收缩，始终保持平滑，称膀胱三角（trigone of bladder）。

膀胱三角是肿瘤、结核和炎症的好发部位，膀胱镜检查时应特别注意。两个输尿管口之间的皱襞称输尿管间襞（interureteric fold），是临床寻找输尿管口的标志。在男性尿道内口后方的膀胱三角处，受前列腺中叶推挤形成纵嵴状隆起，称膀胱垂（vesical uvula）（图4-15）。

:::definition{label="膀胱襞"}
膀胱壁收缩时，黏膜聚成的皱襞。体的内面有襞；三角没有——三角缺少黏膜下层，黏膜贴着肌层，展不出皱襞。
:::

:::definition{label="输尿管口"}
壁内部开口于膀胱三角底边两端。空虚时两口间距约 **2.5 cm**（上一节已经钉过）。口本身是进尿的门，不是出尿的尿道内口。
:::

:::definition{label="尿道内口"}
膀胱通向尿道的开口，位于三角的尖端、颈的内面。尿液从这里离开膀胱。女性低于男性；新生儿约平耻骨联合上缘，见位置段。
:::

:::definition{label="膀胱三角"}
膀胱底内面，**左、右输尿管口和尿道内口**之间的三角形区域。黏膜与肌层紧密连接，**缺少黏膜下层**，无论扩张还是收缩，**始终保持平滑**。肿瘤、结核和炎症的好发部位；膀胱镜要重点看这里。
:::

:::definition{label="输尿管间襞"}
两个输尿管口之间的皱襞。临床**寻找输尿管口的标志**：先看见这一条横行的隆起，再在两端找口。
:::

:::definition{label="膀胱垂"}
男性尿道内口后方、膀胱三角处，受**前列腺中叶**推挤形成的纵嵴状隆起。女性没有前列腺中叶，不要把膀胱垂写进女性三角。
:::

::figure{src="/images/anatomy/textbook/p0169_02.png" caption="图4-15　膀胱前面观" alt="膀胱前面剖开：尖连脐正中韧带，体壁黏膜成膀胱襞；底内面膀胱三角平滑，可见输尿管间襞、输尿管口、尿道内口、膀胱垂、尿道嵴，下方为前列腺、前列腺小囊、射精管口和前列腺排泄管开口"}

图4-15 从前面把膀胱剖开。体壁仍是皱襞；底内面那一块平滑区就是三角。三角上缘是输尿管间襞，两端是输尿管口，下角是尿道内口；内口后方的纵嵴是膀胱垂。画面下部进入前列腺：尿道嵴、前列腺小囊、射精管口和前列腺排泄管开口——那是男性尿道起始部的邻居，形态归男性生殖系统，本节只借它们把颈和内口的位置钉死。

:::compare{title="三角三顶点"}
| 顶点 | 本版 |
|------|------|
| 左上 | 左输尿管口 |
| 右上 | 右输尿管口 |
| 下 | 尿道内口 |

上边（两口之间）是输尿管间襞。三角始终平滑；周围的体壁才有膀胱襞。
:::

:::compare{title="有襞的壁和无襞的三角"}
| | 黏膜下层 | 收缩时 | 临床 |
|--|----------|--------|------|
| 体等处 | 有 | 聚成膀胱襞 | 充盈时襞展平 |
| 膀胱三角 | **缺少**黏膜下层，黏膜紧贴肌层 | **始终平滑** | 肿瘤、结核、炎症好发；膀胱镜重点 |

「始终平滑」不是「从不生病」，而是没有皱襞可藏——病变反而更早被看见，也更常落在这里。
:::

:::cause-effect{title="为什么三角始终平滑"}
- **因** 黏膜与肌层紧密连接，缺少黏膜下层组织
- **果** 无论膀胱扩张还是收缩，这块三角形都不聚成皱襞

体壁有黏膜下层，收缩就起襞。三角少了这一层，镜下去是平的。
:::

:::pitfall{label="三角是两输尿管口加尿道内口，不要漏掉尿道内口或把两口间距当成三角的定义"}
定义是三个口围成的区域。只写「两输尿管口之间」会变成输尿管间襞；只写「尿道内口周围」会变成颈。三顶点都要。
:::

:::pitfall{label="输尿管间襞是找口的标志，不要把间襞本身当成输尿管口"}
先认间襞这条横嵴，再在两端找口。把间襞听成「口」，插管会顶在皱襞上而不是进壁内部。
:::

:::pitfall{label="膀胱垂是男性才有，不要写进女性三角"}
本版原句：受前列腺中叶推挤。女性颈邻盆膈，没有这枚中叶，也就没有这道纵嵴。图4-15 是男性前面观，垂在内口后方。
:::

:::insight{label="镜下去先找一条横的间襞，两端是进口，下角是出口"}
两口进、一口出。间襞是上边，内口是下角。肿瘤、结核、炎症爱落在这块始终平滑的黏膜上，所以膀胱镜的第一眼不是去数体壁上的皱襞。
:::

:::keypoint{label="内面就记三角这一块"}
- 三角 = 左、右输尿管口 + 尿道内口；始终平滑；肿瘤 / 结核 / 炎症好发。
- 输尿管间襞 = 找口标志。
- 体壁收缩成膀胱襞；三角没有黏膜下层。
- 男性内口后方有膀胱垂（前列腺中叶）。
:::

## 三、膀胱的位置和毗邻

膀胱前方为耻骨联合，二者之间称膀胱前隙（prevesical space，Retzius 间隙）或耻骨后间隙。此间隙内，男性有耻骨前列腺韧带（puboprostatic ligament）；女性有耻骨膀胱韧带（pubovesical ligament）。耻骨膀胱韧带是女性在耻骨后面和盆筋膜腱弓前部与膀胱颈之间相连的两条结缔组织索。此外，间隙中还有丰富的结缔组织与静脉丛。

男性膀胱的后方与精囊、输精管壶腹和直肠相毗邻，女性膀胱的后方与子宫和阴道相毗邻。男性两侧输精管壶腹之间的区域称输精管壶腹三角，借结缔组织连接直肠壶腹，称直肠膀胱筋膜。

膀胱空虚时全部位于盆腔内，充盈时膀胱腹膜返折线可上移至耻骨联合上方，此时可在耻骨联合上方施行穿刺术，不会伤及腹膜和污染腹膜腔。新生儿膀胱的位置高于成年人，尿道内口在耻骨联合上缘水平，而老年人的膀胱位置较低。

:::definition{label="膀胱前隙"}
膀胱与耻骨联合之间，又称 **Retzius 间隙**、耻骨后间隙。内容：男性耻骨前列腺韧带，女性耻骨膀胱韧带，以及丰富的结缔组织和静脉丛。
:::

:::definition{label="耻骨前列腺韧带"}
男性膀胱前隙内，连接耻骨与前列腺的韧带。它把颈和前列腺固定在耻骨后面，不是把尖固定到脐。
:::

:::definition{label="耻骨膀胱韧带"}
女性膀胱前隙内。耻骨后面和盆筋膜腱弓前部与**膀胱颈**之间相连的**两条**结缔组织索。不要写成一条，也不要写成连到膀胱尖。
:::

:::definition{label="男性膀胱后方的毗邻"}
**精囊、输精管壶腹和直肠**。两侧输精管壶腹之间称输精管壶腹三角，借结缔组织连到直肠壶腹，称**直肠膀胱筋膜**。
:::

:::definition{label="女性膀胱后方的毗邻"}
**子宫和阴道**。不要把精囊、输精管壶腹写到女性后方。
:::

:::definition{label="空虚与充盈的位置"}
空虚时**全部位于盆腔内**。充盈时腹膜返折线上移到**耻骨联合上方**，可在耻骨联合上方穿刺，**不伤腹膜、不污染腹膜腔**。
:::

:::definition{label="新生儿与老人的膀胱位置"}
新生儿高于成人，**尿道内口在耻骨联合上缘水平**。老年人的膀胱位置较低。不要把新生儿写成「已经降到盆底」，也不要把老人写成与新生儿同高。
:::

:::compare{title="前方、后方（先分男女）"}
| 方向 | 男性 | 女性 |
|------|------|------|
| 前方 | 耻骨联合；前隙内有耻骨前列腺韧带 | 耻骨联合；前隙内有耻骨膀胱韧带 |
| 后方 | 精囊、输精管壶腹、直肠；直肠膀胱筋膜 | 子宫、阴道 |
| 颈的下方 | 前列腺底（见形态段） | 盆膈 |

前隙里都有结缔组织和静脉丛。后方名单不要左右对调、男女对调。
:::

:::compare{title="空虚、充盈、新生儿、老人"}
| | 本版位置 |
|--|----------|
| 空虚（成人） | 全部在盆腔内 |
| 充盈（成人） | 腹膜返折可到耻骨联合上方 → 可在联合上方穿刺 |
| 新生儿 | 较高；尿道内口平耻骨联合**上缘** |
| 老人 | 较低 |

穿刺平面只在充盈时成立。空虚时联合上方没有膀胱可穿，新生儿则本来就高。
:::

:::cause-effect{title="为什么充盈时能在耻骨联合上方穿刺而不伤腹膜"}
- **因** 充盈时膀胱把腹膜返折线推到耻骨联合上方，联合上方、腹膜返折以下这一段膀胱壁没有腹膜覆盖
- **果** 在耻骨联合上方穿刺，不进入腹膜腔，也就不污染腹膜腔

空虚时膀胱全在盆里，联合上方没有这段「裸区」。把空虚膀胱当充盈去穿，会穿空或伤及腹膜。
:::

:::pitfall{label="穿刺只在充盈时、耻骨联合上方，不要写成空虚也可穿"}
本版原句把「腹膜返折上移」和「可穿刺」写在同一句。空虚时返折没有上移，联合上方不是安全平面。也不要写成「经直肠穿刺膀胱」。
:::

:::pitfall{label="新生儿尿道内口平耻骨联合上缘，不要写成成人也在上缘"}
成人空虚时全在盆内，内口低于联合上缘。把成人体表按新生儿来找，导尿和穿刺的高度都会偏上。
:::

:::insight{label="前贴耻骨、后贴直肠或子宫，中间这个囊会随尿液涨到联合上方"}
空虚时它是盆里的三棱锥；涨起来才从联合上缘探出头来。穿刺用的就是这颗探出腹膜返折的「无腹膜前壁」。
:::

## 四、膀胱的固定

耻骨前列腺韧带、耻骨膀胱韧带、脐正中襞与脐外侧襞等结构将膀胱固定于盆腔。这些结构的发育不良是膀胱脱垂（cystoptosis）与女性尿失禁（urinary incontinence）的重要原因（图4-16）。

:::definition{label="膀胱的固定结构"}
**耻骨前列腺韧带**（男）、**耻骨膀胱韧带**（女）、**脐正中襞**与**脐外侧襞**等。它们把膀胱留在盆腔，不是把膀胱吊在腹膜腔里。
:::

:::definition{label="膀胱脱垂与女性尿失禁"}
上述固定结构发育不良，是膀胱脱垂和女性尿失禁的重要原因。脱垂是膀胱失去盆内的固定而下移；尿失禁在这里对应的是固定装置不能维持颈和尿道内口的位置。
:::

::figure{src="/images/anatomy/textbook/p0170_01.png" caption="图4-16　膀胱（男性盆腔正中矢状切面）" alt="男性盆腔正中矢状切：耻骨联合后方为膀胱，上方壁腹膜，后方直肠膀胱陷凹、精囊和输精管，下方前列腺和尿生殖膈；画面上还可见尿道前列腺部、膜部、海绵体部及阴茎、阴囊，形态归男性生殖系统"}

图4-16 用男性盆腔正中矢状切把膀胱安进盆腔：前方耻骨联合，上方壁腹膜，后方直肠膀胱陷凹、精囊和输精管，下方前列腺，再下是尿生殖膈。尖朝前上，底朝后，颈坐在前列腺上——和侧面观的四部能对上。画面上还能看见尿道前列腺部、膜部和海绵体部，以及阴茎、阴囊，那是男性尿道和生殖器的行程，形态见男性生殖系统；本节只认膀胱在这张矢状切里的座位和腹膜返折。

:::compare{title="固定结构各管哪一段"}
| 结构 | 主要连到 |
|------|----------|
| 耻骨前列腺韧带（男） | 耻骨 ↔ 前列腺 / 颈 |
| 耻骨膀胱韧带（女） | 耻骨后面、盆筋膜腱弓前部 ↔ 膀胱颈（两条） |
| 脐正中襞 | 膀胱尖 ↔ 脐 |
| 脐外侧襞 | 与脐正中襞一起参与把膀胱留在盆腔 |

前两条管颈，后两条管尖和前壁。发育不良时，颈和内口的位置先松。
:::

:::pitfall{label="图4-16 是膀胱的男性盆腔矢状切，不要当成女性尿道图"}
下一节的女性尿道是图4-17。图4-16 上的尿道前列腺部、膜部、海绵体部是男性矢状切里顺带看见的结构，不在本节展开，也不要挪去当女性尿道的形态。
:::

:::insight{label="矢状切里膀胱像楔在耻骨和直肠之间的囊"}
前壁对耻骨联合，顶被腹膜盖住，后下是直肠膀胱陷凹。充盈时这只楔子向上顶，腹膜返折跟着上移，联合上方才露出可穿的前壁。固定结构松了，楔子会往下掉，变成脱垂和女性尿失禁的形态底板。
:::

:::keypoint{label="位置和固定三句话"}
- 空虚全在盆腔；充盈腹膜返折到耻骨联合上方，可在联合上方穿刺不伤腹膜。
- 前：耻骨联合和前隙；后：男为精囊、输精管壶腹、直肠，女为子宫、阴道。
- 固定：耻骨前列腺韧带 / 耻骨膀胱韧带、脐正中襞、脐外侧襞。发育不良 → 膀胱脱垂、女性尿失禁。
:::

:::note{label="本节止于膀胱的固定"}
尿液经尿道内口离开膀胱。女性尿道的长度、外口和旁腺归下一节；男性尿道见男性生殖系统。图4-16 里那些尿道分段，不要在本节写成户头。
:::

:::memory{label="本节必背要点"}
- [ ] 膀胱：储尿的肌性囊状器官。成人容量平均 **350～500 ml**，超过 **500 ml** 疼痛。新生儿约成人 **1/10**；女小于男；老人增大。
- [ ] 空虚呈三棱锥，分尖、体、底、颈。尖朝前上，连脐正中韧带；底朝后下、呈三角形；颈在最下，男邻前列腺底，女邻盆膈。
- [ ] 体壁收缩成膀胱襞。三角 = 左、右输尿管口 + 尿道内口，缺黏膜下层，始终平滑；肿瘤、结核、炎症好发。膀胱镜重点看这里。
- [ ] 输尿管间襞 = 找输尿管口的标志。男性内口后方有膀胱垂（前列腺中叶推挤）。空虚时两输尿管口间距约 2.5 cm。
- [ ] 前方耻骨联合，之间为膀胱前隙（Retzius 间隙）：男有耻骨前列腺韧带，女有耻骨膀胱韧带（两条，连到颈），并有结缔组织与静脉丛。
- [ ] 后方：男为精囊、输精管壶腹、直肠（输精管壶腹三角、直肠膀胱筋膜）；女为子宫、阴道。
- [ ] 空虚全部在盆腔。充盈时腹膜返折到耻骨联合上方，可在联合上方穿刺，不伤腹膜。新生儿较高（内口平联合上缘）；老人较低。
- [ ] 固定：耻骨前列腺韧带、耻骨膀胱韧带、脐正中襞、脐外侧襞。发育不良是膀胱脱垂和女性尿失禁的重要原因。

:::
