# 四、　甲状旁腺

上一节把甲状腺写成 H 形，并点到囊鞘间隙里住着甲状旁腺。本节只写这几粒黄豆：棕黄色、扁椭圆形，一般上、下两对，每个 35～50 mg；上对位置恒定，下对变异较大。分泌甲状旁腺激素，和降钙素一起维持血钙。肾上腺不在本节展开。

甲状旁腺（parathyroid gland）为棕黄色、黄豆大小的扁椭圆形腺体（图6-4）。常位于甲状腺侧叶后缘与其被膜之间，亦可埋入甲状腺实质内，或位于甲状腺鞘外。一般有上、下两对，每个重 35～50 mg。表面覆有薄层结缔组织被膜，被膜携带血管、淋巴管和神经伸入腺内成为小梁，将甲状旁腺分为不完全的小叶。小叶内腺实质细胞排列成索或团状，其间有少量结缔组织和丰富的毛细血管。

上甲状旁腺的位置恒定，位于甲状腺侧叶后缘的上、中 1/3 交界处；下甲状旁腺的位置变异较大，多位于甲状腺侧叶后缘靠近下端的甲状腺下动脉处。

:::definition{label="甲状旁腺"}
棕黄色、黄豆大小的扁椭圆形腺体。一般**上、下两对**，每个 **35～50 mg**。常在甲状腺侧叶后缘与其被膜之间，也可埋入实质或位于甲状腺鞘外。
:::

:::compare{title="每个甲状旁腺的重量（本版）"}
| | 本版 |
|--|------|
| 每个 | **35～50 mg** |
| 数目 | 一般上、下两对（四个） |

按毫克、按每个记。不要写成 35～50 g，也不要把四个加在一起当成「一侧重」。
:::

:::definition{label="上甲状旁腺"}
位置**恒定**：甲状腺侧叶后缘的**上、中 1/3 交界处**。
:::

:::definition{label="下甲状旁腺"}
位置**变异较大**：多位于甲状腺侧叶后缘靠近下端的**甲状腺下动脉**处。
:::

:::compare{title="上对恒定、下对易变"}
| | 位置 | 本版要点 |
|--|------|----------|
| 上甲状旁腺 | 侧叶后缘，上、中 1/3 交界 | 恒定 |
| 下甲状旁腺 | 侧叶后缘近下端，邻甲状腺下动脉 | 变异较大 |

手术要找下对时，先沿甲状腺下动脉在后缘下端找，但不要假定它一定在那里。
:::

:::compare{title="三种可能的座位"}
| 座位 | 本版 |
|------|------|
| 最常见 | 甲状腺侧叶后缘与其被膜之间（囊鞘间隙里） |
| 也可 | 埋入甲状腺实质内 |
| 也可 | 位于甲状腺鞘外 |

三种都要。写成「一定贴在后缘表面」，埋在实质里的那一对会在切除甲状腺时被一起拿掉。
:::

:::pitfall{label="一般是上、下两对，不要写成一对或三对"}
本版：一般有上、下两对。写成「左右各一」会少掉下对或上对；写成「每侧三粒」又不是本版原句。
:::

:::pitfall{label="上对在上中 1/3 交界，不要写成上端或下端"}
上端是甲状腺侧叶到达甲状软骨中部的那一头，不是上甲状旁腺的座位。上对钉在后缘上、中 1/3 交界；下端附近是下对常出现的地方。
:::

::figure{src="/images/anatomy/textbook/p0199_02.png" caption="图6-4　甲状腺和甲状旁腺（后面观）" alt="后面观：咽缩肌、舌骨大角、甲状舌骨膜；甲状腺左、右叶夹着食管和气管；右叶后缘可见上甲状旁腺和下甲状旁腺"}

图6-4 从后面把上、下甲状旁腺摆在甲状腺右叶后缘。上粒对上中 1/3 交界，下粒靠近下端。左叶后缘本版同一套，画面上没有再标一回。

甲状旁腺分泌甲状旁腺激素，主要作用是调节体内钙和磷的代谢。甲状旁腺激素和降钙素共同调节，维持机体血钙稳定。甲状旁腺激素分泌不足可引起血钙降低，机体发生酸中毒，从而导致中枢神经和肌肉的功能紊乱。

:::definition{label="甲状旁腺激素"}
甲状旁腺分泌。主要作用：调节体内**钙和磷**的代谢。与降钙素共同维持血钙稳定。
:::

:::cause-effect{title="为什么甲状腺手术后可能手脚麻木、抽搐"}
- **因** 甲状旁腺常在囊鞘间隙或埋入甲状腺实质，术中可能被误切或损伤，激素分泌不足
- **果** 血钙降低，中枢神经和肌肉功能紊乱，出现麻木、无力、抽搐

这一笔的形态底板是「旁腺住在甲状腺后面，不一定看得见」。降钙素不在本节展开来源。
:::

:::pitfall{label="旁腺激素管钙磷，不要写成甲状腺素管钙磷"}
甲状腺素管兴奋性和生长发育。钙磷这一笔落在甲状旁腺激素，并和降钙素共同维持血钙。写反之后，手足抽搐会去甲状腺素上找原因。
:::

:::insight{label="后面观先数四粒，再问有没有埋进实质里"}
图6-4 能看见的是后缘那两对。本版还写了「可埋入实质或在鞘外」——看不见不等于没有。找下对时把甲状腺下动脉当作路标，而不是当作保证。
:::

:::keypoint{label="甲状旁腺三句话"}
- 棕黄、黄豆大、扁椭圆；一般两对，每个 35～50 mg。
- 上对恒定在后缘上、中 1/3 交界；下对易变，多在后缘下端邻甲状腺下动脉。
- 激素调节钙磷；分泌不足 → 血钙降低，神经和肌肉紊乱。
:::

:::note{label="本节止于甲状旁腺"}
肾上腺在肾上方，左半月形、右三角形，是下一节的户头。不要把降钙素的腺来源在这里展开。
:::

:::memory{label="本节必背要点"}
- [ ] 甲状旁腺：棕黄色、黄豆大小、扁椭圆形。一般上、下两对，每个 **35～50 mg**。
- [ ] 常见位置：甲状腺侧叶后缘与被膜之间；也可埋入实质或位于甲状腺鞘外。
- [ ] 上对位置恒定：侧叶后缘上、中 1/3 交界处。
- [ ] 下对变异较大：多在侧叶后缘近下端、邻甲状腺下动脉。
- [ ] 被膜伸入成小梁，分成不完全小叶；细胞成索或团，毛细血管丰富。
- [ ] 甲状旁腺激素调节钙磷代谢，与降钙素共同维持血钙。
- [ ] 分泌不足 → 血钙降低，酸中毒，中枢神经和肌肉功能紊乱。
:::
