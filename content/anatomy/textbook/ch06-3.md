# 三、　甲状腺

甲状腺是人体最大的内分泌腺。本节把这一户写完：红褐色、H 形，左、右侧叶加中间的峡；成人平均重量男 26.71 g、女 25.34 g；侧叶贴在喉下部和气管颈部前外侧，吞咽时随喉上下移动。甲状旁腺虽住在囊鞘间隙里，形态归下一节。

甲状腺（thyroid gland）为红褐色腺体，呈 H 形，由左、右侧叶和中间的甲状腺峡组成（图6-3、图6-4）。成人甲状腺平均重量，在成年男性为 26.71 g，在女性为 25.34 g；不同年龄段会有女性稍重的情况，月经期和妊娠期甲状腺也增大。

侧叶位于喉下部和气管颈部的前外侧。左、右侧叶分为前、后缘，上、下端和前外侧面、内侧面。上端到达甲状软骨中部，下端至第 6 气管软骨环，后方平对第 5～7 颈椎高度。甲状腺峡位于第 2～4 气管软骨环的前方，连接左、右侧叶。约 50% 人的峡部向上伸出一锥状叶，长者可到达舌骨平面。

:::definition{label="甲状腺"}
人体**最大的内分泌腺**。红褐色，**H 形**：左、右侧叶 + 中间的甲状腺峡。职能：分泌甲状腺素。
:::

:::compare{title="成人甲状腺平均重量（本版）"}
| | 本版 |
|--|------|
| 成年男性 | **26.71 g** |
| 成年女性 | **25.34 g** |
| 变动 | 不同年龄段可有女性稍重；月经期和妊娠期增大 |

两个数都要带两位小数。不要改成「约 25 g」或「男 30 g」。平均重量是男略重；「女性稍重」是另一句年龄段情况，不要和平均值对调。
:::

:::definition{label="甲状腺侧叶"}
喉下部和气管颈部的**前外侧**。两缘（前、后）、两端（上、下）、两面（前外侧、内侧）。上端到**甲状软骨中部**，下端至**第 6 气管软骨环**，后方平对 **C5～C7**。
:::

:::definition{label="甲状腺峡"}
位于**第 2～4 气管软骨环前方**，连接左、右侧叶。约 **50%** 人向上伸出锥状叶，长者可到**舌骨平面**。
:::

:::compare{title="侧叶和峡部贴在哪几块软骨上"}
| 结构 | 本版高度 |
|------|----------|
| 侧叶上端 | 甲状软骨中部 |
| 侧叶下端 | 第 6 气管软骨环 |
| 侧叶后方 | 平对第 5～7 颈椎 |
| 峡 | 第 2～4 气管软骨环前方 |
| 锥状叶（约半数） | 自峡向上，长者到舌骨平面 |

上端对甲状软骨，下端对第 6 气管环，峡对 2～4 环。三套高度不要并成「都在甲状软骨上」。
:::

:::pitfall{label="重量按男 26.71 g、女 25.34 g，不要写成女更重的平均值"}
本版平均值是男性 26.71 g、女性 25.34 g。后面那句「不同年龄段会有女性稍重」是补充，不是把平均值改成女大于男。
:::

:::pitfall{label="峡在第 2～4 气管软骨环前方，不要写成第 6 环或甲状软骨前方"}
第 6 环是侧叶下端；甲状软骨中部是侧叶上端。峡只占 2～4 环前方这一小段。写错之后，气管切开和触及峡部的平面会对不上。
:::

## 一、被膜、囊鞘间隙和悬韧带

甲状腺被气管前筋膜包裹，该筋膜形成甲状腺假被膜，即甲状腺鞘。甲状腺的外膜称为真被膜，即纤维囊。二者之间的间隙为囊鞘间隙，内有疏松结缔组织、血管、神经和甲状旁腺。假被膜内侧增厚形成甲状腺悬韧带，使两侧叶内侧和峡部连于甲状软骨、环状软骨和气管软骨环，将甲状腺固定于喉和气管壁上。当吞咽时，甲状腺可随喉的活动而上、下移动。

:::definition{label="真被膜与假被膜"}
真被膜 = 甲状腺外膜 = **纤维囊**。假被膜 = 气管前筋膜形成的**甲状腺鞘**。真在里，假在外，中间是囊鞘间隙。
:::

:::definition{label="囊鞘间隙"}
纤维囊与甲状腺鞘之间。内容：疏松结缔组织、血管、神经和**甲状旁腺**。甲状旁腺常住在这里，形态下一节再写。
:::

:::definition{label="甲状腺悬韧带"}
假被膜内侧增厚而成。把两侧叶内侧和峡部连到**甲状软骨、环状软骨和气管软骨环**上，所以吞咽时甲状腺随喉上下移动。
:::

:::cause-effect{title="为什么吞咽时甲状腺会动"}
- **因** 悬韧带把侧叶内侧和峡固定在喉和气管壁上
- **果** 喉一上下，甲状腺跟着上下

这一笔用来和颈部其他肿块对照：随吞咽移动的，先想甲状腺。
:::

:::pitfall{label="真被膜是纤维囊，假被膜是甲状腺鞘，不要把真假写反"}
本版：外膜 = 真被膜 = 纤维囊；气管前筋膜 = 假被膜 = 甲状腺鞘。写成「真被膜就是气管前筋膜」，囊鞘间隙里的甲状旁腺会跟着搬错层。
:::

## 二、甲状腺素

甲状腺分泌甲状腺素，可提高神经兴奋性，促进生长发育。甲状腺素对婴幼儿的骨骼发育和中枢神经系统发育影响显著。小儿甲状腺功能减退时，不仅身体矮小，而且出现脑发育障碍，导致呆小症。

:::definition{label="甲状腺素"}
甲状腺分泌。作用：提高神经兴奋性，促进生长发育。对婴幼儿的**骨骼发育和中枢神经系统发育**影响显著。
:::

:::definition{label="呆小症"}
小儿甲状腺功能减退：身体矮小，并有**脑发育障碍**。和垂体性侏儒症都矮，呆小症多了智力这一笔。
:::

:::pitfall{label="小儿甲减是呆小症，不要写成垂体性侏儒症"}
侏儒症是幼年生长激素不足，本版不强调脑发育障碍。呆小症必须同时记住矮小和脑发育障碍。病名写错，缺的激素就从甲状腺素换成生长激素。
:::

:::insight{label="前面看 H 形和锥状叶，后面看后缘那两粒旁腺"}
图6-3 把峡和锥状叶摆在气管前方；图6-4 把上、下甲状旁腺钉在侧叶后缘。手术从前面进，旁腺却住在后面的囊鞘间隙里——两张图要一起看。
:::

:::keypoint{label="甲状腺先钉这几句"}
- 最大内分泌腺；H 形 = 两侧叶 + 峡；约 50% 有锥状叶，长者到舌骨。
- 重量：男 26.71 g，女 25.34 g。
- 上端甲状软骨中部，下端第 6 气管环，峡在第 2～4 气管环前方；后方平 C5～C7。
- 真被膜 = 纤维囊；假被膜 = 甲状腺鞘；囊鞘间隙里有甲状旁腺。
- 悬韧带固定于喉和气管，吞咽随喉上下。
- 甲减（小儿）→ 呆小症：矮小 + 脑发育障碍。
:::

:::note{label="本节止于甲状腺"}
甲状旁腺的上、下两对和囊鞘间隙里的座位，是下一节的户头。图6-4 上已经能看见它们，形态不要在这里展开。
:::
