# 第四节　尿道

第三节把膀胱写到尿道内口：尿液在这里离开储尿的囊。本节只写**女性尿道**：短、宽而直的一段管道，内口的括约肌、穿尿生殖膈处的括约肌、外口的位置，以及尿道旁腺。男性尿道见男性生殖系统，形态不在本节展开。

女性尿道把膀胱里的尿液排到阴道前庭。它不是膀胱三角的向下延长「黏膜区」，而是独立的一段肌性管道：内口在上，外口在下，中间穿过尿生殖膈。

:::definition{label="女性尿道"}
平均长 **3～5 cm**，直径约 **0.6 cm**，较男性尿道**短、宽而直**。起自尿道内口，向前下方穿过尿生殖膈，开口于阴道前庭的尿道外口。
:::

:::definition{label="男性尿道（本节）"}
见**男性生殖系统**。
:::

:::concept{term="先问这是不是女性那条短宽直的排尿管道"}
看见尿道，先问男女。本节户头是女性：3～5 cm、直径约 0.6 cm、短宽直。男性尿道见男性生殖系统。把膀胱三角整段再写一遍，是重复上一节。
:::

## 一、女性尿道的形态

女性尿道（female urethra）平均长 3～5 cm，直径约 0.6 cm，较男性尿道短、宽而直（图4-17）。尿道内口约平耻骨联合后面中央或下部，女性低于男性。其走行向前下方，穿过尿生殖膈，开口于阴道前庭的尿道外口。

短、宽而直，是这一段管道最要紧的形态：路程短、管腔相对宽、行程直，尿液容易排出，逆行的病原体也更容易进入膀胱。

:::definition{label="女性尿道的长度与口径"}
长 **3～5 cm**，直径约 **0.6 cm**。长度按这一段记，不要改成「约 4 cm」一个定点；口径 0.6 cm 是直径，不要写成半径。
:::

:::definition{label="短、宽而直"}
相对男性而言：短（3～5 cm）、宽（直径约 0.6 cm）、直（向前下穿尿生殖膈）。三字一起背，缺「直」会画成弯管，缺「短、宽」对不上逆行感染的形态底板。
:::

:::definition{label="女性尿道内口的高度"}
约平**耻骨联合后面中央或下部**，女性低于男性。上一节新生儿内口在耻骨联合上缘，那是年龄差；这里是男女差——同一成人骨盆，女性内口更低。
:::

:::definition{label="女性尿道的行程"}
自内口**向前下方**，穿过**尿生殖膈**，开口于阴道前庭的尿道外口。方向是前下，不是垂直向下，也不是向后开口于阴道。
:::

:::definition{label="尿生殖膈（女性尿道）"}
女性尿道向前下穿过的那一层。穿膈处被尿道阴道括约肌（横纹肌）环绕。膈的详细结构不在本节展开，这里只认管道从这里穿过去。
:::

:::definition{label="阴道前庭（尿道外口）"}
女性尿道外口的开口部位。外口在阴道口前方、阴蒂后方 2.0～2.5 cm，三者从前到后排在前庭中线上。
:::

::figure{src="/images/anatomy/textbook/p0170_02.png" caption="图4-17　女性尿道" alt="女性膀胱与尿道剖面：膀胱尖、体，黏膜成膀胱襞，三角区平滑并见输尿管间襞、输尿管口；尿道内口以下为尿道，可见尿道嵴、尿道肌层，外口开于阴道口前方，两侧小阴唇"}

图4-17 把女性膀胱和尿道画在同一张冠状剖面上。上方仍能看见三角：平滑、有输尿管间襞和输尿管口，下角是尿道内口——这是上一节的出口，本节的入口。内口以下管道变细，向前下走向外口；外口开在阴道口前方，两侧是小阴唇。画面上的黏膜、黏膜下层、肌层是膀胱壁的层次，用来对照「三角缺黏膜下层」；尿道本身另标了尿道肌层。尿道嵴是内口下方的纵行黏膜隆起，用来认中线。

:::compare{title="和上一节交界：内口这一刀"}
| | 落在哪一户 |
|--|-----------|
| 三角三顶点、间襞、膀胱垂 | 第三节膀胱 |
| 尿道内口作为三角的下角 | 上一节收笔，本节开篇 |
| 内口以下的管道、括约肌、外口、旁腺 | 本节 |

内口两边都要认，户头不要并成「三角就是尿道」。
:::

:::compare{title="短、宽、直对上的三个数"}
| 形态 | 本版数字或事实 |
|------|----------------|
| 短 | 长 **3～5 cm** |
| 宽 | 直径约 **0.6 cm** |
| 直 | 向前下穿尿生殖膈，开口于阴道前庭 |

男性尿道见男性生殖系统。把女性也写成弯管，短宽直就作废。
:::

:::pitfall{label="女性尿道开口于阴道前庭，不要写成开口于阴道"}
外口在阴道前庭，位置在阴道口的**前方**。写成「开口于阴道」会把尿道和阴道并成一条管。
:::

:::pitfall{label="长度按 3～5 cm，不要改成 2 cm 或 8 cm"}
3～5 cm 已经短于男性。再改短或改长，和「短、宽而直」以及外口到阴蒂 2.0～2.5 cm 都对不上。直径钉在约 0.6 cm，不要写成与输尿管平均管径 0.5～1.0 cm 同一段。
:::

:::insight{label="图4-17 从上往下：平滑的三角 → 内口 → 一条直管道 → 外口在阴道口前方"}
三角是上一节的平地，管道是本节的路。路很短，几乎不拐弯，外口又靠近阴道口——形态上就是一条又短又直的排水管。
:::

:::keypoint{label="形态三句话"}
- 长 3～5 cm，直径约 0.6 cm，短、宽而直。
- 内口约平耻骨联合后面中央或下部，女性低于男性。
- 向前下穿尿生殖膈，开口于阴道前庭的尿道外口。
:::

## 二、内口、括约肌与外口

尿道内口（internal orifice of urethra）周围为平滑肌组成的膀胱括约肌所环绕。穿过尿生殖膈处则被由横纹肌形成的尿道阴道括约肌所环绕。尿道外口（external orifice of urethra）位于阴道口的前方、阴蒂的后方 2.0～2.5 cm 处，为尿道阴道括约肌所环绕。

两个括约肌一上一下：内口是平滑肌的膀胱括约肌，尿生殖膈处是横纹肌的尿道阴道括约肌。外口落在阴道口前方、阴蒂后方那 2.0～2.5 cm 的位置上，也被尿道阴道括约肌环绕。

:::definition{label="膀胱括约肌"}
环绕**尿道内口**，由**平滑肌**组成。它是内口这一圈的括约装置，不是尿生殖膈上的那一块横纹肌。
:::

:::definition{label="尿道阴道括约肌"}
**横纹肌**，环绕女性尿道**穿过尿生殖膈处**，并环绕**尿道外口**。不要把它写成平滑肌，也不要写成只包外口、不包膈处。
:::

:::definition{label="尿道外口"}
位于**阴道口的前方**、**阴蒂的后方 2.0～2.5 cm**处。开口于阴道前庭。为尿道阴道括约肌所环绕。
:::

:::compare{title="两个括约肌（肌性质地不要并）"}
| | 位置 | 肌纤维 |
|--|------|--------|
| 膀胱括约肌 | 尿道内口周围 | **平滑肌** |
| 尿道阴道括约肌 | 穿尿生殖膈处；并环绕外口 | **横纹肌** |

上为平滑肌、下为横纹肌。写成「内外都是平滑肌」或「内口也是横纹肌」，随意控制的那一圈会安错层。
:::

:::compare{title="外口的前后邻居"}
| 方向 | 本版 |
|------|------|
| 前方关系 | 在**阴道口前方**（外口比阴道口更靠前） |
| 后方关系 | 在**阴蒂后方 2.0～2.5 cm** |
| 开口于 | 阴道前庭 |

先找阴蒂，向后 2.0～2.5 cm 是外口，再往后才是阴道口。三个结构在前庭中线上从前到后：阴蒂 → 尿道外口 → 阴道口。
:::

:::compare{title="本节出现的几个 2.5 cm（不要和上一章并）"}
| 本版 2.5 cm 左右 | 在哪一节、量什么 |
|------------------|------------------|
| 空虚时两输尿管口间距约 2.5 cm | 第二节 / 第三节，三角上两口 |
| 女性输尿管在子宫颈外侧约 2.5 cm | 第二节，宫旁、桥下流水 |
| 外口在阴蒂后方 **2.0～2.5 cm** | **本节**，前庭中线 |

三个 2.5 cm 不在同一条线上。本节只用 2.0～2.5 cm 钉外口到阴蒂的距离。
:::

:::pitfall{label="内口是平滑肌括约肌，尿生殖膈处是横纹肌，不要对调"}
膀胱括约肌在内口、平滑肌；尿道阴道括约肌在膈处和外口、横纹肌。对调之后，「能随意收缩的那一圈」会假想成在内口。
:::

:::pitfall{label="外口在阴道口前方、阴蒂后方，不要写成阴蒂前方或阴道口后方"}
本版两个方位一起写：阴道口前方 + 阴蒂后方 2.0～2.5 cm。写成「阴蒂前方」会跑到阴蒂背侧；写成「阴道口后方」会掉进阴道。
:::

:::cause-effect{title="为什么女性更容易发生逆行感染"}
- **因** 女性尿道短、宽而直，外口又靠近阴道口
- **果** 病原体更容易经外口上行进入膀胱

形态底板就是这三字：短、宽、直。不是另有一条「感染管道」。
:::

:::insight{label="从上往下两道箍：平滑肌箍内口，横纹肌箍膈和外口"}
内口那道箍跟着膀胱走，是平滑肌；尿生殖膈那道箍可以随意收缩，是横纹肌，一直环到外口。导尿和检查外口时，先在阴蒂后方 2.0～2.5 cm、阴道口前方这一小段前庭上找口。
:::

:::keypoint{label="括约肌和外口"}
- 内口：膀胱括约肌，**平滑肌**。
- 穿尿生殖膈处及外口：尿道阴道括约肌，**横纹肌**。
- 外口：阴道口前方，阴蒂后方 **2.0～2.5 cm**，开口于阴道前庭。
:::

## 三、尿道旁腺

在尿道下端有尿道旁腺（paraurethral gland），也称女性前列腺（female prostate），其导管开口于尿道周围。尿道旁腺发生感染时可形成囊肿，并可压迫尿道，导致尿路不畅。

:::definition{label="尿道旁腺"}
位于尿道**下端**，导管开口于**尿道周围**。也称**女性前列腺**。感染可形成囊肿，压迫尿道，导致尿路不畅。
:::

:::definition{label="女性前列腺"}
尿道旁腺的别名。它不是男性前列腺的缩小版搬到盆膈上，而是尿道下端这组旁腺。男性前列腺在膀胱颈下方，户头在男性生殖系统。
:::

:::compare{title="旁腺和两个括约肌不要并户"}
| 结构 | 位置 | 出了问题 |
|------|------|----------|
| 膀胱括约肌 | 内口，平滑肌 | 内口关闭不全 |
| 尿道阴道括约肌 | 尿生殖膈处和外口，横纹肌 | 随意控制这一圈失灵 |
| 尿道旁腺 | 尿道下端，导管开口于尿道周围 | 感染 → 囊肿 → 压迫尿道 → 尿路不畅 |

旁腺不是括约肌。囊肿压迫的是管腔，不是「括约肌肥大」。
:::

:::pitfall{label="尿道旁腺在尿道下端，不要写成开在膀胱三角"}
导管开口于尿道周围。把旁腺安到三角，囊肿会假想成膀胱内占位；本版的压迫部位是尿道，后果是尿路不畅。
:::

:::pitfall{label="女性前列腺就是尿道旁腺，不要把男性前列腺的分叶写进来"}
别名只是提醒这组腺在女性尿道下端。中叶、膀胱垂、射精管口都是男性颈下方的结构，上一节图4-15 里见过，不在本节展开。
:::

:::insight{label="下端一圈腺，感染后会从旁边把细管子挤窄"}
女性尿道本来就只有约 0.6 cm 直径。旁腺在下端、开口在尿道周围，囊肿一涨，最先挤的就是外口附近这一段。短宽直让感染容易上行，旁腺又给下端留了这处可以成囊肿的附属结构。
:::

:::keypoint{label="旁腺一句话"}
尿道下端，导管开口于尿道周围，又名女性前列腺；感染成囊肿可压迫尿道，导致尿路不畅。
:::

:::note{label="本节止于女性尿道"}
男性尿道见男性生殖系统。膀胱的三角、穿刺和固定已经在上一节写完。泌尿系统四件套到此收口：肾产尿，输尿管输尿，膀胱储尿，尿道排尿。
:::
