# 一、　垂体

内分泌系统（endocrine system）是机体的调节系统，与神经系统相辅相成：共同维持内环境的平衡与稳定，调节生长发育和各种代谢，并调控生殖、影响行为（图6-1）。本节先把「腺」和「组织」切开，再把垂体这一户写完：灰红色椭圆形小体，坐在颅底蝶鞍的垂体窝里，表面有结缔组织被膜，分成来源、结构和功能都不同的腺垂体与神经垂体。松果体、甲状腺以下各腺是后面几节的户头，不要提前写成一锅。

内分泌系统由内分泌腺和内分泌组织组成。内分泌腺（endocrine gland）毛细血管丰富，**无导管**，分泌的物质称为激素（hormone）。激素直接进入血液循环，作用于特定的靶器官。本版名单是垂体、松果体、甲状腺、甲状旁腺、肾上腺、胸腺和生殖腺。内分泌腺的血液供应非常丰富，与旺盛的新陈代谢和激素的运送有关；结构和功能活动有明显的年龄变化。内分泌组织（endocrine tissue）以细胞团分散于机体的器官或组织内，本版点名胰内的胰岛、睾丸内的间质细胞、卵巢内的卵泡和黄体。内脏和脉管等系统的许多器官也兼具内分泌功能，形态不在本章展开。

:::definition{label="内分泌系统"}
机体的**调节系统**，与神经系统相辅相成。职能：维持内环境平衡与稳定，调节生长发育和代谢，调控生殖，影响行为。组成先切成**内分泌腺**和**内分泌组织**两块，不要一上来写成「就是甲状腺加肾上腺」。
:::

:::definition{label="内分泌腺"}
毛细血管丰富，**无导管**。分泌物是激素，直接入血，作用于靶器官。本版名单：**垂体、松果体、甲状腺、甲状旁腺、肾上腺、胸腺和生殖腺**。血供丰富，结构和功能有年龄变化。
:::

:::definition{label="内分泌组织"}
以细胞团分散在器官或组织里。本版三处：**胰内的胰岛、睾丸内的间质细胞、卵巢内的卵泡和黄体**。它们不是独立的腺器官，不要另立成「第八、第九、第十个内分泌腺」。
:::

:::definition{label="激素"}
内分泌腺（及内分泌组织）分泌的物质。无导管，直接进入血液循环，作用于特定靶器官。不要把激素听成「沿导管排到体表或体腔的分泌物」。
:::

:::concept{term="先问这是无导管的腺，还是器官里的一团细胞"}
看见内分泌，先把腺和组织切开。腺是独立器官、无导管、激素入血；组织是胰岛、间质细胞、卵泡和黄体这类细胞团。把「内分泌系统」听成「就是几个有名字的腺体」，胰岛会从开篇丢掉；把甲状腺滤泡写成有导管的外分泌腺，激素入血这一笔就断了。
:::

:::compare{title="内分泌腺与内分泌组织（本版对照）"}
| | 本版 | 例子 |
|--|------|------|
| 内分泌腺 | 独立器官，无导管，激素入血 | 垂体、松果体、甲状腺、甲状旁腺、肾上腺、胸腺、生殖腺 |
| 内分泌组织 | 细胞团分散在器官或组织内 | 胰岛、睾丸间质细胞、卵泡和黄体 |

腺没有导管。把甲状腺、垂体听成「有导管把激素送到靶器官」，和消化腺、汗腺就并成一套了。
:::

:::note{label="本节止于垂体"}
图6-1 是章首全貌，用来认腺和组织的座位。画面上的松果体、甲状腺、甲状旁腺、胸腺、肾上腺、胰和生殖腺，形态归后面几节；下丘脑本身不是本版内分泌腺名单里的一项，这里只用来认它和垂体的邻居关系。
:::

:::insight{label="无导管，所以激素只能入血，不能沿管子送到靶器官"}
外分泌腺靠导管把分泌物送到体表或管腔。内分泌腺把导管这一笔删掉，毛细血管又特别丰富——激素只能进循环。图6-1 上那些器官看起来各据一方，连起来的是血，不是管子。
:::

## 一、位置和外形

垂体（pituitary gland，hypophysis）为一灰红色的椭圆形小体，位于颅底蝶鞍的**垂体窝**内（图6-2）。成年人垂体重约 0.5～0.6 g，女性略大于男性，妊娠期显著增大。表面包裹结缔组织被膜。垂体在神经系统和内分泌腺的相互作用中处于重要地位。

:::definition{label="垂体"}
灰红色椭圆形小体。位置钉死：颅底蝶鞍的**垂体窝**。成人约 **0.5～0.6 g**，女性略大于男性，妊娠期显著增大。表面有结缔组织被膜。
:::

:::compare{title="垂体的重量和性别差（本版）"}
| | 本版 |
|--|------|
| 成人重量 | 约 **0.5～0.6 g** |
| 性别 | 女性略大于男性 |
| 妊娠 | 显著增大 |

只记这一段。不要改成「约 1 g」，也不要把妊娠期增大听成「另长出一个腺」。
:::

:::pitfall{label="垂体在蝶鞍垂体窝，不要写成蝶窦里或颅外"}
本版原句：位于颅底蝶鞍的垂体窝内。蝶窦在鞍下方的骨腔里，不是垂体的座位；写成「挂在咽顶」会把颅底这一户搬到颈部去。
:::

## 二、分部：腺垂体和神经垂体

垂体由腺垂体和神经垂体两个部分组成，来源、结构和功能均不同。神经垂体（neurohypophysis）分为神经部和漏斗两部分，漏斗与下丘脑相连，包括漏斗柄和正中隆起。腺垂体（adenohypophysis）分为远侧部、结节部和中间部三部分：远侧部最大；中间部位于远侧部与神经部之间；结节部围绕在漏斗周围。

腺垂体的远侧部和结节部又合称为垂体前叶；神经垂体的神经部和腺垂体的中间部又合称为垂体后叶。前叶、后叶是功能分组，和「腺垂体、神经垂体」不是同一刀：中间部属于腺垂体，却划进后叶。

:::definition{label="腺垂体"}
三部：**远侧部、结节部、中间部**。远侧部最大；中间部夹在远侧部与神经部之间；结节部围绕漏斗。来源、结构和功能都与神经垂体不同。
:::

:::definition{label="神经垂体"}
两部：**神经部和漏斗**。漏斗与下丘脑相连，包括**漏斗柄和正中隆起**。神经部是后叶的主体，漏斗是连下丘脑的柄。
:::

:::definition{label="垂体前叶与后叶"}
前叶 = 腺垂体的**远侧部 + 结节部**，负责分泌多种激素。后叶 = 神经垂体的**神经部 + 腺垂体的中间部**，负责贮存和释放下丘脑合成的激素。中间部不要两边都算，也不要从腺垂体名单里删掉。
:::

:::compare{title="两套切法不要并成一刀"}
| 套 | 本版名单 | 职能怎么记 |
|----|----------|------------|
| 按来源结构 | 腺垂体（远侧部、结节部、中间部）；神经垂体（神经部、漏斗） | 来源、结构、功能均不同 |
| 按前叶后叶 | 前叶 = 远侧部 + 结节部；后叶 = 神经部 + 中间部 | 前叶分泌；后叶贮存释放 |

漏斗（漏斗柄 + 正中隆起）连下丘脑，不要把它听成「前叶的第四部」。
:::

:::pitfall{label="中间部属于腺垂体，却划进后叶，不要写反"}
本版：中间部位于远侧部与神经部之间，是腺垂体的一部；前、后叶分组时它和神经部合称后叶。写成「中间部 = 神经垂体」或「后叶 = 整个腺垂体」，生长激素和抗利尿激素的产地会对调。
:::

:::pitfall{label="漏斗包括漏斗柄和正中隆起，不要只记一根柄"}
本版原句：漏斗与下丘脑相连，包括漏斗柄和正中隆起。图6-2 右侧放大把正中隆起、漏斗、结节部画在同一条连线上。丢掉正中隆起，下丘脑和垂体的交界就少了一块。
:::

::figure{src="/images/anatomy/textbook/p0198_01.png" caption="图6-2　垂体和松果体" alt="颅正中矢状切：上方全貌示松果体与垂体位置；左下放大松果体，标软脑膜、松果体隐窝、缰连合、后连合和中脑顶盖；右下放大垂体，标视交叉、正中隆起、漏斗、结节部、远侧部、中间部和神经部"}

图6-2 上一张全貌、两张放大。左侧放大是松果体，形态归第二节；右侧放大才是本节的户头：视交叉后方，漏斗连下去，结节部围着漏斗，远侧部最大，中间部夹在远侧部与神经部之间。

:::insight{label="先认漏斗这条柄，再把远侧部和神经部分到柄的两边"}
图6-2 右侧：漏斗从下丘脑垂下来，结节部包住它；远侧部鼓在前方，神经部鼓在后方，中间部是夹心。前叶在前（远侧部 + 结节部），后叶在后（神经部 + 中间部），座位和职能是同一套前后。
:::

## 三、前叶分泌、后叶贮存释放

腺垂体的远侧部和结节部合称垂体前叶，能分泌多种激素，如生长激素、促甲状腺激素、促肾上腺皮质激素、促性腺激素等。后三种激素分别促进甲状腺、肾上腺皮质和生殖腺的分泌活动。生长激素可促进肌、内脏的生长和多种代谢过程，尤其是刺激骺软骨生长，使骨增长。幼年时生长激素分泌不足可导致垂体性侏儒症；分泌过多时，在骨骼发育成熟前引起巨人症，在骨骼发育成熟后引起肢端肥大症。

神经垂体的神经部和腺垂体的中间部合称垂体后叶，能贮存和释放视上核、室旁核的神经内分泌细胞合成的抗利尿激素（加压素）和缩宫素。抗利尿激素主要促进肾远曲小管和集合管重吸收水，使尿液浓缩；分泌减少可导致尿崩症。缩宫素可促进子宫平滑肌收缩，还可促进乳腺分泌。后叶自己不合成这两样激素，合成地点在下丘脑的视上核和室旁核。

:::definition{label="垂体前叶激素"}
本版点名：**生长激素、促甲状腺激素、促肾上腺皮质激素、促性腺激素**。后三种分别促进甲状腺、肾上腺皮质和生殖腺的分泌。生长激素促进肌、内脏生长和多种代谢，尤其刺激骺软骨使骨增长。
:::

:::definition{label="垂体后叶激素"}
贮存并释放下丘脑**视上核、室旁核**合成的**抗利尿激素（加压素）**和**缩宫素**。后叶是仓库，不是这两样激素的工厂。
:::

:::compare{title="生长激素过多、过少（本版三症）"}
| 情况 | 本版结果 |
|------|----------|
| 幼年分泌不足 | **垂体性侏儒症** |
| 骨骼发育成熟前分泌过多 | **巨人症** |
| 骨骼发育成熟后分泌过多 | **肢端肥大症** |

三症不要并成「个子出问题」。成熟前是整根骨头变长，成熟后骺软骨已经闭合，只能往肢端和骨隆起上长。
:::

:::compare{title="后叶两样激素各管什么"}
| 激素 | 合成 | 本版作用 | 分泌减少 |
|------|------|----------|----------|
| 抗利尿激素（加压素） | 视上核、室旁核 | 促进肾远曲小管和集合管重吸收水，使尿液浓缩 | **尿崩症** |
| 缩宫素 | 同上 | 促进子宫平滑肌收缩，还可促进乳腺分泌 | 本版未另立病名 |

抗利尿激素的靶是肾的远曲小管和集合管，不要写成「肾小球不滤过」。
:::

:::pitfall{label="后叶贮存释放，不要写成后叶自己合成抗利尿激素和缩宫素"}
本版原句：贮存和释放视上核、室旁核的神经内分泌细胞合成的抗利尿激素和缩宫素。工厂在下丘脑，仓库在后叶。写成「神经部细胞分泌加压素」，下丘脑这一笔就没了。
:::

:::pitfall{label="幼年生长激素不足是垂体性侏儒症，不要和呆小症并成一个词"}
侏儒症落在本节的生长激素。呆小症是小儿甲状腺功能减退，归甲状腺那一户：身体矮小还加脑发育障碍。两症都矮，一个不强调智力，一个强调脑发育。
:::

:::cause-effect{title="为什么骨骼成熟前后，生长激素过多的结果不一样"}
- **因** 生长激素尤其刺激骺软骨生长使骨增长；骨骼发育成熟后骺软骨闭合，长骨不能再向长轴生长
- **果** 成熟前过多 → 巨人症；成熟后过多 → 肢端肥大症

同一激素，靶组织还能不能长，决定了病名。
:::

:::keypoint{label="垂体先钉这几句"}
- 颅底蝶鞍垂体窝；成人约 0.5～0.6 g；女略大，妊娠显著增大。
- 腺垂体：远侧部、结节部、中间部。神经垂体：神经部、漏斗（漏斗柄 + 正中隆起）。
- 前叶 = 远侧部 + 结节部，分泌 GH、TSH、ACTH、促性腺激素。
- 后叶 = 神经部 + 中间部，贮存释放视上核、室旁核的抗利尿激素和缩宫素。
- GH：幼年不足 → 垂体性侏儒症；成熟前过多 → 巨人症；成熟后过多 → 肢端肥大症。
- 抗利尿激素减少 → 尿崩症。
:::
