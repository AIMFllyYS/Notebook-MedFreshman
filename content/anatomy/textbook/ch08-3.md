# 第三节　其他感觉器

前两节把特殊感觉器里的视器和前庭蜗器立完。本节收其余三户：**嗅器、味器和皮肤**。内耳的前庭水管、蜗神经不在本节——那是第二节迷路的尾巴。皮肤是一般感受器最集中的地方，痛、温、触、压都落在这一张「封面」上。

:::concept{term="先问这是鼻顶的嗅黏膜、舌上的味蕾，还是全身那张皮"}
看见「其他感觉器」，不要回头写螺旋器。嗅器只在上鼻甲及相对鼻中隔以上；味蕾嵌在菌状、轮廓、叶状乳头，丝状乳头不是这一户；皮肤由表皮和真皮构成，附属结构另计。把嗅区写成整个鼻黏膜，或把分裂线听成皮褶，户头就并了。
:::

:::compare{title="本节三户（对照前两节）"}
| 户 | 本版位置 | 特殊还是一般 |
|----|----------|----------------|
| 嗅器 | 上鼻甲及其相对鼻中隔及以上 | 特殊（嗅觉） |
| 味器 | 味蕾：菌状 / 轮廓 / 叶状乳头，以及软腭、会厌 | 特殊（味觉） |
| 皮肤 | 体表；表皮 + 真皮，深面浅筋膜 | 一般（痛、温、触、压）；兼屏障和体温 |

螺旋器、囊斑、壶腹嵴已在第二节。
:::

## 一、嗅器

嗅器（olfactory organ）在鼻腔上部，即**上鼻甲及其相对的鼻中隔及以上部分**。此部黏膜呈淡黄色，血管比呼吸部少。黏膜内含嗅细胞，为双极神经元：周围突有纤毛，中枢突汇集成嗅丝，穿筛骨的筛板进入嗅球（图8-1）。

:::definition{label="嗅器"}
鼻腔上部的嗅黏膜。本版范围：**上鼻甲、相对的鼻中隔，以及二者以上**。不是整个鼻腔，也不是下鼻甲。
:::

:::definition{label="嗅细胞"}
双极神经元。周围突有纤毛（嗅毛），中枢突汇成嗅丝，穿筛骨筛板入嗅球。换能发生在黏膜里，入颅走的是嗅丝，不是「嗅神经干从鼻孔伸进去」。
:::

::figure{src="/images/anatomy/textbook/p0261_02.png" caption="图8-1　特殊感受器（嗅觉感受器）" alt="嗅黏膜剖面：感受器细胞有纤毛，支持细胞和基底细胞夹在其间，黏液分泌腺开口于表面，中枢突穿骨和硬脑膜入嗅球"}

:::compare{title="嗅区与呼吸区（和第三章对上）"}
| | 位置 | 本版形态 |
|--|------|----------|
| 嗅区 | 上鼻甲、相对鼻中隔及二者上方的鼻腔顶部 | 淡黄色，血管较少，有嗅细胞 |
| 呼吸区 | 其余鼻黏膜 | 富含鼻腺，温暖湿润空气 |

第三章已把嗅区钉在同一范围。本节补的是嗅细胞：双极、有纤毛、嗅丝穿筛板。
:::

:::pitfall{label="嗅器在上鼻甲及相对鼻中隔以上，不要写成中鼻甲"}
中鼻甲对的是中鼻道和筛泡，不是嗅黏膜。范围少写「以上」，顶部那一块嗅细胞会丢掉；写成「整个上鼻道侧壁」，又和呼吸区边界糊在一起。
:::

:::insight{label="嗅丝穿筛板，筛板骨折可以失嗅也可以出现脑脊液鼻漏"}
中枢突汇成嗅丝后立刻穿筛骨筛板进嗅球。筛板是颅前窝底，也是鼻腔顶。这一穿既解释了脑脊液鼻漏可以经过嗅区，也解释了头部外伤后的嗅觉丧失。
:::

## 二、味器

味器（gustatory organ）即味蕾（taste bud）。人类的味蕾嵌于舌的菌状乳头、轮廓乳头和叶状乳头的上皮内，以轮廓乳头上的味蕾最多；在软腭、会厌等处的上皮内也有味蕾分布。味蕾呈卵圆形，底部抵达基板，有味觉神经分布，顶端借味孔通口腔。图8-1 左扇把这一枚卵圆画清楚：周围是舌的上皮细胞，味蕾内有感受器细胞和支持细胞，顶端味毛经味孔伸向口腔，底部神经纤维进入。味觉刺激主要有酸、甜、苦、咸四种。分布于味蕾的神经主要是面神经和舌咽神经。

:::definition{label="味器"}
就是味蕾。本版嵌在**菌状乳头、轮廓乳头、叶状乳头**的上皮内，轮廓乳头最多；软腭、会厌也有。丝状乳头不在名单里。
:::

:::definition{label="味蕾"}
卵圆形。底到基板，有味觉神经；顶借**味孔**通口腔。刺激主要四味：酸、甜、苦、咸。
:::

:::definition{label="味觉神经（本版）"}
主要是**面神经和舌咽神经**。不要自行补进「全部由舌神经」或把迷走神经写成主要支配。
:::

::figure{src="/images/anatomy/textbook/p0262_01.png" caption="图8-1　特殊感受器（味觉感受器与平衡觉感受器）" alt="左：味蕾嵌于舌上皮，味孔朝向口腔，味毛、感受器细胞和支持细胞排列成卵圆，底部神经纤维进入；右：膜迷路的壶腹嵴、椭圆囊斑和球囊斑，平衡觉形态见第二节"}

:::compare{title="三种乳头与味蕾"}
| 乳头 | 味蕾 |
|------|------|
| 轮廓乳头 | **最多** |
| 菌状乳头 | 有 |
| 叶状乳头 | 有 |
| 丝状乳头 | 本版未列入味器名单 |

软腭、会厌是舌外的补充分布，不是「只有舌头才有味蕾」。
:::

:::pitfall{label="丝状乳头管摩擦，不管味觉"}
本版味器只点名菌状、轮廓、叶状。把丝状乳头写成「也有味蕾」，和舌黏膜的功能分户就并了。四味是酸、甜、苦、咸，不要用后出的「鲜味」替换本版名单。
:::

:::note{label="图8-1 右侧是平衡觉，不在本节展开"}
同一张特殊感受器图的右扇是膜壶腹、椭圆囊斑和球囊斑。位置觉感受器的形态和前庭神经三支见第二节内耳。
:::

## 三、皮肤

皮肤覆盖在身体表面，成人皮肤表面积约为 **1.7 m²**。皮肤柔软而有弹性，各处厚薄不等：手掌和足跖处皮肤最厚，缺乏毛囊，具有皮嵴，以抵抗摩擦。身体背侧和伸侧较腹侧和屈侧的皮肤厚。皮肤由表皮和真皮构成。其深面主要为疏松结缔组织构成的皮下组织，即浅筋膜，含丰富的血管、淋巴管、浅淋巴结等。浅筋膜将皮肤和深部的组织连接起来，既让皮肤能移动，又把体表感受器收到的刺激传到深部神经。毛发、指（趾）甲、皮脂腺、汗腺和乳腺均是皮肤的附属结构。

本节把皮肤当作一般感受器的「封面」来写：痛、温、触、压的感受器就埋在这张皮里。组织学上的表皮分层、真皮乳头，以及乳腺的小叶导管，都不在系统解剖学这一节展开。

:::definition{label="皮肤"}
体表的覆盖。成人表面积约 1.7 m²。由表皮和真皮构成，深面是浅筋膜。手掌、足跖最厚，无毛囊而有皮嵴。
:::

:::definition{label="皮肤的附属结构"}
本版五件：**毛发、指（趾）甲、皮脂腺、汗腺和乳腺**。乳腺按附属结构记，形态细节不在本节展开。
:::

**1. 表皮（epidermis）**　为复层鳞状上皮，无血管分布。在手掌和足底最厚。在表皮的基底层细胞之间有色素细胞。色素细胞的多少是决定肤色的主要因素。

:::definition{label="表皮"}
复层鳞状上皮，**无血管**。手掌、足底最厚。基底层细胞之间有色素细胞，其多少是肤色的主要因素。
:::

**2. 真皮（dermis）**　位于表皮深面，主要由胶原纤维和弹性纤维交织构成，并含有从表皮陷入的毛囊和腺体，以及来自深层的血管、淋巴管、神经及其末梢。

:::definition{label="真皮"}
表皮深面。胶原纤维 + 弹性纤维交织。含毛囊、腺体，以及血管、淋巴管、神经及其末梢。痛、温、触、压的一般感受器多落在这一层及其末梢。
:::

**3. 皮褶和分裂线**　皮褶（crease）是位于关节屈侧或伸侧皮肤的褶线，褶处的皮肤较薄，其真皮借结缔组织固着于深层结构。分裂线（line of cleavage）或 Lange 氏线是由胶原纤维束所形成的皮肤纹理，在真皮内按一定的张力方向平行排列。外科手术沿分裂线做皮肤切口，伤口愈合后瘢痕较小。

:::definition{label="皮褶"}
关节屈侧或伸侧的褶线。褶处皮肤较薄，真皮借结缔组织固着于深层。是「折出来的线」，不是胶原的张力方向。
:::

:::definition{label="分裂线"}
又称 Lange 氏线。真皮内胶原纤维束按张力方向平行排列形成的皮肤纹理。沿此线切开，愈合后瘢痕较小。
:::

:::compare{title="皮褶 vs 分裂线"}
| | 本版 | 手术意义 |
|--|------|----------|
| 皮褶 | 关节屈/伸侧的褶，真皮固着于深层 | 是体表标志，不是切口方向的金标准 |
| 分裂线（Lange 氏线） | 真皮胶原按张力方向平行 | **沿此切开瘢痕较小** |

把皮褶当分裂线，切口会横着切断胶原束。
:::

皮肤的功能包括：① 防止体内液体的丧失；② 防止体外物质（如病原微生物、化学物质等）侵入机体，是机体免疫系统的第一道防线；③ 排泄废物并调节体温，皮肤表面有汗腺的开口，排出汗液时可调节体温；④ 感受刺激，皮肤内含有多种感受器，如接受痛、温、触、压觉的感受器。

:::compare{title="皮肤四项功能（本版原句）"}
| 项 | 本版 |
|----|------|
| 保水 | 防止体内液体丧失 |
| 屏障 | 防止体外物质侵入，免疫系统第一道防线 |
| 排泄与体温 | 汗腺开口，排汗调节体温 |
| 感觉 | 痛、温、触、压等一般感受器 |

四项都要，缺「感觉」这一节就和感觉器对不上，缺「屏障」又只剩一张感受器图。
:::

:::keypoint{label="厚薄和皮嵴按部位记"}
- 最厚：手掌、足跖；无毛囊，有皮嵴，抗摩擦。
- 背侧、伸侧厚于腹侧、屈侧。
- 表皮无血管，营养从真皮来；肤色看基底层色素细胞多少。
:::

:::pitfall{label="沿分裂线切开，不是「顺着皮褶切开」"}
本版原句把瘢痕较小写在分裂线（Lange 氏线）上。皮褶是关节处真皮固着形成的褶，方向和胶原张力线并不总一致。手术切口先问张力线。
:::

:::insight{label="掌跖最厚又没毛囊，是为了摩擦而不是为了出汗"}
皮嵴把接触面变成防滑纹，毛囊在这里缺席。汗腺仍在，但「最厚」这一笔首先是抗摩擦，不要把掌跖写成「全身汗腺最密所以最厚」。
:::
