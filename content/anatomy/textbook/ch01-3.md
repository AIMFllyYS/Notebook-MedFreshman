# 第三节　骨骼肌

骨和骨连结是运动系统的被动部分，本节写**主动部分**：骨骼肌。先立总论——构造、形态、起止、配布、命名和辅助装置，再按头、颈、躯干、上肢、下肢把本版名单落到对照表，最后收到体表的肌性标志。肌名以本版为准，不把运动解剖学讲义的别名换进来。

:::concept{term="先问这是不是主动部分，再问外形四类和起止，最后才按部位背肌名"}
先问骨骼肌是不是运动系统的动力装置、是不是随意肌、一块肌算不算一个器官。再问外形是长、短、扁、轮匝中的哪一类，有没有二腹、多头或羽状。起止问的是定点/动点，辅助装置问筋膜、滑膜囊、腱鞘、籽骨。各论用对照表收肌名，不要把每一块肌都做成一张定义卡片。
:::

## 一、概述

肌（muscle）按组织结构和功能分为心肌、平滑肌和骨骼肌。心肌（cardiac muscle）构成心壁主体，平滑肌（smooth muscle）主要分布于内脏中空器官及血管壁，二者不直接受意志支配。骨骼肌（skeletal muscle）是运动系统的动力部分，也就是主动部分：多数附着于骨骼，主要存在于躯干和四肢，受意识控制，又称随意肌（voluntary muscle）。人体约有 600 多块骨骼肌，约占体重的 40%。每块骨骼肌都有位置、形态、结构和辅助装置，并有丰富的血管、淋巴管和神经，执行一定功能，所以每块肌都可视为一个器官。

:::definition{label="骨骼肌"}
运动系统的动力部分、主动部分。多数附着于骨骼，主要在躯干和四肢，受意识控制，又称随意肌。约 600 多块，约占体重 40%。每块肌都是一个器官。
:::

:::compare{title="三类肌各守哪一户"}
| | 骨骼肌 | 心肌 | 平滑肌 |
|--|--------|------|--------|
| 主要位置 | 躯干、四肢，附着于骨 | 心壁 | 内脏中空器官、血管壁 |
| 意志 | 随意 | 不直接受意志支配 | 不直接受意志支配 |
| 本节 | 写完 | 不写 | 不写 |

本节只写骨骼肌。心、内脏壁的肌留给循环和内脏学。
:::

:::pitfall{label="不要把「动力部分」听成可以离开骨和关节单独产生运动"}
没有骨就没有杠杆，没有骨连结就没有枢纽。骨骼肌跨过关节牵拉骨，运动才发生。写成「肌自己就能完成关节运动」，第一、第二节的户头会被第三节吞掉。
:::

### （一）骨骼肌的构造和形态

骨骼肌包括肌腹和肌腱两部分。肌腹（muscle belly）是肌性部分，主要由肌纤维（肌细胞）组成，因血供丰富且富含肌红蛋白而呈红色，有收缩能力。肌腱（muscle tendon）主要由平行致密的胶原纤维束构成，色白、强韧而无收缩功能，抗张强度约为肌腹的 100 多倍。肌多借肌腱附着于骨骼。

:::definition{label="肌腹"}
肌性部分，红色，能收缩。材料是肌纤维。
:::

:::definition{label="肌腱"}
腱性部分，白色，无收缩功能，抗张强度约为肌腹的 100 多倍。肌多借它附着于骨。
:::

肌的形态多样，外形大致分为长肌、短肌、扁肌和轮匝肌四种（图1-77）。另有二腹、多腹、多头和羽状等变形，都是在这四类上再分，不是第五类外形。

::figure{src="/images/anatomy/textbook/p0082_01.png" caption="图1-77　肌的各种形态" alt="上排为长肌、短肌、扁肌、轮匝肌、二腹肌、多腹肌；下排为二头肌、三头肌、半羽肌、羽肌、多羽肌"}

**长肌（long muscle）**　肌束与肌的长轴平行，收缩时显著缩短，可引起大幅度运动，多见于四肢。起端有 2 个以上的头、以后合成 1 个肌腹的，称二头肌、三头肌或四头肌。肌腹被中间腱分成两部分的，如肩胛舌骨肌、二腹肌；被腱划分成多个部分的，如腹直肌。肌束斜行排于腱的两侧或一侧，形如鸟羽或半侧鸟羽，称羽肌或半羽肌，如趾长屈肌、趾长伸肌；多个小的半羽肌或羽肌组成多羽肌，如三角肌。

**短肌（short muscle）**　外形小而短，节段性明显，收缩幅度较小，多见于躯干深层。

**扁肌（flat muscle）**　宽扁呈薄片状，除运动外还兼有保护内脏的作用，多见于胸腹壁。腱性部分呈薄膜状，称腱膜（aponeurosis）。

**轮匝肌（orbicular muscle）**　主要由环形肌纤维构成，位于孔裂周围，收缩时关闭孔裂，如眼轮匝肌、口轮匝肌。

:::compare{title="外形四类（图1-77 上排）"}
| 类 | 形态 | 收缩特点 | 常见部位 | 本版举例 |
|----|------|----------|----------|----------|
| 长肌 | 肌束平行于长轴 | 缩短幅度大 | 四肢 | 肱二头肌、缝匠肌 |
| 短肌 | 小而短，节段性明显 | 幅度小 | 躯干深层 | 椎骨间短肌 |
| 扁肌 | 宽扁薄片 | 运动兼保护 | 胸腹壁 | 腹外斜肌；腱性部为腱膜 |
| 轮匝肌 | 环形纤维 | 关闭孔裂 | 口、眼等孔裂 | 眼轮匝肌、口轮匝肌 |
:::

:::compare{title="长肌上的几种变形（图1-77 其余）"}
| 变形 | 本版怎么说 | 例子 |
|------|------------|------|
| 多头 | 起端 2 个以上的头合成 1 个肌腹 | 二头肌、三头肌、四头肌 |

| 半羽 / 羽 / 多羽 | 肌束斜排于腱的一侧、两侧，或多个小羽合成 | 趾长伸肌、趾长屈肌；三角肌 |

不要把二腹、多头、羽状另立成与长、短、扁、轮匝并列的第五类。
:::

:::definition{label="腱膜"}
扁肌的腱性部分，呈薄膜状。腹外斜肌腱膜、腹直肌鞘、白线、掌腱膜，都是这一户的落点。
:::

:::insight{label="肌腱不收缩，但抗张比肌腹高两个数量级"}
收缩发生在肌腹。肌腱把拉力传到骨，自己几乎不缩短。写成「整块肌都在收缩」，腱鞘炎、跟腱断裂和腱划就没有材料学依据。
:::

### （二）骨骼肌的起止、配布和功能

骨骼肌通常以两端附于两块或两块以上的骨，中间跨过一个或多个关节。肌收缩时，两骨彼此靠近或分离而产生运动：一块骨相对固定，另一块相对移动。肌在固定骨上的附着点称为**起点**或**定点**；在移动骨上的附着点称为**止点**或**动点**（图1-78）。通常把靠近身体正中面或四肢近侧端的附着点看作起点，反之为止点。定点和动点是相对的，在一定条件下可以互相转换。

::figure{src="/images/anatomy/textbook/p0082_02.png" caption="图1-78　肌的起、止点" alt="屈肘持球：近侧为起点，肌腹在中，远侧肌腱为止点"}

:::definition{label="起点（定点）"}
肌在固定骨上的附着点。习惯上靠近正中面或四肢近侧端。
:::

:::definition{label="止点（动点）"}
肌在移动骨上的附着点。习惯上远离正中面或位于四肢远侧端。
:::

:::pitfall{label="定点和动点可以换，不要把「近侧永远是起点」写成绝对"}
引体向上时，肱骨相对固定，胸大肌、背阔肌拉躯干向上，原来的止点变成定点。图1-78 画的是持球屈肘的常用方向，不是不可逆的标签。
:::

肌在关节周围的配布与关节运动轴的数量密切相关：一个运动轴的相对侧至少配布两组作用相反的肌或肌群，称为拮抗肌（antagonist）；位于同一运动轴同侧、作用相同的两块或多块肌，称为协同肌（synergist）。单轴关节通常配备两组肌，如肘关节前方屈肌组、后方伸肌组；双轴关节通常有四组，如桡腕关节的屈、伸、内收、外展；三轴关节配备六组，如肩关节在屈伸、收展之外还有旋内、旋外。这些肌在神经系统支配下彼此协调。一块肌若与两个以上关节的运动有关，即可产生两个以上动作，如股四头肌跨过髋关节和膝关节前方，既能屈髋，又能伸膝。

:::definition{label="拮抗肌"}
配布在同一运动轴相对侧、作用相反的肌或肌群。
:::

:::definition{label="协同肌"}
位于同一运动轴同侧、作用相同的两块或多块肌。
:::

:::compare{title="关节轴数与肌组数"}
| 关节类型 | 肌组 | 本版举例 |
|----------|------|----------|
| 单轴 | 2 组 | 肘：前方屈、后方伸 |
| 双轴 | 4 组 | 桡腕：屈、伸、内收、外展 |
| 三轴 | 6 组 | 肩：屈、伸、内收、外展、旋内、旋外 |
:::

:::insight{label="跨两个关节的肌，动作可以方向相反"}
股四头肌在髋是屈，在膝是伸。不要用「屈肌就只会屈」去套跨双关节肌。
:::

### （三）骨骼肌的命名

骨骼肌通常按位置、形态、大小、起止点、作用或肌束走行方向命名，也可综合命名。掌握命名原则有助于理解起止和作用，但考试仍以本版肌名为准。

:::compare{title="命名怎么读（本版举例）"}
| 依据 | 例子 |
|------|------|
| 位置 | 肋间内肌、肋间外肌 |
| 形态 | 斜方肌、三角肌 |
| 位置 + 形态 | 肱二头肌、小腿三头肌 |
| 位置 + 大小 | 胸大肌、臀大肌 |
| 起止点 | 胸锁乳突肌、肩胛舌骨肌 |
| 作用 | 旋后肌、拇收肌 |
| 位置 + 走行 | 腹外斜肌、腹横肌 |
:::

### （四）骨骼肌的辅助装置

骨骼肌周围有筋膜、滑膜囊、腱鞘和籽骨等辅助装置，用来保持肌的位置、保护和协助活动。本版名单就是这四件，不要自行补「滑车」当第五类辅助装置——滑车是腱鞘纤维层的功能，不是另立的一类。

**1. 筋膜（fascia）**　由结缔组织构成，分浅筋膜和深筋膜，被覆全身（图1-79）。

浅筋膜（superficial fascia）又称皮下筋膜、皮下组织或皮下脂肪，位于真皮之下，包被全身，由疏松结缔组织构成，富含脂肪。厚度因人而异，与遗传、性别、营养状况有关。内有浅动脉、浅静脉、皮神经及淋巴管，有些局部还有乳腺和皮肌。下腹部及会阴部浅筋膜分两层：浅层含脂肪较多，深层呈膜状，一般不含脂肪而含较多弹性组织。

深筋膜（deep fascia）又称固有筋膜，位于浅筋膜深面，包被体壁和四肢的肌、血管和神经，由致密结缔组织构成。可随肌的分层而分层。在四肢，深筋膜插入肌群之间并附着于骨，形成肌间隔，把功能、发育过程和神经支配不同的肌群分隔开；肌间隔与包被肌群的深筋膜构成筋膜鞘，保证肌群能单独活动。在腕部和踝部，深筋膜增厚形成支持带，约束其深面的肌腱。某些部位可供肌附着。深筋膜还包绕血管、神经形成血管神经鞘。病理情况下可潴留脓液、限制炎症扩散，临床上可根据其层次推测积液蔓延方向。

::figure{src="/images/anatomy/textbook/p0083_01.png" caption="图1-79　大腿中部水平切面（示筋膜）" alt="皮肤、浅筋膜、深筋膜；股内侧、股外侧、股后肌间隔包绕肌群，并见股动静脉、坐骨神经、大隐静脉"}

:::definition{label="浅筋膜"}
真皮之下的皮下筋膜，疏松结缔组织，富含脂肪，内走浅血管、皮神经和淋巴管。
:::

:::definition{label="深筋膜"}
浅筋膜深面的固有筋膜，致密结缔组织，包被肌、血管和神经。在四肢形成肌间隔和筋膜鞘，在腕踝增厚为支持带。
:::

:::definition{label="肌间隔与筋膜鞘"}
四肢深筋膜插入肌群之间并附着于骨，形成肌间隔；与包被肌群的深筋膜共同构成筋膜鞘，让不同神经支配的肌群分开活动。
:::

**2. 滑膜囊（synovial bursa）**　封闭的结缔组织囊，形扁、壁薄，内有滑液，多位于肌或肌腱与骨面相接触处，减少摩擦。关节附近的滑膜囊可与关节腔相通。滑膜囊炎症可影响局部运动。

**3. 腱鞘（tendinous sheath）**　包围在肌腱外面的鞘管，存在于肌腱活动较灵活的部位，如腕、踝、手指和足趾（图1-80）。分纤维层和滑膜层。纤维层又称腱纤维鞘，为深筋膜增厚形成的骨性纤维性管道，起滑车和约束作用。滑膜层又称腱滑膜鞘，是滑膜构成的双层圆筒：内层（脏层）包肌腱，外层（壁层）贴纤维层内面和骨面，两层移行形成腔隙，内含少量滑液。从骨面移行到肌腱的部分称腱系膜（mesotendon），供应肌腱的血管由此通过。手指长期、过度且快速活动可致腱鞘炎。

::figure{src="/images/anatomy/textbook/p0083_02.png" caption="图1-80　腱鞘示意图" alt="纵切与横切：腱纤维鞘、腱滑膜鞘脏层与壁层、滑膜腔、腱系膜、指屈肌腱"}

:::definition{label="腱鞘"}
肌腱外面的鞘管，分腱纤维鞘和腱滑膜鞘。滑膜鞘分脏、壁两层，移行部为腱系膜。
:::

:::pitfall{label="腱系膜不是「把肌腱吊起来的筋膜装饰」"}
它是滑膜从骨面走到肌腱的通路，血管走这里。写成可有可无的系带，肌腱血供这一笔会丢。
:::

**4. 籽骨（sesamoid bone）**　发生在某些肌腱内的扁圆形小骨。髌骨是人体最大的籽骨。运动中可减少肌腱与骨面的摩擦，并改变骨骼肌的牵引方向。

:::compare{title="辅助装置四件（本版名单）"}
| 装置 | 要点 |
|------|------|
| 筋膜 | 浅筋膜 + 深筋膜；深筋膜形成肌间隔、筋膜鞘、支持带、血管神经鞘 |
| 滑膜囊 | 封闭扁囊，减摩擦；近关节者可通关节腔 |
| 腱鞘 | 纤维层滑车约束，滑膜层润滑；腱系膜走血管 |
| 籽骨 | 肌腱内小骨；髌骨最大；减摩擦、改牵引方向 |
:::

### （一）面肌

面肌（facial muscle）为面部扁薄的皮肌，位置表浅，大多起自颅骨、止于面部皮肤，主要配布于口、眼、鼻等孔裂周围，分环形肌和辐射状肌，有闭合或开大孔裂的作用，同时牵动皮肤显示表情，故又称表情肌。面神经支配。

**1. 颅顶肌（epicranius）**　颅顶部阔而薄，左、右各一枕额肌（occipitofrontalis），由额腹、枕腹及中间的帽状腱膜（galea aponeurotica）构成。额腹止于眉部皮肤；枕腹起自枕骨，止于帽状腱膜。枕额肌与颅部皮肤、皮下组织紧密结合组成头皮，与骨膜之间隔以疏松结缔组织。枕腹向后牵拉帽状腱膜，额腹提眉并使额部出现皱纹。

**2. 眼轮匝肌（orbicularis oculi）**　位于眼裂周围，呈椭圆形，分眶部、睑部和泪囊部（图1-83）。睑部收缩可眨眼；与眶部共同收缩使眼裂闭合；泪囊部收缩扩大泪囊、产生负压，利于泪液引流。

::figure{src="/images/anatomy/textbook/p0085_01.png" caption="图1-82　头肌（侧面）" alt="额腹、枕腹、帽状腱膜、颞肌、咬肌、颊肌、口周肌及胸锁乳突肌上端"}

::figure{src="/images/anatomy/textbook/p0085_02.png" caption="图1-83　眼轮匝肌分部" alt="眶部、睑部和泪囊部，泪囊在内眦深面"}

**3. 口周围肌**　人类口周肌高度分化，包括环形的口轮匝肌（orbicularis oris）和上、下方的辐射状肌。口轮匝肌收缩闭口，并使上、下唇与牙贴紧。辐射状肌能上提上唇、降下唇或拉口角向上、向下或向外。其中较重要的是颊肌（buccinator）：起自面颊深层，止于口角，使唇、颊贴紧牙齿，帮助咀嚼和吸吮，并拉口角向外；与口轮匝肌共同作用可吹口哨。

**4. 鼻肌（nasalis）**　几块不发达的薄扁小肌，配布于鼻孔周围，开大或缩小鼻孔。

:::pitfall{label="面肌止于皮肤，不要写成止于下颌骨"}
止于皮肤才能牵出表情。止于骨的是咀嚼肌。把面肌听成「也是闭口肌」，三叉神经和面神经的分工会并户。
:::

### （二）咀嚼肌

咀嚼肌（masticatory muscle）本版只收四块：咬肌、颞肌、翼内肌、翼外肌，配布于颞下颌关节周围，由三叉神经支配。

**1. 咬肌（masseter）**　起自颧弓下缘和内面，斜向后下止于咬肌粗隆。收缩时上提下颌骨，同时向前牵引下颌骨。

**2. 颞肌（temporalis）**　起自颞窝，扇形向下汇聚，经颧弓深面止于冠突。上提下颌骨，并可向后牵拉下颌骨。

**3. 翼内肌（medial pterygoid）**　起自蝶骨翼突窝，止于下颌角内面的翼肌粗隆（图1-84）。上提下颌骨并使其向前。

**4. 翼外肌（lateral pterygoid）**　位于颞下窝，起自蝶骨大翼下面和翼突外侧面，向后外止于下颌颈。两侧同时收缩作张口运动；一侧收缩使下颌骨移向对侧。

::figure{src="/images/anatomy/textbook/p0086_01.png" caption="图1-84　翼内肌和翼外肌" alt="翼外肌止于下颌颈，翼内肌止于下颌角内面"}

:::compare{title="四块咀嚼肌：谁闭口、谁张口"}
| 肌 | 上提（闭口） | 其他 |
|----|--------------|------|
| 咬肌 | 是 | 向前牵引 |
| 颞肌 | 是 | 向后牵拉 |
| 翼内肌 | 是 | 向前 |
| 翼外肌 | **否** | 双侧张口；单侧下颌移向对侧 |

张口主要靠翼外肌，不要把四块都写成闭口肌。
:::

:::insight{label="面肌走面神经，咀嚼肌走三叉神经"}
孔裂开闭和表情是面神经；颞下颌关节的咀嚼是三叉神经。一侧面瘫眼裂闭不上，是面肌的事；咬紧牙摸不到咬肌隆起，是咀嚼肌的事。
:::

### （一）颈浅肌与颈外侧肌

**1. 颈阔肌（platysma）**　颈部浅筋膜内的皮肌，薄而宽阔。起自胸大肌和三角肌表面筋膜，向上内止于口角、下颌骨下缘及面下部皮肤（图1-85）。拉口角及下颌向下，并使颈部皮肤出现皱褶。

**2. 胸锁乳突肌（sternocleidomastoid）**　位于颈部两侧，大部分被颈阔肌覆盖。起自胸骨柄前面和锁骨胸骨端，二头会合斜向后上，止于乳突。一侧收缩使头向同侧倾斜、脸转向对侧；两侧同时收缩使头后仰。

::figure{src="/images/anatomy/textbook/p0087_01.png" caption="图1-85　颈浅肌与颈外侧肌（前面）" alt="右侧颈阔肌，左侧胸锁乳突肌"}

:::pitfall{label="胸锁乳突肌一侧收缩，脸转向对侧，不是转向同侧"}
头向同侧倾，脸转向对侧。写成「一侧收缩脸也转向同侧」，斜颈的方向会说反。
:::

### （二）颈前肌

颈前肌包括舌骨上肌群和舌骨下肌群。

**1. 舌骨上肌群**　位于舌骨与下颌骨、颅底之间，每侧 4 块，皆止于舌骨（图1-86～图1-88）。二腹肌（digastric）有前、后腹，中间腱借筋膜滑车系于舌骨。下颌舌骨肌（mylohyoid）是二腹肌前腹深面的三角形扁肌。茎突舌骨肌（stylohyoid）与二腹肌后腹伴行。颏舌骨肌（geniohyoid）在下颌舌骨肌深面。下颌骨固定时上提舌骨、帮助吞咽；舌骨固定时下拉下颌骨。

**2. 舌骨下肌群**　位于颈前部、舌骨下方正中线两旁，居喉、气管、甲状腺前方，每侧 4 块。浅层自外向内为肩胛舌骨肌、胸骨舌骨肌；深层自下而上为胸骨甲状肌、甲状舌骨肌。肩胛舌骨肌分上腹、下腹，中间腱在胸锁乳突肌下部深面。作用是下降舌骨和喉，利于吞咽。

::figure{src="/images/anatomy/textbook/p0088_01.png" caption="图1-86　颈肌（前面）" alt="二腹肌、下颌舌骨肌、茎突舌骨肌、肩胛舌骨肌上腹下腹、胸骨舌骨肌及斜角肌"}

::figure{src="/images/anatomy/textbook/p0088_02.png" caption="图1-87　颈肌（侧面）" alt="舌骨上、下肌群侧面观，可见甲状腺及前、中、后斜角肌"}

::figure{src="/images/anatomy/textbook/p0088_03.png" caption="图1-88　口底部肌（后面）" alt="下颌舌骨肌与颏舌骨肌止于舌骨"}

### （三）颈深肌

颈深肌分内、外侧两群。

**1. 外侧群**　脊柱颈段两侧的三块斜角肌：前斜角肌（scalenus anterior）、中斜角肌（scalenus medius）、后斜角肌（scalenus posterior）。均起自颈椎横突；前、中斜角肌止于第 1 肋，后斜角肌止于第 2 肋。前、中斜角肌与第 1 肋之间为斜角肌间隙（scalene fissure），有锁骨下动脉和臂丛通过（图1-89）。胸廓固定时，一侧收缩使颈向同侧屈，两侧同时收缩使颈前屈；颈部固定时，双侧收缩上提第 1、2 肋助吸气。

**2. 内侧群**　脊柱颈段前面、正中线两侧，每侧 4 块：头长肌、颈长肌、头前直肌、头外侧直肌（图1-89）。头前直肌使头前屈和转头，头外侧直肌使头侧屈；一侧头长肌和颈长肌使颈向同侧屈，两侧同时收缩使颈前屈。

::figure{src="/images/anatomy/textbook/p0089_01.png" caption="图1-89　颈深肌群" alt="头长肌、颈长肌、头前直肌、头外侧直肌及前中后斜角肌；斜角肌间隙内有臂丛和锁骨下动脉"}

:::definition{label="斜角肌间隙"}
前、中斜角肌与第 1 肋之间的间隙，通过锁骨下动脉和臂丛。后斜角肌不参与围成此间隙。
:::

:::pitfall{label="斜角肌间隙走锁骨下动脉和臂丛，不是锁骨下静脉"}
图1-89 上静脉在间隙前方。写成「锁骨下动静脉都从间隙走」，静脉的毗邻会说错。
:::

## 四、躯干肌

躯干肌分背肌、胸肌、膈肌、腹肌和会阴肌。会阴肌（包括盆肌）在「会阴」部分叙述，本节不写。

### （一）背肌

背肌分背浅肌和背深肌（表1-5）。浅肌分两层，均起自脊柱不同部位，止于上肢带骨或肱骨：浅层斜方肌、背阔肌，深面肩胛提肌和菱形肌（图1-90）。

:::compare{title="表1-5　背肌的起止点、主要作用和神经支配"}
| 肌群 | 肌名 | 起点 | 止点 | 主要作用 | 神经 |
|------|------|------|------|----------|------|
| 浅 | 斜方肌 | 上项线、枕外隆凸、项韧带、C7 及全部胸椎棘突 | 锁骨外侧 1/3、肩峰、肩胛冈 | 拉肩胛骨向脊柱；上部上提、下部下拉肩胛骨；肩胛骨固定时作用同胸锁乳突肌 | 副神经 |
| | 背阔肌 | 下 6 胸椎棘突、全部腰椎棘突、骶正中嵴、髂嵴后部及下 3 肋外面 | 肱骨小结节嵴 | 肩关节后伸、内收及旋内 | 胸背神经 |
| | 肩胛提肌 | 上 4 颈椎横突 | 肩胛骨上角和内侧缘上部 | 上提肩胛骨 | 肩胛背神经 |

| | 夹肌 | 项韧带下半、下位颈椎及上位胸椎棘突和棘上韧带 | 上 2～3 颈椎横突、乳突和上项线 | 一侧转头向同侧；两侧后仰 | 颈神经后支 |

::figure{src="/images/anatomy/textbook/p0090_01.png" caption="图1-90　背肌" alt="浅层斜方肌、背阔肌；深层肩胛提肌、菱形肌、竖脊肌、夹肌；图上可见听诊三角和腰下三角"}

**斜方肌（trapezius）**　项部和背上部浅层的三角形扁肌，左右合呈斜方形。上部纤维斜向外下，中部平行向外，下部斜向外上。瘫痪时产生「塌肩」。肩胛骨固定时，一侧收缩使颈向同侧屈、脸转向对侧，两侧同时收缩使头后仰。

**背阔肌（latissimus dorsi）**　全身最大的扁肌，位于背下部及胸后外侧壁。上肢上举固定时可协助引体向上。

**肩胛提肌（levator scapulae）**　项部两侧、斜方肌深面。肩胛骨固定时可使颈向同侧屈。

**菱形肌（rhomboideus）**　斜方肌深面的菱形扁肌。

背深肌在脊柱两侧排列，长肌较浅，主要有竖脊肌和夹肌；短肌位于深部。竖脊肌（erector spinae）是最粗的背肌，纤维向外上分为髂肋肌、最长肌和棘肌三组（由外向内），对维持人体直立起重要作用。夹肌（splenius）分头夹肌和颈夹肌，位于上后锯肌深面。

**背部筋膜**　斜方肌和背阔肌表面的深筋膜较薄弱。被覆背部深层肌的深筋膜较发达，称胸腰筋膜（thoracolumbar fascia）。腰部明显增厚，分浅、中、深三层，包裹竖脊肌和腰方肌（图1-91）：浅层在竖脊肌后面；中层分隔竖脊肌与腰方肌，浅、中两层在竖脊肌外侧缘愈合构成竖脊肌鞘；深层覆盖腰方肌前面。三层于腰方肌外侧缘会合，成为腹内斜肌和腹横肌的起点。胸腰筋膜在腰部剧烈运动中常可扭伤，为腰背劳损病因之一。

::figure{src="/images/anatomy/textbook/p0091_01.png" caption="图1-91　胸腰筋膜" alt="腰部横切：胸腰筋膜浅、中、深层包裹竖脊肌和腰方肌，外侧续腹内斜肌和腹横肌"}

:::definition{label="胸腰筋膜"}
背部深层肌表面发达的深筋膜。腰部分浅、中、深三层，包裹竖脊肌和腰方肌；三层在腰方肌外侧缘会合，成为腹内斜肌和腹横肌的起点。
:::

:::pitfall{label="斜方肌瘫痪是塌肩，前锯肌瘫痪才是翼状肩"}
两块肌都管肩胛骨贴胸廓，但方向不同。塌肩是斜方肌，翼状肩是前锯肌，不要对调。
:::

### （二）胸肌

胸肌均为扁肌，按附着骨分为胸上肢肌和胸固有肌（表1-6）。胸上肢肌起自胸壁，止于上肢带骨或肱骨；胸固有肌参与构成胸壁，在肋间隙内。

:::compare{title="表1-6　胸肌与膈肌的起止点、主要作用和神经支配"}

|------|------|------|------|----------|------|
| 胸上肢肌 | 胸大肌 | 锁骨内侧 2/3、胸骨前面、第 1～6 肋软骨前面等 | 肱骨大结节嵴 | 肩关节内收、旋内和前屈 | 胸内、外侧神经 |
| | 胸小肌 | 第 3～5 肋骨 | 喙突 | 拉肩胛骨向前下方 | 胸内、外侧神经 |
| | 前锯肌 | 上位 8 或 9 肋外面 | 肩胛骨内侧缘和下角 | 拉肩胛骨向前并紧贴胸廓 | 胸长神经 |
| 胸固有肌 | 肋间外肌 | 上位肋骨下缘 | 下位肋骨上缘 | 提肋助吸气 | 肋间神经 |
| | 肋间内肌 | 下位肋骨上缘 | 上位肋骨下缘 | 降肋助呼气 | 肋间神经 |
| | 肋间最内肌 | 同肋间内肌 | 同肋间内肌 | 降肋助呼气 | 肋间神经 |

| 膈肌 | 胸骨部 | 剑突后面 | 中心腱 | 助呼吸、增加腹压 | 膈神经 |
| | 肋部 | 下 6 对肋 | 中心腱 | 同上 | 膈神经 |

**1. 胸上肢肌**

胸大肌（pectoralis major）位于胸廓前上部浅层，扇形，分锁骨部、胸肋部和腹部，以扁腱止于肱骨大结节嵴（图1-92）。上肢固定时可牵引躯体向上，与背阔肌一起完成引体向上，也可提肋助吸气。

胸小肌（pectoralis minor）在胸大肌深面，呈三角形，止于喙突。肩胛骨固定时可上提第 3～5 肋助吸气。

前锯肌（serratus anterior）位于胸廓侧壁，以肌齿起自上位 8～9 肋外面，向后经肩胛下肌前方止于肩胛骨内侧缘和下角（图1-93）。下部肌束使肩胛骨下角旋外，助外展的臂举高；肩胛骨固定时可上提肋骨助深吸气。瘫痪时肩胛骨内侧缘与下角离开胸廓突出于皮下，称「翼状肩」。

::figure{src="/images/anatomy/textbook/p0092_01.png" caption="图1-92　胸肌" alt="左侧胸大肌分锁骨部与胸肋部；右侧胸小肌、前锯肌及喙肱肌、大圆肌"}

::figure{src="/images/anatomy/textbook/p0092_02.png" caption="图1-93　前锯肌" alt="前锯肌止于肩胛骨内侧缘；肋间隙可见肋间外肌和肋间内肌"}

**2. 胸固有肌**

肋间外肌（intercostales externi）共 11 对，在肋间隙浅层，肌束斜向前下。前部仅达肋骨与肋软骨结合处，在肋软骨间隙移行为肋间外膜（external intercostal membrane）。提肋、扩大胸廓，助吸气。

肋间内肌（intercostales interni）在肋间外肌深面，肌束斜向前上，与外肌交叉。后部仅达肋角，向后移行为肋间内膜（internal intercostal membrane）。降肋助呼气。

肋间最内肌（intercostales intimi）位于肋间隙中份、肋间内肌深面，方向和作用与肋间内肌相同。

胸横肌（transversus thoracis）位于胸前壁内面，降肋助呼气。

**3. 胸部筋膜**　浅筋膜含脂肪，内有乳腺。深筋膜分浅、深二层：浅层覆盖胸大肌，称胸肌筋膜（pectoral fascia）；深层包裹锁骨下肌和胸小肌，在喙突、锁骨下肌与胸小肌上缘之间增厚为锁胸筋膜（clavipectoral fascia），有血管神经穿过。胸壁内面和膈上面衬胸内筋膜。

:::compare{title="肋间外肌 vs 肋间内肌"}
| | 肋间外肌 | 肋间内肌 |
|--|----------|----------|
| 层次 | 浅 | 深 |
| 肌束 | 斜向前下 | 斜向前上 |
| 膜性延续 | 前方 → 肋间外膜 | 后方 → 肋间内膜 |
| 作用 | 提肋助吸气 | 降肋助呼气 |
:::

### （三）膈肌

膈肌（diaphragm）位于胸、腹腔之间，为穹窿状扁肌，封闭胸廓下口。周边是肌性部，中央为腱膜，称中心腱（central tendon）。肌性部分三部：胸骨部起自剑突后面；肋部起自下 6 对肋；腰部以左、右两个膈脚起自上位 2～3 个腰椎以及内、外侧弓状韧带。各部肌束均止于中心腱（图1-94、图1-95）。

膈肌上有三个裂孔。主动脉裂孔（aortic hiatus）位于第 12 胸椎前方，左、右膈脚与脊柱之间，有主动脉和胸导管通过。食管裂孔（esophageal hiatus）位于主动脉裂孔左前上方，约平第 10 胸椎，有食管和迷走神经通过。腔静脉孔（vena caval foramen）位于食管裂孔右前上方的中心腱内，约平第 8 胸椎，有下腔静脉通过。

三个起始部之间常留三角形小间隙，无肌纤维，仅覆盖结缔组织，为薄弱区。胸骨部与肋部之间为胸肋三角（sternocostal triangle），有腹壁上血管和来自腹壁及肝上面的淋巴管通过。腰部与肋部之间为腰肋三角（lumbocostal triangle）。腹部脏器经上述三角区突入胸腔则形成膈疝，最常见的是食管裂孔疝。

膈肌是主要的呼吸肌：收缩时穹窿下降，胸腔容积扩大，助吸气；松弛时穹窿上升，胸腔容积减小，助呼气。与腹肌同时收缩则增加腹压，协助排便、呕吐、咳嗽、打喷嚏及分娩。

::figure{src="/images/anatomy/textbook/p0093_01.png" caption="图1-94　膈肌与腹后壁肌" alt="中心腱、腔静脉孔、食管裂孔、主动脉裂孔、膈脚、弓状韧带及腰方肌、腰大肌、髂肌"}

::figure{src="/images/anatomy/textbook/p0094_01.png" caption="图1-95　膈肌的位置" alt="侧胸位：三个裂孔的相对高度，中心腱与膈脚"}

膈肌中央的腱膜。腔静脉孔就开在中心腱内，不在肌性部。
:::

:::compare{title="膈的三个裂孔（本版）"}
| 裂孔 | 约平椎体 | 位置 | 通过结构 |
|------|----------|------|----------|
| 主动脉裂孔 | T12 | 膈脚与脊柱之间 | 主动脉、胸导管 |
| 食管裂孔 | T10 | 主动脉裂孔左前上方 | 食管、迷走神经 |

:::

:::

### （四）腹肌

腹肌位于胸廓与骨盆之间，分前外侧群和后群（表1-7）。前外侧群构成腹腔前外侧壁：腹外斜肌、腹内斜肌、腹横肌和腹直肌。后群有腰方肌；腰大肌放到下肢肌。

:::compare{title="表1-7　腹肌的起止点、主要作用和神经支配"}
| 肌群 | 肌名 | 起点 | 止点 | 主要作用 | 神经 |
|------|------|------|------|----------|------|
| 前外侧 | 腹外斜肌 | 下 8 对肋外面 | 髂嵴前部、腹股沟韧带、白线 | 保护脏器、维持腹压；增加腹压；脊柱前屈、侧屈及旋转；降肋助呼气 | 第 5～11 肋间神经、肋下神经、髂腹下神经、髂腹股沟神经 |
| | 腹内斜肌 | 胸腰筋膜、髂嵴、腹股沟韧带外侧 1/2 | 白线 | 同上 | 同上 |
| | 腹横肌 | 下 6 对肋软骨内面、胸腰筋膜、髂嵴、腹股沟韧带外侧 1/3 | 白线 | 同上 | 同上 |
| | 腹直肌 | 耻骨联合、耻骨嵴 | 剑突、第 5～7 肋软骨前面 | 同上 | 第 5～11 肋间神经、肋下神经 |
| 后群 | 腰方肌 | 髂嵴后份 | 第 12 肋、L1～4 横突 | 降第 12 肋；脊柱侧屈 | 腰神经前支 |
:::

**1. 前外侧群**

腹外斜肌（obliquus externus abdominis）为腹前外侧部浅层的宽阔扁肌（图1-96）。以 8 对肌齿起自下 8 对肋外面，与背阔肌及下部前锯肌的肌齿交错，肌束由外上斜向前下。后部止于髂嵴前部；其余在腹直肌外侧缘、髂前上棘与脐连线以下移行为腱膜，经腹直肌前面参与腹直肌鞘前层，止于白线。腱膜下缘卷曲增厚，连于髂前上棘与耻骨结节之间，形成腹股沟韧带（inguinal ligament）。其内侧端一小部分由耻骨结节向下后外转折附于耻骨梳，形成腔隙韧带（lacunar ligament，陷窝韧带）；延伸并附于耻骨梳的部分称耻骨梳韧带（pectineal ligament）。腹外斜肌腱膜在耻骨结节外上方形成三角形裂孔，即腹股沟管浅环（superficial inguinal ring，皮下环）。

腹内斜肌（obliquus internus abdominis）在腹外斜肌深面（图1-96、图1-97）。起自胸腰筋膜、髂嵴和腹股沟韧带外侧 1/2，呈扇形斜向内上。后部几乎垂直向上止于下 3 对肋；其余移行为腱膜：上 2/3 在腹直肌外侧缘分前、后两层包裹腹直肌，下 1/3 全部行于腹直肌前面。下部起自腹股沟韧带的肌束呈弓形向前下，越过精索或子宫圆韧带后与腹横肌相应腱膜结合，形成腹股沟镰（inguinal falx，联合腱），止于耻骨梳内侧端及耻骨结节附近。最下部细散肌束与腹横肌最下部一起包绕精索和睾丸，称为提睾肌（cremaster）。

腹横肌（transversus abdominis）是腹前外侧壁最深层的扁肌。肌束自后横行向前内移行为腱膜，上 2/3 行于腹直肌后面、下 1/3 行于前面。最下部参与提睾肌和腹股沟镰。

腹直肌（rectus abdominis）位于前正中线两侧，居腹直肌鞘中，上宽下窄。全长被 3～4 条腱划（tendinous intersection）分成多个肌腹。腱划与鞘前层紧密结合；后面腱划不明显，不与鞘后层愈合，故腹直肌后面是游离的。

前外侧群共同作用：保护腹腔脏器，维持腹内压；收缩时增加腹压，协助排便、呕吐、咳嗽及分娩；使脊柱前屈、侧屈和旋转；降肋助呼气。

::figure{src="/images/anatomy/textbook/p0095_02.png" caption="图1-96　腹前外侧壁肌" alt="腹外斜肌、腱膜、白线、腹直肌及腱划、腹直肌鞘前层后层、弓状线、腹股沟韧带"}

::figure{src="/images/anatomy/textbook/p0095_01.png" caption="图1-97　腹前外侧壁肌（下部）" alt="腹外斜肌腱膜、腹内斜肌、腹横肌、提睾肌、精索、腹股沟镰、腹股沟管浅环"}

**2. 后群**　腰方肌（quadratus lumborum）呈长方形，位于腹后壁、腰大肌外侧（见图1-94）。下降第 12 肋并使脊柱侧屈。

**3. 腹直肌鞘（sheath of rectus abdominis）**　由腹外侧壁三块扁肌的腱膜构成，包绕腹直肌，分前、后两层（图1-98）。鞘的上 2/3：前层 = 腹外斜肌腱膜 + 腹内斜肌腱膜前层；后层 = 腹内斜肌腱膜后层 + 腹横肌腱膜。鞘的下 1/3：三块扁肌腱膜全部行于腹直肌前面构成前层，后层下部缺如。后层下端游离，约在脐下 4～5 cm 形成凸向上的弧形下缘，称弓状线（arcuate line，半环线）。此线以下腹直肌后面与腹横筋膜相贴。

::figure{src="/images/anatomy/textbook/p0096_01.png" caption="图1-98　腹直肌鞘" alt="弓状线以上后层完整；弓状线以下后层缺如，腹直肌后面贴腹横筋膜"}

:::definition{label="腹直肌鞘"}
腹外侧壁三块扁肌腱膜构成的鞘，包绕腹直肌。上 2/3 有前、后层；下 1/3 后层缺如，以下腹直肌贴腹横筋膜。
:::

:::definition{label="弓状线"}
腹直肌鞘后层下端游离的凸向上缘，约在脐下 4～5 cm。又称半环线。
:::

:::compare{title="腹直肌鞘前、后层（本版）"}
| | 上 2/3 | 下 1/3（弓状线以下） |
|--|--------|----------------------|
| 前层 | 腹外斜肌腱膜 + 腹内斜肌腱膜前层 | 三块扁肌腱膜全部 |
| 后层 | 腹内斜肌腱膜后层 + 腹横肌腱膜 | **缺如**，腹直肌贴腹横筋膜 |
:::

**4. 白线（linea alba）**　腹前壁正中线上，两侧腹直肌鞘纤维交织形成的腱性结构，上起剑突、下止耻骨联合。上宽下窄，坚韧而缺少血管。约在中点处有疏松瘢痕组织区即脐环（umbilical ring），是腹壁薄弱点，脏器经此膨出为脐疝。

**5. 腹股沟管（inguinal canal）**　腹前外侧壁三层扁肌和腱膜之间的裂隙，位于腹股沟韧带内侧半上方，由外上斜向内下，长约 4～5 cm，有男性精索或女性子宫圆韧带通过。有两口四壁：内口为腹股沟管深环（deep inguinal ring），在腹股沟韧带中点上方约 1.5 cm，是腹横筋膜向外突的卵圆形孔；外口即浅环。前壁为腹外斜肌腱膜和腹内斜肌；后壁为腹横筋膜和腹股沟镰；上壁为腹内斜肌和腹横肌的弓状下缘；下壁为腹股沟韧带。

**6. 腹股沟（海氏）三角（inguinal / Hesselbach triangle）**　由腹直肌外侧缘、腹股沟韧带和腹壁下动脉围成。腹腔内容物经深环入管再经浅环下降入阴囊，为腹股沟斜疝；不经深环而从海氏三角膨出，为腹股沟直疝。

:::compare{title="腹股沟管两口四壁"}
| | 结构 |
|--|------|
| 深环 | 腹股沟韧带中点上方约 1.5 cm，腹横筋膜 |
| 浅环 | 耻骨结节外上方，腹外斜肌腱膜 |
| 前壁 | 腹外斜肌腱膜 + 腹内斜肌 |
| 后壁 | 腹横筋膜 + 腹股沟镰 |
| 上壁 | 腹内斜肌和腹横肌弓状下缘 |
| 下壁 | 腹股沟韧带 |
| 内容 | 精索或子宫圆韧带 |
:::

:::compare{title="斜疝 vs 直疝"}
| | 斜疝 | 直疝 |
|--|------|------|
| 出路 | 深环 → 腹股沟管 → 浅环（可入阴囊） | 海氏三角膨出 |
| 与腹壁下动脉 | 从动脉外侧的深环进 | 从动脉内侧的三角出 |
:::

**7. 腹部筋膜**　浅筋膜在腹上部为一层；脐平面以下分浅、深两层：浅层含大量脂肪，称 Camper 筋膜；深层为膜性层，富含弹性纤维，称 Scarpa 筋膜，中线附于白线，向下与股部阔筋膜愈着。深筋膜覆盖前外侧群各肌。腹内筋膜贴腹腔各壁内面，其中腹横筋膜（transverse fascia）衬于腹横肌、腹直肌鞘后层和腹直肌（弓状线以下）的深面。

:::keypoint{label="经腹前外侧壁入腹膜腔的层次"}
皮肤 → 浅筋膜（脐下为 Camper + Scarpa）→ 腹外斜肌（腱膜）→ 腹内斜肌 → 腹横肌 → 腹横筋膜 → 腹膜外组织 → 壁腹膜。正中线附近还要加上白线 / 腹直肌鞘。这是层次账，不是手术步骤说明书。
:::

## 五、上肢肌

上肢肌分上肢带肌、臂肌、前臂肌和手肌。

### （一）上肢带肌

上肢带肌配布于肩关节周围，起自上肢带骨、止于肱骨，运动肩关节并增强稳固性（表1-8，图1-99、图1-100）。

:::compare{title="表1-8　上肢带肌的起止点、主要作用和神经支配"}
| 层次 | 肌名 | 起点 | 止点 | 主要作用 | 神经 |
|------|------|------|------|----------|------|
| 浅 | 三角肌 | 锁骨外侧 1/3、肩峰、肩胛冈 | 三角肌粗隆 | 肩关节外展；前部屈和旋内，后部伸和旋外 | 腋神经 |
| 深 | 冈上肌 | 冈上窝 | 肱骨大结节上部 | 肩关节外展 | 肩胛上神经 |
| | 冈下肌 | 冈下窝 | 肱骨大结节中部 | 肩关节旋外 | 肩胛上神经 |
| | 小圆肌 | 肩胛骨外侧缘上 2/3 背面 | 肱骨大结节下部 | 肩关节旋外 | 腋神经 |
| | 大圆肌 | 肩胛骨下角背面 | 肱骨小结节嵴 | 肩关节后伸、内收、旋内 | 肩胛下神经 |
| | 肩胛下肌 | 肩胛下窝 | 肱骨小结节 | 肩关节内收、旋内 | 肩胛下神经 |

三角肌（deltoid）包绕肩关节除下内侧外的各个面，形成肩部圆隆外形。瘫痪萎缩时肩峰突出，肩部呈方形。起点恰与斜方肌止点相对应。冈上肌腱经肩峰和喙肩韧带下方，与关节囊融合。肩胛下肌、冈上肌、冈下肌和小圆肌的肌腱在经过关节囊前、上、后面时与囊紧贴，并有腱纤维编入囊内，形成肌腱袖（muscle tendinous cuff），对肩关节稳定起重要作用。大圆肌不参加肌腱袖。

:::definition{label="肌腱袖"}
肩胛下肌、冈上肌、冈下肌、小圆肌的肌腱与肩关节囊愈合并编入囊内，稳定肩关节。大圆肌不在此名单。
:::

:::pitfall{label="方肩是三角肌，塌肩是斜方肌，翼状肩是前锯肌"}
三块肌瘫痪的外形不要串：三角肌 → 方肩；斜方肌 → 塌肩；前锯肌 → 翼状肩。
:::

### （二）臂肌

臂肌覆盖肱骨，前群为屈肌，后群为伸肌（图1-99、图1-100，表1-9）。

|----|------|------|------|----------|------|
| 前 | 肱二头肌 | 长头：盂上结节；短头：喙突 | 桡骨粗隆 | 屈肘、前臂旋后；协助屈肩 | 肌皮神经 |
| | 喙肱肌 | 喙突 | 肱骨中部内侧 | 肩关节屈和内收 | 肌皮神经 |
| | 肱肌 | 肱骨体下半前面 | 尺骨粗隆 | 屈肘 | 肌皮神经 |
| 后 | 肱三头肌 | 长头：盂下结节；外侧头：桡神经沟外上方；内侧头：桡神经沟内下方 | 尺骨鹰嘴 | 伸肘；长头协助肩关节伸及内收 | 桡神经 |
:::

::figure{src="/images/anatomy/textbook/p0098_02.png" caption="图1-100　上肢带肌与臂肌后群" alt="冈上肌、冈下肌、小圆肌、大圆肌、肱三头肌三头；三边孔与四边孔"}

肱二头肌（biceps brachii）长头以长腱起自盂上结节，通过肩关节囊，经结节间沟下降，包以结节间腱鞘；短头与喙肱肌共同起自喙突。止腱分出腱膜编入前臂深筋膜。前臂处于旋前位时，此肌能使其旋后。肱肌（brachialis）是单纯的屈肘肌。肱三头肌（triceps brachii）长头行经大、小圆肌之间。

:::insight{label="前群肌皮神经，后群桡神经"}
臂部屈伸的神经分界就这一刀。不要把肱三头肌写成肌皮神经，也不要把肱肌写成桡神经。
:::

### （三）前臂肌

前臂肌多数是长肌，近侧肌腹、远侧细腱，分前（屈肌）、后（伸肌）两群，主要运动肘、腕和手关节（表1-10）。

**1. 前群**　共 9 块，分四层（图1-101、图1-102）。第一层 5 块，自桡侧向尺侧：肱桡肌、旋前圆肌、桡侧腕屈肌、掌长肌、尺侧腕屈肌。肱桡肌起自肱骨外上髁上方，止于桡骨茎突，由桡神经支配；其余四肌以屈肌总腱起自肱骨内上髁及前臂深筋膜。第二层仅指浅屈肌，4 条腱经腕管入手掌，在近节指骨中部分两脚止于第 2～5 指中节指骨体两侧。第三层为拇长屈肌（外侧）和指深屈肌（内侧），腱经腕管；指深屈肌腱穿指浅屈肌两脚之间止于远节指骨底。第四层为旋前方肌。

**2. 后群**　共 10 块，分浅、深两层（图1-103、图1-104）。浅层 5 块以伸肌总腱起自肱骨外上髁及邻近深筋膜，自桡侧向尺侧：桡侧腕长伸肌、桡侧腕短伸肌、指伸肌、小指伸肌、尺侧腕伸肌。深层 5 块从上外向下内：旋后肌、拇长展肌、拇短伸肌、拇长伸肌、示指伸肌。后四肌起自桡、尺骨和骨间膜背面，作用与名称一致。

### （四）手肌

手肌位于掌侧，分外侧、中间、内侧三群（表1-11），运动手指。外侧群在拇指侧形成鱼际（thenar），4 块，分浅、深两层：拇短展肌、拇短屈肌、拇对掌肌、拇收肌。内侧群形成小鱼际（hypothenar），3 块：小指展肌、小指短屈肌、小指对掌肌。中间群包括蚓状肌和骨间肌（图1-105～图1-107）。手固有肌完成精细动作，前臂长肌完成用力运动。

## 六、下肢肌

下肢肌分髋肌、大腿肌、小腿肌和足肌。下肢主要维持直立、支持体重和行走，故比上肢肌粗壮。

### （一）髋肌

髋肌又称盆带肌，起自骨盆内、外面，跨过髋关节止于股骨上部。分前、后两群（表1-12）。前群 2 块（图1-108）：髂腰肌（iliopsoas）由腰大肌和髂肌组成，经腹股沟韧带深面止于股骨小转子，使髋关节前屈和旋外；下肢固定时可使躯干前屈（如仰卧起坐）。阔筋膜张肌（tensor fasciae latae）起自髂前上棘，移行于髂胫束，止于胫骨外侧髁。后群又称臀肌，本版表列 7 块（图1-109～图1-112）。臀大肌（gluteus maximus）大而肥厚，使髋关节伸和旋外；下肢固定时能伸直躯干、防止前倾。臀中肌和臀小肌止于大转子，外展髋关节，前部肌束旋内、后部旋外。梨状肌出坐骨大孔。闭孔内肌出坐骨小孔后与上、下孖肌融合止于转子窝。后六肌皆经髋关节囊后面，均可使髋关节旋外，作用类似于上肢肌腱袖，是髋关节的固定肌。

### （二）大腿肌

大腿肌分前群、内侧群和后群（表1-13）。

前群 2 块（见图1-108）。缝匠肌（sartorius）是全身最长的肌，扁带状，起自髂前上棘，止于胫骨上端内侧面，屈髋、屈膝并使已屈的膝关节旋内。股四头肌（quadriceps femoris）是全身最大的肌，四个头为股直肌、股内侧肌、股外侧肌和股中间肌；四个头构成髌腱，包绕髌骨续为髌韧带，止于胫骨粗隆。作用是屈髋（股直肌跨髋）和伸膝。

内侧群 5 块，分层排列（图1-108、图1-113）：耻骨肌、长收肌、股薄肌、短收肌、大收肌。除股薄肌止于胫骨上端内侧面外，其余止于股骨粗线等；大收肌另有一腱止于收肌结节。该腱与股骨之间形成收肌腱裂孔（adductor tendinous opening），为收肌管下口，通腘窝，有股血管通过。内侧群使髋关节内收和旋外。

后群 3 块，均起自坐骨结节（股二头肌短头起自股骨粗线），跨过髋、膝关节后面（见图1-109）。股二头肌止于腓骨头；半腱肌止于胫骨上端内侧，肌腱细长，适合作转移肌瓣；半膜肌上部几乎占一半为腱膜，止于胫骨内侧髁后面。后群屈膝、伸髋；屈膝时股二头肌使膝旋外，半腱肌和半膜肌使膝旋内。

### （三）小腿肌

小腿肌分前群、外侧群和后群（表1-14）。

前群 3 块（图1-114）：胫骨前肌止于内侧楔骨内侧面和第 1 跖骨底，伸踝（背屈）并使足内翻；趾长伸肌分为 4 腱到第 2～5 趾；拇长伸肌位于二者之间，止于拇趾远节趾骨底背面。三肌均经伸肌上、下支持带深面，由腓深神经支配。

外侧群 2 块：腓骨长肌（peroneus longus）和腓骨短肌（peroneus brevis），起自腓骨外侧面，腱经外踝后方转向前。短肌腱止于第 5 跖骨粗隆；长肌腱绕至足底，止于内侧楔骨和第 1 跖骨底。屈踝（跖屈）并使足外翻，腓浅神经支配。

后群分浅、深两层（图1-115）。浅层为小腿三头肌（triceps surae）：浅层腓肠肌（gastrocnemius）内、外侧头起自股骨内、外上髁后面，深层比目鱼肌（soleus）起自腓骨后面上部和胫骨比目鱼肌线，两肌腱合成跟腱（tendo calcaneus）止于跟骨。收缩时屈踝和屈膝；站立时固定两关节，防止身体前倾。深层 4 块：腘肌屈膝并使小腿旋内；趾长屈肌、胫骨后肌、拇长屈肌经内踝后方至足底。后群由胫神经支配。

### （四）足肌

## 七、体表的肌性标志

肌性标志是把前面各肌落到活体上的最后一笔。骨性标志在第一节，肌性标志在本节，不要并户。

### （一）头颈部

1. **咬肌**　牙咬紧时，在下颌角前上方、颧弓下方可摸到坚硬的条状隆起。
2. **颞肌**　牙咬紧时，在颞窝、颧弓上方可摸到坚硬的隆起。
3. **胸锁乳突肌**　头向一侧转动时，对侧可见从前下方斜向后上方的长条状隆起。

### （二）躯干部

1. **斜方肌**　项部和背上部可见其外上缘轮廓。
2. **背阔肌**　背下部可见其轮廓，外下缘参与形成腋后壁。
3. **竖脊肌**　脊柱两旁的纵行肌性隆起。
4. **胸大肌**　胸前壁较膨隆的肌性隆起，下缘构成腋前壁。
5. **前锯肌**　胸部外侧壁，发达者可见肌齿。
6. **腹直肌**　腹前正中线两侧的纵行隆起；肌肉发达者脐以上可见 3 条横沟，即腱划。

### （三）上肢

1. **三角肌**　肩部圆隆外形，止点在臂外侧中部呈现一小凹。
2. **肱二头肌**　屈肘握拳旋后时，臂前面可见膨隆肌腹；肘窝中央可摸到肌腱。
3. **肱三头肌**　臂后面、三角肌后缘下方可见长头。
4. **肱桡肌**　握拳用力屈肘时，肘部可见膨隆肌腹。
5. **鼻烟窝**　腕背侧面，拇指伸直外展时，自桡侧向尺侧可见拇长展肌、拇短伸肌和拇长伸肌腱；后二肌腱之间的深凹陷即鼻烟窝。

### （四）下肢

1. **股四头肌**　大腿屈和内收时，可见股直肌在缝匠肌和阔筋膜张肌组成的夹角内；股内侧肌和股外侧肌在大腿前面下部，位于股直肌内、外侧。
2. **臀大肌**　臀部圆隆外形。
3. **股二头肌**　腘窝外上界，可摸到肌腱止于腓骨头。
4. **半腱肌、半膜肌**　腘窝内上界，肌腱止于胫骨。半腱肌腱较窄、位置浅表且略靠外；半膜肌腱粗而圆钝，位于半腱肌腱深面内侧。
5. **小腿三头肌（腓肠肌和比目鱼肌）**　小腿后面可见膨隆肌腹及跟腱。

:::definition{label="鼻烟窝"}
拇指伸直外展时，拇短伸肌腱与拇长伸肌腱之间的凹陷。桡侧还有拇长展肌腱。不要把三条腱都算进窝的两壁。
:::

:::memory{label="本节必背要点"}
- [ ] 骨骼肌是运动系统主动部分（动力部分），随意肌，约 600 多块，约占体重 40%，每块肌是一个器官。
- [ ] 外形四类：长、短、扁、轮匝；另有二腹、多腹、多头、羽状。肌腹能收缩，肌腱抗张约为肌腹 100 多倍。
- [ ] 起点 / 定点 vs 止点 / 动点，可互换。拮抗肌对轴，协同肌同侧。单轴 2 组、双轴 4 组、三轴 6 组。
- [ ] 辅助装置本版四件：筋膜、滑膜囊、腱鞘、籽骨。腱鞘分纤维层和滑膜层，有腱系膜。髌骨是最大籽骨。
- [ ] 头肌 = 面肌（表情肌，面神经）+ 咀嚼肌四块（咬肌、颞肌、翼内肌、翼外肌，三叉神经）。翼外肌双侧收缩张口。
- [ ] 胸锁乳突肌：一侧头向同侧倾、脸转向对侧；两侧后仰。斜角肌间隙：前、中斜角肌 + 第 1 肋，走锁骨下动脉和臂丛。
- [ ] 斜方肌瘫痪塌肩（副神经）；前锯肌瘫痪翼状肩（胸长神经）；三角肌瘫痪方肩（腋神经）。
- [ ] 膈三个裂孔：T12 主动脉 + 胸导管；T10 食管 + 迷走神经；T8 腔静脉（中心腱内）。最常见膈疝是食管裂孔疝。
- [ ] 腹直肌鞘上 2/3 有后层，下 1/3 后层缺如，弓状线约脐下 4～5 cm。腹股沟管两口四壁；斜疝走深环，直疝走海氏三角。
- [ ] 肌腱袖 = 肩胛下肌 + 冈上肌 + 冈下肌 + 小圆肌。大圆肌不参加。
- [ ] 前臂前群 9 块四层，后群 10 块浅深两层。肱桡肌是前群但走桡神经。指浅屈肌止中节，指深屈肌止远节。
- [ ] 鱼际四块里拇收肌走尺神经。骨间掌侧肌内收、骨间背侧肌外展，轴在中指。
- [ ] 股四头肌全身最大，缝匠肌全身最长，背阔肌全身最大扁肌。小腿三头肌 = 腓肠肌 + 比目鱼肌 → 跟腱。
- [ ] 胫骨前、后肌内翻；腓骨长、短肌外翻。足底肌维持足弓，无对掌肌。
- [ ] 鼻烟窝：拇短伸肌腱与拇长伸肌腱之间。腋前壁胸大肌，腋后壁背阔肌。
:::
