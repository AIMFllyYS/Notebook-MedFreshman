# 第二节　中枢神经系统

中枢神经系统（central nervous system）是神经系统的中枢部：颅腔内的**脑**加上椎管内的**脊髓**。本节把这一户写完：脊髓的位置、外形、内部灰白质、功能和损伤；脑的脑干、小脑、间脑和端脑；以及脑和脊髓的被膜、血管、脑脊液循环和脑屏障。脊神经丛、脑神经周围段和内脏神经是第三节的户头；三级神经元的传导通路名单交给第四节。不要把马尾听成「脊神经已经写完」，也不要把脑干核名逐个写成段落。

:::definition{label="中枢神经系统"}
颅腔内的**脑** + 椎管内的**脊髓**。与周围部（脑神经 + 脊神经）在结构和功能上是一个整体。本节写中枢这一户；周围部的丛、周围段和内脏神经不提前拆开。
:::

:::concept{term="先问脊髓还是脑，再问脑干六部里的哪一块，再问被膜血管脑脊液有没有另立户"}
看见中枢，先切成脊髓和脑。脑再切成延髓、脑桥、中脑、小脑、间脑、端脑；前三块合称脑干。被膜、血管、脑脊液和脑屏障是中枢的外套和循环，仍在本节。把「中枢」听成「就是大脑」，脊髓和脑干会从开篇丢掉；把周围神经的丛和周围段写进来，又是吞了第三节。
:::

:::compare{title="本节户头（本版顺序）"}
| 户 | 本版要点 | 不要写成 |
|----|----------|----------|
| 脊髓 | 位置、圆锥、31 节、两个膨大、内部灰白质、传导与反射、损伤 | 把脊神经前支的丛提前立户 |
| 脑干 | 延髓 + 脑桥 + 中脑；外形用散文；核团、长束用表 | 每个核一张 definition |
| 小脑 / 间脑 / 端脑 | 外形和关键结构用散文；小脑核、丘脑核、内囊、侧脑室用表 | 把第四节的三级通路整段搬过来 |
| 被膜、血管、脑脊液、脑屏障 | 循环路径写全；Willis 环用表 | 只写「有三层膜」而不写隙和窦 |

:::

:::note{label="本节点到脊神经根，不写脊神经丛"}
一对脊神经的根丝附着处就是一个脊髓节段。31 对脊神经是脊髓分节的标志，前根、后根、马尾都要写。周围神经的丛、周围段和皮支运动支，全部交给第三节。
:::

## 一、脊髓

脊髓（spinal cord）是中枢神经系统的低级部分，起源于胚胎神经管的尾端，原始管腔演化为中央管。构造上保留节段性，与分布于躯干和四肢的 **31** 对脊神经相连。脊髓与脑各部有广泛的纤维联系；正常状态下脊髓的活动在脑的控制下进行，但脊髓本身也能完成一些反射。

:::definition{label="脊髓"}
位于**椎管内**的中枢低级部分，外包三层被膜，与脑的被膜相续。上端在枕骨大孔续延髓，下端成圆锥。本版全长约 **42～45 cm**，最宽横径 **1.0～1.2 cm**，重约 **20～25 g**。
:::

### （一）脊髓的位置和形态

成人脊髓全长约 **42～45 cm**，最宽处横径 **1.0～1.2 cm**，重约 **20～25 g**，位于椎管内。上端在枕骨大孔处与延髓相连；下端逐渐变细呈圆锥状，称脊髓圆锥（conus medullaris），末端约平对**第 1 腰椎椎体下缘**（新生儿可达第 3 腰椎椎体下缘；部分成人可达第 2 腰椎椎体下缘）。软脊膜包绕脊髓，在末端向下延续为一条结缔组织细丝，即终丝（filum terminale），止于第 1 尾椎背面，起固定脊髓的作用。

脊髓呈前后稍扁的圆柱形，全长粗细不等，有两个梭形膨大。上方的颈膨大（cervical enlargement）支配上肢，从第 **3** 颈髓节段至第 **2** 胸髓节段；下方的腰骶膨大（lumbosacral enlargement）支配下肢，从第 **1** 腰髓节段至第 **3** 骶髓节段。人类上肢功能强于下肢，因而颈膨大比腰骶膨大明显。一对脊神经的根丝所附着的一段脊髓，称一个脊髓节段。

:::definition{label="脊髓圆锥"}
脊髓下端的圆锥状膨大末端。本版约平 **L1 椎体下缘**。新生儿可达 L3；部分成人可达 L2 下缘。L1 以下椎管内已经没有脊髓实质。
:::

:::definition{label="终丝"}
软脊膜在脊髓末端向下延续的结缔组织细丝，止于**第 1 尾椎背面**，固定脊髓。不要把终丝听成还有神经组织的「细脊髓」。
:::

:::definition{label="马尾"}
腰、骶、尾部脊神经根在穿出相应椎间孔前，于圆锥下方围绕终丝垂直下行，聚集成束，称马尾（cauda equina）。因为脊髓相对升高，这些根丝必须先在椎管内走一段。
:::

:::compare{title="两个膨大（本版节段）"}
| | 颈膨大 | 腰骶膨大 |
|--|--------|----------|
| 节段 | **C3～T2** | **L1～S3** |
| 支配 | 上肢 | 下肢 |
| 外形 | 更明显（上肢功能更强） | 较细 |

膨大是前角运动神经元增多撑出来的，不是「骨头粗」。写成「颈膨大在颈椎、腰膨大在腰椎」，节段和椎骨又对不上。
:::

脊髓表面有 6 条平行纵沟。前面正中较深的是前正中裂（anterior median fissure），平均深度 **3 mm**；后面正中较浅的是后正中沟（posterior median sulcus）。这两条沟把脊髓分成左右对称的两半。前外侧面有一对前外侧沟，脊神经前根的根丝在此附着；后外侧面有一对后外侧沟，脊神经后根的根丝在此附着。在颈髓和上部胸髓，后正中沟与后外侧沟之间还有一条较浅的后中间沟，把后索分成内侧的薄束和外侧的楔束。

脊髓外形上没有明显的节段标志。脊神经有 **31** 对，故脊髓分为 31 个节段：颈髓（C）8、胸髓（T）12、腰髓（L）5、骶髓（S）5、尾髓（Co）1。

:::definition{label="脊髓节段"}
每一对脊神经前、后根根丝附着处的那一段脊髓。节段数等于脊神经对数：**8 + 12 + 5 + 5 + 1 = 31**。不是「有几块椎骨就有几节脊髓」。
:::

::figure{src="/images/anatomy/textbook/p0291_01.png" caption="图9-12　脊髓外形" alt="前面观和后面观：上接脑干，颈膨大、腰骶膨大、终丝；前面标前正中裂和前外侧沟，后面标后正中沟、后中间沟和后外侧沟"}

胚胎早期脊髓几乎与椎管等长，脊神经根基本呈直角连脊髓。从胚胎第 4 个月起，脊柱生长快于脊髓，脊髓长度短于脊柱。脊髓上端连延髓、位置固定，下部节段因而高于相应椎骨：出生时下端已平 L3，至成人达 L1 椎体下缘。腰、骶、尾部脊神经根必须在椎管内垂直下行一段，形成马尾。因第 1 腰椎以下已无脊髓，临床上做脊髓蛛网膜下隙穿刺抽取脑脊液或行硬膜外麻醉时，常选第 **3、4** 或第 **4、5** 腰椎棘突间进针，以免损伤脊髓。

成人脊髓节段与椎骨不在同一高度。了解对应关系，对判断损伤平面和手术定位有临床意义。

:::compare{title="成人脊髓节段与椎骨（本版对应）"}
| 脊髓节段 | 约平对的椎骨 |
|----------|----------------|
| 上颈髓 C1～C4 | 同序数椎骨 |
| 下颈髓 C5～C8、上胸髓 T1～T4 | 同序数椎骨的上 1 块 |
| 中胸髓 T5～T8 | 同序数椎骨的上 2 块 |
| 下胸髓 T9～T12 | 同序数椎骨的上 3 块 |
| 腰髓 | 第 10～12 胸椎 |
| 骶髓、尾髓 | 第 1 腰椎 |

口诀是「上颈同位、下颈上一、中胸上二、下胸上三、腰对下胸、骶尾对 L1」，不要按椎骨序数去数脊神经。
:::

::figure{src="/images/anatomy/textbook/p0291_02.png" caption="图9-13　脊髓节段与椎骨对应关系" alt="侧面观：颈、胸、腰、骶、尾神经根丝从相应脊髓节段斜向下出椎间孔；下部根丝垂直下行形成马尾，圆锥止于上部腰椎水平"}

:::pitfall{label="腰穿进的是终池，不是扎进脊髓"}
成人圆锥约平 L1 下缘，L3～L4 或 L4～L5 棘突间已经没有脊髓，针尖进的是终池里的脑脊液和马尾。写成「从腰椎间隙扎进腰髓」，平面和结构都错了。硬膜外麻醉走的是硬膜外隙，和蛛网膜下隙穿刺不是同一层。
:::

:::insight{label="图9-12 先认两个梭形膨大，再认终丝"}
前面看前正中裂，后面看后正中沟和后中间沟。颈膨大在上、腰骶膨大在下，末端拖一条终丝。图9-13 把根丝画成斜向下的「马尾」，那是节段高于椎骨的后果，不是另长出来的一条神经。
:::

### （二）脊髓的内部结构

脊髓由中央的灰质和外围的白质组成。横切面上，中央有细小的中央管（central canal），围绕它的是呈 **H** 形的灰质，灰质外围是白质。中央管纵贯全长，内含脑脊液，向上通第四脑室，向下在圆锥内扩大为梭形的终室（terminal ventricle）；40 岁以上时中央管常闭塞。

每侧灰质前部扩大为前角（或前柱），后部狭细为后角（或后柱）；后角由后向前分为头、颈和基底三部分。前、后角之间为中间带；在胸髓和上腰髓（**T1～L3**），中间带外侧部向外伸出侧角（或侧柱）。中央管前、后的灰质分别称灰质前连合和灰质后连合，连接两侧灰质。

白质借纵沟分为 3 个索：前正中裂与前外侧沟之间为前索，前、后外侧沟之间为外侧索，后外侧沟与后正中沟之间为后索。灰质前连合前方的白质称白质前连合，有纤维横越。后角基底部外侧与白质之间，灰白质混合交织，称网状结构，在颈部比较明显。

:::definition{label="脊髓灰质"}
神经元胞体及突起、神经胶质和血管的复合体，横切面呈 H 形。前角管运动，后角管感觉，侧角（T1～L3）是交感神经低级中枢。细胞聚集成核或分层（Rexed Ⅰ～Ⅹ）。
:::

:::definition{label="脊髓白质"}
灰质外围的纤维。按沟裂分成前索、外侧索、后索。含后根传入、前根传出、上行束、下行束和脊髓固有束。
:::

::figure{src="/images/anatomy/textbook/p0292_01.png" caption="图9-14　脊髓内部结构（新生儿脊髓颈膨大水平切面）" alt="左半实物：后根、胶状质、网状结构、中央管、前角、白质前连合、前根；右半模式：薄束与楔束、后角诸核、皮质脊髓侧束、红核脊髓束、脊髓丘脑束、前角内外侧核、皮质脊髓前束和内侧纵束"}

::figure{src="/images/anatomy/textbook/p0292_02.png" caption="图9-15　脊髓内部结构（新生儿脊髓胸部水平切面）" alt="胸部横切：可见侧角、中间带外侧核和中间带内侧核、胸核；白质中有皮质脊髓侧束、脊髓小脑前束、脊髓丘脑束和皮质脊髓前束"}

**1. 灰质**　20 世纪 50 年代 Rexed 把脊髓灰质从后向前分成 10 层，中央管周围为第Ⅹ层。核团与板层对应，记表不记每个核的散文。

:::compare{title="Rexed 分层与核团（表9-1 收口）"}
| 层 | 部位 | 对应核团或要点 |
|----|------|----------------|
| Ⅰ | 后角头最外层（边缘层、海绵带） | 后角边缘核；参与脊髓丘脑束 |
| Ⅱ | 后角头大部 | **胶状质**；几乎无有髓纤维，加工痛觉 |
| Ⅲ、Ⅳ | 后角头 | 后角固有核；大量后根传入 |
| Ⅴ | 后角颈 | 外侧 1/3 形成网状结构 |
| Ⅵ | 后角基底（膨大处明显） | 本体感觉初级传入 + 皮质下行 |
| Ⅶ | 中间带 | 胸核（Clarke 柱，C8～L3）、中间带内侧核、中间带外侧核（T1～L3，交感低级中枢）、骶副交感核（S2～S4） |
| Ⅷ | 前角基底（膨大处偏内侧） | 固有中间神经元 |
| Ⅸ | 前角腹侧核柱 | 前角内侧核（躯干肌）、前角外侧核（四肢肌）；α 与 γ 运动神经元 |
| Ⅹ | 中央管周围 | 灰质前、后连合 |

Ⅰ～Ⅳ层属外感受区，向上与三叉神经脊束核尾端相续。Ⅴ、Ⅵ层与运动调节相关。不要把 10 层逐张立定义。
:::

:::compare{title="前角运动神经元（Ⅸ层）"}
| | α-运动神经元 | γ-运动神经元 |
|--|--------------|--------------|
| 大小 | 大型 | 小型 |
| 支配 | 梭外肌，引起关节运动 | 梭内肌，调节肌张力 |
| 损伤 | 所支配骨骼肌**弛缓性瘫痪**（软瘫）：运动丧失、肌肉萎缩、肌张力低下、腱反射消失 | 肌张力调节障碍 |

Renshaw 细胞接受 α 轴突侧支，再抑制同一或其他 α 神经元，形成负反馈。C3～C7 有膈神经核；C1～C5/C6 有副神经核组（脊髓部）。
:::

:::pitfall{label="侧角不是全长都有"}
侧角只在 **T1～L3**，是交感神经节前神经元所在。骶副交感核在 **S2～S4** 的Ⅶ层外侧部，发出盆内脏神经，不要写成「侧角里也有副交感」。胸核（背核、Clarke 柱）在 C8～L3 后角基底内侧，发出脊髓小脑后束，和侧角不是同一团细胞。
:::

**2. 白质**　后根进入脊髓后分内、外侧部：内侧部为粗有髓纤维，入后索组成薄束、楔束，传导本体感觉和精细触觉；外侧部为细纤维，在胶状质背外侧聚成背外侧束（Lissauer 束），主要传导痛温觉、粗触压觉和内脏感觉。前根走出的是前角运动纤维和侧角（或骶副交感核）的节前纤维。

:::compare{title="主要上行纤维束"}
| 束 | 位置 | 起止要点 | 传导 | 损伤 |
|----|------|----------|------|------|
| 薄束 | 后索内侧 | 同侧 T5 及以下脊神经节 → 延髓薄束核 | 同侧下半身本体感觉、精细触觉 | 后索病变：闭目不能辨肢位，感觉性共济失调，精细触觉丧失 |
| 楔束 | 后索外侧（T4 以上才出现） | 同侧 T4 及以上脊神经节 → 延髓楔束核 | 同侧上半身同上 | 同上，累及上肢 |
| 脊髓小脑后束 | 外侧索周边背侧 | 同侧胸核为主；经小脑下脚入小脑 | 下肢和躯干下部非意识性本体感觉（个别肌的精细协调） | L2 以上才见到此束 |
| 脊髓小脑前束 | 外侧索周边腹侧 | 腰骶膨大Ⅴ～Ⅶ层，大部交叉；经小脑上脚入小脑 | 整个肢体的运动和姿势 | |
| 脊髓丘脑侧束 | 外侧索前部 | Ⅰ、Ⅳ～Ⅷ层，交叉后对侧上行 → 丘脑 | **痛、温觉** | 一侧损伤：损伤下方 1～2 节以下**对侧**痛温觉减退或消失 |
| 脊髓丘脑前束 | 前索 | 同上 | 粗触觉、压觉 | |
| 内脏感觉束 | 伴脊髓丘脑束 | 后角和中间带中继后上行 | 胸腹腔脏器感觉 | |

薄、楔束在同侧后索直接上行，脊髓丘脑束边走边交叉。写成「痛温觉也走后索」，分离性感觉障碍就对不上。
:::

:::compare{title="主要下行纤维束"}
| 束 | 位置 | 要点 | 损伤 |
|----|------|------|------|
| 皮质脊髓侧束 | 外侧索后部，至约 S4 | 锥体交叉后 **75%～90%** 的纤维；支配对侧前角，主达膨大处前角外侧核 | 一侧损伤：同侧损伤平面以下肢体**痉挛性瘫痪**（硬瘫：随意运动障碍、肌张力增高、腱反射亢进）；躯干肌不瘫（双侧支配） |
| 皮质脊髓前束 | 前索最内侧，只达中胸部 | 未交叉；大部逐节经白质前连合交叉到对侧前角 | |
| 皮质脊髓前外侧束 | 侧索前外侧 | 不交叉；大部终于颈髓 | |
| 红核脊髓束 | 外侧索 | 人类可能仅至上 3 个颈节；兴奋屈肌、抑制伸肌 | |
| 前庭脊髓束 | 前索外侧部 | 兴奋伸肌、抑制屈肌，维持平衡 | |
| 网状脊髓束 | 前索和外侧索前内侧 | 兴奋或抑制 α、γ 运动神经元 | |
| 顶盖脊髓束 | 前索 | 视觉、听觉姿势反射 | |
| 内侧纵束降部 | 前索 | 协调眼球运动和头部姿势 | |

### （三）脊髓的功能

脊髓是神经系统的低级中枢，主要功能是**传导**和**反射**。躯干、四肢及部分内脏的感觉经后根入脊髓，由上行束传到脑；脑发出的冲动经下行束到达前角和侧角，控制骨骼肌、平滑肌、心肌和腺体。

脊髓反射的反射弧是：感受器 → 脊神经节感觉神经元及后根 → 脊髓固有神经元及固有束 → 脊髓运动神经元及前根 → 效应器。只经过一次突触的称单突触反射；两个以上神经元的称多突触反射。只涉及一个节段的称节段内反射，跨节段的称节段间反射。还可以按躯体/内脏交叉搭配分类。

:::compare{title="脊髓反射三件套（本版原句）"}
| | 牵张反射 | γ-环路 | 屈曲反射 |
|--|----------|--------|----------|
| 刺激 | 骨骼肌被牵拉 | γ 兴奋使梭内肌收缩，肌梭放电 | 皮肤伤害性刺激 |
| 通路 | 肌梭 → 后根 → α 运动神经元 → 同一块肌收缩 | 经牵张反射弧再兴奋 α，使梭外肌收缩 | 至少 3 个神经元，常多节段 |
| 类型 | 腱反射（单突触，如膝反射、跟腱反射、肱二头肌反射）；肌紧张（多突触，维持姿势） | 维持肌张力 | 保护性；刺激够大时出现**对侧伸直反射** |

正常反射都在脑的控制下进行。不要把牵张反射写成「大脑下令肌肉缩短」。
:::

### （四）脊髓常见损伤的表现

:::compare{title="脊髓损伤四型"}
| 型 | 受损结构 | 本版表现 |
|----|----------|----------|
| 全横断 | 该平面全部上、下行束 | 平面以下全部感觉和运动丧失，反射消失（脊髓休克）；数周至数月后反射恢复且深反射、肌张力高于正常；感觉和随意运动不能恢复 |

前角（下运动神经元）伤是软瘫：萎缩、张力低、腱反射消失。皮质脊髓束（上运动神经元）伤是硬瘫：张力高、腱反射亢进、无严重萎缩。写成「脊髓损伤都是软瘫」，半横断的同侧肢体对不上。
:::

## 二、脑

脑（brain，encephalon）位于颅腔内，由胚胎神经管前部分化而来，是中枢的最高级部位。成人脑平均重量约 **1400 g**。一般分为 6 部分：延髓、脑桥、中脑、小脑、间脑和端脑。其中延髓、脑桥和中脑合称脑干。

胚胎 4 周末，神经管前部分化为前脑泡、中脑泡和菱脑泡。5 周时前脑泡前端成左、右大脑半球，后部成间脑；中脑泡成中脑；菱脑泡分成后脑（再成脑桥和小脑）和末脑（成延髓）。神经管在各部围成连续的脑室系统。

:::definition{label="脑"}
颅腔内的中枢最高级部位。本版六部：**延髓、脑桥、中脑、小脑、间脑、端脑**。前三部合称脑干。重量约 1400 g 是本版均数，不要把它听成「只有大脑」。
:::

:::definition{label="脑干"}
自下而上由**延髓、脑桥、中脑**组成。位于颅后窝前部，上接间脑，下续脊髓；腹侧邻斜坡，背面连小脑。延髓、脑桥与小脑之间的室腔是第四脑室。表面附有第 **Ⅲ～Ⅻ** 对脑神经根。
:::

### （一）脑干

#### 1. 脑干的外形

**（1）腹侧面**　延髓形似倒置圆锥，下端以第 1 颈神经最上根丝（约平枕骨大孔）与脊髓相续，上端借横行的延髓脑桥沟与脑桥为界。下部外形像脊髓，各纵沟向上延续。前正中裂两侧的纵行隆起是锥体，由下行锥体束（主要为皮质脊髓束）构成；锥体下端大部分纤维左右交叉，形成发辫状的锥体交叉，部分填堵前正中裂。锥体上部背外侧的卵圆形隆起称橄榄，内含下橄榄核。锥体与橄榄之间的前外侧沟有舌下神经根丝出脑；橄榄背外侧的后外侧沟内，自上而下依次有舌咽、迷走和副神经根丝。

脑桥腹侧面宽阔隆起，称脑桥基底部，正中纵行浅沟为基底沟，容纳基底动脉。基底部向外后变窄成小脑中脚（脑桥臂），交界处连三叉神经根（粗大感觉根 + 前内侧细小运动根）。上缘接中脑大脑脚，下缘即延髓脑桥沟，沟内自中线向外侧依次连展神经、面神经和前庭蜗神经根。延髓脑桥沟外侧部，延髓、脑桥和小脑的结合处称脑桥小脑三角，前庭蜗神经根恰在此处；此处肿瘤除听力障碍和小脑症状外，还可压迫面、三叉、舌咽和迷走神经。

中脑上界为间脑视束，下界为脑桥上缘。两侧各有一粗大纵行柱状隆起，称大脑脚，浅部主要是皮质下行纤维。两侧大脑脚之间的凹陷为脚间窝，窝底称后穿质。动眼神经根连于脚间窝下部、大脑脚内侧。

**（2）背侧面**　延髓上部构成菱形窝下半；下部形似脊髓，后正中沟两侧有薄束结节和楔束结节，深面分别是薄束核和楔束核。楔束结节外上方的隆起是小脑下脚（绳状体）。脑桥背面构成菱形窝上半，外上界为左右小脑上脚（结合臂），两脚间夹薄层白质板上髓帆。脑桥与中脑移行部缩窄称菱脑峡。中脑背面为四叠体：上一对上丘（视觉反射中枢），下一对下丘（听觉反射中枢）；上丘臂连外侧膝状体，下丘臂连内侧膝状体。下丘下方与上髓帆之间有滑车神经根出脑——它是**唯一自脑干背面出脑**的脑神经。

菱形窝是延髓上部和脑桥的背面，由中央管后壁中线处向后敞开形成，构成第四脑室底。正中沟把窝分成左右两半；自正中沟中部向外至外侧角的横行纤维束称髓纹，是脑桥和延髓在背面的分界。正中沟外侧的纵行界沟把每一半分成内侧的内侧隆起和外侧的前庭区（深面有前庭神经核）；前庭区外侧角的听结节内藏蜗背侧核。髓纹上方圆形隆凸为面神经丘（内隐面神经膝和展神经核）；髓纹下方内上为舌下神经三角，外下为迷走神经三角。迷走神经三角外下缘的窄嵴称分隔索，与薄束结节之间的窄带称最后区。界沟上端外侧蓝灰色小区是蓝斑。菱形窝下角两侧外下界之间的圆弧形移行部称闩。

第四脑室位于延髓、脑桥和小脑之间，呈四棱锥形，底为菱形窝，顶朝向小脑蚓。顶的前上部由两侧小脑上脚及上髓帆构成，后下部由下髓帆及第四脑室脉络组织形成。脉络组织内血管成丛，突入室腔成为第四脑室脉络丛，产生脑脊液。第四脑室向上经中脑导水管通第三脑室，向下续中央管，并借 **3** 个孔与蛛网膜下隙相通：单一的正中孔在菱形窝下角正上方，成对的外侧孔在外侧隐窝尖端。脑脊液经这 3 个孔注入小脑延髓池。

:::definition{label="第四脑室"}
延髓、脑桥和小脑围成的室腔。底 = 菱形窝；顶朝小脑。借中脑导水管通第三脑室，向下续中央管，借正中孔和成对外侧孔通蛛网膜下隙。
:::

#### 2. 脑干的内部结构

与脊髓相比：延髓下部仍像脊髓；延髓上部和脑桥中央管后壁敞开成菱形窝，原腹背排列的核柱变成由中线向两侧的内、外侧排列；白质被推到腹外侧。灰质不再是连续细胞柱，而是断续的核团：脑神经核、中继核和网状核。网状结构明显扩大，含心血管运动中枢和呼吸中枢等生命中枢。

脑神经纤维成分增至 7 种，对应 7 种核团，纵排成 6 个功能柱：运动性核柱在界沟内侧，感觉性核柱在界沟外侧。

中继核不要和脑神经核混户。黑质在被盖与大脑脚底之间，红核在上丘高度被盖中央。
:::

:::compare{title="脑干长的上、下行纤维束"}
| 束 | 传导 / 行程要点 |
|----|------------------|
| 内侧丘系 | 对侧薄、楔束核发出，交叉后上行 → 丘脑腹后外侧核；对侧躯干四肢意识性本体感觉和精细触觉 |
| 脊髓丘脑束（脊髓丘系） | 延髓在下橄榄核背外侧，脑桥中脑在内侧丘系背外侧 → 丘脑腹后外侧核；对侧痛温、粗触压 |
| 三叉丘脑束（三叉丘系） | 贴内侧丘系背外侧 → 腹后内侧核；对侧头面痛温，双侧触压 |
| 外侧丘系 | 双侧听觉；一侧受损不致全聋 |
| 脊髓小脑前、后束 | 后束经小脑下脚，前束经小脑上脚入小脑 |
| 内侧纵束 | 协调眼外肌，调节眼球慢速运动和头部姿势 |

:::

脑干网状结构在被盖广大区域，纤维成网、核团边界不清，可分向小脑投射的核群、中缝核群（5-羟色胺能）、内侧核群（效应区）和外侧核群（感受区）。

:::compare{title="脑干网状结构的功能组合"}
| 组合 | 本版要点 |
|------|----------|
| 睡眠、觉醒、意识 | 上行网状激活系统维持皮质觉醒；与上行网状抑制系统（孤束核周围及脑桥下部内侧）动态平衡决定睡眠-觉醒。损伤 → 意识障碍 |
| 躯体运动 | 延髓腹内侧抑制区降低肌张力；背外侧易化区增强肌张力。上、下丘之间横断脑干 → **去大脑僵直**（抑制区失去高级始动，易化占优） |
| 躯体感觉 | 调制痛觉及其他感觉上传 |
| 内脏活动 | 呼吸中枢、心血管运动中枢等生命中枢。脑干损伤可致呼吸循环障碍，危及生命 |

:::

:::compare{title="代表性脑干综合征"}
| 综合征 | 常见血管 | 本版受损与表现 |
|--------|----------|----------------|
| 延髓内侧（舌下神经交叉性偏瘫） | 椎动脉延髓支 | 锥体束 → 对侧上下肢瘫；内侧丘系 → 对侧本体觉精细触觉障碍；舌下神经根 → 同侧半舌瘫，伸舌偏患侧 |
| 延髓外侧（Wallenberg） | 椎动脉延髓支或小脑下后动脉 | 三叉脊束 → 同侧头面痛温障碍；脊髓丘脑束 → 对侧躯体痛温障碍；疑核 → 吞咽困难、声音嘶哑；交感下行 → 同侧 Horner 综合征；小脑下脚 → 同侧共济失调；前庭核 → 眩晕、眼震 |
| 脑桥基底部（展神经交叉性偏瘫） | 基底动脉脑桥支 | 锥体束 → 对侧上下肢瘫；展神经根 → 同侧眼球不能外展 |
| 脑桥背侧部 | 小脑下前或小脑上动脉背外侧支 | 展核、面核、前庭核、三叉脊束、脊髓丘脑束、内侧丘系、交感下行、小脑下脚等，交叉性感觉运动障碍 + 同侧 Horner |
| 大脑脚底（Weber） | 大脑后动脉分支 | 动眼神经根 → 同侧眼外肌麻痹（外直、上斜除外）+ 瞳孔散大；皮质脊髓束 → 对侧上下肢瘫；皮质核束 → 对侧面神经和舌下神经核上瘫 |
| Benedikt | 中脑被盖腹内侧 | 动眼神经根同侧眼肌麻痹；红核和小脑丘脑纤维 → 对侧意向性震颤、共济失调；内侧丘系 → 对侧深感觉障碍 |

交叉性瘫痪：同侧脑神经 + 对侧肢体。写成「脑干损伤就是四肢瘫」，核和束的左右就丢了。
:::

:::pitfall{label="Horner 综合征不是动眼神经损伤"}
下丘脑到脊髓中间带外侧核的交感下行通路在延髓外侧、脑桥背侧被累及时，同侧瞳孔缩小、上睑轻度下垂、面部无汗。动眼神经伤是瞳孔**散大**、上睑明显下垂。两户都有「眼裂和瞳孔」，方向相反。
:::

### （二）小脑

小脑位于颅后窝，借上、中、下三对小脑脚连于脑干背面，上方借小脑幕与大脑分隔。主要功能是维持身体平衡、调节肌张力和协调随意运动。两侧膨大为小脑半球，中间狭窄为小脑蚓。上面稍平坦，有前切迹和后切迹；下面膨隆，前内侧一对突起称小脑扁桃体，紧邻延髓和枕骨大孔两侧。颅内压增高时，扁桃体可被挤入枕骨大孔，形成枕骨大孔疝（小脑扁桃体疝），压迫延髓呼吸和心血管中枢，危及生命。

小脑蚓下面从前向后为小结、蚓垂、蚓锥体和蚓结节。小结向两侧借绒球脚连绒球。表面许多浅沟分成小脑叶片；上面前、中 1/3 交界处的 V 形深沟称原裂，绒球和小结后方的深沟称后外侧裂。原裂与后外侧裂几乎成环：前上部为前叶，后下部为后叶，绒球、绒球脚和小结为绒球小结叶。前叶和后叶合称小脑体。

::figure{src="/images/anatomy/textbook/p0323_02.png" caption="图9-51　小脑的外形（上面）" alt="小脑上面：中间小脑蚓，两侧小脑半球，原裂把前叶和后叶分开，可见小脑前切迹、后切迹和水平裂"}

:::definition{label="小脑"}
颅后窝内的躯体运动调节中枢。借三对脚连脑干。功能是平衡、肌张力和随意运动的协调，不产生瘫痪，但会让运动质量变差。
:::

:::compare{title="小脑三分区（解剖 / 种系 / 功能）"}
| | 前庭小脑（原小脑） | 脊髓小脑（旧小脑） | 大脑小脑（新小脑） |
|--|---------------------|---------------------|---------------------|
| 形态 | 绒球小结叶 | 小脑体内侧区 + 中间区 | 小脑体外侧区 |
| 主要传入 | 前庭神经和前庭核，经小脑下脚 | 脊髓小脑前、后束，经上、下脚 | 对侧脑桥核，经小脑中脚 |
| 传出 | 顶核或直接 → 前庭核、网状结构 | 顶核、中间核 → 前庭核、网状结构、红核 | 齿状核 → 对侧红核和丘脑腹前、腹外侧核 → 皮质运动区 |
| 功能 | 躯干肌、眼球运动、身体平衡 | 调节肌张力 | 精细运动的起始、方向、速度和终止 |

内侧向外侧的核：顶核（原小脑）、球状核 + 栓状核 = 中间核（旧小脑）、齿状核（新小脑，最大，呈皱缩口袋状）。
:::

小脑皮质由浅至深为分子层、梨状细胞层、颗粒层。5 类神经元里只有颗粒细胞是谷氨酸能兴奋性，其余为 GABA 能抑制性。梨状细胞（Purkinje 细胞）轴突是皮质唯一的传出。传入分攀缘纤维（下橄榄核，直接缠梨状细胞）和苔藓纤维（脊髓、脑桥核等，经颗粒细胞平行纤维间接兴奋梨状细胞）。

::figure{src="/images/anatomy/textbook/p0327_01.png" caption="图9-58　小脑水平切面（示小脑核）" alt="水平切：活树状小脑髓质，皮质在表面；中线顶核，向外依次球状核、栓状核、齿状核，前方连脑桥"}

:::compare{title="三对小脑脚"}
| 脚 | 别名 | 主要成分 |
|----|------|----------|
| 下脚 | 绳状体，连延髓 | 传入：前庭、下橄榄、脊髓小脑后束、楔小脑束；传出：小脑前庭纤维、顶核延髓束 |
| 中脚 | 脑桥臂，最粗、最外侧 | 几乎全是对侧脑桥核来的脑桥小脑纤维 |
| 上脚 | 结合臂，连中脑 | 主要是小脑核到对侧红核和背侧丘脑的传出；传入有脊髓小脑前束等 |

:::

小脑损伤不引起瘫痪。典型体征：平衡失调（阔基步态，状如醉汉）、共济失调（不能闭眼指鼻、不能快速轮替）、意向性震颤（越接近目标越剧烈）、眼球震颤、肌张力低下（旧小脑）。

:::pitfall{label="小脑扁桃体疝压的是延髓，不是小脑自己"}
扁桃体紧邻枕骨大孔。颅压高时它往下掉，压的是延髓里的呼吸和心血管中枢，所以会致命。写成「疝了只是走路不稳」，把生命中枢那一户丢掉了。
:::

### （三）间脑

间脑位于中脑与端脑之间，体积不到中枢的 2%，结构和功能却十分复杂。大脑半球掩盖其两侧和背面，仅腹侧的视交叉、灰结节、漏斗、垂体和乳头体露于脑底。间脑分背侧丘脑、后丘脑、上丘脑、底丘脑和下丘脑 5 部。两侧之间的矢状窄腔是第三脑室：顶为脉络丛，底为视交叉、灰结节、漏斗和乳头体，前界终板，后经中脑导水管通第四脑室；背侧丘脑与下丘脑以下丘脑沟为界，沟前端有室间孔，侧脑室经此通第三脑室。

:::definition{label="间脑"}
中脑与端脑之间的中枢高级部位。五部：**背侧丘脑、后丘脑、上丘脑、底丘脑、下丘脑**。中间的腔是第三脑室。不要把「丘脑」听成间脑的全部。
:::

::figure{src="/images/anatomy/textbook/p0330_01.png" caption="图9-64　间脑" alt="上图正中矢状切示背侧丘脑、第三脑室脉络丛、下丘脑沟、室间孔、松果体、漏斗和垂体；下图背面示尾状核、豆状核、内囊、第三脑室和侧脑室脉络丛"}

| 部 | 关键结构 | 本版功能落点 |
|----|----------|--------------|
| 背侧丘脑 | 卵圆形灰质团，内髓板呈 Y 形分成前、内、外侧核群 | 感觉中继与整合；受损可痛觉过敏、自发性疼痛并伴情绪反应 |
| 后丘脑 | 内侧膝状体、外侧膝状体 | 听辐射 → 颞叶听区；视辐射 → 枕叶视区 |
| 上丘脑 | 松果体、缰三角、丘脑髓纹、后连合 | 松果体是内分泌腺，16 岁后渐钙化，可作影像定位标志 |
| 底丘脑 | 底丘脑核、未定带 | 抑制苍白球；一侧病变 → 对侧半身颤搐 |
| 下丘脑 | 视前区、视上区、结节区、乳头区 | 内脏和内分泌的高级中枢，约占脑重 0.3% |

:::

:::compare{title="背侧丘脑三类核团"}
| 类 | 核 | 联系要点 |
|----|----|----------|
| 非特异性投射核团（原丘脑） | 中线核、板内核、网状核 | 中继上行网状激活系统，弥散投射皮质，维持觉醒 |
| 特异性中继核团（旧丘脑） | 腹前核、腹外侧核、腹后核 | 腹前 / 腹外侧：小脑齿状核、苍白球、黑质 → 运动皮质。腹后内侧核收三叉丘系和味觉；腹后外侧核收内侧丘系和脊髓丘系 → 中央后回。头面在内侧，上肢躯干下肢由内向外 |

:::

下丘脑从前向后分视前区、视上区、结节区、乳头区。视上核和室旁核合成抗利尿激素和缩宫素，经视上垂体束到神经垂体贮存释放；漏斗核等经结节漏斗束到垂体门脉，调控腺垂体。

:::compare{title="下丘脑主要功能"}
| 功能 | 本版要点 |
|------|----------|
| 神经-内分泌 | 下丘脑-垂体-甲状腺 / 性腺 / 肾上腺轴 |
| 自主神经 | 前区内侧兴奋副交感，后区外侧兴奋交感 |
| 体温 | 前区热敏（散热）；后区冷敏（产热）。损前区 → 高热；损后区 → 变温症 |
| 摄食 | 腹内侧核 = 饱食中枢；外侧部 = 摄食中枢 |
| 昼夜节律 | 视交叉上核 → 交感 → 松果体褪黑素 |
| 情绪 | 参与情感、学习、记忆 |

:::

:::pitfall{label="下丘脑沟不是第三脑室的底"}
下丘脑沟把背侧丘脑和下丘脑分开，沟前端才是室间孔。第三脑室的底是视交叉、灰结节、漏斗和乳头体。写成「丘脑下面那条缝就是脑室底」，漏斗和垂体就挂错层。
:::

### （四）端脑

端脑也称大脑，是脑的最高级部位，由左、右大脑半球、半球间连合及其内腔构成。每侧半球表面的灰质层称大脑皮质，深部白质称大脑髓质，埋在髓质内的灰质核团称基底核，内腔称侧脑室。Brodmann 分区法将皮质分成 52 区。

左、右半球之间为大脑纵裂，底面是胼胝体；半球后部与小脑之间为大脑横裂。每侧半球有上外侧面、内侧面和下面。三条恒定的沟把半球分成 5 叶：外侧沟、中央沟、顶枕沟。

:::definition{label="端脑"}
左、右大脑半球 + 连合 + 侧脑室。表面皮质，深部髓质，髓质里埋基底核。五叶是额、顶、枕、颞和岛叶。
:::

:::compare{title="大脑半球五叶"}
| 叶 | 边界 | 上外侧面主要回 |
|----|------|----------------|
| 额叶 | 外侧沟上方、中央沟以前 | 中央前回；额上、中、下回（额下回后部被外侧沟前支、升支分成眶部、三角部、岛盖部） |
| 顶叶 | 中央沟后方、枕叶以前 | 中央后回；顶上小叶、顶下小叶（缘上回、角回） |
| 枕叶 | 内侧面顶枕沟以后；上外侧面以顶枕线为界 | 与顶、颞叶在凸面分界不明显 |
| 颞叶 | 外侧沟以下 | 颞上、中、下回；颞上回背侧有颞横回 |
| 岛叶 | 外侧沟深面，被额顶颞叶掩盖 | 三角形岛状 |

内侧面：中央旁小叶是中央前、后回的延续；距状沟与顶枕沟之间为楔叶，距状沟下方为舌回；扣带回在胼胝体沟与扣带沟之间。下面：海马旁回前端弯曲成钩；海马和齿状回构成海马结构。环绕胼胝体和侧脑室下角底壁的隔区、扣带回、海马旁回、海马、齿状回等，加上岛叶前部和颞极，构成边缘叶。
:::

::figure{src="/images/anatomy/textbook/p0336_01.png" caption="图9-72　大脑半球内侧面" alt="内侧面：胼胝体嘴膝干压、扣带回、中央旁小叶、楔叶、距状沟、舌回、海马旁回和钩；可见室间孔区域和背侧丘脑"}

大脑皮质功能定位只是执行该功能的核心，周围还有广泛联络区。左半球与语言、意识、数学分析相关，语言中枢主要在左侧；右半球主要感知非语言信息、音乐、图形和时空概念。

## 三、脑和脊髓的被膜、血管及脑脊液循环和脑屏障

脑和脊髓表面包三层被膜，由外向内为硬膜、蛛网膜和软膜，支持并保护中枢。

### （一）脊髓和脑的被膜

脊髓被膜由外向内为硬脊膜、脊髓蛛网膜和软脊膜。硬脊膜厚而坚韧，上端附于枕骨大孔边缘续硬脑膜，约在 S2 水平变细包裹终丝，下端附于尾骨。硬脊膜与椎管骨膜之间为硬膜外隙，含脂肪、静脉丛和脊神经根，略呈负压，**不与颅腔相通**；硬膜外麻醉把药物注入此隙。硬脊膜与蛛网膜之间为潜在的硬膜下隙。脊髓蛛网膜与软脊膜之间为较宽的蛛网膜下隙，充满脑脊液；自脊髓下端至 S2 扩大为终池，内容马尾。软脊膜紧贴脊髓，下端移行为终丝；在两侧前、后根之间形成齿状韧带，尖端附于硬脊膜，与脊神经根一起固定脊髓。

::figure{src="/images/anatomy/textbook/p0348_01.png" caption="图9-89　脊髓的被膜示意图" alt="椎管横切：硬脊膜、蛛网膜、软脊膜三层；硬膜外隙、硬膜下隙、蛛网膜下隙；齿状韧带在前后根之间连到硬脊膜，脊神经前支穿出"}

硬脑膜是厚而坚韧的双层膜：外层即颅骨内面骨膜，与颅盖连结疏松（硬脑膜血管损伤可形成硬膜外血肿），与颅底结合紧密（颅底骨折易同时撕裂硬脑膜和蛛网膜，脑脊液可经鼻漏出）。内层折叠成板状突起：大脑镰伸入纵裂，小脑幕伸入横裂，小脑镰伸入两小脑半球之间，鞍膈封闭垂体窝。小脑幕前内侧缘游离成小脑幕切迹，与鞍背围成小脑幕裂孔，中脑通过。上部颅压增高时，海马旁回和钩可被挤入切迹，形成小脑幕切迹疝，压迫大脑脚和动眼神经。

|------|------|------|
| 大脑镰 | 纵裂内，下缘游离于胼胝体上方 | |

硬脑膜窦由两层硬脑膜分开、衬以内皮而成，含静脉血，窦壁无平滑肌，损伤难以止血。

|----|------|------|
| 上矢状窦 | 大脑镰上缘 | 向后入窦汇 |
| 下矢状窦 | 大脑镰下缘 | 向后入直窦 |

海绵窦腔内有结缔组织小梁。**内侧壁**有颈内动脉和展神经通过；**外侧壁**自上而下有动眼神经、滑车神经、眼神经和上颌神经。海绵窦向前借眼静脉与面静脉交通，向下经卵圆孔小静脉与翼静脉丛相通，面部感染可蔓延引起海绵窦炎和血栓，累及过路神经。

脑蛛网膜薄而透明，除纵裂和横裂外不深入沟内，故蛛网膜下隙大小不一，扩大处称蛛网膜下池（小脑延髓池、交叉池、脚间池、桥池、四叠体上池）。上矢状窦处蛛网膜形成蛛网膜粒，脑脊液经此渗入窦内。软脑膜薄而富血管，伸入沟裂；在脑室一定部位与室管膜共同构成脉络组织，血管成丛即脉络丛，是产生脑脊液的主要结构。

:::pitfall{label="硬膜外隙颅椎不通，蛛网膜下隙颅椎相通"}
硬膜外麻醉走椎管硬膜外隙，那一层到不了颅内。腰穿走的是终池的蛛网膜下隙，向上一直通到脑的蛛网膜下隙。写成「硬膜外和腰穿打的是同一个腔」，药和脑脊液就走错层。
:::

### （二）脑和脊髓的血管

脑的动脉来自颈内动脉和椎动脉。左、右椎动脉入颅后合成一条基底动脉，故分颈内动脉系和椎-基底动脉系。以顶枕沟为界：半球前 2/3 和部分间脑由颈内动脉供应；半球后 1/3 及部分间脑、脑干和小脑由椎动脉供应。分支再分皮质支（皮质及深面髓质）和中央支（基底核、内囊、间脑）。

颈内动脉起自颈总动脉，经颈动脉管入颅，穿海绵窦。行程分颈部、岩部、海绵窦部和前床突上部；后两部合称虹吸部，常呈 U 或 V 形，是动脉硬化好发部位。出海绵窦处发出眼动脉。供应脑的主要分支见下表。

椎动脉起自锁骨下动脉，穿第 6 至第 1 颈椎横突孔，经枕骨大孔入颅，在脑桥与延髓交界腹侧汇成基底动脉；基底动脉沿基底沟上行，至脑桥上缘分为左、右大脑后动脉。

:::compare{title="脑的主要动脉"}
| 动脉 | 来源 | 供应要点 |
|------|------|----------|
| 大脑前动脉 | 颈内动脉 | 顶枕沟以前的半球内侧面、额叶底面一部分和额顶上外侧面上部；中央支含内侧豆纹动脉 |
| 大脑中动脉 | 颈内动脉的直接延续 | 半球外侧面大部和岛叶（含运动、感觉和语言中枢）；途经前穿质发豆纹动脉（中央支）营养尾状核、豆状核、内囊膝和后肢前部。高血压时易破，又称出血动脉 |
| 脉络丛前动脉 | 颈内动脉 | 外侧膝状体、内囊后肢后下部、大脑脚底中 1/3、苍白球；细长易血栓 |

| 小脑下后动脉 | 椎动脉最大分支 | 小脑下面后部和延髓后外侧；栓塞 → Wallenberg 综合征 |

| 大脑后动脉 | 基底动脉终末支 | 颞叶内侧面、底面及枕叶；中央支供应丘脑、内膝状体、下丘脑、底丘脑。颅压高时钩疝可把该动脉下移，牵拉压迫动眼神经 |

大脑动脉环（Willis 环）位于脑底下方、蝶鞍上方，环绕视交叉、灰结节及乳头体。正常时两侧血液不相混合，是潜在代偿结构；约 48% 国人发育不全或异常，动脉瘤好发于大脑前动脉与前交通动脉连接处。

:::compare{title="大脑动脉环（Willis 环）组成"}
| 组成 | 本版 |
|------|------|
| 两侧大脑前动脉起始段 | 颈内动脉系 |
| 前交通动脉 | 连接左右大脑前动脉 |
| 两侧颈内动脉末段 | 颈内动脉系 |
| 两侧后交通动脉 | 沟通颈内动脉系与椎-基底动脉系 |
| 两侧大脑后动脉 | 椎-基底动脉系终末 |

:::

脑的静脉不与动脉伴行，无瓣膜，分浅、深两组，最终经硬脑膜窦回流入颈内静脉。浅组：大脑上静脉入上矢状窦，大脑下静脉入横窦和海绵窦，大脑中浅静脉入海绵窦。深组：左右大脑内静脉在松果体后方合成大脑大静脉（Galen 静脉），收集半球深部髓质、基底核、间脑和脉络丛的血，注入直窦。

脊髓动脉有两个来源：椎动脉发出的脊髓前、后动脉，以及颈升、肋间后、腰、骶外侧等节段性动脉的补充。左、右脊髓前动脉在延髓腹侧合成一干，沿前正中裂下行；脊髓后动脉沿后外侧沟下行。前、后动脉借动脉冠吻合。脊髓前动脉主要营养前角、侧角、灰质连合、后角基部、前索和外侧索；脊髓后动脉营养后角其余部分和后索。两个来源吻合薄弱处称危险区，如 **T1～T4**（尤其 T4）和 **L1** 的腹侧面。脊髓静脉经根静脉注入椎内静脉丛。

:::insight{label="图9-94 先把环数齐，再认大脑中动脉不在环上"}
环上能数到：前交通、左前、左颈内、左后交通、左后、右后、右后交通、右颈内、右前。大脑中动脉从颈内动脉向外进外侧沟，豆纹动脉从它近段垂直向上，高血压出血常打在这一支。
:::

### （三）脑脊液及其循环

脑脊液（cerebrospinal fluid，CSF）是充满脑室系统、蛛网膜下隙和脊髓中央管的无色透明液体，含无机离子、葡萄糖、微量蛋白和少量淋巴细胞，pH 7.4。成人总量平均约 **150 ml**，对中枢起缓冲、保护、运输代谢产物和调节颅内压等作用，处于不断产生、循环和回流的平衡中。

脑脊液主要由脑室脉络丛产生，少量由室管膜上皮和毛细血管产生。循环路径：

**侧脑室脉络丛 → 室间孔 → 第三脑室**（汇合第三脑室脉络丛产生的脑脊液）**→ 中脑导水管 → 第四脑室**（再汇合第四脑室脉络丛产生的脑脊液）**→ 第四脑室正中孔和两个外侧孔 → 蛛网膜下隙**（先到小脑延髓池等，再流向大脑背面）**→ 蛛网膜粒 → 硬脑膜窦（主要是上矢状窦）→ 静脉血**。

途中阻塞可致脑积水，颅内压升高，脑组织受压移位甚至脑疝。

:::definition{label="脑脊液循环"}
脉络丛产生 → 侧脑室 → 室间孔 → 第三脑室 → 中脑导水管 → 第四脑室 → 正中孔及成对外侧孔 → 蛛网膜下隙 → 蛛网膜粒 → 上矢状窦等硬脑膜窦。成人约 150 ml。缺室间孔、导水管或正中孔/外侧孔任何一站，上游都会积水。
:::

::figure{src="/images/anatomy/textbook/p0356_01.png" caption="图9-102　脑脊液循环模式图" alt="侧脑室脉络丛经室间孔入第三脑室，经中脑导水管到第四脑室，经正中孔入小脑延髓池及蛛网膜下隙，向上经蛛网膜粒入上矢状窦；并标交叉池、脚间池、桥池和终池"}

:::cause-effect{title="循环路上堵住为什么会脑疝"}
- **因** 脑脊液持续产生，必须沿室间孔 → 导水管 → 第四脑室孔 → 蛛网膜粒回流
- **果** 任一狭窄处阻塞即上游积水、颅压升高，海马旁回和钩可疝入小脑幕切迹，扁桃体可疝入枕骨大孔

腰穿抽的是终池里已经出了第四脑室的脑脊液，不是侧脑室里的。
:::

:::insight{label="图9-102 顺着白箭头从侧脑室走到上矢状窦"}
先找室间孔和导水管这两处细颈，再找出第四脑室正中孔进小脑延髓池。大脑背面那一层蓝的是窦，蛛网膜粒把脑脊液渗进去。终池在最下端，腰穿从这里进。
:::

### （四）脑屏障

中枢内对物质在毛细血管或脑脊液与脑组织间转运加以限制或选择的结构，称脑屏障。它维持神经元微环境中氧、有机物和无机离子的稳定。脑屏障包括 3 个部分。

:::compare{title="脑屏障三道"}
| | 血-脑屏障（BBB） | 血-脑脊液屏障 | 脑脊液-脑屏障 |
|--|------------------|---------------|----------------|
| 位置 | 血液 ↔ 脑、脊髓神经细胞 | 脉络丛血液 ↔ 脑脊液 | 脑室和蛛网膜下隙的脑脊液 ↔ 神经细胞 |
| 结构基础 | 连续型无窗孔毛细血管内皮 + 紧密连接；完整基膜；星形胶质细胞胶质膜 | 脉络丛上皮细胞之间的闭锁小带（紧密连接）。内皮本身有窗孔 | 室管膜上皮、软脑膜和软膜下胶质膜 |
| 效能 | 限制大分子 | 有一定通透性 | 屏障作用低；脑脊液成分与脑细胞外液大致相同 |

:::

::figure{src="/images/anatomy/textbook/p0357_01.png" caption="图9-103　脑屏障的结构和位置关系" alt="模式图：a 血-脑屏障在无窗孔内皮、基膜和星形胶质胶质膜；b 血-脑脊液屏障在有窗孔的脉络丛内皮与上皮闭锁小带之间；c 脑脊液-脑屏障在室管膜、软脑膜和胶质膜；N 为神经元，AS 为星形胶质细胞，CSF 为脑脊液"}

脑屏障保证神经细胞有相对稳定的微环境。外伤、炎症或血管病可使通透性改变，导致脑水肿、脑出血、免疫异常。屏障作用是相对的：松果体、神经垂体等处缺乏血-脑屏障，毛细血管内皮有窗孔；脑脊液与脑细胞外液能相互交通。这种相对性使神经、免疫和内分泌三大调节系统的物质能够相互调节，形成神经-免疫-内分泌网络。

:::pitfall{label="三道屏障不要合成「就是血脑屏障」"}
BBB 管的是血和神经元之间；脉络丛那一层管的是血和脑脊液；室管膜和软膜管的是脑脊液和脑。写成只有一道 BBB，图9-103 的 a、b、c 三支箭头对不上。
:::
