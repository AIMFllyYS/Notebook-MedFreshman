# 五、 解剖学姿势、方位术语与人体的轴和面

前四节已经把这门课的户头、分科、年表和九大系统立住。本节只回答另一问：位置关系用哪一套**公认语法**来写。人体各部与器官结构的位置关系不是恒定不变的，为了准确描述人体各器官的形态结构和位置，需要有公认的标准和规范的描述，以便统一认识，避免混淆与理解错误。因此，确立了解剖学姿势，形成了轴、面和方位等术语。这些概念和术语是学习解剖学必须遵循的基本原则。变异与畸形留给第六节，学习方法留给第七节。

:::concept{term="先把身体摆成解剖学姿势，再问上/下、前/后、内/外，最后才问轴和面"}
看见「在哪里」，先不要用日常站姿或标本在桌上的摆法开口。先把被观察的客体还原成标准解剖学姿势：身体直立、面向前、两眼平视、足尖向前、上肢下垂、掌心向前。所有方位术语都以此为准。再问：这对词量的是距颅/足、距腹/背、距正中矢状面，还是距内腔、距体表、距肢体根部。轴和面是另一套互相垂直的坐标，用来写形态和关节运动，不要和方位词并成一串同义词。
:::

:::note{label="本节两张教学插图"}
本版绪论的教学插图从这里才出现：绪图-1 常用方位术语，绪图-2 人体的轴和面。不要把编委肖像或封面图误嵌进来。器官切面只用纵切/横切，不把人体的冠状面、矢状面、水平面直接套到器官自身的长轴上。
:::

## 一、为什么必须先立姿势和术语

第一节把「位置与毗邻」写成学习目的的独立一笔；本节给出写位置的语法。没有这套语法，九大系统里每一个器官都无法被统一描述：同一颗心，仰卧标本上「朝上」的面，换成站立的活体就不再朝上。公认标准的作用，是让不同体位、不同标本、不同作者说的是同一套方向。

:::definition{label="公认标准和规范描述"}
人体各部与器官结构的位置关系不是恒定不变的。要准确描述形态结构和位置，必须有公认的标准和规范的描述，以便统一认识，避免混淆与理解错误。解剖学姿势、方位术语、轴和面，就是这套标准。
:::

:::definition{label="必须遵循的基本原则"}
解剖学姿势、轴、面和方位等术语，是学习解剖学必须遵循的基本原则。不是「方便记忆的口诀」，也不是可选用、可不用的修辞。后文每一章的上/下、前/后、内侧/外侧，都默认已经站在这套原则上。
:::

:::pitfall{label="不要用标本在桌上的摆法当方向"}
尸体可俯卧、仰卧、横放或倒置；离体器官可以单独放在托盘里。描述时仍按人体的标准解剖学姿势，不按「此刻哪一面朝向天花板」。写成「朝上的就是上面」，换一个体位整段描述都会反号。
:::

:::insight{label="语法先于各论"}
运动系统的骨面、关节运动，内脏的毗邻，血管神经的走行，断层影像的断面，用的都是本节这套词。把本节听成「绪论里的名词表，考完可忘」，第一章起所有方位都会失去参照。
:::

:::compare{title="本节三套词各管什么"}
| 套 | 管什么 | 不负责什么 |
|----|--------|------------|
| 解剖学姿势 | 描述时的标准体位 | 病人实际采取的体位、手术体位 |
| 方位术语 | 一个结构相对另一个结构的远近（上/下、前/后、内/外、浅/深等） | 关节绕哪根轴转 |
| 轴和面 | 人体互相垂直的三轴、三面；器官自身的纵切/横切 | 把「上面」改名为「垂直轴」 |

三套词叠在同一具人体上，但尺子不同，不能并户。
:::

## 二、解剖学姿势

人体的标准解剖学姿势（anatomical position）是指身体直立，面向前方，两眼平视正前方，两足并拢，足尖向前，双上肢下垂于躯干的两侧，掌心向前。描述任何人体结构时，均应以此姿势为标准，即使被观察的客体、标本或模型是俯卧位、仰卧位、横位或倒置，或只是身体的一个局部，仍应按人体的标准解剖学姿势进行描述。

:::definition{label="人体的标准解剖学姿势"}
身体直立，面向前方，两眼平视正前方，两足并拢，足尖向前，双上肢下垂于躯干的两侧，掌心向前。英文 anatomical position。所有方位术语、轴和面，都以此姿势为基准。
:::

:::keypoint{label="解剖学姿势六件事，缺一不可"}
- 身体直立。
- 面向前方。
- 两眼平视正前方。
- 两足并拢，足尖向前。
- 双上肢下垂于躯干的两侧。
- 掌心向前。
:::

:::definition{label="即使客体不是这个姿势，仍按这个姿势描述"}
被观察的可以是俯卧、仰卧、横位、倒置，也可以只是身体的一个局部（离体的肝、单独的肱骨、影像上的一个断面）。描述时仍把它们放回标准解剖学姿势里说上/下、前/后。局部标本没有「此刻哪边朝上」，只有「在完整人体上它朝哪」。
:::

:::pitfall{label="日常自然站立不是解剖学姿势"}
日常站立时上肢下垂、掌心朝向大腿，拇指朝前。解剖学姿势要求**掌心向前**，于是桡骨在外侧、尺骨在内侧，拇指在外侧。漏掉「掌心向前」，前臂的尺侧/桡侧会和内侧/外侧对错号，绪图-1 上「内侧或尺侧」「外侧或桡侧」也会读反。
:::

:::pitfall{label="两足并拢、足尖向前，不要写成外八字站姿"}
足尖向前、两足并拢，才使下肢的胫侧朝向正中矢状面、腓侧远离正中矢状面。写成随便站，胫侧/腓侧与内侧/外侧的对应会漂。
:::

:::insight{label="掌心向前是为了把前臂的骨和方位钉死"}
掌心向前之后，前臂处于旋后位：桡骨在外侧，尺骨在内侧。后面凡是说「桡侧」「尺侧」，都是在这根钉子上量，而不是在「手怎么转」上量。旋前、旋后是第一章关节运动的落点，本节先把基准钉住。
:::

:::compare{title="解剖学姿势 vs 几种常见误用"}
| | 解剖学姿势 | 误用 |
|--|------------|------|
| 躯干 | 直立 | 用仰卧标本的「上方」当人体的上方 |
| 面部与眼 | 面向前方，两眼平视正前方 | 头转向一侧再描述「前」 |
| 足 | 并拢，足尖向前 | 外八字或足尖向外 |
| 上肢 | 下垂于躯干两侧，**掌心向前** | 掌心贴大腿的自然下垂 |
| 局部标本 | 仍按完整人体的标准姿势描述 | 按托盘上哪一面朝观察者 |

手术体位、检查体位是临床另立的，不取代解剖学姿势。
:::

:::cause-effect{title="为什么局部也要按整个人体来描述"}
- **因** 方位词的参照是颅顶与足底、腹侧面与背侧面、正中矢状面、体表和肢体根部，这些参照只存在于完整人体的标准姿势里
- **果** 一块单独的肱骨、一张仰卧的 CT，仍然要说近侧/远侧、前/后，而不能改口说「靠近桌子的那一端」
:::

## 三、方位术语

按照人体的标准解剖学姿势，又规定了一些表示方位的术语（绪图-1）。方位词都是**相对**关系：说的是这个结构距某个参照更近还是更远，不是结构自己身上贴的绝对标签。

::figure{src="/images/anatomy/textbook/p0031_01.png" caption="绪图-1　常用方位术语。人体取解剖学姿势：上/下，前或腹侧与后或背侧，近侧/远侧，内侧或尺侧与外侧或桡侧，内侧或胫侧与外侧或腓侧；肠管断面示内/外，大腿断面示浅/深。" alt="左上为肠管断面，由内向外标上皮、黏膜、黏膜下层、环行肌、纵行肌、外膜；左下为大腿断面，浅层为皮肤与浅筋膜，深层为肌、股骨与坐骨神经；中为解剖学姿势正面人体，标上、下、近侧、远侧、手掌面、尺桡侧与胫腓侧；右为侧面观，标后或背侧、前或腹侧"}

### （一）上和下

上（superior）和下（inferior）是描述器官或结构距颅顶或足底的相对远近关系的术语。近颅者为上，近足者为下。如眼位于鼻的上方，而口位于鼻的下方。比较解剖学常用颅侧（cranial）和尾侧（caudal）作为对应名词。

:::definition{label="上 superior"}
近颅顶者为上。参照是颅顶，不是「此刻朝向天花板的那一侧」。
:::

:::definition{label="下 inferior"}
近足底者为下。参照是足底。口在鼻的下方，是因为口比鼻更近足，不是因为口在画面的下缘。
:::

:::definition{label="颅侧 cranial 与尾侧 caudal"}
比较解剖学常用的对应名词：近颅为颅侧，近尾为尾侧。人体解剖学日常描述用上/下；在胚胎、比较解剖或需要强调头尾轴时，才会改口称颅侧/尾侧。不要把四对词当成四套互不相干的方向。
:::

:::pitfall{label="仰卧时「朝上」不等于解剖学的上"}
病人仰卧，胸廓前壁朝向天花板，那是**前**，不是上。上仍是近颅的方向。把 CT 报告里的「上方」听成「靠近床头或靠近天花板」，心脏、肝、肾的上下极都会说反。
:::

### （二）前和后，腹侧和背侧

前（anterior）和后（posterior）是描述器官或结构距身体前、后面相对远近关系的术语。距身体腹侧面近者为前，也称为腹侧（ventral）；距身体背侧面近者为后，也称为背侧（dorsal）。如眼在前，耳在后。

:::definition{label="前 anterior"}
距身体腹侧面近者为前。腹侧面是胸腹部这一面，不是「观察者面对的那一面」。
:::

:::definition{label="后 posterior"}
距身体背侧面近者为后。
:::

:::definition{label="腹侧 ventral"}
前的同义说法，强调距腹侧面近。人体直立时腹侧即前；四足动物腹侧朝向地面，这时腹侧不再等于「上方」。
:::

:::definition{label="背侧 dorsal"}
后的同义说法，强调距背侧面近。
:::

:::compare{title="前 / 后 与 腹侧 / 背侧"}
| | 前 anterior | 后 posterior |
|--|-------------|--------------|
| 参照 | 距腹侧面近 | 距背侧面近 |
| 同义 | 腹侧 ventral | 背侧 dorsal |
| 本版举例 | 眼在前 | 耳在后 |
| 不要听成 | 画面左边、观察者对面 | 画面右边、背对观察者 |

人体取解剖学姿势时，前＝腹侧，后＝背侧。换到比较解剖或胚胎，腹侧/背侧这组词更稳。
:::

:::insight{label="绪图-1 右侧面观把前/后画成腹/背"}
侧面人体上标的是「前或腹侧」「后或背侧」：胸腹部朝前，背部朝后。正面人体上看不见这组词，必须转到侧面。读图时正面管上/下、内/外、近/远，侧面管前/后。
:::

### （三）内侧和外侧

内侧（medial）和外侧（lateral）是描述器官或结构距人体正中矢状面相对远近关系的术语。距人体正中矢状面近者为内侧，远离正中矢状面者为外侧。如眼位于鼻的外侧、耳的内侧。

:::definition{label="内侧 medial"}
距人体正中矢状面近。正中矢状面是把人体分成左右对等两部的那个矢状面，本节后面才正式定义；这里先把它当成「左右的中线」。
:::

:::definition{label="外侧 lateral"}
远离正中矢状面。眼在鼻的外侧，因为眼比鼻更远离中线；眼又在耳的内侧，因为眼比耳更靠近中线。同一只眼，相对不同参照，内侧、外侧都可以成立。
:::

:::pitfall{label="内侧/外侧是相对正中矢状面，不是相对「身体中心器官」"}
不要把「靠近心」写成内侧、「靠近体表」写成外侧。靠近体表的是浅，靠近内腔的是内。内侧只问：离左右中线近不近。
:::

:::insight{label="方位词永远带着参照物"}
「眼在鼻的外侧、耳的内侧」说明：离开参照物，方位词没有意义。后文写「肱骨内侧髁」「股骨外侧髁」，默认参照仍是正中矢状面，不是这块骨自己的中心。
:::

### （四）内和外：不要和内侧、外侧并户

内（internal）和外（external）是描述体腔或空腔器官相互位置关系的术语。近内腔者为内，离内腔远者为外。内、外与内侧、外侧是两种完全不同含义的解剖学术语，初学者一定要注意区别。

:::definition{label="内 internal"}
近内腔者为内。内腔可以是体腔（胸腔、腹腔），也可以是空腔器官的腔（肠腔、血管腔、心腔）。
:::

:::definition{label="外 external"}
离内腔远者为外。肠管断面上，黏膜近腔为内，外膜远离腔为外——这正是绪图-1 左上角在画的那一笔。
:::

:::compare{title="内/外 vs 内侧/外侧"}
| | 内 / 外 | 内侧 / 外侧 |
|--|---------|-------------|
| 英文 | internal / external | medial / lateral |
| 参照 | 体腔或空腔器官的**内腔** | 人体**正中矢状面** |
| 问的是 | 离腔近还是远 | 离左右中线近还是远 |
| 绪图-1 落点 | 肠管断面的「内外」 | 正面人体的内侧/外侧（及尺桡、胫腓） |
| 典型说法 | 黏膜在内、外膜在外；胸腔内、胸腔外 | 眼在鼻的外侧；尺侧对应内侧 |

两套词汉字只差一个「侧」字，含义完全不同。
:::

:::pitfall{label="内、外与内侧、外侧不要互换"}
「胃内」指近胃腔；「胃的内侧」指胃相对正中矢状面更靠近中线的那一侧。血管「内膜」是近管腔的一层，不是「内侧的膜」。教材把这一对单独警告初学者，就是因为并户之后所有中空器官的层次都会写乱。
:::

### （五）浅和深

浅（superficial）和深（profundal）是描述器官或结构距皮肤表面相对远近的术语。距体表近者为浅，远离体表者为深。

:::definition{label="浅 superficial"}
距皮肤表面近。浅筋膜、浅静脉、皮神经，都是在「近体表」这把尺子上命名的。
:::

:::definition{label="深 profundal"}
远离皮肤表面。深筋膜、深部的肌、骨和坐骨神经，都比浅筋膜更远离体表。本版英文用 profundal。
:::

:::note{label="绪图-1 左下角的大腿断面"}
大腿断面用「深浅」这一对：皮肤、浅筋膜近体表为浅；穿深筋膜以后的肌、股骨、坐骨神经为深。大隐静脉走在浅筋膜里，股动、静脉走在深部——同一断面上，浅静脉和深血管不要并成「都是腿上的血管」。
:::

:::pitfall{label="浅/深不是内/外，也不是上/下"}
浅/深的参照是**皮肤表面**。把「深」听成「里面的腔」，会和内/外打架；把「浅」听成「上面」，会和上/下打架。背部的皮肤仍然是浅，尽管它在人体的后面。
:::

:::compare{title="三把容易并户的尺子"}
| 词对 | 参照 | 典型画面（绪图-1） |
|------|------|-------------------|
| 上 / 下 | 颅顶 / 足底 | 正面人体最上与最下 |
| 内 / 外 | 内腔 | 肠管断面由黏膜到外膜 |
| 浅 / 深 | 皮肤表面 | 大腿断面由皮肤到骨 |
| 内侧 / 外侧 | 正中矢状面 | 正面人体四肢标注 |

四对词可以同时成立：股骨相对皮肤是深，相对髓腔壁可以谈内/外，相对正中矢状面有内侧外侧，相对颅顶是下。
:::

### （六）近侧和远侧

近侧（proximal）和远侧（distal）是描述器官或结构距肢体根部相对远近的术语，常用于四肢。距肢体根部近者为近侧，远离肢体根部者为远侧。

:::definition{label="近侧 proximal"}
距肢体根部近。上肢根部在肩，下肢根部在髋。臂相对前臂是近侧，大腿相对小腿是近侧。
:::

:::definition{label="远侧 distal"}
远离肢体根部。手相对前臂是远侧，足相对小腿是远侧。绪图-1 在上肢标出近侧（近肩）和远侧（近手）。
:::

:::pitfall{label="近侧/远侧不要用来写躯干的上/下"}
躯干近颅为上、近足为下。把「胃的近侧」随口说成「上面」，和四肢术语混用。本版明文：近侧和远侧常用于四肢，参照是肢体根部。
:::

:::insight{label="绪图-1 把近侧、远侧和手掌面画在同一只上肢上"}
近侧在上臂近肩处，远侧在前臂近手处，手掌面朝前——这正是解剖学姿势里掌心向前的落点。读图时把这三笔当成一句：上肢下垂、掌心向前，再量距肩的远近。
:::

### （七）尺侧和桡侧，胫侧和腓侧

上肢的尺侧（ulnar）和桡侧（radial）、下肢的胫侧（tibial）和腓侧（fibular）分别与其内侧和外侧相对应，是根据前臂桡骨、尺骨和小腿胫骨、腓骨的位置，描述前臂和小腿与正中矢状面相对位置的关系术语。在前臂，距尺骨近者为尺侧，距桡骨近者为桡侧；在小腿，距胫骨近者为胫侧，距腓骨近者为腓侧。

:::definition{label="尺侧 ulnar"}
前臂距尺骨近的一侧。解剖学姿势下尺骨在内侧，故尺侧与内侧相对应。
:::

:::definition{label="桡侧 radial"}
前臂距桡骨近的一侧。解剖学姿势下桡骨在外侧，故桡侧与外侧相对应。
:::

:::definition{label="胫侧 tibial"}
小腿距胫骨近的一侧。胫骨在内侧，胫侧与内侧相对应。
:::

:::definition{label="腓侧 fibular"}
小腿距腓骨近的一侧。腓骨在外侧，腓侧与外侧相对应。
:::

:::compare{title="四肢特有的骨侧名称，对应内侧/外侧"}
| 部位 | 近正中矢状面（内侧） | 远离正中矢状面（外侧） | 依据的骨 |
|------|----------------------|------------------------|----------|
| 前臂 | 尺侧 ulnar | 桡侧 radial | 尺骨、桡骨 |
| 小腿 | 胫侧 tibial | 腓侧 fibular | 胫骨、腓骨 |
| 通用（四肢） | 近侧 → 根部 | 远侧 → 游离端 | 肢体根部 |

绪图-1 的写法是「内侧或尺侧」「外侧或桡侧」「内侧或胫侧」「外侧或腓侧」：两套词在解剖学姿势下重合。
:::

:::pitfall{label="尺桡、胫腓是按骨的位置，不要在旋前以后改口"}
前臂旋前时桡骨交叉到尺骨前方，手背朝前，但「桡侧」仍是距桡骨近的一侧，不改成「现在的内侧」。这正是专门造尺侧/桡侧的理由：骨的名称比「此时哪边靠中线」更稳。基准仍然是解剖学姿势（掌心向前）。
:::

:::keypoint{label="方位术语按参照分组记"}
- 颅顶 / 足底 → 上、下（比较解剖：颅侧、尾侧）。
- 腹侧面 / 背侧面 → 前＝腹侧，后＝背侧。
- 正中矢状面 → 内侧、外侧。
- 内腔 → 内、外（≠ 内侧、外侧）。
- 皮肤表面 → 浅、深。
- 肢体根部 → 近侧、远侧。
- 前臂骨 / 小腿骨 → 尺侧与桡侧、胫侧与腓侧（对应内侧与外侧）。
:::

## 四、轴

轴和面是描述人体器官的形态，尤其是描述关节运动时常用的术语。人体可设有互相垂直的 3 种轴，即垂直轴、矢状轴和冠状轴；依据上述 3 种轴，人体还可设有互相垂直的 3 种面，即矢状面、冠状面和水平面（绪图-2）。

::figure{src="/images/anatomy/textbook/p0031_02.png" caption="绪图-2　人体的轴和面。互相垂直的三个面：矢状面、冠状面、水平面；互相垂直的三轴：垂直轴、矢状轴、冠状轴。" alt="解剖学姿势人体：紫色矢状面把身体分成左右，蓝色冠状面分成前后，绿色水平面分成上下；右下三箭头标冠状轴、矢状轴和垂直轴"}

:::definition{label="轴和面的用途"}
描述人体器官的形态，尤其是描述关节运动时常用。三轴互相垂直，三面互相垂直；面是依据轴设出来的。不是给器官另起一套与人体无关的坐标。
:::

:::definition{label="垂直轴 vertical axis"}
上自头侧，下至尾侧，并与地平面（水平面）相垂直的轴。直立时即头尾方向的轴。关节沿垂直轴作的运动，后文称为旋转。
:::

:::definition{label="矢状轴 sagittal axis"}
从腹侧面至背侧面，同时与垂直轴呈直角交叉的轴，又名腹背轴。前–后方向，与地面平行。关节沿矢状轴作的运动，后文多称为收和展。
:::

:::definition{label="冠状轴 frontal axis"}
为左、右方向，与水平面平行，与前两个轴相垂直的轴。英文 frontal axis。关节沿冠状轴作的运动，后文多称为屈和伸。
:::

:::compare{title="三轴"}
| 轴 | 英文 | 方向 | 与谁垂直 | 别名 / 提醒 |
|----|------|------|----------|-------------|
| 垂直轴 | vertical axis | 头侧 → 尾侧 | 与地平面（水平面）垂直 | 不是「前后的轴」 |
| 矢状轴 | sagittal axis | 腹侧 → 背侧 | 与垂直轴呈直角 | 又名腹背轴 |
| 冠状轴 | frontal axis | 左 → 右 | 与水平面平行，与前两轴垂直 | 不要听成「只存在于头部」 |

三轴过同一原点时构成直角坐标系。任一轴都与另外两轴垂直。
:::

:::pitfall{label="矢状轴不是矢状面，冠状轴不是冠状面"}
轴是一条线，面是一张平面。矢状轴是前–后的线，矢状面是前–后展开、把人体分成左右的面——面里含有矢状轴和垂直轴，并与冠状轴垂直。名字共享「矢状」「冠状」，几何对象不是同一个。
:::

:::note{label="后文骨连结会用三轴写运动，本节只立轴"}
滑膜关节的运动形式基本上是沿三个互相垂直的轴作运动：通常，屈和伸沿冠状轴，收和展沿矢状轴，旋转沿垂直轴。拇指、膝关节、足的屈伸有本版写明的例外，那是第一章的账。本节只要求能指认三轴的方向。
:::

:::insight{label="绪图-2 右下角的三箭头就是三轴"}
垂直轴上下，矢状轴前后，冠状轴左右。三个面穿在人体上：紫色矢状面、蓝色冠状面、绿色水平面。轴在交点上，面在人体上，读图时先对箭头、再对色块。
:::

## 五、面

### （一）矢状面与正中矢状面

矢状面（sagittal plane）是指前、后方向，将人体分成左、右两部的剖面，该切面与地平面垂直。经过人体正中的矢状面称为正中矢状面，它将人体分成左、右对等的两部分。

:::definition{label="矢状面 sagittal plane"}
前、后方向展开，把人体分成左、右两部，并与地平面垂直。可以有许多张彼此平行的矢状面；只有正中那一张左右对等。
:::

:::definition{label="正中矢状面"}
经过人体正中的矢状面，将人体分成左、右**对等**的两部分。内侧、外侧的参照就是这张面：近它为内侧，远它为外侧。
:::

:::pitfall{label="不是所有矢状面都把人体分成对等的左右"}
只有正中矢状面左右对等。偏左或偏右的矢状面仍是矢状面，仍分出左、右两部，但两部不对等。把「矢状面」一律听成「左右各一半」，正中矢状面这个专名就没有独立户头了。
:::

### （二）冠状面

冠状面（frontal plane）是指左、右方向，将人体分为前、后两部的剖面，该切面与水平面及矢状面互相垂直。

:::definition{label="冠状面 frontal plane"}
左、右方向展开，把人体分成前、后两部；与水平面、矢状面都垂直。英文与冠状轴一样用 frontal。
:::

:::pitfall{label="冠状面分的是前和后，不是左和右"}
「冠状」容易让人想到从头顶套下来的冠，误以为切的是左右。本版定义写得很死：左、右方向的剖面，分成的是前、后两部。分成左右的是矢状面。
:::

### （三）水平面

水平面（horizontal plane）又称横切面，是指与地平面平行，与矢状面和冠状面相互垂直，将人体分为上、下两部的剖面。

:::definition{label="水平面 horizontal plane"}
与地平面平行，与矢状面、冠状面相互垂直，把人体分成上、下两部。在人体上又称横切面。
:::

:::pitfall{label="人体的横切面 ≠ 器官的横切面"}
水平面在人体可称横切面，因为它与头尾轴（垂直轴）垂直。描述**器官**切面时，横切面改以器官自身的长轴为标准，见下一小节。两处都叫「横切」，参照不同。
:::

:::compare{title="三面"}
| 面 | 英文 | 展开方向 | 把人体分成 | 与谁垂直 |
|----|------|----------|------------|----------|
| 矢状面 | sagittal plane | 前–后 | 左、右两部 | 与地平面垂直 |
| 正中矢状面 | — | 经过正中的矢状面 | 左、右**对等**两部 | 同上 |
| 冠状面 | frontal plane | 左–右 | 前、后两部 | 与水平面及矢状面垂直 |
| 水平面 | horizontal plane | 与地平面平行 | 上、下两部 | 与矢状面、冠状面垂直；人体上又称横切面 |
:::

:::compare{title="轴与面如何配套"}
| 面 | 面内主要含哪两轴 | 该面与哪一轴垂直 |
|----|-------------------|-------------------|
| 矢状面 | 垂直轴、矢状轴 | 冠状轴 |
| 冠状面 | 垂直轴、冠状轴 | 矢状轴 |
| 水平面 | 矢状轴、冠状轴 | 垂直轴 |

「依据三轴设三面」指的就是这张配套表：每个面垂直于一根轴，包含另外两根。
:::

:::keypoint{label="三轴三面互相垂直"}
- 轴：垂直轴、矢状轴（腹背轴）、冠状轴。
- 面：矢状面（含正中矢状面）、冠状面、水平面（横切面）。
- 正中矢状面：左右对等；内侧/外侧以它为参照。
- 后文关节：屈伸多沿冠状轴，收展多沿矢状轴，旋转沿垂直轴。
:::

## 六、器官切面：纵切和横切，不要套人体的三面

在描述器官切面时，常以器官自身的长轴为标准，与其长轴平行的切面称为纵切面，与其长轴垂直的切面称为横切面，而不用冠状面、矢状面和水平面来描述。

:::definition{label="纵切面"}
与器官自身长轴平行的切面。长轴弯、斜、横卧都可以，纵切跟着器官走，不跟着人体的垂直轴走。
:::

:::definition{label="器官的横切面"}
与器官自身长轴垂直的切面。肠管断面、大腿断面在绪图-1 里画的就是这一类：垂直于管道或肢体的长轴，用来展示层次（内/外、浅/深）。
:::

:::pitfall{label="不要用冠状面、矢状面、水平面去套器官自身"}
肾的长轴并不等于人体垂直轴，胃的长轴更不是前后方向的矢状轴。说「胃的矢状切」会把人体坐标强加给器官。本版规定：器官只用纵切、横切。人体三面留给人体，器官两切留给器官。
:::

:::compare{title="人体的面 vs 器官的切面"}
| | 参照 | 名称 | 禁止的说法 |
|--|------|------|------------|
| 人体 | 解剖学姿势下的三轴 | 矢状面、冠状面、水平面（横切面） | 用器官长轴改定义人体的面 |
| 器官 | 该器官自身的长轴 | 纵切面、横切面 | 用冠状/矢状/水平去叫器官切面 |

绪图-1 的肠管断面、大腿断面，是器官/局部的横切，用来讲内/外、浅/深；绪图-2 的三色块，是人体的三面。
:::

:::cause-effect{title="为什么器官要另立纵切/横切"}
- **因** 器官长轴可以倾斜、弯曲、横走，并不与人体三轴重合
- **果** 若把人体的冠状面、矢状面、水平面直接套上去，同一器官在不同个体、不同充盈状态下「切面名称」会跟着漂；用自身长轴，层次和管腔关系才稳定
:::

:::insight{label="断层影像仍用人体的三面，标本上的器官另说"}
CT、MRI 的横断、冠状、矢状是按人体坐标切的，那是第二节 X 线解剖学、断层解剖学的语言，和绪图-2 一致。拿在手里的肾、切开的肠管，改用纵切/横切。两种场合都对，参照不同。
:::

:::memory{label="本节必背要点"}
- [ ] 标准解剖学姿势：身体直立，面向前方，两眼平视正前方，两足并拢，足尖向前，双上肢下垂于躯干两侧，掌心向前。
- [ ] 任何体位、任何局部，描述时仍按解剖学姿势。
- [ ] 上 / 下：近颅为上，近足为下；比较解剖用颅侧 / 尾侧。
- [ ] 前 / 后：近腹侧面为前（腹侧），近背侧面为后（背侧）。
- [ ] 内侧 / 外侧：距正中矢状面近为内侧，远为外侧。
- [ ] 内 / 外：近内腔为内，离内腔远为外；与内侧 / 外侧完全不同。
- [ ] 浅 / 深：距皮肤近为浅，远离皮肤为深。
- [ ] 近侧 / 远侧：常用于四肢，距肢体根部近为近侧，远为远侧。
- [ ] 尺侧 / 桡侧、胫侧 / 腓侧分别与内侧 / 外侧相对应。
- [ ] 三轴：垂直轴、矢状轴（腹背轴）、冠状轴，互相垂直。
- [ ] 三面：矢状面、冠状面、水平面（横切面），互相垂直。
- [ ] 正中矢状面将人体分成左右对等的两部分。
- [ ] 器官切面以自身长轴为准：平行为纵切，垂直为横切；不用冠状 / 矢状 / 水平去套器官。
- [ ] 绪图-1 方位术语，绪图-2 轴和面。
:::
