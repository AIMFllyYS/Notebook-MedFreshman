# 第二节　肺

第一节已经把呼吸道从鼻写到左、右主支气管。本节把呼吸系统的第二户——**肺**——从胸腔里的外形落到叶、段和两套血管。主支气管的长短粗细、嵴下角和「异物多入右主支气管」以第一节为准，这里不再抄第二遍；胸膜腔、胸膜隐窝和肺的下界投影留给第三节，纵隔留给第四节。本节的正业是五件事：肺在纵隔两侧长什么样、左二叶右三叶怎么裂、支气管树怎样进到肺泡、支气管肺段按本版怎样数、功能性血管和营养性血管怎样分户。

呼吸系统由呼吸道和肺组成。肺本身又分成**肺实质**和**肺间质**：实质是支气管树加肺泡，间质是结缔组织、血管、淋巴管、淋巴结和神经。气体交换发生在肺泡，管道和血管都要在肺门进出——外形上的一尖、一底、三面、三缘，就是为了把肺门和叶间裂摆到能摸、能切的位置上。

:::concept{term="先问这是左肺还是右肺，再问几叶几段，最后才问这根管子是换气的还是养肺的"}
看见「肺」，先不要默写段号。先问：左还是右——右肺宽而短、三叶，左肺狭而长、二叶，心切迹和小舌只在左肺。再问裂：斜裂两肺都有，水平裂只在右肺。然后才问段：通常左右各 10 段，左肺可以因为共干变成 8 段。最后问血管：肺动脉、肺静脉是功能性的，支气管动脉是营养性的。把鼻、喉、气管从第一节整段搬过来，或者把胸膜腔写进本节，户头就并了。
:::

:::definition{label="肺"}
位于胸腔内、纵隔两侧的一对实质性器官，分左肺和右肺。生活状态下呈浅红色，质软、海绵状、富有弹性。表面覆盖脏胸膜。功能的第一笔是气体交换；发音、嗅觉不在肺这一户。
:::

:::definition{label="肺实质"}
支气管树和肺泡。气体进出和气体交换都落在这一户里。
:::

:::definition{label="肺间质"}
肺内的结缔组织、血管、淋巴管、淋巴结和神经。它不是「肺的废物」，肺根里进出的管道有相当一部分属于间质。
:::

## 一、肺的位置和形态

肺（lung）位于胸腔内，纵隔的两侧，分为左肺和右肺。肺的表面覆盖脏胸膜，透过胸膜可见许多呈多角形的小区，称为**肺小叶**（pulmonary lobule）；肺小叶感染即临床所说的小叶性肺炎。生活状态下的正常肺呈浅红色，质柔软呈海绵状，富有弹性。一般成人肺的重量约等于本人体重的 1/50，男性平均为 1000～1300 g，女性平均为 800～1000 g。健康成年男性两肺的空气容量约为 5000～6500 ml，女性则小于男性。

:::definition{label="肺小叶"}
透过脏胸膜看见的多角形小区。它是肺表面能直接读到的结构单位。小叶感染称小叶性肺炎，不要把「看见小叶」写成已经发生了肺炎。
:::

:::pitfall{label="生活状态的肺是浅红、柔软、有弹性，标本上的灰黑色不是同一回事"}
本版把活体写成浅红色、海绵状、富有弹性。固定标本、长期吸入尘埃或吸烟后的颜色另见第二节后文。把标本上的深灰色当成「正常活体」，和触诊、影像上的含气肺对不上。
:::

:::compare{title="成人肺：重量和空气容量按本版"}
| | 本版数字 |
|--|----------|
| 重量约占体重 | 约 1/50 |
| 男性重量 | 平均 1000～1300 g |
| 女性重量 | 平均 800～1000 g |
| 健康成年男性两肺空气容量 | 约 5000～6500 ml |
| 女性空气容量 | 小于男性 |

重量和容量都是「约」「平均」，不要改写成一个定点。女性容量本版只写「小于男性」，没有另给毫升数。
:::

两肺外形不同：**右肺宽而短，左肺狭而长**。肺呈圆锥形，包括一尖、一底、三面、三缘（图3-18）。认肺先把这十个字摆上：尖、底、肋面、纵隔面、膈面、前缘、后缘、下缘——再在左肺前缘补心切迹和小舌，在右肺补水平裂。

:::definition{label="肺的外形通式"}
圆锥形，一尖、一底、三面、三缘。三面是肋面、纵隔面、膈面；三缘是前缘、后缘、下缘。左、右肺都按这套零件来认，差别写在叶数、裂和左肺前缘。
:::

::figure{src="/images/anatomy/textbook/p0154_02.png" caption="图3-18　肺的形态" alt="左、右肺前面观，示肺尖、肺底、右肺上中下叶与水平裂和斜裂、左肺上叶下叶与斜裂、心切迹和左肺小舌"}

### （一）肺尖和肺底

**肺尖**（apex of lung）即肺的上端，钝圆，经胸廓上口突入颈根部，达锁骨内侧 1/3 段上方 2～3 cm。颈根部的穿刺、麻醉或外伤，首先要想到肺尖已经高出锁骨，不是「肺都在胸廓里面」。

**肺底**（base of lung）即肺的下面，与膈相贴，受膈压迫呈半月形凹陷。肺底并不是一块平底：膈顶上来，底就被顶成凹面。膈面（diaphragmatic surface）说的就是这一面，和肺底是同一块地方的两个名字。

:::definition{label="肺尖"}
肺的上端，钝圆，经胸廓上口突入颈根部，达锁骨内侧 1/3 段上方 2～3 cm。
:::

:::definition{label="肺底"}
肺的下面，与膈相贴，受膈压迫呈半月形凹陷。与膈面是同一部位。
:::

:::pitfall{label="肺尖高出锁骨的是内侧 1/3 段上方 2～3 cm，不是锁骨中点"}
本版原句是锁骨**内侧 1/3 段**上方 2～3 cm。写成锁骨中点或锁骨全长上方，颈根部的危险区会平移。第三节胸膜顶的投影另有「胸锁关节与锁骨中、内 1/3 交界处」那一套数字，不要和肺尖这一句并成一个点。
:::

:::insight{label="肺底是凹的，因为膈顶是凸的"}
标本上把肺底摊平，会误以为底像杯子底。活体里膈向上隆，肺底被压成半月形凹陷。深吸气时膈下降，下缘跟着走——下缘位置随呼吸变化，这一笔在后文三缘里还要再用一次。
:::

### （二）三面

**肋面**（costal surface）即肺的外侧面，与胸廓的侧壁和前、后壁相邻。肋骨、肋间隙的压迹主要读这一面。

**纵隔面**（mediastinal surface）即内侧面，与纵隔相邻。中央的椭圆形凹陷称**肺门**（hilum of lung），或称第一肺门。肺门是支气管、血管、神经和淋巴管等出入的门户；这些结构被胸膜包绕，形成**肺根**（root of lung）（图3-19）。纵隔面上还有心压迹和一侧一条大血管或食管的压迹，后文单独列。

**膈面**即肺底，与膈相邻。三面里它最小，却是下缘随呼吸移动的那一面。

:::definition{label="肋面"}
肺的外侧面，邻胸廓的侧壁和前、后壁。
:::

:::definition{label="纵隔面"}
肺的内侧面，邻纵隔。中央椭圆形凹陷是肺门。
:::

:::definition{label="膈面"}
肺的下面，即肺底，邻膈，呈半月形凹陷。
:::

:::compare{title="三面各贴谁"}
| 面 | 朝向 | 贴什么 | 这一面要认出的结构 |
|----|------|--------|-------------------|
| 肋面 | 外 | 胸廓侧壁和前、后壁 | 外形轮廓、叶间裂在表面的走行 |
| 纵隔面 | 内 | 纵隔 | 肺门、肺根、心压迹、一侧的食管或主动脉压迹 |
| 膈面 | 下 | 膈 | 半月形凹陷；下缘随呼吸升降 |

:::

### （三）肺门和肺根

肺门是「门」，肺根是「从门里进出的那一把东西」。门在纵隔面中央；根被胸膜包绕，连到纵隔。图3-19 在肺根下方还能看见三角形的**肺韧带**，它的构成（脏、壁胸膜在肺根下方融合）留给第三节，本节只要求在肺根图上把这条皱襞认出来，不要和肺根里的支气管、血管并户。

:::definition{label="肺门"}
纵隔面中央的椭圆形凹陷，又称第一肺门。是支气管、血管、神经和淋巴管出入肺的门户。
:::

:::definition{label="肺根"}
出入肺门的支气管、血管、神经和淋巴管被胸膜包绕后形成的结构。它是「门里那一把东西」，不是肺门这个凹陷本身。
:::

两肺根内的结构排列，本版给了两套次序，必须分开背。

**自前向后**（左、右相同）：上肺静脉、肺动脉、主支气管、下肺静脉。

**自上而下**（左、右不同）：

- 左肺根：左肺动脉、左主支气管、左上肺静脉、左下肺静脉。
- 右肺根：右肺上叶支气管，右肺动脉，右肺中、下叶支气管，右上肺静脉和右下肺静脉。

右肺根最上头先露出的是**右肺上叶支气管**，而不是右肺动脉——右肺上叶支气管走在动脉上方，中、下叶支气管才走在动脉下方。左肺没有这一刀，最上头是左肺动脉，然后才是左主支气管。下肺静脉在两肺都偏后下，所以它既出现在「自前向后」的最后，也出现在「自上而下」的最下。

:::definition{label="肺根自前向后的次序"}
两肺相同：上肺静脉 → 肺动脉 → 主支气管 → 下肺静脉。
:::

:::definition{label="左肺根自上而下的次序"}
左肺动脉 → 左主支气管 → 左上肺静脉 → 左下肺静脉。
:::

:::definition{label="右肺根自上而下的次序"}
右肺上叶支气管 → 右肺动脉 → 右肺中、下叶支气管 → 右上肺静脉和右下肺静脉。
:::

::figure{src="/images/anatomy/textbook/p0154_01.png" caption="图3-19　肺根的结构" alt="右肺门前面观与左肺门前面观，示肺动脉、主支气管、上肺静脉、下肺静脉、迷走神经、肺韧带，以及右侧的奇静脉、食管和左侧的主动脉弓、左喉返神经"}

:::compare{title="肺根：前到后一套，上到下两套"}
| 方向 | 左肺根 | 右肺根 |
|------|--------|--------|
| 自前向后 | 上肺静脉、肺动脉、主支气管、下肺静脉 | 同左 |
| 自上而下 | 左肺动脉 → 左主支气管 → 左上肺静脉 → 左下肺静脉 | 右肺上叶支气管 → 右肺动脉 → 右肺中、下叶支气管 → 右上、下肺静脉 |
| 和支气管的上下关系 | 动脉在主支气管**上方** | 上叶支气管在动脉**上方**，中、下叶支气管在动脉**下方** |

前到后不要左右分家；上到下必须左右分家。把「静脉总在最前」理解成「静脉也总在最上」，右肺上叶支气管和左肺动脉两户都会排错。
:::

:::pitfall{label="不要用一句「动脉在支气管前面」同时回答前后和上下"}
自前向后：动脉在上肺静脉之后、主支气管之前，两肺一样。自上而下：左肺是动脉在支气管之上；右肺是上叶支气管在动脉之上。把 RALS 口诀或「静脉、动脉、支气管」一层次序套到上下，右肺根会少掉最上头的上叶支气管。
:::

:::keypoint{label="肺门只记本版进出名单和两套次序"}
- 进出：支气管、血管、神经、淋巴管。
- 这些结构被胸膜包绕 → 肺根。
- 前 → 后：上肺静脉、肺动脉、主支气管、下肺静脉（左右相同）。
- 上 → 下：左是动脉、主支气管、上肺静脉、下肺静脉；右是上叶支气管、动脉、中下叶支气管、上肺静脉、下肺静脉。
- 肺韧带在肺根下方，构成见第三节。
:::

:::insight{label="右肺上叶支气管为什么能排到肺根最上面"}
右主支气管在肺门外已经分出上叶支气管，所以上叶支气管可以出现在肺根的最上份，把右肺动脉压到第二位。左主支气管进肺门时还保持为一条，肺根最上份让给左肺动脉。叶支气管的级数在后文支气管树里写，这里先用它解释为什么左右肺根的「第一名」不是同一种管道。
:::

### （四）三缘

**前缘**是肋面与纵隔面在前方的移行处，较锐利。左肺前缘下部有**心切迹**（cardiac notch），切迹下方有一突起称**左肺小舌**（lingula of left lung）。心切迹和小舌是左肺的身份证，右肺前缘没有这一对结构。

**后缘**是肋面与纵隔面在后方的移行处，位于脊柱两侧的肺沟内，钝圆。

**下缘**是肋面与膈面、膈面与纵隔面的移行处，其位置随呼吸运动而变化。不要把下缘背成一条固定的肋号——下界的体表投影在第三节和胸膜下界对照着写。

:::definition{label="心切迹"}
左肺前缘下部的切迹。只出现在左肺。切迹下方的突起是左肺小舌。
:::

:::definition{label="左肺小舌"}
心切迹下方、左肺上叶前缘的一个突起。它是上叶的一部分，不是左肺的「中叶」。
:::

:::pitfall{label="心切迹和小舌不能写成右肺也有，也不能把小舌升级成第三叶"}
本版左肺借斜裂分成上、下两叶。小舌是上叶前缘在心切迹下方的突起，不是单独一叶，也不是水平裂围出来的中叶。右肺前缘没有心切迹，不要画成对称。
:::

:::compare{title="三缘怎么认"}
| 缘 | 由哪两面移行 | 形态 | 左、右差别 |
|----|-------------|------|-----------|
| 前缘 | 肋面 × 纵隔面（前） | 较锐利 | 左肺下部有心切迹和左肺小舌；右肺无 |
| 后缘 | 肋面 × 纵隔面（后） | 位于脊柱两侧肺沟内 | 两肺同在脊柱旁 |
| 下缘 | 肋面 × 膈面，以及膈面 × 纵隔面 | 随呼吸升降 | 具体肋号对照见第三节，本节不提前写胸膜下界 |

:::

### （五）分叶：右三左二

肺借叶间裂分叶。左肺的叶间裂称**斜裂**（oblique fissure），由肺门的后上斜向前下，将左肺分为上叶和下叶。右肺除了斜裂，还有**右肺水平裂**（horizontal fissure of right lung），将右肺分为上叶、中叶和下叶。

认叶的顺序是：先找斜裂（两肺都有），再问有没有水平裂（只有右肺有）。水平裂把右肺斜裂前上方的那一块再横切一刀，分出中叶；左肺没有这一刀，所以上叶前缘下部用小舌来占住心切迹下方的位置，仍叫上叶。

:::definition{label="斜裂"}
由肺门后上斜向前下的叶间裂。左、右肺都有。左肺借它分为上、下两叶；右肺的斜裂参与围成下叶，并与水平裂共同分出上叶和中叶。
:::

:::definition{label="右肺水平裂"}
只存在于右肺的叶间裂，与斜裂一起把右肺分成上叶、中叶和下叶。左肺没有水平裂。
:::

:::definition{label="右肺三叶"}
上叶、中叶、下叶。裂是斜裂加水平裂。
:::

:::definition{label="左肺二叶"}
上叶、下叶。裂只有斜裂。心切迹和左肺小舌都在上叶一侧。
:::

:::compare{title="左二叶、右三叶（按本版裂来划）"}
| | 右肺 | 左肺 |
|--|------|------|
| 外形 | 宽而短 | 狭而长 |
| 叶间裂 | 斜裂 + 水平裂 | 只有斜裂 |
| 叶 | 上叶、中叶、下叶 | 上叶、下叶 |
| 前缘特有结构 | 无心切迹、无小舌 | 心切迹 + 左肺小舌（属上叶） |

:::

:::pitfall{label="左肺没有中叶，不要把小舌或舌段写成第三叶"}
后文支气管肺段里左肺上叶有上舌段、下舌段，那是段的名字，不是叶的名字。本版叶的名单到「左上、左下、右上、右中、右下」就停。把舌段升级成「左肺中叶」，和斜裂只有一条会冲突。
:::

### （六）压迹

肺的表面有被毗邻器官压迫形成的压迹或沟。两肺门前下方均有**心压迹**。右肺门后方有食管压迹，上方有奇静脉沟。左肺门后方和上方分别有胸主动脉和主动脉弓的压迹。

压迹在纵隔面，切迹在前缘：心压迹是心压出来的凹，心切迹是左肺前缘让给心的那一缺。不要把两个「心」字并成一个结构。

:::compare{title="纵隔面压迹：左右不对称"}
| 部位 | 右肺 | 左肺 |
|------|------|------|
| 肺门前下方 | 心压迹 | 心压迹 |
| 肺门后方 | 食管压迹 | 胸主动脉压迹 |
| 肺门上方 | 奇静脉沟 | 主动脉弓压迹 |

心压迹两肺都有；食管和奇静脉是右侧的邻居，主动脉弓和胸主动脉是左侧的邻居。图3-19 里右侧能看见奇静脉和食管，左侧能看见主动脉弓，和这份压迹名单一致。
:::

:::insight{label="左肺狭而长，先从心切迹读起"}
本版只写外形「右宽短、左狭长」，没有另给肝把右肺「压矮」的句子。能从本节读出来的不对称，是左肺前缘缺一块（心切迹）加上纵隔面让给主动脉弓和胸主动脉。右肺门上方是奇静脉沟，不要画成也有主动脉弓。
:::

## 二、胎儿和婴幼儿肺的特点

胎儿和未曾呼吸过的新生儿肺不含空气，比重较大（1.045～1.056），可沉于水底。呼吸过的肺因为含空气，比重较小（0.345～0.746），能浮出水面。这在法医鉴定上具有重要价值：问的是「这肺进过气没有」，不是问死因的全部名单。

婴幼儿肺呈淡红色。随着生长，空气中的尘埃和炭粒被吸入肺内并沉积，使肺变为暗红色或深灰色；烟尘重污染环境或吸烟可致肺呈棕黑色。颜色是沉积造成的，不是叶间裂改了颜色。

:::definition{label="未曾呼吸肺的比重"}
1.045～1.056，不含空气，可沉于水底。对象是胎儿和未曾呼吸过的新生儿。
:::

:::definition{label="已呼吸肺的比重"}
0.345～0.746，含空气，能浮出水面。
:::

:::cause-effect{title="为什么没呼吸过的肺会沉、呼吸过的会浮"}
- **因** 未曾呼吸：肺内无气，比重 1.045～1.056，大于水
- **果** 沉于水底
- **因** 已经呼吸：肺内含气，比重 0.345～0.746，小于水
- **果** 浮出水面。本版把这一对比重明确写成法医鉴定的依据
:::

:::pitfall{label="浮起来只说明进过气，沉下去只说明几乎没含气"}
本版给的是比重和浮沉，没有把「浮」写成活产的唯一定义，也没有把「沉」写成死产的全部证明。腐败产气、人工呼吸等后文临床课才会展开，本节不要用一个浮沉实验替代整份法医鉴定。数字必须用本版这两段区间，不要改成「小于 1 就浮」。
:::

:::compare{title="肺的颜色按生命阶段和环境"}
| 阶段 / 条件 | 本版颜色 |
|-------------|----------|
| 生活状态下的正常成人肺 | 浅红色 |
| 婴幼儿 | 淡红色 |
| 随生长吸入尘埃、炭粒 | 暗红色或深灰色 |
| 烟尘重污染或吸烟 | 棕黑色 |
| 未曾呼吸 | 不写颜色，写「不含空气、能沉」 |

把吸烟肺的棕黑写成「正常生活状态」，和开篇那句浅红色会打架。
:::

:::timeline{period="从含气到沉浮、从淡红到棕黑"}
- **胎儿 / 未呼吸新生儿** 无气，比重 1.045～1.056，沉于水底
- **呼吸之后** 含气，比重 0.345～0.746，能浮；法医用这一对数字
- **婴幼儿** 肺淡红
- **生长过程** 尘埃、炭粒沉积 → 暗红或深灰
- **烟尘或吸烟** 可呈棕黑
:::

## 三、支气管树

在肺门处，左、右主支气管分出 2 级支气管，进入肺叶，称为**肺叶支气管**（lobar bronchi）。左肺有上叶和下叶支气管；右肺有上叶、中叶和下叶支气管——叶支气管的条数和叶的条数一致，还是右三左二。肺叶支气管进入肺叶后，再分出 3 级支气管，称为**肺段支气管**（segmental bronchi）。全部各级支气管在肺叶内反复分支，直达肺泡管，共分 23～25 级，形状如树，称为**支气管树**（bronchial tree）（图3-20）。

主支气管是树干进肺门之前的那一段，形态、软骨环数和嵴下角已经在第一节写完。本节从 2 级叶支气管起笔，不要把气管杈、气管隆嵴再写一遍。

:::definition{label="肺叶支气管"}
主支气管在肺门处分出的 2 级支气管，进入相应肺叶。左肺两支（上、下），右肺三支（上、中、下）。
:::

:::definition{label="肺段支气管"}
肺叶支气管再分出的 3 级支气管。每一支供应一个支气管肺段。
:::

:::definition{label="支气管树"}
从主支气管起，在肺叶内反复分支直达肺泡管的整套管道，共 23～25 级，形状如树。
:::

:::timeline{period="支气管树的级数（本版）"}
- **一级** 左、右主支气管（第一节；本节不重复嵴下角和异物径路）
- **二级** 肺叶支气管：左肺上、下叶支气管；右肺上、中、下叶支气管
- **三级** 肺段支气管
- **继续分支** 在肺叶内反复分支，直达肺泡管，一共 23～25 级
:::

::figure{src="/images/anatomy/textbook/p0155_01.png" caption="图3-20　支气管树整体观" alt="喉、气管及左、右支气管树在两肺轮廓内的分支，示右上、中、下叶支气管和左上、下叶支气管"}

:::compare{title="叶支气管条数跟着叶走"}
| | 叶 | 2 级支气管 |
|--|----|-----------|
| 右肺 | 上、中、下三叶 | 右上、右中、右下叶支气管 |
| 左肺 | 上、下二叶 | 左上、左下叶支气管 |

右肺根之所以最上头能排出「右肺上叶支气管」，就是因为右上叶支气管作为 2 级支，在进肺门的位置已经独立出来。
:::

:::pitfall{label="23～25 级是到肺泡管，不是只数到段支气管"}
3 级才是肺段支气管。后面还要在肺叶里反复分支，本版把终点写到肺泡管，总数 23～25 级。把支气管树背成「主支气管、叶、段一共三级」，肺泡这一头会从树上掉下去。
:::

**肺泡这一头长什么样**　实质里，支气管树的末梢连到肺泡。呼吸性细支气管已经开口通向肺泡；肺泡壁外面包绕毛细血管网。这张网是肺动脉在肺泡隔里的终末，不是支气管动脉的营养网。右肺剖开看管道：右肺动脉、右主支气管和右肺静脉在肺内伴行、分支，门还在纵隔面那一椭圆形凹陷上（图3-1A）。微细结构只认到本版插图上的这些名字，不把组织学的上皮分型搬进来。

:::definition{label="肺泡毛细血管网"}
肺动脉的分支进入肺泡隔、包绕肺泡壁形成的毛细血管网。它是功能性血管做气体交换的终点，不是支气管动脉在管壁里的营养网。
:::

::figure{src="/images/anatomy/textbook/p0143_02.png" caption="图3-1A　肺泡毛细血管网与右肺内管道" alt="上图：呼吸性细支气管、肺泡及包绕肺泡的毛细血管网；下图：右肺内右肺动脉、右主支气管与右肺静脉的配布"}

:::insight{label="树画到肺泡管，网铺在肺泡壁上"}
支气管树回答「气从哪条管子来」；肺泡毛细血管网回答「血在哪一层换气」。两张图不要并成一张「肺里只有支气管」。右肺内那三条主干——肺动脉、主支气管、肺静脉——和肺根名单是同一套东西，只是从门走到了叶里。
:::

## 四、支气管肺段

每一肺段支气管及其分布区域的肺组织在结构和功能上均为一个独立的单位，称为**支气管肺段**（bronchopulmonary segment），简称肺段。支气管肺段呈圆锥形，尖朝向肺门，底朝向肺的表面。通常左、右肺各有 10 个支气管肺段。有时左肺出现共干肺段支气管，例如后段与尖段、前底段与内侧底段支气管形成共干，此时左肺只有 8 个支气管肺段。

每个支气管肺段由一个肺段支气管分布。相邻支气管肺段之间隔以肺静脉属支及疏松结缔组织。支气管肺段具有结构和功能的相对独立性，因此临床可以支气管肺段为单位进行手术切除（图3-21，表3-2）。

:::definition{label="支气管肺段"}
一个肺段支气管加上它分布区域的肺组织，结构和功能上相对独立。呈圆锥形，尖朝肺门，底朝肺表面。简称肺段。
:::

:::definition{label="段间隔"}
相邻支气管肺段之间的肺静脉属支和疏松结缔组织。段支气管和肺动脉的分支走在段内，静脉属支走在段间。
:::

:::keypoint{label="肺段为什么能切"}
- 一个段支气管管一块肺组织。
- 段和段之间是静脉属支加疏松结缔组织，不是另一套段支气管交叉供应。
- 所以可以按段切除，而不必把整个叶都拿掉。
- 相对独立不是绝对独立：手术仍要处理段间的静脉。
:::

:::pitfall{label="通常是左右各 10 段；8 段是左肺共干时的变体，不是把右肺也改成 8"}
本版原句有两层：①通常左、右肺各 10 个支气管肺段；②左肺若后段与尖段共干、前底段与内侧底段共干，则左肺只有 8 段。共干的例子只点了左肺这两对。把「肺段一共 8 个」写成两肺通例，或把右肺中叶两段并掉，都和本版冲突。
:::

## 五、支气管和肺段的血液供应

肺里的血管要分两户：**功能性血管**把血送到肺泡去换气，再把换过气的血送回心；**营养性血管**给支气管壁和肺组织供氧供养。功能性这一户是肺动脉和肺静脉，营养性这一户是支气管动脉。不要看见「动脉」就写成换气，也不要看见「静脉」就写成营养。

:::concept{term="先问这根血管是来换气的还是来养管壁的"}
肺动脉、肺静脉走的是肺循环：右心室出来的血到肺泡毛细血管网换气，再经肺静脉回左心房。支气管动脉走的是体循环的分支：把营养血送到支气管壁的外膜和黏膜下层。两套网可以在末梢交通，但户头不能并。把肺动脉写成「给肺送氧」，和它运来的是待换气的血正好反了。
:::

### （一）功能性血管：肺动脉和肺静脉

**肺动脉**（pulmonary artery）是运送血液至肺进行气体交换的功能性血管。肺动脉由右心室动脉圆锥发出后，在主动脉弓下方分为左、右肺动脉。左、右肺动脉分别进入左、右肺；在肺门，其先位于支气管前方，再转向后方。在肺内的分支多与支气管的分支伴行，直至进入肺泡隔，包绕肺泡壁形成肺泡毛细血管网（见图3-1A）。

「先在支气管前方，再转向后方」这一句，和肺根「自前向后：上肺静脉、肺动脉、主支气管」是同一空间里的不同观察角度：肺动脉干进门时偏前，绕到支气管后方再按段支往下走。不要把它理解成「肺动脉永远在支气管前面」或「永远在后面」。

:::definition{label="肺动脉"}
运送血液至肺进行气体交换的功能性血管。起自右心室动脉圆锥，在主动脉弓下方分成左、右肺动脉入肺。肺内分支多与支气管伴行，终末在肺泡隔形成肺泡毛细血管网。
:::

**肺静脉**（pulmonary vein）是功能性血管的回流段：把在肺泡换过气、含氧量高的血液送回左心房。肺根名单里每侧已经出现上、下两条，分别叫左上、左下肺静脉和右上、右下肺静脉。相邻支气管肺段之间走的就是肺静脉属支——段间隔那一户。肺静脉起自肺门，向内穿过纤维心包，注入左心房后部；引流范围在脉管系统写清：左上、左下肺静脉分别收集左肺上、下叶的血液，右上肺静脉收集右肺上、中叶的血液，右下肺静脉收集右肺下叶的血液。本节认的是「肺根里那两条」和「段间那些属支」，不要把心腔内的开口细节从第七章整段搬过来。

:::definition{label="肺静脉"}
功能性血管的回流段，运送肺泡换气后的血液入左心房。每侧两条：上肺静脉和下肺静脉。属支走在段间隔里。
:::

:::compare{title="功能性血管一对：肺动脉去、肺静脉回"}
| | 肺动脉 | 肺静脉 |
|--|--------|--------|
| 户头 | 功能性，去肺换气 | 功能性，换气后回心 |
| 起点 / 终点 | 右心室动脉圆锥 → 肺泡毛细血管网 | 肺泡毛细血管网 → 左心房后部 |
| 肺门位置 | 自前向后排在上肺静脉之后、主支气管之前；先居支气管前方再转向后方 | 上肺静脉最前，下肺静脉最后、最下 |
| 肺内走行 | 多与支气管分支伴行，走段内 | 属支走段间 |
| 引流 / 分布（后文原句） | 左、右肺动脉入左、右肺 | 左上、左下收左肺上、下叶；右上收右肺上、中叶；右下收右肺下叶 |

右肺三叶、两条肺静脉：上、中叶合走右上肺静脉，下叶走右下肺静脉。不要按「一叶一条静脉」去拆右肺。
:::

:::pitfall{label="肺动脉里走的是待换气的血，不要按「动脉=氧合血」来记"}
肺循环里，肺动脉离开右心室，运的是含二氧化碳较多的血；氧合之后走肺静脉回左心房。营养肺组织的氧合血是支气管动脉送来的。用体循环的颜色口诀套到肺门，肺动脉和支气管动脉会并户。
:::

:::keypoint{label="肺动脉在肺门先前再后，分支多跟支气管走"}
- 发自右心室动脉圆锥，主动脉弓下方分左、右。
- 肺门：先在支气管前方，再转向后方。
- 肺内：与支气管分支伴行 → 肺泡隔 → 肺泡毛细血管网。
- 回流不走原路动脉，走肺静脉，段间汇合后经上、下肺静脉出肺门。
:::

### （二）营养性血管：支气管动脉

**支气管动脉**（bronchial artery）是肺的营养血管，通常有 1～4 支。左侧支气管动脉主要起自胸主动脉和主动脉弓，右侧支气管动脉主要来自第 3～5 肋间后动脉。在肺门处，支气管动脉互相吻合，交通成网，并伴随肺叶支气管走行进入肺叶内，随肺段支气管进入支气管肺段内，形成 1～3 支肺段支气管动脉。支气管动脉最终在支气管壁的外膜和黏膜下层形成供应支气管的毛细血管网。经支气管动脉的介入疗法目前已成为治疗肺肿瘤的方法之一。

营养网铺在支气管壁的外膜和黏膜下层；换气网铺在肺泡壁上。一个养管子，一个换气，不要把「毛细血管网」写成只有一张。

:::definition{label="支气管动脉"}
肺的营养血管，通常 1～4 支。左侧主要起自胸主动脉和主动脉弓，右侧主要来自第 3～5 肋间后动脉。随叶、段支气管入肺，在支气管壁外膜和黏膜下层成网。
:::

:::definition{label="肺段支气管动脉"}
支气管动脉随肺段支气管进入支气管肺段后形成的 1～3 支动脉。它养这一段的支气管壁，不替代该段的肺动脉去做气体交换。
:::

:::compare{title="功能性血管 vs 营养性血管"}
| | 功能性 | 营养性 |
|--|--------|--------|
| 本版名字 | 肺动脉、肺静脉 | 支气管动脉 |
| 干什么 | 把血送到肺泡换气，再送回左心房 | 营养支气管壁和肺组织 |
| 起点 | 右心室动脉圆锥（肺动脉） | 左：胸主动脉、主动脉弓；右：第 3～5 肋间后动脉 |
| 终末毛细血管 | 肺泡隔、包绕肺泡壁 | 支气管壁外膜和黏膜下层 |
| 支数（本版） | 肺动脉干分左、右；肺静脉每侧上、下各一 | 支气管动脉通常 1～4 支；入段后成 1～3 支肺段支气管动脉 |
| 临床一句 | 肺循环、气体交换 | 经支气管动脉的介入疗法可治疗肺肿瘤 |

:::

:::compare{title="支气管动脉左右起点按本版"}
| | 主要起点 | 入肺以后 |
|--|----------|----------|
| 左侧 | 胸主动脉和主动脉弓 | 肺门处互相吻合、交通成网 |
| 右侧 | 第 3～5 肋间后动脉 | 同上，再伴随肺叶支气管入叶、随肺段支气管入段 |
| 终末 | 支气管壁外膜和黏膜下层的毛细血管网 | 养的是管道，不是肺泡换气面 |

左侧不要只背「胸主动脉」而丢掉主动脉弓；右侧不要写成支气管动脉也从胸主动脉发出——本版右侧写的是肋间后动脉。
:::

:::cause-effect{title="为什么肺肿瘤的介入可以走支气管动脉"}
- **因** 支气管动脉是肺的营养血管，沿叶、段支气管入肺，在管壁成网；肿瘤要生长，营养来自这一户
- **果** 经支气管动脉的介入疗法成为治疗肺肿瘤的方法之一
- 换气那一户（肺动脉）不承担「给肿瘤送养」的户头，不要把介入起点写成肺动脉干
:::

:::pitfall{label="支气管动脉的毛细血管网不在肺泡隔"}
肺动脉 → 肺泡隔、肺泡壁（换气）。支气管动脉 → 支气管壁外膜和黏膜下层（营养）。两张网都叫毛细血管网，位置不同。把营养网写到肺泡隔，气体交换和管壁营养会并户。
:::

:::insight{label="肺根里不一定单独点名支气管动脉，但不等于肺没有营养血管"}
图3-19 和肺根次序突出的是上肺静脉、肺动脉、主支气管、下肺静脉。支气管动脉细、支数 1～4、在肺门吻合后贴着支气管走，所以认肺根先背那四样，认血供必须再单列营养这一户。漏写支气管动脉，介入治疗那一句就没有解剖起点。
:::

:::keypoint{label="肺的血管就记两户"}
- 功能性：肺动脉去肺泡换气，肺静脉回左心房；段内动脉、段间静脉。
- 营养性：支气管动脉 1～4 支，左来自胸主动脉和主动脉弓，右来自第 3～5 肋间后动脉，终末在支气管壁。
- 肺动脉在肺门先位于支气管前方，再转向后方。
- 右上肺静脉收上叶加中叶，不要给中叶再造一条出肺门的静脉。
:::

本节写到两套血管为止。脏胸膜如何在肺根处返折、胸膜腔和胸膜隐窝、肺下界相对胸膜下界高出两个肋，下一节从胸膜起笔，不把支气管动脉再抄一遍。

:::memory{label="本节必背要点"}
- [ ] 肺在胸腔内、纵隔两侧。活体浅红、海绵状、有弹性。成人重量约体重 1/50：男 1000～1300 g，女 800～1000 g。男两肺空气容量约 5000～6500 ml。
- [ ] 透过脏胸膜的多角形小区是肺小叶；感染称小叶性肺炎。
- [ ] 外形通式：一尖、一底、三面、三缘。右肺宽而短，左肺狭而长。
- [ ] 肺尖钝圆，经胸廓上口达锁骨内侧 1/3 段上方 2～3 cm。肺底即膈面，半月形凹陷。
- [ ] 肺门 = 纵隔面中央椭圆形凹陷（第一肺门）。肺根 = 支气管、血管、神经、淋巴管被胸膜包绕。
- [ ] 肺根自前向后（左右同）：上肺静脉、肺动脉、主支气管、下肺静脉。
- [ ] 肺根自上而下：左 = 肺动脉、主支气管、上肺静脉、下肺静脉；右 = 上叶支气管、肺动脉、中下叶支气管、上肺静脉、下肺静脉。
- [ ] 左肺前缘有心切迹和左肺小舌（小舌属上叶，不是中叶）。
- [ ] 左肺斜裂分上、下二叶；右肺斜裂 + 水平裂分上、中、下三叶。
- [ ] 压迹：两肺门前下都有心压迹；右后方食管、上方奇静脉沟；左后方胸主动脉、上方主动脉弓。
- [ ] 未呼吸肺比重 1.045～1.056 沉，已呼吸 0.345～0.746 浮（法医）。婴幼儿淡红，尘埃沉积暗红或深灰，吸烟可棕黑。
- [ ] 支气管树：2 级叶支气管（左二右三），3 级段支气管，共 23～25 级到肺泡管。
- [ ] 支气管肺段：圆锥形，尖朝肺门。通常左右各 10 段；左肺尖段与后段、前底段与内侧底段可共干而成 8 段。段间隔走肺静脉属支。可按段切除。
- [ ] 右肺段：上叶尖、后、前；中叶外侧、内侧；下叶尖（上）、内侧（心）底、前底、外侧底、后底。左肺上叶多出上舌、下舌，没有中叶。
- [ ] 功能性血管：肺动脉（右心室动脉圆锥 → 肺泡毛细血管网）、肺静脉（每侧上、下，回左心房）。营养性血管：支气管动脉 1～4 支（左：胸主动脉和主动脉弓；右：第 3～5 肋间后动脉），终末在支气管壁外膜和黏膜下层；可作肺肿瘤介入。
:::
