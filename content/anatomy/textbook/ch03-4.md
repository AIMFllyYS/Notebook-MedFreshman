# 第四节　纵隔

第三节已经把胸膜、胸膜腔和投影写完。胸膜腔左右各一、互不相通，中间夹着的这一整块才是纵隔。本节把「两侧纵隔胸膜之间」这一户写完：先钉死定义、外形和六界，再按本版常用的四分法把上纵隔和下纵隔（前、中、后）的内容与好发部位摆上，最后写结缔组织间隙怎样通到颈和腹膜后。心的外形、出入心大血管的详细行程、胸腺的内分泌功能分别在循环系统和内分泌系统展开，这里只认它们在纵隔里的座位。

纵隔（mediastinum）是两侧纵隔胸膜之间全部器官、结构和结缔组织的总称。它不是两肺之间的一条空缝，也不是「心再加几根大血管」：胸腺、气管、食管、胸导管、神经和疏松结缔组织都算在这一户里。纵隔稍偏左，上窄下宽、前短后长，呈矢状位。前界是胸骨，后界是脊柱胸段，两侧是纵隔胸膜，上界是胸廓上口，下界是膈（图3-24、图3-25）。左、右胸膜腔各占一侧，互不相通，纵隔是它们中间的隔壁兼内容物。

:::concept{term="先问这是不是两侧纵隔胸膜之间的全部内容，再问四分法切在哪一刀"}
看见「纵隔」，先不要默写胸腺瘤。先问：它是不是两侧纵隔胸膜之间的器官、结构和结缔组织的总称——答案是，空腔、心包腔、胸膜腔都不在这一句里。再问外形：稍偏左、上窄下宽、前短后长、矢状位。然后才问分区：本版解剖学常用四分法，第一刀在胸骨角水平。把肺下界投影、肋膈隐窝整段搬进来，户头就并了第三节；把心的沟、腔、瓣提前写完，又吞了循环系统。
:::

:::definition{label="纵隔"}
两侧**纵隔胸膜**之间全部器官、结构和结缔组织的总称。本版原句不要改成「心所在的间隙」或「两肺之间的空腔」——器官和结缔组织都算，空腔不算。
:::

:::definition{label="纵隔的外形"}
稍偏左；上窄下宽；前短后长；呈矢状位。四句话一起背，缺「稍偏左」会画成正中一条缝，缺「前短后长」会对不上胸骨短、脊柱胸段长。
:::

:::definition{label="纵隔六界"}
前界胸骨，后界脊柱胸段，两侧纵隔胸膜，上界胸廓上口，下界膈。六界缺一，纵隔的盒子就少一面。
:::

:::definition{label="纵隔胸膜（两侧界）"}
壁胸膜衬于纵隔两侧的那一份。它是纵隔的侧壁，不是纵隔里的器官。中部包裹肺根并移行为脏胸膜——肺根穿出这一面，详细返折见第三节。
:::

:::keypoint{label="六界就记这一张盒子"}
- 前：胸骨（上份是胸骨柄，下份是胸骨体）。
- 后：脊柱胸段。
- 两侧：纵隔胸膜（外面才是左、右胸膜腔）。
- 上：胸廓上口，通颈。
- 下：膈，经裂孔通腹。
- 外形：稍偏左，上窄下宽，前短后长，矢状位。
:::

:::insight{label="前短后长，是因为前壁是胸骨、后壁是脊柱胸段"}
胸骨柄加胸骨体的前后径短，脊柱胸段从上胸椎排到膈的附着处更长。把纵隔画成前后等长的长方体，后纵隔里的食管、胸主动脉、胸导管会没有纵深可放。上窄下宽，则是胸廓本身上口小、膈面宽。
:::

:::pitfall{label="纵隔不是空腔，胸膜腔也不是纵隔的一部分"}
纵隔是「之间的全部内容」。胸膜腔左右各一、呈负压、互不相通，贴在纵隔两侧外面。把纵隔听成「胸腔正中的空房间」，胸腺、气管、食管和结缔组织间隙都会从定义里掉出去；把两侧胸膜腔算进纵隔，气胸和纵隔气肿又并户。
:::

纵隔分区的方法较多。解剖学**常用四分法**：在胸骨角水平面将纵隔分为上纵隔和下纵隔；下纵隔再以心包为界，分为前纵隔、中纵隔和后纵隔。图3-27 左侧画的就是这一套。同一张图的右侧还画了九分法，用第 4、第 8 胸椎把纵隔再切成上、中、下三层，每层再分前、中、后，共九区。九分法只作对照，**不是**本版正文唯一的分区。

:::definition{label="解剖学常用四分法"}
第一刀：胸骨角水平面 → 上纵隔 / 下纵隔。第二刀：下纵隔以心包为界 → 前、中、后纵隔。本版立户的是这一套，不要改成「只有九分法」。
:::

:::definition{label="胸骨角平面（四分法第一刀）"}
胸骨柄与胸骨体连接处向前的横嵴所在的水平面，向后平对**第 4 胸椎椎体下缘**。第一章已经把它写成：左、右主支气管分叉处，主动脉弓下缘水平，心房上缘，上、下纵隔交界部。本节第一刀就落在这里。
:::

:::definition{label="九分法（对照）"}
图3-27 右侧：以 T4、T8 为水平标志，把纵隔分成上、中、下三层，每层再分前、中、后三区，共九区（上前区、上中区、上后区、中前区、中中区、中后区、下前区、下中区、下后区）。本版正文不用它替代四分法。
:::

:::compare{title="四分法与九分法（本版以四分法立户）"}
| | 四分法（本版常用） | 九分法（图3-27 对照） |
|--|-------------------|----------------------|
| 第一刀 | 胸骨角水平面 → 上 / 下纵隔 | T4 水平把「上」再切一刀 |
| 再分 | 下纵隔以心包为界 → 前、中、后 | T8 再切一刀，上中下 × 前中后 = 九区 |
| 标志椎骨 | 上纵隔后界第 1～4 胸椎；下界平 T4 椎体下缘 | 图中标 T4、T8 |
| 本版用法 | **解剖学常用**，正文按这一套写内容和好发 | 只在图上对照，不要写成「本版唯一分区」 |

两套图可以叠在同一心脏轮廓上，户头不要并成一套。
:::

:::pitfall{label="不要把九分法写成「本版唯一分区」"}
图3-27 左右并排，右侧九区看起来更细。本版原句是「分区方法较多，解剖学常用四分法」。影像科、外科可以另用九分法谈病变，考试和本节默写仍以胸骨角 + 心包这两刀为准。
:::

:::insight{label="左侧看弓，右侧看腔和奇静脉"}
心和主动脉弓把纵隔推向稍偏左，所以左侧面几乎是「弓和降主动脉的侧面」；右侧面让出上腔静脉和奇静脉上行、弓形跨过右肺根的空间。两幅图对看，四分法里的上纵隔（弓、头臂静脉）和下纵隔（心包、主支气管、胸主动脉）会同时出现，不要指望一幅侧面只画上纵隔。
:::

## 一、上纵隔

上纵隔（superior mediastinum）是指胸骨角平面以上的纵隔部分。上界是胸廓上口，下界是胸骨角至第 4 胸椎椎体下缘的平面，前方是胸骨柄，后方是第 1～4 胸椎椎体。上纵隔内自前向后有：胸腺，左头臂静脉、右头臂静脉，上腔静脉，膈神经，迷走神经，喉返神经，主动脉弓及其 3 大分支，以及后方的气管、食管、胸导管等（图3-26）。

:::definition{label="上纵隔"}
胸骨角平面**以上**的纵隔。上界胸廓上口，下界胸骨角至第 4 胸椎椎体下缘，前界胸骨柄，后界第 1～4 胸椎椎体。
:::

:::definition{label="上纵隔的下界"}
胸骨角至**第 4 胸椎椎体下缘**的平面。不是 T4 上缘，也不是 T5，更不是「大约第 3 胸椎」——图3-26 的水平切面标的是第 3 胸椎，那是上纵隔内部的一刀，不是下界。
:::

:::keypoint{label="上纵隔的境界四句话"}
- 上：胸廓上口。
- 下：胸骨角 → 第 4 胸椎椎体下缘。
- 前：胸骨柄（不是胸骨体）。
- 后：第 1～4 胸椎椎体。
:::

:::pitfall{label="上纵隔下界是 T4 椎体下缘，不要写成 T4 上缘或 T5"}
本版把这一平面同时写成气管杈、主动脉弓下缘、上、下纵隔交界。写成 T4 上缘，弓的下缘和气管杈会差出一截椎体；写成 T5，后纵隔又会把第 4 胸椎吃进去。图3-26 平第 3 胸椎，用来看自前向后的排列，不能拿它替换下界。
:::

自前向后这一条名单，要按层次读，不要背成一串无关的器官。最前是胸腺，贴在胸骨柄后方；其后是左、右头臂静脉汇向上腔静脉；神经（膈神经、迷走神经、喉返神经）和主动脉弓及其 3 大分支占据中层；最后才是气管、食管和胸导管。图3-26 是上纵隔的水平切面：前份看见胸腺和头臂静脉，中份看见头臂干、左颈总动脉、左锁骨下动脉，后份气管在前、食管在后，胸导管走在食管左侧，椎体是第 3 胸椎。

:::definition{label="上纵隔自前向后"}
胸腺 → 左、右头臂静脉 → 上腔静脉 → 膈神经 → 迷走神经 → 喉返神经 → 主动脉弓及其 3 大分支 → 后方的气管、食管、胸导管。次序是本版原句，不要把气管提到胸腺前面。
:::

:::compare{title="上纵隔自前向后（按层读）"}
| 层 | 本版名单 | 图3-26 这一刀能看见什么 |
|----|----------|-------------------------|
| 最前 | 胸腺 | 胸骨柄后方的胸腺 |
| 静脉 | 左头臂静脉、右头臂静脉、上腔静脉 | 左、右头臂静脉已入画面；上腔静脉在名单里紧随其后 |
| 神经 | 膈神经、迷走神经、喉返神经 | 左、右膈神经偏外侧，左、右迷走神经贴气管食管旁 |
| 动脉弓 | 主动脉弓及其 3 大分支 | 头臂干、左颈总动脉、左锁骨下动脉（由右向左） |
| 最后 | 气管、食管、胸导管 | 气管在前、食管在后，胸导管在食管左侧，后对第 3 胸椎 |

3 大分支以图3-26 的标签为准：头臂干、左颈总动脉、左锁骨下动脉。
:::

::figure{src="/images/anatomy/textbook/p0161_02.png" caption="图3-26　上纵隔各结构排列关系（水平切面观）" alt="平第3胸椎的上纵隔水平切面：前为胸腺与左、右头臂静脉，中为头臂干、左颈总动脉、左锁骨下动脉，后为气管、食管、胸导管，两侧有膈神经和迷走神经"}

:::definition{label="胸腺（上纵隔前部）"}
上纵隔自前向后的第一件。贴胸骨柄后方。成人胸腺多萎缩成遗迹，向下可以伸到前纵隔，所以前纵隔的名单里写的是「胸腺或胸腺遗迹」。重量、内分泌功能归内分泌系统，本节只认座位。
:::

:::definition{label="左、右头臂静脉与上腔静脉"}
上纵隔静脉层。左、右头臂静脉在胸腺后方汇入上腔静脉。上腔静脉全干主要在上纵隔；中纵隔名单里只再写「上腔静脉根部」——根部入心包、入右心房，户头落到中纵隔。
:::

:::definition{label="上纵隔的神经"}
膈神经、迷走神经、喉返神经。膈神经更靠前外，贴纵隔胸膜下降，中纵隔还要再写一次（伴心包膈动脉走心包外侧面）。迷走神经更靠后，贴气管、食管。左喉返神经在图3-24 上勾绕主动脉弓，是左侧面认弓的配套标志。
:::

:::definition{label="主动脉弓及其 3 大分支"}
上纵隔动脉层。弓本身在上纵隔；弓的下缘平胸骨角、T4 椎体下缘，向下续胸主动脉（后纵隔）。3 大分支按图3-26 由右向左：头臂干、左颈总动脉、左锁骨下动脉。升主动脉不在这一层，它在中纵隔。
:::

:::definition{label="上纵隔后层"}
气管、食管、胸导管。气管在前、食管在后；胸导管走在食管左侧（图3-26）。气管下端在本平面附近分成左、右主支气管，气管杈和主支气管的户头本版写在后纵隔，不要把整条气管搬进后纵隔。
:::

:::insight{label="胸骨角这一刀同时切到三件大事"}
第一章把胸骨角写成：气管杈、主动脉弓下缘、心房上缘、上、下纵隔交界。所以上纵隔下界不是一条随便画的线——弓在此续降主动脉，气管在此成杈，心的上缘在此进入中纵隔。背下界时把这三件一起想，比单记「T4」稳。
:::

:::pitfall{label="气管在上纵隔，气管杈和主支气管在后纵隔"}
上纵隔后层是气管；后纵隔名单是气管杈及左、右主支气管。把「气管」整条写进后纵隔，上纵隔后层会空掉；把气管杈写进上纵隔，又和胸骨角平面「刚好是分叉处」这一刀对不上。杈卡在交界，本版把它算进后纵隔。
:::

:::pitfall{label="升主动脉、主动脉弓、胸主动脉不要写成同一段的同一户"}
升主动脉在中纵隔（出入心的大血管）。主动脉弓在上纵隔。胸主动脉在后纵隔。三段连成一条主动脉，座位却分属三个纵隔。写成「主动脉都在中纵隔」或「弓在后纵隔」，好发部位里的主动脉瘤也会放错区。
:::

## 二、下纵隔

下纵隔（inferior mediastinum）是指胸骨角平面以下的纵隔部分。上界是上纵隔的下界，下界是膈，两侧是纵隔胸膜。下纵隔分 3 部分：心包前方与胸骨体之间是前纵隔，心包连同其包裹的心脏所在的部位是中纵隔，心包后方与脊柱胸段之间是后纵隔（图3-27）。

:::definition{label="下纵隔"}
胸骨角平面**以下**的纵隔。上界 = 上纵隔的下界（胸骨角至 T4 椎体下缘），下界膈，两侧纵隔胸膜。它不是「心所在的那一块」——心只占其中的中纵隔。
:::

:::definition{label="心包（下纵隔第二刀）"}
下纵隔前、中、后三分的界标。心包前方与胸骨体之间 → 前纵隔；心包连同其包裹的心脏 → 中纵隔；心包后方与脊柱胸段之间 → 后纵隔。第二刀切的是心包，不是「肺根」，也不是「气管杈」。
:::

:::compare{title="下纵隔三分（以心包为界）"}
| | 前纵隔 | 中纵隔 | 后纵隔 |
|--|--------|--------|--------|
| 位置 | 胸骨体与心包之间 | 前、后纵隔之间；心包连同其包裹的心脏 | 心包与脊柱胸部之间 |
| 厚薄 | 很窄的一条间隙 | 最「占地方」的一份 | 纵深最长的一份 |
| 本版好发 | 胸腺瘤、皮样囊肿、淋巴瘤 | 心包囊肿 | 支气管囊肿、神经瘤、主动脉瘤、膈疝 |

前纵隔不要画成「心脏前面的一大块」——心连心包已经算中纵隔。
:::

### （一）前纵隔

前纵隔（anterior mediastinum）位于胸骨体与心包之间，容纳胸腺或胸腺遗迹、纵隔前淋巴结、胸廓内动脉纵隔支、疏松结缔组织和胸骨心包韧带等。前纵隔是胸腺瘤、皮样囊肿和淋巴瘤的好发部位。

:::definition{label="前纵隔"}
胸骨体与心包之间。上纵隔前界是胸骨柄，前纵隔前界换成胸骨体——第一刀切在胸骨角，柄以上归上纵隔，体以下这一窄条才是前纵隔。
:::

:::definition{label="前纵隔的内容"}
胸腺或胸腺遗迹、纵隔前淋巴结、胸廓内动脉纵隔支、疏松结缔组织、胸骨心包韧带等。没有心，没有主支气管，没有胸主动脉。
:::

:::definition{label="前纵隔好发"}
胸腺瘤、皮样囊肿、淋巴瘤。三件套钉在前纵隔，不要写成中纵隔。
:::

:::insight{label="胸腺跨了上纵隔和前纵隔两户"}
上纵隔最前是胸腺，前纵隔是胸腺或胸腺遗迹。同一器官在胸骨角以上是「胸腺」，角以下常只剩遗迹，所以肿瘤仍可出现在前纵隔。把胸腺只写在上纵隔，前纵隔好发里的胸腺瘤会没有解剖座位。
:::

:::pitfall{label="前纵隔很窄，不是心前面那一整块"}
本版原句：心包前方与胸骨体之间。心包连同心脏已经是中纵隔。把前纵隔画宽，心包囊肿会被误放到前纵隔，胸腺瘤、皮样囊肿、淋巴瘤又会和「心」挤在同一区。
:::

### （二）中纵隔

中纵隔（middle mediastinum）位于前、后纵隔之间，容纳心及出入心的大血管，如升主动脉、肺动脉干、上腔静脉根部、左肺动脉、右肺动脉、左肺静脉、右肺静脉、奇静脉末端、心包、心包膈动脉、膈神经和淋巴结等。中纵隔是心包囊肿的好发部位。

:::definition{label="中纵隔"}
前、后纵隔之间，心包连同其包裹的心脏所在的部位。本版说「容纳心及出入心的大血管」，不是只容纳心腔。
:::

:::definition{label="中纵隔的内容"}
心；升主动脉、肺动脉干、上腔静脉根部；左、右肺动脉；左、右肺静脉；奇静脉末端；心包；心包膈动脉；膈神经；淋巴结等。肺动脉干在主动脉弓下方分成左、右肺动脉，这一笔与第二节肺的血管衔接，行程细节归循环系统。
:::

:::definition{label="中纵隔好发"}
心包囊肿。本版中纵隔好发只点这一项，不要把胸腺瘤或神经瘤塞进来。
:::

:::compare{title="同一条管道，上纵隔写全干，中纵隔写根部"}
| 结构 | 上纵隔 | 中纵隔 | 后纵隔 |
|------|--------|--------|--------|
| 上腔静脉 | 上腔静脉 | 上腔静脉根部 | — |
| 主动脉 | 主动脉弓及其 3 大分支 | 升主动脉 | 胸主动脉 |
| 膈神经 | 有 | 有（伴心包膈动脉） | — |
| 奇静脉 | — | 奇静脉末端 | 奇静脉、半奇静脉 |

「末端 / 根部」不是抄漏，是户头换区。
:::

:::pitfall{label="心包囊肿在中纵隔，不要写成前纵隔"}
前纵隔好发是胸腺瘤、皮样囊肿、淋巴瘤；中纵隔好发是心包囊肿。囊肿两个字很像，座位差在心包这一刀的前或里。写成前纵隔，会和皮样囊肿抢户。
:::

:::pitfall{label="中纵隔有心包和心，不等于有气管杈"}
气管杈及左、右主支气管在后纵隔。中纵隔的气道相关结构止于出入心的大血管和肺根朝向心的那一端。把主支气管写进中纵隔，支气管囊肿的好发就会从后纵隔被搬走。
:::

### （三）后纵隔

后纵隔（posterior mediastinum）位于心包与脊柱胸部之间，容纳气管杈及左主支气管、右主支气管、食管、胸主动脉、奇静脉、半奇静脉、胸导管、交感干胸段和淋巴结等。后纵隔是支气管囊肿、神经瘤、主动脉瘤及膈疝的好发部位。

:::definition{label="后纵隔"}
心包与脊柱胸部之间。前短后长里「后长」的那一份，主要在这里。
:::

:::definition{label="后纵隔的内容"}
气管杈及左、右主支气管；食管；胸主动脉；奇静脉、半奇静脉；胸导管；交感干胸段；淋巴结等。图3-24 左侧还标出副半奇静脉；本版正文名单写的是奇静脉、半奇静脉。
:::

:::definition{label="后纵隔好发"}
支气管囊肿、神经瘤、主动脉瘤、膈疝。四件套钉在后纵隔。神经瘤贴交感干胸段这一户；主动脉瘤贴胸主动脉；膈疝贴下界的膈。
:::

:::definition{label="胸导管在纵隔中的两处"}
上纵隔后层有胸导管，后纵隔也有胸导管。它穿膈的主动脉裂孔上行，先走后纵隔，再进入上纵隔后层，图3-26 里贴在食管左侧。不要问「胸导管到底算上还是后」——两户都写，是同一条管道穿过交界。
:::

:::compare{title="前、中、后纵隔：内容与好发（本版名单）"}
| | 前纵隔 | 中纵隔 | 后纵隔 |
|--|--------|--------|--------|
| 位置 | 胸骨体 ↔ 心包 | 心包 + 心 | 心包 ↔ 脊柱胸部 |
| 主要内容 | 胸腺或遗迹、纵隔前淋巴结、胸廓内动脉纵隔支、疏松结缔组织、胸骨心包韧带 | 心及出入心大血管、心包、心包膈动脉、膈神经、淋巴结 | 气管杈及左、右主支气管、食管、胸主动脉、奇静脉、半奇静脉、胸导管、交感干胸段、淋巴结 |
| 好发 | 胸腺瘤、皮样囊肿、淋巴瘤 | 心包囊肿 | 支气管囊肿、神经瘤、主动脉瘤、膈疝 |

好发按区背，不要混成「纵隔肿瘤」一张单。
:::

:::keypoint{label="好发部位三句话"}
- 前纵隔：胸腺瘤、皮样囊肿、淋巴瘤。
- 中纵隔：心包囊肿。
- 后纵隔：支气管囊肿、神经瘤、主动脉瘤、膈疝。
:::

:::pitfall{label="神经瘤、主动脉瘤、膈疝都在后纵隔，不要前移"}
后纵隔有交感干胸段、胸主动脉、下界贴膈，所以这三件落在这里。写成中纵隔（「反正都靠心」）或上纵隔（「反正都靠脊柱」），和本版名单对不上。支气管囊肿跟气管杈、主支气管走，同样在后纵隔。
:::

:::insight{label="后纵隔是「管道走廊」"}
气管杈和主支气管、食管、胸主动脉、奇静脉系统、胸导管、交感干，都在心包后方的纵深里上下走。前纵隔是窄间隙，中纵隔是心包这个盒子，后纵隔才是通颈、通腹的长走廊——下一节间隙蔓延，走的就是这条走廊外面的结缔组织，而不是把心包腔打开。
:::

## 三、纵隔间隙与蔓延

纵隔内结缔组织及间隙向上经胸廓上口与颈部的结缔组织及间隙相互延伸；向下经主动脉裂孔及食管裂孔与腹部的结缔组织及间隙相互延伸。因此，纵隔气肿可向上蔓延达颈部，向下蔓延至腹膜后间隙。

:::definition{label="纵隔结缔组织间隙"}
器官与器官之间、器官与心包、纵隔胸膜之间的疏松结缔组织及其间隙。向上经胸廓上口通颈；向下经主动脉裂孔、食管裂孔通腹膜后。它是纵隔定义里「结构和结缔组织」那一半，不是可有可无的填充。
:::

:::definition{label="纵隔气肿的蔓延"}
向上：经胸廓上口到颈。向下：经主动脉裂孔及食管裂孔到腹膜后间隙。两个方向都走结缔组织间隙，不走气管腔，也不走食管腔。
:::

第一章写膈肌三个裂孔：主动脉裂孔在第 12 胸椎前方，有主动脉和胸导管通过；食管裂孔约平第 10 胸椎，有食管和迷走神经通过；另有腔静脉孔约平第 8 胸椎，走下腔静脉。本版纵隔气肿向下只点名**主动脉裂孔和食管裂孔**，没有把腔静脉孔写成通路。

:::cause-effect{title="纵隔气肿为什么能到颈，也能到腹膜后"}
- **因** 纵隔内的结缔组织及间隙向上经胸廓上口与颈部间隙相通，向下经主动脉裂孔、食管裂孔与腹部腹膜后间隙相通
- **果** 气体一旦进入纵隔间隙，可以向上到颈，向下到腹膜后，而不必先破入胸膜腔

左、右胸膜腔互不相通，所以纵隔气肿不是「变成双侧气胸」的同义词。
:::

:::compare{title="气肿两个方向（裂孔不要记混）"}
| 方向 | 通道 | 到达 |
|------|------|------|
| 向上 | 胸廓上口 | 颈部结缔组织间隙 |
| 向下 | 主动脉裂孔、食管裂孔 | 腹膜后间隙 |
| 不作为本版通路写出的 | 腔静脉孔 | — |

主动脉裂孔同时走主动脉和胸导管，食管裂孔走食管和迷走神经。气肿走的是裂孔周围的间隙，不是把这些管道的管腔当作气管。
:::

:::pitfall{label="纵隔气肿不经腔静脉孔，也不等于气胸"}
向下的通路本版只写主动脉裂孔和食管裂孔。把三个裂孔一齐写成气肿通路，腔静脉孔会被误算进去。气肿在纵隔结缔组织里走；气胸在胸膜腔里走。两侧胸膜腔各一、互不相通，纵隔是它们中间的内容，不是把两腔连通的孔。
:::

:::insight{label="气肿走的是疏松结缔组织，不是沿着气管「流」下去"}
气管、食管、胸主动脉都是实心的管道壁围成的腔。气体要蔓延，走的是管道外面那一层蜂窝组织。所以上面出胸廓上口，下面出两个裂孔，都能到颈或腹膜后，而不必先在气管镜下看见「管腔内的气泡」。
:::

:::keypoint{label="间隙蔓延两句话"}
- 上：胸廓上口 ↔ 颈。
- 下：主动脉裂孔、食管裂孔 ↔ 腹膜后间隙。
- 临床对应：纵隔气肿可到颈，可到腹膜后。
:::

:::note{label="本节止于纵隔的座位与间隙"}
心的一尖一底两面三缘、瓣膜和传导系，出入心大血管的全程，胸腺的重量与内分泌功能，都不在本节展开。图3-24、图3-25 侧面能看见肺根、肺动脉和肺静脉，那是中纵隔与肺门交界的形态，血管行程以第二节和循环系统为准。胸膜腔、胸膜隐窝和胸膜、肺的体表投影是第三节的户头，本节不再写下界交于哪一根肋。
:::

:::memory{label="本节必背要点"}
- [ ] 纵隔 = 两侧纵隔胸膜之间全部器官、结构和结缔组织。稍偏左，上窄下宽、前短后长，矢状位。不是空腔。
- [ ] 六界：前胸骨、后脊柱胸段、两侧纵隔胸膜、上胸廓上口、下膈。胸膜腔左右各一，在纵隔两侧外面。
- [ ] 解剖学常用四分法：胸骨角水平 → 上 / 下纵隔；下纵隔以心包为界 → 前、中、后。图3-27 右侧九分法（T4 / T8）只作对照。
- [ ] 上纵隔：上胸廓上口，下胸骨角至第 4 胸椎椎体下缘，前胸骨柄，后第 1～4 胸椎。
- [ ] 上纵隔自前向后：胸腺 → 左、右头臂静脉 → 上腔静脉 → 膈神经 → 迷走神经 → 喉返神经 → 主动脉弓及其 3 大分支 → 气管、食管、胸导管。
- [ ] 3 大分支（图3-26 由右向左）：头臂干、左颈总动脉、左锁骨下动脉。
- [ ] 下纵隔：上界 = 上纵隔下界，下界膈。前纵隔 = 胸骨体与心包之间；中纵隔 = 心包连同心脏；后纵隔 = 心包与脊柱胸部之间。
- [ ] 前纵隔内容：胸腺或遗迹、纵隔前淋巴结、胸廓内动脉纵隔支、疏松结缔组织、胸骨心包韧带。好发：胸腺瘤、皮样囊肿、淋巴瘤。

- [ ] 后纵隔内容：气管杈及左、右主支气管、食管、胸主动脉、奇静脉、半奇静脉、胸导管、交感干胸段、淋巴结。好发：支气管囊肿、神经瘤、主动脉瘤、膈疝。
- [ ] 升主动脉在中纵隔，主动脉弓在上纵隔，胸主动脉在后纵隔。气管在上纵隔，气管杈和主支气管在后纵隔。胸导管上纵隔后层和后纵隔都有。
- [ ] 左侧面（图3-24）先认左锁骨、左喉返神经、胸主动脉、半奇静脉 / 副半奇静脉、左主支气管；右侧面（图3-25）先认右锁骨、上腔静脉、奇静脉、气管、右主支气管。
- [ ] 纵隔气肿：向上经胸廓上口到颈，向下经主动脉裂孔及食管裂孔到腹膜后间隙。不走腔静脉孔，不等于气胸。
:::
