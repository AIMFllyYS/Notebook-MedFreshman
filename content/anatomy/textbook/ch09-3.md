# 第三节　周围神经系统

周围神经系统（peripheral nervous system）是除中枢神经系统以外、分布于全身各处的神经结构和神经组织。它与脑、脊髓相连，借末梢装置接到身体各器官和组织，把中枢和效应器、感受器接成一条回路。本节把「周围」这一户写完：脊神经、脑神经、内脏神经。传导通路是下一节的户头，不要提前写成束、交叉或皮质投射。脑屏障属中枢第三节，本节不开那一户。

周围部可以按与中枢的连接切成脊神经和脑神经，也可以按终末分布切成躯体神经和内脏神经。两把刀交叉：每一对脊神经、每一对脑神经都可以既含躯体纤维又含内脏纤维。为了叙述方便，本版把周围神经写成三部分——脊神经、脑神经，再把其中的内脏成分抽出来单立一户。

:::definition{label="周围神经系统"}
除中枢以外、遍布全身的神经结构。与脊髓相连的是**脊神经**（31 对），与脑相连的是**脑神经**（12 对）。中枢和周围在结构和功能上是一个整体，不是两套互不相干的系统。
:::

:::concept{term="先问连脊髓还是连脑，再问躯体还是内脏，再问传入还是传出"}
看见周围神经，先切脊神经和脑神经。再按对象切躯体（体表、骨、关节、骨骼肌）和内脏（内脏、心血管、平滑肌、腺体），按方向切入（感觉）和传出（运动）。把「周围」听成「就是四肢的神经」，脑神经和内脏神经会从开篇丢掉；把传导通路、脑屏障写进本节，又是吞了别的户。
:::

:::compare{title="本节三户（本版顺序）"}
| 户 | 本版要点 | 不要写成 |
|----|----------|----------|
| 脊神经 | 31 对；前根运动、后根感觉；四丛 + 胸神经前支保持节段 | 每条肌支一张定义；把马尾、脊髓外形从第二节搬回来 |
| 脑神经 | Ⅰ–Ⅻ 一张总表；三叉、面、迷走写短散文 | 把每条脑神经的核团再灌一遍脑干 |
| 内脏神经 | 交感 vs 副交感；牵涉痛点名本版例子 | 自主神经 = 全部内脏神经；把传导通路当内脏感觉 |

:::

从功能上看，周围任何一段都同时有感觉和运动。感觉神经把冲动从感受器送进中枢，又称传入神经；运动神经把冲动从中枢送到效应器，又称传出神经。内脏运动不受主观意志控制，又称自主神经或植物神经，再分为交感神经和副交感神经。总论已经切过这三把刀，本节落到具体干和丛。

周围部的形态名单是神经、神经节、神经丛和终末装置。躯体神经多呈条索状走到骨骼肌和皮肤；内脏神经多在脏器或血管周围交织成丛。神经元胞体在周围聚成**神经节**：脑神经节和脊神经节是感觉性的，内脏运动神经节再分为交感神经节和副交感神经节。

周围神经纤维与胞体离断后会发生溃变：离断数小时后轴突和髓鞘膨胀崩解。自损伤处向远侧段的溃变称顺行溃变；向近侧段的称逆行溃变。胞体肿胀、核偏位、尼氏体溶解。第 2～3 周起，尼氏体恢复、核回中央，轴突向远侧生出幼芽，沿仍然存活的施万细胞索生长，到达原来的靶器官后增粗成髓。施万细胞增生是再生最重要的条件。临床常用神经束膜端端吻合保证对位。

:::compare{title="溃变方向（不要记反）"}
| | 走向 | 本版要点 |
|--|------|----------|
| 顺行溃变 | 损伤处 → 纤维远侧段 | 与胞体离断的那段先崩 |
| 逆行溃变 | 损伤处 → 纤维近侧段 | 可波及胞体；严重则神经元死亡 |

再生靠的是还活着的施万细胞索，不是把崩掉的轴突重新粘回去。
:::

:::pitfall{label="周围神经再生不要听成中枢也能同样再生"}
本版写的是周围纤维沿施万细胞索长回去。中枢少突胶质和微环境不同，不要把「第 2～3 周开始再生」套到脊髓和脑的长束上。
:::

## 一、脊神经

### （一）概述

脊神经（spinal nerves）连接脊髓，共 **31 对**。每对连一个脊髓节段，由前根（anterior root）和后根（posterior root）在椎间孔处合成，成为既含感觉又含运动的混合神经。前根连脊髓前外侧沟，由运动性根丝构成；后根连后外侧沟，由感觉性根丝构成。后根在椎间孔处有椭圆形膨大，称脊神经节（spinal ganglion），内含假单极感觉神经元。

:::definition{label="脊神经"}
连于脊髓的周围神经，**31 对**。前根运动、后根感觉，在椎间孔合成混合神经。不是「前根管前面的皮肤、后根管后面的肌肉」。
:::

:::definition{label="脊神经节"}
后根在椎间孔处的膨大，假单极感觉神经元的胞体所在。中枢突进后根入脊髓，周围突加入脊神经走到感受器。运动神经元的胞体不在这里，在脊髓前角或侧角。
:::

:::compare{title="31 对怎么拆"}
| 部 | 对数 | 出椎管 |
|----|------|--------|
| 颈神经 | 8 | 第 1 颈神经走寰椎与枕骨之间；第 2～7 经同序数颈椎**上方**的椎间孔；第 8 经第 7 颈椎**下方**的椎间孔 |
| 胸神经 | 12 | 同序数椎骨下方的椎间孔 |
| 腰神经 | 5 | 同序数椎骨下方的椎间孔 |
| 骶神经 | 5 | 第 1～4 经同序数骶前孔和骶后孔；第 5 经骶管裂孔 |
| 尾神经 | 1 | 骶管裂孔 |

颈神经 8 对、颈椎 7 块，所以 C8 只能走 C7 下方。写成「每对都走同序数椎骨下方」，第 2～7 颈神经会对错孔。
:::

颈神经根最短、近于水平；胸神经根斜向外下；腰神经根最长、几近垂直下行，在无脊髓的椎管内参与形成马尾。合成后的脊神经都在椎间孔穿出，前方是椎体及椎间盘，后方是关节突关节和黄韧带，上、下是椎切迹。椎间盘突出、关节突增生或黄韧带肥厚，都可能在这里同时伤到感觉和运动。

脊神经含 4 种纤维（图9-104）。

::figure{src="/images/anatomy/textbook/p0359_01.png" caption="图9-104　脊神经的组成、分支和分布示意图" alt="脊髓横切：后根连脊神经节，前根出前角；前支、后支、白交通支和灰交通支连交感干；左侧示躯体感觉（触、痛、本体）、内脏感觉、内脏运动和躯体运动四种纤维分别走到皮肤、肌梭、骨骼肌、血管和胃"}

:::compare{title="脊神经四种纤维"}
| 纤维 | 胞体 / 起点 | 周围走到 | 传入还是传出 |
|------|-------------|----------|--------------|
| 躯体感觉 | 脊神经节假单极 | 皮肤、骨骼肌、肌腱、关节 | 传入：浅感觉（痛、温、触）+ 深感觉（运动觉、位置觉） |
| 内脏感觉 | 脊神经节假单极 | 内脏、心血管、腺体感受器 | 传入 |
| 躯体运动 | 脊髓前角运动神经元 | 躯干和肢体骨骼肌 | 传出，随意运动 |
| 内脏运动 | 胸髓 12 节段 + 腰髓 1～3 中间带外侧核（交感）；骶髓 2～4 骶副交感核 | 内脏、心血管、腺体效应器 | 传出，心肌和平滑肌、腺体 |

四种都在同一条脊神经干里。写成「脊神经只有躯体感觉和躯体运动」，内脏这一户会从椎间孔丢掉。
:::

:::insight{label="图9-104 先数四色，再数前支后支和交通支"}
左侧四色线分别进皮肤、肌梭、骨骼肌、血管和胃——对应四种纤维。右侧后根有节、前根无节；前支出前，后支出后，灰、白交通支把脊神经接到交感干。本节先认这张组成图，皮区图放到节段性那一小节。
:::

前根和后根合成脊神经后立即分为 4 支：前支、后支、脊膜支和交通支。

:::compare{title="脊神经干的四支"}
| 支 | 本版 | 要点 |
|----|------|------|
| 前支 | 最粗，混合性 | 躯干前外侧部和四肢的肌及皮肤。胸神经前支保持节段；其余交织成颈丛、臂丛、腰丛、骶丛 |
| 后支 | 较细，混合性 | 经横突之间或骶后孔向后，分肌支和皮支，走项、背、腰、骶、臀部。节段性明显 |
| 交通支 | 连交感干 | 白交通支：有髓节前纤维，脊神经 → 交感干；灰交通支：无髓节后纤维，交感干 → 脊神经 |
| 脊膜支 | 返回椎管 | 被膜、血管壁、骨膜、韧带、椎间盘。每条都接受邻近灰交通支。上 3 对颈神经脊膜支可到颅后窝硬脑膜 |

:::

后支里几条有独立名称，放在表里记，不再各开定义：第 1 颈神经后支为枕下神经，走寰椎后弓上方与椎动脉下方之间，支配椎枕肌；第 2 颈神经后支的皮支为枕大神经，穿斜方肌腱至枕、项部皮肤；第 3 颈神经后支内侧支为第 3 枕神经，至枕部下方皮肤；第 1～3 腰神经后支外侧支为臀上皮神经；第 1～3 骶神经后支皮支为臀中皮神经。

脊神经走行还有几条共同形态：较大的干多与血管伴行成血管神经束，在关节屈侧走；干上再分皮支、肌支和关节支。皮支穿深筋膜浅出，常伴浅静脉，含躯体感觉和到血管、竖毛肌、汗腺的内脏运动纤维。肌支多从肌的近侧端入肌。关节支可一条神经管几个关节，一个关节也可接受几条神经。坐骨神经行程中没有相应伴行血管，是胚胎期伴行血管退化。相邻皮支分布区有重叠。

:::pitfall{label="前支成丛，不等于后支也成丛"}
除胸神经前支外，颈、臂、腰、骶的前支才交织成丛。后支保持节段，不要把枕大神经、臀上皮神经写成「后支丛」。
:::

### （二）颈丛

颈丛（cervical plexus）由第 1～4 颈神经前支交织构成（图9-105），位于胸锁乳突肌上部深面，中斜角肌和肩胛提肌起始端的前方。分支分三类：皮支、肌支、交通支。

::figure{src="/images/anatomy/textbook/p0361_01.png" caption="图9-105　颈丛的组成及颈袢示意图" alt="C1～C4 前支交织：上方枕小神经、耳大神经，前方颈横神经，下方锁骨上神经；C1 纤维加入舌下神经后分出舌下神经降支，与 C2、C3 的颈神经降支在环状软骨水平合成颈袢，发支至舌骨下肌群；C3～C5 合成膈神经；内侧可见颈上神经节"}

皮支在胸锁乳突肌深面集中，从该肌**后缘中点**附近浅出，散向一侧颈部皮肤。这个浅出点是颈部浅层浸润麻醉的阻滞点，临床称神经点。肌支支配颈部深层肌、肩胛提肌、舌骨下肌群和膈肌。

:::definition{label="颈丛"}
**C1～C4** 前支构成。位置：胸锁乳突肌上部深面。皮支从胸锁乳突肌后缘中点浅出；最重要的肌支是膈神经。
:::

:::compare{title="颈丛主要终支（名单收表，不再各开定义）"}
| 支 | 节段 | 走行和分布 |
|----|------|------------|
| 枕小神经 | C2 | 沿胸锁乳突肌后缘上行，枕部及耳郭背面上部皮肤 |
| 耳大神经 | C2、C3 | 沿胸锁乳突肌表面向耳垂上行，耳郭及附近皮肤。位置表浅，可作神经移植供体（长约 5.5～7.4 cm，直径 2～4 mm） |
| 颈横神经 | C2、C3 | 横过胸锁乳突肌表面向前，颈前部皮肤；与面神经分支常有交通 |
| 锁骨上神经 | C3、C4 | 2～4 支，辐射向下外越过锁骨，颈侧区下份、胸壁上部和肩部皮肤 |
| 膈神经 | C3～C5 | 见下段短文 |
| 颈袢 | C1～C3 与舌下神经交通 | 舌下神经降支（来自 C1）与颈神经降支（C2、C3）在环状软骨水平结合，发支支配舌骨下肌群 |

:::

膈神经（phrenic nerve，C3～C5）是颈丛最重要的肌支。起初在前斜角肌上端外侧下行，沿该肌前面降到内侧，在锁骨下动、静脉之间经胸廓上口入胸腔；入胸后伴心包膈血管，经肺根前方，在纵隔胸膜与心包之间下行到膈，于中心腱附近入膈。运动纤维支配膈肌；感觉纤维走胸膜、心包和膈下面部分腹膜。一般认为右膈神经的感觉纤维还到肝、胆囊和肝外胆道的浆膜。损伤后同侧半膈肌运动障碍，腹式呼吸减弱或消失，严重可有窒息感；受刺激则呃逆。副膈神经不恒定，国人出现率约 48%，多发自 C4、C5，也可起自 C6，在锁骨下静脉上或下方加入膈神经。

颈丛与副神经、迷走神经、交感神经都有交通。最重要的交通形式就是颈袢，不要把舌骨下肌群写成「舌下神经本干支配」——纤维来自颈神经，只是借道舌下神经走一段。

:::pitfall{label="膈神经是 C3～C5，不是「颈丛只有 C1～C4 所以不管膈」"}
颈丛本体是 C1～C4，膈神经还收 C5 的纤维。写成「C1～C4 管膈」，漏了 C5；写成「膈神经只管运动」，胸膜、心包、右肝胆的感觉会丢掉。胆囊病变牵到右肩，部分就是右膈神经这条感觉路。
:::

:::insight{label="图9-105 先认四条皮支散开，再认颈袢和膈神经下行"}
枕小、耳大、颈横、锁骨上从丛上散开；深面两条降支合成颈袢，最下一条干是膈神经。颈上神经节贴在内侧，那是交感干的户，不要把颈袢当成交感神经袢。
:::

### （三）臂丛

臂丛（brachial plexus）由第 5～8 颈神经前支和第 1 胸神经前支的大部分纤维构成。经斜角肌间隙向外穿出，在锁骨后方进入腋窝；出间隙后位于锁骨下动脉后上方。五条前支反复分支组合，最后形成三个束，在腋窝内分别走在腋动脉的内侧、外侧和后方，因而称内侧束、外侧束和后束（图9-108）。分支按发出部位分为锁骨上分支和锁骨下分支。

::figure{src="/images/anatomy/textbook/p0363_01.png" caption="图9-108　臂丛组成模式图" alt="右侧颈根和腋窝：C5～T1 前支合成上干、中干、下干，再编成外侧束、后束、内侧束夹持腋动脉；可见胸长神经、肩胛下神经上支和下支、胸背神经、肌皮神经、腋神经、桡神经、正中神经、尺神经、臂内侧皮神经和前臂内侧皮神经"}

:::definition{label="臂丛"}
**C5～T1**（T1 前支大部）。穿斜角肌间隙，三束夹腋动脉中段。锁骨上分支发自根和干，锁骨下分支发自三个束。
:::

| 尺神经 | C8、T1 | 内侧束 | 前臂尺侧屈肌和手内在肌大部；见下段 |
| 臂内侧皮神经 | C8、T1 | 内侧束 | 臂内侧和臂前面皮肤；腋窝内常与肋间臂神经交通 |
| 前臂内侧皮神经 | C8、T1 | 内侧束 | 前臂内侧前、后面皮肤，终末可到腕部 |

:::

正中神经由内、外侧根夹持腋动脉会合。臂部沿肱二头肌内侧沟下行，逐渐从肱动脉外侧跨到内侧，降入肘窝；穿旋前圆肌和指浅屈肌腱弓，在指浅、深屈肌之间到腕，经桡侧腕屈肌腱与掌长肌腱之间入腕管，在掌腱膜深面到手掌。臂部一般无分支。前臂支配除肱桡肌、尺侧腕屈肌和指深屈肌尺侧半以外的前臂屈肌和旋前肌。腕部发返支入鱼际，支配除拇收肌以外的鱼际肌；手掌发指掌侧总神经，再分指掌侧固有神经。手部运动：第 1、2 蚓状肌和鱼际肌（拇收肌除外）；感觉：桡侧半手掌、桡侧三个半指掌面及其中、远节指背。旋前圆肌综合征是正中神经在旋前圆肌和指浅屈肌腱弓处受压。腕管综合征：鱼际萎缩，拇指不能外展、对掌和对指，桡侧三个半指掌面及桡侧半手掌感觉障碍。

尺神经自内侧束发出，伴肱动脉内侧到臂中部，穿内侧肌间隔入尺神经沟，再穿尺侧腕屈肌起点到前臂，伴尺动脉下行。腕上发手背支后，主干在豌豆骨桡侧、屈肌支持带浅面分浅、深支入掌（腕管浅面）。臂部无分支。前臂肌支：尺侧腕屈肌和指深屈肌尺侧半。手背支：手背尺侧半和小指、环指尺侧半指背，以及环指桡侧半、中指尺侧半近节指背。浅支：小鱼际皮肤、小指掌面和环指尺侧半掌面。深支：小鱼际肌、拇收肌、骨间肌及第 3、4 蚓状肌。易伤部位：肱骨内上髁后方、尺侧腕屈肌起点、豌豆骨外侧。前两处损伤出现屈腕力弱，环、小指远节不能屈，小鱼际和骨间肌萎缩，拇指不能内收，指不能靠拢，掌指关节过伸，呈爪形手；手掌和手背内侧缘感觉丧失。豌豆骨处受损时感觉支已发出，皮肤感觉可不受影响。正中神经合并尺神经损伤，鱼际和小鱼际都萎缩，手掌变平坦，称猿掌。尺神经在尺神经沟内位置最浅，极易触及。

桡神经发自后束，先在腋动脉后方，伴肱深动脉经肱三头肌长头与内侧头之间，沿桡神经沟绕肱骨中段后面旋向外下，在肱骨外上髁上方穿外侧肌间隔，于外上髁前方分浅、深两终支。浅支为皮支，沿桡动脉外侧下行，前臂中、下 1/3 交界处转背侧，到手背桡侧半和桡侧两个半指近节背面。深支较粗，穿旋后肌至前臂后面，沿骨间膜后面下行，又称骨间后神经，支配前臂伸肌群。臂部肌支：肱三头肌、肘肌、肱桡肌和桡侧腕长伸肌。肱骨中段或中下 1/3 交界处骨折易合并桡神经损伤，前臂伸肌瘫，抬前臂呈垂腕，第 1、2 掌骨间背面感觉障碍明显。桡骨颈骨折可伤深支，伸腕无力、不能伸指。

腋神经穿四边孔后绕肱骨外科颈。外科颈骨折、肩关节脱位、腋杖压迫都可能损伤，三角肌瘫：臂不能外展，肩部和臂外上部皮肤感觉障碍，三角肌萎缩后肩部失去圆隆，称方肩。肌皮神经损伤则屈肘无力和前臂外侧皮肤感觉减弱。

::figure{src="/images/anatomy/textbook/p0367_02.png" caption="图9-115　桡、尺和正中神经损伤时的手形及皮肤感觉丧失区" alt="A 垂腕，手背桡侧和拇指感觉区着色；B 爪形手，尺侧一个半指着色；C 正中神经损伤手形，鱼际平坦，桡侧三个半指着色；D 猿掌，正中神经合并尺神经，鱼际和小鱼际都萎缩，桡侧和尺侧感觉区同时着色"}

:::compare{title="正中、尺、桡三干（损伤体征对表）"}
| | 正中神经 | 尺神经 | 桡神经 |
|--|----------|--------|--------|
| 束 | 内、外侧束各一根 | 内侧束 | 后束 |
| 易伤处 | 旋前圆肌 / 指浅屈肌腱弓；腕管 | 尺神经沟；尺侧腕屈肌起点；豌豆骨外侧 | 桡神经沟（肱骨中段）；桡骨颈（深支） |
| 运动要点 | 前臂屈肌和旋前肌（肱桡肌、尺侧腕屈肌、指深屈肌尺侧半除外）；鱼际（拇收肌除外）；第 1、2 蚓状肌 | 尺侧腕屈肌、指深屈肌尺侧半；小鱼际、骨间肌、拇收肌、第 3、4 蚓状肌 | 上肢伸肌；肱桡肌、桡侧腕长伸肌在臂部已发出 |
| 手形 | 猿掌（合并尺神经时更典型）；拇指对掌不能 | 爪形手 | 垂腕 |
| 感觉 | 桡侧三个半指掌面及桡侧半手掌 | 手掌和手背内侧缘（豌豆骨处可保留） | 手背桡侧、第 1～2 掌骨间背面最明显 |

三干不要按「屈肌全归正中、伸肌全归桡」来记：肱桡肌是桡神经的，尺侧腕屈肌和指深屈肌尺侧半是尺神经的，拇收肌是尺神经的。
:::

:::pitfall{label="垂腕、爪形手、猿掌不要对错神经"}
垂腕是桡神经（伸肌瘫）。爪形手是尺神经（骨间肌、蚓状肌 3～4 瘫，掌指过伸、指间不能屈）。猿掌是正中神经（常合并尺神经）鱼际、小鱼际萎缩，掌弓变平。写成「尺神经垂腕」或「桡神经爪形手」，图9-115 四幅对不上。
:::

:::insight{label="图9-108 先认三干三束夹动脉，再认正中神经两根会合"}
上、中、下干在锁骨后方编束，外侧束、后束、内侧束把腋动脉夹在中间。正中神经由内、外侧根呈锐角会合，尺神经贴内侧束下行，桡神经和腋神经从后束出。胸长神经走在丛的后方，不要把它算进三个束。
:::

### （四）胸神经前支

胸神经前支 12 对。第 1～11 对走相应肋间隙，称肋间神经；第 12 对称肋下神经。肋间神经在肋间内、外肌之间，肋间血管下方，沿肋骨下缘的肋沟前行，至腋前线附近离开肋沟，改走肋间隙中间。第 1 胸神经前支大部分加入臂丛，余部走第 1 肋间隙。第 2 肋间神经外侧皮支称肋间臂神经，横过腋窝到臂上部内侧，与臂内侧皮神经交通。第 4～6 肋间神经外侧皮支和第 2～4 前皮支分支到乳房。第 7～11 肋间神经及肋下神经出肋间隙后走腹横肌与腹内斜肌之间，在腹直肌外侧缘穿腹直肌鞘，支配腹前外侧壁肌。

::figure{src="/images/anatomy/textbook/p0368_01.png" caption="图9-116　肋间神经走行及分支" alt="胸腔横切：胸神经前支出椎间孔后走肋沟，位于肋间后动脉下方；分出外侧皮支和前皮支；后支出向背部；交通支连交感干；胸主动脉和奇静脉在椎前，胸廓内动脉在胸骨两侧"}

胸神经前支在胸、腹壁皮肤的分布节段性非常明显，由上向下按序数排列。临床用地标记平面：

:::compare{title="胸神经皮支的节段地标"}
| 神经 | 平面 |
|------|------|
| T2 | 胸骨角 |
| T4 | 乳头 |
| T6 | 剑突 |
| T8 | 两侧肋弓中点连线 |
| T10 | 脐 |
| T12 | 脐与耻骨联合连线中点 |

可以根据感觉障碍的皮肤区反推受损胸神经，也可以由已知受损神经估计感觉障碍范围。
:::

:::pitfall{label="肋间神经在肋沟里走在血管下方"}
血管神经束在肋沟内的次序是静脉、动脉、神经（上→下）。写成「神经贴着肋骨上缘」或「神经在动脉上方」，胸腔穿刺进针点会扎错。穿刺应靠肋骨上缘进针，避开肋沟里的束。
:::

:::insight{label="图9-116 先认前支出肋沟，再认外侧皮支和前皮支浅出"}
椎旁是后支和交通支，肋间隙里是前支（肋间神经），腋前线附近出外侧皮支，近胸骨处出前皮支。胸廓内动脉在最前，不要和肋间后动脉记反。
:::

### （五）腰丛

腰丛（lumbar plexus）由第 12 胸神经前支的一部分、第 1～3 腰神经前支及第 4 腰神经前支的一部分组成（图9-118）。位于腰大肌深面、腰椎横突前方。就近支配髂腰肌和腰方肌，长支走到腹股沟区、大腿前面和内侧。

:::definition{label="腰丛"}
**T12 一部分 + L1～L3 + L4 一部分**。腰大肌深面。最大支是股神经，走腰大肌外侧缘；闭孔神经走内侧缘。
:::

:::compare{title="腰丛主要终支"}
| 神经 | 节段 | 出腰大肌 | 分布要点 |
|------|------|----------|----------|
| 髂腹下神经 | T12、L1 | 外侧缘 | 经肾后面、腰方肌前面，腹股沟管浅环上方约 3 cm 穿出。腹壁肌；臀外侧、腹股沟区及下腹部皮肤 |
| 髂腹股沟神经 | L1 | 外侧缘，在髂腹下神经下方 | 入腹股沟管，与精索或子宫圆韧带伴行，从浅环穿出。腹壁肌；腹股沟部、阴囊或大阴唇皮肤 |
| 股外侧皮神经 | L2、L3 | 外侧缘 | 过髂肌表面，在腹股沟韧带深面入股，髂前上棘下方 5～6 cm 浅出，大腿前外侧皮肤 |
| 股神经 | L2～L4 | 外侧缘，最粗 | 见下段 |
| 闭孔神经 | L2～L4 | 内侧缘 | 贴盆壁，伴闭孔血管穿闭膜管，分前、后支。闭孔外肌、长/短/大收肌、股薄肌（偶至耻骨肌）；大腿内侧皮肤；髋、膝关节 |
| 生殖股神经 | L1、L2 | 前面穿出 | 生殖支入腹股沟管，提睾肌和阴囊（或随子宫圆韧带至大阴唇）；股支至股三角皮肤。疝修补和盲肠后位阑尾手术勿伤 |

:::

股神经是腰丛最大支。在腰大肌与髂肌之间下行，于腹股沟韧带中点稍外侧的深面入股三角，走在股动脉外侧。肌支：髂肌、耻骨肌、股四头肌、缝匠肌。皮支：股中间、股内侧皮神经走大腿和膝关节前面；最长的是隐神经，伴股动脉入收肌管，出管后在缝匠肌下端后方浅出，伴大隐静脉沿小腿内侧面到足内侧缘。股神经尚有支至膝关节和股动脉。损伤：屈髋无力，坐位不能伸膝，行走困难，膝跳反射消失，大腿前面和小腿内侧面感觉障碍。

闭孔神经在股内侧区先入长收肌再入股薄肌。用股薄肌替代肛门外括约肌时要保留这一支。副闭孔神经偶见，沿腰大肌内侧缘下行，跨耻骨上支至耻骨肌和髋关节。

:::pitfall{label="股神经出外侧缘，闭孔神经出内侧缘"}
两支都是 L2～L4，差别在腰大肌的哪一侧穿出。写成「闭孔神经也走腹股沟韧带中点入股三角」，就把闭膜管和股三角并成一个出口。隐神经是股神经的皮支，不是独立从腰丛发出的干。
:::

### （六）骶丛

骶丛（sacral plexus）由来自腰丛的腰骶干和全部骶、尾神经前支组成。腰骶干由 L4 前支余部和 L5 前支在腰丛下方合成，越盆腔上口入小骨盆加入骶丛。按参与的脊神经数目，骶丛是全身最大的脊神经丛（图9-118）。位于盆内，骶骨和梨状肌前面、髂血管后方；左侧前方有乙状结肠，右侧前方有回肠襻。盆腔脏器恶性肿瘤可浸润此丛。

::figure{src="/images/anatomy/textbook/p0369_02.png" caption="图9-118　腰、骶丛的组成模式图" alt="腰椎和骨盆前面：上方肋下神经、髂腹下神经、髂腹股沟神经、生殖股神经、股外侧皮神经从腰丛发出，闭孔神经和股神经分列内侧与外侧；腰骶干下行加入骶丛，发出阴部神经和坐骨神经，坐骨神经经坐骨大孔出盆"}

:::definition{label="骶丛"}
**腰骶干（L4 余部 + L5）+ S1～S5 + 尾神经前支**。梨状肌前面。全身最大的脊神经丛。最长最粗的支是坐骨神经。
:::

短支就近到梨状肌、闭孔内肌、股方肌等盆壁肌。长支名单如下。

:::compare{title="骶丛主要长支"}
| 神经 | 节段 | 出盆 | 分布要点 |
|------|------|------|----------|
| 臀上神经 | L4、L5、S1 | 梨状肌上孔，伴臀上血管 | 臀中肌、臀小肌、阔筋膜张肌 |
| 臀下神经 | L5、S1、S2 | 梨状肌下孔，伴臀下血管 | 臀大肌 |
| 股后皮神经 | S1～S3 | 梨状肌下孔 | 臀区、股后区和腘窝皮肤 |
| 阴部神经 | S2～S4 | 梨状肌下孔 → 绕坐骨棘经坐骨小孔入坐骨肛门窝 | 肛神经（肛门外括约肌和肛门皮肤）、会阴神经（会阴肌、阴囊或大阴唇）、阴茎/阴蒂背神经 |
| 坐骨神经 | L4、L5、S1～S3 | 梨状肌下孔（最常见） | 见下段 |

:::

坐骨神经是全身直径最大、行程最长的神经。出盆后走臀大肌深面，在坐骨结节与大转子连线中点深面下行入股后区，行于股二头肌长头深面，一般在腘窝上方分为胫神经和腓总神经。股后区肌支：股二头肌、半腱肌、半膜肌，并有支至髋关节。体表投影：坐骨结节与大转子连线中点 → 股骨内、外侧髁连线中点，上 2/3 段即股后区投影，坐骨神经痛时常沿此线压痛。

出盆与梨状肌的关系有变异。国人单干经梨状肌下孔出盆占 66.3%；其余 33.7% 包括单干穿梨状肌、一支出梨状肌一支出下孔、一支出上孔一支出下孔。单干穿梨状肌对神经最不利，长期受压可致梨状肌综合征。分叉部位也可提前到出盆处甚至盆内。

胫神经（L4、L5、S1～S3）是本干的延续，入腘窝后伴腘血管到小腿后区、比目鱼肌深面，伴胫后血管至内踝后方，在踝管内分为足底内侧神经和足底外侧神经。足底内侧神经：足底内侧肌群，足底内侧半及内侧三个半趾跖面皮肤。足底外侧神经：足底中间群和外侧群肌，足底外侧半及外侧一个半趾跖面皮肤。小腿后群肌由胫神经肌支支配。皮支主要是腓肠内侧皮神经，在小腿下部与腓肠外侧皮神经吻合成腓肠神经，经外踝后方至足外侧缘。损伤：足不能跖屈、不能以足尖站立、内翻力弱，足底感觉障碍；前外侧群过度牵拉，足呈背屈外翻，称钩状足。

腓总神经（L4、L5、S1、S2）沿股二头肌腱内侧向外下，绕腓骨颈向前穿腓骨长肌，分为腓浅神经和腓深神经。腓浅神经走腓骨长、短肌与趾长伸肌之间，支配腓骨长、短肌，终支在小腿中下 1/3 交界处浅出，小腿外侧、足背和第 2～5 趾背皮肤。腓深神经伴胫前血管走小腿前群肌之间，至足背，支配小腿前群肌、足背肌及第 1、2 趾相对缘皮肤。腓骨颈处最表浅，易伤。伤后前、外侧群肌丧失：足不能背屈、趾不能伸，足下垂且内翻，呈马蹄内翻足，行走呈跨阈步态；小腿前外侧及足背感觉障碍。

尾丛由 S4、S5 前支及尾神经分支构成，位于尾骨盆面，分支到尾骨肌、部分肛提肌和骶尾关节；肛尾神经至尾骨背面小片皮肤。

:::compare{title="钩状足和马蹄内翻足"}
| | 损伤 | 不能做的动作 | 足的姿势 |
|--|------|--------------|----------|
| 钩状足 | 胫神经 | 跖屈、以足尖站立；内翻力弱 | 背屈 + 外翻 |
| 马蹄内翻足 | 腓总神经 | 背屈、伸趾 | 下垂 + 内翻；跨阈步态 |

一个是小腿后群瘫，一个是前外侧群瘫，方向正好相反。不要都写成「足下垂」。
:::

:::pitfall{label="坐骨神经最常见是梨状肌下孔出盆，不是穿梨状肌"}
66.3% 单干走下孔。穿梨状肌是变异，而且是对神经最不利的一种。写成「坐骨神经都穿梨状肌」，梨状肌综合征的形态学前提就被说成了常态。
:::

:::insight{label="图9-118 先认腰丛在腰大肌深面，再认腰骶干掉进盆里"}
腰丛的皮支和股神经、闭孔神经在上方散开；一束腰骶干贴骶骨前面加入骶丛，最粗的干从坐骨大孔出去，就是坐骨神经。阴部神经更靠内侧。不要把股神经画进骶丛。
:::

### （七）皮神经分布的节段性和重叠性

胚胎早期每个脊髓节段的脊神经都管特定的肌节和皮节。后来肌群和皮肤位置变了，对应的脊神经和节段并不改。躯干背面的后支、胸神经前支的外侧皮支和前皮支，节段性都还清楚。四肢因为肢芽生长方向的关系，典型节段被拉乱：组成神经丛的最上和最下一支往往分布到肢体近侧靠近躯干处，中间几支走到远侧和手、足。臂丛里 C5 和 T1 管上肢近侧，C6～C8 管远侧和手；腰骶丛在下肢也是同样逻辑（图9-125）。

::figure{src="/images/anatomy/textbook/p0374_01.png" caption="图9-125　脊神经的节段性分布（前面观和后面观）" alt="人体前面和后面皮节图：躯干呈环带，T4 平乳头、T10 平脐；上肢前面 C5～C7 走桡侧、C8 走尺侧，T1 走臂内侧；下肢前面 L2～L4 走大腿和小腿内侧，L5 走足背，S1 走足外侧；后面颈项为 C2～C4，躯干 T 段环带，臀部 S 段，足底和足外侧为 S1、S2"}

相邻两条皮神经的分布区互相重叠。一条皮神经受损，该区多半只是感觉迟钝，不是完全丧失；两条以上相邻皮神经同时受损，才会出现分布区感觉完全消失。这个重叠性加上节段性地标，是定位诊断的形态底板。

:::pitfall{label="一条皮神经断了，不要写成整块皮区麻木消失"}
重叠存在，单根损伤常只是迟钝。写成「断了哪根、哪块皮肤完全没感觉」，把图9-125 的虚线边界听成了绝缘墙。
:::

:::insight{label="图9-125 躯干看横带，四肢看从近到远哪几节被拉长"}
胸腹是 T 段环带，乳头 T4、脐 T10 仍在。上肢前面桡侧是 C6、C7，尺侧是 C8；下肢前面大腿 L2、L3，小腿内侧 L4，足背 L5，足外侧 S1。不要用胸神经的横带去套手指。
:::

## 二、脑神经

脑神经（cranial nerves）是与脑相连的周围神经，共 12 对。按连脑先后用罗马数字编号：Ⅰ 嗅、Ⅱ 视、Ⅲ 动眼、Ⅳ 滑车、Ⅴ 三叉、Ⅵ 展、Ⅶ 面、Ⅷ 前庭蜗、Ⅸ 舌咽、Ⅹ 迷走、Ⅺ 副、Ⅻ 舌下。Ⅰ 连端脑，Ⅱ 连间脑，Ⅲ～Ⅳ 连中脑，Ⅴ～Ⅷ 连脑桥，Ⅸ～Ⅻ 连延髓（图9-127）。

:::definition{label="脑神经"}
与脑相连的周围神经，**12 对**。有的只含感觉，有的只含运动，有的混合。每一对脊神经都是混合的，脑神经不是。
:::

::figure{src="/images/anatomy/textbook/p0376_01.png" caption="图9-127　脑神经概况" alt="脑干腹面发出十二对脑神经：嗅神经至鼻黏膜，视神经至眼球，动眼、滑车、展神经至眼外肌，三叉神经三大支至头面皮肤和咀嚼肌，面神经至面肌并含副交感，前庭蜗神经至内耳，舌咽、迷走至咽喉和胸腹腔脏器，副神经至胸锁乳突肌和斜方肌，舌下神经至舌肌。红线运动，黄线副交感，蓝线感觉"}

头面部衍化出眼、耳、鼻、咽、喉、口，所以脑神经的纤维成分比脊神经复杂，共 7 种。就某一对而言，可以只含一种，也可以含多种。

:::compare{title="脑神经七种纤维"}
| 纤维 | 分布 / 起点 | 本版例子 |
|------|-------------|----------|
| 一般躯体感觉 | 皮肤、肌、肌腱、口腔及鼻腔黏膜、结膜、角膜、脑膜 | 三叉神经三大支 |
| 一般内脏感觉 | 头、颈、胸、腹部内脏 | 迷走、舌咽 |
| 一般躯体运动 | 脑干一般躯体运动核 → 肌节衍化的骨骼肌 | 眼外肌、舌肌（Ⅲ、Ⅳ、Ⅵ、Ⅻ） |
| 一般内脏运动 | 脑干副交感核 → 器官旁节或壁内节换元 | Ⅲ、Ⅶ、Ⅸ、Ⅹ 的副交感 |
| 特殊躯体感觉 | 视器、前庭蜗器 | Ⅱ、Ⅷ |
| 特殊内脏感觉 | 味蕾、嗅器 | Ⅰ、Ⅶ、Ⅸ |
| 特殊内脏运动 | 脑干特殊内脏运动核 → 鳃弓衍化的骨骼肌 | 咀嚼肌、面肌、咽喉肌（Ⅴ、Ⅶ、Ⅸ、Ⅹ、Ⅺ） |

「特殊内脏运动」管的仍是骨骼肌，只是来源于鳃弓，不要听成平滑肌。
:::

:::compare{title="感觉性、运动性、混合性"}
| 类 | 对 | 不要写成 |
|----|----|----------|
| 感觉性 | Ⅰ、Ⅱ、Ⅷ | 把三叉也算纯感觉（它有运动根） |
| 运动性 | Ⅲ、Ⅳ、Ⅵ、Ⅺ、Ⅻ | 把动眼算纯躯体运动（它含副交感） |
| 混合性 | Ⅴ、Ⅶ、Ⅸ、Ⅹ | 把迷走算纯内脏 |

:::

:::compare{title="脑神经与脊神经的三处不同"}
| | 脑神经 | 脊神经 |
|--|--------|--------|
| 纤维搭配 | 可纯感觉、纯运动或混合 | 每一对都是混合 |
| 特殊感觉器 | 有 Ⅰ、Ⅱ、Ⅷ | 无对等的特殊感觉对 |
| 内脏运动 | 一般内脏运动是副交感，只在 Ⅲ、Ⅶ、Ⅸ、Ⅹ | 主要是交感（胸神经 12 对 + L1～L3）；副交感只在 S2～S4 |

:::

感觉纤维的胞体绝大多数是假单极，在脑外聚成三叉神经节（Ⅴ）、膝神经节（Ⅶ）、舌咽和迷走的上、下神经节（Ⅸ、Ⅹ）。与平衡、听觉相关的是双极神经元，聚成前庭神经节和蜗神经节（Ⅷ）。

:::compare{title="Ⅰ–Ⅻ 总表（性质、出颅、主要分布）"}
| | 性质 | 连脑 | 出颅 | 主要分布 | 损伤要点 |
|--|------|------|------|----------|----------|
| Ⅰ 嗅 | 感觉 | 端脑 | 筛孔 | 鼻腔嗅黏膜 | 嗅觉障碍；筛板骨折可致脑脊液鼻漏 |
| Ⅱ 视 | 感觉 | 间脑 | 视神经管 | 视网膜 | 视觉障碍；颅内压高可致视神经盘水肿 |
| Ⅲ 动眼 | 运动（含副交感） | 中脑 | 眶上裂 | 上睑提肌，上、下、内直肌，下斜肌；睫状神经节 → 瞳孔括约肌、睫状肌 | 上睑下垂、眼外下斜、瞳孔散大、对光反射消失 |
| Ⅳ 滑车 | 运动 | 中脑 | 眶上裂 | 上斜肌 | 眼不能外下斜视 |
| Ⅴ 三叉 | 混合 | 脑桥 | V1 眶上裂，V2 圆孔，V3 卵圆孔 | 头面皮肤、口鼻黏膜、牙、眼球、硬脑膜；咀嚼肌等 | 见短文 |
| Ⅵ 展 | 运动 | 脑桥 | 眶上裂 | 外直肌 | 内斜视 |
| Ⅶ 面 | 混合 | 脑桥 | 内耳门 → 茎乳孔 | 面肌；泪腺、下颌下腺、舌下腺；舌前 2/3 味觉 | 见短文 |
| Ⅷ 前庭蜗 | 感觉 | 脑桥 | 内耳门 | 壶腹嵴、球囊斑、椭圆囊斑；螺旋器 | 伤侧耳聋、平衡障碍，可伴恶心呕吐 |
| Ⅸ 舌咽 | 混合 | 延髓 | 颈静脉孔 | 茎突咽肌；腮腺；舌后 1/3 黏膜和味蕾；颈动脉窦、颈动脉小球 | 舌后 1/3 感觉和味觉障碍，咽反射消失 |
| Ⅹ 迷走 | 混合 | 延髓 | 颈静脉孔 | 咽喉肌；颈、胸、腹腔脏器（结肠左曲以上） | 见短文 |
| Ⅺ 副 | 运动 | 延髓 | 颈静脉孔 | 脑根加入迷走管咽喉肌；脊髓根管胸锁乳突肌、斜方肌 | 头不能向患侧侧屈、面不能转向对侧；肩下垂、提肩无力 |
| Ⅻ 舌下 | 运动 | 延髓 | 舌下神经管 | 舌内肌和大部分舌外肌 | 患侧舌肌瘫、萎缩，伸舌舌尖偏向患侧 |

眶上裂走过 Ⅲ、Ⅳ、Ⅵ 和 V1，不要漏。Ⅸ、Ⅹ、Ⅺ 同出颈静脉孔。
:::

:::insight{label="图9-127 先按颜色认三种纤维，再按出口认十二对"}
蓝线感觉、红线运动、黄线副交感。嗅、视走在最前；动眼、滑车、展和三叉围着眼球；面神经和前庭蜗神经进内耳门；舌咽、迷走、副神经从颈静脉孔那一带出去；舌下神经走舌。胸腹腔脏器那一笔是迷走，不是脊神经前支。
:::

嗅神经由上鼻甲和鼻中隔上部黏膜内嗅细胞的中枢突聚成 20 多条嗅丝，穿筛孔入颅前窝连嗅球。筛板骨折可撕脱嗅丝和脑膜。视神经由视网膜节细胞轴突在视神经盘集中，穿巩膜筛板后经视神经管入颅中窝，续为视交叉。眼是脑向前突出形成的，三层被膜和蛛网膜下隙都包到视神经周围，所以颅内压可传到视神经盘。

动眼神经含一般躯体运动和副交感。自脚间窝出脑，贴小脑幕切迹缘和后床突侧面前行，走海绵窦外侧壁上部，穿眶上裂入眶。上支：上直肌、上睑提肌；下支：下直肌、内直肌、下斜肌。副交感经睫状神经节短根入睫状神经节换元，节后纤维入眼球管瞳孔括约肌和睫状肌。一侧损伤：同侧上睑提肌和上、内、下直肌及下斜肌瘫，上睑下垂，瞳孔斜向外下，瞳孔扩大，对光反射消失。滑车神经自下丘下方出脑（是唯一从脑干背面出脑的脑神经），绕大脑脚，经海绵窦外侧壁、眶上裂入眶，管上斜肌。展神经自脑桥延髓沟中线两侧出脑，经海绵窦内、眶上裂入眶，管外直肌；损伤则内斜视。

:::compare{title="眼外肌的神经（不要记串）"}
| 肌 | 神经 | 伤后 |
|----|------|------|
| 上睑提肌，上、下、内直肌，下斜肌 | 动眼神经 | 上睑下垂，眼外下斜 |
| 上斜肌 | 滑车神经 | 不能外下斜视 |
| 外直肌 | 展神经 | 内斜视 |
| 瞳孔括约肌、睫状肌 | 动眼神经副交感（睫状神经节） | 瞳孔散大，调节障碍 |
| 瞳孔开大肌 | 交感（颈上神经节，不走脑神经运动根） | 瞳孔缩小（Horner 征的一员） |

「动眼神经管所有眼外肌」漏了上斜肌和外直肌。
:::

### 三叉神经

三叉神经（trigeminal nerve）是混合性脑神经，含一般躯体感觉和特殊内脏运动。运动纤维起于三叉神经运动核，组成运动根，自脑桥基底部与小脑中脚交界处出脑，并入下颌神经，经卵圆孔出颅，支配咀嚼肌、二腹肌前腹、下颌舌骨肌、鼓膜张肌和腭帆张肌。感觉纤维的胞体在三叉神经节：位于颅中窝颞骨岩部尖端前面的三叉神经压迹，由硬脑膜形成的美克尔腔包裹。中枢突组成粗大感觉根入脑，痛温觉主要止于三叉神经脊束核，触觉主要止于三叉神经脑桥核；周围突分成眼神经、上颌神经、下颌神经（图9-131）。

::figure{src="/images/anatomy/textbook/p0380_01.png" caption="图9-131　三叉神经" alt="头侧面：三叉神经节分出眼神经、上颌神经、下颌神经。眼神经分额神经、泪腺神经、鼻睫神经；上颌神经经眶下管出眶下孔，发上牙槽支；下颌神经发耳颞神经、舌神经、下牙槽神经、颊神经和下颌舌骨肌神经。面神经鼓索加入舌神经，下颌下神经节贴舌神经"}

:::definition{label="三叉神经"}
第 Ⅴ 对，混合性。感觉管头面部皮肤和口、鼻腔黏膜、牙、眼球、硬脑膜；运动只随**下颌神经**走，管咀嚼肌等。三大支出颅：眼神经走眶上裂，上颌神经走圆孔，下颌神经走卵圆孔。
:::

:::compare{title="三叉神经三大支"}
| | 眼神经 V1 | 上颌神经 V2 | 下颌神经 V3 |
|--|-----------|-------------|-------------|
| 纤维 | 只含躯体感觉 | 只含躯体感觉 | 感觉 + 特殊内脏运动 |
| 出颅 | 海绵窦外侧壁 → 眶上裂 | 海绵窦外侧壁 → 圆孔 → 翼腭窝 | 卵圆孔 |
| 终支地标 | 眶上神经出眶上切迹 | 眶下神经出眶下孔 | 颏神经出颏孔 |
| 皮肤区 | 睑裂以上：额顶、上睑、鼻背 | 睑裂与口裂之间 | 口裂以下、颞部、耳前 |
| 主要分支 | 额神经（眶上、滑车上）、泪腺神经、鼻睫神经（滑车下、筛前/后、睫状长） | 眶下神经、上牙槽神经、颧神经、翼腭神经 | 耳颞神经、舌神经、下牙槽神经、颊神经、咀嚼肌神经 |

上颌部手术常在眶下孔麻醉。下牙槽神经经下颌孔入下颌管，管下颌牙及牙龈，末支出颏孔。
:::

舌神经管口腔底和舌前 2/3 黏膜的一般感觉；行程中接受面神经的鼓索，鼓索才带来舌前 2/3 味觉和到下颌下腺、舌下腺的副交感。耳颞神经两根夹持脑膜中动脉；来自舌咽神经的副交感在耳神经节换元后，经耳颞神经的腮腺支管腮腺分泌。一侧三叉神经损伤：伤侧面部皮肤及口、鼻腔黏膜感觉障碍，角膜反射消失，咀嚼肌瘫痪。

:::pitfall{label="舌前 2/3 的一般感觉是三叉，味觉是面神经鼓索"}
舌神经是下颌神经的支，只管一般感觉。味觉纤维是面神经经鼓索借道舌神经走的。写成「三叉神经管舌前 2/3 味觉」，把 Ⅶ 的特殊内脏感觉安到了 Ⅴ 上。运动根只并入下颌神经，眼神经和上颌神经没有咀嚼肌支。
:::

:::insight{label="图9-131 先认三叉神经节分三叉，再认鼓索是后来加入舌神经的"}
节上三条干：眼神经进眶，上颌神经走眶下管，下颌神经走下颌管。舌神经弓形向前，鼓索从后方加入——那一笔是面神经，不是三叉本干。下颌下神经节贴在舌神经上，换的是副交感，不是三叉的感觉细胞。
:::

### 面神经

面神经（facial nerve）含 4 种纤维：① 特殊内脏运动，起自面神经核，管面部表情肌；② 一般内脏运动，起自上泌涎核，经翼腭神经节、下颌下神经节换元，到泪腺、舌下腺、下颌下腺及鼻腔、口腔黏膜腺；③ 特殊内脏感觉，胞体在膝神经节，周围突到舌前 2/3 味蕾，中枢突止于孤束核；④ 一般躯体感觉，耳部小块皮肤和面肌本体感觉。连于脑桥延髓沟外侧部，经内耳门、内耳道入面神经管，从茎乳孔出颅，进入腮腺深面，分数支从腮腺前缘穿出（图9-135、图9-136）。

::figure{src="/images/anatomy/textbook/p0383_02.png" caption="图9-135　面神经在面部的分支" alt="头侧面腮腺深面：面神经主干入腮腺后呈放射状发出颞支、颧支、颊支、下颌缘支和颈支至面肌和颈阔肌；同时可见三叉神经的眶上神经、眶下神经、颏神经、耳颞神经以及枕大、枕小、耳大、颈横等皮神经"}

::figure{src="/images/anatomy/textbook/p0384_01.png" caption="图9-136　鼓索、翼腭神经节与耳神经节" alt="颞骨岩部剖面：面神经在膝神经节处发岩大神经至翼腭神经节，出茎乳孔前发鼓索加入舌神经；镫骨肌神经在鼓室发出；耳神经节在下颌神经内侧，岩小神经进入该节"}

:::definition{label="面神经"}
第 Ⅶ 对，混合性。出颅路径是**内耳门 → 面神经管 → 茎乳孔**。管面肌；副交感管泪腺和下颌下腺、舌下腺；味觉管舌前 2/3。管内、管外损伤症状不一样。
:::

管内分支：鼓索在出茎乳孔前发出，返回鼓室，穿岩鼓裂加入舌神经，含味觉和副交感（到下颌下神经节，管舌下腺、下颌下腺）；岩大神经在膝神经节处发出，与岩深神经合成翼管神经，入翼腭神经节，节后纤维到泪腺及鼻腔、腭黏膜腺；镫骨肌神经支配镫骨肌。出茎乳孔后，细支到枕额肌枕腹、二腹肌后腹、茎突舌骨肌和耳周肌；主干在腮腺内成丛，再以颞支、颧支、颊支、下颌缘支、颈支呈放射状到面肌和颈阔肌。

翼腭神经节和下颌下神经节都有副交感根、交感根和感觉根：只有副交感根在节内换元，交感根和感觉根路过。耳神经节的副交感根来自舌咽神经的岩小神经，不来自面神经。

面神经管外损伤主要表现为伤侧表情肌瘫痪：口角偏向健侧、不能鼓腮，说话时唾液从口角流出，额纹消失、鼻唇沟变浅，眼轮匝肌瘫则闭眼困难、角膜反射消失。管内损伤并伤及管段分支时，除面肌瘫外，还可有听觉过敏（镫骨肌）、舌前 2/3 味觉障碍、泪腺和唾液腺分泌障碍。

:::pitfall{label="茎乳孔以外只伤面肌；面神经管内才会加上味觉、泪腺和听觉过敏"}
鼓索、岩大神经、镫骨肌神经都在管内发出。写成「面瘫就一定没有味觉」，把管外损伤和管内损伤并成一户。腮腺手术伤的是管外五支，通常没有舌前 2/3 味觉障碍。
:::

:::insight{label="图9-135 认腮腺前缘五支，图9-136 认膝神经节和鼓索"}
五支是管外的面肌名单。岩大神经从膝神经节向前，鼓索从面神经干向下去会舌神经——这两笔决定管内损伤比管外多出来的症状。耳神经节那一笔是舌咽神经管腮腺的路，不要算进面神经。
:::

前庭蜗神经居面神经外侧，由前庭神经和蜗神经组成。前庭神经节在内耳道底，双极神经元，周围突到椭圆囊斑、球囊斑和壶腹嵴，中枢突止于前庭神经核群和小脑。蜗神经节（螺旋神经节）在蜗轴内，周围突到螺旋器毛细胞，中枢突止于蜗神经前、后核。

舌咽神经含 5 种纤维，与迷走神经、副神经同穿颈静脉孔。主要终支收表：鼓室神经 → 鼓室丛 → 岩小神经 → 耳神经节 → 腮腺；颈动脉窦支感受压力和二氧化碳，调节血压和呼吸；舌支到舌后 1/3 黏膜和味蕾；咽支参与咽丛，与咽反射直接相关。运动只到茎突咽肌。

### 迷走神经

迷走神经（vagus nerve）是行程最长、分布最广的脑神经，含 4 种纤维：① 一般内脏运动，起自迷走神经背核，到颈部、胸腔脏器和腹腔大部分脏器，在器官内节换元，管平滑肌、心肌和腺体；② 一般内脏感觉，胞体在下神经节，中枢突止于孤束核；③ 特殊内脏运动，起自疑核，管软腭和咽喉肌；④ 一般躯体感觉，胞体在上神经节，到硬脑膜、耳郭和外耳道，中枢突止于三叉神经脊束核（图9-139）。

连于橄榄后沟、舌咽神经下方，与舌咽、副神经同出颈静脉孔。颈部走在颈内静脉与颈内动脉或颈总动脉之间的后方，经胸廓上口入胸。左迷走神经越主动脉弓前方，经左肺根后方到食管前面，成左肺丛和食管前丛，下段续为迷走神经前干。右迷走神经经右锁骨下动、静脉之间，沿气管右侧、右肺根后方到食管后面，成右肺丛和食管后丛，集为迷走神经后干。前、后干与食管同穿食管裂孔入腹，分支到胃至横结肠的消化管及肝、胰、脾、肾。

::figure{src="/images/anatomy/textbook/p0387_01.png" caption="图9-139　迷走神经的纤维成分及分布示意图" alt="脑干内可见三叉神经脊束核、孤束核、疑核和迷走神经背核；上、下神经节以下发出咽支、喉上神经、颈心支，右喉返神经勾绕后上行续喉下神经，支气管支入肺；入腹后前干发胃前支、肝支、脾支，后干发腹腔支、胃后支和肾支，分布至结肠左曲以上消化管"}

:::definition{label="迷走神经"}
第 Ⅹ 对，混合性，行程最长。出**颈静脉孔**。特殊内脏运动管咽喉肌；副交感管颈、胸、腹腔脏器，腹腔只到**结肠左曲以上**。左、右喉返神经勾绕的动脉不同。
:::

:::compare{title="迷走神经主要分支"}
| 段 | 支 | 要点 |
|----|----|------|
| 颈 | 喉上神经 | 内支穿甲状舌骨膜，声门裂**以上**喉黏膜、会厌、舌根，伤则易误吞呛咳；外支伴甲状腺上动脉，管环甲肌，伤则声带松弛、音调降低 |
| 颈 | 颈心支 | 入心丛；上支的主动脉神经（减压神经）感受血压和化学刺激 |
| 颈 | 耳支、咽支、脑膜支 | 外耳道皮肤；咽丛；颅后窝硬脑膜 |
| 胸 | 喉返神经 | 右绕右锁骨下动脉，左绕主动脉弓，再沿气管食管沟上行，终支称喉下神经。声门裂**以下**喉黏膜 + 除环甲肌外的所有喉肌 |
| 胸 | 支气管支、食管支 | 肺丛、食管丛 |
| 腹 | 前干 | 胃前支（幽门部前壁末梢呈鸦爪支）、肝支 |
| 腹 | 后干 | 胃后支、腹腔支（随腹腔干、肠系膜上动脉、肾动脉到胰、脾、肾和结肠左曲以上消化管） |

:::

甲状腺手术结扎甲状腺下动脉时要避开喉返神经。一侧喉返神经受损：声音嘶哑。两侧同时受损：失音、呼吸困难，甚至窒息。主干损伤还可有脉速、心悸、恶心呕吐、呼吸深慢；咽喉感觉障碍和肌肉瘫痪则声音嘶哑、语言和吞咽困难、腭垂偏向一侧。

:::pitfall{label="环甲肌是喉上神经外支，不是喉返神经"}
喉返神经管除环甲肌以外的喉肌，以及声门裂以下黏膜。写成「喉返神经管全部喉肌」，结扎甲状腺上动脉伤外支时就会对不上。左喉返绕主动脉弓、右喉返绕锁骨下动脉，两侧不对称，不要画成一对镜像。
:::

:::insight{label="图9-139 先认四个核，再认喉返勾动脉、入腹只到结肠左曲"}
疑核的红线走咽喉肌，背核的黄线走胸腹脏器，孤束核收内脏感觉，脊束核收耳部躯体感觉。右喉返神经勾过来再上行。腹腔支和胃支铺到小肠和右半结肠一带为止，降结肠不在迷走副交感户里。
:::

副神经的延髓根加入迷走神经管咽喉肌；脊髓根自脊髓前、后根之间出脊髓，经枕骨大孔入颅，与延髓根合成后出颈静脉孔，支配胸锁乳突肌和斜方肌。脊髓根损伤：头不能向患侧侧屈、面不能转向对侧，患侧肩胛骨下垂。舌下神经自锥体与橄榄之间出脑，经舌下神经管出颅，沿舌骨舌肌浅面入舌。一侧完全损伤：患侧半舌肌瘫，伸舌时舌尖偏向患侧；久之舌肌萎缩。

:::pitfall{label="伸舌偏向患侧，面瘫口角偏向健侧"}
舌下神经伤，健侧颏舌肌把舌尖推向患侧。面神经伤，健侧面肌把口角拉向健侧。两个「偏」方向参照的不是同一侧，不要写成「都偏向患侧」。
:::

:::note{label="脑神经核团的内部构造归第二节"}
起核、终核在总表里点名即可。三叉脊束核、孤束核、疑核、迷走神经背核的切面位置是脑干的户，本节只把它们当作纤维的起点或止点。
:::

## 三、内脏神经

内脏神经系统（visceral nervous system）有中枢部和周围部，纤维分感觉性和运动性。内脏运动神经调节内脏、心血管和腺体，通常不受意志控制，又称自主神经系统或植物神经系统。内脏感觉神经元胞体在脑神经节和脊神经节，把内感受器的刺激传到各级中枢，也可到大脑皮质；中枢再经内脏运动神经或体液调节器官活动。

:::definition{label="内脏神经"}
分布到内脏、心血管、平滑肌和腺体的周围神经。既有传入也有传出。把内脏神经写成「就是自主神经」，等于把内脏感觉从户头删掉。
:::

:::definition{label="内脏运动神经"}
即自主神经、植物神经。支配心肌、平滑肌和腺体。从低级中枢到效应器要经过**两个**神经元（肾上腺髓质例外，只需一个）：节前神经元在脑干或脊髓，节后神经元在周围的内脏神经节。
:::

:::compare{title="内脏运动神经与躯体运动神经"}
| | 躯体运动 | 内脏运动 |
|--|----------|----------|
| 效应器 | 骨骼肌，受意志控制 | 平滑肌、心肌、腺体，通常不受意志控制 |
| 神经元数目 | 低级中枢到骨骼肌一个神经元 | 两个神经元（肾上腺髓质例外） |
| 纤维成分 | 一种 | 交感 + 副交感，多数器官双重支配 |
| 纤维粗细 | 较粗的有髓纤维 | 节前薄髓、节后无髓的细纤维 |
| 分布形式 | 神经干 | 节后纤维攀附脏器或血管成丛 |

一个节前神经元可与多个节后神经元形成突触。终末缺少躯体运动那种典型运动终板，递质常以扩散方式起作用。
:::

根据形态、功能和药理，内脏运动神经分为交感神经和副交感神经。

### （一）交感神经

交感神经（sympathetic nerve）的低级中枢在脊髓 **T1～L3** 灰质侧柱的中间带外侧核（胸腰部）。周围部包括交感干、交感神经节、节的分支和交感神经丛（图9-143、图9-145）。

::figure{src="/images/anatomy/textbook/p0391_01.png" caption="图9-143　内脏运动神经概况示意图" alt="脊髓胸腰段发黑线经白交通支入交感干，再经灰交通支回脊神经至皮肤汗腺血管竖毛肌，或经内脏大、小神经和腰内脏神经到腹腔神经节、肠系膜上、下神经节；脑干和 S2～S4 发绿线：动眼、面、舌咽到头部四个副交感节，迷走到胸腹器官，盆内脏神经到盆腔脏器和结肠远端"}

::figure{src="/images/anatomy/textbook/p0393_01.png" caption="图9-145　交感干和交感神经节" alt="脊柱两侧交感干：颈部颈上、颈中、颈下神经节发颈内和颈外动脉神经；胸部发内脏大神经、内脏小神经；椎前有腹腔神经节、肠系膜上神经节、主动脉肾神经节、肠系膜下神经节；腹主动脉丛向下续上腹下丛，尾端为奇神经节"}

:::definition{label="交感神经"}
低级中枢在脊髓 **T1～L3** 中间带外侧核。节在椎旁（交感干神经节）和椎前（腹腔、主动脉肾、肠系膜上、肠系膜下神经节）。节前纤维相对短，节后纤维相对长，作用范围较广。
:::

椎旁神经节借节间支连成左、右交感干，上端附于颅底，下端在第 3 尾椎前面借奇神经节相连。每侧 19～24 个节：颈 3～4，胸 10～12，腰 4，骶 2～3，尾部两侧合为 1 个奇神经节。椎前神经节位于同名动脉根部附近。

每个椎旁神经节与相应脊神经借交通支相连。

:::compare{title="白交通支与灰交通支"}
| | 白交通支 | 灰交通支 |
|--|----------|----------|
| 纤维 | 有髓节前纤维，色白 | 无髓节后纤维，色灰 |
| 方向 | 脊神经 → 交感干 | 交感干 → 脊神经 |
| 对数 | **15 对**，只在 T1～L3 | **31 对**，连每一对脊神经 |

节前神经元只在 T1～L3，所以白交通支不能出现在颈神经或骶神经上。灰交通支把节后纤维送回全部脊神经，随其到全身血管、汗腺、竖毛肌。
:::

节前纤维经前根、脊神经、白交通支进交感干后有 3 种去向：① 在相应椎旁节换元；② 在交感干内上升或下降后，在上方或下方的椎旁节换元（T1～T6 多上升到颈部，T6～T10 在胸部升降，T11～L3 多下降到腰骶部）；③ 穿过椎旁节，到椎前神经节换元。节后纤维也有 3 种去向：① 经灰交通支回 31 对脊神经；② 攀附动脉成丛，随动脉到器官；③ 由神经节直接发支到脏器。

:::compare{title="交感干各段的节和去向"}
| 段 | 节 | 节后 / 内脏神经 |
|----|----|-----------------|
| 颈 | 颈上（最大，C2～C3 横突前）、颈中（可缺如，C6）、颈下（常与 T1 合成颈胸神经节 / 星状神经节） | 无白交通支。灰交通支连 8 对颈神经；攀附成颈内、颈外、锁骨下、椎动脉丛；咽支入咽丛；三对心神经入心丛 |
| 胸 | 10～12 个（11 个最常见），肋头前方 | 灰交通支连 12 对胸神经；上 5 对节后入胸主动脉丛、食管丛、肺丛、心丛。内脏大神经（穿 T5 或 T6～T9）→ 腹腔节、肠系膜上节；内脏小神经（T10～T12）→ 主动脉肾节；内脏最小神经常缺如 |
| 腰 | 约 4 对，腰椎体前外侧 | 灰交通支连 5 对腰神经。腰内脏神经 → 腹主动脉丛、肠系膜下丛内椎前节，管结肠左曲以下消化管、盆腔脏器，并随血管到下肢。下肢血管痉挛可切腰交感干 |
| 盆 | 2～3 对骶节 + 1 个奇神经节 | 灰交通支连骶、尾神经；小支加入盆丛 |

:::

节段支配的规律：T1～T5 换元后管头、颈、胸腔脏器和上肢的血管、汗腺、竖毛肌；T5～T12 管肝、胰、脾、肾和结肠左曲以上消化管；上腰段管结肠左曲以下消化管、盆腔脏器和下肢的血管、汗腺、竖毛肌。

颈部交感损伤可出现 Horner 综合征：瞳孔缩小、上睑下垂、同侧头面部汗腺分泌障碍——因为交感还管睑板肌（Müller 肌）和头面部汗腺，不只管瞳孔开大肌。

:::pitfall{label="白交通支只有 15 对，灰交通支才是 31 对"}
节前纤维只从 T1～L3 出来，颈交感干没有白交通支，纤维是从胸段在干内升上去的。写成「每对脊神经都有白交通支」，颈、骶那两段会对空。
:::

:::insight{label="图9-145 先认两条纵干，再认椎前四个节和内脏大、小神经"}
颈上、颈中、颈下排在颈动脉后方；胸段发出内脏大、小神经穿膈到腹腔神经节一带；肠系膜上、下神经节和主动脉肾神经节贴在动脉根上。奇神经节是两干下端的会合点。图9-143 用黑线画交感、绿线画副交感，头部四个副交感节和盆内脏神经都在绿线上。
:::

### （二）副交感神经

副交感神经（parasympathetic nerve）的低级中枢在脑干的一般内脏运动核和脊髓 **S2～S4** 的骶副交感核。周围部是节前纤维、器官旁节或器官内节及其节后纤维。颅部四对肉眼可见的副交感神经节：睫状神经节、翼腭神经节、耳神经节、下颌下神经节。节内还有交感纤维和感觉纤维穿过，不换元。其他部位的副交感节很小，在心丛、肺丛、膀胱丛、子宫阴道丛以及支气管和消化管壁内。

:::definition{label="副交感神经"}
低级中枢在脑干副交感核 + **S2～S4** 骶副交感核。节在器官旁或壁内，所以节前纤维长、节后纤维短，作用较局限。颅部走 Ⅲ、Ⅶ、Ⅸ、Ⅹ；盆部走盆内脏神经。
:::

:::compare{title="颅部副交感四对节"}
| 节前起点 | 走行 | 换元 | 节后分布 |
|----------|------|------|----------|
| 动眼神经副核（E-W 核） | 动眼神经 → 睫状神经节短根 | 睫状神经节 | 瞳孔括约肌、睫状肌 |
| 上泌涎核 | 岩大神经 → 翼管神经 | 翼腭神经节 | 泪腺，鼻腔、口腔及腭黏膜腺 |
| 上泌涎核 | 鼓索 → 舌神经 | 下颌下神经节 | 下颌下腺、舌下腺 |
| 下泌涎核 | 鼓室神经 → 岩小神经 | 耳神经节 | 腮腺（经耳颞神经） |
| 迷走神经背核 | 迷走神经分支 | 器官旁节或壁内节 | 胸、腹腔脏器（结肠左曲以下及盆腔脏器除外） |

:::

骶部节前纤维随骶神经出骶前孔，再分出组成盆内脏神经，加入直肠两侧的盆丛，在脏器附近或壁内换元，支配结肠左曲以下的消化管和盆腔脏器。结肠左曲是迷走副交感和骶副交感的分界，不要把降结肠写成迷走支配。

### （三）交感与副交感的区别

:::compare{title="交感神经与副交感神经"}
| | 交感 | 副交感 |
|--|------|--------|
| 低级中枢 | 脊髓 T1～L3 中间带外侧核 | 脑干一般内脏运动核 + S2～S4 骶副交感核 |
| 周围神经节 | 椎旁、椎前，离器官较远 | 器官旁、器官内，离器官近 |
| 纤维长短 | 节前较短，节后较长 | 节前较长，节后较短 |
| 节前 : 节后 | 一个节前对多个节后，范围广 | 一个节前对较少节后，较局限 |
| 分布 | 头颈胸腹盆 + 全身血管、汗腺、竖毛肌 | 不如交感广。大部分血管、汗腺、竖毛肌、肾上腺髓质只接受交感 |
| 活动偏向 | 运动、应急：心跳加快、血压升高、支气管扩张、瞳孔开大、消化抑制 | 安静、恢复：心跳减慢、血压下降、支气管收缩、瞳孔缩小、消化增强 |

二者对同一器官既拮抗又统一，并接受下丘脑和边缘叶等较高级中枢调控。
:::

:::pitfall{label="大部分血管、汗腺、竖毛肌和肾上腺髓质没有副交感"}
双重支配不是「每个内脏结构都有两套」。皮肤血管、汗腺、竖毛肌和肾上腺髓质本版原句只写交感。写成「全身都是交感加副交感」，Horner 征里的无汗和皮肤血管变化就对不上副交感损伤。
:::

内脏神经丛是交感、副交感和内脏感觉在血管及脏器周围的交织。颈内、颈外、锁骨下、椎动脉丛没有副交感参与；其余丛三种纤维都有。

:::compare{title="主要内脏神经丛（收名单，不逐条定义）"}
| 丛 | 位置 | 组成要点 | 去向 |
|----|------|----------|------|
| 心丛 | 浅丛在主动脉弓前下，深丛在主动脉弓与气管杈之间 | 颈上、中、下心神经 + T1～T4/5 胸心神经 + 迷走心支 | 心房丛和左、右冠状动脉丛。丛内有心神经节 |
| 肺丛 | 肺根前、后方 | T2～T5 胸神经节支、迷走支气管支、心丛分支 | 随支气管和肺血管入肺 |
| 腹腔丛 | 腹腔干和肠系膜上动脉根部，最大 | 内脏大、小神经 + 迷走后干腹腔支 + 腰上部交感支 | 肝、胃、脾、肾、肠系膜上副丛 |
| 腹主动脉丛 | 腹主动脉前及两侧 | 腹腔丛向下延续 + L1～L2 节后纤维 | 肠系膜下丛；部分入盆成腹下丛；部分随髂动脉到下肢 |
| 上腹下丛 | 第 5 腰椎前面、腹主动脉分叉处 | 腹主动脉丛向下 + L3～L4 腰内脏神经 | 续为盆丛 |
| 盆丛（下腹下丛） | 直肠两侧 | 上腹下丛 + 骶交感节后 + S2～S4 盆内脏神经 | 直肠、膀胱、前列腺或子宫阴道等副丛 |

:::

### （四）内脏感觉与牵涉性痛

内脏感觉神经元是假单极，胞体在膝神经节、舌咽下神经节、迷走下神经节和脊神经节。脑神经这一路的中枢突止于孤束核；脊神经这一路经后根入脊髓后角。在中枢可完成内脏–内脏反射或内脏–躯体反射，也可上行到皮质形成内脏感觉。一般认为，与牵拉、充盈有关的纤维多与副交感伴行；痛觉纤维多与交感伴行进入脊髓（盆腔部分脏器的痛觉可走盆内脏神经；气管、食管的痛觉可经迷走入脑干）。

与躯体感觉相比，内脏感觉有两个形态学后果。第一，痛阈较高：纤维数目少、多为细纤维，切割或烧灼内脏往往不痛，但强烈牵拉、痉挛、缺血可致痛。第二，内脏痛弥散、定位不准：一个脏器的纤维可经多个节段入中枢，一条脊神经也可含几个脏器的纤维。心的痛觉主要随颈中、颈下心神经，经 T1～T5 进入脊髓。

某些内脏器官病变时，在体表一定区域产生感觉过敏或疼痛，称牵涉性痛（referred pain）。体表感觉过敏、骨骼肌反射性僵硬、血管运动和汗腺分泌障碍的部位称海德带，有助于定位。牵涉痛可发生在患病脏器邻近的皮肤，也可发生在较远的皮肤：心绞痛常在胸前区及左上臂内侧；肝胆疾患常在右肩（图9-152）。机制：病变器官与该皮肤区的感觉纤维进入同一脊髓节段，在后角密切联系；一个脊神经节神经元的周围突分叉到躯体和内脏，是形态学基础。

::figure{src="/images/anatomy/textbook/p0400_01.png" caption="图9-152　内脏器官疾病时的牵涉性痛区" alt="人体前面和后面：心在左胸和左臂内侧，胆囊在右肩，胃胰在上腹和背部 T8 一带，肝胆在右上腹和右肩胛区，肾和输尿管沿腰到腹股沟，膀胱在耻骨上，小肠在脐周，肺支气管在上胸背部"}

:::definition{label="牵涉性痛"}
内脏病变时，在体表一定区域出现的感觉过敏或疼痛。本版点名：**心绞痛 → 胸前区及左上臂内侧**；**肝胆疾患 → 右肩**。不是内脏本身被「移到」体表，是共用脊髓节段。
:::

:::compare{title="牵涉性痛与脊髓节段（本版表9-6）"}
| 器官 | 节段 | 器官 | 节段 |
|------|------|------|------|
| 膈 | C4 | 肾、输尿管 | T11～L1 |
| 心 | C8～T5 | 膀胱 | S2～S4（沿骶副交感）及 T11～L2 |
| 胃 | T6～T10 | 睾丸、附睾 | T12～L3 |
| 小肠 | T7～T10 | 卵巢及附件 | L1～L3 |
| 阑尾 | T（8、9）10～L1（右） | 子宫体 | T10～L1 |
| 肝、胆囊 | T7～T10，有时沿膈神经至 C3、C4 | 子宫颈 | S1～S4（沿骶副交感） |
| 胰 | T8（左） | 直肠 | S1～S4 |

肝胆可以经膈神经牵到 C3、C4，所以右肩那一笔不是「搞错了部位」。
:::

:::pitfall{label="牵涉痛不是内脏感觉纤维直接走到那块皮肤"}
痛在左臂内侧，不等于心脏的感觉纤维分布到左臂皮肤。两路初级传入进了同一节段，后角里互相影响。写成「心的痛觉神经走在臂内侧皮神经里」，把牵涉当成了皮支走行。
:::

:::insight{label="图9-152 先对两条例子，再对节段表"}
前面左胸到左臂是心，右肩是胆囊；上腹是胃和胰，脐周是小肠，腰到腹股沟是肾和输尿管。后面右肩胛区仍是肝胆，背部 T8 一带是胃胰。先把心和肝胆两条例子钉死，其余用表9-6 的节段去对，不必每块皮区再开一张图。
:::

:::cause-effect{title="为什么内脏痛定位不准，牵涉痛却相对恒定"}
- **因** 一个脏器的传入可经多个节段进入中枢，一条脊神经又可含几个脏器的纤维；同时这些纤维与特定躯体传入在同一后角会聚
- **果** 患者说不清腹痛的精确点；但特定脏器仍会牵到相对恒定的海德带（心 → 左上臂内侧，肝胆 → 右肩）

临床问的是「痛牵到哪块皮区」，不是要求患者指出脏器本身的轮廓。
:::

:::keypoint{label="周围神经先问三户再问出入口"}
- 脊神经 31 对，前根运动、后根感觉，椎间孔合成。前支除胸神经外成颈、臂、腰、骶四丛。
- 脑神经 12 对。感觉 Ⅰ Ⅱ Ⅷ，运动 Ⅲ Ⅳ Ⅵ Ⅺ Ⅻ，混合 Ⅴ Ⅶ Ⅸ Ⅹ。副交感只在 Ⅲ Ⅶ Ⅸ Ⅹ。
- 内脏运动 = 自主 = 交感（T1～L3）+ 副交感（脑干 + S2～S4）。牵涉痛点名心和肝胆。

下一节才写传导通路。本节不把束的交叉和皮质投射提前立户。
:::

:::memory{label="本节必背要点"}
- [ ] 周围神经 = 脊神经 31 对 + 脑神经 12 对。叙述分成脊神经、脑神经、内脏神经三户。脑屏障、传导通路不在本节。
- [ ] 脊神经：8 颈、12 胸、5 腰、5 骶、1 尾。C1 走枕寰之间，C2～C7 走同序数颈椎上方，C8 走 C7 下方。前根运动、后根感觉，椎间孔合成。四种纤维：躯体感觉、内脏感觉、躯体运动、内脏运动。
- [ ] 四支：前支、后支、交通支、脊膜支。前支除胸神经外成颈丛（C1～C4）、臂丛（C5～T1）、腰丛（T12～L4 一部分）、骶丛（腰骶干 + 骶尾前支）。
- [ ] 颈丛皮支从胸锁乳突肌后缘中点浅出（神经点）。膈神经 C3～C5，经肺根前方到膈；右膈神经感觉到肝胆浆膜。
- [ ] 臂丛三束夹腋动脉。正中神经：腕管，鱼际（拇收肌除外），第 1、2 蚓状肌，桡侧三个半指掌面。尺神经：尺神经沟，骨间肌和第 3、4 蚓状肌、拇收肌，爪形手。桡神经：桡神经沟，伸肌，垂腕。
- [ ] 胸神经皮支地标：T2 胸骨角，T4 乳头，T6 剑突，T8 肋弓中点，T10 脐，T12 脐与耻骨联合中点。肋沟内静脉、动脉、神经自上而下。
- [ ] 股神经出腰大肌外侧缘，闭孔神经出内侧缘。坐骨神经最常见经梨状肌下孔出盆，腘窝上分为胫神经（钩状足）和腓总神经（马蹄内翻足、跨阈步态）。
- [ ] 皮神经有节段性和重叠性。单根损伤多为感觉迟钝，相邻多根损伤才完全消失。
- [ ] 脑神经总表：出颅和性质按Ⅰ–Ⅻ记。眶上裂：Ⅲ、Ⅳ、Ⅵ、V1。圆孔 V2，卵圆孔 V3。内耳门：Ⅶ、Ⅷ。颈静脉孔：Ⅸ、Ⅹ、Ⅺ。舌下神经管：Ⅻ。
- [ ] 三叉：V1、V2 纯感觉，V3 混合。舌前 2/3 一般感觉走舌神经，味觉走鼓索。面神经管外只见面肌瘫，管内加味觉、泪腺、听觉过敏。迷走：喉上外支管环甲肌，喉返管其余喉肌；左绕主动脉弓，右绕锁骨下动脉；副交感到结肠左曲以上。
- [ ] 伸舌偏向患侧（Ⅻ），面瘫口角偏向健侧（Ⅶ）。
- [ ] 交感低级中枢 T1～L3；白交通支 15 对，灰交通支 31 对。副交感：Ⅲ、Ⅶ、Ⅸ、Ⅹ + S2～S4。大部分血管、汗腺、竖毛肌、肾上腺髓质只有交感。
- [ ] 牵涉痛：心 → 胸前区及左上臂内侧（C8～T5）；肝胆 → 右肩（可经膈神经到 C3、C4）。海德带用于定位，不是皮支走行。
