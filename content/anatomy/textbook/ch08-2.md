# 第二节　前庭蜗器

第一节把视器从眶里写完。本节另立「前庭蜗器」这一户：外耳和中耳负责收集、传导声波，内耳同时接受声波和位置觉。三块听小骨——锤骨、砧骨、镫骨——属本节鼓室，不要推回运动系统。嗅器、味器和皮肤留给第三节。

前庭蜗器（vestibulocochlear organ）包括前庭器（vestibular apparatus）和听器（auditory apparatus）。二者功能不同，结构上关系密切。前庭蜗器又称耳，包括外耳、中耳和内耳 3 部分（图8-16）。外耳和中耳是声波的收集和传导装置，内耳接受声波和位置觉的刺激。听觉感受器和位置觉感受器都位于内耳。

:::definition{label="前庭蜗器"}
又称耳。三部：**外耳、中耳、内耳**。前庭器管平衡，听器管听觉，两套感受器都坐在内耳里。
:::

:::concept{term="先问这是传声的管子还是换能的迷路，再问听小骨有没有被赶到运动系统"}
看见耳，先切开外、中、内。外耳和中耳是收集和传导，内耳才是螺旋器和壶腹嵴、囊斑。锤、砧、镫三块听小骨是鼓室内的杠杆，不是四肢骨。把乳突小房写成「另一套鼻旁窦」，户头就并了。
:::

## 一、外耳

外耳（external ear）包括耳郭、外耳道和鼓膜 3 部分。

### （一）耳郭

耳郭（auricle）位于头部两侧，凸面向后，凹面朝向前外（图8-17）。上方大部以弹性软骨为支架，外覆皮肤，皮下组织少。下方为耳垂（auricular lobule），无软骨，仅含结缔组织和脂肪，为临床常用采血部位。

耳郭前外面高低不平。卷曲的游离缘称耳轮。耳轮前方有与其平行的弧形隆起，称对耳轮。对耳轮上端分叉形成对耳轮上、下脚，两脚之间的三角形浅窝称三角窝。耳轮与对耳轮之间的狭长凹陷称耳舟。对耳轮前方的深窝称耳甲，被耳轮脚分为上部的耳甲艇和下部的耳甲腔。耳甲腔通入外耳门（external acoustic pore）。耳甲腔前方有一突起称耳屏；后方对耳轮下部有一突起称对耳屏。耳屏与对耳屏之间的凹陷称耳屏间切迹。对耳屏下方为耳垂。耳郭外部形态为耳针定穴的标志。

:::definition{label="耳郭"}
凸面向后、凹面向前外。上方大部弹性软骨，皮下少；下方耳垂无软骨，是常用采血部位。
:::

:::compare{title="耳郭前外面几个名（对照图8-17）"}
| 名 | 位置 |
|----|------|
| 耳轮 | 卷曲的游离缘 |
| 对耳轮 | 耳轮前方平行的弧形隆起，上端分上、下脚 |
| 三角窝 | 对耳轮两脚之间 |

| 耳屏 / 对耳屏 | 耳甲腔前、后方的突起，中间是耳屏间切迹 |

:::

### （二）外耳道

外耳道（external acoustic meatus）（图8-16）是从外耳门至鼓膜的弯曲管道，成人长约 **2.0～2.5 cm**。外 1/3 为软骨部，与耳郭软骨相延续；内 2/3 为骨性部，由颞骨鳞部和鼓部围成椭圆形短管。两部交界处较为狭窄。外耳道呈弯曲状，由外向内先向前上，继而稍向后，然后弯向前下。检查鼓膜时，成人需将耳郭向**后上方**牵拉，使外耳道变直，方可窥见。婴儿因颞骨尚未骨化，外耳道几乎全由软骨支持，短而直，鼓膜近于水平位，检查时须将耳郭拉向**后下方**。

外耳道表面覆盖皮肤，内含感觉神经末梢、毛囊、皮脂腺及耵聍腺。皮下组织少，皮肤与软骨膜、骨膜结合紧密，不易移动，故外耳道皮肤疖肿时疼痛剧烈。耵聍腺分泌的黏稠液体为耵聍；凝结成块阻塞外耳道则为耵聍栓塞，影响听力。

:::definition{label="外耳道"}
外耳门到鼓膜。成人长 2.0～2.5 cm。外 1/3 软骨、内 2/3 骨，交界处窄。走行：向前上 → 稍向后 → 向前下。
:::

:::compare{title="检查鼓膜时牵拉耳郭的方向"}
| | 牵拉 | 原因 |
|--|------|------|
| 成人 | **后上** | 外耳道弯曲，拉直后才能看见鼓膜 |
| 婴儿 | **后下** | 几乎全软骨、短而直，鼓膜近水平 |

方向写反，窥镜会顶到弯道而看不见光锥。
:::

:::pitfall{label="外耳道疖肿特别痛，是因为皮肤贴骨膜，不是「神经特别多」这一笔就能概括"}
本版强调皮下组织少、皮肤与软骨膜和骨膜结合紧密、不易移动。肿胀无处可让，所以剧痛。
:::

### （三）鼓膜

鼓膜（tympanic membrane）的形态在中耳「鼓室的壁」外侧壁展开。

## 二、中耳

中耳（middle ear）由鼓室、咽鼓管、乳突窦和乳突小房组成，为一含气的不规则腔道，大部分位于颞骨岩部内。中耳向外借鼓膜与外耳道相隔，向内毗邻内耳，向前以咽鼓管通向鼻咽部。

:::definition{label="中耳"}
鼓室 + 咽鼓管 + 乳突窦 + 乳突小房。向外鼓膜，向内迷路，向前咽鼓管通鼻咽。四件都衬黏膜并互相延续。
:::

### （一）鼓室

鼓室（tympanic cavity）是颞骨岩部内含气的不规则小腔，由 6 个壁围成，内有听小骨、韧带、肌、血管和神经。鼓室内面及上述结构均被覆黏膜，此黏膜与咽鼓管和乳突窦、乳突小房的黏膜相延续。

:::definition{label="鼓室"}
颞骨岩部内含气小腔，六壁。内容：听小骨、韧带、肌、血管和神经。黏膜与咽鼓管、乳突窦、乳突小房相延续，所以中耳炎可以「顺着黏膜走」。
:::

**1. 鼓室的壁**

（1）外侧壁：大部分由鼓膜构成，故又名鼓膜壁（图8-18、图8-19）。鼓膜上方为骨部，即鼓室上隐窝的外侧壁。

鼓膜位于外耳道与鼓室之间，为椭圆形半透明薄膜，直径约 **1 cm**，与外耳道底约成 **45°～50°** 的倾斜角。小儿的鼓膜更为倾斜，几乎呈水平位。鼓膜边缘大部分附着于颞骨，中心向内凹陷称鼓膜脐（umbo of tympanic membrane），为锤骨柄末端附着处。由鼓膜脐沿锤骨柄向上，鼓膜向前、后分别形成锤骨前襞和锤骨后襞。两襞之间、鼓膜上 1/4 的三角形区薄而松弛，为松弛部，活体呈淡红色。鼓膜下 3/4 区坚实紧张，为紧张部，活体呈灰白色。紧张部前下方有一三角形反光区，称光锥（cone of light）。耳镜检查可窥见光锥；中耳疾患可引起光锥改变或消失，严重时鼓膜穿孔，影响听力。

鼓膜组织结构分 3 层：外层复层鳞状上皮，与外耳道皮肤相续；中层纤维层，松弛部无此层；内层黏膜，与鼓室黏膜相续。

:::definition{label="鼓膜"}
椭圆形半透明，直径约 1 cm，与外耳道底成 45°～50° 倾斜。脐在中央，锤骨柄附于此。上 1/4 松弛部（淡红），下 3/4 紧张部（灰白）；紧张部前下有光锥。
:::

::figure{src="/images/anatomy/textbook/p0274_01.png" caption="图8-18　鼓膜（右侧）" alt="右侧鼓膜外面：松弛部在上，紧张部在下，鼓膜脐、锤纹、锤骨前襞和后襞、光锥在前下；上方可见锤骨头与砧骨体的砧锤关节"}

:::pitfall{label="光锥在紧张部前下方，不要画到松弛部"}
活体灰白色的是紧张部，淡红色薄区才是松弛部。光锥消失提示中耳疾患，认错象限会把穿孔位置报反。
:::

（2）上壁：又称盖壁，由颞骨岩部前外侧面的鼓室盖构成，分隔鼓室与颅中窝。盖壁向后延伸形成乳突窦的上壁。中耳疾患可侵犯此壁，引起耳源性颅内并发症（图8-19、图8-20）。

（3）下壁：亦称颈静脉壁，为一薄层骨板，分隔鼓室与颈静脉窝内的颈静脉球。部分人下壁未骨化，仅借黏膜和纤维结缔组织分隔鼓室和颈静脉球，鼓膜或鼓室手术时易伤及颈静脉球而发生严重出血。

（4）前壁：也称颈动脉壁，即颈动脉管的后壁，甚薄，借骨板分隔鼓室与颈内动脉。此壁上部为颞骨岩部和鳞部交界处，有两个小管：上方为鼓膜张肌半管，下方为咽鼓管半管（图8-19）。

（5）内侧壁：又称迷路壁，与内耳相隔。中部有圆形隆起称岬（promontory），由耳蜗第一圈的隆凸形成。岬的后上方有卵圆形小孔，称前庭窗（fenestra vestibuli）或卵圆窗，通向前庭；活体由镫骨底及其周缘韧带封闭。岬的后下方有圆形小孔，称蜗窗（fenestra cochleae）或圆窗，活体由第二鼓膜封闭。前庭窗后上方有弓形隆起，称面神经管凸，内藏面神经。面神经管壁骨质甚薄，中耳炎或手术时易伤及面神经，引起面瘫（图8-20）。

（6）后壁：为乳突壁，上部有乳突窦入口，鼓室借此连通乳突内的乳突小房。中耳炎易侵入乳突小房而引起乳突炎。乳突窦入口下方有一锥状突起称锥隆起，内藏镫骨肌。面神经管由鼓室内侧壁经锥隆起上方转至后壁，然后垂直向下达茎乳孔。在茎乳孔上方约 **6 mm** 处有鼓索神经自面神经管穿出，经鼓索后小管进入鼓室（图8-19、图8-20）。

:::definition{label="前庭窗与蜗窗"}
都在内侧壁（迷路壁）。前庭窗（卵圆窗）在岬的后上，活体由**镫骨底**封闭，通前庭。蜗窗（圆窗）在岬的后下，活体由**第二鼓膜**封闭。两窗不要对调。
:::

:::definition{label="面神经管凸"}
前庭窗后上方的弓形隆起，内藏面神经。管壁薄，中耳炎或手术易致面瘫。
:::

**2. 鼓室内的结构**

（1）听小骨（auditory ossicles）（图8-21）：有 3 块，即锤骨、砧骨和镫骨。属本节前庭蜗器，不是运动系统的骨。

1）锤骨（malleus）：形如鼓槌，分头、柄、外侧突和前突。锤骨头与砧骨体形成砧锤关节，位于鼓室上隐窝，并借韧带连于上壁。锤骨柄附于鼓膜脐内面，柄的上端有鼓膜张肌附着。前突有韧带连于鼓室前壁；外侧突为鼓膜紧张部与松弛部分界的标志。

2）砧骨（incus）：形如砧，分体和长、短二脚。体与锤骨头形成砧锤关节，长脚与镫骨头形成砧镫关节，短脚以韧带连于鼓室壁。

3）镫骨（stapes）：形似马镫，分为头、颈，前、后二脚和一底。底借韧带连于前庭窗周边，封闭前庭窗。

:::definition{label="听小骨"}
三块：**锤骨、砧骨、镫骨**。锤骨柄贴鼓膜脐，镫骨底封前庭窗。户头在鼓室，不要写进运动系统骨学。
:::

（2）听小骨链：锤骨借柄连于鼓膜，镫骨底封闭前庭窗，它们在鼓膜与前庭窗之间以关节和韧带连结成听小骨链，组成杠杆系统。声波冲击鼓膜时，听小骨链相继运动，使镫骨底在前庭窗上来回摆动，将声波的振动传入内耳。炎症引起听小骨粘连和韧带硬化时，听觉减弱。

:::definition{label="听小骨链"}
鼓膜 → 锤骨 → 砧骨 → 镫骨 → 前庭窗。杠杆放大振动。粘连、硬化 → 听觉减弱（传导性）。
:::

::figure{src="/images/anatomy/textbook/p0276_01.png" caption="图8-21　听小骨" alt="左：鼓室剖面示外耳道、鼓膜、锤骨、砧骨、镫骨和鼓室上隐窝；右：听小骨链放大，锤骨头、柄、前突、外侧突，砧骨体、长脚、短脚，镫骨头、后脚和镫骨底"}

（3）运动听小骨的肌

1）鼓膜张肌（tensor tympani）（图8-19）：位于咽鼓管上方的鼓膜张肌半管内，起自咽鼓管软骨部上壁内面和蝶骨大翼，止于锤骨柄上端。收缩可紧张鼓膜，受三叉神经的下颌神经支配。

2）镫骨肌（stapedius）（图8-19）：位于锥隆起内，肌腱经锥隆起尖端穿出进入鼓室，止于镫骨颈。是鼓膜张肌的拮抗肌，收缩时解除鼓膜的紧张状态，受面神经支配。镫骨肌瘫痪常引起听觉过敏。

（4）鼓索和鼓室丛见神经系统。

:::compare{title="鼓室内两块肌"}
| 肌 | 位置 | 止点 | 作用 | 神经 |
|----|------|------|------|------|
| 鼓膜张肌 | 鼓膜张肌半管（咽鼓管上方） | 锤骨柄上端 | 紧张鼓膜 | 三叉神经（下颌神经） |
| 镫骨肌 | 锥隆起内 | 镫骨颈 | 拮抗，解除鼓膜紧张 | 面神经 |

镫骨肌瘫痪 → 听觉过敏，不是「听不见」。
:::

:::insight{label="三块听小骨就是鼓膜到前庭窗的杠杆，不是「又一套关节」"}
砧锤关节、砧镫关节是为了把面积大、位移大的鼓膜振动，换成面积小、压强大的镫骨底运动。炎症把杠杆粘住，空气传导就断在中耳这一段。
:::

### （二）咽鼓管

咽鼓管（pharyngotympanic tube）（图8-19）为连通鼻咽部与鼓室的通道，长 **3.5～4.0 cm**，斜向前内下方。分为骨部和软骨部。两部交界处称咽鼓管峡，是管腔最窄处，内径仅为 **1～2 mm**。

**1. 咽鼓管骨部**　约占全长的外 1/3，以颞骨的咽鼓管半管为基础，向后外侧开口于鼓室前壁的咽鼓管鼓室口。

**2. 咽鼓管软骨部**　约占全长的内 2/3，紧连骨部，向前内侧开口于鼻咽部侧壁的咽鼓管咽口，平对下鼻甲的后方。咽口平时关闭，吞咽或打哈欠时张开，空气进入鼓室。

咽鼓管的功能是使鼓室气压与外界大气压相等，保持鼓膜内、外压力平衡。幼儿咽鼓管较成人短而平，管径也较大，故咽部感染易经咽鼓管侵入鼓室。

:::definition{label="咽鼓管"}
鼻咽 ↔ 鼓室，长 3.5～4.0 cm。外 1/3 骨部开鼓室前壁，内 2/3 软骨部开鼻咽侧壁（平对下鼻甲后方）。峡最窄，1～2 mm。
:::

:::pitfall{label="幼儿咽鼓管短、平、粗，中耳炎容易从咽部「灌」进来"}
成人咽口平时关，吞咽才开。幼儿短而平、管径大，咽部感染更容易经此入鼓室。写成「小儿咽鼓管更长所以不易感染」，方向反了。
:::

### （三）乳突窦和乳突小房

**1. 乳突窦（mastoid antrum）**　位于鼓室上隐窝的后方，向前开口于鼓室后壁上部，向后与乳突小房相连通，为鼓室和乳突小房之间的通道（图8-19、图8-20）。

**2. 乳突小房（mastoid cell）**　颞骨乳突部内的许多含气小腔，大小不等、互相连通，腔内覆盖黏膜，与乳突窦和鼓室黏膜相连续。中耳炎可经乳突窦侵犯乳突小房而引起乳突炎。耳内手术可经乳突小房入路。

:::definition{label="乳突窦"}
鼓室上隐窝后方的通道：向前开口于鼓室后壁上部，向后通乳突小房。中耳炎侵入乳突，先经过这一口。
:::

## 三、内耳

内耳（internal ear）位于颞骨岩部骨质内，介于鼓室和内耳道底之间（图8-22）。形状不规则、构造复杂，又称迷路，由骨迷路和膜迷路两部分组成。骨迷路与膜迷路之间充满外淋巴，膜迷路内充满内淋巴，内、外淋巴互不相通。

:::definition{label="内耳"}
颞骨岩部内，鼓室与内耳道底之间。骨迷路套膜迷路：骨与膜之间是外淋巴，膜内是内淋巴，**两套淋巴不相通**。
:::

::figure{src="/images/anatomy/textbook/p0277_01.png" caption="图8-22　内耳在颞骨岩部的投影" alt="颞骨岩部剖面：耳蜗、前庭、前骨半规管、外骨半规管和后骨半规管嵌在骨质内"}

### （一）骨迷路

骨迷路（bony labyrinth）是颞骨岩部骨密质围成的不规则腔隙（图8-23），分为耳蜗、前庭和骨半规管 3 部分，从前向后依次沿颞骨岩部长轴排列，互相通连，长度约为 **18.6 mm**。

:::definition{label="骨迷路"}
耳蜗（前）+ 前庭（中）+ 骨半规管（后），沿岩部长轴排列，长约 18.6 mm。
:::

**1. 前庭（vestibule）**　位于骨迷路中部，近似椭圆形腔隙，长约 **5 mm**。前部较窄，有一孔连通耳蜗；后上部较宽，有 5 个小孔通骨半规管。外侧壁即鼓室的内侧壁，有前庭窗和蜗窗。内侧壁即内耳道底，有前庭蜗神经通过。内侧壁上有自前上向后下的前庭嵴。嵴的后上方为椭圆囊隐窝，前下方为球囊隐窝，分别容纳椭圆囊和球囊。前庭嵴下部分开，分叉处有一小凹面，为蜗管隐窝，容纳蜗管的前庭盲端。椭圆囊隐窝靠近总骨脚开口处的前方有前庭水管内口，由此通向后下至内耳门后外侧的前庭水管外口。

前庭水管（vestibular aqueduct）是一骨性管道，内淋巴管经此管至内淋巴囊。内淋巴囊位于颞骨岩部后面近前庭水管外口处的硬脑膜内。前庭水管起于前庭，向后下走行，开口于颞骨岩部后面的前庭水管外口，有小静脉和内淋巴管通过。前庭水管外口位于颞骨岩部后面，**距内耳门的后外约 11 mm**，呈裂缝状，常被一骨嵴遮盖，该骨嵴对内淋巴囊有保护作用。

:::definition{label="前庭"}
骨迷路中部，长约 5 mm。前通耳蜗，后以 5 孔通骨半规管。外侧是前庭窗和蜗窗，内侧是内耳道底。
:::

:::definition{label="前庭水管"}
骨性管道，走内淋巴管至内淋巴囊。外口在颞骨岩部后面，**距内耳门后外约 11 mm**，裂缝状，常被骨嵴遮盖。
:::

**2. 骨半规管（bony semicircular canals）**　3 个半环形骨管，相互垂直排列。

（1）前骨半规管：弓向上方，埋于颞骨岩部弓状隆起的深面，与岩部长轴垂直。

（2）外骨半规管：弓向外侧，头前倾 30° 时呈水平位，是 3 个半规管中最短的。

（3）后骨半规管：弓向后外方，是 3 个半规管中最长的，与岩部长轴平行。

每个骨半规管皆有两个骨脚连于前庭：一个膨大称壶腹骨脚，膨大部称骨壶腹；另一个细小称单骨脚。前、后半规管的单骨脚合成一个总骨脚，故 3 个骨半规管共有 **5 个口**连于前庭。

:::definition{label="骨半规管"}
前、外、后三条，互相垂直。外半规管最短，头前倾 30° 时水平；后半规管最长。三管五口入前庭（前、后单骨脚合成总骨脚）。
:::

::figure{src="/images/anatomy/textbook/p0277_02.png" caption="图8-23　骨迷路" alt="打开的骨迷路：耳蜗可见前庭阶与鼓阶，前庭有前庭嵴、椭圆囊隐窝、球囊隐窝、蜗管隐窝、前庭水管内口和蜗水管内口；前、外、后骨半规管经总骨脚和骨壶腹连前庭"}

**3. 耳蜗（cochlea）**　位于前庭前方，形如蜗牛壳，尖朝向前外侧称蜗顶，底朝向内耳道底称蜗底。由蜗轴和蜗螺旋管构成（图8-23、图8-24、图8-25）。

蜗轴为蜗顶至蜗底的中央骨质，呈圆锥形，由蜗轴伸出骨螺旋板。骨螺旋板基部有蜗轴螺旋管，内藏蜗神经节；蜗轴骨松质内有蜗神经和血管穿过。

蜗螺旋管是骨密质围成的骨管，围绕蜗轴盘曲约**两圈半**，底部较大通向前庭，行向蜗顶逐渐细小，以盲端终于蜗顶。骨螺旋板由蜗轴突向蜗螺旋管内，未达外侧壁，空缺处由膜迷路的蜗管填补封闭。故蜗螺旋管腔分为 3 部分：近蜗顶侧为前庭阶；中间为膜性蜗管；近蜗底侧为鼓阶，终于封闭蜗窗的第二鼓膜。前庭阶和鼓阶内均含外淋巴，在蜗顶处借蜗孔彼此相通。蜗孔由骨螺旋板和膜螺旋板与蜗轴围成，是前庭阶和鼓阶连通的唯一通道。

:::definition{label="耳蜗"}
前庭前方，蜗顶尖向前外，蜗底对内耳道底。蜗螺旋管绕蜗轴约**两圈半**。
:::

:::definition{label="前庭阶、蜗管与鼓阶"}
蜗螺旋管内三层：近蜗顶 = 前庭阶（外淋巴）；中间 = 蜗管（内淋巴）；近蜗底 = 鼓阶（外淋巴，终于第二鼓膜）。前庭阶与鼓阶只在蜗顶**蜗孔**相通。
:::

:::pitfall{label="两圈半是蜗螺旋管绕蜗轴的圈数，不要写成半规管"}
半规管是三条互相垂直的半环。写成「耳蜗三圈半」或「半规管绕两圈半」，图8-23 对不上。
:::

### （二）膜迷路

膜迷路（membranous labyrinth）是套在骨迷路内封闭的膜性管和囊（图8-24），借纤维束固定于骨迷路壁上。由椭圆囊和球囊、膜半规管和蜗管 3 部分组成，互相通连，内充满内淋巴。

:::definition{label="膜迷路"}
椭圆囊 + 球囊 + 膜半规管 + 蜗管。封闭，内淋巴。套在骨迷路里，借纤维束固定。
:::

**1. 椭圆囊（utricle）和球囊（saccule）**　位于骨迷路的前庭部（图8-24）。椭圆囊位于椭圆囊隐窝，呈椭圆形，后壁有 5 个开口连通 3 个膜半规管。前壁借椭圆球囊管（utriculosaccular duct）与球囊相连，由此管发出内淋巴管，穿前庭水管至颞骨岩部后面，在硬脑膜下扩大为内淋巴囊。球囊较椭圆囊小，位于椭圆囊前下方的球囊隐窝，下端借连合管连于蜗管。

椭圆囊上端的底部和前壁上有感觉上皮，称椭圆囊斑（macula utriculi）。球囊内前上壁亦有感觉上皮，称球囊斑（macula sacculi）。二者均属位置觉感受器，感受头部静止的位置及直线变速运动引起的刺激。神经冲动分别沿前庭神经的椭圆囊支和球囊支传入。

:::definition{label="椭圆囊斑与球囊斑"}
位置觉感受器，感受**头部静止位置**和**直线变速运动**。椭圆囊斑在椭圆囊，球囊斑在球囊。不要写成感受旋转。
:::

**2. 膜半规管（membranous semicircular ducts）**　形态与骨半规管相似，套于同名骨半规管内，管径约为骨半规管的 **1/4～1/3**。在骨壶腹内，膜半规管有相应膨大的膜壶腹，壁上有隆起的壶腹嵴（crista ampullaris），是位置觉感受器，能感受头部**旋转变速运动**的刺激。3 个膜半规管内的壶腹嵴相互垂直，可分别将头部在三维空间中的运动变化转变成神经冲动，经前庭神经的壶腹支传入。

:::definition{label="壶腹嵴"}
膜壶腹壁上的位置觉感受器，感受**头部旋转变速运动**。三条互相垂直。直线变速不归这一户，归两斑。
:::

::figure{src="/images/anatomy/textbook/p0278_01.png" caption="图8-24　内耳模式图" alt="膜迷路套在骨迷路内：蜗管借连合管连球囊，椭圆球囊管连椭圆囊并发内淋巴管至内淋巴囊；前、外、后膜半规管经总膜脚连椭圆囊，可见膜壶腹；蜗窗、蜗水管和镫骨在前庭窗"}

**3. 蜗管（cochlear duct）**　位于耳蜗内，盘绕蜗轴两圈半。前庭端借连合管与球囊相通，顶端终于蜗顶为盲端，故蜗管为盲管。水平断面上呈三角形，有上壁、外侧壁和下壁：① 上壁为蜗管前庭壁（前庭膜），将前庭阶和蜗管分开；② 外侧壁为蜗螺旋管内表面骨膜的增厚部分，富有血管，称血管纹，一般认为与内淋巴的产生有关；③ 下壁由骨螺旋板和蜗管鼓壁（螺旋膜，又称基底膜）组成，与鼓阶相隔。在螺旋膜上有螺旋器（spiral organ），又称 Corti 器，是听觉感受器。

:::definition{label="蜗管"}
三角形盲管，绕蜗轴两圈半。上壁前庭膜，外侧壁血管纹（与内淋巴产生有关），下壁基底膜上坐着螺旋器。
:::

:::definition{label="螺旋器"}
又称 Corti 器，在基底膜上，是**听觉感受器**。不要和壶腹嵴、囊斑并成「都叫 Corti」。
:::

::figure{src="/images/anatomy/textbook/p0278_02.png" caption="图8-25　耳蜗切面图" alt="耳蜗断面：蜗轴居中，各圈可见前庭阶、蜗管和鼓阶；蜗管上壁为前庭膜，下壁为螺旋膜，上有螺旋器（Corti 器）和盖膜；骨螺旋板基部有蜗神经节"}

:::compare{title="内耳三套感受器（不要串户）"}
| 感受器 | 位置 | 刺激 |
|--------|------|------|
| 螺旋器（Corti） | 蜗管基底膜 | 声波 → 听觉 |
| 椭圆囊斑、球囊斑 | 椭圆囊、球囊 | 静止位置 + 直线变速 |
| 壶腹嵴 | 膜半规管膜壶腹 | 旋转变速 |

听只认 Corti，旋转只认嵴，直线只认斑。
:::

:::insight{label="内淋巴是一套通的：半规管、两囊、蜗管"}
椭圆囊 5 口接膜半规管，椭圆球囊管接球囊，连合管再接蜗管，内淋巴管通向内淋巴囊。外淋巴走骨与膜之间，经蜗孔沟通前庭阶和鼓阶。内外不相通，所以内淋巴积水（膜迷路积水）和外淋巴漏不是同一户。
:::

### 声音的传导

声音的传导分空气传导和骨传导两条路径。正常情况下以空气传导为主。

**（1）空气传导**　声波经外耳道传至鼓膜，引起鼓膜振动，继而使听小骨链随之运动，将声波转换成机械振动并加以放大，经镫骨底传至前庭窗，引起前庭阶的外淋巴波动。外淋巴波动经前庭膜传至内淋巴，内淋巴的波动刺激基底膜上的螺旋器，产生神经冲动，再经蜗神经传入中枢，产生听觉（图8-26）。前庭阶外淋巴的波动也引起鼓阶外淋巴的波动，传至蜗窗时，第二鼓膜外凸而缓冲波动。

鼓膜穿孔时，声波引起鼓室内空气振动，直接波及第二鼓膜，引起鼓阶外淋巴波动，使基底膜振动以兴奋螺旋器。通过这条途径能产生部分听觉。

**（2）骨传导**　声波经颅骨传入内耳的过程。声波的冲击可经颅骨和骨迷路传入，使耳蜗内的外淋巴和内淋巴波动，刺激基底膜上的螺旋器产生神经兴奋，引起较弱听觉。

外耳和中耳的疾患引起的耳聋为**传导性耳聋**。此时骨传导尚可部分代偿，故不会产生完全性耳聋。内耳、蜗神经、听觉传导通路及听觉中枢的疾患引起的耳聋为**神经性耳聋**。此时空气传导和骨传导途径虽正常，但均不能引起听觉，称完全性耳聋。

:::definition{label="空气传导"}
外耳道 → 鼓膜 → 听小骨链 → 镫骨底 → 前庭窗 → 前庭阶外淋巴 → 前庭膜 → 内淋巴 → 螺旋器 → 蜗神经。正常以这条为主。
:::

:::definition{label="骨传导"}
声波经颅骨和骨迷路传入，引起耳蜗内、外淋巴波动，兴奋螺旋器。较弱，可部分代偿传导性耳聋。
:::

:::definition{label="传导性耳聋与神经性耳聋"}
传导性：外耳、中耳疾患；骨传导可部分代偿，不是全聋。神经性：内耳、蜗神经、传导通路或中枢疾患；气导、骨导都听不见，是完全性耳聋。
:::

::figure{src="/images/anatomy/textbook/p0279_01.png" caption="图8-26　声波的传导" alt="气导路径：外耳道推动鼓膜，锤砧镫把振动传入前庭窗；前庭阶外淋巴波动绕蜗孔至鼓阶，蜗窗第二鼓膜缓冲；蜗管内淋巴兴奋螺旋器，冲动沿前庭蜗神经传出"}

- **果** 还有较弱听觉

- **果** 完全性耳聋
:::

### （三）内耳道

内耳道（internal acoustic meatus）（图8-27）位于颞骨岩部后面的中部，自内耳门至内耳道底，长约 **10 mm**。内耳道底邻接骨迷路的内侧壁，有很多孔隙，前庭蜗神经、面神经和迷路动脉由此穿行。

内耳道底有一横位骨嵴称横嵴，将内耳道底分隔为上、下两部。上部前内份有圆形的面神经区（面神经管入口），有面神经通过；后外侧有前庭上区，有前庭神经上支通过，即椭圆囊壶腹神经。下部前份为蜗区，有蜗神经通过；下部后份有前庭下区，有球囊神经通过；稍后为单孔，容后壶腹神经通过。

:::definition{label="内耳道"}
内耳门到内耳道底，长约 10 mm。穿行：前庭蜗神经、面神经、迷路动脉。
:::

:::compare{title="内耳道底（右侧，对照图8-27）"}
| 分区 | 位置 | 通过 |
|------|------|------|
| 面神经区 | 上部前内 | 面神经 |
| 前庭上区 | 上部后外 | 前庭神经上支（椭圆囊壶腹神经） |
| 蜗区 | 下部前份 | 蜗神经（螺旋孔） |
| 前庭下区 | 下部后份 | 球囊神经 |
| 单孔 | 前庭下区稍后 | 后壶腹神经 |

横嵴先把底分成上下，再在各区认神经。不要把蜗神经画到上半。
:::

### （四）内耳的血管、淋巴和神经

**1. 内耳的血管**　由迷路动脉和茎乳动脉供血。迷路动脉多发自小脑下前动脉或基底动脉，少数发自小脑下后动脉和椎动脉的颅内段。在内耳道底分为前庭支和蜗支：前庭支分布于椭圆囊、球囊和半规管；蜗支分布于蜗螺旋管。茎乳动脉发自耳后动脉，分布到部分半规管。颈椎肥大、椎动脉血运受阻、基底动脉供血不足等均可影响内耳血液供应，导致眩晕。内耳的静脉汇入岩上、下窦或横窦。

:::definition{label="迷路动脉"}
内耳的主要动脉。多发自小脑下前动脉或基底动脉。在内耳道底分前庭支和蜗支。供血不足可致眩晕。
:::

**2. 内耳的淋巴**　外淋巴成分与脑脊液相似，其来源、产生、循环和吸收尚不清楚。前庭内的外淋巴向后与半规管的外淋巴相通，向前与耳蜗前庭阶内的外淋巴通连，继经蜗孔进入鼓阶。前庭内的外淋巴通过蜗水管引流至蛛网膜下隙。蜗水管位于颞骨岩部内，蜗水管内口位于蜗窗内侧，外口位于颈静脉窝内侧、内耳道下方。

内淋巴类似细胞内液，其产生与蜗管外侧壁的血管纹、前庭的暗细胞以及外淋巴的滤过液有关。内淋巴所含电解质分子的大小及浓度受内淋巴管上皮泵系统调节，特别是血管纹内钠泵的调节。内淋巴经内淋巴管引流至内淋巴囊，再经内淋巴囊渗透入周围的静脉丛。内淋巴管和部分内淋巴囊位于前庭水管内。

:::definition{label="蜗水管"}
引流外淋巴至蛛网膜下隙。内口在蜗窗内侧，外口在颈静脉窝内侧、内耳道下方。不要和前庭水管（走内淋巴管）记混。
:::

:::compare{title="前庭水管与蜗水管"}
| | 走什么 | 内口 | 外口 |
|--|--------|------|------|
| 前庭水管 | 内淋巴管（至内淋巴囊） | 前庭（椭圆囊隐窝附近） | 岩部后面，距内耳门后外约 **11 mm** |
| 蜗水管 | 外淋巴（至蛛网膜下隙） | 蜗窗内侧 | 颈静脉窝内侧、内耳道下方 |

一个管内淋巴，一个管外淋巴。外口位置差得很远。
:::

**3. 内耳的神经**　前庭蜗神经包括前庭神经和蜗神经。

前庭神经由前庭神经节的中枢突组成，周围突有 3 支：① 上支为椭圆囊壶腹神经，穿前庭上区小孔，分布于椭圆囊斑以及前膜半规管和外膜半规管的壶腹嵴；② 下支为球囊神经，穿前庭下区小孔，分布至球囊斑；③ 后支为后壶腹神经，穿内耳道底后下部的单孔，分布至后膜半规管的壶腹嵴。

蜗神经由蜗螺旋神经节细胞的中枢突组成，经蜗轴纵管，穿内耳道底筛状区的螺旋孔，经内耳门入颅；周围突穿经骨螺旋板和基底膜，分布于螺旋器。

:::definition{label="前庭神经三支"}
上支椭圆囊壶腹神经 → 椭圆囊斑 + 前、外膜半规管壶腹嵴。下支球囊神经 → 球囊斑。后支后壶腹神经 → 后膜半规管壶腹嵴。
:::

:::definition{label="蜗神经"}
蜗螺旋神经节细胞的中枢突，穿蜗区螺旋孔入颅；周围突穿骨螺旋板和基底膜，分布于螺旋器。
:::

:::pitfall{label="后半规管的壶腹嵴不走前庭上区，走单孔"}
上支包了椭圆囊斑和前、外半规管嵴，后嵴单独走后壶腹神经、穿单孔。把三条嵴都写成「前庭上区」，图8-27 的单孔就空了。
:::

- [ ] 外耳道成人 2.0～2.5 cm，外 1/3 软骨、内 2/3 骨。查鼓膜：成人拉耳郭后上，婴儿后下。
- [ ] 鼓膜直径约 1 cm，倾斜 45°～50°。上 1/4 松弛部淡红，下 3/4 紧张部灰白，光锥在紧张部前下。
- [ ] 鼓室六壁：外鼓膜、上盖（颅中窝）、下颈静脉球、前颈内动脉（上张肌半管、下咽鼓管半管）、内迷路（岬、前庭窗、蜗窗、面神经管凸）、后乳突（窦口、锥隆起、镫骨肌）。
- [ ] 听小骨链：鼓膜脐—锤骨—砧骨—镫骨底封前庭窗。鼓膜张肌（下颌神经）紧张鼓膜；镫骨肌（面神经）拮抗，瘫痪致听觉过敏。
- [ ] 咽鼓管 3.5～4.0 cm，峡 1～2 mm；咽口平对下鼻甲后方，吞咽时开。幼儿短、平、粗，咽部感染易入鼓室。
