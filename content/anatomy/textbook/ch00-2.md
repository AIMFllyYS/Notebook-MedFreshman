# 二、 人体解剖学的分科

上一节把人体解剖学钉成「研究正常人体形态结构及其发生发展的形态学」。本节回答另一问：这门学问内部怎么分户。先从「解剖」一词的直译和方法说起，再写大体、显微、超微三个阶段，然后钉死广义解剖学的四户，以及我国通常采用的系统解剖学与局部解剖学。巨视/微视、外科解剖到艺术解剖、以及微创/虚拟/数字等新学科，都在本节收口。九大系统的组成与功能留给第四节；方位术语留给第五节。

「解剖」一词直译是剖开、切割的意思。用刀剪剖割的方法是研究人体形态结构的基本方法之一。由于科学技术的进步、研究方法的更新、相关学科发展的推进等，解剖学科不断发展，研究范围和内容不断扩展与深入。从发展的角度，解剖学经历了大体解剖学、显微解剖学、超微解剖学三个阶段，逐渐分化形成许多新的分支学科。广义的解剖学包括人体解剖学、组织学、细胞学和胚胎学。我国对人体解剖学的分科有多种方法，通常分为系统解剖学和局部解剖学。

:::note{label="本节无教学插图"}
分科是概念与名单，本版没有配套教学插图。不要把编委肖像或第五节的方位图误嵌入本节。
:::

:::definition{label="解剖（词义）"}
「解剖」直译为剖开、切割。刀剪剖割是研究人体形态结构的**基本方法之一**，不是唯一方法，更不是学科的全部定义。定义在第一节；方法在本节开口。
:::

:::concept{term="先问这是方法、阶段、广义四户，还是我国通常的两分法"}
看见「分科」，先不要把所有名词排成一列。教材用了几把不同的尺子：① 方法——刀剪剖割；② 发展三阶段——大体、显微、超微；③ 广义四户——人体解剖学、组织学、细胞学、胚胎学；④ 我国通常分科——系统解剖学与局部解剖学；⑤ 巨视与微视；⑥ 按研究角度分化的分支；⑦ 智能化时代的新学科。尺子不同，名单就不能并成「解剖学的十几个同义词」。
:::

:::pitfall{label="不要把「解剖＝用刀切」写成学科定义"}
直译是剖开、切割，那是方法。第一节的定义是研究正常人体形态结构及其发生发展。X 线、断层、虚拟、数字解剖学并不靠刀剪，但仍属解剖学。写成「不拿刀就不是解剖」，后文影像和数字分支会没有户头。
:::

:::insight{label="方法会变，对象不变"}
刀剪、光镜、电镜、X 线、CT、计算机建模，都是看同一件事情：正常人体的形态结构及其发生发展。分科的动力是技术与相关学科在推，对象并没有改成「疾病」或「纯功能」。
:::

## 一、三个阶段：大体、显微、超微

从发展的角度，解剖学经历了大体解剖学、显微解剖学、超微解剖学三个阶段，逐渐分化形成许多新的分支学科。三个阶段是分辨率和研究手段的推进，不是三门互相取代的课。第三节简史会把电镜、CT、PET 写回这条轴；本节先把三个名字立住。

:::definition{label="大体解剖学"}
大体解剖学以肉眼（可辅以简单放大）观察人体形态结构，是三个阶段的第一阶段。系统解剖学和局部解剖学主要通过肉眼观察，属于这一尺度。尸解剖、标本、模型仍是医学生入门的基本手段。
:::

:::definition{label="显微解剖学"}
显微解剖学以光学显微镜观察微细结构，对应组织学、细胞学、胚胎学等微视内容。没有切片、染色和光镜，这一阶段不能成立。
:::

:::definition{label="超微解剖学"}
超微解剖学以电子显微镜等观察细胞的超微结构与三维构筑，使形态科学研究达到细胞和亚细胞水平并发展到分子水平。它没有取消大体解剖学，只是把分辨率继续往下推。
:::

:::compare{title="大体、显微、超微三个阶段"}
| | 主要手段 | 主要看见什么 | 对应的分科说法 | 不要写成 |
|--|----------|--------------|----------------|---------|
| 大体解剖学 | 肉眼、刀剪、标本 | 器官外形、位置、毗邻、系统配布 | 巨视解剖学（系统+局部） | 「过时了，已被电镜取代」 |
| 显微解剖学 | 光镜、切片染色 | 组织、细胞、胚胎微细结构 | 微视解剖学 | 「就是超微结构」 |
| 超微解剖学 | 电子显微镜等 | 超微结构、三维构筑，至亚细胞与分子水平 | 从显微再往下的阶段 | 「人体解剖学课只讲这一阶段」 |

三阶段是发展轴，巨视/微视是观察手段轴，两套词不要对成一一对应的六个同义词。
:::

:::keypoint{label="三阶段记住「肉眼 → 光镜 → 电镜」"}
- 推动力：科学技术、研究方法、相关学科。
- 结果：研究范围和内容扩展、深入，并分化出许多分支。
- 大体解剖学并未因后两个阶段出现而停止——第三节会原句重申这一点。
:::

:::pitfall{label="三个阶段不是「人体解剖 / 组织 / 分子生物」三门课的别名"}
大体≈巨视的人体解剖学（系统+局部）；显微≈组织学、细胞学、胚胎学这一尺度；超微是电镜把同一形态学再往下推。分子生物学、基因组不在本版分科名单里。不要用别的教材把三阶段改写成「宏观、微观、分子」三门独立课程。
:::

## 二、广义解剖学的四户

广义的解剖学包括人体解剖学、组织学、细胞学和胚胎学。这是本版写下的四户，不要自行增删。

:::definition{label="广义的解剖学"}
包括人体解剖学、组织学、细胞学和胚胎学。四户都研究正常形态及其发生发展，差别在尺度和侧重点：肉眼器官与系统、组织、细胞、胚胎发生。
:::

:::definition{label="人体解剖学（狭义，作为广义中的一户）"}
广义四户里的「人体解剖学」，主要指以肉眼观察为主、阐述器官系统形态位置的这一户，也就是医学生这门课的主体。它与第一节总定义并不打架：总定义给整个学科；此处是在广义名单里的位置。
:::

:::definition{label="组织学（在广义解剖学中的位置）"}
以显微镜观察组织的微细结构及其相关功能，属微视解剖学。本课程不替代《组织学与胚胎学》。
:::

:::definition{label="细胞学（在广义解剖学中的位置）"}
以细胞为对象的形态学，属微视解剖学。不要把它听成「只有分子生物学才研究细胞」。
:::

:::definition{label="胚胎学（在广义解剖学中的位置）"}
研究个体发生发展，与第一节定义中的「发生发展」直接衔接。胚胎学在广义上仍属解剖学，但我国课程通常单独开设。
:::

:::compare{title="广义解剖学四户"}
| 户头 | 主要尺度 | 主要问题 | 与本课关系 |
|------|----------|----------|------------|
| 人体解剖学 | 肉眼为主 | 器官系统的形态、位置、毗邻、生长发育 | 本教材主体（系统解剖学） |
| 组织学 | 光镜（及电镜） | 组织微细结构及相关功能 | 广义内的另一户，另有课程 |
| 细胞学 | 细胞水平 | 细胞形态与结构 | 广义内的另一户 |
| 胚胎学 | 发生过程 | 如何从受精卵建成各器官系统 | 对应「发生发展」，另有课程 |

四户是「广义包括」，不是「四门课可以互相替代」。
:::

:::pitfall{label="广义是四户，不要写成两户或五户"}
本版名单是人体解剖学、组织学、细胞学、胚胎学。不要漏细胞学，不要把生理学、病理解剖学塞进来凑数，也不要把「系统解剖学、局部解剖学」当成广义的另外两户——那是下一把尺子。
:::

:::insight{label="「发生发展」在广义里主要落在胚胎学，但不从人体解剖学里消失"}
第一节定义已经写下发生发展。广义把胚胎学单列，是尺度和课程分工，不是说系统解剖学可以不谈生长发育。长骨骺软骨、青春期生殖器、老年器官的形态改变，仍在人体解剖学各论里。
:::

## 三、我国通常分为系统解剖学和局部解剖学

我国对人体解剖学的分科有多种方法，通常分为系统解剖学和局部解剖学。这是医学生最常用的一把尺子，也是本课程的户头。

系统解剖学（systematic anatomy）是按人体的器官功能系统（如运动系统、消化系统、呼吸系统、泌尿系统、生殖系统、内分泌系统、脉管系统、感觉器和神经系统）阐述正常人体器官的形态结构及其生长发育规律的科学，是医学生的必修课。如果按人体的某一局部（如头部、颈部、胸部、腹部、盆部、背部和四肢等），重点描述人体的结构层次、器官配布、毗邻关系等，称为局部解剖学（regional anatomy）。

:::definition{label="系统解剖学"}
系统解剖学（systematic anatomy）按人体的器官功能系统，阐述正常人体器官的形态结构及其生长发育规律。本版举例的功能系统是：运动系统、消化系统、呼吸系统、泌尿系统、生殖系统、内分泌系统、脉管系统、感觉器和神经系统。它是医学生的必修课，也是本教材的编写方式。
:::

:::definition{label="局部解剖学"}
局部解剖学（regional anatomy）按人体的某一局部，重点描述结构层次、器官配布、毗邻关系。本版举例的局部是：头部、颈部、胸部、腹部、盆部、背部和四肢等。
:::

:::definition{label="器官功能系统（系统解剖学的目录尺子）"}
把执行同一类功能的器官归为一系统，按系统叙述形态与生长发育。九个名字的完整组成与功能在第四节展开；此处只把「按功能系统叙述」立成方法。
:::

:::keypoint{label="系统解剖学举例的九个功能系统（本版名单，不要改）"}
- 运动系统
- 消化系统
- 呼吸系统
- 泌尿系统
- 生殖系统
- 内分泌系统
- 脉管系统
- 感觉器
- 神经系统

是九个，不是十个。感觉器不要改写成「感觉系统」再外加「免疫系统」充第十户。组成与功能见第四节。
:::

:::compare{title="系统解剖学 vs 局部解剖学"}
| | 系统解剖学 | 局部解剖学 |
|--|------------|------------|
| 英文 | systematic anatomy | regional anatomy |
| 叙述顺序 | 按器官功能系统 | 按身体局部 |
| 本版举例 | 运动、消化、呼吸、泌尿、生殖、内分泌、脉管、感觉器、神经 | 头、颈、胸、腹、盆、背、四肢等 |
| 重点 | 正常形态结构及其生长发育规律 | 结构层次、器官配布、毗邻关系 |
| 课程地位 | 医学生必修课；本教材 | 通常另设课程或后续模块 |
| 观察手段 | 主要为肉眼，属巨视 | 主要为肉眼，属巨视 |
| 要回答的典型问题 | 肝属于什么系统、由什么构成、如何发育 | 右上腹从浅到深是哪些层、肝和谁毗邻 |

两门课观察尺度相同，组织材料的尺子不同。
:::

:::pitfall{label="系统解剖不是「不管毗邻」，局部解剖不是「不管系统」"}
系统解剖学的学习目的里已经包含位置与毗邻；局部解剖学也不会否认器官属于某系统。差别是**叙述的主轴**：功能系统 vs 身体局部。写成「系统课只背器官、局部课才有层次」，第一节的学习目的和本节的重点描述会对不上。
:::

:::pitfall{label="九个功能系统不要按别的书改名单"}
有的书把脉管系统改称循环系统，把感觉器改称感觉系统，再把免疫单列。本版系统解剖学举例是运动、消化、呼吸、泌尿、生殖、内分泌、脉管、感觉器、神经。第四节按同一名单写组成。免疫相关结构在本版不另立为第十系统。
:::

:::concept{term="先问这页是按系统写还是按局部写"}
同一结构可以出现在两套目录里。例如胃：系统解剖学放在消化系统，写形态分部、血管神经；局部解剖学放在腹部，写腹膜、层次、与胰、肝、横结肠的毗邻。看见名词先问当前用的是哪把尺子，再进入细节。
:::

:::note{label="「有多种方法，通常分为」"}
教材写：我国对人体解剖学的分科有多种方法，通常分为系统解剖学和局部解剖学。「通常」意味着这是最常用的两分，不是唯一合法的分法。后面的外科、表面、X 线、断层等，是另一把「按研究角度、手段和目的」的尺子。
:::

## 四、巨视解剖学与微视解剖学

系统解剖学和局部解剖学主要通过肉眼观察来描述人体的形态结构，统称巨视解剖学（macroanatomy）。以显微镜观察为研究手段的组织学、细胞学、胚胎学，称微视解剖学（microanatomy）。

:::definition{label="巨视解剖学"}
巨视解剖学（macroanatomy）统称系统解剖学和局部解剖学，手段是肉眼观察人体形态结构。巨视不是「粗略」，而是尺度在器官、系统和局部层次。
:::

:::definition{label="微视解剖学"}
微视解剖学（microanatomy）以显微镜为研究手段，包括组织学、细胞学、胚胎学。微视对应广义四户里除人体解剖学以外的三户。
:::

:::compare{title="巨视 vs 微视"}
| | 巨视解剖学 macroanatomy | 微视解剖学 microanatomy |
|--|-------------------------|-------------------------|
| 手段 | 肉眼 | 显微镜 |
| 包括 | 系统解剖学、局部解剖学 | 组织学、细胞学、胚胎学 |
| 和三阶段 | 大体解剖学这一尺度 | 显微解剖学这一尺度（超微再往下） |
| 和广义四户 | 人体解剖学 | 组织学、细胞学、胚胎学 |

巨视/微视按手段分；系统/局部分按叙述顺序分。系统解剖学是巨视，不是微视。
:::

:::pitfall{label="不要把系统解剖学写成微视，也不要把组织学写成巨视"}
判断尺子是观察手段：肉眼 → 巨视；显微镜 → 微视。系统解剖学尽管写到组织名称（如骨骼肌、上皮），主体仍是肉眼下的器官系统。组织学尽管也谈器官，手段是显微镜。
:::

:::insight{label="医学生两门形态课，正好对应巨视和微视"}
《系统解剖学》走巨视、按系统；《组织学与胚胎学》走微视。两门课覆盖广义四户中的主体，细胞学内容常含在组胚或细胞生物学中。不要把其中一门听成可以代替另一门。
:::

## 五、按研究角度、手段和目的分化的分支

此外，由于研究的角度、手段和目的不同，人体解剖学又逐渐分化形成许多新的分支学科。教材点名的有：外科解剖学、表面解剖学、X 线解剖学、断层解剖学、运动解剖学、神经解剖学、艺术解剖学。

:::definition{label="外科解剖学"}
外科解剖学（surgical anatomy）是密切联系外科手术的解剖学。户头是手术需要的层次、毗邻、血管神经和可利用的间隙，不是另写一套与系统解剖学冲突的器官。
:::

:::definition{label="表面解剖学"}
表面解剖学（surface anatomy）联系临床应用，研究人体表面形态特征。体表标志、投影、肌性轮廓都落在这一户，是视诊、触诊和穿刺定位的形态学底板。
:::

:::definition{label="X 线解剖学"}
X 线解剖学（X-ray anatomy）运用 X 线摄影技术研究人体形态结构。它把活体内部结构写成可以在平片上辨认的影像，而不是把解剖改成放射治疗学。
:::

:::definition{label="断层解剖学"}
断层解剖学（sectional anatomy）研究人体各局部或器官的断面形态结构。CT、MRI 读片用的就是这一户的断面语言。与 X 线解剖学手段不同：一个侧重摄影投影，一个侧重断面。
:::

:::definition{label="运动解剖学"}
运动解剖学（locomotive anatomy）以提高体育运动效果为目的，研究体育运动与人体形态结构的关系。户头是运动与形态的关系，不是第一章运动系统的别名。
:::

:::definition{label="神经解剖学"}
神经解剖学（neuroanatomy）以研究脑形态与功能为主。本教材第九章神经系统是系统解剖学框架下的神经，神经解剖学作为分支把脑的形态与功能写得更专。
:::

:::definition{label="艺术解剖学"}
艺术解剖学（art anatomy）研究人体外形轮廓和结构比例，为绘画造型奠定基础。目的是造型，不是诊疗，但用的仍是正常人体形态。
:::

:::compare{title="七个经典分支：角度、手段、目的"}
| 分支 | 英文 | 分化所据 | 主要问题 | 不要听成 |
|------|------|----------|----------|----------|
| 外科解剖学 | surgical anatomy | 目的：手术 | 层次、毗邻、入路 | 「只有外科才需要解剖」 |
| 表面解剖学 | surface anatomy | 目的：临床体表 | 表面形态特征、标志与投影 | 「只是皮肤」 |
| X 线解剖学 | X-ray anatomy | 手段：X 线摄影 | 活体投影下的形态 | 「等于断层」 |
| 断层解剖学 | sectional anatomy | 手段/对象：断面 | 局部或器官的断面形态 | 「等于 CT 机器」 |
| 运动解剖学 | locomotive anatomy | 目的：体育运动效果 | 运动与形态结构的关系 | 「等于运动系统」 |
| 神经解剖学 | neuroanatomy | 对象：脑的形态与功能 | 脑 | 「等于第九章全文的另一个名字」 |
| 艺术解剖学 | art anatomy | 目的：绘画造型 | 外形轮廓和结构比例 | 「与医学无关所以不属解剖学」 |

七户都从人体解剖学分化，广义上仍属解剖学。
:::

:::pitfall{label="运动解剖学 ≠ 运动系统；神经解剖学 ≠ 可以取消第九章"}
运动系统是系统解剖学的一个功能系统（骨、骨连结、骨骼肌）。运动解剖学是以提高体育运动效果为目的的分支。神经解剖学以脑的形态与功能为主，系统解剖学仍要按中枢和周围把神经系统写全。同名容易并户，本版用目的和对象把它们切开。
:::

:::pitfall{label="X 线解剖学和断层解剖学不要并成「影像」一词"}
教材分开写：X 线摄影 → X 线解剖学；断面形态 → 断层解剖学。后文智能化时代还有数字、虚拟。临床口中的「影像解剖」常混用，答题按本版分户。
:::

:::cause-effect{title="手段和目的一变，就会长出分支"}
- **因** 研究角度、手段、目的不同（手术、体表、X 线、断面、体育、脑、造型）
- **果** 从人体解剖学中分化出外科、表面、X 线、断层、运动、神经、艺术等分支学科
:::

## 六、智能化、信息化、数字化时代的新学科

当前，人类进入了智能化、信息化和数字化的时代，解剖学也随之产生了微创解剖学、虚拟解剖学、数字解剖学等新学科。随着人体奥秘的不断揭示和破译，又会有新的学科不断从解剖学中脱颖而出，形成新兴的边缘交叉学科，但在广义上仍属于解剖学范畴。

:::definition{label="微创解剖学"}
微创解剖学伴随微创外科而来，研究在有限切口、腔镜或介入路径下必须掌握的层次、腔隙和毗邻。第三节会写：显微外科、微创外科的进步，推动了显微外科解剖学和微创外科解剖学的发展。
:::

:::definition{label="虚拟解剖学"}
虚拟解剖学用计算机生成的三维人体进行研究与教学，使形态结构可以在虚拟空间里被观察、剖切和重组。它不取代标本，但扩展了「看」的方式。
:::

:::definition{label="数字解剖学"}
数字解剖学建立在人体结构数字化的基础上，把形态变成可计算、可重建、可仿真的数据。与虚拟解剖学常连用，但教材把它们并列为新学科。
:::

:::definition{label="边缘交叉学科（仍属解剖学）"}
新学科会从解剖学中脱颖而出，与外科、影像、力学、免疫、工程等交叉。教材收口：在广义上仍属于解剖学范畴。不要因为名字里有「数字」「虚拟」「微创」就把它们划出形态学。
:::

:::compare{title="经典分支与时代新学科"}
| | 教材点名 | 直接推动 | 广义归属 |
|--|----------|----------|----------|
| 经典分支 | 外科、表面、X 线、断层、运动、神经、艺术 | 手术、体表、摄影、断面、体育、脑研究、造型 | 解剖学 |
| 时代新学科 | 微创解剖学、虚拟解剖学、数字解剖学 | 微创外科；智能化、信息化、数字化 | 解剖学 |
| 第三节还将出现 | 影像解剖学、器官移植解剖学、组织工程学等 | CT/PET、免疫学、外科分段 | 交叉，广义仍属解剖学 |

本节先立微创、虚拟、数字三户；CT、PET、肝段肺段等细节在第三节简史里写。
:::

:::pitfall{label="新学科不是把刀剪方法作废"}
开口已经写：刀剪剖割是基本方法**之一**。虚拟和数字提供新的观察和教学手段，标本和层次仍是形态学的实物底板。写成「以后只看软件」，巨视解剖学的必修地位会被误取消。
:::

:::insight{label="分科名单会变，范畴句子不变"}
教材预告：还会有新学科脱颖而出。判断新名词是否还在解剖学里，用第一节的定义：是不是在研究正常人体形态结构及其发生发展。是，就仍属广义解剖学；不是，才是真正跑到别的学科。
:::

:::timeline{period="分科这几把尺子怎么叠在一起"}
- **方法** 刀剪剖割是基本方法之一，不是唯一
- **发展三阶段** 大体解剖学 → 显微解剖学 → 超微解剖学
- **广义四户** 人体解剖学、组织学、细胞学、胚胎学
- **我国通常** 系统解剖学（必修，本教材）与局部解剖学
- **手段** 巨视（系统+局部）vs 微视（组、细、胚）
- **角度/目的** 外科、表面、X 线、断层、运动、神经、艺术
- **当代** 微创、虚拟、数字；广义上仍属解剖学
:::

:::memory{label="本节必背要点"}
- [ ] 「解剖」直译剖开、切割；刀剪剖割是研究形态结构的基本方法之一。
- [ ] 三阶段：大体解剖学、显微解剖学、超微解剖学。
- [ ] 广义解剖学包括人体解剖学、组织学、细胞学和胚胎学。
- [ ] 我国通常分为系统解剖学与局部解剖学。
- [ ] 系统解剖学（systematic anatomy）：按器官功能系统阐述正常形态及其生长发育规律，医学生必修课。
- [ ] 功能系统举例（九个）：运动、消化、呼吸、泌尿、生殖、内分泌、脉管、感觉器、神经。
- [ ] 局部解剖学（regional anatomy）：按局部描述层次、配布、毗邻；局部举例：头、颈、胸、腹、盆、背、四肢等。
- [ ] 系统+局部，肉眼观察 → 巨视解剖学（macroanatomy）。
- [ ] 组织学、细胞学、胚胎学，显微镜 → 微视解剖学（microanatomy）。
- [ ] 分支：外科解剖学、表面解剖学、X 线解剖学、断层解剖学、运动解剖学、神经解剖学、艺术解剖学。
- [ ] 时代新学科：微创解剖学、虚拟解剖学、数字解剖学；广义上仍属解剖学。
- [ ] 运动解剖学 ≠ 运动系统；感觉器不要改成第十系统。
:::
