# 八、　胰岛

胰岛是胰内的内分泌组织，不是另一个独立的腺器官。本节把这一户写完：大小不等、形状不一的球形细胞团；成人胰约有 100 万个胰岛，约占胰体积的 1.5%；数目最多的是 α 细胞和 β 细胞，分别分泌胰高血糖素和胰岛素，协同维持血糖稳态。不要把胰管、十二指肠和胆囊的外分泌形态写成胰岛。

胰岛（pancreatic islet）为许多大小不等、形状不一的球形细胞团（图6-7）。成人胰约有 100 万个胰岛，约占胰体积的 1.5%。每个胰岛含有若干球形、椭圆形或多边形细胞，数目最多的是胰岛 α 细胞和 β 细胞，分别分泌胰高血糖素和胰岛素。胰高血糖素和胰岛素协同作用，能调节血糖浓度，维持血糖稳态。

:::definition{label="胰岛"}
胰内大小不等、形状不一的**球形细胞团**。是内分泌组织，无导管，激素入血。不要把它听成胰管树上的一个膨大。
:::

:::compare{title="成人胰岛的数目和体积（本版）"}
| | 本版 |
|--|------|
| 数目 | 约 **100 万** 个 |
| 占胰体积 | 约 **1.5%** |

100 万是约数，不要改成「几千个」或「和腺泡一样多」。体积只占约 1.5%，外分泌部仍是胰的主体。
:::

:::definition{label="胰岛α细胞"}
数目最多的两类之一。分泌**胰高血糖素**。
:::

:::definition{label="胰岛β细胞"}
数目最多的两类之一。分泌**胰岛素**。
:::

:::definition{label="胰高血糖素与胰岛素"}
协同调节血糖浓度，维持血糖稳态。本版把「数目最多」给 α 和 β 这两类，其他细胞不在本节展开名单。
:::

:::compare{title="α 与 β 不要对调"}
| 细胞 | 激素 | 不要写成 |
|------|------|----------|
| α 细胞 | 胰高血糖素 | 「α 产胰岛素」 |
| β 细胞 | 胰岛素 | 「β 产胰高血糖素」 |

两样激素协同，不是互相替代。写反之后，升糖和降糖的细胞来源就对调。
:::

:::concept{term="先问这是不是胰里的内分泌组织，再问有没有把胰管写成胰岛"}
看见胰，先切开外分泌和内分泌。胰管排胰液进十二指肠，是有导管的外分泌；胰岛是散在的细胞团，激素入血。把胰岛听成「胰管末端的球」，无导管这一笔就从内分泌组织里删掉了。
:::

:::pitfall{label="成人约 100 万个胰岛，不要写成 100 个或 10 万"}
本版原句：成人胰约有 100 万个胰岛。少一个「万」或少一个数量级，和「约占体积 1.5%」对不上。
:::

:::pitfall{label="α 产胰高血糖素，β 产胰岛素，不要写反"}
本版把两类并列，分别对应两种激素。口诀记反是常见错。协同维持稳态，不是「只有胰岛素管血糖」。
:::

:::pitfall{label="胰岛无导管，不要把图6-7 里的胰管当成胰岛的排出管"}
图6-7 主图上的胰管、胆总管是外分泌通路，开口走向十二指肠。右下放大框里，胰岛周围是腺泡，胰岛内部标的是毛细血管——激素走血，不走胰管。
:::

::figure{src="/images/anatomy/textbook/p0201_01.png" caption="图6-7　胰岛" alt="胰及十二指肠、胆囊、胆总管和胰管；右下放大示胰腺细胞、导管、胰岛、胰岛细胞和毛细血管"}

图6-7 主图先认胰的外形和胰管走向十二指肠；箭头指到实质里的一团，放大后才是胰岛：周围腺泡有导管，胰岛本身贴着毛细血管。章首图6-1 上的「胰」指的就是这里的内分泌组织座位。

:::insight{label="主图看有导管的胰，放大框看无导管的胰岛"}
外分泌走胰管，内分泌走毛细血管。1.5% 的体积里挤着约 100 万个细胞团，数目最多的两类分别出胰高血糖素和胰岛素，把血糖钉在稳态上。
:::

:::keypoint{label="胰岛三句话"}
- 胰内球形细胞团；成人约 100 万个，约占体积 1.5%。
- 数目最多：α 细胞 → 胰高血糖素；β 细胞 → 胰岛素。
- 两者协同调节血糖，维持稳态；激素入血，不走胰管。
:::

:::note{label="本章止于胰岛"}
内分泌腺无导管、内分泌组织是细胞团，这两句从章首贯穿到这里。胰岛写完，内分泌这一章就收口。
:::
