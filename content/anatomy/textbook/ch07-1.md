# 第一节　心血管系统

脉管系统（vascular system）是封闭的管道系统，分布于人体各部，包括心血管系统和淋巴系统。本节把「心血管系统」这一户写完：心、动脉、毛细血管和静脉，以及体循环与肺循环。下一节另立户头，不要把那边的管道和器官名单提前写进来。

心血管系统由心、动脉、毛细血管和静脉组成，血液在其中循环流动。主要功能是物质运输：把消化吸收的营养和肺吸收的氧送到组织和细胞，把代谢产物、多余的水和二氧化碳送到肾、肺、皮肤排出。内分泌细胞分泌的激素也经脉管运到靶器官。心肌细胞、血管平滑肌细胞和内皮细胞还能分泌心房钠尿肽、肾素、血管紧张素等，参与功能调节。

:::definition{label="脉管系统"}
封闭的管道系统，包括**心血管系统**和**淋巴系统**。心血管系统走血液。本节只写前一户；后一户的管道最后汇入静脉，形态归下一节。
:::

:::definition{label="心血管系统"}
由**心、动脉、毛细血管和静脉**组成。心是动力泵，动脉离心，静脉回心，毛细血管是物质交换的场所。四件缺一，循环就断。
:::

:::concept{term="先问这是不是心加三条管子，再问有没有把下一节写成心血管"}
看见脉管，先切成心血管和下一节两户。心血管的户头是心、动脉、毛细血管、静脉。把「脉管系统」听成「就是心脏」，毛细血管和侧支循环会从开篇丢掉；把下一节的管道写进本节，又是吞户。
:::

|--|------|
| 本节 | 心血管系统：心、动脉、毛细血管、静脉 |
| 下一节 | 另立户头，管道最后汇入静脉 |

## 一、概述

### （一）心血管系统的组成

**1. 心（heart）**　连接动、静脉的枢纽，心血管系统的动力泵，主要由心肌构成，并有内分泌功能。心内部被心间隔分成互不相通的左、右两半，每半再分为心房和心室，故有四个腔：左心房、左心室、右心房、右心室。同侧心房和心室借房室口相通。心房接受静脉，心室发出动脉。房室口和动脉口都有瓣膜，顺流开启、逆流关闭，保证血液定向流动。

:::definition{label="心"}
中空的肌性纤维性器官，形似倒置、前后稍扁的圆锥体，斜位于胸腔中纵隔内。四个腔、两套瓣，把体循环和肺循环接到同一台泵上。
:::

**2. 动脉（artery）**　运送血液离心的管道。管壁分内膜、中膜、外膜三层：内膜菲薄，腔面是内皮；中膜含平滑肌、弹性纤维和胶原纤维，大动脉以弹性纤维为主，中、小动脉以平滑肌为主；外膜为疏松结缔组织，防止过度扩张。大动脉弹性回缩，在心室舒张时继续推动血液；中、小动脉，尤其是小动脉，平滑肌舒缩改变管腔，影响局部血流量和血流阻力。动脉越分越细，最后移行为毛细血管。

:::definition{label="动脉"}
运送血液**离心**的管道。户头落在方向，不落在颜色：左心室发出的主动脉走动脉血，右心室发出的肺动脉干走的是静脉血。
:::

**3. 毛细血管（capillary）**　连接动、静脉末梢的管道，管径一般为 **6～8 μm**，管壁主要由一层内皮细胞和基膜构成。彼此吻合成网。除角膜、晶状体、毛发、软骨、牙釉质和被覆上皮外，遍布全身。数量多、管壁薄、通透性大、血流缓慢，是血液与组织液进行物质交换的场所。

:::definition{label="毛细血管"}
动、静脉末梢之间的交换管道。本版管径 **6～8 μm**。无毛细血管的名单按原句记：**角膜、晶状体、毛发、软骨、牙釉质、被覆上皮**。不要自行加减。
:::

**4. 静脉（vein）**　运送血液回心的血管。小静脉由毛细血管汇合而成，向心回流中不断接受属支，汇成中静脉、大静脉，最后注入心房。管壁也可分三层，但界线常不明显。与伴行动脉相比：管壁薄、管腔大、弹性小、容血量较大。

:::definition{label="静脉"}
运送血液**回心**的血管。肺静脉送的是含氧血，上、下腔静脉和冠状窦送的是静脉血。方向比颜色先问。
:::

:::pitfall{label="不要按颜色给动脉、静脉下定义"}
动脉是离心，静脉是回心。肺动脉干里是静脉血，肺静脉里是动脉血。写成「动脉=红、静脉=蓝」，肺循环这一户当场对不上。
:::

在神经体液调节下，血液沿心血管系统循环不息。血液由左心室泵出，经主动脉及其分支到达全身毛细血管，与组织、细胞进行物质和气体交换，再经各级静脉，最后经上、下腔静脉及心冠状窦返回右心房，这一途径称**体循环**（大循环）。血液由右心室搏出，经肺动脉干及其分支到达肺泡毛细血管进行气体交换，再经肺静脉进入左心房，称**肺循环**（小循环）。两条循环同时进行：体循环路程长、范围广，以动脉血滋养全身，并把代谢产物和二氧化碳运回心；肺循环路程短，只通过肺，主要使静脉血转变成氧饱和的动脉血。

::figure{src="/images/anatomy/textbook/p0203_01.png" caption="图7-1　血液循环示意图" alt="体循环与肺循环模式：左心室经主动脉至全身毛细血管，经上、下腔静脉回右心房；右心室经肺动脉干至肺毛细血管，经肺静脉回左心房；并标出肝门静脉及腹腔脏器毛细血管"}

:::definition{label="体循环"}
左心室 → 主动脉及分支 → 全身毛细血管 → 各级静脉 → 上、下腔静脉及冠状窦 → 右心房。大循环，路程长，滋养全身。
:::

:::definition{label="肺循环"}
右心室 → 肺动脉干及分支 → 肺泡毛细血管 → 肺静脉 → 左心房。小循环，只通过肺，把静脉血变成动脉血。肺动脉、肺静脉的细部分支已在呼吸系统写过，本节点到干和开口即可。
:::

:::compare{title="体循环与肺循环"}
| | 体循环（大循环） | 肺循环（小循环） |
|--|------------------|------------------|
| 起点 | 左心室 | 右心室 |
| 动脉干 | 主动脉 | 肺动脉干 |
| 交换部位 | 全身毛细血管 | 肺泡毛细血管 |
| 回心 | 上、下腔静脉及冠状窦 → 右心房 | 肺静脉 → 左心房 |
| 路程 | 长，范围广 | 短，只通过肺 |
| 完成的事 | 动脉血滋养全身，运回代谢产物和二氧化碳 | 静脉血转变成氧饱和的动脉血 |

两条同时转。写成「先体循环再肺循环」或「肺循环也滋养全身」，泵和交换场所都错了。
:::

:::insight{label="图7-1 先认两圈，再认肝门静脉这一笔"}
红圈是体循环，蓝圈过肺是肺循环。腹腔不成对脏器先汇入肝门静脉、过肝血窦，再经肝静脉进下腔静脉——那是静脉户里的门静脉系，不是第三条循环。
:::

### （二）血管的吻合及功能意义

人体血管除经动脉—毛细血管—静脉相通外，动脉与动脉、静脉与静脉、甚至动脉与静脉之间，可借吻合支或交通支彼此连接，形成血管吻合（vascular anastomosis）。

::figure{src="/images/anatomy/textbook/p0204_01.png" caption="图7-2　血管吻合和侧支循环示意图" alt="A 交通支、动脉弓、动脉网、动静脉吻合；B 动脉主干两侧的侧支，以及主干阻塞后侧支增粗绕过阻塞段"}

:::definition{label="血管吻合"}
动脉与动脉、静脉与静脉、动脉与静脉之间借交通支相连。不是「必须先过毛细血管才能见面」。
:::

:::definition{label="侧支循环"}
主干行程中发出平行的侧副管，不同高度的侧副管彼此吻合，称侧支吻合。主干阻塞后侧副管逐渐增粗，血流经扩大的侧支到达阻塞远端，使受阻区得到不同程度的代偿。侧支循环显示血管的适应能力和可塑性。
:::

:::compare{title="吻合四类（对照图7-2）"}
| 类 | 本版形态 | 本版例子 | 功能 |
|----|----------|----------|------|
| 动脉间吻合 | 交通支；关节网；动脉弓 | 脑底动脉；关节网；掌浅弓、掌深弓、胃小弯动脉弓 | 缩短循环时间，调节血流量 |
| 静脉间吻合 | 比动脉更丰富；脏器周围或壁内成静脉丛 | 膀胱、子宫、直肠等处的静脉丛 | 器官扩大或受压时血流通畅 |
| 动、静脉吻合 | 小动脉与小静脉直接相连 | 指尖、趾端、鼻、唇、外耳皮肤、生殖器勃起组织 | 缩短循环途径，调节局部血流量和体温 |
| 侧支吻合 | 侧副管平行主干并互吻 | 主干阻塞后建立侧支循环 | 病理状态下保证供血 |

:::

体内少数器官的动脉与相邻动脉无吻合，称**终动脉**，如视网膜中央动脉。终动脉阻塞可导致供血区缺血甚至坏死。若虽有吻合，但阻塞后邻近动脉不足以代偿，称**功能性终动脉**，如脑、肾和脾内的部分动脉分支。

:::definition{label="终动脉与功能性终动脉"}
终动脉：与相邻动脉无吻合，本版例子是**视网膜中央动脉**。功能性终动脉：有吻合但代偿不足，本版点名**脑、肾、脾**内的部分分支。两户不要并成「都叫终动脉」。
:::

:::pitfall{label="不要把侧支循环听成平时就一样粗"}
正常状态下侧副管比较细小；主干阻塞后才逐渐增粗。写成「侧支一直可以完全代替主干」，代偿的限度和建立时间都被抹掉。
:::

## 二、心

### （一）心的位置、外形和毗邻

心是中空的肌性纤维性器官，形似倒置、前后稍扁的圆锥体，周围裹以心包，斜位于胸腔的中纵隔内。国人成年男性正常心重约（284±50）g，女性约（258±49）g，可因年龄、身高、体重和体力活动而有差异。心约 **2/3 位于正中线的左侧**，1/3 位于正中线的右侧。前方对向胸骨体和第 2～6 肋软骨；后方平对第 5～8 胸椎；两侧邻胸膜腔和肺；上方连接出入心的大血管；下方邻膈。心的长轴自右肩斜向左肋下区，与身体正中线成 45° 角。心底部被大血管根部和心包反折固定，心室部分活动度较大。

:::definition{label="心的位置"}
胸腔**中纵隔**内。约 **2/3 在正中线左侧**，1/3 在右侧。前方胸骨体和第 2～6 肋软骨，后方第 5～8 胸椎，两侧肺，上连大血管，下邻膈。不要写成「全在左边」或「正中对称」。
:::

::figure{src="/images/anatomy/textbook/p0205_01.png" caption="图7-3　心的位置" alt="打开胸前壁：心包包裹心脏居中纵隔，约三分之二偏左；可见升主动脉、主动脉弓、头臂干、左颈总动脉、左锁骨下动脉、上腔静脉、肺动脉干、前室间沟和心尖"}

心可分为一尖、一底、两面、三缘，表面尚有 4 条沟。

**心尖（cardiac apex）**　圆钝、游离，由左心室构成，朝向左前下方，贴近左胸前壁。在左侧第 5 肋间隙、锁骨中线内侧 1～2 cm 处可触及心尖搏动。

**心底（cardiac base）**　朝向右后上方，主要由左心房和小部分右心房构成。上、下腔静脉从上、下注入右心房；左、右肺静脉从两侧注入左心房。心底后面隔心包壁与食管、迷走神经和胸主动脉相邻。

:::definition{label="心尖"}
由**左心室**构成，朝左前下。体表：左侧第 **5** 肋间隙，锁骨中线内侧 **1～2 cm**。不是右心室，也不是第 4 肋间隙。
:::

:::definition{label="心底"}
朝右后上，主体是**左心房**，小部分右心房。上、下腔静脉进右房，肺静脉进左房。后面隔心包邻食管、迷走神经和胸主动脉。
:::

:::pitfall{label="心底不是心尖的反面那么简单"}
心尖朝左前下、心底朝右后上，长轴是斜的。写成「心底就是后面那头、心尖就是前面那头」，大血管开口和食管毗邻都会对错方向。
:::

::figure{src="/images/anatomy/textbook/p0205_02.png" caption="图7-4　心的外形和血管（前面观）" alt="胸肋面：右心耳、右冠状动脉、右缘支、心前静脉、左心耳、左冠状动脉、旋支、前室间支、心大静脉、心尖切迹；肺动脉干以动脉韧带连于主动脉弓"}

::figure{src="/images/anatomy/textbook/p0206_01.png" caption="图7-5　心的外形和血管（后下面观）" alt="膈面：左、右肺静脉注入左心房，下腔静脉注入右心房，冠状窦走在冠状沟，心中静脉伴后室间支，心小静脉注入冠状窦右端"}

**胸肋面（前面）**　朝向前上方，大部分由右心房和右心室构成，一小部分由左心耳和左心室构成。该面大部分隔心包被胸膜和肺遮盖；小部分隔心包与胸骨体下部和左侧第 4～6 肋软骨邻近，故在左侧第 4 肋间隙靠近胸骨左缘作心内注射，一般不会伤及胸膜和肺。胸肋面上部可见起于右心室的肺动脉干行向左上，起于左心室的升主动脉在肺动脉干后方行向右上。

**膈面（下面）**　几呈水平位，朝下并略朝后，隔心包与膈毗邻，大部分由左心室构成，一小部分由右心室构成。

**下缘（锐缘）**　介于膈面与胸肋面之间，接近水平，由右心室和心尖构成。**左缘（钝缘）**　绝大部分由左心室构成，上方一小部分有左心耳。**右缘**由右心房构成。左、右缘形态圆钝，隔心包分别与左、右膈神经和心包膈血管以及纵隔胸膜、肺相邻。

心表面 4 条沟是四个心腔的表面分界。**冠状沟**（房室沟）几乎呈额状位，近似环形，前方被肺动脉干中断，是右上方心房与左下方心室的表面分界。**前室间沟**和**后室间沟**分别在心室的胸肋面和膈面，从冠状沟走向心尖右侧，与室间隔前、下缘一致，是左、右心室在心表面的分界。前、后室间沟在心尖右侧会合处稍凹陷，称**心尖切迹**。冠状沟和前、后室间沟内被冠状血管和脂肪填充，轮廓常不清。心底、右心房与右上、下肺静脉交界处的浅沟称**后房间沟**，与房间隔后缘一致，是左、右心房的表面分界。后房间沟、后室间沟与冠状沟的相交处称**房室交点（crux）**，是心表面重要标志：左、右心房与左、右心室在心后面互相接近，深面有重要血管和神经。此处冠状沟左侧高于右侧，后房间沟偏右、后室间沟偏左，故房室交点不是一个十字交叉点，而应视为一个区域。

:::compare{title="一尖一底两面三缘四沟"}
| | 朝向 / 构成 | 不要写成 |
|--|-------------|----------|
| 心尖 | 左前下；左心室 | 右心室；第 4 肋间隙 |
| 心底 | 右后上；左心房为主 | 「心底=右心房」 |
| 胸肋面 | 右房 + 右室为主 | 「前面全是左心」 |
| 膈面 | 左室为主 | 「下面全是右室」 |
| 下缘 | 右室 + 心尖（锐缘） | 左室 |
| 左缘 | 左室为主（钝缘） | 右房 |
| 右缘 | 右心房 | 右心室 |
| 冠状沟 | 心房 / 心室表面分界 | 左、右心室分界 |
| 前、后室间沟 | 左、右心室表面分界 | 心房 / 心室分界 |
| 后房间沟 | 左、右心房表面分界 | 室间沟的别名 |
| 房室交点 | 后房间沟 + 后室间沟 + 冠状沟相交的**区域** | 一个几何十字 |

:::

:::pitfall{label="心内注射走左侧第 4 肋间隙近胸骨左缘，不是心尖搏动点"}
胸肋面小部分贴胸骨体下部和左侧第 4～6 肋软骨，这里注射一般不伤胸膜和肺。心尖搏动在第 5 肋间隙锁骨中线内侧。两处不要对调。
:::

:::keypoint{label="外形先钉这一串"}
- 约 2/3 在正中线左侧。
- 心尖：左室，第 5 肋间隙锁骨中线内侧 1～2 cm。
- 前面大部分是右心，所以心内注射多进右心室。
- 四沟分四腔；房室交点是区域，不是十字。
:::

### （二）心腔

心被心间隔分为左、右两半心，各分成左、右心房和左、右心室，同侧心房和心室借房室口相通。发育中心沿纵轴轻度向左旋转，故左半心位于右半心的左后方。

**1. 右心房（right atrium）**　位于心的右上部，壁薄腔大，分前、后两部。前部为固有心房，由原始心房衍变；后部为腔静脉窦，由原始静脉窦右角发育。两者以纵行于右心房表面的**界沟**为界；腔面与界沟相对的纵行肌隆起为**界嵴**。

固有心房内面有大致平行的**梳状肌**，起自界嵴，止于右房室口。心耳处肌束交错成网，心功能障碍时血流更缓慢，易淤积成血栓。腔静脉窦内壁光滑，有上腔静脉口、下腔静脉口和冠状窦口。上腔静脉与右心耳交界处、界沟上 1/3 的心外膜下有窦房结，手术剥离上腔静脉根部时要避开。下腔静脉口前缘有下腔静脉瓣（Eustachian 瓣）。冠状窦口位于下腔静脉口与右房室口之间，相当于房室交点区深面，后缘常有冠状窦瓣（Thebesian 瓣，出现率约 70%）。右心房许多部位可见直径小于 0.5 mm 的小孔，为心最小静脉开口。

房间隔右侧面中下部有**卵圆窝**，是胚胎卵圆孔闭合的遗迹，此处薄弱，是房间隔缺损的好发部位，也是从右心房进入左心房心导管穿刺的理想部位。房间隔前上部由主动脉窦向右心房凸起形成主动脉隆凸，为心导管术标志。

冠状窦口前内缘、三尖瓣隔侧尖附着缘和 Todaro 腱之间的三角区，称 **Koch 三角**。Todaro 腱是下腔静脉口前方心内膜下的腱性结构，向前经房间隔附着于右纤维三角，向后续下腔静脉瓣。Koch 三角前部心内膜深面为房室结，其尖对着膜性室间隔的房室部。右心房前下部为右房室口，血液由此流入右心室。

::figure{src="/images/anatomy/textbook/p0207_01.png" caption="图7-6　右心房内面观" alt="切开右心房：界嵴、梳状肌、卵圆窝、冠状窦口、下腔静脉瓣、Todaro 腱、Koch 三角和右房室口；上腔静脉与右心耳交界处为窦房结所在"}

:::definition{label="右心房"}
心的右上部，前为固有心房（梳状肌），后为腔静脉窦（上、下腔静脉口和冠状窦口）。界沟 / 界嵴是前后两部的分界。
:::

:::definition{label="卵圆窝"}
房间隔右侧面中下部的卵圆形凹陷，卵圆孔闭合的遗迹。最薄弱，房间隔缺损好发；也是右房进左房穿刺的理想部位。
:::

:::definition{label="Koch 三角"}
冠状窦口前内缘、三尖瓣隔侧尖附着缘和 Todaro 腱围成。前部深面是**房室结**。不要把 Koch 三角听成左心房的结构。
:::

**2. 右心室（right ventricle）**　位于右心房前下方，直接位于胸骨左缘第 4、5 肋软骨后方，胸骨旁第 4 肋间隙心内注射多注入右心室。前壁较薄，约只左心室壁厚度的 1/3，血管相对较少，通常是右心室手术的切口部位。

右心室腔被弓形肌性隆起即**室上嵴**分成后下方的流入道和前上方的流出道。

流入道又称固有心腔，从右房室口延伸至右心室尖。室壁有纵横交错的**肉柱**。基部附于室壁、尖端突入室腔的锥体形肌隆起称**乳头肌**。右心室乳头肌分前、后、隔侧三群：前乳头肌发出腱索连于三尖瓣前、后尖；后乳头肌多连于后尖；隔侧乳头肌位于室间隔右侧面。前乳头肌根部有一条肌束横过室腔至室间隔下部，称**隔缘肉柱**（节制索），构成流入道下界，有防止心室过度扩张的作用。房室束的右束支及供应前乳头肌的血管经隔缘肉柱达前乳头肌，右心室手术要防止损伤，以免右束支传导阻滞。

流入道入口为右房室口，周围有三尖瓣环。**三尖瓣**（右房室瓣）基底附于该环，游离缘垂入室腔，分前尖、后尖和隔侧尖。相邻瓣膜之间为连合，病理粘连多发生在连合处，可造成房室口狭窄。心室收缩时三尖瓣环缩小、血液推动使三尖瓣关闭，乳头肌收缩和腱索牵拉使瓣膜不致翻向心房。三尖瓣环、三尖瓣、腱索和乳头肌在结构和功能上是一个整体，称**三尖瓣复合体**。任何一部分损伤都会改变血流动力学。

流出道又称**动脉圆锥**或漏斗部，内壁光滑无肉柱，上端借肺动脉口通肺动脉干。肺动脉口周缘有肺动脉环，上附三个半月形**肺动脉瓣**，游离缘朝向肺动脉干，中点增厚为半月瓣小结。瓣与肺动脉壁之间的袋状间隙称肺动脉窦。心室收缩时血液冲开肺动脉瓣；舒张时肺动脉窦被倒流血液充盈，三个瓣互相靠拢，阻止血液反流入右心室。

::figure{src="/images/anatomy/textbook/p0208_01.png" caption="图7-7　右心室内部结构" alt="切开右心室：三尖瓣前尖、后尖、隔侧尖，前乳头肌，隔缘肉柱，肉柱，动脉圆锥处的肺动脉瓣；肺动脉干以动脉韧带连主动脉弓"}

:::definition{label="三尖瓣复合体"}
三尖瓣环、三尖瓣、腱索和乳头肌四件一套。共同保证单向流动，缺一件就会反流或狭窄。
:::

:::definition{label="隔缘肉柱"}
前乳头肌根部连至室间隔下部的肌束，又称节制索。右束支走这里。损伤它，右束支传导阻滞。
:::

:::pitfall{label="右心室手术不要当成只切肉柱"}
前壁薄、血管少，是常用切口；隔缘肉柱里走右束支。只记得「右室壁薄好切」，传导阻滞这一笔会漏。
:::

**3. 左心房（left atrium）**　位于右心房左后方，构成心底的大部，是四个心腔中最靠后的腔。前方有升主动脉和肺动脉，后方邻食管。亦分前部的左心耳和后部的左心房窦。

左心耳较右心耳狭长，突向左前方，覆盖肺动脉干根部左侧及左冠状沟前部，因邻近二尖瓣，是心外科常用入路之一。内壁有梳状肌，但不如右心耳发达。左心房窦腔面光滑，后壁两侧各有一对肺静脉开口，开口处无静脉瓣，但心房肌可围绕肺静脉延伸 1～2 cm，具括约肌样作用。前下部借左房室口通左心室。

**4. 左心室（left ventricle）**　位于右心室左后方，呈圆锥形。左心室壁厚度约是右心室的 3 倍。心壁肌肉最薄处在心尖。左心室腔以二尖瓣前尖为界，分为左后方的流入道和右前方的流出道。室壁与乳头肌之间常有游离的细索状**左心室条索**（假腱索），多含 Purkinje 纤维。

流入道入口为左房室口，周围为二尖瓣环。**二尖瓣**（左房室瓣）分前尖和后尖：前尖呈半卵圆形，介于左房室口与主动脉口之间；后尖略似长条形。前外侧连合和后内侧连合处前、后尖融合。二尖瓣环、二尖瓣、腱索和乳头肌合称**二尖瓣复合体**。左心室乳头肌较粗大，分前、后两组，排列几乎与左心室壁平行，收缩时对腱索产生垂直牵拉力，使二尖瓣有效闭合，并限制瓣尖翻向心房。

流出道又称**主动脉前庭**，由室间隔上部和二尖瓣前尖围成，室壁光滑，缺乏伸展性和收缩性。上界为主动脉口，位于左房室口的右前方，纤维环上附三个半月形**主动脉瓣**，按方位分为左、右、后半月瓣。每个瓣相对的主动脉壁向外膨出，形成**主动脉窦**：主动脉右窦、左窦和后窦。冠状动脉口一般位于窦内、主动脉瓣游离缘以上。心室收缩、主动脉瓣开放时，瓣膜未贴附窦壁，进入窦内的血液形成小涡流，既利于射血后瓣立即关闭，又保证收缩期和舒张期都有足够血液流入冠状动脉。

::figure{src="/images/anatomy/textbook/p0209_01.png" caption="图7-8　心瓣膜和纤维环（上面观）" alt="心底上面观：肺动脉瓣环三个半月瓣，主动脉瓣环三个半月瓣及左、右冠状动脉口，二尖瓣前尖后尖与前外侧、后内侧连合，三尖瓣前尖后尖隔侧尖，左、右纤维三角"}

::figure{src="/images/anatomy/textbook/p0209_02.png" caption="图7-9　左心房和左心室" alt="切开左心：左心房、二尖瓣前尖、前乳头肌和后乳头肌、腱索、主动脉前庭、主动脉右半月瓣、室间隔；可见右冠状动脉口"}

:::definition{label="二尖瓣复合体"}
二尖瓣环、二尖瓣、腱索和乳头肌。前尖夹在左房室口与主动脉口之间，既管流入道，也构成流出道后外侧壁。
:::

:::definition{label="主动脉窦"}
半月瓣与主动脉壁之间的袋状间隙，分右窦、左窦、后窦。左、右冠状动脉分别起于左窦、右窦。后窦不发冠状动脉，故也称无冠窦。
:::

|----|----------|------|------|----|
| 右心房 | 右上；固有心房 + 腔静脉窦 | 上、下腔静脉，冠状窦 | 右房室口 | 三尖瓣 |

| 左心房 | 最靠后；构成心底大部 | 两对肺静脉（无瓣） | 左房室口 | 二尖瓣 |
| 左心室 | 壁厚约右室 3 倍；流入道 + 主动脉前庭 | 左房室口 | 主动脉口 | 主动脉瓣 |

左半心在右半心的左后方。前面看到的大半是右心。
:::

| | 尖瓣（房室瓣） | 半月瓣（动脉瓣） |
|--|----------------|------------------|
| 右 | 三尖瓣：前、后、隔侧尖 | 肺动脉瓣 |
| 左 | 二尖瓣：前、后尖 | 主动脉瓣：左、右、后 |

:::

:::pitfall{label="肺静脉口没有瓣，不要写成「四条肺静脉都有静脉瓣」"}
开口处无静脉瓣。心房肌包绕肺静脉根 1～2 cm，起括约样作用。把肺静脉口当成腔静脉口那样有瓣，反流机制会说错。
:::

:::insight{label="主动脉窦的涡流既关瓣，也养心肌"}
瓣开放时并不贴死窦壁，窦内涡流让瓣在射血后马上靠拢，又让冠状动脉口在收缩期也不至于被瓣贴住。写成「只有舒张期才有冠脉血流」，窦这一笔就浪费了。
:::

### （三）心的构造

**1. 心纤维性支架**　又称心纤维骨骼，位于房室口、肺动脉口和主动脉口周围，由致密结缔组织构成。质地坚韧而富有弹性，为心肌纤维和心瓣膜提供附着处。随年龄可钙化甚至骨化。包括左、右纤维三角，四个瓣纤维环（肺动脉瓣环、主动脉瓣环、二尖瓣环、三尖瓣环），圆锥韧带，室间隔膜部和瓣膜间隔等。

**右纤维三角**位于二尖瓣环、三尖瓣环和主动脉后瓣环之间，又称**中心纤维体**。向前移行为室间隔膜部；后面有时发出 Todaro 腱。房室束穿过右纤维三角的右上面，在室间隔膜部和肌部交界处离开。**左纤维三角**位于主动脉左瓣环与二尖瓣环之间，外侧邻近左冠状动脉旋支，是二尖瓣手术的重要标志，也是易于损伤冠状动脉的部位。肺动脉瓣环位置较高，借圆锥韧带（漏斗腱）与主动脉瓣环相连。

::figure{src="/images/anatomy/textbook/p0211_01.png" caption="图7-10　心纤维支架模式图" alt="四个瓣环与左、右纤维三角：肺动脉瓣环经圆锥韧带连主动脉瓣环，右纤维三角即中心纤维体连 Todaro 腱和室间隔膜部，二尖瓣环与三尖瓣环分列左右"}

:::definition{label="中心纤维体"}
右纤维三角的别名，位于二尖瓣环、三尖瓣环和主动脉后瓣环之间。房室结、房室束与它贴得很近。
:::

**2. 心壁**　由心内膜、心肌层和心外膜组成，分别与血管三层膜相对应。心内膜由内皮和内皮下层构成，心瓣膜即心内膜向心腔折叠而成。心肌层是主体，心房肌和心室肌都附着于纤维骨骼，被其分开而不延续，因此心房和心室不会同时收缩。心房肌较薄，浅层横行环绕左、右心房，深层为各房固有，环绕心耳、腔静脉口、肺静脉口和卵圆窝；心房肌可分泌心房钠尿肽。心室肌较厚，尤其左心室，分浅、中、深三层：浅层斜行，在心尖捻转形成心涡转入深层；中层环行。心外膜即浆膜性心包的脏层。

::figure{src="/images/anatomy/textbook/p0212_01.png" caption="图7-11　心肌层" alt="心室壁剖开示浅层、中层、深层心肌；心底可见主动脉瓣和肺动脉瓣，以及左、右肺静脉和上腔静脉开口"}

**3. 心间隔**　把心分成容纳动脉血的左半心和容纳静脉血的右半心。左、右心房之间为房间隔，左、右心室之间为室间隔，右心房与左心室之间为房室隔。

房间隔向左前方倾斜，两层心内膜中间夹心房肌和结缔组织，右侧面中下部的卵圆窝是最薄弱处。室间隔呈 45° 倾斜并螺旋扭转，中部凸向右心室、凹向左心室，分肌部和膜部。肌部占大部分，厚约 1～2 cm。膜部上界为主动脉右瓣和后瓣下缘；右侧面有三尖瓣隔侧尖附着，由此分为后上部的**房室部**（右心房与左心室之间）和前下部的**室间部**（左、右心室之间）。室间隔缺损多发生在室间部。

房室隔是房间隔与室间隔之间的过渡、重叠区域：上界为间隔上的二尖瓣环，下界为三尖瓣隔侧尖附着缘。右侧面全部属于右心房，左侧面属左心室流入道后部和流出道前部。前部有房室束通过，后端右纤维三角右侧有房室结。

::figure{src="/images/anatomy/textbook/p0212_02.png" caption="图7-12　房间隔与室间隔（右面）" alt="右心面：卵圆窝、室间隔膜部房室部、冠状窦口、三尖瓣隔侧尖、隔缘肉柱和隔侧乳头肌；主动脉右半月瓣环投影于膜部上方"}

:::definition{label="室间隔膜部"}
室间隔上部的薄区。三尖瓣隔侧尖把它切成**房室部**（后上，右房—左室）和**室间部**（前下，左室—右室）。室间隔缺损多在室间部。
:::

:::pitfall{label="膜部缺损不要一律写成「房间隔缺损」"}
卵圆窝薄弱是房间隔缺损好发处。室间隔缺损好发在膜部室间部。两户隔、两个好发点，不要并成「间隔缺损就是卵圆窝」。
:::

:::compare{title="三隔（谁隔开谁）"}
| 隔 | 两侧 | 本版要点 |
|----|------|----------|
| 房间隔 | 左心房 / 右心房 | 卵圆窝最薄 |
| 室间隔 | 左心室 / 右心室 | 肌部 + 膜部；缺损多在膜部室间部 |
| 房室隔 | 右心房 / 左心室 | 过渡重叠区；深面有房室结和房室束 |

:::

### （四）心传导系

心肌细胞分普通心肌细胞和特殊心肌细胞。前者主要收缩；后者有自律性和传导性，产生并传导兴奋。心传导系由特殊心肌细胞构成，包括：窦房结、结间束、房室交界区、房室束、左束支、右束支和 Purkinje 纤维网。

**窦房结**是心的正常起搏点，多呈长梭形或半月形，位于上腔静脉与右心房交界处界沟上 1/3 的心外膜深面，长轴与界沟基本平行，肉眼不易辨认。结内恒定有窦房结动脉穿过中央。结内主要有起搏细胞（P 细胞）和过渡细胞（T 细胞）。

结间束的形态学证据迄今仍不充分。本版仍列 3 条：前结间束（分出上房间束即 Bachmann 束至左心房，另一束经卵圆窝前方至房室结上缘）；中结间束（Wenckebach 束）；后结间束（Thorel 束，走界嵴）。

**房室交界区**位于房室隔内，范围基本与 Koch 三角一致，由房室结、房室结心房扩展部和房室束近侧部组成。房室结是中央部分，位于 Koch 三角尖端，前端变细穿入右纤维三角形成房室束。房室交界区把来自窦房结的兴奋延搁下传，使心房和心室按顺序分开收缩，是兴奋入室的必经之路，也是最重要的次级起搏点。

**房室束**（His 束）起自房室结前端，穿右纤维三角，沿室间隔膜部后下缘前行，分为左、右束支。瓣膜置换等手术要避开这条毗邻。左束支在室间隔左侧心内膜下分为前组、后组和间隔组，吻合成 Purkinje 纤维网。右束支经过右心室圆锥乳头肌后方，进入隔缘肉柱达前乳头肌根部；主干圆索状且较长，分支晚，易受局部病灶影响而发生传导阻滞。心内膜下 Purkinje 纤维网主要分布在室间隔中下部、心尖、乳头肌下部和游离室壁下部；室间隔上部、动脉口和房室口附近则稀少或没有。

异常传导束或纤维可使心房兴奋过早传到心室某部，与预激综合征有关。

::figure{src="/images/anatomy/textbook/p0214_02.png" caption="图7-16　心传导系模式图" alt="窦房结发出前、中、后结间束至房室结，房室束分为左、右束支，右束支走隔缘肉柱，末梢成 Purkinje 纤维网；并标出上房间束及异常的 Kent 束、Mahaim 纤维、James 旁路"}

:::definition{label="窦房结"}
正常起搏点。位置钉死：上腔静脉与右心房交界、**界沟上 1/3 的心外膜深面**。不是心内膜下，也不在 Koch 三角。
:::

:::definition{label="房室交界区"}
房室隔内、与 Koch 三角基本一致。三部：房室结、心房扩展部、房室束近侧部。职责是延搁下传，让心房先收缩、心室后收缩。
:::

:::compare{title="传导系的座位（不要把结放错层）"}
| 结构 | 本版位置 | 易错 |
|------|----------|------|
| 窦房结 | 界沟上 1/3，心外膜深面 | 写成心内膜下或 Koch 三角 |
| 房室结 | Koch 三角尖端，心内膜深面 | 写成界沟 |
| 房室束 | 穿右纤维三角，走膜部后下缘 | 当成可以随便切开的肌束 |
| 右束支 | 隔缘肉柱 → 前乳头肌 | 当成走左室面 |
| 左束支 | 室间隔左侧心内膜下，分前、后、间隔组 | 当成一条圆索 |

:::

:::pitfall{label="窦房结在心外膜下，房室结在心内膜下"}
剥离上腔静脉根部伤窦房结；Koch 三角前部深面是房室结。两结的深浅和邻居写反，手术避开的方向就反。
:::

:::keypoint{label="传导系走这一条链"}
窦房结 → 结间束 → 房室交界区（延搁）→ His 束 → 左、右束支 → Purkinje 网 → 心室肌。右束支又细又长还走隔缘肉柱，所以更容易单独阻滞。
:::

### （五）心的血管

心的血液供应来自左、右冠状动脉。回流的静脉血绝大部分经冠状窦汇入右心房，一部分直接流入右心房，极少部分流入左心房和左、右心室。心本身的循环称冠状循环。心约占体重 0.5%，冠脉血流量却占心输出量的 4%～5%。

:::definition{label="左、右冠状动脉"}
心的动脉。左冠状动脉起于主动脉左窦，主干约 5～10 mm，分为前室间支和旋支。右冠状动脉起于主动脉右窦，沿冠状沟到房室交点，多发后室间支和房室结支。不要写成「冠状动脉从肺动脉干发出」。
:::

**1. 左冠状动脉**　起于主动脉左窦，主干很短，约 5～10 mm，行于左心耳与肺动脉干之间，分为前室间支和旋支。分叉处常发出对角支，分布于左心室前壁。

前室间支（前降支）沿前室间沟下行，末梢多数绕心尖切迹至后室间沟下 1/3，可与后室间支吻合。分布于左心室前壁、前乳头肌、心尖、右心室前壁一小部分、室间隔前 2/3，以及右束支和左束支前半。主要分支：左室前支、右室前支（第 1 支常为左圆锥支，与右圆锥支吻合成 Vieussens 环）、室间隔前支（12～17 支，供室间隔前 2/3）。

旋支走左侧冠状沟，绕心左缘至左心室膈面。分布于左心房、左心室前壁一小部分、侧壁、后壁一部分或大部分，约 40% 的人发出窦房结支。主要分支：左缘支、左室后支、窦房结支（约 40%）、心房支、左房旋支。

**2. 右冠状动脉**　起于主动脉右窦，行于右心耳与肺动脉干之间，沿冠状沟右行，绕心锐缘至膈面，在房室交点附近分为后室间支和右旋支。一般分布于右心房、右心室前壁大部分、侧壁和后壁全部，以及左心室后壁一部分和室间隔后 1/3，包括左束支后半、房室结和窦房结。

主要分支：窦房结支（约 60% 起于右冠状动脉起始 1～2 cm 内）；右缘支（粗大恒定，造影时可作为心缘标志）；后室间支（约 94% 起于右冠状动脉，发 7～12 支室间隔后支供室间隔后 1/3）；右旋支；右房支；房室结支（约 93% 起于右冠状动脉，多起自房室交点处倒 U 形弯曲的顶端，该 U 形弯曲出现率约 69%，是右冠状动脉造影的辨认标志）。

按 Schlesinger 分型，以后室间沟为标准，国人冠状动脉分布分为三型。

::figure{src="/images/anatomy/textbook/p0217_01.png" caption="图7-18　冠状动脉的分布类型（后面观）" alt="后面观三型：右优势型后室间支来自右冠状动脉并越过交点；均衡型左、右互不越过房室交点；左优势型旋支越过交点至右心室膈面"}

:::compare{title="左、右冠状动脉（主干和供区）"}
| | 左冠状动脉 | 右冠状动脉 |
|--|------------|------------|
| 起点 | 主动脉左窦 | 主动脉右窦 |
| 主干 | 5～10 mm，分为前室间支和旋支 | 沿冠状沟到房室交点，分为后室间支和右旋支 |
| 室间隔 | 前 2/3（前室间支的室间隔前支） | 后 1/3（后室间支的室间隔后支） |

前室间支管前壁和心尖，旋支管左缘和膈面外侧，右冠状动脉管右缘和膈面后室间沟一带。
:::

:::compare{title="冠状动脉分布类型（本版国人数字）"}

|----|--------|------------|----------|

左优势型少，但左主干或旋支加前室间支同时受累时，梗死范围大，传导系也可全被波及。另：分型看的是心外膜下走行，左心室壁厚、负荷重，左冠状动脉管径大、分支多，是生理上的优势动脉。
:::

冠状动脉主干及主要分支大部分走行于心外膜下。有时一段被浅层心肌（心肌桥）掩盖，称**壁冠状动脉**，好发于前、后室间支。一般认为局部应力较小，较少硬化；手术时须注意其存在。

**3. 心的静脉**　浅静脉大部分由冠状窦收集汇入右心房；深静脉多直接汇入心腔，以右心房居多。

**冠状窦**位于心膈面、左心房与左心室之间的冠状沟内，以左房斜静脉与心大静脉汇合处为起点，注入右心房的冠状窦口。主要属支：心大静脉（伴前室间支上行，绕心左缘续为冠状窦，收左室前面等）；心中静脉（伴后室间支，注入冠状窦末端）；心小静脉（伴右冠状动脉，注入冠状窦右端或心中静脉）。**心前静脉**起于右心室前壁，越过冠状沟直接注入右心房。**心最小静脉**（Thebesius 静脉）位于心壁内，直接开口于心房或心室腔，无瓣膜；冠状动脉阻塞时，可作为心肌从心腔获血的途径。

::figure{src="/images/anatomy/textbook/p0218_01.png" caption="图7-20　心的静脉模式图（前面观）" alt="前面观示心大静脉、心中静脉、心小静脉汇入冠状窦，心前静脉直接入右心房，左房斜静脉在冠状窦起点附近"}

:::definition{label="冠状窦"}
心膈面冠状沟内的静脉窦，收心大、中、小静脉等，注入右心房冠状窦口。心本身的静脉血绝大部分走这一户，不是走上腔静脉。
:::

:::compare{title="心的静脉三条出路"}
| | 走哪 | 注入 |
|--|------|------|
| 冠状窦属支 | 心大、中、小静脉等 | 冠状窦 → 右心房 |
| 心前静脉 | 右心室前壁，越冠状沟 | 直接入右心房 |
| 心最小静脉 | 心壁内，无瓣 | 直接开口于心房或心室腔 |

浅静脉在心表面吻合丰富。壁内侧副血管还包括动脉心腔血管和心肌窦状隙。
:::

:::pitfall{label="室间隔前 2/3 是前室间支，后 1/3 是后室间支"}
不要写成「左冠状动脉管整个室间隔」或「右冠状动脉管前壁」。前降支堵了，室间隔前部和左束支前半、右束支都在供区内。
:::

### （六）心的神经

心的神经包括交感神经、副交感神经和感觉神经。心内还有多种肽能神经纤维，参与复杂功能调节，形态细节见神经系统。

### （七）心包

心包是包裹心和出入心大血管根部的圆锥形纤维浆膜囊，分外层纤维心包和内层浆膜心包。

纤维心包由坚韧纤维结缔组织构成，上方包裹升主动脉、肺动脉干、上腔静脉和肺静脉的根部并与这些大血管外膜相延续，下方与膈的中心腱愈着。浆膜心包分脏、壁两层：壁层衬于纤维心包内面；脏层包于心肌表面，即心外膜。脏、壁两层在大血管根部互相移行，两层之间的潜在腔隙称**心包腔**，内含少量浆液。返折处的间隙称心包窦。

::figure{src="/images/anatomy/textbook/p0219_02.png" caption="图7-22　心包" alt="切除心脏后的心包腔：升主动脉与肺动脉干后方为心包横窦，左心房后壁、左右肺静脉与下腔静脉之间为心包斜窦"}

:::definition{label="心包"}
纤维心包 + 浆膜心包。纤维层是硬囊；浆膜层分脏、壁，脏层就是心外膜。
:::

:::definition{label="心包腔"}
浆膜心包脏、壁两层之间的潜在腔隙。不是纤维心包外面的胸膜腔。
:::

:::compare{title="三个心包窦"}
| 窦 | 位置 | 临床形态 |
|----|------|----------|
| 心包横窦 | 主动脉、肺动脉后方与上腔静脉、左心房前壁前方之间 | 直视手术可在此钳夹主动脉和肺动脉 |
| 心包斜窦 | 左心房后壁，左、右肺静脉、下腔静脉与心包后壁之间，口向下的盲囊 | 不是穿刺首选 |
| 心包前下窦 | 心包前壁与膈交角，直立时最低 | 积液常存于此；从剑突与左侧第 7 肋软骨交角穿刺较安全 |

:::

:::pitfall{label="心包穿刺的安全部位是前下窦，不是横窦"}
横窦是给阻断升主动脉和肺动脉用的手术间隙。积液最低点在前下窦。写成「从横窦抽积液」，把手术钳夹通道当成了穿刺点。
:::

### （八）心的体表投影

心外形体表投影个体差异较大，也可因体位变化。通常用四点连线法：①左上点：左侧第 2 肋软骨下缘，距胸骨侧缘约 1～2 cm；②右上点：右侧第 3 肋软骨上缘，距胸骨侧缘约 1 cm；③右下点：右侧第 7 胸肋关节处；④左下点：左侧第 5 肋间隙，距前正中线约 7～9 cm。左、右上点连线为上界；左、右下点连线为下界；右上点与右下点之间微向右凸的弧为右界；左上点与左下点之间微向左凸的弧为左界。

:::definition{label="心的体表投影（四点）"}
左上：左第 2 肋软骨下缘，距胸骨侧缘 1～2 cm。右上：右第 3 肋软骨上缘，距胸骨侧缘约 1 cm。右下：右第 7 胸肋关节。左下：左第 5 肋间隙，距前正中线 7～9 cm。

## 三、动脉

输送血液离开心的血管都称动脉。左心室发出的主动脉及分支运送动脉血；右心室发出的肺动脉干及其分支运送静脉血。入器官前称器官外动脉，入器官后称器官内动脉。肺循环的动脉本节只点到肺动脉干；细分支见呼吸系统。体循环的动脉用表把本版名单写全，不为每一条动脉单开定义。

器官外动脉配布的基本规律：人体左右对称，动脉分支也左右对称；每一大局部有 1～2 支动脉干；躯干部有壁支和脏支，壁支常保留分节状态；动脉常与静脉、神经伴行成血管神经束；行程多居屈侧、深部或骨肌筋膜形成的沟管内；常以最短距离到达器官（睾丸动脉等例外与发生有关）；容积常变的器官先在器官外成弓再入内，实质性器官常从「门」进入；管径不完全取决于器官大小，而与功能有关（肾动脉粗于肠系膜上动脉）。

::figure{src="/images/anatomy/textbook/p0220_02.png" caption="图7-24　躯干部动脉分布模式图" alt="横断面模式：腹主动脉向前发不成对脏支至肠管，向两侧发成对脏支至肾，向体壁发节段性壁支，向后发支至脊髓"}

### （一）肺循环的动脉

肺动脉干（pulmonary trunk）是心包内一条粗短的动脉干，起自右心室，在主动脉前方向左后上斜行，至主动脉弓下方分为左、右肺动脉。左肺动脉较短，分上、下支入左肺上、下叶；右肺动脉较长且粗，分上、中、下三支入右肺上、中、下叶。**动脉韧带**连于肺动脉干分叉处稍左侧至主动脉弓下缘，是胚胎动脉导管闭锁的遗迹。若出生后 6 个月尚未闭锁，称动脉导管未闭。

:::definition{label="动脉韧带"}
肺动脉干分叉处稍左侧连至主动脉弓下缘的纤维索，动脉导管的遗迹。出生后 6 个月仍不闭，就是动脉导管未闭。
:::

### （二）体循环的动脉

主动脉是体循环的动脉主干。升主动脉自左心室向右前上斜行，达右侧第 2 胸肋关节高度移行为主动脉弓，发出左、右冠状动脉。主动脉弓弯向左后，至第 4 胸椎椎体下缘移行为降主动脉；凸侧由右向左发出头臂干、左颈总动脉和左锁骨下动脉。头臂干向右上至右胸锁关节后方，分为右颈总动脉和右锁骨下动脉，有时发出甲状腺最下动脉。主动脉弓壁外膜下有压力感受器；弓下方近动脉韧带处有 2～3 个粟粒样**主动脉小球**，为化学感受器。降主动脉自第 4 胸椎下缘至第 4 腰椎下缘，在第 12 胸椎高度穿膈的主动脉裂孔，上方为胸主动脉，下方为腹主动脉；腹主动脉在第 4 腰椎下缘分为左、右髂总动脉。

:::compare{title="主动脉分段（三大分支只在弓上）"}
| 段 | 起止 | 本版分支 |
|----|------|----------|
| 升主动脉 | 左心室 → 右第 2 胸肋关节 | 左、右冠状动脉 |
| 主动脉弓 | → 第 4 胸椎下缘 | 头臂干、左颈总动脉、左锁骨下动脉（右→左） |
| 胸主动脉 | 第 4 胸椎下缘 → 膈主动脉裂孔（T12） | 壁支 + 脏支，见表 |
| 腹主动脉 | 裂孔 → 第 4 腰椎下缘 | 壁支 + 脏支，分为左、右髂总动脉 |

头臂干再分成右颈总和右锁骨下。不要给升主动脉、头臂干、左颈总各开一张定义。
:::

**1. 颈总动脉与颈外、颈内动脉**　左颈总起自主动脉弓，右颈总起自头臂干，均经胸锁关节后方沿食管、气管和喉外侧上行，至甲状软骨上缘分为颈内、颈外动脉。上段表浅，可摸到搏动。头面部大出血时，可在胸锁乳突肌前缘、平环状软骨弓侧方，向后内把该动脉压向第 6 颈椎横突。分叉处有颈动脉窦和颈动脉小球。

:::definition{label="颈动脉窦"}
颈总动脉末端与颈内动脉起始部的膨大部分，壁内是**压力感受器**。血压增高 → 心跳减慢、末梢血管扩张 → 血压下降。
:::

:::definition{label="颈动脉小球"}
扁椭圆形小体，借结缔组织连于颈总动脉分叉处后方，是**化学感受器**，感受血中二氧化碳分压、氧分压和氢离子浓度。氧分压降低或二氧化碳分压增高时，反射性使呼吸加深加快。
:::

:::pitfall{label="窦管压力，小球管化学，不要对调"}
颈动脉窦是膨大的压力感受器；颈动脉小球是分叉后方的化学感受器。写成「小球感受血压」或「窦感受缺氧」，反射方向全反。
:::

颈外动脉初居颈内动脉前内侧，后经其前方转至外侧，穿腮腺至下颌颈处分为颞浅动脉和上颌动脉两个终支。颈内动脉在颈部无分支，经颈动脉管入颅，分布于视器和脑。

| 颈总 / 颈外动脉 | 胸锁关节至耳屏稍前下；甲状软骨上缘以上为颈外，以下为颈总 | 环状软骨弓侧方，压向第 6 颈椎横突 | 头面部 |

| 肱动脉 | 上肢外展 90°，锁骨中点至肘窝中点稍下；腋后襞以下为肱动脉 | 肱二头肌内侧沟中份压向肱骨；止血带避开中份 | 压迫点以下整个上肢 |

| 指掌侧固有动脉 | 手指近掌面两侧 | 指根两侧向指骨压 | 手指 |

桡动脉在茎突内上方摸脉搏；止血还要会压锁骨下、颈总、面动脉、肱动脉、股动脉。肱动脉用止血带必须避开臂中 1/3，那是桡神经沟。
:::

## 四、静脉

静脉起于毛细血管，止于心房，向心汇集中管径逐渐增粗。与伴行动脉相比：数量多，管壁薄而柔软，管腔粗，弹性小，收缩力弱，压力低，血流缓慢。肺循环的静脉点到四条肺静脉即可。体循环静脉分上腔静脉系、下腔静脉系和心静脉系（心静脉已在心的血管中写过）。

:::compare{title="静脉配布的四条特点"}
| 特点 | 本版原句 |
|------|----------|
| 浅、深两组 | 浅静脉在浅筋膜，多不与动脉伴行，临床输液、采血、置管走这里；深静脉多与动脉伴行，名称和引流范围大体一致 |
| 吻合丰富 | 浅静脉在手足成网；深静脉环绕容积常变的脏器成丛；浅、深之间交通支多，利于侧支循环 |
| 静脉瓣 | 常成对，半月形，游离缘朝向心；四肢多，头颈和躯干少或阙如 |
| 结构特殊 | 硬脑膜窦：无平滑肌、无瓣，外伤出血不易止；板障静脉：无瓣，借导血管连头皮静脉和硬脑膜窦 |

:::

::figure{src="/images/anatomy/textbook/p0238_01.png" caption="图7-50　静脉瓣" alt="静脉纵剖：成对半月形静脉瓣，游离缘朝向血流的向心方向"}

### （一）肺循环的静脉

肺静脉每侧两条：左上、左下和右上、右下。起自肺门，穿纤维心包，注入左心房后部，输送含氧量高的血液。左上、左下肺静脉分别收集左肺上、下叶；右上肺静脉收集右肺上、中叶，右下肺静脉收集右肺下叶。开口处无静脉瓣。

### （二）体循环的静脉

**1. 上腔静脉系**　由上腔静脉及其属支组成，收集头颈部、上肢和胸部（心除外）的静脉血。

::figure{src="/images/anatomy/textbook/p0239_01.png" caption="图7-52　头颈部静脉" alt="头颈侧面浅深静脉：面静脉、下颌后静脉、颈外静脉、颈内静脉、颈前静脉和颈静脉弓，锁骨下静脉在静脉角与颈内静脉汇合"}

:::compare{title="头颈部静脉"}
| 静脉 | 合成 / 行程 | 注入 | 要点 |
|------|-------------|------|------|
| 面静脉 | 起自内眦静脉，面动脉后方下行 | 舌骨大角附近入颈内静脉 | 口角以上一般缺乏瓣膜；经眼上、下静脉和面深静脉—翼静脉丛与海绵窦交通 |
| 下颌后静脉 | 颞浅静脉 + 上颌静脉（起自翼静脉丛）在腮腺内汇合 | 前支入面静脉，后支参与颈外静脉 | 收集面侧区和颞区 |
| 颈外静脉 | 下颌后静脉后支 + 耳后静脉 + 枕静脉 | 锁骨下静脉或静脉角 | 末端有一对瓣但不能防止逆流；半卧 30°～45° 显著充盈称颈静脉怒张 |

| 锁骨下静脉 | 第 1 肋外侧缘续腋静脉 | 与颈内静脉合成头臂静脉 | 汇合部即**静脉角**；可经此插管测中心静脉压 |

:::definition{label="静脉角"}
颈内静脉与锁骨下静脉的汇合部。不要把静脉角听成上腔静脉的别名，也不要当成头臂静脉本身。
:::

:::definition{label="危险三角"}
鼻根至两侧口角的三角区。面静脉口角以上一般无瓣，并可经眼静脉、翼静脉丛通海绵窦。该区化脓性感染若挤压，细菌可至海绵窦引起颅内感染。
:::

:::pitfall{label="危险三角不是「脸上随便一块三角」"}
本版原句：鼻根至两侧口角。写成「鼻唇沟」或「整个面部」，交通途径和挤压禁忌都会说宽。

**2. 下腔静脉系**　由下腔静脉及其属支组成，收集下半身的静脉血。下肢静脉瓣膜比上肢多，浅、深交通也更丰富。

|------|------|------|------|

**3. 肝门静脉系**　由肝门静脉及其属支组成，收集腹腔内除肝以外的不成对脏器（含食管腹段）及盆腔消化道（齿状线以下肛管除外）的静脉血。起始端和末端都与毛细血管相连，且无静脉瓣。

肝门静脉多由肠系膜上静脉和脾静脉在胰颈后面汇合，经胰颈与下腔静脉之间进入肝十二指肠韧带，在肝固有动脉和胆总管后方上行至肝门，分为两支入肝左、右叶，最终注入肝血窦。

::figure{src="/images/anatomy/textbook/p0245_01.png" caption="图7-62　肝门静脉及其属支" alt="腹腔不成对脏器静脉：肠系膜上静脉与脾静脉在胰颈后方合成肝门静脉，肠系膜下静脉、胃左静脉、胃右静脉、胆囊静脉汇入这一系"}

:::definition{label="肝门静脉"}
多由**肠系膜上静脉 + 脾静脉**在胰颈后面合成。两端都是毛细血管，无瓣。收集腹腔不成对脏器（肝除外）及齿状线以上消化道的静脉血，送进肝血窦。
:::

:::insight{label="门静脉无瓣，所以堵了只能往吻合口倒"}
两端都是毛细血管，中间没有瓣。肝门一堵，血就顺着食管、脐周、直肠、椎丛四条路找上、下腔静脉。四条路的曲张表现不一样，不要都写成「消化道出血」。
:::

:::pitfall{label="齿状线以下肛管不进肝门静脉系"}
本版原句：盆腔消化道（齿状线以下肛管除外）。齿状线以下走髂内静脉系的肛静脉。写成「整个直肠肛管都进门静脉」，表 7-3 的直肠静脉丛就会少算下腔这一侧。
:::

### （三）全身静脉回流概况

表 7-4 把肺静脉、心静脉系、上腔静脉系、下腔静脉系和肝门静脉系收到同一张回流图上。名单按本节各表收全。

:::compare{title="表7-4　全身静脉回流概况"}
| 静脉系 | 主干 | 本版收集范围 | 注入 |
|--------|------|--------------|------|
| 肺循环静脉 | 左上、左下、右上、右下肺静脉 | 肺泡毛细血管（含氧血）；右上还收右肺中叶 | 左心房后部 |
| 心静脉系 | 冠状窦（心大、中、小静脉）；心前静脉；心最小静脉 | 心壁绝大部分；心前静脉走右室前壁；心最小静脉走心壁内 | 冠状窦口 → 右心房；后两户可直接入心腔 |
| 上腔静脉系 | 上腔静脉（左、右头臂静脉合成，收奇静脉） | 头颈、上肢、胸部（心除外）；奇静脉沟通下腔 | 右心房（平第 3 胸肋关节下缘） |
| 下腔静脉系 | 下腔静脉（左、右髂总静脉合成） | 下肢、盆部、腹部成对脏器和腹后壁；肝静脉在腔静脉沟注入 | 右心房 |
| 肝门静脉系 | 肝门静脉（肠系膜上静脉 + 脾静脉） | 腹腔不成对脏器（肝除外，含食管腹段）及齿状线以上消化道 | 肝血窦 → 肝静脉 → 下腔静脉 |

体循环静脉血最终都进右心房：心走冠状窦，上半身走上腔，下半身走下腔；腹腔不成对脏器先过门静脉和肝，再进下腔。肺静脉是唯一把含氧血送进左心房的静脉干。
:::

:::keypoint{label="静脉回流先问三系再问一门"}
- 心：冠状窦。
- 膈以上（心除外）：上腔静脉。
- 膈以下：下腔静脉。
- 腹腔不成对脏器：先肝门静脉，后肝静脉。

四条门腔吻合是高压时的侧支，不是平时的主干。
:::
