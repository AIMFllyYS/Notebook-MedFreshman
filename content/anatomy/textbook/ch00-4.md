# 四、 人体的组成与器官系统

第一节把学习对象钉成正常人体的形态结构及其发生发展。第二节按功能系统叙述的系统解剖学，需要一张「人体由什么组成」的总表。本节从细胞起笔：细胞是构成人体的基本单位；细胞与细胞间质构成组织；四大基本组织结合成器官；器官按功能组成 **9 大系统**。九个名字与第二节系统解剖学的举例名单一致，不要漏系统，也不要自造第十个。解剖学姿势、方位术语、轴和面是第五节的语法，本节不写完。

细胞是构成人体的基本单位，细胞与细胞间质共同构成组织。人体的基本组织包括上皮组织、结缔组织、肌肉组织和神经组织。几种组织相互结合，组成器官。人体的诸多器官按功能的不同，分别组成 9 大系统。

:::note{label="本节无教学插图"}
组成与器官系统在本版绪论中无教学插图。全身骨骼等图从第一章才出现。方位术语图绪图-1、绪图-2 属于第五节。
:::

:::concept{term="先问层次在哪一级，再问它被哪个系统收编"}
看见一个名词，先放在四层尺子上：细胞 → 组织（细胞+细胞间质）→ 器官（几种组织结合）→ 系统（按功能归组的器官）。再问它落在 9 大系统的哪一户。把「肝组织」「神经系统」「上皮」当成同一级，层次账会做乱；把免疫再加成第十系统，九户名单会对不上。
:::

## 一、细胞、细胞间质、组织、器官

:::definition{label="细胞"}
细胞是构成人体的基本单位。没有细胞，就没有组织和器官。组织学把同一句话写成「人体结构和功能的基本单位」；本版解剖学先强调「构成」——形态学从这里起层。
:::

:::definition{label="细胞间质"}
细胞与细胞间质共同构成组织。细胞间质是细胞之间的非细胞成分，与细胞一起才成为组织。不要把组织听成「一堆细胞」，把间质当成可有可无的空隙。
:::

:::definition{label="组织"}
组织由细胞与细胞间质共同构成。它是介于细胞和器官之间的层次：还不是器官，但已经是构成器官的基本材料。
:::

:::definition{label="器官"}
几种组织相互结合，组成器官。器官执行比单一组织更完整的功能，并在 9 大系统中找到自己的功能归属。
:::

:::compare{title="细胞 → 组织 → 器官 → 系统"}
| 层次 | 本版原句 | 组成 | 下一层如何收编 |
|------|----------|------|----------------|
| 细胞 | 构成人体的基本单位 | 基本单位本身 | 与细胞间质一起构成组织 |
| 组织 | 细胞与细胞间质共同构成 | 四大基本组织 | 几种组织相互结合组成器官 |
| 器官 | 几种组织相互结合 | 如骨、胃、肺、肾、心 | 按功能分别组成 9 大系统 |
| 系统 | 诸多器官按功能不同组成 | 9 大系统 | 在神经系统等调控下协调统一 |

缺任何一层，后文「肺是器官还是系统」「骨骼肌是组织还是器官」都会吵起来。
:::

:::pitfall{label="细胞间质不要写成第五种基本组织"}
基本组织只有四种：上皮、结缔、肌肉、神经。细胞间质是构成组织的成分，尤其在结缔组织里分量很重，但它不是与四大组织并列的第五户。
:::

:::insight{label="「基本单位」和「基本组织」不是同一级"}
细胞是构成人体的基本单位——层级在最底。基本组织是四种组织类型——层级在细胞之上、器官之下。单位说的是「最小构成者」，基本组织说的是「材料的四类」。
:::

:::keypoint{label="组成层次四句话"}
- 细胞：基本单位。
- 细胞 + 细胞间质 → 组织。
- 几种组织结合 → 器官。
- 器官按功能 → 9 大系统。
:::

## 二、四大基本组织

人体的基本组织包括上皮组织、结缔组织、肌肉组织和神经组织。名单是四个，顺序按本版：上皮、结缔、肌肉、神经。组织学课程会把微细结构写开；本节只把四户立在解剖学总表上。

:::definition{label="基本组织"}
上皮组织、结缔组织、肌肉组织和神经组织。器官由这几种组织相互结合而成，没有第五种并列的「基本组织」。
:::

:::definition{label="上皮组织"}
被覆于体表、衬于管腔面或构成腺的组织。在消化管黏膜、呼吸道黏膜、血管内膜、浆膜和腺体中反复出现。器官的「面」和「分泌部」常常是上皮。
:::

:::definition{label="结缔组织"}
细胞分散、细胞间质丰富的一类基本组织，包括固有结缔组织、软骨、骨和血液等。骨作为器官以骨组织为主体，但骨组织本身属于结缔组织范畴——第一章会落到器官层面，本节先承认结缔组织是四户之一。
:::

:::definition{label="肌肉组织"}
以肌细胞为主、司收缩的基本组织。本版用「肌肉组织」这一名称（组织学常称肌组织）。骨骼肌、心肌、平滑肌是其类型；运动系统里作为器官出现的是骨骼肌。
:::

:::definition{label="神经组织"}
由神经元和胶质细胞等构成、司感受刺激与传导冲动的基本组织。神经系统作为 9 大系统之一，是神经组织在器官和系统层面的收编，二者不要并成一词。
:::

:::compare{title="四大基本组织"}
| | 本版名称 | 在器官里常干什么 | 不要听成 |
|--|----------|------------------|----------|
| 上皮组织 | 上皮组织 | 被覆、衬里、构成腺 | 「只有皮肤」 |
| 结缔组织 | 结缔组织 | 连接、支持、营养、保护；骨、软骨、血液也在这一类 | 「软组织的别名」；「骨另立为第五种基本组织」 |
| 肌肉组织 | 肌肉组织 | 收缩 | 「等于运动系统」 |
| 神经组织 | 神经组织 | 感受与传导 | 「等于神经系统」 |

组织是材料，系统是功能编组。骨骼肌组织 ≠ 运动系统；神经组织 ≠ 神经系统。
:::

:::pitfall{label="肌肉组织不要写成运动系统，神经组织不要写成神经系统"}
运动系统由骨、骨连结和骨骼肌组成——那是器官组合。神经系统由中枢和周围组成——也是器官组合。肌肉组织、神经组织是四种基本组织里的两户，可以出现在许多器官里（血管壁有平滑肌，腺体有神经支配）。层次并户以后，9 大系统会少两户又多两个「组织」。
:::

:::pitfall{label="本版称「肌肉组织」，不要擅自改成与四大组织并列的其他叫法"}
本版四户是上皮组织、结缔组织、肌肉组织、神经组织。组胚教材常写「肌组织」。笔记可以注明异名，答题按本版「肌肉组织」。不要另加「血液组织」「淋巴组织」充当第五、第六种基本组织。
:::

:::compare{title="组织层次 vs 器官层次（几个容易并户的例子）"}
| 名词 | 在本节的层次 | 后文落点 |
|------|--------------|----------|
| 骨组织 | 结缔组织一类 | 第一章：骨是器官 |
| 骨骼肌 | 肌肉组织的一种；作为器官属于运动系统 | 第一章第三节 |
| 心肌 | 肌肉组织的一种；作为器官属于脉管系统的心 | 第七章 |
| 上皮 | 基本组织 | 消化管壁、呼吸道壁等器官的一层 |
| 神经组织 | 基本组织 | 第九章神经系统 |

问「骨是组织还是器官」：骨组织是组织，一块骨是器官。
:::

## 三、9 大系统：名单先钉死

人体的诸多器官按功能的不同，分别组成 9 大系统。本版名单与第二节系统解剖学的举例一致，也与全书章次一致：运动、消化、呼吸、泌尿、生殖、内分泌、脉管、感觉器、神经系统。

:::definition{label="9 大系统"}
器官按功能不同组成的九个系统：运动系统、消化系统、呼吸系统、泌尿系统、生殖系统、内分泌系统、脉管系统、感觉器、神经系统。是 9 个，不多不少。
:::

:::keypoint{label="九个名字按本版顺序记"}
1. 运动系统
2. 消化系统
3. 呼吸系统
4. 泌尿系统
5. 生殖系统
6. 内分泌系统
7. 脉管系统
8. 感觉器
9. 神经系统

感觉器不称「感觉系统」；脉管系统不改称「循环系统」来顶替；免疫不单列第十系统。
:::

:::pitfall{label="不要漏系统，也不要自造第 10 个"}
漏掉感觉器或把内分泌并进神经，会变成 8 个；把免疫、皮肤各自独立，会变成 10 个以上。本版皮肤的结构分散在感觉器等叙述中，淋巴系统归在脉管系统之内。名单以本节九户为准。
:::

:::pitfall{label="感觉器是九大系统之一，不要改名成感觉系统再另立一户"}
第二节举例写「感觉器和神经系统」；本节写「感觉器由感受器和附属器构成」。教材用「感觉器」当系统级户头，不用「感觉系统」。改名容易让人再加「免疫系统」凑十。
:::

:::compare{title="本节 9 大系统 vs 全书章次"}
| 本节顺序 | 系统 | 本教材章 |
|----------|------|----------|
| 1 | 运动系统 | 第一章 |
| 2 | 消化系统 | 第二章 |
| 3 | 呼吸系统 | 第三章 |
| 4 | 泌尿系统 | 第四章 |
| 5 | 生殖系统 | 第五章 |
| 6 | 内分泌系统 | 第六章 |
| 7 | 脉管系统 | 第七章 |
| 8 | 感觉器 | 第八章 |
| 9 | 神经系统 | 第九章 |

绪论总表与各论目录是同一张名单。
:::

:::note{label="系统解剖学按这九户展开"}
第二节：系统解剖学按器官功能系统阐述形态及其生长发育规律，举例正是这九户。本节补上每户的组成与功能。各论从第一章起按同一顺序写开。
:::

## 四、运动、消化、呼吸、泌尿、生殖

运动系统由骨、骨连结和骨骼肌组成，执行躯体的运动功能。消化系统由消化管和消化腺组成，主要执行消化食物、吸收营养物质和排出代谢产物的功能。呼吸系统由呼吸道和肺组成，执行气体交换功能，吸进氧气，排出二氧化碳。泌尿系统由肾、输尿管、膀胱和尿道构成，排出机体内多余的水分和溶于水的代谢产物，如尿素、尿酸等。生殖系统分为男性生殖器和女性生殖器，主要执行生殖繁衍后代的功能并具有分泌性激素的功能。

:::definition{label="运动系统"}
由骨、骨连结和骨骼肌组成，执行躯体的运动功能。第一章还要补：支持、保护、维持体姿、造血与钙磷贮存等，但绪论先把「骨 + 骨连结 + 骨骼肌 → 躯体运动」立住。
:::

:::definition{label="骨、骨连结、骨骼肌（运动系统三件）"}
骨是杠杆和支架；骨连结（含关节）是枢纽；骨骼肌是动力。缺一件，躯体运动不能完成。骨连结不要写成「只有滑膜关节」。
:::

:::definition{label="消化系统"}
由消化管和消化腺组成，主要执行消化食物、吸收营养物质和排出代谢产物的功能。管与腺两件都要，不能只记一条消化管。
:::

:::definition{label="消化管与消化腺"}
消化管是食物通过的管道；消化腺分泌消化液进入管道。肝、胰等大消化腺与管道壁内的小腺体都属消化腺一侧。代谢产物经消化系统排出的，是未被吸收的食物残渣等，不要和泌尿系统的尿素、尿酸并成同一条出路。
:::

:::definition{label="呼吸系统"}
由呼吸道和肺组成，执行气体交换功能：吸进氧气，排出二氧化碳。呼吸道是传导气体的管道，肺是气体交换的器官。
:::

:::definition{label="呼吸道与肺"}
呼吸道传导气体；肺执行气体交换。缺肺只剩管道，不能完成气体交换；缺呼吸道，肺无法与外界相通。功能原句是「吸进氧气，排出二氧化碳」。
:::

:::definition{label="泌尿系统"}
由肾、输尿管、膀胱和尿道构成，排出机体内多余的水分和溶于水的代谢产物，如尿素、尿酸等。四件器官按「生成 → 输送 → 贮存 → 排出」排列。
:::

:::definition{label="肾与尿路"}
肾生成尿；输尿管输送；膀胱贮存；尿道排出。功能强调：多余的水，以及溶于水的代谢产物（尿素、尿酸等）。固体食物残渣不走这一户。
:::

:::definition{label="生殖系统"}
分为男性生殖器和女性生殖器，主要执行生殖繁衍后代的功能，并具有分泌性激素的功能。性别分成两套器官，功能是两笔：繁衍 + 性激素。
:::

:::compare{title="前五个系统：组成与功能"}
| 系统 | 组成（本版） | 功能（本版） | 不要写成 |
|------|--------------|--------------|----------|
| 运动系统 | 骨、骨连结、骨骼肌 | 躯体的运动功能 | 「只有骨骼肌」；「骨是第五种基本组织所以不算器官」 |
| 消化系统 | 消化管、消化腺 | 消化食物、吸收营养、排出代谢产物 | 「肝不属于消化系统」；「尿素也从肛门排出」 |
| 呼吸系统 | 呼吸道、肺 | 气体交换：吸氧、排出二氧化碳 | 「只有肺」；「气体交换在呼吸道完成」 |
| 泌尿系统 | 肾、输尿管、膀胱、尿道 | 排出多余的水和溶于水的代谢产物（尿素、尿酸等） | 「只有肾」；「二氧化碳也由肾排出」 |
| 生殖系统 | 男性生殖器、女性生殖器 | 生殖繁衍；分泌性激素 | 「性激素只属于内分泌系统，生殖系统无内分泌功能」 |

五户都是「组成 + 功能」两句话，缺一不可。
:::

:::pitfall{label="消化排出的代谢产物 ≠ 泌尿排出的尿素、尿酸"}
消化系统「排出代谢产物」主要指食物残渣等经消化管末端排出；泌尿系统排出多余的水和溶于水的代谢产物（尿素、尿酸等）；呼吸系统排出二氧化碳。三条出路不要并成「废物都从肾走」或「都从消化管走」。
:::

:::pitfall{label="运动系统三件是骨、骨连结、骨骼肌，不要丢掉骨连结"}
只记骨和肌肉，关节和韧带等骨连结会从总表消失，第一章第二节就没有户头。功能是躯体运动：骨是被动部分，骨骼肌是主动部分——那是第一章的句子，本节先把三件组成记全。
:::

:::insight{label="管道系统先问「管道 + 实质性器官」"}
消化：管 + 腺；呼吸：道 + 肺；泌尿：肾 + 输尿管膀胱尿道。前两户明确是管道加工作器官；泌尿把生成器官和排出管道写成四个名字。看见中空结构，先问它属于哪一条管道系统。
:::

:::cause-effect{title="为什么这五户常被放在一起记"}
- **因** 它们直接对应躯体运动、摄取与排出、气体交换、水盐与含氮废物、种族延续
- **果** 系统解剖学把它们写成前五章；缺任何一户，人体作为活体和物种都不能维持教材所写的那些功能
:::

## 五、内分泌、脉管、感觉器、神经系统

内分泌系统由内分泌细胞、组织和器官组成，协调全身各系统的器官活动。脉管系统包括心血管系统和淋巴系统，输送血液和淋巴在体内循环流动。感觉器由感受器和附属器构成，感受机体内、外环境刺激并产生兴奋。神经系统由中枢神经系统和周围神经系统组成，调控人体全身各系统器官活动的协调和统一。

:::definition{label="内分泌系统"}
由内分泌细胞、组织和器官组成，协调全身各系统的器官活动。组成不是「只有几个内分泌腺」，而是细胞、组织、器官三个层次都可以分泌激素。功能是协调，不是传导冲动。
:::

:::definition{label="内分泌细胞、组织、器官"}
有的内分泌功能由独立的器官（腺）完成，有的由器官内的内分泌组织或散在细胞完成。写成「内分泌系统＝甲状腺+肾上腺+垂体」会把散在的内分泌细胞和组织漏掉。
:::

:::definition{label="脉管系统"}
包括心血管系统和淋巴系统，输送血液和淋巴在体内循环流动。本版户头是「脉管系统」，下设两户，不要把淋巴系统逐出脉管、也不要把脉管改名为循环系统来顶替本版术语。
:::

:::definition{label="心血管系统"}
脉管系统的一户，输送血液在体内循环流动。心是泵，动脉、毛细血管、静脉是管道。哈维在第三节提出的封闭管道，落在这一户的形态上。
:::

:::definition{label="淋巴系统"}
脉管系统的另一户，输送淋巴在体内循环流动。不单列为第 10 系统。免疫相关结构在本版不另立系统户头。
:::

:::definition{label="感觉器"}
由感受器和附属器构成，感受机体内、外环境刺激并产生兴奋。系统级名称是「感觉器」，组成是感受器 + 附属器。
:::

:::definition{label="感受器与附属器"}
感受器接受刺激并产生兴奋；附属器协助感受器完成功能（如眼的附属器）。不要把感觉器听成「只有感受器」，也不要听成「只有眼耳鼻舌」。
:::

:::definition{label="神经系统"}
由中枢神经系统和周围神经系统组成，调控人体全身各系统器官活动的协调和统一。功能是调控与统一，和内分泌的「协调」一起，把 9 大系统收成一个整体。
:::

:::definition{label="中枢神经系统与周围神经系统"}
中枢：脑和脊髓；周围：与中枢相连的神经和神经节等。本节只立两户名称；核、束、通路是第九章的内容。
:::

:::compare{title="后四个系统：组成与功能"}
| 系统 | 组成（本版） | 功能（本版） | 不要写成 |
|------|--------------|--------------|----------|
| 内分泌系统 | 内分泌细胞、组织、器官 | 协调全身各系统的器官活动 | 「只有内分泌腺」；「性激素与生殖系统无关」 |
| 脉管系统 | 心血管系统 + 淋巴系统 | 输送血液和淋巴在体内循环流动 | 「循环系统＝只有心血管」；「淋巴是第 10 系统」 |
| 感觉器 | 感受器 + 附属器 | 感受内、外环境刺激并产生兴奋 | 「感觉系统」；「只有感觉神经」 |
| 神经系统 | 中枢 + 周围 | 调控全身各系统器官活动的协调和统一 | 「等于神经组织」；「内分泌已经协调，神经可省」 |
:::

:::compare{title="内分泌与神经：都在协调，手段不同"}
| | 内分泌系统 | 神经系统 |
|--|------------|----------|
| 组成 | 细胞、组织、器官 | 中枢、周围 |
| 本版动词 | 协调 | 调控……协调和统一 |
| 作用范围 | 全身各系统的器官活动 | 全身各系统器官活动 |
| 与生殖 | 生殖系统自身也分泌性激素 | 生殖活动同样受神经调控 |

两户都对全身说话，不能互相取消。生殖系统「具有分泌性激素的功能」，并不把内分泌系统删掉。
:::

:::pitfall{label="脉管系统必须同时包含心血管和淋巴"}
只记心和血管，淋巴系统会变成无家可归的第十户。本版明确：脉管系统包括心血管系统和淋巴系统，输送血液和淋巴。血液循环和淋巴回流是同一系统里的两本账。
:::

:::pitfall{label="感觉器产生兴奋，不要写成感觉器自己完成所有感觉中枢分析"}
功能原句：感受内、外环境刺激并产生兴奋。兴奋如何传到中枢、如何形成感觉，是神经系统的事。感觉器和神经系统两户都要，不要把第八章写成第九章的附录，也不要把第九章写成「感觉器的延长」。
:::

:::insight{label="9 大系统不是九个互不往来的科室"}
脉管把血液和淋巴送到各器官；神经和内分泌协调各系统；感觉器提供内、外环境信息；运动、消化、呼吸、泌尿、生殖在被协调的前提下执行各自功能。系统解剖学按户叙述，是为了讲得清；活体上九户同时在工作。
:::

:::cause-effect{title="没有调控，九户只是一份名单"}
- **因** 各系统器官活动需要协调和统一，并需要感受内、外环境
- **果** 教材把内分泌、脉管、感觉器、神经系统写成后四户：输送、感受、协调、调控——前五户的功能才能在整体上实现
:::

## 六、九户总表与后文分界

:::compare{title="9 大系统总表（组成 / 功能）"}
| 系统 | 组成 | 功能 |
|------|------|------|
| 运动系统 | 骨、骨连结、骨骼肌 | 躯体的运动功能 |
| 消化系统 | 消化管、消化腺 | 消化食物、吸收营养物质、排出代谢产物 |
| 呼吸系统 | 呼吸道、肺 | 气体交换：吸进氧气，排出二氧化碳 |
| 泌尿系统 | 肾、输尿管、膀胱、尿道 | 排出多余的水和溶于水的代谢产物（尿素、尿酸等） |
| 生殖系统 | 男性生殖器、女性生殖器 | 生殖繁衍后代；分泌性激素 |
| 内分泌系统 | 内分泌细胞、组织、器官 | 协调全身各系统的器官活动 |
| 脉管系统 | 心血管系统、淋巴系统 | 输送血液和淋巴在体内循环流动 |
| 感觉器 | 感受器、附属器 | 感受内、外环境刺激并产生兴奋 |
| 神经系统 | 中枢神经系统、周围神经系统 | 调控全身各系统器官活动的协调和统一 |
:::

:::keypoint{label="组成与功能两列都要能默写"}
只背九个名字不够。每一户都是「由什么组成 + 执行什么功能」。运动三件、消化两件、呼吸两件、泌尿四件、生殖按性别两套、内分泌三个层次、脉管两户、感觉器两件、神经两户——这些数字是组成侧的记忆单位。
:::

:::compare{title="三条排出路径不要并户"}
| 系统 | 排出什么（本版原句） |
|------|----------------------|
| 消化系统 | 代谢产物（与消化、吸收并列的功能之一） |
| 呼吸系统 | 二氧化碳（气体交换的一侧） |
| 泌尿系统 | 多余的水分和溶于水的代谢产物，如尿素、尿酸等 |

问「人体废物从哪出」，先问是气体、含氮溶质还是消化残渣，再选系统。
:::

:::pitfall{label="不要把方位术语写进本节"}
人体各部位置关系、解剖学姿势、上/下/前/后、轴和面，属于第五小节。本节只把组成层次和 9 大系统立住。dump 阶段曾把第五节开头粘在本节文末，重写后必须切开。
:::

:::note{label="王清任、黄宽、北洋医学堂不在本节"}
