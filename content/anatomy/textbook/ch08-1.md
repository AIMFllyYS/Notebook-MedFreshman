# 第一节　视器

感觉器（sensory organ）是机体感受环境刺激的装置，是感受器（receptor）及其附属结构的总称。两个词有时混用，户头并不等同：感受器是产生兴奋的那一层，感觉器还带着附属装置。本节把「视器」这一户写完：眼球接受光波、眼副器负责保护运动。前庭蜗器是第二节，嗅器、味器和皮肤是第三节，不要提前写成一锅。

感受器接受相应刺激后转变为神经冲动，经感觉神经和中枢传导通路到大脑皮质产生感觉，再由高级中枢经运动神经传到效应器作出反应。正常状况下，感受器只对某一特异刺激敏感：视网膜的特异刺激是一定波长的光，耳蜗的特异刺激是一定频率的声波。高度特化是长期进化的结果，使机体能对内、外环境变化作出精确反应。

:::definition{label="感觉器"}
感受器**及其附属结构**的总称。视器 = 眼球（感受器）+ 眼副器；听器 = 声音感受器 + 耳的传音结构。比感受器多一截附属装置。
:::

:::definition{label="感受器"}
感受内、外环境刺激而产生兴奋的结构。可以简单到痛觉的游离神经末梢，也可以是触觉小体、环层小体这类被囊神经末梢。它是产生感觉的媒介，不是整套「器」。
:::

:::concept{term="先问这是感受器还是感觉器，再问刺激从外、从内还是从本体来"}
看见「感觉」，先切开器和感受器。器带着附属结构，感受器只负责换能。再问三类：外感受器走皮肤黏膜视听，内感受器走内脏心血管，本体感受器走肌、腱、关节、韧带和内耳位置觉。把视器听成「就是视网膜」，眼副器会从开篇丢掉。
:::

:::compare{title="感受器的两种分法（本版）"}
| 分法 | 本版户头 | 不要写成 |
|------|----------|----------|
| 按部位和刺激来源 | 外感受器、内感受器、本体感受器 | 「只有五官」 |
| 按特化程度 | 一般感受器（全身各部）；特殊感受器（头部：视觉、听觉、嗅觉、味觉、平衡觉） | 把痛、温、触也算成特殊感受器 |

:::

:::definition{label="外感受器"}
分布在皮肤、黏膜、视器和听器等处，感受外界的痛、温、触、压、光、声。
:::

:::definition{label="内感受器"}
分布在内脏器官和心血管等处，接受体内渗透压、压力、温度、离子和化合物浓度变化。
:::

:::definition{label="本体感受器"}
分布在肌、肌腱、关节、韧带和**内耳的位置觉器**等处，接受运动和平衡变化时的刺激。内耳这一笔属第二节，本节只点名、不展开壶腹嵴。
:::

:::definition{label="一般感受器与特殊感受器"}
一般感受器分布全身，如皮肤的痛、温、触、压，以及肌、腱、关节、内脏和心血管的感受器。特殊感受器分布在头部，本版五户：**视觉、听觉、嗅觉、味觉和平衡觉**（图8-1）。
:::

::figure{src="/images/anatomy/textbook/p0262_01.png" caption="图8-1　特殊感受器（味觉感受器与平衡觉感受器）" alt="左：味蕾嵌于舌上皮，味孔、味毛、感受器细胞和支持细胞，底部有神经纤维；右：膜迷路示膜壶腹、壶腹嵴、椭圆囊斑和球囊斑"}

:::pitfall{label="感受器和感觉器不要画等号"}
痛觉游离末梢是感受器，还称不上感觉器。视器、听器才是特殊感觉器。写成「人体所有感受器都叫感觉器」，附属结构这一户就空了。
:::

视器（visual organ）由眼球和眼副器共同构成。眼球接受光波刺激，转变为神经冲动，经视觉传导通路传到大脑视觉中枢，产生视觉。眼副器位于眼球周围或附近，包括眼睑、结膜、泪器、眼球外肌、眶脂体和眶筋膜，对眼球起支持、保护和运动作用。

:::definition{label="视器"}
**眼球 + 眼副器**。眼球负责感光换能；眼副器负责支持、保护和运动。缺副器，眼球在眶里既站不稳也闭不上。
:::

:::definition{label="眼副器"}
眼睑、结膜、泪器、眼球外肌、眶脂体和眶筋膜。名单六件，不要漏眶脂体和眶筋膜，也不要把视网膜算进副器。
:::

## 一、眼球

眼球（eyeball）是视器的主要部分，近似球形，位于眶内。两眼眶各呈四棱锥形，**内侧壁几乎平行，外侧壁向后相交成 90° 角。同侧眼眶内侧壁与外侧壁的夹角为 45°**（图8-2、图8-3）。眼球借筋膜与眶壁相连，后部借视神经连于间脑的视交叉。

当眼平视前方时，眼球前面正中点称前极，后面正中点称后极。前、后两极连线中点的环行线称赤道（中纬线）。自前极至后极的矢状轴称**眼轴**。经瞳孔的中央至视网膜黄斑中央凹的连线称**视轴**，眼轴与视轴呈锐角交叉。

眼球由眼球壁和眼球的内容物构成（图8-4）。

:::definition{label="眼球"}
近似球形，位于眶内。前极、后极、赤道；后部借视神经连视交叉。由眼球壁和内容物两户构成。
:::

:::definition{label="眼轴与视轴"}
眼轴：前极到后极的矢状轴。视轴：瞳孔中央到黄斑**中央凹**的连线。二者呈**锐角交叉**，不是重合，也不是直角。
:::

:::keypoint{label="眶壁夹角按本版三句话"}
- 两眶内侧壁几乎平行。
- 两眶外侧壁向后相交成 **90°**。
- 同侧内侧壁与外侧壁夹角 **45°**。

数字不要改成「眶轴 23°」或其他版的说法。
:::

### （一）眼球壁

从外向内依次分为眼球纤维膜、眼球血管膜和视网膜 3 层。

**1. 眼球纤维膜**　又称眼球外膜，由坚韧的纤维结缔组织构成，有支持和保护作用。由前向后分为角膜和巩膜两部分。

（1）角膜（cornea）：占眼球纤维膜的前 1/6，无色透明，富有弹性，无血管但富有感觉神经末梢，感觉敏锐。角膜曲度较大，外凸内凹，具有屈光作用，营养来自周围的毛细血管、泪液和房水。角膜炎或溃疡可致角膜混浊，失去透明性，影响视觉。

:::definition{label="角膜"}
纤维膜前 **1/6**。无色透明、无血管、感觉敏锐，外凸内凹，是屈光装置的第一块。营养走周围毛细血管、泪液和房水，不是「角膜自己有血管」。
:::

（2）巩膜（sclera）：占眼球纤维膜的后 5/6，乳白色不透明，厚而坚韧，保护内容物并维持眼球形态。前缘接角膜缘，后方与视神经的硬膜鞘相延续。巩膜与角膜交界处外面稍内陷，称巩膜沟。靠近角膜缘处的巩膜实质内，有环形的**巩膜静脉窦**（sinus venosus sclerae），为房水流出的通道。巩膜在视神经穿出附近最厚，向前逐渐变薄，赤道附近最薄，眼外肌附着处再度增厚。巩膜前部露于眼裂的部分正常呈乳白色，黄色常是黄疸的重要体征；老年人因脂肪沉积略呈黄色；先天性薄巩膜呈蔚蓝色。

:::definition{label="巩膜"}
纤维膜后 **5/6**。乳白不透明。视神经穿出附近最厚，赤道附近最薄，肌附着处再增厚。
:::

:::definition{label="巩膜静脉窦"}
靠近角膜缘的巩膜实质内环形管道，房水从虹膜角膜角流入此处。不是「巩膜自己的营养静脉」。
:::

:::pitfall{label="巩膜发黄先问黄疸，再问老年脂肪"}
本版原句：露于眼裂的巩膜正常乳白，黄色常是黄疸的重要体征；老年人因脂肪沉积略黄。把老年的浅黄一律写成黄疸，或把黄疸写成「结膜色素」，体征就对不上。
:::

**2. 眼球血管膜**　又称眼球中膜，富含血管和色素细胞，呈棕黑色，营养眼球内组织并遮光。由前至后分为虹膜、睫状体和脉络膜 3 部分。

（1）虹膜（iris）：呈冠状位，位于血管膜最前部，圆盘形（图8-4、图8-5），中央有圆形的瞳孔（pupil）。角膜与晶状体之间的间隙称眼房（chamber of eyeball）。虹膜将眼房分为较大的前房和较小的后房，二者借瞳孔相通。前房周边、虹膜与角膜交界处的环形区域，称虹膜角膜角，又称前房角。

虹膜内有环绕瞳孔周缘排列的瞳孔括约肌（sphincter pupillae）和呈放射状排列的瞳孔开大肌（dilator pupillae）。弱光下或视远物时瞳孔开大；强光下或看近物时瞳孔缩小，以调节进光量。活体透过角膜可见虹膜及瞳孔。虹膜颜色取决于色素多少，有种族差异：白色人种因缺乏色素呈浅黄或浅蓝，黄色人种多呈棕色。

:::definition{label="虹膜"}
血管膜最前部，圆盘，中央是瞳孔。把眼房分成较大的前房和较小的后房，二者借瞳孔交通。
:::

:::definition{label="虹膜角膜角"}
前房周边、虹膜与角膜交界的环形区，又称前房角。房水经此进入巩膜静脉窦。狭窄可致眼压升高。
:::

:::definition{label="瞳孔括约肌与瞳孔开大肌"}
括约肌环形，缩小瞳孔，动眼神经副交感纤维支配。开大肌放射状，开大瞳孔，颈上神经节交感纤维支配。弱光、视远 → 开大；强光、视近 → 缩小。
:::

:::compare{title="表8-2　眼内肌的位置、功能和神经支配"}
| 名称 | 位置 | 功能 | 神经支配 |
|------|------|------|----------|
| 睫状肌 | 睫状体 | 调节晶状体曲度 | 动眼神经（副交感纤维） |
| 瞳孔括约肌 | 虹膜（环形） | 缩小瞳孔 | 动眼神经（副交感纤维） |
| 瞳孔开大肌 | 虹膜（放射状） | 开大瞳孔 | 颈上神经节（交感纤维） |

三块都是平滑肌，不要和外直肌、上睑提肌等骨骼肌眼外肌并户。
:::

（2）睫状体（ciliary body）：是血管膜中部最肥厚的部分，位于巩膜与角膜移行部的内面（图8-4、图8-5）。后部较平坦，为睫状环；前部有向内突出、呈放射状排列的皱襞，称睫状突（ciliary processes）。睫状突发出睫状小带与晶状体相连。眼球水平切面上睫状体呈三角形。睫状体内含睫状肌（ciliary muscle），由副交感神经支配。睫状体有调节晶状体曲度和产生房水的作用。

:::definition{label="睫状体"}
血管膜中部最肥厚。后部睫状环，前部睫状突，突发睫状小带连晶状体。职能两件：**调节晶状体曲度**和**产生房水**。
:::

（3）脉络膜（choroid）：占血管膜的后 2/3，富含血管及色素。外面与巩膜疏松相连，内面紧贴视网膜色素层，后方有视神经穿过。脉络膜营养眼球内组织并吸收分散光线。

:::definition{label="脉络膜"}
血管膜后 **2/3**。外松贴巩膜，内紧贴视网膜色素层。营养 + 吸收散光，不是感光层。
:::

:::pitfall{label="血管膜三部不要按「前中后各 1/3」来切"}
虹膜在最前，睫状体是中部最肥厚，脉络膜占后 2/3。写成「三等分」，睫状突和锯状缘的位置会对不上图8-5。
:::

**3. 视网膜（retina）**　又称眼球内膜，贴在血管膜内面，自前向后分为视网膜虹膜部、睫状体部和脉络膜部（图8-4）。虹膜部和睫状体部分别贴虹膜和睫状体内面，薄而无感光作用，称视网膜盲部。脉络膜部附于脉络膜内面，范围最大，有感光作用，称视网膜视部。

视部后部最厚，越向前越薄。视神经起始处有境界清楚、略呈椭圆形的盘状结构，称视神经盘（optic disc），又称视神经乳头（papilla of optic nerve）。视神经盘中央凹陷称视盘陷凹，有视网膜中央动、静脉穿过，无感光细胞，称生理性盲点。在视神经盘的颞侧稍偏下方约 **3.5 mm** 处，有一黄色小区，由密集的视锥细胞构成，称黄斑（macula lutea），直径约 **1.8～2.0 mm**。黄斑中央凹陷称中央凹（fovea centralis）（图8-6），此区无血管，为感光最敏锐处。

:::definition{label="视网膜盲部与视部"}
盲部 = 虹膜部 + 睫状体部，无感光。视部 = 脉络膜部，有感光。分界在锯状缘一带，不要把整层视网膜都听成感光。
:::

:::definition{label="视神经盘"}
视神经起始处的盘状结构，中央有视盘陷凹，视网膜中央动、静脉在此穿过。无感光细胞，是**生理性盲点**。不要写成「病变才能出现的盲点」。
:::

:::definition{label="黄斑与中央凹"}
黄斑在视神经盘**颞侧稍偏下约 3.5 mm**，直径约 1.8～2.0 mm，由密集视锥细胞构成。中央凹无血管，是感光最敏锐处。视轴对准的就是这里，不是视盘。
:::

::figure{src="/images/anatomy/textbook/p0265_01.png" caption="图8-6　眼底（右侧）" alt="右侧眼底：视神经盘偏鼻侧，黄斑和中央凹在颞侧；视网膜鼻侧上、下小动脉和颞侧上、下小动脉自视盘发出"}

视网膜视部分两层。外层为色素上皮层，由单层色素上皮细胞构成（图8-7）；内层为神经层，是视网膜的固有结构。两层之间有一潜在性间隙，是造成视网膜脱离的解剖学基础。神经层由外向内由 3 层神经细胞组成：外层为视锥和视杆细胞，是感光细胞，紧邻色素上皮层；中层为双极细胞，传导感光细胞的神经冲动；内层为节细胞，轴突向视神经盘汇集，穿脉络膜和巩膜后构成视神经。在视网膜中央凹区域，节细胞通过一个双极细胞与一个视锥细胞相联系，因此视觉敏锐。

视锥细胞主要分布在视网膜中央部，感受强光和颜色，在白天或明亮处视物时起主要作用；视杆细胞主要分布于周边部，感受弱光，在夜间或暗处视物时起主要作用。

:::definition{label="视锥细胞与视杆细胞"}
都是感光细胞，紧邻色素上皮。视锥：中央部，强光和颜色，白昼。视杆：周边部，弱光，夜间。中央凹几乎是视锥的天下。
:::

:::compare{title="视网膜视部：两层上皮 + 三层神经元"}
| 层次（外 → 内） | 本版内容 |
|------------------|----------|
| 色素上皮层 | 单层色素上皮；与神经层之间有潜在间隙 |
| 感光细胞 | 视锥（中央、强光颜色）+ 视杆（周边、弱光） |
| 双极细胞 | 中层，传导冲动 |
| 节细胞 | 内层，轴突汇成视神经；中央凹处「一个视锥—一个双极—一个节细胞」 |

光线从内向外打到感光细胞，冲动再从外向内传出——和图8-7 上「光」的箭头方向一致。
:::

::figure{src="/images/anatomy/textbook/p0265_02.png" caption="图8-7　视网膜神经细胞示意图" alt="光线从内向外：色素上皮在外，其内为视杆和视锥，再内为水平细胞、双极细胞，最内为节细胞轴突汇出"}

:::insight{label="中央凹敏锐，是因为「一对一」，不是因为「细胞最多」"}
周边可以是多个视杆汇到一个节细胞，空间分辨率低。中央凹一个视锥只对一个双极、一个节细胞，所以最敏锐。无血管则减少光线散射。
:::

:::pitfall{label="视盘在鼻侧，黄斑在颞侧，不要对调"}
检眼镜下视神经盘偏鼻侧，黄斑在盘的颞侧稍下。把中央凹画在视盘上，视轴和生理性盲点会并成一个点。
:::

:::cause-effect{title="视网膜为什么容易从色素上皮「揭下来」"}
- **因** 视部神经层与色素上皮层之间只有潜在间隙，两层贴合不牢
- **果** 外力、玻璃体支撑减弱或裂孔，神经层可从色素上皮脱离

脉络膜贴住的是色素层，不是神经层。脱离发生在这两层之间，不是巩膜和脉络膜之间。
:::

### （二）眼球的内容物

眼球的内容物包括房水、晶状体和玻璃体（图8-4、图8-5）。这些结构透明而无血管，具有屈光作用。它们与角膜合称为眼的屈光装置，使所视物体在视网膜上清晰成像。

:::definition{label="屈光装置"}
角膜 + 房水 + 晶状体 + 玻璃体。共同特征：**透明、无血管**。缺一则光线到不了视网膜或到了却散焦。
:::

**1. 房水（aqueous humor）**　无色透明的液体，充填于眼房内。房水由睫状体产生，进入眼后房，经瞳孔至眼前房，又经虹膜角膜角进入巩膜静脉窦，借睫前静脉汇入眼上、下静脉。生理功能是为角膜和晶状体提供营养并维持正常眼压。房水回流受阻可引起眼压升高，导致青光眼；临床上常见于前房角狭窄等疾病。

:::definition{label="房水"}
睫状体产生 → 后房 → 瞳孔 → 前房 → 虹膜角膜角 → 巩膜静脉窦 → 睫前静脉 → 眼上、下静脉。营养角膜和晶状体，维持眼压。
:::

:::pitfall{label="青光眼是房水回流受阻，不是「房水分泌太多」这一户的原句"}
本版原句落在回流：前房角狭窄等使房水回不去巩膜静脉窦，眼压升高。先问前房角和静脉窦通不通，再问分泌。
:::

**2. 晶状体（lens）**　位于虹膜和玻璃体之间，借睫状小带与睫状体相连；呈双凸透镜状，前面曲度较小，后面曲度较大，无色透明、富有弹性、不含血管和神经。外包高度弹性的晶状体囊。本身由平行排列的晶状体纤维组成，周围部较软称晶状体皮质，中央部较硬称晶状体核。疾病或创伤致晶状体变混浊，称白内障。临床上糖尿病患者常并发白内障及视网膜病变。

晶状体是眼屈光系统的主要调节装置，曲度因所视物体远近而改变。视近物时，睫状肌收缩，牵引脉络膜向前，睫状突内伸，睫状小带变松弛，晶状体借晶状体囊及其本身弹性变凸，尤其前部凸度增大，屈光度加强，使光线聚焦于视网膜上。视远物时，睫状肌舒张，睫状突外伸，睫状小带加强对晶状体的牵拉，晶状体曲度变小，远处物体清晰成像。

若眼轴较长或屈光装置屈光率过强，物像落在视网膜前，称近视。反之，眼轴较短或屈光率过弱，物像落在视网膜后，称远视。随年龄增长，晶状体核逐渐增大变硬、弹性减退，睫状肌逐渐萎缩，调节能力减弱，近距离视物困难，出现老视，即「老花眼」。

:::definition{label="晶状体"}
虹膜与玻璃体之间的双凸透镜，前曲小、后曲大，无血管神经。皮质软、核硬。混浊称白内障。
:::

:::compare{title="视近与视远（睫状肌—小带—晶状体）"}
| | 视近 | 视远 |
|--|------|------|
| 睫状肌 | 收缩 | 舒张 |
| 睫状突 | 内伸 | 外伸 |
| 睫状小带 | 松弛 | 拉紧 |
| 晶状体 | 变凸（前部更明显），屈光加强 | 曲度变小 |

近物不是「晶状体自己用力凸」，是小带放松后弹性回凸。
:::

:::compare{title="近视、远视、老视"}
| | 本版机制 | 物像位置 |
|--|----------|----------|
| 近视 | 眼轴较长，或屈光率过强 | 视网膜**前** |
| 远视 | 眼轴较短，或屈光率过弱 | 视网膜**后** |
| 老视 | 晶状体核变硬、弹性减退，睫状肌萎缩，调节减弱 | 近处看不清（「老花」） |

老视不是另一种眼轴异常，是调节装置老化。
:::

:::insight{label="看近时小带是松的，不是绷紧才变凸"}
骨骼肌越用力越短，晶状体相反：睫状肌收缩把「吊着晶状体的绳子」放松，晶状体才靠自身弹性变凸。把小带听成「收缩把晶状体挤凸」，调节方向整表反掉。
:::

**3. 玻璃体（vitreous body）**　无色透明的胶状物质，表面被覆玻璃体膜。填充于晶状体与视网膜之间，约占眼球内腔的后 4/5。前面以晶状体及其悬韧带（睫状小带）为界，呈凹面状，称玻璃体凹。其余部分与睫状体和视网膜相邻，对视网膜起支撑作用，使神经层与色素上皮紧贴；支撑减弱可导致视网膜脱离。玻璃体混浊可影响视力。

:::definition{label="玻璃体"}
晶状体与视网膜之间的透明胶状体，约占内腔后 **4/5**。支撑视网膜；支撑减弱是视网膜脱离的原因之一。
:::

## 二、眼副器

眼副器（accessory organ of eye）为保护、运动和支持眼球的装置，包括眼睑、结膜、泪器、眼球外肌、眶脂体和眶筋膜。

### （一）眼睑

眼睑（palpebrae）（图8-8）位于眼球前方，分上睑和下睑，二者之间的裂隙称睑裂。睑裂内、外侧端分别称内眦和外眦。睑的游离缘称睑缘，又分为睑前缘和睑后缘。

睑缘有 2～3 行睫毛，上、下睑睫毛均弯曲向前：上睑睫毛硬而长，下睑睫毛短而少，可防止灰尘进入并减弱强光。睫毛长向角膜称倒睫，可引起角膜上皮缺损、角膜炎和溃疡。睫毛根部有汗腺（Moll 腺）和皮脂腺（Zeis 腺，又称睑缘腺）。汗腺和皮脂腺的急性炎症称外睑腺炎。

:::definition{label="眼睑"}
上睑 + 下睑，中间是睑裂，两端是内眦、外眦。游离缘是睑缘。睫毛弯曲向前，不是弯向角膜。
:::

眼睑由浅至深分 5 层（图8-9）：皮肤、皮下组织、肌层、睑板和睑结膜。皮肤细薄，皮下组织疏松，可因积水或出血肿胀；睑部感染、肾炎等常伴眼睑水肿。肌层主要是眼轮匝肌睑部，收缩可闭合睑裂。眼睑部手术切口应与眼轮匝肌纤维方向平行，以利于愈合。上睑还有上睑提肌，腱膜止于上睑上部，可提起上睑。

睑板（tarsus）为一半月形致密结缔组织板，上、下各一。内、外两端借横位的睑内、外侧韧带与眶缘相连。睑内侧韧带较强韧，前面有内眦动、静脉越过，后面有泪囊，是手术时寻找泪囊的标志。睑板内有麦穗状的睑板腺（tarsal gland），与睑缘垂直排列，开口于睑缘（图8-10）。睑板腺分泌油样液体，润滑眼睑、防止泪液外流。导管阻塞形成睑板腺囊肿；睑板腺感染导致的炎症为内睑腺炎。

眼睑血液供应丰富（图8-11）：① 颈外动脉发出的面动脉、颞浅动脉、眶下动脉等分支；② 眼动脉发出的眶上动脉、泪腺动脉和滑车上动脉等分支。这些动脉在眼睑浅部形成动脉网，深部吻合成动脉弓。静脉回流至眼静脉和内眦静脉。

:::definition{label="睑板与睑板腺"}
睑板是半月形致密结缔组织板。睑板腺与睑缘垂直，开口于睑缘，分泌油样液体。阻塞 → 睑板腺囊肿；感染 → **内睑腺炎**。Moll / Zeis 腺炎才是外睑腺炎。
:::

:::compare{title="内睑腺炎与外睑腺炎"}
| | 发炎的腺 | 位置 |
|--|----------|------|
| 外睑腺炎 | Moll 腺（汗腺）、Zeis 腺（睑缘腺） | 睫毛根部 |
| 内睑腺炎 | 睑板腺 | 睑板内 |

不要把「麦粒肿」笼统写成同一种腺。
:::

:::pitfall{label="睑内侧韧带后面是泪囊，不要只当「眼角的一条筋」"}
本版原句：韧带前面有内眦动、静脉，后面有泪囊，是寻泪囊的标志。内眦切开或泪囊手术先认这条韧带。
:::

### （二）结膜

结膜（conjunctiva）是一层薄而透明、富含血管的黏膜，覆盖在眼球前面及眼睑内面（图8-8）。按部位分 3 部分。

**1. 睑结膜（palpebral conjunctiva）**　衬覆于上、下睑内面，与睑板结合紧密。内表面可透视深层小血管和睑板腺。

**2. 球结膜（bulbar conjunctiva）**　覆盖眼球前面，近角膜缘处移行为角膜上皮，该处与巩膜结合紧密，其余部分连结疏松、易移动。

**3. 结膜穹窿（conjunctival fornix）**　睑结膜与球结膜的移行处，分结膜上穹和结膜下穹，上穹较下穹深。上、下睑闭合时，整个结膜形成囊状腔隙称结膜囊（conjunctival sac），经睑裂与外界相通。

结膜病变常局限：沙眼易发于睑结膜和结膜穹窿；疱疹多见于角膜缘的结膜和球结膜。结膜炎会引起结膜充血肿胀。

:::definition{label="结膜三部"}
睑结膜贴睑板（紧）；球结膜贴眼球前面（角膜缘处紧，其余松）；结膜穹窿是二者移行，上穹更深。
:::

:::definition{label="结膜囊"}
睑闭合时结膜围成的囊，经睑裂通外界。滴眼药滴进的是这个囊，不是「眼球里面」。
:::

:::pitfall{label="沙眼好发睑结膜和穹窿，不要写成球结膜专属"}
本版把沙眼和疱疹分了部位。球结膜充血常见于结膜炎，但沙眼的户头在睑结膜和穹窿。
:::

### （三）泪器

泪器（lacrimal apparatus）由泪腺和泪道组成（图8-12）。

**1. 泪腺（lacrimal gland）**　位于眼眶外上方的泪腺窝内，长约 2 cm，有 10～20 条排泄管开口于结膜上穹的外侧部。分泌的泪液借眨眼涂抹于眼球表面，防止角膜干燥并冲洗微尘；泪液含溶菌酶，具有灭菌作用。多余泪液流向内眦处的泪湖（lacrimal lake），经泪点、泪小管进入泪囊，再经鼻泪管至鼻腔。

**2. 泪道**

（1）泪点（lacrimal punctum）：上、下睑缘近内侧端各有一隆起，称泪乳头（lacrimal papilla），顶部小孔即泪点，是泪小管的开口。沙眼等可造成泪点变位而引起溢泪症。

（2）泪小管（lacrimal ductule）：连结泪点与泪囊，分上、下泪小管，分别垂直向上、下行，继而几乎成直角转向内侧汇合，开口于泪囊上部。

（3）泪囊（lacrimal sac）：位于眶内侧壁前下部的泪囊窝中，膜性囊。上端为盲端，下部移行为鼻泪管。前面有睑内侧韧带和眼轮匝肌纤维，少量肌束跨过泪囊深面。眼轮匝肌收缩时牵引睑内侧韧带，扩大泪囊产生负压，促使泪液流入泪囊。

（4）鼻泪管（nasolacrimal duct）：膜性管道，上部包埋在骨性鼻泪管中与骨膜结合紧密；下部在鼻腔外侧壁黏膜深面，开口于下鼻道外侧壁。开口处黏膜内有丰富静脉丛，感冒时黏膜充血肿胀可导致下口闭塞，泪液向鼻腔引流不畅，故感冒常有流泪。

:::definition{label="泪腺"}
眶外上方泪腺窝，长约 2 cm，10～20 条排泄管开口于**结膜上穹外侧部**。不是开在内眦。
:::

:::definition{label="泪道"}
泪点 → 泪小管 → 泪囊 → 鼻泪管 → **下鼻道外侧壁**。泪囊上端盲，下续鼻泪管；睑内侧韧带是寻囊标志。
:::

::figure{src="/images/anatomy/textbook/p0268_01.png" caption="图8-12　泪器" alt="左眶前面：泪腺在外上，泪点、上泪小管、下泪小管汇入泪囊，向下续鼻泪管开口于下鼻道，下鼻甲可见"}

:::cause-effect{title="感冒为什么会流泪"}
- **因** 鼻泪管下口黏膜静脉丛丰富，感冒时充血肿胀，下口闭塞
- **果** 泪液不能排入下鼻道，溢到面颊

不是「泪腺感冒后分泌增多」这一户的原句。
:::

:::pitfall{label="鼻泪管开下鼻道，不是中鼻道"}
中鼻道走的是鼻旁窦口。写成「泪液排进中鼻道」，和第三章鼻泪管开口就撞车。
:::

### （四）眼球外肌

眼球外肌（extraocular muscle）为视器的运动装置，包括运动眼球的 4 块直肌、2 块斜肌和运动眼睑的上睑提肌，均为骨骼肌（表8-3，图8-13）。

**1. 上睑提肌（levator palpebrae superioris）**　起自视神经管前上方的眶壁，向前行于上直肌上方，止于上睑皮肤和上睑板。收缩提上睑、开大眼裂，由动眼神经支配。瘫痪可导致上睑下垂。Müller 肌是一块薄而小的平滑肌，起于上睑提肌下面的肌纤维之间，在上睑提肌与上直肌、结膜穹窿之间向前下走行，止于睑板上缘。Müller 肌助提上睑，受颈交感神经支配；该神经麻痹导致霍纳综合征（Horner 综合征），可出现瞳孔缩小、眼球内陷、上睑下垂等症状。

:::definition{label="上睑提肌"}
起视神经管前上方眶壁，止上睑皮肤和上睑板。骨骼肌，动眼神经。瘫痪 → 上睑下垂。
:::

:::definition{label="Müller 肌"}
平滑肌，助提上睑，颈交感神经支配。麻痹参与 Horner 综合征：瞳孔缩小、眼球内陷、上睑下垂。不要和上睑提肌并成「同一块肌、同一条神经」。
:::

**2. 上、下、内、外直肌**　四块直肌分别位于眼球上、下、内侧和外侧：上直肌（rectus superior）、下直肌（rectus inferior）、内直肌（rectus medialis）、外直肌（rectus lateralis）。各直肌共同起自视神经管周围和眶上裂内侧的总腱环，在赤道前方分别止于巩膜的上、下、内侧和外侧。收缩时分别使瞳孔转向上内、下内、内侧和外侧。

**3. 上斜肌和下斜肌**　上斜肌（obliquus superior）位于上直肌与内直肌之间，起于蝶骨体，以细腱通过眶内侧壁前上方的滑车，然后转向后外，在上直肌下方止于眼球赤道后方的巩膜。收缩使瞳孔转向下外方。下斜肌（obliquus inferior）位于眶下壁与下直肌之间，起自眶下壁前内侧，斜向后外，止于眼球下面赤道后方的巩膜。收缩使瞳孔转向上外方。

眼球的正常运动并非单一肌肉收缩，而是双眼数条肌肉协同的结果。俯视时两眼下直肌和上斜肌同时收缩；仰视时两眼上直肌和下斜肌同时收缩；侧视时一侧外直肌和对侧内直肌共同作用；聚视中线则是两眼内直肌共同作用。某一眼肌麻痹时可出现斜视和复视。

:::definition{label="眼球外肌"}
7 块骨骼肌：上睑提肌 + 上、下、内、外直肌 + 上、下斜肌。直肌起总腱环、止赤道以前；两斜肌止赤道以后。
:::

:::pitfall{label="上斜肌使瞳孔下外，下斜肌使瞳孔上外，不要按「上斜就向上」记"}
上斜肌腱过滑车后转向后外，止赤道后方，收缩把眼球后部上提，瞳孔反而下外。下斜肌止眼球下面赤道后，收缩使瞳孔上外。图8-13 右侧六箭头按这个方向，不要和直肌的上内、下内对调。
:::

:::insight{label="Horner 综合征三件套落在交感神经，不落在动眼神经"}
上睑提肌瘫痪也下垂，但不同时缩瞳、眼球内陷。Müller 肌和瞳孔开大肌都走颈交感，所以 Horner 是缩瞳 + 内陷 + 下垂。动眼神经麻痹是上睑下垂加「瞳孔开大、眼外斜」。
:::

### （五）眶脂体与眶筋膜

**1. 眶脂体（adipose body of orbit）**　眼眶内的脂肪组织，充填于眼球、眼球外肌与眶骨膜之间，起支持和保护作用（图8-8）。眼球后方、视神经与各肌之间脂肪较多，前部较少。眶脂体与眼球之间类似关节头与关节窝，允许眼球作多轴运动，并减少外来震动。

**2. 眶筋膜（orbital fasciae）**　包括眶骨膜、眼球筋膜鞘、眼肌筋膜和眶隔（图8-8）。

（1）眶骨膜（periorbita）：疏松衬于眶壁内面，在面前部与周围骨膜续连。视神经管处硬脑膜分两层，内层为视神经外鞘，外层续为眶骨膜。眶后部眶骨膜增厚形成总腱环，为眼球外肌提供附着处。

（2）眼球筋膜鞘（sheath of eyeball）：眶脂体与眼球之间薄而致密的纤维膜，又称 Tenon 囊。包绕眼球大部，向前在角膜缘稍后方与巩膜融合，向后与视神经硬膜鞘结合。内面光滑，与眼球之间的间隙称巩膜外隙，眼球在鞘内可灵活运动。

（3）眼肌筋膜（fascia of ocular muscle）：呈鞘状包绕眼球外肌。

（4）眶隔（orbital septum）：上睑板上缘和下睑板下缘的薄层结缔组织，分别连于眶上缘和眶下缘，与眶骨膜相延续。

:::definition{label="眶脂体"}
充填眼球、眼外肌与眶骨膜之间的脂肪。后部多、前部少。既是「关节窝」，也是减震垫。
:::

:::definition{label="眼球筋膜鞘"}
Tenon 囊。与眼球之间是巩膜外隙，眼球在鞘内转动。不是巩膜本身。
:::

:::keypoint{label="眶筋膜四件套"}
- 眶骨膜：衬眶壁，后部增厚成总腱环。
- 眼球筋膜鞘：Tenon 囊，内有巩膜外隙。
- 眼肌筋膜：包眼外肌。
- 眶隔：睑板缘连眶缘。
:::

## 三、眼的血管

### （一）眼的动脉

眼的血液供应来自眼动脉（ophthalmic artery）（图8-14）。眼动脉自颈内动脉发出，经视神经管入眶，先居视神经下外侧，然后在上直肌下方越至眶内侧前行，走在上斜肌和内直肌之间，终支出眶，终于滑车上动脉。行程中发支供应眼球、眼球外肌、泪腺和眼睑。主要分支如下。

**1. 视网膜中央动脉（central artery of retina）**　供应视网膜内层的唯一动脉。发自眼动脉，行于视神经下方，在距眼球约 **10～15 mm** 处穿入视神经鞘，走行约 **0.9～2.5 mm** 后行于视神经中央，在视神经盘处分为上、下 2 支，再分成视网膜鼻侧上、下和颞侧上、下 4 支小动脉（图8-6），分布至四个扇形区。临床上用检眼镜可直接观察这些血管。黄斑中央凹 **0.5 mm** 范围内无血管分布。

视网膜中央动脉是终动脉，在视网膜内的分支之间无吻合，亦不与脉络膜内的血管吻合，但行于视神经鞘和视神经内的分支间有吻合。阻塞时可导致眼全盲。

:::definition{label="眼动脉"}
发自**颈内动脉**，经视神经管入眶。先在视神经下外侧，再经上直肌下方向内侧，终于滑车上动脉。
:::

:::definition{label="视网膜中央动脉"}
供应视网膜内层的**唯一**动脉，终动脉。距眼球 10～15 mm 处穿入视神经鞘。视盘处分成鼻上、鼻下、颞上、颞下四支。中央凹 0.5 mm 内无血管。阻塞 → 眼全盲。
:::

**2. 睫后短动脉**　又称脉络膜动脉，有很多支，在视神经周围垂直穿入巩膜，分布于脉络膜（图8-15）。

**3. 睫后长动脉**　又称虹膜动脉，有 2 支，在视神经内、外侧穿入巩膜，在巩膜与脉络膜间前行至睫状体，发出 3 支：① 回归动脉支：进入脉络膜与睫后短动脉吻合；② 睫状肌支：至睫状肌；③ 虹膜动脉大环支：与睫前动脉吻合。

**4. 睫前动脉**　由眼动脉的各肌支发出，共 7 支，在眼球前部距角膜缘 **5～8 mm** 处穿入巩膜，在巩膜静脉窦后面入睫状肌，发分支与虹膜动脉大环吻合，营养巩膜前部、虹膜和睫状体。进入巩膜前分支至球结膜。

眼动脉还发出泪腺动脉、筛前动脉、筛后动脉以及眶上动脉等至相应部位。

:::compare{title="眼动脉到眼球的几组终支"}
| 动脉 | 本版 | 分布 |
|------|------|------|
| 视网膜中央动脉 | 1 支，终动脉 | 视网膜内层；视盘四扇区 |
| 睫后短动脉 | 多支，脉络膜动脉 | 脉络膜 |
| 睫后长动脉 | 2 支，虹膜动脉 | 睫状体；回归支吻睫后短；虹膜动脉大环 |
| 睫前动脉 | 7 支，距角膜缘 5～8 mm 入巩膜 | 巩膜前部、虹膜、睫状体；入巩膜前发支至球结膜 |

内层视网膜只认中央动脉；外层（色素上皮侧）靠脉络膜的睫后短动脉。
:::

### （二）眼的静脉

**1. 眼球内的静脉**

（1）视网膜中央静脉（central vein of retina）：与同名动脉伴行，收纳视网膜的静脉血（图8-6）。

（2）涡静脉（vorticose vein）：眼球血管膜的主要静脉，多数为 4 条，即两条上涡静脉和两条下涡静脉，分散在眼球赤道后方的 4 条直肌之间，收集虹膜、睫状体和脉络膜的静脉血。上涡静脉汇入眼上静脉，下涡静脉汇入眼下静脉。不与动脉伴行，在眼球赤道附近穿出巩膜，经眼上、下静脉汇入海绵窦（图8-15）。

（3）睫前静脉：收集眼球前部虹膜等处的静脉血。这些静脉以及眶内其他静脉，最后均汇入眼上、下静脉。

**2. 眼球外的静脉**

（1）眼上静脉：起自眶内上角，向后经眶上裂注入海绵窦。

（2）眼下静脉：起自眶下壁和内侧壁的静脉网，向后分 2 支。一支经眶上裂注入眼上静脉；另一支经眶下裂汇入翼静脉丛。

眼静脉内无瓣膜，在内眦处向前与面静脉吻合，向后注入海绵窦。面部感染可经眼静脉侵入海绵窦引起颅内感染。

:::definition{label="涡静脉"}
血管膜的主要静脉，多数 **4 条**，赤道后方四直肌之间穿出巩膜。收集虹膜、睫状体、脉络膜的静脉血。不与动脉伴行。
:::

:::definition{label="眼上、下静脉"}
眼上静脉经眶上裂入海绵窦。眼下静脉一支经眶上裂入眼上静脉，一支经眶下裂入翼静脉丛。无瓣膜，内眦处与面静脉吻合。
:::

:::pitfall{label="眼静脉无瓣膜，面静脉感染可以倒灌海绵窦"}
内眦 ↔ 面静脉 ↔ 眼静脉 ↔ 海绵窦是一条没有瓣的通道。危险三角的感染不要挤，解剖学底板就是这道无瓣吻合。
:::

:::insight{label="检眼镜看见的是终动脉，看不见涡静脉"}
图8-6 上红蓝相间的是视网膜中央动、静脉，走在视部内层。涡静脉走血管膜，从赤道后方穿巩膜，眼底镜下不在这张「红树」里。
:::

:::memory{label="本节必背要点"}
- [ ] 感觉器 = 感受器 + 附属结构。感受器按来源分外、内、本体；按特化分一般与特殊（视、听、嗅、味、平衡）。
- [ ] 视器 = 眼球 + 眼副器（眼睑、结膜、泪器、眼球外肌、眶脂体、眶筋膜）。
- [ ] 眶：内侧壁几乎平行；两外侧壁向后交 90°；同侧内、外侧壁夹角 45°。眼轴连前后极，视轴经瞳孔中央到黄斑中央凹，两轴锐角交叉。
- [ ] 纤维膜：角膜前 1/6（透明无血管、感觉敏锐）+ 巩膜后 5/6（巩膜静脉窦走房水）。血管膜：虹膜、睫状体、脉络膜（后 2/3）。
- [ ] 眼房分前房（大）、后房（小），借瞳孔交通。虹膜角膜角 = 前房角。瞳孔括约肌（环、副交感、缩瞳）；瞳孔开大肌（放射、交感、开大）。
- [ ] 睫状体：睫状环 + 睫状突；调节晶状体曲度并产生房水。
- [ ] 视网膜盲部无感光；视部感光。视神经盘 = 生理性盲点。黄斑在视盘颞侧稍下约 3.5 mm，直径 1.8～2.0 mm；中央凹无血管，感光最敏锐。
- [ ] 视锥：中央、强光颜色；视杆：周边、弱光。神经层与色素上皮之间的潜在间隙是视网膜脱离的解剖学基础。
- [ ] 屈光装置 = 角膜 + 房水 + 晶状体 + 玻璃体，透明无血管。房水：睫状体 → 后房 → 瞳孔 → 前房 → 前房角 → 巩膜静脉窦。回流受阻 → 青光眼。
- [ ] 视近：睫状肌收缩，小带松，晶状体变凸。视远相反。眼轴长或屈光过强 → 近视（像在视网膜前）；眼轴短或屈光过弱 → 远视；核硬弹性减 → 老视。晶状体混浊 = 白内障。
- [ ] 眼睑五层。睑板腺垂直开口于睑缘，感染 = 内睑腺炎；Moll / Zeis 腺炎 = 外睑腺炎。睑内侧韧带后面是泪囊。
- [ ] 结膜：睑结膜、球结膜、结膜穹窿。闭合形成结膜囊。泪腺在眶外上，导管开结膜上穹外侧；鼻泪管开下鼻道。感冒可堵下口而流泪。
- [ ] 眼外肌：外直肌展神经，上斜肌滑车神经，其余（含上睑提肌）动眼神经。上斜肌 → 瞳孔下外，下斜肌 → 瞳孔上外。Müller 肌交感，Horner：缩瞳、内陷、上睑下垂。
- [ ] 眼动脉发自颈内动脉。视网膜中央动脉是内层唯一终动脉，阻塞全盲；中央凹 0.5 mm 无血管。涡静脉多数 4 条。眼静脉无瓣，面静脉感染可入海绵窦。
:::
