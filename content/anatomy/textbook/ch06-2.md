# 二、　松果体

上一节把垂体钉在蝶鞍垂体窝里。本节只写松果体：灰红色椭圆形小体，重 120～200 mg，坐在上丘脑后上方，以柄附着于第三脑室顶的后部。它合成褪黑素，间接管性腺发育；儿童期病变引起功能不全时，可出现性早熟。甲状腺以下各腺不在本节展开。

松果体（pineal body）为一灰红色的椭圆形腺体（图6-2）。位置：上丘脑的后上方，以柄附着于第三脑室顶的后部。表面包以软脑膜，结缔组织伴随血管伸入腺实质，将实质分为许多小叶。松果体在儿童期比较发达，一般在 7 岁左右开始退化；青春期后可有钙盐沉积，出现大小不一的脑砂，随年龄增长而增多。脑砂可作为影像诊断颅内病变的定位标志。

松果体合成和分泌褪黑素，可抑制垂体促性腺激素的释放，间接影响性腺的发育。褪黑素参与调节生殖系统的发育、月经周期的节律和许多神经功能活动。在儿童期，松果体病变引起其功能不全时，可出现性早熟或生殖器官过度发育。

:::definition{label="松果体"}
灰红色椭圆形腺体。位置：**上丘脑后上方**，以柄附着于**第三脑室顶的后部**。重 **120～200 mg**。表面软脑膜，实质被结缔组织分成许多小叶。
:::

:::compare{title="松果体的重量（本版）"}
| | 本版 |
|--|------|
| 重量 | **120～200 mg** |

按毫克记。不要改成 120～200 g，也不要和垂体 0.5～0.6 g 并成同一数量级。
:::

:::definition{label="脑砂"}
青春期后松果体内的钙盐沉积，大小不一，随年龄增多。用途：影像诊断颅内病变的**定位标志**。不是「松果体病了才出现的结石」。
:::

:::compare{title="年龄变化（本版）"}
| 阶段 | 本版 |
|------|------|
| 儿童期 | 比较发达 |
| 约 7 岁 | 开始退化 |
| 青春期后 | 可有钙盐沉积，出现脑砂 |
| 随年龄 | 脑砂增多，可作影像定位标志 |

7 岁是开始退化，不是「7 岁突然消失」。发达在儿童，退化从约 7 岁起。
:::

:::definition{label="褪黑素"}
松果体合成并分泌。作用：抑制垂体**促性腺激素**的释放，间接影响性腺发育；还参与调节生殖系统发育、月经周期节律和许多神经功能活动。
:::

:::cause-effect{title="为什么儿童期松果体功能不全会出现性早熟"}
- **因** 褪黑素抑制垂体促性腺激素释放；功能不全时这道抑制减弱
- **果** 促性腺激素相对失控，可出现性早熟或生殖器官过度发育

这一笔落在儿童期。成年后松果体已经在退化，不要把性早熟写成「老人脑砂多了就会早熟」。
:::

:::pitfall{label="重量按 120～200 mg，不要写成 g 或和垂体 0.5～0.6 g 对调"}
本版原句是毫克。写成克会把绿豆大的腺体听成半两；和垂体重量对调之后，蝶鞍里那一团和第三脑室顶后部这一小体就分不清谁重。
:::

:::pitfall{label="脑砂是钙盐沉积，用作影像定位，不要写成松果体的分泌物"}
分泌物是褪黑素。脑砂是青春期后的钙盐，随年龄增多，给影像当路标。把脑砂听成激素，性腺抑制和颅内定位会对错地方。
:::

:::pitfall{label="儿童期功能不全是性早熟，不要写成性发育迟缓"}
本版原句：功能不全时，可出现性早熟或生殖器官过度发育。抑制没了，性腺提前醒。写成「功能不全 → 不发育」，因果就反了。
:::

图6-2 左侧放大才是本节：软脑膜包着松果体，前方是松果体隐窝和缰连合，下方是后连合和中脑顶盖。右侧放大是上一节的垂体，座位不要并到第三脑室顶后来。

:::insight{label="第三脑室顶后部往下一指，就是松果体，不是垂体窝"}
垂体在蝶鞍里，松果体在上丘脑后上方。图6-2 全貌上两个箭头分开指：一个向前下到垂体，一个向后上到松果体。认座比认名先。
:::

:::keypoint{label="松果体三句话"}
- 上丘脑后上方，柄附第三脑室顶后部；重 120～200 mg。
- 儿童期发达，约 7 岁开始退化；青春期后脑砂，影像定位用。
- 褪黑素抑制促性腺激素；儿童期功能不全 → 性早熟或生殖器官过度发育。
:::
