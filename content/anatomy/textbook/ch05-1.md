# 第一节　男性生殖系统

生殖系统（reproductive system）的功能是繁殖后代和形成并保持第二性征。本节把「男性」这一户写完：内生殖器从睾丸写到尿道球腺，外生殖器写阴囊和阴茎，再把男性尿道的三部、三狭窄、三膨大和两弯曲钉死。女性各户只在章首表里点名，形态归第二节。

生殖系统包括内生殖器和外生殖器两部分。内生殖器由生殖腺、生殖管道和附属腺组成；外生殖器则以两性交媾器官为主。男性内生殖器由生殖腺（睾丸）、输精管道（附睾、输精管、射精管、男性尿道）和附属腺（精囊、前列腺、尿道球腺）组成。睾丸产生精子和分泌雄性激素；精子先贮存于附睾内，射精时经输精管、射精管和尿道排出体外。精囊、前列腺和尿道球腺的分泌液参与精液的组成，供给精子营养，有利于精子的活动。男性外生殖器为阴茎和阴囊：前者是男性交媾器官，后者容纳睾丸和附睾（图5-1）。

:::definition{label="生殖系统"}
功能是**繁殖后代**和**形成并保持第二性征**。组成先切成内生殖器和外生殖器两块，不要一上来写成「就是睾丸加阴茎」。
:::

:::definition{label="内生殖器与外生殖器"}
内生殖器 = 生殖腺 + 生殖管道 + 附属腺。外生殖器以两性交媾器官为主。男性外生殖器是阴囊和阴茎；女性外生殖器点名为女阴，本节不展开。
:::

:::definition{label="男性生殖系统"}
内生殖器：睾丸、附睾、输精管、射精管、男性尿道，以及精囊、前列腺、尿道球腺。外生殖器：阴囊、阴茎。精子的产生、贮存、输送和排出都落在这一户。
:::

:::concept{term="先问这是不是男性这一户，再问有没有把卵巢、子宫写成男性器官"}
看见生殖系统，先把男、女切开。本节的户头是睾丸到男性尿道；卵巢、输卵管、子宫、阴道归第二节。把「生殖系统」听成「就是外生殖器」，附睾和前列腺会从开篇丢掉；把卵巢、子宫的形态写进本节，又是吞了下一户。
:::

## 一、男性内生殖器

男性内生殖器按职能分成三块：生殖腺是睾丸；输精管道是附睾、输精管、射精管和男性尿道；附属腺是精囊、前列腺和尿道球腺。尿道兼具排精和排尿，形态放到本节第三部分单独写，以免和前列腺、阴茎搅成一锅。

:::definition{label="男性内生殖器"}
生殖腺：**睾丸**。输精管道：**附睾、输精管、射精管、男性尿道**。附属腺：**精囊、前列腺、尿道球腺**。三块都要，缺腺就把精液成分写丢。
:::

:::compare{title="内生殖器三块各管什么"}
| 块 | 本版名单 | 职能 |
|----|----------|------|
| 生殖腺 | 睾丸 | 产生精子，分泌雄性激素 |
| 输精管道 | 附睾、输精管、射精管、男性尿道 | 贮存、成熟、输送并排出精子 |
| 附属腺 | 精囊、前列腺、尿道球腺 | 分泌液参与精液，营养并利于精子活动 |

把尿道只写成「泌尿器官」，排精这一笔就从男性户头里消失。
:::

:::timeline{period="精子从产生到排出（排精径路）"}
- **生精小管** 生精上皮产生精子
- **精直小管** 出小叶，进入纵隔
- **睾丸网** 纵隔内交织
- **睾丸输出小管** 12～15 条，经后缘上部入附睾
- **附睾管** 头、体、尾；贮存并促进成熟
- **输精管** 四部走完，末端成壶腹
- **射精管** 与精囊排出管汇合，穿前列腺
- **男性尿道** 前列腺部开口后，经膜部、海绵体部出外口
:::

### （一）睾丸

睾丸（testis）位于阴囊内，左、右各一，一般左侧略低于右侧，是产生精子和分泌雄性激素的器官（图5-2）。睾丸呈微扁的卵圆形，表面光滑，分前、后缘，上、下端和内、外侧面。前缘游离，后缘有血管、神经和淋巴管出入，并与附睾相连。上端被附睾头遮盖，下端游离。外侧面较隆凸，与阴囊壁相贴；内侧面较平坦，与阴囊中隔相依。成人单侧睾丸约重 10～15 g。新生儿的睾丸相对较大，性成熟期以前发育较慢，随着性成熟发育迅速；老年人的睾丸萎缩变小。

:::definition{label="睾丸"}
阴囊内成对的生殖腺，微扁卵圆形。职能两笔：**产生精子**和**分泌雄性激素**。一般**左侧略低于右侧**。
:::

:::definition{label="睾丸的外形"}
两缘（前、后）、两端（上、下）、两面（内、外）。前缘游离；后缘是血管神经淋巴管出入处，连附睾。上端被附睾头遮盖，下端游离。外侧面隆凸贴阴囊壁，内侧面较平坦依阴囊中隔。
:::

:::compare{title="成人单侧睾丸的重量（本版）"}
| | 本版 |
|--|------|
| 单侧重 | 约 **10～15 g** |

只记这一段。不要改成「约 20 g」或把两侧加在一起当成单侧重。
:::

:::pitfall{label="睾丸是左侧略低，不要写成右侧低，也不要和右肾较低并成一套"}
本版原句：一般左侧略低于右侧。肾是右肾因肝而较低；睾丸是左侧略低。左右对调之后，阴囊触诊和疝的对照都会偏。
:::

:::pitfall{label="后缘才是门，不要把前缘当成血管神经出入处"}
前缘游离，后缘连附睾并有管道出入。把「游离缘」听成「门」，输出小管和附睾头会对不上图5-2、图5-3。
:::

睾丸表面覆盖浆膜，即鞘膜脏层；其深部是坚韧的白膜（tunica albuginea）。白膜在睾丸后缘增厚进入睾丸，形成睾丸纵隔（mediastinum testis）。纵隔发出许多睾丸小隔（septula testis），呈扇形伸入睾丸实质并与白膜相连，将睾丸实质分为 100～200 个睾丸小叶（lobule of testis）。每个小叶内含有 2～4 条盘曲的生精小管（seminiferous tubule），精子由其生精上皮产生。生精小管之间的结缔组织内有分泌雄性激素的间质细胞。生精小管汇合成精直小管（straight seminiferous tubule），进入睾丸纵隔交织形成睾丸网（rete testis）。睾丸网发出 12～15 条睾丸输出小管（efferent ductule of testis），经睾丸后缘上部进入附睾（图5-3）。

:::definition{label="白膜与睾丸纵隔"}
白膜是鞘膜脏层深面的坚韧膜。它在**后缘增厚进入睾丸**，形成睾丸纵隔。纵隔不是「睾丸外面的另一层膜」。
:::

:::definition{label="睾丸小叶"}
纵隔发出睾丸小隔，扇形连到白膜，把实质分成 **100～200** 个小叶。每个小叶含 **2～4** 条盘曲的生精小管。
:::

:::definition{label="生精小管与间质细胞"}
精子由生精小管的**生精上皮**产生。小管之间的结缔组织里有**间质细胞**，分泌雄性激素。产精子和产激素不在同一个细胞团里。
:::

:::definition{label="精直小管、睾丸网与输出小管"}
生精小管 → 精直小管 → 睾丸网（纵隔内交织）→ **12～15** 条睾丸输出小管，经后缘上部进入附睾。12～15 是输出小管条数，不是小叶数。
:::

:::compare{title="睾丸实质里的几组数目（不要并）"}
| 结构 | 本版数目 | 下一站 |
|------|----------|--------|
| 睾丸小叶 | 100～200 个 | 每个小叶 2～4 条生精小管 |
| 生精小管 | 每小叶 2～4 条 | 汇合成精直小管 |
| 睾丸输出小管 | **12～15** 条 | 经后缘上部入附睾头 |

小叶是百位数，输出小管是十几条。把 12～15 听成小叶数，排精径路会从纵隔就对不上。
:::

:::

:::insight{label="白膜从后缘钻进去，管道也从后缘走出来"}
纵隔、输出小管、附睾都挤在后缘这一侧。图5-2 右侧观先认后缘连附睾；图5-3 剖面再把小隔、睾丸网和输出小管串成一条路。

- 阴囊内成对；左侧略低；单侧约 10～15 g。
- 前缘游离，后缘连附睾并有管道出入。
- 白膜后缘增厚成纵隔 → 小隔 → 100～200 个小叶；每小叶 2～4 条生精小管。
- 间质细胞在小管之间，分泌雄性激素。
- 生精小管 → 精直小管 → 睾丸网 → 12～15 条输出小管入附睾。
:::

### （二）附睾

附睾（epididymis）呈新月形，由睾丸输出小管和迂曲的附睾管组成，紧贴睾丸上端和后缘。附睾分为上端膨大的附睾头、中部的附睾体和下端的附睾尾。睾丸输出小管进入附睾盘曲形成附睾头，而后汇合成一条附睾管（duct of epididymis）；附睾管长约 4～6 m，迂曲盘回形成附睾体和尾；附睾尾向后上弯曲移行为输精管。附睾管腔面衬以假复层柱状上皮，上皮外侧有薄层平滑肌围绕；肌层产生蠕动性收缩，将精子向尾部推动（见图5-2、图5-3）。附睾暂时储存精子，分泌附睾液营养精子，促进精子进一步成熟。

:::definition{label="附睾"}
新月形，贴睾丸**上端和后缘**。由输出小管和迂曲的附睾管组成。职能：暂时贮存精子，分泌附睾液营养精子，促进精子进一步成熟。
:::

:::definition{label="附睾头、体、尾"}
头在上端，膨大，由输出小管盘曲形成。体在中部。尾在下端，向后上弯曲移行为输精管。头、体、尾不要写成「左、中、右」。
:::

:::definition{label="附睾管"}
输出小管汇合成**一条**附睾管，长约 **4～6 m**，迂曲构成体和尾。腔面假复层柱状上皮，外侧薄层平滑肌蠕动，把精子推向尾部。
:::

:::pitfall{label="附睾管是 4～6 m，不要写成 4～6 cm 或 4～6 mm"}
本版原句是米。写成厘米或毫米，会把这条迂曲长管听成「一小段」，和「盘回形成体、尾」对不上。
:::

:::cause-effect{title="为什么附睾长在睾丸的上端和后缘"}
- **因** 输出小管从睾丸后缘上部走出，进入附睾头盘曲，再汇成一条附睾管下行
- **果** 附睾呈新月形贴在上端和后缘；尾折向后上才续输精管

前缘游离、下端游离，附睾不走那两侧。
:::

:::insight{label="附睾不是「精子工厂」，是仓库加成熟车间"}
工厂在生精小管。附睾负责暂存、给营养、让精子成熟，再用平滑肌蠕动送到输精管。把附睾听成第二个睾丸，雄性激素那一笔会对错地方。
:::

### （三）输精管和射精管

#### 1. 输精管

输精管（deferent duct）是附睾管的直接延续，长度约 50 cm，一般左侧较右侧稍长；管壁较厚，肌层较发达；管径约 0.3 cm，管腔窄小。活体触摸时，呈坚实的圆索状。

输精管依其行程可分为四部：①睾丸部：始于附睾尾，最短，较迂曲，沿睾丸后缘、附睾内侧行至睾丸上端。②精索部：介于睾丸上端与腹股沟管皮下环之间，在精索内位于其他结构的后内侧。此段位置表浅，易于触及，为结扎输精管的理想部位。③腹股沟管部：全程位于腹股沟管的精索内。④盆部：为输精管最长一段，经腹环出腹股沟管后，弯向内下，越过髂外动、静脉，沿盆侧壁腹膜外行向后下，跨过输尿管末端前内方至膀胱底的后面和直肠前面。两侧输精管在此逐渐接近，膨大形成输精管壶腹（ampulla of deferent duct）（图5-4）。末端变细，两侧并列穿过前列腺，与精囊的排出管汇合成射精管。

:::definition{label="输精管"}
附睾管的直接延续。长约 **50 cm**，一般左侧稍长；管径约 **0.3 cm**，壁厚腔窄，活体摸起来是坚实圆索。
:::

:::definition{label="输精管四部"}
按行程：**睾丸部、精索部、腹股沟管部、盆部**。结扎的理想部位是**精索部**，不是盆部，也不是睾丸部。
:::

:::compare{title="输精管四部（本版行程）"}
| 部 | 起止 / 位置 | 本版要点 |
|----|-------------|----------|
| 睾丸部 | 附睾尾 → 睾丸上端 | 最短、较迂曲；沿睾丸后缘、附睾内侧 |
| 精索部 | 睾丸上端 ↔ 腹股沟管皮下环 | 精索内后内侧；表浅易触及；**结扎理想部位** |
| 腹股沟管部 | 全程在腹股沟管的精索内 | 不要把这一段听成「已经出腹股沟管」 |
| 盆部 | 出腹环后最长一段 | 越髂外血管，沿盆侧壁腹膜外后下，跨输尿管末端前内方，成壶腹 |

四部少写一部，结扎点和壶腹就会换地方。
:::

:::definition{label="输精管壶腹"}
两侧输精管在膀胱底后面、直肠前面逐渐接近并膨大而成。末端变细，穿前列腺，与精囊排出管汇合成射精管。
:::

:::pitfall{label="结扎输精管在精索部，不要扎到腹股沟管部或盆部"}
本版把「表浅、易于触及」写在精索部：睾丸上端与腹股沟管皮下环之间。写成「在腹股沟管内结扎」或「在盆部结扎」，理想部位就移到深部去了。
:::

:::pitfall{label="输精管跨过输尿管末端的前内方，不要写成输尿管跨输精管"}
本版原句：跨过输尿管末端前内方至膀胱底后面。这是「水上架桥」：水是输尿管，桥是输精管。左右说反，膀胱底后面的交叉关系会画反。
:::

:::keypoint{label="输精管三句话"}
- 约 50 cm，管径约 0.3 cm，壁厚腔窄，摸起来坚实圆索。
- 四部：睾丸部、精索部、腹股沟管部、盆部。结扎选精索部。
- 盆部跨输尿管末端前内方，膨大成壶腹，再与精囊排出管合成射精管。
:::

#### 2. 精索

精索（spermatic cord）是位于睾丸上端和腹股沟管腹环之间的一对柔软的圆索状结构。精索内主要有输精管和睾丸动脉、蔓状静脉丛、输精管血管、神经、淋巴管和腹膜鞘突的残余（鞘韧带）等。精索表面包有三层被膜，从内向外依次为精索内筋膜、提睾肌和精索外筋膜。

:::definition{label="精索"}
睾丸上端与腹股沟管**腹环**之间的柔软圆索。内容：输精管，睾丸动脉，蔓状静脉丛，输精管血管，神经，淋巴管，腹膜鞘突残余（鞘韧带）。
:::

:::definition{label="精索被膜三层"}
从**内向外**：精索内筋膜 → 提睾肌 → 精索外筋膜。和阴囊深面「由外向内」那套是同一组膜，方向写反就全错。
:::

:::compare{title="精索里有什么（本版名单）"}
| 类别 | 本版 |
|------|------|
| 管道 | 输精管 |
| 动脉 | 睾丸动脉；还有输精管血管 |
| 静脉 | 蔓状静脉丛 |
| 其他 | 神经、淋巴管、腹膜鞘突残余（鞘韧带） |

精索不是「只有一根输精管」。结扎精索部时摸到的坚实圆索，主要是输精管壁厚。
:::

:::pitfall{label="精索被膜从内向外是内筋膜、提睾肌、外筋膜，不要写成从外向内的顺序"}
本版原句：从内向外依次为精索内筋膜、提睾肌和精索外筋膜。阴囊段「由外向内」才是外筋膜 → 提睾肌 → 内筋膜 → 鞘膜。两套顺序对着抄，层次会倒过来。
:::

#### 3. 射精管

射精管（ejaculatory duct）由输精管的末端与精囊的排出管汇合而成，长约 2 cm，向前下穿前列腺实质，开口于尿道前列腺部（图5-5）。射精管管壁有平滑肌纤维，能够产生有力的收缩，帮助精液排出。

:::definition{label="射精管"}
输精管末端 + 精囊排出管。长约 **2 cm**，向前下穿前列腺实质，开口于**尿道前列腺部**后壁的精阜。管壁平滑肌收缩，帮助排精。
:::

:::pitfall{label="射精管开口在尿道前列腺部，不要写成开口在膜部或膀胱"}
本版原句：开口于尿道前列腺部。膜部是穿过尿生殖膈的一段，没有射精管口；膀胱底后面是壶腹和精囊的位置，不是开口。
:::

:::cause-effect{title="为什么射精管只有约 2 cm"}
- **因** 它在前列腺实质里斜向前下走完就开口于精阜，路程短
- **果** 本版长度约 2 cm，不要把它听成输精管 50 cm 的「末段别名」

输精管走完四部才到壶腹；射精管是汇合之后穿腺的那一小段。
:::

### （四）精囊

精囊（seminal vesicle）又称精囊腺，为长椭圆形的囊状器官，表面凹凸不平，位于膀胱底的后方，输精管壶腹的下外侧；左、右各一，由迂曲的管道组成，其排出管与输精管壶腹的末端汇合成射精管（图5-4、图5-5）。精囊的分泌物参与精液的组成。

:::definition{label="精囊"}
成对，长椭圆形囊状，表面凹凸不平。位置：膀胱底后方，输精管壶腹的**下外侧**。排出管与壶腹末端汇合成射精管。分泌物参与精液。
:::

:::pitfall{label="精囊在壶腹下外侧，不要写成「精囊就是输精管壶腹」"}
壶腹是输精管末端膨大；精囊是另一套迂曲管道，贴在壶腹下外侧。图5-4 后面观把两者并排，一侧还做了纵切——看的就是「两个器官，不是一个」。
:::

::figure{src="/images/anatomy/textbook/p0174_01.png" caption="图5-4　膀胱、前列腺、精囊和尿道球腺（后面）" alt="后面观：膀胱；两侧输尿管与输精管交叉；输精管壶腹和精囊（一侧纵切）；前列腺；尿生殖膈；尿道球腺；尿道膜部；尿道球"}

图5-4 从后面把膀胱底、壶腹、精囊、前列腺、尿生殖膈和尿道球腺一次性摆开。输尿管与输精管的交叉、球腺开口前的膜部，都在这张后面观上。

### （五）前列腺

前列腺（prostate）是由腺组织和平滑肌组织构成的不成对的实质性器官，表面包有筋膜鞘，称前列腺囊（prostatic capsule）；囊与前列腺之间有前列腺静脉丛。前列腺位于膀胱与尿生殖膈之间，前列腺上端与膀胱颈、精囊和输精管壶腹相邻；前列腺的前方为耻骨联合，后方为直肠壶腹。前列腺的分泌物是精液的主要组成部分。

前列腺形似栗子，重 8～20 g，质韧，色淡红。上端宽大，为前列腺底，横径约 4 cm，前后径约 2 cm，垂直径约 3 cm。下端尖细，为前列腺尖，与尿生殖膈相贴（见图5-4）。底与尖之间的部分为前列腺体。体的后面平坦，中间有一纵行浅沟，称前列腺沟（sulcus of prostate）。活体直肠指诊可触及此沟；前列腺肥大时，此沟消失。男性尿道在前列腺底近前缘处进入，经前列腺实质前部下行，由前列腺尖穿出。在近前列腺底的后缘处，射精管穿入前列腺，斜向前下方，开口于尿道前列腺部后壁的精阜上。前列腺的输出管开口于尿道前列腺部后壁尿道嵴两侧（图5-5）。

:::definition{label="前列腺"}
不成对实质器官，腺组织加平滑肌。外有前列腺囊，囊与腺体之间是前列腺静脉丛。位于**膀胱与尿生殖膈之间**。分泌物是精液的主要组成部分。
:::

:::definition{label="前列腺的毗邻"}
底（上端）邻**膀胱颈**、精囊和输精管壶腹；尖贴**尿生殖膈**。前方耻骨联合，后方直肠壶腹。不要把底写成贴尿生殖膈。
:::

:::definition{label="前列腺底、尖、体"}
底在上，宽大；尖在下，尖细；底与尖之间是体。本版径线：横径约 **4 cm**，前后径约 **2 cm**，垂直径约 **3 cm**；重 **8～20 g**。
:::

:::definition{label="前列腺沟"}
体的后面正中一条纵行浅沟。直肠指诊可触及；前列腺肥大时**此沟消失**。
:::

:::compare{title="前列腺的位置和径线（本版）"}
| | 本版 |
|--|------|
| 上下邻居 | 底邻膀胱颈；尖贴尿生殖膈 |
| 前后邻居 | 前 = 耻骨联合；后 = 直肠壶腹 |
| 横径 | 约 4 cm |
| 前后径 | 约 2 cm |
| 垂直径 | 约 **3 cm** |
| 重量 | 8～20 g |

垂直径 3 cm 不要改成 5 cm。底在上、尖在下，和「膀胱在上、尿生殖膈在下」是同一套。
:::

:::pitfall{label="前列腺底邻膀胱颈，尖贴尿生殖膈，不要把底和尖倒过来"}
本版：上端宽大为底，下端尖细为尖。写成「尖朝膀胱」或「底贴尿生殖膈」，尿道从底近前缘进、从尖穿出的走行也会反。
:::

:::cause-effect{title="为什么直肠指诊能摸到前列腺沟"}
- **因** 前列腺后方是直肠壶腹，体的后面平坦且正中有纵行浅沟
- **果** 经直肠可触及此沟；肥大时沟消失，是活体判断的形态标志

前方是耻骨联合，指诊不走前面。
:::

前列腺分为五叶：前叶、中叶、后叶和两侧叶（图5-6）。前叶很小，位于尿道前方和左、右侧叶之间；中叶呈楔形，位于尿道和射精管之间；左、右侧叶分别位于尿道、中叶和前叶两侧；后叶位于中叶和侧叶的后方，是前列腺肿瘤易发部位。

小儿前列腺较小，腺部不甚明显；青春期前列腺迅速生长发育成熟。中年以后腺部逐渐退化，结缔组织增生，常形成老年性前列腺肥大。前列腺肥大多发生在中叶和侧叶，压迫尿道，造成排尿困难甚至尿潴留。

:::definition{label="前列腺五叶"}
前叶、中叶、后叶和**两侧叶**。名单是五叶，不是「左、右、中」三叶，也不是把两侧叶并成一叶来凑数。
:::

:::compare{title="五叶怎么围着尿道和射精管"}
| 叶 | 本版位置 | 临床形态 |
|----|----------|----------|
| 前叶 | 很小，尿道前方，左、右侧叶之间 | 不是肥大的主发叶 |
| 中叶 | 楔形，**尿道和射精管之间** | 肥大好发；从后方抬压尿道 |
| 左、右侧叶 | 在尿道、中叶和前叶两侧 | 肥大好发；从两侧压尿道 |
| 后叶 | 中叶和侧叶的后方 | **肿瘤易发部位** |

肥大盯中叶和侧叶；肿瘤盯后叶。两套好发不要并成「后面那一叶什么都爱得」。
:::

:::definition{label="老年性前列腺肥大"}
中年以后腺部退化、结缔组织增生。肥大多在**中叶和侧叶**，压迫尿道 → 排尿困难甚至尿潴留。肥大时前列腺沟消失。
:::

:::pitfall{label="五叶是前、中、后加两侧叶，不要记成三叶"}
本版明确「前叶、中叶、后叶和两侧叶」。把两侧叶丢掉，或把后叶听成「中叶的背面别名」，肿瘤好发部位和肥大好发部位会对调。
:::

:::pitfall{label="肥大好发中叶和侧叶，肿瘤好发后叶，不要写反"}
中叶在尿道与射精管之间，侧叶在两侧，所以肥大容易挤尿道。后叶在中叶和侧叶后方，本版点名肿瘤易发。写反之后，指诊和排尿困难的解释会对不上。
:::

::figure{src="/images/anatomy/textbook/p0175_01.png" caption="图5-5　前列腺和射精管（纵切面）" alt="前列腺纵切：尿道内口、尿道前列腺部、尿道膜部、前列腺前叶、中叶和后叶、射精管，以及后方的精囊和输精管壶腹"}

图5-5 纵切把尿道前列腺部、射精管斜向前下、中叶夹在尿道与射精管之间一次看清；图5-6 横切把五叶围着尿道和一对射精管口摊开，后面正中是前列腺沟。

:::insight{label="中叶像楔子从后方插在尿道和射精管之间"}
肥大时楔子变厚，尿道被从后面抬起来，排尿先难。图5-5 看楔子的纵切，图5-6 看它在横切里围着尿道嵴和前列腺小囊。
:::

:::keypoint{label="前列腺先钉这几句"}
- 底邻膀胱颈，尖贴尿生殖膈；前耻骨联合，后直肠壶腹。
- 横径约 4 cm，前后径约 2 cm，垂直径约 3 cm；重 8～20 g。
- 五叶：前、中、后、两侧叶。肥大：中叶和侧叶。肿瘤：后叶。
- 尿道从底近前缘进、尖穿出；射精管从底后缘斜向前下，开口于精阜。
:::

### （六）尿道球腺

尿道球腺（bulbourethral gland）是一对豌豆大的球形腺体，位于会阴深横肌内。腺的输出管开口于尿道球部（见图5-3、图5-4）。尿道球腺的分泌物参与精液的组成，有利于精子的活动。

:::definition{label="尿道球腺"}
一对豌豆大的球形腺，位于**会阴深横肌**内。输出管开口于**尿道球部**。分泌物参与精液，利于精子活动。
:::

:::pitfall{label="尿道球腺开口于尿道球部，不要写成开口于膜部或前列腺部"}
腺本体在会阴深横肌内，开口却在海绵体部起始处的尿道球部。写成「开口于膜部」，会和后尿道的括约肌段搅在一起。
:::

:::compare{title="三对附属腺开口落在哪"}
| 腺 | 成对？ | 开口 |
|----|--------|------|
| 精囊 | 成对 | 排出管与输精管末端汇合成射精管，开口于尿道前列腺部精阜 |
| 前列腺 | **不成对** | 输出管开口于尿道前列腺部后壁、尿道嵴两侧 |
| 尿道球腺 | 成对 | 开口于尿道球部 |

前列腺是唯一不成对的附属腺。三个开口都进男性尿道，但不在同一段。
:::

## 二、男性外生殖器

男性外生殖器是阴囊和阴茎。阴囊容纳睾丸、附睾和精索下段；阴茎是交媾器官，尿道海绵体部走在它里面。被膜层次和海绵体配布是这一部分的正业。

### （一）阴囊

阴囊（scrotum）是位于阴茎后下方的皮肤囊袋，阴囊壁由皮肤和肉膜组成（图5-7）。皮肤薄而柔软，颜色较深，有少量阴毛；其皮脂腺分泌物有特殊气味。肉膜（dartos coat）为浅筋膜，与腹前外侧壁的 Scarpa 筋膜和会阴部的 Colles 筋膜相延续；内含平滑肌纤维，随外界温度变化而舒缩，以调节阴囊内的温度，有利于精子的发育与生存。阴囊皮肤表面沿中线有纵行的阴囊缝，对应的肉膜向深部发出阴囊中隔（septum of scrotum），将阴囊分为左、右两腔，容纳两侧的睾丸、附睾及精索等。

阴囊深面有包被睾丸和精索的被膜，由外向内依次为：①精索外筋膜（external spermatic fascia），为腹外斜肌腱膜的延续。②提睾肌（cremaster），来自腹内斜肌和腹横肌的肌纤维束。③精索内筋膜（internal spermatic fascia），为腹横筋膜的延续。④睾丸鞘膜（tunica vaginalis）来自腹膜，分为壁层和脏层；壁层紧贴精索内筋膜内面，脏层包贴睾丸和附睾表面；两层在睾丸后缘处返折移行；二者之间的腔隙即为鞘膜腔（vaginal cavity），内有少量浆液。

:::definition{label="阴囊"}
阴茎后下方的皮肤囊袋。壁 = **皮肤 + 肉膜**。容纳两侧睾丸、附睾及精索等。
:::

:::definition{label="肉膜"}
阴囊的浅筋膜，内含平滑肌。与腹前外侧壁 **Scarpa 筋膜**、会阴部 **Colles 筋膜** 相延续。随温度舒缩，调节阴囊内温度，利于精子发育与生存。
:::

:::definition{label="阴囊中隔"}
中线阴囊缝的深面，肉膜发向深部，把阴囊分成左、右两腔。不是「第三层筋膜」。
:::

:::definition{label="睾丸鞘膜与鞘膜腔"}
鞘膜来自腹膜，分壁层和脏层。壁层贴精索内筋膜内面，脏层包睾丸和附睾；两层在**睾丸后缘**返折。两层之间是鞘膜腔，内有少量浆液。
:::

:::compare{title="阴囊深面被膜（由外向内）与腹壁来源"}
| 层次（外 → 内） | 来源 |
|-----------------|------|
| 皮肤 + 肉膜 | 阴囊壁本身；肉膜 = 浅筋膜 |
| 精索外筋膜 | 腹外斜肌腱膜 |
| 提睾肌 | 腹内斜肌和腹横肌的肌纤维束 |
| 精索内筋膜 | 腹横筋膜 |
| 睾丸鞘膜（壁层 / 脏层） | 腹膜 |

精索表面那三层被膜（内筋膜、提睾肌、外筋膜）是同一组，只是书写方向相反。
:::

:::compare{title="两套「内外」不要抄反"}
| 写法 | 本版顺序 |
|------|----------|
| 精索被膜，从内向外 | 精索内筋膜 → 提睾肌 → 精索外筋膜 |
| 阴囊深面，由外向内 | 精索外筋膜 → 提睾肌 → 精索内筋膜 → 睾丸鞘膜 |

外筋膜永远更浅，内筋膜永远更深。鞘膜只包睾丸和附睾，不计入精索三层被膜。
:::

:::pitfall{label="肉膜是浅筋膜加平滑肌，不要把它写成提睾肌"}
提睾肌来自腹内斜肌和腹横肌，是阴囊深面的一层。肉膜在皮肤深面，管温度。把肉膜听成提睾肌，腹壁延续（Scarpa / Colles）和对温度的调节都会写错层次。
:::

:::cause-effect{title="为什么阴囊能帮精子存活"}
- **因** 肉膜平滑肌随外界温度舒缩，改变阴囊壁的松紧和散热
- **果** 阴囊内温度被调节到适合精子发育与生存的范围

这一笔解释的是肉膜，不是白膜，也不是前列腺囊。
:::

:::insight{label="从腹壁一层层掉进阴囊，名字换了，来源没换"}

- 壁 = 皮肤 + 肉膜（Scarpa / Colles 延续，平滑肌调温）。
- 中隔分左右腔。
- 外 → 内：外筋膜、提睾肌、内筋膜、鞘膜。
- 鞘膜腔在壁、脏两层之间，后缘返折。
:::

### （二）阴茎

阴茎（penis）为男性交媾器官，分为头、体和根三部分。阴茎根埋藏于阴囊和会阴部皮肤深面，固定在耻骨下支和坐骨支，为固定部。阴茎体呈圆柱形，被韧带悬于耻骨联合的前下方，为可动部。阴茎前端膨大称阴茎头（glans），尖端有呈矢状位裂隙的尿道外口（external orifice of urethra）。头与体交界的狭窄处称为阴茎颈。

阴茎由两条阴茎海绵体和一条尿道海绵体组成，呈圆柱状（图5-8）。阴茎海绵体（cavernous body of penis）为两端尖细的圆柱体，位于阴茎的背侧，左、右各一，两者紧密相连，前端嵌入阴茎头后面的凹陷内。阴茎海绵体后端称阴茎脚（crus of penis），分别附于两侧的耻骨下支和坐骨支。尿道海绵体（cavernous body of urethra）位于阴茎海绵体的腹侧，尿道贯穿其全长，前端膨大为阴茎头；后端扩大为尿道球（bulb of urethra），位于两侧的阴茎脚之间，外面包绕球海绵体肌，固定在尿生殖膈的下面。每个海绵体外面都被覆一层坚韧的纤维膜，称为海绵体白膜。海绵体内部由许多海绵体小梁和与血管相通的腔隙组成。当腔隙充血时，阴茎即变粗变硬而勃起。

阴茎的三个海绵体外面包裹深、浅筋膜和皮肤（图5-9）。深筋膜在阴茎前端逐渐变薄消失；在阴茎根处，深筋膜形成富含弹性纤维的阴茎悬韧带（suspensory ligament of penis），将阴茎悬吊于耻骨联合前面。浅筋膜疏松无脂肪组织。皮肤薄而柔软，颜色较深，富有伸展性。在阴茎颈前方，皮肤形成双层游离的环形皱襞包绕阴茎头，称为阴茎包皮（prepuce of penis）。包皮内层和阴茎头之间的窄隙称包皮腔，腔内常有包皮垢。包皮与阴茎头腹侧中线处连有一条皮肤皱襞，称包皮系带（frenulum of prepuce）。作包皮环切术时勿损伤该系带，以免影响阴茎的勃起。

幼儿包皮较长，包裹整个阴茎头。随着年龄的增长，包皮逐渐向后退缩，包皮口逐渐扩大，阴茎头显露于外。成年后，包皮覆盖阴茎头和尿道外口，但仍可上翻露出尿道外口和阴茎头的现象，称为包皮过长；因阴茎包皮与阴茎头粘连、包皮外口狭窄等，阴茎包皮不能外翻显露阴茎头及尿道外口的状态，称为包茎。

:::definition{label="阴茎"}
男性交媾器官。三部：**根**（固定部，埋于阴囊和会阴皮肤深面，附于耻骨下支和坐骨支）、**体**（可动部，悬于耻骨联合前下方）、**头**（前端膨大）。头尖端是矢状裂隙状的尿道外口；头与体交界狭窄处为阴茎颈。
:::

:::definition{label="阴茎海绵体"}
两端尖细的圆柱体，位于阴茎**背侧**，左、右各一，紧密相连；前端嵌入阴茎头后面的凹陷。后端是阴茎脚，分附两侧耻骨下支和坐骨支。
:::

:::definition{label="尿道海绵体"}
位于阴茎海绵体**腹侧**，尿道贯穿其全长。前端膨大为阴茎头；后端扩大为尿道球，在两侧阴茎脚之间，外包球海绵体肌，固定在尿生殖膈下面。
:::

:::definition{label="海绵体白膜与勃起"}
每个海绵体外面都有坚韧的纤维白膜。内部是小梁加与血管相通的腔隙。**腔隙充血** → 阴茎变粗变硬而勃起。
:::

:::compare{title="三条海绵体（2 + 1）"}
| | 位置 | 两端怎么收 |
|--|------|------------|
| 阴茎海绵体 ×2 | 背侧 | 前端嵌入阴茎头后面凹陷；后端 = 阴茎脚，附耻骨下支和坐骨支 |
| 尿道海绵体 ×1 | 腹侧 | 前端 = 阴茎头；后端 = 尿道球（两脚之间，尿生殖膈下面） |

尿道走在腹侧那一条里，不走背侧那一对。图5-8 把三条拆开再拼回去。
:::

:::definition{label="阴茎悬韧带"}
阴茎根处，深筋膜形成、富含弹性纤维，把阴茎悬吊于**耻骨联合前面**。深筋膜在阴茎前端逐渐变薄消失。
:::

:::definition{label="阴茎包皮"}
阴茎颈前方、皮肤形成的双层游离环形皱襞，包绕阴茎头。内层与阴茎头之间是包皮腔，常有包皮垢。
:::

:::definition{label="包皮系带"}
包皮与阴茎头**腹侧中线**的一条皮肤皱襞。包皮环切术时**勿损伤**该系带，以免影响勃起。
:::

:::definition{label="包皮过长与包茎"}
包皮过长：成年后包皮仍覆盖阴茎头和尿道外口，但**可上翻**显露。包茎：粘连或包皮外口狭窄，**不能外翻**显露阴茎头及尿道外口。能否上翻是分界。
:::

:::pitfall{label="两条海绵体在背侧，一条尿道海绵体在腹侧，不要把背腹写反"}
本版：阴茎海绵体在背侧，尿道海绵体在腹侧。图5-9 水平切面上，一对阴茎海绵体在上（背），尿道海绵体带着尿道在下（腹）。写反之后，阴茎深动脉和尿道的位置全错。
:::

:::pitfall{label="包皮过长还能翻上去，包茎翻不上去，不要并成一个词"}
本版把「仍可上翻」和「不能外翻」分开写。把包茎听成「包皮有点长」，手术指征和能否显露尿道外口会对不上。
:::

:::pitfall{label="环切不要伤包皮系带"}
系带在腹侧中线。损伤后影响勃起。这一笔是本版写在包皮段的手术形态，不是把系带听成「可有可无的皱襞」。
:::

::figure{src="/images/anatomy/textbook/p0177_01.png" caption="图5-8　阴茎的海绵体" alt="三图：左侧为成对阴茎海绵体及阴茎脚、尿道；中为尿道海绵体，标尿道外口、阴茎头和尿道球；右侧为二者会合，可见尿道球、尿道海绵体和阴茎海绵体"}

::figure{src="/images/anatomy/textbook/p0177_02.png" caption="图5-9　阴茎中部水平切面" alt="阴茎中部水平切面：皮肤、阴茎浅筋膜、阴茎深筋膜；背侧为阴茎背浅静脉、阴茎背深静脉、阴茎背动脉和神经；一对阴茎海绵体及其中的阴茎深动脉、阴茎中隔；腹侧尿道海绵体及其内的尿道；各海绵体外为海绵体白膜"}

:::insight{label="横切面先认「背上两块、腹下一块，尿在那一块里」"}
图5-9：一对阴茎海绵体并排，各有一条阴茎深动脉；腹侧尿道海绵体里才是尿道。血管神经走在背侧浅、深筋膜之间。认面比认名先。
:::

:::keypoint{label="阴茎三句话"}
- 根固定、体可动、头有矢状裂隙状外口。
- 背侧两条阴茎海绵体 + 腹侧一条尿道海绵体；腔隙充血即勃起。
- 包皮、包皮腔、系带；过长可翻，包茎不能翻；环切勿伤系带。
:::

## 三、男性尿道

男性尿道（male urethra）兼具排精和排尿的功能，起自膀胱的尿道内口，止于阴茎头的尿道外口。成人尿道管径平均为 5～7 mm，长为 16～22 cm；分前列腺部、膜部和海绵体部三部分（图5-10）。临床上将尿道前列腺部和膜部合称为后尿道，海绵体部称为前尿道。

:::definition{label="男性尿道"}
兼具**排精和排尿**。起自膀胱的尿道内口，止于阴茎头的尿道外口。成人管径平均 **5～7 mm**，长 **16～22 cm**。
:::

:::definition{label="男性尿道三部"}
按穿过的结构：**前列腺部、膜部、海绵体部**。不要把舟状窝或球部另算成第四部——它们是海绵体部里的膨大。
:::

:::definition{label="后尿道与前尿道"}
后尿道 = **前列腺部 + 膜部**。前尿道 = **海绵体部**。前、后不是「内口以前、外口以后」，是临床按穿过前列腺和尿生殖膈来切。
:::

:::compare{title="三部的长度和临床前后"}
| 部 | 穿过 | 本版长度 | 临床 |
|----|------|----------|------|
| 前列腺部 | 前列腺 | 约 3 cm | 后尿道 |
| 膜部 | 尿生殖膈 | 约 **1.5 cm** | 后尿道 |
| 海绵体部 | 尿道海绵体 | 约 **12～17 cm** | 前尿道 |

全长 16～22 cm 是三部加在一起。管径 5～7 mm 是平均值，狭窄和膨大另记。
:::

:::pitfall{label="后尿道是前列腺部加膜部，不要把海绵体部算进后尿道"}
本版：前列腺部 + 膜部 = 后尿道；海绵体部 = 前尿道。把球部、舟状窝算进后尿道，三狭窄三膨大的位置会整段后移。
:::

:::pitfall{label="管径按 5～7 mm、长度按 16～22 cm，不要改成一个定点"}
本版同时给了范围。只记「大约 20 cm」或把 5～7 mm 改成 1 cm，和导尿、结石嵌顿用的口径对不上。
:::

### （一）前列腺部

前列腺部（prostatic urethra）是尿道穿行于前列腺内的一段，长约 3 cm。后壁有一纵行隆起称为尿道嵴（urethral ridge），嵴中部隆起称为精阜（seminal colliculus）。精阜中央小凹称为前列腺小囊（prostatic utricle），两侧各有一个细小的射精管口。精阜两侧的尿道黏膜上有许多细小的前列腺输出管的开口。

:::definition{label="尿道前列腺部"}
尿道穿过前列腺的一段，长约 **3 cm**。男性尿道在前列腺底近前缘处进入，经实质前部下行，由前列腺尖穿出。
:::

:::definition{label="尿道嵴、精阜与前列腺小囊"}
后壁纵行隆起是尿道嵴；嵴中部隆起是精阜。精阜中央小凹是前列腺小囊；小囊**两侧**各有一个射精管口。精阜两侧黏膜上还有许多前列腺输出管开口。
:::

:::compare{title="前列腺部后壁上开了哪些口"}
| 结构 | 开口位置 |
|------|----------|
| 射精管 | 精阜上，前列腺小囊两侧各一 |
| 前列腺输出管 | 尿道嵴两侧黏膜，许多细小开口 |
| 前列腺小囊 | 精阜中央小凹（是凹，不是第三条射精管） |

排精进入尿道的第一站在这一段，不在膜部。
:::

:::pitfall{label="射精管口在精阜两侧，不要写成开在前列腺小囊里"}
小囊是中央小凹；射精管口在它两侧。把小囊听成「射精管的总开口」，精阜上的两个细口就没了。
:::

### （二）膜部

膜部（membranous part of urethra）是穿过尿生殖膈的一段，长约 1.5 cm。周围有属于横纹肌的尿道外括约肌环绕，该肌有控制排尿的作用。膜部位置比较固定，当骨盆骨折时，易损伤此部。临床上把前列腺部和膜部合称后尿道。

:::definition{label="尿道膜部"}
尿道穿过**尿生殖膈**的一段，长约 **1.5 cm**。周围有横纹肌的**尿道外括约肌**环绕，控制排尿。位置较固定。
:::

:::cause-effect{title="为什么骨盆骨折容易伤膜部"}
- **因** 膜部穿尿生殖膈，被固定在这段较短的膈里，周围没有海绵体那样的可位移缓冲
- **果** 骨盆骨折时此部易损伤

海绵体部随阴茎可动，前列腺部包在腺实质里；固定而短的是膜部。
:::

:::pitfall{label="膜部约 1.5 cm，不要写成 15 cm，也不要和海绵体部 12～17 cm 对调"}
1.5 cm 是穿过尿生殖膈的短段。写成 15 cm 会把膜部听成前尿道的主体；和 12～17 cm 对调之后，前、后尿道的长度关系全反。
:::

:::insight{label="膜部又短又固定，所以既是括约肌段，也是骨折的薄弱段"}
外括约肌环绕于此，控制排尿；同一段被尿生殖膈钉住，骨盆骨折就先伤这里。图5-1、图5-10 里它夹在前列腺尖和尿道球之间。
:::

### （三）海绵体部

海绵体部（cavernous part of urethra）是穿过尿道海绵体的一段，长约 12～17 cm，临床上称为前尿道。在尿道海绵体尿道球内的尿道最宽，称尿道球部，尿道球腺开口于此。阴茎头内的尿道扩大成尿道舟状窝（navicular fossa of urethra）。

:::definition{label="尿道海绵体部"}
尿道穿过尿道海绵体的一段，长约 **12～17 cm**，即临床**前尿道**。起自尿生殖膈下方，止于尿道外口。
:::

:::definition{label="尿道球部与舟状窝"}
球部：尿道球内的一段，是海绵体部里**最宽**处，尿道球腺开口于此。舟状窝：阴茎头内尿道的扩大。两者都是膨大，不是独立的「第 4、第 5 部」。
:::

:::compare{title="海绵体部里的宽和窄"}
| 段 | 本版 |
|----|------|
| 尿道球部 | 最宽；球腺开口 |
| 中间份 | 走在尿道海绵体干内 |
| 舟状窝 | 阴茎头内扩大 |
| 尿道外口 | 矢状裂隙，全尿道最窄 |

宽的是球部和舟状窝，最窄的是外口。不要把「最宽」和「最窄」都安在外口上。
:::

尿道有三个狭窄、三个膨大和两个弯曲（见图5-1，图5-10）。三个狭窄分别是尿道内口、尿道膜部和尿道外口。其中，尿道外口最窄，呈矢状裂隙。尿道结石易嵌顿在这些狭窄部位。三个膨大是尿道前列腺部、尿道球部和尿道舟状窝。两个弯曲为：①凸向下后方、位于耻骨联合下方 2 cm 处恒定的耻骨下弯（subpubic curvature），包括尿道的前列腺部、膜部和海绵体部的起始段；②凸向上前方、位于耻骨联合前下方阴茎根与阴茎体之间的耻骨前弯（prepubic curvature），阴茎勃起或将阴茎向上提起时，此弯曲变直而消失。临床上行膀胱镜检查或导尿时应注意这些解剖特点。

:::definition{label="男性尿道三狭窄"}
**尿道内口、尿道膜部、尿道外口**。外口最窄，呈**矢状裂隙**。结石易嵌顿在这三处。
:::

:::definition{label="男性尿道三膨大"}
**尿道前列腺部、尿道球部、尿道舟状窝**。前列腺部既是一部，也是一处膨大；球部和舟状窝是海绵体部里的膨大。
:::

:::definition{label="耻骨下弯"}
凸向**下后方**，位于耻骨联合下方 **2 cm**，**恒定**。包括前列腺部、膜部和海绵体部起始段。勃起或上提阴茎时它不会消失。
:::

:::definition{label="耻骨前弯"}
凸向**上前方**，位于耻骨联合前下方、阴茎根与阴茎体之间。阴茎勃起或将阴茎向上提起时，此弯**变直而消失**。
:::

:::compare{title="三狭窄、三膨大、两弯曲（本版钉死）"}
| 套 | 本版名单 | 最要记住的一笔 |
|----|----------|----------------|
| 三狭窄 | 内口、膜部、外口 | 外口最窄，矢状裂隙；结石易嵌顿 |
| 三膨大 | 前列腺部、球部、舟状窝 | 球部是海绵体部最宽处 |
| 耻骨下弯 | 凸向下后方；耻骨联合下方 2 cm | 恒定；前列腺部 + 膜部 + 海绵体起始 |
| 耻骨前弯 | 凸向上前方；根与体之间 | 可消失（勃起或上提阴茎） |

狭窄不要写成「内口、外口、舟状窝」。舟状窝是膨大。
:::

:::compare{title="两弯的凸向和能不能变直"}
| | 凸向 | 位置 | 能否消失 |
|--|------|------|----------|
| 耻骨下弯 | 下后方 | 耻骨联合下方 2 cm | **不能**，恒定 |
| 耻骨前弯 | 上前方 | 耻骨联合前下方，阴茎根与体之间 | **能**，勃起或上提时变直 |

导尿、膀胱镜要顺着这两弯走：能变直的先变直，恒定的那一弯必须记住凸向下后方。
:::

:::timeline{period="从内口走到外口"}
- **尿道内口** 第一处狭窄，出膀胱
- **前列腺部** 约 3 cm；膨大；精阜、射精管口
- **膜部** 约 1.5 cm；第二处狭窄；外括约肌；骨盆骨折易伤
- **尿道球部** 海绵体部起始，最宽；球腺开口；进入耻骨下弯的海绵体起始段
- **海绵体部干** 前尿道主体，12～17 cm 的大部分
- **舟状窝** 阴茎头内膨大
- **尿道外口** 第三处狭窄，最窄，矢状裂隙
:::

:::pitfall{label="三狭窄是内口、膜部、外口，不要把舟状窝或球部写成狭窄"}
舟状窝和球部是膨大。写成「内口、外口、舟状窝」会少掉膜部这条骨折好发的狭窄，还把一处膨大错当成最窄段之一。
:::

:::pitfall{label="外口最窄而且是矢状裂隙，不要写成膜部最窄"}
本版原句：尿道外口最窄，呈矢状裂隙。膜部是三狭窄之一，但「最窄」这一顶帽子给外口。导尿器械的通过难度按外口来记。
:::

:::pitfall{label="耻骨下弯恒定，耻骨前弯可消失，不要写反"}
下弯在耻骨联合下方 2 cm，包括后尿道加海绵体起始，凸向下后方，变不直。前弯在根与体之间，凸向上前方，上提或勃起就消失。写反之后，导尿时该提起阴茎的动作会用错弯。
:::

:::cause-effect{title="为什么导尿或膀胱镜要把阴茎向上提起"}
- **因** 耻骨前弯在根与体之间、凸向上前方，上提或勃起时变直消失；耻骨下弯恒定，仍凸向下后方
- **果** 提起阴茎后只剩一个恒定的下弯，器械沿下弯走行，避免在可消失的那一弯里顶穿

临床上要注意三狭窄、三膨大和两弯曲，依据就是这套形态。
:::

:::note{label="本节止于男性尿道的弯曲"}
女性生殖系统的卵巢、管道和女阴是第二节的户头。男性尿道写完三部、三狭窄、三膨大和两弯曲，这一户就收口。
:::

:::keypoint{label="尿道数字和名单"}
- 管径 5～7 mm，长 16～22 cm。
- 三部：前列腺部约 3 cm、膜部约 1.5 cm、海绵体部 12～17 cm。
- 后尿道 = 前列腺部 + 膜部；前尿道 = 海绵体部。
- 三狭窄：内口、膜部、外口（最窄，矢状裂隙）。
- 三膨大：前列腺部、球部、舟状窝。
- 耻骨下弯恒定（耻骨联合下方 2 cm，凸向下后方）；耻骨前弯可消失。
- 骨盆骨折易伤膜部。
:::

:::memory{label="本节必背要点"}
- [ ] 生殖系统：繁殖后代，形成并保持第二性征。内生殖器 = 生殖腺 + 管道 + 附属腺；外生殖器以交媾器官为主。
- [ ] 男性内生殖器：睾丸；附睾、输精管、射精管、男性尿道；精囊、前列腺、尿道球腺。外生殖器：阴囊、阴茎。
- [ ] 睾丸：阴囊内成对，左侧略低；单侧约 10～15 g。前缘游离，后缘连附睾。白膜后缘增厚成纵隔 → 小隔 → 100～200 小叶；每小叶 2～4 条生精小管。间质细胞分泌雄性激素。
- [ ] 生精小管 → 精直小管 → 睾丸网 → **12～15** 条输出小管入附睾。
- [ ] 附睾：新月形，头、体、尾。附睾管约 4～6 m。贮存、营养并促进精子成熟。
- [ ] 输精管约 50 cm、管径约 0.3 cm，壁厚腔窄。四部：睾丸部、精索部、腹股沟管部、盆部。结扎选精索部。跨输尿管末端前内方，成壶腹。
- [ ] 精索：睾丸上端至腹环。内容含输精管、睾丸动脉、蔓状静脉丛等。被膜内→外：内筋膜、提睾肌、外筋膜。
- [ ] 射精管约 2 cm，穿前列腺，开口于尿道前列腺部精阜。
- [ ] 精囊：膀胱底后方、壶腹下外侧，排出管参与组成射精管。
- [ ] 前列腺：底邻膀胱颈，尖贴尿生殖膈；前耻骨联合，后直肠壶腹。垂直径约 3 cm，横径约 4 cm，前后径约 2 cm，重 8～20 g。五叶：前、中、后、两侧叶。肥大：中叶和侧叶。肿瘤：后叶。沟可指诊，肥大时消失。
- [ ] 尿道球腺：会阴深横肌内，开口于尿道球部。
- [ ] 阴囊壁 = 皮肤 + 肉膜（Scarpa / Colles，平滑肌调温）。外→内：外筋膜、提睾肌、内筋膜、鞘膜。鞘膜腔在后缘返折。
- [ ] 阴茎：根、体、头。背侧两条阴茎海绵体 + 腹侧一条尿道海绵体。腔隙充血即勃起。包皮过长可翻，包茎不能翻；环切勿伤系带。
- [ ] 男性尿道：5～7 mm，16～22 cm。三部：前列腺部约 3 cm、膜部约 1.5 cm、海绵体部 12～17 cm。后尿道 = 前列腺部 + 膜部；前尿道 = 海绵体部。
- [ ] 三狭窄：内口、膜部、外口（最窄，矢状裂隙）。三膨大：前列腺部、球部、舟状窝。耻骨下弯恒定（耻骨联合下方 2 cm）；耻骨前弯可消失。骨盆骨折易伤膜部。
:::
