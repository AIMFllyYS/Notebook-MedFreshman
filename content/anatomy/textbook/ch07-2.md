# 第二节　淋巴系统

脉管系统包括心血管系统和淋巴系统。第一节已经把心、动脉、毛细血管和静脉写完；本节把「淋巴系统」这一户写完：淋巴管道、淋巴组织和淋巴器官，以及各部淋巴结的位置和部分器官的引流。静脉干、门腔吻合、表 7-4 属于上一节，不要再抄一遍。

淋巴系统（lymphatic system）由淋巴管道、淋巴组织和淋巴器官组成（图7-65）。淋巴管道和淋巴结的淋巴窦内含有淋巴液，简称为淋巴（lymph）。自小肠绒毛中的中央乳糜池至胸导管的淋巴管道中的淋巴因含乳糜微粒呈白色，其他部位的淋巴管道中的淋巴无色透明。血液流经毛细血管动脉端时，一些成分经毛细血管壁进入组织间隙，形成组织液。组织液与细胞进行物质交换后，大部分（约 90%）经毛细血管静脉端回流入静脉，小部分（约 10%）水分以及大分子物质进入毛细淋巴管，形成淋巴液。淋巴液沿淋巴管和淋巴结的淋巴窦向心流动，最后汇入静脉。因此，淋巴系统是心血管系统的辅助系统，其功能是协助静脉引流组织液。同时，淋巴器官和淋巴组织具有产生淋巴细胞、过滤淋巴液和进行免疫应答的功能。此外，淋巴系统可吸收消化系统中的脂肪和脂溶性维生素，并将其运送到静脉循环。

:::definition{label="淋巴系统"}
由**淋巴管道、淋巴组织和淋巴器官**组成。管道最后汇入静脉，是静脉的辅助管道；器官和组织负责产生淋巴细胞、过滤淋巴和免疫应答，并吸收脂肪及脂溶性维生素。
:::

:::definition{label="淋巴"}
淋巴管道和淋巴结淋巴窦内的液体。小肠绒毛中央乳糜池至胸导管这一段因含乳糜微粒呈白色，其余部位无色透明。不要把「淋巴」听成「就是淋巴结」。
:::

:::concept{term="先问这 10% 进了哪根管子，再问有没有把静脉回流表抄进来"}
组织液约 90% 回静脉、约 10% 进毛细淋巴管，最后仍汇入静脉——这是本节的总账。把「脉管系统」听成「就是心血管」，淋巴干和胸导管会从开篇丢掉；把表 7-4 静脉回流再贴一遍，又是吞了上一节。
:::

:::compare{title="脉管两户（本章两节各守一户）"}
| | 第一节 | 本节 |
|--|--------|------|
| 户头 | 心血管系统 | 淋巴系统 |
| 管道里走什么 | 血液 | 淋巴 |
| 组织液去向 | 约 90% 经毛细血管静脉端回静脉 | 约 10% 进毛细淋巴管 |
| 终点 | 循环不息 | 汇入静脉，是静脉的辅助管道 |

本节名单从毛细淋巴管写到胸导管、淋巴结群和器官引流。不要把心、动脉、门静脉提前写进来。
:::

## 一、概述

### （一）淋巴管道

淋巴管道按口径从细到粗依次是毛细淋巴管、淋巴管、淋巴干和淋巴导管。

**1. 毛细淋巴管（lymphatic capillary）**　以膨大的盲端起始，互相吻合成毛细淋巴管网，然后汇入淋巴管（图7-66）。管壁由很薄的内皮细胞构成，基膜不完整。内皮细胞间隙较大，外面有纤维细丝牵拉，使管腔处于扩张状态。因此通透性较大，蛋白质、细胞碎片、脂类、细菌和肿瘤细胞等容易进入。恶性肿瘤细胞经淋巴管道转移是恶性肿瘤转移的常见途径。上皮、角膜、晶状体、软骨、胎盘、脊髓等处无毛细淋巴管。

:::definition{label="毛细淋巴管"}
以膨大的**盲端**起始，吻合成网后汇入淋巴管。内皮薄、基膜不完整、间隙大，纤维细丝把它拉开，所以蛋白质、细胞碎片、脂类、细菌和肿瘤细胞都进得去。
:::

::figure{src="/images/anatomy/textbook/p0248_02.png" caption="图7-66　毛细淋巴管的结构" alt="内皮细胞围成盲端管腔，细胞间隙较大，外侧有纤维细丝牵拉使管腔扩张"}

:::pitfall{label="无毛细淋巴管的名单，不要抄成无毛细血管"}
本节原句：**上皮、角膜、晶状体、软骨、胎盘、脊髓**。上一节无毛细血管是角膜、晶状体、毛发、软骨、牙釉质、被覆上皮。毛发、牙釉质在毛细血管名单里，胎盘、脊髓在毛细淋巴管名单里。两张表不要并成一张。
:::

:::pitfall{label="小肠绒毛里的中央乳糜池，不是第 1 腰椎前方的乳糜池"}
开篇「中央乳糜池」在小肠绒毛里，乳糜微粒从这里进淋巴管。后文乳糜池（cisterna chyli）在第 1 腰椎前方，是胸导管的起点囊。一个在肠绒毛，一个在腹后壁，不要写成同一个膨大。
:::

**2. 淋巴管（lymphatic vessel）**　由毛细淋巴管汇合而成，淋巴结串联其中（图7-67）。结构与静脉相似，内有很多单向开放的瓣膜，可防止淋巴液逆流。相邻两对瓣膜之间的管段扩张明显，外观呈串珠状或藕节状。淋巴管分浅、深两类：浅淋巴管位于浅筋膜内，与浅静脉伴行；深淋巴管位于深筋膜深面，多与血管、神经伴行。浅、深淋巴管之间交通丰富。

:::definition{label="淋巴管"}
毛细淋巴管汇合而成，淋巴结串联在路上。瓣膜单向开放，外观串珠状或藕节状。浅的走浅筋膜、伴浅静脉；深的走深筋膜深面、伴血管神经。
:::

:::compare{title="浅淋巴管与深淋巴管"}
| | 位置 | 伴行 | 交通 |
|--|------|------|------|
| 浅淋巴管 | 浅筋膜内 | 浅静脉 | 与深淋巴管交通丰富 |
| 深淋巴管 | 深筋膜深面 | 多与血管、神经伴行 | 同上 |

两类不要写成「互不相通」。交通支是后文淋巴侧支循环的形态底板。
:::

**3. 淋巴干（lymphatic trunk）**　全身各部的淋巴管经过一系列淋巴结群中继后，在膈下和颈根部等处汇合成淋巴干（图7-67）。全身共 **9** 条淋巴干：成对的腰干、支气管纵隔干、锁骨下干、颈干，和不成对的肠干。

:::definition{label="淋巴干"}
淋巴结群中继之后、淋巴导管之前的 9 条干。成对四色：**腰干、支气管纵隔干、锁骨下干、颈干**；不成对一条：**肠干**。不要写成 8 条或 10 条，也不要把肠干听成成对。
:::

:::compare{title="9 条淋巴干（本版名单）"}
| 干 | 成对？ | 随后汇入 |
|----|--------|----------|
| 腰干 | 成对 | 乳糜池 → 胸导管 |
| 肠干 | 不成对 | 乳糜池 → 胸导管 |
| 支气管纵隔干 | 成对 | 左侧入胸导管，右侧入右淋巴导管 |
| 锁骨下干 | 成对 | 同上 |
| 颈干 | 成对 | 同上 |

先数 4 对 + 1 条 = 9。肠干只有一条，不要给它配成左右两条。
:::

**4. 淋巴导管（lymphatic duct）**　淋巴干汇合成胸导管和右淋巴导管，分别注入左、右静脉角（图7-67、图7-68）。此外，少数淋巴管注入盆腔静脉、肾上腺静脉、肾静脉和下腔静脉等。

:::definition{label="淋巴导管"}
两条：胸导管注入**左静脉角**，右淋巴导管注入**右静脉角**。干汇成导管，导管进静脉角——这是淋巴回血的总出口。
:::

::figure{src="/images/anatomy/textbook/p0249_01.png" caption="图7-67　淋巴管和淋巴干" alt="胸导管起自乳糜池，收肠干和左、右腰干，上行注入左静脉角，并收左颈干、左锁骨下干、左支气管纵隔干；右淋巴导管收右颈干等注入右静脉角"}

胸导管（thoracic duct）是全身最大的淋巴管，于平**第 12 胸椎下缘**高度起自乳糜池（cisterna chyli），经主动脉裂孔进入胸腔。沿脊柱右前方、胸主动脉与奇静脉之间上行，至第 5 胸椎高度经食管与脊柱之间向左侧斜行，再沿脊柱左前方上行，经胸廓上口至颈部。在左颈总动脉和左颈内静脉的后方转向前内下方，注入左静脉角。胸导管末端有一对瓣膜，可阻止静脉血逆流入胸导管。在标本上，胸导管末段常含有血液，外观似静脉。

乳糜池位于第 1 腰椎前方，呈囊状膨大，接受左、右腰干和肠干的淋巴。胸导管在注入左静脉角处接受左颈干、左锁骨下干和左支气管纵隔干。胸导管引流下肢、盆部、腹部、左上肢、左胸部和左头颈部等全身约 3/4 部位的淋巴。胸导管与肋间淋巴结、纵隔后淋巴结、气管支气管淋巴结和左锁骨上淋巴结之间存在广泛的淋巴侧支通路，胸导管内的肿瘤细胞可转移至以上淋巴结。胸导管常发出较细的侧支注入奇静脉和肋间后静脉等，故手术误伤胸导管末段后结扎时一般不会引起淋巴水肿。

右淋巴导管（right lymphatic duct）长 **1.0～1.5 cm**，由右颈干、右锁骨下干和右支气管纵隔干汇合而成，注入右静脉角。引流右上肢、右胸部和右头颈部的淋巴，即全身约 1/4 部位的淋巴。右淋巴导管与胸导管之间存在着交通。

:::definition{label="胸导管"}
全身最大的淋巴管。平**第 12 胸椎下缘**起自乳糜池，穿主动脉裂孔入胸腔，先走脊柱右前方（胸主动脉与奇静脉之间），平第 5 胸椎向左斜，再沿脊柱左前方上行，注入**左静脉角**。末端有一对瓣膜，阻止静脉血倒灌。
:::

:::definition{label="乳糜池"}
第 **1** 腰椎前方的囊状膨大，接受**左、右腰干和肠干**。它是胸导管的起点，不是小肠绒毛里的那一截。
:::

:::definition{label="右淋巴导管"}
长 **1.0～1.5 cm**。由**右颈干、右锁骨下干、右支气管纵隔干**合成，注入**右静脉角**。只收全身约 1/4：右上肢、右胸部、右头颈部。
:::

:::compare{title="表7-5　全身淋巴引流概况"}
| 导管 | 收纳的干 | 引流范围 | 注入 |
|------|----------|----------|------|
| 胸导管 | 乳糜池收左、右腰干和肠干；末端再收左颈干、左锁骨下干、左支气管纵隔干 | 下肢、盆部、腹部、左上肢、左胸部、左头颈部（约 3/4） | 左静脉角 |
| 右淋巴导管 | 右颈干、右锁骨下干、右支气管纵隔干 | 右上肢、右胸部、右头颈部（约 1/4） | 右静脉角 |

两侧不对称：左边一条大干收 3/4，右边一条短导管收 1/4。两条导管之间有交通。
:::

:::pitfall{label="胸导管起于 T12 下缘，乳糜池在 L1 前方，不要写成同一个椎体"}
起点高度是第 12 胸椎下缘；乳糜池坐在第 1 腰椎前方。写成「胸导管起自 L1」或「乳糜池平 T12」，起点和膨大会错位一节椎骨。
:::

:::pitfall{label="胸导管进左静脉角，不要写成进上腔静脉或右静脉角"}
末端在左颈总动脉和左颈内静脉后方转向前内下，注入左静脉角。右淋巴导管才进右静脉角。标本末段常含血液、看起来像静脉，那是倒灌被瓣膜挡住后的外观，不是它改名成了静脉。
:::

:::insight{label="结扎胸导管末段，一般不会淋巴水肿"}
胸导管常发细侧支注入奇静脉和肋间后静脉，和肋间、纵隔后、气管支气管、左锁骨上淋巴结还有侧支通路。末段误伤后结扎，淋巴还能绕道。反过来，这些侧支也是肿瘤细胞从胸导管跳到上述淋巴结的路。
:::

### （二）淋巴组织

淋巴组织分为弥散淋巴组织和淋巴小结两类。除淋巴器官外，消化、呼吸、泌尿和生殖管道及皮肤等处均含有丰富的淋巴组织，起防御屏障的作用。

1. **弥散淋巴组织**　主要位于消化道和呼吸道的黏膜固有层。
2. **淋巴小结**　包括小肠黏膜固有层内的孤立淋巴滤泡、集合淋巴滤泡及阑尾壁内的淋巴小结等。

:::definition{label="淋巴组织"}
两类：弥散淋巴组织（消化道、呼吸道黏膜固有层为主）和淋巴小结（孤立淋巴滤泡、集合淋巴滤泡、阑尾壁内小结）。它们不是独立器官，不要加成「第五个淋巴器官」。
:::

:::compare{title="淋巴组织两型"}
| | 本版位置 |
|--|----------|
| 弥散淋巴组织 | 消化道和呼吸道黏膜固有层为主 |
| 淋巴小结 | 小肠孤立/集合淋巴滤泡，阑尾壁内淋巴小结 |

管道黏膜里的这些组织是屏障，淋巴结、胸腺、脾、扁桃体才是器官。
:::

### （三）淋巴器官

淋巴器官包括淋巴结、胸腺、脾和扁桃体。

:::definition{label="淋巴器官"}
本版四件：**淋巴结、胸腺、脾和扁桃体**。胸腺是中枢淋巴器官；脾是人体最大的淋巴器官。扁桃体的形态已在消化管写过，本节不重开户。
:::

淋巴结（lymph node）为大小不一的圆形或椭圆形灰红色小体，一侧隆凸，另一侧凹陷，凹陷中央处为淋巴结门（图7-69）。凸侧连有数条输入淋巴管（afferent lymphatic vessel）；淋巴结门有输出淋巴管（efferent lymphatic vessel）、神经和血管出入。一个淋巴结的输出淋巴管可成为另一个淋巴结的输入淋巴管。淋巴结多成群分布，数目不恒定，青年人约有 **400～450** 个。按位置分为浅淋巴结和深淋巴结：浅淋巴结（superficial lymph node）位于浅筋膜内，深淋巴结（deep lymph node）位于深筋膜深面。淋巴结多沿血管排列，位于关节屈侧和体腔的隐藏部位，如肘窝、腋窝、腘窝、腹股沟、脏器门和体腔大血管附近。直径多为 0.2～0.5 cm，不易触及。可触到的淋巴结（如腹股沟浅淋巴结）质地柔软，表面光滑，与周围组织无粘连。主要功能是滤过淋巴、产生淋巴细胞和进行免疫应答。淋巴结内的淋巴窦是淋巴管道的组成部分，故淋巴结对于淋巴引流起着重要作用。

引流某一器官或部位淋巴的第一级淋巴结称局部淋巴结（regional lymph node），临床通常称哨位淋巴结（sentinel lymph node）。当某器官或部位发生病变时，细菌、毒素、寄生虫或肿瘤细胞可沿淋巴管进入相应的局部淋巴结；如将该淋巴结进行阻截和清除，从而阻止病变扩散，临床称之为淋巴结清扫。此时淋巴结发生细胞增殖等病理变化，致淋巴结肿大。如果局部淋巴结不能阻止病变的扩散，病变可沿淋巴管道向远处蔓延转移。因此，局部淋巴结肿大常反映其引流范围存在病变。了解淋巴结的位置、淋巴引流范围和途径，对于病变的诊断和治疗具有重要意义。甲状腺、食管和肝的部分淋巴管不经过淋巴结，直接注入胸导管，这可使肿瘤细胞更容易迅速向远处转移。

:::definition{label="淋巴结"}
灰红色圆形或椭圆形小体。凸侧进**输入淋巴管**，门里出**输出淋巴管**（兼神经血管）。青年人约 400～450 个，多成群、沿血管，藏在关节屈侧和体腔隐蔽处。功能：滤过淋巴、产生淋巴细胞、免疫应答。
:::

:::definition{label="局部淋巴结（哨位淋巴结）"}
引流某一器官或部位淋巴的**第一级**淋巴结。临床称哨位淋巴结。肿大常反映其引流范围有病变；清扫是把这一级拦下来。不是「全身最大的那一枚」。
:::

::figure{src="/images/anatomy/textbook/p0251_01.png" caption="图7-69　淋巴结" alt="淋巴结剖面：凸侧多条输入淋巴管进入，被膜和小梁伸入实质，门部有输出淋巴管走出"}

:::compare{title="浅淋巴结与深淋巴结"}
| | 位置 | 本版例子 |
|--|------|----------|
| 浅淋巴结 | 浅筋膜内 | 腹股沟浅淋巴结、颈外侧浅淋巴结 |
| 深淋巴结 | 深筋膜深面 | 腹股沟深淋巴结、颈外侧深淋巴结 |

可触及时应柔软、光滑、无粘连。质硬、固定是另一笔病理账，不是正常形态。
:::

:::compare{title="输入淋巴管与输出淋巴管"}
| | 进出 | 条数 |
|--|------|------|
| 输入淋巴管 | 凸侧进入 | 数条 |
| 输出淋巴管 | 淋巴结门走出 | 与神经、血管同行；可成为下一枚淋巴结的输入管 |

淋巴在结内走淋巴窦。把输入、输出听成「动脉进、静脉出」，方向就和血管搞反了。
:::

:::pitfall{label="甲状腺、食管、肝的部分淋巴管可以不经过淋巴结"}
本版原句：这三处部分淋巴管直接注入胸导管，肿瘤细胞更容易迅速向远处转移。写成「所有器官淋巴都必须先过哨位结」，这三户的跳跃转移就没有形态依据。
:::

在安静状态下，每小时约有 **120 ml** 淋巴回流入血液，每天回流的淋巴相当于全身血浆总量。淋巴流动缓慢，流量约是静脉的 1/10。远近相邻两对瓣膜之间的淋巴管段构成「淋巴管泵」，通过平滑肌的收缩和瓣膜的开闭，推动淋巴向心流动。淋巴管周围的动脉搏动、肌肉收缩和胸腔负压对于淋巴回流有促进作用。运动和按摩有助于改善淋巴回流功能。如果淋巴回流受阻，大量含蛋白质的组织液不能及时被吸收，可导致局部淋巴水肿，压迫体表组织后**不出现凹陷**。

淋巴管间的交通支丰富，参与构成淋巴侧支循环。当炎症、寄生虫、异物或肿瘤栓子致淋巴管阻塞，外伤或手术切断淋巴管时，淋巴经交通支回流，形成淋巴侧支循环，从而保证淋巴回流。外伤后、炎症或肿瘤等状态下，常出现淋巴管新生，这对于组织修复、机体免疫和肿瘤转移有着重要作用。

:::definition{label="淋巴管泵"}
相邻两对瓣膜之间的淋巴管段。平滑肌收缩加瓣膜开闭，把淋巴推向心脏方向。动脉搏动、肌肉收缩、胸腔负压是外加的推力。
:::

:::pitfall{label="淋巴水肿按压不凹陷，不要写成凹陷性水肿"}
回流受阻时，含蛋白质的组织液积在局部，按下去不留坑。静脉性、低蛋白性水肿常凹陷。写成「淋巴水肿也是指凹性」，和本版原句相反。
:::

:::insight{label="每小时约 120 ml，一天相当于血浆总量"}
流量只有静脉的约 1/10，但一天加起来等于全身血浆。运动和按摩能推这 10%；堵了就走侧支，侧支不够就水肿，新生的淋巴管既修复也给肿瘤开路。
:::

胸腺（thymus）是中枢淋巴器官，培育、选择和向周围淋巴器官（淋巴结、脾和扁桃体）和淋巴组织（淋巴小结）输送 T 淋巴细胞。胸腺还有内分泌功能。胸腺的位置和形态见第六章。

:::definition{label="胸腺"}
**中枢**淋巴器官。培育、选择 T 淋巴细胞，输送到淋巴结、脾、扁桃体和淋巴小结。兼内分泌。形态户头在第六章，本节只钉它在淋巴器官名单里的角色。
:::

:::note{label="胸腺形态不在本节重写"}
位置、分叶、年龄变化归内分泌章。这里只保留：它是中枢淋巴器官，向周围输送 T 细胞。
:::

脾（spleen）是人体**最大的淋巴器官**，具有储血、造血、清除衰老红细胞和进行免疫应答的功能（图7-70）。

脾位于左季肋部，胃底与膈之间，第 9～11 肋的深面，长轴与第 10 肋一致。正常时在左肋弓下触不到脾。脾的位置可随呼吸和体位变化，站立比平卧时低 2.5 cm。脾由胃脾韧带、脾肾韧带、膈脾韧带和脾结肠韧带支持固定。

脾呈暗红色，质软而脆。可分为膈、脏两面，前、后两端和上、下两缘。膈面光滑隆凸，对向膈。脏面凹陷，中央处有脾门（splenic hilum），是血管、神经和淋巴管出入之处。在脏面，脾与胃底、左肾、左肾上腺、胰尾和结肠左曲毗邻。前端较宽，朝向前外方，达腋中线。后端钝圆，朝向后内方，距离正中线 4～5 cm。上缘较锐，朝向前上方，前部有 2～3 个脾切迹（splenic notch）。脾大时，脾切迹是触诊脾的标志。下缘较钝，朝向后下方。在脾的附近，特别是在胃脾韧带和大网膜中存在副脾（accessory spleen），出现率为 10%～40%。副脾的位置、大小和数目不定。因脾功能亢进而做脾切除术时，应同时切除副脾。

:::definition{label="脾"}
人体**最大的淋巴器官**。左季肋部，胃底与膈之间，第 **9～11** 肋深面，长轴与第 **10** 肋一致。功能：储血、造血、清除衰老红细胞、免疫应答。正常左肋弓下触不到。
:::

:::definition{label="脾门"}
脏面中央的凹陷，血管、神经和淋巴管在此出入。不要把膈面的光滑隆凸听成门。
:::

:::definition{label="脾切迹"}
上缘前部的 **2～3** 个切迹。脾大时是触诊脾的标志——摸到切迹，才能把左肋弓下的包块认成脾，而不是肾或肿瘤。
:::

:::definition{label="副脾"}
脾附近的额外脾组织，尤其在胃脾韧带和大网膜中，出现率 **10%～40%**。位置、大小、数目不定。因脾功能亢进做脾切除时，必须一并切除，否则功能亢进可复发。
:::

::figure{src="/images/anatomy/textbook/p0252_01.png" caption="图7-70　脾" alt="左侧第 9 肋水平：脾脏面凹陷处为脾门，有脾动脉、静脉出入，上缘可见脾切迹"}

:::compare{title="脾的面、端、缘"}
| | 本版 |
|--|------|
| 膈面 | 光滑隆凸，对向膈 |
| 脏面 | 凹陷，中央脾门；邻胃底、左肾、左肾上腺、胰尾、结肠左曲 |
| 前端 | 较宽，朝前外，达腋中线 |
| 后端 | 钝圆，朝后内，距正中线 4～5 cm |
| 上缘 | 较锐，朝前上，前部 2～3 个脾切迹 |
| 下缘 | 较钝，朝后下 |

四条韧带：胃脾、脾肾、膈脾、脾结肠。质软而脆，外伤易破裂。
:::

:::pitfall{label="正常脾在左肋弓下触不到，不要把肋弓下的包块默认成脾"}
本版：正常时左肋弓下触不到。站立比平卧低 2.5 cm，仍应在肋弓以上。脾大时才靠脾切迹确认。写成「左肋弓下摸到就是脾」，和正常形态相反。
:::

:::cause-effect{title="脾功能亢进做切除，为什么必须找副脾"}
- **因** 副脾出现率 10%～40%，位置不定，仍具脾的功能
- **果** 只切主脾、留下副脾，功能亢进可以复发

手术清单上副脾不是可选项。
:::

## 二、淋巴结的位置和淋巴引流范围

各部淋巴结群的位置、引流范围和输出去向用对照表收纳，不为每一群单独开定义。临床上点名的专名（哨位、Virchow、颈内静脉二腹肌淋巴结等）另立户。

### （一）头颈部淋巴管和淋巴结

头颈部的淋巴结在头、颈部交界处呈环状排列，在颈部沿静脉纵向排列，少数位于消化道和呼吸道周围。头颈部淋巴结的输出淋巴管下行，直接或间接地注入颈外侧下深淋巴结。

**1. 头部淋巴结**　多位于头、颈部交界处，主要引流头面部淋巴，输出淋巴管直接或间接注入颈外侧上深淋巴结（图7-71、图7-72）。

::figure{src="/images/anatomy/textbook/p0252_02.png" caption="图7-71　头颈部淋巴管和淋巴结（Ⅰ）" alt="头颈侧面浅层：枕淋巴结、乳突淋巴结、腮腺淋巴结、下颌下淋巴结、颏下淋巴结、颈外侧浅淋巴结沿颈外静脉排列，锁骨上淋巴结在颈根"}

| 枕淋巴结 | 浅群在斜方肌起点表面，深群在头夹肌深面 | 枕部、项部 | 直接或间接 → 颈外侧上深 |
| 乳突淋巴结（耳后淋巴结） | 胸锁乳突肌止点表面 | 颅顶部、颞区、耳郭后 | 同上 |

**2. 颈部淋巴结**　主要包括颈前淋巴结和颈外侧淋巴结（图7-71、图7-72）。

:::definition{label="Virchow 淋巴结"}
左侧斜角肌淋巴结，即位于前斜角肌前方的那枚锁骨上淋巴结。胸、腹、盆部肿瘤，尤其是食管腹段癌和胃癌，癌栓经胸导管转移到此，常在胸锁乳突肌后缘与锁骨上缘的夹角处触到肿大淋巴结。
:::

:::pitfall{label="Virchow 淋巴结在左侧，不要写成右侧锁骨上"}
本版点名**左侧**斜角肌淋巴结。胸导管进的是左静脉角，所以腹盆和食管腹段的癌栓先出现在左锁骨上。写成「两侧锁骨上都可以叫 Virchow」，左右这一笔就没了。
:::

:::pitfall{label="鼻咽癌、舌根癌先到二腹肌结，舌尖癌先到肩胛舌骨肌结"}
颈内静脉二腹肌淋巴结收鼻咽、腭扁桃体和舌根；颈内静脉肩胛舌骨肌淋巴结收舌尖。两枚都在颈外侧上深群里，哨位不同。写成「头颈癌一律先到锁骨上」，会跳过真正的第一站。
:::

:::pitfall{label="气管旁淋巴结贴喉返神经，肿大可声嘶"}
气管旁淋巴结在气管与食管之间的侧沟，沿喉返神经排列。感染或肿瘤转移引起肿大，压迫喉返神经，出现声音嘶哑。声嘶不要只想到声带本身。
:::

### （三）胸部淋巴管和淋巴结

胸部淋巴结位于胸壁内和胸腔器官周围。

### （四）下肢淋巴管和淋巴结

下肢浅、深淋巴管分别与浅静脉和深血管伴行，直接或间接注入腹股沟淋巴结。臀部的深淋巴管沿深血管注入髂内淋巴结。

:::compare{title="下肢淋巴结"}
| 淋巴结 | 位置 | 引流 | 输出 |
|--------|------|------|------|
| 腘淋巴结 | 浅群沿小隐静脉末端，深群沿腘血管 | 足外侧缘和小腿后外侧部的浅淋巴管；足和小腿的深淋巴管 | 沿股血管 → 腹股沟深淋巴结 |
| 腹股沟浅淋巴结上群 | 腹股沟韧带下方，与韧带平行 | 腹前外侧壁下部、臀部、会阴、子宫底 | 腹股沟深或髂外淋巴结 |
| 腹股沟浅淋巴结下群 | 沿大隐静脉末端 | 除足外侧缘和小腿后外侧部以外的下肢浅淋巴管 | 同上 |
| 腹股沟深淋巴结 | 股静脉周围和股管内 | 大腿深部结构、会阴；收腘淋巴结深群和腹股沟浅淋巴结 | 髂外淋巴结 |

:::

### （六）腹部淋巴管和淋巴结

腹部淋巴结位于腹后壁和腹腔脏器周围，沿腹腔血管排列。

**1. 腹壁淋巴结**　脐平面以上腹前外侧壁的浅、深淋巴管分别注入腋淋巴结和胸骨旁淋巴结；脐平面以下腹壁的浅淋巴管注入腹股沟浅淋巴结，深淋巴管注入腹股沟深淋巴结、髂外淋巴结和腰淋巴结。

腰淋巴结（lumbar lymph node）位于腹后壁，沿腹主动脉和下腔静脉分布，引流腹后壁深层结构和腹腔成对器官的淋巴，并收纳髂总淋巴结的输出淋巴管，其输出淋巴管汇合成左、右腰干（见图7-68）。

:::definition{label="腰淋巴结"}
腹后壁，沿腹主动脉和下腔静脉。收腹后壁深层、腹腔**成对**器官，以及髂总淋巴结。输出合成左、右**腰干**，进乳糜池。
:::

:::compare{title="腹壁淋巴引流（先问脐平面）"}
| | 浅淋巴管 | 深淋巴管 |
|--|----------|----------|
| 脐平面以上 | 腋淋巴结 | 胸骨旁淋巴结 |
| 脐平面以下 | 腹股沟浅淋巴结 | 腹股沟深、髂外、腰淋巴结 |

脐是分水岭。不要把全腹壁都写成进腹股沟。
:::

**2. 腹腔器官的淋巴结**　腹腔成对器官的淋巴管注入腰淋巴结；不成对器官的淋巴管注入沿腹腔干、肠系膜上动脉和肠系膜下动脉及其分支排列的淋巴结。

|--------|----------------|------|
| 胃左、右淋巴结 | 相应动脉 | → 腹腔淋巴结 |
| 胃网膜左、右淋巴结 | 相应动脉 | → 腹腔淋巴结 |
| 幽门上、下淋巴结 | 幽门上、下方 | → 腹腔淋巴结 |
| 肝淋巴结 | 肝门、肝动脉 | → 腹腔淋巴结 |
| 胰淋巴结 | 胰 | → 腹腔淋巴结 |
| 脾淋巴结 | 脾门 | → 腹腔淋巴结 |
| 腹腔淋巴结 | 腹腔干周围 | 与肠系膜上、下淋巴结的输出管汇合成**肠干** |

:::

:::

## 三、部分器官的淋巴引流

各器官的引流方向用对照表收纳。甲状腺、食管和肝另有部分淋巴管不经过淋巴结、直接注入胸导管，已在概述点名。

### （一）肺的淋巴引流

肺浅淋巴管位于胸膜脏层深面，肺深淋巴管位于肺小叶间结缔组织内、肺血管和支气管的周围，注入肺淋巴结和支气管肺门淋巴结。浅、深淋巴管之间存在交通。通过淋巴管，肺的淋巴依次由肺淋巴结、支气管肺门淋巴结、气管支气管淋巴结和气管旁淋巴结引流。肺下叶下部的淋巴注入肺韧带处的淋巴结，其输出淋巴管注入胸导管或腰淋巴结。左肺上叶下部和下叶的部分淋巴注入右气管支气管淋巴结上群和右气管旁淋巴结。

:::compare{title="肺的淋巴引流"}
| 来源 | 注入 |
|------|------|
| 浅淋巴管（胸膜脏层深面） | 肺淋巴结、支气管肺门淋巴结 |
| 深淋巴管（小叶间、血管和支气管周围） | 同上；浅深之间有交通 |
| 常规链 | 肺淋巴结 → 支气管肺门淋巴结 → 气管支气管淋巴结 → 气管旁淋巴结 |
| 肺下叶下部 | 肺韧带处淋巴结 → 胸导管或腰淋巴结 |
| 左肺上叶下部和下叶的部分淋巴 | **右侧**气管支气管淋巴结上群和右气管旁淋巴结 |

左下肺可以交叉到右纵隔。写成「左肺只走左支气管纵隔干」，会漏掉对侧转移。
:::

### （二）食管的淋巴引流

食管颈部的淋巴注入气管旁淋巴结和颈外侧下深淋巴结。食管胸部的淋巴除注入纵隔后淋巴结外，胸上部注入气管旁淋巴结和气管支气管淋巴结，胸下部注入胃左淋巴结。食管腹部的淋巴管注入胃左淋巴结。食管的部分淋巴管注入胸导管。

:::compare{title="食管的淋巴引流"}
| 段 | 注入 |
|----|------|
| 颈部 | 气管旁淋巴结、颈外侧下深淋巴结 |
| 胸部（除纵隔后淋巴结外） | 胸上部 → 气管旁、气管支气管淋巴结；胸下部 → 胃左淋巴结 |
| 腹部 | 胃左淋巴结 |
| 部分淋巴管 | **直接注入胸导管**（不经过淋巴结） |

胸下部和腹部都向胃左淋巴结走，所以食管腹段癌可以出现 Virchow 淋巴结。直接进胸导管的那一部分，转移可以跳过局部结。
:::

### （三）胃的淋巴引流

胃的淋巴引流方向有 4 个：①胃底右侧部、贲门部和胃体小弯侧的淋巴注入胃上淋巴结；②幽门部小弯侧的淋巴注入幽门上淋巴结；③胃底左侧部、胃体大弯侧左侧部的淋巴注入胃网膜左淋巴结、胰淋巴结和脾淋巴结；④胃体大弯侧右侧部和幽门部大弯侧的淋巴注入胃网膜右淋巴结和幽门下淋巴结。各引流范围的淋巴管之间存在丰富的交通。

:::compare{title="胃的淋巴引流（四个方向）"}
| 胃的部位 | 注入 |
|----------|------|
| 胃底右侧、贲门、胃体小弯侧 | 胃上淋巴结 |
| 幽门部小弯侧 | 幽门上淋巴结 |
| 胃底左侧、胃体大弯侧左侧部 | 胃网膜左淋巴结、胰淋巴结、脾淋巴结 |
| 胃体大弯侧右侧部、幽门部大弯侧 | 胃网膜右淋巴结、幽门下淋巴结 |

四向之间交通丰富，所以胃癌的清扫范围不能按「只切一个方向」来理解。
:::

### （四）肝的淋巴引流

肝浅淋巴管位于肝被膜的结缔组织内。肝膈面的浅淋巴管多经镰状韧带和冠状韧带注入膈上淋巴结和肝淋巴结，部分淋巴管注入腹腔淋巴结和胃左淋巴结。冠状韧带内的部分淋巴管注入胸导管。肝脏面浅淋巴管注入肝淋巴结。深淋巴管位于门管区和肝静脉及其属支的周围，沿静脉出肝，注入肝淋巴结、腹腔淋巴结和膈上淋巴结。肝浅、深淋巴管之间存在丰富的交通。

:::compare{title="肝的淋巴引流"}
| 来源 | 注入 |
|------|------|
| 膈面浅淋巴管 | 多经镰状韧带、冠状韧带 → 膈上淋巴结、肝淋巴结；部分 → 腹腔淋巴结、胃左淋巴结 |
| 冠状韧带内部分淋巴管 | **直接注入胸导管** |
| 脏面浅淋巴管 | 肝淋巴结 |
| 深淋巴管（门管区、肝静脉周围） | 肝淋巴结、腹腔淋巴结、膈上淋巴结 |

浅深交通丰富。肝上面还可以走膈上淋巴结进胸腔，所以肝的转移不只在腹腔。
:::

### （五）直肠的淋巴引流

齿状线以上的淋巴管引流有 4 个方向：①沿直肠上血管上行，注入直肠上淋巴结；②沿直肠下血管行向两侧，注入髂内淋巴结；③沿肛血管和阴部内血管进入盆腔，注入髂内淋巴结；④少数淋巴管沿骶外侧血管走行，注入骶淋巴结。齿状线以下的淋巴管注入腹股沟浅淋巴结。

:::compare{title="直肠的淋巴引流（先问齿状线）"}
| | 注入 |
|--|------|
| 齿状线以上：沿直肠上血管 | 直肠上淋巴结 |
| 齿状线以上：沿直肠下血管 | 髂内淋巴结 |
| 齿状线以上：沿肛血管、阴部内血管 | 髂内淋巴结 |
| 齿状线以上：少数沿骶外侧血管 | 骶淋巴结 |
| 齿状线以下 | **腹股沟浅淋巴结** |

齿状线是分水岭。线以下走腹股沟浅，不要写成「整个直肠都进髂内」。腹股沟浅淋巴结肿大，要问是不是齿状线以下的病变。
:::

:::pitfall{label="齿状线以下走腹股沟浅淋巴结，不要和肝门静脉的齿状线搞混户头"}
上一节：齿状线以下肛管的静脉不进肝门静脉系。本节：齿状线以下的淋巴进腹股沟浅淋巴结。两条界都在齿状线，一个管静脉、一个管淋巴，清扫和门腔吻合不是同一张表。
:::

### （六）子宫的淋巴引流

子宫的淋巴引流方向较广：①子宫底和子宫体上部的淋巴管沿卵巢血管上行，注入腰淋巴结；沿子宫圆韧带穿腹股沟管，注入腹股沟浅淋巴结。②子宫体下部和子宫颈的淋巴管沿子宫血管行向两侧，注入髂内、外淋巴结；经子宫主韧带注入沿闭孔血管排列的闭孔淋巴结；沿子宫骶韧带向后注入骶淋巴结。

:::compare{title="子宫的淋巴引流"}
| 部位 | 路径 | 注入 |
|------|------|------|
| 子宫底、子宫体上部 | 沿卵巢血管上行 | 腰淋巴结 |
| 子宫底、子宫体上部 | 沿子宫圆韧带穿腹股沟管 | 腹股沟浅淋巴结 |
| 子宫体下部、子宫颈 | 沿子宫血管向两侧 | 髂内、髂外淋巴结 |
| 子宫体下部、子宫颈 | 经子宫主韧带 | 闭孔淋巴结 |
| 子宫体下部、子宫颈 | 沿子宫骶韧带向后 | 骶淋巴结 |

宫底可以走到腰淋巴结，也可以走到腹股沟浅。宫颈主要走盆壁。不要写成「子宫只进髂内」。
:::

### （七）乳房的淋巴引流

乳房的淋巴主要注入腋淋巴结，引流方向有 3 个：①乳房外侧部和中央部的淋巴管注入胸肌淋巴结；②上部的淋巴管注入尖淋巴结和锁骨上淋巴结；③内侧部的淋巴管注入胸骨旁淋巴结。乳房内侧部的浅淋巴管与对侧乳房淋巴管交通，内下部的淋巴管通过腹壁和膈下淋巴管与肝的淋巴管交通（见图7-73）。

:::compare{title="乳房的淋巴引流（三个方向）"}
| 部位 | 注入 |
|------|------|
| 外侧部、中央部 | 胸肌淋巴结（腋淋巴结） |
| 上部 | 尖淋巴结、锁骨上淋巴结 |
| 内侧部 | 胸骨旁淋巴结 |
| 内侧部浅淋巴管 | 与**对侧乳房**淋巴管交通 |
| 内下部 | 经腹壁、膈下淋巴管与**肝**的淋巴管交通 |

主要出口是腋淋巴结，但内侧和内下不是腋窝能包住的。对侧乳房和肝是两条容易漏记的交通。
:::

:::pitfall{label="乳房内侧走胸骨旁，不要全部写成腋淋巴结"}
外侧部和中央部才是胸肌淋巴结。上部可直接到尖淋巴结和锁骨上淋巴结，内侧部到胸骨旁。写成「乳腺癌只清腋窝」，胸骨旁和对侧、肝的通路就被漏掉。
:::

:::insight{label="哨位淋巴结是第一站，不是唯一站"}
局部淋巴结肿大，先问它收哪一片。拦不住就沿管道向下一群走；甲状腺、食管、肝还有直接进胸导管的旁路。清扫的形态依据是引流表，不是「肿了就一律清腋窝」。
:::

:::keypoint{label="淋巴系统先钉这几句"}
- 组织液约 90% 回静脉，约 10% 进毛细淋巴管，最后汇入静脉。
- 无毛细淋巴管：上皮、角膜、晶状体、软骨、胎盘、脊髓。
- 9 条淋巴干：成对腰干、支气管纵隔干、锁骨下干、颈干 + 不成对肠干。
- 胸导管平 T12 下缘起自乳糜池（L1 前方，收左右腰干和肠干），注入左静脉角，收全身约 3/4。
- 右淋巴导管长 1.0～1.5 cm，由右颈干、右锁骨下干、右支气管纵隔干合成，注入右静脉角，收约 1/4。
- 脾是最大淋巴器官；左季肋第 9～11 肋深面，长轴对第 10 肋；脾大切迹是触诊标志；副脾 10%～40%。
- Virchow 淋巴结 = 左侧斜角肌淋巴结。齿状线以下直肠淋巴 → 腹股沟浅。乳房内侧 → 胸骨旁。
:::

:::memory{label="本节必背要点"}
- [ ] 淋巴系统 = 淋巴管道 + 淋巴组织 + 淋巴器官。组织液约 90% 回静脉，约 10% 入毛细淋巴管，最后汇入静脉。
- [ ] 无毛细淋巴管：上皮、角膜、晶状体、软骨、胎盘、脊髓（不要抄成无毛细血管名单）。
- [ ] 9 条淋巴干：成对腰干、支气管纵隔干、锁骨下干、颈干 + 不成对肠干。
- [ ] 胸导管：全身最大；平第 12 胸椎下缘起自乳糜池；乳糜池在 L1 前方，收左、右腰干和肠干；注入左静脉角；引流约 3/4。
- [ ] 右淋巴导管长 1.0～1.5 cm，由右颈干、右锁骨下干、右支气管纵隔干合成，注入右静脉角，引流约 1/4。
- [ ] 淋巴结：凸侧输入、门部输出；青年人约 400～450 个；局部淋巴结 = 哨位淋巴结。
- [ ] 甲状腺、食管、肝的部分淋巴管可直接注入胸导管。安静时约 120 ml/h 回血；淋巴水肿按压不凹陷。
- [ ] 胸腺是中枢淋巴器官，输送 T 细胞；脾是最大淋巴器官（储血、造血、清除衰老红细胞、免疫）。
- [ ] 脾：第 9～11 肋深面，长轴对第 10 肋；正常左肋弓下触不到；上缘 2～3 个脾切迹；副脾 10%～40%，脾亢切除须同切。
- [ ] Virchow 淋巴结 = 左侧斜角肌淋巴结；鼻咽癌/舌根癌 → 颈内静脉二腹肌淋巴结；舌尖癌 → 颈内静脉肩胛舌骨肌淋巴结。
- [ ] 腋淋巴结五群：胸肌、外侧、肩胛下、中央、尖；尖淋巴结合成锁骨下干。
- [ ] 成对腹盆器官和腹后壁 → 腰干；不成对消化管等 → 肠干；两干在乳糜池会合。
- [ ] 肺：肺结 → 肺门结 → 气管支气管结 → 气管旁结；左下肺部分淋巴可到右侧。
- [ ] 齿状线以上直肠四向（直肠上、髂内、髂内、骶）；齿状线以下 → 腹股沟浅淋巴结。
- [ ] 乳房：外侧/中央 → 胸肌淋巴结；上部 → 尖结和锁骨上；内侧 → 胸骨旁；内侧交通对侧，内下交通肝。
:::
