# 第二节　骨连结

第一节已经把骨作为器官和体表标志写完。本节把运动系统的第二户——**骨连结**——从分类写到脊柱、胸廓、颞下颌和四肢大关节，最后收到足弓。骨骼肌是第三节，不要把肌腹、起止点提前塞进来；髂嵴、坐骨结节、内踝那些扪诊标志属于第一节，不必再抄一遍。

骨与骨之间借纤维结缔组织、软骨或骨相连，形成骨连结。按连结方式分为直接连结和间接连结两大类（图1-48）。直接连结牢固，不活动或少许活动；间接连结即滑膜关节，是最高分化形式，相对骨面分开、中间充滑液，一般具有较大活动性。人类直立之后，上肢关节以灵活为主，下肢关节以稳定为主——这一笔贯穿本节后半。

:::concept{term="先问直接还是滑膜，再问关节三件套齐不齐，最后才问韧带、盘和运动轴"}
看见两块骨怎么连，先不要报韧带名。先问：相对骨面是贴在一起，还是中间隔着滑液腔。贴在一起的是直接连结（纤维、软骨或骨性结合）。隔着腔的才叫关节。再问三件套：关节面、关节囊、关节腔缺不缺。韧带、关节盘、半月板、关节唇是辅助结构，不是每个关节都有。运动形式按三轴来写，不要和方位词并户。
:::

:::definition{label="骨连结"}
骨与骨之间借纤维结缔组织、软骨或骨相连所形成的连结。按方式分为直接连结和间接连结两大类。后文的 fibrous joint、cartilaginous joint、synostosis、synovial joint 都落在这一句下面。
:::

## 一、概述

### （一）直接连结

直接连结较牢固，不活动或少许活动。按中间的组织分为三类：纤维连结、软骨连结和骨性结合。

:::definition{label="直接连结"}
相对骨面借纤维结缔组织、软骨或骨直接相连，中间没有滑液腔。牢固，不活动或仅少许活动。不是「完全不能动」的同义词：缝和椎间盘都还能有微量形变。
:::

**1. 纤维连结（fibrous joint）**　两骨之间以纤维结缔组织相连，分两种。

（1）**韧带连结（syndesmosis）**：连接两骨的纤维结缔组织呈条索状或膜板状，如椎骨棘突之间的棘间韧带、前臂骨间膜等。

（2）**缝（suture）**：两骨间借少量纤维结缔组织相连，如颅的矢状缝和冠状缝。如果缝骨化，则成为骨性结合。

**2. 软骨连结（cartilaginous joint）**　两骨之间借软骨相连，也分两种。

（1）**透明软骨结合（synchondrosis）**：如长骨骨干与骺之间的骺软骨、蝶骨与枕骨的结合等，多见于幼年发育时期，随着年龄增长可骨化形成骨性结合。

（2）**纤维软骨联合（symphysis）**：如椎骨椎体之间的椎间盘及耻骨联合。这一户一般保持为软骨，不要和骺软骨一起写成「长大了都会变成骨」。

**3. 骨性结合（synostosis）**　两骨间以骨组织连结，常由纤维连结或透明软骨骨化而成，如骶椎椎骨之间的骨性结合，以及髂、耻、坐骨之间在髋臼处的骨性结合。

:::definition{label="骨性结合"}
两骨间以骨组织连结，常由缝或透明软骨骨化而来。骶骨五块椎骨融合成一块、髋骨三骨在髋臼处融合，都是这一户。融合之后不再有关节腔，也不再按滑膜关节描述运动。
:::

:::compare{title="直接连结三类怎么分"}
| 类 | 中间组织 | 亚型 / 例子 | 以后会不会变成骨 |
|----|----------|-------------|-------------------|
| 纤维连结 | 纤维结缔组织 | 韧带连结：棘间韧带、前臂骨间膜；缝：矢状缝、冠状缝 | 缝可骨化；韧带连结多保持 |
| 软骨连结 | 软骨 | 透明软骨结合：骺软骨、蝶枕结合；纤维软骨联合：椎间盘、耻骨联合 | 透明软骨结合多可骨化；纤维软骨联合保持 |
| 骨性结合 | 骨组织 | 骶椎之间；髋臼处髂、耻、坐骨 | 已经是骨 |

:::

:::pitfall{label="缝骨化之后就不再叫缝"}
颅的矢状缝、冠状缝在幼年是纤维连结。骨化完成后户头改成骨性结合。把成人颅顶仍写成「靠缝活动」，和新生儿前囟会并户。
:::

### （二）间接连结

间接连结又称为关节（articulation）或滑膜关节（synovial joint）（图1-49），是骨连结的最高分化形式：相对骨面互相分离，中间充以滑液的腔隙，仅借周围的结缔组织相连，因而一般具有较大的活动性。后文凡是说「关节」，默认指这一户，不要把椎间盘、耻骨联合、缝也叫成关节。

:::definition{label="间接连结（滑膜关节）"}
相对骨面互相分离、充以滑液的腔隙，仅借周围结缔组织相连。又称关节或滑膜关节，是骨连结的最高分化形式，一般活动性较大。基本结构只有三件：关节面、关节囊、关节腔。
:::

:::compare{title="直接连结 vs 间接连结"}
| | 直接连结 | 间接连结（滑膜关节） |
|--|----------|----------------------|
| 相对骨面 | 贴在一起 | 分开，中间有腔 |
| 中间物 | 纤维、软骨或骨 | 滑液 |
| 活动性 | 不活动或少许活动 | 一般较大 |
| 本版例子 | 缝、骺软骨、椎间盘、骶椎融合 | 肩、肘、髋、膝、桡腕 |

:::

#### 1. 关节的基本构造

每个滑膜关节都必须具备关节面、关节囊、关节腔。缺一件就不是完整的滑膜关节。

**（1）关节面（articular surface）**　是参与组成关节的各相关骨的接触面。每一关节至少包括两个关节面，一般为一凸一凹：凸者称为关节头，凹者称为关节窝。关节面上被覆关节软骨（articular cartilage）。关节软骨多数由透明软骨构成，少数为纤维软骨（如颞下颌关节），厚薄因关节和年龄而异，通常为 2～7 mm。关节软骨使粗糙的关节面变光滑，运动时减少摩擦，并缓冲震荡和冲击。

:::definition{label="关节面"}
组成关节的相关骨的接触面。至少两个，一般一凸一凹：凸为关节头，凹为关节窝。面上被覆关节软骨。
:::

**（2）关节囊（articular capsule）**　由纤维结缔组织膜构成，附着于关节面周围，并与骨膜融合续连，包围关节、封闭关节腔，分内外两层。

外层为**纤维膜（fibrous membrane）**，厚而坚韧，由致密结缔组织构成，含丰富的血管和神经。纤维膜的厚薄与关节功能有关：下肢关节负重大、相对稳固，纤维膜坚韧而紧张；上肢关节运动灵活，纤维膜薄而松弛。纤维膜的有些部分可明显增厚形成韧带，增强稳固、限制过度运动。

内层为**滑膜（synovial membrane）**，由薄而柔润的疏松结缔组织膜构成，衬贴于纤维膜内面，边缘附着于关节软骨周缘，包被关节内除关节软骨、关节唇和关节盘以外的所有结构。滑膜表面有时形成许多小突起，称为滑膜绒毛（synovial villus），多见于关节囊附着处附近。滑膜富含血管网，能产生滑液（synovial fluid）。滑液是透明的蛋清样液体，呈弱碱性，为关节腔提供液态环境，既能润滑，也是关节软骨、半月板等新陈代谢的重要媒介。

:::definition{label="关节囊"}
附着于关节面周围、与骨膜续连的纤维结缔组织囊，分纤维膜（外）和滑膜（内）两层，包围关节并封闭关节腔。下肢负重则纤维膜坚韧紧张，上肢求灵活则薄而松弛。
:::

**（3）关节腔（articular cavity）**　为关节囊滑膜层和关节面共同围成的密闭腔隙，腔内含少量滑液，呈负压，对维持关节稳固有一定作用。

:::definition{label="关节腔"}
滑膜层与关节面共同围成的密闭腔隙，含少量滑液，腔内负压。它不是「骨头中间挖出来的洞」，壁的一圈是滑膜，两端是关节软骨。
:::

:::keypoint{label="滑膜关节基本结构只有三件"}
- 关节面（含关节软骨）。
- 关节囊（纤维膜 + 滑膜）。
- 关节腔（密闭、少量滑液、负压）。
- 韧带、盘、唇、滑膜襞是辅助结构，不是三件套里的第四件。
:::

#### 2. 关节的辅助结构

部分关节为适应功能还形成特殊的辅助结构，用来增加灵活性或稳固性。不是每个关节都有全套。

**（1）韧带（ligament）**　连于相邻两骨之间的致密纤维结缔组织束，加强稳固或限制过度运动。位于囊外的称囊外韧带：有的与囊相贴，为囊的局部纤维增厚，如髋关节的髂股韧带；有的与囊不相贴、分离存在，如膝关节的腓侧副韧带；有的是关节周围肌腱的直接延续，如膝关节的髌韧带。位于囊内的称囊内韧带，有滑膜包裹，如膝关节内的交叉韧带。

:::definition{label="韧带"}
连于相邻两骨之间的致密纤维结缔组织束。囊外韧带可与囊相贴、分离存在，或为肌腱延续；囊内韧带有滑膜包裹。功能是加强稳固、限制过度运动，不是产滑液。
:::

**（2）关节盘（articular disc）和关节唇（articular labrum）**　是关节腔内两种不同形态的纤维软骨。

关节盘位于两骨的关节面之间，周缘附着于关节囊，将关节腔分成两部分。多呈圆盘状，中部稍薄、周缘略厚。有的呈半月形，称关节半月板。关节盘使关节面更为适配，减少冲击和震荡；分成的两个腔还可增加运动的形式和范围。

关节唇是附着于关节窝周缘的纤维软骨环，加深关节窝、增大关节面，如髋臼唇，增加稳固性。

:::definition{label="关节盘"}
位于两骨关节面之间的纤维软骨，周缘附于关节囊，把关节腔分成两部分。可呈圆盘状或半月形（半月板）。颞下颌、胸锁、桡尺远侧都有盘；膝的半月板是这一户的半月形。
:::

:::definition{label="关节唇"}
附着于关节窝周缘的纤维软骨环，加深关节窝。肩有盂唇，髋有髋臼唇。唇加深的是窝，不是把关节腔一分为二——那是盘的工作。
:::

**（3）滑膜襞（synovial fold）和滑膜囊（synovial bursa）**　有些关节囊的滑膜表面积大于纤维层，滑膜重叠卷折并突入关节腔形成滑膜襞。襞内含脂肪则形成滑膜脂垫。关节运动时腔的形状、容积、压力改变，脂垫起调节或填充作用。滑膜襞和脂垫扩大了滑膜面积，有利于滑液的分泌和吸收。滑膜也可从纤维膜薄弱或缺如处呈囊状膨出，充填于肌腱与骨面之间，形成滑膜囊，减少肌肉活动时与骨面的摩擦。

:::compare{title="辅助结构各管什么"}
| 结构 | 本质 | 位置 | 主要作用 | 本版例子 |
|------|------|------|----------|----------|
| 韧带 | 致密纤维束 | 囊外或囊内 | 稳固、限制过度运动 | 髂股韧带；腓侧副韧带；交叉韧带 |
| 关节盘 | 纤维软骨 | 两关节面之间 | 适配、减震、分腔 | 颞下颌、胸锁；膝的半月板 |
| 关节唇 | 纤维软骨环 | 关节窝周缘 | 加深窝、增大面 | 盂唇、髋臼唇 |
| 滑膜襞 / 脂垫 | 滑膜卷折 | 突入关节腔 | 调节容积、扩大分泌面 | 膝的翼状襞 |
| 滑膜囊 | 滑膜膨出 | 肌腱与骨面之间 | 减少摩擦 | 髌上囊、髌下深囊 |

:::

:::pitfall{label="半月板是关节盘的半月形，不是第三种软骨"}
本版原句：有的关节盘呈半月形，称关节半月板。把半月板另立成与关节盘并列的「第四件辅助结构」，分类会多出一户。
:::

#### 3. 关节的运动

滑膜关节的关节面形态、运动轴的数量和位置，决定运动形式和范围。运动基本上沿三个互相垂直的轴进行。绪论里的冠状轴、矢状轴、垂直轴在这里才真正用来写动作。

**（1）移动（translation）**　一个骨关节面在另一骨关节面上滑动，如跗跖关节、腕骨间关节。连续放射摄影显示即便小的跗骨或腕骨也有旋转和成角，并不是纯平移。

**（2）屈（flexion）和伸（extension）**　通常沿冠状轴：角度变小为屈，增大为伸。一般屈向腹侧成角；**膝关节相反**，小腿向后贴近大腿为屈。拇指屈伸围绕**矢状轴**。足尖上抬、足背靠向小腿前面为踝的伸，习惯称**背屈（dorsiflexion）**；足尖下垂为屈，称**跖屈（plantarflexion）**。

**（3）收（adduction）和展（abduction）**　通常沿矢状轴：向正中矢状面靠拢为收，远离为展。手指、足趾分别以**中指**、**第二趾**为中轴。拇指收展围绕**冠状轴**。

**（4）旋转（rotation）**　沿垂直轴。肱骨向前内侧为旋内（medial rotation），向后外侧为旋外（lateral rotation）。前臂绕桡骨头中心到尺骨茎突基底的轴线：手背转向前方为**旋前（pronation）**，手掌恢复向前为**旋后（supination）**。

**（5）环转（circumduction）**　上端原位转动、下端作圆周，轨迹呈圆锥。能沿两轴以上运动的关节均可环转（肩、髋、桡腕），实质是屈、展、伸、收的连续动作，不是第四根轴。

:::compare{title="五类运动：通常轴与本版例外"}
| 运动 | 通常绕哪根轴 | 本版写明的例外 |
|------|----------------|----------------|
| 移动 | 关节面之间滑动 | 跗骨、腕骨实际上仍有旋转和成角 |
| 屈 / 伸 | 冠状轴；屈向腹侧成角 | 膝：小腿向后为屈。拇指：绕矢状轴。踝：背屈＝伸，跖屈＝屈 |
| 收 / 展 | 矢状轴；向/离正中矢状面 | 手指以中指为轴，足趾以第二趾为轴。拇指收展绕冠状轴 |
| 旋转 | 垂直轴 | 前臂旋前/旋后绕桡骨头中心至尺骨茎突基底 |
| 环转 | 两轴以上的连续屈展伸收 | 肩、髋、桡腕可做；不是单独一根「环转轴」 |
:::

:::pitfall{label="膝关节的屈不是小腿向前抬"}
一般关节屈向腹侧成角。膝相反：小腿向后贴近大腿才叫屈。把「踢腿向前」写成屈膝，和踝的背屈会一起说反。
:::

:::pitfall{label="背屈是踝的伸，不要另立第四对屈伸"}
足尖上抬是踝关节的伸，习惯叫背屈；足尖下垂是屈，习惯叫跖屈。考试若问「踝关节的伸」，答案是背屈，不是另造一个「足伸」。
:::

#### 4. 关节的分类

关节有多种分类方法。按构成关节的骨数目：两块骨构成的为单关节，两块以上为复关节。按是否必须同时运动：髋、肩等为单动关节，两侧颞下颌关节为联动关节。**常用分类**按运动轴的数目和关节面的形态，分为单轴、双轴、多轴三类（图1-50）。

:::compare{title="先分单关节 / 复关节，再分单动 / 联动"}
| 分法 | 含义 | 例子 |
|------|------|------|
| 单关节 | 两块骨构成 | 指间关节、髋关节 |
| 复关节 | 两块以上的骨构成 | 肘关节（肱、尺、桡） |
| 单动关节 | 可单独运动 | 髋、肩 |
| 联动关节 | 必须两侧或两处同时动 | 两侧颞下颌；桡尺近侧与远侧 |

:::

**（1）单轴关节**　只能绕一个运动轴作一组运动：屈戌关节（hinge joint，又名滑车关节）通常只绕冠状轴屈伸，如指间关节；车轴关节（trochoid joint, pivot joint）的关节窝常由骨和韧带连成环，沿垂直轴旋转，如寰枢正中关节和桡尺近侧关节。

**（2）双轴关节**　能绕两个互相垂直的轴作两组运动，也可环转：椭圆关节（ellipsoidal joint）如桡腕、寰枕；鞍状关节（sellar joint, saddle joint）两面均呈鞍状，如拇指腕掌关节。

**（3）多轴关节**　具有两个以上运动轴。球窝关节（ball-and-socket joint, spheroidal joint）的关节头呈球形：肩关节窝浅而小，接触面积不到 1/3，可作屈伸、收展、旋转和环转；髋关节窝深，包绕头的大部分，幅度受限；掌指关节亦属球窝，因侧副韧带较强，旋转受限。平面关节（plane joint）两面较平坦但仍有弧度，列入多轴，可滑动或转动，如腕骨间关节和跗跖关节。

::figure{src="/images/anatomy/textbook/p0064_01.png" caption="图1-50　滑膜关节的分类"}

:::compare{title="按轴和关节面形态的常用三分法"}
| 类 | 形式 | 关节面 | 运动 | 本版例子 |
|----|------|--------|------|----------|
| 单轴 | 屈戌（滑车） | 滑车状头 + 相应窝 | 冠状轴屈伸 | 指间关节 |
| 单轴 | 车轴 | 圆柱头 + 骨－韧带环 | 垂直轴旋转 | 寰枢正中、桡尺近侧 |
| 双轴 | 椭圆 | 椭圆形凸凹 | 屈伸、收展、环转 | 桡腕、寰枕 |
| 双轴 | 鞍状 | 双方均呈鞍状 | 屈伸、收展、环转 | 拇指腕掌关节 |
| 多轴 | 球窝 | 球头，窝可浅可深 | 三轴 + 环转 | 肩（浅）；髋（深，幅度小）；掌指（旋转受限） |
| 多轴 | 平面 | 较平坦仍有弧度 | 多轴滑动或转动 | 腕骨间、跗跖 |

:::pitfall{label="平面关节不是单轴，更不是‘不能动’"}
两面平坦仍列入多轴关节。把腕骨间、跗跖写成屈戌或「不动关节」，和肋椎微动、胸肋微动会并户。
:::

## 二、躯干骨的连结

躯干骨的连结包括椎骨间的连结和肋的连结。24 块椎骨、1 块骶骨和 1 块尾骨借骨连结形成**脊柱（vertebral column）**，构成人体中轴，上承载颅，下连肢带骨；12 块胸椎、12 对肋和 1 块胸骨连结构成**胸廓（thoracic cage）**。

:::definition{label="脊柱"}
24 块椎骨、1 块骶骨和 1 块尾骨借骨连结形成的中轴，上承载颅，下连肢带骨。功能是支持躯干和保护脊髓。
:::

### （一）椎骨间的连结

各椎骨之间借韧带、软骨和滑膜关节相连，分为椎体间连结和椎弓间连结。

#### 1. 椎体间连结

椎体之间借椎间盘及前、后纵韧带相连。

**（1）椎间盘（intervertebral disc）**　连结相邻两个椎体的纤维软骨盘（第 1 及第 2 颈椎之间除外），成人有 **23** 个（图1-51）。中央部为**髓核（nucleus pulposus）**，是柔软而富有弹性的胶状物质，为胚胎时脊索的残留物。周围部为**纤维环（annulus fibrosus）**，由多层纤维软骨环按同心圆排列组成，富于坚韧性，牢固连结各椎体上、下面，保护髓核并限制其向周围膨出。

椎间盘既坚韧又富弹性，承受压力时被压缩，除去压力后又复原，具有「弹性垫」样作用，可缓冲外力对脊柱的震动，也可增加脊柱的运动幅度。23 个椎间盘厚薄不同：中胸部较薄，颈部较厚，腰部最厚，所以颈椎、腰椎活动度较大。颈、腰部椎间盘前厚后薄，胸部则相反。厚薄和大小可随年龄变化。当纤维环破裂时，髓核容易向**后外侧**脱出，突入椎管或椎间孔，压迫相邻脊髓或脊神经根引起牵涉性痛，临床称为椎间盘突出症。

:::definition{label="椎间盘"}
连结相邻两椎体的纤维软骨盘，第 1、2 颈椎之间除外，成人 23 个。中央髓核 + 周围纤维环。不是滑膜关节，户头仍是纤维软骨联合。
:::

:::definition{label="髓核"}
椎间盘中央柔软而富弹性的胶状物质，为胚胎脊索残留物。纤维环破裂时，它容易从后外侧突向椎管或椎间孔。
:::

:::definition{label="纤维环"}
椎间盘周围部，多层纤维软骨环按同心圆排列，连结椎体上、下面，保护髓核并限制其膨出。破裂是椎间盘突出的入口。
:::

::figure{src="/images/anatomy/textbook/p0064_02.png" caption="图1-51　椎间盘和关节突（腰椎上面）"}

:::keypoint{label="椎间盘三句不要拆"}
- 23 个，C1 与 C2 之间没有。
- 纤维环在外、髓核在内；髓核是脊索残留。
- 颈、腰前厚后薄，胸相反；突出好发后外侧。
:::

:::pitfall{label="突出方向是后外侧，不是正后方一整个髓核掉进椎管"}
后纵韧带贴在椎体后面，正中相对加强；后外侧纤维环较薄弱，又正对椎间孔。写成「一律向正后突出」，神经根受压这一笔会失去部位。
:::

**（2）前纵韧带（anterior longitudinal ligament）**　椎体前面延伸的一束坚固纤维，宽而坚韧，上自枕骨大孔前缘，下达第 1 或第 2 骶椎椎体。纵行纤维牢固附着于椎体和椎间盘，有防止脊柱**过度后伸**和椎间盘向前脱出的作用（图1-52）。

**（3）后纵韧带（posterior longitudinal ligament）**　位于椎管内椎体的后面，窄而坚韧。起自枢椎并与覆盖枢椎椎体的覆膜相续，下达骶骨。与椎间盘纤维环及椎体上下缘紧密连结，与椎体结合较疏松，有限制脊柱**过度前屈**的作用。

:::definition{label="前纵韧带"}
贴在椎体前面，宽而坚韧，上自枕骨大孔前缘，下至第 1 或第 2 骶椎。限制过度后伸，并防止椎间盘向前脱出。
:::

:::definition{label="后纵韧带"}
贴在椎管内椎体后面，窄而坚韧，上续覆膜，下达骶骨。限制过度前屈。与纤维环及椎体上下缘紧密，与椎体中部较疏松。
:::

:::pitfall{label="前纵韧带限制后伸，后纵韧带限制前屈"}
「前」不是限制前屈。前纵韧带在椎体前面，后伸时被拉紧，所以限制后伸；后纵韧带在后面，前屈时被拉紧，所以限制前屈。把两句按字面写成「前的管前、后的管后」，功能会整段反号。
:::

::figure{src="/images/anatomy/textbook/p0065_01.png" caption="图1-52　椎骨间的连结"}

#### 2. 椎弓间连结

包括椎弓板、棘突、横突间的韧带连结和上、下关节突间的滑膜关节连结。

椎弓间韧带先用对照表把位置和功能钉死，再单独点名黄韧带——腰穿进针会碰到它。

:::compare{title="椎弓间连结（韧带 + 关节突关节）"}
| 名称 | 位置 | 要点 |
|------|------|------|
| 黄韧带 ligamenta flava | 相邻椎弓板之间，位于椎管内 | 黄色弹性纤维；协助围成椎管；限制过度前屈 |
| 棘间韧带 | 相邻棘突根到尖 | 薄层纤维；前续黄韧带，后续棘上韧带 |
| 棘上韧带 | 胸、腰、骶椎棘突尖 | 限制脊柱前屈；前方与棘间韧带融合 |
| 项韧带 ligamentum nuchae | 颈椎棘突尖向后扩展的三角形弹性膜 | 上附枕外隆凸及枕外嵴，下达第 7 颈椎棘突并续棘上韧带 |
| 横突间韧带 | 相邻横突之间 | 纤维索，部分与横突间肌混合 |
| 关节突关节 | 相邻椎骨上、下关节突 | 平面关节，仅轻微滑动 |
:::

:::definition{label="黄韧带"}
连结相邻两椎弓板的弹性韧带，色黄，位于椎管内，协助围成椎管，限制脊柱过度前屈。腰穿进针经过棘上韧带、棘间韧带之后，下一层弹性阻力就是它。
:::

::figure{src="/images/anatomy/textbook/p0066_01.png" caption="图1-53　黄韧带（腰椎前面）"}

项韧带是颈部由棘突尖向后扩展的三角形弹性膜，上附枕外隆凸及枕外嵴，下达第 7 颈椎棘突并续于棘上韧带，供颈部肌肉附着。

::figure{src="/images/anatomy/textbook/p0066_02.png" caption="图1-54　项韧带"}

:::insight{label="限制前屈的不只后纵韧带"}
后纵韧带、黄韧带、棘间韧带、棘上韧带都在脊柱后方，前屈时被拉紧。前纵韧带单独在前方管后伸。把「限制前屈」只记成后纵韧带一条，黄韧带在腰穿中的手感会失去功能解释。
:::

#### 3. 寰椎与枕骨及枢椎的关节

**（1）寰枕关节（atlantooccipital joint）**　两侧枕髁与寰椎侧块的上关节凹构成的联合关节，属双轴性椭圆关节。两侧同时活动，使头作俯仰和侧屈。关节囊和寰枕前、后膜相连结。寰枕前膜（anterior atlantooccipital membrane）是前纵韧带的最上部分，连结枕骨大孔前缘与寰椎前弓上缘；寰枕后膜（posterior atlantooccipital membrane）位于枕骨大孔后缘与寰椎后弓上缘之间。

:::definition{label="寰枕关节"}
枕髁与寰椎上关节凹构成的联合关节，双轴椭圆关节。两侧同时动，头作俯仰和侧屈。不管旋转——旋转是寰枢关节沿齿突垂直轴的工作。
:::

**（2）寰枢关节（atlantoaxial joint）**　包括 3 个滑膜关节：2 个在寰椎侧块，1 个在正中复合体，分别称为寰枢外侧关节和寰枢正中关节。

1）寰枢外侧关节：左、右各一，由寰椎侧块的下关节面与枢椎上关节面构成，关节囊后部及内侧有韧带加强。

2）寰枢正中关节：由齿突与寰椎前弓后方的关节面和寰椎横韧带构成。

寰枢关节沿齿突垂直轴运动，使头连同寰椎旋转。寰枕、寰枢联合，头可作俯仰、侧屈和旋转。

:::definition{label="寰枢关节"}
3 个滑膜关节：左、右寰枢外侧关节 + 寰枢正中关节。正中关节由齿突、寰椎前弓后面和寰椎横韧带构成，沿齿突垂直轴旋转。
:::

:::compare{title="加强寰枢关节的韧带"}
| 名称 | 走行 | 关键作用 |
|------|------|----------|
| 齿突尖韧带 | 齿突尖 → 枕骨大孔前缘 | 连齿突与枕骨 |
| 翼状韧带 | 齿突尖向外上 → 枕髁内侧 | 限制过度旋转 |
| 寰椎横韧带 | 连结寰椎左、右侧块 | 防止齿突后退 |
| 寰椎十字韧带 | 横韧带 + 向上至枕骨大孔前缘、向下至枢椎椎体后面的纵行纤维 | 横 + 上、下纵束合称十字韧带 |
| 覆膜 | 从枕骨斜坡下降，覆盖上述韧带后面，下移行为后纵韧带 | 椎管内最前方的覆盖膜 |
:::

:::pitfall{label="寰椎横韧带断了，齿突会后退"}
横韧带把齿突限制在前弓后面。它一断，齿突可向后压迫脊髓。不要只记「十字韧带」这个形状，不记横束防后退这一句。
:::

### （二）脊柱的整体观及其运动

#### 1. 脊柱的整体观

脊柱（图1-56）支持躯干并保护脊髓。成年男性脊柱长约 **70 cm**，女性略短，约 **60 cm**。长度因姿势略有差异：静卧比站立时可长 2～3 cm，因为站立时椎间盘被压缩。椎间盘总厚度约为脊柱全长的 **1/4**。老年时椎间盘可因胶原成分改变而变薄，骨质疏松使椎体加宽、高度降低，脊柱肌肉动力学下降使胸曲和颈曲凸度增加，这些变化都直接导致老年脊柱变短。

**（1）前面观**　自第 2 颈椎到第 3 腰椎的椎体，自上而下随负载增加逐渐加宽，到第 2 骶椎为最宽。骶骨耳状面以下，重力经髂骨传到下肢骨，椎体已无承重意义，体积逐渐缩小。正常人脊柱有轻度侧屈：惯用右手者上部略凸向右侧，下部代偿性略凸向左侧。

**（2）后面观**　所有椎骨棘突连贯成纵嵴，位于背部正中线。颈椎棘突短而分叉，近水平位；胸椎棘突细长，斜向后下，呈叠瓦状；腰椎棘突呈板状，水平伸向后方。

**（3）侧面观**　成人脊柱有颈、胸、腰、骶 4 个生理性弯曲。颈曲和腰曲凸向前，胸曲和骶曲凸向后。这些弯曲增大脊柱弹性，对维持重心稳定和减轻震荡有重要意义。胸曲和骶曲凹向前方，在胚胎时已形成——胚胎在全身屈曲状态下发育。婴儿出生后开始抬头、坐起及站立行走，对颈曲和腰曲的形成有明显影响。也有学者认为凸向前的颈曲在胚胎时已显现，是胚胎伸头动作肌肉发育的结果。功能上：颈曲支持头的抬起，腰曲使身体重心垂线后移、保持稳固直立，胸曲和骶曲在一定意义上扩大胸腔和盆腔容积。

:::definition{label="脊柱的生理性弯曲"}
成人四个弯曲：颈曲、腰曲凸向前，胸曲、骶曲凸向后。胸曲和骶曲胚胎期已有；颈曲、腰曲主要在出生后抬头、坐、站中形成。不是侧弯，也不是老年变短本身。
:::

::figure{src="/images/anatomy/textbook/p0067_01.png" caption="图1-56　脊柱"}

:::compare{title="四个生理弯曲"}
| 弯曲 | 凸向 | 何时形成 | 功能意义 |
|------|------|----------|----------|
| 颈曲 | 前 | 出生后抬头；亦有胚胎已显现之说 | 支持头抬起 |
| 胸曲 | 后 | 胚胎（全身屈曲） | 扩大胸腔容积 |
| 腰曲 | 前 | 出生后坐起、站立行走 | 重心垂线后移，稳固直立 |
| 骶曲 | 后 | 胚胎 | 扩大盆腔容积 |
:::


#### 2. 脊柱的运动

相邻两椎骨之间的运动有限，整个脊柱活动范围较大，可作屈、伸、侧屈、旋转和环转。各部运动性质和范围取决于关节突关节的方向和形状、椎间盘厚度、韧带位置及厚薄，也与年龄、性别和锻炼程度有关。

:::compare{title="颈、胸、腰运动为什么不一样"}
| 部 | 关节突关节面 | 椎间盘 | 其他限制 | 结果 |
|----|--------------|--------|----------|------|
| 颈部 | 略呈水平位，关节囊松弛 | 较厚 | — | 屈、伸及旋转幅度较大 |
| 胸部 | 呈冠状位 | 较薄 | 连肋骨；棘突叠瓦状 | 活动范围较小 |
| 腰部 | 几乎呈矢状位 | 最厚 | — | 屈、伸灵活，旋转受限 |

颈、腰运动灵活，损伤也较多见。
:::

:::pitfall{label="腰部不是‘什么方向都最灵活’"}
腰椎间盘最厚，屈伸好；关节突几乎矢状位，旋转反而被限制。写成「腰部六向活动都最大」，和颈部的旋转会并户。
:::

### （三）肋的连结

肋的连结由肋椎关节和胸肋关节组成。

**1. 肋椎关节（costovertebral joint）**　肋骨后端与胸椎的连结，包括肋头与椎体的连结（肋头关节）以及肋结节与横突的连结（肋横突关节）。二者在功能上是联合关节：运动时肋骨沿肋头至肋结节的轴线旋转，使肋上升或下降，以增加或缩小胸廓的前后径和横径，从而改变胸腔容积，有助于呼吸（图1-57）。

（1）**肋头关节（joint of costal head）**：肋头关节面与相邻胸椎椎体边缘的肋凹（常称半关节面）构成，微动，有肋头辐状韧带和关节内韧带加强。

（2）**肋横突关节（costotransverse joint）**：肋结节关节面与相应椎骨的横突肋凹构成，亦微动，有肋横突韧带、囊韧带、肋横突上韧带和肋横突外侧韧带等加强。

::figure{src="/images/anatomy/textbook/p0068_01.png" caption="图1-57　肋椎关节"}

**2. 胸肋关节（sternocostal joint）**　第 2～7 肋软骨与胸骨相应肋切迹构成，属微动关节。第 1 肋与胸骨柄之间是一种特殊的不动关节；第 8～10 肋软骨前端不直接连胸骨，依次与上位肋软骨形成软骨连结，在剑突两侧各成一个连续软骨弓，称肋弓；第 11、12 肋前端游离于腹壁肌肉之中（图1-58）。

:::compare{title="12 对肋前端怎么连胸骨"}
| 肋 | 前端连结 | 本版名称 |
|----|----------|----------|
| 第 1 肋 | 与胸骨柄之间为特殊不动关节 | — |
| 第 2～7 肋 | 肋软骨与胸骨肋切迹，微动 | 胸肋关节 |
| 第 8～10 肋 | 不直接连胸骨，依次连上位肋软骨 | 形成肋弓 |
| 第 11、12 肋 | 前端游离于腹壁肌中 | 浮肋 |

:::

::figure{src="/images/anatomy/textbook/p0068_02.png" caption="图1-58　胸肋关节和胸锁关节"}

:::insight{label="肋椎两个关节是联合关节"}
肋头关节和肋横突关节必须一起动：肋骨绕「肋头到肋结节」那根轴转，胸廓前后径和横径才一起变。写成只动肋头、横突不动，呼吸时的胸廓变形会少一半。
:::

### （四）胸廓

胸廓（thoracic cage）由 12 块胸椎、12 对肋、1 块胸骨和它们之间的连结共同构成（图1-59）。上窄下宽，前后扁平，由于胸椎椎体前凸，水平切面呈肾形。构成胸廓的主要关节是肋椎关节和胸肋关节。

:::definition{label="胸廓"}
12 块胸椎 + 12 对肋 + 1 块胸骨及其连结。容纳胸腔脏器，有上、下两口和前、后、外侧壁。除保护、支持外，主要参与呼吸运动。
:::

成人胸廓近似圆锥形。两侧肋弓在中线构成向下开放的胸骨下角，剑突再把它分成左、右剑肋角。剑突尖约平对第 10 胸椎下缘。前壁最短（胸骨、肋软骨及肋骨前端），后壁较长（胸椎和肋角内侧的部分肋骨），外侧壁最长（肋骨体）。相邻两肋之间称肋间隙。

吸气时，在肌的作用下，肋的前部抬高，伴以胸骨上升，加大胸廓前后径；肋上提时肋体向外扩展，加大横径，胸腔容积增大。呼气时，在重力和肌肉作用下作相反运动，容积减小。

::figure{src="/images/anatomy/textbook/p0069_01.png" caption="图1-59　胸廓（前面）"}

:::compare{title="胸廓上口与下口"}
| | 围成 | 特点 |
|--|------|------|
| 上口 | 胸骨柄上缘、第 1 肋、第 1 胸椎椎体 | 较小；平面向前下倾斜；胸骨柄上缘约平 T2 椎体下缘 |
| 下口 | 第 12 胸椎、第 11 及 12 肋前端、肋弓、剑突 | 宽而不整；膈封闭；肋弓构成胸骨下角 |

剑突尖约平 T10 椎体下缘，不要和胸骨角平面（T4 椎体下缘）并户。
:::

:::pitfall{label="胸骨柄上缘并不平对第1胸椎"}
上口虽有 T1 椎体参加围成，但平面向前下倾斜，胸骨柄上缘约平 T2 椎体下缘。把颈静脉切迹写成「平 T1」，和第一节胸骨角平 T4 会一起错位。
:::

## 三、颅骨的连结

颅骨的连结包括纤维连结、软骨连结和滑膜关节三种。颅盖多缝，颅底多软骨结合，唯一的滑膜关节是颞下颌关节。

### （一）颅骨的纤维连结和软骨连结

各颅骨之间借缝、软骨和骨相连，结合较为牢固。

颅盖诸骨在膜的基础上骨化，骨与骨之间留有薄层结缔组织膜，构成缝：冠状缝、矢状缝、人字缝和蝶顶缝等。随年龄增长，有的缝可骨化成为骨性结合。

颅底诸骨在软骨基础上骨化，骨与骨之间多为软骨连结，如成年前蝶骨体后面与枕骨基底部之间的蝶枕软骨结合，此外尚有蝶岩、岩枕软骨结合等，以后都先后骨化成为骨性结合。

:::compare{title="颅盖的缝 vs 颅底的软骨结合"}
| | 发生 | 连结形式 | 本版例子 | 结局 |
|--|------|----------|----------|------|
| 颅盖 | 膜化骨 | 缝 | 冠状缝、矢状缝、人字缝、蝶顶缝 | 可骨化成骨性结合 |
| 颅底 | 软骨化骨 | 透明软骨结合 | 蝶枕、蝶岩、岩枕 | 先后骨化成骨性结合 |

第一节把膜化骨、软骨化骨写在骨的发生里；本节落到「成年后还剩什么缝」。
:::

### （二）颅骨的滑膜关节

颅骨唯一的滑膜关节是**颞下颌关节（temporomandibular joint）**，又称下颌关节，由下颌骨的下颌头与颞骨的下颌窝和关节结节构成（图1-60）。关节面覆盖的是**纤维软骨**。关节囊松弛，上方附着于下颌窝和关节结节周围，下方附着于下颌颈，囊外有外侧韧带加强。关节腔内有纤维软骨构成的关节盘：盘呈椭圆形，上面如鞍状，前凹后凸，与关节结节和下颌窝的形状相对应。盘的周缘与关节囊相连，将关节腔分为上、下两部分。关节囊前份较薄弱，故颞下颌关节易向前脱位。

:::definition{label="颞下颌关节"}
下颌头与颞骨下颌窝、关节结节构成的联动关节。关节面为纤维软骨；囊内有关节盘，把腔分成上、下两部。两侧必须同时运动。
:::

::figure{src="/images/anatomy/textbook/p0070_02.png" caption="图1-60　颞下颌关节"}

颞下颌关节属于联合关节，两侧必须同时运动。下颌骨可作上提、下降、前进、后退和侧方运动。上提和下降发生在**下关节腔**，前进和后退发生在**上关节腔**；侧方运动是一侧下颌头对关节盘作旋转，对侧下颌头和关节盘一起对关节窝作前进。张口是下颌骨下降并伴向前：大张口时，下颌骨体降向下后方，下颌头随关节盘滑至关节结节下方。若张口过大且关节囊过于松弛，下颌头可滑至关节结节前方而不能退回关节窝，造成下颌关节脱位。手法复位必须先将下颌骨拉向下，超过关节结节，再向后推，才能将下颌头纳回下颌窝。闭口则是下颌骨上提，下颌头和关节盘一起滑回关节窝。

:::compare{title="颞下颌关节：哪个腔管哪组运动"}
| 运动 | 主要发生部位 |
|------|----------------|
| 上提、下降 | 下关节腔（下颌头对盘） |
| 前进、后退 | 上关节腔（盘对下颌窝 / 关节结节） |
| 侧方 | 一侧头对盘旋转，对侧头连盘前进 |
| 张口 | 下降 + 向前；大张口时头滑到关节结节下方 |
| 向前脱位 | 头滑到关节结节前方；复位先向下超过结节再向后 |
:::

:::pitfall{label="复位不是直接往后推"}
下颌头已经在关节结节前方，直接后推会撞在结节上。本版手法：先向下拉、超过关节结节，再向后推。把「脱位向前」理解成「往回一推就进」，会卡在结节上。
:::

## 四、附肢骨的连结

附肢的主要功能是支持和运动，故附肢骨的连结以滑膜关节为主。人类直立后，上肢获得了适于抓握和操作的很大活动度，因而上肢关节以**灵活性**为主；下肢支持身体，下肢关节以**稳定性**为主。

:::concept{term="上肢问灵活，下肢问稳固，再问这个关节的面、囊、辅助结构有没有为这个目标让步"}
看见肩，先问窝浅不浅、囊松不松；看见髋，先问窝深不深、囊紧不紧。灵活和稳固是同一套滑膜关节在两端的取值，不是两套解剖学术语。
:::

### （一）上肢骨的连结

包括上肢带骨的连结和自由上肢骨的连结。

#### 1. 上肢带骨的连结

**（1）胸锁关节（sternoclavicular joint）**　上肢骨与躯干骨之间连结的**唯一关节**。由锁骨的胸骨端与胸骨的锁切迹及第 1 肋软骨的上面共同构成（图1-61），属多轴关节。关节囊坚韧，有胸锁前、后韧带，锁间韧带，肋锁韧带等囊外韧带加强。囊内有纤维软骨关节盘，将关节腔分为外上和内下两部分。关节盘使头窝更为适应；盘的下缘附着于第 1 肋软骨，能阻止锁骨向内上方脱位。锁骨外侧端可向前、后运动 20°～30°，向上、下约 60°，并绕冠状轴作微小旋转和环转。活动度虽小，但以此为支点扩大了上肢的活动范围。

:::definition{label="胸锁关节"}
锁骨胸骨端、胸骨锁切迹和第 1 肋软骨上面共同构成的多轴关节，是上肢与躯干之间的唯一关节。囊内有关节盘，分腔为外上、内下。
:::

::figure{src="/images/anatomy/textbook/p0070_01.png" caption="图1-61　胸锁关节"}

**（2）肩锁关节（acromioclavicular joint）**　锁骨肩峰端与肩峰关节面构成，属平面关节，是肩胛骨活动的支点。上方有肩锁韧带加强；关节囊和锁骨下方有坚韧的喙锁韧带连于喙突。囊内关节盘常出现于关节上部，部分分隔关节（完全分隔罕见），活动度小。

**（3）喙肩韧带（coracoacromial ligament）**　三角形扁韧带，连于肩胛骨的喙突与肩峰之间，与喙突、肩峰共同构成**喙肩弓**，架于肩关节上方，防止肱骨头向上脱位。

:::compare{title="上肢带三件：两个关节 + 一条喙肩弓"}
| 名称 | 构成 / 附着 | 类型或作用 |
|------|-------------|------------|
| 胸锁关节 | 锁骨胸骨端 + 锁切迹 + 第 1 肋软骨 | 多轴；上肢与躯干唯一关节；囊内有盘 |
| 肩锁关节 | 锁骨肩峰端 + 肩峰 | 平面关节；肩胛骨活动支点 |
| 喙肩韧带 | 喙突 ↔ 肩峰 | 与喙突、肩峰构成喙肩弓，防肱骨头向上脱位 |

喙肩弓不是第三个滑膜关节，是肩关节上方的骨－韧带拱。
:::

#### 2. 自由上肢骨的连结

**（1）肩关节（shoulder joint）**　由肱骨头与肩胛骨的关节盂构成，也称盂肱关节，是典型的多轴球窝关节。关节盂周缘有纤维软骨盂唇加深关节窝，仍仅能容纳关节头的 **1/4～1/3**。这一结构增加了运动幅度和灵活性，也减少了稳固性，因此周围的肌肉、韧带对稳固起重要作用（图1-62）。

关节囊薄而松弛：肩胛骨端附着于关节盂缘，肱骨端附于肱骨解剖颈，内侧可达肱骨外科颈。滑膜层可膨出形成滑膜鞘或滑膜囊，以利于肌腱活动。肱二头肌长头腱在结节间滑膜鞘内穿过关节。囊的上壁有喙肱韧带，从喙突根部至肱骨大结节前面，与冈上肌腱交织并融入纤维层。前壁和后壁也有许多肌腱加入。囊的下壁相对最为薄弱，故肩关节脱位时肱骨头常从下份滑出，发生**前下方脱位**。

肩关节为全身最灵活的关节，可作三轴运动：冠状轴屈伸，矢状轴收展，垂直轴旋内、旋外及环转。臂外展超过 40°～60°、继续抬高至 180° 时，常伴随胸锁与肩锁关节的运动及肩胛骨的旋转。灵活也易导致损伤。

:::definition{label="肩关节"}
肱骨头与关节盂构成的多轴球窝关节，也称盂肱关节。盂唇加深后仍只容纳头的 1/4～1/3。囊薄而松弛，下壁最薄弱，脱位多从前下方。
:::

::figure{src="/images/anatomy/textbook/p0071_01.png" caption="图1-62　肩关节"}

:::keypoint{label="肩关节为什么灵活又不稳"}
- 头大窝浅：接触不到 1/3（本版 1/4～1/3）。
- 囊薄而松，下壁最弱 → 前下方脱位。
- 盂唇、喙肩弓、肌腱（含肱二头肌长头腱）补稳固。
- 外展超过 40°～60° 再抬到 180°，要借胸锁、肩锁和肩胛骨旋转。
:::

:::pitfall{label="肩关节脱位不是‘向上顶破喙肩弓’"}
喙肩弓架在上方，防的是肱骨头向上脱。囊的下壁最薄弱，头从下份滑出，临床多见前下方脱位。写成「头往上掉」，和喙肩弓的功能打架。
:::

**（2）肘关节（elbow joint）**　肱骨下端与尺、桡骨上端构成的**复关节**，包括三个关节，包在一个关节囊内（图1-63）。

1）肱尺关节（humeroulnar joint）：肱骨滑车 + 尺骨滑车切迹。

2）肱桡关节（humeroradial joint）：肱骨小头 + 桡骨关节凹。

3）桡尺近侧关节（proximal radioulnar joint）：桡骨环状关节面 + 尺骨桡切迹。

肘关节囊前、后壁薄而松弛，两侧壁厚而紧张并有韧带加强。后壁最薄弱，故常见桡、尺两骨向后脱位，移向肱骨后上方。

:::definition{label="肘关节"}
肱尺、肱桡、桡尺近侧三个关节包在一个囊内的复关节。运动以肱尺关节的屈伸为主；桡尺近侧与远侧联合完成旋前、旋后。
:::

::figure{src="/images/anatomy/textbook/p0072_01.png" caption="图1-63　肘关节"}

:::compare{title="肘关节的三条韧带"}
| 韧带 | 附着 | 作用 |
|------|------|------|
| 桡侧副韧带 | 肱骨外上髁 → 桡骨环状韧带 | 加强囊的桡侧 |
| 尺侧副韧带 | 肱骨内上髁扇形 → 尺骨滑车切迹内侧缘 | 加强囊的尺侧 |
| 桡骨环状韧带 | 环绕桡骨环状关节面，两端附于尺骨桡切迹前、后缘 | 与尺骨桡切迹共同构成上口大、下口小的骨纤维环，容纳桡骨头 |
:::

幼儿 4 岁以前，桡骨头尚在发育，环状韧带松弛：肘关节伸直位猛力牵拉前臂时，桡骨头易被环状韧带卡住，或环状韧带部分夹在肱、桡骨之间，发生**桡骨小头半脱位**。

肘关节运动以肱尺关节为主，尺骨在肱骨滑车上运动，桡骨头在肱骨小头上运动。肱骨滑车内侧缘更为向前下突出，超过外侧缘约 6 mm，使运动轴斜向下外。伸前臂时，前臂偏向外侧，与上臂形成一向外开放的钝角，约 165°～170°；臂轴延长线与前臂轴之间的补角为 10°～15°，称**提携角**。伸位时前臂远离正中线，增大运动幅度；屈位时前臂贴近正中线，便于操作。肱桡关节能作屈、伸和旋前、旋后；桡尺近侧与远侧联合使前臂旋前、旋后。

肱骨内、外上髁和尺骨鹰嘴都易在体表扪及。肘伸直时三点在一条直线上；屈至 90° 时，三点连线构成尖端朝下的等腰三角形。脱位时鹰嘴移位，三点关系改变；肱骨髁上骨折时三点关系不变。

:::definition{label="提携角"}
伸前臂时，臂轴延长线与前臂轴之间 10°～15° 的补角。来源是肱骨滑车内侧缘比外侧缘更向前下突出约 6 mm。不是病理外翻。
:::

:::pitfall{label="幼儿牵拉前臂造成的是桡骨头半脱位，不是肘关节后脱位"}
4 岁前环状韧带松、桡骨头未发育完，伸肘猛拉 → 桡骨头被环卡住。成人后脱位是尺、桡骨一起移向肱骨后上方，三点关系改变。两户不要并成「都是肘脱位」。
:::

:::pitfall{label="髁上骨折三点关系不变，脱位则变"}
伸肘三点一线、屈肘 90° 成等腰三角形，靠的是内上髁、外上髁和鹰嘴。骨折在髁上，三点仍在肱骨远端这块「三角形」上；脱位是鹰嘴离开原位。不要用手摸「肿了」来代替三点。
:::

**（3）桡尺连结**　桡、尺骨借前臂骨间膜、桡尺近侧关节和桡尺远侧关节相连。

1）**前臂骨间膜（interosseous membrane of forearm）**：连结尺骨和桡骨骨间缘的坚韧纤维膜（图1-64）。纤维从桡骨斜向下内达尺骨。旋前或旋后位时骨间膜松弛；半旋前位时最紧张，也是骨间膜最大宽度。处理前臂骨折时应将前臂固定于半旋前或半旋后位，以防骨间膜挛缩，影响愈后旋转功能。

2）桡尺近侧关节：见肘关节。

3）**桡尺远侧关节（distal radioulnar joint）**：尺骨头环状关节面构成关节头；桡骨的尺切迹及自下缘至尺骨茎突根部的关节盘共同构成关节窝。关节盘为三角形纤维软骨板，将尺骨头与腕骨隔开。关节囊松弛，附着于关节面和关节盘周缘。

桡尺近侧和远侧是联合关节。旋转轴为桡骨头中心至尺骨头中心的连线：桡骨头原位自转，桡骨下端连同关节盘围绕尺骨头旋转，实际上只是桡骨在转。桡骨转到尺骨前方并与之交叉、手背向前，为旋前；桡骨转回尺骨外侧，为旋后。

::figure{src="/images/anatomy/textbook/p0073_01.png" caption="图1-64　前臂骨的连结"}

:::insight{label="旋前旋后是桡骨在转，尺骨几乎不转"}
近侧头原位自转，远侧下端带着关节盘绕尺骨头转。写成「两根骨头一起拧」，骨间膜的纤维方向和骨折固定位都会失去着落。
:::

**（4）手关节（joint of hand）**　包括桡腕关节、腕骨间关节、腕掌关节、掌骨间关节、掌指关节和指骨间关节（图1-65）。关节名用对照表，不把每一条韧带写成定义。

::figure{src="/images/anatomy/textbook/p0073_02.png" caption="图1-65　手关节（冠状切面）"}

|------|------|------|------------|
| 桡腕关节（腕关节） | radiocarpal / wrist joint | 头：手舟骨、月骨、三角骨近侧关节面；窝：桡骨腕关节面 + 尺骨头下方关节盘 | 典型椭圆关节；屈伸、收展、环转；掌侧韧带最坚韧，后伸受限 |

典型椭圆关节，又称腕关节。关节头是手舟骨、月骨和三角骨的近侧关节面；关节窝是桡骨腕关节面和尺骨头下方的关节盘。尺骨不直接参加桡腕关节。
:::

:::pitfall{label="尺骨不进入桡腕关节"}
尺骨头被三角形关节盘与腕骨隔开。把头写成「桡骨 + 尺骨对腕骨」，和桡尺远侧关节会并户。豌豆骨也不参加桡腕关节的头。
:::

:::definition{label="拇指腕掌关节"}
大多角骨与第 1 掌骨底构成的鞍状关节，为灵长目所特有。可作屈、伸、收、展、环转和对掌。第 1 掌骨向内侧旋转近 90°，故拇指屈伸在冠状面上、收展在矢状面上。
:::

:::compare{title="拇指运动所在的面（第1掌骨内旋近90°之后）"}

| 屈 | 冠状面 | 在手掌平面上向掌心靠拢 |
| 伸 | 冠状面 | 在手掌平面上离开掌心 |
| 展 | 矢状面 | 在与手掌垂直的平面上离开示指 |
| 收 | 矢状面 | 在与手掌垂直的平面上靠拢示指 |
| 对掌 | — | 拇指尖对其余四指尖掌侧面；加深掌凹陷，为握持和精细操作所必需 |

掌指关节的侧副韧带屈指时紧张、伸指时松弛，所以伸指才能收展，握拳时收展基本锁死。手指收、展以通过中指的正中线为准：向中线靠拢是收，远离是展。握拳时手背凸出的是掌骨头；指屈曲时指背凸出的是指骨滑车。

### （二）下肢骨的连结

下肢主要功能是支持体重、运动和维持直立。骨更粗大，骨小梁按重力线排列；髋骨形态有性别差异。直立后重心在脊柱前方；髋关节水平则位于髋关节后方和第 2 骶椎之前。重力线经两膝及踝关节之前，踝部通过足舟骨。下肢关节的牢固性来自关节面形态、囊韧带和周围肌肉。连结包括下肢带骨的连结和自由下肢骨的连结。

#### 1. 下肢带骨的连结

**（1）骶髂关节（sacroiliac joint）**　骶骨和髂骨的耳状面构成，关节面凹凸不平，彼此结合十分紧密。关节囊紧张，有骶髂前、后韧带加强，后上方尚有骶髂骨间韧带充填。稳固性相当大，以适应支持体重。妊娠妇女活动度可稍增大。

**（2）髋骨与脊柱间的韧带连结**

:::compare{title="髋骨与脊柱之间、以及骨盆后壁的韧带"}
| 名称 | 走行 | 围成什么 |
|------|------|----------|
| 髂腰韧带 | 第 5 腰椎横突 → 髂嵴后上部 | 加固腰骶 |
| 骶结节韧带 | 骶、尾骨侧缘扇形 → 坐骨结节内侧缘 | 与骶棘韧带、坐骨小切迹围成坐骨小孔 |
| 骶棘韧带 | 骶、尾骨侧缘 → 坐骨棘（起始部被骶结节韧带遮掩） | 与坐骨大切迹围成坐骨大孔 |
:::

肌肉、血管和神经等从盆腔经坐骨大、小孔达臀部和会阴（图1-66）。

::figure{src="/images/anatomy/textbook/p0075_01.png" caption="图1-66　骨盆的韧带"}

**（3）耻骨联合（pubic symphysis）**　两侧耻骨联合面借纤维软骨构成的耻骨间盘连结（图1-67）。耻骨间盘中往往出现矢状位裂隙，女性较男性厚，裂隙也较大，孕妇和经产妇尤为显著。上、下方分别有耻骨上韧带和耻骨弓状韧带。活动甚微，分娩时裂隙增宽以增大骨盆径线。

::figure{src="/images/anatomy/textbook/p0075_02.png" caption="图1-67　耻骨联合（冠状切面）"}

**（4）髋骨的固有韧带**　即闭孔膜（obturator membrane），封闭闭孔并为盆内外肌肉提供附着。膜的上部与闭孔沟围成闭膜管（obturator canal），有神经、血管通过。

**（5）骨盆（pelvis）**　由左、右髋骨和骶、尾骨以及其间的骨连结构成。人体直立时骨盆向前倾斜，两侧髂前上棘与两耻骨结节位于同一冠状面内，尾骨尖与耻骨联合上缘位于同一水平面。由骶骨岬向两侧经弓状线、耻骨梳、耻骨结节至耻骨联合上缘构成的环形界线，把骨盆分为上方的大骨盆（假骨盆）和下方的小骨盆（真骨盆）。

:::definition{label="骨盆"}
左、右髋骨 + 骶骨 + 尾骨及其连结。界线以上为大骨盆（假骨盆），以下为小骨盆（真骨盆）。传导重力，支持并保护盆腔脏器。
:::

大骨盆（greater pelvis）由界线上方的髂骨翼和骶骨构成。骨盆前倾，故大骨盆几乎没有前壁。

小骨盆（lesser pelvis）是大骨盆向下延伸的骨性狭窄部，分骨盆上口、骨盆下口和骨盆腔。上口由上述界线围成，呈圆形或卵圆形。下口由尾骨尖、骶结节韧带、坐骨结节、坐骨支、耻骨下支和耻骨联合下缘围成，呈菱形。两侧坐骨支与耻骨下支连成耻骨弓，夹角称耻骨下角。上、下口之间的腔为骨盆腔（固有盆腔），内有直肠、膀胱和部分生殖器官。小骨盆腔是前壁短、侧壁和后壁较长的弯曲通道，中轴为骨盆轴；分娩时胎儿循此轴娩出（图1-68）。

::figure{src="/images/anatomy/textbook/p0076_01.png" caption="图1-68　骨盆径线"}

人体直立时，体重自第 5 腰椎、骶骨经两侧骶髂关节、髋臼传导至两侧股骨头，再向下达下肢，这种弓形力传递线称为**股骶弓**。坐位时，重力由骶髂关节传导至两侧坐骨结节，称为**坐骶弓**。骨盆前部还有两条约束弓，防止上述两弓向两侧分开：一条在耻骨联合处连结两侧耻骨上支，防止股骶弓被压挤；另一条为两侧耻骨、坐骨下支连成的耻骨弓，约束坐骶弓不致散开。约束弓不如重力弓坚强，外伤时约束弓的耻骨上支较下支更易骨折（图1-69）。

::figure{src="/images/anatomy/textbook/p0076_02.png" caption="图1-69　骨盆的力传导方向"}

骨盆位置随姿势变动。直立时向前倾斜，上口平面与水平面约成 **50°～55°** 角（女性可为 60°），称为骨盆倾斜度。倾斜度增大则重心前移、腰曲前凸增大；减小则腰曲前凸减小。

骨盆的性别差异在全身骨骼中最为显著，甚至胎儿时期耻骨弓就有差别。主要功能虽是运动，女性骨盆还要满足分娩。

:::compare{title="骨盆性别差异（本版数字）"}
| | 女性 | 男性 |
|--|------|------|
| 外形 | 短而宽 | 相对高而窄 |
| 上口 | 近似圆形，较宽大 | 较窄 |
| 下口、耻骨下角 | 较大；耻骨下角 90°～100° | 较小；耻骨下角 70°～75° |
| 倾斜度 | 可为 60° | 约 50°～55°（本版通值） |
:::

#### 2. 自由下肢骨的连结

**（1）髋关节（hip joint）**　髋臼与股骨头构成，属多轴的球窝关节（图1-70）。髋臼周缘附有纤维软骨构成的髋臼唇（acetabular labrum），以增加深度。髋臼切迹被髋臼横韧带封闭，使半月形的髋臼关节面扩大为环形以紧抱股骨头。髋臼窝内充填脂肪。

关节囊坚韧致密：向上附着于髋臼周缘及横韧带，向下附着于股骨颈——**前面达转子间线，后面仅包罩股骨颈的内侧 2/3**（转子间嵴略上方），因此股骨颈骨折有囊内、囊外之分。

:::definition{label="髋关节"}
髋臼与股骨头构成的多轴球窝关节。窝深，有髋臼唇和髋臼横韧带加深、成环；囊坚韧，前面包到转子间线，后面只包颈的内侧 2/3。稳固远大于灵活。
:::

::figure{src="/images/anatomy/textbook/p0077_01.png" caption="图1-70　髋关节"}

:::compare{title="髋关节的韧带"}
| 韧带 | 位置 | 限制什么 |
|------|------|----------|
| 髂股韧带 | 最坚韧；髂前下棘呈「人」字形止于转子间线 | 限制大腿过伸，维持直立 |
| 耻股韧带 | 耻骨上支 → 囊前下壁，与髂股韧带深部融合 | 限制外展及旋外 |
| 坐股韧带 | 坐骨体 → 大转子根部，加强后部 | 限制旋内 |
| 轮匝带 | 囊的深层纤维环绕股骨颈 | 约束股骨头向外脱出 |
| 股骨头韧带 | 囊内，股骨头凹 ↔ 髋臼横韧带；滑膜包被，内含营养股骨头的血管 | 半屈并内收时紧张，外展时松弛 |
:::

髋关节可作三轴的屈、伸、展、收、旋内、旋外以及环转。股骨头深埋髋臼，囊紧张坚韧又受多条韧带限制，运动幅度远不及肩关节，但稳固性大，适应承重和行走。囊的后下部相对薄弱，脱位时股骨头易向下方脱出（图1-71）。

::figure{src="/images/anatomy/textbook/p0077_02.png" caption="图1-71　髋关节（冠状切面）"}

:::keypoint{label="髋关节囊在颈上的附着决定囊内 / 囊外骨折"}
- 前面：包到转子间线 → 前面颈骨折多为囊内。
- 后面：只包内侧 2/3，转子间嵴在囊外 → 后外侧颈骨折可以是囊外。
- 不要把「股骨颈骨折」一律写成囊内。
:::

:::compare{title="肩关节 vs 髋关节（都是球窝，取值相反）"}
| | 肩 | 髋 |
|--|----|----|
| 头与窝 | 头大，窝浅，接触 1/4～1/3 | 头深埋，唇 + 横韧带成环紧抱 |
| 囊 | 薄而松，下壁最弱 | 坚韧致密，后下部相对弱 |
| 脱位 | 前下方 | 下方 |
| 运动 | 全身最灵活 | 三轴都有，幅度远不及肩 |
| 功能取向 | 灵活 | 稳固、承重 |
:::

**（2）膝关节（knee joint）**　股骨下端、胫骨上端和髌骨构成，是人体最大、最复杂的关节（图1-72）。髌骨与股骨髌面相接，股骨内、外侧髁分别与胫骨内、外侧髁相对。

关节囊薄而松弛，附着于各关节面周缘，周围有韧带加固。

:::definition{label="膝关节"}
股骨下端、胫骨上端和髌骨构成的人体最大、最复杂的关节。属屈戌关节，主要屈伸；半屈位还可少许旋转。交叉韧带和半月板是辅助结构里最常考的两户。
:::

::figure{src="/images/anatomy/textbook/p0078_01.png" caption="图1-72　膝关节"}

:::compare{title="膝关节主要韧带"}
| 韧带 | 要点 |
|------|------|
| 髌韧带 | 股四头肌腱中央部，髌骨 → 胫骨粗隆；浅层纤维越过髌骨连于股四头肌腱 |
| 腓侧副韧带 | 条索状，股骨外上髁 → 腓骨头；与外侧半月板**不直接相连** |
| 胫侧副韧带 | 宽扁，股骨内上髁 → 胫骨内侧髁及骨体；与关节囊和内侧半月板**紧密结合** |
| 腘斜韧带 | 半膜肌腱延伸，防过伸 |
| 前交叉韧带 | 胫骨髁间隆起前方内侧 → 股骨外侧髁内侧面；伸膝最紧张，防胫骨前移 |
| 后交叉韧带 | 较短而强；胫骨髁间隆起后方 → 股骨内侧髁外侧面；屈膝最紧张，防胫骨后移 |
:::

胫侧副韧带和腓侧副韧带在伸膝时紧张，屈膝时松弛，半屈膝时最松弛，因此半屈膝位允许膝关节作少许旋内、旋外。

:::definition{label="膝交叉韧带"}
位于膝关节中央稍后方，滑膜衬覆，分前、后两条。前交叉韧带伸膝最紧张，防止胫骨前移；后交叉韧带屈膝最紧张，防止胫骨后移。起止见上表。
:::

:::pitfall{label="前交叉防前移，后交叉防后移——以胫骨相对股骨为准"}
两韧带连的是股骨和胫骨，写的是「防止胫骨沿股骨向前、后移位」。不要改口成「防止股骨前移」而不说相对谁。伸膝查前抽屉、屈膝查后抽屉，和「何时最紧张」是同一句话。
:::

膝关节囊的滑膜层是全身关节中最宽阔、最复杂的，覆盖关节内除关节软骨和半月板以外的所有结构。滑膜在髌骨上缘上方向上突起，形成深达约 5 cm 的**髌上囊**，位于股四头肌腱与股骨体下部之间。髌骨下方中线两侧，部分滑膜突入关节腔形成一对**翼状襞（alar fold）**，襞内含脂肪。还有不与关节腔相通的滑液囊，如髌韧带与胫骨上端之间的髌下深囊。

**半月板（meniscus）**　垫在股骨内、外侧髁与胫骨内、外侧髁关节面之间的两块半月形纤维软骨板。内侧半月板（medial meniscus）较大，呈「C」形，前端窄、后份宽，外缘与关节囊及胫侧副韧带紧密相连。外侧半月板（lateral meniscus）较小，近似「O」形，外缘亦与关节囊相连（图1-73）。半月板使关节面更为适应，增加关节窝深度，并能连同股骨髁一起对胫骨作旋转运动；缓冲压力、吸收震荡，起弹性垫作用。半月板随膝关节运动而移动，强力骤然运动时易损伤：急速伸小腿并强力旋转（如踢足球）时，原移位的半月板尚未前滑，被上、下关节面挤住即可破裂。内侧半月板与囊及胫侧副韧带紧密相连，损伤机会较多。

:::definition{label="半月板"}
垫在股、胫内、外侧髁之间的半月形纤维软骨板。内侧「C」形、较大，连胫侧副韧带；外侧「O」形、较小。增加适配和深度，并参与旋转时的运动。
:::

::figure{src="/images/anatomy/textbook/p0079_01.png" caption="图1-73　膝关节内韧带和软骨"}

膝关节属屈戌关节，主要作屈、伸运动：屈可达 130°，伸不超过 10°。半屈位时小腿尚可旋转，即胫骨髁沿垂直轴对半月板和股骨髁运动。

:::pitfall{label="内侧半月板更容易伤，因为它连着胫侧副韧带"}
外侧半月板与腓侧副韧带不直接相连，活动度相对大；内侧「C」形还和囊、胫侧副韧带长在一起，旋转时更容易被卡住。不要只记「C 大 O 小」不记谁和副韧带相连。
:::

**（3）胫腓连结**　胫、腓两骨连结紧密：上端由胫骨外侧髁的腓关节面与腓骨头构成微动的胫腓关节；两骨干之间有坚韧的小腿骨间膜；下端借胫腓前、后韧带构成坚强的韧带连结。小腿两骨间活动度甚小——和前臂骨间膜允许旋前旋后不是同一户。

**（4）足关节（joint of foot）**　包括距小腿关节（踝关节）、跗骨间关节、跗跖关节、跖骨间关节、跖趾关节和趾骨间关节（图1-74）。

::figure{src="/images/anatomy/textbook/p0079_02.png" caption="图1-74　足关节（水平切面）"}

1）**距小腿关节（talocrural joint）**　亦称踝关节（ankle joint），由胫、腓骨下端与距骨滑车构成，近似单轴的屈戌关节，背屈或跖屈时旋转轴可变。囊附着于各关节面周围，前、后壁薄而松弛，两侧有韧带增厚。

:::definition{label="距小腿关节"}
胫、腓骨下端与距骨滑车构成，亦称踝关节。近似单轴屈戌关节，作背屈（伸）和跖屈（屈）。距骨滑车前宽后窄：背屈稳，跖屈不稳。
:::

:::compare{title="踝关节两侧韧带"}
| | 内侧 | 外侧 |
|--|------|------|
| 名称 | 内侧韧带（三角韧带） | 外侧韧带，三条独立 |
| 组成 | 坚韧三角形纤维索 | 距腓前韧带、跟腓韧带、距腓后韧带 |
| 起止 | 内踝尖扇形 → 足舟骨、距骨、跟骨 | 均起自外踝，分别向前、下、后内止于距骨及跟骨 |
| 强弱 | 坚韧 | 均较薄弱 |
| 损伤 | 较少 | 足过度内翻易扭伤 |
:::

踝关节能作背屈（伸）和跖屈（屈）。距骨滑车前宽后窄：背屈时较宽的前部嵌入关节窝，关节较稳定；跖屈时较窄的后部进入关节窝，足能作轻微侧方运动，关节不够稳定，故扭伤多发生在跖屈（下山、下坡、下楼梯）（图1-75）。

::figure{src="/images/anatomy/textbook/p0080_01.png" caption="图1-75　踝关节周围韧带"}

:::pitfall{label="踝扭伤多在跖屈 + 内翻，伤的是外侧韧带"}
滑车后部窄，跖屈时窝里有余隙；外侧三条韧带又比三角韧带弱。写成「背屈时最容易扭」或「三角韧带最常断」，和本版原句相反。
:::

2）**跗骨间关节（intertarsal joint）**　以距跟关节（talocalcaneal joint，也称距下关节 subtalar joint）、距跟舟关节（talocalcaneonavicular joint）和跟骰关节（calcaneocuboid joint）较重要。

距跟关节和距跟舟关节在功能上是联合关节：跟骨与足舟骨连同其余足骨一起对距骨作内翻或外翻。足内侧缘提起、足底转向内侧为内翻；外侧缘提起、足底转向外侧为外翻。内、外翻常与踝关节协同：内翻常伴跖屈，外翻常伴背屈。

跟骰关节和距跟舟关节联合构成**跗横关节（transverse tarsal joint）**，又称 Chopart 关节。关节线横过跗骨中份，呈横位「S」形，内侧部凸向前，外侧部凸向后。两关节腔互不相通，解剖学上是两个独立关节，临床上常可沿此线离断足。

:::compare{title="跗骨间主要韧带（维持足弓）"}
| 韧带 | 要点 |
|------|------|
| 跟舟足底韧带（跳跃韧带） | 宽而肥厚，足底连跟骨与足舟骨；维持内侧纵弓 |
| 分歧韧带 | 「Y」形，跟骨前部背面分两股止于足舟骨和骰骨 |
| 其他足底韧带 | 连跟骨、骰骨和跖骨底，维持足弓 |
:::

3）**跗跖关节（tarsometatarsal joint）**　又称 Lisfranc 关节，由 3 块楔骨和骰骨的前端与 5 块跖骨底构成，属平面关节，可轻微滑动。内侧楔骨和第 1 跖骨之间可有轻微屈、伸。

4）**跖骨间关节（intermetatarsal joint）**　第 2～5 跖骨底毗邻面借韧带连结，平面关节，活动甚微。第 1、2 跖骨底之间并未相连，在这一点上与拇指相似。

5）**跖趾关节（metatarsophalangeal joint）**　跖骨头与近节趾骨底构成，可作轻微屈、伸、收、展。

6）**趾骨间关节（interphalangeal joint）**　各趾相邻两节趾骨的底与滑车构成，可作屈、伸。

**（5）足弓**　跗骨和跖骨借其连结形成凸向上的弓，称为足弓。灵长目中只有人类的足基于骨骼形态形成明显弓形。足弓是动态的，与肌肉、韧带构成功能上不可分割的复合体。习惯上分为前后方向的内、外侧纵弓和内外方向的一个横弓（图1-76）。足弓属于本节，不要写进第三节骨骼肌。

:::definition{label="足弓"}
跗骨和跖骨借连结形成的凸向上的弓，分内侧纵弓、外侧纵弓和一个横弓。与肌肉、韧带构成动态复合体，使足成为弹性「三脚架」。
:::

::figure{src="/images/anatomy/textbook/p0080_02.png" caption="图1-76　足弓"}

内侧纵弓由跟骨、距骨、足舟骨、3 块楔骨和内侧的 3 块跖骨连结构成，弓的**最高点为距骨头**。前端承重点在第 1 跖骨头，后端承重点是跟骨的跟结节。内侧纵弓比外侧纵弓高，活动性大，更具弹性。

外侧纵弓由跟骨、骰骨和外侧的 2 块跖骨连结构成，弓的最高点在骰骨。运动幅度非常有限，活动度较小，适于传递重力和推力，而不是吸收这些力。

横弓由骰骨、3 块楔骨和跖骨连结构成，弓的最高点在中间楔骨。横弓呈半穹窿形，足底凹陷朝内，两足紧紧并拢时形成完整穹窿。横弓通常由跖骨头传递力，腓骨长肌腱是维持横弓的强大力量。

:::compare{title="三个足弓"}
| 弓 | 构成 | 最高点 | 功能取向 |
|----|------|--------|----------|
| 内侧纵弓 | 跟、距、足舟、3 楔、内侧 3 跖骨 | **距骨头** | 高，活动大，弹性好 |
| 外侧纵弓 | 跟、骰、外侧 2 跖骨 | 骰骨 | 活动小，传重力与推力 |
| 横弓 | 骰、3 楔、跖骨 | 中间楔骨 | 半穹窿；跖骨头传力；腓骨长肌腱维持 |
:::

足弓增加足的弹性，使足成为具有弹性的「三脚架」，在行走和跳跃时发挥弹性和缓冲震荡的作用。除各骨的连结外，足底韧带以及足底长、短肌腱的牵引对维持足弓也起重要作用。这些韧带虽然坚韧，但缺乏主动收缩能力，一旦被拉长或受损，足弓便可能塌陷，成为扁平足。

:::pitfall{label="内侧纵弓最高点是距骨头，不是足舟骨"}
足舟骨在弓的中段，但本版原句把最高点写在距骨头。口诀若改成「舟骨最高」，和承重点（第 1 跖骨头、跟结节）会一起记错。
:::

:::insight{label="韧带能撑弓，但不能主动收缩"}
跟舟足底韧带（跳跃韧带）维持内侧纵弓，腓骨长肌腱维持横弓。韧带被拉长或受损 → 扁平足。主动的那一笔要等第三节的肌，但弓的形态学户头在本节。
:::

- [ ] 辅助结构：韧带（囊外 / 囊内）、关节盘（含半月板）、关节唇、滑膜襞和滑膜囊。
- [ ] 屈伸通常绕冠状轴；膝向后为屈；拇指屈伸绕矢状轴；踝背屈＝伸、跖屈＝屈。
- [ ] 常用分类：单轴（屈戌、车轴）、双轴（椭圆、鞍状）、多轴（球窝、平面）。髋是深窝球窝，幅度不及肩。
- [ ] 椎间盘 23 个（C1–C2 除外）＝ 纤维环 + 髓核。颈、腰前厚后薄；突出好发后外侧。
- [ ] 前纵韧带限制过度后伸，后纵韧带限制过度前屈。黄韧带连椎弓板，也限制前屈。
- [ ] 成人脊柱四弯：颈、腰凸向前，胸、骶凸向后。男约 70 cm，女约 60 cm；间盘约占全长 1/4。
- [ ] 颞下颌：纤维软骨关节面 + 关节盘分上、下腔；两侧联动；易向前脱位，复位先向下再向后。
- [ ] 胸锁关节是上肢与躯干的唯一关节。肩：头大窝浅，囊下壁弱，前下方脱位。肘：三关节一囊；幼儿牵拉 → 桡骨头半脱位；提携角 10°～15°。
- [ ] 桡腕关节头＝舟、月、三角，窝＝桡骨 + 关节盘，尺骨不参加。拇指腕掌＝鞍状，能对掌。
- [ ] 髋：前面囊到转子间线，后面只包颈内侧 2/3；髂股韧带限制过伸。
- [ ] 膝：前交叉伸膝紧张防胫骨前移，后交叉屈膝紧张防胫骨后移；内侧半月板 C 形连胫侧副韧带，更易伤。
- [ ] 踝：滑车前宽后窄，扭伤多在跖屈 + 内翻，伤外侧韧带。
- [ ] 足弓：内侧纵弓最高点为距骨头；外侧纵弓最高点骰骨；横弓最高点中间楔骨。韧带拉长 → 扁平足。
