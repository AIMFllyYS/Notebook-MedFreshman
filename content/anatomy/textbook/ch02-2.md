# 第二节　消化腺

第一节已经把消化管从口腔写到肛管。本节把消化系统的第二户——**消化腺**——从「管壁外的独立器官」落到肝、肝外胆道和胰。三大唾液腺（腮腺、下颌下腺、舌下腺）的形态、导管和开口已经在第一节口腔写过，这里只点名，不再把腮腺管横过咬肌、下颌下腺管开口于舌下阜再抄第二遍。下一章才是呼吸系统，本节写完胰就收束。

消化腺（alimentary gland）包括口腔腺、肝、胰和消化管壁内的许多小腺体。按体积大小和位置分成两类：大消化腺位于消化管壁外，本身是一个独立器官，分泌物经导管流入消化管腔，本版点名大唾液腺、肝和胰；小消化腺位于黏膜层或黏膜下层，如唇腺、颊腺、舌腺、食管腺、胃腺和肠腺。本节的正业是三件事：肝在腹腔里长什么样、胆汁怎样出肝进十二指肠、胰怎样横在腹后壁——黄疸、门脉高压和胰头肿大的定位，都从这三笔读起。

:::concept{term="先问这是不是管壁外的大消化腺，再问胆汁和胰液分别从哪条管道进十二指肠"}
看见「消化腺」，先不要默写肝段号码。先问：这个腺体是长在管壁里，还是管壁外的独立器官。壁内的是小消化腺，本节不展开；壁外的大消化腺里，三大唾液腺回口腔，剩下肝和胰才是本节正文。再问两根开口：胆汁走肝外胆道，胰液走胰管，二者多数在肝胰壶腹会合，开口于十二指肠大乳头。把开口提前记到空肠，或者把唾液腺整段从第一节搬过来，户头就并了。
:::

:::definition{label="消化腺"}
包括口腔腺、肝、胰和消化管壁内许多小腺体。按体积和位置分为大消化腺与小消化腺。大消化腺是独立器官，经导管把消化液送进消化管腔。
:::

:::definition{label="大消化腺"}
位于消化管壁外的独立器官，分泌物经导管流入消化管腔。本版点名大唾液腺、肝和胰。肝和胰是本节要写完的两座腺体；唾液腺只点名。
:::

:::compare{title="大消化腺 vs 小消化腺"}
| | 大消化腺 | 小消化腺 |
|--|----------|----------|
| 位置 | 消化管壁外，独立成器官 | 管壁内，黏膜层或黏膜下层 |
| 引流 | 自有导管通入消化管腔 | 就近开口于管腔面 |
| 本版例子 | 大唾液腺、肝、胰 | 唇腺、颊腺、舌腺、食管腺、胃腺、肠腺 |
| 本节怎么写 | 肝、肝外胆道、胰写全；三大唾液腺回第一节 | 不另立专节 |

:::

:::note{label="三大唾液腺只点名"}
腮腺、下颌下腺、舌下腺是三对大唾液腺。腮腺管开口于平对上颌第二磨牙的腮腺管乳头，下颌下腺管与舌下腺大管开口于舌下阜，舌下腺小管开口于舌下襞。形态、重量和导管行程以第一节为准，本节不再展开。
:::

## 一、肝

肝（liver）是人体内最大的腺体，也是最大的实质性器官。我国成年人肝的重量，男性为 1230～1450 g，女性为 1100～1300 g，约占体重的 1/50～1/40。胎儿和新生儿的肝相对较大，重量可达体重的 1/20，体积可占腹腔容积的一半以上。肝的长（左右径）×宽（上下径）×厚（前后径）约为 258 mm × 152 mm × 58 mm。血液供应十分丰富，活体呈棕红色。质地柔软而脆弱，易受外力冲击而破裂，发生腹腔内大出血。

功能极为复杂，是机体新陈代谢最活跃的器官：参与蛋白质、脂类、糖类和维生素等的合成、转化与分解，也参与激素、药物等的转化和解毒；还分泌胆汁，有吞噬、防御功能，胚胎时期还能造血。解剖学这一节不把生化通路写进来，但「分泌胆汁」这一笔要一直接到肝外胆道。

:::definition{label="肝"}
人体最大的腺体，也是最大的实质性器官。活体棕红、质软而脆。功能包括物质代谢、解毒、分泌胆汁、吞噬防御，以及胚胎时期造血。
:::

:::pitfall{label="新生儿肝相对大，不是一出生就该叫肝大"}
胎儿和新生儿肝可达体重的 1/20、腹腔容积一半以上，这是发育比例，不是病。体格检查那一笔要等到 7 岁以后：右肋弓下仍能触及，才考虑病理性肝大。把「小孩摸得到肝」一律写成病变，和后面的触诊标准会并户。
:::

:::insight{label="质软而脆，所以右季肋区的暴力不是「只断肋骨」"}
肝大部分被肋掩盖，但腹上区和右季肋区受到冲击或肋骨骨折时，肝可以裂。裂开之后首先是腹腔内大出血，不是等黄疸出现才想到肝。位置和毗邻写完，这句临床意义才落得住。
:::

### （一）肝的形态

肝呈不规则楔形，分为上、下两面，前、后、左、右 4 缘。上面膨隆，与膈相接触，称**膈面**（diaphragmatic surface）（图2-27）；下面凹凸不平，邻接腹腔器官，称**脏面**（visceral surface）（图2-28）。外形分叶先按韧带和 H 形沟来认，不要一上来用 Couinaud 段号替换左叶、右叶、方叶、尾状叶。

:::definition{label="膈面"}
肝上面膨隆、与膈相接触的一面。有镰状韧带和冠状韧带附着。后部冠状韧带两层之间无腹膜被覆的部分是裸区。
:::

:::definition{label="脏面"}
肝下面凹凸不平、邻接腹腔器官的一面。中部有略呈 H 形的三条沟，横沟即肝门。外形四叶主要在这一面划出来。
:::

::figure{src="/images/anatomy/textbook/p0136_01.png" caption="图2-27　肝（膈面）" alt="肝膈面，示镰状韧带、冠状韧带、左右三角韧带、肝左叶、肝右叶、肝圆韧带和胆囊"}

**1. 膈面的韧带与外形左、右叶**　膈面上有镰状韧带和冠状韧带附着。**镰状韧带**（falciform ligament）呈矢状位，肝借此分为左、右两叶：**肝左叶**（left lobe of liver）小而薄，**肝右叶**（right lobe of liver）大而厚。这是外形分叶，户头在镰状韧带，还不是后文按 Glisson 系统划的左、右半肝。

**冠状韧带**（coronary ligament）呈冠状位，分前、后两层。膈面后部两层之间没有腹膜被覆的部分称**裸区**（bare area）。裸区左侧有一较宽的沟，称为腔静脉沟，内有下腔静脉通过。冠状韧带向左、右延伸形成左、右三角韧带（图2-27）。

:::definition{label="镰状韧带"}
附着于肝膈面的矢状位腹膜皱襞，把外形上的肝分成左、右两叶。游离缘内有肝圆韧带行至脐。它不是正中裂，也不等于 Couinaud 的左、右半肝分界。
:::

:::definition{label="冠状韧带"}
附着于肝膈面的冠状位腹膜皱襞，分前、后两层。两层之间无腹膜的部分是裸区。
:::

:::definition{label="裸区"}
膈面后部冠状韧带前、后两层之间没有腹膜被覆的肝表面。裸区左侧的腔静脉沟内容纳下腔静脉。
:::

:::pitfall{label="镰状韧带分的是外形左、右叶，不是左、右半肝"}
外形：镰状韧带（脏面则是左纵沟）把肝分成小而薄的左叶和大而厚的右叶。管道：正中裂（胆囊切迹中点到下腔静脉左缘）才把肝分成左、右半肝。方叶、尾状叶在外形上跟着右叶走，在 Couinaud 里分别靠近左内叶和独立的尾状叶（Ⅰ段）。用八段号码替换「左叶、右叶、方叶、尾状叶」，本版的外形用语会丢。
:::

**2. 脏面的 H 形沟与肝门**　脏面中部有略呈 H 形的三条沟。中间的横沟称**肝门**（porta hepatis），位于脏面正中，有肝左、右管，肝固有动脉左、右支，肝门静脉左、右支和神经、淋巴管出入，又称**第一肝门**。出入肝门的这些结构被结缔组织包绕，构成**肝蒂**。

:::definition{label="肝门"}
肝脏面正中的横沟，即第一肝门。出入结构按本版名单：肝左、右管，肝固有动脉左、右支，肝门静脉左、右支，以及神经和淋巴管。
:::

:::definition{label="肝蒂"}
出入肝门的肝管、肝固有动脉、肝门静脉以及神经、淋巴管被结缔组织包绕后形成的结构。它是「第一肝门里那一把东西」，不是第二肝门的肝静脉。
:::

:::keypoint{label="第一肝门出入只记本版名单"}
- 肝左、右管。
- 肝固有动脉左、右支。
- 肝门静脉左、右支。
- 神经、淋巴管。
- 这些结构包在结缔组织里，叫肝蒂。
- 肝静脉不走第一肝门，它们在第二肝门出肝。
:::

左侧纵沟较窄而深：前部称**肝圆韧带裂**（fissure for ligamentum teres hepatis），有肝圆韧带通过；后部称**静脉韧带裂**（fissure for ligamentum venosum），容纳静脉韧带。**肝圆韧带**（ligamentum teres hepatis）由胎儿时期的脐静脉闭锁而成，经镰状韧带游离缘内行至脐。**静脉韧带**（ligamentum venosum）由胎儿时期的静脉导管闭锁而成。

右侧纵沟比左侧宽而浅：前部为一浅窝，容纳胆囊，称**胆囊窝**（fossa for gallbladder）；后部为**腔静脉沟**（sulcus for vena cava），容纳下腔静脉。腔静脉沟向后上伸入膈面，此沟与胆囊窝虽不相连，但可视为肝门右侧的纵沟。

在腔静脉沟的上端，肝左、中、右静脉出肝后立即注入下腔静脉，临床上常称此处为**第二肝门**（secondary porta of liver）。

:::definition{label="肝圆韧带"}
胎儿脐静脉闭锁而成的纤维索，走在肝圆韧带裂和镰状韧带游离缘内，行至脐。它是左纵沟前部的内容物，不是静脉韧带。
:::

:::definition{label="静脉韧带"}
胎儿静脉导管闭锁而成，容纳于静脉韧带裂（左纵沟后部）。和肝圆韧带一前一后，共同构成左纵沟。
:::

:::definition{label="第二肝门"}
腔静脉沟上端，肝左、中、右静脉出肝后立即注入下腔静脉的部位。出的是肝静脉，不是肝门静脉。
:::

:::compare{title="脏面 H 形沟怎么拆"}
| 沟 | 位置 | 前部 | 后部 |
|----|------|------|------|
| 横沟 | 脏面正中 | 即肝门（第一肝门） | 与前部同一条横沟 |
| 左纵沟 | 窄而深 | 肝圆韧带裂，走肝圆韧带（脐静脉残留） | 静脉韧带裂，走静脉韧带（静脉导管残留） |
| 右纵沟 | 宽而浅；前、后并不直接相连 | 胆囊窝，容纳胆囊 | 腔静脉沟，容纳下腔静脉；上端为第二肝门 |

:::

::figure{src="/images/anatomy/textbook/p0136_02.png" caption="图2-28　肝（脏面）" alt="肝脏面，示方叶、尾状叶、胆囊、肝门处肝固有动脉与肝门静脉、裸区和下腔静脉"}

**3. 脏面四叶**　借 H 形的沟、裂和窝，脏面把肝分为 4 个叶：

- **肝左叶**：位于肝圆韧带裂和静脉韧带裂的左侧，即左纵沟的左侧。与膈面的肝左叶一致。
- **肝右叶**：位于胆囊窝与腔静脉沟的右侧，即右纵沟的右侧。
- **方叶**（quadrate lobe）：位于肝门之前，肝圆韧带裂与胆囊窝之间。
- **尾状叶**（caudate lobe）：位于肝门之后，静脉韧带裂与腔静脉沟之间。

脏面的肝右叶、方叶和尾状叶加在一起，相当于膈面的肝右叶。方叶、尾状叶是外形用语，不要改写成「Ⅳ段」「Ⅰ段」再把四叶名单删掉。

:::definition{label="方叶"}
脏面、肝门之前，夹在肝圆韧带裂与胆囊窝之间的一叶。外形上它跟着膈面的右叶走，不是镰状韧带左侧的肝左叶。
:::

:::definition{label="尾状叶"}
脏面、肝门之后，夹在静脉韧带裂与腔静脉沟之间的一叶。第二肝门在它右后上方的腔静脉沟上端；背裂把它与左内叶、右前叶分开。
:::

:::compare{title="外形四叶：沟在哪，叶就在哪"}
| 叶 | 脏面边界 | 和膈面的关系 |
|----|----------|--------------|
| 肝左叶 | 左纵沟左侧 | 与膈面肝左叶一致 |
| 肝右叶 | 右纵沟右侧 | 只是膈面肝右叶的外侧份 |
| 方叶 | 肝门之前，肝圆韧带裂与胆囊窝之间 | 属于膈面肝右叶这一侧 |
| 尾状叶 | 肝门之后，静脉韧带裂与腔静脉沟之间 | 属于膈面肝右叶这一侧 |

膈面只看见镰状韧带分成的左叶（小而薄）和右叶（大而厚）。脏面把「大而厚」的那一侧再拆出方叶和尾状叶。
:::

**4. 肝的缘**　肝前缘是脏面与膈面的分界线，薄而锐利。胆囊窝处的前缘有**胆囊切迹**，胆囊底常在此处露出于肝前缘；肝圆韧带通过处有**肝圆韧带切迹**（notch for ligamentum teres hepatis），或称脐切迹。肝后缘钝圆，朝向脊柱。肝右缘是肝右叶的右下缘，亦钝圆。肝左缘即肝左叶的左缘，薄而锐利（见图2-28）。

:::definition{label="胆囊切迹"}
肝前缘在胆囊窝处的切迹。胆囊底常从此处露出，是后文胆囊底体表投影和正中裂脏面标志的共同锚点。
:::

**5. 浆膜与 Glisson 囊**　肝的表面，除膈面后份与膈愈着的部分（裸区）以及脏面各沟处以外，均覆有浆膜。浆膜与肝实质之间有一层结缔组织构成的纤维膜。在肝门处，纤维膜较发达，缠绕在肝固有动脉、肝门静脉和肝管及其分支的周围，构成血管周围纤维囊（或称 **Glisson 囊**）。后文 Glisson 系统，就是这三套管道加上这层囊。

:::definition{label="Glisson 囊"}
肝门处发达的纤维膜，缠绕肝固有动脉、肝门静脉和肝管及其分支，又称血管周围纤维囊。它包的是入肝的 Glisson 系统，不包出肝的肝静脉。
:::

### （二）肝的位置和毗邻

肝大部分位于右季肋区和腹上区，小部分位于左季肋区。前面大部分被肋掩盖，仅在腹上区左、右肋弓之间，有一小部分露出于剑突之下，直接与腹前壁相接触。腹上区和右季肋区遭到暴力冲击或肋骨骨折时，肝可能被损伤而破裂。

:::definition{label="肝的位置"}
大部分在右季肋区和腹上区，小部分到左季肋区。前面多被肋掩盖，仅剑突下左、右肋弓之间的一小块直接贴腹前壁。
:::

**体表投影**　肝上界与膈穹窿一致，用三点的连线表示：右锁骨中线与第 5 肋的交点，前正中线与剑胸结合线的交点，左锁骨中线与第 5 肋间隙的交点。肝下界与肝前缘一致：右侧与右肋弓一致；中部超出剑突下约 3 cm；左侧被肋弓掩盖。因此体格检查时，在右肋弓下不能触到肝。但 3 岁以下的健康幼儿，腹腔容积较小而肝相对较大，肝前缘常低于右肋弓下 1.5～2.0 cm；到 7 岁以后，在右肋弓下不能触到，若能触及，则应考虑为病理性肝大。

:::compare{title="肝上界三点、下界三句"}
| | 标志 |
|--|------|
| 上界右点 | 右锁骨中线 × 第 5 肋 |
| 上界中点 | 前正中线 × 剑胸结合 |
| 上界左点 | 左锁骨中线 × 第 5 肋间隙 |
| 下界右侧 | 与右肋弓一致 |
| 下界中部 | 超出剑突下约 3 cm |
| 下界左侧 | 被肋弓掩盖 |
| 成人触诊 | 右肋弓下不能触及 |
| 3 岁以下 | 可低于右肋弓下 1.5～2.0 cm |
| 7 岁以后仍能触及 | 考虑病理性肝大 |

:::

:::pitfall{label="右锁骨中线对的是第5肋，左侧对的是第5肋间隙"}
上界三点不要写成左右对称都在第 5 肋。右侧是第 5 肋，左侧是第 5 肋间隙，中间是剑胸结合。记成「一律第 5 肋」或「一律肋间隙」，叩诊肝上界会差一肋。
:::

**毗邻**　肝上方为膈，膈上有右侧胸膜腔、右肺及心等，故肝脓肿有时可与膈粘连，并经膈侵入右肺，甚至脓汁还能经支气管排出。肝右叶下面：前部与结肠右曲邻接，中部近肝门处邻接十二指肠上曲，后部邻接右肾上腺和右肾。肝左叶下面与胃前壁相邻，后上方邻接食管腹部。

肝借镰状韧带和冠状韧带连于膈下面和腹前壁，呼吸时肝可随膈上下移动。平静呼吸时，上下移动范围为 2～3 cm。

:::compare{title="肝脏面贴着谁"}
| 部位 | 邻接 |
|------|------|
| 上方（隔着膈） | 右侧胸膜腔、右肺、心；脓肿可穿膈入右肺 |
| 右叶下面前部 | 结肠右曲 |
| 右叶下面中部近肝门 | 十二指肠上曲 |
| 右叶下面后部 | 右肾上腺、右肾 |
| 左叶下面 | 胃前壁 |
| 左叶后上方 | 食管腹部 |

:::

:::insight{label="肝随膈上下走 2～3 cm，触诊要会用呼吸"}
平静呼吸时肝不是钉死在第 5 肋上的。深吸气膈下降，肝前缘可以一过性压向肋弓下，这和「7 岁以后病理性肝大」不是同一回事。检查要在同一呼吸时相里比较，不要把随呼吸移动写成肿大。
:::

### （三）肝的分叶和分段

外形四叶（左叶、右叶、方叶、尾状叶）已经在脏面立住。外科定位还要按肝内管道再划半肝、叶和段。两套用语并存：先报外形四叶，再报 Glisson 系统上的半肝和段，不要用八段名单把方叶、尾状叶从教材里删掉。

#### 1. 肝叶与肝段

肝内有 4 套管道，形成两个系统，即 **Glisson 系统**和**肝静脉系统**（图2-29）。肝门静脉、肝固有动脉和肝管的各级分支在肝内的走行、分支和配布基本一致，并有 Glisson 囊包绕，共同组成 Glisson 系统。

肝段依据 Glisson 系统在肝内的分布提出。按照 Couinaud 肝段划分法，可将肝分为左、右半肝，进而再分成 5 个叶和 8 个段（表2-5，图2-30）。Glisson 系统位于肝叶和肝段内；肝静脉系统的各级属支行于肝段之间，其主干即肝左、中、右静脉，相应地行于各肝裂中，最后在腔静脉沟上端即第二肝门处出肝，分别注入下腔静脉（见图2-29）。

有若干条肝静脉系统的小静脉，如来自右半肝脏面的副肝右静脉和尾状叶的一些小静脉，在腔静脉沟的下段内汇入下腔静脉，该处称**第三肝门**。

:::definition{label="Glisson 系统"}
肝门静脉、肝固有动脉和肝管的各级分支，走行、分支和配布基本一致，外有 Glisson 囊包绕。它们走在肝叶和肝段**里面**，是分段的依据。
:::

:::definition{label="肝静脉系统"}
肝左、中、右静脉及其属支。主干走在肝裂里，属支走在肝段之间，在第二肝门出肝注入下腔静脉。它不包在 Glisson 囊里，也不走第一肝门。
:::

:::definition{label="第三肝门"}
腔静脉沟下段，副肝右静脉和尾状叶的小静脉汇入下腔静脉的部位。与第二肝门同在腔静脉沟，一个在上端（三大肝静脉），一个在下段（若干小静脉）。
:::

:::compare{title="三个肝门各走什么"}
| | 部位 | 出入的结构 |
|--|------|------------|
| 第一肝门 | 脏面横沟 | 肝左、右管，肝固有动脉左、右支，肝门静脉左、右支，神经、淋巴管 |
| 第二肝门 | 腔静脉沟上端 | 肝左、中、右静脉出肝注入下腔静脉 |
| 第三肝门 | 腔静脉沟下段 | 副肝右静脉、尾状叶小静脉汇入下腔静脉 |

入肝看第一肝门，出肝看第二、第三肝门。把肝静脉写成「从肝门进去」，和门静脉会并户。
:::

::figure{src="/images/anatomy/textbook/p0137_01.png" caption="图2-29　肝内管道与肝裂" alt="肝内肝门静脉属支与肝静脉主干，示正中裂、左叶间裂、右叶间裂和左、右段间裂"}

:::keypoint{label="两套管道一内一间"}
- Glisson 系统（门静脉 + 固有动脉 + 肝管）在段内。
- 肝静脉在段间、裂内，第二肝门出肝。
- 肝部分切除优先沿肝裂走，因为裂里缺少 Glisson 系统。
:::

#### 2. 肝裂和肝段划分法

肝内有些部位缺少 Glisson 系统的分布，这些部位称**肝裂**（hepatic fissure）。肝裂是分叶、分段的自然界线，也是肝部分切除的适宜部位。肝内有 3 个叶间裂、3 个段间裂。叶间裂：正中裂、左叶间裂、右叶间裂。段间裂：左段间裂、右段间裂、背裂（图2-30）。

:::definition{label="肝裂"}
肝内缺少 Glisson 系统分布的部位。既是分叶分段的自然界线，也是肝部分切除的适宜平面。叶间裂 3 条，段间裂 3 条。
:::

**正中裂**（middle hepatic fissure）在膈面相当于自肝前缘胆囊切迹中点至下腔静脉左缘连线的平面；脏面以胆囊窝和腔静脉沟为标志。裂内有肝中静脉走行。此裂将肝分为对称的左、右半肝，直接分开相邻的左内叶与右前叶。

**右叶间裂**（right interlobar fissure）位于正中裂右侧。膈面相当于从肝前缘胆囊切迹右侧部的外、中 1/3 交界处，斜向右上到达下腔静脉右缘连线的平面，转至脏面连于肝门右端。裂内有肝右静脉走行。此裂将右半肝分为右前叶和右后叶。

**左叶间裂**（left interlobar fissure）位于正中裂左侧，起自肝前缘肝圆韧带切迹，向后上至肝左静脉汇入下腔静脉处连线的平面。膈面相当于镰状韧带附着线的左侧 1 cm，脏面以左纵沟为标志。裂内有肝左静脉的左叶间支走行。此裂将左半肝分为左外叶和左内叶。

**左段间裂**（left intersegmental fissure）相当于自肝左静脉汇入下腔静脉处与肝左缘的中、上 1/3 交界处连线的平面。裂内有肝左静脉走行。此裂将左外叶分为上、下两段。

**右段间裂**（right intersegmental fissure）在脏面相当于肝门横沟的右端与肝右缘中点连线的平面，再转到膈面，向左至正中裂。此裂相当于肝门静脉右支主干平面，既把右前叶分为右前上、下段，又将右后叶分为右后上、下段。

**背裂**（dorsal fissure）位于尾状叶前方，将尾状叶与左内叶和右前叶分开。上起自肝左、中、右静脉出肝处（第二肝门），下至第一肝门，在肝上极形成一弧形线。

:::definition{label="正中裂"}
自胆囊切迹中点至下腔静脉左缘的平面，脏面以胆囊窝和腔静脉沟为标志，裂内走肝中静脉。它分的是左、右半肝，不是镰状韧带分的外形左、右叶。
:::

:::definition{label="右叶间裂"}
正中裂右侧，裂内走肝右静脉。把右半肝分成右前叶和右后叶。
:::

:::definition{label="左叶间裂"}
正中裂左侧，脏面以左纵沟为标志，膈面约在镰状韧带附着线左侧 1 cm，裂内走肝左静脉的左叶间支。把左半肝分成左外叶和左内叶。
:::

:::compare{title="三条叶间裂：标志、裂内静脉、分开谁"}
| 裂 | 膈面 / 脏面标志 | 裂内静脉 | 分开的叶 |
|----|-----------------|----------|----------|
| 正中裂 | 胆囊切迹中点 → 下腔静脉左缘；脏面：胆囊窝 + 腔静脉沟 | 肝中静脉 | 左半肝 / 右半肝（左内叶 / 右前叶） |
| 右叶间裂 | 胆囊切迹右侧部外、中 1/3 交界 → 下腔静脉右缘；脏面连肝门右端 | 肝右静脉 | 右前叶 / 右后叶 |
| 左叶间裂 | 肝圆韧带切迹 → 肝左静脉入下腔静脉；膈面在镰状韧带左侧约 1 cm；脏面即左纵沟 | 肝左静脉左叶间支 | 左外叶 / 左内叶 |

:::

:::compare{title="三条段间裂"}
| 裂 | 平面 | 裂内结构 | 分开的段 |
|----|------|----------|----------|
| 左段间裂 | 肝左静脉入下腔静脉处 × 肝左缘中、上 1/3 交界 | 肝左静脉 | 左外叶上段 / 下段（Ⅱ / Ⅲ） |
| 右段间裂 | 脏面：肝门横沟右端 × 肝右缘中点，转膈面向左至正中裂 | 约当肝门静脉右支主干平面 | 右前上、下段（Ⅷ / Ⅴ）；右后上、下段（Ⅶ / Ⅵ） |
| 背裂 | 第二肝门 → 第一肝门，肝上极弧形 | 尾状叶前方 | 尾状叶与左内叶、右前叶 |

:::

:::pitfall{label="左叶间裂在镰状韧带左侧约 1 cm，不是贴在韧带上"}
外形左、右叶的界是镰状韧带；Couinaud 左外叶与左内叶的界（左叶间裂）还要再偏左约 1 cm。把「韧带左边全是Ⅱ、Ⅲ段」写成贴着镰状韧带切，左内叶（Ⅳ段）会被切错。
:::

## 二、肝外胆道系统

肝外胆道系统是指肝门之外的胆道系统，包括胆囊和输胆管道（肝左管、肝右管、肝总管和胆总管）。这些管道与肝内胆道一起，把肝分泌的胆汁输送到十二指肠腔（图2-31）。肝内的毛细胆管、小叶间胆管属于肝实质，不另立节；出了肝门，才进入本节。

:::definition{label="肝外胆道系统"}
肝门之外的胆道，包括胆囊和输胆管道。输胆管道是肝左管、肝右管、肝总管和胆总管。功能是把胆汁送到十二指肠腔。
:::

:::concept{term="先问胆汁现在是进胆囊还是进十二指肠，再问开口在大乳头还是偶尔单独开口"}
看见一根绿色的管子，先不要报「胆总管」三个字。先问：肝门以里还是肝门以外。以外再问四件套齐不齐：胆囊、肝左管、肝右管、肝总管、胆总管。最后才问下端：多数与胰管汇合成肝胰壶腹，开口于十二指肠大乳头；少数胆总管单独开口。把胆囊当成「造胆汁的器官」，和肝的分泌功能会并户。
:::

### （一）胆囊

胆囊（gallbladder）为贮存和浓缩胆汁的囊状器官，呈梨形，长 8～12 cm，宽 3～5 cm，容量 40～60 ml。位于肝下面的胆囊窝内，上面借疏松结缔组织与肝相连，易于分离；下面覆以浆膜，并与结肠右曲和十二指肠上曲相邻。位置有的较深，甚至埋在肝实质内；有的各面均覆以浆膜，并借系膜连于胆囊窝，可以活动。

:::definition{label="胆囊"}
贮存和浓缩胆汁的梨形囊状器官，长 8～12 cm，宽 3～5 cm，容量 40～60 ml，位于肝脏面胆囊窝内。它不制造胆汁，制造者是肝。
:::

:::pitfall{label="胆囊贮存浓缩胆汁，并不分泌胆汁"}
肝细胞分泌胆汁，胆囊负责存和浓。写成「胆囊分泌胆汁」或「没有胆囊就不能产生胆汁」，和切除胆囊后胆汁仍能经肝总管入胆总管这一事实对不上。
:::

胆囊分底、体、颈、管 4 部分（图2-31）。

**胆囊底**（fundus of gallbladder）是胆囊突向前下方的盲端，常在肝前缘的胆囊切迹处露出。胆汁充满时，胆囊底可贴近腹前壁。体表投影位于右腹直肌外缘或右锁骨中线与右肋弓交点附近。胆囊发炎时，该处可有压痛。

**胆囊体**（body of gallbladder）是胆囊的主体部分，与胆囊底之间无明显界限。体向后逐渐变细，约在肝门右端附近移行为胆囊颈。

**胆囊颈**（neck of gallbladder）狭细，在肝门右端常以直角起于胆囊体，略作 S 状扭转：开始向前上方弯曲，继而转向后下方续为胆囊管。颈与管相延续处较狭窄。胆囊颈借疏松结缔组织连于肝，胆囊动脉通过该疏松结缔组织分布于胆囊。在胆囊颈的右侧壁常有一突向后下方的小囊，朝向十二指肠，称为 **Hartmann 囊**，胆囊结石常在此处存留。较大的 Hartmann 囊可与胆囊管粘连，手术中分离、结扎切断胆囊管时易将此囊包入而损伤。

**胆囊管**（cystic duct）比胆囊颈稍细，长约 3～4 cm，直径 0.2～0.3 cm，在肝十二指肠韧带内与其左侧的肝总管汇合，形成胆总管。

:::definition{label="胆囊底"}
胆囊突向前下方的盲端，常在肝前缘胆囊切迹处露出。体表投影：右腹直肌外缘或右锁骨中线与右肋弓交点附近。发炎时此处压痛。
:::

:::definition{label="胆囊体"}
胆囊的主体，与底无明显界限，向后变细，约在肝门右端移行为胆囊颈。
:::

:::definition{label="胆囊颈"}
狭细，在肝门右端常以直角起于体，略呈 S 状扭转后续胆囊管。右侧壁常有 Hartmann 囊，结石好存于此。
:::

:::definition{label="胆囊管"}
比颈稍细，长约 3～4 cm，直径 0.2～0.3 cm，在肝十二指肠韧带内与左侧肝总管汇合成胆总管。管内有螺旋襞。
:::

:::definition{label="Hartmann 囊"}
胆囊颈右侧壁突向后下方、朝向十二指肠的小囊。结石常在此存留；囊较大时可与胆囊管粘连，术中易被包入而损伤。
:::

胆囊内面衬以黏膜。底和体的黏膜呈蜂窝状；颈和管的黏膜呈螺旋状突入腔内，形成**螺旋襞**（spiral fold，或称 Heister 瓣）（图2-31），可控制胆汁的流入和流出。较大的结石也常因螺旋襞阻碍而嵌顿于此。

:::definition{label="螺旋襞"}
衬于胆囊颈和胆囊管的螺旋状黏膜皱襞，又称 Heister 瓣，控制胆汁流入和流出。结石可在此嵌顿。底和体的黏膜是蜂窝状，不要写成整囊都是螺旋瓣。
:::

::figure{src="/images/anatomy/textbook/p0139_01.png" caption="图2-31　胆囊与输胆管道" alt="胆囊底体颈管、肝总管、胆总管、肝胰壶腹及 Oddi 括约肌，以及胆囊和胆管的剖面"}

胆囊管、肝总管和肝的脏面围成的三角形区域称**胆囊三角**（或称 Calot 三角），三角内常有胆囊动脉通过，因此该三角是胆囊手术中寻找胆囊动脉的标志。

:::definition{label="胆囊三角"}
胆囊管、肝总管和肝脏面围成的三角形，又称 Calot 三角。三角内常有胆囊动脉经过，是术中寻找胆囊动脉的标志。
:::

:::compare{title="胆囊四部各管什么"}
| 部 | 形态要点 | 临床锚点 |
|----|----------|----------|
| 底 | 前下盲端，常露于胆囊切迹 | 体表：右腹直肌外缘或右锁骨中线 × 右肋弓；炎时压痛 |
| 体 | 主体，与底无明显界限 | 下面邻结肠右曲、十二指肠上曲 |
| 颈 | 狭细，直角起始，S 状扭转 | Hartmann 囊；结石；胆囊动脉从颈与肝之间的疏松组织入胆囊 |
| 管 | 长 3～4 cm，直径 0.2～0.3 cm | 螺旋襞；与肝总管锐角合成胆总管；参与围成胆囊三角 |

:::

:::pitfall{label="胆囊底的体表投影有两个等价说法"}
本版写的是「右腹直肌外缘**或**右锁骨中线与右肋弓交点附近」。两句指向同一点附近，不是两个不同器官。只背「锁骨中线」丢掉腹直肌外缘，或把投影写成麦氏点，都会错位——麦氏点是阑尾，在第一节。
:::

### （二）肝管和肝总管

肝左、右管分别由左、右半肝内的毛细胆管逐渐汇合而成，出肝门之后即合成肝总管。**肝总管**（common hepatic duct）长约 3 cm，下行于肝十二指肠韧带内，并在韧带内与胆囊管以锐角结合成胆总管（见图2-31，图2-32）。

:::definition{label="肝左管与肝右管"}
分别引流左、右半肝的胆汁，由半肝内毛细胆管逐渐汇合，出肝门后合成肝总管。这里的左、右半肝是正中裂分出来的，不是外形左、右叶。
:::

:::definition{label="肝总管"}
肝左、右管出肝门后合成，长约 3 cm，走在肝十二指肠韧带内，与胆囊管以锐角汇合成胆总管。
:::

:::pitfall{label="肝总管不是胆总管"}
肝左、右管 → 肝总管；肝总管再加胆囊管 → 胆总管。把「总管」一律叫胆总管，胆囊切除时结扎平面会搞错：该留的是肝总管，该切的是胆囊管。
:::

### （三）胆总管

**胆总管**（common bile duct）由肝总管与胆囊管汇合而成。长度取决于两者汇合部位的高低，一般长约 4～8 cm，直径 0.6～0.8 cm。直径若超过 1 cm，可视为病理状态。管壁含大量弹性纤维，有一定舒缩能力；下端梗阻时（如胆总管结石或胆道蛔虫症），管腔可扩张到相当粗，甚至达肠管粗细，而不致破裂。

胆总管在肝十二指肠韧带内下行于肝固有动脉的右侧、肝门静脉的前方，向下经十二指肠上部的后方，降至胰头后方，再转向十二指肠降部中份，在此处的十二指肠后内侧壁内与胰管汇合，形成一略膨大的共同管道称**肝胰壶腹**（hepatopancreatic ampulla，或称 Vater 壶腹），开口于十二指肠大乳头（见图2-31）。少数情况，胆总管未与胰管汇合而单独开口于十二指肠腔。

:::definition{label="胆总管"}
肝总管与胆囊管汇合而成，一般长 4～8 cm，直径 0.6～0.8 cm；超过 1 cm 视为病理。在肝十二指肠韧带内位于肝固有动脉右侧、肝门静脉前方。
:::

:::definition{label="肝胰壶腹"}
胆总管与胰管在十二指肠降部后内侧壁内汇合后略膨大的共同管道，又称 Vater 壶腹，开口于十二指肠大乳头。少数胆总管不汇合而单独开口。
:::

在肝胰壶腹周围有**肝胰壶腹括约肌**（sphincter of hepatopancreatic ampulla）包绕，在胆总管末段及胰管末段周围亦有少量平滑肌包绕。以上三部分括约肌统称为 **Oddi 括约肌**（见图2-31）。Oddi 括约肌平时保持收缩状态。

:::definition{label="Oddi 括约肌"}
三部分平滑肌的统称：肝胰壶腹括约肌，加上胆总管末段和胰管末段周围的少量平滑肌。平时收缩，进食后舒张，让胆汁（和胰液）进入十二指肠。
:::

:::compare{title="肝十二指肠韧带内，胆总管跟谁前后左右"}
| 结构 | 相对胆总管 |
|------|------------|
| 肝固有动脉 | 胆总管在其**右侧** |
| 肝门静脉 | 胆总管在其**前方** |
| 去向 | 向下经十二指肠上部后方 → 胰头后方 → 十二指肠降部后内侧壁 |

韧带内这一段就是后文所称十二指肠上段。不要把肝门静脉写成走在胆总管前面。
:::

由肝分泌的胆汁，经肝左管、肝右管、肝总管、胆囊管进入胆囊内贮存。进食后，尤其进食高脂肪食物时，在神经体液因素调节下，胆囊收缩，Oddi 括约肌舒张，使胆汁自胆囊经胆囊管、胆总管、肝胰壶腹、十二指肠大乳头，排入十二指肠腔（图2-32）。

:::timeline{period="胆汁的两条路"}
- **空腹贮存** 肝左、右管 → 肝总管 → 胆囊管 → 胆囊（贮存并浓缩）
- **Oddi 平时** 保持收缩，胆汁不向十二指肠漏
- **进食后（尤其高脂肪）** 胆囊收缩，Oddi 括约肌舒张
- **排出路径** 胆囊 → 胆囊管 → 胆总管 → 肝胰壶腹 → 十二指肠大乳头 → 十二指肠腔
- **少数变异** 胆总管未与胰管汇合，单独开口于十二指肠腔
:::

:::pitfall{label="空腹时胆汁不是从肝总管直灌十二指肠"}
Oddi 括约肌平时收缩，肝来的胆汁被改道进胆囊。写成「肝总管直接开口于十二指肠」或「不吃饭也在往肠腔滴胆汁」，和贮存、浓缩这两项功能都对不上。排出必须同时有胆囊收缩和 Oddi 舒张。
:::

根据胆总管的行程，可将其分为 4 段：十二指肠上段、十二指肠后段、胰腺段和十二指肠壁段。四段就是前面那句行程拆开，不要另造长度数字。

:::compare{title="胆总管四段（按行程拆）"}
| 段 | 行程上对应哪一句 | 毗邻要点 |
|----|------------------|----------|
| 十二指肠上段 | 在肝十二指肠韧带内下行 | 肝固有动脉右侧、肝门静脉前方 |
| 十二指肠后段 | 经十二指肠上部的后方 | 贴十二指肠上部后面下行 |
| 胰腺段 | 降至胰头后方 | 可部分或全部被胰头实质包埋；胰头肿大可压管致阻塞性黄疸 |
| 十二指肠壁段 | 转向十二指肠降部中份的后内侧壁内 | 与胰管汇合成肝胰壶腹，开口于十二指肠大乳头 |

:::

::figure{src="/images/anatomy/textbook/p0140_01.png" caption="图2-32　胆道、十二指肠和胰" alt="肝内胆管汇成肝总管，胆囊管汇入后成胆总管，与胰管会于十二指肠大乳头；并示副胰管开口于十二指肠小乳头"}

:::cause-effect{title="胆总管下端堵住之后为什么管子能变粗却不一定裂"}
- **因** 管壁含大量弹性纤维，有舒缩能力；下端梗阻（结石、蛔虫等）时压力升高
- **果** 管腔可扩张到相当粗，甚至接近肠管口径，而不致破裂。直径超过 1 cm 已视为病理，但「粗」不等于「已经穿孔」
:::

## 三、胰

胰（pancreas）是人体第二大的消化腺，由外分泌部和内分泌部组成。外分泌部（腺细胞）分泌胰液，内含多种消化酶（如蛋白酶、脂肪酶及淀粉酶等），分解消化蛋白质、脂肪和糖类；内分泌部即胰岛，散在于胰实质内，胰尾部较多，主要分泌胰岛素，调节血糖浓度。解剖学这一节把胰岛的位置写在胰尾偏多，不把 A 细胞、B 细胞的名单从组织学搬进来。

:::definition{label="胰"}
人体第二大消化腺，横在腹后壁。外分泌部分泌含蛋白酶、脂肪酶、淀粉酶的胰液；内分泌部是胰岛，胰尾较多，主要分泌胰岛素。
:::

:::compare{title="胰的外分泌部 vs 内分泌部"}
| | 外分泌部 | 内分泌部 |
|--|----------|----------|
| 本质 | 腺细胞，有导管 | 胰岛，散在实质内 |
| 产物 | 胰液（蛋白酶、脂肪酶、淀粉酶等） | 主要是胰岛素 |
| 去向 | 胰管 →（多数）肝胰壶腹 → 十二指肠大乳头 | 入血，调节血糖 |
| 分布提示 | 贯穿头颈体尾 | 胰尾部较多 |

:::

### （一）胰的位置和毗邻

胰是一个狭长的腺体，质地柔软，呈灰红色，长 17～20 cm，宽 3～5 cm，厚 1.5～2.5 cm，重 82～117 g，位于腹上区和左季肋区，横置于第 1～2 腰椎椎体前方，并紧贴于腹后壁。前面隔网膜囊与胃相邻，后方有下腔静脉、胆总管、肝门静脉和腹主动脉等重要结构。右端被十二指肠环抱，左端抵达脾门。上缘约平脐上 10 cm，下缘约相当于脐上 5 cm。位置较深，前方有胃、横结肠和大网膜等遮盖，故胰病变时早期腹壁体征往往不明显，增加了诊断困难。

:::definition{label="胰的位置"}
腹上区和左季肋区，横置于第 1～2 腰椎椎体前方，紧贴腹后壁。右端被十二指肠环抱，左端抵脾门；前面隔网膜囊邻胃。
:::

:::compare{title="胰四周贴着谁"}
| 方向 | 毗邻 |
|------|------|
| 前方 | 隔网膜囊邻胃；更浅面还有横结肠、大网膜 |
| 后方 | 下腔静脉、胆总管、肝门静脉、腹主动脉 |
| 右端 | 十二指肠环抱（头） |
| 左端 | 抵达脾门（尾） |
| 上、下缘体表 | 约平脐上 10 cm、脐上 5 cm |

:::

:::insight{label="深、被盖住，所以早期可以没有腹壁体征"}
胰贴腹后壁，前面隔着网膜囊、胃、横结肠和大网膜。病变早期腹壁可以看起来安静，不等于胰没有事。这和肝在剑突下还有一小块贴腹前壁不一样。
:::

### （二）胰的分部

胰可分头、颈、体、尾 4 部分，各部之间无明显界限（图2-33）。头、颈部在腹中线右侧，体、尾部在腹中线左侧。

:::definition{label="胰的分部"}
头、颈、体、尾四部，部间无明显界限。头、颈在腹中线右侧，体、尾在腹中线左侧。
:::

::figure{src="/images/anatomy/textbook/p0141_01.png" caption="图2-33　胰的分部和毗邻" alt="胰头被十二指肠环抱，钩突附近有肠系膜上动静脉，颈、体、尾向左抵脾门，后方可见腹主动脉和下腔静脉"}

**胰头**（head of pancreas）为胰右端膨大的部分，位于第 2 腰椎椎体的右前方，其上、下方和右侧被十二指肠包绕。胰头下部有一向左后上方的**钩突**（uncinate process）。钩突与胰头和胰颈之间夹有肝门静脉起始部和肠系膜上动、静脉，故胰头肿大时可压迫肝门静脉起始部，影响血液回流，出现腹水、脾大等症状。胰头右后方与十二指肠降部之间常有胆总管经过，有时胆总管可部分或全部被胰头实质包埋。胰头肿大压迫胆总管时，可影响胆汁排出，发生阻塞性黄疸。

:::definition{label="胰头"}
胰右端的膨大部，位于第 2 腰椎椎体右前方，上、下和右侧被十二指肠包绕。肿大既可压胆总管致阻塞性黄疸，也可压肝门静脉起始部致腹水、脾大。
:::

:::definition{label="钩突"}
胰头下部向左后上方的突起。它与胰头、胰颈之间夹着肝门静脉起始部和肠系膜上动、静脉。
:::

:::cause-effect{title="胰头肿大为什么会又黄又有腹水"}
- **因 1** 胆总管走在胰头右后方，可被胰头实质包埋 → **果** 胆汁排出受阻，阻塞性黄疸
- **因 2** 钩突与头、颈之间夹肝门静脉起始部和肠系膜上动、静脉 → **果** 门静脉回流受阻，腹水、脾大
- 两套管道紧挨着胰头，不要把黄疸只写成「肝坏了」、把腹水只写成「腹膜病」
:::

**胰颈**（neck of pancreas）是位于胰头与胰体之间的狭窄扁薄部分，长 2.0～2.5 cm。前上方邻接胃幽门，后面有肠系膜上静脉和肝门静脉起始部通过。肠系膜上静脉经过胰颈后面时，没有来自胰腺的小静脉注入其中，因此行胰头十二指肠切除术时，可沿肠系膜上静脉前面与胰颈后面之间进行剥离，以备切断胰腺（图2-33）。

:::definition{label="胰颈"}
头与体之间的狭窄扁薄部，长 2.0～2.5 cm。前上邻胃幽门，后面有肠系膜上静脉和肝门静脉起始部。肠系膜上静脉此段无胰腺小静脉注入，是手术剥离平面。
:::

**胰体**（body of pancreas）位于胰颈与胰尾之间，占胰的大部分，略呈三棱柱形。横位于第 1 腰椎椎体前方，故向前凸起。前面隔网膜囊与胃后壁相邻，故胃后壁癌肿或溃疡穿孔时常与胰体粘连。

:::definition{label="胰体"}
颈与尾之间的大部分，略呈三棱柱形，横在第 1 腰椎前方而前凸。前面隔网膜囊邻胃后壁，胃后壁病变常与之粘连。
:::

**胰尾**（tail of pancreas）较细，行向左上方至左季肋区，在脾门下方与脾的脏面相接触。胰尾各面均包有腹膜，此点可作为与胰体分界的标志。胰尾与脾血管一起位于脾肾韧带两层之间，故脾切除需结扎脾血管时，应注意勿损伤胰尾（图2-33）。

:::definition{label="胰尾"}
较细，行向左上至左季肋区，在脾门下方接触脾的脏面。各面均包腹膜，借此与胰体分界；与脾血管同走脾肾韧带两层之间。
:::

:::compare{title="头颈体尾：位置、关键毗邻、临床一句"}
| 部 | 位置 | 关键毗邻 | 临床一句 |
|----|------|----------|----------|
| 头 | 第 2 腰椎右前方，腹中线右侧 | 十二指肠环抱；钩突夹门静脉起始部与肠系膜上动、静脉；右后方走胆总管 | 肿大 → 阻塞性黄疸和/或腹水、脾大 |
| 颈 | 头、体之间，长 2.0～2.5 cm | 前上邻幽门；后有肠系膜上静脉、门静脉起始部 | 可沿肠系膜上静脉前面与颈后面之间剥离 |
| 体 | 大部分，第 1 腰椎前方 | 隔网膜囊邻胃后壁 | 胃后壁癌或溃疡穿孔常与之粘连 |
| 尾 | 左季肋区，抵脾门下方 | 各面包腹膜；与脾血管同在脾肾韧带内 | 脾切除结扎脾血管时勿伤胰尾 |

:::

:::pitfall{label="胰尾各面包腹膜，不是整条胰都是腹膜内位"}
本版把「各面均包有腹膜」明确写成与胰体分界的标志。头、颈、体贴腹后壁，并不各面都包腹膜。写成「胰是腹膜内位器官」或「尾和体的腹膜情况一样」，和脾肾韧带里那一笔会冲突。
:::

**胰管与副胰管**　**胰管**（pancreatic duct）位于胰实质内，偏背侧，走行与胰的长轴一致，从胰尾经胰体走向胰头，沿途接受许多小叶间导管，最后于十二指肠降部的后内侧壁内与胆总管汇合成肝胰壶腹，开口于十二指肠大乳头；偶尔单独开口于十二指肠腔。在胰头上部常可见一小管，行于胰管上方，称**副胰管**（accessory pancreatic duct），开口于十二指肠小乳头，主要引流胰头前上部的胰液（见图2-32）。

:::definition{label="胰管"}
走在胰实质内偏背侧，与长轴一致：尾 → 体 → 头，收小叶间导管，多数与胆总管汇成肝胰壶腹，开口于十二指肠大乳头；偶尔单独开口。
:::

:::definition{label="副胰管"}
常位于胰头上部、胰管上方的小管，开口于十二指肠小乳头，主要引流胰头前上部的胰液。
:::

:::compare{title="胰液从哪两个乳头进十二指肠"}
| 管道 | 引流范围 | 开口 |
|------|----------|------|
| 胰管（主） | 沿长轴收各部小叶间导管，主体 | 多数：肝胰壶腹 → **十二指肠大乳头**；少数单独开口 |
| 副胰管 | 胰头前上部 | **十二指肠小乳头**（在大乳头上方近侧约 1～2 cm，开口细节见第一节十二指肠） |
| 胆总管 | 胆汁 | 多数与胰管共用大乳头；少数单独开口 |

大乳头是胆汁和胰液的共同大门，小乳头是副胰管的侧门。不要把副胰管写成开口于大乳头。

:::pitfall{label="胰管开口按本版：多数汇合，少数单独，副胰管走小乳头"}
本版原句有三层：①多数胰管与胆总管汇合成肝胰壶腹，开口于十二指肠大乳头；②胰管偶尔单独开口；③副胰管开口于十二指肠小乳头。口诀若缩成「胰管一律进大乳头」，副胰管和少数单独开口两户都会丢。
:::

:::keypoint{label="胰：横、深、四部、两根管"}
- 第二大消化腺，腹上区 + 左季肋区，第 1～2 腰椎前方。
- 头颈在中线右，体尾在中线左；右抱十二指肠，左抵脾门。
- 钩突夹门静脉起始部；胆总管可埋进胰头。
- 胰管偏背侧走长轴，多与胆总管会于肝胰壶腹；副胰管开口于小乳头。
:::

:::memory{label="本节必背要点"}
- [ ] 大消化腺：大唾液腺、肝、胰。三大唾液腺回第一节；本节主写肝、肝外胆道、胰。
- [ ] 肝：最大腺体。男 1230～1450 g，女 1100～1300 g。外形两面四缘；膈面借镰状韧带分左、右叶。
- [ ] 脏面 H 沟：横沟 = 第一肝门（肝左、右管，肝固有动脉左、右支，肝门静脉左、右支，神经淋巴管）→ 肝蒂。左纵沟 = 肝圆韧带裂 + 静脉韧带裂；右纵沟 = 胆囊窝 + 腔静脉沟。
- [ ] 脏面四叶：左叶、右叶、方叶（肝门前）、尾状叶（肝门后）。不要用 Couinaud 段号替换这四个名字。
- [ ] 第二肝门：腔静脉沟上端，肝左、中、右静脉入下腔静脉。第三肝门：腔静脉沟下段，副肝右静脉和尾状叶小静脉。
- [ ] Glisson 系统（门静脉 + 固有动脉 + 肝管）在段内；肝静脉在段间、裂内。
- [ ] 正中裂（胆囊切迹中点 → 下腔静脉左缘，走肝中静脉）分左、右半肝，不是镰状韧带那一刀。Couinaud：5 叶 8 段（Ⅰ尾状，ⅡⅢ左外，Ⅳ左内，ⅤⅧ右前，ⅥⅦ右后）。
- [ ] 肝上界三点：右锁骨中线 × 第 5 肋，前正中线 × 剑胸结合，左锁骨中线 × 第 5 肋间隙。成人右肋弓下不能触及；7 岁后能触及考虑病理性肝大。
- [ ] 胆囊：底、体、颈、管。底的投影在右腹直肌外缘或右锁骨中线与右肋弓交点附近。颈有 Hartmann 囊；颈和管有螺旋襞。胆囊三角（Calot）= 胆囊管 + 肝总管 + 肝脏面，内常有胆囊动脉。
- [ ] 肝左、右管出肝门合成肝总管（约 3 cm）；肝总管与胆囊管锐角合成胆总管（4～8 cm，直径 0.6～0.8 cm，＞1 cm 病理）。
- [ ] 胆总管在肝十二指肠韧带内：固有动脉右侧、门静脉前方。四段：十二指肠上段、后段、胰腺段、壁段。多数与胰管汇成肝胰壶腹（Vater），开口十二指肠大乳头。
- [ ] Oddi 括约肌 = 壶腹括约肌 + 胆总管末段 + 胰管末段。空腹收缩，胆汁进胆囊；进食后胆囊收缩、Oddi 舒张，胆汁入肠。
- [ ] 胰：17～20 cm，第 1～2 腰椎前方。头（钩突、十二指肠环抱）、颈（2.0～2.5 cm）、体、尾（各面包腹膜，抵脾门）。胰管偏背侧，多开口大乳头；副胰管开口小乳头。
- [ ] 胰头肿大：压胆总管 → 阻塞性黄疸；压门静脉起始部 → 腹水、脾大。脾切除时勿伤胰尾。
