# 第一节　总论

神经系统（nervous system）是人体各系统中结构和功能最为复杂、并起主导作用的调节系统。本节把「总论」这一户写完：分部、神经元与胶质、常用术语、反射弧。脊髓外形、脑的分部是第二节的户头，不要提前写成节段、沟裂或脑干核团。

人体内各系统器官在神经系统的协调控制下完成统一的生理功能。例如运动时，除肌肉收缩外，同时出现呼吸加深加快、心跳加速、出汗等一系列变化。天气寒冷时，通过神经系统的调节，周围小血管收缩减少散热，同时肌肉收缩产热，使体温维持在正常水平。人类神经系统在漫长进化中既保留了与脊椎动物相似的感觉和运动中枢，又因生产劳动、语言交流和社会生活而出现语言分析中枢以及与思维、意识相关的中枢。人脑不仅能被动适应环境，还能主动认识并改造外界环境。

神经系统的复杂功能离不开特殊的形态：组成它的细胞以特殊方式连结，把全身器官组织联系在一起，并组合成具有高度整合功能的结构。在此基础上，通过各种反射，机体得以进行多种多样的复杂活动。

:::definition{label="神经系统"}
结构和功能最为复杂、起**主导作用**的调节系统。协调各系统器官，维持内环境稳定，适应外环境变化，并认识、改造外界环境。缺它，呼吸、循环、体温和运动无法被统一调度。
:::

:::concept{term="先问中枢还是周围，再问躯体还是内脏，再问传入还是传出"}
看见神经系统，先切成中枢部（颅内的脑 + 椎管内的脊髓）和周围部（脑神经 + 脊神经）。再按分布对象切躯体神经和内脏神经，按传导方向切传入和传出。把「神经系统」听成「就是大脑」，脊髓和周围神经会从开篇丢掉；把脊髓外形、脑分部写进本节，又是吞了第二节。
:::

## 一、神经系统的分部

神经系统分为中枢部和周围部，在结构和功能上二者是一个整体（图9-1）。中枢部包括位于颅腔内的脑和位于椎管内的脊髓，也称中枢神经系统（central nervous system）。周围部是遍布全身、与脑相连的脑神经和与脊髓相连的脊神经，又称周围神经系统（peripheral nervous system）。

又可根据周围神经在各器官、系统中所分布的对象不同，将其分为躯体神经（somatic nerve）和内脏神经（visceral nerve）。躯体神经分布于体表、骨、关节和骨骼肌；内脏神经分布于内脏、心血管、平滑肌和腺体。根据功能又分为感觉神经（sensory nerve）和运动神经（motor nerve）。感觉神经将神经冲动自感受器传向中枢，故又称传入神经（afferent nerve）；运动神经将神经冲动自中枢传向周围的效应器，故又称传出神经（efferent nerve）。内脏神经中的传出神经（即内脏运动神经 visceral motor nerve）支配心肌、平滑肌和腺体，其活动不受人的主观意志控制，故又称自主神经或植物神经，它们又可分为交感神经和副交感神经。

:::definition{label="中枢神经系统"}
颅腔内的**脑** + 椎管内的**脊髓**。户头落在位置：脑在颅，脊髓在椎管。不要把脊神经、脑神经算进中枢。
:::

:::definition{label="周围神经系统"}
与脑相连的**脑神经** + 与脊髓相连的**脊神经**。遍布全身。中枢和周围在结构和功能上是一个整体，不是两套互不相干的系统。
:::

::figure{src="/images/anatomy/textbook/p0283_03.png" caption="图9-1　神经系统的区分" alt="背面观和侧面观：颅内大脑、小脑，椎管内脊髓；周围部可见脑神经、臂丛、胸神经和腰骶丛"}

:::definition{label="躯体神经"}
分布于**体表、骨、关节和骨骼肌**。感觉可被清楚定位，运动多可随意志支配。不要听成「只有运动、没有感觉」。
:::

:::definition{label="内脏神经"}
分布于**内脏、心血管、平滑肌和腺体**。内脏神经本身既有传入也有传出；不要一上来就把它和自主神经画等号。
:::

:::definition{label="感觉神经与运动神经"}
感觉神经 = 传入神经：冲动自感受器走向中枢。运动神经 = 传出神经：冲动自中枢走向效应器。方向以中枢为参照，不是以「左、右」或「上、下」为参照。
:::

:::definition{label="自主神经"}
即内脏**运动**神经，又称植物神经。支配心肌、平滑肌和腺体，不受主观意志控制。本版再分为**交感神经和副交感神经**。名单里没有躯体运动。
:::

:::compare{title="分部的三把刀（先切开再往下记）"}
| 切法 | 本版户头 | 要点 |
|------|----------|------|
| 部位 | 中枢部 vs 周围部 | 中枢 = 脑 + 脊髓；周围 = 脑神经 + 脊神经 |
| 分布对象 | 躯体神经 vs 内脏神经 | 躯体走体表、骨、关节、骨骼肌；内脏走内脏、心血管、平滑肌、腺体 |
| 传导方向 | 传入（感觉）vs 传出（运动） | 传入朝中枢，传出离中枢 |

三把刀是交叉的：躯体和内脏都可以再分传入、传出。内脏传出才叫自主神经。
:::

:::compare{title="内脏运动神经的几个别名"}

内脏神经有传入也有传出。自主神经、植物神经这两个别名落在传出一侧，支配心肌、平滑肌和腺体。写成「内脏神经 = 自主神经」，内脏感觉（牵涉痛、内脏牵张）会从户头里丢掉。
:::

## 二、神经系统的组成

神经系统主要由神经组织构成。神经组织有两种主要的细胞成分：神经细胞（nerve cell，或称神经元 neuron）和神经胶质细胞（neuroglial cell，或称神经胶质 neuroglia）。

:::definition{label="神经组织的两种细胞"}
**神经元**负责感受刺激、传导冲动；**神经胶质**数量是神经细胞的数十倍，支持和调控微环境。两种一起才构成神经组织，不是「只有神经元算数」。
:::

### （一）神经元

神经元是神经系统结构和功能的基本单位，具有感受刺激和传导神经冲动的功能。

:::definition{label="神经元"}
神经系统结构和功能的基本单位。胞体是代谢中心，树突接收信息，轴突把冲动传给其他神经元或效应细胞（肌细胞、腺细胞等）。
:::

**1. 神经元的构造**　神经元的大小和形态差异较大，胞体有圆形、梭形和锥体形等，直径从 4～150 μm 不等。尽管形态各异（图9-2、图9-3），每个神经元都可以分为胞体和突起两部分。

（1）胞体：为神经元的代谢中心。细胞核大而圆，核仁明显。胞质内含有神经细胞所特有的尼氏体（Nissl body）、神经原纤维（neurofibril）（图9-4），以及发达的高尔基复合体和丰富的线粒体。典型的神经元胞体富含粗面内质网、滑面内质网和游离多聚核糖体，后者聚集于粗面内质网；这种富含核糖核酸（RNA）的聚集物，即光镜下所见的嗜碱性尼氏体。胞体内有丰富的神经丝（neurofilament）和微管（microtubule），神经丝聚集成束即光镜下所见的神经原纤维。

:::definition{label="胞体"}
神经元的代谢中心。核大而圆、核仁明显。本版特有结构是**尼氏体**和**神经原纤维**；另有发达的高尔基复合体和丰富的线粒体。直径 4～150 μm。
:::

:::definition{label="尼氏体"}
光镜下胞质中嗜碱性的 RNA 聚集物，电镜下对应粗面内质网加游离多聚核糖体。蛋白质合成的形态底板。**轴突和轴丘处没有尼氏体**。
:::

:::definition{label="神经原纤维"}
光镜下胞体内的纤维网。电镜下主要是聚集成束的神经丝，并与微管共存。不要和「神经纤维」（被髓鞘/神经膜包裹的长突起）混名。
:::

::figure{src="/images/anatomy/textbook/p0285_01.png" caption="图9-3　各种类型的神经元" alt="脊神经节细胞为假单极神经元；嗅细胞为双极神经元；小脑梨状细胞、脑干神经细胞、脊髓前角细胞和大脑皮质锥体细胞均为多极神经元"}

::figure{src="/images/anatomy/textbook/p0285_02.png" caption="图9-4　尼氏体和神经原纤维" alt="同一类多极神经元胞体对照：左侧胞质斑块为尼氏体，右侧网格为神经原纤维"}

（2）突起：是神经元胞体向外伸出的部分，按形态构造分为树突和轴突。

树突（dendrite）通常有多个，为胞体向外伸出的树枝状突起，一般较短，局限于胞体附近，结构大致与胞体相似。树突基部较宽，向外逐渐变细并反复分支，其小分支上有大量微小突起，称树突棘（dendrite spine），是接收信息的装置。

轴突（axon）是由胞体发出的一条细长突起，全长粗细均匀一致，有的可呈直角发出侧支。轴突起始处有一特化区称轴丘（axon hillock）。轴突和轴丘处无尼氏体。小型细胞的轴突短而细，大细胞的轴突较长，有的可达 1 m 以上。轴突远端发出许多终末分支，其末端即轴突终末（axon terminal），可与其他细胞构成突触。轴突内的细胞质称为轴浆（axoplasm），与胞体的胞质连通，具有不断的流动性，称为轴浆流（axoplasmic flow），轴浆流是双向的。轴突因缺乏核糖体而不能合成蛋白质，大分子的合成、组装成细胞器的过程都在胞体内完成。轴浆流将这些物质运送到轴突末梢，或将末梢的物质输送至胞体，这种现象称为轴突运输（axonal transport）。轴突的功能主要是传导由胞体发出的冲动，将其传递给其他的神经元或细胞。

:::definition{label="树突与树突棘"}
树突通常**多条**、较短、局限在胞体附近，结构大致同胞体。小分支上的微小突起是树突棘，本版原句称之为**接收信息的装置**。
:::

:::definition{label="轴突"}
胞体发出的**一条**细长突起，全长粗细均匀，可呈直角发出侧支。功能是把胞体发出的冲动传给其他神经元或效应细胞。大细胞的轴突有的可达 1 m 以上。
:::

:::definition{label="轴丘"}
轴突起始处的特化区。轴突和轴丘都**没有尼氏体**——蛋白质合成不在这一段完成。
:::

:::definition{label="轴浆流与轴突运输"}
轴浆与胞体胞质连通，流动是**双向**的。轴突自身不能合成蛋白质，大分子在胞体内合成后再经轴突运输送达末梢，或从末梢运回胞体。
:::

:::compare{title="树突和轴突（不要记反）"}
| | 树突 | 轴突 |
|--|------|------|
| 数目 | 通常多个 | 一条 |
| 形态 | 基部宽，反复分支变细 | 全长粗细均匀，可直角侧支 |
| 特有结构 | 树突棘（接收信息） | 轴丘、轴突终末 |
| 尼氏体 | 结构大致与胞体相似，可有 | **轴突和轴丘处无** |
| 功能 | 接收信息 | 传导胞体发出的冲动 |

:::

:::pitfall{label="神经原纤维不是神经纤维"}
神经原纤维在胞体内，是神经丝聚集成束后的光镜所见。神经纤维是被髓鞘和/或神经膜包裹的长突起。一个在细胞内骨架，一个在细胞外走行，名字只差一字。
:::

**2. 神经元的分类**　可按突起数目、功能和传导方向、以及所分泌的化学递质来分。

根据突起数目：①假单极神经元（pseudounipolar neuron）：自胞体发出一个突起，但很快呈「T」形分叉为两支，一支至周围的感受器，称周围突；另一支入脑或脊髓，称中枢突。脑神经节、脊神经节中的感觉神经元属于此类。②双极神经元（bipolar neuron）：自胞体两端各发出一个突起，一个抵达感受器称周围突，另一个进入中枢部称中枢突。如视网膜内的双极细胞、内耳前庭神经节和蜗神经节内的感觉神经元。③多极神经元（multipolar neuron）：具有多个树突和一个轴突，中枢部内的神经元绝大部分属于此类。

依据功能和传导方向：①感觉神经元（sensory neuron，或称传入神经元）：将内、外环境的各种刺激传向中枢部，假单极和双极神经元属此类。②运动神经元（motor neuron，或称传出神经元）：将冲动自中枢部传向身体各部，支配骨骼肌或管理心肌、平滑肌和腺体的活动，多极神经元属于此类。③联络神经元（association neuron，或称中间神经元）：位于中枢部、介于感觉和运动神经元之间的多极神经元。数量很大，占神经元总数的 **99%**，在中枢内构成复杂网络，对传入信息贮存、整合和分析。按轴突长短，中间神经元再分两类：高尔基Ⅰ型细胞轴突较长，将冲动从中枢某一部位传向其他部位，也称接替性或投射性中间神经元；高尔基Ⅱ型细胞轴突较短，常在特定局限的小范围内传递信息，又称局部中间神经元。

根据合成、分泌化学递质的不同：①胆碱能神经元：位于中枢神经的躯体运动核团和部分内脏运动核团或神经节。②单胺能神经元：包括儿茶酚胺能（分泌去甲肾上腺素、多巴胺等）、5-羟色胺能和组胺能神经元，广泛分布于中枢和周围神经系统。③氨基酸能神经元：以 γ-氨基丁酸、谷氨酸等为神经递质，主要分布于中枢神经系统，谷氨酸也是初级传入的主要递质。④肽能神经元：以生长抑素、P 物质、脑啡肽等肽类为递质，广泛分布于中枢和周围神经系统。

:::definition{label="假单极神经元"}
胞体只发出**一个**突起，随即「T」形分成周围突（到感受器）和中枢突（入脑或脊髓）。本版落点：脑神经节、脊神经节中的感觉神经元。
:::

:::definition{label="双极神经元"}
胞体两端各发出一个突起，仍分周围突和中枢突。本版例子：**视网膜双极细胞**、内耳**前庭神经节和蜗神经节**内的感觉神经元。
:::

:::definition{label="多极神经元"}
多个树突 + 一条轴突。中枢部内的神经元绝大部分属于此类；运动神经元和中间神经元都落在这一形态。
:::

:::compare{title="按突起数目（图9-3 对号）"}
| 类型 | 突起 | 本版例子 |
|------|------|----------|
| 假单极 | 一个突起，「T」形分成周围突和中枢突 | 脊神经节细胞、脑神经节感觉神经元 |
| 双极 | 两端各一突 | 嗅细胞、视网膜双极细胞、前庭神经节、蜗神经节 |
| 多极 | 多树突 + 一轴突 | 小脑梨状细胞、脑干神经细胞、脊髓前角细胞、大脑皮质锥体细胞 |

形态分类先数突起，再问它是感觉还是运动。假单极、双极走感觉；多极走运动和联络。
:::

:::compare{title="按功能和传导方向"}
| 类型 | 传导方向 | 形态归属 | 本版要点 |
|------|----------|----------|----------|
| 感觉（传入）神经元 | 刺激 → 中枢 | 假单极、双极 | 把内、外环境刺激送进中枢 |
| 运动（传出）神经元 | 中枢 → 效应器 | 多极 | 骨骼肌，或心肌、平滑肌和腺体 |
| 联络（中间）神经元 | 中枢内部 | 多极 | 占总数 **99%** |

中间神经元再按轴突长短：高尔基Ⅰ型（长，投射/接替）vs 高尔基Ⅱ型（短，局部）。
:::

:::compare{title="按化学递质（本版四类，不另开定义）"}
| 类型 | 递质/成员 | 本版分布 |
|------|-----------|----------|
| 胆碱能 | 乙酰胆碱 | 躯体运动核团；部分内脏运动核团或神经节 |
| 单胺能 | 儿茶酚胺（去甲肾上腺素、多巴胺等）、5-羟色胺、组胺 | 中枢和周围 |
| 氨基酸能 | γ-氨基丁酸、谷氨酸 | 主要在中枢；**谷氨酸是初级传入的主要递质** |
| 肽能 | 生长抑素、P 物质、脑啡肽等 | 中枢和周围 |

四类可以共存在不同部位，不要把「一个神经元只能有一种分类法」写成互斥。
:::

:::pitfall{label="假单极看起来像一条突起，功能上仍是传入"}
「T」形分叉后，周围突到感受器、中枢突入中枢，走的是感觉通路。不要因为光镜下只见到一个起始突起，就把它写成运动神经元。
:::

:::pitfall{label="中间神经元占 99%，不要把神经系统听成「感觉加运动两群」"}
感觉和运动是方向上的两端。中枢里真正把信息贮存、整合、分析的是中间神经元。写成「神经元就分感觉和运动」，高尔基Ⅰ型和Ⅱ型这一户会空掉。
:::

**3. 神经纤维**　神经元较长的突起被髓鞘（myelin sheath）和神经膜包裹，称为神经纤维（nerve fiber）。若被髓鞘和神经膜共同包裹称有髓纤维（myelinated fiber）（图9-5），仅为神经膜所包裹则为无髓纤维（nonmyelinated fiber）（图9-6）。周围神经的髓鞘由施万细胞（Schwann cell）环绕轴突形成；中枢神经系统的髓鞘由少突胶质细胞形成（图9-7）。髓鞘呈节段状包绕在轴突外面，直至神经末梢之前，在相邻两髓鞘节段间的区域称郎飞结（Ranvier's node），该处轴突裸露。神经冲动在有髓纤维中以跳跃的方式传导。神经纤维的传导速度与髓鞘厚薄和神经纤维直径成正比：神经纤维越粗、髓鞘越厚，传导电信号的速度就越快。

:::definition{label="神经纤维"}
神经元较长的突起被**髓鞘和/或神经膜**包裹后的名称。有髓 = 髓鞘 + 神经膜；无髓 = 仅神经膜。不是「一条轴突的别名」这么简单——包不包鞘，决定传导方式。
:::

:::definition{label="郎飞结"}
相邻两段髓鞘之间、轴突裸露的区域。有髓纤维的冲动在郎飞结之间**跳跃传导**。图9-2、图9-7 都能看见这一圈缩窄。
:::

:::compare{title="有髓纤维与无髓纤维"}
| | 有髓纤维 | 无髓纤维 |
|--|----------|----------|
| 包裹 | 髓鞘 + 神经膜 | 仅神经膜 |
| 周围谁成鞘 | 施万细胞环绕**一条**轴突（图9-5） | 一个施万细胞可包多条轴突（图9-6） |
| 中枢谁成鞘 | 少突胶质细胞，一个细胞可形成**多条**轴突的髓鞘（图9-7） | — |
| 传导 | 跳跃传导，速度快 | 不跳跃，相对慢 |

传导速度还与纤维直径成正比。粗而髓鞘厚的最快。
:::

::figure{src="/images/anatomy/textbook/p0286_02.png" caption="图9-6　无髓纤维与施万细胞关系模式图" alt="一个施万细胞内陷包绕多条轴突，无多层髓鞘环"}

::figure{src="/images/anatomy/textbook/p0287_02.png" caption="图9-7　中枢神经有髓纤维构成模式图" alt="一个少突胶质细胞发出多条突起，分别包绕多条轴突形成髓鞘，节间可见郎飞结"}

:::cause-effect{title="有髓纤维为什么能跳着传"}
- **因** 髓鞘呈节段包绕，郎飞结处轴突裸露，兴奋只在结与结之间依次发生
- **果** 冲动以跳跃方式传导；纤维越粗、髓鞘越厚，跳跃间距和速度越大

无髓纤维没有这种节段绝缘，不能靠同一套「结间跳跃」。
:::

:::pitfall{label="周围一条轴突对一个施万，中枢一个少突对多条轴突"}
图9-5 是施万细胞膜一圈圈包**一条**轴突；图9-7 是一个少突胶质细胞同时给**多条**轴突做鞘。把两套成鞘细胞写反，周围神经损伤后的再生和中枢脱髓鞘会对错细胞。
:::

**4. 突触**　突触（synapse）是神经元与神经元之间，或神经元与效应细胞之间传递信息的特化接触区域，通过它实现细胞与细胞间的通信。根据连接方式可分为轴-树突触、轴-体突触、轴-轴突触、树-树突触和体-体突触等。根据传递方式可分为化学突触和电突触。一个神经元可以与一个或多个神经元形成突触，如人的大脑皮质每个神经元平均有 **30 000** 个突触。

化学突触（chemical synapse）（图9-8）是神经系统内信息传递的主要方式，以释放化学递质为中介。化学突触包括三个部分：突触前部（presynaptic element）、突触后部（postsynaptic element）和突触间隙（synaptic cleft）。突触前部有密集的突触小泡（synaptic vesicle），小泡内含高浓度神经递质。当神经冲动沿轴突传到突触前部时，小泡向突触前膜（presynaptic membrane）移动并与其融合，神经递质被释放到突触间隙（约为 30～50 nm）。神经递质作用于突触后膜（postsynaptic membrane）上的受体，使受体蛋白或离子通道构型发生改变，产生电位变化，从而影响突触后神经元或效应细胞的活性。化学突触的传递具有单向性，时间上有突触延迟。

电突触（electrical synapse）（图9-8）是以电位扩布的方式进行信息传递的突触。低等脊椎动物和某些无脊椎动物有丰富的电突触；哺乳动物的上橄榄核、前庭核、大脑和小脑皮质、中脑、嗅球和视网膜也存在电突触。电突触的结构基础是缝隙连接（gap junction）。在缝隙连接处，相邻细胞借膜上的跨膜结构连接子（connexon）对合，构成相邻细胞间的水相通道。每个连接子由 6 个蛋白亚单位连接子蛋白（connexin）呈环形排列而成，中间有一小孔，直径为 **2 nm**，因此通道允许分子量小于 **1.2 kD** 的物质自由通过。电突触的电阻低，传导速度快，传导具有双向性，可使相接触的神经元或细胞功能同步，形成功能合胞体。

:::definition{label="突触"}
神经元与神经元之间，或神经元与效应细胞之间传递信息的特化接触区。连接方式可轴-树、轴-体、轴-轴、树-树、体-体；传递方式分化学突触和电突触。
:::

:::definition{label="化学突触"}
以释放化学递质为中介，是神经系统内信息传递的**主要方式**。三部：**突触前部、突触后部、突触间隙**。间隙约 30～50 nm。传递**单向**，有突触延迟。
:::

:::definition{label="电突触"}
以电位扩布传递信息，结构基础是**缝隙连接**。连接子由 6 个连接子蛋白围成，孔径 2 nm，允许小于 1.2 kD 的物质通过。电阻低、传导快、**双向**，使接触的细胞功能同步。
:::

::figure{src="/images/anatomy/textbook/p0287_01.png" caption="图9-8　神经细胞突触" alt="左侧化学突触：突触前部含突触小泡和线粒体，经突触前膜、突触间隙到突触后膜；右侧电突触为缝隙连接，连接子对合，连接蛋白亚单位围成通道"}

:::compare{title="化学突触与电突触"}
| | 化学突触 | 电突触 |
|--|----------|--------|
| 中介 | 化学递质 | 电位扩布 |
| 结构 | 前部 + 间隙（30～50 nm）+ 后部 | 缝隙连接；连接子孔径 2 nm |
| 方向 | **单向** | **双向** |
| 时间 | 有突触延迟 | 电阻低，传导快 |
| 本版地位 | 神经系统内信息传递的主要方式 | 哺乳动物上橄榄核、前庭核、大脑和小脑皮质、中脑、嗅球、视网膜等处也有 |

人大脑皮质每个神经元平均约 30 000 个突触，不要把「主要是化学突触」听成「没有电突触」。
:::

:::pitfall{label="化学突触单向有延迟，电突触双向快"}
把两套突触都听成「都是递质从突触前到突触后」，缝隙连接、连接子、功能合胞体这一笔会没有着落。化学突触靠小泡释放，电突触靠 2 nm 的水相通道。
:::

:::insight{label="图9-8 左边数三层膜，右边数六个亚单位"}
化学突触先认突触前膜、间隙、突触后膜，小泡堆在前部。电突触先认对合的连接子，再认 6 个连接蛋白亚单位围成的孔。一张图把「递质」和「离子流」两套通信钉在一起。
:::

### （二）神经胶质细胞

神经胶质细胞（图9-9）是神经组织中的另一类主要细胞，数量是神经细胞的数十倍，可分为中枢神经系统和周围神经系统的胶质细胞。前者有星形胶质细胞、少突胶质细胞、小胶质细胞、室管膜细胞等；后者有施万细胞和卫星细胞等。

一般认为神经胶质细胞是神经系统的辅助细胞，主要对神经元起支持、营养、保护和修复作用。随着细胞内注射、钙成像、膜片钳和分子生物学等技术的应用，人们对胶质细胞的形态和功能有了进一步认识：胶质细胞在神经系统中所起的作用不亚于神经细胞，神经系统的复杂功能由神经细胞和神经胶质细胞共同完成。

:::definition{label="神经胶质细胞"}
数量约为神经细胞的**数十倍**。中枢：星形、少突、小胶质、室管膜；周围：施万、卫星。不只是填充物，和神经元一起完成神经系统的复杂功能。
:::

::figure{src="/images/anatomy/textbook/p0288_01.png" caption="图9-9　神经胶质细胞" alt="原浆性星形胶质细胞突起粗短贴血管；纤维性星形胶质细胞突起细长贴血管；少突胶质细胞胞体较小、突起少；小胶质细胞突起细而多棘"}

**1. 星形胶质细胞**　星形胶质细胞（astrocyte）是胶质细胞中体积最大、数量最多的细胞。银染色显示此类细胞呈星形，由胞体发出许多突起，伸展包绕在神经元的胞体、树突、突触等处，有的延伸至郎飞结。突起的末端常膨大形成脚板（foot plate）或称终足（end foot）。有些脚板贴附在邻近的毛细血管壁上，靠近脑脊髓表面的脚板则附着在软膜内表面，彼此连接构成胶质界膜（glia limitans）。星形胶质细胞的核比其他胶质细胞大，呈圆形或卵圆形，胞质中含有由胶质细胞原纤维酸性蛋白（glial fibrillary acidic protein，GFAP）组成的胶质丝。GFAP 仅存在于星形胶质细胞的胞体中，因此可利用 GFAP 的特异性抗体来检测星形胶质细胞。

根据胶质丝的含量以及突起的形状，可将星形胶质细胞分为纤维性星形胶质细胞（fibrous astrocyte）和原浆性星形胶质细胞（protoplasmic astrocyte）。前者多分布在白质，细胞突起细长，胞质中含大量胶质丝；后者多分布在灰质，细胞突起粗短，胞质内胶质丝较少。星形胶质细胞借缝隙连接在脑内形成一个功能网络。本版列举的功能包括：分泌神经递质和神经营养因子、参与神经发育及再生、调控神经元微环境、形成血-脑屏障及参与免疫功能调节、调控突触传递、与神经元有信息交流、在突触形成和突触可塑性中发挥作用等。星形胶质细胞也具有可兴奋性，即具有跨膜电位，也可去极化，但**不形成动作电位**。还有几种特殊类型：小脑中的 Bergmann 细胞、视网膜中的 Müller 细胞、神经垂体中的垂体细胞（pituicyte）以及正中隆起等处的伸长细胞（tanycyte）。

:::definition{label="星形胶质细胞"}
胶质中体积最大、数量最多。突起末端膨大成脚板（终足），可贴毛细血管或软膜内表面（构成胶质界膜）。标记物是胞体中的 **GFAP**。可去极化，但不形成动作电位。
:::

:::compare{title="两种星形胶质细胞（图9-9 左列）"}
| | 纤维性 | 原浆性 |
|--|--------|--------|
| 分布 | 多在**白质** | 多在**灰质** |
| 突起 | 细长 | 粗短 |
| 胶质丝 | 大量 | 较少 |

特殊类型（Bergmann、Müller、垂体细胞、伸长细胞）仍属星形胶质这一户，不为每一型单独立定义。
:::

**2. 少突胶质细胞**　少突胶质细胞（oligodendrocyte）胞体较小，呈梨形或椭圆形，有少量突起，核较小，呈圆形或卵圆形，着色较深。少突胶质细胞是中枢神经系统形成髓鞘的细胞，一个少突胶质细胞可形成多条轴突的髓鞘。

:::definition{label="少突胶质细胞"}
中枢的成髓鞘细胞。胞体小、突起少。一个少突胶质细胞可给**多条**轴突做鞘——和图9-7 是同一件事。
:::

**3. 小胶质细胞**　小胶质细胞（microglia）来源于中胚层的单核巨噬细胞，胞体很小，呈短棒状，一般由胞体两端伸出数条枯树枝样突起，突起表面粗糙有棘刺。小胶质细胞参与中枢神经系统的免疫、炎性反应及损伤修复。当脑组织有炎症或损伤时，小胶质细胞被激活，变为大而圆的阿米巴样细胞，游走至损伤处，吞噬和清除坏死组织。

:::definition{label="小胶质细胞"}
来源于中胚层单核巨噬细胞。静息时短棒状、枯树枝样突起有棘；激活后变成大而圆的阿米巴样细胞，吞噬坏死组织。中枢的免疫和损伤修复细胞。
:::

**4. 室管膜细胞**　室管膜细胞（ependymocyte）是衬附于脑室面和脊髓中央管内面的一层立方或柱状上皮细胞，游离面可有微绒毛和纤毛。室管膜细胞参与组成脑脊液-脑屏障和血-脑屏障。脉络丛处的室管膜细胞还有分泌脑脊液的功能。

:::definition{label="室管膜细胞"}
衬在**脑室面和脊髓中央管内面**的立方或柱状上皮，游离面可有微绒毛和纤毛。参与脑脊液-脑屏障和血-脑屏障；脉络丛处还分泌脑脊液。
:::

**5. 周围胶质**　施万细胞（Schwann cell）又称神经膜细胞（neurilemmal cell），是周围神经系统的成髓鞘细胞；与少突胶质细胞不同的是，施万细胞只形成一条轴突的髓鞘。卫星细胞（satellite cell）又称被囊细胞（capsule cell），是神经节内包裹神经元胞体的一层扁平细胞。

:::definition{label="施万细胞"}
周围神经系统的成髓鞘细胞，又称神经膜细胞。**只形成一条轴突的髓鞘**。无髓纤维里，一个施万细胞可以包绕多条轴突，但并不做成节段性髓鞘。
:::

:::definition{label="卫星细胞"}
又称被囊细胞。神经节内包裹神经元胞体的一层扁平细胞。户头落在**节内胞体周围**，不是包轴突。
:::

:::compare{title="中枢胶质与周围胶质"}
| 部位 | 本版细胞 | 成鞘关系 |
|------|----------|----------|
| 中枢 | 星形、少突、小胶质、室管膜 | 少突：1 细胞 → 多条轴突的髓鞘 |
| 周围 | 施万、卫星 | 施万：1 细胞 → 1 条轴突的髓鞘；卫星包神经节胞体 |

星形最大最多，小胶质管免疫，室管膜衬管腔。不要把四类中枢胶质都听成「成髓鞘细胞」。
:::

:::pitfall{label="胶质不是可有可无的填充"}
支持、营养、保护、修复是老说法。本版明确：胶质数量数十倍于神经元，星形胶质参与血-脑屏障和突触可塑性，小胶质负责吞噬，室管膜参与屏障并分泌脑脊液。写成「神经组织 = 神经元」，图9-9 四类细胞会从开篇丢掉。
:::

:::insight{label="GFAP 只在星形胶质胞体里"}
要在切片上认星形胶质，用的是 GFAP 抗体，因为这种胶质丝蛋白只存在于星形胶质细胞的胞体。纤维性（白质、突细长）和原浆性（灰质、突粗短）是同一户的两种形态，不是另外两种胶质。
:::

## 三、神经系统的常用术语

在中枢和周围神经系统中，神经元胞体和突起在不同部位有不同的组合编排方式，故用不同的术语表示。术语是读后面各节的底板：同一群胞体，在中枢叫核，在周围叫节；同一束纤维，在中枢叫束，在周围叫神经。不要为每一个名词再单开一张过长定义，更不要在这里灌入脊髓内部的核团名单。

在中枢部，神经元胞体及其树突的聚集部位，在新鲜标本中色泽灰暗，称灰质（gray matter）。配布于大脑和小脑表面的灰质称皮质（cortex）。形态和功能相似的神经元胞体聚集成团或柱称神经核（nucleus）。神经纤维在中枢部聚集的部位称白质（white matter），因髓鞘含类脂质色泽明亮而得名。位于大脑和小脑皮质深部的白质称髓质（medulla）。白质中，凡起止、行程和功能基本相同的神经纤维集合在一起称为纤维束（fasciculus）。

在周围部，神经元胞体聚集处称神经节（ganglion）。神经纤维在周围部聚集为粗细不等的神经（nerve）（图9-10）。神经内的每条神经纤维由称为神经内膜（endoneurium）的结缔组织包绕；若干神经纤维聚集为一条神经束（nerve tract）；包被神经束的结缔组织称神经束膜（perineurium）；由若干神经束汇聚成一条神经，包裹在神经外面的结缔组织称神经外膜（epineurium）。一条神经内的若干神经束，在行程中常相互反复编排、重新组合。了解神经内神经束的编排组合，对外伤后的对位缝合很重要，对位准确有利于神经的再生和功能恢复。

:::compare{title="中枢部术语（灰暗的是胞体，明亮的是纤维）"}
| 术语 | 本版所指 | 不要写成 |
|------|----------|----------|
| 灰质 | 中枢内神经元胞体及其树突的聚集，新鲜标本色泽灰暗 | 「所有灰质都叫皮质」 |
| 皮质 | 配布于**大脑和小脑表面**的灰质 | 把脑干内部的核团也叫皮质 |
| 神经核 | 形态和功能相似的胞体聚集成团或柱 | 和周围的神经节混名 |
| 白质 | 中枢内神经纤维聚集处，因髓鞘类脂质而明亮 | 「白质里没有纤维束」 |
| 髓质 | 大脑和小脑**皮质深部**的白质 | 和延髓（脑干一部）混名 |
| 纤维束 | 白质中起止、行程、功能基本相同的纤维集合 | 和周围的「神经」混名 |

皮质是表面的灰质，髓质是深部的白质。脑干、脊髓里的灰质多排成核或柱，不叫皮质。
:::

:::compare{title="周围部术语（节是胞体，神经是纤维）"}
| 术语 | 本版所指 | 中枢对应 |
|------|----------|----------|
| 神经节 | 周围部神经元胞体聚集处 | 神经核 |
| 神经 | 周围部神经纤维聚集成的粗细不等的条索 | 纤维束 / 白质 |
| 神经内膜 | 包绕**每条**神经纤维的结缔组织 | — |
| 神经束 | 若干神经纤维聚成的一束 | — |
| 神经束膜 | 包被神经束的结缔组织 | — |
| 神经外膜 | 包裹整条神经外面的结缔组织 | — |

内膜 → 束膜 → 外膜，由内向外三层。图9-10 把这一套横切钉死。
:::

::figure{src="/images/anatomy/textbook/p0289_01.png" caption="图9-10　神经（横切，示内膜、束膜、外膜）" alt="周围神经横切：轴突外包髓鞘，神经内膜包每条纤维，若干纤维成神经束并由神经束膜包裹，表面为神经外膜，束间可见血管"}

:::definition{label="灰质与白质"}
灰质：中枢内胞体及其树突聚集，色泽灰暗。白质：中枢内神经纤维聚集，因髓鞘类脂质明亮。这一对只用于**中枢部**。
:::

:::definition{label="皮质与髓质"}
皮质 = 大脑和小脑**表面**的灰质。髓质 = 大脑和小脑皮质**深部**的白质。不是「皮质等于全部灰质」，也不是把延髓听成髓质。
:::

:::definition{label="神经核与神经节"}
形态功能相似的胞体：在中枢聚成团或柱叫**神经核**，在周围聚集叫**神经节**。同一类胞体，换地方换名字。
:::

:::definition{label="纤维束与神经"}
起止、行程、功能基本相同的纤维：在中枢白质里叫**纤维束**，在周围聚成条索叫**神经**。
:::

:::keypoint{label="神经的三层膜（图9-10）"}
- 神经内膜包每条纤维。
- 神经束膜包每一神经束。
- 神经外膜包整条神经。
- 束在行程中会反复编排、重新组合；外伤缝合要对准束，才利于再生。
:::

:::pitfall{label="图9-10 是神经横切，不是反射弧"}
内膜、束膜、外膜和束间血管是周围神经的结缔组织鞘。反射弧是下一户的五环节模式，教材图号是图9-11。把这张横切听成反射弧，会把感受器、中枢、效应器全读成结缔组织膜。
:::

:::pitfall{label="皮质不是灰质的别名，髓质不要和延髓混"}
只有铺在大脑、小脑表面的灰质才叫皮质；深部白质才叫髓质。延髓是脑干的一部，名字里也有「髓」，户头完全不同。
:::

:::insight{label="中枢用核和束，周围用节和神经"}
读后文时先问：这团胞体在颅椎管内还是在管外？在管内叫核，在管外叫节。这束纤维在白质里走叫束，出了中枢叫神经。术语表就是这把刀，不需要在这里展开薄束、楔束或脑神经核名单。
:::

## 四、神经系统的活动方式

神经系统在调节机体的活动中，对内、外环境的各种刺激作出适宜的反应，称为反射（reflex）。反射的结构基础是反射弧（reflex arc）。反射弧由感受器、传入神经、中枢、传出神经和效应器构成。反射是神经系统的基本活动方式。整个神经系统是由亿万个细胞组成的庞大而复杂的信息网络，它通过各种反射来维持机体内环境的稳定以及内环境与外环境的统一。

:::definition{label="反射"}
神经系统对内、外环境各种刺激作出的适宜反应。是神经系统的**基本活动方式**。冷了收缩周围小血管、运动时心跳加速，开篇那些例子都是反射在调。
:::

:::definition{label="反射弧"}
反射的结构基础。本版五环节：**感受器 → 传入神经 → 中枢 → 传出神经 → 效应器**。五件缺一，反射中断。
:::

:::compare{title="反射弧五环节（按传导方向）"}
| 环节 | 本版角色 | 和前面户头的对应 |
|------|----------|------------------|
| 感受器 | 接受刺激，转变为神经冲动 | 树突棘、周围突末端；特殊感觉器见第八章 |
| 传入神经 | 把冲动送进中枢 | 感觉（传入）神经；假单极、双极 |
| 中枢 | 在脑或脊髓内整合 | 中间神经元所在的灰质、神经核 |
| 传出神经 | 把冲动送出中枢 | 运动（传出）神经；可走躯体或内脏 |
| 效应器 | 作出反应 | 骨骼肌，或心肌、平滑肌和腺体 |

五环节是总论的收口：分部里的传入/传出、组成里的神经元和突触，都在这一条链上碰头。
:::

:::note{label="图9-11 电子版未在总论页单列"}
教材「图9-11　反射弧」的图注落在下一页脊髓段起始处，扫描图与脊髓外形在同一页。本节用文字把五环节写全，不把脊髓外形图塞进来冒充反射弧，也不把图9-10 神经横切改挂成图9-11。
:::

:::cause-effect{title="反射弧缺一环为什么反射消失"}
- **因** 反射必须沿感受器 → 传入 → 中枢 → 传出 → 效应器这一条完整通路进行
- **果** 任一环节损伤（如传入纤维断、中枢被毁、效应器瘫痪），该反射不能完成

临床查反射，查的就是这条链还通不通，而不是「大脑是否还在想」。
:::

:::pitfall{label="反射弧不要写成只有传入和传出两根线"}
中间必须有中枢。只有传入、传出而没有中枢，冲动无处整合；只有中枢没有效应器，反应落不了地。五环节是本版原句，不要缩成「刺激进、反应出」两个词。
:::

:::insight{label="总论到反射弧为止，脊髓外形归第二节"}
开篇说神经系统靠反射把全身联系在一起；收口把反射弧五环节钉死。下一节才写脊髓的位置、膨大和节段。把马尾、终丝、31 个节段写进总论，是把第二节的户头提前拆开。
:::

:::memory{label="本节必背要点"}
- [ ] 神经系统 = 主导调节系统。中枢 = 脑（颅内）+ 脊髓（椎管内）；周围 = 脑神经 + 脊神经。
- [ ] 躯体神经 → 体表、骨、关节、骨骼肌；内脏神经 → 内脏、心血管、平滑肌、腺体。传入 = 感觉，传出 = 运动。
- [ ] 自主神经 = 植物神经 = 内脏**运动**神经 = 交感 + 副交感。不等于全部内脏神经（内脏还有传入）。
- [ ] 神经元是结构和功能的基本单位。胞体是代谢中心；尼氏体 = 粗面内质网 + 多聚核糖体（轴突和轴丘处无）；神经原纤维 = 神经丝束。
- [ ] 树突通常多条，树突棘接收信息；轴突一条、粗细均匀，可直角侧支。轴浆流双向；轴突不能自身合成蛋白质。
- [ ] 假单极（脑、脊神经节感觉）「T」形分周围突和中枢突；双极（视网膜、前庭和蜗神经节）；多极（中枢绝大部分）。中间神经元占 99%，分高尔基Ⅰ型（长、投射）和Ⅱ型（短、局部）。
- [ ] 递质四类：胆碱能、单胺能、氨基酸能（谷氨酸是初级传入主要递质）、肽能。
- [ ] 有髓 = 髓鞘 + 神经膜，跳跃传导；无髓 = 仅神经膜。周围施万 1 对 1 条轴突成鞘；中枢少突 1 对多条。郎飞结处轴突裸露。传导速度 ∝ 髓鞘厚度和纤维直径。
- [ ] 化学突触：前部 + 间隙 30～50 nm + 后部，单向、有延迟。电突触：缝隙连接，连接子孔径 2 nm，< 1.2 kD 可通过，双向、快。大脑皮质每个神经元平均约 30 000 个突触。
- [ ] 中枢胶质：星形（最大最多，GFAP，脚板，纤维性在白质 / 原浆性在灰质）、少突、小胶质（中胚层，可成阿米巴样吞噬）、室管膜（衬脑室和中央管，脉络丛分泌脑脊液）。周围胶质：施万、卫星（被囊细胞）。
- [ ] 中枢：灰质 / 白质；表面灰质 = 皮质，深部白质 = 髓质；核、纤维束。周围：神经节、神经。内膜包纤维，束膜包束，外膜包神经。图9-10 是神经横切，不是反射弧。
- [ ] 反射是基本活动方式。反射弧五环节：感受器、传入神经、中枢、传出神经、效应器。缺一则反射中断。脊髓外形、脑分部不在本节。
:::
