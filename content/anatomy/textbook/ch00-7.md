# 七、 学习人体解剖学的方法

前六节把这门课的对象、分科、年表、组成、方位语法和「正常 / 变异 / 畸形」立住。本节回答：用什么观点、什么方法去学，才不至于在「形态结构描述多、专业名词多」里死记硬背。总原则是辩证唯物主义指导、理论联系实际。落到操作上，是四个观点加三个结合。不要把本节写成考研经验帖或软件清单；条目以本版教材为准。

要全面正确地认识人体形态结构，必须以辩证唯物主义的观点为指导，运用理论联系实际的方法去探讨、研究人体。学习人体解剖学时，要坚持进化发展的观点、形态与功能相互影响的观点、局部与整体统一的观点和理论与实际相结合的观点。同时，解剖学是一门形态学科，形态结构描述多、专业名词多，如果死记硬背则效果不佳，且容易遗忘。因此，学好解剖学除了要坚持上述四个观点，特别要做到三个结合：① 文字与图画相结合；② 理论与实物相结合；③ 解剖与临床相结合。

:::note{label="本节无教学插图"}
学习方法在本版绪论中无教学插图。文字与图画相结合，用的是各章自己的图（本节可回扣绪图-1、绪图-2），不要把编委肖像嵌进正文。
:::

:::concept{term="先立四个观点，再做三个结合，不要一上来就背名词表"}
看见「怎么学」，先不要默写记忆术。教材的顺序是：指导——辩证唯物主义；方法——理论联系实际；观点——进化发展、形态与功能、局部与整体、理论与实际；结合——文字与图画、理论与实物、解剖与临床。四个观点管「怎么看人体」，三个结合管「怎么读这门形态课」。把本节听成「多做题、多背英文」，观点和结合两本账都会丢掉。
:::

## 一、总原则：辩证唯物主义，理论联系实际

要全面正确地认识人体形态结构，必须以辩证唯物主义的观点为指导，运用理论联系实际的方法去探讨、研究人体。这一句是本节的总纲，四个观点和三个结合都从这里长出来。

:::definition{label="全面正确地认识人体形态结构"}
学习目的不是记下部分名词，而是对形态结构有全面、正确的认识。全面：不能只盯一个局部、一个系统；正确：不能离开正常模板，也不能把变异、畸形和体型并户。
:::

:::definition{label="辩证唯物主义的观点为指导"}
本版把辩证唯物主义写成本课程的指导。落到解剖学里，就是后面四句话：人体是进化来的，形态和功能互相作用，局部和整体互相约束，认识必须连着实际。不要把这一句扩写成哲学讲义，也不要删掉当空话。
:::

:::definition{label="理论联系实际的方法"}
探讨、研究人体时，理论要连着实际。实际包括标本与模型上的形态、活体上的体表和功能、临床上的案例。三个结合是这一方法的具体化；第四个观点「理论与实际相结合」与这里是同一本账，不是另一套口号。
:::

:::pitfall{label="不要把指导写成可以跳过的前言"}
删掉「辩证唯物主义」和「理论联系实际」，四个观点会变成互不相关的四条忠告，三个结合会变成「多看看图」的技巧。教材把指导写在最前，是为了给后面的名单一个总开关。
:::

:::compare{title="总纲的两层"}
| 层 | 本版原句 | 后面落到 |
|----|----------|----------|
| 指导 | 以辩证唯物主义的观点为指导 | 四个观点 |
| 方法 | 运用理论联系实际的方法去探讨、研究人体 | 三个结合；第四个观点 |

指导和方法不是两门课，是同一句话的两截。
:::

:::cause-effect{title="为什么形态课特别需要「联系实际」"}
- **因** 解剖学是形态学科，描述多、名词多，对象却是可以看见、摸到的人体
- **果** 离开标本、模型和活体、临床，名词只在纸上；联系实际，形象思维才能被触发，系统思维和初步临床思维才接得上
:::

## 二、四个观点

学习人体解剖学时，要坚持进化发展的观点、形态与功能相互影响的观点、局部与整体统一的观点和理论与实际相结合的观点。四条是并列的「坚持」，不是选一条即可。

:::definition{label="四个观点"}
进化发展；形态与功能相互影响；局部与整体统一；理论与实际相结合。学人体解剖学时都要坚持。
:::

:::keypoint{label="四个观点的名单（本版顺序）"}
- 进化发展的观点。
- 形态与功能相互影响的观点。
- 局部与整体统一的观点。
- 理论与实际相结合的观点。
:::

### （一）进化发展的观点

:::definition{label="进化发展的观点"}
把人体形态结构放在种系发生和个体发生的时间轴上看：它是进化来的，也是生长发育来的。不是把成人标本当成从来如此的成品。
:::

:::note{label="回扣第三节与第一节"}
第三节写：达尔文《物种起源》《人类起源与性的选择》建立人类起源和进化的理论，使探索人体形态结构的工作有了正确的遵循。第一节定义里的「及其发生发展」，是个体发生这一侧。进化发展的观点把两条轴都要。
:::

:::insight{label="成人标本是时间轴上的一个切面"}
台上一具成人尸体，是种系发生走到人、个体发生走到成年的结果。骨的骺软骨、牙的萌出、生殖器的青春期变化，以及第六节体型里的「发育状况」，都是这条轴上的点。把解剖学听成只描述完成态，儿童、老年和比较解剖都会变成「例外」。
:::

:::pitfall{label="不要把进化发展听成另上一门进化论"}
本版要求的是观点：解释形态时要问它从哪来、怎么长成这样。不是让系统解剖学改成物种史教材，也不要用课外进化故事替换各论里已经写明的发生要点。
:::

:::compare{title="进化发展要问的两段时间"}
| 轴 | 问什么 | 绪论里已经出现的钉子 |
|----|--------|------------------------|
| 种系发生 | 人体这种形态如何在进化中形成 | 达尔文两部著作；比较解剖的颅侧 / 尾侧 |
| 个体发生 | 这个人如何从胚胎长到成年、再到改建 | 定义中的「发生发展」；生长发育规律 |

两段都缺，发展的观点就只剩口号。
:::

### （二）形态与功能相互影响的观点

:::definition{label="形态与功能相互影响的观点"}
形态不是为形态而存在，功能也不是悬空发生。形态使某种功能成为可能；功能的长期需求也可以反过来塑造形态。是「相互影响」，不是单向的「形态决定功能」或「功能决定形态」。
:::

:::note{label="回扣第一节与第六节"}
第一节学习目的里有「及其功能意义」：管状器官为什么中空、关节面为什么光滑、肌为什么跨过关节，都是形态对功能的交代。第六节体型的影响因素包括职业和锻炼：长期做什么，高矮胖瘦和器官形态会留下痕迹。两节已经在用这个观点，本节把它立成必须坚持的一条。
:::

:::insight{label="相互影响有两个方向"}
正向：这种结构使它能够完成相应功能——这是「功能意义」。反向：锻炼、职业、发育和营养改写形态——这是体型段已经承认的事实。只记正向，会把活体看成不会变的标本；只记反向，又会把解剖课改写成训练学。
:::

:::pitfall{label="不要把「形态与功能」听成可以把解剖课改写成生理课"}
属形态学这一户在第一节已经钉死。观点要求指出形态对功能意味着什么，并承认功能会反过来影响形态；不要求在绪论里讲心率、酶动力学。功能的机制是生理学的正业。
:::

:::compare{title="形态与功能：两种说反了的听法"}
| 听法 | 错在哪 | 本版要求 |
|------|--------|----------|
| 只背名字，功能以后再说 | 丢掉「功能意义」和相互影响 | 形态课也要问这种结构能做什么 |
| 把解剖写成生理教程 | 丢掉形态学范畴 | 先结构、位置、发生，再指出功能意义 |
| 承认职业、锻炼改形态 | 与第六节体型一致 | 相互影响的反向 |
:::

### （三）局部与整体统一的观点

:::definition{label="局部与整体统一的观点"}
任何一个局部都在整体里工作；整体的功能又通过各局部实现。不能把器官从系统里摘走单独理解，也不能把系统解剖学的「按户叙述」听成九个互不往来的科室。
:::

:::note{label="回扣第二节与第四节"}
第二节：系统解剖学按功能系统写，局部解剖学按头部、颈部、胸部等写层次与毗邻——两门课是同一人体的两把刀。第四节：内分泌协调、神经调控统一、脉管输送，九大系统在活体上同时工作。「统一」不是修辞，是组成总表已经写过的事。
:::

:::insight{label="系统解剖按户写，是为了讲得清，不是因为人体按户生活"}
教材一章一个系统，是叙述顺序。活体上，肝既在消化系统里，又要血供、神经、腹膜和毗邻。局部解剖学把这些层次重新按区收编。坚持局部与整体统一，就是读系统时想到毗邻，读局部时想到它属于哪个系统。
:::

:::pitfall{label="不要把「局部」听成可以不学系统，或把「整体」听成可以不记层次"}
只学系统、不问层次，手术和穿刺没有入路；只记局部、不问系统，管道和神经没有功能归属。两门课、两种叙述，对象仍是一个人体。
:::

:::compare{title="局部与整体在课程里的两张地图"}
| | 系统解剖学 | 局部解剖学 |
|--|------------|------------|
| 叙述单位 | 功能系统（九户） | 头、颈、胸、腹、盆、背、四肢等 |
| 看见的 | 器官在系统中的形态与发生 | 层次、配布、毗邻 |
| 若缺统一的观点 | 器官名录，不知挨着谁 | 层次清单，不知属于哪一系统 |

本课是系统解剖学，但观点要求从现在起就问「它在整体里的位置」。
:::

### （四）理论与实际相结合的观点

:::definition{label="理论与实际相结合的观点"}
书上的形态描述必须连到可以观察、触摸、辨识的人体实际，并连到临床实际。它与总纲里「理论联系实际的方法」是同一条要求，又在三个结合里被拆成图画、实物、临床三步。
:::

:::insight{label="实际有三层，不要只认纸面"}
实物（标本、模型）、活体（体表标志、自身或同学身上能摸到的结构）、临床（案例、功能变化）。后文各章的「体表的骨性标志」就是把理论落到活体上。医学研究的对象是人（第一节），活体观察不是额外的技巧，而是理论联系实际的应有之义。本版在三个结合里明文写的是标本、模型；活体和临床分别落在体表标志与第三个结合上。
:::

:::pitfall{label="不要把理论与实际相结合听成「先应付考试，以后临床再补」"}
观点要求现在就结合。第三节已经用亚里士多德、盖伦的教训说明：资料不来自人体实际，结论会错。把结合推迟到实习，等于取消这条观点。
:::

:::compare{title="四个观点各管一问"}
| 观点 | 主要问 | 丢掉会怎样 |
|------|--------|------------|
| 进化发展 | 这种形态从哪来、怎么长成 | 只剩成人完成态 |
| 形态与功能相互影响 | 这种形态能做什么、功能是否改写形态 | 名词与生理两张皮 |
| 局部与整体统一 | 这个局部在哪个整体里、整体靠哪些局部 | 系统与局部互相取消 |
| 理论与实际相结合 | 这句话在标本、活体、临床上落在哪 | 死记硬背，易遗忘 |
:::

## 三、三个结合

解剖学是一门形态学科，形态结构描述多、专业名词多，如果死记硬背则效果不佳，且容易遗忘。因此，学好解剖学除了要坚持上述四个观点，特别要做到三个结合。四个观点是「看人体的方式」，三个结合是「读这门形态课的做法」；后者是前者在学习过程中的落地，不是另一套可以替换观点的口号。

:::definition{label="三个结合"}
① 文字与图画相结合；② 理论与实物相结合；③ 解剖与临床相结合。本版用「特别要做到」强调：观点之外，这三步不可省。
:::

:::pitfall{label="死记硬背：效果不佳，且容易遗忘"}
原因写在形态学科的性质上：描述多、名词多。对策不是更拼命地背单词表，而是三个结合。把本节听成「多背几遍」，正好是教材反对的那条路。
:::

### ① 文字与图画相结合

看书学习时，对应着书中的插图或者借助有关的图谱、视频、动画等看文字描述更容易理解。

:::definition{label="文字与图画相结合"}
读文字时对着插图（或图谱、视频、动画）看，形态描述才容易理解。文字给名称和关系，图画给空间。
:::

:::note{label="绪论自己的第一对图"}
绪图-1 常用方位术语、绪图-2 人体的轴和面，就是用图画把第五节的词钉到人体上。内/外画在肠管断面，浅/深画在大腿断面，掌心向前画在正面人体上——这些关系只靠文字很容易并户，一对图就拆开了。
:::

:::insight{label="图不是装饰，是形态课的另一半语言"}
方位、层次、毗邻、断面，本质上是空间关系。离开图，名词只是声音。教材把插图、图谱、视频、动画并提，是承认不同媒介都能承担「图画」这一半；本平台正文用各章插图，不另嵌视频。
:::

:::pitfall{label="不要只看图不读定义，或只背定义不看图"}
只看图，会指得出结构却说不清参照（上/下还是浅/深）。只背定义，会默写「掌心向前」却在旋前的标本上把桡侧指错。结合是双向的。
:::

### ② 理论与实物相结合

要充分利用标本、模型等，通过对标本和模型的观察、触摸、辨识，对人体形态和结构形成直观的认识，触发形象思维和记忆。

:::definition{label="理论与实物相结合"}
充分利用标本、模型等：观察、触摸、辨识，形成直观认识，触发形象思维和记忆。实物是理论的落点，不是参观。
:::

:::definition{label="观察、触摸、辨识"}
三步都要：看外形与层次，摸骨性标志和软组织的质地、边界，辨认「这是哪一块、它挨着谁」。只隔着玻璃看，触摸和辨识两步会缺。
:::

:::definition{label="形象思维和记忆"}
形态课的记忆从形象来：空间里的形状、走行、毗邻，比单词表更稳。标本和模型是触发这一记忆的实物条件。
:::

:::insight{label="活体是更近的一层实物"}
标本、模型是本版明文。后文「体表的骨性标志」要求在活体上扪及乳突、下颌角、髂嵴、第 7 颈椎棘突等——那是把实物从台面转移到仍在工作的人体。第一节已写医学研究的对象是人，活体观察因此不是考研经验，而是理论联系实际在体表上的落点。
:::

:::pitfall{label="不要把模型当成可以替代标本的「标准人体」"}
模型为了清楚，常常把变异抹平、把层次画成理想状态。第六节刚刚立过：正常是绝大多数，旁边还有变异。只认模型，会把真实标本上的差异一律判成做错了。模型辅助辨认，标本和活体校正模型。
:::

:::compare{title="文字 / 图画 / 实物 各给什么"}
| | 给什么 | 缺了会怎样 |
|--|--------|------------|
| 文字 | 名称、定义、参照、功能意义 | 指得出、说不出 |
| 图画 | 空间关系、断面层次 | 名词在脑子里没有位置 |
| 标本与模型 | 真实（或近似）的三维、可触摸 | 形象思维触发不了，易遗忘 |
| 活体体表 | 仍在工作的人体上的标志 | 理论停在尸体和塑料上 |
:::

### ③ 解剖与临床相结合

通过思考题提供的临床案例、查阅有关临床资料等把解剖学知识与临床实际案例结合起来，把书中对各器官系统形态结构知识的单独介绍串联起来，并结合其功能和变化形成系统思维和初步的临床思维。

:::definition{label="解剖与临床相结合"}
用临床案例和临床资料，把解剖学知识连到实际案例上。目的不是提前上临床课，而是让单独介绍的器官系统重新串成整体，并连上功能和变化。
:::

:::definition{label="系统思维"}
把书中按系统单独介绍的形态结构串联起来，并结合功能和变化来看。它是「局部与整体统一」在思维上的产物：肝不只是消化章里的一个器官，还要问血供、神经、腹膜和它变化时会牵动谁。
:::

:::definition{label="初步的临床思维"}
在解剖学阶段开始用形态去理解案例：这个症状可能对应哪一结构、哪一毗邻、哪一种变异或畸形。是「初步」，不是完整的诊断学。
:::

:::note{label="回扣第一节的因果链"}
只有掌握正常形态结构，才能判断正常与异常，理解生理现象和病理变化，从而预防、诊断和治疗。第三个结合就是把这条因果链从绪论落到日常阅读：每读一个器官，问它在临床上被怎样用到。
:::

:::pitfall{label="不要把「结合临床」听成只记刀口、不记系统全貌"}
案例是为了串联和形成思维，不是把系统解剖学改成手术步骤手册。缺了九大系统的底板，案例里的结构没有位置。
:::

:::pitfall{label="不要把本节写成考研经验或软件推荐"}
本版条目是四个观点、三个结合，外加「不要死记硬背」。不要改写成背多少单词、用哪款 APP、如何押题。那些不是教材正文。
:::

:::compare{title="三个结合各自对治什么"}
| 结合 | 主要手段（本版） | 对治 | 形成什么 |
|------|------------------|------|----------|
| 文字与图画 | 插图、图谱、视频、动画 | 名词在纸上没有空间 | 理解形态描述 |
| 理论与实物 | 标本、模型的观察、触摸、辨识 | 没有直观，易遗忘 | 形象思维和记忆 |
| 解剖与临床 | 思考题案例、临床资料 | 各系统单独介绍、与功能脱节 | 系统思维和初步临床思维 |
:::

:::cause-effect{title="为什么三个结合要并提"}
- **因** 形态课既有空间对象，又有名词系统，还要为临床底板服务
- **果** 图画解决空间，实物触发形象记忆，临床把分系统的叙述重新串成整体；省掉任何一步，死记硬背都会回来
:::

## 四、把观点和结合叠回前六节

四个观点、三个结合不是另起的学习章，而是读前六节和后面各论时的同一套用法。

:::compare{title="前六节各自在用哪一条"}
| 节 | 观点上 | 结合上 |
|----|--------|--------|
| 一 定义和地位 | 形态与功能（功能意义）；理论与实际（对象是人） | 为临床奠定基础，已经在说第三个结合 |
| 二 分科 | 局部与整体（系统 vs 局部）；进化发展（三阶段） | 标本仍是巨视手段；影像、数字是新的「图画 / 实物」 |
| 三 简史 | 进化发展（达尔文）；理论与实际（必须解剖人体） | 达·芬奇的素描是文字与图画；维萨里是理论与实物 |
| 四 组成与系统 | 局部与整体（九户在神经、内分泌下统一） | 各系统单独介绍，正是第三个结合要去串联的对象 |
| 五 姿势、方位、轴面 | 理论与实际（任何标本仍按活体标准姿势描述） | 绪图-1、绪图-2 是文字与图画的示范 |
| 六 变异与畸形 | 进化发展（发育中的偏离）；形态与功能（影响功能则入畸形）；体型含职业和锻炼 | 标本上的差异要用正常模板对照，不能只认模型 |
:::

:::timeline{period="学解剖学时坚持什么、结合什么"}
- **指导** 辩证唯物主义
- **方法** 理论联系实际
- **观点一** 进化发展
- **观点二** 形态与功能相互影响
- **观点三** 局部与整体统一
- **观点四** 理论与实际相结合
- **结合一** 文字与图画（插图、图谱、视频、动画）
- **结合二** 理论与实物（标本、模型：观察、触摸、辨识；活体体表是其延伸）
- **结合三** 解剖与临床（案例与资料 → 系统思维、初步临床思维）
- **反面** 死记硬背：效果不佳，且容易遗忘
:::

:::tip{label="后面各章都可以用这张清单自测"}
读到一块骨、一根血管、一条神经时问：它在进化或发生上从哪来？这种形态的功能意义是什么？它在哪个局部、属于哪个整体？这句话在标本、活体、临床上落在哪？眼前这个差异是变异、畸形还是体型？图看了没有、实物对过没有、有没有一条临床线索能把它串起来？问得动，本节就没有停在绪论里。
:::

:::keypoint{label="本节不要减成「好好学习」"}
- 指导：辩证唯物主义。
- 方法：理论联系实际。
- 四个观点：进化发展；形态与功能相互影响；局部与整体统一；理论与实际相结合。
- 三个结合：文字与图画；理论与实物；解剖与临床。
- 反面教材：死记硬背，效果不佳且易遗忘。
:::
