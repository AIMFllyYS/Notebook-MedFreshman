# 第一节　呼吸道

呼吸系统（respiratory system）由呼吸道和肺组成。本节把「呼吸道」这一户写完：从鼻到左、右主支气管，按鼻、咽、喉、气管和支气管把各段形态钉死。肺泡、肺叶、肺段是第二节的户头；胸膜腔、纵隔是第三、四节，不要提前写成叶间裂或胸膜隐窝。

呼吸道包括鼻、咽、喉、气管和支气管。通常称鼻、咽、喉为上呼吸道，气管和各级支气管为下呼吸道。肺由肺实质和肺间质组成：实质含支气管树和肺泡，间质含结缔组织、血管、淋巴管、淋巴结和神经。呼吸系统的主要功能是气体交换，即吸入氧、呼出二氧化碳。此外还有发音、嗅觉、神经内分泌、协助静脉血回流入心和参与体内某些物质代谢。

:::definition{label="呼吸系统"}
由**呼吸道和肺**组成。管负责通气，肺负责换气。缺管则空气到不了肺泡，缺肺则通气没有交换场所。
:::

:::definition{label="呼吸道"}
鼻、咽、喉、气管和支气管这一条通气管道。本版名单不要改成「从鼻到肺泡」或「从喉到肺」——肺泡不在呼吸道户头里。
:::

:::definition{label="上呼吸道与下呼吸道"}
上呼吸道：鼻、咽、喉。下呼吸道：气管和各级支气管。分界在喉与气管之间（环状软骨下缘），不是鼻后孔，也不是气管杈。
:::

:::concept{term="先问这是不是通气的管子，再问有没有把肺叶写成呼吸道"}
看见呼吸系统，先把管和肺切开。管的户头是鼻到主支气管；肺的分叶、肺段、肺泡归第二节。把「呼吸系统」听成「就是肺」，鼻旁窦和喉腔会从开篇丢掉；把斜裂、水平裂写进本节，又是吞了下一节。
:::

:::compare{title="呼吸道各段（本版顺序）"}
| 段 | 本版要点 | 不要写成 |
|----|----------|----------|
| 鼻 | 起始部，兼嗅觉；外鼻 + 鼻腔 + 鼻旁窦 | 「鼻只有外鼻」；漏掉鼻旁窦 |
| 咽 | 消化与呼吸共用；形态见消化系统 | 「咽只属于呼吸道」或把整段咽从消化管删掉 |
| 喉 | 通气管道兼发音器官；上界会厌上缘，下界环状软骨下缘 | 「喉只负责发音」 |
| 气管 | 喉与气管杈之间；C 形软骨环 | 「气管直通肺泡」 |
| 支气管 | 一级分支是左、右主支气管 | 把肺叶支气管、肺段支气管提前写成本节的户头 |

:::

::figure{src="/images/anatomy/textbook/p0144_01.png" caption="图3-1　呼吸系统全貌" alt="矢状面示鼻腔、咽、喉、气管，以及左、右肺轮廓与支气管树"}

:::pitfall{label="上呼吸道止于喉，不是止于鼻"}
本版原句：鼻、咽、喉为上呼吸道，气管和各级支气管为下呼吸道。写成「上呼吸道 = 鼻」会把咽和喉丢掉；写成「下呼吸道从咽开始」会把喉从下呼吸道误算进去。环状软骨下缘才是上、下的分界。
:::

## 一、鼻

鼻（nose）是呼吸道的起始部，也是嗅觉器官，分为外鼻、鼻腔和鼻旁窦 3 部分。

:::definition{label="鼻"}
呼吸道起始部，兼嗅觉器官。本版三部是**外鼻、鼻腔、鼻旁窦**，不是「外鼻加鼻腔」两部，也不是把鼻旁窦挪到颅骨去单独立户。
:::

### （一）外鼻

外鼻（external nose）位于面部中央，以鼻骨和鼻软骨为支架，外被皮肤，内覆黏膜，分为骨部和软骨部。软骨部的皮肤因富含皮脂腺和汗腺，成为痤疮、酒渣鼻和疖肿的好发部位。外鼻与额相连的狭窄部分称鼻根，鼻根与鼻尖之间称鼻背，外鼻前下端的隆凸部位称鼻尖，鼻尖两侧的半圆形隆起称鼻翼（nasal ala）。当呼吸困难时可出现鼻翼扇动。

:::definition{label="外鼻"}
面中部的外露部分。支架是鼻骨加鼻软骨，表面皮肤、内面黏膜；分骨部和软骨部。软骨部皮肤是痤疮、酒渣鼻和疖肿的好发部位。
:::

:::definition{label="鼻翼"}
鼻尖两侧的半圆形隆起。呼吸困难时可出现**鼻翼扇动**——这是本版写在外鼻段的临床形态，不是把鼻翼听成装饰性软骨。
:::

:::compare{title="外鼻的几个体表名"}
| 名 | 位置 |
|----|------|
| 鼻根 | 外鼻与额相连的狭窄部 |
| 鼻背 | 鼻根与鼻尖之间 |
| 鼻尖 | 外鼻前下端的隆凸 |
| 鼻翼 | 鼻尖两侧的半圆形隆起 |

四名不要各开一张定义。看见鼻翼扇动，先想到呼吸困难。
:::

:::pitfall{label="鼻翼扇动是呼吸困难的体表征，不是「鼻翼自己会扇」"}
本版原句：当呼吸困难时可出现鼻翼扇动。把这一笔听成「鼻翼是呼吸肌」，会和外鼻「以骨和软骨为支架」对不上。
:::

### （二）鼻腔

鼻腔（nasal cavity）由骨和软骨及其表面被覆的黏膜和皮肤构成，位于呼吸道起始部，是顶部窄、底部宽、前后狭长的腔隙（图3-2）。鼻腔被鼻中隔分为左、右两腔，向前借鼻孔（nostril）通外界，向后经鼻后孔（choana）通鼻咽部。每侧鼻腔以鼻阈（nasal limen）为界分为鼻前庭（nasal vestibule）和固有鼻腔（nasal cavity proper）。

鼻阈是鼻前庭上方的弧形隆起，是皮肤和黏膜的交界处。鼻前庭内面由皮肤覆盖，富含皮脂腺和汗腺，生有鼻毛，有滤过和净化空气的功能。鼻前庭是疖肿的好发部位；因此处缺少皮下组织，发生疖肿时疼痛较为剧烈。固有鼻腔是鼻腔的主要部分，常简称为鼻腔，每侧鼻腔有顶、底和内、外侧壁。鼻腔顶自前向后由鼻骨、额骨、筛骨筛板和蝶骨体下面构成。鼻腔底即口腔顶，由硬腭构成。

:::definition{label="鼻腔"}
顶部窄、底部宽、前后狭长。被鼻中隔分成左、右两腔；向前经鼻孔通外界，向后经鼻后孔通鼻咽。
:::

:::definition{label="鼻阈、鼻前庭与固有鼻腔"}
鼻阈是鼻前庭上方的弧形隆起，皮肤与黏膜在此交界。阈以前是鼻前庭（皮肤、鼻毛、疖肿好发、缺皮下组织故痛剧）；阈以后是固有鼻腔（常简称鼻腔）。不要把鼻前庭听成「鼻腔的黏膜部」。
:::

::figure{src="/images/anatomy/textbook/p0145_01.png" caption="图3-2　鼻腔外侧壁（右侧面观）" alt="右侧鼻腔外侧壁，示鼻前庭、鼻阈、上中下鼻甲及鼻道、嗅区、蝶筛隐窝"}

鼻中隔（nasal septum）由筛骨垂直板、犁骨和鼻中隔软骨组成支架，表面被覆黏膜而成，构成鼻腔的内侧壁。鼻中隔位置居中者较少，通常偏向一侧。鼻中隔前下部的血管丰富、位置浅表，外伤或干燥刺激均易引起出血，约 90% 的鼻出血发生于此区，故称易出血区（又称 Little 区或 Kiesselbach 区）。

:::definition{label="鼻中隔"}
鼻腔内侧壁。支架三件套：筛骨垂直板、犁骨、鼻中隔软骨，表面覆黏膜。完全居中的少，通常偏一侧。
:::

:::definition{label="易出血区"}
鼻中隔**前下部**。血管丰富、位置浅表，约 90% 的鼻出血发生于此，又称 Little 区或 Kiesselbach 区。不是下鼻道，也不是嗅区。
:::

鼻腔外侧壁自上而下可见上、中、下 3 个鼻甲（nasal concha）。上鼻甲和中鼻甲由筛骨迷路内侧壁向下卷曲的薄骨片覆以黏膜构成，二者之间称上鼻道；中鼻甲与下鼻甲之间称中鼻道；下鼻甲下方称下鼻道。多数人上鼻甲的后上方有最上鼻甲（supreme nasal concha）。最上鼻甲或上鼻甲后上方与蝶骨体之间的凹陷称蝶筛隐窝（sphenoethmoidal recess）。

切除中鼻甲，在中鼻道中部凹向上方的弧形裂隙称半月裂孔（semilunar hiatus），其前端的漏斗状管道称筛漏斗（ethmoidal infundibulum），通额窦和前筛窦。半月裂孔上方的圆形隆起称筛泡（ethmoidal bulla），筛泡内有中筛窦。鼻泪管开口于下鼻道的前上方。

鼻黏膜分两部分：位于上鼻甲和与其相对的鼻中隔以及二者上方鼻腔顶部的区域称嗅区（olfactory region），富含接受嗅觉刺激的嗅细胞；其余黏膜部分则富含鼻腺（nasal gland），称呼吸区（图3-2）。

:::definition{label="鼻甲与鼻道"}
外侧壁自上而下三个鼻甲，甲下方对应上、中、下三道。上甲与中甲之间是上鼻道，中甲与下甲之间是中鼻道，下甲下方是下鼻道。多数人还有最上鼻甲。
:::

:::definition{label="蝶筛隐窝"}
最上鼻甲或上鼻甲后上方与蝶骨体之间的凹陷。**蝶窦**开口于此，不是开在中鼻道。
:::

:::definition{label="半月裂孔与筛漏斗"}
切掉中鼻甲后，中鼻道中部凹向上的弧形裂隙是半月裂孔；其前端漏斗状管道是筛漏斗，通额窦和前筛窦。半月裂孔上方的圆形隆起是筛泡，泡内是中筛窦。
:::

:::definition{label="嗅区与呼吸区"}
嗅区：上鼻甲、相对的鼻中隔，以及二者上方的鼻腔顶部，有嗅细胞。其余黏膜富含鼻腺，称呼吸区。不要把整个鼻黏膜都听成嗅黏膜。
:::

:::compare{title="鼻腔外侧壁开口（先分清道）"}
| 部位 | 本版开口/内容 |
|------|----------------|
| 上鼻道 | 后筛窦 |
| 中鼻道 | 额窦（经筛漏斗）、前筛窦、中筛窦（筛泡内）、上颌窦（半月裂孔） |
| 下鼻道前上方 | 鼻泪管 |
| 蝶筛隐窝 | 蝶窦 |

中鼻道最忙，下鼻道只有鼻泪管，蝶窦不走鼻道走隐窝。
:::

:::pitfall{label="约 90% 的鼻出血在鼻中隔前下部，不要写成下鼻甲"}
易出血区又称 Little 区、Kiesselbach 区，户头落在鼻中隔前下。写成「鼻腔外侧壁」或「下鼻道」，压迫止血会按错壁。
:::

### （三）鼻旁窦

鼻旁窦是指鼻腔周围含气颅骨内的空腔，分别位于额骨、筛骨、蝶骨和上颌骨内，窦壁内衬黏膜并与鼻腔黏膜相移行，有温暖、湿润空气及对发音产生共鸣的作用，又称副鼻窦（图3-3、图3-4）。

:::definition{label="鼻旁窦"}
额窦、筛窦、蝶窦、上颌窦四对。衬黏膜，与鼻腔黏膜相移行；功能是温暖湿润空气、发音共鸣。别名副鼻窦。不要漏掉其中一对，也不要把乳突气房算进来。
:::

::figure{src="/images/anatomy/textbook/p0146_01.png" caption="图3-3　鼻旁窦开口（上、中、下鼻甲及筛骨迷路内侧壁切除）" alt="切除鼻甲后的鼻腔外侧壁，示额窦、筛窦、蝶窦、上颌窦开口及鼻泪管"}

::figure{src="/images/anatomy/textbook/p0146_02.png" caption="图3-4　鼻旁窦体表投影" alt="头面正面和侧面示额窦、筛窦、蝶窦、上颌窦的体表投影"}

**1. 额窦**　额窦（frontal sinus）位于额骨额鳞的下部内，左、右各一，呈三棱锥体形。底向下，尖向上，中隔常偏向一侧，大小不一。国人额窦高为 3.2 cm，宽为 2.6 cm，前后深度为 1.8 cm。额窦口在窦底部通筛漏斗，开口于中鼻道。

:::definition{label="额窦"}
额鳞下部，三棱锥体，底向下、尖向上。本版国人数字：高 3.2 cm、宽 2.6 cm、前后深度 1.8 cm。开口经筛漏斗入**中鼻道**。
:::

**2. 筛窦**　筛窦（ethmoidal sinus）是位于筛骨迷路内的海绵状小气房，每侧 3～18 个。筛窦按部位分为前筛窦、中筛窦和后筛窦。前筛窦气房数为 1～6 个，中筛窦的气房有 1～7 个，二者均开口于中鼻道；后筛窦位于筛骨迷路的后部，开口于上鼻道。因后筛窦与视神经管毗邻，故后筛窦的感染向周围蔓延可引起视神经炎。

:::definition{label="筛窦"}
筛骨迷路内的小气房，每侧 3～18 个，分前、中、后三群。前筛窦 1～6 个、中筛窦 1～7 个，都开中鼻道；后筛窦开**上鼻道**。后筛窦贴视神经管，感染可致视神经炎。
:::

**3. 蝶窦**　蝶窦（sphenoidal sinus）是蝶骨体内的含气空腔，位于鼻腔上部的后方，与后筛窦毗邻，容积平均为 7.5 ml，被中隔分为左、右两个腔，窦口直径为 2～3 mm，分别开口于左、右蝶筛隐窝。

:::definition{label="蝶窦"}
蝶骨体内，鼻腔上部后方，平均容积 7.5 ml，窦口直径 2～3 mm。开口于**蝶筛隐窝**，不是上鼻道，也不是中鼻道。
:::

**4. 上颌窦**　上颌窦（maxillary sinus）位于上颌骨体内，呈三角锥体形。成人上颌窦平均高 3.3 cm、宽 2.3 cm、长 3.4 cm，平均容积是 14.67 ml，有 5 个壁。前壁是上颌骨体前面的尖牙窝，骨质较薄；后外壁较厚，与翼腭窝毗邻；内侧壁即鼻腔的外侧壁，由中鼻道和大部分下鼻道构成；上壁即眶下壁；底壁即上颌骨的牙槽突，常低于鼻腔下壁。因上颌第二前磨牙、第一和第二磨牙根部与窦底壁邻近，只有一层薄的骨质相隔，有时牙根可突入窦内，此处牙根仅以黏膜与窦腔相隔，故患牙病和上颌窦的炎症或肿瘤时可相互累及。上颌窦开口于中鼻道的半月裂孔。上颌窦的开口位置较高，分泌物不易排出，当窦腔积液时，应采取体位引流。

:::definition{label="上颌窦"}
上颌骨体内，最大的一对鼻旁窦。本版成人数字：高 3.3 cm、宽 2.3 cm、长 3.4 cm，平均容积 14.67 ml。开口于中鼻道半月裂孔，开口位置高，积液要体位引流。
:::

:::compare{title="四对鼻旁窦（开口不要记混）"}
| 窦 | 位置 | 本版数字 | 开口 |
|----|------|----------|------|
| 额窦 | 额鳞下部 | 高 3.2 cm，宽 2.6 cm，前后 1.8 cm | 中鼻道（经筛漏斗） |
| 筛窦 | 筛骨迷路 | 每侧 3～18 个气房 | 前、中 → 中鼻道；后 → 上鼻道 |
| 蝶窦 | 蝶骨体 | 容积 7.5 ml，口 2～3 mm | 蝶筛隐窝 |
| 上颌窦 | 上颌骨体 | 高 3.3、宽 2.3、长 3.4 cm，容积 14.67 ml | 中鼻道半月裂孔 |

:::

:::compare{title="上颌窦五壁"}
| 壁 | 本版对应 |
|----|----------|
| 前壁 | 尖牙窝，骨质较薄 |
| 后外壁 | 较厚，毗邻翼腭窝 |
| 内侧壁 | 鼻腔外侧壁（中鼻道 + 大部分下鼻道） |
| 上壁 | 眶下壁 |
| 底壁 | 上颌骨牙槽突，常低于鼻腔下壁 |

底壁邻上颌第二前磨牙、第一和第二磨牙牙根。牙病和上颌窦炎、肿瘤可互相累及。
:::

:::pitfall{label="后筛窦开上鼻道，蝶窦开蝶筛隐窝，不要都写成中鼻道"}
中鼻道确实最忙（额窦、前筛窦、中筛窦、上颌窦），但后筛窦走的是上鼻道，蝶窦走的是蝶筛隐窝。四对窦「一律开中鼻道」会把后筛窦炎和蝶窦炎的引流方向写反。
:::

:::insight{label="上颌窦口高，积液不会自己流干净"}
开口在半月裂孔，位置高于窦底。立位时脓液积在底壁，要靠体位引流。加上底壁邻磨牙牙根，牙痛和上颌窦炎会互相「串户」——形态底板就是这口开得太高、这底贴得太近。
:::

## 二、咽

咽的形态、分部、咽壁肌和咽淋巴环，本版写在消化系统（第二章消化管）。呼吸道这一节只钉死一件事：咽是上呼吸道的一段，是消化管与呼吸道的共同通道。

咽（pharynx）呈上宽下窄、前后略扁的漏斗形肌性管道，上起颅底，下至第 6 颈椎下缘或环状软骨高度续食管。以腭帆游离缘和会厌上缘平面为界，分为鼻咽、口咽和喉咽。向前依次经鼻后孔通鼻腔、经咽峡通口腔、经喉口通喉腔。口咽和喉咽才是消化与呼吸真正交叉的路段；鼻咽主要属呼吸道。

:::definition{label="咽（呼吸道）"}
上呼吸道的中段，消化管与呼吸道的共同通道。形态细节见第二章消化管。本节只保留它在通气链上的位置：鼻后孔之后、喉口之前。
:::

:::compare{title="咽的三部与通气"}
| | 上下界 | 向前通 | 与呼吸的关系 |
|--|--------|--------|--------------|
| 鼻咽 | 颅底 → 腭帆游离缘 | 鼻后孔 → 鼻腔 | 主要属呼吸道 |
| 口咽 | 腭帆游离缘 → 会厌上缘 | 咽峡 → 口腔 | 消化与呼吸共用 |
| 喉咽 | 会厌上缘 → 第 6 颈椎下缘（续食管） | 喉口 → 喉腔 | 消化与呼吸共用 |

三部分界用的是腭帆游离缘和会厌上缘，不要用「软腭」或「喉口」含糊替换。
:::

:::pitfall{label="咽的形态不要在本节重写一遍，也不要从上呼吸道名单里删掉"}
本版在呼吸系统原句是「具体内容见消化系统」。漏写咽，上呼吸道会少一段；把咽隐窝、梨状隐窝、咽淋巴环整节复制过来，又和第二章撞户。通气链上点名、细节回消化管。
:::

## 三、喉

喉（larynx）既是呼吸的管道，又是发音的器官，主要由喉软骨和喉肌构成。上界是会厌上缘，下界是环状软骨下缘。借喉口通喉咽部，以环状软骨气管韧带连接气管。成年人喉位于第 3～6 颈椎前方。喉的前方被皮肤、颈筋膜及舌骨下肌群所覆盖，喉的后方紧邻喉咽部，两侧有颈血管、神经和甲状腺侧叶。

:::definition{label="喉"}
通气管道兼发音器官。上界会厌上缘，下界环状软骨下缘；借喉口通喉咽，借环状软骨气管韧带接气管。成人平对第 3～6 颈椎前方。
:::

:::keypoint{label="喉的位置三句话"}
- 上界会厌上缘，下界环状软骨下缘。
- 前方皮肤、颈筋膜、舌骨下肌群；后方喉咽；两侧颈血管、神经和甲状腺侧叶。
- 成人在第 3～6 颈椎前方。环状软骨弓平第 6 颈椎，是颈部标志。
:::

### （一）喉软骨

喉的支架由甲状软骨、环状软骨、会厌软骨和成对的杓状软骨等喉软骨构成。图中还可见成对的小角软骨、楔状软骨，以及甲状舌骨外侧韧带内的麦粒软骨；本版正文立户的是前四块。

:::definition{label="喉软骨（本版立户）"}
甲状软骨、环状软骨、会厌软骨、成对的杓状软骨。环状软骨是其中**唯一完整的软骨环**。
:::

**1. 甲状软骨**　甲状软骨（thyroid cartilage）是最大的喉软骨，位于环状软骨与会厌软骨之间，构成喉的前壁和侧壁。甲状软骨由前缘互相愈合的呈四边形的左、右软骨板组成。左、右软骨板的融合处称前角（anterior horn），前角上端向前突出，称为喉结（laryngeal prominence），在成年男子明显。喉结上方有呈 V 形的切迹，称为上切迹（superior notch）。左、右软骨板的后缘游离并向上、下发出突起，分别称为上角和下角。上角较长，借韧带与舌骨大角相连；下角较短，与环状软骨相关节（图3-5）。

:::definition{label="甲状软骨"}
最大的喉软骨，构成喉的前壁和侧壁。左、右四边形软骨板在前缘愈合形成前角；前角上端的喉结在成年男子明显。上角连舌骨大角，下角与环状软骨相关节。
:::

::figure{src="/images/anatomy/textbook/p0147_01.png" caption="图3-5　甲状软骨前、后面观" alt="甲状软骨前面观和后面观，示喉结、上切迹、上角、下角和左、右板"}

**2. 环状软骨**　环状软骨（cricoid cartilage）是喉软骨中唯一完整的软骨环，位于甲状软骨的下方。环状软骨由前部低窄的环状软骨弓（cricoid arch）和后部高阔的环状软骨板（cricoid lamina）构成（图3-6）。环状软骨弓平对第 6 颈椎高度，是颈部的重要标志之一。环状软骨板上缘两侧各有一杓关节面（arytenoid articular surface）。在环状软骨弓与板的交界处，两侧各有一圆形的甲关节面（thyroid articular surface）。环状软骨的作用是支撑呼吸道，保持其畅通，若损伤会造成喉狭窄。

:::definition{label="环状软骨"}
喉软骨中**唯一完整的软骨环**。前低窄为弓，后高阔为板。弓平第 6 颈椎。板上缘两侧是杓关节面，弓板交界两侧是甲关节面。损伤会造成喉狭窄。
:::

**3. 会厌软骨**　会厌软骨（epiglottic cartilage）位于舌骨体后方，形似树叶，上宽下窄，上端游离，下端借甲状会厌韧带连于甲状软骨前角内面的上部（图3-7）。会厌软骨被覆黏膜构成会厌（epiglottis）。会厌是喉口的活瓣：吞咽运动时，喉随咽上提并向前移动，会厌封闭喉口，阻止食团入喉并引导食团入咽。

:::definition{label="会厌"}
会厌软骨覆黏膜而成。形似树叶，上宽下窄；下端借甲状会厌韧带连甲状软骨前角内面。吞咽时封闭喉口，是喉口的活瓣，不是一块「盖在舌根上的装饰」。
:::

**4. 杓状软骨**　杓状软骨（arytenoid cartilage）位于环状软骨板上方中线两侧，形似三棱锥体，是成对的喉软骨。杓状软骨分为一尖、一底、两突和三面。杓状软骨底与环状软骨杓关节面形成环杓关节。底面有向前伸出的突起称声带突（vocal process），是声韧带附着处；向外侧伸出的突起称肌突（muscular process），大部分喉肌附着于此（见图3-6）。

:::definition{label="杓状软骨"}
成对，三棱锥体，坐在环状软骨板上缘两侧。一尖、一底、两突、三面。底参与环杓关节；声带突向前附着声韧带，肌突向外附着大部分喉肌。
:::

::figure{src="/images/anatomy/textbook/p0147_02.png" caption="图3-6　环状软骨和杓状软骨（前面观）" alt="环状软骨弓和板，板上的杓状软骨，示声带突、肌突、杓关节面和甲关节面"}

::figure{src="/images/anatomy/textbook/p0147_03.png" caption="图3-7　会厌软骨（后面观）" alt="树叶形会厌软骨后面观，示会厌软骨茎"}

:::compare{title="四块喉软骨（先认支架）"}
| 软骨 | 单/对 | 本版要点 |
|------|-------|----------|
| 甲状软骨 | 单 | 最大；喉结、上切迹、上角、下角 |
| 环状软骨 | 单 | 唯一完整软骨环；弓平 C6；损伤 → 喉狭窄 |
| 会厌软骨 | 单 | 树叶形；覆黏膜成会厌，吞咽时关喉口 |
| 杓状软骨 | 对 | 三棱锥；声带突 + 肌突 |

:::

:::pitfall{label="环状软骨是唯一完整的软骨环，甲状软骨不是环"}
甲状软骨是两块四边形板在前方愈合，后方敞开。把「喉的支架」听成「甲状软骨围成一圈」，环状软骨支撑气道、损伤致喉狭窄这一笔就没有着落。
:::

### （二）喉的连结

喉的连结包括喉软骨间的连结及舌骨、气管与喉之间的连结。

**1. 甲状舌骨膜**　甲状舌骨膜（thyrohyoid membrane）是位于甲状软骨上缘与舌骨之间的结缔组织膜，其中部增厚称甲状舌骨正中韧带（median thyrohyoid ligament）。连接甲状软骨上角和舌骨大角的韧带是甲状舌骨外侧韧带，其内常含有麦粒软骨（triticeal cartilage）（图3-8、图3-9）。

:::definition{label="甲状舌骨膜"}
甲状软骨上缘与舌骨之间。中部增厚为甲状舌骨正中韧带；外侧份连上角与舌骨大角，内常有麦粒软骨。
:::

**2. 环甲关节**　环甲关节（cricothyroid joint）由环状软骨的甲关节面和甲状软骨下角构成，属于联合关节（图3-8、图3-9）。在环甲肌的牵引下，甲状软骨在冠状轴上作前倾运动。甲状软骨前倾使甲状软骨前角与杓状软骨间距加大，使声带紧张；甲状软骨复位时，两者间距缩小，使声带松弛。

:::definition{label="环甲关节"}
环状软骨甲关节面 + 甲状软骨下角，联合关节。甲状软骨前倾 → 前角与杓状软骨间距加大 → 声带紧张；复位 → 间距缩小 → 声带松弛。
:::

**3. 环杓关节**　环杓关节（cricoarytenoid joint）由环状软骨板上缘的杓关节面和杓状软骨底的关节面构成（见图3-8）。杓状软骨可沿该关节垂直轴作旋内和旋外运动。杓状软骨旋内使声带突互相靠近，缩小声门裂；旋外使声带突互相分开，开大声门裂。环杓关节还可作向前、后、内侧、外侧等方向的滑动运动。

:::definition{label="环杓关节"}
环状软骨板上缘杓关节面 + 杓状软骨底。旋内：声带突靠近，声门裂缩小；旋外：声带突分开，声门裂开大。还可前后内外滑动。
:::

::figure{src="/images/anatomy/textbook/p0148_01.png" caption="图3-8　喉软骨连结" alt="喉软骨连结前面观和后面观，示甲状舌骨膜、环甲关节、环杓关节和环甲正中韧带"}

::figure{src="/images/anatomy/textbook/p0148_02.png" caption="图3-9　喉软骨连结（侧面观）" alt="喉侧面观，示甲状舌骨膜、环甲肌、环甲正中韧带和麦粒软骨"}

**4. 方形膜**　方形膜（quadrangular membrane）起于甲状软骨前角后面和会厌软骨两侧缘，向后附着于杓状软骨前内侧缘，构成喉前庭外侧壁的基础。上缘位于杓状会厌襞内，下缘游离称前庭韧带（vestibular ligament），即室韧带（图3-10）。

:::definition{label="方形膜"}
喉前庭外侧壁的弹性膜。起甲状软骨前角后面和会厌软骨两侧缘，止杓状软骨前内侧缘。上缘在杓状会厌襞内，**下缘游离 = 前庭韧带（室韧带）**。
:::

**5. 弹性圆锥**　弹性圆锥（conus elasticus）是喉腔内呈圆锥形的弹性结缔组织膜，又称环声膜或环甲膜。弹性圆锥起于甲状软骨前角内面，呈扇形向后、向下止于杓状软骨声带突和环状软骨上缘。弹性圆锥上缘游离增厚，紧张于甲状软骨至声带突之间，称为声韧带（vocal ligament），较前庭韧带厚而短（图3-10）。声韧带连同声带肌及覆盖于其表面的喉黏膜一起构成声带（vocal cord）。弹性圆锥前面中部弹性纤维增厚称环甲正中韧带（median cricothyroid ligament）。急性喉阻塞时，可在环甲正中韧带处进行穿刺，以建立暂时性通气道。当紧急切开弹性圆锥进行抢救时，注意勿损伤环甲动脉吻合弓（图3-11）。

:::definition{label="弹性圆锥"}
喉腔内圆锥形弹性膜，又称环声膜或环甲膜。起甲状软骨前角内面，扇形向后下止于声带突和环状软骨上缘。**上缘游离增厚 = 声韧带**（较前庭韧带厚而短）。
:::

:::definition{label="声带"}
声韧带 + 声带肌 + 表面的喉黏膜。三件一起才叫声带，不是「只有一条韧带」。
:::

:::definition{label="环甲正中韧带"}
弹性圆锥前面中部增厚。急性喉阻塞可在此处穿刺建立暂时通气道。紧急切开弹性圆锥时，勿损伤环甲动脉吻合弓。
:::

**6. 环状软骨气管韧带**　环状软骨气管韧带（cricotracheal ligament）是连接环状软骨下缘和第 1 气管软骨环的结缔组织膜。

:::compare{title="方形膜与弹性圆锥（上下两张膜）"}
| | 方形膜 | 弹性圆锥 |
|--|--------|----------|
| 位置 | 偏上，构成喉前庭外侧壁 | 偏下，喉腔内呈圆锥形 |
| 游离缘 | 下缘 = 前庭韧带（室韧带） | 上缘 = 声韧带 |
| 韧带厚薄 | 前庭韧带相对薄而长 | 声韧带较厚而短 |
| 临床 | — | 前面中部 = 环甲正中韧带，可穿刺通气 |

两张膜不要并成「喉的一张弹性膜」。
:::

::figure{src="/images/anatomy/textbook/p0149_01.png" caption="图3-10　方形膜和弹性圆锥（上面观）" alt="上面观示方形膜、前庭韧带、弹性圆锥、声韧带和声门裂"}

::figure{src="/images/anatomy/textbook/p0149_02.png" caption="图3-11　环甲动脉吻合弓与环甲正中韧带" alt="颈前血管神经，示环甲动脉吻合弓、环甲正中韧带、甲状腺和左喉返神经"}

:::cause-effect{title="环甲关节前倾为什么使声带紧张"}
- **因** 甲状软骨在冠状轴上前倾，前角与杓状软骨之间的距离加大
- **果** 连在两者之间的声韧带被拉长、拉紧

复位则间距缩小，声带松弛。环甲肌是拉动这一关节的肌。
:::

:::pitfall{label="声韧带是弹性圆锥上缘，前庭韧带是方形膜下缘"}
上下记反，声带和室带会对调：上面那条粉红色皱襞是前庭襞，下面更突向喉腔的才是声襞。环甲膜、环声膜都是弹性圆锥的别名，不要另立一张膜。
:::

### （三）喉肌

喉肌（laryngeal muscle）是发音的动力器官，属于横纹肌。喉肌分为附着于喉和邻近结构的喉外肌和附着于喉软骨间的喉内肌。喉外肌的作用是使喉上升或下降。喉肌一般指喉内肌，具有紧张或松弛声带、缩小或开大声门裂以及缩小喉口等作用（表3-1）。喉内肌按其部位分内、外两群，按其功能分声门开大肌和声门括约肌（图3-12～图3-14）。

:::definition{label="喉肌"}
发音的动力器官，属横纹肌。广义分喉外肌（升、降喉）和喉内肌；一般所说喉肌指喉内肌：紧张或松弛声带、缩小或开大声门裂、缩小喉口。
:::

:::compare{title="表3-1　喉肌的名称、起止和主要作用"}
| 名称 | 起止 | 主要作用 |
|------|------|----------|
| 环甲肌 | 起于环状软骨弓前外侧面，止于甲状软骨下角和下缘 | 紧张声带 |
| 环杓后肌 | 起于环状软骨板后面，止于杓状软骨肌突 | 开大声门裂，紧张声带 |
| 环杓侧肌 | 起于环状软骨上缘和弹性圆锥的外面，止于杓状软骨肌突 | 使声门裂变窄 |
| 甲杓肌 | 起于甲状软骨前角后面，止于杓状软骨外侧面 | 松弛声带，缩小声门裂 |
| 杓横肌 | 肌束横行连于两侧杓状软骨肌突和外侧缘 | 缩小喉口和喉前庭，紧张声带 |
| 杓斜肌 | 起于杓状软骨肌突，止于对侧杓状软骨尖 | 缩小喉口和声门裂 |
| 杓会厌肌 | 起于杓状软骨尖，止于会厌软骨及甲状会厌韧带 | 拉会厌向后下，关闭喉口 |

肌名用这一张表，不为每一条肌束单独开定义。环甲肌是本版「唯一的一对喉外群肌」。
:::

**1. 环甲肌**　环甲肌（cricothyroid muscle）是唯一的一对喉外群肌。环甲肌起于环状软骨弓前外侧面，肌束斜向后上方，止于甲状软骨下角和下缘。环甲肌收缩将增加甲状软骨前角与杓状软骨的间距，紧张并拉长声带。

:::definition{label="环甲肌"}
本版唯一的一对喉外群肌。起环状软骨弓前外侧面，止甲状软骨下角和下缘。收缩加大前角与杓状软骨间距，紧张并拉长声带。
:::

**2. 环杓后肌**　环杓后肌（posterior cricoarytenoid muscle）起于环状软骨板后面，斜向外上方，止于同侧杓状软骨的肌突。环杓后肌收缩能使环杓关节在垂直轴上旋转，拉肌突转向后内下，使声带突转向外上，开大声门裂，紧张声带。

:::definition{label="环杓后肌"}
起环状软骨板后面，止同侧肌突。拉肌突后内下、声带突外上，**开大声门裂**并紧张声带。功能表上开大声门裂的就是这一对。
:::

**3. 环杓侧肌**　环杓侧肌（lateral cricoarytenoid muscle）起于环状软骨弓上缘和弹性圆锥的外面，自甲状软骨板的内侧向后上方斜行，止于杓状软骨肌突的前面。环杓侧肌收缩牵引肌突向前下方运动，使声带突转向内侧，声门裂变窄。

**4. 甲杓肌**　甲杓肌（thyroarytenoid muscle）起于甲状软骨前角后面，向后止于杓状软骨外侧面。甲杓肌上部肌束位于前庭韧带外侧，收缩能缩短前庭襞；下部肌束位于声襞内、声韧带的外侧，称为声带肌（vocalis），声带肌收缩使声襞变短并松弛。

**5. 杓肌**　杓肌（arytenoid）位于喉的后壁，包括杓横肌、杓斜肌和杓会厌肌。

::figure{src="/images/anatomy/textbook/p0151_01.png" caption="图3-14　喉内肌（通过声带水平切面）" alt="经声带水平切面，示声襞、声韧带、声带肌、声门裂膜间部和软骨间部"}

:::compare{title="声门开大与括约（功能不要记反）"}
| 作用 | 本版的肌 |
|------|----------|
| 开大声门裂 | 环杓后肌 |
| 声门裂变窄 / 缩小 | 环杓侧肌、甲杓肌、杓斜肌 |
| 紧张声带 | 环甲肌、环杓后肌、杓横肌 |
| 松弛声带 | 甲杓肌（声带肌） |
| 关闭喉口 | 杓会厌肌（拉会厌后下）；杓横肌缩小喉口和喉前庭 |

开大只记环杓后肌。两侧环杓后肌同时麻痹，声门裂不能开大，通气会出大事。
:::

:::pitfall{label="环甲肌紧张声带，环杓后肌才开大声门裂"}
环甲肌走环甲关节，拉长声带，并不旋开声带突。把「紧张声带」听成「开大声门」，环杓后肌这一对唯一的开大肌会从功能表里丢掉。
:::

:::insight{label="肌突是杠杆的外臂，声带突是内臂"}
大部分喉肌止于肌突。环杓后肌把肌突拉向后内下，声带突就转向外上，声门裂开大；环杓侧肌把肌突拉向前下，声带突转向内侧，声门裂变窄。先认两突，再背肌名。
:::

### （四）喉腔

喉腔（laryngeal cavity）是由喉软骨、韧带、纤维膜、喉肌和喉黏膜等共同围成的管腔。喉腔上起自喉口，与咽相通；向下经气管通支气管和肺。喉腔侧壁有上、下两对黏膜皱襞，上方的一对称前庭襞，下方的一对称声襞。上述两对皱襞将喉腔分为 3 部分，即前庭襞上方的喉前庭，声襞下方的声门下腔，前庭襞和声襞之间的喉中间腔。

:::definition{label="喉腔"}
喉软骨、韧带、纤维膜、喉肌和喉黏膜共同围成的管腔。上起喉口通咽，下经气管通支气管和肺。两对皱襞把它分成喉前庭、喉中间腔、声门下腔。
:::

:::definition{label="喉腔三部"}
前庭襞以上 = 喉前庭；前庭襞与声襞之间 = 喉中间腔；声襞以下到环状软骨下缘 = 声门下腔。分界是两对皱襞，不是三块软骨。
:::

**1. 喉口**　喉口（aditus laryngis）是喉腔的上口。由会厌上缘、杓状会厌襞和杓间切迹共同围成。连接杓状软骨尖与会厌软骨侧缘的黏膜皱襞称杓状会厌襞（aryepiglottic fold）。

前庭襞（vestibular fold）是喉腔侧壁上呈矢状位、粉红色的黏膜皱襞。连于甲状软骨前角后面与杓状软骨声带突上方的前内侧缘之间。两侧前庭襞之间的裂隙称前庭裂（rima vestibuli），较声门裂宽。声襞（vocal fold）是连于甲状软骨前角后面和杓状软骨声带突之间的黏膜皱襞，位于前庭襞的下方，其较前庭襞更突向喉腔（图3-15）。

:::definition{label="喉口"}
喉腔上口。围成：会厌上缘 + 杓状会厌襞 + 杓间切迹。少写了杓间切迹，后界会缺一口。
:::

:::definition{label="前庭襞与声襞"}
上都是侧壁上的矢状位黏膜皱襞。前庭襞在上，粉红色，两侧之间是前庭裂（较宽）。声襞在下，更突向喉腔，连甲状软骨前角后面与声带突。不要把上面那条粉红色的当成声带。
:::

**2. 喉前庭**　喉前庭（laryngeal vestibule）位于喉口与前庭襞之间，上宽下窄呈漏斗状。前壁中下份有会厌软骨茎附着，附着处的上方有呈结节状的隆起称会厌结节。

**3. 喉中间腔**　喉中间腔（intermediate cavity of larynx）是喉腔中声襞与前庭襞之间的部分，向两侧经前庭襞与声襞间的裂隙至喉室（ventricle of larynx）。声门裂（fissure of glottis）是两侧声襞与杓状软骨底和声带突之间的裂隙，较前庭裂长而窄，是喉腔最狭窄之处。声门裂前 2/3 位于两侧声带之间称膜间部（intermembranous part），后 1/3 位于两侧杓状软骨底和声带突之间称软骨间部（intercartilaginous part）。声带和声门裂合称为声门（glottis）（图3-15）。

:::definition{label="喉中间腔与喉室"}
声襞与前庭襞之间的中段。向两侧伸入前庭襞与声襞之间的裂隙，形成喉室。喉室不是第三对皱襞，是中间腔向两侧的隐窝。
:::

:::definition{label="声门裂"}
两侧声襞与杓状软骨底、声带突之间的裂隙。较前庭裂**长而窄**，是喉腔最狭窄处。前 2/3 膜间部，后 1/3 软骨间部。
:::

:::definition{label="声门"}
声带 + 声门裂。两件合称，不要把声门听成「只是一条缝」或「只是两条带」。
:::

**4. 声门下腔**　声门下腔（infraglottic cavity）是声襞与环状软骨下缘之间的部分，其黏膜下组织疏松，炎症时易发生喉水肿，尤以婴幼儿更易发生急性喉水肿而致喉阻塞，造成呼吸困难。

:::definition{label="声门下腔"}
声襞至环状软骨下缘。黏膜下组织疏松，炎则水肿；婴幼儿更易急性喉水肿 → 喉阻塞 → 呼吸困难。
:::

::figure{src="/images/anatomy/textbook/p0152_01.png" caption="图3-15　喉（后正中切开）及平静呼吸、发声时的声带变化" alt="喉后正中切开示喉腔结构，下方为平静呼吸和发声时的声带所见"}

:::compare{title="喉腔侧壁两对襞、两道裂"}
| | 襞 | 两侧之间的裂 | 本版要点 |
|--|----|--------------|----------|
| 上 | 前庭襞（粉红） | 前庭裂 | 较宽 |
| 下 | 声襞（更突向喉腔） | 声门裂 | 较长较窄，喉腔最窄 |

声门裂再分膜间部（前 2/3）和软骨间部（后 1/3）。
:::

:::pitfall{label="喉腔最窄的是声门裂，不是前庭裂，也不是声门下腔"}
前庭裂更宽。声门下腔的危险不在「更窄」，而在黏膜下疏松、婴幼儿易水肿。把三部的「危险」都写成「最狭窄」，临床处理会对错层。
:::

:::insight{label="平静呼吸声门裂开，发声时膜间部靠拢"}
图3-15 把喉镜所见钉在形态上：平静呼吸时能看见声门裂；发声时声襞向中线靠拢。膜间部是发声的主要缝，软骨间部在后方连着杓状软骨底。
:::

## 四、气管和支气管

### （一）气管

气管（trachea）位于喉与气管杈之间，成年男、女性气管平均长分别是 10.31 cm 和 9.71 cm。气管起自环状软骨下缘（约平第 6 颈椎），向下至胸骨角平面（约平第 4 胸椎椎体下缘），分叉形成左、右主支气管，分叉处称气管杈（bifurcation of trachea）（图3-16）。气管全长以胸廓上口为界，分为气管颈部和气管胸部。在气管杈的内面，有一矢状位向上凸出的半月状嵴称气管隆嵴（carina of trachea），略偏向左侧，是支气管镜检查时判断气管分叉的重要标志（图3-17）。

气管由黏膜、气管软骨、平滑肌和结缔组织构成。气管软骨（tracheal cartilage）由 14～17 个呈 C 形缺口向后的透明软骨环构成。气管软骨后壁缺口由气管的膜壁（membranous wall）封闭，该膜壁由弹性纤维和平滑肌构成，这些平滑肌纤维又称气管肌（tracheal muscle）。甲状腺峡多位于第 2～4 气管软骨环前方，气管切开术常在第 3～5 气管软骨环处施行。

:::definition{label="气管"}
喉与气管杈之间的管道。本版长度：男性平均 10.31 cm，女性平均 9.71 cm。起自环状软骨下缘（约平 C6），向下至胸骨角平面（约平 T4 椎体下缘）分成左、右主支气管。
:::

:::definition{label="气管杈"}
气管下端的分叉，形成左、右主支气管。平面约平胸骨角、第 4 胸椎椎体下缘。不要把气管杈听成肺门。
:::

:::definition{label="气管隆嵴"}
气管杈内面矢状位向上凸的半月状嵴，**略偏向左侧**。支气管镜检查时判断气管分叉的标志。偏左这一笔，和右主支气管较陡直是同一套形态。
:::

:::keypoint{label="气管切开与甲状腺峡"}
- 气管软骨 14～17 个，C 形，缺口向后，膜壁补后壁。
- 甲状腺峡多在第 2～4 气管软骨环前方。
- 气管切开术常在第 3～5 气管软骨环处施行。
- 上端借环状软骨气管韧带接环状软骨下缘。
:::

:::pitfall{label="气管切开常在第 3～5 环，不要写成第 2～4 环"}
第 2～4 环前方是甲状腺峡的常见位置。切开选 3～5 环，是为了避开峡部又不要太靠下进入胸骨后。把两个数字并成一个「2～4」，会切到峡。
:::

### （二）支气管

支气管（bronchi）是气管分出的各级分支，其中一级分支是左、右主支气管（图3-16）。主支气管入肺门后的肺叶支气管、肺段支气管和支气管树，形态归第二节。

:::definition{label="支气管"}
气管分出的各级分支。本节只把**一级分支**——左、右主支气管——写完。二级肺叶支气管、三级肺段支气管是第二节的户头。
:::

**1. 右主支气管**　右主支气管（right principal bronchus）是气管杈与右肺门之间的通气管道。右主支气管在男性平均长 2.1 cm，在女性平均长 1.9 cm。其外径在男性平均是 1.5 cm，在女性平均是 1.4 cm。气管中线与主支气管下缘间的夹角称嵴下角（subcarinal angle），男性右嵴下角平均是 21.96°，女性平均是 24.7°。

:::definition{label="右主支气管"}
气管杈到右肺门。本版：男性长 2.1 cm、外径 1.5 cm；女性长 1.9 cm、外径 1.4 cm。短、粗、陡。
:::

:::definition{label="嵴下角"}
气管中线与主支气管下缘间的夹角。本版右嵴下角：男性平均 **21.96°**，女性平均 **24.7°**。不要改成其他教材常见的「左右夹角约 70°」或「60°～75°」。
:::

**2. 左主支气管**　左主支气管（left principal bronchus）是气管杈与左肺门之间的通气管道。左主支气管在男性平均长 4.8 cm，在女性平均长 4.5 cm。其外径在男性平均是 1.4 cm，在女性平均是 1.3 cm。男性左嵴下角平均是 36.4°，女性平均是 39.3°。

:::definition{label="左主支气管"}
气管杈到左肺门。本版：男性长 4.8 cm、外径 1.4 cm；女性长 4.5 cm、外径 1.3 cm。细、长、斜。左嵴下角男性平均 36.4°，女性平均 39.3°。
:::

**3. 左、右主支气管的特点**　左主支气管细而长，嵴下角大，斜行，通常有 7～8 个软骨环；右主支气管短而粗，嵴下角小，走行较陡直，通常有 3～4 个软骨环。因此，经气管坠入的异物多进入右主支气管。

:::compare{title="左、右主支气管（本版数字）"}
| | 右主支气管 | 左主支气管 |
|--|------------|------------|
| 长度（男 / 女） | 2.1 cm / 1.9 cm | 4.8 cm / 4.5 cm |
| 外径（男 / 女） | 1.5 cm / 1.4 cm | 1.4 cm / 1.3 cm |
| 嵴下角（男 / 女） | 21.96° / 24.7° | 36.4° / 39.3° |
| 软骨环 | 通常 3～4 个 | 通常 7～8 个 |
| 走行 | 短、粗、陡直 | 细、长、斜行 |
| 异物 | **多进入右侧** | 较少 |

:::

::figure{src="/images/anatomy/textbook/p0153_01.png" caption="图3-16　气管与支气管" alt="气管和左、右主支气管前面观、后面观，示气管杈、膜壁、气管隆嵴及肺叶支气管起始"}

::figure{src="/images/anatomy/textbook/p0153_02.png" caption="图3-17　气管隆嵴" alt="气管杈内面观，示略偏左的气管隆嵴以及左、右主支气管开口"}

:::cause-effect{title="异物为什么多坠入右主支气管"}
- **因** 右主支气管短而粗、嵴下角小、走行陡直；气管隆嵴又略偏向左侧，右侧开口更「正对」气管长轴
- **果** 经气管坠入的异物多进入右主支气管

左主支气管细长、嵴下角大、斜行，异物不容易「拐」进去。
:::

:::pitfall{label="嵴下角按本版右 21.96° / 24.7°，不要改写成 70°"}
有的教材把左、右主支气管之间的夹角写成约 70°。本版立户的是气管中线与主支气管下缘的嵴下角，右侧男性平均 21.96°、女性平均 24.7°；左侧男性 36.4°、女性 39.3°。数字不要互换，左右不要对调。
:::

:::insight{label="气管隆嵴略偏左，和右主支气管较陡是同一幅图"}
隆嵴偏向左侧，等于把分叉的「脊」推向左，右侧管道更接近气管的延长线。支气管镜到隆嵴，先认这一条偏左的半月嵴，再进右或左主支气管。
:::

:::note{label="本节止于主支气管"}
图3-16 上能看见左、右肺叶支气管的起始，那是主支气管入肺门后的下一级。肺叶、肺段、肺泡、支气管树的 23～25 级分支，以及胸膜腔、纵隔，都不在本节展开。
:::

:::memory{label="本节必背要点"}
- [ ] 呼吸系统 = 呼吸道 + 肺。上呼吸道：鼻、咽、喉；下呼吸道：气管和各级支气管。分界在环状软骨下缘。
- [ ] 鼻分外鼻、鼻腔、鼻旁窦。鼻翼扇动见于呼吸困难。软骨部皮肤是痤疮、酒渣鼻、疖肿好发部位。
- [ ] 鼻腔以鼻阈为界：前为鼻前庭（皮肤、鼻毛、疖肿痛剧），后为固有鼻腔。向前鼻孔、向后鼻后孔通鼻咽。
- [ ] 鼻中隔 = 筛骨垂直板 + 犁骨 + 鼻中隔软骨。易出血区在前下部，约 90% 鼻出血，Little / Kiesselbach 区。
- [ ] 上、中、下三个鼻甲对应三道。蝶筛隐窝开蝶窦；半月裂孔 / 筛漏斗通额窦和前筛窦；鼻泪管开下鼻道前上。嗅区在上鼻甲及相对鼻中隔和顶部。
- [ ] 鼻旁窦四对：额窦、筛窦、蝶窦、上颌窦。前中筛窦和额窦、上颌窦开中鼻道；后筛窦开上鼻道；蝶窦开蝶筛隐窝。上颌窦口高，积液体位引流；底壁邻磨牙牙根。
- [ ] 咽是上呼吸道中段，形态见消化系统。三部分界：腭帆游离缘、会厌上缘。
- [ ] 喉：上界会厌上缘，下界环状软骨下缘，成人平 C3～C6。甲状软骨最大有喉结；环状软骨是唯一完整软骨环，弓平 C6，损伤致喉狭窄；会厌是喉口活瓣；杓状软骨有声带突和肌突。
- [ ] 方形膜下缘 = 前庭韧带；弹性圆锥上缘 = 声韧带。声带 = 声韧带 + 声带肌 + 喉黏膜。环甲正中韧带可穿刺通气，避开环甲动脉吻合弓。
- [ ] 环甲肌（唯一喉外群肌）紧张拉长声带；环杓后肌开大声门裂；环杓侧肌使声门裂变窄；甲杓肌（声带肌）松弛声带。
- [ ] 喉腔三部：喉前庭、喉中间腔（两侧为喉室）、声门下腔。声门裂是最窄处，前 2/3 膜间部、后 1/3 软骨间部。声门 = 声带 + 声门裂。声门下腔黏膜下疏松，婴幼儿易喉水肿。
