# 七、　生殖腺

生殖腺在第五章已经按器官写过外形和管道。本节只把它们当成内分泌组织来点名：睾丸间质细胞产雄激素；卵泡壁细胞和黄体产雌激素、孕激素。不要重写睾丸小叶、附睾管或子宫壁。胰岛是下一节的户头。

睾丸（testis）是男性生殖腺，产生精子和雄激素。雄激素由生精小管之间的**间质细胞**产生，经毛细血管进入血液循环至全身靶器官。它可刺激男性附属性腺的生长，在青春期激发男性第二性征——促进胡须生长、喉增大以及骨骼迅速增长——并维持正常的性功能；同时促使生精细胞发育成精子，并促进全身代谢活动。

卵巢（ovary）是女性生殖腺，可产生卵泡。卵泡壁的细胞主要产生雌激素和孕激素。卵泡排卵后转变成黄体，黄体可分泌孕激素和雌激素。雌激素可刺激子宫、阴道和乳腺的生长发育，出现并维持女性第二性征。孕激素的主要作用是促进子宫内膜在雌激素作用的基础上继续生长发育，为受精卵着床做准备，亦促进乳腺发育，为哺乳做准备。

:::definition{label="生殖腺（内分泌）"}
男性是睾丸，女性是卵巢。本章只写激素来源：睾丸**间质细胞**、卵巢**卵泡**和**黄体**。外形、管道和附属腺见第五章，不在这里重开户头。
:::

:::definition{label="睾丸间质细胞"}
位于生精小管之间。产生**雄激素**，经毛细血管入血。这是内分泌组织，不是另一条生精管道。
:::

:::definition{label="雄激素（本版作用）"}
刺激男性附属性腺生长；青春期激发男性第二性征（胡须生长、喉增大、骨骼迅速增长）；维持正常性功能；促使生精细胞发育成精子；促进全身代谢。
:::

:::definition{label="卵泡与黄体"}
卵泡壁细胞主要产生**雌激素和孕激素**。排卵后卵泡转变成黄体，黄体分泌**孕激素和雌激素**。两者都是卵巢里的内分泌组织。
:::

:::compare{title="三种内分泌组织各产什么"}
| 组织 | 所在 | 本版激素 |
|------|------|----------|
| 间质细胞 | 生精小管之间 | 雄激素 |
| 卵泡壁细胞 | 卵巢卵泡 | 主要是雌激素和孕激素 |
| 黄体 | 排卵后的卵泡转变而来 | 孕激素和雌激素 |

精子在生精上皮产生，雄激素在间质细胞产生——产精子和产激素不在同一个细胞团里。第五章已经写过这一刀，这里再钉一次。
:::

:::compare{title="雌激素与孕激素（本版）"}
| | 主要作用 |
|--|----------|
| 雌激素 | 刺激子宫、阴道和乳腺生长发育；出现并维持女性第二性征 |
| 孕激素 | 在雌激素作用基础上，促进子宫内膜继续生长发育，为着床做准备；亦促进乳腺发育，为哺乳做准备 |

孕激素不单独起头：内膜这一笔写明「在雌激素作用的基础上」。不要把两者写成可以互相替换的「女性激素」。
:::

:::concept{term="先问激素产在哪一团细胞，再问有没有把第五章形态整节搬过来"}
看见生殖腺，本章只问间质细胞、卵泡、黄体。把附睾管 4～6 m、输精管四部、子宫峡写进本节，就是吞了第五章。把胰岛听成生殖腺，又是跳过了下一节。
:::

:::pitfall{label="雄激素由间质细胞产生，不要写成由生精上皮产生"}
生精上皮产精子。间质细胞在小管之间，激素入血。写反之后，内分泌组织和生精管道会并成一个细胞团。
:::

:::pitfall{label="黄体是排卵后的卵泡转变而来，不要写成卵巢里另长的第三个腺"}
本版：卵泡排卵后转变成黄体。黄体不是与卵泡并列、从一开始就独立存在的腺体。
:::

:::pitfall{label="孕激素在雌激素基础上作用于内膜，不要写成孕激素单独启动内膜"}
本版原句：促进子宫内膜在雌激素作用的基础上继续生长发育。缺了「基础上」这一笔，周期里谁先谁后就乱了。
:::

:::insight{label="第五章看外形，本章看细胞团把激素送进血"}
间质细胞、卵泡、黄体在图6-1 的睾丸和卵巢座位上，本身没有单独的插图。认的是「组织在腺里」，不是再画一遍阴囊和子宫。
:::

:::keypoint{label="生殖腺（内分泌）三句话"}
- 睾丸间质细胞 → 雄激素：附属性腺、第二性征、性功能、生精、代谢。
- 卵泡壁细胞 → 雌激素和孕激素；排卵后黄体 → 孕激素和雌激素。
- 雌激素管子宫、阴道、乳腺和第二性征；孕激素在雌激素基础上准备着床，并准备哺乳。
:::

:::note{label="本节止于生殖腺的内分泌组织"}
睾丸、卵巢的外形、被膜和管道见第五章。胰岛是胰内的内分泌组织，下一节单独立户，不要在这里顺手写 α、β 细胞。
:::
