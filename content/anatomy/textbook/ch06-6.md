# 六、　胸腺

胸腺大部分位于上纵隔前部，胸骨柄后方。本节只写这一户：左、右叶不对称的扁条，新生儿和幼儿相对较大，性成熟后达高峰再萎缩；它是淋巴器官，兼分泌胸腺素和促胸腺生成素。生殖腺作为内分泌组织，形态归下一节点名，不要在这里重写第五章。

胸腺（thymus）位于胸骨柄的后方，大部分位于上纵隔的前部（图6-6），贴近心包上方和大血管前面，向上到达胸廓上口，向下至前纵隔。由左、右叶构成，呈不对称的扁条状，质软，两叶之间借结缔组织相连。新生儿和幼儿的胸腺相对较大，重 10～15 g。性成熟后发育至最高峰，重达 25～40 g，随后逐渐萎缩，多被结缔组织替代。胸腺也可伸至颈部，尤其是小儿；胸腺肿大时可压迫头臂静脉、主动脉弓和气管，出现发绀和呼吸困难。

胸腺属于淋巴器官，兼有内分泌功能，可分泌胸腺素和促胸腺生成素，参与机体的免疫反应。

:::definition{label="胸腺"}
位于**胸骨柄后方**，大部分在**上纵隔前部**，贴近心包上方和大血管前面；向上到胸廓上口，向下至**前纵隔**。左、右叶不对称扁条状，质软，两叶借结缔组织相连。
:::

:::compare{title="胸腺的位置（本版范围）"}
| 方向 | 本版 |
|------|------|
| 主体 | 胸骨柄后方；大部分在上纵隔前部 |
| 贴邻 | 心包上方、大血管前面 |
| 上界 | 胸廓上口；小儿尤其可伸至颈部 |
| 下界 | 前纵隔 |

上纵隔前部是主座位，前纵隔是向下的延伸。不要写成「整个胸腔」或「只在颈部」。
:::

:::compare{title="重量随年龄（本版）"}
| 阶段 | 重量 | 本版要点 |
|------|------|----------|
| 新生儿和幼儿 | **10～15 g** | 相对较大 |
| 性成熟后高峰 | **25～40 g** | 发育至最高峰 |
| 高峰之后 | 逐渐萎缩 | 多被结缔组织替代 |

幼儿 10～15 g 是相对大，不是终身最重。最重在性成熟后的 25～40 g，然后才萎缩。
:::

:::definition{label="胸腺的左、右叶"}
不对称的扁条状，质软，两叶之间借结缔组织相连。不要写成对称的 H 形或一对圆形小体——那是甲状腺和甲状旁腺的外形。
:::

:::definition{label="胸腺的内分泌功能"}
淋巴器官，兼内分泌。分泌**胸腺素**和**促胸腺生成素**，参与免疫反应。不要把它只写成「心包前方的一堆脂肪」。
:::

:::definition{label="胸腺肿大的压迫"}
可压迫**头臂静脉、主动脉弓和气管**，出现发绀和呼吸困难。尤其小儿，胸腺可伸至颈部。
:::

:::cause-effect{title="为什么小儿胸腺肿大可发绀、呼吸困难"}
- **因** 胸腺可贴心包上方和大血管前面，向上到胸廓上口，小儿更易伸至颈部；肿大时可压迫头臂静脉、主动脉弓和气管
- **果** 出现发绀和呼吸困难

压迫名单是头臂静脉、主动脉弓和气管，不是「随便哪根颈动脉」。
:::

:::pitfall{label="高峰在性成熟后 25～40 g，不要把幼儿 10～15 g 当成最重"}
本版：新生儿和幼儿相对较大（10～15 g）；性成熟后才到 25～40 g 的最高峰，随后萎缩。写成「出生时最大、以后只缩小」，高峰重量会对不上。
:::

:::pitfall{label="胸腺大部分在上纵隔前部，不要写成后纵隔或全在颈部"}
主座位是胸骨柄后方、上纵隔前部，向下到前纵隔。伸至颈部是「也可」，尤其小儿。写成后纵隔，和食管、胸主动脉那一户就并车了。
:::

::figure{src="/images/anatomy/textbook/p0200_02.png" caption="图6-6　胸腺" alt="上纵隔前面观：气管前方可见胸腺右叶和左叶，邻上腔静脉、主动脉弓、左肺动脉，下方为心包"}

图6-6 把不对称的两叶摆在心包上方、大血管前面：右侧邻上腔静脉，左侧邻主动脉弓和左肺动脉。看的就是「上纵隔前部」这四个字的座位，不是把两叶画成甲状腺。

:::insight{label="两叶扁条贴在心包上方，像垫在大血管前面的软垫"}
图6-6：气管在后，胸腺两叶在前，再往下是心包。小儿这张垫子相对更大，肿起来先挤头臂静脉、主动脉弓和气管。
:::

:::keypoint{label="胸腺三句话"}
- 胸骨柄后方，大部分上纵隔前部，下至前纵隔；可伸至颈部（尤其小儿）。
- 幼儿 10～15 g（相对大）；性成熟后高峰 25～40 g，随后萎缩。
- 淋巴器官兼内分泌：胸腺素、促胸腺生成素，参与免疫。肿大可压头臂静脉、主动脉弓和气管。
:::

:::note{label="本节止于胸腺"}
生殖腺在内分泌这一章只点间质细胞、卵泡和黄体，形态见第五章。不要把睾丸小叶和子宫的户头搬进来。
:::
