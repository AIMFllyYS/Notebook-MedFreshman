# 第四节　神经系统的传导通路

传导通路（conductive pathway）是中枢内把感受器的冲动送到皮质、再把皮质指令送到效应器的长纤维链。本节把这一户写完：感觉（上行）通路和运动（下行）通路。脊神经丛、脑神经周围段和内脏运动的节前节后是第三节的户头，不要再拆一遍；脊髓外形、脑干核团名单是第二节的户头，这里只取通路要用的核和束。

感受器把内、外环境刺激变成神经冲动，沿传入神经元送到中枢，最后到大脑皮质产生感觉。皮质把感觉信息分析整合后发出指令，沿传出纤维经脑干和脊髓的运动神经元到达躯体和内脏效应器。因此中枢里有两大类通路：感觉（上行）传导通路 sensory (ascending) conductive pathway，和运动（下行）传导通路 motor (descending) conductive pathway。总体上它们分别是反射弧的传入部和传出部，但**只有不经过大脑皮质的上、下行通路才称为反射通路**。

:::definition{label="传导通路"}
中枢内起止、行程和功能相对固定的长纤维链。本版两户：感觉上行把冲动送到皮质，运动下行把指令送到效应器。不要听成「周围神经的走行」。
:::

:::concept{term="先问上行还是下行，再问几级神经元、在哪交叉、皮质落在哪一块"}
看见传导通路，先切感觉还是运动。感觉再问深感觉还是浅感觉、特殊感觉还是内脏感觉；运动再问锥体系还是锥体外系。每条通路只记三件事：几级神经元、交叉部位、皮质终止（或效应器）。把「通路」听成「就是脊神经」，交叉这一刀会从开篇丢掉。
:::

:::compare{title="本节两户（本版顺序）"}
| 户 | 本版要点 | 不要写成 |
|----|----------|----------|
| 感觉（上行） | 本体觉（意识性 / 非意识性）；痛温粗触压；视觉及瞳孔对光反射；听觉；平衡觉；内脏感觉 | 把脊神经节段分布、皮节图画进来 |
| 运动（下行） | 锥体系（皮质脊髓束、皮质核束）；锥体外系环路 | 把交感干、副交感节前节后提前立户 |

感觉通路多数是 3 级，听觉是 4 级，非意识性本体觉是 2 级。运动通路在锥体系是上、下两级神经元。
:::

:::note{label="反射通路和皮质通路不要并成一条"}
不经过大脑皮质的上、下行纤维才叫反射通路，例如牵张反射、瞳孔对光反射。意识性感觉和随意运动必须过皮质。写成「所有上行纤维都产生感觉」，小脑和顶盖那一截会从户头里丢掉。
:::

:::compare{title="表9-8　主要传导通路（先记级数、交叉、终止）"}
| 通路 | 神经元级数 | 交叉部位 | 皮质（或效应）终止 |
|------|------------|----------|-------------------|
| 意识性本体觉 + 精细触觉 | **3** | 延髓**内侧丘系交叉** | 中央后回中、上部，中央旁小叶后部（部分到中央前回） |
| 非意识性本体觉 | **2** | 后束同侧；前束同侧+对侧 | **旧小脑皮质**（不进大脑皮质） |
| 躯干四肢痛温、粗触压 | **3** | 脊髓**白质前连合**（先升 1～2 节） | 中央后回中、上部，中央旁小叶后部 |
| 头面痛温、触压 | **3** | 脑干（组成三叉丘脑束时交叉） | 中央后回**下部** |
| 视觉 | **3** | **视交叉**（仅鼻侧半纤维） | 距状沟上下纹状区 |
| 听觉 | **4** | 脑桥**斜方体**（大部分交叉，有不交叉） | 颞横回听区 |
| 平衡觉 | 2（皮质投射可能再换元） | 多通路，内侧纵束走中线两侧 | 可能到颞上回前方；大量止于眼肌核、脊髓、小脑 |
| 皮质脊髓侧束 | 上 + 下 2 级 | 延髓**锥体交叉**（75%～90%） | 对侧前角 → 四肢肌 |
| 皮质脊髓前束 | 上 + 下 2 级 | 终止前经白质前连合（部分始终不交叉） | 躯干肌、上肢近端肌 |
| 皮质核束 | 上 + 下 2 级 | 大部分**双侧**；面神经核下部、舌下神经核只接对侧 | 脑神经运动核 |

交叉这一列是损伤定位的刀：交叉以上伤对侧，交叉以下伤同侧。听觉因为双侧传导，外侧丘系以上单侧损伤往往没有明显耳聋。
:::

## 一、感觉传导通路

感觉传导通路包括：本体感觉；痛温觉、粗略触觉和压觉；视觉及瞳孔对光反射；听觉；平衡觉；内脏感觉。头面部本体感觉传导通路目前尚不清楚，本版只写躯干和四肢。

:::definition{label="感觉传导通路"}
把感受器冲动送到大脑皮质（或小脑、脑干反射中枢）的上行链。产生意识性感觉的，终止于大脑皮质；反射性地调节肌张力和姿势的，可以止于小脑或脑干，不产生意识性感觉。
:::

### （一）本体感觉传导通路

本体感觉是肌、肌腱、关节等在运动或静止时产生的感觉，包括位置觉、运动觉和振动觉。感受器位置较深，故又称**深感觉**。闭眼时仍能感知肢体在哪里、怎么动，靠的就是这条通路。

本体感觉有两条：一条传到大脑皮质，产生意识性感觉，称意识性本体感觉传导通路，该通路还传导皮肤的**精细触觉**（两点辨别、纹理粗细）；另一条传到小脑，不产生意识性感觉，称非意识性本体感觉传导通路，反射地调节肌张力和协调肌运动，维持姿势和平衡。

:::definition{label="本体感觉"}
肌、肌腱、关节的位置觉、运动觉和振动觉，又称深感觉。本版两条：意识性走到皮质，非意识性走到小脑。不要把痛、温觉算进深感觉。
:::

:::compare{title="意识性 vs 非意识性本体感觉"}
| | 意识性 | 非意识性 |
|--|--------|----------|
| 终点 | 大脑皮质 | 旧小脑皮质 |
| 是否产生感觉 | 产生位置、运动、振动觉，并带精细触觉 | **不产生**意识性感觉 |
| 级数 | **3** 级 | **2** 级 |
| 功能 | 知道肢体在哪、两点距离、纹理 | 反射性调节肌张力、协调运动、维持平衡 |
| 损伤后 | 闭眼不能定位关节，精细触觉丧失 | 共济失调、肌张力调节障碍（不表现为「不知道脚在哪」） |

两条都从脊神经节出发，分叉在第 2 级：一个去薄、楔束核，一个去胸核和小脑。
:::

#### 1. 躯干和四肢意识性本体感觉和精细触觉传导通路

由 **3** 级神经元组成。

**第 1 级**　脊神经节内假单极神经元，胞体多为大、中型，纤维较粗、有髓鞘。周围突分布于肌、肌腱、关节的本体感受器和皮肤的精细触觉感受器；中枢突经脊神经后根**内侧部**进入脊髓后索，分为长的升支和短的降支。来自第 **5** 胸节及以下的升支走后索内侧，形成薄束（fasciculus gracilis）；来自第 **4** 胸节及以上的升支走后索外侧，形成楔束（fasciculus cuneatus）。两束上行，分别止于延髓的薄束核和楔束核。短的降支到后角或前角，完成脊髓牵张反射。

**第 2 级**　胞体在薄束核、楔束核。发出内弓状纤维，向前绕过延髓中央灰质腹侧，在中线上与对侧纤维交叉，称**内侧丘系交叉**。交叉后转折向上，在锥体束背侧呈前后方向排列，行于延髓中线两侧，称内侧丘系（medial lemniscus）。内侧丘系在脑桥呈横位，居被盖前缘；在中脑被盖居红核后外侧；最后止于背侧丘脑腹后外侧核（VPL）。

**第 3 级**　胞体在腹后外侧核。发出纤维参与组成丘脑中央辐射，经**内囊后肢**主要投射到中央后回的中、上部和中央旁小叶后部，部分纤维投射到中央前回（图9-153）。

:::definition{label="薄束与楔束"}
后索里的同侧升支。薄束靠**内**，收 T5 及以下（躯干下部和下肢）；楔束靠**外**，收 T4 及以上（躯干上部和上肢）。颈髓后索两者都有，腰骶髓后索几乎只见薄束。
:::

:::definition{label="内侧丘系"}
薄、楔束核发出的第 2 级纤维，在延髓中线交叉后上行，止于丘脑腹后外侧核。交叉以前叫内弓状纤维，交叉以后才叫内侧丘系。
:::

:::compare{title="表9-9　意识性本体感觉和精细触觉（三级）"}
| 级 | 胞体 | 纤维走行 | 终止 |
|----|------|----------|------|
| 1 | 脊神经节（大、中型假单极） | 后根内侧部 → 后索。T5↓ = 薄束（内）；T4↑ = 楔束（外） | 延髓薄束核、楔束核 |
| 2 | 薄束核、楔束核 | 内弓状纤维 → **内侧丘系交叉** → 内侧丘系（延髓中线两侧 → 脑桥被盖前缘 → 中脑红核后外侧） | 丘脑腹后外侧核 |
| 3 | 腹后外侧核 | 丘脑中央辐射，经内囊后肢 | 中央后回中、上部，中央旁小叶后部；部分到中央前回 |

交叉只在延髓做一次。交叉以上伤对侧，交叉以下伤同侧。
:::

::figure{src="/images/anatomy/textbook/p0405_01.png" caption="图9-153　躯干和四肢意识性本体感觉传导通路" alt="冠状切面串联：腰髓、胸髓、颈髓后索可见薄束靠内、楔束靠外；延髓薄束核与楔束核发出纤维在中线做内侧丘系交叉；内侧丘系经脑桥、中脑到丘脑腹后外侧核，再经内囊投射到中央后回；旁标豆状核、背侧丘脑"}

该通路不同部位损伤，症状不同。内侧丘系交叉**以上**损伤，症状在损伤**对侧**：闭眼不能确定对侧关节的位置和运动方向，也不能辨别两点距离。交叉**以下**损伤（后索、薄楔束核），症状在损伤**同侧**。相应部位皮肤的精细触觉也丧失。

:::pitfall{label="薄束靠内、楔束靠外，不要按「上肢应该靠内」去记"}
下肢、下躯干的纤维先进入后索，被挤在最内侧，所以薄束靠内；上肢后到，贴在外侧成楔束。写成「上肢走薄束、下肢走楔束」，后索的内外侧会整排反掉。胸髓分界按本版：**T5 及以下薄束，T4 及以上楔束**。
:::

:::pitfall{label="精细触觉不走脊髓丘脑束"}
两点辨别和纹理粗细跟本体觉走同一条后索—内侧丘系。脊髓丘脑前束走的是粗略触觉和压觉。后索伤可以「摸得着、分不清」，浅感觉通路伤是痛温先没。
:::

:::insight{label="图9-153 先认后索分家，再认延髓那一刀交叉"}
腰髓、T4、C8 的后索都把薄束画在中线旁。纤维一直爬到延髓才拐弯交叉，交叉以后才叫内侧丘系，贴着中线两侧上升，经内囊后肢散到中央后回。豆状核和背侧丘脑是路过的地标，不是第 2 级换元的地方。
:::

#### 2. 躯干和四肢非意识性本体感觉传导通路

实际上是反射通路的上行部分，传入到小脑，由 **2** 级神经元组成。

**第 1 级**　脊神经节内假单极神经元。周围突分布于肌、肌腱、关节的本体感受器；中枢突经后根内侧部入脊髓，止于 C8～L2 节段的胸核，以及腰骶膨大第 Ⅴ～Ⅶ 层外侧部。

**第 2 级**　胸核发出的纤维在**同侧**脊髓侧索组成脊髓小脑后束，向上经小脑下脚进入旧小脑皮质。腰骶膨大第 Ⅴ～Ⅶ 层外侧部发出的纤维组成对侧和同侧的脊髓小脑前束，经小脑上脚止于旧小脑皮质。以上传导躯干（除颈部外）和下肢的本体感觉。

传导上肢和颈部的第 2 级胞体在颈膨大第 Ⅵ、Ⅶ 层和延髓的楔束副核，纤维也经小脑下脚进入小脑皮质（图9-154）。

:::compare{title="非意识性本体感觉（二级，终点是小脑）"}
| 第 2 级胞体 | 组成的束 | 入小脑的脚 | 交叉 | 管哪一段 |
|-------------|----------|------------|------|----------|
| 胸核（C8～L2） | 脊髓小脑**后**束 | **小脑下脚** | **同侧** | 躯干（除颈）+ 下肢 |
| 腰骶膨大 Ⅴ～Ⅶ 层外侧部 | 脊髓小脑**前**束 | **小脑上脚** | 同侧 + 对侧 | 躯干（除颈）+ 下肢 |
| 颈膨大 Ⅵ、Ⅶ 层；楔束副核 | 经小脑下脚的纤维 | **小脑下脚** | 主要同侧 | 上肢 + 颈 |

终点都是旧小脑皮质，不是中央后回。后束不交叉，前束双侧走。
:::

::figure{src="/images/anatomy/textbook/p0406_02.png" caption="图9-154　躯干和四肢非意识性本体感觉传导通路" alt="矢状位：脊神经节纤维入脊髓；绿色脊髓小脑后束经小脑下脚到小脑皮质；黑色脊髓小脑前束经小脑上脚入小脑；旁标齿状核、小脑中脚、大脑脚、脑桥和延髓"}

:::pitfall{label="非意识性本体觉不到中央后回"}
这条通路的终点是旧小脑皮质，用来调肌张力和共济，患者不会说「我感觉不到关节在哪」。写成「也是 3 级、也到腹后外侧核」，和意识性通路就并成一条了。
:::

:::insight{label="图9-154 后束走下脚、前束走上脚"}
绿色后束贴脊髓侧索后部，经小脑下脚进小脑；黑色前束走得更靠前，经小脑上脚进小脑。齿状核在图里是小脑内部的地标，不是第 1 级换元处。第 1 级仍在脊神经节。
:::

### （二）痛温觉、粗略触觉和压觉传导通路

又称浅感觉传导通路，由 **3** 级神经元组成（图9-155）。分躯干四肢和头面部两支。

:::definition{label="浅感觉传导通路"}
痛觉、温度觉、粗略触觉和压觉的上行链。躯干四肢走脊髓丘脑束，头面走三叉丘脑束。不要把精细触觉算进来。
:::

#### 1. 躯干和四肢痛温觉、粗略触觉和压觉传导通路

**第 1 级**　脊神经节内假单极神经元，胞体中、小型，突起较细，为薄髓或无髓纤维。周围突分布于躯干和四肢皮肤内的感受器；中枢突经后根入脊髓。传导痛温觉的细纤维走后根**外侧部**，经背外侧束再终止于第 2 级神经元；传导粗略触觉和压觉的粗纤维走后根**内侧部**，入后索后再终止于第 2 级神经元。

**第 2 级**　胞体主要在脊髓第 Ⅰ、Ⅳ 到 Ⅷ 层。发出纤维上升 **1～2** 个节段，经**白质前连合**交叉到对侧的外侧索和前索内上行，组成脊髓丘脑侧束和脊髓丘脑前束（侧束传导痛温觉，前束传导粗略触觉和压觉），合称脊髓丘脑束。脊髓丘脑束上行，经延髓下橄榄核的背外侧、脑桥和中脑内侧丘系的外侧，止于丘脑腹后外侧核。

**第 3 级**　胞体在腹后外侧核。发出纤维参与组成丘脑中央辐射，经内囊后肢投射到中央后回中、上部和中央旁小叶后部。

脊髓内纤维排列有顺序：由外侧向内侧、由浅入深，依次是骶、腰、胸、颈。因此一侧脊髓丘脑束被**脊髓内肿瘤**压迫时，痛、温觉障碍首先出现在身体对侧**上半部**（先压到靠内侧的颈、胸纤维），再逐渐波及下半部。若是**脊髓外肿瘤**从外侧压进来，感觉障碍的发生顺序相反——先下半身、后上半身。

#### 2. 头面部的痛温觉和触压觉传导通路

**第 1 级**　三叉神经节内假单极神经元（外耳道和耳甲的皮肤感觉除外）。周围突经三叉神经分支分布于头面部皮肤及口鼻黏膜；中枢突经三叉神经根入脑桥。传导痛温觉的纤维入脑后下降为三叉神经脊束，止于三叉神经脊束核；传导触压觉的纤维止于三叉神经脑桥核。

**第 2 级**　胞体在三叉神经脊束核和三叉神经脑桥核。发出纤维交叉到对侧，组成三叉丘脑束（三叉丘系），止于丘脑腹后内侧核（VPM）。

**第 3 级**　胞体在腹后内侧核。发出纤维参与组成丘脑中央辐射，经内囊后肢投射到中央后回**下部**。

三叉丘脑束**以上**受损，对侧头面部痛、温觉和触压觉障碍；三叉丘脑束**以下**受损，同侧头面部障碍。

:::compare{title="表9-10　浅感觉传导通路（三级）"}
| | 躯干四肢 | 头面部 |
|--|----------|--------|
| 第 1 级 | 脊神经节（中、小型） | 三叉神经节 |
| 入中枢 | 后根。痛温走外侧部经背外侧束；粗触压走内侧部入后索 | 三叉神经根入脑桥。痛温下降成脊束；触压到脑桥核 |
| 第 2 级 | 脊髓 Ⅰ、Ⅳ～Ⅷ 层 | 三叉神经脊束核 + 三叉神经脑桥核 |
| 交叉 | 先升 1～2 节，经**白质前连合** | 在脑干交叉，组成三叉丘脑束 |
| 第 2 级纤维 | 脊髓丘脑侧束（痛温）+ 前束（粗触压） | 三叉丘脑束（三叉丘系） |
| 第 3 级 | 腹后**外**侧核 | 腹后**内**侧核 |
| 皮质 | 中央后回中、上部，中央旁小叶后部 | 中央后回**下部** |

两支都是 3 级、都经内囊后肢。差别在第 1、2 级的核，以及丘脑的内外侧核。
:::

::figure{src="/images/anatomy/textbook/p0407_01.png" caption="图9-155　痛温觉、粗略触觉和压觉传导通路" alt="A 左列：脊神经后根入脊髓，纤维经白质前连合交叉，脊髓丘脑侧束与前束上行，经延髓、脑桥、中脑到腹后核，再经内囊到中央后回。B 右列：三叉神经节入脑桥，触压觉进三叉神经脑桥核，痛温觉沿三叉神经脊束下降到脊束核，交叉后成三叉丘系到腹后核，投射中央后回"}

:::pitfall{label="浅感觉在脊髓交叉，深感觉在延髓交叉"}
痛温觉进入脊髓后只再升 1～2 节就经白质前连合交叉，所以脊髓半横断会出现对侧痛温觉丧失、同侧深感觉丧失（布朗-塞卡）。写成「浅、深感觉都在延髓交叉」，分离性感觉障碍这一户就对不上第二节。
:::

:::pitfall{label="VPL 收躯干四肢，VPM 收头面，不要记反"}
腹后外侧核（VPL）接内侧丘系和脊髓丘脑束；腹后内侧核（VPM）接三叉丘系。写成「头面也进 VPL」，中央后回下部的投射会从丘脑这一级接错线。
:::

:::insight{label="图9-155 左图在脊髓交叉，右图在脑干交叉"}
A 的蓝、绿纤维都在脊髓白质前连合翻到对侧，侧束靠外、前束靠前。B 的触压觉（蓝）在脑桥核换元，痛温觉（绿）先下降成脊束再换元，两支交叉后合成三叉丘系。左图止于腹后核偏外，右图偏内，最后都散到中央后回。
:::

:::keypoint{label="脊髓丘脑束的内外侧顺序"}
- 由外向内：骶 → 腰 → 胸 → 颈。
- 髓内肿瘤先压内侧（颈胸），对侧上半身痛温先没。
- 髓外肿瘤先压外侧（骶腰），对侧下半身痛温先没。
- 和后索「薄内楔外」不是同一套排法，不要并记。
:::

### （三）视觉传导通路和瞳孔对光反射通路

#### 1. 视觉传导通路

视觉传导通路（visual conductive pathway）由 **3** 级神经元组成。视网膜神经部外层的视锥细胞和视杆细胞是视觉感受器，不算进三级神经元。中层的双极细胞是第 1 级，内层的节细胞是第 2 级。节细胞轴突在视神经盘汇成视神经，经视神经管入颅，形成视交叉后延为视束。

视交叉中，来自两眼视网膜**鼻侧半**的纤维交叉，加入对侧视束；来自视网膜**颞侧半**的纤维不交叉，进入同侧视束。因此左侧视束含两眼视网膜左侧半的纤维，右侧视束含两眼视网膜右侧半的纤维。视束绕过大脑脚向后，主要止于外侧膝状体。

**第 3 级**　胞体在外侧膝状体。外侧膝状体核发出纤维组成视辐射（optic radiation），经内囊后肢投射到端脑距状沟上下的视区皮质（纹状区 striate area），产生视觉（图9-156）。

视束中尚有少数纤维经上丘臂止于上丘和顶盖前区。上丘发出顶盖脊髓束下行至脊髓，完成视觉反射。顶盖前区发出纤维到中脑动眼神经副核，构成瞳孔对光反射通路的一部分。

:::definition{label="视野"}
眼球固定向前平视时所能看到的空间范围。由于眼球屈光装置的折射，鼻侧半视野的物像落到颞侧半视网膜，颞侧半视野落到鼻侧半视网膜；上半视野落到下半视网膜，下半视野落到上半视网膜。
:::

:::compare{title="表9-11　视觉传导通路（三级）"}
| 级 | 胞体 | 纤维 | 交叉 | 终止 |
|----|------|------|------|------|
| 感受器 | 视锥、视杆（不计入三级） | — | — | 双极细胞 |
| 1 | 视网膜双极细胞 | 在视网膜内 | 不交叉 | 节细胞 |
| 2 | 视网膜节细胞 | 视神经 → 视交叉 → 视束 | **仅鼻侧半纤维**在视交叉交叉 | 外侧膝状体（主）；少数到上丘、顶盖前区 |
| 3 | 外侧膝状体 | 视辐射，经内囊后肢 | 不再交叉 | 距状沟上下纹状区 |

左侧视束 = 两眼视网膜左半 = 两眼右半视野。右侧视束相反。
:::

当视觉传导通路不同部位受损时，视野缺损不同：

:::compare{title="视野缺损与损伤部位（对图9-156 的 A～D）"}
| 损伤 | 视野 | 本版机制 |
|------|------|----------|
| 视网膜 | 与损伤位置对应的暗点。视神经盘处较大暗点；黄斑处中央暗点 | 感受器或节细胞局部缺失 |
| 一侧视神经 | 该侧眼**全盲** | 该眼交叉与不交叉纤维全断 |
| 视交叉中部交叉纤维 | 双眼视野**颞侧半偏盲**（颞侧偏盲、异向性） | 两眼鼻侧视网膜纤维在此交叉 |
| 一侧视交叉外侧不交叉纤维 | **患侧眼**视野鼻侧半偏盲 | 该眼颞侧视网膜纤维未交叉，贴交叉外侧走 |
| 一侧视束、视辐射或视区皮质 | 双眼病灶**对侧半**视野同向性偏盲 | 如右侧受损：右眼鼻侧半 + 左眼颞侧半 |

屈光装置把视野左右、上下都倒了一回，记缺损时先回到「哪一半视网膜」，再问纤维交叉了没有。
:::

#### 2. 瞳孔对光反射通路

光照一侧瞳孔，引起双眼瞳孔缩小，称瞳孔对光反射（pupillary light reflex）。光照侧的反应称直接对光反射，未照射侧称间接对光反射。通路：视网膜 → 视神经 → 视交叉 → 视束 → 上丘臂 → 顶盖前区 → **两侧**动眼神经副核 → 动眼神经 → 睫状神经节 → 节后纤维 → 瞳孔括约肌收缩 → 两侧瞳孔缩小（图9-156）。

对光反射消失可能预示病危，但视神经或动眼神经受损也能改变反射，必须分开传入和传出。

:::definition{label="瞳孔对光反射"}
光照一侧，**双眼**瞳孔缩小。直接 = 光照侧，间接 = 对侧。中枢在顶盖前区，传出走两侧动眼神经副核，所以正常时两侧会一起缩。
:::

:::compare{title="一侧视神经伤 vs 一侧动眼神经伤"}
| | 一侧视神经（传入断） | 一侧动眼神经（传出断） |
|--|----------------------|------------------------|
| 光照患侧 | 两侧瞳孔**都不缩** | 患侧不缩，健侧可缩（间接仍在） |
| 光照健侧 | 两侧都缩（患侧间接存在） | 健侧缩，患侧仍不缩 |
| 患侧直接 | 消失 | 消失 |
| 患侧间接 | **存在** | **消失** |
| 健侧直接、间接 | 都在 | 都在 |

传入断的是「看不见光」；传出断的是「缩不了瞳」。两侧动眼神经副核都收顶盖前区的纤维，所以传入只要有一侧完好，两眼都能缩。
:::

::figure{src="/images/anatomy/textbook/p0409_01.png" caption="图9-156　视觉传导通路和瞳孔对光反射通路" alt="俯视：两眼视网膜鼻侧纤维在视交叉交叉、颞侧不交叉，视束到外侧膝状体，视辐射散向枕叶距状沟上下的视皮质；部分纤维到顶盖前区和动眼神经副核。右上 A～D 示一侧视神经、视交叉交叉纤维、视交叉外侧不交叉纤维、一侧视束损伤的视野缺损。左下为距状沟剖面"}

:::pitfall{label="鼻侧视网膜纤维才交叉，不要写成「视野鼻侧纤维交叉」"}
交叉的是视网膜鼻侧半的轴突。鼻侧半视野的物像其实落在颞侧视网膜，走的是不交叉纤维。写成「鼻侧视野的纤维在视交叉交叉」，双颞侧偏盲和同向性偏盲会对调。
:::

:::pitfall{label="对光反射不走视辐射、不到视皮质"}
缩瞳这条路在视束分出后走上丘臂、顶盖前区，不经外侧膝状体，也不经纹状区。枕叶损伤可以偏盲，对光反射仍在。写成「看不见就一定缩不了瞳」，传入和视皮质被并成一户。
:::

:::insight{label="图9-156 先认视交叉那一处半交叉，再对 A～D"}
鼻侧半（对侧视野）的纤维在交叉处对穿，颞侧半留在同侧。A 在视神经，一眼全黑；B 在交叉中部，两眼颞侧黑；C 在交叉外侧，患侧鼻侧黑；D 在视束以后，双眼对侧半同向黑。顶盖前区和动眼神经副核画在交叉后方，是缩瞳的中继，不是视辐射。
:::

:::cause-effect{title="为什么光照一眼两侧都缩"}
- **因** 视束分出的光反射纤维到顶盖前区后，顶盖前区发出纤维到**两侧**动眼神经副核。
- **果** 只要传入侧视神经完好，两侧瞳孔括约肌都会收到传出指令。
- **所以** 间接对光反射存在，说明对侧传入和本侧传出至少有一条路是通的；两侧都不缩，要先问光照的是哪一只眼。
:::

### （四）听觉传导通路

听觉传导通路（auditory conductive pathway）是本版少数的 **4** 级通路。

**第 1 级**　蜗神经节内的双极细胞。周围突分布于内耳螺旋器（Corti 器）；中枢突组成蜗神经，与前庭神经伴行，在延髓和脑桥交界处入脑，止于蜗腹侧核和蜗背侧核。

**第 2 级**　胞体在蜗腹侧核、蜗背侧核。发出纤维大部分在脑桥内形成斜方体并交叉至对侧，到上橄榄核外侧折向上行，形成外侧丘系。外侧丘系经中脑被盖背外侧部，大多数止于下丘核。少数蜗神经核纤维不交叉，进入同侧外侧丘系；也有在上橄榄核换元后再加入同侧外侧丘系；还有少数外侧丘系纤维直接止于内侧膝状体。

**第 3 级**　胞体在下丘核。纤维经下丘臂止于内侧膝状体。

**第 4 级**　胞体在内侧膝状体。发出听辐射（acoustic radiation），经内囊后肢，止于大脑皮质颞横回的听区（图9-157）。

因此听觉冲动是**双侧传导**的。一侧通路在外侧丘系以上受损，不会产生明显耳聋；损伤蜗神经、内耳或中耳，才会有明显听觉障碍。

听觉的反射中枢在下丘。下丘神经元发纤维到上丘，再经顶盖脊髓束到脊髓前角，完成听觉反射。大脑皮质听区还可发出下行纤维，经通路上各级神经元中继，影响螺旋器的感受功能，形成负反馈调节。

:::compare{title="听觉传导通路（四级）"}
| 级 | 胞体 | 纤维 | 交叉 | 终止 |
|----|------|------|------|------|
| 1 | 蜗神经节（双极） | 蜗神经，脑桥延髓交界入脑 | 不交叉 | 蜗腹侧核、蜗背侧核 |
| 2 | 蜗腹侧核、蜗背侧核 | 大部分形成**斜方体**交叉，再折成外侧丘系；有不交叉成分 | 脑桥斜方体（不完全） | 下丘核（主）；少数直达内侧膝状体 |
| 3 | 下丘核 | 下丘臂 | 不再作为主交叉 | 内侧膝状体 |
| 4 | 内侧膝状体 | 听辐射，经内囊后肢 | — | 颞横回听区 |

视觉过外侧膝状体，听觉过内侧膝状体。外视内听，不要记反。
:::

::figure{src="/images/anatomy/textbook/p0410_01.png" caption="图9-157　听觉传导通路" alt="内耳螺旋器经蜗神经节、蜗神经入脑桥；蜗背侧核与蜗腹侧核发出纤维经斜方体、上橄榄核折成外侧丘系，到下丘核，再经内侧膝状体、听辐射抵达颞横回听区；两侧均有上行纤维"}

:::pitfall{label="听觉是双侧传导，不要把「一侧外侧丘系损伤」写成全聋"}
斜方体大部分交叉，但仍有不交叉纤维，上橄榄核也向两侧送。外侧丘系以上单侧损伤，临床症状往往不明显。真正一侧耳聋，先查蜗神经、内耳和中耳，不要先怪颞横回。
:::

:::insight{label="图9-157 先认斜方体那一层横行交叉，再认下丘和内膝状体"}
蜗神经节在螺旋器下方。入脑后在脑桥被盖腹侧横行交叉的是斜方体，折向上才叫外侧丘系。下丘核是中脑背侧的停靠点，内侧膝状体才是进内囊、上天的第 4 级。颞横回在外侧裂深处，不是颞叶外侧面随便一块。
:::

### （五）平衡觉传导通路

平衡觉传导通路（equilibrium conductive pathway）的第 1 级是前庭神经节内的双极神经元。周围突分布于半规管的壶腹嵴及前庭内的球囊斑、椭圆囊斑；中枢突组成前庭神经，与蜗神经一起在延髓脑桥交界处入脑，止于前庭神经核群（图9-158）。

第 2 级是前庭神经核群。由此发出到大脑皮质的路径尚不完全清楚，可能在背侧丘脑腹后核换元，再投射到颞上回前方的大脑皮质。

前庭神经核群发出的纤维更多是反射通路，而不是「产生位置感觉」：

- 至中线两侧组成内侧纵束。上升支止于动眼、滑车和展神经核，完成眼肌前庭反射（如眼球震颤）；下降支至副神经脊髓核和上段颈髓前角，完成转眼、转头的协调运动。
- 前庭神经外侧核发出前庭脊髓束，完成躯干、四肢的姿势反射（伸肌兴奋、屈肌抑制）。
- 前庭神经核群发出的纤维，与部分直接来自前庭神经的纤维一起，经小脑下脚入小脑，参与平衡调节。
- 还与脑干网状结构、迷走神经背核及疑核联系。平衡觉通路或前庭器受刺激时，可引起眩晕、恶心、呕吐。

:::compare{title="平衡觉：皮质投射少，反射侧支多"}
| 从何处 | 到何处 | 完成的事 |
|--------|--------|----------|
| 前庭神经节（1 级） | 前庭神经核群 | 传入 |
| 前庭核 → 内侧纵束上升 | Ⅲ、Ⅳ、Ⅵ 核 | 眼肌前庭反射、眼球震颤 |
| 前庭核 → 内侧纵束下降 | 副神经脊髓核、上颈髓前角 | 转眼与转头协调 |
| 前庭外侧核 | 前庭脊髓束 → 脊髓前角 | 伸肌兴奋、屈肌抑制，姿势反射 |
| 前庭核 + 部分初级纤维 | 小脑下脚 → 小脑 | 平衡调节 |
| 前庭核 | 网状结构、迷走神经背核、疑核 | 眩晕、恶心、呕吐 |
| 前庭核（可能经腹后核） | 颞上回前方皮质 | 意识性平衡感觉（路径尚不完全清楚） |

本户的重点在反射侧支，不在「第 3 级一定到哪一回」。
:::

::figure{src="/images/anatomy/textbook/p0410_02.png" caption="图9-158　平衡觉传导通路" alt="内耳经前庭神经节入脑干前庭神经上核、内侧核、外侧核、下核；内侧纵束连动眼、滑车、展神经核；前庭脊髓束到脊髓前角；并与小脑齿状核、球状核及疑核、副神经核相连；少量纤维经腹后核向大脑皮质"}

:::pitfall{label="平衡觉不是「第 3 级到中央后回」的翻版"}
前庭通路大量止于眼肌核、脊髓和小脑，皮质投射路径本版写的是「尚不清楚」。写成和痛温觉一样的 3 级到中央后回，眼球震颤和呕吐这两支侧支会被抹掉。
:::

:::insight{label="图9-158 先认四个前庭核，再认内侧纵束这条中轴线"}
前庭神经上、内、外、下核铺在脑桥延髓交界。紫色内侧纵束贴中线走，上连Ⅲ、Ⅳ、Ⅵ，下连副神经核和颈髓前角——转眼转头靠这一条。绿色初级纤维从内耳进来，红色前庭脊髓束出外侧核往脊髓。小脑的齿状核、球状核是平衡调节的落点，不是听觉的下丘。
:::

### （六）内脏感觉传导通路

内脏感觉分一般和特殊两户。一般内脏感觉指嗅觉和味觉以外的心、血管、腺体和内脏的感觉，传入路径复杂，至今尚不完全清楚。特殊内脏感觉指嗅觉和味觉。内脏运动（交感、副交感的节前节后）是第三节的户头，本节只写传入怎么进中枢、皮质落在哪。

:::definition{label="一般内脏感觉"}
嗅、味以外的心、血管、腺体和内脏感觉。第 1 级在脑神经感觉节或脊神经节；中枢突随脑神经入孤束核，或随后根入脊髓后角。再经网状结构到下丘脑、丘脑，投射到岛叶和边缘叶。路径不完全清楚，不要写成和皮肤痛温完全同一条脊髓丘脑束。
:::

:::compare{title="表9-12　一般内脏感觉传导通路"}
| 级 | 常见胞体 | 周围突 | 中枢突 / 上行 | 终止 |
|----|----------|--------|---------------|------|
| 1 | 脊神经节；膝神经节、岩神经节、下神经节等 | 随交感或副交感纤维到内脏、心血管、腺体 | 后根入脊髓后角；或随Ⅸ、Ⅹ入孤束核 | 后角或孤束核 |
| 2 | 脊髓后角；孤束核 | — | 经网状结构、孤束核上行；部分加入脊髓丘脑束 | 下丘脑、丘脑（背内侧核等） |
| 3（部分） | 丘脑 | — | 丘脑皮质纤维 | 岛叶、边缘叶、下丘脑 |

内脏痛常随交感神经进入与该脏器胚胎来源相近的脊髓节段，与躯体传入在后角会聚，这是牵涉痛的形态底板。详细节段对照见第三节内脏神经，本节不把器官名单再抄一遍。
:::

:::compare{title="表9-13　嗅觉和味觉传导通路"}
| | 嗅觉 | 味觉 |
|--|------|------|
| 感受器 | 嗅黏膜嗅细胞（本身是第 1 级双极神经元） | 味蕾 |
| 第 1 级 | 嗅细胞 | 膝神经节（Ⅶ，舌前 2/3）、岩神经节（Ⅸ，舌后 1/3）、下神经节（Ⅹ，会厌） |
| 第 2 级 | 嗅球（僧帽细胞、丛状细胞） | 孤束核 |
| 交叉 | 部分纤维经前连合到对侧 | 孤束核发出后不完全交叉 |
| 是否经丘脑 | **不经丘脑**，嗅束经外侧嗅纹到皮质 | 经丘脑腹后内侧核 |
| 皮质终止 | 梨状前区、杏仁周区、内嗅区（初级嗅皮质） | 岛叶、中央后回下部 |

嗅觉是本版几乎唯一「不经丘脑直达皮质」的感觉。味觉的第 1 级分散在三对脑神经的感觉节，第 2 级都汇到孤束核。
:::

:::pitfall{label="嗅觉不经丘脑，不要给它配一条内侧丘系"}
嗅细胞 → 嗅丝穿筛孔 → 嗅球换元 → 嗅束 → 初级嗅皮质。写成「也在丘脑腹后核换第 3 级」，嗅觉就和躯体感觉并户了。味觉可以经 VPM，嗅觉不行。
:::

:::note{label="内脏运动不在本节展开"}
心肌、平滑肌、腺体的传出是第三节内脏神经的交感和副交感。本节内脏感觉只负责「感觉怎么上来」。不要把节前纤维、交感干神经节从第三节搬回来。
:::

## 二、运动传导通路

运动传导通路是从大脑皮质到躯体运动和内脏活动效应器的神经联系。到骨骼肌的称躯体运动传导通路，包括锥体系和锥体外系。到心肌、平滑肌、腺体的称内脏运动传导通路，详见第三节「内脏神经」。

:::definition{label="运动传导通路"}
皮质到效应器的下行链。本版只写到骨骼肌的两户：**锥体系**发起随意运动，**锥体外系**调节肌张力、协调姿势和习惯性动作。内脏传出不在本节立户。
:::

:::compare{title="锥体系 vs 锥体外系"}
| | 锥体系 | 锥体外系 |
|--|--------|----------|
| 组成 | 上运动神经元（皮质锥体细胞）+ 下运动神经元（脑神经运动核、脊髓前角） | 皮质、纹状体、丘脑、底丘脑、红核、黑质、脑桥核、前庭核、小脑、网状结构及其纤维 |
| 下行束 | 皮质脊髓束、皮质核束 | 红核脊髓束、网状脊髓束等 |
| 交叉 | 锥体交叉为主；皮质核束大部分双侧 | 环路中多次交叉 |
| 功能 | 发起精确随意运动（写字、刺绣） | 调节肌张力、协调肌肉、维持姿势和习惯性动作（走路摆臂） |
| 种系 | 哺乳类尤其人类高度发达 | 较古老；鱼类已出现，鸟类曾是主控 |

两户互相依赖：没有锥体外系把肌张力稳住，锥体系完不成精细动作；习惯性动作往往由锥体系发起，再交给锥体外系管理（骑车、游泳）。
:::

### （一）锥体系

锥体系（pyramidal system）由上运动神经元和下运动神经元两级组成。上运动神经元（upper motor neuron）是位于大脑皮质的传出神经元。下运动神经元（lower motor neuron）是脑干内一般躯体和特殊内脏运动核，以及脊髓前角的运动神经元，它们的胞体和轴突构成传导运动冲动的**最后公路**。

上运动神经元包括：中央前回和中央旁小叶前部的巨型锥体细胞（Betz 细胞）和其他锥体细胞，以及额、顶叶部分区域的锥体细胞。它们的轴突共同组成锥体束（pyramidal tract）。下行到脊髓的称皮质脊髓束；止于脑干内一般躯体和特殊内脏运动核的称皮质核束（图9-159、图9-160）。

:::definition{label="上运动神经元"}
大脑皮质的传出神经元（锥体细胞）及其轴突组成的锥体束。损伤在脑神经运动核和脊髓前角**以上**。不是「位置靠头侧的神经元」这么含糊一句。
:::

:::definition{label="下运动神经元"}
脑干脑神经运动核和脊髓前角运动神经元，以及它们的轴突（脑神经、脊神经）。胞体加轴突是最后公路：骨骼肌只听这一级的直接支配。
:::

:::compare{title="表9-14　锥体系两束"}
| | 皮质脊髓束 | 皮质核束 |
|--|------------|----------|
| 主要起点 | 中央前回上、中部，中央旁小叶前部 | 中央前回下部 |
| 内囊 | **后肢前部** | **膝** |
| 大脑脚底 | 中 3/5 的**外侧部** | 中 3/5 的**内侧部** |
| 再向下 | 脑桥基底部 → 延髓锥体 | 陆续分出，止于脑神经运动核 |
| 交叉 | 锥体下端 **75%～90%** 交叉（侧束）；前束多在终止前经白质前连合交叉 | 大部分**双侧**终止；面神经核下部、舌下神经核只接对侧 |
| 下运动神经元 | 脊髓前角 | Ⅲ、Ⅳ、Ⅵ、三叉运动核、面神经核、疑核、副神经脊髓核、舌下神经核 |
| 效应 | 四肢肌（侧束）；躯干肌和上肢近端肌（前束） | 头面部骨骼肌、眼外肌、舌肌等 |

两束在内囊就分家：膝走头面，后肢走躯干四肢。
:::

#### 1. 皮质脊髓束

皮质脊髓束（corticospinal tract）由中央前回上、中部和中央旁小叶前部等处皮质的锥体细胞轴突集中而成，下行经内囊后肢前部、大脑脚底中 3/5 的外侧部和脑桥基底部，至延髓锥体。

在锥体下端，**75%～90%** 的纤维交叉到对侧，形成锥体交叉。交叉后的纤维在对侧脊髓侧索内下行，称皮质脊髓侧束，沿途发出侧支，逐节终止于前角细胞（可达骶节），主要支配**四肢肌**。

延髓锥体中小部分未交叉的纤维在同侧脊髓前索内下行，称皮质脊髓前束。该束终止于颈髓和上胸髓，终止前经白质前连合逐节交叉到对侧，止于前角运动神经元，支配躯干肌和上肢近端肌。前束中有一部分纤维始终不交叉，止于同侧前角，主要支配躯干肌。

所以：**躯干肌受两侧大脑皮质支配，上、下肢肌只受对侧大脑皮质支配**。一侧皮质脊髓束在锥体交叉前受损，主要引起对侧肢体瘫痪，躯干肌运动不受明显影响；在锥体交叉后受损，主要引起同侧肢体瘫痪。

实际上只有 **10%～20%** 的纤维直接终止于前角运动神经元，主要支配肢体远端肌；大部分需经中间神经元与前角联系。

::figure{src="/images/anatomy/textbook/p0412_02.png" caption="图9-159　锥体系中的皮质脊髓束" alt="中央前回纤维经内囊下行，过中脑、脑桥至延髓锥体；大部分在锥体交叉到对侧成皮质脊髓侧束，止于前角运动神经元；小部分在同侧前索成皮质脊髓前束，终止前经白质前连合到对侧前角"}

:::pitfall{label="锥体交叉前伤对侧肢体，交叉后伤同侧肢体"}
交叉这一刀在延髓下端。内囊、大脑脚、脑桥的皮质脊髓束还没交叉，伤的是对侧上下肢；脊髓侧索里的皮质脊髓侧束已经交叉，伤的是同侧。躯干肌因为有不交叉和双侧支配，单侧束伤往往看不出明显瘫痪。
:::

:::insight{label="图9-159 先认锥体交叉这一刀，再分侧束和前束"}
红纤维从中央前回进内囊，贴中脑、脑桥腹侧下行，到延髓下端大部分横穿中线，变成对侧侧索里的皮质脊髓侧束。前束继续在同侧前索走，终止前才经白质前连合翻过去。前角运动神经元是最后公路，图画在脊髓前角，不要看成丘脑。
:::

#### 2. 皮质核束

皮质核束（corticonuclear tract）主要由中央前回下部锥体细胞的轴突集合而成，下行经内囊膝至大脑脚底中 3/5 的内侧部，由此向下陆续分出纤维。大部分终止于**双侧**脑神经运动核：动眼神经核、滑车神经核、展神经核、三叉神经运动核、面神经核支配面上部肌的神经元、疑核和副神经脊髓核。小部分纤维交叉到对侧，终止于面神经核支配面下部肌的神经元和舌下神经核，二者发出的纤维分别支配同侧面下部的面肌和舌肌。

因此：除面神经核下部和舌下神经核只接受单侧（对侧）皮质核束支配外，其他脑神经运动核均接受双侧皮质核束的纤维（图9-160）。

::figure{src="/images/anatomy/textbook/p0412_03.png" caption="图9-160　锥体系中的皮质核束" alt="中央前回下部的皮质核束下行，陆续分到动眼、滑车、三叉运动、展、面（上半双侧、下半主要对侧）、疑核、舌下（主要对侧）和副神经核；双侧终止画成两侧都有终末，对侧终止只画交叉后一支"}

一侧上运动神经元受损，导致对侧眼裂以下的面肌和对侧舌肌瘫痪：病灶对侧鼻唇沟消失，口角低垂并歪向病灶侧，流涎，不能鼓腮、露齿；伸舌时舌尖偏向病灶对侧。这是核上瘫（supranuclear paralysis）。

一侧面神经核的神经元受损，病灶侧所有面肌瘫痪：额横纹消失，眼不能闭，口角下垂并歪向健侧，鼻唇沟消失。一侧舌下神经核受损，病灶侧全部舌肌瘫痪，伸舌时舌尖偏向病灶侧。两者都是下运动神经元损伤，统称核下瘫（infranuclear paralysis）（图9-161、图9-162）。

:::definition{label="核上瘫"}
上运动神经元（皮质核束）损伤。面：只瘫对侧眼裂**以下**，额纹和闭眼能保留（面上部核收双侧）。舌：对侧舌肌瘫，伸舌偏**病灶对侧**，早期无明显萎缩。
:::

:::definition{label="核下瘫"}
下运动神经元（脑神经核或脑神经）损伤。面：病灶侧**全部**面肌瘫，额纹消失、眼闭不上。舌：病灶侧全部舌肌瘫并萎缩，伸舌偏**病灶侧**。
:::

:::compare{title="面肌、舌肌：核上瘫 vs 核下瘫"}
| | 核上瘫（上运动神经元） | 核下瘫（下运动神经元） |
|--|------------------------|------------------------|
| 损伤部位 | 对侧皮质核束（内囊膝等） | 同侧面神经核 / 面神经；同侧舌下神经核 / 舌下神经 |
| 面肌 | 对侧眼裂**以下**；额纹、闭眼保留 | 病灶侧额纹、闭眼、口角**全瘫** |
| 口角 | 偏向病灶侧（对侧口角下垂） | 偏向健侧（患侧口角下垂） |
| 舌 | 伸舌偏病灶**对侧**；无明显萎缩 | 伸舌偏病灶**同侧**；舌肌萎缩 |
| 本质 | 面下核、舌下核只接对侧皮质 | 最后公路断了，同侧肌直接失神经 |

面上部肌的核收双侧皮质，所以核上瘫「还能皱额、闭眼」；核下瘫把这一侧核或神经全断，额头和眼一起没。
:::

::figure{src="/images/anatomy/textbook/p0413_01.png" caption="图9-161　面肌瘫痪" alt="左侧皮质核束损伤（黑杠）导致右侧眼裂以下面肌瘫，额纹保留，为核上瘫；右侧面神经核或面神经损伤导致右侧全部面肌瘫、眼闭合不全，为核下瘫"}

::figure{src="/images/anatomy/textbook/p0413_02.png" caption="图9-162　舌肌瘫痪" alt="左侧舌下神经核或舌下神经损伤：舌尖偏向病灶侧，患侧舌肌萎缩，为核下瘫；右侧皮质核束损伤：舌尖偏向病灶对侧，无明显萎缩，为核上瘫"}

:::pitfall{label="面神经核下部和舌下神经核只接对侧皮质，其他脑神经核接双侧"}
动眼、滑车、展、三叉运动、面上部、疑核、副神经脊髓核都能靠对侧皮质活命，单侧上运动神经元损伤时这些肌不明显瘫。只有眼裂以下面肌和对侧舌肌会瘫。写成「核上瘫也是半张脸全瘫」，额纹和闭眼这一截就和周围性面瘫分不开。
:::

:::pitfall{label="伸舌偏向的是瘫侧，核上和核下的「瘫侧」不是同一边"}
舌尖被健侧颏舌肌推过去，所以偏向瘫痪的那一半舌。核下瘫瘫的是病灶同侧舌，舌尖偏病灶侧；核上瘫瘫的是病灶对侧舌，舌尖偏病灶对侧。不要背成「核上偏左、核下偏右」这种不带病灶的口诀。
:::

:::insight{label="图9-161、图9-162 把黑杠当损伤，再看脸上和舌头"}
面：核上瘫那张脸还能睁眼、额纹在，口角那一侧垮；核下瘫连眼都闭不全。舌：核下瘫那一侧瘦、起皱，舌尖歪向瘦的一边；核上瘫舌体不瘦，舌尖歪向病灶对侧。两张图的黑杠位置不同：核上在内囊或皮质，核下在核或周围神经。
:::

锥体系任何部位损伤都可引起支配区的随意运动障碍，导致瘫痪。表现分成两类。

上运动神经元损伤：脊髓前角细胞和脑神经运动核**以上**的锥体系损伤，即锥体细胞或其轴突组成的锥体束损伤。表现为：①随意运动障碍；②肌张力增高，称痉挛性瘫痪（硬瘫），因为上运动神经元对下运动神经元的抑制作用丧失（脑神经核上瘫时肌张力增高不明显），早期肌萎缩不明显（尚未失去直接神经支配）；③深反射亢进（失去高级控制），浅反射（腹壁反射、提睾反射等）减弱或消失（锥体束完整性被破坏）；④出现病理反射（如 Babinski 征）。

下运动神经元损伤：脑神经运动核和脊髓前角细胞**以下**的锥体系损伤，即这些核、前角细胞以及它们的轴突（脑神经和脊神经）损伤。表现为：①随意运动障碍；②肌张力降低，称弛缓性瘫痪（软瘫），并因神经营养障碍导致肌萎缩；③浅反射和深反射都消失（反射弧中断）；④不出现病理反射。

:::compare{title="上运动神经元损伤 vs 下运动神经元损伤"}
| | 上运动神经元 | 下运动神经元 |
|--|--------------|--------------|
| 解剖 | 皮质锥体细胞及其锥体束 | 脑神经运动核、脊髓前角及其轴突 |
| 瘫痪 | 痉挛性（硬瘫） | 弛缓性（软瘫） |
| 肌张力 | 增高 | 降低 |
| 早期肌萎缩 | 不明显 | 明显（失神经） |
| 深反射 | 亢进 | 消失 |
| 浅反射 | 减弱或消失 | 消失 |
| 病理反射 | 有（Babinski 等） | 无 |
| 典型 | 内囊出血对侧偏瘫；核上性面舌瘫 | 前角、周围神经、面神经核下瘫 |

硬瘫是「下级还在、上级不管」；软瘫是「最后公路断了」。不要用「中枢性 / 周围性」替代本版的上、下运动神经元，除非题目明确对译。
:::

:::pitfall{label="上、下运动神经元不是「脑内 vs 脑外」"}
下运动神经元的胞体可以在脑干核和脊髓前角——都在中枢里。周围神经只是它的轴突。写成「中枢损伤=上运动神经元、周围损伤=下运动神经元」，前角细胞本身的软瘫会从户头丢掉。核上瘫、核下瘫只用于脑神经这一截；到了脊髓，前角伤是下运动神经元，侧索里的皮质脊髓侧束伤是上运动神经元。
:::

:::cause-effect{title="为什么上运动神经元伤是硬瘫、下运动神经元伤是软瘫"}
- **因** 上运动神经元对下运动神经元有抑制；下运动神经元直接支配骨骼肌并维持营养。
- **果** 上级断了：下级释放 → 张力高、腱反射亢进、出现病理反射，早期肌还不瘦。下级断了：肌失去冲动和营养 → 张力低、反射全无、迅速萎缩，病理反射引不出。
- **所以** 硬瘫、软瘫首先问「最后公路还在不在」，不要先问「病在颅内还是颅外」。
:::

### （二）锥体外系

锥体外系（extrapyramidal system）指锥体系以外影响和控制躯体运动的所有传导路径。结构复杂，包括大脑皮质（主要是躯体运动区和躯体感觉区）、纹状体、背侧丘脑、底丘脑、中脑顶盖、红核、黑质、脑桥核、前庭核、小脑和脑干网状结构，以及它们的纤维联系。纤维最后经红核脊髓束、网状脊髓束等下行，终止于脑神经运动核和脊髓前角运动神经元。

种系发生上，锥体外系较古老：鱼类开始出现，鸟类曾是控制全身运动的主要系统。到了哺乳类尤其人类，大脑皮质和锥体系高度发达，锥体外系主要协调锥体系的活动。人类锥体外系的主要功能是调节肌张力、协调肌肉活动、维持体态姿势和习惯性动作（例如走路时双臂自然摆动）。

锥体系和锥体外系在运动功能上互相依赖、不可分割。只有锥体外系保持肌张力稳定协调，锥体系才能完成写字、刺绣这类精确随意运动；锥体外系对锥体系也有依赖——锥体系是运动的发起者，有些习惯性动作开始由锥体系发起，然后才处于锥体外系管理之下，如骑车、游泳。

:::definition{label="锥体外系"}
锥体系以外影响和控制躯体运动的全部路径。不是「锥体束旁边的一条束」，而是皮质—纹状体—小脑—脑干核团的一套环路。最后仍落到脑神经运动核和脊髓前角。
:::

:::pitfall{label="锥体外系不是一条和锥体束平行的「外束」"}
没有单独名叫「锥体外束」的一条白质。它是多条环路的总称，纤维最后借红核脊髓束、网状脊髓束等到下运动神经元。写成「锥体外系也从内囊膝下行、也在锥体交叉」，和锥体系就并成一束了。
:::

#### 1. 皮质-新纹状体-背侧丘脑-皮质环路

该环路对发出锥体束的皮质运动区有重要的反馈调节作用。

:::compare{title="表9-15　皮质-新纹状体-丘脑-皮质环路"}
| 起点 | 纤维 | 止点 |
|------|------|------|
| 额、顶叶皮质 | 皮质纹状体纤维 | 尾状核、壳（新纹状体） |
| 新纹状体 | 纹状体苍白球纤维 | 苍白球 |
| 苍白球 | 豆核袢、豆核束 | 丘脑腹前核、腹外侧核 |
| 丘脑腹前核、腹外侧核 | 丘脑皮质束 | 额叶运动区 |

环路闭合后回到发出锥体束的皮质，起反馈调节，不是另起一条随意运动的发起束。
:::

#### 2. 新纹状体-黑质环路

尾状核和壳发出纤维止于黑质，黑质再发纤维返回尾状核和壳。黑质神经细胞产生并释放多巴胺。黑质变性后，纹状体内多巴胺含量降低，与帕金森病的发生有关。

#### 3. 苍白球-底丘脑环路

苍白球发出纤维止于底丘脑核，后者经同一途径返回苍白球，对苍白球发挥抑制性反馈。一侧底丘脑核受损，丧失对同侧苍白球的抑制，对侧肢体出现大幅度颤搐。

#### 4. 皮质-脑桥-小脑-皮质环路

此环路是锥体外系中又一重要的反馈环路，人类最为发达。小脑还接受来自脊髓的本体感觉纤维，因而能更好地协调和共济肌肉运动。环路任何部位损伤，都会导致共济失调，如行走蹒跚和醉汉步态（图9-163）。

:::compare{title="表9-16　皮质-脑桥-小脑-皮质环路"}
| 起点 | 纤维 | 止点 |
|------|------|------|
| 额、顶、枕、颞叶皮质 | 皮质脑桥束 | 脑桥核 |
| 脑桥核 | 脑桥小脑纤维（交叉，经小脑中脚 / 桥臂） | 新小脑皮质 |
| 新小脑皮质 | 皮质核纤维 | 齿状核 |
| 齿状核 | 小脑上脚纤维（交叉） | 对侧红核、丘脑腹外侧核 |
| 红核 | 红核脊髓束 | 脊髓前角运动神经元 |
| 丘脑腹外侧核 | 丘脑皮质束 | 皮质运动区 |
| 脊髓（本体觉） | 脊髓小脑束 | 小脑皮质（为环路提供肢体位置信息） |

脑桥核发出的纤维交叉经小脑中脚进对侧小脑；齿状核发出的纤维经小脑上脚再交叉。环路上两次交叉，损伤定位不能按「只交叉一次」去套锥体交叉。
:::

::figure{src="/images/anatomy/textbook/p0415_02.png" caption="图9-163　锥体外系的皮质-脑桥-小脑-皮质环路" alt="大脑皮质经皮质脑桥束到脑桥核，再经桥臂纤维到小脑皮质；齿状核发出纤维到对侧红核，红核脊髓束下行到脊髓前角；脊髓小脑束把本体觉送回小脑；并有纤维返回大脑皮质"}

:::insight{label="图9-163 先认脑桥核这一站，再认齿状核出小脑"}
皮质脑桥束贴大脑脚、脑桥腹侧进脑桥核；横行的桥臂纤维进小脑皮质。齿状核是出小脑的枢纽，纤维到对侧红核，红核脊髓束才落到前角。脊髓小脑束从脊髓爬回来，给小脑提供「肢体现在在哪」的信息。这张图不是锥体交叉，不要在延髓腹侧找交叉。
:::

:::compare{title="锥体外系四条环路（功能对照）"}
| 环路 | 关键结构 | 伤了会怎样（本版） |
|------|----------|-------------------|
| 皮质-新纹状体-丘脑-皮质 | 尾状核、壳、苍白球、丘脑腹前/腹外侧核 | 皮质运动区失去反馈调节 |
| 新纹状体-黑质 | 黑质多巴胺 | 黑质变性 → 纹状体多巴胺降低 → 帕金森病 |
| 苍白球-底丘脑 | 底丘脑核抑制苍白球 | 一侧底丘脑核伤 → 对侧肢体大幅度颤搐 |
| 皮质-脑桥-小脑-皮质 | 脑桥核、齿状核、红核 | 共济失调、蹒跚、醉汉步态 |

四条都是反馈，不是四条平行的「随意运动发起束」。发起仍在锥体系。
:::

:::pitfall{label="不要把锥体外系伤写成和锥体系伤同一套硬瘫"}
锥体系伤是痉挛性瘫痪加病理反射。锥体外系伤更多是肌张力改变、不自主运动或共济失调：帕金森病的震颤强直、底丘脑核伤的大幅度颤搐、小脑环路的醉汉步态。写成「锥体外系损伤也是 Babinski 阳性的硬瘫」，两户的临床对不上。
:::

:::keypoint{label="内囊里和本节通路有关的几束"}
- 膝：皮质核束。
- 后肢前部：皮质脊髓束。
- 后肢：丘脑中央辐射（深、浅感觉第 3 级）、视辐射、听辐射。
- 一侧内囊后肢广泛损伤，可以把对侧偏瘫、偏身感觉障碍和偏盲凑在一起。具体血管和出血好发部位是第二节内囊的户，本节只认纤维名单。
:::

:::memory{label="本节必背要点"}
- [ ] 传导通路分上行感觉、下行运动。不经过皮质的才叫反射通路。每条先问：几级、在哪交叉、皮质（或效应器）止于哪。
- [ ] 意识性本体觉 + 精细触觉：3 级。脊神经节 → 薄束（T5↓，内）/ 楔束（T4↑，外）→ 薄楔束核 → **内侧丘系交叉** → VPL → 内囊后肢 → 中央后回中上部、中央旁小叶后部。交叉上伤对侧，交叉下伤同侧。
- [ ] 非意识性本体觉：2 级，止于旧小脑。后束同侧经小脑下脚，前束经小脑上脚（可双侧）。
- [ ] 浅感觉：3 级。躯干四肢在脊髓白质前连合交叉（先升 1～2 节），侧束痛温、前束粗触压，到 VPL。头面：三叉神经节 → 脊束核 / 脑桥核 → 三叉丘系 → VPM → 中央后回下部。
- [ ] 脊髓丘脑束由外向内：骶腰胸颈。髓内肿瘤对侧上半身痛温先没，髓外相反。
- [ ] 视觉：双极细胞 → 节细胞 → 视交叉（仅鼻侧交叉）→ 外侧膝状体 → 视辐射 → 距状沟纹状区。一侧视神经全盲；交叉中部双颞侧偏盲；交叉外侧患侧鼻侧偏盲；视束以后对侧同向性偏盲。
- [ ] 对光反射：视束 → 上丘臂 → 顶盖前区 → 两侧动眼神经副核。视神经伤：患侧直接消失、间接存在；动眼神经伤：患侧直接和间接都消失。
- [ ] 听觉：4 级，蜗神经节 → 蜗核 → 斜方体 / 外侧丘系 → 下丘 → 内侧膝状体 → 颞横回。双侧传导，外侧丘系以上单侧伤不明显。
- [ ] 锥体系：上运动神经元 = 皮质锥体细胞 + 锥体束；下运动神经元 = 脑神经运动核 / 前角及其轴突（最后公路）。皮质脊髓束 75%～90% 锥体交叉，侧束管四肢，前束管躯干；躯干肌双侧支配。
- [ ] 皮质核束大部分双侧；面神经核下部和舌下神经核只接对侧。核上瘫：对侧眼裂以下 + 伸舌偏病灶对侧。核下瘫：同侧全脸或同侧舌萎缩。
- [ ] 上运动神经元伤 = 硬瘫、张力高、腱反射亢进、有病理反射、早期不瘦。下运动神经元伤 = 软瘫、张力低、反射全无、肌萎缩、无病理反射。
- [ ] 锥体外系是环路不是一条束。黑质多巴胺 ↔ 帕金森病；底丘脑核伤 → 对侧大幅度颤搐；皮质-脑桥-小脑环路伤 → 共济失调。
:::
