# 1.4 教学大纲与实验要求：课时、掌握档和标本考试怎么对

本课教学大纲写明：课程编码 BMS0514，系统解剖学（Systematic anatomy），总学时 96，学分 4.5，理论 48 学时、实验（实习）48 学时，授课专业为基础医学强基班，开课单位为基础医学院人体解剖学系。教材指定《系统解剖学》第九版，丁文龙、刘学政主编，人民卫生出版社，2018.8。评价方法：平时成绩 10% + 标本考试 20% + 理论考试 70%。实验指导扫描件几乎没有可提取文字，本篇只写大纲里真正出现的实验（实习）学时、示教要求和观察任务，不编造解剖步骤。

:::insight{label="大纲要解决的三件事"}
态度观点、基本理论、基本技能是并列的三档，不是「先背完理论再去标本室」。96 学时对半切开：理论讲构成和毗邻，实习课用标本把同一批结构认出来。标本考试单独占 20%，和理论卷不是同一张卷。
:::

:::definition{label="系统解剖学（大纲原句）"}
系统解剖学是按人体器官功能系统（运动、消化、呼吸、泌尿、生殖、脉管、感觉器、神经和内分泌等）阐述人体正常器官形态结构及其发生发展的科学，是医学科学中一门重要的基础课程，是人体解剖学的主要分科之一。
:::

:::definition{label="本课任务"}
使医学生理解和掌握人体各器官的正常形态结构特征、位置毗邻、生长发育规律及其功能意义，为其他基础医学和临床医学课程奠定形态学基础。只有掌握正常形态，才能正确理解生理和病理过程，判断正常与异常。
:::

## 一、态度、理论和技能三档

大纲把「课程基本内容和要求」写成三块。态度不是口号，而是后面每一章都要带着走的五条观点。

:::keypoint{label="态度：五条观点"}
- 形态与功能相互依存
- 进化发展
- 局部与整体统一
- 理论与实际相结合
- 实践第一
:::

:::compare{title="基本理论与基本技能"}
| 档 | 大纲要求 |
|----|----------|
| 基本理论 | 掌握人体九大系统的组成及主要功能；掌握各器官主要形态结构、位置毗邻及主要功能；掌握主要解剖学英文名词 |
| 基本技能 | 正确观察、辨认人体器官形态和构造；正确使用解剖学术语，描述主要器官的形态结构、位置毗邻 |
:::

:::pitfall{label="英文名词不是选修"}
大纲把「掌握人体主要的解剖学英文名词」写进基本理论，和形态结构并列。理论卷互译、标本标签上的英文，都从这里出。不要把 1.3 当成课外兴趣。
:::

## 三、评价与标本考试在大纲里的位置

:::definition{label="成绩构成"}
平时成绩 10%，标本考试 20%，理论考试 70%。标本考试是独立评价，不是理论卷的附图题。
:::

大纲在心、动脉、静脉、淋巴、神经各章的「学习内容和要点」里反复写：结合示教尸体弄清毗邻，在示教标本上观察心腔、冠状动脉、胸导管、淋巴结。这些句子就是标本考试的出题范围——你要能在尸体或游离标本上指出大纲「掌握」档的结构，并用术语描述。

实验指导 PDF 为扫描件，文本几乎为空，不能从中恢复逐步的解剖操作。因此本篇不编写「如何剖开腋腔」「如何翻起胸膜」之类步骤。实验室课次目录（人卫课堂实习单元标题）可用于对照进度：绪论与骨关节总论及躯干骨；躯干骨连结和上肢骨及连结；下肢骨及连结；颅骨及其连结；肌学；消化系统。具体剖割手法以课堂上教师示教为准。

:::pitfall{label="不要把实验指导扫描件脑补成操作手册"}
61 页实验指导几乎抽不出字。若按记忆补一套「从皮肤到腹膜的刀法」，和本实验室实际示教可能对不上，也会和大纲「观察、辨认」的技能定位偏离。大纲要的技能是辨认和描述，不是独立完成系统解剖操作。
:::

## 四、绪论与运动系统：大纲的重点难点

绪论重点是标准姿势、轴、面和方位术语；难点是「内、外」与「内侧、外侧」的区别。思考题要求举例说明这两组词。

:::compare{title="内 / 外 对 内侧 / 外侧"}
| | 英文 | 相对什么 | 例子 |
|--|------|----------|------|
| 内、外 | internal, external | 空腔或器官壁的里外 | 肋内面、关节囊内 |
| 内侧、外侧 | medial, lateral | 正中矢状面 | 尺骨在内侧，桡骨在外侧（解剖学姿势下） |
:::

骨学掌握：骨的形态、构造、功能及分类；躯干骨、颅骨、上下肢骨的组成、形态、位置及主要结构；主要骨性标志。难点是颅底内面观。思考题点名：小儿与成人骨的理化性质；颅中窝主要结构；骨性鼻腔外侧壁；鼻旁窦名称、位置及开口；全身主要骨性标志。

关节学掌握：关节基本结构、辅助结构和运动；脊柱、胸廓、足弓；肩、肘、桡腕、髋、膝、踝。难点是膝关节。思考题：关节基本构造；肩与髋比较；膝关节构成与特点；椎间盘；足弓。

肌学掌握：骨骼肌形态结构；咀嚼肌；胸锁乳突肌和斜角肌间隙；斜方肌、背阔肌、胸大肌、膈、腹前外侧肌群、腹直肌鞘、腹股沟管；三角肌和臂肌；臀大肌、髂腰肌、股四头肌、小腿三群。难点是前臂肌分层。思考题包括腹股沟管的位置、构成及内容。

:::keypoint{label="运动系统大纲点名的局部结构"}
斜角肌间隙、腹直肌鞘、腹股沟管；简介腋窝、肘窝、股三角、腘窝。标本课要把这些腔隙的边界和内容指认出来，而不是只背名单。
:::

## 五、内脏、脉管、感官：大纲掌握档压缩

消化系统掌握从口腔到肛管、肝外胆道和胰。难点：颏舌肌作用、咽的交通、齿状线上下。思考题：胃的位置形态分部；打开腹腔如何区分大肠小肠并找阑尾；胆汁产生与排出。

呼吸系统掌握鼻旁窦开口、喉腔、左右支气管差别、肺门、胸膜隐窝、纵隔。难点：前庭裂与声门裂的空间、胸膜窦的立体概念。

泌尿掌握肾剖面、肾蒂排列、被膜、输尿管狭窄、膀胱三角、女尿道特点和男尿道狭窄膨大弯曲。男性生殖掌握睾丸附睾、输精管、前列腺、精索、阴茎；思考题含精子通路和男性绝育部位。女性生殖掌握卵巢固定装置、输卵管分部、子宫位置与固定、阴道穹；思考题含输卵管结扎部位。腹膜掌握网膜囊、陷凹、系膜；思考题：胃后壁穿孔物流向何处，腹膜炎为何半卧位。

:::definition{label="脉管总论掌握"}
心血管系组成；体循环与肺循环基本途径和特点；熟悉血管吻合和侧支循环。
:::

心：位置毗邻外形、心腔、纤维骨骼、传导系、冠状动脉、心包横窦和斜窦。动脉：肺动脉干、主动脉分段、颈总动脉和颈动脉窦、锁骨下至掌弓、腹腔干和肠系膜上、下动脉、子宫动脉与输尿管关系、压迫止血点。静脉：静脉角、浅静脉、奇静脉、大隐静脉、门静脉及其与腔静脉吻合。淋巴：胸导管和右淋巴导管、局部淋巴结、左锁骨上淋巴结、脾和胸腺。内分泌：垂体、甲状腺、甲状旁腺、肾上腺、松果体的形态位置。

视器掌握眼球壁、房水循环、结膜、泪器、眼球外肌、视网膜中央动脉。前庭蜗器掌握外耳道（含幼儿特点）、鼓膜、鼓室六壁、咽鼓管、骨迷路与膜迷路、听觉和位置觉感受器。

## 六、神经系统：大纲把外形和内构拆开实习

神经总论掌握神经元结构和功能，熟悉反射弧和常用术语。脊髓掌握节段与椎骨对应、马尾、灰白质、薄束楔束、脊髓丘脑束、皮质脊髓束。思考题用高空坠落病例：左下肢痉挛性瘫、本体感觉精细触觉丧失、右侧脐平面以下痛温觉丧失——要求判断脊髓损伤节段和哪一椎骨骨折。

脑干掌握外形（锥体、橄榄、锥体交叉、大脑脚、上丘下丘）、第四脑室、脑神经核机能柱、内侧丘系和锥体束。间脑掌握背侧丘脑特异性中继核、内/外侧膝状体、下丘脑。小脑掌握扁桃体和功能分叶。周围神经在脊神经章掌握颈丛膈神经、臂丛五大终支、腰骶丛股神经和坐骨神经。

:::compare{title="大纲实验课在神经部分怎么切开"}
| 实习单元（学时表） | 理论对应 | 标本上要能指 |
|--------------------|----------|--------------|
| 神经总论、脊髓外形、脊神经（2 学时） | 外形、节段、神经丛 | 脊髓圆锥、马尾、脊神经根 |
| 脊髓内构、脑干外形、脑神经（3 学时） | 灰质核团、十二对脑神经 | 脑干腹背面结构、脑神经根 |
| 脑干内构、小脑、间脑（3 学时） | 丘系、小脑核、丘脑 | 小脑扁桃体、间脑分部 |
| 端脑、内脏神经（2 学时） | 内囊、皮质定位、交感副交感 | 内囊 “<” 形、交感干 |
| 传导路、被膜血管脑脊液（3 学时） | 循环路径 | 硬膜窦、蛛网膜粒 |
:::
