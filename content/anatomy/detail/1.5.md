# 1.5 人卫课堂课件精要：只收 dump 里真正有的结构要点

人卫课堂课件按章拆成 PPT 文本。很多页是图，抽取出来的字很短。本篇只写 dump 里实际出现的句子：关节基本构造、心血管分节、淋巴干、神经总论和脊神经、肌的形态构造。不发明教材和课件都没有列出的全身肌起止点清单。图片页没有抽出的起止、神经核坐标，一律不补。

:::insight{label="课件和教材怎么对读"}
课件「重点难点」页几乎是考试蓝图：关节三件套、椎间盘、肩髋膝、体肺循环、心外形沟、血管吻合、九条淋巴干、脊神经纤维成分、臂丛组成。文字短的章节（部分脑神经 PPT 几乎是二进制残留）不要靠想象补全，回到 1.1 名词和 1.2 提纲。
:::

## 一、关节学课件：连结分类与三件套

课件把骨连结分成直接连结和间接连结。直接连结包括纤维连结（韧带连结、缝）、软骨连结（透明软骨结合如骺软骨，纤维软骨联合如耻骨联合）和骨性结合（髂、耻、坐骨之间骨化）。间接连结即关节或滑膜关节，是最高分化形式：相对骨面分离，有充以滑液的腔隙，借周围结缔组织相连，活动度较大。

:::definition{label="关节的基本构造（课件原文结构）"}
- 关节面：相关骨的接触面，一般一凸一凹，凸为关节头、凹为关节窝，被覆关节软骨。
- 关节囊：纤维结缔组织膜构成的囊，分外层纤维膜（厚而坚韧）和内层滑膜（薄而柔润，富含血管网，产生滑液）。
- 关节腔：滑膜层与关节面共同围成的密闭腔隙，含少量滑液，呈负压，对稳固有一定作用。
:::

:::definition{label="关节的辅助结构"}
韧带：连于相邻两骨的致密纤维束，加强稳固或限制过度运动。关节盘和关节唇：关节腔内不同形态的纤维软骨。滑膜襞：滑膜重叠突入关节腔。滑膜囊：滑膜从纤维膜薄弱处膨出，充填于肌腱与骨面之间。
:::

:::compare{title="关节运动与分类（课件）"}
| 运动 | 轴 |
|------|----|
| 移动 | 一骨关节面在另一骨关节面上滑动 |
| 屈和伸 | 冠状轴 |
| 收和展 | 矢状轴 |
| 旋转 | 垂直轴 |
| 环转 | 上端原位，下端圆周，全骨描绘圆锥 |

单轴：屈戌（滑车）关节、车轴关节。双轴：椭圆关节、鞍状关节。多轴：球窝关节、平面关节。
:::

椎间盘是连结相邻椎体的纤维软骨盘（C1 与 C2 之间除外），成人 23 个。髓核在中央，柔软富弹性，为脊索残留；纤维环在周围，多层纤维软骨同心圆排列，限制髓核膨出。脊柱侧面观有颈、胸、腰、骶四个生理弯曲：颈曲腰曲凸向前，胸曲骶曲凸向后。胸廓由 12 块胸椎、12 对肋和 1 块胸骨构成。胸廓上口：胸骨柄上缘、第 1 肋、第 1 胸椎体；下口：第 12 胸椎、第 11 及 12 肋前端、肋弓和剑突，膈封闭。

颞下颌关节由下颌头与颞骨下颌窝和关节结节构成，囊内有关节盘把关节腔分成上、下两部；囊前份薄弱，易向前脱位。胸锁关节是上肢骨与躯干骨连结的唯一关节，囊内有关节盘。喙肩韧带与喙突、肩峰构成喙肩弓，防止肱骨头向上脱位。肩关节：肱骨头 + 关节盂，囊下壁最薄弱，易前下方脱位，全身最灵活。肘关节是复关节，包括肱尺、肱桡、桡尺近侧三个关节，以肱尺关节为主作屈伸。

:::pitfall{label="基本构造不要把辅助结构写进去"}
课件把韧带、关节盘、滑膜襞明确放在「辅助结构」。简答「基本构造」只答面、囊、腔。
:::

:::memory{label="关节课件必背"}
- [ ] 直接：纤维、软骨、骨性结合；间接：滑膜关节
- [ ] 三件套：面、囊、腔（负压）
- [ ] 椎间盘 23 个；髓核是脊索残留
- [ ] 肩：盂浅囊松，前下脱位；喙肩弓防向上脱位
- [ ] 肘：三个关节共一个囊，屈伸为主
:::

## 二、肌学课件：形态四类，不展开无清单的起止

课件总论：肌分心肌、平滑肌和骨骼肌，本章叙述骨骼肌。骨骼肌是运动系统的动力部分，受人意识控制，又称随意肌。构造：肌腹（肌纤维，色红柔软，能收缩）+ 肌腱（平行胶原纤维，色白强韧，无收缩功能）。形态四类：长肌、短肌、扁肌、轮匝肌。

重点难点页点名要掌握的肌，是名称、位置和作用，不是一份起止表：咀嚼肌；胸锁乳突肌和斜角肌间隙；斜方肌、背阔肌、竖脊肌、胸大肌、前锯肌、肋间肌；膈；腹前外侧群；上肢带肌和臂肌；髂腰肌、臀大肌、梨状肌；股四头肌；小腿三头肌。课件未给出完整起止点坐标的，本篇不编。

:::keypoint{label="斜角肌间隙与膈（课件与提纲交叉）"}
斜角肌间隙：前、中斜角肌和第 1 肋，通过臂丛和锁骨下动脉。膈构成胸腔底和腹腔顶，三个裂孔分别走主动脉、食管（及迷走神经）、下腔静脉。具体椎序见 1.2，课件重点页只要求「裂孔及通过的结构」。
:::

:::pitfall{label="不要根据课件空白页发明起止"}
肌学 PPT 后续大量是图。dump 没有写出某肌的起点、止点、神经节段时，不要从其他教材抄一份清单进来。考试若要起止，以课堂上板书和第九版教材为准，不在本篇杜撰。
:::

## 三、心血管课件：组成、循环、吻合、心外形

脉管系统是封闭管道，由心血管系统和淋巴系统组成，功能是物质运输。心血管系统包括心、动脉、静脉、毛细血管。心是动力泵；动脉运送血液离心；静脉引导血液回心；毛细血管是物质交换场所。

:::definition{label="肺循环（课件）"}
右心室射出静脉血 → 肺动脉干 → 左、右肺动脉及其分支 → 肺泡壁毛细血管（气体交换）→ 肺静脉（动脉血）→ 左心房。行程短，分支少，范围小，把静脉血转化为动脉血。
:::

:::definition{label="体循环（课件）"}
左心室射出动脉血 → 主动脉 → 各级动脉 → 全身毛细血管（物质交换）→ 各级静脉 → 上、下腔静脉 → 右心房。行程长，分支多，范围广。
:::

:::definition{label="血管吻合与终动脉"}
吻合包括动脉间、静脉间、动静脉吻合和侧支吻合。动脉主干阻塞时，血流经侧副支到达阻塞以下主干，称侧支循环。终动脉：与相邻动脉无吻合，如视网膜中央动脉、阑尾动脉。功能性终动脉：虽有吻合但不足以代偿，如脑、脾、肾动脉。
:::

心位于胸腔中纵隔的心包内，约 2/3 在正中面左侧，1/3 在右侧。毗邻：外侧左右肺和纵隔胸膜，上为出入心的大血管，下为膈，前为胸骨体和第 2～6 肋软骨，后为第 5～8 胸椎。外形：倒置、前后稍扁的圆锥，约与本人握拳相似。一尖、一底、两面、三缘、四条沟。心尖由左心室构成，朝左前下；心底主要由左心房构成，朝右后上。胸肋面大部分是右心室和右心房；膈面大部分是左心室。前、后室间沟是左右心室在心表面的分界。

动脉课件概括器官外动脉配布：左右对称；每一局部 1～2 条动脉干；壁支和脏支；与静脉神经伴行成血管神经束；多在屈侧、深部；以最短距离到达器官。器官内分布模式点名放射型（脊髓）、横行型（肠管）、纵行型（输尿管、肌）、自门进入（肾）。肺循环动脉：肺动脉干 → 左、右肺动脉，动脉韧带连于肺动脉干分叉附近与主动脉弓之间。体循环动脉按升主动脉、主动脉弓、降主动脉分段。

:::compare{title="心外形课件分户"}
| 结构 | 主要由谁构成 |
|------|----------------|
| 心尖 | 左心室 |
| 心底 | 左心房（小部分右心房） |
| 胸肋面 | 大部分右室、右房 |
| 膈面 | 大部分左室 |
| 右缘 | 右心房 |
| 左缘 | 大部分左室、小部分左心耳 |
| 前 / 后室间沟 | 左右心室表面分界 |
:::

:::memory{label="心血管课件"}
- [ ] 心是泵，动脉离心，静脉回心，毛细血管交换
- [ ] 肺循环右室出、短；体循环左室出、长
- [ ] 终动脉：视网膜中央动脉、阑尾动脉
- [ ] 心 2/3 在左侧；心尖左室、心底左房
- [ ] 动脉韧带是动脉导管遗迹
:::

## 四、淋巴系统课件：管道四级和九条干

淋巴系统是心血管系统的辅助系统，组成：淋巴管道、淋巴组织、淋巴器官。功能：产生淋巴细胞、过滤淋巴、免疫应答。小肠绒毛来的淋巴呈乳糜状。

:::definition{label="淋巴管道四级"}
- 毛细淋巴管：通透性大于毛细血管；上皮、角膜、晶状体、软骨、脑和脊髓等处无毛细淋巴管（课件写「无毛细淋巴管」的部位以此为准，不要另造名单）
- 淋巴管：有瓣膜，分浅深，其间串联淋巴结
- 淋巴干：9 条。成对：颈干、锁骨下干、支气管纵隔干、腰干；不成对：肠干
- 淋巴导管：胸导管、右淋巴导管
:::

淋巴组织：弥散淋巴组织（消化、呼吸道黏膜固有层）；淋巴小结（孤立和集合淋巴滤泡）。淋巴器官：淋巴结、胸腺、脾、扁桃体。淋巴结成群分布，多在血管周围、屈侧、隐蔽处、交界处、器官门。局部淋巴结是某器官或局部的第一级淋巴结，即哨兵淋巴结。

课件重点还点名：下颌下淋巴结、腋淋巴结分群、腹股沟淋巴结、Virchow 淋巴结（左侧斜角肌淋巴结）。乳腺癌、食管癌转移途径写在难点里，具体引流链以标本课挂图为准。

## 五、神经总论与脊神经课件

神经系统协调各器官，维持内环境稳定，适应外环境。区分：中枢（脑、脊髓）和周围（脑神经、脊神经、内脏神经）。神经组织两种细胞：神经元和神经胶质。神经元是结构和功能的基本单位，能感受刺激和传导冲动。突起分树突和轴突。按突起数目：假单极、双极、多极。按功能：感觉、运动、联络。突触是神经元之间或神经元与效应细胞之间传递信息的特化区，分化学突触和电突触。

:::definition{label="脊神经构成（课件）"}
31 对。前根运动性，后根感觉性，合为混合性脊神经。分部：颈 8、胸 12、腰 5、骶 5、尾 1。纤维四种：躯体感觉、内脏感觉、躯体运动、内脏运动。
:::

:::keypoint{label="脊神经分支"}
- 前支：粗大；除胸神经前支保持节段性外，其余交织成颈丛、臂丛、腰丛、骶丛
- 后支：分布于项背腰骶深肌和皮肤
- 交通支：连脊髓与交感干
- 脊膜支：返回椎管，分布于脊髓被膜
:::

颈丛由 C1～C4 前支构成，位于胸锁乳突肌上部深面。皮支：枕小、耳大、颈横、锁骨上神经。膈神经：经前斜角肌前面下行，经锁骨下动、静脉之间入胸腔，经肺根前方、心包两侧至膈；支配膈运动，感觉纤维到心包、胸膜和膈部腹膜（包括肝、胆囊表面腹膜）。损伤致同侧膈肌瘫痪、呼吸困难；刺激产生呃逆。

臂丛由 C5～C8、T1 前支构成，经斜角肌间隙向外侧穿出，锁骨后方入腋窝，夹持腋动脉。分支总图见 1.2 臂丛图。课件重点：肌皮、腋、正中、尺、桡神经的走行、分布和损伤表现（垂腕、爪形手、猿手等在难点页点名，具体肌名单以课堂示教为准，本篇不补一份未出现在 dump 里的肌表）。

:::compare{title="周围神经三大块（课件开篇）"}
| | 构成 | 分布 |
|--|------|------|
| 脊神经 | 31 对 | 躯干四肢 |
| 脑神经 | 12 对 | 头颈，迷走还到胸腹 |
| 内脏神经 | 交感（胸腰）+ 副交感（颅骶） | 内脏、心血管、腺体、平滑肌 |
:::

脑干课件把脑分成端脑、间脑、小脑、脑干（中脑、脑桥、延髓）。重点在代表平面和 III～XII 核的性质位置，文字页很短，核团坐标以教材和示教切片为准，不在本篇用口诀填空。

:::memory{label="神经课件必背"}
- [ ] 神经元：胞体代谢中心；假单极 / 双极 / 多极
- [ ] 脊神经 31 对，前根运动后根感觉
- [ ] 胸神经前支节段性；其余成四丛
- [ ] 膈神经：前斜角肌前，肺根前，管膈
- [ ] 臂丛 C5–T1，斜角肌间隙，包腋动脉
:::
