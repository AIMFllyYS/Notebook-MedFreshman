# 1.1 系统解剖学名词解释：按系统把常考户头钉死

名词解释不是把中文名再抄一遍，而是把「这个结构在哪里、由谁围成、里面走什么、临床上为什么要命」写成一张可默写的户头。本篇按运动、内脏、脉管、感觉器、神经摊开，词条来自系解名词解释清单；讲解用自己的话重组，不把原文当讲义堆砌。

:::insight{label="名词解释怎么拿满"}
阅卷通常按「位置 + 构成 / 内容 + 功能或临床」给分。只写中文名得零分；只写「是一个三角」而不写三条边，也只拿一半。先问这个词是空间、管道、复合体还是功能单位，再把围成它的边界和穿过它的结构写全。
:::

:::definition{label="解剖学姿势"}
解剖学姿势是描述方位的唯一坐标系：身体直立，面向前方，两眼平视正前方，两足并拢、足尖向前，双上肢下垂于躯干两侧，**掌心向前**。所有「前、后、内、外、尺、桡」都相对这一姿势，而不是相对病人此刻怎么躺。
:::

:::pitfall{label="掌心向前不能省"}
自然下垂时掌心朝向大腿，那是生活姿势，不是解剖学姿势。省掉掌心向前，尺骨、桡骨、尺侧、桡侧会整章写反。
:::

:::memory{label="名词解释答题三问" mode=cloze}
先写**位置**，再写**由谁围成或由谁组成**，最后写**穿行结构或临床意义**。三角、间隙、隐窝三类词最容易漏第三条边。
:::

## 一、运动系统：骨性标志、间隙、韧带与关节

胸骨角是计数肋的钥匙。胸骨柄与胸骨体连接处微向前突，两侧平对第 2 肋，向后平对第 4 胸椎体下缘。它同时是上、下纵隔的分界平面，也常对主动脉弓下缘、气管权。把胸骨角听成「随便一个隆起」，后面数肋、读胸片都会错位。

:::definition{label="胸骨角"}
胸骨柄与体连接处微向前突称胸骨角。两侧平对第 2 肋，向后平对第 4 胸椎体下缘，是计数肋的重要标志。
:::

:::definition{label="翼点（Pterion）"}
颅侧面额、顶、颞、蝶四骨会合处最为薄弱，常成 “H” 形缝，称翼点。内面有脑膜中动脉前支经过。外力打在此处，易撕破该动脉，形成硬膜外血肿。
:::

:::keypoint{label="翼点三笔不要漏"}
- 四骨：额、顶、颞、蝶
- 缝形成 “H”
- 深面：脑膜中动脉前支，不是脑膜中动脉主干随便一说
:::

:::definition{label="蝶筛隐窝"}
最上鼻甲或上鼻甲后上方与蝶骨之间的间隙，是蝶窦的开口部位。鼻旁窦开口里，只有蝶窦不进上、中鼻道，而开在这个隐窝。
:::

:::definition{label="黄韧带"}
位于椎管内、连结相邻两椎弓板的韧带，由黄色弹性纤维构成。协助围成椎管，并限制脊柱过度前屈。腰穿针从后路进入椎管，最后穿过的黄韧带是手感突然落空的那一层。
:::

:::compare{title="脊柱几条纵韧带各管什么方向"}
| 韧带 | 位置 | 主要限制 |
|------|------|----------|
| 前纵韧带 | 椎体前面 | 过度后伸 |
| 后纵韧带 | 椎体后面（椎管前壁） | 过度前屈 |
| 黄韧带 | 椎弓板之间 | 过度前屈 |
| 棘间、棘上韧带 | 棘突之间、棘突尖 | 过度前屈 |
:::

:::definition{label="椎间盘"}
连结相邻两个椎体的纤维软骨盘，由周围的纤维环和中央的髓核构成。既坚韧又富弹性，缓冲外力、增加脊柱运动幅度。第 1、2 颈椎之间没有椎间盘；成人通常 23 个。髓核向后外侧突出，可压迫脊神经根。
:::

:::definition{label="关节（滑膜关节）"}
骨的间接连结，是骨连结的最高分化形式：相对骨面分离，具有充以滑液的腔隙，借周围结缔组织相连，一般活动度较大。基本构造只有三件：关节面、关节囊、关节腔。关节腔由滑膜层和关节面围成，呈负压，含少量滑液，对稳固有一定作用。韧带、关节盘、关节唇、滑膜襞和滑膜囊都是辅助结构，不要写进「基本构造」。
:::

:::pitfall{label="关节基本构造不要写成五件套"}
韧带、半月板、关节唇再重要，也是辅助结构。简答「关节的基本构造」只答关节面、关节囊、关节腔。
:::

:::definition{label="界线（骨盆上口）"}
由骶骨岬向两侧经弓状线、耻骨梳、耻骨结节至耻骨联合上缘构成的环形界线，把上方的大骨盆和下方的小骨盆分开。产科说的骨盆入口，就是这条界线围成的口。
:::

:::definition{label="骨盆下口"}
由尾骨尖、骶结节韧带、坐骨结节、坐骨支、耻骨支和耻骨联合下缘围成，呈菱形。不要漏掉两条骶结节韧带，否则菱形的后外侧边会缺。
:::

:::definition{label="足弓"}
跗骨和跖骨借其连结形成凸向上的弓，分内侧纵弓、外侧纵弓和横弓。内侧纵弓最高点在距骨头。足弓提供稳定与弹跳，并保护足底的神经和血管。扁平足是弓塌陷，不是少了一块骨。
:::

:::definition{label="斜角肌间隙"}
前斜角肌、中斜角肌与第 1 肋共同围成的裂隙，有臂丛和锁骨下动脉通过。锁骨下静脉走在前斜角肌前方，**不进**这个间隙。胸廓出口综合征常在此处卡臂丛或锁骨下动脉。
:::

:::pitfall{label="斜角肌间隙只走动脉和臂丛"}
锁骨下静脉在前斜角肌前。写成「锁骨下动、静脉和臂丛都从间隙过」，静脉户头就错了。
:::

:::definition{label="腹股沟韧带"}
腹外斜肌腱膜下缘卷曲增厚，连于髂前上棘与耻骨结节之间，有弹性和韧性。局部可延续出腔隙韧带、耻骨梳韧带，并参与围成腹股沟管浅环。它是腹股沟区几乎所有三角、管、裂孔的下边界。
:::

:::definition{label="海氏三角（Hesselbach triangle）"}
腹前壁下部由腹直肌外侧缘、腹股沟韧带和腹壁下动脉围成的三角，是腹壁薄弱区。腹腔内容物由此膨出形成腹股沟直疝。斜疝走腹股沟管，直疝走海氏三角，不要并户。
:::

:::memory{label="运动系统高频名词"}
- [ ] 胸骨角：平第 2 肋、平 T4 椎体下缘
- [ ] 翼点：额顶颞蝶，“H” 缝，脑膜中动脉前支
- [ ] 蝶筛隐窝：蝶窦开口
- [ ] 黄韧带：椎弓板之间，限制前屈
- [ ] 关节三件套：关节面、关节囊、关节腔
- [ ] 斜角肌间隙：前、中斜角肌 + 第 1 肋；臂丛 + 锁骨下动脉
- [ ] 海氏三角：腹直肌外侧缘 + 腹股沟韧带 + 腹壁下动脉 → 直疝
:::

## 二、消化系统：从咽峡到胆囊三角

:::definition{label="咽峡"}
由腭垂、腭帆游离缘、左右腭舌弓及舌根共同围成的狭窄处，是口腔通咽的孔裂，也是口腔与咽的分界。口咽检查让患者发「啊」，看的就是咽峡这一圈。
:::

:::definition{label="梨状隐窝"}
喉咽部、喉口两侧各有一深凹，称梨状隐窝，是异物易嵌顿滞留的部位。鱼刺卡在「嗓子眼两侧」，解剖户头往往在这里，而不是声门裂。
:::

:::definition{label="回盲瓣"}
回肠末端向盲肠开口处环形肌增厚，覆以黏膜形成上、下两片半月形皱襞。既阻止小肠内容物过快流入大肠，又防止盲肠内容物反流。
:::

:::definition{label="齿状线"}
肛瓣边缘与相邻肛柱下缘构成的环形齿状缘。齿状线上下的动脉来源、静脉回流、淋巴引流、神经分布都不同；也是内痔与外痔、黏膜与皮肤的分界。内痔一般不痛，外痔常痛，神经支配在这条线上换班。
:::

:::definition{label="肝门"}
肝脏面近似 “H” 形沟中的横沟称第一肝门，是肝固有动脉左、右支，肝门静脉左、右支，肝左、右管以及神经、淋巴管出入肝的部位。肝静脉出肝走第二肝门（腔静脉沟上部），不要把两扇门写成同一条沟。
:::

:::definition{label="Calot 三角（胆囊三角）"}
由胆囊管、肝总管和肝的脏面围成。胆囊动脉一般在此三角内经过，是胆囊手术中寻找胆囊动脉的标志。三边缺任何一边，术中定位就不可靠。
:::

:::compare{title="肝门与胆囊三角不要并"}
| | 肝门（第一肝门） | Calot 三角 |
|--|------------------|------------|
| 围成 | 脏面横沟 | 胆囊管 + 肝总管 + 肝脏面 |
| 出入 / 内容 | 固有动脉、门静脉、肝管、神经、淋巴 | 胆囊动脉经过 |
| 临床 | 入肝管道 | 胆囊切除找胆囊动脉 |
:::

## 三、呼吸与胸膜：纵隔、隐窝、声门

:::definition{label="鼻旁窦"}
上颌骨、额骨、筛骨、蝶骨内的骨腔，位于鼻腔周围并开口于鼻腔，有发音共鸣和减轻颅骨重量的作用。开口要分户：额窦、前中筛窦、上颌窦开中鼻道；后筛窦开上鼻道；蝶窦开蝶筛隐窝。上颌窦口高于窦底，直立位引流最差。
:::

:::definition{label="易出血区（Little 区）"}
鼻中隔前下部血管丰富、位置浅表，干燥或外伤时易出血，约 90% 的鼻出血发生于此。不要把「鼻出血」笼统写成下鼻甲。
:::

:::definition{label="声带"}
声韧带 + 声带肌 + 喉黏膜。三条缺一不可；只写声韧带，肌和黏膜两本账会丢。
:::

:::definition{label="声门裂"}
两侧声襞、杓状软骨底和声带突之间的裂隙，是喉腔最狭窄处。异物、水肿、痉挛卡呼吸，首先卡在这里。
:::

:::definition{label="喉室"}
喉中间腔两侧、前庭襞与声襞之间的裂隙称喉室。它是中间腔向外侧的隐窝，不是声门裂的别名。
:::

:::definition{label="纵隔"}
左、右纵隔胸膜之间的全部器官、结构与结缔组织的总称。纵隔不是一个空腔，而是一堆器官加结缔组织；胸膜腔才是负压间隙。
:::

:::definition{label="胸膜腔"}
脏胸膜与壁胸膜之间密闭、狭窄、呈负压的腔隙，内有少量浆液减少摩擦。左右各一，互不相通。
:::

:::definition{label="胸膜隐窝"}
不同部位壁胸膜折返并相互移行处的胸膜腔，即使深吸气时肺缘也达不到其内。包括肋膈隐窝、肋纵隔隐窝、膈纵隔隐窝。肋膈隐窝最低最大，是胸腔积液首先充满、穿刺抽液常选的地方。膈纵隔隐窝仅在左侧。
:::

:::pitfall{label="纵隔不是胸膜腔"}
纵隔是「左右纵隔胸膜之间的内容物总称」；胸膜腔是脏、壁胸膜之间的负压间隙。把纵隔写成空腔，心、气管、胸主动脉就没有户头。
:::

## 四、泌尿与生殖、腹膜陷凹

:::definition{label="肾门"}
肾内侧缘中部的凹陷，为肾的血管、神经、淋巴管及肾盂出入之门户。
:::

:::definition{label="肾蒂"}
出入肾门的肾动脉、肾静脉、肾盂、神经和淋巴管等合称肾蒂。排列：从前向后为肾静脉、肾动脉、肾盂；从上向下为肾动脉、肾静脉、肾盂。右侧肾蒂较短。
:::

:::definition{label="肾窦"}
由肾门伸入肾实质的凹陷，被肾血管、肾小盏、肾大盏、肾盂和脂肪占据，是肾门向内的延续。肾门是门口，肾窦是门厅。
:::

:::definition{label="肾区"}
竖脊肌外侧缘与第 12 肋之间的夹角，又称脊肋角。深面为肾门和肾的内侧缘；某些肾病此处可有叩击痛。
:::

:::keypoint{label="肾三户：门、蒂、窦、区"}
- 肾门：内侧缘凹陷，是门户
- 肾蒂：进出门的管道束，有前→后、上→下两套顺序
- 肾窦：门向实质内延伸的腔
- 肾区：体表叩击的脊肋角
:::

:::definition{label="膀胱三角"}
膀胱底内面，两侧输尿管口与尿道内口围成的三角形区域。缺少黏膜下层，无论充盈或空虚都保持平滑，是肿瘤、结核、炎症的好发区。
:::

:::definition{label="输尿管间襞"}
膀胱内面两输尿管口之间的横行皱襞，是膀胱镜检查时寻找输尿管口的标志。
:::

:::definition{label="子宫峡"}
子宫颈阴道上部的上端与子宫体相接处较狭细。非妊娠期不明显，妊娠末期可延长至 7～11 cm，峡壁变薄，剖宫产术常在此进行。不要把峡部写成宫颈阴道部。
:::

:::definition{label="阴道穹"}
阴道上端包绕子宫颈阴道部，二者间形成环形凹陷，分前、后和两个侧部。后部最深，紧邻直肠子宫陷凹，临床上可经此后穹穿刺或引流陷凹内积液。
:::

:::definition{label="卵巢悬韧带"}
又称骨盆漏斗韧带，起自小骨盆侧壁，向内下至卵巢输卵管端的腹膜皱襞，内含卵巢血管、神经、淋巴管、结缔组织和少量平滑肌，是寻找卵巢血管的标志。
:::

:::definition{label="直肠子宫陷凹"}
女性盆腔内，腹膜在直肠与子宫之间移行折返形成的陷凹，又称 Douglas 腔，是女性腹膜腔的最低点。站立或半卧时积液、积血先到这里；后穹穿刺抽的就是这一窝。
:::

:::definition{label="肝肾隐窝"}
位于肝右叶与右肾之间，左界为网膜孔和十二指肠降部，右界为右结肠旁沟。仰卧时是腹膜腔的最低部位。胃后壁穿孔的内容物经网膜孔可到此处。
:::

:::compare{title="两个「腹膜腔最低点」不要抢"}
| 体位 | 最低点 | 临床 |
|------|--------|------|
| 仰卧 | 肝肾隐窝 | 上腹积液、穿孔物流向 |
| 坐 / 半卧 / 女性直立 | 直肠子宫陷凹（女）或直肠膀胱陷凹（男） | 后穹穿刺、腹膜炎半卧位让积液积在盆底 |
:::

## 五、脉管系统：循环、瓣膜复合体、淋巴结

:::definition{label="体循环"}
血液由左心室搏出，经主动脉及其分支到达全身毛细血管，与组织细胞进行物质和气体交换，再经各级静脉，最后经上、下腔静脉及心冠状窦返回右心房。路程长、范围广，以动脉血滋养全身，并把代谢产物和二氧化碳运回心。
:::

:::definition{label="肺循环"}
血液由右心室搏出，经肺动脉干及其各级分支到达肺泡毛细血管进行气体交换，再经肺静脉进入左心房。路程短，只通过肺，使静脉血转变成氧饱和的动脉血。
:::

:::pitfall{label="肺动脉里走的是静脉血"}
「动脉」按离心定义，不按含氧量。肺动脉离心、走静脉血；肺静脉回心、走动脉血。写成「动脉里一定是动脉血」，体、肺循环两本账都会乱。
:::

:::definition{label="心传导系"}
由特殊心肌细胞构成，包括窦房结、结间束、房室交界区、房室束、左右束支和 Purkinje 纤维网，产生并传导兴奋，控制心的节律性活动。它是心肌特化细胞，不是植物神经纤维。
:::

:::definition{label="Koch 三角"}
右心房内，冠状窦口前内缘、三尖瓣隔侧尖附着缘和 Todaro 腱之间的三角。前部心内膜深面为房室结。导管消融靠近此区时要知道深面是房室结。
:::

:::definition{label="三尖瓣复合体"}
三尖瓣环、瓣尖、腱索和乳头肌在结构和功能上是一个整体，共同保证血液单向流动。任何一部分损伤都会改变血流动力学。
:::

:::definition{label="二尖瓣复合体"}
二尖瓣环、二尖瓣、腱索和乳头肌，同样保证左房室口的单向流动。两套复合体的零件名单平行，只是左右房室口不同。
:::

:::definition{label="心包腔"}
浆膜心包脏、壁两层之间的潜在性腔隙，内含少量浆液起润滑作用。
:::

:::definition{label="心包横窦"}
心包腔在主动脉、肺动脉后方与上腔静脉、左心房前壁前方之间的间隙。心脏手术可在此钳夹大血管。
:::

:::definition{label="掌浅弓"}
由尺动脉末端与桡动脉掌浅支吻合而成，位于掌腱膜深面，弓的凸缘约平掌骨中部。
:::

:::definition{label="掌深弓"}
由桡动脉末端与尺动脉掌深支吻合而成，位于指深屈肌腱深面，弓的凸缘约平腕掌关节高度。浅弓以尺动脉为主，深弓以桡动脉为主，深浅不要写反。
:::

:::definition{label="危险三角"}
鼻根至两侧口角的三角区。面静脉缺乏静脉瓣，并与颅内海绵窦交通，面部化脓性感染处理不当可导致颅内感染。切忌挤压该区疖肿。
:::

:::definition{label="静脉角"}
锁骨下静脉与颈内静脉在胸锁关节后方汇合成头臂静脉，汇合部称静脉角。胸导管注入左静脉角，右淋巴导管注入右静脉角。
:::

:::definition{label="颈动脉窦"}
颈总动脉末端和颈内动脉起始处的膨大，管壁有丰富的游离神经末梢，是压力感受器，可反射性减慢心率、扩张末梢血管、使血压下降。
:::

:::definition{label="局部淋巴结"}
引流某一器官或部位淋巴的第一级淋巴结，临床通常称哨位淋巴结。肿瘤转移首先到达的就是这一级。
:::

:::definition{label="Virchow 淋巴结"}
左侧斜角肌淋巴结，位于左侧前斜角肌前方。胸、腹、盆部肿瘤，尤其是食管腹段癌和胃癌，癌栓可经胸导管转移到此。左锁骨上窝无痛性肿大淋巴结，是这条户头。
:::

:::definition{label="乳糜池"}
由左、右腰干和肠干在第 1 腰椎前方汇合而成，是胸导管的起始膨大。
:::

:::definition{label="大脑动脉环（Willis 环）"}
两侧大脑前动脉、颈内动脉、大脑后动脉借前交通动脉、后交通动脉构成，位于蝶鞍上方，环绕视交叉、灰结节、乳头体周围。使两侧颈内动脉系与椎–基底动脉系相交通。正常情况下环两侧血液并不混合，而是潜在代偿装置；某处发育不良或堵塞时，血液可重新分配以维持脑供血。**大脑中动脉不参与成环。**
:::

:::pitfall{label="Willis 环不含大脑中动脉"}
成环的是大脑前、颈内、大脑后，加上前、后交通。大脑中动脉是颈内动脉的直接延续，供血范围大，但不构成环的一段。
:::

## 六、感觉器：眼与内耳

:::definition{label="结膜"}
覆盖眼睑后面和眼球前面的薄而光滑、富含血管的黏膜，分球结膜、睑结膜和结膜穹窿三部。
:::

:::definition{label="瞳孔"}
虹膜中央的圆孔，光线由此进入眼球；瞳孔括约肌和开大肌改变其大小。
:::

:::definition{label="黄斑"}
视神经盘颞侧稍下方的黄色区域，中央凹陷称中央凹，是感光最敏锐区。
:::

:::definition{label="视神经盘"}
视神经起始处境界清楚、略呈椭圆形的盘状结构，中央凹陷称视盘凹陷，有视网膜中央动、静脉穿过。此处无感光细胞，称生理性盲点。黄斑感光最敏锐，视盘完全不感光，两户不要对调。
:::

:::definition{label="巩膜静脉窦"}
靠近角膜缘处巩膜实质内呈环形的房水流出通道。房水循环的出路经过这里；阻塞可致眼压升高。
:::

:::definition{label="壶腹嵴"}
各膜半规管的膜壶腹壁上隆起的结构，是感受旋转变速运动刺激的位觉感受器。
:::

:::definition{label="螺旋器"}
内耳膜蜗管基底膜上的听觉感受器。位觉在壶腹嵴、椭圆囊斑和球囊斑；听觉在螺旋器。不要把螺旋器写成「管平衡」。
:::

:::compare{title="眼底两个「盘 / 斑」"}
| | 视神经盘 | 黄斑 / 中央凹 |
|--|----------|----------------|
| 位置 | 视神经起始 | 视盘颞侧稍下 |
| 血管 | 视网膜中央动静脉穿过 | 中央凹无血管 |
| 感光 | 无感光细胞，生理性盲点 | 最敏锐 |
:::

## 七、神经系统：灰白质术语与几个要命结构

:::definition{label="灰质"}
中枢神经系统中神经元胞体聚集处。在端脑和小脑表面铺开称皮质，在深部聚成团块或柱状称神经核。
:::

:::definition{label="神经核"}
中枢内形态、功能相近的神经元胞体聚集成的团块状或柱状结构。
:::

:::definition{label="神经节"}
周围神经系统中形态和功能相似的神经元胞体聚集处。同一件事：胞体在中枢叫核，在周围叫节。
:::

:::definition{label="纤维束"}
白质中起止、行程、功能基本相同的神经纤维集合在一起。
:::

:::definition{label="网状结构"}
中枢内神经纤维交织成网，网眼内含分散的神经元或较小核团，这些区域称网状结构。脑干网状结构参与觉醒、睡眠和对肌紧张、内脏活动的调节。
:::

:::definition{label="内侧丘系"}
薄束核、楔束核发出的传导同侧深感觉和精细触觉的二级纤维，于中央管腹外侧左右交叉（内侧丘系交叉），交叉后在中线两侧、锥体后方上行，终止于背侧丘脑腹后外侧核。交叉后才叫内侧丘系；交叉前仍是丘系交叉的内弓状纤维。
:::

:::definition{label="小脑扁桃体"}
小脑半球向前、内、下膨出的部分，靠近延髓并位于枕骨大孔附近。颅内压增高时可能被挤入枕骨大孔与延髓之间，形成小脑扁桃体疝，压迫延髓内呼吸中枢和心血管中枢，危及生命。
:::

:::definition{label="上丘脑"}
背侧丘脑与中脑顶盖前区的移行部，包括松果体、缰三角、缰连合、丘脑髓纹和后连合。
:::

:::definition{label="海马"}
在大脑颞叶，齿状回外侧卷入侧脑室下角底壁上的弓形灰质隆起。属于边缘系统相关结构，不是「脑子里的一条肌肉」。
:::

:::definition{label="内囊"}
位于背侧丘脑、尾状核和豆状核之间、投射纤维高度集中的白质板。端脑水平切面上呈 “<” 形，分前肢、膝和后肢。膝部走皮质核束，后肢走皮质脊髓束、丘脑皮质束、视辐射、听辐射等。此处出血可出现对侧偏身感觉障碍、偏瘫和偏盲（「三偏」）。
:::

:::definition{label="纹状体"}
大脑基底核中的豆状核和尾状核。尾状核和壳称新纹状体，苍白球称旧纹状体。豆状核 = 壳 + 苍白球，不要把苍白球排除在纹状体之外，也不要把杏仁体算进纹状体。
:::

:::compare{title="核、节、束、质四户"}
| 术语 | 在哪 | 是什么 |
|------|------|--------|
| 灰质 | 中枢 | 胞体聚集 |
| 皮质 | 中枢表面 | 铺开的灰质 |
| 神经核 | 中枢深部 | 团块 / 柱状灰质 |
| 神经节 | 周围 | 胞体聚集 |
| 白质 / 髓质 | 中枢 | 纤维聚集 |
| 纤维束 | 中枢白质 | 起止行程功能相同的纤维 |
:::
