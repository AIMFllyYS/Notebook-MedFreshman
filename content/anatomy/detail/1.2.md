# 1.2 复习提纲与考点：按系统把简答和病例收成一张网

复习提纲、国家题库考纲、考点词、理论考试回忆、短复习稿问的是同一批结构，只是切口不同：有的要你「以胸椎为例描述」，有的要你「右侧面瘫出现什么」，有的要你默英文。本篇不把五份提纲原文并排粘贴，而是按运动、内脏、脉管、感觉器、神经把高频简答收成可默写的考点网。传导通路、淋巴回流、十二对脑神经和臂丛分支用思维导图钉位置。

:::insight{label="提纲题怎么答"}
提纲几乎都是「构成 + 特点 + 临床」。构成要写全零件，特点只写与运动或疾病相关的那几条，临床只写提纲点名的脱位、狭窄、疝和损伤。不要把教材整节搬进一份简答。
:::

## 一、运动系统：骨、连结、肌、局部层次

成人骨 206 块。以长骨为例：一体两端，骨干有髓腔，骺幼年借骺软骨连于骨干，成年骨化成骺线。构造三件套是骨质（密质 / 松质）、骨膜（关节面除外）、骨髓（红 / 黄）。化学成分：有机质赋予弹性，无机质赋予硬度；幼儿约各半，易青枝骨折；成人无机质比例升高，易完全骨折。

椎骨一般形态以胸椎为模板：椎体 + 椎弓，围成椎孔；椎弓发出一对棘突、一对横突、两对关节突。颈椎有横突孔，寰椎无椎体、枢椎有齿突、隆椎棘突易触及。椎体之间借椎间盘（纤维环 + 髓核）以及前、后纵韧带相连；椎弓之间借黄韧带、棘间韧带、棘上韧带和关节突关节相连。脊柱由 24 块椎骨 + 骶骨 + 尾骨借骨连结而成，有颈、胸、腰、骶四个生理弯曲：颈曲、腰曲凸向前，胸曲、骶曲凸向后。

:::definition{label="胸廓"}
由 12 块胸椎、12 对肋和 1 块胸骨连结构成。上口：胸骨柄上缘、第 1 肋、第 1 胸椎体；下口：第 12 胸椎、第 11 及 12 肋前端、肋弓和剑突，由膈封闭。
:::

:::definition{label="骨盆"}
由左、右髋骨和骶、尾骨及其骨连结构成。界线以上为大骨盆，以下为小骨盆。
:::

肩关节由肱骨头与肩胛骨关节盂构成，是典型多轴球窝关节。关节盂浅小，关节囊薄而松弛，下壁最薄弱，肱骨头易向前下方脱位。可作屈伸、收展、旋内旋外及环转。髋关节由股骨头与髋臼构成，髋臼深、有髋臼唇，囊外有髂股韧带等加强，稳度大于肩，灵活度小于肩。膝关节由股骨内、外侧髁，胫骨内、外侧髁和髌骨构成，是人体最大最复杂的关节；囊内有前、后交叉韧带和内、外侧半月板。

:::compare{title="肩关节与髋关节（提纲常考对照）"}
| | 肩关节 | 髋关节 |
|--|--------|--------|
| 构成 | 肱骨头 + 关节盂 | 股骨头 + 髋臼 |
| 头窝匹配 | 头大、盂浅 | 头圆、臼深，有髋臼唇 |
| 囊 | 薄而松弛，下壁弱 | 坚韧，髂股韧带限制过伸 |
| 脱位 | 前下方 | 相对少；后脱位可见 |
| 运动 | 全身最灵活，三轴 + 环转 | 三轴但幅度较小 |
:::

:::keypoint{label="运动系统提纲高频"}
- 骨构造三件套；幼儿有机质相对多
- 脊柱：24 + 骶 + 尾；四弯；椎间盘 23 个
- 肩易前下脱位；膝有交叉韧带和半月板
- 斜角肌间隙：臂丛 + 锁骨下动脉
- 腕管：腕骨沟 + 屈肌支持带，走指浅、指深屈肌腱、拇长屈肌腱和正中神经
:::

肌学提纲反复点名：咀嚼肌四块（咬肌、颞肌、翼内肌、翼外肌），翼外肌双侧收缩张口。胸锁乳突肌一侧收缩使头向同侧倾斜、面转向对侧；两侧同时收缩使头后仰。膈有三个裂孔：主动脉裂孔约平 T12，走主动脉和胸导管；食管裂孔约平 T10，走食管和迷走神经；腔静脉裂孔约平 T8，走下腔静脉。小腿三头肌 = 腓肠肌 + 比目鱼肌。

腹壁层次是提纲里的「刀口题」。经腹壁正中切口：皮肤 → 浅筋膜 → 白线 → 腹横筋膜 → 腹膜外筋膜 → 壁腹膜。脐上经腹直肌切口还要穿过腹直肌鞘前层、腹直肌、鞘后层。阑尾切口（麦氏点）穿过腹外斜肌腱膜、腹内斜肌、腹横肌，没有腹直肌鞘。海氏三角是直疝出口；斜疝走腹股沟管。

:::pitfall{label="面肌瘫痪对侧还是同侧"}
面神经管外损伤是同侧眼裂不能闭合、口角被拉向健侧、额纹消失。把「口角歪向患侧」写进去就反了：口角是被健侧面肌拉过去的。伸舌偏向患侧是颏舌肌，和面肌不是同一条神经。
:::

:::memory{label="运动系统刀口与脱位"}
- [ ] 正中切口走白线，没有腹直肌
- [ ] 阑尾切口没有腹直肌鞘
- [ ] 直疝：海氏三角；斜疝：腹股沟管
- [ ] 肩关节前下方脱位
- [ ] 膈裂孔：T12 主动脉，T10 食管 + 迷走，T8 腔静脉
:::

## 二、内脏学：消化、呼吸、泌尿生殖、腹膜

舌乳头：丝状、菌状、轮廓、叶状。味蕾主要在菌状、轮廓、叶状乳头，丝状乳头管一般感觉、不管味觉。一侧颏舌肌瘫痪，伸舌时舌尖偏向患侧。

大消化腺：三对大唾液腺 + 肝 + 胰。腮腺管开口于平对上颌第 2 磨牙的颊黏膜；下颌下腺管和舌下腺大管开口于舌下阜。肝分泌胆汁，经肝管 → 肝总管，胆囊贮存浓缩胆汁；排入十二指肠时走胆囊管 + 肝总管 → 胆总管，与胰管汇合开口于十二指肠大乳头（降部后内侧壁）。

:::keypoint{label="食管三狭窄"}
- 起始处，约平 C6，距中切牙约 15 cm
- 与左主支气管交叉处，约 25 cm
- 穿膈处，约平 T10，约 40 cm
:::

十二指肠分上部、降部、水平部、升部；上部近侧称十二指肠球，是溃疡好发处。结肠带、结肠袋、肠脂垂只属于盲肠和结肠，不是直肠的特征。阑尾根部体表投影在麦氏点（右髂前上棘与脐连线中外 1/3 交点）。

鼻旁窦开口见 1.1。喉软骨主要有甲状软骨、环状软骨、会厌软骨和成对杓状软骨。喉腔分喉前庭、喉中间腔、声门下腔。右主支气管短、陡、粗，气管异物易坠入右肺。肺门通行结构：支气管、肺动脉、肺静脉、神经和淋巴管。支气管肺段是每一段支气管及其所属肺组织的总称。

:::definition{label="肾被膜三层"}
由内向外：纤维囊、脂肪囊、肾筋膜。肾筋膜下方开放，是肾下垂的解剖学基础；肾上腺在肾筋膜内、肾的上方，不随肾下垂。
:::

输尿管三狭窄：肾盂移行处、跨过髂血管处、壁内部。膀胱三角见 1.1。男性尿道长约 16～22 cm，三狭窄（尿道内口、膜部、尿道外口最窄），三膨大（前列腺部、尿道球部、舟状窝），两弯曲（耻骨下弯恒定，耻骨前弯可消失）。精子通路：精曲小管 → 精直小管 → 睾丸网 → 睾丸输出小管 → 附睾 → 输精管 → 射精管 → 尿道。输卵管分输卵管漏斗、壶腹、峡和子宫部；壶腹是受精部位，峡部是结扎部位。子宫固定：阔韧带限制侧移，圆韧带维持前倾，主韧带防止脱垂，骶子宫韧带协同后倾后屈的平衡。

:::definition{label="小网膜"}
肝门至胃小弯和十二指肠上部之间的双层腹膜，分肝胃韧带和肝十二指肠韧带。肝十二指肠韧带内有胆总管、肝固有动脉和肝门静脉（前右、前左、后方）。
:::

胃后壁穿孔，胃内容物先入网膜囊，可经网膜孔到肝肾隐窝。腹膜炎取半卧位，是为了让炎性渗出积在盆腔最低点，减轻膈下感染。

:::pitfall{label="胆汁不是胆囊制造的"}
胆汁在肝细胞产生，胆囊只贮存浓缩。排出路径要会画箭头：肝 → 肝管 → 肝总管 →（贮存时进胆囊管）胆囊；进食时胆囊管回流 → 胆总管 → 肝胰壶腹 → 十二指肠大乳头。
:::

## 三、脉管系统：心、血管、淋巴

二尖瓣、三尖瓣复合体均包括瓣环、瓣膜、腱索、乳头肌。心传导系见 1.1。营养心的动脉是左、右冠状动脉，起于主动脉窦。供给胃的动脉来自腹腔干的胃左动脉，以及肝总动脉发出的胃右动脉、胃十二指肠动脉的胃网膜右动脉，脾动脉发出的胃网膜左动脉和胃短动脉。

大隐静脉起于足背静脉弓内侧，经内踝前方上行，沿小腿、大腿内侧至隐静脉裂孔注入股静脉；属支有旋髂浅静脉、腹壁浅静脉、阴部外静脉、股内侧浅静脉、股外侧浅静脉。肝门静脉由肠系膜上静脉与脾静脉在胰颈后方汇合，收集腹腔不成对脏器（除肝以外）的静脉血；与上、下腔静脉的交通主要在食管静脉丛、直肠静脉丛、脐周静脉网和腹后壁。

:::keypoint{label="九条淋巴干与两条导管"}
成对：颈干、锁骨下干、支气管纵隔干、腰干；不成对：肠干。左颈干、左锁骨下干、左支气管纵隔干、肠干和两侧腰干多注入胸导管；右颈干、右锁骨下干、右支气管纵隔干注入右淋巴导管。胸导管起于乳糜池（约平 T12 / L1），注入左静脉角。
:::

::figure{src="/images/anatomy/detail/lymph.jpg" caption="淋巴系统：毛细淋巴管→淋巴管→九条淋巴干→胸导管/右淋巴导管，以及全身淋巴结分群。" alt="淋巴管道四级和头颈、腋、腹股沟等淋巴结分群思维导图"}

局部淋巴结是第一级哨位淋巴结。Virchow 淋巴结见 1.1。颈动脉窦是压力感受器，颈动脉小球是化学感受器，动脉韧带是胚胎动脉导管闭锁的遗迹，连于肺动脉干分叉处稍左侧与主动脉弓下缘之间。

:::compare{title="颈动脉窦与颈动脉小球"}
| | 颈动脉窦 | 颈动脉小球 |
|--|----------|------------|
| 位置 | 颈总动脉末端 / 颈内动脉起始膨大 | 颈内、外动脉分叉处后方 |
| 性质 | 压力感受器 | 化学感受器 |
| 效应 | 降压、减慢心率 | 感受血氧、二氧化碳、H+ |
:::

## 四、感觉器：眼球壁、房水、眼外肌、内耳

眼球壁分外膜（角膜 + 巩膜）、中膜（虹膜、睫状体、脉络膜）、内膜（视网膜）。屈光装置：角膜、房水、晶状体、玻璃体，均透明无血管。房水由睫状体产生 → 眼后房 → 瞳孔 → 眼前房 → 虹膜角膜角 → 巩膜静脉窦 → 静脉。

:::keypoint{label="眼外肌神经支配"}
- 动眼神经：上睑提肌、上直肌、下直肌、内直肌、下斜肌；副交感支配瞳孔括约肌和睫状肌
- 滑车神经：上斜肌（使瞳孔转向下外）
- 展神经：外直肌
口诀「上斜滑车外直展，其余都是动眼管」只记支配，不代替作用方向。
:::

鼓室内容：三块听小骨（锤、砧、镫）、韧带、肌（鼓膜张肌、镫骨肌）、血管神经和空气。咽鼓管连通鼓室与鼻咽。听觉感受器是螺旋器（膜蜗管基底膜）；位觉感受器是壶腹嵴（旋转变速）以及椭圆囊斑、球囊斑（直线变速和头的位置）。

## 五、神经系统：脊髓、脑、内囊、脑脊液、损伤定位

成人脊髓下端约平 L1 下缘（小儿略低）。胸髓灰质：前角运动、后角感觉、侧角（中间带外侧核）交感节前神经元。脑分端脑、间脑、小脑、中脑、脑桥、延髓；脑干 = 中脑 + 脑桥 + 延髓。脑神经连于脑干的规律：中脑连 III、IV；脑桥连 V、VI、VII、VIII；延髓连 IX、X、XI、XII；I 连端脑，II 连间脑。

语言运动中枢（说话中枢）在额下回后部，书写中枢在额中回后部，听觉性语言中枢在颞上回后部，视觉性语言中枢在角回——优势半球。内囊位于丘脑、尾状核与豆状核之间，水平切面呈 “<” 形。膝部走皮质核束；后肢走皮质脊髓束、丘脑皮质束、视辐射等。右侧内囊出血：左侧偏身感觉障碍、左侧偏瘫、双眼对侧同向性偏盲（三偏）。左侧大脑中动脉皮质支根部血栓：优势半球还可叠加失语。

:::compare{title="上、下运动神经元损伤"}
| | 上运动神经元 | 下运动神经元 |
|--|--------------|--------------|
| 损伤部位 | 皮质锥体细胞或锥体束 | 脊神经前角 / 脑神经运动核及其轴突 |
| 瘫痪 | 痉挛性（硬瘫） | 弛缓性（软瘫） |
| 肌张力 | 增高 | 降低 |
| 腱反射 | 亢进 | 减弱或消失 |
| 病理反射 | 阳性 | 阴性 |
| 肌萎缩 | 不明显 | 明显 |
:::

右侧视束或右枕叶损伤：双眼左侧同向性偏盲。视交叉中部（鼻侧纤维交叉处）损伤则是双眼颞侧偏盲。脑脊液：侧脑室脉络丛产生 → 室间孔 → 第三脑室 → 中脑水管 → 第四脑室 → 正中孔和外侧孔 → 蛛网膜下隙 → 蛛网膜粒回流入上矢状窦。
