一、上肢肌——上肢带肌与肌腱袖

1.1 上肢带肌（6块）

均起自上肢带骨（肩胛骨和锁骨），配布于肩关节周围，止于肱骨。功能是运动肩关节、增强肩关节稳定性。

三角肌起锁骨外侧端、肩峰、肩胛冈 → 止肱骨三角肌粗隆。整体收缩外展；前束屈+旋内；后束伸+旋外。腋神经支配。瘫痪→方肩畸形
肩胛下肌起肩胛下窝 → 止肱骨小结节
冈上肌起冈上窝 → 止肱骨大结节上部。从喙肩韧带下方穿过（不是上面绕过），贴着关节囊走行
冈下肌起冈下窝 → 止肱骨大结节
小圆肌起肩胛骨外侧缘靠上 → 止肱骨大结节
大圆肌止肱骨小结节下方（小结节嵴）。不参与肌腱袖构成
考试范围说明
上肢带肌的起止点不属于考试范围，支配神经待神经系统模块统一学习，无需提前记忆。重点掌握肌腱袖构成和三角肌瘫痪表现。

1.2 肌腱袖（肩袖/旋转袖）

核心考点
构成：肩胛下肌 + 冈上肌 + 冈下肌 + 小圆肌的肌腱
不含：大圆肌（关键考点）
结构：肌腱与肩关节囊纤维融合交织，像袖子一样包裹肩关节
功能：加强肩关节稳固性，防止脱位
临床：肩袖损伤常见，冈上肌肌腱最易受损（穿过喙肩韧带下方，易受挤压）

二、上肢肌——臂肌与前臂肌

2.1 臂肌（前群3块 + 后群1块）

以深筋膜的内侧肌间隔和外侧肌间隔分隔为前后群。

前群

肱二头肌长头穿结节间沟（滑膜鞘包裹）→ 盂上结节；短头起喙突。止桡骨粗隆（主腱）+前臂尺侧筋膜（腱膜）。功能：屈肘+协助屈肩
喙肱肌起喙突 → 止肱骨体中部内侧。不跨过肘关节，只参与肩关节运动。为什么是臂肌？肌腹在上臂（判断标准是肌腹位置，不是功能）
肱肌起肱骨体下半前面 → 止尺骨粗隆。只跨过肘关节。功能：屈肘。与肱二头肌是协同肌

后群

肱三头肌长头起盂下结节；内侧头起桡神经沟内下方；外侧头起桡神经沟外下方。止尺骨鹰嘴。功能：伸肘；长头协助肩内收后伸
对比记忆
肱二头肌长头 → 盂上结节；肱三头肌长头 → 盂下结节。一个在上一个在下，别记反。

2.2 前臂肌（前群4层9块 + 后群2层10块）

前群（屈肌群）

层次肌肉要点
第一层（浅）肱桡肌、旋前圆肌、桡侧腕屈肌、掌长肌、尺侧腕屈肌肱桡肌不跨腕关节，仅屈肘（桡神经支配）
第二层指浅屈肌止中节指骨，只能屈近侧指间关节
第三层拇长屈肌、指深屈肌指深屈肌止远节指骨，能屈近侧+远侧指间关节
第四层旋前方肌紧贴桡尺骨远端，前臂旋前

后群（伸肌群）

浅层5块以伸肌总腱共同起自肱骨外上髁：桡侧腕长伸肌、桡侧腕短伸肌、指伸肌、小指伸肌、尺侧腕伸肌。深层5块对照教材了解。

腕关节运动总结
屈=前群；伸=后群；内收（尺偏）=尺侧腕屈肌+尺侧腕伸肌；外展（桡偏）=桡侧腕屈肌+桡侧腕长/短伸肌。腕关节是椭圆关节，不能旋转

2.3 手肌

鱼际群（外侧）4块，使拇指展/屈/对掌/收。拇指对掌的解剖学基础：第一掌骨发育时轴就有90度角度
小鱼际群（内侧）3块，使小指屈/外展/对掌。小指对掌不典型
中间群蚓状肌4块+骨间掌侧肌3块+骨间背侧肌4块，手指精细运动控制

三、上肢局部解剖

3.1 腋窝

顶锁骨 + 肩胛骨上缘（上角）+ 第一肋骨上面
前壁胸大肌 + 胸小肌
后壁肩胛下肌 + 大圆肌 + 背阔肌 + 肩胛骨
内侧壁上部胸壁 + 前锯肌。前锯肌瘫痪→翼状肩畸形（肩胛骨不能贴胸廓）
外侧壁喙肱肌 + 肱二头肌短头 + 肱骨
内容腋动脉、腋静脉、臂丛及其分支

三角胸肌肩沟：三角肌和胸大肌之间，有头静脉走行。

3.2 三边孔与四边孔

结构围成穿行结构
三边孔小圆肌（上）+ 大圆肌（下）+ 肱三头肌长头（外侧）旋肩胛动脉
四边孔上述三边 + 肱骨（外侧）旋肱后动脉 + 腋神经
助记口诀
三边旋肩胛，四边旋肱后加腋神经。四边比三边多一个肱骨，所以多一个腋神经。

3.3 肘窝

肘关节前方，皮肤深面无肌肉，有血管神经。穿行结构（从外向内）：

  1. 肱二头肌肌腱（止于桡骨粗隆）
  2. 肱动脉
  3. 肱静脉
  4. 正中神经

3.4 腕管

核心考点
构成：屈肌支持带（腕横韧带，腕部深筋膜增厚）+ 腕骨沟围成的骨性纤维管道
穿行：指浅屈肌腱4条 + 指深屈肌腱4条 + 拇长屈肌腱1条 + 正中神经 = 9条肌腱 + 1条神经
腕管综合征：正中神经受压 → 拇指、食指、中指麻木疼痛
割腕：一般不致死，多仅导致手部瘫痪（正中神经损伤），出血量通常不足以致死

四、下肢肌——髋肌

下肢肌比上肢肌粗大，功能是维持直立姿势、支持体重、行走。对应关系：上肢带肌↔髋肌，臂肌↔大腿肌，前臂肌↔小腿肌，手肌↔足肌。

4.1 髋肌前群（2块）

髂腰肌

构成腰大肌 + 髂肌（两个相对独立的肌腹，有共同止点）
为什么是两块肌腹不融合（与肱二头肌不同，肱二头肌肌腹在一起）
起点腰大肌起腰椎椎体侧面和横突；髂肌起髂窝
走行汇合后经腹股沟韧带深面穿出
止点股骨小转子
功能髋关节前屈和旋外；下肢固定时使躯干前屈（如仰卧起坐）

腰小肌：在腰大肌表面，斜向下，作用是紧张髂筋膜（非重点）。

阔筋膜张肌

位置大腿上部前外侧
起点髂前上棘
走行肌腹在阔筋膜两层之间，向下移行为髂胫束
止点胫骨外侧髁（通过髂胫束）
特点肌腹只在大腿上1/3，下方变为坚韧的肌腱（髂胫束）
功能紧张阔筋膜 + 屈髋

4.2 髋肌后群（7块，多位于臀部）

肌肉起点止点功能
臀大肌髂骨翼外面+骶骨背面髂胫束+臀肌粗隆髋伸+旋外
臀中肌髂骨翼外面股骨大转子髋外展（前束旋内/后束旋外）
臀小肌髂骨翼外面股骨大转子同臀中肌（完全并行）
梨状肌盆内骶骨前面股骨大转子髋外展+旋外。穿坐骨大孔，分上下孔
闭孔内肌闭孔膜内面转子窝髋旋外（经坐骨小孔出孔）
股方肌坐骨结节转子间嵴髋旋外
闭孔外肌闭孔膜外面转子窝髋旋外
臀中肌/臀小肌特点
二者完全并行，臀中肌更大。只有髂骨翼起点（没有骶骨背面，与臀大肌不同）。类似三角肌：跨的范围大，前后部肌束功能相反（前束旋内，后束旋外）。

五、下肢肌——大腿肌与小腿肌

5.1 大腿肌前群（2块）

缝匠肌

地位全身最长的肌（注意：竖脊肌是躯干最长的肌肉，且有多个止点；缝匠肌起止点各一个）
起点髂前上棘
止点胫骨上端内侧
走行斜过大腿前面
功能屈髋关节 + 屈膝关节 + 使已屈的膝关节旋内
命名由来缝匠（裁缝）肌，因裁缝盘腿坐姿时该肌处于紧张状态

股四头肌

构成四块独立肌肉，下端肌腱融合
股直肌起髂前下棘（注意：缝匠肌是髂前上棘）
股内侧肌起股骨粗线内侧唇
股外侧肌起股骨粗线外侧唇
股中间肌起股骨前面（在股直肌深面）
止点四头向下包绕髌骨，形成髌韧带，止于胫骨粗隆
髌韧带就是股四头肌的肌腱（内含髌骨），膝跳反射即敲击髌韧带引出
功能股直肌：屈髋（因到髂骨）；其余三块：伸膝（因跨过膝关节）

5.2 大腿肌内侧群（内收肌群，5块）

共同特点：均起自闭孔周围。

  • 耻骨肌：止于耻骨肌线
  • 股薄肌：止于胫骨上端内侧（唯一止于胫骨的内收肌）
  • 长收肌、短收肌、大收肌：止于股骨粗线。大收肌还止收肌结节（股骨内上髁上方）

功能：髋关节内收 + 旋转。

5.3 大腿肌后群（腘绳肌，3块）

肌肉起点止点
半腱肌坐骨结节胫骨上端内侧
半膜肌坐骨结节胫骨内侧髁（靠后）
股二头肌长头：坐骨结节；短头：股骨粗线腓骨（外侧）

功能：屈膝 + 伸髋。

记忆口诀
半膜半腱在内侧（胫骨），股二头在外侧（腓骨）。共同起点坐骨结节（股二头肌短头除外）。

5.4 小腿肌

分组前群、外侧群、后群（内侧群无肌肉，胫骨直接在皮下）
前群（3块）胫骨前肌（伸踝+足内翻）、趾长伸肌（伸踝+伸第2-4趾）、拇长伸肌（伸踝+伸拇指）
外侧群（2块）腓骨长肌+腓骨短肌。功能：足外翻+屈踝。重要功能：维持足横弓
后群浅层小腿三头肌=腓肠肌（外侧，浅层）+比目鱼肌（内侧，深层）
跟腱小腿三头肌下端肌腱融合，止于跟骨。人体最粗大的肌腱
小腿三头肌功能屈踝 + 屈膝 + 维持直立
后群深层跖肌、胫骨后肌、趾长屈肌、拇长屈肌。功能：屈踝、屈趾、足内翻
注意
下肢的"趾"和"拇"与上肢不同，别弄错（上肢是"指"和"拇"）。足弓三条：内侧纵弓、外侧纵弓、横弓。

六、下肢局部解剖

6.1 梨状肌上孔与下孔

梨状肌起自骶骨前面，穿坐骨大孔，将坐骨大孔分为上下两部分。

坐骨大孔围成坐骨大切迹 + 骶棘韧带
坐骨小孔围成骶棘韧带 + 骶结节韧带 + 坐骨小切迹
孔穿行结构
梨状肌上孔臀上血管（动脉、静脉）+ 臀上神经
梨状肌下孔坐骨神经（最粗大）+ 股后皮神经 + 臀下血管神经 + 阴部血管神经
临床联系
梨状肌综合征：梨状肌痉挛或肥厚压迫坐骨神经，导致下肢放射痛。坐骨神经是人体最粗大的神经，从梨状肌下孔穿出后一直在下肢后面走行。

6.2 肌腔隙与血管腔隙

位置：腹股沟韧带与髋骨之间的腔隙。分隔：髂耻弓（中间的韧带）。

腔隙位置穿行结构
肌腔隙后上侧髂腰肌 + 股神经（股神经从前边出来）
血管腔隙前内侧股动脉 + 股静脉 + 股管

股管与股疝

股管位置股静脉内侧，是一个盲管（不通到其他地方，下端盲端）
股管内容少量淋巴结和脂肪组织
股环股管上端开口
股疝腹腔器官经股环→股管突出，在大腿根部形成鼓包。股疝女性多见（关键考点）

股管四壁

前壁腹股沟韧带
后壁耻骨梳韧带
内侧壁腔隙韧带（又名旋窝韧带，是腹股沟韧带连向耻骨梳的片状韧带）
外侧壁股动静脉的血管鞘
股管四壁口诀
前腹股沟后耻骨梳，内腔隙外血管鞘，股疝女多见。

其他疝类型：腹股沟斜疝（经腹股沟管突出，男性可降至阴囊）、腹股沟直疝（经海氏三角从后向前突出）。

七、下肢局部解剖（续）

7.1 股三角

位置大腿前上部
上界腹股沟韧带
内侧界长收肌内侧缘
外侧界缝匠肌内侧缘
前壁阔筋膜（大腿深筋膜）+ 皮肤
后壁（底）髂腰肌、耻骨肌、长收肌
穿行结构（外→内）股神经 → 股动脉 → 股静脉 → 淋巴结

股神经下行后像扫把一样分散，其中最长的分支是隐神经。

7.2 收肌管（Hunter管）

位置大腿中部前内侧，股三角下方
前壁大收肌腱膜（板腱）
后壁大收肌
外侧壁股内侧肌
上口股三角尖（与股三角相通）
下口通腘窝
关键考点
只有股动脉、股静脉穿收肌管向后入腘窝。
隐神经从收肌管前壁（大收肌腱膜）穿出，不入腘窝。
这是考试高频考点，务必记住隐神经的特殊走行。

7.3 腘窝

位置膝关节后方（菱形凹陷）
上外侧界股二头肌
上内侧界半膜肌、半腱肌
下外侧界腓肠肌外侧头
下内侧界腓肠肌内侧头
穿行结构（浅→深）坐骨神经（最浅层，一直从后边走行下来）→ 腘动脉（股动脉移行）→ 腘静脉（股静脉移行）
腘窝边界口诀
上外股二头，上内半膜半腱，下外下内腓肠肌两头。

八、标本实操要点

8.1 腹直肌鞘与弓状线

弓状线位置肚脐以下4-5cm（又名半环线）
意义腹直肌鞘后壁的下界
部位前层构成后层构成
弓状线以上腹外斜肌腱膜 + 腹内斜肌腱膜前层腹内斜肌腱膜后层 + 腹横肌腱膜
弓状线以下三块肌肉腱膜都只构成前层无鞘后壁，腹直肌后面直接是腹横筋膜

标本观察：腹直肌鞘后壁在下1/3缺失，可见弓状线的弧形边缘。

8.2 腹壁三层扁肌

腹外斜肌最浅层，肌纤维从外上斜向内下。下缘腱膜增厚 → 腹股沟韧带（髂前上棘→耻骨结节）
腹内斜肌中间层，肌纤维从外下斜向内上（与腹外斜肌垂直）
腹横肌最深层，肌纤维横行

8.3 胸部与颈部结构

胸大肌胸前壁浅层
胸小肌胸大肌深面
锁胸筋膜胸小肌上方，锁骨下方，筋膜增厚，有血管穿出（头静脉、胸肩峰动脉等）
颈阔肌皮肌（位于浅筋膜内），连到锁骨前部皮肤

8.4 实操安全与学习方法

安全提示
标本固定液甲醛：具有刺激性，明确致癌性。实操时必须佩戴口罩减少吸入，避免长时间近距离无防护接触。
废料处理：使用后的手套、口罩统一投放至生物废料垃圾桶，不得混入普通垃圾桶。
学习方法
先背再来看标本，对照教材和解剖图谱逐一识别。优先识别体表大块肌肉（三角肌、肱二头肌、肱三头肌、臀大肌、股四头肌、缝匠肌）和标志性腔隙结构（三边孔、四边孔、腕管、股三角、收肌管、腘窝）。深层结构无需强行辨认。
