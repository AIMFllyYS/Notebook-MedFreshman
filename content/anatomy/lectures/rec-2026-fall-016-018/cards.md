# 系统解剖学 · 第16-18节 复习手卡

> 用法：先看卡片标题回忆，点击展开对照「直接结论 / 深度解析 / 助记口诀」。共 14 张。

## 第1章

:::memory{label="1.1 上肢带肌与肌腱袖" mode="reveal"}
**直接结论**

- 上肢带肌6块：三角肌、冈上肌、冈下肌、大圆肌、小圆肌、肩胛下肌
- 肌腱袖（肩袖）= 肩胛下肌+冈上肌+冈下肌+小圆肌的肌腱
- 关键考点：不含大圆肌
- 功能：加强肩关节稳固性，防止脱位

**深度解析**

上肢带肌均起自肩胛骨和锁骨，配布于肩关节周围，止于肱骨。肌腱与关节囊纤维融合交织，像袖子一样包裹肩关节。冈上肌肌腱最易受损（穿过喙肩韧带下方，易受挤压）。

> 🎯 助记：肩袖四块：肩胛下冈上冈下小圆，大圆不在里面

:::

:::memory{label="1.2 三角肌（重点）" mode="reveal"}
**直接结论**

- 起点：锁骨外侧端、肩峰、肩胛冈
- 止点：肱骨三角肌粗隆
- 功能：外展（整体）、屈+旋内（前束）、伸+旋外（后束）
- 支配神经：腋神经
- 瘫痪表现：方肩畸形

**深度解析**

三角肌是肩部最明显的肌肉，呈三角形。前后跨度大，不同部位肌束功能不同。腋神经损伤导致三角肌瘫痪，肩部圆润形态消失，可见骨骼轮廓（方肩）。

> 🎯 助记：三角肌起锁肩冈，止三角肌粗隆，腋神经伤方肩

:::

:::memory{label="1.3 臂肌：肱二头肌与肱三头肌" mode="reveal"}
**直接结论**

- 肱二头肌长头：穿结节间沟（滑膜鞘包裹），止于盂上结节
- 肱二头肌短头：起自喙突
- 肱二头肌止点：桡骨粗隆（主腱）+前臂尺侧筋膜（腱膜）
- 肱二头肌功能：屈肘+协助屈肩
- 肱三头肌长头：起自盂下结节
- 肱三头肌内外侧头：桡神经沟内下方/外下方
- 肱三头肌止点：尺骨鹰嘴
- 肱三头肌功能：伸肘+长头协助肩内收后伸

**深度解析**

对比记忆：肱二头肌长头→盂上结节，肱三头肌长头→盂下结节。喙肱肌不跨过肘关节，只参与肩关节运动，但肌腹在上臂所以归为臂肌（判断标准是肌腹位置）。

> 🎯 助记：二头长头盂上结，三头长头盂下结，屈肘伸肘各负责

:::

:::memory{label="1.4 前臂肌分层与手肌" mode="reveal"}
**直接结论**

- 前群四层9块：浅层5块（肱桡肌/旋前圆肌/桡侧腕屈肌/掌长肌/尺侧腕屈肌）、第二层指浅屈肌、第三层拇长屈肌+指深屈肌、第四层旋前方肌
- 后群两层10块：浅层5块（伸肌总腱起自肱骨外上髁）、深层5块
- 手肌分组：鱼际群（拇指：展/屈/对掌/收）、中间群（蚓状肌+骨间肌）、小鱼际群（小指）
- 指浅屈肌止点：中节指骨（只能屈近侧指间关节）
- 指深屈肌止点：远节指骨（能屈近侧+远侧指间关节）

**深度解析**

肱桡肌不跨过腕关节，仅屈肘（由桡神经支配，是前群中唯一由桡神经支配的肌肉）。腕关节是椭圆关节，不能旋转。示指=食指，英文index finger，因常用于指示东西而得名。

> 🎯 助记：前臂前群四层九，浅五深四记心头，指浅中节指深远

:::

## 第2章

:::memory{label="2.1 腋窝、三边孔、四边孔" mode="reveal"}
**直接结论**

- 腋窝顶：锁骨+肩胛骨上缘+第一肋
- 腋窝内侧壁：胸壁+前锯肌（瘫痪→翼状肩）
- 三边孔围成：小圆肌+大圆肌+肱三头肌长头
- 三边孔穿行：旋肩胛动脉
- 四边孔围成：上述+肱骨
- 四边孔穿行：旋肱后动脉+腋神经

**深度解析**

腋窝前壁=胸大肌+胸小肌，后壁=肩胛下肌+大圆肌+背阔肌+肩胛骨，外侧壁=喙肱肌+肱二头肌短头+肱骨。三角胸肌肩沟有头静脉走行。翼状肩是前锯肌瘫痪导致肩胛骨不能贴胸廓。

> 🎯 助记：三边旋肩胛，四边旋肱后+腋神经

:::

:::memory{label="2.2 肘窝与腕管" mode="reveal"}
**直接结论**

- 肘窝穿行（外→内）：肱二头肌肌腱→肱动脉→肱静脉→正中神经
- 腕管构成：屈肌支持带（腕横韧带）+腕骨沟
- 腕管穿行：指浅屈肌腱4+指深屈肌腱4+拇长屈肌腱1+正中神经
- 腕管综合征：正中神经受压→拇指食指中指麻木
- 割腕：一般不致死，多致手部瘫痪

**深度解析**

腕管内共9条肌腱+1条神经。正中神经在腕管内位置表浅，易受腕横韧带压迫。指浅屈肌腱和指深屈肌腱在腕管内排列有特定关系。

> 🎯 助记：肘窝：肱二头肌腱动静脉正中神经；腕管：九腱一神经

:::

## 第3章

:::memory{label="3.1 髋肌：髂腰肌与臀肌" mode="reveal"}
**直接结论**

- 髂腰肌构成：腰大肌+髂肌（两个独立肌腹）
- 髂腰肌止点：股骨小转子
- 髂腰肌功能：髋前屈+旋外；下肢固定时屈躯干
- 阔筋膜张肌：起髂前上棘→移行髂胫束→止胫骨外侧髁
- 臀大肌：起髂骨翼外面+骶骨背面→止髂胫束+臀肌粗隆，功能：髋伸+旋外
- 臀中肌/臀小肌：起髂骨翼外面→止大转子，功能：髋外展（前束旋内/后束旋外）
- 梨状肌：起骶骨前面→穿坐骨大孔→止大转子，功能：髋外展+旋外

**深度解析**

髂腰肌为什么是两块肌肉？肌腹不融合（与肱二头肌不同，肱二头肌肌腹在一起）。腰小肌在腰大肌表面，紧张髂筋膜（非重点）。臀中肌臀小肌类似三角肌，跨的范围大，前后束功能相反。

> 🎯 助记：髂腰两块止小转子，臀大伸旋外，臀中小管外展

:::

:::memory{label="3.2 大腿肌：股四头肌与腘绳肌" mode="reveal"}
**直接结论**

- 缝匠肌：全身最长肌，起髂前上棘→止胫骨上端内侧，功能：屈髋+屈膝+屈膝旋内
- 股四头肌四头：股直肌（髂前下棘）+股内侧肌+股外侧肌（粗线内外唇）+股中间肌（股骨前面）
- 股四头肌止点：髌韧带→胫骨粗隆（膝跳反射部位）
- 股四头肌功能：股直肌屈髋，其余三块伸膝
- 内侧群：起自闭孔周围，功能髋内收+旋转；大收肌还止收肌结节
- 后群（腘绳肌）：半膜肌+半腱肌（止胫骨内侧）+股二头肌（止腓骨外侧）
- 腘绳肌共同起点：坐骨结节（股二头肌短头除外，起粗线）

**深度解析**

髌韧带就是股四头肌的肌腱（内含髌骨），膝跳反射敲击髌韧带引出。股薄肌是内收肌群中唯一止于胫骨的。股二头肌短头起自股骨粗线，不是坐骨结节。

> 🎯 助记：缝匠最长屈髋膝，股四头伸膝强，腘绳三块屈膝髋，半膜半腱内股二外

:::

:::memory{label="3.3 小腿肌与跟腱" mode="reveal"}
**直接结论**

- 小腿三群：前群（伸踝+足内翻）、外侧群（足外翻+屈踝+维持足横弓）、后群（屈踝）
- 后群浅层：小腿三头肌=腓肠肌+比目鱼肌
- 跟腱：小腿三头肌下端肌腱，止于跟骨，人体最粗大肌腱
- 小腿三头肌功能：屈踝+屈膝+维持直立
- 外侧群：腓骨长肌+腓骨短肌，维持足横弓

**深度解析**

小腿内侧群无肌肉（胫骨直接在皮下）。后群深浅两层由小腿横肌间隔分隔。足弓三条：内侧纵弓、外侧纵弓、横弓。下肢的趾和拇与上肢不同（上肢是指和拇）。

> 🎯 助记：小腿三头腓肠比目鱼，跟腱止跟骨，屈踝屈膝维直立

:::

## 第4章

:::memory{label="4.1 梨状肌上下孔与肌血管腔隙" mode="reveal"}
**直接结论**

- 梨状肌上孔：臀上血管+臀上神经
- 梨状肌下孔：坐骨神经+股后皮神经+臀下血管神经+阴部血管神经
- 肌腔隙：髂腰肌+股神经
- 血管腔隙：股动脉+股静脉+股管
- 股管：盲管，含淋巴结和脂肪，上端=股环
- 股疝：腹腔器官经股环突出，女性多见

**深度解析**

梨状肌穿坐骨大孔，将其分为上下两部分。坐骨神经是人体最粗大的神经，从梨状肌下孔穿出，一直在下肢后面走行。髂耻弓分隔肌腔隙和血管腔隙。股疝与腹股沟斜疝/直疝不同：股疝经股环→股管突出，在大腿根部形成鼓包。

> 🎯 助记：上孔臀上，下孔坐骨股后臀下阴部；肌腔髂腰股神经，血管股动股静股管

:::

:::memory{label="4.2 股管四壁" mode="reveal"}
**直接结论**

- 前壁：腹股沟韧带
- 后壁：耻骨梳韧带
- 内侧壁：腔隙韧带（旋窝韧带）
- 外侧壁：股动静脉血管鞘
- 股疝特点：女性多见

**深度解析**

腔隙韧带又名旋窝韧带，是腹股沟韧带连向耻骨梳的片状韧带。股管是盲管，下端不通，只有上端股环与腹腔相通。股疝容易嵌顿（因股环周围都是韧带，扩张性差）。

> 🎯 助记：股管四壁：前腹股沟后耻骨梳，内腔隙外血管鞘，股疝女多见

:::

:::memory{label="4.3 股三角、收肌管、腘窝" mode="reveal"}
**直接结论**

- 股三角上界：腹股沟韧带
- 股三角内侧界：长收肌内侧缘
- 股三角外侧界：缝匠肌内侧缘
- 股三角穿行：股神经+股动脉+股静脉+淋巴结
- 收肌管前壁：大收肌腱膜
- 收肌管后壁：大收肌
- 收肌管外侧壁：股内侧肌
- 收肌管穿行：股动静脉（向后入腘窝）+隐神经（从前壁穿出）
- 腘窝上外侧界：股二头肌
- 腘窝上内侧界：半膜肌+半腱肌
- 腘窝下内外侧界：腓肠肌内外侧头
- 腘窝穿行：坐骨神经（最浅）+腘动脉+腘静脉

**深度解析**

关键考点：收肌管中只有股动静脉向后穿入腘窝，隐神经从收肌管前壁（大收肌腱膜）穿出，不入腘窝。股神经下行后分散，最长分支是隐神经。腘窝是菱形凹陷，股动静脉穿收肌管后移行为腘动静脉。

> 🎯 助记：股三角：腹股沟长收缝匠；收肌管：大收肌腱膜大收肌股内侧肌，隐神经前壁穿出；腘窝：股二头半膜半腱腓肠肌两头

:::

## 第5章

:::memory{label="5.1 腹直肌鞘与弓状线" mode="reveal"}
**直接结论**

- 弓状线位置：脐下4-5cm
- 弓状线以上前层：腹外斜肌腱膜+腹内斜肌腱膜前层
- 弓状线以上后层：腹内斜肌腱膜后层+腹横肌腱膜
- 弓状线以下：三块肌肉腱膜都只构成前层，腹直肌后面直接是腹横筋膜
- 腹壁三层扁肌：腹外斜肌（最浅）→腹内斜肌（中间）→腹横肌（最深）
- 腹股沟韧带：腹外斜肌腱膜下缘增厚形成

**深度解析**

弓状线（半环线）是腹直肌鞘后壁的下界。标本上可见腹直肌鞘后壁在下1/3缺失，呈弧形边缘。腹外斜肌肌纤维从外上斜向内下，腹内斜肌从外下斜向内上（两者垂直），腹横肌横行。

> 🎯 助记：弓状线脐下四五厘，以上前后两层齐，以下只有前层壁

:::

:::memory{label="5.2 标本其他结构与安全" mode="reveal"}
**直接结论**

- 胸大肌/胸小肌：胸前壁，胸小肌在胸大肌深面
- 锁胸筋膜：胸小肌上方锁骨下方，有血管穿出
- 颈阔肌：皮肌，连到锁骨前部皮肤
- 胸锁乳突肌：起胸骨柄+锁骨内侧端→止颞骨乳突
- 甲醛：刺激性+明确致癌，实操须戴口罩
- 废料处理：手套口罩丢生物废料垃圾桶，不混入普通垃圾桶

**深度解析**

标本观察方法：先背再来看，对照教材和解剖图谱逐一识别。优先识别体表大块肌肉（三角肌、肱二头肌、肱三头肌、臀大肌、股四头肌、缝匠肌）和标志性腔隙结构（三边孔、四边孔、腕管、股三角、收肌管、腘窝）。深层结构无需强行辨认。

> 🎯 助记：先背后看对照图，大块肌肉标志腔，甲醛致癌戴口罩

:::
