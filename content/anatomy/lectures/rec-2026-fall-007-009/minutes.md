## 二、核心知识点

### （一）下肢骨

#### 1. 整体分类与特征

- **下肢带骨**：仅1块——**髋骨**
- **自由下肢骨**（从上到下）：股骨 → 髌骨 → 胫骨 → 腓骨 → 足骨
- **足骨细分**：跗骨（7块）+ 跖骨（5块）+ 趾骨（14块），对应上肢的腕/掌/指骨
- **整体特征**：粗大坚固 → 承担体重、支撑运动、适配直立行走

> **易错字提醒**：趾（不是指）、臀、髂、髁、踝、髌

#### 2. 髋骨（不规则骨）

由**髂骨、耻骨、坐骨**三块骨发育融合而成，中间有**闭孔**，构成骨盆的前壁与侧壁。

**髂骨**（构成髋臼上2/5）：
- 分为髂骨体 + 髂骨翼
- 髂骨翼上缘 = **髂嵴**
- 重要结构：髂前上棘、髂结节、**髂后上棘**（临床骨髓穿刺优先部位）
- 内侧面：髂窝、耳状面（与骶骨构成骶髂关节）、弓状线

**坐骨**（构成髋臼后下2/5）：
- 分为坐骨体 + 坐骨支
- **坐骨结节**：末端粗大，坐姿时承重的最低骨性结构
- 坐骨棘：坐骨结节上方
- 坐骨大切迹（髂后下棘下方）、坐骨小切迹（坐骨棘下方）

**耻骨**（构成髋臼前下1/5）：
- 分为耻骨体 + 耻骨上支 + 耻骨下支
- 耻骨梳（弓状线向下延续）、髂耻隆起、耻骨结节、耻骨嵴
- **耻骨联合面**：两侧耻骨借纤维软骨盘形成耻骨联合（无关节结构）

**髋臼**：
- 关节面仅上半部分为**月状面**（向上凹陷的弓状区域）
- 中间凹陷 = **髋臼窝**（非关节面，有囊内韧带）
- 下方关节面缺失 = 髋臼切迹，其间韧带防止髋关节向下脱位

**闭孔**：
- 由耻骨与坐骨共同构成，大部分由闭孔膜封闭
- 闭孔沟（未被膜封闭）→ **闭膜管**（供血管神经穿行）
- 性别差异：男性呈椭圆形（较大），女性近似三角形（较小）

#### 3. 自由下肢骨

**股骨**（人体最长最结实的长骨）：
- 略向前弓
- 上端：股骨头 → 股骨颈 → 大转子 / 小转子
- 前有转子间线，后有转子间嵴
- 骨干后有粗线（肌附着隆起）
- 下端：髌面、内侧髁 / 外侧髁、内上髁 / 外上髁、髁间窝

**髌骨**（人体最大的籽骨）：
- 籽骨 = 生长在肌腱韧带内的骨头
- 位于膝关节前方**股四头肌肌腱**内，板栗状
- 向下延伸的肌腱 = **髌韧带**（膝跳反射敲击处）
- 参与构成膝关节；人人都有（其他籽骨不一定）

**胫骨**（三棱柱体）：
- 上端：内侧髁 / 外侧髁（与股骨髁对应）
- 髁间隆起：非关节面，是半月板和前后交叉韧带附着处
- 外侧髁有腓关节面 → 与腓骨构成胫腓关节
- **前缘、内侧缘无肌肉覆盖，可直接触及**
- 下端：**内踝**（内侧凸起）；外侧有腓切迹（与腓骨韧带连接）

**腓骨**：
- 上端 = 腓骨头，与胫骨形成胫腓关节
- **不参与构成膝关节**（类比尺骨不参与腕关节）
- 下端膨大 = **外踝**，是踝关节重要组成部分

**足骨**：
- 7块跗骨 + 5块跖骨 + 14块趾骨
- 跗骨分三列：
  - 后列：距骨、跟骨
  - 中列：足舟骨
  - 前列：3块楔骨 + 骰骨
- 整体粗大，灵活度远低于手骨（适配负重需求）

### （二）下肢骨连接与骨盆

#### 1. 下肢带骨连接

**骶髂关节**：
- 髋骨髂骨与骶骨的**耳状面**构成
- 关节囊周围有骶髂前、后韧带加强
- **活动度极小**；妊娠期女性活动度略有提升

**髋骨间韧带**：
- 髂腰韧带
- **骶结节韧带** + **骶棘韧带**：与坐骨切迹共同围成**坐骨大孔、坐骨小孔**（重要血管神经走行通道）

**耻骨联合**：
- 两侧耻骨借**纤维软骨盘**连接
- 软骨盘中间有纵向裂隙
- 经产妇裂隙宽度 > 未生育女性
- 活动度极低

#### 2. 骨盆

**构成**：左右髋骨 + 骶骨 + 尾骨 + 骨连接
- 直立位时：髂前上棘与耻骨结节处于同一水平面，整体向前倾斜

**分区**（以**界限**为界）：
- 界限 = 骶骨岬 + 弓状线 + 耻骨梳 + 耻骨联合上缘
- 上方 = **大骨盆（假骨盆）**
- 下方 = **小骨盆（真骨盆）** → 女性骨性产道

**性别差异**：
- 女性骨盆前后径、横径均大于男性 → 适配分娩
- 闭孔：男性椭圆形，女性近似三角形

**重力传导弓**：
- **骶股弓**：骶髂关节 → 髋关节
- **坐骶弓**：骶髂关节 → 坐骨结节
- 约束弓：抵消传导应力
- **耻骨上下支 = 外伤骨折高发部位**

### （三）下肢核心关节

#### 1. 髋关节

- 构成：**髋臼 + 股骨头**（球窝/杵臼关节）
- 关节窝深度远大于肩关节 → 活动度更低，**稳定性极强**
- 关节囊质密坚韧

**囊内结构**：股骨头韧带、髋臼横韧带
**囊外韧带**：髂股韧带、耻骨韧带、坐骨韧带、轮匝带

**临床关联**：
- 股骨颈骨折分囊内、囊外两类
- 血供不足 → **股骨头坏死**（股骨颈骨折损伤营养血管）
- 严重时需人工髋关节置换

#### 2. 膝关节（人体最大、最复杂的关节）

**构成**：股骨下端 + 胫骨上端 + 髌骨
- 关节囊薄而松弛，依赖多重韧带加固

**运动**：
- 主要完成屈伸
- 半屈状态下可小幅度旋内、旋外
- 其余状态无明显旋转

**囊外韧带**：
- 髌韧带（股四头肌肌腱延续，膝跳反射处）
- 胫侧副韧带
- 腓侧副韧带
- 腘斜韧带

**囊内韧带**：
- **前交叉韧带** + **后交叉韧带**
- 损伤检测：**抽屉试验**

**半月板**：
- 内侧：**C型**
- 外侧：**O型**
- 功能：缓冲震荡、适配关节面
- 无充足血供 → 难以愈合；非运动员可直接切除

**滑膜结构**：髌上囊、翼状襞等

**损伤处理**：
- 半月板损伤：非运动员可切除
- 交叉韧带断裂：自体肌腱移植替代（无明显排异反应）

#### 3. 胫腓连接

- 近端：**胫腓关节**
- 远端：胫腓前后韧带连接
- 骨干间：**骨间膜**直接连接
- 无桡尺骨对应的远侧关节结构

#### 4. 踝关节（滑车关节）

- 构成：**胫腓骨下端 + 距骨滑车**
- 内侧韧带：**三角韧带**（强大）
- 外侧韧带（3条）：**距腓前韧带** + **跟腓韧带** + **距腓后韧带**

**损伤特征**：
- 背屈状态：稳定性高
- 跖屈状态：活动度增加、稳定性下降
- **崴脚多发生于跖屈状态，以外侧韧带损伤最常见**

#### 5. 跗骨间关节

- 距跟关节
- **跗横关节**：足部前端截肢时常规选择的离断平面（截面平整，操作难度低）

---

### （四）足弓

**构成**：7块跗骨 + 5块跖骨借骨连接形成向上的弓形结构
- 灵长类特有结构（与手部对掌运动同属灵长类标志性特征）

**分类**：
- **内侧纵弓**：弹性最强、减震效果最显著
- **外侧纵弓**：适配重力传递
- **横弓**

**功能**：
- 缓冲地面冲击
- 保护足底血管神经免受压迫
- **无足弓 = 扁平足**（不符合军校招生身体条件）

## 三、例题 / 强调点

1. **髋骨三骨融合比例**：髂骨上2/5、坐骨后下2/5、耻骨前下1/5 → 髋臼构成
2. **髂后上棘 = 骨髓穿刺优先部位**（临床操作常考点）
3. **坐骨结节 = 坐姿承重最低点**
4. **髌骨是最大籽骨，位于股四头肌肌腱内**；膝跳反射敲击髌韧带
5. **腓骨不参与膝关节**（类比尺骨不参与腕关节）
6. **胫骨前缘可直接触及**（无肌肉覆盖）
7. **膝关节半月板：内侧C型、外侧O型**（记忆：内C外O）
8. **抽屉试验 = 交叉韧带损伤检测**
9. **崴脚 = 跖屈位外侧韧带损伤**（距腓前韧带最常见）
10. **跗横关节 = 足部截肢常规平面**
11. **扁平足 = 无足弓，军校不录取**
12. **股骨颈骨折 → 血供不足 → 股骨头坏死**
13. **骨盆界限四结构**：骶骨岬 + 弓状线 + 耻骨梳 + 耻骨联合上缘
14. **闭孔男女差异**：男椭圆、女三角
15. **足弓三型**：内侧纵弓（弹性最强）+ 外侧纵弓 + 横弓

## 五、主动回忆题

**Q1：髋骨由哪三块骨融合而成？各自构成髋臼的哪个部分？**
> 髋骨由髂骨、耻骨、坐骨三块骨发育融合而成。髂骨构成髋臼上2/5，坐骨构成髋臼后下2/5，耻骨构成髋臼前下1/5。

**Q2：膝关节由哪些骨构成？其囊内和囊外韧带分别有哪些？半月板的形态和功能是什么？**
> 膝关节由股骨下端、胫骨上端和髌骨构成，是人体最大最复杂的关节。囊外韧带包括髌韧带、胫侧副韧带、腓侧副韧带、腘斜韧带；囊内韧带为前交叉韧带和后交叉韧带（损伤用抽屉试验检测）。半月板内侧呈C型、外侧呈O型，功能为缓冲震荡、适配关节面；半月板无充足血供难以愈合。

**Q3：踝关节为什么容易在跖屈状态下发生崴脚？通常损伤哪一侧的韧带？**
> 踝关节由胫腓骨下端与距骨滑车构成，属滑车关节。背屈状态下距骨滑车前部较宽嵌于关节窝内，稳定性高；跖屈状态下距骨后部较窄，关节窝内活动度增加、稳定性下降，因此崴脚多发生于跖屈状态。外侧韧带（距腓前韧带、跟腓韧带、距腓后韧带）较内侧三角韧带薄弱，故以外侧韧带损伤最常见，其中距腓前韧带损伤最多。

**Q4：足弓由哪些骨构成？分为哪几型？各有什么功能特点？扁平足有什么影响？**
> 足弓由7块跗骨和5块跖骨借骨连接形成向上的弓形结构，是灵长类特有结构。分为内侧纵弓、外侧纵弓和横弓三型。内侧纵弓弹性最强、减震效果最显著；外侧纵弓适配重力传递需求。足弓功能为缓冲地面冲击、保护足底血管神经免受压迫。无足弓即为扁平足，缓冲能力差，足底血管神经易受压，不符合军校招生的身体条件要求。

**Q5：股骨颈骨折为什么可能导致股骨头坏死？临床上如何处理？**
> 股骨头的血液供应部分来自沿股骨颈走行的营养血管。股骨颈骨折时可能损伤这些血管，导致股骨头血供不足，进而引发股骨头缺血性坏死。严重时需进行人工髋关节置换手术。股骨颈骨折按骨折位置可分为囊内骨折和囊外骨折两类。

**Q6：骨盆的界限由哪些结构构成？如何区分大骨盆和小骨盆？女性骨盆有什么特点？**
> 骨盆界限由骶骨岬、弓状线、耻骨梳和耻骨联合上缘共同构成。界限以上为大骨盆（假骨盆），以下为小骨盆（真骨盆）。女性骨盆的前后径和横径均大于男性，小骨盆为女性骨性产道，适配分娩需求。此外女性闭孔近似三角形（男性为椭圆形），耻骨联合处软骨盘裂隙经产妇更宽。
