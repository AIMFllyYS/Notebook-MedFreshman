按讲解顺序的详细笔记

一、胃（Stomach / Ventriculus）（02:11-17:17）

1.1 概述

  • 消化管中最膨大的部分
  • 上接食管（第6颈椎下缘/环状软骨水平），下续十二指肠
  • 功能：收纳食物、分泌胃液、内分泌
  • 形态：空虚时呈管状，充盈时呈球囊状

1.2 胃的形态和分部

入口与出口：

  • 贲门（Cardia）：入口，接食管
  • 幽门（Pylorus）：出口，接十二指肠

结构说明
胃底/胃穹窿贲门平面以上，实际最高的部分（做影像时含气呈空泡状）
胃体角切迹以上的大部分区域
胃小弯胃右上缘，最短
胃大弯胃左下缘，最长
角切迹胃小弯最低点转折处，是胃体与幽门部的分界标志
幽门部角切迹右侧至幽门，以中间沟分为幽门窦（左）和幽门管（右）
贲门部贲门附近，分界不清
🔔 老师强调："这张slide是今天第一张要记的。"贲门=cardia，幽门=pylorus。

幽门的术中定位标志：幽门前静脉——在幽门前方的环形沟内。

胃癌好发区：角切迹附近（胃小弯侧）。

1.3 胃的位置

  • 中等充盈：大部分在左季肋区，小部分在腹上区
  • 垂直定位：
  • 贲门：第11胸椎体左侧
  • 幽门：第1腰椎体右侧
  • 胃大弯最低点：脐平面
  • 胃底最高点：左锁骨中线外侧，第6肋间隙

前壁毗邻：膈、肋弓、肝左叶、腹前壁（剑突下为触诊区）

后壁毗邻：左肾、左肾上腺、胰、脾、结肠左曲

💬 老师临床联系：第1-3腰椎区域集中了胰、十二指肠等重要结构——所以胰腺癌进展快、死亡快。

1.4 胃壁的结构

消化管壁四层：黏膜→黏膜下层→肌层→浆膜。

黏膜层：

  • 空虚时形成皱襞
  • 胃小弯处黏膜形成胃道（纵行皱襞）
  • 食管胃交界处：食管胃黏膜线（锯齿状）
  • 🔑 幽门瓣：幽门处黏膜突向十二指肠，形成单向瓣膜（只出不进）

肌层：三层平滑肌（区别于一般消化管的两层）：

  • 外纵行
  • 中环形（在幽门处增厚形成幽门括约肌）
  • 内斜行
  • 斜行纤维主要分布在胃前壁和后壁
🔔 重点掌握：胃道（黏膜）、幽门瓣（黏膜）、外纵中环内斜（肌层）、幽门括约肌（肌层）。

二、小肠（Small Intestine）（17:17-45:00）

2.1 概述

  • 消化管最长部分：成人5-7米
  • 上起幽门，下接盲肠
  • 三部分：十二指肠（duodenum）、空肠（jejunum）、回肠（ileum）
  • 功能：消化吸收、内分泌
💬 老师联系临床：克罗恩病（Crohn's disease）——免疫系统攻击消化系统，导致肠壁黏膜严重破坏，持续腹泻、腹痛、便血。

2.2 十二指肠（Duodenum）

特点：小肠中最短、管径最大、位置最深、最固定。长约25cm（12横指宽），呈C形包绕胰头。

四部分：

部分长度特点
上部~5cm起自幽门；十二指肠球是溃疡好发处（壁薄、腔大、黏膜光滑无皱襞）
降部7-8cm沿第1-3腰椎右侧下行；有十二指肠大乳头（肝胰壶腹开口）和小乳头（副胰管开口）
水平部~10cm跨下腔静脉、腹主动脉前方，第3腰椎水平
升部2-3cm最短，至第2腰椎左侧转折为空肠

关键结构：

  1. 十二指肠球：上部起始段，壁薄、腔大、黏膜光滑——十二指肠溃疡好发部位
  2. 十二指肠纵襞：降部内侧壁的纵行隆起
  3. 十二指肠大乳头：纵襞下端，是肝胰壶腹（Vater壶腹）的开口——胆总管+主胰管汇合开口
  4. 十二指肠小乳头：副胰管开口，位于大乳头上方
    5. 🔍 临床联系：
    - 幽门螺杆菌破坏十二指肠黏膜→易受胃液腐蚀→溃疡
    - 长期吃布洛芬等NSAIDs→胃黏膜破坏→胃出血
    - 急性胰腺炎：胰液外漏到腹腔→消化自身内脏，死亡率高
    - 钡餐造影：溃疡处出现"龛影"

    2.3 十二指肠悬韧带（Treitz韧带）⭐

    位置：十二指肠空肠曲的上后壁。

    构成：

    • 十二指肠悬肌（肌纤维+结缔组织）——固定于右膈脚
    • 包绕悬肌的腹膜皱襞

    意义：🔑 是空肠起始的重要标志，也是上、下消化道的分界。

    🔔 经典名词解释：十二指肠悬韧带=十二指肠悬肌+其表面的腹膜皱襞，是确定空肠起始的标志。

    2.4 空肠与回肠对比 ⭐

    特征空肠（近端2/5）回肠（远端3/5）
    管径较粗较细
    管壁较厚较薄
    黏膜皱襞高而密低而疏
    血管弓弓数少，直血管长弓数多，直血管短
    颜色较红（血供丰富）较浅
    淋巴滤泡散在集合淋巴滤泡（Peyer斑）
    🔔 老师强调：这是经典简答题。空回肠之间无明显界限。

    Peyer斑（集合淋巴滤泡）：位于回肠下段对系膜缘，是椭圆形淋巴组织块，病变时易致肠穿孔或肠出血。

    Meckel憩室：2%成人存在，回肠末端0.3-1m范围内对系膜缘的盲囊突起，胚胎期卵黄管未闭。症状类似阑尾炎。

    三、大肠（Large Intestine）（55:47-01:24:00）

    3.1 概述

    • 全长约1.5m，围绕空回肠周围
    • 分部：盲肠→升结肠→横结肠→降结肠→乙状结肠→直肠→肛管
    • 功能：吸收水分、维生素、无机盐，形成粪便

    特征性结构——"三带一垂"（盲肠和结肠有，直肠/肛管/阑尾无）：

    结构说明
    结肠带3条纵行肌增厚形成，沿肠壁纵轴排列
    结肠袋因结肠带短于肠管长度，肠壁外凸成囊袋状
    肠脂垂沿结肠带两侧分布的脂肪突起
    🔔 临床金标准：3条结肠带汇聚于阑尾根部——手术中沿结肠带找阑尾。

    3.2 盲肠与回盲瓣

    • 盲肠（Cecum）：大肠起始部，长6-8cm，位于右髂窝，下端盲端
    • 回盲口：回肠末端通入盲肠的开口
    • 回盲瓣：回盲口处上下两个半月形皱襞——单向瓣膜，防止大肠内容物反流

    3.3 阑尾（Appendix）

    • 长5-7cm，连于盲肠后内侧壁
    • 阑尾口：回盲口下方约2cm处，有阑尾瓣覆盖
    • 容易发炎的原因：阑尾系膜短于阑尾→阑尾弯曲→残渣易嵌顿
    • 术中注意：系膜内有阑尾动脉，必须结扎！
    • 体表投影：
    • 麦氏点（McBurney点）：脐与右髂前上棘连线外1/3
    • 兰氏点（Lanz点）：左右髂前上棘连线右中1/3
    • 手术找阑尾：沿3条结肠带向下追踪（金标准）

    3.4 结肠

    分部特点
    升结肠盲肠→肝右叶下方，位置固定；转弯处=结肠右曲/肝曲
    横结肠肝曲→脾下方，有系膜，活动度大；转弯处=结肠左曲/脾曲
    降结肠脾曲→左髂嵴，位置固定
    乙状结肠左髂窝入盆腔，呈S形弯曲；腔最窄，憩室和肿瘤好发；至第3骶椎续直肠
    🔍 老师临床联系：40岁以上定期肠镜检查；发现肠息肉切除可使肠癌发病推迟约7年。

    3.5 直肠

    • 第3骶椎处续乙状结肠
    • 矢状面两个弯曲：
    • 直肠骶曲（凸向后，沿骶骨）
    • 直肠会阴曲（凸向前）
    • 冠状面三个弯曲：上、下凸向右，中间凸向左
    • 直肠壶腹：肠腔膨大处
    • 直肠横襞：由黏膜+环形肌构成，阻挡粪便下行；中间横襞最恒定，距肛门约7cm

    3.6 肛管 ⭐

    肛管结构层次（由上至下）：

    结构说明
    肛柱肛管上段纵行黏膜皱襞
    肛瓣相邻肛柱下端之间的半月形皱襞
    肛窦肛瓣与肛柱间开口向上的隐窝
    肛直肠线肛柱上端的连线——直肠与肛管分界
    齿状线肛柱下端+肛瓣连线——黏膜与皮肤分界
    肛梳齿状线下方约1cm光滑区，静脉丛丰富——痔的发生区
    白线肛梳下界——肛门内、外括约肌分界标志

    齿状线的临床意义（⭐重点）：

    齿状线以上齿状线以下
    黏膜皮肤
    植物神经支配（不敏感）躯体神经支配（敏感）
    内痔外痔
    痔不怎么痛痔很痛

    肛门括约肌与肛直肠环：

    肌肉类型作用
    肛门内括约肌平滑肌（环形肌增厚）协助排便，无括约功能；下界=白线
    肛门外括约肌皮下部骨骼肌（随意）切断不致大便失禁
    肛门外括约肌浅部+深部骨骼肌（随意）参与构成肛直肠环
    直肠纵行肌—参与构成肛直肠环
    肛提肌骨骼肌参与构成肛直肠环
    🔔 肛直肠环 = 肛门内括约肌 + 直肠纵行肌 + 肛提肌 + 肛门外括约肌浅部和深部。手术损伤→大便失禁。皮下部切断不影响。

    四、肝（Liver）（01:24:46-01:32:00）

    4.1 概述

    • 人体最大的腺体、最大的实质性器官
    • 活体棕红色，柔软脆弱
    • 位置：大部分右季肋区和腹上区，小部分左季肋区
    • 正常成人右肋弓下不能触及

    4.2 肝的形态

    膈面（上面）：

    • 镰状韧带：矢状位，将肝分为左叶和右叶
    • 冠状韧带：前后两层，之间未被腹膜覆盖的区域=肝裸区

    脏面（下面）——H形沟⭐：

    H形位置结构来源
    左纵沟前肝圆韧带裂脐静脉闭锁
    左纵沟后静脉韧带裂静脉导管闭锁
    横沟（中间）肝门肝左右管、肝固有动脉左右支、肝门静脉左右支出入（6个管道）
    右纵沟前胆囊窝胆囊所在
    右纵沟后腔静脉沟肝左中右静脉汇入下腔静脉

    肝的四叶：

    • 左叶（镰状韧带左侧/左纵沟左侧）
    • 右叶（右纵沟右侧）
    • 方叶（肝门前方，胆囊窝与肝圆韧带裂之间）
    • 尾状叶（肝门后方，腔静脉沟与静脉韧带裂之间）

    4.3 肝的管道系统

    1. Glisson系统（格利森系统）：肝门静脉+肝固有动脉+肝管三者伴行，被结缔组织包裹共同走行
    2. 肝静脉系统：单独走行，在腔静脉沟处汇入下腔静脉

      3. 五、肝外胆道系统（01:32:00-01:42:00）

      5.1 组成

      • 胆囊：储存和浓缩胆汁
      • 输胆管道：
      • 肝左管 + 肝右管 → 肝总管
      • 肝总管 + 胆囊管 → 胆总管
      🔔 重要：胆汁由肝分泌，胆囊只负责储存和浓缩。

      5.2 胆囊

      分部：胆囊底→胆囊体→胆囊颈→胆囊管

      • 胆囊颈和胆囊管内有螺旋襞——控制胆汁流出，也是胆结石嵌顿处
      • 胆囊三角（Calot三角）：胆囊管+肝总管+肝肝脏面围成——手术中寻找胆囊动脉的标志
      🔍 临床警示：胆囊癌预后极差，生存期仅数月。胆结石、胆囊炎应正规治疗。

      5.3 胆汁排出途径

      空腹时：肝分泌胆汁→肝左右管→肝总管→胆囊管→胆囊储存浓缩

      进食时：

      • 胆囊内胆汁：胆囊→胆囊管→胆总管
      • 肝直接分泌：肝左右管→肝总管→胆总管
      • 两者汇合后→胆总管→肝胰壶腹（Vater壶腹）→十二指肠大乳头→十二指肠腔

      老师强调的重点/考点汇总

      1. 胃的分部：贲门、胃底、胃体、角切迹、幽门窦、幽门管
      2. 胃壁肌层：外纵、中环、内斜三层；幽门括约肌
      3. 十二指肠四部分：上部（球部=溃疡好发）、降部（大乳头=肝胰壶腹开口）、水平部、升部
      4. 十二指肠悬韧带（Treitz韧带）：空肠起始标志——经典名词解释
      5. 空肠vs回肠对比表：粗细、厚薄、皱襞、血管弓、Peyer斑
      6. 大肠"三带一垂"：结肠带、结肠袋、肠脂垂
      7. 阑尾根部体表投影：麦氏点；3条结肠带汇聚=找阑尾金标准
      8. 齿状线的意义：黏膜vs皮肤、植物神经vs躯体神经、内痔vs外痔
      9. 肛直肠环组成：内括约肌+纵行肌+肛提肌+外括约肌浅深部；损伤致大便失禁
      10. 肝门：6个管道出入（左右管、肝动脉左右支、门静脉左右支）
      11. 肝脏面H形沟：肝圆韧带裂、静脉韧带裂、肝门、胆囊窝、腔静脉沟
      12. 胆囊三角：找胆囊动脉的标志
      13. 胆汁排出途径：空腹vs进食两条路径

        主动回忆题

        Q1：胃分为哪几部？胃壁肌层与一般消化管有何不同？

        答案要点

        胃分部：贲门部、胃底（胃穹窿）、胃体、幽门部（幽门窦+幽门管）。胃壁肌层有三层——外纵、中环、内斜（一般消化管只有两层）。幽门处环形肌增厚形成幽门括约肌，黏膜形成幽门瓣。

        Q2：十二指肠分哪几部？降部内面有何重要结构？

        答案要点

        上部（含十二指肠球——溃疡好发）、降部、水平部、升部。降部有十二指肠纵襞，其下端有十二指肠大乳头（肝胰壶腹开口，胆总管+主胰管汇合处），上方有十二指肠小乳头（副胰管开口）。

        Q3：十二指肠悬韧带是什么？有什么临床意义？

        答案要点

        位于十二指肠空肠曲上后壁，由十二指肠悬肌（肌纤维+结缔组织，固定于右膈脚）和其表面腹膜皱襞共同构成。是确定空肠起始的重要标志，也是上下消化道分界。

        Q4：空肠和回肠如何区别？

        答案要点

        空肠（近2/5）：管径粗、管壁厚、皱襞高而密、血管弓少直血管长、血供丰富色红、无集合淋巴滤泡。回肠（远3/5）：管径细、管壁薄、皱襞低而疏、血管弓多直血管短、色浅、有Peyer集合淋巴滤泡。

        Q5：齿状线上下有何不同？为什么内痔不痛外痔痛？

        答案要点

        齿状线以上为黏膜、植物神经支配（不敏感），形成内痔；以下为皮肤、躯体神经支配（敏感），形成外痔。故内痔疼痛轻、外痔疼痛明显。

        Q6：简述胆汁从肝分泌后排入十二指肠的途径（进食时）。

        答案要点

        肝分泌胆汁→肝左管+肝右管→肝总管→胆总管（同时胆囊收缩→胆囊→胆囊管→胆总管）→胆总管与胰管汇合形成肝胰壶腹（Vater壶腹）→十二指肠大乳头开口→十二指肠腔。空腹时胆汁经肝总管→胆囊管入胆囊储存浓缩。
