## 第一章 胃

:::memory{label="1.1 胃的形态分部" mode="reveal"}
**直接结论**

- **必背**：贲门 → 胃底 → 胃体 → 幽门部（幽门管+幽门窦）
- 贲门：食管与胃交接处（入口）
- 胃底：贲门平面以上，向左上方膨出（实际最高，影像含气呈空泡状）
- 胃体：胃底与角切迹之间的大部分
- 幽门部：角切迹至幽门，以中间沟分为幽门窦（左）和幽门管（右）
- 角切迹：胃小弯最低点转折处，胃体与幽门部分界标志

**深度解析**

胃是消化管中最膨大的部分，上接食管（第6颈椎下缘/环状软骨水平），下续十二指肠。入口为贲门（cardia），出口为幽门（pylorus），这两个英文词是老师强调今天第一张要记的 slide。幽门的术中定位标志是幽门前静脉（位于幽门前方环形沟内）；胃癌好发于角切迹附近（胃小弯侧）。

> 🎯 助记：贲门接食管，胃底在上膨，胃体最大块，幽门窦管分。

:::

:::memory{label="1.2 胃壁结构" mode="reveal"}
**直接结论**

- 必背：胃壁四层——黏膜层 → 黏膜下层 → 肌层 → 浆膜（外膜）
- 肌层：外纵、中环、内斜（三层平滑肌，区别于一般消化管的两层）
- 幽门括约肌：环形肌在幽门处增厚，控制胃内容物排空
- 胃道：胃小弯处黏膜形成的纵行皱襞
- 幽门瓣：幽门处黏膜突向十二指肠，形成单向瓣膜（只出不进）

**深度解析**

黏膜层在空虚时形成皱襞，胃小弯处的纵行皱襞称胃道；食管胃交界处有锯齿状食管胃黏膜线。黏膜下层为疏松结缔组织，起缓冲作用。肌层有三层：外纵行（分布于大弯小弯）、中环形（幽门处增厚成幽门括约肌）、内斜行（主要分布于胃前壁和后壁，起支撑作用）。重点掌握：胃道（黏膜）、幽门瓣（黏膜）、外纵中环内斜（肌层）、幽门括约肌（肌层）。

> 🎯 助记：胃壁四层膜，肌层外纵中环内斜，幽门括约管控排空。

:::

## 第二章 小肠

:::memory{label="2.1 十二指肠分部" mode="reveal"}
**直接结论**

- **必背**：上部 → 降部 → 水平部 → 升部
- 上部：含十二指肠球，壁薄腔大黏膜光滑，是溃疡好发部位
- 降部：后内侧壁有十二指肠大乳头（肝胰壶腹/Vater壶腹开口）和小乳头（副胰管开口）
- 水平部：横行跨过下腔静脉和腹主动脉前方，第3腰椎水平
- 升部：最短（2-3cm），至第2腰椎左侧以十二指肠空肠曲（Treitz韧带）续空肠

**深度解析**

十二指肠是小肠中最短（约25cm，12横指宽）、管径最大、位置最深、最固定的部分，呈C形包绕胰头。上部起始段的十二指肠球壁薄、腔大、黏膜光滑无皱襞，是十二指肠溃疡和穿孔的好发部位；幽门螺杆菌破坏该处黏膜后易受胃液腐蚀。降部内侧壁有十二指肠纵襞，其下端的大乳头是胆总管+主胰管汇合形成的肝胰壶腹开口，上方的小乳头是副胰管开口。

> ⚠️ 易错：十二指肠球是溃疡好发部位；大乳头是胆总管和胰管共同开口处。

> 🎯 助记：上球溃疡好，降部大乳头胆胰管，水平过脊柱，升部Treitz接空肠。

:::

:::memory{label="2.2 空肠与回肠对比" mode="reveal"}
**直接结论**

- 空肠（近端2/5）：位于左上腹，管径较粗、管壁较厚、血管丰富、环状襞高而密、颜色较红、淋巴滤泡散在
- 回肠（远端3/5）：位于右下腹，管径较细、管壁较薄、血管较少、环状襞低而疏、颜色较浅、有集合淋巴滤泡（Peyer斑）
- 血管弓：空肠弓数少、直血管长；回肠弓数多、直血管短

**深度解析**

空肠和回肠合称系膜小肠，之间无明显界限，一般以近端2/5为空肠、远端3/5为回肠。这是老师强调的经典简答题。Peyer斑（集合淋巴滤泡）位于回肠下段对系膜缘，是椭圆形淋巴组织块，病变时易致肠穿孔或肠出血。Meckel憩室见于约2%成人，位于回肠末端0.3-1m范围内对系膜缘，是胚胎期卵黄管未闭形成的盲囊突起，症状类似阑尾炎。

> 🎯 助记：空肠粗厚血管密，回肠细薄淋巴多。

:::

## 第三章 大肠

:::memory{label="3.1 大肠特征与分部" mode="reveal"}
**直接结论**

- **必背**：三带一垂——结肠带、结肠袋、肠脂垂
- 分部：盲肠 → 阑尾 → 结肠（升/横/降/乙状）→ 直肠 → 肛管
- 回盲瓣：回肠与盲肠交界处上下两个半月形皱襞，单向瓣膜，防止大肠内容物逆流
- 全长约1.5m，围绕空回肠周围

**深度解析**

"三带一垂"是盲肠和结肠的特征性结构（直肠、肛管、阑尾无此结构）：结肠带由3条纵行肌增厚沿肠壁纵轴排列；因结肠带短于肠管长度，肠壁外凸成结肠袋；沿结肠带两侧分布的脂肪突起为肠脂垂。3条结肠带汇聚于阑尾根部，是手术中寻找阑尾的金标准。大肠功能为吸收水分、维生素、无机盐，形成粪便。

> 🎯 助记：三带一垂认大肠，盲肠阑尾升横降乙状直肠肛管。

:::

:::memory{label="3.2 阑尾与麦氏点" mode="reveal"}
**直接结论**

- 麦氏点（McBurney点）：脐与右髂前上棘连线的外1/3处
- 兰氏点（Lanz点）：左右髂前上棘连线的右中1/3处
- 寻找方法：三条结肠带汇聚处即阑尾根部（手术金标准）
- 阑尾长5-7cm，连于盲肠后内侧壁；阑尾系膜短于阑尾→阑尾弯曲→残渣易嵌顿发炎

**深度解析**

阑尾口位于回盲口下方约2cm处，有阑尾瓣覆盖。阑尾系膜内有阑尾动脉，手术时必须结扎，不能直接剪断系膜。阑尾位置不固定，但3条结肠带恒定汇聚于阑尾根部，因此沿结肠带向下追踪是术中寻找阑尾的可靠方法。

> 🎯 助记：麦氏点右髂前上棘外1/3，结肠带汇找阑尾。

:::

:::memory{label="3.3 肛管结构与齿状线" mode="reveal"}
**直接结论**

- 肛柱：肛管上段纵行黏膜皱襞
- 肛瓣：相邻肛柱下端之间的半月形皱襞
- 肛窦：肛瓣与肛柱间开口向上的隐窝
- 齿状线：肛柱下端+肛瓣连成的锯齿状环——黏膜与皮肤的分界线
- 肛梳：齿状线下方约1cm光滑区，静脉丛丰富，是痔的发生区
- 白线：肛梳下界——肛门内、外括约肌分界标志
- 肛直肠环：肛门内括约肌 + 直肠纵行肌 + 肛提肌 + 肛门外括约肌浅部和深部

**深度解析**

齿状线以上为黏膜、植物神经支配（不敏感），形成内痔，疼痛轻；齿状线以下为皮肤、躯体神经支配（敏感），形成外痔，疼痛明显。肛门内括约肌为平滑肌（环形肌增厚），协助排便但无括约功能，下界为白线；肛门外括约肌为骨骼肌（随意），分皮下部、浅部、深部，其中皮下部切断不致大便失禁，浅部和深部参与构成肛直肠环。肛直肠环损伤→大便失禁。

> 🎯 助记：肛柱纵肛瓣连，肛窦开口齿状线，肛直肠环控排便。

:::

## 第四章 肝与胆道

:::memory{label="4.1 肝的形态与分叶" mode="reveal"}
**直接结论**

- 必背：肝四叶——左叶、右叶、方叶、尾状叶
- 膈面：镰状韧带矢状位将肝分为左叶和右叶；冠状韧带前后两层之间为肝裸区
- 脏面：H形沟——左纵沟前=肝圆韧带裂（脐静脉闭锁）、左纵沟后=静脉韧带裂（静脉导管闭锁）、横沟=肝门、右纵沟前=胆囊窝、右纵沟后=腔静脉沟
- 肝门：肝左右管、肝固有动脉左右支、肝门静脉左右支共6个管道出入

**深度解析**

肝是人体最大的腺体、最大的实质性器官，活体棕红色、柔软脆弱，大部分位于右季肋区和腹上区，小部分在左季肋区，正常成人右肋弓下不能触及。方叶位于肝门前方（胆囊窝与肝圆韧带裂之间），尾状叶位于肝门后方（腔静脉沟与静脉韧带裂之间）。肝内管道分两套：Glisson系统（肝门静脉+肝固有动脉+肝管三者伴行，被结缔组织包裹）和肝静脉系统（单独走行，在腔静脉沟汇入下腔静脉）。

> 🎯 助记：膈面镰韧带分左右，脏面H沟肝门通，四叶左右方尾状。

:::

:::memory{label="4.2 肝外胆道系统与胆汁排出" mode="reveal"}
**直接结论**

- 胆汁由肝分泌，胆囊只储存和浓缩胆汁
- 输胆管道：肝左管+肝右管 → 肝总管；肝总管+胆囊管 → 胆总管
- 胆囊三角（Calot三角）：胆囊管+肝总管+肝脏面围成，是手术中寻找胆囊动脉的标志
- 进食时：肝胆汁（肝左右管→肝总管→胆总管）+胆囊胆汁（胆囊→胆囊管→胆总管）汇合 → 胆总管 → 肝胰壶腹（Vater壶腹）→ 十二指肠大乳头 → 十二指肠腔

**深度解析**

空腹时胆汁经肝总管→胆囊管入胆囊储存浓缩；进食时胆囊收缩，胆汁与肝直接分泌的胆汁汇合入胆总管，与胰管汇合形成肝胰壶腹后开口于十二指肠大乳头。胆囊分部为胆囊底→胆囊体→胆囊颈→胆囊管，胆囊颈和胆囊管内有螺旋襞控制胆汁流出，也是胆结石嵌顿处。胆囊癌预后极差，生存期仅数月，胆结石、胆囊炎应正规治疗。

> 🎯 助记：左右肝管肝总管，胆囊管汇胆总管，肝胰壶腹大乳头，胆囊三角找动脉。

:::
