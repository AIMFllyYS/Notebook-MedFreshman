## 一、绪论

### 1.1 系统解剖学 vs 局部解剖学

| | 系统解剖学 | 局部解剖学 |
|---|---|---|
| 组织方式 | 按器官功能系统 | 按局部/器官 |
| 内容 | 正常器官的形态结构及发生发展 | 器官的配伍位置、关系及层次结构 |
| 用途 | 基础医学基础 | 外科手术解剖基础 |

> 基础医学专业只上系统解剖学，不上局部解剖学。

### 1.2 人体九大系统

1. **运动系统**：骨、骨连接、骨骼肌 → 保护躯体、运动
2. **内脏系统**（4个）：
   - 呼吸系统：气体交换
   - 消化系统：消化吸收、排粪便
   - 泌尿系统：代谢废物→尿液
   - 生殖系统：生殖繁衍
3. **脉管系统**：动脉、静脉、淋巴管
4. **神经系统**：控制器官活动（最复杂，需显微解剖学辅助）
5. **内分泌系统**：内分泌腺（甲状腺、卵巢/睾丸、松果体等）
6. **感官系统**：视觉、听觉

### 1.3 解剖学发展史要点

- 盖伦：《医经》，欧洲中世纪权威医学著作（类似中国《黄帝内经》），但错误很多
- **维萨里（Vesalius）**：比利时人，"解剖学之父"，出版第一部真正解剖学图谱《人体结构》
- 中国：宋代宋慈《洗冤集录》（法医），近现代解剖学从西方传入
- 1832年英国《解剖法》：允许使用死刑犯遗体进行解剖研究
- 遗体捐献通过红十字会，严禁倒卖人体组织

## 二、解剖学基本术语

### 2.1 标准解剖学姿势

> 身体直立，面向前，两眼平视前方，上肢下垂于躯干两侧，**掌心向前**，下肢并拢，足尖向前。

⚠️ 与体育课立正的区别：**掌心向前**（体育课立正掌心向内）。掌心向前→大拇指在食指外侧。

### 2.2 方位术语

| 术语 | 含义 |
|---|---|
| 上/下 | 靠近头为上，靠近足为下 |
| 前/后 | 靠近胸腹为前（腹侧），靠近背为后（背侧） |
| 内侧/外侧 | 靠近正中矢状面为内侧，远离为外侧 |
| 内/外 | 描述腔隙结构（颅腔、胸腔等），腔内为内 |
| 浅/深 | 离体表近为浅，远为深 |
| 近侧/远侧 | 靠近躯干为近侧，远离为远侧（用于四肢） |
| 尺侧/桡侧 | 前臂内侧=尺侧，外侧=桡侧 |
| 胫侧/腓侧 | 小腿内侧=胫侧，外侧=腓侧 |

### 2.3 轴和面

**三个轴**：
- 垂直轴：垂直于地面
- 冠状轴（额状轴）：平行地面，左右方向
- 矢状轴：平行地面，前后方向

**三个面**：
- 矢状面：沿矢状轴，分左右（正中矢状面=等分左右）
- 冠状面（额状面）：沿冠状轴，分前后
- 水平面（横切面）：平行地面，分上下

### 2.4 变异 vs 异常

- **变异**：差异不显著，统计学上占优势（如身高1.7m vs 1.8m）
- **异常**：统计学概率极低（如四五百斤体重）
- 体型：矮胖型、瘦长型、适中型

## 三、骨学总论

### 3.1 骨的数量与分类

- 成人**206块骨**（含3对听小骨，属感觉器）
- 按部位：**中轴骨**（颅骨+躯干骨）+ **四肢骨**
- 按形态：

| 类型 | 特点 | 分布/例子 |
|---|---|---|
| 长骨 | 一体两端，骨干+骺 | 四肢（肱骨、股骨、指骨） |
| 短骨 | 立方形，成群排列 | 腕骨、跗骨 |
| 扁骨 | 板状，围成腔隙 | 颅盖骨、肋骨、胸骨 |
| 不规则骨 | 形状不规则，含空腔 | 椎骨、筛骨 |

> ⚠️ 肋骨虽然长，但属于**扁骨**（围成胸腔）。指骨虽短，属于**长骨**。

### 3.2 长骨的结构

- **骨干（diaphysis）**：中间细长部分，中空=骨髓腔
- **骺（epiphysis）**：两端膨大
- **干骺端**：骨干与骺交界区域
- **骺线/骺软骨**：软骨组织，含成骨细胞，促进骨生长
  - 12岁以前X线下可见骺线（透亮线）
  - 骺线闭合→骨骼停止生长
  - 测骨龄常用腕部X线

### 3.3 骨的构造

| 结构 | 位置 | 特点 |
|---|---|---|
| **骨密质** | 骨表层 | 致密坚硬，抗压性强；骨干处厚 |
| **骨松质** | 骨内部 | 片状骨小梁交织；骺部多，骨干内沿压力曲线排列 |
| **骨膜** | 骨外表面（关节面除外） | 致密结缔组织，含神经血管、成骨细胞、破骨细胞；功能：营养、再生、感觉 |
| **骨髓** | 骨髓腔+骨松质间隙 | 红骨髓（造血）/黄骨髓（脂肪，无造血） |

**红骨髓 vs 黄骨髓**：
- 胎儿/幼儿：全部骨髓都是红骨髓
- 成人：长骨骨髓腔为黄骨髓；骨松质内仍有红骨髓（椎骨、髂骨、胸骨）
- 骨髓穿刺常选**髂骨**或**胸骨**
- 黄骨髓在失血/疾病时可转化为红骨髓恢复造血

### 3.4 骨的化学成分

| 成分 | 占比 | 作用 | 实验 |
|---|---|---|---|
| **有机质** | 成人约1/3 | 韧性和弹性（胶原纤维、粘多糖蛋白） | 脱钙骨→可弯折如皮筋 |
| **无机质** | 成人约2/3 | 硬度和脆性（碱性磷酸钙） | 煅烧骨→骨灰，一碰就碎 |

- 儿童：有机质多→韧性大，不易骨折但易变形（青枝骨折）
- 老人：无机质多→脆性大，易骨折
- 比例随年龄变化：有机质逐渐减少，无机质逐渐增多

## 四、骨连接

### 4.1 分类

- **直接连接**：纤维连接（缝、韧带）、软骨连接（椎间盘）、骨性结合
  - 活动度极小或无
- **间接连接 = 关节**：骨连接的最高形式，活动度最大

### 4.2 关节的基本结构（所有关节共有）

| 结构 | 特点 |
|---|---|
| **关节面** | 一凸（关节头）一凹（关节窝），表面覆关节软骨（减少摩擦、增加弹性） |
| **关节囊** | 外层=纤维膜（致密结缔组织），内层=滑膜（分泌滑液） |
| **关节腔** | 关节囊滑膜层+关节软骨围成，呈**负压**，含滑液（润滑、营养） |

### 4.3 关节的辅助结构（部分关节有）

| 结构 | 功能 | 例子 |
|---|---|---|
| **韧带** | 加强稳固、限制过度运动 | 膝关节交叉韧带（囊内）、腓侧副韧带（囊外） |
| **关节盘** | 调节关节面适配、缓冲、分腔增加运动形式 | 膝关节半月板（内侧/外侧） |
| **关节唇** | 加深关节窝、增大关节面、增加稳定性 | 髋关节盂唇、肩关节盂唇 |
| **滑膜襞/滑膜垫** | 填充关节腔、调节压力、扩大滑膜面积 | 膝关节翼状襞 |
| **滑膜囊** | 减少肌腱/韧带与骨面摩擦 | 髌下囊 |

> 肩关节囊薄而松弛→活动度大但易脱位；髋关节囊厚→稳固。

### 4.4 关节的运动（基于三个轴）

| 运动 | 轴 | 描述 |
|---|---|---|
| **屈/伸** | 冠状轴 | 两骨靠拢角度变小=屈，反之=伸 |
| **收/展** | 矢状轴 | 向正中矢状面靠拢=收，远离=展 |
| **旋转（旋内/旋外）** | 垂直轴 | 骨前面转向内侧=旋内（旋前），向外=旋外（旋后） |
| **环转** | 复合 | 屈→展→伸→收的连续运动，骨远端画圆 |

⚠️ **特殊情况**：
- 踝关节：屈伸与日常认知相反！勾脚=伸（背屈），绷脚=屈（跖屈）
- 拇指腕掌关节：屈/伸沿矢状轴，收/展沿冠状轴（与其他四指相反），因为第一掌骨旋转了90°

### 4.5 关节的分类

- 按骨数：单关节（2骨）/ 复关节（2骨以上）
- 按运动方式：单动关节 / 联动关节（如颞下颌关节、桡尺近远侧关节）
- 按运动轴数：单轴关节（指间关节，仅屈伸）/ 双轴关节（腕掌关节，屈伸+收展）/ 多轴关节（肩关节、髋关节，可旋转）

## 五、躯干骨

> 躯干骨 = 椎骨 + 肋骨 + 胸骨。躯干骨 + 颅骨 = 中轴骨。

### 5.1 椎骨数量

| 时期 | 数量 | 组成 |
|---|---|---|
| 幼年 | 32-33块 | 颈椎7 + 胸椎12 + 腰椎5 + 骶椎5 + 尾椎3-4 |
| 成年 | 24块（独立） | 颈椎7 + 胸椎12 + 腰椎5；5骶椎融合为1块骶骨，3-4尾椎融合为1块尾骨 |

### 5.2 椎骨一般形态

- **椎体**：前方，承重，上下面有椎间盘
- **椎弓**：后方，与椎体围成**椎孔**；所有椎孔连成**椎管**（容纳脊髓）
- **7个突起**：
  - 1个**棘突**（向后，可在体表摸到）
  - 1对**横突**（向两侧）
  - 2对**关节突**（上关节突+下关节突，形成关节突关节）
- **椎上切迹/椎下切迹**：相邻椎骨切迹围成**椎间孔**（脊神经、血管通过）

> 腰椎间盘突出：椎间盘向侧后方突出→压迫椎间孔内的脊神经（不是掉到椎管里）。

### 5.3 颈椎（7块）

**共同特点**：
- 椎体小（承重少）
- 椎孔大，呈三角形（脊髓颈膨大最粗）
- 横突有**横突孔**（椎动脉通过，但椎动脉从第6颈椎横突孔上行，第7颈椎孔内无椎动脉）
- 第2-6颈椎棘突末端分叉

**特殊颈椎**：

| 颈椎 | 别称 | 特点 |
|---|---|---|
| 第1颈椎 | **寰椎** | 无椎体，呈环形；前弓+后弓+侧块；前弓内侧有齿突凹（与枢椎齿突相关节）；后弓有椎动脉沟；上关节面与枕骨形成寰枕关节 |
| 第2颈椎 | **枢椎** | 椎体向上伸出**齿突**（发育上是第1颈椎椎体融合而来）；与寰椎齿突凹形成寰枢正中关节 |
| 第7颈椎 | **隆椎** | 棘突最长，末端不分叉，体表易触及→计数椎骨的标志 |

**钩椎关节（Luschka关节）**：颈椎椎体上面侧缘向上突起（钩），与上位椎体下面斜坡形成的关节。增生→压迫椎间孔血管神经→颈椎病。

**颈动脉结节**：第6颈椎横突前结节，前方有颈总动脉，头部出血时可压迫止血。

### 5.4 胸椎（12块）

- 椎体侧面有**肋凹**（与肋头相关节）
- 横突末端有**横突肋凹**（与肋结节相关节）
- 棘突长，**斜向后下方**，呈叠瓦状排列
- 关节突关节面几乎呈冠状位
- 第1胸椎和第11、12胸椎为全肋凹（一个完整肋凹）；第2-10胸椎有上、下肋凹（肋骨关节在两椎体之间）
- 第11、12胸椎无横突肋凹

### 5.5 腰椎（5块）

- 椎体**肥大**（承重最大）
- 棘突呈**板状，水平向后**（不斜向下）→ 腰椎穿刺（腰穿）从棘突间隙进针
- 关节突关节面呈**矢状位**
- 腰部脊髓已形成马尾，腰穿不易损伤脊髓

### 5.6 骶骨与尾骨

- **骶骨**：5块骶椎融合，三角形；底向上，尖向下
  - 前面（盆面）光滑，有4对**骶前孔**
  - 后面粗糙，有4对**骶后孔**，棘突融合为**骶正中嵴**
  - 两侧有**耳状面**（与髋骨形成骶髂关节）
  - 骶管上通椎管，下端开口为**骶管裂孔**
- **尾骨**：3-4块尾椎融合，三角形，末端游离，易骨折

### 5.7 胸骨

- 分三部分：**胸骨柄** + **胸骨体** + **剑突**
- **胸骨角**：胸骨柄与体连接处，向前突出，体表可触及
  - 两侧平对**第2肋**→计数肋骨的标志
  - 向后平对**第4胸椎下缘**
- 胸骨柄上缘正中：**颈静脉切迹**
- 两侧：锁切迹（与锁骨相关节）、第1肋切迹

### 5.8 肋（12对）

- 肋 = **肋骨**（骨性）+ **肋软骨**（透明软骨，终生不骨化）
- 分类：
  - **真肋（1-7）**：肋软骨直接与胸骨相连
  - **假肋（8-10）**：肋软骨依次连于上位肋软骨，形成**肋弓**
  - **浮肋（11-12）**：前端游离于腹壁肌中

**肋骨一般形态**：
- 后端：肋头（关节面，与椎体肋凹相关节）→ 肋颈 → 肋结节（与横突肋凹相关节）
- 肋体：有**肋角**（转折处），内面有**肋沟**（肋间神经、血管走行）
- 前端：接肋软骨

**特殊肋骨**：
- 第1肋：最短最宽，上面有前斜角肌结节，两侧有锁骨下动静脉沟
- 第11、12肋：无肋颈、无肋结节、无肋角（浮肋）

## 六、教师强调与易错点

1. **标准解剖学姿势掌心向前**——这是所有方位描述的基础。
2. **长骨≠长的骨**：指骨虽短属于长骨；肋骨虽长属于扁骨。
3. **骺线闭合=停止生长**；测骨龄看腕部。
4. **骨膜对骨的再生至关重要**——骨折愈合依赖骨膜成骨细胞。
5. **成人红骨髓位置**：椎骨、髂骨、胸骨的骨松质内；骨髓穿刺选髂骨/胸骨。
6. **关节腔负压**——维持关节稳固。
7. **踝关节屈伸与日常相反**：勾脚=伸（背屈），绷脚=屈（跖屈）。
8. **拇指运动轴与其他四指相反**（第一掌骨旋转90°）。
9. **椎骨7个突起**：1棘突+2横突+4关节突。
10. **寰椎无椎体，枢椎有齿突，隆椎棘突最长**。
11. **胸骨角平对第2肋、第4胸椎下缘**——重要体表标志。
12. **真肋1-7，假肋8-10，浮肋11-12**。
13. **腰椎穿刺选腰椎**：棘突水平向后+马尾，安全。

## 八、主动回忆题

**Q1. 为什么儿童骨骼不易骨折但易变形？**
儿童骨的有机质（胶原纤维）比例高，韧性和弹性大，所以不易完全骨折但易弯曲变形（青枝骨折）。老年人无机质比例高，脆性大，易骨折。

**Q2. 关节的基本结构有哪些？关节腔为什么呈负压？**
基本结构：关节面（覆关节软骨）、关节囊（纤维膜+滑膜）、关节腔。关节腔负压有助于维持关节的稳固性，使关节面紧密贴合。

**Q3. 腰椎穿刺为什么选在腰部而不是胸部？**
腰椎棘突呈板状水平向后，棘突间隙大，便于进针；胸部棘突斜向后下呈叠瓦状，间隙小。且腰部脊髓已延续为马尾（漂浮在脑脊液中），穿刺不易损伤脊髓。

**Q4. 如何在体表计数肋骨和椎骨？**
计数肋骨：胸骨角平对第2肋，向下依次计数。计数椎骨：第7颈椎（隆椎）棘突最长最突出，作为椎骨计数起点。
