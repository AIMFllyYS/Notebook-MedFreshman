## 一、运动系统

### 第1题

:::callout{kind=note label="题目"}
请写出箭头所指结构的名称。

来源：标本考试复习 · Slide 2
:::

:::figure{src="/images/anatomy/specimen-exam-2021/ea277818591352cd.png" alt="脊柱后面观，相邻椎骨之间的椎间孔" caption="课件箭头所指：相邻椎弓根之间的孔"}
:::

:::callout{kind=insight label="解析"}
**【答案】椎间孔**

相邻椎骨的上、下切迹围成椎间孔，脊神经和血管由此出入椎管。后面观时孔在椎弓根外侧，不要指成椎孔（椎孔在椎管里，上下叠成椎管）。
:::

:::callout{kind=note label="知识卡片：椎孔 vs 椎间孔"}
椎孔 = 椎体 + 椎弓围成，上下连通成椎管。椎间孔 = 相邻椎骨之间，走脊神经。
:::

:::callout{kind=tip label="结论速记"}
侧方相邻椎骨之间的孔 = **椎间孔**，出脊神经。
:::

### 第3题

:::callout{kind=note label="题目"}
请写出箭头所指骨连接的名称。

来源：标本考试复习 · Slide 4
:::

:::figure{src="/images/anatomy/specimen-exam-2021/8e27726743624722.png" alt="锁骨胸骨端与胸骨柄的关节冠状切" caption="课件箭头所指：锁骨与胸骨柄之间的关节"}
:::

:::callout{kind=insight label="解析"}
**【答案】锁胸关节**（即胸锁关节）

锁骨胸骨端与胸骨柄锁切迹（常有第一肋软骨参与）构成，是上肢与躯干之间的唯一骨连结。课件用名「锁胸关节」，与教材「胸锁关节」为同一户。
:::

:::callout{kind=tip label="结论速记"}
锁骨内侧端对胸骨柄 = **胸锁（锁胸）关节**。
:::

### 第6题

:::callout{kind=note label="题目"}
请写出箭头所指结构的名称，有什么结构通过？

来源：标本考试复习 · Slide 7
:::

:::figure{src="/images/anatomy/specimen-exam-2021/26a5d8b4d2588e8f.png" alt="颅底内面，蝶骨大翼上的卵圆孔" caption="课件箭头所指：蝶骨大翼上、棘孔前方的卵圆形孔"}
:::

:::callout{kind=insight label="解析"}
**【答案】卵圆孔；下颌神经**

颅中窝底、蝶骨大翼上的卵圆形孔，三叉神经第三支（下颌神经）由此出颅到颞下窝。其后方较小的是棘孔（脑膜中动脉）。
:::

:::callout{kind=note label="知识卡片：颅中窝三个孔"}
圆孔走上颌神经，卵圆孔走下颌神经，棘孔走脑膜中动脉。由前内向后外：圆 → 卵圆 → 棘。
:::

:::callout{kind=tip label="结论速记"}
卵圆孔出 **V3（下颌神经）**。
:::

### 第17题

:::callout{kind=note label="题目"}
请写出箭头所指牙齿正确的牙式。

来源：标本考试复习 · Slide 18
:::

:::figure{src="/images/anatomy/specimen-exam-2021/b896686574ae5b6a.png" alt="混合牙列，部分恒牙尚未萌出" caption="课件箭头所指牙：牙式记 3（图中箭头为 PPT 形状，提取图未带箭头）"}
:::

:::callout{kind=insight label="解析"}
**【答案】3**

课件标注为 3。按部位记录法，从中线向外：1 中切牙、2 侧切牙、**3 尖牙**、4 第一前磨牙……图为混合牙列（乳牙与未萌恒牙并存），以课件箭头所指那一颗为准。
:::

:::callout{kind=note label="知识卡片：牙式"}
恒牙每象限 2-1-2-3；乳牙每象限 2-1-2。单个牙写「3」即该象限尖牙。
:::

:::callout{kind=tip label="结论速记"}
本站牙式答案 **3** = **尖牙**。
:::

:::callout{kind=tip label="结论速记"}
面动脉后方伴行的静脉 = **面静脉**，可通海绵窦。
:::

:::callout{kind=insight label="解析"}
