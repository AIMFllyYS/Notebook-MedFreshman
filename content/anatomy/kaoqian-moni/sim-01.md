## 一、名词解释

### 第1题

:::callout{kind=note label="题目"}
关节的基本结构。

来源：简答题.doc · 名词解释残片「关节的基本结构」
:::

:::callout{kind=insight label="解析"}
**【答案】** 关节面、关节囊、关节腔。

骨的间接连结又称滑膜关节。相对骨面分离，借周围结缔组织相连，腔内有滑液。基本构造只有这三件；韧带、关节盘、关节唇、滑膜襞和滑膜囊都是**辅助结构**，不能写进「基本结构」。
:::

:::callout{kind=note label="知识卡片：关节三件套"}
| 构件 | 要点 |
|------|------|
| 关节面 | 覆关节软骨，减少摩擦、缓冲震荡 |
| 关节囊 | 外纤维膜、内滑膜；滑膜参与围成关节腔 |
| 关节腔 | 滑膜层与关节面围成，呈负压，含少量滑液 |
:::

:::callout{kind=pitfall label="易错警示"}
半月板、盂唇再重要，也只是辅助结构。写成五件套会直接扣点。
:::

:::callout{kind=tip label="结论速记"}
关节基本结构只记三件：**面、囊、腔**。
:::

### 第2题

:::callout{kind=note label="题目"}
主动脉弓的分支从右向左。

来源：简答题.doc · 「主动脉弓的分支从右向左」
:::

:::callout{kind=insight label="解析"}
**【答案】** 头臂干、左颈总动脉、左锁骨下动脉。

主动脉弓弯向左后，至第 4 胸椎椎体下缘移行为降主动脉；凸侧由右向左发出这三支。头臂干再分成右颈总动脉和右锁骨下动脉。不要把右颈总、右锁骨下直接写成弓上的独立分支。
:::

:::callout{kind=note label="知识卡片：弓上三支"}
| 顺序（右→左） | 去向 |
|----------------|------|
| 头臂干 | 右胸锁关节后方 → 右颈总 + 右锁骨下 |
| 左颈总动脉 | 直接起自弓 |
| 左锁骨下动脉 | 直接起自弓 |
:::

:::callout{kind=tip label="结论速记"}
弓上右→左：**头臂干、左颈总、左锁骨下**。
:::

### 第3题

:::callout{kind=note label="题目"}
咀嚼肌组成。

来源：简答题.doc · 「咀嚼肌组成」
:::

:::callout{kind=insight label="解析"}
**【答案】** 咬肌、颞肌、翼内肌、翼外肌。

四块都由三叉神经运动根（下颌神经）支配。双侧翼外肌收缩使下颌下降（张口）；咬肌、颞肌、翼内肌上提下颌（闭口）。
:::

:::callout{kind=note label="知识卡片：咀嚼肌四块"}
| 肌 | 主要作用 |
|----|----------|
| 咬肌 | 上提下颌 |
| 颞肌 | 上提下颌；后份后拉 |
| 翼内肌 | 上提下颌 |
| 翼外肌 | 双侧收缩张口；单侧使下颌偏向对侧 |
:::

:::callout{kind=tip label="结论速记"}
咀嚼肌四块：**咬、颞、翼内、翼外**；张口靠**翼外肌**。
:::

### 第4题

:::callout{kind=note label="题目"}
心传导系。

来源：简答题.doc · 「心传导系」；残片含 Purkinje
:::

:::callout{kind=insight label="解析"}
**【答案】** 由特殊心肌细胞构成，包括窦房结、结间束、房室交界区（房室结）、房室束、左、右束支和 Purkinje 纤维网。

它产生并传导兴奋，控制心的节律。是心肌特化细胞，不是植物神经纤维。窦房结是正常起搏点。
:::

:::callout{kind=note label="知识卡片：传导系顺序"}
窦房结 → 结间束 → 房室结 → 房室束（His 束）→ 左、右束支 → Purkinje 纤维 → 心室肌
:::

:::callout{kind=tip label="结论速记"}
传导系是**特殊心肌**，不是神经；起搏在**窦房结**。
:::

### 第5题

:::callout{kind=note label="题目"}
胆囊三角。

来源：简答题.doc · 「胆囊三角」
:::

:::callout{kind=insight label="解析"}
**【答案】** 由胆囊管、肝总管和肝的脏面围成，又称 Calot 三角。三角内常有胆囊动脉经过，是胆囊手术中寻找胆囊动脉的标志。
:::

:::callout{kind=note label="知识卡片：Calot 三边"}
| 边 | 结构 |
|----|------|
| 右 | 胆囊管 |
| 左 | 肝总管 |
| 上 | 肝脏面 |

肝总管 ≠ 胆总管。肝左、右管合成肝总管；肝总管再加胆囊管才是胆总管。
:::

:::callout{kind=tip label="结论速记"}
Calot = **胆囊管 + 肝总管 + 肝脏面**，内走**胆囊动脉**。
:::

### 第6题

:::callout{kind=note label="题目"}
易出血区。

来源：简答题.doc · 「易出血区」
:::

:::callout{kind=insight label="解析"}
**【答案】** 鼻中隔前下部，又称 Little 区（或 Kiesselbach 区）。

此处血管丰富、位置浅表，干燥或外伤时易出血，约 90% 的鼻出血发生于此。不要笼统写成下鼻甲或鼻腔后部。
:::

:::callout{kind=pitfall label="易错警示"}
后部鼻出血多来自蝶腭动脉分支，不是 Little 区。卷面写「易出血区」默认指**鼻中隔前下**。
:::

:::callout{kind=tip label="结论速记"}
易出血区 = **鼻中隔前下部**（Little 区）。
:::

### 第7题

:::callout{kind=note label="题目"}
大脑动脉环。

来源：简答题.doc · 「大脑动脉环」
:::

:::callout{kind=insight label="解析"}
**【答案】** Willis 环：两侧大脑前动脉、颈内动脉、大脑后动脉借前交通动脉和后交通动脉构成，位于蝶鞍上方，环绕视交叉、灰结节和乳头体。使颈内动脉系与椎–基底动脉系交通。

**大脑中动脉不参与成环。** 正常时环两侧血液并不混合，是潜在代偿装置。
:::

:::callout{kind=note label="知识卡片：成环名单"}
前交通 → 左、右大脑前 → 左、右颈内 → 左、右后交通 → 左、右大脑后。

缺一不算闭合环。大脑中动脉是颈内动脉的直接延续，供血范围大，但不是环的一段。
:::

:::callout{kind=tip label="结论速记"}
Willis 环：**前、后交通 + 大脑前 + 颈内 + 大脑后**；不含大脑中。
:::

### 第8题

:::callout{kind=note label="题目"}
膀胱三角。

来源：简答题.doc · 「膀胱三角」
:::

:::callout{kind=insight label="解析"}
**【答案】** 膀胱底内面，两侧输尿管口与尿道内口围成的三角形区域。缺少黏膜下层，无论充盈或空虚都保持平滑，是肿瘤、结核、炎症的好发部位。
:::

:::callout{kind=note label="知识卡片：三角三顶点"}
两输尿管口 + 尿道内口。两输尿管口之间的横行皱襞称输尿管间襞，是膀胱镜寻找输尿管口的标志。
:::

:::callout{kind=tip label="结论速记"}
膀胱三角：**两输尿管口 + 尿道内口**，始终平滑，肿瘤结核好发。
:::

### 第9题

:::callout{kind=note label="题目"}
心包横窦。

来源：简答题.doc · 「心包横窦」
:::

:::callout{kind=insight label="解析"}
**【答案】** 心包腔在升主动脉、肺动脉干后方与上腔静脉、左心房前壁前方之间的间隙。心脏直视手术可在此钳夹升主动脉和肺动脉干。
:::

:::callout{kind=note label="知识卡片：三个心包窦"}
| 窦 | 位置 | 用途 |
|----|------|------|
| 横窦 | 主动脉、肺动脉后方 | 钳夹大血管 |
| 斜窦 | 左心房后壁与肺静脉、下腔静脉、心包后壁之间 | 口向下的盲囊 |
| 前下窦 | 心包前壁与膈交角 | 积液最低；穿刺走左剑肋角 |
:::

:::callout{kind=pitfall label="易错警示"}
横窦是手术钳夹通道，不是抽积液的地方。积液最低点在**前下窦**。
:::

:::callout{kind=tip label="结论速记"}
横窦 = **主、肺动脉后方**的左右通道，用来钳夹，不用来穿刺。
:::

### 第10题

:::callout{kind=note label="题目"}
胸膜隐窝。

来源：简答题.doc · 「胸膜隐窝」
:::

:::callout{kind=insight label="解析"}
**【答案】** 不同部位壁胸膜折返并相互移行处的胸膜腔，即使深吸气时肺缘也达不到其内。包括肋膈隐窝、肋纵隔隐窝、膈纵隔隐窝。

肋膈隐窝最低最大，是胸腔积液首先充满、穿刺抽液常选的部位。膈纵隔隐窝仅在左侧。
:::

:::callout{kind=note label="知识卡片：隐窝三户"}
| 隐窝 | 由谁折返 | 临床 |
|------|----------|------|
| 肋膈隐窝 | 肋胸膜 + 膈胸膜 | 最低最大，积液先到 |
| 肋纵隔隐窝 | 肋胸膜 + 纵隔胸膜 | 左侧较明显（心切迹） |
| 膈纵隔隐窝 | 膈胸膜 + 纵隔胸膜 | 仅左侧 |
:::

:::callout{kind=tip label="结论速记"}
胸膜隐窝是肺进不去的壁胸膜返折；积液先填**肋膈隐窝**。
:::

### 第11题

:::callout{kind=note label="题目"}
局部淋巴结。

来源：简答题.doc · 「局部淋巴结」
:::

:::callout{kind=insight label="解析"}
**【答案】** 引流某一器官或部位淋巴的第一级淋巴结，临床常称哨位淋巴结。肿瘤转移首先到达这一级。
:::

:::callout{kind=note label="知识卡片：哨位 vs Virchow"}
局部淋巴结是「这一器官的第一站」。Virchow 淋巴结是左侧前斜角肌前方的斜角肌淋巴结，胸、腹、盆部癌（尤其胃、食管腹段）可经胸导管转移到此，是远处转移的标志，不是所有器官的第一站。
:::

:::callout{kind=tip label="结论速记"}
局部淋巴结 = **第一级哨位淋巴结**。
:::

### 第12题

:::callout{kind=note label="题目"}
灰质。

来源：简答题.doc · 残片「灰质椎间盘」（两词连写，本条取灰质）
:::

:::callout{kind=insight label="解析"}
**【答案】** 中枢神经系统内神经元胞体及树突聚集的部位。在端脑和小脑表面铺开称皮质，在深部聚成团块或柱状称神经核。

:::callout{kind=note label="知识卡片：灰白质四户"}

|------|------|--------|
| 灰质 | 中枢 | 胞体聚集 |
| 皮质 | 中枢表面 | 铺开的灰质 |
| 神经核 | 中枢深部 | 团 / 柱状灰质 |
| 神经节 | 周围 | 胞体聚集 |
:::

:::callout{kind=tip label="结论速记"}
灰质 = **中枢里的胞体聚集**；表面叫皮质，深部叫核。
:::

### 第13题

:::callout{kind=note label="题目"}
椎间盘。

来源：简答题.doc · 残片「灰质椎间盘」（两词连写，本条取椎间盘）
:::

:::callout{kind=insight label="解析"}
**【答案】** 连结相邻两个椎体的纤维软骨盘，由周围的纤维环和中央的髓核构成。既坚韧又富弹性，缓冲外力并增加脊柱运动幅度。

第 1、2 颈椎之间没有椎间盘；成人通常 23 个。髓核易向后外侧突出，压迫脊神经根。
:::

:::callout{kind=note label="知识卡片：纤维环与髓核"}
纤维环是同心圆排列的纤维软骨，前厚后薄，所以突出多走后外侧。髓核是胶状，含水量高。前纵韧带限制后伸，后纵韧带限制前屈，但后纵韧带较窄，挡不住后外侧突出。
:::

:::callout{kind=tip label="结论速记"}
椎间盘 = **纤维环 + 髓核**；成人 23 个；突出走**后外侧**。
:::

## 二、运动系统简答

### 第14题

:::callout{kind=note label="题目"}
试述膈的位置和主要结构（分部、裂孔及穿行结构）。

来源：简答题.doc · 「位置和主要结构」及膈肌、裂孔残片
:::

:::callout{kind=insight label="解析"}
**【答案】** 膈位于胸、腹腔之间，构成胸腔的底。分周围的肌性部和中央的中心腱。肌束起自胸廓下口周缘和腰椎前面：胸骨部起自剑突后面，肋部起自下位肋和肋软骨，腰部起自上腰椎及内、外侧弓状韧带，各部均止于中心腱。

三个裂孔：
1. **腔静脉孔**约平 T8，有下腔静脉穿过
2. **食管裂孔**约平 T10，有食管和迷走神经穿过
3. **主动脉裂孔**位于两膈脚与脊柱之间，约平 T12，有主动脉和胸导管穿过

三部起点之间有胸肋三角、腰肋三角等薄弱区，无肌纤维，是膈疝的潜在部位。
:::

:::callout{kind=note label="知识卡片：膈三孔"}
| 裂孔 | 约平 | 穿行 |
|------|------|------|
| 腔静脉孔 | T8 | 下腔静脉 |
| 食管裂孔 | T10 | 食管 + 迷走神经 |
| 主动脉裂孔 | T12 | 主动脉 + 胸导管 |
:::

:::callout{kind=tip label="结论速记"}
膈三孔口诀：**腔 8、食 10、主 12**；食管裂孔还走迷走，主动脉裂孔还走胸导管。
:::

### 第15题

:::callout{kind=note label="题目"}
试述肩关节的组成、结构特点及运动。

来源：简答题.doc · 「试述肩关节的组成 / 结构特点及运动」
:::

:::callout{kind=insight label="解析"}
**【答案】** 由肱骨头和肩胛骨的关节盂构成，是多轴球窝关节。

特点：头大盂浅，虽有盂唇加深，仍仅能容纳关节头的一小部分，运动幅度大而稳固性差。关节囊薄而松弛，肩胛骨端附于关节盂缘，肱骨端附于解剖颈，内侧可达外科颈；肱二头肌长头腱穿经囊内；上壁有喙肱韧带加强，前、后壁有肌腱加入，**下壁最薄弱**，故易向前下方脱位。

运动：屈、伸、收、展、旋内、旋外及环转。
:::

:::callout{kind=note label="知识卡片：肩 vs 髋"}
| | 肩 | 髋 |
|--|----|----|
| 构成 | 肱骨头 + 关节盂 | 股骨头 + 髋臼 |
| 匹配 | 头大盂浅 | 头圆臼深，有髋臼唇 |
| 囊 | 薄松，下壁弱 | 坚韧，髂股韧带限制过伸 |
| 脱位 | 前下方 | 相对少 |
:::

:::callout{kind=tip label="结论速记"}
肩关节：**头大盂浅、囊松下弱、前下脱位**，全身最灵活。
:::

### 第16题

:::callout{kind=note label="题目"}
试述骨盆的构成、分部及小骨盆上、下口的构成。

来源：简答题.doc · 「试述骨盆的构成 / 分部及小骨盆上下口的构成」
:::

:::callout{kind=insight label="解析"}
**【答案】** 由左、右髋骨和骶骨、尾骨及其骨连结构成。界线以上为大骨盆，以下为小骨盆。

小骨盆上口（界线）：骶骨岬 → 弓状线 → 耻骨梳 → 耻骨结节 → 耻骨联合上缘。

小骨盆下口：尾骨尖、骶结节韧带、坐骨结节、坐骨支、耻骨下支和耻骨联合下缘，呈菱形。
:::

:::callout{kind=note label="知识卡片：上下口不要漏韧带"}
下口后外侧边是**骶结节韧带**，漏写菱形会缺边。产科说的骨盆入口就是上口。
:::

:::callout{kind=tip label="结论速记"}
骨盆 = **两髋 + 骶 + 尾**；上口走界线，下口记得**骶结节韧带**。
:::

### 第17题

:::callout{kind=note label="题目"}
试述臂丛的组成、位置及主要分支。

来源：简答题.doc · 「臂丛的组成 / 位置及主要分支」
:::

:::callout{kind=insight label="解析"}
**【答案】** 由第 5～8 颈神经前支和第 1 胸神经前支的大部分组成。穿斜角肌间隙，在锁骨下动脉后上方进入腋窝。

锁骨上部主要分支：胸长神经、肩胛背神经、肩胛上神经。

锁骨下部按三束发终支：
- 外侧束：肌皮神经、正中神经外侧根、胸外侧神经
- 内侧束：正中神经内侧根、尺神经、臂内侧皮神经、前臂内侧皮神经、胸内侧神经
- 后束：腋神经、桡神经、肩胛下神经、胸背神经
:::

:::callout{kind=note label="知识卡片：斜角肌间隙"}
前、中斜角肌与第 1 肋围成。走**臂丛 + 锁骨下动脉**。锁骨下静脉在前斜角肌前方，**不进**此间隙。
:::

:::callout{kind=tip label="结论速记"}
臂丛 **C5～T1**，出斜角肌间隙；后束出**腋神经和桡神经**。
:::

### 第18题

:::callout{kind=note label="题目"}
某处肌肉瘫痪是何神经损伤？肱骨中段骨折等常见损伤有何表现？

来源：简答题.doc · 「某处肌肉瘫痪 / 是何神经损伤」及桡、尺、正中、腋、腓总、动眼、滑车、面、舌下残片
:::

:::callout{kind=insight label="解析"}
**【答案】** 按损伤部位对号入座（残片给出的典型表现）：

| 神经 | 常见损伤原因 | 主要表现 |
|------|----------------|----------|
| 桡神经 | 肱骨中段骨折 | 垂腕；虎口区皮肤感觉障碍 |
| 骨间后神经 | 桡骨颈骨折 | 伸腕无力、不能伸指 |
| 尺神经 | 肱骨内上髁 / 尺侧腕屈肌起点 | 爪形手；环、小指远节不能屈；小鱼际和骨间肌萎缩；拇指不能内收；手尺侧皮肤感觉障碍 |
| 正中神经 | 旋前肌综合征等 | 不能旋前、屈腕减弱、拇示指不能屈、不能对掌、鱼际萎缩；感觉以桡侧三指远节最明显 |
| 腋神经 | 肱骨外科颈骨折 / 肩关节脱位 | 三角肌瘫痪萎缩，上肢不能外展 |
| 腓总神经 | 腓骨颈 | 足不能背屈、趾不能伸；足下垂内翻（马蹄内翻足） |
| 动眼神经 | 颅内压 / 海绵窦 | 上睑下垂、眼外斜视、瞳孔散大、对光反射消失 |
| 滑车神经 | — | 眼不能转向外下 |
| 面神经核上瘫 | 对侧皮质核束 | 病灶对侧眼裂**以下**面肌瘫（额纹仍在） |
| 面神经核下瘫 | 面神经核或面神经 | 同侧全部面肌瘫（额纹消失、眼不能闭） |
| 舌下神经核上瘫 | 对侧皮质核束 | 伸舌偏向病灶**对侧** |
| 舌下神经核下瘫 | 核或舌下神经 | 伸舌偏向病灶**侧**，伴萎缩 |
:::

:::callout{kind=note label="知识卡片：核上瘫 vs 核下瘫"}
额肌、眼轮匝肌受双侧皮质核束支配，核上瘫额纹不消失。口轮匝肌、舌下神经核主要受对侧支配。口角被健侧面肌拉向健侧，不要写成「口角歪向患侧」。
:::

:::callout{kind=tip label="结论速记"}
肱骨中段 → **桡神经、垂腕**；内上髁 → **尺神经、爪形手**；外科颈 → **腋神经、不能外展**；腓骨颈 → **马蹄内翻足**。
:::

### 第31题

:::callout{kind=note label="题目"}

### 第37题

:::callout{kind=note label="题目"}
试述肝门静脉的组成、结构特点、属支，以及与腔静脉的吻合途径。肝门静脉高压时胃肠道血液可经何途径回流入心？

来源：简答题.doc · 「试述门静脉的组成 / 结构特点 / 属支及吻合」；「肝门静脉高压时胃肠道血液可经何途径回流入心」并入
:::

:::callout{kind=insight label="解析"}
**【答案】** 由肠系膜上静脉与脾静脉在胰颈后方汇合而成。经肝十二指肠韧带，在肝固有动脉和胆总管的**后方**上行至肝门，分为肝左、右支入肝。

特点：起止都是毛细血管（一端收腹腔不成对脏器的静脉血，一端连肝血窦）；无瓣膜。

主要属支：肠系膜上静脉、脾静脉、肠系膜下静脉（多注入脾静脉）、胃左静脉、胃右静脉、胆囊静脉、附脐静脉。

高压时侧支（残片路径）：
1. **食管静脉丛**：胃左静脉 ↔ 食管静脉 ↔ 奇静脉 / 半奇静脉 ↔ 上腔静脉（临床：食管静脉曲张、呕血）
2. **直肠静脉丛**：直肠上静脉 ↔ 直肠下静脉 / 肛静脉 ↔ 髂内静脉 ↔ 下腔静脉（便血）
3. **脐周静脉网**：附脐静脉 ↔ 腹壁上、下静脉 ↔ 上、下腔静脉（海蛇头）
4. **腹后壁（Retzius）**：肠系膜静脉 ↔ 肋间后静脉、腰静脉等 ↔ 腔静脉
:::

:::callout{kind=pitfall label="易错警示"}
肝门静脉收集的是腹腔**不成对**脏器（除肝本身以外）。肾、肾上腺走腔静脉系，不要写进门静脉属支。
:::

:::callout{kind=tip label="结论速记"}
门静脉 = **肠系膜上静脉 + 脾静脉**（胰颈后）；高压三大口：**食管、直肠、脐周**。
:::

:::callout{kind=tip label="结论速记"}
双眼颞侧偏盲 → **视交叉中央**（交叉的鼻侧纤维）。
:::

### 第49题

:::callout{kind=note label="题目"}
试述脊髓节段与椎骨节段的位置关系。

来源：简答题.doc · 「试述脊髓节段与椎骨节段的位置关系」
:::

:::callout{kind=insight label="解析"}
**【答案】** 成人脊髓短于椎管，下端约平 L1 椎体下缘。本版对应：

| 脊髓节段 | 约平对的椎骨 |
|----------|----------------|
| 上颈髓 C1～C4 | 同序数椎骨 |
| 下颈髓 C5～C8、上胸髓 T1～T4 | 同序数椎骨的上 1 块 |
| 中胸髓 T5～T8 | 同序数椎骨的上 2 块 |
| 下胸髓 T9～T12 | 同序数椎骨的上 3 块 |
| 腰髓 | 第 10～12 胸椎 |
| 骶髓、尾髓 | 第 1 腰椎 |
:::

:::callout{kind=note label="知识卡片：腰穿平面"}
成人圆锥平 L1 下缘，腰穿选 L3～L4 或 L4～L5 棘突间，进的是终池，不是脊髓。
:::

:::callout{kind=tip label="结论速记"}
上颈同位、下颈上一、中胸上二、下胸上三、腰对下胸、骶尾对 L1。
:::

### 第50题

:::callout{kind=note label="题目"}
试述躯干和四肢意识性本体感觉和精细触觉传导通路。

来源：简答题.doc · 「试述躯干和四肢意识性本体感觉和精细触觉传导通路」
:::

:::callout{kind=insight label="解析"}
**【答案】** 三级神经元，在延髓交叉。

1. **第一级**：脊神经节细胞。周围突至肌、腱、关节和皮肤精细触觉感受器；中枢突经后根入同侧后索：T5 以下走**薄束**，T4 以上走**楔束**，上行至延髓薄束核、楔束核
2. **第二级**：薄、楔束核细胞发出内弓状纤维，在中央管腹侧交叉（内侧丘系交叉），此后称**内侧丘系**，止于背侧丘脑腹后外侧核（VPL）
3. **第三级**：VPL 发丘脑中央辐射，经内囊后肢至中央后回中上部和中央旁小叶后部，并至中央前回
:::

:::callout{kind=pitfall label="易错警示"}
浅感觉（痛温）在脊髓交叉；深感觉在**延髓**交叉。脊髓半切：伤侧深感觉障碍、对侧痛温障碍（Brown-Séquard）。
:::

:::callout{kind=tip label="结论速记"}
深感觉：**后索 → 薄楔束核 → 内侧丘系交叉 → VPL → 内囊后肢**。
:::

### 第51题

:::callout{kind=note label="题目"}
左手小指被锐物扎到，痛觉如何传导到大脑？投射部位在哪？

来源：简答题.doc · 「左手小指被锐物扎到疼痛 / 如何传导到大脑及部位」
:::

:::callout{kind=insight label="解析"}
**【答案】** 浅感觉（痛温）通路，脊髓内交叉。

左手小指 → 尺神经 → 臂丛下干 / 内侧束 → C8～T1 脊神经节 → 后根入后角 → 上升 1～2 节段经白质前连合交叉到对侧 → 脊髓丘脑侧束（痛温）→ 延髓、脑桥、中脑 → 背侧丘脑 VPL → 丘脑中央辐射 → 内囊后肢 → **右侧中央后回中部**（手区；小指不在中央旁小叶，中央旁小叶后部主要是足和会阴）。
:::

:::callout{kind=pitfall label="易错警示"}
残片把投射写成「中央后回中上部和中央旁小叶后部」，那是躯干下肢的通用结尾。小指的皮质区在中央后回**中部偏外**的手区。残片后半混入皮质脊髓束和肌皮神经，与小指痛觉无关，不采用。
:::

:::callout{kind=tip label="结论速记"}
小指痛觉：尺神经 → 后角 → **脊髓交叉** → 脊髓丘脑侧束 → VPL → 对侧中央后回手区。
:::

### 第52题

:::callout{kind=note label="题目"}
试述第四脑室的位置、构成和交通。

来源：简答题.doc · 「试述第四脑室的位置 / 构成和交通」
:::

:::callout{kind=insight label="解析"}
**【答案】** 位于延髓、脑桥与小脑之间，呈四棱锥形。底为菱形窝，顶向后上朝向小脑。顶的后部有第四脑室脉络组织，突入脑室的部分为第四脑室脉络丛。

交通：向上借中脑水管通第三脑室；向下连通脊髓中央管；经菱形窝下角的正中孔和外侧隐窝尖端的成对外侧孔通入蛛网膜下隙。
:::

:::callout{kind=tip label="结论速记"}
第四脑室在**脑桥延髓与小脑之间**；上通中脑水管，下通中央管，三孔通蛛网膜下隙。
:::

### 第54题

:::callout{kind=note label="题目"}
简述内囊的位置、分部及各部通过的主要纤维束，并说明损伤表现。

来源：简答题.doc · 「简述内囊的位置 / 分部及各部通过的主要纤维束」；「损伤的表现」并入
:::

:::callout{kind=insight label="解析"}
**【答案】** 位于背侧丘脑、尾状核和豆状核之间。水平切面呈 “<” 形，分前肢、膝、后肢。豆纹动脉（大脑中动脉中央支）营养，易出血。

| 分部 | 主要纤维 |
|------|----------|
| 前肢 | 丘脑前辐射、额桥束 |
| 膝 | 皮质核束 |
| 后肢 | 皮质脊髓束、皮质红核束、丘脑中央辐射、视辐射、听辐射 |

损伤（三偏综合征）：丘脑中央辐射 → 对侧偏身感觉障碍；皮质核束 + 皮质脊髓束 → 对侧偏瘫（核上性面、舌瘫 + 肢体硬瘫）；视辐射 → 双眼对侧同向性偏盲。
:::

:::callout{kind=tip label="结论速记"}
内囊在丘脑、尾状核与豆状核之间；出血典型**三偏**。
:::

### 第55题

:::callout{kind=note label="题目"}
大脑皮质第一躯体运动区、第一躯体感觉区、各语言中枢分别位于何处？第一躯体运动区和第一躯体感觉区在大脑皮质上投影的特点是什么？

来源：简答题.doc · 「大脑皮质第一躯体运动区 / 第一躯体感觉区 / 各语言中枢」
:::

:::callout{kind=insight label="解析"}
**【答案】**
- **第一躯体运动区**：中央前回和中央旁小叶前部
- **第一躯体感觉区**：中央后回和中央旁小叶后部
- **视区**：距状沟上、下的楔叶和舌回
- **运动性语言中枢（说话）**：额下回后部
- **书写中枢**：额中回后部
- **听觉性语言中枢**：颞上回后部
- **视觉性语言中枢**：角回

残片把「视觉性语言中枢」写在额中回后部，与本版不符：额中回后部是**书写中枢**。

投影特点：①上下颠倒，但头部正立；②左右交叉（除受双侧支配的联合运动肌）；③投影区大小与形体大小无关，而与功能重要性和复杂程度、感觉灵敏程度有关。
:::

:::callout{kind=tip label="结论速记"}
运动在中央**前**，感觉在中央**后**；说话额下回，书写额中回，听懂颞上回，阅读在**角回**。
:::

### 第56题

:::callout{kind=note label="题目"}
试述脑干脑神经核团的分类，每一种核团举几例说明。

来源：简答题.doc · 「试述脑干的脑神经核团的分类 / 每一种核团举几例说明」
:::

:::callout{kind=insight label="解析"}
**【答案】** 按纤维成分分成四类功能柱（躯体 / 内脏 × 运动 / 感觉）。

| 核团类型 | 例子 |
|----------|------|
| 一般躯体运动核 | 动眼神经核、滑车神经核、展神经核、舌下神经核 |
| 特殊内脏运动核（鳃弓） | 三叉神经运动核、面神经核、疑核、副神经核 |
| 一般内脏运动核（副交感） | 动眼神经副核、上泌涎核、下泌涎核、迷走神经背核 |
| 一般内脏感觉核 | 孤束核（下部） |
| 特殊内脏感觉核 | 孤束核（上部，味觉） |
| 一般躯体感觉核 | 三叉神经中脑核、脑桥核、脊束核 |
| 特殊躯体感觉核 | 前庭神经核、蜗神经核 |
:::

:::callout{kind=note label="知识卡片：脑干连哪几对脑神经"}
中脑连 III、IV；脑桥连 V、VI、VII、VIII；延髓连 IX、X、XI、XII。I 连端脑，II 连间脑，不在脑干核团表里。
:::

:::callout{kind=tip label="结论速记"}
脑干核团先切**运动 / 感觉**，再切**躯体 / 内脏**；孤束核管内脏感觉，三叉三个核管头面躯体感觉。
:::
