## 一、填空题

### 第1题

:::callout{kind=note label="题目"}
运动系统包括 ________、________ 和 ________ 三部分。
:::

:::callout{kind=insight label="解析"}
**【答案】骨、骨连结、骨骼肌**

运动系统三件套：骨是杠杆，骨连结是枢纽，骨骼肌是动力。少写「骨连结」或把「骨骼」当成已经包含关节，后面关节学整章会没有户头。
:::

:::callout{kind=note label="知识卡片：运动系统三户"}
| 构件 | 职能 |
|------|------|
| 骨 | 支架、杠杆、造血、钙磷库 |
| 骨连结 | 直接连结或滑膜关节 |
| 骨骼肌 | 收缩产生运动 |
:::

:::callout{kind=tip label="结论速记"}
运动系统 = **骨 + 骨连结 + 骨骼肌**。
:::

---

### 第2题

:::callout{kind=note label="题目"}
根据骨的外形，可将骨分为 ________、________、________ 和 ________ 四类。
:::

:::callout{kind=insight label="解析"}
**【答案】长骨、短骨、扁骨、不规则骨**

四类按外形，不是按「有没有骨髓」。籽骨是长骨肌腱里的特例，不另立第五类。
:::

:::callout{kind=pitfall label="易错警示"}
漏写短骨、把椎骨写成「长骨」都会丢空。椎骨、髋骨是不规则骨。
:::

:::callout{kind=tip label="结论速记"}
骨外形四类：**长、短、扁、不规则**。
:::

---

### 第3题

:::callout{kind=note label="题目"}
骨的构造主要由 ________、________ 和 ________ 构成，此外还有血管和神经等。
:::

:::callout{kind=insight label="解析"}
**【答案】骨质、骨髓、骨膜**

源答案顺序是骨质、骨髓、骨膜。本版教材常写骨质、骨膜、骨髓，三件都要在，顺序不扣。
:::

:::callout{kind=note label="知识卡片：骨质再切一刀"}
骨质分骨密质和骨松质。骨膜分骨外膜、骨内膜。骨髓红、黄可随年龄互变。
:::

:::callout{kind=tip label="结论速记"}
骨构造三件：**骨质、骨膜、骨髓**。
:::

---

### 第4题

:::callout{kind=note label="题目"}
上、下牙弓将口腔分为前方 ________ 和后方 ________ 的两部分。
:::

:::callout{kind=insight label="解析"}
**【答案】口腔前庭、固有口腔**

牙弓以外、唇颊以内是口腔前庭；牙弓以内才是固有口腔。张口不够大时，两者经最后磨牙后方的间隙相通。
:::

:::callout{kind=tip label="结论速记"}
牙弓前 = **口腔前庭**，牙弓后 = **固有口腔**。
:::

---

### 第5题

:::callout{kind=note label="题目"}
咽峡是由 ________、________ 和 ________ 共同围成的。
:::

:::callout{kind=insight label="解析"}
**【答案】腭垂、腭舌弓、舌根**

咽峡是口腔通向咽的门户。源答案三件：腭垂、腭舌弓、舌根。更完整的围成还要加上腭帆游离缘；**腭咽弓不参与**。
:::

:::callout{kind=pitfall label="易错警示"}
写成腭咽弓是经典错项。腭舌弓在前，腭咽弓在后，两弓之间才是扁桃体窝。
:::

:::callout{kind=tip label="结论速记"}
咽峡：**腭垂 + 腭舌弓 + 舌根**（可补腭帆游离缘）；不含腭咽弓。
:::

---

### 第6题

:::callout{kind=note label="题目"}
舌被 ________ 分为前 2/3 的 ________ 和后 1/3 的 ________。
:::

:::callout{kind=insight label="解析"}
**【答案】界沟、舌体、舌根**

界沟前方是舌体（口部），后方是舌根（咽部）。舌尖是舌体前端，不要把舌尖写成第三部来占空。
:::

:::callout{kind=tip label="结论速记"}
界沟：前 2/3 **舌体**，后 1/3 **舌根**。
:::

---

### 第7题

:::callout{kind=note label="题目"}
喉软骨包括单块的 ________、________、________ 和成对的 ________。
:::

:::callout{kind=insight label="解析"}
**【答案】甲状软骨、环状软骨、会厌软骨、杓状软骨**

三块单软骨 + 一对杓状软骨。小角软骨、楔状软骨是成对的小结节软骨，本空不写。
:::

:::callout{kind=note label="知识卡片：喉软骨户头"}
| | 单块 | 成对 |
|--|------|------|
| 必背 | 甲状、环状、会厌 | 杓状 |
| 环状软骨 | 唯一完整软骨环 | 下接气管 |
:::

:::callout{kind=tip label="结论速记"}
单：甲状、环状、会厌；对：**杓状**。
:::

### 第8题

:::callout{kind=note label="题目"}
成人肾门约平第 ________ 椎体，肾门在腹后壁的体表投影一般在 ________ 外侧缘与第 ________ 肋所成的夹角内。
:::

:::callout{kind=insight label="解析"}
**【答案】1 腰（L1）、竖脊肌、12**

肾门平 L1。该夹角就是**肾区**（脊肋角），叩击痛在这里查。
:::

:::callout{kind=pitfall label="易错警示"}
写成第 11 肋是错的。第 12 肋斜过左肾后面中部、右肾后面上部，不要和肾区用肋搞混。
:::

:::callout{kind=tip label="结论速记"}
肾门 **L1**；肾区 = **竖脊肌外侧缘 × 第 12 肋**。
:::

### 第9题

:::callout{kind=note label="题目"}
一般左肾上端约平 ________ 椎体下缘，右肾上端约平第 ________ 椎体。
:::

:::callout{kind=insight label="解析"}
**【答案】11 胸（T11）、12 胸（T12）**

右肾被肝压低约半个椎体。完整高度：左肾 T11 下缘～L2 下缘；右肾 T12～L3。
:::

:::callout{kind=tip label="结论速记"}
左肾高：**T11 下缘**；右肾低：**T12**。
:::

### 第10题

:::callout{kind=note label="题目"}
射精管是由 ________ 末端与 ________ 的排泄管汇合而成。
:::

:::callout{kind=insight label="解析"}
**【答案】输精管、精囊腺**

输精管壶腹末端与精囊排泄管合成射精管，穿前列腺开口于尿道前列腺部精阜两侧。
:::

:::callout{kind=tip label="结论速记"}
射精管 = **输精管末端 + 精囊排泄管**。
:::

### 第11题

:::callout{kind=note label="题目"}
右心房的出口叫 ________，其与 ________ 之间有冠状窦口。
:::

:::callout{kind=insight label="解析"}
**【答案】右房室口、下腔静脉口**

右心房三个入口：上腔静脉口、下腔静脉口、冠状窦口；唯一出口是右房室口。冠状窦口紧挨下腔静脉口与右房室口之间。源 dump「房窒口」为笔误。
:::

:::callout{kind=tip label="结论速记"}
右房出口 = **右房室口**；冠状窦口在它与 **下腔静脉口** 之间。
:::

---

### 第12题

:::callout{kind=note label="题目"}
右心室的入口叫 ________，出口为 ________。
:::

:::callout{kind=insight label="解析"}
**【答案】右房室口、肺动脉口**

入口周缘附三尖瓣，出口周缘附肺动脉瓣。不要把主动脉口写给右室。
:::

:::callout{kind=tip label="结论速记"}
右室：**右房室口进、肺动脉口出**。
:::

---

### 第13题

:::callout{kind=note label="题目"}
左心室的入口称 ________，出口为 ________。
:::

:::callout{kind=insight label="解析"}
**【答案】左房室口、主动脉口**

入口二尖瓣，出口主动脉瓣。主动脉前庭是出口前方的光滑区。
:::

:::callout{kind=tip label="结论速记"}
左室：**左房室口进、主动脉口出**。
:::

### 第14题

:::callout{kind=note label="题目"}
房室口的周缘附有 ________，各借 ________ 与乳头肌相连。
:::

:::callout{kind=insight label="解析"}
**【答案】房室瓣、腱索**

右是三尖瓣，左是二尖瓣。腱索连瓣缘与乳头肌，防止心室收缩时瓣膜翻入心房。
:::

:::callout{kind=tip label="结论速记"}
房室口：**房室瓣 — 腱索 — 乳头肌**。
:::

### 第15题

:::callout{kind=note label="题目"}
睫状体位于 ________ 与 ________ 之间，其内含有的平滑肌称 ________，此肌的收缩与舒张有调节 ________ 的作用。
:::

:::callout{kind=insight label="解析"}
**【答案】脉络膜、虹膜；睫状肌；晶状体折光率（或凸度）**

血管膜（中膜）自后向前：脉络膜 → 睫状体 → 虹膜。看近物时睫状肌收缩，睫状小带放松，晶状体变凸。
:::

:::callout{kind=tip label="结论速记"}
睫状体夹在 **脉络膜与虹膜** 之间；**睫状肌** 调晶状体凸度。
:::

### 第16题

:::callout{kind=note label="题目"}
视网膜视部由三种神经元构成，由外向内依次为 ________、________ 和 ________。
:::

:::callout{kind=insight label="解析"}
**【答案】视细胞（视杆细胞和视锥细胞）、双极细胞、节细胞**

外层感光，中层传导，内层把轴突汇成视神经。色素上皮在更外层，不是这三种神经元。
:::

:::callout{kind=tip label="结论速记"}
视部由外向内：**视细胞 → 双极细胞 → 节细胞**。
:::

---

### 第17题

:::callout{kind=note label="题目"}
新纹状体包括 ________ 和 ________。
:::

:::callout{kind=insight label="解析"}
**【答案】尾状核、壳**

纹状体 = 尾状核 + 豆状核。豆状核 = 壳 + 苍白球。新纹状体 = 尾状核 + 壳；旧纹状体 = 苍白球。
:::

:::callout{kind=pitfall label="易错警示"}
把苍白球写进新纹状体，或把整个豆状核当成新纹状体，都错。
:::

:::callout{kind=tip label="结论速记"}
新纹状体 = **尾状核 + 壳**。
:::

### 第18题

:::callout{kind=note label="题目"}
脑和脊髓的被膜由外而内依次为 ________、________ 和 ________。
:::

:::callout{kind=insight label="解析"}
**【答案】硬膜、蛛网膜、软膜**

硬膜外隙（脊）、硬膜下隙（潜在）、蛛网膜下隙（脑脊液）都挂在这三层上。
:::

:::callout{kind=tip label="结论速记"}
被膜外→内：**硬膜、蛛网膜、软膜**。
:::

### 第19题

:::callout{kind=note label="题目"}
脊髓丘脑束起于 ________ 侧的 ________ 核。
:::

:::callout{kind=insight label="解析"}
**【答案】对、后角固有核**

后角固有核发纤维经白质前连合交叉到对侧，再组成脊髓丘脑束上行，止于背侧丘脑腹后核（主要为腹后外侧核）。
:::

:::callout{kind=tip label="结论速记"}
脊髓丘脑束起于 **对侧后角固有核**。
:::

### 第20题

:::callout{kind=note label="题目"}
附着于中脑的脑神经是 ________ 神经和 ________ 神经。
:::

:::callout{kind=insight label="解析"}
**【答案】动眼、滑车**

动眼神经自脚间窝出脑，滑车神经是唯一从脑干背面出脑的脑神经（下丘下方）。三叉在脑桥，展、面、前庭蜗在桥延沟，舌咽、迷走、副、舌下在延髓。
:::

:::callout{kind=tip label="结论速记"}
中脑只挂 **III、IV**。
:::

## 二、单项选择题

### 第1题

:::callout{kind=note label="题目"}
每块椎骨均具有（　　）

A. 横突　　B. 横突孔　　C. 末端分叉的棘突　　D. 上、下关节突　　E. 肋凹
:::

:::callout{kind=insight label="解析"}
**【答案】A**

横突孔只在颈椎；棘突分叉是典型颈椎；肋凹是胸椎；关节突在寰椎变为关节凹，表述不如「横突」稳。寰椎无椎体、无棘突，但仍有横突。
:::

:::callout{kind=tip label="结论速记"}
「每块椎骨都有」优先锁 **横突**；孔、分叉、肋凹都是分区特征。
:::

---

### 第2题

:::callout{kind=note label="题目"}
胸椎的特征（　　）

A. 有横突孔　　B. 棘突分叉　　C. 椎体侧方有肋凹　　D. 没有明显的上、下关节突　　E. 椎体大而粗壮
:::

:::callout{kind=insight label="解析"}
**【答案】C**

胸椎靠肋凹接肋。A、B 是颈椎；E 是腰椎；关节突胸椎也有。
:::

:::callout{kind=tip label="结论速记"}
胸椎认 **肋凹**。
:::

### 第3题

:::callout{kind=note label="题目"}
围成椎孔的是（　　）

A. 上、下相邻的椎弓根　　B. 椎弓根与椎弓板　　C. 椎体与椎弓　　D. 上、下相邻的棘突　　E. 上、下相邻的椎弓
:::

:::callout{kind=insight label="解析"}
**【答案】C**

椎孔 = 椎体 + 椎弓（椎弓根 + 椎弓板）。上下椎孔叠成椎管。A、E 说的是椎间孔/椎管的上下邻接，不是单块椎骨的椎孔。
:::

:::callout{kind=tip label="结论速记"}
椎孔 = **椎体 + 椎弓**。
:::

### 第4题

:::callout{kind=note label="题目"}
下颌下腺的导管开口于（　　）

A. 舌系带　　B. 舌下阜　　C. 舌扁桃体　　D. 舌下襞　　E. 舌根
:::

:::callout{kind=insight label="解析"}
**【答案】B**

下颌下腺管开口于舌下阜。舌下腺大管也开口于舌下阜，小管开口于舌下襞。腮腺管开口于上颌第二磨牙相对的颊黏膜。
:::

:::callout{kind=tip label="结论速记"}
下颌下腺管 → **舌下阜**。
:::

### 第5题

:::callout{kind=note label="题目"}
食管的第二狭窄在（　　）

A. 起始处　　B. 穿膈处　　C. 与左主支气管交叉处　　D. 与右主支气管交叉处　　E. 与胃相接处
:::

:::callout{kind=insight label="解析"}
**【答案】C**

三处狭窄：①起始（咽与食管交界，距中切牙约 15 cm）；②与左主支气管交叉（约 25 cm）；③穿膈食管裂孔（约 40 cm）。交叉的是左主支气管，不是右。
:::

:::callout{kind=tip label="结论速记"}
食管第二狭窄 = **左主支气管交叉**，约 25 cm。
:::

### 第6题

:::callout{kind=note label="题目"}
下列关于空、回肠的说法中，错误的是（　　）

A. 借小肠系膜固定于腹后壁　　B. 空肠占空、回肠全长的下 3/5　　C. 回肠位于腹腔的右下部　　D. 空肠有孤立淋巴滤泡　　E. 回肠有集合淋巴滤泡
:::

:::callout{kind=insight label="解析"}
**【答案】B**

空肠约占空回肠全长的**上 2/5**，回肠占下 3/5。B 把空肠写成下 3/5，是错句。集合淋巴滤泡主要在回肠。
:::

:::callout{kind=tip label="结论速记"}
空肠 **上 2/5**，回肠 **下 3/5**；集合淋巴滤泡在回肠。
:::

### 第7题

:::callout{kind=note label="题目"}
属于下呼吸道的是（　　）

A. 口腔　　B. 鼻　　C. 咽　　D. 气管　　E. 喉
:::

:::callout{kind=insight label="解析"}
**【答案】D**

临床上鼻、咽、喉为上呼吸道；气管、支气管及其分支和肺为下呼吸道。喉不算下呼吸道。
:::

:::callout{kind=tip label="结论速记"}
上呼吸道 = 鼻咽喉；下呼吸道从 **气管** 起。
:::

### 第8题

:::callout{kind=note label="题目"}
肾（　　）

A. 长轴呈垂直状　　B. 位于腹膜后面　　C. 右侧较左侧高　　D. 女性肾较男性肾高　　E. 第 12 肋斜过右肾下部
:::

:::callout{kind=insight label="解析"}
**【答案】B**

肾是腹膜外位器官，在腹膜后面。长轴斜向外下；右肾低于左肾；第 12 肋斜过右肾**上部**、左肾中部。E 把右肾「上部」写成「下部」。
:::

:::callout{kind=tip label="结论速记"}
肾 = **腹膜外位**；右低左高。
:::

### 第9题

:::callout{kind=note label="题目"}
不通过肾门的是（　　）

A. 输尿管　　B. 肾动脉　　C. 肾静脉　　D. 神经　　E. 淋巴管
:::

:::

:::callout{kind=insight label="解析"}
**【答案】** 肱骨头大、关节盂小、关节囊松弛。因此灵活性大于稳固性。

关节盂周缘有盂唇加深少许；囊的上、前、后壁有肌腱和韧带加强，**下壁薄弱**，肱骨头易向下脱位。肱二头肌长头腱穿囊内。
:::

:::callout{kind=note label="知识卡片：肩关节不要写成胸锁关节"}
上肢骨与躯干骨连结的唯一关节是胸锁关节，不是肩关节。肩关节是肱骨头与肩胛骨关节盂。
:::

:::callout{kind=tip label="结论速记"}
肩：**头大盂小囊松**，灵活＞稳固；下壁易脱。
:::

### 第2题

:::callout{kind=note label="题目"}
大唾液腺有哪几对？其导管各开口于何处？
:::

:::callout{kind=insight label="解析"}
**【答案】** 有腮腺、下颌下腺和舌下腺三对。腮腺导管开口于上颌第二磨牙相对的颊黏膜上。下颌下腺导管开口于舌下阜。舌下腺导管开口于舌下阜，另有若干小管开口于舌下襞。

腮腺 → 上颌第二磨牙颊黏膜；下颌下腺 → 舌下阜；舌下腺 → 舌下阜 + 舌下襞。

左、右肾在位置上有何区别？

### 第5题

:::callout{kind=note label="题目"}
男性尿道分哪几部？有哪些弯曲和狭窄？
:::

:::callout{kind=insight label="解析"}
**【答案】** 男性尿道分为前列腺部、膜部和海绵体部。有耻骨下弯和耻骨前弯两个弯曲，3 处狭窄分别位于尿道内口、尿道膜部和尿道外口。

耻骨下弯恒定；耻骨前弯可在上提阴茎时变直。三处扩大：前列腺部、尿道球、舟状窝。
:::

:::callout{kind=tip label="结论速记"}
男尿道三部、两弯、三窄：**内口、膜部、外口**。

### 第6题

:::callout{kind=note label="题目"}
心房与心室及左、右心室的表面分界标志是什么？
:::

:::callout{kind=insight label="解析"}
**【答案】** 心房与心室的表面分界标志是冠状沟。左、右心室的表面分界标志为前、后室间沟。

前室间沟有前室间支和心大静脉；后室间沟有后室间支和心中静脉。
:::

:::callout{kind=tip label="结论速记"}
房室交界 **冠状沟**；左右室交界 **前、后室间沟**。
:::

### 第8题

:::callout{kind=note label="题目"}
外界光线经过哪些结构才能投射到视网膜上？
:::

:::callout{kind=insight label="解析"}

源 dump「幢孔」为瞳孔。屈光装置四件是角膜、房水、晶状体、玻璃体；瞳孔是虹膜围成的孔，光路必经，但不是屈光介质。
:::

:::callout{kind=tip label="结论速记"}
光路：角膜 → 房水 → 瞳孔 → 晶状体 → 玻璃体 → 视网膜。

### 第9题

:::callout{kind=note label="题目"}
脊髓灰质后角固有核和前角运动细胞各接受什么纤维？发出的纤维（轴突）各形成什么结构？后者抵止于何处？
:::

:::callout{kind=insight label="解析"}
**【答案】** 脊髓灰质后角固有核接受脊神经后根的躯体浅感觉传入纤维，发出纤维经白质前连合交叉至对侧组成脊髓丘脑束，止于背侧丘脑腹后核。脊髓前角运动细胞接受皮质脊髓束纤维，发出纤维组成脊神经的躯体运动纤维。

前角细胞的轴突经前根出椎管，到达骨骼肌。丘脑端更精确是腹后外侧核。
:::

:::callout{kind=tip label="结论速记"}
后角固有核 → 交叉成 **脊髓丘脑束** → 丘脑腹后核；前角 → **脊神经运动纤维**。
:::

### 第10题

:::callout{kind=note label="题目"}
薄束和楔束起于何处？止于何处？有何作用？
:::

:::callout{kind=insight label="解析"}
**【答案】** 薄束和楔束起于（同侧）脊神经节，分别止于薄束核和楔束核，传导同侧颈以下的深感觉和精细触觉。

第 1 级胞体在脊神经节，中枢突走后根入后索：T4 以下占薄束，以上占楔束。第 2 级在延髓换元后交叉成内侧丘系。
:::

:::callout{kind=tip label="结论速记"}
薄、楔束：同侧脊神经节 → 薄束核 / 楔束核；**深感觉 + 精细触觉**。
:::
