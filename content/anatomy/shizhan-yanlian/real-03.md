## 一、单项选择题

### 第1题

:::callout{kind=note label="题目"}
瞳孔对光反射：直接对光反射消失、间接对光反射存在，损伤的是（　　）

来源：2021.12.30 回忆「直接对光反射无和间接对光反射有，什么损伤」
:::

:::callout{kind=insight label="解析"}
**【答案】同侧视神经（传入）**

光照侧缩小是直接反射，对侧缩小是间接反射。通路：视网膜 → 视神经 → 视交叉 → 视束 → 上丘臂 → 顶盖前区 → **两侧**动眼神经副核 → 动眼神经 → 睫状神经节 → 瞳孔括约肌。

患侧直接消失而间接存在：光照患眼时两侧都不缩（传入断），光照健眼时患眼仍能缩（传出通）→ 患侧视神经。一侧动眼神经伤则患侧直接、间接都消失。
:::

:::callout{kind=note label="知识卡片：传入断 vs 传出断"}
| | 光照患眼 | 光照健眼 |
|--|----------|----------|
| 视神经（传入） | 两眼都不缩 | 两眼都缩（患眼间接存在） |
| 动眼神经（传出） | 患眼不缩、健眼缩 | 患眼不缩、健眼缩 |
:::

:::callout{kind=tip label="结论速记"}
直接无、间接有 → **同侧视神经**。
:::

### 第2题

:::callout{kind=note label="题目"}
踢足球时膝关节损伤，最常伤及（　　）

来源：2021.12.30 回忆「踢足球膝关节损伤（前交叉韧带受损）」
:::

:::callout{kind=insight label="解析"}
**【答案】前交叉韧带**

前交叉韧带起自胫骨髁间隆起前方，止于股骨外侧髁内面，限制胫骨前移。急停、变向、膝关节屈曲外翻时最易断。后交叉韧带限制胫骨后移。
:::

:::callout{kind=tip label="结论速记"}
足球膝先想 **前交叉韧带**（防胫骨前移）。
:::

### 第3题

:::callout{kind=note label="题目"}
翼状肩：损伤的肌肉和支配该肌的神经是（　　）

来源：2021.12.30 回忆「翼状肩（损伤肌肉和支配该肌肉的神经）」
:::

:::callout{kind=insight label="解析"}
**【答案】前锯肌；胸长神经**

前锯肌把肩胛骨拉向前并紧贴胸廓。瘫痪后内侧缘和下角翘起，成翼状肩。胸长神经来自臂丛锁骨上部（C5–C7）。斜方肌瘫痪是塌肩，三角肌瘫痪是方肩，不要对调。
:::

:::callout{kind=tip label="结论速记"}
翼状肩 = **前锯肌 + 胸长神经**。
:::

:::callout{kind=note label="题目"}
男性尿道（　　）

A. 有两处扩大、三处狭窄
B. 两个弯曲不可矫正

### 第18题

:::callout{kind=note label="题目"}
肾（小书原题）（　　）

A. 肾门向内深入，形成肾盂
B. 上端窄薄
C. 下端宽后
D. 右肾比左肾高

来源：2021.12.30 回忆标 A
:::

:::callout{kind=insight label="解析"}
**【答案】回忆标 A；教材纠正：肾门向内深入形成的是肾窦，不是肾盂**

肾窦内容才包括肾盂、肾盏、血管和脂肪。B、C 与「上端宽而薄、下端窄而厚」不符；D 说反（右肾更低）。若原题问「正确的是」，A 的标准表述应是「形成肾窦」；若问「错误的是」，A 恰好是错句。本卷按教材记：**门 → 窦，窦内有盂**。
:::

:::callout{kind=pitfall label="易错警示"}
不要把肾门、肾窦、肾盂写成同一个洞。
:::

:::callout{kind=tip label="结论速记"}
肾门开口，**肾窦**是房间，肾盂放在房间里。
:::

### 第4题

:::callout{kind=note label="题目"}
王大爷与人激烈交谈时晕倒。检查：左侧偏瘫（硬瘫、肌张力高）；右侧视觉同向性偏盲；左侧偏身感觉丧失；左侧表情丧失（面瘫）；伸舌向患侧。问：受损的部位、交叉的位置、最后到达的传导束名称。（10 分）

来源：2021.12.30 回忆；注明类似大纲思考题
:::

:::callout{kind=insight label="解析"}
**【答案】**

一次同时出现对侧上运动神经元性偏瘫、对侧偏身感觉丧失、对侧中枢性面舌瘫，定位在**内囊**。锥体束在内囊尚未交叉，故**右侧内囊**（膝 + 后肢）损伤导致左侧症状。

| 体征 | 受损纤维 | 交叉部位 | 终止 |
|------|----------|----------|------|
| 左侧硬瘫 | 皮质脊髓束（内囊后肢前部） | 延髓锥体交叉 | 对侧脊髓前角 |
| 左侧面舌瘫（上运动神经元） | 皮质核束（内囊膝） | 面神经核下部、舌下神经核只接对侧，相当于核前交叉 | 对侧面神经核下部、舌下神经核 |
| 左侧偏身感觉丧失 | 丘脑中央辐射（内囊后肢） | 痛温觉在脊髓白质前连合；深感觉在延髓内侧丘系交叉 | 中央后回 |
| 同向性偏盲 | 视辐射（内囊后肢后部） | 鼻侧纤维已在视交叉交叉，视辐射不再交叉 | 距状沟视区 |

回忆写「右侧视觉同向性偏盲」。右侧视辐射损伤造成的是**双眼左侧视野**同向性偏盲（两眼右半视网膜纤维）。左右视野不要跟「右侧内囊」捆死成「右侧偏盲」。伸舌向患侧：患侧是左侧肢体，伸舌向左（健侧颏舌肌把舌推向瘫侧）。
:::

:::callout{kind=pitfall label="易错警示"}
内囊的皮质脊髓束还没交叉，伤右侧出现左侧硬瘫。不要写成「左侧内囊」。周围性面瘫是同侧全部面肌；这里是中枢性，病灶对侧下面部。
:::

:::callout{kind=tip label="结论速记"}
左偏瘫 + 左偏身感觉 + 中枢性面舌瘫 → **右侧内囊膝和后肢**；视辐射管对侧半视野。
:::
