## 一、单项选择题

### 第1题

:::callout{kind=note label="题目"}
支配肱二头肌的神经是（　　）

A. 尺神经　　B. 桡神经　　C. 正中神经　　D. 腋神经　　E. 肌皮神经
:::

:::callout{kind=insight label="解析"}
**【答案】E**

肌皮神经支配臂前群：肱二头肌、喙肱肌、肱肌。桡神经管臂后群；正中、尺神经主要下手；腋神经管三角肌和小圆肌。
:::

:::callout{kind=tip label="结论速记"}
肱二头肌 ← **肌皮神经**。
:::

| 桡神经沟 | 桡神经 |
| 尺神经沟 | 尺神经 |
:::

:::callout{kind=tip label="结论速记"}
外科颈 → **腋神经**。

### 第3题

:::callout{kind=note label="题目"}
下列各骨中，不属于长骨（　　）

A. 股骨　　B. 肱骨　　C. 跖骨　　D. 指骨　　E. 肋骨

:::callout{kind=insight label="解析"}
**【答案】E**

肋骨属扁骨。跖骨、指骨是长骨（有一体两端），不要因为短就改成短骨。

:::callout{kind=tip label="结论速记"}
肋骨是 **扁骨**，不是长骨。

### 第9题

:::callout{kind=note label="题目"}
关于肋的组成下列哪项是正确的（　　）

A. 真肋：1—7 肋，假肋：8—12 肋
B. 真肋：1—5 肋，假肋：6—10 肋；浮肋：11—12 肋
C. 真肋：1—8 肋，假肋：9—12 肋
D. 真肋：1—7 肋，假肋：8—10 肋；浮肋：11—12 肋
E. 以上都不是
:::

:::callout{kind=insight label="解析"}
**【答案】D**

:::

:::callout{kind=tip label="结论速记"}
真 1–7，假 8–10，浮 **11–12**。
:::

**【答案】** dump 只残「桡关节、桡尺近侧关节」。完整：肱尺关节、肱桡关节、桡尺近侧关节，包在同一关节囊内，以屈伸运动为主；桡尺近侧关节还参与旋前旋后。
:::

:::callout{kind=tip label="结论速记"}
肘 = **肱尺 + 肱桡 + 桡尺近侧**，主运动屈伸。
:::

### 第4题

:::callout{kind=note label="题目"}
脑脊液的产生及回流（6 分）
:::

:::callout{kind=insight label="解析"}
**【答案】** dump 仅「各脑室的脉络丛产生，侧脑室……上矢状窦」。补全：

各脑室脉络丛产生脑脊液 → 侧脑室 → 室间孔 → 第三脑室 → 中脑水管 → 第四脑室 → 正中孔和外侧孔 → 蛛网膜下腔 → 蛛网膜粒 → 上矢状窦（硬脑膜窦）→ 颈内静脉。

:::callout{kind=tip label="结论速记"}
脉络丛 → 四脑室孔 → 蛛网膜下腔 → **蛛网膜粒 → 上矢状窦**。
:::

### 第5题

:::callout{kind=note label="题目"}
肝门静脉与上、下腔静脉的主要吻合途径有哪些？
:::

:::callout{kind=insight label="解析"}
**【答案】**

1. 通过食管静脉丛与上腔静脉系吻合
2. 通过直肠静脉丛与下腔静脉吻合
3. 通过脐周静脉网与上、下腔静脉吻合

门脉高压时这三处可出现食管静脉曲张、痔和脐周「海蛇头」。
:::

:::callout{kind=tip label="结论速记"}
门腔吻合三丛：**食管、直肠、脐周**。

喉腔分哪几部分？各部分是如何划分的？（7 分）

### 第10题

:::callout{kind=note label="题目"}
头静脉注射抗生素治疗面部疖肿，药物如何到达患部？（6 分）
:::

:::callout{kind=insight label="解析"}
**【答案】** dump 仅「头静脉……面部」。按体循环补全：

头静脉 → 腋静脉 → 锁骨下静脉 → 头臂静脉 → 上腔静脉 → 右心房 → 右心室 → 肺动脉 → 肺毛细血管 → 肺静脉 → 左心房 → 左心室 → 主动脉 → 主动脉弓 → 头臂干 / 左颈总动脉 → 颈总动脉 → 颈外动脉 → 面动脉 → 患部。

dump「疥肿」为疖肿。
:::

:::callout{kind=tip label="结论速记"}
头静脉回心 → 肺 → 左心 → 颈外动脉 → **面动脉**。
:::
