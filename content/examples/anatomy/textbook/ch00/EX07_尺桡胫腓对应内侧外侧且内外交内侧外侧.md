**题目**：上/下的参照是颅顶和足底还是「此刻朝向天花板」？前/后与腹侧/背侧在解剖学姿势下是否同义？内侧/外侧的参照是人体正中矢状面还是「靠近心」？内（internal）/外（external）的参照是什么，能不能和内侧/外侧互换？浅/深的参照是皮肤表面还是内腔？近侧/远侧常用于何处，参照是肢体根部还是躯干的上/下？在解剖学姿势下，前臂的尺侧、桡侧分别对应内侧还是外侧，小腿的胫侧、腓侧呢？前臂旋前以后，「桡侧」要不要改口成「现在的内侧」？绪图-1 肠管断面画的是内/外还是内侧/外侧，大腿断面画的是浅/深还是上/下？

**解**：
教材 definition：**上 superior / 下 inferior**——近颅顶者为上，近足底者为下。比较解剖学常用颅侧（cranial）和尾侧（caudal）。教材 pitfall：**仰卧时「朝上」不等于解剖学的上。** 胸廓前壁朝向天花板是**前**，不是上。

教材 definition：**前 anterior＝腹侧 ventral；后 posterior＝背侧 dorsal。** 距身体腹侧面近者为前，距背侧面近者为后。教材举例：眼在前，耳在后。

教材 definition：**内侧 medial / 外侧 lateral**——距人体正中矢状面近者为内侧，远离者为外侧。如眼位于鼻的外侧、耳的内侧。教材 pitfall：**内侧/外侧是相对正中矢状面，不是相对「身体中心器官」。** 不要把「靠近心」写成内侧、「靠近体表」写成外侧。靠近体表的是浅，靠近内腔的是内。

教材 definition：**内 internal / 外 external**——近内腔者为内，离内腔远者为外。内腔可以是体腔，也可以是空腔器官的腔。教材 pitfall：**内、外与内侧、外侧不要互换。** 「胃内」指近胃腔；「胃的内侧」指胃相对正中矢状面更靠近中线的那一侧。血管「内膜」是近管腔的一层，不是「内侧的膜」。绪图-1 左上角肠管断面：黏膜近腔为内，外膜远离腔为外。

教材 definition：**浅 superficial / 深 profundal**——距皮肤表面近者为浅，远离体表者为深。本版英文用 profundal。教材 pitfall：**浅/深不是内/外，也不是上/下。** 背部的皮肤仍然是浅，尽管它在人体的后面。绪图-1 左下角大腿断面：皮肤、浅筋膜为浅；肌、股骨、坐骨神经为深。

教材 definition：**近侧 proximal / 远侧 distal**——常用于四肢，距肢体根部近者为近侧，远离者为远侧。上肢根部在肩，下肢根部在髋。教材 pitfall：**近侧/远侧不要用来写躯干的上/下。**

教材 definition：**尺侧 ulnar / 桡侧 radial；胫侧 tibial / 腓侧 fibular**——分别与其内侧和外侧相对应。解剖学姿势下：尺骨在内侧，尺侧＝内侧；桡骨在外侧，桡侧＝外侧；胫骨在内侧，胫侧＝内侧；腓骨在外侧，腓侧＝外侧。教材 pitfall：**尺桡、胫腓是按骨的位置，不要在旋前以后改口。** 前臂旋前时桡骨交叉到尺骨前方，但「桡侧」仍是距桡骨近的一侧，不改成「现在的内侧」。基准仍然是解剖学姿势（掌心向前）。

| 词对 | 参照 | 不要听成 |
|------|------|----------|
| 上 / 下 | 颅顶 / 足底 | 天花板方向 |
| 前 / 后（腹侧 / 背侧） | 腹侧面 / 背侧面 | 观察者对面 |
| 内侧 / 外侧 | 正中矢状面 | 「靠近心」；靠近体表 |
| 内 / 外 | 体腔或空腔器官的内腔 | 内侧 / 外侧 |
| 浅 / 深 | 皮肤表面 | 内 / 外；上 / 下 |
| 近侧 / 远侧 | 肢体根部（常用于四肢） | 躯干的上 / 下 |
| 尺侧 / 桡侧 | 尺骨 / 桡骨；对应内侧 / 外侧 | 旋前以后改口 |
| 胫侧 / 腓侧 | 胫骨 / 腓骨；对应内侧 / 外侧 | 与尺桡对调 |

易错点：内/外与内侧/外侧并户；浅/深写成内/外；尺侧写成外侧；旋前以后改口桡侧；近侧用来写胃的「上面」；仰卧朝上写成上。
