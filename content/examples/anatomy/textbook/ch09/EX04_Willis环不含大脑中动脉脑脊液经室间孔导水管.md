**题目**：大脑动脉环（Willis 环）由哪几段围成，大脑中动脉算不算环壁，缺哪一条交通动脉环就不完整？脑脊液主要由什么产生、成人约多少毫升，从侧脑室走到上矢状窦要经过哪些孔和管，缺哪一站会积水？

**解**：
教材 compare：**大脑动脉环（Willis 环）组成**——位于脑底下方、蝶鞍上方，环绕视交叉、灰结节及乳头体。本版环壁：**两侧大脑前动脉起始段 + 前交通动脉 + 两侧颈内动脉末段 + 两侧后交通动脉 + 两侧大脑后动脉**。正常时两侧血液不相混合，是潜在代偿结构。教材 pitfall：**不要写成「Willis 环 = 大脑前 + 大脑中 + 大脑后」。** 大脑中动脉是颈内动脉的直接延续，向外进外侧沟，**不构成环壁**。缺前交通或后交通，环就不完整。豆纹动脉是大脑中动脉的中央支，高血压时易破，又称出血动脉，不要把它安进环上。

教材 definition：**脑脊液循环**——主要由脑室脉络丛产生。路径：**侧脑室脉络丛 → 室间孔 → 第三脑室 → 中脑导水管 → 第四脑室 → 第四脑室正中孔和两个外侧孔 → 蛛网膜下隙 → 蛛网膜粒 → 硬脑膜窦（主要是上矢状窦）**。成人总量平均约 **150 ml**。教材 pitfall：**缺室间孔、导水管或正中孔/外侧孔任何一站，上游都会积水。** 腰穿抽的是终池里已经出了第四脑室的脑脊液，不是侧脑室里的。

| 户 | 本版要点 |
|----|----------|
| Willis 环 | 前交通 + 两侧大脑前起始段 + 两侧颈内末段 + 两侧后交通 + 两侧大脑后 |
| 不在环上 | **大脑中动脉**（颈内的延续）；豆纹动脉是出血动脉 |
| 脑脊液 | 约 150 ml；侧脑室 → 室间孔 → 三室 → 导水管 → 四室 → 正中孔和外侧孔 → 蛛网膜下隙 → 蛛网膜粒 → 上矢状窦 |

易错点：把大脑中动脉写进 Willis 环；脑脊液跳过室间孔或导水管；把腰穿听成抽侧脑室。
