**题目**：体循环（大循环）从哪一腔出发、经哪条动脉干、在哪里交换、经什么回来、进哪一腔？肺循环（小循环）这一串怎么写，能不能写成「先体循环再肺循环」或「肺循环也滋养全身」？动脉、静脉按颜色还是按方向定义，肺动脉干和肺静脉里各走什么血？肝门静脉是不是第三条循环？

**解**：
教材 definition：**体循环**——左心室 → 主动脉及分支 → 全身毛细血管 → 各级静脉 → 上、下腔静脉及冠状窦 → 右心房。大循环，路程长，以动脉血滋养全身，并把代谢产物和二氧化碳运回心。教材 definition：**肺循环**——右心室 → 肺动脉干及分支 → 肺泡毛细血管 → 肺静脉 → 左心房。小循环，只通过肺，把静脉血变成氧饱和的动脉血。教材 pitfall：**两条同时转，不要写成先体循环再肺循环。** 写成「肺循环也滋养全身」，泵和交换场所都错了。

教材 definition：**动脉**——运送血液**离心**的管道。左心室发出的主动脉走动脉血，右心室发出的肺动脉干走的是静脉血。教材 definition：**静脉**——运送血液**回心**的血管。肺静脉送的是含氧血，上、下腔静脉和冠状窦送的是静脉血。教材 pitfall：**不要按颜色给动脉、静脉下定义。** 写成「动脉=红、静脉=蓝」，肺循环这一户当场对不上。

教材 insight：**图7-1 先认两圈，再认肝门静脉这一笔**——红圈是体循环，蓝圈过肺是肺循环。腹腔不成对脏器先汇入肝门静脉、过肝血窦，再经肝静脉进下腔静脉——那是静脉户里的门静脉系，不是第三条循环。

| | 体循环（大循环） | 肺循环（小循环） |
|--|------------------|------------------|
| 起点 | 左心室 | 右心室 |
| 动脉干 | 主动脉 | 肺动脉干 |
| 交换部位 | 全身毛细血管 | 肺泡毛细血管 |
| 回心 | 上、下腔静脉及冠状窦 → 右心房 | 肺静脉 → 左心房 |
| 路程 | 长，范围广 | 短，只通过肺 |

易错点：体、肺循环起点写反；按颜色定义动脉静脉；两条听成先后转；把门静脉另立成第三条循环。
