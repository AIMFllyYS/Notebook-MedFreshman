**题目**：眼的屈光装置本版几件，角膜算不算进去，视网膜算不算？共同特征是有血管还是无血管、浑浊还是透明？房水从哪产、经哪条路回巩膜静脉窦，青光眼本版原句落在分泌过多还是回流受阻？视近时睫状肌收缩还是舒张，睫状小带是松还是紧，晶状体怎么变？近视物像落在视网膜前还是后？

**解**：
教材 definition：**屈光装置**——角膜 + 房水 + 晶状体 + 玻璃体。共同特征：**透明、无血管**。缺一则光线到不了视网膜或到了却散焦。视网膜是感光层，不进屈光装置名单。角膜属纤维膜前 1/6，无色透明、无血管、感觉敏锐，营养走周围毛细血管、泪液和房水，不是「角膜自己有血管」。

教材 definition：**房水**——睫状体产生 → 后房 → 瞳孔 → 前房 → 虹膜角膜角 → 巩膜静脉窦 → 睫前静脉 → 眼上、下静脉。营养角膜和晶状体，维持眼压。教材 pitfall：**青光眼是房水回流受阻，不是「房水分泌太多」这一户的原句。** 先问前房角和静脉窦通不通，再问分泌。

教材 compare：**视近与视远（睫状肌—小带—晶状体）**——视近：睫状肌收缩，睫状突内伸，小带松弛，晶状体借自身弹性变凸（前部更明显），屈光加强。视远相反。教材 insight：**看近时小带是松的，不是绷紧才变凸。** 教材 compare：**近视、远视、老视**——近视：眼轴较长或屈光率过强，物像在视网膜**前**；远视：眼轴较短或屈光率过弱，物像在视网膜**后**；老视是核硬、弹性减退、睫状肌萎缩，不是另一种眼轴异常。晶状体混浊称白内障。玻璃体约占内腔后 4/5，支撑减弱可致视网膜脱离。

| 件 | 本版要点 |
|----|----------|
| 角膜 | 纤维膜前 1/6，透明无血管 |
| 房水 | 睫状体产，经前房角入巩膜静脉窦 |
| 晶状体 | 双凸透镜；视近小带松、弹性回凸 |
| 玻璃体 | 后 4/5，支撑视网膜 |

易错点：把视网膜写进屈光装置；给角膜加血管；青光眼写成分泌过多；视近小带拉紧；近视远视前后对调。
