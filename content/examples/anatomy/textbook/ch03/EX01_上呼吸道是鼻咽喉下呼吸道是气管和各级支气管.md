**题目**：呼吸系统由哪两户组成？呼吸道本版名单从哪一段到哪一段，肺泡算不算呼吸道？临床上上呼吸道、下呼吸道按本版怎么分，分界在鼻后孔、气管杈，还是环状软骨下缘？写成「上呼吸道＝鼻」或「下呼吸道从咽开始」错在哪？鼻分哪三部，易出血区在鼻中隔前下部还是下鼻甲？喉软骨本版立户哪四块，唯一完整的软骨环是甲状软骨还是环状软骨？喉腔最窄的是前庭裂、声门裂还是声门下腔？

**解**：
教材 definition：**呼吸系统**——由呼吸道和肺组成。管负责通气，肺负责换气。两件都要。教材 definition：**呼吸道**——鼻、咽、喉、气管和支气管这一条通气管道。本版名单不要改成「从鼻到肺泡」——肺泡不在呼吸道户头里。教材 definition：**上呼吸道与下呼吸道**——上呼吸道：鼻、咽、喉。下呼吸道：气管和各级支气管。分界在喉与气管之间（环状软骨下缘），不是鼻后孔，也不是气管杈。

教材 pitfall：**上呼吸道止于喉，不是止于鼻。** 写成「上呼吸道＝鼻」会把咽和喉丢掉；写成「下呼吸道从咽开始」会把喉从下呼吸道误算进去。教材 definition：**鼻**——呼吸道起始部，兼嗅觉器官。本版三部是外鼻、鼻腔、鼻旁窦。教材 definition：**易出血区**——鼻中隔前下部，约 90% 鼻出血，Little / Kiesselbach 区。教材 pitfall：**约 90% 的鼻出血在鼻中隔前下部，不要写成下鼻甲。**

教材 definition：**喉软骨（本版立户）**——甲状软骨、环状软骨、会厌软骨、成对的杓状软骨。环状软骨是其中唯一完整的软骨环，弓平 C6，损伤会造成喉狭窄。教材 pitfall：**环状软骨是唯一完整的软骨环，甲状软骨不是环。** 甲状软骨是两块四边形板在前方愈合，后方敞开。教材 definition：**声门裂**——两侧声襞与杓状软骨底、声带突之间的裂隙，较前庭裂长而窄，是喉腔最狭窄处。教材 pitfall：**喉腔最窄的是声门裂，不是前庭裂，也不是声门下腔。** 声门下腔的危险在黏膜下疏松、婴幼儿易水肿，不在「更窄」。

| 本版原句 | 不要写成 |
|----------|----------|
| 呼吸系统＝呼吸道＋肺 | 呼吸系统就是肺 |
| 上呼吸道＝鼻、咽、喉 | 止于鼻；下呼吸道从咽开始 |
| 分界在环状软骨下缘 | 鼻后孔；气管杈 |
| 易出血区在鼻中隔前下部 | 下鼻甲 |
| 环状软骨是唯一完整软骨环 | 甲状软骨围成一圈 |
| 喉腔最窄＝声门裂 | 前庭裂；声门下腔 |

易错点：上呼吸道止于鼻；肺泡写进呼吸道；分界改成鼻后孔或气管杈；鼻出血写成下鼻甲；把甲状软骨当成完整环；把前庭裂或声门下腔当成最窄。
