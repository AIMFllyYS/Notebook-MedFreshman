**题目**：气管起止平哪些椎体，气管杈约平哪一平面？气管隆嵴偏向哪一侧，支气管镜靠它认什么？左、右主支气管本版长度、外径、嵴下角各是多少，谁短粗陡、谁细长斜？嵴下角是气管中线与主支气管下缘的夹角，能不能改写成「左右夹角约 70°」？经气管坠入的异物多进入哪一侧，和隆嵴偏左是不是同一幅图？气管切开常在第几环，能不能写成第 2～4 环？肺叶支气管、肺段支气管是不是本节的户头？

**解**：
教材 definition：**气管**——喉与气管杈之间的管道。本版长度：男性平均 10.31 cm，女性平均 9.71 cm。起自环状软骨下缘（约平 C6），向下至胸骨角平面（约平 T4 椎体下缘）分成左、右主支气管。教材 definition：**气管杈**——气管下端的分叉，平面约平胸骨角、第 4 胸椎椎体下缘。不要把气管杈听成肺门。教材 definition：**气管隆嵴**——气管杈内面矢状位向上凸的半月状嵴，**略偏向左侧**。支气管镜检查时判断气管分叉的标志。

教材 definition：**嵴下角**——气管中线与主支气管下缘间的夹角。本版右嵴下角：男性平均 **21.96°**，女性平均 **24.7°**。左嵴下角：男性平均 36.4°，女性平均 39.3°。教材 pitfall：**嵴下角按本版右 21.96° / 24.7°，不要改写成 70°。** 有的教材把左、右主支气管之间的夹角写成约 70°。本版立户的是嵴下角，右侧更小、左侧更大，数字不要互换。教材 compare：**左、右主支气管（本版数字）**——右：男长 2.1 cm、外径 1.5 cm，女长 1.9 cm、外径 1.4 cm，软骨环通常 3～4 个，短、粗、陡直；左：男长 4.8 cm、外径 1.4 cm，女长 4.5 cm、外径 1.3 cm，软骨环通常 7～8 个，细、长、斜行。因此经气管坠入的异物多进入右主支气管。

教材 insight：**气管隆嵴略偏左，和右主支气管较陡是同一幅图。** 隆嵴偏向左侧，等于把分叉的「脊」推向左，右侧开口更接近气管长轴。教材 pitfall：**气管切开常在第 3～5 环，不要写成第 2～4 环。** 第 2～4 环前方是甲状腺峡的常见位置；切开选 3～5 环，是为了避开峡部又不要太靠下进入胸骨后。教材 definition：**支气管**——本节只把一级分支——左、右主支气管——写完。二级肺叶支气管、三级肺段支气管是第二节的户头。

| | 右主支气管 | 左主支气管 |
|--|------------|------------|
| 长度（男 / 女） | 2.1 cm / 1.9 cm | 4.8 cm / 4.5 cm |
| 外径（男 / 女） | 1.5 cm / 1.4 cm | 1.4 cm / 1.3 cm |
| 嵴下角（男 / 女） | 21.96° / 24.7° | 36.4° / 39.3° |
| 走行 | 短、粗、陡直 | 细、长、斜行 |
| 异物 | **多进入右侧** | 较少 |

易错点：把嵴下角改成左右夹角 70°；左右数字对调；隆嵴写成偏右；切开写成第 2～4 环；把肺叶、肺段支气管提前写进第一节。
