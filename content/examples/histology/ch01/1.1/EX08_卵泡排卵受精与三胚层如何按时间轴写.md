**题目**：从卵泡升级写到受精、植入和三胚层分化，哪些时间点和结构是指南明确给出的？

**解**：
卵泡先问有没有腔：无腔且卵泡细胞单层扁平 = 原始卵泡（初级卵母细胞休止于第一次成熟分裂前期）；出现透明带和多层卵泡细胞但仍无腔 = 初级卵泡；出现卵泡腔 = 次级卵泡（腔内仍是初级卵母细胞；膜细胞合成雄激素，经颗粒细胞转化为雌激素）；成熟卵泡在排卵前 $1\sim 1.5\,\mathrm{d}$ 才形成次级卵母细胞和第一极体。

排卵约在月经周期第 $14$ 天：次级卵母细胞 + 透明带 + 放射冠排入腹膜腔。$24\,\mathrm{h}$ 内受精则完成第二次成熟分裂，形成 $23,\mathrm{X}$ 的卵细胞和第二极体。未受精黄体维持 $12\sim 14\,\mathrm{d}$ 成月经黄体再变白体；受精则妊娠黄体维持 $4\sim 6$ 个月。颗粒黄体细胞分泌孕激素，膜黄体细胞分泌雌激素。

精子须在女性生殖管道**获能**。受精一般在输卵管壶腹部：顶体反应溶蚀放射冠和透明带 → 精卵融合 → **透明带反应**保证单精受精 → 雌雄原核染色体混合成二倍体。卵裂至 $12\sim 16$ 细胞为桑椹胚，再成胚泡（滋养层 + 内细胞群）。植入通常在子宫体和底部后壁，内膜处于分泌期，植入后称蜕膜。

| 时期 | 指南时间 |
|------|----------|
| 胚前期 | 受精至第 $2$ 周末（二胚层胚盘） |
| 胚期 | 第 $3$ 周至第 $8$ 周末（初具人形） |
| 胎期 | 第 $9$ 周至出生 |
| 足月受精龄 / 月经龄 | $38$ 周 / $40$ 周（指南习题） |

外胚层→神经管（中枢等）及表皮；间介中胚层→泌尿生殖主要器官；内胚层→消化管和喉以下呼吸道等上皮。胎盘 = 丛密绒毛膜 + 基蜕膜；绒毛干 $40\sim 60$ 根。生精侧：初级精母 $46,\mathrm{XY}$，精液每毫升低于 $400$ 万精子可致不育——与卵子减数分裂时间轴不要并户。

易错点：把「次级卵泡」听成「已经是次级卵母细胞」；排卵写成裸卵；获能放进睾丸；胚期从受精算起把胚前期吃掉。
