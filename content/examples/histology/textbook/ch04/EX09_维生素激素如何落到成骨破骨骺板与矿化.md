**题目**：维生素 D、A、C 各调骨的哪一环节、缺乏分别导致什么？生长激素和甲状腺激素作用于骺板的什么过程、过少过多各写成哪些病、为何儿童期过多是巨人症而成年期过多是肢端肥大症？甲状旁腺激素和降钙素怎样对拉血钙？雌激素不足如何走向骨质疏松？生理高应力和长期低应力各写成骨形成还是骨吸收？骨质疏松是组成变了还是骨量少？为什么不能把佝偻病写成“没做成骨细胞”，也不能把成年后再多的生长激素听成还能让长骨长长？

**解**：
教材 concept：**先问调的是成骨、破骨，还是骺板软骨。** 维生素 D 主要把钙磷送进类骨质；维生素 A 协调成骨与破骨的节奏；维生素 C 管胶原和骨祖细胞分裂。生长激素和甲状腺激素推骺板；甲状旁腺素和降钙素对拉血钙；雌激素不足则成骨弱、破骨相对强。应力在生理高位写成骨、低位写吸收。

教材 definition：**维生素 D 促进小肠对钙、磷的吸收，提高血钙和血磷水平，有利于类骨质的矿化。** 儿童期缺乏维生素 D 或饮食缺钙可导致佝偻病；成人缺乏则引起骨软化症。教材 definition：**维生素 A 协调成骨细胞和破骨细胞的活动，影响骨的生长速度和塑形，在重建中发挥重要作用。** 严重缺乏时，骨的重吸收和重建跟不上骨的形成，引起畸形发育；也可影响骺板软骨细胞发育，导致长骨生长迟缓。教材 definition：**维生素 C 影响骨祖细胞的分裂增殖，并影响成骨细胞合成胶原纤维与基质。** 严重缺乏可导致骨干密质骨变薄变脆，骨折后愈合缓慢。教材 pitfall：**佝偻病是矿化不够，不是没做成骨细胞。** 成骨细胞仍可分泌类骨质，只是羟基磷灰石沉不上去。不要和维生素 C 缺乏（胶原与基质合成障碍）或维生素 A 缺乏（重建跟不上形成）混成“缺维生素骨头就软”。

教材 definition：**生长激素和甲状腺激素促进骺板软骨细胞的生长，并促进软骨替换为骨。** 生长发育期分泌过少，分别导致侏儒症和呆小病；儿童期生长激素过多导致巨人症，成年期导致肢端肥大症。教材 pitfall：**成年后再多的生长激素也不能让长骨长长。** 骺线形成后纵向生长停止。儿童期生长激素过多走巨人症，成年期过多走肢端肥大症，差别就是骺板还在不在。

教材 definition：**甲状旁腺激素激活骨细胞和破骨细胞的溶骨作用，释放骨钙入血，使血钙升高。降钙素抑制骨盐溶解，并刺激骨祖细胞分化为成骨细胞，促进成骨而使血钙入骨。** 雌激素和雄激素都能促进成骨细胞的活动。雌激素不足可致成骨细胞活跃度降低、破骨细胞活动相对增强，骨钙流失，形成骨质疏松。糖皮质激素可抑制小肠对钙的吸收和肾小管对钙的重吸收。

教材 definition：**骨处于生理范围内的高应力作用下以骨形成为主；低应力条件下以骨吸收为主。** 长期低应力可造成骨质疏松，如长期卧床造成骨钙流失。教材 definition：**骨质疏松症是骨矿物质丢失到一定程度后，骨微细结构不能维持正常形态。** 骨小梁变窄、变细、弯曲、错位甚至断裂，有的被全部吸收形成空洞；强度降低、脆性增加，可发生自发性压缩性或横断性骨折。教材 pitfall：**骨质疏松是骨量少，不是骨质换成了另一种成分。** 骨组织组成并没有改变，但骨量明显减少。不要把它写成“钙没了只剩胶原”，或写成编织骨取代板层骨。成人 $3\%\sim 5\%$ 骨组织持续重建；正常每年约丢失骨矿物质总量的 $0.5\%$，老年女性因雌激素缺乏丢失更多。

| 因素 | 主要环节 | 缺乏或异常 |
|------|----------|------------|
| 维生素 D | 小肠吸钙磷 → 血钙血磷 ↑ → 类骨质矿化 | 儿童佝偻病；成人骨软化症 |
| 维生素 A | 协调成骨与破骨，影响生长速度、塑形和重建 | 重建跟不上形成 → 畸形；骺板受累 → 长骨生长迟缓 |
| 维生素 C | 骨祖细胞分裂；成骨细胞合成胶原与基质 | 密质骨变薄变脆，骨折愈合缓慢 |
| 生长激素 / 甲状腺激素 | 促进骺板软骨细胞生长及软骨替换为骨 | 过少：侏儒症 / 呆小病；GH 过多：儿童巨人症、成年肢端肥大症 |
| 甲状旁腺激素 | 激活骨细胞和破骨细胞溶骨，骨钙入血 | 溶骨增强，血钙升高 |
| 降钙素 | 抑制骨盐溶解；刺激骨祖细胞分化为成骨细胞 | 成骨增强方向，血钙入骨 |
| 雌激素 | 促进成骨细胞活动 | 不足：成骨弱、破骨相对强 → 骨质疏松 |
| 应力 | 生理高应力 → 骨形成；低应力 → 骨吸收 | 长期卧床等低应力 → 骨钙流失、骨质疏松 |

易错点：把佝偻病/骨软化症听成胶原没做出来；把维生素 A、C、D 的环节写串；把巨人症和肢端肥大症写成同一机制的不同程度；把甲状旁腺素和降钙素的升降血钙写反；把骨质疏松写成组成改变或编织骨取代板层骨。
