**题目**：弓动脉起自什么囊，第 $4\sim 6$ 周相继发生几对，分别走行于各对什么弓内、与同侧什么主动脉相连，六对是否同时存在？第 $1$、$2$ 对弓动脉基本怎样，但与其相连的一段什么动脉保留？第 $3$ 对左、右各发出 $1$ 个分支形成左、右什么动脉，以该动脉起始点为界近侧段及部分主动脉囊发育成什么动脉，远侧段及与其相连的背主动脉共同形成什么动脉？左侧第 $4$ 弓动脉与主动脉囊左半共同形成什么，主动脉囊右半形成什么干，左侧背主动脉背侧发出的第 $7$ 节间动脉形成什么，右侧第 $4$ 弓动脉及与其相连的尾侧背主动脉和右侧第 $7$ 节间动脉共同组成什么，第 $3$、$4$ 对之间的背主动脉怎样？第 $5$ 对弓动脉发育怎样？第 $6$ 对近侧段形成什么的基部，左侧远侧段形成什么导管，右侧远侧段怎样，随着动脉干的分隔肺动脉才与什么干通连？卵黄静脉被肝切成哪三段、门静脉来自哪一段，右脐静脉全部怎样、左脐静脉只留哪一段并靠静脉导管通入下腔静脉？为什么不能把六对画在同一张“同时存在”的图上，也不能把左锁骨下写成左侧第 $4$ 弓变的、把动脉导管写成左右第 $6$ 弓都有？

**解**：
教材 definition：**弓动脉起自主动脉囊，走行于各对鳃弓内，与同侧的背主动脉相连。第 $4\sim 6$ 周相继发生 $6$ 对，并不同时存在。演变主要发生在第 $6\sim 8$ 周。** 教材 pitfall：**六对弓动脉并不同时存在。** 常是后 $1$ 对出现时，前 $1$ 对已退化或发生演变。教材 definition：**第 $1$、$2$ 对弓动脉基本退化消失，但与其相连的一段背主动脉保留。** 不要写成“第 $1$、$2$ 对连背主动脉一起扔掉”。

教材 definition：**第 $3$ 对弓动脉本身分成三段账：发出的分支 → 左、右颈外动脉；以颈外动脉的起始点为界，近侧段及部分主动脉囊 → 颈总动脉；远侧段及与其相连的背主动脉 → 颈内动脉。** 教材 pitfall：**颈外动脉是第 $3$ 对发出的分支，不是第 $3$ 对远侧段改名。** 把第 $3$ 对整条写成颈总动脉，或把颈内动脉写成“第 $3$ 对单独变的”，头颈三条动脉会对错节段。

教材 definition：**左侧第 $4$ 弓动脉与主动脉囊左半共同形成主动脉弓。左锁骨下动脉不来自左侧第 $4$ 弓，而来自左侧背主动脉背侧发出的第 $7$ 节间动脉。** 教材 definition：**主动脉囊右半形成头臂干。右锁骨下动脉由三截拼成：右侧第 $4$ 弓动脉 + 与其相连的尾侧背主动脉 + 右侧第 $7$ 节间动脉。** 第 $3$、$4$ 对弓动脉之间的背主动脉萎缩消失。教材 definition：**第 $5$ 对弓动脉发育不全并很快退化。** 六对里它几乎不留成体血管。

教材 definition：**第 $6$ 对近侧段形成肺动脉的基部；左侧远侧段形成动脉导管；右侧远侧段退化。动脉干分隔之后，肺动脉才与肺动脉干通连。** 教材 definition：**动脉导管来自左侧第 $6$ 弓动脉的远侧段，连接肺动脉干与降主动脉。右侧第 $6$ 弓没有对等的远侧段保留。** 出生后它闭锁为动脉韧带。教材 concept：**先问这是第几对弓动脉，再问左侧保留什么、右侧退化什么。** 教材 insight：**左右不对称，是第 $4$、$6$ 对在左右走了不同的远侧命运。** 把左锁骨下写成“左侧第 $4$ 弓变的”，或把动脉导管写成“左右第 $6$ 弓都有”，后面的导管未闭和锁骨下起源都会对错户头。

肝形成后卵黄静脉分三段：与肝相邻的一段并入肝内形成肝血窦；出肝后的近心段左侧支消失、右侧支形成肝静脉和下腔静脉的近心段；入肝前的远心段形成一条 S 形血管，发育形成门静脉。教材 pitfall：**门静脉来自卵黄静脉远心段，肝静脉和下腔近心段来自右侧近心段。** 脐静脉：右脐静脉全部退化；左脐静脉在肝与静脉窦之间的一段也退化，只留脐至肝段到出生；肝内小血管合成静脉导管，一端接左脐静脉，一端通下腔静脉，再入静脉窦右角。教材 pitfall：**静脉导管不是门静脉，门静脉也不是脐静脉改名。**

| 对 | 保留 | 退化 |
|----|------|------|
| 第 $1$、$2$ 对 | 与其相连的一段背主动脉 | 弓动脉本身基本退化消失 |
| 第 $3$ 对 | 分支 → 左、右颈外动脉；近侧段 + 部分主动脉囊 → 颈总动脉；远侧段 + 相连背主动脉 → 颈内动脉 | — |
| 第 $4$ 对 | 左侧 + 主动脉囊左半 → 主动脉弓；主动脉囊右半 → 头臂干；左第 $7$ 节间动脉 → 左锁骨下动脉；右侧第 $4$ 弓 + 尾侧背主动脉 + 右第 $7$ 节间动脉 → 右锁骨下动脉 | 第 $3$、$4$ 对之间的背主动脉萎缩消失 |
| 第 $5$ 对 | — | 发育不全并很快退化 |
| 第 $6$ 对 | 近侧段 → 肺动脉的基部；左侧远侧段 → 动脉导管 | 右侧远侧段退化 |

| 项目 | 左锁骨下动脉 | 右锁骨下动脉 |
|------|--------------|--------------|
| 第 $4$ 弓动脉 | 不参加（左侧第 $4$ 弓走主动脉弓） | 参加（右侧第 $4$ 弓是近侧段） |
| 尾侧背主动脉 | 不作为其组成 | 与右侧第 $4$ 弓相连的那一段参加 |
| 第 $7$ 节间动脉 | 左侧第 $7$ 节间动脉形成左锁骨下动脉 | 右侧第 $7$ 节间动脉参加组成 |

易错点：把六对弓动脉画成同时存在；把第 $1$、$2$ 对连背主动脉一起扔掉；把第 $3$ 对整条写成颈总动脉；把左锁骨下写成左侧第 $4$ 弓变的；把动脉导管写成左右第 $6$ 弓都有；把第 $5$ 对硬找成体遗迹；把门静脉写成脐静脉改名、把静脉导管写成门静脉的一段。
