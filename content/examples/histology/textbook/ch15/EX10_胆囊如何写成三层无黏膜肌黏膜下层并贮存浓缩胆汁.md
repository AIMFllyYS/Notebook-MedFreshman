**题目**：胆囊分哪 3 部分、壁由哪 3 层组成、有没有黏膜肌层和黏膜下层？黏膜皱襞在排空和充盈时如何改变、上皮是什么、怎样浓缩胆汁？肌层厚薄如何分布、外膜大部分是什么、容量大约多少？进食尤其进高脂肪食物后，缩胆囊素-促胰酶素使胆囊收缩多久、胆总管括约肌如何？肝外胆管几层、胆总管上皮有没有杯状细胞、肌层上中下 $1/3$ 如何成层？壶腹括约肌同时控制什么？为什么不能把第 14 章的管壁四层硬套到胆囊，也不能把皱襞写成小肠绒毛，更不能把壶腹括约肌写成只关胆囊？

**解**：
教材 definition：**胆囊分底、体、颈 3 部分，颈部连胆囊管。功能是贮存和浓缩胆汁。** 教材 definition：**胆囊壁由黏膜、肌层和外膜 3 层组成。** 没有黏膜肌层和黏膜下层这本消化管四层账，不要把第 14 章的管壁通例硬套过来。教材 definition：**黏膜有许多高而分支的皱襞突入腔内。** 胆囊收缩排空时，皱襞高大而分支；胆囊充盈扩张时，皱襞减少变矮。上皮为单层柱状上皮，固有层为薄层结缔组织。教材 concept：**先问皱襞是排空时高，还是充盈时高。** 胆囊皱襞不是小肠那种永远高耸的吸收面积装置。上皮仍是单层柱状，职分是主动吸收胆汁中的水和无机盐，把胆汁浓缩。教材 pitfall：**胆囊黏膜皱襞随充盈改变，不要写成小肠绒毛那种永久高耸的吸收装置。** 绒毛是黏膜上皮加固有层的指状突起，有中央乳糜管，为了吸收食糜。胆囊皱襞是黏膜折向管腔，排空时才高大分支，用来在容积变化时铺开单层柱状上皮去吸水和盐。没有黏膜肌，也不形成绒毛。

教材 definition：**肌层的平滑肌厚薄不一：底部较厚，颈部次之，体部最薄。** 外膜较厚，大部分为浆膜。教材 definition：**胆囊容量为 $40\sim 70\,\mathrm{ml}$。** 肝排出的胆汁流入舒张的胆囊内贮存。上皮细胞主动吸收胆汁中的水和无机盐，使胆汁浓缩。教材 definition：**进食后，尤其进高脂肪食物后，小肠分泌的缩胆囊素-促胰酶素使胆囊持续收缩 $30\sim 60$ 分钟，胆总管括约肌松弛，将胆汁排入肠腔。** 同一激素在上一节还调节胰腺泡细胞分泌酶原。教材 insight：**缩胆囊素一身兼两职：胰酶出腺泡，胆汁出胆囊。** 小肠 I 细胞的缩胆囊素-促胰酶素，对胰腺写的是促酶原分泌，对胆囊写的是持续收缩加括约肌松弛。高脂肪食物把这两本消化液同时叫进十二指肠。把胆囊收缩听成“自己想缩就缩”，会漏掉小肠内分泌这一站。

教材 definition：**肝分泌的胆汁经左右肝管、肝总管、胆囊管进入胆囊贮存；浓缩胆汁经胆囊管、胆总管排入十二指肠。** 肝外胆管管壁亦分黏膜、肌层和外膜 3 层。胆总管黏膜上皮为单层柱状，有杯状细胞，固有层内有黏液腺。肝管和胆总管的上 $1/3$ 段肌层很薄，平滑肌分散；胆总管的中 $1/3$ 段肌层渐厚，尤其是纵行平滑肌增多；胆总管下 $1/3$ 段的肌层分内环行、外纵行两层。教材 definition：**胆总管与胰管汇合后穿入十二指肠壁，局部扩大形成壶腹。** 此处环行平滑肌增厚形成壶腹括约肌，其舒缩控制胆汁和胰液的排出。教材 pitfall：**壶腹括约肌同时管胆汁和胰液，不要写成只关胆囊。** 胆总管与胰管先汇合，再穿十二指肠壁扩大成壶腹。括约肌一缩，两管的出口一起关上；一舒，胆汁和胰液一起进肠腔。缩胆囊素让胆囊收缩的同时让这圈括约肌松弛。把括约肌只写成“胆囊颈部的开关”，胰液排出账会找不到门。

| 项目 | 胆囊 | 消化管（除口腔与咽） |
|------|------|----------------------|
| 层次 | 黏膜、肌层、外膜 3 层 | 黏膜、黏膜下层、肌层、外膜 4 层 |
| 黏膜 | 单层柱状；固有层薄；无黏膜肌 | 上皮 + 固有层 + 黏膜肌层 |
| 皱襞 | 随排空 / 充盈高低变化 | 黏膜 + 黏膜下层共同突起 |
| 功能侧重 | 贮存、浓缩并按时排出胆汁 | 消化、吸收、屏障 |

| 段 | 肌层 |
|----|------|
| 肝管和胆总管上 $1/3$ | 很薄，平滑肌分散 |
| 胆总管中 $1/3$ | 渐厚，纵行平滑肌增多 |
| 胆总管下 $1/3$ | 内环行、外纵行两层 |
| 壶腹 | 环行平滑肌增厚为壶腹括约肌，同时管胆汁和胰液 |

易错点：把胆囊硬套消化管四层；给胆囊加上黏膜肌和黏膜下层；把皱襞写成小肠绒毛；把浓缩写成“把胆汁蒸发掉”而不是上皮主动吸水和盐；把 CCK 只写成胆囊自己想缩；把壶腹括约肌写成只关胆囊；把胆总管上皮写成没有杯状细胞。
