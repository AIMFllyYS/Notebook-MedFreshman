:::example{label="分子筛与组织液如何动态更新而不是把基质当成切片空白"}
**题目**：基质是什么、主要生物大分子有哪些、孔隙里充满什么？蛋白聚糖如何从糖胺聚糖、核心蛋白、透明质酸搭成聚合体？分子筛让哪些物质通过、把什么挡住？透明质酸酶拆的是什么、溶血性链球菌和癌细胞借此做什么？纤维粘连蛋白连接哪三种成分？组织液从动脉端到静脉端再到淋巴怎样更新、失衡导致什么？为什么不能把基质听成空白，也不能把透明质酸酶理解成直接杀细胞？

**解**：
教材 definition：**基质（ground substance）是由生物大分子构成的无定形胶状物，无色透明，具有一定黏性，孔隙中充满组织液，填充于结缔组织细胞和纤维之间。** 主要生物大分子为蛋白聚糖和纤维粘连蛋白。纤维提供可看见的丝状支架，基质提供可滤过的胶，组织液在孔隙中不断循环更新。

教材 definition：**蛋白聚糖（proteoglycan）亦称蛋白多糖，是基质的主要成分，由糖胺聚糖（占 $80\%\sim 90\%$）与蛋白质以共价键结合而成的聚合体。** 糖胺聚糖分硫酸化和非硫酸化两类：硫酸化者有硫酸软骨素、硫酸角质素、硫酸皮肤素和硫酸乙酰肝素等，分子较小；非硫酸化者主要为透明质酸，曲折盘绕，可长达 $2.5\,\mu\mathrm{m}$，构成蛋白聚糖聚合体的主干。小分子糖胺聚糖与核心蛋白共价结合并辐射状排列，形成蛋白聚糖亚单位；亚单位再经结合蛋白挂到透明质酸主干上，形成蛋白聚糖聚合体。

教材 concept：**分子筛先问：孔隙让谁过、把谁挡住。** 大量蛋白聚糖聚合体形成有许多微孔的分子筛：水、营养物、代谢产物、激素、气体分子可以通过；大于孔隙的大分子物质、细菌等则被阻挡，使基质成为限制细菌等有害物扩散的防御屏障。教材 pitfall：**透明质酸酶拆的是分子筛的梁，不是把细胞“消化掉”。** 溶血性链球菌和癌细胞能产生透明质酸酶，水解透明质酸主干，蛋白聚糖聚合体散架，病原或肿瘤细胞才得以扩散、转移。不要把透明质酸酶理解成直接杀细胞的酶。

教材 definition：**纤维粘连蛋白（fibronectin）是结缔组织基质中最主要的粘连性糖蛋白。** 分子表面具有与多种细胞、胶原蛋白及蛋白聚糖的结合位点，把这三种成分有机连接成整合的胶原纤维网络，从而影响细胞的黏附、迁移或肿瘤转移、胚胎发育、生长和分化等。

教材 definition：**组织液（tissue fluid）是溶解有电解质、单糖、气体分子等小分子的水溶液：在毛细血管动脉端渗入基质，在静脉端大部分回血，小部分进入毛细淋巴管成为淋巴液后再回流入血。** 它动态更新，是血液与组织细胞物质交换的介质，也是细胞赖以生存的体液环境。电解质和蛋白质代谢障碍时，产生与回流失去平衡，基质中组织液增多导致水肿，减少导致脱水。

| 账本 | 要点 |
|------|------|
| 基质通式 | 无定形胶状物；孔隙充满组织液；主要成分为蛋白聚糖和纤维粘连蛋白 |
| 分子筛结构 | 透明质酸主干 + 结合蛋白 + 核心蛋白 + 小分子 GAG（刷状侧链）→ 蛋白聚糖聚合体 → 微孔 |
| 通过 | 水、营养物、代谢产物、激素、气体分子 |
| 阻挡 | 大于孔隙的大分子、细菌 |
| 透明质酸酶 | 拆掉透明质酸主干 → 筛孔崩解 → 溶血性链球菌扩散、癌细胞转移 |
| 纤维粘连蛋白 | 连接细胞、胶原蛋白和蛋白聚糖 |
| 组织液 | 动脉端渗入 → 静脉端大部分回血，小部分入毛细淋巴管；失衡 → 水肿或脱水 |

易错点：把基质听成切片空白或“没有结构的水”；把透明质酸写成小分子侧链、把硫酸软骨素写成主干；把透明质酸酶理解成杀细胞；漏写纤维粘连蛋白的三种结合位点；把组织液写成只进不出，或漏写小部分入毛细淋巴管。
