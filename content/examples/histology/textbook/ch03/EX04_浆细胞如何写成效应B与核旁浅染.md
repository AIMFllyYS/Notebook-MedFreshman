**题目**：浆细胞又称什么、从哪种淋巴细胞分化而来、主要分布在哪里、一般结缔组织内多不多？光镜下核、异染色质、胞质嗜色性和核旁浅染区各怎样？电镜下环行结构和核旁浅染区分别对应什么细胞器？抗体两端各结合什么、如何接到巨噬细胞的特异性吞噬？为什么不能把浆细胞写成结缔组织固有细胞，也不能把核旁浅染当成脂肪空泡？

**解**：
教材 definition：**浆细胞（plasma cell）又称效应 B 细胞，主要分布于脾、淋巴结以及消化管、呼吸道等黏膜的结缔组织或淋巴组织内及慢性炎症部位，一般结缔组织内很少。** 细胞呈卵圆形或圆形；核圆或卵圆，多偏于一侧，异染色质呈粗条块状、从核中心向核膜辐射状分布；胞质丰富、嗜碱性，核旁有一浅染区。电镜下胞质几乎充满环行平行排列的粗面内质网，核旁浅染区为发达的高尔基复合体。功能是合成并分泌免疫球蛋白（抗体）。浆细胞属持续型蛋白质分泌细胞，胞质内无明显分泌颗粒。

教材 pitfall：**浆细胞就是效应 B 细胞，不要另立一种“专门造抗体的结缔组织固有细胞”。** 它是 B 淋巴细胞受抗原刺激后分化而来的效应细胞，属于游走细胞，不是成纤维细胞那一类固有细胞。一般结缔组织内很少见到，大量出现提示局部慢性炎症或黏膜淋巴组织。核偏位、核旁浅染、胞质嗜碱性，对应的是环行粗面内质网加高尔基复合体，不是脂肪空泡。

| 项目 | 要点 |
|------|------|
| 身份 | 效应 B 细胞；游走细胞，不是固有细胞 |
| 来源 | B 淋巴细胞受抗原刺激后分化 |
| 分布 | 脾、淋巴结、消化管/呼吸道黏膜结缔组织或淋巴组织、慢性炎症部位；一般结缔组织内很少 |
| 光镜 | 卵圆或圆形；核偏位；异染色质辐射状粗块；胞质嗜碱性；核旁浅染区 |
| 电镜 | 环行平行粗面内质网几乎充满胞质；核旁浅染区 = 发达高尔基复合体 |
| 产物 | 免疫球蛋白（Ig），即抗体 |

教材 definition：**抗体（antibody）即免疫球蛋白（immunoglobulin，Ig），由浆细胞合成并分泌。** 一端与抗原高度特异性结合（一种抗体只能结合一种特定抗原），形成抗原–抗体复合物；另一端与吞噬细胞（如巨噬细胞）上的受体结合，使该复合物被吞噬和杀灭。这正是巨噬细胞特异性吞噬所依赖的识别因子来源之一。看见核旁浅染，先问是不是高尔基复合体在打包抗体，而不是把浅染区听成脂滴被溶掉的空泡。

易错点：把浆细胞算进固有细胞；把一般疏松结缔组织写成浆细胞很多；把辐射状异染色质听成核仁；把核旁浅染写成脂滴或水肿；漏写抗体另一端接巨噬细胞受体，从而接不上特异性吞噬。
