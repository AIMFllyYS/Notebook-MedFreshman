**题目**：生殖腺最初位于何处，体积增大后逐渐突入腹膜腔，由厚而短的系膜悬吊于腹腔腰部？随后系膜变得细长，逐步形成纤维索状连于生殖腺尾端与阴唇、阴囊隆起之间，称什么？随着胚体生长、腰部直立，该结构相对怎样从而牵拉生殖腺下降？第 $3$ 个月时卵巢停留在何处，睾丸继续下降停留在何处？第 $7\sim 8$ 个月时睾丸与包绕它的双层腹膜经什么管降入阴囊，双层腹膜构成什么、覆盖在睾丸的前面及侧面成为什么？出生前后鞘膜腔与腹膜腔之间的通路怎样？通路不闭合或闭合不全、腹内压增高时肠管可突入鞘膜腔称什么，睾丸未降入阴囊称什么？为什么不能把卵巢也写成“降进大阴唇”，也不能把鞘突听成引带，更不能把隐睾和先天性腹股沟疝写成同一种病？

**解**：
教材 definition：**引带（gubernaculum）是系膜变细后形成的纤维索，连于生殖腺尾端与阴唇、阴囊隆起之间。** 胚体生长、腰部直立时引带相对缩短，牵拉生殖腺下降。生殖腺最初位于腹后壁，体积增大后突入腹膜腔，由厚而短的系膜悬吊于腹腔腰部，随后系膜才细长成引带。教材 concept：**先问引带相对缩短有没有把性腺拉下来，再问卵巢是不是停在盆腔、睾丸是不是经腹股沟管入阴囊。**

教材 definition：**第 $3$ 个月时卵巢停留在盆腔。睾丸继续下降，先停留在腹股沟管内口；第 $7\sim 8$ 个月与包绕它的双层腹膜经腹股沟管降入阴囊。** 卵巢不再进入阴囊，不要写成“也降进大阴唇”。教材 definition：**双层腹膜构成鞘突，覆盖在睾丸的前面及侧面，成为鞘膜。** 出生前后，鞘膜腔与腹膜腔之间的通路逐渐闭合。通路不闭合或闭合不全，腹内压增高时肠管可突入鞘膜腔，即先天性腹股沟疝。睾丸未降入阴囊则称隐睾。

教材 pitfall：**隐睾是睾丸没降完，疝是鞘突通路没关，不要写成同一种病。** 隐睾问的是睾丸停在腹膜腔或腹股沟；疝问的是鞘膜腔还通腹膜腔、肠管会不会进来。可以同时存在，但机制不是同一句话。双侧腹膜腔内隐睾因温度高影响精子发生，可致男性不育；不要把单侧腹股沟隐睾直接写成“一定不育”。把鞘突听成引带，下降的牵引索和入阴囊的腹膜通路会对成一条。

| 项目 | 卵巢 | 睾丸 |
|------|------|------|
| 起点 | 腹后壁，突入腹膜腔 | 同左 |
| 牵引 | 引带相对缩短 | 同左 |
| 第 $3$ 个月 | 停留在盆腔 | 继续下降，停在腹股沟管内口 |
| 第 $7\sim 8$ 个月 | 不再进入阴囊 | 与双层腹膜经腹股沟管降入阴囊 |
| 腹膜 | 不形成鞘突这套入阴囊的通路 | 双层腹膜成鞘突 → 鞘膜；出生前后通路闭合 |

| 时间 | 事件 |
|------|------|
| 最初 | 位于腹后壁，体积增大后突入腹膜腔，厚而短的系膜悬于腰部 |
| 随后 | 系膜细长成引带，连于生殖腺尾端与阴唇、阴囊隆起之间 |
| 第 $3$ 个月 | 卵巢停留盆腔；睾丸停在腹股沟管内口 |
| 第 $7\sim 8$ 个月 | 睾丸与双层腹膜经腹股沟管降入阴囊，腹膜成鞘突、鞘膜 |
| 出生前后 | 鞘膜腔与腹膜腔之间的通路逐渐闭合 |

易错点：把卵巢写成降进大阴唇或阴囊；把鞘突听成引带；把隐睾和先天性腹股沟疝写成同一种病；把单侧腹股沟隐睾直接写成一定不育；把第 $3$ 个月睾丸写成已经入阴囊；把鞘膜腔通路写成出生时立刻完全闭合、漏掉“逐渐”；把下降写成睾丸自己掉下去、漏掉引带相对缩短。
