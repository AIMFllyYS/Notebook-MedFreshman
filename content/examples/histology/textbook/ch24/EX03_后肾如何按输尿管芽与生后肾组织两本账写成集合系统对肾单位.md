**题目**：后肾是不是人体永久肾、由哪两块原基互相诱导、共同分化而成？第几周初、中肾管近何处向胚体背外侧头端发出一盲管、称什么芽？该芽长入哪一嵴的尾端，诱导周围中胚层细胞向其末端聚集、包绕，形成什么组织、又称什么原基？输尿管芽主干分化成什么、末端反复分支分别形成哪些管道？集合管呈什么形分支、末端由什么帽状组织覆盖，内部细胞团先成小泡再演化为什么形肾小管，一端成什么、另一端必须与什么接通、其余弯曲延长成哪三段？肾单位来自哪一块、集合管来自哪一块？第 $12$ 周左右后肾开始产生什么、构成羊水的主要来源？原始位置在哪、随后怎样上升并沿纵轴怎样旋转？为什么不能把肾单位写成输尿管芽长出来的，也不能把远曲小管与集合管未接通听成“芽没分好支”？

**解**：
教材 definition：**后肾（metanephros）是人体永久肾。它不是中肾改名，而是输尿管芽与生后肾组织互相诱导、共同分化的新器官。** 教材 definition：**输尿管芽（ureteric bud）是第 $5$ 周初中肾管近泄殖腔处向胚体背外侧头端发出的盲管。** 它长入中肾嵴尾端，诱导周围中胚层细胞向其末端聚集、包绕，形成生后肾组织（metanephrogenic tissue），又称生后肾原基（metanephrogenic blastema）。教材 concept：**先问后肾里集合管是输尿管芽变的还是肾单位是生后肾组织变的。**

教材 definition：**输尿管芽伸长，主干分化成输尿管，末端反复分支，分别形成肾盂、肾盏和集合管。** 集合管呈 T 形分支，末端由帽状生后肾组织覆盖。末端陆续诱导内部细胞团：先成小泡，再成 S 形肾小管。一端膨大凹陷成双层囊，包绕毛细血管球形成肾小体；另一端必须与集合管接通；其余弯曲延长成近端小管、细段和远端小管。集合管末端不断向浅部呈 T 形生长，诱导大量肾单位构成肾皮质；生后肾组织外周形成肾被膜。

教材 definition：**肾单位来自生后肾组织，不来自输尿管芽。集合管来自输尿管芽，不来自生后肾组织。** 教材 pitfall：**集合管和肾单位不是同一块原基长出来的。** 输尿管芽这一本账走到集合管为止；生后肾组织这一本账走到肾小体和近端小管、细段、远端小管。接通发生在远曲小管与集合管之间。写成“输尿管芽长出整个肾单位”，多囊肾就变成“芽没分好支”，和教材机制对不上。芽未形成或早期退化 → 肾缺如；过早分支或同侧两个芽 → 双输尿管；远曲小管与集合管未接通 → 多囊肾。

教材 definition：**人胚第 $12$ 周左右，后肾开始产生尿液，构成羊水的主要来源。** 后肾发生于中肾嵴尾端，原始位置较低、位于盆腔；随后因胎儿生长、输尿管伸展及胚体直立，肾移至腰部，同时沿纵轴旋转，肾门从腹侧转向内侧。上升受阻 → 异位肾；卡在肠系膜下动脉根部、两肾下端融合 → 马蹄肾。

| 项目 | 输尿管芽 | 生后肾组织（生后肾原基） |
|------|----------|--------------------------|
| 英文 | ureteric bud | metanephrogenic tissue / blastema |
| 来源 | 中肾管近泄殖腔处向背外侧头端发出的盲管 | 输尿管芽诱导中肾嵴尾端中胚层细胞聚集、包绕 |
| 出现 | 第 $5$ 周初 | 芽长入尾端之后 |
| 分化 | 主干 → 输尿管；末端反复分支 → 肾盂、肾盏、集合管 | 细胞团 → 小泡 → S 形肾小管 → 肾小体 + 近端小管、细段、远端小管；外周 → 肾被膜 |
| 关键一步 | T 形分支，末端诱导帽状组织 | 肾小管另一端必须与集合管接通 |
| 未形成 / 未接通 | 芽未形成或早期退化 → 肾缺如；过早分支或同侧两个芽 → 双输尿管 | 远曲小管与集合管未接通 → 多囊肾 |

易错点：把后肾写成中肾改名；把肾单位写成输尿管芽长出来的、把集合管写成生后肾组织变的；把多囊肾听成“芽没分好支”；漏写远曲小管必须与集合管接通；把第 $12$ 周产尿听成“排泄废物为主”而不是羊水主要来源；把原始位置写成腰部、漏掉盆腔上升和肾门由腹侧转向内侧。
