**题目**：第 $3$ 周末泄殖腔膜周围的间充质细胞增生形成头尾走向的两条弧形皱褶称什么，第 $6$ 周伴随泄殖腔和泄殖腔膜的分隔被分成腹侧较大的什么褶和背侧较小的什么褶？尿生殖褶之间的凹陷为尿生殖沟、沟底为尿生殖膜，尿生殖褶的头端靠拢增殖隆起为什么结节，左、右尿生殖褶外侧的间充质增生形成一对大的纵行隆起称什么？在雄激素作用下生殖结节明显伸长增粗形成什么，左、右尿生殖褶在腹侧中线闭合形成什么并参与阴茎，左、右阴唇阴囊隆起向尾端牵拉于中线融合形成什么？无雄激素作用时外生殖器自然分化为女性，生殖结节稍增大为什么，尿生殖褶发育为什么，阴唇阴囊隆起继续增大形成什么、其头端合并为什么、尾端合并为什么，尿生殖沟扩展参与形成什么？外生殖器性别到第几周才可分辨？为什么不能把女性外生殖器写成另分泌一套“女性激素”才长出来，也不能把小阴唇写成尿生殖窦下段、把阴囊写成“睾丸自己带下来的皮肤袋”？

**解**：
教材 definition：**第 $3$ 周末，泄殖腔膜周围间充质增生，形成头尾走向的两条弧形皱褶，称泄殖腔褶。** 第 $6$ 周随泄殖腔和泄殖腔膜分隔，分成腹侧较大的尿生殖褶和背侧较小的肛褶。尿生殖褶之间的凹陷为尿生殖沟，沟底为尿生殖膜。尿生殖褶的头端靠拢，增殖隆起为生殖结节。左、右尿生殖褶外侧的间充质增生，形成一对大的纵行隆起，称阴唇阴囊隆起。教材 concept：**先问有没有雄激素，再问生殖结节、尿生殖褶、阴唇阴囊隆起各走哪一条。** 外生殖器性别到第 $12$ 周才可分辨。

教材 definition：**雄激素作用下：生殖结节 → 阴茎；左右尿生殖褶腹侧中线闭合 → 尿道海绵体，参与阴茎；左右阴唇阴囊隆起中线融合 → 阴囊。** 褶没闭全，阴茎腹侧就留下尿道开口，即尿道下裂。教材 definition：**无雄激素作用，外生殖器自然分化为女性。** 生殖结节稍增大为阴蒂；左、右尿生殖褶发育为小阴唇；两侧阴唇阴囊隆起继续增大隆起，形成大阴唇，其头端合并为阴阜，尾端合并形成阴唇后连合；尿生殖沟扩展，参与形成阴道前庭。教材 pitfall：**女性外生殖器是无雄激素下的自然分化，不是另分泌一套“女性激素”才长出来。** 雄激素不足的 $46,\mathrm{XY}$ 胎儿，外生殖器可向女性方向不完全分化；肾上腺雄激素过多的 $46,\mathrm{XX}$ 胎儿，可向男性方向不完全分化。开关在雄激素，不在“有没有卵巢激素驱动外阴发生”。

把小阴唇写成“尿生殖窦下段”，或把阴囊写成“睾丸自己带下来的皮肤袋”，尿道下裂和阴唇后连合会对错原基。尿生殖窦下段在女性扩大为阴道前庭；阴囊来自阴唇阴囊隆起中线融合，不是睾丸下降时自己翻出来的皮袋。

| 未分化结构 | 男性（需雄激素） | 女性（无雄激素，自然分化） |
|------------|------------------|------------------------------|
| 生殖结节 | 明显伸长、增粗 → 阴茎 | 稍增大 → 阴蒂 |
| 尿生殖褶 | 腹侧中线闭合 → 尿道海绵体，参与阴茎 | 小阴唇 |
| 尿生殖沟 | 随褶闭合被包入 | 扩展，参与阴道前庭 |
| 阴唇阴囊隆起 | 向尾端牵拉，中线融合 → 阴囊 | 大阴唇；头端合并为阴阜，尾端合并为阴唇后连合 |

| 时间 | 事件 |
|------|------|
| 第 $3$ 周末 | 泄殖腔膜周围间充质形成泄殖腔褶 |
| 第 $6$ 周 | 泄殖腔褶分成腹侧尿生殖褶、背侧肛褶；头端成生殖结节；外侧成阴唇阴囊隆起 |
| 有雄激素 | 结节成阴茎，褶闭合参与尿道海绵体，隆起融合成阴囊 |
| 无雄激素 | 结节成阴蒂，褶成小阴唇，隆起成大阴唇，沟成阴道前庭 |
| 第 $12$ 周 | 外生殖器性别才可分辨 |

易错点：把女性外生殖器写成另分泌一套女性激素才长出来；把小阴唇写成尿生殖窦下段；把阴囊写成睾丸自己带下来的皮肤袋；把尿生殖褶和阴唇阴囊隆起对调；把尿道下裂写成隐睾或膀胱外翻；把外生殖器可辨认时间写成受精时或第 $7$ 周；漏写泄殖腔褶第 $6$ 周才分成尿生殖褶和肛褶。
