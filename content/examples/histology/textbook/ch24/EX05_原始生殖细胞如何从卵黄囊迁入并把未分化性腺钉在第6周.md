**题目**：遗传性别在何时已由精子的核型确定，生殖腺要到第几周才能辨认性别、外生殖器要到第几周才可分辨？生殖腺、生殖管道和外生殖器的发生过程均分为早期的什么阶段和后期的什么阶段？生殖腺由生殖嵴表面的什么上皮、上皮下的什么以及迁入的什么细胞共同发育而成？第 $5$ 周生殖嵴表面上皮细胞增生、伸入下方间充质形成许多不规则细胞索条称什么？人胚第 $4$ 周初靠近什么根部的卵黄囊壁哪一层出现大而圆的细胞、称什么，它们沿什么向生殖嵴迁移、第几周迁入初级性索？此时的生殖腺有没有性别特征、称什么？为什么不能把原始生殖细胞写成生殖嵴自己长出来的，也不能把“受精就长出阴茎或阴道”写成一句？

**解**：
教材 definition：**遗传性别在受精时已由精子的核型确定。生殖腺要到胚胎第 $7$ 周才能辨认性别，外生殖器要到第 $12$ 周才可分辨。** 中间这一段，形态上仍是未分化。教材 definition：**生殖腺、生殖管道和外生殖器的发生过程均分为早期的性未分化阶段和后期的性分化阶段。** 未分化不是“没有原基”，而是两套原基都在、尚未按男女取舍。教材 concept：**先问遗传性别何时确定，再问生殖腺、外生殖器各到第几周才能辨认。** 把“受精就长出阴茎或阴道”写成一句，未分化性腺、两套管道和未分化外生殖器整段都会被划掉。

教材 definition：**生殖腺由生殖嵴表面的体腔上皮、上皮下的间充质和迁入的原始生殖细胞共同发育而成。** 缺了迁入的原始生殖细胞，上皮和间充质堆不出有配子的性腺。教材 definition：**初级性索（primary sex cord）是第 $5$ 周生殖嵴表面上皮细胞增生、伸入下方间充质形成的许多不规则细胞索条。** 男女未分化期都有这一套。

教材 definition：**原始生殖细胞（primordial germ cell）是人胚第 $4$ 周初靠近尿囊根部的卵黄囊壁内胚层出现的大而圆的细胞。** 它们沿后肠背系膜向生殖嵴迁移，第 $6$ 周迁入初级性索。不是在生殖嵴里就地发生的。教材 definition：**第 $6$ 周原始生殖细胞迁入初级性索后，生殖腺仍无性别特征，称未分化性腺。** 有没有 Y 染色体、有没有 TDF，下一阶段才分出睾丸或卵巢。教材 pitfall：**原始生殖细胞来自卵黄囊内胚层，不是生殖嵴自己长出来的。** 写成“生殖嵴上皮直接变成精原细胞或卵原细胞”，迁移这本账会消失。

| 时间 | 事件 |
|------|------|
| 受精 | 精子核型确定遗传性别 |
| 第 $4$ 周初 | 原始生殖细胞出现于靠近尿囊根部的卵黄囊壁内胚层 |
| 第 $5$ 周 | 生殖嵴表面上皮伸入间充质，形成初级性索 |
| 迁移途中 | 原始生殖细胞沿后肠背系膜走向生殖嵴 |
| 第 $6$ 周 | 迁入初级性索；此时称未分化性腺，尚无性别特征 |
| 第 $7$ 周 | 生殖腺才能辨认性别 |
| 第 $12$ 周 | 外生殖器的性别才可分辨 |

| 项目 | 来源 | 不要听成 |
|------|------|----------|
| 体腔上皮 | 生殖嵴表面，伸入成初级性索 | 自己变成精原细胞或卵原细胞 |
| 间充质 | 上皮下方 | 已经是白膜或间质细胞 |
| 原始生殖细胞 | 卵黄囊内胚层，沿后肠背系膜迁入 | 生殖嵴就地发生 |

易错点：把受精写成已经长出阴茎或阴道；把生殖腺辨认时间写成第 $4$ 周或与外生殖器第 $12$ 周并成一句；把原始生殖细胞写成生殖嵴上皮变的；把迁入时间写成第 $4$ 周而不是第 $6$ 周；把未分化性腺听成“没有原基”；漏写三件套里迁入的原始生殖细胞；把初级性索只写成男性才有。
