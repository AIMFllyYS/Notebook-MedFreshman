**题目**：视细胞分哪两部分外突、内节和外节各干什么、膜盘由什么形成？视杆和视锥在分布、功能、数量、外形、核、膜盘是否脱落上如何对照？视紫红质和视色素各由什么组成、维生素 A 不足伤哪一种、缺某型视锥叫什么？中央凹只有哪一种视细胞？为什么夜盲要找视杆和维生素 A、色盲要找视锥类型，而不能并成一句“视力不好”？

**解**：
教材 definition：**视细胞即感光细胞，是感受光线的感觉神经元，分胞体、外突和内突 3 部分。** 外突伸向色素上皮，中段缩窄分成内节与外节，缩窄处内部为连接纤毛。教材 definition：**内节紧邻胞体，含丰富的线粒体、粗面内质网和高尔基复合体，是合成感光蛋白的部位。** 教材 definition：**外节是感光部位，含大量平行层叠的扁平状膜盘。** 膜盘由外节基部一侧细胞膜向胞质内陷形成，膜中有能感光的镶嵌蛋白。内突末端主要与双极细胞形成突触。

教材 definition：**视杆细胞主要分布在视网膜周围部，感受弱光，数量远多于视锥细胞。** 细胞较细长，核较小、染色较深；外突呈杆状，内突末端膨大呈小球状。膜盘与细胞表面胞膜分离而独立，每个视杆可有数百至上千个膜盘；膜盘不断更新，由外节基部向顶端推移，顶端老化脱落，被色素上皮吞噬消化。教材 definition：**视紫红质是视杆细胞膜盘上的感光蛋白，由 11-顺式视黄醛和视蛋白组成。** 维生素 A 是合成 11-顺式视黄醛的原料。维生素 A 不足 → 视紫红质缺乏 → 弱光视力减退，即夜盲症。病在视杆，不在视锥。

教材 definition：**视锥细胞主要分布在视网膜中部，感受强光和颜色。** 外形较视杆粗大，核较大、染色较浅；外突呈圆锥形，内突末端膨大呈足状。外节膜盘大多与细胞膜不分离，顶端膜盘也不脱落。教材 definition：**视色素是视锥细胞的感光物质，由 11-顺式视黄醛和视蛋白组成，视蛋白结构与视紫红质不同。** 视锥分 3 种功能类型，分别含红敏、绿敏和蓝敏色素。缺少感红光（或绿光）的视锥细胞，则不能分辨红（或绿）色，为红（或绿）色盲。病在某种视锥，不在视杆。

教材 pitfall：**夜盲找视杆和维生素 A，色盲找视锥类型，不要并成“视力不好”。** 两种细胞都用 11-顺式视黄醛，差别在视蛋白和外节膜盘是否脱落。中央凹只有视锥、没有视杆，所以黄昏看细字要靠周围视网膜的视杆——不要以为“黄斑最敏锐”等于“哪里都最敏锐”。侏儒双极细胞只与一个视锥和一个节细胞联系，位于中央凹边缘，为一对一精确传导提供中间站。

| 项目 | 视杆细胞 | 视锥细胞 |
|------|----------|----------|
| 英文 | rod cell | cone cell |
| 主要分布 | 视网膜周围部 | 视网膜中部；中央凹只有视锥 |
| 功能 | 感受弱光 | 感受强光和颜色 |
| 数量 | 远多于视锥 | 较少 |
| 外形 | 较细长；外突杆状；内突末端小球状 | 较粗大；外突圆锥形；内突末端足状 |
| 核 | 较小，染色较深 | 较大，染色较浅 |
| 膜盘 | 与表面胞膜分离；基部新生、顶端脱落，被色素上皮吞噬 | 大多与细胞膜不分离；顶端不脱落 |
| 感光蛋白 | 视紫红质（11-顺式视黄醛 + 视蛋白） | 视色素（11-顺式视黄醛 + 另一种视蛋白）；红、绿、蓝三型 |
| 缺乏时 | 维生素 A 不足 → 夜盲 | 缺某型视锥 → 红/绿色盲 |

易错点：把夜盲和色盲并成“视力不好”；把视紫红质写到视锥上；把膜盘脱落写到视锥上；以为中央凹既有视杆又有视锥所以“什么光都最敏锐”；把色素上皮的吞噬写成视锥膜盘的日常更新。
