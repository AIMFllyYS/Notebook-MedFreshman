:::example{label="输尿管如何写成变移上皮星形腔而不套复层扁平"}
**题目**：输尿管是产尿器官还是排尿器官、管壁由内向外分哪 3 层、有没有黏膜肌层和黏膜下层？黏膜由什么上皮加什么固有层构成、为什么管腔呈星形？变移上皮空虚时大约几层、扩张时变为几层、为什么不能写成复层扁平？上 $2/3$ 段和下 $1/3$ 段肌层各几层、排列如何、和消化管内环外纵有何对调？外膜是什么组织？终尿从乳头管到尿道怎样走？为什么看见输尿管切片要先认星形管腔和变移上皮，再数肌层是两层还是三层，而不能把输尿管听成“消化管四层”或“全程三层肌”？

**解**：
教材 definition：**输尿管（ureter）是排尿器官。** 管壁由内向外分黏膜、肌层和外膜 3 层。它把肾形成的终尿送向膀胱，本身不产尿。教材 concept：**先认星形管腔和变移上皮，再数肌层是两层还是三层。** 不要按第 14 章消化管四层去找黏膜肌和黏膜下层。

教材 definition：**黏膜由变移上皮和固有层的结缔组织构成。** 黏膜形成许多纵行皱襞，故管腔呈星形。黏膜的变移上皮较厚，有 $4\sim 5$ 层细胞，扩张时可变为 $2\sim 3$ 层。细胞形状和层数随管腔空虚或扩张而改变，不是固定层数的复层扁平上皮。教材 pitfall：**输尿管变移上皮不是复层扁平。** 复层扁平上皮的层数不随管腔充盈这样折叠减少，表层也不形成变移上皮那种盖细胞。写成交接部的复层扁平，排尿管道的伸缩账就做成了皮肤或食管。

教材 definition：**输尿管上 $2/3$ 段的肌层为内纵行、外环行两层平滑肌；下 $1/3$ 段肌层增厚，为内纵行、中环行和外纵行 3 层平滑肌。** 教材 pitfall：**不要把输尿管上 $2/3$ 也写成内纵中环外纵三层肌。** 三层肌只在下 $1/3$ 段出现。上 $2/3$ 环行在外、纵行在内，和消化管常见的内环外纵正好对调。套错模板，上段切片会数出一层并不存在的外纵肌。外膜为疏松结缔组织，不是浆膜，也没有软骨支架。

教材 insight：**星形管腔是皱襞留下的余地，变移上皮是给扩张用的。** 纵行皱襞使空虚时管腔呈星形；尿液经过时皱襞展平，上皮从 $4\sim 5$ 层变成 $2\sim 3$ 层。终尿经乳头管 → 肾小盏 → 肾大盏 → 肾盂 → 输尿管 → 膀胱 → 尿道。肾盏、肾盂同样衬变移上皮，但管壁分层以黏膜、肌层、外膜为观察模板。

| 项目 | 上 $2/3$ 段 | 下 $1/3$ 段 |
|------|-------------|-------------|
| 肌层数目 | 2 层 | 3 层（增厚） |
| 排列 | 内纵行、外环行 | 内纵行、中环行、外纵行 |
| 上皮 | 变移上皮，$4\sim 5$ 层，扩张时 $2\sim 3$ 层 | 同左 |
| 管腔 | 黏膜纵行皱襞，呈星形 | 同左 |
| 外膜 | 疏松结缔组织 | 疏松结缔组织 |

| 项目 | 输尿管 | 消化管（除口腔与咽外） |
|------|--------|--------------------------|
| 层次 | 黏膜、肌层、外膜 3 层 | 黏膜、黏膜下层、肌层、外膜 4 层 |
| 上皮 | 变移上皮 | 多为单层柱状或复层扁平 |
| 黏膜肌层 | 无 | 有 |
| 管腔形态 | 纵行皱襞，横切呈星形 | 不以星形为特征 |

易错点：把变移上皮写成复层扁平；把管壁硬套消化管四层；把上 $2/3$ 也写成三层肌；把内纵外环写成消化管的内环外纵；把外膜写成浆膜；把输尿管听成产尿器官。
