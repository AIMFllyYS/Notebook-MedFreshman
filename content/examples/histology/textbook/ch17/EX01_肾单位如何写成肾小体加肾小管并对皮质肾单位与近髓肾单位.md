:::example{label="肾单位如何写成肾小体加肾小管并对皮质肾单位与近髓肾单位"}
**题目**：泌尿系统包括哪些器官、谁产尿谁排尿？肾实质怎样分成皮质和髓质、肾小叶和肾叶各由什么组成、肾柱是皮质还是髓质？肾单位由哪两部分组成、每个肾大约多少个、集合管算不算肾单位的一段？肾小管怎样从尿极走到集合管、谁构成髓袢？浅表肾单位（皮质肾单位）和髓旁肾单位（近髓肾单位）在位置、体积、髓袢、百分比和生理意义上如何对照？为什么看见“一个肾单位”要先沿一条管子从尿极走到集合管，再问这个肾小体浅还是深，而不能把集合管写进肾单位，也不能把髓旁听成数量更多的那种？

**解**：
教材 definition：**泌尿系统（urinary system）包括肾、输尿管、膀胱和尿道。** 肾产生尿液，输尿管、膀胱和尿道为排尿器官。教材 concept：**先问这是产尿的肾，还是只负责把尿送出去的管道。** 把“泌尿”听成“从肾到尿道都在造尿”，滤过屏障和变移上皮会并成一句。

肾实质分为皮质和髓质。髓质由 $10\sim 18$ 个肾锥体组成；锥体尖端称肾乳头，突入肾小盏。从锥体底辐射伸入皮质的条纹称髓放线；髓放线之间的皮质称皮质迷路。教材 definition：**一条髓放线及其周围的皮质迷路组成一个肾小叶；一个肾锥体与相连的皮质组成一个肾叶；肾锥体之间的皮质部分称为肾柱。** 教材 pitfall：**肾柱是皮质伸进锥体之间，不要写成髓质。** 弯曲的肾小体、近曲、远曲落在皮质迷路和肾柱；直行的近直、细段、远直和直集合管落在髓放线和肾锥体。

教材 definition：**肾单位（nephron）是肾的结构与功能单位，由肾小体和肾小管组成。** 每个肾约有 150 万个肾单位，它们与集合管共同行使泌尿功能。教材 definition：**肾小管汇入集合管，二者都是单层上皮性管道，合称泌尿小管。** 教材 pitfall：**集合管与肾单位共同泌尿，但集合管不是肾单位的一段。** 把集合管写进肾单位，乳头管和心房钠尿肽那本账会算错户头。

教材 concept：**先沿一条管子从尿极走到集合管，再问这个肾小体浅还是深。** 走行背成一条线：肾小体 → 近曲 → 近直 → 细段 → 远直 → 远曲 → 集合管。近直、细段、远直三者构成 U 形髓袢。浅表肾单位又称皮质肾单位：肾小体位于皮质浅层和中层，体积较小，髓袢较短，约占总数的 $85\%$，在尿液形成中起重要作用。髓旁肾单位又称近髓肾单位：肾小体位于皮质深部，体积较大，髓袢较长，约占 $15\%$，对尿液浓缩具有重要生理意义。教材 pitfall：**浅表肾单位占 85%，不要写成髓旁占大多数。** 数量账在浅表，浓缩账在髓旁（髓袢长、直小血管袢）。把“重要”听成“数量多”，百分比会对调。

| 项目 | 浅表肾单位（皮质肾单位） | 髓旁肾单位（近髓肾单位） |
|------|--------------------------|--------------------------|
| 肾小体位置 | 皮质浅层和中层 | 皮质深部 |
| 体积 | 较小 | 较大 |
| 髓袢 | 较短 | 较长 |
| 约占总数 | $85\%$ | $15\%$ |
| 主要生理意义 | 尿液形成 | 尿液浓缩 |
| 出球微动脉去向 | 分支形成球后毛细血管网 | 球后毛细血管网 + 直小动脉入髓质 |

| 项目 | 组成 | 不要听成 |
|------|------|----------|
| 肾小叶 | 一条髓放线 + 其周围的皮质迷路 | 一个肾锥体 |
| 肾叶 | 一个肾锥体 + 相连的皮质 | 一条髓放线 |
| 肾柱 | 肾锥体之间的皮质 | 髓质 |
| 肾单位 | 肾小体 + 肾小管 | 肾小体 + 肾小管 + 集合管 |

易错点：把集合管写进肾单位；把“一个肾单位”听成“一个肾小体”；把髓旁写成数量占优；把肾柱写成髓质；把肾小叶和肾叶对调；漏写浅表又称皮质肾单位、髓旁又称近髓肾单位。
