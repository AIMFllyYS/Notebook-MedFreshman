**题目**：前列腺呈什么形、环绕何处、被膜与支架组织富含什么、实质大约多少个复管泡状腺、导管大约多少条开口于何处？腺实质分哪 3 个带、黏膜腺、黏膜下腺和主腺各在哪、谁最小、谁构成大部？腺分泌部为何由三种上皮交错构成、腺腔为什么不规则、腔内圆形嗜酸性板层状小体称什么、年纪大了可以变成什么？前列腺分泌物是什么颜色、富含哪些物质、受什么激素刺激？老年人增生肥大多发生在哪两带、为何造成排尿困难？前列腺癌主要发生在哪一带？为什么不能把增生和癌的部位对调，也不能把凝固体当成卵或寄生虫卵？

**解**：
教材 definition：**前列腺（prostate）呈栗形，环绕于尿道起始段。** 被膜与支架组织均由富含弹性纤维和平滑肌纤维的结缔组织组成。实质主要由 $30\sim 50$ 个复管泡状腺组成，有 $15\sim 30$ 条导管开口于尿道精阜两侧。平滑肌出现在腺泡之间，收缩有助于排出分泌物；不要把它当成间质细胞那种嗜酸性内分泌细胞。

腺实质可分 3 个带：尿道周带（又称黏膜腺）最小，位于尿道黏膜内；内带（又称黏膜下腺）位于黏膜下层；外带（又称主腺）构成前列腺的大部。教材 pitfall：**老年增生多在黏膜腺和黏膜下腺，前列腺癌主要在外带，两本账不要对调。** 压迫尿道、排尿困难，落点是尿道周带和内带的增生肥大。癌的主账在构成大部的外带。把“老年人前列腺出问题”一律写成外带增生，或把癌写到黏膜腺，部位会整段反了。

腺分泌部由单层立方上皮、单层柱状上皮及假复层柱状上皮交错构成，故腺腔很不规则。腔内可见分泌物浓缩形成的圆形嗜酸性板层状小体，称前列腺凝固体（prostatic concretion），随年龄增长而增多，甚至可以钙化成为前列腺结石。教材 insight：**腺腔不规则是三种上皮交错铺的，板层小体是浓缩的分泌物。** 不要把凝固体当成卵或寄生虫卵。

从青春期开始，前列腺在雄激素的刺激下分泌活动增强，分泌物为稀薄的乳白色液体，富含酸性磷酸酶和纤维蛋白溶酶，还有柠檬酸和锌等物质。纤维蛋白溶酶参与精液液化；酸性磷酸酶、柠檬酸和锌是前列腺分泌物的化学标记。这本分泌账听雄激素，和间质细胞的睾酮来源相接。果糖不在前列腺，写在精囊那一题。

| 项目 | 尿道周带（黏膜腺） | 内带（黏膜下腺） | 外带（主腺） |
|------|--------------------|------------------|--------------|
| 位置 | 尿道黏膜内 | 黏膜下层 | 最外围，构成大部 |
| 体积 | 最小 | 介于两者之间 | 最大 |
| 老年增生 | 常见 | 常见；二者增生可压迫尿道，造成排尿困难 | 不是增生的主账 |
| 前列腺癌 | 不是主要发生部位 | 不是主要发生部位 | 主要发生在外带 |

| 观察点 | 要点 |
|--------|------|
| 外形 | 栗形，环绕尿道起始段 |
| 被膜与支架 | 富含弹性纤维和平滑肌纤维的结缔组织 |
| 实质 | $30\sim 50$ 个复管泡状腺；$15\sim 30$ 条导管开口于尿道精阜两侧 |
| 分泌部上皮 | 单层立方、单层柱状、假复层柱状交错 → 腺腔不规则 |
| 腔内 | 圆形嗜酸性板层状凝固体，可钙化成结石 |
| 分泌物 | 稀薄乳白色；酸性磷酸酶、纤维蛋白溶酶、柠檬酸、锌 |
| 激素 | 青春期后雄激素刺激分泌增强 |

易错点：把增生写到外带、把癌写到黏膜腺；把三种上皮听成单一型；把凝固体当成卵；把平滑肌支架写成间质细胞；把果糖写到前列腺；漏写酸性磷酸酶和纤维蛋白溶酶。
