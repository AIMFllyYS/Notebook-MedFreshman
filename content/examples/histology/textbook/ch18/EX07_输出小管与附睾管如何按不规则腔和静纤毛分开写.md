**题目**：附睾位于何处、分哪 3 部分、头部和体尾各由什么小管组成？输出小管有几根、上皮为何高低相间、管腔为什么不规则、高柱状细胞的纤毛干什么、矮柱状细胞含什么？附睾管长约多少、管腔规则不规则、上皮由哪两种细胞组成、主细胞表面是运动纤毛还是静纤毛？精子在附睾内停留多少天、依赖什么激素、与哪些分泌物密切相关、达不到功能成熟会怎样？血-附睾屏障位于何处、和血-睾屏障如何对照？为什么不能把输出小管的不规则腔和附睾管的规则腔写反，也不能把静纤毛写成会摆动的运动纤毛？

**解**：
教材 definition：**附睾（epididymis）位于睾丸的后外侧，分头、体、尾 3 部分。** 头部主要由与睾丸网相连的输出小管组成；体部和尾部由极度盘曲的附睾管组成。远端附睾管与输精管相连。精子在此停留 $8\sim 17$ 天（本章小结亦称约 2 周），获得运动能力并达到功能成熟。

教材 definition：**输出小管（efferent duct）是与睾丸网连接的 $8\sim 12$ 根弯曲小管。** 上皮由高柱状纤毛细胞和矮柱状细胞相间排列，故管腔不规则。高柱状纤毛细胞游离面有大量纤毛，纤毛摆动促使精子向附睾管运行——这是能摆动的运动纤毛。矮柱状细胞含大量溶酶体及吞饮小泡，可吸收和消化管腔内物质。教材 pitfall：**输出小管管腔不规则，不要和附睾管的规则管腔写反。** 高低柱状细胞相间，腔缘像锯齿，这是输出小管的身份证。附睾管腔规则、充满精子。只写“附睾里都是一样的小管”，头部和体尾会认错，纤毛和静纤毛也会并成一句。

教材 definition：**附睾管（epididymal duct）长 $4\sim 6\,\mathrm{m}$，极度盘曲，远端连输精管。** 管腔规则，腔内充满精子和分泌物。上皮为假复层柱状上皮，由主细胞和基细胞组成。主细胞起始段为高柱状，而后逐渐变低，至末段转变为立方形；表面有成簇排列的粗而长的静纤毛，具有分泌和吸收功能。基细胞矮小，呈锥形，位于上皮深层。上皮外侧有薄层平滑肌和富含血管的疏松结缔组织。教材 definition：**静纤毛是微绒毛样结构，不摆动，与输出小管高柱状细胞的运动纤毛不是一本账。** 教材 pitfall：**附睾管的静纤毛不能摆动，不要写成输出小管那种运动纤毛。** 把静纤毛听成“也会扫精子”，成熟所需的肉毒碱、甘油磷酸胆碱和唾液酸会失去细胞学落点。

精子在附睾内经历一系列成熟变化，获得运动能力，达到功能上的成熟。这不仅依赖于雄激素的存在，而且与附睾上皮细胞分泌的肉毒碱、甘油磷酸胆碱和唾液酸等密切相关。附睾功能异常也会影响精子的成熟，导致不育。教材 definition：**血-附睾屏障位于主细胞近腔面的紧密连接处。** 保护成熟中的精子不受外界干扰，并将精子与免疫系统隔离。教材 insight：**睾丸交出的是还不会动的精子，附睾用八到十七天把它养成。** 离开睾丸网时精子形态已经是蝌蚪，功能并未成熟。附睾一坏，精液里可以有精子，却仍可不育。

| 项目 | 输出小管 | 附睾管 |
|------|----------|--------|
| 位置 | 附睾头部，连睾丸网，$8\sim 12$ 根 | 附睾体部和尾部，长 $4\sim 6\,\mathrm{m}$，极度盘曲 |
| 上皮 | 高柱状纤毛细胞与矮柱状细胞相间 | 假复层柱状上皮：主细胞 + 基细胞 |
| 管腔 | 不规则 | 规则，充满精子和分泌物 |
| 游离面 | 运动纤毛，摆动推送精子 | 成簇粗长静纤毛，不摆动 |
| 吸收 | 矮柱状细胞：溶酶体、吞饮小泡 | 主细胞有分泌和吸收功能 |
| 屏障 | 不作为血-附睾屏障的主账 | 主细胞近腔面紧密连接 = 血-附睾屏障 |
| 下游 | 连附睾管 | 连输精管 |

| 项目 | 血-睾屏障 | 血-附睾屏障 |
|------|-----------|--------------|
| 位置 | 生精小管与血液之间 | 附睾管主细胞近腔面 |
| 核心结构 | 支持细胞近基底部紧密连接（外加内皮及基膜、结缔组织、生精上皮基膜） | 主细胞近腔面的紧密连接 |
| 隔离对象 | 生精过程中的精子抗原；维持精子发生微环境 | 成熟中的精子；与免疫系统隔离 |
| 住在屏障腔内的细胞 | 近腔室：精母细胞、精子细胞、精子 | 附睾管腔内的成熟中精子 |

易错点：把输出小管不规则腔和附睾管规则腔写反；把静纤毛写成运动纤毛；把附睾头写成附睾管、体尾写成输出小管；漏写 $8\sim 17$ 天和肉毒碱、甘油磷酸胆碱、唾液酸；把血-附睾屏障写成支持细胞紧密连接；把睾丸交出的精子听成已经会动。
