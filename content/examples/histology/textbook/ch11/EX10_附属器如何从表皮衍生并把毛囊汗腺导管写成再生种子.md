:::example{label="附属器如何从表皮衍生并把毛囊汗腺导管写成再生种子"}
**题目**：全章把皮肤怎样写成通式：表皮几层、三种非角质形成细胞、真皮两层、附属器哪四套？附属器为何说是表皮衍生、位置深到真皮甚至皮下能否改写来源？表皮干细胞写在哪一层、毛囊干细胞写在哪一段、甲母质写在哪、深创时上皮小岛又来自哪？EGF 由谁在创面早期释放、后期如何与瘢痕相关？为什么不能把附属器听成真皮自己长出的器官，也不能把再生写成与毛囊汗腺无关的另一本账？

**解**：
教材 definition：**皮肤 = 表皮（角化复层扁平上皮）+ 真皮（乳头层 + 网织层），借皮下组织连到深层。** 表皮主体是角质形成细胞五层，夹着黑素细胞、朗格汉斯细胞和梅克尔细胞。附属器从表皮衍生：毛（毛干、毛根、毛球）、皮脂腺、外泌/顶泌汗腺、指（趾）甲。更新靠基底层和毛囊/汗腺导管干细胞；深大损伤走肉芽，过深需植皮。教材 concept：**先问这套结构是不是从表皮长下去的。** 毛囊上皮根鞘与表皮连续，皮脂腺导管开口于毛囊或皮面，外泌汗腺导管螺旋穿过表皮成汗孔，甲体是连接牢固的角质细胞。把它们听成“真皮自己长出的器官”，毛母质、甲母质和汗腺导管提供再生干细胞那几本账都会写错层。

生理性再生把基底层干细胞写成 $3\sim 4$ 周更新的源头；换毛把毛囊干细胞钉在隆起部（皮脂腺开口与立毛肌附着点之间）；甲体把生长区钉在甲母质。代偿性再生则把同一批“长下去的表皮”再写一遍：深创把基底层掀掉以后，残存毛囊和汗腺导管上皮在肉芽表面冒出上皮小岛，与创缘迁来的角质形成细胞一起覆盖创面。过大过深、无残存附属器且创缘太远，才植皮。再生账和附属器账是同一批细胞的两种写法。

插入框把这条形态学通式补上分子抓手。教材 definition：**表皮生长因子（epidermal growth factor，EGF）是与组织修复密切相关的体内活性物质。** 1962 年 Cohen 首次从雄鼠颌下腺分离；1986 年因此获诺贝尔生理学或医学奖。创面修复早期，血小板释放的 EGF 趋化上皮细胞、巨噬细胞、成纤维细胞，并促内皮和成纤维增殖、血管生成、胶原和糖胺聚糖沉积，加速上皮化和创面收缩。后期降低组织组胺水平以调节拉伸强度，抑炎、降低 TGF-$\beta 1$、介导成熟胶原以减少瘢痕，EGF 浓度与瘢痕严重程度呈负相关。它还能促 DNA、RNA 和羟脯氨酸合成，诱导成熟皮肤细胞逆转为表皮干细胞。插入框不改写肉芽和植皮的形态学通式，只是给那条通式补上分子抓手。

| 结构 | 关键细胞或成分 | 职分 |
|------|----------------|------|
| 基底层 | 基底细胞（干细胞）；黑素细胞；梅克尔细胞 | 增殖；产黑素并转移；轻触觉 |
| 棘层 | 棘细胞；朗格汉斯细胞 | 张力丝、内披蛋白、板层颗粒；抗原呈递 |
| 颗粒层 / 透明层 / 角质层 | 透明角质颗粒 → 角蛋白 | 角化、屏障、脱落为皮屑 |
| 乳头层 | 毛细血管、触觉小体 | 营养表皮、精细触觉 |
| 网织层 | 粗胶原束、弹性纤维、环层小体 | 韧性与弹性、深压觉 |
| 毛球 / 隆起部 | 毛母质细胞；毛囊干细胞 | 生毛；换毛及表皮再生后备 |
| 皮脂腺 / 外泌汗腺 / 顶泌汗腺 | 全浆 / 胞吐 / 顶浆 | 润泽；散热排泄；体味 |
| 甲母质 | 增殖活跃的甲床上皮 | 甲体生长区 |
| 残存毛囊与汗腺导管 | 表皮源性干细胞 | 深创时形成上皮小岛 |

易错点：把附属器写成真皮另长的器官；把基底层干细胞、毛母质、隆起部干细胞、甲母质和汗腺导管干细胞并成一个没有位置的“皮肤干细胞”；把再生写成与附属器无关；用 EGF 改写肉芽–植皮的形态学通式，或把插入框听成可以替代植皮。
