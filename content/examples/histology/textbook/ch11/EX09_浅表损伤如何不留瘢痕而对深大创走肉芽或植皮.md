**题目**：皮肤再生分成哪两类、生理性再生包括哪些过程、表皮更新周期多久？代偿性再生的过程和时间依什么而异？小面积浅表损伤大约几天、留不留瘢痕？较大较深损伤按怎样的顺序走到肉芽组织和上皮小岛？上皮小岛的干细胞来自残存的什么结构？过大过深如大面积烧伤为何常需植皮？肉芽组织和瘢痕肉眼怎样、能不能划等号？为什么不能把“皮肤都能再生”写成无条件结论，也不能把所有愈合都写成必定留疤？

**解**：
教材 definition：**皮肤再生分为生理性再生和代偿性再生。** 生理性再生是正常情况下表皮增殖、角化和脱落，附属器周期性生长变化以及真皮成分的自我更新；代偿性再生是皮肤受损后的再生和修复。教材 definition：**生理性再生包括：表皮角质形成细胞不断增殖、迁移、角化并脱落（周期 $3\sim 4$ 周）；毛等附属器按生长周期更新；真皮纤维和基质的自我更新。** 教材 concept：**先问损伤有多深、面积有多大。** 浅而小的缺口，基底层还在，数天即可修复、不留瘢痕。深而大的缺口，表皮干细胞要靠残存毛囊和汗腺导管支援，真皮侧先走凝血–巨噬细胞–肉芽组织这条路。伤处既无残存附属器、创缘又隔得太远，就必须植皮。

教材 definition：**小面积浅表损伤数天即可修复，不留瘢痕。** 较大面积和较深的损伤：创伤处首先发生凝血；单核细胞进入组织，分化为巨噬细胞，清除组织碎片；巨噬细胞分泌趋化因子，吸引成纤维细胞和血管内皮细胞；成纤维细胞产生纤维和基质充填缺损，毛细血管长入，形成富含毛细血管的肉芽组织。损伤边缘的角质形成细胞逐渐移行至肉芽组织表面；残存的毛囊和汗腺导管上皮可提供表皮再生的干细胞，在局部形成上皮小岛。新生表皮的基底细胞继续增生分化形成各层，直至填补缺损。教材 definition：**损伤过大过深（如大面积烧伤），伤处无残存毛囊和汗腺、创缘相距太远，常需植皮。**

教材 definition：**肉芽组织是成纤维细胞产生纤维和基质充填缺损、毛细血管长入其中所形成的富含毛细血管的新生组织。** 教材 definition：**瘢痕组织是修复后的肉芽组织中胶原纤维逐渐形成粗纤维束、细胞成分和血管减少后的结局。** 肉眼观呈灰白色，质地坚韧，缺乏弹性。教材 pitfall：**肉芽组织不是化脓，也不等于最后留下的瘢痕。** 肉芽鲜红湿润，是表皮爬行的垫子；以后才变成灰白、坚韧、缺乏弹性的瘢痕。教材 pitfall：**小面积浅表损伤不留瘢痕，不要把所有愈合都写成“必定留疤”。** 深度决定结局，不是“破了皮就会留疤”。

第三节把毛囊隆起部和汗腺导管上皮写成表皮衍生。深部损伤把基底层整片掀掉以后，这些“长下去的表皮”反而成了再生的种子，在肉芽表面冒出上皮小岛。大面积烧伤把毛囊和汗腺一起烧掉，种子没了，创缘又够不着，才必须植皮。再生账和附属器账是同一批细胞的两种写法。

| 损伤 | 残留结构 | 表皮来源 | 真皮侧 | 结局 |
|------|----------|----------|--------|------|
| 小面积浅表 | 基底层及真皮大部保留 | 周围及底部基底细胞 | 无需大量肉芽 | 数天修复，不留瘢痕 |
| 较大较深 | 可有残存毛囊、汗腺导管 | 创缘移行 + 上皮小岛 | 凝血 → 巨噬 → 肉芽 | 可修复；肉芽常被瘢痕取代 |
| 过大过深（如大面积烧伤） | 无残存毛囊和汗腺，创缘太远 | 自身无法覆盖 | 肉芽不足或无法上皮化 | 常需植皮 |

| 步骤 | 过程 |
|------|------|
| ① 凝血 | 创伤处首先发生凝血 |
| ② 清创 | 单核细胞进入并分化为巨噬细胞，清除组织碎片 |
| ③ 募集 | 巨噬细胞分泌趋化因子，吸引成纤维细胞和血管内皮细胞 |
| ④ 肉芽 | 成纤维细胞产纤维和基质，毛细血管长入 |
| ⑤ 表皮覆盖 | 创缘角质形成细胞移行；残存毛囊、汗腺导管形成上皮小岛 |
| ⑥ 分层重建 | 新生表皮基底细胞增生分化，形成各层 |
| ⑦ 转归 | 浅表小创不留瘢痕；深大创肉芽 → 瘢痕；过大过深需植皮 |

易错点：把“皮肤都能再生”写成无条件、不需要植皮；把所有愈合都写成必定留疤；把肉芽组织写成化脓或直接等于瘢痕；漏写上皮小岛来自残存毛囊和汗腺导管；把基底层干细胞和附属器干细胞并丢，导致无法解释深创表皮从哪来。
