**题目**：骨骼肌、心肌、平滑肌在细胞形态、核的数目与位置、有无横纹、有无肌原纤维和肌节上如何对照？T 管或相当结构落在哪、与终池组成三联体还是二联体、平滑肌用什么代替？谁有闰盘、闰盘横纵各是什么连接、平滑肌纤维之间靠什么同步？谁是随意肌、神经支配有何不同？再生能力怎样分？为什么对照时不能只背「有没有横纹」，也不能把「横纹肌 = 骨骼肌、平滑肌 = 没有肌丝」两句话打发三种肌？

**解**：
教材 definition：**根据结构和功能特点，肌组织分为骨骼肌、心肌和平滑肌 3 种。前两种因有横纹，属横纹肌。骨骼肌受躯体神经支配，属随意肌；心肌和平滑肌受自主神经支配，为不随意肌。** 教材 pitfall：**三种肌对照时不要只背「有没有横纹」。** 横纹只回答光镜下明暗带齐不齐。核的位置和数目、T 管落点、三联体还是二联体、有没有闰盘、是不是随意肌，是五本不同的账。平滑肌无横纹也无闰盘，但有缝隙连接；心肌有横纹又有闰盘；骨骼肌有横纹无闰盘。把「横纹肌 = 骨骼肌、平滑肌 = 没有肌丝」两句话打发三种肌，切片上心肌和平滑肌会互相认错。

光镜先问形状和核：长圆柱、周边一圈扁核、明显横纹、无闰盘 → 骨骼肌；短圆柱有分支成网、中央卵圆核、横纹较浅、纵切有深染闰盘 → 心肌；长梭形、中央一个常扭曲的杆状核、无横纹 → 平滑肌。超微再问膜偶联：骨骼肌 T 管在 A–I 交界、两侧终池成三联体，钙主要来自肌质网（网内浓度为肌质的上千倍）；心肌 T 管较粗、在 Z 线水平、多见二联体，贮钙低、需细胞外 $\mathrm{Ca}^{2+}$；平滑肌以沿长轴带状排列的小凹相当 T 管，肌质网少，同样需细胞外钙。

肌丝组织也不一样：骨骼肌和心肌都有粗、细肌丝和肌节，骨骼肌肌原纤维界限清楚，心肌肌原纤维粗细不等、界限不很分明、线粒体极为丰富。平滑肌无肌原纤维、无肌节，但有收缩单位，粗细丝数量比约 $1:12$，细丝钉在密斑或密体上。闰盘是心肌特有：横向黏着小带 + 桥粒机械锚定，纵向缝隙连接电偶联，使心房肌、心室肌各自整体同步。平滑肌没有闰盘，但纤维间有发达缝隙连接，管壁才能形成一圈协调的张力。

再生账三套：骨骼肌靠肌卫星细胞增殖分化参与修复；心肌一般无再生，损伤由瘢痕代替；平滑肌可肥大，如妊娠子宫平滑肌纤维可长达 $500\,\mu\mathrm{m}$。

| 项目 | 骨骼肌 | 心肌 | 平滑肌 |
|------|--------|------|--------|
| 细胞形态 | 长圆柱状，极少分支 | 不规则短圆柱状，有分支，成网 | 长梭形 |
| 核 | 多核（几十至几百），扁椭圆，肌膜下 | 1 个或 2 个，卵圆，细胞中央 | 1 个，杆状或椭圆，中央，常扭曲 |
| 横纹 | 明显 | 有，较不明显 | 无 |
| 肌原纤维 / 肌节 | 有，界限清楚；肌节为基本单位 | 有，粗细不等、界限不清；亦有肌节 | 无肌原纤维、无肌节；有收缩单位 |
| 粗、细肌丝 | 有（细丝约 $1\,\mu\mathrm{m}$、$5\,\mathrm{nm}$；粗丝约 $1.5\,\mu\mathrm{m}$、$15\,\mathrm{nm}$） | 有，类型和排列同骨骼肌 | 有；数量比约 $1:12$ |
| T 管 / 相当结构 | 横小管在 A–I 交界 | 横小管较粗，在 Z 线水平 | 小凹沿长轴呈带状，相当 T 管 |
| 肌质网偶联 | 三联体（T 管 + 两侧终池） | 二联体（T 管 + 一侧终池） | 肌质网少；需细胞外钙 |
| 闰盘 | 无 | 有（横：黏着小带、桥粒；纵：缝隙连接） | 无闰盘；纤维间有发达缝隙连接 |
| 随意性 | 随意（躯体神经） | 不随意（自主神经），有自动节律性 | 不随意（自主神经） |
| 再生 | 肌卫星细胞可修复 | 一般无再生，瘢痕代替 | 可肥大（如妊娠子宫） |

易错点：把横纹肌写成骨骼肌的别名；把心肌核写成周边多核；把平滑肌写成没有肌丝；把 T 管落点和三联体/二联体写串；给平滑肌画闰盘，或把缝隙连接听成闰盘的全部；三种肌的再生写成同一句话。
