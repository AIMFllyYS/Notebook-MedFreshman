**题目**：气管与主支气管属于哪一部、管壁由内向外分哪 3 层、有没有黏膜肌层？黏膜上皮是什么、由哪 5 种细胞组成？纤毛细胞最多干什么、慢性支气管炎先打在谁身上？杯状细胞和气管腺如何构成黏液性屏障？刷细胞游离面是纤毛还是微绒毛？小颗粒细胞和基细胞各干什么？固有层如何分泌 sIgA？黏膜下层有什么腺？外膜含多少个什么样的软骨环、缺口处膜性部有什么、咳嗽时平滑肌干什么？主支气管软骨和平滑肌如何移行？为什么看见气管切片要先数三层、再认 C 形软骨缺口朝哪，而不能套消化管四层？

**解**：
教材 definition：**气管与主支气管是肺外的气体通道，属于导气部。** 管壁结构相似，由内向外依次为黏膜、黏膜下层和外膜 3 层。教材 concept：**先数三层，再认 C 形软骨缺口朝哪。** 看见气管切片，先把消化管那本四层账放下：这里没有黏膜肌层，黏膜只有上皮和固有层。教材 pitfall：**气管是黏膜、黏膜下层、外膜三层，不要套消化管四层。** 外膜的主角是 C 字形透明软骨环，不是浆膜或单纯纤维膜。硬套四层，气管腺会找不到黏膜下层，膜性部平滑肌也会被算进“肌层”。

教材 definition：**黏膜由上皮和固有层组成。** 上皮为假复层纤毛柱状上皮，由纤毛细胞、杯状细胞、刷细胞、基细胞和小颗粒细胞组成。光镜下上皮与固有层之间基膜明显。教材 definition：**纤毛细胞（ciliated cell）是气管上皮中数量最多的细胞，呈柱状，游离面有密集的纤毛。** 纤毛向咽部快速摆动，将黏液及其黏附的尘埃、细菌等推向咽部咳出。教材 pitfall：**慢性支气管炎先打在纤毛上，不要只写成“腺体分泌多了”。** 慢性支气管炎会导致纤毛变短、粘连、倒伏和脱失。黏液还在，传送带断了，痰才积下来。教材 definition：**杯状细胞较多。** 分泌的黏蛋白与混合腺分泌物在上皮表面构成黏液性屏障，可黏附空气中的异物颗粒，溶解吸入的 $\mathrm{SO}_{2}$ 等有毒气体。

教材 definition：**刷细胞（brush cell）较少，呈柱状，游离面有排列整齐的微绒毛，形如刷状。** 功能尚未定论；有报道基部与感觉神经末梢形成突触，故可能有感受刺激的作用。教材 pitfall：**刷细胞游离面是微绒毛，不要看成纤毛细胞。** 教材 definition：**小颗粒细胞（small granule cell）较少，呈锥形，单个或成团分布在上皮深部。** 胞质内有许多分泌颗粒，含 5-羟色胺等物质，可调节呼吸道平滑肌的收缩和腺体的分泌，是一种弥散的神经内分泌细胞。教材 definition：**基细胞呈锥形，位于上皮深部，为干细胞，可增殖分化为上皮中其他各类细胞。** 固有层结缔组织中有较多弹性纤维，也常见淋巴组织。教材 definition：**固有层中的浆细胞与上皮细胞联合分泌 sIgA，释放入管腔，可杀灭细菌、病毒。** 抗体不是杯状细胞的黏蛋白，也不来自软骨细胞。教材 insight：**黏液-纤毛和 sIgA 是同一条管腔里的两道防线。**

教材 definition：**黏膜下层为疏松结缔组织，与固有层和外膜无明显界限，其内有较多混合腺，也称气管腺。** 教材 definition：**外膜较厚，主要含 $16\sim 20$ 个 C 字形透明软骨环。** 软骨环之间以弹性纤维构成的膜状韧带连接，共同构成管壁的支架。教材 definition：**气管外膜的支架是 $16\sim 20$ 个 C 字形透明软骨环，不是完整的圆环形软骨。** 缺口朝向膜性部，才能给食管留扩张的空间，并让平滑肌改变管径。教材 definition：**软骨环的缺口处为气管膜性部，内有弹性纤维组成的韧带、平滑肌束和气管腺。** 咳嗽时平滑肌收缩，使气管腔缩小，有助清除痰液。教材 definition：**主支气管壁随着管腔变小，管壁变薄，3 层分界不明显；环状软骨逐渐变为不规则的软骨片，而平滑肌纤维逐渐增多，呈螺旋形排列。** 这是后文肺内支气管“软骨减少、平滑肌增多”的起点。教材 insight：**C 形环把“硬支架”和“可缩小的缺口”写在同一圈外膜里。**

| 层次（内→外） | 组织 | 要点 |
|----------------|------|------|
| 黏膜 | 假复层纤毛柱状上皮 + 固有层 | 无黏膜肌层；基膜明显；固有层弹性纤维多，常见淋巴组织 |
| 黏膜下层 | 疏松结缔组织 | 与固有层和外膜无明显界限；较多混合腺（气管腺） |
| 外膜 | 较厚；主要含 $16\sim 20$ 个 C 字形透明软骨环 | 软骨环之间以弹性纤维膜状韧带连接；缺口为膜性部 |

| 细胞 | 数量与形态 | 游离面 / 位置 | 职分 |
|------|------------|---------------|------|
| 纤毛细胞 | 最多，柱状 | 密集纤毛，向咽部摆动 | 清扫黏液和异物；慢性支气管炎时变短、粘连、倒伏、脱失 |
| 杯状细胞 | 较多 | 分泌黏蛋白 | 与气管腺共同构成黏液性屏障，黏附异物，溶解 $\mathrm{SO}_{2}$ 等 |
| 刷细胞 | 较少，柱状 | 排列整齐的微绒毛，形如刷状 | 功能未定论；可能感受刺激 |
| 小颗粒细胞 | 较少，锥形 | 上皮深部，单个或成团 | 含 5-羟色胺等，调节平滑肌和腺体；弥散神经内分泌细胞 |
| 基细胞 | 锥形 | 上皮深部 | 干细胞，增殖分化为其他各类细胞 |

易错点：把气管硬套消化管四层、给它加上黏膜肌；把 C 形环写成完整圆环或弹性软骨；把膜性部平滑肌算进“肌层”；把刷细胞看成纤毛细胞；把慢性支气管炎只写成腺体增生、漏掉纤毛倒伏脱失；把 sIgA 写成杯状细胞的黏蛋白。
