**题目**：肺表面被覆什么、实质和间质如何分？肺小叶由什么组成、呈什么形态、底部轮廓直径大约多少、每叶大约多少个、累及若干肺小叶的炎症称什么？肺泡管和肺泡囊如何用结节状膨大鉴别？肺泡管相邻开口之间深部有什么、肺泡囊为何没有小结？肺的血液供应来自哪两套动脉、谁是功能血管、谁是营养血管、各是弹性动脉还是肌性动脉、毛细血管网分别铺在哪？为什么不能把所有“一串肺泡”都写成肺泡管，也不能把支气管动脉写成也在肺泡换气？

**解**：
教材 definition：**肺表面被覆浆膜（胸膜脏层）。** 肺组织分实质和间质两部分。实质即肺内支气管的各级分支及其终末的大量肺泡；间质包括结缔组织、血管、淋巴管和神经。教材 definition：**每一细支气管连同它的各级分支和肺泡，组成一个肺小叶（pulmonary lobule）。** 肺小叶呈锥形，尖朝向肺门，底向肺表面，小叶之间有结缔组织间隔；肺表面可见肺小叶底部轮廓，直径 $1\sim 2.5\,\mathrm{cm}$。每叶肺有 $50\sim 80$ 个肺小叶，是肺的结构单位。教材 definition：**临床上常见累及若干肺小叶的炎症，称小叶性肺炎。** 结构单位是细支气管所辖的那一锥，不是“一叶肺”。

肺呼吸部包括呼吸性细支气管、肺泡管、肺泡囊和肺泡。呼吸性细支气管管壁出现少量肺泡，上皮单层立方，肺泡开口处改单层扁平。教材 definition：**肺泡管（alveolar duct）为支气管树第 $20\sim 22$ 级。** 管壁上有许多肺泡，自身管壁结构很少。相邻肺泡开口之间有结节状膨大：表面覆单层立方或扁平上皮，深部有弹性纤维和环行平滑肌束。教材 definition：**肺泡囊（alveolar sac）为支气管树第 23 级，实为若干肺泡的共同开口处。** 相邻肺泡开口之间无平滑肌，故无结节状膨大。教材 pitfall：**肺泡囊没有结节状膨大，不要按肺泡管的平滑肌小结来认。** 切片上相邻肺泡开口之间若有结节状膨大，那是肺泡管还剩的那点管壁。把所有“一串肺泡”都写成肺泡管，平滑肌账会多算一级。

教材 definition：**肺的血液供应来自肺动脉和支气管动脉。** 教材 definition：**肺动脉是肺的功能血管，管径较粗，为弹性动脉。** 从右心室发出，至肺门入肺，分支与各级支气管伴行直至肺泡隔内形成毛细血管网；气体交换后汇入小静脉，最终汇合成肺静脉出肺门回到左心房。教材 definition：**支气管动脉是肺的营养血管，管径细，为肌性动脉。** 发自胸主动脉或肋间动脉，与支气管伴行入肺，沿途在导气部各段管壁内分支形成毛细血管网，营养管壁组织。教材 pitfall：**支气管动脉养的是导气部管壁，不要写成“也在肺泡换气”。** 肺泡隔里与Ⅰ型细胞面对面的毛细血管网来自肺动脉。把两套动脉写成“都是肺的血供，都会换气”，功能血管和营养血管会并成一句。

| 项目 | 肺泡管 | 肺泡囊 |
|------|--------|--------|
| 分级 | 第 $20\sim 22$ 级 | 第 23 级 |
| 肺泡开口 | 许多 | 若干肺泡的共同开口 |
| 自身管壁 | 很少 | 几乎只剩开口 |
| 结节状膨大 | 有（深部弹性纤维 + 环行平滑肌束） | 无（相邻开口之间无平滑肌） |

| 项目 | 肺动脉 | 支气管动脉 |
|------|--------|------------|
| 职分 | 功能血管（来进行气体交换的血） | 营养血管（养管壁） |
| 管径 / 类型 | 较粗，弹性动脉 | 细，肌性动脉 |
| 起点 | 右心室 | 胸主动脉或肋间动脉 |
| 走行 | 与各级支气管伴行至肺泡隔毛细血管网 | 与支气管伴行，在导气部管壁内成网 |
| 终点 | 气体交换后经肺静脉回左心房 | 营养导气部各段管壁组织 |

| 肺小叶要点 | 内容 |
|------------|------|
| 组成 | 一细支气管 + 其各级分支和肺泡 |
| 形态 | 锥形，尖朝肺门，底向肺表面 |
| 底部轮廓 | 直径 $1\sim 2.5\,\mathrm{cm}$；每叶 $50\sim 80$ 个 |
| 临床 | 累及若干肺小叶的炎症称小叶性肺炎 |

易错点：把肺小叶写成“一叶肺”；把肺泡管和肺泡囊都按结节状膨大来认；把支气管动脉写成也在肺泡换气；把肺动脉听成营养血管、支气管动脉听成功能血管；把弹性动脉和肌性动脉写反；漏写肺泡隔毛细血管网来自肺动脉。
