**题目**：肺泡隔是什么、隔内有哪些结构、弹性纤维干什么、老人和吸烟者弹性纤维退化会走向什么？气–血屏障是什么、从肺泡腔到血液依次包括哪几层、有的部位两层基膜如何？此结构总厚度多少、为何有利于气体迅速交换？临床上急慢性炎症如何影响换气？为什么不能把气–血屏障写成整层肺泡隔，也不能把隔内的尘细胞和弹性纤维当成换气结构？

**解**：
教材 definition：**相邻肺泡之间的薄层结缔组织称肺泡隔。** 隔内有密集的连续毛细血管和丰富的弹性纤维，还有成纤维细胞、肺巨噬细胞、肥大细胞、毛细淋巴管和神经纤维。教材 definition：**肺泡隔内有丰富的弹性纤维，起回缩肺泡的作用。** 老年人弹性纤维退化，吸烟可加速退化进程。弹性降低后回缩较差，呼气时肺内残留气体增加，久之肺泡扩大形成肺气肿。教材 insight：**回缩肺泡的是隔里的弹性纤维，不是Ⅱ型细胞把气挤出去。** 表面活性物质管的是表面张力，弹性纤维管的是组织回缩。把回缩听成“平滑肌收缩”，肺泡隔里并没有一整圈能排空肺泡的肌层。

教材 definition：**气–血屏障（blood-air barrier）是肺泡腔内氧气与肺泡隔毛细血管中的二氧化碳进行气体交换所通过的结构。** 组成：肺泡表面液体层、Ⅰ型肺泡细胞与基膜、薄层结缔组织、毛细血管基膜与连续内皮。有的部位两层基膜间无结缔组织，两层基膜融合。总厚度 $0.2\sim 0.5\,\mu\mathrm{m}$。教材 pitfall：**气–血屏障不是整层肺泡隔。** 肺泡隔里还有弹性纤维、成纤维细胞、肺巨噬细胞、肥大细胞、毛细淋巴管和神经纤维。气体并不穿过这整本隔，只走最薄的那条路径：液体层 → Ⅰ型细胞及基膜 →（可缺如的薄层结缔组织）→ 连续毛细血管内皮及基膜，总厚度仅 $0.2\sim 0.5\,\mu\mathrm{m}$。把气–血屏障写成“整个肺泡隔”，隔内的尘细胞和弹性纤维会被误当成换气结构。

气–血屏障走的是连续毛细血管，不是有孔毛细血管或血窦。上皮主体是Ⅰ型肺泡细胞，不是Ⅱ型。Ⅰ型胞质本身就大约 $0.2\,\mu\mathrm{m}$，再加上液体层、基膜和内皮，整条路径仍只有 $0.2\sim 0.5\,\mu\mathrm{m}$。教材 insight：**炎症渗出只要把这 $0.2\sim 0.5\,\mu\mathrm{m}$ 加厚，换气就先垮。** 屏障能工作，是因为它薄。炎性细胞浸润、渗出或增生都会把路径加厚，氧气来不及过。临床气体交换障碍，组织学落点往往就在这几层被抬厚，而不必先毁掉整棵支气管树。

| 顺序（肺泡腔 → 血液） | 结构 |
|------------------------|------|
| 1 | 肺泡表面液体层 |
| 2 | Ⅰ型肺泡细胞与其基膜 |
| 3 | 薄层结缔组织（有的部位缺如，两层基膜融合） |
| 4 | 毛细血管基膜与连续内皮 |
| 总厚度 | $0.2\sim 0.5\,\mu\mathrm{m}$ |

| 结构 | 在不在气–血屏障里 | 职分 |
|------|--------------------|------|
| 肺泡表面液体层 + Ⅰ型细胞及基膜 + 连续内皮及基膜 | 在 | 气体交换的最短路径 |
| 肺泡隔弹性纤维 | 不在 | 回缩肺泡；退化 → 肺气肿 |
| 肺巨噬细胞 / 尘细胞 | 不在 | 吞噬尘粒和细菌 |
| 成纤维细胞、肥大细胞、毛细淋巴管、神经纤维 | 不在 | 间质成分，不是换气膜 |

易错点：把气–血屏障写成整层肺泡隔；把厚度听成肺泡隔全厚或肺泡直径 $200\,\mu\mathrm{m}$；把Ⅱ型细胞写进屏障上皮；把连续毛细血管写成有孔或血窦；把弹性纤维、尘细胞当成换气结构；漏写有的部位两层基膜融合；把炎症换气障碍只写成“支气管堵住了”。
