:::example{label="滤泡上皮如何把胶质写成碘化甲状腺球蛋白的细胞外贮存"}
**题目**：甲状腺分哪两叶、中间以什么相连、实质由什么组成、滤泡间有什么血管？滤泡直径大约多少、由什么上皮围成、腔内均质嗜酸性物质叫什么、本质是什么？滤泡上皮功能活跃和低下时形态与胶质如何对改？甲状腺激素形成经过哪六步，$\mathrm{T}_3$、$\mathrm{T}_4$ 从哪一面入血？为什么甲状腺是少数把半成品贮在细胞外的内分泌腺，而不能把胶质听成废料，也不能把 $\mathrm{T}_3$、$\mathrm{T}_4$ 写成向滤泡腔分泌？

**解**：
教材 definition：**甲状腺（thyroid gland）分左右两叶，中间以峡部相连。** 表面包薄层结缔组织被膜。实质由大量甲状腺滤泡组成，滤泡间有少量疏松结缔组织和丰富的有孔毛细血管。教材 concept：**先问这是滤泡上皮、胶质，还是滤泡旁细胞。** 第一眼是大小不等的滤泡：单层上皮围一腔嗜酸胶质。三本账不要并成“滤泡里的细胞”。

教材 definition：**甲状腺滤泡大小不等，直径 $0.02\sim 0.9\,\mathrm{mm}$，呈圆形或不规则形。** 由单层立方的滤泡上皮细胞围成，腔内充满均质状、嗜酸性的胶质。教材 definition：**胶质即滤泡上皮细胞的分泌物——碘化的甲状腺球蛋白，是甲状腺激素尚未水解入血之前的细胞外贮存形式。** 功能活跃时上皮增高呈低柱状、腔内胶质减少；功能低下时上皮变矮呈扁平状、腔内胶质增多。教材 pitfall：**扁平滤泡上皮不是内皮，也不要当成滤泡旁细胞。** 围的仍是胶质腔，基底面有完整基膜。

电镜下滤泡上皮属含氮激素分泌细胞：较丰富粗面内质网、较多线粒体、散在溶酶体、核上区高尔基复合体。顶部有电子密度中等、体积很小的分泌颗粒（把甲状腺球蛋白前体排入滤泡腔），还有从滤泡腔摄入的低电子密度胶质小泡。基底面有完整基膜。

教材 note：**甲状腺激素形成经过合成、贮存、碘化、重吸收、分解和释放。** 摄取氨基酸 → 粗面内质网造甲状腺球蛋白前体 → 高尔基加糖浓缩为分泌颗粒 → 胞吐入滤泡腔贮存。从血中摄取 $\mathrm{I}^{-}$，经过氧化物酶活化，入滤泡腔与甲状腺球蛋白结合，形成碘化甲状腺球蛋白。碘化发生在滤泡腔内，不是在粗面内质网里。在腺垂体 TSH 作用下胞吞碘化甲状腺球蛋白成为胶质小泡，与溶酶体融合后水解，形成大量四碘甲腺原氨酸（$\mathrm{T}_4$，甲状腺素）和少量三碘甲腺原氨酸（$\mathrm{T}_3$），于滤泡上皮基底部释放入血。

教材 insight：**蛋白质类激素通常先装进分泌颗粒再胞吐入血；滤泡上皮却把甲状腺球蛋白先吐到滤泡腔碘化贮存，等 TSH 下令再吞回来水解。** 所以光镜下那团嗜酸胶质不是废料，是激素仓库。甲亢时胶质减少、功能低下时胶质增多，两眼才能对上。教材 pitfall：**$\mathrm{T}_3$、$\mathrm{T}_4$ 从基底面入血，不要写成向滤泡腔分泌甲状腺素。** 向腔面吐的是甲状腺球蛋白（贮存），向基底面放的才是成品激素。方向写反，会把胶质当成成品，也会把滤泡腔误写成“内分泌导管”。

甲状腺激素促进新陈代谢、提高神经兴奋性、促进生长发育；对婴幼儿骨骼和中枢神经系统发育影响显著。小儿甲状腺功能减退：长骨生长停滞、身材矮小，同时脑发育障碍、智力低下，即呆小病（cretinism）。成人甲亢则以中枢兴奋性增高和心血管、消化等功能紊乱为主。教材 pitfall：**呆小病是小儿甲减，不要写成缺钙或生长激素不足。** 缺钙写甲状旁腺 / 降钙素；GH 不足写垂体性侏儒，智力通常不受同样方式的打击。

| 步骤 | 落点 |
|------|------|
| 合成 | 氨基酸 → 粗面内质网造前体 → 高尔基加糖浓缩 → 分泌颗粒 |
| 贮存 | 胞吐入滤泡腔，以胶质形式存放 |
| 碘化 | $\mathrm{I}^{-}$ 经过氧化酶活化，入腔与甲状腺球蛋白结合 |
| 重吸收 | TSH 作用下胞吞，成胶质小泡 |
| 分解 | 胶质小泡与溶酶体融合，切出大量 $\mathrm{T}_4$、少量 $\mathrm{T}_3$ |
| 释放 | 从上皮基底部入有孔毛细血管 |

| 项目 | 分泌颗粒 | 胶质小泡 |
|------|----------|----------|
| 电子密度 | 中等 | 低 |
| 方向 | 出细胞：前体排入滤泡腔 | 进细胞：碘化甲状腺球蛋白从腔内重吸收 |
| 下一步 | 在腔内碘化、贮存 | 与溶酶体融合，水解出 $\mathrm{T}_3$、$\mathrm{T}_4$ |

易错点：把胶质听成可有可无的管腔内容物；把碘化写到粗面内质网里；把 $\mathrm{T}_3$、$\mathrm{T}_4$ 写成向滤泡腔分泌；把扁平滤泡上皮当成内皮或滤泡旁细胞；把呆小病写成缺钙或 GH 不足。
