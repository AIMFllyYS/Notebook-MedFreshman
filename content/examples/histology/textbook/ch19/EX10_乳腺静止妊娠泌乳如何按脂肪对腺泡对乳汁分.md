**题目**：乳腺主要功能是分泌乳汁、哺育婴儿，属不属于女性生殖器官？结缔组织将乳腺分成大约多少个叶、每个小叶属一种什么腺？腺泡上皮是什么、腺上皮与基膜之间有什么细胞？小叶内导管、小叶间导管和输乳管的上皮各是什么？静止期乳腺导管和腺体发不发达、腺泡多少、脂肪和结缔组织如何、经前有没有轻度增生充血？妊娠期在哪些激素作用下小导管和腺泡迅速增生、后期哪种激素启动分泌、乳腺是顶浆、局浆还是全浆分泌？初乳与规律性泌乳相比脂肪和蛋白质、抗体如何、初乳小体是什么细胞？哺乳期结缔组织更少还是更多、腺腔是否充满乳汁、上皮可呈高柱状到什么形状？停止哺乳后如何复旧？为什么不能把腺泡写成卵泡或子宫腺，也不能把妊娠期直接写成腺腔胀满乳汁的哺乳期切面，更不能把初乳小体当成脱落腺细胞？

**解**：
教材 definition：**乳腺主要功能是分泌乳汁、哺育婴儿，不属于女性生殖器官。** 因与卵巢激素联动发育并在妊娠、哺乳期泌乳，教材列入本章。教材 concept：**先问此刻有没有泌乳，再问切面是脂肪多还是腺泡多。** 没有泌乳是静止期，妊娠和哺乳才是活动期。把三种状态听成“同一种复管泡状腺切面”，初乳小体和顶浆分泌会从静止期里凭空冒出来。

结缔组织将乳腺分成 $15\sim 25$ 个叶，每叶再分若干小叶，每个小叶属一个复管泡状腺。腺泡上皮为单层立方或柱状，腺腔很小；腺细胞基底面有基膜，腺上皮与基膜之间有肌上皮细胞，收缩有助于把乳汁挤入导管。小叶内导管多为单层立方或柱状上皮；小叶间导管为复层柱状上皮；总导管又称输乳管，开口于乳头，上皮与乳头表皮相续，为复层扁平上皮。

教材 definition：**静止期乳腺指绝经前没有分泌功能的乳腺。导管和腺体均不发达，腺泡小而少，脂肪组织和结缔组织极为丰富。** 随月经周期可有轻度变化：经前腺泡与导管增生充血，乳腺可略增大；经后消失。这只是轻度波动，并不等于进入活动期。教材 pitfall：**静止期不是没有腺，只是腺泡小而少、脂肪特别多。** 写成“静止期完全没有腺体”，和妊娠期的对照就失去起点。

妊娠期和哺乳期合称活动期乳腺。妊娠期在雌激素和孕激素作用下，小导管和腺泡迅速增生，腺泡增大，结缔组织和脂肪相应减少。妊娠后期催乳素使腺泡开始分泌。乳腺为顶浆分泌腺。第一次分泌给新生儿的乳汁叫初乳（colostrum），含少量脂肪和多量蛋白质，富含抗体；初乳中常含吞噬脂滴的巨噬细胞，称为初乳小体（colostrum corpuscle）。教材 pitfall：**初乳小体是巨噬细胞，不是脱落的腺上皮细胞，也不是脂肪细胞本身。**

哺乳期与妊娠期相似，但结缔组织更少，腺体更发达，腺泡腔增大，可处于不同分泌时期。腺上皮可呈高柱状、立方形甚至扁平状，腺腔内充满乳汁。电镜下 RER、线粒体丰富，可见分泌颗粒和脂滴。教材 pitfall：**妊娠期已经开始长腺体，哺乳期才是腺腔充满乳汁的高峰。** 把妊娠期直接写成胀满腺泡，时间轴会提前一截。停止哺乳后腺体停止分泌并萎缩，结缔组织增多，回到静止期。教材 pitfall：**乳腺不属于生殖器官，不要把腺泡写成卵泡或子宫腺。** 卵泡在卵巢皮质，子宫腺在内膜固有层，乳腺腺泡是复管泡状腺的分泌部。

| 项目 | 静止期 | 妊娠期 | 哺乳期（泌乳期） |
|------|--------|--------|------------------|
| 是否活动期 | 否 | 是 | 是 |
| 激素 | 随月经周期轻度波动 | 雌激素 + 孕激素促增生；后期催乳素启动分泌 | 催乳素维持泌乳 |
| 腺泡 / 导管 | 不发达，腺泡小而少 | 小导管和腺泡迅速增生、腺泡增大 | 腺体更好，腺腔更大，可处于不同分泌时相 |
| 脂肪 / 结缔组织 | 极为丰富 | 相应减少 | 更少 |
| 分泌 | 无泌乳 | 后期开始；第一次为初乳 | 腔内充满乳汁；顶浆分泌 |
| 特殊结构 | 经前可轻度增生充血 | 初乳、初乳小体 | 电镜见 RER、线粒体、分泌颗粒和脂滴 |

| 导管 | 上皮 |
|------|------|
| 小叶内导管 | 单层立方或柱状 |
| 小叶间导管 | 复层柱状 |
| 输乳管（总导管） | 复层扁平，与乳头表皮相续 |

易错点：把乳腺写成生殖器官；把腺泡听成卵泡或子宫腺；把静止期写成完全没有腺体；把妊娠期直接写成哺乳期那种胀满腺泡；把初乳小体当成脱落腺细胞或凝固体；把顶浆分泌写成全浆或单纯局浆；把三级导管上皮写反；漏写断乳后复旧为静止期。
