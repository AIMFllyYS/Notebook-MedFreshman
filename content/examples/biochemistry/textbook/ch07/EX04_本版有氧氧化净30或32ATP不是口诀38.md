**题目**：一轮三羧酸循环几步，几次脱氢、几次脱羧、几次底物水平磷酸化，大量 $\mathrm{ATP}$ 来自循环里那一次底物水平磷酸化还是还原当量走电子传递链？$3\,\mathrm{NADH}$ 和 $1\,\mathrm{FADH}_2$ 在本版各按多少分子 $\mathrm{ATP}$ 计，加上底物水平磷酸化后一分子乙酰 $\mathrm{CoA}$ 是多少？从丙酮酸脱氢算起一分子丙酮酸是多少，两分子丙酮酸呢？细胞质甘油醛-3-磷酸脱氢产生的 $\mathrm{NADH}$ 怎样进线粒体，两种穿梭分别给 $2.5$ 还是 $1.5$，两分子就是 $+5$ 还是 $+3$？表7-1 把 $1\,\mathrm{mol}$ 葡萄糖净得写成多少？释出的 $2$ 个 $\mathrm{CO}_2$ 碳原子来自当轮乙酰 $\mathrm{CoA}$ 还是草酰乙酸？巴斯德效应和瓦尔堡效应差在哪一句？为什么本版不是口诀 $36/38$，也不能把瓦尔堡听成“肿瘤细胞缺氧所以酵解”？

**解**：
教材 keypoint：**一轮三羧酸循环先记四句话：$2$ 次脱羧 → $2\,\mathrm{CO}_2$；$1$ 次底物水平磷酸化 → $1\,\mathrm{GTP}$（或 $\mathrm{ATP}$）；$4$ 次脱氢 → $3\,\mathrm{NADH}+\mathrm{H}^{+}$ ＋ $1\,\mathrm{FADH}_2$；大量 $\mathrm{ATP}$ 来自这些还原当量走电子传递链，不是循环里那一次底物水平磷酸化。** 三个关键酶：柠檬酸合酶、异柠檬酸脱氢酶、$\alpha$-酮戊二酸脱氢酶复合体。琥珀酸脱氢酶结合在线粒体内膜，辅因子为 $\mathrm{FAD}$。

教材 derivation：**$1$ 分子乙酰 $\mathrm{CoA}\rightarrow 10$ 分子 $\mathrm{ATP}$。** 线粒体内每分子 $\mathrm{NADH}$ 的氢传递给氧生成 $2.5$ 分子 $\mathrm{ATP}$，每分子 $\mathrm{FADH}_2$ 生成 $1.5$ 分子 $\mathrm{ATP}$。$3\times 2.5=7.5$，$1\times 1.5=1.5$，加底物水平磷酸化 $1$，合计 $10$。

教材 derivation：**$1$ 分子丙酮酸 $\rightarrow 12.5$ 分子 $\mathrm{ATP}$。** 丙酮酸脱氢酶复合体 $1\,\mathrm{NADH}\times 2.5=2.5$，加上乙酰 $\mathrm{CoA}$ 经三羧酸循环 $10$，合计 $12.5$。两分子丙酮酸即 $25$。

教材 pitfall：**本版是 $30$ 或 $32$，不要默写成 $36$ 或 $38$。** 糖酵解在细胞质生成的 $\mathrm{NADH}$，氧充足时要转运入线粒体。将 $\mathrm{NADH}$ 从细胞质运到线粒体的机制有两种，分别产生 $2.5$ 分子或者 $1.5$ 分子 $\mathrm{ATP}$（见第十章）。两分子就是 $+5$ 或 $+3$，所以净得 $32$ 或 $30$。旧账按 $\mathrm{NADH}=3$、$\mathrm{FADH}_2=2$ 加出 $36/38$，与本版表7-1 对不上。

表7-1 加总：底物水平净 $4$（酵解净 $2$＋琥珀酰 $\mathrm{CoA}$ 合成酶 $2$）；线粒体 $\mathrm{NADH}$ $8\times 2.5=20$；$\mathrm{FADH}_2$ $2\times 1.5=3$；细胞质 $\mathrm{NADH}$ $3$ 或 $5$。$4+20+3+(3\text{ 或 }5)=30$ 或 $32$。

教材 pitfall：**释出的 $2$ 个 $\mathrm{CO}_2$ 碳原子来自草酰乙酸，不是当轮乙酰 $\mathrm{CoA}$。** 碳数账是平的，同位素账不平。中间产物不能靠循环从乙酰 $\mathrm{CoA}$ 净合成；要补草酰乙酸，主要靠丙酮酸羧化。

教材 definition：**巴斯德效应指糖有氧氧化抑制无氧氧化。** 肌组织也有，以便有氧时产能最大化。机制：细胞质 $\mathrm{NADH}$ 的去路决定丙酮酸去向——有氧则 $\mathrm{NADH}$ 和丙酮酸都进线粒体；缺氧则 $\mathrm{NADH}$ 留在细胞质还原丙酮酸成乳酸。教材 definition：**瓦尔堡效应指肿瘤等快速增殖的细胞即使在有氧时也不把葡萄糖彻底氧化，而是生成乳酸。** 教材 pitfall：**瓦尔堡效应不是“肿瘤细胞缺氧所以酵解”。** 产能少导致 $\mathrm{ATP}/\mathrm{AMP}$ 偏低，激活 $\mathrm{PFK}$-$1$ 和丙酮酸激酶，糖消耗显著多于有氧氧化，留下碳骨架作合成原料。

| 本版当量 | 数字 |
|----------|------|
| 线粒体 $\mathrm{NADH}$ | $2.5\,\mathrm{ATP}$ |
| $\mathrm{FADH}_2$ | $1.5\,\mathrm{ATP}$ |
| 乙酰 $\mathrm{CoA}$ | $10\,\mathrm{ATP}$ |
| 丙酮酸 | $12.5\,\mathrm{ATP}$ |
| 葡萄糖净得 | $30$ 或 $32\,\mathrm{ATP}$（看胞质 $\mathrm{NADH}$ 穿梭） |
| 不要写 | $36$ 或 $38$ |

易错点：用口诀 $3$ 和 $2$ 加成 $36/38$；把循环里那一次底物水平磷酸化当成主要产能；把 $2$ 个 $\mathrm{CO}_2$ 写成当轮乙酰 $\mathrm{CoA}$ 的碳；把瓦尔堡并成巴斯德（缺氧）；漏掉胞质 $\mathrm{NADH}$ 两种穿梭才出现 $30$ 或 $32$。
