**题目**：$1$ 分子软脂酸（$16$ 碳）彻底氧化要几次 β-氧化、生成几分子 $\mathrm{FADH}_2$、$\mathrm{NADH}$、乙酰 $\mathrm{CoA}$？本版标准条件下每分子 $\mathrm{FADH}_2$、$\mathrm{NADH}$、乙酰 $\mathrm{CoA}$ 各按多少分子 $\mathrm{ATP}$ 计，毛产额怎样加成，活化为什么减 $2$ 而不是减 $1$，净得多少？第七章葡萄糖有氧氧化净 $30$ 或 $32$ 用的是不是同一套 $2.5$／$1.5$／$10$？旧口诀按 $3$ 和 $2$ 加成毛产 $131$ 再减 $2$ 得 $129$，和本版哪一笔对不上？第一节 $1\,\mathrm{g}$ 甘油三酯 $38\,\mathrm{kJ}$ 能不能拿来当软脂酸净 $\mathrm{ATP}$，葡萄糖口诀 $38$ 能不能串过来？活化减 $2$ 与碳链长度有没有关系？为什么本版不是 $129$，也不是 $38$？

**解**：
教材 derivation：**$1$ 分子软脂酸彻底氧化净生成 $106$ 分子 $\mathrm{ATP}$。** 软脂酸 $16$ 碳，每次切 $2$ 碳，需 $7$ 次 β-氧化，得 $8$ 分子乙酰 $\mathrm{CoA}$、$7$ 分子 $\mathrm{FADH}_2$、$7$ 分子 $\mathrm{NADH}$。在 $\mathrm{pH}\,7.0$，$25^{\circ}\mathrm{C}$ 的标准条件下氧化磷酸化，每分子 $\mathrm{FADH}_2$ 产生 $1.5$ 分子 $\mathrm{ATP}$，每分子 $\mathrm{NADH}$ 产生 $2.5$ 分子 $\mathrm{ATP}$；每分子乙酰 $\mathrm{CoA}$ 经三羧酸循环彻底氧化产生 $10$ 分子 $\mathrm{ATP}$。毛产额：$(7\times 1.5)+(7\times 2.5)+(8\times 10)=10.5+17.5+80=108$。脂肪酸活化 $\mathrm{ATP}\rightarrow\mathrm{AMP}+\mathrm{PP}_\mathrm{i}$ 且 $\mathrm{PP}_\mathrm{i}$ 被焦磷酸酶水解，消耗 $2$ 个高能磷酸键，相当于减 $2$。净得 $106$。

教材 pitfall：**本版是 $106$，不要默写成 $129$ 或 $131$。** $\mathrm{NADH}$ 按 $2.5$、$\mathrm{FADH}_2$ 按 $1.5$、乙酰 $\mathrm{CoA}$ 按 $10$ 计，与第七章有氧氧化同一套标准条件。旧口诀 $3$ 和 $2$、毛产 $131$ 再减 $2$ 得 $129$，与本版 $108-2=106$ 对不上。图8-3 也把呼吸链标成 $1.5$／$2.5$、三羧酸循环标成 $10\,\mathrm{ATP}$。

教材 pitfall：**不要把第一节的 $38\,\mathrm{kJ/g}$ 或葡萄糖口诀 $38\,\mathrm{ATP}$ 串到软脂酸账上。** $1\,\mathrm{g}$ 甘油三酯彻底氧化 $38\,\mathrm{kJ}$ 是单位质量产能（蛋白质／糖各 $17\,\mathrm{kJ}$）；第七章葡萄糖有氧氧化净 $30$ 或 $32\,\mathrm{ATP}$，不是口诀 $36/38$。三本账单位不同、分子不同，并户就会写成“软脂酸净 $38$”或“净 $129$”。

教材 keypoint：**次数：碳数 $/2-1=7$ 次 β-氧化；$8$ 个乙酰 $\mathrm{CoA}$。每次 β-氧化：$1\,\mathrm{FADH}_2+1\,\mathrm{NADH}$。活化永远减 $2$，与碳链长度无关。**

| 项目 | 本版数字 |
|------|----------|
| β-氧化次数 | $7$ |
| $\mathrm{FADH}_2$／$\mathrm{NADH}$／乙酰 $\mathrm{CoA}$ | $7$／$7$／$8$ |
| 当量 | $1.5$／$2.5$／$10$ |
| 毛产额 | $108$ |
| 活化 | 减 $2$ |
| 净得 | $106$ |
| 不要写 | $129$、$131$、$38$ |

易错点：用口诀 $3$ 和 $2$ 加成 $129$；活化只减 $1$（忘了 $\mathrm{PP}_\mathrm{i}$ 水解）；把 $7$ 次写成 $8$ 次（乙酰 $\mathrm{CoA}$ 数和循环次数差 $1$）；把 $38\,\mathrm{kJ/g}$ 或葡萄糖 $38\,\mathrm{ATP}$ 听成软脂酸净 $\mathrm{ATP}$；把第七章 $30$ 或 $32$ 套到软脂酸上。
