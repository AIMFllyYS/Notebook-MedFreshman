**题目**：高通量测序本版从哪一年哪一款仪器算起？$\mathrm{WES}$ 先捕获什么、外显子占基因组多少、致病突变大约多少在外显子？性价比高的代价是什么？人 $\mathrm{WGS}$ 覆盖率多少倍、准确率本版怎么写？$\mathrm{WGRS}$ 是第三种化学原理吗？四种 $\mathrm{DNA}$ 变异是哪四户？图22-3 左列和右列各干什么？临床是不是一律做全基因组？

**解**：
教材 definition：**第二代测序（$\mathrm{NGS}$）**又称高通量测序，基于 $\mathrm{PCR}$ 和基因芯片发展而来。与 Sanger 法相比，以大规模并行方式扩增数百万份特定 $\mathrm{DNA}$ 片段。本版时间钉：$2005$ 年罗氏 $454$ 为第一款二代测序仪；随后 Illumina 系列极大降价并推动普及。教材 insight：**$2005$ 年同时出现 $\mathrm{GWAS}$ 第一篇和第一款二代测序仪**，不要把这一年只记成其中一件。

教材 definition：**全外显子组测序（$\mathrm{WES}$）**利用序列捕获技术将全基因组的外显子区域 $\mathrm{DNA}$ 捕获富集后进行高通量测序，能够直接发现与蛋白质功能变异相关的遗传变异 $\mathrm{SNP}$。人类外显子只占基因组的 $1\%$，但 $85\%$ 的致病突变都在外显子区域；测约 $1\%$ 的基因组片段就可覆盖外显子绝大部分疾病相关基因变异，对常见和罕见变异都有较高灵敏度，可实现定位克隆。性价比高、数据量和复杂性下降，复杂疾病易感基因研究中颇受推崇。代价：只测一部分，重要信息可能遗漏，新发现机会减少。教材 pitfall：**$\mathrm{WES}$ 可实现定位克隆，不是取消定位克隆这个概念。** 候选区域、家系、表型同质仍是第一节的原则。功能克隆「现在已经基本被全外显子组测序取代」对着这一小节：不再要求先拿到那一盘纯蛋白。

教材 definition：**全基因组测序（$\mathrm{WGS}$）**是应用最广泛的 $\mathrm{NGS}$ 形式，对生物体基因组的整个核苷酸序列进行分析。人全基因组测序：$10\sim 20$ 倍覆盖率，与人类基因组精确图谱比较，准确检测个人基因组中的变异集合；准确率可高达 $99.99\%$。相比芯片可全面挖掘序列差异和结构变异；在鉴定 $\mathrm{SNP}$、插入和缺失突变（$\mathrm{InDel}$）时更有优势。教材 definition：**全基因组重测序（$\mathrm{WGRS}$）**是对已知参考基因组和注释的物种，在不同个体间（如家系中所有成员）做 $\mathrm{WGS}$，再做差异性分析。它是 $\mathrm{WGS}$ 在不同样本上的重复，不是第三种化学测序原理。

教材 definition：**四种 $\mathrm{DNA}$ 变异**——$\mathrm{WES}$／$\mathrm{WGS}$／$\mathrm{WGRS}$ 都在找基因组上的变异，主要四种：①$\mathrm{SNV}$（同义与非同义）；②$\mathrm{InDel}$；③$\mathrm{SV}$（$50\,\mathrm{bp}$ 以上的 big indel、串联重复、倒位、染色体内部或之间的易位等）；④$\mathrm{CNV}$。$\mathrm{CNV}$ 在第一节已经当遗传标记立过（$1\,\mathrm{KB}$～$3\,\mathrm{MB}$），这里不要改写区间。

教材 insight：**图22-3 左列是文库化学，右列是分析分叉。** 左列：双链 $\mathrm{DNA}$ 片段化 → $3'$ 末端修复（图上标出 $\mathrm{A}$ 突出）→ 连接接头 → $\mathrm{PCR}$ 扩增 → 深度测序。右列：基因组 $\mathrm{DNA}$ → 文库 → 高通量测序 → 预处理得高质量 clean data → 参考序列比对看覆盖度和深度，然后三支应用：基因变异／疾病相关（含易感基因 $\mathrm{GWAS}$ 注释、家族遗传病关联）、肿瘤相关（体细胞变异、驱动基因、Hotspot、频率）、群体（共有／特有差异的 $\mathrm{GO}$／$\mathrm{KEGG}$ 与 $\mathrm{SNP}$／$\mathrm{InDel}$）。肿瘤那一支是 $\mathrm{WGS}$ 的应用分叉，不是把第二十三章癌症整章搬进来。教材 pitfall：**临床是选路，不是默认全基因组。** 根据家系、患者等多方面实际情况选择最佳策略。写成「现在一律 $\mathrm{WGS}$」，图22-1 的多路互补就被一笔勾销。教材 pitfall：**$\mathrm{WGS}$ 不是 $\mathrm{RNA}$-$\mathrm{seq}$。** 图22-3 材料是基因组 $\mathrm{DNA}$；图22-2 材料是 $\mathrm{RNA}$。

| | 覆盖 | 本版一句话 |
|--|------|-----------|
| $\mathrm{WES}$ | 外显子（约 $1\%$） | $85\%$ 致病突变在外显子；性价比高，但可能遗漏 |
| $\mathrm{WGS}$ | 全基因组 | $10\sim 20$ 倍；准确率可高达 $99.99\%$；$\mathrm{SNP}$／$\mathrm{InDel}$ 更有优势 |
| $\mathrm{WGRS}$ | 全基因组，在不同样本上重复 | 已知参考基因组的物种，家系等个体间 $\mathrm{WGS}$ |

易错点：$1\%$ 与 $85\%$ 对调；$\mathrm{WES}$ 写成已经取消定位克隆；$\mathrm{WGRS}$ 写成第三种测序化学；四种变异漏 $\mathrm{SV}$ 或 $\mathrm{CNV}$；图22-3 与图22-2 并户；临床一律 $\mathrm{WGS}$；$\mathrm{WGS}$ 展开成第三节精准医学定义。
