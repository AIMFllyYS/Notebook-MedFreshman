**题目**：鉴定原则三句话按什么排？图22-1 上方三路入口是什么？哪几路先到候选染色体区域，哪几路可以不靠位置？功能克隆从蛋白质到 $\mathrm{DNA}$ 还是从位置到基因，本版镰状细胞贫血写的是哪条珠蛋白、哪号染色体？表型克隆三种策略比的是 $\mathrm{DNA}$ 还是 $\mathrm{mRNA}$？候选基因从 $2$ 万降到 $10\sim 30$ 是不是已经找到致病基因？计算机模拟克隆搜到序列算不算鉴定完毕？

**解**：
教材 definition：**鉴定原则三句**——①关键：确定疾病表型和基因间的实质联系（诊断准、表型同质；家系／孪生子／领养／同胞罹患率看遗传度和遗传因素）。②手段：多途径、多种方法，如图22-1 互为补充。③核心：确定候选基因，明晰序列改变和表型的关系。教材 pitfall：**不要跳过遗传度直接上测序。** 遗传贡献很小，后面连锁、$\mathrm{GWAS}$、全外显子组都缺少前提。教材 pitfall：**不要只背手段里的某一种技术。**

教材 insight：**图22-1 先认三路入口，再认是否经过候选染色体区域。** 上方是数据库、动物模型、病例家系。家系连锁／关联和细胞遗传学先到「确定候选染色体区域」，再汇到候选基因。功能克隆、表型克隆、动物模型同源基因、$\mathrm{EST}$ 可以不经过「候选染色体区域」那一格。$\mathrm{GWAS}$ 和全外显子组／全基因组测序从图上较直接通向候选基因。最后共同经过突变筛查与鉴定，功能分析与结构分析并列，才「确定致病基因」。教材 pitfall：**位点里已经有数个到数十个基因，不是找到染色体就结束。** 写成「连锁分析已经鉴定出致病基因」，候选基因交汇那一小节就没有工作可做。

教材 definition：**功能克隆**是在掌握或部分了解基因功能产物蛋白质的基础上鉴定编码基因，路线从蛋白质到 $\mathrm{DNA}$，相对于利用基因位置的定位克隆。本版点名血红蛋白病、苯丙酮尿症等。氨基酸序列路线：表达丰富→纯化→测序→简并寡核苷酸探针筛 $\mathrm{cDNA}$ 文库（除甲硫氨酸和色氨酸外都有简并，可设计混合探针）。抗体路线：低丰度时用特异性抗体钓核糖体 $\mathrm{mRNA}$ 或筛表达文库。教材 definition：**本版镰状细胞贫血**——免疫电泳显示珠蛋白异常 → 简并探针筛有核红细胞系 $\mathrm{cDNA}$ 文库 → $\alpha$ 珠蛋白基因 $\mathrm{cDNA}$ → 定位于第 $16$ 号染色体 → 提出分子病概念。教材 pitfall：**本版这一段写的是 $\alpha$ 珠蛋白和第 $16$ 号染色体**，不要用其他教材改写；第二节原位杂交另写 $\alpha$→$16$ 号、$\beta$→$11$ 号，两处各按本版句子记。功能克隆现在已经基本被全外显子组测序取代，不等于从未成功。

教材 definition：**表型克隆三种策略**——①直接比较患者与正常人基因组 $\mathrm{DNA}$（不需要位置和产物信息；动态突变是三联重复随世代扩大，用基因组错配筛选、$\mathrm{RDA}$）。②已知基因比表达（Northern、$\mathrm{RNA}$ 酶保护、$\mathrm{RT}$-$\mathrm{PCR}$、实时定量 $\mathrm{RT}$-$\mathrm{PCR}$）。③未知基因比全部 $\mathrm{mRNA}$ 种类和含量（早前 $\mathrm{mRNA}$-$\mathrm{DD}$／$\mathrm{SSH}$／$\mathrm{SAGE}$；目前芯片和 $\mathrm{RNA}$-$\mathrm{seq}$，图22-2 在第二节）。教材 pitfall：**第三种差异不一定是基因结构变了**，也可能源于表达调控机制改变。

教材 definition：**候选基因是交汇点。** 可不依赖染色体位置鉴定，但常用策略仍是先找候选染色体区域。人类基因组计划把位置信息从 $2$ 万个基因降到候选区域的 $10\sim 30$ 个，鉴定较以往相对容易，但仍缺乏「预测出那一个」的能力，需要大量重复、逐个排除。教材 definition：**计算机模拟克隆（in silico cloning）**是电子辅助克隆：同源比较、跨物种拼接、预测全长，再经实验从组织细胞中克隆。教材 definition：**$\mathrm{EST}$** 是 $\mathrm{cDNA}$ 文库随机克隆的部分测序产物；人类新基因克隆大都从同源 $\mathrm{EST}$ 分析开始。至 $1995$ 年，阳性克隆发现的 $45$ 种人类疾病基因中 $78\%$ 可与 $\mathrm{EST}$ 匹配，随后转为基因依赖的 $\mathrm{STS}$ 扩展转录图谱。教材 pitfall：**网上比完不等于实验室里已经拿到克隆。** 本节数据库只写到 $\mathrm{EST}$／$\mathrm{STS}$；$\mathrm{OMIM}$、$\mathrm{GWAS}$ catalog 等是第二节的账。

| 入口 | 先得到什么 | 是否必经候选染色体区域 |
|------|-----------|---------------------|
| 家系连锁／关联、细胞遗传学 | 候选染色体区域 | 是 |
| 功能克隆 | 已知蛋白质功能／结构 | 否 |
| 表型克隆 | 表型与 $\mathrm{DNA}$／$\mathrm{mRNA}$ 差异 | 否 |
| 动物模型同源基因 | 动物突变基因，再找人的同源 | 比较基因组学相连 |
| 数据库 $\mathrm{EST}$ | 序列与注释 | 否 |
| $\mathrm{GWAS}$、全外显子组／全基因组测序 | 变异与表型关联或编码区变异 | 图上不经过「候选区域」那一格 |

易错点：策略＝只有 $\mathrm{GWAS}$；连锁到染色体就等于鉴定完毕；$2$ 万$\rightarrow 10\sim 30$ 等于找到了；功能克隆写成定位克隆别名；本版镰状细胞贫血改成别的珠蛋白；动态突变写成点突变；in silico 搜到就算克隆完；把第二节疾病库提前写进本节。
