**题目**：定位克隆的定义是「已经拿到致病基因」还是「仅根据大体位置」？起点是什么？经典流程和基因组计划后的定位候选克隆差在哪一格？基因定位四法各靠什么——$\mathrm{TK}$ 在几号、$\alpha$／$\beta$ 珠蛋白分别在几号、Down 综合征 $\mathrm{SOD}$-$1$ 高几倍？定位克隆三步是什么，优先基因三条尺子？第一个成功鉴定的疾病基因是哪个？定位克隆能不能写成 $\mathrm{GWAS}$、$\mathrm{RNA}$-$\mathrm{seq}$ 或 $\mathrm{WGS}$ 的别名？

**解**：
教材 definition：**定位克隆（positional cloning）**是仅根据疾病基因在染色体上的大体位置，鉴定克隆疾病相关基因。起点是基因定位。教材 definition：**经典流程**——基因定位确定位置 → $\mathrm{DNA}$ 标记把经典遗传学信息转换成遗传标记所代表的特定基因组区域 → 用该区域相连重叠群（contig）筛选候选基因 → 比较患者和正常人这些基因的差异。教材 definition：**定位候选克隆**——人类基因组计划之后，定位到某一染色体区域，根据该区域的基因、$\mathrm{EST}$ 或模式生物对应同源区的已知基因等信息，直接进行基因突变筛查。现在已不必先自己拼一套重叠群。教材 pitfall：**大体位置不是已经鉴定出基因。** 位点里还有数个到数十个基因。基因组计划改变的是「区域内的基因列表从哪读」，不是取消定位这一步。

教材 definition：**基因定位四法**——①体细胞杂交：人—啮齿类杂种细胞繁殖中人类染色体逐渐丢失（原因至今不明），把活性扣到剩下的那条。Miller 等：含人 $17$ 号染色体的杂种细胞因有胸苷激酶（$\mathrm{TK}$）活性而存活 → $\mathrm{TK}$ 定位于第 $17$ 号染色体；肿瘤抑制基因也是此法发现。丢染色体是方法的关键，不是实验失败。②染色体原位杂交／$\mathrm{FISH}$：中期染色体变性后与标记探针杂交，可到某染色体及区段。$1978$ 年用 $\alpha$ 及 $\beta$ 珠蛋白基因 $\mathrm{cDNA}$：$\alpha$ 在第 $16$ 号，$\beta$ 在第 $11$ 号。特别适用于不转录的重复序列（卫星 $\mathrm{DNA}$ 着丝粒和端粒附近）。③染色体异常：有时可替代连锁；散发性、严重显性遗传病中甚至是获得候选基因的唯一方法。本版点名多囊肾、巨肠症、假肥大型肌营养不良很大程度上借助于异常核型。$6$ 号臂间倒位与某一 $\mathrm{HLA}$ 等位基因共分离 → $\mathrm{HLA}$ 定于 $6$ 号短臂远侧区。Down 综合征（$47,+21$）超氧化物歧化酶-$1$ 活性高 $1.5$ 倍 → 该酶基因在 $21$ 号；并非所有基因都有明显剂量效应。④连锁分析：待定基因与标记连锁 → 同一染色体；重组率度量顺序和遗传距离（$\mathrm{cM}$）。血型基因 $\mathrm{Xs}$ 在 $\mathrm{X}$ 上，普通鱼鳞病和眼白化病与其连锁。

教材 definition：**定位克隆三步**——①尽可能缩小候选区域（更多标记、最近标记、更多家系、所有个体单倍体型，增加重组机会，结合连锁不平衡）。②构建目的区域的基因列表：现在已无须建立 $\mathrm{DNA}$ 重叠群，用 Ensembl 或 the Santa Cruz 阅览器显示已肯定或可能的基因，但要检查重叠拼装是否正确，并结合 $\mathrm{ENCODE}$、非编码序列、选择性转录本。③优先考虑基因的选择及突变检测：对无血缘关系患者测序。优先三条：合适的表达（与表型一致；不一定特征性表达于病变组织，但至少发病前／时疾病组织表达；神经管缺损应在闭锁前即人胚胎 $3\sim 4$ 周表达）；合适的功能（如 fibrillin 与 Marfan 综合征；跨膜或酪氨酸激酶基序）；同源性和功能关系（paralog 是与人的间接同源，ortholog 是与其他种的直接同源，且同源突变引起类似表型；也可基于受体—配体、同途径组分）。教材 definition：**两个成功例**——第一个疾病相关基因是 $\mathrm{X}$ 连锁慢性肉芽肿病基因；更彰显优势的是假肥大型肌营养不良（$\mathrm{DMD}$）基因。

教材 pitfall：**定位克隆 ≠ $\mathrm{GWAS}$ ≠ $\mathrm{RNA}$-$\mathrm{seq}$ ≠ $\mathrm{WGS}$。** 定位克隆从大体位置出发筛区域内基因。$\mathrm{GWAS}$ 是无假说全基因组 $\mathrm{SNP}$ 关联，找复杂病易感基因。$\mathrm{RNA}$-$\mathrm{seq}$ 材料是 $\mathrm{RNA}$，问表达差异（图22-2）。$\mathrm{WGS}$ 材料是基因组 $\mathrm{DNA}$，问全部核苷酸变异（图22-3）。四户不要并成「都是测序」。

| 方法 | 关键观察 | 本版钉子 |
|------|---------|---------|
| 体细胞杂交 | 杂种细胞丢人染色体后剩哪条 | $\mathrm{TK}$ → $17$ 号 |
| 原位杂交／$\mathrm{FISH}$ | 中期染色体上的杂交信号 | $\alpha$→$16$ 号，$\beta$→$11$ 号 |
| 染色体异常／剂量 | 核型异常、共分离、拷贝剂量 | $\mathrm{HLA}$／$6\mathrm{p}$；$\mathrm{SOD}$-$1$ 与 $21$ 三体 $1.5$ 倍 |
| 连锁分析 | 与标记共分离、重组率 | $\mathrm{Xs}$、鱼鳞病、眼白化病在 $\mathrm{X}$ 上 |

易错点：定位＝已经拿到基因；四法并成只有连锁；$\mathrm{TK}$ 写成别的染色体；$\alpha$／$\beta$ 记反；剂量法夸成所有基因都能这样定位；paralog 与 ortholog 并成一个词；把定位克隆写成 $\mathrm{GWAS}$ 或 $\mathrm{WGS}$。
