:::example{label="血红素合成：起始和终末在线粒体，中间在胞质；成熟红细胞不能合成"}
**题目**：血红素合成的起始、中间、终末各在哪个亚细胞部位？图26-4 按什么顺序读，「出线粒体再进来」指哪两步？尿卟啉原Ⅲ还在不在胞质，粪卟啉原Ⅲ从哪回线粒体？中间产物进出线粒体的机制本版怎么写？成熟红细胞为什么不能合成血红素，网织红细胞还能不能？血红素生成后到哪与珠蛋白结合？$\mathrm{EPO}$ 是什么、主要由哪合成、缺氧时运到哪、促进哪些集落？四种加快血红素合成的方式能不能并成一句？

**解**：
教材 keypoint：**分区先记成两头线粒体、中间胞质**——起始：线粒体合成 $\mathrm{ALA}$（图26-2）。中间：胞质里 $\mathrm{ALA}$ → 胆色素原 → 尿卟啉原Ⅲ → 粪卟啉原Ⅲ。终末：粪卟啉原Ⅲ回线粒体，变成原卟啉Ⅸ再装 $\mathrm{Fe}^{2+}$。中间产物进出线粒体的机制，本版写「目前尚不清楚」。教材 insight：**图26-4 按「出线粒体再进来」读**——右侧胞液是 $\mathrm{ALA}$ → 胆色素原 → 线状四吡咯 → 尿卟啉原Ⅲ；底部尿卟啉原Ⅲ → 粪卟啉原Ⅲ仍在胞液侧；左侧线粒体内从下往上：粪卟啉原Ⅲ进来 → 原卟啉原Ⅸ → 原卟啉Ⅸ → 装上 $\mathrm{Fe}^{2+}$ 成血红素 → 出去与珠蛋白会合。不要把尿卟啉原Ⅲ画进线粒体。

教材 definition：**血红素合成的三个特点**——①主要部位骨髓与肝；成熟红细胞不含线粒体，故不能合成。②原料是小分子；中间变化主要是侧链脱羧和脱氢；卟啉原无共轭、无色、不稳定、易氧化、对光敏感。③起始终末在线粒体，中间在胞质，便于终产物反馈。教材 definition：**从血红素到血红蛋白**——血红素生成后从线粒体转到胞质，在骨髓有核红细胞及网织红细胞中与珠蛋白结合成为血红蛋白。成熟红细胞既不能合成血红素，也不能合成珠蛋白（第三节表26-2）。教材 insight：**幼红细胞和网织红细胞还有线粒体。** 表26-2：有核红细胞和网织红细胞能合成血红素，成熟红细胞不能。

教材 timeline：**血红素合成四步（按本版）**——线粒体：琥珀酰 $\mathrm{CoA}$ 与甘氨酸缩合成 $\mathrm{ALA}$（$\mathrm{ALA}$ 合酶，磷酸吡哆醛，限速）。胞质：$2$ 分子 $\mathrm{ALA}$ 脱水成胆色素原（$\mathrm{ALA}$ 脱水酶，含巯基，铅敏感）。胞质：$4$ 分子胆色素原经线状四吡咯变成尿卟啉原Ⅲ，再脱羧成粪卟啉原Ⅲ。线粒体：粪卟啉原Ⅲ氧化成原卟啉原Ⅸ、原卟啉Ⅸ，亚铁螯合酶装上 $\mathrm{Fe}^{2+}$ 成血红素。

教材 definition：**促红细胞生成素 EPO**——集落刺激因子。$166$ 个氨基酸的糖蛋白，$34\,\mathrm{kDa}$。主要在肾合成，缺氧时释放入血，运至骨髓。结合并激活原始红细胞表面的 $\mathrm{EPO}$ 受体，促进 $\mathrm{BFU}$-$\mathrm{E}$ 和 $\mathrm{CFU}$-$\mathrm{E}$ 的繁殖分化，加速有核红细胞成熟以及血红素和 $\mathrm{Hb}$ 合成。红细胞生成的主要调节剂。教材 pitfall：**EPO 主要在肾合成，不是在骨髓合成。** 骨髓是靶器官。

| | 作用点 | 器官 |
|--|------|------|
| 血红素／高铁血红素减少（负反馈解除） | $\mathrm{ALA}$ 合酶 | 合成血红素的细胞自己 |
| 睾酮 $5$-$\beta$ 还原物、药物等 | 诱导肝 $\mathrm{ALA}$ 合酶 | 肝（$\mathrm{P}450$ 需求） |
| $\mathrm{EPO}$ | 红系繁殖分化＋血红素／$\mathrm{Hb}$ 合成 | 肾合成，骨髓执行 |

易错点：尿卟啉原Ⅲ画进线粒体；整条路都在胞质或都在线粒体；成熟红细胞还能合成血红素；网织红细胞与成熟红细胞并户；$\mathrm{EPO}$ 写成骨髓自己分泌；药物诱导并进 $\mathrm{EPO}$；进出线粒体机制写成已经清楚。
