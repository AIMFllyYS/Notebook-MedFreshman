:::example{label="红细胞运氧、白细胞免疫、血小板凝血；血小板来自巨核细胞脱落的胞质"}
**题目**：三类血细胞各干什么？血小板是巨核细胞的别名，还是巨核细胞脱落的胞质被细胞膜包裹形成的？粒细胞、单核巨噬细胞、$\mathrm{T}$ 淋巴细胞获能方式本版各怎么写，「主要」能不能抄成「唯一」？吞噬细胞怎样用 $\mathrm{NADPH}$ 氧化酶产生活性氧？Ⅰ型超敏反应三种介质——血栓烷／前列腺素、白三烯、组胺——各来自谁？成熟粒细胞为什么蛋白质合成很少，抗体是谁分泌的？第一节 $\gamma$ 球蛋白由浆细胞合成，和这一小节怎么合拢？急性肝炎看前清蛋白还是等 $\mathrm{A}/\mathrm{G}$ 倒置？

**解**：
教材 definition：**三类血细胞的职分**——红细胞运送氧；白细胞参与免疫；血小板参与凝血。血小板由骨髓造血组织中的巨核细胞脱落的胞质被细胞膜包裹而形成。本节展开红、白两系，血小板只点名。教材 pitfall：**不要把巨核细胞写成血小板的另一种名字。** 血小板是巨核细胞脱落的胞质碎片。写成「血小板在骨髓里分裂增殖」，表26-2 那套有核红细胞的分裂账就会被安到错误的细胞头上。

教材 compare：**白细胞获能不要抄成同一句**——粒细胞：线粒体很少，糖无氧氧化是主要途径；中性粒细胞用外源糖和内源糖原做无氧氧化，给吞噬提供能量。单核巨噬细胞：虽能进行有氧氧化，但糖无氧氧化仍占很大比重。$\mathrm{T}$ 淋巴细胞：激活前主要通过葡萄糖有氧氧化获能，激活后主要通过糖无氧氧化获能。与成熟红细胞「唯一途径」不同：白细胞不是没有线粒体，只是有的很少、有的激活后改道。教材 pitfall：**不要把「主要途径」写成「唯一途径」。**

教材 definition：**NADPH 氧化酶递电子体系**——成分：$\mathrm{NADPH}$ 氧化酶、细胞色素 $b_{558}$ 和两种胞质多肽等。趋化因子激活中性粒细胞和单核巨噬细胞 → 戊糖磷酸途径产生大量 $\mathrm{NADPH}$ → $\mathrm{O}_2$ 单电子还原成 $\mathrm{O}_2^{\cdot -}$ → 再变成 $\mathrm{H}_2\mathrm{O}_2$、$\cdot\mathrm{OH}$ 等活性氧杀菌。反应式：$2\mathrm{O}_2+\mathrm{NADPH}\rightarrow 2\mathrm{O}_2^{\cdot -}+\mathrm{NADP}^{+}+\mathrm{H}^{+}$。教材 insight：**超氧阴离子是单电子还原，不是四电子变成水。**

教材 definition：**Ⅰ型超敏反应的三种介质来源**——单核巨噬细胞：花生四烯酸 → 血栓烷和前列腺素。粒细胞和单核巨噬细胞：脂氧化酶催化花生四烯酸 → 白三烯。粒细胞：组氨酸 → 组胺。不要把组胺写成花生四烯酸的产物。教材 definition：**成熟粒细胞蛋白质合成很少**——缺乏内质网。不要把抗体、补体、细胞因子都写成粒细胞的分泌物。教材 definition：**单核／巨噬细胞合成酶、补体和细胞因子**。教材 definition：**B 淋巴细胞 → 浆细胞 → 抗体**——参与体液免疫。第一节 $\gamma$ 球蛋白由浆细胞合成，在这里接到白细胞代谢。抗体不是 $\mathrm{T}$ 细胞分泌的。

教材 definition：**肝疾病的血浆蛋白改变**——急性肝炎：非典型急性时相反应，前清蛋白是肝功能损害的敏感指标。肝硬化：清蛋白减少、球蛋白增加，$\mathrm{A}/\mathrm{G}$ 倒置。急性看前清蛋白，慢性看清蛋白和 $\mathrm{A}/\mathrm{G}$，不要并成「肝病都是 $\mathrm{A}/\mathrm{G}$ 倒置」。清蛋白半衰期约 $20$ 天，急性损伤时浓度往往还来不及掉到位。

| | 内质网／蛋白合成 | 本版产物 |
|--|----------------|---------|
| 成熟粒细胞 | 缺乏内质网，合成量很少 | 不是抗体工厂 |
| 单核／巨噬细胞 | 活跃 | 酶、补体、细胞因子 |
| $\mathrm{B}$ 细胞 → 浆细胞 | 分泌型 | 多种抗体蛋白 |
| 血小板 | 巨核细胞脱落的胞质 | 凝血；不是巨核细胞的别名 |

易错点：血小板＝巨核细胞；粒细胞「唯一途径」；组胺写成花生四烯酸产物；抗体由粒细胞或 $\mathrm{T}$ 细胞分泌；超氧阴离子写成呼吸链末端的水；肝病一律等 $\mathrm{A}/\mathrm{G}$ 倒置。
