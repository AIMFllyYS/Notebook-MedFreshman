:::example{label="血型、选凝素与IgG如何把聚糖写成识别"}
**题目**：聚糖中单糖间的连接方式有哪四种，又分 $\alpha$ 与 $\beta$，这种结构多样性是什么作用的基础？猪卵细胞透明带中分子质量 $5.5$ 万的 $\mathrm{ZP}$-$3$ 含哪一型聚糖、识别谁？整合素与纤连蛋白结合依赖完整的哪一型聚糖，用加工酶抑制剂把整合素聚糖改成高甘露糖型或杂合型会怎样？红细胞血型物质含糖达多少，$\mathrm{ABO}$ 血型物质存在于细胞表面糖脂还是糖蛋白里的聚糖组分？物质 $\mathrm{A}$ 和 $\mathrm{B}$ 只是在物质 $\mathrm{O}$ 的非还原端各加上哪个糖基？细菌表面凝集素样蛋白识别什么进而侵袭细胞？选凝素在谁的表面、识别内皮细胞表面糖蛋白上的什么，怎样完成出血管至炎症组织？$\mathrm{IgG}$ 属于哪一型糖蛋白，聚糖主要在 $\mathrm{Fc}$ 段还是 $\mathrm{Fab}$ 段，去聚糖后铰链区构象破坏会丢掉哪些功能？为什么识别读的是聚糖结构、不是只读肽？

**解**：
教材 definition：**单糖间可有 $1,2$、$1,3$、$1,4$、$1,6$ 连接，又分 $\alpha$ 与 $\beta$。这种结构多样性是聚糖分子识别作用的基础。** 教材 concept：**看见“聚糖有什么用”，先回到 $1,2$／$1,3$／$1,4$／$1,6$ 和 $\alpha$／$\beta$。多样性是识别的基础。**

教材 example：**识别账上的几条例子按教材记。** 猪卵细胞透明带中分子质量为 $5.5$ 万的 $\mathrm{ZP}$-$3$ 蛋白含有 $O$-连接型聚糖，能识别精子并与之结合。整合素与其配体纤连蛋白结合，依赖完整的整合素 $N$-连接型聚糖；若用聚糖加工酶抑制剂处理白血病 $\mathrm{K}562$ 细胞，使整合素聚糖改变成高甘露糖型或杂合型，均可降低与纤连蛋白识别和结合的能力。

红细胞的血型物质含糖达 $80\%\sim 90\%$。$\mathrm{ABO}$ 血型物质是存在于细胞表面糖脂中的聚糖组分。$\mathrm{ABO}$ 系统中血型物质 $\mathrm{A}$ 和 $\mathrm{B}$ 均是在血型物质 $\mathrm{O}$ 的聚糖非还原端各加上 $\mathrm{GalNAc}$ 或 $\mathrm{Gal}$，仅一个糖基之差，使红细胞能分别识别不同的抗体，产生不同的血型。第三节把这一笔收成：聚糖作为某些蛋白质组分与生物表型密切相关，体现生物信息。细菌表面存在各种凝集素样蛋白，可识别人体细胞表面的聚糖结构，进而侵袭细胞。

教材 definition：**选凝素（selectin）是白细胞表面的一类黏附分子，能识别并结合内皮细胞表面糖蛋白分子中的特异聚糖结构，使白细胞与内皮黏附，再经其他黏附分子完成移动及出血管。** 血液循环中的白细胞需通过沿血管壁排列的内皮细胞，才能出血管至炎症组织。

免疫球蛋白 $\mathrm{G}$（$\mathrm{IgG}$）属于 $N$-连接糖蛋白，其聚糖主要存在于 $\mathrm{Fc}$ 段。$\mathrm{IgG}$ 的聚糖可结合单核细胞或巨噬细胞上的 $\mathrm{Fc}$ 受体，并与补体 $\mathrm{C}1\mathrm{q}$ 的结合和激活以及诱导细胞毒等过程有关。若 $\mathrm{IgG}$ 去除聚糖，其铰链区的空间构象遭到破坏，上述与 $\mathrm{Fc}$ 受体和补体的结合功能将会丢失。

教材 insight：**精子认 $\mathrm{ZP}$-$3$ 的 $O$-聚糖，整合素认完整 $N$-聚糖，选凝素认内皮糖蛋白上的特异聚糖，$\mathrm{IgG}$ 去糖就丢 $\mathrm{Fc}$ 功能。第三节把这件事提升为“聚糖结构蕴藏大量生物信息”；本节先把例子写全。**

| 例子 | 读哪一段聚糖 | 结果 |
|------|----------------|------|
| $\mathrm{ZP}$-$3$（$5.5$ 万） | $O$-连接型聚糖 | 识别并结合精子 |
| 整合素–纤连蛋白 | 完整 $N$-连接型聚糖；改成高甘露糖型或杂合型则结合下降 | 受体–配体识别 |
| $\mathrm{ABO}$ | 物质 $\mathrm{O}$ 非还原端加 $\mathrm{GalNAc}$（$\mathrm{A}$）或 $\mathrm{Gal}$（$\mathrm{B}$） | 仅一个糖基之差即不同血型 |
| 选凝素 | 内皮细胞表面糖蛋白中的特异聚糖 | 白细胞黏附、出血管至炎症组织 |
| $\mathrm{IgG}$ 的 $\mathrm{Fc}$ | $N$-连接聚糖 | 结合 $\mathrm{Fc}$ 受体、补体 $\mathrm{C}1\mathrm{q}$；去糖则功能丢失 |

易错点：把 $\mathrm{ABO}$ 血型物质写成糖蛋白而不是细胞表面糖脂中的聚糖组分；把 $\mathrm{A}$／$\mathrm{B}$ 所加糖基写反；把选凝素写成内皮细胞表面的分子去认白细胞；把 $\mathrm{IgG}$ 聚糖放到 $\mathrm{Fab}$ 段；把整合素改成高甘露糖型听成“结合更强”；漏掉连接方式 $1,2$／$1,3$／$1,4$／$1,6$ 和 $\alpha$／$\beta$ 才是识别的结构基础。
