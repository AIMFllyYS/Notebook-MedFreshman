:::example{label="叶酸／B12 巨幼与恶性贫血、坏血病与贫血分户"}
**题目**：叶酸的活性形式是什么，血液循环主力是哪一种，$\mathrm{N}^{5}$、$\mathrm{N}^{10}$ 是什么位点，缺乏怎样变成巨幼细胞贫血，孕妇缺乏还可能造成什么？维生素 $\mathrm{B}_{12}$ 为什么是唯一含金属元素的维生素，植物中有没有，吸收为什么必须内因子、部位在哪一段肠？甲钴胺素和 $5'$-脱氧腺苷钴胺素各管哪条酶，为什么 $\mathrm{B}_{12}$ 缺乏也会走向巨幼细胞，恶性贫血点名的是叶酸还是 $\mathrm{B}_{12}$？维生素 C 是不是天然活性形式，坏血病的分子户头是哪一步羟化，缺乏多久才出现症状？思考题“维生素缺乏导致贫血的类型和机制”怎样分户：E 的溶血、$\mathrm{B}_{6}$ 的小细胞低色素、叶酸／$\mathrm{B}_{12}$ 的巨幼细胞，坏血病算不算贫血？高同型半胱氨酸血症与哪三种维生素有关？

**解**：
教材 definition：**5,6,7,8-四氢叶酸（$\mathrm{FH}_{4}$）是叶酸的活性型，由小肠黏膜上皮细胞二氢叶酸还原酶催化生成。** 教材 definition：**含单谷氨酸的 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 是叶酸在血液循环中的主要形式。组织中 $\mathrm{FH}_{4}$ 主要以多谷氨酸形式存在。** 教材 definition：**$\mathrm{FH}_{4}$ 是体内一碳单位转移酶的辅因子。分子中 $\mathrm{N}^{5}$、$\mathrm{N}^{10}$ 是一碳单位的结合位点。一碳单位参与嘌呤、胸腺嘧啶核苷酸等多种物质的合成。** 甲氨蝶呤、氨蝶呤结构与叶酸相似，抑制二氢叶酸还原酶 → $\mathrm{FH}_{4}$ 合成减少 → 胸腺嘧啶核苷酸合成受抑制。教材 definition：**巨幼细胞贫血：叶酸缺乏时，骨髓幼红细胞 DNA 合成减少，细胞分裂速度降低，细胞体积变大。维生素 $\mathrm{B}_{12}$ 缺乏也可产生巨幼细胞贫血（即恶性贫血）。** 孕妇叶酸缺乏可能造成胎儿脊柱裂和神经管缺陷。叶酸缺乏还可引起高同型半胱氨酸血症和 DNA 低甲基化。

教材 definition：**维生素 $\mathrm{B}_{12}$ 含金属元素钴，又称钴胺素，是唯一含金属元素的维生素。仅由微生物合成，酵母和动物肝含量丰富，不存在于植物中。** 药用常见形式：氰钴胺素、羟钴胺素；体内活性形式：甲钴胺素、$5'$-脱氧腺苷钴胺素。教材 definition：**内因子（IF）由胃黏膜细胞分泌。维生素 $\mathrm{B}_{12}$ 必须与之紧密结合生成 $\mathrm{B}_{12}$-IF 复合物，才能被回肠吸收。** 教材 pitfall：**没有内因子就没有回肠吸收，植物性食物本来也没有 $\mathrm{B}_{12}$。** 萎缩性胃炎、胃全切或内因子先天性缺陷 → 严重吸收障碍。教材 definition：**甲钴胺素是 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 转甲基酶（甲硫氨酸合成酶）的辅因子，催化同型半胱氨酸生成甲硫氨酸，进而生成 SAM。** 教材 definition：**$5'$-脱氧腺苷钴胺素是 L-甲基丙二酰 $\mathrm{CoA}$ 变位酶的辅因子，催化琥珀酰 $\mathrm{CoA}$ 的生成。** 教材 cause-effect：**甲钴胺素不足，甲硫氨酸合成酶不能把 $\mathrm{N}^{5}\text{-}\mathrm{CH}_{3}\text{-}\mathrm{FH}_{4}$ 的甲基交给同型半胱氨酸，$\mathrm{FH}_{4}$ 不能再生 → 一碳单位代谢受阻，核酸合成障碍。** 教材 definition：**维生素 $\mathrm{B}_{12}$ 缺乏可产生巨幼细胞贫血（即恶性贫血），故维生素 $\mathrm{B}_{12}$ 也称为抗恶性贫血维生素。** 教材 pitfall：**巨幼细胞贫血两家都会，恶性贫血点名 $\mathrm{B}_{12}$。** 有内因子、髓鞘质、甲基丙二酰 $\mathrm{CoA}$ 的是 $\mathrm{B}_{12}$。

教材 definition：**维生素 C 又称 L-抗坏血酸，是 L-己糖酸内酯，具有不饱和的一烯二醇结构，是天然的活性形式。** 人类和其他灵长类不能合成，必须由食物供给。教材 definition：**维生素 C 是含铜羟化酶和 $\alpha$-酮戊二酸-铁羟化酶的辅因子，并参与对-羟苯丙酮酸羟化、多巴胺 $\beta$-羟化、$7\alpha$-羟化、胶原脯氨酸／赖氨酸羟化以及肉碱合成中的羟化。** 教材 insight：**坏血病的分子户头是胶原羟化。** 毛细血管易破裂、牙龈腐烂松动、骨折、创伤不易愈合，都落在胶原成熟。教材 definition：**坏血病（scurvy）即维生素 C 严重缺乏所致，以毛细血管易破裂、牙龈腐烂和松动、骨折以及创伤不易愈合为主要症状。正常可储存一定量维生素 C，缺乏 $3\sim 4$ 个月后才出现症状。** 教材 pitfall：**水溶维生素 C 仍能储存数月，过量可成草酸盐结石。** 不要把水溶听成“当天不吃当天得坏血病”。教材 compare：**本节不把坏血病写成贫血。**

教材 compare：**本节缺乏症与贫血类型（思考题第 4 题用）。** 维生素 E（第一节）：溶血性贫血，红细胞减少、脆性增加。维生素 $\mathrm{B}_{6}$：低血色素小细胞性贫血（维生素 $\mathrm{B}_{6}$ 反应性贫血），血清铁增高——磷酸吡哆醛是 ALA 合酶辅因子，缺的是血红素合成，不是铁。叶酸：巨幼细胞贫血。维生素 $\mathrm{B}_{12}$：巨幼细胞贫血（恶性贫血），可伴髓鞘质变性。$\mathrm{B}_{1}$ 脚气病、$\mathrm{B}_{2}$ 口角炎、$\mathrm{PP}$ 糙皮病、维生素 C 坏血病，本节都不写成贫血。教材 insight：**$2/3$ 以上高同型半胱氨酸血症与维生素 $\mathrm{B}_{6}$、叶酸和维生素 $\mathrm{B}_{12}$ 缺乏有关。** $\mathrm{B}_{6}$ 走胱硫醚 $\beta$ 合成酶（同型半胱氨酸 → 半胱氨酸）；叶酸走 $\mathrm{FH}_{4}$ 一碳单位；$\mathrm{B}_{12}$ 走甲钴胺素／甲硫氨酸合成酶。

| 维生素 | 缺乏症 | 是否贫血、哪一型 |
|--------|--------|------------------|
| E | 溶血性贫血 | 红细胞减少、脆性增加 |
| $\mathrm{B}_{6}$ | 维生素 $\mathrm{B}_{6}$ 反应性贫血 | 低血色素小细胞性；血清铁增高 |
| 叶酸 | 巨幼细胞贫血；神经管缺陷 | 巨幼细胞贫血 |
| $\mathrm{B}_{12}$ | 恶性贫血；髓鞘质变性 | 巨幼细胞贫血（恶性贫血） |
| C | 坏血病 scurvy | 本节不把坏血病写成贫血 |
| $\mathrm{B}_{1}$／$\mathrm{B}_{2}$／$\mathrm{PP}$ | 脚气病／口角炎／糙皮病 | 否 |

易错点：把恶性贫血写成叶酸；把巨幼细胞只答一家；把 $\mathrm{B}_{12}$ 写成植物性食物也有；漏掉内因子和回肠；把 $\mathrm{B}_{6}$ 反应性贫血听成缺铁（血清铁其实增高）；把坏血病写成贫血或听成当天出现；高同型半胱氨酸只答叶酸，漏 $\mathrm{B}_{6}$ 和 $\mathrm{B}_{12}$。
