:::example{label="维生素PP 的 NAD+／NADP+ 与糙皮病 3D 如何记"}
**题目**：维生素 $\mathrm{PP}$ 包括哪两种，曾称什么，是不是维生素中最稳定的一种？体内活性形式是什么，食物里以什么形式存在、吸收后再合成？色氨酸生成烟酸的效率怎样记，$60\,\mathrm{mg}$ 色氨酸生成多少毫克烟酸，还需要哪三种维生素？$\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$ 作为不需氧脱氢酶辅因子怎样分工，乳酸那一笔用谁，脂酸和胆固醇合成用谁？人类缺乏症叫什么，3D 是哪三征，为什么又称抗糙皮病维生素？异烟肼怎样拮抗 $\mathrm{PP}$，它和后文补 $\mathrm{B}_{6}$ 是不是同一机制？大量服用烟酸会怎样，能不能把糙皮病写成缺 $\mathrm{B}_{1}$？

**解**：
教材 definition：**维生素 $\mathrm{PP}$ 包括烟酸（nicotinic acid）和烟酰胺（nicotinamide），曾称尼克酸和尼克酰胺，均为氮杂环吡啶衍生物。烟酸为吡啶-3-羧酸，很容易转变为烟酰胺。它是维生素中最稳定的一种。** 教材 definition：**$\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$ 是维生素 $\mathrm{PP}$ 在体内的活性形式。** 食物中维生素 $\mathrm{PP}$ 以这两种形式存在，小肠内水解成游离维生素 $\mathrm{PP}$ 吸收，再到组织细胞重新合成。未被利用的烟酸可被甲基化，以 N-甲基烟酰胺和 2-吡啶酮由尿中排出。

教材 definition：**体内色氨酸代谢也可生成维生素 $\mathrm{PP}$，但效率较低：$60\,\mathrm{mg}$ 色氨酸仅能生成 $1\,\mathrm{mg}$ 烟酸，并且需要维生素 $\mathrm{B}_{1}$、$\mathrm{B}_{2}$ 和 $\mathrm{B}_{6}$ 参与。** 不要把内源合成听成“有色氨酸就不必从食物摄取 $\mathrm{PP}$”。

教材 definition：**$\mathrm{NAD}^{+}$ 和 $\mathrm{NADP}^{+}$ 是不需氧脱氢酶的辅因子。烟酰胺部分可逆加氢、脱氢，发挥递氢体作用。** 教材 compare：**$\mathrm{NAD}^{+}$：糖酵解和三羧酸循环中一些脱氢酶的受氢体，$\mathrm{NADH}+\mathrm{H}^{+}$ 为丙酮酸生成乳酸提供氢。$\mathrm{NADP}^{+}$：磷酸戊糖途径 G6PD 的受氢体，$\mathrm{NADPH}+\mathrm{H}^{+}$ 作为供氢体参与脂肪酸、胆固醇等合成。** 教材 pitfall：**$\mathrm{NAD}^{+}$ 主要走分解供氢，$\mathrm{NADP}^{+}$ 主要走合成供氢。** 都是维生素 $\mathrm{PP}$ 的活性形式，分工不要并成“都是递氢”。

教材 definition：**糙皮病（pellagra）即人类维生素 $\mathrm{PP}$ 缺乏症，主要表现有皮炎、腹泻及痴呆（3D）。维生素 $\mathrm{PP}$ 又称抗糙皮病维生素。** 3D：皮炎（dermatitis）、腹泻（diarrhea）、痴呆（dementia）。成人男性 RNI $15\,\mathrm{mg}/\mathrm{d}$ NE，女性 $12\,\mathrm{mg}\,\mathrm{NE}/\mathrm{d}$。抗结核药物异烟肼的结构与维生素 $\mathrm{PP}$ 相似，两者有拮抗作用，长期服用可能引起维生素 $\mathrm{PP}$ 缺乏。烟酸作为药物已用于治疗高胆固醇血症。大量服用烟酸或烟酰胺（$1\sim 6\,\mathrm{g}/\mathrm{d}$）会引发血管扩张、脸颊潮红、痤疮及胃肠不适；长期日服用量超过 $500\,\mathrm{mg}$ 可引起肝损伤。教材 pitfall：**异烟肼两边都要补：$\mathrm{PP}$ 和 $\mathrm{B}_{6}$ 不是同一机制。** 异烟肼与维生素 $\mathrm{PP}$ 结构相似、拮抗；后文它又能与磷酸吡哆醛的醛基结合使其失活，服异烟肼时应补维生素 $\mathrm{B}_{6}$。两笔都是抗结核药，缺的维生素和机制不同，不要写成“异烟肼缺 B 族”。

| 项目 | 教材落点 |
|------|----------|
| 活性形式 | $\mathrm{NAD}^{+}$、$\mathrm{NADP}^{+}$ |
| 内源合成 | $60\,\mathrm{mg}$ 色氨酸 → $1\,\mathrm{mg}$ 烟酸，需 $\mathrm{B}_{1}$、$\mathrm{B}_{2}$、$\mathrm{B}_{6}$ |
| $\mathrm{NAD}^{+}$ | 糖酵解、三羧酸；$\mathrm{NADH}$ 供乳酸 |
| $\mathrm{NADP}^{+}$ | G6PD；$\mathrm{NADPH}$ 供脂酸、胆固醇合成 |
| 缺乏 | 糙皮病 pellagra：皮炎、腹泻、痴呆 |
| 异烟肼 | 结构拮抗 $\mathrm{PP}$；另与磷酸吡哆醛醛基结合（须补 $\mathrm{B}_{6}$） |

易错点：把 $\mathrm{NAD}^{+}/\mathrm{NADP}^{+}$ 写成核黄素的活性形式；把 $\mathrm{NAD}^{+}$ 与 $\mathrm{NADP}^{+}$ 的分解／合成账并户；把糙皮病写成脚气病或口角炎；把 $60\,\mathrm{mg}$ 色氨酸听成可以完全替代膳食 $\mathrm{PP}$；把异烟肼只写成“缺 B 族”而不分 $\mathrm{PP}$ 拮抗和 $\mathrm{B}_{6}$ 醛基结合。
