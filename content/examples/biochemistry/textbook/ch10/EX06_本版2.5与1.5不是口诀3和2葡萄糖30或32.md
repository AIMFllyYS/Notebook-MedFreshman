**题目**：本版一对电子经 NADH 呼吸链、琥珀酸呼吸链的 $\mathrm{P/O}$ 各接近多少，旧口诀 $3$ 和 $2$ 还能不能用？$1\,\mathrm{mol}$ 葡萄糖彻底氧化生成多少摩尔 $\mathrm{ATP}$，其中多少来自 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的氧化，差额 $4\,\mathrm{mol}$ 来自哪里？$30$ 还是 $32$ 取决于细胞质 $\mathrm{NADH}$ 走哪一条穿梭？一对电子经复合体Ⅰ、Ⅲ、Ⅳ分别泵出几个 $\mathrm{H}^{+}$，琥珀酸不经Ⅰ泵几个，合成 $1$ 分子 $\mathrm{ATP}$ 按几个 $\mathrm{H}^{+}$ 计（几个走合酶、几个走转运），$10/4$ 和 $6/4$ 怎样对上 $2.5$ 和 $1.5$？为什么不能把“合酶转一周 $3$ 个 $\mathrm{ATP}$”直接当成 $\mathrm{P/O}$？

**解**：
教材 pitfall：**本版不要默写 $36$、$38$ 或 $\mathrm{P/O}$ 等于 $3$ 和 $2$。** 旧口诀把 $\mathrm{NADH}$ 写成 $3\,\mathrm{ATP}$、$\mathrm{FADH}_2$ 写成 $2\,\mathrm{ATP}$，葡萄糖就变成 $36$ 或 $38$。本版与第七、第八章对齐：$\mathrm{NADH}$ 呼吸链约 $2.5\,\mathrm{ATP}$，琥珀酸／$\mathrm{FADH}_2$ 呼吸链约 $1.5\,\mathrm{ATP}$，葡萄糖 $30$ 或 $32$。实验值写的是“接近 $2.5$”“接近 $1.5$”。

教材 keypoint：**$1\,\mathrm{mol}$ 葡萄糖彻底氧化生成 $30$ 或 $32\,\mathrm{mol}\,\mathrm{ATP}$（第七章有氧氧化同一套标准）。其中 $26$ 或 $28\,\mathrm{mol}$ 来自 $\mathrm{NADH}$ 和 $\mathrm{FADH}_2$ 的氧化。差额 $4\,\mathrm{mol}$ 来自底物水平磷酸化（糖酵解净 $2$、三羧酸循环 $2$ 个 $\mathrm{GTP}/\mathrm{ATP}$）。$30$ 还是 $32$，取决于细胞质 $\mathrm{NADH}$ 走哪一条穿梭：甘油-3-磷酸穿梭按 $\mathrm{FADH}_2$ 入口计 $1.5$，苹果酸-天冬氨酸穿梭按 $\mathrm{NADH}$ 入口计 $2.5$。** 两分子细胞质 $\mathrm{NADH}$ 就是 $+3$ 或 $+5$。人体约 $90\%$ 的 $\mathrm{ATP}$ 由线粒体氧化体系产生；底物水平磷酸化产量少，还原性辅酶彻底氧化才是大头。

教材 definition：**$\mathrm{P/O}$ 比值是氧化磷酸化过程中，每消耗 $1/2$ 摩尔 $\mathrm{O}_2$ 所需磷酸的摩尔数，即所能合成 $\mathrm{ATP}$ 的摩尔数，或一对电子通过呼吸链传递给氧所生成 $\mathrm{ATP}$ 的分子数。** 丙酮酸等 $\rightarrow\mathrm{NADH}$，$\mathrm{P/O}$ 接近 $2.5$；琥珀酸，$\mathrm{P/O}$ 接近 $1.5$，差在复合体Ⅰ；抗坏血酸经 $\mathrm{Cyt}\,c$，$\mathrm{P/O}$ 接近 $1$，钉住复合体Ⅳ；剩下的部位在复合体Ⅲ。偶联部位是复合体Ⅰ、Ⅲ、Ⅳ，不是合酶本身，也不是复合体Ⅱ。

教材 definition：**一对电子经复合体Ⅰ、Ⅲ、Ⅳ传递，分别向膜间隙侧泵出 $4\mathrm{H}^{+}$、$4\mathrm{H}^{+}$ 和 $2\mathrm{H}^{+}$，共 $10$ 个 $\mathrm{H}^{+}$。琥珀酸呼吸链不经复合体Ⅰ，每传递 $2$ 个电子泵出 $6$ 个 $\mathrm{H}^{+}$。** 教材 pitfall：**复合体Ⅳ泵 $2$ 个 $\mathrm{H}^{+}$，不是 $4$ 个。** 口诀容易把三个偶联部位都写成“各泵 $4\mathrm{H}^{+}$”。总数 $10$ 不是 $12$，后面 $10/4=2.5$ 才和 $\mathrm{P/O}$ 对齐。

教材 derivation：**实验数据表明，合成 $1$ 分子 $\mathrm{ATP}$ 需要 $4$ 个 $\mathrm{H}^{+}$，其中 $3$ 个 $\mathrm{H}^{+}$ 通过 $\mathrm{ATP}$ 合酶穿内膜回流入基质，另 $1$ 个 $\mathrm{H}^{+}$ 用于转运 $\mathrm{ADP}$、$\mathrm{P}_\mathrm{i}$ 和 $\mathrm{ATP}$。** 每分子 $\mathrm{NADH}$ 泵出 $10\mathrm{H}^{+}$，生成约 $2.5$（$10/4$）分子 $\mathrm{ATP}$；琥珀酸泵出 $6\mathrm{H}^{+}$，生成 $1.5$（$6/4$）分子 $\mathrm{ATP}$。教材 pitfall：**不要把“转一周 $3$ 个 $\mathrm{ATP}$”直接当成 $\mathrm{P/O}$。** 一周 $3$ 个 $\mathrm{ATP}$ 是合酶催化计量。$\mathrm{P/O}$ 还要计入把 $\mathrm{ATP}$ 运出线粒体、把 $\mathrm{ADP}$ 和磷酸运进来所花的那 $1$ 个 $\mathrm{H}^{+}$。只按合酶的 $3\mathrm{H}^{+}/\mathrm{ATP}$ 去除以 $10$，会得到与本版 $2.5$ 对不上的数。基质里做出 $\mathrm{ATP}$ 还不等于细胞质已经拿到。

| 本版当量 | 数字 |
|----------|------|
| NADH 呼吸链 $\mathrm{P/O}$ | 约 $2.5$（$10\mathrm{H}^{+}/4$） |
| 琥珀酸呼吸链 $\mathrm{P/O}$ | 约 $1.5$（$6\mathrm{H}^{+}/4$） |
| 每分子 $\mathrm{ATP}$ | $4\mathrm{H}^{+}$（$3$ 合酶 $+1$ 转运） |
| 葡萄糖净得 | $30$ 或 $32\,\mathrm{ATP}$（看胞质 $\mathrm{NADH}$ 穿梭） |
| 不要写 | $3$ 和 $2$；$36$ 或 $38$ |

易错点：用口诀 $3$ 和 $2$ 加成 $36/38$；把复合体Ⅳ也写成泵 $4\mathrm{H}^{+}$；漏掉转运那 $1$ 个 $\mathrm{H}^{+}$；把 $30/32$ 的分叉写成“有没有氧”；把偶联部位写成 $\mathrm{ATP}$ 合酶或复合体Ⅱ。
