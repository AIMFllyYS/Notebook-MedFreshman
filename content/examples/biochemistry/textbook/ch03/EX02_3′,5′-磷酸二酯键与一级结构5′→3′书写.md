:::example{label="3′，5′-磷酸二酯键与一级结构5′→3′书写如何记"}
**题目**：相邻（脱氧）核糖核苷酸之间靠什么共价键连接，$3'$ 对的是哪一位，$5'$ 对的是哪一位？一条链的 $5'$-端和 $3'$-端各露出什么基团，新的磷酸二酯键只能由哪一端去打游离 $\mathrm{dNTP}$ 的哪一个磷酸，因此链有怎样的方向性？$\mathrm{RNA}$ 虽有 $2'$-羟基，磷酸二酯键一般还走哪两位，不要写成 $2',5'$ 骨架？核酸的一级结构怎样定义，为什么也就是碱基序列，图3-7 从骨架式到最简字母式如何写，默认方向是不是从左到右 $5'\rightarrow 3'$？单链用 $\mathrm{nt}$ 还是 $\mathrm{bp}$，双链用什么，短于 $50$ 个核苷酸常称什么，$n$ 个脱氧核苷酸有多少种排列？为什么不能把磷酸二酯键写成 $5'$ 对 $5'$，也不能把一级结构听成已经是双螺旋？

**解**：
教材 definition：**$3',5'$-磷酸二酯键是连接相邻脱氧核糖核苷酸（或核糖核苷酸）的共价键：上一核苷酸的 $\mathrm{C}$-$3'$ 羟基与下一核苷酸的 $\mathrm{C}$-$5'$ 磷酸之间形成磷酸二酯。** 教材 definition：**一端是连在 $\mathrm{C}$-$5'$ 上的磷酸基团，称为 $5'$-端；另一端是 $\mathrm{C}$-$3'$ 上的羟基，称为 $3'$-端。** 教材 definition：**多聚脱氧核苷酸链只能从它的 $3'$-端得以延长：已有链的 $3'$-羟基与游离 $\mathrm{dNTP}$ 的 $\alpha$-磷酸缩合，生成新的 $3',5'$-磷酸二酯键，新的 $3'$-端仍留羟基。** 由此 $\mathrm{DNA}$ 链有 $5'\rightarrow 3'$ 的方向性。教材 pitfall：**磷酸二酯键是 $3'$ 对 $5'$，不要写成 $5'$ 对 $5'$ 或 $2'$ 对 $5'$。** $\mathrm{cAMP}$ 的 $3',5'$-环磷酸是分子内成环，不是把核酸链焊成环状单体。

教材 definition：**$\mathrm{RNA}$ 同样在 $\mathrm{RNA}$ 聚合酶催化下通过 $3',5'$-磷酸二酯键连接，同样有 $5'\rightarrow 3'$ 方向性。** 教材 pitfall：**虽然核糖核苷酸的 $\mathrm{C}$-$2'$ 也有羟基，多聚核糖核苷酸的磷酸二酯键一般只能在 $\mathrm{C}$-$3'$ 与 $\mathrm{C}$-$5'$ 之间形成。** 教材把 $\mathrm{RNA}$ 与 $\mathrm{DNA}$ 的差别写成仅两点：①戊糖是核糖不是脱氧核糖；②嘧啶是 $\mathrm{C}$ 和 $\mathrm{U}$，一般没有 $\mathrm{T}$。构成 $\mathrm{RNA}$ 的 $4$ 种基本核苷酸是 $\mathrm{AMP}$、$\mathrm{GMP}$、$\mathrm{CMP}$ 和 $\mathrm{UMP}$。

教材 definition：**把 $\mathrm{RNA}$ 的核苷酸和 $\mathrm{DNA}$ 的脱氧核苷酸从 $5'$-端至 $3'$-端的排列顺序定义为核酸的一级结构。核苷酸之间的差异仅在于碱基不同，因此一级结构也就是碱基序列。** 图3-7：骨架式保留 $5'\mathrm{P}$ 与 $\mathrm{OH}\,3'$；含磷酸的字母式写成 $5'\,\mathrm{p}$-$\mathrm{ApGp}\ldots$-$\mathrm{OH}\,3'$；习惯上默认从左到右即 $5'\rightarrow 3'$，最简可只写碱基序列。不要从 $3'$ 往回念。教材 definition：**单链 $\mathrm{DNA}$ 和 $\mathrm{RNA}$ 用核苷酸数目（$\mathrm{nt}$）表示；双链 $\mathrm{DNA}$ 用碱基对数目（$\mathrm{bp}$ 或 $\mathrm{kb}$）。长度短于 $50$ 个核苷酸常称寡核苷酸。** $n$ 个脱氧核苷酸有 $4^{n}$ 种排列，遗传信息完全依靠碱基顺序，不依靠磷酸骨架的花样。教材 pitfall：**$\mathrm{nt}$ 用于单链，$\mathrm{bp}$ 用于双链。** 一条 $100\,\mathrm{nt}$ 的单链 $\mathrm{RNA}$ 是 $100$ 个核苷酸；一段 $100\,\mathrm{bp}$ 的双链 $\mathrm{DNA}$ 对应 $200$ 个核苷酸。教材 concept：**先问 $5'\rightarrow 3'$ 的碱基序列，再问双螺旋怎么配对。** 把一级结构听成“已经是双螺旋”，Chargaff 规则和 Watson-Crick 配对会没有需要解释的对象。

| 项目 | $\mathrm{DNA}$ 链 | $\mathrm{RNA}$ 链 |
|------|-------------------|------------------|
| 连接键 | $3',5'$-磷酸二酯键 | 同样是 $3',5'$-磷酸二酯键 |
| $2'$-羟基 | 无 | 有，但一般不参与链的磷酸二酯键 |
| 延长端 | $3'$-羟基打游离 $\mathrm{dNTP}$ 的 $\alpha$-磷酸 | $\mathrm{RNA}$ 聚合酶催化，方向同样 $5'\rightarrow 3'$ |
| 一级结构书写 | $5'\rightarrow 3'$ 的脱氧核苷酸排列 | $5'\rightarrow 3'$ 的核苷酸排列 |
| 大小单位 | 双链用 $\mathrm{bp}/\mathrm{kb}$ | 单链用 $\mathrm{nt}$ |

易错点：把磷酸二酯键写成 $5'$-$5'$ 或 $\mathrm{RNA}$ 的 $2',5'$；把延长听成在 $5'$-端加帽子；从 $3'$ 往回念一级结构；把 $\mathrm{nt}$ 和 $\mathrm{bp}$ 混着数；把一级结构听成已经是双螺旋。
