**题目**：启动子是结构基因本身还是调控序列里让 $\mathrm{RNA}\,\mathrm{pol}$ 结合的部位？$\mathrm{RNA}\,\mathrm{pol}$ 保护法先温育再加外切酶，留下的 $40\sim 60\,\mathrm{bp}$ 在起点上游还是下游？$-35$ 和 $-10$ 的一致性序列各是什么，谁叫 Pribnow 盒、哪一年发现？识别序列是结合最牢的那段吗？$-35$ 与 $-10$ 相隔多少，$ -10$ 与 $+1$ 相距多少？闭合复合体是酶还没碰到 $\mathrm{DNA}$ 吗，开放复合体解开约多少 bp？Pribnow 盒能不能答成真核 $\mathrm{TATA}$（Hognest）盒？

**解**：
教材 definition：**启动子是 $\mathrm{RNA}\,\mathrm{pol}$ 结合模板 $\mathrm{DNA}$ 的部位，也是决定转录起始点的关键部位。** 它在操纵子的调控序列里，不是结构基因本身。原核以全酶结合启动子而启动转录，$\sigma$ 辨认启动子，其他亚基配合。教材 pitfall：**启动子不是被转录成蛋白质的那段 $\mathrm{DNA}$。** 图15-4 上排左段是 $\mathrm{RNA}$ 聚合酶保护区，中段才是结构基因。

教材 definition：**$\mathrm{RNA}\,\mathrm{pol}$ 保护法**——提取的 $\mathrm{DNA}$ 与提纯的 $\mathrm{RNA}\,\mathrm{pol}$ 先混合温育，再加核酸外切酶；酶结合部位不被水解，留下 $40\sim 60\,\mathrm{bp}$，位于转录起点**上游**，即转录起始调节区。教材 keypoint：**先温育结合，再加外切酶，留下的片段在上游。**

教材 definition：**$-35$ 区一致性序列 $\mathrm{TTGACA}$**，是 $\mathrm{RNA}\,\mathrm{pol}$ 对转录起始的识别序列（recognition sequence），酶在这一区段与模板结合松弛。教材 definition：**$-10$ 区一致性序列 $\mathrm{TATAAT}$**，$1975$ 年 Pribnow D. 发现，称 Pribnow 盒。结合平衡常数表明酶结合 $-10$ 比结合 $-35$ 更牢固，形成相对稳定的复合物后即可开始转录。教材 definition：**启动子内部距离**——$-35$ 与 $-10$ 相隔 $16\sim 18$ 个核苷酸；$-10$ 与转录起点相距 $6$ 或 $7$ 个核苷酸。两区 $\mathrm{A}$-$\mathrm{T}$ 集中、只有两个氢键，所以容易解链。教材 pitfall：**识别序列不是结合最牢的那段。** $-35$ 叫 recognition sequence，结合却更松；更牢的是 $-10$。教材 pitfall：**间隔 $16\sim 18$ 不要记成 $-35$ 到 $+1$。** 把 $16\sim 18$ 安到 $-10$ 与 $+1$ 之间，Pribnow 盒就会被画到 $-20$ 附近。教材 pitfall：**$-10$ 不要写成真核 $\mathrm{TATA}$ 盒。** Pribnow 是原核 $-10$ 的 $\mathrm{TATAAT}$；真核 Hognest／$\mathrm{TATA}$ 盒是第三节的账，位置和配套因子都不同。

教材 definition：**闭合转录复合体**——酶已识别并结合启动子，$\mathrm{DNA}$ 仍保持完整双链。$\sigma$ 先认 $-35$ 的 $\mathrm{TTGACA}$（结合松弛），再移向 $-10$ 的 $\mathrm{TATAAT}$ 并跨过起点，形成稳定结合。教材 pitfall：**闭合不是“酶还没碰到 $\mathrm{DNA}$”。** 教材 definition：**开放转录复合体**——接近 $-10$ 区域的部分双螺旋解开后形成；无论起始还是延长，解开范围都只在约 $17\,\mathrm{bp}$，比复制叉小得多。教材 pitfall：**$17\,\mathrm{bp}$ 不是复制叉的尺寸。** 把转录泡画成大 $\mathrm{Y}$，延长节的 $8\,\mathrm{bp}$ 杂合双链会对不上。$+1$ 处常见 $\mathrm{pppG}$ 或 $\mathrm{pppA}$；翻译开始更在下游，不是同一点。

| | $-35$（$\mathrm{TTGACA}$） | $-10$（$\mathrm{TATAAT}$，Pribnow 盒） |
|--|---------------------------|----------------------------------------|
| 功能 | 识别序列 | 紧密结合，随后开链、开始转录 |
| 结合 | 松弛 | 更牢固（平衡常数） |
| 顺序 | 先被辨认 | 酶向下游移动后到达 |
| 与 $+1$ | 更远 | $6$ 或 $7$ 个核苷酸 |

易错点：启动子当成结构基因；保护法留下的片段放到下游；$-10/-35$ 序列对调；把识别听成抓得最紧；$16\sim 18$ 安错区间；Pribnow 答成真核 $\mathrm{TATA}$；闭合听成未结合。
