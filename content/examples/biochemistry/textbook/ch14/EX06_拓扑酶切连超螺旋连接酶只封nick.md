**题目**：解旋酶 DnaB、拓扑酶、连接酶是不是同一类“解开 $\mathrm{DNA}$ 的酶”？复制解链为什么一定会碰到超螺旋，旋转约多少次/s？拓扑酶 $\mathrm{I}$ 切几股、要不要 $\mathrm{ATP}$，拓扑酶 $\mathrm{II}$（促旋酶）切几股、再连接用不用 $\mathrm{ATP}$，起始阶段正超螺旋变成什么才更好当模板？拓扑酶是不是只在起始需要一次？连接酶连的是 $3'$-$\mathrm{OH}$ 与 $5'$-$\mathrm{P}$，耗不耗 $\mathrm{ATP}$，能不能把两条游离单链或 $\mathrm{RNA}$ 单链糊在一起？gap 和 nick 谁来填、谁来封？思考题第 $4$ 问：聚合酶、拓扑酶和连接酶都生成 $3'$，$5'$-磷酸二酯键，底物和场景怎样分户？

**解**：
教材 compare：**解旋酶和 SSB 不是同一个动作**；教材 pitfall：**拓扑酶不是解旋酶。** DnaB 利用 $\mathrm{ATP}$ 把双链分成两股单链，沿解链方向移动。$\mathrm{SSB}$ 把已解开的单链稳住，协同结合、不断结合—脱离，不沿复制方向滑行。拓扑酶改变超螺旋和连环，切的是磷酸二酯键再封上。把 gyrase 答成 helicase，表14-4 两行就并了。

教材 definition：**为什么复制一定会碰到超螺旋**——双螺旋沿轴旋绕，解链沿同一轴反向旋转，速度快（$100$ 次/s），叉前方会打结、缠绕、连环。一端若能自由转可以不形成超螺旋；两端固定或有蛋白挡住时，局部解开就会出超螺旋；复制蛋白前方为正超螺旋，后方为负超螺旋。教材 definition：**拓扑酶又能切又能连**——水解造成切口，下游链穿越并旋转把结打开，再连接复位。教材 definition：**拓扑酶 $\mathrm{I}$** 切断双链中的一股，使解链旋转不致打结，适时封闭切口变为松弛，无须 $\mathrm{ATP}$。教材 definition：**拓扑酶 $\mathrm{II}$（促旋酶 gyrase）** 切断处于正超螺旋的 $\mathrm{DNA}$ **双链**，使超螺旋松弛；再利用 $\mathrm{ATP}$ 供能，由同一酶把断端连接恢复。可解开螺旋、连环或解连环；母链与新链互相缠绕造成的打结或连环也需要它。教材 cause-effect（第三节）：起始阶段拓扑酶 $\mathrm{II}$ 把正超螺旋变为负超螺旋，负超螺旋模板作用更好。教材 pitfall：**不要写“拓扑酶只在起始需要”。** 原句：复制全过程都需要拓扑酶。一边解链一边复制。

教材 definition：**$\mathrm{DNA}$ 连接酶**连接一股 $\mathrm{DNA}$ 的 $3'$-$\mathrm{OH}$ 与相邻片段的 $5'$-$\mathrm{P}$，生成磷酸二酯键，把两段连成完整的链。需要 $\mathrm{ATP}$。只能连双链中的单链缺口，不能连单独存在的 $\mathrm{DNA}$ 单链或 $\mathrm{RNA}$ 单链。复制中接合冈崎片段之间的缺口；修复、重组同样接合缺口；两股都有单链缺口时只要缺口前后碱基互补也可连接，故为基因工程重要工具酶。教材 pitfall：**连接酶不能把两条游离单链糊在一起。** 教材 compare：**聚合酶填空隙 vs 连接酶封缺口。** gap 缺一段核苷酸（引物去掉后），由 $\mathrm{pol}\,\mathrm{I}$ 用 $\mathrm{dNTP}$ 从 $5'\rightarrow 3'$ 填；nick 只缺一个磷酸二酯键（$3'$-$\mathrm{OH}$ 紧挨 $5'$-$\mathrm{P}$），连接酶耗 $\mathrm{ATP}$ 封。先填到足够长度，仍留下 nick，再连接。不要让连接酶“聚合一段 $\mathrm{DNA}$”。教材 pitfall：**连接反应耗 $\mathrm{ATP}$，拓扑酶 $\mathrm{I}$ 封口不耗 $\mathrm{ATP}$。** 不要写成“凡是连磷酸二酯键都不耗能”。

思考题第 $4$ 问按教材：都生成 $3'$，$5'$-磷酸二酯键，底物和场景不同。$\mathrm{DNA}$ 聚合酶：引物或子链 $3'$-$\mathrm{OH}$ 与 $\mathrm{dNTP}$ 聚合，释放焦磷酸，用于链延长（及填空隙）。拓扑酶：先切断再连接，改变超螺旋，不断开成永久缺口。连接酶：只封双链中已有的单链缺口（$3'$-$\mathrm{OH}$ 对 $5'$-$\mathrm{P}$），耗 $\mathrm{ATP}$，不能把两条游离单链连起来。

| | 切／连什么 | 能量 | 场景 |
|--|------------|------|------|
| DnaB 解旋酶 | 把双链分成单链 | $\mathrm{ATP}$ | 向前解链 |
| 拓扑酶 $\mathrm{I}$ | 切一股再封 | 无须 $\mathrm{ATP}$ | 松弛、防打结 |
| 拓扑酶 $\mathrm{II}$ | 切两股再封 | 再连接用 $\mathrm{ATP}$ | 正 $\rightarrow$ 负；解连环 |
| 连接酶 | 封 nick | 耗 $\mathrm{ATP}$ | 冈崎片段最后一步 |

易错点：gyrase 并到 helicase；拓扑酶只写起始用一次；连接酶去填 gap 或连游离单链；gap 与 nick 倒序；三种酶都生成磷酸二酯键就并成一个反应。
