**题目**：下列英汉互译哪一组全部正确（　）。

**解**：
往年真题高频：amino acid 氨基酸；$K_\mathrm{m}$ 米氏常数；transformation 转化（导入细菌的转化，不是变形）；glycogen 糖原；plasmid 质粒；transcription 转录；biochemistry 生物化学；genetic engineering 基因工程；polymerase chain reaction（$\mathrm{PCR}$）聚合酶链式反应；lipoprotein 脂蛋白。2004 八年制再加 genome 基因组、oncogene 癌基因、biotransformation 生物转化、cis-acting element 顺式作用元件、$\mathrm{DNA}$ denaturation $\mathrm{DNA}$ 变性、bile pigment 胆色素、gene therapy 基因治疗。

| 英文 | 中文 |
|------|------|
| translation | 翻译 |
| replication | 复制 |
| trans-acting factor | 反式作用因子 |
| oxidative phosphorylation | 氧化磷酸化 |
| essential amino acids | 必需氨基酸 |

易错点：transformation 译成转染或变形；transcription / translation 对调；biotransformation 译成生物氧化。
