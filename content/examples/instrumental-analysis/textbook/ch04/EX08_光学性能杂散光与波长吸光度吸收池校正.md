**题目**：本版列出的八项光学性能里，波长范围、波长准确度、谱带宽度、分辨率、杂散光、光度准确度各写什么数字？波长重现性、光度重现性与相应准确度是什么关系？杂散光在哪些波长处统计、一般不超过多少，它是定律偏离因素还是仪器指标？波长校正用汞灯、氢灯、氘灯、钬玻璃各列哪些线？吸光度用什么溶液检定？吸收池怎样对调校正？超微量分光光度计本版给的样品量和浓度范围是多少？

**解**：
教材 memory 把八项收齐：波长范围一般 $200\sim 800\,\mathrm{nm}$（仪器性能，不要与第 1 节光区 $200\sim 760\,\mathrm{nm}$ 并句）；波长准确度一般 $\pm 0.5\,\mathrm{nm}$ 或更小；波长重现性约准确度的一半；狭缝／谱带一般 $0\sim 5\,\mathrm{nm}$ 可调；分辨率用最接近两谱线的 $\Delta\lambda$，愈小愈好；杂散光以 $200$ 或 $220\,\mathrm{nm}$、$310$ 或 $340\,\mathrm{nm}$ 等弱信号处的强度百分比为指标，一般可不超过 $0.5\%$；光度准确度透光率约 $\pm 0.5\%$ 或更小，$A=1$ 时 $\pm 0.005$ 以内，$A=0.5$ 时 $\pm 0.003$ 以内；光度重现性约为光度准确度误差范围的一半。

教材 definition：**杂散光是仪器光学性能指标，本版没有把它写进第 1 节“偏离朗伯–比尔定律的主要因素”。**

波长校正：汞灯 $237.83$、$275.28$、$313.16$、$365.02$、$453.83$、$576.96\,\mathrm{nm}$；氢灯 $379.79$、$486.13$、$656.28\,\mathrm{nm}$；氘灯 $486.02$、$656.10\,\mathrm{nm}$。教材 pitfall：**氢灯 $486.13$／$656.28$ 与氘灯 $486.02$／$656.10$ 不要并成同一对。** 钬玻璃 $279.4$、$287.5$、$333.7$、$418.5$、$536.2\,\mathrm{nm}$ 有尖锐吸收峰，来源不同会有微小差别。吸光度准确度用重铬酸钾的硫酸（$0.005\,\mathrm{mol}\cdot\mathrm{L}^{-1}$）检定，本版只写到这一句，不要补课外浓度表。吸收池 A 装样品、B 装参比测一次，洗净对调再测，差值小于 $1\%$，并多选几个波长。

超微量分光光度计：仅需 $1\sim 2\,\mu\mathrm{L}$，无须稀释，$6\sim 15\,000\,\mathrm{ng}/\mu\mathrm{L}$。

| 校正对象 | 本版做法 |
|----------|----------|
| 波长 | 汞／氢／氘原子线或钬玻璃吸收峰；测定前也要校 |
| 吸光度 | $\mathrm{K_2Cr_2O_7}$–$\mathrm{H_2SO_4}$（$0.005\,\mathrm{mol}\cdot\mathrm{L}^{-1}$） |
| 吸收池 | 对调两次，$A$ 差 $<1\%$，多波长 |

易错点：把 $200\sim 800\,\mathrm{nm}$ 写成光区定义；杂散光补进定律偏离；氢灯／氘灯校正线并户；吸收池只校一个 $\lambda_{\max}$。
