**题目**：光谱仪或分光光度计研究的是什么关系？三类光谱法共同的三个主要过程是什么？典型光谱仪由哪五个部分组成？图3-4里发射光谱仪、吸收光谱仪、荧光或散射光谱仪的部件顺序有何不同？样品相对单色器分别在哪？思考题要求绘制分光光度计基本结构示意图时默认画哪一条？为什么不能把五块口诀成“光源–样品–检测器”三块？

**解**：
教材 definition：**光谱仪或分光光度计（spectrophotometer）用来研究吸收、发射或荧光的电磁辐射强度和波长的关系。** 三个主要过程：①光源提供能量；②能量与待测物质相互作用；③检测相互作用时产生的信号。

教材 definition：**五个部分：光源、样品池、单色器、检测器和读出器件。**

教材 compare / 图3-4：
- （a）发射：样品在光源处被激发 → 单色器 → 检测器 → 读出器件／工作站（先发光再分光）。
- （b）吸收：光源 → 单色器 → 样品池 → 检测器 → 读出器件（先分光，单色光再打样品）。
- （c）荧光或散射：光源 → 单色器 → 样品池 → 另一单色器 → 检测器 → 读出器件（两边都有单色器，激发光与检测光常成角度）。

思考题第10题按图3-4（b）画吸收仪五块；题目写明荧光才画两台单色器。教材 pitfall：**不要把五块记成三块**——单色器和读出器件经常被口诀吃掉。吸收仪单色器在样品前，荧光仪有两台单色器。

易错点：发射仪也画成“光源–单色器–样品”；荧光漏掉第二台单色器；把工作站／读出器件丢掉；用第4章双光束紫外仪的细节替换本章总论图。
