**题目**：同源异形框有多少碱基、编码多少氨基酸的什么结构域、其中哪一段识别 DNA 大沟？果蝇 HOM-C 由哪两个复合体组成、在哺乳动物中重复为几簇、人的四簇分别在哪号染色体？这些基因的染色体排列顺序与体内时空表达怎样对应？*HOM* 突变导致什么、双翅膀果蝇是哪一节变成了哪一节？为什么不能把 Hox 只写成“又一种转录因子”？

**解**：
果蝇触角足复合体（Antennapedia complex，Antp）基因的 cDNA 探针不仅与 *Antp* 杂交，也与相邻的 *ftz* 杂交，提示二者含有一个共同 DNA 片段。序列分析显示这个共同片段为 $180\,\mathrm{bp}$，编码高度同源的 $60$ 个氨基酸。教材 definition：**同源异形框基因含有一段高度保守的 $180\,\mathrm{bp}$ 同源异形框，编码 $60$ 个氨基酸的同源异形结构域。同源异形结构域蛋白作为转录因子，把胚胎细胞沿前–后轴分成不同区域，并决定各主要区域器官的形态建成。果蝇为 *HOM* 基因，脊椎动物为 *Hox* 基因。**

同源异形结构域蛋白含同源异形结构域和特异结构域：特异结构域通常靠近 N 端，同源异形结构域靠近 C 端。由 $60$ 个氨基酸组成的同源异形结构域是一种拐弯的螺旋–环–螺旋（HLH）立体结构，其中第 $42\sim 50$ 位的 $9$ 个氨基酸与 DNA 大沟相吻合，识别所控制基因启动子中的应答元件。迄今已发现同源异形框基因 $300$ 多种，从酵母到人类均有。

果蝇 *HOM* 基因位于 $3$ 号染色体，由触角足复合体和双胸复合体组成，二者所在区域称为同源异形复合体（HOM-C）。进化中果蝇 *HOM* 在哺乳动物中重复了 $4$ 次：*Hox-A*、*Hox-B*、*Hox-C*、*Hox-D*，分别定位于人的 $7$、$17$、$12$ 和 $2$ 号染色体（小鼠为 $6$、$11$、$15$ 和 $2$ 号）。*HOM* 或 *Hox* 基因在染色体上的排列顺序与其体内不同时空表达模式相对应：越靠近前部的基因表达越早，靠近后部的基因表达越迟；头区最前叶只表达该基因簇的第一个基因，身体最后部则表达基因簇的最后一个基因。

| 项目 | 内容 |
|------|------|
| 同源异形框 | $180\,\mathrm{bp}$ → $60$ 氨基酸同源异形结构域；第 $42\sim 50$ 位认 DNA 大沟 |
| 果蝇 | $3$ 号染色体 HOM-C = 触角足复合体 + 双胸复合体 |
| 哺乳动物 | 四簇 Hox；人：$7$、$17$、$12$、$2$ 号染色体 |
| 共线性 | 染色体 $3'\to 5'$ 的排列 = 身体从前到后 = 从早到晚打开 |
| 突变 | 同源异形转化：果蝇第三胸节变为第二胸节，长出第二对翅膀 |

当 *HOM* 基因突变时，可发生同源异形转化（homeosis）：与发育有关的某一基因错误表达，导致一种器官生长在错误部位。典型读出是双翅膀果蝇——第三胸节转变为第二胸节，形成像第二胸节一样的翅膀。

教材 concept：**Hox 的染色体顺序就是身体的前–后顺序。** 不必把 *lab*、*Antp*、*Ubx* 的名字逐个背成孤立单词。先记住共线性：基因在染色体上从 $3'$ 到 $5'$ 的排列，对应身体从前到后的表达，也对应从早到晚的打开。突变把后部基因错开在前部，器官就会长错地方。把 Hox 只写成“转录因子”，会漏掉这张身体蓝图。

易错点：把 $180\,\mathrm{bp}$ 和 $60$ 氨基酸写反；漏写第 $42\sim 50$ 位认大沟；把人的四簇染色体号记错；以为四个 Hox 簇是随机散在；把双翅膀写成触角变成腿这一种（教材此处读出的是胸节身份）；漏写共线性。
