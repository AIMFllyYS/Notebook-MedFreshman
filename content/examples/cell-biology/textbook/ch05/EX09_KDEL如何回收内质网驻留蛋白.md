**题目**：网质蛋白有什么共同的 C 端信号？BiP、钙连蛋白、PDI 各做什么？驻留蛋白若逃到高尔基复合体，由哪种有被小泡、经什么受体遣返？这与溶酶体酶的 M-6-P 分选在方向上有何不同？信号肽被切除后，驻留靠的还是 N 端信号肽吗？

**解**：
第一节定义：**网质蛋白（reticuloplasmin）** 是普遍存在于内质网腔中的一类可溶性蛋白，共同特点是多肽链 **C 端含有 KDEL（Lys-Asp-Glu-Leu）或 HDEL（His-Asp-Glu-Leu）四肽驻留信号（retention signal）**。该信号与内质网膜上相应受体识别结合，使蛋白驻留于内质网腔而不被转运走。教材把 KDEL 比作“请把我留在内质网”的邮编。

**主要网质蛋白 / 分子伴侣**
- **BiP**：与 Hsp70 同源的单体非糖蛋白，阻止聚集或不可逆变性，协助折叠。
- **内质蛋白（GRP94）**：含量丰富的二聚体糖蛋白，参与新生肽折叠转运，并可结合 $\mathrm{Ca}^{2+}$。
- **钙网蛋白**：高/低亲和 $\mathrm{Ca}^{2+}$ 位点，参与钙平衡、折叠、抗原呈递等。
- **钙连蛋白**：$\mathrm{Ca}^{2+}$ 依赖的凝集素样伴侣，结合尚未折好的寡糖链，避免凝集与泛素化，阻止未折好蛋白离开内质网。
- **PDI**：催化二硫键交换，保证正常折叠。

分子伴侣帮助折叠、组装和转运，**自身不成为最终产物的组分**。腔内未折叠蛋白积聚时，通过 **UPR** 上调分子伴侣表达；过强或过久的内质网应激可走向凋亡。

**逃逸与回收（与第五节衔接）**
分泌蛋白要离开内质网，驻留蛋白必须留下。没有这段四肽，分子伴侣就会被错误地分泌出去。即便有 KDEL，仍可能有少量驻留蛋白从内质网“漏”到高尔基。进入高尔基后仍会被甄别、捕捉：腔面 **KDEL 受体**结合逃逸的可溶性驻留蛋白，装入 **COPⅠ有被小泡**，**逆向**运回内质网。COPⅡ则负责把新合成的分泌蛋白、溶酶体酶前体等**顺向**送到高尔基。

与 M-6-P 的对比：M-6-P 是溶酶体酶在 TGN 的“去溶酶体”正向分选信号；KDEL 是内质网腔蛋白的“请送回 ER”回收信号。二者都靠腔面受体捕获货物，但衣被、方向和目的地都不同。

信号肽在转位进入内质网时即被信号肽酶切除，后续驻留**不再依赖 N 端信号肽**，而依赖 C 端 KDEL/HDEL（或膜蛋白上的其他回收基序）。把“进入 ER”和“留在 ER”混成同一个信号，是概念性错误。

易错点：把 KDEL 写成 N 端序列；把回收衣被写成 COPⅡ或网格蛋白；以为驻留蛋白绝对不会离开内质网，因而否认回收途径。
