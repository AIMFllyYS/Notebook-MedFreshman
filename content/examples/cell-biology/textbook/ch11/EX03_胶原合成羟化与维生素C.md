:::example{label="胶原如何在细胞内做成前胶原、又为何缺维生素 C 会出血"}
**题目**：胶原约占人体蛋白质总量的多少？原胶原的外形和 Gly-X-Y 重复有何约束？前 $\alpha$ 链在哪里合成、脯氨酸和赖氨酸在哪里被羟基化、维生素 C 扮演什么角色？前肽在何时被谁切掉？原纤维 $67\,\mathrm{nm}$ 横纹从哪来？Ⅳ 型胶原为什么不织成绳子？成骨不全和埃勒斯-当洛综合征各打哪一步？

**解**：
胶原是体内含量最丰富的蛋白质，约占人体蛋白质总量的 25% 以上，由 3 条 $\alpha$ 链盘绕成 3 股螺旋。典型分子呈纤维状，长 $300\,\mathrm{nm}$、直径 $1.5\,\mathrm{nm}$，称为**原胶原**（tropocollagen）。每条 $\alpha$ 链甘氨酸约占 1/3，脯氨酸和羟脯氨酸合计约占 1/4，并以 Gly-X-Y 三肽重复：X 常为脯氨酸，Y 常为羟脯氨酸或羟赖氨酸。教材 concept：**Gly-X-Y 让甘氨酸钻进螺旋轴心**——轴心只能容纳最小的侧链，甘氨酸突变因此特别伤骨骼。Ⅰ 型是异源三聚体 $[\alpha 1(\text{Ⅰ})]_2[\alpha 2(\text{Ⅰ})]$；Ⅱ、Ⅲ 型分别是同源三聚体。人有 42 个 $\alpha$ 链基因，目前只发现 27 型。

合成与组装必须把“细胞内做成可溶分子、细胞外才织纤维”分开：

1. **细胞内。** 糙面内质网核糖体合成前 $\alpha$ 链，两端各有一段不含 Gly-X-Y 的前肽。进入内质网腔后信号肽被切除，脯氨酸和赖氨酸被羟基化为羟脯氨酸和羟赖氨酸；脯氨酰 3-羟化酶和脯氨酰 4-羟化酶都以**维生素 C** 为辅助因子。羟基化是链间交联、形成稳定 3 股螺旋的必要条件。随后 3 条前 $\alpha$ 链的 C 端前肽借二硫键对齐，从 C 端向 N 端聚合成 3 股螺旋，即**前胶原**（procollagen）。前肽使分子在细胞内不能聚成纤维，是防止细胞内纤维化的安全销。前胶原经高尔基复合体进一步糖基化后分泌。
2. **细胞外。** 两种 $\mathrm{Zn}^{2+}$ 依赖性前胶原 N-蛋白酶和 C-蛋白酶切去两端前肽，保留一小段端肽区，形成原胶原。原胶原按 1/4 长度（约 $67\,\mathrm{nm}$）交错平行排列，前后分子首尾相隔 $35\,\mathrm{nm}$，电镜下出现典型的 $67\,\mathrm{nm}$ 明暗相间周期性条纹。原纤维直径 $10\sim 300\,\mathrm{nm}$，再聚集成直径约 $0.5\sim 3.0\,\mu\mathrm{m}$、光镜下可见的胶原纤维。

**Ⅳ 型胶原织网不织绳。** $\alpha$ 链不含规则 Gly-X-Y，不形成典型 $\alpha$ 螺旋；分泌后前肽不被切除；两个分子羧基端头对头相接成二聚体，再交联成二维网络，构成基膜骨架。看见“胶原”不要默认一定有 $67\,\mathrm{nm}$ 横纹。Ⅶ 型是复层鳞状上皮下方的锚定纤维，ⅩⅦ 型在半桥粒。

维生素 C 缺乏时，羟基化不充分，不能形成稳定 3 股螺旋，新合成的链在细胞内被降解；原先存在于基质及血管中的正常胶原逐渐丧失。结果是组织胶原缺乏，血管、肌腱、皮肤脆性增加，皮下和牙龈易出血、牙齿松动——这是**合成障碍**，不是“血管自己破了”。成骨不全因编码 Ⅰ 型胶原 $\alpha 1$（Ⅰ）或 $\alpha 2$（Ⅰ）的基因突变；埃勒斯-当洛综合征因缺乏一种切除前肽的酶，前胶原不能组装为高度有序的纤维，关节活动过度，皮肤、肌腱、血管变脆。

易错点：把羟基化写成胞外步骤；把维生素 C 写成胶原的组成氨基酸；把前肽切掉写成在内质网里完成；把 Ⅳ 型也写成有横纹的纤维；把坏血病写成凝血因子缺乏。
