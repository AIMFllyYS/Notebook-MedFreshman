:::example{label="Bcl-2家族如何决定细胞色素c是否释放而不是把抗凋亡和促凋亡写成同一句话"}
**题目**：Bcl-2 家族蛋白大多定位于哪里、含哪些同源结构域？抗凋亡成员和促凋亡成员各有哪些、二者怎样相互拮抗？Bcl-2 和 Bax 对细胞色素 c 释放各起什么作用？p53 在 DNA 损伤后怎样经 NOXA/PUMA 接到线粒体途径、$p53$ 在肿瘤中的突变频率如何？IAP 怎样抑制 caspase、线粒体释放的哪两种蛋白解除这道刹车？凋亡过低和过多各写成哪些疾病？为什么不能把 Bcl-2 只当成 B 细胞淋巴瘤才有的癌基因？

**解**：
教材 definition：**Bcl-2 家族是调控 MOMP 的线粒体膜蛋白家族，含 BH 同源结构域。** $Bcl$-$2$ 是 B 细胞淋巴瘤/白血病-2 的缩写，但其不仅存在于 B 细胞淋巴瘤中，也见于几乎所有正常组织。家族成员大多包含 BH1～4 同源结构域，部分成员只有 BH3 结构域，大部分成员的 C 端还有一个穿膜结构域，帮助其插入细胞器膜。很多 Bcl-2 家族蛋白如 Bcl-2、Bax、Bcl-XL 都定位于线粒体膜上。

抗凋亡成员包括 Bcl-2、Bcl-XL 和 Mcl-1；促凋亡成员包括 Bax、Bak、Bok 以及 Bad、Bid、Bim 等 BH3-only 蛋白。这两类蛋白质通过同源结构域相互作用、相互拮抗，诱导或抑制 MOMP 和细胞色素 c 从线粒体的释放。例如，Bcl-2 通过阻止细胞色素 c 从线粒体释放来抑制凋亡；而 Bax 则通过与线粒体上的膜通道结合，促使细胞色素 c 释放而促进凋亡。衰老细胞中抗凋亡的 Bcl-2 家族蛋白水平也会上升，所以衰老细胞停在周期外却不容易死。

| 调控层 | 分子 | 作用 |
|--------|------|------|
| MOMP 开关 | Bcl-2/Bcl-XL/Mcl-1 vs Bax/Bak/Bok/Bad/Bid/Bim | 拮抗决定细胞色素 c 是否释放 |
| 核损伤接口 | p53 转录 NOXA、PUMA | 与 Bcl-2 家族作用，触发 MOMP |
| caspase 阈值 | IAP（cIAP1、cIAP2、xIAP）vs Smac/Diablo、Omi | IAP 泛素化降解 caspase-9/3/7；Smac/Omi 解除刹车 |

p53 是重要的应激感受分子。作为转录因子，DNA 损伤后它激活检查点、促进修复；同时诱导 $NOXA$ 和 $PUMA$ 等促凋亡基因，经 Bcl-2 家族触发线粒体途径。损伤可逆时细胞停在 $\mathrm{G}_1$ 修复；损伤不可逆或不稳定基因组则走凋亡被清除。第一节的衰老和这里的凋亡，是 p53 对同一损伤的两条出路。$p53$ 是肿瘤中突变频率最高的基因；放化疗诱导凋亡也依赖它。

IAP 定位于细胞质，具有泛素 E3 连接酶活性，通过对 caspase-9、3、7 的泛素化修饰抑制 caspase 激活。线粒体途径激活时释放的 Smac/Diablo 和 Omi 是 IAP 的抑制蛋白。在一些死亡受体途径中，也需要线粒体释放的 Smac/Diablo、Omi 才能解除对 caspase-3 的抑制。促凋亡药物开发因此对准 IAP 小分子抑制剂和 Smac 类似物。

凋亡过低：肿瘤（$p53$ 突变或缺失，高表达 FasL、低表达 Fas 以逃逸免疫）；SLE（Fas 表达缺陷，自身反应性 $\mathrm{CD}4^{+}$、$\mathrm{CD}8^{+}$ T 淋巴细胞凋亡障碍）。凋亡过度：神经退行性疾病（caspase-3 既介导凋亡又与 AD/PD/亨廷顿病致病蛋白相互作用；$\beta$ 淀粉样蛋白诱导神经元凋亡，可被抗氧化剂阻断；NAIP 突变致脊髓前角运动神经元凋亡）；AIDS（gp120 与 $\mathrm{CD}4^{+}$ T 细胞结合诱导凋亡，并对 TRAIL/FasL 特别敏感）；心血管疾病（血管平滑肌细胞和巨噬细胞凋亡；传导系统细胞过多凋亡致心功能不全）。

易错点：把 Bcl-2 只写成淋巴瘤癌基因；把抗凋亡和促凋亡成员记反；漏写 p53→NOXA/PUMA；把 IAP 当成促凋亡蛋白；把 MOMP 和 mPT 混成一个孔；只背肿瘤、漏写 SLE 与 AIDS。
