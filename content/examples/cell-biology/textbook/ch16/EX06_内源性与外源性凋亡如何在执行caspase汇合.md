:::example{label="内源性与外源性凋亡如何在执行caspase汇合而不是两条永不相交的路"}
**题目**：外源性（死亡受体）途径的配体和受体有哪些、激活平台叫什么、起始 caspase 是哪一个？内源性（线粒体）途径的早期决定性改变是什么、细胞色素 c 与谁装配成凋亡体、起始 caspase 是哪一个？两条路在哪里汇合、caspase-8 怎样经 Bid 把外源信号灌进线粒体？内质网的 $\mathrm{Ca}^{2+}$ 和 caspase-12 怎样参与？为什么不能把“死亡受体”自动翻译成一定走凋亡？

**解**：
诱导凋亡的信号可来源于细胞内或细胞外。细胞外信号通过膜表面死亡受体介导，称为死亡受体途径，也称为外源性途径；细胞内损伤通过线粒体释放促凋亡物质起始，称为线粒体途径，也称为内源性途径。两条路在执行 caspase-3、6、7 汇合。

教材 definition：**死亡诱导信号复合体（DISC）是外源性凋亡中由死亡受体、衔接蛋白 FADD 和 caspase-8 酶原组成的多聚平台。** 以 Fas 为例：FasL 结合 Fas 胞外区引起受体寡聚化 → Fas 胞质死亡结构域（DD）招募 FADD → FADD 氨基端死亡效应结构域暴露并结合 caspase-8 酶原 → Fas–FADD–caspase-8 装配成 DISC，caspase-8 互相剪切而活化 → 活性 caspase-8 剪切 caspase-3、6、7。配体属 TNF 家族（TNF-$\alpha$、FasL、TRAIL）；受体属 TNF 受体超家族（TNFR1、Fas/Apo-1/CD95、DR-4、DR-5）。

教材 definition：**线粒体外膜通透作用（MOMP）是内源性凋亡的早期决定性改变：Bax/Bak 在线粒体外膜寡聚成孔，膜间腔的细胞色素 c、Smac/Diablo、AIF 等释放。** 细胞色素 c 与 Apaf-1、dATP 和 caspase-9 酶原装配凋亡体，是 caspase-9 的激活平台。活化的 caspase-9 再剪切执行 caspase。DNA 损伤、氧化剂、药物等都可以直接或间接走到这一步。

| 项目 | 外源性（死亡受体）途径 | 内源性（线粒体）途径 |
|------|------------------------|------------------------|
| 信号来源 | 细胞外：TNF-$\alpha$、FasL、TRAIL 等 | 细胞内：DNA 损伤、氧化剂、药物等 |
| 激活平台 | DISC（受体–FADD–caspase-8） | 凋亡体（cyt c–Apaf-1–dATP–caspase-9） |
| 起始 caspase | caspase-8（及 10） | caspase-9 |
| 决定性事件 | 配体结合后 DISC 装配 | MOMP 与细胞色素 c 释放 |
| 与另一条路的桥梁 | caspase-8 切 Bid → tBid 插入线粒体 | 执行 caspase 被两侧共用 |
| 共同终点 | 执行 caspase-3、6、7 剪切 ICAD、PARP-1、核纤层和微丝 | 同左 |

caspase-8 催化 Bid 裂解，含 BH3 结构域的 C 端片段（tBid）插入线粒体膜，引起细胞色素 c 释放，沟通了两条途径。内质网也参与：凋亡早期胞质 $\mathrm{Ca}^{2+}$ 升高（外流内流加内质网释放），可影响 MOMP；内质网膜上的 Bcl-2 维持 $\mathrm{Ca}^{2+}$ 稳定、抑制凋亡；$\mathrm{Ca}^{2+}$ 升高等可激活内质网膜上的 caspase-12，再参与 caspase-9 介导的凋亡。MOMP 是外膜 Bax/Bak 成孔、放细胞色素 c；mPT 是内膜电位塌陷、放 $\mathrm{Ca}^{2+}$。两件事都写在线粒体上，不要并成一个孔。

教材 concept：**同一扇 TNF 的门，通向凋亡或坏死性凋亡。** 第四节补了一句：caspase-8 被抑制时，门后站着 RIPK1/RIPK3。不要把“死亡受体”自动翻译成凋亡；先问 caspase-8 还能不能装配。

易错点：把 DISC 和凋亡体的成员写串；把 caspase-8 和 caspase-9 的归属写反；漏写 tBid 桥梁；把 MOMP 和 mPT 并成一个孔；以为死亡受体结合后只能凋亡。
