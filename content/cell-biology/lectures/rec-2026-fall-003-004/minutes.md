## 一、单细胞生物学

### 1.1 为什么需要单细胞生物学

- **传统方法的局限**：将整个组织/器官的细胞混合分析，得到的是"混合信号"（黑盒子）
  - 例：敲除肝脏某基因后观察表型，无法判断是哪种肝细胞出了问题
  - 知道输入端和输出端，中间过程不清楚
- **单细胞生物学**：对组织中每个细胞（功能单元）单独分析，再组合信息
  - 肝脏中有多种细胞（肝细胞、胆管上皮细胞、Kupffer细胞、星状细胞等），空间分布不同
  - 每个细胞的基因/蛋白/代谢物表达水平不同

### 1.2 空间组学（Spatial Omics）

- 在单细胞分析基础上，增加**空间位置信息**
- 输出：三维空间数据——不仅知道每个细胞的表达水平，还知道它在组织中的位置
- 应用：
  - **发育**：从一个细胞→组织→器官，追踪细胞分化过程（像看电影，有时间有空间）
  - **疾病**：正常肝 vs 病人肝，定位是哪种细胞类型出了问题，问题出在哪个层面（DNA/RNA/蛋白/脂类/代谢物）

### 1.3 当前局限

- 组学数据量大，常用AI/大数据构建空间网络
- 但人很难从海量数据中捕捉到底层机制
- 大量文章（包括CNS主刊）结论较弱——"开了头但没闭环"
- 做到80%就停下来，剩下20%留给其他实验室（但其他实验室很难跟上）
- **未来趋势**：各种组学最终要回归分子机制层面

## 二、组学概述

### 2.1 筛选——生物学研究的核心方式

- 生物学/生物医学的绝大部分发现是**筛选**出来的
- **随机筛选**：无偏差、不带主观意识地找到目标
- 传统筛选：遗传学筛选、蛋白筛选
- 局限：很多东西筛不到（脂类、代谢物、表达变化不明显的、功能冗余的基因）
- **组学 = 筛选的高阶阶段**：更全面、无偏差的筛选方式

### 2.2 各类组学

| 组学 | 研究对象 | 说明 |
|---|---|---|
| **基因组学**（Genomics） | DNA全序列 | 最早，人类基因组计划；30亿碱基，2万多基因；几十亿美元→几千元 |
| **转录组学**（Transcriptomics） | RNA表达水平 | 基因转录产物 |
| **表观组学**（Epigenomics） | DNA/蛋白化学修饰 | DNA甲基化、组蛋白修饰、泛素化、磷酸化等；不是100%遗传，更像生化传递 |
| **蛋白质组学**（Proteomics） | 蛋白质表达水平 | 无偏差（全蛋白）vs 靶向（蛋白互作组） |
| **代谢组学**（Metabolomics） | 代谢物小分子 | 糖/脂/氨基酸/小分子代谢；除能量外还调控表观转录 |
| **脂质组学**（Lipidomics） | 脂质 | 脂类物质 |
| **单细胞组学** | 单个细胞的多组学 | 与上述组学结合 |

### 2.3 基因组学的发展

- 人类基因组计划（HGP）：90年代启动，全世界合作，花了约30亿美元，十几年
- 现在：抽一滴血，两天测完，几千元人民币
- 效率提升了千万倍
- 未来诊断学要求：快速、便宜

### 2.4 表观遗传学

- 虽然叫"遗传学"，但**不是传统意义上的遗传**
- 传统遗传：DNA序列从父辈→子代，100%忠实传递
- 表观遗传：在DNA/蛋白质上进行化学修饰，可以从父母传递到子代，但**不是100%传递**，有选择性
- 更像一种"生化传递"
- 重要性：在发育、疾病过程中，修饰改变对机制影响很大
- 类型：DNA甲基化、组蛋白修饰（乙酰化/甲基化）、泛素化、SUMO化、磷酸化等
- 有限的蛋白通过修饰变成多种功能类型

### 2.5 蛋白质组学

- 一个细胞中有百万种蛋白
- **无偏差蛋白组学**：提取全部蛋白，质谱分析，得到每种蛋白表达水平
- **靶向蛋白组学**：已知一个蛋白，拉取与其结合的所有蛋白，得到蛋白互作网络
- 空间蛋白组学：只检测特定区域的蛋白

### 2.6 代谢组学

- 代谢物：糖代谢、脂代谢、氨基酸代谢、小分子代谢
- 为什么关注代谢物？除了提供能量，还可能调控表观遗传、转录等
- 代谢是生命的底层逻辑——没有代谢就是死的东西

## 三、教师强调与易错点

1. **单细胞生物学解决"混合信号"问题**：传统方法是黑盒子，单细胞分析每个功能单元。
2. **空间组学 = 单细胞 + 空间位置**：三维数据，信息量更大。
3. **组学是筛选的高阶阶段**：传统筛选筛不到的东西（脂类、代谢物、功能冗余基因）需要组学。
4. **表观遗传不是100%遗传**：是化学修饰的选择性传递，更像生化传递。
5. **目前组学文章结论弱**：数据多但机制研究不足，未来要回归分子层面。
6. **人类基因组计划费用变化**：30亿美元/十几年 → 几千元/2天。
7. **代谢是生命底层逻辑**：没有代谢就是死的。

## 五、主动回忆题

**Q1. 为什么传统的基因敲除实验被称为"黑盒子"？单细胞生物学如何解决这个问题？**
传统方法将整个组织的所有细胞混合分析，敲除某基因后观察到的表型是所有细胞的混合结果，无法判断具体是哪种细胞出了问题——知道输入和输出，中间过程不清楚。单细胞生物学对组织中每种细胞单独分析，得到每个功能单元的信息后再组合，就能理解输入和输出之间发生了什么。

**Q2. 表观遗传为什么"虽然叫遗传，但不是遗传"？**
传统遗传是DNA序列从父辈到子代100%忠实传递。表观遗传是在DNA或蛋白质上进行化学修饰（如甲基化、乙酰化），这些修饰可以传递给子代，但不是100%传递，有选择性。因此它更像一种"生化传递"，而非传统意义上的遗传。

**Q3. 为什么说组学是筛选的高阶阶段？**
生物学研究的核心方式是筛选。传统筛选（遗传学筛选、蛋白筛选）有局限——脂类、代谢物、表达变化不明显的、功能冗余的基因都筛不到。组学技术能更全面、无偏差地分析所有分子（DNA/RNA/蛋白/代谢物/脂类），是筛选技术的更高阶发展阶段。
