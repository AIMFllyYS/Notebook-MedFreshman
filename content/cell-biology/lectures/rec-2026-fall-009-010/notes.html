知识结构总览

内膜系统内质网(RER/SER) → 高尔基体(cis/medial/trans/TGN) → 溶酶体 → 过氧化物酶体

囊泡运输出芽(包被蛋白) → 脱包被 → 长距离运输(马达蛋白) → 对接(Rab) → 融合(SNARE)

核心机制信号肽假说(SRP→Sec61) | M6P分选(溶酶体) | KDEL回收(ER驻留蛋白)

一、内质网的结构与功能

1.1 分类与结构连通性

粗面内质网RER扁平囊状，膜外附着核糖体，分泌蛋白合成主要场所
光面内质网SER管状结构，无核糖体，脂质合成与解毒
二者关系同一细胞器的不同功能形态，膜系统连续连通
RER与核膜外层相连，ER腔与核间隙直接连通

1.2 微粒体体系（研究工具）

定义细胞匀浆后ER脂双层自封闭形成的小型囊泡，非天然细胞器
分离蔗糖密度梯度离心，分离粗面微粒体（有核糖体，密度大）和光面微粒体
应用微粒体体外重构体系是验证信号肽假说的核心工具，获诺贝尔奖

1.3 化学组成与驻留信号

膜蛋白占60%-70%
脂类占30%-40%，以磷脂为主，胆固醇/鞘磷脂远低于质膜
驻留信号ER腔驻留蛋白C端带KDEL/HDEL信号，逃逸后被高尔基体KDEL受体识别经COPI回收

1.4 光面内质网功能

基础功能所有膜脂（磷脂、胆固醇）合成场所
肝细胞药物解毒，依赖细胞色素P450
肌细胞钙储存与释放（肌质网），调控肌肉收缩
类固醇细胞类固醇激素合成

二、信号肽假说与共翻译转位

2.1 信号肽假说完整流程

分泌蛋白N端信号肽 → SRP识别 → 暂停翻译 → ER膜SRP受体 → Sec61通道 → 共翻译转位
信号肽分泌蛋白N端的疏水氨基酸序列，是进入分泌途径的标签
SRP信号识别颗粒，识别信号肽后暂停翻译，引导核糖体至ER膜
Sec61ER膜上的转位通道，新生肽通过此通道进入ER腔
共翻译转位边翻译边转运，翻译和转运同时进行
信号肽在N端，SRP识别停翻译；内质网膜上Sec61，共翻译转位进腔里。

三、蛋白折叠质量控制与糖基化

3.1 蛋白折叠与质量控制

分子伴侣BipHsp70家族，协助新生肽折叠
PDI蛋白二硫键异构酶，催化二硫键形成与重排
ERAD内质网相关降解，错误折叠蛋白逆向转运回胞质→蛋白酶体降解
⚠️ 囊性纤维化ΔF508突变：CFTR蛋白错误折叠→ERAD提前降解→细胞膜CFTR不足→氯离子转运障碍

3.2 N-糖基化 vs O-糖基化

特征N-糖基化O-糖基化
场所内质网高尔基体
方式14糖基整体添加糖基逐个添加
连接原子天冬酰胺侧链氮原子丝氨酸/苏氨酸侧链羟基氧原子

四、高尔基体的结构与功能

4.1 极性特征

顺面cis
(接收ER物质) → 中间层
(加工) → 反面trans
(分选输出) → TGN
(反面管网)
结构极性顺面接收→中间加工→反面分选输出
化学极性不同膜囊区域分布特异性糖苷酶/糖基转移酶，逐级有序加工

4.2 修饰与分选功能

O-糖基化高尔基体完成，糖基逐个添加至丝氨酸/苏氨酸羟基氧
蛋白水解加工胰岛素原C肽切除在分泌颗粒；白蛋白原水解在TGN
TGN分选三条输出路径：①溶酶体(M6P→网格蛋白囊泡) ②质膜(组成型分泌) ③调节性分泌囊泡(等待信号)

五、溶酶体与M6P分选机制

5.1 M6P分选完整流程

RER合成
+N-糖基化 → 顺面高尔基体
添加M6P → TGN
M6P受体识别 → 网格蛋白囊泡
→内体 → 酸性环境
受体配体分离 → 溶酶体
溶酶体环境单层膜，pH 4.5-5.0酸性，膜蛋白高度糖基化防自身降解
M6P标记水解酶N-糖链在顺面高尔基体被添加甘露糖-6-磷酸（M6P）
⚠️ M6P标记缺失→水解酶分泌至胞外→溶酶体酶缺失→底物积累→I细胞病（粘脂贮积症II型）
溶酶体酸四点五，M6P标记是关键；顺面高尔基体加上，TGN受体网格囊；内体酸来受体回，I细胞病因标记缺。

六、过氧化物酶体

标志性酶氧化酶（氧化底物产H₂O₂）+ 过氧化氢酶（将H₂O₂歧化为水和氧气）
核心功能脂肪酸β-氧化（超长链脂肪酸）、解毒、活性氧代谢
蛋白转运胞质游离核糖体合成后，经PTS信号识别转运进入（不含DNA/核糖体）

七、三类包被蛋白

包被类型运输方向功能
COPIIER → 高尔基体（顺向）内质网输出囊泡
COPI高尔基体 → ER（逆向）+ 高尔基体膜囊间回收逃逸蛋白（KDEL）、Golgi内运输
网格蛋白TGN → 内体 + 质膜 → 内体溶酶体分选（M6P）、受体介导胞吞
包被蛋白9字功能：货物选择与膜芽的塑形上
COPII顺向ER走，COPI逆向回收留；网格蛋白两头跑，TGN内体质膜收。

八、囊泡运输全流程

①出芽
(包被蛋白) → ②脱包被 → ③长距离运输
(细胞骨架+马达蛋白) → ④初始对接
(Rab GTPase) → ⑤膜融合
(SNARE)
出芽包被蛋白选择货物+膜芽塑形
脱包被囊泡形成后包被解离，暴露融合蛋白
长距离运输不依赖随机扩散，依托细胞骨架+马达蛋白拖拽
初始对接Rab GTPase作为囊泡身份标识，介导与靶膜初始对接
膜融合v-SNARE与t-SNARE缠绕，拉近两膜至1nm，脂类自发流动完成融合
出芽脱壳再运输，马达蛋白拖囊泡；Rab身份来对接，SNARE缠绕膜融合。

十、主动回忆题

Q1 简述信号肽假说的主要内容

分泌蛋白N端信号肽→SRP识别暂停翻译→ER膜SRP受体→Sec61通道→共翻译转位。微粒体体外重构验证，获诺贝尔奖。

Q2 比较N-糖基化和O-糖基化

N-糖基化：内质网，14糖基整体添加，天冬酰胺氮原子。O-糖基化：高尔基体，糖基逐个添加，丝氨酸/苏氨酸羟基氧原子。

Q3 简述溶酶体水解酶的M6P分选机制

顺面高尔基体添加M6P→TGN被M6P受体识别→网格蛋白囊泡→内体→酸性环境受体配体分离→溶酶体。M6P缺失导致I细胞病。

Q4 比较三类包被蛋白的运输方向

COPII：ER→高尔基体顺向。COPI：高尔基体→ER逆向回收+Golgi内。网格蛋白：TGN→内体+质膜→内体。共同功能：货物选择+膜芽塑形。
