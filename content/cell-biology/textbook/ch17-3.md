# 第三节 组织干细胞

第二节把 ES 写成体外的内细胞团：能出三个胚层，生长快，克隆像鸟巢。成体里真正负责几十年更新的，不是这一种细胞。组织干细胞住在相应的干细胞巢内，通过有序的增殖与分化，参与组织器官生长发育，完成细胞新旧更替和损伤修复，以维持结构和功能的稳态（homeostasis）。目前已有包括造血干细胞在内的多种组织干细胞被分离鉴定（图 17-4）。本节先写它们与 ES 不同的增殖和分化逻辑，再写巢，最后落在造血、间充质、神经、肝和精原这几条研究得较清楚的谱系。

:::definition{label="组织干细胞"}
组织干细胞是成体组织内具有自我更新能力、并能分化产生一种或一种以上特化细胞的原始细胞，也称成体干细胞。它们存在于相应干细胞巢中，基本功能是在整个生命过程中维持所在组织的稳态。
:::

:::definition{label="组织稳态"}
组织稳态（homeostasis）是组织器官在结构和功能上保持动态平衡：该补的细胞补上，不该长的细胞不长。组织干细胞的有序增殖与分化，是这份平衡的细胞学基础。
:::

:::compare{title="胚胎干细胞 vs 组织干细胞"}
| 项目 | 胚胎干细胞（ES） | 组织干细胞（成体干细胞） |
|------|-------------------|---------------------------|
| 来源 | 囊胚内细胞团（EG 来自原始性腺） | 成体（及胚胎期）各组织器官的巢 |
| 潜能等级 | 多能（pluripotent）：三个胚层 | 专能或单能（multipotent / unipotent）：基本限于本谱系 |
| 体外生长 | 克隆化、快速增殖，鸟巢样集落 | 生理状态下分裂缓慢；培养体系远不如 ES 成熟 |
| 主要功能 | 可以在体外被诱导为多种功能细胞；支撑遗传操作 | 生命全程维持所在组织稳态、修复和再生 |
| 鉴定金标准 | 小鼠可用嵌合体；人用胚状体和畸胎瘤 | 体内再殖、谱系示踪；标志分子因组织而异 |
| 成瘤风险 | 未分化细胞移植后易成畸胎瘤 | 巢紊乱可参与衰老或肿瘤转化，但本身不是以成瘤为特征 |
| 伦理 | 人 ES 涉及胚胎 | 一般取自成体或围产组织，伦理门槛较低 |
:::

## 一、组织干细胞的基本特征

### （一）增殖相对缓慢而且具有自稳定性

**1. 生理状态下分裂慢。** 小鼠造血干细胞约每 $2.5$ 周才分裂一次，人的造血干细胞约每 $10$ 个月才分裂一次。慢有两层好处：一是留出时间对特定外界信号作出反应，决定进入增殖还是进入分化；二是减少 DNA 复制中的突变机会，降低突变累积。发育中需要形成新组织时，分裂会加快；机体成熟后逐渐变慢并进入静息，避免成熟前把储备耗尽。第十六章把静息写成可被召回的 $\mathrm{G}_0$；组织干细胞正是这类细胞的典型。

**2. 增殖系统具有自稳定性。** 自稳定性（self-maintenance）是干细胞在生物个体生命期间自我更新并维持自身数目恒定的特性。要维持自我更新，必须进入周期分裂，而且后代中至少有一个保持未分化；这两方面失衡，就会出现细胞缺损或组织异常。

当干细胞分裂后，若两个子代都是干细胞或都是分化细胞，称为对称分裂（symmetric division）；若产生一个干细胞和一个分化细胞，称为不对称分裂（asymmetric division）（图 17-5）。对无脊椎动物，不对称分裂是维持自身数目的基本方式。哺乳动物更灵活：既可以像上面那样做单个细胞的不对称分裂，也可以在可自我更新的组织中出现两个子代都是干细胞、或都是特定分化细胞的对称分裂。但平均而言，每一个干细胞产生一个子代干细胞和一个特定分化细胞，因此称为种群不对称分裂（populational asymmetric division）。

小肠隐窝（crypt）把数目控制的重要性写得很清楚：额外多产生一个干细胞，随后会多出 $64\sim 128$ 个子代；而每个正常隐窝大约只有 $250$ 个细胞。多一个干细胞，不是多一个细胞，而是多出一串扩增。

:::definition{label="自稳定性"}
自稳定性（self-maintenance）是干细胞在个体生命期间自我更新并维持自身数目恒定的特性。它要求“有细胞分裂”和“子代中留下未分化者”同时成立。
:::

:::definition{label="对称分裂与不对称分裂"}
对称分裂（symmetric division）产生两个干细胞或两个分化细胞。不对称分裂（asymmetric division）产生一个干细胞和一个分化细胞。哺乳动物成体组织在群体水平上平均仍是“留一个、走一个”，称为种群不对称分裂。
:::

::figure{src="/images/cell-biology/textbook/p0380_01.png" caption="图17-5 干细胞的不对称分裂。A. 简单不对称分裂：巢中的干细胞（S）产生祖细胞（P），再产生分化细胞；B. 群体不对称分裂。教材标注 S 为全能干细胞、P 为多能干细胞，在成体巢的语境中应对应未分化干细胞及其定向子代。" alt="简单不对称分裂与群体不对称分裂模式图"}

**3. 过渡放大细胞的增殖速率远高于干细胞。** 过渡放大细胞（transit amplifying cell，TAC）是激活的干细胞经不对称分裂产生、位于干细胞和分化细胞之间的细胞类型（图 17-6），也称过渡放大前体细胞（transit amplifying progenitor cell，TAP）。它仍有一定分化潜能，但最显著的特性是分裂比干细胞快得多——小肠 TAC 大约比小肠干细胞快一倍。角膜、乳腺、前列腺上皮、表皮、胃肠道和毛囊等许多组织干细胞，都会通过不对称分裂产生 TAC。

生理意义分成两半：干细胞借不对称分裂保住身份和数目；TAC 用高增殖速率和剩余的分化潜能把细胞数目做出来，满足更新或修复。小鼠表皮是一个清楚的例子：基底层不对称分裂，一个子代留在基底层当干细胞，另一个到基底上层成为快速分裂的 TAC，再分化出新的表皮层或用于修复。

:::definition{label="过渡放大细胞"}
过渡放大细胞（transit amplifying cell，TAC）是干细胞和终末分化细胞之间的快速增殖群体。干细胞分裂慢以保护基因组和储备；TAC 分裂快以供应成熟细胞。把 TAC 的高增殖误记成干细胞本人，会把突变风险和储备消耗算错账。
:::

::figure{src="/images/cell-biology/textbook/p0380_02.png" caption="图17-6 组织稳态维持和再生相关干细胞的分化等级。巢信号维持静息或活化干细胞的自我更新；活化干细胞产生过渡放大细胞，再形成谱系特异性前体细胞和分化细胞。损伤/再生信号可改变这条瀑布，并出现转分化或去分化。" alt="从巢内干细胞经过渡放大细胞到谱系分化细胞的等级，并标出损伤信号和转分化"}

:::cause-effect{title="为什么成体干细胞自己不拼命分裂"}
- 因：每次复制都有突变风险；过快消耗会把储备在成熟前用尽
- 因：不对称或种群不对称分裂把“留下自己”和“交出分化细胞”拆开
- 果：干细胞分裂慢，TAC 分裂快，成熟细胞被源源不断供应，干细胞数目仍大致恒定
- 结果：隐窝里多一个干细胞会变成多出数十上百个子代；慢分裂是稳态的安全阀，不是无能
:::

### （二）分化具有谱系限定性

在整个个体发育中，不同阶段、不同组织的干细胞，其分化潜能和方向具有严格的谱系限定性（lineage restriction）：一种组织干细胞通常只产生所在组织内执行特定功能的细胞。小肠干细胞产生吸收细胞、杯状细胞、帕内特细胞和肠内分泌细胞；神经干细胞产生神经元、星形胶质细胞或少突胶质细胞。全能、多能和组织特异性干细胞的谱系限定都有复杂调控，是理解许多生物医学现象的分子基础。

:::definition{label="谱系限定性"}
谱系限定性（lineage restriction）是组织干细胞通常只能产生其所在组织谱系以内细胞类型的性质。小肠干细胞不到神经系统去上班，是这条规则的日常写法。
:::

### （三）特殊条件下可出现可塑性

尽管发育中的谱系限定很严，某些特殊条件下，部分组织干细胞的谱系可变宽，表现出跨组织甚至跨胚层分化，称为组织干细胞的可塑性（plasticity）。例如生理条件下神经干细胞分化为神经元和两类胶质细胞，特殊条件下可分化为造血细胞，植入小鼠胚胎后甚至可出现三胚层来源的细胞；小鼠造血干细胞异体移植后能在受体脑中分化为胶质细胞，成体造血干细胞还可被报道分化为肌细胞和肝细胞。这类观察曾经有过争议，随后大量研究支持其在特定条件下确实存在。

要在活体内证明可塑性，常用报告基因标记后追踪，即谱系示踪（lineage tracing）。它要求同时证明：被标记的成体干细胞能形成具备特定生化特性的组织细胞并构成该组织的关键结构；这些细胞能适应新组织内存活，并像该组织其他成熟细胞那样执行生理功能。只看到标志转阳，不够。

:::definition{label="组织干细胞的可塑性"}
可塑性（plasticity）是某些组织干细胞在特殊条件下跨组织甚至跨胚层分化的能力。它是谱系限定性的有条件例外，必须用谱系示踪同时证明形态、结构和功能，而不是只看一张标志。
:::

:::pitfall{label="可塑性不是成体干细胞平时就能跨胚层改行"}
教材后半段会写神经干细胞出造血细胞、造血干细胞出胶质或肝细胞，容易把组织干细胞听成小号的 ES。生理默认值仍是谱系限定：小肠就出小肠四类细胞，神经就出神经元和胶质。跨谱系是特殊条件、曾经有过争议、并且要用谱系示踪把结构和功能一起钉死。把可塑性当成日常能力，第三节的巢和第四节的定向治疗都会失去边界。
:::

## 二、组织干细胞生理活动的微环境

组织干细胞在活体内都存在于特定微环境（microenvironment）中。认识它们不能只看干细胞本人，更要看它与微环境的关系。增殖与分化是调控干细胞群体稳定性、也是调控组织器官动态平衡的基本方式；这套调控很可能就写在它所在的微环境里。这种微环境称为干细胞巢（stem cell niche）或干细胞龛。

不同巢的结构和组成差别很大，这也许就是不同干细胞各有一套调控的结构基础。巢中各种因素的相互作用，决定干细胞在休眠、增殖或分化之间切换。即便用照射等方法把干细胞去掉，巢仍可保留关键作用，招募外源干细胞归巢。巢的功能紊乱，则与干细胞衰老或肿瘤转化密切相关。

:::definition{label="干细胞巢"}
干细胞巢（stem cell niche，也称干细胞龛）不是单纯的解剖住址，而是干细胞与外源信号相互作用的场所：由干细胞及其相邻细胞、细胞外基质和调控增殖分化的因子组成，并保持动态平衡的局部环境。
:::

### （一）干细胞巢由执行不同功能的异源性成员组成

**1. 巢不只是物理位置。** 各种组织干细胞虽然都有相对固定的组织学部位，但巢是一个有动态平衡的局部环境（图 17-7）。

::figure{src="/images/cell-biology/textbook/p0382_01.png" caption="图17-7 表皮干细胞巢示意图。干细胞通过整联蛋白锚定于细胞外基质，接收巢细胞分泌的生长因子和干细胞调控因子，并与相邻子代细胞相互作用，在增殖、静息和分化之间切换。" alt="表皮干细胞巢：整联蛋白、细胞外基质、巢细胞分泌因子和相邻子代细胞"}

**2. 整联蛋白和胞外基质是结构体系的重要成员。** 胞外基质（ECM）蛋白和整联蛋白塑造微环境并调控干细胞行为。ECM 中某些蛋白可结合特定生长因子和形态发生素（morphogen），调节局部分泌因子浓度，完成生长因子、细胞因子等信号的局部整合。整联蛋白是依赖 $\mathrm{Ca}^{2+}$ 的细胞黏附分子，介导细胞–细胞以及细胞–ECM 相互作用，是 ECM 蛋白的主要受体；其激活和表达受 ECM 调节。整联蛋白还与生长因子、细胞因子受体发生广泛串流（cross-talk），激活细胞内信号网络。此外，整联蛋白维系干细胞的空间位置，否则细胞会脱离生存环境而分化或凋亡。高表达 $\beta$ 整联蛋白对维持表皮干细胞的增殖分化至关重要，并经 MAPK（mitogen-activated protein kinase）途径调节角质化细胞等的分化。

**3. 分泌因子是增殖分化的调控因子。** 分泌因子（secreted factor）可以来自干细胞自身、外围细胞或其他组织。不同微环境、不同生理或发育状态下，种类和水平差异很大，但总与机体需求相适应。TGF-$\beta$ 和 Wnt 家族信号在多种干细胞的不对称分裂及自我更新中起重要作用。干细胞形成的胞外囊泡，特别是外泌体，也被视为巢的重要成员。

**4. 过渡放大细胞和分化子代提供反馈。** TAC 本身也是巢的组成部分：巢成员刺激活化干细胞分裂，建立“过渡放大细胞池”（TAC pool）；TAC 池又作为信号中心向干细胞回传巢信号，调控呈双向性。一些已分化的后代同样可以当巢成员。例如，毛囊中分化的 $\mathrm{K6}^{+}$（Keratin6 阳性）细胞在隆起内层抑制外层干细胞激活；造血系统中，分化的巨噬细胞归巢到骨髓后增强造血干细胞滞留、限制其进入外周血。处于分化末端的子代形成“谱系反馈循环”，在巢中调控干细胞分化。

:::concept{term="巢是住址，更是许可证"}
整联蛋白把干细胞按在 ECM 上，分泌因子和 Wnt/TGF-$\beta$ 决定它睡、它分裂还是它分化，TAC 和成熟子代再把信号回传。照射去掉干细胞之后巢还在，仍能把外源细胞招回来——说明编制不完全写在干细胞基因组里，有一部分写在房间的墙壁上。巢乱了，第四节的衰老和肿瘤就会从这里进门。
:::

### （二）器官水平上各干细胞巢之间存在协同

单个巢和干细胞的对话只是第一层。组织和器官再生还依赖散布于整个器官的许多巢之间的协同：分子特性、分裂模式、群体大小可以差得很远。越来越多证据表明，大部分自我更新组织受到多维度干细胞巢支持。挑战因此是多层的：既有巢单元内部调控，也有巢与巢之间的协同。外泌体不仅在巢内传递信息和物质，也在不同巢之间交流。

:::note{label="第十一章的微环境，在这里收成一个巢"}
第十一章把细胞微环境写成 ECM、相邻细胞和可溶性因子。干细胞巢是这份清单在“储备细胞”上的专用写法：多了 TAC 池和谱系反馈，多了归巢，也多了巢与巢之间的外泌体对话。看见“微环境”，在成体组织里先找巢。
:::

## 三、几种组织干细胞的研究现状

### （一）造血干细胞

20 世纪 40 年代后期，核辐射损伤造血的动物实验显示，正常骨髓可以修复已被严重损伤的骨髓，由此出现造血干细胞（hematopoietic stem cell，HSC）的概念。1961 年，J. E. Till 和 E. A. McCulloch 通过小鼠脾集落形成实验（spleen colony-forming assay）首次在成体内证实其存在。HSC 在骨髓细胞中所占比例很小，但增殖分化能力极强：一个单独的造血干细胞就可以重建整个造血系统。

个体发育中，HSC 最早见于早期胚胎卵黄囊壁的血岛（blood island），随后出现于主动脉–性腺–中肾（aorta-gonad-mesonephros，AGM）区，再见于肝和脾，最后落户骨髓。骨髓是胚胎中后期和出生后整个生命周期的造血场所。

分离纯化依靠表面标志。目前较明确的人造血干细胞标志包括 $\mathrm{CD34}^{+}$、$\mathrm{CD38}^{-}$、$\mathrm{Lin}^{-}$、$\mathrm{HLA}$-$\mathrm{DR}^{-}$、$\mathrm{Thy}^{+}$、$\mathrm{c}$-$\mathrm{Kit}^{+}$、$\mathrm{CD45RA}^{-}$ 和 $\mathrm{CD71}^{-}$ 等，其中 CD34 是临床上应用最多的标志物。

HSC 的维持和分化方向与造血微环境密切相关。哺乳动物骨髓中，一部分 HSC 位于骨小梁骨内膜区、紧靠成骨细胞；另一部分与血窦周围的血管内皮细胞相连。这提示两种微环境：成骨巢维持 HSC 静态，成骨细胞提供调节数量和功能的因子；血管巢调控增殖、分化和动员。

临床上的骨髓移植或造血干细胞移植，利用的就是 HSC 再殖（repopulate）损伤骨髓的能力。该疗法使白血病患者长期生存率提高到 $50\%\sim 70\%$，远胜于单纯化疗。E. D. Thomas 于 1956 年完成首例人类骨髓移植，并因此获得 1990 年诺贝尔生理学或医学奖。

:::definition{label="造血干细胞"}
造血干细胞（hematopoietic stem cell，HSC）是能重建整个造血系统的组织干细胞。发育上从卵黄囊血岛经 AGM、肝、脾迁入骨髓；临床上多用 $\mathrm{CD34}^{+}$ 分选，并栖息于成骨巢（静态）和血管周围巢（增殖、分化、动员）。
:::

### （二）间充质干细胞

间充质干细胞（mesenchymal stem cell，MSC）起源于胚胎期胚外中胚层，可从许多由间充质分化来的成体组织分离，包括脂肪、胎盘、皮肤、脐带血、脐带血管周细胞、牙髓、羊水、滑膜、母乳等。在体内或体外特定诱导下，可分化为脂肪、骨、软骨、肌肉、肌腱、韧带、神经、肝、心肌、内皮等多种组织细胞。

不同来源 MSC 的生物学特性存在差异，与组织来源、供体种属、分离技术、培养条件和传代次数都有关系。按 2006 年国际细胞治疗学会（International Society for Cellular Therapy）标准，MSC 的基本特性包括：①能够在塑料培养皿上黏附生长；②具有“三向分化”（tri-lineage differentiation）潜能，即脂肪细胞、软骨细胞和成骨细胞；③表面表达 CD105（endoglin，SH2）、CD73（ecto-$5'$-nucleotidase）及 CD90（Thy1），并且不表达 CD45、CD19 或 CD79、CD14 或 CD11b 及 HLA-DR。即便如此，MSC 鉴定目前仍缺乏真正特异的分子标志。

近十年基础研究问题仍多，临床应用却发展很快，主要包括：①造血干细胞移植中增强造血、促进植入、治疗移植物抗宿主病；②修复骨、软骨、关节、心脏、肝脏、脊髓和神经系统损伤；③治疗系统性红斑狼疮、硬皮病、炎症性肠病等自身免疫病；④作为基因治疗载体。有学者认为，MSC 临床走得这么快，并不主要因为它的干细胞性质，而是因为它的免疫调节功能，这为异基因型 MSC 移植提供了便利。

:::definition{label="间充质干细胞"}
间充质干细胞（mesenchymal stem cell，MSC）是可贴壁生长、至少具备脂/软骨/骨三向分化，并呈 $\mathrm{CD105}^{+}$、$\mathrm{CD73}^{+}$、$\mathrm{CD90}^{+}$ 而缺乏造血标志的细胞。来源广，标志并不特异；临床上的热度很大程度来自免疫调节，而不只是多向分化。
:::

### （三）神经干细胞

神经外胚层形成后，在邻近神经诱导信号作用下形成神经盘，最早的神经干细胞就位于其中。传统观点认为哺乳动物中枢神经系统出生后不久即丧失再生能力。近年发现，大多数成体哺乳动物在侧脑室壁室管膜下区（subventricular zone，SVZ）和海马齿状回颗粒下区（subgranular zone，SGZ）仍有神经干细胞（neural stem cell，NSC）（图 17-8）。这两个区域的 NSC 具有自我更新能力，并能分化为成熟神经元、星形胶质细胞和少突胶质细胞，为成年期神经系统特定结构与功能的维持奠基，称为神经源性巢（neurogenic niche）。

::figure{src="/images/cell-biology/textbook/p0384_01.png" caption="图17-8 神经干细胞巢及神经干细胞的分化和迁移。SVZ 的 NSC 经前体细胞和神经母细胞沿胶质轨道迁向嗅球；SGZ 的 NSC 最终分化为颗粒细胞层神经元。巢内还有星形胶质细胞、小胶质细胞、室管膜细胞以及血管内皮和管周细胞。LV：侧脑室；Ce：小脑；Str：纹状体；CSF：脑脊液；GCL：颗粒细胞层。" alt="成体脑SVZ和SGZ神经源性巢、向嗅球迁移以及海马颗粒细胞层分化"}

正常生理下 SVZ 的 NSC 多处于静息。损伤或其他病理情况下，它们可产生增殖性 TAC，即神经前体细胞（neural precursor cell，NPC），进而产生可迁移的神经母细胞（neuroblast），再沿胶质细胞形成的轨道网络从 SVZ 迁向嗅球。分子表型大致为：NSC 呈 $\mathrm{GFAP}^{+}$、$\mathrm{nestin}^{+}$、$\mathrm{Lex}/\mathrm{CD15}^{+}$；TAC 呈 $\mathrm{Dlx}^{+}$、$\mathrm{nestin}^{+}$、$\mathrm{Tbr2}^{+}$、$\mathrm{Lex}/\mathrm{CD15}^{+}$；神经母细胞呈 $\mathrm{DCX}^{+}$、$\mathrm{Dlx2}^{+}$、$\mathrm{PSA}$-$\mathrm{NCAM}^{+}$、$\mathrm{nestin}^{+}$；嗅球神经元呈 $\mathrm{NeuN}^{+}$ 和 $\mathrm{DABA}^{+}$。SGZ 的 NSC 标志与 SVZ 相似，最终分化为成熟神经元并迁入颗粒细胞层。

神经源性巢的细胞组分包括：①NSC、NPC 和可迁移神经母细胞；②胶质细胞（星形胶质细胞、小胶质细胞、室管膜细胞），其中星形胶质细胞是主要成分；③血管细胞（内皮细胞和管周细胞）。细胞–细胞接触和细胞外信号共同调节自我更新与分化的平衡；远处器官的信号也可经脑脊液或脉管系统到达。细胞因子、生长因子、神经递质和激素都参与调控。

NSC 的体外培养由 B. A. Reynolds 和 S. Weiss 于 1992 年建立：在 EGF 存在下以非贴壁的“神经球”方式生长，撤去生长因子后可分化为神经元和胶质细胞。

:::definition{label="神经干细胞"}
神经干细胞（neural stem cell，NSC）在成体主要位于 SVZ 和 SGZ 两个神经源性巢，能自我更新并产生神经元、星形胶质细胞和少突胶质细胞。生理下多静息，损伤后经 NPC 和神经母细胞扩增、迁移。
:::

### （四）肝干细胞

成体肝干细胞（hepatic stem cell，liver stem cell）能分化为肝细胞和胆管细胞，通常认为位于肝细胞与小叶内胆管交界处的黑林管（Hering canal），或小叶间胆管的胆管周围腺（peribiliary gland）（图 17-9）。它们对肝脏稳态的贡献一直有争议。

::figure{src="/images/cell-biology/textbook/p0385_01.png" caption="图17-9 肝脏内肝干细胞巢和肝外胆管系统。肝内巢位于黑林管（红色圆圈），胆管周围腺也含干细胞巢（蓝色圆圈）。肝干细胞是肝母细胞（hepatoblast）的前体；肝母细胞作为过渡放大细胞，先产生定向前体细胞，再产生肝实质细胞和胆管上皮细胞。" alt="肝脏胆管树及黑林管、胆管周围腺中的肝干细胞巢"}

肝脏与造血器官、小肠和皮肤不同：生理状况下细胞新旧更替主要靠成熟肝细胞和胆管细胞增殖，高度分化的肝细胞仍有强大增殖能力。1931 年 G. M. Higgins 和 R. M. Anderson 建立经典肝再生模型：切除大鼠 $\dfrac{2}{3}$ 肝组织，两周内可恢复到原来大小。慢性药物损伤中，肝细胞也发挥主要修复作用。肝细胞的自我修复削弱甚至掩盖了肝干细胞的贡献。目前没有证据表明肝干细胞在 $\dfrac{2}{3}$ 切除后的再生或生理性更新中起作用；但在 DDC（3,5-diethoxycarbonyl-1,4-dihydrocollidine）饲料、CDE 饮食（胆碱缺乏、甲硫氨酸补充）或四氯化碳长期损伤等模型中，源于胆管的肝干/前体细胞可在一定程度上参与修复，分化为成熟肝细胞或胆管细胞。体内示踪进一步显示：肝细胞、肝星状细胞、胆管细胞在不同损伤条件下都可能参与修复。肝脏的稳态是一张看损伤类型的分工表，不是单一干细胞瀑布。

:::definition{label="成体肝干细胞"}
成体肝干细胞是存在于成年肝脏、能分化为肝细胞和胆管细胞的干细胞，巢位于黑林管或胆管周围腺。生理性更新和 $\dfrac{2}{3}$ 肝切除后的再生主要靠成熟肝细胞；肝干细胞更多出现在特定慢性损伤模型中。
:::

### （五）精原干细胞

精原干细胞（spermatogonial stem cell）紧贴睾丸生精小管基底膜，在精原细胞（spermatogonium）中比例很小，是分化程度最低的原始细胞，也是精子发生的细胞基础。精子发生全过程都在生精小管内完成（详见第十四章）。各哺乳动物遵循同一基本规律，但精原干细胞到初级精母细胞这一段的细节因物种而异。

小鼠精原细胞分 A、B 两型：A 型较原始，B 型由 A 型分化而来。按形态和空间排布，A 型又分单体（$\mathrm{A}_{\mathrm{single}}$，$\mathrm{A}_\mathrm{s}$）、双合体（$\mathrm{A}_{\mathrm{paired}}$，$\mathrm{A}_{\mathrm{pr}}$）和链状体（$\mathrm{A}_{\mathrm{aligned}}$，$\mathrm{A}_{\mathrm{al}}$）。一般认为只有 $\mathrm{A}_\mathrm{s}$ 是真正的精原干细胞，$\mathrm{A}_{\mathrm{pr}}$ 和 $\mathrm{A}_{\mathrm{al}}$ 已是精子发生的前体。$\mathrm{A}_\mathrm{s}$ 有两种分裂方式：子细胞完全分开，仍为两个 $\mathrm{A}_\mathrm{s}$，用于维持干细胞库；或者核分裂而胞质不完全分裂，以胞质间桥（cytoplasmic bridge）连成 $\mathrm{A}_{\mathrm{pr}}$，标志进入精子发生程序。$\mathrm{A}_{\mathrm{pr}}$ 继续以不完全胞质分裂形成四、八、十六甚至三十二合体，统称链状体 A 型精原细胞。随后连续分裂 $6$ 次，依次为 $\mathrm{A}1$、$\mathrm{A}2$、$\mathrm{A}3$、$\mathrm{A}4$、In（intermediate，中间型）和 B 型。B 型分裂形成初级精母细胞，再经减数分裂 I、II 成为精子细胞并演变为精子。若链状体按十六合体计，则 $1$ 个 $\mathrm{A}_\mathrm{s}$ 进入程序后经 $10$ 次有丝分裂产生 $1\,024$ 个初级精母细胞，两次减数分裂产生 $4\,096$ 个单倍体精子细胞。

人和非人灵长类的细节仍不十分清楚。基底膜上的生精上皮含未分化型精原干细胞（$\mathrm{A}_{\mathrm{dark}}$ 和 $\mathrm{A}_{\mathrm{pale}}$）以及分化型 B 型精原细胞。$\mathrm{A}_{\mathrm{dark}}$ 是最初的精原干细胞，经 $\mathrm{A}_{\mathrm{pale}}$ 分化为 B 型；B 型产生初级精母细胞，进入减数分裂并离开基底膜，再依次形成精母细胞、精子细胞和成熟精子，释放到管腔。原书作“人和非灵长类”，但 $\mathrm{A}_{\mathrm{dark}}/\mathrm{A}_{\mathrm{pale}}$ 体系描述的是人与非人灵长类。

分化的早期关键调控之一是 Kit 受体；其配体为干细胞因子（stem cell factor，SCF），可通过 Kit 促进增殖。

:::definition{label="精原干细胞"}
精原干细胞是紧贴生精小管基底膜、分化程度最低的精原细胞。小鼠中真正的干细胞是 $\mathrm{A}_\mathrm{s}$；人和非人灵长类以 $\mathrm{A}_{\mathrm{dark}}$ 为储备干细胞。它是精子发生的源头，也是维持生精小管结构和功能平衡的基础。
:::

:::keypoint{label="成体干细胞慢分裂、守谱系、住在巢里"}
- 与 ES 不同，组织干细胞生理下分裂慢，靠不对称或种群不对称分裂维持自稳定性，用 TAC 去扩数目。
- 默认谱系限定；跨组织、跨胚层的可塑性是有条件例外，必须用谱系示踪同时证明结构和功能。
- 巢由干细胞、相邻细胞、ECM、整联蛋白和分泌因子组成，TAC 和成熟子代提供反馈；没了干细胞，巢仍可招募归巢。
- HSC 能一个重建整个造血系统；MSC 临床热度很大程度来自免疫调节；NSC 限于 SVZ/SGZ；肝的日常再生主要靠成熟肝细胞；精原干细胞在小鼠是 $\mathrm{A}_\mathrm{s}$。
:::

:::memory{label="本节必背要点"}
- [ ] 组织干细胞：成体组织中能自我更新并产生一种或以上特化细胞，住在干细胞巢里，维持稳态。
- [ ] 与 ES 对照：ES 多能、增殖快、来自 ICM；组织干细胞专能或单能、生理下分裂慢、来自成体巢。
- [ ] 慢分裂：小鼠 HSC 约 $2.5$ 周一次，人 HSC 约 $10$ 个月一次；利于响应信号并降低突变累积。
- [ ] 自稳定性：生命期间维持自身数目；必须分裂，且至少留一个未分化子代。
- [ ] 不对称分裂：一个干细胞 + 一个分化细胞；对称分裂：两个干细胞或两个分化细胞；哺乳动物群体上是种群不对称分裂。
- [ ] 小肠隐窝多一个干细胞可多出 $64\sim 128$ 个子代，正常隐窝约 $250$ 个细胞。
- [ ] TAC：干细胞与分化细胞之间的快速增殖群体；小肠 TAC 约比干细胞快一倍；表皮基底层留一个、上层走一个。
- [ ] 谱系限定：小肠干细胞出吸收/杯状/帕内特/肠内分泌细胞；神经干细胞出神经元和两类胶质。
- [ ] 可塑性：特殊条件下可跨组织甚至跨胚层；需谱系示踪证明生化特性、关键结构和生理功能。
- [ ] 干细胞巢：干细胞 + 相邻细胞 + ECM + 调控因子的动态微环境；可在干细胞缺席时招募归巢；紊乱与衰老、肿瘤相关。
- [ ] ECM 结合生长因子和形态发生素；整联蛋白依赖 $\mathrm{Ca}^{2+}$，锚定位置并与受体串流；表皮干细胞依赖高表达 $\beta$ 整联蛋白和 MAPK。
- [ ] TGF-$\beta$、Wnt 参与不对称分裂和自我更新；外泌体是巢内和巢间的信使；TAC 池和 K6$^{+}$ 内层、骨髓巨噬细胞构成谱系反馈。
- [ ] HSC：Till 与 McCulloch（1961）脾集落实验证实；发育路径血岛 → AGM → 肝/脾 → 骨髓；一个 HSC 可重建造血；临床标志 CD34；成骨巢维持静态，血管巢管增殖分化动员；骨髓移植使白血病长期生存率达 $50\%\sim 70\%$。
- [ ] MSC：可贴壁、三向分化（脂/软骨/骨）、$\mathrm{CD105}^{+}\mathrm{CD73}^{+}\mathrm{CD90}^{+}$、缺乏造血标志；临床应用广，免疫调节可能比“干细胞性”更关键。
- [ ] NSC：成体位于 SVZ 和 SGZ；静息，损伤后经 NPC、神经母细胞迁向嗅球或颗粒细胞层；1992 年 Reynolds 与 Weiss 建立神经球培养。
- [ ] 肝干细胞巢在黑林管和胆管周围腺；$\dfrac{2}{3}$ 切除后两周恢复主要靠成熟肝细胞；DDC/CDE/CCl4 等慢性损伤中胆管来源前体才明显参与。
- [ ] 小鼠精原干细胞是 $\mathrm{A}_\mathrm{s}$；经 $\mathrm{A}_{\mathrm{pr}}$、$\mathrm{A}_{\mathrm{al}}$ 和 $6$ 次分裂到 B 型，再减数分裂；$1$ 个 $\mathrm{A}_\mathrm{s}$ 理论上可产生 $4\,096$ 个精子细胞。人与非人灵长类为 $\mathrm{A}_{\mathrm{dark}}/\mathrm{A}_{\mathrm{pale}}$。Kit/SCF 调控早期分化。
:::
