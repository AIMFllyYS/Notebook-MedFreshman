# 第三节 细胞凋亡

第二节把死亡按可控性分成意外性和调控性，凋亡是调控性死亡里被写得最清楚的一种。细胞凋亡（apoptosis）是细胞在一定的生理或病理条件下，遵循自身的程序，自己结束生命的过程。“apoptosis”来源于希腊语，“apo”意为“分离”，“ptosis”指脱落、凋零。当时选用这个词，就是为了强调这种细胞死亡是自然的生理过程。它普遍存在于人类及动、植物中，贯穿整个生命过程。本节先写它在发育和疾病中的位置，再写形态与生化判据，最后把死亡受体途径和线粒体途径、以及 Bcl-2、p53、IAP 这套调控拆开。

:::definition{label="细胞凋亡"}
细胞凋亡（apoptosis）是细胞在一定生理或病理条件下，遵循自身程序结束生命的过程。它是细胞生理性死亡的普遍形式，也是多细胞生物个体发育和成体组织更新不可缺少的部分。
:::

:::definition{label="失巢凋亡"}
失巢凋亡（anoikis）是细胞脱离原来生存微环境后发生的凋亡。正常上皮或不具备转移性质的实体瘤细胞从原位脱落进入血流即会触发；其意义在于防止脱落细胞种植于不适宜的部位。易远处转移的恶性肿瘤则具有极强的抗失巢凋亡特性。
:::

凋亡是细胞生理性死亡的普遍形式。例如人体内每天有 $5\times 10^{11}$ 个血细胞通过凋亡被清除，同时新的血细胞产生，实现造血更新。在个体发育过程中，细胞按时空程序发生死亡：蝌蚪变态时尾部细胞的凋亡、脊椎动物神经元发育过程中的凋亡，以及哺乳动物指（趾）发育时指（趾）间细胞的凋亡。脊椎动物发育早期一般先产生过量的神经元，后来近一半发生凋亡，只有那些与靶细胞（如肌细胞、腺体细胞等）建立起良好突触联系、并充分接受靶细胞分泌的存活因子的神经元才保留下来（图 16-4）。第十五章把神经元写成终末分化；这里它们的数目是被凋亡裁出来的。

::figure{src="/images/cell-biology/textbook/p0361_01.png" caption="图16-4 个体发育过程中的细胞凋亡事例。A. 发育中神经细胞的凋亡：未与靶细胞配对、得不到存活因子的神经元被清除；B. 哺乳动物手指和足趾在发育早期连在一起，指（趾）间的蹼通过凋亡被清除，使单个指（趾）分开；C. 幼体蝌蚪向成体发育过程中尾部细胞的凋亡。" alt="发育中神经元依赖存活因子、指间蹼消退和蝌蚪尾部凋亡三个事例"}

凋亡也是疾病发生的基础。很多病理条件下细胞发生凋亡。除生理性诱导因子（肿瘤坏死因子及其家族中的 Fas 配体、转化生长因子 $\beta$、神经递质、$\mathrm{Ca}^{2+}$、糖皮质激素）之外，损伤相关因子（病毒感染、细菌毒素、氧化剂、自由基、缺氧、缺血）、疾病治疗相关因子（化疗、放疗、生物治疗、中药治疗），以及其他细胞毒性物质（乙醇、氧化砷、$\beta$ 淀粉样蛋白）等均可诱发凋亡。细胞脱离其所处微环境也是诱发因素：失巢凋亡防止脱落细胞异位种植，而高转移肿瘤细胞从瘤体脱落进入循环后并不发生凋亡。

## 一、细胞凋亡的特征

细胞凋亡具有典型的形态学改变和特异的生化特征。

### （一）细胞凋亡呈现出特征性形态学变化

主要包括细胞皱缩（cell shrinkage）、染色质凝集（chromatin condensation）、凋亡小体形成、细胞骨架解体等，其中以胞核的变化最为显著。

**1. 细胞核的变化。** 细胞核体积变小，染色质凝集。凝集起始于核膜边缘，呈新月帽状贴附在核膜上，随后扩展到整个细胞核。当凝集的染色质断裂时，呈现多个大小不同的块状或花瓣状染色质。凋亡后期核膜断裂，染色质碎片散布于细胞内，很快与细胞质断裂成分一起形成凋亡小体。

**2. 细胞质的变化。** 凋亡细胞的胞质发生明显浓缩，其中的细胞器也发生不同程度变化，尤其是线粒体和内质网。凋亡早期可观察到线粒体增大、嵴增多，随后出现空泡化。多数情况下内质网腔膨大，并为凋亡小体提供包裹膜。原有疏松、有序的细胞骨架也变得致密和紊乱。细胞骨架的改变不仅仅是凋亡的后果，还影响到凋亡的过程。

**3. 细胞膜的变化。** 凋亡细胞表面原有的特化结构，如微绒毛、细胞突起及细胞连接等逐渐消失，细胞膜起泡（blebbing），但细胞膜仍保持完整。一些与细胞间连接有关的蛋白质从凋亡细胞膜上消失，但正常情况下位于细胞膜内侧的磷脂酰丝氨酸（phosphatidylserine，PS）则从细胞膜内侧翻转到表面，暴露于细胞外环境中，与凋亡细胞被识别和清除有关。

**4. 凋亡小体的形成。** 细胞核及细胞质的碎片被膜包围形成凋亡小体，此时完整细胞碎裂为多个散落、大小不等的凋亡小体。形成步骤为：①细胞膜起泡。凋亡时细胞骨架重新装配引起物理特性改变，尤其是流体静力学压力产生，水流动到压力改变的质膜局部，造成该处质膜像发泡一样鼓起。②膜突起形成。在一些特定蛋白质作用下，在微丝重排的基础上，膜继续向外伸出相对较长的突起，细胞质和染色质的断片进入突起。③凋亡小体脱落。膜突起开始脱离细胞，凋亡细胞解体。这是最后一步，也是机制最不清楚的步骤。在凋亡小体未脱落前，质膜一直维持完整性；防止细胞过早破裂是重要的生物学问题，但机制尚不清楚。有些细胞仅仅发生核固缩和胞质浓缩，成为单个致密结构，也被称为凋亡小体；病毒性肝炎中见到的嗜酸性小体（康斯尔曼体，Councilman body）就是这种凋亡小体的例子。

:::derivation{label="凋亡小体怎样把内容物封进完整膜"}
1. 骨架重装配改变流体静力学压力，局部质膜起泡（blebbing）。
2. 微丝重排，膜伸出较长突起，核与胞质断片进入突起。
3. 突起脱落成为大小不等的凋亡小体；脱落前质膜一直完整。
4. 内质网膨大的膜常提供包裹；PS 翻到外表面，作为“请来吞噬”的信号。
5. 吞噬细胞（多为巨噬细胞，有时是上皮或血管内皮）吞掉小体，内容物不逸散，故不引发炎症。
:::

### （二）凋亡细胞呈现特异的生化特征

**1. DNA 片段化。** 细胞凋亡时，细胞内源性核酸酶活化，特异地在染色质核小体的连接段切断 DNA 链，形成长度为 $180\sim 200\,\mathrm{bp}$ 整数倍的寡聚核苷酸片段，称为 DNA 片段化（DNA fragmentation）。这种片段化的结果是在琼脂糖凝胶电泳时，凋亡细胞表现出特征性的 DNA 梯状条带（DNA ladder）（图 16-7）。而细胞坏死时，DNA 随意断裂为长度不一的片段，电泳呈现“弥散状”（smear）。因此，DNA 规律片段化也是区分凋亡和坏死的依据。DNA 断裂和小片段漏出还会造成 DNA 含量降低，流式细胞术检测时，凋亡细胞可以在 $\mathrm{G}_0/\mathrm{G}_1$ 期（二倍体）细胞前面形成独立的亚二倍体峰。

:::definition{label="DNA 片段化"}
DNA 片段化（DNA fragmentation）是凋亡时内源性核酸酶在核小体连接段切断 DNA，形成 $180\sim 200\,\mathrm{bp}$ 整数倍寡聚核苷酸片段的过程。电泳呈梯状条带（DNA ladder）；坏死则为随机断裂的 smear。流式上表现为 $\mathrm{G}_0/\mathrm{G}_1$ 前的亚二倍体峰。
:::

::figure{src="/images/cell-biology/textbook/p0363_02.png" caption="图16-7 凋亡细胞 DNA 凝胶电泳时呈现梯状条带。A. 细胞凋亡中 DNA 内切酶在核小体连接段活化并切断 DNA；B. 凋亡所形成的 180～200 bp 整倍性 DNA 片段在电泳上呈梯状，与正常细胞高分子量 DNA 形成对照。" alt="核小体间切割产生180到200bp整数倍片段，凋亡DNA呈梯状条带"}

**2. 细胞凋亡中的蛋白酶。** 凋亡的发生通过多种蛋白酶控制，蛋白酶对底物蛋白质的级联剪切（cleavage）是凋亡细胞的关键特征。控制凋亡的蛋白酶最主要的是胱天蛋白酶（cysteine aspartic acid specific protease，caspase）家族，其他也包括免疫细胞中的颗粒酶（granzyme）等。

caspase 剪切底物依赖自身的半胱氨酸残基（Cys），而水解底物的位点在特定的天冬氨酸（Asp）与其后氨基酸残基间的肽键，这也是胱天蛋白酶名称的由来。目前发现的哺乳动物 caspase 家族成员有十余种，分子间同源性很高、结构相似。除参与炎症反应的 caspase-1、4、5、11 外，参与细胞凋亡的包括 caspase-2、3、6、7、8、9、10。caspase 通常以无活性的酶原形式存在，其活化也是级联剪切的过程。

:::definition{label="胱天蛋白酶"}
胱天蛋白酶（caspase）是半胱氨酸依赖、在天冬氨酸后剪切底物的蛋白酶家族。凋亡相关成员包括起始 caspase（caspase-2、8、9）和执行/效应 caspase（caspase-3、6、7）；炎症相关成员为 caspase-1、4、5、11。酶原经级联剪切才获得活性。
:::

:::derivation{label="caspase 酶原怎样变成活性四聚体"}
1. 先在酶原 N 端前域与大亚基之间剪切，前域被去除。
2. 再在大、小亚基之间剪切，释放大亚基和小亚基。
3. 大亚基与小亚基组成二聚体。
4. 两个二聚体装配成有活性的四聚体。
5. 起始 caspase 先在衔接蛋白搭建的平台上互相靠近、自身激活；再剪切执行 caspase；执行 caspase 剪切非 caspase 底物，凋亡形态出现。
:::

caspase 家族成员可分为起始 caspase（initiator caspase）和执行 caspase（execution caspase）。起始 caspase 被首先激活，激活后又剪切执行 caspase，以级联激活的方式启动凋亡。起始 caspase 包括 caspase-2、8、9，特征是 N 端前域均包含一段特殊的结构域 CARD（caspase recruitment domain）。起始 caspase 酶原的 CARD 与衔接蛋白同样的结构域结合，形成大的多聚复合体，这个复合体便成为起始 caspase 互相靠近、相互剪切的平台，也就是引发自身激活的平台。虽然激活 caspase-8 和 caspase-9 的信号不同、形成的复合体也不同，但它们均以这种机制完成激活。起始 caspase 一旦活化即开启细胞内的死亡程序，通过水解切割 caspase-3、6、7 使它们激活；这些执行 caspase 则剪切非 caspase 家族的各类蛋白质，并因此介导凋亡的最终发生，故 caspase-3、6、7 又称为效应 caspase（effector caspase）。

起始 caspase 剪切的底物是效应 caspase，而效应 caspase 剪切的底物已发现有上千种，其中较为重要的包括 caspase 激活的 DNA 酶的抑制蛋白（inhibitor of caspase-activated deoxyribonuclease，ICAD）、聚腺苷二磷酸核糖聚合酶-1（poly ADP-ribose polymerase，PARP-1）、微丝和核纤层等。这些蛋白质被剪切后造成的结果既有功能上的激活，也有失活，并最终负责凋亡的发生：ICAD 被剪切失活，释放 CAD，解除对 CAD 的抑制，CAD 才能对 DNA 进行水解，导致凋亡细胞的 DNA 片段化。第八章的核纤层、第七章的微丝，在这里都被写成效应 caspase 的底物。

:::concept{term="起始 caspase 切同类，执行 caspase 切全场"}
CARD 把起始酶原招集到 DISC 或凋亡体上，让它们互相剪开。真正把核、骨架和 ICAD 拆掉的是 caspase-3、6、7。把“有 caspase 活性”听成已经凋亡，会漏掉炎症 caspase（1、4、5、11）并不走这条形态学路线——那是第四节焦亡的设备。
:::

### （三）细胞凋亡与细胞坏死的比较

由于细胞凋亡是一种主动的、由基因决定的细胞自杀（cell suicide）过程，其性质与细胞坏死完全不同。细胞坏死是细胞受到激烈的物理、化学刺激或严重的病理性刺激后引起的细胞损伤和死亡。坏死时细胞膜发生渗漏，细胞内容物（包括膨大、破碎的细胞器以及染色质片段等）释放到胞外，导致炎症反应；而在凋亡过程中，细胞膜反折并包裹断裂的染色质片段或细胞器等，随后逐渐分离形成众多凋亡小体，并最终被邻近的吞噬细胞吞噬破坏。行使吞噬功能的细胞一般是巨噬细胞，有时是上皮细胞或血管内皮细胞。整个凋亡过程中细胞膜的完整性保持良好，死亡细胞的内容物不会逸散到胞外环境中，因此并不引发炎症反应（图 16-8）。表 16-1 把对照写成可背的条目。

::figure{src="/images/cell-biology/textbook/p0364_01.png" caption="图16-8 细胞凋亡与细胞坏死的形态比较。坏死一侧：细胞器肿胀、染色质凝集呈絮状，细胞分解自溶，释放内容物并引起炎症。凋亡一侧：细胞固缩、染色质致密呈半月状，核固缩并 DNA 片段化，形成凋亡小体后被吞噬细胞吞噬。" alt="坏死肿胀自溶致炎，凋亡固缩形成凋亡小体被吞噬"}

:::compare{title="细胞凋亡 vs 细胞坏死"}
| 项目 | 细胞凋亡 | 细胞坏死 |
|------|----------|----------|
| 起因 | 生理性或病理性 | 主要是病理性变化或剧烈损伤 |
| 范围 | 单个散在细胞 | 大片组织或成群细胞 |
| 细胞膜 | 保持完整，一直到形成凋亡小体 | 破损 |
| 细胞核 | 固缩，DNA 片段化 | 弥漫性降解 |
| 染色质 | 凝聚在核膜下呈半月状 | 呈絮状 |
| 线粒体 | 自身吞噬 | 肿胀 |
| 细胞体积 | 固缩变小 | 肿胀变大 |
| 凋亡小体 | 有，被邻近细胞或巨噬细胞吞噬 | 无，细胞自溶，残余碎片被巨噬细胞吞噬 |
| 基因组 DNA | 有控降解，电泳图谱呈梯状 | 随机降解，电泳图谱呈涂抹状 |
| 基因活动 | 有基因调控 | 无基因调控（程序性坏死除外） |
| 蛋白质合成 | 有 | 无 |
:::

:::pitfall{label="电泳 smear 不是“凋亡失败的 ladder”"}
ladder 来自核小体连接段的定点切割，$180\sim 200\,\mathrm{bp}$ 整数倍；smear 来自坏死时 DNA 随机断裂。把 smear 看成“凋亡发生了但条带没跑开”，会把 ACD 误判成凋亡。同样，亚二倍体峰支持凋亡，但不能单独排除其他 DNA 丢失。形态、ladder 和 caspase 底物剪切要合在一起看。
:::

## 二、细胞凋亡的分子机制

细胞凋亡与细胞增殖和细胞分化一样，受细胞内外多种信号的诱导而启动。

### （一）细胞凋亡主要由死亡受体途径和线粒体途径介导

诱导凋亡的信号可来源于细胞内或细胞外。细胞内部的信号可来自 DNA、线粒体、内质网等的损伤；细胞外的信号可以是药物、射线、其他细胞分泌释放的信号分子，也可以是其他细胞的膜表面分子，甚至失去细胞黏附也可成为诱导信号。这些信号或刺激有的通过膜表面的死亡受体而介导，有的通过线粒体释放促进凋亡的物质而起始。前者称为死亡受体途径，也称为外源性途径（extrinsic pathway）；后者称为线粒体途径，也称为内源性途径（intrinsic pathway）（图 16-9）。

::figure{src="/images/cell-biology/textbook/p0365_01.png" caption="图16-9 哺乳动物细胞凋亡的主要途径。左侧为死亡受体途径：FasL 结合 Fas/Apo-1/CD95，经 FADD 招募 caspase-8 酶原形成 DISC，活化 caspase-8 再激活 caspase-3。右侧为线粒体途径：DNA 损伤、氧化剂等促使细胞色素 c 释放，与 Apaf-1、dATP 和 caspase-9 酶原形成凋亡体。两条路在 caspase-3 汇合；caspase-8 切割 Bid 可沟通线粒体途径。" alt="外源性DISC激活caspase-8，内源性凋亡体激活caspase-9，Bid为桥梁"}

**1. 死亡受体介导的细胞凋亡途径。** 细胞外的信号分子与细胞表面相应的死亡受体（death receptor，DR）结合，激活凋亡信号通路。这些信号分子属于肿瘤坏死因子（tumor necrosis factor，TNF）家族，包括 TNF-$\alpha$、Fas 配体（Fas ligand，FasL）、TRAIL；而受体也属于 TNF 受体超家族，主要成员有肿瘤坏死因子受体（tumor necrosis factor receptor，TNFR）1、Fas/Apo-1/CD95、DR-4、DR-5 等。信号分子与死亡受体结合后引起 caspase-8 活化。以 Fas 为例，Fas 胞外结构域与 FasL 结合后，诱发 Fas 胞质死亡结构域（death domain，DD）结合 Fas 相关死亡结构域蛋白（Fas-associated protein with death domain，FADD），此时 FADD 的氨基端死亡效应结构域暴露，得以与 caspase-8 酶原结合，形成由 Fas–FADD–caspase-8 组成的死亡诱导信号复合体（death inducing signaling complex，DISC），该复合体即为 caspase-8 的激活平台。活化的 caspase-8 可以进一步激活执行死亡功能的效应蛋白 caspase-3、6、7 等，导致细胞凋亡。

:::definition{label="死亡诱导信号复合体"}
死亡诱导信号复合体（DISC）是外源性凋亡中由死亡受体、衔接蛋白 FADD 和 caspase-8 酶原组成的多聚平台。以 Fas–FasL 为例：Fas 的死亡结构域招募 FADD，FADD 再招募 caspase-8，酶原在 DISC 上互相剪切而活化。
:::

:::derivation{label="Fas 怎样把细胞外配体写成 caspase-8"}
1. FasL 结合 Fas 胞外区，受体寡聚化。
2. Fas 胞质死亡结构域（DD）招募 FADD。
3. FADD 氨基端死亡效应结构域暴露，结合 caspase-8 酶原。
4. Fas–FADD–caspase-8 装配成 DISC，caspase-8 互相剪切而活化。
5. 活性 caspase-8 剪切 caspase-3、6、7；也可剪切 Bid 生成 tBid，插入线粒体，把外源性信号灌进内源性途径。
:::

**2. 线粒体介导的细胞凋亡途径。** 许多凋亡信号，如 DNA 损伤、氧化剂、药物等都可以直接或间接作用于线粒体，引起线粒体的损伤和膜渗透性改变，导致细胞色素 c（cytochrome c，cyt c）释放，触发凋亡。

线粒体外膜通透作用（mitochondrial outer membrane permeability，MOMP）是线粒体途径介导凋亡的早期决定性改变。在凋亡信号刺激时，Bcl-2 家族的 Bax 和 Bak 被激活，在线粒体外膜上聚集，以数量不等的同型或异型寡聚体的形式围成环形或弧形的“孔洞”，这种现象被称为线粒体外膜通透作用。线粒体膜间腔的细胞色素 c 从这些孔洞释放，释放的细胞色素 c 与胞质的凋亡蛋白酶激活因子（apoptosis protease activating factor-1，Apaf-1）、dATP 及 caspase-9 酶原形成蛋白质复合体。这个复合体是 caspase-9 激活的平台，被称为凋亡体（apoptosome），启动细胞凋亡。因此，MOMP 和细胞色素 c 的释放是线粒体途径触发凋亡的核心事件。

MOMP 促使线粒体释放的蛋白质还包括凋亡诱导因子（AIF）和凋亡抑制因子（IAP）的抑制蛋白 Smac/Diablo，它们也参与凋亡发生。此外，死亡受体途径中激活的 caspase-8 也可催化 Bcl-2 家族促凋亡分子 Bid 的切割。caspase-8 催化 Bid 裂解成两个片段，其中含有 BH3 结构域的 C 端片段（tBid）也插入线粒体膜，引起细胞色素 c 释放，沟通了死亡受体途径和线粒体途径。

:::definition{label="线粒体外膜通透作用"}
线粒体外膜通透作用（MOMP）是内源性凋亡的早期决定性改变：Bax/Bak 在线粒体外膜寡聚成孔，膜间腔的细胞色素 c、Smac/Diablo、AIF 等释放。细胞色素 c 与 Apaf-1、dATP 和 caspase-9 酶原装配凋亡体。
:::

:::definition{label="凋亡体"}
凋亡体（apoptosome）是细胞色素 c、Apaf-1、dATP 与 caspase-9 酶原组成的蛋白质复合体，是 caspase-9 的激活平台。活化的 caspase-9 再剪切执行 caspase，启动内源性凋亡。
:::

:::derivation{label="细胞色素 c 怎样把线粒体损伤写成 caspase-9"}
1. DNA 损伤、氧化剂、药物等激活 Bax/Bak，在线粒体外膜寡聚成孔（MOMP）。
2. 膜间腔细胞色素 c 经孔释放入胞质；同时释放 Smac/Diablo、Omi、AIF。
3. 细胞色素 c 与 Apaf-1、dATP、caspase-9 酶原装配凋亡体。
4. caspase-9 在凋亡体上活化，剪切 caspase-3、6、7。
5. Smac/Diablo 和 Omi 抑制 IAP，解除对 caspase-9/3/7 的刹车，使级联能够跑完。
:::

**3. 其他细胞凋亡途径。** 内质网和溶酶体在凋亡中也起重要作用。内质网与凋亡的联系主要表现在两个方面：①内质网对 $\mathrm{Ca}^{2+}$ 浓度的调控。很多细胞在凋亡早期会出现胞质内 $\mathrm{Ca}^{2+}$ 浓度升高，这种升高由细胞外 $\mathrm{Ca}^{2+}$ 内流和胞内钙库（内质网）中 $\mathrm{Ca}^{2+}$ 释放所致。胞质内高浓度 $\mathrm{Ca}^{2+}$ 一方面可以激活胞质中的钙依赖性蛋白激酶，另一方面可影响线粒体外膜通透性从而促进凋亡。内质网膜上的凋亡抑制蛋白 Bcl-2 则具有维持胞质内 $\mathrm{Ca}^{2+}$ 浓度稳定、抑制凋亡的作用。②caspase 在内质网的激活。胞质内 $\mathrm{Ca}^{2+}$ 浓度升高等因素可激活位于内质网膜上的 caspase-12，活化的 caspase-12 被转运到胞质中参与 caspase-9 介导的凋亡过程。

:::compare{title="外源性途径 vs 内源性途径"}
| 项目 | 外源性（死亡受体）途径 | 内源性（线粒体）途径 |
|------|------------------------|------------------------|
| 信号来源 | 细胞外：TNF-$\alpha$、FasL、TRAIL 等 | 细胞内：DNA 损伤、氧化剂、药物等 |
| 关键受体/细胞器 | 死亡受体 TNFR1、Fas/CD95、DR-4/5 | 线粒体 |
| 激活平台 | DISC（受体–FADD–caspase-8） | 凋亡体（cyt c–Apaf-1–dATP–caspase-9） |
| 起始 caspase | caspase-8（及 10） | caspase-9 |
| 决定性事件 | 配体结合后 DISC 装配 | MOMP 与细胞色素 c 释放 |
| 与另一条路的桥梁 | caspase-8 切 Bid → tBid 插入线粒体 | 执行 caspase 被两侧共用 |
| 共同终点 | 执行 caspase-3、6、7 剪切 ICAD、PARP-1、核纤层和微丝 | 同左 |
:::

### （二）细胞凋亡受多种因素调控

一些基因的表达产物能够调控凋亡，这些基因称为凋亡相关基因，包括 $Bcl$-$2$、$IAP$ 和 $p53$ 等。另外，线粒体释放的小分子 ROS、$\mathrm{Ca}^{2+}$、cAMP 也调控凋亡的发生。

**1. 既能抑制又能促进凋亡的 Bcl-2 基因家族。** Bcl-2 家族蛋白在凋亡中扮演重要角色。$Bcl$-$2$ 基因是 B 细胞淋巴瘤/白血病-2（B-cell lymphoma/leukemia-2，Bcl-2）的缩写，但其不仅存在于 B 细胞淋巴瘤中，也见于几乎所有正常组织。很多 Bcl-2 家族蛋白，如 Bcl-2、Bax、Bcl-XL 等都定位于线粒体膜上。家族成员大多包含 BH1～4 同源结构域，部分成员只有 BH3 结构域，大部分成员的 C 端还有一个穿膜结构域，帮助其插入细胞器膜。家族中有的成员对凋亡发挥抑制作用，有的发挥促进作用：前者如 Bcl-2、Bcl-XL 和 Mcl-1，后者如 Bax、Bak、Bok、Bad、Bid 和 Bim 等。这两类蛋白质通过同源结构域相互作用、相互拮抗，诱导或抑制 MOMP 和细胞色素 c 从线粒体的释放，调控凋亡的发生。例如，Bcl-2 通过阻止细胞色素 c 从线粒体释放来抑制凋亡；而 Bax 则通过与线粒体上的膜通道结合，促使细胞色素 c 释放而促进凋亡。

:::definition{label="Bcl-2 家族"}
Bcl-2 家族是调控 MOMP 的线粒体膜蛋白家族，含 BH 同源结构域。抗凋亡成员包括 Bcl-2、Bcl-XL、Mcl-1；促凋亡成员包括 Bax、Bak、Bok 以及 Bad、Bid、Bim 等 BH3-only 蛋白。二者相互拮抗，决定细胞色素 c 是否释放。
:::

**2. 调控细胞凋亡的 p53 基因。** p53 是一种重要的应激感受分子，在 DNA 损伤应答中扮演核心角色。p53 作为转录因子，在 DNA 损伤后激活，诱导一系列基因的转录，激活细胞周期检查点，促进 DNA 修复，维持基因组稳定性。同时，p53 诱导了 $NOXA$ 和 $PUMA$ 等促凋亡基因的转录，而 NOXA 和 PUMA 蛋白与 Bcl-2 家族蛋白作用，触发线粒体 MOMP，故细胞核的 DNA 损伤通过 p53 诱导了线粒体途径的凋亡。凋亡使基因组不稳定的细胞被清除，抑制细胞的恶性转化和肿瘤发生。当 $p53$ 基因突变、失去上述功能，肿瘤就可能发生。迄今为止，$p53$ 已被证明是肿瘤中突变频率最高的基因。另外，在肿瘤治疗中，化疗药物、放射治疗造成的 DNA 损伤也需要通过 p53 达到治疗效果（诱导凋亡），因此恢复 p53 的活性一直以来都是肿瘤治疗药物开发的目标。第一节的衰老和这里的凋亡，是 p53 对同一损伤的两条出路。

**3. IAP 和 IAP 的抑制蛋白。** 凋亡抑制因子（IAP）是一类抑制 caspase 的蛋白质，在哺乳动物细胞中包括 cIAP1、cIAP2 和 xIAP。IAP 定位于细胞质，具有泛素 E3 连接酶活性，通过对 caspase-9、3、7 以及其他相关蛋白质的泛素化修饰抑制 caspase 激活（促进 caspase 的降解），进而抑制凋亡。当线粒体途径被激活时，从线粒体释放的两种蛋白质 Smac/Diablo 和 Omi 为 IAP 的抑制蛋白，解除了 IAP 对 caspase 的抑制作用。因而 IAP 和 Smac/Diablo、Omi 成为相互拮抗的力量，就像为 caspase 激活设置了阈值和开关。在一些死亡受体途径介导的凋亡中，也需要线粒体释放的 Smac/Diablo、Omi 才能解除对 caspase-3 的抑制作用。在促凋亡药物开发时，IAP 的小分子抑制剂和 Smac/Diablo 的小分子类似物也成为新的方向。

**4. 线粒体膜电位的下降和小分子物质的释放。** 在细胞凋亡时，线粒体膜电位下降，钙离子等小分子从基质腔释放到细胞质，促进凋亡发生。这种现象被称为线粒体通透性转变（mitochondrion permeability transition，mPT），但目前对其分子机制的了解较少。线粒体内膜较外膜更紧密、通透性较弱，故形成线粒体通透性转变孔（mPT pore，mPTP）使小分子穿过内膜，是目前研究者认为的合理机制。虽然推测该孔含有线粒体膜上运输小分子的特异载体或通道蛋白，也有证据证明是 $\mathrm{F}_1\mathrm{F}_0$ ATP 合酶的亚基，但目前 mPTP 的结构尚不清楚。MOMP 是外膜 Bax/Bak 成孔、放细胞色素 c；mPT 是内膜电位塌陷、放 $\mathrm{Ca}^{2+}$。两件事都写在线粒体上，不要并成一个孔。

:::note{label="经典实验：线虫 ced 基因鉴定程序性死亡"}
自 20 世纪 60 年代起人们认识到细胞死亡是动物发育中的正常事件。线虫发育图谱显示，早期 $1\,090$ 个细胞中有 $131$ 个发生程序性死亡，同一类型细胞在所有胚胎中同时死亡，形态变化相似。1986 年 Ellis 和 Horvitz 用甲磺酸乙酯（EMS）处理约 $4\,000$ 条线虫，找到 $ced$-$3$ 隐性突变体：预期该死亡的细胞未死，$131$ 个程序性死亡受阻。随后鉴定的 $ced$-$4$ 位于另一条染色体，隐性突变同样阻碍全部程序性死亡。论文为 ELLIS H M，HORVITZ H R. Genetic control of programmed cell death in the nematode *C. elegans*. Cell，1986，44（6）：817–829。

$ced$-$3$、$ced$-$4$ 以及后来鉴定的 $ced$-$9$ 在进化中高度保守：$ced$-$3$ 与哺乳动物白介素-$1\beta$ 转换酶（ICE）同源性 $28\%$、与 caspase-3 同源性 $35\%$；$ced$-$4$ 与 Apaf-1 同源；$ced$-$9$ 与 Bcl-2 同源。Horvitz 与 Brenner、Sulston 因此共同获得 2002 年诺贝尔生理学或医学奖。线虫把“死亡是基因写好的”从观察写成了分子。
:::

:::cause-effect{title="p53 为什么既能停周期又能启动凋亡"}
- 因：DNA 损伤激活 p53，作为转录因子打开检查点并促进修复
- 因：同一 p53 还诱导 NOXA、PUMA，经 Bcl-2 家族触发 MOMP
- 果：损伤可逆时细胞停在 $\mathrm{G}_1$ 修复；损伤不可逆或不稳定基因组则走线粒体凋亡被清除
- 结果：$p53$ 突变既逃过衰老（第一节）也逃过凋亡，成为肿瘤中突变频率最高的基因；放化疗诱导凋亡也依赖它
:::

## 三、细胞凋亡与疾病

细胞凋亡是机体维持自身稳定的一种生理机制。机体通过凋亡清除损伤、衰老与突变的细胞，维持生理平衡。某些致病因子可使凋亡的基因调控失常，致使凋亡减少或增多，从而破坏机体细胞稳态，最终导致各种疾病。

### （一）细胞凋亡过低导致相关疾病的发生

**1. 细胞凋亡与肿瘤。** 凋亡在肿瘤的发病机制中占有重要地位。癌变前的细胞可以通过凋亡被清除。恶性肿瘤发病过程中，常可见到凋亡抑制基因和凋亡活化基因表达异常。如在人的肿瘤细胞中常常检测到 $p53$ 基因的突变或缺失，使细胞对 DNA 损伤的敏感性大大降低，凋亡发生障碍，细胞进入失控的生长状态。一般肿瘤细胞高表达 FasL，借以使淋巴细胞凋亡，而又低表达 Fas 以降低自身凋亡，从而形成肿瘤细胞逃逸免疫及凋亡耐受的特性。

**2. 细胞凋亡与系统性红斑狼疮。** 系统性红斑狼疮（systemic lupus erythematosus，SLE）是典型的自身免疫病。Fas 表达缺陷引起自身反应性 T 细胞阴性选择的凋亡功能丧失，导致 T 淋巴细胞凋亡障碍，因此在外周淋巴器官出现大量 $\mathrm{CD}4^{+}$、$\mathrm{CD}8^{+}$ 的 T 淋巴细胞，这些细胞具有自身反应性，从而引起 SLE。

### （二）细胞凋亡过度导致相关疾病的发生

**1. 细胞凋亡与神经退行性疾病。** 中枢神经系统不同部位特殊类型神经元的丧失是各种神经退行性疾病的病理特点，凋亡与神经元丢失密切相关。现已发现，caspase-3 在神经退行性疾病的病理过程中担任重要角色：它不仅介导凋亡，还能直接与阿尔茨海默病（AD）、帕金森病（PD）、亨廷顿病、脊髓小脑性共济失调等疾病的致病蛋白质分子相互作用，参与致病过程。AD 发生时 $\beta$ 淀粉样蛋白在脑内进行性堆积，能诱导神经元凋亡，但能被抗氧化剂阻断。已经在肌萎缩患者体内发现与神经元凋亡抑制蛋白有关的基因突变，该突变使神经元凋亡抑制蛋白缺乏，导致脊髓前角运动神经元凋亡，肌肉出现失用性萎缩。

**2. 细胞凋亡与 AIDS。** 人类免疫缺陷病毒（human immunodeficiency virus，HIV）感染可导致获得性免疫缺陷综合征（AIDS）。HIV 感染的宿主细胞膜表面可表达 gp120，其受体存在于 $\mathrm{CD}4^{+}$ T 淋巴细胞膜上。因此，当 gp120 与 $\mathrm{CD}4^{+}$ T 淋巴细胞结合后，可诱导 $\mathrm{CD}4^{+}$ T 淋巴细胞凋亡，导致免疫系统崩溃。另外，HIV 感染的外周血 T 淋巴细胞对 TRAIL 和 FasL 的诱导凋亡特别敏感。第十三章把 HIV 写成把 T 细胞卡在 $\mathrm{G}_2$ 再凋亡；这里 gp120–CD4 和 TRAIL/FasL 是把外源性途径接到同一群细胞上。

**3. 细胞凋亡与心血管疾病。** 人类的血管内皮细胞、平滑肌细胞和心肌细胞的凋亡是多种心血管疾病发生与演变的病理基础。在动脉粥样硬化、心肌病、急性心肌梗死以及心力衰竭中均伴随着细胞凋亡。近年来对动脉粥样硬化的研究发现，凋亡主要以血管平滑肌细胞和巨噬细胞凋亡为主。窦房结、房室结和希氏束细胞发生过多凋亡，引起心脏传导系统障碍而致心功能不全。

:::keypoint{label="凋亡是封好的自杀，两条路在执行 caspase 汇合"}
- 发育用凋亡裁神经元、拆指间蹼、收蝌蚪尾；成体每天用凋亡更新约 $5\times 10^{11}$ 个血细胞。
- 形态：皱缩、新月状染色质、PS 外翻、凋亡小体；生化：DNA ladder 与 caspase 级联剪切。
- 外源走 DISC–caspase-8，内源走 MOMP–凋亡体–caspase-9；tBid 把前者灌入后者。
- Bcl-2 家族决定 MOMP，p53 把 DNA 损伤接到线粒体，IAP/Smac 给 caspase 设阈值。
- 凋亡过低写成肿瘤和 SLE，过多写成神经退行、AIDS 和心血管损伤。
:::

:::memory{label="本节必背要点"}
- [ ] 凋亡：一定生理或病理条件下遵循自身程序结束生命；希腊语“分离、凋零”，强调自然过程。
- [ ] 每天约 $5\times 10^{11}$ 个血细胞经凋亡更新；发育事例：神经元依赖存活因子、指（趾）间蹼、蝌蚪尾。
- [ ] 诱因：TNF/FasL、TGF-$\beta$、神经递质、$\mathrm{Ca}^{2+}$、糖皮质激素；损伤、放化疗；乙醇、氧化砷、$\beta$ 淀粉样蛋白。
- [ ] 失巢凋亡：脱离微环境后的凋亡，防止异位种植；高转移瘤抗失巢凋亡。
- [ ] 形态：皱缩，染色质新月状贴核膜，骨架紊乱，膜起泡但完整，PS 外翻，形成凋亡小体。
- [ ] 凋亡小体三步：起泡 → 突起（断片进入）→ 脱落；脱落前膜完整。康斯尔曼体是单个致密凋亡小体。
- [ ] DNA 片段化：$180\sim 200\,\mathrm{bp}$ 整数倍，电泳 ladder；坏死为 smear；流式见亚二倍体峰。
- [ ] caspase：Cys 催化、Asp 后剪切；凋亡成员 2、3、6、7、8、9、10；炎症成员 1、4、5、11。
- [ ] 酶原活化：去前域 → 大小亚基分开 → 二聚体 → 活性四聚体。起始 caspase 有 CARD，在多聚平台上自身激活。
- [ ] 起始：caspase-2、8、9；执行/效应：caspase-3、6、7。效应底物包括 ICAD、PARP-1、微丝、核纤层；切 ICAD 释放 CAD 造成 ladder。
- [ ] 凋亡 vs 坏死：单个 vs 成片；膜完整 vs 破损；固缩/半月/ladder vs 肿胀/絮状/smear；有凋亡小体 vs 自溶致炎；有基因调控和蛋白合成 vs 无（程序性坏死除外）。
- [ ] 外源性：TNF-$\alpha$/FasL/TRAIL → TNFR1/Fas/DR-4/5 → DISC → caspase-8 → 执行 caspase。
- [ ] 内源性：损伤 → Bax/Bak 成孔（MOMP）→ cyt c + Apaf-1 + dATP + caspase-9 = 凋亡体。
- [ ] caspase-8 切 Bid 得 tBid，插入线粒体，沟通两条途径。内质网 $\mathrm{Ca}^{2+}$ 和 caspase-12 也参与。
- [ ] Bcl-2/Bcl-XL/Mcl-1 抗凋亡；Bax/Bak/Bok/Bad/Bid/Bim 促凋亡；拮抗决定 cyt c 是否释放。
- [ ] p53：检查点修复 + 转录 NOXA/PUMA 触发 MOMP；肿瘤中突变频率最高；放化疗诱导凋亡依赖它。
- [ ] IAP（cIAP1、cIAP2、xIAP）泛素化降解 caspase-9/3/7；Smac/Diablo、Omi 抑制 IAP。mPT 为内膜电位下降，mPTP 结构未明。
- [ ] 线虫：$1\,090$ 个细胞中 $131$ 个 PCD；$ced$-$3$（≈caspase-3）、$ced$-$4$（≈Apaf-1）、$ced$-$9$（≈Bcl-2）；Horvitz 等 2002 年诺奖。
- [ ] 凋亡过低：肿瘤（$p53$ 突变，FasL 高、Fas 低）；SLE（Fas 缺陷，自身反应性 $\mathrm{CD}4^{+}$/$\mathrm{CD}8^{+}$ T 细胞）。
- [ ] 凋亡过度：神经退行（caspase-3、$\beta$ 淀粉样蛋白、NAIP 突变）；AIDS（gp120–CD4，TRAIL/FasL 敏感）；心血管（VSMC 与巨噬细胞；传导系统细胞过多凋亡）。
:::
