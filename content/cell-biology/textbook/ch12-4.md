# 第四节 细胞信号转导的网络化效应

前两节把通路一条条拆开：GPCR 写成 cAMP 或 $\mathrm{IP}_3$/DAG，RTK 写成 Ras–MAPK，核受体写成 HRE。真实细胞并不按教科书的章节听信号。细胞内有多种多样的信号转导系统，形成相互作用的网络：各条途径相互沟通、串联、影响、制约和协调，共同对各种刺激作出迅速而准确的响应。本节把“一条通路”改写成“一张网”。

:::definition{label="信号网络"}
信号网络（signaling network）是细胞内多条信号转导途径相互沟通、串联、制约和协调而形成的整体。细胞通过网络对胞外信号分子的特异性组合作出分流或整合，从而维持生命活动的有序性。
:::

:::definition{label="串流"}
串流（cross-talk）是相互平行的各条信号转导通路之间发生的交流。一条途径的成员可以激活或抑制另一条途径；不同途径也可以汇聚到同一种效应蛋白或同一基因调控区。
:::

## 一、细胞信号的应答反应特征

### （一）受体–配体反应的特异性与转导分子活化机制的类同性

细胞受体与配体依靠立体构象互补形成受体–配体复合物，启动特定的细胞信号途径，引起特异性生理反应。这是第一节已经写过的特异性。

但是，不同信号通路的绝大多数信号转导分子，其激活或失活机制基本相同：磷酸化和去磷酸化是可逆激活的共同机制，而不同生物的分子开关蛋白的氨基酸组成是保守的。多样性写在受体–配体这一对上，保守性写在激酶和 GTP 酶这两类开关上。看见陌生通路，先问开关是磷酸化还是 GTP/GDP，往往就能读懂它如何开和关。

:::concept{term="锁是特异的，钥匙孔后面的齿轮是通用的"}
肾上腺素认 $\alpha$ 还是 $\beta$，EGF 认 RTK，TGF-$\beta$ 认丝/苏氨酸激酶受体——配体和受体这一层高度特异。进了膜以后，几乎都是“激酶加磷酸、磷酸酶去磷酸”或“GEF 换成 GTP、GAP 促成水解”。把每一条通路都当成全新的化学，反而看不出网络在哪里交叉。
:::

### （二）细胞信号在往前转导过程中被不断放大

细胞内信号传递途径中的组分，每次传递都可以把接收到的信号放大。经历多次信号转换后，引发细胞内信号层层放大的级联反应，即放大效应（amplification）。因此极微量的细胞外信号分子就足以激起一个巨大的胞内反应，有助于信号在细胞中的传播。第一节图 12-5 已经用肾上腺素–cAMP 把这棵放大树画出来；网络并不取消放大，只是让放大后的信号可以被其他通路改写。

:::definition{label="放大效应"}
放大效应（amplification）是信号在胞内逐级传递时，每一级激活的分子数目都比上一级增加，使微量胞外配体足以引发巨大胞内反应的现象。催化性步骤（腺苷酸环化酶、蛋白激酶）是放大的主要引擎。
:::

### （三）细胞外信号强度或持续时间的不同能控制反应的性质

细胞外信号的强度或持续时间不同，引起的效应可能会不一样。体外培养中，神经生长因子（NGF）促进 PC12 细胞分化形成神经元，而表皮生长因子（EGF）则促进 PC12 细胞形成脂肪细胞；如果延长 EGF 刺激时间来强化 EGF 信号强度，也能引起向神经元分化。

NGF 和 EGF 都是 Ras–MAPK 通路的信号分子，但与 EGF 相比，NGF 是更强的激活因子，可以在相对较小的刺激强度下启动神经分化通路；EGF 受体只有延长刺激时间才可能激活同一条神经分化信号通路。通路名字相同，并不等于细胞读到的指令相同——剂量和时间本身就是信息。

:::pitfall{label="同一条 Ras–MAPK 不等于同一个细胞命运"}
把“NGF 和 EGF 都走 Ras–MAPK”写成“二者效应相同”，解释不了 PC12 为什么一个分化、一个偏向别的命运。细胞读的是强度和持续时间，不只是通路的名字。第四节的网络效应，首先是把“开哪条路”改写成“这条路开多久、开多强”。
:::

:::cause-effect{title="EGF 延长刺激如何改写 PC12 命运"}
- 因：NGF 是 Ras–MAPK 的强激活因子，较短刺激即可启动神经分化
- 因：EGF 在常规刺激下强度不足，PC12 走向另一命运（如形成脂肪细胞）
- 果：人为延长 EGF 刺激时间，MAPK 信号被强化到接近 NGF 的工作窗口
- 结果：同一条通路因强度/持续时间不同写出不同分化结局；网络读的是动力学，不只是分子身份
:::

## 二、细胞信号的分流与整合

细胞通过信号网络化效应，能对细胞外信号分子的特异性组合作出分流或整合，调控细胞生命活动。

### （一）细胞信号的分流

:::definition{label="信号分流"}
信号分流是指一个信号可以进入不止一个传递途径或作用于不止一种效应蛋白，在信息流程中形成分支，激起复杂反应。转导途径中的许多步骤对其他因子的调节是开放的，既有胞内因子也有胞外因子；相同受体因下游胞内信号蛋白不同，可引发不同通路。
:::

在秀丽隐杆线虫研究中已经证明，RTK 受体介导的下游通路具有细胞类型特异性。例如 EGF 信号在不同细胞类型中至少可诱发 5 种不同的反应，其中 4 种由共同的 Ras–MAPK 信号通路介导。同一把锁，后面接的齿轮组随细胞类型而换。

### （二）细胞信号的整合

细胞外大量信息以不同组合方式调节细胞行为。细胞必须整合不同的信息，对细胞外信号分子的特异性组合作出程序性反应，从而维持生命活动的有序性。细胞信号转导体系的各种信号通路并非独立存在、彼此无关，而是存在着多种交互联系。相互平行的通路之间的交流就是串流。

信号通路之间的串流有以下特征。

**① 一条途径的成员可激活或抑制另一条途径。** 例如，肾上腺素与其受体结合后，不仅可以通过 $\mathrm{Ca}^{2+}$–二酰甘油/三磷酸肌醇信使体系激活 PKC，而且还可以因 $\mathrm{Ca}^{2+}$ 浓度升高而激活腺苷酸环化酶，促进 cAMP 生成，进而使 PKA 激活。磷脂酰肌醇通路因此可以“串”进 cAMP 通路。

**② 不同途径可磷酸化同一转录因子。** cAMP 信号途径与 $\mathrm{Ca}^{2+}$–二酰甘油/三磷酸肌醇信号途径均能使细胞内的转录因子 CREB 磷酸化并与 DNA 序列结合，影响多种基因的转录。快反应的第二信使在慢反应层汇合。

**③ 不同途径汇聚到同一效应蛋白或同一基因调控区。** 细胞中存在一种受体激活多条信号转导途径、一种信号分子参与多条途径等情况。与细胞增殖和存活密切相关的 cyclin D1、c-myc、survivin 和 VEGF 等基因，其表达受多条通路调控，而且还充当 NF-$\kappa$B 和 STAT 信号转导通路的靶基因。

**④ 通路彼此不同，机制上又相似。** 最终都是激活蛋白激酶；由蛋白激酶形成的信息网络原则上可调节细胞任何特定的过程。蛋白激酶的网络整合信息、调控复杂细胞行为，是不同信号通路之间实现串流的重要方式之一（图 12-21）。

::figure{src="/images/cell-biology/textbook/p0294_01.png" caption="图12-21 细胞信号网络之间的整合。GPCR 经 G 蛋白分出 cAMP–PKA 和磷脂酶 C–IP₃/DAG–PKC 两条支路；RTK 经 Grb2–Ras–MAPK 和 PI3K–Akt 两条支路。四条激酶通路在底部汇聚，共同磷酸化转录因子或其他功能靶蛋白。" alt="GPCR和RTK的多条下游激酶通路在底部汇聚整合"}

:::compare{title="分流 vs 整合"}
| 项目 | 分流 | 整合（含串流） |
|------|------|----------------|
| 信息流向 | 一个输入写成多个输出 | 多个输入写成一个（或一套）输出 |
| 典型机制 | 同一受体接不同下游蛋白；PLC 同时产生 $\mathrm{IP}_3$ 和 DAG | 不同通路磷酸化同一激酶或同一转录因子 |
| 教材例子 | EGF 在线虫不同细胞类型诱发至少 5 种反应 | 肾上腺素既走 PKC 又抬 $\mathrm{Ca}^{2+}$ 激活 AC；CREB 被 cAMP 和 $\mathrm{Ca}^{2+}$ 通路共同磷酸化 |
| 下游汇聚点 | 分支后各走各的效应器 | cyclin D1、c-myc、survivin、VEGF 等可同时作为 NF-$\kappa$B 和 STAT 的靶基因 |
| 网络意义 | 解释“同一配体、多种细胞结局” | 解释“多种配体、同一套增殖/存活程序” |
:::

:::note{label="图 12-21 把第二节的通路接到一张底板上"}
左侧 GPCR 的 cAMP 支路和 $\mathrm{IP}_3$/DAG 支路，右侧 RTK 的 Ras–MAPK 支路和 PI3K–Akt 支路，在“磷酸化转录因子”和“磷酸化功能蛋白”两处汇合。复习第二节时若只记四条孤岛，这张图读不出来；反过来，这张图也提示：PKA、CaMK、PKC、MAPK、Akt 才是网络真正的接线柱。
:::

## 三、细胞信号的反馈调节

细胞信号网络由反馈（feedback）环路组成，包括系列正反馈和负反馈，及时校正反应的速率和强度。

:::definition{label="反馈调节"}
反馈调节是信号网络用输出反过来改写输入或通路中间步骤的机制。正反馈放大并延长反应，负反馈校正速率和强度并帮助终止。细胞对外界信号作出适度反应，既依赖信号的有效刺激和启动，也依赖信号的解除与反应终止，二者同等重要。
:::

当信号浓度过高或细胞长时间暴露于某一种信号刺激时，细胞会以不同机制使受体脱敏，解除与终止信号。这是一种负反馈调节机制。

:::definition{label="受体脱敏"}
受体脱敏是靶细胞在信号过强或过久时，通过减少表面受体数目、清除配体或使信号分子失活等方式，下调自身对信号敏感性的负反馈过程。它防止细胞被持续锁定在一种应答状态。
:::

靶细胞下调敏感性的主要方式有五种。

**① 受体没收（receptor sequestration）。** 细胞通过受体介导的内吞作用减少细胞表面可利用的受体数目。扣留的受体可返回细胞膜被再利用，配体被溶酶体消化。

**② 受体下调（receptor down-regulation）。** 同样通过受体介导的内吞，但受体–配体复合物被溶酶体消化降解，不能被重新利用。表面受体数目因此持久减少。

**③ 受体失活（receptor inactivation）。** 受体结合配体发生自身磷酸化后，再通过抑制蛋白结合而抑制受体活性。这是一种快速使受体脱敏的机制，不必等内吞。

**④ 信号蛋白失活（inactivation of signaling protein）。** 细胞内信号蛋白发生改变，导致信号级联反应被阻断，不能诱导正常的细胞效应，细胞对信号反应脱敏。

**⑤ 产生抑制性蛋白。** 配体与受体结合后，下游反应产生的抑制性蛋白形成负反馈，降低或阻断信号转导途径。例如抑制型 Smad 对 TGF-$\beta$ 通路的刹车。

:::compare{title="五种脱敏方式"}
| 方式 | 主要动作 | 受体能否再利用 | 速度与持久性 |
|------|----------|----------------|--------------|
| 受体没收 | 内吞，受体扣留在胞内 | 可返回质膜 | 可逆、中等速度 |
| 受体下调 | 内吞后受体与配体一起被溶酶体降解 | 不能再利用 | 持久减少表面受体 |
| 受体失活 | 自身磷酸化后结合抑制蛋白 | 仍在膜上，活性被关 | 快速 |
| 信号蛋白失活 | 切断级联中的中间蛋白 | 受体本身可仍在 | 取决于该蛋白的周转 |
| 产生抑制性蛋白 | 下游诱导负反馈蛋白 | 受体可仍在 | 需转录或已有蛋白激活，属负反馈环 |
:::

:::keypoint{label="网络读的是组合、强度和能否关掉"}
- 受体–配体特异，开关机制类同：磷酸化和 GTP/GDP 是共用语言。
- 级联放大让微量配体足够用；强度和持续时间决定同一通路写出哪种命运。
- 分流解释一配体多结局，整合/串流解释多配体一套程序。
- 启动和终止同等重要：五种脱敏方式从膜上的受体一直管到下游抑制蛋白。
:::

:::memory{label="本节必背要点"}
- [ ] 信号网络：多条途径相互沟通、串联、制约、协调；串流（cross-talk）是平行通路之间的交流。
- [ ] 受体–配体反应特异，但转导分子活化机制类同：磷酸化/去磷酸化，开关蛋白序列保守。
- [ ] 放大效应：逐级传递使微量胞外信号激起巨大胞内反应。
- [ ] 信号强度或持续时间可控制反应性质：NGF 与 EGF 都走 Ras–MAPK，但在 PC12 细胞上命运不同；延长 EGF 刺激也可引起神经分化。
- [ ] 分流：一个信号进入多条途径或多种效应蛋白；EGF 在线虫不同细胞类型至少诱发 5 种反应，其中 4 种经 Ras–MAPK。
- [ ] 整合：细胞对信号组合作出程序性反应。
- [ ] 串流特征：一条途径可激活/抑制另一条；cAMP 与 $\mathrm{Ca}^{2+}$–DAG/$\mathrm{IP}_3$ 均可磷酸化 CREB；不同途径汇聚到同一效应蛋白或基因调控区。
- [ ] cyclin D1、c-myc、survivin、VEGF 等既受多通路调控，也是 NF-$\kappa$B 和 STAT 的靶基因。
- [ ] 蛋白激酶网络是实现串流的重要方式。
- [ ] 反馈包括正反馈和负反馈；启动与终止同等重要。
- [ ] 脱敏五种方式：受体没收、受体下调、受体失活、信号蛋白失活、产生抑制性蛋白。
- [ ] 没收的受体可返回膜上；下调则受体被溶酶体降解。
:::
