# 第四节 细胞的运动

细胞有多种运动方式。少数细胞通过纤毛和鞭毛运动：纤毛虫借助纤毛移动和摄取食物，精子依靠鞭毛的摆动在液体中游动。但绝大多数动物细胞通过爬行，在细胞外基质或固体表面上运动。胚胎发育中，机体结构的形成依赖胚胎期细胞向特定靶部位的迁移以及上皮层细胞的协同运动，最典型的例子是神经嵴细胞从神经管长距离迁到体内多个部位、形成不同类型的细胞。巨噬细胞和白细胞从血液循环运动到炎症部位，吞噬并杀伤微生物；成纤维细胞在结缔组织中迁移，有助于创伤组织的修复和重塑；肿瘤细胞的运动则会导致原发肿瘤向周围组织侵袭。

:::definition{label="细胞运动"}
细胞运动泛指细胞整体或局部的主动位移，主要包括纤毛/鞭毛的弯曲拍打和细胞在基质上的爬行。前者以微管轴丝的滑动为基础，后者以皮层肌动蛋白的聚合、黏附和收缩三步循环为基础，并受细胞外信号和 Rho GTP 酶家族调控。
:::

## 一、微管与细胞运动

一些细胞通过纤毛和鞭毛进行运动。例如精子靠鞭毛摆动游动，动物呼吸道上皮细胞靠纤毛的规律摆动向气道外转运痰液。每根纤毛都以高频率往复拍打的方式运动，如同蝶泳者身躯的波浪式动作（图 7-17A）。鞭毛通常比纤毛长，主要用来推动整个细胞：鞭毛不作拍打，而是沿纵轴方向传播规律性波动，类似正弦曲线的运动波，从而推动细胞在液体中穿行（图 7-17B）。

::figure{src="/images/cell-biology/textbook/p0183_01.png" caption="图7-17 纤毛和鞭毛的运动。A. 一根纤毛的拍打运动；B. 海鞘精子鞭毛的波动。" alt="纤毛有效拍打与回复拍打的不对称波形，以及精子鞭毛沿纵轴传播的正弦波"}

:::concept{term="纤毛拍打与鞭毛波动"}
纤毛的有效拍打硬而快、回复拍打弯而慢，才能把液体单向推走；如果两边对称，痰液只会原地搅拌。鞭毛则把弯曲以波的形式从基部传到末梢，细胞被推向波传播的反方向。二者轴丝结构同为“9+2”，差别在波形而不在零件清单。
:::

纤毛和鞭毛的运动是一种简单的弯曲运动，其机制一般用微管滑动模型解释（图 7-18）。

::figure{src="/images/cell-biology/textbook/p0184_01.png" caption="图7-18 微管滑动模型。纤毛和鞭毛动力微管的滑动模型。" alt="动力蛋白臂沿相邻二联管 B 管步进，因横连接限制而把滑动转为轴丝弯曲"}

:::derivation{label="微管滑动如何变成纤毛弯曲"}
1. 动力蛋白头部与相邻微管的 B 管接触，促进与动力蛋白结合的 ATP 水解，并释放 ADP 和磷酸；头部构象改变，朝向相邻二联管的正端滑动，使相邻二联管之间产生滑动趋势。
2. 新的 ATP 结合，促使动力蛋白头部与相邻 B 管脱离。
3. ATP 水解，释放的能量使动力蛋白头部的角度复原，相当于把“腿”重新迈出。
4. 带有水解产物的动力蛋白头部与相邻二联管上的另一个位点结合，开始下一个循环。
5. 若二联管可以自由滑开，轴丝会像望远镜一样伸长；实际上微管连接蛋白和放射辐条把九组二联管拴在一起，滑动受阻，局部伸长转化为弯曲。不同周向位置的动力蛋白臂交替激活，弯曲就沿轴丝传播，形成拍打或波动。
:::

:::pitfall{label="动力蛋白在纤毛里不是“运货”，是“打折”"}
胞质动力蛋白把货物沿微管负端拉向 MTOC；轴丝动力蛋白的“货物”其实是相邻的那根二联管。同一家族的马达，一个负责物流，一个负责把滑动变成弯曲。把第四节的滑动模型直接说成“向核运输”，方向和功能就全错了。
:::

:::note{label="没有 ATP，纤毛立刻僵住"}
滑动循环的每一步都卡在 ATP 的结合、水解或产物释放上。因此缺氧、代谢毒物或轴丝动力蛋白臂缺失（纤毛不动综合征）会得到相似的表型：纤毛还在，却不会弯。结构完整不等于能够运动。
:::

## 二、微丝与细胞运动

细胞爬行是一个高度协同的复杂过程，主要依赖于肌动蛋白和微丝结合蛋白的相互作用。细胞运动可以分为三个过程（图 7-19）：①细胞在运动前缘伸出突起，形成伪足；②这些突起附着在其爬行的表面上；③细胞的其余部分通过锚着点上的牵引力将细胞体向前牵拉。

::figure{src="/images/cell-biology/textbook/p0184_02.png" caption="图7-19 细胞运动三个过程。培养的动物细胞爬行过程模式图。" alt="爬行三步：前缘聚合伸出伪足、整联蛋白黏附成锚着点、胞体收缩前拉并伴随尾缘去黏附"}

所有这三个过程都涉及肌动蛋白丝，但具体机制有所不同。

**第一步，通过肌动蛋白聚合使细胞表面形成突起。** 以成纤维细胞为例，细胞在爬行过程中，其前缘伸出薄薄的片状伪足。片状伪足中含有致密的肌动蛋白丝网络，大部分肌动蛋白丝的正端接近细胞质膜。细胞也会伸出纤细而坚挺的丝状伪足，不仅分布在前缘，也分布在细胞表面的其他部分。丝状伪足宽约 $0.1\,\mu\mathrm{m}$，长 $5\sim 10\,\mu\mathrm{m}$，由 $10\sim 20$ 根松散的肌动蛋白丝纤维束组成，同样正端朝向质膜。发育中神经元的生长锥甚至可以长出 $50\,\mu\mathrm{m}$ 长的丝状伪足，帮助神经元探索周围环境，发现到达目标的正确途径。丝状伪足和片状伪足的形成和回缩速度都很快。

肌动蛋白丝在细胞前缘的形成和生长由微丝结合蛋白介导，它们有助于肌动蛋白在质膜下成核。例如，肌动蛋白相关蛋白 2/3（actin-related protein 2/3，Arp2/3）复合物能够促进分枝状肌动蛋白丝的形成。Arp2/3 复合物在生长的肌动蛋白丝的负端形成一个核心，肌动蛋白丝由此向正端快速生长。Arp2/3 也能以约 $70^{\circ}$ 角结合在原有的肌动蛋白丝上，促进成核并形成新的肌动蛋白丝，进而形成树枝状纤维网络。这个网络在伪足前端聚合、在伪足后端解聚，推动细胞前缘向前移动（图 7-20）。

::figure{src="/images/cell-biology/textbook/p0185_01.png" caption="图7-20 微丝装配的成核作用及微丝网络的形成" alt="Arp2/3 在母丝上以约 70° 成核，树枝状网络前端聚合、后端解聚，推动片状伪足"}

:::definition{label="Arp2/3 复合物"}
Arp2/3 复合物是由肌动蛋白相关蛋白 Arp2、Arp3 及若干辅助亚基组成的成核机器。它结合在已有微丝的侧方，以约 $70^{\circ}$ 角萌出新的子丝，并把负端帽住，使正端朝质膜快速生长，从而把皮层改建成分枝网络，推动片状伪足。
:::

:::concept{term="片状伪足与丝状伪足"}
片状伪足（lamellipodia）是宽而薄的前缘褶皱，内部是 Arp2/3 主导的分枝网络；丝状伪足（filopodia）是细而硬的探针，内部是平行成束的微丝。二者正端都朝向质膜。神经元生长锥把丝状伪足当作“手指”摸路，成纤维细胞则更多靠片状伪足铺开前进面。
:::

**第二步，当片状伪足或丝状伪足接触到适当的表面时，它们就黏附在上面。** 称为整联蛋白的穿膜蛋白与胞外基质中的特定分子或与另一细胞表面上的特定分子结合，这个运动着的细胞就在基质或另一个细胞上面爬行。同时，在爬行细胞膜的内表面，整联蛋白紧密结合肌动蛋白丝，为内部肌动蛋白丝网络提供牢固的锚着点。

**第三步，细胞通过内部的收缩产生拉力，利用锚着点将胞体向前拉动。** 该过程依赖于肌动蛋白与肌球蛋白的相互作用。目前对这种拉力如何在整个细胞尺度上整合，仍有不少细节有待研究；但局部的应力纤维和皮层收缩，足以把后缘从基质上撕脱，并把胞体送向前缘已经铺好的锚点。

:::derivation{label="爬行三步如何把聚合变成位移"}
1. 前缘：WASP 家族活化 Arp2/3，ATP-肌动蛋白在贴近质膜的正端聚合，分枝网络膨胀，膜被推成片状或丝状伪足。
2. 黏附：整联蛋白与细胞外基质配体成簇，胞内经踝蛋白、黏着斑蛋白、桩蛋白接到微丝，把临时突起变成可受力的锚着点。
3. 牵引：细胞后部和中部的肌球蛋白-II 与微丝相互作用产生收缩力，以新锚着点为支点把胞体前拉；尾缘整联蛋白去黏附，旧锚点释放。
4. 三步在空间上同时进行——前端还在聚合，中部已经收缩，尾部正在揭开——细胞才能连续爬行而不是“一伸一停”。
:::

## 三、细胞运动的调节机制

### （一）细胞外信号可以引起细胞骨架的重排

细胞外信号可以调节微丝结合蛋白的活性，使细胞通过细胞骨架重排对外界环境作出应答。许多镶嵌在质膜中的受体蛋白活化后可引发骨架重排。这些信号均由一类称为 Rho GTP 酶的家族介导。该家族的主要成员是 Rho、Rac 和 Cdc42。这类蛋白可以在活化的 GTP 结合状态和失活的 GDP 结合状态之间转换，从而控制细胞骨架重排。Rho 家族不同成员的激活可通过不同方式影响肌动蛋白丝的排列。

- 活化的 **Rho** 既可以促进肌动蛋白丝聚集成束形成应力纤维，又能促进细胞形成黏着斑。
- 活化的 **Rac** 可以促进片状伪足和膜褶皱的形成。
- 活化的 **Cdc42** 可以导致丝状伪足的形成。

这些结构上的显著变化是 Rho GTP 酶分子与不同靶蛋白相互作用的结果，包括控制肌动蛋白结构和动力学的蛋白激酶及其辅助蛋白。下面分别说明引起细胞表面突起、细胞黏附及胞体前移的信号转导机制。

:::definition{label="Rho GTP 酶家族"}
Rho、Rac 和 Cdc42 是调控肌动蛋白构型的分子开关：结合 GTP 时活化，结合 GDP 时关闭。Rho 主掌应力纤维和黏着斑，Rac 主掌片状伪足，Cdc42 主掌丝状伪足。三者把细胞外信号翻译成前缘伸出、黏附和胞体收缩的空间分工。
:::

:::compare{title="Rho vs Rac vs Cdc42"}
| 项目 | Rho | Rac | Cdc42 |
|------|-----|-----|-------|
| 活化后的肌动蛋白表型 | 应力纤维成束，黏着斑增大 | 片状伪足、膜褶皱 | 丝状伪足 |
| 在爬行中的位置倾向 | 胞体中后部，产生牵引力 | 前缘铺开前进面 | 前缘探路、定向 |
| 关键下游 | ROCK → 抑制 MLCP → 肌球蛋白轻链磷酸化↑ → 收缩增强 | WASP 家族、PAK1；PAK1 也可抑制 MLCK 使局部收缩减弱 | WASP 家族 → Arp2/3 成核；作用类似地增强定向收缩 |
| 过度活化的风险 | 黏得太牢，细胞铺开却走不动 | 满细胞起褶皱，失去单一前缘 | 丝状伪足过多，方向信息噪声增大 |
:::

**1. 肌动蛋白聚合使细胞表面形成突起。** Wiskott-Aldrich 综合征蛋白（Wiskott-Aldrich syndrome protein，WASP）是调节细胞运动的关键分子，也是 Rac 和 Cdc42 下游的重要效应分子。Rac 和 Cdc42 通过活化 WASP 家族成员诱导伪足形成，以及细胞外基质的降解。Arp2/3 复合物和肌动蛋白单体与活化的 WASP 家族分子羧基端结构域结合，促进肌动蛋白成核。

**2. 细胞的黏附。** 迁移细胞前缘与细胞外基质的黏附、尾缘与基质的去黏附不断交替，细胞才能向前移动。细胞表面的整联蛋白受体与细胞外基质中特异的配体结合，聚集成簇形成黏着斑复合体；整联蛋白胞内区与桩蛋白（paxillin）、黏着斑蛋白（vinculin，纽蛋白）和踝蛋白（talin）等多种肌动蛋白结合蛋白相互作用，形成分子桥并与细胞骨架相连，提供迁移的锚着点。活化的 Rac 和 Cdc42 通过激活 PAK1 激酶磷酸化下游的黏着斑激酶（focal adhesion kinase，FAK）；活化的 FAK 作为分子支架招募胞质内桩蛋白、黏着斑蛋白和踝蛋白等，促进黏着斑复合体形成。

**3. 细胞胞体前移。** Rho 激活 Rho 相关激酶（Rho-associated kinase，ROCK）。ROCK 活化后通过抑制肌球蛋白轻链磷酸酶（myosin light chain phosphatase，MLCP）活性，增强肌球蛋白轻链磷酸化水平，导致细胞收缩能力增强。Cdc42 的作用与其类似。另外，Rac 会激活 PAK1，活化的 PAK1 通过磷酸化肌球蛋白轻链激酶（myosin light chain kinase，MLCK）使其失活，以降低肌球蛋白轻链的磷酸化水平，使局部收缩力减弱。前缘收缩弱、后部收缩强，才不会把刚伸出的伪足立刻拽回去。

:::insight{label="前缘要“软”，后缘要“狠”"}
Rac 在前缘鼓励聚合、同时压低局部肌球蛋白活性，伪足才能铺开；Rho 在后部拉高肌球蛋白活性，才能把胞体拽上去。如果整细胞同时打开 Rho，细胞会变成一张绷紧却挪不动的饼。极化不是多装微丝，而是把 Rac 和 Rho 放在相反的两端。
:::

:::concept{term="黏着斑是爬行的临时地桩"}
黏着斑把细胞外基质、整联蛋白和细胞内微丝连成一条力的通路。前缘的新斑提供支点，尾缘的旧斑必须拆掉，否则细胞会被自己的锚钉在原地。FAK、踝蛋白和纽蛋白是这条通路上的适配器，不是装饰蛋白。
:::

### （二）细胞外信号可以指导细胞运动的方向

细胞运动需要在特定方向上进行极化（polarization）。细胞分裂以及多细胞结构的形成都依赖于精密调控的细胞极化过程。来自酵母、果蝇、线虫以及脊椎动物的研究表明，细胞骨架在细胞极化过程中起主导作用，触发极化的许多分子在进化上是保守的。

物理性或化学性的外界环境改变能够引起细胞极化并使其产生运动。趋化（chemotaxis）是指在可扩散化学因子的调控下，细胞向某个方向的运动。研究最多的例子是中性粒细胞向细菌感染部位的趋化运动。中性粒细胞表面的受体可以监测到来源于细菌的、浓度极低的 N-甲酰化肽（只有原核细胞从甲酰甲硫氨酸开始进行蛋白质合成），从而引导中性粒细胞向细菌方向移动。

吸附在细胞外基质或细胞表面的非扩散性化学因子也可以影响细胞运动的方向。受体被信号激活后，除了可引起方向性的肌动蛋白聚合，还可导致细胞黏附增强。大多数动物细胞的长距离迁移，如神经嵴细胞，依赖于可扩散的和非扩散性的信号因子协同作用来决定运动方向。

:::definition{label="趋化"}
趋化（chemotaxis）是细胞沿着可扩散化学因子的浓度梯度定向运动。中性粒细胞借助表面受体感知细菌 N-甲酰化肽，把微弱的浓度差转换成前缘 Rac/Cdc42 活化和后缘 Rho 活化，从而朝感染灶爬行。
:::

:::example{label="中性粒细胞如何闻出细菌"}
原核翻译以甲酰甲硫氨酸起始，细菌蛋白和其降解片段常常带着 N-甲酰基；真核胞质翻译没有这一修饰。中性粒细胞把 N-甲酰化肽当作“现场有原核生物”的气味。受体一占领，靠近源的一侧皮层优先活化 Rac 和 Cdc42，对侧 Rho 占优，细胞在几十秒内极化并转向。梯度可以极浅，细胞靠前缘和后缘的信号差而不是绝对浓度来作决定。
:::

:::keypoint{label="两种运动共用马达逻辑、分属两套轨道"}
- 纤毛/鞭毛：微管滑动，动力蛋白臂把相邻二联管的步进变成弯曲。
- 爬行：微丝三步曲——聚合伸出、整联蛋白锚定、肌球蛋白牵引。
- Rho/Rac/Cdc42 把胞外梯度翻译成前缘、黏着斑和应力纤维的空间分工。
- 没有极化就没有有效位移，只有原地起皱或对称拍打。
:::
