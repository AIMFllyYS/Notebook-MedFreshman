# 第三节 蛋白质的生物合成

翻译是遗传信息传递的关键环节，需要 300 多种生物大分子协作，其中包括核糖体、mRNA、tRNA 及多种蛋白质因子。mRNA 作为模板，决定氨基酸顺序；tRNA 作为接合器，把氨基酸送到指定密码子上；rRNA 与蛋白质组成核糖体，作为装配机器。上一节产出的成熟 mRNA 出核之后，本节从密码子读到肽链折叠，再到蛋白质被降解。

:::definition{label="翻译"}
翻译（translation）是以 mRNA 为模板、在核糖体上按遗传密码把氨基酸连接成多肽的过程。信息从核苷酸顺序转换成氨基酸顺序，不能再靠碱基配对直接完成，而必须通过 tRNA 这个接合器。
:::

## 一、遗传信息翻译的基本原理

### （一）mRNA 携带指导蛋白质合成的遗传密码

RNA 和蛋白质结构不同，无法通过碱基互补把信息直接传给蛋白质。组成蛋白质的氨基酸有 20 种，组成 RNA 的碱基只有 4 种，也无法一一对应。现已确定：mRNA 链上从 $5'$ 端到 $3'$ 端每 3 个相邻核苷酸决定一个特定氨基酸，这种核苷酸三联体称为密码子（codon）。除两端非翻译区外，整条 mRNA 由串联排列的密码子组成。mRNA 的碱基排列顺序称作遗传密码（genetic code），它决定蛋白质合成时氨基酸的排列顺序。4 种核苷酸每 3 个一组，共组成 64 种密码子（表 9-2）。

:::definition{label="密码子与遗传密码"}
密码子（codon）是 mRNA 上决定一个氨基酸（或翻译终止）的核苷酸三联体。遗传密码（genetic code）是 mRNA 上密码子的排列，决定肽链的氨基酸顺序。64 个密码子中，UAA、UAG、UGA 为终止密码子，其余 61 个编码氨基酸；AUG 编码甲硫氨酸，并兼作起始密码子。
:::

遗传密码有如下特点。

1. **通用性（universality）。** 从原核到真核，一个特定密码子在几乎所有生物中都编码同一种氨基酸。例外主要出现在动物细胞线粒体和植物细胞叶绿体（详见第六章）。
2. **简并性（degeneracy）。** 61 个密码子编码 20 种氨基酸，必然出现多个密码子决定同一氨基酸的情况。简并多发生在第三位碱基。
3. **连续性（commaless）。** 密码子之间没有间隔，翻译时被连续阅读。移码一个核苷酸，后面的读框全部错位。
4. **方向性（directionality）。** 阅读方向都是 $5'\rightarrow 3'$。起始密码子位于 mRNA 的 $5'$ 侧，终止密码子位于 $3'$ 侧，肽链从 N 端走向 C 端。

:::pitfall{label="终止密码子不编码氨基酸"}
UAA、UAG、UGA 是“停”，不是第 21 种氨基酸。简并性只发生在那 61 个有义密码子上。另外，人线粒体里 UGA 编码色氨酸、AGA/AGG 反而是终止密码子（第六章），不要用核密码去读 mtDNA。
:::

### （二）tRNA 既能识别密码子又能携带特定氨基酸

mRNA 的碱基与氨基酸之间没有直接的化学识别。两者的对应通过 tRNA 实现：tRNA 既能识别 mRNA 上的密码子，又能携带特定氨基酸，因而被称为蛋白质合成的接合器（adaptor）（图 9-8）。

::figure{src="/images/cell-biology/textbook/p0223_01.png" caption="图9-8 tRNA 转运氨基酸机制示意图。氨酰 tRNA 合成酶把氨基酸接到 tRNA 的 3′ CCA 上，反密码子再与 mRNA 密码子配对。" alt="tRNA 氨基酸臂连接活化氨基酸，反密码子与 mRNA 三联体配对"}

tRNA 结构的要点之一是 $3'$ 端的 CCA 序列，活化后的氨基酸通过 CCA 上的 $-$OH 与 tRNA 结合。携带氨基酸由氨酰 tRNA 合成酶催化：第一步是氨基酸活化，氨基酸与 ATP 形成氨酰-AMP；第二步是氨酰基转移到 tRNA 上，形成氨酰 tRNA（aminoacyl tRNA）并释放 AMP。

tRNA 的另一关键部位是反密码环中的三联核苷酸。它在蛋白质合成中通过碱基配对识别 mRNA 上的密码子，称为反密码子（anticodon）。不同 tRNA 有不同的反密码子；反密码子与密码子的正确识别，是遗传信息正确传递的保证。

密码子和反密码子配对具有摆动性（wobble）。密码子的前两位碱基与反密码子配对时严格遵循碱基互补，第三位则有一定灵活性：反密码子的第三个碱基（即其 $5'$ 碱基）可与密码子第三位上的不同碱基配对。例如，携带丙氨酸的 tRNA 反密码子为 $3'$-CGC-$5'$，既可以和密码子 $5'$-GCG-$3'$ 配对，也可以和 $5'$-GCU-$3'$ 配对。

:::definition{label="反密码子与摆动"}
反密码子（anticodon）是 tRNA 反密码环上与 mRNA 密码子配对的核苷酸三联体。摆动（wobble）指配对时密码子第三位（对应反密码子 $5'$ 端碱基）允许非标准配对，使一种 tRNA 可以识别编码同一氨基酸的多个密码子。
:::

:::concept{term="氨酰 tRNA 合成酶才是真正的“翻译官”"}
密码子–反密码子配对只保证“这个 tRNA 对上了那个三联体”。氨基酸是不是挂对了，取决于氨酰 tRNA 合成酶：它既认氨基酸，又认对应的 tRNA。酶一旦挂错，核糖体仍会按反密码子把错的氨基酸嵌进肽链。
:::

## 二、蛋白质合成的场所——核糖体

核糖体（ribosome）也称核蛋白体，是按照 mRNA 指令由氨基酸合成蛋白质的机器。它几乎存在于所有细胞中，线粒体中也有核糖体。

### （一）核糖体是由 rRNA 和蛋白质组成的大分子复合物

生物体有两类基本核糖体：原核的 70S 核糖体，以及真核的 80S 核糖体（真核细胞线粒体内的核糖体近于 70S）。二者均由大、小两个亚基组成。大、小亚基在细胞内一般以游离状态存在，只有当小亚基与 mRNA 结合后，大亚基才与小亚基结合，形成完整核糖体。

在 70S 核糖体中，小亚基为 30S，由 16S rRNA 和 21 种蛋白质组成；大亚基为 50S，由 23S rRNA、5S rRNA 和 34 种蛋白质组成。在 80S 核糖体中，小亚基为 40S，由 18S rRNA 和 33 种蛋白质组成；大亚基为 60S，由 28S rRNA、5.8S rRNA、5S rRNA 及约 49 种蛋白质组成。RNA 约占核糖体的 60%，蛋白质约占 40%。rRNA 主要构成骨架，把蛋白质串联起来并决定其定位。

核糖体是由 rRNA 和蛋白质组成的颗粒，原核为 70S（30S + 50S），真核胞质为 80S（40S + 60S）。它是肽链合成的场所：小亚基负责对准 mRNA，大亚基催化成肽。线粒体核糖体近于 70S，反映其内共生来源。
:::

### （二）核糖体是蛋白质合成的场所

原核细胞中，除少数核糖体附着在质膜上外，大部分以游离形式存在。真核细胞中，很多核糖体附着在内质网膜外表面形成糙面内质网，还有一部分以游离形式分布于细胞质。游离核糖体主要合成细胞的基础性蛋白，附着核糖体主要合成分泌蛋白和膜蛋白。两者结构与功能基本相同，差别在于所合成蛋白质的去向。

核糖体上存在多个与多肽链形成密切相关的活性部位（图 9-10）。

::figure{src="/images/cell-biology/textbook/p0225_02.png" caption="图9-10 核糖体的主要功能位点。包括 mRNA 结合位点、P 位、A 位、转肽酶活性部位以及起始/延长/释放因子结合部位。" alt="核糖体 A 位、P 位、mRNA 通道和转肽酶中心示意图"}

1. **mRNA 结合位点。** 原核 30S 小亚基能专一识别和选择 mRNA 起始位点：16S rRNA 的 $3'$ 端与 mRNA $5'$ 端起始密码子上游碱基配对。原核 mRNA 起始密码子上游有一段富含嘌呤的 SD 序列（Shine-Dalgarno sequence）$5'$-AGGAGGU-$3'$，与 16S rRNA $3'$ 端富含嘧啶的序列 $5'$-CACCUCCUUA-$3'$ 互补，从而把起始密码子正确定位到 30S 小亚基的 P 位。SD 序列又称核糖体结合位点（ribosome binding site，RBS）。真核生物中，核糖体上有专一位点或因子识别 mRNA 的帽子结构，使 mRNA 与核糖体结合。
2. **P 位（peptidyl site）。** 肽酰 tRNA 结合的位置。大部分位于小亚基，小部分位于大亚基，是结合起始肽酰 tRNA、并向 A 位给出肽链延长末端氨基酸的位置。
3. **A 位（aminoacyl site）。** 氨酰 tRNA 结合的位置。大部分位于大亚基而小部分位于小亚基，接受新进入的氨酰 tRNA。
4. **转肽酶活性部位。** 位于 P 位和 A 位的连接处，在肽链延长时催化进入核糖体的氨基酸之间形成肽键。
5. **蛋白因子结合部位。** 结合起始因子（initiation factor，IF）、延长因子（elongation factor，EF）和终止因子或释放因子（release factor，RF）。

:::concept{term="SD 序列是原核的“停靠站”"}
原核 mRNA 没有 $5'$ 帽，小亚基靠 16S rRNA 与 SD 序列配对，把 AUG 对准 P 位。真核则先认帽，再扫描到第一个合适的 AUG。两套起始几何不同，所以真核起始因子不能简单换成 IF1/2/3。
:::

## 三、蛋白质合成及合成后的加工修饰

蛋白质合成可分为氨基酸活化、多肽链合成起始、肽链延长、肽链终止和释放。新合成的蛋白质通常还要经过加工修饰才能成为有特定功能的成熟蛋白质。真核过程较复杂，下面以原核为代表，并指出真核的不同之处。

### （一）氨基酸活化是蛋白质合成的预备阶段

氨基酸在进核糖体前需活化以获得能量。在氨酰 tRNA 合成酶作用下，利用 ATP，氨基酸的羧基与 tRNA $3'$ 端的 CCA-OH 缩合成氨酰 tRNA。生成的酯酰键含较高能量，可用于肽链合成。总反应为：

$$
\text{氨基酸} + \text{tRNA} + \text{ATP} \rightarrow \text{氨酰tRNA} + \text{AMP} + \text{PP}_\mathrm{i}
$$

氨酰 tRNA 合成酶分布在胞质中，既能识别特异氨基酸，又能辨认携带该氨基酸的特异 tRNA，这是保证遗传信息准确翻译的关键之一。

### （二）起始阶段形成起始复合物

起始阶段指核糖体大、小亚基，mRNA 和起始氨酰 tRNA 装配为起始复合物的过程。起始氨酰 tRNA 在原核是甲酰甲硫氨酰 tRNA（fMet-tRNA$^{\mathrm{fMet}}$），在真核是甲硫氨酰 tRNA（Met-tRNA$^{\mathrm{Met}}$）。

大肠埃希菌中翻译起始复合物的形成过程为（图 9-11）：①在起始因子 IF1 和 IF3 作用下，30S 小亚基附着于 mRNA 起始信号部位（SD 序列），形成 IF1–IF3–30S–mRNA 复合物；②在 IF2 作用下，fMet-tRNA$^{\mathrm{fMet}}$ 与 mRNA 的起始密码子配对，形成 30S 前起始复合物；③50S 亚基结合，IF1、IF2 和 IF3 脱落，形成 70S 起始复合物。此时 fMet-tRNA$^{\mathrm{fMet}}$ 占据 50S 亚基的 P 位，A 位留空，等待对应第二个密码子的氨酰 tRNA 进入。

::figure{src="/images/cell-biology/textbook/p0226_01.png" caption="图9-11 大肠埃希菌中翻译起始复合物的形成。IF1/IF3 协助 30S 结合 mRNA，IF2 送入 fMet-tRNA，50S 加入后因子脱落，P 位被占据、A 位空出。" alt="原核翻译起始：30S 前起始复合物再与 50S 结合成 70S 起始复合物"}

真核翻译起始因子称为 eIF（e 代表真核）。某些 eIF 参与 40S 小亚基与 mRNA $5'$ 端帽子结构的结合。起始复合物形成后，40S 小亚基在 mRNA 上扫描直到发现起始密码子 AUG，然后 eIF 被释放，60S 大亚基结合，启动蛋白质合成。此外，mRNA $3'$ 端的 poly A 可以促进起始复合物形成，提高翻译效率。

:::definition{label="翻译起始复合物"}
翻译起始复合物是核糖体亚基、mRNA 与起始氨酰 tRNA 的装配产物。原核以 SD 序列定位，起始 tRNA 为 fMet-tRNA$^{\mathrm{fMet}}$，因子为 IF1、IF2、IF3；真核以帽识别后扫描至 AUG，起始 tRNA 为 Met-tRNA$^{\mathrm{Met}}$，因子为 eIF，poly A 尾协助高效起始。无论原核还是真核，起始 tRNA 都先占据 P 位。
:::

:::pitfall{label="起始氨基酸在成熟蛋白里常常已经不在"}
原核用甲酰甲硫氨酸、真核用甲硫氨酸起步，只说明第一条肽键从这里开始。成熟蛋白质的 N 端大多已经去掉甲酰基、甲硫氨酸甚至更长的一段（包括信号肽）。看见“起始密码子编码甲硫氨酸”，不要推断每个天然蛋白都以 Met 开头。
:::

### （三）肽链延长是多因子参与的核糖体循环过程

起始复合物形成后，根据 mRNA 上密码子的指导，各种氨酰 tRNA 依次结合到核糖体上，使肽链从 N 端向 C 端延长。该过程在核糖体上连续循环进行，又称为核糖体循环（ribosome circulation）。核糖体循环包括进位（registration）、成肽（peptide bond formation）、转位（translocation）三步（图 9-12），每循环一次肽链增加一个氨基酸残基。

:::definition{label="核糖体循环"}
核糖体循环是肽链延长的基本单元，包括进位、成肽和转位。每完成一轮，核糖体沿 mRNA 向 $3'$ 端移动一个密码子，肽链增加一个氨基酸残基。
:::

:::derivation{label="核糖体循环"}
1. **进位。** 起始复合物形成时 A 位空出。延长因子 EF-Tu 与 GTP、氨酰 tRNA 形成三元复合物氨酰 tRNA–EF-Tu–GTP，使与 A 位密码子匹配的氨酰 tRNA 进入 A 位。EF-Ts 调控 EF-Tu–GTP 的再生。
2. **成肽。** P 位和 A 位上各结合一个（肽酰/氨酰）tRNA。大亚基转肽酶催化 P 位氨基酸的 $\alpha$-COOH 与 A 位氨基酸的 $\alpha$-NH_{2} 形成肽键，P 位氨基酸接到 A 位氨基酸的氨基上。A 位形成二肽酰 tRNA，P 位 tRNA 脱落，P 位空出。
3. **转位。** 在延长因子 EF-G 作用下，核糖体沿 mRNA 从 $5'$ 向 $3'$ 移动一个密码子距离，肽酰 tRNA 由 A 位移到 P 位，空出的 A 位接受下一个氨酰 tRNA。
4. 每增加一个氨基酸残基即重复进位、成肽、转位，直至终止密码子进入 A 位。真核延长过程与此大致相同，延长因子为 eEF1$\alpha$、eEF1$\beta\gamma$ 和 eEF2（转位所需）。
:::

:::concept{term="肽链在 A 位长长，再被搬回 P 位"}
成肽发生后，新生肽的羧基端暂时挂在 A 位的 tRNA 上，而不是留在 P 位。转位把这根“已经变长的肽酰 tRNA”搬到 P 位，A 位才腾出来迎接下一个底物。把 P 位理解成“肽链一直呆着的地方”，会说反转位的方向。
:::

### （四）肽链合成终止过程包括三个步骤

当 mRNA 的终止密码子进入 A 位时，没有任何 tRNA 能与之配对，只有释放因子（RF）识别这一信号。原核有 3 种 RF：RF1 识别 UAA 和 UAG，RF2 识别 UAA 和 UGA，RF3 结合 GTP 并促进 RF1、RF2 与核糖体结合。

1. **终止密码的辨认。** A 位出现终止密码子时，RF1 或 RF2 识别并结合到 A 位。
2. **肽链和 mRNA 等释出。** RF 结合使转肽酶构象改变而产生水解酶活性，水解 P 位 tRNA 与肽链间的酯键，肽链脱落。随后 tRNA、RF、mRNA 从核糖体上释出。
3. **核糖体大、小亚基解聚。** 在 IF3 作用下，大、小亚基解聚，重新进入新循环。

真核终止过程相似，但释放因子为 eRF1，可识别全部 3 种终止密码子。

在肽链合成过程中，第一个核糖体向 mRNA 的 $3'$ 端逐步移动，空出翻译起始部位；因此 mRNA 又可结合第二个、第三个甚至更多核糖体。多个核糖体结合到一条 mRNA 上成串排列，是肽链合成的功能单位，称为多聚核糖体（polyribosome）（图 9-13）。每个核糖体独立合成一条多肽链，因此一条 mRNA 可同时合成多条相同的多肽链，大大提高翻译效率。

::figure{src="/images/cell-biology/textbook/p0228_01.png" caption="图9-13 多聚核糖体与蛋白质合成。同一条 mRNA 上串有多个核糖体，各自独立合成一条相同的多肽链。" alt="多聚核糖体：一条 mRNA 上多个核糖体同时翻译"}

:::definition{label="多聚核糖体"}
多聚核糖体（polyribosome）是一条 mRNA 上串接多个核糖体所形成的翻译功能单位。每个核糖体独立合成一条相同的多肽，使同一模板被并行使用。
:::

### （五）蛋白质合成后的加工修饰包括一级结构修饰和高级结构修饰

新生多肽链一般不具有生物活性，需经过化学修饰和加工，才能形成具有天然构象和生物活性的功能蛋白。

#### 1. 一级结构的修饰改变多肽链氨基酸的性质和组成

**（1）肽链氨基端的修饰。** 原核和真核分别以 N-甲酰甲硫氨酸和甲硫氨酸起始，但成熟蛋白质大多不以二者作为 N 端。肽链合成终止时，甚至在合成进行的同时，甲酰基经脱甲酰基酶水解除去，甲硫氨酸或 N 端若干氨基酸残基由氨肽酶水解，包括除去信号肽。

**（2）共价修饰。** 磷酸化、糖基化、甲基化、乙酰化、羟基化和二硫键形成等可改变蛋白质的活性状态。磷酸化多发生在丝氨酸、苏氨酸和酪氨酸残基上，由蛋白激酶催化；许多质膜蛋白和分泌蛋白的丝氨酸或苏氨酸羟基上存在糖基化；胶原蛋白前体的脯氨酸和赖氨酸羟基化形成羟脯氨酸和羟赖氨酸；二硫键在肽链合成后由两个半胱氨酸的巯基氧化形成。

**（3）多肽链的水解修饰。** 有些活性蛋白由其无活性前体水解而来，如蛋白酶原转变为蛋白酶。真核一个 mRNA 一般对应一条多肽链，但少数翻译产物还可通过水解产生不同蛋白质或多肽。例如哺乳动物阿黑皮素原（pro-opiomelanocortin，POMC）可水解产生 $\beta$-促脂解素（$\beta$-LT）、促肾上腺皮质激素（ACTH）、$\beta$-内啡肽及促黑激素（$\alpha$-melanotropin）。

#### 2. 高级结构的修饰包括亚基聚合、多肽折叠和辅基连接

许多蛋白由两个以上亚基构成，各亚基需通过非共价键聚合成多聚体才表现出完整活性，如由两条 $\alpha$ 链和两条 $\beta$ 链组成的人血红蛋白。

新生肽链必须折叠成天然空间构象才能成为有活性的功能蛋白。一级结构是空间结构的基础，同时还需要其他酶和蛋白质辅助。分子伴侣（molecular chaperone）能识别肽链的非天然结构并促进正确折叠，本身并不参与最终装配产物的组成。主要有两类：①蛋白因子，如热激蛋白（heat shock protein，Hsp）、伴侣蛋白（chaperonin），可与部分折叠或未折叠的蛋白质结合，使其免遭水解并促进正确折叠；②酶，如蛋白质二硫键异构酶（protein disulfide isomerase，PDI）识别并水解非正确配对的二硫键，肽-脯氨酸顺反异构酶（PPIase）促进肽酰脯氨酸肽键的顺反异构转换。有些蛋白是带辅基的酶，合成后需要结合相应辅基才有活性。

:::definition{label="分子伴侣"}
分子伴侣（molecular chaperone）是一类识别非天然构象、促进蛋白质正确折叠的蛋白或酶，本身不出现在最终产物中。包括 Hsp、伴侣蛋白，以及 PDI、PPIase 等催化二硫键重整和脯氨酸异构的酶。
:::

## 四、蛋白质的降解

细胞内蛋白质处于不断合成与降解的动态平衡。降解速率或位点异常会影响细胞功能并导致疾病。主要有两条途径：泛素-蛋白酶体途径（ubiquitin-proteasome system）和溶酶体途径。

### （一）蛋白质通过泛素-蛋白酶体途径被降解

这是细胞内蛋白质选择性降解的重要途径。泛素（ubiquitin）是含 76 个氨基酸的小肽，因广泛存在于不同组织和机体中而得名。泛素可与待降解蛋白质共价结合；一个蛋白质可以结合多个泛素分子，称为多泛素化（polyubiquitination），这是启动降解的信号。催化酶主要有 3 种：泛素活化酶（E1）、泛素结合酶（E2）、泛素蛋白连接酶（E3）。E1 激活泛素，需 ATP；激活的泛素被送到 E2；E3 同时结合 E2–泛素和底物，催化泛素转移到底物赖氨酸上。循环反复，一般认为至少结合 5 个泛素后，底物被送入蛋白酶体（proteasome）降解（图 9-14）。

::figure{src="/images/cell-biology/textbook/p0229_01.png" caption="图9-14 蛋白质降解的泛素化反应。E1、E2、E3 依次把泛素装到底物赖氨酸上，多泛素化蛋白进入 26S 蛋白酶体被降解。" alt="泛素经 E1、E2、E3 连接到靶蛋白并被 26S 蛋白酶体降解"}

蛋白酶体是 26S 蛋白复合体，胞核和胞质中均有分布，负责降解泛素化蛋白质，主要是异常蛋白和短寿命蛋白。蛋白酶体本身不具备选择底物的能力，只有被泛素化的蛋白才能被识别、降解。

:::definition{label="泛素-蛋白酶体途径"}
泛素-蛋白酶体途径是 ATP 依赖的选择性蛋白降解系统。泛素（76 氨基酸）经 E1、E2、E3 接到底物赖氨酸上，多泛素化（一般至少 5 个）后被 26S 蛋白酶体识别并降解。主要清除异常蛋白和短寿命蛋白。
:::

### （二）蛋白质在溶酶体通过 ATP 非依赖方式被降解

溶酶体含多种酸性水解酶，可直接分解蛋白质。与蛋白酶体消耗 ATP 不同，溶酶体途径不需要 ATP 提供能量。蛋白质经自噬形成自噬体，或经内吞进入细胞后，在溶酶体中分解为氨基酸。该途径通常是非特异性的蛋白质降解系统：真核的膜蛋白、长寿命蛋白和一部分短寿命蛋白都在溶酶体中降解。降解产物可通过溶酶体膜载体运至胞质，为合成新蛋白质提供原料。

:::compare{title="泛素-蛋白酶体途径 vs 溶酶体途径"}
| 项目 | 泛素-蛋白酶体途径 | 溶酶体途径 |
|------|--------------------|------------|
| 能量 | 需要 ATP（E1 活化泛素等） | ATP 非依赖 |
| 选择性 | 高，依赖多泛素化标签 | 相对非特异 |
| 主要底物 | 异常蛋白、短寿命蛋白 | 膜蛋白、长寿命蛋白、部分短寿命蛋白 |
| 场所 | 胞核与胞质中的 26S 蛋白酶体 | 溶酶体（自噬体或内吞体汇入） |
| 识别 | 蛋白酶体只认泛素化蛋白 | 酸性水解酶直接分解进入溶酶体的蛋白 |
:::

:::keypoint{label="密码、接合器、循环、销毁"}
- 三联体密码连续、$5'\rightarrow 3'$ 阅读；tRNA 用反密码子和 CCA 把氨基酸对上密码子，第三位可摆动。
- 原核 70S、真核 80S；起始 tRNA 进 P 位，延长走“进位–成肽–转位”。
- 一条 mRNA 可串多个核糖体；新生肽还要修饰、折叠，错误或到期的蛋白走 UPS 或溶酶体。
:::

:::memory{label="本节必背要点"}
- [ ] 密码子是 mRNA 上的核苷酸三联体；64 个密码子中 61 个编码氨基酸，UAA、UAG、UGA 为终止，AUG 为起始/甲硫氨酸。
- [ ] 遗传密码：通用性、简并性、连续性、方向性（$5'\rightarrow 3'$）；线粒体/叶绿体有例外。
- [ ] tRNA 是接合器：$3'$ CCA 接氨基酸，反密码子认密码子；摆动发生在反密码子 $5'$ 碱基（密码子第三位）。
- [ ] 氨酰化：氨基酸 + tRNA + ATP → 氨酰 tRNA + AMP + PP$_\mathrm{i}$；特异性由氨酰 tRNA 合成酶保证。
- [ ] 原核核糖体 70S = 30S（16S rRNA + 21 种蛋白）+ 50S（23S、5S rRNA + 34 种蛋白）。
- [ ] 真核核糖体 80S = 40S（18S rRNA + 33 种蛋白）+ 60S（28S、5.8S、5S rRNA + 约 49 种蛋白）；RNA 约 60%、蛋白约 40%。
- [ ] 核糖体直径约 $15\sim 25\,\mathrm{nm}$；游离核糖体合成基础蛋白，附着核糖体合成分泌蛋白和膜蛋白。
- [ ] 原核 SD 序列 $5'$-AGGAGGU-$3'$ 与 16S $3'$ 端互补，把 AUG 放到 P 位；真核依赖帽识别后扫描 AUG。
- [ ] 功能位点：mRNA 结合位点、P 位、A 位、转肽酶、IF/EF/RF 结合部位。
- [ ] 原核起始 tRNA 为 fMet-tRNA$^{\mathrm{fMet}}$（IF1/2/3）；真核为 Met-tRNA$^{\mathrm{Met}}$（eIF），poly A 促进起始。
- [ ] 核糖体循环：进位（EF-Tu/GTP）→ 成肽（转肽酶）→ 转位（EF-G）；真核对应 eEF1$\alpha$、eEF1$\beta\gamma$、eEF2。
- [ ] 终止：RF1 认 UAA/UAG，RF2 认 UAA/UGA，RF3 助结合；真核 eRF1 认三种终止密码子。
- [ ] 多聚核糖体：一条 mRNA 同时合成多条相同多肽。
- [ ] 一级修饰：去 N 端甲酰基/Met/信号肽；磷酸化、糖基化、羟基化、二硫键；POMC 等前体水解。
- [ ] 高级修饰：亚基聚合（如血红蛋白 $\alpha_2\beta_2$）、分子伴侣协助折叠、连接辅基。
- [ ] UPS：泛素 76 氨基酸，E1/E2/E3，多泛素化（≥5）后进 26S 蛋白酶体；溶酶体途径不耗 ATP，降解膜蛋白和长寿命蛋白。
:::
