# 第三节 细胞微环境与细胞间的相互作用

机体的组织是细胞与细胞微环境组成的有机整体，两者相互依存、相互影响，共同决定组织的结构与功能。微环境与细胞之间的相互作用主要包括两条轴线：细胞外基质与细胞之间的相互作用，以及微环境中细胞与细胞之间的相互作用。第二节把基质拆成分子；本节问这些分子和邻居怎样改写细胞的形态、存活、增殖、分化和迁移，细胞又怎样反过来改写基质。

:::definition{label="细胞与微环境的相互作用"}
细胞与微环境的相互作用是组织得以建成并维持功能的双向过程：一方面细胞通过控制基质成分的合成和降解决定 ECM 的组成；另一方面 ECM 和邻居细胞通过黏附受体、可溶性因子、膜结合配体和外泌体，调控细胞的形态、存活、增殖、分化和迁移。
:::

:::definition{label="贴壁依赖性生长"}
贴壁依赖性生长（anchorage dependent growth）是指大多数细胞只有黏附在一定的细胞外基质上并铺展开，增殖周期才能运行。黏附通过整联蛋白把 MAPK 等存活和增殖信号传入细胞内，最终影响增殖相关基因的表达。
:::

## 一、细胞外基质与细胞间的相互作用

关系是双向的。细胞决定基质长什么样；基质决定细胞过怎样的日子。

### （一）细胞外基质对细胞生物学行为的影响

ECM 除与细胞一起构建组织、提供支持、连接和保护外，还对细胞的结构与功能有直接影响。

**1. 影响细胞的形态结构。** 细胞形态往往与特定的生存环境相关。同一种细胞在不同环境中可以有不同形态。体外实验表明，几乎所有组织的细胞在脱离组织、处于单个游离悬浮状态时均呈圆球状。同一种细胞在不同的 ECM 上黏附和铺展时，可表现出不同形态：上皮细胞只有黏附在基膜上才能显示极性，并通过细胞连接成为柱状上皮；成纤维细胞在天然 ECM 中呈扁平多突状，而在 Ⅰ 型胶原凝胶中则呈梭形。

基质对形态的决定作用，主要是通过与细胞表面受体结合，影响细胞骨架成分以不同方式组装和排列来实现的。第十章的黏着斑和半桥粒，就是这套力学语言的结构装置。

:::concept{term="形态是骨架被基质改写后的外观"}
悬浮时大家都是圆的，并不是细胞“本来长这样”，而是没有地方把微丝和中间纤维锚出去。上皮在基膜上才拉出极性，成纤维细胞在 Ⅰ 型胶原凝胶里被拉成梭形。看见一种细胞形态，先问它踩在哪一种基质上，再问整联蛋白把骨架接到了哪一侧。
:::

**2. 影响细胞的生存与死亡。** 大多数类型的细胞需要黏附在一定的 ECM 上才能存活。上皮细胞和内皮细胞一旦脱离基质就会发生凋亡。这种因失去基质、缺少黏附而导致的凋亡称为失巢凋亡（anoikis）。机制主要是：脱离基质后细胞骨架松散，线粒体释放细胞色素 $c$，从而活化 caspase 凋亡途径。当细胞通过整联蛋白黏附于 ECM 时，则可启动存活相关的信号转导途径，维持存活。

:::definition{label="失巢凋亡"}
失巢凋亡（anoikis）是上皮细胞、内皮细胞等因脱离细胞外基质、缺少黏附而发生的凋亡。骨架松散促使线粒体释放细胞色素 $c$，活化 caspase 途径。整联蛋白介导的黏附则启动存活信号，对抗这条通路。
:::

:::cause-effect{title="没地方站，为什么会走到 caspase"}
- 因：上皮或内皮细胞脱离 ECM，整联蛋白失去配体
- 因：细胞骨架松散，线粒体释放细胞色素 $c$
- 果：caspase 凋亡途径被活化，细胞执行失巢凋亡
- 结果：正常组织用这套机制清除“掉队”的细胞；肿瘤细胞若逃过失巢凋亡，就能在悬浮状态下存活并转移
:::

**3. 调节细胞的增殖。** 体外培养证实，大多数细胞只有在一定的 ECM 上黏附并铺展，增殖周期才能运行，即贴壁依赖性生长。细胞黏附于基质时，整联蛋白介导 MAPK 等多种存活和增殖信号传入细胞内，最终影响增殖相关基因的表达。不铺展，信号链就写不完整——这与“有没有生长因子”是两件事。

**4. 参与细胞分化的调控。** ECM 的多种组分可通过与细胞表面受体特异性结合，触发细胞内信号传递的连锁反应，影响核基因的表达，调控分化。特定基质可使某些细胞撤离细胞周期而进入分化状态。例如，内皮细胞在胶原基质上培养时进行增殖，而在层粘连蛋白基质上则停止增殖、进行分化，形成毛细血管样结构；乳腺上皮细胞在基质胶上培养时，不但具有腺管样形态，而且分泌酪蛋白等乳汁成分——酪蛋白基因的表达，是层粘连蛋白与细胞表面 $\alpha_3\beta_1$ 整联蛋白作用后，活化相应信号转导系统而启动的。

第二节已经写过干细胞在不同胶原上的分化选择：Ⅳ 型胶原加层粘连蛋白走向极性上皮，Ⅰ 型胶原加纤连蛋白走向成纤维细胞，Ⅱ 型胶原加软骨粘连蛋白走向软骨细胞。分化不是细胞自己“想起来”的，基质把选项写在贴附面上。

**5. 影响细胞的迁移。** 无论个体发育还是成体组织再生及创伤修复，都伴随着活跃的细胞迁移。迁移过程中的黏附与去黏附、骨架组装与去组装，都离不开 ECM。细胞通过基膜迁移时，需要基质成分的局部降解；胶原酶等基质金属蛋白酶分解局部基质，为迁移开辟道路。这种情况既可发生在白细胞穿过血管基膜迁至炎症或创伤部位，也可发生在肿瘤细胞的浸润和转移过程。

:::pitfall{label="基质不是“越完整越好”的墙"}
完整的基膜挡住成纤维细胞进入表皮，这是屏障；局部被 MMP 打开一个口，白细胞才能抵达炎症灶，这是通路。把 ECM 只写成支架，解释不了为什么没有胶原酶，细胞反而走不动；把降解只写成破坏，又解释不了创伤修复为什么必须先“拆一点”。完整与可降解是同一张网的两面。
:::

### （二）细胞对细胞外基质的影响

**1. ECM 由其所在组织的细胞分泌。** 各种组织的 ECM 都由该组织的实质细胞和间质细胞合成、分泌，成分、含量和存在形式不同。同一个体的不同组织、处于不同发育阶段的同一组织，所产生的 ECM 也不同。例如，胚胎结缔组织主要产生 Ⅲ 型胶原、透明质酸和弹性蛋白；成年结缔组织中成纤维细胞则以 Ⅰ 型胶原、纤连蛋白等为主要产物。组织的功能状态不同，基质成分也会跟着变。

**2. ECM 成分的降解由细胞分泌的蛋白水解酶催化。** 降解源于细胞分泌的基质金属蛋白酶（matrix metalloproteinase，MMP）和丝氨酸蛋白酶家族的联合作用。MMP 是一类 $\mathrm{Zn}^{2+}$ 和 $\mathrm{Ca}^{2+}$ 依赖的蛋白酶，迄今已鉴定 20 余种，如胶原酶、明胶酶、基质溶解素、弹性蛋白酶等。其中胶原酶具有高度特异性，可以切割蛋白质上的特异位点，从而既保证基质结构的完整性，又为细胞迁移开辟道路。

:::definition{label="基质金属蛋白酶"}
基质金属蛋白酶（MMP）是 $\mathrm{Zn}^{2+}$、$\mathrm{Ca}^{2+}$ 依赖的细胞外蛋白酶家族，已鉴定 20 余种，包括胶原酶、明胶酶、基质溶解素和弹性蛋白酶等。它们由细胞分泌，特异性切割 ECM 组分；细胞同时分泌其抑制剂，把降解限制在局部、控制在一定程度。
:::

细胞还可分泌 MMP 和丝氨酸蛋白酶的抑制剂，控制蛋白酶的作用程度和范围。细胞对 ECM 降解的控制与调节，对创伤修复、组织重构以及细胞迁移都有重要作用。合成与降解这一对反向操作，才是微环境稳态在基质这一侧的具体写法。

:::note{label="谁分泌基质，谁就有资格改写微环境"}
胚胎间质写 Ⅲ 型胶原和透明质酸，成年成纤维细胞改写成 Ⅰ 型和纤连蛋白；肿瘤相关成纤维细胞再把这套装置加成蛋白水解酶工厂。基质的身份证上写的是分泌它的细胞，而不是组织的中文名。
:::

## 二、微环境中细胞与细胞间的相互作用

在细胞微环境中，细胞与细胞之间的相互作用（cell-cell interaction）对多细胞生物个体的发育和分化，以及维持正常生命活动至关重要。机制主要有三条：①相邻细胞分泌的旁分泌因子（paracrine factor）对细胞的作用；②细胞膜并置在一起的近分泌相互作用（juxtacrine interaction）；③相邻细胞分泌的外泌体对细胞的调控。

:::definition{label="旁分泌"}
旁分泌（paracrine）是细胞把可溶性因子分泌到局部细胞外液，作用于邻近靶细胞的通讯方式。因子作用距离短、浓度梯度陡，是微环境中最常见的化学语言，与经血液运输的内分泌相对。
:::

:::definition{label="近分泌"}
近分泌（juxtacrine interaction）是相邻细胞膜并置时，膜结合配体与对侧膜受体直接结合而传递信号的方式。配体不离开质膜，因此只有真正贴在一起的细胞才能通话，典型如 Notch 等膜受体系统。
:::

:::definition{label="外泌体"}
外泌体（exosome）是细胞释放到微环境中的膜性小囊泡，内含蛋白质、脂质和核酸。相邻或近距离细胞摄取外泌体后，可获得其中的调控分子，从而在不直接接触、也不单靠可溶性因子的情况下改写靶细胞行为。
:::

处于微环境中的细胞还可接受来自远距离的、经血液运输物质的调控，如激素的调控，以及器官之间的互作调控（如脑-肠轴、骨-脑轴及肝-骨轴等）。微环境是局部的，但不孤立：局部旁分泌、近分泌和外泌体写的是邻里关系，内分泌和器官轴写的是远程补给。

:::compare{title="旁分泌 vs 近分泌 vs 外泌体"}
| 项目 | 旁分泌 | 近分泌 | 外泌体 |
|------|--------|--------|--------|
| 信号载体 | 可溶性因子（生长因子、细胞因子等） | 膜结合配体 | 膜性小囊泡（含蛋白、脂质、核酸） |
| 是否离开细胞 | 分泌到局部液体或被 ECM 暂存 | 不离开质膜 | 囊泡释放到微环境 |
| 作用距离 | 邻近细胞，有浓度梯度 | 必须膜与膜并置 | 邻近或近距离，可跨越一小段间隙 |
| 对接触的依赖 | 不要求稳定的细胞连接 | 高度依赖接触 | 不要求稳定连接，但需靶细胞摄取 |
| 可被 ECM 调制 | 常被蛋白聚糖结合、储存、释放 | 一般不经基质仓库 | 可在基质和液体相中扩散 |
| 典型功能 | 局部增殖、分化、炎症 | 精确的邻细胞命运决定 | 批量递送调控分子，包括核酸 |
:::

:::concept{term="局部对话和远程补给不是同一套邮路"}
旁分泌、近分泌、外泌体都发生在微环境尺度，决定的是“这一个龛里的细胞此刻做什么”。激素和器官轴走血液，决定的是器官之间的配合。把甲状腺激素写成微环境因子，或把肿瘤相关巨噬细胞分泌的细胞因子写成内分泌，都会把尺度写错。
:::

:::keypoint{label="基质改细胞，细胞改基质"}
- ECM 决定形态（经骨架）、存活（失巢凋亡）、增殖（贴壁依赖）、分化（配体特异性）和迁移（局部降解）。
- 失巢凋亡：脱离基质 → 骨架松散 → 细胞色素 $c$ → caspase。
- 细胞用合成和 MMP/丝氨酸蛋白酶降解两套操作改写基质；抑制剂把降解限制在局部。
- 细胞间局部对话：旁分泌（可溶）、近分泌（膜并置）、外泌体（囊泡）。
- 远程调控（激素、器官轴）叠加在微环境之上，不取代局部机制。
:::

:::memory{label="本节必背要点"}
- [ ] 组织 = 细胞 + 微环境；相互作用包括 ECM–细胞 和 细胞–细胞 两条轴线，且都是双向的。
- [ ] 游离悬浮时细胞呈圆球状；上皮必须黏附基膜才显示极性；成纤维细胞在 Ⅰ 型胶原凝胶中呈梭形。
- [ ] 形态改变通过表面受体影响骨架组装与排列来实现。
- [ ] 失巢凋亡（anoikis）：上皮/内皮脱离 ECM → 骨架松散 → 线粒体释放细胞色素 $c$ → caspase。
- [ ] 整联蛋白黏附可启动存活信号，对抗失巢凋亡。
- [ ] 贴壁依赖性生长：多数细胞须在基质上黏附铺展才能运行增殖周期；整联蛋白→MAPK 等通路。
- [ ] 内皮细胞在胶原上增殖，在层粘连蛋白上分化成毛细血管样结构。
- [ ] 乳腺上皮在基质胶上呈腺管样并分泌酪蛋白，依赖层粘连蛋白与 $\alpha_3\beta_1$ 整联蛋白。
- [ ] 干细胞：Ⅳ 型胶原+LN → 上皮；Ⅰ 型胶原+FN → 成纤维细胞；Ⅱ 型胶原+软骨粘连蛋白 → 软骨细胞。
- [ ] 迁移需要黏附/去黏附和局部基质降解；MMP 为白细胞过血管基膜和肿瘤浸润开路。
- [ ] ECM 由实质细胞和间质细胞分泌；胚胎结缔组织以 Ⅲ 型胶原、HA、弹性蛋白为主，成年以 Ⅰ 型胶原、FN 为主。
- [ ] MMP 依赖 $\mathrm{Zn}^{2+}$、$\mathrm{Ca}^{2+}$，已鉴定 20 余种（胶原酶、明胶酶、基质溶解素、弹性蛋白酶）；胶原酶位点特异。
- [ ] 细胞同时分泌 MMP/丝氨酸蛋白酶抑制剂，控制降解范围，服务创伤修复和组织重构。
- [ ] 细胞–细胞相互作用三条：旁分泌因子、近分泌（膜并置）、外泌体。
- [ ] 细胞还接受远程调控：激素以及脑-肠轴、骨-脑轴、肝-骨轴等器官互作。
:::
