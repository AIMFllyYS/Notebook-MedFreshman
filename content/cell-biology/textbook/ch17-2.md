# 第二节 胚胎干细胞

第一节把干细胞写成自我更新加上受限定的分化潜能，并把内细胞团定为多能这一级。把内细胞团从囊胚里取出来、在体外稳定培养，得到的就是通常所说的胚胎干细胞（ES 细胞）。本节写它的形态、三胚层潜能怎么被证明、体外怎样被诱导，以及用核移植和转录因子重编程得到的“看起来像 ES”的多能干细胞。组织干细胞留在第三节对照。

胚胎干细胞还可以从原肠胚之后的原始性腺中分离，称为胚胎生殖细胞（embryonic germ cell，EG 细胞），性质与 ES 相似。通过细胞重编程获得的多能干细胞，包括体细胞核移植（somatic cell nuclear transfer，SCNT）得到的 ES 细胞（SCNT-ES）以及诱导多能干细胞（induced pluripotent stem cell，iPSC），在形态、生长和分化潜能方面与 ES 也极其相似。

:::definition{label="胚胎干细胞"}
胚胎干细胞（embryonic stem cell，ES 细胞）是从囊胚内细胞团分离并在体外稳定培养所得到的多能干细胞。它可以分化为胎儿或成体组织中的各种细胞类型，在适宜条件下呈克隆化生长并保持正常二倍体核型。
:::

:::definition{label="胚胎生殖细胞"}
胚胎生殖细胞（embryonic germ cell，EG 细胞）是从原肠胚之后的原始性腺分离获得的多能干细胞，性质与 ES 细胞相似。来源是生殖嵴/原始生殖细胞，不是内细胞团。
:::

## 一、胚胎干细胞的生物学特性

### （一）体外培养呈克隆化生长并快速增殖

胚胎干细胞具有原始细胞的形态和生化特征：体积较小，核质比例较大，内质网及高尔基复合体等细胞器不发达。在囊胚中，它们以致密集落（即内细胞团）贴在囊胚内侧壁上。体外培养时仍保持这些特征：体积小、核质比很大，核中可有多个核仁，生长呈致密的鸟巢样集落。单个 ES 细胞在适合条件下迅速增殖，形成由性质相同的细胞构成的克隆，可以传代、做遗传操作和冻存。传代条件稳定时，能保持正常的二倍体核型。各种哺乳动物的胚胎干细胞在体外都有相似的形态。

:::definition{label="ES 的克隆化生长"}
克隆化生长是指单个 ES 细胞在体外迅速增殖，形成由性质相同的细胞构成的致密集落（鸟巢样），并可连续传代。条件稳定时核型保持为正常二倍体，这是后续遗传操作和分化实验的前提。
:::

### （二）具有向三个胚层分化的潜能

囊胚内细胞团在体内可以分化为个体的任何组织细胞。ES 体外培养成功后，这件事被三套实验钉死：胚状体形成、畸胎瘤实验，以及被称作“金标准”的嵌合体实验（图 17-3）。体外自发分化和诱导分化是另外两条常用路径，细节在下一小节。

**1. 胚状体形成实验。** 将 ES 或 EG 置于白血病抑制因子（LIF）存在的条件下，部分细胞能分化成胚状体（embryoid body，也称类胚体、拟胚体）。胚状体中可以找到来源于三个胚层的各种分化细胞。

**2. 畸胎瘤实验。** 把体外培养的胚胎干细胞移植到免疫缺陷小鼠皮下，观察是否形成由外、中、内胚层来源细胞组成的混合组织瘤。能出三胚层组织，才算多能还在。

**3. 嵌合体实验。** 把体外培养的胚胎干细胞移植到小鼠囊胚腔中，观察植入细胞是否分化为后代小鼠的组织细胞。这被认为是证明 ES 多向分化潜能的金标准。由于伦理学原因，该方法不能用于人胚胎干细胞的分化评价。

:::definition{label="胚状体"}
胚状体（embryoid body）是 ES 或 EG 在体外聚集成的三维分化结构，内部可出现来源于外、中、内三个胚层的多种细胞。它把“能出三胚层”写成可以在培养皿里解剖的标本。
:::

:::definition{label="嵌合体实验"}
嵌合体实验是把体外培养的 ES 注入宿主囊胚，看植入细胞是否参与后代各组织的发育。它是证明小鼠 ES 多能性的金标准；人 ES 因伦理学限制不能做这一步，只能退到胚状体和畸胎瘤。
:::

::figure{src="/images/cell-biology/textbook/p0377_02.png" caption="图17-3 胚胎干细胞分化潜能检测方法。A. 低密度培养形成胚状体，再在体外分化出多种细胞；B. 注射至 NOD/SCID 小鼠皮下形成畸胎瘤，做组织学分析；C. 标记的 ES 注入未标记宿主囊胚，形成嵌合体小鼠。" alt="ES多能性三套检测：胚状体、免疫缺陷小鼠畸胎瘤和囊胚嵌合体"}

应当指出，人与小鼠的胚胎干细胞在诸多方面存在差异：培养条件完全不同，克隆形态、生长、表面标记及潜能状态也不一样。虽然小鼠和人类 ES 多能性的维持都有转录因子 Oct4、Sox2 和 Nanog 参与，但下游通路和精细调控并不完全一致。把小鼠培养体系原样搬到人 ES 上，克隆会散、多能性会掉。

:::pitfall{label="嵌合体是金标准，并不等于人 ES 也能去做"}
三套实验里，只有嵌合体证明“这颗细胞能走进完整个体的每一种组织”。畸胎瘤证明能出三胚层肿瘤组织，胚状体证明能在体外出三胚层细胞，都比嵌合体弱一档。人 ES 停在前两档，不是因为多能性一定更差，而是伦理把金标准关掉了。用人 ES 的畸胎瘤阳性直接等同于“可以参与人体发育”，会把实验证据的级别说满。
:::

:::cause-effect{title="为什么证明多能性要过三道关"}
- 因：体外出现几种分化细胞，可能只是培养条件碰巧推了一两个方向
- 因：皮下成瘤可以出三胚层组织，但仍是肿瘤微环境，不是正常发育
- 果：注入囊胚并参与嵌合体，才证明这些细胞能被正常胚胎信号收编、走进身体各组织
- 结果：小鼠 ES 用嵌合体做金标准；人 ES 只能用胚状体和畸胎瘤近似，临床应用更要另证功能和安全性
:::

## 二、胚胎干细胞的体外分化

ES 细胞的分化受内源性和外源性因素共同调节。内源性因素是不同基因在不同时间和空间的开启与关闭，涉及各种转录因子；外源性因素则是细胞间的分化诱导、分化抑制以及细胞外物质的介导。第十二章把信号写成细胞怎么听；这里听的对象换成“要不要继续当多能干细胞，还是滚向某一个胚层”。

ES 分化研究分成一般诱导分化和定向诱导分化。前者加入一定的分化诱导剂，如全反式维 A 酸（all-trans-retinoic acid，ATRA），细胞就可以同时或先后分化出不同类型，反映的是不受约束的随机分化，应用意义不大。定向诱导分化才是热点：改进培养方式、选择诱导剂，获得终末目标细胞，并研究定向分化的分子机制。目前已报道由 ES 诱导得到的细胞包括造血细胞、心肌细胞、神经细胞、脂肪细胞、胰岛细胞、内皮细胞、上皮细胞、肝细胞、成骨细胞和软骨细胞等。

体外诱导的研究思路大约分成两类。一类先诱导形成胚状体，再从中分离目标细胞并扩大培养；另一类不经过胚状体，用单层培养的 ES 直接诱导，往往需要分步才能完成。

实验室里确实可以把胚胎干细胞诱导成许多具有相应表型的组织细胞，但分化效率、成熟程度、分离纯度，以及在活体中是否具有真正功能，仍然有许多问题没有解决。表型像心肌，不等于移植后能同步搏动；表型像神经元，不等于能接进宿主环路。

:::concept{term="随机分化出一堆细胞，不等于拿到了药"}
ATRA 一类诱导剂把多能性的刹车松开，三个胚层都会往外冒，看起来“什么都能变”。治疗需要的是某一类足够纯、足够成熟、在活体里真能工作的细胞。定向诱导是把许可收成一条路；胚状体路径和单层分步路径是两条操作，不是两个终点。
:::

:::note{label="LIF 维持未分化，撤掉或换诱导剂才让路"}
小鼠 ES 常用 LIF 维持多能性。胚状体实验却写“在 LIF 存在下部分细胞能成胚状体”，提示同一培养体系里总有细胞掉队进入分化。读实验时要分清：体系是为了维持干细胞，还是故意让它聚成三维结构往三胚层走。条件一乱，建系会变成一盘杂细胞。
:::

## 三、利用重编程技术获得的多能干细胞

第十五章已经把已分化细胞核写入去核卵仍能发育成体，叫做全能性细胞核；把人为逆转称为细胞重编程，产物是 iPSC。这里把两条操作写具体。

**1. 体细胞核移植。** SCNT 是把供体细胞核移入已去核的卵细胞。由此获得与供体遗传匹配的胚胎，再从囊胚中取出胚胎干细胞。美国俄勒冈健康与科学大学的 S. Mitalipov 首次用 SCNT 获得人类胚胎干细胞（hESC）。这一结果有助于解析患者个体差异病因，也指向个性化疗法；但卵细胞来源相关的伦理学问题，限制了它在基础研究和临床中的铺开。

**2. 诱导多能干细胞。** 2006 年，山中伸弥团队用病毒载体把四个转录因子 Klf4、Sox2、Oct4 及 c-Myc 导入小鼠成纤维细胞，获得诱导多能干细胞，即 iPS 细胞。一年后，人 iPS 也用类似因子体系建成。人 iPS 的多潜能性质与人 ES 并不完全一致，但形态和分化能力极其相似：体外能分化成三胚层，能在免疫缺陷小鼠体内形成畸胎瘤。与 ES 相比，iPS 最大的优势是避开胚胎伦理争议，并显著缓解异体移植的免疫排斥。

:::definition{label="体细胞核移植 ES"}
SCNT-ES 细胞是通过体细胞核移植（somatic cell nuclear transfer）把供体核移入去核卵，再从重构囊胚的内细胞团建立的胚胎干细胞。遗传上与供体匹配，但依赖卵母细胞，伦理门槛高。
:::

:::definition{label="诱导多能干细胞"}
诱导多能干细胞（induced pluripotent stem cell，iPSC）是用特定转录因子（经典为 Oct4、Sox2、Klf4、c-Myc）把已分化体细胞重编程得到的多能干细胞。它在形态和三胚层分化能力上与 ES 极其相似，并避开胚胎来源和部分免疫排斥问题。
:::

:::definition{label="多能干细胞"}
多能干细胞（pluripotent stem cell，PSC）在本节是 ES、SCNT-ES 和 iPS 的统称。它们都能（或近似能）分化为三个胚层，用于药物筛选、疾病模型和患者个体化治疗。
:::

通过对 PSC 的定向诱导，目前已可高效获得心肌细胞、肝细胞、特定神经元、胰腺 $\beta$ 细胞、视网膜色素上皮等功能细胞。例如：多能干细胞来源的中脑多巴胺神经元移植治疗帕金森病、视网膜色素上皮治疗黄斑变性，以及胰腺 $\beta$ 细胞移植物治疗 1 型和 2 型糖尿病，均已进入临床研究。长处在于能出功能细胞；第四节会补上成瘤性这个致命短板。

:::compare{title="ES vs SCNT-ES vs iPS"}
| 项目 | ES | SCNT-ES | iPS |
|------|----|---------|-----|
| 起点 | 囊胚内细胞团（或 EG 来自原始性腺） | 体细胞核 + 去核卵 → 重构囊胚 ICM | 已分化体细胞 + 重编程因子 |
| 遗传匹配 | 与供胚个体相同，对患者通常是异体 | 与核供体匹配 | 可做成患者自体 |
| 伦理焦点 | 使用人类胚胎 | 使用卵母细胞和重构胚胎 | 一般不消耗胚胎和卵 |
| 多能性证据 | 小鼠可达嵌合体金标准；人 ES 用胚状体和畸胎瘤 | 同 ES 路径 | 三胚层分化和畸胎瘤；与人 ES 并非完全等同 |
| 临床吸引力 | 分化潜能强，来源受限 | 个性化，卵源受限 | 避开胚胎伦理，减轻免疫排斥 |
| 共同风险 | 残留未分化细胞可能成瘤；定向分化的效率、纯度和活体功能仍需过关 | 同左 | 同左；重编程本身还可能留下表观遗传记忆 |
:::

:::keypoint{label="ES 是体外的内细胞团，iPS 是重编程出来的近亲"}
- ES 体积小、核质比大、鸟巢样克隆生长，条件稳定则保持二倍体核型。
- 多能性三套证据：胚状体、畸胎瘤、嵌合体；嵌合体是金标准，人 ES 做不了。
- 人与小鼠 ES 的培养条件、克隆形态和 Oct4/Sox2/Nanog 下游通路并不相同。
- 随机诱导意义有限；定向诱导走胚状体或单层分步，仍要过效率、纯度和活体功能三关。
- ES、SCNT-ES、iPS 统称 PSC：前两条靠胚胎或卵，iPS 靠四个转录因子把体细胞往回写。
:::

:::memory{label="本节必背要点"}
- [ ] ES：从囊胚 ICM 体外培养得到的多能干细胞；EG：从原肠胚后原始性腺分离，性质相似。
- [ ] 重编程来源：SCNT-ES（核移植）和 iPSC；与 ES 在形态、生长和分化潜能上极其相似。
- [ ] 形态：体积小、核质比大、细胞器不发达；核可有多个核仁；体外呈致密鸟巢样集落。
- [ ] 克隆化生长：单个 ES 迅速增殖成性质相同的克隆，可传代、遗传操作和冻存；条件稳定则保持正常二倍体核型。
- [ ] 多能性检测：①胚状体（三胚层细胞）；②畸胎瘤（免疫缺陷小鼠皮下，三胚层混合组织瘤）；③嵌合体（注入囊胚，金标准）。
- [ ] 嵌合体实验因伦理不能用于人 ES。
- [ ] 人与小鼠 ES 培养条件、克隆形态、表面标记和潜能状态不同；都用 Oct4、Sox2、Nanog，下游通路不完全一致。
- [ ] 分化受内源基因时空开关和外源诱导/抑制及胞外物质共同调节。
- [ ] 一般诱导（如 ATRA）是随机分化，应用价值有限；定向诱导才为了拿终末目标细胞。
- [ ] 已诱导细胞类型包括造血、心肌、神经、脂肪、胰岛、内皮、上皮、肝、成骨和软骨等。
- [ ] 两条思路：先成胚状体再分离；或单层分步直接诱导。效率、成熟度、纯度和活体功能仍是瓶颈。
- [ ] SCNT：供体核 → 去核卵 → 遗传匹配胚胎 → ES。Mitalipov 首次获得人 SCNT-ES；卵源伦理限制应用。
- [ ] 2006 年山中伸弥用 Klf4、Sox2、Oct4、c-Myc 把小鼠成纤维细胞做成 iPS；一年后建成了人 iPS 细胞。
- [ ] 人 iPS 与人 ES 多潜能性质不完全一致，但能成三胚层、能成畸胎瘤；优势是伦理和免疫排斥。
- [ ] ES、SCNT-ES、iPS 统称 PSC，用于药物筛选、疾病模型和个体化治疗。
- [ ] 已进入临床研究的例子：中脑多巴胺神经元（帕金森病）、视网膜色素上皮（黄斑变性）、胰腺 $\beta$ 细胞（1 型和 2 型糖尿病）。
:::
