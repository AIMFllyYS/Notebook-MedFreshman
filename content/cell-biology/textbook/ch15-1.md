# 第一节 细胞分化的基本概念

第十四章把受精写成单倍体精子和卵子再合成 $2n$ 的受精卵。受精卵随后走第十三章的卵裂和有丝分裂，把同一套基因组交给越来越多的子代。子代为什么不再彼此相同——神经元长出突起并以突触传导冲动，肌细胞呈梭形、靠肌动蛋白和肌球蛋白收缩，红细胞呈双凹圆盘并装载血红蛋白，胰岛 $\beta$ 细胞分泌胰岛素——是本章的问题。人体和其他脊椎动物约有 $200$ 多种形态、结构和功能都稳定不同的成熟细胞，全部来自同一个受精卵。细胞分化（cell differentiation）贯穿个体发育、成熟与维持，胚胎期最活跃；弄清它的机制，既是理解多细胞生命怎样被写出来，也是给肿瘤、再生和出生缺陷找入口。本节先把概念写清楚：潜能怎样缩窄、决定怎样先于可识别的分化、分化稳不稳、还能不能回头；第二节写基因组怎么选择性表达；第三节写细胞外信号怎样把位置信息写进核；第四节把分化接到医学。

:::definition{label="细胞分化"}
细胞分化（cell differentiation）是在生命个体发育、成熟及维持过程中，一种细胞向生化组成、结构和功能上更为特定的细胞转变的过程。分化细胞获得并保持特化特征，合成特异性蛋白质。
:::

:::definition{label="成熟细胞"}
成熟细胞（maturation cell）是形态、结构和功能已特化并具有稳定特性的终末分化细胞。神经元、肌细胞、红细胞和胰岛 $\beta$ 细胞都是例子：它们由单个受精卵经分化形成，一般情况下不再回到未分化状态。
:::

个体生命历程一般包括胚胎发育和胚后发育、成熟与维持。前者经卵裂、囊胚、原肠胚及器官发生，形成与亲代相似的幼小个体；后者从孵化或分娩一直走到衰老与死亡。细胞分化贯穿全生命周期，但胚胎期最活跃。

## 一、多细胞生物个体发育过程与细胞分化潜能

### （一）三胚层代表不同类型细胞的分化去向

动物胚胎发育始于受精卵进入快速有丝分裂。这一分裂时期称为卵裂（cleavage）。卵裂产生许多较小的细胞，形成中空球形体，即囊胚（blastula）；到这一时期，各细胞开始显示出功能差异。胚胎随后进入原肠胚（gastrula）期，形成去向不同的内、中、外三个胚层。

:::definition{label="卵裂、囊胚与原肠胚"}
卵裂（cleavage）是受精后受精卵的快速有丝分裂。囊胚（blastula）是卵裂后形成的中空球体，细胞开始出现功能差异。原肠胚（gastrula）期形成内胚层、中胚层和外胚层，三胚层分别代表不同类型细胞的分化去向。
:::

内胚层（endoderm）发育为消化道及其附属器官、唾液腺、胰腺、肝脏以及肺等的上皮成分；中胚层（mesoderm）发育为骨骼、肌肉、纤维组织和真皮，以及心血管系统和泌尿系统；外胚层（ectoderm）形成神经系统、表皮及其附属物。生殖细胞另成一条线，最终形成精子和卵子（图 15-1）。第十四章已经把原始生殖细胞写成从上胚层指定、迁入生殖嵴；这里只需记住：原肠胚把“往后能变成什么”第一次写成空间分区。

::figure{src="/images/cell-biology/textbook/p0333_01.png" caption="图15-1 脊椎动物细胞分化示意图。受精卵经囊胚、原肠胚分成外胚层、中胚层、内胚层和生殖细胞：外胚层形成表皮、脑神经元和色素细胞；中胚层形成脊索、骨骼肌、肾小管、红细胞和面部肌肉；内胚层形成胰腺、甲状腺和肺上皮；生殖细胞形成精子和卵子。" alt="受精卵经囊胚原肠胚分化为外中内三胚层和生殖细胞及其代表性组织细胞"}

### （二）细胞分化的潜能随个体发育逐渐缩窄

随着胚胎发育，来源于单一受精卵的细胞逐渐在空间与时间上获得特定形态和功能。两栖类囊胚形成之前的卵裂球、哺乳动物 $8$ 细胞期之前的桑葚胚细胞，和受精卵一样可形成完整个体。三胚层形成后，细胞所处的空间位置和微环境不同，分化潜能受到限制：各胚层细胞只能向本胚层组织和器官方向发育，进行器官发生（organogenesis），最终分化为各器官组织内具有特定形态结构与功能的成熟细胞。

这条路可以写成四级缩窄。胚胎细胞由受精卵及早期桑葚胚时期、既能形成胚胎外细胞也能形成胚胎内细胞的全能（totipotency）细胞，到仅能形成个体而不能形成胚胎外细胞的多潜能（pluripotency）细胞，再到具有胚层分化能力的限制性多能（multipotency）细胞，最后成为向特定器官组织细胞分化的单能（unipotency）细胞，并分化为成熟细胞。

:::definition{label="全能性"}
全能性（totipotency）是细胞既能形成胚胎内各类细胞、也能形成胚胎外细胞、从而发育为完整个体的能力。受精卵和哺乳动物 $8$ 细胞期之前的桑葚胚细胞具有全能性。
:::

:::definition{label="多潜能、限制性多能与单能"}
多潜能（pluripotency）是仅能形成个体、不能形成胚胎外细胞的能力。限制性多能（multipotency）是限于一个胚层内多种组织方向的能力。单能（unipotency）是只能向特定器官组织细胞分化的能力。成体中组织干细胞先变成多系祖细胞（progenitor cell），再变成单系祖细胞，继而成为前体细胞（precursor cell），最终成为成熟细胞。
:::

胚胎发育成熟、幼体孵化或分娩之后，各器官组织内保留的组织干细胞（成体干细胞）仍按“干细胞 → 多系祖细胞 → 单系祖细胞 → 前体细胞 → 成熟细胞”这条瀑布往下走。细胞分化能力逐渐缩窄，是个体发育、成熟及维持过程中的一般规律（图 15-2）。进入老年后，成体干细胞与多系祖细胞的多系分化能力减弱，偏向特定细胞；随着年龄增长，分化能力衰退直至消失，维持器官结构与功能所需的成熟细胞补充不上，个体进入衰老直至死亡。第十六章会把衰老写成增殖停滞；这里先记下：潜能缩窄一旦走到尽头，更新也就停了。

::figure{src="/images/cell-biology/textbook/p0333_03.png" caption="图15-2 细胞分化潜能逐渐缩窄示意图。A. 多潜能细胞位于命运地形顶部，可滚向外胚层、中胚层或内胚层；B. 多潜能干细胞经定向干细胞、前体细胞，最终成为分化细胞。" alt="Waddington地形显示多潜能细胞滚向三胚层，右侧显示干细胞到分化细胞的层级"}

大多数植物和少数低等动物（如水螅）的体细胞仍具有全能性。高等动物和人类在胚胎发育成熟后，器官组织内只保留少量组织干细胞、祖细胞和前体细胞，绝大部分是终末分化的成熟细胞。但把部分终末分化细胞的细胞核转入去核的受精卵，仍能发育成完整生命个体，说明这类细胞核仍然具有全能性，称为全能性细胞核（totipotent nucleus）（图 15-3）。细胞已经单能，核还可能全能：第二节会用核移植把这句话写成实验。

:::definition{label="全能性细胞核"}
全能性细胞核（totipotent nucleus）是指已分化细胞的细胞核被转入去核受精卵后，仍能支持完整个体发育的细胞核。它证明分化一般并不丢掉基因组，丢掉的是核在原细胞质环境中的表达许可。
:::

::figure{src="/images/cell-biology/textbook/p0334_01.png" caption="图15-3 爪蟾细胞核移植实验证明已分化细胞的细胞核具有全能性。紫外线破坏未受精卵（含 2 个核仁）的核后，注入蝌蚪肠上皮细胞核（含 1 个核仁）；部分重组卵可经囊胚发育为含 1 个核仁的成体蛙，也有停留在异常胚胎或不分裂的结局。" alt="爪蟾肠上皮细胞核移植到去核卵，部分发育为含单个核仁的成体蛙"}

:::concept{term="缩窄的是细胞的许可，不一定是核的基因组"}
桑葚胚之后细胞逐渐不能形成完整个体，这是细胞潜能在缩窄。Gurdon 把肠上皮核放进去核卵，仍能得到成体爪蟾，说明核里的基因大体还在。把“单能”听成“基因已经丢掉”，后面的重编程、iPS 和克隆就会没有着落。
:::

## 二、细胞决定与细胞分化

### （一）细胞决定先于细胞分化并制约分化方向

生命个体发育、成熟与维持过程中，细胞在具有可识别的分化特征之前，就已经确定了未来命运，只能向特定方向分化。这种状态称为细胞决定（cell determination）。原肠胚期内、中、外三胚层形成时，细胞形态上还看不出明显差异，但各器官形成的预定区已经确定，每个预定区决定了它只能发育分化为特定的组织、器官和系统。

:::definition{label="细胞决定"}
细胞决定（cell determination）是细胞在出现可识别的分化特征之前，命运已被限定、只能向特定方向分化的状态。决定先于分化，并制约随后的分化方向；一旦形成，即使外界因素不再存在，细胞仍按已确定的命运分化。
:::

细胞决定可通过胚胎移植实验（grafting experiment）证明。在两栖类胚胎，若把原肠胚早期预定发育为表皮的细胞（供体）移植到另一个胚胎（受体）预定发育为脑组织的区域，供体细胞在受体中分化为脑组织；到原肠胚晚期再做同样移植，供体则发育为表皮。说明两栖类在早期原肠胚和晚期原肠胚之间的某个时期开始了细胞决定（图 15-4）。

::figure{src="/images/cell-biology/textbook/p0334_02.png" caption="图15-4 细胞决定实验示意图。正常命运下供体区域发育为特定结构；明显分化之前把供体组织移植到宿主，供体随宿主位置改变命运（未决定）；明显分化之后再移植，供体仍按原定命运发育（已决定）。" alt="原肠胚早期移植随宿主改命运，晚期移植保持供体原定命运"}

分化去向源于细胞决定。目前确定胚胎细胞分化方向的因素尚不完全清楚，已知两类因素起重要作用：一是卵细胞的极性与早期胚胎细胞的不对称分裂，二是发育早期胚胎细胞所处的位置差异及细胞间相互作用。细胞的不对称分裂是指具有分化调控作用的蛋白因子（包括其 mRNA）在细胞质中分布不均等；分裂时这些因子被不均匀地分配到两个子细胞中，造成两个子细胞命运差异。第十四章已经把形态发生因子写成卵内的极性储备；第二节会把 bicoid、numb 写成具体分子。

### （二）细胞决定具有遗传稳定性

细胞决定具有遗传稳定性。典型例子是果蝇成虫盘细胞移植实验。成虫盘是幼虫体内已决定、尚未分化的细胞团，在变态期之后分别发育为腿、翅、触角等成体结构。把成虫盘的部分细胞移植到成体果蝇腹腔内，成虫盘可以不断增殖并一直保持未分化；即使在腹腔中移植 $1\,800$ 代之后再放回幼虫，被移植的成虫盘细胞在变态时仍能发育成相应的成体结构。说明成虫盘细胞的决定状态非常稳定，并且可遗传。

人们在认识到稳定性的同时，也开始探索可逆性。某些培养的成虫盘细胞会不按已决定的类型发育，长出非对应的成体结构，发生细胞命运的转决定（transdetermination）。探讨转决定机制，对理解胚胎细胞命运决定具有重要意义。近年来的主要策略是利用模式生物做选择性干预（基因敲除或小分子化合物处理等），筛查早期胚胎中某个蛋白在内、中、外三胚层形成及细胞命运中的作用，寻找分化的决定因子。

:::note{label="决定稳定，不等于永远不能改写"}
成虫盘在腹腔里传 $1\,800$ 代仍按原定结构发育，说的是决定可遗传。转决定和后面的去分化、转分化说的是：在特定条件下，这张已经盖过章的命运还可以被改写。把“稳定”写成“绝对不可逆”，第四节的诱导分化和重编程就没有理论位置。
:::

## 三、细胞分化的可塑性

在一般条件下，细胞分化具有高度的稳定性（stability）：正常生理条件下，已经分化为具有特异性稳定类型的细胞，不可逆转到未分化状态，也不会变成其他类型的分化细胞。神经元在整个生命过程中都保持特定分化状态。已分化终末细胞在形态结构和功能上保持稳定，是个体生命活动的基础。离体培养也一样：一个皮肤上皮细胞保持为上皮细胞，不转变为其他类型；黑色素细胞在体外培养 $30$ 多代后仍能合成黑色素。然而，在特定条件下，细胞分化又表现出可塑性（plasticity）。

:::definition{label="细胞分化的可塑性"}
细胞分化的可塑性（plasticity）是指已分化的细胞在特定条件下重新进入未分化状态，或转分化为另一种类型细胞的现象。稳定性是普遍情况；可塑性是有条件的例外，也是重编程和再生医学的入口。
:::

### （一）已分化的细胞可发生去分化

一般情况下，细胞分化过程不可逆。在特定条件下，已经分化的细胞其基因活动模式发生可逆性变化，回到未分化状态，这一过程称为去分化（dedifferentiation）。实验室培养及营养体繁殖中，高度分化的植物细胞可失去分化特性，重新进入未分化状态，成为能够发育为一株完整植物的全能性细胞。动物和人类体内，分化成熟的细胞可部分去分化（如蝾螈肢体再生时形成的胚芽细胞，以及人类的各种肿瘤细胞），但体细胞通常难以完全去分化成为全能性细胞。目前虽对体内去分化的机制认识不清，但已能通过人为手段把分化成熟的细胞逆转为未分化细胞，此即细胞重编程（cellular reprogramming）。通过重编程，分化成熟的细胞可以转变为能够形成生命个体的多潜能干细胞——诱导多能干细胞（induced pluripotent stem cell，iPSC）。第十七章会把 iPS 的分子操作展开；第四节会把它接到肿瘤和再生。

:::definition{label="去分化与细胞重编程"}
去分化（dedifferentiation）是已分化细胞的基因活动模式发生可逆变化、回到未分化状态的过程。细胞重编程（cellular reprogramming）是用人为手段把分化成熟的细胞逆转为未分化细胞；其标志性产物是诱导多能干细胞（iPSC）。
:::

### （二）特定条件下已分化的细胞可转分化为另一种类型的细胞

在高度分化的动物细胞中还可见到另一种现象：从一种分化状态转变为另一种分化状态，称为转分化（transdifferentiation）。转分化可以形成一种与发育过程相关联的细胞类型。典型例子是肾上腺嗜铬细胞。交感神经元和嗜铬细胞均来源于神经嵴；体积较小的嗜铬细胞分泌肾上腺素入血。培养时去除甾体激素并加入神经生长因子后，嗜铬细胞转分化为交感神经元，分泌去甲肾上腺素而非肾上腺素（图 15-5）。

:::definition{label="转分化"}
转分化（transdifferentiation）是从一种分化状态的细胞转变为另一种分化状态的细胞。它可以形成与发育过程相关联的细胞类型（如嗜铬细胞转为交感神经元），也可以连续形成无发育关联的类型（如水母横纹肌转为平滑肌再转为神经元）。
:::

::figure{src="/images/cell-biology/textbook/p0335_01.png" caption="图15-5 细胞转分化示意图。肾上腺嗜铬细胞分泌肾上腺素；从培养基中去除糖皮质激素并加入神经生长因子后，转分化为交感神经元，改为分泌去甲肾上腺素。" alt="嗜铬细胞在去激素加NGF后转分化为释放去甲肾上腺素的交感神经元"}

转分化也可以形成无发育关联的细胞类型。水母横纹肌可由一种细胞类型连续转分化形成两种不同类型的细胞：离体横纹肌与相关细胞外基质共同培养时保持横纹肌状态；用降解细胞外基质的酶处理后，细胞形成聚合体，先转分化为平滑肌细胞，继续培养则形成神经元。

无论动物还是植物，细胞分化的稳定性是普遍存在的。可以认为分化具有单向性、序列性和终末性（一般情况下都会到达分化的目标终点，成为终末分化的成熟细胞）；去分化是逆向运动，转分化是转序列运动。发生转分化或去分化是有条件的：①细胞核必须处于有利于逆转分化的环境中；②分化能力的逆转必须具有相应的遗传物质基础。通常情况下，细胞分化的逆转易发生于具有增殖能力的组织细胞中。

:::pitfall{label="可塑性不是分化可以随便掉头"}
教材后半段会写 iPS、蝾螈再生和肿瘤去分化，容易把“分化可逆”听成常态。稳定性才是普遍规律：神经元、上皮和黑色素细胞在正常生理和普通培养里都不改身份。去分化、转分化要求核处于有利环境，并且要有相应的遗传物质基础；植物体细胞容易完全去分化，高等动物体细胞通常只能部分去分化。把终末分化写成“随时可逆”，会把第四节的诱导分化和重编程当成体内日常事件。
:::

:::compare{title="去分化 vs 转分化"}
| 项目 | 去分化 | 转分化 |
|------|--------|--------|
| 运动方向 | 逆向：已分化 → 未分化 | 转序列：一种分化类型 → 另一种分化类型 |
| 终点 | 未分化或再获多潜能（如 iPSC） | 另一种成熟或相关分化细胞 |
| 典型例子 | 植物细胞再生成株；蝾螈胚芽；肿瘤细胞部分去分化 | 嗜铬细胞 → 交感神经元；水母横纹肌 → 平滑肌 → 神经元 |
| 与发育的关系 | 回到更早的许可状态 | 可关联（同一神经嵴来源）也可不关联 |
| 共同条件 | 核处于有利于逆转的环境；具备相应遗传物质基础；较易发生在仍有增殖能力的细胞 | 同左 |
:::

## 四、细胞分化的时空性

在个体发育过程中，多细胞生命体的细胞既有时间上的分化，也有空间上的分化。一个细胞在不同发育阶段可以有不同的形态结构和功能，即时间序列上的分化；同一种细胞的后代，由于所处空间位置不同、微环境不一样，具有不同的形态和功能，即空间上的分化。高等动植物胚胎发育中，随着细胞数目不断增加，分化程度越来越复杂，细胞间差异也越来越大；同一个体的细胞由于所处空间位置不同而确定了命运，出现头与尾、背与腹等不同的器官与组织。这些时空差异为形成功能各异的多种组织和器官提供了基础。第二节的珠蛋白基因时序转换、Hox 基因沿前–后轴的表达，就是把这句话写成分子。

## 五、细胞分裂与细胞分化

细胞分裂和细胞分化是多细胞生命个体发育过程中的两个重要事件，二者密切联系。通常细胞在增殖（细胞分裂）的基础上进行分化；早期胚胎细胞的不对称分裂所引起的细胞质中调控蛋白因子的差异，制约着细胞的分化方向和进程。细胞分化发生于细胞分裂的 $\mathrm{G}_1$ 期。在早期胚胎发育阶段特别是卵裂过程中，细胞快速分裂，$\mathrm{G}_1$ 期很短或几乎没有 $\mathrm{G}_1$ 期，此时细胞分化减慢。细胞分裂旺盛时分化变缓，分化较高时分裂速度减慢，是个体生长发育的一般规律。例如哺乳动物表皮角化层等终末细胞分化程度较高，分裂频率明显减慢；高度分化的细胞如神经元和心肌细胞则很少分裂或完全失去分裂能力。终末分化的成熟细胞一般不具有分裂能力。第十三章把 $\mathrm{G}_1$ 写成周期的准备段；这里它同时是分化被允许发生的窗口。

:::cause-effect{title="为什么卵裂期分化慢、终末细胞几乎不分裂"}
- 因：分化主要发生在 $\mathrm{G}_1$；卵裂时 $\mathrm{G}_1$ 很短或几乎没有，$\mathrm{G}_1$ 窗口关着
- 因：早期不对称分裂把胞质决定因子分到不同子细胞，命运在形态分化之前就已经被写上
- 果：分裂旺盛时分化变缓；分化程度升高后分裂减慢，神经元和心肌细胞可完全失去分裂能力
- 结果：胚胎先用快速卵裂把细胞数目做出来，再用拉长的 $\mathrm{G}_1$ 把身份写进去；成体用“高度分化 ≈ 退出周期”维持稳定
:::

:::keypoint{label="分化是潜能缩窄后的特化"}
- 一个受精卵写成约 $200$ 种成熟细胞，靠的是分化，不是基因组被切成 $200$ 份。
- 全能 → 多潜能 → 限制性多能 → 单能，是发育、成熟和成体更新的共同方向。
- 决定先于可识别的分化；原肠胚晚期再移植，表皮预定区就不再改行做脑。
- 稳定性是常态，去分化和转分化是有条件的可塑性；核还在，许可可以改写。
- 分化写在 $\mathrm{G}_1$：卵裂几乎没有 $\mathrm{G}_1$，所以先分裂、后特化。
:::

:::memory{label="本节必背要点"}
- [ ] 细胞分化：一种细胞向生化组成、结构和功能上更为特定的细胞转变；贯穿全生命周期，胚胎期最活跃。
- [ ] 人体约 $200$ 种稳定不同的成熟细胞，全部来自同一个受精卵。
- [ ] 卵裂：受精后快速有丝分裂；囊胚：中空球体，细胞开始出现功能差异；原肠胚：形成内、中、外三胚层。
- [ ] 内胚层：消化道及其附属器官、唾液腺、胰、肝、肺的上皮；中胚层：骨骼、肌肉、纤维组织、真皮、心血管、泌尿；外胚层：神经系统、表皮及其附属物。
- [ ] 全能：能形成胚胎内和胚胎外细胞，发育为完整个体（受精卵、哺乳动物 $8$ 细胞期前桑葚胚）。
- [ ] 多潜能：能形成个体，不能形成胚胎外细胞；限制性多能：限于胚层内多种方向；单能：只向特定器官组织细胞分化。
- [ ] 成体：组织干细胞 → 多系祖细胞 → 单系祖细胞 → 前体细胞 → 成熟细胞；老年后多系能力减弱直至消失。
- [ ] 高等动物体细胞大多终末分化；终末分化细胞核转入去核卵仍可发育为个体，为全能性细胞核。
- [ ] 细胞决定先于可识别分化；两栖类在早、晚期原肠胚之间开始决定，一旦形成即按既定命运分化。
- [ ] 决定的两类因素：卵的极性与不对称分裂；早期胚胎细胞的位置及相互作用。
- [ ] 果蝇成虫盘在成体腹腔移植 $1\,800$ 代后放回幼虫，仍发育为相应成体结构；也可发生转决定。
- [ ] 分化稳定性是普遍规律；可塑性指特定条件下去分化或转分化。
- [ ] 去分化：已分化 → 未分化；植物可完全去分化，高等动物多为部分去分化；人为逆转即重编程，产物为 iPSC。
- [ ] 转分化：一种分化类型 → 另一种；嗜铬细胞去甾体激素加 NGF → 交感神经元（肾上腺素改为去甲肾上腺素）。
- [ ] 逆转条件：核处于有利环境；具备相应遗传物质基础；较易发生在仍有增殖能力的细胞。
- [ ] 分化有时间特异性和空间特异性；分化发生在 $\mathrm{G}_1$，卵裂期 $\mathrm{G}_1$ 短则分化慢，终末分化细胞一般不再分裂。
:::
