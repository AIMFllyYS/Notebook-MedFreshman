# 第二节 受精

第一节把配子写成从 PGC 走到单倍体精子和“停在中期 II”的次级卵母细胞。二者如果不相遇，会在几分钟到数小时内死亡。受精挽救它们，并标志一个新生命的开始。阐明过程与机制，对解决不孕不育和无害避孕都有直接意义。

:::definition{label="受精"}
受精（fertilization）是精子与卵子融合形成受精卵（合子）的过程。人类和其他哺乳动物的受精一般发生在输卵管壶腹部。参与融合的卵子，其实是处于减数分裂 II 中期的次级卵母细胞。
:::

:::definition{label="精子获能"}
精子获能（capacitation）是精子进入雌性生殖管道后停留一段时间、获得对卵子受精能力的过程。人类约需 $5\sim 6$ 小时。获能后游动和细胞呼吸增强，与卵子相遇的概率提高。
:::

## 一、受精的条件

受精除了要求精子和卵子在发育阶段上“刚好能遇”之外，进入雌性生殖管道的精子还必须先获得活力，即游动与受精的能力。

完成减数分裂和变形的精子脱离支持细胞，进入生精小管管腔，依次经直精小管、睾丸网、输出小管到达附睾管和输精管，在附睾尾和输精管内成熟、储存，直至射精。附睾中的成熟不仅依赖雄激素，也依赖附睾上皮分泌的甘油磷酸胆碱、肉毒碱、唾液酸等。即便如此，哺乳动物精子进入雌性生殖管道后并不立即受精，而要停留一段时间完成获能。有证据表明，排卵周围的卵泡细胞会释放化学信号吸引精子到达卵子，但这种信号的化学本质尚未完全清楚。

获能机制也未完全阐明，一般认为由雌性生殖管道的液体环境决定：精子被管道中的“特殊条件”改写。实验证据较一致的顺序是：精子内部钾离子先外流，质膜静息电位改变、不稳定性增加，膜胆固醇脱落，促使管道中的 $\mathrm{HCO}_3^{-}$ 和 $\mathrm{Ca}^{2+}$ 进入精子，激活质膜腺苷酸环化酶，cAMP 升高；经 PKA 激活蛋白酪氨酸激酶，多种蛋白质磷酸化，代谢和运动能力提高，细胞膜进入超极化状态。获能还改变膜脂质和糖蛋白组成。精液中的唾液酸附着在精子头部外表面，阻止顶体酶释放；精子在子宫和输卵管中运动时，该糖蛋白被分泌物中的唾液酸酶及 $\alpha$、$\beta$ 淀粉酶等降解，精子才真正获得受精能力。

正常情况下获能发生在雌性生殖管道中，但也可在实验条件下离体诱发。这是临床人工授精和体外受精能够成功的基础：用合适的获能液，受精就可以在体外完成。

精子的数量和质量是另一项条件。一次射精中，正常精液的精子总数大于 $4\times 10^{7}$，能向前运动的大于 $50\%$，形态正常的大于 $30\%$。受精虽然只由一个精子和一个卵子完成，但精–卵接触有随机性，必须有较多精子到达输卵管壶腹部，才能保证结合真正发生。

:::concept{term="获能是改写质膜，不是放出顶体酶"}
获能改变胆固醇、糖蛋白和磷酸化状态，让精子变得可被触发；顶体酶此时仍被按住。把获能写成“精子一进女性生殖道就开始顶体反应”，会把后面 ZP3 触发的胞吐提前到错误的地点。
:::

:::note{label="体外获能液就是把管道条件搬到培养皿"}
IVF 并不发明了一种新的受精，只是用获能液代替子宫和输卵管的液体环境。能在体外走完获能–顶体反应–融合，说明这些步骤的分子开关在配子自身，管道提供的是许可条件。
:::

## 二、受精过程

当获能的精子与停在减数分裂 II 中期的次级卵母细胞相遇，会引发一系列连锁反应：精子识别卵细胞并诱发顶体反应（acrosome reaction），穿过卵外被抵达卵细胞膜，精–卵质膜融合后精子细胞核等成分进入卵内，次级卵母细胞完成减数分裂，皮质反应阻止多精入卵，以及精–卵核融合（图 14-7）。精卵融合标志新生命开始；受精过程完成，则要等到两个原核的染色体在第一次卵裂纺锤体上混合。

### （一）精子识别卵细胞并穿过卵外被

**1. 精子–卵子识别诱发顶体反应。** 精子一旦获能，便穿过卵泡细胞层，结合到透明带。透明带是受精的种属屏障。人卵透明带主要由透明带蛋白（zona pellucida protein，ZP）组成，包括 ZP1、ZP2、ZP3 和 ZP4，由初级卵母细胞及卵泡细胞产生。ZP3 是精子与透明带结合的第一受体，可以诱导顶体反应；其特异性由肽链上的 O-连接寡糖决定。ZP3 缺陷会导致雌性小鼠不育。ZP2 则作为已经发生顶体反应的精子的第二受体。

:::definition{label="顶体反应"}
顶体反应（acrosome reaction）是获能精子与放射冠、透明带相互作用后发生的特异性胞吐：顶体外膜与精子质膜融合、破裂，释放透明质酸酶等水解酶，消化放射冠和透明带，并改用 ZP2 继续抓住卵外被。
:::

精子与 ZP3 结合后，触发 $\mathrm{Ca}^{2+}$ 向精子胞质内流，进而引发顶体反应。释放的水解酶消化透明带，帮助精子穿过；同时把能与 ZP2 结合的蛋白质暴露到精子表面，使穿越过程中精子与透明带保持紧密连接。顶体反应期间，与 ZP3 结合的顶体前端发生胞吐，ZP3 配体随之丢失，精子必须改用顶体内膜上的蛋白与 ZP2 结合才能完成穿透。也就是说，顶体反应后精子与透明带的结合由 ZP3 转到 ZP2，ZP2 作为第二受体进一步加固连接。

顶体的系列变化自获能精子接触放射冠时即开始。顶体前膜先与头部质膜融合、破裂成许多小孔，酸性水解酶逐渐释放。与 ZP3 结合后，顶体破裂、内含物完全释放。接触透明带之前，卵丘细胞分泌的孕酮即可启动顶体反应；与透明带结合后，启动者换成 ZP3。于是顶体酶（acrosomal enzyme）先解离放射冠的卵泡细胞，再分解透明带，形成一个精子穿过的通道。

**2. 精子穿过透明带抵达卵细胞膜。** 精子以种特异性方式结合透明带、完成顶体反应并穿过透明带后，到达卵质膜。精子与卵细胞膜的直接接触，标志着受精开始。

:::pitfall{label="顶体反应不是获能的同义词"}
获能发生在子宫和输卵管的液体环境里，改的是膜稳定性和磷酸化；顶体反应发生在卵子附近，由孕酮和 ZP3 触发，放出的才是顶体酶。把两个词当成一回事，会既说不清 IVF 获能液在做什么，也说不清 ZP3 敲除为什么造成雌性不育。
:::

### （二）精–卵融合

**1. 质膜融合，精子核等成分进入卵细胞。** 受精开始时，精子头侧面的细胞膜与卵细胞膜融合，随即细胞核和细胞质进入卵内。

卵细胞膜表面覆盖许多微绒毛。精子先作用于微绒毛顶端的细胞膜，邻近微绒毛迅速伸长、聚丛，包绕精子，保证紧密结合并发生质膜融合。随后微绒毛被吸收，精子以头部先入的方式进入卵细胞质。

融合机制尚未完全清楚。目前认为可能与精子中的解整联蛋白金属蛋白酶（a disintegrin and metalloprotease，ADAM）家族和卵细胞膜上的整联蛋白（integrin）相互作用有关。小鼠精子膜上的致育蛋白（fertilin）属 ADAM 家族，是顶体反应后暴露于精子表面的跨膜蛋白，帮助精子结合卵质膜并促进融合。它是 Fertilin $\alpha$（ADAM1b）和 Fertilin $\beta$（ADAM2）组成的受体样异二聚体。其胞外 N 端可与卵质膜整联蛋白 $\alpha_6\beta_1$ 结合，使精子黏附在卵子表面。$\alpha$ 亚单位胞外区含有一个类似病毒融合蛋白的疏水区，该区的人工合成多肽能诱导试管内精–卵质膜融合。致育蛋白缺失的雄性小鼠不育：精子与卵质膜结合能力约为正常的 $1/8$，融合能力约为正常的 $50\%$。但体外实验中，致育蛋白缺失的精子仍可使卵子受精，提示还有其他精子蛋白参与。

近年来发现，精子表面蛋白 Izumo1 与卵子表面蛋白 Juno 在融合中相互作用。顶体反应后，精子经透明带到达卵周间隙，Izumo1 与 Juno 相遇；Izumo1 构象变化并与 Juno 结合，随后可能再与卵膜上的整联蛋白相关蛋白 CD9 等结合，触发融合。融合发生后，卵质膜上的 Juno 脱落，并与进入卵周间隙的其他精子上的 Izumo1 结合，从而阻止多精入卵。

:::note{label="Izumo1–Juno 是融合配对，脱落是第一道分子封条"}
精–卵识别在透明带靠 ZP3/ZP2，融合在质膜靠 Izumo1/Juno。Juno 一脱落，后来的精子即便穿过透明带，也抓不住卵膜。这和下面皮质反应改写 ZP 是前后两道锁，不要写成同一件事。
:::

**2. 次级卵母细胞完成减数分裂。** 精子进入后，激发次级卵母细胞迅速完成减数分裂 II，形成一个成熟卵子和一个第二极体。卵细胞单倍染色体向中央移行，核膜形成，雌原核（female pronucleus）出现。精子进入后，自身核膜崩溃，尾部退化消失，染色质解聚，核内精蛋白被组蛋白替换，新形成的原核膜包在染色质外周，形成雄原核（male pronucleus）。

:::definition{label="原核"}
原核（pronucleus）是精、卵染色体在融合前各自装配的单倍体核。雌原核来自完成减数分裂 II 的卵核；雄原核来自解聚并换回组蛋白的精子染色质。二者在哺乳动物中并不立即融合成一个核。
:::

**3. 皮质反应阻止多精入卵。** 虽然许多精子可以与卵子结合，通常只有一个精子能与卵质膜融合并向卵内释放细胞核和其他细胞器。一个以上精子与卵子融合称为多精入卵（polyspermy）。此时将形成多极或过多的纺锤体，导致染色体错误分配、非二倍体细胞产生以及发育停滞。

:::definition{label="多精入卵"}
多精入卵（polyspermy）是一个以上精子与卵子融合的异常受精。多余的中心粒和染色体使纺锤体变成多极，基因组无法均分，发育停滞。
:::

有两套机制确保单精受精。① 卵子与一个精子融合后，质膜快速去极化，阻止其他精子再融合。这是快速的早期阻断。② 质膜电位在受精后很快恢复，因此还需要皮质反应（cortical reaction）来做慢速、稳妥的阻断：卵子通过胞吐释放皮质颗粒，改变卵外被结构。哺乳动物中，皮质颗粒的糖苷酶把 ZP3 降解为缺少糖基的 ZP3f，精子膜表面蛋白无法识别；蛋白酶把 ZP2 降解为 ZP2f，ZP2f 不能与顶体反应后的精子结合，使多余精子不能进入。

:::definition{label="皮质反应"}
皮质反应（cortical reaction）是精–卵融合后卵皮质颗粒的胞吐。释放的糖苷酶和蛋白酶把 ZP3、ZP2 改写成 ZP3f、ZP2f，透明带失去结合精子的能力，从而阻止多精入卵。
:::

卵内储存 $\mathrm{Ca}^{2+}$ 的释放与皮质反应直接相关。精–卵质膜融合激活内质网上的 $\mathrm{Ca}^{2+}$ 通道，储存钙释放，局部游离 $\mathrm{Ca}^{2+}$ 升高并形成钙波（calcium wave）传遍整个卵子，启动皮质反应。卵子发生过程中透明带蛋白是泛素化的；用泛素–蛋白酶体抑制剂处理卵子，可阻止精子进入透明带，表明去泛素化也可参与阻止多精入卵。

:::cause-effect{title="钙波怎样把“一个精子”写成不可逆"}
- 因：精–卵质膜融合打开卵内内质网 $\mathrm{Ca}^{2+}$ 通道，钙波传遍卵质
- 果：皮质颗粒胞吐，ZP3→ZP3f、ZP2→ZP2f，透明带不再接受后来的精子
- 因：融合后卵膜上的 Juno 脱落，卵周间隙中的多余精子抓不住卵膜
- 结果：快速去极化只挡一瞬间，皮质反应和 Juno 脱落把单精受精锁死；多精一旦发生，多余中心粒会把第一次卵裂纺锤体拉成多极
:::

:::compare{title="快速阻断 vs 皮质反应"}
| 项目 | 快速阻断 | 皮质反应（慢速阻断） |
|------|----------|----------------------|
| 发生时间 | 融合后几乎立即 | 钙波触发的胞吐，稍晚但持久 |
| 结构靶点 | 卵质膜电位 | 卵外被（透明带 ZP3/ZP2） |
| 分子事件 | 质膜去极化 | 皮质颗粒释放糖苷酶、蛋白酶，ZP3/ZP2 变为 ZP3f/ZP2f |
| 持续时间 | 短，电位很快恢复 | 透明带被永久改写 |
| 单独够不够 | 不够，电位恢复后仍可能再融 | 是防止多精入卵的主要稳妥机制 |
:::

### （三）精–卵核融合完成受精过程

卵子一旦与精子融合即为合子。但只有当两个单倍体核（雄原核和雌原核）的染色体混合成一个二倍体细胞核时，受精过程才算完成。哺乳动物的雌、雄原核并不像某些物种那样直接融合：它们先彼此靠近，一直持续到合子准备进行第一次有丝分裂（卵裂）时才真正会合。此时，在卵质微管和微丝作用下，两个原核相互靠近，接触处原核膜呈指状交错对插；染色体浓缩，原核膜崩解、消失，精–卵染色体组合在一起形成合子染色体组，定位于纺锤体上。此时细胞即为受精卵，受精至此完成。

多数动物（包括人类）受精时，精子提供的不仅是 DNA，还有中心粒——人类未受精卵里不存在中心粒。精子中心粒随细胞核和尾端进入卵子，并在周围形成中心体。在人类，精子中心粒复制并组织合子第一次有丝分裂的纺锤体。这也解释了多精入卵时为什么出现多极和多余纺锤体：每多进一个精子，就多带进一套中心粒。

受精的意义可以写成四条。① 使缓慢代谢的卵子转入代谢旺盛期，启动细胞分裂。② 精卵结合恢复二倍体，维持物种染色体数目稳定。③ 决定性别：带 Y 染色体的精子与卵子结合发育为男性，带 X 的则发育为女性。④ 染色体来自父母双方，加之减数分裂中的联会与片段交换，遗传物质重新组合，新个体具有与亲代不完全相同的性状。

:::keypoint{label="受精是一套按顺序打开的锁"}
- 管道里先获能：钾外流、胆固醇脱落、cAMP 升高，顶体酶仍被按住。
- 卵子附近才顶体反应：孕酮和 ZP3 触发胞吐，ZP2 接棒抓住透明带。
- 质膜融合靠 Izumo1–Juno 和 ADAM/整联蛋白；融合后 Juno 脱落。
- 钙波启动皮质反应，把 ZP3/ZP2 改写成不能再结合的 ZP3f/ZP2f。
- 次级卵母细胞完成减数分裂 II；雌、雄原核在第一次卵裂纺锤体上混合，受精才算完成。精子还要提供中心粒。
:::

:::memory{label="本节必背要点"}
- [ ] 受精：精子与停在中期 II 的次级卵母细胞融合形成受精卵；人类发生在输卵管壶腹部。
- [ ] 不受精则配子在数分钟至数小时内死亡；受精挽救双方并启动新生命。
- [ ] 精子先在附睾成熟（雄激素、甘油磷酸胆碱、肉毒碱、唾液酸），进入雌性生殖管道后再获能。
- [ ] 获能约 $5\sim 6$ 小时：$\mathrm{K}^{+}$ 外流 → 胆固醇脱落 → $\mathrm{HCO}_3^{-}$/$\mathrm{Ca}^{2+}$ 内流 → cAMP–PKA–酪氨酸磷酸化；头部唾液酸被唾液酸酶和淀粉酶降解。
- [ ] 获能可在体外用获能液诱发，是 IVF 的基础。
- [ ] 正常精液：精子总数 $>4\times 10^{7}$，向前运动 $>50\%$，形态正常 $>30\%$。
- [ ] 透明带 ZP1–4；ZP3 是第一受体（O-连接寡糖决定种属特异性）并诱导顶体反应；ZP2 是顶体反应后的第二受体。ZP3 缺陷 → 雌性小鼠不育。
- [ ] 顶体反应：$\mathrm{Ca}^{2+}$ 内流，顶体胞吐；孕酮启动于接触透明带前，ZP3 启动于结合后；酶先解离放射冠，再打通透明带。
- [ ] 精–卵融合：微绒毛包绕；致育蛋白（ADAM1b/ADAM2）结合整联蛋白 $\alpha_6\beta_1$；Izumo1–Juno（可再及 CD9）触发融合，随后 Juno 脱落。
- [ ] 精子入卵后：卵完成减数分裂 II，出第二极体，形成雌原核；精子染色质解聚、精蛋白换组蛋白，形成雄原核。
- [ ] 多精入卵产生多极纺锤体，发育停滞。
- [ ] 快速阻断：质膜去极化。慢速阻断：皮质反应，ZP3→ZP3f、ZP2→ZP2f。钙波启动皮质反应。
- [ ] 哺乳动物原核不直接融合，靠近至第一次卵裂，核膜对插崩解，染色体在纺锤体上混合，受精才完成。
- [ ] 人类精子提供中心粒，组织合子第一次有丝分裂纺锤体。
- [ ] 受精意义：启动代谢与分裂、恢复 $2n$、决定性别、重组产生不同于亲代的性状。
