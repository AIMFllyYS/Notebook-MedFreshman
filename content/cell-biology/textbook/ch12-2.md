# 第二节 细胞膜受体介导的信号转导

第一节把亲水性信号分子拦在质膜外，把转导任务交给三类膜受体。在调节细胞生命活动中，常见而重要的通路按受体蛋白类型分成三块：G 蛋白耦联受体介导的信号通路、酶联受体介导的信号通路、蛋白复合体解离介导的信号通路。本节按这三块把通路拆开，不把 Gs/Gi、$\mathrm{IP}_3$/DAG 和 RTK–Ras 缩成一张摘要表。

:::definition{label="膜受体介导的信号转导"}
膜受体介导的信号转导是亲水性（或膜结合型）信号分子与细胞表面受体结合后，经 G 蛋白、酶联激酶或蛋白复合体解离等机制，在胞内产生第二信使或激活激酶级联，从而改写代谢、离子通量和基因表达的过程。
:::

:::definition{label="G 蛋白耦联受体"}
G 蛋白耦联受体（GPCR）是细胞表面受体中最大的多样性家族。人类有 700 余种 GPCR，介导对极为多样的胞外分子作出反应。从单细胞酵母到人类，真核 GPCR 都具有相似的结构：7 个穿膜 $\alpha$ 螺旋，N 端在细胞外侧，C 端在胞质侧。
:::

## 一、G 蛋白耦联受体介导的信号转导通路

GPCR 信号途径涉及受体、G 蛋白及 G 蛋白效应器、蛋白激酶及效应蛋白，与人类生命活动的调控密切相关。一些临床处方药物以这条通路的组成分子为靶点。

### （一）G 蛋白耦联受体的结构与活化

GPCR 家族包括识别并结合蛋白或肽类激素、局部介质、神经递质的受体，以及哺乳类嗅觉、味觉受体和视觉的光激活受体（视紫红质）。配体与受体结合后，螺旋 5 和 6 之间的胞内环状结构域（C3）构象改变，结合并激活 G 蛋白的 $\alpha$ 亚基（图 12-7）。

::figure{src="/images/cell-biology/textbook/p0281_01.png" caption="图12-7 G 蛋白耦联受体的结构模式图。7 次穿膜 α 螺旋把 N 端（NH₃⁺）留在胞外、C 端（COO⁻）留在胞内；胞外环提供信号结合位点，螺旋 5 与 6 之间的胞内环是 G 蛋白耦联区（C3）。" alt="七次跨膜GPCR：胞外配体结合位点，胞内C3环为G蛋白耦联区"}

G 蛋白位于质膜内胞质侧，为可溶性的膜外周蛋白。M. Rodbell 和 A. G. Gilman 分离纯化并命名了 G 蛋白，因此获得 1994 年诺贝尔生理学或医学奖。G 蛋白由 $\alpha$、$\beta$ 和 $\gamma$ 三种亚基组成，$\beta$ 和 $\gamma$ 以异二聚体形式存在；$\mathrm{G}\alpha$ 和 $\mathrm{G}\beta\gamma$ 分别通过共价结合脂分子锚定于细胞膜上。$\mathrm{G}\alpha$ 本身具有 GTP 酶活性，是分子开关蛋白。

:::definition{label="异三聚体 G 蛋白"}
异三聚体 G 蛋白由 $\alpha$、$\beta$、$\gamma$ 三种亚基组成，经脂锚定贴在质膜胞质面。未受刺激时以结合 GDP 的三聚体形式存在；配体激活受体后，$\mathrm{G}\alpha$ 上的 GDP 被 GTP 替代并与 $\mathrm{G}\beta\gamma$ 解离，游离的 $\mathrm{G}\alpha$-GTP（以及游离的 $\beta\gamma$）作用于效应蛋白。$\mathrm{G}\alpha$ 把 GTP 水解成 GDP 后重新装配三聚体，信号关闭。
:::

::figure{src="/images/cell-biology/textbook/p0281_02.png" caption="图12-8 G 蛋白三聚体激活机制。静息时受体旁的 G 蛋白以结合 GDP 的 αβγ 三聚体存在；配体结合后 GDP 换成 GTP，α-GTP 与 βγ 解离，二者都可以作为激活的信号输出。" alt="GPCR激活后G蛋白GDP换成GTP，α亚基与βγ解离"}

:::derivation{label="G 蛋白三聚体工作循环"}
1. 静息：G 蛋白以 $\alpha\beta\gamma$ 三聚体存在，$\mathrm{G}\alpha$ 结合 GDP，经脂锚定贴在质膜胞质面；受体尚未被配体占领。
2. 配体结合 GPCR：7 次螺旋重排，螺旋 5 和 6 之间的胞内环 C3 构象改变，结合 $\mathrm{G}\alpha$。
3. 核苷酸交换：受体充当鸟苷酸交换因子，$\mathrm{G}\alpha$ 上的 GDP 被 GTP 替代。
4. 解离输出：$\mathrm{G}\alpha$-GTP 与 $\mathrm{G}\beta\gamma$ 解离。游离的 $\mathrm{G}\alpha$-GTP 结合并激活效应蛋白；游离的 $\beta\gamma$ 在某些通路（如心肌 M 受体）中同样是效应器的直接调节者。
5. 计时关闭：$\mathrm{G}\alpha$ 的 GTP 酶把 GTP 水解成 GDP，$\mathrm{G}\alpha$-GDP 与 $\beta\gamma$ 重新装配三聚体，系统回到静息。

净结果：配体不进入细胞，受体负责“换成 GTP”，$\mathrm{G}\alpha$ 的 GTP 酶负责“到点关掉”。霍乱毒素破坏的就是第 5 步计时器。
:::

GPCR 按其效应器蛋白的不同可分为 3 类：①激活或抑制腺苷酸环化酶，产生 cAMP 为第二信使；②激活磷脂酶 C，以 $\mathrm{IP}_3$ 和 DAG 作为双信使；③激活离子通道。下面按这三类分开写。

### （二）G 蛋白耦联受体介导的 cAMP 信号通路

cAMP 信号途径中，$\mathrm{G}\alpha$ 亚基的首要效应酶是腺苷酸环化酶（adenylate cyclase，AC）。通过 AC 活性的变化调节靶细胞内第二信使 cAMP 的水平，进而影响下游事件，是真核细胞应答激素反应的主要机制之一。该途径由刺激性受体（stimulatory receptor，Rs）、抑制性受体（inhibitory receptor，Ri）、刺激性 G 蛋白（stimulatory G-protein，Gs）、抑制性 G 蛋白（inhibitory G-protein，Gi）和腺苷酸环化酶五组分相互协作，刺激或者抑制 AC，从而激活或抑制信号途径。

:::definition{label="刺激性与抑制性受体"}
刺激性受体（Rs）和抑制性受体（Ri）都是 GPCR，但结合的配体不同。已知 Rs 有几十种，包括肾上腺素 $\beta$ 受体、胰高血糖素受体、促黄体生成素受体、促甲状腺素受体、促肾上腺皮质激素受体等。Ri 包括肾上腺素 $\alpha$ 受体、乙酰胆碱 M 受体、前列腺素受体等。
:::

刺激性激素与相应 Rs 结合，耦联 Gs，导致腺苷酸环化酶活化，催化 ATP 转化为 cAMP，激活信号途径。抑制性激素和 Ri 结合后，一方面耦联 Gi，抑制腺苷酸环化酶活性；另一方面 Gi 的 $\alpha$ 亚基与 $\beta$、$\gamma$ 解离后，游离的 $\beta\gamma$ 可在膜上与 $\mathrm{Gs}\alpha$ 结合成为非活性的 Gs，从而间接抑制腺苷酸环化酶。两方面共同降低靶细胞 cAMP 水平（图 12-9）。

关闭信号的机制与开放信号的机制同样重要，二者协同使细胞生理活动处于有序调控中，任一机制失调都会引起严重后果。霍乱弧菌产生的毒素蛋白与 $\mathrm{Gs}\alpha$ 亚基相互作用，致使 $\mathrm{Gs}\alpha$ 丧失 GTP 酶活性，不能将结合的 GTP 水解成 GDP，Gs 处于持续活化状态，不断激活腺苷酸环化酶，催化小肠上皮细胞中 cAMP 含量增加 100 倍以上，大量电解质离子与水外流，引起急性腹泻与脱水。第五节会把这个开关失灵写成完整的临床链条。

::figure{src="/images/cell-biology/textbook/p0282_01.png" caption="图12-9 刺激性和抑制性 G 蛋白耦联系统工作机制。左侧肾上腺素、胰高血糖素、ACTH 等经刺激性受体激活 Gs（结合 GTP），激活腺苷酸环化酶；右侧前列腺素、腺苷等经抑制性受体作用于 Gi，抑制该酶。AC 把 ATP 转为 cAMP，受两侧对向控制。" alt="Gs激活腺苷酸环化酶、Gi抑制腺苷酸环化酶，对向调节cAMP"}

:::compare{title="Gs vs Gi"}
| 项目 | Gs（刺激性） | Gi（抑制性） |
|------|--------------|--------------|
| 耦联受体 | Rs：肾上腺素 $\beta$、胰高血糖素、促黄体生成素、促甲状腺素、ACTH 等 | Ri：肾上腺素 $\alpha$、乙酰胆碱 M、前列腺素等 |
| 配体结合后 | $\mathrm{Gs}\alpha$ 结合 GTP，激活腺苷酸环化酶 | $\mathrm{Gi}\alpha$ 抑制腺苷酸环化酶；游离 $\beta\gamma$ 还可绑住 $\mathrm{Gs}\alpha$，间接再抑制一次 |
| 对 cAMP | 升高 | 降低 |
| 毒素打击点 | 霍乱毒素使 $\mathrm{Gs}\alpha$ 失去 GTP 酶，开关关不掉 | 百日咳毒素使 $\mathrm{Gi}\alpha$ 不能换成 GTP，抑制开不了（见第五节） |
| 生理意义 | 升血糖激素、多种促激素的主通路 | 与 Gs 对向，把 cAMP 写成可上可下的设定值 |
:::

细胞内 cAMP 水平上升后，结合并活化依赖于 cAMP 的蛋白激酶 A（protein kinase A，PKA）。无活性的 PKA 是含 2 个调节亚基（R）和 2 个催化亚基（C）的四聚体，每个 R 亚基上有 2 个 cAMP 结合位点。cAMP 与 R 亚基结合后，四聚体解聚，C 亚基释放并且激酶活性被激活。激活的 C 亚基催化下游蛋白的丝氨酸或苏氨酸磷酸化，启动生化级联。在不同组织细胞中，PKA 的靶蛋白不同，因而产生不同的生物学作用。

:::definition{label="蛋白激酶 A"}
蛋白激酶 A（PKA）是 cAMP 依赖性丝/苏氨酸激酶。静息时为 $\mathrm{R}_2\mathrm{C}_2$ 四聚体；4 分子 cAMP 结合调节亚基后，催化亚基释放并磷酸化下游靶蛋白。它既可在胞质改写代谢酶（快反应），也可入核磷酸化转录因子（慢反应）。
:::

cAMP 信号通路可通过快反应调节细胞代谢，也可通过慢反应调控基因表达（图 12-10）。

**快反应：糖原分解。** 升血糖激素（胰高血糖素、肾上腺素等）与肝脏和肌细胞膜上的受体结合后，激活 Gs，再激活腺苷酸环化酶，催化 cAMP 合成；cAMP 激活 PKA。PKA 催化无活性的糖原磷酸化酶激酶（GPK）磷酸化而激活，GPK 再催化无活性的糖原磷酸化酶（GP）磷酸化而转变为有活性的 GP，GP 促进糖原分解。同时 PKA 还使糖原合酶（GS）磷酸化，抑制糖原合成。一条通路同时打开分解、关上合成。

**慢反应：cAMP–PKA 调控转录。** 这是重要的真核基因表达调控途径。配体与 Gs 耦联受体结合后，升高 cAMP 并激活 PKA；释放的催化亚基 C 由细胞质转入细胞核，催化 cAMP 反应元件结合蛋白（cAMP-response element binding protein，CREB）N 端转录活性区磷酸化。磷酸化 CREB 与 CREB 结合蛋白（CREB-binding protein，CBP）特异性结合形成复合物，复合物与含有 cAMP 反应元件（cAMP-response element，CRE）的靶基因结合，激活转录，表达靶蛋白。

::figure{src="/images/cell-biology/textbook/p0283_01.png" caption="图12-10 cAMP-PKA 信号通路。肾上腺素激活 GPCR 和 Gsα，腺苷酸环化酶催化生成 cAMP，PKA 解聚活化。左侧快反应：PKA 磷酸化糖原磷酸化酶激酶，再激活糖原磷酸化酶，促进糖原分解；右侧慢反应：PKA 入核磷酸化 CREB，启动靶基因转录。" alt="cAMP-PKA分成糖原分解快反应和CREB转录慢反应"}

:::cause-effect{title="升血糖激素如何同时打开分解、关上合成"}
- 因：肾上腺素或胰高血糖素结合 Rs，Gs 激活 AC，cAMP 升高，PKA 释放 C 亚基
- 因：PKA 磷酸化并激活糖原磷酸化酶激酶，再激活糖原磷酸化酶
- 因：同一 PKA 也磷酸化糖原合酶，使其失活
- 结果：糖原分解被打开、糖原合成被关上，肝和肌细胞迅速输出或动用葡萄糖
:::

### （三）G 蛋白耦联受体介导的磷脂酰肌醇信号通路

磷脂酰肌醇信号通路是细胞外信号分子与膜上 GPCR 结合后，激活磷脂酶 C（phospholipase C，PLC），使膜上的 4,5-二磷酸磷脂酰肌醇（$\mathrm{PIP}_2$）水解，产生两个第二信使——1,4,5-三磷酸肌醇（$\mathrm{IP}_3$）和二酰甘油（DAG）。DAG 继续停留在细胞膜上，$\mathrm{IP}_3$ 离开细胞膜转移到细胞质。

:::definition{label="双信使系统"}
双信使系统是磷脂酰肌醇信号途径同时产生 $\mathrm{IP}_3$ 和 DAG 两个第二信使，分别启动 $\mathrm{IP}_3$–$\mathrm{Ca}^{2+}$ 和 DAG–PKC 两条传递途径，实现细胞对外界刺激应答的机制。一条配体、一次 PLC 水解，写出钙信号和脂信号两半。
:::

$\mathrm{IP}_3$ 与内质网上的 $\mathrm{IP}_3$ 配体门控钙通道结合，开启钙通道，动员内质网中的 $\mathrm{Ca}^{2+}$ 到细胞质，$\mathrm{Ca}^{2+}$ 浓度瞬间由 $10^{-7}\,\mathrm{mol/L}$ 升至 $10^{-5}\,\mathrm{mol/L}$。

当细胞表面受体与相应外界信号结合后，$\mathrm{PIP}_2$ 水解，膜上的 DAG 瞬间增多。胞内 $\mathrm{Ca}^{2+}$ 浓度升高后，与细胞质中蛋白激酶 C（protein kinase C，PKC）结合并转位到细胞膜内表面。PKC 具有 1 个亲水性催化活性中心和 1 个疏水的膜结合区；未受刺激时主要分布在细胞质中，呈非活性状态。转位到膜内表面的 PKC 受 DAG 作用而被活化，使靶蛋白磷酸化，细胞产生分泌、肌肉收缩、血小板颗粒释放等反应，也可通过调控相关靶基因表达促进增殖和分化。

::figure{src="/images/cell-biology/textbook/p0284_01.png" caption="图12-11 磷脂酰肌醇“双信使系统”信号通路。GPCR 激活 G 蛋白后激活 PLC，水解 PIP₂ 为膜上的 DAG 和胞质中的 IP₃。IP₃ 打开内质网膜钙通道，Ca²⁺ 释放；Ca²⁺ 既激活钙调蛋白（CaM），又协助 DAG 在膜上激活 PKC。" alt="PLC水解PIP2产生IP3和DAG，分别释放钙和激活PKC"}

:::derivation{label="磷脂酰肌醇双信使的分流与终止"}
1. 配体激活 GPCR，相应 G 蛋白激活 PLC。
2. PLC 水解膜脂 $\mathrm{PIP}_2$，生成留在膜上的 DAG 和进入胞质的 $\mathrm{IP}_3$。
3. $\mathrm{IP}_3$ 结合内质网膜上的 $\mathrm{IP}_3$ 门控钙通道，通道开放，内质网 $\mathrm{Ca}^{2+}$ 释放；胞质 $\mathrm{Ca}^{2+}$ 由 $10^{-7}\,\mathrm{mol/L}$ 升至 $10^{-5}\,\mathrm{mol/L}$。
4. $\mathrm{Ca}^{2+}$ 结合 PKC 并使其转位到膜内表面；膜上堆积的 DAG 激活 PKC，PKC 磷酸化靶蛋白。
5. $\mathrm{Ca}^{2+}$ 同时与钙调蛋白（calmodulin，CaM）结合，CaM 构象改变后激活钙调蛋白激酶，引起另一组靶蛋白磷酸化；CaM 还可激活质膜 $\mathrm{Ca}^{2+}$ 泵，反过来调节胞内钙浓度。$\mathrm{Ca}^{2+}$ 也可直接调节 $\mathrm{Na}^+$、$\mathrm{K}^+$ 等通道。
6. 终止：$\mathrm{IP}_3$ 去磷酸化形成 $\mathrm{IP}_2$，或被磷酸化形成 $\mathrm{IP}_4$；$\mathrm{Ca}^{2+}$ 由质膜 $\mathrm{Ca}^{2+}$ 泵和 $\mathrm{Na}^+$–$\mathrm{Ca}^{2+}$ 交换器排出，或由内质网膜钙泵收回。$\mathrm{Ca}^{2+}$ 浓度高时与 CaM 结合，浓度低时解离，CaM 失活，反应终止。

净结果：一次 $\mathrm{PIP}_2$ 水解同时写出钙波和 PKC，收缩、分泌、分裂都要用到这套双信使；关通路必须同时清 $\mathrm{IP}_3$ 和抽回 $\mathrm{Ca}^{2+}$。
:::

:::compare{title="cAMP 通路 vs 磷脂酰肌醇双信使"}
| 项目 | cAMP–PKA | $\mathrm{IP}_3$/DAG–$\mathrm{Ca}^{2+}$/PKC |
|------|----------|------------------------------------------|
| 效应酶 | 腺苷酸环化酶（AC） | 磷脂酶 C（PLC） |
| 第二信使 | cAMP（胞质可溶） | $\mathrm{IP}_3$（可溶）+ DAG（留在膜上） |
| 下游激酶 | PKA（$\mathrm{R}_2\mathrm{C}_2$，cAMP 解聚） | PKC（需 $\mathrm{Ca}^{2+}$ 转位到膜，再被 DAG 激活）；另有 CaM 激酶 |
| 离子 | 不直接动员内质网钙 | 内质网 $\mathrm{Ca}^{2+}$ 由 $10^{-7}$ 升至 $10^{-5}\,\mathrm{mol/L}$ |
| 快反应例子 | 糖原分解/抑制糖原合成 | 分泌、肌肉收缩、血小板颗粒释放 |
| 慢反应 | PKA 入核磷酸化 CREB | PKC 调控增殖、分化相关基因 |
| 终止 | cAMP 被磷酸二酯酶降解；Gs 水解 GTP | $\mathrm{IP}_3$→$\mathrm{IP}_2$ 或 $\mathrm{IP}_4$；钙泵和 $\mathrm{Na}^+$–$\mathrm{Ca}^{2+}$ 交换器回收 $\mathrm{Ca}^{2+}$ |
:::

:::pitfall{label="不要把 DAG 和 IP3 写成同一个信使的两个名字"}
$\mathrm{PIP}_2$ 水解一次得到两个化学性质不同的分子：$\mathrm{IP}_3$ 离开膜去开内质网钙通道，DAG 留在膜上等 PKC 转位过来。把双信使记成“就是钙信号”，会把 PKC 和佛波酯（第五节）整段漏掉；把 PKC 写成“被 $\mathrm{IP}_3$ 激活”，空间位置就写反了。
:::

:::concept{term="钙调蛋白是可逆的钙传感器"}
CaM 本身不是酶，是 $\mathrm{Ca}^{2+}$ 浓度的读数器：浓度高时结合钙并激活下游激酶和钙泵，浓度低时解离并终止反应。它既把钙波写成磷酸化，也通过钙泵帮着把钙波关掉。把 CaM 记成“又一种第二信使”，会和 $\mathrm{IP}_3$、$\mathrm{Ca}^{2+}$ 的层级打架。
:::

### （四）G 蛋白耦联受体介导的离子通道信号通路

有一些神经递质受体是 GPCR，通过 G 蛋白的分子开关作用，调控跨膜离子通道的开启与关闭，进而调节靶细胞活性。光感受器、嗅觉神经受体也是 GPCR。这里与第一节的“离子通道耦联受体（配体门控通道）”不是同一类：配体门控通道本身就是孔道；本小节的受体仍是 7 次跨膜 GPCR，孔道是它下游的效应器。

**1. G 蛋白耦联的乙酰胆碱 M 受体。** 乙酰胆碱 M 受体（muscarinic acetylcholine receptor）在心肌细胞膜上与抑制性 Gi 蛋白耦联。乙酰胆碱与受体结合使受体活化，Gi 的 $\alpha$ 亚基上 GDP 被 GTP 取代，三聚体解离，游离的 $\beta\gamma$ 亚基得以释放，致使心肌细胞质膜上相关的 $\mathrm{K}^+$ 通道开启，$\mathrm{K}^+$ 外流，膜电位改变，细胞膜超极化（hyperpolarization），减缓心肌细胞的收缩频率。这里的效应器不是 AC，而是钾通道；执行者主要是 $\beta\gamma$，不是 $\mathrm{G}\alpha$。

**2. G 蛋白耦联的光敏感受体。** 人类视网膜的视锥细胞光受体与色彩感受相关；视杆细胞光受体接受弱光刺激。视紫红质是视杆细胞的 GPCR，定位在视杆细胞外段上千个扁平膜盘上。人类视杆细胞含有大约 $4\times 10^{7}$ 个视紫红质分子。耦联视紫红质的三聚体 G 蛋白称为转导蛋白（transducin，Gt）。

在暗适应状态下，视杆细胞具有高浓度 cGMP，使细胞膜 cGMP 门控阳离子通道保持开放，膜电位保持在 $-30\,\mathrm{mV}$，视杆细胞持续释放神经递质。吸收光后视蛋白被激活，活化的视蛋白与无活性的 GDP–Gt 三聚体结合，GDP 被 GTP 置换，三聚体解离形成游离的 Gt；Gt 与 cGMP 磷酸二酯酶（PDE）结合导致 PDE 活化，催化 cGMP 转换成 GMP。胞质 cGMP 水平降低，阳离子通道关闭，细胞膜负值加大而超极化，视杆细胞释放神经递质减少。这种变化传递到大脑皮质，感受到光的存在。

:::note{label="光把 cGMP 写低，激素常把 cAMP 写高"}
视杆的逻辑与肝细胞升血糖相反：暗处通道开着、持续释放递质；光子激活 Gt–PDE，把 cGMP 拆掉，通道才关。不要把“G 蛋白激活 = 第二信使升高”写成通例。
:::

## 二、酶联受体介导的信号转导通路

酶联受体都是单次穿膜蛋白，胞外区与配体结合，胞内区本身具有酶活性或直接与酶结合形成复合物。多数酶联受体在配体结合后激活胞内区酶活性，经过多步传递最终改变基因表达，调节生长、增殖、分化，一般不调控细胞中间代谢。根据作用性质，分为受体酪氨酸激酶、受体丝氨酸/苏氨酸激酶、受体酪氨酸磷酸酯酶、受体鸟苷酸环化酶、酪氨酸激酶耦联受体。下面展开三条教材主通路。

:::definition{label="酶联受体"}
酶联受体是单次穿膜的细胞表面受体：胞外区结合配体，胞内区或自身是酶，或直接结合酶。配体结合后激活蛋白激酶（或募集激酶），使靶蛋白顺次磷酸化，通常通向基因表达而不是中间代谢。
:::

### （一）酪氨酸激酶受体介导的 RTK–Ras 信号通路

受体酪氨酸激酶（receptor tyrosine kinase，RTK）是细胞表面一大类重要受体家族，迄今已鉴定有 7 个亚族、50 余种。RTK 的 N 端位于细胞外，是配体结合域；C 端位于胞内，具有酪氨酸激酶结构域。胞外配体是可溶性或膜结合的多肽或蛋白类激素，包括多种生长因子。

:::definition{label="受体酪氨酸激酶"}
受体酪氨酸激酶（RTK）是胞内段具有酪氨酸激酶活性的单次穿膜受体。未结合配体时以单体失活形式存在；配体结合后二聚化，二聚体内交叉磷酸化胞内肽段的酪氨酸残基，即自体磷酸化（autophosphorylation）。磷酸化酪氨酸形成 SH2 结合位点，供含 SH2 结构域的胞内信号蛋白停靠。
:::

::figure{src="/images/cell-biology/textbook/p0285_01.png" caption="图12-12 受体酪氨酸激酶的激活。二聚体配体使两个无活性的 RTK 单体成对，酪氨酸激酶结构域被刺激；交叉磷酸化的酪氨酸形成 SH2 结合位点，供含 SH2 结构域的信号蛋白识别。" alt="RTK单体经配体二聚化交叉磷酸化，形成SH2停靠位点"}

细胞内存在蛋白酪氨酸磷酸酶，可通过催化酪氨酸脱去磷酸基终止激活；有时也可通过内吞将受体转入细胞内被溶酶体消化。第四节的受体下调，在 RTK 上同样适用。

在许多真核细胞中，Ras 蛋白是 RTK 介导信号通路中的关键组分。Ras 是原癌基因 ras 的表达产物，由 190 个氨基酸残基组成，是具有 GTP 酶活性的 GTP 结合蛋白，分布于细胞膜胞质侧：结合 GTP 为活化态，结合 GDP 为失活态，起到分子开关作用。Ras 被激活后能启动一条磷酸化级联，把细胞外信号传入细胞核，激活相关基因表达。

:::definition{label="Ras 蛋白"}
Ras 蛋白是原癌基因 ras 编码的小 GTP 结合蛋白，190 个氨基酸残基，贴在质膜胞质侧。GTP 结合为开、GDP 结合为关。它把活化的 RTK 接到 MAP 激酶级联上。若 Ras 一直处于激活状态，细胞增殖失控；约 30% 的癌症患者体内 ras 基因发生了激活突变。
:::

RTK–Ras 信号通路的基本过程如下。

**① RTK 受体活化。** 生长因子与 RTK 结合，导致受体二聚体化，胞内区酪氨酸残基磷酸化，形成可被 SH2 结构域识别的位点。

**② Ras 蛋白激活。** 磷酸化酪氨酸被衔接蛋白通过其 SH2 结构域识别并结合。衔接蛋白既能结合 RTK，又能结合并激活 Sos 蛋白；Sos 再与 Ras 结合，催化 Ras 释放 GDP、结合 GTP，使 Ras 激活。Sos 在这里相当于 Ras 的 GEF。

**③ MAP 激酶信号组件的顺次激活。** 活化的 Ras 促进一系列激酶链顺次激活。酶链的最后一个称为 MAPK（促分裂原活化的蛋白激酶），所以称作 MAP 激酶信号组件。活化 Ras 激活 MAPKKK（MAPKK 的激酶，也称 Raf），MAPKKK 再激活 MAPKK，MAPKK 激活 MAPK。

**④ 生理效应或基因表达。** 活化的 MAPK 催化一些效应蛋白磷酸化，引起许多生化反应。最为重要的是 MAPK 进入细胞核，催化专一转录因子的丝氨酸和苏氨酸残基磷酸化，磷酸化转录因子被激活，对靶基因表达进行调控，进而影响增殖、分化等生命活动（图 12-13）。

::figure{src="/images/cell-biology/textbook/p0286_01.png" caption="图12-13 Ras 蛋白激活的磷酸化级联反应途径。活化 RTK 经含 SH2 的衔接蛋白募集 Sos，催化 Ras 由 GDP 态转为 GTP 态；Ras-GTP 顺次激活 MAPKKK（Raf）、MAPKK、MAPK。MAPK 既磷酸化胞质效应蛋白，也入核激活转录因子。" alt="RTK经衔接蛋白和Sos激活Ras，再经MAPKKK-MAPKK-MAPK级联入核"}

:::derivation{label="RTK–Ras–MAPK 级联"}
1. 生长因子结合 RTK 胞外区，受体二聚化。
2. 二聚体内交叉自体磷酸化，磷酸化酪氨酸形成 SH2 停靠位点。
3. 含 SH2 的衔接蛋白结合 RTK，并结合 Sos。
4. Sos 作为 GEF，催化膜上的 Ras 释放 GDP、结合 GTP。
5. Ras-GTP 激活 MAPKKK（Raf）→ MAPKK → MAPK，三级激酶逐级磷酸化放大。
6. MAPK 磷酸化胞质效应蛋白（快），并入核磷酸化转录因子（慢），改写增殖和分化。
7. 蛋白酪氨酸磷酸酶去磷酸化，或受体被内吞进溶酶体，信号终止。Ras 若因突变失去 GTP 酶、一直停在 GTP 态，级联关不掉，约 30% 癌症与此类 ras 激活突变相关。
:::

### （二）TGF-β 受体信号通路

转化生长因子 $\beta$（transforming growth factor-$\beta$，TGF-$\beta$）家族是一类结构相似的分泌型多肽生长因子，包括 TGF-$\beta$、骨形成蛋白（bone morphogenetic protein，BMP）、活化素（activin）等多个亚家族。TGF-$\beta$ 家族分子在合成后被分泌到细胞外，其活性形式大多为二聚体。第十一章把 TGF-$\beta$ 写成纤维化的关键因子；这里补上它的受体和 Smad。

:::definition{label="TGF-β 受体"}
TGF-$\beta$ 受体的胞内段均含丝氨酸/苏氨酸激酶结构域，按分子量分为 RⅠ、RⅡ 和 RⅢ 三类。RⅢ 在细胞膜上结合并富集成熟的 TGF-$\beta$；RⅠ 和 RⅡ 为二聚体化的穿膜蛋白，直接参与转导。
:::

TGF-$\beta$ 与 RⅢ 结合后，RⅢ 将 TGF-$\beta$ 递交给 RⅡ；RⅡ 进一步招募 RⅠ 并与之结合，形成四聚体，激酶结构域靠近。RⅡ 磷酸化 RⅠ 胞内段的丝氨酸/苏氨酸残基，激活 RⅠ。活化的 RⅠ 直接结合并磷酸化下游的基因调节蛋白 Smad 家族，因此称为 TGF-$\beta$–Smad 信号通路。

:::definition{label="Smad 蛋白"}
Smad 是 TGF-$\beta$ 通路的基因调节蛋白，分为三类：受体激活型 R-Smad（Smad1/2/3/5/8）、通用型 Smad（Smad4）和抑制型 Smad（Smad6/7）。分子由 MH1、MH2 两个结构域及连接它们的铰链区组成：MH1 结合 DNA，MH2 与其他转录因子相互作用。
:::

TGF-$\beta$ 与细胞表面受体结合后，RⅠ 活化并磷酸化 R-Smad。磷酸化 R-Smad 在细胞质内与 Smad4 组成复合体，转运到细胞核发挥转录因子作用，激活特定靶基因的转录（图 12-14）。抑制型 Smad6/7 则在这条路上充当负反馈刹车，对应第四节“产生抑制性蛋白”那一种脱敏。

::figure{src="/images/cell-biology/textbook/p0286_02.png" caption="图12-14 TGF-β-Smad 信号通路。TGF-β 二聚体结合受体后，RⅠ 磷酸化 R-Smad；磷酸化 R-Smad 与 Smad4 组成复合体入核，与其他转录因子和 DNA 共结合因子一起启动靶基因转录。" alt="TGF-β受体磷酸化R-Smad，与Smad4入核调控转录"}

TGF-$\beta$ 还可以激活包括 MAPK 在内的其他信号通路，共同调节细胞生命活动。它不仅影响增殖、分化，而且在创伤愈合、细胞外基质形成、胚胎发育、组织分化、骨重建、免疫调节以及神经系统发育中都有重要作用。Smad2/Smad4 或 Smad3/Smad4 可以阻遏 c-myc 基因转录，从而减少受 Myc 调控的促进细胞增殖基因的表达，抑制细胞增殖。因而 TGF-$\beta$ 信号的缺失会导致细胞异常增殖和癌变。

### （三）细胞因子受体信号通路

细胞因子（cytokine）是影响和调控多种类型细胞增殖、分化与成熟的活性因子，包括白介素（interleukin，IL）、干扰素（interferon，IFN）、集落刺激因子（colony-stimulating factor，CSF）、促红细胞生成素（erythropoietin，EPO）和某些激素（如生长激素和催乳素）等，分子量相对较小。

:::definition{label="细胞因子受体"}
细胞因子受体（cytokine receptor）是细胞表面一类与酪氨酸激酶耦联的受体（tyrosine kinase-linked receptor）。蛋白单次跨膜，本身不具有酶活性，但胞内段具有胞质酪氨酸激酶 JAK（Janus kinase）的结合位点。JAK 的 N 端结合受体，C 端为激酶结构域。
:::

JAK 的底物是信号转导子和转录激活子（signal transducer and activator of transcription，STAT）。STAT 的 N 端具有 SH2 结构域和核定位信号（NLS），中间为 DNA 结合域，C 端的酪氨酸残基对其活化至关重要。STAT 家族有 7 个成员，具有信号转导和转录激活的双重功能，因此这条通路又称为 JAK–STAT 信号通路。

:::definition{label="JAK-STAT 通路"}
JAK–STAT 通路是细胞因子受体介导的信号途径。配体引起受体二聚化，结合在受体上的 JAK 交叉磷酸化而激活；JAK 磷酸化受体胞内段酪氨酸，STAT 经 SH2 结合上去并被磷酸化。两个磷酸化 STAT 形成同源二聚体，暴露 NLS，入核结合特异调控序列，调节基因表达。
:::

::figure{src="/images/cell-biology/textbook/p0287_01.png" caption="图12-15 JAK-STAT 信号通路。细胞因子使受体二聚化，JAK 交叉磷酸化后磷酸化 STAT；磷酸化 STAT 形成二聚体，入核启动靶基因转录。" alt="细胞因子受体经JAK磷酸化STAT，STAT二聚体入核转录"}

细胞因子对多种细胞特别是造血细胞和免疫细胞的生长、分化与成熟起重要调控作用，对增殖、分化、迁移和凋亡也具有重要调节作用。目前已在人类肿瘤中发现 STAT3 信号的异常持续活化，并发现其在心血管疾病、肥胖症、糖尿病以及支气管哮喘等疾病中可能起关键调控作用。

| 项目 | RTK–Ras–MAPK | TGF-$\beta$–Smad | JAK–STAT |

| 受体酶活性 | 自身是酪氨酸激酶 | 自身是丝/苏氨酸激酶（RⅠ/RⅡ） | 自身无酶活性，耦联胞质激酶 JAK |
| 配体 | 生长因子等 | TGF-$\beta$、BMP、活化素 | IL、IFN、CSF、EPO、生长激素、催乳素等 |

| 关键开关 | Ras（小 G 蛋白） | R-Smad 磷酸化后与 Smad4 成复合体 | STAT 磷酸化后同源二聚化 |

:::

:::insight{label="经典实验：Src 蛋白酪氨酸激酶活性的发现"}
劳斯肉瘤病毒（Rous sarcoma virus，RSV）是第一个被分离的能引起动物肿瘤的病毒。研究人员在 RSV 基因组中发现了在诱导肿瘤发生中起关键作用的癌基因 src。更为重要的是，各种脊椎动物（包括人类）的正常基因组中也存在与病毒 src 同源的基因。1977 年，R. Erikson 和他的同事利用抗血清，通过免疫沉淀分离得到了 Src 蛋白。随后发现，Src 的免疫沉淀物在 ATP 存在时可导致免疫球蛋白分子磷酸化，因此推测 Src 可能是一种蛋白激酶，但其作为蛋白激酶的本质并不清楚。

T. Hunter 和 B. M. Sefton 追问：Src 磷酸化的是酪氨酸残基，还是丝/苏氨酸残基？他们将底物蛋白质（免疫球蛋白分子）与 Src 免疫沉淀物及 $^{32}$P 标记的 ATP 共同孵育，使被磷酸化的氨基酸残基带上放射性；再把底物水解为单个氨基酸，用电泳、层析分离磷酸化的酪氨酸、丝氨酸及苏氨酸。检测到的放射性氨基酸是酪氨酸，表明 Src 能特异磷酸化底物中的酪氨酸残基。进一步实验显示，正常细胞的 Src 和病毒 Src 均具有酪氨酸激酶活性。

他们还通过体外实验证实细胞总蛋白中存在磷酸化酪氨酸。正常细胞中，磷酸化酪氨酸仅占整个细胞磷酸化氨基酸的 0.03%（其余是磷酸化的丝氨酸和苏氨酸），这也正是过去不易被检测到的原因。而在受 RSV 感染的细胞中，磷酸化酪氨酸含量升高了 10 倍之多，表明蛋白酪氨酸激酶活性增加可诱导细胞非正常增殖。

论文：Hunter T, Sefton B M. Transforming gene product of Rous sarcoma virus phosphorylates tyrosine. *Proc Natl Acad Sci U S A*, 1980, 77(3): 1311-1315。

Src 的发现确定了一种新的蛋白酪氨酸激酶，并把酪氨酸激酶活性与细胞增殖调控绑在一起。后续发现许多其他肿瘤病毒蛋白也具有这一功能，EGF 受体本身就是蛋白酪氨酸激酶，从而证明酪氨酸磷酸化既参与癌细胞的非正常增殖，也参与正常细胞的增殖调控。由原癌基因编码的蛋白酪氨酸激酶，至今仍是癌细胞特异性药物的潜在靶标。
:::

## 三、蛋白复合体解离介导的信号转导通路

生物个体内存在一系列可控的蛋白复合体解离介导的信号通路：信号分子与受体结合后，细胞内蛋白复合体水解或切割，释放出活化的转录因子，进而调控基因表达。引起复合体解离的机制主要分为两类：一类为泛素化降解介导，如 Wnt、Hedgehog 和 NF-$\kappa$B；另一类是蛋白切割（cleavage）介导，如 Notch。

:::definition{label="蛋白复合体解离介导的信号通路"}
蛋白复合体解离介导的信号通路是配体结合受体后，通过泛素化–蛋白酶体降解或蛋白酶切割，把原先被扣留的转录因子从抑制性复合体中释放出来、使之入核的转导方式。与 GPCR 和 RTK 的“逐级磷酸化”不同，这里的关键步骤是把刹车拆掉。
:::

### （一）泛素化降解介导的信号通路

**1. NF-$\kappa$B 信号通路。** 核因子 $\kappa$B（nuclear factor-kappa B，NF-$\kappa$B）是哺乳动物免疫系统的主要转录调控因子，能促进中性粒细胞迁移到炎症组织，也能在细菌刺激下引起诱导型一氧化氮合酶（iNOS）的表达，以及产生一些抗凋亡蛋白抵抗细胞死亡。其受体主要包括 TNF-$\alpha$ 受体、Toll 样受体和 IL-1 受体。

NF-$\kappa$B 通常以异二聚体形式存在于细胞质，两个亚基 p50 和 p65 的 N 端有一个同源核定位信号区（NLS），形成二聚体并与 DNA 结合。在细胞没有应激或感染时，抑制子 I$\kappa$B$\alpha$ 与 NF-$\kappa$B 异二聚体的 N 端同源区结合，NLS 被隐藏，处于失活状态。

在感染源或炎症因子的短时间刺激下，胞内异三聚体复合物 I$\kappa$B 激酶中的 IKK$\beta$ 激活并被磷酸化。活化的 IKK$\beta$ 进一步磷酸化 I$\kappa$B$\alpha$ N 端的丝氨酸残基，E3 泛素化连接酶结合到这些磷酸丝氨酸位点，对 I$\kappa$B$\alpha$ 进行多泛素化修饰并诱导其被蛋白酶体降解。I$\kappa$B$\alpha$ 降解后，NF-$\kappa$B 的抑制被解除，其上的核定位序列暴露，引导 NF-$\kappa$B 进入细胞核激活靶基因转录（图 12-16）。

::figure{src="/images/cell-biology/textbook/p0289_01.png" caption="图12-16 NF-κB 信号通路。炎症刺激激活 IKK（IKKα/IKKβ/IKKγ），IKKβ 磷酸化 IκBα 并送入蛋白酶体降解；p50/p65 的 NLS 暴露，二聚体入核启动靶基因转录。" alt="IKK磷酸化IκBα使其被蛋白酶体降解，NF-κB入核"}

**2. Wnt 信号通路。** Wnt 通路同样由泛素化降解介导，在个体发育中发挥重要作用，但过度活化会导致肿瘤或其他疾病。Wnt 通路有两种细胞表面受体蛋白：①Frizzled（Fz）含有 7 次跨膜 $\alpha$ 螺旋，能直接与 Wnt 结合；②共受体 LRP，以 Wnt 信号依赖的方式与 Fz 受体结合。

:::definition{label="Wnt-β-catenin 通路"}
Wnt-$\beta$-catenin 通路中，$\beta$-catenin 兼具转录激活因子和膜骨架连接蛋白双重角色。无 Wnt 时，胞质 $\beta$-catenin 被 Axin、APC、GSK3 等组成的降解复合物磷酸化、泛素化并被蛋白酶体降解，核内没有足够的 $\beta$-catenin。有 Wnt 时，Wnt 结合 Fz 和 LRP，降解复合物被拆开，$\beta$-catenin 稳定并入核，与转录因子 TCF 共同调控靶基因。
:::

当没有 Wnt 信号分子时，细胞膜上的 $\beta$-catenin 发挥连接蛋白的作用；细胞质中的 $\beta$-catenin 结合在由支架蛋白 Axin 介导、包含 APC 等蛋白的降解复合物上，复合物中的 GSK3 激酶磷酸化 $\beta$-catenin，磷酸化的 $\beta$-catenin 被泛素标记，最终被蛋白酶体降解。因而胞质内仅有低水平的 $\beta$-catenin，无法进入细胞核激活下游基因。

当细胞外存在高水平的 Wnt 时，Wnt 与膜表面受体 Fz 和 LRP 结合，磷酸化 LRP 受体的胞质结构域；Axin 与 LRP 磷酸化的胞质结构域结合，释放出 GSK3，避免 $\beta$-catenin 被 GSK3 磷酸化，因此 $\beta$-catenin 不会被泛素化降解，在胞质中维持稳定。游离的 $\beta$-catenin 进入细胞核，结合转录因子 TCF，共同调控下游靶基因表达（图 12-17）。图中还标出了 Dishevelled（Dsh）对降解复合物的抑制，以及膜上与 E-cadherin、$\alpha$-catenin 相连的那一库 $\beta$-catenin。

::figure{src="/images/cell-biology/textbook/p0290_01.png" caption="图12-17 Wnt-β-catenin 信号通路。Wnt 结合 Frizzled 后经 Dsh 抑制 APC–Axin–GSK3 降解复合物，未磷酸化的 β-catenin 入核与 TCF 启动转录；被 GSK3 磷酸化的 β-catenin 则走蛋白酶体。膜上另有与 E-cadherin、α-catenin 相连的 β-catenin 库。" alt="Wnt抑制β-catenin降解复合物，稳定的β-catenin入核与TCF转录"}

**3. Hedgehog（Hh）信号通路。** Hh 通路有两种膜受体：Smoothened（Smo）和 Patched（Ptc）。在 Hh 信号不存在时，Ptc 主要富集于细胞膜上，并将 Smo 限制在细胞内膜泡中。当 Hh 与膜上的 Ptc 结合后，Ptc 的活性被抑制并诱发内吞、被溶酶体消化，从而解除对 Smo 的限制；Smo 通过膜泡融合移位至质膜上并被磷酸化，启动下游蛋白复合体解离，释放出转录因子 Ci。Ci 进入细胞核与转录激活子 CREB 结合蛋白（CBP）结合，促进靶基因表达。

### （二）通过蛋白切割激活的信号通路

Notch 信号通路属于细胞接触依赖性通讯。Notch 受体与其对应的配体 Delta 皆是位于细胞膜表面的单次穿膜蛋白。一个细胞上的 Delta 与邻近细胞上的 Notch 受体结合，Notch 被激活：其胞外部分首先被 MMP 家族蛋白 ADAM10 切割，释放 Notch 受体的胞外段；随后，$\gamma$-分泌酶（$\gamma$-secretase）结合到 Notch 的细胞质内残余部分，切割并释放 Notch 胞质片段（Notch1 intracellular cytoplasmic domain，NICD）。NICD 进入细胞核与转录因子（如图中的 CSL）相互作用，调控基因表达，影响发育过程中细胞命运的决定（图 12-18）。

:::definition{label="Notch 通路"}
Notch 通路是接触依赖性通讯：邻细胞的膜配体 Delta 结合本细胞的 Notch 受体后，依次经 ADAM10 和 $\gamma$-分泌酶两次切割，释放胞质片段 NICD；NICD 入核与转录因子相互作用，决定发育中的细胞命运。没有可溶性配体的长程扩散，命运在细胞–细胞界面上当场写定。
:::

::figure{src="/images/cell-biology/textbook/p0290_02.png" caption="图12-18 Notch 信号通路。信号产生细胞上的 Delta 结合信号接收细胞上的 Notch，蛋白酶切割释放 Notch 胞质片段，入核与 CSL 等转录因子结合，启动靶基因转录。" alt="邻细胞膜上Delta结合Notch，切割后NICD入核与CSL转录"}

:::compare{title="泛素化降解通路 vs Notch 切割通路"}
| 项目 | NF-$\kappa$B / Wnt / Hh | Notch |
|------|------------------------|-------|
| 解离手段 | 泛素化后蛋白酶体降解抑制蛋白或转录因子本身 | 蛋白酶两次切割受体，释放胞质片段 |
| 被释放的入核分子 | NF-$\kappa$B、$\beta$-catenin、Ci | NICD（受体自身的胞质段） |
| 无信号时 | 转录因子被扣留或被持续降解 | Notch 完整留在膜上，不入核 |
| 通讯方式 | 可溶配体（TNF-$\alpha$、Wnt、Hh 等） | 接触依赖性（Delta–Notch） |
| 关键酶 | IKK、GSK3、E3、蛋白酶体 | ADAM10（MMP 家族）、$\gamma$-分泌酶 |
:::

:::keypoint{label="膜受体三条主路，开关各不相同"}
- GPCR：7 次跨膜，G 蛋白循环当计时器；效应器可以是 AC、PLC 或离子通道。
- Gs 抬 cAMP、Gi 压 cAMP；PLC 一次水解写出 $\mathrm{IP}_3$ 和 DAG 两个信使。
- 酶联受体单次跨膜：RTK 走长级联 Ras–MAPK，TGF-$\beta$ 走 Smad，细胞因子走 JAK–STAT。
- 复合体解离：要么把刹车泛素化拆掉（NF-$\kappa$B、Wnt、Hh），要么把受体胞质段切下来（Notch）。
:::

:::memory{label="本节必背要点"}
- [ ] 膜受体三条主路：GPCR、酶联受体、蛋白复合体解离。
- [ ] 人类约 700 余种 GPCR；7 次穿膜，N 端在外、C 端在内，C3 环耦联 G 蛋白。
- [ ] G 蛋白 $\alpha\beta\gamma$ 三聚体：静息结合 GDP；GTP 置换后 $\alpha$ 与 $\beta\gamma$ 解离；$\mathrm{G}\alpha$ 的 GTP 酶负责关闭。Rodbell 与 Gilman，1994 年诺贝尔奖。
- [ ] Gs 耦联 Rs 激活 AC 升 cAMP；Gi 耦联 Ri 抑制 AC，且游离 $\beta\gamma$ 可再绑 $\mathrm{Gs}\alpha$。
- [ ] 霍乱毒素使 $\mathrm{Gs}\alpha$ 失去 GTP 酶，小肠上皮 cAMP 增加 100 倍以上。
- [ ] PKA 为 $\mathrm{R}_2\mathrm{C}_2$；cAMP 结合 R 后释放 C。快反应：糖原磷酸化酶级联；慢反应：C 入核磷酸化 CREB，结合 CRE。
- [ ] PLC 水解 $\mathrm{PIP}_2$ → $\mathrm{IP}_3$（开内质网钙通道）+ DAG（膜上激活 PKC）；$\mathrm{Ca}^{2+}$ 由 $10^{-7}$ 升至 $10^{-5}\,\mathrm{mol/L}$。
- [ ] $\mathrm{IP}_3$ 终止为 $\mathrm{IP}_2$ 或 $\mathrm{IP}_4$；钙由泵和 $\mathrm{Na}^+$–$\mathrm{Ca}^{2+}$ 交换器清除。CaM 是可逆钙传感器。
- [ ] 心肌 M 受体经 Gi 的 $\beta\gamma$ 打开 $\mathrm{K}^+$ 通道，超极化，减慢心率。
- [ ] 视紫红质–Gt–PDE：光使 cGMP 下降，阳离子通道关闭，视杆超极化；暗处电位约 $-30\,\mathrm{mV}$，约 $4\times 10^{7}$ 个视紫红质分子。
- [ ] RTK：7 亚族 50 余种；二聚化自体磷酸化，SH2 停靠；Ras 190 氨基酸；Sos 是 GEF；Raf–MAPKK–MAPK；约 30% 癌症有 ras 激活突变。
- [ ] TGF-$\beta$ 受体分 RⅠ/RⅡ/RⅢ；R-Smad 与 Smad4 入核；Smad2/3 与 Smad4 阻遏 c-myc。
- [ ] JAK–STAT：受体无酶活性，耦联 JAK；STAT 家族 7 成员；STAT3 持续活化见于肿瘤。
- [ ] Hunter 与 Sefton（1980）证明 Src 磷酸化酪氨酸；正常细胞磷酸化酪氨酸仅占 0.03%，RSV 感染后升高 10 倍。
- [ ] NF-$\kappa$B：I$\kappa$B$\alpha$ 被 IKK$\beta$ 磷酸化后泛素化降解，p50/p65 入核。
- [ ] Wnt：无信号时 GSK3 磷酸化 $\beta$-catenin 使之降解；有 Wnt 时 $\beta$-catenin 稳定入核结合 TCF。
- [ ] Hh：无信号时 Ptc 把 Smo 关在内膜泡；Hh 抑制 Ptc，Smo 上膜，释放转录因子 Ci。
- [ ] Notch：Delta 接触激活，ADAM10 与 $\gamma$-分泌酶两次切割，NICD 入核决定细胞命运。
:::
