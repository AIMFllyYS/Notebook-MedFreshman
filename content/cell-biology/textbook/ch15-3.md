# 第三节 调控细胞分化的细胞外因素

第二节把分化写成核内的许可：母体因子和转录因子决定谁被打开，甲基化和超级增强子把许可记住。核并不能自己知道自己在胚胎的哪一侧。随着细胞数目增加，细胞之间的相互作用对分化的调控越来越重要。原肠胚以后，三个胚层的发育前途虽已确定，但各胚层进一步分化还有赖于细胞群之间的相互作用。这种作用可视为细胞外因素对细胞分化的调节：近处是旁分泌和近分泌的胚胎诱导，远处是经血液运送的激素，再外面是温度、碘和病毒这类环境信号。第十二章已经把配体–受体–转录写成通式；这里它们被用来写位置信息和发育时间表。

:::definition{label="胚胎诱导"}
胚胎诱导（embryonic induction）是胚胎发育过程中，一部分细胞对邻近细胞产生影响并决定其分化方向的现象。起诱导作用的细胞或组织称为诱导细胞或诱导组织，被诱导而发生分化的细胞或组织称为反应细胞或反应组织。胚胎诱导最初由 Spemann 在胚胎移植（embryo transfer）实验中发现。
:::

:::definition{label="旁分泌因子"}
旁分泌因子（paracrine factor）是诱导组织释放、以诱导组织为中心形成浓度梯度的信号分子。它们与反应组织细胞表面的受体结合，把信号传至细胞内，通过调节反应组织细胞的基因表达而诱导分化。胚胎中常见的有 FGF、Hedgehog、Wnt 和 TGF-$\beta$ 超家族。
:::

## 一、细胞间相互作用对细胞分化的调控

在多细胞生命个体各阶段——胚胎发育、幼体发育成熟、成熟个体各组织器官内各种功能与结构细胞的维持——细胞间相互作用都是细胞分化调控的关键因素之一。胚胎时期细胞间的相互作用协调细胞分化的方向，是理解这一调控的经典模型。

### （一）胚胎诱导是胚胎细胞间相互作用调控细胞分化的表现形式

胚胎细胞间的相互诱导作用是有层次的。在三个胚层中，中胚层首先独立分化，该过程对相邻胚层有很强的分化诱导作用，促进内胚层、外胚层各自向相应的组织器官分化。如中胚层脊索诱导覆盖其表面的外胚层形成神经板，这是初级诱导；神经板形成神经管后，其前端进一步膨大为原脑，原脑两侧突出的视杯诱导其上方的外胚层形成晶状体，此为次级诱导；晶状体又诱导覆盖在其上方的外胚层形成角膜，这为三级诱导（图 15-15）。不同胚层细胞通过这种进行性的相互作用实现胚胎细胞特异分化。个体发育过程中，胚胎诱导具有严格的区域特异性和时空限制性。

::figure{src="/images/cell-biology/textbook/p0347_01.png" caption="图15-15 眼球发育过程中的多级诱导作用。A. 初级诱导：前脑（神经管上皮）形成视泡；B. 次级诱导：视杯诱导上方外胚层形成晶状体泡；C. 三级诱导：晶状体诱导表面外胚层形成角膜，并分化出视网膜神经上皮与色素上皮。" alt="眼发育三级诱导：视泡、晶状体泡和角膜依次被诱导形成"}

:::cause-effect{title="中胚层怎样一层层把眼写出来"}
- 因：中胚层脊索首先独立分化，诱导表面外胚层成神经板（初级诱导）
- 因：神经管前端成原脑，视杯诱导上方外胚层成晶状体（次级诱导）
- 果：晶状体再诱导表面外胚层成角膜（三级诱导）
- 结果：眼的各层按区域和时序依次特化；缺了上一级诱导，下一级反应组织没有信号可听
:::

胚胎诱导通过诱导组织释放的各种旁分泌因子实现。这些因子在胚胎的不同发育阶段以及处于不同位置的胚胎细胞中差异表达，提供了胚胎发育过程中的位置信息。常见家族如下。

**① 成纤维细胞生长因子（fibroblast growth factor，FGF）。**

**② Hedgehog 家族蛋白。** 脊椎动物中至少有 $3$ 个果蝇 Hedgehog 基因同源体，即 *shh*（sonic hedgehog）、*dhh*（desert hedgehog）和 *ihh*（indian hedgehog）。

**③ Wnt 家族蛋白。** 为富含半胱氨酸的糖蛋白，在脊椎动物中至少有 $15$ 个家族成员。其名称由 *wingless* 和 *integrated* 融合而成：*wingless* 为果蝇分节极性基因，*integrated* 是它的脊椎动物同源体。

**④ TGF-$\beta$ 超家族。** 由 $30$ 多个结构相关的成员组成，包括 TGF-$\beta$ 家族、活化素（activin）家族、骨形成蛋白（bone morphogenetic protein，BMP）家族及 Vgl 家族等。

果蝇和脊椎动物翅芽是研究胚胎诱导的经典模型。原位杂交显示，sonic hedgehog mRNA 定位于将来发育为翅膀小趾的翅芽后部。如果把另一产生 sonic hedgehog 蛋白的翅芽后部细胞团移植到受体宿主翅芽的前部，那么受体宿主以后发育成的翅膀上将出现镜向的趾重复（图 15-16）。位置信息还表现在不同部位胚胎细胞对同一种旁分泌因子的分化效应不同：sonic hedgehog 蛋白诱导翅芽细胞发育为趾，而由脊索产生的 sonic hedgehog 蛋白则诱导邻近的神经管细胞分化成底板（floor plate）和运动神经元。第二节的 *myoD* 正是被脊索来源的 Shh、Wnt 点燃的；同一分子在翅芽后部写的是趾的顺序。

### （二）胚胎细胞间的相互作用还表现为细胞分化的抑制效应

胚胎发育中已分化的细胞能够抑制邻近细胞进行相同分化，这种抑制为负反馈调节作用。把发育中的蛙胚置于含蛙心组织碎片的培养液中，胚胎将受到抑制不能产生正常的心脏。说明已分化的细胞可产生某种物质，抑制邻近细胞向其相同方向分化，这种物质称为抑素（chalone）。

在具有相同分化命运的胚胎细胞中，如果一个细胞“试图”向某个特定方向分化，那么这个细胞在启动分化指令的同时也发出另一个信号去抑制邻近细胞的分化，这种现象被称为侧向抑制（lateral inhibition）。比如在脊椎动物的神经板细胞向神经前体细胞（neural precursor cell，NPC）分化的过程中，尽管这些神经板细胞均有发育为神经前体细胞的潜能，但只有部分细胞发育为神经前体细胞，其余细胞则分化为上皮性表皮细胞。这种现象是由神经板细胞间的侧向抑制作用所决定的。正是细胞之间有诱导分化和抑制分化的存在，才使胚胎发育有序地进行，使发育的器官之间得以相互区别、避免重复。

:::definition{label="侧向抑制"}
侧向抑制（lateral inhibition）是具有相同分化命运的细胞中，一个细胞在启动自身分化的同时发出信号、抑制邻近细胞作相同分化的现象。神经板中只有部分细胞成为神经前体细胞、其余成为表皮，就是侧向抑制的结果。已分化细胞释放的、抑制邻居向同一方向分化的物质也称抑素（chalone）。
:::

:::pitfall{label="同一分子在不同位置不是同一句话"}
sonic hedgehog 在翅芽后部写趾序，在脊索旁写底板和运动神经元。把旁分泌因子背成“一种配体对应一种细胞类型”，解释不了镜向趾重复，也解释不了为什么神经板只有一部分细胞成为神经元。位置信息包括两层：配体在哪里形成梯度，以及反应细胞当时带着哪一套受体和转录因子。Delta–Notch 的侧向抑制进一步说明：诱导之外还有“不许邻居跟我一样”。
:::

## 二、激素对细胞分化的调节

激素是远距离细胞间相互作用的分化调节因子。在个体细胞分化与发育过程中，除相邻细胞间可发生相互作用之外，不相邻的远距离细胞之间也可发生相互作用。与介导邻近细胞间相互作用的旁分泌因子不同，远距离细胞间的相互作用由经血液循环输送至各部位的激素来完成。激素所引起的反应是按预先决定的分化程序进行的，参与个体发育晚期、幼体发育与成熟、成熟期维持过程中的细胞分化调控。

激素可分为甾类激素和多肽类激素两大类。甾类激素如类固醇激素、雌激素和昆虫的蜕皮激素等为脂溶性，分子小，可穿过靶细胞的细胞膜进入细胞质，与细胞质内的特异受体结合形成受体–激素复合物，该复合物入核后作为转录调控复合物，直接结合到 DNA 调控位点上激活（或在一些情况下抑制）特异基因的转录。多肽类激素如促甲状腺素、肾上腺素、生长激素和胰岛素等为水溶性，分子量较大，不能穿过细胞膜，而是通过与质膜上的受体结合，并经过细胞内信号转导过程将信号传递到细胞核，调节核内基因的转录。如同许多其他的细胞内信号转导途径一样，这个过程包括蛋白激酶的顺序激活。第十二章把脂溶性配体写成直接入核、把水溶性配体写成膜受体和激酶级联；激素对分化的调节走的就是这两条路。

:::definition{label="变态"}
变态（metamorphosis）是动物从幼体变为在形态结构和生活方式上有很大差异的成熟个体的发育过程。昆虫的变态受蜕皮激素影响；两栖类有尾蝌蚪的变态与甲状腺激素（$\mathrm{T}_3$、$\mathrm{T}_4$）有关。激素不重新发明分化程序，而是按已经决定的程序，在发育晚期把整套变化一起打开。
:::

激素调节细胞分化与发育的典型例子是动物发育过程中的变态效应。蝇类和蛾类等昆虫的幼虫身体被一坚硬的角质层所覆盖，运动能力有限，它需要经过多次蜕皮才能成为在空中飞舞的成虫；在水中生活的两栖类生物有尾蝌蚪需经过变态发育才能形成可在陆地生活的无尾的蛙。

## 三、环境因素对细胞分化的影响

细胞分化的方向可因外部环境变化而改变。外部环境因素调节或影响动物细胞分化与发育方面的研究越来越受到重视。目前已了解到，物理、化学和生物性因素均可对细胞的分化与发育产生重要影响。

两栖类动物受精卵的背–腹轴确定除了取决于精子穿透进入卵的位点之外，还和重力影响相关。低等脊椎动物的性别决定与分化受环境因素的影响较大，环境信号可启动不同基因的表达，从而影响动物的性别。比如，孵化温度可以决定某些爬行动物（如鳄鱼）的性别：在其受精卵发育的一个特定时期，温度是性别分化的决定因子，在低温下孵化产生一种性别，在高温下孵化则产生另一种性别。而哺乳动物（包括人类）B 淋巴细胞的分化与发育则依赖于外来性抗原的刺激。

目前已发现许多环境因素可干扰人类的正常发育。例如，碘缺乏将引起甲状腺肿、精神发育和生长发育迟缓；在妊娠期感染风疹病毒易引起发育畸形，该病毒主要作用于胚胎的视觉器官和心脏，引起先天性白内障和心脏发育畸形。有关环境因素影响细胞分化与发育的机制也是目前生物医学研究的重要领域之一。该领域的深入研究，可望为环境有害物质引起的出生缺陷和发育畸形等提供新的干预靶点。第十四章把 SRY 写成哺乳动物性别的染色体开关；鳄鱼把同一件生死决定交给了孵化温度，说明“决定”并不总是写在基因组的某一基因上。

:::note{label="激素和环境都不改已经写下的程序，只决定何时何地执行"}
蜕皮激素和 $\mathrm{T}_3$/$\mathrm{T}_4$ 能把幼体整套改写成成体，是因为变态程序事先已经决定。碘缺乏、风疹病毒和鳄鱼的孵化温度，则是在执行窗口里插入或扭曲信号。把环境因素写成“可以任意把内胚层变成神经元”，会和第一节的细胞决定、本节的区域特异性打架。
:::

:::compare{title="旁分泌诱导 vs 激素调节"}
| 项目 | 旁分泌 / 近分泌诱导 | 激素调节 |
|------|----------------------|----------|
| 作用距离 | 邻近组织；近分泌还要求细胞膜并置 | 经血液到达远距离靶细胞 |
| 主要分子 | FGF、Hedgehog、Wnt、TGF-$\beta$；Delta–Notch | 甾类（蜕皮激素、雌激素等）；多肽类（胰岛素、生长激素等） |
| 信息形式 | 浓度梯度和位置；同一分子在不同部位效应不同 | 循环浓度；按预先决定的分化程序反应 |
| 典型时期 | 原肠胚以后的器官发生（如眼的三级诱导、翅芽趾序） | 发育晚期、幼体成熟和成体维持（如变态） |
| 入核方式 | 膜受体 → 信号转导 → 基因表达 | 甾类直接入核；多肽类走膜受体和激酶级联 |
| 负向作用 | 侧向抑制、抑素，避免器官重复 | 反馈调节循环激素水平，不负责局部“禁止邻居” |
:::

:::keypoint{label="细胞外因素把位置和时间写进核"}
- 原肠胚之后，胚层前途已定，但器官发生靠细胞群之间的诱导和抑制。
- 旁分泌因子以诱导源为中心形成梯度，提供位置信息；Delta–Notch 则要求细胞贴在一起。
- 眼是三级诱导的样板：脊索 → 神经板 → 视杯 → 晶状体 → 角膜。
- 激素走远距离，执行已经决定的程序，典型事件是昆虫蜕皮和蝌蚪变态。
- 温度、碘、病毒可以改写或干扰分化窗口，是出生缺陷的细胞外入口。
:::
