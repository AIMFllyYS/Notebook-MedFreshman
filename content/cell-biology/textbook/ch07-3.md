# 第三节 中间纤维

中间纤维（intermediate filament，IF）广泛存在于真核细胞中，最早在平滑肌细胞内被发现。它是三类细胞骨架纤维中结构最为复杂的一种。细胞在受到浓盐溶液与非离子性去污剂处理后，胞内大部分细胞骨架消失，中间纤维却能保留下来——这说明在三类纤维中，中间纤维最为坚韧。

:::definition{label="中间纤维"}
中间纤维（intermediate filament，IF）是直径约 $10\,\mathrm{nm}$ 的坚韧蛋白质纤维，其名来自直径介于微管（约 $25\,\mathrm{nm}$）与微丝（$5\sim 8\,\mathrm{nm}$）之间。亚基为纤维状蛋白，装配成非极性的多级螺旋；对细胞松弛素和秋水仙碱均不敏感。
:::

## 一、中间纤维的结构和类型

### （一）中间纤维是纤维状蛋白多聚体

中间纤维直径为 $10\,\mathrm{nm}$，是一种坚韧、耐久的蛋白质纤维，相对较为稳定，既不受细胞松弛素影响，也不受秋水仙碱影响。

中间纤维的单体（亚基）是蛋白质纤维分子，有 50 多种，都有共同的结构特点：由头部（N 端）、中间的杆状区和尾部（C 端）组成。杆状区为 $\alpha$ 螺旋区，内含 4 段高度保守的 $\alpha$ 螺旋，其间被 3 个短小间隔区隔开；亚基装配时靠 $\alpha$ 螺旋配对形成二聚体。位于杆状区两侧的 N 端头部和 C 端尾部通常折叠成球状结构（图 7-14）。

::figure{src="/images/cell-biology/textbook/p0180_02.png" caption="图7-14 中间纤维的结构模型" alt="中间纤维亚基：球状头部、含 4 段保守 α 螺旋的杆状区、可变的球状尾部"}

虽然 $\alpha$ 螺旋区高度保守，但 N 端头部和 C 端尾部都高度可变，不同类型中间纤维亚基的头部和尾部氨基酸组成差别很大。中间纤维分子量的大小主要取决于尾部；结构变化的关键则在杆状区，它们表现出形成多级螺旋所需的分子结构。

:::concept{term="中间纤维亚基的三区结构"}
所有中间纤维蛋白都是“头—杆—尾”：杆负责互相拧成卷曲螺旋，几乎不变；头和尾负责与其他细胞成分对话，因而高度可变。分子量差在尾巴上，装配逻辑在杆上。不要把 50 多种亚基当成 50 套互不相干的折叠方式。
:::

### （二）中间纤维蛋白的类型和分布较为复杂

根据氨基酸序列特征，可将中间纤维分为六种类型（表 7-2）。

角蛋白（keratin）存在于上皮细胞内，分成两种主要类型：Ⅰ型（酸性）和 Ⅱ型（中性/碱性）角蛋白。Ⅲ型包括多种：波形蛋白存在于间充质来源的细胞；结蛋白是肌细胞特有的，在骨骼肌、心肌和平滑肌中表达；外周蛋白存在于中枢神经系统神经元和外周神经系统感觉神经元中；胶质细胞原纤维酸性蛋白特异分布于神经胶质细胞。Ⅳ型神经丝蛋白主要分布在神经元轴突中。Ⅴ型核纤层蛋白存在于内核膜下的核纤层。Ⅵ型神经上皮干细胞蛋白分布于神经干细胞。

| 类型 | 举例 | 分子量 / kDa | 细胞内分布 |
|------|------|--------------|------------|
| Ⅰ | 酸性角蛋白（acidic keratin） | $40\sim 60$ | 上皮细胞 |
| Ⅱ | 中性/碱性角蛋白（neutral or basic keratin） | $50\sim 70$ | 上皮细胞 |
| Ⅲ | 波形蛋白（vimentin） | 54 | 成纤维细胞、白细胞及其他间充质来源细胞 |
|  | 结蛋白（desmin） | 53 | 肌细胞 |
|  | 外周蛋白（peripherin） | 57 | 神经元 |
|  | 胶质细胞原纤维酸性蛋白（GFAP） | 51 | 神经胶质细胞 |
| Ⅳ | 神经丝蛋白 NF-L | 67 | 神经元 |
|  | 神经丝蛋白 NF-M | 150 | 神经元 |
|  | 神经丝蛋白 NF-H | 200 | 神经元 |
| Ⅴ | 核纤层蛋白 A | 70 | 各种类型细胞的核纤层 |
|  | 核纤层蛋白 B | 67 | 各种类型细胞的核纤层 |
|  | 核纤层蛋白 C | 60 | 各种类型细胞的核纤层 |
| Ⅵ | 神经上皮干细胞蛋白（nestin） | 200 | 神经干细胞 |

:::definition{label="中间纤维的六型分类"}
脊椎动物中间纤维按序列分为六型：Ⅰ/Ⅱ型角蛋白（上皮）、Ⅲ型（波形蛋白、结蛋白、外周蛋白、GFAP）、Ⅳ型神经丝、Ⅴ型核纤层蛋白、Ⅵ型 nestin。类型与组织来源严格对应，这是肿瘤病理用中间纤维做“出身鉴定”的根据。
:::

:::note{label="上皮角蛋白必须 I 型配 II 型"}
酸性（Ⅰ型）与中性/碱性（Ⅱ型）角蛋白形成异源二聚体，才能装成上皮中间纤维。只表达其中一型，网络搭不起来。这也解释了为什么单纯型大疱性表皮松解症只要突变一对搭配中的一个基因，整张表皮就会变脆。
:::

## 二、中间纤维的装配和调节

与肌动蛋白和微管蛋白单体的球状结构不同，中间纤维蛋白单体大多数是长丝状，称纤维状蛋白（fibrous protein），由氨基末端的头部、中间杆状区和羧基末端的尾部组成。中间杆状区由展开的 $\alpha$ 螺旋组成，螺旋中含有纵排的重复组件，称为七位复件（heptad repeat），是一段有特色的氨基酸序列。七位复件能促进两个平行单体的 $\alpha$ 螺旋形成卷曲螺旋（coiled-coil）二聚体。

二聚体组装完成后，两个超螺旋二聚体以反向平行方式相连，形成四聚体（tetramer）亚单位。二聚体的反向平行排列说明：四聚体以及由其形成的更高级中间纤维都是非极性结构——纤维两端相同，沿长轴具有对称性。这一特点使中间纤维明显区别于有极性的微管和微丝。

中间纤维组装的最后步骤仍不甚清楚，可能是由四聚体以简单结合反应加到伸长中的纤维上；结合沿长轴排列，按螺旋形式包裹在一起。各种中间纤维蛋白分子的中间杆状区结构高度保守，在组装过程中调节纤维之间的横向相互作用；头部与尾部的大小和氨基酸序列差别较大，但不影响纤维的主轴结构。头部或尾部往往突出于纤维表面，调节中间纤维与其他成分之间的相互作用（图 7-15）。

::figure{src="/images/cell-biology/textbook/p0182_01.png" caption="图7-15 中间纤维的装配模型。A. 中间纤维蛋白单体；B. 超螺旋二聚体；C. 两个超螺旋二聚体交错形成四聚体；D. 两个或多个四聚体组装在一起；E. 八个四聚体装配形成中间纤维；F. 电镜下的中间纤维结构。" alt="单体→平行卷曲螺旋二聚体→反向平行四聚体→原纤维→约八个四聚体围成非极性中间纤维"}

:::derivation{label="中间纤维如何装成非极性电缆"}
1. 两个单体平行排列，杆状区 $\alpha$ 螺旋按七位复件拧成卷曲螺旋二聚体，此时二聚体仍有方向。
2. 两个二聚体反向平行、交错并列，形成四聚体：两端在统计上等价，极性被抵消。
3. 四聚体作为可溶性装配亚单位，沿长轴结合并按螺旋包裹，约八个四聚体构成一根直径约 $10\,\mathrm{nm}$ 的纤维。
4. 头、尾突出于表面，不参与主轴，但决定与桥粒、核膜或其他骨架纤维的连接。
5. 因为没有正负端，中间纤维不能作为马达蛋白的单向轨道，它的本职是抗拉，而不是运输。
:::

:::pitfall{label="中间纤维不是“较粗的微丝”"}
直径介于微管和微丝之间，并不意味着装配逻辑也介于二者之间。微管和微丝都是球状亚基、有极性、靠 NTP 水解驱动动态；中间纤维是纤维状亚基、非极性、装配不依赖 NTP 水解。用“三种管子粗细不同”来记，会把最关键的极性差异丢掉。
:::

中间纤维装配的调控与其蛋白氨基末端头部结构域内特殊氨基酸（如丝氨酸残基）的磷酸化相关。目前认为，丝氨酸和苏氨酸残基的磷酸化是调节中间纤维动态最常见且有效的方式。最明显的例子是有丝分裂时：形成核纤层的蛋白亚单位发生磷酸化，核纤层完全解体；分裂完成时，特定丝氨酸残基去磷酸化，核纤层再形成。

:::concept{term="磷酸化拆掉核纤层"}
核纤层蛋白被 CDK1 等激酶在头部丝氨酸上磷酸化后，纤维解体，核膜得以在前期拆开；末期磷酸酶把这些位点去掉，核纤层重新组装到子代核膜下。中间纤维“稳定”是相对间期而言的——到了分裂期，它一样可以被迅速拆掉。
:::

## 三、中间纤维的功能

中间纤维在胞质中形成纤维网络，向外与细胞膜及细胞外基质相连，在胞质中与微管、微丝和细胞器相连，向内与细胞核内的核纤层相连，因此具有多种功能。

### （一）中间纤维在细胞内形成一个完整的网状骨架系统

中间纤维向外与质膜和细胞外基质有直接联系，向内与核膜、核基质联系，贯穿整个细胞，起广泛的骨架作用，并具有一定可塑性，对维持细胞质的整体结构和功能有重要作用，也与细胞核的定位和固定有关。

### （二）中间纤维为细胞提供机械强度支持

中间纤维在那些容易受到机械应力的细胞中特别丰富。体外实验证实，中间纤维比微管和微丝更耐受剪切力，在受到较大剪切力时不易断裂，在维持细胞机械强度方面有重要作用（图 7-16）。皮肤、肌肉和神经元轴突之所以能经受牵拉，很大程度上靠的是这一套抗拉网络。

::figure{src="/images/cell-biology/textbook/p0182_02.png" caption="图7-16 中间纤维增强细胞的强度" alt="有中间纤维网络的细胞在剪切力下保持完整，缺乏中间纤维时细胞更易破裂"}

### （三）中间纤维参与细胞连接

一些器官和皮肤的上皮细胞通过桥粒和半桥粒连接在一起：桥粒介导细胞与细胞之间的黏附，半桥粒介导细胞与细胞外基质之间的黏附。中间纤维与桥粒和半桥粒的结构连接在一起，加之中间纤维还在细胞中形成网络，这样既能维持细胞形态，又能把机械力分散到整个组织，而不是压在单个细胞上。

:::concept{term="桥粒把中间纤维织成组织级缆绳"}
一根上皮细胞里的角蛋白网络若只连自己的质膜，抗拉能力止于一个细胞。桥粒把相邻细胞的角蛋白接到同一块斑上，半桥粒再把这张网锚到基底膜，于是机械负荷被分摊到整片上皮。角蛋白一突变，这张组织级缆绳就在表皮底层断开，轻微摩擦即可起疱。
:::

### （四）中间纤维参与细胞内信息传递及物质运输

由于中间纤维向外连接质膜和胞外基质、向内连接核骨架，因此形成一个跨膜的信息通道。中间纤维蛋白在体外与单链 DNA 有高度亲和性；中间纤维有明显的核周聚集特点，可能与 DNA 的复制和转录有关。此外，近年来研究发现中间纤维参与 mRNA 的运输，可能与 mRNA 在细胞内的定位及是否翻译有关。需要强调的是：中间纤维本身没有极性，不能像微管那样作为驱动蛋白或动力蛋白的单向轨道；它更多地提供停靠和定位的支架。

### （五）中间纤维维持细胞核膜稳定

在细胞核的内核膜下面有一层由核纤层蛋白组成的网络，对于细胞核形态的维持具有重要作用，而核纤层蛋白是中间纤维的一种。组成这种网络的核纤层蛋白 A 和 C 交联在一起，然后通过核纤层蛋白 B 附着到内核膜上；内核膜上有核纤层蛋白 B 的受体。

:::definition{label="核纤层"}
核纤层（nuclear lamina）是紧贴内核膜的 Ⅴ 型中间纤维网络，主要由核纤层蛋白 A、B、C 组成。A、C 交联成网，B 通过膜受体锚到内膜。它支撑核形态，并在有丝分裂时随磷酸化可逆地解体和重建。
:::

### （六）中间纤维参与细胞分化

微丝和微管的表达在各种细胞中都是相同的，而中间纤维蛋白的表达则具有组织特异性，说明中间纤维可能与细胞分化密切相关，但其详细机制有待研究。正是这一组织特异性，使中间纤维成为判断肿瘤细胞来源的免疫组化标志，详见第五节。

:::compare{title="微管 vs 微丝 vs 中间纤维"}
| 项目 | 微管 | 微丝 | 中间纤维 |
|------|------|------|----------|
| 直径 | $24\sim 26\,\mathrm{nm}$，中空 | $5\sim 8\,\mathrm{nm}$ | 约 $10\,\mathrm{nm}$ |
| 亚基 | 球状 $\alpha/\beta$ 微管蛋白 | 球状 G 肌动蛋白 | 纤维状蛋白（头—杆—尾），50 余种 |
| 极性 | 有（正端快、负端慢） | 有（秃端快、指向端慢） | 无（反向平行四聚体抵消极性） |
| 核苷酸 | GTP 帽，动态不稳定 | ATP，踏车为主 | 不依赖 NTP 水解 |
| 成核位置 | MTOC（$\gamma$-TuRC） | 主要在质膜（皮层） | 胞质中逐步组装；核纤层在核膜下 |
| 马达蛋白 | 驱动蛋白、动力蛋白 | 肌球蛋白 | 一般不作为单向轨道 |
| 药物 | 秋水仙碱、长春新碱、紫杉醇 | 细胞松弛素、鬼笔环肽 | 对上述药物均不敏感 |
| 典型特化 | 纺锤体、纤毛/鞭毛、轴突轨道 | 皮层、伪足、微绒毛、收缩环、肌节 | 桥粒/半桥粒、核纤层、角蛋白网络 |
| 主要力学 | 抗压、抗弯，作轨道 | 产生张力与运动 | 抗剪切、抗牵拉 |
| 组织特异性 | 各类细胞基本相同 | 各类细胞基本相同 | 六型蛋白严格按组织表达 |
:::

:::insight{label="三种纤维是分工，不是备份"}
微管负责“往哪里送、染色体怎么分”，微丝负责“往哪里爬、细胞怎么勒成两个”，中间纤维负责“拉不断、核不塌”。药物可以单独拆掉其中一套，细胞立刻露出对应的缺陷：没有微管则高尔基复合体散掉，没有微丝则无法胞质分裂，没有中间纤维则皮肤一碰就破。
:::

:::keypoint{label="中间纤维在细胞骨架中的位置"}
- 直径居中，但装配逻辑完全不同：纤维状亚基、非极性、抗拉。
- 六型蛋白按组织表达，是分化标志，也是病理诊断的身份证。
- 向外连桥粒/半桥粒，向内连核纤层，把细胞质和细胞核织进同一张网。
- 磷酸化是拆装开关，核纤层在有丝分裂中的解体与重建是最清楚的例子。
:::

:::memory{label="本节必背要点"}
- [ ] 中间纤维直径约 $10\,\mathrm{nm}$，三类骨架中最坚韧；浓盐和非离子去污剂处理后仍保留。
- [ ] 亚基为纤维状蛋白：N 端头部 + 保守 $\alpha$ 螺旋杆状区（4 段螺旋、3 个间隔）+ C 端尾部。
- [ ] 分子量主要取决于尾部；装配靠杆状区的卷曲螺旋。
- [ ] 六型：Ⅰ/Ⅱ角蛋白（上皮），Ⅲ波形蛋白/结蛋白/外周蛋白/GFAP，Ⅳ神经丝，Ⅴ核纤层蛋白，Ⅵ nestin。
- [ ] 装配：平行二聚体 → 反向平行四聚体 → 原纤维 → 约八个四聚体成纤维；纤维非极性。
- [ ] 七位复件（heptad repeat）促进卷曲螺旋形成。
- [ ] 磷酸化（Ser/Thr）调控动态；核纤层蛋白有丝分裂期磷酸化解体、末期去磷酸化重建。
- [ ] 功能：贯穿细胞的网状骨架、抗剪切机械支持、桥粒/半桥粒连接、信息与 mRNA 定位、维持核膜、参与分化。
- [ ] 核纤层：A、C 交联，B 经受体贴在内核膜上。
- [ ] 对细胞松弛素和秋水仙碱均不敏感；不作为驱动蛋白/动力蛋白的单向轨道。
- [ ] 与微管、微丝的关键差别：极性、核苷酸、成核位置、组织特异性和力学分工。
:::
