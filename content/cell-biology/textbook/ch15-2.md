# 第二节 细胞分化的分子基础

第一节把分化写成潜能缩窄、决定先于形态、以及有条件的可塑性。这些细胞命运最终都要落到基因组上：同一套 DNA 为什么在红细胞里写出血红蛋白、在表皮里写出角蛋白、在肌细胞里写出肌动蛋白和肌球蛋白？本节把答案写成基因的选择性表达——普遍规律是基因组不丢，变的是谁被打开；卵里的母体因子和不对称分裂给出最初的许可，转录因子、LCR、Hox 和表观遗传把许可维持下去，可变剪接和非编码 RNA 再在转录后微调。第九章已经把转录和表观遗传的分子零件摆出来；这里它们被征用为分化的时间表。

:::definition{label="差异基因表达"}
差异基因表达（differential gene expression）是细胞内基因组并不全部表达，而是按照一定的时空顺序选择性地表达特定基因，使不同细胞以及同一细胞的不同发育阶段出现不同的基因表达谱。细胞分化的实质是特化：分化细胞表达具有功能与结构特征的特异性蛋白。
:::

:::definition{label="管家基因"}
管家基因（housekeeping gene）编码维持细胞存活和生长所必需的蛋白质，如细胞骨架蛋白、染色质的组蛋白、核糖体蛋白以及参与能量代谢的糖酵解酶类。分化细胞的基因表达产物不只是特异性蛋白，也包括这套管家蛋白。
:::

## 一、基因组的活动模式

### （一）基因的选择性表达是细胞分化的普遍规律

细胞分化的实质是细胞的特化。认识分化机制的过程中，曾根据少数分化细胞的染色体丢失现象，认为分化的本质是遗传信息的丢失或突变。后来大量实验证明，细胞分化过程中一般不伴有基因组的改变。把动物体细胞的核移植到去核的卵细胞或受精卵的细胞质中，能够形成生命个体，证明分化细胞核含有完整的基因组。转分化和细胞融合实验也表明，分化过程中一般不发生基因组的改变。第一节的全能性细胞核，说的就是这件事。

Gurdon 在 $20$ 世纪 $60$ 年代初期用非洲爪蟾把这句话写成实验。他从一种突变型蝌蚪（核中只有 $1$ 个核仁）的肠上皮细胞取出细胞核，移植到事先用紫外线照射、破坏了细胞核的野生型未受精卵中（野生型卵核本有 $2$ 个核仁）。含肠上皮核的重组卵有的能发育成囊胚，其中少数可发育成蝌蚪和成体爪蟾，成体爪蟾的细胞核均含 $1$ 个核仁（见图 15-3）。结果表明：已分化的肠上皮核中仍然保持着能分化出成体爪蟾各种组织细胞的全部基因。

:::note{label="Gurdon 克隆的是核的许可，不是把肠上皮直接变成蛙"}
1938 年 Spemann 在《胚胎发育和诱导》中提出：把已分化的核导入去核卵，看它还能不能发育。1952—1962 年 Briggs、King 和 Gurdon 把方案做成实验，Gurdon 成功克隆出成体爪蟾。后续路线直接通向 1997 年 Wilmut 的“多莉”羊，以及克隆牛、克隆狗和克隆猴。Gurdon 最初想问的是分化是否伴随基因组不可逆改变，却意外地给出了动物克隆的技术路线，也催生了细胞重编程；他与 Yamanaka 因此共同获得 2012 年诺贝尔生理学或医学奖。把核移植听成“肠上皮细胞自己长成了蛙”，会漏掉卵细胞质这个重编程环境。
:::

多细胞生命个体内，细胞内基因组的基因并不全部表达，而是选择性地按照一定的时空顺序表达特定基因。红细胞中的血红蛋白、皮肤表皮细胞中的角蛋白、肌细胞中的肌动蛋白和肌球蛋白，都是特异性蛋白。一个分化细胞当然也表达管家基因。简单对照就能证明分化的本质：鸡的输卵管细胞合成卵清蛋白，胰岛 $\beta$ 细胞合成胰岛素，成红细胞合成 $\beta$-珠蛋白；对比分析基因组 DNA 序列及细胞表达的 mRNA，就能确定不同分化细胞内不同的基因表达表型。

### （二）基因组改变是细胞分化的特例

细胞在分化过程中可表现出基因组扩增或基因组丢失。如果蝇卵巢滤泡细胞在分化过程中呈现特定基因的选择性扩增；果蝇卵巢滋养细胞、唾液腺细胞和马氏管细胞发育过程中，染色体 DNA 多次复制，形成多倍体（polyploid）和多线体（polyteny）染色体。与此相反，一些细胞则发生遗传物质丢失。典型例子是马蛔虫（*Ascaris equorum*）：个体发育中生殖细胞获得完整染色体，体细胞仅含染色体部分片段，其余片段在发育过程中丢失。摇蚊发育中，许多体细胞仅含 $2$ 条染色体，丢失了 $38$ 条；哺乳动物（除骆驼外）的红细胞以及皮肤、羽毛和毛发的角化细胞则失去所有核内基因组。人类和其他脊椎动物的 T 淋巴细胞中，编码抗原受体的基因发生重排，丢失无关 DNA 片段，形成能够特异性识别各类抗原的受体基因；B 淋巴细胞同样通过基因重排丢掉无关片段，形成针对各类特异抗原的抗体基因。基于这类事例，曾有过基因扩增、DNA 重排和染色体丢失等假说。它们是细胞分化的特例，不是普遍规律。

:::pitfall{label="淋巴细胞重排和红细胞去核，不能反过来说分化等于丢基因"}
T、B 细胞受体/抗体基因重排、马蛔虫体细胞丢染色体、哺乳动物红细胞去核，都是真实事件。它们不能推翻 Gurdon：绝大多数体细胞的核仍带着完整基因组，否则核移植和 iPS 都不会成功。看见“基因组改变”，先问是不是特例；普遍规律仍是同一套基因组的选择性表达。
:::

## 二、胞质中的细胞分化决定因子与传递方式

### （一）母体效应基因产物的极性分布决定细胞分化与发育的初始命运

成熟卵细胞中储存 $20\,000\sim 50\,000$ 种 RNA，其中大部分为 mRNA，受精后翻译为蛋白质发挥功能。卵细胞中部分 mRNA 在细胞质中分布不均：爪蟾未受精卵中，有些 mRNA 特异分布于动物极，有些分布于植物极，其编码蛋白在细胞初始发育命运决定中起重要调控作用。通常将这类在卵细胞胞质中呈极性分布、受精后被翻译为胚胎发育中起重要作用的转录因子和调节蛋白的 mRNA 分子称为母体因子。编码母体因子的基因为母体效应基因（maternal effect gene），也称母体基因（maternal gene）：这些基因在卵子发生过程中表达，表达产物（母体因子）存留于卵子中，受精后调控胚胎发育。第十四章已经把卵内极性分布的形态发生因子写成储备；这里它们有了基因的名字。

:::definition{label="母体效应基因"}
母体效应基因（maternal effect gene）在卵子发生过程中表达，其产物（母体因子）存留于卵内并呈极性分布，受精后翻译为转录因子和调节蛋白，决定胚胎发育的初始命运。果蝇用它们预先决定相互垂直的前–后轴和背–腹轴。
:::

果蝇与一般脊椎动物有所不同，其母体效应基因预先决定了胚胎未来相互垂直的前–后轴和背–腹轴。例如 *bicoid* mRNA 在未受精时定位于卵母细胞将来发育为胚胎前端的位置。受精后 *bicoid* mRNA 翻译为含有一个螺旋–转角–螺旋结构域（helix-turn-helix domain）的 BICOID 蛋白，通过有限扩散建立蛋白梯度：BICOID 沿胚胎前–后轴呈浓度梯度分布，越靠近前端浓度越高（图 15-6）。果蝇早期胚胎为多个细胞核共存于一个细胞质中的合胞体，BICOID 蛋白与位于前部区域的胚胎细胞核染色质 DNA 结合：高浓度启动调控头部发育的特异性基因，低浓度则调控胸部形成的特异性基因。

### （二）胚胎细胞分裂时细胞质不均等分配调控细胞命运与分化

在胚胎早期发育过程中，细胞质成分是不均质的，胞质中某些成分的分布有区域性。细胞分裂时，细胞质成分被不均等地分配到子细胞中；这种不均一性胞质成分能够调控细胞核基因的表达，以决定细胞的早期分化路径。

果蝇感觉器官发育中，一个细胞命运的决定蛋白是 *numb* 基因编码的转录因子。该转录因子在感觉性母细胞的胞质中呈不对称分布，细胞第一次分裂时只有一个子代细胞含 numb 蛋白。含 numb 蛋白的子代在第二次分裂时形成神经元及鞘层细胞，而无 numb 蛋白的子代则分化为支持细胞（图 15-7）。第一节把不对称分裂写成决定的原因之一；这里 numb 是一个可以画出来的分配方案。

:::definition{label="不对称分裂"}
不对称分裂是指具有分化调控作用的蛋白因子（包括其 mRNA）在细胞质中分布不均等，分裂时被不均匀地分配到两个子细胞中，使两个子细胞获得不同命运。*numb* 蛋白在果蝇感觉性母细胞中的单侧分配是典型例子。
:::

## 三、细胞分化过程中基因选择性表达的转录调控

在多细胞生命个体发育过程中，细胞内基因表达具有严格的时间和空间（或组织）特异性。某个基因在一类细胞中被激活而在另一类细胞中被抑制。细胞分化的基因表达调控主要发生在基因转录过程。调节基因转录的因素很多（详见第九章），这里写分化过程中转录调控的特点。

### （一）细胞内基因的时序性表达

细胞内基因如严格按照时间顺序表达，即为基因表达的时间特异性（temporal specificity）。从受精卵到组织、器官形成的各个发育阶段，都有不同的基因严格按照自己特定的时间顺序开启或关闭，表现为与分化、发育阶段一致的时序性基因表达，也称为阶段特异性（stage specificity）基因表达。

血红蛋白的表达是红细胞分化的特征之一，红细胞内血红蛋白基因在发育不同阶段的表达，是经典的时序性表达。脊椎动物的血红蛋白由 $2$ 条 $\alpha$-珠蛋白链和 $2$ 条 $\beta$-珠蛋白链组成。$\alpha$-珠蛋白和 $\beta$-珠蛋白基因分别定位于不同染色体，它们都由一个基因簇（基因家族）构成。在哺乳动物，每个家族的不同成员在发育的各个时期表达，在胚胎、胎儿和成体中分别编码形成不同的血红蛋白。人 $\beta$-珠蛋白基因簇包括五个基因——$\varepsilon$、$^{\mathrm{G}}\gamma$、$^{\mathrm{A}}\gamma$、$\delta$ 和 $\beta$：$\varepsilon$ 在早期胚胎的卵黄囊中表达；$^{\mathrm{G}}\gamma$ 和 $^{\mathrm{A}}\gamma$ 在胎儿肝脏中表达；$\delta$ 和 $\beta$ 基因在成人骨髓红细胞前体细胞中表达。所有这些基因的蛋白质产物都与 $\alpha$-珠蛋白结合，在早期胚胎、胎儿与成年期分别形成具有不同生理特性的血红蛋白（图 15-8）。

:::definition{label="基因座控制区"}
基因座控制区（locus control region，LCR）是远离基因簇上游、能指导整个基因簇按时间顺序高水平表达的调控区。人 $\beta$-珠蛋白基因簇的 LCR 距离 $\varepsilon$ 基因 $5'$ 末端约 $10\,000\,\mathrm{bp}$ 以上；即使 $\beta$ 基因本身距离它约 $50\,000\,\mathrm{bp}$，LCR 也能指导转基因小鼠中整个 $\beta$-珠蛋白基因簇的顺序表达。
:::

在个体发育过程中依次有不同的 $\beta$-珠蛋白基因打开和关闭，这与 $\beta$-珠蛋白基因簇上游的 LCR 有关（图 15-8）。$\beta$-珠蛋白基因簇中每个基因的有效表达，除受到每个基因 $5'$ 端上游的启动子和调控位点及基因下游（$3'$ 端）的增强子控制之外，还将受到远离基因簇上游的 LCR 的严格制约。LCR 可使任何与它相连的 $\beta$ 家族基因呈高水平表达。目前已经明确许多基因的表达受到 LCR 调控。

### （二）细胞内基因的器官组织特异性表达

在个体发育过程中，同一基因产物在不同组织器官中是否表达及表达量多少有明确差异。一种基因在个体的不同组织或器官细胞中表达，即在个体的不同空间出现，这就是基因表达的空间特异性（spatial specificity）。不同器官组织细胞中不仅表达的基因数量不相同，而且基因表达的强度和种类也各不相同，这就是基因表达的组织特异性。

细胞中基因的转录要求转录因子结合于基因的调控区（control region，启动子区和其他能调节基因表达的 DNA 位点）。与基因表达调控区相结合的转录因子可分为通用性转录因子和组织细胞特异性转录因子：前者为大量基因转录所需，并在许多类型的细胞中都存在；后者则为特定基因或一系列组织特异性基因表达所需，并在一个或很少的几种类型细胞中存在。

:::definition{label="组织细胞特异性转录因子"}
组织细胞特异性转录因子是只在一个或很少几种类型细胞中存在、为特定基因或一系列组织特异性基因表达所需的转录因子。细胞特异性基因表达是这类因子与基因调控区相互作用的结果。胰岛中的 Isl-I、骨骼肌中的 MyoD I 是典型例子。
:::

通过替换组织特异性（表达）基因调控区的实验可证明组织特异性转录因子的存在。弹性蛋白酶仅在小鼠胰腺中表达，而生长激素只在脑垂体中形成。将人生长激素基因的蛋白编码区连接于小鼠弹性蛋白酶基因的调控区之后，把此重组 DNA 注射到小鼠受精卵中使其整合到基因组，由此发育而来的转基因小鼠胰腺组织中可检测到人生长激素。表明胰腺组织中的特异转录因子通过作用于弹性蛋白酶基因调控区，使胰腺细胞表达人生长激素。

迄今已鉴定出一系列组织特异性转录因子。一个转录因子是否影响特定基因的活动取决于许多因素：除基因的调控区是否含有该转录因子的结合位点外，转录因子的转录活性还受到转录因子调节蛋白的严格制约。在调控区上不同转录调节因子（转录因子和转录因子调节蛋白）的相互作用，决定了特定基因是否被激活。被激活的分化基因通常有复杂的调控区。

### （三）细胞分化过程中基因表达调控的复杂性

动物受精卵第一次卵裂后的卵裂球，在个体发育中通过细胞分裂分化形成各类祖细胞及其子代细胞。祖细胞与其分化的子代细胞先后连续的宗系关系被称为细胞谱系（cell lineage）。在特定谱系细胞形成过程中，转录因子（或转录调节蛋白）普遍的作用方式是：①一个转录因子能同时调控几个基因的表达，表现为同时发生的特定基因的激活和特定基因的关闭；②组合调控（combinatory control），即特异基因的转录受多种调节蛋白组合调控，而非受单个调节蛋白调控。

:::definition{label="细胞谱系"}
细胞谱系（cell lineage）是祖细胞与其分化的子代细胞先后连续的宗系关系。谱系分化依赖转录因子的两种普遍方式：一个因子同时开关若干基因，以及多种调节蛋白的组合调控。
:::

**1. 一个关键基因的转录调节蛋白能够启动特定谱系细胞的分化。** 在生命个体发育过程中，一个关键基因的转录调节蛋白能够引发一系列相关基因的表达。这种调控方式表现为一些特定基因的永久性关闭和一些特定基因的持续性激活。这类调控因子一旦发挥作用，就维持在活化状态，能充分诱导细胞沿着某一途径分化，从而导致特定谱系细胞的发育。这说明只需要调控某一特定发育途径的关键基因启动表达，就能够激活一系列细胞分化的相关基因。能够调控分化起始的基因通常称为细胞分化主导（主控）基因（master control gene）。

:::definition{label="细胞分化主导基因"}
细胞分化主导基因（master control gene）是能够调控分化起始的关键基因。其产物一旦表达并维持活化，即可引发一系列相关基因的开与关，把细胞锁进特定谱系。*myoD* 是肌细胞分化的主导基因；果蝇的 *Ey*（脊椎动物为 *Pax-6*）能触发整个眼器官的形成。
:::

例如 *myoD* 在肌前体细胞和肌细胞中表达。在哺乳动物的肌干细胞向肌细胞分化过程中，*myoD* 的表达引起一系列级联反应，包括 *MRF4*、*myogenin* 基因的顺序活化，启动肌细胞分化（图 15-9）。*myoD*、*MRF4* 和 *myogenin* 都编码一个含有碱性螺旋–环–螺旋（bHLH）DNA 结合域的转录因子。一般将 *myoD* 基因视为肌细胞分化的主导基因：*myoD* 能够诱导成纤维细胞以及其他一些类型的细胞转分化为肌细胞。外部信号（旁分泌因子 Wnt、Shh）通过 *myoD* 和 *myf-5* 启动肌细胞分化，这两个基因中哪一个优先表达取决于物种；它们的基因活化形成交互抑制并维持自身状态，其编码蛋白进一步激活 *MRF4* 和 *myogenin*，最终导致肌细胞特异性蛋白表达。第三节会把 Wnt、Shh 写成细胞外的位置信息；这里它们已经接到了核内的主控基因。

::figure{src="/images/cell-biology/textbook/p0341_01.png" caption="图15-9 脊椎动物骨骼肌细胞分化机制。神经管和脊索来源的旁分泌因子 Wnt、Shh 经 myoD 或 myf-5 决定肌原细胞命运；随后细胞扩增、停止扩增并依次激活 MRF4 和 myogenin，细胞融合形成肌管，最终形成有收缩功能的肌纤维。" alt="Wnt和Shh经myoD或myf-5启动肌原细胞，经MRF4和myogenin形成肌纤维"}

单个基因调节蛋白不仅在特定谱系细胞的分化过程中起重要作用，而且还能触发整个器官的形成。在眼发育过程中，有一个基因调节蛋白（在果蝇中称为 Ey，在脊椎动物中称为 Pax-6）很关键：如果在适当的条件下表达，Ey 能触发形成的不只是一种类型的细胞，而是由不同类型细胞组成的、在三维空间中正确组织起来的整个器官——眼。

**2. 基因转录调节因子组合调控多种类型细胞分化。** 基因转录组合调控是指许多转录调节因子共同作用，调节特定基因的最终转录及转录速率。在细胞内基因转录调控中，多个转录调控因子可共同调控单个基因，单个转录调控因子也可参与调控多个基因的转录。在细胞分化过程中，单个基因转录调控因子（如 MyoD）可以调控细胞特异性分化，但在大多数情况下，特定的基因转录调控因子存在于多种类型的细胞中，在体内多个部位和多种类型细胞分化过程中与其他转录调控因子共同发挥基因转录调控作用。图 15-10 显示了组合调控能够以相对较少的转录调节蛋白调控多种类型细胞的分化。

::figure{src="/images/cell-biology/textbook/p0342_01.png" caption="图15-10 发育过程中一些基因调节蛋白的组合有助于产生许多细胞类型。每一次分裂后作出一个决定，合成一对不同基因调节蛋白中的一个；朝向胚胎左侧的子细胞常诱导偶数蛋白，朝向右侧的诱导奇数蛋白。蛋白一旦合成即自我持续，通过细胞记忆逐步建立组合指令。图中用 5 种调节蛋白最终形成 8 种细胞类型（G～N）。" alt="五种基因调节蛋白经三次分裂的组合产生八种细胞类型"}

**3. 同源异形框基因的时空表达确定了机体前–后轴结构的分化与发育蓝图。** 果蝇触角足复合体（Antennapedia complex，Antp）基因形成的 mRNA 经逆转录合成的 cDNA 探针，不仅与 *Antp* 基因编码区杂交，也与同一染色体上相邻的 *ftz*（*fushi tarazu*）基因杂交，提示在 *Antp* 和 *ftz* 基因中都含有一个共同的 DNA 片段。利用该片段为探针，相继发现在果蝇的许多同源异形基因（homeotic gene）中都含有该 DNA 片段。序列分析显示这个共同片段为 $180\,\mathrm{bp}$，具有相同的开放读码框架，编码高度同源的由 $60$ 个氨基酸组成的结构单元。酵母、小鼠、人等生命体的若干基因含有该片段。该 $180\,\mathrm{bp}$ DNA 片段被称为同源异形框（homeobox），含有同源异形框的基因为同源异形框基因（homeobox gene）。迄今已发现同源异形框基因 $300$ 多种，从酵母到人类的各种真核生物均有该类基因，如果蝇的 *HOM* 基因，动物和人类的 *Hox* 基因。

:::definition{label="同源异形框基因"}
同源异形框基因（homeobox gene）含有一段高度保守的 $180\,\mathrm{bp}$ 同源异形框（homeobox），编码 $60$ 个氨基酸的同源异形结构域（homeodomain）。同源异形结构域蛋白作为转录因子，把胚胎细胞沿前–后轴分成不同区域，并决定各主要区域器官的形态建成。果蝇为 *HOM* 基因，脊椎动物为 *Hox* 基因。
:::

由同源异形框基因编码的蛋白称为同源异形结构域蛋白（homeodomain protein）。它含有同源异形结构域和特异结构域（specific domain）：特异结构域通常靠近蛋白 N 端，同源异形结构域则靠近蛋白 C 端，这两个结构域在其蛋白作为转录因子发挥作用时均起决定性作用。由高度保守的 $60$ 个氨基酸组成的同源异形结构域，为一种拐弯的螺旋–环–螺旋（HLH）立体结构，其中的 $9$ 个氨基酸片段（第 $42\sim 50$ 位）与 DNA 的大沟相吻合，即它能识别其所控制的基因启动子中的特异序列（应答元件），从而激活或抑制特定基因的表达。

目前认为，*HOM* 或 *Hox* 基因产物是一类非常重要的转录调节因子，其功能是将胚胎细胞沿前–后轴分为不同的区域，并决定各主要区域器官的形态建成。例如，果蝇 *HOM* 基因的功能是决定一组细胞发育途径的一致性，确保体节或肢芽的发育。当 *HOM* 基因突变时，可发生同源异形转化（homeosis），即与发育有关的某一基因错误表达，导致一种器官生长在错误部位：果蝇的第三胸节转变为第二胸节，形成像第二胸节一样的翅膀（双翅膀果蝇）。

果蝇的 *HOM* 基因位于 $3$ 号染色体上，由两个独立的复合体组成，即触角足复合体和双胸复合体（bithorax complex），含有这两个复合体的染色体区域通常称为同源异形复合体（homeotic complex，HOM-C）。在进化过程中，果蝇 *HOM* 基因在哺乳动物中重复了 $4$ 次：*Hox-A*、*Hox-B*、*Hox-C*、*Hox-D*，分别定位于人的 $7$、$17$、$12$ 和 $2$ 号染色体；在小鼠则分别定位于 $6$、$11$、$15$ 和 $2$ 号染色体上。*HOM* 或 *Hox* 基因在染色体上的排列顺序与其在体内的不同时空表达模式相对应：这些基因激活的时间顺序表现为越靠近前部的基因表达越早，而靠近后部的基因表达越迟；这些基因表达的空间顺序表现为头区的最前叶只表达该基因簇的第一个基因，而身体最后部则表达基因簇的最后一个基因（图 15-11）。

::figure{src="/images/cell-biology/textbook/p0343_01.png" caption="图15-11 同源异形框基因在果蝇和小鼠染色体上的排列顺序及其基因表达的解剖顺序。果蝇 HOM 复合体与哺乳动物四簇 Hox 基因共线性对应；颜色表示跨越两种动物的结构相似性。基因表达顺序与染色体排列顺序相对应，越靠近前部表达的基因转录越早。" alt="果蝇HOM与小鼠四簇Hox基因共线性排列，沿胚胎前-后轴依次表达"}

:::concept{term="Hox 的染色体顺序就是身体的前–后顺序"}
不必把 *lab*、*Antp*、*Ubx* 的名字逐个背成孤立单词。先记住共线性：基因在染色体上从 $3'$ 到 $5'$ 的排列，对应身体从前到后的表达，也对应从早到晚的打开。突变把后部基因错开在前部，器官就会长错地方。把 Hox 只写成“转录因子”，会漏掉这张身体蓝图。
:::

### （四）表观遗传在转录水平上调控细胞的分化

细胞内基因表达的激活，首先是致密的异染色质舒展为常染色质，涉及染色质成分的化学修饰变化及一系列蛋白复合体的调控过程。染色质成分的化学修饰变化，包括染色质 DNA 甲基化修饰变化和染色质组蛋白修饰变化。所形成的染色质成分（DNA 和组蛋白）的修饰性标记能够在细胞分裂过程中继承并调控细胞内基因表达，决定细胞分化表型，即细胞分化的表观遗传（epigenetics，DNA 序列变化以外的可遗传的基因表达改变）调控。

:::definition{label="表观遗传"}
表观遗传（epigenetics）是 DNA 序列变化以外的、可遗传的基因表达改变。分化中的表观遗传调控主要包括 DNA 甲基化、组蛋白修饰，以及组蛋白组分变化、染色质重塑子和非编码 RNA 等非共价机制；它们在同一基因组上建立起能把不同转录和沉默模式传递下去的染色质模板。
:::

**1. DNA 甲基化修饰在转录水平上调控细胞分化基因的表达。** 在甲基化酶的催化下，DNA 分子中的胞嘧啶可转变成 $5$-甲基胞嘧啶，为 DNA 甲基化，它可以通过 DNA 复制直接遗传给子代细胞的 DNA。DNA 甲基化主要集中于异染色质区，其余则散在分布于基因组中。甲基化常见于富含 CG 二核苷酸的 CpG 岛，哺乳动物基因组中约 $70\%\sim 80\%$ 的 CpG 位点是甲基化的。

DNA 甲基化对基因转录的调控作用之一是启动子区域的 DNA 甲基化。启动子区域的 DNA 甲基化程度越高，DNA 转录活性越低。直接证据来自对基因活化与胞嘧啶甲基化程度的观察。在人类红细胞发育过程中，与珠蛋白合成有关的 DNA 几乎无甲基化，而在其他不合成珠蛋白的细胞中，相应的 DNA 部位则高度甲基化。如在胚胎期卵黄囊，$\varepsilon$-珠蛋白基因的启动子未甲基化，而 $\gamma$-珠蛋白基因的启动子则甲基化，因此胚胎期 $\varepsilon$-珠蛋白基因开放、$\gamma$-珠蛋白基因关闭；至胎儿期，在胎儿肝细胞中与合成胎儿血红蛋白有关的基因如 $\gamma$-珠蛋白基因无甲基化，在成体肝细胞中相应的基因则被甲基化（图 15-12）。表明细胞内当某些基因的功能完成之后，甲基化有助于这些基因的关闭。

::figure{src="/images/cell-biology/textbook/p0344_01.png" caption="图15-12 人类胚胎红细胞中珠蛋白基因的甲基化。胚胎约 6 周时 ε-珠蛋白基因启动子未甲基化而活化，γ 基因启动子甲基化而失活；约 12 周时 ε 启动子甲基化关闭，γ 启动子去甲基化而活化。" alt="ε和γ珠蛋白基因启动子甲基化状态随胚胎6周到12周切换"}

DNA 甲基化导致基因失活（或沉默）的可能机制是：①DNA 甲基化直接干扰转录因子与启动子中特定结合位点的结合，致基因转录受到抑制；②DNA 甲基化可致特异转录抑制因子直接与甲基化 DNA 结合，抑制基因的转录，致使基因表达沉默；③DNA 甲基化可导致染色质浓缩形成致密结构的异染色质，对基因的转录产生抑制作用，致使基因表达沉默。

甲基化作用也与基因组印记（genomic imprinting）关联。哺乳动物细胞是二倍体，含有一套来自父系的基因和一套来自母系的基因。在某些情况下，一个细胞内特定基因的表达与父系或母系来源有关，只允许父系或母系基因表达，这种现象称为基因组印记，与之相关的基因为印记基因（imprinted gene）。印记基因在哺乳动物的发育过程中普遍存在。多数情况下来源于父系和母系的等位基因都同时表达，但印记基因仅在特定的发育阶段和特定的组织中表达等位基因中的一个：在某种组织细胞中，有些仅从父源染色体上表达，有些仅从母源染色体上表达。在小鼠配子生成和胚胎发育早期，印记基因是选择表达还是关闭，其可能机制是在特定发育时期甲基化印记基因 DNA。此外，在哺乳动物（雌性）和人类女性的两条 X 染色体中，其中一条沉默（钝化）的 X 染色体就与 DNA 的甲基化有关，去甲基化可以使钝化的 X 染色体基因重新活化。

:::definition{label="基因组印记"}
基因组印记（genomic imprinting）是细胞内特定基因的表达取决于它来自父系还是母系、只允许其中一方表达的现象。相关基因为印记基因（imprinted gene）。配子生成和胚胎早期常通过甲基化写下或擦掉这枚印记；雌性一条 X 染色体的钝化也与 DNA 甲基化有关。
:::

**2. 染色质组蛋白化学修饰调控基因转录与细胞分化。** 第九章已经介绍了组蛋白的共价化学修饰，如组蛋白氨基酸残基的乙酰化、甲基化、磷酸化、泛素化、类泛素修饰（sumoylation）及糖基化等。这些修饰导致染色质结构改变，调控细胞内基因的转录或沉默。组蛋白的化学修饰所引起的染色质结构的动态变化能够调控细胞分化状态的转变（transition）。胚胎干细胞向神经元分化的过程中，组蛋白的甲基化和乙酰化状态，特别是一些与神经元分化关联基因（如 *Mash1*、*Pax6*）的启动子区域组蛋白的修饰状态呈现明显改变。果蝇 *scrawny* 基因（因突变的成熟果蝇的外观而得名）的编码产物为泛素蛋白酶（ubiquitin protease），通过抑制组蛋白 H2B 的泛素化而沉默细胞分化关键基因，使果蝇的生殖干细胞、皮肤上皮和肠道的组织干细胞等多种干细胞维持于未分化状态。*scrawny* 功能缺失导致果蝇突变体生殖组织、皮肤和肠道组织过早丢失这些组织内的干细胞。

**3. 染色质成分的化学修饰具有时空性。** 影响染色质结构变化的因素，除染色质组蛋白修饰和 DNA 甲基化等表观遗传调控因素外，还包括组蛋白组分变化、染色质重塑子（remodeler）和非编码 RNA 等因素的调控作用。表观遗传在分子或机制上被定义为“在同一基因组上建立的能将不同基因转录和基因沉默模式传递下去的染色质模板变化的总和”。在单个受精卵发育为多细胞个体（如脊椎动物）的过程中，一个受表观遗传调控的单基因组逐渐演变为存在于 $200$ 多种不同类型细胞中的多种表观基因组（图 15-13）。这种程序性的变化被视为组成了一种“表观遗传密码”，从而使经典遗传密码中所隐藏的信息得到了扩展。可以认为，染色质的共价化学修饰（即 DNA 和组蛋白的共价化学修饰）和非共价机制（如组蛋白组分改变、染色质重塑子和非编码 RNA 作用）相互结合，促使形成一种染色质状态，使其在细胞的分化过程中能够作为基因转录的模板，结合特异性转录因子及相关转录复合物，转录细胞分化的基因。

::figure{src="/images/cell-biology/textbook/p0345_01.png" caption="图15-13 表观基因组与细胞分化。基因组是某一个体不变的 DNA 序列；表观基因组是对应特定细胞的染色质模板总体构成，随细胞类型及内外信号而变。同一套大于 25 000 个基因的 DNA 序列，经干细胞和已定向细胞，写成 200 种以上不同类型的细胞；分化或去分化的转变需要表观基因组重编程。" alt="同一基因组经修饰和重建形成多种表观基因组，对应两百多种细胞类型"}

非编码 RNA 在染色质重塑中也有调控作用。如 miRNA 与蛋白质复合体——RITS（RNA-induced transcriptional silencing）结合，将 RITS 复合体引导至 miRNA 同源基因区域，通过募集组蛋白甲基化酶，使组蛋白 H3 的赖氨酸-9 甲基化，致异染色质形成，最终抑制该染色质区域内基因的转录（详见第九章）。

在哺乳动物的发育过程中，发育后期生殖细胞染色质内甲基化的 DNA，包括亲本特异性的基因印记，在受精后合子细胞内的雄原核基因组中迅速去甲基化，而在雌原核基因组中则维持不变。合子细胞中的雄原核被包装上组蛋白，但其组蛋白上缺乏 H3K9me2 和 H3K27me3，而此时雌原核则具有这些标记。在发育过程中，合子细胞基因组后续的去甲基化发生于着床前发育期，直至囊胚期。在囊胚期，内细胞团开始出现 DNA 甲基化，组蛋白 H3K9me2 和 H3K27me3 水平上升，胚胎内各细胞基因表达出现差异；随着发育过程的进展，胚胎进入原肠期，形成三胚层，继而分化形成各组织器官。而由滋养外胚层（trophectoderm）发育而来的胎盘细胞则表现出相对较低的染色质甲基化水平。第十四章把雌、雄原核写成受精后的两套核；这里它们带着不同的甲基化和组蛋白标记进入第一次卵裂。

细胞内基因表达的转录水平调控极其复杂，新的转录调控机制被不断揭示。增强子在细胞特化中的作用还表现为多个增强子丛（cluster）组合在一起形成超级增强子（super-enhancer）而发挥作用。

:::definition{label="超级增强子"}
超级增强子（super-enhancer）是含有高密度转录活性增强子的染色质区域，富集关键转录因子（master transcription factor）、辅因子（cofactor）结合元件和基因活化的组蛋白修饰标记（histone modification mark），能够驱动控制细胞身份（cell identity）基因的表达。哺乳动物中已鉴别出超过 $100$ 万个增强子，其中数百个超级增强子控制赋予每个细胞特性和功能的大多数关键基因；发育中旧的超级增强子失活、新的超级增强子活化，驱动细胞分化。
:::

深入探索超级增强子在细胞分化过程中的基因转录调控，将有助于阐明表达基因数量的改变、特异基因表达量的变化及基因表达水平临界值与细胞分化、表型特化的关系，同时也将加深认识既往鉴定的基因座控制区等调控细胞分化的机制。LCR 可以看成较早被认出的远程控制区；超级增强子把同类逻辑推广到细胞身份基因。

## 四、基因选择性表达的转录后调控

生命体内细胞分化过程，实质上是细胞内特异蛋白质不断合成的过程。在真核细胞内基因的表达，在基因转录后，还有 RNA 加工、RNA 转运、mRNA 降解、蛋白质翻译及蛋白质活性修饰等调控过程，均参与细胞分化调控。这里从 RNA 可变剪接和非编码 RNA 两个方面阐述转录后调控在细胞分化中的作用。

**1. RNA 剪接与细胞分化。** RNA 剪接对细胞分化的一种调控方式为可变剪接（alternative splicing，也称选择性剪接），即在同一基因中，其剪接位点和拼接方式可以改变，从而导致一个基因能产生多个具有明显功能差异的蛋白。例如，RNA 可变剪接能使 $\beta$-原肌球蛋白（$\beta$-tropomyosin）基因编码出在骨骼肌细胞和成纤维细胞内的两种形式的蛋白。$\beta$-原肌球蛋白的前体核 RNA 含有 $11$ 个外显子，其中外显子 $1\sim 5$、$8$ 和 $9$ 是表达这一基因的所有 mRNA 共有的，外显子 $7$ 和 $10$ 被用于骨骼肌的 $\beta$-原肌球蛋白合成中，而外显子 $6$ 和 $11$ 则被用于成纤维细胞和平滑肌细胞中（图 15-14）。

:::definition{label="可变剪接"}
可变剪接（alternative splicing）是同一基因中剪接位点和拼接方式发生改变，从而由一个基因产生多个功能明显差异的蛋白的过程。$\beta$-原肌球蛋白前体含 $11$ 个外显子：骨骼肌使用外显子 $7$ 和 $10$，成纤维细胞和平滑肌使用外显子 $6$ 和 $11$。
:::

::figure{src="/images/cell-biology/textbook/p0346_01.png" caption="图15-14 β-原肌球蛋白 mRNA 前体的可变剪接示意图。骨骼肌细胞中外显子 6 和 11 被当作内含子剪掉；成纤维细胞和平滑肌细胞中外显子 7 和 10 被当作内含子，6 和 11 则被用作外显子。" alt="β-原肌球蛋白前体经两种剪接产生骨骼肌型和成纤维细胞平滑肌型蛋白"}

**2. 非编码 RNA 与细胞分化。** 非编码 RNA（non-coding RNA）在细胞分化中的作用近年逐渐被揭示。哺乳动物基因组中近 $98\%$ 不与蛋白质编码基因相对应。在人类，虽然基因组包含约 $32$ 亿个碱基，但编码蛋白质的基因仅有约 $2$ 万$\sim 3$ 万个，其余绝大部分为非编码序列。这些非编码序列转录形成微小 RNA（microRNA，miRNA）、内源性 siRNA（endo-siRNA）、piRNA（Piwi-interacting RNA）等非编码小 RNA 及长链非编码 RNA（long non-coding RNA，lncRNA）。

非编码小 RNA 主要在转录后调控细胞的分化。小 RNA 通过与靶基因 mRNA $3'$ 端 UTR 互补结合，抑制靶基因的蛋白质合成或促使靶基因的 mRNA 降解，从而参与细胞分化和发育相关基因的表达调控。小 RNA 在生命体发育中的调控作用，是在研究秀丽隐杆线虫（*C. elegans*）细胞命运的时间控制过程中被发现的：高浓度的转录因子 LIN-14 可特异性地促进早期幼虫器官的蛋白质合成，但在后续的发育中，尽管体内一直存在 *lin-14* mRNA 却检测不到 LIN-14 蛋白。后来发现在线虫的第一、二龄幼虫期存在一个 $22\,\mathrm{nt}$ 的 miRNA，即 *lin-4* RNA。*lin-4* RNA 通过与 *lin-14* mRNA $3'$ 端 UTR 互补结合，短暂下调 LIN-14 蛋白水平，促进线虫从第一龄幼虫期向第二龄幼虫期发育。如果 *lin-4* 基因突变而失去功能，那么线虫幼虫体内可持续合成 LIN-14 蛋白，使线虫长期停滞在幼虫的早期发育阶段。随后在线虫体内又发现了另一个 miRNA——*let-7* RNA。*let-7* RNA 长为 $21\,\mathrm{nt}$，存在于线虫的第三、四龄幼虫期及成虫期，其功能是决定线虫从幼虫向成虫的形态转变。后续研究发现，*let-7* RNA 不仅存在于线虫，也存在于人类和其他脊椎动物。越来越多的研究资料表明，小 RNA 广泛地存在于哺乳动物，具有高度的保守性。目前在各种生物中已发现数千种 miRNA，大部分 miRNA 的产生机制和功能尚有待阐明。迄今已鉴定了一系列与细胞分化有关的 miRNA，如 miR-143 和 miR-145 参与调控平滑肌细胞的分化；miR-126 特异性表达于内皮细胞，调控血管形成。piRNA 与 Piwi 蛋白家族成员的结合，在调节精子成熟发育中起重要作用（第十四章已经把 piRNA–Piwi 写在精子发生里）。非编码小 RNA 参与细胞分化和发育的机制有待进一步探索。

:::cause-effect{title="lin-4 怎样把线虫从第一龄推到第二龄"}
- 因：早期幼虫需要高浓度 LIN-14 来合成早期器官蛋白
- 因：第一、二龄出现 $22\,\mathrm{nt}$ 的 *lin-4*，与 *lin-14* mRNA 的 $3'$ UTR 互补结合
- 果：LIN-14 蛋白被短暂下调，即使 mRNA 还在也不再翻译
- 结果：线虫进入下一龄；*lin-4* 失活则 LIN-14 持续存在，发育卡在早期幼虫阶段
:::

长链非编码 RNA 与细胞的分化密切相关。细胞中 lncRNA 的来源极其复杂，有资料显示，哺乳动物基因组序列中 $4\%\sim 9\%$ 的序列产生的转录物是 lncRNA。lncRNA 可通过多种方式调控基因表达，如在蛋白编码基因上游启动子区发生转录，干扰下游基因的表达；通过调控 RNA 聚合酶 II 转录活性或者介导染色质重塑，调节下游基因表达；通过与蛋白编码基因的转录物形成互补双链而干扰 mRNA 的剪接；通过结合到特定蛋白质上，调节相应蛋白质的活性。在细胞分化与发育过程中 lncRNA 能调控基因组印记和 X 染色体失活；在细胞分化中 lncRNA 参与调控特定基因区域内染色质组蛋白甲基化修饰、重塑染色质结构等，在基因选择性表达过程中发挥调控作用。

:::compare{title="主导基因 vs 组合调控"}
| 项目 | 主导（主控）基因 | 组合调控 |
|------|-----------------|----------|
| 核心逻辑 | 一个关键转录调节蛋白启动并锁定整条谱系 | 多种调节蛋白的不同组合决定多种细胞类型 |
| 结果 | 若干基因永久关闭、若干基因持续激活 | 较少种类的因子产生较多细胞类型 |
| 典型分子 | *myoD*（肌）、*Ey*/*Pax-6*（眼） | 图 15-10 中 $5$ 种蛋白 → $8$ 种细胞 |
| 自我维持 | 一旦活化即维持，可诱导异位转分化 | 依赖细胞记忆把已选组合传给子代 |
| 与位置信息 | 常由 Wnt、Shh 等外源信号点燃 | 左右、前后等位置可决定选哪一个因子 |
:::

:::keypoint{label="分化几乎从不改基因组，改的是许可"}
- 普遍规律是差异基因表达；核移植、转分化和细胞融合都证明基因组大体还在。
- 扩增、丢失、重排是特例，不能用来定义分化。
- 母体因子和 *numb* 这类不对称分配，把第一节的“决定”写成卵裂时的分子。
- 转录水平：LCR 管珠蛋白的时间表，组织特异性转录因子管空间表，*myoD* 一类主控基因锁谱系，Hox 按染色体顺序画前–后轴。
- 甲基化关掉用完的基因，组蛋白修饰和超级增强子维持细胞身份；可变剪接和 miRNA 在转录后再选一次产物。
:::

:::memory{label="本节必背要点"}
- [ ] 分化实质是特化：选择性表达特异性蛋白；管家基因维持存活和生长。
- [ ] 普遍规律：分化一般不伴基因组改变；Gurdon 肠上皮核移植到去核爪蟾卵可发育为成体（核含 $1$ 个核仁）。
- [ ] 特例：基因扩增（果蝇滤泡细胞、多线体）、染色体丢失（马蛔虫、摇蚊）、红细胞去核、T/B 细胞基因重排。
- [ ] 母体效应基因在卵子发生中表达，产物极性分布于卵质，受精后决定初始命运；果蝇预先决定前–后轴和背–腹轴。
- [ ] *bicoid* mRNA 定位于前端，翻译 BICOID（螺旋–转角–螺旋），高浓度→头部基因，低浓度→胸部基因。
- [ ] 不对称分裂：*numb* 只进入一个子细胞，该系形成神经元和鞘层细胞，无 numb 一系形成支持细胞。
- [ ] 时间特异性：人 $\beta$-珠蛋白簇 $\varepsilon$（卵黄囊）→ $^{\mathrm{G}}\gamma$/$^{\mathrm{A}}\gamma$（胎儿肝）→ $\delta$/$\beta$（成体骨髓）；LCR 距 $\varepsilon$ 上游约 $10\,000\,\mathrm{bp}$，可远程指导顺序表达。
- [ ] 空间特异性：组织细胞特异性转录因子（Isl-I、MyoD I）结合调控区；弹性蛋白酶调控区可驱使胰腺表达人生长激素。
- [ ] 细胞谱系：一个因子可同时开关多个基因；组合调控用多种调节蛋白的组合产生多种细胞类型。
- [ ] 主导基因：*myoD*（bHLH）经 *MRF4*、*myogenin* 启动肌分化，可诱导成纤维细胞转分化为肌细胞；Wnt/Shh 经 *myoD* 或 *myf-5* 点燃；*Ey*/*Pax-6* 可触发整个眼。
- [ ] 同源异形框：$180\,\mathrm{bp}$ 编码 $60$ 氨基酸同源异形结构域（第 $42\sim 50$ 位识别 DNA 大沟）。果蝇 HOM-C（触角足+双胸复合体）在哺乳动物重复为四簇 Hox（人：7、17、12、2 号染色体），共线性对应前–后轴；突变可致同源异形转化（双翅膀果蝇）。
- [ ] DNA 甲基化：启动子甲基化程度越高转录越低；胚胎 $6$ 周 $\varepsilon$ 开、$\gamma$ 关，$12$ 周对调。沉默机制：挡转录因子、招募抑制因子、形成异染色质。
- [ ] 基因组印记：只允许父源或母源等位基因表达；雌性一条 X 钝化也与甲基化有关。
- [ ] 组蛋白修饰调控分化转变；*scrawny* 编码泛素蛋白酶，抑制 H2B 泛素化以维持干细胞未分化。
- [ ] 受精后雄原核迅速去甲基化且缺 H3K9me2/H3K27me3，雌原核维持；囊胚期内细胞团再甲基化，滋养外胚层甲基化较低。
- [ ] 超级增强子富集主控转录因子和活化组蛋白标记，驱动细胞身份基因；发育中旧的失活、新的活化。
- [ ] 可变剪接：$\beta$-原肌球蛋白 $11$ 个外显子，骨骼肌用 $7$、$10$，成纤维/平滑肌用 $6$、$11$。
- [ ] *lin-4*（$22\,\mathrm{nt}$）下调 LIN-14 推动 L1→L2；*let-7*（$21\,\mathrm{nt}$）决定幼虫→成虫。miR-143/145 调控平滑肌，miR-126 调控内皮血管形成。
- [ ] lncRNA 可干扰下游转录、介导染色质重塑、干扰剪接、调节蛋白活性，并参与印记和 X 失活。
:::
