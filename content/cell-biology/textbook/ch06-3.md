# 第三节 线粒体与医学

线粒体与细胞的许多生命活动有关，因此维持线粒体的正常结构与功能对生命体至关重要。在特定条件下，线粒体与疾病发生有密切的关系：一方面，线粒体作为细胞病变的一部分，是疾病在细胞水平上的一种表现形式；另一方面，线粒体可作为疾病发生的主要动因，是疾病发生的关键。

:::definition{label="线粒体与疾病的双重关系"}
线粒体既可被动地成为细胞损伤的形态学指标（肿胀、嵴减少、基质致密），也可主动成为病因：mtDNA 突变、核编码动力学蛋白缺陷或呼吸链中毒都会直接摧毁氧化磷酸化，首先打击高耗能的神经和肌肉组织。
:::

## 一、生理及疾病过程中的线粒体变化

线粒体作为全身能量代谢的关键调节器，在维持正常生理过程中起着至关重要的作用。例如，在耐力运动后可观察到肌细胞中线粒体质量和活性的增加；在寒冷刺激下，脂肪细胞中线粒体数量及产热蛋白显著增加，从而维持体温；在饥饿条件下，肝脏线粒体可产生酮体，替代葡萄糖作为全身细胞的能量来源。除此之外，随着线粒体代谢模式的改变，产生的各类代谢物可控制转录因子和染色质修饰，从而改变细胞功能。

:::concept{term="线粒体代谢物的信号功能"}
TCA 中间物、乙酰 CoA、NADH/$\mathrm{NAD}^{+}$ 比值不仅反映“有没有燃料”，还直接修饰转录因子和组蛋白。能量状态因此可以写进基因表达程序：运动、寒冷和饥饿改变的不只是 ATP 数量，还有细胞的转录面貌。
:::

在衰老过程中，线粒体与各类衰老的标志相关联。衰老细胞中可观察到线粒体氧化磷酸化能力下降、膜电位降低、ROS 产生增加以及 mtDNA 突变的累积。这些线粒体功能障碍可进一步引起机体的衰老过程。

在病理状态下常见线粒体的结构、数量及功能改变。线粒体对外界环境变化很敏感，在有害物质渗入、病毒入侵、辐射等情况下，线粒体可发生肿胀甚至破裂，肿胀后的体积有的比正常体积大 3～4 倍。人肝细胞癌变过程中，线粒体嵴的数目逐渐下降而最终成为液泡状线粒体。细胞缺血性损伤时，线粒体出现凝集、肿胀等结构变异。帕金森病等神经退行性疾病常见神经元线粒体功能障碍及线粒体自噬受损。一些细胞病变时，可观察到线粒体中累积大量的脂肪或蛋白质，有时可见线粒体基质颗粒大量增加，这些物质的充塞往往影响线粒体功能甚至导致细胞死亡。氰化物、CO 等物质可阻断呼吸链上的电子传递，造成生物氧化中断、细胞死亡（图 6-18）。在这些情况下，线粒体常作为细胞病变或损伤时最敏感的指标之一，成为分子细胞病理学检查的重要依据。

::figure{src="/images/cell-biology/textbook/p0166_01.png" caption="图6-18 线粒体病患者的 mtDNA 状态与氧化磷酸化" alt="线粒体病时突变 mtDNA 比例升高，氧化磷酸化复合体装配和电子传递受损"}

:::note{label="病理切片里先看线粒体"}
肿胀、嵴变少变短、基质颗粒堆塞、外膜破裂，往往比细胞核的改变出现得更早。缺血、中毒、辐射和一部分肿瘤，电镜下线粒体是最先“报警”的细胞器之一。
:::

:::cause-effect{title="呼吸链中毒导致细胞死亡"}
- 因：氰化物或一氧化碳结合细胞色素氧化酶（复合体Ⅳ）的血红素铁
- 因：电子无法交给 $\mathrm{O_2}$，质子泵停止，ATP 合成中断
- 果：膜电位崩溃，离子稳态和主动运输失守
- 结果：组织急性缺氧样坏死，中枢神经系统和心肌最先受累
:::

## 二、mtDNA 突变与疾病

线粒体含有自身独特的环状 DNA。其 DNA 是裸露的，易发生突变且很少能修复。当突变 mtDNA 进行异常复制时，机体并不能予以识别和阻止。细胞能以加快分裂的方式将突变的线粒体分散到子细胞中，以减轻对细胞的损害，但持续的损害终将导致疾病的发生。这类以线粒体结构和功能缺陷为主要原因的疾病称为线粒体病（mitochondrial disorder）。

:::definition{label="线粒体病"}
线粒体病（mitochondrial disorder）是以线粒体结构和功能缺陷为主要原因的疾病。多数影响氧化磷酸化，临床常累及神经和肌肉系统，故有时统称为线粒体脑肌病（mitochondrial encephalomyopathy）。同一突变在不同个体、甚至同一患者的不同组织中，可因异质性比例不同而表现悬殊。
:::

mtDNA 特别容易成为突变的靶子，原因可以收成三条。第一，它不与组蛋白结合，缺少核基因组那样的包装保护。第二，它就在呼吸链旁边，持续暴露于 ROS。第三，修复系统远比细胞核简陋，复制又不与细胞周期严格耦联。突变一旦出现，便以多拷贝形式在细胞质中漂变。

:::cause-effect{title="mtDNA 突变如何导致线粒体病"}
- 因：mtDNA 裸露、紧邻呼吸链，ROS 损伤和复制错误使其突变率高，修复能力弱
- 因：突变 mtDNA 与野生型共存（异质性），经复制分离在子线粒体和子细胞中随机漂变
- 因：受精卵中的线粒体几乎全部来自卵细胞，突变随细胞质母系传递
- 果：当突变负荷超过组织阈值，呼吸链亚基合成不足，氧化磷酸化下降
- 果：ATP 亏欠首先打击中枢神经、骨骼肌、心肌、视网膜等高耗能组织
- 结果：出现线粒体脑肌病等临床表型，个体差异大，可在同一家系中轻重悬殊
:::

线粒体病主要影响神经、肌肉系统，但不同的疾病，或同一疾病不同的个体常有不同的临床表现。由于受精卵中绝大多数的线粒体都来自卵细胞，由 mtDNA 突变引起的线粒体病在遗传方式上表现出明显的母系遗传特征。利用现代生物学技术可以使线粒体病得到明确诊断。

:::concept{term="母系遗传与阈值效应"}
精子几乎不把线粒体带进受精卵，因此 mtDNA 突变沿母系下传：母亲的子女都可能带突变，父亲则不传给下一代。组织要等突变 mtDNA 比例跨过阈值，氧化磷酸化才明显失代偿——脑和肌的阈值往往较低，所以先出现脑肌病，而同一血样的突变比例未必代表受累器官。
:::

:::pitfall{label="不要把“线粒体病”等同于“mtDNA 病”"}
mtDNA 点突变、缺失确实是一类重要病因，但核基因编码的呼吸链亚基、TOM/TIM、动力学蛋白（DRP1、OPA1、MFN2）出问题，同样可以表现为线粒体病。母系遗传支持 mtDNA 起源；常染色体遗传则要把目光转到核基因组。
:::

## 三、线粒体融合和分裂异常相关的疾病

线粒体融合和分裂异常，或者编码线粒体融合和分裂相关蛋白的基因发生突变，就可能导致疾病发生。如参与线粒体分裂的 DRP1 基因突变可导致婴儿出生后大脑发育障碍、视神经萎缩，并伴有其他严重并发症。而介导融合的蛋白 OPA1 和 MFN2 的突变会引起 Kjer 病（常染色体显性视神经萎缩）和 2A 型腓骨肌萎缩症。

这些疾病从另一侧证明：线粒体必须能分裂以分配和质控，也必须能融合以交换膜电位、基质成分和 mtDNA。网络一旦被锁死在过度碎片或过度黏连的状态，视神经、周围神经和发育中的大脑这类“细长、高耗能”的细胞最先撑不住。

:::cause-effect{title="动力学蛋白突变破坏线粒体网络"}
- 因：DRP1 突变使分裂环不能在外膜正确组装
- 因：OPA1 或 MFN2 突变分别阻断内膜或外膜融合
- 果：线粒体不能按能量需求调整形态，损伤片段难以隔离，mtDNA 不能有效互补
- 结果：婴儿脑发育障碍与视神经萎缩（DRP1）、Kjer 病（OPA1）、2A 型腓骨肌萎缩症（MFN2）
:::

:::compare{title="mtDNA 突变病 vs 动力学蛋白病"}
| 项目 | mtDNA 突变相关疾病 | 融合/分裂蛋白病 |
|------|---------------------|------------------|
| 突变基因组 | 线粒体 DNA | 核 DNA（DRP1、OPA1、MFN2 等） |
| 遗传方式 | 母系遗传，伴异质性漂变 | 多为孟德尔遗传（如常显视神经萎缩） |
| 直接打击 | 呼吸链核心亚基、tRNA/rRNA | 线粒体形态、质控与内容物交换 |
| 典型受累 | 脑、骨骼肌、心肌、内分泌腺 | 视神经、周围神经、发育中的脑 |
| 诊断线索 | mtDNA 测序、异质性定量、母系家系 | 核基因检测，不一定有 mtDNA 突变 |
:::

## 四、线粒体病的治疗

线粒体病的治疗尚待突破。目前的治疗包括补充疗法、选择疗法和基因疗法。

**补充疗法**是给患者添加呼吸链所需的辅酶，如辅酶 Q，用于治疗线粒体脑肌病（卡恩斯-塞尔综合征，Kearns-Sayre syndrome）、心肌病及其他呼吸链复合物缺陷引起的线粒体病，同时也可缓解与衰老有关的氧化/抗氧化失衡。

**选择疗法**是选用一些能促进细胞排斥突变线粒体的药物进行治疗，以增加细胞中正常线粒体的比例。如连续低剂量使用 ATP 合酶抑制剂氯霉素，促进对缺陷线粒体的排斥。其逻辑与复制分离相反相成：不是让突变漂变到更高，而是给野生型线粒体选择优势。

**线粒体基因疗法**是将正常的线粒体基因转入患者体内以替代缺陷 mtDNA，或通过线粒体基因编辑技术修正缺陷 mtDNA。改善线粒体功能的新药研发及创新疗法将促进线粒体病的临床治疗。

:::tip{label="治疗对准的是“突变负荷”而不只是“缺 ATP”"}
补辅酶 Q 是在下游给呼吸链加油；选择疗法和基因治疗则试图改写细胞内野生型与突变型 mtDNA 的比例。异质性不降到阈值以下，单纯补能量往往只能缓解、难以根治。
:::

:::keypoint{label="从细胞器到临床"}
- 生理上，线粒体随运动、寒冷、饥饿改写数量和代谢程序；衰老时 OXPHOS 下降、ROS 和 mtDNA 突变累积。
- 中毒、缺血、肿瘤和神经退行性变都先在线粒体留下形态和功能痕迹。
- mtDNA 突变经母系传递，靠异质性和阈值决定表型；动力学核基因突变走孟德尔遗传。
- 治疗仍在补充辅酶、选择清除缺陷线粒体和基因修正三条路上推进。
:::

:::memory{label="本节必背要点"}
- [ ] 线粒体既是病变的敏感指标，也可以是原发病因。
- [ ] 生理适应：运动增加肌线粒体质量；寒冷诱导产热蛋白；饥饿时肝线粒体生成酮体。
- [ ] 衰老：氧化磷酸化下降、膜电位降低、ROS 升高、mtDNA 突变累积。
- [ ] 病理形态：肿胀可达正常 3～4 倍；肝癌嵴减少成液泡状；缺血时凝集、肿胀；帕金森病伴自噬受损。
- [ ] 氰化物、CO 阻断呼吸链电子传递，生物氧化中断。
- [ ] 线粒体病：以线粒体结构功能缺陷为主因，常表现为脑肌病；mtDNA 裸露、易突变、难修复。
- [ ] 母系遗传：受精卵线粒体几乎全部来自卵细胞。
- [ ] 异质性 + 复制分离 + 阈值效应解释同一突变的表型差异。
- [ ] DRP1 突变：婴儿脑发育障碍、视神经萎缩；OPA1：Kjer 病；MFN2：2A 型腓骨肌萎缩症。
- [ ] 治疗：补充疗法（辅酶 Q 等）、选择疗法（促进排斥突变线粒体）、基因疗法（转入或编辑 mtDNA）。
:::
