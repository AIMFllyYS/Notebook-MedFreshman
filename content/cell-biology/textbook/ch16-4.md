# 第四节 其他类型细胞死亡

第三节把凋亡写成封在完整膜里的主动自杀，执行器是 caspase。调控性死亡并不只有这一种机器。有的死亡保持坏死外表——肿胀、膜破、内容物外溢、引发炎症——却能被小分子抑制剂逆转；有的把自噬开到细胞把自己吃空；有的在膜上打出炎症因子可以钻出去的孔；有的则让铁催化的脂质过氧化把膜氧化穿。本节依次写程序性坏死、自噬性细胞死亡、细胞焦亡和铁死亡。它们都是第二节的 RCD，只是执行器换成了 RIPK3/MLKL、ATG 系统、gasdermin 和脂质过氧化。

:::definition{label="坏死性凋亡"}
坏死性凋亡（necroptosis）又称程序性坏死（programmed necrosis），是具有坏死样形态、但不依赖 caspase、而依赖 RIPK1/RIPK3/MLKL 坏死复合体的调控性死亡。小分子抑制剂 Nec-1 可逆转 RIPK1 介导的这类死亡。
:::

:::definition{label="细胞焦亡"}
细胞焦亡（pyroptosis）是由 gasdermin（GSDM）家族蛋白在膜上打孔所介导的调控性死亡，表现为细胞肿胀、质膜吹起大泡直至破裂，释放内容物和 IL-1$\beta$、IL-18 等促炎细胞因子。它曾被误认为 caspase-1 介导的特殊凋亡。
:::

## 一、程序性细胞坏死

细胞坏死一直被认为是在严重损伤条件下发生的一种被动的非程序性细胞死亡。然而某些类型的细胞坏死，例如最先发现的感染牛痘病毒的猪肾细胞坏死，显示出可被抑制和调控的特征。这种类型的细胞坏死被命名为程序性坏死或坏死性凋亡。

**1. 程序性坏死呈现出坏死样细胞的典型特征。** 在显微镜下，细胞肿胀、体积增大，细胞膜完整性破坏，细胞质内容物流出；核膜肿胀、染色质碎裂。组织中坏死细胞周围出现炎症细胞浸润等炎症反应。形态上它更像第二节的坏死，而不像第三节的凋亡小体。

**2. 程序性坏死具有 RIPK1/RIPK3 复合体形成和 MLKL 磷酸化的典型生化特征。** 早期研究已观察到，程序性坏死不依赖 caspase，因为在坏死细胞中表达了一种能抑制 caspase-1 和 caspase-8 的蛋白。后续发现受体相互作用蛋白激酶 1（receptor-interacting protein kinase 1，RIPK1）在程序性坏死中起重要作用，因为化学合成的 RIPK1 小分子抑制剂 Nec-1（necrostatin-1）能逆转这种细胞坏死。

尽管诱发程序性坏死的胞外信号主要是 TNF 和 FasL 等，但这些分子介导的死亡信号途径与诱导凋亡不同——因为存在 caspase-8 抑制因子。配体与膜受体 TNFR、Fas、TRAIL 结合后，受体胞内段不能招募和组装激活 caspase-8 的复合体，而是触发 RIPK1 与 RIPK3 结合。形成的复合体促使 RIPK1 与 RIPK3 相互磷酸化而被活化，并催化下游效应分子 MLKL（mixed lineage kinase domain like protein）的磷酸化。由 RIPK1、RIPK3 和 MLKL 构成的蛋白质复合体就被称为坏死复合体（necrosome）。磷酸化的 MLKL 结合膜磷脂酰肌醇，插入膜结构并形成寡聚体，迅速改变膜通透性，钠、钾离子穿膜运输增多，细胞渗透压升高，水运输增加。膜的通透性改变也发生于线粒体和内质网膜等膜性细胞器。当质膜胀破后，细胞内容物流出，引起炎症反应。

此外，干扰素（interferon，IFN）通过干扰素受体信号途径、细菌脂多糖（LPS）通过 Toll 样受体 4（Toll like receptor 4，TLR4）信号途径、病毒通过细胞内的核酸受体（Z-DNA-binding protein 1，ZBP1）等也可以激活坏死复合体，触发程序性坏死。第三节的 FasL 在 caspase-8 能用时写成凋亡，在 caspase-8 被卡住时改写成坏死性凋亡：同一扇门，钥匙换了。

:::definition{label="坏死复合体"}
坏死复合体（necrosome）是由 RIPK1、RIPK3 和 MLKL 构成的蛋白质复合体。RIPK1 与 RIPK3 相互磷酸化后催化 MLKL 磷酸化；磷酸化的 MLKL 结合磷脂酰肌醇、插入并寡聚于膜上，造成离子和水内流，质膜胀破。
:::

:::derivation{label="caspase-8 被抑制时 TNF 怎样改写成坏死"}
1. TNF、FasL 等与 TNFR、Fas、TRAIL 结合。
2. caspase-8 抑制因子存在，DISC 无法成为 caspase-8 激活平台。
3. 受体改为招募 RIPK1，RIPK1 与 RIPK3 结合并相互磷酸化。
4. 磷酸化的 RIPK3 催化 MLKL 磷酸化，装配坏死复合体。
5. p-MLKL 插入质膜（及线粒体、内质网膜）寡聚成孔，Na$^{+}$/K$^{+}$ 和水内流，渗透压升高，质膜胀破，内容物致炎。
6. Nec-1 抑制 RIPK1，可把这条路关掉。IFN、LPS–TLR4、ZBP1 也可从旁路激活坏死复合体。
:::

**3. 程序性坏死与机体的发育和疾病有关。** 程序性坏死既存在于个体发育过程，也参与机体组织损伤和炎症反应，与心、脑、肾的缺血再灌注损伤，急性肝损伤，以及急性胰腺炎、溃疡性结肠炎等密切相关。第二节把生理条件下的 RCD 称为 PCD；坏死性凋亡可以是 PCD，也可以是组织损伤里的炎症放大器。

## 二、自噬性细胞死亡

自噬性细胞死亡（autophagic cell death）最初是在胚胎发育中观察到的一种细胞死亡。因其主要表现为细胞中的自噬性囊泡增多，但染色质没有凝集，不同于凋亡和坏死的形态学改变，而将其命名为 II 型细胞凋亡。此后，随着自噬的分子机制被揭示，自噬性细胞死亡被进一步认识。通常将在一些特定条件下发生的、与自噬有严格依赖关系、抑制细胞自噬后细胞不再死亡、且其他分子机制的细胞死亡没有参与其中的细胞死亡，称为自噬性细胞死亡或自噬依赖性细胞死亡（autophagy-dependent cell death）。而其他与自噬相关的细胞死亡，如凋亡伴随的自噬现象（出现自噬样结构），以及自噬造成的其他调控性死亡（主要是因自噬降解了生存相关的蛋白质，如降解铁蛋白、磷酸酶或 cIAP2，分别造成铁死亡、凋亡）等，均不属于通常意义上的自噬性细胞死亡范畴。第五章的自噬是活下去的回收；这里回收本身必须是死因，而不是旁观者。

:::definition{label="自噬性细胞死亡"}
自噬性细胞死亡又称自噬依赖性细胞死亡，是形态上出现大量自噬囊泡、分子上严格依赖自噬蛋白质复合物、抑制这些成分后死亡可被逆转的调控性死亡。伴随凋亡的自噬泡，或自噬降解铁蛋白/cIAP2 后再走铁死亡/凋亡，都不算。
:::

**1. 自噬性细胞死亡是细胞质的过度自噬和分子机制上严格依赖自噬的调控性细胞死亡。** 它最初被定义的基本特征是形态上出现大量自噬囊泡，细胞质被包裹形成的自噬结构明显增多，此后又增加了由分子机制来严格定义的特征。从生化特征上看，自噬性细胞死亡是指依赖于自噬的蛋白质复合物或其中成分的细胞死亡，以遗传手段或抑制剂干预这些成分后，细胞死亡能够被逆转。这样的特征建立了自噬与死亡的因果关系，而非伴随关系。

目前对机制的认识还比较初步。已发现其分子机制主要为依赖于细胞自噬的经典分子机制（第五章），如依赖 ULK1、Atg5、Atg7 和 LC3-II 等。也发现有不依赖经典机制的特殊自噬性死亡机制，如依赖葡萄糖苷神经酰胺酶 GBA1（glucosylceramidase beta）。其精细分子机制仍在探索中。

自噬性细胞死亡的一个亚型是自体死亡（autosis）。它是在利用经典自噬诱导蛋白 Beclin1 改造的诱导融合肽处理细胞后被发现的，细胞出现过度自噬和最终的自噬性死亡。形态上，早期和中期细胞中出现大量自噬结构、内质网片段化、线粒体电子密度增高；而晚期自噬结构消失、线粒体肿胀。细胞核的改变非常特异，包括核膜卷曲、皱缩，核表面灶性凹陷，核周空间“气球样改变”和染色质轻到中度凝集。这种细胞死亡的分子机制除了依赖 ATG 家族分子，也有独特的 $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-ATP 酶活性增强的特点。

:::definition{label="自体死亡"}
自体死亡（autosis）是自噬性细胞死亡的一个亚型，由 Beclin1 诱导融合肽等触发。核膜卷曲、核周间隙气球样改变、晚期线粒体肿胀，并依赖 ATG 家族和增强的 $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-ATP 酶活性。
:::

:::pitfall{label="看见自噬泡，不等于死于自噬"}
凋亡细胞里也可以出现自噬样结构；自噬降解铁蛋白会把细胞推进铁死亡，降解 cIAP2 会推进凋亡。这些都是“自噬相关”，不是自噬性细胞死亡。判决标准是：抑制 ULK1/Atg5/Atg7/LC3-II（或特殊情况下的 GBA1）之后死亡被逆转，并且其他 RCD 没有顶上来。把自噬染色阳性写成死因，会把第五章的生存机制和本节的死亡机制混成一件事。
:::

**2. 自噬性细胞死亡在不同的生理和病理条件下发生。** 机体的自噬性细胞死亡对个体发育有一定影响，尤其是果蝇等昆虫的发育。在果蝇幼虫的中肠（midgut）退化时发生了自噬性细胞死亡，唾液腺退化时同时发生了凋亡和自噬性细胞死亡。另外，对哺乳动物来说，在特定病理条件下细胞出现自噬性死亡。在神经退行性疾病、心血管疾病中，均可检测到自噬的缺陷或过度增多。在新生大鼠缺氧和缺血脑损伤时发现了自体死亡；化疗药等处理体外培养的人卵巢癌细胞时也出现自体死亡；白藜芦醇处理人肺癌细胞株后也发现有自噬性细胞死亡。总之，自噬性细胞死亡的分子机制和生理病理意义，均有待进一步认识。

## 三、细胞焦亡

细胞焦亡（pyroptosis）是在机体被感染时发现的。感染引起的单核巨噬细胞死亡依赖 caspase-1，故很长时间以来被定义为 caspase-1 介导的单核细胞死亡，也曾被认为是一种特殊类型的细胞凋亡。直至这种细胞死亡被发现存在炎症因子 IL-1$\beta$ 分泌特征时，才开始认识到这是一种新的细胞死亡方式。

**1. 细胞焦亡表现为细胞溶解的坏死样形态。** 焦亡细胞以细胞肿胀和质膜吹起的大泡为特征。细胞肿胀至细胞膜破裂，细胞内容物流出，表现为坏死样形态，因而细胞焦亡又称细胞炎性坏死。焦亡细胞的染色质表现为轻度凝集，染色质 DNA 有少量断裂，但无 DNA 的完全片段化，细胞核也保持完整。第三节的 ladder 和核碎裂，在这里都缺席。

**2. 细胞焦亡是由细胞内部一类称为 gasdermin（GSDM）的蛋白所介导的调控性细胞死亡。** GSDM 家族有 6 个成员，其中 5 个成员（GSDMA、GSDMB、GSDMC、GSDMD、GSDME）均可以导致细胞焦亡。研究最为充分的是 GSDMD 介导的细胞焦亡。caspase 剪切 GSDMD 解释了细胞渗透压改变和焦亡特征：激活的 caspase-1、caspase-4/5 或 caspase-11 有两类重要的特异性底物。一是 GSDMD，经剪切后释放的 N 端片段具有结合膜脂分子的特性，寡聚化后插入细胞膜，形成特异的孔洞，该孔洞是水进入细胞造成渗透压改变和细胞“胀亡”的原因；二是 IL-1$\beta$ 和 IL-18，剪切产生的活性片段通过 GSDMD 形成的孔洞释放至细胞外，招募炎症细胞，扩大炎症反应。

caspase-1 的激活依赖细胞内的炎症小体（inflammasome）。当细菌、病毒等微生物及细菌毒素进入机体的固有免疫细胞（如单核巨噬细胞）后，细胞内模式识别受体 NLRP（NOD-, LRR- and pyrin domain-containing protein）家族成员如 NLRP3 被激活，NLRP3 通过衔接蛋白 ASC（apoptosis-associated speck-like protein containing a CARD）与 caspase-1 酶原结合，形成含有 caspase-1 的炎症小体，成为 caspase-1 激活的平台。该途径被视为细胞焦亡的经典途径。

与经典途径不同，非经典途径激活的是 caspase-11（小鼠）和 caspase-4/5（人类），而胞内革兰氏阴性菌脂多糖（lipopolysaccharide，LPS）可直接激活这两类 caspase。

:::definition{label="炎症小体"}
炎症小体（inflammasome）是焦亡经典途径中激活 caspase-1 的多聚平台。以 NLRP3 为例：模式识别受体 NLRP3 经衔接蛋白 ASC 招募 caspase-1 酶原。活化的 caspase-1 剪切 GSDMD 和 IL-1$\beta$/IL-18 前体。
:::

:::derivation{label="GSDMD 怎样把感染写成炎性孔"}
1. 微生物或毒素进入巨噬细胞，NLRP3 等被激活。
2. NLRP3–ASC–caspase-1 酶原装配炎症小体，caspase-1 活化（经典途径）；或胞内 LPS 直接激活小鼠 caspase-11 / 人 caspase-4/5（非经典途径）。
3. 这些 caspase 剪切 GSDMD，N 端片段结合膜脂并寡聚打孔。
4. 水经孔内流，细胞肿胀、质膜吹大泡后破裂。
5. 同时剪切 IL-1$\beta$、IL-18 前体，活性细胞因子经 GSDMD 孔释放，招募炎症细胞。
6. 染色质仅轻度凝集，DNA 无完全片段化，核保持完整——这是与凋亡的形态分界。
:::

**3. 细胞焦亡与疾病。** 细胞焦亡作为机体的固有免疫反应，在抗感染中发挥重要作用。事实上，各种病原相关分子、损伤相关分子都可触发细胞内炎症小体的组装，诱发细胞焦亡。因此，除感染性疾病外，细胞焦亡也与心血管疾病、神经系统疾病及肿瘤等有关。

## 四、铁死亡

2003 年研究人员在筛选抗肿瘤药物时发现了一种细胞死亡时胞内活性氧升高、可被铁螯合剂抑制的细胞死亡方式，因此提出了铁依赖的程序性细胞死亡的概念，并将其命名为铁死亡（ferroptosis）。

:::definition{label="铁死亡"}
铁死亡（ferroptosis）是依赖铁离子和脂质过氧化的调控性死亡。过量游离铁经芬顿反应产生大量活性氧，生物膜中多不饱和脂肪酸发生脂质过氧化，膜变薄、完整性和流动性改变，最终造成细胞死亡。它可被铁螯合剂抑制。
:::

**1. 铁死亡是依赖铁离子和脂质过氧化的调控性细胞死亡。** 其特点是细胞内铁离子累积和铁离子流紊乱。过量的铁通过芬顿反应（Fenton reaction）产生大量活性氧，生物膜中多不饱和脂肪酸（polyunsaturated fatty acid）发生脂质过氧化（lipid peroxidation）。

过度的脂质过氧化是铁死亡的重要标志。脂质分子在活性氧或脂质过氧化酶的作用下失去氢原子，导致脂质碳链的氧化、断裂及缩短，改变了多不饱和脂肪酸及磷脂酰乙醇胺这两种生物膜组分的分子构型，导致细胞器膜和质膜变薄，膜的完整性和流动性改变，最终造成细胞死亡。目前认为，以下几种因素在调控铁死亡中起重要作用。

**（1）细胞中的铁代谢。** 铁是生物体必需的营养元素之一，维持机体铁的吸收、运输、利用和储存平衡的相关蛋白质包括转铁蛋白（transferrin）、转铁蛋白受体（transferrin receptor）、铁蛋白（ferritin）和血红素加氧酶。这些调控铁代谢的分子均被证明与铁死亡有关。当细胞内铁代谢异常时，氧化性极强的游离铁过载，会经芬顿反应产生大量活性氧，对 DNA、蛋白质和脂质分子造成氧化损伤，尤其是膜脂质的过氧化作用。

**（2）胱氨酸/谷氨酸反向转运体。** 胱氨酸/谷氨酸反向转运体（Xc$^{-}$ 系统）由催化亚基 SLC7A11 和伴侣亚基 SLC3A2 组成，负责将胱氨酸运输到细胞内，将谷氨酸排出细胞外。进入细胞的胱氨酸作为半胱氨酸前体，经过转化后再合成重要的抗氧化物质谷胱甘肽（glutathione；因还原型谷胱甘肽含有巯基，简称 GSH）。当转运体功能异常时，GSH 合成减少，铁离子过载造成的脂质过氧化诱导了细胞死亡。

**（3）谷胱甘肽过氧化物酶 4（glutathione peroxidase 4，GPX4）。** GPX4 是 GPX–GSH 系统中能够特异性催化过氧化脂质还原的酶。GPX4 缺失的小鼠胚胎成纤维细胞出现了脂质过氧化和铁死亡；高表达 GPX4 能有效抑制铁死亡。

**（4）不依赖 GPX4 的非经典调控机制。** 铁死亡抑制蛋白 1（ferroptosis suppressor protein 1，FSP1）是在 GPX4 缺失的细胞中被筛选出的。FSP1 的 N 端发生豆蔻酰化修饰后可与脂质结合，因其具有辅酶氧化还原酶的活性而起到清除脂质过氧化基团的作用。FSP1 通过还原辅酶 Q10 发挥还原作用的特点与 GPX4 对 GSH 的依赖作用类似，但又互为独立的两个系统，故称为不依赖 GPX4 的铁死亡调控系统。

:::definition{label="Xc- 系统与 GPX4"}
Xc$^{-}$ 系统由 SLC7A11 和 SLC3A2 组成，输入胱氨酸、排出谷氨酸，为 GSH 合成提供半胱氨酸前体。GPX4 利用 GSH 还原过氧化脂质，是铁死亡的经典刹车。FSP1–辅酶 Q10 是另一套不依赖 GPX4 的刹车。
:::

:::cause-effect{title="铁过载怎样把膜脂质写成死因"}
- 因：转铁蛋白/受体、铁蛋白或血红素加氧酶异常，游离铁过载
- 因：Xc$^{-}$ 故障则 GSH 不足，GPX4 无法还原过氧化脂质；FSP1–CoQ10 这套备用刹车若也失效
- 果：芬顿反应产生大量 ROS，多不饱和脂肪酸和磷脂酰乙醇胺过氧化、碳链断裂缩短
- 结果：细胞器膜和质膜变薄、流动性改变，细胞死亡；铁螯合剂或高表达 GPX4 可抑制
:::

**2. 铁死亡的形态改变以线粒体为主。** 主要表现为线粒体双层膜的密度增高，内膜的嵴显著减少或消失，线粒体皱缩。细胞核大小正常且保持完整、染色质未见固缩凝集；细胞膜未见发泡，但膜密度增加。对照第三节：没有新月状核，没有凋亡小体；对照坏死性凋亡和焦亡：没有典型的质膜大泡和迅速胀破。铁死亡把破坏写在线粒体膜和脂相上。

**3. 铁死亡与疾病。** 铁死亡与神经退行性疾病、脏器的缺血再灌注损伤及肿瘤等的发生发展密切相关。例如，在阿尔茨海默病患者的脑切片中发现病灶细胞中铁含量增加、铁代谢蛋白质的基因表达异常、过氧化脂质及其他大分子积累。在帕金森病患者中同样发现铁代谢异常、铁离子增加，患者脑组织的过氧化脂质增多。第一节的 SASP、第三节的 caspase-3 和本节的铁过载，可以写在同一类退行性病灶里，执行器却不是同一台。

:::compare{title="四种其他调控性死亡"}
| 项目 | 坏死性凋亡 | 自噬性细胞死亡 | 细胞焦亡 | 铁死亡 |
|------|------------|----------------|----------|--------|
| 形态 | 肿胀、膜破、内容物外溢、炎症 | 大量自噬囊泡，染色质不凝集 | 肿胀、质膜大泡、溶解性坏死样 | 线粒体皱缩、嵴消失；核完整，膜不发泡 |
| 是否依赖 caspase | 不依赖；caspase-8 被抑制时转向此路 | 不作为定义标准 | 依赖 caspase-1 或 4/5/11 剪切 GSDMD | 不依赖 |
| 核心机器 | 坏死复合体 RIPK1–RIPK3–MLKL | ULK1、Atg5、Atg7、LC3-II（或 GBA1） | 炎症小体 + GSDMD 打孔 | 铁–芬顿反应 + 脂质过氧化 |
| 可逆转的关键干预 | Nec-1 抑制 RIPK1 | 抑制自噬成分后死亡停止 | 干扰炎症小体或 GSDM | 铁螯合剂；GPX4 或 FSP1 |
| 炎症 | 内容物外溢致炎 | 非定义特征 | IL-1$\beta$、IL-18 经孔释放，强炎症 | 非以细胞因子孔为特征 |
| 典型场景 | 缺血再灌注、急性胰腺炎、溃疡性结肠炎 | 果蝇中肠退化；自体死亡见于缺氧缺血和部分化疗 | 感染时巨噬细胞；也见于心血管、神经、肿瘤 | AD/PD、缺血再灌注、抗肿瘤筛选 |
:::

:::concept{term="同一扇 TNF 的门，通向凋亡或坏死性凋亡"}
TNF/FasL 在第三节写成 DISC–caspase-8。本节补了一句：caspase-8 被抑制时，门后站着 RIPK1/RIPK3。不要把“死亡受体”自动翻译成凋亡；先问 caspase-8 还能不能装配。焦亡用的也是 caspase，但切的是 GSDMD 而不是 ICAD，所以核还在、膜已经破了。
:::

第十七章会把干细胞写成组织更新的源头。衰老把增殖停住，死亡把细胞撤走；更新能不能补上，决定个体是维持还是走向老化。四种 RCD 的执行器不同，临床干预的靶点也就不同：Nec-1、自噬抑制剂、GSDMD/炎症小体、铁螯合剂和 GPX4，不能互相顶替。

:::keypoint{label="其他 RCD 看执行器，不看坏死外表"}
- 坏死性凋亡：caspase-8 被卡住后 RIPK1/RIPK3 磷酸化 MLKL，膜被打孔胀破。
- 自噬性死亡：必须证明抑制自噬则不死；看见自噬泡或自噬推动了凋亡/铁死亡都不算。
- 焦亡：炎症小体激活 caspase，GSDMD 打孔，IL-1$\beta$/IL-18 漏出，核仍完整。
- 铁死亡：铁催化脂质过氧化；Xc$^{-}$–GSH–GPX4 和 FSP1–CoQ10 是两套刹车。
- 四条路都可以参与发育或疾病，靶点不能混用。
:::

:::memory{label="本节必背要点"}
- [ ] 程序性坏死/坏死性凋亡：坏死样形态（肿胀、膜破、内容物外溢、炎症），但可被调控；最先见于牛痘病毒感染的猪肾细胞。
- [ ] 不依赖 caspase；Nec-1 抑制 RIPK1 可逆转。
- [ ] TNF/FasL/TRAIL 在 caspase-8 被抑制时不组装 DISC，改为 RIPK1 与 RIPK3 相互磷酸化，催化 MLKL 磷酸化，形成坏死复合体。
- [ ] p-MLKL 结合磷脂酰肌醇、插入并寡聚于膜，Na$^{+}$/K$^{+}$ 和水内流，质膜胀破。IFN、LPS–TLR4、ZBP1 也可激活坏死复合体。
- [ ] 相关：发育；心脑肾缺血再灌注、急性肝损伤、急性胰腺炎、溃疡性结肠炎。
- [ ] 自噬性死亡：曾称 II 型凋亡；现定义为与自噬严格依赖、抑制自噬后不再死亡、且无其他 RCD 参与。
- [ ] 伴随凋亡的自噬泡，或自噬降解铁蛋白/磷酸酶/cIAP2 后再走铁死亡/凋亡，都不属自噬性死亡。
- [ ] 机制：多依赖 ULK1、Atg5、Atg7、LC3-II；也有依赖 GBA1 的非经典途径。
- [ ] 自体死亡：Beclin1 融合肽诱发；核膜卷曲、核周气球样变；依赖 ATG 和 $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-ATP 酶活性增强。
- [ ] 果蝇中肠退化走自噬性死亡，唾液腺同时走凋亡和自噬性死亡；新生大鼠缺氧缺血脑损伤、部分化疗和白藜芦醇处理可见自体死亡或自噬性死亡。
- [ ] 焦亡：曾被当成 caspase-1 介导的单核细胞凋亡；因分泌 IL-1$\beta$ 才被承认为新方式。
- [ ] 形态：肿胀、质膜大泡、内容物流出；染色质轻度凝集，DNA 无完全片段化，核完整。
- [ ] GSDM 家族 6 个成员，5 个可致焦亡；GSDMD 最清楚。caspase-1/4/5/11 切 GSDMD，N 端打孔；同时切 IL-1$\beta$、IL-18，经孔释放。
- [ ] 经典途径：NLRP3–ASC–caspase-1 炎症小体。非经典：胞内 LPS 直接激活鼠 caspase-11、人 caspase-4/5。
- [ ] 焦亡是抗感染固有免疫，也与心血管、神经、肿瘤有关。
- [ ] 铁死亡：2003 年抗肿瘤筛选中发现，ROS 升高且可被铁螯合剂抑制。
- [ ] 芬顿反应 + 多不饱和脂肪酸/磷脂酰乙醇胺过氧化；膜变薄、流动性改变。
- [ ] 铁代谢：转铁蛋白、转铁蛋白受体、铁蛋白、血红素加氧酶。Xc$^{-}$（SLC7A11+SLC3A2）输入胱氨酸以合成 GSH。GPX4 还原过氧化脂质。FSP1 经 CoQ10 构成不依赖 GPX4 的刹车。
- [ ] 铁死亡形态以线粒体为主：双层膜密度增高、嵴减少或消失、线粒体皱缩；核完整不固缩，膜不发泡但密度增加。
- [ ] 相关疾病：AD/PD（铁增加、过氧化脂质积累）、缺血再灌注、肿瘤。
:::
