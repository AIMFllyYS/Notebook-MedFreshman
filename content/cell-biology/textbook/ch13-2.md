# 第二节 细胞周期及其调控

第一节把分裂写成可以看到的形态学：染色体怎么凝集、纺锤体怎么拉、收缩环怎么勒。形态事件并不能自己按时发生。通过细胞周期，细胞完成生长、分裂前 DNA 复制以及细胞分裂。周期演进具有高度精确性：事件的严格时序、遗传物质复制的精确性、分配的均等性。这套规律由复杂的调控系统决定，各种环境因素都可以影响它。本节先给出周期的时间表，再把开关写成 cyclin–Cdk，最后把刹车写成检查点。

:::definition{label="细胞周期"}
细胞周期（cell cycle）是细胞经过一系列生化事件复制其组分、然后一分为二形成两个子细胞的周而复始过程。通常将从一次细胞分裂结束开始，经过物质准备，到下一次细胞分裂结束为止，称为一个细胞周期。
:::

:::definition{label="分裂间期"}
分裂间期（interphase）是两次有丝分裂之间的准备阶段，包括 G1 期、S 期和 G2 期，占据细胞周期 $95\%$ 以上的时间。G1 和 G2 通过合成特定蛋白质、储存能量并增大细胞体积，分别为 DNA 复制和分裂做准备。
:::

## 一、细胞周期的概念

地球上所有生物，从单细胞到哺乳动物，都靠重复的细胞生长和分裂维持生存、保持物种延续。绝大多数真核细胞严格按“间期（G1—S—G2）—M—间期”连续循环。细胞分裂期（M 期）与 DNA 复制合成期（S 期）是两大关键环节（图 13-8）。

同种细胞之间周期长短基本相同，但在不同发育阶段和不同种类细胞中差别很大：芽殖酵母仅约 $90$ 分钟，受精卵早期可能短于 $30$ 分钟。M 期很短，间期占 $95\%$ 以上。就高等生物而言，周期长短主要取决于 G1，而 S、G2 与 M 总体恒定。典型快速增殖的人体细胞周期约 $24$ 小时，其中 G1 约 $11$ 小时、S 约 $8$ 小时、G2 约 $4$ 小时、M 约 $1$ 小时。G1 的长度与该期某些特殊 mRNA 及蛋白质的积累相关。激素、生长因子等环境因素也能影响周期长短；环境温度高于 $39^{\circ}\mathrm{C}$ 或低于 $36^{\circ}\mathrm{C}$ 时，各时相时间将按比例变化。

依据增殖及周期特性，多细胞生物中的细胞群体分为三类。

:::definition{label="周期细胞"}
周期细胞（cycling cell）持续分裂、增殖，细胞周期连续循环，如上皮组织的基底层细胞。
:::

:::definition{label="终末分化细胞"}
终末分化细胞是分化程度高、成熟后不再分裂、周期因此终止的细胞，包括神经元、大量横纹肌细胞、红细胞等。
:::

:::definition{label="G0 期细胞"}
G0 期细胞又称静止细胞（quiescent cell），暂时终止周期、停止分裂，但一旦需要可快速返回正常周期实施增殖。皮肤成纤维细胞和肝实质细胞在替换损伤或死亡细胞时可迅速重新分裂。
:::

:::pitfall{label="G0 不是终末分化，也不是“G1 的延长版”"}
终末分化细胞把周期关掉，通常不再回来；G0 是可逆的休眠，保留返回 G1 并越过限制点的能力。把肝再生写成“神经元那样重新分裂”，或把 G0 写成“G1 多等了几小时”，第三节的补偿性再生和肿瘤复发都接不上。
:::

## 二、细胞周期各期的主要特征

### （一）G1 期是 DNA 复制的准备期

G1 期两大活动是细胞生长，以及为进入 S 期做准备。细胞体积与质量都比上次分裂结束时约增加一倍，物质代谢极为活跃。

**1. 大量 RNA 和蛋白质合成。** 合成 S 期 DNA 复制起始与延伸所需的酶类，如 DNA 聚合酶；也包括 G1 向 S 转换中起重要作用的蛋白质，如触发蛋白、钙调蛋白、细胞周期蛋白、抑素等。

**2. 蛋白质磷酸化。** 组蛋白、非组蛋白及某些蛋白激酶发生磷酸化，促进 G1 晚期染色体结构改变，有利于 S 期 DNA 合成。

**3. 细胞膜物质转运加强。** 氨基酸、核苷酸、葡萄糖等小分子营养物摄入增加；对可能参与 G1→S 转变的调控物质转运也增加。cAMP 含量在 G1 早期迅速增加；$\mathrm{Na}^+$-$\mathrm{K}^+$-ATP 酶活性可短暂升高，使 $\mathrm{K}^+$ 大量流入。

G1 是推动周期演进的始发阶段。它依赖细胞外生长和分裂信号，如相关生长因子。当物质合成足够充足，细胞将通过 G1 晚期的一个特定时相位点：酵母中称为起始点（start），哺乳动物中称为限制点（restriction point，R 点）。一旦通过此点，即使缺少生长因子，细胞仍会进入 S 期并完成后续分裂。

:::definition{label="限制点"}
限制点（restriction point，R 点）是哺乳动物 G1 晚期的承诺位点（酵母中对应起始点）。G1 细胞一旦越过 R 点，不再受生长因子控制，将进入 S 期并完成后续分裂；过不了则脱离周期，成为 G0 细胞。
:::

### （二）S 期中完成 DNA 复制

S 期的主要特征是 DNA 复制，合成组蛋白及非组蛋白等染色质蛋白，并把新合成 DNA 装配成染色质。

进入 S 期时，DNA 聚合酶、DNA 连接酶、胸腺嘧啶核苷激酶、核苷酸还原酶等含量或活性显著增高。复制遵循严格时间顺序：早复制的多为 GC 含量较高的序列，晚复制的 AT 含量较高；常染色质在先，异染色质在后，女性失活的 X 染色体最后复制。

S 期是组蛋白合成的主要时期。进入 S 期后，组蛋白 mRNA 水平可增加 $50$ 倍，新合成的组蛋白迅速入核，与已复制的 DNA 结合，组装成核小体，进而形成具有两条单体的染色体。组蛋白合成与 DNA 复制同步、相互依存：S 期末 DNA 复制完成，组蛋白 mRNA 也在短时间大量降解。羟基脲、阿糖胞苷抑制 DNA 复制时，组蛋白 mRNA 并行降低、组蛋白合成停止；环己亚胺、嘌呤霉素、依米丁抑制组蛋白合成时，DNA 合成速率迅速降低，数秒内停止。S 期组蛋白合成后进一步发生磷酸化、乙酰化、甲基化等修饰，有助于基因转录和染色质凝集。

中心粒复制开始于 G1、完成于 S。相互垂直的一对中心粒彼此分离，各自在垂直方向形成一个子中心粒；所形成的两对中心粒将作为微管组织中心，参与纺锤体和星体微管的形成。

### （三）G2 期是细胞分裂的准备期

G2 期主要为进入 M 期做准备：大量合成与 M 期结构和功能相关的蛋白质，如组装纺锤体必需的微管蛋白，以及对核膜破裂、染色体凝集有重要作用的周期调控因子，尤其是促成熟因子（maturation promoting factor，MPF）。S 期已复制的中心粒在此期体积逐渐增大，开始分离并移向两极。

### （四）M 期中细胞进行分裂

M 期通过分裂把染色体遗传物质平均分配到两个子细胞。形态变化包括染色体凝集后姐妹染色单体分离、核膜崩解与重建、纺锤体形成与消失、收缩环出现与胞质分裂等。第一节已经按时间把这些事件拆开；下面把驱动它们的激酶写出来。

:::concept{term="间期不是“休息”"}
光学显微镜下间期核看起来平静，但 $95\%$ 的周期时间都花在这里：G1 攒够越过 R 点的蛋白，S 把基因组只复制一次，G2 把 MPF 和微管蛋白备齐。把间期理解成停工，会把限制点、预复制复合体和 MPF 全部漏掉。
:::

## 三、细胞周期的调控

周期调控是一个精细复杂的过程，依赖于细胞周期蛋白网络，即细胞周期调控系统。从酵母到人类，这套系统的基本构成高度保守，本质是一系列生化反应的有序发生。它像可靠的分子开关：特定反应在特定周期事件起始时被激活，事件结束时被灭活，使各步在正确的时间、以正确的顺序开始和结束。它也能应答细胞内外信号：细胞外蛋白质或生长因子作用于该系统，实现对周期的多因子、多层次调控。

### （一）细胞周期蛋白与细胞周期蛋白依赖性激酶构成调控系统的核心

细胞周期蛋白（cyclin）为全酶调节亚基，细胞周期蛋白依赖性激酶（cyclin-dependent kinase，Cdk）为催化亚基。不同 cyclin 选择性结合特定 Cdk，结合后 Cdk 呈现激酶活性，再通过磷酸化一系列特定底物，实现不同周期进程及转换。

**1. 细胞周期蛋白。** cyclin 能随周期进程周期性地出现（合成）及消失（降解）。它通过选择性与 Cdk 结合形成复合物，介导 Cdk 激活。

真核 cyclin 是功能相似的同源蛋白，种类多达数十种。酵母中有 Cln1～3、Clb1～6、Cig 等；哺乳动物包括 cyclin A～H 及 cyclin T 等九大类，每大类可含多种蛋白，如三种具有组织及细胞特异性的 cyclin D（D1～D3）。

按出现及发挥作用的阶段，分为四类：①G1 期细胞周期蛋白：cyclin D；②G1/S 期：cyclin E；③S 期：cyclin A；④M 期：cyclin B。

不同 cyclin 分子结构上有一段氨基酸组成保守的细胞周期蛋白框，约 $100$ 个氨基酸残基，介导与 Cdk 结合（图 13-9A）。S 期及 M 期 cyclin 近 N 端还有一段由 $9$ 个氨基酸残基构成的破坏框，介导 cyclin A、B 的快速降解。G1 期周期蛋白虽不具破坏框，但可通过 C 端一段 PEST 序列介导降解。cyclin 的丰度随 G1、S、G2、M 依次起伏，构成后面所有激酶活性的时间表（图 13-9B）。

:::definition{label="细胞周期蛋白"}
细胞周期蛋白（cyclin）是随周期进程周期性合成与降解的调节亚基。其保守的细胞周期蛋白框介导与 Cdk 结合；S/M 期 cyclin 靠破坏框、G1 期 cyclin 靠 PEST 序列被送去降解。
:::

泛素–蛋白酶体途径调控 cyclin 降解（第九章）。参与的 E3 泛素连接酶主要有两类：后期促进复合物（anaphase promoting complex，APC）和 SCF（Skp1–cullin–F-box protein）。活化的 APC（与活化亚基 Cdc20 结合后被激活）把泛素连到 cyclin A、B 破坏框附近的赖氨酸上，再延伸成多聚泛素链，作为蛋白酶体识别和降解的标记；SCF 则把泛素连到 cyclin D、E 上。APC 还可泛素化分离酶抑制蛋白（securin），SCF 还可泛素化某些 CKI（如 p27$^{\mathrm{Kip1}}$）。因此 APC 和 SCF 本身就是周期调控的一部分。

**2. 细胞周期蛋白依赖性激酶。** Cdk 必须与 cyclin 结合才具有激酶活性，通过磷酸化多种周期相关蛋白发挥核心作用。现已鉴定 Cdk1～8。不同 Cdk 都有相似的激酶结构域，其中一小段高保守序列介导与 cyclin 结合。因 cyclin 不断被合成与降解，Cdk 对蛋白质磷酸化的作用也呈周期性变化（表 13-3）。

:::definition{label="细胞周期蛋白依赖性激酶"}
细胞周期蛋白依赖性激酶（Cdk）是一类必须与 cyclin 结合后才具激酶活性的蛋白激酶。它通过磷酸化周期相关蛋白，引发或控制周期的主要事件。
:::

| Cdk | 结合的 cyclin | 主要作用时期 | 作用特点 |
|-----|---------------|--------------|----------|
| Cdk1 | cyclin A | G2 | 促进 G2→M |
| Cdk1 | cyclin B | G2、M | 磷酸化多种有丝分裂相关蛋白，促进 G2→M |
| Cdk2 | cyclin A | S | 启动 DNA 复制，并阻止已复制的 DNA 再复制 |
| Cdk2 | cyclin E | G1 晚期 | 使晚 G1 细胞跨越限制点进入 S |
| Cdk3 | 尚不清楚 | G1 | 有待进一步研究 |
| Cdk4 | cyclin D（D1/D2/D3） | G1 中、晚期 | 使晚 G1 细胞跨越限制点进入 S |
| Cdk5 | 尚不清楚 | 可能与 G0 有关 | 有待进一步研究 |
| Cdk6 | cyclin D（D1/D2/D3） | G1 中、晚期 | 使晚 G1 细胞跨越限制点进入 S |

以 Cdk 为核心的调控系统是周期事件时序性和协调性的根本保证，因此 Cdk 的活性调节就是调控的关键。细胞从多个层面正、反调控 Cdk，主导方式有三种：①与特定 cyclin 结合；②多重磷酸化/去磷酸化修饰；③与 Cdk 抑制因子（CKI）结合。

**（1）与 cyclin 结合是活化的基本条件。** cyclin 结合可通过改变 Cdk 空间构象，暴露底物结合的激酶催化位点，从而部分激活 Cdk。在裂殖酵母中，非磷酸化无活性 Cdk 含一个弯曲的环状区域，称为 T 环，把催化部位入口封闭，阻止底物结合。cyclin 与 T 环强烈相互作用，引起 T 环位移，入口打开，活性位点暴露（图 13-10）。

::figure{src="/images/cell-biology/textbook/p0310_01.png" caption="图13-10 Cdk 与 cyclin 结合。无活性 Cdk 的 T 环封闭催化口袋；结合 cyclin 后 T 环移位、缩回，底物附着位点转向催化部位，Cdk 获得部分活性；完全激活还需要 T 环上特定位点磷酸化。" alt="Cdk无活性、与cyclin结合部分激活、T环磷酸化完全激活三步"}

**（2）多重磷酸化/去磷酸化实现完全激活。** 仅完成 cyclin 结合的 Cdk 活性仍较低。以 Cdk1 为例，完全活化依赖三个残基的修饰：第 $161$ 位苏氨酸（Thr161）、第 $15$ 位酪氨酸（Tyr15）以及第 $14$ 位苏氨酸（Thr14），即活化型磷酸化的加上（Thr161 磷酸化）以及抑制性磷酸化的去除（Tyr15、Thr14 去磷酸化）。

Thr161 位于 T 环上，经 Cdk 激活激酶（Cdk activating kinase，CAK）磷酸化后，复合物与底物的结合能力显著增强，催化活性可提高约 $300$ 倍，故称活化型磷酸化。Tyr15、Thr14 分布于 Cdk 与 ATP 结合部位，由 Wee1/Myt1 等激酶加上抑制性磷酸；必须由 Cdc25 磷酸酶去除后，Cdk 才最终被激活（图 13-11）。因此，Cdk 只有在结合 cyclin 的前提下，再完成 Thr161 磷酸化及 Thr14/Tyr15 去磷酸化，才能被完全激活。

::figure{src="/images/cell-biology/textbook/p0310_02.png" caption="图13-11 多重磷酸化对 Cdk 活性的影响。Cdk1 的 Thr14、Tyr15 磷酸化为抑制性修饰；Thr161 磷酸化增强与底物结合。当 cyclin B 结合、Thr161 被磷酸化且 Thr14/Tyr15 去磷酸化后，Cdk 完全激活。" alt="Cdk1在Thr14、Tyr15和Thr161不同磷酸化状态下的活性"}

**（3）Cdk 抑制因子的负性调节。** G1 期 Cdk 受到严格控制。条件不理想或细胞发生故障（如 DNA 损伤）时，细胞可通过合成 CKI 应激性抑制 Cdk，把细胞阻滞在 G1，防止把错误带入复制和分裂。

:::definition{label="Cdk 抑制因子"}
Cdk 抑制因子（Cdk inhibitor，CKI）是直接抑制 cyclin–Cdk 的负调控蛋白。哺乳动物分为 CIP/KIP 和 INK4 两大家族：CIP/KIP（p21$^{\mathrm{Cip1/Waf1}}$、p27$^{\mathrm{Kip1}}$、p57$^{\mathrm{Kip2}}$ 等）与 cyclin–Cdk 形成三元复合物而抑制活性；INK4（p16$^{\mathrm{INK4}}$、p15$^{\mathrm{INK4}}$、p18$^{\mathrm{INK4}}$ 等）与 Cdk4 或 Cdk6 结合，阻断它们与 cyclin D 结合。
:::

:::derivation{label="Cdk 激活级联"}
1. 特定 cyclin 出现并与对应 Cdk 结合：T 环位移，催化口袋打开，Cdk 获得部分活性。
2. CAK 磷酸化 T 环上的 Thr161，底物亲和显著提高（约 $300$ 倍）。
3. Cdc25 去除 ATP 结合区 Thr14、Tyr15 上的抑制性磷酸（这些磷酸由 Wee1/Myt1 事先加上），Cdk 完全激活。
4. 活化的 cyclin–Cdk 磷酸化该时相的底物，驱动 G1→S、S 期复制、G2→M 或中期→后期。
5. 反向关闭：CKI 结合（G1 为主）；SCF 降解 cyclin D/E；APC 降解 cyclin A/B 并使 securin 消失。cyclin 一旦被蛋白酶体拆掉，该 Cdk 立即失去活性，转换不可逆。
:::

### （二）cyclin–Cdk 复合体对细胞周期的核心调控

cyclin–Cdk 复合物是调控体系的核心，直接掌控各时相有序运转。cyclin 的周期性表达及降解，引发复合物周期性组装及解体，导致不同 Cdk 在特定时相顺序激活。不同 Cdk 的底物不同，磷酸化后的底物作为执行者，引发特定细胞事件，并促成 G1→S、G2→M、中期→后期等关键过程的不可逆转换。

**1. cyclin D–Cdk4/6、cyclin E–Cdk2 顺序启动 G1/S 转化。** 在外界生长因子等促有丝分裂原刺激下，G1 期 cyclin D 表达增强。cyclin D–Cdk4/6 促进细胞生长；积累到一定程度后，活化的 Cdk4/6 磷酸化 Rb 蛋白使其失活，释放被 Rb 抑制的转录因子 E2F。E2F 恢复活性，启动 S 期相关基因转录。G1 晚期 cyclin E 上升，cyclin E–Cdk2 逐渐增多，活化的 Cdk2 进一步激活 E2F（正反馈）及其他转录因子，启动与 DNA 复制相关的基因表达，使细胞跨过限制点，产生 DNA 合成所需的酶与蛋白质（图 13-12）。

::figure{src="/images/cell-biology/textbook/p0311_01.png" caption="图13-12 cyclin E–Cdk2 复合物的形成和 S 期的启动。cyclin D–Cdk4/6 磷酸化 Rb，释放 E2F，启动 S 期基因及 cyclin E、A 转录；cyclin E–Cdk2 正反馈强化 E2F，随后 cyclin A–Cdk2 推动 DNA 合成。" alt="Rb-E2F通路：cyclin D和cyclin E依次释放E2F并进入S期"}

**2. cyclin A–Cdk2 保障 S 期的 DNA 复制。** 进入 S 期后，cyclin D/E 发生降解，cyclin A–Cdk2 成为最主要的复合物。cyclin D/E 降解不可逆，已进入 S 期的细胞无法退回 G1。cyclin A–Cdk2 既能启动 DNA 复制，又能阻止已复制的 DNA 再复制。

**（1）启动 DNA 复制。** 与复制起点结合的蛋白质是一个大的多蛋白复合体，称为起始点识别复合体（origin recognition complex，ORC），并作为许多调节蛋白的连接位点。其中 Cdc6 在大多数周期中呈低水平，但在 G1 早期瞬间升高，与复制起点的 ORC 结合；一组称为 Mcm 的解旋酶也结合上来，形成预复制复合体（pre-replication complex）。cyclin A–Cdk2 磷酸化预复制复合体的某些位点，使之激活，DNA 合成启动；还可通过磷酸化激活其中的 DNA 解旋酶，解离双链，促进 DNA 聚合酶等与单链结合（图 13-13）。

**（2）保障 DNA 只能复制一次。** 复制启动后，cyclin A–Cdk2 使 Cdc6 从 ORC 上解离，预复制复合体去组装，原复制起点不能再次复制。它还可进一步磷酸化组成预复制复合体的蛋白质，导致其降解或向核外转运，阻止在其他起点重新装配。这一作用维持到 G2 及 M 期，直至有丝分裂后期染色单体彼此分离前，DNA 都无法再复制。

::figure{src="/images/cell-biology/textbook/p0312_01.png" caption="图13-13 cyclin A–Cdk 复合物启动 DNA 复制。G1 期 ORC 招募 Cdc6 与解旋酶装配预复制复合体；S 期 Cdk 激活起点、磷酸化并降解 Cdc6，复制叉前行，同时阻止新的预复制复合体在已用过的起点重新装配。" alt="预复制复合体在G1装配、S期被Cdk激活并拆除以保证只复制一次"}

**3. cyclin B–Cdk1 启动 G2/M 转换。** G2 晚期形成的 cyclin B–Cdk1 复合物在促进 G2→M 中起关键作用，该复合物又称为促成熟因子（MPF）。G2 晚期 cyclin B 表达达峰，与 Cdk1 结合并按上面的级联被完全激活，MPF 活性显著升高，细胞进入 M 期。

:::definition{label="促成熟因子"}
促成熟因子（maturation promoting factor，MPF）是 cyclin B 与 Cdk1 组成的异二聚体（亚基分子量分别约 $45\,\mathrm{kDa}$ 和 $32\,\mathrm{kDa}$），能促进 G2 期细胞进入 M 期。它存在于从酵母到哺乳动物的细胞中，是有丝分裂和减数分裂进入 M 期的共同调节剂。
:::

**4. M 期中 cyclin B–Cdk1 的作用。** M 期形态结构变化，以及中期→后期、M 期→下一个 G1 的转换，都与 MPF 相关。

**（1）促进染色质凝集。** 分裂早、中期，MPF 磷酸化组蛋白 H1 上与有丝分裂有关的特殊位点，诱导染色质凝集。它也可直接作用于染色体凝集蛋白：散在的 DNA 结合于磷酸化的凝集蛋白后沿其表面缠绕、聚集，形成超螺旋并凝集。

**（2）促进核膜崩解。** 核纤层蛋白是 MPF 的底物之一。特定丝氨酸残基被高度磷酸化后，核纤层纤维解体，核膜破裂成小泡。

**（3）促进纺锤体形成。** MPF 磷酸化多种微管结合蛋白，调控微管动态变化并重排，促进纺锤体装配。

**（4）促进姐妹染色单体分离。** 中期姐妹染色单体在着丝粒部位依靠粘连蛋白复合体（主要由 Scc1 和 Smc 组成）相连。粘连蛋白被分离酶（separase）分解，是姐妹分开的首要机制。后期前，分离酶与分离酶抑制蛋白（securin）结合而无活性。中期较晚阶段，APC 在 MPF 作用下磷酸化，进而与 Cdc20 结合被激活，引起 securin 多聚泛素化并被降解；分离酶被释放、活化，剪切 Scc1，粘连解体，着丝粒分离，染色单体在微管牵引下移向两极（图 13-14）。

:::definition{label="后期促进复合物"}
后期促进复合物（anaphase promoting complex，APC）是驱动中期向后期转换的 E3 泛素连接酶。MPF 磷酸化 APC 后，APC 与 Cdc20 结合被激活，既泛素化 securin 以释放分离酶，也泛素化 cyclin A、B 以使 MPF 失活。
:::

::figure{src="/images/cell-biology/textbook/p0313_01.png" caption="图13-14 APC 的激活与染色单体的分离。M 期 Cdk 磷酸化 APC，Cdc20 结合后 APC 活化，securin 被多聚泛素化降解，分离酶释放并剪切粘连蛋白复合体的 Scc1，着丝粒松开，细胞进入后期。" alt="APC激活后降解securin，分离酶切开粘连蛋白，姐妹染色单体分离"}

:::derivation{label="APC 驱动后期并结束 M 期"}
1. MPF（cyclin B–Cdk1）磷酸化 APC。
2. 磷酸化的 APC 结合活化亚基 Cdc20，成为有活性的 E3。
3. APC 给 securin 挂多聚泛素链，蛋白酶体降解 securin，分离酶（separase）被释放。
4. 分离酶剪切粘连蛋白复合体中的 Scc1，着丝粒粘连解体；纺锤体把姐妹染色单体拉向两极，后期开始。
5. APC 同时泛素化 cyclin A、B，MPF 解聚失活。组蛋白、核纤层蛋白等被磷酸酶去磷酸化，染色体去凝集，核膜重建，细胞转入末期。
6. MPF 失活后，磷酸酶使肌球蛋白去磷酸化而恢复活性，肌球蛋白与肌动蛋白相互作用，收缩环缢缩，完成胞质分裂。
:::

**（5）MPF 失活促进末期。** 随着后期进程，cyclin B 经多聚泛素化被降解，MPF 解聚失活，细胞转向末期。失去 MPF 后，磷酸化的组蛋白、核纤层蛋白等发生去磷酸化，染色体去凝集，核膜再次组装，子代核逐渐形成。MPF 激酶活性降低也促进胞质分裂：肌球蛋白恢复活性，收缩环不断缢缩直至细胞质分裂。

:::insight{label="经典实验：MPF 的发现"}
20 世纪 60 年代的核移植与细胞融合实验已经提示：把细胞核放进处于有丝分裂不同阶段的细胞中，该核会逐渐适应宿主的行为，说明核的有丝分裂活性由细胞质调节。但当时没有办法直接证明这种胞质因子。

爪蟾卵母细胞体积大，注射后仍能存活，是测验胞质因子的良好体系。卵母细胞减数分裂阻滞在 G2 期（第一次减数分裂前期），用孕酮处理可触发减数分裂恢复，相当于体细胞从 G2 向 M 转换；随后卵母细胞发育并阻滞在第二次减数分裂中期直至受精。Y. Masui 与 C. L. Markert 猜测，孕酮和受精的效应都是因为细胞质发生了变化。他们从经孕酮处理恢复减数分裂的供体卵母细胞中移出胞质，分成不同分量注入未处理的受体卵母细胞。关键结果是：供体经孕酮处理 $6$ 小时或更久后，移出的胞质能诱导受体恢复减数分裂；未经孕酮处理的对照胞质则无影响。把孕酮直接注入受体并不能诱导减数分裂，说明孕酮只在细胞外起作用，通过表面受体激活了胞质内的一种特殊因子。由于卵母细胞减数分裂恢复通常称为成熟，他们将该因子命名为促成熟因子（MPF）。

R. T. Johnson 与 P. N. Rao 用人工方法诱导 M 期及间期 HeLa 细胞融合，无论间期细胞处于周期何种阶段，其核中染色质均出现早熟凝集（premature chromosome condensation，PCC），并能向 M 期转换，说明 M 期细胞中普遍存在促进染色质凝集及有丝分裂的因子。

论文：Masui Y, Markert C L. Cytoplasmic control of nuclear behavior during meiotic maturation of frog oocytes. *J Exp Zool*, 1971, 177(2): 129-145。

后续在体细胞中也发现了 MPF。1988 年研究者从非洲爪蟾卵母细胞中纯化出 MPF，并结合酵母遗传学及海胆胚胎研究，确认它是 cyclin B 与 Cdk1 组成的二聚体。这两类蛋白质大家族的其他成员，在调节周期的其他转换时起类似于 MPF 的作用。MPF 的发现揭示了一种保守存在于所有真核生物的周期调控元件。
:::

### （三）细胞周期检查点监控周期运行

周期在正常条件下按 G1—S—G2—M 顺序运转。进程不可逆，但环境变化或关键事件受干扰时，为确保正确性，可以暂停乃至终止。为防止子细胞出现 DNA 突变，细胞中存在一系列监控系统，对重要事件及故障加以检测，只有当这些事件完成或故障修复后才能进入下一环节。该监控系统即为检查点（checkpoint），包括 DNA 复制检查点、纺锤体组装检查点、染色体分离检查点及 DNA 损伤检查点（图 13-15）。

:::definition{label="细胞周期检查点"}
细胞周期检查点（checkpoint）又称周期检测系统，本质是由众多蛋白质构成的复杂信号转导网络。感受分子（sensor）捕捉异常信号，经转导分子（conductor）传递，由效应分子（effector）执行负性调控：先启动周期阻滞（cell cycle arrest），再动员修复；故障排除后阻滞解除，错误无法纠正（如严重 DNA 双链断裂）则细胞凋亡。
:::

::figure{src="/images/cell-biology/textbook/p0315_01.png" caption="图13-15 细胞周期检查点。1. DNA 复制检查点经 ATR–Chk1 抑制 Cdc25C，拦住 cyclin A/B–Cdk1；2. 纺锤体组装检查点由 Mad2 抑制 APC–Cdc20；3. 染色体分离检查点经 Cdc14 控制 cyclin B 降解和末期；4. DNA 损伤检查点经 ATM/ATR–Chk–p53–p21 及 Cdc25 降解，把细胞挡在 G1、S 或 G2。" alt="四个细胞周期检查点在G1、S、G2、M的作用位置和关键蛋白"}

严格的检查点可最大限度保证遗传稳定；失去检查点的细胞中，基因组高度不稳定，基因扩增、重排、点突变概率增高，可导致肿瘤发生。

**1. DNA 复制检查点。** 正常周期中，DNA 未复制完成时细胞不能进入有丝分裂。该检查点识别未复制 DNA 并抑制 MPF 激活。在裂殖酵母与爪蟾卵提取物中，蛋白激酶 ATR 与 Chk1 有重要作用。复制进行时，ATR 与复制叉结合后被激活，磷酸化激活 Chk1；Chk1 再磷酸化 Cdc25，使其不能去除 M 期 Cdk 上的抑制性磷酸，cyclin A/B–Cdk1 保持被抑制，不能磷酸化启动 M 期的靶蛋白。这一活动持续到所有复制叉上 DNA 合成完成、复制叉解体，从而保证 M 期必须在 DNA 合成结束后才能发生。

**2. 纺锤体组装检查点。** 它阻止纺锤体装配不完全或发生错误的中期细胞进入后期；即使仅有一个染色单体上的动粒未与微管正确相连，后期也不能发生。酵母突变体研究表明，Mad2 是关键蛋白。APC 介导的 securin 多聚泛素化控制中期向后期转化，而 Mad2 抑制 APC 的激活因子 Cdc20。若某一动粒未与微管连接，Mad2 结合于该动粒并短暂激活，附着 Cdc20 使其失活，APC 不能活化，securin 不被降解，着丝粒不能分离。一旦所有动粒均被动粒微管附着，Mad2 脱离并恢复无活性，Cdc20 抑制被解除，APC 活化，启动染色单体分离及向后期转化。

**3. 染色体分离检查点。** 末期各种事件及随后的胞质分裂都需要 MPF 失活。Cdc14 磷酸酶活化能促使 M 期周期蛋白经多聚泛素化降解，导致 MPF 丧失，细胞转向末期。该检查点监测发生分离的子代染色体在后期末的位置，决定是否产生活化的 Cdc14，从而决定能否进入末期、发生胞质分裂并退出 M 期。它阻止在子代染色体未正确分离前发生末期及胞质分裂，保证子代含有一套完整染色体。

**4. DNA 损伤检查点。** DNA 可因外界化学及物理因素被损伤。此时该检查点阻止周期继续，直到损伤被修复。若阻滞在 G1 或 S，受损碱基将不能被复制，可避免基因组突变及染色体结构重排；若阻滞在 G2，可使 DNA 双链断片在有丝分裂以前被修复。

三种肿瘤抑制蛋白在此起关键作用：ATM/ATR、Chk1/2 及 p53。紫外线或射线造成损伤时，检查点激活，Chk2 磷酸化 Cdc25，Cdc25 经多聚泛素化降解；Cdc25 失活导致 Cdk2 不能活化，cyclin E/A–Cdk2 介导的跨越 G1 或 S 的进程不能发生，细胞滞留于 G1 或 S。活化的 ATM/ATR 也能磷酸化并稳定原本极不稳定的 p53，增强其对特定基因转录的促进，其中包括编码 p21$^{\mathrm{Cip}}$ 的基因。产生的 p21$^{\mathrm{Cip}}$ 可抑制哺乳动物几乎所有 cyclin–Cdk，进一步使细胞在 DNA 修复完成以前被阻留在 G1（图 13-16）。

:::cause-effect{title="DNA 损伤怎样把周期写成停或死"}
- 因：紫外线或电离辐射造成 DNA 损伤，ATM/ATR–Chk1/2 被激活
- 因：Cdc25 被磷酸化后降解，Cdk2 无法去抑制性磷酸；同时 p53 稳定，转录 p21，广泛抑制 cyclin–Cdk
- 果：细胞阻滞于 G1、S 或 G2，赢得修复时间
- 结果：修复成功则阻滞解除、周期继续；双链断裂过重则检查点把细胞送去凋亡，避免把突变传给子代
:::

四种检查点的特点归纳如下。

| 检查点 | 作用特点 | 相关主要蛋白质 |
|--------|----------|----------------|
| DNA 复制检查点 | 监控 DNA 复制，决定能否进入 M 期 | ATR、Chk1、Cdc25、cyclin A/B–Cdk1 |
| 纺锤体组装检查点 | 监控纺锤体组装，决定能否进入后期 | Mad2、APC、分离酶抑制蛋白 |
| 染色体分离检查点 | 监控后期末子代染色体位置，决定能否进入末期及胞质分裂 | Tem1、Cdc14、M 期细胞周期蛋白 |
| DNA 损伤检查点 | 监控损伤修复，决定周期是否继续 | ATM/ATR、Chk1/2、p53、Cdc25、cyclin E/A–Cdk2 |

### （四）多种因素与细胞周期调控密切相关

**1. 生长因子。** 生长因子（growth factor）是细胞自分泌或旁分泌产生的多肽，与膜上特异性受体结合后，经信号转换及多级传递，激活多种蛋白激酶，促进或抑制周期相关蛋白表达。G1 早期若缺乏生长因子，细胞不能向 S 转换，进而脱离周期成为 G0。常见的有表皮生长因子（EGF）、血小板衍生生长因子（PDGF）、转化生长因子（TGF）、白介素（IL）等，主要作用阶段在 G1 与 S：刺激或抑制静止期细胞进入 G1 或 S。调节点并不相同：PDGF 一般在 G0→G1；EGF、IL、TGF-$\alpha$、TGF-$\beta$ 在 G1→S。一种细胞可受多种生长因子调控，同一种因子也可作用于多种细胞，且效应随细胞类型而异。就大多数细胞而言，TGF-$\beta$ 抑制分裂，但对少数间质来源细胞（如成骨细胞）却促进分裂。浓度升高或与受体亲和性增强时，调控作用得到促进。第十二章已经把这些因子写成受体后通路；这里只强调它们最终都要落到 G1 的限制点上。

:::definition{label="生长因子"}
生长因子（growth factor）是由细胞自分泌或旁分泌产生的多肽类物质，与膜受体结合后经信号转导改写周期相关蛋白的表达。G1 早期缺乏生长因子，细胞不能向 S 转换而进入 G0。
:::

**2. 抑素。** 抑素（chalone）是细胞自身分泌、能抑制周期进程的糖蛋白，通常分布于其发挥作用的特异性组织中。主要在 G1 期末及 G2 期调节：G1 期抑素又称 S 因子，阻滞 G1 进入 S；G2 期抑素又称 M 因子，抑制 G2 向 M 转变。抑素与膜上特异性受体结合，引起信号转换并影响周期相关蛋白表达，方式与生长因子类似，但效应无毒、可逆，并有较强的细胞系特异性，如红细胞、淋巴细胞、肝细胞、表皮细胞均存在各自的抑素。

:::definition{label="抑素"}
抑素（chalone）是细胞自身分泌的、能抑制周期进程的糖蛋白，具有组织特异性。G1 期末的 S 因子阻滞进入 S 期，G2 期的 M 因子阻滞进入 M 期；作用无毒、可逆。
:::

**3. 胞内信使。** cAMP 与 cGMP 在周期中相互拮抗。cGMP 能促进分裂中 DNA 及组蛋白的合成；cAMP 对分裂有负调控作用，其含量降低时 DNA 合成及分裂将加速。二者数量平衡是维持正常周期的重要因素；cGMP 浓度升高常发生于一些恶性肿瘤细胞中。

**4. RNA 剪接因子。** 真核基因在表达为蛋白质前均需 RNA 剪接。剪接因子 SR 蛋白与 SR 特异激酶（SR protein-specific kinase，SRPK1）已被证实与周期调控相关。

:::note{label="外源信号最终都要改写 cyclin–Cdk"}
生长因子、抑素和 cAMP/cGMP 并不另起一套周期。它们改变的是：G1 能不能攒够 cyclin D/E、CKI 会不会上升、Cdc25 能不能打开 MPF。把“EGF 促进增殖”停在受体那一层，解释不了为什么过了 R 点之后撤掉 EGF，细胞仍然进 S。
:::

:::keypoint{label="周期是一张不可逆的时间表"}
- 时间结构：G1 准备并过 R 点，S 只复制一次，G2 备齐 MPF，M 把基因组交出去。
- 引擎：cyclin 周期性出现，Cdk 被结合、Thr161 磷酸化和 Thr14/Tyr15 去磷酸化三重打开。
- 转换：D–Cdk4/6 和 E–Cdk2 过 G1/S；A–Cdk2 启动并锁定“复制一次”；B–Cdk1（MPF）进 M；APC 打开后期并拆掉 MPF。
- 刹车：四个检查点分别盯复制叉、动粒附着、子染色体位置和 DNA 损伤；修不好就凋亡。
:::

:::memory{label="本节必背要点"}
- [ ] 周期 = 上次分裂结束 → 物质准备 → 下次分裂结束；按 G1—S—G2—M 循环。
- [ ] 间期占 $95\%$ 以上；高等生物周期长短主要取决于 G1。典型人体快速增殖细胞约 $24$ 小时（G1 $11$、S $8$、G2 $4$、M $1$）。
- [ ] 三类群体：周期细胞持续分裂；终末分化细胞不再分裂；G0 静止细胞可返回周期。
- [ ] G1：生长、合成复制酶和调控蛋白、转运加强；R 点（酵母起始点）一过即不依赖生长因子。
- [ ] S：DNA 按 GC 早、AT 晚、常染色质先、失活 X 最后的顺序复制；组蛋白 mRNA 可增 $50$ 倍，与 DNA 复制相互依存；中心粒复制完成于 S。
- [ ] G2：合成微管蛋白和 MPF；中心粒增大并开始分离。
- [ ] cyclin 分四类：D（G1）、E（G1/S）、A（S）、B（M）；共同有周期蛋白框；A/B 靠破坏框、G1 cyclin 靠 PEST 降解。
- [ ] APC 降解 cyclin A/B 和 securin；SCF 降解 cyclin D/E 和部分 CKI。
- [ ] Cdk 完全激活：结合 cyclin → CAK 磷酸化 Thr161（活性升约 $300$ 倍）→ Cdc25 去除 Thr14/Tyr15 抑制性磷酸。
- [ ] CKI：CIP/KIP 形成三元复合物；INK4 阻断 Cdk4/6 与 cyclin D 结合。
- [ ] G1/S：cyclin D–Cdk4/6 磷酸化 Rb，释放 E2F；cyclin E–Cdk2 正反馈，越过限制点。
- [ ] S：cyclin A–Cdk2 激活预复制复合体启动复制，并拆掉 Cdc6 等，保证只复制一次。
- [ ] MPF = cyclin B–Cdk1（约 $45\,\mathrm{kDa}$+$32\,\mathrm{kDa}$），促染色质凝集、核膜崩解、纺锤体形成。
- [ ] APC–Cdc20 降解 securin → 分离酶剪 Scc1 → 姐妹分开；同时降解 cyclin B，MPF 失活进入末期。
- [ ] 1971 年 Masui 与 Markert 用爪蟾卵母细胞胞质移植发现 MPF；孕酮本身注入无效。
- [ ] 四个检查点：复制（ATR–Chk1–Cdc25）、纺锤体组装（Mad2–Cdc20）、染色体分离（Cdc14）、DNA 损伤（ATM/ATR–Chk–p53–p21）。
- [ ] 生长因子主要调 G1/S；PDGF 多在 G0→G1，EGF/IL/TGF 多在 G1→S。TGF-$\beta$ 对多数细胞抑制、对成骨细胞可促进。
- [ ] 抑素：组织特异糖蛋白，S 因子阻 G1→S，M 因子阻 G2→M。
- [ ] cAMP 负调控分裂，cGMP 促进 DNA 和组蛋白合成；肿瘤中 cGMP 常升高。
:::
