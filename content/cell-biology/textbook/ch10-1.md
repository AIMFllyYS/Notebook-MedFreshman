# 第一节 细胞连接

机体的形态建成既是细胞分裂、分化的结果，也是细胞通过表面分子相互识别和黏着的结果。胚胎中的细胞迁移到预定位置后，同一组织内靠特化的膜装置连成整体，不同组织再彼此识别、黏着，进一步装配成器官与系统。细胞连接与细胞黏附就是这套“社会关系”的结构基础。

:::definition{label="细胞连接"}
细胞连接（cell junction）是细胞表面与相邻细胞或细胞外基质相结合的特化区。除结缔组织和血液外，人和多细胞动物的组织细胞普遍借助膜表面蛋白形成连接，以加强机械联系并维持组织结构的完整与协调。
:::

:::definition{label="细胞黏附"}
细胞黏附（cell adhesion）是在细胞识别的基础上，同类细胞聚集形成细胞团或组织的过程，由细胞表面的细胞黏附分子介导。它既可以停留在可逆的分子识别水平，也可以在细胞骨架参与下进一步装配成锚定连接。黏附分子的分类与功能见第二节。
:::

根据结构和功能，细胞连接分为三大类：封闭连接（occluding junction）、锚定连接（anchoring junction）和通讯连接（communicating junction）。脊椎动物的封闭连接只有紧密连接一种；锚定连接再按骨架纤维分成黏着连接与桥粒连接；通讯连接则以间隙连接为主，化学突触也归入此类（表 10-1，图 10-1）。第七章把微丝和中间纤维写成胞质骨架，本章把它们接到邻细胞和基质上；细胞外基质本身将在第十一章展开。

| 功能分类 | 结构分类 | 主要特征 | 主要分布 |
|----------|----------|----------|----------|
| 封闭连接 | 紧密连接 | 相邻质膜形成封闭索，点状接触处间隙消失 | 上皮细胞顶部侧面、脑毛细血管内皮 |
| 锚定连接 | 黏着带 | 肌动蛋白丝参与的细胞–细胞连接 | 上皮细胞（紧密连接下方） |
| 锚定连接 | 黏着斑 | 肌动蛋白丝参与的细胞–细胞外基质连接 | 上皮细胞基底面 |
| 锚定连接 | 桥粒 | 中间纤维参与的细胞–细胞连接 | 心肌细胞、上皮细胞 |
| 锚定连接 | 半桥粒 | 中间纤维参与的细胞–细胞外基质连接 | 上皮细胞基底面 |

:::concept{term="连接是特化装置，黏附是分子识别"}
细胞连接指已经装配好的膜特化区，电镜下能看到封闭索、胞质斑或连接子斑块。细胞黏附强调表面分子谁认谁、黏得住黏不住。同一套钙黏着蛋白既可以只做临时黏着，也可以在黏着带和桥粒里被“焊”进骨架。把两个词当成同义词，后面的分类表就会串行。
:::

## 一、紧密连接

人和其他脊椎动物体内的封闭连接只有一种，即紧密连接（tight junction）。它广泛分布于消化道上皮、膀胱上皮、腺体上皮管腔面的顶端侧面，以及睾丸生精小管支持细胞基部；脑毛细血管内皮细胞之间同样存在紧密连接，是血脑屏障的结构关键。

透射电镜显示，紧密连接处两个相邻质膜以断续的点状结构贴在一起：点状接触部位细胞间隙消失，非接触处仍保留 $10\sim 15\,\mathrm{nm}$ 的间隙。冷冻断裂复型把这一区域显示为“焊接线”样的带状网络，焊接线又称嵴线；扫描电镜可见嵴线由成串排列的穿膜蛋白颗粒构成。相邻细胞膜上的这种特征结构称为封闭索（sealing strand）。封闭索相互交错成网，呈带状环绕每个上皮细胞的顶部，把细胞间隙封起来（图 10-3）。

:::definition{label="紧密连接"}
紧密连接（tight junction）是脊椎动物唯一的封闭连接。相邻质膜借闭合蛋白和密封蛋白在顶部侧面形成封闭索，点状接触处间隙消失，从旁路堵住溶质，并限制膜蛋白与膜脂的侧向扩散，以维持上皮极性。
:::

:::definition{label="封闭索"}
封闭索（sealing strand）是紧密连接区相邻质膜上由成串穿膜蛋白颗粒连成的嵴线。多条封闭索交错成网、环绕上皮细胞顶部，把细胞间隙封闭成带状屏障。
:::

::figure{src="/images/cell-biology/textbook/p0242_01.png" caption="图10-3 紧密连接模式图。A. 相邻质膜上的蛋白颗粒连成封闭索，环绕细胞顶部约 $0.6\,\mu\mathrm{m}$ 的区带；B. 闭合蛋白与密封蛋白均为 4 次穿膜蛋白，胞外环在相邻细胞间成对结合。" alt="紧密连接封闭索呈网状焊接两层质膜，右侧显示闭合蛋白与密封蛋白的四次穿膜拓扑"}

参与紧密连接的蛋白质已逾 40 种，主要是穿膜蛋白和胞质外周蛋白（cytoplasmic peripheral protein）。嵴线中至少有两类 4 次穿膜蛋白：闭合蛋白（occludin）分子量约 $65\,\mathrm{kDa}$；密封蛋白（claudin）分子量较小，约 $20\sim 27\,\mathrm{kDa}$，至少已鉴定 24 种。两类分子的 N 端和 C 端都伸向细胞质，C 端带有与其他紧密连接蛋白结合的区域。胞质外周蛋白包括 PDZ 蛋白、ZO 家族、PATJ、PAR-3 和 PAR-6 等，它们把穿膜蛋白接到细胞骨架上，并募集蛋白激酶、磷酸酶、小 GTP 酶和转录因子，使紧密连接同时成为信号平台。

:::concept{term="封闭索是一条可调节的拉链，不是焊缝"}
闭合蛋白和密封蛋白在相邻细胞间成对咬合，看起来像把两层膜焊死。实际上封闭索的条数、密封蛋白亚型都可以变，旁路通透性因此可调。把紧密连接记成“膜融合”，既解释不了非接触处仍有 $10\sim 15\,\mathrm{nm}$ 间隙，也解释不了炎症时屏障为什么会漏。
:::

紧密连接有两项互相咬合的功能。

**（1）封闭细胞间隙，稳定组织内环境。** 小肠上皮的紧密连接阻止肠腔内容物从细胞旁路进入黏膜。脑毛细血管内皮以及睾丸支持细胞之间的紧密连接，分别构成血脑屏障（blood-brain barrier）和血睾屏障（blood-testis barrier），把异物挡在脑和生精上皮之外。

**（2）限制膜蛋白和膜脂的侧向扩散，维持上皮极性。** 小肠上皮游离面有大量 $\mathrm{Na}^{+}$ 驱动的葡萄糖同向转运载体，基底面则是执行被动运输的葡萄糖载体。葡萄糖必须“顶进底出”。正是紧密连接把两套载体隔在膜的两个区域，吸收才有方向。

:::note{label="血脑屏障和血睾屏障都是紧密连接"}
两道屏障的共同点是内皮或支持细胞顶部侧面的封闭索把旁路封死，而不是另外长出一层“墙”。临床要打开或保护屏障，分子入口往往就是密封蛋白和闭合蛋白的表达与磷酸化，而不是“毛细血管有没有孔隙”这一句话。
:::

:::cause-effect{title="紧密连接破坏如何写成黏膜或神经炎症"}
- 因：活动期炎症性肠病中 ZO-1、闭合蛋白以及密封蛋白-1、密封蛋白-2 表达下降，封闭索不完整
- 果：肠腔细菌和抗原经细胞间隙进入黏膜固有层，激发异常免疫应答
- 因：糖皮质激素维持密封蛋白-1、密封蛋白-5 和闭合蛋白的表达
- 果：脑毛细血管内皮紧密连接得以保持，血脑屏障功能增强
- 结果：同一套封闭装置，在肠是黏膜通透性的开关，在脑是药物与炎症能否入颅的关口
:::

:::pitfall{label="紧密连接封闭的是旁路，不是跨细胞通路"}
葡萄糖、氨基酸仍可经顶端载体进入细胞、再从基底面出去。紧密连接禁止的是“从细胞缝里漏过去”，以及顶端膜蛋白滑到基底面。考试里把“吸收被完全挡住”写成紧密连接的功能，就把跨细胞转运一并删掉了。
:::

## 二、锚定连接

锚定连接是一类由细胞骨架纤维参与、存在于细胞之间或细胞与细胞外基质之间的连接。它广泛分布于人和动物组织，在上皮、心肌和子宫颈等需要承受机械力的部位尤其丰富，作用是形成能够抵抗张力的牢固黏合，并参与器官形态维持、细胞迁移和分化。

按骨架纤维类型，锚定连接分为两大类。肌动蛋白丝参与的称为黏着连接（adhering junction）：细胞与细胞之间是黏着带（adhesion belt），细胞与细胞外基质之间是黏着斑（focal adhesion）。中间纤维参与的称为桥粒连接（desmosome junction）：细胞与细胞之间是桥粒（desmosome），细胞与细胞外基质之间是半桥粒（hemidesmosome）。

锚定连接由两类蛋白搭成（图 10-4）。胞内锚定蛋白（intracellular anchor protein）一端抓住特定骨架纤维（肌动蛋白丝或中间纤维），另一端抓住穿膜黏着蛋白；穿膜黏着蛋白（transmembrane adhesion protein）属于细胞黏附分子，胞外部分再与相邻细胞的同类分子或基质蛋白结合。张力因此从一只细胞的骨架传到邻细胞或基膜，而不是只压在质膜上。

:::definition{label="锚定连接"}
锚定连接（anchoring junction）是由胞内锚定蛋白和穿膜黏着蛋白把细胞骨架接到邻细胞或细胞外基质上的牢固连接。与微丝相连的是黏着带和黏着斑，与中间纤维相连的是桥粒和半桥粒。
:::

::figure{src="/images/cell-biology/textbook/p0243_01.png" caption="图10-4 锚定连接的两类蛋白示意图。胞内锚定蛋白把骨架纤维接到穿膜黏着蛋白的胞质尾；穿膜黏着蛋白在细胞外再与邻细胞的同类分子或基质配体结合。" alt="两个细胞的骨架纤维经胞内锚定蛋白和穿膜黏着蛋白相连，基底面同类装置接到细胞外基质"}

### （一）黏着带位于紧密连接下方，把微丝网连成一体

黏着带是相邻上皮细胞之间的连续带状结构，紧贴在紧密连接下方（图 10-5A）。透射电镜下，此处细胞间隙约 $15\sim 30\,\mathrm{nm}$，两侧质膜伸出的穿膜黏着蛋白在间隙中互相黏合（图 10-5B）。

参与黏着带的穿膜黏着蛋白是钙黏着蛋白（cadherin），一类 $\mathrm{Ca}^{2+}$ 依赖性细胞黏附分子（详见第二节）。它在质膜中形成同源二聚体，相邻细胞的胞外区结成胞间横桥；胞内区则通过锚定蛋白接到肌动蛋白丝上，使细胞间的牵拉力被微丝束网络分担。胞内锚定蛋白包括 $\alpha$、$\beta$、$\gamma$ 联蛋白（catenin），黏着斑蛋白（vinculin，纽蛋白），斑珠蛋白（plakoglobin）和 $\alpha$ 辅肌动蛋白（$\alpha$-actinin）等，它们组装成多分子复合体，专门锚定微丝。

:::definition{label="黏着带"}
黏着带（adhesion belt）是上皮细胞紧密连接下方的带状细胞–细胞锚定连接。钙黏着蛋白在间隙（约 $15\sim 30\,\mathrm{nm}$）中同源结合，胞内经联蛋白等接到肌动蛋白丝，使相邻细胞的微丝网连成可分担张力的整体。
:::

::figure{src="/images/cell-biology/textbook/p0243_03.png" caption="图10-5 小肠上皮细胞间黏着带结构模式图。A. 黏着带位于顶端紧密连接下方，微绒毛内的肌动蛋白丝向下汇入微丝束；B. 钙黏着蛋白二聚体在相邻质膜间成桥，锚定蛋白再把桥接到肌动蛋白丝。" alt="小肠上皮顶端紧密连接下方环绕黏着带，放大显示钙黏着蛋白二聚体与肌动蛋白丝相连"}

黏着带的功能有两条。第一，为上皮和心肌提供抵抗机械张力的牢固黏合，维持细胞形态和组织完整。第二，微丝束可以收缩，在胚胎发育中使上皮片内陷，形成管状或泡状原基，从而参与形态发生。没有这条“可收缩的腰带”，神经管、腺体原基等结构很难从扁平上皮折出来。

:::concept{term="黏着带是一条可收缩的腰带"}
紧密连接负责封缝，黏着带负责把微丝圈成一圈。发育中这圈微丝一收缩，上皮片就会像收口的口袋那样内陷。把黏着带只写成“粘得更牢”，漏掉了它在形态发生中的主动形变角色。
:::

### （二）黏着斑把细胞钉在基质上，并转导存活信号

黏着斑位于上皮细胞基底部，是细胞通过局部黏附与细胞外基质形成的黏着连接。穿膜黏着蛋白是整联蛋白：胞外区结合纤连蛋白、胶原等基质成分，胞内区经锚定蛋白接到肌动蛋白丝上（图 10-6）。常见锚定蛋白有踝蛋白（talin）、$\alpha$ 辅肌动蛋白、纽蛋白（vinculin）和桩蛋白（paxillin）。整联蛋白本身就是纤连蛋白的受体，因此细胞与基质在黏着斑处的结合是受体–配体识别，而不是简单的胶水粘连。

:::definition{label="黏着斑"}
黏着斑（focal adhesion）是细胞基底面与细胞外基质之间的斑点状黏着连接。整联蛋白结合纤连蛋白或胶原，胞内通过踝蛋白、纽蛋白、桩蛋白等接到肌动蛋白丝，并经黏着斑激酶向核内传递生长与存活信号。
:::

::figure{src="/images/cell-biology/textbook/p0244_01.png" caption="图10-6 黏着斑的结构与功能。整联蛋白胞外结合胶原和纤连蛋白，胞内经纽蛋白、踝蛋白、桩蛋白和 $\alpha$ 辅肌动蛋白接到肌动蛋白丝，并可激活黏着斑激酶，把信号传到细胞核。" alt="黏着斑：整联蛋白跨膜连接细胞外基质与肌动蛋白丝，并经黏着斑激酶向核内转导信号"}

黏着斑的功能可归纳为三点。① 在肌细胞与肌腱（主要是胶原）的连接中很常见，把收缩力传到胞外纤维。② 体外培养细胞常靠黏着斑贴在培养基质上，它的形成与解离决定细胞能否铺展和迁移。③ 整联蛋白胞内区结合黏着斑激酶（focal adhesion kinase，FAK）等蛋白激酶；配体结合后激酶被激活，连锁促进与生长、增殖相关基因的转录。细胞“抓得住基质”和“愿不愿意分裂”，在黏着斑被写成同一件事。

:::note{label="黏着斑是可拆的铆钉"}
整联蛋白与配体的亲和力并不高，但分子数量多。低亲和、高密度使细胞可以黏附、分离、再黏附，从而迁移。把黏着斑理解成永久焊点，就无法解释伤口愈合和肿瘤细胞的移动。
:::

### （三）桥粒用中间纤维把组织织成一张网

桥粒连接广泛分布于皮肤、心肌、食管、膀胱、子宫和阴道等承受机械力的上皮，提供支持力并维持组织完整。按位置分为桥粒和半桥粒。

桥粒位于上皮细胞黏着带的下方，是相邻细胞间的斑点状锚定结构，含有桥粒斑（desmosomal plaque）。电镜下，连接处细胞间隙约 $20\sim 30\,\mathrm{nm}$，质膜胞质侧各有一块致密的胞质斑（cytoplasmic plaque），直径约 $0.5\,\mu\mathrm{m}$，由桥粒斑珠蛋白和桥粒斑蛋白（desmoplakin）等锚定蛋白组成，是中间纤维的附着点。成束的中间纤维伸向桥粒斑，被更细的纤维系在斑上，再折返成袢。上皮细胞中主要是角蛋白丝（keratin filament），心肌细胞中则是结蛋白丝（desmin filament）。

桥粒处的穿膜黏着蛋白是桥粒黏蛋白（desmoglein）和桥粒胶蛋白（desmocollin），同属钙黏着蛋白家族。胞内部分连桥粒斑，胞外部分与邻细胞的同类分子结合，依赖 $\mathrm{Ca}^{2+}$ 把两个细胞铆在一起（图 10-7）。相邻细胞的中间纤维由此经桥粒斑和穿膜蛋白连成贯穿整片组织的网架，抗压和抗拉的机械强度明显提高。

:::definition{label="桥粒"}
桥粒（desmosome）是黏着带下方的斑点状细胞–细胞锚定连接。桥粒黏蛋白和桥粒胶蛋白在 $20\sim 30\,\mathrm{nm}$ 间隙中 $\mathrm{Ca}^{2+}$ 依赖结合，胞内经直径约 $0.5\,\mu\mathrm{m}$ 的桥粒斑把角蛋白丝或结蛋白丝锚定成跨细胞的张力网。
:::

::figure{src="/images/cell-biology/textbook/p0245_01.png" caption="图10-7 桥粒的结构。A. 桥粒电镜照片，中间致密、两侧有中间纤维插入；B. 模式图显示桥粒黏蛋白在间隙成桥，胞质斑锚定角蛋白丝。" alt="桥粒电镜呈斑点状致密结构，模式图中角蛋白丝插入胞质斑，桥粒黏蛋白跨越细胞间隙"}

桥粒是一种坚韧的连接。胰蛋白酶、胶原酶、透明质酸酶以及 $\mathrm{Ca}^{2+}$ 螯合剂（如乙二胺四乙酸）都能破坏它，说明其稳定性既依赖蛋白质完整性，也依赖胞外 $\mathrm{Ca}^{2+}$。

临床上，天疱疮（pemphigus）是针对桥粒穿膜黏着蛋白的自身免疫病：抗体破坏桥粒后，上皮细胞彼此分离，组织液经细胞间隙进入表皮，形成严重的表皮内水疱。家族性良性天疱疮（Hailey-Hailey 病）则与桥粒斑组分被内化、分子破坏以及桥粒数量减少有关。

### （四）半桥粒把上皮铆在基膜上

半桥粒是上皮细胞基底面与基膜之间的连接，因形态上像桥粒的一半而得名。它看起来像桥粒，分子组成和功能却不同。胞质斑由网蛋白（plectin）等锚定蛋白组成，连接细胞内的中间纤维。穿膜黏着蛋白是整联蛋白 $\alpha_6\beta_4$ 或穿膜蛋白 BP180，再通过一种特殊的层粘连蛋白（锚定纤维）连到基膜，把细胞铆住。整联蛋白同时还把基质信号传向胞内，影响上皮的形状和活性（图 10-8）。

:::definition{label="半桥粒"}
半桥粒（hemidesmosome）是上皮基底面与基膜之间的锚定连接。网蛋白组成胞质斑并抓住中间纤维，整联蛋白 $\alpha_6\beta_4$ 或 BP180 经层粘连蛋白锚定纤维连到基膜，防止上皮被机械力撕离。
:::

::figure{src="/images/cell-biology/textbook/p0246_01.png" caption="图10-8 半桥粒的结构。A. 基底面半桥粒电镜照片；B. 中间纤维经桥粒斑和整联蛋白 $\alpha_6\beta_4$ 连到层粘连蛋白及 Ⅶ 型胶原纤维，从而固定于基膜。" alt="半桥粒电镜位于上皮基底面，模式图显示中间纤维经整联蛋白接到基膜的层粘连蛋白和胶原"}

半桥粒的核心功能是防止机械力把上皮从下方组织揭走。大疱性类天疱疮（bullous pemphigoid）患者体内的抗体破坏半桥粒，表皮基底层细胞脱离基膜，组织液渗入表皮下空间，引起表皮下水疱。层粘连蛋白或整联蛋白 $\alpha_6$、$\beta_4$ 基因突变可引起大疱性表皮松解症（epidermolysis bullosa），症状与类天疱疮相似，但病因在基因而不在自身抗体。

:::pitfall{label="半桥粒不是“砍成两半的桥粒”"}
名字像，构件完全不是一套。桥粒用钙黏着蛋白家族（桥粒黏蛋白、桥粒胶蛋白）连邻细胞，半桥粒用整联蛋白 $\alpha_6\beta_4$ 连基膜；一个抓中间纤维对着细胞，一个抓中间纤维对着基质。天疱疮打的是桥粒，水疱在表皮内；类天疱疮打的是半桥粒，水疱在表皮下。位置差一层，病就不是同一种。
:::

:::cause-effect{title="自身抗体打在哪一层，水疱就起在哪一层"}
- 因：天疱疮抗体针对桥粒穿膜黏着蛋白，细胞–细胞铆钉脱落
- 果：组织液进入表皮细胞间隙，形成表皮内水疱
- 因：类天疱疮抗体破坏半桥粒，细胞–基膜铆钉脱落
- 果：基底层脱离基膜，组织液进入表皮下空间
- 结果：两种“疱”看起来都是皮肤起泡，解剖层面和靶分子并不相同
:::

## 三、通讯连接

大多数组织的相邻细胞膜上还有专门传递电信号和化学信号的装置，使一群细胞能够合作、协调，这类结构称为通讯连接。它除了提供一定的机械联系，更重要的是形成代谢耦联或电耦联。动物组织中，细胞间通讯主要由间隙连接（gap junction）介导；神经元之间或神经元与效应细胞之间的化学突触也属于通讯连接。

:::definition{label="通讯连接"}
通讯连接（communicating junction）是相邻细胞间传递电信号或化学信号的特化连接，主要包括间隙连接和化学突触。间隙连接形成代谢耦联与电耦联；化学突触则把电信号转成神经递质，再在突触后转回电信号。
:::

### （一）间隙连接几乎遍布动物组织

间隙连接是相邻细胞的连接子相对接、形成微小通道的连接方式。除骨骼肌细胞和血细胞外，几乎所有动物组织都用它通讯。透射电镜下，连接部位两层膜之间有 $2\sim 4\,\mathrm{nm}$ 的缝，因此也称缝隙连接。

基本结构单位是连接子（connexon）。每个连接子长约 $7.5\,\mathrm{nm}$、外径约 $6\,\mathrm{nm}$，由 6 个相同或相似的穿膜连接子蛋白——连接子蛋白（connexin，Cx）环绕而成，中央是直径 $1.5\sim 2.0\,\mathrm{nm}$ 的亲水通道。相邻质膜上的两个连接子对接到一起，细胞质便经中央通道相通。冷冻蚀刻显示，许多间隙连接单位常集结成斑块，单位面积内可有几个到数百个连接子（图 10-9）。

:::definition{label="连接子"}
连接子（connexon）是间隙连接的基本单位，由 6 个连接子蛋白围成，长约 $7.5\,\mathrm{nm}$、外径约 $6\,\mathrm{nm}$，中央亲水通道直径 $1.5\sim 2.0\,\mathrm{nm}$。相邻细胞各出一个连接子相对接，两个细胞的胞质即经此连通。
:::

::figure{src="/images/cell-biology/textbook/p0247_01.png" caption="图10-9 间隙连接的结构。A. 质膜横切面显示大小不等的间隙连接斑；B. 冷冻蚀刻显示连接子成片分布；C. 三维结构示 $2\sim 4\,\mathrm{nm}$ 缝隙和直径约 $1.5\,\mathrm{nm}$ 的通道；D. 6 个连接子蛋白围成同源或异源连接子。" alt="间隙连接电镜与冷冻蚀刻呈斑块，模式图显示六聚体连接子对接形成亲水通道"}

已从不同动物和组织中鉴定出 20 余种连接子蛋白，同属一个家族，都有 4 个保守的 $\alpha$ 螺旋穿膜区，分子量可以相差很大。一个连接子可由相同蛋白构成同源连接子，也可由不同蛋白构成异源连接子。异源连接子在通透性、导电率和可调性上并不相同，分布也有组织特异性。例如心肌工作细胞主要用 Cx43，心脏传导系统细胞主要用 Cx40；这两种蛋白形成的间隙连接没有通透功能，从而保证两类细胞的电活动相对独立。

:::concept{term="对接不等于一定相通"}
两个连接子对上了，通道却可能是“哑”的。Cx43 与 Cx40 的组合就是心脏用来隔离工作心肌和传导系统的分子闸门。看见“有间隙连接”不要直接写成“离子一定能过去”——还要问是哪一种连接子蛋白。
:::

间隙连接的主要功能是介导细胞通讯，方式有代谢耦联（metabolic coupling）和电耦联（electric coupling）两种。

**（1）代谢耦联。** 分子量小于 $1\,\mathrm{kDa}$ 的代谢物和信号分子可经连接子在相邻细胞间传递，如无机离子、单糖、氨基酸、核苷酸、维生素、$\mathrm{cAMP}$ 和三磷酸肌醇（$\mathrm{IP}_3$）。细胞因此共享小分子、协调群体活动。这一功能在胚胎发育早期特别重要：血液循环建立以前，同一发育区的细胞靠代谢耦联把物质分配均匀，以控制分化；细胞开始分化时与周围组织解耦联，但群内仍互相耦联，以保持发育行为一致。

间隙连接的通透性可调节。细胞受损、大量 $\mathrm{Ca}^{2+}$ 进入时，间隙连接关闭，避免损伤信号灌进邻居。胞外化学信号也能调：胰高血糖素作用于肝细胞使 $\mathrm{cAMP}$ 升高，激活依赖 $\mathrm{cAMP}$ 的蛋白激酶，连接子蛋白磷酸化后构象改变、通透性增加，$\mathrm{cAMP}$ 迅速扩散到周围肝细胞，使一群肝细胞共同应答。

**（2）电耦联。** 也称离子耦联（ionic coupling）。连接子是离子通道，带电离子能把电信号传到邻细胞。兴奋性组织广泛依赖这一机制：电耦联使心肌同步收缩与舒张，连接破坏则心脏停跳；成年动物中仅少数平滑肌直接受神经支配，大多数平滑肌的兴奋靠间隙连接传导，小肠平滑肌因此能同步收缩和蠕动。

**（3）机械加固。** 相邻质膜内连接子颗粒互相融合，也加强了细胞间的机械联系。

:::cause-effect{title="损伤细胞如何被间隙连接隔离"}
- 因：细胞膜破损，$\mathrm{Ca}^{2+}$ 大量涌入
- 因：高 $\mathrm{Ca}^{2+}$ 使连接子关闭
- 果：离子、代谢物和凋亡信号不再灌入邻细胞
- 结果：损伤被局限；反过来，胚胎和肝小叶需要共享信号时，通道必须保持可调的开放
:::

:::note{label="肿瘤细胞往往把间隙连接拆掉"}
间隙连接在胚胎中为细胞提供“位置信息”，破坏可导致发育缺陷。肿瘤细胞之间的间隙连接显著减少或消失，Cx43 等连接子蛋白表达下降。群体一旦解耦联，接触抑制和代谢协调都会削弱，这是肿瘤生物学里反复出现的表型，而不是电镜下的偶然发现。
:::

### （二）突触把神经冲动写成化学或电的语言

神经元之间或神经元与效应细胞（如肌细胞）之间通过突触（synapse）传递神经冲动。突触分为电突触（electronic synapse）和化学突触。电突触就是细胞间的间隙连接，电冲动可直接从突触前传到突触后（图 10-10），速度快、方向精确。化学突触的突触前、后膜之间有约 $20\,\mathrm{nm}$ 的间隙，电信号过不去，必须先把电信号写成神经递质，再在突触后写成新的电信号：冲动到达轴突末端，递质小泡释放，递质作用于突触后细胞。这种传递慢于电突触。电突触对某些无脊椎动物和鱼类的快速逃避反射尤为重要。

:::definition{label="突触"}
突触（synapse）是神经元之间或神经元与效应细胞之间的通讯连接。电突触即间隙连接，离子电流直接过细胞；化学突触前、后膜相距约 $20\,\mathrm{nm}$，必须经神经递质把电信号转换成化学信号再转回电信号。
:::

::figure{src="/images/cell-biology/textbook/p0247_03.png" caption="图10-10 电突触结构示意图。A. 两个神经元在接触区形成电突触；B. 接触区的间隙连接由成排连接子对接而成，电流可直接通过。" alt="电突触接触区排列多个连接子，使突触前电流直接进入突触后细胞"}

:::concept{term="化学突触慢在换语言，电突触快在不换语言"}
化学突触多了“电→化学→电”两道翻译，可做兴奋或抑制，也便于整合许多输入；电突触几乎是瞬时的电流短路，适合同步放电和逃避反射。教材把化学突触放进通讯连接，是因为它在功能上完成细胞间信号传递，不要因为它没有连接子就把它从本章删掉。
:::

:::compare{title="紧密连接 vs 黏着带 vs 桥粒 vs 间隙连接"}
| 项目 | 紧密连接 | 黏着带 | 桥粒 | 间隙连接 |
|------|----------|--------|------|----------|
| 功能分类 | 封闭连接 | 锚定连接 | 锚定连接 | 通讯连接 |
| 典型位置 | 上皮顶部侧面 | 紧密连接正下方 | 黏着带下方；心肌 intercalated disc | 斑块状，除骨骼肌和血细胞外几乎各组织 |
| 细胞间隙 | 点状接触处消失，其余约 $10\sim 15\,\mathrm{nm}$ | 约 $15\sim 30\,\mathrm{nm}$ | 约 $20\sim 30\,\mathrm{nm}$ | 约 $2\sim 4\,\mathrm{nm}$，通道直径 $1.5\sim 2.0\,\mathrm{nm}$ |
| 穿膜蛋白 | 闭合蛋白、密封蛋白 | 钙黏着蛋白 | 桥粒黏蛋白、桥粒胶蛋白 | 连接子蛋白（6 个围成连接子） |
| 胞内锚定 | ZO 等外周蛋白，连向微丝 | 联蛋白、纽蛋白、$\alpha$ 辅肌动蛋白 | 桥粒斑蛋白、斑珠蛋白 | 一般不借骨架做主承力 |
| 相连骨架 | 间接连肌动蛋白 | 肌动蛋白丝 | 中间纤维（角蛋白丝或结蛋白丝） | 无典型骨架锚定 |
| 核心功能 | 封闭旁路、维持极性 | 抗拉、发育中收缩成管/泡 | 把中间纤维网织成整片组织 | 代谢耦联与电耦联 |
| 典型医学 | 肠屏障、血脑屏障 | 形态发生异常 | 天疱疮（表皮内水疱） | 心肌不同步、肿瘤解耦联 |
:::

黏着斑和半桥粒不在上表：它们是细胞–基质的锚定，穿膜蛋白都是整联蛋白，分别抓微丝和中间纤维。把四类细胞–细胞连接记熟后，再把基底面的两颗“钉子”补上，整张上皮的力学和通透图就齐了。

:::keypoint{label="三种连接，三条任务"}
- 封闭连接（紧密连接）封旁路、锁极性，封闭索由闭合蛋白和密封蛋白织成。
- 锚定连接把骨架接到邻细胞或基质：微丝走黏着带/黏着斑，中间纤维走桥粒/半桥粒。
- 通讯连接让小分子和电流过细胞：间隙连接是连接子通道，化学突触则换语言传递。
- 自身抗体打桥粒起表皮内疱，打半桥粒起表皮下疱；不要靠“都是水疱”混为一谈。
:::

:::memory{label="本节必背要点"}
- [ ] 细胞连接是细胞表面与邻细胞或细胞外基质结合的特化区；除结缔组织和血液外普遍存在。
- [ ] 三大类：封闭连接（紧密连接）、锚定连接（黏着带/黏着斑、桥粒/半桥粒）、通讯连接（间隙连接、化学突触）。
- [ ] 紧密连接：封闭索环绕上皮顶部；点状接触处间隙消失，非接触处约 $10\sim 15\,\mathrm{nm}$。
- [ ] 闭合蛋白（occludin，约 $65\,\mathrm{kDa}$）和密封蛋白（claudin，约 $20\sim 27\,\mathrm{kDa}$，至少 24 种）均为 4 次穿膜蛋白；ZO、PAR 等外周蛋白连接骨架并募集信号分子。
- [ ] 紧密连接两大功能：封闭旁路（血脑屏障、血睾屏障）；限制膜蛋白/膜脂侧向扩散，维持极性（小肠顶端 $\mathrm{Na}^{+}$–葡萄糖同向转运 vs 基底面被动转运）。
- [ ] 活动期炎症性肠病中 ZO-1、闭合蛋白、密封蛋白-1/2 下降，肠屏障泄漏。
- [ ] 锚定连接 = 胞内锚定蛋白 + 穿膜黏着蛋白；微丝 → 黏着连接，中间纤维 → 桥粒连接。
- [ ] 黏着带：紧密连接下方，间隙 $15\sim 30\,\mathrm{nm}$，钙黏着蛋白 + 联蛋白/纽蛋白/$\alpha$ 辅肌动蛋白 + 肌动蛋白丝；可收缩，参与上皮内陷成管/泡。
- [ ] 黏着斑：基底面，整联蛋白结合纤连蛋白/胶原，经踝蛋白、纽蛋白、桩蛋白接微丝，并可激活 FAK。
- [ ] 桥粒：黏着带下方斑点，间隙 $20\sim 30\,\mathrm{nm}$，胞质斑直径约 $0.5\,\mu\mathrm{m}$；桥粒黏蛋白/桥粒胶蛋白 + 角蛋白丝（上皮）或结蛋白丝（心肌）。
- [ ] 天疱疮：抗桥粒穿膜蛋白抗体 → 表皮内水疱。EDTA、蛋白酶可破坏桥粒。
- [ ] 半桥粒：形态像桥粒一半，但是整联蛋白 $\alpha_6\beta_4$ 或 BP180 + 网蛋白 + 层粘连蛋白，连的是基膜。
- [ ] 类天疱疮：抗半桥粒抗体 → 表皮下水疱；$\alpha_6/\beta_4$ 或层粘连蛋白突变 → 大疱性表皮松解症。
- [ ] 连接子：6 个连接子蛋白，长 $7.5\,\mathrm{nm}$、外径 $6\,\mathrm{nm}$、通道 $1.5\sim 2.0\,\mathrm{nm}$；膜间隙 $2\sim 4\,\mathrm{nm}$。除骨骼肌和血细胞外几乎都有。
- [ ] 代谢耦联：允许 $<1\,\mathrm{kDa}$ 分子（离子、糖、氨基酸、核苷酸、$\mathrm{cAMP}$、$\mathrm{IP}_3$）共享；高 $\mathrm{Ca}^{2+}$ 关闭通道。电耦联使心肌和平滑肌同步。
- [ ] Cx43（工作心肌）与 Cx40（传导系统）形成的间隙连接无通透功能。肿瘤细胞间隙连接减少，Cx43 下降。
- [ ] 电突触 = 间隙连接，快而方向精确；化学突触间隙约 $20\,\mathrm{nm}$，需神经递质，速度较慢。
