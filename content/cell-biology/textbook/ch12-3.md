# 第三节 细胞内受体介导的信号转导

第一节把亲脂性信号分子和气体性信号分子写成可以穿过质膜的第一信使。它们不在细胞表面排队，而是入胞后认细胞内受体，或直接激活胞内效应酶。本节把这两条路拆开：一条是核受体改写转录，一条是 NO 这类气体分子在局部快速改写 cGMP。

:::definition{label="细胞内受体"}
细胞内受体位于细胞质或细胞核基质中。由于细胞质受体结合相应配体后也转位入核，因此细胞内受体也称为核受体（nuclear receptor，NR）。其本质是依赖激素激活的基因调控蛋白，主要识别类固醇激素、甲状腺素、维生素 D 和视黄酸等小的亲脂性信号分子。
:::

:::definition{label="核受体"}
核受体（nuclear receptor）是细胞内受体的统称，包括糖皮质激素受体、盐皮质激素受体、雄激素受体、雌激素受体等类固醇激素受体以及甲状腺素受体。人类核受体家族有数十个成员，调控细胞生长与分化，并与糖尿病、脂肪肝等疾病的发生发展密切相关。
:::

## 一、细胞内受体及其对基因表达的调控

细胞内受体有相似的高级结构：C 端是激素结合域，可与激素结合；中央区是 DNA 结合域；N 端是调节区，也是受体转录激活区之一。受体有活性和非活性两种状态。通常与细胞内抑制性蛋白结合形成复合物，处于非活化状态。激素与受体结合形成激素–受体复合物，导致抑制性蛋白从复合物上解离，使受体暴露 DNA 结合位点而被激活。

:::definition{label="激素应答元件"}
激素应答元件（hormone response element，HRE）是受激素调节的基因上的特殊 DNA 序列。活化的激素–受体复合物进入细胞核，与靶基因 HRE 结合，影响基因转录。
:::

::figure{src="/images/cell-biology/textbook/p0291_01.png" caption="图12-19 类固醇激素激活靶基因表达的途径。A. 未活化受体：N 端转录激活域、中央 DNA 结合域和 C 端配体结合域被抑制蛋白占据；B. 配体结合后抑制蛋白解离，辅助激活蛋白加入，受体结合 DNA 上的受体结合元件（HRE），启动靶基因转录。" alt="未活化核受体被抑制蛋白封闭；配体结合后受体结合HRE并募集辅助激活蛋白启动转录"}

细胞核受体通过 3 种基本作用模式调节基因转录：

**① 直接结合 HRE。** 核受体受到亲脂性信号分子激活后，结合到靶基因 HRE 序列，调节转录。这是最经典的写法。

**② 通过其他转录因子。** 核受体被亲脂性信号分子激活后，影响其他转录因子，再由这些因子与靶基因调控序列结合，调节转录。受体自己不一定坐到 DNA 上。

**③ 被膜受体或 CDK 激活。** 核受体被细胞表面受体或周期蛋白依赖性激酶（CDK）激活，再与靶基因结合，调节转录。这条路把膜信号和核受体接到一起，说明“脂溶性激素专管转录、膜受体专管代谢”不是绝对分界。

类固醇激素诱导的基因活化通常分为两个阶段。一是快速的初级反应阶段，直接激活特殊靶基因转录；二是延迟的次级反应阶段，初级反应的基因产物再激活其他基因转录，对初级反应起放大作用。把核受体只写成“开一个基因”，解释不了为什么激素效应会分两波出现。

:::concept{term="核受体是配体门控的转录因子"}
离子通道耦联受体用配体开门放离子；核受体用配体开门放 DNA 结合面。抑制蛋白相当于插在 DNA 结合域上的销子，激素把它拔掉。HRE 是基因上留给这块受体的停机坪。把核受体记成“激素的载体”，会漏掉它本身就是转录装置的一部分。
:::

:::pitfall{label="胞质受体不是另一套系统"}
糖皮质激素受体等先停在胞质里，配体一到就转位入核，所以教材把它们和本来就在核内的受体统称为核受体。考试里把“胞质受体”和“核受体”写成并列的两大类，会把转位这一步丢掉，也和第一节的分类打架。
:::

:::cause-effect{title="激素如何把抑制复合物改写成转录装置"}
- 因：未活化核受体与抑制性蛋白形成复合物，DNA 结合位点被遮住
- 因：亲脂性激素穿过质膜，结合 C 端激素结合域，抑制蛋白解离
- 果：受体暴露 DNA 结合位点，与靶基因 HRE 结合，并可募集辅助激活蛋白
- 结果：初级反应基因先被转录，其产物再放大次级反应；生长、分化和代谢基因被成套改写
:::

## 二、气体信号分子激活的信号通路

近些年发现，一些气体分子具有细胞内信号传递的信使作用。一氧化氮（NO）是这个领域的重要发现，特别是其在血管扩张机制及心、脑血管疾病治疗中的研究，引起广泛重视。

人们多年前就知道乙酰胆碱通过引起平滑肌松弛而舒张血管。1980 年 R. Furchgott 提出，血管舒张是因为血管内皮细胞产生一种信号分子，引起血管平滑肌松弛。随后 R. Furchgott 和 Louis Ignarro 证实，引起血管平滑肌松弛的信号分子是 NO。他们因此获得 1998 年诺贝尔生理学或医学奖。

:::definition{label="一氧化氮"}
一氧化氮（NO）是具有自由基性质的脂溶性气体分子，作为局部介质在许多组织中发挥作用。循环系统的 NO 由血管内皮细胞合成和释放。内皮细胞含 NO 合酶（NOS），催化 L-精氨酸生成 NO。NO 没有专门的储存及释放调节机制，生成后透过细胞膜快速扩散，作用于邻近靶细胞；因此作用于靶细胞的 NO 量直接取决于合成速率。
:::

血管内皮细胞受到外界因子（如乙酰胆碱、组胺等神经递质）的刺激后生成 NO，并释放扩散到邻近的平滑肌细胞，与平滑肌细胞内鸟苷酸环化酶（G-cyclase，GC）结合，激活其活性，催化 cGMP 生成。cGMP 的结构与功能类似于 cAMP，活化 cGMP 依赖性蛋白激酶 G（PKG）；PKG 启动一系列生化反应，导致血管平滑肌细胞迅速松弛，血管舒张（图 12-20）。

::figure{src="/images/cell-biology/textbook/p0292_01.png" caption="图12-20 NO 促进血管平滑肌细胞松弛。内皮细胞内 Ca²⁺ 升高激活 NOS，以精氨酸为底物生成 NO；NO 扩散进入平滑肌，激活 NO 受体（鸟苷酸环化酶），使 GTP 生成 cGMP，再激活 PKG，引起舒张。" alt="内皮NOS催化精氨酸生成NO，扩散入平滑肌经cGMP-PKG引起舒张"}

:::derivation{label="NO 舒血管的信号链"}
1. 乙酰胆碱、组胺等刺激血管内皮细胞，胞内 $\mathrm{Ca}^{2+}$ 升高。
2. $\mathrm{Ca}^{2+}$ 激活 NOS，催化 L-精氨酸生成 NO。
3. NO 作为脂溶性自由基，立即扩散出内皮、进入邻近平滑肌，没有储存库可调节。
4. NO 结合并激活平滑肌细胞内的可溶性鸟苷酸环化酶，GTP → cGMP。
5. cGMP 激活 PKG，PKG 改写下游靶蛋白，平滑肌迅速松弛，血管舒张。
6. 信号随 NO 失活和 cGMP 被磷酸二酯酶降解而终止。

临床上硝酸甘油在体内转变为 NO，扩张心脏血管、改善心肌供氧；西地那非阻断 cGMP 降解，延长这条通路的开启时间。
:::

NO 也由许多神经细胞产生并传递信号，在大脑的学习记忆过程中具有重要作用。大脑海马某些区域在受到重复刺激后可产生一种持续增强的突触效应，称为长时程增强（long-term potentiation，LTP），是学习和记忆的分子基础。LTP 的产生涉及神经元间突触连接重构：既需要突触前神经元释放神经递质作用于突触后膜，也需要突触后神经元将信息反馈到突触前膜。NO 作为 LTP 的逆行信使弥散至突触前末梢，刺激谷氨酸递质不断释放，从而对 LTP 效应的维持起促进作用。

:::compare{title="核受体通路 vs NO 气体通路"}
| 项目 | 核受体（类固醇激素等） | NO 气体通路 |
|------|------------------------|-------------|
| 信号分子性质 | 亲脂性小分子（类固醇、甲状腺素、维生素 A/D、视黄酸） | 脂溶性自由基气体 |
| 是否储存 | 内分泌腺合成后释放入血 | 不储存，生成即扩散，量取决于 NOS |
| 受体本质 | 配体激活的基因调控蛋白（核受体） | 平滑肌内可溶性鸟苷酸环化酶 |
| 直接产物 | 激素–受体复合物结合 HRE | cGMP，再激活 PKG |
| 时间尺度 | 以转录、翻译为主，偏慢反应；可分初级和次级两波 | 平滑肌松弛为快反应；LTP 中作为逆行信使 |
| 空间范围 | 可经血液到达远距靶器官 | 局部旁分泌，作用于邻近细胞 |
| 临床相关 | 糖尿病、脂肪肝等与核受体家族相关 | 硝酸甘油扩冠；西地那非延长 cGMP；LTP 与学习记忆 |
:::

:::note{label="气体信使仍要落到第二信使上"}
NO 自己可以扩散进细胞，看起来跳过了膜受体，但在平滑肌里它仍然通过 cGMP 这个第二信使工作。第一节把 NO、CO 写成“直接激活效应酶、产生 cGMP”，指的就是这一步。不要把“气体入胞”理解成“不再需要下游信号”。
:::

:::keypoint{label="入胞信号有两条时间线"}
- 核受体是配体门控的转录因子：激素拔掉抑制蛋白，受体坐到 HRE 上。
- 基因活化分初级反应和次级放大，不是只开一个启动子。
- NO 由内皮 NOS 现产现用，扩散到平滑肌，经 GC–cGMP–PKG 写成舒张。
- 同一分子 NO 在突触里还可以当逆行信使，维持 LTP。
:::

:::memory{label="本节必背要点"}
- [ ] 细胞内受体位于胞质或核基质，统称核受体；本质是依赖激素激活的基因调控蛋白。
- [ ] 结构：N 端调节/转录激活区，中央 DNA 结合域，C 端激素结合域。
- [ ] 未活化时与抑制性蛋白结合；激素结合后抑制蛋白解离，暴露 DNA 结合位点。
- [ ] HRE（hormone response element）是靶基因上被激素–受体复合物识别的 DNA 序列。
- [ ] 核受体三种转录模式：直接结合 HRE；通过其他转录因子；被膜受体或 CDK 激活后再结合靶基因。
- [ ] 类固醇激素基因活化分初级反应（直接激活靶基因）和次级反应（初级产物再放大）。
- [ ] 人类核受体家族有数十个成员，与糖尿病、脂肪肝等相关。
- [ ] 1998 年 Furchgott 与 Ignarro 因证实舒血管信号分子是 NO 获诺贝尔奖。
- [ ] NOS 催化 L-精氨酸生成 NO；NO 不储存，扩散作用于邻近靶细胞。
- [ ] 内皮 NO → 平滑肌 GC → cGMP → PKG → 血管平滑肌松弛。
- [ ] 硝酸甘油在体内转变为 NO；西地那非阻断 cGMP 降解。
- [ ] NO 作为 LTP 的逆行信使，弥散至突触前末梢，促进谷氨酸持续释放。
:::
