# 第四节 干细胞与医学

前三节把干细胞写成一条沿发育变窄的储备：全能受精卵把身体写出来，多能 ES/iPS 在体外还能被改写，专能组织干细胞在巢里维持稳态。许多重大疾病和特殊生命现象，都可以从这套储备重新认识——衰老是储备衰退，肿瘤是储备失控或被微环境改写，再生是按损伤等级启动不同层级的细胞，治疗则是把正常干细胞或它们做出的功能细胞送回病变部位。本节把这四件事接到医学；真正进临床，仍然有赖于前三节那些还没有完全写清的生物学细节。

:::definition{label="干细胞治疗"}
干细胞治疗是把正常的干细胞、或其定向分化产生的功能细胞植入病变部位，代偿病变细胞丧失的功能。理论上它瞄准许多常规手段难以治愈的疾病，但成瘤性、生物学规律不清以及伦理法规，决定了它还不是万能钥匙。
:::

:::definition{label="组织再生"}
组织再生是组织器官受外来因素损伤或破坏后，机体启动修复，使受损部位在结构和功能上得以恢复的过程。局部出现大量细胞增殖，并伴随分化和组织形成。生理状态下由组织干细胞完成的血细胞更新、上皮脱落置换与再生相似，但性质并不相同。
:::

## 一、干细胞与器官和个体衰老

细胞衰老是细胞的基本生命现象，但细胞衰老与组织、器官和个体衰老之间的关系仍所知有限。把组织特异性干细胞放进“个体生长发育”这条时间轴，研究才从静态切片变成四维。第十六章已经把衰老写成不可逆增殖停滞、把静息写成可召回的 $\mathrm{G}_0$；成体干细胞平时可以静息，一旦自己衰老，更新账本就会出现赤字。

几乎所有组织器官中都有干细胞，基本功能是在生命过程中维持结构与功能的稳定，并避免过度生长（如肿瘤）或萎缩。它们从静息到活化、增殖和分化，都受微环境因子和信号分子调控，因而干细胞衰老不可避免地同时受内在因素和外在环境的影响。随着年龄增加，组织干细胞的数量、静息/活化状态以及增殖分化能力都发生明显改变（图 17-10），最终导致组织退化和功能障碍，并引起贫血、帕金森病、阿尔茨海默病、肿瘤、肌肉萎缩及骨质疏松等衰老相关疾病。

::figure{src="/images/cell-biology/textbook/p0387_01.png" caption="图17-10 干细胞的衰老与异常。年轻时干细胞自我更新并产生正常后代；衰老时可出现谱系特异性丢失、自我更新能力丧失、衰老引起的细胞数量减少，以及细胞恶性转化。" alt="年轻与衰老干细胞：谱系丢失、自我更新丧失、数量减少和恶性转化四条异常路径"}

对衰老机制的认识正在变成干预策略：人为调节干细胞自身的基因表达和信号通路、改变微环境因子，或清除衰老细胞，有望使成体干细胞发生衰老逆转，从而改善老年人的健康状况。第十六章的 SASP 和衰老细胞清除，在这里接到的是“把巢里的储备救回来”。

:::cause-effect{title="为什么个体老化会写成组织干细胞的账"}
- 因：成体器官靠巢里的干细胞按需补细胞，干细胞自己又受巢信号约束
- 因：年龄增长使干细胞数量、静息/活化比例和分化能力同时改变，巢本身也可以紊乱
- 果：该补的成熟细胞补不上，不该出现的谱系漂移或恶性转化却出现
- 结果：贫血、神经退行、肌萎、骨质疏松和部分肿瘤，都可以先问“这份组织的干细胞还在不在编制里”
:::

:::concept{term="衰老的是储备，不只是已经特化的细胞"}
把老化只写成“神经元老了、肌细胞老了”，解释不了为什么有些组织还能更新、有些却塌陷。组织干细胞数量下降、自我更新丢掉、谱系特异性丢失或恶性转化，是同一份储备的四种坏法。干预基因表达、信号、微环境或清除衰老细胞，目标是把储备从坏法里拉回来，而不是让已经终末分化的细胞再年轻一次。
:::

## 二、干细胞与肿瘤的发生和复发

把干细胞理论用于解释肿瘤的发生和复发，就产生了肿瘤干细胞的概念。T. Lapidot 在 1994 年最先提出急性髓样白血病干细胞。经过十余年研究，2006 年美国癌症研究协会专题讨论会将肿瘤干细胞定义为：肿瘤组织中具有无限自我更新能力、能够产生肿瘤细胞的异源性后代并进而形成肿瘤的细胞；并把“在免疫缺陷小鼠体内形成与原发肿瘤类型相同的肿瘤”作为鉴定金标准。这一界定为药物研发提供了新思路。随后脑瘤干细胞、慢性髓系白血病干细胞、结肠癌干细胞等相继被鉴定。质疑一直存在，但 2012 年美国、荷兰和比利时的研究组分别在《自然》和《科学》报道，首次用谱系示踪在肿瘤的自然栖息地（native habitat）中证明了肿瘤干细胞的存在。

:::definition{label="肿瘤干细胞"}
肿瘤干细胞是肿瘤组织中具有无限自我更新能力、能够产生异源性肿瘤细胞后代并形成肿瘤的细胞。鉴定金标准是：在免疫缺陷小鼠体内形成与原发肿瘤类型相同的肿瘤。它借用了成体干细胞的自我更新和等级结构，但编制已经改写成恶性的。
:::

肿瘤干细胞学说出现后，关于肿瘤发生有三种模型。

**1. 随机模型。** 这是传统认识：所有肿瘤细胞都有相同的成瘤能力，哪一个细胞真正形成肿瘤是随机事件。治疗如果把能看见的瘤块切净或杀死，按这个模型就应该够。

**2. 等级模型。** 只有肿瘤干细胞能够形成肿瘤，因此治疗的关键是杀死肿瘤干细胞。打掉快速分裂的主体细胞，如果干细胞还在，复发只是时间问题。

**3. 演化模型。** 引入肿瘤微环境，结合上述两种观点，但认为微环境改变可以创造普通肿瘤细胞演化为肿瘤干细胞的条件。因此近年来在关注肿瘤干细胞的同时，特别关注肿瘤微环境的检测和控制。已有研究证实微环境改变可引起肿瘤细胞“去分化”，这与某些组织干细胞的性质相符。也有实验表明，放疗和某些化疗药物能够“激活”静息的肿瘤干细胞，反而促进肿瘤发生。

因此，用肿瘤干细胞理论讨论发生、复发和转移时，要把肿瘤细胞和其所在微环境看成完整的“肿瘤生态环境”：肿瘤干细胞与普通肿瘤细胞可以在这个系统中相互转化，二者与微环境相互依存、相互作用。第十五章把肿瘤写成分化障碍，第十三章写成周期失控；这里补第三句：杀伤必须对准能自我更新的那一层，并且不能把巢刺激成新的干细胞工厂。

:::compare{title="肿瘤发生的随机模型 vs 等级模型 vs 演化模型"}
| 项目 | 随机模型 | 等级模型 | 演化模型 |
|------|----------|----------|----------|
| 谁能成瘤 | 所有肿瘤细胞能力相同，成瘤是随机事件 | 只有肿瘤干细胞能成瘤 | 普通肿瘤细胞可被微环境改写成肿瘤干细胞 |
| 细胞关系 | 扁平，无必要的等级 | 干细胞 → 异源性后代，等级稳定 | 干细胞与非干细胞可相互转化 |
| 治疗含义 | 尽量杀灭全部肿瘤细胞 | 关键是杀死肿瘤干细胞 | 同时处理细胞和微环境，防止去分化和再转化 |
| 复发解释 | 残留任何活细胞都可能再长 | 残留肿瘤干细胞即可再长 | 治疗本身（如放化疗）可能激活静息肿瘤干细胞 |
| 与本节关系 | 传统起点 | 肿瘤干细胞金标准所支持的核心 | 把第三节的巢搬进肿瘤，成为“肿瘤生态环境” |
:::

:::pitfall{label="打掉瘤块不等于打掉编制"}
等级模型很容易被听成“只要发明一种专杀肿瘤干细胞的药就够了”。演化模型马上补刀：微环境能把普通肿瘤细胞去分化成干细胞，放化疗还能把静息的肿瘤干细胞唤醒。把肿瘤看成一袋彼此相同的细胞，会漏掉干细胞；把肿瘤干细胞看成一张永不改写的名单，会漏掉巢。临床策略必须把细胞和微环境当成同一个生态系统。
:::

## 三、干细胞与组织再生

一般组织中都存在处于不同分化状态的细胞群体，从低到高构成潜在等级：组织特异性干细胞处于最基础位置，随后是过渡放大细胞，最后是成熟细胞。沿着这条瀑布，增殖能力和分化特性逐步降低。到成熟细胞时，增殖和分化已经十分有限——成熟肝细胞大约还能分裂 $2\sim 3$ 次；有的则完全丧失，如人体内耳毛细胞不能增殖。

机体根据损伤程度的高低，启动不同分化等级细胞的增殖与分化，以适应修复需求。不同组织的损伤修复机制和结果并不一样：皮肤和造血系统习惯于从干细胞加 TAC 重建；肝脏在 $\dfrac{2}{3}$ 切除后主要让成熟肝细胞加班；内耳毛细胞则几乎没有可启动的等级。第三节的肝干细胞争议，在这里变成一条临床原则——先问这份组织平时靠谁更新，再问这次损伤有多深。

:::note{label="再生不是把 ES 直接填进伤口"}
生理更新和创伤再生都动用等级瀑布，但起点和规模不同。ES/iPS 能出许多功能细胞，第四节后半会写它们的治疗策略；那是体外造好再送回去，不是体内伤口自动变成囊胚。把再生听成“局部重新变成内细胞团”，会把成瘤风险写成治疗机制。
:::

## 四、干细胞与细胞治疗

许多疾病由细胞功能缺陷或器官损伤造成。作为细胞治疗的选择之一，可以把正常干细胞或其分化产物植入病变部位并代偿功能。理论上最吸引人的地方，是它可能治疗目前常规方法无法治愈的疾病，几乎涉及各器官系统，包括阿尔茨海默病、脑卒中、癫痫、泰-萨克斯（Tay-Sachs）病、心脏病、股骨头坏死、关节炎、糖尿病、系统性红斑狼疮等。

目前可用于治疗的干细胞有两大类：一是多潜能干细胞，主要包括 ES 和 iPS；二是组织干细胞。两类细胞的主要策略如图 17-11 所示。

::figure{src="/images/cell-biology/textbook/p0389_01.png" caption="图17-11 疾病的干细胞治疗策略。左侧：ES 定向分化为成体干细胞、前体细胞和功能细胞，或由成体细胞重编程为 iPS 后再走分化，功能细胞直接回输靶器官。右侧：治疗基因包装后导入成体干细胞，体外获得遗传修饰细胞再回输体内。" alt="ES/iPS定向分化回输与基因修饰成体干细胞回输两条治疗策略"}

ES 和 iPS 具有多向分化潜能，是理想的治疗用细胞，但成瘤性是致命缺点。对那些难以获得功能性组织干细胞、或相应组织干细胞难以在体外扩增到足够数量的疾病，ES/iPS 才显示出优势。组织干细胞种类繁多，临床研究已经覆盖间充质干细胞、内皮细胞和前体细胞、神经干细胞、角膜缘干细胞、胎盘来源干细胞等。单就神经干细胞，治疗病种就包括肌萎缩侧索硬化和慢性脊髓损伤、下肢缺血和休克、神经元蜡样质脂褐质沉积症、颈髓损伤、黄斑退化、佩利措伊斯-梅茨巴赫病等。

干细胞治疗的临床试验出现了较多失败案例，根本原因是对干细胞生物学行为规律认识不够。伦理和法规问题同样需要被放在技术前面，而不是事后补票。

:::concept{term="能分化是长处，未分化残留是短板"}
PSC 的价值是可以在体外走到心肌、多巴胺神经元或 $\beta$ 细胞；风险是只要还剩未分化的多能细胞，移植后就可能变成畸胎瘤。组织干细胞成瘤风险较低，但来源、数量和谱系边界都更窄。选哪一条路，先问目标组织有没有可扩增的成体干细胞，再问残留多能细胞杀得干净不干净。
:::

前三节可以收成四句话。干细胞是具有自我更新能力、并能分化产生一种或一种以上特化细胞的原始细胞；个体的正常发育和功能维持，有赖于它们在空间和时间上的有序增殖与分化。受精卵是全能干细胞，内细胞团和生殖嵴可以分离出多潜能胚胎干细胞，成体组织器官中存在组织干细胞，三者的潜能和职责并不相同。组织干细胞住在巢里，分裂慢、能自稳，分化上既有谱系限定也有有限可塑性；巢在没有干细胞时仍可招募归巢，巢紊乱则与衰老或肿瘤转化相关。胚胎干细胞的培养体系已经比较成熟，组织干细胞的培养仍在补课。眼下最受关注的两件事，一是发育和成体中的基本生物学细节，二是组织修复等再生医学应用——前景已经看得见，进临床仍然要等基础研究把规律写清楚。

:::keypoint{label="医学上先问储备还在不在、编制有没有改写"}
- 个体老化可以写成组织干细胞数量、状态和能力的改变；干预基因表达、信号、微环境或清除衰老细胞，是在救储备。
- 肿瘤干细胞能自我更新并重建原发类型肿瘤；随机、等级、演化三种模型里，演化模型要求连微环境一起处理。
- 再生按损伤深度启动干细胞、TAC 或残存成熟细胞；不是所有器官都有同等的再生等级。
- 治疗分 PSC 和组织干细胞两条路：前者潜能大、成瘤风险高，后者谱系窄、临床已部分落地；失败多半因为生物学行为还没写清。
:::

:::memory{label="本节必背要点"}
- [ ] 许多重大疾病可以从干细胞角度重新认识，并由此产生新的防治手段。
- [ ] 组织干细胞衰老受内在因素和微环境影响；年龄增长改变其数量、静息/活化及增殖分化能力，导致组织退化和贫血、帕金森病、阿尔茨海默病、肿瘤、肌萎、骨质疏松等。
- [ ] 干预基因表达、信号通路、微环境或清除衰老细胞，有望逆转成体干细胞衰老。
- [ ] 肿瘤干细胞：无限自我更新，产生异源性肿瘤细胞并形成肿瘤；Lapidot（1994）提出急性髓样白血病干细胞；2006 年 AACR 给出定义。
- [ ] 鉴定金标准：免疫缺陷小鼠体内形成与原发肿瘤类型相同的肿瘤。2012 年谱系示踪在自然栖息地证实其存在。
- [ ] 三种发生模型：随机（每个瘤细胞能力相同）；等级（只有肿瘤干细胞成瘤，治疗关键是杀死它们）；演化（微环境使普通瘤细胞变成肿瘤干细胞）。
- [ ] 微环境改变可引起肿瘤细胞去分化；放疗和某些化疗可激活静息肿瘤干细胞。应把肿瘤细胞与微环境视为完整的肿瘤生态环境。
- [ ] 组织再生：损伤后局部增殖、分化并形成组织，使结构和功能恢复。
- [ ] 等级瀑布：组织干细胞 → TAC → 成熟细胞，增殖和分化能力逐步降低。成熟肝细胞约可再分裂 $2\sim 3$ 次，内耳毛细胞不能增殖。
- [ ] 机体按损伤程度启动不同等级；不同组织的修复机制和结果不同。
- [ ] 干细胞治疗：植入正常干细胞或其功能细胞以代偿功能；潜在病种覆盖神经、心脏、骨关节、代谢和自身免疫等。
- [ ] 两大类来源：多潜能干细胞（ES、iPS）和组织干细胞。PSC 潜能理想但有成瘤性；组织干细胞难以获得或难以扩增时，PSC 才显出优势。
- [ ] 组织干细胞临床研究包括 MSC、内皮及前体、NSC、角膜缘干细胞、胎盘来源干细胞等。
- [ ] 试验失败的根本原因是对干细胞生物学行为认识不够；伦理和法规必须同步关注。
- [ ] 培养：人、小鼠等 ES 体系较成熟；组织干细胞培养仍待深入研究。真正进入临床，有赖于基础生物学细节。
:::
