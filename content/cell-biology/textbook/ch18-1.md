# 第一节 细胞工程的主要相关技术

第十七章把干细胞写成更新的源头：全能受精卵把身体写出来，多能 ES/iPS 在体外还能被改写，专能组织干细胞在巢里维持稳态。要把这些细胞按预先设计改造成新细胞、放大培养，并送去生产或医疗，还缺一套操作。本章把这套操作写成细胞工程。它属于生物工程，可以在细胞整体上融合、培养和重编程，也可以在细胞器上做核移植，还可以在分子上做基因转移。本节先把主要技术按拆合层次摊开；第二节接到单克隆抗体、医用蛋白、细胞治疗和组织工程。按操作对象，细胞工程分成动物、植物和微生物三类，本章只写动物细胞工程。

:::definition{label="生物工程"}
生物工程（bioengineering）又称生物技术（biotechnology），是用生物体或其组成成分在最适条件下产生有益产物、并进行有效生产的技术。近代内容已扩展到基因与基因组工程、酶工程、发酵工程、细胞与组织工程、生化工程、微生物工程等层次。
:::

:::definition{label="细胞工程"}
细胞工程（cell engineering）是生物工程的基本组成部分，通过细胞融合或拆合、核质交换或核移植、染色体或基因转移以及细胞培养和筛选，按照预先设计产生新的细胞，用于生产、医疗实践或更深层次的研究开发。
:::

细胞工程的技术程序往往不必先做基因分离、提纯、剪切和拼接，一般把细胞遗传物质直接转入受体即可形成杂交细胞，因而相对简捷，对受体损伤较小，转移效率也较高。操作不仅可以在动物之间、植物之间、微生物之间进行，还可以在动物与植物、动物与微生物、植物与微生物之间进行，从而产生新品种甚至新物种。细胞治疗、动物克隆、转基因动物和再生医学，是近年来被迅速推到台前的几块。第五节的基因转移会把“不必做分子操作”这句话收回去一截：分子层次本来就在细胞工程的清单里。

根据细胞拆合与重组的层次，相关技术可以分成三类：①细胞整体层次，如细胞培养、细胞融合、细胞重编程；②细胞器层次，如核移植；③分子层次，如基因转移。细胞培养的基本原理已在第三章写过，这里只把大规模培养和三维培养补成工程规模。

:::concept{term="细胞工程先问三个层次：整颗细胞、一个核，还是一段基因"}
融合、悬浮培养和重编程动的是整颗细胞；核移植动的是细胞核和胞质的搭配；基因转移动的是一段外源 DNA。三层都可以“按设计产生新细胞”，只是改写的分辨率不同。把细胞工程听成只做融合、或听成基因工程的别名，都会把层次账做丢。
:::

## 一、大规模细胞培养

:::definition{label="大规模细胞培养"}
大规模细胞培养（large scale cell culture）是在人工条件下、在特定培养容器中高密度或高浓度培养细胞，以制备大量细胞或其产物。培养容量通常在 $2\,\mathrm{L}$ 以上。
:::

大约 $1\times 10^{9}\sim 1\times 10^{10}$ 个细胞可在 $1\sim 10\,\mathrm{L}$ 的简单搅拌瓶中获得；$1\times 10^{11}\sim 1\times 10^{12}$ 个细胞则需要生物反应器。规模大致分成实验室（约 $100\,\mathrm{L}$）、中试（$100\sim 1\,000\,\mathrm{L}$）和产业化（$5\,000\sim 20\,000\,\mathrm{L}$）三档。方法很多，常用的是悬浮培养和固定化培养。

### （一）悬浮培养

:::definition{label="悬浮培养"}
悬浮培养（suspension culture）是细胞在培养液中呈悬浮状态生长和增殖的方法。它适用于血液淋巴组织细胞，以及肿瘤细胞（如小鼠骨髓瘤 $\mathrm{SP}2/0$、$\mathrm{NSO}$）、转化细胞（如 Namalwa 细胞）和融合细胞（如杂交瘤）；贴壁细胞如 $\mathrm{CHO}$ 经悬浮驯化后也可采用。
:::

悬浮培养多用于大量生产抗体、疫苗和细胞因子等重组蛋白类药物。图 18-1 是容积 $8\,\mathrm{L}$ 的搅拌瓶：侧臂加细胞、取样和补营养，$\mathrm{CO}_{2}$ 经滤膜通入，磁力搅拌使悬液均一并避免沉降。

::figure{src="/images/cell-biology/textbook/p0392_01.png" caption="图18-1 搅拌瓶（容积为8L）。培养液深度超过 50 cm 时需供应 CO2；侧臂用于加入细胞、排出 CO2、取样和补充营养，磁化旋转摆由磁力搅拌器驱动。" alt="8L搅拌培养瓶：CO2通气侧臂、取样侧臂和底部磁力搅拌"}

优点可以先记四条。设备相对简单，容积可选择，最大培养容积可达 $25\,000\,\mathrm{L}$。可以连续收集细胞或其产物，也可以适时传代，操作和控制简便。传代无须消化，细胞不会因胰酶和 EDTA（ethylenediaminetetraacetic acid）处理以及激烈机械力分散而受损，回收率高。细胞处于不断搅动的动态生长中，浓度（细胞数/ml）均一，可在线监测并调控，产量比较恒定，工艺可控性强。

技术关键是不断搅拌并连续供给 $\mathrm{CO}_{2}$ 和空气，使营养和气体交换均匀，同时避免沉降。渗透压、剪切力和气泡破裂都会损伤细胞，可用非离子表面活性剂 Pluronic 家族保护，使其免受搅拌和通气反应器中的流体机械破坏。常用保护性添加剂包括 Pluronic F68（$0.01\%\sim 0.10\%$）和羧甲基纤维素（$1\%\sim 2\%$）等。

### （二）固定化培养

:::definition{label="固定化培养"}
固定化培养（immobilized culture）是把细胞限制或定位于特定空间内或表面上的培养技术。几乎所有动物细胞都可以做。制备方法包括吸附法、共价贴附法、离子/共价交联法、包埋法和微囊化等，常用的是吸附法和包埋法。
:::

吸附法最简单：让细胞在适当条件下贴附在陶瓷颗粒、玻璃珠、硅胶颗粒或中空纤维膜等载体表面。微载体培养是其中用得最多的一种。

:::definition{label="微载体培养"}
微载体培养是让细胞吸附于微载体（microcarrier）表面或内部进行生长与增殖的技术。微载体是直径 $150\sim 250\,\mu\mathrm{m}$ 的透明小颗粒，材料包括交联葡聚糖、塑料基质、聚苯乙烯、明胶、玻璃介质、胶原或胶原涂层、纤维素、生物玻璃等。把微载体放入生物反应器，等于让贴壁细胞按悬浮方式放大。
:::

猴肾成纤维细胞 Vero 在微载体表面生长，是教科书上的典型画面（图 18-2）。

::figure{src="/images/cell-biology/textbook/p0392_02.png" caption="图18-2 猴肾成纤维细胞 Vero 在微载体表面上生长。细胞铺满直径约 150～250 μm 的透明微载体颗粒，使贴壁细胞能在搅拌式反应器中高密度扩增。" alt="Vero细胞贴附生长于球形微载体表面的显微照片"}

包埋法是把细胞包在多聚物海绵状基质中。常用蛋白质多聚物有明胶、海藻酸钙凝胶、胶原和纤维蛋白等：贴壁依赖性细胞多用胶原，非贴壁依赖性细胞常用海藻酸钙凝胶。

最简单的固定化培养系统是细胞工厂，由一组长方形 Petri 培养板组成，总面积可达 $600\sim 2\,400\,\mathrm{cm}^{2}$（图 18-3）。此外常用中空纤维灌流法（图 18-4）和螺旋卷膜培养等。中空纤维系统里，培养液经蠕动泵在储存器与培养小室之间循环，储存器内完成换气和 $\mathrm{CO}_{2}$ 交换；细胞走纤维外侧或腔面，大分子产物可从另一端收集。

::figure{src="/images/cell-biology/textbook/p0393_01.png" caption="图18-3 填充式细胞工厂。先竖放灌流接种，再旋转使开口朝上并中断供液，最后放平使培养面呈水平、通入 5% CO2。" alt="多层细胞工厂从竖放灌流、旋转到水平通气培养的三步操作"}

::figure{src="/images/cell-biology/textbook/p0393_02.png" caption="图18-4 中空纤维灌流（截面图）。培养液通过蠕动泵从培养液储存器循环到培养小室；培养液储存器内进行换气和 CO2 交换。" alt="中空纤维灌流：细胞入口、大分子产物出口、纤维束与带CO2通气的培养液储存器"}

固定化培养对贴壁和非贴壁细胞都适用。优点是细胞可维持在较小体积培养液中生长，抗剪切力和抗污染能力强，能实现高密度培养并提高目的产物产率——细胞工厂一次产量可高达 $3\times 10^{8}\sim 3\times 10^{9}$ 个细胞。细胞与产物易于分开，也有利于后续纯化。

:::compare{title="悬浮培养 vs 固定化培养"}
| 项目 | 悬浮培养 | 固定化培养 |
|------|----------|------------|
| 细胞状态 | 在培养液中自由悬浮 | 被限制在载体表面或内部空间 |
| 典型对象 | 血液淋巴、骨髓瘤、转化细胞、杂交瘤；$\mathrm{CHO}$ 等经驯化后也可 | 几乎所有动物细胞（贴壁与非贴壁） |
| 放大方式 | 搅拌瓶至生物反应器，最大约 $25\,000\,\mathrm{L}$ | 微载体、细胞工厂、中空纤维灌流、包埋/微囊 |
| 传代 | 无须胰酶/EDTA，回收率高 | 取决于载体；产物与细胞易分开 |
| 主要长处 | 设备简单、可连续收集、浓度均一、可在线监测 | 小体积高密度、抗剪切、抗污染、产率高 |
| 主要风险 | 渗透压、剪切力、气泡破裂；需 Pluronic 等保护 | 载体选择和传质；不是所有体系都便于在线计数 |
| 典型产物 | 抗体、疫苗、细胞因子等重组蛋白 | 高密度细胞本身及其分泌产物 |
:::

## 二、三维细胞培养

:::definition{label="三维细胞培养"}
三维细胞培养（three-dimensional cell culture，TDCC）是把具有三维结构的载体与细胞在体外共同培养，使细胞在载体的立体空间中迁移、生长，构成三维的细胞–载体复合物。
:::

三维体系为细胞提供类似体内的生长环境。细胞通过紧密连接和/或缝隙连接建立细胞间及细胞与胞外基质间的联系，形成一定的三维结构。与传统二维培养相比，三维培养的细胞在基因表达、基质分泌、功能活动和分化等方面更接近体内。它既保留体内微环境的物质结构基础，又保留培养的直观性和条件可控性，把单层培养与组织器官及整体研究联系起来，甚至在一定程度上可以替代动物，用于药物研发与毒性试验。第七节的类器官，是把三维培养从“载体上的细胞团”推进到“能自组装的微型器官”。

:::note{label="二维便于看清，三维才开始像体内"}
第三章的单层培养把细胞摊在平面上，便于观察和传代。工程上要的是密度、产物和接近体内的功能。悬浮和固定化回答密度；三维培养回答“有没有细胞间连接和基质”。看见立体结构，先问它只是高密度团块，还是已经建立起连接和功能分区。
:::

## 三、细胞融合

:::definition{label="细胞融合"}
细胞融合（cell fusion）是在自然条件或人工诱导下，两个或两个以上细胞合并成一个细胞的过程。它涉及质膜连接与融合，胞质合并，以及染色体、细胞器和各种胞质成分的混合。基因型不同的细胞合并又称细胞杂交（cell hybridization），产物是异核体（heterokaryon），也称杂交细胞（hybrid cell）；基因型相同的细胞融合则形成同核体（homokaryon）。
:::

细胞融合现象最早由 G. Barski 等于 1961 年发现：高度恶性与低度恶性肿瘤细胞混合培养时，可自发融合产生杂交细胞。1962 年，Y. Okada 和 J. Tadokoro 发现紫外线灭活的仙台病毒可以促进融合。后来知道，除灭活病毒外，聚乙二醇（polyethylene glycol，PEG）、溶血卵磷脂、油酸等化学物质，以及电场、电脉冲等物理刺激，都可以促进融合。

融合成功最关键的一步是筛选出杂交细胞。HAT 培养基筛选是常用方法之一。

:::definition{label="HAT 选择培养基"}
HAT 培养基由次黄嘌呤（hypoxanthine，H）、氨基蝶呤（aminopterin，A）和胸腺嘧啶脱氧核苷（thymidine，T）组成。氨基蝶呤抑制 $\mathrm{dATP}$、$\mathrm{dGTP}$ 和 $\mathrm{dTTP}$ 的从头合成，从而阻断正常 DNA 合成；次黄嘌呤可在次黄嘌呤鸟嘌呤磷酸核糖基转移酶（HGPRT）作用下合成肌苷一磷酸（IMP），再生成 $\mathrm{dATP}$ 和 $\mathrm{dGTP}$；胸苷则在胸苷激酶（TK）作用下生成 $\mathrm{dTTP}$。
:::

因此，胸苷激酶缺陷细胞（$\mathrm{TK}^{-}\,\mathrm{HGPRT}^{+}$）与 HGPRT 缺陷细胞（$\mathrm{HGPRT}^{-}\,\mathrm{TK}^{+}$）融合后，只有同时带有 TK 和 HGPRT 的杂交细胞，能在氨基蝶呤阻断从头合成之后，改走旁路，利用次黄嘌呤和胸苷把 DNA 做出来，从而在 HAT 中存活（图 18-5）。未融合的亲本缺其中一种酶，无法在 HAT 中生存。图中还标出：亲本可分别具有 5-溴脱氧尿核苷抗性或 8-氮杂鸟嘌呤抗性；融合后出现同核体和异核体，只有两个不同亲本构成的异核体克隆能在 HAT 上留下。

::figure{src="/images/cell-biology/textbook/p0394_01.png" caption="图18-5 杂交细胞的 HAT 培养基筛选。TK− HGPRT+ 与 TK+ HGPRT− 经 PEG 融合后，只有同时具备两种酶的异核体杂交细胞能在 HAT 中存活；未融合亲本和同核体因酶缺陷被淘汰。" alt="HAT筛选：两种酶缺陷亲本融合后仅异核体杂交细胞存活"}

:::cause-effect{title="为什么 HAT 能把杂交细胞单挑出来"}
- 因：氨基蝶呤切断 $\mathrm{dATP}/\mathrm{dGTP}/\mathrm{dTTP}$ 的从头合成，细胞必须改走补救途径
- 因：补救途径一边靠 HGPRT 吃次黄嘌呤，一边靠 TK 吃胸苷；缺任何一种酶都做不成 DNA
- 果：只有 $\mathrm{TK}^{+}\,\mathrm{HGPRT}^{+}$ 的杂交细胞能在 HAT 中存活，亲本和同核体被淘汰
- 结果：HAT 不是让杂交细胞“更强”，而是把不会走旁路的细胞饿死；第二节的杂交瘤筛选，用的就是这一关
:::

细胞融合既是研究遗传变异、进化和发育的方法，也是细胞工程的重要工具。种内、种间甚至动植物间都可以融合，用来产生新品种甚至新物种，更常用来生产单克隆抗体等生物制剂。

## 四、细胞核移植

:::definition{label="细胞核移植"}
细胞核移植（nuclear transfer）是通过显微操作（micromanipulation）把一个细胞的细胞核移植到另一个去核细胞内的过程。它常用于克隆动物和研究核质关系：先无性复制遗传背景相同的胚胎，再经胚胎移植，生产基因型相同的动物群体。操作可用显微操作仪（micromanipulator），也可用化学药物实现。
:::

一条不必上显微操作仪的路径如图 18-6：先用细胞松弛素（cytochalasin）处理，再结合离心取出细胞核，然后用 PEG 把该核融合进另一去除细胞核的细胞。这种杂交细胞称为胞质杂种（cybrid），与有核细胞之间融合产生的杂交细胞不同——它带的是一份核加另一份质，而不是两份核。

:::definition{label="胞质杂种"}
胞质杂种（cybrid）是把游离细胞核融合进去核细胞后得到的重组细胞。它与有核细胞融合产生的杂交细胞不同：后者是两套核加两套质的混合，前者是“核来自一方、质来自另一方”。
:::

::figure{src="/images/cell-biology/textbook/p0395_01.png" caption="图18-6 游离细胞核的获取及融合。细胞松弛素 B 结合离心取核后，用 PEG 将核融合至另一完整细胞或胞质体，分别得到双核杂交细胞或胞质杂种。" alt="盖玻片上取核后，PEG介导核与完整细胞或胞质体融合"}

1938 年，H. Spemann 首先提出在两栖类中做核移植的设想。1953 年，R. Briggs 和 T. J. King 把已分化的细胞核移入去核豹蛙（*Rana pipiens*）卵，改造后的卵仍可发育为幼体。1962 年，J. Gurdon 把已分化的非洲爪蟾（*Xenopus laevis*）蝌蚪肠上皮细胞核移入去核同种卵，得到完全正常的成体爪蟾。这项工作标志着体细胞核移植在两栖类中育成动物，为哺乳动物核移植奠基。1963 年，童第周把金鱼囊胚核植入去核未受精卵，首次得到克隆鱼。

最引人瞩目的是克隆羊多莉（Dolly）。1997 年 2 月 23 日，英国 Roslin 研究所宣布世界第一头克隆绵羊诞生（图 18-7）。多莉的遗传特性来源于供核母羊（B），因此是供核母羊的克隆；母羊（A）主要提供细胞核发育所需的营养与环境，母羊（C）只是“代孕”母亲。I. Wilmut 所用的是乳腺细胞核，所以该过程称为体细胞核移植（somatic cell nuclear transfer，SCNT）。

:::definition{label="体细胞核移植"}
体细胞核移植（SCNT）是把成体体细胞核移入去核卵母细胞，使重组卵被激活、重新编程并发育的技术。多莉羊证明：高度分化的成体体细胞核仍具有发育为新个体的全能性（totipotency），在成熟卵母细胞中仍可被激活并重新编程。核–质相互作用的机制尚未完全阐明。
:::

::figure{src="/images/cell-biology/textbook/p0395_02.png" caption="图18-7 克隆羊的产生过程。供核母羊 B 的乳腺细胞核与供卵母羊 A 的去核卵融合，体外培养至胚胎后移入代孕母羊 C，产出与供核母羊遗传一致的克隆羊。" alt="Dolly克隆：供核羊乳腺核与去核卵融合，代孕母羊产出克隆羊"}

除理论意义外，SCNT 使动物克隆可以指向治疗或生殖。

:::definition{label="治疗性克隆"}
治疗性克隆（therapeutic cloning）是胚胎干细胞技术与核移植相结合、用于产生疾病替代治疗细胞的技术。以患者体细胞核为供核，核移植得到杂交细胞，培育至囊胚后从内细胞团分离患者的 ES 细胞，体外培养后提供与患者遗传物质一致的组织细胞或器官，从而避免异种或同种异体移植的免疫排斥。
:::

:::definition{label="生殖性克隆"}
生殖性克隆（reproductive cloning）是体细胞核移植后任其发育直至产生一个新个体。多莉绵羊即通过生殖性克隆产生。
:::

第十七章已经把 SCNT-ES 写成与供体遗传匹配、但依赖卵母细胞的多能干细胞；这里补的是工程操作：先有核移植，再决定胚胎是停在囊胚取 ES，还是继续往个体走。核–质互作还没有写完，把多莉听成“随便一个体细胞核塞进任何卵都能成体”，会把尚未阐明的机制说满。

:::pitfall{label="细胞工程并不是“不做分子操作”"}
开篇把细胞工程的长处写成：不必先分离、提纯、剪切和拼接基因，把遗传物质整包转入受体即可。这句话对融合和核移植大体成立，对基因转移并不成立——磷酸钙、脂质体、电穿孔和病毒载体，做的就是把外源基因送进基因组。另一处容易混的是杂交细胞和胞质杂种：前者是有核细胞之间融合，两套核加两套质；后者是游离核进入去核细胞，核与质来自不同一方。看见“杂交”，先问进受体的是整颗细胞、一个核，还是一段 DNA。
:::

## 五、基因转移

:::definition{label="基因转移"}
基因转移（gene transfer）是把外源基因导入受体细胞并整合至受体细胞基因组、从而定向改造其表型的技术。借助该技术可以选出所需的新型细胞，乃至新的个体。
:::

:::definition{label="转基因动物"}
转基因动物（transgenic animal）是外源基因不但能在其体内表达、并且可以遗传的动物。获得转基因动物一般包括：选择与提取外源目的基因；导入受体细胞；对整合细胞进行筛选、扩增及鉴定；若受体为卵细胞则体外培育后植入合适子宫；再筛选转基因动物并做后续研究。基因转移是其中的核心步骤。
:::

基本步骤如图 18-8：从供体提取 DNA 或 RNA 并制备 cDNA，限制性内切酶酶切后掺入带选择性标记的质粒，在选择条件下于细菌中扩增，再用磷酸钙、脂质体或电穿孔转入受体细胞，最后在选择性培养基中生长并检测表达。

::figure{src="/images/cell-biology/textbook/p0396_01.png" caption="图18-8 基因转移的基本步骤。提取 DNA/RNA 并制备 cDNA，酶切后插入带选择性标记的质粒，细菌中扩增，再经磷酸钙、脂质体或电穿孔转入受体细胞，在选择培养基中检测表达。" alt="从核酸提取、质粒构建、细菌扩增到转染受体细胞的基因转移流程"}

方法通常分成三类。物理法：电穿孔、显微注射、裸 DNA 直接注射等。化学法：DEAE-葡聚糖、磷酸钙共沉淀、脂质体包埋等。生物法：病毒介导、体细胞核移植、精子载体以及胚胎干细胞转染等。下面几种是常用的细胞转染（transfection）手段。

:::definition{label="转染"}
转染起初指外源基因通过病毒或噬菌体感染进入细胞或个体；现在常泛指外源 DNA 进入细胞或个体并导致遗传改变的过程。
:::

**1. 磷酸钙介导的转染。** 1973 年 F. L. Graham 等最早用磷酸钙把外源基因导入哺乳动物细胞。操作简单，无须昂贵设备，实验室仍广泛采用。先把氯化钙与外源 DNA 混合，加入含磷酸根离子的溶液，形成钙–磷酸–DNA 共沉淀；沉淀被培养细胞内吞进入细胞质，再进入细胞核，外源 DNA 整合入基因组并表达。

**2. 脂质体介导的转染。** 1987 年 P. L. Felgner 等建立阳离子脂质体（liposome）介导的 DNA 转染：多价阳离子脂质体包被 DNA 形成复合物，与细胞膜融合后把外源 DNA 带入细胞。阴离子脂质体也可用于转染。优点是适用性广、细胞毒性较低、成功率高，$70\%\sim 80\%$ 的离体细胞可瞬时表达外源基因；缺点是费用高，不利于大规模使用。

**3. 电穿孔法。** 高压脉冲电流在细胞膜上形成纳米级微孔，外源 DNA 直接经微孔进入。它适用于对化学法不敏感的细胞和悬浮培养细胞。所需细胞及 DNA 数量比化学法多，不同细胞的最佳参数差异较大。

**4. 病毒感染法。** 按受体细胞类型选择不同宿主范围和感染途径的病毒基因组作载体。常用 DNA 病毒载体包括腺病毒、腺相关病毒、牛痘病毒等；RNA 病毒载体包括逆转录病毒、慢病毒等。用作基因转染的病毒载体均为复制缺陷型：感染后仅能将基因组整合至细胞，不能产生包装的病毒颗粒。缺点是不适合大规模生产，可导致一定程度的免疫反应，并有整合引起基因突变和致癌的风险。比较常用的是逆转录病毒载体和腺病毒载体。

逆转录病毒（retrovirus）是单链 RNA 病毒，进入细胞后在逆转录酶作用下变成双链 DNA，再整合至受体基因组。转染可以是病毒直接感染细胞，或注射至动物体内。诱导多能干细胞就是利用逆转录病毒作为载体，把特定基因导入小鼠成体细胞而获得的。腺病毒（adenovirus）为线性双链 DNA，无包膜；优点是安全性较好，不整合入人的染色体，不会导致肿瘤发生，受体细胞范围广，外源基因在载体上容易高效表达。

**5. 显微注射法。** 主要用于制备转基因动物。使用显微操作仪，在显微镜下用玻质注射针把 DNA 迅速注入受精卵，部位通常在雄原核内或其附近，再把注射后的受精卵移植至假孕动物输卵管，最后产生转基因动物。该方法需要较昂贵的显微操作仪（图 18-9），操作人员须经培训才能保证成功率。成熟卵母细胞数量少，需用超数排卵（superovulation）才能获得较多的卵。

::figure{src="/images/cell-biology/textbook/p0397_01.png" caption="图18-9 显微操作仪外观及结构。倒置显微镜两侧分别为卵细胞显微操作仪（负压固定）和 DNA 显微操作仪（正压注射），微量注射控制器调节注入量。" alt="显微操作仪：倒置显微镜、卵细胞固定器、DNA注射针和正负压控制"}

:::note{label="病毒载体能进基因组，不等于可以随便放大"}
复制缺陷把“只送基因、不产毒”写成设计目标；整合和免疫反应仍在。逆转录病毒走整合，适合要长期表达的重编程；腺病毒不整合，适合强调安全的一过性表达。把“转染成功”听成“已经可以产业化”，会漏掉教材写明的那句：病毒载体不适合大规模生产。
:::

## 六、细胞重编程

:::definition{label="细胞重编程"}
细胞重编程（cellular reprogramming）是把已分化细胞的核基因组恢复至其分化前的功能状态。它在不改变基因序列的情况下，通过表观遗传修饰（如 DNA 甲基化）改变分化状态，分为多能性重编程和谱系重编程两大类。
:::

由此获得的诱导多能干细胞，或由谱系重编程得到的组织干细胞、组织细胞，既具有类似胚胎干细胞的多能性（或目标谱系功能），又避开胚胎干细胞应用的伦理学限制，同时可做成患者特异性或疾病特异性，显著减少免疫排斥，使细胞治疗的临床应用成为可能。第十五章把重编程写成分化可逆；第十七章把 iPS 写成四个转录因子把体细胞往回写。这里把它收进工程操作清单。

### （一）多能性重编程

:::definition{label="多能性重编程"}
多能性重编程（pluripotent reprogramming）是把已分化细胞在特定条件下去分化，恢复到全能性或多能性功能状态。常用手段包括核移植、细胞融合、多能细胞提取物共培养以及诱导性重编程。
:::

核移植涉及伦理问题；细胞融合得到的重编程细胞是四倍体，基因组不稳定程度高；提取物与体细胞共培养仍然需要干细胞，伦理问题并未真正绕开。诱导性重编程是一项重大进展：由此获得的诱导多能干细胞（induced pluripotent stem cell，iPSC）为干细胞研究乃至生命科学带来概念性革新。2014 年，日本进行了世界首例 iPSC 应用的临床研究，将 iPSC 分化出的视网膜色素上皮细胞移植到患者体内，治疗老年性黄斑变性——这是重编程细胞首次移植到人体。

### （二）谱系重编程

:::definition{label="谱系重编程"}
谱系重编程（lineage reprogramming）是不经过多能干细胞阶段，直接把已经分化的成熟细胞（或祖细胞）转换为另一种成熟细胞或干/祖细胞。通常通过转分化、去分化、转决定、特定类型的化生等实现。
:::

转分化（transdifferentiation）又称谱系转换，是直接把一类已分化细胞重编程为另一类已分化细胞，不经过多能干细胞阶段。去分化（dedifferentiation）是已分化细胞失去原有结构和功能、成为未分化细胞，再分化成另一种细胞。转决定（transdetermination）是把一种定向但尚未完全分化的细胞类型重编程为另一种细胞类型，例如把成体造血干细胞分化为神经胶质细胞。化生（metaplasia）是组织中一种分化细胞被另一种分化细胞替代，通常由慢性炎症刺激导致，常见鳞状上皮化生、肠上皮化生、间叶组织化生等。

图 18-10 把四条策略画在一起：SCNT 把体细胞核注入去核卵，体外培养可产生 ES；细胞融合把体细胞与 ES 融合，得到具备多能特性的杂合细胞；iPS 通过诱导表达 Oct3/4、Sox2、c-myc 和 Klf4 等把小鼠成纤维细胞转变为多能干细胞；谱系转化则例如直接把胰腺细胞转为肝细胞，关键是细胞类型特异性转录因子。

::figure{src="/images/cell-biology/textbook/p0398_01.png" caption="图18-10 细胞重编程的主要策略。A. 体细胞核移植（SCNT）：体细胞核注入去核卵，体外培养可产生 ES 细胞；B. 细胞融合：体细胞与 ES 融合，产生具备多能特性的杂合细胞；C. iPS 细胞：导入 Oct3/4、Sox2、c-myc 和 Klf4 等将体细胞转变为多能干细胞；D. 谱系转化：例如直接将胰腺细胞转化为肝细胞，关键是特异性转录因子。" alt="SCNT、细胞融合、iPS和谱系转化四条重编程策略并排"}

:::concept{term="往回写成多能，和横着改写成另一谱系，不是同一条路"}
SCNT、融合、提取物和 iPS，目标是把分化账清零，回到全能或多能。谱系重编程不经过这一站，靠转录因子把胰腺写成肝、或把造血干细胞写成胶质细胞。化生是体内慢性炎症干的同类事，不是实验室里的治疗协议。把所有“细胞身份变了”都叫 iPS，会把四倍体融合细胞和直接转分化混成一种产品。
:::

## 七、类器官培养

:::definition{label="类器官"}
类器官（organoid）是体外三维培养干细胞所形成的、在结构和功能上都类似于目标器官或组织的三维细胞复合体。它具有自我更新和自我组装的能力，能模拟真实器官的部分功能。这种体外三维培养干细胞的技术称为类器官培养或类器官技术。
:::

用于类器官培养的干细胞包括胚胎干细胞、成体干细胞和诱导多能干细胞等。经典途径是把干细胞培养在 3D 支架（如基质胶）上，在培养基中添加特定生长因子和诱导物以模拟体内微环境，使干细胞分化并最终自组装为类器官。它把本节的三维培养和第十七章的干细胞接到同一块胶里。

2009 年，荷兰 Hans Clevers 团队通过三维培养成体干细胞，培育出具有隐窝和绒毛结构的小肠类器官。此后十余年，实验室已能培育小肠、胃、结肠、肺、膀胱、大脑、肝脏、胰腺、肾脏、卵巢、食管、心脏等类器官，以及肿瘤类器官。2013 年，类器官技术被 *Science* 评选为十大科学进展，成为再生医学领域最重要的生物技术之一。

作为工具，类器官是目前体外细胞模型中最能模拟体内器官结构及功能的技术。与动物模型相比，操作更简单，更适用于高通量筛选和疾病发生发展机制研究，因而在疾病建模、药物筛选、精准医疗、器官发育和再生医学中都有广阔前景。它仍然是“部分功能”的微型器官，不是可以立刻替换的完整器官——完整替代要等到第二节的组织工程，并且那里也还没有全部写完。

:::keypoint{label="细胞工程按层次拆合，培养、融合、核、基因和重编程是一套工具"}
- 细胞工程按设计产生新细胞，层次分整体（培养/融合/重编程）、细胞器（核移植）和分子（基因转移）。
- 大规模培养分悬浮和固定化：前者容积大、可连续收集；后者小体积高密度，微载体让贴壁细胞按悬浮放大。
- 三维培养补上连接和基质；类器官再把干细胞自组装写成微型器官。
- 融合靠 PEG、灭活病毒或电脉冲；HAT 用补救途径把 $\mathrm{TK}^{+}\,\mathrm{HGPRT}^{+}$ 杂交细胞单挑出来。
- SCNT 证明成体细胞核仍可被卵质重编程；治疗性克隆停在囊胚取 ES，生殖性克隆走到个体。
- 基因转移是转基因动物的核心；转染方法分物理、化学、生物，病毒载体复制缺陷但仍有免疫和插入风险。
- 重编程分多能性（SCNT/融合/iPS）和谱系（转分化、去分化、转决定、化生）两条，不改基因序列、改的是表观状态。
:::

:::memory{label="本节必背要点"}
- [ ] 生物工程/生物技术：用生物体或其组分在最适条件下产生有益产物并有效生产；含基因、酶、发酵、细胞与组织、生化、微生物等工程。
- [ ] 细胞工程：融合或拆合、核质交换或核移植、染色体或基因转移、培养和筛选，按设计产生新细胞，用于生产、医疗或研究。本章只写动物细胞工程。
- [ ] 三个层次：整体（培养、融合、重编程）；细胞器（核移植）；分子（基因转移）。相对简捷、损伤较小，并可跨界操作。
- [ ] 大规模培养：容量通常 $\geqslant 2\,\mathrm{L}$；约 $10^{9}\sim 10^{10}$ 个细胞用 $1\sim 10\,\mathrm{L}$ 搅拌瓶，$10^{11}\sim 10^{12}$ 需生物反应器（$100\,\mathrm{L}$ / $100\sim 1\,000\,\mathrm{L}$ / $5\,000\sim 20\,000\,\mathrm{L}$）。
- [ ] 悬浮培养：血淋巴、骨髓瘤（$\mathrm{SP}2/0$、$\mathrm{NSO}$）、Namalwa、杂交瘤；$\mathrm{CHO}$ 可驯化。用于抗体、疫苗、细胞因子。最大约 $25\,000\,\mathrm{L}$。传代无须消化。关键是搅拌+通气；Pluronic F68 $0.01\%\sim 0.10\%$、羧甲基纤维素 $1\%\sim 2\%$ 抗剪切。
- [ ] 固定化培养：吸附、共价贴附、交联、包埋、微囊化。微载体直径 $150\sim 250\,\mu\mathrm{m}$。包埋：贴壁用胶原，非贴壁用海藻酸钙。细胞工厂面积 $600\sim 2\,400\,\mathrm{cm}^{2}$，一次可达 $3\times 10^{8}\sim 3\times 10^{9}$ 个细胞。另有中空纤维灌流、螺旋卷膜。
- [ ] 三维细胞培养（TDCC）：载体立体空间中迁移生长，连接和基质更接近体内，可部分替代动物做药效和毒性试验。
- [ ] 细胞融合：质膜融合+胞质混合。不同基因型 → 异核体/杂交细胞；相同基因型 → 同核体。Barski（1961）自发融合；Okada、Tadokoro（1962）灭活仙台病毒；PEG、溶血卵磷脂、油酸、电脉冲也可诱导。
- [ ] HAT：氨基蝶呤阻断从头合成；HGPRT 走次黄嘌呤，$\mathrm{TK}$ 走胸苷。只有 $\mathrm{TK}^{+}\,\mathrm{HGPRT}^{+}$ 杂交细胞存活。
- [ ] 核移植：显微操作或细胞松弛素+离心取核，再 PEG 融合。胞质杂种（cybrid）≠ 有核细胞融合的杂交细胞。
- [ ] 历史：Spemann（1938）设想；Briggs 与 King（1953）豹蛙幼体；Gurdon（1962）爪蟾成体；童第周（1963）克隆鱼；1997-02-23 多莉（Wilmut，乳腺核，SCNT）。
- [ ] 多莉：遗传来自供核母羊 B；供卵母羊 A 提供卵质环境；母羊 C 代孕。证明成体体细胞核仍具全能性，可在成熟卵中被激活并重编程；核–质机制未完全阐明。
- [ ] 治疗性克隆：患者体细胞核 → 囊胚 ICM → 自体 ES/组织，避免疫排斥。生殖性克隆：核移植后发育为新个体。
- [ ] 基因转移：外源基因导入并整合，定向改造表型。能表达且可遗传 → 转基因动物。
- [ ] 转染方法：物理（电穿孔、显微注射、裸 DNA）；化学（DEAE-葡聚糖、磷酸钙、脂质体）；生物（病毒、SCNT、精子载体、ES 转染）。
- [ ] 磷酸钙：Graham（1973），钙–磷酸–DNA 共沉淀后内吞。脂质体：Felgner（1987），$70\%\sim 80\%$ 瞬时表达，费用高。电穿孔：纳米孔，适合悬浮和化学法不敏感细胞。
- [ ] 病毒载体均为复制缺陷型。逆转录病毒：ssRNA→dsDNA 并整合，曾用于制备 iPS。腺病毒：线性 dsDNA、无包膜、不整合、不易致瘤。风险：免疫反应、插入突变和致癌。
- [ ] 显微注射：注入受精卵雄原核附近，移植至假孕输卵管；需超数排卵。
- [ ] 重编程：不改序列，改表观（如 DNA 甲基化）。多能性：核移植、融合（四倍体、不稳定）、提取物共培养、iPS。2014 年日本 iPSC 来源 RPE 治疗老年性黄斑变性。
- [ ] 谱系重编程：不经多能阶段。转分化/谱系转换；去分化后再分化；转决定（如 HSC → 胶质细胞）；化生（慢性炎症，如鳞状上皮化生、肠上皮化生）。
- [ ] 类器官：三维培养干细胞形成的结构和功能类似目标器官的复合体，能自我更新和自组装。Clevers（2009）小肠类器官；2013 年 *Science* 十大进展。用于疾病建模、药物筛选、精准医疗、发育和再生医学。
