# 第一节 细胞分裂

第十二章把信号写成细胞怎么听、怎么改写成代谢和基因表达。听完之后，最重大的命运之一就是增殖：一个亲代细胞怎样把自己的基因组和细胞组分交给两个子代。本章把这件事拆成三层——分裂怎么发生（本节），周期怎么被 cyclin–Cdk 和检查点锁住时序（第二节），以及这条锁链在再生、肿瘤和衰老里怎么写成临床（第三节）。

细胞分裂（cell division）是细胞生命活动的重要特征之一。通过分裂，亲代的遗传物质和某些细胞组分相对均等地分配到两个子代中，保证遗传稳定，也支撑新个体发生以及成体器官组织的维持与更新。分裂总是呈周期性进行：子代先完成 DNA 复制和蛋白质合成等准备，再进入下一轮分裂。从上次分裂结束到下次分裂结束所经历的规律性变化，称为一个细胞周期（cell cycle）。周期的规律性由一套复杂调控系统决定；自身因素或环境一旦把这套系统卡住，增殖就会失控，肿瘤等疾病随之发生。

:::definition{label="细胞分裂"}
细胞分裂（cell division）是一个亲代细胞形成两个子代细胞的过程。通过分裂，亲代细胞的遗传物质和某些细胞组分相对均等地分配到两个子代中，从而保证生物遗传的稳定性。
:::

:::definition{label="细胞周期"}
细胞周期（cell cycle）是从一次细胞分裂结束开始，经过物质准备，到下一次细胞分裂结束为止所经历的规律性变化过程。其精确性首先要求分裂前遗传物质精确复制，再要求分裂时把复制产物均等分配。调控细节在第二节展开。
:::

真核细胞的分裂方式主要有三种：有丝分裂、减数分裂和无丝分裂。三者在过程、子代染色体数目和遗传组成上并不相同。本节先把形态事件写清楚，分子开关放到第二节。

## 一、有丝分裂

有丝分裂（mitosis）也称间接分裂（indirect division），是高等真核生物体细胞分裂的主要方式。它是一系列连续事件，持续约 $1\sim 2$ 小时，形态变化最丰富，包括核分裂和胞质分裂。以核分裂为坐标，通常人为划成五个时期：前期、前中期、中期、后期、末期。胞质分裂可从后期启动，延续至末期。借助细胞骨架重排，染色体和胞质被相对均等地分到两个子代。染色质凝集、纺锤体和收缩环是三个重要特征，也是长期进化的结果。蛋白质磷酸化与去磷酸化，是染色质凝集与去凝集、核膜解聚与重建等变化的分子基础（图 13-1）；这些磷酸基团主要由第二节的 MPF 写上去、再被磷酸酶擦掉。

:::definition{label="有丝分裂"}
有丝分裂（mitosis）是高等真核生物体细胞的主要分裂方式：DNA 复制一次、细胞分裂一次，两个子代获得与亲代相同的染色体数目和遗传组成。它包括核分裂与胞质分裂，持续约 $1\sim 2$ 小时。
:::

### （一）分裂前期：核内染色质开始凝集

前期（prophase）的主要特征是：染色质凝集、核仁缩小解体、分裂极确定、纺锤体开始形成。

**1. 染色质凝集成染色体。** 间期核中松散的染色质纤维螺旋化并折叠，变粗变短，是进入前期的标志。核仁组织中心被收进所属染色体后，rRNA 合成停止，核仁缩小并最终消失。此时每条染色体已含两条染色单体，中间以着丝粒相连；随后在着丝粒外侧将形成动粒（kinetochore）。

**2. 分裂极确定和纺锤体形成。** 原来位于细胞同一侧、间期已完成复制的两个中心体（centrosome），沿核膜外围分别移向两极，它们最终到达的位置决定分裂极。每个中心体由一对中心粒（centriole）及周围无定形基质构成，基质中含微管蛋白、微管结合蛋白、马达蛋白以及部分周期调控蛋白。中心体是微管组织中心之一，周围放射状微管与中心体合称星体（aster）。星体周围微管按功能分成三类。

**① 极微管。** 两个星体在赤道附近重叠的微管；重叠区在动力蛋白作用下相互滑动，促成星体向两极移动。

**② 动粒微管。** 一端起于中心体，另一端结合染色体动粒，主要靠自身缩短把染色单体拉向两极。

**③ 星体微管。** 位于星体周围，游离端伸向胞质，稳定星体位置并参与拉长纺锤体。

间期已复制的中心体完全分成两个后形成两个星体。星体中的马达蛋白以星体微管为轨道，水解 ATP 沿微管移动，牵引两个子中心体彼此分离。最终两个星体以各自的中心体为两极，装配成纺锤体。

:::definition{label="纺锤体"}
纺锤体（spindle）是分裂期出现的临时性梭形细胞骨架，由星体微管、极微管和动粒微管纵向排列组成，以中心体为两极，因状如纺锤而得名。第七章把微管写成动态轨道；这里它们被征用为分染色体的机器（图 13-2）。
:::

::figure{src="/images/cell-biology/textbook/p0299_03.png" caption="图13-2 纺锤体结构示意图。两极中心粒发出三类微管：星体微管伸向胞质，极微管在赤道重叠，动粒微管捕捉着丝粒外侧的动粒。" alt="纺锤体：星体微管、极微管和动粒微管连接两极中心粒与染色体着丝粒"}

### （二）分裂前中期：细胞核膜崩解

前中期（prometaphase）的主要特征是：核膜崩解、完成纺锤体装配、染色体列队。

**1. 核纤层降解，促发核膜崩解。** 前期末，核纤层蛋白多肽链多个位点被磷酸化，核纤层解体，核膜破裂成许多断片和小泡，散在胞质中；核重建时这些小泡再成为新核膜的组分。第八章把核纤层写成核的结构支架；这里磷酸化是拆支架的开关。

**2. 纺锤体“捕捉”染色体，形成有丝分裂器。** 在驱动蛋白及其他微管结合蛋白协助下，两极发出的极微管游离端在赤道面交叠或搭桥，形成纺锤体的基本架构；星体微管与胞质骨架结合，稳定星体位置；动粒微管与主缢痕处的着丝粒–动粒复合体结合，捕捉染色体。

:::definition{label="有丝分裂器"}
有丝分裂器（mitotic apparatus）是纺锤体（包括星体和三类星体周围微管）及其所结合染色体共同构成的临时装置。它负责把已复制的染色体对准赤道、再均分到两极。
:::

**3. 染色体列队。** 前中期纺锤体两极距离较短、赤道面直径较大，同一条染色体两侧的动粒微管并不等长。随着动粒微管不断聚合与解聚，牵引造成染色体在震荡中向中央赤道面移动。

### （三）分裂中期：染色体排列在赤道面

中期（metaphase）的要点是：同一条染色体两侧的动粒微管等长而力量平衡，全部染色体排列在细胞中央的赤道面上。此期染色体比其他任何时期都短粗，两条姐妹染色单体的臂较易分开，因而特别适合于计数染色体、观察结构异常等细胞遗传学研究。中期看起来“静止”，其实是拉力与粘连的动态平衡；平衡一旦被打破，后期立刻开始。

### （四）分裂后期：姐妹染色单体分离

后期（anaphase）的主要特征是两条姐妹染色单体分离并移向两极。

姐妹染色单体原先在着丝粒处依靠粘连蛋白相连。后期粘连蛋白复合体被蛋白酶剪切而崩解，粘合力消失，两侧动粒微管的拉力占上风，染色单体分开，各自成为独立的子代染色体。剪切粘连蛋白的酶就是分离酶；它怎样被 APC 放出来，第二节再写。

分离后的子代染色体以基本相同的速度向两极移动。这种移动由两类微管机制共同完成，因而后期再分成后期 A 和后期 B（图 13-3）。

**后期 A** 主要由动粒微管变化介导：动粒微管正端去组装而缩短，带动动粒向两极移动。

**后期 B** 主要由极微管变化介导：极微管聚合伸长，重叠区滑动，加上星体微管向外的作用力，纺锤体被逐步拉长，进一步把染色体送向两极。

::figure{src="/images/cell-biology/textbook/p0300_01.png" caption="图13-3 有丝分裂的后期。后期 A：动粒微管正端去组装、缩短，染色体向两极移动；后期 B：极微管伸长并滑动，星体微管向外拉，两极距离增大。" alt="后期A动粒微管缩短拉染色体，后期B极微管伸长拉开两极"}

:::cause-effect{title="姐妹染色单体怎样从粘住变成分开"}
- 因：中期两侧动粒微管的拉力已经被对准，但着丝粒处粘连蛋白仍把两条单体粘在一起
- 因：后期粘连蛋白复合体被分离酶剪切，粘合力突然消失
- 果：拉力与粘连的平衡被打破，两条单体成为独立染色体并分向两极
- 结果：每个子核得到一套完整的染色体；粘连蛋白若提前被剪，基因组就会不稳，第三节的肿瘤会把这一环写进来
:::

### （五）分裂末期：核重建完成核分裂

末期（telophase）的主要特点是子代细胞核重建。染色体被均分到两极后，发生与前期相反的去凝集：动粒微管消失，核膜重新形成，染色体恢复间期染色质形态，核仁重新出现。至此两个子代核形成，核分裂完成。这些“反向事件”依赖 MPF 失活后的去磷酸化，细节在第二节。

### （六）依靠收缩环实现胞质分裂

:::definition{label="胞质分裂"}
胞质分裂（cytokinesis）是母细胞胞体一分为二的过程。典型有丝分裂中，它伴随每次核分裂，通常开始于后期、完成于末期。破骨细胞、骨骼肌细胞和肝细胞等可以只核分裂而不胞质分裂，成为多核细胞。
:::

**1. 收缩环实现胞质分裂。** 后期末或末期初，中部质膜下方出现由大量肌动蛋白和肌球蛋白聚集形成的环状结构，即收缩环（contractile ring）。此时纺锤体逐渐解体，残存微管及一些囊泡聚集于两个子核之间的细胞中部，形成环形致密层，称为中体（图 13-4）。收缩环中微丝束相互滑动使环不断缢缩，相连质膜内陷形成分裂沟；沟深至中央时细胞在此断裂。同时，胞内小泡融合插入邻近质膜，补充膜面积，使新细胞与亲代具有相似的表面积。

:::definition{label="收缩环"}
收缩环（contractile ring）是胞质分裂时在赤道质膜下方由肌动蛋白和肌球蛋白装配的环状微丝束。滑动缢缩产生分裂沟，把一个细胞勒成两个。
:::

::figure{src="/images/cell-biology/textbook/p0301_01.png" caption="图13-4 收缩环。A. 肌动蛋白和肌球蛋白纤维在赤道形成收缩环，缢出分裂沟；B. 扫描电镜显示正在分裂的蛙卵细胞。" alt="收缩环模式图与蛙卵细胞分裂沟扫描电镜"}

分裂沟发生的时间和部位与纺锤体位置密切相关，纺锤体位置决定两个子代细胞的大小。纺锤体居中则对称分裂，两个子代大小与成分相近；纺锤体偏位则不均等分裂，子代在大小和成分上都会有差异。

**2. 细胞器的非绝对均等分配。** 每个子细胞必须得到母细胞的基本成分，包括各种膜性细胞器。进入后期时，细胞器数目或体积大致扩增一倍：线粒体数量可在每个周期中简单加倍，内质网和高尔基复合体则体积加大。胞质分裂时，这些细胞器较为均匀、但并非数量绝对均等地分到子细胞。染色体的均分是硬指标；细胞器是“够用就行”。

:::pitfall{label="有丝分裂五个时期不是五场互不连续的戏"}
教材把前期到末期划成五段，只是为了用核的形态当坐标。细胞内微管捕捉、染色体震荡、粘连蛋白剪切和收缩环装配是连续的。把“中期”理解成细胞停住不动，会漏掉动粒微管的动态平衡；把胞质分裂写成末期之后才开始，会漏掉它其实从后期就已经启动。
:::

## 二、减数分裂

减数分裂（meiosis）是生殖细胞形成过程中的特殊有丝分裂。主要特征是：DNA 只复制一次，细胞连续分裂两次，产生四个子代，每个子代染色体数目比亲代减少一半，成为仅具单倍体遗传物质的配子。因为它只发生于生殖细胞成熟阶段，又称（性）成熟分裂。

经过减数分裂，有性生殖生物配子中的染色体数目由 $2n$ 变为 $n$。受精后配子融合，受精卵又恢复 $2n$，从而保证世代间染色体数目恒定。此外，非同源染色体的自由组合，以及同源染色体的交换、重组，使配子遗传基础多样化，后代变异增大，对环境的适应力增强。所以减数分裂既维持遗传稳定，也构成变异和进化的基础。第十四章会把它接到精子、卵子和受精。

两次分裂分别称为第一次减数分裂（meiosis I）和第二次减数分裂（meiosis II）。减数分裂 I 完成同源染色体分离，实现遗传物质交换及染色体数目减半；减数分裂 II 与有丝分裂相似，实现姐妹染色单体分开。经过两次分裂形成 4 个单倍体子代（图 13-5）。

:::definition{label="减数分裂"}
减数分裂（meiosis）是配子成熟过程中的特殊分裂：DNA 复制一次、细胞连续分裂两次，四个子代染色体数目减半（$2n\to n$）。减数分裂 I 是减数和重组的关键，减数分裂 II 类似有丝分裂。
:::

::figure{src="/images/cell-biology/textbook/p0302_01.png" caption="图13-5 减数分裂图解。前期 I 经细线、偶线、粗线、双线、终变完成联会与交叉；中期 I 四分体列于赤道，后期 I 同源染色体分离使数目减半；减数分裂 II 姐妹染色单体分开，形成四个单倍体配子。" alt="减数分裂全过程：前期I五期、两次分裂和四个单倍体配子"}

### （一）第一次减数分裂：配对、重组与减数

第一次减数分裂可进一步分为前期 I、中期 I、后期 I 和末期 I。减数分裂的特殊过程主要发生在前期 I。

**1. 前期 I。** 主要事件是同源染色体配对、交换与重组，随后随机分离进入两个子代。通常把前期 I 人为划分为五个时期：细线期、偶线期、粗线期、双线期、终变期。

**（1）细线期（leptotene stage）。** 核及核仁体积增大，间期已复制的染色质开始凝集。每条染色体已有两条染色单体，但光镜下仍呈单条细线，染色单体臂未完全分离，可能与局部 DNA 片段复制尚未完成有关。细线状染色体通过端粒附着于核膜，局部出现成串、大小不一的珠状结构，称为染色粒。

**（2）偶线期（zygotene stage）。** 染色质进一步凝集，分别来自父母、形态及大小相同的同源染色体（homologous chromosome）相互靠近、配对，称为联会（synapsis）。配对从端粒开始，同源染色体间出现若干接触点，再沿长轴迅速扩展，直至侧面紧密联会。完全配对后的复合结构称为二价体（bivalent）；因其共有四条染色单体，又称四分体（tetrad）。

在联会的同源染色体之间，沿纵轴形成一种临时结构，称联会复合体（synaptonemal complex，SC）。电镜下它包括三个平行部分：两侧电子密度较高的侧生成分（宽约 $20\sim 40\,\mathrm{nm}$），外侧为同源染色体 DNA；两侧之间电子密度较低的中间区宽约 $100\,\mathrm{nm}$，中央为电子密集的中央成分（宽约 $30\,\mathrm{nm}$）。侧生成分与中央成分之间有横向纤维，大致呈直角相连，间距约 $20\sim 30\,\mathrm{nm}$，因而联会复合体像一条“拉链”把同源染色体连在一起（图 13-6）。它主要由蛋白质、RNA 及少量 DNA 组成，对配对、交换与分离都重要。偶线期细胞中存在约 $0.3\%$ 的 DNA 合成，称为 Z-DNA；抑制其合成将阻止联会复合体组装。

联会起始时染色质凝集程度较低，同源染色体主要通过特定位点上碱基互补进行接触。随着凝集加深，联会复合体加入某些单链 DNA 序列和蛋白质序列识别分子，构成有组织的网络，促使配对完成。

:::definition{label="联会与二价体"}
联会（synapsis）是分别来自父母的同源染色体侧面紧密配对的过程。完全配对后形成二价体（bivalent），又称四分体（tetrad），含四条染色单体。
:::

:::definition{label="联会复合体"}
联会复合体（synaptonemal complex，SC）是偶线期沿同源染色体纵轴临时装配的蛋白质–核酸拉链，电镜下为两侧侧生成分夹一条中央成分，其间以横向纤维相连。它稳定同源配对，并为粗线期重组提供支架。
:::

::figure{src="/images/cell-biology/textbook/p0302_02.png" caption="图13-6 联会复合体的结构。两侧电子密度较高的侧生成分夹着中央成分，横向纤维把三者连成拉链；粗线期中央还可出现重组结。" alt="联会复合体：侧生成分、中央成分、横向纤维和重组结"}

**（3）粗线期（pachytene stage）。** 持续时间较长，可达几天甚至几个月。紧密联会的两条同源染色体进一步缩短变粗，同源染色体间出现染色体段的交换及重组，故又称重组期。联会复合体中央出现一些椭圆形或球形、富含蛋白质及酶的棒状结构，称为重组结（recombination nodule）。多个重组结相间分布于联会复合体上，把同源非姐妹染色单体的相对 DNA 区域结合在一起，发生活跃的片段交换，导致基因重组。此期除合成减数分裂特有的组蛋白外，还合成少部分 DNA，称为 P-DNA，主要编码与 DNA 剪切和修复相关的酶，在重组中发挥修复作用。

**（4）双线期（diplotene stage）。** 持续时间变化很大，一般较长。例如两栖类卵母细胞的双线期可持续近一年。作为临时结构的联会复合体在此期去组装并趋于消失，紧密配对的同源染色体相互分离。大部分片段分开，但非姐妹染色单体之间的某些部位仍残留接触点，称为交叉（chiasma）（图 13-7）。交叉是粗线期同源交换的形态学证据。交叉部位和数量与物种、细胞类型、染色体长度有关，一般每条染色体至少有一个交叉；染色体越长，交叉越多。人类平均每对染色体交叉数为 $2\sim 3$ 个。随着双线期进行，交叉点逐渐移向染色体两端、数目减少，这种现象称为交叉端化（chiasma terminalization）。

:::definition{label="交叉"}
交叉（chiasma）是双线期同源染色体大部分分开后，非姐妹染色单体之间残留的接触点，是粗线期交换的形态学证据。交叉随后端化，终变期末往往只在端部把同源染色体连在一起。
:::

::figure{src="/images/cell-biology/textbook/p0303_01.png" caption="图13-7 同源染色体交叉、重组。光镜和电镜下可见同源染色体在若干位点相连；模式图把交叉画成两条同源非姐妹染色单体局部互换后仍扣在一起的接点。" alt="同源染色体交叉的显微图像与模式图"}

**（5）终变期（diakinesis stage）。** 同源染色体进一步凝集，核仁消失，交叉端化继续。终变期末，同源染色体仅在端部靠交叉结合，重组完成。核膜逐渐解体，纺锤体装配完成，染色体开始移向赤道面。终变期结束标志着前期 I 完成。

**2. 中期 I。** 以端化交叉连接在一起的四分体向细胞中部汇集，最终排列于赤道面。每个二价体的两个动粒分别位于赤道面两侧，各自面向相对两极；一侧纺锤体的动粒微管只连接同侧动粒。由此决定二价体中每条染色体后续的相反去向。

**3. 后期 I。** 每个同源染色体的两条姐妹染色单体共有一个着丝粒和动粒。受纺锤体微管牵拉，同源染色体彼此分离，姐妹染色单体并不分开；含两条姐妹染色单体的同源染色体分别移向两极。结果每极染色体数为原有的一半，所以后期 I 是减数分裂中染色体减半的关键时期。同时，同源染色体向两极的移动是随机的，非同源染色体以自由组合方式进入两极，有利于变异与进化。

**4. 末期 I。** 存在两种类型：①类似有丝分裂末期，到达两极的染色体去凝集为细丝状染色质纤维，核仁和核膜重新出现，胞质分裂后形成两个子代；②某些生物末期 I 染色体不发生去凝集，保持凝集状态直至胞质分裂完成。

### （二）第一次减数分裂后出现短暂的间期

与有丝分裂间期相比，减数分裂间期通常很短，不发生 DNA 合成，无染色体复制。某些生物甚至没有间期，第一次减数分裂结束后直接进入第二次减数分裂。把这段间期写成“又复制一次”，后面的 $n$ 配子就对不上。

### （三）第二次减数分裂与有丝分裂过程相似

第二次减数分裂过程与有丝分裂基本相同，可分为前期 II、中期 II、后期 II、末期 II 和胞质分裂。

**1. 前期 II。** 末期 I 松散的染色体重新凝聚，核仁消失，核膜崩解，纺锤体再次形成，染色体逐渐向赤道面移动。

**2. 中期 II。** 染色体整齐排列在赤道面，两个姐妹染色单体分别通过各自的动粒与动粒微管相连，朝向纺锤体两极。

**3. 后期 II。** 姐妹染色单体分离，移向两极。

**4. 末期 II 与胞质分裂。** 染色体去凝集成为染色质纤维，核仁和核膜重新出现；经胞质分裂形成新的子代，子细胞是染色体数目为 $n$ 的单倍体。

第二次减数分裂结束时，一个亲代细胞共形成 4 个子代，染色体数目均减少一半；子代之间在染色体组成及组合上也存在差异。这些变化主要在第一次减数分裂中完成。

与有丝分裂相比，同源染色体配对是减数分裂的显著特征。配对使母方染色体某一片段与同源父方染色单体相应片段发生互换。交叉互换时，两条非姐妹染色单体的 DNA 双螺旋都打开，有利于片段互相交换，这一过程就是遗传重组，增加了后代细胞中的基因类型。

性染色体也要配对。雌性哺乳动物有两条 X 染色体，能够像其他同源染色体那样配对。雄性有一条 X 和一条 Y，二者并非同源染色体，但在末端存在一个小的同源区域（假常染色质区）。前期 I 可在此发生配对及交叉互换，保证 X 和 Y 能连接在纺锤体上并分离，结果只产生两种精子：含 X 的和含 Y 的。

:::concept{term="减数发生在后期 I，不是后期 II"}
后期 I 分开的是同源染色体，姐妹染色单体仍共有一个着丝粒，所以每极染色体条数减半、但每条仍是“双单体”。后期 II 才把姐妹染色单体分开，数目不再减半。把“减数”记在第二次分裂，会把四分体、自由组合和交叉端化全部接到错误的时间点上。
:::

:::compare{title="有丝分裂 vs 减数分裂"}
| 项目 | 有丝分裂 | 减数分裂 |
|------|----------|----------|
| 发生范围 | 体细胞 | 生殖细胞（成熟分裂） |
| DNA 复制次数 | 1 | 1 |
| 分裂次数 | 1 | 2 |
| 前期 | 无同源配对、交换、重组 | 前期 I 有联会、交换、重组 |
| 中期 | 二分体排在赤道面，动粒微管连染色体的两个动粒 | 中期 I 四分体排在赤道面，一侧微管只连一个动粒 |
| 后期 | 姐妹染色单体分向两极 | 后期 I 同源染色体分向两极，姐妹不分开 |
| 末期结果 | 染色体数目不变 | 末期 I 染色体数目减半 |
| 子代遗传 | 与亲代相同 | 比亲代少一半；子代之间、子代与亲代均不相同 |
| 持续时间 | 一般为 $1\sim 2$ 小时 | 较长，可为数月、数年甚至数十年 |
:::

## 三、无丝分裂

无丝分裂（amitosis）又称为直接分裂（direct division），是最早发现的细胞分裂方式。间期核复制后直接分成大小基本相等的两部分，期间不形成染色体和纺锤体，核膜也不消失，由亲代细胞直接断裂形成子代。因此两个子代获得的遗传物质和其他胞质成分并不一定均等。无丝分裂中细胞维持遗传稳定性的机制目前仍不清楚。

它是低等生物细胞增殖的主要方式，但也存在于高等生物的组织细胞，例如动物的上皮组织、疏松结缔组织、肌组织及肝脏等。创伤、癌变及衰老的细胞中也能进行无丝分裂。其特点是能量消耗少、分裂迅速、分裂中细胞仍可执行功能，快速性与便捷性有利于细胞应激并适应外界变化。

:::definition{label="无丝分裂"}
无丝分裂（amitosis）又称直接分裂，间期核复制后直接断裂成两个子核，不形成染色体和纺锤体，核膜不消失。子代遗传物质和其他胞质成分不一定均等。
:::

:::note{label="三种分裂先问“染色体怎么走”"}
- 有丝分裂：复制一次、分裂一次，姐妹染色单体分开，$2n\to 2n$。
- 减数分裂：复制一次、分裂两次，先分同源再分姐妹，$2n\to n$。
- 无丝分裂：不走纺锤体，核膜不拆，均分没有形态学保证。

看见“分裂”，先问有没有纺锤体、分的是同源还是姐妹、子代是 $2n$ 还是 $n$。第二节再问这些形态事件被哪些 cyclin–Cdk 按时启动。
:::

:::keypoint{label="分裂是把复制产物交出去的形态学"}
- 有丝分裂靠染色质凝集、纺锤体和收缩环，把一套完整染色体和够用的细胞器交给两个 $2n$ 子代。
- 后期分 A（动粒微管缩短）和 B（极微管拉长）；粘连蛋白被剪，才允许姐妹分开。
- 减数分裂 I 用联会复合体完成配对与重组，后期 I 同源分离使数目减半；减数分裂 II 才分姐妹。
- 交叉是重组的形态证据；X 与 Y 靠末端同源区配对，保证只产生含 X 或含 Y 的两种精子。
- 无丝分裂快而不保证均分，不是高等生物体细胞的常规路径。
:::

:::memory{label="本节必背要点"}
- [ ] 细胞分裂：一个亲代形成两个子代，遗传物质和某些组分相对均等分配。
- [ ] 细胞周期：上次分裂结束到下次分裂结束；精确复制 + 均等分配。
- [ ] 三种方式：有丝分裂、减数分裂、无丝分裂。
- [ ] 有丝分裂持续约 $1\sim 2$ 小时，人为分为前期、前中期、中期、后期、末期；胞质分裂从后期延至末期。
- [ ] 三大特征：染色质凝集、纺锤体、收缩环；分子基础是蛋白质磷酸化与去磷酸化。
- [ ] 前期：染色质凝集、核仁消失、中心体移向两极；每条染色体含两条染色单体，着丝粒外侧形成动粒。
- [ ] 纺锤体三类微管：极微管（重叠滑动）、动粒微管（缩短拉染色体）、星体微管（伸向胞质）。
- [ ] 前中期：核纤层磷酸化→核膜崩解；纺锤体捕捉染色体，构成有丝分裂器。
- [ ] 中期：两侧动粒微管等长，染色体排在赤道面，最适于核型分析。
- [ ] 后期：粘连蛋白被剪，姐妹分开；后期 A 动粒微管缩短，后期 B 极微管伸长、星体微管外拉。
- [ ] 末期：染色体去凝集，核膜、核仁重建，核分裂完成。
- [ ] 收缩环由肌动蛋白和肌球蛋白构成；纺锤体位置决定对称或不对称分裂；细胞器非绝对均等分配。
- [ ] 减数分裂：DNA 复制 1 次、分裂 2 次，$2n\to n$，形成 4 个单倍体配子。
- [ ] 前期 I 五期：细线、偶线（联会、SC、Z-DNA）、粗线（重组结、P-DNA）、双线（交叉及端化）、终变。
- [ ] 联会复合体：侧生成分 + 中央成分 + 横向纤维，像拉链。
- [ ] 人类平均每对染色体交叉 $2\sim 3$ 个；后期 I 是染色体减半的关键。
- [ ] 减数分裂间期短、无 DNA 复制；减数分裂 II 类似有丝分裂，分开姐妹染色单体。
- [ ] X 与 Y 靠末端同源区配对，产生含 X 或含 Y 的两种精子。
- [ ] 无丝分裂不形成染色体和纺锤体，核膜不消失，子代不一定均等；能量少、速度快，分裂中仍可执行功能。
:::
