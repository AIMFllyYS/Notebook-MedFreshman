# 第四节 细胞微环境异常与疾病

在正常生理条件下，细胞微环境依赖其中各种组分共同作用的动态平衡而维持稳态。当受到其他组织来源或病理因素——激素、生长因子、免疫因子、化学物质、生物致病因子及免疫细胞等——影响时，稳态将被打破。如果平衡被打破后不能重建新的平衡，即微环境失衡，细胞行为就会改变，并诱发疾病。第一节把微环境写成四块积木，第二节和第三节写它们如何互相改写；本节看积木倒塌时最常写成的两种病：肿瘤和器官纤维化。

:::definition{label="微环境失衡"}
微环境失衡是细胞微环境中细胞成分、细胞外基质和调节因子的动态平衡被病理因素打破、又不能重建新平衡的状态。失衡改写细胞的增殖、迁移、分化和免疫应答，是肿瘤发生发展和器官纤维化等病理过程的共同背景。
:::

:::definition{label="肿瘤微环境"}
肿瘤微环境是肿瘤细胞赖以生存的局部生态系统，由肿瘤细胞、肿瘤相关成纤维细胞、肿瘤相关巨噬细胞、内皮细胞、脂肪细胞、T 细胞和骨髓来源的间充质干细胞等，以及被改造过的细胞外基质共同构成。它不仅是肿瘤生长的土壤，还主动促进侵袭、血管生成和免疫逃逸。
:::

## 一、细胞微环境异常与肿瘤的发生发展

除基因突变等基因组不稳定性之外，肿瘤的发生发展与肿瘤细胞生存的微环境密切相关。肿瘤微环境中细胞和基质成分的异常，本身就是肿瘤发生的重要因素。图 11-11 显示了这个复杂系统里最常出场的角色。

::figure{src="/images/cell-biology/textbook/p0273_01.png" caption="图11-11 肿瘤细胞微环境。肿瘤细胞和肿瘤干细胞被巨噬细胞、中性粒细胞、成纤维细胞、脂肪细胞和 T 细胞包围，其间填充细胞外基质，并与血管相邻。间质细胞和基质共同构成促进生长、侵袭和免疫逃逸的局部生态。" alt="肿瘤微环境：肿瘤细胞群周围有巨噬、中性粒、成纤维、脂肪和T细胞，旁有血管和细胞外基质"}

**① 肿瘤相关成纤维细胞是实体瘤中最丰富的基质细胞。** 成纤维细胞是肿瘤微环境中主要的基质细胞。肿瘤邻近的成纤维细胞被活化，成为肿瘤相关成纤维细胞（tumor-associated fibroblast，CAF）。它是乳腺癌、大肠癌、胰腺癌等实体肿瘤中最丰富的细胞成分，可产生大量生长因子和细胞因子，影响肿瘤细胞行为；同时也是蛋白水解酶的主要来源，通过降解 ECM 直接影响肿瘤迁移。

:::definition{label="肿瘤相关成纤维细胞"}
肿瘤相关成纤维细胞（CAF）是被肿瘤细胞活化的成纤维细胞，为实体瘤中最丰富的基质细胞。它大量分泌生长因子、细胞因子和蛋白水解酶，既改写肿瘤细胞行为，又通过降解基质为侵袭开路。
:::

**② 肿瘤相关巨噬细胞促进基质降解、血管形成和侵袭。** 肿瘤微环境中存在大量巨噬细胞，它们被肿瘤细胞募集到周围，成为肿瘤相关巨噬细胞（tumor-associated macrophage，TAM）。与正常巨噬细胞相比，TAM 产生细胞因子和组织蛋白酶等的能力更强，对促进基质降解、肿瘤周围血管形成和肿瘤细胞侵袭周围组织起重要作用。

:::definition{label="肿瘤相关巨噬细胞"}
肿瘤相关巨噬细胞（TAM）是被肿瘤细胞募集并改写的巨噬细胞。与正常巨噬细胞相比，它分泌细胞因子和组织蛋白酶的能力更强，促进基质降解、肿瘤血管生成和侵袭，是微环境中的促瘤炎症细胞。
:::

**③ 微环境抑制 T 细胞，造成免疫逃逸。** 肿瘤微环境影响 T 细胞功能，导致 T 细胞免疫功能下降。微环境促使肿瘤细胞的 PD-L1（programmed death-ligand 1）表达上调；PD-L1 与活化 T 细胞表面的 PD-1（programmed death-1）结合后，抑制 T 细胞的活化和增殖，诱导 T 细胞凋亡，从而使肿瘤细胞逃逸机体的免疫监视。

:::definition{label="PD-1/PD-L1 免疫检查点"}
PD-1/PD-L1 是肿瘤微环境中的一对免疫抑制分子。肿瘤细胞表面的程序性死亡配体 1（PD-L1）与活化 T 细胞表面的程序性死亡受体 1（PD-1）结合后，抑制 T 细胞活化和增殖并诱导其凋亡，是肿瘤细胞逃逸免疫监视的重要机制。
:::

**④ 骨髓来源的间充质干细胞参与迁移和免疫抑制。** 在原发性肿瘤细胞周围还有许多间质细胞，如骨髓来源的间充质干细胞，它们在促进肿瘤细胞迁移和抑制 T 细胞免疫中起重要作用。

**⑤ 被改造的 ECM 本身就能改变增殖和迁移。** 肿瘤微环境中 ECM 的成分和力学特性可以不同程度地影响肿瘤细胞的增殖和迁移能力。第二节写过肿瘤细胞常过量分泌透明质酸和硫酸软骨素，使局部变成利于走、不利于分化的凝胶；针对 Ⅳ 型胶原的水解酶则把基膜这道墙拆开。基质在这里不再是被动的舞台，而是被改写过的道具。

:::concept{term="微环境是帮凶，不只是土壤"}
“种子和土壤”容易让人以为基质只是躺在那里等肿瘤来长。CAF 分泌酶、TAM 促血管、PD-L1 关掉 T 细胞、间充质干细胞帮忙迁移——这些都是主动操作。基因突变写下肿瘤细胞的内在不稳定性，微环境写下它能不能活下去、走出去、躲过免疫。两件事缺一不可。
:::

:::pitfall{label="肿瘤不等于一堆突变细胞"}
只写癌基因和抑癌基因，解释不了为什么同一种突变在不同微环境里侵袭能力可以差很远，也解释不了 PD-1/PD-L1 抗体为什么能成为治疗靶点。微环境中的 CAF、TAM、T 细胞和 ECM 刚度都是可干预的变量。把肿瘤写成“细胞自己变坏了”，等于把第四节从本章删掉。
:::

:::cause-effect{title="PD-L1 如何把 T 细胞从监视者写成旁观者"}
- 因：肿瘤微环境上调肿瘤细胞表面的 PD-L1
- 因：PD-L1 结合活化 T 细胞表面的 PD-1
- 果：T 细胞活化与增殖被抑制，并走向凋亡
- 结果：免疫监视失效，肿瘤细胞在原位和转移灶中得以存活；阻断这一对分子，相当于把监视重新打开
:::

:::compare{title="CAF vs TAM"}
| 项目 | 肿瘤相关成纤维细胞（CAF） | 肿瘤相关巨噬细胞（TAM） |
|------|------------------------------|---------------------------|
| 来源 | 邻近成纤维细胞被活化 | 巨噬细胞被肿瘤细胞募集、改写 |
| 在实体瘤中的位置 | 往往是最丰富的基质细胞（乳腺癌、大肠癌、胰腺癌等） | 大量存在于肿瘤周围 |
| 主要分泌物 | 生长因子、细胞因子、蛋白水解酶 | 细胞因子、组织蛋白酶 |
| 对基质的作用 | 降解 ECM，直接促进肿瘤迁移 | 促进基质降解，并促肿瘤血管形成 |
| 对免疫的影响 | 改写局部细胞因子谱 | 强化促瘤炎症，协同免疫抑制 |
| 共同结果 | 把微环境改造成利于生长、侵袭和逃逸的生态 | 同左，偏重炎症、血管和蛋白酶 |
:::

## 二、细胞微环境异常与器官纤维化

纤维化（fibrosis）是间质纤维结缔组织对受损实质细胞修复失衡的结果，表现为组织或器官中纤维组织增生，胶原纤维显著增加，以及 ECM 成分及量的改变。持续发展将导致正常器官结构破坏和功能减退。肝纤维化若持续增加，将导致肝硬化，甚至诱发肝癌。

:::definition{label="纤维化"}
纤维化（fibrosis）是间质纤维结缔组织对受损实质细胞修复失衡的病理过程，以纤维组织增生、胶原纤维显著增加以及细胞外基质成分和含量改变为特征。持续进展会破坏器官结构并导致功能丧失，如肝纤维化发展为肝硬化，并可继发肝癌。
:::

细胞微环境成分的变化与组织器官纤维化关系密切。多种细胞因子、生长因子和代谢产物可激活致纤维化的信号转导通路。转化生长因子 $\beta$（transforming growth factor-$\beta$，TGF-$\beta$）被认为是介导纤维增生性疾病的关键因子。TGF-$\beta$ 的自分泌环路使组织修复过程变成慢性的、进行性的过程，因而最终导致肝、肺、肾等器官发生纤维化、硬化、结构破坏和功能丧失。

:::definition{label="TGF-β 自分泌环"}
TGF-$\beta$ 自分泌环是细胞分泌转化生长因子 $\beta$、又被自身及邻近细胞的 TGF-$\beta$ 持续激活的正反馈。它把本应结束的修复变成慢性、进行性的基质堆积，是肝、肺、肾等器官纤维化和硬化的关键驱动机制。
:::

第二节表 11-2 里，$\beta$-蛋白聚糖和饰胶蛋白聚糖都能结合 TGF-$\beta$。基质因此不只是纤维化的产物，也是把 TGF-$\beta$ 存住、放出、放大的仓库。修复启动时需要这块仓库；仓库若关不上，胶原就会按病理性比例持续堆积。

:::cause-effect{title="TGF-β 自分泌环如何把修复写成硬化"}
- 因：实质细胞受损，修复启动，TGF-$\beta$ 等因子激活成纤维细胞
- 因：TGF-$\beta$ 自分泌环路使信号不能随损伤消退而关闭
- 果：胶原等 ECM 持续堆积，纤维组织增生
- 结果：器官结构破坏、功能减退；在肝则从纤维化走向肝硬化，并可继发肝癌
:::

:::note{label="从纤维化到肝癌是微环境连续改写"}
肝纤维化首先是基质和间质细胞的病，不是一开始就有一块癌。持续的纤维增生改变刚度、血管和免疫微环境，为后来的恶性转化提供土壤。把肝硬化和肝癌写成互不相关的两章，会漏掉这条微环境连续谱。
:::

:::keypoint{label="稳态一破，细胞改行"}
- 微环境靠动态平衡维持；失衡且不能重建，就会诱发疾病。
- 肿瘤微环境是主动的生态系统：CAF 供因子和酶，TAM 促血管和降解，PD-L1/PD-1 关掉 T 细胞，ECM 被改写成利于迁移的凝胶和缺口。
- 纤维化是修复失衡：胶原和基质堆多了；TGF-$\beta$ 自分泌环把急性修复锁成慢性硬化。
- 肿瘤和纤维化都证明：微环境组分异常可以独立于（或叠加于）基因组改变，推动疾病。
:::

:::memory{label="本节必背要点"}
- [ ] 微环境稳态依赖组分动态平衡；病理因素打破平衡且不能重建即失衡，诱发疾病。
- [ ] 肿瘤发生发展除基因组不稳定性外，依赖肿瘤细胞生存的微环境。
- [ ] CAF：邻近成纤维细胞活化而来，实体瘤（乳腺癌、大肠癌、胰腺癌）中最丰富的基质细胞；分泌生长因子、细胞因子和蛋白水解酶。
- [ ] TAM：被肿瘤募集的巨噬细胞，分泌细胞因子和组织蛋白酶的能力更强，促基质降解、血管形成和侵袭。
- [ ] 微环境上调肿瘤细胞 PD-L1，与 T 细胞 PD-1 结合后抑制 T 细胞活化、增殖并诱导凋亡，造成免疫逃逸。
- [ ] 骨髓来源间充质干细胞促进肿瘤细胞迁移并抑制 T 细胞免疫。
- [ ] ECM 的成分和力学特性本身即可影响肿瘤细胞增殖和迁移。
- [ ] 纤维化：间质对实质损伤修复失衡，纤维组织和胶原显著增加，ECM 质与量改变。
- [ ] 肝纤维化持续发展 → 肝硬化，并可诱发肝癌。
- [ ] TGF-$\beta$ 是纤维增生性疾病的关键因子；其自分泌环使修复变成慢性、进行性过程，导致肝、肺、肾纤维化、硬化和功能丧失。
- [ ] 细胞微环境由相邻细胞和非细胞成分（ECM、调节因子等）构成，稳态是正常生命活动的基础；组分异常与肿瘤和器官纤维化密切相关。
:::
