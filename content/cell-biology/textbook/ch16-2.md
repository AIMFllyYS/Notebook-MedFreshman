# 第二节 细胞死亡

第一节把衰老写成不可逆的增殖停滞：细胞还活着，只是不再分裂。停滞之后，账本的下一栏是终结——细胞生命现象结束。细胞死亡的进程可以很快，剧烈的理化因子可使细胞迅速死亡；在非剧烈因素作用时，死亡则有一定的自然过程。引起死亡的原因很多，对机体的影响也错综复杂：它既可在病理因素下发生，也发生于生理条件下的个体发育。本节先把常见死亡方式摊开，再按“能不能被逆转”分成意外性死亡和调控性死亡；凋亡的形态、caspase 和两条通路放到第三节，坏死性凋亡、自噬性死亡、焦亡和铁死亡的分子细节放到第四节。

:::definition{label="细胞死亡"}
细胞死亡是细胞生命现象的终结。剧烈理化因子可使细胞迅速死亡；非剧烈因素作用时，死亡有一定的自然过程。它既发生于病理条件，也发生于生理发育。
:::

:::definition{label="调控性细胞死亡"}
调控性细胞死亡（regulated cell death，RCD）由温和的细胞内、外损伤引发，或发生于生理过程中，特征是有特异蛋白质复合物的形成和激活，并可被遗传学方法或药物所逆转。凋亡、程序性坏死、自噬性细胞死亡、焦亡、铁死亡都属于 RCD。
:::

## 一、细胞死亡的方式

早在 19 世纪初，显微镜下已观察到细胞死亡。20 世纪 70 年代之前，人们将所有细胞死亡均称为坏死（necrosis）。1972 年，某些细胞的死亡方式被命名为细胞凋亡（apoptosis）；1973 年，电子显微镜下观察到的大鼠和小鼠出生前胚胎细胞死亡，按形态差异分成细胞凋亡、细胞坏死，以及以胞质过度囊泡化为特征的自噬性细胞死亡。近 30 年来，随着对生化特征和功能意义认识的深入，又相继发现和命名了 10 余种新的细胞死亡。这里先介绍常见方式；第三节、第四节再把分子机器拆开。

**1. 细胞凋亡。** 细胞凋亡是在特定信号诱导下，由细胞内的死亡级联反应被触发所致的生理性或病理性、主动性的死亡过程。它既可由病理因素刺激引起，也发生于生理条件下的发育过程。凋亡细胞呈现皱缩样改变。早期细胞核内染色质固缩凝集，并聚集在核膜周围；后期细胞核和细胞质内容物片段化断裂，但由膜结构将它们包裹，形成多个球形小体，即凋亡小体（apoptotic body）。凋亡小体可被周围吞噬细胞吞噬，不引起炎症反应。

:::definition{label="细胞凋亡"}
细胞凋亡（apoptosis）是特定信号诱导下、由细胞内死亡级联反应触发的主动性死亡，可发生于生理发育或病理刺激。细胞皱缩，染色质固缩并贴核膜，内容物被膜包裹成凋亡小体，吞噬后不引发炎症。
:::

:::definition{label="凋亡小体"}
凋亡小体（apoptotic body）是凋亡后期由膜结构包裹核与胞质断片所形成的球形小体。它把“要扔掉的内容物”封在完整膜里交给邻居吞噬，因而凋亡一般不引起炎症。
:::

**2. 细胞坏死。** 细胞坏死是在致病因子作用下，细胞生命活动被强行终止所致的病理性、被动性的死亡过程。它主要发生于病理情况（创伤、缺血、缺氧等）。导致坏死的环境因素可以是物理的，如高温与超低温、高渗与低渗、射线；也可以是化学的，如化学毒物；还可以是生物的，如细菌和病毒感染。坏死时呈现肿胀性变化，之后细胞膜和细胞器膜崩解破裂，细胞解体，内容物外溢，引起周围组织发生炎症反应。

:::definition{label="细胞坏死"}
细胞坏死（necrosis）是致病因子把细胞生命活动强行终止所致的病理性、被动性死亡。细胞肿胀，质膜和细胞器膜破裂，内容物外溢，引发炎症。传统上它被写成与凋亡截然不同的急性死亡。
:::

坏死一直被认为是在严重损伤下发生的一种被动、急性的细胞死亡，与凋亡完全不同。后来研究发现，某些表现为坏死表型的细胞死亡，能够被化学合成的小分子抑制剂逆转，显示出程序性调控。这种类型的细胞坏死被称为程序性坏死（programmed necrosis）或坏死性凋亡（necroptosis）。第四节会把它写成 RIPK1/RIPK3/MLKL 坏死复合体；这里只需先记住：坏死的外表，不等于没有程序。

:::definition{label="程序性坏死"}
程序性坏死（programmed necrosis）又称坏死性凋亡（necroptosis），是具有坏死样形态、但可被小分子抑制剂逆转的调控性死亡。表型仍是肿胀、膜破、内容物外溢和炎症；机制上不依赖 caspase，而依赖坏死复合体。
:::

**3. 自噬性细胞死亡。** 细胞自噬可以帮助细胞抵抗饥饿、衰老等外界压力，但过度的自噬又将导致细胞发生程序性死亡。这种细胞质中伴随有大量自噬性囊泡的细胞死亡，称为自噬依赖性细胞死亡（autophagy-dependent cell death）或自噬性细胞死亡（autophagic cell death）。第五章把自噬写成回收车间；这里车间开过头，回收本身变成死因。

:::definition{label="自噬性细胞死亡"}
自噬性细胞死亡（autophagic cell death）又称自噬依赖性细胞死亡，是细胞质中出现大量自噬性囊泡、并且死亡在分子上严格依赖自噬的调控性死亡。抑制自噬后细胞不再死亡，才算数；仅仅“看见自噬泡”不够。
:::

**4. 细胞焦亡。** 焦亡表现为细胞不断胀大直至细胞膜破裂，导致细胞内容物释放进而激活强烈的炎症反应。这种坏死样形态的细胞死亡称为细胞焦亡（pyroptosis）。焦亡也是程序性调控的，是机体一种重要的天然免疫反应，在抗感染中发挥重要作用。相比于细胞凋亡，细胞焦亡发生得更快，并会伴随大量促炎性细胞因子的释放。

:::definition{label="细胞焦亡"}
细胞焦亡（pyroptosis）是坏死样形态的调控性死亡：细胞胀大直至质膜破裂，内容物和促炎细胞因子大量释放。它发生更快，是抗感染的固有免疫反应，由 gasdermin 在膜上打孔执行。
:::

**5. 铁死亡。** 铁死亡（ferroptosis）是一种铁依赖性的脂质过氧化物过度累积诱导的细胞死亡，区别于凋亡、坏死和自噬性细胞死亡。生理状态下铁离子水平在细胞内处于动态平衡；过量铁离子可导致细胞铁浓化，其主要表现形式为铁离子沉积导致的氧化应激及膜脂质过氧化。

:::definition{label="铁死亡"}
铁死亡（ferroptosis）是铁依赖性的、由脂质过氧化物过度累积诱导的调控性死亡。铁过载经芬顿反应产生大量活性氧，生物膜多不饱和脂肪酸发生脂质过氧化，膜变薄、完整性和流动性改变，细胞死亡。
:::

:::compare{title="细胞坏死 vs 细胞凋亡"}
| 项目 | 细胞坏死 | 细胞凋亡 |
|------|----------|----------|
| 性质 | 病理性、被动；生命活动被强行终止 | 生理性或病理性、主动；死亡级联被触发 |
| 形态 | 肿胀性变化 | 皱缩样改变 |
| 膜 | 质膜和细胞器膜崩解破裂 | 膜保持完整，内容物被包进凋亡小体 |
| 结局 | 内容物外溢，周围组织炎症 | 凋亡小体被吞噬，不引起炎症 |
| 程序 | 经典坏死视为意外性死亡；坏死性凋亡是可被抑制剂逆转的程序化坏死 | 典型的调控性/程序性死亡 |
| 本节位置 | 先建立对照；坏死性凋亡细节在第四节 | 形态、caspase 和两条通路在第三节展开 |
:::

:::pitfall{label="坏死的外表，不等于没有程序"}
1970 年代以前所有死亡都叫坏死；后来凋亡被分出去，坏死就被听成“完全被动、完全不可逆”。教材马上补了一句：某些坏死表型能被小分子抑制剂逆转，这就是坏死性凋亡。把肿胀、膜破、炎症自动等同于 ACD，第四节的 RIPK1 和 Nec-1 就没有理论位置。先看形态，再问能不能被遗传或药物关掉。
:::

## 二、细胞死亡的分类

随着对机制认识的深入，从 2005 年开始，国际细胞死亡命名委员会（Nomenclature Committee on Cell Death，NCCD）建议对细胞死亡进行分类，并在此后不断修正。2015 年起，根据死亡过程是否可控，将其分为意外性细胞死亡（accidental cell death，ACD）和调控性细胞死亡（regulated cell death，RCD）两大类。

**1. 意外性细胞死亡。** 是指剧烈损伤造成的迅速细胞死亡，具有不可避免、无法逆转的特点。这些损伤因素包括物理的创伤、烧伤，也包括剧烈的化学毒素。高温把蛋白质烫开、强酸把膜溶掉，细胞内来不及组装任何死亡复合体，这就是 ACD。

:::definition{label="意外性细胞死亡"}
意外性细胞死亡（accidental cell death，ACD）是剧烈损伤造成的迅速死亡，不可避免、无法逆转。创伤、烧伤和剧烈化学毒素是典型诱因。它没有可被遗传学方法或药物关掉的特异蛋白质机器。
:::

**2. 调控性细胞死亡。** 由温和的细胞内、外损伤引发，或发生于生理过程中。主要特征是有特异的蛋白质复合物形成和激活，并可被遗传学方法或药物所逆转。在 RCD 过程中，蛋白质或蛋白质复合物就像为死亡进行遗传编码的装置（genetically encoded apparatus），也像分子机器（molecular machinery）一样触发下游信号转导和效应蛋白的激活，分别引起膜的通透性转变、膜打孔、膜脂过氧化、膜破裂和细胞的片段化，最终造成细胞死亡。细胞凋亡、程序性坏死、自噬性细胞死亡、细胞焦亡、铁死亡等被归类于调控性细胞死亡。

其中，在生理条件下发生的调控性细胞死亡称为程序性细胞死亡（programmed cell death，PCD）。程序性细胞死亡可以是细胞凋亡，也可以是其他形式的细胞死亡（如自噬依赖性死亡、程序性坏死）。把 PCD 听成凋亡的别名，会把发育中的坏死性凋亡和自噬性死亡从程序里划掉。

:::definition{label="程序性细胞死亡"}
程序性细胞死亡（programmed cell death，PCD）是在生理条件下发生的调控性细胞死亡。它可以是凋亡，也可以是自噬依赖性死亡、程序性坏死等其他 RCD。PCD 是生理场景下的 RCD，不是凋亡的同义词。
:::

:::compare{title="意外性细胞死亡 vs 调控性细胞死亡"}
| 项目 | 意外性细胞死亡（ACD） | 调控性细胞死亡（RCD） |
|------|------------------------|------------------------|
| 诱因 | 剧烈创伤、烧伤、剧毒化学物 | 温和的内外损伤，或生理过程 |
| 可否逆转 | 不可避免、无法逆转 | 可被遗传学方法或药物逆转 |
| 分子机器 | 无特异蛋白质复合体 | 有遗传编码的蛋白质装置 |
| 执行方式 | 结构被直接破坏 | 膜通透性转变、打孔、脂过氧化、破裂或片段化 |
| 成员 | 经典的急性坏死 | 凋亡、程序性坏死、自噬性死亡、焦亡、铁死亡 |
| 生理亚类 | 无 | 生理条件下的 RCD 称为 PCD |
:::

:::derivation{label="NCCD 怎样把死亡重新分家"}
1. 19 世纪起显微镜看见死亡；1970 年代前一律叫坏死。
2. 1972–1973 年按形态分出凋亡、坏死和自噬性死亡。
3. 此后 30 年按生化和功能又命名 10 余种新方式。
4. 2005 年起 NCCD 建议分类并不断修正。
5. 2015 年起按是否可控分为 ACD 与 RCD；生理条件下的 RCD 再称为 PCD。
6. 形态仍用于辨认，判决权交给“有没有可被关掉的分子机器”。
:::

:::cause-effect{title="为什么要用蛋白质复合体来定义 RCD"}
- 因：温和损伤或发育信号本身不一定立刻把细胞物理摧毁
- 因：细胞装配 DISC、凋亡体、坏死复合体、炎症小体或脂质过氧化系统等遗传编码装置
- 果：下游造成膜打孔、脂过氧化、破裂或片段化；用基因敲除或药物拆掉装置，死亡可被逆转
- 结果：RCD 是“程序在跑”，ACD 是“机器被砸毁”；同一坏死外表，既可能是 ACD，也可能是坏死性凋亡
:::

:::concept{term="形态是名片，可控性是户籍"}
皱缩、凋亡小体指向凋亡；肿胀、膜破、炎症指向坏死样死亡。但焦亡、坏死性凋亡和铁死亡都可以是坏死样外表。NCCD 用“有没有可逆转的蛋白质机器”上户籍：有机器的进 RCD，没机器、来不及组装的进 ACD。只背形态，第四节四种死亡会混成一锅坏死。
:::

第三节专门把凋亡写成主动自杀的样板：DNA 梯状条带、caspase 级联，以及死亡受体途径与线粒体途径。其他 RCD 的执行器——MLKL、gasdermin、脂质过氧化——留在第四节对照。

:::keypoint{label="死亡先问可控，再问哪一台机器"}
- 死亡可以是病理的，也可以是发育程序；快慢取决于损伤是否剧烈。
- 凋亡：皱缩、凋亡小体、无炎症；坏死：肿胀、膜破、有炎症。
- 坏死外表可以是 ACD，也可以是可被 Nec-1 逆转的坏死性凋亡。
- 2015 年起按可控性分成 ACD 和 RCD；生理条件下的 RCD 叫 PCD。
- 凋亡、坏死性凋亡、自噬性死亡、焦亡、铁死亡都是 RCD，执行器不同。
:::

:::memory{label="本节必背要点"}
- [ ] 细胞死亡：生命现象的终结；剧烈因子可迅速致死，非剧烈因素下有自然过程；病理与生理发育均可发生。
- [ ] 1970 年代前所有死亡称坏死；1972 年命名凋亡；1973 年按电镜形态分出凋亡、坏死和自噬性死亡；其后又命名 10 余种。
- [ ] 凋亡：特定信号触发死亡级联的主动性死亡；皱缩，染色质固缩贴核膜，膜包裹形成凋亡小体，吞噬后无炎症。
- [ ] 坏死：致病因子强行终止生命活动的病理性、被动性死亡；肿胀，膜破裂，内容物外溢，引起炎症。诱因可以是物理、化学或生物因子。
- [ ] 程序性坏死/坏死性凋亡：坏死样表型，但可被小分子抑制剂逆转，显示程序性调控。
- [ ] 自噬性细胞死亡：胞质大量自噬囊泡，且分子上严格依赖自噬；过度自噬可致死，抑制自噬后不再死亡才算。
- [ ] 焦亡：细胞胀大至膜破裂，内容物和大量促炎细胞因子释放；发生更快，是抗感染固有免疫。
- [ ] 铁死亡：铁依赖性脂质过氧化物过度累积；区别于凋亡、坏死和自噬性死亡。
- [ ] NCCD 自 2005 年建议分类；2015 年起按是否可控分为 ACD 和 RCD。
- [ ] ACD：剧烈创伤、烧伤、剧毒，不可避免、无法逆转。
- [ ] RCD：温和损伤或生理过程，有特异蛋白质复合物，可被遗传或药物逆转；像遗传编码的分子机器，造成膜通透性转变、打孔、脂过氧化、破裂或片段化。
- [ ] RCD 包括凋亡、程序性坏死、自噬性死亡、焦亡、铁死亡。
- [ ] PCD：生理条件下发生的 RCD，可以是凋亡，也可以是自噬依赖性死亡或程序性坏死；PCD ≠ 凋亡的别名。
:::
