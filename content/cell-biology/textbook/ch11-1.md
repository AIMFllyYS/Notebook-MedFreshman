# 第一节 细胞微环境的组成

第十章把细胞写成用连接装置和黏附分子彼此铆住的社会；本章把镜头再拉远一格：细胞还活在由邻居、基质、可溶性调节因子和液体共同构成的局部区域里。这个区域叫细胞微环境。

1978 年，R. Schofield 提出“微环境”（microenvironment）假说，用来描述支持干细胞生长的生理性微环境。其后这一概念从造血干细胞龛扩展到几乎所有组织：微环境维持组织结构的有序性和稳定性，并以动态平衡即微环境稳态的方式保持细胞的正常生命活动。微环境成分一旦异常，就与肿瘤发生发展、组织器官纤维化等病理过程绑在一起，是细胞生物学和医学共同的前沿。

:::definition{label="细胞微环境"}
细胞微环境（cellular microenvironment）是由相邻细胞和非细胞成分共同构成的局部区域。它参与维持细胞所在组织结构的有序性和稳定性，并调控细胞的增殖、分化、黏附、迁移和代谢等功能活动。
:::

:::definition{label="微环境稳态"}
微环境稳态（microenvironmental homeostasis）是细胞微环境以动态平衡的方式保持细胞正常生命活动的状态。组分之间互相制约、互相补偿；平衡被病理因素打破又不能重建时，细胞行为随之改变，疾病随之发生。
:::

细胞微环境主要由四类组分构成：不同类型的细胞、细胞外基质、细胞外调节因子，以及作为溶剂和运输介质的液体物质。它们不仅对细胞起支持、保护、连接和营养作用，而且直接参与细胞的基本生命活动。细胞与微环境稳态一旦失衡，就会诱发多种疾病。第四节将把这条线索接到肿瘤和纤维化；本节先把四类组分拆开。

:::definition{label="液体微环境"}
液体物质是微环境中的溶剂相，主要包括组织液、淋巴液以及浆膜腔和关节腔内的液体。营养物、气体、代谢废物和可溶性调节因子都溶解或悬浮其中，使细胞外基质的凝胶相和纤维网架成为可灌注的空间，而不是一块干的支架。
:::

## 一、微环境的细胞成分

微环境里的细胞名单随组织而变。实质细胞是该组织执行功能的主角；间质细胞则提供支架、血管、免疫监视和可溶性信号。没有一份适用于所有器官的“标准邻居表”，但有一条通例：微环境中的非实质细胞并不是背景群众，它们分泌基质、细胞因子，并与实质细胞互相识别。

肿瘤细胞微环境把这条通例放大到可以看见。其中存在大量间质细胞（mesenchymal cell），包括炎症细胞、内皮细胞、脂肪细胞和肿瘤相关成纤维细胞等。间质细胞与肿瘤细胞相互作用，为肿瘤细胞的生长、侵袭以及逃避免疫系统攻击提供条件。部分间质细胞还分泌多种细胞因子，促进肿瘤的转移和定植，并参与抗原呈递。具体机制见第四节。

:::definition{label="间质细胞"}
间质细胞（mesenchymal cell）是微环境中与实质细胞相对的支持性细胞，包括成纤维细胞、内皮细胞、脂肪细胞和各类炎症细胞等。它们合成细胞外基质、分泌细胞因子，并与实质细胞（或肿瘤细胞）相互作用，从而影响增殖、侵袭和免疫逃逸。
:::

:::concept{term="邻居名单随组织改写"}
软骨微环境几乎看不到血管和淋巴；肿瘤微环境则挤满活化的成纤维细胞、巨噬细胞和内皮细胞。看见“微环境”不要默认为同一张细胞表。先问：这是哪一种组织、处于发育、稳态还是病理？细胞成分不同，后面的基质和因子也会跟着换。
:::

:::note{label="肿瘤微环境是细胞成分最被写清楚的例子"}
炎症细胞、内皮细胞、脂肪细胞、肿瘤相关成纤维细胞，再加上被募集的巨噬细胞和功能被抑制的 T 细胞，构成实体瘤周围最常见的细胞群落。本节只负责认出这些角色；它们如何改写基质、如何关掉 T 细胞，放到第四节展开。
:::

## 二、细胞外基质

细胞外基质（extracellular matrix，ECM）是细胞微环境的核心组分，由细胞合成并分泌到细胞外空间，主要是蛋白与多糖（或蛋白聚糖）构成的精密有序三维网状结构。ECM 可以填在细胞之间，形成间质性基质（interstitial matrix）；也可以铺在内皮细胞和上皮细胞基底面，形成基膜（basal lamina，basement membrane）。

:::definition{label="细胞外基质"}
细胞外基质（extracellular matrix，ECM）是细胞合成并分泌到胞外的三维网状结构，主要由蛋白聚糖、胶原与弹性蛋白、以及纤连蛋白和层粘连蛋白等非胶原糖蛋白构成。它既是结构支架，也是黏附受体的配体库和生长因子的储存库。
:::

:::definition{label="间质性基质与基膜"}
间质性基质是填充于细胞之间的 ECM，在结缔组织中最丰富。基膜是 ECM 的特化网膜，厚约 $40\sim 120\,\mathrm{nm}$，位于上皮和内皮的基底部，或包绕肌细胞、脂肪细胞，并在肾小球中作为滤过膜的主要结构。
:::

ECM 贴在细胞周围，是细胞赖以生存的微环境。细胞通过 ECM 使细胞与细胞、细胞与基膜之间紧密联系，从而装配成组织和器官。功能可以先记两条，细节在第二节展开。

**（1）结构支持、保护和营养。** ECM 中的生物大分子织成三维网，承受张力与压力，限制细胞的位移，并保留水分和可溶性分子。

**（2）信号转导与因子储存。** ECM 通过黏附受体（主要是整联蛋白）向细胞内传信；同时结合、储存并在蛋白酶作用下释放生长因子和其他生物活性分子。血管组织是一个清楚的例子：ECM 既作为结构物质支持血管形成，也是血管生成促进因子和抑制因子的仓库；蛋白酶把这些分子从基质上“剪”下来，才能作用于内皮细胞或微环境中的其他细胞。

ECM 的结构或功能异常，与组织器官纤维化、肿瘤浸润转移以及创伤修复等病理过程直接相关。把基质只写成“胶水”，后面无法解释为什么切一刀胶原酶，细胞的命运会一起改写。

:::cause-effect{title="基质仓库如何变成血管生成开关"}
- 因：血管壁 ECM 结合并储存血管生成促进因子和抑制因子
- 因：局部蛋白酶被激活，把这些分子从基质上释放或剪切激活
- 果：游离的活性分子作用于内皮细胞，促进或抑制新血管形成
- 结果：同一张基质网既是血管的支架，也是血管生成信号的缓冲器；仓库一旦被病理蛋白酶打开，出芽或纤维化都会失控
:::

:::compare{title="间质性基质 vs 基膜"}
| 项目 | 间质性基质 | 基膜 |
|------|------------|------|
| 位置 | 细胞与细胞之间，结缔组织中最丰富 | 上皮/内皮基底面；包绕肌细胞和脂肪细胞；肾小球两层细胞之间 |
| 主要纤维 | Ⅰ、Ⅱ、Ⅲ 型等纤维状胶原，弹性纤维 | Ⅳ 型胶原织成的二维网络 |
| 标志黏着蛋白 | 纤连蛋白 | 层粘连蛋白 |
| 特征蛋白聚糖 | 蛋白聚糖聚合体、饰胶蛋白聚糖等 | 串珠蛋白聚糖 |
| 厚度/形态 | 因组织而异，可形成透明片层或绳索样结构 | 柔软坚韧的网膜，约 $40\sim 120\,\mathrm{nm}$ |
| 代表性功能 | 抗张、抗压、引导迁移 | 支撑上皮、分子筛滤、阻挡成纤维细胞进入表皮 |
:::

:::pitfall{label="微环境不等于细胞外基质"}
ECM 是核心组分，但不是全部。微环境还包括邻居细胞、激素与细胞因子、剪切流等力学信号，以及液体相。考试里把“微环境异常”直接写成“胶原变了”，会把免疫细胞、PD-1/PD-L1 和 TGF-$\beta$ 自分泌环全部漏掉。基质是舞台，不是整出戏。
:::

## 三、细胞外调节因子

信号分子和细胞因子是微环境中重要的细胞外调节因子。激素、神经递质等体内信号分子与细胞受体结合，在细胞间和细胞内传递信息。按溶解性，信号分子分为亲水性和亲脂性两类：亲水性分子不能穿过脂双层，必须认细胞表面受体；亲脂性分子可以入胞，认细胞内受体。这两套受体将在第十二章展开；本节只强调它们是微环境的可溶（或局部结合）组分。

:::definition{label="细胞外调节因子"}
细胞外调节因子是微环境中调控细胞行为的信号分子和细胞因子，包括激素、神经递质、各类生长因子和免疫因子等。它们或溶于液体相，或被 ECM 储存后释放，通过与特异受体结合调节免疫应答、增殖分化和损伤修复。
:::

:::definition{label="细胞因子"}
细胞因子（cytokine）是由免疫细胞（单核细胞、巨噬细胞、T 细胞、B 细胞、NK 细胞等）以及内皮细胞、表皮细胞、成纤维细胞等分泌的蛋白信号分子。它们与特异受体结合，调节免疫应答、增殖分化和损伤修复；在肿瘤微环境中，其信号通路异常可推动肿瘤的发生、发展和转移。
:::

细胞外调节因子除了生物化学上的多样性和特异性，还具有生物物理学上的多样性，包括分子结构的力学特性，以及微环境剪切流（shear flow）等。血流或组织液的剪切力可以改变受体构象、影响因子递送，使“同一分子、不同力学环境”写出不同的细胞应答。把调节因子只记成一张浓度表，会漏掉这半边物理语言。

:::concept{term="微环境是稳态，不是布景板"}
细胞在改写微环境：合成或降解基质、分泌或清除因子、募集或赶走邻居。微环境也在改写细胞：决定它贴不贴得住、分不分裂、迁不迁移。Schofield 当初用这个词描述干细胞龛，正是因为龛一变，干细胞的命运就变。把微环境理解成“细胞外面那层不动的垫子”，既解释不了创伤修复，也解释不了肿瘤为什么能把垫子改造成帮凶。
:::

:::keypoint{label="微环境的四块积木"}
- 细胞微环境 = 相邻细胞 + 细胞外基质 + 细胞外调节因子 + 液体物质。
- 稳态是动态平衡；失衡且不能重建，就会改写细胞行为并诱发疾病。
- ECM 是核心组分：间质性基质填缝，基膜铺底或包绕；既承力，也储信号。
- 间质细胞在肿瘤微环境中尤其活跃，为生长、侵袭和免疫逃逸提供条件。
- 调节因子既有化学特异性，也有力学和剪切流等物理维度。
:::

- [ ] 微环境稳态（microenvironmental homeostasis）以动态平衡保持正常生命活动。
