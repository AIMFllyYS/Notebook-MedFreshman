# 第五节 细胞骨架与疾病

细胞骨架对细胞的形态维持和改变、细胞内物质运输、细胞分裂与分化具有重要作用。骨架纤维的装配失衡、结合蛋白异常或组织特异性中间纤维基因突变，都会把这些基本功能写成临床表型，涉及肿瘤、神经系统疾病和遗传性疾病等。反过来，不同细胞骨架在细胞内的特异性分布可用于疾病诊断，也可根据骨架与疾病的关系来设计药物。

:::definition{label="细胞骨架病"}
细胞骨架病并不是单一病名，而是一类以微管、微丝、中间纤维或其结合蛋白、马达蛋白异常为主要环节的疾病。病变可以表现为纤维解聚或过度稳定、错误交联、运输阻滞或组织特异性网络崩溃，并因此出现侵袭、神经变性、表皮起疱或纤毛不动等表型。
:::

## 一、细胞骨架与肿瘤

在恶性转化的细胞中，细胞常表现为细胞骨架结构的破坏和微管解聚。在肿瘤细胞的浸润转移过程中，某些骨架成分的改变可增加肿瘤细胞的运动能力。体外培养的肿瘤细胞中，免疫荧光染色显示微管数量减少，微管网络紊乱甚至消失；应力纤维破坏和消失，肌动蛋白发生重组，形成小体，聚集分布在细胞皮层。由于其形状为小球形或不规则，被命名为“肌动蛋白小体”“皮层小体”，以及“面包圈”“玫瑰花”小体等。这些改变削弱了正常的形状约束，增加了肿瘤细胞的运动能力。

因此，微管和微丝可作为肿瘤化疗药物的作用靶点。长春新碱、秋水仙碱和细胞松弛素及其衍生物等，正是通过分别打断微管或微丝的动态，使肿瘤细胞无法完成有丝分裂或胞质分裂，从而成为有效的化疗药物。紫杉醇则把微管锁在聚合态，同样使纺锤体失去必要的动态，停在分裂期。

另外，不同类型的中间纤维严格分布于不同类型的细胞中，而绝大多数肿瘤细胞通常继续表达其来源细胞特征性的中间纤维类型；即便在转移后，仍表达其原发肿瘤中的特定中间纤维。因此，中间纤维的表达类型可用于区分肿瘤细胞的类型及其来源，是肿瘤病理诊断中常用的免疫组化依据。

:::concept{term="中间纤维是肿瘤的“出身证明”"}
微管蛋白和肌动蛋白几乎在所有细胞中都有，做不出组织来源。角蛋白指向上皮癌，波形蛋白指向间叶来源，GFAP 指向胶质瘤，结蛋白指向肌源性肿瘤，神经丝指向神经元分化。转移灶长在肺里，只要中间纤维类型仍是原发器官那一套，就能把“从哪里来”读出来。
:::

:::cause-effect{title="骨架重排如何助长肿瘤侵袭"}
- 因：恶性转化使微管网络解聚、紊乱，应力纤维破坏
- 因：肌动蛋白在皮层重组成小体，伪足形成能力增强
- 果：细胞失去正常形状约束，整联蛋白—微丝黏附周期被改写
- 果：迁移和穿越基质的能力上升
- 结果：肿瘤细胞更易浸润周围组织并形成转移
:::

:::cause-effect{title="抗微管药物如何杀死分裂中的肿瘤细胞"}
- 因：长春新碱、秋水仙碱抑制微管蛋白聚合，或紫杉醇过度稳定微管
- 因：纺锤体无法完成“聚合—解聚”的动态探路和染色体双向附着
- 果：有丝分裂纺锤体检查点持续激活，细胞阻滞于 M 期
- 结果：增殖迅速的肿瘤细胞优先被杀死；神经等依赖长轴突运输的组织则成为剂量限制性毒性的来源
:::

:::pitfall{label="中间纤维分型不能代替组织学诊断"}
转移后的肿瘤细胞多数仍表达原发类型的中间纤维，这是重要线索，但去分化、混合分化或上皮—间质转化会使波形蛋白与角蛋白同时出现。中间纤维免疫组化是出身鉴定，不是单证定罪。
:::

:::note{label="化疗打的是动态，不是“把管子拆光”"}
肿瘤细胞要的是能迅速改建的纺锤体和皮层。紫杉醇让微管不能拆，秋水仙碱让微管不能装，细胞松弛素让微丝正端不能加——三条路都是让动态停摆。稳定和打散在治疗逻辑上是对称的。
:::

## 二、细胞骨架蛋白与神经系统疾病

许多神经系统疾病与细胞骨架蛋白的异常表达有关。神经元拥有人体最长的微管轨道，轴突运输对 MAP 和神经丝的依赖也最明显，因此骨架异常往往先在神经系统显露。

### （一）阿尔茨海默病中的 tau 与神经原纤维缠结

在阿尔茨海默病（Alzheimer's disease，AD，也称老年性痴呆）患者的神经元中，可见到不溶性神经原纤维缠结（neurofibrillary tangle，NFT），主要由高磷酸化状态的 tau 蛋白组成。tau 是一种微管结合蛋白，正常情况下结合并稳定轴突微管。过度磷酸化的 tau 对微管的亲和力降低，从微管上脱落并彼此聚集，从而使微管稳定性降低。AD 患者神经元中微管蛋白的数量并无异常，但存在微管聚集缺陷——零件还在，轨道却拼不起来。

:::definition{label="神经原纤维缠结"}
神经原纤维缠结（NFT）是阿尔茨海默病神经元内的不溶性纤维聚集体，主要成分为过度磷酸化的 tau。tau 脱离微管后，轴突微管失稳、顺向运输受阻，突触和远端轴突逐渐萎缩。
:::

:::cause-effect{title="tau 过度磷酸化导致轴突微管失稳"}
- 因：tau 被异常激酶过度磷酸化，对微管亲和力下降
- 因：游离的高磷酸化 tau 聚集成神经原纤维缠结
- 果：轴突微管不能正常成束和稳定，虽然微管蛋白数量并不减少
- 果：驱动蛋白依赖的顺向运输（突触小泡、线粒体）发生障碍
- 结果：神经元远端营养中断，出现阿尔茨海默病的变性表型
:::

### （二）运动神经元病中的神经丝堆积

在肌萎缩侧索硬化（amyotrophic lateral sclerosis，ALS）和婴儿型脊髓性肌萎缩（infantile spinal muscular atrophy）中，神经原纤维在运动神经元胞体和轴突近端的堆积是神经元退化的早期表现。随后运动神经元丧失，导致骨骼肌失去神经支配而萎缩，造成瘫痪，最终死亡。神经丝本应在轴突中形成抗拉的核心并保持口径，一旦在胞体和近端轴突堵成团，远端轴突的物资供应和机械完整性一起垮掉。

:::concept{term="运输堵塞比“缺少骨架”更常见"}
AD 是微管轨道拆掉（tau 脱落），ALS 等则是中间纤维在路口堆车（神经丝滞留）。两种病变看起来都是“骨架坏了”，一个是路没了，一个是路被占了。看见纤维聚集体，先问它是从轨道上掉下来的结合蛋白，还是本该运走却卡住的结构蛋白。
:::

:::cause-effect{title="神经丝堆积如何毁掉运动神经元"}
- 因：神经丝蛋白在运动神经元胞体和轴突近端异常聚集
- 因：轴突运输通道被占据，细胞体与神经肌肉接头之间的物资往来中断
- 果：运动神经元逆行性退化、死亡
- 结果：骨骼肌失神经支配而萎缩，出现 ALS 或婴儿型脊髓性肌萎缩的瘫痪表型
:::

## 三、细胞骨架与遗传性疾病

一些遗传性疾病的患者常有细胞骨架的异常，或编码细胞骨架蛋白的基因发生突变。这类疾病把第三节强调的“组织特异性”写进了家系：突变落在哪一种中间纤维或哪一套轴丝马达上，受累的就是那一种组织。

### （一）单纯型大疱性表皮松解症

人类遗传性疾病单纯型大疱性表皮松解症（epidermolysis bullosa simplex）是由于表皮细胞层表达的角蛋白基因突变，破坏了表皮细胞的角蛋白中间纤维网络，导致表皮细胞对机械损伤非常敏感。轻微的挤压就可使突变的细胞破坏，患者皮肤起疱。在人类或小鼠中，凡带有这种突变基因的个体都变得很脆弱，常常死于机械创伤。这是中间纤维“提供机械强度”这一功能最直接的人体证据：网络一断，上皮细胞无法把剪切力传导到桥粒和半桥粒，细胞自己裂开。

:::cause-effect{title="角蛋白突变使表皮一碰即破"}
- 因：表皮角蛋白（Ⅰ型或 Ⅱ型）基因突变，卷曲螺旋或头尾结构破坏
- 因：角蛋白中间纤维网络不能在基底层细胞中正确装配并连到桥粒/半桥粒
- 果：机械负荷无法在细胞和组织之间分散，基底层细胞在剪切下破裂
- 结果：轻微摩擦即形成表皮内水疱，表现为单纯型大疱性表皮松解症
:::

### （二）纤毛不动综合征

纤毛不动综合征是一种由纤毛结构缺陷引起的常染色体隐性遗传病。据统计，它占男性不育因素的 1.14%。除导致男性不育外，还伴随慢性支气管炎、支气管扩张、慢性鼻窦炎、中耳炎、内脏反位等。最常见的病理变化是动力蛋白臂异常，其次为放射辐条和中心微管异常，甚至有的患者纤毛或鞭毛无中心微管或无轴丝。

精子鞭毛不能波动，自然造成不育；呼吸道纤毛不能把黏液向外输送，痰液潴留继发感染和扩张；胚胎期节点纤毛若不能形成定向液流，左右不对称信号就会随机化，于是出现内脏反位。同一套“9+2”零件，在不同器官写出不同的病历。

:::cause-effect{title="动力蛋白臂缺陷导致纤毛不动综合征"}
- 因：轴丝动力蛋白臂（或放射辐条、中央微管）先天缺失或结构异常
- 因：ATP 水解无法转换成相邻二联管的滑动和弯曲
- 果：呼吸道纤毛不能清扫黏液，精子鞭毛不能波动，胚胎节点纤毛不能规定左右轴
- 结果：慢性鼻窦炎—支气管扩张、男性不育，部分患者伴内脏反位（Kartagener 综合征谱系）
:::

:::compare{title="三类骨架相关疾病的定位"}
| 类别 | 分子环节 | 典型疾病 | 主要受累 |
|------|----------|----------|----------|
| 微管动态/MAP | tau 过度磷酸化，微管不能成束；化疗药物打击纺锤体 | 阿尔茨海默病；抗微管化疗的神经毒性 | 轴突运输；分裂期肿瘤细胞 |
| 微丝皮层 | 应力纤维消失、肌动蛋白小体；细胞松弛素类 | 肿瘤侵袭表型 | 迁移、胞质分裂 |
| 中间纤维网络 | 角蛋白、神经丝等组织特异性突变或堆积 | 单纯型大疱性表皮松解症；ALS 等 | 表皮抗拉；运动神经元轴突 |
| 轴丝马达 | 动力蛋白臂/辐条/中央微管缺陷 | 纤毛不动综合征 | 呼吸道、精子、左右不对称 |
:::

:::insight{label="同一套零件，坏在不同位置就换一种科"}
微管结合蛋白坏了进神经科，角蛋白坏了进皮肤科，动力蛋白臂坏了进呼吸科和生殖医学，核纤层蛋白坏了还会进心脏和衰老相关病。学习细胞骨架不要停在“三种纤维的直径”，要把纤维、结合蛋白和马达对应到会就诊的器官。
:::

:::tip{label="诊断时先问“哪一类纤维、哪一种细胞”"}
免疫组化看中间纤维类型，电镜看轴丝有没有动力蛋白臂，生化看 tau 磷酸化和微管成束。三种检查分别对准第三节的组织特异性、第四节的滑动模型和第一节的 MAP 分区，比笼统地说“骨架异常”更接近可治疗的环节。
:::

:::keypoint{label="从纤维到病床"}
- 肿瘤：微管/微丝动态既是侵袭的帮凶，也是化疗的靶点；中间纤维类型泄露肿瘤出身。
- 神经：tau 脱落拆轨道，神经丝堆积堵轨道，运动和认知系统最先倒下。
- 遗传：角蛋白决定皮肤能不能扛摩擦，轴丝动力蛋白决定纤毛和鞭毛能不能弯。
- 治疗和诊断都建立在前四节的结构知识上，而不是另起一套名词。
:::

:::memory{label="本节必背要点"}
- [ ] 肿瘤细胞常见微管解聚、网络紊乱，应力纤维消失，皮层出现肌动蛋白小体（面包圈、玫瑰花等形态）。
- [ ] 微管和微丝是化疗靶点：长春新碱、秋水仙碱抑制聚合，紫杉醇稳定微管，细胞松弛素抑制微丝聚合。
- [ ] 肿瘤细胞即使转移仍多表达来源细胞的中间纤维类型，可用于判断起源。
- [ ] 阿尔茨海默病：NFT 主要由高磷酸化 tau 组成；微管蛋白数量可正常，但微管聚集缺陷。
- [ ] ALS 和婴儿型脊髓性肌萎缩：神经原纤维在运动神经元胞体及轴突近端堆积，随后失神经、肌萎缩。
- [ ] 单纯型大疱性表皮松解症：表皮角蛋白突变，中间纤维网络破坏，轻微挤压即起疱。
- [ ] 纤毛不动综合征：常染色体隐性；约占男性不育因素的 1.14%。
- [ ] 纤毛不动综合征伴慢性支气管炎、支气管扩张、鼻窦炎、中耳炎、内脏反位；最常见病理是动力蛋白臂异常。
- [ ] 骨架异常可以是解聚、过度稳定、运输堵塞或组织特异性网络崩溃，临床表型随受累纤维和组织而异。
:::
