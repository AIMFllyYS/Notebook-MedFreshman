# 第三节 细胞周期与医学

前两节把分裂写成可以看到的形态学，把周期写成 cyclin–Cdk 和检查点锁住的时间表。这些开关一旦卡住或被拧死，临床表型就会出现：该增殖的组织长不出来，不该增殖的细胞停不下来，该修复的基因组把突变传给子代。本节把周期接到组织再生、肿瘤、获得性免疫缺陷和细胞衰老上。

:::definition{label="组织再生"}
组织再生是机体组织组成细胞因生理或病理原因不断死亡后，由新细胞替代和修复受损组织的过程。人体组织细胞每天的更新率约 $1\%\sim 2\%$。细胞增殖是组织再生的基础。
:::

:::definition{label="肿瘤"}
肿瘤是生物体正常组织细胞过度增殖后形成的赘生物。其产生与细胞周期调控异常密切相关：正负调节因子失衡造成高增殖，检查点失效造成基因组高度不稳定。
:::

## 一、细胞周期与组织再生

### （一）生理性再生依赖干细胞持续过周期

生理性再生与干细胞分裂增殖直接相关，常见于正常人体的骨髓、皮肤表皮和肠上皮等组织。新细胞不断产生，以替代逐渐衰老、死亡的细胞，借此维持组织细胞数量基本恒定，同时使组织处于不断更新状态。第二节把这类细胞写成周期细胞：基底层和隐窝上皮走完整的 G1—S—G2—M 圆环。

造血干细胞在骨髓细胞中所占比例仅为 $0.25\%$，但一个造血干细胞经一天分裂后，经分化可形成 $12$ 种结构与功能不同的血细胞；其中仅外周血红细胞数量就可达 $200\,000$ 个，粒细胞约 $1\,000$ 个。如果细胞增殖受到抑制，会导致相关疾病：造血干细胞增殖障碍引起再生障碍性贫血，生殖细胞增殖障碍引起不育。

### （二）补偿性再生把 G0 细胞召回周期

:::definition{label="补偿性再生"}
补偿性再生是指机体一些高度分化、一般不发生增殖的组织（如肝、肾、骨骼等）在组织损伤后可恢复增殖能力的现象。损伤刺激原处于 G0 期的细胞重新进入周期，同时周期进程加快、所需时间显著缩短，从而在短时期内产生大量新生细胞，促进创伤后修复。
:::

若切除小鼠 $70\%$ 的肝脏，存留的肝细胞 $24$ 小时后分裂指数可提高近 $200$ 倍。第二节强调 G0 不是终末分化：肝实质细胞保留返回 G1 并越过限制点的能力，切掉大部分肝脏等于把限制点重新打开。

:::cause-effect{title="肝部分切除如何写成补偿性再生"}
- 因：切除大部分肝组织，残存肝细胞受到损伤相关信号和生长因子刺激
- 因：原处于 G0 的肝细胞重返 G1，越过限制点，周期时间显著缩短
- 果：$24$ 小时内分裂指数可提高近 $200$ 倍，短时期内产生大量新生肝细胞
- 结果：肝脏体积和功能被补偿性恢复；临床用生长因子促进创伤修复，走的是同一条召回 G0 的路
:::

在临床治疗中，刺激细胞增殖以增强补偿性再生是治疗创伤等相关疾病的重要策略。多使用促使分化细胞重新分裂、增殖的细胞因子、生长因子，常见有 EGF、IL-2、碱性成纤维细胞生长因子（bFGF）等。角膜移植和外科手术后常用 EGF 促进伤口愈合，bFGF 则可用于慢性软组织溃疡的治疗。这些因子的调节点仍在 G1：把细胞从 G0 推回 G1，或帮助 G1 细胞越过限制点。

:::note{label="再生障碍是周期过不了，不是“没有细胞”"}
再障是造血干细胞增殖障碍，不育可以是生殖细胞增殖障碍。治疗创伤时给 EGF、bFGF，目的是让 G0 或受限的 G1 细胞重新过 R 点，而不是凭空多造一种组织。把再生写成“补营养”，会漏掉第二节已经写过的生长因子–限制点通路。
:::

## 二、细胞周期异常与肿瘤发生

了解肿瘤细胞周期的特点，研究其形成机制，对临床诊断及治疗有重要意义。肿瘤细胞周期异常主要写在三层：增殖快、基因组不稳、以及因此而来的治疗入口。

### （一）肿瘤细胞具有高增殖性

肿瘤细胞可以自分泌大量生长因子，摆脱对细胞外生长因子的依赖，并获得抵御胞外抑制因子的能力，从而极大程度刺激自我生长及增殖。肿瘤细胞总体活跃细胞多，群体数目增加很快，因此一般比正常组织细胞增殖快。

肿瘤细胞中也存在少量 G0 期细胞。这些细胞可能为肿瘤前体细胞，虽暂不增殖，但在一定条件下可重新进入周期，补充产生新的肿瘤细胞。放、化疗使肿瘤细胞大量死亡时，可激发 G0 期肿瘤细胞或肿瘤干细胞的增殖、分化，成为肿瘤复发的根源。第二节把 G0 写成可逆休眠；在肿瘤里，这份可逆性变成了治疗的盲区。

:::pitfall{label="化疗杀的是过周期的细胞，杀不掉睡在 G0 的那一小群"}
秋水仙碱、阿糖胞苷都作用于正在走 S 或 M 的细胞。G0 肿瘤细胞不复制、不分裂，药物打不中；残留灶一旦被死亡信号唤醒，重新过 R 点，肿瘤就复发。把“缓解”写成“肿瘤细胞已经被全部杀死”，会漏掉第二节的三类细胞群体。
:::

周期中某些重要调节因子异常、正负调节因子失衡，是肿瘤高增殖性的重要原因。其中，原癌基因与抑癌基因的平衡失调是无限增殖的重要机制。

:::definition{label="原癌基因"}
原癌基因（proto-oncogene）是细胞内与细胞增殖相关的基因，是维持机体正常生命活动所必需的，在进化上高度保守。成员包括 src、ras、sis、myc、myb 等基因家族，产物主要分为生长因子类、生长因子受体类、胞内信号转导相关蛋白及转录因子类，参与对周期的调控。
:::

:::definition{label="癌基因"}
癌基因（oncogene）是原癌基因经点突变、基因扩增或重排等改变后的形式。它通常因获得新的表达产物而过度刺激细胞增殖，把原本受节制的周期驱动拧成持续开启。
:::

:::definition{label="抑癌基因"}
抑癌基因是正常细胞所具有的、能抑制细胞恶性增殖的基因。其编码蛋白通常能与转录因子结合或本身即为转录因子，作为负调控因子影响周期相关蛋白合成及 DNA 复制。已分离鉴定数十种，其中 Rb、p53、p21、p16 的作用机制研究较为深入。
:::

细胞增殖有赖于原癌基因与抑癌基因的平衡。一旦原癌基因过度促进增殖，或抑癌基因的抑制作用减弱或丧失，平衡打破，增殖失去控制。

原癌基因可发生点突变、基因扩增、重排等，转化成为癌基因。例如 ras 突变构成癌基因后，表达产物 Ras 蛋白构型改变，与 GTP 解离减少；失去 GTP/GDP 的有节制调节后，结合 GTP 的 Ras 持续活化，持续激活磷脂酶 C 产生第二信使，造成细胞不可控制地增殖。第十二章把 Ras 写成 GTP 结合开关；这里开关拧不回去，周期就停不下来。

抑癌基因功能丧失同样促进增殖失控。约 $50\%$ 的人类肿瘤中发现 p53 基因突变，导致 p53 蛋白失活。p53 可作为转录因子，促进 p21$^{\mathrm{Cip1/Waf1}}$ 基因转录。p21$^{\mathrm{Cip1/Waf1}}$ 是一种 CKI，抑制 Cdk 活性，使 Rb 磷酸化受阻，与 S 期相关的转录因子 E2F 不能被释放，DNA 复制不能进行，细胞无法从 G1 进入 S。p53 也在检查点发挥枢纽作用：DNA 损伤时，它在周期阻滞、DNA 修复乃至凋亡等多个事件中决定细胞转归。第二节图 13-16 已经把这条链画出来；肿瘤里缺的就是这根刹车。

:::compare{title="原癌基因 vs 抑癌基因"}
| 项目 | 原癌基因 / 癌基因 | 抑癌基因 |
|------|-------------------|----------|
| 正常功能 | 推动增殖（生长因子、受体、信号蛋白、转录因子） | 抑制恶性增殖，影响周期蛋白合成和 DNA 复制 |
| 代表 | src、ras、sis、myc、myb | Rb、p53、p21、p16 |
| 致病方式 | 点突变、扩增、重排后获得功能，过度刺激增殖 | 突变或失活后丧失负调控 |
| 接到周期的位置 | 如持续活化的 Ras 不断产生第二信使，相当于生长因子信号关不掉 | 如 p53 不能诱导 p21，Cdk 抑制解除，Rb 持续被磷酸化，E2F 释放，G1→S 失控 |
| 检查点 | 不直接充当检查点，但可让细胞无视外源抑制 | p53 是 DNA 损伤检查点的枢纽，决定阻滞、修复或凋亡 |
:::

:::concept{term="肿瘤是油门和刹车同时坏"}
只记住“癌基因打开”不够：许多肿瘤同时丢掉 p53、Rb、p16 这类刹车。油门坏了，细胞对生长因子不依赖；刹车坏了，DNA 损伤也过得了 R 点。复习时把 ras 和 p53 成对记，才能对上“高增殖 + 基因组不稳”这两条临床线索。
:::

### （二）肿瘤细胞周期异常导致基因组高度不稳定

细胞通过严格的检查点最大限度保证遗传稳定。肿瘤细胞各个周期检查点均可能发生异常；失去检查点后，基因扩增、重排、点突变等概率增高，基因组高度不稳定。肿瘤细胞通常存在染色体异常，包括数目异常及结构异常。

染色体分离检查点异常，可导致一些还没有完成纺锤体组装的细胞中发生姐妹染色单体提前分离。有丝分裂中纺锤体的其他行为异常也常伴随染色体异常，如动粒附着、姐妹染色单体的粘连与解离等。第一节把后期写成“粘连蛋白被剪、微管再拉”；检查点一旦不管动粒是否挂好就允许剪切，子代得到的就不是一套完整染色体。

中心体数目扩增是肿瘤细胞的重要特征之一。正常细胞有 $1$ 个中心体，S 期复制后形成 $2$ 个，保障纺锤体形成两个分裂极；超过 $1$ 个乃至数个中心体的肿瘤细胞，分裂时形成多极分裂极，染色体无法均等分配到子细胞中。

:::cause-effect{title="检查点失效如何写成染色体混乱"}
- 因：纺锤体组装或染色体分离检查点失灵，未附着的动粒不再拦住 APC
- 因：中心体扩增，纺锤体出现多个极
- 果：姐妹染色单体提前分离或被拉向多个方向，子代染色体数目和结构都错
- 结果：基因组高度不稳定，突变加速积累，肿瘤演进加快
:::

### （三）肿瘤细胞周期特点可能为治疗提供新思路

阐明肿瘤细胞周期的特点，可为临床治疗提供理论依据。化疗通过选择一定化学药物，干扰肿瘤细胞代谢，阻止其增殖。常用药物在周期中的作用点不同，因而对“正在走哪一段”的细胞杀伤力不同。

:::compare{title="常用化疗药物的周期作用点"}
| 药物 | 周期中的作用点 | 相关机制 |
|------|----------------|----------|
| 放线菌素 D | G1 期、S/G2 期 | 抑制 DNA 聚合酶、DNA 解旋酶及组蛋白等的合成；也能抑制 rRNA 的合成 |
| 阿糖胞苷 | 专一作用于 S 期 | 抑制核苷三磷酸还原酶，使脱氧核糖核苷酸形成受阻，进而阻止 DNA 合成 |
| 秋水仙碱 | 特异性作用于 M 期 | 结合微管蛋白，促使纺锤体微管解聚；阻止中期染色体向两极移动，将有丝分裂阻断在中期 |
| 氮芥 | 无特异性作用点 | 与 DNA 结合使其分子结构改变 |
:::

秋水仙碱把第一节的纺锤体写成药靶：微管解聚，中期不能进入后期。阿糖胞苷把第二节的 S 期核苷酸供应切断。选药等于选周期时相；G0 那一小群仍然不在这些靶点上。

## 三、细胞周期与其他医学问题

### （一）人类免疫缺陷病毒把 T 细胞堵在 G2

细胞周期异常与获得性免疫缺陷综合征（艾滋病）相关。T 细胞受人类免疫缺陷病毒感染后，在 G2 向 M 转化中有重要作用的 Cdk1 酪氨酸残基发生过度磷酸化，由此丧失激酶活性，细胞不能向 M 期转换而滞留于 G2，最终发生凋亡。第二节把 Tyr15 的抑制性磷酸化写成 Cdc25 必须拆掉的刹车；HIV 让这枚磷酸拆不掉，MPF 打不开，T 细胞在 G2 死去。

### （二）衰老细胞把时间花在 G1

细胞衰老时，周期也呈现某些异常：分裂速度明显降低，cyclin A、B 表达下降，cyclin E 不稳定性增加、更易被降解，使得 Rb 不能被磷酸化，与 Rb 结合的转录因子不能发挥相应作用，细胞被阻留于 G1 而不能进入 S。因此与正常细胞相比，衰老细胞中 G1 可持续更长时间。这和限制点过不去是同一句话：cyclin E–Cdk2 不够，E2F 放不出来。

:::note{label="同一套开关，三种临床写法"}
- 再生：把 G0 召回，打开限制点（EGF、bFGF）。
- 肿瘤：油门（ras 等）拧死、刹车（p53/Rb/p21/p16）丢掉，检查点和中心体一起乱。
- 衰老与 HIV：分别卡在 G1（cyclin E 不稳、Rb 不能磷酸化）和 G2（Cdk1 抑制性磷酸化去不掉）。

看见疾病，先问周期停在哪一段、坏的是 cyclin–Cdk 还是检查点。
:::

:::keypoint{label="医学入口在限制点和检查点"}
- 生理性再生靠周期细胞持续循环；补偿性再生靠 G0 细胞重返周期并加速。
- 肿瘤高增殖来自生长因子自给和癌基因/抑癌基因失衡；复发常来自 G0 肿瘤细胞。
- ras 持续结合 GTP、p53 不能诱导 p21，分别是油门和刹车的样板。
- 检查点失效和中心体扩增写成染色体混乱；化疗按 S、M 等时相选靶，但打不中 G0。
:::

- [ ] 人体组织细胞每天更新约 $1\%\sim 2\%$；增殖是组织再生的基础。
- [ ] 生理性再生：骨髓、皮肤表皮、肠上皮等，与干细胞持续分裂直接相关。
- [ ] 造血干细胞约占骨髓细胞 $0.25\%$，一天可分化出 $12$ 种血细胞；外周血红细胞可达 $200\,000$ 个，粒细胞约 $1\,000$ 个。
- [ ] 增殖受抑：造血干细胞障碍→再生障碍性贫血；生殖细胞障碍→不育。
- [ ] 补偿性再生：肝、肾、骨骼等损伤后 G0 细胞重返周期并加速；小鼠切肝 $70\%$，$24$ 小时分裂指数可提高近 $200$ 倍。
- [ ] 促再生常用 EGF（角膜移植、术后伤口）、IL-2、bFGF（慢性软组织溃疡）。
- [ ] 肿瘤细胞可自分泌生长因子，摆脱外源依赖；一般比正常组织增殖快。
- [ ] 肿瘤中少量 G0 细胞/肿瘤干细胞在放化疗后可被激发，成为复发根源。
- [ ] 原癌基因（src、ras、sis、myc、myb）产物为生长因子、受体、信号蛋白或转录因子；突变、扩增、重排后成为癌基因。
- [ ] ras 突变使 Ras–GTP 不能水解/解离，持续激活磷脂酶 C，增殖失控。
- [ ] 抑癌基因代表：Rb、p53、p21、p16；约 $50\%$ 人类肿瘤有 p53 突变。
- [ ] p53 → p21$^{\mathrm{Cip1/Waf1}}$ → 抑制 Cdk → Rb 不能磷酸化 → E2F 不释放 → 不能 G1→S；p53 也决定损伤后的阻滞、修复或凋亡。
- [ ] 检查点异常和中心体扩增导致染色体数目/结构异常及多极分裂。
- [ ] 放线菌素 D：G1 及 S/G2，抑制 DNA/组蛋白/rRNA 合成；阿糖胞苷：专一 S 期；秋水仙碱：M 期解聚纺锤体，阻断在中期；氮芥：无特异时相，直接改 DNA 结构。
- [ ] HIV 感染 T 细胞：Cdk1 酪氨酸过度磷酸化，滞留 G2 并凋亡。
- [ ] 衰老细胞：cyclin A、B 下降，cyclin E 易降解，Rb 不能磷酸化，G1 延长、不能进 S。
:::
