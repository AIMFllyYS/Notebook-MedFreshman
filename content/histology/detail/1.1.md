# 1.1 组织学与胚胎学学习指南：按上皮到胚胎主题摊开

刘少纯、刘德明主编的《组织学与胚胎学学习与解题指南》不是另一本教材，而是把第五版统编教材拆成各章「学习要点」，再配 A 型、C 型、X 型题、名词解释和论述。本篇不按二十七章目录扫描，也不整本粘贴 OCR，而是把真正写在指南里的掌握点重新摊开：先问四种基本组织如何立账，再问循环、消化、呼吸、泌尿、生殖如何把上皮和结缔收成器官，最后接到受精、胚层和胎盘。数字只采用指南写明的户头：胶原原纤维周期性横纹 $64\,\mathrm{nm}$、气血屏障总厚度 $0.2\sim 0.5\,\mu\mathrm{m}$、排卵约在月经周期第 $14$ 天。指南没有写的口诀不要补。

:::insight{label="为什么指南要先问层次再问切片颜色"}
掌握是考试能默写、能比较、能接到切片上的那一档：定义、分类尺子、典型数字、功能落点。熟悉是能说清超微结构和分布，不必逐步默写电镜每一条嵴。把「学习要点」听成「全都背习题」会爆仓；把掌握听成「只背名词」又会在论述里交白卷。看见一张切片，先问它落在细胞、组织、器官还是系统，再问 HE 里紫蓝和红分别钉在谁身上。
:::

:::definition{label="组织学"}
组织学（histology）是研究机体微细结构及其相关功能的科学，主要在组织、细胞、亚细胞和分子水平上对机体进行研究。
:::

:::definition{label="组织"}
组织（tissue）由细胞群和细胞外基质构成。根据胚胎发生来源、细胞构成、形态特点和功能，人体组织归纳为上皮组织、结缔组织、肌组织和神经组织 $4$ 种基本类型。细胞由细胞膜、细胞质和细胞核构成，是组织的主要构成成分；细胞外基质是细胞的产物。
:::

:::compare{title="四种基本组织先立户"}
| 基本组织 | 指南落点 | 不要听成 |
|----------|----------|----------|
| 上皮组织 | 细胞排列紧密、有极性、贴基膜、无血管 | 「有丰富毛细血管的保护层」 |
| 结缔组织 | 细胞散在、无极性；广义含固有结缔、血液、淋巴、软骨和骨 | 「只有疏松结缔那一种」 |
| 肌组织 | 肌细胞即肌纤维；骨骼肌、心肌、平滑肌三种，前两种属横纹肌 | 「心肌没有横纹」 |
| 神经组织 | 神经细胞 + 神经胶质细胞；神经元是结构和功能单位 | 「胶质细胞也传导冲动」 |
:::

:::keypoint{label="石蜡切片与 HE 染色"}
最常用的光镜技术是石蜡切片术，基本程序：取材→固定（或固定→取材）→脱水→透明→包埋→切片→染色→封片。HE 染色中苏木素为碱性，主要使细胞核内染色质与胞质内核糖体着紫蓝色；伊红为酸性染料，主要使细胞质和细胞外基质中的成分着红色。易于被碱性或酸性染料着色的性质分别称为嗜碱性（basophilia）和嗜酸性（acidophilia）；与两种染料亲和力都不强则称为中性。
:::

:::compare{title="免疫组化与原位杂交不要并户"}
| 项目 | 免疫组织化学术 | 原位杂交术 |
|------|----------------|------------|
| 原理 | 抗原与抗体特异性结合 | 核酸分子互补、碱基配对 |
| 检测物 | 肽和蛋白质、膜表面抗原和受体 | 基因（DNA 片段）、mRNA |
| 显示 | 带标记物的特异性抗体 | 带标记物的已知序列探针 |
:::

:::pitfall{label="细胞外基质不是切片上的空白"}
指南把组织写成细胞群加细胞外基质，基质是细胞的产物。把基质听成可有可无的空隙，或把四种基本组织之外再单列一种「基质组织」，组织的定义会做窄。电镜分辨平面超微结构靠透射电镜、显示立体构像靠扫描电镜，两本账也不要并。
:::

:::memory{label="绪论掌握清单"}
- [ ] 组织学：机体微细结构及其相关功能；层次含组织、细胞、亚细胞、分子
- [ ] 基本组织只有上皮、结缔、肌、神经 $4$ 种
- [ ] 细胞外基质是细胞的产物
- [ ] HE：苏木素→核与核糖体紫蓝（嗜碱）；伊红→胞质与部分基质红（嗜酸）
- [ ] 免疫组化查肽和蛋白质；原位杂交查 DNA / RNA
- [ ] 组织工程四件：种子细胞、细胞外基质、组织器官构建、构建物植入
:::

## 一、上皮：先问极性，再问层数和形状

:::definition{label="被覆上皮"}
被覆上皮覆盖于身体表面或衬贴在体腔和有腔器官内表面。细胞形状较规则、排列紧密；有明显极性，即游离面和基底面；基底附着于基膜，并借此与深部结缔组织相连；无血管分布。功能包括保护、吸收、分泌和排泄。
:::

:::concept{term="先问一层还是多层，再问游离面那一层是扁、立方还是柱状"}
分类尺子只有两把：组成上皮的细胞层数，以及（复层看浅层）细胞形状。假复层看起来核有高有低，但所有细胞基底部都贴基膜，户头仍在单层。把「核不在同一平面」写成复层，呼吸道那本账会从一开始就丢。
:::

:::compare{title="七种被覆上皮的分布与功能"}
| 类型 | 结构钥匙 | 指南分布 | 功能落点 |
|------|----------|----------|----------|
| 单层扁平 | 一层扁平；核椭圆居中；边缘齿状嵌合 | 心血管和淋巴管腔面称内皮；胸膜、腹膜、心包膜表面称间皮 | 表面光滑，利血流或减摩擦 |
| 单层立方 | 一层近似立方形；核圆居中 | 肾小管、甲状腺滤泡等 | 吸收、分泌 |
| 单层柱状 | 一层棱柱状；核长圆、邻近基底部 | 胃、肠、胆囊、子宫及输卵管等 | 吸收、分泌 |
| 假复层纤毛柱状 | 柱状、梭形、锥形和杯状细胞；核位高低不一，均贴基膜；柱状细胞游离面有大量纤毛 | 呼吸管道等 | 分泌、保护 |
| 复层扁平 | 多层；浅层扁平鳞片状 | 角化：皮肤表层；未角化：口腔、食管、阴道等 | 保护 |
| 复层柱状 | 浅层为一层较整齐的柱状细胞 | 睑结膜、男性尿道等 | 保护 |
| 变移上皮 | 细胞形状和层数随器官收缩与扩张改变；收缩时表层细胞较大、立方形，可单核或双核 | 肾盂、肾盏、输尿管、膀胱等 | 适应容积变化 |
:::

:::definition{label="腺上皮和腺"}
腺上皮是由腺细胞组成、以分泌功能为主的上皮。腺是以腺上皮为主要成分的器官。腺分内分泌腺和外分泌腺。外分泌腺由分泌部和导管两部分组成。组成腺泡的腺细胞分为浆液性细胞和黏液性细胞，故外分泌腺分为浆液性腺、黏液性腺和混合性腺。
:::

游离面两件不要并：微绒毛是微细指状突起，内含纵行肌动蛋白丝，直径 $0.1\,\mu\mathrm{m}$，小于光镜分辨率，作用是增大表面积利于吸收；纤毛较粗而长，内含微管，形成 $9+2$ 结构，光镜下可见，能节律性定向摆动，主要分布于呼吸道，把黏液及其黏附颗粒定向推送。

:::compare{title="侧面四种连接从上到下不要串层"}
| 连接 | 别名与位置 | 间隙 / 结构 | 功能 |
|------|------------|-------------|------|
| 紧密连接 | 闭锁小带；侧面顶端 | 膜内蛋白颗粒排成 $2\sim 4$ 条线状网格，带状环绕细胞 | 牢牢连接；阻挡物质穿过细胞间隙（屏障） |
| 中间连接 | 黏着小带；多在紧密连接下方，环绕顶部 | 间隙 $15\sim 20\,\mathrm{nm}$，内有丝状物；胞质面有薄层致密物和微丝 | 黏着；保持细胞形状；传递收缩力 |
| 桥粒 | 斑状 | 间隙 $20\sim 30\,\mathrm{nm}$；中央有与胞膜平行的致密中间线；胞质面附着板，角蛋白丝附于板上 | 很牢固的细胞连接 |
| 缝隙连接 | 高度平行的膜 | 间隙 $3\,\mathrm{nm}$；连接小体（connexon）由 $6$ 个连接素分子围成，中央管腔对接 | 营养代谢、增殖分化和功能上成为统一体 |
:::

:::keypoint{label="基底面三件：基膜、质膜内褶、半桥粒"}
- 基膜在上皮基底面与深部结缔组织之间共同形成。电镜下分基板和网板：基板由上皮细胞分泌，网板由成纤维细胞分泌。支持、连接、固着，并有半通透作用。
- 质膜内褶是基底面细胞膜垂直折向胞质形成的许多内褶，光镜下称基底纵纹，其间有平行杆状线粒体，扩大基底部表面积。
- 半桥粒是桥粒结构的一半，把上皮细胞固着在基膜上。
:::

:::pitfall{label="内皮不是间皮，假复层不是复层"}
衬于心血管和淋巴管腔面的单层扁平上皮叫内皮；胸膜、腹膜、心包膜表面叫间皮。肺泡和肾小囊壁层也是单层扁平，但指南不把它们叫做内皮或间皮。角化与未角化复层扁平的最大区别在浅表层细胞是否含细胞核，不是层数本身。基膜是上皮产物加成纤维细胞产物：基板归上皮，网板归成纤维细胞。
:::

:::memory{label="上皮掌握清单"}
- [ ] 紧密、规则、有极性、贴基膜、无血管
- [ ] 内皮走管腔，间皮走浆膜
- [ ] 假复层：四种细胞都贴基膜；游离面有纤毛
- [ ] 变移上皮层数随舒缩变，分布于排尿管道
- [ ] 微绒毛 = 微丝 + 吸收面积；纤毛 = 微管 $9+2$ + 摆动
- [ ] 连接从上到下：紧密 → 中间 → 桥粒；缝隙管腔互通
- [ ] 基板上皮分泌，网板成纤维细胞分泌
:::

## 二、结缔：细胞散在，基质和纤维才是大量

:::definition{label="结缔组织"}
结缔组织由细胞和大量细胞外基质构成。细胞散在分布，无极性。细胞外基质包括无定形基质、丝状纤维和不断循环更新的组织液。广义结缔组织包括固有结缔组织、血液、淋巴、软骨和骨；狭义指固有结缔组织，包括疏松结缔组织、致密结缔组织、脂肪组织和网状组织。均来源于胚胎时期的间充质。
:::

疏松结缔组织又称蜂窝组织：细胞种类较多，纤维数量较少、排列稀疏，分布广。细胞成分有成纤维细胞与纤维细胞、巨噬细胞、浆细胞、肥大细胞、脂肪细胞、白细胞及未分化间充质细胞。

:::compare{title="疏松结缔五种常考细胞"}
| 细胞 | 光镜钥匙 | 电镜 / 化学 | 功能 |
|------|----------|-------------|------|
| 成纤维细胞 | 扁平多突起；核大卵圆着色浅、核仁明显；胞质弱嗜碱 | 丰富粗面内质网、游离多核糖体、发达高尔基复合体 | 合成、分泌纤维和基质；最主要的细胞 |
| 纤维细胞 | 长梭形；核小着色深；胞质少、嗜酸 | 细胞器少 | 功能静止；创伤等条件下可再转变为成纤维细胞 |
| 巨噬细胞 | 形态多样，活跃时伸出伪足；核小着色深；胞质嗜酸，可含异物颗粒和空泡 | 皱褶、微绒毛；大量溶酶体、吞噬体 | 吞噬、抗原递呈、分泌多种活性物质；固定者又称组织细胞；来源于单核细胞 |
| 浆细胞 | 圆或卵圆；核偏位，异染色质沿核膜呈车轮状；核旁浅染区 | 丰富平行粗面内质网；浅染区为高尔基复合体及中心体 | 合成、分泌抗体（免疫球蛋白） |
| 肥大细胞 | 体积较大；核小圆、居中、染色深；胞质粗大异染性颗粒，易溶于水 | 颗粒含肝素、组胺、嗜酸性粒细胞趋化因子 | 参与过敏反应；受刺激时释放颗粒，同时合成并释放白三烯 |
:::

:::compare{title="三种纤维"}
| 纤维 | 染色 | 超微 | 力学 |
|------|------|------|------|
| 胶原纤维 | 又称白纤维；HE 嗜酸；数量最多 | 胶原原纤维有明暗相间 $64\,\mathrm{nm}$ 周期性横纹；分子组成为Ⅰ型和Ⅲ型胶原蛋白 | 韧性大，抗拉力强 |
| 弹性纤维 | 又称黄纤维；HE 淡红，不易与胶原区别；醛复红染成紫色 | 核心均质弹性蛋白；周围微原纤维主要为原纤维蛋白 | 弹性很好 |
| 网状纤维 | 银盐染成黑色，又称嗜银纤维 | 也有 $64\,\mathrm{nm}$ 周期性横纹 | 主要存在于网状组织，分支交织成网 |
:::

基质以蛋白多糖为主要成分：透明质酸为主干，连接许多蛋白质和硫酸软骨素、硫酸角质素、硫酸皮肤素、硫酸肝素，形成有许多微小孔隙的分子筛——限制细菌和肿瘤细胞扩散，而水、代谢产物、激素、营养物质和气体分子可以通过。组织液从毛细血管动脉端渗入基质，大部分在静脉端回血，小部分进毛细淋巴管成为淋巴。

:::keypoint{label="致密、网状与两种脂肪"}
- 致密结缔组织以纤维为主要成分，纤维粗大、排列致密，分规则、不规则和弹性组织；主要功能是支持和连接。
- 网状组织由网状细胞和网状纤维构成，常为造血组织和淋巴组织的基本组成成分。
- 黄色脂肪组织：单泡脂肪细胞，一个大脂滴，分布广，储能、维持体温、缓冲、保护和填充。
- 棕色脂肪组织：多泡脂肪细胞，许多散在小脂滴；成年人极少，多见新生儿，需要时可产生大量热能。
:::

软骨组织由软骨细胞和软骨基质构成，与周围软骨膜共同构成软骨。周边幼稚细胞扁圆、常单个；越近中央越成熟，常 $2\sim 8$ 个聚集，称同源细胞群。软骨囊是陷窝周围含硫酸软骨素较多、HE 强嗜碱的基质。透明软骨含交织的Ⅱ型胶原原纤维，HE 不能分辨，见于肋软骨、关节软骨、呼吸道软骨；纤维软骨含大量平行或交叉胶原纤维束，见于椎间盘、关节盘及耻骨联合；弹性软骨含大量弹性纤维，见于耳廓及会厌。软骨膜（除关节软骨和纤维软骨外）内有骨祖细胞。生长方式：附加性生长（软骨膜下）和间质性生长（软骨内）。

骨组织由细胞和钙化的细胞外基质组成。骨基质包括有机成分（大量胶原纤维和少量基质）和无机成分（骨盐，主要是羟基磷灰石结晶）。无骨盐沉积称类骨质，钙化后才成骨质。骨单位（哈佛斯系统）由 $4\sim 20$ 层同心圆哈佛骨板围绕中央管构成，是长骨中起支持作用的主要结构。

:::compare{title="骨组织四种细胞"}
| 细胞 | 位置与形态 | 职分 |
|------|------------|------|
| 骨祖细胞 | 骨膜内；梭形 | 骨组织的干细胞；可分化为成骨细胞和成软骨细胞 |
| 成骨细胞 | 骨组织表面；立方或矮柱状；胞质嗜碱 | 分泌类骨质；释放基质小泡启动钙化；自身被包埋后成为骨细胞 |
| 骨细胞 | 骨陷窝；多突起，突起走骨小管，相邻借缝隙连接 | 居于骨质内部 |
| 破骨细胞 | 数量少；多核体大；由若干单核细胞融合；贴骨质一侧有皱褶缘 | 溶解和吸收骨质 |
:::

骨发生两种方式：膜内成骨（原始结缔组织内直接成骨）和软骨内成骨（预先形成软骨雏形，再逐步替换为骨）。

血液由红细胞、白细胞、血小板和血浆组成；血浆相当于细胞外基质。体外凝固后析出的淡黄色清亮液体称血清。血细胞形态、数量、百分比和血红蛋白含量的测定称血象。

:::compare{title="正常血象（指南数字）"}
| 项目 | 数值 |
|------|------|
| 红细胞 | 男 $(4.0\sim 5.5)\times 10^{12}/\mathrm{L}$；女 $(3.5\sim 5.0)\times 10^{12}/\mathrm{L}$ |
| 血红蛋白 | 男 $120\sim 150\,\mathrm{g}/\mathrm{L}$；女 $110\sim 140\,\mathrm{g}/\mathrm{L}$ |
| 白细胞 | $(4.0\sim 10.0)\times 10^{9}/\mathrm{L}$ |
| 中性粒细胞 | $50\%\sim 70\%$ |
| 嗜酸性粒细胞 | $0.5\%\sim 3\%$ |
| 嗜碱性粒细胞 | $0\%\sim 1\%$ |
| 单核细胞 | $3\%\sim 8\%$ |
| 淋巴细胞 | $25\%\sim 30\%$ |
| 血小板 | $(100\sim 300)\times 10^{9}/\mathrm{L}$ |
:::

:::keypoint{label="三种有粒白细胞不要靠颜色蒙"}
- 红细胞直径约 $7.5\,\mu\mathrm{m}$，双凹圆盘，无核无细胞器，充满血红蛋白；平均寿命约 $120$ 天。网织红细胞残留部分核糖体，成人约占红细胞总数 $0.5\%\sim 1.5\%$，是了解骨髓造血功能的指标。
- 中性粒细胞数量最多；核杆状或 $2\sim 5$ 叶（以 $2\sim 3$ 叶居多）；杆状核与 $2$ 叶核增多称核左移，$4\sim 5$ 叶增多称核右移。强趋化和吞噬。
- 嗜酸性粒细胞核多为 $2$ 叶，粗大鲜红色颗粒含组胺酶等；抑制过敏反应、杀灭寄生虫。
- 嗜碱性粒细胞数量最少，颗粒含肝素、组胺、嗜酸性粒细胞趋化因子，基质内有白三烯，参与过敏反应。
- 单核细胞体积最大，进入组织分化成巨噬细胞等。淋巴细胞是主要免疫细胞，分 T、B、NK。血小板分颗粒区和透明区，参与止血和凝血。
:::

血细胞发生形态演变的一般规律：胞体由大变小（巨核细胞由小变大）；胞核由大变小，染色质由细疏变粗密，核仁由有到无；胞质由少变多，嗜碱性逐渐变弱（单核、淋巴细胞保持嗜碱性）；细胞分裂能力由有到无（淋巴细胞保持分裂能力）。

:::pitfall{label="浆细胞分泌抗体，巨噬细胞不分泌抗体"}
抗体户头在浆细胞。巨噬细胞吞噬、抗原递呈、分泌溶菌酶和细胞因子，不合成免疫球蛋白。肥大细胞与嗜碱性粒细胞都参与过敏，但一个在结缔组织、一个在血液，颗粒化学相近不要写成同一种细胞。胶原纤维和网状纤维都有 $64\,\mathrm{nm}$ 横纹，嗜银的才是网状纤维。
:::

:::memory{label="结缔掌握清单"}
- [ ] 广义：固有结缔 + 血液、淋巴、软骨和骨；来源于间充质
- [ ] 成纤维细胞造纤维和基质；纤维细胞可逆
- [ ] 浆细胞 = 车轮核 + 核旁浅染 + 抗体
- [ ] 肥大细胞异染颗粒：肝素、组胺、嗜酸趋化因子
- [ ] 胶原 $64\,\mathrm{nm}$ 横纹；网状纤维嗜银
- [ ] 分子筛限制细菌和肿瘤细胞，不挡水分子
- [ ] 骨单位 $4\sim 20$ 层哈佛骨板；破骨细胞有皱褶缘
- [ ] 血象数字按指南记；核左移是杆状核与 $2$ 叶核增多
:::

## 三、肌：横纹看肌节，心肌看闰盘

:::definition{label="肌组织"}
肌组织主要由肌细胞构成。肌细胞呈细长纤维状，故又称肌纤维。分骨骼肌、心肌和平滑肌 $3$ 种，前两种属横纹肌。
:::

:::definition{label="肌节"}
相邻两条 Z 线之间的一段肌原纤维称为肌节（sarcomere）。每个肌节由 $1/2\,\mathrm{I}$ 带 $+$ $\mathrm{A}$ 带 $+$ $1/2\,\mathrm{I}$ 带组成。肌节递次排列构成肌原纤维，是骨骼肌纤维结构和功能的基本单位。
:::

骨骼肌纤维呈长圆柱形，多核，核位于肌膜下方。肌浆中有平行排列的肌原纤维，明带（I 带）和暗带（A 带）相间；一条纤维内各条肌原纤维的明暗带都准确排在同一平面上，构成周期性横纹。暗带中央有 H 带，H 带中央有 M 线，明带中央有 Z 线。骨骼肌还有扁平、有突起的肌卫星细胞，附着在肌纤维表面，可增殖分化参与修复。

:::compare{title="粗细肌丝与三联体"}
| 结构 | 组成与位置 | 职分 |
|------|------------|------|
| 粗肌丝 | 肌球蛋白；位于肌节中部，两端游离，中央借 M 线固定 | 与细肌丝滑动 |
| 细肌丝 | 肌动蛋白、原肌球蛋白和肌钙蛋白；一端附于 Z 线，伸至粗肌丝之间，止于 H 带外侧 | 与粗肌丝滑动 |
| 横小管 | 肌膜向肌浆内凹陷，环绕每条肌原纤维；骨骼肌位于明带与暗带交界处 | 把肌膜兴奋迅速传到内部 |
| 肌浆网 | 特化滑面内质网；中部纵小管，两端终池；膜上有钙泵和钙通道 | 贮存和释放 $\mathrm{Ca}^{2+}$ |
| 三联体 | 每条横小管与两侧终池 | 兴奋从肌膜传到肌浆网膜 |
:::

心肌纤维呈不规则短圆柱状，有分支互联成网，连接处形成闰盘。多数一个核、少数双核，核位于细胞中央。心肌内没有肌卫星细胞，局部受损由结缔组织细胞增殖修复。超微与骨骼肌相似，但：肌原纤维粗细不等、界限不分明，线粒体极为丰富；横小管较粗，位于 Z 线水平；肌浆网稀疏，终池少而小，多与横小管形成二联体；闰盘横位部分有中间连接和桥粒，纵位部分有缝隙连接，使心房肌和心室肌整体收缩舒张同步化。

平滑肌广泛分布于消化管等中空性器官管壁。纤维长梭形，中央一个杆状或椭圆核，胞质嗜酸，无横纹。细胞内无肌原纤维，可见大量密斑、密体、中间丝、细肌丝和粗肌丝。中间丝连接密斑与密体形成骨架；细肌丝一端附于密斑或密体。粗细肌丝滑动仍是收缩基础。纤维间有较发达的缝隙连接，引起相邻纤维同步收缩。

:::pitfall{label="骨骼肌三联体不要写成心肌的配置"}
骨骼肌横小管在明暗带交界，一条横小管加两侧终池是三联体。心肌横小管在 Z 线，多成二联体。把两本账对调，兴奋-收缩耦联会讲反。闰盘不是「另一种横纹」，横位管牢固、纵位管电冲动。平滑肌没有肌原纤维，不等于没有粗细肌丝。
:::

:::memory{label="肌组织掌握清单"}
- [ ] 肌节 = $1/2\,\mathrm{I}+\mathrm{A}+1/2\,\mathrm{I}$，是骨骼肌结构和功能基本单位
- [ ] 粗丝肌球蛋白；细丝肌动蛋白 + 原肌球蛋白 + 肌钙蛋白
- [ ] 骨骼肌：核在膜下、三联体、有肌卫星细胞
- [ ] 心肌：核居中、闰盘、二联体、无肌卫星细胞
- [ ] 平滑肌：长梭形、密斑密体、缝隙连接同步
:::

## 四、神经：胞体代谢，胶质包绝缘

:::definition{label="神经组织"}
神经组织由神经细胞和神经胶质细胞组成。神经细胞是神经系统的结构和功能单位，也称神经元，具有接受刺激、整合信息和传导神经冲动的能力。神经胶质细胞对神经元起支持、保护、营养和绝缘等作用。
:::

神经元分胞体、树突和轴突。胞体是营养和代谢中心：核大而圆、着色浅、核仁大而圆。特征性结构为尼氏体和神经原纤维。尼氏体位于胞体和树突，强嗜碱；电镜下由发达粗面内质网和游离核糖体构成，主要合成结构蛋白、合成神经递质所需的酶类以及肽类神经调质。神经递质在轴突末端内合成；神经调质一般为肽类，增强或减弱神经元对递质的反应。神经原纤维镀银呈棕黑色，电镜下由神经丝和微管构成，既是骨架，微管还参与物质运输。树突主要接受刺激，分支上有大量树突棘。每个神经元只有一个轴突；轴丘无尼氏体故染色淡。

:::definition{label="突触"}
神经元与神经元之间，或神经元与效应细胞之间传递信息的特化结构称突触。化学突触以神经递质为媒介，一般所讲的突触即指此类；电突触是缝隙连接，以电流为信息载体。突触由突触前成分、突触间隙和突触后成分构成。突触前成分一般是轴突终末膨大形成的突触小体，内含突触小泡。
:::

:::compare{title="中枢四型胶质与周围两型"}
| 细胞 | 系统 | 指南职分 |
|------|------|----------|
| 星形胶质细胞 | 中枢 | 支持、绝缘；脚板参与血-脑屏障的神经胶质膜；分泌神经营养因子；损伤时增生形成胶质瘢痕 |
| 少突胶质细胞 | 中枢 | 突起末端扁平薄膜包卷轴突形成髓鞘；一个细胞可包卷多个轴突 |
| 小胶质细胞 | 中枢 | 体积最小；损伤时可转变为巨噬细胞；一般认为来源于血液单核细胞 |
| 室管膜细胞 | 中枢 | 衬于脑室和脊髓中央管，形成室管膜；可产生脑脊液 |
| 施万细胞 | 周围 | 髓鞘形成细胞；外表面有基膜，能分泌神经营养因子，促进受损神经元存活及轴突再生 |
| 卫星细胞 | 周围 | 神经节内包裹神经元胞体的一层扁平或立方细胞 |
:::

有髓神经纤维因有郎飞结而跳跃式传导，速度快；无髓神经纤维沿轴膜连续传导，速度慢。周围有髓纤维一个结间体对应一个施万细胞；中枢则由少突胶质细胞包卷。周围无髓纤维是较细轴突陷入施万细胞表面纵沟，不形成髓鞘，一个施万细胞可含多条轴突。

:::keypoint{label="感觉末梢与运动终板"}
- 游离神经末梢：冷、热、轻触和痛。
- 触觉小体：真皮乳头，触觉。
- 环层小体：皮下、腹膜、肠系膜、韧带和关节囊等，压觉和振动觉。
- 肌梭：骨骼肌内本体感受器，调节骨骼肌活动。
- 躯体运动神经末梢与骨骼肌形成运动终板（神经肌连接），突触小泡含乙酰胆碱。
- 内脏运动神经末梢较细、无髓鞘，分支末段为串珠样膨体。
:::

大脑皮质表及里一般 $6$ 层：分子层、外颗粒层、外锥体细胞层、内颗粒层、内锥体细胞层、多形细胞层。$1\sim 4$ 层主要接受传入；投射纤维主要起自第 $5$ 层锥体细胞和第 $6$ 层梭形细胞。小脑皮质表及里 $3$ 层：分子层、蒲肯野细胞层、颗粒层。脊髓前角多数是躯体运动神经元（$\alpha$ 到骨骼肌，$\gamma$ 到梭内肌），侧角含内脏运动神经元，后角主要接受感觉传入。

:::definition{label="血-脑屏障"}
血-脑屏障由脑毛细血管内皮细胞、基膜和神经胶质膜构成。脑的毛细血管属连续型，内皮细胞之间以紧密连接封闭，是血-脑屏障的主要结构。可阻止血液中某些物质进入脑组织，但能选择性让营养物质和代谢产物顺利通过。
:::

:::pitfall{label="尼氏体不在轴突，髓鞘细胞中枢周围不要对调"}
尼氏体在胞体和树突，轴丘和轴突没有，所以轴丘染色淡。中枢形成髓鞘的是少突胶质细胞，周围是施万细胞。电突触就是缝隙连接，不要再发明第四种「电学突触器」。血-脑屏障的主要结构是连续型内皮的紧密连接，不是「只有胶质脚板」。
:::

:::memory{label="神经掌握清单"}
- [ ] 神经元 = 胞体 + 树突 + 一条轴突；尼氏体 = 粗面内质网 + 核糖体
- [ ] 化学突触三部：前成分、间隙、后成分
- [ ] 中枢髓鞘少突，周围髓鞘施万；跳跃传导靠郎飞结
- [ ] 星形胶质脚板参与血-脑屏障；小胶质可变为巨噬细胞
- [ ] 大脑六层、小脑三层；蒲肯野细胞在中间那一层
- [ ] 血-脑屏障：连续内皮紧密连接 + 基膜 + 神经胶质膜
:::

## 五、循环：心壁三层，毛细血管才是交换

:::definition{label="心壁"}
心壁由心内膜、心肌膜和心外膜构成。心内膜由内皮和内皮下层组成；心室壁心内膜下层中有蒲肯野纤维。心肌膜由内纵、中环、外斜的心肌纤维束组成；心房肌与心室肌不相连续，分别附着于心骨骼。心房肌纤维内含心房特殊颗粒，可分泌心房钠尿肽，具有排钠、利尿、扩张血管和降压作用。心外膜由薄层结缔组织和外表面的间皮组成。
:::

心脏传导系统由心壁内特殊心肌纤维组成，发生并传导冲动，包括窦房结、房室结、房室束、左右房室束支及分布到心室乳头肌和心室壁的许多细支。组成细胞有起搏细胞、移行细胞和蒲肯野纤维。

动脉管壁均分内膜、中膜和外膜。大动脉中膜主要由数十层弹性膜组成，内皮细胞中有丰富的 W-P 小体，内含 vWF，参与凝血。中动脉内膜有明显内弹性膜，中膜主要由数十层环形平滑肌构成，外膜与中膜交界处有明显外弹性膜。小动脉管径 $0.3\sim 1\,\mathrm{mm}$，较大者有明显内弹性膜，中膜有几层平滑肌。微动脉管径在 $0.3\,\mathrm{mm}$ 以下，无内外弹性膜，中膜 $1\sim 2$ 层平滑肌。

:::compare{title="三种毛细血管"}
| 类型 | 内皮与基膜 | 交换方式 | 分布 |
|------|------------|----------|------|
| 连续毛细血管 | 内皮连续，细胞间紧密连接，胞质大量吞饮小泡，基膜完整 | 主要通过吞饮小泡 | 结缔组织、肌组织、中枢神经系统、胸腺和肺等 |
| 有孔毛细血管 | 不含核部分极薄，有贯穿胞质的内皮窗孔，一般有隔膜封闭，基膜连续 | 窗孔利于通透 | 胃肠黏膜、某些内分泌腺和肾血管球等 |
| 血窦 | 腔大不规则，内皮细胞间隙较大，基膜不连续或缺如 | 大分子或血细胞易出入 | 肝、脾、骨髓和某些内分泌腺 |
:::

毛细血管壁主要由内皮和基膜组成，内皮外有周细胞，参与血管收缩，损伤时可分化为内皮细胞。静脉管壁平滑肌和弹性组织不及动脉丰富，结缔组织较多；大静脉中膜不发达，外膜较厚，结缔组织中有较多纵形平滑肌束。

:::pitfall{label="蒲肯野纤维不是小脑蒲肯野细胞"}
心内膜下层的蒲肯野纤维属于心脏传导系统，和小肠腺底部的潘氏细胞、小脑皮质的蒲肯野细胞不是同一户头。肾血管球是有孔毛细血管，但孔处无隔膜，和胃肠黏膜「一般有隔膜」的有孔内皮不要并成一句。血窦不要写成「连续毛细血管的别名」。
:::

:::memory{label="循环掌握清单"}
- [ ] 心壁：心内膜、心肌膜、心外膜；心房钠尿肽排钠利尿扩管降压
- [ ] 传导系：窦房结→房室结→房室束→左右束支；三种特化细胞
- [ ] 大动脉看弹性膜，中动脉看平滑肌，微动脉无弹性膜
- [ ] 连续 / 有孔 / 血窦三型按内皮窗孔和基膜分
- [ ] 周细胞在内皮外
:::

## 六、消化：四层通式，胃小肠把上皮写细

:::definition{label="消化管壁四层"}
除口腔与咽外，消化管壁自内向外均由黏膜、黏膜下层、肌层与外膜四层构成。黏膜是功能最重要的部分，由上皮、固有层和黏膜肌层组成。上皮在消化管中段为单层柱状（消化吸收），两端（口腔、咽、食管及肛门）为未角化复层扁平（保护）。肌层除食管上段与肛门处为骨骼肌外，其余均为平滑肌，一般内环外纵，两层间有肌间神经丛。胃、大部分小肠与大肠外膜为浆膜；食管颈、胸段和大肠末段为纤维膜。
:::

:::compare{title="食管、胃、小肠、大肠的黏膜钥匙"}
| 器官 | 上皮与特化 | 固有层 / 黏膜下层 | 肌层与外膜 |
|------|------------|-------------------|------------|
| 食管 | 未角化复层扁平 | 黏膜下层含黏液性食管腺 | 上 $1/3$ 骨骼肌，下 $1/3$ 平滑肌，中 $1/3$ 兼具；纤维膜 |
| 胃 | 单层柱状；表面黏液细胞形成胃小凹；无杯状细胞 | 贲门腺、幽门腺、胃底腺 | 内斜、中环、外纵三层平滑肌；浆膜 |
| 小肠 | 单层柱状；环行皱襞 + 肠绒毛 + 微绒毛 | 小肠腺；十二指肠黏膜下层有十二指肠腺 | 除十二指肠后壁为纤维膜外，其余浆膜 |
| 大肠 | 单层柱状；无环形皱襞、无绒毛、无潘氏细胞；杯状细胞多 | 大肠腺；阑尾淋巴组织极丰富 | 纵行肌局部增厚成三条结肠带 |
:::

胃底腺又称泌酸腺，存在于胃底和胃体，由主细胞、壁细胞、颈黏液细胞、干细胞和内分泌细胞组成。

:::compare{title="胃底腺与小肠上皮细胞"}
| 细胞 | 位置 | 分泌 / 结构 | 意义 |
|------|------|-------------|------|
| 主细胞 | 胃底腺底部最多 | 典型蛋白质分泌细胞；分泌胃蛋白酶原 | 又称胃酶细胞 |
| 壁细胞 | 体积大，圆锥形，胞质嗜酸 | 细胞内泌小管、微管泡系统、丰富线粒体；分泌盐酸和内因子 | 盐酸激活胃蛋白酶原并杀菌；内因子辅助维生素 $\mathrm{B}_{12}$ 吸收 |
| 表面黏液细胞 | 胃上皮与胃小凹 | 顶部黏原颗粒，分泌含高浓度 $\mathrm{HCO}_3^{-}$ 的不可溶性黏液 | 黏液-碳酸氢盐屏障；局部 $\mathrm{pH}$ 为 $7$ |
| 吸收细胞 | 小肠绒毛最多 | 纹状缘 = 密集微绒毛；细胞衣有双糖酶、肽酶及吸附的胰酶 | 滑面内质网形成乳糜微粒；还分泌肠致活酶激活胰蛋白酶原 |
| 潘氏细胞 | 小肠腺底部 | 顶部粗大嗜酸性颗粒；分泌防御素（隐窝素）和溶菌酶 | 小肠腺的特征性细胞 |
| 杯状细胞 | 小肠、大肠增多 | 分泌黏液 | 润滑保护；胃上皮正常没有 |
:::

绒毛中轴有 $1\sim 2$ 条纵行毛细淋巴管，称中央乳糜管，乳糜微粒由此输出；周围有孔毛细血管接收氨基酸、单糖等。I 细胞产生胆囊收缩素-促胰酶素；S 细胞产生促胰液素。十二指肠腺分泌碱性黏液，保护十二指肠免受胃酸侵蚀。回肠有集合淋巴小结。消化管淋巴组织主要通过产生并向管腔分泌 sIgA 进行免疫应答；集合淋巴小结处上皮内有 M 细胞摄取抗原。

大唾液腺：腮腺为浆液性腺；下颌下腺为混合性、浆液性腺泡较多；舌下腺为混合性、以黏液性腺泡为主。纹状管又名分泌管，转运水和电解质，吸收钠离子、排出钾离子。

胰腺外分泌部为浆液性腺，腺泡腔面有泡心细胞（闰管起始部伸入腺泡的上皮）。胰岛主要有 A、B、D、PP 四种细胞：A 细胞分泌高血糖素使血糖升高；B 细胞数量最多，分泌胰岛素使血糖降低；D 细胞分泌生长抑素，以旁分泌抑制邻近 A、B 或 PP 细胞；PP 细胞分泌胰多肽。

:::definition{label="肝小叶"}
肝小叶是肝的基本结构单位，有 $50$ 万 $\sim$ $100$ 万个。中央有纵行中央静脉，肝细胞排成肝板并吻合成迷路状，肝板间为肝血窦，均以中央静脉为中心呈放射状排列。肝细胞相邻面的质膜局部凹陷成胆小管。
:::

肝细胞有血窦面、胆小管面和肝细胞连接面三种功能界面。肝血窦内皮有窗孔、无隔膜，细胞间隙较宽，内皮外无基膜；内皮与肝板之间为窦周隙，充满血浆，肝细胞微绒毛浸泡其中。窦内有库普弗细胞（肝巨噬细胞，来自单核细胞）和肝内大颗粒淋巴细胞（属 NK 细胞）。窦周隙内贮脂细胞贮存大部分维生素 A，并能产生以网状纤维为主的细胞外基质。门管区可见伴行的小叶间静脉、小叶间动脉和小叶间胆管，合称门三联管。

肝内血液循环：门静脉→小叶间静脉、肝动脉→小叶间动脉，二者汇入肝血窦→中央静脉→小叶下静脉→肝静脉。胆汁：肝细胞→胆小管→Herring 管→小叶间胆管→左、右肝管→肝总管，再经胆囊和胆囊管与胆总管开口于十二指肠。

:::pitfall{label="正常胃上皮没有杯状细胞，潘氏细胞只在小肠腺"}
把胃写成「单层柱状加杯状细胞」，黏液-碳酸氢盐屏障会没有户头。大肠无绒毛、无潘氏细胞。肝血窦是血窦型，不是连续毛细血管。B 细胞是胰岛里数量最多、降血糖的那一群，不要和浆细胞（B 淋巴细胞的效应细胞）并户。
:::

:::memory{label="消化掌握清单"}
- [ ] 四层：黏膜（上皮+固有层+黏膜肌）、黏膜下层、肌层、外膜
- [ ] 胃：黏液-碳酸氢盐屏障；主细胞酶原，壁细胞盐酸+内因子
- [ ] 小肠：皱襞+绒毛+微绒毛；中央乳糜管走脂肪；潘氏细胞在腺底
- [ ] 胰岛：A 升糖、B 降糖、D 旁分泌抑制
- [ ] 肝小叶 $50$ 万 $\sim$ $100$ 万；门三联管；窦周隙物质交换
:::

## 七、呼吸：导气部无肺泡，呼吸部从呼吸性细支气管起

:::definition{label="呼吸系统两部"}
呼吸系统由导气部和呼吸部构成。导气部从鼻腔开始直至肺内的终末细支气管，无气体交换功能。呼吸部从肺内的呼吸性细支气管开始直至末端的肺泡，这部分管道都有肺泡，行使气体交换功能。每条细支气管连同它的各级分支和肺泡组成一个肺小叶，肺小叶是肺的结构单位。
:::

鼻黏膜分前庭部（复层扁平，有鼻毛）、呼吸部（假复层纤毛柱状，加湿加温）和嗅部（假复层柱状，含支持细胞、基细胞和嗅细胞）。嗅细胞为双极神经细胞，树突末端膨大成嗅泡并发出嗅毛。喉的会厌舌面及喉面上部和声带处为复层扁平上皮，其余大部分为假复层纤毛柱状；声襞固有层有大量弹性纤维束构成声韧带，下方骨骼肌为声带肌。

气管与主支气管管壁分黏膜、黏膜下层和外膜。黏膜上皮为假复层纤毛柱状，由纤毛细胞、杯状细胞、刷细胞、基细胞和小颗粒细胞构成。外膜主要含 “C” 字形透明软骨环；软骨环缺口处为气管后壁，有弹性纤维韧带与平滑肌束。固有层浆细胞分泌的 IgA 与上皮分泌片结合形成 sIgA。

:::compare{title="肺内导气部管壁演变"}
| 结构 | 叶支气管 | 小支气管 | 细支气管 | 终末细支气管 |
|------|----------|----------|----------|--------------|
| 上皮 | 假复层纤毛柱状 | 低假复层纤毛柱状 | 单层纤毛柱状 | 单层柱状 |
| 杯状细胞 | 尚多 | 逐渐减少 | 很少 | 无 |
| 腺体 | 逐渐减少 | 少量 | 很少 | 无 |
| 透明软骨 | 不规则片状 | 片状，逐渐减少 | 稀少至消失 | 无 |
| 平滑肌 | 分散 | 相对增多 | 渐成环形 | 完整环形 |
:::

呼吸性细支气管管壁出现少量肺泡，上皮为单层立方，有克拉拉细胞和少许纤毛细胞。肺泡管管壁有许多肺泡，相邻肺泡开口之间有结节状膨大；肺泡囊则无结节状膨大。肺泡是气体交换场所，上皮分Ⅰ型和Ⅱ型：Ⅰ型扁平菲薄，覆盖绝大部分内表面，参与气-血屏障；Ⅱ型立方形或圆形，分泌颗粒为板层小体，释放表面活性物质，稳定肺泡大小，并能分裂增殖转变为Ⅰ型肺泡细胞。肺泡隔含丰富连续毛细血管网和弹性纤维。肺泡孔起侧支通气作用。

:::definition{label="气-血屏障"}
气-血屏障是肺泡内气体与血液中气体分子交换所通过的结构，包括肺泡表面的液体层、Ⅰ型肺泡细胞及其基膜、薄层结缔组织和毛细血管基膜与内皮。有的部位两层基膜融合为一层。总厚度为 $0.2\sim 0.5\,\mu\mathrm{m}$，有利于气体交换迅速进行。
:::

肺巨噬细胞由单核细胞分化而来；尘细胞和心力衰竭细胞是吞噬不同物质的肺泡巨噬细胞。

:::pitfall{label="终末细支气管还在导气部，不要因为管径细就写成呼吸部"}
呼吸部从管壁出现肺泡的呼吸性细支气管才开始。终末细支气管：无杯状细胞、无腺体、无软骨，平滑肌完整环形——仍无气体交换。Ⅰ型细胞覆盖面积大，Ⅱ型细胞才分泌表面活性物质；不要把两型对调。肺的毛细血管是连续型，和气血屏障那一层内皮对得上。
:::

:::memory{label="呼吸掌握清单"}
- [ ] 导气部到终末细支气管；呼吸部从呼吸性细支气管起
- [ ] 肺小叶 = 一条细支气管 + 各级分支和肺泡
- [ ] 越分支：上皮变矮、杯状细胞和软骨消失、平滑肌成环
- [ ] Ⅰ型构成屏障，Ⅱ型分泌表面活性物质并可补Ⅰ型
- [ ] 气血屏障总厚度 $0.2\sim 0.5\,\mu\mathrm{m}$
:::

## 八、泌尿：肾单位产尿，滤过膜三层是闸门

:::definition{label="肾单位"}
肾单位由肾小体、近端小管、细段和远端小管组成，是肾脏的基本结构和功能单位。肾小体和肾小管组成肾单位；肾小管与集合管系组成泌尿小管。浅表肾单位位于皮质浅部，数量较多、体积较小，在形成尿液中起重要作用；髓旁肾单位位于皮质深部，数量较少、体积较大，对尿液浓缩具有重要生理意义。
:::

肾实质含皮质和髓质。从肾锥体底部呈辐射状伸入皮质的条纹称髓放线，其间的皮质称皮质迷路。一个肾锥体与相连的皮质组成肾叶。肾小体位于皮质迷路和肾柱内，由血管球和肾小囊构成，有血管极和尿极。

血管球是介于入球、出球微动脉之间的动脉性毛细血管网。电镜下属有孔毛细血管，孔处无隔膜，基膜完整。入球微动脉较出球微动脉粗，球内血压高于肾小囊腔，水和小分子物质滤入囊腔形成原尿。球内系膜细胞合成基膜和系膜基质，并吞噬降解沉积于基膜上的免疫复合物。肾小囊外层单层扁平；内层为足细胞，次级突起互相嵌合成栅栏状，突起之间为裂孔，覆有裂孔膜。

:::definition{label="滤过膜"}
当血液流经血管球毛细血管时，血浆内部分物质经有孔毛细血管内皮、基膜和足细胞裂孔膜滤入肾小囊腔，这 $3$ 层结构称为滤过屏障或滤过膜。正常时，血液的细胞成分和大分子物质不能通过此屏障。
:::

:::compare{title="近端小管、细段、远端小管"}
| 节段 | 光镜 | 超微与功能 |
|------|------|------------|
| 近端小管 | 最长最粗；细胞界限不清，胞质强嗜酸，游离面刷状缘，基部纵纹 | 大量长微绒毛；顶小管和顶小泡胞饮小分子蛋白；侧突交错；质膜内褶。原尿重吸收的主要场所；分泌 $\mathrm{H}^{+}$、氨、肌酐和马尿酸 |
| 细段 | 单层扁平 | 水和离子较易透过 |
| 远端小管 | 腔较大较规则；立方细胞，弱嗜酸，分界清，无刷状缘，基部纵纹明显 | 微绒毛少而短；质膜内褶发达。直部主动向间质转运 $\mathrm{Na}^{+}$；曲部是离子交换重要部位。醛固酮促进重吸收 $\mathrm{Na}^{+}$、排出 $\mathrm{K}^{+}$；抗利尿激素促进水分重吸收 |
:::

近端小管直部、细段和远端小管直部共同组成髓袢。集合管系分弓形集合小管、直集合小管和乳头管，能进一步重吸收水分和交换离子；功能受醛固酮、抗利尿激素和心房钠尿肽调节。

球旁复合体位于肾小体血管极，由球旁细胞、致密斑和球外系膜细胞组成。球旁细胞由入球微动脉管壁平滑肌转变成上皮样细胞，颗粒内含肾素，将血管紧张素原转变成血管紧张素Ⅰ，后者在肺血管内皮作用下变为血管紧张素Ⅱ，促使血管收缩、血压升高；肾素还能促进肾上腺皮质分泌醛固酮。致密斑是远端小管靠近血管极侧上皮增高变窄而成的椭圆斑，感受滤过液中钠离子浓度变化。球外系膜细胞可能起信息传递作用。

肾血液循环特点：血流量大且流速快，全身血液每隔 $4\sim 5$ 分钟经肾滤过一次；入球比出球粗，利于滤过；两种毛细血管网（血管球滤过，球后营养和运输重吸收物质）；髓质直小血管与髓袢伴行，利于浓缩尿液。肾小管周围血管内皮能产生红细胞生成素。

输尿管和膀胱黏膜为变移上皮。输尿管肌层上 $2/3$ 段内纵外环，下 $1/3$ 段内纵、中环、外纵。膀胱盖细胞游离面胞膜有内褶和囊泡，充盈时可展开拉平；盖细胞间有桥粒和紧密连接，防止尿液渗漏。

:::pitfall{label="血管球有孔但孔处无隔膜，不要写成胃肠那种有隔膜的有孔内皮"}
滤过膜三层是内皮、基膜、裂孔膜，缺一层闸门就关不严。近端小管才是重吸收主场，远端小管才是醛固酮和抗利尿激素的主要作用段之一。致密斑在远端小管，不在近端。球旁细胞分泌肾素，不是直接分泌醛固酮。
:::

:::memory{label="泌尿掌握清单"}
- [ ] 肾单位 = 肾小体 + 近端小管 + 细段 + 远端小管
- [ ] 滤过膜：有孔内皮（无隔膜）+ 基膜 + 足细胞裂孔膜
- [ ] 入球粗、出球细 → 原尿
- [ ] 近端小管刷状缘，重吸收主场所
- [ ] 球旁复合体：球旁细胞（肾素）+ 致密斑 + 球外系膜细胞
- [ ] 全身血液每隔 $4\sim 5$ 分钟经肾滤过一次
:::

## 九、生殖：生精上皮一层层变，卵泡先问有没有腔

:::definition{label="睾丸"}
睾丸是产生精子和分泌雄性激素的器官。白膜在后缘增厚形成睾丸纵隔，实质分成约 $250$ 个锥体形睾丸小叶，每个小叶内有 $1\sim 4$ 条袢状生精小管。生精小管之间的疏松结缔组织内含睾丸间质细胞。
:::

生精上皮由支持细胞和 $5\sim 8$ 层生精细胞组成。自基底到腔面：精原细胞 → 初级精母细胞 → 次级精母细胞 → 精子细胞 → 精子。精子发生经历精原细胞增殖、精母细胞减数分裂和精子形成三个阶段。A 型精原细胞是干细胞。初级精母细胞核型 $46,\mathrm{XY}$（$4n\,\mathrm{DNA}$），第一次成熟分裂形成次级精母细胞（$23,\mathrm{X}$ 或 $23,\mathrm{Y}$，$2n\,\mathrm{DNA}$）；次级精母细胞不进行 DNA 复制即进入第二次成熟分裂，产生精子细胞（$1n\,\mathrm{DNA}$）。精子形成包括：核浓缩成头部、高尔基复合体形成顶体、中心体迁移形成轴丝、线粒体鞘包裹中段、残余胞质脱落。精子头前 $2/3$ 有顶体覆盖，顶体是特殊溶酶体；尾部轴丝为 $9+2$ 微管，中段外包线粒体鞘。

相邻支持细胞近基部紧密连接将生精上皮分成基底室（精原细胞）和近腔室（精母细胞、精子细胞和精子）。支持细胞：支持和营养、分泌雄激素结合蛋白和抑制素、吞噬残余胞质、参与血-睾屏障。血-睾屏障包括毛细血管内皮及其基膜、结缔组织、生精上皮基膜和支持细胞紧密连接，其中紧密连接最重要。

睾丸间质细胞（Leydig 细胞）具有类固醇激素分泌细胞超微结构，在黄体生成素刺激下分泌雄激素。青春期前生精小管无管腔，上皮仅支持细胞和精原细胞。附属腺和生殖管道分泌物以及精子共同组成精液：每次射精量 $3\sim 5\,\mathrm{ml}$，每毫升含 $1$ 亿 $\sim$ $2$ 亿个精子；若每毫升低于 $400$ 万个，可导致不育症。

:::compare{title="卵泡四级：先问有没有卵泡腔"}
| 项目 | 原始卵泡 | 初级卵泡 | 次级卵泡 | 成熟卵泡 |
|------|----------|----------|----------|----------|
| 卵母细胞 | 初级卵母细胞，长期休止于第一次成熟分裂前期 | 初级，体积渐大，出现皮质颗粒 | 初级，体积更大 | 排卵前 $1\sim 1.5\,\mathrm{d}$ 形成次级卵母细胞和第一极体 |
| 透明带 | 无 | 有，嗜酸性均质状，含精子受体 | 有 | 有 |
| 放射冠 | 无 | 有 | 有 | 有 |
| 卵泡细胞 | 单层扁平 | 单层立方增至多层 | 多层；有卵泡腔、颗粒层及卵丘 | 卵泡腔更大，颗粒层变菲薄 |
| 卵泡膜 | 无 | 有，薄 | 渐厚，分内外两层，有膜细胞 | 两层更明显 |
| 内分泌 | 无 | 有 | 膜细胞合成雄激素，经颗粒细胞转化为雌激素 | 同左 |
:::

排卵在月经周期第 $14$ 天左右：成熟卵泡向卵巢表面突出形成卵泡小斑，次级卵母细胞 + 透明带 + 放射冠排入腹膜腔。若 $24\,\mathrm{h}$ 内受精，完成第二次成熟分裂，形成单倍体（$23,\mathrm{X}$）的卵细胞和第二极体；未受精则退化死亡。

排卵后卵泡壁和卵泡膜向腔内塌陷形成黄体：颗粒黄体细胞数量多、体积大、染色浅，位于中央，分泌孕激素；膜黄体细胞数量少、体积小、染色深，位于周边，分泌雌激素。未受精则维持 $12\sim 14\,\mathrm{d}$ 后退化，称月经黄体，再变为白体。受精则在绒毛膜促性腺激素作用下成为妊娠黄体，维持 $4\sim 6$ 个月后退化成白体。

子宫内膜分功能层和基底层。月经周期约 $28\,\mathrm{d}$，分增生期（卵泡期，雌激素）、分泌期（黄体期，雌激素和孕激素）和月经期（螺旋动脉收缩→缺血坏死→短暂扩张出血）。宫颈外口处单层柱状上皮与复层扁平上皮移行，是宫颈癌好发部位。阴道黏膜上皮为未角化复层扁平上皮。

:::pitfall{label="次级卵泡里仍是初级卵母细胞，不要把腔和减数分裂并成一级"}
卵泡腔出现才叫次级卵泡；次级卵母细胞要到成熟卵泡排卵前 $1\sim 1.5\,\mathrm{d}$ 才出现。排卵带出的是次级卵母细胞加透明带加放射冠，不是「裸卵」。黄体不是卵泡的别名：颗粒黄体细胞出孕激素，膜黄体细胞出雌激素。精子发生减数分裂在生精小管，卵子第一次成熟分裂长期停在前期，第二次停在中期等受精。
:::

## 十、胚胎总论：三期时间轴，受精先获能

:::definition{label="胚胎学"}
胚胎学研究内容主要包括生殖细胞发生、受精、胚胎发育、胚胎与母体的关系、先天性畸形等。
:::

:::compare{title="人胚胎发育三期"}
| 时期 | 时间 | 内容落点 |
|------|------|----------|
| 胚前期 | 从受精卵形成至第 $2$ 周末二胚层胚盘出现 | 受精、卵裂、胚泡形成、植入、二胚层胚盘形成 |
| 胚期 | 从第 $3$ 周至第 $8$ 周末 | 三胚层胚盘形成及其早期分化、胎膜与胎盘形成、胚体形成及胚层进一步分化 |
| 胎期 | 从第 $9$ 周至出生 | 胎儿逐渐长大，各器官系统继续发育，多数器官出现不同程度功能活动 |
:::

指南习题把足月胎儿娩出的受精龄定为 $38$ 周、月经龄定为 $40$ 周。不要把胚期写成「从受精一直到第 $8$ 周末」——那把胚前期也并进去了。

生殖细胞包括精子和卵子，均为单倍体。精子头表面有一层糖蛋白，阻止顶体酶释放；通过女性生殖管道时该糖蛋白被去除，称获能。从卵巢排出的次级卵母细胞处于第二次成熟分裂中期；受精才完成第二次成熟分裂，未受精则在排卵后 $24\,\mathrm{h}$ 内退化。

:::definition{label="受精"}
受精指精子与卵子结合形成受精卵的过程，一般发生在输卵管壶腹部。获能的精子通过顶体反应（释放顶体酶溶蚀放射冠和透明带）与透明带特异性结合并通过，精卵细胞膜融合。一个精子进入后，卵子释放皮质颗粒中的酶类，使透明带结构变化而不能再与其他精子结合，称为透明带反应，以保证单精受精。随后完成第二次成熟分裂，雄原核与雌原核染色体混合，形成二倍体受精卵。受精可决定子代遗传性别，并使子代具有双亲的遗传物质。
:::

受精卵细胞分裂称卵裂，子细胞称卵裂球。$12\sim 16$ 个卵裂球组成的实心胚称桑椹胚，再变成囊泡状胚泡：壁为滋养层，内侧一群细胞为内细胞群。植入是胚泡埋入子宫内膜的过程，又称着床，部位通常在子宫体和底部的后壁；植入子宫以外称宫外孕。植入时透明带已完全溶解，内细胞群侧滋养层先接触内膜。滋养层分化为细胞滋养层和合体滋养层。植入时内膜处于分泌期，植入后的内膜改称蜕膜，分基蜕膜、包蜕膜和壁蜕膜。

第 $2$ 周形成二胚层胚盘：上胚层柱状，下胚层立方；背侧羊膜囊，腹侧卵黄囊；胚外中胚层及胚外体腔出现，体蒂将来参与构成脐带。第 $3$ 周初上胚层正中线一侧形成原条、原结、原凹、原沟；部分细胞形成中胚层，部分置换下胚层形成内胚层，上胚层改称外胚层。原结向头端形成脊索。脊索头侧和原条尾侧各有口咽膜和泄殖腔膜。

:::compare{title="三胚层分化主账"}
| 胚层 | 分化去向 |
|------|----------|
| 外胚层 | 神经板→神经管→脑、脊髓、松果体、神经垂体和视网膜等；神经嵴是周围神经系统原基；表面外胚层→表皮及附属器、角膜上皮、晶状体、内耳膜迷路、腺垂体等 |
| 中胚层 | 轴旁中胚层（体节）→真皮、中轴骨骼及骨骼肌；间介中胚层→泌尿、生殖系统主要器官；侧中胚层→体壁（胸腹和四肢的真皮、骨骼肌、骨骼和血管等）与脏壁（消化、呼吸管道壁的肌组织和结缔组织等）；间充质→身体各处骨骼、肌肉、结缔组织和血管等 |
| 内胚层 | 消化管、消化腺、喉以下呼吸道和肺的上皮，以及胸腺、甲状腺、甲状旁腺和膀胱等器官的上皮 |
:::

至第 $8$ 周末，胚体外表可见眼、耳和鼻的原基及发育中的四肢，初具人形。胎膜包括绒毛膜、羊膜、卵黄囊、尿囊和脐带。人体造血干细胞和原始生殖细胞分别来自卵黄囊壁的胚外中胚层和内胚层。脐带内含两条脐动脉及一条脐静脉。胎盘由胎儿的丛密绒毛膜和母体的基蜕膜组成；绒毛膜发出 $40\sim 60$ 根绒毛干。胎盘膜（胎盘屏障）由合体滋养层、细胞滋养层及其基膜、薄层绒毛结缔组织、毛细血管基膜和内皮组成。胎盘分泌人绒毛膜促性腺激素、人胎盘催乳素、孕激素和雌激素。

:::pitfall{label="获能在女性管道里发生，透明带反应保证单精受精"}
把获能写成「在睾丸里完成」，顶体酶释放会提前。把透明带反应写成「精子自己关闭顶体」，单精受精的闸门会安错地方。胚泡植入通常在子宫体和底部后壁，不是「任何内膜都一样」。神经管来自外胚层，泌尿生殖主要器官来自间介中胚层，不要把三胚层去向对调。
:::
