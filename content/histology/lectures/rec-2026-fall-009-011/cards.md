# 人体组织学 · 第9-11节 复习手卡

> 用法：先看卡片标题回忆，点击展开对照「直接结论 / 深度解析 / 助记口诀」。共 13 张。

## 第一章

:::memory{label="1.1 上皮组织 vs 结缔组织" mode="reveal"}
**直接结论**

- 血管｜上皮无血管；结缔组织有丰富血管
- 排列｜上皮紧密、间质少；结缔松散、间质多
- 极性｜上皮有极性（游离面/基底面/侧面）；结缔无极性
- 分布｜上皮在表面或腔面；结缔分布最广、位于上皮下方

**深度解析**

上皮组织无血管，其营养靠下方结缔组织的血管透过基膜供给、代谢废物也经此排出，故上皮下方必衬结缔组织。两种组织均有神经分布（皮肤的触觉、温度觉即由上皮内神经末梢感受）。上皮因位于临界面而细胞排列紧密、间质少；结缔组织承担缓冲、营养、支持、连接，细胞散在、细胞外间质丰富且无方向性。

> 🎯 助记：上皮无血有极性，结缔有血无极性。

:::

:::memory{label="1.2 被覆上皮分类依据" mode="reveal"}
**直接结论**

- 分类依据｜细胞层数（单层/复层）+ 表层细胞形态
- 单层分类｜按细胞整体形态（扁平/立方/柱状）
- 复层分类｜按最表层细胞形态

**深度解析**

假复层实质为单层：所有细胞都附着在基膜上，只是细胞核高低不一、镜下看似复层，故称假复层。就像操场上排队，虽然高矮不一，但都站在地面上。复层上皮命名以最浅表一层细胞形态为准。

:::

## 第二章

:::memory{label="2.1 单层扁平上皮" mode="reveal"}
**直接结论**

- 间皮｜胸膜腔、腹膜腔、心包腔表面（体腔浆膜）
- 内皮｜心、血管、淋巴管腔面（脉管系统）
- 切片｜6号大网膜银染（正面观）；46号小肠（侧面观）

**深度解析**

6号切片为大网膜铺片、硝酸银染色，银颗粒沉着在细胞膜与少量间质处，正面观勾勒出多边形细胞轮廓。46号小肠HE染色看侧面观，单层扁平细胞呈扁平梭形核。三大体腔中以腹膜腔最大（含胃肠等腹腔盆腔脏器）。

:::

:::memory{label="2.2 单层柱状上皮" mode="reveal"}
**直接结论**

- 分布｜消化管腔面（胃、肠）
- 必背｜光镜纹状缘 = 电镜微绒毛；功能为增大吸收面积
- 杯状细胞｜高脚杯状，胞质浅染，三角核位于基底部

**深度解析**

纹状缘是单层柱状上皮游离面在光镜下所见的一条致密嗜酸性红带，电镜下其结构基础是大量整齐排列的微绒毛。纹状缘在杯状细胞处中断，因杯状细胞表面微绒毛少。切片斜切时可同时切到前后几个细胞，单层上皮看似复层。

:::

:::memory{label="2.3 假复层纤毛柱状上皮" mode="reveal"}
**直接结论**

- 分布｜呼吸管道（气管、支气管等）
- 必背｜实为单层（所有细胞附基膜），核高低不一看似复层
- 纤毛｜可摆动，推送粉尘、异物、分泌物排出

**深度解析**

游离面有比微绒毛粗长、光镜下可见明显突起的纤毛，基膜常较明显，可含杯状细胞。⚠️ 纤毛可动、微绒毛不可动，二者功能不同：纤毛司推送排出，微绒毛司扩大吸收面积。

:::

:::memory{label="2.4 复层扁平上皮" mode="reveal"}
**直接结论**

- 未角化｜食管、口腔、阴道等，表层细胞仍有核
- 角化｜皮肤表皮，表层核消失、细胞透明
- 交界｜与结缔组织凹凸不平——增大接触面以利营养

**深度解析**

复层扁平上皮层数多、表层细胞扁平。本次观察的是未角化型（43号食管），浅层仍可见细胞核；角化型（皮肤表皮）浅层细胞核消失，留待皮肤章节。因上皮较厚且无血管，与下方结缔组织的交界凹凸不平以扩大接触面积，利于营养渗透。

:::

:::memory{label="2.5 变移上皮" mode="reveal"}
**直接结论**

- 分布｜膀胱、输尿管等泌尿系统腔面
- 必背｜表层盖细胞可双核；形态随充盈度变化
- 空虚｜表层细胞大、立方形/多边形、层数多
- 充盈｜细胞被拉平变扁、层数减少

**深度解析**

变移上皮为复层，表层盖细胞体积大、可覆盖下方多个细胞，部分盖细胞可见双核。空虚时细胞大而层数多；充盈时被拉伸变扁平、层数减少，故名变移。其与结缔组织交界较平坦（60号膀胱切片）。

:::

## 第三章

:::memory{label="3.1 成纤维细胞 vs 纤维细胞" mode="reveal"}
**直接结论**

- 成纤维细胞｜激活态，核大浅染、核仁清，合成纤维和基质
- 纤维细胞｜静止态，核细长梭形、染色深
- 必背｜二者为同一细胞的不同功能状态

**深度解析**

正常未受伤组织中以静止的纤维细胞居多；组织损伤时纤维细胞变胖、胞质增多、核变浅且核仁清晰，转为激活的成纤维细胞，开始合成胶原等纤维与基质。HE下主要依核的形态判断。

:::

:::memory{label="3.2 巨噬细胞" mode="reveal"}
**直接结论**

- 识别｜12号皮下铺片，台盼蓝染色→胞质内蓝色吞噬颗粒
- 形态｜不规则形，可发出伪足
- 功能｜吞噬异物和衰老细胞，参与免疫

**深度解析**

实验前给家兔皮下注射蓝色染料台盼蓝，有吞噬功能的巨噬细胞将染料颗粒吞入胞质，光镜下核周胞质内见蓝色颗粒者即为巨噬细胞；无颗粒者不能仅凭形态认定。切片另以醛复红染弹性纤维。

:::

:::memory{label="3.3 ★浆细胞（四要素）" mode="reveal"}
**直接结论**

- 必背｜核偏位 + 胞质嗜碱 + 车辐状核 + 核周浅染区
- 来源｜B淋巴细胞
- 功能｜分泌抗体（体液免疫）

**深度解析**

浆细胞核偏心位为最明显特征；胞质丰富、HE染色偏蓝紫色而嗜碱性深染，边界清楚；核内异染色质沿核膜下方呈车辐状（车轮状）排列；部分于核旁见浅染区。镜下找法：低倍先找偏蓝紫的浆细胞密集区，再换高倍逐一确认。

> 🎯 助记：偏位嗜碱车轮核，B细胞来分泌抗体。

:::

:::memory{label="3.4 肥大细胞与脂肪细胞" mode="reveal"}
**直接结论**

- 肥大细胞｜甲苯胺蓝染色紫红色（异染性）颗粒，轮廓清晰，参与过敏
- 脂肪细胞｜HE空泡状（脂滴被酒精溶解），核扁、偏位贴边

**深度解析**

肥大细胞圆形或卵圆形，染料结合于胞质颗粒而呈紫红异染，核小而染色浅，释放组胺、肝素等与过敏反应相关。脂肪细胞含一个大脂滴，HE制片中脂滴被酒精溶解而呈中央大空泡，胞质与核被挤到边缘（单泡性黄/白色脂肪）。

:::

## 第四章

:::memory{label="4.1 三种纤维" mode="reveal"}
**直接结论**

- 胶原纤维｜HE粉红，边界模糊、粗细不均、波浪状
- 弹性纤维｜醛复红紫，发丝状、可有卷曲
- 网状纤维｜镀银黑，纤细网状（本次不观察）

**深度解析**

HE下粉红色、边界不清、粗细不均波浪状的是数量最多的胶原纤维；弹性纤维需醛复红特染呈深紫色、发丝状；网状纤维需镀银染色呈黑色。三者染色方法与形态各异，不能仅凭HE区分弹性与网状纤维。

> 🎯 助记：胶原粉红弹性紫，网状镀银细细网。

:::

:::memory{label="4.2 实验操作要点" mode="reveal"}
**直接结论**

- 切片编号｜卡槽数字=顺序号，切片标签号=片号；白色标签以最右下角数字为片号
- 显微镜｜低倍定位、禁油镜（100×需油介质）
- 平台｜学习通 / Spark组胚 / 数字切片平台
- 成绩｜平时15 + 切片考试25 + 期末60

**深度解析**

领取时须保证座位号=切片盒号=显微镜号=座凳号四号一致，按盒面目录由片号查顺序号取片；切片取后盖盒、避光防褪色。显微镜先用4×/10×低倍定位，眼睛侧视升载物台后再目镜下调防压碎切片，移动载物台用下方旋钮。Imageview软件选YW1600相机同步观察。

:::
