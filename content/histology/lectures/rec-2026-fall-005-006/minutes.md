## 二、核心知识点

### （一）固有结缔组织（续）

#### 1. 网状纤维

| 项目 | 内容 |
|---|---|
| 染色特征 | HE染色无法与胶原纤维区分；**镀银染色**特异性显示（嗜银纤维） |
| 电镜特征 | 可见典型**周期性横纹**，核心成分为**Ⅲ型胶原蛋白** |
| 分布 | 基膜网板、淋巴结皮质、脾、内分泌腺、肝小叶；肝内**储脂细胞**可合成网状纤维 |

#### 2. 基质（Ground Substance）

- **基本属性**：细胞与纤维之间的无定型胶状物质，有粘性
- **三大成分**：
  1. **蛋白聚糖**：核心蛋白 + 硫酸化糖胺聚糖 → 亚单位；通过结合蛋白连接长链**透明质酸** → 聚合体
  2. **多联糖蛋白**：连接作用，将细胞、纤维、基质相互结合
  3. **组织液**：毛细血管动脉端渗出 → 静脉端回流；失衡 → 水肿/脱水
- **糖胺聚糖分类**：
  - 硫酸化小分子：硫酸软骨素、硫酸角质素等
  - 非硫酸化长链：**透明质酸**（即玻尿酸）
- **分子筛功能**：蛋白聚糖聚合体形成带网孔的分子筛 → 阻挡大分子、细菌扩散 → 局限感染
- **屏障局限性**：**透明质酸酶**可破坏分子筛；溶血性链球菌、肿瘤细胞可分泌该酶 → 感染/病灶扩散

#### 3. 致密结缔组织

| 类型 | 纤维特征 | 分布 |
|---|---|---|
| 规则致密结缔组织 | 胶原纤维平行定向排列；成纤维细胞特化为**腱细胞** | 肌腱、韧带、腱膜 |
| 不规则致密结缔组织 | 纤维无定向、相互交织 | 真皮、硬脑膜、巩膜、内脏被膜 |
| 弹性组织 | 以弹性纤维为核心 | 项韧带、黄韧带；**大动脉根部弹性膜**（多方向弹性纤维，心脏舒张期回缩排血，保障血液循环连续性） |

#### 4. 脂肪组织

| 类型 | 细胞类型 | 形态特征 |
|---|---|---|
| 黄色/白色脂肪 | **单泡脂肪细胞** | 一个大脂滴，HE染色呈空泡状，核被挤至细胞边缘 |
| 棕色脂肪 | **多泡脂肪细胞** | 多个小脂滴，核位于细胞中央 |

#### 5. 网状组织

- **构成**：网状细胞 + 网状纤维 + 基质
- **网状细胞**：胞体大、星状多突起，胞质弱嗜碱性，核大而圆、核仁清晰；突起互联成网架
- **功能**：类似成纤维细胞，合成网状纤维与基质；作为**造血组织、淋巴组织、内分泌组织的支架**

### （二）软骨组织

#### 1. 基本属性与分类

- 属于**特殊结缔组织**：细胞外基质呈**固态**、**无血管**，营养靠基质通透性扩散
- **分类依据**：细胞外基质中纤维种类
  - **透明软骨**：Ⅱ型胶原原纤维（折光率与基质接近，光镜下不可见）
  - **弹性软骨**：大量弹性纤维
  - **纤维软骨**：大量粗大胶原纤维

#### 2. 透明软骨（重点掌握）

**分布**：肋软骨、关节面、呼吸道管壁软骨环、早期胚胎骨架（分布最广）

**器官结构**：软骨组织 + 软骨膜（关节面处无软骨膜）

**软骨基质**：
- 坚硬凝胶状，Ⅱ型胶原蛋白细胶原原纤维
- HE染色呈**嗜碱性**
- **软骨陷窝**：基质内的空腔，软骨细胞位于其中
- **软骨囊**：紧邻陷窝的基质，含大量硫酸软骨素，嗜碱性强

**软骨细胞**：
- 靠近软骨膜：体积小、单个分散（幼稚状态）
- 向内部：体积增大，形成**同源细胞群**（同一个幼稚软骨细胞分裂增殖形成的细胞团）
- 超微结构：丰富粗面内质网，线粒体极少（**无氧糖酵解供能**）

**软骨膜**：
- 外层：纤维多、细胞少
- 内层：纤维少、细胞丰富，含**软骨祖细胞**（可分化为软骨细胞）
- 功能：保护、营养、生长与修复

#### 3. 另外两类软骨

| 类型 | 分布 | 特征 |
|---|---|---|
| 弹性软骨 | 耳郭、外耳道、会厌 | 大量弹性纤维，弹性极强；地衣红染色显示 |
| 纤维软骨 | 椎间盘、关节盘、耻骨联合 | 大量平行/垂直排列的粗大胶原纤维；**无软骨膜** |

#### 4. 软骨发生与生长

- **起源**：胚胎时期**间充质** → 间充质细胞密集 → 软骨形成中心 → 软骨祖细胞 → 成软骨细胞 → 软骨细胞
- **外加生长（外生长）**：软骨膜内层软骨祖细胞分化 → 外周产生新软骨 → 向外增厚扩大
- **间质生长（内积生长）**：软骨内部已有软骨细胞增殖、合成基质 → 从内部向外生长

### （三）骨组织

#### 1. 骨的功能与组成

**五大功能**：支撑躯体、保护内脏、运动杠杆、储存机体**99%的钙与磷**、骨髓造血

**骨器官组成**：骨组织 + 骨膜 + 骨髓

#### 2. 骨基质

| 成分 | 占比 | 内容 |
|---|---|---|
| 有机成分 | 35% | 95%为**Ⅰ型胶原蛋白**胶原纤维；其余为无定型基质（骨黏连蛋白、骨钙素等） |
| 无机成分 | 65% | **羟基磷灰石结晶**（针状/片状，分布于胶原纤维间隙）→ 骨硬度来源 |

- **类骨质**：未发生钙盐沉着的骨基质有机成分
- 钙化依赖**维生素D**介导的钙磷吸收；缺阳光 → 维生素D不足 → 软骨病（婴幼儿：颅骨软、鸡胸、X型腿）

#### 3. 四类细胞

**骨祖细胞**：
- 分布于骨组织表面，梭形、胞质染色浅
- 骨组织干细胞 → 分化为成骨细胞

**成骨细胞**：
- 位于骨组织表面，立方/矮柱状，HE染色嗜碱性
- 丰富粗面内质网与高尔基复合体
- 功能：分泌胶原纤维与有机基质 → 形成**类骨质**；通过**基质小泡**启动钙盐沉着；分泌细胞因子调控骨代谢
- 转归：10%~15%被基质包埋 → **骨细胞**；部分转为骨被覆细胞；其余凋亡

**骨细胞**：
- 扁椭圆形，位于**骨陷窝**中
- 胞体伸出大量突起 → **骨小管**内（类似手掌与手套关系）
- 功能静止，保留一定成骨/破骨能力；通过骨小管内组织液获取营养

**破骨细胞**：
- 来源：多个单核细胞融合（骨组织内的巨噬细胞）
- 胞体巨大、多核、胞质嗜酸性
- 结构：靠近骨组织一侧形成**皱折缘**，周围环绕**亮区**（封闭局部微环境，提供酸性环境）
- 功能：释放酸性物质、蛋白酶溶解骨基质 → 内吞消化吸收；参与骨改建与血钙平衡
- **血钙调控**：甲状旁腺激素 → 破骨细胞活跃 → 升高血钙；降钙素 → 促进成骨 → 降低血钙

#### 4. 骨组织类型

| 类型 | 别名 | 特征 |
|---|---|---|
| 初级骨组织 | 编织骨 | 胶原纤维粗大、排列紊乱呈编织状；钙盐少、骨细胞多；有机成分占比高 |
| 次级骨组织 | 板层骨 | 胶原纤维细、排列规律；相邻骨板胶原纤维**相互垂直**；钙盐充分 |

#### 5. 长骨密质骨结构（三种骨板 + 两种管道）

**环骨板**：
- 外环骨板：环绕骨干外表面，厚、排列规则
- 内环骨板：衬在骨髓腔面，薄、排列不规则

**穿通管（福尔克曼管）**：
- 垂直于长骨长轴，穿过环骨板
- 连接骨膜与内部管道，导入血管、结缔组织

**骨单位（哈佛系统）**：
- 长骨骨干核心结构单位，圆筒状
- 中央为**哈佛管**，周围环绕多层同心圆排列的骨单位骨板
- 骨小管逐层相通，最内层与中央管连通 → 营养通路

**间骨板**：
- 骨改建中未被完全吸收的残留骨单位片段
- 无中央管，扇形分布于相邻骨单位之间

**松质骨**：骨骺深部、骨髓腔内侧；条索状骨板交织成**骨小梁**，网孔填充骨髓

#### 6. 骨膜

- **分布**：除关节面外，所有骨表面、骨髓腔面、骨小梁表面、中央管与穿通管内壁
- **骨外膜**：外层纤维多（穿通纤维固定），内层细胞丰富（含骨祖细胞）
- **骨内膜**：薄层结缔组织，覆盖骨髓腔面等，含骨祖细胞与骨被覆细胞
- 功能：保护、营养、骨祖细胞分化为成骨细胞 → 生长与修复

#### 7. 骨发生

**膜内成骨**：
- 颅骨、顶骨、锁骨
- 间充质结缔组织膜 → 膜内骨化中心 → 初级松质骨 → 骨膜内层成骨细胞形成密质骨

**软骨内成骨**（四肢骨、躯干骨）：
1. 透明软骨雏形（与最终骨形态一致）
2. **骨领形成**：软骨雏形中段软骨膜 → 骨膜 → 内层成骨细胞以膜内成骨方式形成领状骨套层
3. **初级骨髓腔**：骨膜结缔组织+血管侵入退化软骨基质 → 破骨细胞溶解吸收 → 初始骨髓腔
4. **次级骨化中心**：两端骨骺区域形成骨化中心 → 改建为骨骺；关节面永久保留透明软骨（关节软骨）

#### 8. 骨生长调控

**骺板（生长板）**：
- 骨骺与骨干之间保留的透明软骨层
- 不断增殖产生新软骨 → 长骨加长的结构基础
- **五区**（从骨骺向骨干）：软骨储备区 → 软骨增生区 → 软骨成熟区 → 软骨钙化区 → 成骨区

**激素调控**：
| 激素 | 作用 | 缺乏/过量 |
|---|---|---|
| 生长激素 | 促进骺板软骨增殖 | 青春期前不足 → 侏儒症；过量 → 巨人症 |
| 甲状腺激素 | 调控骺板生长 + 神经系统发育 | 不足 → 呆小症（生长停滞 + 智力障碍） |

**长骨增粗**：骨膜内层成骨细胞不断在骨干外周形成新骨 → 横向增粗

**骨改建**：骨单位不断更新迭代 → 旧骨单位残留片段 → 间骨板 → 密质骨更坚固

## 三、例题 / 强调点

1. **透明质酸酶与感染扩散**：溶血性链球菌分泌透明质酸酶 → 破坏分子筛 → 蜂窝织炎扩散
2. **PS外翻 = 细胞凋亡信号**（细胞生物学关联，但组织学中膜结构也涉及）
3. **大动脉弹性组织**：心脏间断射血 → 大动脉弹性膜舒张储存能量 → 舒张期回缩 → 血液循环连续
4. **同源细胞群**：软骨内部细胞增殖的形态学标志，由同一个幼稚软骨细胞分裂形成
5. **骨细胞的"手掌-手套"关系**：骨陷窝（手套）容纳骨细胞胞体（手掌），骨小管容纳突起
6. **破骨细胞的皱折缘+亮区**：封闭微环境 → 酸性溶解骨基质
7. **骺板五区顺序**：储备→增生→成熟→钙化→成骨（必考排序）
8. **呆小症 vs 侏儒症**：甲状腺激素缺乏 = 呆小（智力+身材）；生长激素缺乏 = 侏儒（仅身材，智力正常）

## 五、主动回忆题

**Q1：网状纤维为什么需要镀银染色才能显示？其主要分布在哪些部位？**
> 网状纤维由Ⅲ型胶原蛋白构成，HE染色下折光率与胶原纤维接近无法区分；镀银染色可特异性显示（嗜银性）。分布于基膜网板、淋巴结皮质、脾、内分泌腺、肝小叶等处。

**Q2：蛋白聚糖聚合体如何形成分子筛？什么情况下屏障作用会被破坏？**
> 核心蛋白结合硫酸化糖胺聚糖形成亚单位，再通过结合蛋白连接长链透明质酸形成聚合体，聚合体交织成带网孔的分子筛。透明质酸酶可降解透明质酸破坏骨架，溶血性链球菌和肿瘤细胞可分泌该酶导致感染或病灶扩散。

**Q3：透明软骨的软骨细胞在分布上有什么规律？什么是同源细胞群？**
> 靠近软骨膜的软骨细胞体积小、单个分散（幼稚状态）；向组织内部体积增大，形成同源细胞群。同源细胞群是由同一个幼稚软骨细胞分裂增殖形成的软骨细胞团，是软骨内部细胞增殖的形态学特征。

**Q4：骨组织的四类细胞分别是什么？破骨细胞如何实现骨吸收？**
> 骨祖细胞（干细胞）、成骨细胞（形成类骨质、启动钙化）、骨细胞（被包埋，功能静止）、破骨细胞（骨吸收）。破骨细胞靠近骨组织一侧形成皱折缘，周围亮区封闭局部微环境，释放酸性物质和蛋白酶溶解骨基质，再经内吞作用消化吸收。

**Q5：长骨密质骨由哪三种骨板和哪两种管道构成？骨单位的结构是怎样的？**
> 三种骨板：外环骨板、内环骨板、骨单位骨板（+间骨板）。两种管道：穿通管（垂直长轴，连接骨膜与内部）、哈佛管（骨单位中央管）。骨单位=中央哈佛管+周围多层同心圆排列的骨单位骨板，骨小管逐层相通连至中央管提供营养。

**Q6：软骨内成骨的基本过程是怎样的？骺板在长骨加长中起什么作用？**
> 透明软骨雏形→骨领形成（软骨膜转骨膜，膜内成骨形成领状骨套）→初级骨髓腔（血管侵入+破骨吸收）→次级骨化中心（两端骨骺）。骺板是骨骺与骨干间保留的透明软骨层，不断增殖产生新软骨，是长骨不断加长的结构基础，分储备区、增生区、成熟区、钙化区、成骨区五区。

**Q7：生长激素和甲状腺激素缺乏分别导致什么疾病？区别在哪里？**
> 生长激素缺乏→侏儒症（仅身材矮小，智力正常）；甲状腺激素缺乏→呆小症（身材矮小+智力障碍，因甲状腺激素同时调控骺板生长和神经系统发育）。
