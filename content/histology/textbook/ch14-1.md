# 一、消化管壁的一般结构

消化系统（digestive system）由消化管和消化腺组成。消化管是从口腔至肛门的连续性管道，依次分为口腔、咽、食管、胃、小肠和大肠，主要对食物进行物理性和化学性消化，将大分子物质分解为小分子的氨基酸、单糖、脂肪酸等，进而吸收营养物质和排泄食物残渣。此外，消化管黏膜还是机体的一个重要屏障，黏膜内富有淋巴组织和免疫细胞，对病原生物等有害物质具有重要的防御作用。消化管上皮内还含有多种内分泌细胞。消化管的管壁结构具有共同的分层规律，又各具有与其功能相适应的特点。本章先把除口腔与咽外的管壁四层摊开；口腔与咽、食管、胃、小肠、大肠、淋巴组织和胃肠内分泌细胞各立一节。

:::definition{label="消化系统"}
消化系统（digestive system）由消化管和消化腺组成。消化管完成物理性与化学性消化、吸收营养并排泄残渣；消化腺（唾液腺、肝、胰等）另立第 15 章。
:::

:::definition{label="消化管"}
消化管是从口腔至肛门的连续性管道，依次分为口腔、咽、食管、胃、小肠和大肠。管壁有共同的分层规律，各段又有与功能相适应的结构特点。
:::

:::definition{label="消化管黏膜的屏障功能"}
消化管黏膜是机体的一个重要屏障。黏膜内富有淋巴组织和免疫细胞，对病原生物等有害物质具有重要的防御作用。上皮内还含有多种内分泌细胞。
:::

:::concept{term="先问这一段管壁有没有黏膜肌，再数黏膜、黏膜下层、肌层、外膜"}
看见消化管切片，先把四本账立住：黏膜（上皮 + 固有层 + 黏膜肌层）→ 黏膜下层 → 肌层 → 外膜。口腔与咽没有黏膜肌层，不能硬套四层。两端上皮是复层扁平（保护），中间是单层柱状（消化吸收）。把“管壁都是四层平滑肌”听成一句，贲门、肛门的骨骼肌和浆膜–纤维膜那两本账会一起错位。
:::

:::compare{title="消化管各段的功能侧重"}
| 项目 | 口腔、咽 | 食管 | 胃 | 小肠 | 大肠 |
|------|----------|------|----|------|------|
| 主要职分 | 摄食、初步咀嚼与味觉；咽是消化与呼吸交叉 | 运送食团入胃 | 贮存，初步消化蛋白质，吸收部分水、无机盐和醇类 | 消化和吸收的主要部位 | 吸收水分、形成粪便 |
| 上皮大方向 | 复层扁平（保护） | 未角化复层扁平 | 单层柱状 | 单层柱状 | 单层柱状（肛管下部改复层扁平） |
| 本章位置 | 第二节 | 第三节 | 第四节 | 第五节 | 第六节 |
:::

除口腔与咽外，消化管壁自内向外分为黏膜、黏膜下层、肌层与外膜 4 层（图 14-1）。

:::definition{label="消化管壁四层"}
除口腔与咽外，消化管壁自内向外分为黏膜（mucosa）、黏膜下层（submucosa）、肌层（muscularis）与外膜（adventitia）4 层。
:::

## （一）黏膜

黏膜（mucosa）由上皮、固有层和黏膜肌层组成，是消化管各段结构差异最大、功能最重要的部分。

:::definition{label="黏膜"}
黏膜（mucosa）由上皮、固有层和黏膜肌层组成。它是消化管各段结构差异最大、功能最重要的部分：消化、吸收、屏障和局部免疫主要写在这一层。
:::

### 1. 上皮

上皮的类型依部位而异。消化管的两端（口腔、咽、食管及肛门）为复层扁平上皮，以保护功能为主；余为单层柱状上皮，以消化吸收功能为主。上皮与管壁内的腺体相连续。上皮细胞间有散在分布的淋巴细胞，尤其在小肠上皮中多见。

:::definition{label="消化管上皮的两端与中间"}
消化管两端（口腔、咽、食管及肛门）为复层扁平上皮，以保护为主；其余各段为单层柱状上皮，以消化吸收为主。上皮与管壁内的腺体相连续。
:::

:::definition{label="上皮内淋巴细胞"}
上皮细胞间有散在分布的淋巴细胞，尤其在小肠上皮中多见。它们是黏膜屏障和局部免疫的细胞学落点，不是“上皮自己变成了白细胞”。
:::

:::compare{title="复层扁平上皮与单层柱状上皮"}
| 项目 | 复层扁平上皮 | 单层柱状上皮 |
|------|--------------|--------------|
| 部位 | 口腔、咽、食管及肛门（消化管两端） | 胃、小肠、大肠等其余各段 |
| 功能侧重 | 保护，抗摩擦和机械损伤 | 消化与吸收 |
| 与腺体 | 可与黏液腺等相续 | 与胃腺、肠腺等相续 |
| 易混点 | 食管下端在贲门处骤变为单层柱状，是食管癌易发部位 | 不要把胃表面黏液细胞写成复层扁平 |
:::

:::pitfall{label="两端是复层扁平，不要把胃和小肠也写成“保护性复层扁平”"}
复层扁平出现在摩擦大、不承担吸收的两端。胃和肠要分泌、吸收，必须是单层柱状。把胃底腺表面写成复层扁平，黏液膜、主细胞和微绒毛那几本账会从第一层就塌掉。
:::

### 2. 固有层

固有层（lamina propria）为疏松结缔组织，细胞成分较多，纤维较细密，有丰富的毛细血管和毛细淋巴管。胃肠固有层内富含腺体和淋巴组织。

:::definition{label="固有层"}
固有层（lamina propria）是黏膜中的疏松结缔组织。细胞成分较多，纤维较细密，有丰富的毛细血管和毛细淋巴管。胃肠固有层内富含腺体和淋巴组织。
:::

:::insight{label="吸收和免疫都先写在固有层里"}
上皮完成消化和屏障，物质要进身体，必须经过固有层里的毛细血管和毛细淋巴管；病原要就地拦住，也靠固有层里的淋巴组织和免疫细胞。把固有层听成“垫在上皮下面的填充物”，胃底腺、小肠腺和集合淋巴小结就没有组织学分母。
:::

### 3. 黏膜肌层

黏膜肌层（muscularis mucosa）为薄层平滑肌，其收缩可促进固有层内的腺体分泌物排出和血液运行，利于物质的吸收和转运。

:::definition{label="黏膜肌层"}
黏膜肌层（muscularis mucosa）是黏膜最外侧的薄层平滑肌。收缩可促进固有层内腺体分泌物排出和血液运行，利于物质的吸收和转运。
:::

:::pitfall{label="黏膜肌层不是肌层，薄薄一层平滑肌就把黏膜从黏膜下层切开"}
切片上紧贴腺体下方的那条薄平滑肌是黏膜肌层，属于黏膜。外面更厚的内环、外纵才是肌层。把黏膜肌层算进肌层，皱襞（黏膜 + 黏膜下层一起突向管腔）会少算一层，食管腺和十二指肠腺的位置账也会写到错误的结缔组织里。
:::

:::compare{title="黏膜的三层"}
| 层次（内→外） | 英文 | 组织 | 要点 |
|----------------|------|------|------|
| 上皮 | epithelium | 两端复层扁平，余单层柱状 | 与腺体相连续；可有上皮内淋巴细胞 |
| 固有层 | lamina propria | 疏松结缔组织 | 毛细血管和毛细淋巴管丰富；胃肠含腺体和淋巴组织 |
| 黏膜肌层 | muscularis mucosa | 薄层平滑肌 | 促腺体排空和血液运行，利于吸收转运 |
:::

## （二）黏膜下层

黏膜下层（submucosa）为较致密的结缔组织，含小动脉、小静脉与淋巴管。在食管及十二指肠的黏膜下层内分别有食管腺和十二指肠腺。黏膜下层中还有黏膜下神经丛，由多极神经元与无髓神经纤维构成，可调节黏膜肌的收缩和腺体分泌。在食管、胃、小肠和大肠中，黏膜与黏膜下层共同向管腔面突起，形成皱襞（plica），具有扩大黏膜表面积的作用。

:::definition{label="黏膜下层"}
黏膜下层（submucosa）为较致密的结缔组织，含小动脉、小静脉与淋巴管。食管的黏膜下层有食管腺，十二指肠的黏膜下层有十二指肠腺。
:::

:::definition{label="黏膜下神经丛"}
黏膜下神经丛位于黏膜下层，由多极神经元与无髓神经纤维构成，调节黏膜肌的收缩和腺体分泌。
:::

:::definition{label="皱襞"}
皱襞（plica）是食管、胃、小肠和大肠中黏膜与黏膜下层共同向管腔面突起形成的结构，用以扩大黏膜表面积。食物通过或胃充盈时皱襞可展平、消失。
:::

:::concept{term="先问腺体在固有层还是黏膜下层"}
胃肠的胃底腺、肠腺长在固有层，开口于胃小凹或肠腔。食管腺和十二指肠腺长在黏膜下层，导管要穿过黏膜才开口。把所有“管壁里的腺”都写进固有层，十二指肠抗酸那一层黏液会找不到组织学分母。
:::

:::note{label="黏膜下层里要同时看见的三件事"}
| 内容 | 落点 |
|------|------|
| 血管淋巴管 | 小动脉、小静脉与淋巴管，是黏膜血供和回流的主干道 |
| 两处黏膜下腺 | 食管腺（黏液性）、十二指肠腺（后文小肠） |
| 黏膜下神经丛 | 多极神经元 + 无髓纤维，管黏膜肌和腺体分泌 |
:::

## （三）肌层

除食管上段与肛门处的肌层（muscularis）为骨骼肌外，其余大部分为平滑肌。肌层一般分为内环行、外纵行两层，胃的肌层较厚，分为内斜、中环和外纵 3 层。肌层间有肌间神经丛，结构与黏膜下神经丛相似，调节肌层的运动。在肌间的结缔组织中有间质卡哈尔细胞（interstitial Cajal cell），呈多突起状，核为椭圆形，细胞质较少，含较多线粒体，在 HE 染色的标本中不易辨认。间质卡哈尔细胞可产生电信号，通过缝隙连接传递给平滑肌细胞，引起肌层自发缓慢的节律性收缩（图 14-2，图 14-3）。

:::definition{label="肌层"}
肌层（muscularis）除食管上段与肛门处为骨骼肌外，其余大部分为平滑肌。一般分内环行、外纵行两层；胃较厚，分为内斜、中环和外纵 3 层。
:::

:::definition{label="肌间神经丛"}
肌间神经丛位于肌层之间，结构与黏膜下神经丛相似（多极神经元 + 无髓神经纤维），调节肌层的运动。
:::

:::definition{label="间质卡哈尔细胞"}
间质卡哈尔细胞（interstitial Cajal cell）位于肌间结缔组织中，呈多突起状，核椭圆形，胞质较少，含较多线粒体。HE 标本中不易辨认。可产生电信号，经缝隙连接传给平滑肌细胞，引起肌层自发缓慢的节律性收缩。
:::

:::concept{term="先问谁在起搏：卡哈尔细胞，还是神经丛在下命令"}
蠕动不是平滑肌自己“随便缩”。卡哈尔细胞起搏，缝隙连接把电信号传给平滑肌，形成自发缓慢的节律；肌间神经丛再调节这层运动的力度和方向，黏膜下神经丛管黏膜肌和腺体。把卡哈尔细胞听成“另一种神经元”，HE 里看不见它、波形蛋白免疫组化才显形那一本账会做丢。
:::

:::compare{title="黏膜下神经丛与肌间神经丛"}
| 项目 | 黏膜下神经丛 | 肌间神经丛 |
|------|--------------|------------|
| 位置 | 黏膜下层 | 肌层之间 |
| 组成 | 多极神经元 + 无髓神经纤维 | 同左 |
| 主要调节 | 黏膜肌收缩、腺体分泌 | 肌层运动 |
| 光镜 | 黏膜下层结缔组织中的神经元胞体 | 内环与外纵之间的神经元胞体（图 14-2，↑） |
:::

:::pitfall{label="食管上段和肛门的肌层是骨骼肌，不要写成全程平滑肌"}
四层通例里，肌层“大部分是平滑肌”有两处例外：食管上段和肛门。食管还要再记一本过渡账：上 $1/3$ 骨骼肌、中 $1/3$ 兼有、下 $1/3$ 平滑肌。把肌层一律写成平滑肌，吞咽起始的随意成分和肛门控便会没有结构落点。
:::

:::compare{title="各段肌层的层次与组织"}
| 部位 | 层次 | 组织 |
|------|------|------|
| 一般消化管 | 内环行、外纵行 2 层 | 平滑肌 |
| 胃 | 内斜、中环、外纵 3 层 | 平滑肌；贲门和幽门环行肌增厚成括约肌 |
| 食管上段、肛门 | 同一般分层 | 骨骼肌 |
| 食管中 $1/3$ | 内环、外纵 | 骨骼肌与平滑肌兼具 |
:::

## （四）外膜

消化管壁的最外层为外膜（adventitia），按其组成的不同可分为浆膜与纤维膜。消化管上段（咽和食管）及下段（直肠）的外膜由疏松结缔组织组成，称纤维膜（fibrosa），与周围的组织相连；消化管中段，包括胃和大部分肠的最外层，除薄层结缔组织外，还有间皮覆盖，称浆膜，可保持胃肠外表面光滑，减少摩擦，有利于胃肠蠕动。

:::definition{label="外膜"}
外膜（adventitia）是消化管壁最外层，按组成分为浆膜与纤维膜。
:::

:::definition{label="纤维膜"}
纤维膜（fibrosa）由疏松结缔组织组成，无间皮，与周围组织相连。见于消化管上段（咽和食管）及下段（直肠）。
:::

:::definition{label="浆膜"}
浆膜是薄层结缔组织表面覆以间皮的外膜。见于消化管中段，包括胃和大部分肠。可保持外表面光滑、减少摩擦，有利于胃肠蠕动。
:::

:::compare{title="纤维膜与浆膜"}
| 项目 | 纤维膜（fibrosa） | 浆膜 |
|------|-------------------|------|
| 组成 | 疏松结缔组织，无间皮 | 薄层结缔组织 + 间皮 |
| 部位 | 咽、食管；直肠 | 胃和大部分肠 |
| 与周围关系 | 与周围组织相连 | 游离面光滑 |
| 功能含义 | 把管道固定在颈部、后纵隔或盆腔 | 减少摩擦，利于蠕动 |
:::

:::pitfall{label="食管外膜是纤维膜，不要因为“消化管中段有浆膜”就把食管也写成浆膜"}
浆膜账写在胃和大部分肠。咽和食管在纵隔里需要被结缔组织拴住，直肠下段同样，所以是纤维膜。胸膜腔里的“光滑外膜”不是食管的组织学外膜。
:::

:::insight{label="四层是通例，功能改写层次而不是另造一套管壁"}
皱襞是黏膜加黏膜下层一起抬高；小肠绒毛只抬上皮和固有层；胃底腺、小肠腺埋在固有层；食管腺、十二指肠腺埋在黏膜下层。四层尺子不换，各段只改上皮类型、腺体位置、肌层组织（骨骼肌/平滑肌）和外膜（纤维膜/浆膜）。
:::

:::keypoint{label="消化管壁先立四层，再记两端上皮和两丛神经"}
- 消化系统 = 消化管 + 消化腺。消化管：口腔 → 咽 → 食管 → 胃 → 小肠 → 大肠。
- 除口腔与咽外，管壁自内向外：黏膜、黏膜下层、肌层、外膜。
- 黏膜 = 上皮 + 固有层 + 黏膜肌层，是差异最大、功能最重要的一层。
- 两端（口腔、咽、食管、肛门）复层扁平以上皮保护为主；余单层柱状以消化吸收为主。
- 黏膜下层为较致密结缔组织，含血管淋巴管、黏膜下神经丛；食管腺和十二指肠腺在此层。
- 皱襞 = 黏膜 + 黏膜下层共同突向管腔。
- 肌层一般内环外纵；胃为内斜、中环、外纵；食管上段与肛门为骨骼肌。
- 肌间神经丛调节肌层运动；间质卡哈尔细胞起搏，经缝隙连接引起自发缓慢节律性收缩。
- 咽、食管、直肠为纤维膜；胃和大部分肠为浆膜。

:::memory{label="本节必背要点"}
- [ ] 消化系统（digestive system）由消化管和消化腺组成。
- [ ] 消化管从口腔至肛门，依次为口腔、咽、食管、胃、小肠和大肠。
- [ ] 消化管对食物进行物理性和化学性消化，将大分子分解为氨基酸、单糖、脂肪酸等，吸收营养并排泄残渣。
- [ ] 黏膜是重要屏障，富含淋巴组织和免疫细胞；上皮内含多种内分泌细胞。
- [ ] 除口腔与咽外，管壁自内向外分为黏膜、黏膜下层、肌层与外膜 4 层。
- [ ] 黏膜（mucosa）由上皮、固有层和黏膜肌层组成，是各段结构差异最大、功能最重要的部分。
- [ ] 消化管两端（口腔、咽、食管及肛门）为复层扁平上皮，以保护为主；余为单层柱状上皮，以消化吸收为主。
- [ ] 上皮与管壁内腺体相连续；上皮细胞间有散在淋巴细胞，小肠上皮中尤多见。
- [ ] 固有层（lamina propria）为疏松结缔组织，细胞较多、纤维较细密，富含毛细血管和毛细淋巴管；胃肠固有层富含腺体和淋巴组织。
- [ ] 黏膜肌层（muscularis mucosa）为薄层平滑肌，收缩促进固有层腺体分泌物排出和血液运行，利于吸收和转运。
- [ ] 黏膜下层（submucosa）为较致密结缔组织，含小动脉、小静脉与淋巴管。
- [ ] 食管黏膜下层有食管腺，十二指肠黏膜下层有十二指肠腺。
- [ ] 黏膜下神经丛由多极神经元与无髓神经纤维构成，调节黏膜肌收缩和腺体分泌。
- [ ] 食管、胃、小肠和大肠中，黏膜与黏膜下层共同向管腔突起形成皱襞（plica），扩大黏膜表面积。
- [ ] 除食管上段与肛门处肌层（muscularis）为骨骼肌外，其余大部分为平滑肌。
- [ ] 肌层一般分内环行、外纵行两层；胃的肌层较厚，分内斜、中环和外纵 3 层。
- [ ] 肌层间有肌间神经丛，结构与黏膜下神经丛相似，调节肌层运动。
- [ ] 间质卡哈尔细胞（interstitial Cajal cell）呈多突起状，核椭圆，胞质少、线粒体较多，HE 不易辨认。
- [ ] 间质卡哈尔细胞产生电信号，经缝隙连接传给平滑肌，引起肌层自发缓慢的节律性收缩。
- [ ] 外膜（adventitia）分为浆膜与纤维膜。
- [ ] 纤维膜（fibrosa）由疏松结缔组织组成，见于咽、食管及直肠，与周围组织相连。
- [ ] 浆膜为薄层结缔组织加间皮，见于胃和大部分肠，保持外表面光滑、减少摩擦，利于蠕动。
:::
