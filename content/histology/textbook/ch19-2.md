# 二、输卵管

输卵管是受精的场所，并输送生殖细胞。卵从卵巢排出后并不在卵巢内受精，而是被输卵管漏斗部接住，多在壶腹部受精，再向子宫运送。管壁由黏膜、肌层和浆膜组成。黏膜向管腔形成许多纵行且分支的皱襞，壶腹部较多，横切面上管腔极不规则（图 19-8）。

:::definition{label="输卵管"}
输卵管是连接卵巢与子宫的肌性管道。职分是接卵、提供受精场所并输送卵子与受精卵。本身不产生卵子，也不形成月经。
:::

:::concept{term="先问这根管子还在造卵吗，再认壶腹皱襞和峡部肌层"}
离开卵巢以后，上皮里不再有卵泡。先看黏膜皱襞多不多、管腔规不规则：皱襞多、横切管腔极不规则，是壶腹部；皱襞渐少、肌层最厚，是峡部。再问上皮两种细胞：有纤毛的把卵推向子宫，无纤毛而有微绒毛的分泌输卵管液。把输卵管听成“另一段会排卵的卵巢”，放射冠和黄体都会被搬错地方。
:::

:::compare{title="卵巢与输卵管"}
| 项目 | 卵巢 | 输卵管 |
|------|------|--------|
| 职分 | 产生卵子；分泌性激素 | 受精场所；输送生殖细胞 |
| 上皮 | 表面单层扁平或立方；实质内为卵泡 | 黏膜单层柱状（纤毛细胞 + 分泌细胞） |
| 腔面特征 | 无管腔，皮质含卵泡 | 纵行分支皱襞，壶腹横切管腔极不规则 |
| 肌层 | 卵巢门处少量平滑肌 | 内环、外纵两层，峡部最厚 |
| 外膜 | 白膜为致密结缔组织 | 浆膜：疏松结缔组织 + 间皮 |
:::

黏膜由单层柱状上皮和固有层构成，上皮主要由纤毛细胞和分泌细胞组成。纤毛细胞在漏斗和壶腹部最多，峡部和子宫部渐少；纤毛向子宫方向摆动，有助于卵子的运送和防止细菌侵入。夹在纤毛细胞之间的分泌细胞游离面无纤毛，但有微绒毛，其分泌物构成输卵管液，含氨基酸、葡萄糖、果糖及少量乳酸等，可营养和辅助运送卵子与受精卵。输卵管黏膜上皮也随月经周期而有相应的周期性变化。固有层为薄层结缔组织，内含较多血管和少量平滑肌。

:::definition{label="输卵管黏膜"}
黏膜由单层柱状上皮和固有层构成，向管腔形成许多纵行且分支的皱襞。壶腹部皱襞最多，故横切面管腔极不规则。
:::

:::definition{label="纤毛细胞"}
纤毛细胞是黏膜上皮的主要细胞之一。漏斗和壶腹部最多，峡部和子宫部渐少。纤毛向子宫方向摆动，运送卵子并防止细菌侵入。
:::

:::definition{label="分泌细胞"}
分泌细胞夹在纤毛细胞之间，游离面无纤毛、有微绒毛。分泌物构成输卵管液，含氨基酸、葡萄糖、果糖及少量乳酸等，营养并辅助运送卵子与受精卵。
:::

:::definition{label="输卵管液"}
输卵管液由分泌细胞产生，含氨基酸、葡萄糖、果糖及少量乳酸等。它不是卵泡液，也不来自子宫腺。
:::

:::definition{label="固有层"}
固有层为薄层结缔组织，内含较多血管和少量平滑肌。没有子宫腺那种单管或分支管状腺。
:::

::figure{src="/images/histology/textbook/p0215_01.png" caption="图19-8 输卵管壶腹部光镜图。示黏膜纵行分支皱襞、肌层与浆膜；左下高倍示单层柱状上皮。" alt="输卵管壶腹横切：管腔因黏膜皱襞极不规则，外周为肌层和浆膜，插图显示柱状上皮"}

输卵管肌层为内环、外纵两层平滑肌，各段肌层厚薄不均，峡部肌层最厚。浆膜由富含血管的疏松结缔组织和间皮构成。

:::definition{label="输卵管肌层"}
肌层为内环、外纵两层平滑肌。各段厚薄不均，峡部肌层最厚。收缩配合纤毛摆动，把卵子和受精卵推向子宫。
:::

:::definition{label="输卵管浆膜"}
浆膜由富含血管的疏松结缔组织和间皮构成。输卵管全程有浆膜，不是纤维膜。
:::

:::compare{title="纤毛细胞与分泌细胞"}
| 项目 | 纤毛细胞 | 分泌细胞 |
|------|----------|----------|
| 游离面 | 有纤毛 | 无纤毛，有微绒毛 |
| 分布 | 漏斗、壶腹部最多；峡部、子宫部渐少 | 夹在纤毛细胞之间 |
| 职分 | 纤毛向子宫方向摆动，运送卵子、防止细菌侵入 | 分泌输卵管液，营养并辅助运送卵子与受精卵 |
| 液体 | 不产液 | 氨基酸、葡萄糖、果糖、少量乳酸 |
:::

:::compare{title="壶腹部与峡部"}
| 项目 | 壶腹部 | 峡部 |
|------|--------|------|
| 皱襞 | 最多，横切管腔极不规则 | 较少 |
| 纤毛细胞 | 多 | 渐少 |
| 肌层 | 相对较薄 | 最厚 |
| 职分侧重 | 受精的常见场所；接卵后运行 | 向子宫推进，管腔较细 |
:::

:::note{label="黏膜上皮随月经周期变化"}
输卵管黏膜上皮也随月经周期出现相应变化，与卵巢激素同步，但管壁不发生月经那样的剥脱出血。周期性变化写在上皮功能状态上，户头不要搬到子宫功能层。
:::

:::pitfall{label="壶腹横切管腔极不规则是皱襞造成的，不要写成病理扩张或多房囊腔"}
黏膜纵行且分支的皱襞把壶腹腔面折成许多裂隙，横切看起来“好几个腔”。那是正常结构，是受精和接卵需要的面积，不是腺体，也不是卵巢卵泡腔。
:::

:::pitfall{label="纤毛向子宫方向摆动，不要写成扫向卵巢"}
运送方向是漏斗 → 壶腹 → 峡部 → 子宫。纤毛朝子宫摆，才能把卵送走并挡住上行细菌。写成“纤毛把精子扫向卵巢”，受精地点和防御账会一起反转。
:::

:::insight{label="皱襞加大面积，纤毛负责推，分泌细胞负责养"}
壶腹皱襞多、纤毛细胞多，适合接卵和受精；峡部肌层最厚，适合把受精卵推入子宫。两种上皮细胞分工明确：能动的不分泌，分泌的没有纤毛。把输卵管上皮听成“全是纤毛柱状”，葡萄糖和果糖那本营养账会从管腔里消失。
:::

:::keypoint{label="输卵管三层壁，皱襞加纤毛把受精和运送收口"}
- 管壁：黏膜、肌层、浆膜。
- 黏膜纵行分支皱襞，壶腹最多，横切管腔极不规则。
- 上皮单层柱状：纤毛细胞（向子宫摆动）+ 分泌细胞（微绒毛，产输卵管液）。
- 纤毛细胞漏斗、壶腹最多，峡部和子宫部渐少。
- 肌层内环外纵，峡部最厚；浆膜为疏松结缔组织 + 间皮。
- 黏膜上皮随月经周期变化，但不剥脱形成月经。
:::
