# 一、原始心血管系统的建立

人胚早期靠物质弥散获取营养。第 $3$ 周形成原始心血管系统，约第 $3$ 周末开始血液循环，心脏于第 $4$ 周末开始节律性跳动，成为体内形成最早、执行功能最早的系统。本节先把左右对称的心管和原始动静脉立住，再按胚外血岛、胚内间充质裂隙和三套循环摊开。早期管子还分不出动脉、静脉，名字按将来的归属来叫。

人胚早期以物质弥散的方式获取营养，由于胚体的快速生长，于第 $3$ 周形成原始心血管系统，约在第 $3$ 周末开始血液循环，心脏于第 $4$ 周末开始节律性跳动，形成定向的功能性血液循环，成为机体内形成最早、执行功能最早的系统，使胚胎能有效地获得养料和排出废物，以适应胚胎迅速发育。

:::definition{label="原始心血管系统"}
原始心血管系统（primitive cardiovascular system）左右对称，由心管、原始动脉系统和原始静脉系统组成。它在第 $3$ 周建立，第 $3$ 周末开始循环，第 $4$ 周末心脏开始节律性跳动。这是体内形成最早、执行功能最早的系统。
:::

:::definition{label="管壁先内皮、后间充质"}
心血管的管壁构造最初为内皮性管道。之后其周围的间充质分化出肌组织和结缔组织，参加管壁的形成，从而演变成心脏、动脉和静脉。先有管子，后有中膜、外膜和心肌，不要写成“一开始就是成体三层壁”。
:::

:::timeline{period="原始心血管系统开始工作"}
- **第3周** 形成原始心血管系统
- **第3周末** 开始血液循环
- **第4周末** 心脏开始节律性跳动，形成定向的功能性血液循环
- **意义** 体内形成最早、执行功能最早的系统，使胚胎能有效获得养料、排出废物
:::

:::insight{label="先有管子再有跳动，营养才从弥散换成循环"}
扁平胚盘还能靠弥散过日子；胚体一快长，弥散就不够。第 $3$ 周把管子搭起来，第 $3$ 周末血开始流，第 $4$ 周末心开始跳，定向循环才成立。只背“心血管很早”，会把“形成”和“执行功能”两本时钟并成一句。
:::

原始心血管系统（primitive cardiovascular system）左右对称，由心管、原始动脉系统和原始静脉系统组成。心血管的管壁构造最初为内皮性管道，之后其周围的间充质分化出肌组织和结缔组织，参加管壁的形成，从而演变成心脏、动脉和静脉。

:::concept{term="先问这是胚外血岛还是胚内裂隙，再问三套循环走的是卵黄囊、绒毛膜还是胚体本身"}
看见原始心血管，先分地点：卵黄囊、体蒂、绒毛膜上成团的是血岛，走胚外血管；胚体内间充质裂隙变扁成内皮，走胚内血管。第 $3$ 周二者经体蒂相通，造血干细胞才进胚体。再问循环户头：卵黄囊毛细血管 ↔ 卵黄动静脉是卵黄囊循环；绒毛膜毛细血管 ↔ 脐动静脉是脐循环；背主动脉分支去胚体、前主静脉和后主静脉经总主静脉回心是胚体循环。把血岛听成“已经在胚体内造血”，或把脐循环听成卵黄囊循环，三套通路会对错户头。
:::

## 1. 胚外血管的发生

人胚第 $3$ 周，卵黄囊壁的胚外中胚层细胞密集成索状或团状，称血岛，继而体蒂和绒毛膜等处的胚外中胚层细胞也形成血岛。不久血岛内出现间隙，其周边的细胞分化为扁平的内皮细胞，中央的细胞分化成游离的造血干细胞（图 25-1）。管道不断向外出芽延伸，使相邻血岛形成的内皮管道互相融合通连，逐渐形成胚外毛细血管网。

:::definition{label="血岛"}
血岛是人胚第 $3$ 周卵黄囊壁胚外中胚层细胞密集成索状或团状形成的结构。体蒂和绒毛膜等处的胚外中胚层随后也形成血岛。血岛不是已经分好的动脉或静脉，只是内皮管加造血干细胞的原基。
:::

:::definition{label="血岛周边与中央"}
血岛内出现间隙后，周边的细胞分化为扁平的内皮细胞，中央的细胞分化成游离的造血干细胞。周边围成管子，中央才是造血，两份不要并成“血岛里全是血细胞”。
:::

:::definition{label="胚外毛细血管网"}
相邻血岛形成的内皮管道不断向外出芽延伸、互相融合通连，逐渐形成胚外毛细血管网。出芽连接发生在卵黄囊、体蒂和绒毛膜这一侧。
:::

::figure{src="/images/histology/textbook/p0270_02.png" caption="图25-1 血岛和血管形成。左上：胚外中胚层细胞；左下：开始分化的血岛；中：胚体头端已见心管与围心腔，体蒂连绒毛膜，尿囊伸入；右：血岛周边分化为内皮细胞，中央为原始血细胞（造血干细胞）。" alt="中为胚体侧面：头端心管与围心腔，右侧绿色绒毛膜含血岛；左右为血岛细胞图，周边扁平内皮、中央圆核血细胞"}

:::cause-effect{title="血岛出芽，才连成胚外毛细血管网"}
- 因：卵黄囊、体蒂、绒毛膜的胚外中胚层密集成血岛，岛内出现间隙
- 果：周边成内皮，中央成造血干细胞
- 因：内皮管道向外出芽、相邻血岛融合通连
- 果：胚外毛细血管网形成
- 制约：此时还没有中膜、外膜，不能按管壁结构叫动脉或静脉
:::

:::pitfall{label="血岛先在卵黄囊，体蒂和绒毛膜随后也有，不要写成只发生在胚体内"}
教材写明：先是卵黄囊壁，继而体蒂和绒毛膜。造血干细胞的第一批地点在胚外。写成“第 $3$ 周胚内间充质直接造血”，胚外血管网和经体蒂入胚这两步会消失。
:::

## 2. 胚内血管的发生

人胚第 $18\sim 20$ 天，胚体内各处间充质出现许多裂隙，裂隙周围的间充质细胞变扁，分化为内皮细胞，形成胚内毛细血管，相邻血管内皮以出芽方式连接，形成胚内原始血管网。

第 $3$ 周，胚体内和胚体外的毛细血管网经过体蒂相通，造血干细胞进入胚体内，形成了人胚的早期原始血管通路。

此时的血管在结构上尚无法区分动脉和静脉，根据它们将来的归属以及与心脏发生的关系进行命名。之后内皮管周围的间充质细胞密集，分化为平滑肌纤维和结缔组织，形成中膜和外膜，演化出动脉和静脉的组织结构。

:::definition{label="胚内原始血管网"}
人胚第 $18\sim 20$ 天，胚体内各处间充质出现许多裂隙，裂隙周围的间充质细胞变扁，分化为内皮细胞，形成胚内毛细血管。相邻血管内皮以出芽方式连接，形成胚内原始血管网。起点是间充质裂隙，不是血岛。
:::

:::definition{label="体蒂把胚内、胚外接通"}
第 $3$ 周，胚体内和胚体外的毛细血管网经过体蒂相通，造血干细胞进入胚体内，形成人胚的早期原始血管通路。体蒂是通道，不是第三套独立的血岛系统。
:::

:::definition{label="按将来归属命名"}
此时血管在结构上尚无法区分动脉和静脉。名字根据它们将来的归属以及与心脏发生的关系来叫：将来出心、走动脉干一侧的叫腹主动脉、背主动脉、弓动脉、卵黄动脉、脐动脉；将来回心的叫卵黄静脉、脐静脉、前主静脉、后主静脉、总主静脉。之后内皮管周围的间充质密集，分化为平滑肌纤维和结缔组织，形成中膜和外膜，才演化出动脉和静脉的组织结构。
:::

:::compare{title="胚外血管与胚内血管"}
| 项目 | 胚外血管 | 胚内血管 |
|------|----------|----------|
| 时间 | 第 $3$ 周 | 第 $18\sim 20$ 天出现裂隙，第 $3$ 周与胚外相通 |
| 地点 | 卵黄囊壁，继而体蒂、绒毛膜 | 胚体内各处间充质 |
| 起点形态 | 胚外中胚层密集成血岛（索状或团状） | 间充质出现裂隙 |
| 内皮来源 | 血岛周边细胞变扁 | 裂隙周围间充质细胞变扁 |
| 中央细胞 | 游离的造血干细胞 | 裂隙本身是管腔，造血干细胞后来经体蒂进入 |
| 连接方式 | 出芽延伸，相邻血岛内皮管融合通连 | 相邻血管内皮出芽连接 |
| 产物 | 胚外毛细血管网 | 胚内毛细血管 → 胚内原始血管网 |
| 相通 | 第 $3$ 周经体蒂与胚内相通 | 第 $3$ 周经体蒂与胚外相通 |
:::

:::example{label="还不能分动静脉时，名字按将来户头叫"}
第 $3$ 周末那几根管子，光看管壁分不出动脉、静脉。教材按将来去向命名：连心管头端的叫腹主动脉；沿胚体背侧走的叫背主动脉；同侧腹、背主动脉之间的叫第一对弓动脉；进卵黄囊壁的叫卵黄动脉；经体蒂进绒毛膜的叫脐动脉。静脉端同理：卵黄囊毛细血管汇合成卵黄静脉，绒毛膜毛细血管汇合成脐静脉，胚体前、后部分别形成前主静脉、后主静脉，再汇入总主静脉。名字是“将来户头”，不是此刻已经能用中膜、外膜认出来。
:::

:::pitfall{label="早期不能按管壁叫动脉或静脉，不要把命名当成已经分化"}
“卵黄动脉”“脐静脉”这些词，是按将来归属和与心脏的关系起的。中膜、外膜要等内皮管周围间充质密集之后才有。写成“第 $3$ 周末已经能从切片上分出动、静脉”，后面的管壁分化就没有地方可放。
:::

:::note{label="造血干细胞从胚外进胚内"}
血岛中央先分化出造血干细胞；要等胚内、胚外毛细血管网经体蒂相通，这些细胞才进入胚体。胚内间充质裂隙造的是管子，不是第一批造血干细胞的产地。
:::

## 3. 胚体早期血液循环

第 $3$ 周末，已有一对心管、一对连接心管头端的腹主动脉、一对背主动脉，以及连接同侧腹主动脉和背主动脉的第一对弓动脉。背主动脉在卵黄囊壁分出若干对卵黄动脉，经过体蒂在绒毛膜分出一对脐动脉；卵黄囊毛细血管汇合成一对卵黄静脉，绒毛膜中毛细血管汇合成一对脐静脉；卵黄静脉和脐静脉分别运送血液回心管的静脉端，从而形成卵黄囊循环和脐循环。

心管合二为一时，两条腹主动脉融合为主动脉囊。两条背主动脉合并，沿途的分支将血液输送至胚体各部。此时，胚体前部形成了一对前主静脉，后部形成了一对后主静脉，分别汇流至左、右总主静脉，再至心管的静脉端，形成胚体循环。

至此，胚内、外形成了胚体循环、卵黄囊循环和脐循环 $3$ 套通路（图 25-2）。

人胚早期心脏和血管是左、右对称的，随着血流动力学的变化以及体内各器官的发生，管道不断经过扩张、延长、合并、退化以及新生等过程，演变成为非对称的心血管布局。

:::definition{label="第3周末的左右对称套件"}
第 $3$ 周末已有：一对心管；一对连接心管头端的腹主动脉；一对背主动脉；连接同侧腹主动脉和背主动脉的第一对弓动脉。左右对称，还没有合成一条心管、一个主动脉囊。
:::

:::definition{label="卵黄动脉与脐动脉"}
背主动脉在卵黄囊壁分出若干对卵黄动脉；经过体蒂在绒毛膜分出一对脐动脉。动脉出心后分别进卵黄囊和绒毛膜，不要对调。
:::

:::definition{label="卵黄静脉与脐静脉"}
卵黄囊毛细血管汇合成一对卵黄静脉，绒毛膜中毛细血管汇合成一对脐静脉。二者分别运送血液回心管的静脉端。静脉回心，动脉出心，户头不要写反。
:::

:::definition{label="卵黄囊循环"}
卵黄囊循环由卵黄动脉（背主动脉在卵黄囊壁的若干对分支）和卵黄静脉（卵黄囊毛细血管汇合、回心管静脉端）构成。它服务卵黄囊，不是胎盘。
:::

:::definition{label="脐循环"}
脐循环由脐动脉（经体蒂在绒毛膜分出的一对）和脐静脉（绒毛膜毛细血管汇合、回心管静脉端）构成。它服务绒毛膜／胎盘侧，不是卵黄囊。
:::

:::definition{label="主动脉囊"}
心管合二为一时，两条腹主动脉融合为主动脉囊。主动脉囊是腹主动脉合并后的动脉端膨大，接以后的动脉干，不是背主动脉合并的产物。
:::

:::definition{label="背主动脉合并"}
两条背主动脉合并后，沿途的分支将血液输送至胚体各部。合并发生在心管合一之后，与腹主动脉融合成主动脉囊是两本账。
:::

:::definition{label="前主静脉、后主静脉与总主静脉"}
胚体前部形成一对前主静脉，后部形成一对后主静脉，分别汇流至左、右总主静脉，再至心管的静脉端。前主静脉收胚体前部，后主静脉收胚体后部，总主静脉是入心前的总汇，三根不要并成“一条主静脉”。
:::

:::definition{label="胚体循环"}
胚体循环：背主动脉合并后的分支把血送到胚体各部；前主静脉、后主静脉汇入左、右总主静脉，再回心管静脉端。它服务胚体本身，与卵黄囊循环、脐循环并列，合称 $3$ 套通路。
:::

:::compare{title="卵黄囊循环、脐循环与胚体循环"}
| 项目 | 卵黄囊循环 | 脐循环 | 胚体循环 |
|------|------------|--------|----------|
| 动脉去向 | 背主动脉在卵黄囊壁分出若干对卵黄动脉 | 经体蒂在绒毛膜分出一对脐动脉 | 背主动脉合并后，沿途分支至胚体各部 |
| 静脉回流 | 卵黄囊毛细血管 → 一对卵黄静脉 → 心管静脉端 | 绒毛膜毛细血管 → 一对脐静脉 → 心管静脉端 | 前主静脉（胚体前部）、后主静脉（胚体后部）→ 左、右总主静脉 → 心管静脉端 |

:::

:::compare{title="心管合一前后的动脉端"}
| 项目 | 合一前（第 $3$ 周末，左右对称） | 合一后 |
|------|----------------------------------|--------|
| 心管 | 一对 | 一条 |
| 腹主动脉 | 一对，连心管头端 | 融合为主动脉囊 |
| 背主动脉 | 一对 | 合并，沿途分支至胚体各部 |
| 第一对弓动脉 | 连接同侧腹主动脉与背主动脉 | 仍连动脉囊与背主动脉系统 |
| 静脉端 | 卵黄静脉、脐静脉回心管静脉端 | 另加前主静脉、后主静脉 → 总主静脉 → 心管静脉端 |
:::

:::pitfall{label="腹主动脉融合成主动脉囊，背主动脉是自己合并，不要写成四条大动脉并成一根"}
腹主动脉在心管头端，合一后变主动脉囊；背主动脉在胚体背侧，合并后才向胚体各部分支。写成“腹、背主动脉一起融成一条”，弓动脉插在哪一侧会对不上图 25-2。
:::

:::pitfall{label="脐动脉出绒毛膜，脐静脉回心，不要和卵黄动静脉对调"}
脐动脉：背主动脉经体蒂在绒毛膜分出。脐静脉：绒毛膜毛细血管汇合回心。卵黄动脉进卵黄囊壁，卵黄静脉从卵黄囊回心。把脐静脉写成“从卵黄囊回来”，脐循环和卵黄囊循环会并成一套。
:::

:::insight{label="三套通路共用一对心管，差别在外周走到哪"}
动脉端都从心管 → 腹主动脉／主动脉囊 → 弓动脉 → 背主动脉出去；静脉端都回到心管静脉端。分叉发生在外周：卵黄囊、绒毛膜、胚体各走各的毛细血管网。只背“有三套循环”，说不清共用的心管和分开的外周，图 25-2 上的红蓝管子会对错。
:::

:::note{label="左右对称只是起点，后面要扩张、延长、合并、退化、新生"}
人胚早期心脏和血管左右对称。随着血流动力学变化和体内各器官发生，管道不断经过扩张、延长、合并、退化以及新生，才变成非对称的成体布局。本节停在对称的三套通路；心管合一、袢曲和内部分隔是下一节的账。
:::

:::tip{label="三套循环口诀"}
卵黄囊走卵黄动静脉，绒毛膜走脐动静脉，胚体本身走背主动脉加前、后、总主静脉。三套都回心管静脉端，名字按将来户头叫。
:::

:::keypoint{label="第3周搭管子，第3周末开循环，第4周末心跳，三套通路共用一对心管"}
- 体内形成最早、执行功能最早的系统：第 $3$ 周原始心血管，第 $3$ 周末循环，第 $4$ 周末节律性跳动。
- 左右对称：心管 + 原始动脉系统 + 原始静脉系统；先内皮管，周围间充质再成肌和结缔组织。
- 胚外：卵黄囊、体蒂、绒毛膜血岛 → 周边内皮、中央造血干细胞 → 出芽连成胚外毛细血管网。
- 胚内：第 $18\sim 20$ 天间充质裂隙成内皮管；第 $3$ 周经体蒂与胚外相通，造血干细胞入胚体。
- 早期不能分动静脉，按将来归属命名；随后间充质成中膜、外膜。
- 第 $3$ 周末：一对心管、腹主动脉、背主动脉、第一对弓动脉；卵黄动脉／脐动脉；卵黄静脉／脐静脉。
- 心管合一：腹主动脉 → 主动脉囊；背主动脉合并。前主静脉、后主静脉汇入总主静脉，成胚体循环。
- 三套通路：胚体循环、卵黄囊循环、脐循环。随后才由对称变为非对称。
:::

:::memory{label="本节必背要点"}
- [ ] 人胚早期以物质弥散的方式获取营养。
- [ ] 第 $3$ 周形成原始心血管系统。
- [ ] 约第 $3$ 周末开始血液循环。
- [ ] 心脏于第 $4$ 周末开始节律性跳动，形成定向的功能性血液循环。
- [ ] 心血管系统是体内形成最早、执行功能最早的系统，使胚胎能有效获得养料并排出废物。
- [ ] 原始心血管系统（primitive cardiovascular system）左右对称，由心管、原始动脉系统和原始静脉系统组成。
- [ ] 管壁最初为内皮性管道；周围间充质分化出肌组织和结缔组织，参加管壁形成，演变成心脏、动脉和静脉。
- [ ] 人胚第 $3$ 周，卵黄囊壁胚外中胚层细胞密集成索状或团状，称血岛。
- [ ] 体蒂和绒毛膜等处的胚外中胚层细胞随后也形成血岛。
- [ ] 血岛内出现间隙：周边细胞分化为扁平内皮细胞，中央细胞分化成游离的造血干细胞。
- [ ] 管道向外出芽延伸，相邻血岛内皮管融合通连，形成胚外毛细血管网。
- [ ] 人胚第 $18\sim 20$ 天，胚体内各处间充质出现许多裂隙。
- [ ] 裂隙周围间充质细胞变扁，分化为内皮细胞，形成胚内毛细血管。
- [ ] 相邻血管内皮以出芽方式连接，形成胚内原始血管网。
- [ ] 第 $3$ 周，胚内和胚外毛细血管网经体蒂相通，造血干细胞进入胚体，形成早期原始血管通路。
- [ ] 此时血管在结构上尚无法区分动脉和静脉，根据将来的归属以及与心脏发生的关系命名。
- [ ] 之后内皮管周围间充质密集，分化为平滑肌纤维和结缔组织，形成中膜和外膜，演化出动、静脉组织结构。
- [ ] 第 $3$ 周末已有一对心管、一对腹主动脉、一对背主动脉，以及连接同侧腹、背主动脉的第一对弓动脉。
- [ ] 背主动脉在卵黄囊壁分出若干对卵黄动脉。
- [ ] 背主动脉经过体蒂在绒毛膜分出一对脐动脉。
- [ ] 卵黄囊毛细血管汇合成一对卵黄静脉。
- [ ] 绒毛膜中毛细血管汇合成一对脐静脉。
- [ ] 卵黄静脉和脐静脉分别运送血液回心管的静脉端，形成卵黄囊循环和脐循环。
- [ ] 心管合二为一时，两条腹主动脉融合为主动脉囊。
- [ ] 两条背主动脉合并，沿途分支将血液输送至胚体各部。
- [ ] 胚体前部形成一对前主静脉，后部形成一对后主静脉。
- [ ] 前、后主静脉分别汇流至左、右总主静脉，再至心管静脉端，形成胚体循环。
- [ ] 胚内、外形成胚体循环、卵黄囊循环和脐循环 $3$ 套通路。
- [ ] 人胚早期心脏和血管左右对称；随后经扩张、延长、合并、退化及新生，演变为非对称的心血管布局。
:::
