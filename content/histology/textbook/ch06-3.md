# 三、平滑肌

平滑肌（smooth muscle）广泛分布于消化管、呼吸道、血管等中空性器官的管壁内。受自主神经支配，属不随意肌；肌质中无明暗相间的横纹，因而不属横纹肌。骨骼肌和心肌把粗、细肌丝装进肌原纤维和肌节；平滑肌把同一套滑行改写到密斑、密体和中间丝搭成的梭形骨架上——细胞内看不见肌原纤维，但粗、细肌丝都在。

:::definition{label="平滑肌"}
平滑肌（smooth muscle）广泛分布于消化管、呼吸道、血管等中空性器官的管壁内。无横纹，受自主神经支配，为不随意肌。
:::

:::concept{term="先问有没有肌原纤维：没有不等于没有肌丝"}
光镜下平滑肌没有横纹，电镜下也找不到界限清楚的肌原纤维和 Z 线。收缩机器并没有缺席：细肌丝挂在密斑或密体上，粗肌丝以约 $1:12$ 的数量比被细丝环绕，中间丝（结蛋白）把密斑、密体连成梭形骨架。把“无肌原纤维”听成“没有粗细肌丝”，会把平滑肌的收缩单位做丢。
:::

## （一）平滑肌纤维的光镜结构

平滑肌纤维呈长梭形，细胞中央有一个杆状或椭圆形的核，常呈扭曲状，细胞质嗜酸性，无横纹（图 6-13）。平滑肌纤维一般长 $200\,\mu\mathrm{m}$，直径 $8\,\mu\mathrm{m}$，但大小不均，如小血管壁上的平滑肌纤维短至 $20\,\mu\mathrm{m}$，妊娠末期的子宫平滑肌纤维可长达 $500\,\mu\mathrm{m}$。

:::definition{label="平滑肌纤维"}
平滑肌纤维呈长梭形，中央有一个杆状或椭圆形的核，常呈扭曲状；胞质嗜酸性，无横纹。一般长 $200\,\mu\mathrm{m}$，直径 $8\,\mu\mathrm{m}$。
:::

:::note{label="平滑肌大小因器官而异"}
一般记载是长 $200\,\mu\mathrm{m}$、直径 $8\,\mu\mathrm{m}$，但这不是固定尺码。小血管壁上的平滑肌纤维可短至 $20\,\mu\mathrm{m}$；妊娠末期子宫平滑肌纤维可长达 $500\,\mu\mathrm{m}$。看见梭形嗜酸性细胞，先问所在器官，再问核是否居中、扭曲，不要拿骨骼肌那 $10\sim 100\,\mu\mathrm{m}$ 的直径去套。
:::

:::pitfall{label="核扭曲是收缩态，不要当成固缩坏死"}
平滑肌细胞核常呈扭曲状，与细胞收缩时梭形胞体被螺旋骨架拧短有关（见图 6-18）。制片上一个弯折的杆状核，多半是功能状态，不是核固缩。横切面上，切到胞体中部者核圆而居中，切到两端者只见嗜酸性胞质、无核——这是梭形细胞斜切或端切的几何结果，不要当成无核细胞。
:::

## （二）平滑肌纤维的超微结构

平滑肌纤维表面常可见肌膜向细胞质凹陷形成小凹（caveola），沿细胞的长轴呈带状排列，相当于骨骼肌的横小管，可传递冲动（图 6-14）。平滑肌细胞内无肌原纤维，可见大量密斑（dense patch）、密体（dense body）、中间丝、细肌丝和粗肌丝。密斑和密体的电子密度较高：前者位于肌膜下，后者位于肌质中，为梭形小体。中间丝由结蛋白（desmin）构成，直径 $10\,\mathrm{nm}$，连接于密斑、密体之间，形成梭形的细胞骨架（图 6-15）。粗、细肌丝的数量比约为 $1:12$。细肌丝主要由肌动蛋白组成，一端附着于密斑或密体，另一端游离，环绕在粗肌丝周围。粗肌丝由肌球蛋白构成，呈圆柱状，表面有成行排列的横桥，相邻的两行横桥屈动方向相反（图 6-16，图 6-17）。若干条粗肌丝和细肌丝聚集形成肌丝单位，又称收缩单位。肌质内只有少量肌质网，肌纤维收缩时也需从细胞外摄取 $\mathrm{Ca}^{2+}$。平滑肌纤维之间有较发达的缝隙连接，可传递信息分子和电冲动，有利于众多平滑肌纤维同时收缩而形成功能整体。教材图 6-15 为平滑肌纤维透射电镜图（示小凹、密体和密斑），对应文件为空，本页不插入。

:::definition{label="小凹"}
小凹（caveola）是平滑肌肌膜向细胞质凹陷形成的结构，沿细胞长轴呈带状排列，相当于骨骼肌的横小管，可传递冲动。
:::

:::definition{label="密斑"}
密斑（dense patch）电子密度较高，位于肌膜下，是细肌丝以及中间丝构成的细胞骨架的附着点，呈螺旋状分布。
:::

:::definition{label="密体"}
密体（dense body）电子密度较高，位于肌质中，为梭形小体，供细肌丝和中间丝附着。
:::

:::definition{label="中间丝（平滑肌）"}
平滑肌的中间丝由结蛋白（desmin）构成，直径 $10\,\mathrm{nm}$，连接于密斑、密体之间，形成梭形的细胞骨架。
:::

:::definition{label="肌丝单位"}
肌丝单位又称收缩单位，由若干条粗肌丝和细肌丝聚集形成。细肌丝一端附于密斑或密体、另一端游离并环绕粗肌丝；粗、细肌丝数量比约为 $1:12$。
:::

:::concept{term="先问密斑密体：贴在膜下，还是浮在肌质里"}
电子密度高的斑块有两处：贴在肌膜下的叫密斑，相当于把 Z 线拆开钉在膜上；浮在肌质里的梭形小体叫密体。中间丝（desmin，$10\,\mathrm{nm}$）把二者连成梭形骨架，细肌丝也挂在这两类锚点上。看见“无 Z 线”，先问锚点改钉到哪里，不要以为细肌丝没有着落。
:::

:::compare{title="骨骼肌 T 管–终池与平滑肌小凹–密斑"}
| 项目 | 骨骼肌 | 平滑肌 |
|------|--------|--------|
| 膜内陷 | 横小管，位于 A–I 交界 | 小凹，沿长轴呈带状排列 |
| 传冲动 | T 管 → 三联体 → 肌质网 | 小凹传递冲动 |
| 钙库 | 肌质网发达，终池大，网内 $\mathrm{Ca}^{2+}$ 为肌质的上千倍 | 肌质网少量，收缩时需从细胞外摄取 $\mathrm{Ca}^{2+}$ |
| 细肌丝锚点 | Z 线 | 密斑（膜下）、密体（肌质内） |
| 骨架 | 肌原纤维 + 肌节整齐排列 | 中间丝（desmin）连接密斑与密体，梭形骨架 |
| 肌丝组织 | 肌原纤维，粗细丝 $1:6$ 的横截面邻居关系 | 无肌原纤维；粗细丝数量比约 $1:12$，组成收缩单位 |
:::

:::pitfall{label="平滑肌无肌原纤维，但仍有粗肌丝和细肌丝"}
“无肌原纤维”只说明粗、细肌丝没有被打包成一条条带横纹的肌原纤维，并不等于细胞内没有肌丝。粗肌丝是肌球蛋白圆柱，表面横桥成行、相邻两行屈动方向相反；细肌丝主要是肌动蛋白，一端钉在密斑或密体上。数量比约 $1:12$，比骨骼肌横切面上“1 粗围 6 细”更“细丝占优”。把平滑肌记成“没有收缩蛋白的梭形细胞”，和光镜下无横纹是两笔不同的账。
:::

:::note{label="缝隙连接把许多梭形细胞写成功能整体"}
平滑肌纤维之间有较发达的缝隙连接，可传递信息分子和电冲动，使众多平滑肌纤维同时收缩。这与心肌闰盘纵向部分的缝隙连接职分相似，但平滑肌没有闰盘那种阶梯状的黏着小带–桥粒机械复合体。中空性器官管壁要形成一圈协调的张力，靠的就是这张电偶联网。
:::

## （三）平滑肌纤维的收缩原理

平滑肌纤维的收缩也是以粗、细肌丝间的滑动为基础。由于细肌丝以及细胞骨架的附着点密斑呈螺旋状分布，且粗肌丝无 M 线，其中点两端的横桥向相反方向屈动，因此当平滑肌纤维收缩时，细肌丝沿着粗肌丝的全长滑动，而相邻细肌丝的滑动方向相反（见图 6-17），致使中间丝构成的细胞骨架和肌纤维呈螺旋状扭曲，长轴缩短（图 6-18）。

:::definition{label="平滑肌收缩原理"}
平滑肌收缩以粗、细肌丝滑动为基础。密斑螺旋状分布，粗肌丝无 M 线、中点两端横桥屈动方向相反，故细肌丝沿粗肌丝全长滑动、相邻细肌丝方向相反，细胞骨架和肌纤维螺旋状扭曲，长轴缩短。
:::

:::derivation{title="平滑肌怎样把滑行写成螺旋缩短"}
1. 冲动经小凹传入，肌质网及细胞外 $\mathrm{Ca}^{2+}$ 使肌质钙升高，启动横桥。
2. 粗肌丝无 M 线，表面横桥排成行，相邻两行屈动方向相反。
3. 细肌丝一端钉在螺旋分布的密斑或密体上，另一端环绕粗肌丝；滑动时沿粗肌丝全长进行，相邻细丝方向相反。
4. 中间丝（desmin）把密斑、密体连成的梭形骨架被反向牵拉，发生螺旋状扭曲。
5. 细胞长轴缩短，核常随之扭曲；舒张时骨架回弹，梭形轮廓恢复。
:::

:::cause-effect{title="为什么平滑肌缩短时会拧成螺旋"}
- 因：密斑在膜下呈螺旋状分布，细肌丝和骨架都挂在这些螺旋锚点上
- 因：粗肌丝无 M 线，中点两端横桥向相反方向屈动，相邻细肌丝滑动方向相反
- 果：细肌丝沿粗肌丝全长滑动，骨架被反向牵拉，细胞呈螺旋状扭曲、长轴缩短
- 制约：这与骨骼肌“细丝两侧对称地滑向 M 线、肌节对折缩短”不同，不要把图 6-8 套到图 6-18 上
:::

:::insight{label="无 M 线，细丝才能沿着粗丝走完全长"}
骨骼肌粗丝被 M 线钉在肌节正中，横桥朝向两端的 Z 线，细丝只能从两侧插到 H 带外侧为止。平滑肌粗丝不设 M 线，相邻两行横桥反向屈动，细丝可以沿粗丝全长滑动。滑动行程更长，缩短幅度可以很大——妊娠子宫平滑肌能拉到 $500\,\mu\mathrm{m}$，也要靠这套“走完全长”的滑行，而不是靠增加肌节数目。
:::

## 本章小结

肌组织由具有收缩功能的肌细胞组成。肌细胞因呈细长纤维状，也称肌纤维，其细胞膜称肌膜，细胞质称肌质。根据结构和功能特点，肌组织分骨骼肌、心肌和平滑肌 3 种，前两种因有横纹，属横纹肌。

骨骼肌纤维呈长圆柱状，为多核细胞，具有明显的明暗相间的横纹，其中暗带也称 A 带，明带也称 I 带，I 带中央有一深色的 Z 线。扁椭圆形细胞核位于肌膜下；肌质内含有细丝样的肌原纤维。肌原纤维由粗、细两种肌丝沿其长轴规律排列而成，相邻两条 Z 线之间的一段肌原纤维称为肌节，由 $1/2$ I 带 $+$ A 带 $+$ $1/2$ I 带构成，是骨骼肌纤维结构和功能的基本单位。肌膜在明、暗带交界处横向伸入肌质，围绕在肌原纤维周围形成横小管。肌质网发达，位于相邻横小管之间呈纵向排列，也称纵小管，其末端膨大形成终池。横小管和两侧的终池构成三联体。

心肌纤维呈短圆柱状，有分支，横纹不如骨骼肌纤维明显；细胞核 1 个或 2 个，位于细胞中央；相邻肌纤维连接处有桥粒、黏着小带和缝隙连接形成的闰盘。肌质内肌丝的类型和排列与骨骼肌纤维相同，但肌质网不如骨骼肌纤维发达；终池较小，多与位于 Z 线水平的横小管形成二联体。

平滑肌纤维呈长梭形，无横纹，一个杆状或椭圆形的核位于中央，收缩时呈扭曲状。肌质内有大量密斑、密体、粗肌丝、细肌丝和中间丝，无肌原纤维。粗肌丝表面有成行排列的横桥，相邻的两行横桥屈动方向相反；细肌丝一端附着于密斑或密体，另一端游离，环绕在粗肌丝周围；若干条粗肌丝和细肌丝聚集形成肌丝单位；中间丝连接于密斑、密体之间，形成梭形的细胞骨架。

:::compare{title="骨骼肌、心肌与平滑肌"}
| 项目 | 骨骼肌 | 心肌 | 平滑肌 |
|------|--------|------|--------|
| 细胞形态 | 长圆柱状，极少分支 | 不规则短圆柱状，有分支，成网 | 长梭形 |
| 核 | 多核（几十至几百），扁椭圆，肌膜下 | 1 个或 2 个，卵圆，细胞中央 | 1 个，杆状或椭圆，中央，常扭曲 |
| 横纹 | 明显 | 有，较不明显 | 无 |
| 肌原纤维 / 肌节 | 有，界限清楚；肌节为基本单位 | 有，粗细不等、界限不清；亦有肌节 | 无肌原纤维、无肌节；有收缩单位 |
| 粗、细肌丝 | 有（细丝约 $1\,\mu\mathrm{m}$、$5\,\mathrm{nm}$；粗丝约 $1.5\,\mu\mathrm{m}$、$15\,\mathrm{nm}$） | 有，类型和排列同骨骼肌 | 有；数量比约 $1:12$ |
| T 管 / 相当结构 | 横小管在 A–I 交界 | 横小管较粗，在 Z 线水平 | 小凹沿长轴呈带状，相当 T 管 |
| 肌质网偶联 | 三联体（T 管 + 两侧终池） | 二联体（T 管 + 一侧终池） | 肌质网少；需细胞外钙 |
| 闰盘 | 无 | 有（横：黏着小带、桥粒；纵：缝隙连接） | 无闰盘；纤维间有发达缝隙连接 |
| 随意性 | 随意（躯体神经） | 不随意（自主神经），有自动节律性 | 不随意（自主神经） |
| 再生 | 肌卫星细胞可修复 | 一般无再生，瘢痕代替 | 可肥大（如妊娠子宫） |
:::

:::pitfall{label="三种肌对照时不要只背“有没有横纹”"}
横纹只回答光镜下明暗带齐不齐。核的位置和数目、T 管落点、三联体还是二联体、有没有闰盘、是不是随意肌，是五本不同的账。平滑肌无横纹也无闰盘，但有缝隙连接；心肌有横纹又有闰盘；骨骼肌有横纹无闰盘。把“横纹肌 = 骨骼肌、平滑肌 = 没有肌丝”两句话打发三种肌，切片上心肌和平滑肌会互相认错。
:::

## 插入框：运动与骨骼肌肌纤维类型的转变

人体各种躯体运动都是通过骨骼肌收缩来完成的，而骨骼肌的收缩能力与其肌纤维类型密切相关。根据骨骼肌纤维的形态特征与内在生物学特征的不同，肌纤维有不同的分类方法。其中根据收缩速度不同，肌纤维可分为慢收缩肌纤维和快收缩肌纤维。慢收缩肌纤维较细，血红蛋白和细胞色素含量丰富，又称为红肌纤维；快收缩肌纤维较粗，血红蛋白和细胞色素较少，又称为白肌纤维。

两种肌纤维所含化学物质的不同使两者的糖代谢方式不同。慢收缩肌纤维糖代谢以有氧氧化为主，肌纤维内丰富的肌红蛋白可储存大量氧，这种代谢方式赋予慢收缩肌纤维不易疲劳、能承受长时间连续活动的特性。快收缩肌纤维糖代谢以无氧酵解为主，可在短时间内爆发出大量的张力，但易疲劳。

肌纤维的类型主要由遗传基因决定，但在不同运动模式和运动负荷下，可以改变肌纤维类型及其在肌肉中的比例。因此，从事速度类、大强度项目的运动员骨骼肌快收缩肌纤维比例比从事耐力项目的运动员高；耐力项目运动员慢收缩肌纤维比例则高于速度项目运动员。

:::definition{label="慢收缩肌纤维"}
慢收缩肌纤维较细，血红蛋白和细胞色素含量丰富，又称红肌纤维。糖代谢以有氧氧化为主，肌红蛋白可贮存大量氧，不易疲劳，能承受长时间连续活动。
:::

:::definition{label="快收缩肌纤维"}
快收缩肌纤维较粗，血红蛋白和细胞色素较少，又称白肌纤维。糖代谢以无氧酵解为主，可在短时间内爆发出大量张力，但易疲劳。
:::

:::compare{title="红肌纤维与白肌纤维"}
| 项目 | 慢收缩肌纤维（红肌纤维） | 快收缩肌纤维（白肌纤维） |
|------|--------------------------|--------------------------|
| 纤维粗细 | 较细 | 较粗 |
| 血红蛋白、细胞色素 | 丰富 | 较少 |
| 肌红蛋白 | 丰富，可贮存大量氧 | 较少 |
| 糖代谢 | 有氧氧化为主 | 无氧酵解为主 |
| 收缩特点 | 较慢；不易疲劳，耐长时间连续活动 | 较快；短时爆发张力大，易疲劳 |
| 训练相关 | 耐力项目运动员比例较高 | 速度类、大强度项目运动员比例较高 |
:::

:::insight{label="类型主要由基因决定，负荷仍能改写比例"}
红、白肌不是出生后就锁死的两种细胞。遗传给出底色，运动模式和负荷可以改变类型及其在一块肌里的比例。耐力训练把慢收缩纤维的份额抬高，速度和大强度项目则抬高快收缩纤维。插入框要接回第一节：肌红蛋白写在骨骼肌肌质里，不是心肌专属；有氧还是酵解，决定这块肌能撑多久、能爆多狠。
:::

:::keypoint{label="平滑肌把滑行挂到密斑密体上，三种肌对照收口"}
- 平滑肌：长梭形、无横纹、单核居中常扭曲；一般 $200\,\mu\mathrm{m}\times 8\,\mu\mathrm{m}$，血管可短至 $20\,\mu\mathrm{m}$，妊娠子宫可达 $500\,\mu\mathrm{m}$。
- 无肌原纤维，但有粗、细肌丝（约 $1:12$）、密斑、密体和 desmin 中间丝（$10\,\mathrm{nm}$）；小凹相当 T 管；肌质网少，需细胞外钙。
- 密斑螺旋分布，粗丝无 M 线、横桥反向，细丝沿粗丝全长反向滑动 → 骨架螺旋扭曲、长轴缩短。
- 三种肌对照：核、横纹、T 管落点、三联体/二联体/小凹、闰盘、随意性，不要只背有无横纹。
- 红肌（慢、有氧、耐疲劳）与白肌（快、酵解、易疲劳）可随运动负荷改变比例。
:::

:::memory{label="本节必背要点"}
- [ ] 平滑肌（smooth muscle）分布于消化管、呼吸道、血管等中空性器官管壁，无横纹，不随意。
- [ ] 平滑肌纤维长梭形；中央 1 个杆状或椭圆形核，常扭曲；胞质嗜酸性，无横纹。
- [ ] 一般长 $200\,\mu\mathrm{m}$、直径 $8\,\mu\mathrm{m}$；小血管壁可短至 $20\,\mu\mathrm{m}$，妊娠末期子宫可达 $500\,\mu\mathrm{m}$。
- [ ] 小凹（caveola）：肌膜内陷，沿长轴呈带状，相当横小管，传递冲动。
- [ ] 无肌原纤维；有密斑（dense patch，肌膜下）、密体（dense body，肌质中梭形小体）、中间丝、细肌丝和粗肌丝。
- [ ] 中间丝由结蛋白（desmin）构成，直径 $10\,\mathrm{nm}$，连接密斑与密体，形成梭形细胞骨架。
- [ ] 粗、细肌丝数量比约 $1:12$；细肌丝主要是肌动蛋白，一端附密斑或密体，另一端游离并环绕粗肌丝。
- [ ] 粗肌丝为肌球蛋白圆柱，横桥成行，相邻两行屈动方向相反；若干粗、细肌丝聚成肌丝单位（收缩单位）。
- [ ] 肌质网少量，收缩需从细胞外摄取 $\mathrm{Ca}^{2+}$；纤维间有发达缝隙连接，形成功能整体。
- [ ] 收缩：细丝沿粗丝全长滑动、相邻细丝方向相反 → 骨架与细胞螺旋扭曲，长轴缩短。
- [ ] 三种肌：骨骼肌多核、膜下核、明显横纹、T 管在 A–I 交界、三联体、随意；心肌 1～2 核居中、横纹较弱、T 管在 Z 线、二联体、闰盘、不随意；平滑肌单核居中、无横纹、小凹、无闰盘、不随意。
- [ ] 慢收缩肌纤维 = 红肌纤维：较细，血红蛋白和细胞色素丰富，有氧氧化，耐疲劳。
- [ ] 快收缩肌纤维 = 白肌纤维：较粗，血红蛋白和细胞色素少，无氧酵解，短时爆发、易疲劳。
- [ ] 肌纤维类型主要遗传决定，但运动模式和负荷可改变类型及比例。
:::
