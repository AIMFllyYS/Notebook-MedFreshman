# 五、松果体

松果体（pineal body）呈扁圆锥形，以细柄连于第三脑室顶。松果体表面包以软膜，软膜结缔组织伴随血管和无髓神经纤维伸入腺实质。腺实质主要由松果体细胞、神经胶质细胞和无髓神经纤维组成。无髓神经纤维可与松果体细胞形成突触。上一节神经垂体把下丘脑激素贮存在赫林体里，本节松果体细胞自己合成褪黑素，参与昼夜节律；脑砂是钙化的分泌物，不是另一种激素。

:::definition{label="松果体"}
松果体（pineal body）呈扁圆锥形，以细柄连于第三脑室顶。表面包软膜，软膜结缔组织伴随血管和无髓神经纤维伸入实质。实质主要由松果体细胞、神经胶质细胞和无髓神经纤维组成。
:::

:::definition{label="松果体的神经支配"}
伸入实质的无髓神经纤维可与松果体细胞形成突触。松果体细胞因此能接受神经信号，再改写成激素输出。
:::

:::definition{label="松果体实质"}
腺实质主要由松果体细胞、神经胶质细胞和无髓神经纤维组成。软膜结缔组织伴随血管和无髓神经纤维伸入实质。
:::

:::concept{term="先问松果体细胞分泌的是褪黑素，还是把脑砂当成激素"}
松果体切片里最抢眼的同心圆钙化团是脑砂，意义不明，不是褪黑素本身。真正分泌的是松果体细胞：核大、胞质少、弱嗜碱，电镜走含氮激素分泌细胞那一本超微账。把脑砂听成“贮存褪黑素的赫林体”，昼夜节律和钙化两本账会并成一句。
:::

:::compare{title="松果体与神经垂体神经部"}
| 项目 | 松果体 | 神经垂体神经部 |
|------|--------|----------------|
| 位置 | 第三脑室顶，细柄相连 | 蝶鞍垂体窝后部 |
| 主要细胞 | 松果体细胞（自己合成褪黑素） | 垂体细胞（胶质，不合成激素） |
| 纤维 | 无髓神经纤维，可与松果体细胞成突触 | 视上核、室旁核轴突（下丘脑神经垂体束） |
| 光镜团块 | 脑砂：分泌物钙化的同心圆，意义不明 | 赫林体：轴突内激素颗粒团，弱嗜酸 |
| 激素 | 褪黑素，细胞本地合成 | 血管升压素、催产素，下丘脑合成后运来贮存 |
:::

松果体细胞（pinealocyte）与神经内分泌细胞类似。在 HE 染色切片，胞体呈圆形或不规则形，核大，细胞质少，呈弱嗜碱性（图 13-14）。电镜下，松果体细胞具有含氮激素分泌细胞的超微结构特点。松果体细胞分泌褪黑素（melatonin），褪黑素参与调节机体的昼夜节律、睡眠、情绪、性成熟等生理活动。在成人的松果体内常见脑砂，是松果体细胞分泌物钙化而成的同心圆结构，其意义不明。

:::definition{label="松果体细胞"}
松果体细胞（pinealocyte）与神经内分泌细胞类似。HE 上胞体圆形或不规则形，核大，胞质少，呈弱嗜碱性。电镜下具有含氮激素分泌细胞的超微结构特点（粗面内质网、高尔基复合体、分泌颗粒）。
:::

:::definition{label="褪黑素"}
褪黑素（melatonin）由松果体细胞分泌，参与调节机体的昼夜节律、睡眠、情绪、性成熟等生理活动。
:::

:::definition{label="脑砂"}
脑砂是成人松果体内常见的同心圆结构，由松果体细胞分泌物钙化而成，其意义不明。不是褪黑素的活性贮存形式，也不能用来代表分泌功能的高低。
:::

:::note{label="松果体实质三成分"}
| 成分 | 职分 |
|------|------|
| 松果体细胞 | 合成、分泌褪黑素；含氮激素细胞超微结构 |
| 神经胶质细胞 | 实质支架与支持 |
| 无髓神经纤维 | 可与松果体细胞形成突触，传入神经信息 |
:::

:::insight{label="褪黑素把神经节律改写成激素节律"}
无髓纤维与松果体细胞成突触，等于把传入的神经时间信号交给一枚含氮激素细胞。产物褪黑素再去调睡眠、情绪和性成熟。后文插入框的中枢生物钟在视交叉上核，松果体是这条时间轴上的内分泌落点之一，不是生物钟的母钟本身。
:::

:::pitfall{label="脑砂意义不明，不要写成褪黑素结晶，也不要当成病理必害"}
教材只写脑砂由分泌物钙化而成、成人常见、意义不明。不要把同心圆听成赫林体，也不要一见钙化就写成肿瘤或坏死。辨认松果体，脑砂是形态路标；讲功能，账仍在松果体细胞和褪黑素上。
:::

:::pitfall{label="松果体细胞弱嗜碱，不要当成腺垂体嗜碱性细胞"}
嗜碱性细胞在远侧部分泌 TSH、ACTH、FSH/LH，颗粒明显嗜碱。松果体细胞只是胞质少、弱嗜碱，激素是褪黑素。同用“嗜碱”二字，器官不同、产物不同。
:::

:::keypoint{label="松果体先立松果体细胞和褪黑素，再认脑砂"}
- 扁圆锥，细柄连第三脑室顶；软膜伸入，实质 = 松果体细胞 + 胶质 + 无髓纤维（可成突触）。
- 松果体细胞类似神经内分泌细胞，含氮激素超微结构，分泌褪黑素，调节昼夜节律、睡眠、情绪、性成熟。
- 成人常见脑砂：分泌物钙化的同心圆，意义不明。
:::
