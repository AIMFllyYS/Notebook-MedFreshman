# 一、甲状腺

内分泌系统（endocrine system）是机体的重要调节系统，由内分泌腺（如甲状腺、甲状旁腺、肾上腺、垂体、松果体等）和分布于其他器官内的内分泌组织和细胞组成。在内分泌腺中，腺细胞排列成索状、网状、团状或围成滤泡状，无输送分泌物的导管，有丰富的有孔或窦状毛细血管。分布于其他器官中的内分泌细胞有的聚集成群，如胰腺中的胰岛细胞、卵巢黄体细胞、睾丸间质细胞等；有的分散存在，如消化管、呼吸道、肾等器官的内分泌细胞。本章先把甲状腺滤泡上皮、胶质和滤泡旁细胞摊开；甲状旁腺、肾上腺、垂体、松果体和弥散神经内分泌系统各立一节。

:::definition{label="内分泌系统"}
内分泌系统（endocrine system）是机体的重要调节系统，由内分泌腺（甲状腺、甲状旁腺、肾上腺、垂体、松果体等）和分布于其他器官内的内分泌组织和细胞组成。
:::

:::definition{label="内分泌腺"}
内分泌腺的腺细胞排列成索状、网状、团状或围成滤泡状，无输送分泌物的导管，有丰富的有孔或窦状毛细血管。分泌物直接入血或作用于邻近细胞。
:::

:::definition{label="器官内的内分泌组织"}
分布于其他器官中的内分泌细胞有的聚集成群，如胰岛细胞、卵巢黄体细胞、睾丸间质细胞；有的分散存在，如消化管、呼吸道、肾等器官的内分泌细胞。后文弥散神经内分泌系统把分散者收成一本账。
:::

内分泌细胞的分泌物称激素（hormone）。大多数内分泌细胞分泌的激素通过血液循环作用于远处的特定细胞，少部分可直接作用于邻近的细胞，称旁分泌（paracrine）。每种激素作用的特定器官或特定细胞，称为这种激素的靶器官（target organ）或靶细胞（target cell）。靶细胞具有与相应激素结合的受体（receptor），激素与受体结合后产生效应。

:::definition{label="激素"}
激素（hormone）是内分泌细胞的分泌物。大多数经血液循环作用于远处靶细胞；少部分直接作用于邻近细胞，称旁分泌。
:::

:::definition{label="旁分泌"}
旁分泌（paracrine）是激素不经血液循环、直接作用于邻近细胞的分泌方式。与经血到达远处靶细胞的经典内分泌相对。
:::

:::definition{label="靶器官与靶细胞"}
每种激素作用的特定器官或特定细胞，称为这种激素的靶器官（target organ）或靶细胞（target cell）。靶细胞具有与相应激素结合的受体（receptor），激素与受体结合后产生效应。
:::

:::definition{label="受体"}
受体（receptor）是靶细胞上能与相应激素结合的分子。无受体则激素到了也不产生该激素的效应。
:::

:::concept{term="先问激素是经血走远处，还是旁分泌到邻居"}
看见“内分泌”，先问两件事：有没有导管；产物是入血还是只交给旁边的细胞。无导管、有孔或窦状毛细血管，是内分泌腺的身份证。经血到远处是经典内分泌，直接作用于邻近细胞才叫旁分泌。把内分泌听成“只要能分泌就算”，外分泌腺那根导管账会并进来；把旁分泌漏掉，滤泡旁细胞降钙素对邻近骨代谢的近距离账也会写丢。
:::

激素按其化学性质分为含氮激素（包括氨基酸衍生物、胺类、肽类和蛋白质类激素）和类固醇激素两大类。机体绝大部分内分泌细胞为含氮激素分泌细胞，其超微结构特点是细胞质中有密集的粗面内质网、较发达的高尔基复合体和数量不等的分泌颗粒。类固醇激素分泌细胞仅包括肾上腺皮质和性腺的内分泌细胞，其超微结构特点是细胞质内含有与合成类固醇激素有关的丰富的滑面内质网；线粒体较多，嵴多呈管状；含较多脂滴，为激素合成的原料；无分泌颗粒，为脂溶性激素，可通过细胞膜直接扩散出细胞。

:::definition{label="含氮激素"}
含氮激素包括氨基酸衍生物、胺类、肽类和蛋白质类激素。机体绝大部分内分泌细胞分泌含氮激素。
:::

:::definition{label="含氮激素分泌细胞"}
含氮激素分泌细胞的超微结构特点是：胞质中有密集的粗面内质网、较发达的高尔基复合体和数量不等的分泌颗粒。甲状腺滤泡上皮、滤泡旁细胞、甲状旁腺主细胞、肾上腺髓质嗜铬细胞、腺垂体嗜色细胞和松果体细胞都走这条超微账。
:::

:::definition{label="类固醇激素分泌细胞"}
类固醇激素分泌细胞仅包括肾上腺皮质和性腺的内分泌细胞。超微结构特点是：胞质内有丰富的滑面内质网；线粒体较多，嵴多呈管状；含较多脂滴（激素合成原料）；无分泌颗粒。激素为脂溶性，可经细胞膜直接扩散出细胞。
:::

:::compare{title="含氮激素分泌细胞与类固醇激素分泌细胞"}
| 项目 | 含氮激素分泌细胞 | 类固醇激素分泌细胞 |
|------|------------------|---------------------|
| 激素化学 | 氨基酸衍生物、胺类、肽类、蛋白质类 | 类固醇 |
| 分布 | 机体绝大部分内分泌细胞 | 仅肾上腺皮质和性腺内分泌细胞 |
| 内质网 | 密集粗面内质网 | 丰富滑面内质网 |
| 高尔基复合体 | 较发达 | 不作为身份证强调 |
| 分泌颗粒 | 数量不等，有 | 无 |
| 线粒体 | 一般线粒体 | 较多，嵴多呈管状 |
| 脂滴 | 不作为原料账 | 较多，为合成原料 |
| 出细胞方式 | 颗粒胞吐 | 脂溶性，经膜扩散 |
:::

:::pitfall{label="类固醇细胞没有分泌颗粒，不要把脂滴当成颗粒"}
含氮激素靠粗面内质网造肽、靠颗粒贮存再胞吐。类固醇细胞没有分泌颗粒，原料是脂滴，成品经膜扩散。把束状带泡沫状空泡听成“分泌颗粒被溶解”，会把皮质写成含氮腺；把滤泡腔内嗜酸胶质听成类固醇原料，碘化甲状腺球蛋白那一本贮存账也会错位。
:::

:::insight{label="无导管加有孔毛细血管，是整章腺体的共同管腔账"}
外分泌把产物送进导管；内分泌把产物送进有孔或窦状毛细血管。滤泡是个例外：甲状腺先把未完成的激素贮在滤泡腔里，再重吸收后从基底面入血。后面甲状旁腺索团、肾上腺索团、腺垂体团索，都不再围出滤泡腔。看见滤泡，先问是不是甲状腺；看见索团加血窦，再往肾上腺或垂体上靠。
:::

甲状腺（thyroid gland）分左右两叶，中间以峡部相连。表面包有薄层结缔组织被膜。腺实质由大量甲状腺滤泡组成，滤泡间有少量疏松结缔组织和丰富的有孔毛细血管（图 13-1，图 13-2）。

:::definition{label="甲状腺"}
甲状腺（thyroid gland）分左右两叶，中间以峡部相连。表面包薄层结缔组织被膜。实质由大量甲状腺滤泡组成，滤泡间有少量疏松结缔组织和丰富的有孔毛细血管。
:::

:::concept{term="先问这是滤泡上皮、胶质，还是滤泡旁细胞"}
甲状腺切片第一眼是大小不等的滤泡：单层上皮围一腔嗜酸胶质。滤泡上皮细胞管甲状腺激素，胶质是碘化甲状腺球蛋白的仓库，滤泡旁细胞既可嵌在上皮之间也可坐在滤泡之间，管降钙素。三本账不要并成“滤泡里的细胞”。腔内没有滤泡旁细胞，旁细胞也不造胶质。
:::

## （一）甲状腺滤泡

甲状腺滤泡（thyroid follicle）大小不等，直径 $0.02\sim 0.9\,\mathrm{mm}$，呈圆形或不规则形。滤泡由单层立方的滤泡上皮细胞（follicular epithelial cell）围成，滤泡腔内充满均质状、嗜酸性的胶质（colloid）（图 13-1）。

:::definition{label="甲状腺滤泡"}
甲状腺滤泡（thyroid follicle）大小不等，直径 $0.02\sim 0.9\,\mathrm{mm}$，呈圆形或不规则形。由单层立方的滤泡上皮细胞围成，腔内充满均质状、嗜酸性的胶质。
:::

:::definition{label="滤泡上皮细胞"}
滤泡上皮细胞（follicular epithelial cell）是围成甲状腺滤泡的单层上皮细胞，合成和分泌甲状腺激素。功能活跃时增高呈低柱状，腔内胶质减少；功能低下时变矮呈扁平状，腔内胶质增多。
:::

:::definition{label="胶质"}
胶质（colloid）是滤泡腔内均质状、嗜酸性物质，即滤泡上皮细胞的分泌物——碘化的甲状腺球蛋白。它是甲状腺激素尚未水解入血之前的细胞外贮存形式。
:::

滤泡上皮细胞可因功能状态不同而有形态差异。在功能活跃时，细胞增高呈低柱状，腔内胶质减少；反之，细胞变矮呈扁平状，腔内胶质增多。胶质是滤泡上皮细胞的分泌物，即碘化的甲状腺球蛋白。

:::note{label="滤泡上皮形态随功能改写"}
| 功能状态 | 上皮形态 | 腔内胶质 |
|----------|----------|----------|
| 活跃 | 增高呈低柱状 | 减少 |
| 低下 | 变矮呈扁平状 | 增多 |
:::

:::pitfall{label="扁平滤泡上皮不是内皮，也不要当成滤泡旁细胞"}
功能低下时滤泡上皮可以扁得像内皮，但围的是胶质腔，基底面仍有完整基膜，腔内是碘化甲状腺球蛋白。滤泡旁细胞稍大、HE 淡染，并不铺成腔面。把扁平上皮听成“滤泡旁细胞铺腔”，降钙素和甲状腺激素两本分泌账会写反。
:::

电镜下，滤泡上皮细胞细胞质内有较丰富的粗面内质网和较多的线粒体，溶酶体散在于细胞质内，高尔基复合体位于核上区。顶部细胞质内有电子密度中等、体积很小的分泌颗粒，还有从滤泡腔摄入的低电子密度的胶质小泡。滤泡上皮基底面有完整的基膜（图 13-3）。

:::definition{label="滤泡上皮的超微结构"}
滤泡上皮细胞属含氮激素分泌细胞：较丰富的粗面内质网、较多线粒体、散在溶酶体、核上区高尔基复合体。顶部有电子密度中等、体积很小的分泌颗粒，以及从滤泡腔摄入的低电子密度胶质小泡。基底面有完整基膜。
:::

:::definition{label="胶质小泡"}
胶质小泡是滤泡上皮顶部胞质内低电子密度的小泡，由胞吞滤泡腔内碘化甲状腺球蛋白而来。与溶酶体融合后，甲状腺球蛋白被水解，释放 $\mathrm{T}_3$、$\mathrm{T}_4$。
:::

:::compare{title="顶部两类小泡"}
| 项目 | 分泌颗粒 | 胶质小泡 |
|------|----------|----------|
| 电子密度 | 中等 | 低 |
| 体积 | 很小 | 由腔内摄入，相对较大 |
| 方向 | 出细胞：甲状腺球蛋白前体排入滤泡腔 | 进细胞：碘化甲状腺球蛋白从腔内重吸收 |
| 下一步 | 在腔内碘化、贮存 | 与溶酶体融合，水解出 $\mathrm{T}_3$、$\mathrm{T}_4$ |
:::

滤泡上皮细胞合成和分泌甲状腺激素。甲状腺激素的形成经过合成、贮存、碘化、重吸收、分解和释放等过程。滤泡上皮细胞从血中摄取氨基酸，在粗面内质网合成甲状腺球蛋白的前体，继而在高尔基复合体加糖并浓缩形成分泌颗粒，再以胞吐方式排放到滤泡腔内贮存。滤泡上皮细胞能从血中摄取 $\mathrm{I}^{-}$，后者经过氧化物酶的作用而活化，再进入滤泡腔与甲状腺球蛋白结合，形成碘化甲状腺球蛋白。

滤泡上皮细胞在腺垂体分泌的促甲状腺激素的作用下，胞吞滤泡腔内的碘化甲状腺球蛋白，成为胶质小泡。胶质小泡与溶酶体融合，小泡内的甲状腺球蛋白被水解酶分解，形成甲状腺激素，即大量的四碘甲腺原氨酸（$\mathrm{T}_4$），也称甲状腺素（thyroxine）和少量的三碘甲腺原氨酸（$\mathrm{T}_3$）。$\mathrm{T}_3$ 和 $\mathrm{T}_4$ 于滤泡上皮细胞基底部释放入血。

:::definition{label="甲状腺激素"}
甲状腺激素主要包括大量四碘甲腺原氨酸（$\mathrm{T}_4$，甲状腺素 thyroxine）和少量三碘甲腺原氨酸（$\mathrm{T}_3$）。由碘化甲状腺球蛋白在溶酶体内水解形成，于滤泡上皮基底部释放入血。
:::

:::definition{label="甲状腺球蛋白"}
滤泡上皮从血中摄取氨基酸，在粗面内质网合成甲状腺球蛋白前体，高尔基复合体加糖并浓缩为分泌颗粒，胞吐入滤泡腔。在腔内与活化碘结合，成为碘化甲状腺球蛋白，即胶质的本质。
:::

:::definition{label="碘的活化和碘化"}
滤泡上皮从血中摄取 $\mathrm{I}^{-}$，经过氧化物酶作用而活化，再进入滤泡腔与甲状腺球蛋白结合，形成碘化甲状腺球蛋白。碘化发生在滤泡腔内，不是在粗面内质网里。
:::

:::definition{label="促甲状腺激素"}
促甲状腺激素（thyroid stimulating hormone，TSH）由腺垂体嗜碱性的促甲状腺激素细胞分泌，促使滤泡上皮胞吞腔内碘化甲状腺球蛋白，启动重吸收、分解和释放。
:::

:::note{label="甲状腺激素形成的六步"}
| 步骤 | 落点 |
|------|------|
| 合成 | 摄取氨基酸 → 粗面内质网造甲状腺球蛋白前体 → 高尔基加糖浓缩 → 分泌颗粒 |
| 贮存 | 胞吐入滤泡腔，以胶质形式存放 |
| 碘化 | 摄取 $\mathrm{I}^{-}$ → 过氧化物酶活化 → 入腔与甲状腺球蛋白结合 |
| 重吸收 | TSH 作用下胞吞碘化甲状腺球蛋白，成胶质小泡 |
| 分解 | 胶质小泡与溶酶体融合，水解酶切出大量 $\mathrm{T}_4$ 和少量 $\mathrm{T}_3$ |
| 释放 | $\mathrm{T}_3$、$\mathrm{T}_4$ 从上皮基底部入血 |
:::

:::insight{label="甲状腺是少数把半成品贮在细胞外的内分泌腺"}
蛋白质类激素通常先装进分泌颗粒再胞吐入血。滤泡上皮却把甲状腺球蛋白先吐到滤泡腔碘化贮存，等 TSH 下令再吞回来水解。所以光镜下那团嗜酸胶质不是废料，是激素仓库。把胶质听成“管腔内容物可有可无”，甲亢时胶质减少、功能低下时胶质增多那两眼就对不上。
:::

:::pitfall{label="T3、T4 从基底面入血，不要写成向滤泡腔分泌甲状腺素"}
向腔面吐的是甲状腺球蛋白（贮存），向基底面放的才是 $\mathrm{T}_3$、$\mathrm{T}_4$（入有孔毛细血管）。方向写反，会把胶质当成成品甲状腺素，也会把滤泡腔误写成“内分泌导管”。
:::

甲状腺激素能促进机体的新陈代谢，提高神经兴奋性，促进生长发育。甲状腺激素对婴幼儿的骨骼发育和中枢神经系统发育有显著影响。小儿甲状腺功能减退，不仅长骨生长停滞、身材矮小，而且脑发育障碍、智力低下，导致呆小病（cretinism）。成人甲状腺功能亢进时，出现明显的中枢神经系统兴奋性增高的表现，同时引起心血管、消化等系统功能的紊乱，即临床上常见的甲状腺功能亢进症，简称甲亢。

:::definition{label="甲状腺激素的作用"}
甲状腺激素能促进机体的新陈代谢，提高神经兴奋性，促进生长发育；对婴幼儿的骨骼发育和中枢神经系统发育有显著影响。
:::

:::definition{label="呆小病"}
呆小病（cretinism）是小儿甲状腺功能减退所致：长骨生长停滞、身材矮小，同时脑发育障碍、智力低下。
:::

:::definition{label="甲状腺功能亢进症"}
成人甲状腺功能亢进时，中枢神经系统兴奋性明显增高，并引起心血管、消化等系统功能紊乱，称甲状腺功能亢进症，简称甲亢。
:::

:::compare{title="小儿甲减与成人甲亢"}
| 项目 | 小儿甲状腺功能减退 | 成人甲状腺功能亢进 |
|------|---------------------|---------------------|
| 关键激素 | 甲状腺激素不足 | 甲状腺激素过多 |
| 骨骼 / 脑 | 长骨生长停滞、身材矮小；脑发育障碍、智力低下 | 发育已完成，不以矮小、呆小为主 |
| 神经兴奋性 | 发育障碍 | 明显增高 |
| 其他系统 | — | 心血管、消化等功能紊乱 |
| 病名 | 呆小病（cretinism） | 甲亢 |
:::

:::pitfall{label="呆小病是小儿甲减，不要写成缺钙或生长激素不足"}
长骨不长加上智力低下，账在甲状腺激素对骨骼和中枢神经发育的双重作用上。缺钙主要写甲状旁腺 / 降钙素；生长激素不足写腺垂体嗜酸性细胞，表现为垂体性侏儒而智力通常不受同样方式的打击。三本发育账不要并成“个子矮就是呆小病”。
:::

## （二）滤泡旁细胞

滤泡旁细胞（parafollicular cell）位于甲状腺滤泡之间和滤泡上皮细胞之间。细胞稍大，在 HE 染色切片中细胞质着色较淡（见图 13-1），镀银染色切片可见其细胞质内有黑色的嗜银分泌颗粒（见图 13-2）。电镜下，位于滤泡上皮中的滤泡旁细胞顶部被相邻的滤泡上皮细胞覆盖（见图 13-3）。滤泡旁细胞以胞吐方式释放分泌颗粒内的降钙素（calcitonin）。降钙素能促进成骨细胞的活动，使骨盐沉着于类骨质，并抑制胃肠道和肾小管吸收 $\mathrm{Ca}^{2+}$，使血钙浓度降低。

:::definition{label="滤泡旁细胞"}
滤泡旁细胞（parafollicular cell）位于甲状腺滤泡之间和滤泡上皮细胞之间。细胞稍大，HE 胞质着色较淡；镀银染色可见胞质内黑色嗜银分泌颗粒。属于含氮激素分泌细胞，也是后文 DNES 的成员。
:::

:::definition{label="降钙素"}
降钙素（calcitonin）贮于滤泡旁细胞的分泌颗粒内，以胞吐释放。促进成骨细胞活动，使骨盐沉着于类骨质，并抑制胃肠道和肾小管吸收 $\mathrm{Ca}^{2+}$，从而降低血钙浓度。
:::

:::compare{title="滤泡上皮细胞与滤泡旁细胞"}
| 项目 | 滤泡上皮细胞 | 滤泡旁细胞 |
|------|--------------|------------|
| 英文 | follicular epithelial cell | parafollicular cell |
| 位置 | 围成滤泡，衬在腔面 | 滤泡之间，以及滤泡上皮细胞之间；不在腔内 |
| 腔面关系 | 游离面朝向胶质 | 嵌在上皮中者顶部被相邻滤泡上皮覆盖，不接触胶质 |
| HE | 立方形（功能可改为低柱状或扁平） | 稍大，胞质淡染 |
| 镀银 | 不以嗜银颗粒为身份证 | 胞质内黑色嗜银分泌颗粒 |
| 产物 | 甲状腺激素（$\mathrm{T}_3$、$\mathrm{T}_4$） | 降钙素 |
| 贮存处 | 先以碘化甲状腺球蛋白贮于滤泡腔 | 分泌颗粒内，胞吐入血 |
| 入血方向 | 基底部 | 基底侧胞吐 |
| 主要效应 | 促代谢、提神经兴奋性、促生长发育 | 降血钙 |
:::

:::pitfall{label="滤泡旁细胞在滤泡之间或上皮之间，绝不在滤泡腔内"}
腔内只有胶质（碘化甲状腺球蛋白），没有滤泡旁细胞。旁细胞或夹在滤泡上皮之间（顶部被盖住），或坐在滤泡与滤泡之间的结缔组织里。镀银看到的黑颗粒在胞质内，不是胶质里的碘。把旁细胞画进腔里，降钙素会变成“向胶质分泌”，血钙账整段错位。
:::

:::insight{label="滤泡旁细胞降钙素与下一节主细胞甲状旁腺激素对打"}
降钙素促成骨、阻肠管和肾小管吸钙，把血钙往下按；甲状旁腺主细胞的甲状旁腺激素溶骨、促肠和肾小管吸钙，把血钙往上抬。同一对血钙闸门，细胞却分属两个腺体。本节只立降钙素这一侧，升钙的账留到甲状旁腺。
:::

:::keypoint{label="甲状腺先立滤泡上皮加胶质，再立滤泡旁细胞"}
- 内分泌腺无导管，有丰富有孔或窦状毛细血管；激素经血至靶细胞，或旁分泌至邻近细胞。
- 含氮激素细胞：粗面内质网、高尔基复合体、分泌颗粒；类固醇激素细胞仅皮质和性腺：滑面内质网、管状嵴线粒体、脂滴、无颗粒。
- 甲状腺实质是滤泡：单层滤泡上皮围嗜酸胶质（碘化甲状腺球蛋白）。
- 甲状腺激素六步：合成、贮存、碘化、重吸收、分解、释放；大量 $\mathrm{T}_4$、少量 $\mathrm{T}_3$ 从基底部入血。
- 滤泡旁细胞在滤泡之间和上皮之间，不在腔内；分泌降钙素，降低血钙。
:::

:::memory{label="本节必背要点"}
- [ ] 内分泌系统由内分泌腺（甲状腺、甲状旁腺、肾上腺、垂体、松果体等）和分布于其他器官内的内分泌组织和细胞组成。
- [ ] 内分泌腺腺细胞排成索状、网状、团状或围成滤泡状，无导管，有丰富有孔或窦状毛细血管。
- [ ] 器官内内分泌细胞可聚集成群（胰岛、黄体、睾丸间质细胞）或分散存在（消化管、呼吸道、肾等）。
- [ ] 激素是内分泌细胞的分泌物；大多经血液循环作用于远处靶细胞，少部分旁分泌作用于邻近细胞。
- [ ] 靶器官 / 靶细胞具有相应受体，激素与受体结合后产生效应。
- [ ] 激素分含氮激素（氨基酸衍生物、胺类、肽类、蛋白质类）和类固醇激素两大类。
- [ ] 含氮激素分泌细胞：密集粗面内质网、较发达高尔基复合体、数量不等的分泌颗粒。
- [ ] 类固醇激素分泌细胞仅包括肾上腺皮质和性腺内分泌细胞：丰富滑面内质网；线粒体较多、嵴多呈管状；较多脂滴；无分泌颗粒；脂溶性激素经膜扩散出细胞。
- [ ] 甲状腺分左右两叶，峡部相连；薄层结缔组织被膜；实质为大量甲状腺滤泡。
- [ ] 滤泡间有少量疏松结缔组织和丰富的有孔毛细血管。
- [ ] 甲状腺滤泡直径 $0.02\sim 0.9\,\mathrm{mm}$，圆形或不规则形，单层立方滤泡上皮围成。
- [ ] 滤泡腔内充满均质状、嗜酸性胶质，即碘化的甲状腺球蛋白。
- [ ] 功能活跃时上皮增高呈低柱状、胶质减少；反之上皮变扁平、胶质增多。
- [ ] 电镜：较丰富粗面内质网、较多线粒体、散在溶酶体、核上区高尔基复合体；顶部有中等电子密度的小分泌颗粒和低电子密度胶质小泡；基底面有完整基膜。
- [ ] 甲状腺激素形成经过合成、贮存、碘化、重吸收、分解和释放。
- [ ] 摄取氨基酸 → 粗面内质网合成甲状腺球蛋白前体 → 高尔基加糖浓缩为分泌颗粒 → 胞吐入滤泡腔贮存。
- [ ] 从血中摄取 $\mathrm{I}^{-}$，经过氧化物酶活化，入滤泡腔与甲状腺球蛋白结合，形成碘化甲状腺球蛋白。
- [ ] 在 TSH 作用下胞吞碘化甲状腺球蛋白成为胶质小泡；与溶酶体融合后水解，形成大量 $\mathrm{T}_4$（甲状腺素）和少量 $\mathrm{T}_3$，从基底部入血。
- [ ] 甲状腺激素促进新陈代谢、提高神经兴奋性、促进生长发育；对婴幼儿骨骼和中枢神经系统发育影响显著。
- [ ] 小儿甲状腺功能减退：长骨生长停滞、身材矮小，脑发育障碍、智力低下，即呆小病（cretinism）。
- [ ] 成人甲状腺功能亢进：中枢神经系统兴奋性增高，心血管、消化等系统功能紊乱，即甲亢。
- [ ] 滤泡旁细胞位于滤泡之间和滤泡上皮细胞之间，不在腔内；细胞稍大，HE 胞质淡染。
- [ ] 镀银染色可见滤泡旁细胞胞质内黑色嗜银分泌颗粒。
- [ ] 位于滤泡上皮中的滤泡旁细胞顶部被相邻滤泡上皮覆盖。
- [ ] 滤泡旁细胞胞吐释放降钙素：促成骨细胞活动、骨盐沉着于类骨质，抑制胃肠道和肾小管吸收 $\mathrm{Ca}^{2+}$，使血钙降低。
