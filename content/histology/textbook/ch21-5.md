# 五、胎膜和胎盘

胎膜和胎盘是对胚胎起保护、营养、呼吸、排泄等作用的附属结构，不参与胚胎本体的形成。有的结构还有内分泌功能。胎儿娩出后，胎膜、胎盘即与子宫壁分离，并被排出体外，总称衣胞（afterbirth）。本节把绒毛膜、羊膜、卵黄囊、尿囊、脐带和胎盘摊开；胚体本身的分化见上一节。

:::definition{label="胎膜和胎盘"}
胎膜和胎盘是附属结构，职分是保护、营养、呼吸、排泄，有的还有内分泌功能。它们不参与胚胎本体的形成，不是“胎儿身体的一部分”。
:::

:::definition{label="衣胞"}
衣胞（afterbirth）是胎儿娩出后，与子宫壁分离并被排出体外的胎膜和胎盘的总称。
:::

:::concept{term="先问这是胚体本身还是附属结构，再问胎盘胎儿部还是母体部"}
看见妊娠子宫里的膜和盘，先切开两本账：神经管、体节、原始消化管属于胚体；绒毛膜、羊膜、卵黄囊、尿囊、脐带是胎膜，丛密绒毛膜加上基蜕膜才组成胎盘。胎盘再切开：胎儿部是丛密绒毛膜，母体部是基蜕膜。把胎盘写成“纯胎儿器官”或把羊膜写成“胚体皮肤”，营养和屏障账都会对错户头。
:::

## （一）胎膜

胎膜（fetal membrane）包括绒毛膜、羊膜、卵黄囊、尿囊和脐带（图 21-22）。

:::definition{label="胎膜"}
胎膜（fetal membrane）包括绒毛膜、羊膜、卵黄囊、尿囊和脐带。五件都是附属结构，分娩后随衣胞排出。
:::

### 1. 绒毛膜

绒毛膜（chorion）由绒毛膜板、各级绒毛干及绒毛组成。滋养层和衬于其内面的胚外中胚层组成绒毛膜板（chorionic plate），在其基础上形成各级绒毛干及绒毛。植入完成后，滋养层已分化为细胞滋养层和合体滋养层两层（见图 21-6）。继而细胞滋养层局部增殖，伸入合体滋养层内，两者共同形成许多绒毛状突起，称为初级绒毛干（primary stem villus）。第 $3$ 周时，胚外中胚层伸入绒毛干内，改称次级绒毛干（secondary stem villus）。此后，绒毛干里的胚外中胚层间充质分化为结缔组织和血管，并与胚体内的血管相通，此时改称三级绒毛干（tertiary stem villus）。各级绒毛干的表面都发出分支，形成许多细小的绒毛（图 21-23，图 21-24）。同时，绒毛干末端的细胞滋养层细胞增殖，穿出合体滋养层，伸抵子宫蜕膜组织，将绒毛干固着于蜕膜上。这些穿出的细胞滋养层细胞还沿蜕膜扩展，彼此连接，在蜕膜表面形成一层细胞滋养层壳，使绒毛膜与子宫蜕膜牢固连接。

:::definition{label="绒毛膜"}
绒毛膜（chorion）由绒毛膜板、各级绒毛干及绒毛组成。它是胎膜的最外层，早期表面绒毛均匀分布，后来才分成平滑绒毛膜和丛密绒毛膜。
:::

:::definition{label="绒毛膜板"}
绒毛膜板（chorionic plate）由滋养层和衬于其内面的胚外中胚层组成，是发出各级绒毛干及绒毛的底板。
:::

:::definition{label="初级绒毛干"}
初级绒毛干（primary stem villus）是细胞滋养层局部增殖、伸入合体滋养层内，两者共同形成的绒毛状突起。此时干心还没有胚外中胚层，更没有血管。
:::

:::definition{label="次级绒毛干"}
次级绒毛干（secondary stem villus）出现于第 $3$ 周：胚外中胚层伸入绒毛干内。干心有间充质，但尚未分化出与胚体相通的血管。
:::

:::definition{label="三级绒毛干"}
三级绒毛干（tertiary stem villus）是绒毛干里的胚外中胚层间充质分化为结缔组织和血管、并与胚体内血管相通之后的绒毛干。此后胚胎才能通过绒毛与母体血交换物质。
:::

:::definition{label="细胞滋养层壳"}
绒毛干末端的细胞滋养层细胞增殖，穿出合体滋养层，伸抵子宫蜕膜，把绒毛干固着于蜕膜上；这些细胞再沿蜕膜扩展、彼此连接，在蜕膜表面形成一层细胞滋养层壳，使绒毛膜与子宫蜕膜牢固连接。
:::

:::concept{term="先问干心里有没有中胚层，再问有没有与胚体相通的血管"}
绒毛干升级只看干心：只有细胞滋养层和合体滋养层，是初级；胚外中胚层伸进去了，是次级；间充质变成结缔组织和血管并且和胚体血管接通，才叫三级。不要把“已经分支的绒毛”或“已经贴上蜕膜”当成升级标准。细胞滋养层壳是末端固着装置，不是第四级绒毛干。
:::

:::compare{title="初级、次级与三级绒毛干"}
| 项目 | 初级绒毛干 | 次级绒毛干 | 三级绒毛干 |
|------|------------|------------|------------|
| 时间 | 植入完成后不久 | 第 $3$ 周 | 次级之后，干心血管分化并与胚体相通 |

:::

原滋养层陷窝演变为绒毛干之间的绒毛间隙，其内充满来自子宫螺旋动脉的母体血，绒毛浸浴其中。胚胎通过绒毛汲取母体血中的营养物质并排出代谢产物。

胚胎早期，整个绒毛膜表面的绒毛均匀分布。之后，由于包蜕膜侧的血供匮乏，绒毛逐渐退化、消失，形成表面无绒毛的平滑绒毛膜（chorion leave）。基蜕膜侧的血供充足，该处绒毛反复分支，生长茂密，称丛密绒毛膜（chorion frondosum），与基蜕膜一起组成胎盘。丛密绒毛膜内的血管通过脐带与胚体内的血管通连。此后，随着胚胎的发育增长及羊膜腔的不断扩大，羊膜、平滑绒毛膜和包蜕膜进一步凸向子宫腔，最终与壁蜕膜融合，子宫腔消失（见图 21-22，图 21-25）。

:::definition{label="绒毛间隙"}
绒毛间隙由原滋养层陷窝演变而来，位于绒毛干之间，内充满来自子宫螺旋动脉的母体血。绒毛浸浴其中，胚胎经此汲取营养并排出代谢产物。
:::

:::definition{label="平滑绒毛膜"}
平滑绒毛膜（chorion leave）是包蜕膜侧因血供匮乏、绒毛逐渐退化消失后形成的无绒毛绒毛膜。它不组成胎盘。
:::

:::definition{label="丛密绒毛膜"}
丛密绒毛膜（chorion frondosum）是基蜕膜侧因血供充足、绒毛反复分支生长茂密而形成的绒毛膜。它与基蜕膜一起组成胎盘；其内血管通过脐带与胚体血管通连。
:::

:::definition{label="子宫腔的消失"}
随着胚胎增大和羊膜腔扩大，羊膜、平滑绒毛膜和包蜕膜凸向子宫腔，最终与壁蜕膜融合，子宫腔消失。
:::

::figure{src="/images/histology/textbook/p0237_01.png" caption="图21-25 胎膜、蜕膜与胎盘模式图。A. 第 2 个月：羊膜、平滑绒毛膜、包蜕膜仍凸向子宫腔，基蜕膜侧为丛密绒毛膜与胎盘绒毛间隙；B. 胎儿后期：羊膜、平滑绒毛膜与包蜕膜融合，并与壁蜕膜相贴，子宫腔消失。" alt="子宫矢状两图：A 胚居一侧、宫腔仍在，B 胎儿占据宫腔、胎盘在底、脐带相连"}

在绒毛膜发育过程中，若血管发育不良或与胚体血管未通连，胚胎可因缺乏营养而发育迟缓或死亡。若滋养层细胞过度增生，绒毛内结缔组织变性水肿，血管消失，胚胎发育受阻，绒毛呈葡萄或水泡状，称葡萄胎或水泡状胎块。若滋养层细胞癌变，则称绒毛膜癌。

:::definition{label="绒毛膜血管未通连"}
绒毛干内血管发育不良，或未能与胚体血管通连时，胚胎缺乏营养，可发育迟缓或死亡。三级绒毛干的“通连”不是可有可无的形态细节。
:::

:::definition{label="葡萄胎（水泡状胎块）"}
葡萄胎或水泡状胎块指滋养层细胞过度增生，绒毛内结缔组织变性水肿、血管消失，胚胎发育受阻，绒毛呈葡萄或水泡状。
:::

:::definition{label="绒毛膜癌"}
绒毛膜癌指滋养层细胞癌变。它不是葡萄胎的别名，而是滋养层细胞的恶性变。
:::

:::compare{title="平滑绒毛膜与丛密绒毛膜"}
| 项目 | 平滑绒毛膜 | 丛密绒毛膜 |
|------|------------|------------|
| 英文 | chorion leave | chorion frondosum |
| 侧别 | 包蜕膜侧 | 基蜕膜侧 |
| 血供 | 匮乏 | 充足 |
| 绒毛 | 退化、消失，表面无绒毛 | 反复分支，生长茂密 |
| 与胎盘 | 不组成胎盘 | 与基蜕膜共同组成胎盘 |
| 血管去向 | — | 经脐带与胚体血管通连 |
:::

:::cause-effect{title="绒毛膜三件发育事故分别通向哪里"}
- 因：血管发育不良或与胚体血管未通连
- 果：胚胎缺乏营养，发育迟缓或死亡
- 因：滋养层细胞过度增生，绒毛内结缔组织变性水肿，血管消失
- 果：葡萄胎（水泡状胎块），胚胎发育受阻
- 因：滋养层细胞癌变
- 果：绒毛膜癌
:::

:::pitfall{label="平滑绒毛膜在包蜕膜侧，丛密绒毛膜在基蜕膜侧，不要对调"}
包蜕膜是盖在胚宫腔面的那一层，血供差，绒毛退化成平滑绒毛膜。基蜕膜夹在胚与肌层之间，血供好，绒毛长成丛密绒毛膜，这才是胎盘胎儿部。把“贴着子宫腔的那面”当成胎盘，母体面和胎儿面会对调。
:::

### 2. 羊膜

羊膜（amnion）为半透明薄膜，由一层羊膜上皮和少量胚外中胚层构成，内无血管（图 21-26）。羊膜腔内充满羊水（amniotic fluid），胚胎浸泡在羊水中。羊膜最初附着于胚盘的边缘，与外胚层连续。随着胚体形成、羊膜腔扩大和胚体凸入羊膜腔内，羊膜在胚胎的腹侧包裹体蒂，形成脐带。羊膜腔的扩大逐渐使羊膜与绒毛膜相贴，胚外体腔消失。

妊娠早期的羊水呈无色透明状，由羊膜不断分泌和吸收。妊娠中期以后，胎儿开始吞咽羊水，其消化系统、泌尿系统的排泄物及脱落的上皮细胞也进入羊水，使羊水变得浑浊。

:::definition{label="羊膜"}
羊膜（amnion）是半透明薄膜，由一层羊膜上皮和少量胚外中胚层构成，内无血管。它最初附着于胚盘边缘，与外胚层连续。
:::

:::definition{label="羊水"}
羊水（amniotic fluid）充满羊膜腔，胚胎浸泡其中。妊娠早期无色透明，由羊膜不断分泌和吸收；妊娠中期以后因胎儿吞咽，消化、泌尿系统排泄物及脱落上皮进入，羊水变浑浊。
:::

:::definition{label="羊膜与脐带、胚外体腔"}
胚体凸入羊膜腔后，羊膜在腹侧包裹体蒂，参与形成脐带。羊膜腔扩大使羊膜与绒毛膜相贴，胚外体腔消失。
:::

::figure{src="/images/histology/textbook/p0237_02.png" caption="图21-26 胚胎与胎盘模式图。A. 第 7 周：胚居羊膜腔，外周为绒毛膜与绒毛，腹侧可见卵黄囊和胚外体腔，脐带连于体蒂侧；B. 第 4 个月：羊膜包绕胎儿，绒毛膜侧出现胎盘隔分隔的胎盘小叶。" alt="两幅模式：A 早期胚泡状绒毛包围羊膜腔中的胚，B 中期胎儿蜷于羊膜囊、顶部为绿色胎盘小叶"}

羊膜和羊水在胚胎发育中对胚胎起重要的保护作用，如胚胎在羊水中可较自由地活动，有利于骨骼和肌肉发育，并防止胚胎局部粘连或受外力的压迫与震荡。临产时，羊水还具有扩张宫颈与冲洗产道的作用。随着胚胎长大，羊水也相应增多，足月分娩时有 $1000\sim 1500\,\mathrm{ml}$。羊水过少（$300\,\mathrm{ml}$ 以下），易发生羊膜与胎儿粘连，影响正常发育；羊水过多（$2000\,\mathrm{ml}$ 以上），也可影响胎儿正常发育。羊水量不正常，还与某些先天畸形有关，如胎儿无肾或尿道闭锁可致羊水过少；无脑畸形或消化管闭锁可致羊水过多。穿刺抽取羊水，进行细胞染色体检查、DNA 分析或测定羊水中某些物质的含量，可以早期诊断某些先天性异常。

:::definition{label="羊水的保护与临产作用"}
胚胎在羊水中可较自由活动，有利于骨骼和肌肉发育，并防止局部粘连或受外力压迫与震荡。临产时羊水扩张宫颈并冲洗产道。
:::

:::definition{label="足月羊水量"}
足月分娩时羊水约 $1000\sim 1500\,\mathrm{ml}$。过少指 $300\,\mathrm{ml}$ 以下，过多指 $2000\,\mathrm{ml}$ 以上。
:::

:::definition{label="羊水穿刺"}
穿刺抽取羊水，做细胞染色体检查、DNA 分析或测定羊水中某些物质含量，可早期诊断某些先天性异常。
:::

:::compare{title="羊水过少与羊水过多"}
| 项目 | 羊水过少 | 羊水过多 |
|------|----------|----------|
| 界值 | $300\,\mathrm{ml}$ 以下 | $2000\,\mathrm{ml}$ 以上 |
| 机械后果 | 羊膜与胎儿粘连，影响正常发育 | 也可影响胎儿正常发育 |
| 相关畸形 | 胎儿无肾或尿道闭锁 | 无脑畸形或消化管闭锁 |
| 足月正常量 | — | 足月为 $1000\sim 1500\,\mathrm{ml}$，不要把正常当成过多 |
:::

:::cause-effect{title="为什么无肾会少水、无脑或消化管闭锁会多水"}
- 因：胎儿无肾或尿道闭锁，尿液不能进入羊水
- 果：羊水过少（$300\,\mathrm{ml}$ 以下），羊膜易与胎儿粘连
- 因：无脑畸形（吞咽调节障碍）或消化管闭锁（吞咽的羊水不能被吸收）
- 果：羊水过多（$2000\,\mathrm{ml}$ 以上）
- 制约：妊娠中期以后羊水组成已有胎儿排泄物参与，量的异常往往提示胚体侧出了问题
:::

:::pitfall{label="羊膜没有血管，不要把羊水当成母体血液渗出来的"}
羊膜是一层上皮加少量胚外中胚层，内无血管。早期羊水由羊膜分泌和吸收；中期以后才加上胎儿吞咽与排泄。把羊水写成“绒毛间隙的母血漏进羊膜腔”，两套循环和屏障账会并成一句。
:::

:::insight{label="羊水量是一条双向管道：羊膜分泌吸收，胎儿也在喝和排"}
早期几乎只靠羊膜周转；中期以后胎儿吞咽、排尿和脱落上皮加入，羊水才变浑。所以无肾会少、不能吞或吞了出不去会多。把羊水只当成“泡胚体的生理盐水”，穿刺诊断和畸形相关那本账会从一开始就丢掉。
:::

### 3. 卵黄囊

卵黄囊位于原始消化管腹侧（见图 21-19）。鸟类等卵生动物胚胎的卵黄囊贮有大量卵黄，为胚胎发育提供营养。胎生动物（包括人）胚胎的卵黄囊内没有卵黄，其出现也是种系发生和进化过程的重演。人胚胎卵黄囊被包入脐带后，与原始消化管相连的部分相对狭窄，称卵黄蒂。卵黄蒂于第 $6$ 周闭锁，卵黄囊逐渐退化。

:::definition{label="人的卵黄囊"}
人胚胎卵黄囊位于原始消化管腹侧，内没有卵黄。它的出现是种系发生和进化过程的重演，不是为人胚储备卵黄。
:::

:::definition{label="卵黄蒂闭锁"}
卵黄囊被包入脐带后，与原始消化管相连的狭窄段称卵黄蒂。卵黄蒂于第 $6$ 周闭锁，卵黄囊逐渐退化。
:::

:::note{label="人没有卵黄，不要把卵黄囊写成营养仓库"}
鸟类等卵生动物的卵黄囊里确有大量卵黄。人是胎生，营养走绒毛和胎盘。人胚仍出现卵黄囊，是进化重演；第 $6$ 周卵黄蒂闭锁后它逐渐退化。
:::

### 4. 尿囊

尿囊（allantois）是从卵黄囊尾侧向体蒂内伸出的一个盲管，随着胚体尾端的卷折而开口于原始消化管尾段的腹侧（见图 21-19）。当从后者演化出膀胱时，尿囊成为从膀胱顶部至脐内的一条细管，称脐尿管。脐尿管将闭锁，成为脐中韧带。尿囊壁的胚外中胚层形成的尿囊动脉和尿囊静脉，分别演变为脐带内的脐动脉和脐静脉。

:::definition{label="尿囊"}
尿囊（allantois）是从卵黄囊尾侧向体蒂内伸出的盲管。胚体尾端卷折后，它开口于原始消化管尾段的腹侧。
:::

:::definition{label="脐尿管与脐中韧带"}
膀胱从原肠尾段演化出来后，尿囊成为从膀胱顶部至脐内的细管，称脐尿管。脐尿管闭锁，成为脐中韧带。
:::

:::definition{label="尿囊血管的去向"}
尿囊壁胚外中胚层形成尿囊动脉和尿囊静脉，分别演变为脐带内的脐动脉和脐静脉。脐血管的“根”在尿囊壁，不在卵黄囊壁。
:::

:::pitfall{label="脐中韧带来自闭锁的脐尿管，脐血管来自尿囊动静脉"}
尿囊这根盲管后来做了两件事：管腔闭锁成脐中韧带；管壁的胚外中胚层血管改行脐动、静脉。不要把脐中韧带写成“退化的卵黄蒂”，也不要把脐血管写成“卵黄囊血管改名”。
:::

### 5. 脐带

脐带（umbilical cord）是连于胚胎脐部与胎盘间的索状结构（图 21-27）。脐带外覆羊膜，内含黏液性结缔组织。结缔组织内除有闭锁的卵黄囊和脐尿管外，还有脐动脉和脐静脉。脐血管连接胚胎血管和胎盘绒毛血管。脐动脉有两条，因其长于脐带，故呈螺旋状走行。脐动脉将胚胎血液运送至胎盘绒毛血管，与绒毛间隙内的母体血进行物质交换。脐静脉仅有一条，将吸收了丰富营养物质和氧的血液送回胚胎。胎儿出生时，脐带长 $40\sim 60\,\mathrm{cm}$，粗 $1.5\sim 2\,\mathrm{cm}$。脐带过短，胎儿娩出时易引起胎盘过早剥离，造成出血过多；脐带过长，易缠绕胎儿四肢或颈部，可致局部发育不良或胎儿窒息死亡。

:::definition{label="脐带"}
脐带（umbilical cord）连于胚胎脐部与胎盘之间。外覆羊膜，内为黏液性结缔组织，其中有闭锁的卵黄囊、脐尿管，以及脐动脉和脐静脉。
:::

:::definition{label="脐动脉与脐静脉"}
脐动脉两条，长于脐带故呈螺旋状走行，把胚胎血液运至胎盘绒毛血管，与绒毛间隙母体血交换。脐静脉仅一条，把吸收了丰富营养物质和氧的血液送回胚胎。
:::

:::definition{label="脐带的长度"}
出生时脐带长 $40\sim 60\,\mathrm{cm}$，粗 $1.5\sim 2\,\mathrm{cm}$。过短易致胎盘过早剥离、出血过多；过长易缠绕四肢或颈部，可致局部发育不良或窒息死亡。
:::

:::compare{title="卵黄囊、尿囊与脐带里留下的东西"}
| 项目 | 卵黄囊 / 卵黄蒂 | 尿囊 / 脐尿管 | 脐动、静脉 |
|------|-----------------|---------------|------------|
| 起点 | 原始消化管腹侧的卵黄囊 | 卵黄囊尾侧伸入体蒂的盲管 | 尿囊壁胚外中胚层的尿囊动、静脉 |
| 人胚特点 | 无卵黄；卵黄蒂第 $6$ 周闭锁，卵黄囊逐渐退化 | 开口于原肠尾段腹侧；膀胱形成后成脐尿管，再闭锁为脐中韧带 | 两条脐动脉螺旋走行，一条脐静脉返回胚体 |
| 在脐带内 | 闭锁的卵黄囊 | 闭锁的脐尿管 | 连接胚体血管与胎盘绒毛血管 |
:::

:::pitfall{label="脐动脉是两条螺旋，脐静脉是一条；动脉运走的是胚胎侧需要交换的血"}
不要按成体“动脉一定含氧”去记。脐动脉把胚胎血送到绒毛去换，脐静脉把营养和氧送回来。条数也不要记反：动脉两条、静脉一条。把脐带写成“一根动脉一根静脉”，螺旋走行和交换方向都会错。
:::

## （二）胎盘

### 1. 胎盘的结构

胎盘（placenta）是由胎儿的丛密绒毛膜与母体的基蜕膜共同组成的圆盘形结构（图 21-26～图 21-29）。足月胎儿的胎盘重约 $500\,\mathrm{g}$，直径 $15\sim 20\,\mathrm{cm}$，中央厚，周边薄，平均厚约 $2.5\,\mathrm{cm}$。胎盘的胎儿面光滑，覆有羊膜，脐带附于中央或稍偏，透过羊膜可见呈放射状走行的脐血管分支。胎盘的母体面粗糙，为剥脱后的基蜕膜，可见 $15\sim 30$ 个由浅沟分隔的胎盘小叶（cotyledon）。

:::definition{label="胎盘"}
胎盘（placenta）由胎儿的丛密绒毛膜与母体的基蜕膜共同组成，呈圆盘形。它不是纯胎儿器官，也不是纯母体器官。
:::

:::definition{label="足月胎盘的外形"}
重约 $500\,\mathrm{g}$，直径 $15\sim 20\,\mathrm{cm}$，中央厚、周边薄，平均厚约 $2.5\,\mathrm{cm}$。
:::

:::definition{label="胎盘的胎儿面与母体面"}
胎儿面光滑，覆有羊膜，脐带附于中央或稍偏，透过羊膜可见放射状脐血管分支。母体面粗糙，为剥脱后的基蜕膜，可见 $15\sim 30$ 个由浅沟分隔的胎盘小叶（cotyledon）。
:::

::figure{src="/images/histology/textbook/p0238_01.png" caption="图21-27 胎盘。A. 胎儿面：光滑，覆羊膜，脐带（1）附着，血管呈放射状走行；B. 母体面：粗糙，可见胎盘小叶（2），边缘为羊膜（3）。" alt="实物标本两面：A 暗红光滑面有脐带和放射状血管，B 分叶状粗糙面为胎盘小叶"}

在胎盘垂直切面上，可见羊膜下方为绒毛膜的结缔组织，脐血管的分支走行其中。绒毛膜板发出 $40\sim 60$ 根绒毛干，绒毛干又发出许多细小绒毛，绒毛干的末端以细胞滋养层壳固着于基蜕膜。脐血管的分支沿绒毛干进入绒毛内，形成毛细血管。绒毛干之间为绒毛间隙，有基蜕膜构成的短隔伸入其内，称胎盘隔（placental septum）。胎盘隔将胎盘分隔为 $15\sim 30$ 个胎盘小叶，每个小叶含 $1\sim 4$ 根绒毛干及其分支。子宫螺旋动脉与子宫静脉的分支开口于绒毛间隙，故绒毛间隙内充满母体血液，绒毛浸泡其中。

:::definition{label="绒毛干与胎盘小叶"}
绒毛膜板发出 $40\sim 60$ 根绒毛干，末端以细胞滋养层壳固着于基蜕膜。基蜕膜构成的胎盘隔（placental septum）伸入绒毛间隙，把胎盘分成 $15\sim 30$ 个小叶；每个小叶含 $1\sim 4$ 根绒毛干及其分支。
:::

:::definition{label="绒毛间隙里的血"}
子宫螺旋动脉与子宫静脉的分支开口于绒毛间隙，故间隙内充满母体血液，绒毛浸泡其中。这是母体循环在胎盘内的开放池，不是胎儿血管。
:::

::figure{src="/images/histology/textbook/p0239_01.png" caption="图21-28 胎盘模式图。A. 羊膜面观：脐带、羊膜、绒毛膜板及呈放射状的绒毛膜血管；B. 子宫蜕膜面观：胎盘小叶；剖开处示去掉基蜕膜后的胎盘小叶内部。" alt="圆盘两面模式：A 浅蓝色羊膜面中央连脐带，B 粉红色母体面分叶，剖开见绿色绒毛"}

### 2. 胎盘的血液循环和胎盘屏障

胎盘内有母体和胎儿两套血液循环系统。母体动脉血从子宫螺旋动脉流入绒毛间隙，在此与绒毛内毛细血管的胎儿血进行物质交换后，再经子宫静脉流回母体。胎儿静脉性质的血经脐动脉及其分支流入绒毛内毛细血管，与绒毛间隙内的母体血进行物质交换，从而成为动脉性质的血，后经脐静脉回流到胎儿。母体和胎儿的血液在各自的封闭管道内循环，互不相混，但可进行物质交换。

胎儿血与母体血在胎盘内进行物质交换所通过的结构，称胎盘屏障（placental barrier）或胎盘膜（placental membrane）。早期胎盘膜由合体滋养层、细胞滋养层和基膜、薄层绒毛结缔组织及毛细血管基膜和内皮组成。发育后期，由于细胞滋养层在许多部位消失，以及合体滋养层在一些部位仅为一薄层细胞质，故胎盘屏障变薄，胎儿血与母体血间仅隔以绒毛毛细血管内皮和薄层合体滋养层及两者的基膜，更有利于物质交换（见图 21-24、图 21-29）。

:::definition{label="胎盘两套循环"}
母体：子宫螺旋动脉 → 绒毛间隙 → 子宫静脉。胎儿：脐动脉（静脉性质的血）→ 绒毛内毛细血管 → 脐静脉（动脉性质的血）。两套血在各自管道内循环，互不相混，但可交换物质。
:::

:::definition{label="胎盘屏障"}
胎盘屏障（placental barrier）又称胎盘膜（placental membrane），是胎儿血与母体血进行物质交换所通过的结构。两套血并不直接相混。
:::

:::definition{label="早期胎盘膜"}
早期由合体滋养层、细胞滋养层和基膜、薄层绒毛结缔组织及毛细血管基膜和内皮组成。层数多，屏障较厚。
:::

:::definition{label="后期变薄的胎盘膜"}
后期细胞滋养层在许多部位消失，合体滋养层在一些部位仅为一薄层细胞质，故屏障变薄：胎儿血与母体血间仅隔以绒毛毛细血管内皮、薄层合体滋养层及两者的基膜，更有利于物质交换。
:::

::figure{src="/images/histology/textbook/p0239_02.png" caption="图21-29 胎盘的结构与血液循环模式图。箭头示血流方向；红色示富含营养和氧的血；蓝色示含代谢产物和二氧化碳的血。示羊膜、平滑绒毛膜、壁蜕膜、丛密绒毛膜、绒毛间隙、绒毛干、胎盘隔、基蜕膜、子宫螺旋动脉与子宫静脉、细胞滋养层壳；脐静脉与脐动脉在绒毛内分支。" alt="子宫壁弧形切面：母体螺旋动脉开口于绒毛间隙，绒毛树内蓝红血管分别连脐动脉与脐静脉"}

:::concept{term="先问血在绒毛内还是在绒毛间隙，再问隔着几层膜"}
看见“胎盘里的血”，先切开两套循环：绒毛间隙里的是母体血，来自子宫螺旋动脉；绒毛毛细血管里的是胎儿血，来自脐动脉。二者不相混。再问屏障：早期要数合体滋养层、细胞滋养层和基膜、绒毛结缔组织、毛细血管基膜和内皮；后期细胞滋养层多处消失，往往只剩薄层合体滋养层、绒毛毛细血管内皮和两者基膜。把间隙里的母血听成“已经进了胎儿血管”，或把后期屏障仍写成“五层俱全”，交换账会对错年代。
:::

| 交换地点 | 绒毛间隙（母血浸泡绒毛） | 绒毛内毛细血管（隔着胎盘膜） |
| 出 | 子宫静脉流回母体 | 换成动脉性质的血，经脐静脉回胎儿 |

:::

|------|------|------|
| 层次 | 合体滋养层 + 细胞滋养层和基膜 + 薄层绒毛结缔组织 + 毛细血管基膜和内皮 | 绒毛毛细血管内皮 + 薄层合体滋养层 + 两者的基膜 |

:::

:::pitfall{label="两套血不相混，绒毛间隙里流的是母血不是胎儿血"}
母体血在间隙里浸泡绒毛，胎儿血关在绒毛毛细血管里。交换隔着胎盘膜，不是“母血灌进脐静脉”。脐动脉里是静脉性质的血、脐静脉里是动脉性质的血，和成体动脉静脉的含氧习惯正好对调。
:::

### 3. 胎盘的功能

#### （1）物质交换

胎儿通过胎盘从母体血中获得营养物质和 $\mathrm{O}_2$，排出代谢产物和 $\mathrm{CO}_2$。因此胎盘具有相当于成体的小肠、肺和肾的功能。母体血中的免疫球蛋白 G 可通过胎盘膜进入胎儿，使胎儿及新生儿具备一定的免疫力。由于某些药物、病毒和激素可以通过胎盘膜，影响胎儿发育，故孕妇用药需慎重，并应预防感染。

:::definition{label="胎盘的物质交换"}
胎儿经胎盘从母体血获得营养物质和 $\mathrm{O}_2$，排出代谢产物和 $\mathrm{CO}_2$。相当于成体小肠、肺和肾的功能。
:::

:::definition{label="IgG 与可通过屏障的物质"}
母体血中的免疫球蛋白 G 可通过胎盘膜进入胎儿，使胎儿及新生儿具备一定免疫力。某些药物、病毒和激素也能通过胎盘膜，影响胎儿发育，故孕妇用药需慎重，并应预防感染。
:::

#### （2）内分泌功能

胎盘的合体滋养层能分泌数种激素，对维持妊娠起重要作用。主要为：①人绒毛膜促性腺激素（human chorionic gonadotropin，hCG），作用类似黄体生成素，能促进母体黄体的生长发育，以维持妊娠。hCG 在妊娠第 $2$ 周开始分泌，第 $8$ 周达高峰，以后逐渐下降。hCG 可经孕妇尿液检出，因此可用来检测早孕。②人胎盘催乳素（human placental lactogen），既能促使母体乳腺生长发育，又可促进胎儿的生长发育。人胎盘催乳素于妊娠第 $2$ 个月开始分泌，第 $8$ 个月达高峰，直到分娩。③孕激素和雌激素，于妊娠第 $4$ 个月开始分泌，以后逐渐增多。母体的卵巢黄体退化后，胎盘的这两种激素起着继续维持妊娠的作用。高水平的雌激素和孕激素具有免疫抑制作用，据认为这是母体免疫系统不会排斥具有抗原性的胚胎的重要原因。

:::definition{label="hCG"}
人绒毛膜促性腺激素（human chorionic gonadotropin，hCG）由合体滋养层分泌，作用类似黄体生成素，促进母体黄体生长发育以维持妊娠。妊娠第 $2$ 周开始分泌，第 $8$ 周达高峰，以后逐渐下降。可经孕妇尿液检出，用于检测早孕。
:::

:::definition{label="人胎盘催乳素"}
人胎盘催乳素（human placental lactogen）促使母体乳腺生长发育，并促进胎儿生长发育。妊娠第 $2$ 个月开始分泌，第 $8$ 个月达高峰，直到分娩。
:::

:::definition{label="胎盘的孕激素和雌激素"}
妊娠第 $4$ 个月开始分泌，以后逐渐增多。卵巢黄体退化后，由它们继续维持妊娠。高水平雌激素和孕激素具有免疫抑制作用，被认为是母体免疫系统不排斥具有抗原性胚胎的重要原因。
:::

:::compare{title="胎盘合体滋养层分泌的主要激素"}
| 激素 | 开始 | 高峰 / 此后 | 作用 |
|------|------|-------------|------|
| hCG | 妊娠第 $2$ 周 | 第 $8$ 周达高峰，以后逐渐下降 | 类似黄体生成素，促母体黄体生长以维持妊娠；尿检早孕 |
| 人胎盘催乳素 | 妊娠第 $2$ 个月 | 第 $8$ 个月达高峰，直到分娩 | 促母体乳腺发育；促胎儿生长发育 |

:::

:::timeline{period="胎膜与胎盘的关键时间"}
- **植入完成后** 滋养层分细胞滋养层与合体滋养层；初级绒毛干出现
- **第3周** 胚外中胚层伸入，次级绒毛干；随后血管分化并与胚体相通，成三级绒毛干
- **妊娠第2周** 合体滋养层开始分泌 hCG（尿检早孕的基础）
- **第6周** 卵黄蒂闭锁，卵黄囊逐渐退化
- **第8周** hCG 达高峰
- **妊娠第2个月** 人胎盘催乳素开始分泌
- **妊娠第4个月** 胎盘开始分泌孕激素和雌激素
- **第8个月** 人胎盘催乳素达高峰，直到分娩
- **足月** 羊水 1000～1500 ml；脐带长 40～60 cm、粗 1.5～2 cm；胎盘约 500 g
:::

:::insight{label="合体滋养层既是屏障的最外层，也是激素工厂"}
同一层细胞对着绒毛间隙的母血：早期它是胎盘膜的第一道，后来变薄仍隔开两套血；同时分泌 hCG、人胎盘催乳素、孕激素和雌激素。把屏障和内分泌写成两个器官，尿检早孕和“黄体退化后谁维持妊娠”会对不上。
:::

:::pitfall{label="hCG 第8周已经过峰，不要把尿检早孕的高峰当成整个孕期都在升"}
hCG 第 $2$ 周起、第 $8$ 周峰、以后下降。人胎盘催乳素是第 $2$ 个月起、第 $8$ 个月峰。孕激素和雌激素从第 $4$ 个月才由胎盘担纲。三套时钟不要并成“胎盘一开始就大量分泌所有激素”。
:::

:::keypoint{label="胎膜五件套，胎盘=丛密绒毛膜+基蜕膜，两套血不相混"}
- 胎膜 = 绒毛膜、羊膜、卵黄囊、尿囊、脐带；娩出后与胎盘合称衣胞。
- 绒毛干：初级（无中胚层）→ 次级（胚外中胚层伸入）→ 三级（血管与胚体相通）；末端细胞滋养层壳固着蜕膜。
- 包蜕膜侧→平滑绒毛膜；基蜕膜侧→丛密绒毛膜，与基蜕膜组成胎盘。
- 羊膜无血管；足月羊水 $1000\sim 1500\,\mathrm{ml}$；过少 $<300$（无肾/尿道闭锁），过多 $>2000$（无脑/消化管闭锁）。
- 人卵黄囊无卵黄；卵黄蒂第 $6$ 周闭锁。尿囊→脐尿管→脐中韧带；尿囊动静脉→脐动静脉。
- 脐带 $40\sim 60\,\mathrm{cm}$，粗 $1.5\sim 2\,\mathrm{cm}$；两条螺旋脐动脉 + 一条脐静脉。
- 足月胎盘约 $500\,\mathrm{g}$，直径 $15\sim 20\,\mathrm{cm}$，厚约 $2.5\,\mathrm{cm}$；$15\sim 30$ 个小叶；$40\sim 60$ 根绒毛干。
- 母血在绒毛间隙，胎血在绒毛内，隔着胎盘屏障，后期变薄。
- 合体滋养层分泌 hCG（第 $2$ 周起、第 $8$ 周峰，尿检早孕）、人胎盘催乳素、孕激素和雌激素（第 $4$ 个月起维持妊娠、免疫抑制）。
:::

:::memory{label="本节必背要点"}
- [ ] 胎膜和胎盘是保护、营养、呼吸、排泄等附属结构，不参与胚胎本体形成；有的有内分泌功能。
- [ ] 胎儿娩出后，胎膜、胎盘与子宫壁分离并排出，总称衣胞（afterbirth）。
- [ ] 胎膜（fetal membrane）包括绒毛膜、羊膜、卵黄囊、尿囊和脐带。
- [ ] 绒毛膜（chorion）由绒毛膜板、各级绒毛干及绒毛组成。
- [ ] 绒毛膜板（chorionic plate）由滋养层和衬于其内面的胚外中胚层组成。
- [ ] 初级绒毛干（primary stem villus）：细胞滋养层局部增殖伸入合体滋养层，两者共同形成绒毛状突起。
- [ ] 第 $3$ 周胚外中胚层伸入绒毛干内，改称次级绒毛干（secondary stem villus）。
- [ ] 干心间充质分化为结缔组织和血管并与胚体血管相通，改称三级绒毛干（tertiary stem villus）。
- [ ] 各级绒毛干表面发出分支，形成许多细小绒毛。
- [ ] 绒毛干末端细胞滋养层穿出合体滋养层，伸抵蜕膜，将绒毛干固着；并沿蜕膜扩展连接，形成细胞滋养层壳。
- [ ] 原滋养层陷窝演变为绒毛间隙，充满来自子宫螺旋动脉的母体血，绒毛浸浴其中。
- [ ] 胚胎早期整个绒毛膜表面绒毛均匀分布。
- [ ] 包蜕膜侧血供匮乏，绒毛退化消失，形成平滑绒毛膜（chorion leave）。
- [ ] 基蜕膜侧血供充足，绒毛反复分支生长茂密，称丛密绒毛膜（chorion frondosum），与基蜕膜组成胎盘。
- [ ] 丛密绒毛膜内血管通过脐带与胚体血管通连。
- [ ] 羊膜、平滑绒毛膜和包蜕膜凸向子宫腔，最终与壁蜕膜融合，子宫腔消失。
- [ ] 绒毛膜血管发育不良或与胚体血管未通连，胚胎可因缺乏营养而发育迟缓或死亡。
- [ ] 滋养层细胞过度增生，绒毛内结缔组织变性水肿、血管消失，绒毛呈葡萄或水泡状，称葡萄胎或水泡状胎块。
- [ ] 滋养层细胞癌变称绒毛膜癌。
- [ ] 羊膜（amnion）为半透明薄膜，由一层羊膜上皮和少量胚外中胚层构成，内无血管。
- [ ] 羊膜腔内充满羊水（amniotic fluid），胚胎浸泡其中。
- [ ] 羊膜最初附着于胚盘边缘，与外胚层连续；腹侧包裹体蒂形成脐带。
- [ ] 羊膜腔扩大使羊膜与绒毛膜相贴，胚外体腔消失。
- [ ] 妊娠早期羊水无色透明，由羊膜不断分泌和吸收。
- [ ] 妊娠中期以后胎儿吞咽羊水，消化、泌尿排泄物及脱落上皮进入，羊水变浑浊。
- [ ] 羊水使胚胎可较自由活动，利于骨骼和肌肉发育，防止局部粘连或受压迫与震荡。
- [ ] 临产时羊水扩张宫颈并冲洗产道。
- [ ] 足月羊水 $1000\sim 1500\,\mathrm{ml}$。
- [ ] 羊水过少（$300\,\mathrm{ml}$ 以下）易羊膜与胎儿粘连；羊水过多（$2000\,\mathrm{ml}$ 以上）也可影响发育。
- [ ] 胎儿无肾或尿道闭锁可致羊水过少；无脑畸形或消化管闭锁可致羊水过多。
- [ ] 羊水穿刺可做染色体检查、DNA 分析或测定某些物质，早期诊断先天性异常。
- [ ] 人卵黄囊内没有卵黄，其出现是种系发生和进化的重演。
- [ ] 卵黄蒂于第 $6$ 周闭锁，卵黄囊逐渐退化。
- [ ] 尿囊（allantois）是从卵黄囊尾侧向体蒂内伸出的盲管，卷折后开口于原始消化管尾段腹侧。
- [ ] 膀胱形成后，尿囊成为从膀胱顶部至脐内的脐尿管；脐尿管闭锁成为脐中韧带。
- [ ] 尿囊动脉和尿囊静脉分别演变为脐动脉和脐静脉。
- [ ] 脐带（umbilical cord）连于胚胎脐部与胎盘之间；外覆羊膜，内含黏液性结缔组织。
- [ ] 脐带内有闭锁的卵黄囊和脐尿管，以及脐动脉、脐静脉。
- [ ] 脐动脉两条，长于脐带故呈螺旋状，将胚胎血运至胎盘绒毛血管。
- [ ] 脐静脉一条，将富含营养物质和氧的血液送回胚胎。
- [ ] 出生时脐带长 $40\sim 60\,\mathrm{cm}$，粗 $1.5\sim 2\,\mathrm{cm}$。
- [ ] 脐带过短易致胎盘过早剥离、出血过多；过长易缠绕四肢或颈部，可致局部发育不良或窒息。
- [ ] 胎盘（placenta）由胎儿丛密绒毛膜与母体基蜕膜共同组成。
- [ ] 足月胎盘重约 $500\,\mathrm{g}$，直径 $15\sim 20\,\mathrm{cm}$，中央厚周边薄，平均厚约 $2.5\,\mathrm{cm}$。
- [ ] 胎儿面光滑，覆羊膜，脐带附于中央或稍偏，透过羊膜可见放射状脐血管分支。
- [ ] 母体面粗糙，为剥脱后的基蜕膜，可见 $15\sim 30$ 个胎盘小叶（cotyledon）。
- [ ] 绒毛膜板发出 $40\sim 60$ 根绒毛干，末端以细胞滋养层壳固着于基蜕膜。
- [ ] 胎盘隔（placental septum）由基蜕膜构成，伸入绒毛间隙，将胎盘分为 $15\sim 30$ 个小叶；每小叶含 $1\sim 4$ 根绒毛干及其分支。
- [ ] 子宫螺旋动脉与子宫静脉分支开口于绒毛间隙，间隙内充满母体血。
- [ ] 母体动脉血：子宫螺旋动脉 → 绒毛间隙 → 子宫静脉。
- [ ] 胎儿静脉性质的血：脐动脉 → 绒毛内毛细血管 → 交换后成动脉性质的血 → 脐静脉回胎儿。
- [ ] 母体血与胎儿血在各自封闭管道内循环，互不相混，但可物质交换。
- [ ] 胎盘屏障（placental barrier）又称胎盘膜（placental membrane）。
- [ ] 早期胎盘膜：合体滋养层、细胞滋养层和基膜、薄层绒毛结缔组织及毛细血管基膜和内皮。
- [ ] 后期细胞滋养层许多部位消失，合体滋养层一些部位仅为一薄层细胞质，屏障变薄，仅隔以绒毛毛细血管内皮、薄层合体滋养层及两者基膜。
- [ ] 胎盘相当于成体小肠、肺和肾的功能。
- [ ] 母体免疫球蛋白 G 可通过胎盘膜进入胎儿。
- [ ] 某些药物、病毒和激素可通过胎盘膜，孕妇用药需慎重并应预防感染。
- [ ] 合体滋养层分泌 hCG、人胎盘催乳素、孕激素和雌激素。
- [ ] hCG 作用类似黄体生成素，促母体黄体生长以维持妊娠；第 $2$ 周开始，第 $8$ 周高峰，以后下降；可经尿检出，用于早孕检测。
- [ ] 人胎盘催乳素促母体乳腺和胎儿生长发育；第 $2$ 个月开始，第 $8$ 个月高峰，直到分娩。
- [ ] 孕激素和雌激素于第 $4$ 个月开始分泌并逐渐增多；黄体退化后由它们维持妊娠。
- [ ] 高水平雌激素和孕激素具免疫抑制，被认为是母体不排斥具抗原性胚胎的重要原因。
:::
