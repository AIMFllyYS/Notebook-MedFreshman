# 三、肝

上一节把胰腺的腺泡酶原颗粒和胰岛 A/B/D/PP 摊开。肝是人体最大的腺体，具有极复杂多样的生物化学功能，被称为机体的化工厂。肝产生的胆汁作为消化液参与脂类食物消化；肝合成多种蛋白质等多类物质，直接分泌入血；肝还参与糖、脂类、激素和药物等代谢。

:::definition{label="肝"}
肝是人体最大的腺体，具有极复杂多样的生物化学功能，被称为机体的化工厂。胆汁作为消化液参与脂类食物消化；多种蛋白质等直接分泌入血；并参与糖、脂类、激素和药物等代谢。
:::

:::concept{term="先问这一笔产物走胆管还是入血：胆汁对外，血浆蛋白对内"}
肝同时做外分泌和“入血工厂”。胆汁经胆小管→闰管（黑林管）→小叶间胆管出肝，管脂类消化；白蛋白、纤维蛋白原等由粗面内质网造好，经血窦面进血浆。把肝听成“只造胆汁的消化腺”，血浆蛋白、生物转化和糖代谢三本账会从第一句漏掉。
:::

肝表面覆以致密结缔组织被膜，除在肝下面各沟、窝处以及右叶上面后部为纤维膜外，其余均被覆浆膜。肝门部的结缔组织随门静脉、肝动脉和肝管的分支伸入肝实质，将实质分成许多肝小叶。肝小叶之间各种管道密集的部位为门管区。

:::definition{label="肝被膜"}
肝表面覆以致密结缔组织被膜。除在肝下面各沟、窝处以及右叶上面后部为纤维膜外，其余均被覆浆膜。
:::

:::definition{label="肝实质的划分"}
肝门部的结缔组织随门静脉、肝动脉和肝管的分支伸入肝实质，将实质分成许多肝小叶。肝小叶之间各种管道密集的部位为门管区。
:::

:::compare{title="肝小叶与门管区"}
| 项目 | 肝小叶 | 门管区 |
|------|--------|--------|
| 英文 | hepatic lobule | portal area |
| 位置 | 肝的基本结构单位 | 相邻肝小叶之间的三角形或椭圆形结缔组织小区 |
| 中心结构 | 中央静脉沿长轴走行 | 无中央静脉 |
| 管道三件套 | 无门静脉、肝动脉、胆管主干；周边借血窦与门管区相通 | 小叶间静脉、小叶间动脉、小叶间胆管（门管区三件套） |
| 实质成分 | 放射状肝板（肝索）、肝血窦、胆小管 | 结缔组织 + 三种管道；还含淋巴管和神经纤维 |
| 每个小叶 | 一个中央静脉 | 周围一般有 $3\sim 5$ 个门管区 |
| 血流方向 | 周边血窦 → 中央静脉 | 小叶间动、静脉注入血窦 |
| 胆汁方向 | 胆小管由中央流向周边 | 小叶间胆管向肝门汇集 |
| 人与猪 | 人小叶间结缔组织很少，分界不清 | 猪小叶周围结缔组织多，分界明显 |
:::

## （一）肝小叶

肝小叶（hepatic lobule）是肝的基本结构单位，呈多角棱柱体，长约 $2\,\mathrm{mm}$，宽约 $1\,\mathrm{mm}$，成人肝有 $50$ 万～$100$ 万个肝小叶。有的动物（如猪）肝小叶因周围结缔组织较多而分界明显，人的肝小叶间结缔组织很少，相邻肝小叶常连成一片，分界不清（图 15-7）。肝小叶中央有一条沿其长轴走行的中央静脉（central vein），周围是大致呈放射状排列的肝索和肝血窦（图 15-7，图 15-8）。

:::definition{label="肝小叶"}
肝小叶（hepatic lobule）是肝的基本结构单位，呈多角棱柱体，长约 $2\,\mathrm{mm}$，宽约 $1\,\mathrm{mm}$。成人肝有 $50$ 万～$100$ 万个肝小叶。中央有一条沿长轴走行的中央静脉，周围是大致呈放射状排列的肝索和肝血窦。
:::

:::definition{label="中央静脉"}
中央静脉（central vein）沿肝小叶长轴走行，接受肝血窦的血液。它在小叶中央，不是门管区里那条管腔大而不规则的小叶间静脉。
:::

:::pitfall{label="人的肝小叶分界不清，不要把猪肝那种结缔组织隔当作人肝通例"}
猪肝小叶周围结缔组织多，横切面像一块块清楚的六角砖（图 15-7 左）。人的小叶间结缔组织很少，相邻肝小叶常连成一片（图 15-7 右）。认人肝小叶，靠中央静脉和放射状肝索，不要等一条厚结缔组织墙。
:::

肝细胞单层排列成凹凸不平的板状结构称肝板（hepatic plate）。相邻肝板吻合连接，形成迷路样结构，其切面呈索状，故也称肝索（hepatic cord）。在肝小叶周边的一层环形肝板，称为界板（limiting plate）。肝板之间为肝血窦，经肝板上的孔互相通连。肝细胞相邻面的质膜局部凹陷，形成微细的胆小管。肝板、肝血窦和胆小管在肝小叶内形成各自独立而又密切相关的复杂网络（图 15-9，图 15-10）。

:::definition{label="肝板"}
肝板（hepatic plate）是肝细胞单层排列成的凹凸不平的板状结构。相邻肝板吻合连接，形成迷路样结构。
:::

:::definition{label="肝索"}
肝索（hepatic cord）是肝板的切面观：迷路样肝板被切成索状，故也称肝索。光镜下放射状排列的“索”，三维上是板。
:::

:::definition{label="界板"}
界板（limiting plate）是肝小叶周边的一层环形肝板，把小叶实质与门管区隔开。
:::

:::definition{label="肝小叶内三套网络"}
肝板、肝血窦和胆小管在肝小叶内形成各自独立而又密切相关的复杂网络。血窦走血浆，胆小管走胆汁，两套管道不相通；物质交换发生在窦周隙。
:::

:::concept{term="先问切面是索、立体是板：肝索就是肝板的切片名"}
三维上肝细胞铺成凹凸的板，板上有孔，血窦经孔相通。切片把板切成一条条索，所以叫肝索。把肝索听成“一列独立的细胞绳子”，界板、迷路吻合和血窦通连都会变成平面游戏。先立板，再看切面。
:::

### 1. 肝细胞

肝细胞（hepatocyte）占肝内细胞总数的 $80\%$。肝细胞呈多面体形，直径 $15\sim 30\,\mu\mathrm{m}$。肝细胞有 3 种不同的功能面，即血窦面、细胞连接面和胆小管面（图 15-11，图 15-12）。血窦面和胆小管面有发达的微绒毛，使细胞表面积增大，有利于进行物质交换。相邻肝细胞之间的连接面有紧密连接、桥粒和缝隙连接等结构，有的肝细胞之间还有贯通的细胞间通道。

:::definition{label="肝细胞"}
肝细胞（hepatocyte）占肝内细胞总数的 $80\%$，呈多面体形，直径 $15\sim 30\,\mu\mathrm{m}$。有 3 种不同的功能面：血窦面、细胞连接面和胆小管面。
:::

:::definition{label="肝细胞的三种功能面"}
血窦面和胆小管面有发达的微绒毛，增大表面积以利于物质交换。相邻肝细胞的连接面有紧密连接、桥粒和缝隙连接；有的肝细胞之间还有贯通的细胞间通道。
:::

:::note{label="肝细胞三面各管什么"}
| 功能面 | 朝向 | 特化 | 职分 |
|--------|------|------|------|
| 血窦面 | 窦周隙 / 肝血窦 | 发达微绒毛，浸于血浆 | 与血液物质交换；分泌血浆蛋白 |
| 胆小管面 | 胆小管 | 发达微绒毛 | 分泌胆汁 |
| 细胞连接面 | 相邻肝细胞 | 紧密连接、桥粒、缝隙连接；可有细胞间通道 | 封闭胆小管、细胞间通讯 |
:::

肝细胞核大而圆，常染色质丰富，有 1 个至数个核仁，双核细胞较多。肝的特点之一是多倍体肝细胞数量多，成人肝的 4 倍体肝细胞占 $60\%$ 以上，这可能与肝细胞长期保持活跃状态有关，而且很可能与肝潜在的强大再生能力相关。肝细胞的细胞质呈嗜酸性，含有弥散分布的嗜碱性团块。电镜下，细胞质内各种细胞器均丰富（图 15-11～图 15-14）。

:::definition{label="肝细胞的核与多倍体"}
肝细胞核大而圆，常染色质丰富，有 1 个至数个核仁，双核细胞较多。成人肝的 4 倍体肝细胞占 $60\%$ 以上。多倍体数量多，可能与肝细胞长期保持活跃状态有关，也很可能与肝潜在的强大再生能力相关。
:::

:::definition{label="肝细胞胞质"}
肝细胞胞质呈嗜酸性，含有弥散分布的嗜碱性团块。电镜下各种细胞器均丰富。嗜碱性团块对应成群的粗面内质网。
:::

::figure{src="/images/histology/textbook/p0178_03.png" caption="图15-11 肝细胞、肝血窦、窦周隙及胆小管结构模式图。示肝巨噬细胞、内皮细胞、贮脂细胞、网状纤维、窦周隙、微绒毛、胆小管及肝细胞内细胞器。" alt="肝细胞超微模式：血窦面微绒毛伸入窦周隙，胆小管面有连接复合体，胞质含粗面/滑面内质网和高尔基复合体"}

**（1）粗面内质网** 呈板层状排列成群，合成多种重要的血浆蛋白，包括白蛋白、纤维蛋白原、凝血酶原、脂蛋白和补体等。

:::definition{label="肝细胞粗面内质网"}
粗面内质网呈板层状排列成群，合成多种重要的血浆蛋白，包括白蛋白、纤维蛋白原、凝血酶原、脂蛋白和补体等。光镜下弥散的嗜碱性团块就是这叠粗面内质网。
:::

**（2）滑面内质网** 为许多散在的小管和小泡，其膜上有多种酶系规律地分布，如氧化还原酶、水解酶、转移酶、合成酶等。肝细胞摄取的有机物在滑面内质网进行连续的合成、分解、结合和转化等反应，包括胆汁合成、脂类代谢、糖代谢和激素代谢，以及从肠道吸收的有机异物（如药物、腐败产物等）的生物转化。

:::definition{label="肝细胞滑面内质网"}
滑面内质网为许多散在的小管和小泡，膜上规律分布氧化还原酶、水解酶、转移酶、合成酶等。肝细胞摄取的有机物在此进行连续的合成、分解、结合和转化，包括胆汁合成、脂类代谢、糖代谢和激素代谢，以及对药物、腐败产物等有机异物的生物转化。
:::

**（3）高尔基复合体** 从粗面内质网合成的蛋白质和脂蛋白中，一部分转移至高尔基复合体加工后，再经分泌小泡由肝细胞血窦面排出。近胆小管处的高尔基复合体尤为发达，参与胆汁的分泌。

:::definition{label="肝细胞高尔基复合体"}
粗面内质网合成的蛋白质和脂蛋白，一部分经高尔基复合体加工后，由分泌小泡从肝细胞血窦面排出。近胆小管处的高尔基复合体尤为发达，参与胆汁的分泌。
:::

此外，肝细胞富含线粒体、溶酶体和过氧化物酶体，以及糖原、脂滴、色素等内含物（图 15-15）。内含物的数量因机体的生理和病理状况不同而异。进食后糖原增多，饥饿时糖原减少；正常时脂滴少，肝病时脂滴可增多。

:::definition{label="肝细胞内含物"}
肝细胞富含线粒体、溶酶体和过氧化物酶体，以及糖原、脂滴、色素等内含物。数量随生理和病理状况而异：进食后糖原增多，饥饿时糖原减少；正常时脂滴少，肝病时脂滴可增多。
:::

:::insight{label="同一枚肝细胞，血窦面出蛋白、胆小管面出胆汁、滑面内质网做转化"}
粗面内质网造血浆蛋白，高尔基复合体加工后从血窦面入血；近胆小管的高尔基复合体参与胆汁分泌；滑面内质网把胆红素、药物和激素写进转化账。三面加上两套内质网，才撑得起“化工厂”这个称呼。把肝细胞只记成“多角形嗜酸细胞”，三面账和酶系账都会塌成形态学空话。
:::

### 2. 肝血窦

肝血窦（hepatic sinusoid）位于肝板之间，腔大而不规则，窦壁由内皮细胞围成。含各种肠道吸收物的门静脉血液和含氧的肝动脉血液，通过在门管区的小叶间动脉和小叶间静脉注入肝血窦，由于在血窦内血流缓慢，血浆得以与肝细胞进行充分的物质交换，然后汇入中央静脉（图 15-16）。

:::definition{label="肝血窦"}
肝血窦（hepatic sinusoid）位于肝板之间，腔大而不规则，窦壁由内皮细胞围成。门静脉血（肠道吸收物）和肝动脉血（含氧）经小叶间动脉、小叶间静脉注入；血流缓慢，血浆与肝细胞充分交换后汇入中央静脉。
:::

::figure{src="/images/histology/textbook/p0179_03.png" caption="图15-16 肝内血管光镜图（肝血管卡红明胶灌注法）。示自周边汇入中央的放射状血窦。" alt="肝血管灌注：血窦呈放射状汇入各小叶中央静脉"}

肝血窦内皮细胞有大量内皮窗孔，其大小不等，无隔膜，直径多为 $0.1\,\mu\mathrm{m}$ 左右，大的可达 $1\sim 2\,\mu\mathrm{m}$（见图 15-11，图 15-17）。内皮细胞连接松散，细胞间隙宽。内皮外无基膜，仅有少量网状纤维附着。因此肝血窦内皮具有很高的通透性，除血细胞和乳糜微粒外，血浆各种成分均可进入窦周隙。

:::definition{label="肝血窦内皮"}
肝血窦内皮有大量无隔膜的窗孔，直径多为 $0.1\,\mu\mathrm{m}$ 左右，大的可达 $1\sim 2\,\mu\mathrm{m}$。内皮细胞连接松散，细胞间隙宽；内皮外无基膜，仅有少量网状纤维附着。通透性很高：除血细胞和乳糜微粒外，血浆各种成分均可进入窦周隙。
:::

:::pitfall{label="肝血窦内皮无基膜、窗孔无隔膜，不要写成普通连续毛细血管"}
普通毛细血管有完整基膜，窗孔常有隔膜。肝血窦把这两道门槛拆掉，血浆才能灌进窦周隙去浸泡肝细胞微绒毛。血细胞和乳糜微粒仍留在窦腔。把肝血窦听成“就是毛细血管变粗”，物质交换账会停在内皮外面。
:::

肝血窦内有定居的肝巨噬细胞（hepatic macrophage）（见图 15-11～图 15-13，图 15-17，图 15-18），又称库普弗细胞（Kupffer cell），其形态不规则，细胞质呈嗜酸性。细胞表面有大量皱褶和微绒毛，并以板状和丝状伪足附着在内皮细胞上，或穿过内皮窗孔和细胞间隙伸入窦周隙。细胞质内有发达的溶酶体，并常见吞噬体和吞饮泡。肝巨噬细胞由血液单核细胞分化而来，在清除从门静脉入肝的抗原异物、衰老的血细胞和监视肿瘤等方面均发挥重要作用。

:::definition{label="肝巨噬细胞"}
肝巨噬细胞（hepatic macrophage）又称库普弗细胞（Kupffer cell），定居在肝血窦内。形态不规则，胞质嗜酸性；表面有大量皱褶和微绒毛，以板状和丝状伪足附着于内皮，或穿过窗孔和细胞间隙伸入窦周隙。胞质内溶酶体发达，常见吞噬体和吞饮泡。由血液单核细胞分化而来。
:::

:::definition{label="肝巨噬细胞的功能"}
肝巨噬细胞清除从门静脉入肝的抗原异物、衰老的血细胞，并在监视肿瘤等方面发挥重要作用。门静脉血先过这一层吞噬，再与肝细胞交换。
:::

肝血窦内还有较多 NK 细胞，称肝内大颗粒淋巴细胞（hepatic large granular lymphocyte），附着在内皮细胞或肝巨噬细胞上。其核呈肾形，常偏于一侧，细胞质含较多溶酶体。此细胞在抵御病毒感染、防止肝内肿瘤及其他肿瘤的肝转移方面有重要作用。

:::definition{label="肝内大颗粒淋巴细胞"}
肝内大颗粒淋巴细胞（hepatic large granular lymphocyte）即肝血窦内的 NK 细胞，附着在内皮细胞或肝巨噬细胞上。核呈肾形，常偏于一侧，胞质含较多溶酶体。在抵御病毒感染、防止肝内肿瘤及其他肿瘤的肝转移方面有重要作用。
:::

:::insight{label="窦腔内先是巨噬细胞和 NK，窦壁外才把血浆交给肝细胞"}
门静脉带来营养，也带来抗原、衰老血细胞和可能的肿瘤细胞。库普弗细胞吞噬清除，肝内大颗粒淋巴细胞监视病毒和转移。血浆再经无隔膜窗孔漏进窦周隙。把血窦只记成“一条血管”，免疫监视账会从化工厂门口漏掉。
:::

### 3. 窦周隙

窦周隙（perisinusoidal space）为肝血窦内皮与肝板之间的狭窄间隙，宽约 $0.4\,\mu\mathrm{m}$（见图 15-11、图 15-17、图 15-18）。由于肝血窦内皮通透性大，故窦周隙充满血浆，肝细胞血窦面的微绒毛伸入窦周隙，浸于血浆之中。窦周隙是肝细胞和血液之间进行物质交换的场所。

:::definition{label="窦周隙"}
窦周隙（perisinusoidal space）又称 Disse 隙，为肝血窦内皮与肝板之间的狭窄间隙，宽约 $0.4\,\mu\mathrm{m}$。因内皮通透性大而充满血浆；肝细胞血窦面的微绒毛伸入其中，浸于血浆之中。它是肝细胞和血液之间进行物质交换的场所。
:::

:::pitfall{label="窦周隙就是 Disse 隙，在内皮和肝板之间，不要写成血窦腔或胆小管"}
血窦腔在内皮围成的管道里，里面走血细胞、库普弗细胞和 NK。窦周隙在内皮外侧、肝板外侧，宽约 $0.4\,\mu\mathrm{m}$，充满血浆，没有血细胞。胆小管在相邻肝细胞之间，走胆汁，被连接复合体封住。三套空隙：窦腔、Disse、胆小管，名字不能互换。
:::

:::concept{term="先问血浆在哪浸泡微绒毛：窦周隙，不是中央静脉腔"}
中央静脉是汇流出口。物质交换不在静脉腔里完成，而在内皮与肝板之间那条 $0.4\,\mu\mathrm{m}$ 的 Disse 隙：窗孔把血浆放进来，微绒毛泡在血浆里。看见“肝细胞和血液交换”，落点写窦周隙。
:::

窦周隙内有一种形态不规则的贮脂细胞（fat-storing cell），又称肝星状细胞（hepatic stellate cell，HSC），它们的突起附于内皮细胞基底面和肝细胞表面，或伸入肝细胞之间。其最主要的特征是细胞质内含有许多大的脂滴。在 HE 染色中，贮脂细胞不易鉴别，用氯化金、硝酸银浸染法，或免疫组织化学法可清楚显示。正常情况下，贮脂细胞呈静止状态，它在肝中主要参与维生素 A 的代谢和贮存脂肪。人体摄取的 $70\%\sim 85\%$ 的维生素 A 贮存在贮脂细胞内，在机体需要时释放入血。在病理条件下，如肝受到物理、化学损伤及病毒感染时，贮脂细胞被激活并异常增殖，产生细胞外基质使肝内纤维增多，可导致肝硬化。

:::definition{label="贮脂细胞"}
贮脂细胞（fat-storing cell）又称肝星状细胞（hepatic stellate cell，HSC），位于窦周隙，形态不规则。突起附于内皮细胞基底面和肝细胞表面，或伸入肝细胞之间。最主要特征是胞质内含有许多大的脂滴。HE 不易鉴别，氯化金、硝酸银浸染或免疫组织化学可清楚显示。
:::

:::definition{label="贮脂细胞的功能"}
正常情况下贮脂细胞呈静止状态，主要参与维生素 A 的代谢和贮存脂肪。人体摄取的 $70\%\sim 85\%$ 的维生素 A 贮存在贮脂细胞内，需要时释放入血。病理条件下（物理、化学损伤及病毒感染）被激活并异常增殖，产生细胞外基质使肝内纤维增多，可导致肝硬化。
:::

:::insight{label="维生素 A 的仓库在窦周隙，纤维化的种子也在这里"}
静止的贮脂细胞把大部分维生素 A 写成脂滴。损伤一旦把它激活，同一群细胞改为产出细胞外基质，肝内纤维增多，走向肝硬化。本章小结还写明：病理状况下贮脂细胞增多并转化为成纤维细胞，合成胶原增强，与肝纤维化有关。夜盲的维生素 A 账和肝硬化的胶原账，落在同一枚细胞的两个功能状态上。
:::

:::pitfall{label="贮脂细胞在窦周隙，不要写成血窦腔内的另一种巨噬细胞"}
库普弗细胞住在窦腔，来自单核细胞，职分是吞噬。贮脂细胞住在 Disse 隙，特征是大脂滴和维生素 A，激活后产基质。HE 里两者都不容易“随便点名”：巨噬细胞常用吞噬颗粒（如图 15-13 的台盼蓝）来显示，贮脂细胞要用氯化金、银浸或免疫组化。
:::

### 4. 胆小管

胆小管（bile canaliculus）是相邻两个肝细胞之间局部细胞膜凹陷形成的微细管道，在肝板内连接成网。在 HE 染色中不易看到，用银染法或 ATP 酶组织化学染色法可清楚显示（图 15-19）。电镜下，肝细胞的胆小管面形成许多微绒毛，突入管腔。靠近胆小管的相邻肝细胞膜形成由紧密连接、桥粒等组成的连接复合体，可封闭胆小管周围的细胞间隙，防止胆汁外溢至细胞间或窦周隙。当肝细胞发生变性、坏死或胆道发生堵塞而内压增大时，胆小管的连接复合体被破坏，胆汁则溢入窦周隙，继而进入肝血窦，导致机体出现黄疸。

:::definition{label="胆小管"}
胆小管（bile canaliculus）是相邻两个肝细胞之间局部细胞膜凹陷形成的微细管道，在肝板内连接成网。HE 不易看到，银染法或 ATP 酶组织化学染色可清楚显示。电镜下胆小管面有许多微绒毛突入管腔。
:::

:::definition{label="胆小管的连接复合体"}
靠近胆小管的相邻肝细胞膜形成由紧密连接、桥粒等组成的连接复合体，封闭胆小管周围的细胞间隙，防止胆汁外溢至细胞间或窦周隙。
:::

:::definition{label="胆汁性黄疸的组织学落点"}
肝细胞变性、坏死或胆道堵塞而内压增大时，胆小管的连接复合体被破坏，胆汁溢入窦周隙，继而进入肝血窦，导致机体出现黄疸。胆汁本不该与血浆相通。
:::

::figure{src="/images/histology/textbook/p0180_03.png" caption="图15-19 胆小管光镜图（镀银染色），胆小管呈黑色。以中央静脉为中心连接成网。" alt="镀银染色：黑色胆小管在肝板内连成网，围绕中央浅染静脉"}

:::pitfall{label="胆小管在肝细胞相邻面，不是门管区那根小叶间胆管，也不是中央静脉"}
胆小管没有自己的管壁上皮，就是两枚肝细胞膜对凹出来的缝，镀银才显黑网（图 15-19）。小叶间胆管在门管区，单层立方上皮，收的是已经出小叶的胆汁。中央静脉收的是血。把这三根管子认成同一条，胆汁和血液会在答题纸上合流。
:::

## （二）门管区

相邻肝小叶之间呈三角形或椭圆形的结缔组织小区，称门管区（portal area），每个肝小叶周围有 $3\sim 5$ 个门管区。门管区内有小叶间静脉、小叶间动脉和小叶间胆管（图 15-20）。小叶间静脉是门静脉的分支，管腔较大而不规则，管壁薄。小叶间动脉是肝动脉的分支，管腔小，管壁相对较厚。小叶间胆管管壁为单层立方上皮，它们向肝门方向汇集，最后形成左、右肝管出肝。

在非门管区的小叶间结缔组织中，还有由中央静脉汇集形成的单独走行的小叶下静脉，它们汇集为肝静脉。

:::definition{label="门管区"}
门管区（portal area）是相邻肝小叶之间呈三角形或椭圆形的结缔组织小区。每个肝小叶周围有 $3\sim 5$ 个门管区。内有小叶间静脉、小叶间动脉和小叶间胆管（门管区三件套），还有淋巴管和神经纤维。
:::

:::definition{label="小叶间静脉"}
小叶间静脉是门静脉的分支，管腔较大而不规则，管壁薄。把肠道吸收的营养和某些有毒物质送进肝血窦。
:::

:::definition{label="小叶间动脉"}
小叶间动脉是肝动脉的分支，管腔小，管壁相对较厚。为肝提供氧及其他器官的代谢产物。
:::

:::definition{label="小叶间胆管"}
小叶间胆管管壁为单层立方上皮，收集来自闰管（黑林管）的胆汁，向肝门方向汇集，最后形成左、右肝管出肝。
:::

:::definition{label="小叶下静脉"}
在非门管区的小叶间结缔组织中，由中央静脉汇集形成单独走行的小叶下静脉，再汇集为肝静脉。它不走门管区三件套。
:::

::figure{src="/images/histology/textbook/p0181_01.png" caption="图15-20 肝门管区光镜图。1. 小叶间动脉；2. 小叶间静脉；3. 小叶间胆管。" alt="门管区：管腔大而不规则的小叶间静脉、管壁较厚的小叶间动脉、单层立方的小叶间胆管"}

:::compare{title="门管区三件套与中央静脉、小叶下静脉"}
| 管道 | 来源 / 去向 | 光镜 | 位置 |
|------|-------------|------|------|
| 小叶间静脉 | 门静脉分支 → 注入肝血窦 | 腔大而不规则，壁薄 | 门管区 |
| 小叶间动脉 | 肝动脉分支 → 注入肝血窦 | 腔小，壁相对较厚 | 门管区 |
| 小叶间胆管 | 收胆汁 → 左、右肝管出肝 | 单层立方上皮 | 门管区 |
| 中央静脉 | 收血窦血液 | 小叶正中，沿长轴 | 肝小叶中央 |
| 小叶下静脉 | 中央静脉汇集 → 肝静脉 | 单独走行 | 非门管区的小叶间结缔组织 |
:::

:::pitfall{label="门管区胆管不是中央静脉，三件套里也没有小叶下静脉"}
中央静脉在小叶正中，收血窦的血，壁上有血窦开口。小叶间胆管在周边结缔组织里，单层立方，走胆汁。门管区三件套是“一门静脉分支、一肝动脉分支、一胆管”，肝静脉系统的小叶下静脉故意写在非门管区。切片上腔大壁薄的是小叶间静脉，不是中央静脉“搬到了旁边”。
:::

:::concept{term="先数门管区三件套：静脉腔大、动脉壁厚、胆管立方"}
认门管区不要只看“旁边有结缔组织”。三件套同时在场：腔大不规则、壁薄 → 小叶间静脉；腔小壁厚 → 小叶间动脉；单层立方围成的小管 → 小叶间胆管。缺一件就先问切面是不是切偏了，不要把中央静脉或小叶下静脉凑进去凑数。
:::

## （三）肝内血液循环

肝与血液内的物质代谢关系密切，其供血血管通常分为功能性血管和营养性血管。进入肝的血管有门静脉和肝动脉，门静脉是肝的功能性血管，主要收集胃肠静脉和脾静脉的血流，将胃肠道吸收的营养和某些有毒物质输入肝内进行代谢和加工处理。肝动脉是肝的营养性血管，为肝提供氧及其他器官的代谢产物。肝血供丰富，成人肝每分钟血流量为 $1\,500\sim 2\,000\,\mathrm{ml}$，占心输出量的 $30\%\sim 40\%$。

:::definition{label="门静脉（功能性血管）"}
门静脉是肝的功能性血管，主要收集胃肠静脉和脾静脉的血流，将胃肠道吸收的营养和某些有毒物质输入肝内进行代谢和加工处理。
:::

:::definition{label="肝动脉（营养性血管）"}
肝动脉是肝的营养性血管，为肝提供氧及其他器官的代谢产物。
:::

:::definition{label="肝的血流量"}
肝血供丰富，成人肝每分钟血流量为 $1\,500\sim 2\,000\,\mathrm{ml}$，占心输出量的 $30\%\sim 40\%$。
:::

:::note{label="肝内血流路径"}
| 顺序 | 站点 | 要点 |
|------|------|------|
| ① 入肝 | 门静脉（功能）+ 肝动脉（营养） | 经肝门入肝 |
| ② 门管区 | 小叶间静脉、小叶间动脉 | 注入肝血窦 |
| ③ 肝血窦 | 板间，血流缓慢 | 血浆经窗孔入窦周隙，与肝细胞交换 |
| ④ 中央静脉 | 小叶长轴 | 收血窦血液 |
| ⑤ 出肝 | 小叶下静脉 → 肝静脉 | 不经过门管区三件套 |
:::

:::insight{label="门静脉先把“吃进来的”和“可能有毒的”交给肝，动脉再给氧"}
功能性血管不是“比较重要的那根”，而是把胃肠吸收物和脾血送进化工厂加工的那根。营养性血管给氧。两路血在血窦里汇合、变慢，才够时间交换。成人每分钟 $1\,500\sim 2\,000\,\mathrm{ml}$，约占心输出量的 $1/3$，解释了为什么门静脉系的栓子和肠道来的抗原会优先经过肝。
:::

## （四）肝的胆汁形成和排出途径

肝细胞吸收血浆中的胆红素后，经滑面内质网内的葡萄糖醛酸转移酶的作用，转化为水溶性的结合胆红素，释放入胆小管，与胆盐和胆固醇等共同组成胆汁，成人每天可分泌 $600\sim 1\,000\,\mathrm{ml}$ 的胆汁。胆小管内的胆汁从肝小叶的中央流向周边。胆小管于小叶边缘处汇集成闰管或黑林管（Hering canal）。闰管与小叶间胆管相连，小叶间胆管向肝门方向汇集，最后形成左、右肝管出肝，在肝外汇成肝总管，再由胆囊管入胆囊，或经胆总管入十二指肠。

:::definition{label="结合胆红素与胆汁"}
肝细胞吸收血浆中的胆红素后，经滑面内质网内的葡萄糖醛酸转移酶作用，转化为水溶性的结合胆红素，释放入胆小管，与胆盐和胆固醇等共同组成胆汁。成人每天可分泌 $600\sim 1\,000\,\mathrm{ml}$。
:::

:::definition{label="黑林管"}
胆小管于小叶边缘处汇集成闰管或黑林管（Hering canal）。闰管与小叶间胆管相连，是胆汁出小叶的第一段真正有管壁的通道。
:::

:::definition{label="胆汁排出途径"}
胆小管（小叶中央→周边）→ 闰管 / 黑林管 → 小叶间胆管 → 左、右肝管出肝 → 肝总管 → 经胆囊管入胆囊贮存，或经胆总管入十二指肠。
:::

:::compare{title="肝内血液与胆汁的流向"}
| 项目 | 血液 | 胆汁 |
|------|------|------|
| 小叶内方向 | 周边（门管区）→ 中央静脉 | 中央 → 周边（门管区） |
| 起始结构 | 小叶间动、静脉注入血窦 | 肝细胞分泌入胆小管 |
| 交换 / 封闭 | 经窦周隙与肝细胞通透交换 | 连接复合体封闭，不进入窦周隙 |
| 出小叶 | 中央静脉 → 小叶下静脉 → 肝静脉 | 黑林管 → 小叶间胆管 → 左右肝管 |
| 逆流后果 | — | 连接复合体破坏 → 胆汁入窦周隙、入血 → 黄疸 |
:::

:::pitfall{label="胆汁从中央流向周边，不要写成和血液同一方向"}
血液：门管区注入血窦，流向中央静脉。胆汁：胆小管从中央流向周边，进黑林管再进小叶间胆管。两套网络伴行但方向相反。把胆汁也写成“汇入中央静脉”，黄疸和胆总管两本账会从流向第一句就反。
:::

## （五）肝的再生

肝的重要特征之一是具有强大的再生能力。正常人体的肝细胞是一种长寿命细胞，极少见分裂象。但在肝受损害后，尤其肝大部分（$2/3$）被切除后，在残余肝不发生炎症和纤维增生的情况下，肝细胞迅速出现快速活跃的分裂增殖，并能精确地调控自身体积的大小。动物实验证明，肝被切除 $3/4$ 后，肝的生理功能仍可维持，并逐渐恢复原来的重量。肝病患者施行大部或部分肝切除后也有再生能力，但因病变情况而异，一般可在半年内恢复正常肝体积。肝的再生受肝内外诸多因子的调控，在肝受损害或部分切除后，这些因子通过肝细胞相应受体作用于肝细胞，启动并促进肝细胞的增殖。

:::definition{label="肝的再生"}
肝具有强大的再生能力。正常肝细胞是长寿命细胞，极少见分裂象。肝受损害后，尤其大部分（$2/3$）被切除后，若残余肝不发生炎症和纤维增生，肝细胞迅速活跃分裂增殖，并能精确调控自身体积。
:::

:::note{label="肝再生的教材数据"}
| 条件 | 结果 |
|------|------|
| 正常 | 长寿命细胞，极少分裂象 |
| 切除 $2/3$，残余肝无炎症和纤维增生 | 迅速增殖，精确调控体积 |
| 动物切除 $3/4$ | 生理功能仍可维持，并逐渐恢复原来重量 |
| 肝病患者大部或部分切除 | 有再生能力，因病变而异；一般可在半年内恢复正常肝体积 |
| 调控 | 肝内外诸多因子经肝细胞相应受体启动并促进增殖 |
:::

:::insight{label="多倍体和长寿命解释平时为什么看不到分裂，切掉以后为什么又能长回来"}
成人 4 倍体肝细胞占 $60\%$ 以上，平时极少分裂，却把再生潜力留着。炎症和纤维增生（贮脂细胞激活那一本）会挡住这股增殖。再生不是“另造一个肝”，而是残余肝细胞按体积精确补回去，因子经受体启动。把肝听成“不能再生的实质器官”，部分肝切除的组织学依据会消失。
:::

:::keypoint{label="肝先立肝小叶和门管区，再记血窦、窦周隙、巨噬细胞和胆汁"}
- 肝是最大腺体、机体化工厂：胆汁消化脂类；血浆蛋白入血；参与糖、脂、激素和药物代谢。
- 肝小叶是基本结构单位：中央静脉 + 放射状肝板（肝索）和肝血窦；人分界不清，猪分界明显。
- 肝细胞占 $80\%$，三面（血窦面、连接面、胆小管面）；多倍体多；粗面内质网造血浆蛋白，滑面内质网做转化和胆汁合成，近胆小管高尔基复合体参与泌胆。
- 肝血窦内皮窗孔无隔膜、无基膜，血浆入窦周隙；窦内有库普弗细胞和肝内大颗粒淋巴细胞。
- 窦周隙（Disse）宽约 $0.4\,\mu\mathrm{m}$，是交换场所；贮脂细胞（HSC）贮维生素 A，激活后可致肝硬化。
- 胆小管在相邻肝细胞之间，连接复合体防外溢；破坏则胆汁入血致黄疸。胆汁：中央→周边→黑林管→小叶间胆管。
- 门管区三件套：小叶间静脉（门静脉，腔大壁薄）、小叶间动脉（肝动脉，腔小壁厚）、小叶间胆管（单层立方）。中央静脉 ≠ 胆管；小叶下静脉不在三件套里。
- 门静脉为功能性血管，肝动脉为营养性血管；每分钟 $1\,500\sim 2\,000\,\mathrm{ml}$。肝再生能力强。
:::

:::memory{label="本节必背要点"}
- [ ] 肝是人体最大的腺体，被称为机体的化工厂。
- [ ] 肝产生的胆汁作为消化液参与脂类食物消化；合成多种蛋白质等多类物质，直接分泌入血；还参与糖、脂类、激素和药物等代谢。
- [ ] 肝表面覆以致密结缔组织被膜；除肝下面各沟、窝处以及右叶上面后部为纤维膜外，其余均被覆浆膜。
- [ ] 肝门部结缔组织随门静脉、肝动脉和肝管的分支伸入实质，将实质分成许多肝小叶；小叶之间管道密集处为门管区。
- [ ] 肝小叶（hepatic lobule）是肝的基本结构单位，呈多角棱柱体，长约 $2\,\mathrm{mm}$，宽约 $1\,\mathrm{mm}$；成人有 $50$ 万～$100$ 万个。
- [ ] 猪等动物肝小叶因周围结缔组织较多而分界明显；人的肝小叶间结缔组织很少，相邻小叶常连成一片，分界不清。
- [ ] 肝小叶中央有一条沿长轴走行的中央静脉（central vein），周围是大致呈放射状排列的肝索和肝血窦。
- [ ] 肝细胞单层排列成凹凸不平的板状结构称肝板（hepatic plate）；切面呈索状，故也称肝索（hepatic cord）。
- [ ] 肝小叶周边的一层环形肝板称为界板（limiting plate）。
- [ ] 肝板之间为肝血窦，经肝板上的孔互相通连；肝细胞相邻面质膜局部凹陷形成微细胆小管。
- [ ] 肝板、肝血窦和胆小管在肝小叶内形成各自独立而又密切相关的复杂网络。
- [ ] 肝细胞（hepatocyte）占肝内细胞总数的 $80\%$，呈多面体形，直径 $15\sim 30\,\mu\mathrm{m}$。
- [ ] 肝细胞有 3 种功能面：血窦面、细胞连接面和胆小管面；血窦面和胆小管面有发达微绒毛。
- [ ] 相邻肝细胞连接面有紧密连接、桥粒和缝隙连接；有的肝细胞之间还有贯通的细胞间通道。
- [ ] 肝细胞核大而圆，常染色质丰富，有 1 个至数个核仁，双核细胞较多。
- [ ] 多倍体肝细胞数量多，成人 4 倍体肝细胞占 $60\%$ 以上，可能与长期活跃及潜在再生能力相关。
- [ ] 肝细胞胞质呈嗜酸性，含弥散分布的嗜碱性团块；电镜下各种细胞器均丰富。
- [ ] 粗面内质网呈板层状排列成群，合成白蛋白、纤维蛋白原、凝血酶原、脂蛋白和补体等血浆蛋白。
- [ ] 滑面内质网为散在小管和小泡，膜上有氧化还原酶、水解酶、转移酶、合成酶等；进行胆汁合成、脂类/糖/激素代谢及药物等有机异物的生物转化。
- [ ] 粗面内质网合成的蛋白质和脂蛋白经高尔基复合体加工后，由分泌小泡从血窦面排出；近胆小管处高尔基复合体尤为发达，参与胆汁分泌。
- [ ] 肝细胞富含线粒体、溶酶体和过氧化物酶体，以及糖原、脂滴、色素等内含物。
- [ ] 进食后糖原增多，饥饿时糖原减少；正常时脂滴少，肝病时脂滴可增多。
- [ ] 肝血窦（hepatic sinusoid）位于肝板之间，腔大而不规则，窦壁由内皮细胞围成。
- [ ] 门静脉血和肝动脉血经小叶间动脉、小叶间静脉注入肝血窦，血流缓慢，交换后汇入中央静脉。
- [ ] 内皮窗孔大小不等、无隔膜，直径多为 $0.1\,\mu\mathrm{m}$，大的可达 $1\sim 2\,\mu\mathrm{m}$；内皮连接松散，间隙宽；内皮外无基膜，仅少量网状纤维。
- [ ] 肝血窦内皮通透性很高，除血细胞和乳糜微粒外，血浆各种成分均可进入窦周隙。
- [ ] 肝巨噬细胞（hepatic macrophage）又称库普弗细胞（Kupffer cell），定居血窦内，形态不规则，胞质嗜酸性。
- [ ] 肝巨噬细胞表面有皱褶和微绒毛，以板状和丝状伪足附着于内皮，或穿过窗孔和间隙伸入窦周隙；溶酶体发达，常见吞噬体和吞饮泡。
- [ ] 肝巨噬细胞由血液单核细胞分化而来，清除门静脉入肝的抗原异物、衰老血细胞并监视肿瘤。
- [ ] 肝血窦内还有较多 NK 细胞，称肝内大颗粒淋巴细胞（hepatic large granular lymphocyte），附着在内皮或肝巨噬细胞上。
- [ ] 肝内大颗粒淋巴细胞核呈肾形、常偏一侧，胞质含较多溶酶体；抵御病毒感染，防止肝内肿瘤及其他肿瘤的肝转移。
- [ ] 窦周隙（perisinusoidal space，Disse 隙）为内皮与肝板之间的狭窄间隙，宽约 $0.4\,\mu\mathrm{m}$，充满血浆。
- [ ] 肝细胞血窦面微绒毛伸入窦周隙、浸于血浆之中；窦周隙是肝细胞和血液之间进行物质交换的场所。
- [ ] 贮脂细胞（fat-storing cell）又称肝星状细胞（hepatic stellate cell，HSC），位于窦周隙，形态不规则，胞质含许多大脂滴。
- [ ] 贮脂细胞突起附于内皮基底面和肝细胞表面，或伸入肝细胞之间；HE 不易鉴别，氯化金、硝酸银浸染或免疫组化可显示。
- [ ] 正常时贮脂细胞呈静止状态，参与维生素 A 代谢和贮存脂肪；人体摄取的 $70\%\sim 85\%$ 维生素 A 贮存在贮脂细胞内。
- [ ] 病理条件下（物理、化学损伤及病毒感染）贮脂细胞被激活并异常增殖，产生细胞外基质使肝内纤维增多，可导致肝硬化。
- [ ] 胆小管（bile canaliculus）是相邻两个肝细胞之间局部细胞膜凹陷形成的微细管道，在肝板内连接成网。
- [ ] 胆小管在 HE 中不易看到，银染法或 ATP 酶组织化学染色可清楚显示；电镜下胆小管面有许多微绒毛突入管腔。
- [ ] 靠近胆小管的相邻肝细胞膜形成紧密连接、桥粒等连接复合体，防止胆汁外溢至细胞间或窦周隙。
- [ ] 肝细胞变性、坏死或胆道堵塞内压增大时，连接复合体被破坏，胆汁溢入窦周隙再入肝血窦，导致黄疸。
- [ ] 门管区（portal area）为相邻肝小叶之间三角形或椭圆形的结缔组织小区；每个肝小叶周围有 $3\sim 5$ 个。
- [ ] 门管区内有小叶间静脉、小叶间动脉和小叶间胆管。
- [ ] 小叶间静脉是门静脉分支，管腔较大而不规则，管壁薄。
- [ ] 小叶间动脉是肝动脉分支，管腔小，管壁相对较厚。
- [ ] 小叶间胆管管壁为单层立方上皮，向肝门汇集，最后形成左、右肝管出肝。
- [ ] 非门管区的小叶间结缔组织中，有由中央静脉汇集、单独走行的小叶下静脉，再汇集为肝静脉。
- [ ] 门静脉是肝的功能性血管，收集胃肠静脉和脾静脉血流，将营养和某些有毒物质输入肝内代谢加工。
- [ ] 肝动脉是肝的营养性血管，为肝提供氧及其他器官的代谢产物。
- [ ] 成人肝每分钟血流量 $1\,500\sim 2\,000\,\mathrm{ml}$，占心输出量的 $30\%\sim 40\%$。
- [ ] 肝细胞吸收血浆胆红素，经滑面内质网葡萄糖醛酸转移酶转化为水溶性结合胆红素，释放入胆小管，与胆盐和胆固醇等组成胆汁。
- [ ] 成人每天可分泌 $600\sim 1\,000\,\mathrm{ml}$ 胆汁；胆小管内胆汁从肝小叶中央流向周边。
- [ ] 胆小管于小叶边缘汇集成闰管或黑林管（Hering canal），再连小叶间胆管，汇成左、右肝管出肝。
- [ ] 出肝后汇成肝总管，再由胆囊管入胆囊，或经胆总管入十二指肠。
- [ ] 肝具有强大再生能力；正常肝细胞为长寿命细胞，极少见分裂象。
- [ ] 肝大部分（$2/3$）被切除后，若残余肝不发生炎症和纤维增生，肝细胞迅速活跃分裂增殖，并精确调控自身体积。
- [ ] 动物肝被切除 $3/4$ 后，生理功能仍可维持，并逐渐恢复原来重量。
- [ ] 肝病患者大部或部分肝切除后也有再生能力，因病变而异，一般可在半年内恢复正常肝体积。
- [ ] 肝的再生受肝内外诸多因子调控，经肝细胞相应受体启动并促进增殖。
:::
