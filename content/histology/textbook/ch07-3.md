# 三、神经胶质细胞

在神经元与神经元之间、神经元与非神经细胞之间，除了突触部位，一般都被神经胶质细胞分隔、绝缘，以保证信息传递的专一性和不受干扰。神经胶质细胞数量为神经元的 $10\sim 50$ 倍，对神经元不仅起支持、保护、营养和绝缘等作用，也参与神经递质和活性物质的代谢；损伤后的修复（胶质瘢痕、吞噬碎屑、神经营养因子）在各型细胞中分别写出。本节按中枢四型和周围两型把这本绝缘账摊开。

:::definition{label="神经胶质细胞的分隔作用"}
除突触部位外，神经元与神经元之间、神经元与非神经细胞之间一般都被神经胶质细胞分隔、绝缘，以保证信息传递的专一性和不受干扰。
:::

:::concept{term="先问这颗胶质在中枢还是周围"}
中枢（脑和脊髓）的胶质是星形胶质细胞、少突胶质细胞、小胶质细胞和室管膜细胞；周围神经系统换成施万细胞和卫星细胞。髓鞘在中枢由少突胶质细胞包卷，在周围由施万细胞参与构成神经纤维。把六种胶质背成一张无部位的名单，血–脑屏障、神经节被囊和后文有髓纤维都会认错地方。
:::

:::pitfall{label="HE 里大部分胶质不好认，不要把所有小核都写成小胶质"}
脑和脊髓的神经胶质细胞有 4 种，在 HE 染色切片中，除室管膜细胞外，都不易区分。要用不同的镀银染色法才能显示各种细胞的全貌。HE 里那些小而深染的核，可能是少突、小胶质，也可能是内皮或其他细胞。先问染色方法，再问突起数目和脚板，不要按“核小就是小胶质”一刀切。
:::

## （一）中枢神经系统的神经胶质细胞

脑和脊髓的神经胶质细胞有 4 种（图 7-11～图 7-14），在 HE 染色切片中，除室管膜细胞外，都不易区分。然而，用不同的镀银染色法则能显示各种细胞的全貌。

:::definition{label="中枢神经胶质细胞"}
中枢神经系统（脑和脊髓）的神经胶质细胞有 4 种：星形胶质细胞、少突胶质细胞、小胶质细胞和室管膜细胞。HE 中除室管膜细胞外不易区分，镀银染色可显示全貌。
:::

::figure{src="/images/histology/textbook/p0087_01.png" caption="图7-11 中枢神经系统神经胶质细胞与神经元和毛细血管的关系示意图。示室管膜细胞、星形胶质细胞及其胶质界膜与脚板、少突胶质细胞包卷有髓神经纤维、小胶质细胞、神经元、毛细血管内皮细胞。" alt="中枢四种胶质与神经元、毛细血管和胶质界膜的立体关系"}

### 1. 星形胶质细胞

星形胶质细胞（astrocyte）是最大的一种神经胶质细胞，胞体呈星形，核圆形或卵圆形，较大，染色较浅。细胞质内含有胶质丝（glial filament），是由胶质原纤维酸性蛋白构成的一种中间丝，参与细胞骨架的组成。从胞体发出的突起伸展充填在神经元胞体及其突起之间，起支持和绝缘作用。有些突起末端扩展形成脚板（end feet），在脑和脊髓表面形成胶质界膜（glial limitans）（图 7-12），或贴附在毛细血管壁上（图 7-13），构成血-脑屏障的神经胶质膜（见第 8 章）。星形胶质细胞能分泌神经营养因子（neurotrophic factor）和多种生长因子，对神经元的分化、功能的维持以及创伤后神经元的可塑性变化有重要的影响。在脑和脊髓损伤时，星形胶质细胞可增生，形成胶质瘢痕修补缺损。此细胞可分为 2 种：①纤维性星形胶质细胞，多分布于脑和脊髓的白质，其突起长而直，分支较少，胶质丝丰富。②原浆性星形胶质细胞，多分布在脑和脊髓的灰质，突起较短粗，分支多，胶质丝较少。

:::definition{label="星形胶质细胞"}
星形胶质细胞（astrocyte）是最大的神经胶质细胞。胞体呈星形；核圆形或卵圆形，较大，染色较浅。胞质含胶质丝。突起充填在神经元胞体及其突起之间，起支持和绝缘作用；部分突起末端扩展为脚板。能分泌神经营养因子和多种生长因子；损伤时可增生形成胶质瘢痕。
:::

:::definition{label="胶质丝"}
胶质丝（glial filament）是星形胶质细胞胞质内的中间丝，由胶质原纤维酸性蛋白（GFAP）构成，参与细胞骨架。免疫细胞化学常用 GFAP 显示星形胶质细胞（图 7-13）。
:::

:::definition{label="脚板"}
脚板（end feet）是星形胶质细胞部分突起末端扩展形成的结构。在脑和脊髓表面参与形成胶质界膜，或贴附在毛细血管壁上，构成血–脑屏障的神经胶质膜。
:::

:::definition{label="胶质界膜"}
胶质界膜（glial limitans）由星形胶质细胞突起的脚板在脑和脊髓表面铺成，是中枢神经组织表面的胶质覆盖（图 7-11、图 7-12）。
:::

:::definition{label="神经营养因子"}
神经营养因子（neurotrophic factor）可由星形胶质细胞（以及周围的施万细胞）分泌，对神经元的分化、功能维持以及创伤后的可塑性变化有重要影响；也促进受损伤神经元存活及其轴突再生。
:::

:::definition{label="纤维性星形胶质细胞"}
纤维性星形胶质细胞多分布于脑和脊髓的白质，突起长而直，分支较少，胶质丝丰富。
:::

:::definition{label="原浆性星形胶质细胞"}
原浆性星形胶质细胞多分布在脑和脊髓的灰质，突起较短粗，分支多，胶质丝较少。
:::

:::compare{title="纤维性与原浆性星形胶质细胞"}
| 项目 | 纤维性星形胶质细胞 | 原浆性星形胶质细胞 |
|------|--------------------|--------------------|
| 主要分布 | 脑和脊髓的白质 | 脑和脊髓的灰质 |
| 突起 | 长而直，分支较少 | 较短粗，分支多 |
| 胶质丝 | 丰富 | 较少 |
| 共同结构 | 星形胞体、较浅的圆或卵圆核、GFAP 胶质丝、脚板 | 同左 |
| 共同功能 | 支持与绝缘；分泌神经营养因子和生长因子；损伤后增生形成胶质瘢痕 | 同左 |
:::

:::concept{term="先问灰质还是白质，再认原浆性还是纤维性"}
同一类星形胶质细胞，在白质把突起拉长、胶质丝堆厚，叫纤维性；在灰质把突起截短、多分支去填神经元之间的空隙，叫原浆性。脚板两头都要认：一头铺在脑和脊髓表面成胶质界膜，一头贴毛细血管，写成血–脑屏障的神经胶质膜（第 8 章再展开）。把“星形”只记成形状，会把白质/灰质和屏障账做丢。
:::

:::cause-effect{title="中枢损伤时星形胶质细胞怎样写成胶质瘢痕"}
- 因：脑和脊髓损伤，局部神经元及其突起缺损
- 因：星形胶质细胞可增生，并分泌神经营养因子和多种生长因子
- 果：增生的星形胶质细胞形成胶质瘢痕，修补缺损
- 影响：对神经元分化、功能维持和创伤后可塑性有重要作用；瘢痕同时占据缺损区
:::

### 2. 少突胶质细胞

少突胶质细胞（oligodendrocyte）分布于神经元胞体附近及轴突周围。胞体较星形胶质细胞小，核卵圆形，染色质致密。在镀银染色标本中，少突胶质细胞的突起较少。在电镜下，可见多数少突胶质细胞突起末端扩展成扁平薄膜，包卷神经元的轴突形成髓鞘，所以它是中枢神经系统的髓鞘形成细胞。

:::definition{label="少突胶质细胞"}
少突胶质细胞（oligodendrocyte）分布于神经元胞体附近及轴突周围。胞体较星形胶质细胞小；核卵圆形，染色质致密。镀银标本中突起较少。电镜下突起末端扩展成扁平薄膜，包卷轴突形成髓鞘，是中枢神经系统的髓鞘形成细胞。
:::

:::insight{label="中枢一条少突胶质细胞可以给多条轴突做髓鞘"}
镀银里它“少突”，电镜下这些突起的末端却展成薄膜去包轴突。周围神经系统对应的髓鞘形成细胞是施万细胞，但施万细胞外表面有基膜，少突胶质细胞形成的中枢有髓纤维外表面无基膜（第五节展开）。本页先立住：看见中枢髓鞘，先找少突，不要写成施万。
:::

### 3. 小胶质细胞

小胶质细胞（microglia）是最小的神经胶质细胞。其胞体细长或椭圆，核小、呈扁平或三角形，染色深。通常从胞体发出细长有分支的突起，突起表面有许多棘突。小胶质细胞是血液单核细胞迁入神经组织后演化而成，当神经系统损伤时，可转变为巨噬细胞，吞噬死亡细胞的碎屑。

:::definition{label="小胶质细胞"}
小胶质细胞（microglia）是最小的神经胶质细胞。胞体细长或椭圆；核小，呈扁平或三角形，染色深。突起细长有分支，表面有许多棘突。由血液单核细胞迁入神经组织后演化而成；损伤时可转变为巨噬细胞，吞噬死亡细胞的碎屑。
:::

:::pitfall{label="小胶质来自单核细胞，不是神经上皮的同胞"}
星形、少突和室管膜都属于中枢胶质的“本地编制”；小胶质细胞是血液单核细胞迁入后演化的。损伤时它变成巨噬细胞，职分是吞噬碎屑，不是形成髓鞘，也不是铺胶质界膜。不要把核小、染色深的细胞一律写成少突，也不要把小胶质和周围神经节里的卫星细胞当成同一种“小细胞”。
:::

:::cause-effect{title="损伤怎样把小胶质细胞改写成巨噬细胞"}
- 因：小胶质细胞由血液单核细胞迁入神经组织演化而来，保留吞噬潜能
- 因：神经系统损伤，出现死亡细胞碎屑
- 果：小胶质细胞转变为巨噬细胞，吞噬碎屑
- 制约：这是中枢内的单核–吞噬系统账，与星形胶质细胞的胶质瘢痕修补不是同一件事
:::

### 4. 室管膜细胞

室管膜细胞（ependymal cell）衬在脑室和脊髓中央管的腔面，形成单层上皮样的室管膜。室管膜细胞呈立方形或柱形，游离面有许多微绒毛，少数细胞有纤毛，其摆动有助于脑脊液流动；部分细胞的基底面有细长的突起伸向深部（见图 7-11）。在脉络丛的室管膜细胞可产生脑脊液（见第 8 章）。

:::definition{label="室管膜细胞"}
室管膜细胞（ependymal cell）衬在脑室和脊髓中央管的腔面，形成单层上皮样的室管膜。细胞呈立方形或柱形；游离面有许多微绒毛，少数有纤毛，摆动有助于脑脊液流动；部分细胞基底面有细长突起伸向深部。脉络丛的室管膜细胞可产生脑脊液。
:::

:::note{label="四种中枢胶质在 HE 与镀银上的认法不同"}
室管膜细胞排成单层立方或柱状，HE 就能在脑室或中央管腔面认出来。其余三种要靠镀银看全貌，或靠 GFAP 免疫荧光认星形胶质细胞。图 7-14 把纤维性、原浆性、少突和小胶质四块镀银标本并排，就是为了按突起形态对照，而不是按 HE 核的大小一锤定音。
:::

## （二）周围神经系统的神经胶质细胞

### 1. 施万细胞

施万细胞（Schwann cell）参与周围神经系统中神经纤维的构成，位于有髓神经纤维和无髓神经纤维中的施万细胞在形态和功能方面有所差异。施万细胞的外表面有基膜，也能分泌神经营养因子，促进受损伤的神经元存活及其轴突再生。

:::definition{label="施万细胞"}
施万细胞（Schwann cell）参与周围神经系统中神经纤维的构成。有髓神经纤维和无髓神经纤维中的施万细胞在形态和功能方面有所差异。外表面有基膜，能分泌神经营养因子，促进受损伤的神经元存活及其轴突再生。
:::

:::insight{label="周围靠施万，中枢靠少突；基膜是周围侧的线索"}
少突胶质细胞是中枢的髓鞘形成细胞；施万细胞参与周围神经纤维（有髓与无髓形态功能不同，第五节再写卷髓鞘和包裸轴突）。施万细胞外表面有基膜，损伤后这条基膜管道对轴突再生很关键（第七节）。看见周围神经，先找施万和基膜；看见中枢白质，先找少突、不要写基膜套在每一条中枢有髓纤维外面。
:::

### 2. 卫星细胞

卫星细胞（satellite cell）是神经节内包裹神经元胞体的一层扁平或立方形细胞，其核呈圆形或卵圆形，染色质较浓密。

:::definition{label="卫星细胞"}
卫星细胞（satellite cell）是神经节内包裹神经元胞体的一层扁平或立方形细胞。核呈圆形或卵圆形，染色质较浓密。
:::

:::pitfall{label="神经节卫星细胞不是骨骼肌的肌卫星细胞"}
本节卫星细胞包在神经节神经元胞体周围，是周围神经系统的胶质。骨骼肌纤维表面那枚扁平有突起、损伤后可增殖分化的细胞也叫肌卫星细胞，是肌组织的干细胞，不是胶质。名字相同，部位、来源和职分都不同。神经节切片上贴在胞体周围的一层扁平或立方细胞，才是本页的卫星细胞。
:::

| 项目 | 中枢神经系统 | 周围神经系统 |
|------|--------------|----------------|
| 成员 | 星形、少突、小胶质、室管膜 | 施万细胞、卫星细胞 |
| 髓鞘形成细胞 | 少突胶质细胞 | 施万细胞（有髓纤维中） |
| 包绕胞体 | 星形胶质细胞突起充填于胞体之间 | 卫星细胞在神经节内包裹胞体 |
| 表面特化 | 脚板 → 胶质界膜；脚板贴毛细血管 → 血–脑屏障胶质膜 | 施万细胞外表面有基膜 |
| HE 可辨者 | 主要是室管膜细胞 | 神经节卫星细胞较易在胞体周缘见到 |
| 营养与再生 | 星形胶质细胞分泌神经营养因子和生长因子 | 施万细胞分泌神经营养因子，促进受损神经元存活和轴突再生 |
:::

:::compare{title="少突胶质细胞与施万细胞"}
| 项目 | 少突胶质细胞 | 施万细胞 |
|------|--------------|----------|
| 部位 | 中枢（脑和脊髓） | 周围神经纤维 |
| 光镜 | 胞体较小，核卵圆、染色质致密，镀银突起较少 | 参与有髓及无髓纤维；核可见于髓鞘边缘（图 7-5） |
| 髓鞘 | 突起末端薄膜包卷轴突，为中枢髓鞘形成细胞 | 有髓与无髓中形态功能有差异；外表面有基膜 |
| 一条细胞与轴突 | 一个少突可包卷多条中枢轴突（后文展开） | 有髓纤维中一个结间体对应一个施万细胞（第五节） |
| 再生相关 | — | 分泌神经营养因子；基膜有助于轴突再生 |
:::

:::timeline{period="从腔面到神经节：六种胶质各守一段"}
- **室管膜** 衬脑室和中央管，微绒毛和纤毛面对脑脊液，脉络丛者可产液
- **星形胶质** 脚板铺胶质界膜、贴毛细血管；灰质原浆性、白质纤维性
- **少突胶质** 在中枢轴突周围展膜成髓鞘
- **小胶质** 巡查实质，损伤时转为巨噬细胞
- **施万细胞** 在周围神经纤维中包轴突，外有基膜，分泌神经营养因子
- **卫星细胞** 在神经节内以扁平或立方细胞包裹神经元胞体
:::

:::keypoint{label="胶质先把中枢四型、周围两型和髓鞘归属立住"}
- 除突触外，胶质把神经元彼此及与非神经细胞分隔绝缘，保证信息传递专一。
- 中枢四型：星形（最大，GFAP 胶质丝，脚板，分纤维性/原浆性）、少突（中枢髓鞘）、小胶质（最小，源自单核细胞，可成巨噬细胞）、室管膜（衬腔，微绒毛/纤毛，脉络丛产脑脊液）。
- HE 除室管膜外不易区分，镀银或 GFAP 才能显示全貌。
- 周围两型：施万细胞构成周围神经纤维（外有基膜，分泌神经营养因子）；卫星细胞包裹神经节胞体。
- 中枢髓鞘找少突，周围神经找施万；不要把神经节卫星细胞写成肌卫星细胞。
:::

:::memory{label="本节必背要点"}
- [ ] 除突触部位外，神经元与神经元、神经元与非神经细胞之间一般都被神经胶质细胞分隔、绝缘，以保证信息传递的专一性和不受干扰。
- [ ] 中枢（脑和脊髓）胶质 4 种：星形胶质细胞、少突胶质细胞、小胶质细胞、室管膜细胞。HE 中除室管膜外不易区分，镀银可显示全貌。
- [ ] 星形胶质细胞（astrocyte）是最大的神经胶质细胞；胞体星形；核圆或卵圆、较大、染色较浅。
- [ ] 胶质丝（glial filament）由胶质原纤维酸性蛋白构成，是一种中间丝，参与细胞骨架。
- [ ] 星形胶质细胞突起充填于神经元胞体及其突起之间，起支持和绝缘作用。
- [ ] 脚板（end feet）：突起末端扩展；在脑和脊髓表面形成胶质界膜（glial limitans），或贴附毛细血管壁，构成血–脑屏障的神经胶质膜。
- [ ] 星形胶质细胞分泌神经营养因子和多种生长因子，影响神经元分化、功能维持和创伤后可塑性；损伤时可增生形成胶质瘢痕修补缺损。
- [ ] 纤维性星形胶质细胞：多在白质，突起长而直、分支少、胶质丝丰富。
- [ ] 原浆性星形胶质细胞：多在灰质，突起较短粗、分支多、胶质丝较少。
- [ ] 少突胶质细胞（oligodendrocyte）：分布于神经元胞体附近及轴突周围；胞体较星形胶质细胞小；核卵圆、染色质致密；镀银突起较少。
- [ ] 少突胶质细胞突起末端扩展成扁平薄膜，包卷轴突形成髓鞘，是中枢神经系统的髓鞘形成细胞。
- [ ] 小胶质细胞（microglia）是最小的神经胶质细胞；胞体细长或椭圆；核小、扁平或三角形、染色深。
- [ ] 小胶质细胞突起细长有分支，表面有许多棘突；由血液单核细胞迁入神经组织演化而成；损伤时可转变为巨噬细胞，吞噬死亡细胞碎屑。
- [ ] 室管膜细胞（ependymal cell）衬于脑室和脊髓中央管腔面，形成单层上皮样室管膜；立方形或柱形。
- [ ] 室管膜细胞游离面有许多微绒毛，少数有纤毛，摆动有助于脑脊液流动；部分细胞基底面有细长突起伸向深部。
- [ ] 脉络丛的室管膜细胞可产生脑脊液。
- [ ] 施万细胞（Schwann cell）参与周围神经纤维构成；有髓与无髓中形态和功能有差异；外表面有基膜；分泌神经营养因子，促进受损神经元存活及轴突再生。
- [ ] 卫星细胞（satellite cell）是神经节内包裹神经元胞体的一层扁平或立方形细胞；核圆或卵圆，染色质较浓密。
:::
