# 三、胚胎学的研究方法

科学研究的进展离不开实验方法的改良和技术的创新，胚胎学的研究方法从简单的肉眼观察、显微镜观察到分子生物学技术的应用，极大地推动了胚胎学研究的发展。本节按教材把八条方法摊开：鸡胚实验，胚胎切片和活体观察，转基因动物实验，示踪技术，显微操作技术，胚胎干细胞技术，基因编辑技术，体细胞克隆技术。学习时先问“看见形态、追踪细胞、改基因，还是重构一个核”，再把临床用得上的卵裂球检测、宫内手术和克隆猴模型接到相应方法上。

:::definition{label="胚胎学研究方法的演进"}
胚胎学的研究方法从简单的肉眼观察、显微镜观察到分子生物学技术的应用，极大地推动了胚胎学研究的发展。方法改良和技术创新是研究前进的条件。
:::

:::concept{term="先问这是看形态、追细胞、改基因，还是把核搬进去核卵"}
八条方法不要背成并列名词。鸡胚和连续切片解决“发育长成什么样、立体如何重建”；活体观察补动态；转基因问外源基因做什么；示踪问某群细胞迁到哪里、变成什么；显微操作在胚上切割、移植，也可切卵裂球或做宫内手术；胚胎干细胞要的是未分化的多能种子；基因编辑按预定方案改 DNA；体细胞克隆把体细胞核送进去核卵母细胞，让它重新编程。把 GFP 示踪听成转基因动物，或把核移植写成基因编辑，户头会接错。
:::

## （一）鸡胚实验

将鸡胚孵化至特定的发育阶段，应用鸡胚作为胚胎发育的研究模型，进行显微镜观察和描述，还可以在胚胎早期进行显微操作。随着分子生物学技术的发展，如 RNA 干扰、基因转染、基因组测序等技术应用，以及鸡胚的实验周期短、容易操作，均对研究胚胎发育相关基因的功能奠定了良好的实验基础。

:::definition{label="鸡胚实验"}
将鸡胚孵化至特定的发育阶段，作为胚胎发育的研究模型：可做显微镜观察和描述，也可在胚胎早期进行显微操作。鸡胚实验周期短、容易操作；结合 RNA 干扰、基因转染、基因组测序等，为研究胚胎发育相关基因的功能奠定实验基础。
:::

:::note{label="鸡胚既接描述，也接早期显微操作和基因功能"}
Hippocrates 已经观察过鸡蛋孵化；现代鸡胚实验把同一模型接到显微镜描述、早期显微操作，以及 RNA 干扰、基因转染、基因组测序。周期短、容易操作是它作为模型的理由，不是“只能看外形”。
:::

## （二）胚胎切片和活体观察

应用切片技术制作胚胎的连续切片，将每张切片的图像用图像分析技术进行计算机处理，可以获得胚胎立体结构图像。用肉眼和显微镜对活体胚胎的局部和整体发育进行观察，获得活体胚胎的动态活动状态。

:::definition{label="胚胎连续切片与立体重建"}
应用切片技术制作胚胎的连续切片，将每张切片的图像用图像分析技术进行计算机处理，可以获得胚胎立体结构图像。连续平面是为了还原立体，不是再多看几张互不相关的切片。
:::

:::definition{label="活体观察"}
用肉眼和显微镜对活体胚胎的局部和整体发育进行观察，获得活体胚胎的动态活动状态。它补的是时间轴，不是固定标本上的某一时刻。
:::

:::compare{title="连续切片与活体观察"}
| 项目 | 连续切片 + 图像分析 | 活体观察 |
|------|----------------------|----------|
| 对象 | 制成切片的胚胎 | 活体胚胎 |
| 手段 | 连续切片；计算机图像分析 | 肉眼和显微镜 |
| 得到 | 胚胎立体结构图像 | 局部和整体的动态活动状态 |
| 主要回答 | 三维形态如何组装 | 发育过程如何动起来 |
:::

## （三）转基因动物实验

把改建后的目的基因用显微注射等方法注入实验动物的受精卵内，将此受精卵植入受体动物的输卵管或子宫，使转基因动物携带有外源基因。该实验方法被广泛应用在基因功能分析、遗传病研究、疾病模式动物建立等。

:::definition{label="转基因动物实验"}
把改建后的目的基因用显微注射等方法注入实验动物的受精卵内，再将此受精卵植入受体动物的输卵管或子宫，使转基因动物携带有外源基因。广泛应用在基因功能分析、遗传病研究、疾病模式动物建立等。
:::

:::pitfall{label="转基因是把改建后的目的基因注入受精卵，不要写成把体细胞核整个搬进去"}
转基因动物携带的是外源基因：改建后的目的基因 → 显微注射等注入受精卵 → 植入受体输卵管或子宫。体细胞克隆是核供体进入去核卵母细胞。两本账都经过“早期胚胎再放回母体”，基因编辑、核移植和转基因不要并成一次操作。
:::

## （四）示踪技术

把带有绿色荧光蛋白（GFP）报告基因的逆转录病毒导入胚胎细胞，观察胚胎发育过程中表达绿色荧光蛋白细胞的迁移、定居和分化，研究胚胎发育过程中特定细胞的动态分化过程。示踪技术也常用无细胞毒性的活体染料，如台盼蓝、辣根过氧化酶等。

:::definition{label="示踪技术"}
示踪技术用于研究胚胎发育过程中特定细胞的动态分化过程。一条路是把带有绿色荧光蛋白（GFP）报告基因的逆转录病毒导入胚胎细胞，观察表达绿色荧光蛋白细胞的迁移、定居和分化；另一条路常用无细胞毒性的活体染料，如台盼蓝、辣根过氧化酶等。
:::

:::definition{label="GFP 报告基因示踪"}
将带有绿色荧光蛋白（GFP）报告基因的逆转录病毒导入胚胎细胞，使被标记细胞在发育中发出绿色荧光，从而观察其迁移、定居和分化。
:::

:::note{label="示踪的两条标记"}
| 标记 | 要点 |
|------|------|
| GFP 报告基因 + 逆转录病毒 | 导入胚胎细胞，观察表达 GFP 细胞的迁移、定居和分化 |
| 无细胞毒性活体染料 | 如台盼蓝、辣根过氧化酶等 |
:::

:::pitfall{label="台盼蓝、辣根过氧化酶是活体染料示踪，不要写成基因编辑或转基因动物"}
示踪问的是“这群细胞后来到了哪里、变成了什么”。GFP 走的是报告基因；台盼蓝和辣根过氧化酶走的是无细胞毒性活体染料。把染料听成“改了基因组”，或把 GFP 示踪听成建立疾病模式动物，会和转基因动物实验抢户头。
:::

## （五）显微操作技术

应用显微手术进行组织移植或组织切除，可以进行自体组织移植，也可以进行同种异体组织移植或异种组织移植。在临床上，也常应用显微操作技术分离切割卵裂球，进行植入前遗传学检测。在宫内手术时，应用显微操作技术治疗先天性膈疝、梗阻性脑积水等。

:::definition{label="显微操作技术"}
应用显微手术进行组织移植或组织切除：可做自体组织移植，也可做同种异体组织移植或异种组织移植。临床上常用于分离切割卵裂球，进行植入前遗传学检测；宫内手术时用于治疗先天性膈疝、梗阻性脑积水等。
:::

:::compare{title="显微操作的实验用途与临床用途"}
| 场景 | 具体操作 | 目的 |
|------|----------|------|
| 实验胚胎学 | 组织移植或组织切除 | 自体、同种异体或异种移植，分析发育影响 |
| 植入前 | 分离切割卵裂球 | 植入前遗传学检测 |
| 宫内手术 | 显微操作 | 治疗先天性膈疝、梗阻性脑积水等 |
:::

## （六）胚胎干细胞技术

$1981$ 年，英国科学家 Martin John Evans 建立首株小鼠胚胎干细胞系，并获得 $2007$ 年诺贝尔生理学或医学奖。胚胎干细胞（embryonic stem cell）是一类未分化的二倍体多能干细胞，具有无限增殖、自我更新和多向分化潜能，可以分化出神经细胞、心肌细胞、血细胞等，为细胞治疗奠定了基础。

:::definition{label="胚胎干细胞"}
胚胎干细胞（embryonic stem cell）是一类未分化的二倍体多能干细胞，具有无限增殖、自我更新和多向分化潜能，可以分化出神经细胞、心肌细胞、血细胞等，为细胞治疗奠定了基础。
:::

:::definition{label="小鼠胚胎干细胞系的建立"}
$1981$ 年，英国科学家 Martin John Evans 建立首株小鼠胚胎干细胞系，并获得 $2007$ 年诺贝尔生理学或医学奖。
:::

:::insight{label="未分化、二倍体、多能，三句话把胚胎干细胞和已定向的组织细胞切开"}
教材给胚胎干细胞的身份证是：未分化、二倍体、多能；能力是无限增殖、自我更新、多向分化；例证是神经细胞、心肌细胞、血细胞，落点是细胞治疗。把它听成“胚胎里随便一种细胞”，多能性和细胞治疗两本账都会做窄。
:::

## （七）基因编辑技术

基因编辑（gene editing）根据科研需要对目的基因进行插入、移除或替换等遗传操作，以引入预定 DNA 片段或修复突变基因等，从而达到控制生物性状和行为的目的。科研工作中，基因编辑技术作为实验工具在基因重组、模式生物制备、物种改良中发挥了重要的作用。第一代基因编辑技术采用核酸内切酶对 DNA 进行切割，DNA 断裂后利用自身的同源重组完成修复过程；第二代基因编辑则采用引导核酸加核酸内切酶技术，实现基于碱基配对原理修复或重组 DNA，提升了基因编辑的精确性。

:::definition{label="基因编辑"}
基因编辑（gene editing）根据科研需要对目的基因进行插入、移除或替换等遗传操作，以引入预定 DNA 片段或修复突变基因等，从而达到控制生物性状和行为的目的。作为实验工具，用于基因重组、模式生物制备、物种改良。
:::

:::definition{label="第一代基因编辑"}
第一代基因编辑技术采用核酸内切酶对 DNA 进行切割，DNA 断裂后利用自身的同源重组完成修复过程。
:::

:::definition{label="第二代基因编辑"}
第二代基因编辑采用引导核酸加核酸内切酶技术，实现基于碱基配对原理修复或重组 DNA，提升了基因编辑的精确性。
:::

:::compare{title="第一代与第二代基因编辑"}
| 项目 | 第一代 | 第二代 |
|------|--------|--------|
| 工具 | 核酸内切酶切割 DNA | 引导核酸 + 核酸内切酶 |
| 修复 / 重组 | 断裂后利用自身同源重组修复 | 基于碱基配对原理修复或重组 DNA |
| 教材强调 | 切割 + 自身同源重组 | 精确性提升 |
:::

:::pitfall{label="教材只写到第二代（引导核酸加核酸内切酶），不要另编第三代名称或工具"}
目的都是插入、移除或替换，以引入预定 DNA 片段或修复突变基因。差别在怎么找到切口、怎么修：第一代靠内切酶切割后自身同源重组；第二代靠引导核酸加内切酶，按碱基配对提高精确性。把两代并成一句“都能改基因”，精确性那本账会做丢；补写教材未给出的工具名称，简史和方法都会失真。
:::

## （八）体细胞克隆技术

体细胞克隆技术（somatic cell clone technology）又称为体细胞核移植技术，是指动物体细胞经过抑制培养，使细胞处于休眠状态。采用核移植的方法，利用细胞拆合或细胞重组技术，将卵母细胞去核作为核受体，以体细胞或含少量细胞质的细胞核，即核质体作为核供体，将后者移入前者中，构建重组胚，核供体在去核卵母细胞的细胞质中重新编程，并启动卵裂，开始胚胎发育过程，妊娠产仔。应用该技术，世界上首例体细胞克隆猴“中中”于 $2017$ 年 $11$ 月 $27$ 日在我国诞生，开启了以体细胞克隆猴作为实验动物模型的新时代。

:::definition{label="体细胞克隆技术"}
体细胞克隆技术（somatic cell clone technology）又称体细胞核移植技术。动物体细胞经抑制培养处于休眠状态；卵母细胞去核作为核受体，体细胞或含少量细胞质的细胞核（核质体）作为核供体，将后者移入前者，构建重组胚。核供体在去核卵母细胞的细胞质中重新编程，启动卵裂，开始胚胎发育，妊娠产仔。
:::

:::definition{label="核受体与核供体"}
核受体是去核的卵母细胞；核供体是体细胞，或含少量细胞质的细胞核（核质体）。方向是核供体移入核受体，不能写反。
:::

:::definition{label="核质体"}
核质体是含少量细胞质的细胞核，可作为核供体进入去核卵母细胞。
:::

:::definition{label="克隆猴“中中”"}
世界上首例体细胞克隆猴“中中”于 $2017$ 年 $11$ 月 $27$ 日在我国诞生，开启了以体细胞克隆猴作为实验动物模型的新时代。
:::

:::compare{title="八种研究方法各问什么"}
| 方法 | 核心操作 | 主要回答 |
|------|----------|----------|
| 鸡胚实验 | 孵化至特定阶段；观察、描述、早期显微操作；可接 RNA 干扰、基因转染、基因组测序 | 基因功能；周期短、易操作的发育模型 |
| 胚胎切片和活体观察 | 连续切片 + 图像分析；肉眼/显微镜看活体 | 立体结构；动态活动状态 |
| 转基因动物实验 | 改建目的基因注入受精卵，植入受体输卵管或子宫 | 基因功能、遗传病、疾病模式动物 |
| 示踪技术 | GFP 逆转录病毒或台盼蓝、辣根过氧化酶等 | 特定细胞的迁移、定居、分化 |
| 显微操作技术 | 组织移植/切除；切卵裂球；宫内手术 | 实验干预；植入前遗传学检测；膈疝、脑积水等 |
| 胚胎干细胞技术 | 未分化二倍体多能干细胞 | 无限增殖、自我更新、多向分化；细胞治疗基础 |
| 基因编辑技术 | 插入、移除或替换目的基因 | 引入预定 DNA 或修复突变；重组、模式生物、物种改良 |
| 体细胞克隆技术 | 核质体/体细胞核 → 去核卵母细胞 | 重新编程、卵裂、妊娠产仔；克隆猴模型 |
:::

:::pitfall{label="核供体是体细胞或核质体，核受体是去核卵母细胞，不要写反"}
体细胞先抑制培养至休眠，再按核移植把核供体移入核受体，构建重组胚；重新编程发生在去核卵母细胞的细胞质里，然后才启动卵裂、妊娠产仔。“中中”是 $2017$ 年 $11$ 月 $27$ 日诞生的体细胞克隆猴，户头是实验动物模型，不是基因编辑的例子。
:::

:::keypoint{label="方法从肉眼、切片推进到分子、干细胞和核移植"}
- 总原则：方法改良和技术创新推动胚胎学研究；从肉眼、显微镜到分子生物学。
- 鸡胚：特定阶段模型，可观察、显微操作，并接 RNA 干扰、基因转染、基因组测序。
- 连续切片经图像分析得立体结构；活体观察得动态。
- 转基因：目的基因 → 受精卵 → 受体输卵管或子宫；用于功能、遗传病、模式动物。
- 示踪：GFP 逆转录病毒，或台盼蓝、辣根过氧化酶等活体染料。
- 显微操作：自体/同种异体/异种移植；切卵裂球做植入前遗传学检测；宫内治疗先天性膈疝、梗阻性脑积水。
- Evans（$1981$）建小鼠胚胎干细胞系，$2007$ 年诺贝尔奖；ESC 为未分化二倍体多能干细胞。
- 基因编辑分第一代（内切酶 + 同源重组）和第二代（引导核酸 + 内切酶，碱基配对，更精确）。
- 体细胞克隆即核移植；$2017$ 年 $11$ 月 $27$ 日克隆猴“中中”在我国诞生。
:::

- [ ] 用肉眼和显微镜观察活体胚胎的局部和整体发育，获得动态活动状态。
- [ ] 转基因：改建后的目的基因用显微注射等方法注入受精卵，再植入受体动物输卵管或子宫，使动物携带外源基因。
- [ ] 转基因动物实验广泛应用于基因功能分析、遗传病研究、疾病模式动物建立等。
- [ ] 示踪：把带 GFP 报告基因的逆转录病毒导入胚胎细胞，观察表达 GFP 细胞的迁移、定居和分化。
- [ ] 示踪也常用无细胞毒性活体染料，如台盼蓝、辣根过氧化酶等。
- [ ] 显微操作可进行组织移植或组织切除；包括自体、同种异体或异种组织移植。
- [ ] 临床可用显微操作分离切割卵裂球，进行植入前遗传学检测。
- [ ] 宫内手术时，显微操作可用于治疗先天性膈疝、梗阻性脑积水等。
- [ ] $1981$ 年英国科学家 Martin John Evans 建立首株小鼠胚胎干细胞系，获 $2007$ 年诺贝尔生理学或医学奖。
- [ ] 胚胎干细胞（embryonic stem cell）是未分化的二倍体多能干细胞，具有无限增殖、自我更新和多向分化潜能。
- [ ] 胚胎干细胞可分化出神经细胞、心肌细胞、血细胞等，为细胞治疗奠定基础。
- [ ] 基因编辑（gene editing）对目的基因进行插入、移除或替换，以引入预定 DNA 片段或修复突变基因，控制性状和行为。
- [ ] 基因编辑用于基因重组、模式生物制备、物种改良。
- [ ] 第一代基因编辑：核酸内切酶切割 DNA，断裂后利用自身同源重组修复。
- [ ] 第二代基因编辑：引导核酸加核酸内切酶，基于碱基配对原理修复或重组 DNA，精确性提升。
- [ ] 体细胞克隆技术（somatic cell clone technology）又称体细胞核移植技术。
- [ ] 体细胞经抑制培养处于休眠；卵母细胞去核为核受体，体细胞或核质体为核供体。
- [ ] 核供体移入核受体构建重组胚，在去核卵母细胞质中重新编程，启动卵裂，妊娠产仔。
- [ ] $2017$ 年 $11$ 月 $27$ 日，世界上首例体细胞克隆猴“中中”在我国诞生，开启克隆猴实验动物模型新时代。
