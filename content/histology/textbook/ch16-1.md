# 一、鼻腔

呼吸系统（respiratory system）包括鼻、咽、喉、气管、主支气管和肺，这些器官共同完成从外界摄入氧气、排出二氧化碳的功能。从鼻腔到肺内终末细支气管，各器官传导气体，为导气部；从肺内呼吸性细支气管至末端的肺泡，是气体交换的部位，为呼吸部。另外，鼻有嗅觉功能，喉有发音功能，肺还参与多种物质的分泌、合成和代谢。本章先把鼻黏膜三部摊开；喉、气管与主支气管、肺各立一节。

:::definition{label="呼吸系统"}
呼吸系统（respiratory system）包括鼻、咽、喉、气管、主支气管和肺。共同完成从外界摄入氧气、排出二氧化碳。鼻另有嗅觉，喉另有发音，肺还参与多种物质的分泌、合成和代谢。
:::

:::definition{label="导气部"}
导气部是传导气体的管道，从鼻腔一直到肺内终末细支气管。这一段没有肺泡开口，不承担气体交换，职分是通气、滤过、加温加湿和调节气流量。
:::

:::definition{label="呼吸部"}
呼吸部是气体交换的部位，从肺内呼吸性细支气管至末端的肺泡。管壁或囊壁上出现肺泡，氧气和二氧化碳才在这里过气–血屏障。
:::

:::concept{term="先问这段管道壁上有没有肺泡开口"}
看见呼吸系统，先把两本账切开：有肺泡开口的才是呼吸部，没有肺泡的全是导气部。鼻、咽、喉、气管、主支气管和肺内直到终末细支气管，都还在“把气送进去”；呼吸性细支气管才开始在管壁上开几个肺泡。把终末细支气管听成“最后一级，当然换气”，气体交换账会提前一级做错。
:::

:::compare{title="导气部与呼吸部"}
| 项目 | 导气部 | 呼吸部 |
|------|--------|--------|
| 起止 | 鼻腔 → 肺内终末细支气管 | 肺内呼吸性细支气管 → 肺泡 |
| 有无肺泡 | 无肺泡开口 | 管壁或囊壁出现肺泡 |
| 主要职分 | 传导气体；滤过、加温加湿；调节气流量 | 气体交换 |
| 上皮大方向 | 假复层纤毛柱状为主，末端渐变为单层柱状 | 单层立方移行为单层扁平（Ⅰ型肺泡细胞） |
| 易混点 | 终末细支气管仍属导气部 | 呼吸性细支气管虽细，已是呼吸部起点 |
:::

:::note{label="鼻、喉、肺在通气之外的职分"}
| 器官 | 额外职分 |
|------|----------|
| 鼻 | 嗅觉（嗅黏膜） |
| 喉 | 发音（声带振动主要在膜部） |
| 肺 | 气体交换之外，还参与多种物质的分泌、合成和代谢（表面活性物质、解毒等写在第 16-4 节） |
:::

:::pitfall{label="终末细支气管不是气体交换部"}
导气部的终点写在终末细支气管，呼吸部的起点写在呼吸性细支气管。判断尺子只有一把：管壁上有没有肺泡。终末细支气管上皮是单层柱状、环行平滑肌完整，但没有肺泡开口，不能把“终末”听成“已经开始换气”。
:::

## 一、鼻腔

鼻腔内表面为黏膜，由上皮和固有层构成；黏膜下方与软骨、骨或骨骼肌相连。依据鼻黏膜的部位和功能分为前庭部、呼吸部和嗅部。

:::definition{label="鼻腔黏膜"}
鼻腔内表面为黏膜，由上皮和固有层构成。黏膜下方与软骨、骨或骨骼肌相连。按部位和功能分为前庭部、呼吸部和嗅部。
:::

:::concept{term="先问这块鼻黏膜是前庭、呼吸还是嗅"}
进鼻腔先换三把尺子：入口附近有没有鼻毛和角化，是前庭部；大面积淡红、假复层纤毛柱状加静脉丛，是呼吸部；鼻中隔上部、上鼻甲和顶部呈棕黄，才是嗅部。三部都叫黏膜，上皮和职分完全不是一本账。把“鼻黏膜”听成全程假复层纤毛柱状，嗅细胞和鼻毛两头都会写丢。
:::

:::compare{title="鼻黏膜前庭部、呼吸部与嗅部"}
| 项目 | 前庭部 | 呼吸部 | 嗅部 |
|------|--------|--------|------|
| 位置 | 鼻腔入口、鼻翼内表面 | 下鼻甲、中鼻甲、鼻道及鼻中隔中下部；占鼻黏膜大部分 | 鼻中隔上部两侧、上鼻甲及鼻腔顶部 |
| 上皮 | 未角化复层扁平；近外鼻孔角化，与皮肤相移行 | 假复层纤毛柱状，杯状细胞较多，基膜较厚 | 较厚的假复层柱状上皮（嗅上皮） |
| 固有层要点 | 细密结缔组织 | 鼻腺（混合腺）、丰富静脉丛与淋巴组织 | 浆液性嗅腺，富含血管 |
| 外观 | 有鼻毛、皮脂腺 | 富含血管，呈淡红色 | 呈棕黄色 |
| 职分 | 阻挡尘埃 | 滤过、加温加湿；黏膜损伤易出血 | 嗅觉 |
| 面积（人 / 狗） | — | 大部分 | 人约 $2\,\mathrm{cm}^{2}$；狗约 $100\,\mathrm{cm}^{2}$ |
:::

### 1. 前庭部

前庭部（vestibular region）为鼻腔入口处。鼻翼内表面为未角化复层扁平上皮，近外鼻孔处上皮出现角化，与皮肤相移行，并有鼻毛和皮脂腺。鼻毛能阻挡空气中的尘埃等异物。固有层为细密结缔组织，鼻疖肿发生时疼痛剧烈。

:::definition{label="前庭部"}
前庭部（vestibular region）是鼻腔入口处。鼻翼内表面为未角化复层扁平上皮；近外鼻孔处上皮出现角化，与皮肤相移行，并有鼻毛和皮脂腺。
:::

:::definition{label="鼻毛"}
鼻毛位于近外鼻孔的角化上皮区，能阻挡空气中的尘埃等异物。它是机械滤网，不是纤毛，不要和呼吸部上皮的摆动纤毛并成一句。
:::

:::insight{label="前庭部按皮肤的规矩长，疼痛也按皮肤的规矩来"}
近外鼻孔已经角化、有鼻毛和皮脂腺，等于把皮肤折进鼻孔。固有层是细密结缔组织，炎症渗出没有疏松空间可退，鼻疖肿发生时疼痛剧烈。把前庭部听成“又一段呼吸道假复层纤毛柱状”，鼻毛、皮脂腺和疖肿那几本账会从第一站错位。
:::

:::pitfall{label="前庭部近外鼻孔是角化复层扁平，不要写成全程未角化"}
鼻翼内表面未角化，近外鼻孔才角化并与皮肤相移行。两段都是复层扁平，角化有无是分界。不要把前庭部一律写成未角化，也不要写成假复层纤毛柱状。
:::

### 2. 呼吸部

呼吸部（respiratory region）占鼻黏膜的大部分，包括下鼻甲、中鼻甲、鼻道及鼻中隔中下部的黏膜，因富含血管而呈淡红色。上皮为假复层纤毛柱状上皮，杯状细胞较多，基膜较厚。固有层内有混合腺，称鼻腺。其分泌物与杯状细胞分泌物共同形成一层黏液覆盖于黏膜表面。纤毛向咽部摆动，将黏着的细菌及尘埃颗粒推向咽部而被咳出。固有层还有丰富的静脉丛与淋巴组织，丰富的血流通过散热和渗出而对吸入的空气有加温或加湿作用。损伤黏膜时此部位容易出血。

:::definition{label="呼吸部（鼻黏膜）"}
呼吸部（respiratory region）占鼻黏膜的大部分，包括下鼻甲、中鼻甲、鼻道及鼻中隔中下部的黏膜，因富含血管而呈淡红色。上皮为假复层纤毛柱状上皮，杯状细胞较多，基膜较厚。
:::

:::definition{label="鼻腺"}
鼻腺是呼吸部固有层内的混合腺。其分泌物与杯状细胞分泌物共同形成一层黏液，覆盖于黏膜表面。纤毛向咽部摆动，把黏着的细菌及尘埃颗粒推向咽部咳出。
:::

:::definition{label="鼻黏膜静脉丛"}
呼吸部固有层有丰富的静脉丛与淋巴组织。丰富的血流通过散热和渗出，对吸入的空气有加温或加湿作用。损伤黏膜时此部位容易出血。
:::

:::insight{label="呼吸部把空气先做成“又湿又暖的黏液传送带”"}
杯状细胞和鼻腺铺黏液，纤毛向咽部摆动，等于一条单向传送带；静脉丛用血流的热量和水汽给空气加温加湿。肺还没接手，空气已经被处理过一遍。把呼吸部听成“已经开始换气”，会和肺泡那本真正的呼吸部账撞名。
:::

:::pitfall{label="鼻黏膜的呼吸部不是肺的呼吸部"}
鼻腔呼吸部的“呼吸”指这块黏膜承担通气时的滤过、加温和加湿，上皮仍是假复层纤毛柱状，没有肺泡。肺的呼吸部从呼吸性细支气管才开始出现肺泡。两个“呼吸部”同名不同账，考试最容易对调。
:::

:::pitfall{label="损伤呼吸部黏膜容易出血，不要只写成“鼻中隔上部才出血”"}
呼吸部因静脉丛丰富而呈淡红色，黏膜损伤时此部位容易出血。嗅部在鼻中隔上部，面积小、呈棕黄，不是这本出血账的主角。
:::

### 3. 嗅部

嗅部（olfactory region）位于鼻中隔上部两侧、上鼻甲及鼻腔顶部。人嗅黏膜面积约为 $2\,\mathrm{cm}^{2}$。狗嗅黏膜面积约为 $100\,\mathrm{cm}^{2}$，故嗅觉特别发达。嗅黏膜呈棕黄色，上皮为较厚的假复层柱状上皮，含嗅细胞、支持细胞和基细胞，称嗅上皮（图 16-1，图 16-2）。

:::definition{label="嗅部"}
嗅部（olfactory region）位于鼻中隔上部两侧、上鼻甲及鼻腔顶部。人嗅黏膜面积约为 $2\,\mathrm{cm}^{2}$，狗约为 $100\,\mathrm{cm}^{2}$。嗅黏膜呈棕黄色。
:::

:::definition{label="嗅上皮"}
嗅上皮是较厚的假复层柱状上皮，含嗅细胞、支持细胞和基细胞三种细胞。它是嗅觉的上皮落点，不是又一段会摆动的呼吸道纤毛上皮。
:::

::figure{src="/images/histology/textbook/p0184_02.png" caption="图16-1 嗅黏膜光镜图。1. 嗅毛与分泌物；2. 支持细胞核；3. 嗅细胞核；4. 基细胞核；5. 嗅腺。" alt="嗅黏膜HE切片：游离面嗅毛与分泌物，上皮内支持细胞、嗅细胞和基细胞核分层，固有层见嗅腺"}

**（1）嗅细胞** 嗅细胞（olfactory cell）呈梭形，夹在支持细胞之间，细胞核位于嗅上皮的中层，为双极神经元，是体内唯一存在于上皮中的感觉神经元。其树突伸至上皮游离面，末端膨大形成球状嗅泡。从嗅泡发出 $10\sim 30$ 根较长的嗅毛，嗅毛属于纤毛，但由于其内含微管（主要为单微管），故不能摆动，而是倒伏、浸埋于上皮表面的嗅腺分泌物中。从嗅细胞基部发出一条细长轴突，在穿过上皮基膜进入固有层时，被一种称为嗅鞘细胞（olfactory ensheathing cell）的神经胶质细胞包裹，构成无髓神经纤维，并组成嗅神经。嗅毛为嗅觉感受器，细胞膜内有多种受体，接受不同化学物质的刺激，使嗅细胞产生冲动，传入中枢，产生嗅觉。

:::definition{label="嗅细胞"}
嗅细胞（olfactory cell）呈梭形，夹在支持细胞之间，核位于嗅上皮中层。它是双极神经元，也是体内唯一存在于上皮中的感觉神经元。
:::

:::definition{label="嗅泡"}
嗅细胞的树突伸至上皮游离面，末端膨大形成球状嗅泡。从嗅泡发出 $10\sim 30$ 根较长的嗅毛。
:::

:::definition{label="嗅毛"}
嗅毛属于纤毛，但其内含微管（主要为单微管），故不能摆动，而是倒伏、浸埋于上皮表面的嗅腺分泌物中。嗅毛是嗅觉感受器，细胞膜内有多种受体，接受不同化学物质刺激。
:::

:::definition{label="嗅鞘细胞"}
嗅鞘细胞（olfactory ensheathing cell）是包裹嗅细胞轴突的神经胶质细胞。嗅细胞基部发出一条细长轴突，穿过上皮基膜进入固有层时被嗅鞘细胞包裹，构成无髓神经纤维，并组成嗅神经。
:::

**（2）支持细胞** 支持细胞数量最多，呈高柱状，顶部宽大，基部较细，游离面有许多微绒毛。细胞核位于嗅上皮浅部，细胞质内线粒体较多，常见黄色色素颗粒。支持细胞起支持和分隔嗅细胞的作用。

:::definition{label="嗅上皮支持细胞"}
支持细胞数量最多，呈高柱状，顶部宽大、基部较细，游离面有许多微绒毛。核位于嗅上皮浅部，胞质内线粒体较多，常见黄色色素颗粒。职分是支持和分隔嗅细胞。
:::

**（3）基细胞** 基细胞呈锥形，位于上皮深部，是干细胞，可增殖分化为嗅细胞和支持细胞。固有层结缔组织中富含血管，并有许多浆液性的嗅腺，分泌的浆液沿导管排至鼻黏膜表面，可溶解空气中的化学物质，刺激嗅毛，引起嗅觉。嗅腺不断分泌浆液，可清洗上皮表面，保持嗅细胞感受刺激的敏感性。

:::definition{label="嗅上皮基细胞"}
基细胞呈锥形，位于上皮深部，是干细胞，可增殖分化为嗅细胞和支持细胞。
:::

:::definition{label="嗅腺"}
嗅腺是固有层内浆液性腺。分泌的浆液沿导管排至鼻黏膜表面，溶解空气中的化学物质以刺激嗅毛；并不断清洗上皮表面，保持嗅细胞感受刺激的敏感性。
:::

:::

:::pitfall{label="嗅毛是纤毛但不能摆动，不要写成呼吸道那种清扫纤毛"}
嗅毛属于纤毛，微管却主要为单微管，所以倒伏在嗅腺浆液里当受体，不向咽部摆动。呼吸部假复层纤毛柱状上皮的纤毛才负责把黏液推向咽部。把嗅毛听成“也会扫灰尘”，嗅觉感受器账就做成了黏液传送带。
:::

:::insight{label="嗅细胞是上皮里的神经元，浆液是它的溶剂"}
感受器不在固有层的游离神经末梢，而在上皮中的双极神经元：树突在游离面变成嗅泡和嗅毛，轴突被嗅鞘细胞送进嗅神经。嗅腺浆液先把气味分子溶进去，再不断冲洗，保持敏感。狗的嗅黏膜约 $100\,\mathrm{cm}^{2}$、人约 $2\,\mathrm{cm}^{2}$，面积差就是灵敏度差。把嗅觉听成“普通黏膜上多了几个受体”，上皮内神经元这本唯一的账会做丢。
:::

:::keypoint{label="鼻腔先立导气部与呼吸部，再把黏膜写成前庭、呼吸、嗅三部"}
- 呼吸系统 = 鼻、咽、喉、气管、主支气管和肺；导气部从鼻腔到终末细支气管，呼吸部从呼吸性细支气管到肺泡。
- 鼻黏膜分前庭部、呼吸部、嗅部；黏膜由上皮和固有层构成，下方连软骨、骨或骨骼肌。
- 前庭部：入口；未角化复层扁平，近外鼻孔角化，有鼻毛和皮脂腺；固有层细密，疖肿疼痛剧烈。
- 呼吸部：大部分，淡红色；假复层纤毛柱状，杯状细胞多，基膜厚；鼻腺 + 静脉丛，加温加湿，损伤易出血。
- 嗅部：鼻中隔上部、上鼻甲和顶部，人约 $2\,\mathrm{cm}^{2}$、狗约 $100\,\mathrm{cm}^{2}$，棕黄色。
- 嗅上皮三种细胞：嗅细胞（双极神经元，$10\sim 30$ 根不摆动的嗅毛）、支持细胞、基细胞；轴突被嗅鞘细胞包裹成嗅神经。
- 嗅腺浆液溶解气味分子并冲洗上皮，保持嗅细胞敏感。
:::

:::memory{label="本节必背要点"}
- [ ] 呼吸系统（respiratory system）包括鼻、咽、喉、气管、主支气管和肺，共同完成从外界摄入氧气、排出二氧化碳。
- [ ] 从鼻腔到肺内终末细支气管传导气体，为导气部；从肺内呼吸性细支气管至末端的肺泡是气体交换部位，为呼吸部。
- [ ] 鼻有嗅觉功能，喉有发音功能，肺还参与多种物质的分泌、合成和代谢。
- [ ] 鼻腔内表面为黏膜，由上皮和固有层构成；黏膜下方与软骨、骨或骨骼肌相连。
- [ ] 依据部位和功能，鼻黏膜分为前庭部、呼吸部和嗅部。
- [ ] 前庭部（vestibular region）为鼻腔入口处；鼻翼内表面为未角化复层扁平上皮。
- [ ] 近外鼻孔处上皮出现角化，与皮肤相移行，并有鼻毛和皮脂腺；鼻毛能阻挡空气中的尘埃等异物。
- [ ] 前庭部固有层为细密结缔组织，鼻疖肿发生时疼痛剧烈。
- [ ] 呼吸部（respiratory region）占鼻黏膜大部分，包括下鼻甲、中鼻甲、鼻道及鼻中隔中下部的黏膜，因富含血管而呈淡红色。
- [ ] 呼吸部上皮为假复层纤毛柱状上皮，杯状细胞较多，基膜较厚。
- [ ] 呼吸部固有层内有混合腺，称鼻腺；其分泌物与杯状细胞分泌物共同形成一层黏液覆盖于黏膜表面。
- [ ] 纤毛向咽部摆动，将黏着的细菌及尘埃颗粒推向咽部而被咳出。
- [ ] 呼吸部固有层还有丰富的静脉丛与淋巴组织；丰富的血流通过散热和渗出，对吸入空气有加温或加湿作用。
- [ ] 损伤呼吸部黏膜时此部位容易出血。
- [ ] 嗅部（olfactory region）位于鼻中隔上部两侧、上鼻甲及鼻腔顶部。
- [ ] 人嗅黏膜面积约为 $2\,\mathrm{cm}^{2}$；狗嗅黏膜面积约为 $100\,\mathrm{cm}^{2}$，故嗅觉特别发达。
- [ ] 嗅黏膜呈棕黄色，上皮为较厚的假复层柱状上皮，含嗅细胞、支持细胞和基细胞，称嗅上皮。
- [ ] 嗅细胞（olfactory cell）呈梭形，夹在支持细胞之间，核位于嗅上皮中层，为双极神经元，是体内唯一存在于上皮中的感觉神经元。
- [ ] 嗅细胞树突伸至游离面，末端膨大形成球状嗅泡；从嗅泡发出 $10\sim 30$ 根较长的嗅毛。
- [ ] 嗅毛属于纤毛，但其内含微管（主要为单微管），故不能摆动，而是倒伏、浸埋于嗅腺分泌物中。
- [ ] 嗅细胞基部发出一条细长轴突，穿过基膜进入固有层时被嗅鞘细胞（olfactory ensheathing cell）包裹，构成无髓神经纤维并组成嗅神经。
- [ ] 嗅毛为嗅觉感受器，细胞膜内有多种受体，接受不同化学物质刺激，使嗅细胞产生冲动传入中枢。
- [ ] 支持细胞数量最多，呈高柱状，顶部宽大、基部较细，游离面有许多微绒毛；核位于嗅上皮浅部，胞质内线粒体较多，常见黄色色素颗粒；起支持和分隔嗅细胞的作用。
- [ ] 基细胞呈锥形，位于上皮深部，是干细胞，可增殖分化为嗅细胞和支持细胞。
- [ ] 固有层有许多浆液性嗅腺，分泌的浆液溶解空气中的化学物质以刺激嗅毛，并不断清洗上皮表面，保持嗅细胞敏感性。
:::
