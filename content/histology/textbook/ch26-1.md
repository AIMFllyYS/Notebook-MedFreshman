# 一、神经组织的发生

神经系统起源于神经外胚层。神经外胚层先形成神经管和神经嵴：神经管分化为中枢神经系统（脊髓、脑）、神经垂体和松果体等；神经嵴分化为周围神经系统（神经节、周围神经）和肾上腺髓质等。本节先把神经板 → 神经沟 → 神经管这一条闭合账立住，再按神经上皮三层（室管膜层、套层、边缘层）、成神经细胞从无极到多极、中枢与周围的胶质发生摊开。脑泡分段和脊髓的基板、翼板见后两节。

神经系统起源于神经外胚层。神经外胚层先形成神经管和神经嵴，前者分化为中枢神经系统（脊髓、脑）、神经垂体和松果体等，后者则分化为周围神经系统（神经节、周围神经）和肾上腺髓质等。

:::definition{label="神经外胚层"}
神经外胚层是神经系统的起源。它先形成神经管和神经嵴两份原基，不是一开始就分成脑和脊髓。
:::

:::definition{label="神经管的分化范围"}
神经管分化为中枢神经系统（脊髓、脑）、神经垂体和松果体等。中枢神经元和大多数中枢胶质细胞都从这里来。
:::

:::definition{label="神经嵴的分化范围"}
神经嵴分化为周围神经系统（神经节、周围神经）和肾上腺髓质等。周围神经系统的神经元和神经胶质细胞由神经嵴细胞迁移分化而成。
:::

胚胎第 $3$ 周末，胚盘背正中部的外胚层增厚为神经板，不久凹陷成神经沟，第 $4$ 周初形成神经管。随着神经管的形成，位于神经板与表面外胚层间的神经上皮移向神经管背外侧，成为两条纵行细胞索，称为神经嵴。神经管产生中枢神经系统的神经元和大多数神经胶质细胞。周围神经系统的神经元和神经胶质细胞则由神经嵴细胞迁移分化而成。

:::definition{label="神经板"}
胚胎第 $3$ 周末，胚盘背正中部的外胚层增厚为神经板。它还是一层加厚的外胚层，尚未凹陷，更没有闭合。
:::

:::definition{label="神经沟"}
神经板不久凹陷成神经沟。沟的两侧缘稍后才对合；对合之前还不是神经管。
:::

:::definition{label="神经管"}
第 $4$ 周初，神经沟闭合形成神经管。闭合完成，中枢神经系统的原基才立住。神经管产生中枢神经系统的神经元和大多数神经胶质细胞。
:::

:::definition{label="神经嵴"}
随着神经管的形成，位于神经板与表面外胚层间的神经上皮移向神经管背外侧，成为两条纵行细胞索，称为神经嵴。它不在管腔内，而在管的背外侧。
:::

:::concept{term="先问这是神经管还是神经嵴，再问细胞已经迁到套层没有"}
看见神经系统发生，先把原基切开：背正中外胚层增厚是神经板，凹陷是神经沟，第 $4$ 周初闭合才是神经管，走中枢、神经垂体和松果体；夹在神经板与表面外胚层之间、迁到管背外侧的两条细胞索才是神经嵴，走周围神经和肾上腺髓质。再问管壁：还是假复层神经上皮，还是已经分出套层、室管膜层和边缘层。把神经嵴听成“神经管里的一层”，或把神经沟听成已经闭合的管，后面的成神经细胞和胶质会对错户头。
:::

:::timeline{period="从神经板到神经管、神经嵴"}
- **第3周末** 胚盘背正中部外胚层增厚为神经板
- **随后** 神经板凹陷成神经沟
- **第4周初** 神经沟闭合形成神经管
- **同时** 神经板与表面外胚层之间的神经上皮移向神经管背外侧，成两条纵行神经嵴
- **去向** 神经管 → 中枢神经元和大多数中枢胶质；神经嵴 → 周围神经元和周围胶质
:::

:::compare{title="神经管与神经嵴"}
| 项目 | 神经管 | 神经嵴 |
|------|--------|--------|
| 形成时间 | 第 $4$ 周初由神经沟闭合 | 随神经管形成，细胞移向管背外侧 |
| 位置 | 胚盘背正中，已闭合的管 | 神经管背外侧两条纵行细胞索 |
| 来源细胞 | 神经板神经上皮 | 原位于神经板与表面外胚层之间的神经上皮 |
| 神经元 | 中枢神经系统的神经元 | 周围神经系统的神经元（脑、脊神经节，交感成神经细胞等） |
| 胶质 | 大多数中枢胶质细胞 | 周围神经系统全部胶质（施万细胞、卫星细胞） |
| 还分出 | 神经垂体、松果体等 | 肾上腺髓质等 |
| 不要听成 | 已经分成脑和脊髓 | 神经管壁上的一层 |
:::

:::pitfall{label="神经沟还不是神经管，第4周初闭合才算管"}
第 $3$ 周末先有神经板，不久成神经沟，第 $4$ 周初才闭合为神经管。写成“第 $3$ 周末已经有神经管”，神经沟闭合这本账会消失；后面无脑畸形、脊髓裂那一套（前、后神经孔未闭）也就没有时间点可挂。
:::

:::insight{label="一份神经外胚层，先分成管和嵴两本账"}
中枢不从神经嵴来，周围不从神经管来——这是默认户头。副交感神经节起源教材写明尚有争议，不能把例外写成通则。神经垂体、松果体挂在神经管上；肾上腺髓质挂在神经嵴上。只背“神经系统来自外胚层”，管和嵴会对错。
:::

## （一）神经上皮的早期分化

神经管壁最初由单层柱状上皮构成，以后演变为假复层柱状上皮，称神经上皮（neuroepithelium）。神经上皮外包一层较厚的基膜，称外界膜；管壁内面也有一层膜，称内界膜（图 26-1）。神经上皮部分细胞迁移至神经上皮的外周，形成一个新的细胞层，称套层（mantle layer），将分化出成神经细胞（neuroblast）和成神经胶质细胞（glioblast）。余下的神经上皮停止分化，变为单层立方或矮柱状上皮，称室管膜层（ependymal layer）。成神经细胞随即伸出突起，并延伸至套层外周，形成细胞稀少的边缘层（marginal layer）。随着成神经细胞的分化，套层中的成神经胶质细胞也分化为星形胶质细胞和少突胶质细胞，并有部分细胞迁入边缘层（图 26-1）。

:::definition{label="神经上皮"}
神经上皮（neuroepithelium）由神经管壁上皮演变而来：最初是单层柱状上皮，以后成为假复层柱状上皮。它外包外界膜，内衬内界膜。
:::

:::definition{label="外界膜"}
外界膜是神经上皮外包的一层较厚基膜，位于管壁外面。它不是细胞层，不要和边缘层并成一层。
:::

:::definition{label="内界膜"}
内界膜是管壁内面的一层膜，朝向神经管腔。内界膜在里、外界膜在外，方位不要反。
:::

:::definition{label="套层"}
套层（mantle layer）由部分神经上皮细胞迁移至神经上皮外周形成。它将分化出成神经细胞和成神经胶质细胞，是后来灰质的细胞来源。
:::

:::definition{label="成神经细胞"}
成神经细胞（neuroblast）由套层分化而来，一般不再分裂增殖。它随后伸出突起，进入边缘层，进一步按无极 → 双极 → 单极 → 多极发育为神经元。
:::

:::definition{label="成神经胶质细胞"}
成神经胶质细胞（glioblast）与成神经细胞一同出自套层。随着成神经细胞分化，套层中的成神经胶质细胞分化为星形胶质细胞和少突胶质细胞，并有部分细胞迁入边缘层。
:::

:::definition{label="室管膜层"}
室管膜层（ependymal layer）是余下的神经上皮停止分化后变成的单层立方或矮柱状上皮，衬于管腔面。它不再迁出细胞去造神经元。
:::

:::definition{label="边缘层"}
边缘层（marginal layer）是成神经细胞突起延伸至套层外周形成的细胞稀少层。后来白质主要在这里加厚。
:::

::figure{src="/images/histology/textbook/p0282_02.png" caption="图26-1 神经管上皮的早期分化模式图。左：神经管外形及横切方位；右上：早期神经上皮为假复层柱状，内衬内界膜、外包外界膜；下：管壁从内向外分为室管膜层、套层和边缘层，套层中可见无极、双极、单极和多极成神经细胞。" alt="左侧神经管纵观与红圈横切；右上管壁假复层柱状上皮夹于内、外界膜之间；下方横切三层：内侧室管膜层、中层套层含各级成神经细胞、外侧浅染边缘层"}

:::compare{title="神经管壁的三层"}
| 项目 | 室管膜层 | 套层 | 边缘层 |
|------|----------|------|--------|
| 英文 | ependymal layer | mantle layer | marginal layer |
| 位置 | 最内，衬管腔 | 中间，神经上皮外周 | 最外，套层外周 |
| 细胞 | 停止分化的单层立方或矮柱状上皮 | 成神经细胞、成神经胶质细胞 | 细胞稀少，主要是突起 |
| 来源 | 余下的神经上皮停止分化 | 部分神经上皮细胞向外迁移 | 成神经细胞突起伸入 |
| 以后 | 室管膜 | 灰质的细胞主体 | 白质 |
| 胶质 | — | 成胶质细胞在此分化为星形胶质细胞和少突胶质细胞 | 部分胶质细胞迁入 |
:::

:::cause-effect{title="神经上皮迁出，才分出套层、室管膜层和边缘层"}
- 因：部分神经上皮细胞迁移至外周
- 果：形成套层，将分化出成神经细胞和成神经胶质细胞
- 因：余下的神经上皮停止分化
- 果：变为单层立方或矮柱状的室管膜层
- 因：成神经细胞伸出突起并延伸至套层外周
- 果：形成细胞稀少的边缘层
:::

:::pitfall{label="从内到外是室管膜层、套层、边缘层，不要把套层写成最外"}
管腔面先是内界膜和室管膜层，中间才是套层（细胞多，将来灰质），最外是边缘层（突起多、细胞少，将来白质）。外界膜是套在整个管壁外面的基膜，不是第四层细胞。写成“边缘层在套层里面”，灰质白质会对调。
:::

:::note{label="神经上皮先单层柱状，再假复层，不是一开始就三层"}
管壁最初是单层柱状上皮，以后才演变成假复层柱状的神经上皮。三层（室管膜层、套层、边缘层）是迁移和长突起之后才有的，不要把第一天的神经管壁写成已经分好灰质白质。
:::

## （二）神经元的发生和成熟

中枢神经系统中的神经元来源于神经上皮。成神经细胞一般不再分裂增殖，起初圆形无突起，称为无极成神经细胞（apolar neuroblast），以后发出两个突起，称双极成神经细胞（bipolar neuroblast）。双极成神经细胞朝向神经管腔一侧的突起退化消失，伸向边缘层的一个突起迅速增长，形成原始轴突，称单极成神经细胞（unipolar neuroblast）。单极成神经细胞内侧端又形成若干短突起，为原始树突，称多极成神经细胞（multipolar neuroblast）（图 26-2）。多极成神经细胞经过进一步发育成为神经细胞或称神经元。胚胎第 $20$ 周，大脑皮质内神经元胞体和树突内可见成层排列的粗面内质网、大量的微丝、微管和溶酶体（图 26-3）。

:::definition{label="无极成神经细胞"}
无极成神经细胞（apolar neuroblast）是成神经细胞的起始形态：圆形，无突起。成神经细胞一般不再分裂增殖。
:::

:::definition{label="双极成神经细胞"}
双极成神经细胞（bipolar neuroblast）由无极成神经细胞发出两个突起形成。一个突起朝向管腔，一个伸向边缘层。
:::

:::definition{label="单极成神经细胞"}
单极成神经细胞（unipolar neuroblast）：朝向神经管腔一侧的突起退化消失，伸向边缘层的一个突起迅速增长，形成原始轴突。留下的是朝外的轴突侧。
:::

:::definition{label="多极成神经细胞"}
多极成神经细胞（multipolar neuroblast）：单极成神经细胞内侧端又形成若干短突起，为原始树突。它再进一步发育成为神经细胞（神经元）。
:::

:::derivation{title="成神经细胞为什么先双极、再单极、才多极"}
成神经细胞不再分裂后，先长出两个突起（双极）。朝向管腔的那一侧没有“出路”，突起退化；朝向边缘层的一侧要进白质，突起迅速增长成原始轴突，于是只剩一个突起（单极）。胞体内侧端再补若干短突起当原始树突，才变成多极。顺序是形态学上的，不是“先有树突后有轴突”的成体印象。
:::

::figure{src="/images/histology/textbook/p0283_01.png" caption="图26-2 神经上皮细胞的分化模式图。神经管神经上皮分化为无极、双极、单极、多极成神经细胞；成神经胶质细胞再分为纤维性和原浆性星形胶质细胞、少突胶质细胞；室管膜细胞参与脉络丛；小胶质细胞来自造血干细胞经单核细胞。" alt="神经管横切放大神经上皮，左侧成神经细胞四级形态，中央星形胶质与少突胶质，右侧造血干细胞至小胶质、室管膜细胞和脉络丛"}

:::example{label="中枢成神经细胞四步只记方向"}
朝管腔的突起退化，朝边缘层的突起变成轴突，内侧再长树突。所以单极成神经细胞的“一极”是原始轴突，不是树突；多极的短突在内侧端。把单极听成脊神经节的假单极，中枢和周围会对错户头。
:::

:::note{label="第20周皮质神经元的胞质已经能看见成层粗面内质网"}
胚胎第 $20$ 周，大脑皮质内神经元胞体和树突内可见成层排列的粗面内质网、大量的微丝、微管和溶酶体。教材图 26-3 为该期人胎脑神经元电镜（粗面内质网、微丝、微管、溶酶体、细胞核）；原图文件为空，这里只保留文字，不嵌空图。
:::

周围神经系统中的神经元主要来源于神经嵴。脑、脊神经节中，神经嵴细胞首先分化为成神经细胞，成神经细胞再分化为感觉神经元。其中成神经细胞最初长出两个突起，成为双极神经元，由于细胞体各面的不均等生长，使两个突起的起始部逐渐靠拢，最后合二为一，形成假单极神经元。而交感神经节中，神经嵴细胞首先分化为交感成神经细胞，再由此分化为多极的交感神经节细胞。副交感神经节中神经元的起源问题尚有争议，有人认为来源于神经管，也有人认为来源于脑神经节中的成神经细胞。在神经细胞的发生过程中，其最初产生细胞的数量要远多于最终分化存留的细胞，这是因为神经细胞之间联系的建立是一个非常复杂精细的过程，凡最终未能与靶细胞建立连接或处于异常部位的神经细胞，都可能发生凋亡。神经细胞的存活及其突起的发生主要受靶细胞产生的神经营养因子的调控，如神经生长因子、成纤维细胞生长因子、表皮生长因子等。大量神经细胞的凋亡，与它们不能获得靶细胞释放的神经营养因子密切相关；此外，也与它们未能和其他神经细胞形成足够的传入性突触相关。

:::definition{label="脑、脊神经节的感觉神经元"}
神经嵴细胞先分化为成神经细胞，再分化为感觉神经元。成神经细胞最初长出两个突起，成为双极神经元；由于细胞体各面不均等生长，两个突起的起始部逐渐靠拢、合二为一，形成假单极神经元。
:::

:::definition{label="假单极神经元"}
假单极神经元由双极神经元的两个突起起始部靠拢融合而成。看起来像一个突起出胞体，实际是周围突和中枢突合成的一条。它不是中枢成神经细胞那条“单极成神经细胞”账。
:::

:::definition{label="交感成神经细胞"}
交感神经节中，神经嵴细胞首先分化为交感成神经细胞，再由此分化为多极的交感神经节细胞。交感走多极，感觉走假单极，不要对调。
:::

:::definition{label="副交感神经节起源（有争议）"}
副交感神经节中神经元的起源尚有争议：有人认为来源于神经管，也有人认为来源于脑神经节中的成神经细胞。考试先写“尚有争议”，不要只锁死一种说法。
:::

:::definition{label="神经营养因子与凋亡"}
神经细胞最初产生的数量远多于最终存留的数量。未能与靶细胞建立连接或处于异常部位者可发生凋亡。存活和突起发生主要受靶细胞产生的神经营养因子调控，如神经生长因子、成纤维细胞生长因子、表皮生长因子等。大量凋亡既与得不到这些因子有关，也与未能形成足够的传入性突触有关。
:::

:::compare{title="中枢成神经细胞与周围感觉、交感神经元"}
| 项目 | 中枢成神经细胞 | 脑、脊神经节感觉神经元 | 交感神经节细胞 |
|------|----------------|--------------------------|----------------|
| 来源 | 神经上皮 → 套层 | 神经嵴 | 神经嵴 |
| 起始 | 无极（圆形无突起） | 成神经细胞长出两个突起 | 交感成神经细胞 |
| 中间型 | 双极 → 单极（管腔侧突起退化，边缘层侧成原始轴突） | 双极神经元 | — |
| 成熟形态 | 多极神经元 | 假单极（两突起始部靠拢融合） | 多极 |
| 机制要点 | 朝向不同，一侧退化、一侧增长 | 胞体不均等生长，起始部合并 | 由交感成神经细胞分化 |
:::

:::pitfall{label="中枢的单极成神经细胞不是脊神经节的假单极"}
中枢单极：管腔侧突起没了，只剩伸向边缘层的原始轴突。周围假单极：两个突起都在，只是起始部合成一条。写成“成神经细胞都变成假单极”，脊髓前角的多极运动神经元会没有来路。
:::

:::insight{label="多造一些、再按靶细胞裁掉，才是正常发生"}
联系建立很精细，对不上靶或站错位置的细胞走凋亡。神经营养因子是靶细胞发的“存活许可证”；传入性突触不够也会死。把凋亡只写成“发育错误”，会把正常的数量修剪漏掉。
:::

:::tip{label="中枢四步口诀"}
无极圆、双极两头长，管腔侧退成单极轴突，内侧再冒树突成多极。
:::

## （三）神经胶质细胞的发生

在中枢神经系统中，来自神经管的成神经胶质细胞分化为胶质细胞的前体细胞，即成星形胶质细胞和成少突胶质细胞，再由前者分化为原浆性和纤维性星形胶质细胞，后者分化为少突胶质细胞。小胶质细胞的形成较晚，来源于血液中的单核细胞（见图 26-2）。活体成像及显微注射等技术证明，神经细胞凋亡是诱导小胶质细胞进入中枢神经系统最重要的原因。

周围神经系统中，所有神经胶质细胞均由神经嵴细胞分化而成。其中施万细胞随神经元轴突或周围突的延长而同步增殖和迁移；而卫星细胞则包绕在脑神经节、脊神经节以及交感神经节的节细胞周围（图 26-4）。

:::definition{label="成星形胶质细胞"}
成星形胶质细胞是成神经胶质细胞分出的前体之一，再分化为原浆性星形胶质细胞和纤维性星形胶质细胞。
:::

:::definition{label="成少突胶质细胞"}
成少突胶质细胞是成神经胶质细胞分出的另一支前体，分化为少突胶质细胞。
:::

:::definition{label="小胶质细胞（发生）"}
小胶质细胞形成较晚，来源于血液中的单核细胞，不是神经管成神经胶质细胞的后代。神经细胞凋亡是诱导它进入中枢神经系统最重要的原因。
:::

:::definition{label="施万细胞（发生）"}
施万细胞由神经嵴细胞分化而成，随神经元轴突或周围突的延长而同步增殖和迁移。周围神经纤维的鞘细胞是它。
:::

:::definition{label="卫星细胞"}
卫星细胞由神经嵴细胞分化而成，包绕在脑神经节、脊神经节以及交感神经节的节细胞周围。它围的是节细胞胞体，不是轴突上的髓鞘。
:::

:::compare{title="中枢胶质与周围胶质的来源"}
| 项目 | 星形胶质细胞 | 少突胶质细胞 | 小胶质细胞 | 施万细胞 | 卫星细胞 |
|------|--------------|--------------|------------|----------|----------|
| 系统 | 中枢 | 中枢 | 中枢 | 周围 | 周围 |
| 直接来源 | 成星形胶质细胞 | 成少突胶质细胞 | 血液单核细胞 | 神经嵴 | 神经嵴 |
| 更早来源 | 神经管成神经胶质细胞 | 神经管成神经胶质细胞 | 造血（非神经上皮） | 神经嵴细胞 | 神经嵴细胞 |
| 分化产物 | 原浆性和纤维性 | 少突胶质细胞 | 小胶质细胞 | 随轴突／周围突迁移 | 包绕节细胞 |
| 时间 | 随成神经细胞分化 | 同左 | 较晚，凋亡诱导进入 | 与突起延长同步 | 围在节细胞周围 |
:::

:::pitfall{label="小胶质细胞不是神经管成胶质细胞变来的"}
星形胶质、少突胶质走神经管成神经胶质细胞；小胶质走血液单核细胞，而且要等神经细胞凋亡来诱导进入。写成“三种中枢胶质都来自套层”，单核细胞这本账会消失。
:::

:::cause-effect{title="凋亡既裁神经元，也把小胶质细胞招进来"}
- 因：大量神经细胞未能获得神经营养因子或传入性突触不足
- 果：凋亡，最终存留数少于最初产生数
- 因：神经细胞凋亡
- 果：诱导小胶质细胞进入中枢神经系统（活体成像及显微注射等技术证明，这是最重要的原因）
:::

:::keypoint{label="管走中枢三层细胞，嵴走周围；成神经细胞按突起改名"}
- 神经外胚层 → 神经管（CNS、神经垂体、松果体）+ 神经嵴（周围神经、肾上腺髓质）。
- 第 $3$ 周末神经板，凹陷成神经沟，第 $4$ 周初闭合为神经管；嵴在管背外侧。
- 管壁：单层柱状 → 假复层神经上皮；内界膜、外界膜。
- 三层从内到外：室管膜层、套层（成神经细胞、成胶质细胞）、边缘层（突起）。
- 中枢成神经细胞：无极 → 双极 → 单极（管腔侧退、边缘层侧成轴突）→ 多极（内侧原始树突）。
- 脑脊神经节：双极 → 假单极；交感：交感成神经细胞 → 多极；副交感起源有争议。
- 凋亡受神经营养因子和传入性突触调控。
- 中枢胶质：成星形 → 原浆性／纤维性；成少突 → 少突胶质；小胶质来自单核细胞。
- 周围胶质全来自神经嵴：施万细胞跟突起走，卫星细胞围节细胞。
:::

:::memory{label="本节必背要点"}
- [ ] 神经系统起源于神经外胚层。
- [ ] 神经外胚层先形成神经管和神经嵴。
- [ ] 神经管分化为中枢神经系统（脊髓、脑）、神经垂体和松果体等。
- [ ] 神经嵴分化为周围神经系统（神经节、周围神经）和肾上腺髓质等。
- [ ] 胚胎第 $3$ 周末，胚盘背正中部外胚层增厚为神经板。
- [ ] 神经板不久凹陷成神经沟，第 $4$ 周初形成神经管。
- [ ] 位于神经板与表面外胚层间的神经上皮移向神经管背外侧，成为两条纵行神经嵴。
- [ ] 神经管产生中枢神经系统的神经元和大多数神经胶质细胞。
- [ ] 周围神经系统的神经元和神经胶质细胞由神经嵴细胞迁移分化而成。
- [ ] 神经管壁最初为单层柱状上皮，以后演变为假复层柱状上皮，称神经上皮（neuroepithelium）。
- [ ] 神经上皮外包较厚基膜称外界膜；管壁内面有内界膜。
- [ ] 部分神经上皮细胞迁至外周形成套层（mantle layer），将分化出成神经细胞（neuroblast）和成神经胶质细胞（glioblast）。
- [ ] 余下的神经上皮停止分化，变为单层立方或矮柱状上皮，称室管膜层（ependymal layer）。
- [ ] 成神经细胞伸出突起并延伸至套层外周，形成细胞稀少的边缘层（marginal layer）。
- [ ] 套层中的成神经胶质细胞分化为星形胶质细胞和少突胶质细胞，部分迁入边缘层。
- [ ] 中枢神经元来源于神经上皮；成神经细胞一般不再分裂增殖。
- [ ] 无极成神经细胞（apolar neuroblast）：圆形无突起。
- [ ] 双极成神经细胞（bipolar neuroblast）：发出两个突起。
- [ ] 朝向管腔一侧的突起退化，伸向边缘层的突起增长为原始轴突，称单极成神经细胞（unipolar neuroblast）。
- [ ] 内侧端形成若干短突起（原始树突），称多极成神经细胞（multipolar neuroblast），进一步发育为神经元。
- [ ] 胚胎第 $20$ 周，大脑皮质神经元胞体和树突内可见成层粗面内质网、大量微丝、微管和溶酶体。
- [ ] 周围神经系统神经元主要来源于神经嵴。
- [ ] 脑、脊神经节：成神经细胞 → 感觉神经元；双极神经元因胞体不均等生长，两突起始部靠拢融合为假单极神经元。
- [ ] 交感神经节：神经嵴 → 交感成神经细胞 → 多极交感神经节细胞。
- [ ] 副交感神经节神经元起源尚有争议（神经管，或脑神经节中的成神经细胞）。
- [ ] 最初产生的神经细胞远多于最终存留者；未能与靶细胞连接或处于异常部位者可凋亡。
- [ ] 存活和突起发生主要受靶细胞神经营养因子调控，如神经生长因子、成纤维细胞生长因子、表皮生长因子。
- [ ] 大量凋亡还与未能形成足够的传入性突触相关。
- [ ] 中枢：成神经胶质细胞 → 成星形胶质细胞（原浆性和纤维性星形胶质细胞）和成少突胶质细胞（少突胶质细胞）。
- [ ] 小胶质细胞形成较晚，来源于血液单核细胞；神经细胞凋亡是诱导其进入中枢最重要的原因。
- [ ] 周围神经系统所有神经胶质细胞均由神经嵴细胞分化而成。
- [ ] 施万细胞随神经元轴突或周围突延长而同步增殖和迁移。
- [ ] 卫星细胞包绕脑神经节、脊神经节以及交感神经节的节细胞。
:::
