# 四、垂体

垂体（pituitary gland）位于颅骨蝶鞍垂体窝内，为一椭圆形小体，重约 $0.5\,\mathrm{g}$，由腺垂体（adenohypophysis）和神经垂体（neurohypophysis）两部分组成，表面包以结缔组织被膜。神经垂体分为神经部和漏斗两部分，漏斗与下丘脑相连，包括漏斗柄和正中隆起。腺垂体分为远侧部、中间部和结节部 3 部分。远侧部最大，中间部位于远侧部和神经部之间，结节部围在漏斗周围（图 13-8）。在位置上，腺垂体居前，神经垂体居后。腺垂体的远侧部又称垂体前叶（anterior lobe of pituitary），神经垂体的神经部和腺垂体的中间部合称垂体后叶（posterior lobe of pituitary）。

:::definition{label="垂体"}
垂体（pituitary gland）位于颅骨蝶鞍垂体窝内，椭圆形，重约 $0.5\,\mathrm{g}$，表面包结缔组织被膜。由腺垂体和神经垂体两部分组成。
:::

:::definition{label="腺垂体"}
腺垂体（adenohypophysis）分为远侧部、中间部和结节部。远侧部最大；中间部位于远侧部和神经部之间；结节部围在漏斗周围。位置居前，腺细胞自己合成含氮激素。
:::

:::definition{label="神经垂体"}
神经垂体（neurohypophysis）分为神经部和漏斗。漏斗与下丘脑相连，包括漏斗柄和正中隆起。位置居后。本身不合成激素，贮存并释放下丘脑视上核和室旁核的激素。
:::

:::definition{label="垂体前叶与后叶"}
腺垂体的远侧部又称垂体前叶（anterior lobe of pituitary）；神经垂体的神经部和腺垂体的中间部合称垂体后叶（posterior lobe of pituitary）。前叶不等于全部腺垂体，后叶也不等于全部神经垂体。
:::

:::concept{term="先问这叶是自己合成激素，还是只贮存下丘脑的激素"}
看见垂体，先把两本账拆开。腺垂体远侧部的嗜酸、嗜碱、嫌色细胞自己造 GH、PRL、TSH、ACTH、FSH/LH；神经部的赫林体（Herring body，亦称赫令体）只是视上核、室旁核轴突上堆起来的分泌颗粒。把神经垂体听成“后叶腺细胞分泌血管升压素和催产素”，合成地点会从下丘脑错搬到垂体窝里。
:::

:::compare{title="腺垂体与神经垂体"}
| 项目 | 腺垂体 | 神经垂体 |
|------|--------|----------|
| 英文 | adenohypophysis | neurohypophysis |
| 分部 | 远侧部、中间部、结节部 | 神经部、漏斗（漏斗柄 + 正中隆起） |
| 与叶的关系 | 远侧部 = 前叶；中间部划入后叶 | 神经部划入后叶 |
| 位置 | 前 | 后 |
| 实质 | 腺细胞团索 + 窦状毛细血管 | 无髓神经纤维 + 垂体细胞 + 有孔毛细血管 |
| 激素来源 | 腺细胞自己合成 | 下丘脑视上核、室旁核合成，经轴突运来贮存、释放 |
| 血管关键结构 | 垂体门脉系统（两级毛细血管网） | 神经部有孔毛细血管，供释放入血 |
| 光镜身份证 | 红的嗜酸、蓝的嗜碱、浅的嫌色 | 弱嗜酸性赫林体 |
:::

:::pitfall{label="神经垂体不合成激素，只贮存和释放下丘脑的激素"}
血管升压素和催产素的合成地点在下丘脑视上核和室旁核的神经内分泌细胞，不在神经部的垂体细胞里。垂体细胞是神经部胶质，管支持和营养纤维。赫林体是轴突上的颗粒团，不是腺细胞。写成“神经垂体细胞分泌抗利尿激素”，合成、运输、贮存三本账会并成一句假话。
:::

## （一）腺垂体

### 1. 远侧部

远侧部（pars distalis）腺细胞排列成团索状，其间有丰富的窦状毛细血管和少量结缔组织。在 HE 染色切片中，腺细胞分为嗜色细胞和嫌色细胞两类；嗜色细胞又分为嗜酸性细胞和嗜碱性细胞两种（图 13-9），均具有含氮激素分泌细胞的超微结构特点（图 13-10）。根据嗜色腺细胞所分泌的激素不同，可进一步对它们进行分类，并按所分泌的激素进行命名。

:::definition{label="远侧部"}
远侧部（pars distalis）是腺垂体最大的部分，即垂体前叶。腺细胞排列成团索状，间有丰富窦状毛细血管和少量结缔组织。
:::

:::definition{label="嗜色细胞与嫌色细胞"}
HE 下远侧部腺细胞分为嗜色细胞和嫌色细胞。嗜色细胞又分为嗜酸性细胞和嗜碱性细胞，均具含氮激素分泌细胞的超微结构（密集粗面内质网、发达高尔基复合体、分泌颗粒）。
:::

:::concept{term="先问这枚远侧部细胞嗜酸、嗜碱，还是嫌色"}
红颗粒是嗜酸性细胞，管 GH 和 PRL；蓝颗粒是嗜碱性细胞，管 TSH、ACTH 和 FSH/LH；浅而不清的是嫌色细胞，可能是脱颗粒的嗜色细胞或嗜色细胞的初期。先按颜色分三类，再按激素命名。把所有远侧部细胞都听成“垂体细胞”，和神经部的胶质同名，账会串叶。
:::

::figure{src="/images/histology/textbook/p0154_02.png" caption="图13-9 腺垂体远侧部光镜图。1. 嗜酸性细胞；2. 嗜碱性细胞；3. 嫌色细胞；4. 血窦。" alt="腺垂体远侧部：嗜酸性细胞红染颗粒，嗜碱性细胞蓝染，嫌色细胞浅淡界限不清，间有血窦"}

**（1）嗜酸性细胞（acidophilic cell）** 数量较多，呈圆形或椭圆形，细胞质内含嗜酸性颗粒。嗜酸性细胞分生长激素细胞和催乳激素细胞两种。

:::definition{label="嗜酸性细胞"}
嗜酸性细胞（acidophilic cell）数量较多，圆形或椭圆形，胞质含嗜酸性颗粒。分为生长激素细胞和催乳激素细胞两种。
:::

**1）生长激素细胞（somatotroph）** 数量较多，所分泌的生长激素（growth hormone，GH）能促进骨骼肌和内脏的生长及多种代谢过程，尤其是刺激骺软骨生长，使骨增长。在未成年时期，生长激素分泌不足可致垂体性侏儒症，分泌过多则引起巨人症；成人生长激素分泌过多会导致肢端肥大症。

:::definition{label="生长激素细胞"}
生长激素细胞（somatotroph）数量较多，分泌生长激素（growth hormone，GH）。GH 促进骨骼肌和内脏的生长及多种代谢，尤其刺激骺软骨生长使骨增长。
:::

:::definition{label="生长激素过多或过少"}
未成年时期 GH 分泌不足可致垂体性侏儒症，分泌过多引起巨人症；成人 GH 分泌过多导致肢端肥大症（骺软骨已闭合，肢端骨、肢端软组织增大）。
:::

**2）催乳激素细胞（mammotroph）** 男女两性的垂体均有，但女性较多，分娩前期和哺乳期细胞功能旺盛。所分泌的催乳素（prolactin，PRL）能促进乳腺发育和乳汁分泌。

:::definition{label="催乳激素细胞"}
催乳激素细胞（mammotroph）男女两性垂体均有，女性较多；分娩前期和哺乳期功能旺盛。分泌催乳素（prolactin，PRL），促进乳腺发育和乳汁分泌。
:::

**（2）嗜碱性细胞（basophilic cell）** 数量较嗜酸性细胞少，呈椭圆形或多边形，细胞质内含嗜碱性颗粒。嗜碱性细胞分促甲状腺激素细胞、促肾上腺皮质激素细胞和促性腺激素细胞 3 种。

:::definition{label="嗜碱性细胞"}
嗜碱性细胞（basophilic cell）数量较嗜酸性细胞少，椭圆形或多边形，胞质含嗜碱性颗粒。分为促甲状腺激素细胞、促肾上腺皮质激素细胞和促性腺激素细胞 3 种。
:::

促甲状腺激素细胞（thyrotroph）所分泌的促甲状腺激素（thyroid stimulating hormone，TSH）能促进甲状腺激素的生成和释放。

促肾上腺皮质激素细胞（corticotroph）所分泌的促肾上腺皮质激素（adrenocorticotropic hormone，ACTH）主要促进肾上腺皮质束状带细胞分泌糖皮质激素。

促性腺激素细胞（gonadotroph）分泌卵泡刺激素（follicle stimulating hormone，FSH）和黄体生成素（luteinizing hormone，LH），在男性和女性均如此。应用免疫电镜技术发现促性腺激素细胞有 3 种，即 FSH 细胞、LH 细胞和两种激素共存的 FSH/LH 细胞。卵泡刺激素促进女性卵泡发育，刺激男性生精小管的支持细胞合成雄激素结合蛋白，以促进精子的发生。黄体生成素促进女性排卵和黄体形成，刺激男性睾丸间质细胞分泌雄激素，故又称间质细胞刺激素（interstitial cell stimulating hormone，ICSH）。

:::definition{label="促甲状腺激素细胞"}
促甲状腺激素细胞（thyrotroph）分泌促甲状腺激素（TSH），促进甲状腺激素的生成和释放。即上一节滤泡上皮重吸收胶质所需的那一枚促激素。
:::

:::definition{label="促肾上腺皮质激素细胞"}
促肾上腺皮质激素细胞（corticotroph）分泌促肾上腺皮质激素（ACTH），主要促进肾上腺皮质束状带细胞分泌糖皮质激素。ACTH 的靶带是束状带，不是球状带。
:::

:::definition{label="促性腺激素细胞"}
促性腺激素细胞（gonadotroph）在男女均分泌 FSH 和 LH。免疫电镜下有 FSH 细胞、LH 细胞和 FSH/LH 细胞 3 种。
:::

:::definition{label="卵泡刺激素"}
卵泡刺激素（FSH）促进女性卵泡发育；刺激男性生精小管的支持细胞合成雄激素结合蛋白，以促进精子发生。
:::

:::definition{label="黄体生成素"}
黄体生成素（LH）促进女性排卵和黄体形成；刺激男性睾丸间质细胞分泌雄激素，故又称间质细胞刺激素（ICSH）。
:::

**（3）嫌色细胞（chromophobe cell）** 数量多，体积小，细胞质少，着色浅，细胞界限不清。电镜下，嫌色细胞细胞质内含少量分泌颗粒，因此这些细胞可能是脱颗粒的嗜色细胞，或是处于形成嗜色细胞的初期阶段。

:::definition{label="嫌色细胞"}
嫌色细胞（chromophobe cell）数量多，体积小，胞质少，着色浅，细胞界限不清。电镜下含少量分泌颗粒，可能是脱颗粒的嗜色细胞，或处于形成嗜色细胞的初期阶段。
:::

:::compare{title="远侧部三类腺细胞"}
| 项目 | 嗜酸性细胞 | 嗜碱性细胞 | 嫌色细胞 |
|------|------------|------------|----------|
| 英文 | acidophilic cell | basophilic cell | chromophobe cell |
| HE | 胞质嗜酸颗粒，红 | 胞质嗜碱颗粒，蓝 | 浅染，界限不清 |
| 数量 | 较多 | 较少 | 多，体积小 |
| 形态 | 圆或椭圆 | 椭圆或多边形 | 小，胞质少 |
| 激素 | GH、PRL | TSH、ACTH、FSH、LH | 少量颗粒，可能为脱颗粒或初期嗜色细胞 |
| 细胞亚型 | 生长激素细胞、催乳激素细胞 | 促甲状腺、促肾上腺皮质、促性腺激素细胞 | 不按激素再分 |
:::

:::compare{title="嗜色细胞按激素命名"}
| 细胞 | 激素 | 主要靶与效应 |
|------|------|----------------|
| 生长激素细胞 | GH | 骨骼肌、内脏生长；骺软骨 → 骨增长 |
| 催乳激素细胞 | PRL | 乳腺发育和乳汁分泌 |
| 促甲状腺激素细胞 | TSH | 甲状腺激素生成和释放 |
| 促肾上腺皮质激素细胞 | ACTH | 束状带分泌糖皮质激素 |
| 促性腺激素细胞 | FSH | 女：卵泡发育；男：支持细胞合成雄激素结合蛋白，促精子发生 |
| 促性腺激素细胞 | LH（ICSH） | 女：排卵和黄体形成；男：间质细胞分泌雄激素 |
:::

:::pitfall{label="ACTH 主要打束状带，不要写成促进球状带分泌醛固酮"}
教材写 ACTH 主要促进束状带细胞分泌糖皮质激素。醛固酮在球状带，不把 ACTH 当作自己的主开关。把三带都写成“受 ACTH 支配”，盐皮质激素和糖皮质激素的上级账会并成一句。
:::

:::pitfall{label="嫌色细胞不是无功能的填充细胞"}
光镜着色浅，不等于没有分泌颗粒。电镜已见到少量颗粒，教材把它解释为脱颗粒的嗜色细胞或嗜色细胞初期。不要把嫌色细胞听成“垂体里的成纤维细胞”或“退化细胞”。
:::

:::note{label="生长激素异常按年龄改写病名"}
| 时期 | GH 不足 | GH 过多 |
|------|---------|---------|
| 未成年（骺未闭） | 垂体性侏儒症 | 巨人症 |
| 成人（骺已闭） | — | 肢端肥大症 |
:::

### 2. 中间部

中间部（pars intermedia）为一纵行狭窄区域，仅占垂体体积的 $2\%$，由滤泡及其周围的嗜碱性细胞和嫌色细胞构成（图 13-11）。滤泡由单层立方或柱状上皮细胞围成，大小不等，内含胶质，呈嗜酸性或嗜碱性，其功能不明。低等脊椎动物此部位的嗜碱性细胞分泌黑素细胞刺激素（melanocyte stimulating hormone，MSH）；人类产生 MSH 的细胞散在于腺垂体中。MSH 可作用于皮肤黑素细胞，促进黑色素的合成和扩散，使皮肤颜色变深。

:::definition{label="中间部"}
中间部（pars intermedia）是纵行狭窄区域，仅占垂体体积的 $2\%$，位于远侧部和神经部之间，由滤泡及其周围的嗜碱性细胞和嫌色细胞构成。划入垂体后叶。
:::

:::definition{label="中间部滤泡"}
中间部滤泡由单层立方或柱状上皮围成，大小不等，内含嗜酸性或嗜碱性胶质，功能不明。不要把它当成甲状腺滤泡：这里不碘化甲状腺球蛋白。
:::

:::definition{label="黑素细胞刺激素"}
黑素细胞刺激素（MSH）在低等脊椎动物由中间部嗜碱性细胞分泌；人类产生 MSH 的细胞散在于腺垂体中。MSH 作用于皮肤黑素细胞，促进黑色素合成和扩散，使皮肤颜色变深。
:::

:::pitfall{label="人的 MSH 细胞散在腺垂体，不要写成中间部是人类 MSH 的唯一产地"}
低等脊椎动物中间部嗜碱性细胞分泌 MSH；人把产生 MSH 的细胞改写到腺垂体各处。中间部滤泡功能不明。看见后叶滤泡，先认中间部位置，不要按甲状腺滤泡的碘化六步去讲。
:::

### 3. 结节部

结节部（pars tuberalis）包围着神经垂体的漏斗，在漏斗的前方较厚，后方较薄或缺如。此部含有丰富的纵行毛细血管，腺细胞纵向分布于这些血管之间，排列成条索状。腺细胞较小，主要是嫌色细胞，其间有少量嗜酸性细胞和嗜碱性细胞。

:::definition{label="结节部"}
结节部（pars tuberalis）包围神经垂体的漏斗，前方较厚，后方较薄或缺如。含丰富纵行毛细血管，腺细胞纵向分布于血管之间呈条索状。细胞较小，主要是嫌色细胞，间有少量嗜酸性和嗜碱性细胞。垂体门微静脉在此部走行。
:::

### 4. 腺垂体的血管分布

腺垂体主要由大脑基底动脉环发出的垂体上动脉供应血液。垂体上动脉穿过结节部上端，进入神经垂体的漏斗，在该处分支并吻合形成有孔毛细血管网，称第一级毛细血管网。这些毛细血管网下行到结节部下端汇集形成数条垂体门微静脉，后者下行进入远侧部，再度分支并吻合，形成第二级毛细血管网。垂体门微静脉及其两端的毛细血管网共同构成垂体门脉系统（hypophyseal portal system）。远侧部的毛细血管最后汇集成小静脉，注入垂体周围的静脉窦（图 13-12）。

:::definition{label="垂体上动脉"}
垂体上动脉由大脑基底动脉环发出，是腺垂体的主要血供。穿过结节部上端进入漏斗，在漏斗形成第一级有孔毛细血管网。
:::

:::definition{label="垂体门脉系统"}
垂体门脉系统（hypophyseal portal system）由垂体门微静脉及其两端的毛细血管网构成：漏斗处第一级有孔毛细血管网 → 结节部下端汇成的垂体门微静脉 → 远侧部第二级毛细血管网。下丘脑释放激素和释放抑制激素经此到达远侧部腺细胞。
:::

:::note{label="门脉血流方向"}
下丘脑弓状核等神经内分泌细胞在漏斗把激素释放入第一级网 → 门微静脉下行 → 远侧部第二级网，分别调节各种腺细胞。远侧部毛细血管再汇成小静脉，注入垂体周围静脉窦。这不是普通营养血管，而是下丘脑指挥腺垂体的专用管道。
:::

:::pitfall{label="第一级毛细血管网在漏斗，不要画到远侧部里"}
第一级网长在神经垂体漏斗，第二级网才在远侧部。门微静脉把两级网串起来。把第一级网听成“远侧部的血窦”，下丘脑激素的入口会写错地方；把门脉系统听成神经部释放血管升压素的通路，两套下丘脑–垂体关系会并成一条管子。
:::

## （二）神经垂体

神经垂体主要由无髓神经纤维和神经胶质细胞组成，含有较丰富的有孔毛细血管（图 13-13）。下丘脑前区的视上核和室旁核的神经元具有内分泌功能，称为神经内分泌细胞（neuroendocrine cell）。这些细胞的轴突经漏斗终止于神经垂体的神经部，构成下丘脑神经垂体束，也是神经部无髓神经纤维的来源（图 13-12）。神经内分泌细胞内的分泌颗粒沿轴突运输下行，在轴突沿途和终末，运输中的分泌颗粒常聚集成团，使轴突呈串珠状膨大，在光镜下呈现为大小不等的弱嗜酸性团块，称赫林体（Herring body，亦称赫令体）。

神经部的胶质细胞又称垂体细胞（pituicyte），是神经部内的主要细胞成分，分布于神经纤维之间，其形状和大小不一，具有支持和营养神经纤维的作用。

:::definition{label="神经部的组成"}
神经垂体主要由无髓神经纤维和神经胶质细胞组成，含较丰富的有孔毛细血管。无髓纤维来自下丘脑视上核和室旁核神经内分泌细胞的轴突。
:::

:::definition{label="神经内分泌细胞"}
下丘脑前区视上核和室旁核的神经元具有内分泌功能，称神经内分泌细胞（neuroendocrine cell）。它们合成血管升压素和催产素，经轴突运到神经部贮存、释放。
:::

:::definition{label="下丘脑神经垂体束"}
视上核和室旁核神经内分泌细胞的轴突经漏斗终止于神经部，构成下丘脑神经垂体束，即神经部无髓神经纤维的来源。
:::

:::definition{label="赫林体"}
赫林体（Herring body，亦称赫令体）是沿轴突运输的分泌颗粒在轴突沿途和终末聚集成团，使轴突呈串珠状膨大，光镜下为大小不等的弱嗜酸性团块。它是贮存中的下丘脑激素，不是神经部分泌的新激素。
:::

:::definition{label="垂体细胞"}
垂体细胞（pituicyte）是神经部的胶质细胞，为神经部主要细胞成分，分布于神经纤维之间，形状和大小不一，支持和营养神经纤维。不合成血管升压素或催产素。
:::

::figure{src="/images/histology/textbook/p0156_02.png" caption="图13-13 垂体神经部光镜图。1. 赫林体；2. 垂体细胞；3. 毛细血管；↑无髓神经纤维。" alt="神经部：大小不等弱嗜酸性赫林体，垂体细胞散在纤维之间，有孔毛细血管，箭头示无髓神经纤维"}

:::pitfall{label="赫林体是轴突上的颗粒团，不要当成腺细胞或淀粉样变性"}
弱嗜酸性团块大小不等，是串珠状膨大的轴突。垂体细胞在纤维之间，核可见、形态不一。把赫林体听成“神经部的嗜酸性腺细胞”，会把 GH 细胞搬到后叶；把它听成病理沉积，又会把正常贮存结构写成病变。
:::

## （三）下丘脑与垂体的关系

### 1. 下丘脑与腺垂体的关系

下丘脑产生的激素经下丘脑腺垂体束和垂体门脉系统调节腺垂体内各种细胞的分泌活动，形成一个功能整体，称为下丘脑-腺垂体系统（hypothalamus-adenohypophysis system）。

下丘脑弓状核等核团的神经内分泌细胞的轴突伸至神经垂体漏斗，构成下丘脑腺垂体束。弓状核细胞合成的多种激素在轴突末端释放，进入漏斗处的第一级毛细血管网，继而经垂体门微静脉到达腺垂体远侧部的第二级毛细血管网，分别调节远侧部各种腺细胞的分泌活动（见图 13-12）。其中对腺细胞分泌起促进作用的激素，称释放激素（releasing hormone，RH）；对腺细胞分泌起抑制作用的激素，则称释放抑制激素（release inhibiting hormone，RIH）。

目前已知的释放激素有：生长激素释放激素（GHRH）、催乳素释放激素（PRH）、促甲状腺激素释放激素（TRH）、促肾上腺皮质激素释放激素（CRH）、促性腺激素释放激素（GnRH）及黑素细胞刺激素释放激素（MSRH）等。释放抑制激素有：生长激素释放抑制激素（简称生长抑素，SST）、催乳素释放抑制激素（PIH）和黑素细胞刺激素释放抑制激素（MSIH）等。

下丘脑通过所产生的释放激素和释放抑制激素，经下丘脑-腺垂体系统调节腺垂体内各种细胞的激素分泌；而腺垂体嗜碱性细胞产生的各种促激素又可调节甲状腺、肾上腺和性腺的内分泌活动，从而神经系统通过内分泌系统调节机体的多种物质代谢及功能活动。

:::definition{label="下丘脑-腺垂体系统"}
下丘脑-腺垂体系统（hypothalamus-adenohypophysis system）是下丘脑产生的激素经下丘脑腺垂体束和垂体门脉系统调节腺垂体各种细胞分泌、形成的功能整体。
:::

:::definition{label="下丘脑腺垂体束"}
下丘脑弓状核等核团的神经内分泌细胞轴突伸至漏斗，构成下丘脑腺垂体束。激素在轴突末端释放入第一级毛细血管网，再经门微静脉到远侧部。
:::

:::definition{label="释放激素"}
释放激素（releasing hormone，RH）对腺垂体腺细胞分泌起促进作用。已知有 GHRH、PRH、TRH、CRH、GnRH、MSRH 等。
:::

:::definition{label="释放抑制激素"}
释放抑制激素（release inhibiting hormone，RIH）对腺垂体腺细胞分泌起抑制作用。已知有生长抑素（SST）、PIH、MSIH 等。
:::

:::note{label="释放激素与释放抑制激素"}
| 腺垂体激素 | 释放激素（促进） | 释放抑制激素（抑制） |
|------------|------------------|----------------------|
| GH | GHRH | 生长抑素 SST |
| PRL | PRH | PIH |
| TSH | TRH | — |
| ACTH | CRH | — |
| FSH / LH | GnRH | — |
| MSH | MSRH | MSIH |
:::

:::insight{label="神经系统经下丘脑-腺垂体系统改写成外周内分泌命令"}
弓状核等把神经冲动换成 RH/RIH，门脉送到远侧部；嗜碱性细胞再换成 TSH、ACTH、FSH/LH，去调甲状腺、肾上腺皮质和性腺。神经和内分泌在这里不是两套并列的调节，而是一条接力。漏掉门脉，下丘脑就只剩神经部那一根轴突索。
:::

### 2. 下丘脑与神经垂体的关系

神经垂体是下丘脑激素的贮存和释放部位，与下丘脑在结构和功能上都是一个整体。下丘脑视上核和室旁核的神经内分泌细胞的轴突下行成为神经垂体内的无髓神经纤维，组成下丘脑神经垂体束（见图 13-12）。这些神经内分泌细胞合成和分泌的血管升压素（vasopressin）和催产素（oxytocin）经轴突运输到神经部贮存，进而释放入有孔毛细血管，再随血液循环到达靶器官和靶细胞发挥作用。血管升压素可使小动脉平滑肌收缩，血压升高，还可促进肾远曲小管和集合管重吸收水，使尿液浓缩。若此激素分泌减少，会导致尿崩症，患者每日排出大量稀释的尿液，故又称抗利尿激素（antidiuretic hormone，ADH）。催产素可引起子宫平滑肌收缩，有助于孕妇分娩，还可促进乳腺分泌。

:::definition{label="下丘脑与神经垂体"}
神经垂体是下丘脑激素的贮存和释放部位，与下丘脑在结构和功能上都是一个整体。视上核、室旁核轴突组成下丘脑神经垂体束。
:::

:::definition{label="血管升压素"}
血管升压素（vasopressin）由视上核和室旁核合成，在神经部贮存释放。使小动脉平滑肌收缩、血压升高；并促进肾远曲小管和集合管重吸收水，使尿液浓缩。又称抗利尿激素（ADH）。分泌减少导致尿崩症，每日排出大量稀释尿液。
:::

:::definition{label="催产素"}
催产素（oxytocin）由视上核和室旁核合成，在神经部贮存释放。引起子宫平滑肌收缩，有助于孕妇分娩；还可促进乳腺分泌。
:::

:::definition{label="尿崩症"}
尿崩症因血管升压素（ADH）分泌减少，肾远曲小管和集合管不能充分重吸收水，患者每日排出大量稀释尿液。不要与糖尿病的糖渗透性利尿并成一种。
:::

::figure{src="/images/histology/textbook/p0156_01.png" caption="图13-12 下丘脑-垂体系统及其血管分布、激素产生和贮存部位模式图。示室旁核、视上核、弓状核，下丘脑腺垂体束与下丘脑神经垂体束，垂体上动脉、第一级和第二级毛细血管网、垂体门微静脉，以及垂体下动脉供应神经部。" alt="下丘脑与垂体：弓状核经门脉调节远侧部，视上核室旁核轴突至神经部释放，两级毛细血管网和静脉窦"}

:::compare{title="下丘脑与腺垂体、神经垂体的两条关系"}
| 项目 | 下丘脑-腺垂体系统 | 下丘脑-神经垂体 |
|------|-------------------|------------------|
| 下丘脑核团 | 弓状核等 | 视上核、室旁核 |
| 纤维束 | 下丘脑腺垂体束（至漏斗） | 下丘脑神经垂体束（至神经部） |
| 输送方式 | 末端释放入第一级网，经门脉到远侧部 | 分泌颗粒沿轴突运到神经部，赫林体贮存 |
| 到达远侧 / 神经部的物质 | RH、RIH | 血管升压素、催产素 |
| 垂体侧是否合成 | 远侧部腺细胞合成自身激素 | 神经部不合成，只贮存释放 |
:::

:::pitfall{label="两套下丘脑束不要并成一条：门脉管腺垂体，轴突直达管神经部"}
RH/RIH 走门脉，不走神经部轴突终末入血那条路；血管升压素和催产素走视上核–室旁核轴突，不经第二级毛细血管网去调节嗜色细胞。把 ADH 写成远侧部嗜碱性细胞产物，或把 TSH 写成赫林体内容，两套系统对调。
:::

:::keypoint{label="垂体先拆腺垂体与神经垂体，再写下丘脑两条指挥线"}
- 腺垂体：远侧部 + 中间部 + 结节部；远侧部 HE 分嗜酸（GH、PRL）、嗜碱（TSH、ACTH、FSH/LH）、嫌色。
- 神经垂体：神经部 + 漏斗；赫林体贮存视上核、室旁核的血管升压素和催产素；垂体细胞是胶质，不合成激素。
- 前叶 = 远侧部；后叶 = 神经部 + 中间部。
- 门脉系统：漏斗第一级网 → 门微静脉 → 远侧部第二级网，运送 RH/RIH。
- ADH 减少 → 尿崩症；未成年 GH 过少/过多 → 侏儒/巨人；成人 GH 过多 → 肢端肥大。
:::

:::memory{label="本节必背要点"}
- [ ] 垂体位于蝶鞍垂体窝，椭圆形，重约 $0.5\,\mathrm{g}$，表面包结缔组织被膜，由腺垂体和神经垂体组成。
- [ ] 神经垂体分为神经部和漏斗；漏斗与下丘脑相连，包括漏斗柄和正中隆起。
- [ ] 腺垂体分为远侧部、中间部和结节部；远侧部最大，中间部位于远侧部与神经部之间，结节部围在漏斗周围。
- [ ] 位置上腺垂体居前、神经垂体居后。
- [ ] 远侧部又称垂体前叶；神经部与中间部合称垂体后叶。
- [ ] 远侧部腺细胞排成团索状，间有丰富窦状毛细血管和少量结缔组织。
- [ ] HE 下腺细胞分嗜色细胞和嫌色细胞；嗜色细胞又分嗜酸性细胞和嗜碱性细胞，均具含氮激素分泌细胞超微结构。
- [ ] 嗜酸性细胞数量较多，圆或椭圆，含嗜酸性颗粒；分生长激素细胞和催乳激素细胞。
- [ ] GH 促进骨骼肌和内脏生长及多种代谢，尤其刺激骺软骨生长使骨增长。
- [ ] 未成年 GH 不足 → 垂体性侏儒症，过多 → 巨人症；成人 GH 过多 → 肢端肥大症。
- [ ] 催乳激素细胞男女均有、女性较多，分娩前期和哺乳期功能旺盛；PRL 促进乳腺发育和乳汁分泌。
- [ ] 嗜碱性细胞数量较少，椭圆或多边形，含嗜碱性颗粒；分促甲状腺、促肾上腺皮质、促性腺激素细胞 3 种。
- [ ] TSH 促进甲状腺激素生成和释放。
- [ ] ACTH 主要促进肾上腺皮质束状带分泌糖皮质激素。
- [ ] 促性腺激素细胞在男女均分泌 FSH 和 LH；免疫电镜下有 FSH 细胞、LH 细胞和 FSH/LH 细胞。
- [ ] FSH：女促卵泡发育；男刺激支持细胞合成雄激素结合蛋白，促精子发生。
- [ ] LH：女促排卵和黄体形成；男刺激间质细胞分泌雄激素，又称 ICSH。
- [ ] 嫌色细胞数量多、体积小、胞质少、着色浅、界限不清；电镜含少量分泌颗粒，可能为脱颗粒或初期嗜色细胞。
- [ ] 中间部占垂体体积约 $2\%$，由滤泡及其周围嗜碱性细胞和嫌色细胞构成。
- [ ] 中间部滤泡由单层立方或柱状上皮围成，内含嗜酸或嗜碱胶质，功能不明。
- [ ] 低等脊椎动物中间部嗜碱性细胞分泌 MSH；人类产生 MSH 的细胞散在于腺垂体中。
- [ ] MSH 作用于皮肤黑素细胞，促进黑色素合成和扩散，使皮肤颜色变深。
- [ ] 结节部包围漏斗，前方较厚、后方较薄或缺如；富含纵行毛细血管，腺细胞成索，主要为嫌色细胞，间有少量嗜酸、嗜碱细胞。
- [ ] 腺垂体主要由大脑基底动脉环发出的垂体上动脉供血。
- [ ] 垂体上动脉在漏斗形成第一级有孔毛细血管网，至结节部下端汇成垂体门微静脉，入远侧部成第二级毛细血管网。
- [ ] 垂体门微静脉及其两端毛细血管网构成垂体门脉系统；远侧部毛细血管汇成小静脉注入周围静脉窦。
- [ ] 神经垂体主要由无髓神经纤维和神经胶质细胞组成，含较丰富有孔毛细血管。
- [ ] 视上核和室旁核神经元为神经内分泌细胞，轴突经漏斗终止于神经部，构成下丘脑神经垂体束。
- [ ] 分泌颗粒沿轴突运输，在沿途和终末聚集成团，轴突串珠状膨大，光镜为大小不等弱嗜酸性团块，称赫林体（赫令体）。
- [ ] 垂体细胞是神经部胶质，主要细胞成分，支持和营养神经纤维。
- [ ] 下丘脑-腺垂体系统：下丘脑激素经下丘脑腺垂体束和门脉系统调节腺垂体细胞。
- [ ] 弓状核等轴突伸至漏斗构成下丘脑腺垂体束；激素入第一级网，经门微静脉到远侧部第二级网。
- [ ] 释放激素 RH：GHRH、PRH、TRH、CRH、GnRH、MSRH 等。
- [ ] 释放抑制激素 RIH：生长抑素 SST、PIH、MSIH 等。
- [ ] 腺垂体嗜碱性细胞的促激素再调节甲状腺、肾上腺和性腺。
- [ ] 神经垂体是下丘脑激素的贮存和释放部位，与下丘脑在结构和功能上为一个整体。
