# 四、阴茎

阴茎主要由两条阴茎海绵体、一条尿道海绵体、白膜和皮肤构成（图 18-15）。海绵体主要由小梁和血窦构成，阴茎深动脉分支的螺旋动脉穿行于小梁中，与血窦通连。静脉多位于海绵体周边部白膜下方，白膜为质地坚韧的致密结缔组织。一般情况下，流入血窦的血液很少，血窦呈裂隙状，海绵体柔软。当大量血液流入血窦，血窦充血而胀大，白膜下的静脉受压，血液回流一时受阻，海绵体变硬，阴茎勃起。阴茎血窦内皮细胞能释放多种使平滑肌细胞舒张的物质，统称内皮舒张因子，一氧化氮是其中之一，可促使螺旋动脉的平滑肌细胞舒张，引起血管扩张，血窦充血。

:::definition{label="阴茎"}
阴茎主要由两条阴茎海绵体、一条尿道海绵体、白膜和皮肤构成。它是外生殖器的主体，不是产生精子的器官。
:::

:::definition{label="阴茎海绵体"}
两条阴茎海绵体位于背侧。海绵体主要由小梁和血窦构成，外包坚韧白膜，是勃起时变硬的主要结构。
:::

:::definition{label="尿道海绵体"}
一条尿道海绵体位于腹侧，尿道穿行其中。同样由小梁和血窦构成，并有白膜。
:::

:::definition{label="海绵体小梁与血窦"}
海绵体主要由小梁和血窦构成。阴茎深动脉分支的螺旋动脉穿行于小梁中，与血窦通连。血窦是可充盈的血管腔隙，不是生精小管。
:::

:::definition{label="螺旋动脉"}
螺旋动脉是阴茎深动脉的分支，穿行于小梁中并与血窦通连。其平滑肌舒张则血管扩张，血窦充血，是启动勃起的动脉侧开关。
:::

:::definition{label="阴茎白膜"}
白膜为质地坚韧的致密结缔组织，包在海绵体外周。静脉多位于海绵体周边部白膜下方。血窦胀大时白膜限制扩张，并把白膜下静脉压住，使回流受阻。
:::

:::concept{term="先问血窦是裂隙还是胀满，再问白膜下的静脉通不通"}
看见阴茎横切，先数三个海绵体：背侧两条阴茎海绵体，腹侧一条包着尿道的尿道海绵体。静息时流入血窦的血很少，血窦呈裂隙状，海绵体柔软。勃起不是“把动脉关掉”，而是螺旋动脉舒张、大量血液涌入，血窦胀大，坚韧白膜把周边静脉压住，回流一时受阻，海绵体才变硬。少写静脉受压这一步，勃起机制会做成单纯充血。
:::

:::compare{title="阴茎海绵体与尿道海绵体"}
| 项目 | 阴茎海绵体 | 尿道海绵体 |
|------|------------|------------|
| 数目与位置 | 两条，位于背侧 | 一条，位于腹侧 |
| 内容 | 小梁 + 血窦；螺旋动脉穿小梁通血窦 | 小梁 + 血窦；尿道穿行其中 |
| 白膜 | 坚韧致密结缔组织 | 同样有白膜 |
| 勃起中的角色 | 充血变硬的主体 | 伴随充血，并保护其中的尿道 |
:::

:::definition{label="勃起"}
一般情况下流入血窦的血液很少，血窦呈裂隙状，海绵体柔软。当大量血液流入血窦，血窦充血而胀大，白膜下的静脉受压，血液回流一时受阻，海绵体变硬，阴茎勃起。
:::

:::definition{label="内皮舒张因子"}
阴茎血窦内皮细胞释放多种使平滑肌细胞舒张的物质，统称内皮舒张因子。一氧化氮是其中之一，可促使螺旋动脉的平滑肌细胞舒张，引起血管扩张，血窦充血。
:::

:::note{label="勃起的血流方向"}
| 状态 | 动脉 | 血窦 | 静脉 | 海绵体 |
|------|------|------|------|--------|
| 一般（疲软） | 流入很少 | 呈裂隙状 | 回流通畅 | 柔软 |
| 勃起 | 螺旋动脉舒张，大量血液流入 | 充血胀大 | 白膜下静脉受压，回流一时受阻 | 变硬 |
:::

:::pitfall{label="勃起是动脉灌入加静脉回流受阻，不要写成“动脉关闭”或“白膜把血窦勒断”"}
螺旋动脉要舒张、血管要扩张，血才能灌进血窦。白膜坚韧，限制血窦无限胀大，并把白膜下静脉压住，回流一时受阻。关掉动脉只会更软。把一氧化氮听成缩血管物质，机制会整段反号。
:::

:::insight{label="一氧化氮把螺旋动脉的平滑肌松开，白膜再把静脉门关上"}
内皮舒张因子是钥匙，一氧化氮是其中一把：螺旋动脉平滑肌一舒张，血窦从裂隙变成充盈腔。坚韧白膜既是外壳，也是压静脉的板。勃起是“灌得进、出不去”的暂时状态，不是海绵体变成固体组织。
:::

:::keypoint{label="阴茎先数三个海绵体，再把螺旋动脉、血窦、白膜下静脉和一氧化氮收口"}
- 两条阴茎海绵体 + 一条尿道海绵体 + 白膜 + 皮肤。
- 海绵体 = 小梁 + 血窦；螺旋动脉穿小梁通血窦；静脉多在白膜下方。
- 白膜是坚韧致密结缔组织。
- 疲软：血少，血窦裂隙状；勃起：灌入增多，血窦胀大，静脉受压，回流受阻。
- 血窦内皮释放内皮舒张因子，一氧化氮使螺旋动脉平滑肌舒张。
:::

## 本章小结

男性生殖系统由睾丸、生殖管道、附属腺及外生殖器组成。睾丸是产生精子和分泌雄性激素的器官，表面覆有浆膜，深部为致密结缔组织构成的白膜，白膜在睾丸后缘增厚形成睾丸纵隔。实质内有大量弯曲细长的生精小管，在接近睾丸纵隔处变为直精小管，后者于睾丸纵隔吻合为睾丸网。生精上皮由生精细胞和支持细胞组成。自生精上皮基底部至腔面依次有精原细胞、初级精母细胞、次级精母细胞、精子细胞和精子。从精原细胞到形成精子的过程称精子发生。支持细胞从生精上皮基底一直伸达腔面，其侧面镶嵌着各级生精细胞，在精子发生过程中发挥重要作用：① 为生精细胞提供结构支持和营养保证；② 吞噬和消化精子形成过程中脱落的残余细胞质等；③ 合成和分泌雄激素结合蛋白、抑制素等；④ 支持细胞间的紧密连接参与构成血-睾屏障等。生精小管之间的疏松结缔组织为睾丸间质，富含血管和淋巴管以及睾丸间质细胞。睾丸间质细胞能够分泌雄激素，促进精子发生和男性生殖器官发育，以及维持第二性征和性功能。生殖管道（附睾、输精管等）具有促进精子成熟，营养、贮存和运输精子的作用。精子在附睾内停留约 2 周，获得运动能力，并达到功能上的成熟。附属腺包括前列腺、精囊和尿道球腺。附属腺和生殖管道的分泌物参与精液的组成。

:::definition{label="本章结构通式"}
男性生殖系统 = 睾丸（生精 + 分泌雄激素）+ 生殖管道（成熟、贮存、运输）+ 附属腺（参与精液）+ 外生殖器（阴茎海绵体勃起）。生精上皮 = 支持细胞 + 五级生精细胞；精子发生 = 增殖 + 减数分裂 + 精子形成。血-睾屏障核心是支持细胞紧密连接；睾酮在小管之间的间质细胞。附睾把精子养熟，前列腺、精囊、尿道球腺兑入精液，海绵体血窦充盈完成勃起。
:::

:::compare{title="全章结构与细胞速查"}
| 结构 | 关键形态 | 职分 |
|------|----------|------|
| 生精小管 | 生精上皮；支持细胞 + $5\sim 8$ 层生精细胞；基膜外肌样细胞 | 精子发生 |

- 精子发生不是一次有丝分裂；精子形成不再分裂。
- 间质细胞不在生精上皮内；支持细胞才构成屏障、分泌 ABP。
- FSH 管支持细胞，LH（ICSH）管间质细胞。
- 附睾停留约 2 周才获得运动能力；输出小管腔不规则，附睾管腔规则。
- 前列腺增生多在黏膜腺和黏膜下腺，癌在外带。
- 勃起是螺旋动脉舒张、血窦充盈、白膜下静脉受压，一氧化氮是内皮舒张因子之一。
:::

## 插入框：睾丸免疫豁免的组织学结构基础及睾丸炎

免疫豁免是指机体某些部位对外来抗原及自身抗原免疫反应很弱，以防止免疫反应引起组织损伤和功能紊乱。机体的免疫豁免位点包括睾丸、大脑、眼及孕期的子宫。

睾丸是典型的免疫豁免组织，其特性包括：将睾丸或生精细胞移植到其他器官中，或将其他组织移植入睾丸中，免疫排斥反应很低。精子发生开始于青春期以后，此时机体的免疫感受能力早已建立，但新发生的生精细胞在睾丸内并不诱发免疫反应。生精上皮中的支持细胞和睾丸间质的结构特点为这些特性的形成奠定了基础。

睾丸中的血-睾屏障严格阻止了生精细胞与抗原物质的接触，为精子发生提供了适宜的微环境。支持细胞还分泌免疫抑制物质，及时吞噬清除凋亡的生精细胞和残体，在维持睾丸免疫豁免环境中同样具有重要意义。

睾丸间质中包括多种细胞，其中约 $80\%$ 是睾丸间质细胞，可合成雄激素。睾丸中雄激素浓度是血液中浓度的 10 倍以上，远多于正常精子发生所需，雄激素可通过调控睾丸间质细胞、支持细胞和肌上皮细胞中免疫调节分子的表达来发挥免疫抑制功能，局部高浓度雄激素在维持睾丸免疫豁免环境中发挥作用。间质的细胞中其余 $20\%$ 多为免疫细胞，来自被膜中的淋巴管，包括大量巨噬细胞、少量 T 淋巴细胞、树突状细胞和肥大细胞，被认为是睾丸抵御血液来源病原体的第一道防线。巨噬细胞中约 $80\%$ 长期驻留在睾丸中，约 $20\%$ 通过外周血液循环新迁移而至。

睾丸炎是引起男性不育的病因之一。若血-睾屏障等免疫豁免相关结构被破坏可诱发特异性自身免疫反应，导致自身免疫性睾丸炎；而细菌感染性睾丸炎多数情况是通过输精管、附睾感染蔓延到睾丸；病毒性睾丸炎常见于系统性病毒感染的并发症，由传染性疾病（流行性腮腺炎、感冒等）的病原体经血流播散引起。睾丸炎发生时，精子发生和激素分泌异常，可影响男性生育能力，甚至导致不育。

:::

:::definition{label="间质细胞与局部高雄激素"}
间质细胞约占间质细胞总数的 $80\%$，合成雄激素。睾丸中雄激素浓度是血液中的 10 倍以上，远多于正常精子发生所需。雄激素通过调控间质细胞、支持细胞和肌上皮细胞（对应生精小管外周的肌样细胞）中免疫调节分子的表达，发挥免疫抑制功能。
:::

:::definition{label="睾丸间质中的免疫细胞"}
间质其余约 $20\%$ 多为免疫细胞，来自被膜中的淋巴管，包括大量巨噬细胞、少量 T 淋巴细胞、树突状细胞和肥大细胞，是抵御血液来源病原体的第一道防线。巨噬细胞中约 $80\%$ 长期驻留，约 $20\%$ 由外周血新迁移而至。
:::

:::definition{label="睾丸炎"}
睾丸炎是引起男性不育的病因之一。发生时精子发生和激素分泌异常，可影响生育能力，甚至导致不育。
:::

:::note{label="三类睾丸炎的路径"}
| 类型 | 路径 | 组织学落点 |
|------|------|------------|
| 自身免疫性睾丸炎 | 血-睾屏障等免疫豁免结构被破坏，诱发特异性自身免疫反应 | 屏障和近腔室精子抗原 |
| 细菌感染性睾丸炎 | 多数经输精管、附睾感染蔓延到睾丸 | 生殖管道逆行 |
| 病毒性睾丸炎 | 系统性病毒感染的并发症；流行性腮腺炎、感冒等病原体经血流播散 | 间质免疫细胞那道防线被突破 |
:::

:::insight{label="免疫豁免不是没有免疫细胞，而是屏障加高雄激素把反应按住"}
间质里仍有巨噬细胞、T 细胞、树突状细胞和肥大细胞，约 $20\%$ 的间质细胞是免疫细胞。真正把反应按住的是：血-睾屏障、支持细胞的免疫抑制物质和清扫、以及高出血液 10 倍以上的局部雄激素。把免疫豁免听成“睾丸里没有免疫细胞”，第一道防线和病毒经血播散那本账会对不上。
:::

:::pitfall{label="细菌性睾丸炎多从管道蔓延，病毒性多经血流，不要都写成血-睾屏障破坏"}
屏障破坏对应自身免疫性睾丸炎。细菌多数走输精管和附睾；病毒走血流，常见于腮腺炎、感冒等的并发症。三条路径并成一句，治疗和预防的落点会找错器官。
:::

:::memory{label="插入框必背"}
- [ ] 免疫豁免指某些部位对外来抗原及自身抗原免疫反应很弱，以避免组织损伤和功能紊乱。
- [ ] 免疫豁免位点包括睾丸、大脑、眼及孕期的子宫。
- [ ] 将睾丸或生精细胞移植到其他器官，或将其他组织移植入睾丸，免疫排斥反应很低。
- [ ] 精子发生始于青春期以后，免疫感受能力早已建立，但新发生的生精细胞在睾丸内不诱发免疫反应。
- [ ] 血-睾屏障阻止生精细胞与抗原物质接触，为精子发生提供微环境。
- [ ] 支持细胞分泌免疫抑制物质，并吞噬清除凋亡生精细胞和残体。
- [ ] 间质中约 $80\%$ 是间质细胞，其余约 $20\%$ 多为免疫细胞。
- [ ] 睾丸中雄激素浓度是血液中的 10 倍以上，通过调控免疫调节分子发挥免疫抑制。
- [ ] 间质免疫细胞来自被膜淋巴管，包括大量巨噬细胞、少量 T 淋巴细胞、树突状细胞和肥大细胞。
- [ ] 巨噬细胞约 $80\%$ 长期驻留，约 $20\%$ 由外周血新迁移而至。
- [ ] 血-睾屏障等结构破坏可致自身免疫性睾丸炎。
- [ ] 细菌感染性睾丸炎多数经输精管、附睾蔓延；病毒性睾丸炎常见于腮腺炎、感冒等经血流播散。
- [ ] 睾丸炎时精子发生和激素分泌异常，可导致不育。
:::
