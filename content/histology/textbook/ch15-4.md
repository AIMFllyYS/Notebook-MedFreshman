# 四、胆囊与胆管

上一节把肝小叶、门管区、血窦、窦周隙和胆汁排出途径摊开。胆汁出肝之后，要在胆囊里被贮存、浓缩，再经胆管在进食后排入十二指肠。胆囊与胆管是这一段通路的管壁组织学。

## （一）胆囊

胆囊分底、体、颈 3 部分，颈部连胆囊管。胆囊壁由黏膜、肌层和外膜 3 层组成。黏膜有许多高而分支的皱襞突入腔内，胆囊收缩排空时，皱襞高大而分支；胆囊充盈扩张时，皱襞减少变矮。黏膜上皮为单层柱状上皮，固有层为薄层结缔组织。肌层的平滑肌厚薄不一，胆囊底部较厚，颈部次之，体部最薄。外膜较厚，大部分为浆膜（图 15-21）。

:::definition{label="胆囊"}
胆囊分底、体、颈 3 部分，颈部连胆囊管。功能是贮存和浓缩胆汁。
:::

:::definition{label="胆囊壁三层"}
胆囊壁由黏膜、肌层和外膜 3 层组成。没有黏膜肌层和黏膜下层这本消化管四层账，不要把第 14 章的管壁通例硬套过来。
:::

:::definition{label="胆囊黏膜皱襞"}
黏膜有许多高而分支的皱襞突入腔内。胆囊收缩排空时，皱襞高大而分支；胆囊充盈扩张时，皱襞减少变矮。上皮为单层柱状上皮，固有层为薄层结缔组织。
:::

:::definition{label="胆囊肌层与外膜"}
肌层的平滑肌厚薄不一：底部较厚，颈部次之，体部最薄。外膜较厚，大部分为浆膜。
:::

::figure{src="/images/histology/textbook/p0182_01.png" caption="图15-21 胆囊光镜图。1. 黏膜；2. 肌层；3. 外膜。" alt="胆囊壁：高而分支的黏膜皱襞、厚薄不一的肌层，以及大部分为浆膜的外膜"}

:::concept{term="先问皱襞是排空时高，还是充盈时高"}
胆囊皱襞不是小肠那种永远高耸的吸收面积装置。排空收缩 → 皱襞高大而分支；充盈扩张 → 皱襞减少变矮。上皮仍是单层柱状，职分是主动吸收胆汁中的水和无机盐，把胆汁浓缩。把皱襞听成“固定的绒毛”，贮存容积 $40\sim 70\,\mathrm{ml}$ 那一本账会写死。
:::

胆囊的功能是贮存和浓缩胆汁。胆囊的容量为 $40\sim 70\,\mathrm{ml}$，从肝排出的胆汁流入舒张的胆囊内贮存。胆囊上皮细胞能主动吸收胆汁中的水和无机盐，使胆汁浓缩。进食后，尤其进高脂肪食物后，在小肠分泌的缩胆囊素-促胰酶素作用下，胆囊持续收缩 $30\sim 60$ 分钟，胆总管括约肌松弛，将胆汁排入肠腔。

:::definition{label="胆囊贮存与浓缩"}
胆囊容量为 $40\sim 70\,\mathrm{ml}$。肝排出的胆汁流入舒张的胆囊内贮存。上皮细胞主动吸收胆汁中的水和无机盐，使胆汁浓缩。
:::

:::definition{label="缩胆囊素与胆囊排空"}
进食后，尤其进高脂肪食物后，小肠分泌的缩胆囊素-促胰酶素使胆囊持续收缩 $30\sim 60$ 分钟，胆总管括约肌松弛，将胆汁排入肠腔。同一激素在上一节还调节胰腺泡细胞分泌酶原。
:::

:::insight{label="缩胆囊素一身兼两职：胰酶出腺泡，胆汁出胆囊"}
小肠 I 细胞的缩胆囊素-促胰酶素，对胰腺写的是促酶原分泌，对胆囊写的是持续收缩加括约肌松弛。高脂肪食物把这两本消化液同时叫进十二指肠。把胆囊收缩听成“自己想缩就缩”，会漏掉小肠内分泌这一站。
:::

:::pitfall{label="胆囊黏膜皱襞随充盈改变，不要写成小肠绒毛那种永久高耸的吸收装置"}
绒毛是黏膜上皮加固有层的指状突起，有中央乳糜管，为了吸收食糜。胆囊皱襞是黏膜折向管腔，排空时才高大分支，用来在容积变化时铺开单层柱状上皮去吸水和盐。没有黏膜肌，也不形成绒毛。
:::

:::compare{title="胆囊壁与消化管壁通例"}
| 项目 | 胆囊 | 消化管（除口腔与咽） |
|------|------|----------------------|
| 层次 | 黏膜、肌层、外膜 3 层 | 黏膜、黏膜下层、肌层、外膜 4 层 |
| 黏膜 | 单层柱状；固有层薄；无黏膜肌 | 上皮 + 固有层 + 黏膜肌层 |
| 皱襞 | 随排空 / 充盈高低变化 | 黏膜 + 黏膜下层共同突起（食管、胃、肠） |
| 肌层 | 平滑肌厚薄不一：底厚、颈次之、体最薄 | 一般内环外纵；胃为内斜、中环、外纵 |
| 外膜 | 较厚，大部分为浆膜 | 中段浆膜，咽、食管、直肠纤维膜 |
| 功能侧重 | 贮存、浓缩并按时排出胆汁 | 消化、吸收、屏障 |
:::

## （二）胆管

由肝分泌的胆汁经左右肝管、肝总管、胆囊管进入胆囊贮存，胆囊中贮存的浓缩胆汁经胆囊管、胆总管排入十二指肠。

肝外胆管管壁分黏膜、肌层和外膜 3 层。胆总管黏膜的上皮为单层柱状上皮，有杯状细胞，固有层内有黏液腺。肝管和胆总管的上 $1/3$ 段肌层很薄，平滑肌分散；胆总管的中 $1/3$ 段肌层渐厚，尤其是纵行平滑肌增多；胆总管下 $1/3$ 段的肌层分内环行、外纵行两层。胆总管在与胰管汇合后，穿入十二指肠壁，局部扩大形成壶腹，此处的环行平滑肌增厚形成壶腹括约肌，其舒缩作用控制了胆汁和胰液的排出。胆管外膜为较厚的结缔组织。

:::definition{label="胆汁入胆囊与出胆囊"}
肝分泌的胆汁经左右肝管、肝总管、胆囊管进入胆囊贮存；浓缩胆汁经胆囊管、胆总管排入十二指肠。
:::

:::definition{label="肝外胆管壁"}
肝外胆管管壁分黏膜、肌层和外膜 3 层。胆总管黏膜上皮为单层柱状，有杯状细胞，固有层内有黏液腺。外膜为较厚的结缔组织。
:::

:::definition{label="胆总管肌层三段"}
肝管和胆总管的上 $1/3$ 段肌层很薄，平滑肌分散；胆总管的中 $1/3$ 段肌层渐厚，尤其是纵行平滑肌增多；胆总管下 $1/3$ 段的肌层分内环行、外纵行两层。
:::

:::definition{label="壶腹与壶腹括约肌"}
胆总管与胰管汇合后穿入十二指肠壁，局部扩大形成壶腹。此处环行平滑肌增厚形成壶腹括约肌，其舒缩控制胆汁和胰液的排出。
:::

:::note{label="胆总管肌层由上向下逐渐成层"}
| 段 | 肌层 |
|----|------|
| 肝管和胆总管上 $1/3$ | 很薄，平滑肌分散 |
| 胆总管中 $1/3$ | 渐厚，纵行平滑肌增多 |
| 胆总管下 $1/3$ | 内环行、外纵行两层 |
| 壶腹 | 环行平滑肌增厚为壶腹括约肌，同时管胆汁和胰液 |
:::

:::compare{title="小叶间胆管、肝外胆管与胆囊"}
| 项目 | 小叶间胆管 | 肝外胆管（胆总管） | 胆囊 |
|------|------------|-------------------|------|
| 位置 | 门管区 | 肝外，汇入十二指肠 | 贮存器官 |
| 上皮 | 单层立方 | 单层柱状，有杯状细胞 | 单层柱状，无杯状细胞强调 |
| 固有层腺体 | — | 有黏液腺 | 薄层结缔组织 |
| 肌层 | — | 上薄下厚，下 $1/3$ 内环外纵 | 底厚、颈次、体薄 |
| 开口 / 职分 | 向肝门汇成左右肝管 | 与胰管汇合，壶腹括约肌控排出 | 浓缩贮存，CCK 下排空 |
:::

:::pitfall{label="壶腹括约肌同时管胆汁和胰液，不要写成只关胆囊"}
胆总管与胰管先汇合，再穿十二指肠壁扩大成壶腹。括约肌一缩，两管的出口一起关上；一舒，胆汁和胰液一起进肠腔。缩胆囊素让胆囊收缩的同时让这圈括约肌松弛。把括约肌只写成“胆囊颈部的开关”，胰液排出账会找不到门。
:::

:::keypoint{label="胆囊先立三层和皱襞，胆管再记下1/3成层和壶腹括约肌"}
- 胆囊分底、体、颈；壁为黏膜、肌层、外膜 3 层。
- 黏膜高而分支的皱襞：排空时高大，充盈时变矮；单层柱状上皮主动吸收水和无机盐，浓缩胆汁。
- 肌层底厚、颈次、体最薄；外膜大部分为浆膜。容量 $40\sim 70\,\mathrm{ml}$。
- 高脂肪食物 → 缩胆囊素-促胰酶素 → 胆囊收缩 $30\sim 60$ 分钟，胆总管括约肌松弛。
- 肝外胆管亦为 3 层；胆总管上皮单层柱状有杯状细胞，固有层有黏液腺。
- 肌层上 $1/3$ 薄而分散，中 $1/3$ 纵行增多，下 $1/3$ 内环外纵；壶腹括约肌控制胆汁和胰液排出。
:::

## 本章小结

消化腺由唾液腺、胰腺、肝和分布于消化管壁内的许多小消化腺组成，参与人体的消化、吸收、代谢等功能。唾液腺起润滑口腔和食物的作用，开始进行食物的消化。胰腺外分泌部每天分泌 $1\,000\sim 2\,000\,\mathrm{ml}$ 含消化酶的胰液进入十二指肠，参与消化功能。人胰岛主要有 A 细胞、B 细胞、D 细胞、PP 细胞。A 细胞分泌胰高血糖素，能促进肝细胞的糖原分解为葡萄糖，并抑制糖原合成，使血糖浓度升高。B 细胞分泌胰岛素，主要促进肝细胞、脂肪细胞等吸收血液内的葡萄糖，合成糖原或转化为脂肪贮存，使血糖降低。若胰岛发生病变，B 细胞退化，胰岛素分泌不足可致血糖升高，并从尿中排出，即为糖尿病。胰岛 B 细胞肿瘤或细胞功能亢进，则胰岛素分泌过多，可导致低血糖症。

肝实质由许多肝小叶组成，小叶周边有门管区。肝小叶中央有中央静脉，周围有肝索（或肝板）和肝血窦，肝小叶为肝的基本结构和功能单位。肝细胞呈多面体形，有 3 种不同的功能面，即血窦面、细胞连接面和胆小管面，肝细胞细胞质呈嗜酸性，含有弥散分布的嗜碱性团块。电镜下，细胞质内各种细胞器均丰富。胆小管位于肝细胞相邻面，并在肝板内连接成网。肝血窦位于肝板之间，互相吻合成网状管道，血窦壁由内皮细胞组成，窦腔内有肝巨噬细胞，具有吞噬和清除细菌、病毒和异物的功能。血液从肝小叶的周边经肝血窦汇入中央静脉。窦周隙是肝血窦内皮细胞与肝细胞之间的狭小间隙，是肝细胞与血液之间进行物质交换的场所。贮脂细胞位于窦周隙，有产生胶原的功能。在病理状况下，贮脂细胞增多并转化为成纤维细胞，合成胶原的功能增强，与肝纤维化的发生有关。门管区位于肝小叶周围，有较多的结缔组织，含有小叶间静脉、小叶间动脉和小叶间胆管，还有淋巴管和神经纤维。每个肝小叶的周围一般有 $3\sim 5$ 个门管区。

:::definition{label="本章结构通式"}
消化腺 = 3 对大唾液腺 + 胰腺（外分泌腺泡 + 胰岛）+ 肝（肝小叶 + 门管区）+ 管壁内小消化腺。唾液腺用浆液 / 黏液腺泡和纹状管开口于口腔；胰液经主导管入十二指肠，胰岛激素入血调血糖；肝小叶以中央静脉为轴，血窦汇入中央，胆汁经胆小管走向周边门管区，胆囊浓缩后再经壶腹括约肌与胰液一同入肠。
:::

:::keypoint{label="全章把三对唾液腺、腺泡对胰岛、肝小叶对门管区收口"}
- 腮腺纯浆液，下颌下腺浆液多的混合腺，舌下腺黏液为主；纹状管基部纵纹转运水和电解质。
- 胰腺腺泡走酶原，胰岛走激素：胰岛不是外分泌。
- 肝小叶中央静脉收血；门管区三件套走门静脉血、动脉血和胆汁；胆管 ≠ 中央静脉。
- 窦周隙是 Disse 隙，不是血窦腔；库普弗细胞在窦内，贮脂细胞在窦周隙。
- 胆汁由中央流向周边，血液由周边流向中央；连接复合体破坏则黄疸。
- 胆囊浓缩贮存，壶腹括约肌同时控制胆汁和胰液。
:::

- [ ] B 细胞分泌胰岛素，促进肝细胞、脂肪细胞等吸收血液内葡萄糖，合成糖原或转化为脂肪贮存，使血糖降低。
- [ ] 胰岛病变、B 细胞退化、胰岛素分泌不足 → 血糖升高并从尿中排出，为糖尿病。
- [ ] 胰岛 B 细胞肿瘤或功能亢进 → 胰岛素过多，可致低血糖症。
- [ ] 肝实质由许多肝小叶组成，小叶周边有门管区。
- [ ] 肝小叶中央有中央静脉，周围有肝索（或肝板）和肝血窦；肝小叶为肝的基本结构和功能单位。
- [ ] 肝细胞呈多面体形，有血窦面、细胞连接面和胆小管面 3 种功能面。
- [ ] 肝细胞胞质呈嗜酸性，含弥散分布的嗜碱性团块；电镜下各种细胞器均丰富。
- [ ] 胆小管位于肝细胞相邻面，并在肝板内连接成网。
- [ ] 肝血窦位于肝板之间，互相吻合成网状管道，血窦壁由内皮细胞组成。
- [ ] 窦腔内有肝巨噬细胞，具有吞噬和清除细菌、病毒和异物的功能。
- [ ] 血液从肝小叶的周边经肝血窦汇入中央静脉。
- [ ] 窦周隙是肝血窦内皮细胞与肝细胞之间的狭小间隙，是肝细胞与血液之间进行物质交换的场所。
- [ ] 贮脂细胞位于窦周隙，有产生胶原的功能。
- [ ] 病理状况下贮脂细胞增多并转化为成纤维细胞，合成胶原增强，与肝纤维化的发生有关。
- [ ] 门管区位于肝小叶周围，结缔组织较多，含小叶间静脉、小叶间动脉和小叶间胆管，还有淋巴管和神经纤维。
- [ ] 每个肝小叶周围一般有 $3\sim 5$ 个门管区。
:::

## 插入框：胰岛素与糖尿病

糖尿病是一组以高血糖为主要标志的代谢性疾病。长期存在的高血糖将导致各种组织，特别是眼、肾、心脏、血管、神经的慢性损害和功能障碍。临床上一般分为 1 型和 2 型两种类型糖尿病，其中 2 型占 $90\%$ 以上。1 型糖尿病患者胰岛 B 细胞被破坏而导致胰岛素绝对缺乏，需依靠外源胰岛素存活，一旦终止胰岛素治疗则威胁生命。2 型糖尿病多起因于胰岛素抵抗伴胰岛素相对性缺乏或胰岛素分泌受损伴胰岛素抵抗，患者可口服促进胰腺分泌胰岛素的药物降糖。我国在 1965 年完成了人工牛胰岛素的全合成，1996 年通过对胰岛素化学结构的改造和修饰得到第一个胰岛素类似物。

近年来科研工作者在糖尿病的新药研发和治疗方法上取得了显著进展。特别值得一提的是胰高血糖素样肽-1（glucagon-like peptide-1，GLP-1）受体激动剂，这类药物模拟体内自然产生的 GLP-1，通过增加胰岛素的分泌而抑制胰高血糖素的释放，降低血糖水平。与传统治疗手段相比，该类药物具有明显的疗效和较高的安全性，除了可以有效地降低血糖水平、改善胰岛素抵抗，还能减轻患者体重，并对心血管系统产生保护作用。除了药物治疗，饮食、运动和心理健康的支持在维护糖尿病患者健康方面都发挥着越来越重要的作用。

:::definition{label="糖尿病"}
糖尿病是一组以高血糖为主要标志的代谢性疾病。长期高血糖导致各种组织，特别是眼、肾、心脏、血管、神经的慢性损害和功能障碍。临床上一般分为 1 型和 2 型，2 型占 $90\%$ 以上。
:::

:::definition{label="1 型糖尿病"}
1 型糖尿病患者胰岛 B 细胞被破坏而导致胰岛素绝对缺乏，需依靠外源胰岛素存活，一旦终止胰岛素治疗则威胁生命。组织学落点是 B 细胞本身没了。
:::

:::definition{label="2 型糖尿病"}
2 型糖尿病多起因于胰岛素抵抗伴胰岛素相对性缺乏，或胰岛素分泌受损伴胰岛素抵抗。患者可口服促进胰腺分泌胰岛素的药物降糖。B 细胞未必被完全破坏，问题常在效应不足。
:::

:::definition{label="GLP-1 受体激动剂"}
胰高血糖素样肽-1（glucagon-like peptide-1，GLP-1）受体激动剂模拟体内自然产生的 GLP-1，通过增加胰岛素分泌而抑制胰高血糖素释放，降低血糖。除降糖、改善胰岛素抵抗外，还能减轻体重并对心血管系统产生保护作用。
:::

:::note{label="1 型与 2 型糖尿病"}
| 项目 | 1 型 | 2 型 |
|------|------|------|
| 约占 | 少数 | $90\%$ 以上 |
| 胰岛 B 细胞 | 被破坏，胰岛素绝对缺乏 | 抵抗和/或分泌受损，相对缺乏 |
| 治疗要点 | 必须外源胰岛素，停药威胁生命 | 可口服促分泌药物；饮食、运动、心理支持同样重要 |
| 与本节胰岛账 | B 细胞退化的极端形式 | 激素有了，靶细胞或分泌量对不上 |
:::

| 年份 | 事件 |

:::

:::insight{label="插入框把 B 细胞的绝对缺乏和抵抗分开，再把 GLP-1 接回 A/B 平衡"}
本节正文写：B 细胞不够 → 糖尿病，B 细胞太多 → 低血糖。插入框把“不够”再拆成两本：1 型是细胞被毁、胰岛素绝对没有；2 型常是抵抗加相对缺乏。GLP-1 受体激动剂一边加胰岛素、一边压胰高血糖素，等于同时改写 A、B 两本血糖账。饮食、运动和心理支持不是附录，是和维护胰岛功能并行的治疗。
:::

:::pitfall{label="2 型不是“另一种胰岛被杀光”，不要把口服药适应证写成 1 型"}
1 型必须外源胰岛素替代，因为 B 细胞毁了。2 型可以口服促分泌药，前提是还有能被推动的 B 细胞，问题常在抵抗。把两类并成“都是胰岛坏了，都打胰岛素”，会把 GLP-1、促分泌药和绝对缺乏三本账拧成一句。
:::
