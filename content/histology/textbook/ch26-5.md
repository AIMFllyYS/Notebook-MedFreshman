# 五、神经系统相关内分泌腺的发生

垂体、松果体和肾上腺并非完全起源于神经外胚层，但它们在发生过程中与神经管和神经嵴密切相关，故在本章一并介绍。本节先把口凹表面外胚层的拉特克囊和间脑神经垂体芽对接到腺垂体、神经垂体，再按松果体板 → 囊 → 实质的时间尺，以及肾上腺皮质（脏壁中胚层）与髓质（神经嵴）摊开。神经垂体、松果体挂在神经管上，肾上腺髓质挂在神经嵴上，与第一节总账一致。

垂体、松果体和肾上腺并非完全起源于神经外胚层，但它们在发生过程中与神经管和神经嵴密切相关，故在本章一并介绍。

:::definition{label="本章为何写这三枚腺"}
垂体、松果体和肾上腺并非完全起源于神经外胚层。它们在发生过程中与神经管和神经嵴密切相关，所以放在神经系统发生这一章。不要写成“三枚腺都是神经外胚层变的”。
:::

:::concept{term="先问这是口凹拉特克囊还是间脑神经垂体芽，再问肾上腺这层是胎儿皮质、永久皮质还是神经嵴髓质"}
看见神经系统相关内分泌腺，先把垂体切开：口凹背侧顶部表面外胚层凹陷成拉特克囊，走腺垂体（远侧部、结节部、中间部，偶尔咽垂体）；间脑底部神经外胚层向腹侧成神经垂体芽，远端成神经垂体、起始部成漏斗柄。松果体走间脑顶板：第 $5$ 周板、第 $7$ 周囊、第 $8$ 周实质。肾上腺再切开胚层：皮质是肠系膜根与生殖嵴之间的脏壁中胚层表面上皮，第 $5$ 周胎儿皮质、第 $7$ 周永久皮质；髓质是第 $6$ 周迁入的神经嵴，出生后 $12\sim 18$ 月龄才完善。把整个垂体听成神经管，或把肾上腺皮质写成神经嵴，户头会对错。
:::

## （一）垂体的发生

垂体包括腺垂体和神经垂体，分别来源于胚胎时期口凹的表面外胚层和脑泡的神经外胚层。胚胎第 $4$ 周，口凹背侧顶部的外胚层上皮向深部凹陷，形成一囊状突起，叫拉特克囊（Rathke pouch）（图 26-10）。稍后，间脑底部的神经外胚层向腹侧朝拉特克囊方向形成一漏斗状突起，即神经垂体芽。拉特克囊和神经垂体芽逐渐增大并相互接近。至第 $2$ 个月末，囊的根部退化消失，其远端长大并与神经垂体芽相贴。神经垂体芽的远端膨大，形成神经垂体，其起始部变细，形成漏斗柄。而囊的前壁迅速增厚，形成垂体的远侧部。由远侧部再向上长出一结节状突起包绕漏斗柄，形成结节部。囊的后壁生长缓慢，形成中间部。囊腔大部消失，只残留小的裂隙。此裂隙偶尔下延，于咽的顶壁内形成咽垂体。腺垂体中分化出多种腺细胞；神经垂体主要由神经纤维和神经胶质细胞构成。

:::definition{label="垂体的两份原基"}
垂体包括腺垂体和神经垂体，分别来源于胚胎时期口凹的表面外胚层和脑泡的神经外胚层。腺垂体对口凹外胚层，神经垂体对脑泡神经外胚层，不要对调。
:::

:::definition{label="拉特克囊"}
胚胎第 $4$ 周，口凹背侧顶部的外胚层上皮向深部凹陷，形成一囊状突起，叫拉特克囊（Rathke pouch）。它是腺垂体的原基，不是间脑长出来的。
:::

:::definition{label="神经垂体芽"}
稍后，间脑底部的神经外胚层向腹侧朝拉特克囊方向形成一漏斗状突起，即神经垂体芽。方向是间脑朝口凹那一侧去对接，不是口凹去顶间脑。
:::

:::definition{label="第2个月末的对接"}
拉特克囊和神经垂体芽逐渐增大并相互接近。至第 $2$ 个月末，囊的根部退化消失，其远端长大并与神经垂体芽相贴。根部退化，远端留下贴神经垂体芽；咽顶若仍有残余，才可能出现咽垂体。
:::

:::definition{label="神经垂体与漏斗柄"}
神经垂体芽的远端膨大，形成神经垂体，其起始部变细，形成漏斗柄。远端是神经垂体，起始部是漏斗柄，不要把柄写成腺垂体。
:::

:::definition{label="远侧部"}
囊的前壁迅速增厚，形成垂体的远侧部。远侧部是拉特克囊前壁，属腺垂体。
:::

:::definition{label="结节部"}
由远侧部再向上长出一结节状突起包绕漏斗柄，形成结节部。结节部来自远侧部，包的是漏斗柄，不是另从神经垂体芽长出。
:::

:::definition{label="中间部"}
囊的后壁生长缓慢，形成中间部。后壁慢、前壁快，所以远侧部厚、中间部薄。
:::

:::definition{label="咽垂体"}
囊腔大部消失，只残留小的裂隙。此裂隙偶尔下延，于咽的顶壁内形成咽垂体。咽垂体是拉特克囊腔残余下延的产物，不是神经垂体芽的分叉。
:::

:::definition{label="腺垂体与神经垂体的组织"}
腺垂体中分化出多种腺细胞；神经垂体主要由神经纤维和神经胶质细胞构成。一边是腺，一边是纤维加胶质，切片上不要认成同一类细胞。
:::

:::timeline{period="垂体两份原基对接"}
- **口凹表面外胚层** 将来的腺垂体侧
- **脑泡神经外胚层（间脑底）** 将来的神经垂体侧
- **第4周（正文）** 口凹背侧顶部外胚层凹陷成拉特克囊
- **稍后** 间脑底部向腹侧成漏斗状神经垂体芽，两份增大并接近
- **第2个月末** 囊根部退化消失，远端与神经垂体芽相贴
- **随后** 芽远端 → 神经垂体，起始部 → 漏斗柄；囊前壁 → 远侧部，远侧部向上包漏斗柄 → 结节部，囊后壁 → 中间部
- **囊腔** 大部消失，残留小裂隙；裂隙偶尔下延 → 咽顶壁内的咽垂体
:::

:::compare{title="拉特克囊与神经垂体芽"}
| 项目 | 拉特克囊 | 神经垂体芽 |
|------|----------|------------|
| 来源胚层 | 口凹的表面外胚层 | 脑泡（间脑底部）的神经外胚层 |
| 形态 | 口凹背侧顶部向深部凹陷的囊状突起 | 向腹侧朝拉特克囊的漏斗状突起 |
| 第 $2$ 个月末 | 根部退化消失，远端长大并与芽相贴 | 与囊远端相贴 |
| 以后 | 前壁 → 远侧部；远侧部向上 → 结节部；后壁 → 中间部；腔残余可成咽垂体 | 远端 → 神经垂体；起始部变细 → 漏斗柄 |
| 组织 | 腺垂体，分化出多种腺细胞 | 神经垂体，主要由神经纤维和神经胶质细胞构成 |
:::

:::compare{title="远侧部、结节部、中间部、神经垂体与咽垂体"}
| 结构 | 来自哪一壁／哪一段 | 要点 |
|------|--------------------|------|
| 远侧部 | 拉特克囊前壁迅速增厚 | 腺垂体主体 |
| 结节部 | 远侧部向上长出的结节状突起，包绕漏斗柄 | 仍属腺垂体，不是漏斗柄本身 |
| 中间部 | 囊的后壁，生长缓慢 | 夹在远侧部与神经垂体之间 |
| 神经垂体 | 神经垂体芽远端膨大 | 纤维 + 胶质 |
| 漏斗柄 | 神经垂体芽起始部变细 | 被结节部包绕 |
| 咽垂体 | 囊腔残余裂隙偶尔下延至咽的顶壁内 | 不是常规都会出现 |
:::

:::derivation{title="两份原基相贴后，才拆得出腺垂体三部和漏斗柄"}
先有口凹凹陷成囊、间脑底漏出芽，两份对长、第 $2$ 个月末根断远端贴上。贴上之后才谈得上：芽的远端膨成神经垂体、起始部细成漏斗柄；囊前壁厚成远侧部，再向上包漏斗柄成结节部；后壁慢成中间部。根没断、两份没贴，咽垂体和漏斗柄都没有着落。
:::

:::cause-effect{title="囊根退化，远端才留下；裂隙下延才可能有咽垂体"}
- 因：第 $2$ 个月末拉特克囊根部退化消失
- 果：囊与口凹／咽顶的通道断开，远端留在颅内与神经垂体芽相贴
- 因：囊腔大部消失，只残留小裂隙，裂隙偶尔下延
- 果：咽的顶壁内可形成咽垂体
- 制约：咽垂体是“偶尔”，不是每例都有
:::

:::pitfall{label="结节部来自远侧部，不要写成神经垂体芽长出来的"}
结节部是远侧部向上长出的结节状突起，去包绕漏斗柄。漏斗柄本身是神经垂体芽起始部变细。把结节部写成神经部的一部分，腺垂体三部会对不成套。
:::

:::insight{label="腺垂体是口凹外胚层，神经垂体是间脑神经外胚层，两份对上才成一枚垂体"}
同一枚垂体，腹侧那一团腺细胞走口凹，背侧那一团纤维走间脑。颅咽管瘤挂在拉特克囊／颅咽管未退化（第六节），漏斗瘤挂在第三脑室底部。发生时就把两份原基分开记，畸形才有原基可对。
:::

## （二）松果体的发生

第 $5$ 周间脑顶板的室管膜上皮增厚，形成松果体板。第 $7$ 周松果体板发生外突，构成松果体囊。第 $8$ 周松果体囊壁细胞增生，囊腔消失，形成一实质性松果样器官，即松果体。松果体细胞和神经胶质细胞均由神经上皮分化而来。其中松果体细胞出现早，胚胎第 $8$ 周即开始出现，第 $5$ 个月增生明显，第 $6$ 个月分化明显，细胞器逐渐增多，第 $8$ 个月已近似成年。神经胶质细胞出现较晚，胚胎第 $12$ 周左右开始出现，属于星形胶质细胞。胚胎第 $3$ 个月初，交感神经的分支长入松果体。

:::definition{label="松果体板"}
第 $5$ 周间脑顶板的室管膜上皮增厚，形成松果体板。起点是间脑顶板室管膜，还不是囊，更不是实质器官。
:::

:::definition{label="松果体囊"}
第 $7$ 周松果体板发生外突，构成松果体囊。板先外突成囊，第 $8$ 周囊腔才消失。
:::

:::definition{label="松果体"}
第 $8$ 周松果体囊壁细胞增生，囊腔消失，形成一实质性松果样器官，即松果体。实质化发生在第 $8$ 周。
:::

:::definition{label="松果体细胞与胶质的共同来源"}
松果体细胞和神经胶质细胞均由神经上皮分化而来。两份都是神经上皮，但出现时间不同。
:::

:::definition{label="松果体细胞的时间尺"}
松果体细胞出现早：胚胎第 $8$ 周即开始出现，第 $5$ 个月增生明显，第 $6$ 个月分化明显，细胞器逐渐增多，第 $8$ 个月已近似成年。
:::

:::definition{label="松果体胶质细胞的时间尺"}
神经胶质细胞出现较晚，胚胎第 $12$ 周左右开始出现，属于星形胶质细胞。不要写成和第 $8$ 周松果体细胞同时出现。
:::

:::definition{label="交感神经长入松果体"}
胚胎第 $3$ 个月初，交感神经的分支长入松果体。传入的是交感神经分支，不是松果体自己长出交感节。
:::

:::timeline{period="松果体：从板到囊到实质"}
- **第5周** 间脑顶板室管膜上皮增厚 → 松果体板
- **第7周** 松果体板外突 → 松果体囊
- **第8周** 囊壁细胞增生，囊腔消失 → 实质性松果体；松果体细胞开始出现
- **第12周左右** 神经胶质细胞开始出现（星形胶质细胞）
- **第3个月初** 交感神经分支长入松果体
- **第5个月** 松果体细胞增生明显
- **第6个月** 松果体细胞分化明显，细胞器逐渐增多
- **第8个月** 松果体细胞已近似成年
:::

:::compare{title="松果体细胞与松果体胶质细胞"}
| 项目 | 松果体细胞 | 神经胶质细胞 |
|------|------------|--------------|
| 来源 | 神经上皮 | 神经上皮 |
| 开始出现 | 第 $8$ 周 | 第 $12$ 周左右 |
| 类型 | 松果体细胞 | 星形胶质细胞 |
| 以后 | 第 $5$ 个月增生明显；第 $6$ 个月分化明显、细胞器增多；第 $8$ 个月近似成年 | 出现晚于松果体细胞 |
:::

:::pitfall{label="第8周是实质化并开始出现松果体细胞，胶质要等到第12周左右"}
第 $8$ 周囊腔消失、松果体细胞开始出现，和“已经近似成年”不是同一时刻；近似成年是第 $8$ 个月。胶质细胞第 $12$ 周左右才出现。把第 $8$ 周听成细胞已经成熟，或把胶质写成和第 $8$ 周一起出现，两本时钟会并成一句。
:::

:::note{label="第8周和第8个月不要并成一个8"}
松果体细胞：第 $8$ 周开始出现，第 $8$ 个月才近似成年。中间还要经过第 $5$ 个月增生、第 $6$ 个月分化。写成“第 $8$ 周已经成年”，增生和分化两段会消失。
:::

## （三）肾上腺的发生

肾上腺实质包括皮质和髓质，皮质来源于脏壁中胚层，而髓质来源于神经嵴（见图 21-18）。

肾上腺皮质发生早。人胚第 $3\sim 4$ 周，肠系膜根部与发育中的生殖嵴之间的中胚层表面上皮增生，并移向深部的间充质，人胚第 $5$ 周分化为肾上腺的胎儿皮质。第 $7$ 周，表面上皮细胞第二次增生，并进入间充质，围绕在胎儿皮质周围，成为永久皮质。胎儿皮质在出生后很快退化，永久皮质在胎儿后期开始分化，到胎儿出生时可见球状带和束状带，到 $3$ 岁时才出现网状带。

肾上腺的髓质发生较晚。约在人胚发育第 $6$ 周，神经嵴的细胞迁移并进入胎儿皮质内侧，与肾上腺皮质接触的细胞分化成髓质的嗜铬细胞，其余少量细胞分化成交感神经节细胞。最初髓质细胞混杂在皮质之间，以后逐渐向中心迁移，第 $20$ 周左右多数髓质细胞迁移至肾上腺中轴。出生后 $12\sim 18$ 月龄时，髓质发育完善。

:::definition{label="肾上腺皮质与髓质的胚层"}
肾上腺实质包括皮质和髓质，皮质来源于脏壁中胚层，而髓质来源于神经嵴。两份胚层不要写反。
:::

:::definition{label="肾上腺原基的地点"}
人胚第 $3\sim 4$ 周，肠系膜根部与发育中的生殖嵴之间的中胚层表面上皮增生，并移向深部的间充质。地点在肠系膜根与生殖嵴之间，不是肾本身长出来的。
:::

:::definition{label="胎儿皮质"}
人胚第 $5$ 周，上述中胚层表面上皮分化为肾上腺的胎儿皮质。这是第一次增生迁入后的产物。
:::

:::definition{label="永久皮质"}
第 $7$ 周，表面上皮细胞第二次增生，并进入间充质，围绕在胎儿皮质周围，成为永久皮质。永久皮质包在胎儿皮质外面，不是先有永久再填胎儿。
:::

:::definition{label="皮质带的出现顺序"}
胎儿皮质在出生后很快退化。永久皮质在胎儿后期开始分化，到胎儿出生时可见球状带和束状带，到 $3$ 岁时才出现网状带。出生时还没有网状带。
:::

:::definition{label="髓质细胞迁入"}
约在人胚发育第 $6$ 周，神经嵴的细胞迁移并进入胎儿皮质内侧。与肾上腺皮质接触的细胞分化成髓质的嗜铬细胞，其余少量细胞分化成交感神经节细胞。嗜铬细胞是接触皮质的那一份。
:::

:::definition{label="髓质向中轴集中"}
最初髓质细胞混杂在皮质之间，以后逐渐向中心迁移，第 $20$ 周左右多数髓质细胞迁移至肾上腺中轴。先混杂，后集中，不是一开始就占中心。
:::

:::definition{label="髓质发育完善"}
出生后 $12\sim 18$ 月龄时，髓质发育完善。完善在出生以后，不是出生当时。
:::

:::timeline{period="肾上腺皮质与髓质"}
- **第3～4周** 肠系膜根与生殖嵴之间的中胚层表面上皮增生，移向深部间充质
- **第5周** 分化为胎儿皮质
- **第6周** 神经嵴细胞迁入胎儿皮质内侧，接触皮质者成嗜铬细胞，少量成交感神经节细胞
- **第7周** 表面上皮第二次增生，进入间充质，围绕胎儿皮质成为永久皮质
- **第20周左右** 多数髓质细胞迁至肾上腺中轴
- **胎儿后期** 永久皮质开始分化
- **出生时** 可见球状带和束状带；胎儿皮质出生后很快退化；尚无网状带
- **3岁** 才出现网状带
- **出生后12～18月龄** 髓质发育完善
:::

:::compare{title="肾上腺皮质与髓质"}
| 项目 | 皮质 | 髓质 |
|------|------|------|
| 胚层 | 脏壁中胚层 | 神经嵴 |
| 开始 | 较早（第 $3\sim 4$ 周表面上皮增生） | 较晚（约第 $6$ 周迁入） |
| 关键结构 | 第 $5$ 周胎儿皮质；第 $7$ 周永久皮质包在其周围 | 嗜铬细胞（与皮质接触者）+ 少量交感神经节细胞 |
| 位置变化 | 永久皮质在外，胎儿皮质在内，出生后胎儿皮质很快退化 | 先混杂在皮质之间，第 $20$ 周左右多数迁至中轴 |
| 完善 | 出生时球状带、束状带；第 $3$ 岁才见网状带 | 出生后 $12\sim 18$ 月龄发育完善 |
:::

:::compare{title="胎儿皮质与永久皮质"}
| 项目 | 胎儿皮质 | 永久皮质 |
|------|----------|----------|
| 形成 | 第 $5$ 周，第一次增生的中胚层表面上皮分化 | 第 $7$ 周，表面上皮第二次增生，进入间充质 |
| 位置 | 被永久皮质围绕，相对靠内 | 围绕在胎儿皮质周围 |
| 出生后 | 很快退化 | 保留并继续分化 |
| 带 | 不形成成体三带 | 胎儿后期开始分化；出生时球状带、束状带；第 $3$ 岁网状带 |
:::

:::cause-effect{title="两次增生才有两层皮质，神经嵴后迁才有髓质"}
- 因：第 $3\sim 4$ 周肠系膜根与生殖嵴之间的中胚层表面上皮增生并内移
- 果：第 $5$ 周出现胎儿皮质
- 因：第 $7$ 周表面上皮第二次增生，进入间充质并包在胎儿皮质周围
- 果：永久皮质形成；出生后胎儿皮质退化，永久皮质留下球状带、束状带，第 $3$ 岁才补上网状带
- 因：第 $6$ 周神经嵴迁入胎儿皮质内侧
- 果：接触皮质者成嗜铬细胞，少量成交感神经节细胞；先混杂后迁中轴，出生后 $12\sim 18$ 月龄完善
:::

:::pitfall{label="网状带不是出生时就有，髓质也不是出生当时就完善"}
出生时永久皮质只见球状带和束状带，网状带到 $3$ 岁才出现。髓质第 $6$ 周已迁入，但要到出生后 $12\sim 18$ 月龄才发育完善。写成“新生儿肾上腺已经是成体三带加成熟髓质”，两本完善时钟都会提前。
:::

:::pitfall{label="嗜铬细胞是神经嵴，皮质不是"}
第四节已写神经嵴迁入肾上腺原基成嗜铬细胞。原基本身由脏壁中胚层增生形成。把整个肾上腺都写成神经嵴，胎儿皮质和永久皮质就没有胚层可挂。
:::

:::keypoint{label="垂体两份原基对接，松果体板囊实质，肾上腺皮质中胚层、髓质神经嵴"}
- 三枚腺并非都来自神经外胚层，但与神经管、神经嵴密切相关。
- 腺垂体：口凹表面外胚层 → 拉特克囊 → 远侧部、结节部、中间部，腔残余可成咽垂体。
- 神经垂体：间脑底神经外胚层 → 神经垂体芽 → 神经垂体 + 漏斗柄。
- 第 $2$ 个月末囊根退化，远端与芽相贴。
- 松果体：第 $5$ 周板 → 第 $7$ 周囊 → 第 $8$ 周实质；松果体细胞早（第 $8$ 周起，第 $8$ 个月近似成年），胶质晚（第 $12$ 周，星形胶质）；第 $3$ 个月初交感神经长入。
- 肾上腺皮质：脏壁中胚层；第 $5$ 周胎儿皮质，第 $7$ 周永久皮质；出生后胎儿皮质退化；出生时球、束状带，$3$ 岁网状带。
- 髓质：第 $6$ 周神经嵴迁入，嗜铬细胞 + 少量交感神经节细胞；第 $20$ 周左右多在中轴；出生后 $12\sim 18$ 月龄完善。
:::

:::memory{label="本节必背要点"}
- [ ] 垂体、松果体和肾上腺并非完全起源于神经外胚层，但发生过程与神经管和神经嵴密切相关，故在本章一并介绍。
- [ ] 垂体包括腺垂体和神经垂体，分别来源于胚胎时期口凹的表面外胚层和脑泡的神经外胚层。
- [ ] 胚胎第 $4$ 周，口凹背侧顶部的外胚层上皮向深部凹陷，形成拉特克囊（Rathke pouch）。
- [ ] 稍后，间脑底部的神经外胚层向腹侧朝拉特克囊方向形成漏斗状突起，即神经垂体芽。
- [ ] 拉特克囊和神经垂体芽逐渐增大并相互接近。
- [ ] 至第 $2$ 个月末，囊的根部退化消失，其远端长大并与神经垂体芽相贴。
- [ ] 神经垂体芽的远端膨大形成神经垂体，起始部变细形成漏斗柄。
- [ ] 囊的前壁迅速增厚，形成垂体的远侧部。
- [ ] 由远侧部再向上长出一结节状突起包绕漏斗柄，形成结节部。
- [ ] 囊的后壁生长缓慢，形成中间部。
- [ ] 囊腔大部消失，只残留小的裂隙；此裂隙偶尔下延，于咽的顶壁内形成咽垂体。
- [ ] 腺垂体中分化出多种腺细胞；神经垂体主要由神经纤维和神经胶质细胞构成。
- [ ] 第 $5$ 周间脑顶板的室管膜上皮增厚，形成松果体板。
- [ ] 第 $7$ 周松果体板发生外突，构成松果体囊。
- [ ] 第 $8$ 周松果体囊壁细胞增生，囊腔消失，形成实质性松果样器官，即松果体。
- [ ] 松果体细胞和神经胶质细胞均由神经上皮分化而来。
- [ ] 松果体细胞出现早：第 $8$ 周开始出现，第 $5$ 个月增生明显，第 $6$ 个月分化明显、细胞器逐渐增多，第 $8$ 个月已近似成年。
- [ ] 神经胶质细胞出现较晚，胚胎第 $12$ 周左右开始出现，属于星形胶质细胞。
- [ ] 胚胎第 $3$ 个月初，交感神经的分支长入松果体。
- [ ] 肾上腺皮质来源于脏壁中胚层，髓质来源于神经嵴。
- [ ] 人胚第 $3\sim 4$ 周，肠系膜根部与发育中的生殖嵴之间的中胚层表面上皮增生，并移向深部的间充质。
- [ ] 人胚第 $5$ 周分化为肾上腺的胎儿皮质。
- [ ] 第 $7$ 周表面上皮细胞第二次增生并进入间充质，围绕在胎儿皮质周围，成为永久皮质。
- [ ] 胎儿皮质在出生后很快退化。
- [ ] 永久皮质在胎儿后期开始分化，出生时可见球状带和束状带，到 $3$ 岁时才出现网状带。
- [ ] 约第 $6$ 周，神经嵴细胞迁移并进入胎儿皮质内侧。
- [ ] 与肾上腺皮质接触的细胞分化成髓质的嗜铬细胞，其余少量细胞分化成交感神经节细胞。
- [ ] 最初髓质细胞混杂在皮质之间，以后逐渐向中心迁移，第 $20$ 周左右多数髓质细胞迁移至肾上腺中轴。
- [ ] 出生后 $12\sim 18$ 月龄时，髓质发育完善。
