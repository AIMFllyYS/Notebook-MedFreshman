# 二、输尿管

输尿管（ureter）为排尿器官，其管壁分 3 层，由内向外为黏膜、肌层和外膜。黏膜由变移上皮和固有层的结缔组织构成。黏膜形成许多纵行皱襞，故管腔呈星形。黏膜的变移上皮较厚，有 $4\sim 5$ 层细胞，扩张时可变为 $2\sim 3$ 层。输尿管上 $2/3$ 段的肌层为内纵行、外环行两层平滑肌；下 $1/3$ 段肌层增厚，为内纵行、中环行和外纵行 3 层平滑肌。外膜为疏松结缔组织（图 17-16）。

:::definition{label="输尿管"}
输尿管（ureter）是排尿器官。管壁由内向外分黏膜、肌层和外膜 3 层。它把肾形成的终尿送向膀胱，本身不产尿。
:::

:::concept{term="先认星形管腔和变移上皮，再数肌层是两层还是三层"}
看见输尿管切片，先找黏膜纵行皱襞围成的星形管腔，上皮是变移上皮而不是复层扁平。再问切的是上段还是下段：上 $2/3$ 只有内纵、外环两层平滑肌，下 $1/3$ 才增厚为内纵、中环、外纵三层。把输尿管听成“消化管四层”或“全程三层肌”，皱襞、上皮和肌层会一起错位。
:::

:::definition{label="输尿管黏膜"}
黏膜由变移上皮和固有层的结缔组织构成。黏膜形成许多纵行皱襞，故管腔呈星形。
:::

:::definition{label="输尿管变移上皮"}
黏膜的变移上皮较厚，有 $4\sim 5$ 层细胞，扩张时可变为 $2\sim 3$ 层。细胞形状和层数随管腔空虚或扩张而改变，不是固定层数的复层扁平上皮。
:::

:::definition{label="输尿管肌层"}
上 $2/3$ 段肌层为内纵行、外环行两层平滑肌；下 $1/3$ 段肌层增厚，为内纵行、中环行和外纵行 3 层平滑肌。
:::

:::definition{label="输尿管外膜"}
外膜为疏松结缔组织。不是浆膜，也没有软骨支架。
:::

:::compare{title="输尿管与消化管管壁"}
| 项目 | 输尿管 | 消化管（除口腔与咽外） |
|------|--------|--------------------------|
| 层次 | 黏膜、肌层、外膜 3 层 | 黏膜、黏膜下层、肌层、外膜 4 层 |
| 上皮 | 变移上皮 | 多为单层柱状或复层扁平 |
| 黏膜肌层 | 无 | 有 |
| 管腔形态 | 纵行皱襞，横切呈星形 | 不以星形为特征 |
:::

:::pitfall{label="输尿管变移上皮不是复层扁平"}
变移上皮的层数和细胞形态随扩张改变：空虚时 $4\sim 5$ 层，扩张时 $2\sim 3$ 层。复层扁平上皮的层数不随管腔充盈这样折叠减少，表层也不形成变移上皮那种盖细胞。写成交接部的复层扁平，排尿管道的伸缩账就做成了皮肤或食管。
:::

:::pitfall{label="不要把输尿管上2/3 也写成内纵中环外纵三层肌"}
三层肌只在下 $1/3$ 段出现。上 $2/3$ 是内纵、外环两层，而且环行在外、纵行在内，和消化管常见的内环外纵正好对调。套错模板，上段切片会数出一层并不存在的外纵肌。
:::

:::insight{label="星形管腔是皱襞留下的余地，变移上皮是给扩张用的"}
纵行皱襞使空虚时管腔呈星形；尿液经过时皱襞展平，上皮从 $4\sim 5$ 层变成 $2\sim 3$ 层。肌层上段两层、下段三层，是把尿液分段推向膀胱。把输尿管听成“一根不会变的硬管”，星形腔和变移上皮会失去功能对应。
:::

:::note{label="输尿管在排尿通路中的位置"}
终尿经乳头管 → 肾小盏 → 肾大盏 → 肾盂 → 输尿管 → 膀胱 → 尿道。输尿管以上的肾盏、肾盂同样衬变移上皮，但管壁分层以本节的黏膜、肌层、外膜为观察模板。
:::

:::keypoint{label="输尿管三层壁、星形腔、变移上皮，肌层按上2/3 与下1/3 分开记"}
- 排尿器官，不产尿；管壁黏膜、肌层、外膜 3 层。
- 黏膜：变移上皮 + 固有层；纵行皱襞，管腔呈星形。
- 变移上皮 $4\sim 5$ 层，扩张时 $2\sim 3$ 层；不是复层扁平。
- 上 $2/3$：内纵、外环两层平滑肌；下 $1/3$：内纵、中环、外纵三层。
- 外膜为疏松结缔组织。
:::
