# 一、疏松结缔组织

结缔组织（connective tissue）由细胞和细胞外基质构成。细胞外基质包括结缔组织细胞分泌产生的呈丝状的纤维和无定形基质，以及不断循环更新的组织液。细胞散在分布于细胞外基质内，无极性。结缔组织分布广泛，形态多样，包括固有结缔组织（即疏松结缔组织、致密结缔组织、脂肪组织和网状组织）和其他特殊类型的结缔组织，如血液、淋巴液、软骨组织和骨组织等。结缔组织具有连接、支持、保护、贮存营养、物质运输等多种功能。本章先把固有结缔组织四型摊开；血液、软骨和骨另立专章。

:::definition{label="结缔组织"}
结缔组织（connective tissue）由细胞和细胞外基质构成。细胞散在分布于细胞外基质内，无极性。细胞外基质包括细胞分泌产生的纤维、无定形基质，以及不断循环更新的组织液。
:::

:::definition{label="细胞外基质"}
细胞外基质（extracellular matrix）在结缔组织中包括：呈丝状的纤维、无定形基质，以及不断循环更新的组织液。纤维和基质由结缔组织细胞分泌产生。
:::

:::concept{term="先问极性：上皮有，结缔组织没有"}
上一章的上皮细胞有游离面、基底面和侧面，层次账靠极性立住。结缔组织把细胞拆进基质里：细胞散在、没有游离面与基底面的对立，营养和信息走纤维、基质和组织液。看见一张切片，先问细胞是不是铺成一层、有没有基膜；若细胞嵌在纤维和基质中，这一层就是结缔组织。把结缔组织听成“少细胞的上皮”，会把极性账做丢。
:::

:::pitfall{label="结缔组织细胞无极性，不要按上皮的三面来记"}
上皮细胞有明显极性，基底面借基膜与结缔组织相连。结缔组织细胞散在分布于细胞外基质内，无极性，也没有统一朝向的游离面。切片上核偏位、突起伸向纤维，是功能状态和附着关系，不是上皮那种顶–底分化。
:::

结缔组织由胚胎时期的间充质（mesenchyme）演化而来。间充质主要源自中胚层，由间充质细胞和无定形基质构成，不含纤维。成体结缔组织内仍保留少量未分化间充质细胞。

:::definition{label="间充质"}
间充质（mesenchyme）是胚胎时期的幼稚结缔组织，主要源自中胚层，由间充质细胞和无定形基质构成，不含纤维。结缔组织由间充质演化而来。
:::

:::definition{label="间充质细胞"}
间充质细胞（mesenchymal cell）胞体大，呈星状，细胞间以突起互连成网；核大，呈卵圆形，核仁明显；细胞质呈弱嗜碱性（图 3-1）。分化程度低，增殖分化能力强：胚胎时期能分化形成多种结缔组织细胞、肌细胞、血细胞、血管内皮细胞等。
:::

::figure{src="/images/histology/textbook/p0043_02.png" caption="图3-1 间充质细胞立体模式图。星状细胞以突起互连成网，核大、卵圆、核仁明显，胞质弱嗜碱性。" alt="星状间充质细胞以突起互连成网的立体模式图"}

疏松结缔组织（loose connective tissue）又称蜂窝组织（areolar tissue），广泛分布于器官之间和组织之间。其特点是细胞种类较多，纤维数量较少，排列稀疏，富含血管及神经（末梢），具有连接、支持、防御和修复等功能。固有结缔组织的其余三型（致密结缔组织、脂肪组织、网状组织）都从这一型的细胞–纤维–基质账上改写密度或细胞组成。

:::definition{label="疏松结缔组织"}
疏松结缔组织（loose connective tissue）又称蜂窝组织（areolar tissue），广泛分布于器官之间和组织之间。细胞种类较多，纤维数量较少、排列稀疏，富含血管及神经末梢，具有连接、支持、防御和修复等功能。
:::

## （一）细胞

疏松结缔组织内有未分化间充质细胞、成纤维细胞、脂肪细胞、巨噬细胞、浆细胞、肥大细胞和白细胞等。其中前三者为结缔组织内固有的细胞，其余源自血液或淋巴组织，因此称为游走细胞。各类细胞的分布和数量随其所在部位和功能状态的不同而不同（图 3-2，图 3-3）。

:::definition{label="固有细胞"}
固有细胞是结缔组织内固有的细胞，包括未分化间充质细胞、成纤维细胞和脂肪细胞。未分化间充质细胞可进一步分化为成纤维细胞和脂肪细胞等。
:::

:::definition{label="游走细胞"}
游走细胞源自血液或淋巴组织，进入结缔组织后行使防御等功能，包括巨噬细胞、浆细胞、肥大细胞和白细胞等。其数量随部位和功能状态而变。
:::

:::compare{title="固有细胞与游走细胞"}
| 项目 | 固有细胞 | 游走细胞 |
|------|----------|----------|
| 来源 | 结缔组织内固有；未分化间充质细胞及其分化产物 | 源自血液或淋巴组织，迁入结缔组织 |
| 成员 | 未分化间充质细胞、成纤维细胞、脂肪细胞 | 巨噬细胞、浆细胞、肥大细胞、白细胞 |
| 主要职分 | 产生和维持细胞外基质；贮存脂肪；保留干细胞潜能 | 吞噬、抗原呈递、分泌抗体、启动炎症和过敏反应 |
| 数量特点 | 相对稳定，成纤维细胞通常最多 | 随部位和功能状态明显波动；一般结缔组织内浆细胞很少 |
| 易混点 | 纤维细胞是静止的成纤维细胞，仍属固有细胞 | 组织细胞是静止的巨噬细胞，仍属游走细胞系统 |
:::

### 1. 成纤维细胞

成纤维细胞（fibroblast）是疏松结缔组织中数目最多、最主要的细胞，常附着在胶原纤维上。功能活跃时，细胞较大，多突起；细胞核大，卵圆形，着色浅，核仁明显；细胞质较丰富，呈弱嗜碱性。电镜下，它具有蛋白质分泌细胞的超微结构特征，即含丰富的粗面内质网和发达的高尔基复合体（图 3-4）。由于所合成的蛋白质以芽生的方式形成许多小囊泡，通过胞吐持续地分泌到细胞外，故细胞质中无明显的分泌颗粒，因而称其为持续型蛋白质分泌细胞，包括后述的浆细胞、成骨细胞等。

成纤维细胞合成、分泌胶原蛋白和弹性蛋白，并形成无定形基质。Ⅰ型胶原蛋白构成胶原（原）纤维，Ⅲ型胶原蛋白构成网状纤维，而弹性蛋白构成弹性纤维。此外，该细胞还可分泌多种生长因子，调节各种细胞的增殖与功能。

:::definition{label="成纤维细胞"}
成纤维细胞（fibroblast）是疏松结缔组织中数目最多、最主要的细胞，常附着在胶原纤维上。功能活跃时细胞较大、多突起；核大、卵圆、着色浅、核仁明显；胞质较丰富，呈弱嗜碱性。电镜下粗面内质网丰富、高尔基复合体发达。它合成并分泌胶原蛋白、弹性蛋白和无定形基质，还可分泌多种生长因子。
:::

:::definition{label="持续型蛋白质分泌细胞"}
持续型蛋白质分泌细胞以芽生方式形成许多小囊泡，经胞吐持续把蛋白质分泌到细胞外，故细胞质中无明显的分泌颗粒。成纤维细胞、浆细胞、成骨细胞等均属此类。这与腺细胞那种调节型、胞质内堆积分泌颗粒的方式不同。
:::

成纤维细胞功能处于静止状态时，称纤维细胞（fibrocyte）。细胞较小，呈长梭形；细胞核小而细长，着色深；细胞质少，呈嗜酸性。电镜下，细胞质内粗面内质网少，高尔基复合体不发达。在创伤等情况下，纤维细胞可逆向分化为成纤维细胞，并分裂、增殖，向受损部位迁移，产生细胞外基质，形成瘢痕组织，参与创伤修复。

:::definition{label="纤维细胞"}
纤维细胞（fibrocyte）是功能处于静止状态的成纤维细胞。细胞较小，呈长梭形；核小而细长，着色深；胞质少，呈嗜酸性。电镜下粗面内质网少，高尔基复合体不发达。创伤时可逆向分化为成纤维细胞，分裂增殖并迁移，产生细胞外基质，形成瘢痕组织。
:::

:::compare{title="成纤维细胞与纤维细胞"}
| 项目 | 成纤维细胞（fibroblast） | 纤维细胞（fibrocyte） |
|------|--------------------------|------------------------|
| 功能状态 | 活跃，合成并分泌纤维和基质 | 静止 |
| 光镜形态 | 较大，多突起 | 较小，长梭形 |
| 细胞核 | 大，卵圆形，着色浅，核仁明显 | 小而细长，着色深 |
| 细胞质 | 较丰富，弱嗜碱性 | 少，嗜酸性 |
| 超微结构 | 粗面内质网丰富，高尔基复合体发达 | 粗面内质网少，高尔基复合体不发达 |
| 分泌颗粒 | 无（持续型蛋白质分泌） | 无明显分泌活动 |
| 互变 | 可进入静止而成为纤维细胞 | 创伤时可逆向分化为成纤维细胞 |
:::

:::pitfall{label="纤维细胞不是终末细胞，可逆分化回成纤维细胞"}
纤维细胞只是成纤维细胞的静止表型，不是另一种来源、也不能当成“老化后不可逆”的终末细胞。创伤等情况下它可逆向分化为成纤维细胞，再分裂、增殖、迁移并产生基质。把两者记成不可互变的两种细胞，会把修复账做死。
:::

:::insight{label="成纤维细胞与创伤修复"}
成纤维细胞是机体创伤修复过程中最主要的功能细胞。当创伤发生时，其修复依赖于成纤维细胞与其分泌合成的细胞外基质之间的相互作用。一方面，成纤维细胞增殖，合成并分泌大量细胞外基质以填补组织间缺损；另一方面，细胞外基质起着支架和连接作用，调节成纤维细胞的迁移、分化和增殖，以及局部生长因子的聚集和释放，增强成纤维细胞的生物学效应。

创伤修复过程涉及伤口收缩、肉芽形成、基质合成、伤口修复、瘢痕形成及无瘢痕愈合等。扁平、多突起的成纤维细胞在创伤修复过程中将发生不同的表型变化，即静止、迁移、合成及收缩四种表型，功能也随之发生变化。创伤发生 $2\sim 3$ 天后，成纤维细胞由静止表型向迁移表型转换，逐渐向创伤中心迁移，同时迅速增殖，成为合成表型，细胞内含有丰富的粗面内质网和高尔基体，大量合成胶原，填补于组织之间。在伤后 $10\sim 14$ 天，成纤维细胞在多种细胞因子诱导作用下，转换为收缩表型，即肌成纤维细胞，兼有平滑肌细胞特点，收缩时可引起整个创伤组织的收缩，使伤口发生收缩，同时产生胶原酶，分解残存与新合成的胶原蛋白，使胶原纤维的沉积和分解形成动态平衡。创面愈合期，肌成纤维细胞凋亡，胶原酶活性逐渐降低，胶原纤维沉积于创面，创伤得以修复。而在某些细胞因子的作用下，成纤维细胞过度增殖和分泌，导致细胞外基质的异常沉积，则可形成病理性瘢痕。
:::

### 2. 巨噬细胞

巨噬细胞（macrophage）是体内广泛存在的一种免疫细胞，来源于血液中的单核细胞。巨噬细胞形态多样，随功能状态而改变。功能活跃者，常伸出较长的伪足而形态不规则。细胞核较小，呈圆形或肾形，着色深。细胞质丰富，多呈嗜酸性，可含有异物颗粒和空泡（图 3-2，图 3-3）。电镜下，细胞表面有许多皱褶、微绒毛和少数球形隆起。细胞质内含大量溶酶体、吞噬体、吞饮泡和残余体，以及数量不等的粗面内质网、高尔基复合体和线粒体。细胞膜内侧和伪足内有较多微丝和微管，参与细胞运动和吞噬（图 3-5）。

:::definition{label="巨噬细胞"}
巨噬细胞（macrophage）来源于血液中的单核细胞，是体内广泛存在的免疫细胞。功能活跃者常伸出较长伪足而形态不规则；核较小，圆形或肾形，着色深；胞质丰富，多呈嗜酸性，可含异物颗粒和空泡。电镜下表面有皱褶、微绒毛和少数球形隆起，胞质内溶酶体、吞噬体、吞饮泡和残余体丰富，膜内侧和伪足内微丝、微管较多。
:::

::figure{src="/images/histology/textbook/p0044_04.png" caption="图3-5 巨噬细胞超微结构立体模式图。示微绒毛、初级溶酶体、次级溶酶体、吞噬体、残余体和空泡。" alt="巨噬细胞超微结构：表面微绒毛与胞质内溶酶体、吞噬体和残余体"}

疏松结缔组织内处于功能静止状态的巨噬细胞称为组织细胞（histocyte）。当受细菌产物、炎症变性蛋白等物质刺激后，细胞伸出伪足，沿这些化学物质的浓度梯度朝浓度高的部位定向移动，聚集到产生和释放这些化学物质的部位，因而被称为游走的活化细胞。细胞的这种特性称趋化性（chemotaxis），而这类化学物质称趋化因子（chemokine）。趋化性是巨噬细胞发挥功能的前提。巨噬细胞行使多种功能，参与免疫应答。

:::definition{label="组织细胞"}
组织细胞（histocyte）是疏松结缔组织内处于功能静止状态的巨噬细胞。受细菌产物、炎症变性蛋白等刺激后伸出伪足，沿趋化因子浓度梯度定向移动，成为游走的活化细胞。
:::

:::pitfall{label="组织细胞就是静止的巨噬细胞，不是另一种组织固有细胞"}
教材把疏松结缔组织内功能静止的巨噬细胞称为组织细胞（histocyte）。它仍来源于单核细胞，属于游走细胞系统，只是暂时停在组织里。不要把它算进“未分化间充质细胞、成纤维细胞、脂肪细胞”那一组固有细胞，也不要另立一种与巨噬细胞无关的“组织细胞”。
:::

:::definition{label="趋化性"}
趋化性（chemotaxis）是细胞沿某些化学物质的浓度梯度、朝浓度高的部位定向移动的特性。对巨噬细胞而言，趋化性是其发挥吞噬、抗原呈递和分泌功能的前提。
:::

:::definition{label="趋化因子"}
趋化因子（chemokine）是能引起趋化性的化学物质，如细菌产物、炎症变性蛋白，以及肥大细胞释放的中性粒细胞趋化因子、嗜酸性粒细胞趋化因子等。
:::

**（1）吞噬作用（phagocytosis）** 可分为特异性吞噬作用和非特异性吞噬作用。特异性吞噬作用的前提是有抗体等识别因子识别和黏附被吞噬物（如细菌、病毒和异体细胞等），然后，巨噬细胞通过其表面的受体与识别因子特异性结合，从而间接黏附被吞噬物，启动吞噬过程。非特异性吞噬作用则无需识别因子的中介，巨噬细胞直接黏附碳粒、粉尘、衰老死亡的自体细胞和某些细菌等，进而吞噬。吞噬较大异物时，多个巨噬细胞常融合形成多核巨细胞（multinuclear giant cell）。巨噬细胞黏附被吞噬物后，伸出伪足将其包围，摄入细胞质内形成吞噬体或吞饮泡。吞噬体或吞饮泡与溶酶体融合，被溶酶体酶分解，可降解产物进入细胞质后再利用，而不可分解的物质构成残余体（图 3-7）。

:::definition{label="吞噬作用"}
吞噬作用（phagocytosis）是巨噬细胞伸出伪足包围被吞噬物、摄入胞质形成吞噬体或吞饮泡，再与溶酶体融合、由溶酶体酶分解的过程。可降解产物进入胞质后再利用，不可分解的物质构成残余体。
:::

:::definition{label="特异性吞噬作用"}
特异性吞噬作用的前提是有抗体等识别因子识别和黏附被吞噬物（如细菌、病毒和异体细胞等）；巨噬细胞通过其表面受体与识别因子特异性结合，从而间接黏附被吞噬物，启动吞噬。
:::

:::definition{label="非特异性吞噬作用"}
非特异性吞噬作用无需识别因子的中介，巨噬细胞直接黏附碳粒、粉尘、衰老死亡的自体细胞和某些细菌等，进而吞噬。
:::

:::definition{label="多核巨细胞"}
多核巨细胞（multinuclear giant cell）由多个巨噬细胞融合形成，见于吞噬较大异物时。
:::

:::definition{label="残余体"}
残余体是吞噬体或吞饮泡与溶酶体融合、酶解之后，不可分解的物质在细胞内存留而形成的结构。
:::

:::compare{title="特异性吞噬与非特异性吞噬"}
| 项目 | 特异性吞噬 | 非特异性吞噬 |
|------|------------|--------------|
| 是否需要识别因子 | 需要抗体等识别因子先识别并黏附被吞噬物 | 无需识别因子中介 |
| 巨噬细胞如何黏附 | 表面受体与识别因子特异性结合，间接黏附 | 直接黏附 |
| 典型对象 | 细菌、病毒、异体细胞等 | 碳粒、粉尘、衰老死亡的自体细胞、某些细菌 |
| 后续过程 | 伪足包围 → 吞噬体/吞饮泡 → 与溶酶体融合 → 酶解 | 同左 |
| 临床相关 | 抗体把抗原“交给”巨噬细胞，与浆细胞分泌的 Ig 相接 | 清除无机颗粒和衰老细胞，不依赖预先免疫 |
:::

::figure{src="/images/histology/textbook/p0045_02.png" caption="图3-7 巨噬细胞特异性吞噬过程示意图。1. 识别因子包裹颗粒；2. 识别与吸附；3. 摄入；4. 吞噬体形成；5. 与溶酶体融合；6. 杀灭与消化，形成残余体。" alt="特异性吞噬六步：识别因子包裹、吸附、摄入、吞噬体形成、与溶酶体融合、消化成残余体"}

**（2）抗原呈递作用** 抗原（antigen）包括蛋白质、多肽、多糖等生物分子。由这些分子构成的细胞、细胞外基质、细菌、病毒等都含有大量抗原。每一个体的免疫系统能够识别自身抗原和外来抗原，主要对外来抗原（如细菌、病毒等）以及表面抗原发生变异的自身细胞（如肿瘤细胞和病毒感染细胞）发动攻击。巨噬细胞吞噬了抗原物质，在溶酶体内进行分解时，能够保留最具特征性的分子基团，与巨噬细胞自身的主要组织相容性复合体（major histocompatibility complex，MHC）结合，形成抗原肽–MHC 分子复合物，呈递到细胞表面（图 3-8）。当 T 淋巴细胞接触到抗原肽后，便被激活，启动免疫应答机制。因此，巨噬细胞为机体主要的抗原呈递细胞（antigen presenting cell，APC）。

:::definition{label="抗原"}
抗原（antigen）包括蛋白质、多肽、多糖等生物分子。由这些分子构成的细胞、细胞外基质、细菌、病毒等都含有大量抗原。免疫系统能识别自身抗原和外来抗原，主要攻击外来抗原以及表面抗原发生变异的自身细胞（如肿瘤细胞和病毒感染细胞）。
:::

:::definition{label="主要组织相容性复合体"}
主要组织相容性复合体（major histocompatibility complex，MHC）是巨噬细胞等抗原呈递细胞自身的分子。抗原在溶酶体内分解时，最具特征性的分子基团与 MHC 结合，形成抗原肽–MHC 分子复合物，呈递到细胞表面，供 T 淋巴细胞识别。
:::

:::definition{label="抗原呈递细胞"}
抗原呈递细胞（antigen presenting cell，APC）能把抗原肽–MHC 分子复合物呈递到细胞表面、激活 T 淋巴细胞并启动免疫应答。巨噬细胞是机体主要的抗原呈递细胞。
:::

:::concept{term="APC 先问：吞进去的抗原有没有被做成抗原肽–MHC"}
吞噬只回答“清不掉”；抗原呈递回答“T 细胞看不看得见”。巨噬细胞在溶酶体内分解抗原时并不把分子全部拆光，而是留下最具特征性的基团，装上自身的 MHC，端到膜上。没有这一步，T 淋巴细胞接触不到抗原肽，免疫应答启动不了。把巨噬细胞只记成“吃细菌的细胞”，会把 APC 账做丢。
:::

::figure{src="/images/histology/textbook/p0045_03.png" caption="图3-8 巨噬细胞处理抗原过程示意图。外来抗原经内吞进入内吞泡，与溶酶体结合后，抗原肽与 MHC-Ⅱ 类分子结合，重新表达于细胞膜表面。" alt="巨噬细胞抗原处理：内吞、溶酶体加工、抗原肽与MHC-II结合并呈递到细胞表面"}

**（3）分泌功能** 巨噬细胞有活跃的分泌功能，能合成和分泌上百种生物活性物质，包括溶菌酶、补体、多种细胞因子（如白细胞介素-1）等。溶菌酶分解细菌的细胞壁，以杀灭细菌。补体参与炎症反应、对病原微生物的溶解等过程。白细胞介素-1 刺激骨髓中白细胞增殖并释放入血。

:::note{label="巨噬细胞的三项功能"}
| 功能 | 要点 |
|------|------|
| 吞噬作用 | 分特异性和非特异性；大异物时常融合为多核巨细胞；酶解后可利用者入胞质，不能分解者成残余体 |
| 抗原呈递 | 保留特征性基团，与 MHC 形成抗原肽–MHC 复合物呈递到膜上，激活 T 淋巴细胞；巨噬细胞是主要 APC |
| 分泌功能 | 溶菌酶（分解细菌细胞壁）、补体（炎症与溶菌）、白细胞介素-1（刺激骨髓白细胞增殖并入血）等上百种活性物质 |
:::

### 3. 浆细胞

浆细胞（plasma cell）又称效应 B 细胞，主要分布于脾、淋巴结以及消化管、呼吸道等黏膜的结缔组织或淋巴组织内及慢性炎症部位，而在一般结缔组织内很少。浆细胞呈卵圆形或圆形；细胞核呈圆形或卵圆形，多偏于一侧，异染色质常呈粗条块状，从核中心向核膜呈辐射状分布。细胞质丰富，呈嗜碱性，细胞核旁有一浅染区（图 3-9）。电镜下，细胞质内几乎充满呈环行平行排列的粗面内质网，细胞核旁浅染区内有发达的高尔基复合体。浆细胞合成并分泌免疫球蛋白（immunoglobulin，Ig），即抗体（antibody）。抗体的一端与抗原高度特异性结合，即一种抗体只能和一种特定的抗原结合，形成抗原–抗体复合物。抗体的另一端与吞噬细胞（如巨噬细胞）上的受体结合，从而使抗原–抗体复合物被吞噬和杀灭。

:::definition{label="浆细胞"}
浆细胞（plasma cell）又称效应 B 细胞，主要分布于脾、淋巴结以及消化管、呼吸道等黏膜的结缔组织或淋巴组织内及慢性炎症部位，一般结缔组织内很少。细胞呈卵圆形或圆形；核圆或卵圆，多偏于一侧，异染色质呈粗条块状、从核中心向核膜辐射状分布；胞质丰富、嗜碱性，核旁有一浅染区。电镜下胞质几乎充满环行平行排列的粗面内质网，核旁浅染区为发达的高尔基复合体。功能是合成并分泌免疫球蛋白（抗体）。
:::

:::definition{label="抗体"}
抗体（antibody）即免疫球蛋白（immunoglobulin，Ig），由浆细胞合成并分泌。一端与抗原高度特异性结合（一种抗体只能结合一种特定抗原），形成抗原–抗体复合物；另一端与吞噬细胞（如巨噬细胞）上的受体结合，使该复合物被吞噬和杀灭。这正是巨噬细胞特异性吞噬所依赖的识别因子来源之一。
:::

:::pitfall{label="浆细胞就是效应 B 细胞，不要另立一种“专门造抗体的结缔组织固有细胞”"}
浆细胞是 B 淋巴细胞受抗原刺激后分化而来的效应细胞，属于游走细胞，不是成纤维细胞那一类固有细胞。一般结缔组织内很少见到，大量出现提示局部慢性炎症或黏膜淋巴组织。核偏位、核旁浅染、胞质嗜碱性，对应的是环行粗面内质网加高尔基复合体，不是脂肪空泡。
:::

### 4. 肥大细胞

肥大细胞（mast cell）源自骨髓的造血祖细胞，经血液循环迁移到全身的结缔组织内，分化成熟后可生存数月。细胞较大，圆形或卵圆形；细胞核小而圆，居中；细胞质内充满粗大的嗜碱性分泌颗粒，可被醛复红染为紫色（见图 3-3）。肥大细胞常沿小血管和淋巴管分布，在皮肤真皮、呼吸道和消化管的黏膜结缔组织内较多。这种分布使其成为免疫系统中首先与侵入体内的病原体接触的“哨兵”，它们通过释放多种活性物质，启动针对病原体的炎症反应：组胺和白三烯可使局部毛细血管和微静脉扩张，通透性增强，组织液渗出增多，导致局部红肿；中性粒细胞趋化因子和嗜酸性粒细胞趋化因子可分别促使这两种血细胞迁入结缔组织内，中性粒细胞可吞噬细菌，嗜酸性粒细胞可吞噬抗原–抗体复合物，并有杀菌作用。此外，肥大细胞分泌的肝素具有抗凝血作用。

:::definition{label="肥大细胞"}
肥大细胞（mast cell）源自骨髓造血祖细胞，经血循环迁入结缔组织，分化成熟后可生存数月。细胞较大，圆形或卵圆形；核小而圆、居中；胞质充满粗大嗜碱性分泌颗粒，醛复红染成紫色。常沿小血管和淋巴管分布，皮肤真皮、呼吸道和消化管黏膜结缔组织内较多，是首先接触病原体的“哨兵”。
:::

:::note{label="肥大细胞释放的活性物质"}
| 物质 | 主要作用 |
|------|----------|
| 组胺、白三烯 | 局部毛细血管和微静脉扩张、通透性增强，组织液渗出增多，局部红肿；过敏时还可致荨麻疹、哮喘、休克 |
| 中性粒细胞趋化因子 | 促使中性粒细胞迁入结缔组织，吞噬细菌 |
| 嗜酸性粒细胞趋化因子 | 促使嗜酸性粒细胞迁入；吞噬抗原–抗体复合物并杀菌；过敏反应部位发挥抗过敏反应作用 |
| 肝素 | 抗凝血 |
:::

由于尚未阐明的原因，少数人的免疫系统对某些对机体无害的花粉、药物（如青霉素）等物质发生免疫应答。当机体第二次接触这些物质（抗原）时，肥大细胞会受到刺激，以胞吐的方式大量释放颗粒内容物，称为脱颗粒。组胺、白三烯可使皮肤的微静脉和毛细血管扩张，形成数量不等的红肿块，称荨麻疹；可使肺内细支气管平滑肌痉挛，黏液分泌增多，导致哮喘；可使全身小动脉扩张，导致血压急剧下降，引起休克。这些病症统称过敏反应，凡可致肥大细胞脱颗粒的物质称为过敏原，即引发过敏反应的抗原。肥大细胞释放的嗜酸性粒细胞趋化因子可趋化嗜酸性粒细胞向过敏反应部位迁移，发挥抗过敏反应作用（图 3-11）。

:::definition{label="脱颗粒"}
脱颗粒是肥大细胞以胞吐方式大量释放颗粒内容物的过程。机体第二次接触过敏原时，肥大细胞表面结合的 IgE 交联，触发脱颗粒。
:::

:::definition{label="过敏原"}
过敏原是可致肥大细胞脱颗粒、从而引发过敏反应的抗原，如某些花粉、药物（如青霉素）等。这些物质对多数人无害，但少数人的免疫系统对其发生免疫应答。
:::

:::cause-effect{title="肥大细胞脱颗粒如何写成荨麻疹、哮喘和休克"}
- 因：过敏原再次进入，与肥大细胞表面 IgE 结合，细胞脱颗粒，释放组胺和白三烯
- 果（皮肤）：微静脉和毛细血管扩张 → 数量不等的红肿块 → 荨麻疹
- 果（肺）：细支气管平滑肌痉挛、黏液分泌增多 → 哮喘
- 果（全身）：小动脉扩张，血压急剧下降 → 休克
- 制约：同时释放的嗜酸性粒细胞趋化因子把嗜酸性粒细胞召到局部，发挥抗过敏反应作用
:::

### 5. 脂肪细胞

脂肪细胞（adipocyte，fat cell）单个或成群存在。胞体大，直径 $50\sim 100\,\mu\mathrm{m}$，常呈球形或多边形；细胞质内含一个大脂滴，将其余细胞质和细胞核挤到细胞周缘，细胞核被挤压成弯月形，位于细胞一侧。在 HE 染色的标本中，脂滴被溶解，细胞呈空泡状。脂肪细胞能合成、储存脂肪，参与脂类代谢。大量群集时构成脂肪组织，详见第三节。

:::definition{label="脂肪细胞"}
脂肪细胞（adipocyte，fat cell）单个或成群存在。胞体大，直径 $50\sim 100\,\mu\mathrm{m}$，常呈球形或多边形；胞质内含一个大脂滴，把其余胞质和核挤到周缘，核呈弯月形、位于一侧。HE 标本中脂滴被溶解，细胞呈空泡状。功能是合成、储存脂肪，参与脂类代谢。
:::

:::pitfall{label="HE 里看见的“空泡”不是空的脂肪细胞，是脂滴被溶掉了"}
制片过程把脂滴溶掉，光镜下只留下空泡状轮廓和被挤到一侧的弯月形核。不要把这种空泡当成水肿或巨噬细胞吞饮泡；苏丹类脂溶性染料才能把脂滴本身显色。黄色脂肪组织的单泡脂肪细胞就是这一型，棕色脂肪组织的多泡脂肪细胞则是许多大小不等的脂滴，核居中。
:::

### 6. 未分化间充质细胞

未分化间充质细胞（undifferentiated mesenchymal cell）是成体结缔组织内的干细胞，分布广泛，多分布在小血管周围，其形态似纤维细胞。该细胞保留着间充质细胞的多向分化潜能，在炎症及创伤修复时大量增殖，可分化为成纤维细胞、血管内皮细胞、平滑肌细胞等，参与结缔组织和小血管的修复。

:::definition{label="未分化间充质细胞"}
未分化间充质细胞（undifferentiated mesenchymal cell）是成体结缔组织内的干细胞，多分布在小血管周围，形态似纤维细胞，保留间充质细胞的多向分化潜能。炎症及创伤修复时大量增殖，可分化为成纤维细胞、血管内皮细胞、平滑肌细胞等，参与结缔组织和小血管的修复。
:::

:::concept{term="小血管周围那颗“像纤维细胞”的细胞，先问是不是干细胞"}
成体里仍留着少量未分化间充质细胞，形态酷似纤维细胞，但职分不同：纤维细胞是静止的成纤维细胞，这颗是还能改写成内皮、平滑肌和成纤维细胞的干细胞。炎症和创伤时它大量增殖，把结缔组织和小血管补上。切片上不能单靠梭形核把两者画等号。
:::

### 7. 白细胞

血液内的各种白细胞（leukocyte，white blood cell）常以变形运动的方式穿出毛细血管和微静脉，游走到疏松结缔组织内，行使免疫防御功能。中性粒细胞、嗜酸性粒细胞等也可因肥大细胞释放的趋化因子而迁入。它们在结缔组织内的数量随功能状态而变，是游走细胞的组成部分。

:::definition{label="白细胞（结缔组织内）"}
血液内的各种白细胞（leukocyte，white blood cell）常以变形运动穿出毛细血管和微静脉，游走到疏松结缔组织内，行使免疫防御功能。
:::

## （二）纤维

疏松结缔组织的纤维有三种：胶原纤维、弹性纤维和网状纤维。三者都由成纤维细胞（网状纤维也可由网状细胞）产生的蛋白质在细胞外组装而成，再被基质黏结或被覆。数量、染色、抗张和弹性各不相同，常交织在一起，使组织既保持形态、又有一定可变性。

### 1. 胶原纤维

在 3 种纤维中，胶原纤维（collagenous fiber）数量最多。因新鲜标本呈白色，故又称白纤维。HE 染色切片中胶原纤维呈嗜酸性，直径 $0.5\sim 20\,\mu\mathrm{m}$，呈波浪形，有分支并交织成网（见图 3-3）。胶原纤维常成束存在。胶原纤维的生化成分为Ⅰ型胶原蛋白。胶原蛋白由成纤维细胞合成分泌，于细胞外聚合为胶原原纤维（collagen fibril），再经少量黏合质（蛋白多糖和糖蛋白，故 PAS 反应阳性）黏结成胶原纤维。电镜下，胶原原纤维直径 $20\sim 200\,\mathrm{nm}$，呈明暗交替的周期性横纹，横纹周期约 $64\,\mathrm{nm}$。胶原纤维的韧性大，抗拉力强。

:::definition{label="胶原纤维"}
胶原纤维（collagenous fiber）是三种纤维中数量最多者。新鲜标本呈白色，又称白纤维。HE 切片中呈嗜酸性，直径 $0.5\sim 20\,\mu\mathrm{m}$，波浪形，有分支并交织成网，常成束。生化成分为Ⅰ型胶原蛋白。韧性大，抗拉力强。
:::

:::definition{label="胶原原纤维"}
胶原原纤维（collagen fibril）由成纤维细胞分泌的胶原蛋白在细胞外聚合而成，再经少量黏合质（蛋白多糖和糖蛋白，PAS 反应阳性）黏结成胶原纤维。电镜下直径 $20\sim 200\,\mathrm{nm}$，呈明暗交替的周期性横纹，横纹周期约 $64\,\mathrm{nm}$。
:::

### 2. 弹性纤维

弹性纤维（elastic fiber）含量较胶原纤维少，但分布很广。因新鲜标本呈黄色，故又称黄纤维。在 HE 染色切片中，弹性纤维着淡红色（醛复红染色将弹性纤维染成紫色），不易与胶原纤维区分。弹性纤维较细，直径 $0.2\sim 1.0\,\mu\mathrm{m}$，表面光滑，末端常卷曲，可有分支，交织成网（见图 3-3）。电镜下，弹性纤维的核心部分电子密度较低，由均质无定形的弹性蛋白（elastin）组成；外周覆盖电子密度较高的微原纤维（microfibril），其直径约 $10\,\mathrm{nm}$，主要由原纤维蛋白（fibrillin）构成，在外周起支架作用。弹性蛋白分子以共价键广泛交联成网，能任意卷曲。在外力牵拉下，卷曲的弹性蛋白分子伸展拉长；除去外力后，又恢复卷曲状态（图 3-13）。强日光照射可使皮肤内的弹性纤维断裂，皮肤因此失去弹性而产生皱纹。

弹性纤维富有弹性，与胶原纤维交织在一起，使疏松结缔组织兼有弹性和韧性，有利于所在器官和组织既可保持形态、位置的相对恒定，又具有一定的可变性。

:::definition{label="弹性纤维"}
弹性纤维（elastic fiber）含量较胶原纤维少而分布广。新鲜标本呈黄色，又称黄纤维。HE 着淡红色，醛复红染成紫色。较细，直径 $0.2\sim 1.0\,\mu\mathrm{m}$，表面光滑，末端常卷曲，可有分支并交织成网。核心为低电子密度的均质弹性蛋白（elastin），外周覆以直径约 $10\,\mathrm{nm}$、主要由原纤维蛋白（fibrillin）构成的高电子密度微原纤维（microfibril）。富有弹性。
:::

:::concept{term="弹性蛋白先问：共价交联的网能不能弹回去"}
弹性蛋白分子以共价键广泛交联成网，能任意卷曲：牵拉时伸展，去力后恢复。微原纤维在外周起支架。胶原纤维提供韧性、弹性纤维提供弹性，二者交织，器官才能既不散架、又能变形。强日光把皮肤弹性纤维拉断，皱纹就是这张网断了的肉眼表现。
:::

::figure{src="/images/histology/textbook/p0048_01.png" caption="图3-13 伸缩状态下弹性蛋白构型示意图。A. 单个分子；B. 多分子聚合体。牵拉时伸展，去力后借共价键交联恢复卷曲。" alt="弹性蛋白单分子与多分子聚合体在卷曲和牵拉伸展之间互变"}

### 3. 网状纤维

网状纤维（reticular fiber）直径 $0.2\sim 1.0\,\mu\mathrm{m}$，分支多，交织成网。网状纤维主要由Ⅲ型胶原蛋白构成，表面被覆糖蛋白（PAS 反应阳性），于 HE 染色切片中与胶原纤维一样呈淡红色，故难以分辨，但于镀银染色切片中呈黑色，故又称嗜银纤维。网状纤维主要存在于网状组织，也分布于基膜的网板、腺泡、毛细血管周围等处。

:::definition{label="网状纤维"}
网状纤维（reticular fiber）直径 $0.2\sim 1.0\,\mu\mathrm{m}$，分支多，交织成网。主要由Ⅲ型胶原蛋白构成，表面被覆糖蛋白（PAS 阳性）。HE 中呈淡红色，与胶原纤维难以分辨；镀银染色呈黑色，故又称嗜银纤维。主要存在于网状组织，也分布于基膜的网板、腺泡、毛细血管周围等处。
:::

:::pitfall{label="网状纤维在 HE 里并不黑，镀银才黑"}
网状纤维表面有糖蛋白，PAS 阳性，但 HE 仍呈淡红色，和胶原纤维叠在一起几乎看不出来。只有镀银染色才把它染成黑色，所以叫嗜银纤维。不要在 HE 切片上“找黑线”来确认网状纤维，也不要把嗜银性当成网状纤维独有的蛋白质种类——它的蛋白主体是Ⅲ型胶原。
:::

## （三）基质

基质（ground substance）是由生物大分子构成的无定形胶状物，无色透明，具有一定黏性，孔隙中充满组织液，填充于结缔组织细胞和纤维之间。其生物大分子主要为蛋白聚糖和纤维粘连蛋白。纤维提供可看见的丝状支架，基质提供可滤过的胶，组织液在孔隙中不断循环更新。

:::definition{label="基质"}
基质（ground substance）是由生物大分子构成的无定形胶状物，无色透明，具有一定黏性，孔隙中充满组织液，填充于结缔组织细胞和纤维之间。主要生物大分子为蛋白聚糖和纤维粘连蛋白。
:::

### 1. 蛋白聚糖

蛋白聚糖（proteoglycan）亦称蛋白多糖，为基质的主要成分，是由糖胺聚糖（占 $80\%\sim 90\%$）与蛋白质以共价键结合而成的聚合体。糖胺聚糖（glycosaminoglycan，GAG），又称氨基聚糖或黏多糖，主要分硫酸化和非硫酸化两种类型。前一类有硫酸软骨素、硫酸角质素、硫酸皮肤素和硫酸乙酰肝素等，分子较小；后一类主要为透明质酸，为曲折盘绕的长链大分子，可长达 $2.5\,\mu\mathrm{m}$，构成蛋白聚糖的主干。

小分子糖胺聚糖犹如试管刷上的鬃毛，与核心蛋白借共价键结合，并以核心蛋白为中心向外呈辐射状排列，形成蛋白聚糖亚单位。后者再通过结合蛋白结合于透明质酸主干，形成蛋白聚糖聚合体（图 3-14）。

大量蛋白聚糖聚合体形成有许多微孔的分子筛，允许水和营养物、代谢产物、激素、气体分子等通过；而大于孔隙的大分子物质、细菌等则被阻挡，使基质成为限制细菌等有害物扩散的防御屏障。溶血性链球菌和癌细胞等因能产生透明质酸酶，破坏基质结构，故得以扩散或转移。

:::definition{label="蛋白聚糖"}
蛋白聚糖（proteoglycan）亦称蛋白多糖，是基质的主要成分，由糖胺聚糖（占 $80\%\sim 90\%$）与蛋白质以共价键结合而成的聚合体。小分子糖胺聚糖与核心蛋白共价结合并辐射状排列，形成蛋白聚糖亚单位；亚单位再经结合蛋白挂到透明质酸主干上，形成蛋白聚糖聚合体。
:::

:::definition{label="糖胺聚糖"}
糖胺聚糖（glycosaminoglycan，GAG）又称氨基聚糖或黏多糖，分硫酸化和非硫酸化两类。硫酸化者有硫酸软骨素、硫酸角质素、硫酸皮肤素和硫酸乙酰肝素等，分子较小；非硫酸化者主要为透明质酸，曲折盘绕，可长达 $2.5\,\mu\mathrm{m}$，构成蛋白聚糖聚合体的主干。
:::

:::concept{term="分子筛先问：孔隙让谁过、把谁挡住"}
蛋白聚糖聚合体在基质里搭出许多微孔：水、营养物、代谢产物、激素、气体分子可以过；大于孔隙的大分子和细菌被挡住。这张筛既是物质交换的通道，也是限制有害物扩散的屏障。筛的梁是透明质酸长链，刷毛是挂在核心蛋白上的小分子 GAG。看见“基质很稀”，先问分子筛还在不在，而不是把它当成空白。
:::

:::pitfall{label="透明质酸酶拆的是分子筛的梁，不是把细胞“消化掉”"}
溶血性链球菌和癌细胞能产生透明质酸酶，水解透明质酸主干，蛋白聚糖聚合体散架，分子筛不再挡细菌和大分子，病原或肿瘤细胞才得以扩散、转移。炎症局部的“蔓延”和肿瘤的“浸润”，有一笔账要记在这张筛上。不要把透明质酸酶理解成直接杀细胞的酶。
:::

::figure{src="/images/histology/textbook/p0048_02.png" caption="图3-14 蛋白聚糖聚合体及分子筛示意图。左：大量聚合体形成微孔分子筛；右：糖胺聚糖挂在核心蛋白上，经结合蛋白连于透明质酸主干。" alt="蛋白聚糖聚合体结构：透明质酸主干、结合蛋白、核心蛋白和糖胺聚糖刷状侧链"}

:::cause-effect{title="分子筛怎样既供营养、又挡细菌"}
- 因：透明质酸长链经结合蛋白挂上许多蛋白聚糖亚单位，聚合体形成微孔
- 果：水和营养物、代谢产物、激素、气体分子可以通过孔隙，完成血液与细胞的物质交换
- 果：大于孔隙的大分子物质、细菌被阻挡，基质成为防御屏障
- 反例：透明质酸酶拆掉主干 → 筛孔崩解 → 溶血性链球菌扩散、癌细胞转移
:::

### 2. 纤维粘连蛋白

纤维粘连蛋白（fibronectin）是结缔组织基质中最主要的粘连性糖蛋白，分子表面具有与多种细胞、胶原蛋白及蛋白聚糖的结合位点，因此是将这 3 种成分有机连接的媒介，形成一个整合的胶原纤维网络结构，从而影响细胞的黏附、迁移或肿瘤转移、胚胎发育、生长和分化等。

:::definition{label="纤维粘连蛋白"}
纤维粘连蛋白（fibronectin）是结缔组织基质中最主要的粘连性糖蛋白。分子表面具有与多种细胞、胶原蛋白及蛋白聚糖的结合位点，把细胞、胶原蛋白和蛋白聚糖有机连接成整合的胶原纤维网络，从而影响细胞的黏附、迁移或肿瘤转移、胚胎发育、生长和分化等。
:::

### 3. 组织液

组织液（tissue fluid）在毛细血管动脉端，溶解有电解质、单糖、气体分子等小分子的水溶液通过毛细血管壁，渗入到基质内，成为组织液。在毛细血管静脉端，组织液的大部分又回到血液中，小部分则进入毛细淋巴管成为淋巴液，最后也回流入血。因此，组织液是动态更新的，有利于血液与组织中的细胞进行物质交换，构成细胞赖以生存的体液环境。当机体电解质和蛋白质代谢发生障碍时，组织液的产生和回流失去平衡，基质中的组织液含量可增多或减少，导致组织水肿或脱水。

:::definition{label="组织液"}
组织液（tissue fluid）是溶解有电解质、单糖、气体分子等小分子的水溶液：在毛细血管动脉端渗入基质，在静脉端大部分回血，小部分进入毛细淋巴管成为淋巴液后再回流入血。它动态更新，是血液与组织细胞物质交换的介质，也是细胞赖以生存的体液环境。
:::

:::cause-effect{title="组织液从动脉端到静脉端、再到淋巴"}
- 因：动脉端血浆中的小分子水溶液经毛细血管壁渗入基质 → 成为组织液
- 因：静脉端大部分组织液回流入血；小部分进入毛细淋巴管成为淋巴液，最后也回血
- 果：组织液不断循环更新，完成血液与细胞的物质交换
- 失衡：电解质和蛋白质代谢障碍 → 产生与回流失去平衡 → 基质中组织液增多（水肿）或减少（脱水）
:::

:::keypoint{label="疏松结缔组织先把细胞、纤维、基质三本账立住"}
- 结缔组织由细胞和细胞外基质构成，细胞散在、无极性；源自间充质；固有结缔组织包括疏松、致密、脂肪和网状四型。
- 疏松结缔组织又称蜂窝组织：细胞种类多，纤维少而稀疏，富含血管神经，司连接、支持、防御和修复。
- 固有细胞：未分化间充质细胞、成纤维细胞、脂肪细胞；游走细胞：巨噬细胞、浆细胞、肥大细胞、白细胞。
- 成纤维细胞是数量最多的细胞，持续分泌Ⅰ型/Ⅲ型胶原蛋白、弹性蛋白和基质；静止时称纤维细胞，创伤可逆分化。
- 巨噬细胞来自单核细胞；静止者称组织细胞；靠趋化性到达病灶；功能为吞噬（特异/非特异）、抗原呈递（APC，MHC）和分泌。
- 浆细胞即效应 B 细胞，分泌 Ig；肥大细胞沿血管分布，脱颗粒释放组胺、白三烯、趋化因子和肝素，介导炎症与过敏。
- 三种纤维：胶原（Ⅰ型，横纹周期约 $64\,\mathrm{nm}$，抗拉）、弹性（弹性蛋白 + 微原纤维，可回弹）、网状（Ⅲ型，镀银才黑）。
- 基质以蛋白聚糖聚合体构成分子筛，纤维粘连蛋白把细胞、胶原和蛋白聚糖连成网络；组织液在孔隙中动态更新。
:::

- [ ] 结缔组织（connective tissue）= 细胞 + 细胞外基质（纤维 + 无定形基质 + 组织液）；细胞散在，无极性。
- [ ] 固有结缔组织：疏松、致密、脂肪、网状；特殊类型包括血液、淋巴液、软骨、骨。功能：连接、支持、保护、贮存营养、物质运输。
- [ ] 间充质（mesenchyme）源自中胚层，由间充质细胞和无定形基质构成，不含纤维；间充质细胞星状、突起成网，可分化为多种结缔组织细胞、肌细胞、血细胞、内皮细胞。
- [ ] 疏松结缔组织（loose connective tissue）又称蜂窝组织（areolar tissue）：细胞种类多，纤维少而稀疏，富含血管及神经末梢。
- [ ] 固有细胞：未分化间充质细胞、成纤维细胞、脂肪细胞；游走细胞：巨噬细胞、浆细胞、肥大细胞、白细胞。
- [ ] 成纤维细胞（fibroblast）：数量最多；活跃时弱嗜碱性、粗面内质网和高尔基复合体发达；持续型蛋白质分泌；产Ⅰ型胶原（胶原纤维）、Ⅲ型胶原（网状纤维）、弹性蛋白（弹性纤维）及基质、生长因子。
- [ ] 纤维细胞（fibrocyte）为静止的成纤维细胞：长梭形、核细长深染、胞质嗜酸性；创伤时可逆向分化，参与瘢痕修复。
- [ ] 创伤修复中成纤维细胞经历静止、迁移、合成、收缩（肌成纤维细胞）四种表型；$2\sim 3$ 天开始迁移，$10\sim 14$ 天转为收缩表型；过度增殖可成病理性瘢痕。
- [ ] 巨噬细胞来源于单核细胞；静止者称组织细胞（histocyte）；趋化性（chemotaxis）沿趋化因子（chemokine）浓度梯度定向移动。
- [ ] 特异性吞噬需抗体等识别因子；非特异性吞噬直接黏附碳粒、粉尘、衰老细胞等；大异物时融合为多核巨细胞（multinuclear giant cell）；不能分解者成残余体。
- [ ] 巨噬细胞是主要 APC：抗原肽与 MHC 形成复合物呈递到膜上，激活 T 淋巴细胞；并分泌溶菌酶、补体、白细胞介素-1 等。
- [ ] 浆细胞（plasma cell）= 效应 B 细胞；核偏位、异染色质辐射状，核旁浅染（高尔基复合体），胞质充满环行粗面内质网；分泌 Ig（抗体）。
- [ ] 肥大细胞（mast cell）沿小血管分布，胞质粗大嗜碱性颗粒（醛复红紫色）；释放组胺、白三烯、中性/嗜酸性粒细胞趋化因子、肝素；脱颗粒导致荨麻疹、哮喘、休克。
- [ ] 脂肪细胞直径 $50\sim 100\,\mu\mathrm{m}$，单泡脂滴把核挤成弯月形；HE 中脂滴溶解呈空泡状。
- [ ] 未分化间充质细胞是成体干细胞，多在小血管周围，形态似纤维细胞，可分化为成纤维细胞、内皮细胞、平滑肌细胞。
- [ ] 胶原纤维：Ⅰ型胶原；直径 $0.5\sim 20\,\mu\mathrm{m}$；原纤维 $20\sim 200\,\mathrm{nm}$，横纹周期约 $64\,\mathrm{nm}$；韧性大、抗拉力强。
- [ ] 弹性纤维：核心弹性蛋白 + 外周约 $10\,\mathrm{nm}$ 微原纤维（fibrillin）；直径 $0.2\sim 1.0\,\mu\mathrm{m}$；醛复红紫色；牵拉可回弹。
- [ ] 网状纤维：Ⅲ型胶原，表面糖蛋白；直径 $0.2\sim 1.0\,\mu\mathrm{m}$；HE 淡红难辨，镀银呈黑色（嗜银纤维）。
- [ ] 蛋白聚糖：GAG 占 $80\%\sim 90\%$；透明质酸（可长达 $2.5\,\mu\mathrm{m}$）为主干，小分子 GAG 挂在核心蛋白上，经结合蛋白连成聚合体，形成分子筛。
- [ ] 透明质酸酶破坏分子筛，溶血性链球菌和癌细胞借此扩散或转移。
- [ ] 纤维粘连蛋白（fibronectin）连接细胞、胶原蛋白和蛋白聚糖。
- [ ] 组织液在毛细血管动脉端渗入、静脉端大部分回血、小部分入毛细淋巴管；失衡导致水肿或脱水。
