# 一、睾丸

男性生殖系统（male reproductive system）由睾丸、生殖管道、附属腺及外生殖器组成。睾丸是产生精子和分泌雄性激素的器官。生殖管道具有促进精子成熟，营养、贮存和运输精子的作用。附属腺包括精囊、尿道球腺和前列腺。附属腺和生殖管道的分泌物参与精液的组成。本章先把睾丸的生精小管、支持细胞、血-睾屏障和间质细胞摊开；生殖管道、附属腺、阴茎各立一节。

:::definition{label="男性生殖系统"}
男性生殖系统（male reproductive system）由睾丸、生殖管道、附属腺及外生殖器组成。睾丸产生精子并分泌雄性激素；生殖管道促进精子成熟，并营养、贮存和运输精子；附属腺和生殖管道的分泌物参与精液组成。
:::

:::definition{label="睾丸"}
睾丸（testis）位于阴囊中，呈略扁椭圆形，是产生精子和分泌雄性激素的器官。
:::

:::concept{term="先问这是产精子和激素的睾丸，还是只负责成熟、贮存和运输的管道"}
看见男性生殖系统，先把两本账切开：生精小管里的精子发生、支持细胞的微环境和间质细胞的睾酮，才是“制造”；附睾、输精管、尿道只是把已经形成的精子养熟、存住、送出；精囊、前列腺、尿道球腺往精液里兑分泌物。把“生殖系统”听成“从睾丸到阴茎都在造精子”，血-睾屏障和前列腺凝固体会并成一句。
:::

:::compare{title="睾丸、生殖管道与附属腺"}
| 项目 | 睾丸 | 生殖管道 | 附属腺 |
|------|------|----------|--------|
| 成员 | 生精小管、直精小管、睾丸网、睾丸间质 | 附睾、输精管及尿道 | 精囊、尿道球腺、前列腺 |
| 职分 | 产生精子；分泌雄性激素 | 促进精子成熟；营养、贮存和运输精子 | 分泌物参与精液组成 |
| 核心细胞 / 结构 | 生精细胞、支持细胞、间质细胞 | 输出小管、附睾管、输精管壁 | 复管泡状腺或盘曲囊状腺 |
| 本章位置 | 第 18-1 节 | 第 18-2 节 | 第 18-3 节 |
:::

:::note{label="外生殖器落在哪一节"}
外生殖器以阴茎为代表，组织学重点是两条阴茎海绵体、一条尿道海绵体、白膜和勃起时的血窦充盈，写在第 18-4 节。精液的数量标准写在附属腺节，因为精液 = 附属腺和生殖管道的分泌物 + 精子。
:::

睾丸表面覆以浆膜，即鞘膜脏层，深部为致密结缔组织构成的白膜（tunica albuginea）。白膜在睾丸后缘增厚形成睾丸纵隔（mediastinum testis）。纵隔的结缔组织呈放射状伸入睾丸实质，将睾丸实质分成约 $250$ 个锥形小叶，每个小叶内有 $1\sim 4$ 条弯曲细长的生精小管。生精小管在接近睾丸纵隔处变为短而直的直精小管，它们进入睾丸纵隔，相互吻合形成睾丸网。生精小管之间的疏松结缔组织称睾丸间质（图 18-1，图 18-2）。

:::definition{label="鞘膜脏层"}
睾丸表面所覆浆膜即鞘膜脏层。它是浆膜，不是白膜；白膜在它的深部。
:::

:::definition{label="白膜"}
白膜（tunica albuginea）是鞘膜脏层深部由致密结缔组织构成的被膜。它在睾丸后缘增厚，改名为睾丸纵隔。
:::

:::definition{label="睾丸纵隔"}
睾丸纵隔（mediastinum testis）是白膜在睾丸后缘增厚形成的结构。其结缔组织呈放射状伸入实质，划分小叶；直精小管在此吻合为睾丸网。
:::

:::definition{label="睾丸小叶"}
纵隔结缔组织把睾丸实质分成约 $250$ 个锥形小叶。每个小叶内有 $1\sim 4$ 条弯曲细长的生精小管。
:::

:::definition{label="睾丸间质"}
生精小管之间的疏松结缔组织称睾丸间质，富含血管和淋巴管，其中有成群的睾丸间质细胞。间质在小管之外，不构成生精上皮。
:::

|------|------|------|----------|
| 鞘膜脏层 | 最表面 | 浆膜 | 白膜 |

鞘膜脏层是浆膜，白膜是它深部的致密结缔组织。生精上皮在小管管壁上，由支持细胞和生精细胞组成。三张皮不要并成“睾丸外面那一层”。
:::

## （一）生精小管

成人的生精小管（seminiferous tubule）长 $30\sim 70\,\mathrm{cm}$，直径 $150\sim 250\,\mu\mathrm{m}$，管壁厚 $60\sim 80\,\mu\mathrm{m}$，由生精上皮（spermatogenic epithelium）构成。生精上皮由支持细胞和 $5\sim 8$ 层生精细胞（spermatogenic cell）组成（图 18-3，图 18-4）。上皮基膜外侧有胶原纤维和梭形的肌样细胞（myoid cell）（图 18-5）。肌样细胞收缩有助于精子排出。

:::definition{label="生精小管"}
生精小管（seminiferous tubule）是睾丸小叶内弯曲细长的管道，成人长 $30\sim 70\,\mathrm{cm}$，直径 $150\sim 250\,\mu\mathrm{m}$，管壁厚 $60\sim 80\,\mu\mathrm{m}$。管壁由生精上皮构成，是精子发生的场所。
:::

:::definition{label="生精上皮"}
生精上皮（spermatogenic epithelium）构成生精小管管壁，由支持细胞和 $5\sim 8$ 层生精细胞组成。它不是普通复层上皮：支持细胞从基膜直达腔面，生精细胞镶嵌在其侧面。
:::

:::definition{label="生精细胞"}
生精细胞（spermatogenic cell）是从精原细胞到精子这一发育谱系的总称。自生精上皮基底部至腔面，依次为精原细胞、初级精母细胞、次级精母细胞、精子细胞和精子。
:::

:::definition{label="肌样细胞"}
肌样细胞（myoid cell）是生精上皮基膜外侧的梭形细胞，与胶原纤维一起包在小管周围。收缩有助于把精子排出生精小管。插入框里调控免疫分子时也称肌上皮细胞，户头仍是这圈小管外周的细胞，不是汗腺那种真正的肌上皮。
:::

:::concept{term="先从基膜数到腔面，再问哪一层还是干细胞、哪一层已经不再分裂"}
切片上先找圆形的生精小管，再沿半径记账：贴基膜的是精原细胞（干细胞在这里）；往腔走是体积最大、核呈丝球状的初级精母细胞；次级精母细胞一闪而过；近腔面是不再分裂、只变态的精子细胞；腔面嵌入支持细胞顶部的是蝌蚪状精子。支持细胞自己从基底一直伸到腔面，轮廓却看不清。把生精上皮听成“几层一样的生精细胞叠在一起”，干细胞、减数分裂和精子形成会并成一次有丝分裂。
:::

### 1. 生精细胞

自生精上皮基底部至腔面，依次有精原细胞、初级精母细胞、次级精母细胞、精子细胞和精子。精原细胞形成精子的过程称精子发生（spermatogenesis），人需要 $(64\pm 4.5)$ 天方可完成。此过程经历了精原细胞增殖、精母细胞减数分裂和精子形成 3 个阶段（图 18-6）。

:::definition{label="精子发生"}
精子发生（spermatogenesis）是精原细胞形成精子的过程，人需要 $(64\pm 4.5)$ 天。它包括 3 个阶段：① 精原细胞增殖；② 精母细胞减数分裂；③ 精子形成。不是一次有丝分裂就能从精原细胞变成精子。
:::

:::note{label="精子发生的三个阶段"}
| 阶段 | 细胞变化 | 分裂与否 |
|------|----------|----------|
| 精原细胞增殖 | A 型干细胞分裂；一部分保持干细胞，一部分成 B 型，B 型再分裂后分化为初级精母细胞 | 有丝分裂 |
| 精母细胞减数分裂 | 初级精母细胞（$4n$ DNA）第一次减数分裂 → 次级精母细胞（$2n$ DNA）；次级不再复制 DNA，第二次减数分裂 → 精子细胞（$1n$ DNA） | 两次减数分裂 |
| 精子形成 | 圆形精子细胞变态为蝌蚪状精子 | 不再分裂 |
:::

:::pitfall{label="精子发生不是一次有丝分裂"}
精子发生要走完三本账：精原细胞的有丝分裂增殖、精母细胞的两次减数分裂、精子细胞的变态（精子形成）。只写“精原细胞分裂成精子”，染色体减半、顶体和鞭毛都没有落点；把三次过程听成一次有丝分裂，核型会从 46，XY 直接跳到蝌蚪，减数分裂那本账会做丢。
:::

#### （1）精原细胞

精原细胞（spermatogonium）紧贴基膜，圆形或卵圆形，直径 $12\,\mu\mathrm{m}$。精原细胞分为 A、B 两型。A 型精原细胞核呈卵圆形，染色质细小、染色深，细胞核中央常见淡染区；或染色质细密、染色浅。A 型精原细胞是生精细胞中的干细胞，不断地分裂增殖，一部分子细胞继续作为干细胞，另一部分分化为 B 型精原细胞。B 型精原细胞核圆形，细胞核周边有较粗的染色质颗粒。B 型精原细胞经过数次分裂后，分化为初级精母细胞。

:::definition{label="精原细胞"}
精原细胞（spermatogonium）紧贴基膜，圆形或卵圆形，直径 $12\,\mu\mathrm{m}$，分为 A、B 两型。它是生精上皮最底层的生精细胞，也是精子发生的起点。
:::

:::definition{label="A型精原细胞"}
A 型精原细胞是生精细胞中的干细胞。核呈卵圆形：或染色质细小、染色深、核中央常见淡染区；或染色质细密、染色浅。不断分裂增殖，一部分子细胞继续作为干细胞，另一部分分化为 B 型精原细胞。
:::

:::definition{label="B型精原细胞"}
B 型精原细胞核圆形，核周边有较粗的染色质颗粒。经过数次分裂后，分化为初级精母细胞。它已经离开干细胞池，但仍在做有丝分裂，还没有进入减数分裂。
:::

:::compare{title="A型与B型精原细胞"}
| 项目 | A 型精原细胞 | B 型精原细胞 |
|------|--------------|--------------|
| 职分 | 干细胞：一部分保持干细胞，一部分分化为 B 型 | 经数次分裂后分化为初级精母细胞 |
| 核形态 | 卵圆形 | 圆形 |
| 染色质 | 细小深染、中央淡染区；或细密浅染 | 周边有较粗的染色质颗粒 |
| 位置 | 紧贴基膜 | 紧贴基膜 |
| 直径 | $12\,\mu\mathrm{m}$ 量级 | $12\,\mu\mathrm{m}$ 量级 |
:::

:::pitfall{label="贴基膜的不都是干细胞，B型已经在通向初级精母细胞"}
A 型才是干细胞。B 型同样贴基膜、直径也约 $12\,\mu\mathrm{m}$，但核圆、周边染色质颗粒粗，经过数次分裂就要变成初级精母细胞。切片上只写“基膜上一圈都是干细胞”，增殖账和减数分裂账会从同一层细胞里算乱。
:::

#### （2）初级精母细胞

初级精母细胞（primary spermatocyte）位于精原细胞近腔侧，圆形，体积较大，直径约 $18\,\mu\mathrm{m}$。细胞核大而圆，呈丝球状，内含或粗或细的染色质丝，核型为 46，XY。初级精母细胞经过 DNA 复制后（$4n$ DNA），进行第一次减数分裂，形成两个次级精母细胞。由于第一次减数分裂的分裂前期历时较长，所以在生精小管的切面中可见到处于不同分裂时期的初级精母细胞。

:::definition{label="初级精母细胞"}
初级精母细胞（primary spermatocyte）位于精原细胞近腔侧，圆形，体积较大，直径约 $18\,\mu\mathrm{m}$。核大而圆，呈丝球状，含或粗或细的染色质丝；核型为 46，XY。DNA 复制后为 $4n$ DNA，进行第一次减数分裂，形成两个次级精母细胞。
:::

:::insight{label="切面上最容易看见的大核丝球，多半是初级精母细胞"}
第一次减数分裂前期特别长，所以同一条小管里可以同时看到细线期、合线期、粗线期等不同时期的初级精母细胞。把“看不见次级精母细胞”听成“减数分裂只做一次”，第二次减数分裂和单倍体精子细胞会对不上。
:::

#### （3）次级精母细胞

次级精母细胞（secondary spermatocyte）位置靠近腔面，直径约 $12\,\mu\mathrm{m}$。细胞核呈圆形，染色较深，核型为 23，X 或 23，Y（$2n$ DNA）。次级精母细胞不进行 DNA 复制，迅速进入第二次减数分裂，产生两个精子细胞，核型为 23，X 或 23，Y（$1n$ DNA）。由于次级精母细胞存在时间短暂，故在生精小管切面中不易见到。减数分裂（meiosis）又称成熟分裂，仅见于生殖细胞的发育过程中。经过两次减数分裂，染色体数目减少一半。

:::definition{label="次级精母细胞"}
次级精母细胞（secondary spermatocyte）靠近腔面，直径约 $12\,\mu\mathrm{m}$。核圆形、染色较深；核型为 23，X 或 23，Y（$2n$ DNA）。不进行 DNA 复制，迅速进入第二次减数分裂，产生两个精子细胞（$1n$ DNA）。存在时间短暂，切面中不易见到。
:::

:::definition{label="减数分裂"}
减数分裂（meiosis）又称成熟分裂，仅见于生殖细胞的发育过程。经过两次减数分裂，染色体数目减少一半：初级精母细胞 46，XY（$4n$ DNA）→ 次级精母细胞 23，X 或 23，Y（$2n$ DNA）→ 精子细胞 23，X 或 23，Y（$1n$ DNA）。
:::

:::compare{title="初级精母细胞与次级精母细胞"}
| 项目 | 初级精母细胞 | 次级精母细胞 |
|------|--------------|--------------|
| 位置 | 精原细胞近腔侧 | 更靠近腔面 |
| 直径 | 约 $18\,\mu\mathrm{m}$，体积较大 | 约 $12\,\mu\mathrm{m}$ |
| 核 | 大而圆，丝球状，染色质丝或粗或细 | 圆形，染色较深 |
| 核型 / DNA | 46，XY；$4n$ DNA（复制后） | 23，X 或 23，Y；$2n$ DNA |
| 分裂 | 第一次减数分裂，前期很长 | 不复制 DNA，迅速第二次减数分裂 |
| 切片 | 容易见到不同分裂时期 | 存在短暂，不易见到 |
:::

:::pitfall{label="次级精母细胞直径也约 12μm，不要和精原细胞画等号"}
精原细胞和次级精母细胞直径都约 $12\,\mu\mathrm{m}$，但一个紧贴基膜、核型仍是 46，XY，一个靠近腔面、核型已是 23，X 或 23，Y，而且几乎看不见。只按直径认细胞，基底室和近腔室会认错层。
:::

#### （4）精子细胞

精子细胞（spermatid）位于近腔面，直径约 $8\,\mu\mathrm{m}$。细胞核呈圆形，染色质细密。精子细胞不再分裂，经过复杂的变态，由圆形细胞逐渐转变为蝌蚪状的精子，这一过程称精子形成（spermiogenesis），包括：① 核染色质高度浓缩，细胞核变长，成为精子头部的主要结构；② 由高尔基复合体形成顶体，位于细胞核的一端；③ 中心体迁移到细胞核的另一端，其中一个中心粒的微管延长，形成轴丝，成为精子尾部（或称鞭毛）的主要结构；④ 线粒体聚集，缠绕在轴丝的近细胞核段周围，形成线粒体鞘；⑤ 多余的细胞质汇聚于尾侧，形成残余细胞质，最后脱落（图 18-7）。

:::definition{label="精子细胞"}
精子细胞（spermatid）位于近腔面，直径约 $8\,\mu\mathrm{m}$。核圆形，染色质细密，核型为 23，X 或 23，Y（$1n$ DNA）。它不再分裂，只进行精子形成。
:::

:::definition{label="精子形成"}
精子形成（spermiogenesis）是圆形精子细胞变态为蝌蚪状精子的过程，属于精子发生的第 3 阶段，不再分裂。五步：核浓缩变长成头部；高尔基复合体形成顶体；中心体迁到对侧，一个中心粒的微管延长成轴丝（尾／鞭毛）；线粒体缠绕近核段形成线粒体鞘；多余胞质成残余细胞质后脱落。
:::

::figure{src="/images/histology/textbook/p0204_04.png" caption="图18-6 精子发生示意图。示 A、B 型精原细胞，初级精母细胞细线前期至粗线期，次级精母细胞，以及不同发育阶段的精子细胞转变为精子并脱落残余体。" alt="精子发生模式：底部精原细胞A、B经减数分裂成为次级精母细胞，再经精子细胞变态为带尾精子并留下残余体"}

::figure{src="/images/histology/textbook/p0205_01.png" caption="图18-7 精子形成模式图。示高尔基复合体形成顶体泡与顶体，中心体发出鞭毛，线粒体鞘形成，残余细胞质脱落。" alt="精子形成四态：圆形精子细胞高尔基区出现顶体泡，鞭毛长出，核变长被顶体覆盖，线粒体鞘包绕近核段，尾侧残余细胞质待脱落"}

:::pitfall{label="精子形成是变态，不是又一次分裂"}
精子细胞已经是 $1n$ DNA，核型 23，X 或 23，Y。从圆形变成蝌蚪，靠的是核浓缩、顶体、轴丝、线粒体鞘和丢胞质，细胞数目不再加倍。把精子形成写成“精子细胞再分裂成精子”，单倍体账和残余细胞质都会算错。
:::

:::insight{label="顶体来自高尔基，鞭毛来自中心粒，能量工厂缠在中段"}
五步可以按细胞器搬家来记：核自己浓缩变长；高尔基复合体在核的一端铺顶体；中心体跑到另一端把微管延长成轴丝；线粒体赶到近核段缠成鞘；用剩的胞质从尾侧丢掉，由支持细胞吞噬。缺一步，受精时的水解酶、运动装置或供能都会缺件。
:::

#### （5）精子

人的精子（spermatozoon）形似蝌蚪，长约 $60\,\mu\mathrm{m}$，可分头、尾两部分（图 18-8，图 18-9）。头部嵌入支持细胞的顶部细胞质中，尾部游离于生精小管腔。头部正面观呈卵圆形，侧面观呈梨形，长 $4\sim 5\,\mu\mathrm{m}$。头内有一个高度浓缩的细胞核，其前 $2/3$ 有顶体（acrosome）覆盖。顶体是特殊的溶酶体，内含多种水解酶，如顶体素、透明质酸酶、磷酸酯酶等，在受精过程中发挥重要作用（见第 21 章）。尾部分为颈段、中段、主段和末段 4 部分。构成尾部全长的轴心是轴丝，由 $9+2$ 排列的微管组成，是精子运动的主要装置，轴丝外有 9 根纵行外周致密纤维。颈段有中心粒。中段的外侧包有线粒体鞘，是精子的能量供应中心。主段最长，外周致密纤维之外有纤维鞘，这两种结构均辅助精子运动。末段短，其内仅有轴丝。

:::definition{label="精子"}
精子（spermatozoon）形似蝌蚪，长约 $60\,\mu\mathrm{m}$，分头、尾两部分。头部嵌入支持细胞顶部胞质，尾部游离于生精小管腔。
:::

:::definition{label="精子头部"}
头部正面观卵圆形，侧面观梨形，长 $4\sim 5\,\mu\mathrm{m}$。内有高度浓缩的细胞核，前 $2/3$ 被顶体覆盖。
:::

:::definition{label="顶体"}
顶体（acrosome）覆盖细胞核前 $2/3$，是特殊的溶酶体，内含顶体素、透明质酸酶、磷酸酯酶等多种水解酶，在受精过程中发挥作用。
:::

:::definition{label="精子尾部"}
尾部分颈段、中段、主段和末段。全长轴心是 $9+2$ 微管组成的轴丝，为运动的主要装置；轴丝外有 9 根纵行外周致密纤维。颈段有中心粒；中段外侧包线粒体鞘，是能量供应中心；主段最长，外周致密纤维之外还有纤维鞘，二者辅助运动；末段短，仅有轴丝。
:::

:::

在精子发生过程中，一个精原细胞增殖分化所产生的各级生精细胞的细胞质并未完全分开，有细胞质桥（cytoplasmic bridge）相连，形成同步发育的同源细胞群（见图 18-5）。细胞质桥的存在有利于细胞间信息传递，保证同源生精细胞同步发育。但从生精小管全长来看，精子发生是不同步的。不同区域生精小管的生精细胞组合不同，因此在睾丸组织切片上可见生精小管不同切面具有不同发育阶段的生精细胞组合。

:::definition{label="细胞质桥"}
细胞质桥（cytoplasmic bridge）是同一精原细胞增殖分化所产生的各级生精细胞之间未完全分开的胞质通道。它把同源细胞连成同步发育的细胞群，利于信息传递。
:::

::figure{src="/images/histology/textbook/p0204_03.png" caption="图18-5 生精细胞与支持细胞关系模式图。示基底室与近腔室、支持细胞紧密连接、细胞质桥、精原细胞至精子的镶嵌关系，以及基膜外肌样细胞和间质细胞。" alt="支持细胞长锥体从基膜伸至腔面，近基底紧密连接划分基底室与近腔室；同源生精细胞以细胞质桥相连，间质细胞在小管之外"}

精子发生和形成需在低于体温 $2\sim 3$℃ 的环境中进行，故隐睾患者因精子发生障碍而不育（见第 24 章）。在精子发生和形成过程中，经常形成一些畸形精子，如光镜可见的双头或双核、大头、小头、不规则形头、无尾、双尾、短尾等；电镜可见的无顶体或小顶体，以及线粒体鞘等结构异常。感染、创伤、辐射、内分泌失调等可增加畸形精子数量，严重者可导致不育。

:::note{label="隐睾与畸形精子"}
| 问题 | 要点 |
|------|------|
| 温度 | 精子发生和形成需低于体温 $2\sim 3$℃；隐睾因温度过高导致精子发生障碍而不育 |
| 光镜畸形 | 双头或双核、大头、小头、不规则形头、无尾、双尾、短尾 |
| 电镜畸形 | 无顶体或小顶体，线粒体鞘等结构异常 |
| 加重因素 | 感染、创伤、辐射、内分泌失调可增加畸形精子数量，严重者导致不育 |
:::

:::insight{label="同源细胞靠细胞质桥同步，整条小管却不同步"}
同一克隆用细胞质桥对表，所以局部像“一窝同龄”；沿小管全长分区推进，所以不同切面的细胞组合不一样。切片上两条小管对不上号，不是染色失败，是精子发生在空间上不同步。
:::

:::pitfall{label="隐睾不育首先是温度账，不要写成“没有生精小管”"}
隐睾的生精小管还在，只是不在阴囊的低温环境里。精子发生和形成需要低于体温 $2\sim 3$℃。把隐睾听成“睾丸没发育、没有小管”，会和第 24 章下降障碍那本形态账打架。
:::

### 2. 支持细胞

支持细胞（sustentacular cell）又称塞托利细胞（Sertoli cell）。每个生精小管的横切面上有 $8\sim 11$ 个支持细胞，呈不规则长锥体形，细胞体从生精上皮基底一直伸达腔面。由于其侧面镶嵌着各级生精细胞，故光镜下细胞轮廓不清。细胞核近似卵圆形或呈三角形，染色浅，核仁明显（见图 18-3～图 18-5）。电镜下，细胞质内有大量滑面内质网和一些粗面内质网，高尔基复合体发达，线粒体和溶酶体较多，并有许多脂滴、糖原、微丝和微管。成人的支持细胞不再分裂，数量恒定。

相邻支持细胞侧面的近基底部细胞膜形成紧密连接，将生精上皮分成基底室（basal compartment）和近腔室（abluminal compartment）两部分。基底室位于生精上皮基膜和支持细胞紧密连接之间，内有精原细胞；近腔室位于紧密连接上方，与生精小管管腔相通，内有精母细胞、精子细胞和精子。生精小管与血液之间存在血-睾屏障（blood-testis barrier），组成包括毛细血管内皮及其基膜、结缔组织、生精上皮基膜和支持细胞的紧密连接。血-睾屏障可阻止血液中某些物质接触生精上皮，形成并维持有利于精子发生的微环境，还能防止精子抗原物质逸出到生精小管外而引发自身免疫反应。

支持细胞对生精细胞起支持和营养作用。支持细胞在卵泡刺激素和雄激素的作用下，合成和分泌雄激素结合蛋白（androgen binding protein，ABP），这种蛋白可与雄激素结合，以保持生精小管内有较高的雄激素水平，促进精子发生。同时，支持细胞又能分泌抑制素（inhibin）释放入血，可反馈性地抑制垂体分泌卵泡刺激素，以维持雄激素结合蛋白分泌量的稳定。支持细胞还分泌少量液体进入生精小管管腔，成为睾丸液，有助于精子的运送，而微丝和微管的收缩可使不断成熟的生精细胞向腔面移动，并促使精子释放入管腔。精子成熟后脱落的残余细胞质被支持细胞吞噬和消化。

:::definition{label="支持细胞"}
支持细胞（sustentacular cell）又称塞托利细胞（Sertoli cell）。横切面上每管 $8\sim 11$ 个，呈不规则长锥体形，从生精上皮基底一直伸达腔面。侧面镶嵌各级生精细胞，故光镜轮廓不清；核近似卵圆或三角形，染色浅，核仁明显。成人不再分裂，数量恒定。
:::

:::definition{label="支持细胞超微结构"}
胞质内有大量滑面内质网和一些粗面内质网，高尔基复合体发达，线粒体和溶酶体较多，并有许多脂滴、糖原、微丝和微管。微丝和微管收缩使成熟中的生精细胞向腔面移动，并促使精子释放入管腔；溶酶体参与吞噬残余细胞质。
:::

:::definition{label="基底室"}
基底室（basal compartment）位于生精上皮基膜与支持细胞紧密连接之间，内有精原细胞。精原细胞仍可与血液侧进行物质交换。
:::

:::definition{label="近腔室"}
近腔室（abluminal compartment）位于紧密连接上方，与生精小管管腔相通，内有精母细胞、精子细胞和精子。减数分裂和精子形成都在这间“隔离室”里完成。
:::

:::definition{label="血-睾屏障"}
血-睾屏障（blood-testis barrier）存在于生精小管与血液之间，组成包括：毛细血管内皮及其基膜、结缔组织、生精上皮基膜、支持细胞的紧密连接。它阻止血液中某些物质接触生精上皮，形成并维持有利于精子发生的微环境，并防止精子抗原逸出到小管外引发自身免疫反应。
:::

:::definition{label="雄激素结合蛋白"}
雄激素结合蛋白（androgen binding protein，ABP）由支持细胞在卵泡刺激素和雄激素作用下合成、分泌。ABP 与雄激素结合，保持生精小管内较高的雄激素水平，促进精子发生。
:::

:::definition{label="抑制素"}
抑制素（inhibin）由支持细胞分泌入血，反馈性抑制垂体分泌卵泡刺激素，以维持 ABP 分泌量稳定。
:::

:::definition{label="睾丸液"}
支持细胞分泌少量液体进入生精小管管腔，成为睾丸液，有助于运送精子。
:::

:::concept{term="先找支持细胞的紧密连接，再问谁在基底室、谁必须待在近腔室"}
支持细胞不是“夹在生精细胞之间的填料”。先在近基底部找到紧密连接：连接下方、基膜上方是基底室，只住精原细胞；连接上方通管腔，是近腔室，住精母细胞、精子细胞和精子。血-睾屏障的核心就是这道紧密连接。少写这一层，精子抗原漏出去就会变成自身免疫性睾丸炎。
:::

:::compare{title="基底室与近腔室"}
| 项目 | 基底室 | 近腔室 |
|------|--------|--------|
| 边界 | 生精上皮基膜 ↔ 支持细胞紧密连接 | 紧密连接上方，与管腔相通 |
| 住客 | 精原细胞 | 精母细胞、精子细胞、精子 |
| 与血液 | 相对可进行物质交换 | 被血-睾屏障严格隔离 |
| 发生事件 | 精原细胞增殖 | 减数分裂、精子形成、精子释放 |
:::

:::compare{title="血-睾屏障层次"}
| 层次（血液 → 管腔） | 结构 | 职分 |
|----------------------|------|------|
| 第 1 层 | 毛细血管内皮及其基膜 | 间质血管壁，第一道 |
| 第 2 层 | 结缔组织 | 小管周围间质 |
| 第 3 层 | 生精上皮基膜 | 上皮外侧 |
| 第 4 层（核心） | 支持细胞近基底部的紧密连接 | 把上皮分成基底室与近腔室；挡血液有害物，也挡精子抗原外逸 |
:::

:::note{label="支持细胞的职分"}
| 职分 | 要点 |
|------|------|
| 支持和营养 | 长锥体从基底伸达腔面，侧面镶嵌各级生精细胞 |
| 构成屏障 | 近基底紧密连接参与血-睾屏障 |
| 分泌 ABP | FSH + 雄激素作用下合成，维持小管内高雄激素，促进精子发生 |
| 分泌抑制素 | 入血反馈抑制垂体 FSH，稳定 ABP 分泌量 |
| 分泌睾丸液 | 帮助运送精子 |
| 移动与释放 | 微丝、微管收缩，使生精细胞向腔面移动并释放精子 |
| 吞噬 | 消化精子形成过程中脱落的残余细胞质；插入框还强调吞噬凋亡生精细胞和残体 |
:::

:::insight{label="青春期后才出现的精子抗原，被支持细胞关在近腔室里"}
精子发生始于青春期以后，此时机体的免疫感受能力早已建立。血-睾屏障把新出现的精子抗原留在近腔室，支持细胞再分泌免疫抑制物质、清扫凋亡细胞和残体，睾丸才成为免疫豁免组织。屏障一破，就是自身免疫性睾丸炎。完整机制见第 18-4 节插入框。
:::

## （二）睾丸间质

睾丸间质位于生精小管之间，为富含血管和淋巴管的疏松结缔组织，其中有睾丸间质细胞（testicular interstitial cell），又称莱迪希细胞（Leydig’s cell）。该细胞成群分布，呈圆形或多边形，细胞核呈圆形，细胞质为嗜酸性，具有类固醇激素分泌细胞的超微结构特征（见图 18-3～图 18-5）。从青春期开始，睾丸间质细胞在黄体生成素刺激下分泌雄激素，包括睾酮、雄烯二酮、双氢睾酮等。血液中 $90\%$ 以上的睾酮由睾丸间质细胞分泌，其余的由肾上腺皮质网状带细胞分泌。雄激素可启动、维持精子发生和男性生殖器官发育，以及维持第二性征和性功能。

:::definition{label="睾丸间质细胞"}
睾丸间质细胞（testicular interstitial cell）又称莱迪希细胞（Leydig’s cell），成群分布于生精小管之间的疏松结缔组织中，不在生精上皮内。细胞呈圆形或多边形，核圆形，胞质嗜酸性，具有类固醇激素分泌细胞的超微结构特征。
:::

:::definition{label="雄激素（睾丸）"}
从青春期开始，间质细胞在黄体生成素（LH，男性又称 ICSH）刺激下分泌雄激素，包括睾酮、雄烯二酮、双氢睾酮等。血液中 $90\%$ 以上的睾酮由睾丸间质细胞分泌，其余由肾上腺皮质网状带细胞分泌。雄激素启动并维持精子发生和男性生殖器官发育，以及维持第二性征和性功能。
:::

:::compare{title="支持细胞与间质细胞"}
| 项目 | 支持细胞（Sertoli / 塞托利细胞） | 间质细胞（Leydig / 莱迪希细胞） |
|------|----------------------------------|----------------------------------|
| 位置 | 生精上皮内，从基膜伸达腔面 | 生精小管之间的睾丸间质，不在上皮内 |
| 光镜 | 不规则长锥体形，轮廓不清；核卵圆或三角、浅染、核仁明显 | 成群，圆形或多边形；核圆；胞质嗜酸性 |
| 超微 | 大量滑面内质网，粗面内质网，发达高尔基，线粒体和溶酶体多，脂滴、糖原、微丝、微管 | 类固醇激素分泌细胞特征 |
| 激素应答 | FSH + 雄激素 → 合成 ABP；分泌抑制素 | LH（ICSH）→ 分泌雄激素 |
| 产物 | ABP、抑制素、睾丸液、免疫抑制物质 | 睾酮、雄烯二酮、双氢睾酮（血中 $90\%$ 以上睾酮） |
| 细胞分裂 | 成人不再分裂，数量恒定 | 青春期开始持续分泌 |
| 屏障 | 近基底紧密连接是血-睾屏障的核心 | 不构成血-睾屏障 |
| 对精子发生 | 支持、营养、移动释放、吞噬残体，维持小管内高雄激素微环境 | 提供雄激素，启动并维持精子发生 |
:::

:::pitfall{label="间质细胞不在生精上皮内"}
生精上皮只有支持细胞和 $5\sim 8$ 层生精细胞。间质细胞成群躺在小管之间的疏松结缔组织里，胞质嗜酸性，分泌睾酮。把莱迪希细胞写进上皮，血-睾屏障的层次会多出一个并不存在的“上皮内内分泌细胞”，FSH 管支持细胞、LH 管间质细胞这两本账也会并户。
:::

:::insight{label="间质细胞按类固醇细胞的样子造睾酮，再把激素交给支持细胞保管"}
嗜酸性、成群、管 LH，是间质细胞的身份证。造出来的睾酮有 $90\%$ 以上进入血液，小管内要靠支持细胞的 ABP 把雄激素留住，精子发生才有高浓度微环境。只记“睾丸分泌雄激素”，不会知道是谁造、谁绑、谁反馈。
:::

:::pitfall{label="血液中90%以上睾酮来自间质细胞，不要写成全部或写成支持细胞分泌"}
其余不到 $10\%$ 由肾上腺皮质网状带细胞分泌。支持细胞分泌的是 ABP 和抑制素，不是睾酮。写反以后，LH 的靶细胞会从间质细胞错接到塞托利细胞。
:::

## （三）直精小管和睾丸网

生精小管近睾丸纵隔处短而细的直行管道，称直精小管（straight tubule），管壁上皮为单层立方上皮或矮柱状上皮，无生精细胞。直精小管进入睾丸纵隔内分支吻合成网状管道，为睾丸网（rete testis），由单层立方上皮组成，管腔大而不规则。来自生精小管的精子经直精小管和睾丸网运出睾丸，进入附睾（图 18-10）。

:::definition{label="直精小管"}
直精小管（straight tubule）是生精小管近睾丸纵隔处短而细的直行管道。上皮为单层立方或矮柱状，无生精细胞。它只负责把精子送进睾丸网，不再发生精子。
:::

:::definition{label="睾丸网"}
睾丸网（rete testis）是直精小管在睾丸纵隔内分支吻合形成的网状管道，由单层立方上皮组成，管腔大而不规则。精子经此运出睾丸，进入附睾。
:::

::figure{src="/images/histology/textbook/p0206_02.png" caption="图18-10 睾丸纵隔光镜图。1. 生精小管；2. 直精小管；3. 睾丸网。" alt="睾丸纵隔：右侧仍见含多层生精细胞的生精小管，移行处上皮变薄为直精小管，纵隔结缔组织中为管腔不规则的睾丸网"}

:::compare{title="生精小管、直精小管与睾丸网"}
| 项目 | 生精小管 | 直精小管 | 睾丸网 |
|------|----------|----------|--------|
| 位置 | 睾丸小叶内，弯曲细长 | 近纵隔，短而直 | 纵隔内，分支吻合成网 |
| 上皮 | 生精上皮（支持细胞 + $5\sim 8$ 层生精细胞） | 单层立方或矮柱状，无生精细胞 | 单层立方，管腔大而不规则 |
| 职分 | 精子发生 | 输送精子入睾丸网 | 运出睾丸，进入附睾 |
:::

:::pitfall{label="直精小管和睾丸网没有生精细胞，不要当成另一段会造精子的小管"}
生精停止在生精小管。直精小管上皮已经换成单层立方或矮柱状，睾丸网腔大而不规则，都只是通道。把纵隔里的网状管道写成“还在发生精子”，支持细胞、血-睾屏障和间质细胞都会被搬错地方。
:::

## （四）睾丸功能的内分泌调节

腺垂体远侧部的促性腺激素细胞在下丘脑分泌的促性腺激素释放激素（GnRH）刺激下，分泌卵泡刺激素（FSH）和黄体生成素（LH）。在男性，LH 又称间质细胞刺激素（ICSH），可刺激间质细胞合成并分泌雄激素；FSH 促进支持细胞合成 ABP，并与雄激素结合，因此能够保持生精小管内高浓度的雄激素环境，促进精子发生。同时，支持细胞分泌的抑制素和间质细胞分泌的雄激素又可以反馈抑制下丘脑 GnRH 和腺垂体 FSH、LH 的分泌。在生理状态下，各种激素的分泌保持相对恒定，若激素的分泌量或受体发生改变，会影响正常精子发生甚至导致性功能障碍。

:::definition{label="GnRH-FSH-LH轴（男性）"}
下丘脑分泌促性腺激素释放激素（GnRH），刺激腺垂体远侧部促性腺激素细胞分泌卵泡刺激素（FSH）和黄体生成素（LH）。二者分别作用于支持细胞和间质细胞，再经抑制素和雄激素反馈抑制 GnRH、FSH、LH，使分泌量保持相对恒定。
:::

:::definition{label="间质细胞刺激素"}
在男性，LH 又称间质细胞刺激素（ICSH）。它刺激间质细胞合成并分泌雄激素。ICSH 不是另一种激素，只是 LH 在男性的别名。
:::

:::compare{title="FSH与LH（ICSH）在睾丸中的落点"}
| 项目 | FSH | LH（ICSH） |
|------|-----|------------|
| 来源 | 腺垂体远侧部促性腺激素细胞（受 GnRH 刺激） | 同左 |
| 靶细胞 | 支持细胞 | 间质细胞 |
| 直接效应 | 促进支持细胞合成 ABP | 刺激间质细胞合成并分泌雄激素 |
| 对精子发生 | ABP 结合雄激素，维持小管内高浓度雄激素环境 | 提供雄激素，启动并维持精子发生 |
| 负反馈 | 支持细胞分泌的抑制素抑制 FSH | 间质细胞分泌的雄激素抑制 GnRH、LH |
:::

:::note{label="男性睾丸的激素回路"}
| 层级 | 激素 | 作用 |
|------|------|------|
| 下丘脑 | GnRH | 刺激腺垂体促性腺激素细胞 |
| 腺垂体 | FSH、LH（ICSH） | FSH → 支持细胞；LH → 间质细胞 |
| 支持细胞 | ABP、抑制素、睾丸液 | ABP 维持小管内高雄激素；抑制素反馈抑制 FSH |
| 间质细胞 | 睾酮等雄激素 | 启动维持精子发生、生殖器官发育、第二性征和性功能；反馈抑制 GnRH、LH |
:::

:::pitfall{label="LH在男性就是ICSH，不要另立一种“专门刺激间质细胞的垂体激素”"}
教材写明：在男性，LH 又称间质细胞刺激素（ICSH）。考试若出现 ICSH，户头仍是 LH，靶细胞仍是间质细胞。另立一种激素，FSH / LH 两本账会变成三本。
:::

:::insight{label="FSH管微环境，LH管原料，抑制素和睾酮把阀门关住"}
没有 LH，间质细胞不造雄激素；没有 FSH，支持细胞少造 ABP，小管内雄激素留不住。两端的产物再回头按住下丘脑和垂体，分泌量才恒定。激素量或受体一变，精子发生和性功能一起出问题。
:::

:::keypoint{label="睾丸先立白膜纵隔和小叶，再把生精上皮、三阶段精子发生、血-睾屏障和间质细胞睾酮收口"}
- 男性生殖系统 = 睾丸 + 生殖管道 + 附属腺 + 外生殖器；睾丸产精子并分泌雄激素。
- 白膜在后缘增厚为纵隔，划分约 $250$ 个小叶，每叶 $1\sim 4$ 条生精小管；近纵隔改直精小管，纵隔内吻合成睾丸网。
- 生精上皮 = 支持细胞 + $5\sim 8$ 层生精细胞；基膜外有肌样细胞。
- 精子发生 $(64\pm 4.5)$ 天，三阶段：精原细胞增殖、精母细胞减数分裂、精子形成；不是一次有丝分裂。
- 精原细胞贴基膜（A 型干细胞，B 型分化为初级精母细胞）；初级精母细胞约 $18\,\mu\mathrm{m}$、46，XY、$4n$ DNA；次级短暂、$2n$ DNA；精子细胞 $1n$、只变态；精子长约 $60\,\mu\mathrm{m}$，顶体是特殊溶酶体。
- 支持细胞长锥体、成人数量恒定；紧密连接分基底室（精原细胞）和近腔室（其余各级）；血-睾屏障 = 内皮及基膜 + 结缔组织 + 生精上皮基膜 + 紧密连接。
- 支持细胞分泌 ABP、抑制素、睾丸液，吞噬残体；间质细胞在小管之间，不在上皮内，LH 刺激下分泌睾酮（血中 $90\%$ 以上）。
- FSH 作用于支持细胞，LH（ICSH）作用于间质细胞；抑制素和雄激素负反馈。
:::

:::memory{label="本节必背要点"}
- [ ] 男性生殖系统（male reproductive system）由睾丸、生殖管道、附属腺及外生殖器组成。
- [ ] 睾丸产生精子并分泌雄性激素；生殖管道促进精子成熟，营养、贮存和运输精子。
- [ ] 附属腺包括精囊、尿道球腺和前列腺；附属腺和生殖管道的分泌物参与精液组成。
- [ ] 睾丸（testis）位于阴囊中，呈略扁椭圆形。
- [ ] 表面覆以浆膜，即鞘膜脏层；深部为致密结缔组织构成的白膜（tunica albuginea）。
- [ ] 白膜在睾丸后缘增厚形成睾丸纵隔（mediastinum testis）。
- [ ] 纵隔结缔组织呈放射状伸入实质，将实质分成约 $250$ 个锥形小叶；每个小叶内有 $1\sim 4$ 条弯曲细长的生精小管。
- [ ] 生精小管近纵隔处变为短而直的直精小管，进入纵隔相互吻合形成睾丸网。
- [ ] 生精小管之间的疏松结缔组织称睾丸间质。
- [ ] 成人生精小管（seminiferous tubule）长 $30\sim 70\,\mathrm{cm}$，直径 $150\sim 250\,\mu\mathrm{m}$，管壁厚 $60\sim 80\,\mu\mathrm{m}$。
- [ ] 管壁由生精上皮（spermatogenic epithelium）构成；生精上皮由支持细胞和 $5\sim 8$ 层生精细胞组成。
- [ ] 上皮基膜外侧有胶原纤维和梭形肌样细胞（myoid cell）；肌样细胞收缩有助于精子排出。
- [ ] 自基底部至腔面依次为精原细胞、初级精母细胞、次级精母细胞、精子细胞和精子。
- [ ] 精原细胞形成精子的过程称精子发生（spermatogenesis），人需要 $(64\pm 4.5)$ 天。
- [ ] 精子发生经历精原细胞增殖、精母细胞减数分裂和精子形成 3 个阶段。
- [ ] 精原细胞（spermatogonium）紧贴基膜，圆形或卵圆形，直径 $12\,\mu\mathrm{m}$，分 A、B 两型。
- [ ] A 型精原细胞核卵圆形：或染色质细小深染、中央常见淡染区，或染色质细密浅染；是生精细胞中的干细胞。
- [ ] A 型不断分裂增殖，一部分子细胞继续作为干细胞，另一部分分化为 B 型精原细胞。
- [ ] B 型精原细胞核圆形，核周边有较粗的染色质颗粒；经数次分裂后分化为初级精母细胞。
- [ ] 初级精母细胞（primary spermatocyte）位于精原细胞近腔侧，直径约 $18\,\mu\mathrm{m}$；核大而圆、呈丝球状；核型 46，XY。
- [ ] 初级精母细胞 DNA 复制后为 $4n$ DNA，进行第一次减数分裂，形成两个次级精母细胞。
- [ ] 第一次减数分裂前期历时较长，切面中可见不同分裂时期的初级精母细胞。
- [ ] 次级精母细胞（secondary spermatocyte）靠近腔面，直径约 $12\,\mu\mathrm{m}$；核圆、染色较深；核型 23，X 或 23，Y（$2n$ DNA）。
- [ ] 次级精母细胞不进行 DNA 复制，迅速第二次减数分裂，产生两个精子细胞（$1n$ DNA）；存在短暂，切面不易见到。
- [ ] 减数分裂（meiosis）又称成熟分裂，仅见于生殖细胞发育；两次减数分裂使染色体数目减半。
- [ ] 精子细胞（spermatid）位于近腔面，直径约 $8\,\mu\mathrm{m}$；核圆、染色质细密；不再分裂。
- [ ] 精子形成（spermiogenesis）是圆形精子细胞转变为蝌蚪状精子的变态过程。
- [ ] 精子形成五步：核浓缩变长成头部；高尔基复合体形成顶体；中心体迁至对侧，一中心粒微管延长成轴丝（尾／鞭毛）；线粒体缠绕近核段成线粒体鞘；多余胞质成残余细胞质后脱落。
- [ ] 人精子（spermatozoon）形似蝌蚪，长约 $60\,\mu\mathrm{m}$，分头、尾两部分。
- [ ] 头部嵌入支持细胞顶部胞质，尾部游离于生精小管腔。
- [ ] 头部正面观卵圆形，侧面观梨形，长 $4\sim 5\,\mu\mathrm{m}$；核高度浓缩，前 $2/3$ 被顶体覆盖。
- [ ] 顶体（acrosome）是特殊溶酶体，含顶体素、透明质酸酶、磷酸酯酶等，参与受精。
- [ ] 尾分颈段、中段、主段和末段；轴心为 $9+2$ 微管组成的轴丝，是运动的主要装置；轴丝外有 9 根纵行外周致密纤维。
- [ ] 颈段有中心粒；中段外侧包线粒体鞘，是能量供应中心；主段最长，致密纤维外有纤维鞘，辅助运动；末段短，仅有轴丝。
- [ ] 同源生精细胞以细胞质桥（cytoplasmic bridge）相连，同步发育；从生精小管全长看，精子发生不同步。
- [ ] 不同区域生精细胞组合不同，故不同切面可见不同发育阶段的生精细胞组合。
- [ ] 精子发生和形成需在低于体温 $2\sim 3$℃ 的环境中进行；隐睾因精子发生障碍而不育。
- [ ] 光镜畸形精子：双头或双核、大头、小头、不规则形头、无尾、双尾、短尾等。
- [ ] 电镜畸形：无顶体或小顶体，线粒体鞘等结构异常；感染、创伤、辐射、内分泌失调可增加畸形数量。
- [ ] 支持细胞（sustentacular cell）又称塞托利细胞（Sertoli cell）；横切面每管 $8\sim 11$ 个。
- [ ] 支持细胞呈不规则长锥体形，从基底伸达腔面；侧面镶嵌生精细胞，光镜轮廓不清。
- [ ] 支持细胞核近似卵圆或三角形，染色浅，核仁明显。
- [ ] 电镜下有大量滑面内质网和一些粗面内质网，高尔基复合体发达，线粒体和溶酶体较多，并有脂滴、糖原、微丝和微管。
- [ ] 成人支持细胞不再分裂，数量恒定。
- [ ] 相邻支持细胞近基底部形成紧密连接，将生精上皮分成基底室（basal compartment）和近腔室（abluminal compartment）。
- [ ] 基底室内有精原细胞；近腔室与管腔相通，内有精母细胞、精子细胞和精子。
- [ ] 血-睾屏障（blood-testis barrier）组成：毛细血管内皮及其基膜、结缔组织、生精上皮基膜、支持细胞紧密连接。
- [ ] 血-睾屏障阻止血液中某些物质接触生精上皮，维持精子发生微环境，并防止精子抗原逸出引发自身免疫反应。
- [ ] 支持细胞对生精细胞起支持和营养作用。
- [ ] 支持细胞在 FSH 和雄激素作用下合成、分泌雄激素结合蛋白（ABP），保持小管内较高雄激素水平，促进精子发生。
- [ ] 支持细胞分泌抑制素（inhibin）入血，反馈抑制垂体 FSH，维持 ABP 分泌量稳定。
- [ ] 支持细胞分泌睾丸液，有助于运送精子；微丝和微管收缩使生精细胞向腔面移动并释放精子。
- [ ] 精子成熟后脱落的残余细胞质被支持细胞吞噬和消化。
- [ ] 睾丸间质位于生精小管之间，为富含血管和淋巴管的疏松结缔组织。
- [ ] 睾丸间质细胞（testicular interstitial cell）又称莱迪希细胞（Leydig’s cell），成群分布，不在生精上皮内。
- [ ] 间质细胞呈圆形或多边形，核圆，胞质嗜酸性，具有类固醇激素分泌细胞超微结构特征。
- [ ] 从青春期开始，间质细胞在 LH 刺激下分泌雄激素，包括睾酮、雄烯二酮、双氢睾酮等。
- [ ] 血液中 $90\%$ 以上的睾酮由睾丸间质细胞分泌，其余由肾上腺皮质网状带细胞分泌。
- [ ] 雄激素启动、维持精子发生和男性生殖器官发育，以及维持第二性征和性功能。
- [ ] 直精小管（straight tubule）上皮为单层立方或矮柱状，无生精细胞。
- [ ] 睾丸网（rete testis）由单层立方上皮组成，管腔大而不规则；精子经直精小管和睾丸网进入附睾。
- [ ] 下丘脑 GnRH 刺激腺垂体促性腺激素细胞分泌 FSH 和 LH。
- [ ] 男性 LH 又称间质细胞刺激素（ICSH），刺激间质细胞合成并分泌雄激素。
- [ ] FSH 促进支持细胞合成 ABP，与雄激素结合，保持小管内高浓度雄激素环境，促进精子发生。
- [ ] 抑制素和雄激素反馈抑制下丘脑 GnRH 和腺垂体 FSH、LH；激素量或受体改变可影响精子发生甚至导致性功能障碍。
