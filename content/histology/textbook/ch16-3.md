# 三、气管与主支气管

气管与主支气管为肺外的气体通道，其管壁结构相似，由内向外依次为黏膜、黏膜下层和外膜 3 层（图 16-4）。

:::definition{label="气管与主支气管"}
气管与主支气管是肺外的气体通道，属于导气部。管壁结构相似，由内向外依次为黏膜、黏膜下层和外膜 3 层。
:::

:::concept{term="先数三层，再认 C 形软骨缺口朝哪"}
看见气管切片，先把消化管那本四层账放下：这里没有黏膜肌层，黏膜只有上皮和固有层。外膜里 $16\sim 20$ 个 C 字形透明软骨环是支架，缺口是膜性部，里面才是弹性韧带、平滑肌束和气管腺。把气管听成“又一段消化管四层”，软骨环和平滑肌会一起写错层。
:::

:::compare{title="气管壁三层"}
| 层次（内→外） | 组织 | 要点 |
|----------------|------|------|
| 黏膜 | 假复层纤毛柱状上皮 + 固有层 | 无黏膜肌层；基膜明显；固有层弹性纤维多，常见淋巴组织 |
| 黏膜下层 | 疏松结缔组织 | 与固有层和外膜无明显界限；较多混合腺（气管腺） |
| 外膜 | 较厚；主要含 $16\sim 20$ 个 C 字形透明软骨环 | 软骨环之间以弹性纤维膜状韧带连接；缺口为膜性部 |
:::

:::pitfall{label="气管是黏膜、黏膜下层、外膜三层，不要套消化管四层"}
消化管除口腔与咽外有黏膜肌层，气管黏膜只有上皮和固有层。外膜的主角是 C 字形透明软骨环，不是浆膜或单纯纤维膜。硬套四层，气管腺会找不到黏膜下层，膜性部平滑肌也会被算进“肌层”。
:::

## （一）黏膜

黏膜由上皮和固有层组成。上皮为假复层纤毛柱状上皮，由纤毛细胞、杯状细胞、刷细胞、基细胞和小颗粒细胞组成（图 16-5～图 16-7）。

:::definition{label="气管黏膜"}
黏膜由上皮和固有层组成。上皮为假复层纤毛柱状上皮，由纤毛细胞、杯状细胞、刷细胞、基细胞和小颗粒细胞组成。光镜下上皮与固有层之间基膜明显。
:::

### 1. 纤毛细胞

纤毛细胞（ciliated cell）最多，呈柱状，游离面有密集的纤毛，纤毛向咽部快速摆动，将黏液及其黏附的尘埃、细菌等推向咽部咳出，以净化吸入的空气。慢性支气管炎会导致纤毛变短、粘连、倒伏和脱失。

:::definition{label="纤毛细胞"}
纤毛细胞（ciliated cell）是气管上皮中数量最多的细胞，呈柱状，游离面有密集的纤毛。纤毛向咽部快速摆动，将黏液及其黏附的尘埃、细菌等推向咽部咳出，以净化吸入的空气。
:::

:::pitfall{label="慢性支气管炎先打在纤毛上，不要只写成“腺体分泌多了”"}
慢性支气管炎会导致纤毛变短、粘连、倒伏和脱失。黏液还在，传送带断了，痰才积下来。把病变听成单纯腺体增生，纤毛细胞这本最多的账会漏掉。
:::

### 2. 杯状细胞

杯状细胞较多，其分泌的黏蛋白与混合腺的分泌物在上皮表面构成黏液性屏障，可黏附空气中的异物颗粒，溶解吸入的 $\mathrm{SO}_{2}$ 等有毒气体。

:::definition{label="气管杯状细胞"}
杯状细胞较多。分泌的黏蛋白与混合腺分泌物在上皮表面构成黏液性屏障，可黏附空气中的异物颗粒，溶解吸入的 $\mathrm{SO}_{2}$ 等有毒气体。
:::

### 3. 刷细胞

刷细胞（brush cell）较少，呈柱状，游离面有排列整齐的微绒毛，形如刷状。刷细胞的功能尚未定论。有报道基部与感觉神经末梢形成突触，故认为该细胞可能有感受刺激的作用。

:::definition{label="刷细胞"}
刷细胞（brush cell）较少，呈柱状，游离面有排列整齐的微绒毛，形如刷状。功能尚未定论；有报道基部与感觉神经末梢形成突触，故可能有感受刺激的作用。
:::

:::pitfall{label="刷细胞游离面是微绒毛，不要看成纤毛细胞"}
刷状外观来自排列整齐的微绒毛，不是能摆动的纤毛。数量少，功能未定论，最多记到“可能感受刺激”。把刷细胞写成另一种纤毛细胞，五种上皮细胞的身份证件会少一本。
:::

### 4. 小颗粒细胞

小颗粒细胞（small granule cell）较少，呈锥形，单个或成团分布在上皮深部，细胞质内有许多分泌颗粒，含 5-羟色胺等物质，可调节呼吸道平滑肌的收缩和腺体的分泌，是一种弥散的神经内分泌细胞。

:::definition{label="小颗粒细胞"}
小颗粒细胞（small granule cell）较少，呈锥形，单个或成团分布在上皮深部。胞质内有许多分泌颗粒，含 5-羟色胺等物质，可调节呼吸道平滑肌的收缩和腺体的分泌，是一种弥散的神经内分泌细胞。
:::

### 5. 基细胞

基细胞呈锥形，位于上皮深部，为干细胞，可增殖分化为上皮中其他各类细胞。

:::definition{label="气管上皮基细胞"}
基细胞呈锥形，位于上皮深部，为干细胞，可增殖分化为上皮中其他各类细胞。
:::

光镜下，上皮与固有层之间基膜明显。固有层结缔组织中有较多弹性纤维，也常见淋巴组织，具有免疫防御功能。其中浆细胞与上皮细胞联合分泌 sIgA，释放入管腔，可杀灭细菌、病毒。

:::definition{label="气管黏膜固有层"}
固有层结缔组织中有较多弹性纤维，也常见淋巴组织，具有免疫防御功能。光镜下上皮与固有层之间基膜明显。
:::

:::definition{label="sIgA（气管）"}
固有层中的浆细胞与上皮细胞联合分泌 sIgA，释放入管腔，可杀灭细菌、病毒。抗体不是杯状细胞的黏蛋白，也不来自软骨细胞。
:::

:::compare{title="气管上皮五种细胞"}
| 细胞 | 数量与形态 | 游离面 / 位置 | 职分 |
|------|------------|---------------|------|
| 纤毛细胞 | 最多，柱状 | 密集纤毛，向咽部摆动 | 清扫黏液和异物；慢性支气管炎时变短、粘连、倒伏、脱失 |
| 杯状细胞 | 较多 | 分泌黏蛋白 | 与气管腺共同构成黏液性屏障，黏附异物，溶解 $\mathrm{SO}_{2}$ 等 |
| 刷细胞 | 较少，柱状 | 排列整齐的微绒毛，形如刷状 | 功能未定论；可能感受刺激 |
| 小颗粒细胞 | 较少，锥形 | 上皮深部，单个或成团 | 含 5-羟色胺等，调节平滑肌和腺体；弥散神经内分泌细胞 |
| 基细胞 | 锥形 | 上皮深部 | 干细胞，增殖分化为其他各类细胞 |
:::

:::insight{label="黏液-纤毛和 sIgA 是同一条管腔里的两道防线"}
杯状细胞和气管腺铺黏液，纤毛向咽部扫；浆细胞把 IgA 交给上皮，做成 sIgA 再释放入管腔。物理黏附和黏膜免疫写在同一层黏膜上。把气管听成“一根有软骨的管子”，净化账会只剩下 C 形环。
:::

## （二）黏膜下层

黏膜下层为疏松结缔组织，与固有层和外膜无明显界限，其内有较多混合腺，也称气管腺。

:::definition{label="黏膜下层（气管）"}
黏膜下层为疏松结缔组织，与固有层和外膜无明显界限，其内有较多混合腺，也称气管腺。
:::

:::definition{label="气管腺"}
气管腺是黏膜下层内的混合腺，分泌物参与上皮表面的黏液性屏障。膜性部内也有气管腺。
:::

## （三）外膜

外膜较厚，主要含 $16\sim 20$ 个 C 字形透明软骨环，软骨环之间以弹性纤维构成的膜状韧带连接，它们共同构成管壁的支架。软骨环的缺口处为气管膜性部，内有弹性纤维组成的韧带、平滑肌束和气管腺。咳嗽时平滑肌收缩，使气管腔缩小，有助清除痰液。

主支气管壁的结构随着管腔变小，管壁变薄，3 层分界不明显；环状软骨逐渐变为不规则的软骨片，而平滑肌纤维逐渐增多，呈螺旋形排列。

:::definition{label="气管外膜"}
外膜较厚，主要含 $16\sim 20$ 个 C 字形透明软骨环。软骨环之间以弹性纤维构成的膜状韧带连接，共同构成管壁的支架。
:::

:::definition{label="C 字形透明软骨环"}
气管外膜的支架是 $16\sim 20$ 个 C 字形透明软骨环，不是完整的圆环形软骨。缺口朝向膜性部，才能给食管留扩张的空间，并让平滑肌改变管径。
:::

:::definition{label="气管膜性部"}
软骨环的缺口处为气管膜性部，内有弹性纤维组成的韧带、平滑肌束和气管腺。咳嗽时平滑肌收缩，使气管腔缩小，有助清除痰液。
:::

:::definition{label="主支气管壁的移行"}
主支气管壁随着管腔变小，管壁变薄，3 层分界不明显；环状软骨逐渐变为不规则的软骨片，而平滑肌纤维逐渐增多，呈螺旋形排列。这是后文肺内支气管“软骨减少、平滑肌增多”的起点。
:::

:::compare{title="气管与主支气管"}
| 项目 | 气管 | 主支气管 |
|------|------|----------|
| 位置 | 肺外气体通道 | 肺外气体通道，入肺前 |
| 层次 | 黏膜、黏膜下层、外膜 3 层清楚 | 管腔变小后 3 层分界不明显 |
| 软骨 | $16\sim 20$ 个 C 字形透明软骨环 | 环状软骨逐渐变为不规则软骨片 |
| 平滑肌 | 主要在膜性部 | 逐渐增多，呈螺旋形排列 |
| 上皮 | 假复层纤毛柱状，五种细胞 | 仍为假复层纤毛柱状，向肺内继续变薄 |
:::

:::insight{label="C 形环把“硬支架”和“可缩小的缺口”写在同一圈外膜里"}
软骨环保证管腔不塌，缺口里的平滑肌保证咳嗽时管腔能缩小、痰能被挤出去。主支气管开始把完整的 C 形环拆成软骨片，平滑肌改螺旋，是为了进肺以后改写成肌性管道。把外膜听成“一圈骨头”，膜性部和螺旋平滑肌两本账会从肺门外就丢。
:::

:::keypoint{label="气管先立三层和五种上皮细胞，再记 C 形环与膜性部"}
- 肺外气体通道：黏膜、黏膜下层、外膜 3 层，无黏膜肌层。
- 上皮为假复层纤毛柱状：纤毛细胞最多，加杯状细胞、刷细胞、基细胞、小颗粒细胞。
- 纤毛向咽部摆动；慢性支气管炎使纤毛变短、粘连、倒伏、脱失。
- 杯状细胞黏蛋白 + 气管腺 → 黏液性屏障，可溶解 $\mathrm{SO}_{2}$。
- 固有层弹性纤维多，浆细胞与上皮联合分泌 sIgA。
- 外膜 $16\sim 20$ 个 C 字形透明软骨环；缺口为膜性部（弹性韧带 + 平滑肌束 + 气管腺）。
- 主支气管：软骨变为不规则片，平滑肌螺旋增多，3 层分界渐不明显。
:::
