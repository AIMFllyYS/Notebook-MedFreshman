# 一、软骨

软骨和骨是人体的支架结构，来源于胚胎时期的间充质。软骨和骨的主体分别是软骨组织和骨组织，它们皆属于高度特化的固态结缔组织，其中骨组织的硬度大大超过软骨组织。本章先把软骨的细胞–基质–软骨膜账立住，再进入骨组织、骨的发生与重建、影响生长发育的因素和关节。

:::definition{label="软骨和骨"}
软骨和骨是人体的支架结构，来源于胚胎时期的间充质。主体分别是软骨组织和骨组织，皆属高度特化的固态结缔组织；骨组织的硬度大大超过软骨组织。
:::

:::concept{term="先问是固态结缔组织，再问硬的是骨还是软骨"}
上一章的固有结缔组织把细胞拆进纤维和基质里。软骨和骨把同一套结缔组织账写成固态支架：细胞仍无极性、仍包在自己分泌的基质里，但基质已经凝胶化或钙化。看见一张硬组织切片，先问有没有软骨陷窝和软骨囊，再问有没有骨盐和骨小管。把软骨听成“硬一点的致密结缔组织”，会把陷窝和同源细胞群做丢。
:::

软骨（cartilage）由软骨组织及包裹它的软骨膜构成。软骨组织（cartilage tissue）由软骨细胞和软骨基质构成。软骨是胚胎早期的主要支架，随着胎儿发育逐渐被骨取代，取代过程一直延续到出生后一段时期。在成体中，仅散在分布一些软骨，其类型与作用因部位而异。

:::definition{label="软骨"}
软骨（cartilage）由软骨组织及包裹它的软骨膜构成。软骨是胚胎早期的主要支架，随胎儿发育逐渐被骨取代，取代过程延续到出生后一段时期；成体仅散在分布一些软骨，类型与作用因部位而异。
:::

:::definition{label="软骨组织"}
软骨组织（cartilage tissue）由软骨细胞和软骨基质构成，是软骨的结构主体。
:::

:::insight{label="胚胎先立软骨支架，出生前后才陆续换成骨"}
软骨在胚胎早期承担主要支架，随后被骨逐步取代，取代并不在出生时停住。成体里剩下的软骨（肋软骨、关节软骨、呼吸道软骨、耳郭、椎间盘等）各有力学职分，不能再把“软骨”听成胚胎残留。骨取代软骨的具体过程是第三节软骨内成骨要接的账。
:::

## （一）软骨组织

### 1. 软骨细胞

软骨细胞（chondrocyte）包埋在软骨基质中，所在腔隙称软骨陷窝（cartilage lacunae）。软骨细胞的大小、形状和分布在软骨内有一定的规律，反映了软骨细胞从幼稚到成熟的发育过程。周边的软骨细胞幼稚，胞体小，呈扁圆形，长轴与软骨表面平行，单个分布；越靠近软骨中部，其细胞越成熟，体积越大，由扁圆形逐渐变成椭圆形或圆形，细胞增生分裂成相对集中的细胞群体（一般为 $2\sim 8$ 个），由于皆由同一个幼稚软骨细胞增殖形成，故称同源细胞群（isogenous group）。成熟软骨细胞的细胞质呈弱嗜碱性，有丰富的粗面内质网和高尔基复合体（图 4-1，图 4-2），表明软骨细胞具有产生软骨基质的强大能力。

:::definition{label="软骨细胞"}
软骨细胞（chondrocyte）包埋在软骨基质中，所在腔隙称软骨陷窝。周边者幼稚、胞体小、扁圆形，长轴与表面平行，单个分布；越近中部越成熟，体积越大，由扁圆形变为椭圆或圆形。成熟者胞质弱嗜碱性，粗面内质网和高尔基复合体丰富，能大量产生软骨基质。
:::

:::definition{label="软骨陷窝"}
软骨陷窝（cartilage lacunae）是软骨细胞在软骨基质中所在的腔隙。制片时细胞收缩，光镜下常在细胞与陷窝壁之间留出空隙。
:::

:::definition{label="同源细胞群"}
同源细胞群（isogenous group）是由同一个幼稚软骨细胞增殖形成、相对集中的细胞群体，一般为 $2\sim 8$ 个。它标记载材所写的成熟过程：越靠近软骨中部，细胞越成熟，分裂后仍挤在同一窝系里。
:::

:::concept{term="先问从周边到中部：扁而单个，还是圆而成群"}
软骨细胞的形态是一张成熟梯度图，不是几种互不相干的细胞。周边：小、扁、单个，长轴贴着表面，刚从软骨膜侧分化进来。中部：大、圆、成群，$2\sim 8$ 个挤在一起，才叫同源细胞群。看见成团的软骨细胞，先问是不是同一个幼稚细胞的子代，再问它们是不是已经被软骨囊围住。
:::

:::pitfall{label="同源细胞群不是碰巧挨在一起的几个软骨细胞"}
教材把 $2\sim 8$ 个细胞写成同源，是因为它们皆由同一个幼稚软骨细胞增殖形成。切片上几个核靠近，不等于同源细胞群；要看它们是否共处于同一软骨囊系统、是否位于软骨中部的成熟区。也不要把同源细胞群听成“一种独立的细胞类型”。
:::

### 2. 软骨基质

软骨基质（cartilage matrix）即软骨组织的细胞外基质，由无定形基质和包埋其中的纤维构成。无定形基质的主要成分为蛋白聚糖和水，此蛋白聚糖与疏松结缔组织中的蛋白聚糖类似，也构成分子筛结构，使其具有较好的渗透性。尽管软骨组织内无血管和淋巴管，处于深部的软骨细胞依然可借助渗透的方式与周围组织进行物质交换。软骨中的蛋白聚糖含量远高于一般的结缔组织，使软骨基质形成较为坚固的凝胶。糖胺聚糖在基质中的分布不均匀，紧靠软骨陷窝部位的硫酸软骨素较多，故此处嗜碱性较强，于 HE 染色切片中，形似囊状包围软骨细胞，故称软骨囊（cartilage capsule）。纤维埋于基质中，使软骨具有韧性或弹性，具体情况取决于纤维的类型和含量。

:::definition{label="软骨基质"}
软骨基质（cartilage matrix）即软骨组织的细胞外基质，由无定形基质和包埋其中的纤维构成。无定形基质的主要成分为蛋白聚糖和水，构成分子筛，渗透性较好；蛋白聚糖含量远高于一般结缔组织，使基质成为较为坚固的凝胶。
:::

:::definition{label="软骨囊"}
软骨囊（cartilage capsule）是紧靠软骨陷窝、硫酸软骨素较多因而嗜碱性较强的基质带。HE 切片中形似囊状包围软骨细胞。
:::

:::cause-effect{title="软骨无血管，深部细胞如何交换物质"}
- 因：软骨组织内无血管和淋巴管
- 因：蛋白聚糖与水构成分子筛，基质渗透性较好
- 果：深部软骨细胞仍可借助渗透与周围组织进行物质交换
- 制约：营养最终来自软骨膜内的血管（关节软骨则来自滑液，见第五节）
:::

:::pitfall{label="软骨囊不是细胞膜，也不是软骨膜"}
软骨囊是陷窝周围那圈嗜碱性更强的基质，硫酸软骨素多，HE 里像口袋套住细胞。它不是细胞自己的膜，更不是表面那层致密结缔组织软骨膜。把“囊”听成细胞结构，会把基质账做成细胞器账。
:::

:::concept{term="纤维埋在凝胶里：韧性还是弹性，先问纤维类型"}
蛋白聚糖把基质写成坚固凝胶，抗压主要靠这团胶；纤维埋在胶里，决定韧性或弹性。透明软骨是极细的Ⅱ型胶原原纤维，光镜下看不见；弹性软骨换成大量弹性纤维；纤维软骨是粗大胶原纤维束。看见软骨，先问胶多还是纤维多，再问纤维是Ⅱ型胶原、弹性纤维还是粗胶原束。
:::

## （二）软骨膜

除关节软骨外，软骨表面被覆薄层致密结缔组织，即软骨膜（perichondrium）。软骨膜内有血管、淋巴管和神经，可为软骨组织提供营养和保护等作用（见图 4-1）。软骨膜内层存在由间充质干细胞分化而来的骨祖细胞，可进一步分化为成软骨细胞（chondroblast）。成软骨细胞狭长，仅含核处略厚，开始具备初步的分泌能力，一旦被分泌的软骨基质包围，即成为软骨细胞。

:::definition{label="软骨膜"}
软骨膜（perichondrium）是除关节软骨外被覆于软骨表面的薄层致密结缔组织。内有血管、淋巴管和神经，为软骨组织提供营养和保护；内层含骨祖细胞，可分化为成软骨细胞。
:::

:::definition{label="成软骨细胞"}
成软骨细胞（chondroblast）由软骨膜内层的骨祖细胞分化而来。细胞狭长，仅含核处略厚，开始具备初步分泌能力；一旦被自己分泌的软骨基质包围，即成为软骨细胞。
:::

:::pitfall{label="关节软骨表面没有软骨膜"}
教材写明：除关节软骨外，软骨表面才被覆软骨膜。关节软骨靠滑液营养，深部直接连着钙化基质和骨，不能按“表面一定有一层致密结缔组织”去找软骨膜。把关节软骨画上软骨膜，附加性生长和营养来源两本账都会做错。第五节还要再写一遍关节软骨的三项差异。
:::

:::note{label="骨祖细胞在软骨膜和骨膜是同一类干细胞"}
骨祖细胞（osteoprogenitor cell）是软骨组织和骨组织共同的干细胞，位于软骨膜和骨膜内层，分化方向取决于所处部位和所受刺激的性质。在软骨膜内层，它走向成软骨细胞；在骨膜内层，它走向成骨细胞。不要把“骨祖”听成只能成骨。
:::

## （三）软骨的类型

### 1. 透明软骨

透明软骨（hyaline cartilage）因新鲜时呈半透明而得名，分布较广，包括肋软骨、关节软骨、呼吸道软骨等。透明软骨具有较强的抗压性，有一定的弹性和韧性，但在外力作用下较其他类型软骨更易断裂。纤维成分主要是由Ⅱ型胶原蛋白组成的胶原原纤维，纤维交织排列成三维网格状。由于纤维极细，直径仅 $10\sim 20\,\mathrm{nm}$，且折光率与基质接近，故光镜下不能分辨（见图 4-1）。基质中含水分较多是透明软骨呈半透明的原因之一。

:::definition{label="透明软骨"}
透明软骨（hyaline cartilage）因新鲜时呈半透明而得名，分布于肋软骨、关节软骨、呼吸道软骨等。抗压性强，有一定弹性和韧性，但较其他类型软骨更易断裂。纤维主要是Ⅱ型胶原蛋白构成的胶原原纤维，交织成三维网格；直径仅 $10\sim 20\,\mathrm{nm}$，折光率与基质接近，光镜下不能分辨。基质含水分较多，是半透明的原因之一。
:::

:::example{label="气管切片上如何认出透明软骨"}
低倍先找嗜碱性的软骨基质和表面的软骨膜（图 4-1A）；高倍在中部找陷窝、软骨囊和 $2\sim 8$ 个细胞的同源细胞群（图 4-1B）。基质里看不见纤维，正是Ⅱ型胶原原纤维太细、折光率接近基质的结果，不要据此判断“透明软骨没有纤维”。
:::

### 2. 弹性软骨

弹性软骨（elastic cartilage）分布于耳郭、咽喉及会厌等处，新鲜时呈黄色。组织结构与透明软骨相似，但纤维成分为大量交织排列的弹性纤维，故有很好的弹性。由于弹性纤维丰富，使基质呈现一定程度的嗜酸性，仅软骨囊嗜碱性明显，因而在光镜下呈现红蓝相间的着色特点（图 4-3）。

:::definition{label="弹性软骨"}
弹性软骨（elastic cartilage）分布于耳郭、咽喉及会厌等处，新鲜时呈黄色。组织结构与透明软骨相似，但纤维成分为大量交织排列的弹性纤维，弹性很好。弹性纤维使基质呈一定程度嗜酸性，仅软骨囊嗜碱性明显，光镜下红蓝相间。
:::

### 3. 纤维软骨

纤维软骨（fibrous cartilage）分布于椎间盘、关节盘和耻骨联合等处，呈不透明的乳白色。大量粗大的胶原纤维平行或交叉排列，故有很强的韧性。软骨细胞较小而少，散在、成对或单行排列于纤维束之间，无定形基质少，呈弱嗜碱性（图 4-4）。

:::definition{label="纤维软骨"}
纤维软骨（fibrous cartilage）分布于椎间盘、关节盘和耻骨联合等处，呈不透明的乳白色。大量粗大胶原纤维平行或交叉排列，韧性很强。软骨细胞较小而少，散在、成对或单行排列于纤维束之间；无定形基质少，呈弱嗜碱性。
:::

:::compare{title="三种软骨"}
| 项目 | 透明软骨（hyaline cartilage） | 弹性软骨（elastic cartilage） | 纤维软骨（fibrous cartilage） |
|------|------------------------------|------------------------------|------------------------------|
| 新鲜外观 | 半透明 | 黄色 | 不透明乳白色 |
| 分布 | 肋软骨、关节软骨、呼吸道软骨等 | 耳郭、咽喉及会厌等 | 椎间盘、关节盘、耻骨联合等 |
| 主纤维 | Ⅱ型胶原蛋白构成的胶原原纤维，三维网格 | 大量交织的弹性纤维 | 粗大胶原纤维，平行或交叉 |
| 纤维能否在光镜下分辨 | 不能：直径仅 $10\sim 20\,\mathrm{nm}$，折光率接近基质 | 能：弹性纤维丰富 | 能：粗大胶原束非常明显 |
| 基质与染色 | 蛋白聚糖多，凝胶坚固；含水分较多 | 基质一定程度嗜酸性，仅软骨囊明显嗜碱性，红蓝相间 | 无定形基质少，弱嗜碱性 |
| 细胞 | 周边扁而单个，中部同源细胞群 $2\sim 8$ 个 | 与透明软骨相似 | 较小而少，散在、成对或单行排于纤维束之间 |
| 力学 | 抗压强，有一定弹性和韧性，较其他类型更易断裂 | 弹性很好 | 韧性很强 |
| 软骨膜 | 有（关节软骨除外） | 有 | 视部位而定；纤维成分占绝对优势 |
:::

:::tip{label="三种软骨的辨认口诀"}
- 看不见纤维、基质透亮嗜碱、中部同源细胞群 → 透明软骨（气管、肋、关节）。
- 红蓝相间、弹性纤维织网、耳郭会厌 → 弹性软骨。
- 粗胶原成束、细胞小而少夹在束间、椎间盘关节盘耻骨联合 → 纤维软骨。
:::

:::pitfall{label="透明软骨不是没有纤维，只是光镜下看不见"}
纤维极细（$10\sim 20\,\mathrm{nm}$）且折光率与基质接近，HE 里像一块均质嗜碱性凝胶。电镜下仍是Ⅱ型胶原原纤维织成的三维网格。不要写成“透明软骨无纤维”，也不要把纤维软骨的粗大Ⅰ型样胶原束套到气管软骨上。
:::

## （四）软骨的发生与生长

软骨来源于胚胎时期的间充质，在将要形成软骨的部位间充质细胞聚集增生，分化为骨祖细胞，后者再分化为成软骨细胞，继而进一步分化为软骨细胞。软骨周边的间充质分化为软骨膜。

出生后，软骨仍将随着身体的发育而继续生长。生长方式包括：①附加性生长，又称软骨膜下生长，由软骨膜深部的骨祖细胞增殖分化为成软骨细胞，后者再分化为软骨细胞生长在软骨组织表面，使软骨逐渐增厚；②间质性生长，又称软骨内生长，通过已有的软骨细胞生长增殖，产生更多的软骨细胞和软骨基质，使软骨从内部膨胀式生长。

:::definition{label="附加性生长"}
附加性生长又称软骨膜下生长：软骨膜深部的骨祖细胞增殖分化为成软骨细胞，再分化为软骨细胞，生长在软骨组织表面，使软骨逐渐增厚。
:::

:::definition{label="间质性生长"}
间质性生长又称软骨内生长：已有的软骨细胞生长增殖，产生更多的软骨细胞和软骨基质，使软骨从内部膨胀式生长。
:::

:::derivation{title="间充质如何写成一块有软骨膜的软骨"}
1. 将要形成软骨的部位，间充质细胞聚集增生。
2. 分化为骨祖细胞，再分化为成软骨细胞，继而成为软骨细胞。
3. 软骨细胞分泌软骨基质，自身被埋入陷窝，周边出现幼稚→中部成熟的梯度，并可形成同源细胞群。
4. 周边的间充质分化为软骨膜；膜内血管供应营养，内层骨祖细胞保留附加性生长的潜能。
:::

:::timeline{period="软骨从发生到出生后生长"}
- **胚胎** 间充质细胞聚集 → 骨祖细胞 → 成软骨细胞 → 软骨细胞；周边间充质 → 软骨膜
- **出生前** 软骨是主要支架，随后开始被骨取代（软骨内成骨，见第三节）
- **出生后** 仍继续生长：附加性生长使表面增厚，间质性生长使内部膨胀
- **成体** 仅散在保留软骨；关节软骨无软骨膜，不能按软骨膜下生长来理解
:::

:::compare{title="附加性生长与间质性生长"}
| 项目 | 附加性生长（软骨膜下生长） | 间质性生长（软骨内生长） |
|------|---------------------------|--------------------------|
| 细胞来源 | 软骨膜深部骨祖细胞 → 成软骨细胞 → 软骨细胞 | 已有的软骨细胞生长增殖 |
| 新组织加在何处 | 软骨组织表面 | 软骨内部 |
| 宏观效果 | 逐渐增厚 | 膨胀式增大 |
| 依赖软骨膜 | 依赖 | 不依赖软骨膜 |
| 关节软骨 | 无软骨膜，不能走这条路 | 内部仍可有细胞增殖与基质更新，但成体关节软骨再生能力有限 |
:::

:::theorem{label="软骨能从内部膨胀，骨不能"}
软骨细胞被凝胶状基质包埋，仍可分裂并分泌更多基质，故有间质性生长。骨细胞被钙化骨质锁在陷窝里，逐渐丧失分泌类骨质的能力，也不能分裂，骨组织不能从内部生长——加长只能走骺板，增粗只能走骨膜下成骨。这是下一节把骨和软骨分开记账的关键。
:::

:::keypoint{label="软骨先把细胞梯度、软骨囊和三型纤维立住"}
- 软骨 = 软骨组织 + 软骨膜（关节软骨无软骨膜）；软骨组织 = 软骨细胞 + 软骨基质。
- 周边幼稚、扁而单个；中部成熟、圆而成群（同源细胞群 $2\sim 8$ 个）。
- 软骨囊是陷窝周围硫酸软骨素多、嗜碱性强的基质，不是细胞膜。
- 无血管淋巴管，靠基质分子筛渗透交换；蛋白聚糖使基质成坚固凝胶。
- 三型：透明（Ⅱ型胶原原纤维光镜下不可见）、弹性（弹性纤维，红蓝相间）、纤维（粗胶原束，细胞少）。
- 发生自间充质；生长有附加性（膜下增厚）和间质性（内部膨胀）两种。
:::

:::memory{label="本节必背要点"}
- [ ] 软骨和骨来源于胚胎间充质，主体分别是软骨组织和骨组织，皆为高度特化的固态结缔组织；骨组织硬度远超软骨。
- [ ] 软骨（cartilage）= 软骨组织 + 软骨膜；软骨组织（cartilage tissue）= 软骨细胞 + 软骨基质。
- [ ] 软骨是胚胎早期主要支架，随胎儿发育逐渐被骨取代，取代延续到出生后一段时期；成体仅散在分布。
- [ ] 软骨细胞（chondrocyte）位于软骨陷窝（cartilage lacunae）；周边幼稚、小而扁、单个，长轴平行于表面；中部成熟、大而圆。
- [ ] 同源细胞群（isogenous group）：同一个幼稚软骨细胞增殖形成，一般为 $2\sim 8$ 个。
- [ ] 成熟软骨细胞胞质弱嗜碱性，粗面内质网和高尔基复合体丰富，产生软骨基质。
- [ ] 软骨基质 = 无定形基质（蛋白聚糖 + 水，分子筛）+ 包埋其中的纤维；蛋白聚糖远高于一般结缔组织，形成坚固凝胶。
- [ ] 软骨组织内无血管和淋巴管，深部细胞靠渗透与周围组织交换物质。
- [ ] 软骨囊（cartilage capsule）：紧靠陷窝处硫酸软骨素多，嗜碱性强，HE 中囊状包围软骨细胞。
- [ ] 除关节软骨外，表面有软骨膜（perichondrium）：薄层致密结缔组织，含血管、淋巴管、神经；内层骨祖细胞 → 成软骨细胞（chondroblast）。
- [ ] 成软骨细胞狭长，含核处略厚；被分泌的基质包围后成为软骨细胞。
- [ ] 透明软骨（hyaline cartilage）：半透明；肋软骨、关节软骨、呼吸道软骨；抗压强，较其他类型更易断裂。
- [ ] 透明软骨纤维为Ⅱ型胶原原纤维，直径 $10\sim 20\,\mathrm{nm}$，折光率接近基质，光镜下不能分辨；含水分较多是半透明原因之一。
- [ ] 弹性软骨（elastic cartilage）：耳郭、咽喉、会厌；新鲜黄色；大量弹性纤维；基质嗜酸、软骨囊嗜碱，红蓝相间。
- [ ] 纤维软骨（fibrous cartilage）：椎间盘、关节盘、耻骨联合；乳白不透明；粗大胶原纤维平行或交叉；细胞小而少，基质少、弱嗜碱。
- [ ] 发生：间充质细胞聚集 → 骨祖细胞 → 成软骨细胞 → 软骨细胞；周边间充质 → 软骨膜。
- [ ] 附加性生长（软骨膜下生长）：膜深部骨祖细胞 → 成软骨细胞 → 软骨细胞，加在表面使软骨增厚。
- [ ] 间质性生长（软骨内生长）：已有软骨细胞增殖，产生更多细胞和基质，内部膨胀式生长。
:::
