# 一、眼

眼和耳均为人体的特殊感觉装置，前者为视觉器官，后者为听觉及位觉器官。本章先把眼球壁三层、屈光装置和眼附属器摊开；耳的外耳、中耳、内耳及螺旋器、位觉斑、壶腹嵴另立一节。

:::definition{label="眼"}
眼是人体的视觉器官，由具有感光功能的眼球及其周围起辅助作用的附属器构成。
:::

:::definition{label="眼球"}
眼球近似圆球体。外壳为眼球壁，内有晶状体、玻璃体和房水等眼内容物（图 12-1～图 12-3）。
:::

:::definition{label="眼内容物"}
眼内容物包括晶状体、玻璃体和房水，均无色透明，与角膜共同组成眼的屈光系统。
:::

:::concept{term="先问哪一层感光，哪一层屈光，哪一层只是外壳"}
看见一张眼球切片，先把三本账拆开：纤维膜和血管膜是外壳与营养遮光层，本身不感光；视网膜视部才把光子写成神经冲动；角膜、房水、晶状体、玻璃体才是屈光。把“眼球壁”听成“都会看见”，视盘生理盲点和角膜无血管那两本账会一起错位。
:::

:::compare{title="眼球壁与眼内容物"}
| 项目 | 眼球壁 | 眼内容物 |
|------|--------|----------|
| 组成 | 外至内：纤维膜、血管膜、视网膜 | 房水、晶状体、玻璃体 |
| 主要职分 | 保护、营养遮光、感光 | 屈光；房水还营养晶状体和角膜、维持眼压 |
| 血管 | 纤维膜前部角膜无血管；血管膜富含血管 | 均无血管 |
| 本章位置 | 本节（一） | 本节（二） |
:::

## （一）眼球壁

眼球壁由外至内依次分为纤维膜、血管膜和视网膜 3 层。

:::definition{label="眼球壁"}
眼球壁由外至内依次分为纤维膜、血管膜和视网膜 3 层。纤维膜是致密结缔组织外壳，血管膜是富含血管和黑素细胞的营养遮光层，视网膜视部才是感光神经组织。
:::

:::compare{title="眼球壁三层"}
| 项目 | 纤维膜 | 血管膜 | 视网膜 |
|------|--------|--------|--------|
| 位置 | 最外 | 中层 | 最内 |
| 组织 | 致密结缔组织 | 富含血管和黑素细胞的疏松结缔组织 | 高度分化的神经组织（视部） |
| 分部 | 前 $1/6$ 角膜，后 $5/6$ 巩膜，移行处角膜缘 | 前至后：虹膜基质、睫状体基质、脉络膜 | 盲部（虹膜上皮、睫状体上皮）与视部，交界为锯齿缘 |
| 光镜第一眼 | 角膜透明分层；巩膜粗胶原、瓷白 | 棕黑，血管多 | 层次分明的核带；色素上皮一行立方 |
:::

### 1. 纤维膜

纤维膜主要由致密结缔组织构成，前 $1/6$ 为透明的角膜，后 $5/6$ 为白色的巩膜，两者的过渡区域称角膜缘。

:::definition{label="纤维膜"}
纤维膜主要由致密结缔组织构成。前 $1/6$ 为透明的角膜，后 $5/6$ 为白色的巩膜，两者的过渡区域称角膜缘。
:::

**（1）角膜** 角膜（cornea）为透明圆盘状结构，弯曲度大于眼球外壁的其他部分，故略向前方突出。角膜中央较薄，约 $0.5\,\mathrm{mm}$；周边较厚，约 $1.0\,\mathrm{mm}$。角膜内不含血管和淋巴管，营养由房水和角膜缘的血管以渗透方式供应。从前至后可将角膜分为 5 层（图 12-4）。

:::definition{label="角膜"}
角膜（cornea）为透明圆盘状结构，弯曲度大于眼球外壁其他部分，略向前方突出。中央约 $0.5\,\mathrm{mm}$，周边约 $1.0\,\mathrm{mm}$。不含血管和淋巴管，营养由房水和角膜缘血管以渗透方式供应。从前至后分为角膜上皮、前界层、角膜基质、后界层和角膜内皮 5 层。
:::

:::concept{term="先从外往里数角膜五层，再问为什么透明"}
角膜不是“一层透明上皮”。从外往里：未角化复层扁平上皮 → 无细胞前界层 → 占厚度约 $90\%$ 的角膜基质 → 更薄的后界层 → 单层扁平角膜内皮。透明账写在成分规则排列、富含水分、无血管、无黑素细胞上。把角膜听成“薄薄一层皮”，五层损伤深度和内皮失代偿那两本账都会做丢。
:::

**1）角膜上皮** 角膜上皮（corneal epithelium）为未角化的复层扁平上皮，其基部平坦，表面平整光滑，由 $5\sim 6$ 层排列整齐的细胞构成，无黑素细胞。上皮基底层为单层矮柱状细胞，具有一定增殖能力，中间为 $2\sim 3$ 层多边形细胞，表面 $1\sim 2$ 层为扁平细胞。上皮更新较快，平均 $7$ 天即可更新一次。上皮内有丰富的游离神经末梢，因此角膜感觉敏锐。

:::definition{label="角膜上皮"}
角膜上皮（corneal epithelium）是未角化的复层扁平上皮。基部平坦，表面平整光滑，由 $5\sim 6$ 层排列整齐的细胞构成，无黑素细胞。基底层为单层矮柱状细胞，有一定增殖能力；中间 $2\sim 3$ 层多边形细胞；表面 $1\sim 2$ 层扁平细胞。平均 $7$ 天更新一次。上皮内有丰富的游离神经末梢，故角膜感觉敏锐。
:::

**2）前界层** 前界层（anterior limiting lamina）为不含细胞的薄层结构，由胶原原纤维和基质构成。

:::definition{label="前界层"}
前界层（anterior limiting lamina）是不含细胞的薄层结构，由胶原原纤维和基质构成，位于角膜上皮与角膜基质之间。
:::

**3）角膜基质** 角膜基质（corneal stroma）又称固有层，约占角膜全厚度的 $90\%$，主要成分为多层与表面平行的胶原板层，含较多水分。胶原板层由大量胶原原纤维平行排列而成，相邻板层的纤维排列方向互相垂直（图 12-5）。扁平多突起的成纤维细胞散在分布于胶原板层之间，能产生基质和纤维，参与角膜损伤的修复。

:::definition{label="角膜基质"}
角膜基质（corneal stroma）又称固有层，约占角膜全厚度的 $90\%$。主要成分为多层与表面平行的胶原板层，含较多水分。每一板层内胶原原纤维平行排列，相邻板层纤维方向互相垂直。扁平多突起的成纤维细胞散在于板层之间，产生基质和纤维，参与损伤修复。
:::

**4）后界层** 后界层（posterior limiting lamina）结构类似前界层，但更薄。

:::definition{label="后界层"}
后界层（posterior limiting lamina）结构类似前界层，由胶原原纤维和基质构成、不含细胞，但更薄。位于角膜基质与角膜内皮之间。角膜内皮参与后界层的形成。
:::

**5）角膜内皮** 角膜内皮（corneal endothelium）为单层扁平上皮，参与后界层的形成。

:::definition{label="角膜内皮"}
角膜内皮（corneal endothelium）为单层扁平上皮，贴在角膜最内面，参与后界层的形成。
:::

角膜成分（特别是纤维）规则排列、富含水分、无血管和黑素细胞存在，是角膜透明的主要原因。

:::note{label="角膜透明的结构基础"}
| 条件 | 落点 |
|------|------|
| 纤维规则排列 | 基质内胶原原纤维平行成板层，相邻板层互相垂直 |
| 富含水分 | 基质含较多水分，维持折光均一 |
| 无血管 | 营养靠房水和角膜缘血管渗透，避免血管遮光 |
| 无黑素细胞 | 角膜上皮无黑素细胞，不引入色素 |
:::

:::compare{title="角膜五层"}
| 层次（外→内） | 英文 | 结构 | 细胞 | 要点 |
|----------------|------|------|------|------|
| 角膜上皮 | corneal epithelium | 未角化复层扁平，$5\sim 6$ 层 | 基底矮柱状，中层多边形，表层扁平 | 无黑素；约 $7$ 天更新；游离神经末梢丰富，感觉敏锐 |
| 前界层 | anterior limiting lamina | 薄层胶原原纤维 + 基质 | 无 | 上皮与基质的无细胞界层 |
| 角膜基质 | corneal stroma | 约占厚度 $90\%$ 的胶原板层，含水 | 扁平多突起成纤维细胞 | 板层内纤维平行，相邻板层垂直；修复靠成纤维细胞 |
| 后界层 | posterior limiting lamina | 类似前界层，更薄 | 无 | 内皮参与其形成 |
| 角膜内皮 | corneal endothelium | 单层扁平上皮 | 单层扁平 | 最内面，朝向前房 |
:::

:::pitfall{label="角膜上皮未角化，不要写成皮肤那种角化复层扁平"}
上一章厚皮角质层是干硬角质细胞。角膜上皮基部平坦、表面光滑，特意保持未角化，才能透明和快速更新。把角膜上皮写成“带角质层的皮肤”，透明账和 $7$ 天更新账都会写错；也不要把角膜内皮听成血管内皮——它是衬在角膜内面的单层扁平上皮，名字里的“内皮”是位置，不是循环系统那一层。
:::

**（2）巩膜** 巩膜（sclera）呈瓷白色，主要由大量粗大的胶原纤维交织而成，质地坚韧，是眼球壁的重要保护层。在与角膜交界处的内侧，巩膜向前内侧稍凸起，形成一环形嵴状突起，称巩膜距（scleral spur）（见图 12-2），是小梁网和睫状肌的附着部位。巩膜前部的外表面覆有球结膜，由复层扁平上皮和疏松结缔组织构成。

:::definition{label="巩膜"}
巩膜（sclera）呈瓷白色，主要由大量粗大的胶原纤维交织而成，质地坚韧，是眼球壁的重要保护层。前部外面覆球结膜（复层扁平上皮 + 疏松结缔组织）。
:::

:::definition{label="巩膜距"}
巩膜距（scleral spur）是巩膜在与角膜交界处内侧向前内侧稍凸起形成的环形嵴状突起，为小梁网和睫状肌的附着部位。
:::

:::definition{label="球结膜"}
球结膜覆盖巩膜前部外面，由复层扁平上皮和疏松结缔组织构成。睑结膜在结膜穹窿处移行为球结膜。
:::

:::pitfall{label="巩膜距是嵴，不是静脉窦"}
前房角附近有三件容易并成一个空洞的结构：巩膜距是胶原嵴，给小梁网和睫状肌提供附着；小梁网是网格，房水从这里滤过；巩膜静脉窦是衬内皮的环形管道，房水进静脉前的最后一站。把巩膜距写成“一条血管”，回流账会从附着点开始错。
:::

**（3）角膜缘** 角膜缘（corneal limbus）为角膜与巩膜的带状移行区域，宽 $1\sim 2\,\mathrm{mm}$。此处通常是临床眼球前部手术的入路之处（见图 12-2，图 12-6）。角膜缘上皮不同于角膜上皮和结膜上皮，其上皮较厚，细胞通常超过 $10$ 层，细胞较小，核深染。基底层细胞为矮柱状，排列成栅栏样。上皮内有黑素细胞，无杯状细胞。角膜缘基底层的细胞具有干细胞特征，称角膜缘干细胞（limbal stem cell），可通过增殖不断向角膜中央方向移行，补充角膜基底层细胞。故临床上可通过角膜缘移植治疗某些严重的眼球表面疾病。

角膜缘内侧有环行的巩膜静脉窦（scleral venous sinus）。在眼球矢状切面上，窦腔呈较大而不太规则的长条形，窦壁衬贴内皮。巩膜静脉窦内侧为网格状的小梁网（trabecular meshwork），由小梁和小梁间隙构成。小梁中央为胶原纤维，表面覆以内皮。小梁间隙与巩膜静脉窦相通，两者是房水回流的必经之路（见图 12-3，图 12-6）。

:::definition{label="角膜缘"}
角膜缘（corneal limbus）是角膜与巩膜的带状移行区域，宽 $1\sim 2\,\mathrm{mm}$，常为临床眼球前部手术入路。上皮较厚，通常超过 $10$ 层，细胞较小、核深染；基底层矮柱状、栅栏样排列；上皮内有黑素细胞，无杯状细胞。
:::

:::definition{label="角膜缘干细胞"}
角膜缘干细胞（limbal stem cell）是角膜缘基底层中具有干细胞特征的细胞，增殖后不断向角膜中央方向移行，补充角膜基底层细胞。临床上可通过角膜缘移植治疗某些严重的眼球表面疾病。
:::

:::definition{label="巩膜静脉窦"}
巩膜静脉窦（scleral venous sinus）位于角膜缘内侧，呈环行。矢状切面上窦腔较大而不太规则、呈长条形，窦壁衬贴内皮。它是房水进入静脉前的窦腔。
:::

:::definition{label="小梁网"}
小梁网（trabecular meshwork）位于巩膜静脉窦内侧，由小梁和小梁间隙构成。小梁中央为胶原纤维，表面覆以内皮。小梁间隙与巩膜静脉窦相通，两者是房水回流的必经之路。
:::

:::compare{title="角膜上皮、角膜缘上皮与结膜上皮"}
| 项目 | 角膜上皮 | 角膜缘上皮 | 结膜上皮 |
|------|----------|------------|----------|
| 层次 | 未角化复层扁平，$5\sim 6$ 层 | 较厚，通常超过 $10$ 层 | 睑结膜为复层柱状；球结膜为复层扁平 |
| 细胞大小与核 | 排列整齐 | 细胞较小，核深染 | 睑结膜有杯状细胞 |
| 黑素细胞 | 无 | 有 | 视部位而定 |
| 杯状细胞 | 无 | 无 | 睑结膜有 |
| 干细胞 | 基底层有一定增殖能力，补充靠角膜缘 | 角膜缘干细胞，向中央补充角膜 | — |
:::

:::insight{label="角膜中央能 7 天一换，种子却在角膜缘"}
角膜上皮自己会增殖，但教材把“不断向角膜中央移行、补充角膜基底层”写在角膜缘干细胞上。中央角膜受伤后若角膜缘被毁，种子没了，上皮覆盖账会停。角膜缘移植不是把透明角膜整片换掉，而是把这圈干细胞送回去。
:::

:::pitfall{label="小梁网和巩膜静脉窦是回流通道，不要写成分泌房水的地方"}
房水由睫状体的血液渗出和非色素上皮细胞分泌，在后房诞生。小梁网、巩膜静脉窦只负责从前房角把房水送进静脉。把这两处写成“产房水”，青光眼会变成“分泌过多”而不是回流受阻。
:::

### 2. 血管膜

血管膜主要由富含血管和黑素细胞的疏松结缔组织构成，从前向后依次为虹膜基质、睫状体基质和脉络膜。因虹膜基质和睫状体基质参与构成血管膜，故在此处介绍虹膜和睫状体。

:::definition{label="血管膜"}
血管膜主要由富含血管和黑素细胞的疏松结缔组织构成，从前向后依次为虹膜基质、睫状体基质和脉络膜。棕黑色，兼营养视网膜外层和遮光。
:::

**（1）虹膜** 虹膜（iris）是位于角膜和晶状体之间的圆环状薄膜，周边与睫状体相连，中央为圆形的瞳孔。虹膜将眼房分隔为前房和后房，前、后房内的房水借瞳孔相通。虹膜直径约为 $12\,\mathrm{mm}$，厚度约 $0.5\,\mathrm{mm}$，近瞳孔缘处较厚，周边较薄。虹膜由前向后分 3 层，即前缘层（anterior border layer）、虹膜基质（iris stroma）和虹膜上皮（iris epithelium）。

前缘层为一层不连续的成纤维细胞和黑素细胞。虹膜基质较厚，为富含血管和黑素细胞的疏松结缔组织。黑素细胞的形态不规则，有突起，细胞质内充满黑素颗粒。在靠近瞳孔缘的虹膜基质中有围绕瞳孔环行排列的平滑肌，收缩时使瞳孔缩小，故称瞳孔括约肌（sphincter pupillae muscle）。虹膜上皮由前、后两层细胞组成。前层为肌上皮细胞，以瞳孔为中心呈放射状分布，称瞳孔开大肌（dilator pupillae muscle），收缩时使瞳孔开大。后层细胞较大，呈立方形，细胞质内充满黑素颗粒（见图 12-2、图 12-6，图 12-7）。

:::definition{label="虹膜"}
虹膜（iris）位于角膜和晶状体之间，为圆环状薄膜，周边连睫状体，中央为瞳孔。直径约 $12\,\mathrm{mm}$，厚度约 $0.5\,\mathrm{mm}$，近瞳孔缘较厚、周边较薄。它把眼房分成前房和后房，房水借瞳孔相通。由前向后分前缘层、虹膜基质和虹膜上皮 3 层。
:::

:::definition{label="前房与后房"}
虹膜将眼房分隔为前房和后房。前房在角膜与虹膜之间，后房在虹膜与晶状体、睫状体之间。前、后房内的房水借瞳孔相通。
:::

:::definition{label="前缘层"}
前缘层（anterior border layer）是虹膜最前面一层不连续的成纤维细胞和黑素细胞。
:::

:::definition{label="虹膜基质"}
虹膜基质（iris stroma）较厚，为富含血管和黑素细胞的疏松结缔组织。黑素细胞形态不规则、有突起，胞质充满黑素颗粒。靠近瞳孔缘的基质中有瞳孔括约肌。
:::

:::definition{label="瞳孔括约肌"}
瞳孔括约肌（sphincter pupillae muscle）位于靠近瞳孔缘的虹膜基质中，为围绕瞳孔环行排列的平滑肌，收缩时使瞳孔缩小。
:::

:::definition{label="虹膜上皮"}
虹膜上皮（iris epithelium）由前、后两层细胞组成。前层为肌上皮细胞，构成瞳孔开大肌；后层细胞较大、立方形，胞质充满黑素颗粒。
:::

:::definition{label="瞳孔开大肌"}
瞳孔开大肌（dilator pupillae muscle）是虹膜上皮前层的肌上皮细胞，以瞳孔为中心呈放射状分布，收缩时使瞳孔开大。
:::

:::compare{title="瞳孔括约肌与瞳孔开大肌"}
| 项目 | 瞳孔括约肌 | 瞳孔开大肌 |
|------|------------|------------|
| 位置 | 靠近瞳孔缘的虹膜基质 | 虹膜上皮前层 |
| 细胞性质 | 平滑肌 | 肌上皮细胞 |
| 排列 | 环行，围绕瞳孔 | 放射状，以瞳孔为中心 |
| 收缩效应 | 瞳孔缩小 | 瞳孔开大 |
| 光镜线索 | 图 12-3 虹膜近瞳孔缘的肌束（↑） | 图 12-2 示于上皮前层 |
:::

:::pitfall{label="括约肌在基质，开大肌在上皮，不要写成两块同样的平滑肌"}
缩瞳那一圈是基质里的环行平滑肌；开大那一层是上皮前层改写成的肌上皮，放射状铺开。后层立方上皮装满黑素，管的是遮光，不是舒缩。把开大肌也记成“基质里的平滑肌”，虹膜三层账会在上皮这一层塌掉。
:::

**（2）睫状体** 睫状体（ciliary body）介于虹膜与脉络膜之间，为具有伸缩功能的环带状结构，在眼球矢状切面上大致呈三角形。前部较宽大，并向前内侧增厚形成许多突起，后部渐平坦，终止于锯齿缘。睫状体由睫状肌、基质和上皮组成（见图 12-2、图 12-3、图 12-6）。

睫状肌（ciliary muscle）为平滑肌，是睫状体的主要组成成分。肌纤维有环行、放射状和纵行 3 种走向。环行的肌纤维分布于睫状体前部，放射状和纵行的肌纤维起点为巩膜距，分别止于睫状体内侧份和后端的脉络膜。睫状体基质为富含血管和黑素细胞的结缔组织。上皮由两层细胞组成，外层为立方形色素上皮细胞；内层为矮柱状非色素上皮细胞，可分泌房水，并产生构成睫状小带和玻璃体的生化成分。

睫状体的前内侧伸出约 $70$ 个呈放射状排列的睫状突（ciliary process），通过大量睫状小带与晶状体相连。睫状小带（ciliary zonule）呈细丝状，由微原纤维借蛋白聚糖黏合而成。睫状小带一端连于睫状体，一端插入晶状体囊内，将晶状体悬吊于虹膜与玻璃体之间。睫状肌收缩时，睫状体突向前方内侧，睫状小带松弛；反之，则睫状小带紧张，借此改变晶状体的位置和曲度，从而调节焦距。

:::definition{label="睫状体"}
睫状体（ciliary body）介于虹膜与脉络膜之间，为具有伸缩功能的环带状结构，矢状切面大致呈三角形。前部宽大，向前内侧增厚成许多突起；后部渐平坦，止于锯齿缘。由睫状肌、基质和上皮组成。
:::

:::definition{label="睫状肌"}
睫状肌（ciliary muscle）为平滑肌，是睫状体的主要组成成分。肌纤维有环行、放射状和纵行 3 种走向：环行分布于睫状体前部；放射状和纵行起于巩膜距，分别止于睫状体内侧份和后端的脉络膜。
:::

:::definition{label="睫状体上皮"}
睫状体上皮由两层细胞组成：外层为立方形色素上皮细胞；内层为矮柱状非色素上皮细胞。非色素上皮可分泌房水，并产生构成睫状小带和玻璃体的生化成分。
:::

:::definition{label="睫状突"}
睫状突（ciliary process）是睫状体前内侧伸出的约 $70$ 个放射状突起，通过大量睫状小带与晶状体相连。
:::

:::definition{label="睫状小带"}
睫状小带（ciliary zonule）呈细丝状，由微原纤维借蛋白聚糖黏合而成。一端连于睫状体，一端插入晶状体囊内，将晶状体悬吊于虹膜与玻璃体之间。
:::

:::concept{term="先问睫状肌缩还是松，再问晶状体变凸还是变扁"}
调节焦距不是晶状体自己会变，而是睫状肌改写小带张力。肌收缩 → 睫状体突向前内 → 小带松弛 → 晶状体依弹性变凸，适合看近；肌舒张 → 小带紧张 → 晶状体被拉扁，适合看远。把“看近”写成“睫状肌放松”，小带和晶状体囊那一本账会反号。
:::

:::note{label="睫状肌与焦距"}
| 睫状肌 | 睫状体 | 睫状小带 | 晶状体 | 适合 |
|--------|--------|----------|--------|------|
| 收缩 | 突向前方内侧 | 松弛 | 位置和曲度改变，依弹性变凸 | 看近 |
| 舒张 | 复位 | 紧张 | 被拉、曲度减小 | 看远 |
:::

:::insight{label="非色素上皮一身兼三职：房水、小带、玻璃体成分"}
睫状体内层矮柱状细胞不产色素，却分泌房水，还产出构成睫状小带和玻璃体的生化成分。把“产房水”只记在血管渗出上，会漏掉这层上皮；把小带听成“平滑肌肌腱”，又会漏掉微原纤维和蛋白聚糖。
:::

**（3）脉络膜** 脉络膜（choroid）是血管膜的后 $2/3$ 部分，充填于巩膜与视网膜之间，为富含血管和大量黑素细胞的疏松结缔组织，呈棕黑色。与视网膜相贴的最内层为一均质透明的薄膜，称玻璃膜，由纤维和基质组成（图 12-8）。

:::definition{label="脉络膜"}
脉络膜（choroid）是血管膜的后 $2/3$，充填于巩膜与视网膜之间，为富含血管和大量黑素细胞的疏松结缔组织，呈棕黑色，营养视网膜外层并遮光。
:::

:::definition{label="玻璃膜"}
玻璃膜是脉络膜与视网膜相贴的最内层，为均质透明的薄膜，由纤维和基质组成。色素上皮基底面紧贴此膜。
:::

:::compare{title="虹膜、睫状体与脉络膜"}
| 项目 | 虹膜 | 睫状体 | 脉络膜 |
|------|------|--------|--------|
| 位置 | 最前，角膜与晶状体之间 | 虹膜与脉络膜之间，止于锯齿缘 | 血管膜后 $2/3$，巩膜与视网膜之间 |
| 外形 | 圆环状薄膜，中央瞳孔 | 环带，矢状面三角形，约 $70$ 个睫状突 | 棕黑膜 |
| 特有结构 | 瞳孔括约肌、瞳孔开大肌 | 睫状肌三走向、睫状小带 | 玻璃膜 |
| 上皮 | 前层肌上皮 + 后层含黑素立方 | 外层色素立方 + 内层非色素矮柱状 | 无自身上皮；内侧贴视网膜色素上皮 |
| 功能侧重 | 调节瞳孔，分隔前、后房 | 调节焦距；分泌房水；产小带和玻璃体成分 | 营养视网膜外层，遮光 |
:::

:::pitfall{label="玻璃膜是脉络膜最内层，不要和玻璃体混成一个词"}
玻璃膜（脉络膜内面那层均质薄膜）和玻璃体（晶状体后方的胶状屈光体）只共用“玻璃”二字。色素上皮贴的是玻璃膜；屈光系统里占 $99\%$ 水分的是玻璃体。名词一混，血管膜和眼内容物两本账会对错层。
:::

### 3. 视网膜

视网膜（retina）位于眼球壁最内层，分为盲部与视部，两者交界处呈锯齿状，称锯齿缘。盲部包括虹膜上皮和睫状体上皮，视部为感光的部位，即通常所称的视网膜。下文所述为视网膜视部。视网膜主要为高度分化的神经组织，由外向内依次是色素上皮层、视细胞层、双极细胞层和节细胞层（图 12-8，图 12-9），后 3 层又统称为神经层。

:::definition{label="视网膜"}
视网膜（retina）位于眼球壁最内层，分为盲部与视部。交界处呈锯齿状，称锯齿缘。盲部包括虹膜上皮和睫状体上皮；视部为感光部位，即通常所称的视网膜。
:::

:::definition{label="锯齿缘"}
锯齿缘是视网膜盲部与视部的交界，呈锯齿状。睫状体后部平坦，终止于此。
:::

:::definition{label="视网膜视部四层"}
视部由外向内依次为色素上皮层、视细胞层、双极细胞层和节细胞层。后 3 层统称神经层。教材按这四层立功能账；光镜下还可按核带和膜把神经层再拆成十层（见下表）。
:::

:::concept{term="先问这一层是色素上皮还是神经层，视杆还是视锥"}
视网膜最外面一行立方、装满黑素的是色素上皮，贴玻璃膜，不产生冲动。往内才是视细胞把光子写成化学信号，双极细胞纵向传递，节细胞把轴突汇成视神经。视杆管弱光、视锥管强光和颜色。把色素上皮听成“第一级神经元”，或把视盘那块无感光区当成黄斑，感光账会从第一眼就反。
:::

**（1）色素上皮层** 是由色素上皮细胞（pigment epithelial cell）构成的单层立方上皮，基底面紧贴玻璃膜。细胞顶部有大量突起伸入视细胞的外节之间。细胞质内含大量粗大的黑素颗粒和吞噬体。黑素颗粒可防止强光对视细胞的损害，吞噬体内通常为视杆细胞脱落的膜盘，表明色素上皮细胞可参与视细胞外节的更新。细胞侧面有紧密连接。视网膜色素上皮有多方面的功能，如保护视细胞、稳定视网膜的内环境、贮存维生素 A，以及营养神经层和吞噬视细胞脱落物等。

:::definition{label="色素上皮细胞"}
色素上皮细胞（pigment epithelial cell）构成单层立方上皮，基底面紧贴玻璃膜，顶部大量突起伸入视细胞外节之间。胞质含大量粗大黑素颗粒和吞噬体；侧面有紧密连接。
:::

:::definition{label="色素上皮的功能"}
视网膜色素上皮可：保护视细胞（黑素颗粒防止强光损害）；稳定视网膜内环境；贮存维生素 A；营养神经层；吞噬视细胞脱落物（吞噬体内通常为视杆细胞脱落的膜盘，参与外节更新）。
:::

:::pitfall{label="色素上皮有紧密连接，不要把它写成“能随便漏光漏液的一行色素”"}
侧面紧密连接把神经层的微环境关住，顶部突起伸进外节之间去吞噬膜盘、挡住强光。它是屏障和保姆，不是感光神经元。夜盲账的维生素 A 也贮在这里，缺了先伤视杆。
:::

**（2）视细胞层** 视细胞（visual cell）是感受光线的感觉神经元，又称感光细胞（photoreceptor cell），分为胞体、外突和内突 3 部分。胞体是细胞核所在部位，略微膨大，众多胞体密集排列成多层，构成视细胞层。外突垂直伸向色素上皮细胞，中段有一缩窄将其分为内节和外节，缩窄处的内部为纤毛样构造，称连接纤毛（connecting cilium）。内节（inner segment）紧邻胞体，含丰富的线粒体、粗面内质网和高尔基复合体，是合成感光蛋白的部位，感光物质经缩窄处转移到外节。外节（outer segment）为感光部位，含有大量平行层叠的扁平状膜盘（membranous disc），它们是由外节基部一侧的细胞膜向细胞质内陷形成（图 12-10），膜中有能感光的镶嵌蛋白。内突末端主要与双极细胞形成突触联系。根据外突形状和感光性质不同，视细胞分为视杆细胞和视锥细胞。

:::definition{label="视细胞"}
视细胞（visual cell）即感光细胞（photoreceptor cell），是感受光线的感觉神经元，分胞体、外突和内突 3 部分。胞体核略膨大，密集排成视细胞层。外突伸向色素上皮，缩窄分成内节与外节；内突末端主要与双极细胞形成突触。
:::

:::definition{label="连接纤毛"}
连接纤毛（connecting cilium）是外突中段缩窄处内部的纤毛样构造，内节合成的感光物质经此处转移到外节。
:::

:::definition{label="内节"}
内节（inner segment）紧邻胞体，含丰富的线粒体、粗面内质网和高尔基复合体，是合成感光蛋白的部位。
:::

:::definition{label="外节"}
外节（outer segment）是感光部位，含大量平行层叠的扁平状膜盘。膜盘由外节基部一侧细胞膜向胞质内陷形成，膜中有能感光的镶嵌蛋白。
:::

:::definition{label="膜盘"}
膜盘（membranous disc）是外节内平行层叠的扁平膜结构，由外节基部质膜内陷形成，膜中镶嵌感光蛋白。视杆的膜盘与表面胞膜分离而独立，并不断更新脱落；视锥的膜盘大多与细胞膜不分离，顶端也不脱落。
:::

::figure{src="/images/histology/textbook/p0140_03.png" caption="图12-10 视锥和视杆外节超微结构模式图。A. 视锥；B. 视杆。示外节、内节、连接纤毛；视锥膜盘多与细胞膜连续，视杆膜盘与表面胞膜分离。" alt="视锥与视杆外节对照：膜盘叠层、连接纤毛和内节"}

**1）视杆细胞** 视杆细胞（rod cell）主要分布在视网膜的周围部，感受弱光，其数量远远多于视锥细胞。视杆细胞较细长，核较小、染色较深，外突呈杆状（视杆），内突末端膨大呈小球状。膜盘与细胞表面胞膜分离而独立。每个视杆细胞可有数百至上千个膜盘。膜盘不断更新，由外节基部向顶端推移，顶端的膜盘则老化脱落，被色素上皮细胞吞噬消化。膜盘上的感光蛋白称视紫红质，由 11-顺式视黄醛和视蛋白组成。维生素 A 是合成 11-顺式视黄醛的原料，当人体维生素 A 不足时，视紫红质缺乏，导致弱光视力减退，即夜盲症。

:::definition{label="视杆细胞"}
视杆细胞（rod cell）主要分布在视网膜周围部，感受弱光，数量远多于视锥细胞。细胞较细长，核较小、染色较深；外突呈杆状，内突末端膨大呈小球状。
:::

:::definition{label="视紫红质"}
视紫红质是视杆细胞膜盘上的感光蛋白，由 11-顺式视黄醛和视蛋白组成。维生素 A 是合成 11-顺式视黄醛的原料。维生素 A 不足 → 视紫红质缺乏 → 弱光视力减退，即夜盲症。
:::

:::definition{label="夜盲症"}
夜盲症是维生素 A 不足导致视紫红质缺乏、弱光视力减退的临床表现。病在视杆，不在视锥。
:::

**2）视锥细胞** 视锥细胞（cone cell）主要分布在视网膜中部，感受强光和颜色。细胞外形较视杆细胞粗大，核较大，染色较浅，外突呈圆锥形（视锥），内突末端膨大呈足状。视锥细胞外节的膜盘大多与细胞膜不分离，顶端膜盘也不脱落。其感光物质称视色素（visual pigment），也由 11-顺式视黄醛和视蛋白组成，但视蛋白的结构与视紫红质不同。视锥细胞有 3 种功能类型，分别含有红敏色素、绿敏色素和蓝敏色素，如缺少感红光（或绿光）的视锥细胞，则不能分辨红（或绿）色，为红（或绿）色盲。

:::definition{label="视锥细胞"}
视锥细胞（cone cell）主要分布在视网膜中部，感受强光和颜色。外形较视杆粗大，核较大、染色较浅；外突呈圆锥形，内突末端膨大呈足状。外节膜盘大多与细胞膜不分离，顶端膜盘也不脱落。
:::

:::definition{label="视色素"}
视色素（visual pigment）是视锥细胞的感光物质，由 11-顺式视黄醛和视蛋白组成，视蛋白结构与视紫红质不同。视锥分 3 种功能类型，分别含红敏、绿敏和蓝敏色素。
:::

:::definition{label="色盲"}
缺少感红光（或绿光）的视锥细胞，则不能分辨红（或绿）色，为红（或绿）色盲。病在某种视锥，不在视杆。
:::

:::compare{title="视杆细胞与视锥细胞"}
| 项目 | 视杆细胞 | 视锥细胞 |
|------|----------|----------|
| 英文 | rod cell | cone cell |
| 主要分布 | 视网膜周围部 | 视网膜中部；中央凹只有视锥 |
| 功能 | 感受弱光 | 感受强光和颜色 |
| 数量 | 远多于视锥 | 较少 |
| 外形 | 较细长；外突杆状；内突末端小球状 | 较粗大；外突圆锥形；内突末端足状 |
| 核 | 较小，染色较深 | 较大，染色较浅 |
| 膜盘 | 与表面胞膜分离；数百至上千个；基部新生、顶端脱落，被色素上皮吞噬 | 大多与细胞膜不分离；顶端不脱落 |
| 感光蛋白 | 视紫红质（11-顺式视黄醛 + 视蛋白） | 视色素（11-顺式视黄醛 + 另一种视蛋白）；红、绿、蓝三型 |
| 缺乏时 | 维生素 A 不足 → 夜盲 | 缺某型视锥 → 红/绿色盲 |
:::

:::pitfall{label="夜盲找视杆和维生素 A，色盲找视锥类型，不要并成“视力不好”"}
两种细胞都用 11-顺式视黄醛，差别在视蛋白和外节膜盘是否脱落。夜盲是弱光系统的原料不足；色盲是某一种视锥缺席。中央凹只有视锥、没有视杆，所以黄昏看细字要靠周围视网膜的视杆——不要以为“黄斑最敏锐”等于“哪里都最敏锐”。
:::

**（3）双极细胞层** 主要由双极细胞（bipolar cell）的胞体构成。双极细胞是连接视细胞和节细胞的纵向中间神经元。其树突与视细胞的内突形成突触，轴突与节细胞的树突形成突触，分别构成外网层和内网层。大多数双极细胞可与多个视细胞和节细胞形成突触联系；但也有少数细胞只与一个视锥细胞和一个节细胞联系，称侏儒双极细胞（midget bipolar cell），它们位于视网膜中央凹边缘。

在双极细胞层还有以下 3 种中间神经元：

水平细胞（horizontal cell）：胞体位于双极细胞层外侧部，其突起呈水平走行，与视杆细胞、双极细胞及网间细胞的突起形成突触，相邻的水平细胞之间有缝隙连接。

无长突细胞（amacrine cell）：位于双极细胞层内侧部，有 $2\sim 3$ 层，胞体较大，突起兼有树突和轴突的特点，与双极细胞的轴突、节细胞树突及网间细胞的突起形成突触。

网间细胞（interplexiform cell）：胞体位于无长突细胞之间，突起向周围广泛伸展，与无长突细胞和水平细胞形成突触。中间神经元通过广泛的突触连接构成局部环路，参与视觉信号的传导和调控。

:::definition{label="双极细胞"}
双极细胞（bipolar cell）是连接视细胞和节细胞的纵向中间神经元。树突与视细胞内突形成突触（外网层），轴突与节细胞树突形成突触（内网层）。大多数可与多个视细胞和节细胞联系。
:::

:::definition{label="外网层与内网层"}
外网层是视细胞内突与双极细胞树突（以及水平细胞突起）形成突触的层次。内网层是双极细胞轴突与节细胞树突（以及无长突细胞突起）形成突触的层次。
:::

:::definition{label="侏儒双极细胞"}
侏儒双极细胞（midget bipolar cell）只与一个视锥细胞和一个节细胞联系，位于视网膜中央凹边缘，为一对一精确传导提供中间站。
:::

:::definition{label="水平细胞"}
水平细胞（horizontal cell）胞体位于双极细胞层外侧部，突起水平走行，与视杆细胞、双极细胞及网间细胞的突起形成突触；相邻水平细胞之间有缝隙连接。
:::

:::definition{label="无长突细胞"}
无长突细胞（amacrine cell）位于双极细胞层内侧部，有 $2\sim 3$ 层，胞体较大。突起兼有树突和轴突的特点，与双极细胞轴突、节细胞树突及网间细胞突起形成突触。
:::

:::definition{label="网间细胞"}
网间细胞（interplexiform cell）胞体位于无长突细胞之间，突起向周围广泛伸展，与无长突细胞和水平细胞形成突触。与水平细胞、无长突细胞一起，通过局部环路参与视觉信号的传导和调控。
:::

:::compare{title="双极细胞层中的纵向通道与横向环路"}
| 细胞 | 位置 | 联系 | 职分 |
|------|------|------|------|
| 双极细胞 | 本层主体 | 视细胞 ↔ 节细胞 | 纵向传递 |
| 侏儒双极细胞 | 中央凹边缘 | 一个视锥 ↔ 一个节细胞 | 一对一精确传导 |
| 水平细胞 | 本层外侧部 | 视杆、双极、网间；细胞间缝隙连接 | 外网层横向整合 |
| 无长突细胞 | 本层内侧部，$2\sim 3$ 层 | 双极轴突、节细胞树突、网间 | 内网层横向整合 |
| 网间细胞 | 无长突细胞之间 | 无长突、水平细胞 | 沟通内、外网层环路 |
:::

**（4）节细胞层** 由节细胞（ganglion cell）的胞体构成，大多排列成单层。节细胞为长轴突的多极神经元，其树突主要与双极细胞形成突触，轴突在视网膜内表面形成密集的视神经纤维层，并向眼球后极汇聚，穿出眼球壁构成视神经。大多数节细胞胞体较大，与多个双极细胞形成突触联系；少数为胞体较小的侏儒节细胞（midget ganglion cell），只和一个侏儒双极细胞联系，也位于视网膜中央凹边缘。

节细胞层中还有少数特殊的非成像性感光细胞，称内在光敏感视神经节细胞（intrinsically photosensitive retinal ganglion cell，ipRGC），其感光色素为视黑蛋白（melanopsin），也称视黑素。ipRGC 的轴突主要投射到视交叉上核、橄榄顶盖前核等脑区，参与调控昼夜节律、瞳孔对光反射等非成像视觉功能。

:::definition{label="节细胞"}
节细胞（ganglion cell）为长轴突的多极神经元，胞体构成节细胞层，大多排成单层。树突主要与双极细胞形成突触；轴突在视网膜内表面形成视神经纤维层，向后极汇聚，穿出眼球壁构成视神经。
:::

:::definition{label="侏儒节细胞"}
侏儒节细胞（midget ganglion cell）胞体较小，只和一个侏儒双极细胞联系，位于视网膜中央凹边缘。与侏儒双极细胞、中央凹视锥一起，构成一对一的精确通路。
:::

:::definition{label="视神经纤维层"}
视神经纤维层是节细胞轴突在视网膜内表面形成的密集纤维层，向眼球后极汇聚后穿出眼球壁，构成视神经。
:::

:::definition{label="内在光敏感视神经节细胞"}
内在光敏感视神经节细胞（ipRGC）是节细胞层中少数非成像性感光细胞，感光色素为视黑蛋白（melanopsin，也称视黑素）。轴突主要投射到视交叉上核、橄榄顶盖前核等脑区，调控昼夜节律、瞳孔对光反射等非成像视觉功能。
:::

:::pitfall{label="ipRGC 感光但不成像，不要把它写成第四种视锥"}
视杆、视锥在视细胞层成像；ipRGC 在节细胞层，用视黑蛋白感受亮度，去对生物钟和瞳孔，不参与“看见图像”。缺少红敏视锥是色盲，不是昼夜节律紊乱。
:::

与其他部位的神经组织一样，视网膜中也有神经胶质细胞分布，如放射状胶质细胞、星形胶质细胞和小胶质细胞，但一般没有少突胶质细胞。放射状胶质细胞（radial neuroglia cell）又称米勒细胞（Müller cell），为视网膜特有的胶质细胞。细胞狭长，几乎贯穿神经层。细胞核位于双极细胞层，宽大的叶片状突起伸展于神经元之间。细胞内外两侧的突起末端常膨大分叉，外侧端于视细胞内节处相互连接构成连续性保护膜。内侧端于视网膜内表面相互连接形成胶质界膜。放射状胶质细胞具有营养、支持、绝缘和保护等作用。

:::definition{label="米勒细胞"}
米勒细胞（Müller cell）即放射状胶质细胞（radial neuroglia cell），是视网膜特有的胶质细胞。细胞狭长，几乎贯穿神经层；核位于双极细胞层；叶片状突起伸于神经元之间。外侧端于视细胞内节处互连成连续性保护膜（外界膜），内侧端于内表面互连成胶质界膜（内界膜）。功能为营养、支持、绝缘和保护。
:::

:::note{label="视网膜一般没有少突胶质细胞"}
视网膜胶质包括米勒细胞、星形胶质细胞和小胶质细胞，一般没有少突胶质细胞。节细胞轴突在眼球内以视神经纤维层走行，出眼球后才由视神经成鞘。不要把纤维层里的轴突写成“已经有髓的视神经”。
:::

:::compare{title="视网膜四层功能账与光镜十层"}
| 外→内（十层） | 主要结构 | 归入教材四层 |
|----------------|----------|----------------|
| 1. 色素上皮层 | 单层立方色素上皮 | 色素上皮层 |
| 2. 视杆视锥层 | 外节、内节、膜盘 | 视细胞层（外突） |
| 3. 外界膜 | 米勒细胞外侧端于内节处互连的保护膜 | 神经层胶质 |
| 4. 外核层 | 视细胞核 | 视细胞层（胞体） |
| 5. 外网层 | 视细胞内突与双极/水平细胞突触 | 视细胞–双极交界 |
| 6. 内核层 | 双极、水平、无长突、网间及米勒细胞核 | 双极细胞层 |
| 7. 内网层 | 双极轴突与节细胞/无长突突触 | 双极–节细胞交界 |
| 8. 节细胞层 | 节细胞胞体 | 节细胞层 |

:::

:::insight{label="四层是功能通道，十层是光镜核带"}
教材用色素上皮 → 视细胞 → 双极细胞 → 节细胞把光子写成视神经冲动。切片上看到的是核深的外核层、内核层、节细胞层，加上两侧网层和两层界膜。考试若问“视网膜有几层”，先看题干要的是功能四层还是光镜十层，不要把两把尺子拧成一句。
:::

黄斑（macula lutea）是视网膜后极的一浅黄色区域，正对视轴处，呈横向椭圆形，直径 $1\sim 3\,\mathrm{mm}$，其中央有一浅凹，称中央凹（central fovea）。中央凹为视网膜最薄的部分，厚度仅 $0.1\,\mathrm{mm}$，只有色素上皮细胞和视锥细胞。其视锥细胞与侏儒双极细胞之间，以及侏儒双极细胞与侏儒节细胞之间均形成一对一联系，能精确地传导信号。此处的双极细胞和节细胞均向外周倾斜，从而形成一局部凹陷，故光线可直接落在视锥细胞上。因此，中央凹是视觉最敏锐的部位（图 12-11）。

视神经乳头（papilla of optic nerve）又称视盘（optic disc），位于黄斑鼻侧，圆盘状，呈乳头状隆起，中央略凹。所有节细胞的轴突在此处汇集，并穿出眼球壁形成视神经。此处无感光细胞，为生理盲点。视网膜中央动脉和中央静脉也在此穿过（图 12-12）。视神经将信息传入大脑枕叶的视觉中枢，产生视觉。

:::definition{label="黄斑"}
黄斑（macula lutea）是视网膜后极正对视轴的浅黄色区域，呈横向椭圆形，直径 $1\sim 3\,\mathrm{mm}$。中央有浅凹，即中央凹。
:::

:::definition{label="中央凹"}
中央凹（central fovea）是黄斑中央的浅凹，为视网膜最薄处，厚度仅 $0.1\,\mathrm{mm}$，只有色素上皮细胞和视锥细胞。视锥、侏儒双极细胞、侏儒节细胞一对一联系；双极细胞和节细胞向外周倾斜，光线直接落在视锥上。中央凹是视觉最敏锐的部位。
:::

:::definition{label="视盘"}
视神经乳头（papilla of optic nerve）又称视盘（optic disc），位于黄斑鼻侧，圆盘状、乳头状隆起，中央略凹。节细胞轴突在此汇集穿出，形成视神经；视网膜中央动、静脉也在此穿过。此处无感光细胞，为生理盲点。
:::

:::definition{label="生理盲点"}
生理盲点即视盘所在处：无感光细胞，光线落在这里不能形成视觉。它不是病变，是轴突出门的位置。
:::

:::compare{title="中央凹与视盘"}
| 项目 | 中央凹 | 视盘（视神经乳头） |
|------|--------|-------------------|
| 位置 | 黄斑中央，正对视轴 | 黄斑鼻侧 |
| 厚度 | 视网膜最薄，$0.1\,\mathrm{mm}$ | 乳头状隆起，中央略凹 |
| 感光细胞 | 只有视锥（无视杆） | 无感光细胞 |
| 传导 | 视锥–侏儒双极–侏儒节细胞一对一 | 节细胞轴突在此汇集出眼球 |
| 功能含义 | 视觉最敏锐 | 生理盲点；视神经及视网膜中央动、静脉出入 |
:::

:::pitfall{label="最敏锐的是中央凹，盲点是视盘，不要把黄斑和视神经乳头写成同一个圆点"}
检眼镜里后极有两个标志：正对视轴的浅黄区是黄斑，中央凹在它正中；鼻侧那团圆盘是视盘，轴突和血管从这里进出。把视盘当成“看东西最清楚的地方”，会把盲点写成敏锐点。
:::

## （二）眼内容物

包括房水、晶状体和玻璃体，均无色透明，与角膜共同组成眼的屈光系统。

:::definition{label="眼的屈光系统"}
眼的屈光系统由角膜与眼内容物（房水、晶状体、玻璃体）共同组成。四者均无色透明，把外来光线聚焦到视网膜上。晶状体是其中最重要的屈光装置，充当生物透镜。
:::

### 1. 晶状体

晶状体（lens）为具有弹性的双凸透明体，是眼球中最重要的屈光装置，充当生物透镜。晶状体前面略平，后面较凸，两面交界处为赤道部。晶状体外包晶状体囊（lens capsule），是由基膜和胶原原纤维等构成的薄层结构。晶状体实质分为外周的皮质和中央的晶状体核（lens nucleus）。皮质的前表面有一层立方形细胞构成的晶状体上皮。在赤道部，细胞逐渐变成长柱状，称晶状体纤维（lens fiber），呈环层状排列。新形成的纤维构成皮质，陈旧的纤维被推向中心，细胞核逐渐消失，含水量减少，参与构成晶状体核（见图 12-2，图 12-13，图 12-14）。晶状体内无血管和神经，靠房水供给营养。老年人晶状体弹性减退，透明度降低，甚至混浊形成老年性白内障。

:::definition{label="晶状体"}
晶状体（lens）是具有弹性的双凸透明体，前面略平、后面较凸，两面交界为赤道部。它是眼球中最重要的屈光装置。无血管和神经，靠房水供给营养。
:::

:::definition{label="晶状体囊"}
晶状体囊（lens capsule）包在晶状体外面，由基膜和胶原原纤维等构成。睫状小带一端插入囊内，把晶状体悬吊起来。
:::

:::definition{label="晶状体上皮"}
晶状体上皮是皮质前表面的一层立方形细胞。在赤道部逐渐变成长柱状，成为晶状体纤维。
:::

:::definition{label="晶状体纤维"}
晶状体纤维（lens fiber）由赤道部上皮细胞变成长柱状而来，呈环层状排列。新形成的纤维构成皮质；陈旧纤维被推向中心，核逐渐消失、含水量减少，参与构成晶状体核。
:::

:::definition{label="晶状体核"}
晶状体核（lens nucleus）位于晶状体中央，由被推向中心的陈旧晶状体纤维构成，核消失、含水量减少。
:::

:::definition{label="老年性白内障"}
老年人晶状体弹性减退，透明度降低，甚至混浊，形成老年性白内障。晶状体代谢紊乱、蛋白质变性而混浊的疾病统称白内障，详见章末插入框。
:::

:::concept{term="先问纤维新旧：皮质核还在不在"}
晶状体不是一块不变的玻璃。赤道部上皮持续改写成新纤维，铺在皮质；旧纤维被挤进核，丢掉细胞核、丢掉水分。一生都在往核里堆。弹性靠皮质，混浊也常从代谢紊乱的纤维蛋白开始。把晶状体听成“出生时就定型的透镜”，调节和白内障两本账都会做死。
:::

:::pitfall{label="晶状体无血管，营养只走房水，不要写成脉络膜供血"}
脉络膜养活的是视网膜外层。晶状体自己没有血管和神经，全靠房水。房水回流受阻时眼压升高（青光眼）；房水成分或晶状体蛋白出问题则走白内障账。两本病不要并成“眼睛不好”。
:::

::figure{src="/images/histology/textbook/p0142_03.png" caption="图12-13 晶状体结构模式图。示晶状体囊、前表面立方形晶状体上皮、赤道部上皮改写成环层状晶状体纤维。" alt="晶状体皮质与赤道部：囊、上皮和环层纤维"}

### 2. 玻璃体

玻璃体（vitreous body）位于晶状体、睫状体与视网膜之间，为无色透明的胶状体，水分占 $99\%$，其余为胶原原纤维、玻璃蛋白、透明质酸和少量细胞。

:::definition{label="玻璃体"}
玻璃体（vitreous body）位于晶状体、睫状体与视网膜之间，为无色透明的胶状体。水分占 $99\%$，其余为胶原原纤维、玻璃蛋白、透明质酸和少量细胞。构成睫状小带和玻璃体的生化成分可由睫状体非色素上皮产生。
:::

### 3. 房水

房水（aqueous humor）为充满于眼房内的透明液体，由睫状体的血液渗出和非色素上皮细胞分泌而成。房水从后房经瞳孔至前房，继而在前房角经小梁间隙进入巩膜静脉窦，最终由睫状前静脉导入血液循环。房水也具有屈光作用，并可营养晶状体和角膜，以及维持眼压。房水的产生和回流保持动态平衡，如回流受阻可引起眼压增高，导致视力受损，称为青光眼。

:::definition{label="房水"}
房水（aqueous humor）是充满于眼房内的透明液体，由睫状体的血液渗出和非色素上皮细胞分泌而成。具有屈光作用，营养晶状体和角膜，并维持眼压。
:::

:::definition{label="房水循环"}
房水从后房经瞳孔至前房，继而在前房角经小梁间隙进入巩膜静脉窦，最终由睫状前静脉导入血液循环。产生与回流保持动态平衡。
:::

:::definition{label="青光眼"}
青光眼是房水回流受阻引起眼压增高、导致视力受损的疾病。阻塞点常在前房角的小梁网–巩膜静脉窦通路，而不是晶状体本身混浊。
:::

:::concept{term="先问房水从哪分泌、从哪回流，堵在哪一站会青光眼"}
产在后房：睫状体血管渗出 + 非色素上皮分泌。路是后房 → 瞳孔 → 前房 → 前房角小梁间隙 → 巩膜静脉窦 → 睫状前静脉。这一圈还顺路养活无血管的晶状体和角膜，并顶住眼压。回流堵住，眼压升高，就是青光眼；晶状体蛋白混浊，才是白内障。两本病的第一站都不要写错。
:::

:::note{label="房水循环路径"}
| 顺序 | 站点 | 结构落点 |
|------|------|----------|
| ① 产生 | 后房 | 睫状体血液渗出 + 非色素上皮分泌 |
| ② 过瞳孔 | 瞳孔 | 前、后房借瞳孔相通 |
| ③ 前房 | 角膜与虹膜之间 | 顺路渗透营养角膜 |
| ④ 前房角 | 小梁间隙 | 小梁中央胶原、表面内皮 |
| ⑤ 入窦 | 巩膜静脉窦 | 窦壁衬内皮 |
| ⑥ 回血 | 睫状前静脉 | 导入血液循环 |
:::

:::compare{title="晶状体、玻璃体与房水"}
| 项目 | 晶状体 | 玻璃体 | 房水 |
|------|--------|--------|------|
| 位置 | 虹膜与玻璃体之间，被小带悬吊 | 晶状体、睫状体与视网膜之间 | 充满前房和后房 |
| 性状 | 弹性双凸透明体 | 无色透明胶状体，水 $99\%$ | 透明液体 |
| 结构要点 | 囊、上皮、皮质纤维、核 | 胶原原纤维、玻璃蛋白、透明质酸、少量细胞 | 无细胞管道液体 |
| 营养 | 无血管神经，靠房水 | 自身含水胶 | 睫状体产生 |
| 病理 | 混浊 → 白内障；弹性减退 → 调节力下降 | — | 回流受阻 → 眼压高 → 青光眼 |
:::

:::pitfall{label="青光眼是回流账，白内障是晶状体混浊账，不要互相替代"}
眼压靠房水产生与回流的平衡。小梁网或巩膜静脉窦堵住，压力顶视网膜，是青光眼。晶状体纤维蛋白变性、透光下降，是白内障。老年人可以两本账同时有，考试必须分开写病因。
:::

## （三）眼的附属器

包括眼睑、泪腺和眼外肌等，对眼球起遮盖、保护和运动等作用。

:::definition{label="眼的附属器"}
眼的附属器包括眼睑、泪腺和眼外肌等，对眼球起遮盖、保护和运动等作用。
:::

### 1. 眼睑

眼睑（eyelid）为薄板状结构，由前至后分为皮肤、皮下组织、肌层、睑板和睑结膜 5 层（图 12-15）。皮肤薄而柔软，睑缘有 $2\sim 3$ 列睫毛，睫毛根部有小的皮脂腺，称睑缘腺或 Zeis 腺。睫毛附近有呈螺旋状的汗腺，称睫腺或 Moll 腺。皮下组织为疏松结缔组织，易水肿和淤血。肌层主要为骨骼肌。睑板由致密结缔组织构成，呈半月形，质如软骨，是眼睑的支架。睑板内有许多平行排列的分支管泡状皮脂腺，称睑板腺（tarsal gland），导管开口于睑缘，分泌物有润滑睑缘和保护角膜的作用。睑结膜为薄层黏膜，上皮为复层柱状上皮，有杯状细胞；固有层为薄层结缔组织。睑结膜在结膜穹窿处移行为球结膜。

:::definition{label="眼睑"}
眼睑（eyelid）为薄板状结构，由前至后分为皮肤、皮下组织、肌层、睑板和睑结膜 5 层。
:::

:::definition{label="睑缘腺"}
睑缘腺即 Zeis 腺，是睫毛根部的小皮脂腺。
:::

:::definition{label="睫腺"}
睫腺即 Moll 腺，是睫毛附近呈螺旋状的汗腺。
:::

:::definition{label="睑板"}
睑板由致密结缔组织构成，呈半月形，质如软骨，是眼睑的支架。
:::

:::definition{label="睑板腺"}
睑板腺（tarsal gland）是睑板内许多平行排列的分支管泡状皮脂腺，导管开口于睑缘，分泌物润滑睑缘并保护角膜。
:::

:::definition{label="睑结膜"}
睑结膜为薄层黏膜。上皮为复层柱状上皮，有杯状细胞；固有层为薄层结缔组织。在结膜穹窿处移行为球结膜。
:::

:::compare{title="眼睑五层"}
| 层次（前→后） | 组织 | 要点 |
|----------------|------|------|
| 皮肤 | 薄而柔软 | 睑缘 $2\sim 3$ 列睫毛；Zeis 腺（皮脂腺）；Moll 腺（螺旋状汗腺） |
| 皮下组织 | 疏松结缔组织 | 易水肿和淤血 |
| 肌层 | 主要为骨骼肌（眼轮匝肌等） | 闭合眼睑 |
| 睑板 | 致密结缔组织，半月形，质如软骨 | 支架；内含睑板腺 |
| 睑结膜 | 复层柱状上皮（有杯状细胞）+ 薄层固有层 | 穹窿处移行为球结膜 |
:::

:::compare{title="睑缘腺、睫腺与睑板腺"}
| 项目 | 睑缘腺（Zeis 腺） | 睫腺（Moll 腺） | 睑板腺（tarsal gland） |
|------|-------------------|-----------------|------------------------|
| 类型 | 小皮脂腺 | 螺旋状汗腺 | 分支管泡状皮脂腺 |
| 位置 | 睫毛根部 | 睫毛附近 | 睑板内，平行排列 |
| 开口 | 与睫毛相关 | 睫毛附近 | 导管开口于睑缘 |
| 功能 | 皮脂 | 汗腺分泌 | 润滑睑缘、保护角膜 |
:::

:::pitfall{label="睑板腺是皮脂腺，不要写成浆液泪腺"}
泪液来自眶外上方的泪腺（浆液复管状腺）。睑板腺是睑板里的皮脂腺，油的是睑缘，不是把结膜囊当成泪腺导管。Zeis、Moll、睑板腺三套附属器都长在睑缘附近，类型分别是小皮脂腺、螺旋汗腺、分支管泡状皮脂腺，不要并成“眼睑上的一种腺”。
:::

:::insight{label="皮下疏松解释为什么眼睑最先肿"}
眼睑皮下是疏松结缔组织，教材写明易水肿和淤血。肾病、过敏、外伤的水液和血液优先垫在这一层，不是因为皮肤厚，恰恰因为这一层空。
:::

### 2. 泪腺

泪腺（lacrimal gland）位于眶外侧上方的泪腺窝内，为浆液复管状腺，被结缔组织分隔成小叶。腺上皮为单层立方上皮或单层柱状上皮，细胞质内有分泌颗粒。腺上皮外有基膜和肌上皮细胞。泪腺分泌的泪液经导管排至结膜上穹窿部，有润滑和清洁角膜的作用。

:::definition{label="泪腺"}
泪腺（lacrimal gland）位于眶外侧上方的泪腺窝内，为浆液复管状腺，被结缔组织分隔成小叶。腺上皮为单层立方或单层柱状，胞质内有分泌颗粒；上皮外有基膜和肌上皮细胞。泪液经导管排至结膜上穹窿部，润滑并清洁角膜。
:::

:::compare{title="泪腺与睑板腺"}
| 项目 | 泪腺 | 睑板腺 |
|------|------|--------|
| 位置 | 眶外侧上方泪腺窝 | 睑板内 |
| 腺类型 | 浆液复管状腺 | 分支管泡状皮脂腺 |
| 上皮 | 单层立方或柱状，有分泌颗粒；外有肌上皮 | 皮脂腺腺泡 |
| 开口 | 导管至结膜上穹窿 | 导管开口于睑缘 |
| 产物 | 泪液：润滑、清洁角膜 | 皮脂：润滑睑缘、保护角膜 |
:::

:::keypoint{label="眼先立眼球壁三层，再立屈光和附属器"}
- 眼球壁外→内：纤维膜（角膜 $1/6$ + 巩膜 $5/6$ + 角膜缘）、血管膜（虹膜、睫状体、脉络膜）、视网膜（盲部 / 视部，锯齿缘分界）。
- 角膜五层：未角化复层扁平上皮 → 前界层 → 基质（约 $90\%$，板层垂直）→ 后界层 → 单层扁平内皮。透明靠规则纤维、水分、无血管、无黑素。
- 角膜缘干细胞补充角膜；小梁网 + 巩膜静脉窦是房水回流必经之路。
- 虹膜三层；括约肌环行在基质，开大肌放射状为上皮前层肌上皮。睫状肌三走向改写小带张力以调节焦距；非色素上皮分泌房水。
- 视网膜功能四层：色素上皮、视细胞、双极细胞、节细胞。视杆弱光（视紫红质，夜盲），视锥强光颜色（三型视色素，色盲）。中央凹最敏锐（仅视锥，一对一）；视盘为生理盲点。
- 屈光系统 = 角膜 + 房水 + 晶状体 + 玻璃体。房水：后房 → 瞳孔 → 前房 → 小梁间隙 → 巩膜静脉窦 → 睫状前静脉；回流受阻为青光眼。晶状体混浊为白内障。
- 眼睑五层；泪腺浆液，睑板腺皮脂。
:::

- [ ] 眼和耳均为特殊感觉装置：眼为视觉器官，耳为听觉及位觉器官。
- [ ] 眼由具有感光功能的眼球及其附属器构成。眼球外壳为眼球壁，内有晶状体、玻璃体和房水。
- [ ] 眼球壁由外至内分为纤维膜、血管膜和视网膜 3 层。
- [ ] 纤维膜主要由致密结缔组织构成：前 $1/6$ 为角膜，后 $5/6$ 为巩膜，过渡区为角膜缘。
- [ ] 角膜（cornea）透明圆盘状，中央约 $0.5\,\mathrm{mm}$、周边约 $1.0\,\mathrm{mm}$；不含血管和淋巴管，营养由房水和角膜缘血管渗透供应。
- [ ] 角膜从前至后 5 层：角膜上皮、前界层、角膜基质、后界层、角膜内皮。
- [ ] 角膜上皮为未角化复层扁平上皮，$5\sim 6$ 层，无黑素细胞；基底层矮柱状有增殖能力，中间 $2\sim 3$ 层多边形，表面 $1\sim 2$ 层扁平；约 $7$ 天更新；游离神经末梢丰富，感觉敏锐。
- [ ] 前界层不含细胞，由胶原原纤维和基质构成。
- [ ] 角膜基质又称固有层，约占厚度 $90\%$；胶原板层与表面平行，板层内纤维平行、相邻板层垂直；成纤维细胞可修复损伤。
- [ ] 后界层类似前界层但更薄；角膜内皮为单层扁平上皮，参与后界层形成。
- [ ] 角膜透明的主要原因：成分（尤其纤维）规则排列、富含水分、无血管、无黑素细胞。
- [ ] 巩膜瓷白色，粗大胶原纤维交织，质地坚韧，是重要保护层。
- [ ] 巩膜距（scleral spur）是角膜交界处内侧的环形嵴，为小梁网和睫状肌的附着部位。
- [ ] 巩膜前部外表面覆球结膜（复层扁平上皮 + 疏松结缔组织）。
- [ ] 角膜缘宽 $1\sim 2\,\mathrm{mm}$，为角膜与巩膜带状移行区，常是前部手术入路。
- [ ] 角膜缘上皮超过 $10$ 层，细胞小、核深染，基底层矮柱状栅栏样；有黑素细胞，无杯状细胞。
- [ ] 角膜缘干细胞可向角膜中央移行，补充角膜基底层细胞；临床上可做角膜缘移植。
- [ ] 巩膜静脉窦在角膜缘内侧，环行，矢状面呈不规则长条形，壁衬内皮。
- [ ] 小梁网在窦内侧，小梁中央为胶原、表面覆内皮；小梁间隙与巩膜静脉窦相通，是房水回流必经之路。
- [ ] 血管膜为富含血管和黑素细胞的疏松结缔组织，前至后为虹膜基质、睫状体基质和脉络膜。
- [ ] 虹膜直径约 $12\,\mathrm{mm}$、厚约 $0.5\,\mathrm{mm}$，分隔前房和后房，房水借瞳孔相通。
- [ ] 虹膜由前向后：前缘层（不连续成纤维细胞和黑素细胞）、虹膜基质、虹膜上皮。
- [ ] 瞳孔括约肌：近瞳孔缘基质中的环行平滑肌，收缩使瞳孔缩小。
- [ ] 虹膜上皮前层为肌上皮，放射状构成瞳孔开大肌，收缩使瞳孔开大；后层立方，胞质充满黑素颗粒。
- [ ] 睫状体介于虹膜与脉络膜之间，矢状面大致三角形，后部止于锯齿缘；由睫状肌、基质和上皮组成。
- [ ] 睫状肌为平滑肌，有环行、放射状和纵行 3 种走向；放射状和纵行起于巩膜距。
- [ ] 睫状体上皮外层为立方形色素上皮，内层为矮柱状非色素上皮，分泌房水并产生睫状小带和玻璃体的生化成分。
- [ ] 约 $70$ 个睫状突经睫状小带连于晶状体；小带由微原纤维借蛋白聚糖黏合，一端插入晶状体囊。
- [ ] 睫状肌收缩 → 睫状体突向前内 → 小带松弛；反之小带紧张，从而调节晶状体位置和曲度。
- [ ] 脉络膜为血管膜后 $2/3$，棕黑色；最内层玻璃膜为均质透明薄膜，由纤维和基质组成。
- [ ] 视网膜分盲部与视部，交界为锯齿缘；盲部包括虹膜上皮和睫状体上皮；通常所称视网膜指视部。
- [ ] 视部由外向内：色素上皮层、视细胞层、双极细胞层、节细胞层；后 3 层称神经层。
- [ ] 色素上皮为单层立方，基底贴玻璃膜，顶部突起伸入外节之间；含黑素颗粒和吞噬体（多为视杆脱落膜盘）；侧面紧密连接。
- [ ] 色素上皮功能：保护视细胞、稳定内环境、贮存维生素 A、营养神经层、吞噬脱落物。
- [ ] 视细胞是感光的感觉神经元，分胞体、外突、内突；外突以连接纤毛分为内节（合成感光蛋白）和外节（膜盘感光）。
- [ ] 视杆主要在周围部，感受弱光，数量远多于视锥；膜盘与胞膜分离，基部新生、顶端脱落。
- [ ] 视紫红质 = 11-顺式视黄醛 + 视蛋白；维生素 A 不足 → 夜盲症。
- [ ] 视锥主要在中部，感受强光和颜色；膜盘大多不与胞膜分离、顶端不脱落；视色素分红、绿、蓝三型；缺某型为色盲。
- [ ] 双极细胞连接视细胞与节细胞；树突突触成外网层，轴突突触成内网层。
- [ ] 侏儒双极细胞只连一个视锥和一个节细胞，位于中央凹边缘。
- [ ] 水平细胞、无长突细胞、网间细胞构成局部环路，调控视觉信号。
- [ ] 节细胞为长轴突多极神经元，轴突形成视神经纤维层并汇成视神经；侏儒节细胞只连一个侏儒双极细胞。
- [ ] ipRGC 以视黑蛋白感光，投射至视交叉上核、橄榄顶盖前核等，调控昼夜节律和瞳孔对光反射。
- [ ] 视网膜胶质有米勒细胞、星形胶质细胞、小胶质细胞，一般无少突胶质细胞。
- [ ] 米勒细胞贯穿神经层，外侧端成外界膜，内侧端成胶质界膜（内界膜）。
- [ ] 黄斑直径 $1\sim 3\,\mathrm{mm}$；中央凹厚仅 $0.1\,\mathrm{mm}$，只有色素上皮和视锥，一对一联系，是视觉最敏锐部位。
- [ ] 视盘在黄斑鼻侧，无感光细胞，为生理盲点；视网膜中央动、静脉在此穿过。
- [ ] 视神经将信息传入大脑枕叶视觉中枢，产生视觉。
- [ ] 屈光系统 = 角膜 + 房水 + 晶状体 + 玻璃体，均无色透明。
- [ ] 晶状体为弹性双凸透明体，前平后凸，赤道部交界；外包晶状体囊（基膜 + 胶原原纤维）。
- [ ] 前表面一层立方晶状体上皮，赤道部改写为环层晶状体纤维；新纤维成皮质，旧纤维成晶状体核（核消失、水减少）。
- [ ] 晶状体无血管神经，靠房水营养；老年弹性减退、混浊形成老年性白内障。
- [ ] 玻璃体为胶状体，水占 $99\%$，其余为胶原原纤维、玻璃蛋白、透明质酸和少量细胞。
- [ ] 房水由睫状体血液渗出和非色素上皮分泌；路径：后房 → 瞳孔 → 前房 → 小梁间隙 → 巩膜静脉窦 → 睫状前静脉。
- [ ] 房水屈光、营养晶状体和角膜、维持眼压；回流受阻 → 眼压增高 → 青光眼。
- [ ] 眼附属器包括眼睑、泪腺和眼外肌等，起遮盖、保护和运动作用。
- [ ] 眼睑由前至后：皮肤、皮下组织、肌层、睑板、睑结膜。
- [ ] 睑缘 $2\sim 3$ 列睫毛；Zeis 腺为睫毛根部皮脂腺；Moll 腺为附近螺旋状汗腺。
- [ ] 皮下疏松，易水肿淤血；肌层主要为骨骼肌；睑板致密结缔组织，半月形，质如软骨。
- [ ] 睑板腺为平行排列的分支管泡状皮脂腺，导管开口于睑缘，润滑睑缘并保护角膜。
- [ ] 睑结膜上皮为复层柱状，有杯状细胞；穹窿处移行为球结膜。
- [ ] 泪腺位于眶外侧上方泪腺窝，浆液复管状腺，有肌上皮；泪液排至结膜上穹窿，润滑清洁角膜。
