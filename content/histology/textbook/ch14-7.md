# 七、消化管的淋巴组织

消化管与体外环境直接相通，各种细菌、病毒、寄生虫（卵）等病原微生物不可避免地随饮食进入。它们大多被胃酸、消化酶以及帕内特细胞分泌的防御素和溶菌酶破坏，其余或以原形排出体外，或受到消化管淋巴组织的免疫抵御。消化管淋巴组织主要包括上皮内的淋巴细胞、固有层中的淋巴细胞、淋巴小结，统称为肠相关淋巴组织（gut-associated lymphoid tissue，GALT），尤以咽、回肠、阑尾等处的淋巴组织丰富。集合淋巴小结为多个淋巴小结聚集形成，主要位于回肠。消化管淋巴组织能接受消化管内病原微生物的抗原刺激，主要通过产生和向消化管腔分泌免疫球蛋白作为应答。

:::definition{label="消化管淋巴组织"}
消化管淋巴组织主要包括上皮内的淋巴细胞、固有层中的淋巴细胞和淋巴小结，统称为肠相关淋巴组织（gut-associated lymphoid tissue，GALT）。尤以咽、回肠、阑尾等处丰富。
:::

:::definition{label="肠相关淋巴组织"}
肠相关淋巴组织（GALT）是消化管黏膜淋巴组织的总称，能接受消化管内病原微生物的抗原刺激，主要通过产生和向消化管腔分泌免疫球蛋白作为应答。
:::

:::definition{label="集合淋巴小结"}
集合淋巴小结为多个淋巴小结聚集形成，主要位于回肠（见第五节图 14-28）。
:::

:::concept{term="先问抗原怎么被 M 细胞递进去，再问 sIgA 从哪扇门出上皮"}
病原不是“自己钻进淋巴小结”。集合淋巴小结处黏膜隆成圆顶，无绒毛、无小肠腺，上皮里的 M 细胞把抗原吞成囊泡，交给下方巨噬细胞，再提呈给淋巴细胞。幼浆细胞经再循环大部分回家，主要产 IgA；IgA 与吸收细胞的分泌片结合成 sIgA，被内吞后释放入肠腔。把 GALT 听成“肠壁里的几枚淋巴结”，分泌片和 sIgA 耐消化酶那两本账会做丢。
:::

:::note{label="进入消化管的病原有三条出路"}
| 出路 | 机制 |
|------|------|
| 被破坏 | 胃酸、消化酶，以及帕内特细胞的防御素和溶菌酶 |
| 原形排出 | 随粪便离开 |
| 免疫抵御 | GALT 接受抗原，向管腔分泌免疫球蛋白（主要是 sIgA） |
:::

在肠集合淋巴小结处，局部黏膜向肠腔呈圆顶状隆起，无绒毛和小肠腺。此部位上皮内有散在的微皱褶细胞（microfold cell），又称 M 细胞，因其游离面有微皱褶而得名。M 细胞基底面质膜内陷形成一较大的穹窿状凹腔，内含多个淋巴细胞和少量巨噬细胞。M 细胞在光镜下难以分辨，只能根据其基底部是否包含淋巴细胞来推断。电镜下可见其细胞质中有丰富的囊泡。M 细胞可摄取肠腔内抗原物质，以囊泡的形式转运并传递给下方的巨噬细胞，后者将抗原处理后提呈给淋巴细胞。淋巴细胞进入黏膜淋巴小结和肠系膜淋巴结内增殖分化为幼浆细胞，然后经淋巴细胞再循环，大部分返回消化管黏膜并转变为浆细胞。浆细胞除产生少量免疫球蛋白 G（IgG）进入血液循环外，主要产生免疫球蛋白 A（IgA）。IgA 能与吸收细胞基底面和侧面膜中的受体（亦称分泌片）相结合，形成分泌型 IgA（secretory IgA，sIgA）。sIgA 被吸收细胞内吞后释放入肠腔（图 14-33）。sIgA 能较强地抵御消化酶的分解，可特异性地与抗原结合，从而抑制或杀灭细菌，中和病毒，防止抗原黏附和穿入上皮。部分幼浆细胞还随血液进入唾液腺、呼吸道黏膜、女性生殖道黏膜和乳腺等部位，产生 sIgA，发挥相似的免疫作用，使消化管免疫成为全身免疫的一部分。

:::definition{label="集合淋巴小结处的圆顶"}
肠集合淋巴小结处局部黏膜向肠腔呈圆顶状隆起，无绒毛和小肠腺。此处上皮内有散在的 M 细胞。
:::

:::definition{label="M 细胞"}
微皱褶细胞（microfold cell）又称 M 细胞，因游离面有微皱褶而得名。基底面质膜内陷成较大穹窿状凹腔，内含多个淋巴细胞和少量巨噬细胞。光镜下难以分辨，只能根据基底部是否包含淋巴细胞来推断；电镜见胞质中有丰富囊泡。
:::

:::definition{label="M 细胞的抗原转运"}
M 细胞摄取肠腔内抗原，以囊泡形式转运并传递给下方巨噬细胞；巨噬细胞将抗原处理后提呈给淋巴细胞。
:::

:::pitfall{label="M 细胞光镜下几乎看不见，不要当成吸收细胞或杯状细胞"}
圆顶区本来就没有纹状缘发达的绒毛。M 细胞靠“基底部是否塞着淋巴细胞”来推断，不是靠找杯状空泡或纹状缘。把它写成“另一种吸收细胞”，抗原转运会变成吸收；把它写成杯状细胞，黏液账和囊泡转运账会并在一起。
:::

:::insight{label="M 细胞是采样口，不是杀菌器"}
游离面微皱褶、胞质囊泡、基底穹窿里塞淋巴细胞和巨噬细胞：这枚细胞把抗原递进去，自己并不靠溶菌酶杀灭。杀菌在帕内特细胞和 sIgA；呈递在 M 细胞和巨噬细胞。把 M 细胞听成“肠上皮的巨噬细胞”，再循环和分泌片那几步会从链条上掉下去。
:::

:::note{label="从抗原到 sIgA 的步骤"}
| 步骤 | 落点 |
|------|------|
| 1. 采样 | M 细胞摄取肠腔抗原，囊泡转运 |
| 2. 处理提呈 | 下方巨噬细胞处理后提呈给淋巴细胞 |
| 3. 增殖分化 | 黏膜淋巴小结和肠系膜淋巴结 → 幼浆细胞 |
| 4. 再循环回家 | 大部分返回消化管黏膜，转变为浆细胞 |
| 5. 两类抗体 | 少量 IgG 入血；主要产 IgA |
| 6. 出上皮 | IgA + 吸收细胞基底面/侧面的分泌片 → sIgA，内吞后释放入肠腔 |
| 7. 腔面效应 | 耐消化酶；抑杀细菌、中和病毒、防抗原黏附穿入上皮 |
:::

:::definition{label="分泌型 IgA"}
分泌型 IgA（secretory IgA，sIgA）由 IgA 与吸收细胞基底面和侧面膜中的受体（分泌片）结合而成，被吸收细胞内吞后释放入肠腔。能较强抵御消化酶分解，特异性结合抗原，抑制或杀灭细菌，中和病毒，防止抗原黏附和穿入上皮。
:::

:::definition{label="消化管免疫与全身黏膜"}
部分幼浆细胞随血液进入唾液腺、呼吸道黏膜、女性生殖道黏膜和乳腺等部位，产生 sIgA，发挥相似的免疫作用，使消化管免疫成为全身免疫的一部分。
:::

:::compare{title="IgG 与 sIgA"}
| 项目 | IgG | sIgA |
|------|-----|------|
| 产量 | 浆细胞产生的少量 | 主要产物 |
| 去路 | 进入血液循环 | 与分泌片结合，经吸收细胞释放入肠腔 |
| 作用场所 | 全身血液 | 消化管腔；也可出现在唾液腺、呼吸道、女性生殖道、乳腺 |
| 耐消化酶 | 不是腔面主力 | 能较强抵御消化酶分解 |
:::

:::pitfall{label="sIgA 不是浆细胞直接吐进肠腔，要借吸收细胞的分泌片"}
IgA 在固有层诞生，必须与吸收细胞基底面和侧面的分泌片结合，再被内吞、释放入肠腔。第五节写过吸收细胞参与 sIgA 释放，落点就是这张膜受体。把 sIgA 写成“杯状细胞黏液里的抗体”或“M 细胞分泌的抗体”，分泌片账会写到错误的细胞上。
:::

:::compare{title="咽、回肠与阑尾的 GALT 形态"}
| 部位 | 形态要点 | 与抗原接触的方式 |
|------|----------|------------------|
| 咽 | 淋巴组织丰富（扁桃体等，见口腔与咽） | 上皮下淋巴组织直接面对抗原 |
| 回肠 | 集合淋巴小结；圆顶处无绒毛、无小肠腺，有 M 细胞 | M 细胞采样 |
| 阑尾 | 淋巴小结连续成层，突入黏膜下层，黏膜肌不完整 | 黏膜免疫器官 |
:::

:::keypoint{label="GALT 用 M 细胞采样，用 sIgA 在腔面作答"}
- 入管病原：胃酸、消化酶、帕内特细胞防御素和溶菌酶破坏；或排出；或由 GALT 抵御。
- GALT = 上皮内淋巴细胞 + 固有层淋巴细胞 + 淋巴小结；咽、回肠、阑尾最丰富。
- 集合淋巴小结主要在回肠；圆顶无绒毛、无小肠腺。
- M 细胞：微皱褶、基底穹窿含淋巴细胞和巨噬细胞；囊泡转运抗原；光镜难认。
- 幼浆细胞再循环回家，主要产 IgA；IgA + 分泌片 → sIgA，经吸收细胞入肠腔。
- sIgA 耐消化酶，抑杀细菌、中和病毒、防黏附穿入。
- 部分幼浆细胞到唾液腺、呼吸道、女性生殖道和乳腺，消化管免疫成为全身黏膜免疫的一部分。
:::
