# 二、口腔与咽

口腔与咽是消化管的起始段。口腔黏膜没有黏膜肌层，不能按食管以下的四层通例硬套；舌背用三种乳头和味蕾把机械摩擦与味觉分开写；牙用三种钙化硬组织加牙髓、牙周组织立硬软两本账；咽是消化管和呼吸道的交叉，上皮类型随口咽、鼻咽、喉咽而变。

:::definition{label="口腔与咽"}
口腔与咽是消化管上端。口腔完成摄食、咀嚼、初步消化和味觉；咽是消化管和呼吸道的交叉部位，分为口咽、鼻咽和喉咽 3 部分。
:::

:::concept{term="先问有没有黏膜肌：口腔和咽没有，不能按四层来数"}
上一节的四层通例从食管才立住。口腔黏膜只有上皮和固有层；咽有黏膜、肌层（骨骼肌）和纤维膜，同样没有典型的黏膜肌层。把唇颊切片硬数“黏膜下层、内环外纵”，乳头、小唾液腺和骨骼肌交织那几本账会错层。
:::

## （一）口腔黏膜的一般结构

口腔黏膜只有上皮和固有层，无黏膜肌层。上皮为复层扁平上皮，仅在硬腭部出现角化。口腔底部的上皮菲薄，通透性高，有利于某些化学物质的吸收，如治疗心绞痛的硝酸甘油。固有层结缔组织突向上皮形成乳头，其内富有毛细血管，故黏膜呈红色。乳头及上皮内有许多感觉神经末梢。固有层中尚有小唾液腺。固有层在唇、颊等处连于骨骼肌，在硬腭连于骨膜。

:::definition{label="口腔黏膜"}
口腔黏膜只有上皮和固有层，无黏膜肌层。上皮为复层扁平上皮，仅硬腭部出现角化。固有层形成乳头，富含毛细血管，黏膜因而呈红色。
:::

:::definition{label="口腔底部上皮"}
口腔底部的复层扁平上皮菲薄，通透性高，有利于某些化学物质吸收，如治疗心绞痛的硝酸甘油可经此吸收。
:::

:::definition{label="口腔黏膜乳头"}
固有层结缔组织突向上皮形成乳头，内富毛细血管，并与上皮内一起含有许多感觉神经末梢。
:::

:::note{label="口腔黏膜固有层连向何处"}
| 部位 | 固有层深面 |
|------|------------|
| 唇、颊等 | 连于骨骼肌 |
| 硬腭 | 连于骨膜 |
| 各处固有层内 | 可有小唾液腺 |
:::

:::pitfall{label="口腔上皮不是到处都角化，只有硬腭明显角化"}
口腔是复层扁平上皮，但角化只明确写在硬腭。舌腹、口底未角化，口底还特意菲薄以便吸收。把口腔一律写成“角化复层扁平”，硝酸甘油经口底吸收和舌腹光滑那两本账都会写错。
:::

:::compare{title="口腔黏膜与食管以下黏膜"}
| 项目 | 口腔黏膜 | 食管及以下典型黏膜 |
|------|----------|---------------------|
| 层次 | 上皮 + 固有层，无黏膜肌层 | 上皮 + 固有层 + 黏膜肌层 |
| 上皮 | 复层扁平；仅硬腭角化 | 食管未角化复层扁平；胃肠单层柱状 |
| 固有层乳头 | 明显，富毛细血管，黏膜红 | 食管固有层也形成乳头 |
| 深面 | 唇颊连骨骼肌，硬腭连骨膜 | 外接黏膜下层 |
:::

## （二）舌

舌由表面的黏膜和深部的肌层组成。黏膜由复层扁平上皮与固有层组成。舌腹面黏膜薄，表面光滑，其复层扁平上皮未角化；舌根部黏膜内有许多淋巴小结，构成舌扁桃体。舌背部黏膜形成许多乳头状隆起，称舌乳头（lingual papilla）。根据形态和结构的不同，人舌乳头可分为丝状乳头、菌状乳头和轮廓乳头 3 种（图 14-4，图 14-5）。肌层由纵行、横行及垂直 3 种不同行走方向的骨骼肌交织构成。

:::definition{label="舌"}
舌由表面的黏膜和深部的肌层组成。黏膜为复层扁平上皮 + 固有层。腹面薄而光滑、上皮未角化；背部形成舌乳头；根部黏膜内有许多淋巴小结，构成舌扁桃体。
:::

:::definition{label="舌扁桃体"}
舌根部黏膜内有许多淋巴小结，构成舌扁桃体，属于口腔内的淋巴组织。
:::

:::definition{label="舌乳头"}
舌乳头（lingual papilla）是舌背部黏膜形成的乳头状隆起。人舌乳头分丝状乳头、菌状乳头和轮廓乳头 3 种。
:::

:::definition{label="舌肌层"}
舌的肌层由纵行、横行及垂直 3 种不同行走方向的骨骼肌交织构成，使舌能灵活改变形态。
:::

:::concept{term="先问这个乳头有没有味蕾，再问尖端有没有角化"}
三种乳头不要并成“舌背上的刺”。丝状乳头数量最多、尖端角化、管摩擦和舌苔，没有味蕾；菌状乳头散在其间、不角化、内有味蕾，肉眼是红点；轮廓乳头只有十来个，陷在界沟前方，环沟两侧味蕾最多，沟底有味腺冲洗。把丝状乳头也写成“管味觉”，舌苔和味觉两本账会缠在一起。
:::

### 1. 丝状乳头

数量最多，遍布于舌背。乳头呈圆锥形，中央为富含血管和神经的固有层结缔组织，表面覆有复层扁平上皮，乳头尖端上皮角化。脱落的角化细胞与唾液和食物残渣等混合，黏附于舌的表面，形成薄的舌苔。

:::definition{label="丝状乳头"}
丝状乳头数量最多，遍布舌背，呈圆锥形。中央为富含血管和神经的固有层，表面覆复层扁平上皮，尖端上皮角化。无味蕾。
:::

:::definition{label="舌苔"}
脱落的角化细胞与唾液和食物残渣等混合，黏附于舌的表面，形成薄的舌苔。原料主要来自丝状乳头尖端的角化上皮。
:::

### 2. 菌状乳头

数量较少，主要分布于舌尖与舌缘，散在于丝状乳头之间。乳头呈蘑菇状，上皮不角化，内有味蕾。固有层富含毛细血管，故肉眼观呈红色小点状。

:::definition{label="菌状乳头"}
菌状乳头数量较少，主要分布于舌尖与舌缘，散在于丝状乳头之间。呈蘑菇状，上皮不角化，内有味蕾。固有层富含毛细血管，肉眼呈红色小点状。
:::

### 3. 轮廓乳头

有 10 余个，位于舌后部界沟前方。形体较大，陷于黏膜中，故顶部平坦，乳头周围的黏膜凹陷形成环沟，乳头表面为未角化的复层扁平上皮，沟两侧的上皮内有较多味蕾。固有层中有浆液性的味腺，导管开口于沟底。味腺分泌的稀薄液体不断冲洗味蕾表面的食物碎渣，以利味蕾不断接受新的物质刺激。

:::definition{label="轮廓乳头"}
轮廓乳头有 10 余个，位于舌后部界沟前方。形体较大，陷于黏膜中，顶部平坦，周围黏膜凹陷成环沟。表面为未角化复层扁平上皮，沟两侧上皮内有较多味蕾。
:::

:::definition{label="味腺"}
味腺是轮廓乳头固有层中的浆液性腺，导管开口于环沟底。分泌稀薄液体，不断冲洗味蕾表面的食物碎渣，使味蕾能接受新的物质刺激。
:::

:::compare{title="丝状乳头、菌状乳头与轮廓乳头"}
| 项目 | 丝状乳头 | 菌状乳头 | 轮廓乳头 |
|------|----------|----------|----------|
| 数量与分布 | 最多，遍布舌背 | 较少，舌尖与舌缘，散在丝状乳头之间 | 10 余个，舌后部界沟前方 |
| 外形 | 圆锥形 | 蘑菇状 | 较大，顶部平坦，周围有环沟 |
| 上皮 | 复层扁平，尖端角化 | 不角化 | 未角化复层扁平 |
| 味蕾 | 无 | 有 | 沟两侧较多 |
| 特有结构 | 角化脱落参与舌苔 | 固有层血管丰富，肉眼红点 | 浆液性味腺开口于沟底 |
| 光镜 | 图 14-4 中的 1 | 图 14-4 中的 2；图 14-5 中的 2 | 图 14-5 中的 1（4 为味腺，3 为骨骼肌） |
:::

味蕾（taste bud）为卵圆形小体，成人约有 $3000$ 个，主要分布于菌状乳头和轮廓乳头，少数散在于软腭、会厌及咽等上皮内。味蕾染色较上皮淡，其基部位于上皮的基膜上，顶端窄小，有一小孔开口于上皮表面，称味孔。组成味蕾的细胞有味细胞、支持细胞和基细胞 3 种（图 14-6）。支持细胞数量较多，呈梭形，位于味细胞之间；味细胞也呈梭形，多位于味蕾中央，细胞顶部微绒毛（也称味毛）突入味孔，细胞基部与味觉神经末梢以突触相连；基细胞呈矮锥体形，是味细胞的前体干细胞，位于味蕾基部。味蕾可感受 4 种基本味觉：甜、苦、酸、咸，甜咸感在舌尖，酸苦感在舌的两侧及舌根。

:::definition{label="味蕾"}
味蕾（taste bud）为卵圆形小体，染色较上皮淡。成人约有 $3000$ 个，主要分布于菌状乳头和轮廓乳头，少数散在于软腭、会厌及咽等上皮内。基部位于上皮基膜上，顶端有味孔开口于上皮表面。
:::

:::definition{label="味孔"}
味孔是味蕾顶端开口于上皮表面的小孔。味细胞顶部的微绒毛（味毛）突入味孔，接触溶解的味觉物质。
:::

:::definition{label="味细胞"}
味细胞呈梭形，多位于味蕾中央。顶部微绒毛（味毛）突入味孔；基部与味觉神经末梢以突触相连，把化学刺激写成神经冲动。
:::

:::definition{label="支持细胞（味蕾）"}
支持细胞数量较多，呈梭形，位于味细胞之间，不形成突触，起支持作用。
:::

:::definition{label="基细胞（味蕾）"}
基细胞呈矮锥体形，位于味蕾基部，是味细胞的前体干细胞。
:::

:::note{label="四种基本味觉的教材定位"}
| 味觉 | 主要部位 |
|------|----------|
| 甜、咸 | 舌尖 |
| 酸、苦 | 舌的两侧及舌根 |
:::

:::pitfall{label="丝状乳头没有味蕾，味蕾也不只长在舌上"}
味蕾主要在菌状乳头和轮廓乳头，少数还散在软腭、会厌和咽上皮。丝状乳头尖端角化、管舌苔，不含味蕾。把“舌乳头 = 味蕾”写成等式，轮廓乳头的味腺冲洗账和口底以外的味觉落点都会消失。
:::

:::insight{label="味腺不是为了产味道，而是把旧碎渣冲掉"}
轮廓乳头陷在环沟里，食物碎渣容易积在沟底。浆液性味腺开口于沟底，持续冲洗，味毛才能接触下一口溶解物。把味腺听成“分泌味觉物质的腺”，环沟的结构意义就反了。
:::

## （三）牙

牙埋在牙槽骨内的为牙根，露在外面的为牙冠，两者交界部为牙颈。牙中央有牙髓腔，开口于牙根底部的牙根孔。牙由牙本质、釉质、牙骨质 3 种钙化的硬组织和牙髓软组织构成。牙根周围的牙周膜、牙槽骨骨膜及牙龈则统称为牙周组织（图 14-7）。

:::definition{label="牙的分部"}
埋在牙槽骨内的为牙根，露在外面的为牙冠，交界部为牙颈。中央有牙髓腔，开口于牙根底部的牙根孔。
:::

:::definition{label="牙的构成"}
牙由牙本质、釉质、牙骨质 3 种钙化的硬组织和牙髓软组织构成。
:::

:::definition{label="牙周组织"}
牙周组织包括牙根周围的牙周膜、牙槽骨骨膜及牙龈。
:::

:::concept{term="先问这一层是釉质、牙本质还是牙骨质，再问硬组织有没有细胞"}
牙不是一块匀质石头。牙本质是主体、包着牙髓，成牙本质细胞的突起伸进小管；釉质只盖牙冠，无机物约 $96\%$，人体最硬，没有细胞；牙骨质包牙根，近牙颈处薄、无骨细胞。软的是牙髓，神经只报告疼痛、不能定位。把三层硬组织并成“牙齿钙化”，龋洞深度和牙周膜锚定那两本账会没有界面。
:::

### 1. 牙本质

牙本质（dentine）是牙的主体结构，包绕着牙髓腔。牙本质主要由牙本质小管与间质构成。牙本质小管从牙髓腔面向周围呈放射状走行，越向周边越细，且有分支吻合。牙本质的内表面有一层成牙本质细胞（odontoblast），其突起伸入牙本质小管，称牙本质纤维。牙本质小管之间为间质，由胶原纤维与钙化的基质构成，其化学成分与骨质相似，但无机成分约占 $80\%$，比骨质坚硬。有机成分由成牙本质细胞产生。

:::definition{label="牙本质"}
牙本质（dentine）是牙的主体结构，包绕牙髓腔。由牙本质小管与间质构成。间质为胶原纤维与钙化基质，化学成分与骨质相似，但无机成分约占 $80\%$，比骨质坚硬。有机成分由成牙本质细胞产生。
:::

:::definition{label="牙本质小管"}
牙本质小管从牙髓腔面向周围呈放射状走行，越向周边越细，且有分支吻合。内含成牙本质细胞的突起（牙本质纤维）。
:::

:::definition{label="成牙本质细胞"}
成牙本质细胞（odontoblast）排列于牙本质内表面。突起伸入牙本质小管，称牙本质纤维。有机成分由其产生。
:::

:::definition{label="牙本质纤维"}
牙本质纤维是成牙本质细胞伸入牙本质小管的突起。
:::

### 2. 釉质

釉质（enamel）位于牙冠表面，其中无机物约占 $96\%$，有机物很少，故为人体最坚硬的结构。釉质由釉柱和极少量的间质构成。釉柱呈棱柱状，主要成分为羟基磷灰石结晶。釉柱从与牙本质交界处向牙冠表面成放射状排列。在牙磨片中，釉柱呈细纹状，另可见釉质内有一种以牙尖为中心的弧形线，称芮氏线（line of Retzius）。芮氏线是釉质的生长线，因釉质在形成过程中呈间歇性生长所致。在间歇期，釉质生长慢，而有机质含量多，故显微镜下呈现该处折光性较差。

:::definition{label="釉质"}
釉质（enamel）位于牙冠表面。无机物约占 $96\%$，有机物很少，是人体最坚硬的结构。由釉柱和极少量间质构成。
:::

:::definition{label="釉柱"}
釉柱呈棱柱状，主要成分为羟基磷灰石结晶，从牙本质交界处向牙冠表面放射状排列。牙磨片中呈细纹状。
:::

:::definition{label="芮氏线"}
芮氏线（line of Retzius）是釉质内以牙尖为中心的弧形线，即釉质的生长线，因釉质间歇性生长所致。间歇期生长慢、有机质含量多，显微镜下该处折光性较差。
:::

:::pitfall{label="釉质最硬是因为无机物约 96%，不要写成“牙本质比釉质更像骨头所以更硬”"}
牙本质无机成分约 $80\%$，比骨质坚硬，但仍远低于釉质的约 $96\%$。釉质只覆盖牙冠，牙根表面是牙骨质。龋坏穿釉质进入牙本质后，小管把刺激更快导向牙髓，痛觉账才开始响。
:::

### 3. 牙骨质

牙骨质（cementum）包在牙根部的牙本质外面，其组成及结构与骨组织相似。近牙颈部的牙骨质较薄，无骨细胞。

:::definition{label="牙骨质"}
牙骨质（cementum）包在牙根部的牙本质外面，组成及结构与骨组织相似。近牙颈部较薄，无骨细胞。
:::

### 4. 牙髓

牙髓（dental pulp）为疏松结缔组织，内含自牙根孔进入的血管、淋巴管和神经纤维，对牙本质和釉质具有营养作用。牙髓与牙本质间有一层排列整齐的成牙本质细胞。感觉神经末梢包绕成牙本质细胞，并有极少量进入牙本质小管。牙髓神经从牙根孔进入牙髓腔，在成牙本质细胞层下形成神经丛，一部分神经末梢终止在牙本质内表面及成牙本质细胞上，另一部分进入牙本质中。牙髓神经接受感觉有两个特点：①不能区别刺激的性质，对任何刺激均以痛觉反应出现；②缺乏定位感觉，不易确定刺激发生的部位。

:::definition{label="牙髓"}
牙髓（dental pulp）为疏松结缔组织，内含自牙根孔进入的血管、淋巴管和神经纤维，营养牙本质和釉质。与牙本质之间有一层排列整齐的成牙本质细胞。
:::

:::definition{label="牙髓神经的感觉特点"}
牙髓神经：①不能区别刺激的性质，对任何刺激均以痛觉反应出现；②缺乏定位感觉，不易确定刺激发生的部位。
:::

:::pitfall{label="牙髓受到冷热酸甜都报痛，不要指望它能分辨刺激种类或定位哪一颗牙"}
教材把牙髓感觉写成两个缺陷：性质不分、定位不清。临床“哪颗牙在痛”往往要靠检查而不是患者的定位。把牙髓听成皮肤那样的精细触觉，这两条会全部写反。
:::

### 5. 牙周膜

牙周膜（peridental membrane）是位于牙根与牙槽骨间的致密结缔组织，内含较粗的胶原纤维束，其一端埋入牙骨质，另一端伸入牙槽骨，将两者牢固连接。

:::definition{label="牙周膜"}
牙周膜（peridental membrane）是牙根与牙槽骨之间的致密结缔组织，内含较粗胶原纤维束：一端埋入牙骨质，另一端伸入牙槽骨，将两者牢固连接。
:::

### 6. 牙龈

牙龈（gingiva）是由复层扁平上皮及固有层组成的黏膜。牙龈包绕着牙颈。老年人的牙龈常萎缩，牙颈外露。

:::definition{label="牙龈"}
牙龈（gingiva）由复层扁平上皮及固有层组成，包绕牙颈。老年人牙龈常萎缩，牙颈外露。
:::

:::compare{title="牙本质、釉质与牙骨质"}
| 项目 | 牙本质（dentine） | 釉质（enamel） | 牙骨质（cementum） |
|------|-------------------|----------------|---------------------|
| 位置 | 牙的主体，包绕牙髓腔 | 牙冠表面 | 牙根部牙本质外面 |
| 无机物 | 约占 $80\%$，比骨质坚硬 | 约占 $96\%$，人体最硬 | 与骨组织相似 |
| 细胞 | 内表面有成牙本质细胞，突起伸入小管 | 无细胞；由釉柱 + 少量间质构成 | 近牙颈处薄，无骨细胞 |
| 特征结构 | 放射状牙本质小管；牙本质纤维 | 釉柱（羟基磷灰石）；芮氏线（生长线） | 供牙周膜纤维埋入 |
| 营养 | 靠牙髓 | 无血管，间接靠牙髓 | 与牙周组织相关 |
:::

:::compare{title="牙周组织三件"}
| 项目 | 牙周膜 | 牙槽骨骨膜 | 牙龈 |
|------|--------|------------|------|
| 组织 | 致密结缔组织，粗胶原束 | 骨膜 | 复层扁平上皮 + 固有层 |
| 位置 | 牙根与牙槽骨之间 | 牙槽骨表面 | 包绕牙颈 |
| 职分 | 纤维两端分别埋入牙骨质和牙槽骨，锚定牙根 | 与牙周膜共同构成牙周组织 | 封闭牙颈；老年萎缩则牙颈外露 |
:::

## （四）咽

咽是消化管和呼吸道的交叉部位，分为口咽、鼻咽和喉咽 3 部分。

1. 黏膜 由上皮和固有层组成。口咽表面覆以未角化的复层扁平上皮，鼻咽和喉咽主要为假复层纤毛柱状上皮。固有层的结缔组织内有丰富的淋巴组织及黏液腺或混合腺，深部有一层弹性纤维。

2. 肌层 由内纵行与外斜或环行的骨骼肌组成，其间可有黏液腺。

3. 外膜 为富有血管及神经纤维的结缔组织（纤维膜）。

:::definition{label="咽"}
咽是消化管和呼吸道的交叉部位，分为口咽、鼻咽和喉咽 3 部分。管壁为黏膜、骨骼肌肌层和纤维膜，无黏膜肌层。
:::

:::definition{label="咽黏膜上皮"}
口咽表面覆未角化的复层扁平上皮；鼻咽和喉咽主要为假复层纤毛柱状上皮。黏膜由上皮和固有层组成。
:::

:::definition{label="咽的肌层与外膜"}
咽肌层由内纵行与外斜或环行的骨骼肌组成，其间可有黏液腺。外膜为富有血管及神经纤维的结缔组织，即纤维膜。
:::

:::compare{title="口咽、鼻咽与喉咽的上皮"}
| 分部 | 上皮 | 与功能 |
|------|------|--------|
| 口咽 | 未角化复层扁平上皮 | 食物摩擦，保护 |
| 鼻咽 | 主要为假复层纤毛柱状上皮 | 呼吸道黏膜延续 |
| 喉咽 | 主要为假复层纤毛柱状上皮 | 消化与呼吸交叉的下份 |
:::

:::pitfall{label="咽不是全程复层扁平，鼻咽喉咽走的是呼吸道上皮"}
只有口咽按消化管上端写成未角化复层扁平。鼻咽、喉咽主要为假复层纤毛柱状上皮，固有层还有淋巴组织和黏液腺或混合腺。把咽一律写成食管那种复层扁平，交叉部位的呼吸账会消失。
:::

:::insight{label="口腔到咽：保护上皮为主，味觉和淋巴是加在黏膜上的功能模块"}
口底菲薄是为了吸收，硬腭角化是为了摩擦，舌乳头把机械和味觉分开，咽按呼吸/消化交叉改写上皮。四层通例在下一节食管才重新对齐。
:::

:::keypoint{label="口腔先立无黏膜肌，再立三种乳头和牙的三层硬组织"}
- 口腔黏膜 = 复层扁平上皮 + 固有层，无黏膜肌层；仅硬腭角化；口底菲薄通透，可吸收硝酸甘油。
- 人舌乳头三种：丝状（最多，尖端角化，形成舌苔，无味蕾）、菌状（蘑菇状，有味蕾，肉眼红点）、轮廓（10 余个，环沟 + 味腺）。
- 味蕾约 $3000$ 个：味细胞、支持细胞、基细胞；味毛入味孔；甜咸在舌尖，酸苦在两侧及舌根。
- 牙 = 牙本质（主体，无机约 $80\%$）+ 釉质（牙冠，无机约 $96\%$，最硬）+ 牙骨质（牙根）+ 牙髓。
- 牙髓神经：任何刺激都是痛，且缺乏定位。
- 咽分口咽、鼻咽、喉咽；口咽未角化复层扁平，鼻咽和喉咽假复层纤毛柱状；肌层为骨骼肌，外膜为纤维膜。
:::

:::memory{label="本节必背要点"}
- [ ] 口腔黏膜只有上皮和固有层，无黏膜肌层。
- [ ] 口腔上皮为复层扁平上皮，仅在硬腭部出现角化。
- [ ] 口腔底部上皮菲薄、通透性高，利于某些化学物质吸收，如治疗心绞痛的硝酸甘油。
- [ ] 固有层突向上皮形成乳头，富含毛细血管，故黏膜呈红色；乳头及上皮内有许多感觉神经末梢。
- [ ] 固有层中有小唾液腺；唇、颊等处连于骨骼肌，硬腭连于骨膜。
- [ ] 舌由黏膜和深部肌层组成；腹面黏膜薄、光滑、上皮未角化。
- [ ] 舌根部黏膜内有许多淋巴小结，构成舌扁桃体。
- [ ] 舌乳头（lingual papilla）分丝状乳头、菌状乳头和轮廓乳头 3 种。
- [ ] 舌肌层由纵行、横行及垂直 3 种行走方向的骨骼肌交织构成。
- [ ] 丝状乳头数量最多，遍布舌背，圆锥形，尖端上皮角化；角化脱落与唾液、食物残渣混合形成舌苔。
- [ ] 菌状乳头数量较少，主要在舌尖与舌缘，蘑菇状，上皮不角化，内有味蕾；固有层血管丰富，肉眼呈红色小点。
- [ ] 轮廓乳头有 10 余个，位于舌后部界沟前方；顶部平坦，周围黏膜凹陷成环沟，沟两侧上皮内有较多味蕾。
- [ ] 味腺为浆液性，导管开口于环沟底，冲洗味蕾表面的食物碎渣。
- [ ] 味蕾（taste bud）为卵圆形小体，成人约 $3000$ 个，主要在菌状乳头和轮廓乳头，少数在软腭、会厌及咽上皮。
- [ ] 味蕾基部在上皮基膜上，顶端有味孔；细胞分味细胞、支持细胞和基细胞。
- [ ] 支持细胞梭形、数量较多，位于味细胞之间；味细胞梭形、多在中央，顶部微绒毛（味毛）突入味孔，基部与味觉神经末梢形成突触。
- [ ] 基细胞呈矮锥体形，是味细胞的前体干细胞，位于味蕾基部。
- [ ] 味蕾感受甜、苦、酸、咸；甜咸感在舌尖，酸苦感在舌的两侧及舌根。
- [ ] 牙根埋于牙槽骨，牙冠外露，交界为牙颈；牙髓腔开口于牙根孔。
- [ ] 牙由牙本质、釉质、牙骨质 3 种钙化硬组织和牙髓软组织构成。
- [ ] 牙周组织 = 牙周膜 + 牙槽骨骨膜 + 牙龈。
- [ ] 牙本质（dentine）是主体，包绕牙髓腔；小管自髓腔放射状走行，越向周边越细并分支吻合。
- [ ] 成牙本质细胞（odontoblast）位于牙本质内表面，突起伸入小管称牙本质纤维；有机成分由其产生。
- [ ] 牙本质间质为胶原纤维与钙化基质，无机成分约占 $80\%$，比骨质坚硬。
- [ ] 釉质（enamel）在牙冠表面，无机物约占 $96\%$，有机物很少，是人体最坚硬的结构。
- [ ] 釉柱呈棱柱状，成分为羟基磷灰石结晶，自牙本质界向牙冠表面放射状排列。
- [ ] 芮氏线（line of Retzius）是以牙尖为中心的弧形生长线，因釉质间歇性生长；间歇期有机质多、折光性较差。
- [ ] 牙骨质（cementum）包在牙根部牙本质外面，结构与骨组织相似；近牙颈部较薄，无骨细胞。
- [ ] 牙髓（dental pulp）为疏松结缔组织，含经牙根孔进入的血管、淋巴管和神经，营养牙本质和釉质。
- [ ] 牙髓神经在成牙本质细胞层下成丛；部分末梢终止于牙本质内表面及成牙本质细胞，部分进入牙本质。
- [ ] 牙髓感觉特点：不能区别刺激性质，任何刺激均以痛觉出现；缺乏定位感觉。
- [ ] 牙周膜（peridental membrane）是牙根与牙槽骨间的致密结缔组织，粗胶原束一端埋入牙骨质、一端伸入牙槽骨。
- [ ] 牙龈（gingiva）由复层扁平上皮及固有层组成，包绕牙颈；老年人牙龈常萎缩，牙颈外露。
- [ ] 咽是消化管和呼吸道的交叉部位，分口咽、鼻咽和喉咽。
- [ ] 口咽上皮为未角化复层扁平上皮；鼻咽和喉咽主要为假复层纤毛柱状上皮。
- [ ] 咽固有层有丰富淋巴组织及黏液腺或混合腺，深部有一层弹性纤维。
- [ ] 咽肌层为内纵行与外斜或环行的骨骼肌，其间可有黏液腺；外膜为纤维膜。
:::
