# 三、脂肪组织

脂肪组织（adipose tissue）主要由大量群集的脂肪细胞构成，被疏松结缔组织分隔成脂肪小叶。根据脂肪细胞结构和功能的不同，脂肪组织分为两类：黄色脂肪组织和棕色脂肪组织。前者是体内最大的贮能库，后者以产热为主。两种组织里的脂肪细胞都来自间充质方向的分化，但脂滴的数目、核的位置和线粒体的配备完全不同。

:::definition{label="脂肪组织"}
脂肪组织（adipose tissue）主要由大量群集的脂肪细胞构成，被疏松结缔组织分隔成脂肪小叶。按脂肪细胞结构和功能分为黄色脂肪组织和棕色脂肪组织。
:::

:::concept{term="先问脂滴是一个还是一堆"}
看见脂肪组织，先数脂滴、再看核在不在中央。一个大脂滴把核挤到一边，是单泡脂肪细胞，构成黄色脂肪组织；许多大小不一的脂滴、核圆居中、线粒体又大又多，是多泡脂肪细胞，构成棕色脂肪组织。HE 里黄色脂肪细胞呈空泡状，是脂滴被溶掉了，不是细胞空了。
:::

:::pitfall{label="黄色脂肪＝单泡，棕色脂肪＝多泡，不要按“颜色深浅”乱配"}
黄色脂肪组织又称单泡脂肪组织，细胞质内只有一个大脂滴；棕色脂肪组织又称多泡脂肪组织，胞质内散在许多大小不一的脂滴。颜色来自白种人标本中脂溶性色素和丰富毛细血管的观感，不能反过来用“看起来黄不黄”去判断单泡还是多泡。也不要把棕色脂肪记成“脂肪细胞少、结缔组织多”——它只是细胞较小、血管更丰富。
:::

## 1. 黄色脂肪组织

黄色脂肪组织（yellow adipose tissue）即通常所说的脂肪组织（图 3-17），主要分布在皮下、网膜和系膜等处，是体内最大的贮能库，还具有维持体温、缓冲、保护和填充等作用。脂肪细胞体积大，细胞质内只有一个大的脂滴，称单泡脂肪细胞（图 3-18），因此，黄色脂肪组织又称单泡脂肪组织（unilocular adipose tissue）。单泡脂肪细胞可分泌瘦素（leptin），通过刺激下丘脑的活动抑制食欲，抑制脂肪合成。

:::definition{label="黄色脂肪组织"}
黄色脂肪组织（yellow adipose tissue）即通常所说的脂肪组织，主要分布在皮下、网膜和系膜等处。它是体内最大的贮能库，并具有维持体温、缓冲、保护和填充等作用。因脂肪细胞为单泡脂肪细胞，又称单泡脂肪组织（unilocular adipose tissue）。
:::

:::definition{label="单泡脂肪细胞"}
单泡脂肪细胞的细胞质内只有一个大脂滴，将其余细胞质和细胞核挤到周缘，核呈弯月形、位于一侧。直径可达 $50\sim 100\,\mu\mathrm{m}$。HE 染色中脂滴被溶解，细胞呈空泡状。
:::

:::definition{label="瘦素"}
瘦素（leptin）由单泡脂肪细胞分泌，通过刺激下丘脑的活动抑制食欲、抑制脂肪合成，是脂肪组织参与能量代谢调控的重要激素。
:::

## 2. 棕色脂肪组织

棕色脂肪组织（brown adipose tissue）的特点是组织中有丰富的毛细血管，脂肪细胞较小，细胞质内散在许多大小不一的脂滴，线粒体大而丰富，细胞核圆，居中，称多泡脂肪细胞（图 3-18），因此，棕色脂肪组织又称多泡脂肪组织（multilocular adipose tissue）。棕色脂肪组织在成人极少，在新生儿及冬眠动物较多，主要分布在新生儿的肩胛间区、腋窝及颈后部。在寒冷的刺激下，多泡脂肪细胞内的脂类分解、氧化，产生大量热能。丰富的毛细血管既带来氧气和底物，也把热量迅速送走。

:::definition{label="棕色脂肪组织"}
棕色脂肪组织（brown adipose tissue）含丰富毛细血管；脂肪细胞较小，为多泡脂肪细胞，故又称多泡脂肪组织（multilocular adipose tissue）。成人极少，新生儿及冬眠动物较多，主要分布在新生儿的肩胛间区、腋窝及颈后部。寒冷刺激下，多泡脂肪细胞内脂类分解、氧化，产生大量热能。
:::

:::definition{label="多泡脂肪细胞"}
多泡脂肪细胞的细胞质内散在许多大小不一的脂滴，线粒体大而丰富，细胞核圆、居中。它构成棕色脂肪组织，主要功能是氧化产热，而不是把脂肪长期贮存为单一大脂滴。
:::

::figure{src="/images/histology/textbook/p0050_01.png" caption="图3-18 单泡脂肪细胞（左）和多泡脂肪细胞（右）超微结构模式图。左：一个大脂滴将核挤至一侧；右：多数脂滴、丰富线粒体，核圆居中。" alt="单泡脂肪细胞与多泡脂肪细胞超微结构对照"}

:::compare{title="黄色脂肪组织与棕色脂肪组织"}
| 项目 | 黄色脂肪组织 | 棕色脂肪组织 |
|------|--------------|--------------|
| 别称 | 单泡脂肪组织（unilocular adipose tissue） | 多泡脂肪组织（multilocular adipose tissue） |
| 脂肪细胞 | 单泡脂肪细胞：体积大，一个大脂滴，核弯月形、偏一侧 | 多泡脂肪细胞：细胞较小，多数大小不一的脂滴，核圆、居中 |
| 线粒体 | 相对较少，被挤到周缘胞质 | 大而丰富 |
| 血管 | 有，但不如棕色脂肪丰富 | 毛细血管丰富 |
| 分布 | 皮下、网膜、系膜等；通常所说的“脂肪” | 成人极少；新生儿肩胛间区、腋窝及颈后部；冬眠动物较多 |
| 主要功能 | 体内最大贮能库；维持体温、缓冲、保护、填充；分泌瘦素 | 寒冷刺激下脂类分解氧化，产生大量热能 |
| HE 所见 | 空泡状细胞密集成小叶，核被挤到一侧 | 胞质内多空泡（多脂滴被溶），核居中，间质血管多 |
:::

:::cause-effect{title="为什么棕色脂肪能产热、黄色脂肪主要贮能"}
- 因：多泡脂肪细胞把脂肪拆成许多小脂滴，并配备大量线粒体，毛细血管又丰富
- 果：寒冷刺激下脂类迅速分解、氧化，热量经血流带走
- 因：单泡脂肪细胞把脂肪合成一个大脂滴，胞质和线粒体被挤到周缘
- 果：适合长期贮存；需要时再动员。单泡细胞还分泌瘦素，经下丘脑抑制食欲和脂肪合成，形成负反馈
:::

:::keypoint{label="脂肪组织按单泡还是多泡分成两型"}
- 脂肪组织由大量脂肪细胞构成，疏松结缔组织将其分隔成小叶。
- 黄色／单泡：一个大脂滴，核偏位；皮下、网膜、系膜；贮能、保温、缓冲、保护、填充；分泌瘦素。
- 棕色／多泡：多数脂滴，核居中，线粒体和毛细血管丰富；新生儿肩胛间、腋窝、颈后及冬眠动物；寒冷时氧化产热。
- HE 中脂滴均被溶解，辨认靠核的位置和空泡是一个还是一堆。
:::
