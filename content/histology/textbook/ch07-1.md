# 一、神经元

神经组织（nervous tissue）由神经细胞和神经胶质细胞组成，是神经系统中最主要的组织成分。神经元（neuron）也称神经细胞（nerve cell），人体约有 $10^{10}$ 个。每个神经元都具有接受刺激、整合信息和传导冲动的能力；通过神经元之间的联系，把接收的信息加以分析或贮存，并传递给各种肌细胞、腺细胞等效应细胞，以产生效应；此外，它们也是意识、记忆、思维和行为调节的基础。神经胶质细胞（neuroglial cell）的数量为神经元的 $10\sim 50$ 倍，对神经元不仅起支持、保护、营养和绝缘等作用，也参与神经递质和活性物质的代谢，对神经组织的生理和病理等方面都有重要的影响。本章先把神经元的胞体、树突、轴突和分类账立住；突触和神经胶质细胞各立一节，神经干细胞、神经纤维、末梢和溃变再生另见后文。

:::definition{label="神经组织"}
神经组织（nervous tissue）由神经细胞和神经胶质细胞组成，是神经系统中最主要的组织成分。
:::

:::definition{label="神经元"}
神经元（neuron）也称神经细胞（nerve cell）。人体约有 $10^{10}$ 个。每个神经元都具有接受刺激、整合信息和传导冲动的能力；通过神经元之间的联系，把接收的信息加以分析或贮存，并传递给肌细胞、腺细胞等效应细胞以产生效应；也是意识、记忆、思维和行为调节的基础。
:::

:::definition{label="神经胶质细胞"}
神经胶质细胞（neuroglial cell）数量为神经元的 $10\sim 50$ 倍。对神经元起支持、保护、营养和绝缘等作用，并参与神经递质和活性物质的代谢，影响神经组织的生理和病理过程。具体分型见第三节。
:::

:::concept{term="先问谁在传信息，谁在把线路隔开"}
看见一张神经组织切片，先问两件事：哪一种细胞有尼氏体、能发冲动；哪一种细胞把神经元彼此隔开、不让信号串线。能接受刺激、整合信息、传导冲动的是神经元；数量多出 $10\sim 50$ 倍、专管支持、保护、营养和绝缘的是神经胶质细胞。把胶质听成“少功能的神经元”，或把神经组织听成“全是神经元”，后文突触专一性和髓鞘账都会做丢。
:::

| 项目 | 神经元（神经细胞） | 神经胶质细胞 |
|------|--------------------|--------------|
| 英文 | neuron，nerve cell | neuroglial cell |
| 数量 | 人体约 $10^{10}$ 个 | 约为神经元的 $10\sim 50$ 倍 |

| 光镜线索 | 大而圆的浅染核、核仁明显；胞质可有尼氏体 | HE 中除室管膜外不易区分，需镀银显示全貌 |
| 本章位置 | 本节摊开结构与分类 | 第三节按中枢四型和周围两型写开 |
:::

:::pitfall{label="神经组织不是“神经元的集合”，胶质细胞必须单独立账"}
教材把神经组织写成神经细胞加神经胶质细胞。胶质不是可有可无的填充：除突触部位外，神经元与神经元、神经元与非神经细胞之间一般都被胶质分隔、绝缘，信息传递才专一、不受干扰。数量上胶质还远多于神经元。把本章只背成“神经元有树突和轴突”，会把绝缘、血–脑屏障、髓鞘和损伤修复那几本账一起丢掉。
:::

神经元的形态不一，但都可分为胞体、树突和轴突 3 部分（图 7-1）。

:::definition{label="神经元的三分结构"}
不论外形如何，神经元都分为胞体、树突和轴突 3 部分。胞体是营养和代谢中心；树突主要接受刺激；轴突主要传导神经冲动。
:::

## （一）神经元的结构

### 1. 胞体

胞体是神经元的营养和代谢中心，主要位于大脑和小脑的皮质、脑干和脊髓的灰质以及神经节内，形状有圆形、锥形、梭形和星形等，大小相差悬殊，小的直径仅 $4\sim 5\,\mu\mathrm{m}$，大的可达到 $150\,\mu\mathrm{m}$，均由细胞核、细胞质和细胞膜构成（图 7-2）。

:::definition{label="神经元胞体"}
胞体是神经元的营养和代谢中心。主要位于大脑和小脑的皮质、脑干和脊髓的灰质以及神经节内。形状有圆形、锥形、梭形和星形等；直径小者仅 $4\sim 5\,\mu\mathrm{m}$，大者可达 $150\,\mu\mathrm{m}$。由细胞核、细胞质和细胞膜构成。
:::

:::concept{term="先问胞体落在灰质还是神经节"}
轴突可以走出很远，胞体却几乎都堆在中枢的灰质和周围的神经节里。看见一个大而圆、核仁明显的浅染核，先问它是皮质/脊髓灰质里的多极神经元，还是神经节里的假单极或双极神经元，再去数尼氏体是斑块还是细颗粒。把胞体听成“跟着神经纤维走遍全身”，会把灰质、神经节和白质三本账做乱。
:::

**（1）细胞核** 位于胞体中央，大而圆，核被膜明显，常染色质多，故着色浅，核仁也大而圆。

:::definition{label="神经元细胞核"}
神经元细胞核位于胞体中央，大而圆，核被膜明显；常染色质多，故着色浅；核仁也大而圆。光镜下这颗“大空泡核加圆核仁”，是认神经元胞体的第一线索。
:::

**（2）细胞质** 在光镜下，其特征性结构为尼氏体和神经原纤维（图 7-3）。

尼氏体（Nissl’s body）具有强嗜碱性，均匀分布。在大神经元中，如脊髓运动神经元，尼氏体呈粗大的斑块状；在小神经元中，如神经节内的神经元，尼氏体呈细颗粒状。电镜下，尼氏体由发达的粗面内质网和游离核糖体构成，表明神经元具有活跃的蛋白质合成功能，主要合成更新细胞器所需的结构蛋白、神经递质所需的酶类以及肽类的神经调质。神经递质（neurotransmitter）是神经元向其他神经元或效应细胞传递信息的化学载体，一般为小分子物质，主要在胞体合成后以小泡的形式贮存于神经元的轴突终末。神经调质（neuromodulator）一般为肽类，能增强或减弱神经元对神经递质的反应，起调节作用。

:::definition{label="尼氏体"}
尼氏体（Nissl’s body）是光镜下神经元胞质的特征性结构，强嗜碱性、均匀分布。大神经元（如脊髓运动神经元）呈粗大斑块状；小神经元（如神经节内神经元）呈细颗粒状。电镜下由发达的粗面内质网和游离核糖体构成，负责合成结构蛋白、递质所需酶类和肽类神经调质。
:::

:::definition{label="神经递质"}
神经递质（neurotransmitter）是神经元向其他神经元或效应细胞传递信息的化学载体，一般为小分子物质，主要在胞体合成后以小泡的形式贮存于轴突终末。
:::

:::definition{label="神经调质"}
神经调质（neuromodulator）一般为肽类，能增强或减弱神经元对神经递质的反应，起调节作用。一般一个神经元只释放一种神经递质，同时还可释放一种神经调质。
:::

:::compare{title="大神经元与小神经元的尼氏体"}
| 项目 | 大神经元 | 小神经元 |
|------|----------|----------|
| 典型例子 | 脊髓运动神经元 | 神经节内的神经元 |
| 尼氏体光镜形态 | 粗大的斑块状 | 细颗粒状 |
| 嗜碱性 | 强，均匀分布 | 强，均匀分布 |
| 电镜本质 | 均为发达粗面内质网 + 游离核糖体 | 同左 |
| 功能含义 | 蛋白质合成旺盛 | 同左，只是光镜下颗粒更细 |
:::

:::pitfall{label="轴丘没有尼氏体，不要把淡染圆锥当成破损"}
胞体发出轴突的部位呈圆锥形，称轴丘，此区无尼氏体，故染色淡。切片上胞体一侧出现一块浅染区，是轴突的出发口，不是尼氏体溶解，也不是制片伪影。后文写溃变时才会见到全胞质尼氏体溶解、着色浅淡——那是损伤账，不要提前安到正常轴丘上。
:::

:::compare{title="神经递质与神经调质"}
| 项目 | 神经递质 | 神经调质 |
|------|----------|----------|
| 英文 | neurotransmitter | neuromodulator |
| 化学性质 | 一般为小分子 | 一般为肽类 |
| 合成与贮存 | 主要在胞体合成，小泡贮存于轴突终末 | 肽类调质同样由尼氏体系统合成 |
| 作用 | 作为化学载体，向其他神经元或效应细胞传递信息 | 增强或减弱神经元对递质的反应，起调节作用 |
| 共存 | 一般一个神经元只释放一种递质 | 同时还可释放一种调质 |
:::

神经原纤维（neurofibril）在 HE 染色切片中无法分辨，在镀银染色切片中呈棕黑色细丝，交错排列成网，并伸入树突和轴突（图 7-3）。电镜下，神经原纤维由神经丝和微管构成。神经丝（neurofilament）是由神经丝蛋白构成的一种中间丝，微管是由微管相关蛋白 2（microtubule-associated protein 2）构成。神经丝和神经管构成神经元的细胞骨架，微管还参与物质运输。

细胞质中还含有线粒体、高尔基复合体、溶酶体等细胞器。此外也含有溶酶体的残余体——脂褐素，随年龄增长而增多。

:::definition{label="神经原纤维"}
神经原纤维（neurofibril）在 HE 切片中无法分辨；镀银染色呈棕黑色细丝，交错成网，并伸入树突和轴突。电镜下由神经丝和微管构成，是神经元的细胞骨架，微管还参与物质运输。
:::

:::definition{label="神经丝"}
神经丝（neurofilament）是由神经丝蛋白构成的一种中间丝，与微管一起构成神经原纤维，并参与神经元细胞骨架。
:::

:::definition{label="脂褐素"}
脂褐素是溶酶体的残余体，位于神经元胞质中，随年龄增长而增多。心肌纤维核周也可见脂褐素，同属老化过程中的残余体类色素。
:::

:::note{label="微管相关蛋白 2 把树突里的微管稳住"}
教材写“微管是由微管相关蛋白 2（MAP2）构成”，强调的是树突胞质与胞体相似、含 MAP2 构成的微管。微管的管壁亚基是微管蛋白；MAP2 是结合在微管上的相关蛋白，把树突侧的骨架和运输轨道定住。轴突运输那一本账，主要靠微管，不靠尼氏体。
:::

:::pitfall{label="细胞骨架是神经丝加微管，不是胚胎神经管"}
电镜下神经原纤维 = 神经丝 + 微管。教材随后写“神经丝和神经管构成神经元的细胞骨架”，这里的“神经管”应读作微管网架，不是胚胎时期的神经管。HE 里看不见神经原纤维，必须换镀银；把 HE 胞质里的嗜碱斑块当成神经原纤维，会把尼氏体和骨架两本账合成一张。
:::

**（3）细胞膜** 是可兴奋膜，具有接受刺激、处理信息、产生和传导神经冲动的功能。神经元细胞膜的性质取决于膜蛋白，其中有些是离子通道，如 $\mathrm{Na}^{+}$ 通道、$\mathrm{K}^{+}$ 通道、$\mathrm{Ca}^{2+}$ 通道和 $\mathrm{Cl}^{-}$ 通道等；有些膜蛋白是受体，与相应的神经递质结合后，可使某种离子通道开放。

:::definition{label="神经元细胞膜"}
神经元细胞膜是可兴奋膜，能接受刺激、处理信息、产生和传导神经冲动。性质取决于膜蛋白：一类是离子通道（$\mathrm{Na}^{+}$、$\mathrm{K}^{+}$、$\mathrm{Ca}^{2+}$、$\mathrm{Cl}^{-}$ 等）；一类是受体，与相应神经递质结合后使某种离子通道开放。
:::

:::insight{label="胞体合成，轴膜才把冲动写出去"}
尼氏体证明胞体是蛋白质工厂：结构蛋白、递质酶类和肽类调质都在这里生产。可兴奋的是膜，尤其是轴突起始段的轴膜。把“神经元会放电”只记在胞体上，会漏掉起始段；把合成只记在轴突终末，又会漏掉尼氏体。合成在胞体，起步在起始段，释放在终末——三本账不要并成一句。
:::

### 2. 树突

树突（dendrite）每个神经元有一至多个树突，形如树枝状，即从树突干发出许多分支。在分支上常可见大量短小突起，称树突棘（dendritic spine）（图 7-4）。树突内细胞质的结构与胞体相似，也含有微管相关蛋白 2 构成的微管。树突的功能主要是接受刺激。树突和树突棘极大地扩展了神经元接受刺激的表面积。因此，神经元接受信息和整合信息的能力与其树突的分支程度以及树突棘的数量密切相关。

:::definition{label="树突"}
树突（dendrite）每个神经元有一至多个，呈树枝状，从树突干发出许多分支。胞质结构与胞体相似，含 MAP2 构成的微管。主要功能是接受刺激。
:::

:::definition{label="树突棘"}
树突棘（dendritic spine）是树突分支上大量短小的突起。树突和树突棘极大扩展接受刺激的表面积；神经元接受和整合信息的能力与树突分支程度及树突棘数量密切相关。
:::

:::concept{term="先问树突棘密不密，再问这颗细胞能接多少突触"}
树突不是“反向的轴突”。它有尼氏体样的合成机器，有棘，表面积被刻意摊开，专门用来接刺激。下一节小脑浦肯野细胞的树突上可以有数十万个突触，靠的就是这张被分支和棘撑开的膜。把树突只记成“短突起”，会把整合信息的形态学基础做丢。
:::

### 3. 轴突

轴突（axon）每个神经元只有一个轴突，一般由胞体发出，短者仅数微米，长者可达 $1\,\mathrm{m}$ 以上。光镜下胞体发出轴突的部位常呈圆锥形，称轴丘（axon hillock），此区无尼氏体，故染色淡。轴突一般比树突细，直径较均一，有侧支呈直角分出（图 7-5）。轴突末端的分支较多，形成轴突终末。轴突表面的细胞膜称轴膜（axolemma），内含的细胞质称轴质（axoplasm）。轴质内有大量神经丝和微管，还有滑面内质网、微丝、线粒体和小泡。神经丝、微管和微丝之间均有横桥连接，构成轴质中的网架。轴突内无粗面内质网和游离核糖体，故不能合成蛋白质。

轴突起始段的轴膜较厚，膜下有电子密度高的致密层。此段轴膜易引起电兴奋，常是神经元产生神经冲动的起始部位。神经冲动形成后沿轴膜向终末传递，因此轴突的主要功能是传导神经冲动。

:::definition{label="轴突"}
轴突（axon）每个神经元只有一个，一般由胞体发出；短者仅数微米，长者可达 $1\,\mathrm{m}$ 以上。比树突细，直径较均一，侧支呈直角分出，末端分支形成轴突终末。主要功能是传导神经冲动。
:::

:::definition{label="轴丘"}
轴丘（axon hillock）是光镜下胞体发出轴突的圆锥形部位，此区无尼氏体，故染色淡。它是认轴突起点的光镜标志。
:::

:::definition{label="轴膜"}
轴膜（axolemma）是轴突表面的细胞膜。神经冲动沿轴膜向终末传递。起始段轴膜较厚，膜下有电子密度高的致密层，易引起电兴奋，常是产生神经冲动的起始部位。
:::

:::definition{label="轴质"}
轴质（axoplasm）是轴突内含的细胞质。含大量神经丝和微管，以及滑面内质网、微丝、线粒体和小泡；神经丝、微管和微丝之间有横桥连接，构成网架。无粗面内质网和游离核糖体，故不能合成蛋白质。
:::

:::compare{title="树突与轴突"}
| 项目 | 树突 | 轴突 |
|------|------|------|
| 数目 | 一至多个 | 每个神经元只有一个 |
| 外形 | 树枝状，反复分支；可有树突棘 | 细而均一；侧支呈直角分出；末端成轴突终末 |
| 起点标志 | 自胞体发出的树突干 | 轴丘（圆锥形，无尼氏体，染色淡） |
| 胞质 | 与胞体相似，含 MAP2 微管，可有尼氏体 | 轴质：神经丝、微管、滑面内质网、微丝、线粒体、小泡；无粗面内质网和游离核糖体 |
| 蛋白质合成 | 可合成 | 不能合成，靠轴突运输从胞体运来 |
| 主要功能 | 接受刺激，扩展接受面积 | 传导神经冲动（沿轴膜） |
| 冲动起步 | 不是起步点 | 起始段轴膜厚、膜下致密，常为起步点 |
:::

:::pitfall{label="轴突不能合成蛋白质，终末的酶和小泡都是运过去的"}
轴质里没有粗面内质网和游离核糖体，所以轴突自己造不出蛋白质。轴膜更新所需的蛋白质、合成递质的酶、含递质或调质的小泡、线粒体，都要由胞体经轴突运输送达。把终末里的突触小泡理解成“在轴突里现场合成”，会把尼氏体和运输两本账一起错。
:::

::figure{src="/images/histology/textbook/p0085_01.png" caption="图7-5 运动神经元模式图。示树突、尼氏体、细胞核、轴突、侧支、髓鞘、施万细胞核、郎飞结、轴突终末、运动终板和骨骼肌纤维。" alt="运动神经元全貌：树突与斑块尼氏体、一条有髓轴突经郎飞结到达运动终板"}

轴突内的物质运输称轴突运输（axonal transport）。由细胞体向轴突终末运输的过程称为顺向轴突运输（anterograde axonal transport）。反之，轴突终末的代谢产物或由轴突终末摄取的物质，如蛋白质、小分子物质、外源性物质等，逆向转运到细胞体，称为逆向轴突运输（retrograde axonal transport）。细胞体内新形成的神经丝、微管和微丝以 $1\sim 4\,\mathrm{mm/d}$ 的速度缓慢地向轴突终末转运，称为慢速轴突运输。轴膜更新所需的蛋白质、合成神经递质的酶、含神经递质或神经调质的小泡、线粒体等，以 $100\sim 400\,\mathrm{mm/d}$ 的速度由胞体向轴突终末输送，称快速顺向轴突运输。轴突终末内的代谢产物或由轴突终末摄取的物质（蛋白质、小分子物质或由邻近细胞产生的神经营养因子等）逆向运输到胞体，称快速逆向轴突运输。某些病毒或毒素（如狂犬病毒、脊髓灰质炎病毒和破伤风毒素）也可经逆向轴突运输侵犯神经元胞体。微管在轴突运输中起重要作用。

:::definition{label="轴突运输"}
轴突运输（axonal transport）是轴突内的物质运输。由胞体到终末为顺向轴突运输（anterograde axonal transport）；由终末到胞体为逆向轴突运输（retrograde axonal transport）。微管在轴突运输中起重要作用。
:::

:::definition{label="慢速轴突运输"}
慢速轴突运输指细胞体内新形成的神经丝、微管和微丝以 $1\sim 4\,\mathrm{mm/d}$ 的速度缓慢向轴突终末转运。
:::

:::definition{label="快速顺向轴突运输"}
快速顺向轴突运输以 $100\sim 400\,\mathrm{mm/d}$ 的速度由胞体向轴突终末输送轴膜更新所需的蛋白质、合成神经递质的酶、含神经递质或神经调质的小泡、线粒体等。
:::

:::definition{label="快速逆向轴突运输"}
快速逆向轴突运输把轴突终末内的代谢产物，或由终末摄取的蛋白质、小分子物质及邻近细胞产生的神经营养因子等，逆向运回胞体。狂犬病毒、脊髓灰质炎病毒和破伤风毒素也可经此途径侵犯神经元胞体。
:::

:::compare{title="顺向与逆向、慢速与快速轴突运输"}
| 类型 | 方向 | 速度 | 主要载荷 |
|------|------|------|----------|
| 慢速轴突运输 | 顺向（胞体 → 终末） | $1\sim 4\,\mathrm{mm/d}$ | 新形成的神经丝、微管和微丝 |
| 快速顺向轴突运输 | 顺向（胞体 → 终末） | $100\sim 400\,\mathrm{mm/d}$ | 轴膜更新蛋白、递质合成酶、含递质或调质的小泡、线粒体 |
| 快速逆向轴突运输 | 逆向（终末 → 胞体） | 快速（教材归入逆向快速一类） | 终末代谢产物；摄取的蛋白质、小分子、神经营养因子；某些病毒和毒素 |
:::

:::timeline{period="轴突运输怎样从胞体写到终末、再写回来"}
- **胞体合成** 尼氏体生产结构蛋白、递质酶类和肽类调质，装配神经丝、微管、微丝和小泡
- **慢速顺向** $1\sim 4\,\mathrm{mm/d}$ — 细胞骨架成分运往终末，维持轴质网架
- **快速顺向** $100\sim 400\,\mathrm{mm/d}$ — 膜蛋白、酶、含递质或调质的小泡、线粒体送达终末
- **终末作业** 小泡待命释放；线粒体供能；代谢产物堆积
- **快速逆向** 代谢产物、神经营养因子以及狂犬病毒、脊髓灰质炎病毒、破伤风毒素沿微管运回胞体
:::

:::cause-effect{title="为什么病毒和毒素能顺着轴突打到胞体"}
- 因：轴突终末可摄取蛋白质、小分子及外源性物质，并经快速逆向轴突运输运回胞体
- 因：微管在轴突运输中起重要作用，这条轨道不区分“营养因子”还是“病原”
- 果：狂犬病毒、脊髓灰质炎病毒和破伤风毒素可经逆向运输侵犯神经元胞体
- 制约：这是终末摄取加逆向运输的正常通道被占用，不是轴突自己合成了病毒蛋白
:::

## （二）神经元的分类

### 1. 按神经元的突起数量

可分为 3 类：①多极神经元（multipolar neuron）：有一个轴突和多个树突。②双极神经元（bipolar neuron）：有树突和轴突各一个。③假单极神经元（pseudounipolar neuron）：从胞体发出一个突起，但在不远处呈 T 形分为两支，一支进入中枢神经系统，称中枢突；另一支分布到周围的其他器官，称周围突（图 7-6）。中枢突传出神经冲动，是轴突；周围突接受刺激，具有树突的功能，但因其细而长，在结构上与轴突相同，故也称轴突。

:::definition{label="多极神经元"}
多极神经元（multipolar neuron）有一个轴突和多个树突。脊髓前角运动神经元、大脑锥体细胞、小脑浦肯野细胞以及绝大多数中间神经元属此类。
:::

:::definition{label="双极神经元"}
双极神经元（bipolar neuron）有树突和轴突各一个。如耳蜗神经节内的双极神经元。
:::

:::definition{label="假单极神经元"}
假单极神经元（pseudounipolar neuron）从胞体发出一个突起，不远处呈 T 形分为两支：中枢突进入中枢神经系统，周围突分布到周围器官。中枢突传出神经冲动，是轴突；周围突接受刺激，具有树突的功能，但细而长、结构与轴突相同，故也称轴突。
:::

:::pitfall{label="假单极不是真的只有一个突起，周围突功能上是树突"}
光镜下从胞体只看到一根突起，所以叫“假”单极：那根突起马上 T 形分叉。功能账要拆开——周围突接受刺激，相当于树突；中枢突把冲动送进中枢，是轴突。结构账又并回去——周围突细而长，与轴突同貌，教材也称之为轴突。把假单极听成“只有轴突没有树突”，或把周围突按树枝状树突去找棘，都会认错脊神经节细胞。
:::

:::compare{title="按突起数量分三型"}
| 项目 | 多极神经元 | 双极神经元 | 假单极神经元 |
|------|------------|------------|--------------|
| 英文 | multipolar neuron | bipolar neuron | pseudounipolar neuron |
| 树突 | 多个 | 一个 | 无典型树突；周围突功能上相当于树突 |
| 轴突 | 一个 | 一个 | 中枢突是轴突；周围突结构上也称轴突 |
| 胞体突起数 | 多个 | 两个 | 一个，随即 T 形分支 |
| 典型位置 | 中枢灰质、前角、皮质 | 耳蜗神经节等特殊感觉通路 | 脊神经节等 |
| 与功能分型的对应 | 运动神经元、中间神经元多为多极 | — | 感觉神经元多为假单极 |
:::

### 2. 按神经元轴突的长短

可分为 2 类：①高尔基Ⅰ型神经元（Golgi type Ⅰ neuron）：是具有长轴突（可长达 $1\,\mathrm{m}$ 以上）的大神经元。②高尔基Ⅱ型神经元（Golgi type Ⅱ neuron）：是具有短轴突（仅数微米）的小神经元。

:::definition{label="高尔基Ⅰ型神经元"}
高尔基Ⅰ型神经元（Golgi type Ⅰ neuron）是具有长轴突（可长达 $1\,\mathrm{m}$ 以上）的大神经元。
:::

:::definition{label="高尔基Ⅱ型神经元"}
高尔基Ⅱ型神经元（Golgi type Ⅱ neuron）是具有短轴突（仅数微米）的小神经元。
:::

:::note{label="高尔基分型问的是轴突长短，不是突起数目"}
多极/双极/假单极按突起数量分类；高尔基Ⅰ/Ⅱ型按轴突长短分类。一个脊髓前角运动神经元既是多极，也常是高尔基Ⅰ型；许多局部回路中的小神经元既是多极，也是高尔基Ⅱ型。两套标签叠在同一颗细胞上，不要互相替代。
:::

### 3. 按神经元的功能

可分为 3 类：①感觉神经元（sensory neuron）：又称传入神经元（afferent neuron），多为假单极神经元，可接受体内、外的化学或物理性刺激，并将信息传向中枢。②运动神经元（motor neuron）：又称传出神经元（efferent neuron），一般为多极神经元，负责把神经冲动传递给肌细胞或腺细胞。③中间神经元（interneuron）：主要为多极神经元，位于前两种神经元之间，起信息加工和传递作用。机体对来自体内、外的刺激所作的反应（亦称反射）均需这 3 类神经元参与，它们和感受器、效应器共同构成反射弧（图 7-6）。动物越进化，其中间神经元越多。人的中间神经元占神经元总数的 $99\%$ 以上，在中枢神经系统内构成复杂的神经元网络，是学习、记忆和思维的基础。

:::definition{label="感觉神经元"}
感觉神经元（sensory neuron）又称传入神经元（afferent neuron），多为假单极神经元，接受体内、外的化学或物理性刺激，并将信息传向中枢。
:::

:::definition{label="运动神经元"}
运动神经元（motor neuron）又称传出神经元（efferent neuron），一般为多极神经元，把神经冲动传递给肌细胞或腺细胞。
:::

:::definition{label="中间神经元"}
中间神经元（interneuron）主要为多极神经元，位于感觉神经元与运动神经元之间，起信息加工和传递作用。人的中间神经元占神经元总数的 $99\%$ 以上，构成中枢内复杂的神经元网络，是学习、记忆和思维的基础。
:::

:::definition{label="反射弧"}
反射弧由感受器、感觉神经元、中间神经元、运动神经元和效应器共同构成。机体对体内、外刺激所作的反应（反射）均需感觉、运动、中间这 3 类神经元参与。
:::

:::concept{term="先问信息往哪走：进中枢、出中枢，还是在中枢里转"}
功能分型其实是方向分型。感觉神经元把刺激送进中枢（传入、多为假单极）；运动神经元把冲动送给肌或腺（传出、一般为多极）；中间神经元夹在两者之间做加工（主要为多极，人脑里超过 $99\%$）。图 7-6 里脊神经节细胞、前角运动神经元和灰质里的中间神经元，正好是这三本账。把“多极”直接等同于“运动”，会把占绝对多数的中间神经元做丢。
:::

:::compare{title="感觉、运动与中间神经元"}
| 项目 | 感觉神经元 | 运动神经元 | 中间神经元 |
|------|------------|------------|------------|
| 别名 | 传入神经元 | 传出神经元 | — |
| 英文 | sensory / afferent neuron | motor / efferent neuron | interneuron |
| 常见形态 | 多为假单极 | 一般为多极 | 主要为多极 |
| 信息方向 | 体内外刺激 → 中枢 | 中枢 → 肌细胞或腺细胞 | 在前两种之间加工和传递 |
| 数量 | 相对少 | 相对少 | 人占神经元总数 $99\%$ 以上 |
| 反射弧中的位置 | 感受器侧 | 效应器侧 | 中枢内网络 |
:::

### 4. 按神经元释放的神经递质和神经调质的化学性质进行分类

①胆碱能神经元：释放乙酰胆碱。②去甲肾上腺素能神经元：释放去甲肾上腺素。③胺能神经元：释放多巴胺、5-羟色胺等。④氨基酸能神经元：释放 $\gamma$-氨基丁酸、甘氨酸和谷氨酸等。⑤肽能神经元：释放脑啡肽、P 物质和神经降压素等，常统称神经肽。另外，一氧化氮（nitric oxide，NO）和一氧化碳（carbon monoxide，CO）也是一种神经递质。一般一个神经元只释放一种神经递质，同时还可释放一种神经调质。

:::definition{label="按化学性质的神经元分型"}
按释放的神经递质和神经调质的化学性质，神经元分为胆碱能（乙酰胆碱）、去甲肾上腺素能（去甲肾上腺素）、胺能（多巴胺、5-羟色胺等）、氨基酸能（$\gamma$-氨基丁酸、甘氨酸、谷氨酸等）和肽能（脑啡肽、P 物质、神经降压素等神经肽）。一氧化氮和一氧化碳也是神经递质。
:::

:::compare{title="按化学性质分类的主要递质"}
| 类型 | 释放的化学物质 |
|------|----------------|
| 胆碱能神经元 | 乙酰胆碱 |
| 去甲肾上腺素能神经元 | 去甲肾上腺素 |
| 胺能神经元 | 多巴胺、5-羟色胺等 |
| 氨基酸能神经元 | $\gamma$-氨基丁酸、甘氨酸、谷氨酸等 |
| 肽能神经元 | 脑啡肽、P 物质、神经降压素等（神经肽） |
| 气体类（教材单列） | 一氧化氮（NO）、一氧化碳（CO） |
:::

:::insight{label="同一颗细胞可以同时带递质和调质，但递质一般只有一种"}
一般一个神经元只释放一种神经递质，同时还可释放一种神经调质。下一节突触小泡的形态会把这本化学账写成电镜像：圆形清亮小泡多含乙酰胆碱，颗粒型小泡含单胺类，扁平清亮小泡含甘氨酸等，大颗粒型小泡含神经肽。先在胞体侧把“释放什么”立住，终末侧才认得出小泡。
:::

:::keypoint{label="神经元先把三分结构、合成运输和四套分类立住"}
- 神经组织 = 神经元 + 神经胶质细胞；胶质数量为神经元的 $10\sim 50$ 倍。
- 神经元一律分为胞体、树突、轴突；胞体是营养代谢中心，位于灰质和神经节。
- 尼氏体 = 粗面内质网 + 游离核糖体，强嗜碱；轴丘无尼氏体。神经原纤维镀银才见，电镜为神经丝 + 微管。
- 树突及树突棘接受刺激；轴突传导冲动，起始段起步；轴质不能合成蛋白质。
- 运输：慢速顺向 $1\sim 4\,\mathrm{mm/d}$（骨架）；快速顺向 $100\sim 400\,\mathrm{mm/d}$（酶、小泡、线粒体）；逆向可运回营养因子，也可运回病毒和毒素。
- 分类四套：突起数量（多极/双极/假单极）、轴突长短（高尔基Ⅰ/Ⅱ型）、功能（感觉/运动/中间）、化学性质（胆碱能等）。人的中间神经元占 $99\%$ 以上。
:::

:::memory{label="本节必背要点"}
- [ ] 神经组织（nervous tissue）由神经细胞和神经胶质细胞组成，是神经系统最主要的组织成分。
- [ ] 神经元（neuron）即神经细胞，人体约 $10^{10}$ 个；能接受刺激、整合信息和传导冲动，也是意识、记忆、思维和行为调节的基础。
- [ ] 神经胶质细胞数量为神经元的 $10\sim 50$ 倍，起支持、保护、营养、绝缘作用，并参与递质和活性物质代谢。
- [ ] 神经元形态不一，都分为胞体、树突和轴突 3 部分。
- [ ] 胞体是营养和代谢中心，主要位于大脑和小脑皮质、脑干和脊髓灰质以及神经节内；形状有圆形、锥形、梭形、星形；直径 $4\sim 5\,\mu\mathrm{m}$ 至 $150\,\mu\mathrm{m}$。
- [ ] 细胞核位于胞体中央，大而圆，核被膜明显，常染色质多故着色浅，核仁大而圆。
- [ ] 光镜下胞质特征性结构为尼氏体和神经原纤维。
- [ ] 尼氏体（Nissl’s body）强嗜碱、均匀分布；大神经元呈粗大斑块状，小神经元呈细颗粒状；电镜为发达粗面内质网 + 游离核糖体。
- [ ] 尼氏体合成结构蛋白、神经递质所需酶类以及肽类神经调质。
- [ ] 神经递质（neurotransmitter）是传递信息的化学载体，一般为小分子，主要在胞体合成后以小泡贮存于轴突终末。
- [ ] 神经调质（neuromodulator）一般为肽类，增强或减弱神经元对递质的反应。
- [ ] 神经原纤维（neurofibril）HE 不可见，镀银呈棕黑色细丝成网并伸入树突和轴突；电镜由神经丝和微管构成。
- [ ] 神经丝（neurofilament）是神经丝蛋白构成的中间丝；微管参与物质运输。
- [ ] 胞质还有线粒体、高尔基复合体、溶酶体及脂褐素（溶酶体残余体，随年龄增多）。
- [ ] 细胞膜是可兴奋膜；膜蛋白包括 $\mathrm{Na}^{+}$、$\mathrm{K}^{+}$、$\mathrm{Ca}^{2+}$、$\mathrm{Cl}^{-}$ 等离子通道和受体。
- [ ] 树突（dendrite）一至多个，树枝状；树突棘（dendritic spine）是分支上的短小突起，扩展接受刺激的表面积。
- [ ] 树突胞质与胞体相似，含 MAP2 构成的微管；主要功能是接受刺激。接受和整合信息的能力与分支程度及树突棘数量密切相关。
- [ ] 每个神经元只有一个轴突（axon），短者数微米，长者可达 $1\,\mathrm{m}$ 以上。
- [ ] 轴丘（axon hillock）呈圆锥形，无尼氏体，染色淡。
- [ ] 轴突较细、直径均一，侧支呈直角分出，末端形成轴突终末。
- [ ] 轴膜（axolemma）为轴突表面细胞膜；轴质（axoplasm）含神经丝、微管、滑面内质网、微丝、线粒体和小泡，彼此以横桥连成网架。
- [ ] 轴突内无粗面内质网和游离核糖体，不能合成蛋白质。
- [ ] 轴突起始段轴膜较厚，膜下有高电子密度致密层，易引起电兴奋，常是产生神经冲动的起始部位；冲动沿轴膜向终末传递。
- [ ] 顺向轴突运输：胞体 → 终末；逆向轴突运输：终末 → 胞体。微管起重要作用。
- [ ] 慢速轴突运输：$1\sim 4\,\mathrm{mm/d}$，转运新形成的神经丝、微管和微丝。
- [ ] 快速顺向轴突运输：$100\sim 400\,\mathrm{mm/d}$，转运轴膜更新蛋白、递质合成酶、含递质或调质的小泡、线粒体。
- [ ] 快速逆向轴突运输：转运终末代谢产物及摄取的蛋白质、小分子、神经营养因子；狂犬病毒、脊髓灰质炎病毒、破伤风毒素可经此侵犯胞体。
- [ ] 多极神经元：一个轴突 + 多个树突。双极神经元：树突和轴突各一个。
- [ ] 假单极神经元：胞体发出一个突起，不远处 T 形分为中枢突（轴突）和周围突（功能上为树突，结构上也称轴突）。
- [ ] 高尔基Ⅰ型：长轴突（可达 $1\,\mathrm{m}$ 以上）的大神经元；高尔基Ⅱ型：短轴突（仅数微米）的小神经元。
- [ ] 感觉（传入）神经元多为假单极；运动（传出）神经元一般为多极；中间神经元主要为多极，人占总数 $99\%$ 以上，是学习、记忆和思维的基础。
- [ ] 反射弧 = 感受器 + 感觉、中间、运动三类神经元 + 效应器。
- [ ] 化学分型：胆碱能（乙酰胆碱）、去甲肾上腺素能、胺能（多巴胺、5-羟色胺等）、氨基酸能（$\gamma$-氨基丁酸、甘氨酸、谷氨酸等）、肽能（脑啡肽、P 物质、神经降压素等）；NO 和 CO 也是递质。
- [ ] 一般一个神经元只释放一种神经递质，同时还可释放一种神经调质。
:::
