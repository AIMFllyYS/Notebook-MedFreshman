# 三、附属腺

附属腺和生殖管道的分泌物以及精子共同组成精液（semen）。正常成年男性每次射精量为 $2\sim 6\,\mathrm{ml}$，每毫升精液含 $0.2$ 亿 $\sim$ $2$ 亿个精子；若精液量少于 $1\,\mathrm{ml}$，或每毫升的精子数低于 $1\,500$ 万个，可导致不育症。附属腺包括前列腺、精囊和尿道球腺，三者分泌物的成分和排出时机不同，不要并成“都是精液工厂里的同一种腺”。

:::definition{label="附属腺"}
附属腺包括精囊、尿道球腺和前列腺。它们的分泌物与生殖管道的分泌物以及精子共同组成精液。
:::

:::definition{label="精液"}
精液（semen）由附属腺和生殖管道的分泌物以及精子共同组成。正常成年男性每次射精量 $2\sim 6\,\mathrm{ml}$，每毫升含 $0.2$ 亿 $\sim$ $2$ 亿个精子。
:::

:::concept{term="先问精液够不够、精子密不密，再问这是前列腺、精囊还是尿道球腺"}
精液不是“睾丸挤出来的纯精子”。先核对两把数量尺子：一次 $2\sim 6\,\mathrm{ml}$，每毫升 $0.2$ 亿 $\sim$ $2$ 亿个精子；少于 $1\,\mathrm{ml}$ 或低于 $1\,500$ 万 / 毫升，可致不育。再问分泌物是谁兑的：前列腺出乳白色液体（酸性磷酸酶、纤维蛋白溶酶、柠檬酸、锌），精囊出弱碱性淡黄色液体（果糖供能），尿道球腺在射精前出黏液润滑尿道。把精液听成“只有精子”，不育的数量账和果糖供能账都会从腺上掉下去。
:::

:::note{label="精液数量与不育阈值"}
| 项目 | 正常 | 可致不育症 |
|------|------|------------|
| 每次射精量 | $2\sim 6\,\mathrm{ml}$ | 少于 $1\,\mathrm{ml}$ |
| 精子密度 | 每毫升 $0.2$ 亿 $\sim$ $2$ 亿个 | 每毫升低于 $1\,500$ 万个 |
| 组成 | 附属腺 + 生殖管道分泌物 + 精子 | 数量不够或密度不够即可影响生育 |
:::

:::pitfall{label="不育阈值是少于1ml或低于每毫升1500万，不要把2～6ml和0.2亿～2亿当成最低值"}
$2\sim 6\,\mathrm{ml}$、$0.2$ 亿 $\sim$ $2$ 亿 / 毫升是正常范围。教材把“可导致不育”写在少于 $1\,\mathrm{ml}$，或每毫升低于 $1\,500$ 万。把正常下限听成不育标准，数量账会提前报警。
:::

## （一）前列腺

前列腺（prostate）呈栗形，环绕于尿道起始段。腺的被膜与支架组织均由富含弹性纤维和平滑肌纤维的结缔组织组成。腺实质主要由 $30\sim 50$ 个复管泡状腺组成，有 $15\sim 30$ 条导管开口于尿道精阜的两侧。腺实质可分 3 个带：尿道周带（又称黏膜腺）最小，位于尿道黏膜内；内带（又称黏膜下腺）位于黏膜下层；外带（又称主腺）构成前列腺的大部（图 18-13）。腺分泌部由单层立方上皮、单层柱状上皮及假复层柱状上皮交错构成，故腺腔很不规则。腔内可见分泌物浓缩形成的圆形嗜酸性板层状小体，称前列腺凝固体（prostatic concretion），随年龄的增长而增多，甚至可以钙化成为前列腺结石（图 18-14）。

从青春期开始，前列腺在雄激素的刺激下分泌活动增强，分泌物为稀薄的乳白色液体，富含酸性磷酸酶和纤维蛋白溶酶，还有柠檬酸和锌等物质。老年人的前列腺常呈增生肥大（多发生在黏膜腺和黏膜下腺），压迫尿道造成排尿困难。前列腺癌主要发生在腺的外带。

:::definition{label="前列腺"}
前列腺（prostate）呈栗形，环绕于尿道起始段。被膜与支架组织均由富含弹性纤维和平滑肌纤维的结缔组织组成。实质主要由 $30\sim 50$ 个复管泡状腺组成，有 $15\sim 30$ 条导管开口于尿道精阜两侧。
:::

:::definition{label="前列腺被膜与支架"}
被膜与支架组织都是富含弹性纤维和平滑肌纤维的结缔组织。平滑肌出现在腺泡之间，收缩有助于排出分泌物；不要把它当成间质细胞那种嗜酸性内分泌细胞。
:::

:::definition{label="尿道周带"}
尿道周带又称黏膜腺，是三带中最小的一带，位于尿道黏膜内。老年人增生肥大多发生在黏膜腺和黏膜下腺。
:::

:::definition{label="内带"}
内带又称黏膜下腺，位于黏膜下层。与黏膜腺一起，是老年性增生肥大的常见部位，可压迫尿道造成排尿困难。
:::

:::definition{label="外带"}
外带又称主腺，构成前列腺的大部。前列腺癌主要发生在腺的外带。
:::

:::definition{label="前列腺分泌部上皮"}
腺分泌部由单层立方上皮、单层柱状上皮及假复层柱状上皮交错构成，故腺腔很不规则。不是单一型上皮铺满所有腺泡。
:::

:::definition{label="前列腺凝固体"}
前列腺凝固体（prostatic concretion）是腺腔内分泌物浓缩形成的圆形嗜酸性板层状小体，随年龄增长而增多，甚至可以钙化成为前列腺结石。
:::

:::definition{label="前列腺分泌物"}
从青春期开始，前列腺在雄激素刺激下分泌活动增强。分泌物为稀薄的乳白色液体，富含酸性磷酸酶和纤维蛋白溶酶，还有柠檬酸和锌等物质。
:::

::figure{src="/images/histology/textbook/p0208_02.png" caption="图18-14 前列腺光镜图。1. 腺泡；2. 前列腺凝固体；3. 平滑肌。" alt="前列腺光镜：不规则腺泡衬高低不等的上皮，腔内圆形嗜酸性板层状凝固体，腺泡之间可见平滑肌"}

:::compare{title="前列腺三带"}
| 项目 | 尿道周带（黏膜腺） | 内带（黏膜下腺） | 外带（主腺） |
|------|--------------------|------------------|--------------|
| 位置 | 尿道黏膜内 | 黏膜下层 | 最外围，构成大部 |
| 体积 | 最小 | 介于两者之间 | 最大 |
| 导管开口 | 经导管开口于尿道精阜两侧（实质共 $15\sim 30$ 条导管） | 同左 | 同左 |
| 老年增生 | 常见 | 常见；二者增生可压迫尿道，造成排尿困难 | 不是增生的主账 |
| 前列腺癌 | 不是主要发生部位 | 不是主要发生部位 | 主要发生在外带 |
:::

:::pitfall{label="老年增生多在黏膜腺和黏膜下腺，前列腺癌主要在外带，两本账不要对调"}
压迫尿道、排尿困难，落点是尿道周带和内带的增生肥大。癌的主账在构成大部的外带。把“老年人前列腺出问题”一律写成外带增生，或把癌写到黏膜腺，部位会整段反了。
:::

:::insight{label="腺腔不规则是三种上皮交错铺的，板层小体是浓缩的分泌物"}
单层立方、单层柱状、假复层柱状在同一腺里交错，腔缘凸凹，这是前列腺切片的身份证。腔内圆形嗜酸性板层状小体是凝固体，年纪越大越多，钙化就成结石。不要把凝固体当成卵或寄生虫卵。
:::

:::note{label="雄激素与前列腺分泌"}
青春期后雄激素刺激分泌增强。纤维蛋白溶酶参与精液液化，酸性磷酸酶、柠檬酸和锌是前列腺分泌物的化学标记。这本分泌账听雄激素，和间质细胞的睾酮来源相接。
:::

## （二）精囊

精囊是一对盘曲的囊状器官。黏膜向腔内突起形成高大的皱襞，黏膜表面是假复层柱状上皮，细胞质内含有许多分泌颗粒和黄色的脂色素。黏膜外有薄的平滑肌层和结缔组织外膜。精囊分泌弱碱性的淡黄色液体，内含果糖、前列腺素等成分。果糖为精子的运动提供能量。

:::definition{label="精囊"}
精囊是一对盘曲的囊状器官。黏膜向腔内突起形成高大的皱襞；黏膜表面为假复层柱状上皮，胞质含许多分泌颗粒和黄色的脂色素。黏膜外有薄的平滑肌层和结缔组织外膜。
:::

:::definition{label="精囊分泌物"}
精囊分泌弱碱性的淡黄色液体，内含果糖、前列腺素等。果糖为精子的运动提供能量。
:::

:::pitfall{label="果糖在精囊，不要写成前列腺的酸性磷酸酶或睾丸间质细胞的产物"}
精子中段的线粒体鞘是用能量的装置，能源之一是精囊果糖。前列腺出的是乳白色液体里的酸性磷酸酶和纤维蛋白溶酶。把果糖写到前列腺或生精小管，供能账会找不到腺体。
:::

## （三）尿道球腺

尿道球腺是一对豌豆状的复管泡状腺。上皮为单层立方上皮或单层柱状上皮，腺体分泌的黏液于射精前排出，以润滑尿道。

:::definition{label="尿道球腺"}
尿道球腺是一对豌豆状的复管泡状腺。上皮为单层立方上皮或单层柱状上皮。分泌的黏液于射精前排出，以润滑尿道。
:::

:::compare{title="前列腺、精囊与尿道球腺"}
| 项目 | 前列腺 | 精囊 | 尿道球腺 |
|------|--------|------|----------|
| 形态 | 栗形，环绕尿道起始段 | 一对盘曲的囊状器官 | 一对豌豆状复管泡状腺 |
| 实质 / 黏膜 | $30\sim 50$ 个复管泡状腺，三带 | 高大皱襞，假复层柱状上皮 | 复管泡状腺，单层立方或柱状上皮 |
| 特殊结构 | 凝固体（可钙化成结石）；腺间平滑肌 | 胞质分泌颗粒和黄色脂色素 | — |
| 分泌物 | 稀薄乳白色；酸性磷酸酶、纤维蛋白溶酶、柠檬酸、锌 | 弱碱性淡黄色；果糖、前列腺素 | 黏液 |
| 排出时机 | 参与精液组成 | 参与精液组成；果糖供能 | 射精前排出，润滑尿道 |
| 激素 | 雄激素刺激分泌增强 | — | — |
:::

:::insight{label="射精前先润滑，精液里再兑酶和糖"}
尿道球腺的黏液走在最前，把尿道润好。随后前列腺的乳白色液体带上纤维蛋白溶酶等，精囊的淡黄色液体带上果糖。精子本身是睾丸造的，运动能量却有一笔记在精囊。三腺不要写成“三种样子的前列腺”。
:::

:::keypoint{label="附属腺先立精液数量，再把前列腺三带、精囊果糖和尿道球腺润滑收口"}
- 精液 = 附属腺和生殖管道分泌物 + 精子；正常 $2\sim 6\,\mathrm{ml}$，每毫升 $0.2$ 亿 $\sim$ $2$ 亿个精子。
- 少于 $1\,\mathrm{ml}$ 或低于 $1\,500$ 万 / 毫升可致不育。
- 前列腺三带：黏膜腺最小、黏膜下腺、主腺（外带，癌的主发部位）；增生多在黏膜腺和黏膜下腺。
- 腺腔不规则，腔内嗜酸性板层状凝固体可钙化成结石；分泌物含酸性磷酸酶、纤维蛋白溶酶、柠檬酸和锌。
- 精囊：高大皱襞，弱碱性淡黄色液体，果糖供能。
- 尿道球腺：射精前黏液润滑尿道。
:::
