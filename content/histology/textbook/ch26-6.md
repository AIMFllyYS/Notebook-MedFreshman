# 六、主要畸形

神经沟应在第 $4$ 周末完全闭合。前神经孔未闭走无脑畸形／露脑，后神经孔未闭走脊髓裂／脊柱裂；膨出要问囊袋里有没有神经组织。脑积水问阻塞在脑室还是蛛网膜下隙。垂体、颅咽管和肾上腺的畸形挂回第五节的原基。本节按神经管缺陷、脑积水和相关内分泌腺畸形摊开，并收本章小结。

## 1. 神经管缺陷

人胚第 $4$ 周末时，神经沟应完全闭合形成神经管。如果因失去了脊索的诱导作用或受到环境致畸因子的影响，神经沟两端的神经孔未能闭合，就会出现脑和脊髓发育的异常。如果前神经孔未闭，会形成无脑畸形（anencephaly）（图 26-11），常伴有颅顶骨发育不全，称露脑（exencephaly）；如果后神经孔未闭，会形成脊髓裂（myeloschisis）（图 26-11）；常伴有相应节段的脊柱裂（spina bifida）。

脊柱裂可发生于脊柱各段，最常见于腰骶部。脊柱裂的发生程度可有不同。其中，中度的脊柱裂比较多见，在患处常形成一个大小不等的皮肤囊袋。如果囊袋中只有脊膜和脑脊液，称脊膜膨出；如果囊袋中既有脊膜和脑脊液，又有脊髓和神经根，则称脊髓脊膜膨出（图 26-12A）。由于颅骨的发育不全，也可出现脑膜膨出和脑膜脑膨出（图 26-12B），多发生于枕部。如果脑室也随之膨出，称积水性脑膜脑膨出。

备孕期增补叶酸摄入，可以预防胎儿神经管缺陷。

:::definition{label="神经管闭合的时间"}
人胚第 $4$ 周末时，神经沟应完全闭合形成神经管。第一节写第 $4$ 周初形成神经管；两端神经孔要到第 $4$ 周末才闭严。
:::

:::definition{label="神经管缺陷的原因"}
如果因失去了脊索的诱导作用或受到环境致畸因子的影响，神经沟两端的神经孔未能闭合，就会出现脑和脊髓发育的异常。原因是诱导丢失或环境致畸，落点是两端神经孔。
:::

:::definition{label="无脑畸形与露脑"}
前神经孔未闭，会形成无脑畸形（anencephaly），常伴有颅顶骨发育不全，称露脑（exencephaly）。无脑畸形对前神经孔；露脑是常伴的颅顶骨发育不全。
:::

:::definition{label="脊髓裂与脊柱裂"}
后神经孔未闭，会形成脊髓裂（myeloschisis）；常伴有相应节段的脊柱裂（spina bifida）。脊髓裂对后神经孔；脊柱裂是相应节段常伴的椎骨闭合不全。
:::

:::definition{label="脊柱裂的好发部位"}
脊柱裂可发生于脊柱各段，最常见于腰骶部。不是只发生在颈段。
:::

:::definition{label="脊膜膨出"}
中度的脊柱裂比较多见，在患处常形成一个大小不等的皮肤囊袋。如果囊袋中只有脊膜和脑脊液，称脊膜膨出。囊里没有脊髓和神经根。
:::

:::definition{label="脊髓脊膜膨出"}
如果囊袋中既有脊膜和脑脊液，又有脊髓和神经根，则称脊髓脊膜膨出。图 26-12A 图注亦作脊膜脊髓膨出，与正文“脊髓脊膜膨出”指同一类囊袋。
:::

:::definition{label="脑膜膨出与脑膜脑膨出"}
由于颅骨的发育不全，也可出现脑膜膨出和脑膜脑膨出，多发生于枕部。脑膜膨出囊内是脑膜；脑膜脑膨出还带有脑组织。
:::

:::definition{label="积水性脑膜脑膨出"}
如果脑室也随之膨出，称积水性脑膜脑膨出。比脑膜脑膨出又多了脑室。
:::

:::definition{label="叶酸预防神经管缺陷"}
备孕期增补叶酸摄入，可以预防胎儿神经管缺陷。预防窗口在备孕期，不是分娩当时才补。
:::

:::concept{term="先问前神经孔还是后神经孔未闭，再问囊袋里有没有脊髓或脑"}
看见神经管缺陷，先对哪一端没闭：前神经孔未闭 → 无脑畸形，常伴颅顶骨发育不全即露脑；后神经孔未闭 → 脊髓裂，常伴相应节段脊柱裂，腰骶部最常见。中度脊柱裂再问皮肤囊袋里有什么：只有脊膜和脑脊液是脊膜膨出；再加上脊髓和神经根是脊髓脊膜膨出。颅骨侧同理：脑膜膨出、脑膜脑膨出（多在枕部），脑室也跟着出来才叫积水性脑膜脑膨出。把前孔听成脊髓裂，或把“有个囊袋”都写成脊髓脊膜膨出，内容物会对错户头。
:::

::figure{src="/images/histology/textbook/p0291_02.png" caption="图26-12 脊膜脊髓膨出和脑膜脑膨出。A. 脊膜脊髓膨出（腰骶部皮肤囊袋，囊内含脊膜、脑脊液、脊髓和神经根）；B. 脑膜脑膨出（枕部囊性膨出）。" alt="左：婴儿俯卧，腰骶部一个紫红色囊性膨出；右：婴儿枕部颅骨缺损处向外膨出囊性肿物"}

| 项目 | 前神经孔未闭 | 后神经孔未闭 |
|------|--------------|--------------|
| 应闭合时间 | 第 $4$ 周末 | 第 $4$ 周末 |
| 主要畸形 | 无脑畸形（anencephaly） | 脊髓裂（myeloschisis） |

| 好发补充 | — | 脊柱裂可在各段，最常见于腰骶部 |
:::

:::compare{title="脊膜膨出、脊髓脊膜膨出与颅侧膨出"}

|------|----------|--------------------------------------|----------|------------|-------------------|
| 背景 | 中度脊柱裂的皮肤囊袋 | 同左 | 颅骨发育不全 | 颅骨发育不全 | 在脑膜脑膨出基础上 |
| 囊内 | 只有脊膜和脑脊液 | 脊膜、脑脊液、脊髓和神经根 | 脑膜 | 脑膜 + 脑 | 再加脑室 |

:::

:::cause-effect{title="神经孔该闭未闭，才有无脑或脊髓裂"}
- 因：第 $4$ 周末神经沟两端神经孔应闭合；失去脊索诱导或环境致畸因子
- 果：神经孔未闭，脑和脊髓发育异常
- 因：前神经孔未闭
- 果：无脑畸形，常伴露脑
- 因：后神经孔未闭
- 果：脊髓裂，常伴相应节段脊柱裂
- 制约：备孕期补叶酸可预防神经管缺陷
:::

:::pitfall{label="有皮肤囊袋不等于囊里一定有脊髓"}
中度脊柱裂常见皮肤囊袋。只有脊膜和脑脊液是脊膜膨出；加上脊髓和神经根才是脊髓脊膜膨出。颅侧同样：脑膜膨出还没有脑，脑膜脑膨出才有脑，脑室跟着出来才叫积水性脑膜脑膨出。三级不要并成“神经管裂开就会膨出一块脑”。
:::

:::insight{label="一端孔、一份诱导，叶酸补在备孕"}
前孔对脑，后孔对脊髓，脊索诱导和叶酸都在闭合窗口之前起作用。只背畸形名字，不背第 $4$ 周末闭合和备孕补叶酸，预防这本账会丢掉。
:::

## 2. 脑积水

脑积水（hydrocephalus）比较多见，是一种颅内脑脊液异常增多的先天畸形，多由脑室系统发育障碍、脑脊液生成和吸收平衡失调所致，以中脑导水管和室间孔狭窄或闭锁最常见。由于脑脊液不能正常循环，致使阻塞处以上的脑室或蛛网膜下隙中积存大量液体，前者称脑内脑积水，后者称脑外脑积水。主要表现为脑颅明显扩大，颅骨和脑组织变薄，颅缝变宽（图 26-13）。

:::definition{label="脑积水"}
脑积水（hydrocephalus）比较多见，是一种颅内脑脊液异常增多的先天畸形。多由脑室系统发育障碍、脑脊液生成和吸收平衡失调所致。
:::

:::definition{label="脑积水最常见的阻塞部位"}
以中脑导水管和室间孔狭窄或闭锁最常见。中脑导水管是中脑泡的腔，室间孔连侧脑室与第三脑室，两处都在第二节脑室账上。
:::

:::definition{label="脑内脑积水"}
脑脊液不能正常循环，致使阻塞处以上的脑室中积存大量液体，称脑内脑积水。积在脑室里。
:::

:::definition{label="脑外脑积水"}
阻塞处以上的蛛网膜下隙中积存大量液体，称脑外脑积水。积在脑室外的蛛网膜下隙。
:::

:::definition{label="脑积水的外形"}
主要表现为脑颅明显扩大，颅骨和脑组织变薄，颅缝变宽。
:::

::figure{src="/images/histology/textbook/p0292_01.png" caption="图26-13 脑积水。A、B. 照片（脑颅明显扩大）；C. 标本（脑上部剖开，脑组织变薄）；D. 10个月女婴脑积水，CT 片显示脑室扩大、皮质变薄（a. 冠状位；b. 矢状位；c. 轴位）。" alt="上排三图：两名婴儿头颅增大和一件上部剖开的头颅标本，脑组织菲薄；下排冠状、矢状、轴位CT，脑室显著扩大、皮质变薄"}

:::compare{title="脑内脑积水与脑外脑积水"}
| 项目 | 脑内脑积水 | 脑外脑积水 |
|------|------------|------------|
| 液体积在 | 阻塞处以上的脑室 | 阻塞处以上的蛛网膜下隙 |
| 常见原因归属 | 脑室系统发育障碍（如中脑导水管、室间孔狭窄或闭锁）导致脑脊液不能正常循环 | 同属循环障碍，落点在蛛网膜下隙 |
| 共同表现 | 脑颅明显扩大，颅骨和脑组织变薄，颅缝变宽 | 同左 |
:::

:::pitfall{label="脑积水不是“脑子里多长了水”一句话，要问积在脑室还是蛛网膜下隙"}
中脑导水管或室间孔一窄，上游脑室先胀，是脑内；积到蛛网膜下隙是脑外。不先问阻塞部位，导水管和室间孔这两处最常见的狭窄会对不上第二节的脑室系统。
:::

## 3. 神经系统相关内分泌腺的畸形

前脑泡不闭合造成前脑缺损往往伴有垂体发育不良或缺如（hypophyseal dysplasia or absence），多与遗传有关，有家族史，患儿甲状腺、肾上腺和睾丸均发育不良，有时伴有面部和腭的畸形。第三脑室底部发育障碍可致漏斗瘤（infundibular tumor），极少见，往往在儿童期发病。如果颅咽管未退化并异常增殖可致颅咽管瘤（craniopharyngioma），又称“拉特克囊瘤”，常伴有垂体功能低下或伴有下丘脑病变综合征。副肾上腺（accessory suprarenal gland）指位于主肾上腺附近，多数仅有皮质而无髓质的团块结构。

:::definition{label="垂体发育不良或缺如"}
前脑泡不闭合造成前脑缺损往往伴有垂体发育不良或缺如（hypophyseal dysplasia or absence）。多与遗传有关，有家族史。患儿甲状腺、肾上腺和睾丸均发育不良，有时伴有面部和腭的畸形。
:::

:::definition{label="漏斗瘤"}
第三脑室底部发育障碍可致漏斗瘤（infundibular tumor）。极少见，往往在儿童期发病。原基对的是间脑底／漏斗，不是拉特克囊。
:::

:::definition{label="颅咽管瘤"}
如果颅咽管未退化并异常增殖可致颅咽管瘤（craniopharyngioma），又称“拉特克囊瘤”。常伴有垂体功能低下或伴有下丘脑病变综合征。原基对的是拉特克囊／颅咽管该退化未退化。
:::

:::definition{label="副肾上腺"}
副肾上腺（accessory suprarenal gland）指位于主肾上腺附近，多数仅有皮质而无髓质的团块结构。多数没有髓质，因为髓质要等神经嵴迁入。
:::

:::compare{title="垂体发育不良、漏斗瘤、颅咽管瘤与副肾上腺"}
| 畸形 | 英文 | 发生机制 | 要点 |
|------|------|----------|------|
| 垂体发育不良或缺如 | hypophyseal dysplasia or absence | 前脑泡不闭合造成前脑缺损，往往伴发 | 多与遗传、家族史有关；甲状腺、肾上腺和睾丸发育不良；可伴面部和腭畸形 |
| 漏斗瘤 | infundibular tumor | 第三脑室底部发育障碍 | 极少见；往往儿童期发病 |
| 颅咽管瘤（拉特克囊瘤） | craniopharyngioma | 颅咽管未退化并异常增殖 | 常伴垂体功能低下或下丘脑病变综合征 |
| 副肾上腺 | accessory suprarenal gland | 主肾上腺附近的团块 | 多数仅有皮质而无髓质 |
:::

:::pitfall{label="漏斗瘤对第三脑室底，颅咽管瘤对拉特克囊，不要对调"}
漏斗瘤是神经垂体芽／第三脑室底部那一本；颅咽管瘤是口凹拉特克囊该断未断、异常增殖。写成“垂体附近的瘤都是拉特克囊瘤”，漏斗瘤会消失。
:::

:::note{label="副肾上腺多数无髓质，对照第五节两份胚层"}
皮质来自脏壁中胚层表面上皮的两次增生，髓质来自第 $6$ 周迁入的神经嵴。主肾上腺附近多出来的团块如果只有皮质，说明神经嵴这份没有迁进去。不要把副肾上腺写成“完整的另一枚肾上腺”。
:::

:::keypoint{label="前孔无脑、后孔脊髓裂，囊袋问内容；脑积水问脑室内外；腺畸形对回原基"}
- 第 $4$ 周末神经孔应闭；失诱导或环境致畸 → 神经管缺陷。
- 前神经孔未闭 → 无脑畸形，常伴露脑；后神经孔未闭 → 脊髓裂，常伴脊柱裂（腰骶部多见）。
- 脊膜膨出只有脊膜和脑脊液；脊髓脊膜膨出加上脊髓和神经根；颅侧为脑膜膨出、脑膜脑膨出、积水性脑膜脑膨出。
- 备孕期补叶酸可预防神经管缺陷。
- 脑积水：脑脊液异常增多；中脑导水管、室间孔狭窄或闭锁最常见；脑内对脑室，脑外对蛛网膜下隙。
- 垂体发育不良／缺如伴前脑缺损；漏斗瘤对第三脑室底；颅咽管瘤对拉特克囊未退化；副肾上腺多数仅皮质。
:::

- [ ] 副肾上腺（accessory suprarenal gland）位于主肾上腺附近，多数仅有皮质而无髓质。
:::

## 本章小结

神经系统自胚胎第 $3$ 周，起源于神经外胚层。神经外胚层先形成神经管和神经嵴。神经管形成后，神经上皮细胞不断分裂增殖，管壁从内向外分为室管膜层、套层和边缘层。中枢神经系统中的神经细胞和神经胶质细胞逐渐发生和成熟。周围神经系统的神经元和神经胶质细胞则由神经嵴细胞迁移分化而成。

神经管的头段形成 $3$ 个膨大的脑泡，依次为前脑泡、中脑泡和菱脑泡。第 $5$ 周，形成端脑（以后演变为两个大脑半球）、间脑、中脑、后脑（演变为脑桥和小脑）和末脑（演变为延髓）$5$ 部分。端脑套层中的大部分细胞都迁至外表面，形成大脑皮质；少部分聚集成团，形成神经核。中脑、后脑和末脑中的套层细胞多聚集成细胞团，形成各种神经核。脑泡内的神经管腔演变为脑室：前脑泡腔演变为左右侧脑室和间脑中的第三脑室；中脑泡腔形成中脑导水管；菱脑泡腔变为第四脑室。

神经管的尾段分化为脊髓。套层分化为脊髓灰质，边缘层分化为白质，管腔演化为中央管。管壁形态特征是具有包含运动神经元的基板、感觉神经元的翼板，以及作为两侧之间连接板的一个顶板和一个底板。神经管周围的间充质分化为脊膜。

神经节起源于神经嵴。神经嵴细胞向两侧迁移，分化为脑、脊神经节。胸段神经嵴的部分细胞迁至主动脉的外侧，形成交感神经节。还有部分神经嵴细胞分化为肾上腺髓质的嗜铬细胞及少量交感神经节细胞。

周围神经由感觉神经纤维和运动神经纤维构成，神经纤维由神经元的突起和施万细胞组成。施万细胞由神经嵴细胞分化而成。

颅内脑脊液异常增多可引起脑积水。前神经孔未闭会形成无脑畸形；后神经孔未闭将导致脊髓裂和脊柱裂。叶酸可以预防神经管缺陷。

:::note{label="先天性脑积水"}
脑积水发生原因是多方面的，其中以先天畸形如中脑导水管狭窄及闭塞、小脑扁桃体下疝、第四脑室中孔或侧孔闭锁为主要病因的为先天性脑积水。先天性脑积水患者中约 $40\%$ 病例伴有中枢神经系统或中枢神经系统外畸形，$12\%$ 病例伴有染色体异常，其中男性病例中 L1 样细胞黏附分子基因变异占 $25\%$。先天性脑积水婴儿出生后数周或数月内头颅快速、进行性增大（正常婴儿最早 $6$ 个月头围增长为每月 $12\sim 13\mathrm{cm}$，本病增速是其 $2\sim 3$ 倍），同时头颅骨呈圆形，额顶凸出，前囟扩大隆起，颅缝错开，颅骨变形，叩诊呈“破壶声”；头发稀少；颞、额部静脉扩张；眼球下旋，上部巩膜暴露，呈落日状。患儿精神萎靡，头不能抬起，严重者可伴有大脑功能障碍，表现为癫痫、呕吐、抽搐、斜视、眼球震颤、语言障碍、肢体瘫痪、共济失调、行走困难及智力发育不全等。少部分先天性脑积水患者到成年时才表现症状。

如果产前发现胎儿脑室扩张，处理原则取决于诊断的孕周和是否存在其他畸形及其性质，可尝试宫内分流术或反复的头颅穿刺术，避免因慢性脑脊液压力增高导致的进展性胎儿脑损伤，也可以考虑终止妊娠。若未患有其他危及生命的疾病，在新生儿出生后 $4$ 天内可进行脑室腹膜分流手术。
:::
