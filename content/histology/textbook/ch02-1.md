# 一、被覆上皮

上皮组织（epithelial tissue）简称上皮（epithelium），由大量形态规则、排列密集的上皮细胞和极少量的细胞外基质组成。上皮细胞具有明显的极性，基底面借基膜与结缔组织相连；上皮内大都无血管，营养由深部血管透过基膜渗入。

:::definition{label="上皮组织"}
上皮组织（epithelial tissue）简称上皮（epithelium），由大量形态规则、排列密集的上皮细胞和极少量的细胞外基质组成。
:::

:::concept{term="极性"}
上皮细胞具有明显的极性（polarity），即细胞的不同面在结构和功能上具有明显差别。朝向身体表面或有腔器官腔面的一面为游离面；与游离面相对、朝向深部结缔组织的一面称基底面；上皮细胞之间的连接面为侧面。极性在单层上皮细胞中表现得最典型。
:::

上皮基底面附着于基膜上，并借此与结缔组织相连。上皮内大都无血管，所需营养依靠结缔组织内的血管提供，血液中的营养物质透过基膜渗入上皮细胞间隙。上皮组织内具有丰富的感觉神经末梢。

根据其功能，上皮组织分为被覆上皮和腺上皮两大类。此外，体内还有少量特化的上皮，如能感受特定理化刺激的感觉上皮（sensory epithelium），具有收缩能力的肌上皮（myoepithelium）等。

:::definition{label="被覆上皮"}
被覆上皮（covering epithelium）覆盖于身体表面或衬贴在体腔和有腔器官内表面，具有保护、吸收、分泌和排泄等功能。
:::

:::definition{label="腺上皮"}
腺上皮（glandular epithelium）是以分泌功能为主的上皮。
:::

## 被覆上皮的分类及分布

被覆上皮根据其构成细胞的层数和表层细胞的形状进行分类（表 2-1）。

:::note{label="表2-1 被覆上皮的分类及分布"}
| 大类 | 上皮类型 | 主要分布 |
| --- | --- | --- |
| 单层上皮 | 单层扁平上皮 | 内皮：心脏、血管和淋巴管的腔面；间皮：胸膜、心包膜和腹膜的表面；其他：肺泡和肾小囊壁层 |
| 单层上皮 | 单层立方上皮 | 肾小管、甲状腺滤泡等 |
| 单层上皮 | 单层柱状上皮 | 胃、肠、胆囊和子宫等腔面 |
| 单层上皮 | 假复层纤毛柱状上皮 | 呼吸道等腔面 |
| 复层上皮 | 复层扁平上皮 | 未角化：口腔大部、食管和阴道等腔面；角化：皮肤表皮 |
| 复层上皮 | 复层柱状上皮 | 睑结膜、男性尿道腔面等 |
| 复层上皮 | 变移上皮 | 肾盏、肾盂、输尿管和膀胱等腔面 |
:::

### 1. 单层扁平上皮

:::definition{label="单层扁平上皮"}
单层扁平上皮（simple squamous epithelium）又称单层鳞状上皮，由一层扁平细胞组成。从上皮表面观察，细胞呈不规则形或多边形，核为椭圆形，位于细胞中央；细胞边缘呈锯齿状或波浪状，互相嵌合。从垂直切面观察，细胞扁薄，细胞质少，只有含核的部分略厚。
:::

:::concept{term="内皮"}
衬贴在心脏、血管和淋巴管腔面的单层扁平上皮称内皮（endothelium）。其表面光滑，有利于血液和淋巴的流动，也有利于内皮细胞进行物质交换。
:::

:::concept{term="间皮"}
分布在胸膜、腹膜和心包膜表面的单层扁平上皮称间皮（mesothelium）。其表面湿润光滑，可减少器官活动的摩擦。
:::

### 2. 单层立方上皮

:::definition{label="单层立方上皮"}
单层立方上皮（simple cuboidal epithelium）由一层近似立方形的细胞组成。从上皮表面观察，细胞呈六角形或多角形；在垂直切面上，细胞呈立方形，核圆、居中。
:::

::figure{src="/images/histology/textbook/p0033_02.png" caption="图2-2 单层立方上皮。A. 单层立方上皮模式图；B. 集合管单层立方上皮光镜图。" alt="单层立方上皮模式图与集合管单层立方上皮光镜图"}

### 3. 单层柱状上皮

:::definition{label="单层柱状上皮"}
单层柱状上皮（simple columnar epithelium）由一层棱柱状细胞组成。从表面观察，细胞呈六角形或多角形；在垂直切面上，细胞为柱状，核为椭圆形，其长轴与细胞长轴一致。此种上皮分布在胃、肠、胆囊和子宫等器官，有吸收或分泌功能。
:::

::figure{src="/images/histology/textbook/p0034_01.png" caption="图2-3 单层柱状上皮。A. 单层柱状上皮模式图；B. 胆囊单层柱状上皮光镜图。↑柱状上皮细胞核。" alt="单层柱状上皮模式图与胆囊单层柱状上皮光镜图"}

在肠道的单层柱状上皮中，除柱状细胞外，还散在杯状细胞。

:::concept{term="杯状细胞"}
杯状细胞（goblet cell）形似高脚酒杯，底部狭窄，含深染的核，顶部膨大，充满分泌颗粒。由于颗粒中含 PAS 反应阳性的黏蛋白，故称黏原颗粒（mucinogen granule）。黏蛋白分泌后，与水结合形成黏液，有润滑和保护上皮的作用。
:::

::figure{src="/images/histology/textbook/p0034_03.png" caption="图2-4 小肠单层柱状上皮光镜图。↑柱状细胞核；纹状缘；* 杯状细胞。" alt="小肠单层柱状上皮光镜图，示柱状细胞核、纹状缘和杯状细胞"}

### 4. 假复层纤毛柱状上皮

:::definition{label="假复层纤毛柱状上皮"}
假复层纤毛柱状上皮（pseudostratified ciliated columnar epithelium）主要分布在呼吸道管腔面，由柱状细胞、梭形细胞、锥形细胞和杯状细胞组成，其中柱状细胞最多，表面有大量纤毛。这些细胞形态不同、高矮不一，核的位置不在同一水平上，但基底部均附着于基膜，因此在垂直切面上观察貌似复层，而实为单层。
:::

::figure{src="/images/histology/textbook/p0034_04.png" caption="图2-5 假复层纤毛柱状上皮。A. 假复层纤毛柱状上皮模式图；B. 气管假复层纤毛柱状上皮光镜图。↑纤毛；基膜；* 杯状细胞。" alt="假复层纤毛柱状上皮模式图与气管假复层纤毛柱状上皮光镜图"}

:::compare{title="单层上皮与复层上皮"}
- 项目 | 单层上皮 | 复层上皮
- 细胞层数 | 一层；所有细胞的基底部均附着于基膜 | 多层；仅基底层细胞附着于基膜
- 核的位置 | 大致同一水平；假复层者核高低不等但仍属单层 | 随层次而异，表层、中间层、基底层形态不同
- 主要类型 | 单层扁平、单层立方、单层柱状、假复层纤毛柱状 | 复层扁平、复层柱状、变移上皮
- 分类依据 | 细胞层数 + 细胞形状 | 细胞层数 + 表层细胞形状
- 典型功能 | 物质交换、吸收、分泌 | 耐摩擦、保护、随器官状态变形
- 易混点 | 假复层垂直切面貌似复层，实为单层 | 变移上皮层数可随器官空虚或扩张而改变
:::

### 5. 复层扁平上皮

:::definition{label="复层扁平上皮"}
复层扁平上皮（stratified squamous epithelium）由多层细胞组成，因表层细胞是扁平鳞片状，又称复层鳞状上皮。在上皮的垂直切面上，细胞形状不一：紧靠基膜的一层基底细胞为矮柱状，为具有增殖分化能力的干细胞，其产生的部分子细胞向浅层移动；基底层以上是数层多边形细胞，再上为几层梭形或扁平细胞；最表层的扁平细胞已退化，逐渐脱落。
:::

上皮与深部结缔组织的连接凹凸不平，可增加两者的连接面积，既利于上皮获得营养供应，又使连接更加牢固。

位于皮肤表皮的复层扁平上皮，浅层细胞的核消失，细胞质充满角蛋白，细胞干硬并不断脱落，称角化复层扁平上皮；衬贴在口腔和食管等腔面的复层扁平上皮，浅层细胞有核，含角蛋白少，称未角化复层扁平上皮。复层扁平上皮具有耐摩擦和阻止异物侵入等作用，受损伤后有很强的再生修复能力。

### 6. 复层柱状上皮

:::definition{label="复层柱状上皮"}
复层柱状上皮（stratified columnar epithelium）由数层细胞组成，其深部为一层或几层多边形细胞，浅部为一层排列较整齐的矮柱状细胞。这种上皮主要分布于结膜、男性尿道和一些腺的大导管处。
:::

### 7. 变移上皮

:::definition{label="变移上皮"}
变移上皮（transitional epithelium）分布于排尿管道，其细胞可分为表层细胞、中间层细胞和基底细胞。变移上皮的特点是细胞形状和层数可随器官的空虚与扩张状态而变化。
:::

:::concept{term="盖细胞"}
一个表层细胞可覆盖几个中间层细胞，故称为盖细胞（umbrella cell）。膀胱空虚时，上皮变厚，细胞层数增多，盖细胞呈大的立方形；膀胱充盈扩张时，上皮变薄，细胞层数减少，盖细胞呈扁平状。
:::

::figure{src="/images/histology/textbook/p0035_02.png" caption="图2-7 变移上皮。A. 变移上皮（空虚状态）模式图；B. 膀胱变移上皮（空虚状态）光镜图；C. 膀胱变移上皮（充盈状态）光镜图。* 盖细胞。" alt="变移上皮空虚状态模式图及膀胱空虚与充盈状态光镜图"}

:::keypoint{label="核心结论"}
被覆上皮按细胞层数和表层细胞形状分类。单层上皮均附着于基膜，适于交换、吸收和分泌；假复层纤毛柱状上皮貌似复层而实为单层。复层扁平上皮耐摩擦，有角化和未角化两型；变移上皮的形状和层数随器官空虚或扩张而改变。内皮衬于心、血管和淋巴管腔面，间皮覆于胸膜、腹膜和心包膜表面。
:::

:::memory{label="本节必背要点"}
- [ ] 上皮组织由大量形态规则、排列密集的上皮细胞和极少量细胞外基质组成；细胞有极性（游离面、基底面、侧面）。
- [ ] 上皮大都无血管，营养由结缔组织血管透过基膜渗入；上皮内有丰富的感觉神经末梢。
- [ ] 按功能分为被覆上皮和腺上皮；另有感觉上皮、肌上皮等特化上皮。
- [ ] 被覆上皮按细胞层数和表层细胞形状分类。
- [ ] 单层扁平上皮又称单层鳞状上皮；心、血管和淋巴管腔面者为内皮，胸膜、腹膜和心包膜表面者为间皮；亦分布于肺泡和肾小囊壁层。
- [ ] 单层立方上皮：表面六角/多角形，垂直切面立方形，核圆居中；见于肾小管、甲状腺滤泡等。
- [ ] 单层柱状上皮分布于胃、肠、胆囊和子宫等腔面；肠道中散在杯状细胞，顶部为 PAS 阳性黏原颗粒。
- [ ] 假复层纤毛柱状上皮主要在呼吸道：柱状、梭形、锥形和杯状细胞高矮不一，核不在同一水平，但均附着于基膜，实为单层。
- [ ] 复层扁平上皮又称复层鳞状上皮；基底细胞为干细胞。皮肤表皮为角化型（浅层无核、充满角蛋白），口腔大部、食管和阴道等为未角化型（浅层有核）。
- [ ] 复层柱状上皮浅部为矮柱状细胞，分布于睑结膜、男性尿道和一些腺的大导管。
- [ ] 变移上皮分布于肾盏、肾盂、输尿管和膀胱；表层为盖细胞，层数和形状随空虚/充盈而变。
:::
