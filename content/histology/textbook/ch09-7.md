# 七、心脏

心脏是中空性器官，心脏壁很厚，主要由心肌构成，心肌的节律性舒缩赋予血液流动的动力。心脏壁内还含有由特殊心肌纤维组成的传导系统，其功能是产生并传导动作电位（action potential，AP），使心肌按一定的节律舒缩。

:::definition{label="心脏"}
心脏是中空性器官，心壁很厚，主要由心肌构成。心肌的节律性舒缩赋予血液流动的动力。心壁内还有由特殊心肌纤维组成的传导系统，产生并传导动作电位，使心肌按一定节律舒缩。
:::

:::concept{term="先问三层心壁，再问传导系统落在哪一层"}
心壁从心腔向外是心内膜、心肌膜、心外膜，对得上血管的内膜、中膜、外膜，但不能用内弹性膜那一套来认。浦肯野纤维写在心室心内膜下层和心肌膜里；窦房结写在心外膜深部。先问普通心肌在哪一层，再问起搏细胞、移行细胞、浦肯野纤维各堆在哪。把传导系统听成“心壁第四层”，或把浦肯野纤维当成心外膜脂肪里的神经，层次会整层错位。
:::

## （一）心脏壁的结构

心脏壁从心腔向外分为心内膜、心肌膜和心外膜 3 层（图 9-16，图 9-17）。

:::definition{label="心壁三层"}
心脏壁从心腔向外分为心内膜（endocardium）、心肌膜（myocardium）和心外膜（epicardium）3 层。
:::

### 1. 心内膜

心内膜（endocardium）由内皮和内皮下层构成。内皮与接入心脏的血管内皮相延续。内皮下层可分内、外两层：内层为薄层结缔组织，含较多弹性纤维和少量平滑肌纤维；外层靠近心肌膜，称心内膜下层（subendocardial layer），为疏松结缔组织，含较小的血管和神经纤维，心室的心内膜下层含心脏传导系统的分支即浦肯野纤维。

:::definition{label="心内膜"}
心内膜（endocardium）由内皮和内皮下层构成。内皮与接入心脏的血管内皮相延续。
:::

:::definition{label="内皮下层（心内膜）"}
心内膜的内皮下层可分内、外两层。内层为薄层结缔组织，含较多弹性纤维和少量平滑肌纤维。
:::

:::definition{label="心内膜下层"}
心内膜下层（subendocardial layer）是内皮下层的外层，靠近心肌膜，为疏松结缔组织，含较小的血管和神经纤维。心室的心内膜下层含心脏传导系统的分支即浦肯野纤维。
:::

:::pitfall{label="心内膜下层是内皮下层的外层，不是心内膜外面又多出来的一层"}
心内膜 = 内皮 + 内皮下层。内皮下层再分为内层（薄层结缔组织）和外层（心内膜下层）。浦肯野纤维写在心室的心内膜下层，所以切片上它紧贴内皮侧、位于普通心肌纤维浅面，细胞更大、着色更浅。不要把心内膜下层理解成心外膜，也不要把“内皮下层”和“心内膜下层”当成两个不相干的名词。
:::

### 2. 心肌膜

心肌膜（myocardium）主要由心肌纤维构成。心肌纤维集合成束，呈螺旋状排列，可分为内纵行、中环行和外斜行 3 层。心肌纤维之间、肌束之间有少量结缔组织和丰富的毛细血管；心室的心肌纤维之间也有浦肯野纤维。心肌膜在心房较薄，左心室最厚。在心房肌和心室肌之间，致密结缔组织构成坚实的支架结构，称心骨骼（cardiac skeleton）。心房肌和心室肌分别附着于心骨骼，并不延续。

心房肌纤维比心室肌纤维短而细。透射电镜下，部分心房肌纤维含电子致密的分泌颗粒，称心房特殊颗粒（specific atrial granule），内含心房钠尿肽（atrial natriuretic peptide，ANP），具有利尿、排钠、舒血管和降血压作用。心肌纤维还能合成和分泌多种其他生物活性物质，如脑钠素、抗心律失常肽、内源性洋地黄素、肾素-血管紧张素等。

:::definition{label="心肌膜"}
心肌膜（myocardium）主要由心肌纤维构成。肌纤维集合成束，螺旋状排列，分内纵行、中环行和外斜行 3 层。纤维之间、肌束之间有少量结缔组织和丰富的毛细血管。心房的心肌膜较薄，左心室最厚。
:::

:::definition{label="心骨骼"}
心骨骼（cardiac skeleton）是心房肌和心室肌之间由致密结缔组织构成的坚实支架。心房肌和心室肌分别附着于心骨骼，并不延续。心瓣膜的基部与心骨骼的纤维环相连。
:::

:::definition{label="心房特殊颗粒"}
心房特殊颗粒（specific atrial granule）是部分心房肌纤维内电子致密的分泌颗粒，内含心房钠尿肽（atrial natriuretic peptide，ANP），具有利尿、排钠、舒血管和降血压作用。
:::

:::definition{label="心房钠尿肽"}
心房钠尿肽（atrial natriuretic peptide，ANP）由心房特殊颗粒贮存，具有利尿、排钠、舒血管和降血压作用。心肌纤维还能合成脑钠素、抗心律失常肽、内源性洋地黄素、肾素-血管紧张素等。
:::

:::note{label="心房肌比心室肌短而细，还能分泌"}
心房肌纤维比心室肌纤维短而细，心肌膜也更薄；左心室心肌膜最厚，对应射血阻力。部分心房肌含心房特殊颗粒，把心肌写成内分泌细胞。不要把 ANP 记成心内膜内皮的产物，也不要把心室肌写成完全没有生物活性物质——教材写心肌纤维还能合成脑钠素等，只是特殊颗粒这一形态落在心房。
:::

:::insight{label="心骨骼把心房肌和心室肌隔开，兴奋不能由普通心肌直接传过"}
心房肌和心室肌分别附着于心骨骼，并不延续。普通心肌纤维到这里就断了，兴奋必须改走房室结、房室束和浦肯野纤维才能下到心室。这是传导系统存在的形态学理由：不是心肌“喜欢走特殊路线”，而是致密结缔组织支架把普通心肌的电偶联切断了。
:::

### 3. 心外膜

心外膜（epicardium）即心包脏层，为浆膜（serosa）。其外表面为间皮，间皮深部为疏松结缔组织。结缔组织内含较小的血管、神经纤维和神经节，并常含脂肪组织。心包的脏、壁两层之间为心包腔，内有少量浆液，可减少摩擦，有利于心脏搏动。

:::definition{label="心外膜"}
心外膜（epicardium）即心包脏层，为浆膜（serosa）。外表面为间皮，间皮深部为疏松结缔组织，内含较小的血管、神经纤维和神经节，常含脂肪组织。
:::

:::definition{label="心包腔"}
心包的脏、壁两层之间为心包腔，内有少量浆液，可减少摩擦，有利于心脏搏动。脏层即心外膜。
:::

:::pitfall{label="心外膜表面是间皮，心内膜表面是内皮，不要对调"}
心内膜衬心腔，与血管内皮延续，是内皮。心外膜是浆膜，游离面是间皮。脂肪、神经节写在心外膜结缔组织里；浦肯野纤维写在心内膜下层。把心外膜当成“外面那层内皮”，或把间皮听成内皮的别名，浆膜账和血管内皮账会并成一句。
:::

### 4. 心瓣膜

心瓣膜（cardiac valve）位于房室孔和动脉口处，包括二尖瓣、三尖瓣、主动脉瓣和肺动脉瓣，是心内膜向腔内凸起形成的薄片状结构，其基部与心骨骼的纤维环相连。心瓣膜表面为内皮，内部为致密结缔组织，基部含平滑肌纤维和弹性纤维。心瓣膜的功能是保证血液沿心房、心室、动脉的方向流动，防止逆流。

:::definition{label="心瓣膜"}
心瓣膜（cardiac valve）位于房室孔和动脉口处，包括二尖瓣、三尖瓣、主动脉瓣和肺动脉瓣。由心内膜向腔内凸起形成；基部与心骨骼的纤维环相连。表面为内皮，内部为致密结缔组织，基部含平滑肌纤维和弹性纤维。保证血液沿心房 → 心室 → 动脉流动，防止逆流。
:::

:::compare{title="心瓣膜与静脉瓣"}
| 项目 | 心瓣膜 | 静脉瓣 |
|------|--------|--------|
| 位置 | 房室孔和动脉口（二尖瓣、三尖瓣、主动脉瓣、肺动脉瓣） | 管径 $2\,\mathrm{mm}$ 以上的静脉 |
| 来源 | 心内膜向腔内凸起 | 静脉内膜向管腔折叠 |
| 表面 | 内皮 | 内皮 |
| 内部 | 致密结缔组织；基部含平滑肌和弹性纤维 | 含较多弹性纤维的结缔组织 |
| 附着 | 基部连心骨骼纤维环 | 附着于静脉内膜 |
| 功能 | 保证心房 → 心室 → 动脉单向流动 | 防止静脉血逆流 |
:::

## （二）心脏传导系统

心脏传导系统包括窦房结、房室结、房室束及其各级分支（见图 9-16、图 9-17，图 9-18）。窦房结位于上腔静脉与右心耳交界处的心外膜深部，是心脏的主要起搏点。房室结、房室束及其主要分支位于心内膜下层，在心室的房室束分支还进一步伸入心肌膜，它们的主要功能是传导动作电位，也是心脏的潜在起搏点。心脏传导系统受自主神经和肽能神经支配。组成心脏传导系统的细胞主要有 3 种，即起搏细胞、移行细胞和浦肯野纤维，这些细胞聚集成结或束。

:::definition{label="心脏传导系统"}
心脏传导系统包括窦房结、房室结、房室束及其各级分支，由特殊心肌纤维组成，产生并传导动作电位。受自主神经和肽能神经支配。组成细胞主要有起搏细胞、移行细胞和浦肯野纤维。
:::

:::definition{label="窦房结"}
窦房结位于上腔静脉与右心耳交界处的心外膜深部，是心脏的主要起搏点。中央部位以起搏细胞为主。
:::

:::definition{label="房室结"}
房室结位于心内膜下层，与房室束及其主要分支一起传导动作电位，也是心脏的潜在起搏点。中央部位有起搏细胞，周边为移行细胞。
:::

:::definition{label="房室束"}
房室束及其主要分支位于心内膜下层，在心室还进一步伸入心肌膜。组成细胞主要是浦肯野纤维，也有移行细胞。功能是传导动作电位，并为潜在起搏点。
:::

### 1. 起搏细胞

起搏细胞（pacemaker cell）位于窦房结和房室结的中央部位，是心肌兴奋的主要起搏细胞。与普通心肌纤维相比，起搏细胞体积小，呈梭形或多边形，有分支连接成网，HE 染色呈浅色，细胞质内细胞器和肌原纤维少，糖原多。

:::definition{label="起搏细胞"}
起搏细胞（pacemaker cell）位于窦房结和房室结的中央部位，是心肌兴奋的主要起搏细胞。体积小，梭形或多边形，分支连网；HE 呈浅色；胞质内细胞器和肌原纤维少，糖原多。
:::

### 2. 移行细胞

移行细胞（transitional cell）主要位于窦房结和房室结周边部位及房室束内，具有传导动作电位的作用。移行细胞的结构介于起搏细胞和普通心肌纤维之间，比普通心肌纤维短而细，细胞质内的肌原纤维较起搏细胞略多，肌质网也较发达。

:::definition{label="移行细胞"}
移行细胞（transitional cell）主要位于窦房结和房室结周边及房室束内，传导动作电位。结构介于起搏细胞和普通心肌纤维之间：比普通心肌纤维短而细，肌原纤维较起搏细胞略多，肌质网较发达。
:::

### 3. 浦肯野纤维

浦肯野纤维（Purkinje fiber）是房室束及其各级分支的主要细胞。在心室，它们位于心内膜下层和心肌膜。与普通心肌纤维相比，浦肯野纤维短而粗，形状常不规则，有 $1\sim 2$ 个细胞核，细胞质含丰富的线粒体和糖原，但肌原纤维较少，故 HE 染色呈浅色。细胞之间有发达的闰盘。房室束分支末端的浦肯野纤维与普通心室肌纤维相连，通过缝隙连接构成功能合胞体，使所有心室肌纤维同步舒缩。

:::definition{label="浦肯野纤维"}
浦肯野纤维（Purkinje fiber）是房室束及其各级分支的主要细胞，在心室位于心内膜下层和心肌膜。短而粗，形状常不规则，有 $1\sim 2$ 个核；线粒体和糖原丰富，肌原纤维较少，故 HE 呈浅色；细胞之间有发达的闰盘。末端与普通心室肌相连，经缝隙连接构成功能合胞体，使心室肌同步舒缩。
:::

:::compare{title="起搏细胞、移行细胞与浦肯野纤维"}
| 项目 | 起搏细胞 | 移行细胞 | 浦肯野纤维 |
|------|----------|----------|------------|
| 英文 | pacemaker cell | transitional cell | Purkinje fiber |
| 位置 | 窦房结、房室结中央 | 两结周边及房室束内 | 房室束及其分支；心室的心内膜下层和心肌膜 |
| 形态 | 体积小，梭形或多边形，分支成网 | 介于起搏细胞与普通心肌之间，比普通心肌短而细 | 短而粗，形状常不规则 |
| 核 | 相对不突出 | 相对不突出 | $1\sim 2$ 个 |
| 肌原纤维 | 少 | 较起搏细胞略多 | 较少（故 HE 浅染） |
| 其他胞质 | 细胞器少，糖原多 | 肌质网较发达 | 线粒体和糖原丰富 |
| 连接 | 分支连网 | 介于两者之间 | 发达闰盘；末端与心室肌缝隙连接成功能合胞体 |
| 职分 | 主要起搏 | 传导动作电位 | 快速传导并使心室肌同步舒缩 |
:::

:::pitfall{label="心脏浦肯野纤维不是小脑浦肯野细胞"}
两者英文都与 Purkinje 有关，不是一种细胞。心脏浦肯野纤维是特殊心肌纤维：短而粗、浅染、肌原纤维少、有闰盘，位于心室心内膜下层和心肌膜，把动作电位交给心室肌。小脑浦肯野细胞是第 7 章的多极神经元，胞体梨形，树突在分子层扇形展开。切片上一个浅染的大细胞贴在心内膜下，是心肌不是神经元；小脑皮质那一层排成一行的梨形细胞，是神经元不是心肌。
:::

:::compare{title="窦房结与房室结、房室束"}
| 项目 | 窦房结 | 房室结及房室束 |
|------|--------|----------------|
| 位置 | 上腔静脉与右心耳交界处的心外膜深部 | 心内膜下层；心室的房室束分支伸入心肌膜 |
| 起搏地位 | 心脏的主要起搏点 | 传导动作电位；也是潜在起搏点 |
| 主要细胞 | 中央起搏细胞，周边移行细胞 | 结内有起搏细胞和移行细胞；束内以浦肯野纤维为主 |
:::

:::cause-effect{title="浦肯野纤维怎样让全部心室肌同步舒缩"}
- 因：房室束分支末端的浦肯野纤维与普通心室肌纤维相连，细胞之间有发达闰盘和缝隙连接
- 果：构成功能合胞体，动作电位几乎同时传到全部心室肌
- 影响：心室肌同步舒缩；心骨骼隔开的心房、心室因此能按结-束-纤维的顺序接力，而不是靠普通心肌直接传过
:::

:::keypoint{label="心壁三层对内皮-心肌-间皮，传导系统三细胞对起搏-移行-浦肯野"}
- 心内膜：内皮 + 内皮下层（内层结缔组织 / 外层心内膜下层）；心室心内膜下层含浦肯野纤维。
- 心肌膜：内纵、中环、外斜；心房薄、左室最厚；心骨骼隔开房肌与室肌。
- 心房特殊颗粒含 ANP（利尿、排钠、舒血管、降血压）。
- 心外膜 = 心包脏层浆膜，表面间皮，常含脂肪。
- 心瓣膜由心内膜凸起，基部连纤维环。
- 窦房结在心外膜深部，主要起搏点；房室结和房室束在心内膜下层，潜在起搏点。
- 起搏细胞小而浅染；移行细胞介于两者之间；浦肯野纤维短粗浅染，不是小脑浦肯野细胞。
:::

:::memory{label="本节必背要点"}
- [ ] 心脏是中空性器官，壁很厚，主要由心肌构成；心肌节律性舒缩赋予血液流动的动力。
- [ ] 传导系统由特殊心肌纤维组成，产生并传导动作电位（AP），使心肌按一定节律舒缩。
- [ ] 心壁从心腔向外分为心内膜、心肌膜和心外膜 3 层。
- [ ] 心内膜（endocardium）由内皮和内皮下层构成；内皮与接入心脏的血管内皮相延续。
- [ ] 内皮下层内层为薄层结缔组织，含较多弹性纤维和少量平滑肌；外层称心内膜下层（subendocardial layer）。
- [ ] 心内膜下层为疏松结缔组织，含较小血管和神经；心室的心内膜下层含浦肯野纤维。
- [ ] 心肌膜（myocardium）主要由心肌纤维构成，集合成束，螺旋排列，分内纵行、中环行和外斜行 3 层。
- [ ] 心肌纤维之间、肌束之间有少量结缔组织和丰富毛细血管；心室心肌纤维之间也有浦肯野纤维。
- [ ] 心肌膜心房较薄，左心室最厚。
- [ ] 心骨骼（cardiac skeleton）是房肌与室肌之间的致密结缔组织支架；房肌和室肌分别附着，并不延续。
- [ ] 心房肌纤维比心室肌纤维短而细。
- [ ] 部分心房肌含心房特殊颗粒（specific atrial granule），内含心房钠尿肽（ANP），利尿、排钠、舒血管、降血压。
- [ ] 心肌纤维还能合成脑钠素、抗心律失常肽、内源性洋地黄素、肾素-血管紧张素等。
- [ ] 心外膜（epicardium）即心包脏层，为浆膜；外表面为间皮，深部疏松结缔组织含血管、神经纤维、神经节，常含脂肪。
- [ ] 心包脏、壁两层之间为心包腔，内有少量浆液，减少摩擦。
- [ ] 心瓣膜位于房室孔和动脉口，包括二尖瓣、三尖瓣、主动脉瓣和肺动脉瓣，由心内膜向腔内凸起，基部连心骨骼纤维环。
- [ ] 心瓣膜表面为内皮，内部为致密结缔组织，基部含平滑肌和弹性纤维；保证心房 → 心室 → 动脉单向流动。
- [ ] 传导系统包括窦房结、房室结、房室束及其各级分支。
- [ ] 窦房结位于上腔静脉与右心耳交界处的心外膜深部，是主要起搏点。
- [ ] 房室结、房室束及其主要分支位于心内膜下层，心室的房室束分支伸入心肌膜；传导动作电位，也是潜在起搏点。
- [ ] 传导系统受自主神经和肽能神经支配；组成细胞为起搏细胞、移行细胞和浦肯野纤维。
- [ ] 起搏细胞位于窦房结和房室结中央，体积小，梭形或多边形，分支成网，HE 浅染，细胞器和肌原纤维少，糖原多。
- [ ] 移行细胞位于两结周边及房室束，结构介于起搏细胞和普通心肌之间，比普通心肌短而细，肌原纤维略多，肌质网较发达。
- [ ] 浦肯野纤维是房室束及其分支的主要细胞，心室位于心内膜下层和心肌膜；短而粗，不规则，$1\sim 2$ 个核，线粒体和糖原丰富，肌原纤维少，HE 浅染，闰盘发达。
- [ ] 浦肯野纤维末端与普通心室肌相连，经缝隙连接构成功能合胞体，使心室肌同步舒缩。
:::

## 本章小结

动脉和静脉管壁由内膜、中膜和外膜构成。内膜又包括内皮、内皮下层和内弹性膜。中膜由弹性膜、平滑肌纤维和结缔组织构成，其厚度及组成成分在不同血管中的差异较大。外膜为疏松结缔组织。

动脉包括大、中、小、微动脉 4 类。大动脉内皮细胞含丰富的 W-P 小体，中膜含 $40\sim 70$ 层弹性膜。中动脉内弹性膜明显，中膜含 $10\sim 40$ 层环行平滑肌纤维。小动脉管径小于 $1\,\mathrm{mm}$，中膜含 $3\sim 9$ 层平滑肌纤维。微动脉管径小于 $0.3\,\mathrm{mm}$，中膜含 $1\sim 2$ 层平滑肌纤维。毛细血管由内皮细胞、基膜和周细胞构成，分为连续毛细血管、有孔毛细血管和血窦 3 类。静脉分为微、小、中、大静脉 4 类。与伴行的动脉相比，静脉管壁 3 层膜的界限不明显，壁薄，平滑肌纤维少；较大静脉的外膜常有纵行平滑肌束，管腔内有静脉瓣。

心脏壁由心内膜、心肌膜和心外膜构成。心内膜包括内皮和内皮下层，内皮下层的外层称心内膜下层。心肌膜主要由心肌纤维构成。心外膜为浆膜。心脏传导系统的起搏细胞位于窦房结和房室结的中心部位，是心肌兴奋的主要起搏细胞；移行细胞位于窦房结和房室结周边及房室束，具有传导动作电位的作用；浦肯野纤维是组成房室束及其分支的主要细胞，在心室位于心内膜下层和心肌膜，与心室肌纤维形成功能合胞体，使所有心室肌纤维同步舒缩。

:::definition{label="本章结构通式"}
循环系统 = 心血管系统（心脏泵血，动脉分弹性/肌性/阻力，毛细血管三类交换，静脉导流）+ 淋巴管系统（盲端毛细淋巴管汇入导管入血）。动脉静脉共有内膜、中膜、外膜；毛细血管换成内皮、基膜、周细胞；心壁换成心内膜、心肌膜、心外膜。中膜层数给动脉分型，内皮窗孔给毛细血管分型，外膜纵行平滑肌给大静脉分型，特殊心肌给传导系统分型。
:::

:::compare{title="全章管道与心壁层次对照"}
| 层次 | 动脉 / 静脉 | 毛细血管 | 心壁 |
|------|-------------|----------|------|
| 最内 | 内膜：内皮、内皮下层、内弹性膜 | 内皮 | 心内膜：内皮、内皮下层（含心内膜下层） |
| 中层 | 中膜：弹性膜和/或平滑肌 | 无中膜；周细胞夹在内皮与基板之间 | 心肌膜：螺旋心肌束 |
| 最外 | 外膜：疏松结缔组织，可有外弹性膜、营养血管 | 无外膜 | 心外膜：浆膜，表面间皮 |
| 分型关键 | 中膜层数；静脉则外膜常更厚 | 内皮连续 / 有孔 / 血窦 | 传导系统三细胞的位置 |
:::

:::keypoint{label="全章把三层管壁、四型动脉、三类毛细血管和传导系统收口"}
- 管壁通式：内膜（内皮、内皮下层、内弹性膜）、中膜、外膜；营养血管供中膜和外膜。
- 大动脉 $40\sim 70$ 层弹性膜（辅助泵）；中动脉 $10\sim 40$ 层环行平滑肌（分配动脉）；小动脉 $3\sim 9$ 层、微动脉 $1\sim 2$ 层（外周阻力血管）。
- 毛细血管：内皮 + 基板 + 周细胞；连续 / 有孔（窗孔 $60\sim 80\,\mathrm{nm}$）/ 血窦（腔可达 $40\,\mu\mathrm{m}$）。
- 静脉壁薄、中膜薄外膜厚；大静脉外膜纵行平滑肌束；瓣膜防逆流。
- 微循环三条通路：迂回（交换）、直捷（大部分血回心）、动-静脉短路（皮肤血流量）。
- 心壁三层 + 窦房结（心外膜深部）/ 房室结与浦肯野纤维（心内膜下层）；浦肯野纤维 ≠ 小脑浦肯野细胞。
:::
