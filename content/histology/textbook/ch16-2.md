# 二、喉

喉以软骨为支架，软骨之间以韧带和肌肉相连。会厌表面为黏膜，内部为会厌软骨（弹性软骨）。会厌舌面及喉面上部的黏膜上皮为复层扁平上皮，内有味蕾，喉面基部为假复层纤毛柱状上皮。固有层为疏松结缔组织，有较多的弹性纤维、混合腺和淋巴组织（图 16-3）。

:::definition{label="喉"}
喉以软骨为支架，软骨之间以韧带和肌肉相连。它是导气部的一段，同时承担发音。管腔侧壁的室襞、喉室和声襞是本节要摊开的三件套。
:::

:::definition{label="会厌"}
会厌表面为黏膜，内部为会厌软骨（弹性软骨）。会厌舌面及喉面上部的黏膜上皮为复层扁平上皮，内有味蕾；喉面基部为假复层纤毛柱状上皮。
:::

:::definition{label="会厌固有层"}
会厌固有层为疏松结缔组织，有较多的弹性纤维、混合腺和淋巴组织。
:::

:::concept{term="先问这块喉黏膜是复层扁平还是假复层纤毛柱状"}
看见喉的切片，先问上皮：摩擦和振动的游离面走复层扁平（会厌舌面及喉面上部、声带膜部），导气的深面走假复层纤毛柱状（会厌喉面基部、室襞、喉室、声带软骨部）。会厌内部是弹性软骨，不是透明软骨。把喉听成“全程呼吸道上皮”，味蕾、声韧带和声带肌那几本账会从第一层错位。
:::

:::compare{title="会厌各面的上皮"}
| 部位 | 上皮 | 特殊结构 | 要点 |
|------|------|----------|------|
| 会厌舌面及喉面上部 | 复层扁平上皮 | 内有味蕾 | 食物摩擦面，不是纤毛传送带 |
| 会厌喉面基部 | 假复层纤毛柱状上皮 | — | 与下呼吸道黏膜相续 |
| 会厌内部 | — | 会厌软骨（弹性软骨） | 支架是弹性软骨，不是透明软骨环 |
:::

:::pitfall{label="会厌内部是弹性软骨，不要写成气管那种透明软骨"}
会厌软骨是弹性软骨，才撑得住卷曲和回弹。气管外膜的支架才是 $16\sim 20$ 个 C 字形透明软骨环。把会厌写成透明软骨，弹性纤维和声韧带那本“能振动”的账会提前做错。
:::

喉侧壁黏膜形成两对皱襞，上为室襞，下为声襞，二者之间为喉室。室襞与喉室的黏膜及黏膜下层结构相似，上皮为假复层纤毛柱状上皮，夹有杯状细胞。固有层和黏膜下层为疏松结缔组织，含有许多混合腺和淋巴组织。声襞即声带，其较薄的游离缘为膜部，基部为软骨部。膜部覆有复层扁平上皮，固有层较厚，浅层疏松，炎症时易发生水肿，深层为致密结缔组织，内含大量弹性纤维与表面平行排列，形成致密板状结构，称声韧带。固有层下方的骨骼肌为声带肌。声带振动主要发生在膜部。声带的软骨部黏膜结构与室襞相仿。

:::definition{label="室襞"}
室襞是喉侧壁上方的一对黏膜皱襞。上皮为假复层纤毛柱状上皮，夹有杯状细胞。固有层和黏膜下层为疏松结缔组织，含有许多混合腺和淋巴组织。
:::

:::definition{label="喉室"}
喉室位于室襞与声襞之间。黏膜及黏膜下层结构与室襞相似：假复层纤毛柱状上皮夹杯状细胞，固有层和黏膜下层疏松，含混合腺和淋巴组织。
:::

:::definition{label="声襞"}
声襞即声带，是喉侧壁下方的一对皱襞。较薄的游离缘为膜部，基部为软骨部。声带振动主要发生在膜部。
:::

:::definition{label="声带膜部"}
膜部覆有复层扁平上皮。固有层较厚：浅层疏松，炎症时易发生水肿；深层为致密结缔组织，内含大量弹性纤维与表面平行排列，形成致密板状结构，称声韧带。固有层下方的骨骼肌为声带肌。
:::

:::definition{label="声韧带"}
声韧带是声带膜部固有层深层的致密板状结构，由大量与表面平行排列的弹性纤维构成。它是振动的弹性支架，不是透明软骨。
:::

:::definition{label="声带肌"}
声带肌是声带固有层下方的骨骼肌。收缩改变声带紧张度；振动本身主要发生在膜部。
:::

:::definition{label="声带软骨部"}
声带基部为软骨部。软骨部黏膜结构与室襞相仿：假复层纤毛柱状上皮，不是膜部那种复层扁平。
:::

:::compare{title="室襞与声襞"}
| 项目 | 室襞 | 声襞（声带） |
|------|------|--------------|
| 位置 | 上 | 下；二者之间为喉室 |
| 上皮 | 假复层纤毛柱状，夹杯状细胞 | 膜部：复层扁平；软骨部：与室襞相仿（假复层纤毛柱状） |
| 固有层 | 疏松结缔组织，许多混合腺和淋巴组织 | 膜部固有层较厚：浅层疏松，深层为声韧带 |
| 肌 | 无声带肌这本账 | 固有层下方为声带肌（骨骼肌） |
| 职分 | 导气、黏液和局部免疫 | 发音；振动主要在膜部 |
| 炎症 | 腺体和淋巴组织所在 | 膜部浅层疏松，炎症时易水肿 |
:::

:::compare{title="声带膜部与软骨部"}
| 项目 | 膜部 | 软骨部 |
|------|------|--------|
| 位置 | 较薄的游离缘 | 基部 |
| 上皮 | 复层扁平上皮 | 与室襞相仿（假复层纤毛柱状） |
| 固有层 | 较厚；浅层疏松、深层声韧带 | 同室襞，含混合腺和淋巴组织 |
| 振动 | 声带振动主要发生在此 | 不承担主要振动 |
:::

:::pitfall{label="声带膜部是复层扁平，不要把整条声带写成假复层纤毛柱状"}
室襞、喉室和声带软骨部才是假复层纤毛柱状。膜部要振动、要耐受撞击，上皮改成复层扁平，深层再铺一层与表面平行的弹性纤维当声韧带。把声带一律写成呼吸道上皮，振动面和水肿面都会找错层。
:::

:::pitfall{label="声带肌是骨骼肌，不要写成气管膜性部那种平滑肌"}
固有层下方的声带肌是骨骼肌，管发声时的精细紧张度。气管膜性部缺口里的才是平滑肌束，咳嗽时缩小管腔助排痰。两本肌账不能并成“喉和气管都是平滑肌”。
:::

:::insight{label="声带浅层疏松是水肿的空间，深层平行弹性纤维才是振动的弦"}
膜部固有层故意分成两层：浅层疏松，炎症液体容易在这里堆积，所以声带水肿来得快；深层把弹性纤维排成板状声韧带，下面再衬骨骼肌。发音先问膜部，炎症也先问浅层。把固有层听成“一整块结缔组织”，水肿和音调会写成同一层的事。
:::

:::keypoint{label="喉先立会厌两面上皮，再把室襞、喉室和声带膜部摊开"}
- 喉以软骨为支架，韧带和肌肉相连；会厌内部为弹性软骨。
- 会厌舌面及喉面上部：复层扁平，内有味蕾；喉面基部：假复层纤毛柱状。
- 侧壁两对皱襞：上室襞、下声襞，中间喉室。
- 室襞与喉室：假复层纤毛柱状夹杯状细胞，疏松结缔组织含混合腺和淋巴组织。
- 声带膜部：复层扁平；固有层浅层疏松易水肿，深层为声韧带；下方声带肌为骨骼肌。振动主要在膜部。
- 声带软骨部黏膜结构与室襞相仿。
:::
