# 一、先天畸形的分类

本章把先天畸形按分类、原因、致畸敏感期和三级预防四条摊开。先天畸形是出生缺陷里形态结构那一份，活产婴儿中约占 $3\%$。本节先把十种类型按“范围”和“机制”切开：整体、局部、器官、组织分化不良是范围；发育过度、吸收不全、超数或异位、发育滞留、重复、寄生是机制。遗传与环境、受精后第 $3\sim 8$ 周敏感期、婚前检查到宫内治疗，放到后面三节。

先天畸形（congenital malformation）是指由于胚胎发育紊乱所致的出生时就存在的各种形态结构异常，属于出生缺陷（birth defect）的一种。出生缺陷还包括先天功能、代谢以及行为等方面的异常。研究出生缺陷的科学称为畸形学（teratology），是胚胎学的一个重要分支。

随着现代工业的快速发展，环境污染日趋严重，先天畸形的发生率约占活产婴儿的 $3\%$，且有上升的趋势，已成为严重危害人类健康的疾病，受到世界各国的高度重视。

:::definition{label="先天畸形"}
先天畸形（congenital malformation）是指由于胚胎发育紊乱所致的出生时就存在的各种形态结构异常。它是出生时就有的形态结构问题，不是出生后才获得的变形。
:::

:::definition{label="出生缺陷"}
出生缺陷（birth defect）口径比先天畸形宽。先天畸形是其中形态结构那一份；出生缺陷还包括先天功能、代谢以及行为等方面的异常。
:::

:::definition{label="畸形学"}
研究出生缺陷的科学称为畸形学（teratology），是胚胎学的一个重要分支。它研究的是出生缺陷的发生、原因和干预，不只是给畸形起名字。
:::

:::definition{label="活产婴儿中的发生率"}
先天畸形的发生率约占活产婴儿的 $3\%$，且有上升趋势。这是活产口径上的形态结构畸形，不要和插入框里我国出生缺陷约 $5.6\%$ 混成同一个数字。
:::

:::concept{term="先问这是形态结构异常还是功能、代谢、行为异常，再问是不是出生时就已经存在"}
看见“先天”二字，先切开口径：形态结构异常才叫先天畸形；功能、代谢、行为异常可以算出生缺陷，但不在先天畸形这一份里。再问时间：必须是胚胎发育紊乱、出生时就存在，不是产后外伤或感染造成的变形。把出生缺陷全部写成先天畸形，后面的分类十条会少掉功能、代谢那一本账。
:::

:::compare{title="先天畸形、出生缺陷与畸形学"}
| 项目 | 先天畸形 | 出生缺陷 | 畸形学 |
|------|----------|----------|--------|
| 英文 | congenital malformation | birth defect | teratology |
| 内涵 | 胚胎发育紊乱所致、出生时即存在的形态结构异常 | 出生时即存在的异常，含形态结构、功能、代谢、行为 | 研究出生缺陷的科学，胚胎学的重要分支 |
| 彼此关系 | 出生缺陷的一种（形态结构那一份） | 口径更宽，包含先天畸形 | 学科名称，不是又一种畸形 |
| 活产数字（教材） | 约占活产婴儿的 $3\%$，且有上升趋势 | 插入框另给我国出生缺陷发生率约 $5.6\%$ | — |
:::

:::pitfall{label="不要把出生缺陷和先天畸形画等号"}
先天畸形只覆盖形态结构。出生缺陷还要算上先天功能、代谢和行为异常。活产约 $3\%$ 说的是先天畸形；我国出生缺陷约 $5.6\%$ 是插入框里另一套口径，不要并成一句。
:::

:::note{label="工业污染与上升趋势"}
教材把上升趋势和现代工业、环境污染写在一起。分类、原因和敏感期都要在这个公共卫生背景下读：不是罕见病例点缀，而是活产约 $3\%$、还在升高的常见问题。
:::

## 十种类型

先天畸形主要分为以下几种类型。十条不要并成“大的、小的、多的、少的”：前四条问发育乱在整体、局部、器官还是组织；后六条问是长多了、该吸收没吸收、多长了一份原基、中途停住、双胎没分开，还是一大一小贴在一起。

### 1. 整体胚胎发育畸形

多数是由严重遗传缺陷引起，一般不能形成完整的胚胎，大多早期死亡。

:::definition{label="整体胚胎发育畸形"}
整体胚胎发育畸形多数由严重遗传缺陷引起，一般不能形成完整的胚胎，大多早期死亡。乱的是整胚能不能成形，不是某一个器官。
:::

### 2. 胚胎局部发育畸形

是由胚体局部发育紊乱所引起的，常涉及多个器官，如头面发育不全、并肢畸形等。

:::definition{label="胚胎局部发育畸形"}
胚胎局部发育畸形由胚体局部发育紊乱引起，常涉及多个器官。教材举例：头面发育不全、并肢畸形。范围大于单个器官，小于整胚不能成形。
:::

### 3. 器官或器官局部畸形

由某一器官不发生或发育不全所致，如单侧或双侧肺不发生、室间隔膜部缺损、腭裂等。

:::definition{label="器官或器官局部畸形"}
器官或器官局部畸形由某一器官不发生或发育不全所致。教材举例：单侧或双侧肺不发生、室间隔膜部缺损、腭裂。落点是一个器官或其局部，不是一片胚体、也不是组织分化那一层。
:::

### 4. 组织分化不良性畸形

由组织分化紊乱所引起，发生时间较晚且肉眼不易识别，如软骨发育不全、克汀病、先天性巨结肠等。

:::definition{label="组织分化不良性畸形"}
组织分化不良性畸形由组织分化紊乱引起，发生时间较晚且肉眼不易识别。教材举例：软骨发育不全、克汀病、先天性巨结肠。外形可以“看起来还在”，乱的是组织分化。
:::

### 5. 发育过度性畸形

由器官或器官的一部分增生过度所致，如多指（趾）畸形等。

:::definition{label="发育过度性畸形"}
发育过度性畸形由器官或器官的一部分增生过度所致。教材举例：多指（趾）畸形。是原有结构长过了，不是另起一份原基。
:::

### 6. 吸收不全性畸形

由胚胎发育过程中某些应全部或部分吸收的结构吸收不全所致，如肛门闭锁、食管闭锁等。

:::definition{label="吸收不全性畸形"}
吸收不全性畸形由胚胎发育过程中某些应全部或部分吸收的结构吸收不全所致。教材举例：肛门闭锁、食管闭锁。该消失的膜或腔没消失干净。
:::

### 7. 超数或异位发生性畸形

由器官原基超数发生或发生于异常部位所致，如多乳腺、异位乳腺、双肾盂、双输尿管等。

:::definition{label="超数或异位发生性畸形"}
超数或异位发生性畸形由器官原基超数发生或发生于异常部位所致。教材举例：多乳腺、异位乳腺、双肾盂、双输尿管。多出来的是原基，或原基长错了地方。
:::

### 8. 发育滞留性畸形

由器官发育中途停止所致，如双角子宫、隐睾、骨盆肾、气管食管瘘等。

:::definition{label="发育滞留性畸形"}
发育滞留性畸形由器官发育中途停止所致。教材举例：双角子宫、隐睾、骨盆肾、气管食管瘘。不是该吸收的没吸收，而是该走完的步骤停在半路。
:::

### 9. 重复畸形

由单卵双胎未能完全分离所致，胎儿整体或部分结构出现不同程度的重复，如连体双胎等。

:::definition{label="重复畸形"}
重复畸形由单卵双胎未能完全分离所致，胎儿整体或部分结构出现不同程度的重复。教材举例：连体双胎。两个胎儿没分开干净。
:::

### 10. 寄生畸形

由单卵双胎的两个胎儿发育速度相差甚大所致，小胎或不完整的小胎附着在大胎的某一结构或部位上。

:::definition{label="寄生畸形"}
寄生畸形由单卵双胎的两个胎儿发育速度相差甚大所致，小胎或不完整的小胎附着在大胎的某一结构或部位上。同样来自单卵双胎，机制不是“没分开”，而是一大一小、小的贴在大的身上。
:::

目前，我国常规监测的先天畸形主要包括神经系统先天畸形、先天性心血管病、颜面和四肢先天畸形、消化和泌尿系统先天畸形等。

:::definition{label="我国常规监测的先天畸形"}
我国常规监测主要包括神经系统先天畸形、先天性心血管病、颜面和四肢先天畸形、消化和泌尿系统先天畸形等。监测名单不能代替上面十条发生学分类。
:::

:::compare{title="先天畸形的十种类型"}
| 类型 | 发生学落点 | 教材举例 | 不要听成 |
|------|------------|----------|----------|
| 整体胚胎发育畸形 | 严重遗传缺陷，不能形成完整胚胎，大多早期死亡 | — | 某一个器官没长好 |
| 胚胎局部发育畸形 | 胚体局部发育紊乱，常涉及多个器官 | 头面发育不全、并肢畸形 | 只有一个器官的局部缺损 |
| 器官或器官局部畸形 | 某一器官不发生或发育不全 | 单侧或双侧肺不发生、室间隔膜部缺损、腭裂 | 整片胚体或多个系统一起乱 |
| 组织分化不良性畸形 | 组织分化紊乱；发生较晚，肉眼不易识别 | 软骨发育不全、克汀病、先天性巨结肠 | 外形一看就缺一块 |
| 发育过度性畸形 | 器官或器官一部分增生过度 | 多指（趾）畸形 | 另起一份器官原基（那是超数） |
| 吸收不全性畸形 | 应全部或部分吸收的结构吸收不全 | 肛门闭锁、食管闭锁 | 器官发育中途停住（那是滞留） |
| 超数或异位发生性畸形 | 器官原基超数发生，或发生在异常部位 | 多乳腺、异位乳腺、双肾盂、双输尿管 | 原有结构单纯增生（那是发育过度） |
| 发育滞留性畸形 | 器官发育中途停止 | 双角子宫、隐睾、骨盆肾、气管食管瘘 | 该吸收的结构没吸收完 |
| 重复畸形 | 单卵双胎未能完全分离，整体或部分重复 | 连体双胎 | 一大一小贴在一起（那是寄生） |
| 寄生畸形 | 单卵双胎两个胎儿发育速度相差甚大，小胎附着于大胎 | 小胎或不完整小胎附在大胎某部位 | 两个差不多大的胎儿没分开 |
:::

:::concept{term="先问乱在整胚、局部、器官还是组织，再问是长多了、没吸收、多一份原基、中途停还是双胎问题"}
十条先切范围：整胚不能成形、局部一片、单个器官、组织分化。范围对上了，再切机制：增生过度、该吸收没吸收、原基超数或异位、发育停在半路。最后两条都来自单卵双胎：没完全分开是重复畸形，速度快慢悬殊、小的贴在大的身上是寄生畸形。把多指写成超数原基，或把连体双胎写成寄生，户头就对错了。
:::

:::compare{title="发育过度、超数或异位、吸收不全与发育滞留"}
| 项目 | 发育过度 | 超数或异位 | 吸收不全 | 发育滞留 |
|------|----------|------------|----------|----------|
| 核心动作 | 已有结构增生过度 | 原基多长一份，或长错地方 | 该吸收的结构没吸收完 | 该完成的发育停在中途 |
| 教材例 | 多指（趾） | 多乳腺、异位乳腺、双肾盂、双输尿管 | 肛门闭锁、食管闭锁 | 双角子宫、隐睾、骨盆肾、气管食管瘘 |
| 问法 | 是不是同一份手指／器官长多了 | 是不是多出一份原基或位置不对 | 是不是胚胎期该消失的隔、膜没消失 | 是不是下降、上升、融合、分隔没做完 |
:::

:::compare{title="重复畸形与寄生畸形"}
| 项目 | 重复畸形 | 寄生畸形 |
|------|----------|----------|
| 共同前提 | 单卵双胎 | 单卵双胎 |
| 机制 | 未能完全分离 | 两个胎儿发育速度相差甚大 |
| 形态 | 整体或部分结构不同程度重复 | 小胎或不完整小胎附着在大胎某一结构或部位上 |
| 教材例 | 连体双胎 | 寄生小胎 |
:::

:::pitfall{label="多指不是超数原基，闭锁不是发育停在半路，连体不是寄生"}
多指（趾）是发育过度：原有指／趾增生过度。多乳腺、双输尿管才是原基超数或异位。肛门闭锁、食管闭锁是该吸收的结构吸收不全；双角子宫、隐睾、骨盆肾、气管食管瘘才是发育滞留。连体双胎是单卵双胎没分开；寄生畸形是速度相差甚大、小的贴在大的身上。四组不要对调。
:::

:::pitfall{label="组织分化不良发生晚、肉眼不易识别，不要只在外形上找缺损"}
软骨发育不全、克汀病、先天性巨结肠，外形可以不缺一块。发生时间较晚，乱的是组织分化。把“看不出来”理解成“不是畸形”，这条会从十条里掉出去。
:::

:::insight{label="前四条问范围，后六条问动作，最后两条才动用单卵双胎"}
整体、局部、器官、组织，是发育乱在哪一层。过度、吸收不全、超数异位、滞留，是同一个体里的四种动作。重复和寄生必须先确认单卵双胎，再问“没分开”还是“一大一小”。分类不是按系统（神经、心血管）来的；我国常规监测名单是另一把尺子。
:::

:::example{label="先对范围再对机制"}
头面发育不全、并肢：局部、常累多个器官。室间隔膜部缺损、腭裂、肺不发生：单个器官或其局部。多指：发育过度。肛门闭锁：吸收不全。隐睾、骨盆肾：发育滞留。连体双胎：重复。小胎贴在大胎上：寄生。对完范围再对机制，不要先背病名。
:::

:::keypoint{label="形态结构才叫先天畸形，十条按范围和机制记"}
- 先天畸形是胚胎发育紊乱所致、出生时即存在的形态结构异常，属于出生缺陷的一种。
- 出生缺陷还包括先天功能、代谢和行为异常；研究出生缺陷的科学称畸形学。
- 活产婴儿中先天畸形约占 $3\%$，且有上升趋势。
- 十条：整体胚胎发育、胚胎局部、器官或器官局部、组织分化不良、发育过度、吸收不全、超数或异位、发育滞留、重复、寄生。
- 重复是单卵双胎未完全分离；寄生是单卵双胎发育速度相差甚大。
- 我国常规监测：神经系统、先天性心血管病、颜面和四肢、消化和泌尿系统等。
:::
