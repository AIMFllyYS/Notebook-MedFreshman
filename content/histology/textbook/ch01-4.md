# 四、常用组织学技术

组织学技术种类较多，每一类技术又含许多分支，有的操作程序十分复杂，有的所用仪器极其精密，其原理涉及物理、化学、生物化学、免疫学、分子生物学等学科的知识。医学生不必在绪论里学会操作每一台仪器，但要把分辨率、染色亲和力和“看见的是结构还是分子”这几本账立住：人眼分辨率约为 $0.2\,\mathrm{mm}$，光镜约为 $0.2\,\mu\mathrm{m}$，扫描电镜约为 $2\,\mathrm{nm}$，透射电镜约为 $0.2\,\mathrm{nm}$。下面按光镜、电镜、组织化学、图像分析、细胞培养与组织工程、组织芯片和类器官逐项摊开。

:::definition{label="光学显微镜技术"}
应用一般光学显微镜（简称光镜）观察组织切片是组织学研究最基本的方法。光镜通常可放大 $1\,000$ 倍左右，分辨率一般为 $0.2\,\mu\mathrm{m}$。
:::

## （一）光学显微镜技术

光镜观察的石蜡包埋组织切片，通过取材、固定、石蜡包埋、切片、脱蜡、染色、透明等步骤制成。组织学中最常用的是苏木精–伊红染色。

:::definition{label="HE 染色"}
苏木精–伊红染色（hematoxylin-eosin staining）简称 HE 染色。苏木精（hematoxylin）是碱性染料，能将细胞核染成蓝紫色；伊红（eosin）是酸性染料，能将细胞质染成红色。
:::

:::definition{label="嗜碱性、嗜酸性与中性"}
对碱性染料亲和力强，称嗜碱性（basophilia）；对酸性染料亲和力强，称嗜酸性（acidophilia）；若与两种染料的亲和力均不强，称中性（neutrophilia）。
:::

小肠绒毛的 HE 染色把这组亲和力写成可看见的颜色：核呈蓝紫色（嗜碱性），细胞质呈红色（嗜酸性）（图 1-1）。

::figure{src="/images/histology/textbook/p0027_01.png" caption="图1-1 HE 染色的小肠绒毛光镜图。↑嗜碱性细胞核；▼嗜酸性细胞质。" alt="小肠绒毛HE染色：蓝紫色嗜碱性细胞核与红色嗜酸性细胞质"}

此外还有利用物理吸附作用的染色方法，如用苏丹染料显示脂肪组织：染料溶于脂肪内，使细胞内的脂滴显色。用硝酸银、氯化金等重金属盐显示细胞和组织的某些结构时，则是使金属微粒附着在结构表面而呈棕黑色或棕黄色。

:::definition{label="亲银性与嗜银性"}
银染法中，有些组织结构可直接使硝酸银还原而显示，称为亲银性（argentaffin）；有些结构无直接还原作用，需加入还原剂方能显色，则称为嗜银性（argyrophilia）。
:::

:::definition{label="异染性"}
结缔组织和软骨基质中的糖胺聚糖等成分，用甲苯胺蓝（toluidine blue）等碱性染料染色后呈紫红色，这种现象称为异染性（metachromasia）。染料本身是蓝的，结构却染成紫红，颜色“走样”恰恰是在报告糖胺聚糖的存在。
:::

以上方法制备的标本一般用普通光镜观察。组织化学技术中常使用荧光染料染色或作为标记物，需用荧光显微镜观察。

:::definition{label="荧光显微镜"}
荧光显微镜（fluorescence microscope）以紫外线为光源，能激发染料发出荧光，用于观察荧光染料染色或作为标记物的标本。
:::

在细胞培养技术中，一般光镜不易分辨无色透明的活细胞，需用相差显微镜才能观察。

:::definition{label="相差显微镜"}
相差显微镜（phase contrast microscope）可将活细胞不同厚度及细胞内各种结构对光产生的不同折射，转换为光密度差异（明暗差），从而使镜下结构反差明显、影像清晰。
:::

:::definition{label="激光扫描共聚焦显微镜"}
激光扫描共聚焦显微镜（laser scanning confocal microscopy，LSCM）是在荧光显微镜的基础上加装了激光共轭聚焦逐层扫描装置，利用计算机进行图像处理，从而得到细胞或组织内部微细结构的普通光或荧光图像。
:::

相对于普通显微镜技术，LSCM 可对较厚的组织切片进行连续精确的断层扫描，获得组织内各个层面的精细图像，然后经计算机处理后形成完整的三维图像。它也有利于用激光激发荧光：激发光强度可精确控制，荧光检测快，对细胞损伤小，具有良好的可重复性。此技术除可观察固定的组织外，还可动态观察体外培养的活细胞；能对已标记的细胞内分子或离子进行检测，发现各种物质的表达及其动态变化；图像数据可及时输出和长期储存。

近年出现的双光子显微镜（two-photon microscope）则结合激光扫描共聚焦显微镜和双光子激发技术，可用于观察更厚的标本，对活细胞的损伤更小，成像的立体感更强。

## （二）电子显微镜技术

与一般光镜相比，电镜用电子束代替可见光，用电磁透镜代替光学透镜，用荧光屏使肉眼不可见的电子束成像。常用的是透射电镜和扫描电镜：前者看内部超微结构，后者看表面立体形貌。

:::definition{label="透射电子显微镜"}
透射电子显微镜（transmission electron microscopy，TEM）因用电子束穿透样品、产生物像而得名。由于电子易被散射或被样品吸收，故穿透力低，需制备超薄切片（$50\sim 80\,\mathrm{nm}$）。透射电子显微镜的分辨率一般为 $0.2\,\mathrm{nm}$。
:::

取材要尽量新鲜，以保存细胞正常的超微结构。组织块（$1\,\mathrm{mm}^{3}$ 以内）用戊二醛与锇酸两次固定，脱水后进行树脂包埋，用超薄切片机切片，再经醋酸铀和柠檬酸铅染色。电子束投射到切片时，随细胞构成成分的密度以及吸附重金属铀、铅、锇的程度不同，而发生相应的电子散射。

:::definition{label="高电子密度与低电子密度"}
当电子束投射到密度大、吸附重金属多的结构（如溶酶体）时，电子被散射得多，投射到荧光屏上的电子少而呈暗像，电镜照片上呈黑或深灰色，习惯称该结构为高电子密度；反之呈浅灰色，称低电子密度。
:::

:::definition{label="扫描电子显微镜"}
扫描电子显微镜（scanning electron microscopy，SEM）观察时，电镜发射极细的电子束在标本表面进行扫描，标本表面散射的二次电子被探测器收集，形成电信号传送到显像管，在荧光屏上显示标本表面的立体结构。扫描电子显微镜的分辨率一般为 $2\,\mathrm{nm}$。
:::

SEM 取材后，组织块用戊二醛和锇酸两次固定，经脱水、干燥后，再在其表面喷镀薄层金膜。用扫描电子显微镜能观察较大的组织表面；因其景深长，凹凸不平的结构也能清晰成像，故图像具有立体感。

:::compare{title="光镜、透射电镜与扫描电镜"}
| 项目 | 光镜 | 透射电镜（TEM） | 扫描电镜（SEM） |
|------|------|-----------------|-----------------|
| 成像媒介 | 可见光 + 光学透镜 | 电子束穿透样品 + 电磁透镜 | 电子束扫描表面，收集二次电子 |
| 分辨率（教材） | 约 $0.2\,\mu\mathrm{m}$ | 约 $0.2\,\mathrm{nm}$ | 约 $2\,\mathrm{nm}$ |
| 放大（光镜） | 通常约 $1\,000$ 倍 | 超微结构 | 表面形貌 |
| 标本 | 石蜡切片等（取材、固定、包埋、切片、脱蜡、染色、透明） | 新鲜取材；$1\,\mathrm{mm}^{3}$ 内；戊二醛与锇酸双重固定；树脂包埋；超薄切片 $50\sim 80\,\mathrm{nm}$；铀、铅染色 | 戊二醛与锇酸双重固定；脱水、干燥；表面喷镀薄层金膜 |
| 图像特点 | 彩色（取决于染色）；平面结构 | 灰阶；高/低电子密度反映内部致密程度 | 景深长，凹凸结构清晰，立体感强 |
| 主要用途 | 基本形态观察（如 HE） | 细胞器等内部超微结构 | 较大组织表面的立体结构 |
:::

## （三）组织化学技术

:::definition{label="组织化学"}
组织化学（histochemistry）为应用化学、物理、生物化学、免疫学或分子生物学的原理和技术，与组织学技术相结合而产生的技术，能在组织切片定性、定位地显示某种物质的存在与否以及分布状态。还可进一步用显微分光光度计或图像分析仪测定切片中该物质反应的强度，获得定量的信息。
:::

:::definition{label="细胞化学"}
应用组织化学技术于游离细胞的样品（如细胞涂片），则称细胞化学（cytochemistry）。
:::

### 1. 一般组织化学

基本原理是在切片上加入某种试剂，与组织中的待检物质发生化学反应，其最终产物为有色沉淀物或重金属沉淀，以便用显微镜观察。显示糖类时，常用过碘酸希夫反应。

:::definition{label="PAS 反应"}
过碘酸希夫反应（periodic acid Schiff reaction）简称 PAS 反应，用于显示聚糖和糖蛋白的糖链。糖被强氧化剂过碘酸氧化后形成多醛，后者再与无色的品红硫酸复合物（即希夫试剂）结合，形成紫红色反应产物。
:::

小肠上皮中，PAS 反应把杯状细胞的黏原颗粒写成紫红色（图 1-2）。

::figure{src="/images/histology/textbook/p0028_01.png" caption="图1-2 小肠光镜图。PAS 反应示上皮中杯状细胞的黏原颗粒呈紫红色。" alt="PAS反应小肠：杯状细胞黏原颗粒呈紫红色"}

### 2. 免疫组织化学

:::definition{label="免疫组织化学"}
免疫组织化学（immunohistochemistry）是根据抗原与抗体特异性结合的原理，检测组织中肽和蛋白质的技术。肽和蛋白质均具有抗原性。
:::

把某种肽或蛋白质作为抗原注入动物体内，会产生针对该抗原的特异性抗体（免疫球蛋白）。将抗体从动物血清中提取出来，与标记物相结合，即成为标记抗体。后者用组织切片或细胞涂片孵育，抗体则与其中相应抗原特异性结合，在显微镜下通过观察标记物而获知该肽或蛋白质的分布部位。常用标记物有荧光素和辣根过氧化物酶（图 1-3～图 1-5）。

::figure{src="/images/histology/textbook/p0028_02.png" caption="图1-3 免疫组织化学原理示意图。抗原分别与荧光素、辣根过氧化物酶或胶体金标记的抗体特异性结合，借标记物显示肽或蛋白质的分布。" alt="免疫组织化学原理：抗原结合荧光素、辣根过氧化物酶或胶体金标记抗体"}

激光扫描共聚焦显微镜可以把免疫细胞化学的多种标记叠在同一视野：神经干细胞呈绿色荧光蛋白阳性、发绿色荧光，神经元呈 $\beta$Ⅲ微管蛋白阳性、发红色荧光，细胞核经 DAPI 荧光染料标记、发蓝色荧光（图 1-4）。ABC 法染色则把大鼠腺垂体中的黄体生成素阳性细胞写成棕色沉淀（图 1-5）。

::figure{src="/images/histology/textbook/p0029_03.png" caption="图1-4 免疫细胞化学、激光扫描共聚焦显微镜图。神经干细胞呈绿色荧光蛋白阳性，发绿色荧光；神经元呈βⅢ微管蛋白阳性，发红色荧光；细胞核为 DAPI 荧光染料标记，发蓝色荧光。" alt="共聚焦免疫细胞化学：GFP绿色神经干细胞、βⅢ微管蛋白红色神经元、DAPI蓝色细胞核"}

### 3. 原位杂交

:::definition{label="原位杂交"}
原位杂交（in situ hybridization）即核酸分子杂交组织化学。免疫组织化学是在翻译水平检测基因的表达结果（肽和蛋白质），原位杂交则是检测基因（DNA 片段），即在转录水平检测基因的活性（mRNA）。
:::

其原理是用带有标记物的已知碱基顺序的核酸探针，与细胞内待测的核酸按碱基配对的原则进行特异性原位结合，即杂交，然后通过对标记物的显示和检测，获知待测核酸的有无及相对量。常用的标记物为地高辛。大鼠主动脉平滑肌细胞表达弹性蛋白 mRNA 时，细胞质呈棕黄色（图 1-6）。

::figure{src="/images/histology/textbook/p0029_01.png" caption="图1-6 原位杂交（地高辛标记）光镜图。大鼠主动脉平滑肌细胞表达弹性蛋白 mRNA，细胞质呈棕黄色。" alt="地高辛原位杂交：大鼠主动脉平滑肌细胞弹性蛋白mRNA，细胞质棕黄"}

:::pitfall{label="嗜酸嗜碱、亲银嗜银、免疫组化与原位杂交不要对调"}
碱性染料染核（嗜碱性、蓝紫），酸性染料染质（嗜酸性、红）；亲和力都不强才叫中性。亲银是结构自己能还原硝酸银，嗜银必须外加还原剂；把“银染阳性”一律写成亲银，会把两套机制做成一种颜色。免疫组织化学检测的是肽和蛋白质（翻译产物），原位杂交检测的是基因或 mRNA（转录水平）；看见棕色信号，先问标记的是抗体还是核酸探针。
:::

## （四）图像分析技术

:::definition{label="图像分析"}
图像分析（image analysis）又称形态计量（morphometry），是应用数学和统计学原理对组织切片提供的平面图像进行分析，获得立体的组织和细胞内各种有形成分的数量、体积、表面积等参数。这些数值从量的角度显示了结构与功能的关系；也可以测量组织化学染色切片，根据染色深浅而提供该物质含量的相对数值。此项技术需使用图像分析仪进行。
:::

常用参数如肺泡的数量和表面积、肾小体的数量和体积、胰岛的数量及其各类细胞的百分比等。

:::definition{label="体视学"}
应用计算机对连续的组织切片进行三维重建，以获得微细结构的立体模型，这部分内容称为体视学（stereology）。
:::

胰腺部分结构的计算机三维重建把动脉写成红色、静脉写成蓝色、导管写成黄色、胰岛写成紫色（图 1-7），正是把连续切片的平面账还原成立体模型。

::figure{src="/images/histology/textbook/p0030_02.png" caption="图1-7 计算机三维重建图像。胰腺部分结构：动脉（红色）、静脉（蓝色）、导管（黄色）和胰岛（紫色）。" alt="胰腺体视学三维重建：红动脉、蓝静脉、黄导管、紫胰岛"}

## （五）细胞培养和组织工程技术

:::definition{label="细胞培养"}
细胞培养（cell culture）是把从机体取得的细胞在体外模拟体内条件下进行培养的技术。如果培养的是组织块、器官的较大部分或全部，则分别称为组织培养和器官培养。但组织块和器官难以长久培养，故细胞培养开展得最广泛。体外培养及用体外培养物进行的实验常简称为 in vitro（在体外）。
:::

培养条件包括适宜的营养、生长因子、pH、渗透压、$\mathrm{O}_{2}$ 和 $\mathrm{CO}_{2}$ 浓度、温度等，还需严防微生物污染。培养液用含有各种营养成分的人工合成培养基配制，内加 $5\%\sim 10\%$ 的胎牛血清，后者含多种生长因子。

培养的细胞除少数种类（如淋巴细胞）悬浮于培养液中，一般都贴在培养瓶壁上生长。对贴壁培养的细胞需用相差显微镜观察，也可用显微录像或显微摄影连续记录细胞的生长过程。体外培养的细胞、组织或器官不仅可用于研究其代谢、增殖、分化、形态和功能变化，还可研究各种理化因子（激素、药物、毒物、辐射等）对活细胞的直接影响。

:::definition{label="原代培养与传代培养"}
将首次从体内取出的细胞进行培养，称原代培养。当细胞增殖、长满瓶壁时，必须将其按一定比例分散到若干个瓶中继续培养，此称传代培养。
:::

:::definition{label="细胞系与细胞株"}
经长期培养而成的细胞群体，称细胞系（cell line）。有的细胞系经一定传代次数培养后死亡，有的则可无限地传代培养，后者多为肿瘤细胞或正常细胞发生了基因突变。从细胞系中选择单个细胞进行培养，所形成的细胞群体称细胞株（cell strain）。
:::

HeLa 细胞株便是 1951 年用一位美国非洲裔妇女的宫颈癌细胞培养形成的，目前仍在世界各地的实验室中广泛应用。贴壁的 HeLa 细胞需在相差显微镜下才能把无色透明的活细胞轮廓看清楚。

:::definition{label="组织工程"}
组织工程（tissue engineering）是用细胞培养技术在体外模拟构建机体组织或器官的技术，旨在为器官缺损患者提供移植替代物。
:::

目前正在研究构建的组织、器官主要有皮肤、软骨、骨、肌腱、骨骼肌、血管、角膜等，其中组织工程皮肤较为成功，已成为商品用于治疗烧伤、皮肤静脉性溃疡等疾病。组织工程包括 4 个方面：①生长旺盛的细胞，也称种子细胞，多为各种组织的干细胞；②细胞外基质，由生物材料（如牛胶原）和无毒、可被机体吸收的人工合成高分子材料组成；③构建组织或器官，即把细胞置于细胞外基质中进行三维培养，并形成所需要的形状；④将构建物移植于机体的方法。

:::concept{term="组织工程四件事：种子细胞、基质、三维成形、移植"}
缺一不可。只有干细胞没有可吸收的基质，堆不成器官形状；只有材料没有种子细胞，只是支架；三维培养成形之后，还要解决如何植回机体。组织工程皮肤已经商品化，不代表骨、血管、角膜都已同等成熟。
:::

## （六）组织芯片技术

:::definition{label="组织芯片"}
组织芯片（tissue chip）也称组织微阵列（tissue microarray，TMA），是生物芯片技术的一个重要分支。将组织标本按不同的设计需求，有序地集成在固相载体上形成组织微阵列，再利用免疫组织化学、原位杂交、原位 PCR 等各种组织学、分子生物学技术对芯片中的组织进行检测。
:::

根据研究目的不同，可将组织芯片分成正常组织芯片、肿瘤组织芯片、单一或复合组织芯片、特定病理类型组织芯片等。其中肿瘤组织芯片又包括：①多肿瘤组织芯片（multitumor TMA），由不同类型肿瘤组成；②肿瘤进展组织芯片（progression TMA），由不同发展阶段肿瘤组成；③预后组织芯片（prognostic TMA），由治疗前后肿瘤组成；④其他组织芯片，对肿瘤病原学等进行相关研究。

组织芯片与基因芯片、蛋白质芯片一起构成了生物芯片系列，使人类能够有效利用成百上千份组织标本，在基因组、转录组和蛋白质组 3 个水平上进行研究，是一项新的生物学研究技术。

## （七）类器官技术

:::definition{label="类器官"}
类器官（organoid）指利用成体干细胞或多能干细胞进行体外三维（3D）培养而形成的、具有一定空间结构的组织类似物。类器官的来源分为两类：组织来源类器官和多能干细胞来源类器官。
:::

人肝类器官的共聚焦图像用 Hoechst 标记细胞核（蓝色）、Deep Red 标记细胞膜（红色）、尼罗红标记脂滴（绿色）（图 1-9）。

::figure{src="/images/histology/textbook/p0030_03.png" caption="图1-9 人肝类器官共聚焦显微镜图。用 Hoechst（蓝色，细胞核）、Deep Red（红色，细胞膜）和尼罗红（绿色，脂滴）标记的人肝类器官。" alt="人肝类器官共聚焦：Hoechst蓝核、Deep Red红膜、尼罗红绿脂滴"}

作为新兴的技术，类器官在科学研究领域潜力巨大，包括发育生物学、疾病病理学、细胞生物学、再生医学、精准医疗以及药物毒性和药效试验。类器官培养为研究人体发育提供了更广阔的平台，为药物筛选提供了新的技术，也是对现有 2D 培养方法和动物模型系统的高信息量的补充。此外，类器官使获取更接近自然人体发育的细胞并用于细胞治疗成为可能。

:::note{label="分辨率先记四档"}
形态学观察中，分辨率是一个重要指标。教材给出的对照是：人眼约为 $0.2\,\mathrm{mm}$，光镜约为 $0.2\,\mu\mathrm{m}$，扫描电镜约为 $2\,\mathrm{nm}$，透射电镜约为 $0.2\,\mathrm{nm}$。看见一张图，先问它是光镜彩色还是电镜灰阶，再问标尺落在微米还是纳米。
:::

:::keypoint{label="常用技术按‘看见什么’来收"}
- 光镜看显微形态：HE 把核写成嗜碱性蓝紫、质写成嗜酸性红；另有亲银/嗜银、异染、荧光、相差、LSCM 和双光子。
- 电镜看超微：TEM 穿透超薄切片，讲高/低电子密度；SEM 扫表面喷金，讲立体感。
- 组织化学把物质留下颜色或标记：PAS 显糖链；免疫组化显肽/蛋白质；原位杂交显基因或 mRNA。
- 图像分析/体视学把平面计量成立体参数；培养把细胞拿到体外；组织工程用种子细胞加基质三维构建；芯片把成百上千份标本做成微阵列；类器官用干细胞 3D 培养出有空间结构的组织类似物。
:::

:::memory{label="本节必背要点"}
- [ ] 光镜：放大约 $1\,000$ 倍，分辨率约 $0.2\,\mu\mathrm{m}$；石蜡切片步骤：取材、固定、石蜡包埋、切片、脱蜡、染色、透明。
- [ ] HE 染色：苏木精（碱性）染核蓝紫；伊红（酸性）染质红。
- [ ] 嗜碱性（basophilia）、嗜酸性（acidophilia）、中性（neutrophilia）。
- [ ] 苏丹染料溶于脂肪显示脂滴；银/金盐使金属微粒附着呈棕黑或棕黄。
- [ ] 亲银性（argentaffin）：结构直接还原硝酸银；嗜银性（argyrophilia）：需加还原剂；异染性（metachromasia）：甲苯胺蓝等碱性染料把糖胺聚糖染成紫红。
- [ ] 荧光显微镜以紫外线为光源激发荧光；相差显微镜把折射差转为明暗差，观察无色透明活细胞。
- [ ] LSCM：荧光显微镜 + 激光共轭聚焦逐层扫描 + 计算机三维重建；可观察固定组织和培养活细胞，检测已标记分子/离子。双光子显微镜观察更厚标本，对活细胞损伤更小。
- [ ] TEM：电子束穿透；超薄切片 $50\sim 80\,\mathrm{nm}$；组织块 $<1\,\mathrm{mm}^{3}$；戊二醛与锇酸双重固定、树脂包埋、铀/铅染色；分辨率约 $0.2\,\mathrm{nm}$。高电子密度：散射多、图像暗；低电子密度：图像浅。
- [ ] SEM：表面喷镀金膜，收集二次电子；景深长、立体感强；分辨率约 $2\,\mathrm{nm}$。
- [ ] 人眼分辨率约 $0.2\,\mathrm{mm}$；光镜 $0.2\,\mu\mathrm{m}$；SEM $2\,\mathrm{nm}$；TEM $0.2\,\mathrm{nm}$。
- [ ] 组织化学：切片上定性、定位显示物质，并可定量；用于涂片则称细胞化学。
- [ ] PAS：过碘酸氧化糖成多醛，与希夫试剂结合呈紫红，显示聚糖和糖蛋白糖链。
- [ ] 免疫组织化学：抗原–抗体特异结合，检测肽和蛋白质（翻译水平）；常用标记物为荧光素、辣根过氧化物酶。
- [ ] 原位杂交：标记核酸探针按碱基配对杂交，检测基因或 mRNA（转录水平）；常用标记物为地高辛。
- [ ] 图像分析/形态计量：由平面图像得数量、体积、表面积等立体参数；体视学是连续切片的三维重建。
- [ ] 细胞培养：体外模拟体内条件；组织块/器官培养难以长久，故细胞培养最广泛；in vitro = 在体外。条件含营养、生长因子、pH、渗透压、$\mathrm{O}_{2}/\mathrm{CO}_{2}$、温度，防污染；培养基加 $5\%\sim 10\%$ 胎牛血清。
- [ ] 淋巴细胞等可悬浮；多数贴壁。原代培养：首次从体内取出；传代培养：按比例分散继续培养。
- [ ] 细胞系（cell line）：长期培养的细胞群体，有的有限传代，有的可无限传代（多为肿瘤或突变）。细胞株（cell strain）：从细胞系选单个细胞培养形成。HeLa（1951，宫颈癌）仍广泛使用。
- [ ] 组织工程：体外模拟构建组织或器官，供器官缺损移植。四方面：种子细胞（多为干细胞）、细胞外基质（生物材料 + 可吸收高分子）、三维培养成形、移植方法。组织工程皮肤已商品化（烧伤、静脉性溃疡等）。
- [ ] 组织芯片/TMA：标本有序集成于固相载体。肿瘤芯片含多肿瘤、进展、预后等类型；与基因芯片、蛋白质芯片构成生物芯片系列，可在基因组、转录组、蛋白质组 3 个水平研究。
- [ ] 类器官：成体干细胞或多能干细胞体外 3D 培养形成的、有一定空间结构的组织类似物；来源分组织来源与多能干细胞来源。用于发育、病理、细胞生物、再生医学、精准医疗、药毒和药效；补充 2D 培养和动物模型，并可能提供更接近自然发育的细胞用于治疗。
:::
