# 二、骨

骨是由骨组织、骨膜和骨髓等构成的坚硬器官，在机体中主要起支持、运动和保护作用。骨中含大量钙、磷等矿物质，是机体的钙、磷贮存库。骨的外形和内部结构符合其所承担的功能与生物力学原理，并能进行适应性重建。

:::definition{label="骨"}
骨是由骨组织、骨膜和骨髓等构成的坚硬器官，主要起支持、运动和保护作用。骨中含大量钙、磷等矿物质，是机体的钙、磷贮存库。外形和内部结构符合其所承担的功能与生物力学原理，并能进行适应性重建。
:::

:::concept{term="先问器官还是组织：骨 ≠ 骨组织"}
骨是器官：骨组织是结构主体，外面还有骨膜，腔内有骨髓，两端关节面覆关节软骨，并有血管神经穿行。骨组织才是“细胞 + 钙化基质”那一层。把骨听成一块骨质，会把骨膜干细胞、中央管营养和骨髓造血三本账做丢。
:::

## （一）骨组织

骨组织（osseous tissue）是骨的结构主体，主要由骨细胞和骨基质组成，由于骨组织有大量骨盐沉积，所以十分坚硬。

:::definition{label="骨组织"}
骨组织（osseous tissue）是骨的结构主体，主要由骨细胞和骨基质组成。大量骨盐沉积使其十分坚硬。
:::

### 1. 骨基质

骨基质（bone matrix）简称骨质，即骨组织中钙化的细胞外基质，包括有机成分和无机成分，含水量极少。有机成分为大量胶原纤维和少量无定形基质。胶原纤维粗大、排列规律，总量约占有机成分的 $90\%$，主要由Ⅰ型胶原蛋白构成。无定形基质的主要成分是蛋白聚糖及其复合物，具有黏合纤维的作用。骨质中还有骨钙蛋白、骨桥蛋白、骨粘连蛋白和钙结合蛋白等，它们在骨的钙化、钙离子的传递与平衡、细胞与骨质的黏附等方面各有作用。无机成分又称骨盐（bone salt），占干骨重量的 $65\%$，以钙、磷离子为主，也含多种其他元素。骨盐的存在形式主要是羟基磷灰石结晶，呈细针状，长 $10\sim 20\,\mathrm{nm}$，沿胶原原纤维长轴沉积并与之紧密结合。

新生骨组织的细胞外基质无骨盐沉积，此时称类骨质（osteoid）。大量骨盐规律性沉积后，类骨质转变为坚硬的骨质，该过程称钙化（calcification）或矿化（mineralization）。

:::definition{label="骨基质"}
骨基质（bone matrix）简称骨质，是骨组织中钙化的细胞外基质，包括有机成分和无机成分，含水量极少。有机成分以Ⅰ型胶原纤维为主（约占有机成分的 $90\%$），另有少量蛋白聚糖等无定形基质及骨钙蛋白、骨桥蛋白、骨粘连蛋白、钙结合蛋白等。无机成分即骨盐，占干骨重量的 $65\%$，以钙、磷为主，主要形式为羟基磷灰石结晶。
:::

:::definition{label="骨盐"}
骨盐（bone salt）是骨基质的无机成分，占干骨重量的 $65\%$，以钙、磷离子为主，也含多种其他元素。主要存在形式是羟基磷灰石结晶，细针状，长 $10\sim 20\,\mathrm{nm}$，沿胶原原纤维长轴沉积并与之紧密结合。
:::

:::definition{label="类骨质"}
类骨质（osteoid）是新生骨组织尚未有骨盐沉积的细胞外基质，即成骨细胞刚分泌出来的有机成分。
:::

:::definition{label="钙化"}
钙化（calcification）又称矿化（mineralization），是大量骨盐规律性沉积、类骨质转变为坚硬骨质的过程。
:::

:::derivation{title="类骨质如何写成坚硬骨质"}
1. 成骨细胞分泌骨基质的有机成分，形成尚无骨盐的类骨质。
2. 成骨细胞释放基质小泡（matrix vesicle），直径 $25\sim 200\,\mathrm{nm}$，内含细小钙盐结晶；小泡膜上有钙结合蛋白和碱性磷酸酶。
3. 钙盐结晶释放进入类骨质，以此为基础形成羟基磷灰石结晶（细针状，长 $10\sim 20\,\mathrm{nm}$），沿胶原原纤维长轴沉积并结合。
4. 钙结合蛋白和碱性磷酸酶对钙化也发挥一定作用。
5. 大量骨盐规律性沉积后，类骨质转变为坚硬骨质。
:::

骨质的结构经历了由编织骨转变为板层骨的过程。编织骨（woven bone）的主要特征是胶原纤维无规则交织排列，是胚胎时期和 $5$ 岁以内儿童的骨质结构形式（也见于骨折修复期），以后逐渐重建成板层骨。成年后仅在牙槽骨和耳蜗等极少数部位存在编织骨。板层骨（lamellar bone）是以骨板形式存在的骨质结构。骨板（bone lamella）内有大量平行排列的胶原纤维，同一层骨板内的纤维相互平行，相邻骨板的纤维则相互垂直，这种排列方式如同多层木质胶合板，可以有效增加骨的强度（图 4-5）。在长骨骨干、扁骨和短骨表层中，骨板层数多、排列规则，所有骨板紧密结合，称密质骨。在长骨骨骺和骨干内表面、扁骨的板障和短骨中心等处，数层不甚规则的骨板形成大量针状或片状骨小梁（bone trabecula），搭建成有较大孔隙的立体网格样结构，肉眼可见骨质呈“疏松状”，故称松质骨。

:::definition{label="编织骨"}
编织骨（woven bone）的主要特征是胶原纤维无规则交织排列。它是胚胎时期和 $5$ 岁以内儿童的骨质结构形式，也见于骨折修复期，以后逐渐重建成板层骨。成年后仅在牙槽骨和耳蜗等极少数部位存在。
:::

:::definition{label="板层骨"}
板层骨（lamellar bone）是以骨板形式存在的骨质结构。骨板（bone lamella）内大量胶原纤维平行排列；同一层骨板内纤维相互平行，相邻骨板的纤维相互垂直，如同多层木质胶合板，有效增加骨的强度。
:::

:::definition{label="密质骨"}
密质骨是骨板层数多、排列规则、所有骨板紧密结合的骨质，分布于长骨骨干、扁骨和短骨表层。肉眼难见明显孔隙。
:::

:::definition{label="松质骨"}
松质骨由数层不甚规则的骨板形成大量针状或片状骨小梁（bone trabecula），搭成有较大孔隙的立体网格，肉眼呈“疏松状”。分布于长骨骨骺和骨干内表面、扁骨的板障和短骨中心等处。
:::

:::definition{label="骨小梁"}
骨小梁（bone trabecula）是松质骨中针状或片状的骨质结构，由数层不甚规则的骨板构成，交织成多孔隙网架，网眼中充填骨髓。骨小梁也属于板层骨。
:::

:::compare{title="编织骨与板层骨"}
| 项目 | 编织骨（woven bone） | 板层骨（lamellar bone） |
|------|---------------------|------------------------|
| 胶原排列 | 无规则交织 | 骨板内平行；相邻骨板相互垂直（胶合板样） |
| 出现时期 | 胚胎时期、$5$ 岁以内儿童；骨折修复期 | 编织骨重建之后的成熟骨质 |

| 力学 | 快速成骨，强度相对较低 | 有效增加骨的强度 |

:::

:::pitfall{label="松质骨不是编织骨，密质骨也不是另一种细胞"}
“疏松状”是肉眼看见骨小梁网格，骨小梁本身仍是板层骨，只是层数少、排列不甚规则。编织骨说的是胶原无规则交织，出现在胚胎、幼儿和骨折修复，不要和松质骨画等号。密质骨与松质骨是板层骨的两种构筑，不是两种细胞。
:::

### 2. 骨组织的细胞

骨组织的细胞包括骨祖细胞、成骨细胞、骨细胞和破骨细胞，其中，仅骨细胞位于骨组织内部，其余 $3$ 种则分布在表面（图 4-6）。

:::definition{label="骨组织的四种细胞"}
骨组织的细胞包括骨祖细胞、成骨细胞、骨细胞和破骨细胞。仅骨细胞位于骨组织内部，其余三种分布在骨组织表面。
:::

:::concept{term="先问细胞在骨里还是在骨表面"}
四种细胞不要平铺成一张名单。骨祖细胞、成骨细胞、破骨细胞都在表面做事：分化、分泌类骨质、溶骨。一旦成骨细胞被自己分泌的类骨质埋住，才改写成骨细胞，靠突起和骨小管在内部传信息和运组织液。切片上先问这颗细胞是埋在骨质里，还是贴在骨质边。
:::

**（1）骨祖细胞（osteoprogenitor cell）** 是软骨组织和骨组织共同的干细胞，位于软骨膜和骨膜内层，分化方向取决于所处部位和所受刺激的性质。细胞呈梭形，胞体小，细胞质少，核小色深（图 4-6）。当骨生长、重建或骨折修复时，骨祖细胞功能活跃，不断增殖分化为成骨细胞。

:::definition{label="骨祖细胞"}
骨祖细胞（osteoprogenitor cell）是软骨组织和骨组织共同的干细胞，位于软骨膜和骨膜内层。梭形，胞体小，胞质少，核小色深。分化方向取决于部位和刺激：在软骨膜内可成软骨细胞，在骨膜内骨生长、重建或骨折修复时增殖分化为成骨细胞。
:::

**（2）成骨细胞（osteoblast）** 分布在骨组织表面，常单层排列，呈矮柱状或不规则形。分泌活动旺盛时细胞质嗜碱性增强，电镜下可见大量粗面内质网和高尔基复合体，分泌产物为骨基质的有机成分，即类骨质。此外，成骨细胞还释放基质小泡（matrix vesicle），小泡直径 $25\sim 200\,\mathrm{nm}$，内含细小钙盐结晶，小泡膜上有钙结合蛋白和碱性磷酸酶。钙盐结晶释放进入类骨质后，即以其为基础形成羟基磷灰石结晶，钙结合蛋白和碱性磷酸酶对钙化也发挥一定作用。除了产生类骨质，成骨细胞还分泌多种细胞因子，调节骨组织的形成和吸收、促进骨组织钙化。随着分泌的类骨质增多，成骨细胞自身被包埋其中，细胞发出许多细长突起，胞体和细胞核逐渐缩小，渐成扁椭圆形，逐渐转变为骨细胞（图 4-6）。

成骨细胞并非持续处于活跃状态，当成骨功能相对静止时，其细胞变扁平，紧贴骨组织表面，称骨被覆细胞（bone lining cell）。当骨组织成骨功能重新活跃时，骨被覆细胞又可恢复为活跃状态的成骨细胞。因此，两者实为同一种细胞于不同功能状态下的表现。

:::definition{label="成骨细胞"}
成骨细胞（osteoblast）分布在骨组织表面，常单层排列，呈矮柱状或不规则形。分泌旺盛时胞质嗜碱性增强，粗面内质网和高尔基复合体发达，分泌类骨质并释放基质小泡，还分泌多种细胞因子调节成骨、吸收和钙化。被类骨质包埋后发出细长突起，逐渐转变为骨细胞。
:::

:::definition{label="基质小泡"}
基质小泡（matrix vesicle）由成骨细胞释放，直径 $25\sim 200\,\mathrm{nm}$，内含细小钙盐结晶，膜上有钙结合蛋白和碱性磷酸酶。钙盐结晶释放进入类骨质后，以此为基础形成羟基磷灰石结晶。
:::

:::definition{label="骨被覆细胞"}
骨被覆细胞（bone lining cell）是成骨功能相对静止时变扁平、紧贴骨组织表面的成骨细胞。成骨重新活跃时可恢复为活跃的成骨细胞。两者是同一种细胞的不同功能状态。
:::

:::pitfall{label="骨被覆细胞不是第四种成骨相关细胞"}
它只是成骨细胞的静止表型，相当于纤维细胞之于成纤维细胞。不要在骨祖细胞、成骨细胞、骨细胞之外再单列一种来源不同的“衬细胞”，也不要把它和破骨细胞混淆——破骨细胞来自单核细胞融合，贴在表面是为了溶骨。
:::

**（3）骨细胞（osteocyte）** 是位于骨组织内部有多个细长突起的细胞，比较均匀地分散于骨板之间或骨板内，由成骨细胞转变而成。细胞体所在腔隙称骨陷窝（bone lacunae），突起所在腔隙称骨小管（bone canaliculus）。骨细胞的结构和功能与其成熟度有关，刚转变的骨细胞仍能有分泌功能，随着细胞成熟，分泌能力逐渐减弱直至停止。在此过程中，胞体进一步变小，呈扁椭圆形，细胞器减少，突起延长。相邻骨细胞的突起以缝隙连接相连，借此可传递信息。此处的骨小管也彼此相通，骨陷窝和骨小管内含少量组织液。骨组织内的相邻骨陷窝通过骨小管互相连通，构成了骨组织内部的物质输送通道（图 4-6，图 4-7）。骨细胞还具有一定的溶骨作用，参与调节钙、磷平衡。

:::definition{label="骨细胞"}
骨细胞（osteocyte）位于骨组织内部，有多个细长突起，比较均匀地分散于骨板之间或骨板内，由成骨细胞转变而成。刚转变时仍能分泌，成熟后分泌减弱直至停止；胞体变小呈扁椭圆形，细胞器减少，突起延长。相邻突起以缝隙连接传递信息；并有一定溶骨作用，参与调节钙、磷平衡。
:::

:::definition{label="骨陷窝与骨小管"}
骨陷窝（bone lacunae）是骨细胞体所在腔隙；骨小管（bone canaliculus）是突起所在腔隙。相邻骨小管彼此相通，陷窝与小管内含少量组织液，构成骨组织内部的物质输送通道。
:::

:::pitfall{label="骨细胞不是孤岛：陷窝经突起和骨小管互相联系"}
钙化骨质把胞体锁进陷窝，营养不能再靠软骨那种整块基质渗透。同一骨单位内，最内层骨小管通中央管，相邻骨细胞突起以缝隙连接相连，组织液在陷窝–小管网里走。把骨细胞记成“埋进骨质就断了联系”，会把中央管营养和黏合线隔断两本账做丢。
:::

**（4）破骨细胞（osteoclast）** 是一种可游走的多核巨细胞，直径 $30\sim 100\,\mu\mathrm{m}$，一般认为由多个单核细胞融合而成，具有强大的溶骨能力。破骨细胞散在分布于骨组织表面，形态不规则，细胞核 $6\sim 50$ 个不等，细胞质丰富、嗜酸性强，含丰富的溶酶体和线粒体（见图 4-6）。溶骨活跃时，细胞呈现明显极性。电镜下可见紧贴骨组织的一侧出现许多长短与粗细不一的突起，构成光镜下的皱褶缘（ruffled border）。环绕于皱褶缘的细胞质略微隆起，构成一圈细胞质围墙环绕皱褶缘。细胞质围墙的电子密度低，称亮区（clear zone），也称封闭区（sealing zone）。亮区的细胞膜紧贴骨组织，使皱褶缘和对应的骨组织表面凹陷之间封闭成一个密闭的腔隙，称吸收陷窝（absorption lacuna）。此处是一个特殊的微环境，破骨细胞在此释放多种水解酶和有机酸，溶解骨盐、分解有机成分。皱褶缘深面的细胞质中有许多吞饮泡和吞噬泡，可将溶解内吞的成分进一步降解（图 4-8）。在骨组织内，破骨细胞和成骨细胞相辅相成，共同参与骨的生长和重建。若破骨细胞异常，可导致骨的生长发育障碍，如骨硬化症患者的破骨细胞不能很好地形成皱褶缘，骨吸收缺陷导致骨质异常硬化，形成所谓的“大理石骨”。

:::definition{label="破骨细胞"}
破骨细胞（osteoclast）是可游走的多核巨细胞，直径 $30\sim 100\,\mu\mathrm{m}$，一般认为由多个单核细胞融合而成，具有强大溶骨能力。散在于骨组织表面，形态不规则，核 $6\sim 50$ 个，胞质丰富、嗜酸性强，溶酶体和线粒体丰富。
:::

:::definition{label="皱褶缘"}
皱褶缘（ruffled border）是溶骨活跃时破骨细胞紧贴骨组织一侧的许多长短粗细不一的突起，光镜下构成皱褶缘。它大大增加释放酶和酸、以及内吞溶解产物的表面积。
:::

:::definition{label="亮区"}
亮区（clear zone）也称封闭区（sealing zone），是环绕皱褶缘、略微隆起的一圈低电子密度细胞质围墙。其细胞膜紧贴骨组织，把皱褶缘与对应的骨表面凹陷封闭成吸收陷窝。
:::

:::definition{label="吸收陷窝"}
吸收陷窝（absorption lacuna）是亮区封闭形成的密闭腔隙。破骨细胞在此释放多种水解酶和有机酸，溶解骨盐、分解有机成分；皱褶缘深面的吞饮泡和吞噬泡将内吞成分进一步降解。
:::

:::example{label="骨硬化症：皱褶缘做不出来，骨就变成大理石"}
骨硬化症患者的破骨细胞不能很好地形成皱褶缘，骨吸收缺陷，骨质异常硬化，形成所谓的“大理石骨”。这从反面说明：重建必须成骨与破骨相辅相成；没有可用的皱褶缘和吸收陷窝，旧骨清不掉，新的力学构筑也排不出来。
:::

:::compare{title="成骨细胞与破骨细胞"}
| 项目 | 成骨细胞（osteoblast） | 破骨细胞（osteoclast） |
|------|----------------------|------------------------|
| 来源 | 骨祖细胞（间充质干细胞方向） | 一般认为由多个单核细胞融合（单核–巨噬细胞系） |
| 位置 | 骨组织表面，常单层 | 骨组织表面，散在可游走 |
| 形态 | 矮柱状或不规则形；静止时扁平为骨被覆细胞 | 多核巨细胞，直径 $30\sim 100\,\mu\mathrm{m}$，核 $6\sim 50$ 个，形态不规则 |
| 染色 | 分泌旺盛时胞质嗜碱性 | 胞质丰富，嗜酸性强 |
| 超微结构 | 粗面内质网、高尔基复合体发达；释放基质小泡 | 皱褶缘、亮区（封闭区）、溶酶体和线粒体丰富，吞饮泡/吞噬泡 |
| 产物与作用 | 分泌类骨质和细胞因子，启动钙化；被包埋后变为骨细胞 | 在吸收陷窝释放水解酶和有机酸，溶解骨盐、分解有机成分 |
| 与对方关系 | 相辅相成，共同参与生长和重建 | 同左；异常（如不能形成皱褶缘）→ 骨硬化症 |
:::

:::pitfall{label="破骨细胞来自单核–巨噬细胞系，不是骨祖细胞的另一种分化"}
骨祖细胞是软骨和骨共同的间充质干细胞，走向成软骨细胞或成骨细胞。破骨细胞一般认为由多个单核细胞融合而成，属于可游走的多核巨细胞。把四种骨组织细胞都写成“骨祖细胞的后代”，会把溶骨的免疫细胞谱系做成间充质谱系。
:::

:::cause-effect{title="皱褶缘 + 亮区如何写成一个溶骨微环境"}
- 因：溶骨活跃时破骨细胞出现极性，贴骨一侧形成皱褶缘
- 因：亮区（封闭区）细胞膜紧贴骨质，围成密闭的吸收陷窝
- 果：水解酶和有机酸被限制在陷窝内，溶解骨盐、分解有机成分，而不泄漏到周围组织
- 果：皱褶缘深面的吞饮泡和吞噬泡把溶解产物内吞并进一步降解
- 反例：不能形成皱褶缘 → 吸收缺陷 → 骨硬化症（大理石骨）
:::

## （二）长骨的结构

长骨由密质骨、松质骨、关节软骨、骨膜、骨髓、血管和神经等构成（图 4-9）。

:::definition{label="长骨的构成"}
长骨由密质骨、松质骨、关节软骨、骨膜、骨髓、血管和神经等构成。
:::

### 1. 密质骨

密质骨（compact bone）分布于骨干和骨骺的外侧面，主要特征是骨板结合紧密，肉眼下难见明显的孔隙。骨板排列有序，按排列方式可分为环骨板、骨单位和间骨板 $3$ 种形式（图 4-9，图 4-10）。

:::definition{label="密质骨（长骨）"}
密质骨（compact bone）分布于骨干和骨骺的外侧面，骨板结合紧密，肉眼难见明显孔隙。按骨板排列方式分为环骨板、骨单位和间骨板三种形式。
:::

**（1）环骨板（circumferential lamellae）** 是环绕骨干内、外表面的骨板，分别称为内环骨板和外环骨板。外环骨板厚，由数层或十多层骨板组成，较整齐地环绕骨干排列。内环骨板薄，仅由数层骨板组成，且不如外环骨板平整。

:::definition{label="环骨板"}
环骨板（circumferential lamellae）是环绕骨干内、外表面的骨板。外环骨板厚，数层或十多层，较整齐环绕骨干；内环骨板薄，仅数层，不如外环骨板平整。
:::

**（2）骨单位（osteon）** 又称哈弗斯系统（Haversian system），位于内、外环骨板之间，是长骨中起支持作用的主要结构。数量多，长筒状，可有分支，排列方向与骨干的长轴基本一致。骨单位由多层同心圆排列的骨单位骨板（又称哈弗斯骨板）围绕中央管（central canal）构成。骨板中的胶原纤维绕中央管呈螺旋状走行，相邻骨板的纤维方向互成直角。骨单位骨板为 $4\sim 20$ 层不等，故骨单位粗细不一。中央管为细长的管道，少量疏松结缔组织穿行其中，内有小血管和神经纤维。

:::definition{label="骨单位"}
骨单位（osteon）又称哈弗斯系统（Haversian system），位于内、外环骨板之间，是长骨中起支持作用的主要结构。长筒状，可有分支，排列方向与骨干长轴基本一致。由 $4\sim 20$ 层同心圆骨单位骨板（哈弗斯骨板）围绕中央管构成；相邻骨板纤维互成直角。
:::

:::definition{label="中央管"}
中央管（central canal）是骨单位中轴的细长管道，少量疏松结缔组织穿行其中，内有小血管和神经纤维。骨单位最内层的骨小管均与中央管相通，同一骨单位内的骨细胞接受来自自身中央管的营养供应。
:::

**（3）间骨板（interstitial lamella）** 位于骨单位之间或骨单位与环骨板之间，为大小和形状皆不规则的骨板聚集体，是骨生长和重建过程中较早期的骨单位和环骨板的残留部分。

:::definition{label="间骨板"}
间骨板（interstitial lamella）位于骨单位之间或骨单位与环骨板之间，大小和形状皆不规则，是骨生长和重建过程中较早期的骨单位和环骨板的残留部分。
:::

在 $3$ 种骨板之间及每个骨单位表面都有一层黏合质，是骨盐较多而纤维很少的骨质，在长骨横切面上呈折光较强的轮廓线，称黏合线（cement line）。骨单位最外层的骨小管在黏合线处折返，一般不与相邻骨单位的骨小管连通，而骨单位最内层的骨小管均与中央管相通。因此，同一骨单位内的骨细胞接受来自自身中央管的营养供应。

长骨骨干内有横向穿行的管道，称穿通管（perforating canal），也称福尔克曼管（Volkmann’s canal）。穿通管在骨外表面的开口为滋养孔，走行几乎与骨的长轴方向垂直，横向穿越密质骨中的环骨板，并连接骨单位的中央管。管内含结缔组织、血管、神经，以及骨祖细胞、成骨细胞和破骨细胞等，这些成分也延续到骨单位的中央管内。

:::definition{label="黏合线"}
黏合线（cement line）是三种骨板之间及每个骨单位表面那层骨盐较多、纤维很少的黏合质，在长骨横切面上呈折光较强的轮廓线。骨单位最外层骨小管在此折返，一般不与相邻骨单位的骨小管连通。
:::

:::definition{label="穿通管"}
穿通管（perforating canal）也称福尔克曼管（Volkmann’s canal），在长骨骨干内横向穿行。外表面开口为滋养孔，几乎与长轴垂直，穿越环骨板并连接各骨单位的中央管。管内含结缔组织、血管、神经以及骨祖细胞、成骨细胞和破骨细胞等，这些成分也延续到中央管内。
:::

:::concept{term="先问这根管子是顺着骨干走，还是横着把中央管串起来"}
中央管在骨单位中轴，与骨干长轴基本一致，养的是本骨单位里的骨细胞。穿通管几乎垂直于长轴，从滋养孔进来，穿过环骨板去接各中央管。黏合线把相邻骨单位的小管隔开，营养不能“串门”。看见横切面上的圆孔，先问它是中央管还是被斜切的穿通管。
:::

:::pitfall{label="黏合线一画，相邻骨单位的骨小管一般不相通"}
最外层骨小管在黏合线处折返，本骨单位的骨细胞只吃自己中央管送来的组织液。不要把骨小管网理解成整块密质骨共享的“一张网”。间骨板是旧骨单位和环骨板被切剩下的残块，不是第三种“正常工作的骨单位”。
:::

### 2. 松质骨

松质骨（spongy bone）分布于骨干的内侧面和骨骺中部，由大量针状或小片状的骨小梁构成，形成肉眼可见的多孔隙网架结构，网眼中充填骨髓。骨小梁也属于板层骨，但仅有数层，排列不甚规则，厚薄也有差异，故骨小梁的大小、形状也不完全相同。

:::definition{label="松质骨（长骨）"}
松质骨（spongy bone）分布于骨干内侧面和骨骺中部，由大量针状或小片状骨小梁构成肉眼可见的多孔隙网架，网眼中充填骨髓。骨小梁属板层骨，仅数层，排列不甚规则，厚薄有差异。
:::

### 3. 关节软骨

详见后文“关节”部分。

### 4. 骨膜

除关节面以外，长骨的内、外表面均覆有纤维性结缔组织构成的骨膜，分别称骨内膜和骨外膜，通常所说的骨膜指骨外膜（见图 4-9）。骨外膜（periosteum）为致密结缔组织，胶原纤维束粗大，交织成网。其中有些纤维束穿入骨质，称穿通纤维（perforating fiber），起固定骨膜和韧带的作用。骨膜内有血管、神经，深面有骨祖细胞。骨内膜（endosteum）为薄层疏松结缔组织，衬于骨髓腔面、骨小梁表面、穿通管和中央管内表面，其中小血管、神经纤维穿行，还含有骨祖细胞等。骨膜的主要作用是营养骨组织，并为骨的生长和修复提供干细胞，故临床上可利用骨膜移植治疗骨折和骨缺损。

:::definition{label="骨外膜"}
骨外膜（periosteum）为致密结缔组织，通常所说的骨膜即指此层。胶原纤维束粗大、交织成网；有些纤维束穿入骨质，称穿通纤维（perforating fiber），固定骨膜和韧带。内有血管、神经，深面有骨祖细胞。
:::

:::definition{label="骨内膜"}
骨内膜（endosteum）为薄层疏松结缔组织，衬于骨髓腔面、骨小梁表面、穿通管和中央管内表面。小血管、神经纤维穿行，并含骨祖细胞等。
:::

:::definition{label="穿通纤维"}
穿通纤维（perforating fiber）是骨外膜中穿入骨质的胶原纤维束，起固定骨膜和韧带的作用。
:::

:::note{label="骨膜的临床意义"}
骨膜营养骨组织，并为骨的生长和修复提供干细胞，故临床上可利用骨膜移植治疗骨折和骨缺损。关节面没有骨膜，与关节软骨无软骨膜是同一类“覆盖账”：运动面留给软骨，干细胞留在非关节面的骨膜里。
:::

### 5. 骨髓

详见第 5 章。

:::compare{title="长骨密质骨的三种骨板"}
| 项目 | 环骨板 | 骨单位（哈弗斯系统） | 间骨板 |
|------|--------|----------------------|--------|
| 位置 | 环绕骨干内、外表面 | 内、外环骨板之间 | 骨单位之间，或骨单位与环骨板之间 |
| 形态 | 外环：厚，数层或十多层，较整齐；内环：薄，数层，欠平整 | 长筒状，可分支，与骨干长轴基本一致；$4\sim 20$ 层同心圆骨板绕中央管 | 大小形状不规则的骨板聚集体 |
| 来源与意义 | 骨干表面添加和骨髓腔侧衬里 | 长骨主要支持结构；中央管供应本单位营养 | 较早期骨单位和环骨板的残留 |
| 营养通路 | 穿通管穿越环骨板连接中央管 | 最内层小管通中央管；最外层小管在黏合线折返 | 残留结构，本身不再是完整营养单位 |
:::

:::keypoint{label="骨组织先把钙化基质和四种细胞立住"}
- 骨是器官（骨组织 + 骨膜 + 骨髓等）；骨组织因骨盐沉积而坚硬，是钙磷贮存库。
- 骨质 = 有机（约 $90\%$ 为Ⅰ型胶原 + 少量基质蛋白）+ 无机（骨盐占干重 $65\%$，羟基磷灰石 $10\sim 20\,\mathrm{nm}$）；未钙化者称类骨质。
- 编织骨胶原交织，见于胚胎、$5$ 岁内及骨折修复；成熟骨为板层骨（邻层纤维垂直）。
- 仅骨细胞在内部，骨祖细胞、成骨细胞、破骨细胞在表面；成骨细胞被埋入后变为骨细胞。
- 破骨细胞由单核细胞融合，靠皱褶缘和亮区围出吸收陷窝溶骨。
- 长骨密质骨三种骨板：环骨板、骨单位、间骨板；黏合线隔开相邻骨单位的小管；穿通管横连中央管。
:::

:::memory{label="本节必背要点"}
- [ ] 骨由骨组织、骨膜和骨髓等构成，司支持、运动、保护，是钙、磷贮存库，并能适应性重建。
- [ ] 骨组织（osseous tissue）主要由骨细胞和骨基质组成，大量骨盐沉积使其坚硬。
- [ ] 骨基质（骨质）：有机成分以Ⅰ型胶原为主（约占有机成分 $90\%$），另有蛋白聚糖及骨钙蛋白、骨桥蛋白、骨粘连蛋白、钙结合蛋白等；含水量极少。
- [ ] 骨盐占干骨重量的 $65\%$，主要是羟基磷灰石结晶，细针状，长 $10\sim 20\,\mathrm{nm}$，沿胶原原纤维长轴沉积。
- [ ] 类骨质（osteoid）为尚未钙化的新生细胞外基质；钙化（calcification）/矿化（mineralization）使其变为坚硬骨质。
- [ ] 编织骨（woven bone）：胶原无规则交织；胚胎及 $5$ 岁以内，也见于骨折修复；成体仅牙槽骨、耳蜗等处。
- [ ] 板层骨（lamellar bone）：骨板内纤维平行，相邻骨板纤维垂直，如胶合板，增加强度。
- [ ] 密质骨：骨板层数多、排列规则、结合紧密；松质骨：骨小梁构成多孔隙网格。
- [ ] 四种细胞：骨祖细胞、成骨细胞、骨细胞、破骨细胞；仅骨细胞位于骨组织内部。
- [ ] 骨祖细胞（osteoprogenitor cell）：软骨和骨共同的干细胞，梭形、核小色深，位于软骨膜和骨膜内层。
- [ ] 成骨细胞（osteoblast）：表面单层，矮柱状或不规则；分泌类骨质，释放直径 $25\sim 200\,\mathrm{nm}$ 的基质小泡；被包埋后变为骨细胞。
- [ ] 骨被覆细胞（bone lining cell）是静止的成骨细胞，可恢复活跃。
- [ ] 骨细胞（osteocyte）：胞体在骨陷窝，突起在骨小管；突起以缝隙连接相连；陷窝经小管连通，构成内部输送通道；有一定溶骨作用，参与钙磷平衡。
- [ ] 破骨细胞（osteoclast）：多核巨细胞，直径 $30\sim 100\,\mu\mathrm{m}$，核 $6\sim 50$ 个，由单核细胞融合；胞质强嗜酸性。
- [ ] 皱褶缘（ruffled border）+ 亮区/封闭区（clear zone / sealing zone）围成吸收陷窝（absorption lacuna），释放酶和酸溶骨。
- [ ] 骨硬化症：破骨细胞不能很好形成皱褶缘，骨吸收缺陷，骨质异常硬化（大理石骨）。
- [ ] 长骨密质骨三种骨板：环骨板、骨单位（哈弗斯系统）、间骨板。
- [ ] 外环骨板厚（数层或十多层）、较整齐；内环骨板薄（数层）、欠平整。
- [ ] 骨单位：$4\sim 20$ 层同心圆骨板绕中央管；纤维螺旋走行，邻层互成直角；可有分支。
- [ ] 黏合线（cement line）：骨盐多、纤维少；最外层骨小管在此折返，一般不与相邻骨单位相通。
- [ ] 穿通管（Volkmann 管）几乎垂直于长轴，滋养孔开口，连接中央管。
- [ ] 骨外膜为致密结缔组织，穿通纤维固定骨膜和韧带；骨内膜为薄层疏松结缔组织，衬骨髓腔、骨小梁、穿通管和中央管。
- [ ] 骨膜营养骨组织并提供干细胞，可移植治疗骨折和骨缺损；骨髓见第 5 章。
