# 四、肺

肺表面被覆浆膜（胸膜脏层）。肺组织分实质和间质两部分，实质即肺内支气管的各级分支及其终末的大量肺泡（图 16-8）。从主支气管至肺泡大约有 24 级分支（表 16-1）。

:::definition{label="肺"}
肺表面被覆浆膜（胸膜脏层）。肺组织分实质和间质两部分。实质即肺内支气管的各级分支及其终末的大量肺泡；间质包括结缔组织、血管、淋巴管和神经。
:::

:::definition{label="肺实质"}
肺实质是肺内支气管的各级分支及其终末的大量肺泡。从主支气管至肺泡大约有 24 级分支。
:::

:::definition{label="支气管树"}
因主支气管的反复分支呈树枝状，故称支气管树。其中，从叶支气管到终末细支气管为肺导气部，呼吸性细支气管以下各段均不同程度出现肺泡，为肺呼吸部。
:::

:::concept{term="先问这级支气管壁上有没有肺泡，再问软骨、腺体和平滑肌还剩多少"}
进肺以后不要按“管子越细就越会换气”来记。先问壁上有没有肺泡：没有，仍是肺导气部；有了，才进肺呼吸部。导气部内部再问三件事：上皮还是不是假复层纤毛柱状，杯状细胞、腺体和软骨片还在不在，平滑肌是断续还是完整环行。把 24 级听成“只是越分越细”，终末细支气管和呼吸性细支气管会写成同一级。
:::

:::note{label="表16-1 主支气管至肺泡的各级分支"}
| 名称 | 分级 | 名称 | 分级 |
|------|------|------|------|
| 主支气管 | 第 1 级 | 终末细支气管 | 第 $14\sim 16$ 级 |
| 叶支气管 | 第 2 级 | 呼吸性细支气管 | 第 $17\sim 19$ 级 |
| 段支气管 | 第 $3\sim 4$ 级 | 肺泡管 | 第 $20\sim 22$ 级 |
| 小支气管 | 第 $5\sim 10$ 级 | 肺泡囊 | 第 23 级 |
| 细支气管 | 第 $11\sim 13$ 级 | 肺泡 | 第 24 级 |
:::

因主支气管的反复分支呈树枝状，故称支气管树。其中，从叶支气管到终末细支气管为肺导气部，呼吸性细支气管以下各段均不同程度出现肺泡，为肺呼吸部。每一细支气管连同它的各级分支和肺泡，组成一个肺小叶（pulmonary lobule）（图 16-9）。肺小叶呈锥形，尖朝向肺门，底向肺表面，小叶之间有结缔组织间隔，在肺表面可见肺小叶底部轮廓，直径 $1\sim 2.5\,\mathrm{cm}$。每叶肺有 $50\sim 80$ 个肺小叶，它们是肺的结构单位。临床上常见累及若干肺小叶的炎症，称小叶性肺炎。

:::definition{label="肺导气部"}
从叶支气管到终末细支气管为肺导气部。这一段仍无肺泡开口，只传导气体并调节进入肺小叶的气流量。
:::

:::definition{label="肺呼吸部"}
呼吸性细支气管以下各段均不同程度出现肺泡，为肺呼吸部，包括呼吸性细支气管、肺泡管、肺泡囊和肺泡。
:::

:::definition{label="肺小叶"}
每一细支气管连同它的各级分支和肺泡，组成一个肺小叶（pulmonary lobule）。肺小叶呈锥形，尖朝向肺门，底向肺表面，小叶之间有结缔组织间隔；肺表面可见肺小叶底部轮廓，直径 $1\sim 2.5\,\mathrm{cm}$。每叶肺有 $50\sim 80$ 个肺小叶，是肺的结构单位。
:::

:::definition{label="小叶性肺炎"}
临床上常见累及若干肺小叶的炎症，称小叶性肺炎。结构单位是细支气管所辖的那一锥，不是“一叶肺”。
:::

:::compare{title="导气部与呼吸部（肺内）"}
| 项目 | 肺导气部 | 肺呼吸部 |
|------|----------|----------|
| 起止 | 叶支气管（第 2 级）→ 终末细支气管（第 $14\sim 16$ 级） | 呼吸性细支气管（第 $17\sim 19$ 级）→ 肺泡（第 24 级） |
| 成员 | 叶支气管、段支气管、小支气管、细支气管、终末细支气管 | 呼吸性细支气管、肺泡管、肺泡囊、肺泡 |
| 肺泡 | 无 | 管壁或囊壁不同程度出现肺泡 |
| 职分 | 传导气体；环行平滑肌调节进入肺小叶的气流量 | 气体交换 |
| 支架演变 | 软骨为支架的管道逐渐变为肌性管道 | 管壁自身结构很少，以肺泡为主 |
| 易混点 | 终末细支气管仍无肺泡，不是换气部 | 呼吸性细支气管虽细，已有少量肺泡 |
:::

:::pitfall{label="终末细支气管不是气体交换部"}
终末细支气管是肺导气部的末站，管径约 $0.5\,\mathrm{mm}$，杯状细胞、腺体和软骨片全部消失，有完整环行平滑肌，但管壁上还没有肺泡。气体交换从下一级呼吸性细支气管才开始。把“终末”听成“已经换气”，肺泡管、肺泡囊和气–血屏障都会提前一级错位。
:::

## （一）肺导气部

### 1. 叶支气管至小支气管

叶支气管至小支气管管壁结构与主支气管相似，但随管径变小，管壁变薄，3 层结构分界渐不明显。上皮仍为假复层纤毛柱状上皮，但由厚逐渐变薄；杯状细胞、腺体和软骨片逐渐减少；固有层外平滑肌纤维相对增多，呈现为断续的环行平滑肌束（图 16-10）。

:::definition{label="叶支气管至小支气管"}
管壁结构与主支气管相似，但随管径变小，管壁变薄，3 层结构分界渐不明显。上皮仍为假复层纤毛柱状上皮，由厚逐渐变薄；杯状细胞、腺体和软骨片逐渐减少；固有层外平滑肌纤维相对增多，呈现为断续的环行平滑肌束。
:::

::figure{src="/images/histology/textbook/p0188_01.png" caption="图16-10 小支气管光镜图。1. 小支气管；2. 混合腺；3. 软骨片；4. 细支气管。" alt="小支气管横切：管壁仍见混合腺和软骨片，邻近有更细的细支气管，周围为肺泡"}

### 2. 细支气管和终末细支气管

细支气管（bronchiole）管径约 $1.0\,\mathrm{mm}$，上皮由假复层纤毛柱状上皮渐变为单层纤毛柱状上皮。杯状细胞、腺体和软骨片很少或消失，环行平滑肌更为明显，黏膜常形成皱襞（图 16-11）。终末细支气管（terminal bronchiole）管径约 $0.5\,\mathrm{mm}$，上皮为单层柱状上皮。杯状细胞、腺体和软骨片全部消失，有完整的环行平滑肌（图 16-12）。其上皮中纤毛细胞减少，主要细胞为无纤毛的分泌细胞（曾称为克拉拉细胞，Clara cell；现多称 Club 细胞），分泌细胞在小支气管即已出现，之后逐渐增多。此时，肺内导气部由软骨为支架的管道逐渐变为肌性管道，以适应肺功能的需要。细支气管和终末细支气管壁中的环行平滑肌可在自主神经的支配下收缩或舒张，调节进入肺小叶的气流量。

分泌细胞为柱状，游离面呈圆顶状凸向管腔，细胞质染色浅（图 16-13）；电镜下，其顶部细胞质内有发达的滑面内质网和较多的分泌颗粒（图 16-14）。滑面内质网有解毒功能，可对吸入的有毒物或药物进行生物转化和解毒；分泌颗粒以胞吐方式释放一种类表面活性物质，在上皮表面形成一层保护膜；分泌物中含有蛋白水解酶可分解管腔中的黏液，降低其黏稠度，有利于排出。

:::definition{label="细支气管"}
细支气管（bronchiole）管径约 $1.0\,\mathrm{mm}$，为支气管树第 $11\sim 13$ 级。上皮由假复层纤毛柱状上皮渐变为单层纤毛柱状上皮。杯状细胞、腺体和软骨片很少或消失，环行平滑肌更为明显，黏膜常形成皱襞。每一细支气管连同其各级分支和肺泡构成一个肺小叶。
:::

:::definition{label="终末细支气管"}
终末细支气管（terminal bronchiole）管径约 $0.5\,\mathrm{mm}$，为支气管树第 $14\sim 16$ 级，是肺导气部的末端。上皮为单层柱状上皮。杯状细胞、腺体和软骨片全部消失，有完整的环行平滑肌。上皮中纤毛细胞减少，主要细胞为无纤毛的分泌细胞。
:::

:::definition{label="分泌细胞（Clara / Club 细胞）"}
分泌细胞曾称为克拉拉细胞（Clara cell），现多称 Club 细胞。在小支气管即已出现，之后逐渐增多，至终末细支气管成为上皮的主要细胞。细胞呈柱状，游离面呈圆顶状凸向管腔，胞质染色浅；电镜下顶部有发达的滑面内质网和较多分泌颗粒。
:::

:::definition{label="分泌细胞的三项职分"}
滑面内质网可对吸入的有毒物或药物进行生物转化和解毒。分泌颗粒以胞吐方式释放一种类表面活性物质，在上皮表面形成一层保护膜。分泌物中含蛋白水解酶，可分解管腔中的黏液、降低黏稠度，有利于排出。
:::

:::insight{label="导气部越分越细，支架从软骨换成平滑肌"}
叶支气管到小支气管还能看见软骨片和腺体；细支气管开始把它们收掉，皱襞是环行平滑肌把黏膜推起来的；终末细支气管软骨、腺体、杯状细胞全部归零，留下完整环行平滑肌和 Club 细胞。肺内导气部由此从软骨管道改写成肌性管道，气流量由自主神经调节。把细支气管听成“缩小版气管”，软骨片会在不该出现的地方被找回来。
:::

| 项目 | 小支气管（第 $5\sim 10$ 级） | 细支气管（第 $11\sim 13$ 级） | 终末细支气管（第 $14\sim 16$ 级） |
|------|------------------------------|--------------------------------|------------------------------------|

| 杯状细胞、腺体、软骨 | 逐渐减少 | 很少或消失 | 全部消失 |

:::

## （二）肺呼吸部

### 1. 呼吸性细支气管

呼吸性细支气管（respiratory bronchiole）管壁上出现少量肺泡，故具有换气功能。管壁上皮为单层立方上皮，有分泌细胞和少许纤毛细胞，上皮下有弹性纤维和少量环行平滑肌细胞。在肺泡开口处，单层立方上皮移行为单层扁平上皮（见图 16-12、图 16-13）。

:::definition{label="呼吸性细支气管"}
呼吸性细支气管（respiratory bronchiole）为支气管树第 $17\sim 19$ 级。管壁上出现少量肺泡，故具有换气功能。上皮为单层立方上皮，有分泌细胞和少许纤毛细胞，上皮下有弹性纤维和少量环行平滑肌细胞。肺泡开口处，单层立方上皮移行为单层扁平上皮。
:::

:::compare{title="终末细支气管与呼吸性细支气管"}
| 项目 | 终末细支气管 | 呼吸性细支气管 |
|------|--------------|----------------|
| 分级 | 第 $14\sim 16$ 级 | 第 $17\sim 19$ 级 |
| 所属 | 肺导气部末端 | 肺呼吸部起点 |
| 肺泡 | 无 | 管壁出现少量肺泡，开始换气 |
| 上皮 | 单层柱状；纤毛细胞少，分泌细胞为主 | 单层立方；分泌细胞 + 少许纤毛细胞；肺泡开口处改单层扁平 |
| 平滑肌 | 完整环行平滑肌 | 上皮下少量环行平滑肌细胞 |
| 管径 | 约 $0.5\,\mathrm{mm}$ | 更细，并开口肺泡 |
:::

:::pitfall{label="不要把终末细支气管和呼吸性细支气管写成同一级“细支气管”"}
二者只差一级，名字都带“细支气管”，切片上却差在有没有肺泡开口。终末细支气管是完整肌性管道；呼吸性细支气管管壁已经被肺泡咬出缺口。把两者并称“细支气管”，肺小叶的导气末端和换气起点会搅在一起。
:::

### 2. 肺泡管

肺泡管（alveolar duct）管壁上有许多肺泡，故其自身的管壁结构很少，相邻肺泡开口之间有结节状膨大。膨大表面覆有单层立方或扁平上皮，深部有弹性纤维和环行平滑肌束（见图 16-12）。

:::definition{label="肺泡管"}
肺泡管（alveolar duct）为支气管树第 $20\sim 22$ 级。管壁上有许多肺泡，自身管壁结构很少。相邻肺泡开口之间有结节状膨大：表面覆单层立方或扁平上皮，深部有弹性纤维和环行平滑肌束。
:::

### 3. 肺泡囊

肺泡囊（alveolar sac）实为若干肺泡的共同开口处。相邻肺泡开口之间无平滑肌，故无结节状膨大（见图 16-12）。

:::definition{label="肺泡囊"}
肺泡囊（alveolar sac）为支气管树第 23 级，实为若干肺泡的共同开口处。相邻肺泡开口之间无平滑肌，故无结节状膨大。
:::

:::compare{title="肺泡管与肺泡囊"}
| 项目 | 肺泡管 | 肺泡囊 |
|------|--------|--------|
| 分级 | 第 $20\sim 22$ 级 | 第 23 级 |
| 肺泡开口 | 许多 | 若干肺泡的共同开口 |
| 自身管壁 | 很少 | 几乎只剩开口 |
| 结节状膨大 | 有（深部弹性纤维 + 环行平滑肌束） | 无（相邻开口之间无平滑肌） |
:::

:::pitfall{label="肺泡囊没有结节状膨大，不要按肺泡管的平滑肌小结来认"}
切片上相邻肺泡开口之间若有结节状膨大，那是肺泡管还剩的那点管壁（弹性纤维 + 环行平滑肌）。肺泡囊是共同开口，开口之间无平滑肌，也就没有小结。把所有“一串肺泡”都写成肺泡管，平滑肌账会多算一级。
:::

### 4. 肺泡

肺泡（pulmonary alveolus）为半球形小囊，直径约 $200\,\mu\mathrm{m}$，开口于肺泡囊、肺泡管或呼吸性细支气管，是肺进行气体交换的部位，构成肺的主要结构。成人肺约有 $3\sim 4$ 亿个肺泡，吸气时总表面积可达 $140\,\mathrm{m}^{2}$。肺泡壁很薄，由单层肺泡上皮组成。相邻肺泡之间的薄层结缔组织称肺泡隔（图 16-15～图 16-17）。

:::definition{label="肺泡"}
肺泡（pulmonary alveolus）为半球形小囊，直径约 $200\,\mu\mathrm{m}$，开口于肺泡囊、肺泡管或呼吸性细支气管，是肺进行气体交换的部位，构成肺的主要结构。成人肺约有 $3\sim 4$ 亿个肺泡，吸气时总表面积可达 $140\,\mathrm{m}^{2}$。
:::

:::definition{label="肺泡壁"}
肺泡壁很薄，由单层肺泡上皮组成。上皮由Ⅰ型肺泡细胞和Ⅱ型肺泡细胞组成。
:::

:::definition{label="肺泡隔"}
相邻肺泡之间的薄层结缔组织称肺泡隔。隔内有密集的连续毛细血管和丰富的弹性纤维，还有成纤维细胞、肺巨噬细胞、肥大细胞、毛细淋巴管和神经纤维。
:::

#### （1）肺泡上皮

肺泡上皮由Ⅰ型肺泡细胞和Ⅱ型肺泡细胞组成。

**1）Ⅰ型肺泡细胞** Ⅰ型肺泡细胞（type Ⅰ alveolar cell）除含核部略厚外，其余细胞质部分扁平菲薄，厚约 $0.2\,\mu\mathrm{m}$，覆盖肺泡约 $95\%$ 表面积，参与气–血屏障的形成，是进行气体交换的部位（图 16-15，图 16-16，图 16-18A）。电镜下，细胞质中可见较多小泡，内有细胞吞入的表面活性物质和微小粉尘，小泡能将它们转运到间质内清除。肺泡上皮细胞之间均有紧密连接和桥粒，以防止组织液向肺泡内渗入。Ⅰ型肺泡细胞无增殖能力，损伤后由Ⅱ型肺泡细胞增殖分化补充。

:::definition{label="Ⅰ型肺泡细胞"}
Ⅰ型肺泡细胞（type Ⅰ alveolar cell）除含核部略厚外，其余胞质扁平菲薄，厚约 $0.2\,\mu\mathrm{m}$，覆盖肺泡约 $95\%$ 表面积，参与气–血屏障形成，是进行气体交换的部位。无增殖能力，损伤后由Ⅱ型肺泡细胞增殖分化补充。
:::

:::definition{label="Ⅰ型肺泡细胞的小泡转运"}
电镜下Ⅰ型肺泡细胞胞质中可见较多小泡，内有细胞吞入的表面活性物质和微小粉尘，小泡能将它们转运到间质内清除。
:::

:::definition{label="肺泡上皮连接"}
肺泡上皮细胞之间均有紧密连接和桥粒，以防止组织液向肺泡内渗入。
:::

**2）Ⅱ型肺泡细胞** Ⅱ型肺泡细胞（type Ⅱ alveolar cell）呈立方形或圆形，散在凸起于Ⅰ型肺泡细胞之间，覆盖肺泡约 $5\%$ 表面积。细胞核圆形，细胞质着色浅（图 16-16）。电镜下，细胞质富含线粒体和溶酶体，有较发达的粗面内质网和高尔基复合体，核上方有较多高电子密度的分泌颗粒，因颗粒内含同心圆或平行排列的板层状结构，故称嗜锇性板层小体（osmiophilic lamellar body）（图 16-18B，图 16-19），其内容物为磷脂（主要是二棕榈酰卵磷脂）、蛋白质和糖的复合物。细胞以胞吐方式将内容物分泌到肺泡内面，铺展形成一薄层液体膜，称表面活性物质（surfactant）。表面活性物质有降低肺泡表面张力、稳定肺泡大小的重要作用。呼气时肺泡缩小，表面活性物质密度增加，降低了表面张力，可防止肺泡塌陷；吸气时肺泡扩大，表面活性物质密度减小，肺泡回缩力增大，可防止肺泡过度膨胀。某些早产儿Ⅱ型肺泡细胞尚未发育完善，不能产生表面活性物质，致使胎儿出生后肺泡不能扩张，呼吸困难，故称新生儿呼吸窘迫综合征。

:::definition{label="Ⅱ型肺泡细胞"}
Ⅱ型肺泡细胞（type Ⅱ alveolar cell）呈立方形或圆形，散在凸起于Ⅰ型肺泡细胞之间，覆盖肺泡约 $5\%$ 表面积。核圆形，胞质着色浅。电镜下富含线粒体和溶酶体，粗面内质网和高尔基复合体较发达，核上方有嗜锇性板层小体。损伤后可增殖分化补充Ⅰ型肺泡细胞。
:::

:::definition{label="嗜锇性板层小体"}
嗜锇性板层小体（osmiophilic lamellar body）是Ⅱ型肺泡细胞核上方高电子密度的分泌颗粒，内含同心圆或平行排列的板层状结构。内容物为磷脂（主要是二棕榈酰卵磷脂）、蛋白质和糖的复合物。
:::

:::definition{label="表面活性物质"}
表面活性物质（surfactant）由Ⅱ型肺泡细胞以胞吐方式分泌到肺泡内面，铺展成一薄层液体膜。作用是降低肺泡表面张力、稳定肺泡大小：呼气时密度增加、表面张力降低，防止塌陷；吸气时密度减小、回缩力增大，防止过度膨胀。
:::

:::definition{label="新生儿呼吸窘迫综合征"}
某些早产儿Ⅱ型肺泡细胞尚未发育完善，不能产生表面活性物质，致使出生后肺泡不能扩张、呼吸困难，称新生儿呼吸窘迫综合征。
:::

:::compare{title="Ⅰ型与Ⅱ型肺泡细胞"}
| 项目 | Ⅰ型肺泡细胞 | Ⅱ型肺泡细胞 |
|------|--------------|--------------|
| 形态 | 除核部略厚外，胞质扁平菲薄，厚约 $0.2\,\mu\mathrm{m}$ | 立方形或圆形，散在凸起 |
| 覆盖面积 | 约 $95\%$ | 约 $5\%$ |
| 超微结构 | 胞质内较多小泡（转运表面活性物质和粉尘） | 线粒体、溶酶体丰富；粗面内质网和高尔基复合体发达；嗜锇性板层小体 |
| 主要职分 | 参与气–血屏障，是气体交换部位 | 分泌表面活性物质；作为干细胞补充Ⅰ型细胞 |
| 增殖 | 无增殖能力 | 可增殖分化为Ⅰ型肺泡细胞 |
| 易混点 | 才是主要换气细胞 | 不是主要换气细胞，也不构成气–血屏障的上皮主体 |
:::

:::pitfall{label="Ⅱ型肺泡细胞不是主要换气细胞"}
覆盖肺泡约 $95\%$ 表面积、扁平到 $0.2\,\mu\mathrm{m}$ 的是Ⅰ型肺泡细胞，气体走的是这一层。Ⅱ型只覆盖约 $5\%$，职分是造表面活性物质，并在Ⅰ型损伤后增殖分化顶上。把Ⅱ型听成“分泌细胞所以更重要、也负责换气”，气–血屏障的上皮主体会写错。
:::

:::insight{label="表面活性物质用密度变化把肺泡大小锁在安全区间"}
呼气缩小时分子挤紧，表面张力被压下去，小肺泡不塌；吸气扩大时分子被拉开，回缩力上来，大肺泡不炸。早产儿没有这层膜，肺泡打不开，就是新生儿呼吸窘迫综合征。Club 细胞在细支气管表面铺的是类表面活性物质保护膜，不要和肺泡这层 surfactant 并成同一泡。
:::

::figure{src="/images/histology/textbook/p0190_03.png" caption="图16-19 Ⅱ型肺泡细胞超微结构模式图。↑嗜锇性板层小体形成过程。" alt="Ⅱ型肺泡细胞超微：核上方板层小体形成并胞吐，表面铺展为液体膜，基部示氨基酸和胆碱入胞"}

#### （2）肺泡隔

相邻肺泡之间的薄层结缔组织构成肺泡隔，其内有密集的连续毛细血管和丰富的弹性纤维（图 16-20），起回缩肺泡的作用（图 16-21）。老年人的弹性纤维退化，吸烟可加速退化进程。肺泡弹性降低后，回缩较差，呼气时肺内残留气体增加，久之，肺泡扩大形成肺气肿。此外，肺泡隔内还有成纤维细胞、肺巨噬细胞、肥大细胞、毛细淋巴管和神经纤维。

:::definition{label="肺泡隔弹性纤维"}
肺泡隔内有丰富的弹性纤维，起回缩肺泡的作用。老年人弹性纤维退化，吸烟可加速退化进程。弹性降低后回缩较差，呼气时肺内残留气体增加，久之肺泡扩大形成肺气肿。
:::

:::insight{label="回缩肺泡的是隔里的弹性纤维，不是Ⅱ型细胞把气挤出去"}
吸气末肺泡要自己弹回来，账写在肺泡隔的弹性纤维上。表面活性物质管的是表面张力，弹性纤维管的是组织回缩。老人和吸烟者纤维退化，残留气体增加，走向肺气肿。把回缩听成“平滑肌收缩”，肺泡隔里并没有一整圈能排空肺泡的肌层。
:::

::figure{src="/images/histology/textbook/p0191_03.png" caption="图16-20 肺弹性纤维光镜图（醛复红染色）。↑弹性纤维染成蓝黑色。" alt="醛复红染色肺切片：肺泡隔内弹性纤维呈蓝黑色，箭头所示沿隔走行"}

#### （3）肺泡孔

肺泡孔（alveolar pore）为相邻肺泡之间气体流通的小孔（见图 16-15），直径 $10\sim 15\,\mu\mathrm{m}$，一个肺泡壁上可有 1 个至数个，可均衡肺泡间气体含量。当某个终末细支气管或呼吸性细支气管阻塞时，肺泡孔起侧支通气作用。肺部感染时，肺泡孔也是炎症迅速蔓延的渠道。

:::definition{label="肺泡孔"}
肺泡孔（alveolar pore）是相邻肺泡之间气体流通的小孔，直径 $10\sim 15\,\mu\mathrm{m}$，一个肺泡壁上可有 1 个至数个，可均衡肺泡间气体含量。终末细支气管或呼吸性细支气管阻塞时起侧支通气作用；肺部感染时也是炎症迅速蔓延的渠道。
:::

#### （4）气–血屏障

气–血屏障（blood-air barrier）是肺泡腔内氧气与肺泡隔毛细血管中的二氧化碳进行气体交换所通过的结构。包括肺泡表面液体层、Ⅰ型肺泡细胞与基膜、薄层结缔组织、毛细血管基膜与连续内皮。有的部位两层基膜间无结缔组织，两层基膜融合（见图 16-21）。此结构总厚度为 $0.2\sim 0.5\,\mu\mathrm{m}$，有利于气体迅速交换。临床上急、慢性炎症引起的炎性细胞浸润、渗出或增生均会影响正常气体交换功能。

:::definition{label="气–血屏障"}
气–血屏障（blood-air barrier）是肺泡腔内氧气与肺泡隔毛细血管中的二氧化碳进行气体交换所通过的结构。组成：肺泡表面液体层、Ⅰ型肺泡细胞与基膜、薄层结缔组织、毛细血管基膜与连续内皮。有的部位两层基膜间无结缔组织，两层基膜融合。总厚度 $0.2\sim 0.5\,\mu\mathrm{m}$。
:::

:::note{label="气–血屏障的层次"}
| 顺序（肺泡腔 → 血液） | 结构 |
|------------------------|------|
| 1 | 肺泡表面液体层 |
| 2 | Ⅰ型肺泡细胞与其基膜 |
| 3 | 薄层结缔组织（有的部位缺如，两层基膜融合） |
| 4 | 毛细血管基膜与连续内皮 |
| 总厚度 | $0.2\sim 0.5\,\mu\mathrm{m}$ |
:::

:::pitfall{label="气–血屏障不是整层肺泡隔"}
肺泡隔里还有弹性纤维、成纤维细胞、肺巨噬细胞、肥大细胞、毛细淋巴管和神经纤维。气体并不穿过这整本隔，只走最薄的那条路径：液体层 → Ⅰ型细胞及基膜 →（可缺如的薄层结缔组织）→ 连续毛细血管内皮及基膜，总厚度仅 $0.2\sim 0.5\,\mu\mathrm{m}$。把气–血屏障写成“整个肺泡隔”，隔内的尘细胞和弹性纤维会被误当成换气结构。
:::

:::insight{label="炎症渗出只要把这 0.2～0.5 µm 加厚，换气就先垮"}
屏障能工作，是因为它薄。炎性细胞浸润、渗出或增生都会把路径加厚，氧气来不及过。临床气体交换障碍，组织学落点往往就在这几层被抬厚，而不必先毁掉整棵支气管树。
:::

## （三）肺间质和肺巨噬细胞

肺间质包括结缔组织、血管、淋巴管和神经，内含较多的弹性纤维和巨噬细胞。主要分布在支气管树的周围，随着支气管树分支增加，间质会逐渐减少。

肺巨噬细胞（pulmonary macrophage）来源于血液中的单核细胞，广泛分布于肺间质，肺泡隔中最多，有的游走进入肺泡腔。肺巨噬细胞具有活跃的吞噬功能，能清除进入肺泡和肺间质的尘粒、细菌等异物，发挥重要的免疫防御作用。吞噬了较多尘粒的肺巨噬细胞称为尘细胞（dust cell）。吞噬了异物的肺巨噬细胞，可沉积在肺间质内，也可从肺泡腔经呼吸道随黏液咳出，还可进入肺淋巴管，再迁移至肺门淋巴结（见图 16-15、图 16-16，图 16-22）。

:::definition{label="肺间质"}
肺间质包括结缔组织、血管、淋巴管和神经，内含较多的弹性纤维和巨噬细胞。主要分布在支气管树周围，随着支气管树分支增加，间质逐渐减少。
:::

:::definition{label="肺巨噬细胞"}
肺巨噬细胞（pulmonary macrophage）来源于血液中的单核细胞，广泛分布于肺间质，肺泡隔中最多，有的游走进入肺泡腔。吞噬功能活跃，能清除进入肺泡和肺间质的尘粒、细菌等异物。
:::

:::definition{label="尘细胞"}
尘细胞（dust cell）是吞噬了较多尘粒的肺巨噬细胞。吞噬异物后可沉积在肺间质内，或从肺泡腔经呼吸道随黏液咳出，或进入肺淋巴管再迁移至肺门淋巴结。
:::

:::insight{label="尘细胞是巨噬细胞的工作痕迹，不是肺泡上皮的第四种细胞"}
Ⅰ型、Ⅱ型才是肺泡上皮。隔里和腔里那些吞了碳末的是单核细胞来源的肺巨噬细胞。三条出路——沉在间质、咳出去、迁到肺门淋巴结——解释了吸烟者肺为什么发黑、痰为什么带尘、肺门淋巴结为什么也有碳末。
:::

## （四）肺的血液供应

肺的血液供应来自肺动脉和支气管动脉。肺动脉是肺的功能血管，管径较粗，为弹性动脉。肺动脉从右心室发出，至肺门入肺，其分支与各级支气管伴行直至肺泡隔内形成毛细血管网，毛细血管内血液与肺泡进行气体交换后，汇入小静脉，最终汇合成肺静脉出肺门回到左心房。支气管动脉是肺的营养血管，管径细，为肌性动脉。支气管动脉发自胸主动脉或肋间动脉，与支气管伴行入肺，沿途在导气部各段管壁内分支形成毛细血管网，营养管壁组织。

:::definition{label="肺动脉"}
肺动脉是肺的功能血管，管径较粗，为弹性动脉。从右心室发出，至肺门入肺，分支与各级支气管伴行直至肺泡隔内形成毛细血管网；气体交换后汇入小静脉，最终汇合成肺静脉出肺门回到左心房。
:::

:::definition{label="支气管动脉"}
支气管动脉是肺的营养血管，管径细，为肌性动脉。发自胸主动脉或肋间动脉，与支气管伴行入肺，沿途在导气部各段管壁内分支形成毛细血管网，营养管壁组织。
:::

:::compare{title="肺动脉与支气管动脉"}
| 项目 | 肺动脉 | 支气管动脉 |
|------|--------|------------|
| 职分 | 功能血管（来进行气体交换的血） | 营养血管（养管壁） |
| 管径 / 类型 | 较粗，弹性动脉 | 细，肌性动脉 |
| 起点 | 右心室 | 胸主动脉或肋间动脉 |
| 走行 | 与各级支气管伴行至肺泡隔毛细血管网 | 与支气管伴行，在导气部管壁内成网 |
| 终点 | 气体交换后经肺静脉回左心房 | 营养导气部各段管壁组织 |
:::

:::pitfall{label="支气管动脉养的是导气部管壁，不要写成“也在肺泡换气”"}
肺泡隔里与Ⅰ型细胞面对面的毛细血管网来自肺动脉。支气管动脉沿导气部管壁成网，职分是营养。把两套动脉写成“都是肺的血供，都会换气”，功能血管和营养血管会并成一句。
:::

:::keypoint{label="肺先立 24 级和肺小叶，再把导气部肌性化、呼吸部写成气–血屏障"}
- 实质 = 支气管树 + 肺泡；主支气管至肺泡约 24 级。肺小叶 = 一细支气管及其分支和肺泡，每叶 $50\sim 80$ 个，底径 $1\sim 2.5\,\mathrm{cm}$。
- 肺导气部：叶支气管 → 终末细支气管。杯状细胞、腺体、软骨渐少至消失，平滑肌渐多至完整环行。
- 细支气管约 $1.0\,\mathrm{mm}$，终末细支气管约 $0.5\,\mathrm{mm}$；主要细胞为 Clara / Club 分泌细胞（解毒、类表面活性物质、蛋白水解酶）。
- 肺呼吸部：呼吸性细支气管（少量肺泡）→ 肺泡管（结节状膨大）→ 肺泡囊（无膨大）→ 肺泡（直径约 $200\,\mu\mathrm{m}$，$3\sim 4$ 亿，吸气面积 $140\,\mathrm{m}^{2}$）。
- Ⅰ型覆盖约 $95\%$、厚约 $0.2\,\mu\mathrm{m}$，是换气细胞；Ⅱ型覆盖约 $5\%$，板层小体分泌表面活性物质，并可补充Ⅰ型。
- 气–血屏障 = 液体层 + Ⅰ型细胞与基膜 + 薄层结缔组织 + 连续内皮与基膜，厚 $0.2\sim 0.5\,\mu\mathrm{m}$，不是整层肺泡隔。
- 肺泡孔 $10\sim 15\,\mu\mathrm{m}$ 可侧支通气，也可让炎症蔓延。尘细胞是吞尘的肺巨噬细胞。
- 肺动脉是弹性功能血管，支气管动脉是肌性营养血管。
:::

:::memory{label="本节必背要点"}
- [ ] 肺表面被覆浆膜（胸膜脏层）；肺组织分实质和间质，实质即肺内支气管的各级分支及其终末的大量肺泡。
- [ ] 从主支气管至肺泡大约有 24 级分支。
- [ ] 主支气管反复分支呈树枝状，称支气管树。
- [ ] 从叶支气管到终末细支气管为肺导气部；呼吸性细支气管以下各段均不同程度出现肺泡，为肺呼吸部。
- [ ] 每一细支气管连同它的各级分支和肺泡组成一个肺小叶（pulmonary lobule）。
- [ ] 肺小叶呈锥形，尖朝向肺门，底向肺表面，小叶之间有结缔组织间隔；肺表面可见底部轮廓，直径 $1\sim 2.5\,\mathrm{cm}$。
- [ ] 每叶肺有 $50\sim 80$ 个肺小叶，是肺的结构单位；累及若干肺小叶的炎症称小叶性肺炎。

- [ ] 细支气管（bronchiole）管径约 $1.0\,\mathrm{mm}$，上皮由假复层纤毛柱状渐变为单层纤毛柱状；杯状细胞、腺体和软骨片很少或消失，环行平滑肌更为明显，黏膜常形成皱襞。
- [ ] 终末细支气管（terminal bronchiole）管径约 $0.5\,\mathrm{mm}$，上皮为单层柱状；杯状细胞、腺体和软骨片全部消失，有完整环行平滑肌。
- [ ] 终末细支气管上皮中纤毛细胞减少，主要细胞为无纤毛的分泌细胞（曾称克拉拉细胞 Clara cell，现多称 Club 细胞）；分泌细胞在小支气管即已出现，之后逐渐增多。
- [ ] 肺内导气部由软骨为支架的管道逐渐变为肌性管道；细支气管和终末细支气管的环行平滑肌在自主神经支配下舒缩，调节进入肺小叶的气流量。
- [ ] 分泌细胞呈柱状，游离面圆顶状凸向管腔，胞质染色浅；电镜下顶部有发达滑面内质网和较多分泌颗粒。
- [ ] 分泌细胞滑面内质网可对吸入的有毒物或药物进行生物转化和解毒。
- [ ] 分泌颗粒以胞吐释放类表面活性物质，在上皮表面形成保护膜；分泌物含蛋白水解酶，分解管腔黏液、降低黏稠度以利排出。
- [ ] 呼吸性细支气管（respiratory bronchiole）管壁出现少量肺泡，故具有换气功能；上皮为单层立方，有分泌细胞和少许纤毛细胞，上皮下有弹性纤维和少量环行平滑肌；肺泡开口处移行为单层扁平上皮。
- [ ] 肺泡管（alveolar duct）管壁有许多肺泡，自身管壁很少；相邻肺泡开口之间有结节状膨大，表面覆单层立方或扁平上皮，深部有弹性纤维和环行平滑肌束。
- [ ] 肺泡囊（alveolar sac）为若干肺泡的共同开口处；相邻开口之间无平滑肌，故无结节状膨大。
- [ ] 肺泡（pulmonary alveolus）为半球形小囊，直径约 $200\,\mu\mathrm{m}$，开口于肺泡囊、肺泡管或呼吸性细支气管，是气体交换部位。
- [ ] 成人肺约有 $3\sim 4$ 亿个肺泡，吸气时总表面积可达 $140\,\mathrm{m}^{2}$。
- [ ] 肺泡壁由单层肺泡上皮组成；相邻肺泡之间的薄层结缔组织称肺泡隔。
- [ ] Ⅰ型肺泡细胞除核部略厚外胞质扁平菲薄，厚约 $0.2\,\mu\mathrm{m}$，覆盖肺泡约 $95\%$ 表面积，参与气–血屏障，是气体交换部位。
- [ ] Ⅰ型肺泡细胞胞质有较多小泡，转运吞入的表面活性物质和微小粉尘到间质清除；上皮细胞之间有紧密连接和桥粒，防止组织液渗入肺泡。
- [ ] Ⅰ型肺泡细胞无增殖能力，损伤后由Ⅱ型肺泡细胞增殖分化补充。
- [ ] Ⅱ型肺泡细胞呈立方形或圆形，散在凸起于Ⅰ型细胞之间，覆盖约 $5\%$ 表面积；核圆，胞质着色浅。
- [ ] Ⅱ型肺泡细胞核上方有嗜锇性板层小体（osmiophilic lamellar body），内容物为磷脂（主要是二棕榈酰卵磷脂）、蛋白质和糖的复合物。
- [ ] Ⅱ型细胞以胞吐将内容物铺展为表面活性物质（surfactant），降低肺泡表面张力、稳定肺泡大小。
- [ ] 呼气时表面活性物质密度增加、表面张力降低，防止塌陷；吸气时密度减小、回缩力增大，防止过度膨胀。
- [ ] 早产儿Ⅱ型细胞发育不完善、不能产生表面活性物质，出生后肺泡不能扩张，称新生儿呼吸窘迫综合征。
- [ ] 肺泡隔内有密集的连续毛细血管和丰富的弹性纤维，起回缩肺泡作用；老年人弹性纤维退化，吸烟加速退化，久之肺泡扩大形成肺气肿。
- [ ] 肺泡隔内还有成纤维细胞、肺巨噬细胞、肥大细胞、毛细淋巴管和神经纤维。
- [ ] 肺泡孔（alveolar pore）直径 $10\sim 15\,\mu\mathrm{m}$，一个肺泡壁上可有 1 个至数个，均衡气体含量；阻塞时侧支通气，感染时也是炎症蔓延渠道。
- [ ] 气–血屏障（blood-air barrier）包括肺泡表面液体层、Ⅰ型肺泡细胞与基膜、薄层结缔组织、毛细血管基膜与连续内皮；有的部位两层基膜融合；总厚度 $0.2\sim 0.5\,\mu\mathrm{m}$。
- [ ] 急慢性炎症的浸润、渗出或增生均会影响正常气体交换。
- [ ] 肺间质包括结缔组织、血管、淋巴管和神经，含较多弹性纤维和巨噬细胞，主要分布在支气管树周围，随分支增加而减少。
- [ ] 肺巨噬细胞来源于单核细胞，肺泡隔中最多，可游走进入肺泡腔，吞噬尘粒和细菌。
- [ ] 吞噬较多尘粒的肺巨噬细胞称尘细胞（dust cell）；可沉积于间质、随黏液咳出，或经淋巴管迁至肺门淋巴结。
- [ ] 肺动脉是功能血管，较粗，为弹性动脉，从右心室经肺门与支气管伴行至肺泡隔毛细血管网，交换后经肺静脉回左心房。
- [ ] 支气管动脉是营养血管，细，为肌性动脉，发自胸主动脉或肋间动脉，在导气部管壁内成网营养管壁。
:::

## 本章小结

呼吸系统包括鼻、咽、喉、气管、主支气管和肺。

气管与主支气管壁由内向外分为黏膜、黏膜下层和外膜 3 层。黏膜由上皮和固有层组成，上皮为假复层纤毛柱状上皮，由纤毛细胞、杯状细胞、刷细胞、基细胞和小颗粒细胞组成。黏膜下层内含较多的气管腺，外膜主要含 $16\sim 20$ 个 C 字形透明软骨环。

肺实质由肺内支气管树及其终末的大量肺泡组成。从叶支气管到终末细支气管为肺导气部，随着管径变小，管壁变薄，上皮由假复层纤毛柱状上皮变为单层柱状上皮，杯状细胞、腺体和软骨片逐渐减少乃至消失；固有层外平滑肌束逐渐增多直至为环行。肺呼吸部包括呼吸性细支气管、肺泡管、肺泡囊和肺泡。呼吸性细支气管壁开始出现少量肺泡；肺泡管有大量肺泡开口，相邻肺泡之间有结节状膨大；肺泡囊为许多肺泡的共同开口处；肺泡壁由Ⅰ型肺泡细胞和Ⅱ型肺泡细胞组成。Ⅰ型肺泡细胞参与气–血屏障形成，是气体交换的部位。气–血屏障包括肺泡表面液体层、Ⅰ型肺泡细胞与基膜、薄层结缔组织、毛细血管基膜与连续内皮。有的部位两层基膜融合为一层。Ⅱ型肺泡细胞的细胞质中含嗜锇性板层小体，内为表面活性物质，能降低肺泡表面张力。肺泡隔富有毛细血管、弹性纤维和肺巨噬细胞。Ⅰ型肺泡细胞无增殖能力，损伤后由Ⅱ型肺泡细胞增殖分化补充。

:::definition{label="本章结构通式"}
呼吸系统 = 导气部（鼻腔 → 终末细支气管）+ 呼吸部（呼吸性细支气管 → 肺泡）。气管三层：假复层纤毛柱状上皮 + 气管腺 + $16\sim 20$ 个 C 形透明软骨环。肺内越分越细：软骨、腺体、杯状细胞减少，平滑肌增多；出现肺泡才换气。Ⅰ型铺 $95\%$ 做气–血屏障，Ⅱ型用板层小体造表面活性物质并补充Ⅰ型。
:::

## 插入框：科赫与肺结核

肺结核是一种由结核分枝杆菌引发的呼吸系统传染病，其病变主要发生在肺组织、气管、支气管和胸膜。作为一种具有高度传染性的慢性消耗性疾病，难以治愈，患者往往表现为剧烈咳嗽、体重下降、脸色苍白，故肺结核曾被称为“白色瘟疫”。

1882 年 3 月 24 日，德国科学家罗伯特·科赫发现结核分枝杆菌，并将其分为人型、牛型、鸟型和鼠型 4 种，其中人型结核分枝杆菌是人类结核病的主要病原体。肺结核主要通过呼吸道传播，当患者咳嗽、打喷嚏、大声说话或吐痰时，会排出含有结核分枝杆菌的飞沫，健康人吸入后可能感染。结核分枝杆菌的发现极大地改变了人类抗击结核病的历程。世界卫生组织将每年的 3 月 24 日定为“世界防治结核病日”。1890 年，科赫进一步提出使用结核菌素治疗结核病，对疾病的控制作出了重要贡献，科赫于 1905 年获得诺贝尔生理学或医学奖。

时至今日，结核病仍是全球性公共卫生问题，严重威胁人们的健康。世界卫生组织发起倡议，呼吁全球共同努力，实现 2030 年终结结核病流行的目标。

:::insight{label="插入框把飞沫传播接回导气部的黏液-纤毛账"}
结核分枝杆菌走呼吸道飞沫，健康人吸入即可能感染。导气部的黏液、纤毛、sIgA 和肺巨噬细胞本来就是这条传播路径上的组织学防线；肺泡孔又让炎症能在肺泡间迅速蔓延。把肺结核只听成“一则医学史”，支气管树和尘细胞那两本防御账会和病原对不上。

:::pitfall{label="人型才是人类结核病的主要病原体，不要把牛型、鸟型、鼠型并成同等致病"}
科赫分出 4 型，教材明确：人型结核分枝杆菌是人类结核病的主要病原体。分型是微生物学的身份证件，不是四种对人都同等重要的病原。
:::

:::memory{label="插入框必背"}
- [ ] 肺结核由结核分枝杆菌引发，病变主要在肺组织、气管、支气管和胸膜。
- [ ] 高度传染的慢性消耗性疾病，曾被称为“白色瘟疫”（剧烈咳嗽、体重下降、脸色苍白）。
- [ ] 1882 年 3 月 24 日罗伯特·科赫发现结核分枝杆菌，分为人型、牛型、鸟型和鼠型 4 种。
- [ ] 人型结核分枝杆菌是人类结核病的主要病原体。
- [ ] 主要通过呼吸道传播：咳嗽、打喷嚏、大声说话或吐痰排出含菌飞沫，健康人吸入后可能感染。
- [ ] 世界卫生组织将每年 3 月 24 日定为“世界防治结核病日”。
- [ ] 1890 年科赫提出使用结核菌素治疗结核病；1905 年获诺贝尔生理学或医学奖。
- [ ] 结核病仍是全球性公共卫生问题；世界卫生组织倡议 2030 年终结结核病流行。
:::
