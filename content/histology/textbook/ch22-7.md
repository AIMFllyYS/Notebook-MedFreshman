# 七、四肢的发生

第 $4$ 周末，左右外侧体壁先后鼓出上、下肢芽。肢芽先是深部中胚层加表面外胚层的小突起，随后被近端、远端两个缩窄环分成 $3$ 段。骨来自中轴间充质的软骨内成骨，肌来自体节间充质，神经由脊神经长入。手板、足板顶端凋亡出 $4$ 条凹沟和 $5$ 条指（趾）线，第 $8$ 周末手指足趾才分开。本节把肢芽到指趾摊开；主要畸形下一节再写。

:::definition{label="肢芽"}
肢芽（limb bud）是第 $4$ 周末胚体左右外侧体壁先后出现的上下两对小突起，即上肢芽与下肢芽。最初由深部增殖的中胚层组织和表面的外胚层组成。
:::

第 $4$ 周末，胚体左右外侧体壁先后出现上下两对小突起，即上肢芽与下肢芽。最初，肢芽（limb bud）由深部增殖的中胚层组织和表面的外胚层组成。肢芽逐渐增长变粗，先后出现近端和远端两个缩窄环，将每一肢芽分为 $3$ 段。上肢芽的 $3$ 段分别发育为上臂、前臂和手，下肢芽则发育为大腿、小腿和足。肢体中轴的间充质先形成软骨，继而以软骨内成骨的方式形成骨；来自体节的间充质细胞迁移到肢芽，分化为骨骼肌；脊神经长入四肢，支配肢体的感觉和肌肉运动。手和足起初为扁平的桨板状，分别称手板（hand plate）和足板（foot plate）。而后其顶端部分细胞凋亡，形成 $4$ 条凹沟，凹沟间则出现 $5$ 条指（趾）线（digital ray）；随着指（趾）线间的细胞不断凋亡，至第 $8$ 周末，手指和足趾形成（图 22-10）。

:::definition{label="上肢芽与下肢芽"}
上、下肢芽是先后出现的两对小突起，位置在胚体左右外侧体壁。上肢芽的 $3$ 段发育为上臂、前臂和手；下肢芽发育为大腿、小腿和足。
:::

:::definition{label="缩窄环"}
肢芽增长变粗后，先后出现近端和远端两个缩窄环，把每一肢芽分成 $3$ 段。不是一开始就长成三段的关节，而是先出芽、再缩窄。
:::

:::definition{label="手板与足板"}
手和足起初为扁平的桨板状，分别称手板（hand plate）和足板（foot plate）。此时还没有分开的手指、足趾。
:::

:::definition{label="指（趾）线"}
顶端部分细胞凋亡形成 $4$ 条凹沟后，凹沟之间出现 $5$ 条指（趾）线（digital ray）。随后指（趾）线间的细胞不断凋亡，至第 $8$ 周末手指和足趾形成。
:::

:::concept{term="先问肢芽被两个缩窄环分成哪3段，再问指趾是凋亡分开的还是5个芽长出来的"}
看见四肢发生，先不要写成“侧面直接长出手和脚”。先问第 $4$ 周末有没有上、下肢芽，再问近端、远端两个缩窄环把芽分成了哪 $3$ 段——上肢是上臂、前臂、手，下肢是大腿、小腿、足。手板、足板出现以后，再问顶端有没有凋亡出 $4$ 条凹沟、$5$ 条指（趾）线；线间细胞继续凋亡，第 $8$ 周末指趾才分开。把桨板听成已经分开的五指，或把骨、肌、神经写成全是肢芽中胚层就地分化，三本账会对错户头。
:::

:::compare{title="上肢芽3段与下肢芽3段"}
| 项目 | 上肢芽 | 下肢芽 |
|------|--------|--------|
| 出现 | 第 $4$ 周末，外侧体壁，与下肢芽先后出现 | 同时间窗，稍后于上肢芽 |
| 组成 | 深部增殖的中胚层 + 表面外胚层 | 相同 |
| 缩窄环 | 近端、远端各一，分成 $3$ 段 | 相同 |
| $3$ 段去向 | 上臂、前臂、手 | 大腿、小腿、足 |
| 末端桨板 | 手板 | 足板 |
| 指（趾） | $4$ 条凹沟 + $5$ 条指线 → 第 $8$ 周末手指 | $4$ 条凹沟 + $5$ 条趾线 → 第 $8$ 周末足趾 |
:::

:::compare{title="四肢的骨、骨骼肌与神经来源"}
| 项目 | 骨 | 骨骼肌 | 神经 |
|------|----|--------|------|
| 细胞来源 | 肢体中轴的间充质 | 来自体节的间充质细胞迁移到肢芽 | 脊神经长入四肢 |
| 过程 | 先形成软骨，再以软骨内成骨的方式成骨 | 在肢芽内分化为骨骼肌 | 支配肢体的感觉和肌肉运动 |
| 不是 | 体节直接变成肢骨 | 肢芽中轴间充质就地成肌 | 肢芽自己长出神经元 |
:::

:::cause-effect{title="桨板先出沟，线间再凋亡，指趾才分开"}
- 因：手、足起初是扁平桨板（手板、足板）
- 果：尚无分开的手指、足趾
- 因：顶端部分细胞凋亡，形成 $4$ 条凹沟
- 果：凹沟之间出现 $5$ 条指（趾）线
- 因：指（趾）线间的细胞不断凋亡
- 果：至第 $8$ 周末，手指和足趾形成
- 制约：并指（趾）是线间凋亡不足的分化障碍，放到第八节；不是“少长了一根芽”
:::

:::pitfall{label="手指足趾是桨板上凋亡分开的，不是一开始就伸出5个独立小芽"}
教材的顺序是：肢芽 → 缩窄成 $3$ 段 → 末端成手板、足板 → 顶端凋亡成 $4$ 沟 $5$ 线 → 线间再凋亡。把五指写成“肢芽远端同时长出五个小芽”，并指、多指的机制会对错户头：并指是线间细胞没凋亡干净，多指是分化障碍，都不是“少长或多长了一个肢芽”。
:::

:::pitfall{label="中轴间充质成骨，体节间充质成肌，脊神经是长入的"}
三件事来源不同。中轴间充质：软骨 → 软骨内成骨。体节间充质细胞迁移到肢芽才分化为骨骼肌。脊神经从中轴长入四肢，支配感觉和运动。写成“肢芽中胚层既变骨又变肌又变神经”，体节和神经管的账会被吃掉。
:::

:::insight{label="第4周末出芽，第8周末分指，刚好覆盖胚期的后半段"}
肢芽在第 $4$ 周末出现，手指足趾在第 $8$ 周末形成。这和颜面“至第 $8$ 周末初具人貌”落在同一条时间尺上：胚期结束时，肢和脸都已经能认。把四肢发生听成胎期才开始的生长，短肢、并指那些畸形会整段丢掉。
:::

:::timeline{period="第4周末至第8周末：从肢芽到指趾"}
- **第4周末** 左右外侧体壁先后出现上肢芽与下肢芽（深部中胚层 + 表面外胚层）
- **增长变粗** 近端、远端两个缩窄环将每一肢芽分为 3 段
- **上肢 3 段** 上臂、前臂、手
- **下肢 3 段** 大腿、小腿、足
- **中轴** 间充质先成软骨，再软骨内成骨
- **肌肉** 体节间充质细胞迁入肢芽，分化为骨骼肌
- **神经** 脊神经长入，支配感觉和肌肉运动
- **桨板** 手、足成扁平手板、足板
- **顶端凋亡** 形成 4 条凹沟，沟间 5 条指（趾）线
- **线间凋亡** 至第 8 周末，手指和足趾形成
:::

:::example{label="上臂—前臂—手 对应 大腿—小腿—足"}
两个缩窄环把上、下肢芽都分成近、中、远 $3$ 段。上肢近段是上臂、中段是前臂、远段是手；下肢近段是大腿、中段是小腿、远段是足。不要把“$3$ 段”听成肩、肘、腕三组关节的名称，教材写的是三段肢体本身。
:::

:::tip{label="肢芽口诀"}
先出芽，再缩两环成三段；骨软骨内成，肌从体节来，神经长进去。桨板四沟五条线，线间凋亡才分指。
:::

:::keypoint{label="肢芽两环三段，骨肌神经分户，凋亡分出指趾"}
- 第 $4$ 周末：上、下肢芽 = 深部增殖中胚层 + 表面外胚层。
- 近端、远端两个缩窄环 → 上臂 / 前臂 / 手；大腿 / 小腿 / 足。
- 中轴间充质 → 软骨 → 软骨内成骨；体节间充质 → 骨骼肌；脊神经长入。
- 手板、足板：顶端凋亡成 $4$ 条凹沟 + $5$ 条指（趾）线；线间继续凋亡，第 $8$ 周末手指足趾形成。
:::
