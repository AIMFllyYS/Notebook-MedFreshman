# 四、阴道

阴道是排出月经和娩出胎儿的肌性管道，不是产生卵子或形成内膜周期的器官。管壁由黏膜、肌层和外膜组成。黏膜向阴道腔内突起形成许多横行皱襞，由上皮和固有层构成。

:::definition{label="阴道"}
阴道壁由黏膜、肌层和外膜组成。黏膜形成许多横行皱襞。它是通道，不形成月经的功能层，也不含卵泡。
:::

:::concept{term="先问上皮是不是未角化复层扁平，再问有没有糖原"}
看见阴道，先认上皮：未角化的复层扁平，不是宫颈管的单层柱状，也不是皮肤那种角化表皮。再问雌激素在不在：有雌激素，上皮细胞内聚集大量糖原；浅层细胞脱落，糖原被阴道乳杆菌转变成乳酸，才能把 pH 压低、抑制细菌。把阴道听成“又一段子宫内膜”，糖原–乳酸这本防御账会做成螺旋动脉剥脱。
:::

上皮为未角化的复层扁平上皮。在雌激素作用下，上皮细胞内聚集大量糖原。浅层细胞脱落后，糖原在阴道乳杆菌作用下转变为乳酸，能抑制细菌生长并防止病菌侵入子宫。老年或其他原因导致雌激素水平下降时，阴道上皮细胞内的糖原减少，阴道液 pH 上升，细菌容易生长繁殖，发生阴道感染。阴道上皮的脱落和更新也与卵巢活动周期关系密切，根据阴道脱落上皮细胞类型不同可推知卵巢的内分泌功能状态。

:::definition{label="阴道上皮"}
上皮为未角化的复层扁平上皮。表层不形成角化层，与皮肤表皮不是一本账。宫颈阴道部黏膜上皮同样是复层扁平，但宫颈管腔面是单层柱状。
:::

:::definition{label="糖原与乳酸"}
雌激素使阴道上皮细胞内聚集大量糖原。浅层细胞脱落后，糖原被阴道乳杆菌转变为乳酸，抑制细菌生长并防止病菌侵入子宫。
:::

:::definition{label="阴道乳杆菌"}
阴道乳杆菌利用脱落上皮中的糖原产生乳酸。没有足够糖原（雌激素下降），这层生物防线就会失守。
:::

:::definition{label="阴道脱落细胞"}
阴道上皮的脱落和更新与卵巢活动周期密切相关。根据脱落上皮细胞类型不同，可推知卵巢的内分泌功能状态。
:::

固有层由含有丰富弹性纤维和血管的致密结缔组织构成。肌层薄，由内环外纵行的平滑肌构成，两层分界不清。阴道外口有环行的骨骼肌构成的括约肌。外膜为富含弹性纤维的致密结缔组织。

:::definition{label="阴道固有层"}
固有层为含丰富弹性纤维和血管的致密结缔组织。没有子宫腺，也没有螺旋动脉那种内膜周期血管。
:::

:::definition{label="阴道肌层"}
肌层薄，内环外纵两层平滑肌，分界不清。与输卵管“峡部肌层最厚”、子宫肌层约 $1\,\mathrm{cm}$ 不是一个量级。
:::

:::definition{label="阴道括约肌"}
阴道外口有环行骨骼肌构成的括约肌。管壁肌层是平滑肌，外口括约肌才是骨骼肌，两本账不要并成一层。
:::

:::definition{label="阴道外膜"}
外膜为富含弹性纤维的致密结缔组织，是纤维膜，不是浆膜。
:::

:::compare{title="阴道、宫颈管与宫颈阴道部的上皮"}
| 项目 | 阴道 | 宫颈管腔面 | 宫颈阴道部 |
|------|------|------------|------------|
| 上皮 | 未角化复层扁平 | 单层柱状（分泌细胞为主） | 复层扁平 |
| 皱襞 | 横行皱襞 | 突向管腔的皱襞，有宫颈腺 | 与阴道相续 |
| 周期剥脱 | 上皮细胞脱落更新，但不形成月经 | 黏膜不周期性剥落 | 不形成月经 |
| 激素相关 | 雌激素 → 糖原 → 乳杆菌产乳酸 | 排卵时黏液稀薄，黄体期黏稠 | 同复层扁平上皮 |
| 临床 | 雌激素下降易感染 | 外口移行区是宫颈癌好发部位 | 与阴道上皮连续 |
:::

:::compare{title="阴道与子宫内膜"}
| 项目 | 阴道 | 子宫内膜（宫体） |
|------|------|------------------|
| 上皮 | 未角化复层扁平 | 单层柱状（纤毛细胞 + 分泌细胞） |
| 固有层 | 致密结缔组织，富含弹性纤维和血管 | 有基质细胞、子宫腺、螺旋动脉 |
| 分层 | 无功能层 / 基底层之分 | 功能层剥脱，基底层保留 |
| 月经 | 不形成月经，只作为排出通道 | 功能层坏死出血即月经 |
| 防御 | 糖原 → 乳酸，抑制细菌 | 不靠乳杆菌产酸 |
:::

:::note{label="雌激素下降时的阴道微环境"}
| 状态 | 上皮糖原 | 阴道液 pH | 结果 |
|------|----------|-----------|------|
| 雌激素作用正常 | 大量聚集 | 因乳酸而较低 | 抑制细菌，防止病菌侵入子宫 |
| 老年或其他原因雌激素下降 | 减少 | 上升 | 细菌易繁殖，发生阴道感染 |
:::

:::pitfall{label="阴道上皮是未角化复层扁平，不要写成角化皮肤或单层柱状"}
角化是皮肤和前庭靠近外口的规矩；单层柱状是宫颈管和宫体内膜的规矩。阴道靠的是未角化复层扁平里的糖原，以及乳杆菌把糖原变成乳酸。写成角化，糖原账没有了；写成单层柱状，又会和宫颈管弄混。
:::

:::pitfall{label="阴道不是形成月经的地方，脱落细胞不等于功能层剥脱"}
月经是子宫内膜功能层缺血坏死后经阴道排出。阴道上皮也随周期脱落更新，那是为了产酸和反映卵巢功能，户头不是螺旋动脉收缩。把“阴道脱落细胞”听成“阴道在来月经”，基底层保留那本账会被搬错器官。
:::

:::insight{label="雌激素把糖原存进上皮，乳杆菌再把糖原酿成酸"}
这是阴道自带的化学防线：激素 → 糖原 → 乳酸 → 低 pH。卵巢周期一乱或雌激素下降，糖原减少，pH 上升，感染就容易发生。脱落细胞涂片能反过来推测卵巢内分泌状态，因为上皮更新节奏跟卵巢走。
:::

:::keypoint{label="阴道三层壁，未角化复层扁平靠糖原和乳杆菌收口"}
- 黏膜、肌层、外膜；黏膜有横行皱襞。
- 上皮：未角化复层扁平；雌激素 → 细胞内大量糖原。
- 脱落细胞中的糖原被乳杆菌变为乳酸，抑制细菌、防止病菌侵入子宫。
- 雌激素下降 → 糖原减少 → pH 上升 → 易感染。
- 脱落细胞类型可推知卵巢内分泌功能。
- 固有层：致密结缔组织，富含弹性纤维和血管。
- 肌层薄，内环外纵，分界不清；外口有骨骼肌括约肌；外膜为富含弹性纤维的致密结缔组织。
:::
