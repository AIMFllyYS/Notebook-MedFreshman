# 二、生殖系统的发生

遗传性别在受精时已由精子核型确定，但生殖腺到第 $7$ 周、外生殖器到第 $12$ 周才能辨认。生殖腺、生殖管道和外生殖器都先走性未分化阶段，再走性分化阶段。未分化性腺有 SRY／TDF 才向睾丸走，没有 Y 染色体则自然发育为卵巢。管道上，中肾管（Wolff）和中肾旁管（Müller）两套并排，男女各留一套。

虽然人类的遗传性别在受精时已由精子的核型确定，但直到胚胎第 $7$ 周，生殖腺才能辨认性别，外生殖器的性别到第 $12$ 周时才可分辨。因此，生殖腺、生殖管道和外生殖器的发生过程均分为早期的性未分化阶段和后期的性分化阶段。

:::definition{label="遗传性别与表型可辨认的时间"}
遗传性别在受精时已由精子的核型确定。生殖腺要到胚胎第 $7$ 周才能辨认性别，外生殖器要到第 $12$ 周才可分辨。中间这一段，形态上仍是未分化。
:::

:::definition{label="性未分化阶段与性分化阶段"}
生殖腺、生殖管道和外生殖器的发生过程均分为早期的性未分化阶段和后期的性分化阶段。未分化不是“没有原基”，而是两套原基都在、尚未按男女取舍。
:::

:::concept{term="先问遗传性别何时确定，再问生殖腺、外生殖器各到第几周才能辨认"}
看见“性别”，先把三张时钟分开：受精时核型已经定了；生殖腺第 $7$ 周才能辨认；外生殖器第 $12$ 周才可分辨。把“受精就长出阴茎或阴道”写成一句，未分化性腺、两套管道和未分化外生殖器整段都会被划掉。
:::

:::timeline{period="性别三张时钟"}
- **受精** 精子核型确定遗传性别
- **第7周** 生殖腺才能辨认性别
- **第12周** 外生殖器的性别才可分辨
- **此前** 生殖腺、生殖管道、外生殖器都处于性未分化阶段
:::

## （一）睾丸和卵巢的发生

生殖腺不是生殖嵴自己变的，要三件套凑齐：表面的体腔上皮、上皮下的间充质，以及从卵黄囊迁来的原始生殖细胞。

生殖腺由生殖嵴表面的体腔上皮、上皮下的间充质和迁入的原始生殖细胞共同发育而成。

:::definition{label="生殖腺的三件套"}
生殖腺由生殖嵴表面的体腔上皮、上皮下的间充质和迁入的原始生殖细胞共同发育而成。缺了迁入的原始生殖细胞，上皮和间充质堆不出有配子的性腺。
:::

### 1. 未分化期

第 $5$ 周时，生殖嵴表面的上皮细胞增生，伸入下方的间充质，形成许多不规则的细胞索条，称初级性索（primary sex cord）。在人胚第 $4$ 周初，靠近尿囊根部的卵黄囊壁内胚层出现大而圆的细胞，称原始生殖细胞（primordial germ cell）；原始生殖细胞沿后肠背系膜向生殖嵴迁移，第 $6$ 周迁入初级性索（图 24-9，图 24-10）。此时的生殖腺无性别特征，称未分化性腺。

:::definition{label="初级性索"}
初级性索（primary sex cord）是第 $5$ 周生殖嵴表面上皮细胞增生、伸入下方间充质形成的许多不规则细胞索条。男女未分化期都有这一套。
:::

:::definition{label="原始生殖细胞"}
原始生殖细胞（primordial germ cell）是人胚第 $4$ 周初靠近尿囊根部的卵黄囊壁内胚层出现的大而圆的细胞。它们沿后肠背系膜向生殖嵴迁移，第 $6$ 周迁入初级性索。不是在生殖嵴里就地发生的。
:::

:::definition{label="未分化性腺"}
第 $6$ 周原始生殖细胞迁入初级性索后，生殖腺仍无性别特征，称未分化性腺。有没有 Y 染色体、有没有 TDF，下一阶段才分出睾丸或卵巢。
:::

::figure{src="/images/histology/textbook/p0264_01.png" caption="图24-10 未分化性腺的发生示意图。横切面示生殖嵴表面上皮伸入间充质形成初级性索，原始生殖细胞已迁入；外侧中肾嵴内可见中肾小管、中肾管和中肾旁管。" alt="胚体横切：内侧生殖嵴含初级性索，外侧中肾嵴含中肾小管、中肾管与中肾旁管"}

:::pitfall{label="原始生殖细胞来自卵黄囊内胚层，不是生殖嵴自己长出来的"}
第 $4$ 周初它们出现在靠近尿囊根部的卵黄囊壁内胚层，沿后肠背系膜走，第 $6$ 周才进初级性索。写成“生殖嵴上皮直接变成精原细胞或卵原细胞”，迁移这本账会消失。
:::

:::timeline{period="未分化性腺"}
- **第4周初** 原始生殖细胞出现于靠近尿囊根部的卵黄囊壁内胚层
- **第5周** 生殖嵴表面上皮伸入间充质，形成初级性索
- **迁移途中** 原始生殖细胞沿后肠背系膜走向生殖嵴
- **第6周** 迁入初级性索；此时称未分化性腺，尚无性别特征
:::

### 2. 睾丸的发生

如果胚胎的遗传性别为男性，其原始生殖细胞即携带 $\mathrm{XY}$ 性染色体。Y 染色体短臂上有 Y 染色体性别决定区（sex determining region of the Y，SRY），可编码睾丸决定因子（testis determination factor，TDF）。该因子能使未分化性腺向睾丸方向分化。人胚第 $7\sim 8$ 周时，在 TDF 影响下，初级性索与表面上皮分离，继续向深部增生，形成许多界限清楚、互相吻合的细长弯曲的睾丸索（testicular cord）（青春期时演化为生精小管）。初级性索上皮细胞演变成支持细胞，原始生殖细胞则增殖分化为精原细胞。睾丸索的末端吻合成睾丸网。第 $8$ 周时，表面上皮下方的间充质形成白膜，睾丸索之间的间充质细胞分化为睾丸间质细胞，有分泌雄激素的功能（图 24-11）。

:::definition{label="SRY 与 TDF"}
Y 染色体短臂上有 Y 染色体性别决定区（sex determining region of the Y，SRY），可编码睾丸决定因子（testis determination factor，TDF）。TDF 使未分化性腺向睾丸方向分化。没有这条短臂上的决定区，未分化性腺不走睾丸。
:::

:::definition{label="睾丸索"}
人胚第 $7\sim 8$ 周，在 TDF 影响下，初级性索与表面上皮分离，继续向深部增生，形成界限清楚、互相吻合的细长弯曲的睾丸索（testicular cord）。青春期时演化为生精小管。末端吻合成睾丸网。
:::

:::definition{label="支持细胞与精原细胞（发生）"}
初级性索上皮细胞演变成支持细胞；原始生殖细胞增殖分化为精原细胞。上皮来源走支持细胞，迁入的原始生殖细胞走精原细胞，两本账不要并成“性索自己变成精子”。
:::

:::definition{label="白膜与睾丸间质细胞（发生）"}
第 $8$ 周，表面上皮下方的间充质形成白膜；睾丸索之间的间充质细胞分化为睾丸间质细胞，有分泌雄激素的功能。雄激素后面要管中肾管和外生殖器向男性分化。
:::

### 3. 卵巢的发生

女性胚胎细胞的性染色体为 $\mathrm{XX}$，无 Y 染色体，故其未分化性腺自然发育为卵巢。人胚第 $10$ 周后，性腺在向卵巢发生过程中，初级性索退化，被基质和血管代替，成为卵巢髓质。未分化性腺的表面上皮增生，再次向间充质伸入，形成次级性索（secondary sex cord），又称皮质索（cortical cord）（图 24-11，图 24-12）。皮质索与上皮分离后构成卵巢皮质。上皮下的间充质形成白膜。第 $3\sim 4$ 个月时，皮质索断裂，形成许多细胞团。细胞团中央为原始生殖细胞分化成的卵原细胞，周围是一层由皮质索上皮细胞分化成的扁平的卵泡细胞，二者构成原始卵泡。卵原细胞继续增殖，原始卵泡也分裂增多。胎儿出生时，两侧卵巢中有 $70\sim 200$ 万个原始卵泡，其中的卵原细胞已分化为初级卵母细胞，并停留在第一次减数分裂的前期。

:::definition{label="卵巢发生的默认方向"}
女性胚胎细胞的性染色体为 $\mathrm{XX}$，无 Y 染色体，未分化性腺自然发育为卵巢。卵巢不是另有一套“卵巢决定因子”按教材必须先写出来；教材写的是无 Y 则自然走卵巢。
:::

:::definition{label="初级性索在卵巢中的结局"}
人胚第 $10$ 周后，初级性索退化，被基质和血管代替，成为卵巢髓质。它不像睾丸那样变成睾丸索和生精小管。
:::

:::definition{label="次级性索（皮质索）"}
次级性索（secondary sex cord）又称皮质索（cortical cord），是未分化性腺表面上皮再次向间充质伸入形成的。它与上皮分离后构成卵巢皮质。
:::

:::definition{label="原始卵泡（发生）"}
第 $3\sim 4$ 个月皮质索断裂成许多细胞团：中央是原始生殖细胞分化成的卵原细胞，周围是皮质索上皮细胞分化成的一层扁平卵泡细胞，二者构成原始卵泡。
:::

:::definition{label="出生时的卵泡与初级卵母细胞"}
胎儿出生时，两侧卵巢中有 $70\sim 200$ 万个原始卵泡。其中的卵原细胞已分化为初级卵母细胞，并停留在第一次减数分裂的前期。出生时不是“还全是卵原细胞”，也还没有完成第一次减数分裂。
:::

::figure{src="/images/histology/textbook/p0264_02.png" caption="图24-11 睾丸与卵巢的分化示意图。左侧卵巢：初级性索退化成髓质，表面上皮再伸入形成皮质索，断裂后中央为卵原细胞、周围为扁平卵泡细胞。右侧睾丸：初级性索成睾丸索和睾丸网，上皮成支持细胞，原始生殖细胞成精原细胞，间质细胞位于索之间。" alt="未分化性腺向左成卵巢皮质索与原始卵泡，向右成睾丸索、睾丸网、支持细胞与精原细胞"}

::figure{src="/images/histology/textbook/p0265_01.png" caption="图24-12 人胎卵巢光镜图。A. 第14周：1. 皮质（含次级性索）；2. 髓质。B. 第18周：↑原始卵泡。" alt="两幅光镜：A 皮质索与髓质分界，B 高倍见原始卵泡"}

:::concept{term="先问有没有 Y 染色体上的 SRY／TDF，再问初级性索是变成睾丸索还是退化成髓质"}
看见未分化性腺，先问核型：有 Y、有 SRY 编码的 TDF，第 $7\sim 8$ 周初级性索深部增生为睾丸索（青春期成生精小管），上皮成支持细胞，原始生殖细胞成精原细胞，间质成白膜和间质细胞。没有 Y，第 $10$ 周后初级性索退化成髓质，表面上皮再伸入成皮质索，第 $3\sim 4$ 个月断裂成原始卵泡。把卵巢写成“也有一套 TDF 的镜像因子”，或把皮质索听成初级性索改名，睾丸索和原始卵泡会对错世代。
:::

:::compare{title="未分化性腺向睾丸或卵巢分化"}
| 项目 | 未分化性腺 | 睾丸 | 卵巢 |
|------|------------|------|------|
| 时间 | 第 $5\sim 6$ 周 | 第 $7\sim 8$ 周可辨 | 第 $10$ 周后走向明确 |
| 性染色体 | 尚未在形态上表达 | $\mathrm{XY}$，Y 短臂 SRY → TDF | $\mathrm{XX}$，无 Y |
| 初级性索 | 表面上皮伸入间充质 | 与上皮分离，深部增生为睾丸索（青春期 → 生精小管），末端成睾丸网 | 退化，被基质和血管代替，成为髓质 |
| 后来的索 | — | 不再另发次级性索 | 表面上皮再伸入 → 次级性索／皮质索 → 皮质 |
| 生殖细胞 | 原始生殖细胞迁入初级性索 | 增殖分化为精原细胞 | 分化为卵原细胞，出生时已成初级卵母细胞，停在第一次减数分裂前期 |
| 上皮来源细胞 | 初级性索上皮 | 支持细胞 | 皮质索上皮 → 扁平卵泡细胞 |
| 间充质 | 上皮下间充质 | 第 $8$ 周成白膜；索之间成间质细胞，分泌雄激素 | 上皮下成白膜 |
:::

:::pitfall{label="卵巢不是“TDF 的反向开关”，教材写的是无 Y 则自然发育"}
睾丸方向依赖 SRY／TDF。卵巢方向在教材里是无 Y 染色体、未分化性腺自然发育。不要发明一套必须与 TDF 对等的“卵巢决定因子”写进这节正文。
:::

:::pitfall{label="出生时卵原细胞已经变成初级卵母细胞，并停在第一次减数分裂前期"}
两侧卵巢 $70\sim 200$ 万个原始卵泡里，中央已经是初级卵母细胞。写成“出生时全是卵原细胞”或“已经完成减数分裂”，和第 $21$ 章排出的次级卵母细胞会对不齐。
:::

### 4. 睾丸和卵巢的下降

生殖腺最初位于腹后壁，随着体积的增大逐渐突入腹膜腔，由厚而短的系膜悬吊于腹腔腰部。随后系膜变得细长，逐步形成纤维索状连于生殖腺尾端与阴唇、阴囊隆起之间，称引带（gubernaculum）。随着胚体生长、腰部直立、引带相对缩短，牵拉生殖腺下降。第 $3$ 个月时，卵巢停留在盆腔；睾丸继续下降，停留在腹股沟管内口。第 $7\sim 8$ 个月时，睾丸与包绕它的双层腹膜经腹股沟管降入阴囊。双层腹膜构成鞘突，覆盖在睾丸的前面及侧面，成为鞘膜。出生前后，鞘膜腔与腹膜腔之间的通路逐渐闭合（图 24-13）。

:::definition{label="引带"}
引带（gubernaculum）是系膜变细后形成的纤维索，连于生殖腺尾端与阴唇、阴囊隆起之间。胚体生长、腰部直立时引带相对缩短，牵拉生殖腺下降。
:::

:::definition{label="卵巢停留与睾丸继续下降"}
第 $3$ 个月时卵巢停留在盆腔。睾丸继续下降，先停留在腹股沟管内口；第 $7\sim 8$ 个月与包绕它的双层腹膜经腹股沟管降入阴囊。
:::

:::definition{label="鞘突与鞘膜"}
双层腹膜构成鞘突，覆盖在睾丸的前面及侧面，成为鞘膜。出生前后，鞘膜腔与腹膜腔之间的通路逐渐闭合。通路不闭合或闭合不全，腹内压增高时肠管可突入鞘膜腔，即先天性腹股沟疝。睾丸未降入阴囊则称隐睾。
:::

::figure{src="/images/histology/textbook/p0265_02.png" caption="图24-13 睾丸下降过程示意图。A. 睾丸位于腹腔，引带连于阴囊隆起；B. 睾丸降至腹股沟管，出现鞘突；C. 经腹股沟管降入阴囊；D. 鞘突成为鞘膜壁层与脏层，通路逐渐闭合。" alt="四幅矢状面：睾丸由腹腔经腹股沟管入阴囊，引带缩短，鞘突覆盖睾丸后闭合"}

:::concept{term="先问引带相对缩短有没有把性腺拉下来，再问卵巢是不是停在盆腔、睾丸是不是经腹股沟管入阴囊"}
看见下降，先认引带：连生殖腺尾端与阴唇、阴囊隆起，相对缩短才牵拉下降。再问时间：第 $3$ 个月卵巢停盆腔，睾丸还在腹股沟管内口；第 $7\sim 8$ 个月睾丸带双层腹膜进阴囊，腹膜成鞘突、鞘膜。最后问闭合：出生前后鞘膜腔与腹膜腔通路该闭。没降完是隐睾，通路没闭是先天性腹股沟疝。把卵巢也写成“降进大阴唇”，或把鞘突听成引带，两张畸形名单会对错结构。
:::

:::compare{title="卵巢下降与睾丸下降"}
| 项目 | 卵巢 | 睾丸 |
|------|------|------|
| 起点 | 腹后壁，突入腹膜腔 | 同左 |
| 牵引 | 引带相对缩短 | 同左 |
| 第 $3$ 个月 | 停留在盆腔 | 继续下降，停在腹股沟管内口 |
| 第 $7\sim 8$ 个月 | 不再进入阴囊 | 与双层腹膜经腹股沟管降入阴囊 |
| 腹膜 | 不形成鞘突这套入阴囊的通路 | 双层腹膜成鞘突 → 鞘膜；出生前后通路闭合 |
:::

:::timeline{period="生殖腺下降"}
- **最初** 位于腹后壁，体积增大后突入腹膜腔，厚而短的系膜悬于腰部
- **随后** 系膜细长成引带，连于生殖腺尾端与阴唇、阴囊隆起之间
- **第3个月** 卵巢停留盆腔；睾丸停在腹股沟管内口
- **第7～8个月** 睾丸与双层腹膜经腹股沟管降入阴囊，腹膜成鞘突、鞘膜
- **出生前后** 鞘膜腔与腹膜腔之间的通路逐渐闭合
:::

:::keypoint{label="卵黄囊迁入未分化性腺，有 TDF 成睾丸，无 Y 成卵巢，引带拉下降"}
- 生殖腺 = 体腔上皮 + 间充质 + 迁入的原始生殖细胞。
- 原始生殖细胞：第 $4$ 周初卵黄囊内胚层 → 后肠背系膜 → 第 $6$ 周初级性索。
- 睾丸：SRY → TDF；初级性索 → 睾丸索（青春期生精小管）+ 睾丸网；支持细胞、精原细胞；第 $8$ 周白膜与间质细胞。
- 卵巢：无 Y，初级性索 → 髓质；皮质索断裂 → 原始卵泡；出生时初级卵母细胞停在第一次减数分裂前期。
- 引带牵拉下降；卵巢第 $3$ 个月停盆腔；睾丸第 $7\sim 8$ 个月入阴囊，鞘突出生前后闭合。
:::

## （二）生殖管道的发生与演化

未分化期男女都有两对管道：中肾管和中肾旁管。男性留中肾管（Wolff），靠雄激素；中肾旁管被支持细胞的抗中肾旁管激素打掉。女性留中肾旁管（Müller，米勒管），因为既没有雄激素也没有抗中肾旁管激素。

### 1. 未分化期

第 $6$ 周时，胚体内已先后出现左、右两对生殖管道，即一对中肾管和一对中肾旁管（paramesonephric duct），后者又称米勒管（Müllerian duct）。中肾旁管由尿生殖嵴头端外侧的体腔上皮凹陷后闭合而成。其起始部呈漏斗形，开口于体腔，上段较长，纵行于中肾管外侧；中段经中肾管腹侧向内弯曲横行，在中线与对侧中肾旁管相遇；下段并列下行，其末端为盲端，突入尿生殖窦背侧壁，在窦腔内形成隆起，称窦结节（sinus tubercle）。中肾管开口于窦结节的两侧（图 24-14）。

:::definition{label="中肾旁管"}
中肾旁管（paramesonephric duct）又称米勒管（Müllerian duct），由尿生殖嵴头端外侧的体腔上皮凹陷后闭合而成。起始部漏斗形开口于体腔；上段纵行于中肾管外侧；中段经中肾管腹侧向内横行，中线相遇；下段并列下行，盲端突入尿生殖窦背侧壁。
:::

:::definition{label="窦结节"}
窦结节（sinus tubercle）是左、右中肾旁管下段盲端突入尿生殖窦背侧壁后，在窦腔内形成的隆起。中肾管开口于窦结节的两侧。女性后来窦结节增生延长成阴道板。
:::

:::note{label="中肾管此时已经在场"}
中肾管来自前肾管改称，不是第 $6$ 周新长的。未分化期它和中肾旁管并排：中肾旁管上段在它外侧，中段绕到它腹侧横行会合。
:::

### 2. 男性生殖管道的分化

睾丸形成后，其支持细胞产生抗中肾旁管激素，使中肾旁管退化。睾丸间质细胞分泌雄激素，促使中肾管延长弯曲形成附睾管、输精管、精囊和射精管。与睾丸相邻的十余条中肾小管分化为附睾的输出小管。

:::definition{label="抗中肾旁管激素"}
睾丸支持细胞产生抗中肾旁管激素，使中肾旁管退化。没有这层抑制，中肾旁管会继续发育成输卵管、子宫。
:::

:::definition{label="雄激素与中肾管（男性）"}
睾丸间质细胞分泌雄激素，促使中肾管延长弯曲形成附睾管、输精管、精囊和射精管。雄激素不够，中肾管留不住。
:::

:::definition{label="输出小管的来源"}
与睾丸相邻的十余条中肾小管分化为附睾的输出小管。输出小管来自中肾小管，不来自中肾管本身。
:::

### 3. 女性生殖管道的分化

卵巢形成后，由于缺乏雄激素，中肾管退化；同时亦无抗中肾旁管激素的抑制作用，中肾旁管进一步发育。其上段和中段演化为输卵管，起始端以漏斗形开口于体腔，形成输卵管漏斗部；下段左、右合并后，演变为子宫及阴道穹。窦结节增生延长，形成阴道板。第 $5$ 个月时，阴道板演化成中空的阴道，上端与子宫相通，下端以处女膜与阴道前庭相隔（图 24-15）。

:::definition{label="女性中肾管退化"}
卵巢形成后缺乏雄激素，中肾管退化。女性不是“主动分泌一种激素去打掉中肾管”，而是没有雄激素维持。
:::

:::definition{label="中肾旁管在女性的三段"}
上段和中段演化为输卵管，起始端漏斗形开口于体腔，形成输卵管漏斗部。下段左、右合并，演变为子宫及阴道穹。未合并 → 双子宫（常伴双阴道）；仅下段上半未融合 → 双角子宫。
:::

:::definition{label="阴道板与处女膜"}
窦结节增生延长形成阴道板。第 $5$ 个月阴道板演化成中空的阴道，上端与子宫相通，下端以处女膜与阴道前庭相隔。窦结节未成阴道板、或成板后未成管道 → 阴道闭锁；仅处女膜出生前后未穿通，外观也可看不见阴道。
:::

::figure{src="/images/histology/textbook/p0266_01.png" caption="图24-14 生殖管道的演变示意图。未分化期中肾管与中肾旁管并行，中肾旁管下段突入尿生殖窦成窦结节。男性：中肾旁管退化，中肾管成附睾管、输精管、精囊和射精管，相邻中肾小管成输出小管。女性：中肾管退化，中肾旁管上中段成输卵管，下段合并成子宫及阴道穹。" alt="三图：上方未分化两套管道，左下男性保留中肾管，右下女性保留中肾旁管成子宫输卵管"}

::figure{src="/images/histology/textbook/p0266_02.png" caption="图24-15 子宫与阴道的形成模式图。左右中肾旁管下段合并为子宫；窦结节增生为阴道板，第5个月中空成阴道，下端以处女膜与阴道前庭相隔。" alt="中肾旁管下段合并成子宫，末端阴道板管道化，处女膜分隔阴道与前庭"}

:::concept{term="先问这是中肾管还是中肾旁管，再问男性靠哪两种激素取舍、女性为什么一套退化一套留下"}
看见生殖管道，先认两套：中肾管是前肾管改称，开口在窦结节两侧；中肾旁管是体腔上皮凹陷闭合的米勒管，下段盲端造窦结节。再问男性：支持细胞抗中肾旁管激素打掉米勒管，间质细胞雄激素保住中肾管（附睾管、输精管、精囊、射精管），相邻中肾小管成输出小管。女性：无雄激素则中肾管退化，无抗中肾旁管激素则米勒管留下——上中段输卵管，下段合并成子宫及阴道穹，窦结节成阴道板。把输卵管写成中肾管变的，或把子宫写成尿生殖窦上段变的，两套管道会对调。
:::

:::compare{title="中肾管（Wolff）与中肾旁管（Müller）"}
| 项目 | 中肾管 | 中肾旁管 |
|------|--------|----------|
| 英文 / 别称 | mesonephric duct（Wolff 管） | paramesonephric duct（Müller 管，米勒管） |
| 来源 | 前肾管向尾延伸后改称 | 尿生殖嵴头端外侧体腔上皮凹陷后闭合 |
| 未分化期位置 | 开口于窦结节两侧 | 上段在中肾管外侧纵行；中段经其腹侧横行会合；下段并列，盲端成窦结节 |
| 男性 | 雄激素作用下延长弯曲 → 附睾管、输精管、精囊、射精管 | 支持细胞的抗中肾旁管激素使其退化 |
| 女性 | 缺乏雄激素而退化 | 上、中段 → 输卵管（漏斗开口于体腔）；下段左右合并 → 子宫及阴道穹 |
| 配套结构 | 相邻十余条中肾小管 → 输出小管（仅男性保留） | 窦结节 → 阴道板 → 第 $5$ 个月中空为阴道，处女膜隔阴道前庭 |
:::

:::pitfall{label="阴道上部来自中肾旁管下段和窦结节，不要写成尿生殖窦上段"}
尿生殖窦上段是膀胱。女性尿生殖窦下段扩大为阴道前庭。子宫及阴道穹来自中肾旁管下段合并；阴道主体由窦结节的阴道板管道化而来。写成“膀胱那一段变成子宫”，开口和畸形（双子宫、阴道闭锁）都会找错原基。
:::

:::cause-effect{title="两套激素决定留下哪一套管"}
- 因：支持细胞产生抗中肾旁管激素
- 果：中肾旁管退化（男性）
- 因：间质细胞分泌雄激素
- 果：中肾管成附睾管、输精管、精囊和射精管
- 因：卵巢侧既无雄激素也无抗中肾旁管激素
- 果：中肾管退化，中肾旁管成输卵管、子宫及阴道穹
- 制约：输出小管来自相邻中肾小管，不来自中肾旁管
:::

:::tip{label="管道口诀"}
男留 Wolff（中肾管），靠雄激素；打掉 Müller，靠支持细胞。女留 Müller（米勒管），上中段输卵管，下段合并成子宫阴道穹；窦结节成阴道板。输出小管是中肾小管，不是中肾管。
:::

:::keypoint{label="未分化期两对管道，男性留中肾管，女性留中肾旁管"}
- 第 $6$ 周：中肾管 + 中肾旁管（米勒管）；窦结节；中肾管开口在两侧。
- 男性：抗中肾旁管激素 → 米勒管退化；雄激素 → 中肾管成附睾管、输精管、精囊、射精管；中肾小管 → 输出小管。
- 女性：中肾管退化；米勒管上中段成输卵管，下段合并成子宫及阴道穹；窦结节 → 阴道板 → 第 $5$ 个月阴道，处女膜隔前庭。
:::

## （三）外生殖器的发生

外生殖器也先共用一套隆起：生殖结节、尿生殖褶、阴唇阴囊隆起。有雄激素才向阴茎、阴囊走；没有雄激素就自然走阴蒂、大小阴唇和阴道前庭。

### 1. 未分化期

第 $3$ 周末，泄殖腔膜周围的间充质细胞增生，形成头尾走向的两条弧形皱褶，称泄殖腔褶。第 $6$ 周时，伴随泄殖腔和泄殖腔膜的分隔，泄殖腔褶被分隔为腹侧较大的尿生殖褶和背侧较小的肛褶。尿生殖褶之间的凹陷为尿生殖沟，沟底为尿生殖膜。尿生殖褶的头端靠拢，增殖隆起为生殖结节。与此同时，左、右尿生殖褶外侧的间充质增生，形成一对大的纵行隆起，称阴唇阴囊隆起（图 24-16）。

:::definition{label="泄殖腔褶"}
第 $3$ 周末，泄殖腔膜周围间充质增生，形成头尾走向的两条弧形皱褶，称泄殖腔褶。第 $6$ 周随泄殖腔和泄殖腔膜分隔，分成腹侧较大的尿生殖褶和背侧较小的肛褶。
:::

:::definition{label="尿生殖褶、尿生殖沟与尿生殖膜"}
尿生殖褶之间的凹陷为尿生殖沟，沟底为尿生殖膜。男性后来左右尿生殖褶在腹侧中线闭合，参与形成尿道海绵体；闭合不全就是尿道下裂。
:::

:::definition{label="生殖结节"}
尿生殖褶头端靠拢、增殖隆起为生殖结节。男性明显伸长增粗成阴茎；女性稍增大为阴蒂。
:::

:::definition{label="阴唇阴囊隆起"}
左、右尿生殖褶外侧的间充质增生，形成一对大的纵行隆起，称阴唇阴囊隆起。男性中线融合成阴囊；女性继续增大成大阴唇，头端合并为阴阜，尾端合并为阴唇后连合。
:::

### 2. 男性外生殖器的分化

在雄激素作用下，生殖结节明显伸长、增粗，形成阴茎。左、右尿生殖褶随生殖结节生长，在腹侧中线闭合，形成尿道海绵体，参与阴茎的形成。左、右阴唇阴囊隆起向尾端牵拉，于中线融合，形成阴囊（图 24-16）。

:::definition{label="男性外生殖器三件套的去向"}
雄激素作用下：生殖结节 → 阴茎；左右尿生殖褶腹侧中线闭合 → 尿道海绵体，参与阴茎；左右阴唇阴囊隆起中线融合 → 阴囊。褶没闭全，阴茎腹侧就留下尿道开口。
:::

### 3. 女性外生殖器的分化

无雄激素作用，外生殖器自然分化为女性。生殖结节稍增大为阴蒂。左、右尿生殖褶发育为小阴唇。两侧阴唇阴囊隆起继续增大隆起，形成大阴唇，其头端合并为阴阜，尾端合并形成阴唇后连合。尿生殖沟扩展，参与形成阴道前庭（图 24-16）。

:::definition{label="女性外生殖器的自然分化"}
无雄激素作用，外生殖器自然分化为女性。生殖结节 → 阴蒂；尿生殖褶 → 小阴唇；阴唇阴囊隆起 → 大阴唇（头端阴阜，尾端阴唇后连合）；尿生殖沟扩展参与阴道前庭。
:::

::figure{src="/images/histology/textbook/p0267_01.png" caption="图24-16 外生殖器的演变模式图。未分化期：生殖结节、尿生殖褶、尿生殖沟、阴唇阴囊隆起与肛褶。男性：生殖结节成阴茎，尿生殖褶闭合参与尿道海绵体，阴唇阴囊隆起融合成阴囊。女性：生殖结节成阴蒂，尿生殖褶成小阴唇，阴唇阴囊隆起成大阴唇，尿生殖沟扩展成阴道前庭。" alt="未分化外生殖器向男性伸长闭合、向女性展开为阴蒂与大小阴唇"}

:::concept{term="先问有没有雄激素，再问生殖结节、尿生殖褶、阴唇阴囊隆起各走哪一条"}
看见外生殖器，先认未分化三件套：头端生殖结节，两侧尿生殖褶夹着尿生殖沟，外侧阴唇阴囊隆起。有雄激素：结节成阴茎，褶在腹侧中线闭合成尿道海绵体，隆起融合成阴囊。无雄激素：结节成阴蒂，褶成小阴唇，隆起成大阴唇，沟扩展成阴道前庭。把小阴唇写成“尿生殖窦下段”，或把阴囊写成“睾丸自己带下来的皮肤袋”，尿道下裂和阴唇后连合会对错原基。
:::

:::compare{title="外生殖器未分化原基的男女去向"}
| 未分化结构 | 男性（需雄激素） | 女性（无雄激素，自然分化） |
|------------|------------------|------------------------------|
| 生殖结节 | 明显伸长、增粗 → 阴茎 | 稍增大 → 阴蒂 |
| 尿生殖褶 | 腹侧中线闭合 → 尿道海绵体，参与阴茎 | 小阴唇 |
| 尿生殖沟 | 随褶闭合被包入 | 扩展，参与阴道前庭 |
| 阴唇阴囊隆起 | 向尾端牵拉，中线融合 → 阴囊 | 大阴唇；头端合并为阴阜，尾端合并为阴唇后连合 |
:::

:::pitfall{label="女性外生殖器是无雄激素下的自然分化，不是另分泌一套“女性激素”才长出来"}
教材写明：无雄激素作用，外生殖器自然分化为女性。雄激素不足的 $46,\mathrm{XY}$ 胎儿，外生殖器可向女性方向不完全分化；肾上腺雄激素过多的 $46,\mathrm{XX}$ 胎儿，可向男性方向不完全分化。开关在雄激素，不在“有没有卵巢激素驱动外阴发生”。
:::

:::timeline{period="外生殖器从褶到可分辨"}
- **第3周末** 泄殖腔膜周围间充质形成泄殖腔褶
- **第6周** 泄殖腔褶分成腹侧尿生殖褶、背侧肛褶；头端成生殖结节；外侧成阴唇阴囊隆起
- **有雄激素** 结节成阴茎，褶闭合参与尿道海绵体，隆起融合成阴囊
- **无雄激素** 结节成阴蒂，褶成小阴唇，隆起成大阴唇，沟成阴道前庭
- **第12周** 外生殖器性别才可分辨
:::

## （四）主要畸形

下降没走完、鞘突没闭、尿生殖褶没闭全、中肾旁管下段没合并、阴道板没管道化、性分化的激素或受体出了问题，分别落在这一节名单里。

### 1. 隐睾

隐睾（cryptorchidism）睾丸未完全下降，停留在腹膜腔或腹股沟处称隐睾（图 24-17A）。隐睾可发生于单侧或双侧。由于温度高会影响精子的发生，所以双侧腹膜腔内隐睾可致男性不育。

:::definition{label="隐睾"}
隐睾（cryptorchidism）指睾丸未完全下降，停留在腹膜腔或腹股沟处。可单侧或双侧。双侧腹膜腔内隐睾因温度高影响精子发生，可致男性不育。
:::

### 2. 先天性腹股沟疝

先天性腹股沟疝（congenital inguinal hernia）若鞘膜腔与腹膜腔之间的通路不闭合或闭合不全，当腹内压增高时，部分肠管可突入鞘膜腔，导致先天性腹股沟疝（图 24-17B）。

:::definition{label="先天性腹股沟疝"}
先天性腹股沟疝（congenital inguinal hernia）因鞘膜腔与腹膜腔之间的通路不闭合或闭合不全，腹内压增高时部分肠管突入鞘膜腔。睾丸可以已经在阴囊里，问题出在通路没关。
:::

### 3. 尿道下裂

尿道下裂（hypospadias）如果左、右尿生殖褶闭合不全，导致阴茎腹侧有尿道开口，称尿道下裂（图 24-17C）。

:::definition{label="尿道下裂"}
尿道下裂（hypospadias）因左、右尿生殖褶闭合不全，阴茎腹侧有尿道开口。它不是隐睾，也不是膀胱外翻。
:::

### 4. 双子宫与双角子宫

双子宫（double uterus）与双角子宫（bicornuate uterus）左、右中肾旁管下段未融合可导致双子宫，常伴有双阴道（图 24-17D）。若仅中肾旁管下段的上半部分未融合，则形成双角子宫。

:::definition{label="双子宫"}
双子宫（double uterus）因左、右中肾旁管下段未融合，常伴双阴道。
:::

:::definition{label="双角子宫"}
双角子宫（bicornuate uterus）因仅中肾旁管下段的上半部分未融合。下半已经合上，所以不是完全的双子宫。
:::

### 5. 阴道闭锁

阴道闭锁（atresia of vagina）窦结节未形成阴道板，或形成阴道板后未形成管道，则导致阴道闭锁。也有的阴道闭锁外观看不见阴道，仅由于处女膜在出生前后未穿通所致。

:::definition{label="阴道闭锁"}
阴道闭锁（atresia of vagina）可因窦结节未形成阴道板，或阴道板未形成管道。另有一种外观不见阴道，仅因处女膜在出生前后未穿通。三种停点不要并成一句“阴道没长”。
:::

### 6. 两性畸形

两性畸形（hermaphroditism）又称半阴阳，是因性分化异常导致的性别畸形，患者的外生殖器介于男女两性之间。根据生殖腺的性别，两性畸形可分为 $3$ 种。①真两性畸形：患者既有睾丸又有卵巢，核型为 $46,\mathrm{XX}/46,\mathrm{XY}$ 嵌合型，极罕见，原因不明；②男性假两性畸形：生殖腺为睾丸，核型为 $46,\mathrm{XY}$，因雄激素分泌不足导致外生殖器向女性方向不完全分化；③女性假两性畸形：生殖腺为卵巢，核型为 $46,\mathrm{XX}$，因肾上腺分泌过多的雄激素，使外生殖器向男性方向不完全分化。

:::definition{label="两性畸形"}
两性畸形（hermaphroditism）又称半阴阳，因性分化异常，外生殖器介于男女两性之间。按生殖腺分成真两性畸形、男性假两性畸形、女性假两性畸形 $3$ 种。
:::

:::definition{label="真两性畸形"}
真两性畸形患者既有睾丸又有卵巢，核型为 $46,\mathrm{XX}/46,\mathrm{XY}$ 嵌合型，极罕见，原因不明。
:::

:::definition{label="男性假两性畸形"}
男性假两性畸形：生殖腺为睾丸，核型为 $46,\mathrm{XY}$，因雄激素分泌不足，外生殖器向女性方向不完全分化。腺是睾丸，外阴没走完男性。
:::

:::definition{label="女性假两性畸形"}
女性假两性畸形：生殖腺为卵巢，核型为 $46,\mathrm{XX}$，因肾上腺分泌过多的雄激素，外生殖器向男性方向不完全分化。腺是卵巢，外阴被多出来的雄激素推偏。
:::

### 7. 雄激素不敏感综合征

雄激素不敏感综合征（androgen insensitivity syndrome）又称睾丸女性化综合征。患者生殖腺为睾丸，核型为 $46,\mathrm{XY}$，可分泌雄激素，但由于体细胞与中肾管细胞缺乏雄激素受体，生殖管道和外生殖器均不能向男性方向发育。由于睾丸支持细胞产生抗中肾旁管激素，致使输卵管和子宫也不发育。外生殖器及青春期后的第二性征均呈女性表型。

:::definition{label="雄激素不敏感综合征"}
雄激素不敏感综合征（androgen insensitivity syndrome）又称睾丸女性化综合征。生殖腺为睾丸，核型 $46,\mathrm{XY}$，能分泌雄激素，但体细胞与中肾管细胞缺乏雄激素受体，管道和外生殖器不能向男性发育。支持细胞仍产生抗中肾旁管激素，故输卵管和子宫也不发育。外生殖器及青春期后第二性征呈女性表型。
:::

看见生殖畸形，先对结构：没降完 → 隐睾；鞘突通路没闭、肠管突入 → 先天性腹股沟疝；尿生殖褶没闭全 → 尿道下裂；中肾旁管下段没融 → 双子宫（常伴双阴道），仅上半没融 → 双角子宫；阴道板或处女膜停住 → 阴道闭锁。再问性分化：外阴介于两性，按生殖腺分三种两性畸形。最后把 AIS 单独提出来：有睾丸、能造雄激素，但受体没有，管道和外阴不向男性走，米勒管又被抗中肾旁管激素打掉，表型是女性。把 AIS 写成男性假两性畸形（雄激素分泌不足），受体和分泌两本账会对成一个。

:::pitfall{label="隐睾是睾丸没降完，疝是鞘突通路没关，不要写成同一种病"}

:::pitfall{label="男性假两性畸形是雄激素分泌不足，AIS 是有激素没受体"}
两者核型都是 $46,\mathrm{XY}$、生殖腺都是睾丸，外阴都可以不像典型男性。差别：假两性畸形是分泌不足；AIS 能分泌，但体细胞和中肾管细胞没有受体，而且抗中肾旁管激素还在，子宫输卵管也不发育，表型走女性。并成“XY 男性化不全”，受体这本账会丢。
:::

:::note{label="克兰费尔特综合征"}
性分化的过程受到遗传因素的调控。性染色体的异常，特别是数目异常，是导致性分化异常的主要原因之一，其中发病率最高的为克兰费尔特综合征（Klinefelter 综合征，又称先天性睾丸发育不全），约占出生男婴的 $0.1\%$。

$1942$ 年，Klinefelter 等描述了一种以 FSH 分泌增加为特征的男性性腺功能减退综合征，首次提出了 Klinefelter 综合征概念。患者的染色体核型主要为 $47,\mathrm{XXY}$（约占 $90\%$），少数为 $46,\mathrm{XY}/47,\mathrm{XXY}$ 嵌合体，其中多余的 X 染色体约 $40\%$ 来源于精子，$60\%$ 来源于卵子。其发生机制为，当生殖细胞进行减数分裂时，性染色体不分离，使精子或卵子多了 $1$ 条 X 染色体。临床主要表现为男性第二性征发育不全。患者出生时及儿童期与正常人无明显差别，到青春期才出现一些异常：外观为男性，但睾丸发育不全，阴茎短小；男性第二性征发育差，有女性化表型，如无胡须、体毛少、阴毛分布如女性等，约 $25\%$ 的患者有乳房发育；多数患者身材高、四肢长，部分患者（约 $1/4$）有智力低下；成年后易患肥胖、糖尿病和骨质疏松等。绝大多数患者因不育而就诊，表现为性功能低下，精液中无精子。

传统观念认为 Klinefelter 综合征患者无法生育，但辅助生殖技术的发展为这些患者带来了生育希望，只要患者精液中有精子或能从睾丸中显微取精，就有可能生育。
:::

:::keypoint{label="下降对隐睾，鞘突对疝，褶对尿道下裂，米勒管下段对双子宫"}
- 隐睾：未降入阴囊；双侧腹膜腔内可致不育。
- 先天性腹股沟疝：鞘突通路未闭，肠管可突入鞘膜腔。
- 尿道下裂：尿生殖褶闭合不全，开口在阴茎腹侧。
- 双子宫常伴双阴道；双角子宫仅下段上半未融合；阴道闭锁看阴道板或处女膜。
- 两性畸形按生殖腺分三种；AIS 是有雄激素无受体，子宫输卵管也不发育。
:::

## 本章小结

间介中胚层头段呈节段性生长，称生肾节；尾段呈索状增生，称生肾索。生肾索继续增生，形成尿生殖嵴，尿生殖嵴又分为外侧的中肾嵴和内侧的生殖嵴。肾的发生分 $3$ 个阶段，即前肾、中肾和后肾。前肾由前肾小管和前肾管构成，中肾由中肾管和中肾小管构成。除中肾管和尾端的少数中肾小管保留外，中肾大部分退化。后肾由输尿管芽与生后肾组织互相诱导、共同分化而成。后肾发育成人体永久肾。

生殖系统的发生包括生殖腺和生殖管道的发生，其发生过程均分为早期的性未分化阶段和后期的性分化阶段。生殖腺由生殖嵴表面的体腔上皮、上皮下的间充质和迁入的原始生殖细胞共同发育而成。睾丸的分化是由 Y 染色体短臂上的 Y 染色体性别决定区决定的，后者可编码睾丸决定因子。在睾丸决定因子影响下，初级性索形成睾丸索，初级性索上皮细胞演变成支持细胞，原始生殖细胞则增殖分化为精原细胞。睾丸索之间的间充质细胞分化为睾丸间质细胞。由于没有 Y 染色体，故未分化性腺自然发育为卵巢，初级性索退化。表面上皮增生，形成皮质索。随后皮质索断裂，形成原始卵泡，中央为卵原细胞，周围是扁平的卵泡细胞。胎儿出生时，卵原细胞已分化为初级卵母细胞。在性未分化期，胚体内出现左、右两对生殖管道，即一对中肾管和一对中肾旁管。中肾旁管下段并列下行，突入尿生殖窦背侧壁，形成窦结节。睾丸的支持细胞产生抗中肾旁管激素，使中肾旁管退化，间质细胞分泌雄激素，促使中肾管形成附睾管、输精管、精囊和射精管。与睾丸相邻的十余条中肾小管分化为附睾的输出小管。由于缺乏雄激素，中肾管退化，又因无抗中肾旁管激素的抑制作用，中肾旁管可进一步发育，其上段和中段演化为输卵管；下段左、右合并后，演变为子宫及阴道穹。窦结节形成阴道板。

:::definition{label="本章小结中的生肾节到后肾"}
头段生肾节、尾段生肾索 → 尿生殖嵴 → 外侧中肾嵴、内侧生殖嵴。肾分前肾、中肾、后肾三阶段。前肾 = 前肾小管 + 前肾管；中肾 = 中肾管 + 中肾小管，大部分退化，留中肾管和尾端少数中肾小管。后肾 = 输尿管芽与生后肾组织互相诱导，发育成永久肾。
:::

:::definition{label="本章小结中的生殖腺"}
生殖腺 = 生殖嵴表面体腔上皮 + 上皮下间充质 + 迁入的原始生殖细胞。Y 短臂性别决定区编码睾丸决定因子 → 初级性索成睾丸索，上皮成支持细胞，原始生殖细胞成精原细胞，索之间间充质成间质细胞。无 Y 则自然成卵巢：初级性索退化，皮质索断裂成原始卵泡（中央卵原细胞，周围扁平卵泡细胞），出生时已成初级卵母细胞。
:::

:::definition{label="本章小结中的两套管道"}
未分化期：中肾管 + 中肾旁管；中肾旁管下段成窦结节。男性：抗中肾旁管激素打掉中肾旁管，雄激素让中肾管成附睾管、输精管、精囊和射精管，相邻中肾小管成输出小管。女性：无雄激素则中肾管退化；无抗中肾旁管激素则中肾旁管上中段成输卵管，下段合并成子宫及阴道穹；窦结节成阴道板。
:::

:::concept{term="先问小结里的肾是不是三阶段加后肾两本账，再问睾丸卵巢和两套管道各靠什么取舍"}
看见本章小结，先把泌尿账收齐：生肾节／生肾索／尿生殖嵴，前肾留管，中肾大部分退化，后肾互相诱导成永久肾。再收生殖腺：三件套；TDF 走睾丸索、支持细胞、精原细胞、间质细胞；无 Y 走皮质索和原始卵泡。最后收管道：两套并排，男性激素取舍留下中肾管，女性留下中肾旁管并合并下段。小结没有展开膀胱、外生殖器和畸形，那些仍以正文为准，不要因为小结没写就从发生过程里删掉。
:::

:::insight{label="同一条中肾管，在肾的发生里发出输尿管芽，在管道分化里决定男女留下哪一套"}
中肾管先给后肾发出输尿管芽，再按有没有雄激素决定自己变成输精管道还是退化。中肾旁管则专门等有没有抗中肾旁管激素。把两章账分开背，输尿管芽和附睾管会对成两条无关的管子。
:::

:::timeline{period="本章小结对照尺"}
- **间介中胚层** 头段生肾节，尾段生肾索 → 尿生殖嵴 → 中肾嵴（外）+ 生殖嵴（内）
- **前肾** 前肾小管 + 前肾管
- **中肾** 中肾管 + 中肾小管；大部分退化，留管和尾端少数小管
- **后肾** 输尿管芽与生后肾组织互相诱导，成永久肾
- **生殖腺** 体腔上皮 + 间充质 + 迁入的原始生殖细胞；未分化后按有无 Y／TDF 分睾丸或卵巢
- **管道** 中肾管 + 中肾旁管 + 窦结节；男性留中肾管，女性留中肾旁管并合并下段，窦结节成阴道板
:::

:::keypoint{label="生肾索成嵴，三套肾只留后肾；性腺看 TDF，管道看两套激素"}
- 生肾节／生肾索 → 尿生殖嵴 → 中肾嵴 + 生殖嵴。
- 前肾有管无功能（正文）；中肾大部分退化；后肾互相诱导成永久肾。
- 生殖腺三件套；TDF → 睾丸索、支持细胞、精原细胞、间质细胞；无 Y → 皮质索、原始卵泡、出生时初级卵母细胞。
- 中肾管对男性管道，中肾旁管对女性管道；窦结节成阴道板。
:::

:::memory{label="本节必背要点"}
- [ ] 遗传性别在受精时已由精子核型确定；生殖腺第 $7$ 周才能辨认性别，外生殖器第 $12$ 周才可分辨。
- [ ] 生殖腺、生殖管道和外生殖器均分为早期性未分化阶段和后期性分化阶段。
- [ ] 生殖腺由生殖嵴表面的体腔上皮、上皮下的间充质和迁入的原始生殖细胞共同发育而成。
- [ ] 第 $5$ 周生殖嵴表面上皮伸入间充质，形成初级性索（primary sex cord）。
- [ ] 第 $4$ 周初原始生殖细胞（primordial germ cell）出现于靠近尿囊根部的卵黄囊壁内胚层，沿后肠背系膜迁移，第 $6$ 周迁入初级性索；此时称未分化性腺。
- [ ] Y 染色体短臂上的 SRY 编码睾丸决定因子（TDF），使未分化性腺向睾丸分化。
- [ ] 第 $7\sim 8$ 周初级性索与表面上皮分离，深部增生为睾丸索（testicular cord），青春期演化为生精小管；末端吻合成睾丸网。
- [ ] 初级性索上皮细胞演变成支持细胞，原始生殖细胞增殖分化为精原细胞。
- [ ] 第 $8$ 周表面上皮下方间充质形成白膜，睾丸索之间的间充质细胞分化为睾丸间质细胞，分泌雄激素。
- [ ] 性染色体为 $\mathrm{XX}$、无 Y，未分化性腺自然发育为卵巢；第 $10$ 周后初级性索退化成为卵巢髓质。
- [ ] 表面上皮再伸入形成次级性索（secondary sex cord），又称皮质索（cortical cord），构成卵巢皮质。
- [ ] 第 $3\sim 4$ 个月皮质索断裂成原始卵泡：中央卵原细胞，周围一层扁平卵泡细胞。
- [ ] 出生时两侧卵巢有 $70\sim 200$ 万个原始卵泡，卵原细胞已分化为初级卵母细胞，停留在第一次减数分裂前期。
- [ ] 引带（gubernaculum）连于生殖腺尾端与阴唇、阴囊隆起之间，相对缩短牵拉下降。
- [ ] 第 $3$ 个月卵巢停留盆腔；睾丸停在腹股沟管内口；第 $7\sim 8$ 个月睾丸与双层腹膜经腹股沟管降入阴囊。
- [ ] 双层腹膜构成鞘突，成为鞘膜；出生前后鞘膜腔与腹膜腔通路逐渐闭合。
- [ ] 第 $6$ 周出现一对中肾管和一对中肾旁管（paramesonephric duct，米勒管，Müllerian duct）。
- [ ] 中肾旁管由尿生殖嵴头端外侧体腔上皮凹陷闭合而成；下段盲端突入尿生殖窦背侧壁，形成窦结节（sinus tubercle）；中肾管开口于窦结节两侧。
- [ ] 男性：支持细胞产生抗中肾旁管激素使中肾旁管退化；间质细胞雄激素使中肾管形成附睾管、输精管、精囊和射精管；相邻十余条中肾小管分化为输出小管。
- [ ] 女性：缺乏雄激素则中肾管退化；无抗中肾旁管激素则中肾旁管上中段成输卵管，下段左右合并成子宫及阴道穹；窦结节成阴道板，第 $5$ 个月成中空阴道，下端以处女膜与阴道前庭相隔。
- [ ] 第 $3$ 周末出现泄殖腔褶；第 $6$ 周分成尿生殖褶和肛褶；头端成生殖结节，外侧成阴唇阴囊隆起。
- [ ] 男性在雄激素作用下：生殖结节成阴茎，尿生殖褶闭合形成尿道海绵体，阴唇阴囊隆起融合成阴囊。
- [ ] 无雄激素则自然分化为女性：生殖结节成阴蒂，尿生殖褶成小阴唇，阴唇阴囊隆起成大阴唇（头端阴阜，尾端阴唇后连合），尿生殖沟扩展参与阴道前庭。
- [ ] 隐睾（cryptorchidism）：睾丸未完全下降，停在腹膜腔或腹股沟；双侧腹膜腔内隐睾可致不育。
- [ ] 先天性腹股沟疝（congenital inguinal hernia）：鞘膜腔与腹膜腔通路不闭合或闭合不全，肠管可突入鞘膜腔。
- [ ] 尿道下裂（hypospadias）：左右尿生殖褶闭合不全，阴茎腹侧有尿道开口。
- [ ] 双子宫（double uterus）因左右中肾旁管下段未融合，常伴双阴道；仅下段上半未融合为双角子宫（bicornuate uterus）。
- [ ] 阴道闭锁（atresia of vagina）：窦结节未成阴道板，或阴道板未成管道；也可仅因处女膜未穿通。
- [ ] 两性畸形（hermaphroditism）：外生殖器介于两性。真两性畸形既有睾丸又有卵巢，核型 $46,\mathrm{XX}/46,\mathrm{XY}$；男性假两性畸形腺为睾丸、核型 $46,\mathrm{XY}$、雄激素分泌不足；女性假两性畸形腺为卵巢、核型 $46,\mathrm{XX}$、肾上腺雄激素过多。
- [ ] 雄激素不敏感综合征（androgen insensitivity syndrome，睾丸女性化综合征）：$46,\mathrm{XY}$，有睾丸能分泌雄激素，但缺乏受体；抗中肾旁管激素仍在，输卵管和子宫不发育；外生殖器及第二性征呈女性表型。
- [ ] 本章小结：生肾节／生肾索 → 尿生殖嵴 → 中肾嵴和生殖嵴；肾分前肾、中肾、后肾，后肾由输尿管芽与生后肾组织互相诱导成永久肾。
- [ ] 本章小结：生殖腺三件套；TDF 决定睾丸；无 Y 则卵巢；中肾管对男性管道，中肾旁管对女性管道，窦结节形成阴道板。
