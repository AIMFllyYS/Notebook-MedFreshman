# 五、骨髓和血细胞发生

体内各种血细胞的寿命有限，每天都有一定数量的血细胞衰老、死亡，同时又有相同数量的血细胞在骨髓生成并进入血液，使外周血中血细胞的数量和质量维持动态平衡。各种血细胞由造血器官生成，胚胎时期的卵黄囊、肝、脾、胸腺和骨髓均能造血；出生后红骨髓成为终身造血的主要器官。

:::definition{label="造血器官"}
造血器官生成各种血细胞。胚胎时期的卵黄囊、肝、脾、胸腺和骨髓均能造血；出生后红骨髓成为终身造血的主要器官。胸腺和淋巴结可终身产生淋巴细胞。
:::

:::concept{term="先问还能自我复制并多向分化，还是已经定向"}
血细胞发生不是骨髓里直接长出五种成熟细胞。第一层是造血干细胞：多数停在 $\mathrm{G}_0$ 期，但能自我复制、也能分化出不同祖细胞。第二层是造血祖细胞（定向干细胞）：分化方向已定，要在 EPO、GM-CSF、TPO 等集落刺激因子作用下才变成形态可辨认的细胞。先问还在不在干细胞层，再问定向到哪一条谱系，集落实验和血象才读得懂。
:::

## （一）造血器官的演变

### 1. 卵黄囊造血期

最早的造血发生在胚胎时期的血岛（blood island）。血岛是胚胎发育第 3 周时由卵黄囊、体蒂和绒毛膜等处的胚外中胚层细胞密集形成的细胞团（见第 25 章），其周边细胞分化为成血管细胞（angioblast），并在周围中胚层分泌的血管内皮生长因子的诱导下增殖并分化成内皮细胞；中间的细胞与周边细胞脱离，分化为原始成血细胞，即最早的造血干细胞，从而进入原始造血或胚胎造血（embryonic hematopoiesis）。原始造血主要是向红细胞系方向分化。

:::definition{label="血岛"}
血岛（blood island）是胚胎发育第 3 周时由卵黄囊、体蒂和绒毛膜等处的胚外中胚层细胞密集形成的细胞团。周边细胞分化为成血管细胞并进而成为内皮；中间细胞脱离后分化为原始成血细胞，即最早的造血干细胞。
:::

:::definition{label="原始造血"}
原始造血又称胚胎造血（embryonic hematopoiesis），由血岛中间的原始成血细胞启动，主要向红细胞系方向分化。
:::

### 2. 肝、脾、胸腺和淋巴结造血期

胚胎发育的第 6 周，卵黄囊内的造血干细胞随血液循环迁入肝并开始造血。胚胎发育的第 12 周，脾内造血干细胞增殖分化产生各种血细胞。肝脾造血的特点是造血干细胞呈现多向分化，称为定型性造血或成人造血（adult hematopoiesis）。胚胎肝和脾内造血干细胞集落由红系细胞、粒单系细胞和巨核细胞组成。胚胎发育至第 3 个月，淋巴干细胞经血液循环进入胸腺并增殖分化为胸腺细胞，最终分化成为 T 淋巴细胞。胚胎第 4 个月时，在胸腺发育成熟的 T 淋巴细胞和在骨髓发育成熟的 B 淋巴细胞进入淋巴结进一步发育成更多的 T 淋巴细胞和 B 淋巴细胞。胸腺和淋巴结可终身产生淋巴细胞。

:::definition{label="定型性造血"}
定型性造血又称成人造血（adult hematopoiesis），特点是造血干细胞呈现多向分化。肝、脾造血和随后的骨髓造血均属此类；胚胎肝、脾内的集落由红系、粒单系和巨核细胞组成。
:::

### 3. 骨髓造血期

胚胎后期骨髓开始造血并维持终身。骨髓造血为定型性造血，主要产生红细胞、粒细胞、单核细胞与巨核细胞–血小板等髓系细胞。

:::compare{title="三个造血期"}
| 项目 | 卵黄囊造血期 | 肝、脾、胸腺和淋巴结造血期 | 骨髓造血期 |
|------|--------------|------------------------------|------------|
| 时间 | 第 3 周起，血岛出现 | 肝约第 6 周，脾约第 12 周；胸腺约第 3 个月，淋巴结约第 4 个月 | 胚胎后期开始，维持终身 |
| 场所 | 卵黄囊、体蒂、绒毛膜等处的血岛 | 肝、脾；胸腺和淋巴结产生淋巴细胞 | 骨髓（出生后主要是红骨髓） |
| 造血性质 | 原始造血（胚胎造血），主要向红系 | 定型性造血（成人造血），干细胞多向分化 | 定型性造血，主要产髓系细胞 |
| 产物特点 | 最早的造血干细胞；红系为主 | 红系、粒单系、巨核系；T、B 淋巴细胞 | 红细胞、粒细胞、单核细胞、巨核细胞–血小板 |
| 出生后 | 停止 | 肝、脾一般不再造血；胸腺和淋巴结终身产淋巴细胞 | 红骨髓成为终身主要造血器官 |
:::

## （二）骨髓的结构

骨髓（bone marrow）位于骨髓腔中，分为红骨髓和黄骨髓，红骨髓的主要结构成分是造血组织，黄骨髓主要为脂肪组织，通常所说的骨髓指红骨髓。胎儿及婴幼儿时期的骨髓都是红骨髓，约从 5 岁开始，长骨干的骨髓腔内出现脂肪组织，并随年龄增长而增多，成为黄骨髓。成人的红骨髓和黄骨髓约各占一半，红骨髓分布在扁骨、不规则骨和长骨骺端的松质骨中；黄骨髓内尚保留少量幼稚血细胞，故有造血潜能，当机体需要时可转变为红骨髓。红骨髓主要由造血组织和血窦构成。

:::definition{label="红骨髓"}
红骨髓以造血组织为主要结构成分，是通常所说的骨髓。成人分布于扁骨、不规则骨和长骨骺端的松质骨中，由造血组织和血窦构成，是出生后终身造血的主要器官。
:::

:::definition{label="黄骨髓"}
黄骨髓主要为脂肪组织，约从 5 岁起在长骨干骨髓腔内出现并随年龄增多。成人红骨髓与黄骨髓约各占一半。黄骨髓内尚保留少量幼稚血细胞，有造血潜能，机体需要时可转变为红骨髓。
:::

:::pitfall{label="黄骨髓不是废骨髓，只是脂肪占了上风"}
约 5 岁后长骨干变黄，不等于造血功能被永久关闭。黄骨髓里仍留着少量幼稚血细胞，需要时可以转回红骨髓。把黄骨髓听成“只有脂肪、不能造血”，会把应急造血和成人红骨髓的分布（扁骨、不规则骨、长骨骺端）一起做窄。
:::

### 1. 造血组织

造血组织由网状组织、造血细胞和基质细胞组成。网状细胞和网状纤维构成网架，网孔中充满不同发育阶段的各种血细胞，以及少量巨噬细胞、脂肪细胞、骨髓基质干细胞等（图 5-7）。

造血细胞赖以生长发育的环境称造血诱导微环境（hemopoietic inductive microenvironment），核心成分是基质细胞（stromal cell），包括巨噬细胞、成纤维细胞、网状细胞、骨髓基质干细胞、血窦内皮细胞等。基质细胞不仅起造血支架作用，并且能分泌多种造血生长因子（hematopoietic growth factor），调节造血细胞的增殖与分化，还能产生网状纤维、粘连性糖蛋白等细胞外基质成分，有滞留造血细胞的作用。

:::definition{label="造血诱导微环境"}
造血诱导微环境（hemopoietic inductive microenvironment）是造血细胞赖以生长发育的环境。核心成分是基质细胞，包括巨噬细胞、成纤维细胞、网状细胞、骨髓基质干细胞、血窦内皮细胞等。
:::

:::definition{label="基质细胞（骨髓）"}
基质细胞（stromal cell）是造血诱导微环境的核心：构成造血支架，分泌多种造血生长因子调节增殖与分化，并产生网状纤维、粘连性糖蛋白等细胞外基质，滞留造血细胞。
:::

::figure{src="/images/histology/textbook/p0069_01.png" caption="图5-7 红骨髓切片光镜图。1. 血窦（内有大量红细胞）；2. 巨核细胞；3. 脂肪细胞。" alt="红骨髓光镜：血窦内充满红细胞，可见巨核细胞和脂肪细胞"}

发育中的各种血细胞在造血组织中的分布呈一定规律。幼稚红细胞常位于血窦附近，成群嵌附在巨噬细胞表面，构成幼红细胞岛（图 5-8）；随着细胞的发育成熟而贴近并穿过血窦内皮，脱去细胞核成为网织红细胞。幼稚粒细胞多远离血窦，当发育至晚幼粒细胞具有运动能力时，以变形运动接近并穿入血窦。巨核细胞常紧靠血窦内皮间隙，将细胞质突起伸入窦腔，脱落形成血小板。这种分布状况表明造血组织的不同部位具有不同的微环境造血诱导作用。

:::definition{label="幼红细胞岛"}
幼红细胞岛是幼稚红细胞成群嵌附在巨噬细胞表面、位于血窦附近而构成的结构。巨噬细胞可吞噬晚幼红细胞脱出的细胞核，并为红细胞发育提供铁质等营养物。细胞成熟后贴近并穿过血窦内皮，脱核成为网织红细胞。
:::

::figure{src="/images/histology/textbook/p0070_01.png" caption="图5-8 骨髓幼红细胞岛超微结构模式图。中央为巨噬细胞，周围依次嵌附原红细胞、早幼红细胞、中幼红细胞、晚幼红细胞；成熟后成为网织红细胞和红细胞进入血窦。" alt="幼红细胞岛：巨噬细胞被各阶段幼红细胞环绕，网织红细胞与红细胞位于周边"}

### 2. 血窦

血窦为管腔大、形状不规则的毛细血管，内皮细胞间隙较大，内皮基膜不完整，呈断续状，有利于成熟血细胞进入血液。

:::definition{label="骨髓血窦"}
骨髓血窦是管腔大、形状不规则的毛细血管。内皮细胞间隙较大，内皮基膜不完整、呈断续状，有利于成熟血细胞进入血液。
:::

:::cause-effect{title="三种细胞为什么不在同一地点入血"}
- 因：造血组织不同部位的微环境诱导作用不同
- 果：幼稚红细胞在血窦附近成幼红细胞岛，成熟后穿内皮、脱核入血
- 果：幼稚粒细胞多远离血窦，晚幼阶段有运动能力才变形接近并穿入血窦
- 果：巨核细胞紧靠血窦内皮间隙，胞质突起伸入窦腔，末端脱落成为血小板
- 制约：血窦内皮间隙大、基膜断续，是成熟细胞入血的结构前提
:::

## （三）造血干细胞和造血祖细胞

血细胞发生是造血干细胞在一定的微环境和某些因素的调节下，先增殖分化为各类血细胞的祖细胞，然后祖细胞定向增殖、分化成为各种成熟血细胞的过程。

### 1. 造血干细胞

造血干细胞（hemopoietic stem cell）是生成各种血细胞的原始细胞，又称多能干细胞（multipotential stem cell），起源于人胚第 3 周初的卵黄囊壁等处的血岛（见第 25 章）。出生后，造血干细胞主要存在于红骨髓中，约占骨髓有核细胞总数的 $0.5\%$，其次是脾和淋巴结，外周血内也有极少量。一般认为，造血干细胞的形态类似小淋巴细胞，即细胞体积小，核相对大，细胞质富含核糖体。

造血干细胞的特性是：①有很强的增殖潜能，在一定条件下能反复分裂，大量增殖；但在一般生理状态下，多数细胞处于静止状态（$\mathrm{G}_0$ 期）。②有多向分化能力，在一些因素的作用下能分化形成不同的祖细胞。③有自我复制能力，即细胞分裂后的部分子代细胞仍具原有特性，故造血干细胞可终身保持恒定的数量。

:::definition{label="造血干细胞"}
造血干细胞（hemopoietic stem cell）又称多能干细胞（multipotential stem cell），是生成各种血细胞的原始细胞。起源于胚第 3 周初卵黄囊壁等处的血岛；出生后主要在红骨髓（约占有核细胞 $0.5\%$），其次在脾和淋巴结，外周血极少量。形态类似小淋巴细胞。具有强增殖潜能（生理状态下多处于 $\mathrm{G}_0$ 期）、多向分化能力和自我复制能力。
:::

造血干细胞的存在是用小鼠脾集落生成实验证实的（图 5-9）。首先将小鼠骨髓细胞悬液输给受致死量射线照射的同系小鼠，使后者重新获得造血能力而免于死亡。接受骨髓的小鼠脾内出现许多小结节状造血灶，称脾集落（spleen colony）。脾集落内含有红细胞系、粒细胞系和巨核细胞系的细胞，它们单独或混合存在。将脾集落细胞分离后，再输给其他用致死量射线照射的同系小鼠，仍能发生多个脾集落，并重建造血功能。脾集落生成数与输入的骨髓细胞数或脾集落细胞数成正比，表明骨髓中有一类能重建造血功能的原始血细胞。为确定一个脾集落的细胞是否起源于同一个原始血细胞，将移植细胞用射线照射，诱发出现畸变染色体，以此作为辨认血细胞发生来源的标志。将此种带标志的细胞输给受照射的小鼠，结果发现，每个脾集落中的所有细胞均具有某种相同的畸变染色体，表明每个集落的细胞来自同一个原始血细胞。造血干细胞中存在不同分化类型的细胞群体，如髓性造血干细胞可分化为红细胞系、粒细胞单核细胞系、巨核细胞系等细胞系的造血祖细胞；淋巴性造血干细胞可分化为各种淋巴细胞（图 5-10）。

人造血干细胞的存在也有一些间接依据，如慢性粒细胞性白血病患者的红细胞系、粒细胞系和巨核细胞系均具有 $\mathrm{Ph}^{1}$ 畸变染色体，由此推测这 3 种细胞来自共同的干细胞；又如人骨髓细胞体外培养，出现混合性细胞集落，也表明造血干细胞的存在。

:::definition{label="脾集落"}
脾集落（spleen colony）是将骨髓细胞输给受致死量射线照射的同系小鼠后，在受体脾内出现的小结节状造血灶。内含红系、粒系和巨核系细胞，可单独或混合存在。每个集落的细胞来自同一个原始血细胞；集落生成数与输入细胞数成正比。
:::

::figure{src="/images/histology/textbook/p0071_01.png" caption="图5-10 血细胞发生模式图。造血干细胞分为髓性造血干细胞和淋巴性造血干细胞，再定向为粒–单核系、嗜酸性、嗜碱性、红系、巨核系及淋巴系祖细胞，最终形成各种成熟血细胞和血小板。" alt="血细胞发生谱系：造血干细胞经髓性和淋巴性两支分化为各系成熟细胞"}

### 2. 造血祖细胞

造血祖细胞（hemopoietic progenitor cell）是由造血干细胞分化而来的分化方向确定的干细胞，故也称定向干细胞（committed stem cell）。它们在不同的集落刺激因子（colony stimulating factor，CSF）作用下，分别分化为形态可辨认的各种血细胞。①红细胞系造血祖细胞，在促红细胞生成素（erythropoietin，EPO）作用下生成红细胞。EPO 主要由肾分泌，肝也分泌少量。②粒细胞单核细胞系造血祖细胞，是中性粒细胞和单核细胞共同的祖细胞，其集落刺激因子由巨噬细胞等细胞分泌，包括 GM-CSF 等。在机体发生炎症时，炎症部位的巨噬细胞释放的白细胞介素-1 能刺激骨髓中这两种细胞的增殖和释放入血。③巨核细胞系造血祖细胞，需在血小板生成素（thrombopoietin，TPO）作用下形成巨核细胞集落，最终产生血小板。TPO 由血管内皮细胞等细胞分泌。嗜酸性粒细胞、嗜碱性粒细胞与肥大细胞也都有各自的祖细胞和集落刺激因子。

:::definition{label="造血祖细胞"}
造血祖细胞（hemopoietic progenitor cell）由造血干细胞分化而来，分化方向已经确定，故也称定向干细胞（committed stem cell）。在不同集落刺激因子（CSF）作用下，分别分化为形态可辨认的各种血细胞。
:::

:::definition{label="集落刺激因子"}
集落刺激因子（colony stimulating factor，CSF）作用于造血祖细胞，使其形成相应细胞集落并分化为成熟血细胞。包括 EPO（红系，主要来自肾）、GM-CSF 等（粒单系，巨噬细胞等分泌）、TPO（巨核系，血管内皮细胞等分泌），以及嗜酸、嗜碱与肥大细胞各自的 CSF。
:::

:::compare{title="造血干细胞与造血祖细胞"}
| 项目 | 造血干细胞（HSC） | 造血祖细胞 |
|------|-------------------|------------|
| 别称 | 多能干细胞 | 定向干细胞 |
| 分化方向 | 未定；可形成不同祖细胞 | 已确定（红系、粒单系、巨核系、淋巴系等） |
| 自我复制 | 有，终身保持恒定数量 | 增殖分化为主，不具备干细胞那种终身自我复制定位 |
| 生理状态 | 多数处于 $\mathrm{G}_0$ 期 | 在相应 CSF 作用下活跃增殖、分化 |
| 形态 | 类似小淋巴细胞 | 仍难以按成熟细胞形态辨认，直到原始/幼稚阶段 |
| 证据 | 脾集落、混合性集落、慢性粒细胞性白血病的 $\mathrm{Ph}^{1}$ 染色体共有 | 在 EPO、GM-CSF、TPO 等作用下形成单系或粒单系集落 |
| 典型调节 | 微环境基质细胞及其造血生长因子 | EPO（肾）、GM-CSF 与 IL-1（炎症时）、TPO（内皮等） |
:::

:::pitfall{label="祖细胞已经定向，不要再把它写成全能的造血干细胞"}
造血祖细胞虽仍称“定向干细胞”，但分化方向已经锁定：红系祖细胞在 EPO 下只产红细胞，粒单系祖细胞是中性和单核的共同上游，巨核系祖细胞在 TPO 下走向血小板。能重建多个谱系、能自我复制的那一层才是造血干细胞。把 EPO、TPO 直接写在造血干细胞头上，会把集落刺激的作用层面做错。
:::

## （四）血细胞发生过程的形态演变

各种血细胞的分化发育过程大致可分为 3 个阶段：原始阶段、幼稚阶段（又分早、中、晚 3 期）和成熟阶段。其形态演变也有一定的规律：①细胞体由大变小，但巨核细胞由小变大。②细胞核由大变小，红细胞的核最后消失，粒细胞的核由圆形逐渐变成杆状乃至分叶；但巨核细胞的核由小变大，呈分叶状。核染色质由细疏变粗密（即常染色质由多变少），核的着色由浅变深，核仁由明显渐至消失。③细胞质由少变多，细胞质嗜碱性逐渐变弱，但单核细胞和淋巴细胞仍保持嗜碱性；细胞质内的特殊结构或蛋白成分，如粒细胞的特殊颗粒、巨核细胞的血小板颗粒、红细胞的血红蛋白，均从无到有，逐渐增多。④细胞分裂能力从有到无，但淋巴细胞仍保持很强的潜在分裂能力。

:::note{label="血细胞发生形态演变的四条规律"}
| 项目 | 一般规律 | 例外 |
|------|----------|------|
| 细胞体 | 由大变小 | 巨核细胞由小变大 |
| 细胞核 | 由大变小；染色质细疏→粗密，着色浅→深，核仁明显→消失 | 红细胞核最后消失；粒细胞核圆→杆状→分叶；巨核细胞核由小变大、呈分叶状 |
| 细胞质 | 由少变多；嗜碱性逐渐变弱；特殊结构或蛋白从无到有 | 单核细胞和淋巴细胞仍保持嗜碱性 |
| 分裂能力 | 从有到无 | 淋巴细胞仍保持很强的潜在分裂能力 |
:::

### 1. 红细胞系的发生

红细胞系历经原红细胞、早幼红细胞、中幼红细胞、晚幼红细胞，晚幼红细胞脱去细胞核成为网织红细胞，入血后变为成熟红细胞（表 5-2）。从原红细胞发育至晚幼红细胞大约需 $3\sim 4$ 天。巨噬细胞可吞噬晚幼红细胞脱出的细胞核，并为红细胞的发育提供铁质等营养物。

:::definition{label="红细胞系发生"}
红细胞系发生依次为原红细胞 → 早幼红细胞 → 中幼红细胞 → 晚幼红细胞，晚幼红细胞脱核成为网织红细胞，入血后变为成熟红细胞。原红至晚幼约需 $3\sim 4$ 天。

### 2. 粒细胞系的发生

3 种粒细胞虽有各自的造血祖细胞，但它们的发育过程基本相同，都历经原粒细胞、早幼粒细胞、中幼粒细胞、晚幼粒细胞，进而分化为成熟的杆状核和分叶核粒细胞（表 5-3）。从原粒细胞增殖分化为晚幼粒细胞大约需 $4\sim 6$ 天。骨髓内的杆状核粒细胞和分叶核粒细胞的贮存量很大，在骨髓停留 $4\sim 5$ 天后入血。在某些病理状态，如急性细菌感染，骨髓加速释放，外周血中的粒细胞可骤然增多。

:::definition{label="粒细胞系发生"}
3 种粒细胞发育过程基本相同：原粒细胞 → 早幼粒细胞 → 中幼粒细胞 → 晚幼粒细胞 → 杆状核和分叶核粒细胞。原粒至晚幼约需 $4\sim 6$ 天。骨髓内杆状核与分叶核贮存量很大，停留 $4\sim 5$ 天后入血。

### 3. 单核细胞系的发生

单核细胞和中性粒细胞具有共同的造血祖细胞，经过原单核细胞和幼单核细胞，变为单核细胞。幼单核细胞增殖力很强，约 $38\%$ 的幼单核细胞处于增殖状态，单核细胞在骨髓中的贮存量不及粒细胞多，当机体出现炎症或免疫功能活跃时，幼单核细胞加速分裂增殖，以提供足量的单核细胞。

:::definition{label="单核细胞系发生"}
单核细胞与中性粒细胞具有共同的造血祖细胞，经原单核细胞、幼单核细胞变为单核细胞。幼单核细胞增殖力很强，约 $38\%$ 处于增殖状态；骨髓贮存量不及粒细胞，炎症或免疫活跃时加速分裂。
:::

### 4. 淋巴细胞系的发生

一部分淋巴性造血干细胞经血流进入胸腺皮质，分化为 T 淋巴细胞，一部分在骨髓内发育为 B 淋巴细胞和 NK 细胞。淋巴细胞的发育主要表现为细胞膜蛋白和功能状态的变化，形态结构的演变不是很明显，故不易从形态上划分淋巴细胞的发生和分化阶段。

:::definition{label="淋巴细胞系发生"}
淋巴性造血干细胞一部分经血流进入胸腺皮质分化为 T 淋巴细胞，一部分在骨髓内发育为 B 淋巴细胞和 NK 细胞。发育主要表现在膜蛋白和功能状态，形态演变不明显，不易按形态划分阶段。
:::

### 5. 巨核细胞–血小板系的发生

原巨核细胞经幼巨核细胞发育为巨核细胞（megakaryocyte），巨核细胞的细胞质块脱落成为血小板。原巨核细胞分化为幼巨核细胞，体积变大，细胞核常呈肾形，细胞质内开始出现血小板颗粒。幼巨核细胞经过数次 DNA 复制，成为 $8\sim 32$ 倍体，但核不分裂，形成巨核细胞。巨核细胞呈不规则形，直径 $50\sim 100\,\mu\mathrm{m}$，核巨大，呈分叶状，细胞质内形成大量血小板颗粒，聚集成团。然后，细胞质内出现大量分隔小管，将细胞质分隔成许多小区，每个小区内有一团血小板颗粒，是一个未来的血小板。巨核细胞伸出细胞质突起从血窦内皮细胞间隙伸入窦腔，其末端细胞质脱落成为血小板。一个巨核细胞可生成 $2\,000\sim 8\,000$ 个血小板。

:::definition{label="巨核细胞"}
巨核细胞（megakaryocyte）由原巨核细胞经幼巨核细胞发育而来。幼巨核细胞经数次 DNA 复制成为 $8\sim 32$ 倍体，核不分裂。细胞不规则，直径 $50\sim 100\,\mu\mathrm{m}$，核巨大、分叶状；胞质内血小板颗粒成团，再被分隔小管划成许多小区。胞质突起伸入血窦，末端脱落成为血小板。一个巨核细胞可生成 $2\,000\sim 8\,000$ 个血小板。
:::

:::note{label="图5-11 巨核细胞电镜图（原图文件为空，此处只保留教材信息）"}
教材图 5-11 为巨核细胞电镜图，标注 1 细胞核、2 血小板颗粒、3 分隔小管，用以对照光镜下巨大分叶核和胞质小区。切片资源中对应文件为空，本页不插入该图。读法仍按：核巨大分叶、颗粒成团、分隔小管划出未来的血小板。
:::

:::cause-effect{title="巨核细胞怎样把一胞体质量产成数千血小板"}
- 因：幼巨核细胞多次复制 DNA 而不分裂，成为 $8\sim 32$ 倍体，细胞体积和核都由小变大
- 因：胞质内血小板颗粒成团，分隔小管把胞质划成许多小区，每区一团颗粒即一个未来的血小板
- 因：细胞紧靠血窦，胞质突起从内皮间隙伸入窦腔
- 果：末端胞质脱落成为血小板；一个巨核细胞可生成 $2\,000\sim 8\,000$ 个
:::

:::insight{label="红系脱核、粒系分叶、巨核系多倍体，是三条相反的核账"}
多数血细胞越成熟核越小。红系把核交给幼红细胞岛的巨噬细胞，留下无核的血红蛋白袋；粒系把圆核拧成杆状再分叶，叶数成为年轻或年老的读数；巨核系反其道而行，核变大、变分叶、变多倍体，只为给胞质小区提供足够的基因组拷贝。三条谱系不要用同一张“核由大变小”的表硬套。
:::

:::keypoint{label="骨髓造血先立微环境，再立干细胞与形态演变"}
- 出生后红骨髓是终身主要造血器官；黄骨髓以脂肪为主，仍保留造血潜能。
- 造血诱导微环境以基质细胞为核心；幼红细胞岛、粒细胞远窦、巨核细胞靠窦，是三种入血路线。
- 造血干细胞：自我复制、多向分化、多数 $\mathrm{G}_0$；造血祖细胞已定向，受 EPO、GM-CSF、TPO 等 CSF 调节。
- 形态演变分原始、幼稚（早中晚）、成熟三阶段；红系脱核，粒系分叶，巨核系多倍体产血小板。
:::

## 本章小结

血液由血浆和血细胞组成。血浆主要成分是水，其余为血浆蛋白和其他成分。血细胞包括红细胞、白细胞和血小板。红细胞呈双凹圆盘状，成熟红细胞无核，也无细胞器，细胞质内充满血红蛋白，具有结合与运输 $\mathrm{O}_2$ 和 $\mathrm{CO}_2$ 的功能。

白细胞包括有粒白细胞和无粒白细胞。前者又可分为中性粒细胞、嗜酸性粒细胞和嗜碱性粒细胞，后者则有单核细胞和淋巴细胞。中性粒细胞是数量最多的白细胞，核呈弯曲杆状或分叶状，细胞质含有嗜天青颗粒和特殊颗粒。中性粒细胞具有很强的趋化作用和吞噬功能。嗜碱性粒细胞数量最少，细胞质内含有嗜碱性颗粒，它与肥大细胞的作用基本相同，也参与过敏反应。嗜酸性粒细胞的细胞质内充满嗜酸性颗粒，能做变形运动并具有趋化性，患过敏性疾病或寄生虫病时，血液中嗜酸性粒细胞增多。单核细胞是体积最大的白细胞，从血液进入结缔组织或其他组织后可分化为巨噬细胞等。淋巴细胞包括胸腺依赖性淋巴细胞（T 淋巴细胞）、骨髓依赖性淋巴细胞（B 淋巴细胞）和自然杀伤细胞（NK 细胞）。淋巴细胞是主要的免疫细胞。血小板是骨髓巨核细胞脱落下来的细胞质小块，参与凝血和止血。淋巴是淋巴管系统内流动的液体，由淋巴液与淋巴细胞构成，淋巴是血浆循环的旁路。

造血器官生成各种血细胞，胚胎时期的卵黄囊、肝、脾、胸腺和骨髓均能造血；出生后红骨髓成为终身造血的主要器官。骨髓分为红骨髓和黄骨髓，红骨髓是造血组织。造血细胞在造血诱导微环境中生长发育。造血干细胞是生成各种血细胞的原始细胞，出生后主要存在于红骨髓。造血祖细胞是由造血干细胞分化而来的分化方向确定的干细胞，可分化为各种血细胞。各种血细胞的分化发育过程大致可分为原始阶段、幼稚阶段和成熟阶段，其形态演变也有一定的规律。

## 插入框：成分输血

输血是一种常用的临床治疗措施。部分患者并不是因为全血的缺乏而需要输血，只是缺乏血液中的某种成分，因此根据患者的病因及输血治疗的目的不同而采取输注不同的血液成分，即成分输血。与输全血相比，成分输血是一种更为个性化的输血方法。

:::definition{label="成分输血"}
成分输血是根据患者的病因及输血治疗目的，输注不同血液成分的方法。部分患者并不缺乏全血，而只缺乏某种成分。它是输血治疗现代化的重要标志。
:::

:::note{label="成分输血的优点"}
| 优点 | 要点 |
|------|------|
| 针对性强 | 按病情选用特定成分，如贫血输红细胞，粒细胞缺乏症输粒细胞等，以提高疗效 |
| 提高安全性 | 全血含大量细胞碎片和抗原物质，易引起输血反应；分解成数种成分有助于降低医疗风险 |
| 一血多用 | 血液来自健康者捐献，分离成各种成分可治疗多个患者，节省血源 |
| 降低传染病风险 | 制备过程采用不同处理方式，可有效去除某些病原微生物 |
| 便于保存 | 不同血液成分有不同保存方式，成分血更便于保存和使用 |
:::

:::memory{label="本节必背要点"}
- [ ] 血细胞寿命有限，骨髓生成与衰老死亡维持动态平衡；出生后红骨髓是终身主要造血器官。
- [ ] 胚胎造血：第 3 周血岛（原始造血，主向红系）→ 第 6 周肝、第 12 周脾（定型性造血，多向分化）→ 第 3 个月胸腺产 T 细胞，第 4 个月淋巴结；胚胎后期骨髓造血并维持终身。
- [ ] 血岛：胚外中胚层细胞团；周边成血管细胞 → 内皮，中间原始成血细胞 = 最早的造血干细胞。
- [ ] 红骨髓：造血组织 + 血窦；成人在扁骨、不规则骨和长骨骺端松质骨。黄骨髓以脂肪为主，约 5 岁起出现于长骨干；保留少量幼稚血细胞，需要时可转红。成人红、黄约各半。
- [ ] 造血诱导微环境：核心是基质细胞（巨噬细胞、成纤维细胞、网状细胞、骨髓基质干细胞、血窦内皮等），分泌造血生长因子，产生网状纤维和粘连性糖蛋白。
- [ ] 幼红细胞岛：幼稚红细胞成群嵌附巨噬细胞表面，位于血窦附近；巨噬细胞吞噬脱出的核并提供铁质。
- [ ] 入血路线：红系近窦、脱核穿内皮；粒系先远离血窦，晚幼后变形入窦；巨核细胞靠窦，胞质突起伸入窦腔脱落为血小板。
- [ ] 血窦：管腔大、不规则；内皮间隙大，基膜断续，利于成熟血细胞入血。
- [ ] 造血干细胞（多能干细胞）：红骨髓约占有核细胞 $0.5\%$；形态似小淋巴；强增殖潜能（多处于 $\mathrm{G}_0$）、多向分化、自我复制。
- [ ] 脾集落实验：致死照射小鼠输骨髓细胞 → 脾内造血灶；每集落来自同一原始细胞（畸变染色体标志）；可再次移植重建造血。
- [ ] 髓性造血干细胞 → 红系、粒单系、巨核系祖细胞；淋巴性造血干细胞 → 各种淋巴细胞。慢性粒细胞性白血病红、粒、巨核系共有 $\mathrm{Ph}^{1}$ 染色体，为人造血干细胞的间接证据。
- [ ] 造血祖细胞 = 定向干细胞；EPO（肾为主）→ 红细胞；粒单系祖细胞 + GM-CSF、炎症时 IL-1 → 中性粒细胞和单核细胞；TPO（内皮等）→ 巨核细胞集落 → 血小板。嗜酸、嗜碱、肥大细胞各有祖细胞和 CSF。
- [ ] 形态演变三阶段：原始、幼稚（早中晚）、成熟。一般规律：胞体大→小（巨核相反）；核大→小（红核消失，粒核分叶，巨核相反）；胞质少→多、嗜碱减弱（单核、淋巴仍嗜碱）；特殊结构从无到有；分裂能力从有到无（淋巴保留）。
- [ ] 红系：原红 → 早幼红 → 中幼红 → 晚幼红（脱核）→ 网织红细胞 → 成熟红细胞；约 $3\sim 4$ 天。
- [ ] 粒系：原粒 → 早幼粒 → 中幼粒 → 晚幼粒 → 杆状核、分叶核；约 $4\sim 6$ 天；骨髓贮存 $4\sim 5$ 天后入血；急性感染可加速释放。
- [ ] 单核系与中性共祖；幼单核约 $38\%$ 处于增殖；骨髓贮存量不及粒细胞。
- [ ] 淋巴系：胸腺皮质 → T 细胞；骨髓 → B 细胞和 NK 细胞；形态演变不明显。
- [ ] 巨核细胞直径 $50\sim 100\,\mu\mathrm{m}$，$8\sim 32$ 倍体，核不分裂；分隔小管划出小区；一个巨核细胞生成 $2\,000\sim 8\,000$ 个血小板。
- [ ] 成分输血：按病因输注特定血液成分，针对性强、更安全、一血多用、降低传染病风险、便于保存。
:::
