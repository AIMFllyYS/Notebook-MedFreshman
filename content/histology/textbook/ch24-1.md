# 一、泌尿系统的发生

胚胎发育的第 $4$ 周初，胚内中胚层由脊索向外依次分成轴旁、间介和侧中胚层。泌尿系统和生殖系统的主要器官都从间介中胚层长出来。本节先把生肾节、生肾索、尿生殖嵴立住，再按前肾、中肾、后肾、膀胱尿道和主要畸形摊开。后肾的集合系统与肾单位是两本账：输尿管芽造管道，生后肾组织造肾单位。

胚胎发育的第 $4$ 周初，胚内中胚层由脊索向外依次分化为 $3$ 部分：轴旁中胚层、间介中胚层和侧中胚层。泌尿系统和生殖系统的主要器官均起源于间介中胚层。在颈部，间介中胚层呈节段性生长，称生肾节（nephrotome）；在尾段，间介中胚层增生形成两条纵行的细胞索，称生肾索（nephrogenic cord）（图 24-1）。第 $4$ 周末，生肾索继续增生，与体节分离，从胚体后壁凸向胚内体腔，成为分列于中轴两侧的一对纵行隆起，称尿生殖嵴（urogenital ridge），是泌尿和生殖系统发生的原基。随后，尿生殖嵴上出现一纵沟，将其分为外侧粗而长的中肾嵴（mesonephric ridge）和内侧细而短的生殖嵴（genital ridge）（图 24-2，图 24-3）。

:::definition{label="间介中胚层"}
间介中胚层位于轴旁中胚层与侧中胚层之间。泌尿系统和生殖系统的主要器官均起源于它，不是轴旁中胚层的体节，也不是侧中胚层的体壁、脏壁。
:::

:::definition{label="生肾节"}
生肾节（nephrotome）是颈部间介中胚层呈节段性生长形成的结构。前肾就在生肾节里发生。它是一节一节的，不是一条纵索。
:::

:::definition{label="生肾索"}
生肾索（nephrogenic cord）是尾段间介中胚层增生形成的两条纵行细胞索。第 $4$ 周末它继续增生、与体节分离，凸向胚内体腔，成为尿生殖嵴。中肾和后肾都在这条索及其衍生物里发生。
:::

:::definition{label="尿生殖嵴"}
尿生殖嵴（urogenital ridge）是第 $4$ 周末生肾索继续增生、与体节分离后，从胚体后壁凸向胚内体腔、分列于中轴两侧的一对纵行隆起。它是泌尿和生殖系统发生的原基。
:::

:::definition{label="中肾嵴与生殖嵴"}
尿生殖嵴上出现一纵沟后，外侧粗而长的是中肾嵴（mesonephric ridge），内侧细而短的是生殖嵴（genital ridge）。外侧走肾，内侧走性腺，不要对调。
:::

:::concept{term="先问这是生肾节还是生肾索，再问尿生殖嵴切开后外侧是中肾嵴还是内侧是生殖嵴"}
看见第 $4$ 周的间介中胚层，先分头尾：颈部一节一节的是生肾节，尾段两条纵索是生肾索。生肾索凸向胚内体腔才叫尿生殖嵴。再问纵沟切开之后：外侧粗而长的是中肾嵴，内侧细而短的是生殖嵴。把生肾节听成“已经是肾”，或把生殖嵴写在外侧，前肾、中肾和性腺会对错户头。
:::

:::pitfall{label="外侧中肾嵴、内侧生殖嵴，不要按“生殖在外”来记"}
尿生殖嵴被纵沟切开后，粗而长的在外侧，是中肾嵴；细而短的在内侧，是生殖嵴。写成“生殖嵴在外侧靠近体壁”，中肾小管、中肾管和原始生殖细胞迁入的地点会对调。
:::

- **尾段** 间介中胚层增生为两条生肾索
- **第4周末** 生肾索与体节分离，凸向胚内体腔，成为尿生殖嵴
- **随后** 纵沟将尿生殖嵴分为外侧中肾嵴、内侧生殖嵴
:::

:::insight{label="一套间介中胚层，先堆出泌尿的嵴，再在内侧留出生殖的嵴"}
轴旁中胚层去造体节，侧中胚层去造体壁和脏壁，夹在中间的间介中胚层才是泌尿生殖的原基。先长生肾节和生肾索，再鼓成尿生殖嵴，最后一刀分成中肾嵴和生殖嵴。只背“中胚层变肾”，后面的前肾、中肾、后肾和性腺都没有地点可放。
:::

## （一）肾和输尿管的发生

人胚肾的发生分 $3$ 个阶段，即从胚体颈部至腰骶部相继出现前肾、中肾和后肾。三套肾头尾接替，只有后肾留下当永久肾。

人胚肾的发生分 $3$ 个阶段，即从胚体颈部至腰骶部相继出现前肾、中肾和后肾。

### 1. 前肾

前肾（pronephros）第 $4$ 周初，在人胚颈部两侧的生肾节内，先后出现 $7\sim 10$ 对横行的细胞索，之后成为小管，称前肾小管（pronephric tubule）。前肾小管的内侧端开口于胚内体腔，外侧端向尾部延伸，互相连接形成头尾走向的前肾管（pronephric duct）。前肾小管和前肾管构成前肾（图 24-4）。人类前肾无泌尿功能。第 $4$ 周末，前肾小管退化，而前肾管大部分保留并向尾部延伸，开口于泄殖腔。

:::definition{label="前肾"}
前肾（pronephros）由前肾小管和前肾管构成，发生在颈部生肾节。人类前肾无泌尿功能。
:::

:::definition{label="前肾小管"}
前肾小管（pronephric tubule）由颈部生肾节内 $7\sim 10$ 对横行细胞索变成。内侧端开口于胚内体腔，外侧端向尾部延伸并互相连接。
:::

:::definition{label="前肾管"}
前肾管（pronephric duct）是前肾小管外侧端互相连接形成的头尾走向管道。第 $4$ 周末前肾小管退化后，前肾管大部分保留，向尾部延伸并开口于泄殖腔，随后改称中肾管。
:::

:::pitfall{label="人类前肾无泌尿功能，但前肾管并不整条扔掉"}
前肾小管第 $4$ 周末退化，前肾管大部分保留并开口于泄殖腔。写成“前肾全退化了，后面的中肾管是另起的一条”，中肾和输尿管芽就没有管道可接。
:::

::figure{src="/images/histology/textbook/p0261_01.png" caption="图24-4 前、中、后肾的发生示意图（第5周）。颈部前肾已退化；胸腰部中肾区可见中肾小管通入中肾管；中肾管近泄殖腔处发出输尿管芽，长入尾端后肾；中肾管开口于泄殖腔。" alt="人胚侧面：头端前肾区已空，中段中肾小管连中肾管，尾端输尿管芽伸入后肾，中肾管通泄殖腔"}

### 2. 中肾

中肾（mesonephros）第 $4$ 周末，前肾小管退化，中肾开始发生。在生肾索及其后形成的中肾嵴内，相继出现约 $80$ 对横行的小管，称中肾小管（mesonephric tubule）。这些小管迅速延长，演变为 S 形小管。其内侧端膨大并凹陷为双层囊，包绕来自背主动脉的毛细血管球，构成肾小体；外侧端通入向尾侧延伸的前肾管，此时的前肾管改称为中肾管（mesonephric duct）。人的中肾在后肾出现之前可有短暂功能。至第 $2$ 个月末，除中肾管和尾端的少数中肾小管保留外，中肾大部分退化。

:::definition{label="中肾"}
中肾（mesonephros）发生在生肾索及其后形成的中肾嵴内。结构上是约 $80$ 对 S 形中肾小管加肾小体，外侧通中肾管。后肾出现之前可有短暂泌尿功能。
:::

:::definition{label="中肾小管"}
中肾小管（mesonephric tubule）约 $80$ 对，迅速延长为 S 形。内侧端膨大凹陷成双层囊，包绕来自背主动脉的毛细血管球，构成肾小体；外侧端通入中肾管。
:::

:::definition{label="中肾管"}
中肾管（mesonephric duct）就是向尾侧延伸的前肾管改称。它开口于泄殖腔；近泄殖腔处后来发出输尿管芽。第 $2$ 个月末中肾大部分退化时，中肾管和尾端少数中肾小管保留——男性后面要靠它们造附睾和输精管。
:::

:::note{label="中肾留下的不是“整个中肾”"}
至第 $2$ 个月末，中肾大部分退化，留下的是中肾管和尾端少数中肾小管。男性：中肾管 → 附睾管、输精管、精囊和射精管；相邻中肾小管 → 输出小管。女性中肾管因缺乏雄激素而退化。不要把“中肾大部分退化”写成“中肾管也没了”。
:::

### 3. 后肾

后肾（metanephros）为人体永久肾，由输尿管芽与生后肾组织互相诱导、共同分化而成。第 $5$ 周初，中肾管近泄殖腔处向胚体的背外侧头端发出一盲管，称输尿管芽（ureteric bud）（图 24-5）。输尿管芽长入中肾嵴尾端，诱导周围的中胚层细胞向其末端聚集、包绕，形成生后肾组织（metanephrogenic tissue），又称生后肾原基（metanephrogenic blastema）。输尿管芽伸长，主干分化成输尿管，末端反复分支，分别形成肾盂、肾盏和集合管。

:::definition{label="后肾"}
后肾（metanephros）是人体永久肾。它不是中肾改名，而是输尿管芽与生后肾组织互相诱导、共同分化的新器官。
:::

:::definition{label="输尿管芽"}
输尿管芽（ureteric bud）是第 $5$ 周初中肾管近泄殖腔处向胚体背外侧头端发出的盲管。它长入中肾嵴尾端，诱导生后肾组织形成。自身伸长后：主干 → 输尿管，末端反复分支 → 肾盂、肾盏和集合管。
:::

:::definition{label="生后肾组织"}
生后肾组织（metanephrogenic tissue）又称生后肾原基（metanephrogenic blastema），是输尿管芽诱导周围中胚层细胞向其末端聚集、包绕而成。它分化为肾单位和肾被膜，不分化为集合管。
:::

::figure{src="/images/histology/textbook/p0261_02.png" caption="图24-5 后肾的发生示意图（第5～8周）。A. 输尿管芽从中肾管近泄殖腔处发出，生后肾组织包绕其末端；B. 芽伸入生后肾原基；C. 末端分支；D. 主干成输尿管，末端成肾盂、肾大盏、肾小盏和集合管。" alt="四阶段：中肾管发出输尿管芽，生后肾原基包绕，随后出现肾盂、肾盏和集合管"}

集合管呈 T 形分支，末端由帽状生后肾组织覆盖。集合管末端陆续诱导生后肾组织内部的细胞团先形成小泡，再演化为 S 形肾小管。肾小管的一端膨大凹陷成双层囊，包绕毛细血管球形成肾小体，另一端与集合管接通，其余部分弯曲延长，逐渐分化成近端小管、细段和远端小管（图 24-6）。集合管末端不断向生后肾组织浅部呈 T 形生长，诱导形成大量肾单位，构成肾皮质。生后肾组织的外周部分形成肾被膜。

:::definition{label="集合管末端的诱导"}
集合管呈 T 形分支，末端由帽状生后肾组织覆盖。末端陆续诱导内部细胞团：先成小泡，再成 S 形肾小管。一端成肾小体，另一端必须与集合管接通，其余弯曲延长成近端小管、细段和远端小管。
:::

:::definition{label="肾单位的来源"}
肾单位来自生后肾组织，不来自输尿管芽。集合管来自输尿管芽，不来自生后肾组织。远曲小管与集合管未接通，就是多囊肾那本账。
:::

:::definition{label="肾皮质与肾被膜（发生）"}
集合管末端不断向生后肾组织浅部呈 T 形生长，诱导形成大量肾单位，构成肾皮质。生后肾组织的外周部分形成肾被膜。
:::

::figure{src="/images/histology/textbook/p0262_01.png" caption="图24-6 集合管与肾单位发生过程示意图。直集合管呈T形分支，浅部弓形集合管末端由帽状生后肾组织覆盖；肾小管一端成肾小囊包绕血管球，另一端通集合管，并分化出近端小管、肾单位袢和远端小管；外周为肾被膜。" alt="集合管树状分支，末端帽状生后肾组织连肾小管，近端小管、袢和远端小管包绕血管球成肾小体"}

人胚第 $12$ 周左右，后肾开始产生尿液，构成羊水的主要来源。由于后肾发生于中肾嵴尾端，故原始位置较低，位于盆腔。后因胎儿的生长、输尿管伸展及胚体直立，肾移至腰部。在肾上升的同时，也沿纵轴旋转，肾门从腹侧转向内侧。

:::definition{label="后肾产尿与羊水"}
人胚第 $12$ 周左右，后肾开始产生尿液，构成羊水的主要来源。此时的尿不是“排泄废物为主”，而是把液体排进羊膜腔。
:::

:::definition{label="肾的上升与旋转"}
后肾发生在中肾嵴尾端，原始位置在盆腔。随后因胎儿生长、输尿管伸展及胚体直立，肾移至腰部；同时沿纵轴旋转，肾门从腹侧转向内侧。上升受阻 → 异位肾；卡在肠系膜下动脉根部、两肾下端融合 → 马蹄肾。
:::

:::concept{term="先问这是前肾、中肾还是后肾，再问后肾里集合管是输尿管芽变的还是肾单位是生后肾组织变的"}
看见肾的发生，先按头尾和时间切三套：颈部生肾节里的前肾第 $4$ 周出现、无功能，小管退化、管保留；中肾嵴里的中肾约 $80$ 对 S 形管加肾小体，后肾出现前可有短暂功能，第 $2$ 个月末大部分退化；中肾嵴尾端的后肾才是永久肾。再问后肾两本账：输尿管芽 → 输尿管、肾盂、肾盏、集合管；生后肾组织 → 肾单位和肾被膜。把三套肾听成“一个肾改了三次名”，或把肾单位写成输尿管芽长出来的，多囊肾和肾缺如都会对错机制。
:::

|------|----------|--------------------------|
| 英文 | ureteric bud | metanephrogenic tissue / blastema |
| 来源 | 中肾管近泄殖腔处向背外侧头端发出的盲管 | 输尿管芽诱导中肾嵴尾端中胚层细胞聚集、包绕 |
| 出现 | 第 $5$ 周初 | 芽长入尾端之后 |
| 分化 | 主干 → 输尿管；末端反复分支 → 肾盂、肾盏、集合管 | 细胞团 → 小泡 → S 形肾小管 → 肾小体 + 近端小管、细段、远端小管；外周 → 肾被膜 |
| 关键一步 | T 形分支，末端诱导帽状组织 | 肾小管另一端必须与集合管接通 |
| 未形成 / 未接通 | 芽未形成或早期退化 → 肾缺如；过早分支或同侧两个芽 → 双输尿管 | 远曲小管与集合管未接通 → 多囊肾 |
:::

:::cause-effect{title="输尿管芽与生后肾组织互相诱导"}
- 因：第 5 周初中肾管近泄殖腔处发出输尿管芽，长入中肾嵴尾端
- 果：周围中胚层聚集包绕，形成生后肾组织
- 因：集合管末端呈 T 形生长并诱导帽状组织内部的细胞团
- 果：小泡 → S 形肾小管 → 肾单位；浅部大量肾单位构成皮质
- 制约：互相诱导缺一不可；无芽则无后肾；小管与集合管未接通则成囊泡
:::

:::pitfall{label="集合管和肾单位不是同一块原基长出来的"}
输尿管芽这一本账走到集合管为止。生后肾组织这一本账走到肾小体和近端小管、细段、远端小管。接通发生在远曲小管与集合管之间。写成“输尿管芽长出整个肾单位”，多囊肾就变成“芽没分好支”，和教材机制对不上。
:::

:::timeline{period="从三套肾到产尿、上升"}
- **第4周初** 颈部生肾节内出现 7～10 对前肾小管，连成前肾管
- **第4周末** 前肾小管退化，前肾管保留并开口于泄殖腔；中肾开始，约 80 对 S 形中肾小管通入中肾管
- **第5周初** 中肾管近泄殖腔处发出输尿管芽，诱导生后肾组织，后肾开始
- **第5～8周** 芽的末端分支成肾盂、肾盏、集合管；帽状组织演化为肾单位
- **第2个月末** 中肾大部分退化，留中肾管和尾端少数中肾小管
- **第12周左右** 后肾开始产尿，构成羊水主要来源；原始位置在盆腔，随后上升至腰部并旋转，肾门转向内侧
:::

:::tip{label="三套肾口诀"}
头段前肾无功能，管子留下改中肾管。中肾 S 形有肾小体，大部分退化留管和少数小管。后肾两块原基：芽造集合系统，帽造肾单位，接通才不囊变。
:::

:::keypoint{label="前肾留管，中肾短暂，后肾两本账互相诱导"}
- 间介中胚层 → 生肾节（颈）/ 生肾索（尾）→ 尿生殖嵴 → 外侧中肾嵴、内侧生殖嵴。
- 前肾：第 $4$ 周，$7\sim 10$ 对前肾小管 + 前肾管；人类无功能；小管退化，管开口泄殖腔。
- 中肾：约 $80$ 对 S 形管 + 肾小体 + 中肾管；后肾出现前可有短暂功能；第 $2$ 个月末大部分退化。
- 后肾 = 输尿管芽（集合系统）+ 生后肾组织（肾单位、被膜）；第 $5$ 周初芽从中肾管近泄殖腔处发出。
- 第 $12$ 周左右产尿，为羊水主要来源；自盆腔上升至腰部，肾门由腹侧转向内侧。
:::

## （二）膀胱和尿道的发生

泄殖腔被尿直肠隔分成腹侧尿生殖窦、背侧原始直肠，是第 $23$ 章已经写过的分隔。膀胱和尿道从尿生殖窦这一侧演变；输尿管的开口还要随中肾管末段并入膀胱而改道。

人胚第 $4\sim 7$ 周，尿直肠隔将泄殖腔分隔为背侧的原始直肠和腹侧的尿生殖窦。泄殖腔膜同时被分割成背侧的肛膜和腹侧的尿生殖膜（见图 23-5）。

膀胱和尿道由尿生殖窦演变形成。尿生殖窦分为 $3$ 段，上段较大，发育为膀胱，起初顶部与脐尿管相连，脐尿管于出生前闭锁，为脐中韧带。中段狭窄，保持管状，形成男性尿道前列腺部、膜部及女性尿道的大部分。下段形成男性尿道海绵体部，在女性扩大为阴道前庭。

输尿管最初开口于中肾管，后者开口于泄殖腔。随着膀胱的发育，输尿管开口以下的一段中肾管并入膀胱。于是，中肾管和输尿管便分别开口于膀胱。

:::definition{label="尿生殖窦（膀胱尿道原基）"}
尿生殖窦是尿直肠隔把泄殖腔分成的腹侧份。膀胱和尿道由它演变形成。背侧那份是原始直肠，不走膀胱户头。
:::

:::definition{label="尿生殖窦上段"}
上段较大，发育为膀胱。起初顶部与脐尿管相连；脐尿管于出生前闭锁，成为脐中韧带。未闭锁则脐尿瘘；仅中段未闭且扩张则脐尿管囊肿。
:::

:::definition{label="尿生殖窦中段"}
中段狭窄，保持管状，形成男性尿道前列腺部、膜部及女性尿道的大部分。
:::

:::definition{label="尿生殖窦下段"}
下段形成男性尿道海绵体部；在女性扩大为阴道前庭。男女不是“下段变成同一条尿道”。
:::

:::definition{label="脐尿管与脐中韧带"}
脐尿管连于膀胱顶部。出生前闭锁，成为脐中韧带。闭锁失败的两种结局见畸形：全段未闭 → 脐尿瘘；仅中段未闭且扩张 → 脐尿管囊肿。
:::

:::definition{label="输尿管与中肾管开口的改道"}
输尿管最初开口于中肾管，中肾管开口于泄殖腔。膀胱发育时，输尿管开口以下的一段中肾管并入膀胱，于是中肾管和输尿管分别开口于膀胱。男性后来中肾管成为输精管等，开口关系在这一步已经分开。
:::

:::concept{term="先问尿生殖窦上中下三段各成什么，再问输尿管是不是一开始就开口在膀胱"}
看见膀胱尿道，先认它们来自腹侧尿生殖窦，不是背侧原始直肠。再问三段：上段膀胱（顶连脐尿管 → 脐中韧带），中段男性尿道前列腺部和膜部、女性尿道大部分，下段男性尿道海绵体部、女性阴道前庭。最后问开口：输尿管起初开在中肾管上，中肾管开在泄殖腔；一段中肾管并入膀胱后，两管才分别开口于膀胱。把下段写成“男女都是尿道”，或把输尿管写成“一开始就通膀胱”，脐尿瘘和射精管开口会对错地点。
:::

:::compare{title="尿生殖窦上、中、下三段"}
| 段 | 形态 | 男性 | 女性 | 相关畸形 |
|----|------|------|------|----------|
| 上段 | 较大 | 膀胱；顶连脐尿管，出生前闭锁为脐中韧带 | 同左（膀胱） | 脐尿管未闭 → 脐尿瘘；中段未闭扩张 → 脐尿管囊肿；腹侧壁无间充质 → 膀胱外翻 |
| 中段 | 狭窄管状 | 尿道前列腺部、膜部 | 尿道的大部分 | — |
| 下段 | 继续延伸或扩大 | 尿道海绵体部 | 扩大为阴道前庭 | 尿生殖褶闭合不全 → 尿道下裂（见第二节） |
:::

:::note{label="见图23-5"}
泄殖腔如何被尿直肠隔分成腹侧尿生殖窦、背侧原始直肠，以及泄殖腔膜分成尿生殖膜和肛膜，见第 $23$ 章图 23-5。本章只接管腹侧这一份来造膀胱和尿道。
:::

:::pitfall{label="输尿管不是一开始就开口于膀胱"}
原初：输尿管 → 中肾管 → 泄殖腔。膀胱长大后，输尿管开口以下的一段中肾管并入膀胱壁，两管才分开开口。写成“输尿管芽直接通膀胱”，双输尿管的开口变化和男性中肾管去路会失去这张迁移图。
:::

:::cause-effect{title="尿直肠隔分开粪、尿，尿生殖窦再分三段"}
- 因：第 4～7 周尿直肠隔分隔泄殖腔
- 果：腹侧尿生殖窦，背侧原始直肠；膜分成尿生殖膜和肛膜
- 因：尿生殖窦分上、中、下三段
- 果：膀胱；男尿道前列腺部与膜部 / 女尿道大部分；男尿道海绵体部 / 女阴道前庭
- 因：输尿管开口以下的中肾管并入膀胱
- 果：中肾管与输尿管分别开口于膀胱
:::

## （三）主要畸形

后肾两本账接通失败、芽没长出来、上升半路停下、脐尿管该闭未闭、膀胱腹侧没铺上间充质，都会写成这一节的名单。只记教材列出的这几项。

### 1. 多囊肾

多囊肾（polycystic kidney）是一种较常见的畸形。在后肾发生过程中，若远曲小管与集合管未接通，尿液便积聚在肾小管内，使肾内出现大小不等的囊泡（图 24-7A，图 24-8）。囊泡可压迫周围正常的肾单位使其萎缩，导致肾功能进一步下降。

:::definition{label="多囊肾"}
多囊肾（polycystic kidney）是较常见的畸形。机制：后肾发生过程中远曲小管与集合管未接通，尿液积在肾小管内，肾内出现大小不等的囊泡。囊泡压迫周围正常肾单位使其萎缩，肾功能进一步下降。
:::

:::note{label="图24-8 近足月人胎多囊肾"}
教材图 24-8 为近足月人胎多囊肾（剖面）。原图未能收入数字版；囊泡与周围肾单位的关系对照见图 24-7A。正文仍保留“图 24-7A，图 24-8”出处。
:::

### 2. 肾缺如

肾缺如（agenesis of kidney）因输尿管芽未形成或早期退化，不能诱导后肾发生，导致肾缺如。以单侧多见，多无临床症状。

:::definition{label="肾缺如"}
肾缺如（agenesis of kidney）因输尿管芽未形成或早期退化，不能诱导后肾发生。以单侧多见，多无临床症状。没有芽，生后肾组织启动不了。
:::

### 3. 异位肾

异位肾（ectopic kidney）由于肾上升过程受阻所致的肾位置异常，常停留在盆腔，与肾上腺分离（图 24-7B）。

:::definition{label="异位肾"}
异位肾（ectopic kidney）是肾上升过程受阻所致的位置异常，常停留在盆腔，与肾上腺分离。它不是肾缺如，肾还在，只是没升到腰部。
:::

### 4. 马蹄肾

马蹄肾（horseshoe kidney）肾在上升过程中受阻于肠系膜下动脉根部，两肾下端融合呈马蹄形（图 24-7C）。

:::definition{label="马蹄肾"}
马蹄肾（horseshoe kidney）因上升时受阻于肠系膜下动脉根部，两肾下端融合呈马蹄形。卡住的是下端，不是“两肾没发生”。
:::

### 5. 双输尿管

双输尿管（double ureter）输尿管芽过早分支或同侧发生两个输尿管芽，形成双输尿管。一侧肾有两个肾盂，各连一条输尿管。两条输尿管或分别开口于膀胱，或合并后开口于膀胱。

:::definition{label="双输尿管"}
双输尿管（double ureter）因输尿管芽过早分支，或同侧发生两个输尿管芽。一侧肾有两个肾盂，各连一条输尿管；两条输尿管或分别开口于膀胱，或合并后开口于膀胱。
:::

### 6. 脐尿瘘

脐尿瘘（urachal fistula）由于脐尿管未闭锁，出生后尿液从脐部溢出，称脐尿瘘（图 24-7D）。若仅脐尿管中段未闭锁且扩张，称脐尿管囊肿（urachal cyst）。

:::definition{label="脐尿瘘"}
脐尿瘘（urachal fistula）因脐尿管未闭锁，出生后尿液从脐部溢出。
:::

:::definition{label="脐尿管囊肿"}
脐尿管囊肿（urachal cyst）是仅脐尿管中段未闭锁且扩张。它不是全段通到脐部的瘘。
:::

### 7. 膀胱外翻

膀胱外翻（exstrophy of bladder）由于尿生殖窦与表面外胚层之间未出现间充质，膀胱腹侧壁与脐下腹壁之间无肌肉发生，致使表皮和膀胱前壁破裂，膀胱黏膜外翻。

:::definition{label="膀胱外翻"}
膀胱外翻（exstrophy of bladder）因尿生殖窦与表面外胚层之间未出现间充质，膀胱腹侧壁与脐下腹壁之间无肌肉发生，表皮和膀胱前壁破裂，膀胱黏膜外翻。它不是脐尿管未闭。
:::

::figure{src="/images/histology/textbook/p0263_01.png" caption="图24-7 泌尿系统主要畸形模式图。A. 多囊肾；B. 异位肾；C. 马蹄肾；D. 脐尿瘘。" alt="四图：A 肾内多发囊泡，B 肾留在盆腔与肾上腺分离，C 两肾下端融合卡在肠系膜下动脉，D 脐尿管未闭尿液从脐溢出"}

:::concept{term="先问是接通失败、芽缺失、上升受阻，还是脐尿管、腹壁间充质的问题"}
看见泌尿畸形，先对机制：远曲小管与集合管未接通 → 多囊肾；芽未形成或早退化 → 肾缺如；上升受阻停在盆腔 → 异位肾；卡在肠系膜下动脉根部、下端融合 → 马蹄肾；芽过早分支或同侧两个芽 → 双输尿管；脐尿管未闭 → 脐尿瘘，仅中段未闭扩张 → 囊肿；尿生殖窦与外胚层之间无间充质 → 膀胱外翻。把马蹄肾听成“两个肾缺如后粘在一起”，或把脐尿瘘写成膀胱外翻，七张名单会并成一句“肾不好”。
:::

:::compare{title="泌尿系统主要畸形"}
| 畸形 | 英文 | 停在哪一步 | 结果 |
|------|------|------------|------|
| 多囊肾 | polycystic kidney | 远曲小管与集合管未接通 | 肾小管积尿成囊泡，压迫正常肾单位 |
| 肾缺如 | agenesis of kidney | 输尿管芽未形成或早期退化 | 不能诱导后肾；单侧多见，多无症状 |
| 异位肾 | ectopic kidney | 上升受阻 | 常留盆腔，与肾上腺分离 |
| 马蹄肾 | horseshoe kidney | 上升时受阻于肠系膜下动脉根部 | 两肾下端融合呈马蹄形 |
| 双输尿管 | double ureter | 芽过早分支或同侧两个芽 | 一侧两个肾盂各连一条输尿管 |
| 脐尿瘘 | urachal fistula | 脐尿管未闭锁 | 尿液从脐部溢出 |
| 脐尿管囊肿 | urachal cyst | 仅中段未闭锁且扩张 | 中段囊性扩张，不是全段瘘 |
| 膀胱外翻 | exstrophy of bladder | 尿生殖窦与表面外胚层之间无间充质 | 腹侧无肌肉，表皮和膀胱前壁破裂，黏膜外翻 |
:::

:::pitfall{label="异位肾是位置不对，肾缺如是肾没发生，马蹄肾是两肾下端融合"}
异位肾常在盆腔，肾上腺还在原位所以“与肾上腺分离”。肾缺如是芽没有诱导出后肾。马蹄肾已经有两个肾，只是上升时被肠系膜下动脉根部挡住、下端连成马蹄。三句话不要并成“肾长错地方”。
:::

:::pitfall{label="脐尿瘘是脐尿管未闭，膀胱外翻是腹侧没长肌肉"}
脐部漏尿，先问脐尿管闭没闭。黏膜翻到腹壁外，问的是尿生殖窦与外胚层之间有没有间充质、有没有腹壁肌。写成“膀胱外翻就是脐尿管通到外面”，两种畸形的原基会对成一个。
:::

:::cause-effect{title="后肾两本账、上升路线和脐尿管，决定畸形落在哪一张名单"}
- 因：远曲小管与集合管未接通
- 果：多囊肾
- 因：输尿管芽未形成或早期退化
- 果：不能诱导后肾，肾缺如
- 因：上升受阻
- 果：异位肾（常在盆腔）；若卡在肠系膜下动脉根部且下端融合，则为马蹄肾
- 因：脐尿管未闭锁，或仅中段未闭扩张
- 果：脐尿瘘或脐尿管囊肿
- 制约：膀胱外翻另走腹侧间充质缺失，不是脐尿管这本账
:::

:::insight{label="畸形就是正常发生停在半路"}
接通、诱导、上升、闭锁、铺上腹壁肌，每一步都有对应的畸形。把七项背成孤立病名，后肾两本账和尿生殖窦三段会失去对照；按停在哪一步来认，名单可以从发生过程里推出来。
:::

:::keypoint{label="多囊肾对未接通，肾缺如对无芽，位置对上升，脐部对脐尿管"}
- 多囊肾：远曲小管 × 集合管未接通；囊泡压迫正常肾单位。
- 肾缺如：无输尿管芽或早退化；单侧多见。
- 异位肾：上升受阻，常在盆腔，与肾上腺分离。
- 马蹄肾：肠系膜下动脉根部受阻，下端融合。
- 双输尿管：芽过早分支或同侧两芽；两肾盂两条管。
- 脐尿瘘 / 脐尿管囊肿：全段未闭漏尿 / 仅中段未闭扩张。
- 膀胱外翻：尿生殖窦与外胚层之间无间充质，腹侧无肌肉，黏膜外翻。
:::

:::memory{label="本节必背要点"}
- [ ] 胚胎发育的第 $4$ 周初，胚内中胚层由脊索向外依次分化为轴旁中胚层、间介中胚层和侧中胚层。
- [ ] 泌尿系统和生殖系统的主要器官均起源于间介中胚层。
- [ ] 颈部间介中胚层呈节段性生长，称生肾节（nephrotome）；尾段增生形成两条纵行细胞索，称生肾索（nephrogenic cord）。
- [ ] 第 $4$ 周末生肾索继续增生、与体节分离，凸向胚内体腔，成为尿生殖嵴（urogenital ridge），是泌尿和生殖系统发生的原基。
- [ ] 尿生殖嵴被纵沟分为外侧粗而长的中肾嵴（mesonephric ridge）和内侧细而短的生殖嵴（genital ridge）。
- [ ] 人胚肾的发生分 $3$ 个阶段，从颈部至腰骶部相继出现前肾、中肾和后肾。
- [ ] 前肾（pronephros）：第 $4$ 周初颈部生肾节内出现 $7\sim 10$ 对前肾小管（pronephric tubule），外侧端连成前肾管（pronephric duct）。
- [ ] 人类前肾无泌尿功能；第 $4$ 周末前肾小管退化，前肾管大部分保留并向尾部延伸，开口于泄殖腔。
- [ ] 中肾（mesonephros）：生肾索及中肾嵴内约 $80$ 对中肾小管（mesonephric tubule）延长为 S 形，内侧成肾小体，外侧通入改称后的中肾管（mesonephric duct）。
- [ ] 人的中肾在后肾出现之前可有短暂功能；第 $2$ 个月末除中肾管和尾端少数中肾小管保留外，中肾大部分退化。
- [ ] 后肾（metanephros）为人体永久肾，由输尿管芽与生后肾组织互相诱导、共同分化而成。
- [ ] 第 $5$ 周初，中肾管近泄殖腔处向背外侧头端发出输尿管芽（ureteric bud）。
- [ ] 输尿管芽长入中肾嵴尾端，诱导形成生后肾组织（metanephrogenic tissue），又称生后肾原基（metanephrogenic blastema）。
- [ ] 输尿管芽主干分化成输尿管，末端反复分支形成肾盂、肾盏和集合管。
- [ ] 集合管呈 T 形分支，末端诱导生后肾组织：细胞团 → 小泡 → S 形肾小管 → 肾小体 + 近端小管、细段、远端小管。
- [ ] 集合管末端向浅部生长，诱导大量肾单位构成肾皮质；生后肾组织外周形成肾被膜。
- [ ] 第 $12$ 周左右后肾开始产尿，构成羊水的主要来源。
- [ ] 后肾原始位置在盆腔，随后上升至腰部并沿纵轴旋转，肾门从腹侧转向内侧。
- [ ] 第 $4\sim 7$ 周尿直肠隔将泄殖腔分为背侧原始直肠和腹侧尿生殖窦（见图 23-5）。
- [ ] 尿生殖窦上段发育为膀胱，顶部脐尿管出生前闭锁为脐中韧带。
- [ ] 中段形成男性尿道前列腺部、膜部及女性尿道的大部分；下段形成男性尿道海绵体部，在女性扩大为阴道前庭。
- [ ] 输尿管最初开口于中肾管；输尿管开口以下的一段中肾管并入膀胱后，中肾管和输尿管分别开口于膀胱。
- [ ] 多囊肾（polycystic kidney）：远曲小管与集合管未接通，肾小管积尿成囊泡，压迫周围肾单位。
- [ ] 肾缺如（agenesis of kidney）：输尿管芽未形成或早期退化；单侧多见，多无临床症状。
- [ ] 异位肾（ectopic kidney）：上升受阻，常停留盆腔，与肾上腺分离。
- [ ] 马蹄肾（horseshoe kidney）：上升受阻于肠系膜下动脉根部，两肾下端融合。
- [ ] 双输尿管（double ureter）：芽过早分支或同侧两个芽；一侧两个肾盂各连一条输尿管。
- [ ] 脐尿瘘（urachal fistula）：脐尿管未闭锁，尿液从脐部溢出；仅中段未闭扩张为脐尿管囊肿（urachal cyst）。
- [ ] 膀胱外翻（exstrophy of bladder）：尿生殖窦与表面外胚层之间未出现间充质，腹侧无肌肉，表皮和膀胱前壁破裂，黏膜外翻。
:::
