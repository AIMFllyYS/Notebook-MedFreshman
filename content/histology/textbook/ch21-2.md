# 二、胚泡的形成和植入

受精卵一旦形成，便开始向子宫方向移行，并做一种很特殊的有丝分裂：子细胞被透明带包裹，分裂间期无生长，细胞越分越小。第 $3$ 天变成实心的桑葚胚，第 $4$ 天在宫腔里形成中空的胚泡，第 $5\sim 6$ 天开始植入，第 $11\sim 12$ 天完成。本节把卵裂、桑葚胚、胚泡、内细胞群、滋养层和植入（着床）摊开。受精三阶段和原核融合见上一节。

## （一）卵裂和胚泡的形成

受精卵一边向子宫移行，一边进行细胞分裂。由于子细胞被透明带包裹，在分裂间期无生长过程，仅原受精卵的细胞质被不断分到子细胞中，因而随着细胞数目增加，细胞体积逐渐变小。受精卵的这种特殊的有丝分裂过程称卵裂（cleavage），卵裂产生的子细胞称卵裂球（blastomere）。

:::definition{label="卵裂"}
卵裂（cleavage）是受精卵的特殊有丝分裂：子细胞被透明带包裹，间期不生长，只把原受精卵的细胞质不断分到子细胞中，结果是数目增加、体积变小。
:::

:::definition{label="卵裂球"}
卵裂球（blastomere）是卵裂产生的子细胞。它们暂时仍包在透明带里，尚未分区为内细胞群或滋养层。
:::

:::concept{term="先问还在不在透明带里，再问是实心桑葚胚还是已经出现胚泡腔"}
离开受精卵，先不要写成“普通细胞分裂、细胞越长越大”。先问透明带在不在：在，细胞质只能越分越薄，这叫卵裂。再问细胞之间有没有汇合成一个大腔：没有腔、外观像桑葚，是桑葚胚；有腔、壁是单层滋养层、一侧堆着内细胞群，才叫胚泡。把卵裂听成“胚胎在长大”，或把桑葚胚听成“已经中空的胚泡”，植入那本账会提前几天。
:::

第 $3$ 天，卵裂球数达 $12\sim 16$ 个，共同组成一个实心胚，外观如桑葚，故称桑葚胚（morula）（图 21-2，图 21-3）。

:::definition{label="桑葚胚"}
桑葚胚（morula，亦作桑椹胚）出现于受精后第 $3$ 天。卵裂球数达 $12\sim 16$ 个，共同组成一个实心胚，外观如桑葚。此时仍被透明带包裹，还没有胚泡腔。
:::

第 $4$ 天，桑葚胚进入子宫腔，其细胞继续分裂，当卵裂球数达到 $100$ 个左右时，细胞间出现若干小的腔隙，它们逐渐汇合成一个腔，腔内充满来自子宫腔内的液体。此时透明带溶解，胚呈囊泡状，故称胚泡（blastocyst）。胚泡中心为胚泡腔（blastocyst cavity）。胚泡壁由单层细胞构成，与吸收营养有关，称滋养层（trophoblast）。位于胚泡腔内一侧的一群细胞，称内细胞群（inner cell mass），细胞具有多种分化潜能（图 21-2、图 21-3）。位于内细胞群一端的滋养层称极端滋养层（polar trophoblast），又称胚端滋养层，其覆盖于内细胞群的表面，细胞胞体略大于其他部位的滋养层细胞。极端滋养层与胚泡植入有关。

:::definition{label="胚泡"}
胚泡（blastocyst）在第 $4$ 天形成：桑葚胚进入子宫腔，卵裂球约达 $100$ 个，细胞间小腔隙汇合成腔，透明带溶解，胚呈囊泡状。
:::

:::definition{label="胚泡腔"}
胚泡腔（blastocyst cavity）是胚泡中心的腔，由卵裂球之间的小腔隙逐渐汇合而成，腔内充满来自子宫腔的液体。
:::

:::definition{label="滋养层"}
滋养层（trophoblast）构成胚泡壁，为单层细胞，与吸收营养有关。它不是内细胞群，将来主要参与胚外结构（如绒毛膜）的形成。
:::

:::definition{label="内细胞群"}
内细胞群（inner cell mass）是位于胚泡腔内一侧的一群细胞，具有多种分化潜能。胚盘、进而人体，主要从这里发生。
:::

:::definition{label="极端滋养层"}
极端滋养层（polar trophoblast）又称胚端滋养层，是覆盖于内细胞群表面的那一端滋养层。胞体略大于其他部位的滋养层细胞，植入时首先与子宫内膜上皮接触并黏附。
:::

:::

:::compare{title="内细胞群、滋养层与极端滋养层"}
| 项目 | 内细胞群 | 滋养层 | 极端滋养层 |
|------|----------|--------|------------|

:::

:::pitfall{label="卵裂不是普通的“细胞分裂后长大”，桑葚胚也还没有腔"}
透明带把子细胞箍住，间期不生长，所以卵裂球越分越小。桑葚胚是 $12\sim 16$ 个细胞的实心团；胚泡要等到约 $100$ 个细胞、小腔汇合成胚泡腔、透明带溶解之后才成立。把第 $3$ 天的桑葚胚写成“已经着床的囊胚”，植入的日期会整体提前。
:::

:::timeline{period="从合子到胚泡"}
- **受精完成** 二倍体受精卵（合子）形成，开始向子宫方向移行
- **卵裂** 透明带内特殊有丝分裂，间期不生长，卵裂球体积渐小
- **第 $3$ 天** $12\sim 16$ 个卵裂球组成实心桑葚胚
- **第 $4$ 天** 进入子宫腔；约 $100$ 个细胞时出现胚泡腔，透明带溶解，形成胚泡（滋养层 + 内细胞群 + 极端滋养层）
:::

:::insight{label="透明带一直箍到胚泡才解开，既限制卵裂球长大，又决定何时能植入"}
受精时透明带是 ZP3 的门和单精的锁；卵裂时它把子细胞包成一团，逼出“只分裂不生长”；到胚泡才溶解，极端滋养层才能贴上内膜。提前脱掉或迟迟不脱，都会让卵裂形态和植入窗口对不上。
:::

## （二）植入

胚泡进入子宫内膜的过程称植入（implantation），又称着床（nidation）。植入于受精后第 $5\sim 6$ 天开始，第 $11\sim 12$ 天完成。植入时，内细胞群一侧的极端滋养层首先与子宫内膜上皮接触并黏附，分泌蛋白水解酶，在内膜溶蚀出一个缺口，然后胚泡陷入缺口，逐渐被包埋其中（图 21-5，图 21-6）。

:::definition{label="植入"}
植入（implantation）又称着床（nidation），指胚泡进入子宫内膜的过程。受精后第 $5\sim 6$ 天开始，第 $11\sim 12$ 天完成。
:::

:::concept{term="先问哪一端先贴内膜，再问滋养层分成了几层"}
看见胚泡要“钻进子宫”，先找内细胞群那一端——极端滋养层先黏附、先分泌蛋白水解酶、先溶蚀缺口。再问与内膜接触的滋养层有没有分成两层：外层细胞融合、界线消失，是合体滋养层；内层立方、界线清楚，是细胞滋养层。把植入听成“整个胚泡平均往下沉”，或把两层滋养层写成“内外皮对调”，蜕膜和陷窝都会认错。
:::

在植入过程中，与内膜接触的滋养层细胞迅速增殖，滋养层增厚，并分化为内、外两层。外层细胞互相融合，细胞间界线（即细胞膜）消失，称合体滋养层（syncytiotrophoblast）；内层细胞界限清楚，由单层立方细胞组成，称细胞滋养层（cytotrophoblast）。后者的细胞通过分裂使细胞数目不断增多，并补充、融入合体滋养层。

:::definition{label="合体滋养层"}
合体滋养层（syncytiotrophoblast）是滋养层的外层。细胞互相融合，细胞间界线（细胞膜）消失。它直接侵蚀内膜，其内随后出现滋养层陷窝。
:::

:::definition{label="细胞滋养层"}
细胞滋养层（cytotrophoblast）是滋养层的内层。细胞界限清楚，由单层立方细胞组成；通过分裂增加数目，并补充、融入合体滋养层。
:::

胚泡全部植入子宫内膜后，缺口修复，植入完成。这时胚泡的整个滋养层均分化为两层，并迅速增厚。在合体滋养层内出现一些小的腔隙，称滋养层陷窝（trophoblastic lacuna），不久与子宫内膜的小血管相通而充满母体血液（图 21-6）。

:::definition{label="滋养层陷窝"}
滋养层陷窝（trophoblastic lacuna）是合体滋养层内的小腔隙。植入完成后不久与子宫内膜小血管相通，充满母体血液，是胚早期从母血取营养的空间。
:::

:::compare{title="合体滋养层与细胞滋养层"}
| 项目 | 合体滋养层 | 细胞滋养层 |
|------|------------|------------|
| 位置 | 外层，直接接触内膜 | 内层 |
| 细胞界线 | 融合，细胞膜消失 | 界限清楚 |
| 形态 | 多核合体 | 单层立方细胞 |
| 增殖 | 自身不靠普通分裂扩增 | 分裂使数目增多，并融入外层 |
| 腔隙 | 内有滋养层陷窝，通母体血管 | 无陷窝 |
:::

:::pitfall{label="合体滋养层在外、细胞滋养层在内，不要写成“合体在里保护胚胎”"}
外层融合、侵蚀内膜、开陷窝接母血；内层立方、界线清楚，负责分裂补充外层。把“合体”听成“里面那层合在一起的胚体”，内细胞群和滋养层两本账会对调。
:::

植入时的子宫内膜正处于分泌期，植入后内膜进一步增厚，血液供应更丰富，腺体分泌更旺盛，基质细胞变得十分肥大，富含糖原和脂滴。子宫内膜的这些变化称蜕膜反应（decidua reaction），此时的子宫内膜改称蜕膜（decidua），基质细胞改称蜕膜细胞。根据蜕膜与胚的位置关系，将其分为 $3$ 部分：① 基蜕膜（decidua basalis），位于胚与子宫肌层之间；② 包蜕膜（decidua capsularis），覆盖在胚的子宫腔侧；③ 壁蜕膜（decidua parietalis），是子宫壁其余部分的蜕膜（图 21-7）。

:::definition{label="蜕膜反应"}
蜕膜反应（decidua reaction）指植入后子宫内膜进一步增厚，血供更丰富，腺体分泌更旺盛，基质细胞十分肥大并富含糖原和脂滴。植入时内膜本已处于分泌期，蜕膜反应是在此基础上再推进一步。
:::

:::definition{label="蜕膜"}
蜕膜（decidua）是发生蜕膜反应之后的子宫内膜。其中的基质细胞改称蜕膜细胞。
:::

:::definition{label="基蜕膜"}
基蜕膜（decidua basalis）位于胚与子宫肌层之间，是将来胎盘母体部的地盘。
:::

:::definition{label="包蜕膜"}
包蜕膜（decidua capsularis）覆盖在胚的子宫腔侧，把胚与子宫腔隔开。
:::

:::definition{label="壁蜕膜"}
壁蜕膜（decidua parietalis）是子宫壁其余部分的蜕膜，既不夹在胚与肌层之间，也不包在胚的宫腔面。
:::

| 项目 | 基蜕膜 | 包蜕膜 | 壁蜕膜 |
|------|--------|--------|--------|
| 位置 | 胚与子宫肌层之间 | 覆盖在胚的子宫腔侧 | 子宫壁其余部分 |
| 与胚的关系 | 底侧，将来参与胎盘 | 宫腔面的“盖子” | 不直接贴在胚上 |
| 不要听成 | 包在胚外面的那一层 | 胚与肌层之间的底 | 基蜕膜的别名 |

胚泡的植入部位通常在子宫的体部和底部，最多见于后壁。若植入位于近子宫颈处，在此形成的胎盘称前置胎盘（placenta praevia），自然分娩时堵塞产道，导致胎儿娩出困难，需行剖宫产。若植入在子宫以外部位，称异位妊娠（ectopic pregnancy），常发生在输卵管，偶见于子宫阔韧带、肠系膜、子宫直肠陷窝，甚至卵巢表面（图 21-8）。异位妊娠胚胎多因营养供应不足导致早期死亡，后被吸收；少数植入输卵管的胚胎发育较大后，引起输卵管破裂和大出血。

:::definition{label="正常植入部位"}
通常在子宫的体部和底部，最多见于后壁。这是分泌期内膜允许极端滋养层黏附、溶蚀并包埋的常规地点。
:::

:::definition{label="前置胎盘"}
前置胎盘（placenta praevia）指植入位于近子宫颈处，胎盘在此形成。自然分娩时堵塞产道，导致胎儿娩出困难，需行剖宫产。它仍在子宫内，不是异位妊娠。
:::

:::definition{label="异位妊娠"}
异位妊娠（ectopic pregnancy）指植入在子宫以外部位。常发生在输卵管，偶见于子宫阔韧带、肠系膜、子宫直肠陷窝，甚至卵巢表面。胚胎多因营养不足早期死亡后被吸收；少数输卵管妊娠发育较大后引起破裂和大出血。
:::

| 项目 | 正常植入 | 前置胎盘 | 异位妊娠 |
|------|----------|----------|----------|
| 部位 | 子宫体部和底部，最多见于后壁 | 近子宫颈处（仍在子宫内） | 子宫以外：输卵管最常见，偶见于阔韧带、肠系膜、子宫直肠陷窝、卵巢表面 |
| 主要后果 | 蜕膜反应，继续发育 | 分娩时堵塞产道，需剖宫产 | 多早期死亡被吸收；输卵管者可破裂大出血 |
| 不要听成 | 可以随便种在宫颈 | 一种异位妊娠 | 种在宫颈的胎盘 |
:::

:::pitfall{label="前置胎盘还在子宫里，异位妊娠才是种到子宫以外"}
近宫颈是位置偏低的子宫内植入，危险在分娩堵塞产道。输卵管、阔韧带、肠系膜、子宫直肠陷窝、卵巢表面才叫异位。把前置胎盘写成“宫颈的宫外孕”，两本临床账会对串。
:::

植入过程受母体雌激素和孕激素的精细调节，这些激素的正常分泌使子宫内膜保持在分泌期。若母体内分泌紊乱，子宫内膜的周期性变化与胚泡发育不同步，植入便不能完成。胚泡的植入还需要有正常的子宫腔内环境。子宫有炎症或有避孕环，均可阻碍胚泡植入。

:::note{label="植入还要内膜时钟和宫腔环境都对上"}
雌激素和孕激素把内膜维持在分泌期，才允许极端滋养层黏附和溶蚀。内膜周期与胚泡发育不同步，植入完不成。宫腔内若有炎症或避孕环，同样阻碍植入。避孕环打断的是“正常宫腔环境”这一条，不是切断输卵管。
:::

:::insight{label="极端滋养层带着内细胞群先钻进去，所以将来的胚盘朝向有母血的一侧"}
植入不是胚泡随便滚进缺口。内细胞群一端的极端滋养层先贴上皮、先打孔，合体滋养层再开陷窝接通母血。胚的方向从这一刻就定了：内细胞群对着植入极。把植入写成“滋养层整圈同时钻”，二胚层胚盘的背腹方向会失去来源。
:::

:::timeline{period="从桑葚胚到植入完成"}
- **第 $3$ 天** 桑葚胚（$12\sim 16$ 细胞，实心）
- **第 $4$ 天** 入宫腔，透明带溶解，胚泡形成
- **第 $5\sim 6$ 天** 植入开始：极端滋养层黏附内膜，蛋白水解酶溶蚀缺口
- **第 $7$ 天** 植入早期（图 21-6A）
- **第 $8$ 天** 滋养层明显分层，羊膜腔等开始出现（图 21-6B）
- **第 $9$ 天** 植入后期，陷窝等结构推进（图 21-6C）
- **第 $11\sim 12$ 天** 缺口修复，植入完成；整个滋养层分两层，陷窝通母血（图 21-6D）
:::

:::keypoint{label="第3天桑葚、第4天胚泡、第5–6天开钻、第11–12天封口"}
- 卵裂：透明带内只分裂不生长，卵裂球越分越小。
- 第 $3$ 天桑葚胚（$12\sim 16$ 细胞，实心）；第 $4$ 天胚泡（约 $100$ 细胞，有腔，透明带溶解）。
- 胚泡 = 滋养层（壁，营养）+ 内细胞群（潜能）+ 胚泡腔；极端滋养层覆盖内细胞群，负责先贴内膜。
- 植入又称着床：第 $5\sim 6$ 天开始，第 $11\sim 12$ 天完成。
- 滋养层外合体、内细胞；细胞滋养层分裂补充合体滋养层；合体内陷窝通母血。
- 分泌期内膜发生蜕膜反应 → 蜕膜；基蜕膜、包蜕膜、壁蜕膜按与胚的位置三分。
- 正常种在体部、底部，最多后壁；近宫颈 → 前置胎盘；子宫以外 → 异位妊娠。
- 植入依赖雌激素和孕激素维持分泌期，也依赖正常宫腔环境。
:::

:::memory{label="本节必背要点"}
- [ ] 受精卵向子宫方向移行并进行细胞分裂。
- [ ] 卵裂（cleavage）：子细胞被透明带包裹，分裂间期无生长，细胞质不断分到子细胞中，数目增加而体积变小。
- [ ] 卵裂产生的子细胞称卵裂球（blastomere）。
- [ ] 第 $3$ 天卵裂球达 $12\sim 16$ 个，组成实心胚，外观如桑葚，称桑葚胚（morula，亦作桑椹胚）。
- [ ] 第 $4$ 天桑葚胚进入子宫腔，细胞继续分裂。
- [ ] 卵裂球约达 $100$ 个时，细胞间小腔隙汇合成腔，腔内充满来自子宫腔的液体。
- [ ] 透明带溶解，胚呈囊泡状，称胚泡（blastocyst）；中心为胚泡腔（blastocyst cavity）。
- [ ] 滋养层（trophoblast）是胚泡壁的单层细胞，与吸收营养有关。
- [ ] 内细胞群（inner cell mass）位于胚泡腔内一侧，具有多种分化潜能。
- [ ] 极端滋养层（polar trophoblast）又称胚端滋养层，覆盖内细胞群表面，胞体略大，与植入有关。
- [ ] 植入（implantation）又称着床（nidation），指胚泡进入子宫内膜。
- [ ] 植入于受精后第 $5\sim 6$ 天开始，第 $11\sim 12$ 天完成。
- [ ] 极端滋养层首先与子宫内膜上皮接触并黏附，分泌蛋白水解酶，溶蚀缺口，胚泡陷入并被包埋。
- [ ] 与内膜接触的滋养层迅速增殖、增厚，分化为内、外两层。
- [ ] 合体滋养层（syncytiotrophoblast）：外层，细胞融合，细胞膜消失。
- [ ] 细胞滋养层（cytotrophoblast）：内层，单层立方，界限清楚；分裂增多并融入合体滋养层。
- [ ] 胚泡全部植入后缺口修复，植入完成；整个滋养层均分化为两层并迅速增厚。
- [ ] 滋养层陷窝（trophoblastic lacuna）出现于合体滋养层内，不久与内膜小血管相通而充满母体血液。
- [ ] 植入时子宫内膜处于分泌期。
- [ ] 蜕膜反应（decidua reaction）：植入后内膜更厚、血供更丰富、腺体分泌更旺盛，基质细胞肥大并富含糖原和脂滴。
- [ ] 此时子宫内膜改称蜕膜（decidua），基质细胞改称蜕膜细胞。
- [ ] 基蜕膜（decidua basalis）位于胚与子宫肌层之间。
- [ ] 包蜕膜（decidua capsularis）覆盖在胚的子宫腔侧。
- [ ] 壁蜕膜（decidua parietalis）是子宫壁其余部分的蜕膜。
- [ ] 植入部位通常在子宫体部和底部，最多见于后壁。
- [ ] 前置胎盘（placenta praevia）：植入近子宫颈处，分娩时堵塞产道，需剖宫产。
- [ ] 异位妊娠（ectopic pregnancy）：植入在子宫以外，常在输卵管，偶见于阔韧带、肠系膜、子宫直肠陷窝甚至卵巢表面。
- [ ] 异位妊娠胚胎多因营养不足早期死亡后被吸收；少数输卵管妊娠可破裂大出血。
- [ ] 植入受母体雌激素和孕激素精细调节，激素正常分泌使内膜保持在分泌期。
- [ ] 内分泌紊乱导致内膜周期与胚泡发育不同步，植入不能完成。
- [ ] 植入需要正常子宫腔内环境；子宫炎症或避孕环均可阻碍植入。
:::
