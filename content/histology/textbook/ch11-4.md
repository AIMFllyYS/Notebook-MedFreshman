# 四、皮肤再生

皮肤再生分为生理性再生和代偿性再生，前者为正常情况下的表皮增殖、角化和脱落，皮肤附属器的周期性生长变化以及真皮成分的自我更新过程；后者为皮肤受损后的再生和修复。第一节把角质形成细胞 $3\sim 4$ 周更新写进表皮，第三节把毛的生长周期写进附属器，那些都属于生理性再生；本节把损伤后的代偿性再生摊开，并收口全章。

:::definition{label="皮肤再生"}
皮肤再生分为生理性再生和代偿性再生。生理性再生是正常情况下表皮增殖、角化和脱落，附属器周期性生长变化以及真皮成分的自我更新；代偿性再生是皮肤受损后的再生和修复。
:::

:::definition{label="生理性再生"}
生理性再生包括：表皮角质形成细胞不断增殖、迁移、角化并脱落（周期 $3\sim 4$ 周）；毛等附属器按生长周期更新；真皮纤维和基质的自我更新。
:::

:::definition{label="代偿性再生"}
代偿性再生是皮肤受损后的再生和修复。过程和时间依损伤面积和深度而异。
:::

:::concept{term="先问损伤有多深、面积有多大"}
浅而小的缺口，基底层还在，数天即可修复、不留瘢痕。深而大的缺口，表皮干细胞要靠残存毛囊和汗腺导管支援，真皮侧先走凝血–巨噬细胞–肉芽组织这条路。伤处既无残存附属器、创缘又隔得太远，就必须植皮。把“皮肤都能再生”写成无条件结论，会漏掉植皮和瘢痕两本账。
:::

:::compare{title="生理性再生与代偿性再生"}
| 项目 | 生理性再生 | 代偿性再生 |
|------|------------|------------|
| 前提 | 皮肤未受明显损伤 | 皮肤受损 |
| 表皮 | 基底层增殖 → 角化 → 脱落，周期 $3\sim 4$ 周 | 创缘角质形成细胞移行；残存毛囊、汗腺导管提供干细胞，形成上皮小岛 |
| 附属器 | 毛等按生长周期更新 | 深部损伤若附属器被毁，则失去这一干细胞来源 |
| 真皮 | 成分自我更新 | 先成肉芽组织，后可被瘢痕组织取代 |
| 结局 | 维持正常厚度和屏障 | 浅表小创不留瘢痕；深大创可留瘢痕，过深过大常需植皮 |
:::

皮肤损伤后修复的过程和时间依损伤面积和深度的不同而异。小面积浅表损伤数天即可修复，不留瘢痕。较大面积和较深的损伤，创伤处首先发生凝血，随之单核细胞进入组织，分化为巨噬细胞，清除组织碎片，同时分泌趋化因子吸引成纤维细胞和血管内皮细胞至损伤处，成纤维细胞产生纤维和基质，充填缺损部，毛细血管长入其中，此种富含毛细血管的新生组织称肉芽组织。损伤边缘的角质形成细胞逐渐移行至肉芽组织表面，同时，残存的毛囊和汗腺导管上皮也可提供表皮再生的干细胞，并在局部形成上皮小岛。从而新生表皮的基底细胞继续增生分化形成各层细胞，直至填补缺损。倘若损伤面积过大过深，如大面积烧伤，伤处无残存的毛囊和汗腺，伤口边缘又相距太远，常需植皮以协助修复。修复后的肉芽组织，胶原纤维逐渐形成粗纤维束，细胞成分和血管减少，被瘢痕组织取代。此时，肉眼观呈灰白色，质地坚韧，缺乏弹性。

:::definition{label="肉芽组织"}
较大面积和较深的损伤处，成纤维细胞产生纤维和基质充填缺损，毛细血管长入其中，此种富含毛细血管的新生组织称肉芽组织。
:::

:::definition{label="上皮小岛"}
残存的毛囊和汗腺导管上皮可提供表皮再生的干细胞，在肉芽组织表面局部形成上皮小岛，与创缘迁来的角质形成细胞一起，使新生表皮基底细胞增生分化，填补缺损。
:::

:::definition{label="瘢痕组织"}
修复后的肉芽组织中，胶原纤维逐渐形成粗纤维束，细胞成分和血管减少，被瘢痕组织取代。肉眼观呈灰白色，质地坚韧，缺乏弹性。
:::

:::note{label="代偿性再生的顺序"}
| 步骤 | 过程 |
|------|------|
| ① 凝血 | 创伤处首先发生凝血 |
| ② 清创 | 单核细胞进入组织，分化为巨噬细胞，清除组织碎片 |
| ③ 募集 | 巨噬细胞分泌趋化因子，吸引成纤维细胞和血管内皮细胞 |
| ④ 肉芽 | 成纤维细胞产纤维和基质，毛细血管长入，形成肉芽组织 |
| ⑤ 表皮覆盖 | 创缘角质形成细胞移行至肉芽表面；残存毛囊、汗腺导管形成上皮小岛 |
| ⑥ 分层重建 | 新生表皮基底细胞增生分化，形成各层，直至填补缺损 |
| ⑦ 转归 | 浅表小创：不留瘢痕。深大创：肉芽 → 瘢痕。过大过深、无残存附属器且创缘太远：需植皮 |
:::

:::insight{label="表皮能爬上来，是因为附属器还留着干细胞"}
第三节把毛囊隆起部和汗腺导管上皮写成表皮衍生。深部损伤把基底层整片掀掉以后，这些“长下去的表皮”反而成了再生的种子，在肉芽表面冒出上皮小岛。大面积烧伤把毛囊和汗腺一起烧掉，种子没了，创缘又够不着，才必须植皮。再生账和附属器账是同一批细胞的两种写法。
:::

:::pitfall{label="肉芽组织不是化脓，也不等于最后留下的瘢痕"}
肉芽组织是修复期富含毛细血管的新生组织，鲜红湿润，是表皮爬行的垫子。以后胶原束变粗、细胞和血管减少，才变成灰白、坚韧、缺乏弹性的瘢痕。把肉芽写成感染化脓，或把刚长出的肉芽当成终末瘢痕，深度和预后都会判断反。
:::

:::pitfall{label="小面积浅表损伤不留瘢痕，不要把所有愈合都写成“必定留疤”"}
基底层和真皮乳头大部分还在时，表皮按生理性再生的路子长回去，数天即可，不走肉芽–瘢痕这条深账。只有较大较深的缺损才先肉芽、后瘢痕；过大过深还要植皮。深度决定结局，不是“破了皮就会留疤”。
:::

:::compare{title="三种损伤深度的修复结局"}
| 损伤 | 残留结构 | 表皮来源 | 真皮侧 | 结局 |
|------|----------|----------|--------|------|
| 小面积浅表 | 基底层及真皮大部保留 | 周围及底部基底细胞 | 无需大量肉芽 | 数天修复，不留瘢痕 |
| 较大较深 | 可有残存毛囊、汗腺导管 | 创缘移行 + 上皮小岛 | 凝血 → 巨噬 → 肉芽 | 可修复；肉芽常被瘢痕取代 |
| 过大过深（如大面积烧伤） | 无残存毛囊和汗腺，创缘太远 | 自身无法覆盖 | 肉芽不足或无法上皮化 | 常需植皮 |
:::

:::keypoint{label="再生先分生理与代偿，代偿再按深度写成肉芽、上皮小岛或植皮"}
- 生理性再生：表皮 $3\sim 4$ 周更新、附属器周期、真皮自我更新。
- 浅小创：数天修复，不留瘢痕。
- 深大创：凝血 → 巨噬细胞清碎片并趋化 → 肉芽组织 → 创缘细胞移行 + 毛囊/汗腺导管上皮小岛 → 新生表皮分层。
- 过大过深且无残存附属器：植皮。
- 肉芽后期可转为灰白、坚韧、缺乏弹性的瘢痕。
:::

## 本章小结

皮肤由表皮和真皮构成，以皮下组织与深层组织相连。表皮由角化的复层扁平上皮构成。细胞分为两大类，即角质形成细胞和非角质形成细胞。前者从表皮基底到表面可分为基底层、棘层、颗粒层、透明层和角质层 5 层。基底层附着于基膜，由一层矮柱状基底细胞组成，是表皮的干细胞，它不断分裂，分化为棘层细胞；棘层由数层多边形、体积较大的棘细胞组成；颗粒层由 $3\sim 5$ 层梭形细胞组成，细胞质内充满嗜碱性颗粒；透明层由 $2\sim 3$ 层扁平细胞组成，细胞界限不清，细胞核和细胞器已消失，细胞质呈强嗜酸性；角质层由多层角质细胞组成，细胞质内充满角蛋白，呈嗜酸性均质状。非角质形成细胞包括黑素细胞、梅克尔细胞和朗格汉斯细胞。位于基底层的黑素细胞生成黑色素，可吸收紫外线，防止对细胞核 DNA 产生辐射损伤；朗格汉斯细胞散在于棘层浅部，是一种抗原呈递细胞；梅克尔细胞数量很少，于指尖、口腔和生殖道黏膜上皮中较多，可感受轻触觉和机械刺激。真皮是位于表皮下方的结缔组织，分为乳头层和网织层。

皮肤有毛、皮脂腺、汗腺和指（趾）甲等附属器。毛分为毛干、毛根和毛球 3 部分，毛球是毛和毛囊的生长点。皮脂腺由腺泡和导管构成，分泌的皮脂可润泽皮肤和毛发。汗腺分泌部上皮由单层淡染的锥形细胞组成，导管由 2 层较小的立方形细胞围成，细胞质呈弱嗜碱性。导管螺旋状走行，开口于皮肤表面汗孔。

:::definition{label="本章结构通式"}
皮肤 = 表皮（角化复层扁平上皮）+ 真皮（乳头层 + 网织层），借皮下组织连到深层。表皮主体是角质形成细胞五层，夹着黑素细胞、朗格汉斯细胞和梅克尔细胞。附属器从表皮衍生：毛（毛干、毛根、毛球）、皮脂腺、外泌/顶泌汗腺、指（趾）甲。更新靠基底层和毛囊/汗腺导管干细胞；深大损伤走肉芽，过深需植皮。
:::

:::compare{title="全章细胞与层次速查"}
| 结构 | 关键细胞或成分 | 职分 |
|------|----------------|------|
| 基底层 | 基底细胞（干细胞）；黑素细胞；梅克尔细胞 | 增殖；产黑素并转移；轻触觉 |
| 棘层 | 棘细胞；朗格汉斯细胞 | 张力丝、内披蛋白、板层颗粒；抗原呈递 |
| 颗粒层 / 透明层 / 角质层 | 透明角质颗粒 → 角蛋白 | 角化、屏障、脱落为皮屑 |
| 乳头层 | 毛细血管、触觉小体 | 营养表皮、精细触觉 |
| 网织层 | 粗胶原束、弹性纤维、环层小体 | 韧性与弹性、深压觉 |
| 毛球 / 隆起部 | 毛母质细胞；毛囊干细胞 | 生毛；换毛及表皮再生后备 |
| 皮脂腺 / 外泌汗腺 / 顶泌汗腺 | 全浆 / 胞吐 / 顶浆 | 润泽；散热排泄；体味 |
| 甲母质 | 增殖活跃的甲床上皮 | 甲体生长区 |
:::

:::keypoint{label="全章把表皮五层、三种非角质形成细胞、真皮两层、附属器和再生收口"}
- 皮肤 = 表皮 + 真皮；皮下组织是浅筋膜，不算第三层。
- 厚皮（掌跖）五层齐全；薄皮颗粒层、透明层不明显。
- 非角质形成细胞：黑素（基底层，转交颗粒）、朗格汉斯（棘层浅部，APC）、梅克尔（基底层，轻触）。
- 真皮：乳头层营养与连接，网织层韧性与弹性。
- 附属器表皮衍生；再生深度决定是否瘢痕或植皮。
:::

## 插入框：表皮生长因子与皮肤创伤愈合

皮肤是人体最大的器官，直接与外界环境接触，不可避免地会因物理、化学、生物因素的影响而损伤。受损的皮肤如果不能尽快修复，皮肤的防御能力将大幅度减弱甚至丧失，严重者会导致感染性休克甚至死亡，因而皮肤创伤后的快速有效愈合对身体健康至关重要。

近年来，研究发现表皮生长因子（epidermal growth factor，EGF）与组织修复有密切关系，在皮肤创面修复中起关键作用。EGF 是一种体内活性物质。1962 年，Cohen 首次从雄鼠颌下腺中分离得到 EGF，并发现有促生长作用。在人体内，EGF 广泛分布于乳汁、血液、尿液、唾液、羊水、胃液和十二指肠中。1986 年，Cohen 因 EGF 研究的杰出贡献获得了诺贝尔生理学或医学奖。

EGF 在创面修复中发挥关键作用。在创面修复的早期，血小板释放的 EGF 能趋化上皮细胞、巨噬细胞、成纤维细胞从创缘向创面聚集，促进创面炎症反应。进而刺激内皮细胞、成纤维细胞、上皮细胞分裂增殖，促进创面血管生成及胶原蛋白、糖胺聚糖的合成，利于纤维组织增生和创面胶原的沉积；EGF 通过促进上皮细胞向表层移行，加速创面的上皮化；通过介导成纤维细胞的活性及促进其增殖，促进创面收缩闭合。在后期，伤口区域组胺含量的增加导致上皮外生性生长和胶原的异常形成，EGF 通过降低皮肤组织中的组胺水平来调节伤口拉伸强度；其次，EGF 可通过抑制炎症反应，降低 TGF-$\beta 1$ 的表达和介导成熟胶原蛋白的形成以减少创面瘢痕，EGF 浓度与瘢痕严重程度呈负相关。

此外，研究还发现 EGF 可以促进皮肤伤口组织修复过程中 DNA、RNA 和羟脯氨酸的合成，诱导分化成熟的皮肤细胞逆转成表皮干细胞，加速伤口肉芽组织生成和上皮细胞增殖，从而缩短伤口愈合时间，提高伤口修复的质量。

:::definition{label="表皮生长因子"}
表皮生长因子（epidermal growth factor，EGF）是与组织修复密切相关的体内活性物质。1962 年 Cohen 首次从雄鼠颌下腺分离并发现其促生长作用；1986 年因此获得诺贝尔生理学或医学奖。人体内广泛分布于乳汁、血液、尿液、唾液、羊水、胃液和十二指肠中。
:::

:::insight{label="EGF 把本节的巨噬细胞、成纤维细胞、上皮移行和瘢痕串成一条分子账"}
早期：血小板释放的 EGF 把上皮、巨噬、成纤维细胞从创缘召到创面，并促内皮和成纤维增殖、血管生成、胶原和糖胺聚糖沉积，加速上皮化和创面收缩。后期：降组胺以调节拉伸强度，抑炎、降 TGF-$\beta 1$、促成熟胶原，以减少瘢痕（浓度与瘢痕严重程度负相关）。它还能促 DNA、RNA 和羟脯氨酸合成，诱导成熟皮肤细胞逆转为表皮干细胞。插入框不改写肉芽和植皮的形态学通式，只是给那条通式补上分子抓手。
:::

| 质量 | 促 DNA、RNA、羟脯氨酸合成；诱导成熟细胞逆转为表皮干细胞；加速肉芽和上皮增殖 |
