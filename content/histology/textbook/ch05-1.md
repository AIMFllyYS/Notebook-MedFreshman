# 一、红细胞

血液（blood）和淋巴（lymph）分别是流动于心血管和淋巴管内的液态组织。血液又称外周血，健康成人约有 $5\,\mathrm{L}$，占体重的 $7\%$。从血管内抽取少量血液，加入适量抗凝剂（肝素或柠檬酸钠），静置或离心沉淀后可分出 3 层：上层为淡黄色的血浆（plasma），下层为红细胞，中间的薄层为白细胞和血小板。因此，血液由红细胞、白细胞、血小板和血浆组成。血细胞约占血液容积的 $45\%$，血浆占 $55\%$。

血浆相当于细胞外基质，$\mathrm{pH}\,7.3\sim 7.4$，主要成分是水，占 $90\%$，其余为血浆蛋白（白蛋白、球蛋白、纤维蛋白原等）、脂蛋白、酶、激素、无机盐和多种营养代谢物质。血细胞主要在骨髓生成。血液中的血细胞陆续衰老死亡，骨髓则源源不断地输出新生细胞，形成动态平衡。血细胞的形态、数量、百分比和血红蛋白含量的测定结果称血象（表 5-1）。患病时，血象常有显著变化，成为诊断疾病的重要指标。Wright 或 Giemsa 染色法染血涂片是最常用的观察血细胞形态的方法（图 5-1）。

:::definition{label="血液"}
血液（blood）又称外周血，是流动于心血管内的液态结缔组织。健康成人约 $5\,\mathrm{L}$，占体重的 $7\%$。由血浆和血细胞（红细胞、白细胞、血小板）组成；血细胞约占容积的 $45\%$，血浆约占 $55\%$。
:::

:::definition{label="血浆"}
血浆（plasma）相当于血液的细胞外基质，抗凝后静置或离心时位于上层，淡黄色。$\mathrm{pH}\,7.3\sim 7.4$，水约占 $90\%$，其余为血浆蛋白（白蛋白、球蛋白、纤维蛋白原等）、脂蛋白、酶、激素、无机盐和多种营养代谢物质。
:::

:::definition{label="血象"}
血象是血细胞的形态、数量、百分比和血红蛋白含量的测定结果。它反映骨髓生成与外周消耗之间的动态平衡，患病时常有显著变化，是诊断疾病的重要指标。
:::

:::concept{term="先问三层：血浆、白膜，还是红细胞"}
抗凝后的血液不是匀浆。上层淡黄色是血浆，下层压实的是红细胞，中间薄层是白细胞加血小板。看见“血液”，先问在问液态基质还是在问有形成分；看见血涂片，再问 Wright/Giemsa 把哪一种细胞染出来。把血浆听成“血清的别名”，或把中间薄层当成“杂质”，都会把 55/45 的容积账和血象账做丢。
:::

:::compare{title="血浆与血细胞"}
| 项目 | 血浆（plasma） | 血细胞 |
|------|----------------|--------|
| 容积比 | 约 $55\%$ | 约 $45\%$ |
| 离心后位置 | 上层，淡黄色 | 下层主要为红细胞；中间薄层为白细胞和血小板 |
| 本质 | 液态细胞外基质 | 有形成分：红细胞、白细胞、血小板 |
| 主要成分 | 水（约 $90\%$）、血浆蛋白、脂蛋白、酶、激素、无机盐、营养代谢物 | 红细胞运气体；白细胞司防御；血小板参与止血 |
| 生成与更新 | 水分和蛋白不断与组织液、淋巴交换 | 主要在骨髓生成，衰老死亡与新生输出维持动态平衡 |
| 观察方法 | 生化与凝血检测 | Wright 或 Giemsa 血涂片观察形态；血象计数 |
:::

红细胞（erythrocyte，red blood cell）在扫描电镜下呈双凹圆盘状，直径约 $7.5\,\mu\mathrm{m}$，中央较薄，厚约 $1\,\mu\mathrm{m}$；周缘较厚，厚约 $2\,\mu\mathrm{m}$。因此在血涂片中，红细胞中央部呈浅红色。这种形态与同体积的球形结构相比，表面积增大约 $25\%$，达 $140\,\mu\mathrm{m}^{2}$，而且细胞内任何一点距细胞表面都不超过 $0.85\,\mu\mathrm{m}$，有利于细胞内外气体的迅速交换。一个人所有红细胞的总表面积约为 $3\,800\,\mathrm{m}^{2}$。

教材图 5-2 为人血细胞扫描电镜图，标注 E 红细胞、G 粒细胞、M 单核细胞、L 淋巴细胞、P 血小板，用以对照双凹圆盘的立体形态。切片资源中对应文件为空，本页不插入该图。光镜下血涂片中央浅染，就是这张双凹盘压扁后的投影。
:::

成熟红细胞无核，也无任何细胞器，细胞质内充满血红蛋白（hemoglobin，Hb），使红细胞呈红色。正常成人血液中血红蛋白的含量男性为 $130\sim 175\,\mathrm{g/L}$，女性为 $115\sim 150\,\mathrm{g/L}$。血红蛋白具有结合与运输 $\mathrm{O}_2$ 和 $\mathrm{CO}_2$ 的功能，所以红细胞能供给全身细胞所需的 $\mathrm{O}_2$，并带走细胞所产生的大部分 $\mathrm{CO}_2$。

:::definition{label="红细胞"}
红细胞（erythrocyte，red blood cell）呈双凹圆盘状，直径约 $7.5\,\mu\mathrm{m}$，中央厚约 $1\,\mu\mathrm{m}$，周缘厚约 $2\,\mu\mathrm{m}$。成熟红细胞无核、无细胞器，胞质充满血红蛋白。血涂片中中央部呈浅红色。正常成人男 $(4.3\sim 5.8)\times 10^{12}/\mathrm{L}$，女 $(3.8\sim 5.1)\times 10^{12}/\mathrm{L}$。
:::

:::definition{label="血红蛋白"}
血红蛋白（hemoglobin，Hb）充满成熟红细胞胞质，使细胞呈红色。正常成人男性 $130\sim 175\,\mathrm{g/L}$，女性 $115\sim 150\,\mathrm{g/L}$。功能是结合与运输 $\mathrm{O}_2$ 和 $\mathrm{CO}_2$。
:::

:::concept{term="先问双凹圆盘：表面积够不够，扩散距离短不短"}
双凹不是为了“好看”。同体积下表面积约增大 $25\%$，达 $140\,\mu\mathrm{m}^{2}$；细胞内任一点距表面不超过 $0.85\,\mu\mathrm{m}$。气体交换靠的是这张被摊开的膜，加上没有核和细胞器挡路。把红细胞只记成“红色的无核细胞”，会把形态账和血红蛋白账拆开。
:::

红细胞具有形态的可变性，当它们通过小于自身直径的毛细血管时，可改变形状。这是因为红细胞膜固定在一个能变形的圆盘状的网架结构上，称红细胞膜骨架（erythrocyte membrane skeleton），其主要成分为血影蛋白（spectrin）和肌动蛋白等。遗传性球形红细胞增多症的血影蛋白分子结构异常，球形红细胞在通过脾时极易被巨噬细胞吞噬清除，导致先天性溶血性贫血。

:::definition{label="红细胞膜骨架"}
红细胞膜骨架（erythrocyte membrane skeleton）是固定在细胞膜内侧、能变形的圆盘状网架，主要成分为血影蛋白（spectrin）和肌动蛋白等。它使红细胞在通过小于自身直径的毛细血管时仍可改变形状。
:::

:::cause-effect{title="血影蛋白异常怎样写成先天性溶血性贫血"}
- 因：遗传性球形红细胞增多症中血影蛋白分子结构异常，圆盘状膜骨架撑不住
- 果：红细胞变成球形，变形性下降
- 果：通过脾时极易被巨噬细胞吞噬清除
- 果：红细胞寿命缩短 → 先天性溶血性贫血
:::

红细胞的细胞膜中有一类镶嵌蛋白质，即血型抗原 A 和/或血型抗原 B，构成人类的 ABO 血型抗原系统，在临床输血中具有重要意义。这是因为人类血液中还有抗异型血的天然抗体（产生原因不明），例如 A 型血的人具有抗血型抗原 B 的抗体，若错配血型，首次输血即可导致抗原抗体结合，引起红细胞膜破裂，血红蛋白逸出，称溶血（hemolysis），溶血后残留的红细胞膜囊称红细胞血影（erythrocyte ghost）。蛇毒、溶血性细菌、脂溶剂等也能引起溶血。

:::definition{label="ABO 血型抗原系统"}
ABO 血型抗原系统由红细胞膜中镶嵌的血型抗原 A 和/或血型抗原 B 构成。人类血液中还有抗异型血的天然抗体，故错配血型时首次输血即可发生抗原抗体结合。
:::

:::definition{label="溶血"}
溶血（hemolysis）是红细胞膜破裂、血红蛋白逸出的过程。血型错配、蛇毒、溶血性细菌、脂溶剂等均可引起。溶血后残留的红细胞膜囊称红细胞血影（erythrocyte ghost）。
:::

:::definition{label="红细胞血影"}
红细胞血影（erythrocyte ghost）是溶血后残留的红细胞膜囊，血红蛋白已经逸出，只剩下塌掉的膜。
:::

:::pitfall{label="红细胞无核不是坏死，是成熟后卸掉的运输袋"}
成熟红细胞无核、无任何细胞器，但不能按坏死、凋亡或“空壳细胞”来记。核和细胞器在晚幼红细胞阶段已经脱去，腾出空间给血红蛋白，并让双凹盘变得可变形。它仍是活着的运输单位，平均寿命约 120 天；真正“死掉”的是衰老后变形性下降、在脾和肝被巨噬细胞清除的那些。把无核听成坏死，会把网织红细胞、溶血和血影全部做错。
:::

红细胞的平均寿命约 120 天。红细胞无任何细胞器，所以不能合成新的蛋白和代谢所需的酶类。随着红细胞逐渐衰老，血红蛋白和膜骨架蛋白变性，导致红细胞的变形性降低。在经过脾和肝时，这些老化的红细胞被巨噬细胞吞噬清除。与此同时，每天都有新生的未完全成熟的红细胞从骨髓进入血液，这些细胞内尚残留部分核糖体，用煌焦油蓝染色呈细网状，故称网织红细胞（reticulocyte）（图 5-3）。未完全成熟的红细胞在血液中大约一天后完全成熟，核糖体消失。成年人网织红细胞占红细胞总数的 $0.5\%\sim 1.5\%$。骨髓造血功能发生障碍的患者，网织红细胞计数降低。如果贫血患者的网织红细胞计数增加，说明治疗有效。

:::definition{label="网织红细胞"}
网织红细胞（reticulocyte）是从骨髓进入血液、尚未完全成熟的红细胞。细胞内尚残留部分核糖体，煌焦油蓝染色呈细网状。入血约一天后核糖体消失，成为成熟红细胞。成年人占红细胞总数的 $0.5\%\sim 1.5\%$。
:::

::figure{src="/images/histology/textbook/p0065_02.png" caption="图5-3 网织红细胞光镜图（煌焦油蓝染色）。残留核糖体被染成细网状，分布于部分红细胞内。" alt="煌焦油蓝染色：部分红细胞内可见蓝紫色细网，为网织红细胞"}

:::compare{title="成熟红细胞与网织红细胞"}
| 项目 | 成熟红细胞 | 网织红细胞 |
|------|------------|------------|
| 核与细胞器 | 无核，无任何细胞器 | 无核，但残留部分核糖体 |
| 形态 | 双凹圆盘，直径约 $7.5\,\mu\mathrm{m}$ | 圆盘状，直径约 $7\sim 9\,\mu\mathrm{m}$（见第五节表 5-2） |
| 特有显示 | Wright/Giemsa 中央浅染 | 煌焦油蓝染成细网状 |
| 占成人红细胞 | 几乎全部 | $0.5\%\sim 1.5\%$ |
| 入血后去向 | 执行气体运输，平均寿命约 120 天 | 约一天后核糖体消失，变为成熟红细胞 |
| 临床读法 | 数量和血红蛋白构成血象主干 | 降低提示骨髓造血障碍；贫血治疗中升高说明治疗有效 |
:::

:::cause-effect{title="为什么网织红细胞能反映骨髓红系造血"}
- 因：每天都有未完全成熟的红细胞从骨髓入血，残留核糖体大约一天后才消失
- 果：外周血网织红细胞比例直接反映刚刚输出的红系细胞
- 果：骨髓造血障碍 → 网织红细胞计数降低
- 果：贫血治疗有效 → 新生红细胞入血增多 → 网织红细胞计数增加
:::

:::insight{label="无细胞器决定了 120 天的上限"}
成熟红细胞把核和细胞器全部卸掉，换来的是更大的血红蛋白容量和更好的变形性，代价是不能再合成新的蛋白和酶。血红蛋白和膜骨架蛋白只能用到变性为止，变形性一降，脾和肝的巨噬细胞就把它们清掉。120 天不是“设定好的倒计时”，而是这只运输袋在无法自我修补的前提下所能维持的时间。网织红细胞还带着核糖体，是这只袋子入血后的最后一天检修期。
:::

:::keypoint{label="红细胞先把双凹盘、血红蛋白和网织红细胞三本账立住"}
- 血液约 $5\,\mathrm{L}$、占体重 $7\%$；血浆约 $55\%$，血细胞约 $45\%$；Wright/Giemsa 血涂片是看形态的常规方法。
- 红细胞双凹圆盘、无核无细胞器，胞质充满血红蛋白，司 $\mathrm{O}_2$ 与 $\mathrm{CO}_2$ 运输；膜骨架（血影蛋白、肌动蛋白）保证变形性。
- ABO 血型抗原在膜上，天然抗体使错配首次即可溶血，留下红细胞血影。
- 平均寿命约 120 天，衰老者在脾、肝被巨噬细胞清除；网织红细胞是残留核糖体的未成熟红细胞，成人 $0.5\%\sim 1.5\%$，用来读骨髓红系造血。
:::

:::memory{label="本节必背要点"}
- [ ] 血液（blood）：心血管内液态组织，又称外周血；健康成人约 $5\,\mathrm{L}$，占体重 $7\%$。
- [ ] 组成：血浆 + 红细胞、白细胞、血小板；血细胞约占容积 $45\%$，血浆约占 $55\%$。
- [ ] 抗凝后分层：上层淡黄色血浆，下层红细胞，中间薄层为白细胞和血小板。抗凝剂为肝素或柠檬酸钠。
- [ ] 血浆相当于细胞外基质，$\mathrm{pH}\,7.3\sim 7.4$，水约占 $90\%$；其余为血浆蛋白（白蛋白、球蛋白、纤维蛋白原等）、脂蛋白、酶、激素、无机盐和营养代谢物。
- [ ] 血象：血细胞形态、数量、百分比和血红蛋白含量的测定结果；Wright 或 Giemsa 染血涂片是最常用观察方法。

- [ ] 白细胞分类：中性 $50\%\sim 70\%$，嗜酸 $0.5\%\sim 5\%$，嗜碱 $0\sim 1\%$，单核 $3\%\sim 8\%$，淋巴 $20\%\sim 40\%$。

- [ ] ABO 血型抗原 A 和/或 B 镶嵌于细胞膜；血液中有抗异型血的天然抗体；A 型血有抗 B 抗体。
- [ ] 溶血（hemolysis）：膜破裂、血红蛋白逸出；错配血型首次即可发生。残留膜囊称红细胞血影（erythrocyte ghost）。蛇毒、溶血性细菌、脂溶剂也可致溶血。
- [ ] 平均寿命约 120 天；无细胞器故不能合成新蛋白和酶；衰老后变形性降低，在脾和肝被巨噬细胞吞噬。
- [ ] 网织红细胞（reticulocyte）：残留核糖体，煌焦油蓝呈细网状；入血约一天后成熟；成人占 $0.5\%\sim 1.5\%$。
- [ ] 网织红细胞降低提示骨髓造血障碍；贫血患者计数增加说明治疗有效。
