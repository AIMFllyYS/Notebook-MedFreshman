# 八、胃肠的内分泌细胞

在胃、肠的上皮及腺体中散布着 40 余种内分泌细胞，尤以胃幽门部和十二指肠上段为多。由于胃肠道黏膜面积巨大，这些细胞的总量估计为 $3\times 10^{9}$ 个，超过所有内分泌腺腺细胞的总和。因此在某种意义上，胃肠是体内最大、最复杂的内分泌器官，所分泌的激素主要协调胃肠道自身的消化吸收功能，也参与调节其他器官的生理活动。

:::definition{label="胃肠内分泌细胞"}
胃肠内分泌细胞散布于胃、肠的上皮及腺体中，约 40 余种，以胃幽门部和十二指肠上段为多。总量估计 $3\times 10^{9}$ 个，超过所有内分泌腺腺细胞的总和。胃肠在某种意义上是体内最大、最复杂的内分泌器官。
:::

:::definition{label="胃肠激素的作用范围"}
所分泌的激素主要协调胃肠道自身的消化吸收功能，也参与调节其他器官的生理活动。
:::

:::concept{term="先问这枚细胞露不露出腔面：开放型还是封闭型"}
绝大多数胃肠内分泌细胞是开放型：游离面有微绒毛，直接尝管腔里的食物和 $\mathrm{pH}$。少数（主要是 D 细胞）被邻细胞盖住，是封闭型，听的是机械牵拉和其他激素，不是腔面化学信号。颗粒都堆在基部，多经血走远，少数旁分泌就近调节。把它们听成“另一种杯状细胞”，开放/封闭和旁分泌那两本账会并进黏液里。
:::

胃肠的内分泌细胞大多单个夹于其他上皮细胞之间，在 HE 染色切片上，细胞多较圆，核圆、居中，细胞质染色浅淡；目前主要用免疫组织化学法显示。细胞在电镜下呈不规则的锥形；基底部附于基膜，并可有基底侧突与邻近细胞相接触；底部细胞质有大量分泌颗粒，分泌颗粒的大小、形状与电子密度依细胞种类而异。绝大多数种类的细胞具有面向管腔的游离面，称开放型，游离面上有微绒毛，对管腔内食物和 $\mathrm{pH}$ 等化学信息有较强感受性，从而引起其内分泌活动的变化。少数细胞（主要是 D 细胞）被相邻细胞覆盖而未露出腔面，称封闭型，主要受胃肠运动的机械刺激或其他激素的调节而改变其内分泌状态（图 14-34）。分泌颗粒含肽和/或胺类激素，多在细胞基底面释放，经血液循环运送并作用于靶细胞；少数激素直接作用于邻近细胞，以旁分泌方式调节靶细胞的生理功能。

:::definition{label="胃肠内分泌细胞的光镜与超微结构"}
大多单个夹于其他上皮细胞之间。HE 中细胞多较圆，核圆居中，胞质浅淡，主要靠免疫组织化学显示。电镜下呈不规则锥形；基底部附于基膜，可有基底侧突与邻细胞接触；底部胞质有大量分泌颗粒，其大小、形状与电子密度依种类而异。
:::

:::definition{label="开放型内分泌细胞"}
开放型细胞具有面向管腔的游离面，游离面上有微绒毛，对管腔内食物和 $\mathrm{pH}$ 等化学信息有较强感受性，从而引起内分泌活动变化。绝大多数种类属开放型。
:::

:::definition{label="封闭型内分泌细胞"}
封闭型细胞被相邻细胞覆盖而未露出腔面，主要是 D 细胞。主要受胃肠运动的机械刺激或其他激素调节而改变内分泌状态。
:::

:::definition{label="胃肠激素的释放方式"}
分泌颗粒含肽和/或胺类激素，多在细胞基底面释放，经血液循环作用于靶细胞；少数激素直接作用于邻近细胞，以旁分泌方式调节靶细胞。
:::

:::compare{title="开放型与封闭型"}
| 项目 | 开放型 | 封闭型 |
|------|--------|--------|
| 腔面 | 有游离面，微绒毛伸向管腔 | 被邻细胞覆盖，不露出腔面 |
| 主要成员 | 绝大多数种类 | 少数，主要是 D 细胞 |
| 感受什么 | 管腔内食物和 $\mathrm{pH}$ 等化学信息 | 胃肠运动的机械刺激或其他激素 |
| 颗粒位置 | 底部胞质 | 底部胞质 |
| 释放 | 多经基底面入血；少数旁分泌 | 同左 |
:::

:::pitfall{label="封闭型不是“没有激素的内分泌细胞”，主要就是 D 细胞"}
封闭型同样有底部颗粒、同样可入血或旁分泌，只是不直接品尝腔面。D 细胞产生长抑素，抑制胃酸和胰液，既可刹车壁细胞，也可抑制 ECL。把封闭型听成“退化细胞”，生长抑素这本抑制账会没有细胞学落点。
:::

:::insight{label="颗粒在基部，所以激素往组织里走，不往肠腔里吐"}
锥形细胞的尖可以朝腔（开放型），颗粒却堆在贴基膜的底部。释放方向是基底面入血或旁分泌，不是把胃泌素、促胰液素倒进食糜。免疫组化在幽门看到的 G 细胞、D 细胞，染色都在细胞下半。
:::

目前已知有 10 余种胃肠内分泌细胞，它们的分布和结构均有一定特点。有些细胞的分泌物及其作用比较明确，有些细胞的分泌物及其生理、病理意义尚有待研究。主要的胃肠内分泌细胞见表 14-1。

## 本章小结

消化管是从口腔至肛门的连续性管道，依次分为口腔、咽、食管、胃、小肠和大肠。主要对食物进行物理性和化学性消化，将大分子物质分解为小分子的氨基酸、单糖、脂肪酸等，进而吸收营养物质和排泄食物残渣。

消化管壁（除口腔与咽外）自内向外分为黏膜、黏膜下层、肌层与外膜 4 层，黏膜由上皮、固有层和黏膜肌层组成。食管的上皮为复层扁平上皮，黏膜下层中有黏液腺，肌层中上 $1/3$ 段为骨骼肌，下 $1/3$ 段为平滑肌，中 $1/3$ 段则兼具两者，外膜为纤维膜。胃的上皮为单层柱状，主要由表面黏液细胞组成，可形成胃黏膜屏障，具有保护作用。固有层中有胃底腺，由主细胞、壁细胞、颈黏液细胞、干细胞和内分泌细胞组成，其中主细胞分泌胃蛋白酶原，壁细胞分泌盐酸和内因子。小肠表面形成皱襞、绒毛和微绒毛，可扩大吸收的表面积。上皮为单层柱状上皮，由吸收细胞、杯状细胞和少量内分泌细胞组成，吸收细胞几乎可将摄入的营养物质全部吸收，杯状细胞分泌黏液，有润滑和保护作用。绒毛中央的固有层中有中央乳糜管，用于吸收脂肪，绒毛深部的固有层中有小肠腺。大肠的上皮为单层柱状上皮，由吸收细胞和杯状细胞组成，吸收细胞主要吸收水分和电解质，杯状细胞分泌的黏液起润滑作用。肌层由内环行和外纵行两层平滑肌组成。内环行肌节段性局部增厚，形成结肠袋；外纵行肌局部增厚形成 3 条结肠带，带间的纵行肌菲薄，甚至缺如。

消化管壁中含有较多的淋巴组织，主要包括黏膜淋巴小结（尤以咽、回肠和阑尾处发达），固有层中有弥散分布的淋巴细胞、浆细胞、巨噬细胞、间质树突状细胞，以及上皮内的淋巴细胞。淋巴组织能接受消化管内病原微生物的抗原刺激，主要通过产生和向消化管腔分泌免疫球蛋白作为应答。在胃、肠的上皮及腺体中散布着 40 余种内分泌细胞，所分泌的激素主要协调胃肠道自身的消化吸收功能，也参与调节其他器官的生理活动。

- [ ] 小肠表面形成皱襞、绒毛和微绒毛，扩大吸收表面积。
- [ ] 小肠上皮为单层柱状，由吸收细胞、杯状细胞和少量内分泌细胞组成。
- [ ] 吸收细胞几乎可将摄入的营养物质全部吸收；杯状细胞分泌黏液，润滑保护。
- [ ] 绒毛中央固有层有中央乳糜管，吸收脂肪；绒毛深部固有层有小肠腺。
- [ ] 大肠上皮为单层柱状，由吸收细胞和杯状细胞组成。
- [ ] 大肠吸收细胞主要吸收水分和电解质，杯状细胞黏液起润滑作用。
- [ ] 大肠肌层内环、外纵；内环肌节段性增厚成结肠袋，外纵肌局部增厚成 3 条结肠带，带间纵肌菲薄甚至缺如。
- [ ] 消化管壁淋巴组织包括黏膜淋巴小结（咽、回肠、阑尾发达），固有层弥散的淋巴细胞、浆细胞、巨噬细胞、间质树突状细胞，以及上皮内淋巴细胞。
- [ ] 淋巴组织接受管腔病原抗原，主要通过产生和向管腔分泌免疫球蛋白作为应答。
- [ ] 胃、肠上皮及腺体中散布 40 余种内分泌细胞，激素主要协调自身消化吸收，也调节其他器官。
:::

## 插入框：内镜黏膜下剥离术

消化管癌前病变和消化管肿瘤的早期发现、早期治疗至关重要。近来发展的一项微创技术引起了广泛关注，这就是内镜黏膜下剥离术（endoscopic submucosal dissection，ESD）。这项以精细和微妙为特点的技术，将内镜通过人体自然腔道进入体内进行可视化检查的能力发挥到了新的境界。患者术前需借助超声内镜等检查确定病变侵及的深度，在病变与肌层之间应能看到完整的黏膜下层分界。运用 ESD 能一次性完整切除病变的黏膜，不会累及肌层和外膜。在较小的创伤下达到与外科手术同样的治疗效果，免除了开腹手术的痛苦和器官切除的弊端。ESD 要求主刀医师必须心态平稳，操作精细，特别是在处理直径 $3\,\mathrm{cm}$ 以上的病变时，精细操作，尽量避免患者出现消化管出血、穿孔等并发症。此外，消化管黏膜具有强大的重生修复能力，每分钟可以产生约 50 万个新黏膜细胞，加上术后的药物治疗，如使用抑酸药、黏膜保护剂、抗生素等，可以为新黏膜创造良好的生长环境，极大地促进消化管黏膜的愈合与再生。

:::definition{label="内镜黏膜下剥离术"}
内镜黏膜下剥离术（endoscopic submucosal dissection，ESD）经人体自然腔道以内部可视方式，一次性完整切除病变黏膜、不累及肌层和外膜的微创技术。
:::

:::insight{label="ESD 能剥的是黏膜，前提是黏膜下层分界还在"}
第一节把管壁写成四层，这一框把那把尺子用到手术上：超声内镜要看见病变与肌层之间完整的黏膜下层分界，才能把黏膜整片剥下来、留下肌层和外膜。出血和穿孔，就是切深了、切穿了这层分界。黏膜每分钟约 50 万个新细胞，加上抑酸药、黏膜保护剂和抗生素，是术后能愈合的组织学理由。
:::

:::pitfall{label="ESD 不是把肠壁全层切掉，更不是开腹切除器官"}
适应证建立在“病变还停在黏膜、黏膜下层仍可分界”上。一旦深度到肌层，四层尺子就不允许只剥黏膜。也不要把 ESD 听成“内镜下烧灼一点黏膜”——教材强调一次性**完整**切除病变黏膜。
:::

:::note{label="ESD 与四层管壁"}
| 环节 | 落点 |
|------|------|
| 术前 | 超声内镜等确定侵及深度；病变与肌层之间应见完整黏膜下层分界 |
| 切除范围 | 完整切除病变黏膜，不累及肌层和外膜 |
| 直径 $>3\,\mathrm{cm}$ | 更需精细，避免出血、穿孔 |
| 愈合 | 每分钟约 50 万个新黏膜细胞；抑酸药、黏膜保护剂、抗生素 |
:::

:::memory{label="插入框必背"}
- [ ] 消化管癌前病变和肿瘤强调早期发现、早期治疗。
- [ ] 内镜黏膜下剥离术（ESD）经自然腔道可视化操作，一次性完整切除病变黏膜。
- [ ] 术前超声内镜等须确认病变与肌层之间有完整的黏膜下层分界。
- [ ] ESD 不累及肌层和外膜，创伤小于开腹和器官切除。
- [ ] 直径 $3\,\mathrm{cm}$ 以上病变更需精细，避免出血、穿孔。
- [ ] 黏膜每分钟约产生 50 万个新黏膜细胞；术后抑酸药、黏膜保护剂、抗生素促进愈合再生。
:::
