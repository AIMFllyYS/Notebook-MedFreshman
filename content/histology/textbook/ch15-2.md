# 二、胰腺

上一节把大唾液腺的浆液、黏液和纹状管摊开。胰腺表面覆有薄层结缔组织被膜，结缔组织伸入腺内将实质分隔为许多小叶。胰腺实质由外分泌部和内分泌部（胰岛）组成（图 15-2）。外分泌部构成腺的大部分，是重要的消化腺，它分泌的胰液经导管排入十二指肠，在食物消化中起重要作用。胰岛分泌的激素进入血液或淋巴，主要调节糖代谢。

:::definition{label="胰腺"}
胰腺表面覆有薄层结缔组织被膜，结缔组织伸入腺内将实质分隔为许多小叶。实质由外分泌部和内分泌部（胰岛）组成。外分泌部构成腺的大部分。
:::

:::definition{label="胰腺外分泌部"}
外分泌部是重要的消化腺，分泌的胰液经导管排入十二指肠，在食物消化中起重要作用。为纯浆液复管泡状腺。
:::

:::definition{label="胰腺内分泌部"}
内分泌部即胰岛，分泌的激素进入血液或淋巴，主要调节糖代谢。它夹在腺泡之间，不走外分泌导管。
:::

:::concept{term="先问这一团是腺泡还是胰岛：酶原走导管，激素走有孔毛细血管"}
看见胰腺切片，先把两本账拆开。深紫、顶部酶原颗粒、中央可能有泡心细胞的是外分泌腺泡，产物经闰管送到十二指肠。染色浅、球团状、细胞间有孔毛细血管的是胰岛，激素入血。把浅染团块写成“扩张的腺泡腔”，糖尿病和胰液两本账会并成一句。
:::

:::compare{title="腺泡与胰岛"}
| 项目 | 外分泌腺泡 | 胰岛 |
|------|------------|------|
| 归属 | 外分泌部，构成腺的大部分 | 内分泌部，夹在腺泡之间 |
| 光镜 | HE 染色深；锥形浆液细胞，顶部酶原颗粒 | HE 染色浅的球形细胞团（图 15-2） |
| 导管 | 有：闰管（泡心细胞）→ 小叶内 → 小叶间 → 主导管 | 无导管；激素入血液或淋巴 |
| 毛细血管 | 普通腺泡间血管 | 细胞间有丰富的有孔毛细血管 |
| 产物 | 胰液：多种消化酶 + 水和碳酸氢盐 | 胰高血糖素、胰岛素、生长抑素、胰多肽 |
| 调节 | 小肠 I 细胞的缩胆囊素-促胰酶素（酶）；S 细胞的促胰液素（水和碳酸氢盐） | 血糖及细胞间旁分泌（D 细胞生长抑素） |
| 肌上皮 | 无 | — |
:::

:::pitfall{label="胰岛不是外分泌，浅染球团不要写成“泡心细胞堆”或“扩张的导管”"}
泡心细胞是伸进腺泡腔的闰管上皮，扁平或立方、胞质淡、仍在外分泌部里。胰岛是内分泌细胞团，约占胰腺体积的 $1.5\%$，激素不进胰管。把胰岛听成外分泌，胰岛素、胰高血糖素会错误地被写成“排进十二指肠的消化液”。
:::

## （一）外分泌部

胰腺的外分泌部为纯浆液复管泡状腺。

### 1. 腺泡

每个腺泡含 $40\sim 50$ 个胰腺泡细胞（pancreatic acinar cell），它们都具有典型的浆液细胞形态特点（图 15-3～图 15-5）。胰腺泡细胞分泌多种消化酶，如胰蛋白酶原、胰糜蛋白酶原、胰淀粉酶、胰脂肪酶、核酸酶等，它们分别消化食物中的各种营养成分。胰蛋白酶原和胰糜蛋白酶原在进入小肠后，被肠激酶激活，成为有活性的胰蛋白酶和胰糜蛋白酶。胰腺泡细胞的分泌活动受小肠 I 细胞分泌的缩胆囊素-促胰酶素的调节。

:::definition{label="胰腺泡细胞"}
胰腺泡细胞（pancreatic acinar cell）是典型的浆液细胞。每个腺泡含 $40\sim 50$ 个。顶部胞质含酶原颗粒；分泌多种消化酶，分别消化食物中的各种营养成分。
:::

:::definition{label="胰酶原与肠激酶"}
胰蛋白酶原和胰糜蛋白酶原在进入小肠后，被肠激酶激活，成为有活性的胰蛋白酶和胰糜蛋白酶。腺泡里贮存的是酶原，不是已经激活的蛋白酶，以免腺体被自我消化。
:::

:::note{label="胰腺泡细胞分泌的主要消化酶"}
| 酶 | 要点 |
|----|------|
| 胰蛋白酶原 | 入小肠后被肠激酶激活为胰蛋白酶 |
| 胰糜蛋白酶原 | 入小肠后被肠激酶激活为胰糜蛋白酶 |
| 胰淀粉酶 | 消化淀粉 |
| 胰脂肪酶 | 消化脂肪 |
| 核酸酶 | 消化核酸 |
:::

:::definition{label="缩胆囊素-促胰酶素（腺泡）"}
胰腺泡细胞的分泌活动受小肠 I 细胞分泌的缩胆囊素-促胰酶素的调节。同一激素后文还作用于胆囊，使胆囊收缩、胆总管括约肌松弛。
:::

胰腺腺泡无肌上皮细胞。胰腺腺泡腔面还可见一些较小的扁平或立方形的泡心细胞（centroacinar cell）（图 15-3，图 15-4），细胞质染色淡，核呈圆形或卵圆形。泡心细胞是延伸入腺泡腔内的闰管起始部上皮细胞。

:::definition{label="泡心细胞"}
泡心细胞（centroacinar cell）是延伸入腺泡腔内的闰管起始部上皮细胞。较小，扁平或立方形，胞质染色淡，核呈圆形或卵圆形。出现在腺泡腔面，是胰腺外分泌部的身份证之一。
:::

:::pitfall{label="胰腺腺泡没有肌上皮，排空不靠那一层收缩细胞"}
大唾液腺腺细胞与基膜之间有肌上皮。胰腺腺泡把这层拿掉：酶原靠细胞分泌，导管上皮再加水加碳酸氢盐。切片上不要为了“腺泡都该有肌上皮”去把泡心细胞或内皮误认成肌上皮。
:::

:::insight{label="泡心细胞把闰管的起点写进腺泡腔里"}
闰管不是在腺泡外面才开始。它的起始部上皮伸进腺泡腔，变成淡染的泡心细胞。所以胰腺闰管又细又长，切片上常在腺泡中央先看见这几颗浅核。把泡心细胞听成“另一种腺泡细胞”，酶原颗粒账会多出一种不存在的消化酶。
:::

::figure{src="/images/histology/textbook/p0175_03.png" caption="图15-4 胰腺腺泡模式图。示浆液细胞、顶部酶原颗粒、伸入腺泡腔的泡心细胞、闰管和基膜。" alt="胰腺腺泡模式：锥形浆液细胞含酶原颗粒，淡染泡心细胞位于腔面并延续为闰管"}

### 2. 导管

由闰管、小叶内导管、小叶间导管和主导管组成。

闰管细而长，管壁为单层扁平或立方上皮，其伸入腺泡的一段由泡心细胞组成。闰管远端逐渐汇合形成小叶内导管。小叶内导管在小叶间结缔组织内汇合成小叶间导管，后者再汇合成一条主导管，贯穿胰腺全长，在胰头部与胆总管汇合，开口于十二指肠乳头。从小叶内导管至主导管，管腔逐渐增大，上皮由单层立方上皮渐变为单层柱状上皮，主导管为单层高柱状上皮，上皮内可见杯状细胞。胰腺导管上皮细胞可分泌水和碳酸氢盐等多种电解质，其分泌活动受小肠 S 细胞分泌的促胰液素调节。

胰液为碱性液体，含多种消化酶和丰富的电解质，是最重要的消化液。成人每天分泌 $1\sim 2\,\mathrm{L}$。

:::definition{label="胰腺导管四级"}
胰腺导管由闰管、小叶内导管、小叶间导管和主导管组成。闰管细而长，单层扁平或立方上皮，伸入腺泡的一段即泡心细胞。
:::

:::definition{label="胰腺主导管"}
小叶间导管汇合成一条主导管，贯穿胰腺全长，在胰头部与胆总管汇合，开口于十二指肠乳头。主导管为单层高柱状上皮，上皮内可见杯状细胞。
:::

:::definition{label="促胰液素（导管）"}
胰腺导管上皮细胞可分泌水和碳酸氢盐等多种电解质，其分泌活动受小肠 S 细胞分泌的促胰液素调节。水和碳酸氢盐把胰液写成碱性，保护十二指肠并给胰酶提供适宜 pH。
:::

:::definition{label="胰液"}
胰液为碱性液体，含多种消化酶和丰富的电解质，是最重要的消化液。成人每天分泌 $1\sim 2\,\mathrm{L}$。酶来自腺泡，水和碳酸氢盐主要来自导管上皮。
:::

:::compare{title="胰腺导管与大唾液腺导管"}
| 项目 | 胰腺 | 大唾液腺 |
|------|------|----------|
| 起始 | 闰管细而长，伸入腺泡成泡心细胞 | 闰管直接连腺泡；舌下腺无闰管 |
| 有无纹状管 | 无纹状管；小叶内导管接在闰管之后 | 有纹状管（分泌管），基部纵纹转运水和电解质 |
| 主导管 / 总导管 | 一条主导管贯穿全长，胰头与胆总管汇合，开口于十二指肠乳头；高柱状，有杯状细胞 | 一条或几条总导管开口于口腔 |
| 导管上皮分泌 | 水和碳酸氢盐（促胰液素调节） | 纹状管转运水和电解质 |
| 肌上皮 | 腺泡无 | 腺细胞和部分导管上皮与基膜之间有 |
:::

:::note{label="两种小肠激素分别管酶和水"}
| 激素 | 来源 | 胰腺落点 | 效应 |
|------|------|----------|------|
| 缩胆囊素-促胰酶素 | 小肠 I 细胞 | 胰腺泡细胞 | 促消化酶（酶原）分泌；后文还促胆囊收缩 |
| 促胰液素 | 小肠 S 细胞 | 导管上皮 | 促水和碳酸氢盐分泌，胰液呈碱性 |
:::

:::pitfall{label="胰液的碱性和酶不是同一段导管、同一群细胞造的"}
酶原在腺泡细胞顶部颗粒里；水和碳酸氢盐主要是导管上皮的活。I 细胞管酶，S 细胞管水和碱。把“胰液碱性”写成腺泡细胞的酶原颗粒属性，十二指肠抗酸那一笔会找不到结构落点。
:::

## （二）胰岛

胰腺内分泌部也称胰岛（pancreas islet），是由内分泌细胞组成的球形细胞团，分布于腺泡之间，HE 染色浅（见图 15-2）。成人胰腺约有 $100$ 万个胰岛，约占胰腺体积的 $1.5\%$，于胰尾部较多。胰岛大小不等，直径 $75\sim 500\,\mu\mathrm{m}$，小的仅由十几个细胞组成，大的有数百个细胞。胰岛细胞间有丰富的有孔毛细血管。人胰岛主要有 A 细胞、B 细胞、D 细胞、PP 细胞 4 种。HE 染色不易区分，目前主要用免疫组织化学法进行鉴别（图 15-6）。

:::definition{label="胰岛"}
胰岛（pancreas islet）是由内分泌细胞组成的球形细胞团，分布于腺泡之间，HE 染色浅。成人约有 $100$ 万个，约占胰腺体积的 $1.5\%$，胰尾部较多。直径 $75\sim 500\,\mu\mathrm{m}$；细胞间有丰富的有孔毛细血管。
:::

:::definition{label="胰岛四种细胞的显示"}
人胰岛主要有 A、B、D、PP 4 种细胞。HE 染色不易区分，目前主要用免疫组织化学法鉴别。图 15-6 用辣根过氧化物酶标记显示含胰岛素的 B 细胞呈棕黑色。
:::

### 1. A 细胞

A 细胞又称 $\alpha$ 细胞，约占胰岛细胞总数的 $20\%$，细胞体积较大，多分布在胰岛周边部。A 细胞分泌胰高血糖素（glucagon），能促进肝细胞的糖原分解为葡萄糖，并抑制糖原合成，使血糖浓度升高，满足机体活动的能量需要。

:::definition{label="A 细胞"}
A 细胞又称 $\alpha$ 细胞，约占胰岛细胞总数的 $20\%$，体积较大，多分布在胰岛周边部。分泌胰高血糖素（glucagon）：促进肝细胞糖原分解为葡萄糖，并抑制糖原合成，使血糖浓度升高。
:::

### 2. B 细胞

B 细胞又称 $\beta$ 细胞，约占胰岛细胞总数的 $70\%$，主要位于胰岛中央部。B 细胞分泌胰岛素（insulin），主要促进肝细胞、脂肪细胞等吸收血液内的葡萄糖，合成糖原或转化为脂肪贮存，使血糖降低。

胰高血糖素和胰岛素的协同作用能保持血糖水平处于动态平衡。若胰岛发生病变，B 细胞退化，胰岛素分泌不足，可致血糖升高，并从尿中排出，即为糖尿病。胰岛 B 细胞肿瘤或细胞功能亢进，则胰岛素分泌过多，可导致低血糖症。

:::definition{label="B 细胞"}
B 细胞又称 $\beta$ 细胞，约占胰岛细胞总数的 $70\%$，主要位于胰岛中央部。分泌胰岛素（insulin）：促进肝细胞、脂肪细胞等吸收血液内的葡萄糖，合成糖原或转化为脂肪贮存，使血糖降低。
:::

:::definition{label="糖尿病（胰岛）"}
若胰岛发生病变，B 细胞退化，胰岛素分泌不足，可致血糖升高，并从尿中排出，即为糖尿病。1 型和 2 型的临床细分见章末插入框。
:::

:::definition{label="低血糖症（胰岛）"}
胰岛 B 细胞肿瘤或细胞功能亢进，则胰岛素分泌过多，可导致低血糖症。和糖尿病是同一条胰岛素账的两端。
:::

:::concept{term="先问升糖还是降糖：周边 A 细胞对中央 B 细胞"}
A 在周边、约 $20\%$，胰高血糖素把肝糖原拆成葡萄糖；B 在中央、约 $70\%$，胰岛素把葡萄糖收进肝细胞和脂肪细胞。两激素协同，血糖才能动态平衡。病变先问 B 细胞是不够还是太多：不够 → 糖尿病；太多 → 低血糖症。不要把“胰岛坏了”一律写成糖尿病。
:::

### 3. D 细胞

D 细胞又称 $\delta$ 细胞，约占胰岛细胞总数的 $5\%$，分散在胰岛周边部，A、B 细胞之间，并与 A、B 细胞紧密相贴，细胞间有缝隙连接。D 细胞分泌生长抑素（somatostatin），以旁分泌方式经缝隙连接直接作用于邻近的 A 细胞、B 细胞或 PP 细胞，抑制这些细胞的分泌活动。

:::definition{label="D 细胞"}
D 细胞又称 $\delta$ 细胞，约占胰岛细胞总数的 $5\%$，分散在胰岛周边部，A、B 细胞之间，并与 A、B 细胞紧密相贴，细胞间有缝隙连接。分泌生长抑素（somatostatin），以旁分泌方式经缝隙连接直接抑制邻近 A、B 或 PP 细胞的分泌。
:::

:::pitfall{label="D 细胞的生长抑素是旁分泌，不要写成经胰管或经体循环去“抑制全身胰岛”"}
D 细胞和邻居紧贴，缝隙连接把生长抑素就近交给 A、B、PP。这是第 13 章那种旁分泌，不是外分泌，也不是胰岛素那种经血走远处的经典内分泌主账。把生长抑素听成“另一种消化酶”，抑制账会写进十二指肠。
:::

### 4. PP 细胞

PP 细胞数量很少，主要存在于胰岛周边部。此外，还可见于外分泌部的导管上皮内及腺泡细胞间。PP 细胞分泌胰多肽（pancreatic polypeptide），具有抑制胃肠运动、胰液分泌及胆囊收缩的作用。

:::definition{label="PP 细胞"}
PP 细胞数量很少，主要存在于胰岛周边部，还可见于外分泌部的导管上皮内及腺泡细胞间。分泌胰多肽（pancreatic polypeptide），抑制胃肠运动、胰液分泌及胆囊收缩。
:::

:::compare{title="人胰岛四种细胞"}
| 细胞 | 别称 | 约占 | 主要位置 | 激素 | 作用 |
|------|------|------|----------|------|------|
| A 细胞 | $\alpha$ 细胞 | $20\%$ | 胰岛周边，体积较大 | 胰高血糖素 | 促肝糖原分解、抑糖原合成，升血糖 |

:::insight{label="HE 只能认出“这是胰岛”，四种细胞要靠免疫组化"}
浅染球团加有孔毛细血管，足够把胰岛从腺泡里切开。谁是 A、谁是 B，HE 染不出来。图 15-6 把胰岛素标成棕黑，中央大片着色，正是 B 细胞占 $70\%$、位于中央的形态学落点。考试若给 HE，只问是不是胰岛；若给免疫组化，再问哪一种激素。
:::

:::keypoint{label="胰腺先把外分泌腺泡和胰岛拆开，再记酶原、泡心细胞和 A/B/D/PP"}
- 胰腺实质 = 外分泌部（大部分，胰液入十二指肠）+ 内分泌部（胰岛，激素入血，调节糖代谢）。
- 外分泌部为纯浆液复管泡状腺；腺泡无肌上皮；每泡 $40\sim 50$ 个胰腺泡细胞，顶部酶原颗粒。
- 胰蛋白酶原、胰糜蛋白酶原入小肠后被肠激酶激活；腺泡受 I 细胞缩胆囊素-促胰酶素调节。
- 泡心细胞 = 伸入腺泡腔的闰管起始部上皮。导管：闰管（细长）→ 小叶内 → 小叶间 → 主导管，胰头与胆总管汇合开口于十二指肠乳头。
- 导管上皮分泌水和碳酸氢盐，受 S 细胞促胰液素调节。胰液碱性，成人每天 $1\sim 2\,\mathrm{L}$，是最重要的消化液。
- 胰岛约 $100$ 万个，占体积约 $1.5\%$，胰尾较多；HE 浅染，有孔毛细血管；HE 不易分型，靠免疫组化。
- A（$20\%$，周边）胰高血糖素升糖；B（$70\%$，中央）胰岛素降糖；不足→糖尿病，过多→低血糖症。
- D（$5\%$）生长抑素旁分泌抑制邻居；PP 细胞分泌胰多肽，抑制胃肠运动、胰液及胆囊收缩。
:::

:::memory{label="本节必背要点"}
- [ ] 胰腺表面覆薄层结缔组织被膜，伸入腺内将实质分隔为许多小叶。
- [ ] 胰腺实质由外分泌部和内分泌部（胰岛）组成；外分泌部构成腺的大部分。
- [ ] 外分泌部分泌的胰液经导管排入十二指肠；胰岛分泌的激素进入血液或淋巴，主要调节糖代谢。
- [ ] 胰腺外分泌部为纯浆液复管泡状腺。
- [ ] 每个腺泡含 $40\sim 50$ 个胰腺泡细胞（pancreatic acinar cell），具有典型浆液细胞形态特点。
- [ ] 胰腺泡细胞分泌胰蛋白酶原、胰糜蛋白酶原、胰淀粉酶、胰脂肪酶、核酸酶等，分别消化各种营养成分。
- [ ] 胰蛋白酶原和胰糜蛋白酶原进入小肠后，被肠激酶激活为有活性的胰蛋白酶和胰糜蛋白酶。
- [ ] 胰腺泡细胞的分泌活动受小肠 I 细胞分泌的缩胆囊素-促胰酶素调节。
- [ ] 胰腺腺泡无肌上皮细胞。
- [ ] 腺泡腔面可见较小的扁平或立方形泡心细胞（centroacinar cell），胞质染色淡，核圆或卵圆。
- [ ] 泡心细胞是延伸入腺泡腔内的闰管起始部上皮细胞。
- [ ] 导管由闰管、小叶内导管、小叶间导管和主导管组成。
- [ ] 闰管细而长，管壁为单层扁平或立方上皮，伸入腺泡的一段由泡心细胞组成。
- [ ] 闰管远端汇合成小叶内导管；小叶内导管在小叶间结缔组织内汇合成小叶间导管，再汇成一条主导管。
- [ ] 主导管贯穿胰腺全长，在胰头部与胆总管汇合，开口于十二指肠乳头。
- [ ] 从小叶内导管至主导管，管腔增大，上皮由单层立方渐变为单层柱状；主导管为单层高柱状，上皮内可见杯状细胞。
- [ ] 胰腺导管上皮可分泌水和碳酸氢盐等多种电解质，受小肠 S 细胞分泌的促胰液素调节。
- [ ] 胰液为碱性液体，含多种消化酶和丰富的电解质，是最重要的消化液；成人每天分泌 $1\sim 2\,\mathrm{L}$。
- [ ] 胰岛（pancreas islet）是内分泌细胞组成的球形细胞团，分布于腺泡之间，HE 染色浅。
- [ ] 成人胰腺约有 $100$ 万个胰岛，约占胰腺体积的 $1.5\%$，于胰尾部较多。
- [ ] 胰岛大小不等，直径 $75\sim 500\,\mu\mathrm{m}$；小的仅十几个细胞，大的有数百个细胞。
- [ ] 胰岛细胞间有丰富的有孔毛细血管。
- [ ] 人胰岛主要有 A、B、D、PP 4 种细胞；HE 不易区分，主要用免疫组织化学法鉴别。
- [ ] A 细胞又称 $\alpha$ 细胞，约占 $20\%$，体积较大，多在胰岛周边部；分泌胰高血糖素（glucagon）。
- [ ] 胰高血糖素促进肝细胞糖原分解为葡萄糖，并抑制糖原合成，使血糖浓度升高。
- [ ] B 细胞又称 $\beta$ 细胞，约占 $70\%$，主要位于胰岛中央部；分泌胰岛素（insulin）。
- [ ] 胰岛素主要促进肝细胞、脂肪细胞等吸收血液内葡萄糖，合成糖原或转化为脂肪贮存，使血糖降低。
- [ ] 胰高血糖素和胰岛素协同，保持血糖动态平衡。
- [ ] B 细胞退化、胰岛素分泌不足 → 血糖升高并从尿中排出，为糖尿病。
- [ ] 胰岛 B 细胞肿瘤或功能亢进 → 胰岛素过多，可致低血糖症。
- [ ] D 细胞又称 $\delta$ 细胞，约占 $5\%$，分散在周边部 A、B 细胞之间，紧密相贴，有缝隙连接。
- [ ] D 细胞分泌生长抑素（somatostatin），以旁分泌方式经缝隙连接抑制邻近 A、B 或 PP 细胞。
- [ ] PP 细胞数量很少，主要在胰岛周边部，也可见于外分泌部导管上皮内及腺泡细胞间。
- [ ] PP 细胞分泌胰多肽（pancreatic polypeptide），抑制胃肠运动、胰液分泌及胆囊收缩。
:::
