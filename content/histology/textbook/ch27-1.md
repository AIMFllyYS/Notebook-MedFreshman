# 一、眼的发生

眼与耳的发生均始于胚胎第 $4$ 周，原基分别是视泡和听泡：视泡来源于神经外胚层，听泡来源于表面外胚层。眼除神经外胚层外，还要表面外胚层和间充质；耳除表面外胚层外，还要内胚层和间充质。本节只把眼摊开：神经管前端的视泡与视柄分别形成视网膜和视神经，表面外胚层在视泡诱导下做成晶状体，周围间充质和表面外胚层做成眼球其余各层及眼睑、泪腺；畸形按教材四条写。耳放到下一节。

眼与耳的发生均始于胚胎第 $4$ 周，其原基分别为视泡和听泡，前者来源于神经外胚层，后者来源于表面外胚层。眼的发生除神经外胚层外，还有表面外胚层和间充质的参与。耳的发生除表面外胚层外，还有内胚层和间充质的参与。

:::definition{label="眼与耳发生的共同起点"}
眼与耳的发生均始于胚胎第 $4$ 周。原基分别是视泡和听泡，不是一开始就有眼球和内、中、外耳三份成品。
:::

:::definition{label="视泡与听泡的胚层"}
视泡来源于神经外胚层；听泡来源于表面外胚层。两份原基不要对调：眼的感光上皮从神经管前端长出来，内耳膜迷路从菱脑两侧的表面外胚层凹进去。
:::

:::definition{label="眼还要的两份材料"}
眼的发生除神经外胚层外，还有表面外胚层和间充质的参与。神经外胚层走视网膜和视神经；表面外胚层走晶状体、角膜上皮、结膜上皮、眼睑表皮和泪腺；间充质走角膜其余各层、虹膜基质、睫状体主体、血管膜、巩膜、眼睑其余结构和玻璃体营养血管所在的那份间充质。
:::

:::definition{label="耳还要的两份材料"}
耳的发生除表面外胚层外，还有内胚层和间充质的参与。表面外胚层走听板至听泡（膜迷路上皮）以及第 $1$ 鳃沟（外耳道）和耳丘（耳郭）；内胚层走第 $1$ 咽囊（咽鼓管、鼓室、鼓膜内上皮）；间充质走听小骨原基、骨迷路、鼓膜内结缔组织和耳郭的其余结构。细节见下一节。
:::

:::compare{title="眼与耳的原基和胚层"}
| 项目 | 眼 | 耳 |
|------|----|----|
| 开始时间 | 胚胎第 $4$ 周 | 胚胎第 $4$ 周 |
| 神经侧 / 表面侧原基 | 视泡（神经外胚层） | 听泡（表面外胚层） |
| 还参与的胚层 | 表面外胚层、间充质 | 内胚层、间充质 |
| 神经外胚层去向 | 视杯 → 视网膜；视柄 → 视神经 | 不直接形成膜迷路 |
| 表面外胚层去向 | 晶状体板 / 晶状体泡、角膜上皮、结膜、眼睑表皮、泪腺 | 听板 → 听窝 → 听泡；第 $1$ 鳃沟 → 外耳道；耳丘表皮 |
| 内胚层去向 | — | 第 $1$ 咽囊 → 管鼓隐窝、咽鼓管、鼓室、鼓膜内上皮 |
| 间充质去向 | 角膜其余各层、虹膜基质、睫状体主体、血管膜、巩膜、眼睑其余结构、脉络膜裂内的玻璃体血管 | 听小骨、骨迷路、鼓膜结缔组织、耳郭其余结构 |
:::

眼的发生开始于胚胎第 $4$ 周，其原基为神经管前端形成的视泡和视柄，分别形成视网膜和视神经。围绕在视泡周围的间充质和表面外胚层则形成眼球的其他结构及眼的附属器。

:::definition{label="眼的发生起点"}
眼的发生开始于胚胎第 $4$ 周。原基是神经管前端形成的视泡和视柄，分别形成视网膜和视神经。
:::

:::definition{label="眼球其余结构与附属器的材料"}
围绕在视泡周围的间充质和表面外胚层形成眼球的其他结构及眼的附属器。视网膜、视神经不从这两份材料来。
:::

:::concept{term="先问这是视泡、视杯还是视柄，再问表面外胚层已经做成晶状体板没有"}
看见眼的发生，先把神经管前端那一份切开：两侧膨出、腔与脑室相通的是视泡；远端内陷成双层杯状才是视杯（外层色素上皮、内层神经层）；近端变细连间脑的是视柄，以后被节细胞轴突填成视神经。再问贴在视泡远端的表面外胚层：受视泡诱导增厚是晶状体板，内陷入视杯并脱离表面外胚层才是晶状体泡。把视泡听成已经是视网膜，或把晶状体听成神经外胚层变的，后面的色素上皮、节细胞轴突和角膜上皮会对错户头。
:::

## （一）眼球的发生

胚胎第 $4$ 周，当神经管前端闭合成前脑时，两侧向外膨出 $1$ 对泡状结构，称视泡（optic vesicle）（图 27-1，图 27-2）。视泡腔与脑室相通，视泡远端膨大，贴近表面外胚层，进而内陷形成双层杯状结构，称视杯（optic cup）。视泡近端变细，称视柄（optic stalk），与间脑相连。与此同时，表面外胚层在视泡的诱导下增厚，形成晶状体板（lens placode）。随后晶状体板内陷入视杯内，且渐与表面外胚层脱离，形成晶状体泡（lens vesicle）。眼的各部分则由视杯、视柄、晶状体泡和它们周围的间充质分化形成。

:::definition{label="视泡"}
胚胎第 $4$ 周，当神经管前端闭合成前脑时，两侧向外膨出 $1$ 对泡状结构，称视泡（optic vesicle）。视泡腔与脑室相通。它还是一对空泡，不是已经分层的视网膜。
:::

:::definition{label="视杯"}
视泡远端膨大，贴近表面外胚层，进而内陷形成双层杯状结构，称视杯（optic cup）。内陷把原来的泡壁折成内、外两层，两层之间暂时还留着视泡腔。
:::

:::definition{label="视柄"}
视泡近端变细，称视柄（optic stalk），与间脑相连。视柄以后演变为视神经，此时还只是连着间脑的细柄。
:::

:::definition{label="晶状体板"}
表面外胚层在视泡的诱导下增厚，形成晶状体板（lens placode）。没有视泡贴上来诱导，表面外胚层不会自己在这里加厚成板。
:::

:::definition{label="晶状体泡"}
晶状体板内陷入视杯内，且渐与表面外胚层脱离，形成晶状体泡（lens vesicle）。脱离之后，表面外胚层在原处重新封严，以后在晶状体泡诱导下分化为角膜上皮；晶状体本身不再连在体表。
:::

:::definition{label="眼球各部分的四份材料"}
眼的各部分由视杯、视柄、晶状体泡和它们周围的间充质分化形成。视杯走视网膜，视柄走视神经，晶状体泡走晶状体，间充质走角膜深层、血管膜、巩膜和虹膜基质等。
:::

:::timeline{period="从视泡到晶状体泡"}
- **第4周** 神经管前端闭合成前脑，两侧向外膨出一对视泡；视泡腔与脑室相通
- **同时** 视泡远端贴近表面外胚层，诱导其增厚为晶状体板
- **随后** 视泡远端内陷成双层视杯；近端变细为视柄，与间脑相连
- **随后** 晶状体板内陷入视杯，渐与表面外胚层脱离，形成晶状体泡
- **去向** 视杯、视柄、晶状体泡及其周围间充质分化为眼的各部分
:::

:::cause-effect{title="视泡贴上来，表面外胚层才加厚成晶状体板"}
- 因：视泡远端膨大并贴近表面外胚层
- 果：该处表面外胚层受诱导增厚，形成晶状体板
- 因：晶状体板内陷入视杯并与表面外胚层脱离
- 果：形成晶状体泡；体表外胚层在原处封严，以后受晶状体泡诱导成角膜上皮
- 制约：没有视泡这份诱导，晶状体板不会在这里出现
:::

:::pitfall{label="视泡还不是视杯，视杯内陷才分成内、外两层"}
第 $4$ 周先有视泡，腔与脑室相通。远端内陷之后才叫视杯，这才有外层色素上皮、内层神经层可分。写成“前脑两侧直接长出视网膜”，视泡腔变窄消失、脉络膜裂和视柄这几本账都会没有地方挂。
:::

:::insight{label="一份神经外胚层先膨出再内陷，一份表面外胚层被诱导内陷成泡"}
视泡从神经管前端长出来，再自己内陷成杯；晶状体板是被视泡诱导的表面外胚层，内陷后脱离体表成泡。感光上皮和屈光体不从同一胚层来。把晶状体写成神经管变的，或把视网膜写成表皮变的，两份诱导会对错。
:::

### 1. 视网膜的发生

视网膜由视杯内、外两层共同分化而成。视杯外层分化为色素上皮层。视杯内层增厚，自第 $5$ 周起，先后分化出节细胞、视锥细胞、无长突细胞、水平细胞、视杆细胞和双极细胞。视杯两层之间的视泡腔变窄，最后消失，于是两层相贴，构成视网膜视部。在视杯口边缘部，内层上皮不增厚，与外层分化的色素上皮相贴，并向晶状体泡与角膜之间的间充质内延伸，形成视网膜盲部，即睫状体与虹膜的上皮。

:::definition{label="视网膜的两层来源"}
视网膜由视杯内、外两层共同分化而成。外层和内层都要，缺一层就不是完整视网膜。
:::

:::definition{label="色素上皮层（发生）"}
视杯外层分化为色素上皮层。它是视网膜最外面那一层色素细胞，不是脉络膜，也不是视杯内层。
:::

:::definition{label="视杯内层的细胞出场顺序"}
视杯内层增厚，自第 $5$ 周起，先后分化出节细胞、视锥细胞、无长突细胞、水平细胞、视杆细胞和双极细胞。顺序以教材为准，不要按成体“光先打在视杆视锥上”倒过来记发生。
:::

:::definition{label="视网膜视部"}
视杯两层之间的视泡腔变窄，最后消失，于是两层相贴，构成视网膜视部。视部是感光的那一段，内层已经增厚并分化出神经元。
:::

:::definition{label="视网膜盲部"}
在视杯口边缘部，内层上皮不增厚，与外层分化的色素上皮相贴，并向晶状体泡与角膜之间的间充质内延伸，形成视网膜盲部，即睫状体与虹膜的上皮。盲部没有节细胞到双极细胞这一套感光通路。
:::

:::compare{title="视杯外层、内层与视部、盲部"}
| 项目 | 视杯外层 | 视杯内层（视部） | 视杯口边缘（盲部） |
|------|----------|------------------|---------------------|
| 分化 | 色素上皮层 | 增厚，自第 $5$ 周起分化出神经元和感觉细胞 | 内层上皮不增厚，与色素上皮相贴 |
| 细胞 | 色素上皮细胞 | 先后：节细胞、视锥细胞、无长突细胞、水平细胞、视杆细胞、双极细胞 | 两层上皮，成为睫状体与虹膜的上皮 |
| 视泡腔 | 与内层之间的腔变窄、消失后两层相贴 | 同左 | 边缘部两层直接相贴并向前延伸 |
| 位置 | 贴在视部神经层外面 | 视杯的大部分 | 视杯口，伸入晶状体泡与角膜之间的间充质 |
| 不要听成 | 脉络膜 | 一开始就有视杆在最外 | 已经能感光的视网膜 |
:::

:::timeline{period="视杯内层细胞的出场顺序"}
- **第5周起** 视杯内层开始增厚并分化
- **先后顺序** 节细胞 → 视锥细胞 → 无长突细胞 → 水平细胞 → 视杆细胞 → 双极细胞
- **同时** 视杯两层之间的视泡腔变窄、消失，两层相贴成视网膜视部
- **视杯口** 内层不增厚，与色素上皮相贴并向前延伸，成视网膜盲部（睫状体与虹膜的上皮）
:::

:::pitfall{label="视杯外层是色素上皮，不是脉络膜；盲部不是“瞎了的视部”"}
脉络膜来自视杯周围间充质的内层，要到血管膜那一本才出现。视杯外层始终是视网膜色素上皮。盲部是视杯口边缘内层不增厚、两层上皮前伸做成睫状体与虹膜的上皮，本来就没有感光细胞，不是视部后来坏掉。把外层写成血管膜，虹膜上皮会没有来路。
:::

:::tip{label="视杯内层细胞出场顺序"}
节细胞、视锥细胞、无长突细胞、水平细胞、视杆细胞、双极细胞。可记「节、锥、无、水、杆、双」。发生顺序与光子到达成体视网膜的顺序不是同一条尺。
:::

:::insight{label="视泡腔一消失，内外两层才贴成视部"}
杯还是空的时候，内外层中间隔着原来的视泡腔。腔变窄消失，两层相贴，视部才立住。临床看到的视网膜脱离，裂开处往往就在这两层曾经夹着腔的界面上——发生学上它们是贴上去的，不是一块组织长出来的。
:::

### 2. 视神经的发生

胚胎第 $5$ 周，视杯及视柄下方向内凹陷，形成 $1$ 条纵沟，称脉络膜裂（choroid fissure）。脉络膜裂内除含间充质外，还有玻璃体动、静脉，为玻璃体和晶状体的发育提供营养。玻璃体动脉还发出分支营养视网膜。脉络膜裂于第 $7$ 周封闭，玻璃体动、静脉穿经玻璃体的一段退化，并遗留一残迹，称玻璃体管（图 27-3，图 27-4）。玻璃体动、静脉的近侧段则成为视网膜中央动、静脉。视柄与视杯相连，也分内、外两层。随着视网膜的分化发育，逐渐增多的节细胞轴突向视柄内层聚集，视柄内层逐渐增厚，并与外层融合。视柄内、外层细胞演变为星形胶质细胞和少突胶质细胞，并围绕在节细胞轴突周围，视柄演变为视神经。

:::definition{label="脉络膜裂"}
胚胎第 $5$ 周，视杯及视柄下方向内凹陷，形成 $1$ 条纵沟，称脉络膜裂（choroid fissure）。它是沟，不是已经分化的脉络膜。
:::

:::definition{label="玻璃体动、静脉"}
脉络膜裂内除含间充质外，还有玻璃体动、静脉，为玻璃体和晶状体的发育提供营养。玻璃体动脉还发出分支营养视网膜。它们走在裂里，给尚未成形的玻璃体、晶状体和视网膜供血。
:::

:::definition{label="玻璃体管"}
脉络膜裂于第 $7$ 周封闭，玻璃体动、静脉穿经玻璃体的一段退化，并遗留一残迹，称玻璃体管。管是退化后的残迹，不是一条长期供血的动脉。
:::

:::definition{label="视网膜中央动、静脉（发生）"}
玻璃体动、静脉的近侧段成为视网膜中央动、静脉。远侧穿经玻璃体的一段退化成玻璃体管，近侧留下来改名。
:::

:::definition{label="视柄的内、外两层"}
视柄与视杯相连，也分内、外两层。后来节细胞轴突向视柄内层聚集，内层增厚并与外层融合。
:::

:::definition{label="视神经（发生）"}
视柄内、外层细胞演变为星形胶质细胞和少突胶质细胞，并围绕在节细胞轴突周围，视柄演变为视神经。视神经的轴突来自视网膜节细胞，胶质来自视柄细胞，不是另从脑里长出一根神经插进眼里。
:::

::figure{src="/images/histology/textbook/p0295_01.png" caption="图27-3 视神经的发生模式图（视柄横切面）。第5周：视柄内、外层围成视柄腔，下方脉络膜裂开放，裂内有间充质和玻璃体血管；第6周：内层增厚，节细胞轴突增多，脉络膜裂变窄；第7周：脉络膜裂闭合，视柄腔消失，轴突充满视柄，中央为视网膜中央动、静脉，外周为视神经鞘。" alt="三幅视柄横切：第5周下方开口的脉络膜裂含红蓝血管；第6周裂变窄；第7周裂闭合，蓝色轴突充满切面，中央动静脉居中"}

:::compare{title="脉络膜裂开放与第7周封闭"}
| 项目 | 第 $5$ 周（裂开放） | 第 $7$ 周（裂封闭） |
|------|---------------------|---------------------|
| 视杯、视柄下方 | $1$ 条纵沟：脉络膜裂 | 裂封闭 |
| 裂内 | 间充质 + 玻璃体动、静脉 | 血管近侧段留下，改称视网膜中央动、静脉 |
| 营养 | 玻璃体、晶状体；玻璃体动脉分支营养视网膜 | 穿经玻璃体的一段退化 |
| 残迹 | — | 玻璃体管 |
| 视柄 | 内、外两层，腔仍在 | 节细胞轴突填入内层，内外层融合，柄成视神经 |
:::

:::cause-effect{title="裂先开给血管走，第7周再关上"}
- 因：第 $5$ 周视杯及视柄下方向内凹陷成脉络膜裂
- 果：间充质和玻璃体动、静脉得以进入，营养玻璃体、晶状体，并分支营养视网膜
- 因：第 $7$ 周脉络膜裂封闭
- 果：穿经玻璃体的血管段退化，留下玻璃体管；近侧段成为视网膜中央动、静脉
- 因：节细胞轴突向视柄内层聚集，内层增厚并与外层融合，视柄细胞变成星形胶质细胞和少突胶质细胞
- 果：视柄演变为视神经
:::

:::pitfall{label="脉络膜裂不是脉络膜，玻璃体管也不是还在供血的玻璃体动脉"}
裂是第 $5$ 周视杯、视柄下方的纵沟，用来给间充质和玻璃体血管通过；脉络膜是第 $6\sim 7$ 周视杯周围间充质内层贴在视网膜外面分化来的。裂在第 $7$ 周要封闭。玻璃体管是穿经玻璃体那一段血管退化后的残迹，不是一条永久动脉。把裂听成血管膜，或把玻璃体管听成还在给晶状体供血，后面的视网膜中央动、静脉会对错户头。
:::

:::insight{label="视神经是节细胞轴突把视柄填满，胶质就地由柄壁细胞变"}
轴突从视网膜视部的节细胞长进视柄内层，柄壁细胞变成星形胶质细胞和少突胶质细胞包在轴突周围。视神经不是“脑神经长进眼睛”，是眼睛这边的轴突沿着视柄走回间脑。少突胶质细胞在这里出现，也解释了视神经属于中枢纤维、可以被中枢脱髓鞘病变累及。
:::

:::note{label="玻璃体在本章怎么出现"}
教材没有单列“玻璃体的发生”一小节。能写进正文的是：脉络膜裂内的间充质和玻璃体动、静脉为玻璃体和晶状体的发育提供营养；穿经玻璃体的血管段第 $7$ 周后退化，留下玻璃体管；图 27-4 在视杯围成的腔内标出玻璃体。玻璃体本身挂在这套营养和残迹账上，不要另造三级玻璃体的说法。
:::

### 3. 晶状体的发生

晶状体由晶状体泡演变而成。最初，晶状体泡由单层上皮组成。泡的前壁细胞呈立方形，分化为晶状体上皮；后壁细胞呈高柱状，并逐渐向前壁方向伸长，形成初级晶状体纤维。泡腔逐渐缩小，直到消失，晶状体变为实体结构（图 27-5）。此后，晶状体赤道区的上皮细胞不断增生、变长，形成次级晶状体纤维，原有的初级晶状体纤维及其胞核逐渐退化形成晶状体核。新的晶状体纤维逐层添加到晶状体核的周围，晶状体核及晶状体逐渐增大。此过程持续终身，但随年龄增长而速度减慢。

:::definition{label="晶状体泡的上皮"}
最初，晶状体泡由单层上皮组成。前壁和后壁还没有分成上皮与纤维。
:::

:::definition{label="晶状体上皮"}
泡的前壁细胞呈立方形，分化为晶状体上皮。前壁保持立方，不伸长成纤维。
:::

:::definition{label="初级晶状体纤维"}
后壁细胞呈高柱状，并逐渐向前壁方向伸长，形成初级晶状体纤维。纤维从后壁朝前长，把泡腔挤小。
:::

:::definition{label="晶状体变为实体"}
泡腔逐渐缩小，直到消失，晶状体变为实体结构。空泡阶段结束，才谈得上次级纤维添到核周围。
:::

:::definition{label="次级晶状体纤维"}
晶状体赤道区的上皮细胞不断增生、变长，形成次级晶状体纤维。赤道区是以后终身加纤维的地点。
:::

:::definition{label="晶状体核"}
原有的初级晶状体纤维及其胞核逐渐退化形成晶状体核。核是初级纤维退下来的中心，不是又长出一枚细胞核团。
:::

:::definition{label="晶状体的终身生长"}
新的晶状体纤维逐层添加到晶状体核的周围，晶状体核及晶状体逐渐增大。此过程持续终身，但随年龄增长而速度减慢。出生后仍在加层，只是越来越慢。
:::

::figure{src="/images/histology/textbook/p0296_01.png" caption="图27-5 晶状体纤维的发育模式图。左：晶状体泡后壁细胞呈高柱状并向前伸长，前壁仍为立方形晶状体上皮，中央尚有晶状体腔；右：后壁来源的初级晶状体纤维充满原泡腔，晶状体变为实体，前壁立方上皮仍在。" alt="左图椭圆泡后壁蓝色高柱状细胞伸向中央空腔，前壁粉染立方形细胞；右图纤维填满，前壁仍为单层立方上皮"}

:::compare{title="初级晶状体纤维与次级晶状体纤维"}
| 项目 | 初级晶状体纤维 | 次级晶状体纤维 |
|------|----------------|----------------|
| 来源 | 晶状体泡后壁高柱状细胞向前壁方向伸长 | 赤道区上皮细胞不断增生、变长 |
| 出现时机 | 泡仍中空时 | 泡腔消失、晶状体成实体之后 |
| 去向 | 连同胞核逐渐退化，形成晶状体核 | 逐层添加到晶状体核周围，使核和晶状体增大 |
| 是否终身 | 作为核被包在中心 | 持续终身，随年龄增长速度减慢 |
:::

:::derivation{title="后壁为什么先变成纤维，前壁为什么保持上皮"}
晶状体泡是单层上皮围成的空泡。后壁细胞变成高柱状并向前伸长，才能把泡腔填实，成为第一批纤维（初级晶状体纤维）。前壁对着将来的角膜和前房，保持立方形，成为晶状体上皮。赤道区夹在前壁上皮和后壁纤维之间，以后从这里不断增生、变长，往核周围加次级纤维。前壁若也全部变成纤维，赤道区就没有上皮可增生，终身加层这本账会断掉。
:::

:::pitfall{label="晶状体上皮在前壁，纤维从后壁和赤道来，不要写成整个泡一次性变成核"}
前壁立方 → 晶状体上皮；后壁伸长 → 初级纤维 → 退化成晶状体核；赤道区以后不断出次级纤维。写成“晶状体泡塌陷就成了一块晶状体核”，次级纤维和终身生长会消失，老年核性白内障也没有“一层层加在核周围”的发生学来路。
:::

:::insight{label="腔先被初级纤维填满，以后的纤维只能围着核加层"}
泡腔一消失，中心就被初级纤维占住，并退化成核。此后只能从赤道往外加次级纤维，所以晶状体是分层的实体，而不是中空的泡。年龄越大核越致密、加层越慢，和这条发生尺是同一件事。
:::

### 4. 角膜、虹膜和眼房的发生

在晶状体泡的诱导下，其前方的表面外胚层分化为角膜上皮，角膜上皮后面的间充质分化为角膜其余各层。位于晶状体前面的视杯口边缘部的间充质形成虹膜基质，其周边部厚，中央部薄，封闭视杯口，称瞳孔膜（pupillary membrane）。视杯两层上皮的前缘部分形成虹膜上皮层，与虹膜基质共同发育成虹膜。在虹膜形成以前，晶状体泡与角膜之间的间充质内出现一个腔隙，即前房。虹膜与睫状体形成后，虹膜、睫状体与晶状体之间形成后房。出生前瞳孔膜被吸收，前、后房经瞳孔相连通（图 27-4）。

:::definition{label="角膜上皮（发生）"}
在晶状体泡的诱导下，其前方的表面外胚层分化为角膜上皮。诱导者是晶状体泡，材料是表面外胚层，不是视杯。
:::

:::definition{label="角膜其余各层"}
角膜上皮后面的间充质分化为角膜其余各层。上皮走外胚层，基质和后面几层走间充质。
:::

:::definition{label="虹膜基质"}
位于晶状体前面的视杯口边缘部的间充质形成虹膜基质。它是间充质来的那一份虹膜，还不是上皮。
:::

:::definition{label="瞳孔膜"}
虹膜基质周边部厚，中央部薄，封闭视杯口，称瞳孔膜（pupillary membrane）。它暂时把视杯口封住，出生前应被吸收。
:::

:::definition{label="虹膜上皮层"}
视杯两层上皮的前缘部分形成虹膜上皮层，与虹膜基质共同发育成虹膜。上皮来自视杯（视网膜盲部那一本），基质来自间充质，两份合起来才是虹膜。
:::

:::definition{label="前房（发生）"}
在虹膜形成以前，晶状体泡与角膜之间的间充质内出现一个腔隙，即前房。前房出现得早，在虹膜还没有立住的时候。
:::

:::definition{label="后房（发生）"}
虹膜与睫状体形成后，虹膜、睫状体与晶状体之间形成后房。后房要等虹膜、睫状体出来才有前后界限。
:::

:::definition{label="瞳孔把前、后房连通"}
出生前瞳孔膜被吸收，前、后房经瞳孔相连通。瞳孔是膜吸收后留下的孔，不是一开始就凿出来的。
:::

:::compare{title="角膜、虹膜与前、后房的材料"}
| 结构 | 主要来源 | 诱导 / 时机 | 不要听成 |
|------|----------|-------------|----------|
| 角膜上皮 | 晶状体泡前方的表面外胚层 | 晶状体泡诱导 | 视杯上皮前伸 |
| 角膜其余各层 | 角膜上皮后面的间充质 | 在上皮后方 | 也是表面外胚层 |
| 虹膜基质 | 视杯口边缘部、晶状体前面的间充质 | 周边厚、中央薄，中央即瞳孔膜 | 视杯上皮 |
| 虹膜上皮层 | 视杯两层上皮的前缘（盲部） | 与基质共同成虹膜 | 间充质 |
| 前房 | 晶状体泡与角膜之间间充质内的腔隙 | 虹膜形成以前 | 虹膜后方的腔 |
| 后房 | 虹膜、睫状体与晶状体之间 | 虹膜与睫状体形成后 | 玻璃体腔 |
| 瞳孔 | 出生前瞳孔膜被吸收留下的通道 | 前、后房经此连通 | 视杯口本身 |
:::

:::cause-effect{title="晶状体泡诱导角膜，视杯前缘加间充质才成虹膜"}
- 因：晶状体泡贴在前方
- 果：前方表面外胚层分化为角膜上皮；其后方间充质分化为角膜其余各层
- 因：视杯口边缘间充质形成虹膜基质，中央薄的部分封闭视杯口
- 果：出现瞳孔膜
- 因：视杯两层上皮前缘形成虹膜上皮层，与基质共同发育
- 果：虹膜立住；虹膜、睫状体与晶状体之间出现后房
- 因：出生前瞳孔膜被吸收
- 果：前、后房经瞳孔相通
:::

:::pitfall{label="瞳孔膜不是虹膜，前房也不是等虹膜长好才出现"}
瞳孔膜是虹膜基质中央那层薄间充质，暂时封住视杯口；虹膜上皮来自视杯前缘。前房在虹膜形成以前就在晶状体泡与角膜之间的间充质里裂出来了；后房才等虹膜、睫状体形成。写成“先有虹膜再挖前房”，或把瞳孔膜当成虹膜本身，瞳孔膜残留和先天性无虹膜会对错户头。
:::

### 5. 血管膜和巩膜的发生

第 $6\sim 7$ 周时，视杯周围的间充质分为内、外两层。内层富含血管和色素细胞，分化成眼球壁的血管膜。血管膜的大部分贴在视网膜外面，即为脉络膜；贴在视杯口边缘部的间充质则分化为虹膜基质和睫状体的主体。外层较致密，分化为巩膜。脉络膜与巩膜分别与视神经周围的软脑膜和硬脑膜相连续（图 27-4）。

:::definition{label="视杯周围间充质的分层"}
第 $6\sim 7$ 周时，视杯周围的间充质分为内、外两层。内层将来是血管膜，外层将来是巩膜，时间在晶状体泡和视杯已经立住之后。
:::

:::definition{label="血管膜（发生）"}
内层富含血管和色素细胞，分化成眼球壁的血管膜。富含血管和色素是这一层的标记，不要和致密的外层搞混。
:::

:::definition{label="脉络膜（发生）"}
血管膜的大部分贴在视网膜外面，即为脉络膜。它贴的是已经相贴的视网膜视部外面，不是视杯外层本身。
:::

:::definition{label="虹膜基质和睫状体主体（血管膜侧）"}
贴在视杯口边缘部的间充质分化为虹膜基质和睫状体的主体。与上一小节虹膜基质是同一份材料，这里补上睫状体的主体也从这份间充质来。
:::

:::definition{label="巩膜（发生）"}
外层较致密，分化为巩膜。致密、少血管，和内层的血管膜相对。
:::

:::definition{label="与脑膜连续"}
脉络膜与巩膜分别与视神经周围的软脑膜和硬脑膜相连续。脉络膜对软脑膜，巩膜对硬脑膜，不要对调。
:::

::figure{src="/images/histology/textbook/p0296_02.png" caption="图27-4 眼球与眼睑的发生模式图。上（第7周）：视杯内、外层，视柄内玻璃体动脉分支入玻璃体，前方晶状体，体表已见上、下眼睑皱褶。下（第15周）：外层巩膜、内层脉络膜贴于视网膜（含色素层）外面，视柄内为视网膜中央动脉，玻璃体充盈视杯腔，晶状体前方可见瞳孔膜与前房，最前为角膜及上、下眼睑。" alt="上图第7周视杯包玻璃体和晶状体，前方上下眼睑皱褶；下图第15周巩膜脉络膜分层，瞳孔膜横在晶状体前，前房在角膜后方"}

:::compare{title="视杯周围间充质的内层与外层"}
| 项目 | 内层 | 外层 |
|------|------|------|
| 性状 | 富含血管和色素细胞 | 较致密 |
| 分化 | 血管膜 | 巩膜 |
| 大部分去向 | 贴视网膜外面 → 脉络膜 | 包在血管膜外面 → 巩膜 |
| 视杯口边缘 | 虹膜基质和睫状体的主体 | — |
| 与脑膜 | 脉络膜与视神经周围的软脑膜相连续 | 巩膜与视神经周围的硬脑膜相连续 |
:::

:::pitfall{label="脉络膜是间充质内层贴在视网膜外面，不是视杯外层改名"}
视杯外层始终是色素上皮。脉络膜是第 $6\sim 7$ 周才从视杯周围间充质内层分化出来、贴到视网膜外面去的。写成“视杯外层变成脉络膜”，色素上皮和血管膜会并成一层，巩膜对硬脑膜、脉络膜对软脑膜这组连续关系也会错位。
:::

:::insight{label="眼球壁三层在发生上不是同时铺上的"}
先有视杯两层（视网膜），再有周围间充质分成血管膜和巩膜。角膜上皮还要等晶状体泡去诱导表面外胚层。三层壁对的是三份时间、两份胚层加间充质，不是“眼泡表面一次性长出三层膜”。
:::

## （二）眼睑和泪腺的发生

第 $7$ 周时，眼球前方与角膜上皮毗邻的表面外胚层形成上、下两个皱褶，分别发育成上、下眼睑。反折到眼睑内表面的外胚层分化为复层柱状的结膜上皮，与角膜上皮相延续。眼睑外面的表面外胚层分化为表皮。皱褶内的间充质则分化为眼睑的其他结构。第 $10$ 周时，上、下眼睑的边缘互相融合，至第 $7$ 或第 $8$ 个月时重新分开。上眼睑外侧部表面外胚层上皮长入间充质内，分化为泪腺的腺泡和导管。泪腺于出生后 $6$ 周分泌泪液；出生后 $3\sim 4$ 岁基本完成发育。

:::definition{label="上、下眼睑的原基"}
第 $7$ 周时，眼球前方与角膜上皮毗邻的表面外胚层形成上、下两个皱褶，分别发育成上、下眼睑。皱褶出现以前还没有眼睑。
:::

:::definition{label="结膜上皮（发生）"}
反折到眼睑内表面的外胚层分化为复层柱状的结膜上皮，与角膜上皮相延续。结膜和角膜上皮是同一份表面外胚层的连续面。
:::

:::definition{label="眼睑表皮与皱褶内间充质"}
眼睑外面的表面外胚层分化为表皮。皱褶内的间充质则分化为眼睑的其他结构。外面表皮、内面结膜、中间间充质，三份不要并成一层。
:::

:::definition{label="眼睑边缘的融合与再分开"}
第 $10$ 周时，上、下眼睑的边缘互相融合，至第 $7$ 或第 $8$ 个月时重新分开。胚期内先合上，胎期后段再睁开，不是一直睁着长。
:::

:::definition{label="泪腺（发生）"}
上眼睑外侧部表面外胚层上皮长入间充质内，分化为泪腺的腺泡和导管。起点是上眼睑外侧部的表面外胚层，不是下眼睑，也不是视杯。
:::

:::definition{label="泪腺开始工作和发育完成"}
泪腺于出生后 $6$ 周分泌泪液；出生后 $3\sim 4$ 岁基本完成发育。出生当时还没有按成体那样分泌，发育完成要到幼儿期。
:::

:::timeline{period="眼睑与泪腺"}
- **第7周** 眼球前方与角膜上皮毗邻的表面外胚层形成上、下两个皱褶 → 上、下眼睑
- **同时** 内表面外胚层 → 复层柱状结膜上皮（与角膜上皮延续）；外面 → 表皮；皱褶内间充质 → 眼睑其他结构
- **第10周** 上、下眼睑边缘互相融合
- **第7或第8个月** 眼睑重新分开
- **上眼睑外侧** 表面外胚层长入间充质 → 泪腺腺泡和导管
- **出生后6周** 开始分泌泪液
- **出生后3～4岁** 泪腺基本完成发育
:::

| 眼睑原基 | 第 $7$ 周角膜上皮毗邻的表面外胚层皱褶 | 上、下眼睑 |

:::pitfall{label="第10周眼睑先融合，第7或第8个月才分开，不要写成一直睁眼发育"}
上、下睑边缘在第 $10$ 周互相融合，到第 $7$ 或第 $8$ 个月才重新分开。把融合听成畸形，或把出生时睁眼写成“从来没有合上过”，这本时间尺会断。泪腺也不要写成“和眼睑同时开始分泌”：腺泡导管来自上眼睑外侧外胚层长入，真正分泌在出生后 $6$ 周，基本完成发育在出生后 $3\sim 4$ 岁。
:::

## （三）主要畸形

### 1. 先天性白内障

先天性白内障（congenital cataract）为晶状体的透明度发生异常。多为遗传性，也可由于母体在妊娠早期感染风疹病毒、母体甲状腺功能减退、营养不良和维生素缺乏等引起。

:::definition{label="先天性白内障"}
先天性白内障（congenital cataract）为晶状体的透明度发生异常。落点在晶状体，不是角膜混浊，也不是玻璃体管残留。
:::

:::definition{label="先天性白内障的原因"}
多为遗传性，也可由于母体在妊娠早期感染风疹病毒、母体甲状腺功能减退、营养不良和维生素缺乏等引起。遗传是多数；环境因素里教材点名的是妊娠早期风疹、母体甲减、营养不良和维生素缺乏。
:::

### 2. 先天性无虹膜

先天性无虹膜属常染色体显性遗传性异常，多为双侧性。形成的确切机制还不清楚，可能是视杯前缘生长和分化障碍，虹膜不能发育所致。由于无虹膜，瞳孔特别大。

:::definition{label="先天性无虹膜"}
先天性无虹膜属常染色体显性遗传性异常，多为双侧性。遗传方式是常染色体显性，侧别多为双侧。
:::

:::definition{label="先天性无虹膜的可能机制"}
形成的确切机制还不清楚，可能是视杯前缘生长和分化障碍，虹膜不能发育所致。对的是视杯前缘（虹膜上皮那一本），不是瞳孔膜没吸收。
:::

:::definition{label="无虹膜时的瞳孔"}
由于无虹膜，瞳孔特别大。这是虹膜缺如的外形，不要写成瞳孔膜残留那种薄膜遮挡。
:::

### 3. 先天性青光眼

先天性青光眼（congenital glaucoma）属常染色体隐性遗传性疾病，发病机制尚不十分明确。有人认为是由于巩膜静脉窦或小梁网发育障碍所致。患儿房水排出受阻，眼压增高，眼球胀大，角膜突出，因眼球增大故又称牛眼。

:::definition{label="先天性青光眼"}
先天性青光眼（congenital glaucoma）属常染色体隐性遗传性疾病，发病机制尚不十分明确。遗传方式是常染色体隐性，机制教材写明尚不十分明确。
:::

:::definition{label="先天性青光眼的可能环节"}
有人认为是由于巩膜静脉窦或小梁网发育障碍所致。房水排出通道这一侧出问题，不是晶状体透明度，也不是视杯前缘没长虹膜。
:::

:::definition{label="牛眼"}
患儿房水排出受阻，眼压增高，眼球胀大，角膜突出，因眼球增大故又称牛眼。牛眼指眼球增大的外形，不是另一种独立疾病。
:::

### 4. 瞳孔膜残留

瞳孔膜残留因瞳孔膜未能全部退化消失所致，在瞳孔处有薄膜或蛛网状细丝遮盖在晶状体前面，轻度残留通常不影响视力和瞳孔活动。

:::definition{label="瞳孔膜残留"}
瞳孔膜残留因瞳孔膜未能全部退化消失所致，在瞳孔处有薄膜或蛛网状细丝遮盖在晶状体前面。材料是没退干净的瞳孔膜，位置在晶状体前面。
:::

:::note{label="轻度瞳孔膜残留"}
轻度残留通常不影响视力和瞳孔活动。不是一律致盲，也不等于先天性无虹膜。
:::

:::compare{title="眼的四种主要畸形"}
| 畸形 | 英文 / 遗传 | 发生学落点 | 主要表现 |
|------|-------------|------------|----------|
| 先天性白内障 | congenital cataract；多为遗传，亦可妊娠早期风疹、母体甲减、营养不良、维生素缺乏 | 晶状体透明度异常 | 晶状体混浊 |
| 先天性无虹膜 | 常染色体显性；多为双侧 | 可能是视杯前缘生长和分化障碍，虹膜不能发育 | 瞳孔特别大 |
| 先天性青光眼 | congenital glaucoma；常染色体隐性；机制尚不十分明确 | 有人认为巩膜静脉窦或小梁网发育障碍 | 房水排出受阻，眼压增高，眼球胀大，角膜突出，又称牛眼 |
| 瞳孔膜残留 | — | 瞳孔膜未能全部退化消失 | 瞳孔处薄膜或蛛网状细丝遮盖晶状体前面；轻度通常不影响视力和瞳孔活动 |
:::

:::pitfall{label="无虹膜是视杯前缘没做成虹膜，瞳孔膜残留是中央那层膜没退干净"}
无虹膜：虹膜本身发育不出来，瞳孔特别大，常染色体显性、多为双侧。瞳孔膜残留：虹膜可以有，只是封闭视杯口的薄间充质没全部吸收，瞳孔上挂着膜或细丝。写成“瞳孔有膜就是无虹膜”，两本账会并成一条。先天性白内障对晶状体透明度，先天性青光眼对房水排出，也不要和这两条对调。
:::

:::insight{label="四种畸形分别挂在晶状体、视杯前缘、房水通道和瞳孔膜上"}
白内障问晶状体清不清；无虹膜问视杯前缘长没长；青光眼问巩膜静脉窦、小梁网排不排得出房水；瞳孔膜残留问出生前该吸收的膜退没退。发生学上的四份结构，恰好是四条畸形的户头。
:::

:::keypoint{label="视泡成杯成柄，晶状体泡被诱导，间充质做膜和巩膜"}
- 第 $4$ 周前脑两侧膨出视泡，远端内陷成双层视杯，近端变细成视柄；表面外胚层受视泡诱导成晶状体板，再内陷脱离成晶状体泡。
- 视杯外层 → 色素上皮；内层自第 $5$ 周起分化节、锥、无、水、杆、双；腔消失两层相贴为视部；杯口内层不增厚，前伸为盲部（睫状体与虹膜上皮）。
- 第 $5$ 周脉络膜裂，第 $7$ 周封闭；玻璃体血管近侧段 → 视网膜中央动、静脉，穿经玻璃体段退化成玻璃体管；视柄被节细胞轴突充填，壁细胞成星形胶质细胞和少突胶质细胞，演变为视神经。
- 晶状体：前壁上皮，后壁初级纤维填腔成核，赤道区次级纤维终身加层。晶状体泡诱导角膜上皮，后方间充质成角膜其余各层。
- 虹膜 = 视杯前缘上皮 + 间充质基质；瞳孔膜出生前吸收，前、后房经瞳孔通。第 $6\sim 7$ 周视杯周围间充质内层 → 血管膜（脉络膜，以及虹膜基质、睫状体主体），外层 → 巩膜，分别连软脑膜、硬脑膜。
- 第 $7$ 周眼睑皱褶，第 $10$ 周融合，第 $7$ 或第 $8$ 个月再分开；泪腺来自上眼睑外侧外胚层，出生后 $6$ 周分泌， $3\sim 4$ 岁基本完成发育。
- 畸形：先天性白内障、先天性无虹膜、先天性青光眼（牛眼）、瞳孔膜残留。
:::

:::memory{label="本节必背要点"}
- [ ] 眼与耳的发生均始于胚胎第 $4$ 周，原基分别为视泡和听泡。
- [ ] 视泡来源于神经外胚层，听泡来源于表面外胚层。
- [ ] 眼的发生除神经外胚层外，还有表面外胚层和间充质的参与。
- [ ] 眼的原基为神经管前端形成的视泡和视柄，分别形成视网膜和视神经。
- [ ] 胚胎第 $4$ 周，神经管前端闭合成前脑时，两侧向外膨出 $1$ 对视泡（optic vesicle）。
- [ ] 视泡腔与脑室相通；远端内陷成双层视杯（optic cup）；近端变细为视柄（optic stalk），与间脑相连。
- [ ] 表面外胚层在视泡诱导下增厚为晶状体板（lens placode），内陷入视杯并脱离表面外胚层，形成晶状体泡（lens vesicle）。
- [ ] 视杯外层分化为色素上皮层。
- [ ] 视杯内层自第 $5$ 周起先后分化出节细胞、视锥细胞、无长突细胞、水平细胞、视杆细胞和双极细胞。
- [ ] 视杯两层之间的视泡腔变窄消失，两层相贴，构成视网膜视部。
- [ ] 视杯口边缘内层不增厚，与色素上皮相贴并向前延伸，形成视网膜盲部，即睫状体与虹膜的上皮。
- [ ] 第 $5$ 周视杯及视柄下方凹陷形成脉络膜裂（choroid fissure）。
- [ ] 脉络膜裂内有间充质和玻璃体动、静脉，营养玻璃体和晶状体；玻璃体动脉分支营养视网膜。
- [ ] 脉络膜裂于第 $7$ 周封闭；穿经玻璃体的血管段退化，遗留玻璃体管；近侧段成为视网膜中央动、静脉。
- [ ] 节细胞轴突向视柄内层聚集，视柄内外层细胞演变为星形胶质细胞和少突胶质细胞，视柄演变为视神经。
- [ ] 晶状体泡前壁立方细胞分化为晶状体上皮；后壁高柱状细胞向前伸长，形成初级晶状体纤维。
- [ ] 泡腔消失后晶状体成实体；赤道区上皮形成次级晶状体纤维；初级纤维及其胞核退化成晶状体核。
- [ ] 新纤维逐层加在核周围，此过程持续终身，随年龄增长而速度减慢。
- [ ] 晶状体泡诱导前方表面外胚层分化为角膜上皮，后方间充质分化为角膜其余各层。
- [ ] 视杯口边缘间充质形成虹膜基质，中央薄的部分称瞳孔膜（pupillary membrane）。
- [ ] 视杯两层上皮前缘形成虹膜上皮层，与基质共同发育成虹膜。
- [ ] 虹膜形成以前出现前房；虹膜与睫状体形成后出现后房；出生前瞳孔膜被吸收，前、后房经瞳孔相通。
- [ ] 第 $6\sim 7$ 周视杯周围间充质内层成血管膜（大部分为脉络膜，杯口边缘为虹膜基质和睫状体主体），外层成巩膜。
- [ ] 脉络膜与视神经周围软脑膜相连续，巩膜与硬脑膜相连续。
- [ ] 第 $7$ 周表面外胚层形成上、下眼睑皱褶；内表面成复层柱状结膜上皮，外面成表皮。
- [ ] 第 $10$ 周上、下眼睑边缘融合，至第 $7$ 或第 $8$ 个月重新分开。
- [ ] 上眼睑外侧部表面外胚层长入间充质，分化为泪腺腺泡和导管；出生后 $6$ 周分泌泪液，出生后 $3\sim 4$ 岁基本完成发育。
- [ ] 先天性白内障（congenital cataract）为晶状体透明度异常；多为遗传，也可因妊娠早期风疹、母体甲减、营养不良和维生素缺乏。
- [ ] 先天性无虹膜属常染色体显性，多为双侧；可能是视杯前缘生长分化障碍；瞳孔特别大。
- [ ] 先天性青光眼（congenital glaucoma）属常染色体隐性；有人认为巩膜静脉窦或小梁网发育障碍；房水排出受阻，眼球胀大称牛眼。
- [ ] 瞳孔膜残留因瞳孔膜未能全部退化；瞳孔处薄膜或蛛网状细丝遮盖晶状体前面，轻度通常不影响视力和瞳孔活动。
:::
