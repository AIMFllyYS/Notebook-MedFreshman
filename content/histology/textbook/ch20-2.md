# 二、胚胎学发展简史

胚胎学能从鸡卵观察写成发育生物学和生殖工程，靠的不是一次发现，而是观察、显微镜、胚层学说、显微操作和分子生物学一层层把机制往下推。本节只摊开教材写出的人名与年份：从 Hippocrates、Aristotle，到 Harvey、Leeuwenhoek 与 Graaf，再到 Remark、Spemann，以及 $20$ 世纪 $50$ 年代以后的分子胚胎学、发育生物学和生殖工程。下一节把方法写开。

被称为医学之父的古希腊学者 Hippocrates（公元前 $460$ 年—公元前 $377$ 年）首次观察并描述了鸡蛋在孵化成鸡的全过程中的形态变化。Aristotle（公元前 $384$ 年—公元前 $322$ 年）推测人胚胎来源于月经血与精液的混合。$1651$ 年，英国学者 Harvey（$1578$—$1658$ 年）提出“一切生命皆来自卵”的假设。显微镜问世后，荷兰学者 Leeuwenhoek（$1632$—$1723$ 年）与 Graaf（$1641$—$1673$ 年）分别发现精子与卵泡。$1855$ 年，德国学者 Remark（$1815$—$1865$ 年）提出胚胎发育的三胚层学说。自 $19$ 世纪末，德国学者 Spemann（$1869$—$1941$ 年）应用显微操作技术对两栖动物的胚进行了分离、切割、移植、重组等实验，奠定了实验胚胎学基础，在胚胎学发展史中具有重要意义。

:::definition{label="Hippocrates 的鸡胚观察"}
古希腊学者 Hippocrates（公元前 $460$ 年—公元前 $377$ 年）被称为医学之父。他首次观察并描述了鸡蛋在孵化成鸡的全过程中的形态变化。这是教材写出的胚胎学观察起点，还不是人胚实验。
:::

:::definition{label="Aristotle 的胚胎来源推测"}
Aristotle（公元前 $384$ 年—公元前 $322$ 年）推测人胚胎来源于月经血与精液的混合。这是推测，不是已经看见受精或卵。
:::

:::definition{label="一切生命皆来自卵"}
$1651$ 年，英国学者 Harvey（$1578$—$1658$ 年）提出“一切生命皆来自卵”的假设。教材把它写成假设，此时尚未用显微镜看清精子与卵泡。
:::

:::definition{label="精子与卵泡的发现"}
显微镜问世后，荷兰学者 Leeuwenhoek（$1632$—$1723$ 年）与 Graaf（$1641$—$1673$ 年）分别发现精子与卵泡。两人分工是：Leeuwenhoek 发现精子，Graaf 发现卵泡。
:::

:::definition{label="三胚层学说"}
$1855$ 年，德国学者 Remark（$1815$—$1865$ 年）提出胚胎发育的三胚层学说。它把胚胎形态发生收成三个胚层，是描述胚胎学的重要节点。
:::

:::definition{label="实验胚胎学基础"}
自 $19$ 世纪末，德国学者 Spemann（$1869$—$1941$ 年）应用显微操作技术对两栖动物的胚进行分离、切割、移植、重组等实验，奠定了实验胚胎学基础，在胚胎学发展史中具有重要意义。
:::

:::concept{term="先问这是肉眼推测、显微镜发现，还是已经在做显微手术"}
简史不要背成一张人名表。Hippocrates 看的是鸡卵孵化的形态变化；Aristotle 仍在推测月经血与精液混合；Harvey 提出“一切生命皆来自卵”还只是假设；显微镜问世后，Leeuwenhoek 和 Graaf 才分别把精子和卵泡推进视野；Remark 用三胚层把形态发生写成学说；Spemann 才对两栖类胚做分离、切割、移植、重组。把 $1651$ 年听成已经完成受精实验，精子、卵泡和实验胚胎学三笔账会并成一次发现。
:::

:::timeline{period="胚胎学关键节点（教材）"}
- **公元前460—前377** Hippocrates——首次观察并描述鸡蛋孵化成鸡全过程的形态变化（医学之父）
- **公元前384—前322** Aristotle——推测人胚胎来源于月经血与精液的混合
- **1651** Harvey——提出“一切生命皆来自卵”的假设（英国，1578—1658 年）
- **显微镜问世后** Leeuwenhoek 与 Graaf——分别发现精子与卵泡（荷兰）
- **1855** Remark——提出胚胎发育的三胚层学说（德国，1815—1865 年）
- **19世纪末起** Spemann——对两栖动物胚做分离、切割、移植、重组，奠定实验胚胎学基础
- **20世纪50年代** DNA 结构阐明与中心法则确立——诞生分子生物学，进而形成分子胚胎学
- **学科交叉后** 发育生物学——分子胚胎学与实验胚胎学、细胞生物学、分子遗传学互相渗透
- **应用转向** 生殖工程——体外受精、胚胎移植等用于解决不孕不育
:::

$20$ 世纪 $50$ 年代，随着 DNA 结构的阐明和中心法则的确立，诞生了分子生物学（molecular biology）。人们开始用分子生物学的观点和方法，研究胚胎发生过程中遗传基因表达的时空顺序和调控机制，形成分子胚胎学。分子胚胎学与实验胚胎学、细胞生物学、分子遗传学等学科互相渗透，发展建立了发育生物学（developmental biology）。发育生物学已成为现代生命科学的重要基础学科。

生殖工程是把某些实验胚胎学技术向应用方面发展而形成的，例如把体外受精、胚胎移植等技术用于解决不孕不育问题。

:::definition{label="分子生物学（简史落点）"}
$20$ 世纪 $50$ 年代，随着 DNA 结构的阐明和中心法则的确立，诞生了分子生物学（molecular biology）。教材在此未写发现者姓名，只把时间落在 $50$ 年代。
:::

:::definition{label="分子胚胎学（简史）"}
人们用分子生物学的观点和方法，研究胚胎发生过程中遗传基因表达的时空顺序和调控机制，形成分子胚胎学。它与第一节的定义一致，历史落点在 DNA 结构和中心法则之后。
:::

:::definition{label="发育生物学"}
发育生物学（developmental biology）由分子胚胎学与实验胚胎学、细胞生物学、分子遗传学等学科互相渗透发展建立，已成为现代生命科学的重要基础学科。
:::

:::definition{label="生殖工程（简史）"}
生殖工程是把某些实验胚胎学技术向应用方面发展而形成的，例如把体外受精、胚胎移植等技术用于解决不孕不育问题。技术清单的完整写法见第一节，临床意义见第四节。
:::

:::compare{title="观察、实验、分子与应用四段"}
| 阶段 | 教材节点 | 看见或做到的事 | 还不是 |
|------|----------|----------------|--------|
| 肉眼观察与推测 | Hippocrates；Aristotle | 鸡卵孵化形态；月经血与精液混合的推测 | 人胚实验；受精过程 |
| 假设与显微发现 | Harvey（$1651$）；Leeuwenhoek、Graaf | “一切生命皆来自卵”的假设；精子与卵泡 | 三胚层学说；基因调控 |
| 胚层与实验 | Remark（$1855$）；Spemann（$19$ 世纪末起） | 三胚层学说；两栖类胚的分离、切割、移植、重组 | 分子生物学 |
| 分子与应用 | $20$ 世纪 $50$ 年代以后 | 分子胚胎学 → 发育生物学；生殖工程用于不孕不育 | 把全部历史写成“现代分子胚胎学”一笔 |
:::

:::pitfall{label="不要把 Aristotle 的混合说当成受精，也不要把 Harvey 的假设当成已经看见卵"}
Aristotle 写的是月经血与精液混合的推测。Harvey 在 $1651$ 年提出“一切生命皆来自卵”，教材明确是假设。精子与卵泡要等到显微镜问世后，才由 Leeuwenhoek 与 Graaf 分别发现。把这三笔并成“古人已经完成受精研究”，后面的三胚层学说和实验胚胎学都会失去台阶。
:::

:::note{label="人名与年份只记教材写出的这些"}
本节出现的人名是 Hippocrates、Aristotle、Harvey、Leeuwenhoek、Graaf、Remark、Spemann；关键年份是公元前 $460$—前 $377$、公元前 $384$—前 $322$、$1651$、$1855$、$19$ 世纪末、$20$ 世纪 $50$ 年代。DNA 结构与中心法则只给年代，不另补姓名。不要把未写入教材的学者或 IVF、克隆羊年份塞进这条简史。
:::

:::insight{label="Spemann 把刀伸进胚里，实验胚胎学才从观察变成可操作"}
描述可以停留在鸡卵和切片；Spemann 对两栖动物胚做分离、切割、移植、重组，才把“发育如何被决定”写成可干预的实验。后面的分子胚胎学追基因表达的时空顺序，生殖工程则把体外受精、胚胎移植接到不孕不育。观察、实验、分子、应用是一条时间轴上的四本账，不是互相取代。
:::

:::keypoint{label="简史按观察→显微镜→胚层→显微手术→分子→应用来记"}
- Hippocrates 观察鸡卵孵化全过程；Aristotle 推测月经血与精液混合。
- Harvey（$1651$）提出“一切生命皆来自卵”的假设；显微镜问世后 Leeuwenhoek 与 Graaf 分别发现精子与卵泡。
- Remark（$1855$）提出三胚层学说；Spemann 自 $19$ 世纪末用显微操作奠定实验胚胎学基础。
- $20$ 世纪 $50$ 年代 DNA 结构与中心法则 → 分子生物学 → 分子胚胎学；再与实验胚胎学、细胞生物学、分子遗传学交叉为发育生物学。
- 生殖工程由实验胚胎学技术转向应用，如体外受精、胚胎移植解决不孕不育。
:::
