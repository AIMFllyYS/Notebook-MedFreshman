# 三、皮肤的附属器

皮肤有毛、皮脂腺、汗腺和指（趾）甲等附属器，均为表皮衍生。人体除手掌、足底等处外均有毛；皮脂腺除掌、跖和足侧部外均有；外泌汗腺遍布全身而掌跖尤其多；指（趾）甲则是指端表皮的特化角质板。本节按毛、皮脂腺、汗腺、指（趾）甲四本账摊开。

:::definition{label="皮肤附属器"}
皮肤附属器包括毛、皮脂腺、汗腺和指（趾）甲，均为表皮衍生。
:::

:::concept{term="先问这套结构是不是从表皮长下去的"}
附属器的位置可以深到真皮甚至皮下，来源却是表皮。毛囊上皮根鞘与表皮连续，皮脂腺导管开口于毛囊或皮面，外泌汗腺导管螺旋穿过表皮成汗孔，甲体是连接牢固的角质细胞。把它们听成“真皮自己长出的器官”，毛母质、甲母质和汗腺导管提供再生干细胞那几本账都会写错层。
:::

## 1. 毛

人体皮肤除手掌、足底等处外，均有毛分布（图 11-10，图 11-11）。尽管不同部位毛的粗细、长短和颜色有差别，但基本结构相同。毛分为毛干、毛根和毛球 3 部分。露在皮肤表面的为毛干，埋在皮肤内的为毛根；毛干和毛根由排列规则的角化上皮细胞组成，细胞内充满角蛋白并含有数量不等的黑素颗粒。包在毛根外面的毛囊分为两层，内层为上皮根鞘，与表皮相连续，包裹毛根，其结构也与表皮相似；外层为结缔组织鞘，与真皮相连续，由薄层致密结缔组织构成。毛根和毛囊上皮根鞘的下端合为一体，膨大为毛球。毛球的上皮细胞称毛母质细胞（hair matrix cell），为干细胞，它们不断增殖，部分子细胞分化形成毛根和上皮根鞘的细胞，并向上迁移。毛球基部的黑素细胞可将黑素颗粒转送到上皮细胞中。毛球底面有结缔组织突入其中形成毛乳头，内含丰富的毛细血管和神经末梢。毛球是毛和毛囊的生长点，毛乳头对毛的生长起诱导和营养作用。毛和毛囊斜长在皮肤内，在毛根与皮肤表面呈钝角的一侧有一束平滑肌，连接毛囊和真皮，称立毛肌。立毛肌受交感神经支配，遇冷或感情冲动时收缩，使毛发竖立，产生“鸡皮疙瘩”现象。

:::definition{label="毛"}
人体皮肤除手掌、足底等处外均有毛。尽管部位不同而粗细、长短和颜色有差别，基本结构相同。毛分为毛干、毛根和毛球 3 部分。
:::

:::definition{label="毛干与毛根"}
露在皮肤表面的为毛干，埋在皮肤内的为毛根。二者由排列规则的角化上皮细胞组成，细胞内充满角蛋白并含数量不等的黑素颗粒。
:::

:::definition{label="毛囊"}
毛囊包在毛根外面，分两层：内层为上皮根鞘，与表皮相连续，包裹毛根，结构与表皮相似；外层为结缔组织鞘，与真皮相连续，由薄层致密结缔组织构成。
:::

:::definition{label="毛球"}
毛根和毛囊上皮根鞘的下端合为一体，膨大为毛球。毛球是毛和毛囊的生长点。
:::

:::definition{label="毛母质细胞"}
毛球的上皮细胞称毛母质细胞（hair matrix cell），为干细胞。不断增殖，部分子细胞分化形成毛根和上皮根鞘的细胞，并向上迁移。毛球基部的黑素细胞可将黑素颗粒转送到上皮细胞中。
:::

:::definition{label="毛乳头"}
毛球底面有结缔组织突入其中形成毛乳头，内含丰富的毛细血管和神经末梢。毛乳头对毛的生长起诱导和营养作用。
:::

:::definition{label="立毛肌"}
毛和毛囊斜长在皮肤内。在毛根与皮肤表面呈钝角的一侧有一束平滑肌，连接毛囊和真皮，称立毛肌。受交感神经支配，遇冷或感情冲动时收缩，使毛发竖立，产生“鸡皮疙瘩”。
:::

:::compare{title="毛的三段与毛囊两层"}
| 结构 | 位置 | 组成 | 职分 |
|------|------|------|------|
| 毛干 | 露在皮肤表面 | 规则排列的角化上皮，充满角蛋白，含黑素颗粒 | 可见的毛发 |
| 毛根 | 埋在皮肤内 | 同毛干 | 被毛囊包裹的部分 |
| 毛球 | 毛根与上皮根鞘下端膨大 | 毛母质细胞（干细胞）+ 基部黑素细胞 | 毛和毛囊的生长点 |
| 上皮根鞘 | 毛囊内层 | 与表皮连续，结构相似 | 包裹毛根 |
| 结缔组织鞘 | 毛囊外层 | 与真皮连续的薄层致密结缔组织 | 外周支架 |
| 毛乳头 | 结缔组织突入毛球底面 | 丰富毛细血管和神经末梢 | 诱导并营养毛的生长 |
:::

:::pitfall{label="毛乳头是结缔组织从底面突进去的，不要和毛球、毛母质写成同一个结构"}
毛球是上皮性膨大，生长点在毛母质细胞；毛乳头是真皮来源的结缔组织芯，只负责诱导和营养。切片上毛球底部那团浅染、有血管的组织是毛乳头（图 11-11 箭头），不是“毛球的细胞核区”。没有毛乳头，毛母质增殖会停。
:::

:::pitfall{label="立毛肌在钝角一侧，不要画到锐角侧或当成横纹肌"}
毛斜插在皮肤里，立毛肌连在毛根与皮面呈钝角的那一侧，是平滑肌、受交感支配。收缩把毛竖起来，同时挤压皮脂腺。画到锐角侧或写成骨骼肌，鸡皮疙瘩和皮脂排出那两本账都会方向反掉。
:::

人类不同种族的毛发颜色有很大差异。黑色和棕黑色毛的黑素颗粒富含黑色素；金黄色和红色毛的黑素颗粒含褐黑色素，这是一种黄色或红色的色素；灰色和白色毛的黑素颗粒及其内含色素均少。

:::note{label="毛发颜色取决于颗粒里的色素，而不是毛母质细胞换了一种"}
| 毛色 | 黑素颗粒 |
|------|----------|
| 黑色、棕黑色 | 富含黑色素 |
| 金黄色、红色 | 含褐黑色素（黄色或红色色素） |
| 灰色、白色 | 黑素颗粒及其内含色素均少 |
:::

毛有一定的生长周期，头发的生长周期通常为 $3\sim 5$ 年，其他部位毛的生长周期只有数月。生长中的毛，其毛球膨大，毛乳头血流丰富，毛母质细胞增殖旺盛。转入静止期的毛球和毛乳头变小萎缩，毛母质细胞停止增殖，毛根与毛球、毛囊连接不牢。在旧毛脱落之前，于毛囊基部形成新的毛球和毛乳头，形成新毛，将旧毛推出。新生毛囊是由毛囊干细胞增殖、分化而来。毛囊干细胞存在于毛囊隆起部，即皮脂腺开口处和立毛肌毛囊附着处之间部位。

:::definition{label="毛的生长周期"}
头发的生长周期通常为 $3\sim 5$ 年，其他部位毛只有数月。生长期：毛球膨大，毛乳头血流丰富，毛母质细胞增殖旺盛。静止期：毛球和毛乳头变小萎缩，毛母质停止增殖，毛根与毛球、毛囊连接不牢。旧毛脱落前，毛囊基部形成新的毛球和毛乳头，新毛将旧毛推出。
:::

:::definition{label="毛囊干细胞"}
新生毛囊由毛囊干细胞增殖、分化而来。毛囊干细胞存在于毛囊隆起部，即皮脂腺开口处和立毛肌毛囊附着处之间。
:::

:::insight{label="毛囊隆起部的干细胞，既管换毛，也是后文表皮再生的后备"}
生长期靠毛母质；换毛、新生毛囊靠隆起部干细胞。第四节皮肤再生还会写：残存毛囊上皮可提供表皮再生的干细胞，在肉芽表面形成上皮小岛。隆起部的位置要记死——皮脂腺开口与立毛肌附着点之间——不要写成毛乳头里。
:::

:::pitfall{label="毛母质细胞和毛囊干细胞不是同一个干细胞池"}
毛母质细胞在毛球，管正在生长的毛根和上皮根鞘；毛囊干细胞在隆起部，管新生毛囊的形成，也是表皮损伤时的后备。把二者并成“毛球里的干细胞”，静止期毛球萎缩后就无法解释新毛从哪里来。
:::

## 2. 皮脂腺

皮脂腺（sebaceous gland）除手掌、足底和足侧部外，其余部位皮肤均有皮脂腺。在有毛的皮肤，它们位于毛囊与立毛肌之间，在无毛的皮肤，则位于真皮浅层。皮脂腺为泡状腺。分泌部由一个或几个腺泡构成，其周边是一层较小的干细胞，称基细胞，它们不断增殖，部分子细胞内形成脂滴，并向腺泡中心移动。腺泡中心的细胞较大，呈多边形，核固缩，细胞质内充满脂滴。在近导管处，腺细胞解体，并排出分泌物即皮脂，此种分泌方式为全浆分泌（holocrine）。皮脂经粗而短的导管排入毛囊上部或直接排到皮肤表面（图 11-12）。皮脂能润泽皮肤和毛发。性激素可促进皮脂生成，故在青春期皮脂腺分泌活跃，过度分泌容易导致排出不畅，引起炎症，形成痤疮。

:::definition{label="皮脂腺"}
皮脂腺（sebaceous gland）除手掌、足底和足侧部外均有。有毛皮肤位于毛囊与立毛肌之间，无毛皮肤位于真皮浅层。为泡状腺；皮脂经粗而短的导管排入毛囊上部或直接排到皮肤表面，能润泽皮肤和毛发。
:::

:::definition{label="皮脂腺的全浆分泌"}
分泌部由一个或几个腺泡构成。周边一层较小的干细胞称基细胞，不断增殖，部分子细胞形成脂滴并向中心移动。中心细胞较大、多边形，核固缩，胞质充满脂滴。近导管处腺细胞解体，排出皮脂，此种方式为全浆分泌（holocrine）。
:::

:::note{label="性激素、皮脂与痤疮"}
性激素促进皮脂生成，青春期分泌活跃；过度分泌导致排出不畅、引起炎症，形成痤疮。立毛肌收缩也可协助把皮脂挤向导管。
:::

:::pitfall{label="全浆分泌是细胞整颗解体，不要写成胞吐或顶浆分泌"}
皮脂腺中心细胞核固缩、脂滴充满，到导管口连人带脂一起排出，腺体靠周边基细胞持续补充。外泌汗腺是胞吐，顶泌汗腺是顶部胞质连颗粒脱落。把三种分泌方式写成“腺体都会出油”，痤疮和腋臭会失去组织学机制。
:::

## 3. 汗腺

汗腺（sweat gland）又称外泌汗腺（eccrine sweat gland），遍布于全身皮肤内，手掌和足底尤其多。汗腺为单曲管状腺，分泌部盘曲成团，位于真皮深层和皮下组织中。腺上皮由 $1\sim 2$ 层淡染的锥形和立方形细胞构成，外方有肌上皮细胞，其收缩有助排出分泌物。导管由两层较小的立方形细胞围成，细胞质呈弱嗜碱性（图 11-13）。导管直行穿过真皮，然后与表皮相连续，管腔在表皮内呈螺旋状走行，开口于皮肤表面的汗孔（见图 11-1）。腺细胞以胞吐的方式进行分泌，产生的汗液中除大量水分外，还有钠、钾、氯、乳酸盐和尿素等。汗腺分泌是机体散热的主要方式，有调节体温、湿润皮肤、排泄机体代谢产物和离子等作用。

:::definition{label="外泌汗腺"}
汗腺（sweat gland）又称外泌汗腺（eccrine sweat gland），遍布全身皮肤，手掌和足底尤其多。为单曲管状腺；腺细胞以胞吐方式分泌。汗液含大量水分及钠、钾、氯、乳酸盐和尿素等。分泌是机体散热的主要方式，并有湿润皮肤、排泄代谢产物和离子等作用。
:::

:::definition{label="外泌汗腺分泌部"}
分泌部盘曲成团，位于真皮深层和皮下组织中。腺上皮由 $1\sim 2$ 层淡染的锥形和立方形细胞构成，外方有肌上皮细胞，收缩有助排出分泌物。
:::

:::definition{label="外泌汗腺导管与汗孔"}
导管由两层较小的立方形细胞围成，胞质弱嗜碱性。导管直行穿过真皮，与表皮相连续后，管腔在表皮内呈螺旋状走行，开口于皮肤表面的汗孔。
:::

:::definition{label="肌上皮细胞"}
肌上皮细胞位于外泌汗腺分泌部外方，收缩有助于把分泌物挤入导管。
:::

::figure{src="/images/histology/textbook/p0134_02.png" caption="图11-13 汗腺光镜图。1. 分泌部；2. 导管。" alt="外泌汗腺：淡染锥形/立方分泌部与弱嗜碱性两层立方细胞导管"}

此外，腋窝、乳晕、会阴等处还有大汗腺，以顶浆分泌的方式分泌汗液，故称顶泌汗腺（apocrine sweat gland）。其分泌部较大，盘曲成团，腺细胞细胞质呈嗜酸性，分泌时顶部细胞质连同分泌颗粒一起脱落进入腺腔；导管开口于毛囊上端（见图 11-10）。顶泌汗腺的分泌物为黏稠乳状液，含蛋白质和脂类等。不同个体的分泌物所含蛋白质和脂类的成分不同，导致形成不同的体味，如分泌过盛并且分泌物被细菌分解，则产生腋臭。顶泌汗腺分泌受性激素影响，青春期分泌较旺盛。

:::definition{label="顶泌汗腺"}
顶泌汗腺（apocrine sweat gland）即大汗腺，位于腋窝、乳晕、会阴等处，以顶浆分泌方式分泌：顶部胞质连同分泌颗粒脱落入腺腔。分泌部较大、盘曲成团，腺细胞胞质嗜酸性；导管开口于毛囊上端。分泌物为含蛋白质和脂类的黏稠乳状液。
:::

:::note{label="体味与腋臭"}
不同个体分泌物中蛋白质和脂类成分不同，形成不同体味。分泌过盛且被细菌分解则产生腋臭。顶泌汗腺受性激素影响，青春期分泌较旺盛。
:::

:::compare{title="外泌汗腺与顶泌汗腺"}
| 项目 | 外泌汗腺（小汗腺） | 顶泌汗腺（大汗腺） |
|------|--------------------|--------------------|
| 英文 | eccrine sweat gland | apocrine sweat gland |
| 分布 | 全身，掌跖尤其多 | 腋窝、乳晕、会阴等 |
| 腺型 | 单曲管状腺 | 分泌部更大，盘曲成团 |
| 分泌部位置 | 真皮深层和皮下组织 | 较大，同样盘曲 |
| 腺上皮 | $1\sim 2$ 层淡染锥形、立方细胞；外有肌上皮 | 胞质嗜酸性 |
| 分泌方式 | 胞吐 | 顶浆分泌（顶部胞质连颗粒脱落） |
| 导管开口 | 表皮内螺旋走行，开口于皮面汗孔 | 开口于毛囊上端 |
| 分泌物 | 稀薄汗液：水、钠、钾、氯、乳酸盐、尿素 | 黏稠乳状液：蛋白质、脂类 |
| 功能 / 临床 | 散热、湿润、排泄 | 体味；过盛被细菌分解 → 腋臭；受性激素影响，青春期旺盛 |
:::

| 腺体 | 分泌方式 | 细胞结局 | 开口 |
|------|----------|----------|------|

| 顶泌汗腺 | 顶浆分泌 | 顶部胞质连颗粒脱落，胞体其余部分保留 | 毛囊上端 |
:::

:::pitfall{label="外泌汗腺开在汗孔，顶泌汗腺开在毛囊上端，不要把两种汗腺的导管画到同一个口"}
掌跖无毛却汗腺极多，开口只能是皮面汗孔，这是外泌汗腺。腋窝那种大汗腺跟毛走，导管进毛囊上端，分泌物再沿毛干到皮面。把顶泌汗腺也画成独立汗孔，或把外泌汗腺画进毛囊，腋臭和掌跖出汗会共用一张错误的开口图。
:::

:::insight{label="导管在表皮里走螺旋，不要把图 11-1 的“5”当成血管"}
手掌厚皮里那条从真皮穿到角质层的嗜酸性螺旋管，是外泌汗腺导管，开口于沟底汗孔。管壁是两层立方细胞延续成的上皮管道，不是真皮乳头的毛细血管迂曲。辨认厚皮切片，角质层、乳头、螺旋导管和皮下汗腺盘曲要一次认全。
:::

## 4. 指（趾）甲

指（趾）甲由甲体及其周围和下方的几部分组织组成。甲体由多层连接牢固的角质细胞构成；甲体的近端埋在皮肤内，称甲根；甲体下面的复层扁平上皮和真皮为甲床；甲体周缘的皮肤为甲襞；甲体与甲襞之间的沟为甲沟。甲根附着处的甲床上皮为甲母质，该部位细胞增殖活跃，是甲体的生长区（图 11-14）。

:::definition{label="指（趾）甲"}
指（趾）甲由甲体及其周围和下方的几部分组织组成：甲体、甲根、甲床、甲襞、甲沟，生长区为甲母质。
:::

:::definition{label="甲体与甲根"}
甲体由多层连接牢固的角质细胞构成。甲体近端埋在皮肤内，称甲根。
:::

:::definition{label="甲床、甲襞与甲沟"}
甲体下面的复层扁平上皮和真皮为甲床。甲体周缘的皮肤为甲襞。甲体与甲襞之间的沟为甲沟。
:::

:::definition{label="甲母质"}
甲根附着处的甲床上皮为甲母质，该部位细胞增殖活跃，是甲体的生长区。
:::

:::compare{title="毛母质与甲母质"}
| 项目 | 毛母质细胞 | 甲母质 |
|------|------------|--------|
| 位置 | 毛球的上皮 | 甲根附着处的甲床上皮 |
| 细胞性质 | 干细胞，不断增殖 | 增殖活跃 |
| 产物 | 毛根和上皮根鞘细胞，向上迁移；接受黑素颗粒 | 甲体（多层连接牢固的角质细胞） |
| 诱导/营养结构 | 毛乳头（结缔组织突入） | 甲床的真皮 |
| 临床含义 | 破坏毛母质或毛乳头 → 毛停止生长 | 破坏甲母质 → 甲体生长障碍 |
:::

:::pitfall{label="甲体从甲母质长出来，不要写成“甲床分泌指甲”"}
甲床是甲体下面的上皮加真皮，主要提供支持和附着；真正的生长区是甲根附着处的甲母质。拔甲后若甲母质保留，甲体还可以再长；把生长点记在露出的甲床上，甲外伤和甲癣的定位会错。
:::

:::keypoint{label="附属器按毛、皮脂腺、两种汗腺和甲来立账"}
- 毛 = 毛干 + 毛根 + 毛球；毛囊 = 上皮根鞘 + 结缔组织鞘；毛母质是生长点，毛乳头诱导营养；立毛肌在钝角侧，交感支配。
- 毛囊干细胞在隆起部（皮脂腺开口与立毛肌附着点之间）；头发周期 $3\sim 5$ 年。
- 皮脂腺：泡状腺，全浆分泌；开口于毛囊上部或皮面；青春期易痤疮。
- 外泌汗腺：单曲管状，胞吐，导管表皮内螺旋开口于汗孔，主散热。
- 顶泌汗腺：腋窝等，顶浆分泌，开口于毛囊上端；细菌分解可致腋臭。
- 甲体来自甲母质；甲床、甲襞、甲沟是周围结构。
:::

:::memory{label="本节必背要点"}
- [ ] 皮肤附属器包括毛、皮脂腺、汗腺和指（趾）甲，均为表皮衍生。
- [ ] 除手掌、足底等处外，人体皮肤均有毛；不同部位粗细、长短和颜色有差别，基本结构相同。
- [ ] 毛分为毛干、毛根和毛球 3 部分；露在表面为毛干，埋在皮肤内为毛根。
- [ ] 毛干和毛根由排列规则的角化上皮细胞组成，细胞内充满角蛋白并含数量不等的黑素颗粒。
- [ ] 毛囊分两层：上皮根鞘与表皮连续、结构相似；结缔组织鞘与真皮连续，为薄层致密结缔组织。
- [ ] 毛根与上皮根鞘下端合一体膨大为毛球；毛球上皮细胞为毛母质细胞（干细胞）。
- [ ] 毛母质细胞不断增殖，部分子细胞分化为毛根和上皮根鞘细胞并向上迁移；基部黑素细胞将黑素颗粒转入上皮细胞。
- [ ] 毛乳头由结缔组织突入毛球底面形成，含丰富毛细血管和神经末梢，对毛的生长起诱导和营养作用。
- [ ] 毛球是毛和毛囊的生长点。
- [ ] 立毛肌连接毛囊和真皮，位于毛根与皮肤表面呈钝角的一侧；交感支配，遇冷或感情冲动时收缩，产生鸡皮疙瘩。
- [ ] 黑色、棕黑色毛的黑素颗粒富含黑色素；金黄和红色毛含褐黑色素；灰色和白色毛的颗粒及色素均少。
- [ ] 头发生长周期通常 $3\sim 5$ 年，其他部位毛只有数月。
- [ ] 生长期毛球膨大、毛乳头血流丰富、毛母质增殖旺盛；静止期毛球和毛乳头萎缩，毛根连接不牢。
- [ ] 旧毛脱落前，毛囊基部形成新的毛球和毛乳头，新毛将旧毛推出。
- [ ] 新生毛囊由毛囊干细胞增殖分化而来；干细胞位于毛囊隆起部，即皮脂腺开口处与立毛肌附着处之间。
- [ ] 皮脂腺除手掌、足底和足侧部外均有；有毛皮肤位于毛囊与立毛肌之间，无毛皮肤位于真皮浅层。
- [ ] 皮脂腺为泡状腺；周边基细胞增殖，中心细胞大、多边形、核固缩、充满脂滴；近导管处细胞解体排出皮脂，为全浆分泌（holocrine）。
- [ ] 皮脂经粗短导管排入毛囊上部或直接到皮肤表面，润泽皮肤和毛发。
- [ ] 性激素促进皮脂生成，青春期分泌活跃；过度分泌、排出不畅可引起炎症，形成痤疮。
- [ ] 外泌汗腺（eccrine sweat gland）遍布全身，掌跖尤其多；为单曲管状腺，分泌部盘曲成团，位于真皮深层和皮下组织。
- [ ] 分泌部腺上皮为 $1\sim 2$ 层淡染锥形和立方细胞，外方有肌上皮细胞。
- [ ] 导管由两层较小立方细胞围成，胞质弱嗜碱；直行穿过真皮，在表皮内螺旋走行，开口于汗孔。
- [ ] 外泌汗腺以胞吐分泌；汗液含水、钠、钾、氯、乳酸盐和尿素等；是散热的主要方式，并湿润皮肤、排泄代谢产物和离子。
- [ ] 顶泌汗腺（apocrine sweat gland）位于腋窝、乳晕、会阴等处，顶浆分泌，导管开口于毛囊上端。
- [ ] 顶泌汗腺分泌部较大，腺细胞胞质嗜酸；分泌物为含蛋白质和脂类的黏稠乳状液；过盛被细菌分解产生腋臭；受性激素影响，青春期旺盛。
- [ ] 甲体由多层连接牢固的角质细胞构成；近端埋在皮肤内为甲根。
- [ ] 甲床为甲体下面的复层扁平上皮和真皮；甲襞为甲体周缘的皮肤；甲沟为甲体与甲襞之间的沟。
- [ ] 甲母质是甲根附着处的甲床上皮，细胞增殖活跃，是甲体的生长区。
:::
