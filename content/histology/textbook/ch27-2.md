# 二、耳的发生

耳分内耳、中耳和外耳 $3$ 部分。内耳从头部表面外胚层的听板凹成听泡，中耳从内胚层来的第 $1$ 咽囊扩出，外耳从第 $1$ 鳃沟和外耳道口周围 $6$ 个耳丘演变。本节按听板 → 听窝 → 听泡 → 膜迷路和骨迷路、管鼓隐窝与听小骨、外耳道栓与耳郭摊开，再写三种主要畸形，并收回本章眼与耳的本章小结。角膜缘干细胞的插入阅读放在节末。

耳分内耳、中耳和外耳 $3$ 部分，分别由头部表面外胚层形成的耳板、内胚层来源的第 $1$ 咽囊、外胚层来源的第 $1$ 鳃沟及围绕鳃沟的 $6$ 个结节演变而来。

:::definition{label="耳的三部分原基"}
耳分内耳、中耳和外耳 $3$ 部分。内耳来自头部表面外胚层形成的耳板（听板）；中耳来自内胚层的第 $1$ 咽囊；外耳来自外胚层的第 $1$ 鳃沟及围绕鳃沟的 $6$ 个结节（耳丘）。三份原基不要对调。
:::

:::definition{label="耳板"}
耳板即听板，是头部表面外胚层在菱脑诱导下增厚形成的板。它是内耳膜迷路的起点，不是中耳的咽囊。
:::

:::concept{term="先问这是听板、第1咽囊还是第1鳃沟，再问听泡已经分成前庭囊和耳蜗囊没有"}
看见耳的发生，先把三份原基切开：菱脑两侧表面外胚层增厚是听板，凹进去闭合才是听泡，走膜迷路；第 $1$ 咽囊向背外侧扩伸，走咽鼓管和鼓室；第 $1$ 鳃沟向内深陷，走外耳道，沟周 $6$ 个耳丘走耳郭。再问听泡内部：背侧前庭囊对膜半规管和椭圆囊，腹侧耳蜗囊对球囊和膜蜗管，背端内侧那条小管才是内淋巴管。把咽囊听成听泡，或把半规管写成耳蜗囊变的，内、中、外三本账会对错户头。
:::

:::compare{title="内耳、中耳与外耳的原基"}
| 项目 | 内耳 | 中耳 | 外耳 |
|------|------|------|------|
| 原基 | 头部表面外胚层的听板（耳板） | 内胚层来源的第 $1$ 咽囊 | 外胚层来源的第 $1$ 鳃沟 + 围绕鳃沟的 $6$ 个结节 |
| 关键中间型 | 听板 → 听窝 → 听泡 → 前庭囊 / 耳蜗囊 / 内淋巴管 | 管鼓隐窝（远侧）+ 咽鼓管（近侧）；听小骨原基在隐窝上方间充质 | 外耳道外侧段、外耳道栓 → 内侧段；耳丘 → 耳郭 |
| 上皮胚层 | 表面外胚层 | 内胚层（鼓膜内上皮）；鼓膜外上皮为鳃沟外胚层 | 外胚层 |
| 间充质还做 | 软骨性囊 → 骨迷路 | 听小骨；鼓膜内结缔组织 | 耳郭其余结构 |
:::

## （一）内耳的发生

第 $4$ 周初，菱脑两侧的表面外胚层在菱脑的诱导下增厚，形成听板（otic placode）（见图 22-1）；继之向下方间充质内陷，形成听窝（otic pit）；最后听窝闭合，并与表面外胚层分离，形成囊状的听泡（otic vesicle）（图 27-6）。听泡初为梨形，以后向背、腹方向延伸增大，形成背侧的前庭囊和腹侧的耳蜗囊，并在背端内侧长出一小囊管，为内淋巴管。前庭囊演化为 $3$ 个膜半规管和椭圆囊的上皮；耳蜗囊演化为球囊和膜蜗管的上皮。这样听泡便演变为内耳膜迷路（图 27-7）。第 $3$ 个月时，膜迷路周围的间充质分化成一个软骨性囊，包绕膜迷路。约在第 $5$ 个月时，软骨性囊骨化，成为骨迷路。于是膜迷路被套在骨迷路内，两者间隔狭窄的外淋巴间隙。

:::definition{label="听板"}
第 $4$ 周初，菱脑两侧的表面外胚层在菱脑的诱导下增厚，形成听板（otic placode）。图 22-1 侧面观已标出听板。没有菱脑这份诱导，表面外胚层不会在这里加厚。
:::

:::definition{label="听窝"}
听板继之向下方间充质内陷，形成听窝（otic pit）。此时仍与表面外胚层相连，还没有闭合离体。
:::

:::definition{label="听泡"}
听窝闭合，并与表面外胚层分离，形成囊状的听泡（otic vesicle）。听泡是内耳膜迷路的原基，已经离开体表。
:::

:::definition{label="前庭囊"}
听泡初为梨形，以后向背、腹方向延伸增大，背侧那一份称前庭囊。前庭囊演化为 $3$ 个膜半规管和椭圆囊的上皮。
:::

:::definition{label="耳蜗囊"}
听泡腹侧那一份称耳蜗囊。耳蜗囊演化为球囊和膜蜗管的上皮。
:::

:::definition{label="内淋巴管（发生）"}
听泡在背端内侧长出一小囊管，为内淋巴管。它不是前庭囊本身，也不是耳蜗囊。
:::

:::definition{label="膜迷路（发生）"}
前庭囊演化为 $3$ 个膜半规管和椭圆囊的上皮，耳蜗囊演化为球囊和膜蜗管的上皮，听泡便演变为内耳膜迷路。膜迷路的上皮全部来自听泡。
:::

:::definition{label="软骨性囊与骨迷路"}
第 $3$ 个月时，膜迷路周围的间充质分化成一个软骨性囊，包绕膜迷路。约在第 $5$ 个月时，软骨性囊骨化，成为骨迷路。骨迷路来自周围间充质，不是听泡上皮骨化。
:::

:::definition{label="外淋巴间隙（发生）"}
膜迷路被套在骨迷路内，两者间隔狭窄的外淋巴间隙。间隙在膜与骨之间，不是听泡腔内的内淋巴。
:::

::figure{src="/images/histology/textbook/p0298_03.png" caption="图27-7 听泡的发育模式图（第4～8周）。第4周听泡分出前庭部和耳蜗部；第5周背侧长出内淋巴管，开始出现半规管；第5.5周半规管更清楚，腹侧球囊与耳蜗管可分；第7周内淋巴管和囊、半规管、耳蜗管进一步卷曲；第8周可见半规管壶腹、椭圆囊、球囊、连合管和卷曲的耳蜗管。" alt="五枚蓝色囊从梨形听泡演变：先后分出前庭部与耳蜗部，长出内淋巴管和半规管，耳蜗管逐渐卷曲成蜗形"}

:::timeline{period="从听板到骨迷路"}
- **第4周初** 菱脑诱导两侧表面外胚层增厚为听板
- **随后** 听板内陷为听窝；听窝闭合并与表面外胚层分离，成囊状听泡
- **听泡变形** 梨形，向背、腹延伸：背侧前庭囊，腹侧耳蜗囊；背端内侧长出内淋巴管
- **前庭囊** 演化为 3 个膜半规管和椭圆囊的上皮
- **耳蜗囊** 演化为球囊和膜蜗管的上皮 → 听泡成为膜迷路
- **第3个月** 周围间充质成软骨性囊，包绕膜迷路
- **约第5个月** 软骨性囊骨化成骨迷路；膜迷路套在骨迷路内，间隔狭窄外淋巴间隙
:::

:::compare{title="前庭囊与耳蜗囊"}
| 项目 | 前庭囊 | 耳蜗囊 |
|------|--------|--------|
| 在听泡上的位置 | 背侧 | 腹侧 |
| 演化为 | $3$ 个膜半规管和椭圆囊的上皮 | 球囊和膜蜗管的上皮 |
| 功能归属（成体） | 平衡觉相关的膜半规管、椭圆囊 | 球囊（兼平衡）与听觉的膜蜗管 |
| 不要写成 | 耳蜗 | 半规管 |
:::

:::compare{title="膜迷路、软骨性囊、骨迷路与外淋巴间隙"}
| 项目 | 来源 | 时间 | 位置关系 |
|------|------|------|----------|
| 膜迷路 | 听泡上皮（前庭囊 + 耳蜗囊 + 内淋巴管） | 听泡演变完成 | 最内，含内淋巴 |
| 软骨性囊 | 膜迷路周围的间充质 | 第 $3$ 个月 | 包绕膜迷路 |
| 骨迷路 | 软骨性囊骨化 | 约第 $5$ 个月 | 套在膜迷路外面 |
| 外淋巴间隙 | 膜迷路与骨迷路之间的狭窄间隙 | 骨迷路形成后 | 隔在膜与骨之间，含外淋巴 |
:::

:::cause-effect{title="菱脑诱导出板，板凹成泡，泡再分成背腹两囊"}
- 因：第 $4$ 周初菱脑诱导两侧表面外胚层
- 果：增厚为听板
- 因：听板向下方间充质内陷并闭合、与表面外胚层分离
- 果：形成听泡
- 因：听泡向背、腹延伸，背端内侧长出小囊管
- 果：背侧前庭囊、腹侧耳蜗囊、内淋巴管；听泡成为膜迷路
- 因：周围间充质第 $3$ 个月成软骨性囊，约第 $5$ 个月骨化
- 果：骨迷路套住膜迷路，中间留下外淋巴间隙
:::

:::pitfall{label="听板、听窝、听泡是三步，听泡还要再分成前庭囊和耳蜗囊"}
增厚是听板，内陷是听窝，闭合离体才是听泡。听泡最初只是梨形囊，要向背腹延伸才分出前庭囊和耳蜗囊。写成“菱脑旁边直接长出半规管和耳蜗”，内淋巴管、软骨性囊和第 $5$ 个月骨化都会没有时间点。半规管对前庭囊，膜蜗管对耳蜗囊，不要对调。
:::

:::insight{label="膜迷路是听泡上皮变的，骨迷路是周围间充质后来套上的"}
上皮先自成一套膜迷路（内淋巴在里）；间充质第 $3$ 个月才围成软骨性囊，第 $5$ 个月骨化成骨迷路，中间夹外淋巴间隙。把骨迷路写成听泡钙化，外淋巴这本间隙会消失。
:::

:::tip{label="听泡背腹两囊"}
背侧前庭囊 → $3$ 个膜半规管 + 椭圆囊上皮；腹侧耳蜗囊 → 球囊 + 膜蜗管上皮。内淋巴管从背端内侧长出，不要塞进耳蜗囊。
:::

## （二）中耳的发生

第 $9$ 周时，第 $1$ 咽囊向背外侧扩伸，远侧盲端膨大成管鼓隐窝（tubotympanic recess），近侧段形成咽鼓管。管鼓隐窝上方的间充质形成 $3$ 个听小骨原基。第 $6$ 个月时，$3$ 个听小骨原基先后骨化成为 $3$ 块听小骨。与此同时，管鼓隐窝远侧段扩大形成原始鼓室，听小骨周围的结缔组织被吸收而形成腔隙，与原始鼓室共同形成鼓室，听小骨位于其内。管鼓隐窝顶部的内胚层与第 $1$ 鳃沟底部的外胚层相对，分别形成鼓膜内、外上皮，两者间的间充质形成鼓膜内的结缔组织（见图 27-6）。

:::definition{label="第1咽囊与中耳"}
第 $9$ 周时，第 $1$ 咽囊向背外侧扩伸。中耳整份从这只咽囊扩出来，不是听泡侧面再鼓出一个中耳。
:::

:::definition{label="管鼓隐窝"}
第 $1$ 咽囊远侧盲端膨大成管鼓隐窝（tubotympanic recess）。远侧是隐窝，近侧才是咽鼓管。
:::

:::definition{label="咽鼓管（发生）"}
第 $1$ 咽囊近侧段形成咽鼓管。咽鼓管连的是咽和后来的鼓室，上皮是内胚层。
:::

:::definition{label="听小骨原基"}
管鼓隐窝上方的间充质形成 $3$ 个听小骨原基。听小骨来自隐窝上方的间充质，不是咽囊内胚层直接骨化。
:::

:::definition{label="听小骨骨化时间"}
第 $6$ 个月时，$3$ 个听小骨原基先后骨化成为 $3$ 块听小骨。原基在先，骨化在第 $6$ 个月。
:::

:::definition{label="原始鼓室与鼓室"}
管鼓隐窝远侧段扩大形成原始鼓室；听小骨周围的结缔组织被吸收而形成腔隙，与原始鼓室共同形成鼓室，听小骨位于其内。鼓室不是隐窝一次性挖空，还要把听小骨周围的结缔组织吸收掉。
:::

:::definition{label="鼓膜的三层（发生）"}
管鼓隐窝顶部的内胚层与第 $1$ 鳃沟底部的外胚层相对，分别形成鼓膜内、外上皮，两者间的间充质形成鼓膜内的结缔组织。内上皮内胚层，外上皮外胚层，中间间充质，三层都要。
:::

:::compare{title="第1咽囊近侧、远侧与鼓膜三层"}
| 项目 | 近侧段 | 远侧盲端（管鼓隐窝） | 隐窝上方间充质 | 鼓膜 |
|------|--------|----------------------|----------------|------|
| 去向 | 咽鼓管 | 扩大成原始鼓室，再与听小骨周围被吸收的腔隙共同成鼓室 | $3$ 个听小骨原基，第 $6$ 个月骨化 | 内上皮 = 隐窝顶内胚层；外上皮 = 第 $1$ 鳃沟底外胚层；中间 = 间充质 |
| 胚层 | 内胚层 | 内胚层 | 间充质 | 内胚层 + 外胚层 + 间充质 |
:::

:::cause-effect{title="咽囊扩出去，隐窝成鼓室，沟底对外才封成鼓膜"}
- 因：第 $9$ 周第 $1$ 咽囊向背外侧扩伸
- 果：远侧成管鼓隐窝，近侧成咽鼓管
- 因：隐窝上方间充质聚成 $3$ 个听小骨原基，第 $6$ 个月骨化；隐窝远侧扩大，听小骨周围结缔组织被吸收
- 果：原始鼓室与这些腔隙共同形成鼓室，听小骨在鼓室内
- 因：隐窝顶内胚层与第 $1$ 鳃沟底外胚层相对，中间夹间充质
- 果：鼓膜内、外上皮和中间结缔组织三层成形
:::

:::pitfall{label="听小骨不是咽囊内胚层变的，鼓膜也不是只有一层上皮"}
咽囊内胚层铺的是咽鼓管和鼓室的上皮衬里。听小骨来自管鼓隐窝上方的间充质，第 $6$ 个月才骨化。鼓膜必须对上三层：里面内胚层、外面第 $1$ 鳃沟外胚层、中间间充质。写成“第 $1$ 咽囊长出三块骨头”，或把鼓膜写成鳃沟底单独一张膜，外耳道和中耳的交界会错位。
:::

:::insight{label="中耳是咽囊向外够到鳃沟底，才在交界处封上鼓膜"}
第 $1$ 咽囊向外扩，第 $1$ 鳃沟向内陷，两份在鼓膜处碰头：内胚层对外胚层，间充质夹在中间。听泡走自己的膜迷路，并不变成鼓室。把中耳听成内耳旁边裂出来的腔，咽鼓管那条通往咽的管道会没有来路。
:::

## （三）外耳的发生

外耳道由第 $1$ 鳃沟演变形成。第 $2$ 个月末，第 $1$ 鳃沟向内深陷，形成外耳道外侧段。管道的底部外胚层细胞增生形成一上皮细胞板，称外耳道栓（meatal plug）。第 $7$ 个月时，外耳道栓内部细胞退化吸收，形成的管腔为外耳道内侧段（见图 27-6）。第 $6$ 周时，第 $1$ 鳃沟周围的间充质增生，形成 $6$ 个结节状隆起，称耳丘（auricular hillock）。后来这些耳丘围绕外耳道口，演变成耳郭（图 27-8）。

:::definition{label="外耳道（发生）"}
外耳道由第 $1$ 鳃沟演变形成。外侧段是鳃沟向内深陷来的，内侧段是外耳道栓内部细胞退化吸收来的，两段都对第 $1$ 鳃沟，不是咽囊。
:::

:::definition{label="外耳道外侧段"}
第 $2$ 个月末，第 $1$ 鳃沟向内深陷，形成外耳道外侧段。深陷发生在第 $2$ 个月末。
:::

:::definition{label="外耳道栓"}
管道的底部外胚层细胞增生形成一上皮细胞板，称外耳道栓（meatal plug）。栓是实心的上皮细胞板，暂时堵住内侧。
:::

:::definition{label="外耳道内侧段"}
第 $7$ 个月时，外耳道栓内部细胞退化吸收，形成的管腔为外耳道内侧段。内侧段要等第 $7$ 个月栓心退化才出现。
:::

:::definition{label="耳丘"}
第 $6$ 周时，第 $1$ 鳃沟周围的间充质增生，形成 $6$ 个结节状隆起，称耳丘（auricular hillock）。一共 $6$ 个，围在沟的周围。
:::

:::definition{label="耳郭（发生）"}
这些耳丘围绕外耳道口，演变成耳郭。耳郭来自 $6$ 个耳丘，不是单独一个结节胀大。
:::

:::timeline{period="外耳道与耳郭"}
- **第6周** 第1鳃沟周围间充质增生，形成 6 个耳丘
- **第2个月末** 第1鳃沟向内深陷，形成外耳道外侧段；底部外胚层增生为外耳道栓
- **耳丘** 围绕外耳道口，演变成耳郭
- **第7个月** 外耳道栓内部细胞退化吸收，形成外耳道内侧段
:::

:::compare{title="外耳道两段与耳郭"}
| 项目 | 外耳道外侧段 | 外耳道内侧段 | 耳郭 |
|------|--------------|--------------|------|
| 时间 | 第 $2$ 个月末 | 第 $7$ 个月 | 耳丘第 $6$ 周出现，随后围绕外耳道口演变 |
| 形成方式 | 第 $1$ 鳃沟向内深陷 | 外耳道栓内部细胞退化吸收成管腔 | $6$ 个耳丘（沟周间充质结节）围绕外耳道口 |
| 材料 | 第 $1$ 鳃沟外胚层 | 栓为底部外胚层增生的上皮细胞板 | 间充质结节 + 表面外胚层 |
:::

:::pitfall{label="外耳道内侧段要等第7个月栓心吸收，不要写成第2个月末一次挖通"}
第 $2$ 个月末只做出外侧段，底部还堵着外耳道栓。第 $7$ 个月栓内部细胞退化吸收，内侧段才通。写成“鳃沟一凹就是整条外耳道”，先天性外耳道闭锁会没有“栓没吸收”这条发生学来路。耳郭也不是一个皮瓣，是 $6$ 个耳丘围着外耳道口演出来的。
:::

:::insight{label="外耳道先深陷再通栓，耳郭用6个丘围住口"}
沟向内够，咽囊向外够，中间夹鼓膜；沟口那一圈 $6$ 个丘变成耳郭。外耳、中耳在鼓膜处对接，内耳仍是听泡自己那一套。三份原基在空间上靠拢，胚层上并不混成一份。
:::

:::example{label="外耳两段只记“先沟后栓”"}
外侧段：第 $2$ 个月末，第 $1$ 鳃沟深陷。内侧段：第 $7$ 个月，外耳道栓中心退化成腔。口诀落在时间和材料上，不要记成“外耳道从软骨挖出来”。
:::

## （四）主要畸形

### 1. 先天性耳聋

先天性耳聋（congenital deafness）有遗传性和非遗传性两类。遗传性耳聋属常染色体隐性遗传，主要由于不同类型和不同程度的内耳发育不全、耳蜗神经发育不良、听小骨发育缺陷与外耳道闭锁所致。非遗传性耳聋与药物中毒、病毒感染等因素有关。先天性耳聋患儿因听不到语言，不能进行语言学习与锻炼，常表现为又聋又哑。

:::definition{label="先天性耳聋"}
先天性耳聋（congenital deafness）有遗传性和非遗传性两类。先分这两类，再问落在内耳、耳蜗神经、听小骨还是外耳道。
:::

:::definition{label="遗传性耳聋"}
遗传性耳聋属常染色体隐性遗传，主要由于不同类型和不同程度的内耳发育不全、耳蜗神经发育不良、听小骨发育缺陷与外耳道闭锁所致。一条遗传方式，四个常见落点：膜迷路／骨迷路侧、蜗神经、听小骨、外耳道。
:::

:::definition{label="非遗传性耳聋"}
非遗传性耳聋与药物中毒、病毒感染等因素有关。环境因素走这一类，不要全部写成常染色体隐性。
:::

:::note{label="又聋又哑"}
先天性耳聋患儿因听不到语言，不能进行语言学习与锻炼，常表现为又聋又哑。哑是听不到语言后的继发，不是另有一套发声器官畸形必须同时存在。
:::

### 2. 副耳郭

副耳郭（accessory auricle）又称耳郭附件，多由于耳丘发生过多所致，常见于耳屏前方。

:::definition{label="副耳郭"}
副耳郭（accessory auricle）又称耳郭附件，多由于耳丘发生过多所致，常见于耳屏前方。多出来的是耳丘，位置多在耳屏前。
:::

### 3. 耳瘘

耳瘘（auricular fistula）常见于耳屏前方，可能因第 $1$ 鳃沟的背部闭合不全，或第 $1$、$2$ 鳃弓发生的耳丘融合不良所致，形成皮肤性盲管继续向下延伸，并和鼓室相通，可挤压出白色乳酪状液体，易感染。

:::definition{label="耳瘘"}
耳瘘（auricular fistula）常见于耳屏前方。可能因第 $1$ 鳃沟的背部闭合不全，或第 $1$、$2$ 鳃弓发生的耳丘融合不良所致。
:::

:::definition{label="耳瘘的管道与内容"}
形成皮肤性盲管继续向下延伸，并和鼓室相通，可挤压出白色乳酪状液体，易感染。管道连的是体表和鼓室，不是听泡。
:::

:::compare{title="耳的三种主要畸形"}
| 畸形 | 英文 | 发生学落点 | 要点 |
|------|------|------------|------|
| 先天性耳聋 | congenital deafness | 遗传性（常染色体隐性）：内耳发育不全、耳蜗神经发育不良、听小骨发育缺陷、外耳道闭锁；非遗传性：药物中毒、病毒感染等 | 听不到语言，常又聋又哑 |
| 副耳郭 | accessory auricle（耳郭附件） | 耳丘发生过多 | 常见于耳屏前方 |
| 耳瘘 | auricular fistula | 第 $1$ 鳃沟背部闭合不全，或第 $1$、$2$ 鳃弓耳丘融合不良 | 耳屏前方皮肤性盲管，向下延伸并与鼓室相通；可挤出白色乳酪状液体，易感染 |
:::

:::pitfall{label="副耳郭是耳丘多长，耳瘘是沟或丘没合好，不要都写成“多长了一个耳朵”"}
副耳郭：耳丘发生过多，多在耳屏前多出一块附件。耳瘘：第 $1$ 鳃沟背部闭合不全，或第 $1$、$2$ 鳃弓的耳丘融合不良，留下通向鼓室的皮肤性盲管。一个是多，一个是没合严。先天性耳聋更不是外耳外形问题，四个落点里内耳、蜗神经、听小骨、外耳道闭锁都要能问到。
:::

:::keypoint{label="听泡做膜迷路，咽囊做鼓室，鳃沟做外耳道"}
- 第 $4$ 周初菱脑诱导听板 → 听窝 → 听泡；背侧前庭囊 → 膜半规管和椭圆囊，腹侧耳蜗囊 → 球囊和膜蜗管；第 $3$ 个月软骨性囊，约第 $5$ 个月骨迷路，中间外淋巴间隙。
- 第 $9$ 周第 $1$ 咽囊 → 管鼓隐窝（鼓室）+ 咽鼓管；隐窝上方间充质第 $6$ 个月骨化成 $3$ 块听小骨；鼓膜 = 内胚层 + 外胚层 + 间充质。
- 第 $1$ 鳃沟 → 外耳道（第 $2$ 个月末外侧段，第 $7$ 个月栓吸收成内侧段）；第 $6$ 周 $6$ 个耳丘 → 耳郭。
- 畸形：先天性耳聋、副耳郭、耳瘘。
:::

:::memory{label="本节必背要点"}
- [ ] 耳分内耳、中耳和外耳 $3$ 部分。
- [ ] 内耳来自头部表面外胚层的耳板（听板）；中耳来自第 $1$ 咽囊；外耳来自第 $1$ 鳃沟及围绕鳃沟的 $6$ 个结节。
- [ ] 第 $4$ 周初，菱脑两侧表面外胚层在菱脑诱导下增厚为听板（otic placode）。
- [ ] 听板内陷成听窝（otic pit）；听窝闭合并与表面外胚层分离，形成听泡（otic vesicle）。
- [ ] 听泡初为梨形，向背、腹延伸，形成背侧前庭囊和腹侧耳蜗囊，背端内侧长出内淋巴管。
- [ ] 前庭囊演化为 $3$ 个膜半规管和椭圆囊的上皮；耳蜗囊演化为球囊和膜蜗管的上皮。
- [ ] 听泡演变为内耳膜迷路。
- [ ] 第 $3$ 个月膜迷路周围间充质分化为软骨性囊；约第 $5$ 个月骨化成骨迷路；两者间隔狭窄外淋巴间隙。
- [ ] 第 $9$ 周第 $1$ 咽囊向背外侧扩伸，远侧成管鼓隐窝（tubotympanic recess），近侧成咽鼓管。
- [ ] 管鼓隐窝上方间充质形成 $3$ 个听小骨原基，第 $6$ 个月骨化成 $3$ 块听小骨。
- [ ] 管鼓隐窝远侧段扩大成原始鼓室，听小骨周围结缔组织被吸收，共同形成鼓室。
- [ ] 鼓膜内上皮来自管鼓隐窝顶内胚层，外上皮来自第 $1$ 鳃沟底外胚层，中间为间充质。
- [ ] 外耳道由第 $1$ 鳃沟演变；第 $2$ 个月末深陷成外侧段；底部外胚层增生为外耳道栓（meatal plug）。
- [ ] 第 $7$ 个月外耳道栓内部细胞退化吸收，形成外耳道内侧段。
- [ ] 第 $6$ 周第 $1$ 鳃沟周围间充质形成 $6$ 个耳丘（auricular hillock），围绕外耳道口演变成耳郭。
- [ ] 先天性耳聋分遗传性和非遗传性；遗传性属常染色体隐性，可因内耳发育不全、耳蜗神经发育不良、听小骨发育缺陷与外耳道闭锁。
- [ ] 非遗传性耳聋与药物中毒、病毒感染等因素有关；患儿常又聋又哑。
- [ ] 副耳郭（accessory auricle）又称耳郭附件，多因耳丘发生过多，常见于耳屏前方。
- [ ] 耳瘘（auricular fistula）常见于耳屏前方，可因第 $1$ 鳃沟背部闭合不全或第 $1$、$2$ 鳃弓耳丘融合不良，皮肤性盲管与鼓室相通，可挤出白色乳酪状液体，易感染。
:::

## 本章小结

胚胎第 $4$ 周，由前脑泡形成的视泡与视柄为眼球发生的原基，分别演变成视网膜和视神经。视泡内陷成双层视杯结构，外层分化为色素上皮层，内层分化为神经层。在视泡的诱导下，与之紧邻的表面外胚层增厚成晶状体板，随之内陷成晶状体泡。晶状体泡后壁细胞向前延伸成初级晶状体纤维，前壁细胞保持单层立方形状，赤道部细胞不断分裂分化形成次级晶状体纤维。初级晶状体纤维形成晶状体核，次级纤维逐层添加到晶状体核周围，使晶状体核及晶状体逐渐增大。在晶状体泡诱导下，其前方表面外胚层分化形成角膜上皮，角膜的其他层次则由上皮后方的间充质分化而成。视杯周围的间充质分为内、外两层，分别分化为血管膜和巩膜。第 $7$ 周时，眼球前方的表面外胚层形成上、下两个皱褶，分别发育成上、下眼睑。胚胎第 $10$ 周，上、下眼睑边缘融合，至第 $7$ 或第 $8$ 个月时又重新分开。上眼睑外侧部表面外胚层上皮长入间充质内，分化为泪腺。眼发育主要畸形有先天性白内障、先天性无虹膜和先天性青光眼等。

胚胎第 $4$ 周，在菱脑的诱导下，表面外胚层增厚内陷形成听板、听窝，最终与表面外胚层分离，形成囊状的听泡，为内耳膜迷路原基，其周围的间充质分化为骨迷路。听泡向背腹方向延伸，形成背侧的前庭囊和腹侧的耳蜗囊，前者演变为半规管和椭圆囊的上皮，后者演变为球囊和膜蜗管的上皮。中耳由第 $1$ 咽囊演变而成，其外侧端膨大形成管鼓隐窝，演变为鼓室和咽鼓管，管鼓隐窝上方的间充质形成听小骨原基，分化成 $3$ 块听小骨。外耳道由第 $1$ 鳃沟演变而来，耳郭则由围绕外耳道口的 $6$ 个结节状隆起，即耳丘演变而成。耳发生的主要畸形有先天性耳聋、副耳郭和耳瘘等。

:::definition{label="本章小结中的眼"}
胚胎第 $4$ 周，前脑泡形成的视泡与视柄为眼球发生的原基，分别演变成视网膜和视神经。视泡内陷成双层视杯：外层色素上皮层，内层神经层。视泡诱导紧邻的表面外胚层增厚成晶状体板，再内陷成晶状体泡。后壁成初级晶状体纤维，前壁保持单层立方，赤道部成次级晶状体纤维；初级纤维成晶状体核，次级纤维逐层添加使核和晶状体增大。晶状体泡诱导前方表面外胚层成角膜上皮，后方间充质成角膜其他层次。视杯周围间充质内、外层分别成血管膜和巩膜。第 $7$ 周上、下眼睑皱褶，第 $10$ 周融合，第 $7$ 或第 $8$ 个月再分开；上眼睑外侧外胚层长入间充质成泪腺。主要畸形：先天性白内障、先天性无虹膜和先天性青光眼等。
:::

:::definition{label="本章小结中的耳"}
胚胎第 $4$ 周，菱脑诱导表面外胚层增厚内陷，形成听板、听窝，再与表面外胚层分离成听泡，为内耳膜迷路原基；周围间充质分化为骨迷路。听泡向背腹延伸：背侧前庭囊 → 半规管和椭圆囊上皮，腹侧耳蜗囊 → 球囊和膜蜗管上皮。中耳由第 $1$ 咽囊演变，外侧端管鼓隐窝演变为鼓室和咽鼓管，隐窝上方间充质成 $3$ 块听小骨。外耳道由第 $1$ 鳃沟演变，耳郭由 $6$ 个耳丘演变。主要畸形：先天性耳聋、副耳郭和耳瘘等。
:::

:::compare{title="本章小结对照：眼与耳"}
| 项目 | 眼 | 耳 |
|------|----|----|
| 第 $4$ 周原基 | 前脑泡 → 视泡与视柄 | 菱脑诱导 → 听板、听窝、听泡 |
| 双层 / 分区 | 视杯外层色素上皮、内层神经层 | 听泡背侧前庭囊、腹侧耳蜗囊 |
| 表面外胚层被诱导 | 晶状体板 → 晶状体泡；前方再成角膜上皮 | 听板本身就是表面外胚层增厚 |

| 附属 / 通道 | 第 $7$ 周眼睑，第 $10$ 周融合，第 $7$ 或第 $8$ 个月分开；泪腺 | 第 $1$ 咽囊 → 鼓室和咽鼓管；第 $1$ 鳃沟 → 外耳道；$6$ 个耳丘 → 耳郭 |
| 小结列出的畸形 | 先天性白内障、先天性无虹膜、先天性青光眼等 | 先天性耳聋、副耳郭、耳瘘等 |
:::

:::concept{term="先问小结里的视泡对听泡，再问晶状体纤维三步和咽囊、鳃沟两份通道"}
看见本章小结，先收第 $4$ 周两份泡：前脑泡出来的视泡、视柄对视网膜和视神经；菱脑诱导出来的听泡对膜迷路，周围间充质对骨迷路。眼再问视杯内外层、晶状体板泡、前壁立方／后壁初级纤维／赤道次级纤维、角膜两份材料、血管膜与巩膜、眼睑融合再分开和泪腺。耳再问前庭囊与耳蜗囊、第 $1$ 咽囊的管鼓隐窝、第 $1$ 鳃沟的外耳道和 $6$ 个耳丘。畸形只点眼三条、耳三条；瞳孔膜残留、玻璃体管、外耳道栓等仍以两节正文为准。
:::

:::insight{label="眼是视泡内陷加两份诱导，耳是听泡分区加咽囊和鳃沟对贴"}
眼：神经外胚层先膨出再内陷，表面外胚层被视泡诱导成晶状体、被晶状体泡诱导成角膜上皮，间充质做膜和巩膜。耳：表面外胚层被菱脑诱导成听泡，自己分成前庭囊和耳蜗囊；中耳、外耳是第 $1$ 咽囊和第 $1$ 鳃沟在鼓膜处对贴。两套感觉器都从第 $4$ 周起步，胚层户头并不相同。

:::keypoint{label="第4周视泡与听泡，晶状体三步纤维，咽囊对鳃沟"}
- 视泡、视柄 → 视网膜、视神经；视杯外层色素上皮、内层神经层。
- 晶状体板 → 晶状体泡：后壁初级纤维成核，前壁立方，赤道次级纤维终身加层；晶状体泡诱导角膜上皮。
- 间充质 → 角膜其他层次、血管膜、巩膜；眼睑第 $7$ 周出、第 $10$ 周合、第 $7$ 或第 $8$ 个月分；泪腺来自上眼睑外侧。
- 听泡 → 膜迷路（前庭囊、耳蜗囊）；周围间充质 → 骨迷路。
- 第 $1$ 咽囊 → 鼓室和咽鼓管及听小骨原基；第 $1$ 鳃沟 → 外耳道；$6$ 个耳丘 → 耳郭。
- 眼畸形：先天性白内障、先天性无虹膜、先天性青光眼等；耳畸形：先天性耳聋、副耳郭、耳瘘等。

:::note{label="角膜缘干细胞与角膜疾病"}
角膜和巩膜之间的狭窄移行区为角膜缘，由于两者逐渐过渡，因而在眼表面两者之间没有明确的分界线。

角膜缘由数层密集细胞和下方基质组成，基底面排列成嵴状，层数超过 $10$ 层，排列不规则，细胞体积小，呈矮柱状，核深染，形成特殊的栅状结构，即 Vogt 栅栏（palisades of Vogt，POV），其中位于基底部的细胞即角膜缘干细胞（limbal stem cell，LSC）。角膜缘中还含有色素细胞、朗格汉斯细胞和丰富的毛细血管，使干细胞免受紫外线损伤，并得到营养支持。

正常情况下，角膜表面上皮细胞不断脱落，通过基底层细胞增殖来替代。角膜上皮基底层细胞是短暂扩增细胞，经历有限几代分裂后即形成末端分化细胞，而角膜缘干细胞则不断缓慢分裂增殖形成子细胞，并向角膜中央转移，补充基底层细胞。

如果角膜损伤，角膜缘干细胞迅速增殖以修复创伤。除分化、增殖为上皮细胞以外，角膜缘干细胞还作为一道屏障，阻止结膜上皮移行至角膜表面，这对于保持角膜的透明性与正常生理功能有重要意义。角膜缘干细胞缺乏时，出现角膜上皮糜烂、结膜上皮增生移行、新生血管形成等表现，角膜透明性将被破坏，导致视力下降。还有许多疾病可损伤角膜缘，导致角膜缘干细胞部分或完全性缺乏，如先天性无虹膜、热烧伤、酸碱烧伤、手术创伤、接触镜佩戴不当、严重干眼症、药物毒性作用等。而为了修复持续性角膜损伤，可采取自体或异体角膜缘干细胞移植重建角膜上皮。
:::
