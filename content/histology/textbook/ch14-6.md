# 六、大肠

大肠（large intestine）分为盲肠、阑尾、结肠、直肠和肛管，主要功能是吸收水分和电解质，使食物残渣形成粪便。上一节小肠用绒毛和微绒毛抢营养；这一节把绒毛收掉、把杯状细胞加密，黏液润滑粪便，肌层改写成结肠袋和三条结肠带。阑尾是黏膜免疫器官；肛管在齿状线把单层柱状骤变成复层扁平。

:::definition{label="大肠"}
大肠（large intestine）分为盲肠、阑尾、结肠、直肠和肛管。主要功能是吸收水分和电解质，使食物残渣形成粪便。
:::

:::concept{term="先问有没有绒毛，再问杯状细胞是不是比小肠多、有没有帕内特细胞"}
大肠黏膜表面光滑、无绒毛。上皮仍是单层柱状，但吸收细胞改收水分、电解质和细菌产的维生素，杯状细胞大量出现。大肠腺是直管状，无帕内特细胞。看见“肠黏膜 + 直腺 + 没有指状突起”，先写大肠，不要按空肠去找中央乳糜管。
:::

:::compare{title="小肠与大肠黏膜"}
| 项目 | 小肠 | 大肠（盲肠、结肠、直肠） |
|------|------|--------------------------|
| 绒毛 | 有（叶状/指状/锥形） | 无，表面光滑 |
| 皱襞 | 环行皱襞（黏膜 + 黏膜下层） | 结肠袋之间半月形皱襞；直肠下段 3 个直肠横襞 |
| 上皮 | 单层柱状：吸收细胞为主，杯状细胞向回肠增多 | 单层柱状：吸收细胞 + **大量**杯状细胞 |
| 腺 | 小肠腺（利伯屈恩隐窝），有帕内特细胞 | 大肠腺，直管状，**无帕内特细胞** |
| 吸收侧重 | 几乎全部营养物质 | 水分、电解质；细菌产生的 B 族维生素和维生素 K |
| 淋巴组织 | 回肠集合淋巴小结 | 孤立淋巴小结；阑尾极丰富 |
:::

## （一）盲肠、结肠和直肠

这 3 部分大肠的组织学结构基本相同（图 14-30）。

:::definition{label="盲肠、结肠与直肠"}
盲肠、结肠和直肠这 3 部分的组织学结构基本相同：黏膜无绒毛，大肠腺直而密，肌层改写出结肠袋和结肠带，外膜按部位为浆膜或纤维膜。
:::

### 1. 黏膜

黏膜表面光滑，无绒毛；在结肠袋之间的横沟处有半月形皱襞，在直肠下段有 3 个横行的皱襞（直肠横襞）。上皮为单层柱状上皮，由吸收细胞和大量杯状细胞组成。大肠的吸收细胞主要吸收水分和电解质，以及大肠内细菌产生的 B 族维生素和维生素 K。固有层内有稠密的大肠腺，呈直管状，含吸收细胞、大量杯状细胞、少量干细胞和内分泌细胞，无帕内特细胞。分泌黏液是大肠腺的重要功能。固有层内可见孤立淋巴小结。黏膜肌层同小肠。

:::definition{label="大肠黏膜表面"}
大肠黏膜表面光滑，无绒毛。结肠袋之间的横沟处有半月形皱襞；直肠下段有 3 个横行的皱襞，称直肠横襞。
:::

:::definition{label="大肠上皮"}
大肠上皮为单层柱状上皮，由吸收细胞和大量杯状细胞组成。吸收细胞主要吸收水分和电解质，以及大肠内细菌产生的 B 族维生素和维生素 K。
:::

:::definition{label="大肠腺"}
大肠腺位于固有层，稠密、呈直管状，含吸收细胞、大量杯状细胞、少量干细胞和内分泌细胞，**无帕内特细胞**。分泌黏液是其重要功能。
:::

:::definition{label="大肠固有层淋巴组织"}
固有层内可见孤立淋巴小结。黏膜肌层同小肠，由内环行和外纵行两薄层平滑肌组成。
:::

:::pitfall{label="大肠无绒毛、无帕内特细胞，不要按小肠腺去找嗜酸性颗粒"}
大肠腺直管状、杯状细胞很多，黏液是主业。帕内特细胞的溶菌酶和防御素账写在小肠腺基部，不要搬到结肠。切片上若腺腔里全是空泡样杯状细胞、腔面平、没有指状绒毛，就是大肠。
:::

:::insight{label="杯状细胞加密，是因为粪便要被黏液送走"}
小肠要吸收营养，杯状细胞从十二指肠到回肠才逐渐增多。大肠要把残渣做成粪便并推向肛门，黏液润滑变成腺的重要功能，杯状细胞因此大量出现。把大肠听成“吸收功能更强的小肠”，维生素 K 和水分账会盖住黏液账。
:::

::figure{src="/images/histology/textbook/p0170_01.png" caption="图14-30 结肠（横切面）光镜图。1. 大肠腺；2. 黏膜肌层；3. 黏膜下层。表面无绒毛，直管状大肠腺密集，杯状细胞多。" alt="结肠横切：腔面平坦无绒毛，固有层直管状腺达黏膜肌，下方为黏膜下层"}

### 2. 黏膜下层

黏膜下层在结缔组织内有小动脉、小静脉和淋巴管，可有成群脂肪细胞。

:::definition{label="大肠黏膜下层"}
大肠黏膜下层结缔组织内有小动脉、小静脉和淋巴管，可有成群脂肪细胞。没有十二指肠腺那样的黏膜下腺。
:::

### 3. 肌层

肌层由内环行和外纵行两层平滑肌组成。内环行肌节段性局部增厚，形成结肠袋；外纵行肌局部增厚形成 3 条结肠带，带间的纵行肌菲薄甚至缺如。

:::definition{label="大肠肌层"}
大肠肌层由内环行和外纵行两层平滑肌组成。
:::

:::definition{label="结肠袋"}
内环行肌节段性局部增厚，形成结肠袋。
:::

:::definition{label="结肠带"}
外纵行肌局部增厚形成 3 条结肠带；带间的纵行肌菲薄甚至缺如。
:::

:::pitfall{label="结肠带是外纵肌局部增厚，不是另长的三条韧带"}
三条结肠带是外纵行平滑肌自己堆厚的结果，带与带之间纵肌可以薄到几乎没有。结肠袋则是内环肌节段性加厚。把结肠带写成“浆膜上的纤维条”，肌层账和外膜肠脂垂会并成一个名词。
:::

:::compare{title="小肠与结肠的肌层改写"}
| 项目 | 小肠 | 结肠 |
|------|------|------|
| 层次 | 内环、外纵 2 层平滑肌 | 仍是内环、外纵 2 层 |
| 内环肌 | 相对均匀 | 节段性局部增厚 → 结肠袋 |
| 外纵肌 | 相对均匀 | 局部增厚成 3 条结肠带，带间菲薄甚至缺如 |
:::

### 4. 外膜

外膜在盲肠、横结肠、乙状结肠为浆膜；在升结肠与降结肠的前壁为浆膜，后壁为纤维膜；在直肠上 $1/3$ 段的大部、中 $1/3$ 段的前壁为浆膜，余为纤维膜。外膜结缔组织中常有脂肪细胞聚集构成的肠脂垂。

:::definition{label="大肠外膜"}
盲肠、横结肠、乙状结肠为浆膜。升结肠与降结肠前壁浆膜、后壁纤维膜。直肠上 $1/3$ 段大部和中 $1/3$ 段前壁为浆膜，其余为纤维膜。
:::

:::definition{label="肠脂垂"}
外膜结缔组织中常有脂肪细胞聚集，构成肠脂垂。
:::

:::note{label="大肠各段外膜"}
| 部位 | 外膜 |
|------|------|
| 盲肠、横结肠、乙状结肠 | 浆膜 |
| 升结肠、降结肠 | 前壁浆膜，后壁纤维膜 |
| 直肠上 $1/3$ 段大部、中 $1/3$ 段前壁 | 浆膜 |
| 直肠其余部分 | 纤维膜 |
| 外膜结缔组织 | 可有肠脂垂（脂肪细胞聚集） |
:::

## （二）阑尾

阑尾的管腔小而不规则，大肠腺短而少。固有层内有极丰富的淋巴组织，大量淋巴小结可连续成层，并突入黏膜下层，致使黏膜肌层不完整。肌层很薄，外覆浆膜，富含血管。阑尾是具有黏膜免疫功能的器官（图 14-31）。

:::definition{label="阑尾"}
阑尾管腔小而不规则，大肠腺短而少。固有层淋巴组织极丰富，大量淋巴小结可连续成层并突入黏膜下层，黏膜肌层因此不完整。肌层很薄，外覆浆膜，富含血管。阑尾是具有黏膜免疫功能的器官。
:::

:::insight{label="阑尾先看成淋巴器官，再看成一条细大肠"}
腺短而少、腔不规则，是因为淋巴小结把黏膜肌顶断、挤进黏膜下层。切片上第一眼是成层的淋巴小结，而不是去数大肠腺有多长。把阑尾只背成“容易发炎的盲管”，黏膜免疫这本账会从固有层里消失。
:::

:::compare{title="结肠与阑尾"}
| 项目 | 结肠 | 阑尾 |
|------|------|------|
| 管腔 | 较大，相对规则 | 小而不规则 |
| 大肠腺 | 稠密、直管状 | 短而少 |
| 淋巴组织 | 孤立淋巴小结 | 极丰富，淋巴小结可连续成层并突入黏膜下层 |
| 黏膜肌层 | 完整 | 不完整 |
| 肌层 | 内环成结肠袋，外纵成结肠带 | 很薄，无结肠带 |
| 外膜 | 按段浆膜或纤维膜，可有肠脂垂 | 浆膜，富含血管 |
| 功能侧重 | 吸收水分、形成粪便 | 黏膜免疫 |
:::

:::pitfall{label="阑尾黏膜肌不完整，不要按完整四层去切淋巴小结的位置"}
淋巴小结连续成层并突入黏膜下层，黏膜肌被顶断。不要把突入黏膜下层的淋巴小结当成“黏膜下层自己长的淋巴结”，也不要把阑尾写成有结肠带的迷你结肠。
:::

::figure{src="/images/histology/textbook/p0170_02.png" caption="图14-31 阑尾（横切面）光镜图。1. 黏膜；↑ 黏膜肌层；2. 黏膜下层；3. 肌层；4. 淋巴小结。管腔不规则，淋巴小结连续成层并突入黏膜下层。" alt="阑尾横切：狭小不规则管腔，黏膜及黏膜下层内多个淋巴小结，肌层薄"}

## （三）肛管

在齿状线以上的肛管黏膜结构和直肠相似，仅在肛管上段出现了纵行皱襞（肛柱）。在齿状线处，单层柱状上皮骤变为轻度角化的复层扁平上皮，大肠腺和黏膜肌消失（图 14-32）。白线以下为和皮肤相同的角化复层扁平上皮，含有很多黑色素；固有层中出现了环肛腺（大汗腺）和丰富的皮脂腺。肛管黏膜下层的结缔组织中有密集的静脉丛，如静脉淤血扩张则形成痔。肌层由两层平滑肌构成，其内环行肌增厚形成肛门内括约肌。近肛门处，外纵行肌周围有骨骼肌形成的肛门外括约肌。

:::definition{label="肛管齿状线以上"}
齿状线以上的肛管黏膜结构和直肠相似，仅在肛管上段出现纵行皱襞，称肛柱。
:::

:::definition{label="齿状线"}
齿状线处单层柱状上皮骤变为轻度角化的复层扁平上皮，大肠腺和黏膜肌消失。
:::

:::definition{label="白线以下的肛管"}
白线以下为和皮肤相同的角化复层扁平上皮，含有很多黑色素；固有层中出现环肛腺（大汗腺）和丰富的皮脂腺。
:::

:::definition{label="痔"}
肛管黏膜下层结缔组织中有密集的静脉丛；静脉淤血扩张则形成痔。
:::

:::definition{label="肛门内括约肌与外括约肌"}
肌层由两层平滑肌构成，内环行肌增厚形成肛门内括约肌。近肛门处，外纵行肌周围有骨骼肌形成的肛门外括约肌。
:::

:::concept{term="先问过没过齿状线：柱状还是复层扁平，平滑肌括约肌还是骨骼肌括约肌"}
齿状线是上皮账的悬崖：上面仍按直肠写单层柱状、大肠腺、黏膜肌；线下腺和黏膜肌消失，变成轻度角化复层扁平。白线以下进一步皮肤化，出现黑素、环肛腺和皮脂腺。内括约肌是内环平滑肌加厚，外括约肌是骨骼肌，不要写成“都是平滑肌括约肌”。
:::

:::compare{title="肛管三段上皮与腺体"}
| 部位 | 上皮 | 腺与黏膜肌 | 其他 |
|------|------|------------|------|
| 齿状线以上（上段有肛柱） | 单层柱状（同直肠） | 有大肠腺和黏膜肌 | 黏膜下层静脉丛 |
| 齿状线处 | 骤变为轻度角化复层扁平 | 大肠腺和黏膜肌消失 | 交界为肿瘤和上皮化生的观察点 |
| 白线以下 | 与皮肤相同的角化复层扁平，黑素多 | 环肛腺（大汗腺）+ 丰富皮脂腺 | 近肛门处骨骼肌形成肛门外括约肌 |
:::

:::pitfall{label="肛门外括约肌是骨骼肌，不要把肌层通例写成全程平滑肌"}
第一节就立过：食管上段与肛门的肌层是骨骼肌。内括约肌仍是内环平滑肌增厚；外括约肌是外纵肌周围的骨骼肌。痔写在黏膜下层静脉丛，不写在括约肌里。
:::

::figure{src="/images/histology/textbook/p0171_02.png" caption="图14-32 直肠–肛管交界处光镜图。↑ 单层柱状上皮–复层扁平上皮交界处（齿状线）。左侧腺性柱状黏膜，右侧复层扁平，大肠腺和黏膜肌在交界处消失。" alt="齿状线：单层柱状骤变为复层扁平，腺消失，下方为平滑肌"}

:::keypoint{label="大肠无绒毛多杯状，肌层写出结肠袋和结肠带"}
- 大肠：盲肠、阑尾、结肠、直肠、肛管；吸收水分和电解质，形成粪便。
- 盲肠/结肠/直肠：无绒毛；上皮为吸收细胞 + 大量杯状细胞；大肠腺直管状，无帕内特细胞。
- 吸收细胞还吸收细菌产生的 B 族维生素和维生素 K。
- 内环肌节段增厚 → 结肠袋；外纵肌局部增厚 → 3 条结肠带。
- 外膜按段浆膜或纤维膜；肠脂垂为外膜脂肪聚集。
- 阑尾：腔小不规则，腺短少，淋巴小结成层并突入黏膜下层，黏膜肌不完整，是黏膜免疫器官。
- 齿状线：单层柱状骤变轻度角化复层扁平，腺和黏膜肌消失；白线以下皮肤化。
- 黏膜下层静脉丛淤血扩张成痔；内括约肌为内环平滑肌，外括约肌为骨骼肌。
:::

- [ ] 齿状线处单层柱状上皮骤变为轻度角化的复层扁平上皮，大肠腺和黏膜肌消失。
- [ ] 白线以下为与皮肤相同的角化复层扁平上皮，含很多黑色素。
- [ ] 白线以下固有层出现环肛腺（大汗腺）和丰富的皮脂腺。
- [ ] 肛管黏膜下层有密集静脉丛，静脉淤血扩张则形成痔。
- [ ] 肌层两层平滑肌，内环行肌增厚形成肛门内括约肌。
- [ ] 近肛门处，外纵行肌周围有骨骼肌形成肛门外括约肌。
