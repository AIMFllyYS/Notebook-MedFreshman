# 二、心肌

心肌（cardiac muscle）分布于心壁和邻近心脏的大血管壁上，其收缩有自动节律性。受自主神经支配，属不随意肌；因肌质中有明暗相间的周期性横纹，与骨骼肌同属横纹肌。上一节把骨骼肌的肌节、三联体和滑行立住以后，心肌沿同一套粗、细肌丝改写四件事：细胞变短并分支成网、核改到中央、T 管改到 Z 线并多成二联体、细胞连接处出现闰盘。

:::definition{label="心肌"}
心肌（cardiac muscle）分布于心壁和邻近心脏的大血管壁上。收缩有自动节律性，受自主神经支配，属不随意肌；有横纹，属横纹肌。
:::

:::concept{term="先问这张切片是不是一张网：有没有分支和闰盘"}
骨骼肌纤维是并排的长圆柱，极少分支；心肌纤维短、不规则、有分支，互连成网，连接处染成深色的闰盘。看见横纹肌，先问纤维是不是连成网、有没有那条深染横线，再问核在周边还是中央。把心肌听成“短一点的骨骼肌”，会把闰盘和同步收缩那一本账做丢。
:::

## （一）心肌纤维的光镜结构

心肌纤维呈不规则的短圆柱状，有分支，互连成网。连接处染色较深，称闰盘（intercalated disk）。多数心肌纤维有一个核，少数有双核，核呈卵圆形，位于细胞中央。心肌纤维也呈明暗相间的周期性横纹，但不如骨骼肌纤维的明显。核周围的细胞质内可见脂褐素，随年龄增长而增多（图 6-9）。一般认为，心肌纤维无再生能力，损伤的心肌纤维由瘢痕组织代替。

:::definition{label="心肌纤维"}
心肌纤维呈不规则的短圆柱状，有分支，互连成网。多数有一个核，少数有双核；核卵圆形，位于细胞中央。有周期性横纹，但不如骨骼肌明显。
:::

:::definition{label="闰盘"}
闰盘（intercalated disk）是相邻心肌纤维的连接处，光镜下染色较深。电镜下，其横向部分位于 Z 线水平，有黏着小带与桥粒；纵向部分有缝隙连接。
:::

:::definition{label="脂褐素"}
脂褐素出现于心肌细胞核周围的细胞质内，随年龄增长而增多，是心肌纤维老化过程中常见的残余体类色素。
:::

:::pitfall{label="心肌核在中央，不要把周边那圈核当成心肌"}
骨骼肌核扁椭圆、贴在肌膜下，一条纤维几十到几百个；心肌核 1 个或 2 个、卵圆、居中。横切面上，中央一个圆核、周围是肌原纤维的，是心肌；核挤在细胞周边、中央铺满点状肌原纤维的，是骨骼肌。闰盘只在纵切面上表现为深染横线，横切面数核、看细胞形状，纵切面找闰盘。
:::

:::note{label="心肌损伤后由瘢痕代替"}
一般认为心肌纤维无再生能力。与骨骼肌纤维表面还有肌卫星细胞不同，心肌损伤后不能靠干细胞把纤维补回去，而是由结缔组织增生形成瘢痕。梗死区“修不好成肌、只能修成疤”，是下一章器官系统里心肌梗死要接的组织学前提。
:::

## （二）心肌纤维的超微结构

心肌纤维的超微结构与骨骼肌纤维相似，也含有粗、细两种肌丝及其组成的肌节。心肌纤维的特点是：①肌原纤维的粗细不等、界限不很分明，肌原纤维间有极为丰富的线粒体。②横小管较粗，位于 Z 线水平。③肌质网的纵小管稀疏，终池少而小，多见横小管与一侧的终池紧贴形成二联体（diad）。因此，心肌纤维的贮钙能力低，收缩前尚需从细胞外摄取 $\mathrm{Ca}^{2+}$。④闰盘的横向部分位于 Z 线水平，有黏着小带与桥粒，使心肌纤维间的连接牢固；在闰盘的纵向部分存在缝隙连接，便于细胞间化学信息的交流和电冲动的传导，分别使心房肌和心室肌整体的收缩和舒张同步化（图 6-10～图 6-12）。教材图 6-10 为心肌纤维透射电镜图（标暗带、明带、Z 线、M 线、肌质网、线粒体和闰盘），对应文件为空，本页不插入。

:::definition{label="二联体"}
二联体（diad）由一根横小管与一侧的终池紧贴形成，是心肌纤维中最常见的膜偶联形式。与骨骼肌的三联体相比，终池少而小，贮钙能力低。
:::

:::concept{term="先问 T 管贴着 Z 线还是 A–I 交界"}
骨骼肌横小管落在暗带与明带交界处，一个肌节两侧各有一套 T 管，每套夹两个终池，写成三联体。心肌横小管较粗，改到 Z 线水平，终池又少又小，多见 T 管只贴一侧终池，写成二联体。同一套滑行机器，钙库规模不同：骨骼肌主要靠肌质网里那上千倍的贮存；心肌贮钙能力低，收缩前还要从细胞外摄取 $\mathrm{Ca}^{2+}$。
:::

:::definition{label="闰盘的横向部分"}
闰盘的横向部分位于 Z 线水平，有黏着小带与桥粒，使相邻心肌纤维连接牢固，收缩时不至于被拉开。
:::

:::definition{label="闰盘的纵向部分"}
闰盘的纵向部分存在缝隙连接，便于细胞间化学信息的交流和电冲动的传导，分别使心房肌和心室肌整体的收缩和舒张同步化。
:::

:::compare{title="闰盘横向部分与纵向部分"}
| 项目 | 横向部分 | 纵向部分 |
|------|----------|----------|
| 所在平面 | 约在 Z 线水平，与肌纤维长轴垂直 | 沿细胞侧面纵向走行 |
| 主要连接 | 黏着小带、桥粒 | 缝隙连接 |
| 职分 | 机械锚定，连接牢固 | 化学信息交流和电冲动传导 |
| 功能后果 | 收缩时纤维不被拉开 | 心房肌、心室肌各自整体同步收缩与舒张 |
| 易混点 | 不是“把两个细胞核粘在一起” | 不是营养孔，也不等同于闰盘的全部 |
:::

:::cause-effect{title="闰盘怎样把许多心肌纤维写成一块功能整体"}
- 因：横向部分的黏着小带与桥粒把相邻纤维在 Z 线水平锚牢
- 因：纵向部分的缝隙连接让化学信息和电冲动在细胞间迅速传递
- 果：心房肌整体、心室肌整体各自同步收缩和舒张，而不是每条纤维各跳各的
- 制约：光镜下只能看见深染的闰盘轮廓；横向锚定与纵向电偶联要到电镜（图 6-12）才能分开记账
:::

:::insight{label="线粒体铺满肌原纤维之间，是节律收缩的能量账"}
心肌纤维的肌原纤维粗细不等、界限不如骨骼肌分明，空隙里却塞满线粒体。自动节律性意味着一生几乎不休息，ATP 消耗持续而高。骨骼肌可以靠肌质里的糖原和肌红蛋白应付爆发；心肌把能量账写进极丰富的线粒体。看见心肌电镜图，先数线粒体，再找稀疏的肌质网——钙库小、能量厂大，是心肌和骨骼肌在超微上的对照。
:::

:::compare{title="骨骼肌纤维与心肌纤维"}
| 项目 | 骨骼肌纤维 | 心肌纤维 |
|------|------------|----------|
| 形态 | 长圆柱状，除舌肌等外极少分支 | 不规则短圆柱状，有分支，互连成网 |
| 核 | 多核（几十至几百），扁椭圆，肌膜下方 | 多数 1 个、少数双核，卵圆形，细胞中央 |
| 横纹 | 明显 | 有，但较不明显 |
| 特有连接 | 无闰盘 | 闰盘（横：黏着小带、桥粒；纵：缝隙连接） |
| 肌原纤维 | 界限清楚，粗细较一致 | 粗细不等，界限不很分明 |
| 线粒体 | 较多 | 极为丰富 |
| 横小管 | 较细，位于 A 带与 I 带交界处 | 较粗，位于 Z 线水平 |
| 肌质网 / 终池 | 发达；终池大，组成三联体 | 纵小管稀疏，终池少而小，多见二联体 |
| 钙来源 | 主要来自肌质网贮存（网内浓度为肌质的上千倍） | 贮钙能力低，收缩前尚需从细胞外摄取 $\mathrm{Ca}^{2+}$ |
| 再生 | 肌卫星细胞可增殖分化参与修复 | 一般认为无再生能力，损伤由瘢痕代替 |
| 支配 / 节律 | 躯体神经，随意 | 自主神经，不随意，有自动节律性 |
| 脂褐素 | 不是光镜识别要点 | 核周可见，随年龄增多 |
:::

:::pitfall{label="二联体不是“缺了一半的三联体”就可以不管钙"}
二联体少一侧终池，贮钙能力低，所以心肌收缩还要借细胞外 $\mathrm{Ca}^{2+}$。这不是把三联体的定义改个名字，而是把钙账从“几乎全靠肌质网”改写成“网内贮存不够、还要吃细胞外钙”。临床里影响细胞外钙或慢钙通道的因素，会直接碰到这本账。不要把二联体只记成形态差异。
:::

:::keypoint{label="心肌在骨骼肌账上改核、改 T 管、加闰盘"}
- 短圆柱、有分支、连成网；核 1～2 个、居中；横纹较浅；核周脂褐素随年龄增多。
- 闰盘：横向黏着小带 + 桥粒（牢固），纵向缝隙连接（电偶联与化学交流），心房、心室各自同步。
- 肌原纤维界限不清，线粒体极丰富；T 管较粗、在 Z 线水平；肌质网稀疏，多见二联体。
- 贮钙能力低，收缩前需摄取细胞外 $\mathrm{Ca}^{2+}$；一般无再生，损伤由瘢痕代替。
:::
