# 三、毛细血管

毛细血管（capillary）为管径最细、分布最广的血管，它们的分支互相吻合成网（图 9-10，图 9-11）。毛细血管网在各器官内的疏密程度不同，代谢旺盛器官（如心脏、肝、肺、肾和骨骼肌等）的毛细血管网很密，代谢较低器官（如骨、肌腱、韧带和平滑肌等）的毛细血管网稀疏。

:::definition{label="毛细血管"}
毛细血管（capillary）为管径最细、分布最广的血管，分支互相吻合成网。管径一般为 $6\sim 8\,\mu\mathrm{m}$，容许 1 个红细胞通过。是血液与组织细胞之间进行物质交换的通透性屏障。
:::

:::concept{term="先问这张网密不密：代谢高就密，代谢低就疏"}
毛细血管不是平均铺在全身的。心脏、肝、肺、肾、骨骼肌要持续交换，网很密；骨、肌腱、韧带、平滑肌代谢低，网稀疏。看见铺片上的细管网，先问所在器官的代谢强度，再问内皮是连续、有孔还是血窦。把“分布最广”听成“密度处处一样”，肝血窦和肌腱毛细血管会被写成同一张网。
:::

:::compare{title="毛细血管网疏密与器官代谢"}
| 器官类型 | 例子 | 毛细血管网 |
|----------|------|------------|
| 代谢旺盛 | 心脏、肝、肺、肾、骨骼肌 | 很密 |
| 代谢较低 | 骨、肌腱、韧带、平滑肌 | 稀疏 |
:::

## （一）毛细血管的基本结构

毛细血管的管径一般为 $6\sim 8\,\mu\mathrm{m}$，容许 1 个红细胞通过，但在不同组织器官和不同功能状态下会有不同。毛细血管壁由内皮细胞及其基膜和周细胞（pericyte）构成。横切面上，毛细血管一般由 $1\sim 2$ 个内皮细胞环绕构成，内皮细胞富含质膜小泡，基膜只有基板。周细胞位于内皮细胞与基板之间，散在分布，细胞扁而有突起，纵向包绕在内皮细胞周围。周细胞的细胞核呈卵圆形或肾形，一端的细胞质内可见高尔基复合体、粗面内质网、线粒体等细胞器，类似于成纤维细胞或间充质细胞，但周细胞的细胞质含较多微丝，散在或成束附着于细胞膜内侧的密体，具有收缩功能，可调节毛细血管血流。毛细血管受损时，周细胞可分化为内皮细胞、平滑肌纤维和成纤维细胞。

:::definition{label="毛细血管壁"}
毛细血管壁由内皮细胞及其基膜和周细胞（pericyte）构成。横切面一般由 $1\sim 2$ 个内皮细胞环绕；内皮富含质膜小泡；基膜只有基板。
:::

:::definition{label="周细胞"}
周细胞（pericyte）位于内皮细胞与基板之间，散在分布。细胞扁而有突起，纵向包绕内皮；核卵圆或肾形。一端胞质含高尔基复合体、粗面内质网、线粒体，类似成纤维细胞或间充质细胞；胞质微丝较多，附着于膜内侧密体，可收缩以调节毛细血管血流。受损时可分化为内皮细胞、平滑肌纤维和成纤维细胞。
:::

:::pitfall{label="周细胞夹在内皮与基板之间，不是外膜成纤维细胞"}
周细胞的细胞器像成纤维细胞，功能上却既能收缩又能分化。位置必须写准：内皮与基板之间，纵向包绕。不要把它算进外膜，也不要因为“可分化为成纤维细胞”就把它直接叫作成纤维细胞。毛细淋巴管无周细胞，这是和毛细血管对照时的一条硬界限。
:::

:::note{label="基膜在毛细血管只有基板"}
教材写“基膜只有基板”，是提醒这里没有明显的网板层。连续毛细血管和有孔毛细血管的基膜完整；血窦的基膜不连续或阙如，那是下一小节的分类账，不要提前写成“所有毛细血管基膜都完整”。
:::

## （二）毛细血管的分类

根据透射电镜下内皮细胞的结构特征，毛细血管可分为 3 类（图 9-12）。

:::definition{label="毛细血管的分类依据"}
根据透射电镜下内皮细胞的结构特征，毛细血管分为连续毛细血管、有孔毛细血管和血窦（窦状毛细血管、不连续毛细血管）3 类。光镜只能看见细管和红细胞，分型必须问内皮有没有窗孔、细胞之间有没有大间隙、基膜完不完整。
:::

**1. 连续毛细血管** 连续毛细血管（continuous capillary）内皮细胞之间有紧密连接，基膜完整；细胞质含大量质膜小泡，是血液和组织之间进行物质交换的主要方式。连续毛细血管主要分布于结缔组织、肌组织、外分泌腺、神经系统、胸腺和肺等，参与了屏障性结构的形成。

:::definition{label="连续毛细血管"}
连续毛细血管（continuous capillary）内皮细胞之间有紧密连接，基膜完整；胞质含大量质膜小泡，物质交换主要经质膜小泡进行。主要分布于结缔组织、肌组织、外分泌腺、神经系统、胸腺和肺等，参与屏障性结构的形成。
:::

**2. 有孔毛细血管** 有孔毛细血管（fenestrated capillary）内皮细胞之间也有紧密连接，基膜也完整，但在内皮细胞不含细胞核的部分极薄，有许多贯穿细胞质的内皮窗孔，窗孔直径 $60\sim 80\,\mathrm{nm}$，一般有厚 $4\sim 6\,\mathrm{nm}$ 的隔膜封闭。内皮窗孔有利于血管内外的中、小分子物质交换。有孔毛细血管主要分布于胃肠黏膜、某些内分泌腺和肾血管球等。

:::definition{label="有孔毛细血管"}
有孔毛细血管（fenestrated capillary）内皮细胞之间有紧密连接，基膜完整；无核部分极薄，有贯穿胞质的内皮窗孔，直径 $60\sim 80\,\mathrm{nm}$，一般有厚 $4\sim 6\,\mathrm{nm}$ 的隔膜封闭。利于中、小分子物质交换。主要分布于胃肠黏膜、某些内分泌腺和肾血管球等。
:::

:::definition{label="内皮窗孔"}
内皮窗孔是有孔毛细血管无核区贯穿胞质的孔，直径 $60\sim 80\,\mathrm{nm}$，一般有厚 $4\sim 6\,\mathrm{nm}$ 的隔膜封闭。它不是血窦那种细胞之间的大间隙。
:::

**3. 血窦** 血窦（sinusoid）也称窦状毛细血管（sinusoid capillary）或不连续毛细血管（discontinuous capillary），管腔较大，直径可达 $40\,\mu\mathrm{m}$，形状不规则。内皮细胞之间的间隙较大，有利于大分子物质甚至血细胞出入血管。血窦主要分布于肝、脾、骨髓和某些内分泌腺，不同器官内的血窦差别较大。

:::definition{label="血窦"}
血窦（sinusoid）也称窦状毛细血管或不连续毛细血管（discontinuous capillary）。管腔较大，直径可达 $40\,\mu\mathrm{m}$，形状不规则；内皮细胞之间间隙较大，利于大分子物质甚至血细胞出入。主要分布于肝、脾、骨髓和某些内分泌腺，不同器官内差别较大。
:::

:::compare{title="连续毛细血管、有孔毛细血管与血窦"}
| 项目 | 连续毛细血管 | 有孔毛细血管 | 血窦（不连续毛细血管） |
|------|--------------|--------------|------------------------|
| 英文 | continuous capillary | fenestrated capillary | sinusoid, discontinuous capillary |
| 内皮连接 | 紧密连接 | 也有紧密连接 | 细胞间隙较大 |
| 内皮本身 | 连续；大量质膜小泡 | 无核区极薄，窗孔 $60\sim 80\,\mathrm{nm}$，隔膜 $4\sim 6\,\mathrm{nm}$ | 不连续；腔大而不规则，直径可达 $40\,\mu\mathrm{m}$ |
| 基膜 | 完整 | 完整 | 不连续或因器官而异 |
| 交换方式 | 主要经质膜小泡 | 窗孔利于中、小分子 | 大分子甚至血细胞可出入 |
| 分布 | 结缔组织、肌组织、外分泌腺、神经系统、胸腺、肺 | 胃肠黏膜、某些内分泌腺、肾血管球 | 肝、脾、骨髓和某些内分泌腺 |
| 与屏障 | 参与屏障性结构 | 利于滤过和分泌物入血 | 利于血细胞穿越（如骨髓、脾） |
:::

:::pitfall{label="血窦不是有孔毛细血管的加大号，窗孔≠细胞间隙"}
有孔毛细血管的内皮细胞之间仍有紧密连接，基膜也完整；“孔”开在无核区的胞质上，多数还盖着 $4\sim 6\,\mathrm{nm}$ 隔膜，只放行中、小分子。血窦的通道是内皮细胞之间的大间隙，管腔可以到 $40\,\mu\mathrm{m}$，大分子甚至血细胞都能进出。某些内分泌腺两种都有，不能看见“内分泌”三个字就一律写成有孔。把血窦背成“窗孔更大的有孔毛细血管”，肝、脾、骨髓的血细胞出入账会做错。
:::

:::concept{term="先问通道开在细胞上还是开在细胞之间"}
连续型：细胞连成完整筒，物质主要坐质膜小泡过细胞。有孔型：筒还在，无核区开窗。血窦：筒本身就不完整，细胞之间留大缝。三种的差别不在管径口号，而在内皮这张膜怎么打孔。肾血管球是有孔（滤过中、小分子），肝血窦是血窦（大分子和细胞），不要因为都会“漏”就并成一类。
:::

## （三）毛细血管的基本功能

毛细血管是血液与组织细胞之间进行物质交换的通透性屏障，决定其通透性的主要结构是内皮细胞，基膜也起一定作用。在不同器官和不同功能状态下，毛细血管的通透性差异很大。

:::definition{label="毛细血管的通透性屏障"}
毛细血管是血液与组织细胞之间进行物质交换的通透性屏障。决定通透性的主要结构是内皮细胞，基膜也起一定作用。不同器官、不同功能状态下通透性差异很大。
:::

:::insight{label="通透性写在内皮上，周细胞只调节血流"}
物质过不过得去，先问内皮：紧密连接有多紧、有没有窗孔、细胞间隙有多大、质膜小泡多不多。基膜帮一把，但不是主角。周细胞的微丝管的是管径和血流，损伤时才分化补内皮、平滑肌或成纤维细胞。把通透性记在周细胞上，或把三类毛细血管的差别写成“周细胞多少不同”，分类依据就离开了电镜下的内皮。
:::

:::cause-effect{title="内皮结构怎样写成三类不同的通透性"}
- 因：内皮紧密连接完整且无窗孔，物质主要经质膜小泡转运
- 果：连续毛细血管参与屏障（神经、胸腺、肺等）
- 因：无核区开窗（$60\sim 80\,\mathrm{nm}$）但仍有紧密连接和完整基膜
- 果：有孔毛细血管利于中、小分子交换（胃肠黏膜、肾血管球、内分泌腺）
- 因：内皮细胞间隙大、管腔不规则
- 果：血窦允许大分子甚至血细胞出入（肝、脾、骨髓）
:::

:::keypoint{label="毛细血管先立内皮-基膜-周细胞，再按内皮分成三类"}
- 管径一般 $6\sim 8\,\mu\mathrm{m}$，容 1 个红细胞；横切 $1\sim 2$ 个内皮细胞；基膜只有基板。
- 网密：心、肝、肺、肾、骨骼肌；网疏：骨、肌腱、韧带、平滑肌。
- 周细胞在内皮与基板之间，可收缩，受损可分化为内皮、平滑肌、成纤维细胞。
- 连续：紧密连接 + 完整基膜 + 大量质膜小泡；屏障。
- 有孔：紧密连接 + 完整基膜 + 窗孔 $60\sim 80\,\mathrm{nm}$（隔膜 $4\sim 6\,\mathrm{nm}$）；中、小分子。
- 血窦：腔可达 $40\,\mu\mathrm{m}$，细胞间隙大；大分子甚至血细胞；肝、脾、骨髓。
- 通透性主要取决于内皮，基膜辅助。
:::
