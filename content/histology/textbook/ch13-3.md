# 三、肾上腺

肾上腺（adrenal gland）表面包以结缔组织被膜，少量结缔组织伴随血管和神经伸入腺实质内。肾上腺实质由周边的皮质和中央的髓质两部分构成（图 13-5）。皮质走类固醇激素账，髓质走含氮的儿茶酚胺账；同一腺体里两套细胞的超微结构不能并成一种。

:::definition{label="肾上腺"}
肾上腺（adrenal gland）表面包结缔组织被膜，少量结缔组织伴随血管和神经伸入实质。实质由周边的皮质和中央的髓质两部分构成。
:::

:::concept{term="先问这是球状带、束状带还是网状带，激素是醛固酮还是皮质醇"}
肾上腺切片从被膜往里数：球状带薄、细胞成团；束状带最厚、细胞成索、胞质泡沫状；网状带细胞索吻合成网；再往里是髓质和中央静脉。球状带出盐皮质激素（醛固酮），束状带出糖皮质激素（皮质醇），网状带主要出雄激素。把“皮质激素”听成只有皮质醇，球状带保钠排钾那一本账会做丢。
:::

:::compare{title="肾上腺皮质与髓质"}
| 项目 | 皮质 | 髓质 |
|------|------|------|
| 位置 | 周边，约占体积 $80\%$ | 中央 |
| 激素化学 | 类固醇 | 儿茶酚胺（含氮） |
| 细胞超微 | 滑面内质网、管状嵴线粒体、脂滴、无分泌颗粒 | 高电子密度分泌颗粒（嗜铬颗粒） |
| 染色 / 固定 | 束状带泡沫状浅染 | 铬盐固定后胞质见黄褐色嗜铬颗粒 |
| 支配与调节 | 腺垂体 ACTH 主要管束状带；血管带来的皮质激素还影响髓质 | 交感神经节前纤维支配 |
:::

:::pitfall{label="皮质是类固醇细胞，不要把束状带空泡写成含氮分泌颗粒被溶解"}
束状带 HE 泡沫状，是脂滴被溶剂抽走后的空泡，原料账，不是颗粒排空。髓质才有嗜铬颗粒。把皮质写成“有分泌颗粒的含氮腺”，管状嵴线粒体和醛固酮、皮质醇那一套类固醇通式会整层错位。
:::

## （一）皮质

皮质约占肾上腺体积的 $80\%$，由皮质细胞、血窦和少量结缔组织组成。根据皮质细胞的形态和排列特征，可将皮质分为 3 个带，即球状带、束状带和网状带，三者间无明显界限（图 13-5）。

:::definition{label="肾上腺皮质"}
皮质约占肾上腺体积的 $80\%$，由皮质细胞、血窦和少量结缔组织组成。按细胞形态和排列分为球状带、束状带和网状带，三者间无明显界限。
:::

:::note{label="三带由外向内"}
被膜 → 球状带（薄，球团）→ 束状带（最厚，细胞索）→ 网状带（最内，吻合成网）→ 髓质。分带靠排列和细胞形态，不是靠一条结缔组织隔膜。
:::

### 1. 球状带

球状带（zona glomerulosa）位于被膜下方，较薄。细胞聚集成许多球团，细胞较小，呈锥形，核小染色深，细胞质较少，含少量脂滴。球状带细胞分泌盐皮质激素（mineralocorticoid），主要是醛固酮（aldosterone），能促进肾远曲小管和集合管重吸收 $\mathrm{Na}^{+}$ 及排出 $\mathrm{K}^{+}$，同时也刺激胃黏膜吸收 $\mathrm{Na}^{+}$，使血 $\mathrm{Na}^{+}$ 浓度升高，$\mathrm{K}^{+}$ 浓度降低，维持血容量于正常水平。

:::definition{label="球状带"}
球状带（zona glomerulosa）位于被膜下方，较薄。细胞聚集成许多球团；细胞较小、呈锥形，核小染色深，胞质较少，含少量脂滴。
:::

:::definition{label="盐皮质激素"}
球状带细胞分泌盐皮质激素（mineralocorticoid），主要是醛固酮（aldosterone）。
:::

:::definition{label="醛固酮"}
醛固酮（aldosterone）促进肾远曲小管和集合管重吸收 $\mathrm{Na}^{+}$ 及排出 $\mathrm{K}^{+}$，并刺激胃黏膜吸收 $\mathrm{Na}^{+}$，使血 $\mathrm{Na}^{+}$ 升高、$\mathrm{K}^{+}$ 降低，维持血容量于正常水平。
:::

:::pitfall{label="球状带出醛固酮，不是皮质醇"}
皮质醇是束状带的糖皮质激素。球状带管的是钠、钾和血容量。把球状带听成“分泌皮质醇的那一层”，盐皮质激素、糖皮质激素和 ACTH 主要作用于束状带这三本账会同时错位。被膜下方那一层薄薄的球团，身份证是醛固酮。
:::

### 2. 束状带

束状带（zona fasciculata）是皮质中最厚的部分。束状带细胞较大，呈多边形，排列成单行或双行的细胞索。细胞核圆形，较大，着色浅。细胞质内含大量脂滴，在 HE 染色切片上因脂滴被溶解，故细胞质呈泡沫状或空泡状而染色浅。束状带细胞分泌糖皮质激素（glucocorticoid），主要为皮质醇（cortisol）。糖皮质激素可促使蛋白质及脂肪分解并转变成糖，还有抑制免疫应答及抗炎症等作用。

:::definition{label="束状带"}
束状带（zona fasciculata）是皮质中最厚的部分。细胞较大、多边形，排成单行或双行细胞索；核圆形较大、着色浅；胞质含大量脂滴，HE 上脂滴被溶解而呈泡沫状或空泡状、染色浅。
:::

:::definition{label="糖皮质激素"}
束状带细胞分泌糖皮质激素（glucocorticoid），主要为皮质醇（cortisol）。可促使蛋白质及脂肪分解并转变成糖，还有抑制免疫应答及抗炎症等作用。腺垂体 ACTH 主要促进束状带细胞分泌糖皮质激素。
:::

:::definition{label="皮质醇"}
皮质醇（cortisol）是束状带分泌的主要糖皮质激素，不是球状带的产物。
:::

:::insight{label="束状带泡沫状浅染，是脂滴被抽走，不是细胞坏死"}
类固醇原料是脂滴。制片溶剂把脂滴溶掉，胞质就变成空泡。电镜下束状带细胞最能代表类固醇分泌细胞：丰富滑面内质网、管状嵴线粒体、脂滴、无分泌颗粒。光镜空泡和电镜脂滴是同一本原料账。
:::

### 3. 网状带

网状带（zona reticularis）位于皮质最内层，细胞索相互吻合成网。网状带细胞较小，核小、着色深，细胞质呈嗜酸性，内含较多脂褐素和少量脂滴。网状带细胞主要分泌雄激素（androgen），也分泌少量雌激素和糖皮质激素。

:::definition{label="网状带"}
网状带（zona reticularis）位于皮质最内层，细胞索相互吻合成网。细胞较小，核小着色深，胞质嗜酸性，含较多脂褐素和少量脂滴。
:::

:::definition{label="网状带的激素"}
网状带细胞主要分泌雄激素（androgen），也分泌少量雌激素和糖皮质激素。
:::

:::pitfall{label="网状带主要出雄激素，不要只把它写成糖皮质激素的内层"}
束状带已经出皮质醇；网状带可以兼出少量糖皮质激素，主业却是雄激素，并有少量雌激素。脂褐素多、脂滴少、胞质偏嗜酸，是和束状带泡沫浅染对看的形态差。把三带都听成“分泌皮质醇”，性激素那一本皮质账会做丢。
:::

肾上腺皮质细胞分泌的激素均属类固醇激素且都具有类固醇激素分泌细胞的超微结构特点，尤以束状带细胞最为典型（图 13-6）。

:::definition{label="皮质细胞的超微通式"}
三带皮质细胞分泌的都是类固醇激素，都具有类固醇激素分泌细胞的超微结构：丰富滑面内质网，线粒体较多且嵴多呈管状，含脂滴，无分泌颗粒。以束状带细胞最为典型。
:::

:::compare{title="皮质三带的激素与形态"}
| 项目 | 球状带 | 束状带 | 网状带 |
|------|--------|--------|--------|
| 英文 | zona glomerulosa | zona fasciculata | zona reticularis |
| 位置 | 被膜下，较薄 | 中层，最厚 | 最内层，邻髓质 |
| 排列 | 细胞聚成球团 | 单行或双行细胞索 | 细胞索吻合成网 |
| 细胞 | 较小，锥形；核小深染；胞质少，少量脂滴 | 较大多边形；核大浅染；大量脂滴，HE 泡沫状 | 较小；核小深染；胞质嗜酸，较多脂褐素、少量脂滴 |
| 主要激素 | 盐皮质激素（醛固酮） | 糖皮质激素（皮质醇） | 雄激素（兼少量雌激素和糖皮质激素） |
| 主要效应 | 远曲小管和集合管保 $\mathrm{Na}^{+}$ 排 $\mathrm{K}^{+}$；胃黏膜吸 $\mathrm{Na}^{+}$；维持血容量 | 蛋白质及脂肪分解成糖；抑制免疫、抗炎 | 雄激素为主 |
:::

## （二）髓质

髓质主要由排列成索状或团状的髓质细胞组成，其间为血窦和少量结缔组织，髓质中央有中央静脉（见图 13-5）。髓质细胞呈多边形，核圆着色浅，细胞质嗜碱性（图 13-7）。如用含铬盐的固定液固定标本，细胞质内可见黄褐色的嗜铬颗粒，因而髓质细胞又称嗜铬细胞（chromaffin cell）。此外，髓质内还有少量交感神经节细胞，胞体较大，散在分布（图 13-7）。

:::definition{label="肾上腺髓质"}
髓质主要由索状或团状的髓质细胞组成，其间为血窦和少量结缔组织，中央有中央静脉。
:::

:::definition{label="嗜铬细胞"}
髓质细胞呈多边形，核圆着色浅，胞质嗜碱性。用含铬盐的固定液固定后，胞质内可见黄褐色嗜铬颗粒，故称嗜铬细胞（chromaffin cell）。
:::

:::definition{label="髓质内的交感神经节细胞"}
髓质内还有少量交感神经节细胞，胞体较大，散在分布。不要把这些大细胞当成另一类嗜铬细胞。
:::

电镜下，嗜铬细胞最显著的特征是细胞质内含许多电子密度高的分泌颗粒。根据颗粒所含物质的差别，嗜铬细胞分为两种。一种为肾上腺素细胞（epinephrine-secreting cell），颗粒内含肾上腺素（epinephrine），此种细胞数量多，占人肾上腺髓质细胞的 $80\%$ 以上；另一种为去甲肾上腺素细胞（norepinephrine-secreting cell），颗粒内含去甲肾上腺素（norepinephrine）。肾上腺素和去甲肾上腺素均为儿茶酚胺类物质，它们与嗜铬颗粒蛋白等组成复合物贮存在颗粒内。嗜铬细胞的分泌活动受交感神经节前纤维支配。肾上腺素使心率加快、心脏和骨骼肌的血管扩张；去甲肾上腺素使血压增高，心脏、脑和骨骼肌内的血流加速。

:::definition{label="肾上腺素细胞"}
肾上腺素细胞（epinephrine-secreting cell）的颗粒内含肾上腺素（epinephrine）。数量多，占人肾上腺髓质细胞的 $80\%$ 以上。
:::

:::definition{label="去甲肾上腺素细胞"}
去甲肾上腺素细胞（norepinephrine-secreting cell）的颗粒内含去甲肾上腺素（norepinephrine），数量较少。
:::

:::definition{label="儿茶酚胺的贮存"}
肾上腺素和去甲肾上腺素均为儿茶酚胺类物质，与嗜铬颗粒蛋白等组成复合物贮存在嗜铬颗粒内。分泌活动受交感神经节前纤维支配。
:::

:::compare{title="肾上腺素与去甲肾上腺素"}
| 项目 | 肾上腺素 | 去甲肾上腺素 |
|------|----------|--------------|
| 细胞 | 肾上腺素细胞（$>80\%$） | 去甲肾上腺素细胞（较少） |
| 化学 | 儿茶酚胺 | 儿茶酚胺 |
| 贮存 | 与嗜铬颗粒蛋白等成复合物，在嗜铬颗粒内 | 同左 |
| 效应 | 心率加快；心脏和骨骼肌的血管扩张 | 血压增高；心脏、脑和骨骼肌内血流加速 |
:::

:::insight{label="嗜铬细胞是改了行的交感神经节后成分"}
交感神经节前纤维直接支配嗜铬细胞，等于把节后神经元改写成内分泌细胞，把递质改写成入血的激素。所以髓质里还能散在少量真正的交感神经节细胞。把髓质听成“皮质最内层的第四带”，节前纤维支配和儿茶酚胺颗粒两本账都会写到类固醇细胞上。
:::

:::pitfall{label="铬盐固定才看到嗜铬颗粒，不要在普通 HE 里找黄褐色颗粒当身份证"}
HE 上髓质细胞胞质嗜碱、核圆浅染；黄褐色嗜铬颗粒是铬盐固定后的反应。普通切片里把任何棕黄颗粒都叫嗜铬，会和脂褐素、含铁血黄素搅在一起。电镜身份证是高电子密度分泌颗粒。
:::

## （三）肾上腺的血管分布

肾上腺动脉进入被膜后，大部分分支进入皮质，形成与髓质的血窦相连续的窦状毛细血管网。少数小动脉分支穿过皮质直接进入髓质，分支形成血窦（见图 13-7）。髓质的小静脉汇合成一条中央静脉（见图 13-5），经肾上腺静脉离开肾上腺。肾上腺皮质的血液流经髓质时，所含较高浓度的糖皮质激素可增强髓质嗜铬细胞苯乙醇胺-$N$-甲基转移酶的活性，促进去甲肾上腺素甲基化为肾上腺素，其所在细胞成为肾上腺素细胞，以致髓质肾上腺素细胞远多于去甲肾上腺素细胞。由此可见，由于肾上腺血管分布的特点，肾上腺皮质对髓质细胞激素的生成有很大的影响。

:::definition{label="肾上腺的血管路径"}
肾上腺动脉入被膜后，大部分分支进入皮质，形成与髓质血窦相连续的窦状毛细血管网；少数小动脉穿过皮质直接进入髓质形成血窦。髓质小静脉汇成一条中央静脉，经肾上腺静脉离开。
:::

:::definition{label="苯乙醇胺-N-甲基转移酶"}
苯乙醇胺-$N$-甲基转移酶（PNMT）的活性可被流经髓质的高浓度糖皮质激素增强，从而促进去甲肾上腺素甲基化为肾上腺素，使该细胞成为肾上腺素细胞。
:::

:::note{label="皮质血流怎样改写髓质细胞表型"}
皮质血窦 → 髓质血窦，血里带着高浓度糖皮质激素 → 增强 PNMT → 去甲肾上腺素甲基化为肾上腺素 → 肾上腺素细胞占 $80\%$ 以上。少数直达髓质的小动脉不经过这条皮质激素浴，对应那一小部分去甲肾上腺素细胞。血管走行不是附属解剖，而是激素生成的条件。
:::

:::pitfall{label="肾上腺素细胞占多数，是因为皮质血流增强了 PNMT，不是因为球状带分泌肾上腺素"}
肾上腺素是髓质嗜铬细胞的产物。皮质只是用糖皮质激素给髓质提供甲基化条件。把肾上腺素写成束状带或球状带激素，儿茶酚胺和类固醇又并成一本账。
:::

:::keypoint{label="肾上腺先立皮质三带激素，再立髓质嗜铬细胞和血管"}
- 皮质约 $80\%$：球状带醛固酮、束状带皮质醇、网状带雄激素为主；均为类固醇细胞。
- 球状带保 $\mathrm{Na}^{+}$ 排 $\mathrm{K}^{+}$ 维持血容量；束状带最厚、泡沫状；网状带含脂褐素。
- 髓质嗜铬细胞：铬盐固定见嗜铬颗粒；肾上腺素细胞 $>80\%$，去甲肾上腺素细胞较少；受交感节前纤维支配。
- 皮质血流经髓质，糖皮质激素增强 PNMT，使肾上腺素细胞远多于去甲肾上腺素细胞。

:::memory{label="本节必背要点"}
- [ ] 肾上腺表面包结缔组织被膜，少量结缔组织伴随血管和神经伸入实质。
- [ ] 实质由周边皮质和中央髓质构成；皮质约占体积 $80\%$。
- [ ] 皮质由皮质细胞、血窦和少量结缔组织组成，分为球状带、束状带和网状带，三者间无明显界限。
- [ ] 球状带位于被膜下方，较薄；细胞聚成球团，较小呈锥形，核小深染，胞质少，含少量脂滴。
- [ ] 球状带细胞分泌盐皮质激素，主要是醛固酮。
- [ ] 醛固酮促进肾远曲小管和集合管重吸收 $\mathrm{Na}^{+}$、排出 $\mathrm{K}^{+}$，并刺激胃黏膜吸收 $\mathrm{Na}^{+}$，使血 $\mathrm{Na}^{+}$ 升高、$\mathrm{K}^{+}$ 降低，维持血容量。
- [ ] 束状带是皮质最厚部分；细胞较大多边形，单行或双行细胞索；核圆较大、着色浅。
- [ ] 束状带胞质含大量脂滴，HE 上脂滴被溶解而呈泡沫状或空泡状、染色浅。
- [ ] 束状带细胞分泌糖皮质激素，主要为皮质醇；促使蛋白质及脂肪分解成糖，并抑制免疫应答、抗炎症。
- [ ] 网状带位于皮质最内层，细胞索吻合成网；细胞较小，核小深染，胞质嗜酸性，含较多脂褐素和少量脂滴。
- [ ] 网状带细胞主要分泌雄激素，也分泌少量雌激素和糖皮质激素。
- [ ] 皮质激素均属类固醇，细胞具类固醇分泌细胞超微特点，尤以束状带最为典型。
- [ ] 髓质由索状或团状髓质细胞组成，间有血窦和少量结缔组织，中央有中央静脉。
- [ ] 髓质细胞多边形，核圆浅染，胞质嗜碱性；铬盐固定后胞质内黄褐色嗜铬颗粒，故称嗜铬细胞。
- [ ] 髓质内还有少量胞体较大、散在的交感神经节细胞。
- [ ] 嗜铬细胞胞质含许多高电子密度分泌颗粒。
- [ ] 肾上腺素细胞数量多，占人肾上腺髓质细胞 $80\%$ 以上，颗粒含肾上腺素。
- [ ] 去甲肾上腺素细胞颗粒含去甲肾上腺素，数量较少。
- [ ] 肾上腺素和去甲肾上腺素为儿茶酚胺，与嗜铬颗粒蛋白等成复合物贮于颗粒内。
- [ ] 嗜铬细胞分泌受交感神经节前纤维支配。
- [ ] 肾上腺素使心率加快、心脏和骨骼肌血管扩张；去甲肾上腺素使血压增高，心脏、脑和骨骼肌血流加速。
- [ ] 肾上腺动脉入被膜后，大部分分支入皮质，形成与髓质血窦连续的窦状毛细血管网；少数小动脉穿过皮质直达髓质成血窦。
- [ ] 髓质小静脉汇成一条中央静脉，经肾上腺静脉离开。
- [ ] 皮质血液流经髓质时，高浓度糖皮质激素增强苯乙醇胺-$N$-甲基转移酶活性，促进去甲肾上腺素甲基化为肾上腺素，故肾上腺素细胞远多于去甲肾上腺素细胞。
- [ ] 由于血管分布特点，肾上腺皮质对髓质细胞激素的生成有很大影响。
