# 四、三胚层的分化和胚体的形成

第 $4\sim 8$ 周，三个胚层逐渐分化，形成各种器官的原基（进一步的演化将在后面各章详述）。与此同时，扁平的胚盘并不是就地铺成人体：边缘向腹侧卷折，头褶、尾褶和左右侧褶把盘收成头大尾小的圆柱形胚体。本节先把外胚层（神经管、神经嵴、表面外胚层）、中胚层（轴旁、间介、侧中胚层）和内胚层的去向摊开，再写卷折如何把外胚层包在外表、把内胚层卷入成原始消化管。胎膜和胎盘下一节再写。

:::definition{label="三胚层分化的时间窗"}
第 $4\sim 8$ 周，外胚层、中胚层和内胚层逐渐分化形成各种器官的原基。本节只写原基的来源户头；各系统如何长成器官，放到后面各章。
:::

:::concept{term="先问这层将来是表皮还是神经管，再问中胚层是轴旁、间介还是侧板"}
看见“三胚层分化”，不要写成“外胚层变皮肤、中胚层变肉、内胚层变肠”一句了事。外胚层先切开神经外胚层和表面外胚层：背侧中线增厚的那一块走神经板→神经管，其余走表皮及其附属器。中胚层先成间充质，再由内向外分成轴旁（体节）、间介（泌尿生殖）、侧中胚层（胚内体腔及体壁/脏壁）。内胚层要等卷折把它包进胚体，才叫原始消化管。三本账对错户头，无脑畸形、髓核和心包腔都会写串。
:::

## （一）三胚层的分化

### 1. 外胚层的分化

脊索形成后，诱导其背侧中线的外胚层增厚呈板状，称神经板（neural plate）。构成神经板的这部分外胚层也称神经外胚层（neural ectoderm），而其余部分常称表面外胚层。神经板随脊索的生长而增长，且头侧宽于尾侧。继而神经板中央沿长轴向脊索方向凹陷，形成神经沟（neural groove），沟两侧边缘隆起称神经褶（neural fold）。两侧神经褶在神经沟中段靠拢而融合，并向头尾两端进展，最后在头尾两端各有一开口，分别称前神经孔和后神经孔，它们在第 $4$ 周闭合，使神经沟完全闭合为神经管（neural tube）。神经管两侧的表面外胚层在管的背侧靠拢并融合，使神经管位居于表面外胚层的深面（图 21-14～图 21-17）。神经管是中枢神经系统的原基，将分化为脑和脊髓以及松果体、神经垂体和视网膜等。如果前、后神经孔未闭合，将会分别导致无脑畸形和脊髓裂（见第 $26$ 章）。

:::definition{label="神经板"}
神经板（neural plate）是脊索诱导其背侧中线外胚层增厚形成的板状结构。它随脊索生长而增长，头侧宽于尾侧。
:::

:::definition{label="神经外胚层"}
神经外胚层（neural ectoderm）就是构成神经板的那一部分外胚层。它不是表面外胚层，也不等于已经闭合的神经管。
:::

:::definition{label="表面外胚层"}
表面外胚层是神经板以外的其余外胚层。神经管闭合后，它在管的背侧靠拢融合，把神经管盖到深面；本身将分化为表皮及其附属器等。
:::

:::definition{label="神经沟与神经褶"}
神经沟（neural groove）是神经板中央沿长轴向脊索方向凹陷形成的沟。沟两侧边缘隆起称神经褶（neural fold）。两侧神经褶先在神经沟中段靠拢融合，再向头尾两端进展。
:::

:::definition{label="前神经孔与后神经孔"}
神经褶融合向头尾推进时，头尾两端暂时各留一个开口，分别称前神经孔和后神经孔。二者在第 $4$ 周闭合，神经沟才完全闭合为神经管。
:::

:::definition{label="神经管"}
神经管（neural tube）由神经沟完全闭合而成，是中枢神经系统的原基。将分化为脑、脊髓，以及松果体、神经垂体和视网膜等。它位于表面外胚层的深面，不是表皮。
:::

:::compare{title="神经板、神经沟、神经褶与神经管"}
| 项目 | 神经板 | 神经沟 | 神经褶 | 神经管 |
|------|--------|--------|--------|--------|
| 形态 | 背侧中线增厚的板 | 板中央沿长轴凹陷成沟 | 沟两侧隆起的边缘 | 沟完全闭合后的管 |
| 何时 | 脊索诱导之后 | 板中央凹陷时 | 与神经沟同时 | 前、后神经孔第 $4$ 周闭合之后 |
| 融合次序 | — | — | 先在神经沟中段靠拢，再向头尾两端进展 | 中段先闭，头尾孔最后闭 |
| 不要听成 | 已经是脑和脊髓 | 已经闭合 | 表面外胚层的皱褶 | 周围神经的原基 |
:::

:::cause-effect{title="前、后神经孔未闭分别走向哪种畸形"}
- 因：前神经孔在第 $4$ 周未能闭合
- 果：无脑畸形
- 因：后神经孔在第 $4$ 周未能闭合
- 果：脊髓裂
- 制约：神经管是中枢神经系统原基，孔未闭不是“皮肤缺一块”那么简单，详见第 $26$ 章
:::

:::pitfall{label="前神经孔未闭是无脑，后神经孔未闭是脊髓裂，不要对调"}
闭合的时间都在第 $4$ 周，户头却按头尾分开：头端的前神经孔对脑，尾端的后神经孔对脊髓。把无脑写成“后神经孔的事”，或把脊髓裂写成“前神经孔的事”，畸形账会从头写到尾。
:::

:::timeline{period="从神经板到神经管闭合"}
- **脊索诱导** 背侧中线外胚层增厚为神经板（神经外胚层）；其余为表面外胚层；头侧宽于尾侧
- **凹陷** 神经板中央沿长轴向脊索方向凹陷，形成神经沟；两侧隆起为神经褶
- **中段先融合** 两侧神经褶在神经沟中段靠拢融合，再向头尾两端进展
- **暂时留孔** 头端为前神经孔，尾端为后神经孔
- **第4周闭合** 前、后神经孔闭合，神经沟完全成为神经管
- **表面外胚层盖住** 神经管两侧的表面外胚层在管背侧靠拢融合，神经管居于其深面
:::

在神经沟闭合为神经管的过程中，神经板外侧缘的细胞也随之进入神经管壁的背侧，并很快从管壁迁移出来，形成位于神经管背外侧的两条纵行细胞索，称神经嵴（neural crest）（图 21-18）。神经嵴是周围神经系统的原基，将分化为脑神经节、脊神经节、自主神经节及周围神经；部分细胞还迁入肾上腺原基，分化为髓质嗜铬细胞。另外，部分神经嵴细胞迁入表皮，分化为黑素细胞；在头端的神经嵴细胞还参与颅面部骨骼和结缔组织的形成。

表面外胚层将分化为皮肤的表皮及其附属器，以及牙釉质、角膜上皮、晶状体、内耳膜迷路、腺垂体、唾液腺、口腔、鼻腔及肛管下段的上皮等。

:::definition{label="神经嵴"}
神经嵴（neural crest）是神经沟闭合为神经管时，神经板外侧缘细胞进入神经管壁背侧、再迁出，在神经管背外侧形成的两条纵行细胞索。它是周围神经系统的原基，不是中枢神经系统的原基。
:::

:::definition{label="神经嵴的去向"}
神经嵴将分化为脑神经节、脊神经节、自主神经节及周围神经；部分细胞迁入肾上腺原基，分化为髓质嗜铬细胞；部分迁入表皮，分化为黑素细胞；头端的神经嵴细胞还参与颅面部骨骼和结缔组织的形成。
:::

:::definition{label="表面外胚层的去向"}
表面外胚层分化为：皮肤的表皮及其附属器；牙釉质；角膜上皮；晶状体；内耳膜迷路；腺垂体；唾液腺；口腔、鼻腔及肛管下段的上皮。
:::

::figure{src="/images/histology/textbook/p0233_02.png" caption="图21-18 神经嵴的发生和细胞迁移模式图。A. 神经嵴细胞在神经褶处形成；B. 神经管闭合后神经嵴细胞开始迁移；C. 神经嵴分化为不同的结构（背根神经节、交感神经节、肾上腺、主动脉前节、肠神经节等）。" alt="三图：A 神经褶处出现神经嵴，B 神经管闭合后细胞向外迁移，C 横切示背根神经节、交感神经节、肾上腺、肠神经节等去向"}

:::concept{term="先问是中枢原基还是周围原基，再问垂体前后叶分别跟谁走"}
外胚层里有三本账。神经管走中枢：脑、脊髓、松果体、神经垂体、视网膜。神经嵴走周围：脑/脊/自主神经节及周围神经，外加肾上腺髓质嗜铬细胞、表皮黑素细胞和头端颅面骨骼结缔组织。表面外胚层走被覆和腺上皮：表皮及附属器、牙釉质、角膜上皮、晶状体、内耳膜迷路、腺垂体、唾液腺、口腔鼻腔及肛管下段上皮。把“神经垂体和腺垂体”写成同一个胚层原基，或把黑素细胞算进表面外胚层的“表皮附属器”，户头都会错。
:::

:::compare{title="神经管、神经嵴与表面外胚层"}
| 项目 | 神经管（神经外胚层闭合） | 神经嵴 | 表面外胚层 |
|------|--------------------------|--------|------------|
| 位置 | 表面外胚层深面的中轴管 | 神经管背外侧两条细胞索 | 包在胚体外表 |
| 职分 | 中枢神经系统原基 | 周围神经系统原基，兼多项迁移 | 被覆、晶状体、腺垂体等 |
| 主要衍生物 | 脑、脊髓、松果体、神经垂体、视网膜 | 脑/脊/自主神经节及周围神经；肾上腺髓质嗜铬细胞；表皮黑素细胞；头端颅面骨骼和结缔组织 | 表皮及附属器、牙釉质、角膜上皮、晶状体、内耳膜迷路、腺垂体、唾液腺、口腔/鼻腔/肛管下段上皮 |
| 闭合相关畸形 | 前神经孔未闭→无脑；后神经孔未闭→脊髓裂 | 不按前、后神经孔这把尺子算 | 不形成神经管 |
:::

:::pitfall{label="神经垂体跟神经管走，腺垂体跟表面外胚层走"}
垂体不是“整个来自神经管”，也不是“整个来自口凹上皮”一句能写完。教材把神经垂体记在神经管户头，把腺垂体记在表面外胚层户头。黑素细胞也不在“表皮附属器”那一本里，它是神经嵴迁入表皮后分化的。
:::

:::insight{label="神经嵴是从管壁里迁出去的周围神经系统原基"}
闭合神经管的同时，外侧缘细胞先进入管壁背侧，再迁出来铺成两条索。中枢留在管里，周围神经节和若干“散在细胞”（嗜铬细胞、黑素细胞、头端颅面间充质）跟索走。把神经嵴写成“神经管的别名”，周围神经和肾上腺髓质会对错户头。
:::

### 2. 中胚层的分化

脊索两旁的中胚层细胞增殖较快，由内向外依次分化为轴旁中胚层、间介中胚层和侧中胚层。中胚层的细胞通常先形成间充质，然后分化为各种结缔组织、肌组织和血管等。

:::definition{label="中胚层先成间充质"}
中胚层细胞通常先形成间充质，然后分化为各种结缔组织、肌组织和血管等。先问间充质，再问它落在轴旁、间介还是侧板。
:::

:::definition{label="中胚层的三分法"}
脊索两旁的中胚层由内向外依次为：紧邻脊索的轴旁中胚层、二者之间的间介中胚层、最外侧的侧中胚层（图 21-14）。
:::

:::concept{term="先由内向外认轴旁、间介、侧板，再问侧板有没有裂出胚内体腔"}
中胚层不要写成“一块肉”。贴脊索的纵行细胞索是轴旁，随即裂成体节；轴旁和侧板之间那一条是间介，走泌尿生殖；最外侧是侧中胚层，内部先出现小腔隙，再融成胚内体腔，侧板才分成贴外胚层的体壁中胚层和贴内胚层的脏壁中胚层。没裂腔，就还没有体壁/脏壁这两本账。
:::

#### （1）轴旁中胚层

轴旁中胚层（paraxial mesoderm）紧邻脊索两侧。这里的中胚层细胞迅速增殖，形成一对纵行的细胞索，即轴旁中胚层。它随即裂为块状细胞团，称体节（somite）（见图 21-14、图 21-16、图 21-17）。体节左右成对，从颈部向尾部依次形成，并逐渐增多。第 $5$ 周时，体节全部形成，共 $42\sim 44$ 对。体节将主要分化为背侧的皮肤真皮、骨骼肌和中轴骨骼（如脊柱）。脊索的大部分将退化消失，仅在脊柱的椎间盘内残留为髓核。

:::definition{label="轴旁中胚层"}
轴旁中胚层（paraxial mesoderm）是紧邻脊索两侧、迅速增殖形成的一对纵行细胞索。它随即裂为成对的体节。
:::

:::definition{label="体节"}
体节（somite）是轴旁中胚层裂成的块状细胞团，左右成对，从颈部向尾部依次形成。第 $5$ 周全部形成，共 $42\sim 44$ 对。主要分化为背侧的皮肤真皮、骨骼肌和中轴骨骼（如脊柱）。
:::

:::definition{label="脊索的结局"}
脊索大部分退化消失，仅在脊柱的椎间盘内残留为髓核。椎间盘纤维环等中轴骨骼来自体节，髓核不是体节的残留。
:::

:::pitfall{label="体节分化的是背侧真皮和中轴骨骼，不要写成全身皮肤和四肢骨"}
体节的真皮账在背侧；胸腹部和四肢的皮肤真皮、骨骼走侧中胚层的体壁中胚层。脊索大部分消失，椎间盘髓核是脊索残留，不是“体节变成了髓核”。
:::

#### （2）间介中胚层

间介中胚层（intermediate mesoderm）位于轴旁中胚层与侧中胚层之间（见图 21-14），分化为泌尿生殖系统的主要器官（见第 $24$ 章）。

:::definition{label="间介中胚层"}
间介中胚层（intermediate mesoderm）夹在轴旁中胚层与侧中胚层之间，分化为泌尿生殖系统的主要器官。它不裂体节，也不围胚内体腔。
:::

#### （3）侧中胚层

侧中胚层（lateral mesoderm）是中胚层最外侧的部分。其内部先出现一些小的腔隙，然后融合为一个大的胚内体腔（intraembryonic coelom），并与胚外体腔相通，侧中胚层便分为两层（见图 21-14，图 21-19）。与外胚层相贴的为体壁中胚层（parietal mesoderm），将主要分化为胸腹部和四肢的皮肤真皮、骨骼肌、骨骼和血管等；与内胚层相贴的为脏壁中胚层（visceral mesoderm），覆盖于由内胚层演化形成的原始消化管外面，将分化为消化、呼吸系统的肌组织、血管、结缔组织和间皮等。

胚内体腔从头端到尾端将分化为心包腔、胸膜腔和腹膜腔。

:::definition{label="侧中胚层"}
侧中胚层（lateral mesoderm）是中胚层最外侧的部分。内部小腔隙融合成胚内体腔并与胚外体腔相通后，它才分成体壁中胚层和脏壁中胚层两层。
:::

:::definition{label="胚内体腔"}
胚内体腔（intraembryonic coelom）由侧中胚层内部小腔隙融合而成，并与胚外体腔相通。从头端到尾端将分化为心包腔、胸膜腔和腹膜腔。
:::

:::definition{label="体壁中胚层"}
体壁中胚层（parietal mesoderm）与外胚层相贴，主要分化为胸腹部和四肢的皮肤真皮、骨骼肌、骨骼和血管等。
:::

:::definition{label="脏壁中胚层"}
脏壁中胚层（visceral mesoderm）与内胚层相贴，覆盖于原始消化管外面，将分化为消化、呼吸系统的肌组织、血管、结缔组织和间皮等。
:::

:::compare{title="轴旁中胚层、间介中胚层与侧中胚层"}
| 项目 | 轴旁中胚层 | 间介中胚层 | 侧中胚层 |
|------|------------|------------|----------|
| 位置 | 紧邻脊索两侧 | 轴旁与侧中胚层之间 | 中胚层最外侧 |
| 标志结构 | 裂为体节（$42\sim 44$ 对，第 $5$ 周全部形成） | 不裂体节、不围体腔 | 内部融成胚内体腔，再分成体壁/脏壁两层 |
| 主要分化 | 背侧皮肤真皮、骨骼肌、中轴骨骼 | 泌尿生殖系统主要器官 | 体壁：胸腹和四肢真皮、骨骼肌、骨骼、血管；脏壁：消化呼吸的肌、血管、结缔组织、间皮 |
| 相关残留 / 腔 | 脊索大部分退化，椎间盘髓核残留 | 见第 $24$ 章 | 胚内体腔 → 心包腔、胸膜腔、腹膜腔 |
:::

:::compare{title="体壁中胚层与脏壁中胚层"}
| 项目 | 体壁中胚层 | 脏壁中胚层 |
|------|------------|------------|
| 贴靠 | 外胚层 | 内胚层（原始消化管外面） |
| 别称含义 | parietal：体壁侧 | visceral：脏器侧 |
| 主要分化 | 胸腹部和四肢的皮肤真皮、骨骼肌、骨骼和血管 | 消化、呼吸系统的肌组织、血管、结缔组织和间皮 |
| 何时出现 | 胚内体腔把侧中胚层分成两层之后 | 同左 |
:::

:::pitfall{label="胚内体腔不是胚外体腔，心包、胸膜、腹膜都从胚内体腔来"}
第 $2$ 周滋养层和羊膜囊、卵黄囊之间扩出来的是胚外体腔；侧中胚层里融出来的才是胚内体腔。早期二者相通，但后来分化为心包腔、胸膜腔、腹膜腔的是胚内这一本。把胸膜腔写成“胚外体腔改名”，浆膜腔账会做到绒毛膜上去。
:::

:::insight{label="真皮有两本账：背侧走体节，胸腹和四肢走体壁中胚层"}
同一张“皮肤真皮”，来源按部位切开。体节负责背侧真皮、中轴骨骼和骨骼肌；体壁中胚层负责胸腹部和四肢的真皮、骨骼肌、骨骼和血管。切片或考题里写“真皮来自中胚层”没错，但再往下不问部位就会把体节和侧板并成一句。
:::

### 3. 内胚层的分化

内胚层被包入胚体形成原始消化管（primitive digestive tube），将分化为咽喉及其以下的消化管、消化腺、呼吸道和肺的上皮组织，以及中耳、甲状腺、甲状旁腺、胸腺、膀胱等器官的上皮组织。

:::definition{label="原始消化管"}
原始消化管（primitive digestive tube）是胚盘卷折时内胚层被包入胚体后形成的头尾方向管道。头端由口咽膜封闭，尾端由泄殖腔膜封闭，中段腹侧经卵黄蒂与卵黄囊相通。
:::

:::definition{label="内胚层的上皮去向"}
内胚层分化为咽喉及其以下消化管、消化腺、呼吸道和肺的上皮，以及中耳、甲状腺、甲状旁腺、胸腺、膀胱等器官的上皮。它给这些器官铺上皮，不单独构成整条消化管的肌层和结缔组织（后者多来自脏壁中胚层）。
:::

:::compare{title="外胚层、中胚层与内胚层的主要去向"}
| 项目 | 外胚层 | 中胚层 | 内胚层 |
|------|--------|--------|--------|
| 先问 | 神经外胚层还是表面外胚层 | 轴旁、间介还是侧板 | 卷没卷入胚体、成没成原始消化管 |
| 中枢 / 被覆 | 神经管→脑脊髓等；表面外胚层→表皮等 | 不形成神经管 | 不形成表皮 |
| 体腔与血管 | 无胚内体腔 | 胚内体腔；间充质→结缔组织、肌、血管 | 无胚内体腔 |
| 消化呼吸 | 口腔、鼻腔及肛管下段上皮 | 脏壁中胚层→消化呼吸的肌、血管、结缔组织、间皮 | 咽喉以下消化管、消化腺、呼吸道和肺的上皮 |
| 特殊器官上皮 | 牙釉质、角膜上皮、晶状体、内耳膜迷路、腺垂体、唾液腺 | 泌尿生殖主要器官（间介） | 中耳、甲状腺、甲状旁腺、胸腺、膀胱等上皮 |
:::

:::pitfall{label="内胚层是上皮原基，消化管壁的肌和结缔组织跟脏壁中胚层走"}
“消化系统来自内胚层”只对上皮这一本账成立。原始消化管外面贴的是脏壁中胚层，肌组织、血管、结缔组织和间皮从那里来。把整条肠壁都写成内胚层，侧中胚层那本账会做丢。
:::

## （二）胚体的形成

伴随三胚层的分化，胚盘边缘向腹侧卷折形成头褶、尾褶和左右侧褶，扁平形胚盘逐渐变为圆柱形的胚体。胚盘卷折主要是因其各部分生长速度的差异所致。胚盘中轴部由于神经管和体节的生长而向背侧隆起，又由于外胚层的生长速度快于内胚层，这样导致了侧褶，使外胚层包于胚体外表，内胚层被卷到胚体内部。胚体头尾方向的生长速度快于左右侧向的生长；头端由于脑和颜面器官的发生，故其生长速度又快于尾端，因而胚盘卷折为头大尾小的圆柱形胚体，胚盘边缘则卷折到胚体腹侧，并逐渐靠拢，最终在胚体成脐处会聚（图 21-19）。

:::definition{label="头褶、尾褶与左右侧褶"}
头褶、尾褶和左右侧褶是胚盘边缘向腹侧卷折形成的褶。四褶一起把扁平胚盘收成圆柱形胚体。
:::

:::definition{label="卷折的动力"}
卷折主要来自生长速度差异：中轴部因神经管和体节生长向背侧隆起；外胚层生长快于内胚层，导致侧褶；头尾方向快于左右侧向；头端因脑和颜面器官发生又快于尾端。结果是头大尾小的圆柱形胚体。
:::

:::definition{label="成脐处会聚"}
胚盘边缘卷折到胚体腹侧后逐渐靠拢，最终在胚体成脐处会聚。体蒂和卵黄囊也在腹侧中心合并，外包羊膜，形成脐带。
:::

::figure{src="/images/histology/textbook/p0234_01.png" caption="图21-19 胚体外形和内部结构的演变模式图。A1. 第 20 天人胚背面观；B1. 第 23 天人胚侧面观；C1. 第 26 天人胚侧面观；D1. 第 28 天人胚侧面观。A2～D2 为相应纵切面，A3～D3 为相应横切面。示口咽膜与泄殖腔膜转向腹侧，头褶、尾褶和侧褶把卵黄囊收细，体蒂参与形成脐带。" alt="四行模式图：背面或侧面外形配纵切与横切，显示神经管、体节、卵黄囊、体蒂、头褶尾褶侧褶及脐带逐渐形成"}

圆柱形胚体形成的结果是胚体凸入羊膜腔，浸泡于羊水中；体蒂和卵黄囊于胚体腹侧中心合并，外包羊膜，形成脐带；口咽膜和泄殖腔膜分别转到胚体头和尾的腹侧；外胚层包于胚体外表；内胚层卷折到胚体内部，形成头尾方向的原始消化管，其中段的腹侧与卵黄囊相通，二者相连的一段卵黄囊相对狭窄，称卵黄蒂，头端由口咽膜封闭，尾端由泄殖腔膜封闭。至第 $8$ 周末，胚体外表已可见眼、耳、鼻及四肢，初具人形（图 21-20）。第 $5$ 周人胚扫描电镜下可见鳃弓、心隆起、上肢芽、体节和下肢芽。

:::definition{label="卵黄蒂"}
卵黄蒂是原始消化管中段腹侧与卵黄囊相连的一段相对狭窄的卵黄囊。原始消化管头端由口咽膜封闭，尾端由泄殖腔膜封闭。
:::

:::definition{label="口咽膜与泄殖腔膜的新位置"}
卷折后，口咽膜转到胚体头的腹侧，泄殖腔膜转到胚体尾的腹侧。它们不再留在扁平胚盘的头、尾端平面上。
:::

:::definition{label="第8周末的胚体"}
至第 $8$ 周末，胚体外表已可见眼、耳、鼻及四肢，初具人形。这是胚期结束、胎期开始的外形标志。
:::

::figure{src="/images/histology/textbook/p0235_01.png" caption="图21-20 第 5～8 周胚体外形的演变模式图。A. 第 33 天：发生中的眼、肘、手板、足板、尾；B. 第 48 天：已有色素的眼、外耳、颈曲、指线间的凹陷、趾线；C. 第 52 天；D. 第 56 天：脐疝明显。至第 8 周末初具人形。" alt="四个侧面胚胎：从有尾和手板足板，到指趾分线、颈曲，再到肢体弯曲、腹侧脐疝"}

:::note{label="第5周扫描电镜能看见什么"}
第 $5$ 周人胚扫描电镜下可见五项外形标志：鳃弓在头侧，心隆起在腹侧，上肢芽和下肢芽先后出现，体节在背外侧成对排列。与图 21-20A（第 $33$ 天）的手板、足板和尾一起，标出胚体外形从卷折完成走向肢芽发生的节点。
:::

:::compare{title="卷折前的胚盘与卷折后的圆柱形胚体"}
| 项目 | 扁平胚盘 | 圆柱形胚体 |
|------|----------|------------|
| 外形 | 第 $3$ 周末梨形盘 | 头大尾小的圆柱，第 $8$ 周末初具人形 |
| 外胚层 | 在背侧 | 包于胚体外表 |
| 内胚层 | 在腹侧铺成盘的一层 | 卷入内部，成头尾方向的原始消化管 |
| 口咽膜 / 泄殖腔膜 | 分别在脊索头侧、原条尾侧的盘面 | 转到头、尾的腹侧，封闭原肠头、尾端 |
| 卵黄囊 | 在腹侧与内胚层广面相通 | 经狭窄的卵黄蒂与原肠中段相通 |
| 体蒂 | 在尾端连滋养层 | 与卵黄囊在腹侧中心合并，外包羊膜形成脐带 |
| 所处环境 | 尚未整体凸入羊膜腔 | 凸入羊膜腔，浸泡于羊水中 |
:::

:::pitfall{label="侧褶把内胚层卷进去，不是内胚层自己长成了一条管子"}
外胚层长得快、中轴又隆起，左右侧褶才把内胚层包进腹侧。原始消化管是卷折的结果，不是内胚层在盘面上“钻出一条管道”。口咽膜和泄殖腔膜也是被转到腹侧的，不是原来就长在肚皮上。
:::

:::insight{label="头褶尾褶侧褶是同一套生长差，不是三次互不相关的折叠"}
中轴隆起、外胚层快于内胚层、头尾快于左右、头端又快于尾端——四条速度差同时起作用。结果是一个头大尾小、腹侧收口于脐的圆柱。把卷折写成“先做头、再做尾、最后左右各折一次”，脐带、卵黄蒂和两个膜的腹侧新位置会对不齐图 21-19。
:::

:::timeline{period="第4～8周：分化与卷折并行"}
- **第4周** 神经褶中段融合，前、后神经孔闭合为神经管；体节迅速增多；头褶、尾褶、侧褶使胚盘变成圆柱
- **口咽膜与泄殖腔膜** 转到头、尾腹侧，分别封闭原始消化管头端和尾端
- **腹侧收口** 体蒂与卵黄囊在成脐处会聚，外包羊膜形成脐带；卵黄蒂连通原肠中段与卵黄囊
- **第5周** 体节全部形成，共 42～44 对；外形可见鳃弓、心隆起、肢芽
- **第5～8周** 眼、耳、鼻及四肢逐渐显现
- **第8周末** 初具人形，胚期结束
:::

:::keypoint{label="第4周闭神经管，第5周齐体节，第8周末初具人形"}
- 脊索诱导神经板；神经沟→神经褶中段先融合→第 $4$ 周前、后神经孔闭合为神经管（脑、脊髓、松果体、神经垂体、视网膜）。
- 前神经孔未闭→无脑畸形；后神经孔未闭→脊髓裂。
- 神经嵴：周围神经节及周围神经、肾上腺髓质嗜铬细胞、黑素细胞、头端颅面骨骼结缔组织。
- 表面外胚层：表皮及附属器、牙釉质、角膜上皮、晶状体、内耳膜迷路、腺垂体等。
- 中胚层先成间充质；由内向外为轴旁（体节 $42\sim 44$ 对）、间介（泌尿生殖）、侧中胚层（胚内体腔→体壁/脏壁；心包、胸膜、腹膜腔）。
- 脊索大部分退化，椎间盘髓核残留。
- 内胚层卷入成原始消化管，给咽喉以下消化管、消化腺、呼吸道和肺以及中耳、甲状腺、甲状旁腺、胸腺、膀胱铺上皮。
- 头褶、尾褶、左右侧褶把盘收成圆柱；外胚层包外表，口咽膜和泄殖腔膜转腹侧，卵黄蒂连卵黄囊，第 $8$ 周末初具人形。
:::

:::memory{label="本节必背要点"}
- [ ] 第 $4\sim 8$ 周，三个胚层逐渐分化形成各种器官的原基。
- [ ] 脊索诱导背侧中线外胚层增厚呈板状，称神经板（neural plate）。
- [ ] 构成神经板的外胚层称神经外胚层（neural ectoderm）；其余称表面外胚层。
- [ ] 神经板随脊索生长而增长，头侧宽于尾侧。
- [ ] 神经板中央沿长轴向脊索方向凹陷，形成神经沟（neural groove）。
- [ ] 沟两侧边缘隆起称神经褶（neural fold）。
- [ ] 两侧神经褶在神经沟中段靠拢融合，并向头尾两端进展。
- [ ] 头尾两端开口分别称前神经孔和后神经孔，第 $4$ 周闭合，神经沟完全闭合为神经管（neural tube）。
- [ ] 神经管两侧的表面外胚层在管背侧靠拢融合，使神经管居于表面外胚层深面。
- [ ] 神经管是中枢神经系统原基，分化为脑和脊髓以及松果体、神经垂体和视网膜等。
- [ ] 前神经孔未闭合导致无脑畸形；后神经孔未闭合导致脊髓裂。
- [ ] 神经沟闭合过程中，神经板外侧缘细胞进入神经管壁背侧并迁出，形成神经管背外侧两条纵行细胞索，称神经嵴（neural crest）。
- [ ] 神经嵴是周围神经系统原基，分化为脑神经节、脊神经节、自主神经节及周围神经。
- [ ] 部分神经嵴细胞迁入肾上腺原基，分化为髓质嗜铬细胞。
- [ ] 部分神经嵴细胞迁入表皮，分化为黑素细胞。
- [ ] 头端神经嵴细胞参与颅面部骨骼和结缔组织的形成。
- [ ] 表面外胚层分化为皮肤表皮及其附属器，以及牙釉质、角膜上皮、晶状体、内耳膜迷路、腺垂体、唾液腺、口腔、鼻腔及肛管下段上皮。
- [ ] 脊索两旁中胚层由内向外依次分化为轴旁中胚层、间介中胚层和侧中胚层。
- [ ] 中胚层细胞通常先形成间充质，再分化为各种结缔组织、肌组织和血管等。
- [ ] 轴旁中胚层（paraxial mesoderm）紧邻脊索两侧，迅速增殖成一对纵行细胞索，随即裂为体节（somite）。
- [ ] 体节左右成对，从颈部向尾部依次形成；第 $5$ 周全部形成，共 $42\sim 44$ 对。
- [ ] 体节主要分化为背侧皮肤真皮、骨骼肌和中轴骨骼（如脊柱）。
- [ ] 脊索大部分退化消失，仅在脊柱椎间盘内残留为髓核。
- [ ] 间介中胚层（intermediate mesoderm）位于轴旁与侧中胚层之间，分化为泌尿生殖系统主要器官。
- [ ] 侧中胚层（lateral mesoderm）是中胚层最外侧部分。
- [ ] 侧中胚层内部小腔隙融合成胚内体腔（intraembryonic coelom），并与胚外体腔相通，于是分为两层。
- [ ] 与外胚层相贴的为体壁中胚层（parietal mesoderm），主要分化为胸腹部和四肢的皮肤真皮、骨骼肌、骨骼和血管等。
- [ ] 与内胚层相贴的为脏壁中胚层（visceral mesoderm），覆盖原始消化管外面，分化为消化、呼吸系统的肌组织、血管、结缔组织和间皮等。
- [ ] 胚内体腔从头端到尾端分化为心包腔、胸膜腔和腹膜腔。
- [ ] 内胚层被包入胚体形成原始消化管（primitive digestive tube）。
- [ ] 内胚层分化为咽喉及其以下消化管、消化腺、呼吸道和肺的上皮，以及中耳、甲状腺、甲状旁腺、胸腺、膀胱等器官的上皮。
- [ ] 胚盘边缘向腹侧卷折形成头褶、尾褶和左右侧褶，扁平胚盘变为圆柱形胚体。
- [ ] 卷折主要因各部分生长速度差异：中轴部因神经管和体节向背侧隆起；外胚层生长快于内胚层导致侧褶。
- [ ] 头尾方向生长快于左右侧向；头端因脑和颜面器官发生又快于尾端，故成头大尾小的圆柱形胚体。
- [ ] 胚盘边缘卷折到腹侧并逐渐靠拢，最终在胚体成脐处会聚。
- [ ] 胚体凸入羊膜腔，浸泡于羊水中。
- [ ] 体蒂和卵黄囊于胚体腹侧中心合并，外包羊膜，形成脐带。
- [ ] 口咽膜和泄殖腔膜分别转到胚体头和尾的腹侧。
- [ ] 外胚层包于胚体外表；内胚层卷入内部形成头尾方向的原始消化管。
- [ ] 原肠中段腹侧与卵黄囊相通，相连的狭窄段称卵黄蒂；头端口咽膜封闭，尾端泄殖腔膜封闭。
- [ ] 至第 $8$ 周末，胚体外表可见眼、耳、鼻及四肢，初具人形。
