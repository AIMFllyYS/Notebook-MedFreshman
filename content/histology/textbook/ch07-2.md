# 二、突触

神经元与神经元之间，或神经元与效应细胞之间传递信息的结构称突触（synapse）。突触也是一种细胞连接方式，最常见的是一个神经元的轴突终末与另一个神经元的胞体、树突或树突棘连接，分别形成轴-体突触、轴-树突触或轴-棘突触。突触可分为化学突触和电突触两类。化学突触以神经递质作为传递信息的媒介，是一般所说的突触（图 7-7～图 7-10）。电突触实际是缝隙连接，以电流作为信息载体，存在于中枢神经系统和视网膜内的同类神经元之间，促进神经元的同步活动。

:::definition{label="突触"}
突触（synapse）是神经元与神经元之间，或神经元与效应细胞之间传递信息的结构，也是一种细胞连接方式。最常见的是一个神经元的轴突终末与另一个神经元的胞体、树突或树突棘相连。
:::

:::definition{label="轴-体突触"}
轴-体突触是一个神经元的轴突终末与另一个神经元的胞体形成的突触。
:::

:::definition{label="轴-树突触"}
轴-树突触是一个神经元的轴突终末与另一个神经元的树突形成的突触。
:::

:::definition{label="轴-棘突触"}
轴-棘突触是一个神经元的轴突终末与另一个神经元的树突棘形成的突触。
:::

:::definition{label="化学突触"}
化学突触以神经递质作为传递信息的媒介，是一般所说的突触。电镜下由突触前成分、突触间隙和突触后成分构成。
:::

:::definition{label="电突触"}
电突触实际是缝隙连接，以电流作为信息载体，存在于中枢神经系统和视网膜内的同类神经元之间，促进神经元的同步活动。
:::

:::concept{term="先问媒介是递质还是电流"}
听见“突触”，先问它靠什么过河。化学突触把递质倒进 $15\sim 30\,\mathrm{nm}$ 的间隙，是教材默认的那一种；电突触就是缝隙连接，电流直接过去，用来让一群同类神经元一起动。把所有突触都听成“释放乙酰胆碱”，会把电突触和视网膜、中枢里的同步活动做丢；把电突触听成“没有结构的接触”，又会漏掉它就是缝隙连接这一句。
:::

:::compare{title="化学突触与电突触"}
| 项目 | 化学突触 | 电突触 |
|------|----------|--------|
| 信息媒介 | 神经递质 | 电流 |
| 结构本质 | 突触前膜–间隙–突触后膜；有突触小泡 | 缝隙连接 |
| 间隙 | $15\sim 30\,\mathrm{nm}$ | 缝隙连接的狭窄间隙 |
| 分布 | 最常见，一般所说的突触 | 中枢神经系统和视网膜内的同类神经元之间 |
| 功能特点 | 可兴奋或抑制，取决于递质及其受体 | 促进神经元的同步活动 |
| 教材地位 | 本节主体（图 7-7～图 7-10） | 对照写出，不展开小泡循环 |
:::

:::pitfall{label="电突触不是“没有突触”，它就是缝隙连接"}
教材把电突触写成缝隙连接，不是化学突触的简化版，也不是“还没有形成前膜后膜的半成品”。它存在于中枢和视网膜的同类神经元之间，职分是同步，不是把一种递质从一个细胞倒进另一个细胞。心肌闰盘纵向部分的缝隙连接是同一类细胞连接，但那是肌组织的功能合体账，不要和神经元电突触混成一个名词。
:::

电镜下，突触由突触前成分（presynaptic element）、突触间隙（synaptic cleft）和突触后成分（postsynaptic element）3 部分构成。突触前成分和突触后成分相对的细胞膜分别称突触前膜和突触后膜，两者之间有宽 $15\sim 30\,\mathrm{nm}$ 的突触间隙。突触前成分一般是神经元的轴突终末，呈球状膨大，在镀银染色的切片上呈棕黑色的圆形颗粒，称突触小体（synaptic knob）。

:::definition{label="突触前成分"}
突触前成分（presynaptic element）一般是神经元的轴突终末，呈球状膨大。其细胞膜称突触前膜，比一般细胞膜略厚；细胞质面有致密物质附着，并有排列规则的致密突起，突起间的空隙可容纳突触小泡。
:::

:::definition{label="突触间隙"}
突触间隙（synaptic cleft）是突触前膜与突触后膜之间宽 $15\sim 30\,\mathrm{nm}$ 的间隙，化学突触的递质经此扩散到后膜受体。
:::

:::definition{label="突触后成分"}
突触后成分（postsynaptic element）与前成分相对，其细胞膜称突触后膜，比一般细胞膜略厚。突触后膜中有特异性的神经递质和调质的受体及离子通道。
:::

:::definition{label="突触小体"}
突触小体（synaptic knob）即球状膨大的轴突终末。镀银染色切片上呈棕黑色圆形颗粒，附着于另一个神经元的胞体或树突表面（图 7-7）。
:::

:::concept{term="先问三件套：前膜、间隙，还是后膜"}
化学突触不是两个细胞贴在一起那么简单。电镜先数三层：前膜（终末侧，有致密突起和停泊位）、$15\sim 30\,\mathrm{nm}$ 的间隙、后膜（有受体和离子通道）。光镜镀银只能看见突触小体这颗棕黑圆粒，看不见间隙。把光镜下的小体直接当成“整个突触”，会把后膜受体那一本账做丢。
:::

:::compare{title="突触前膜、间隙与后膜"}
| 结构 | 位置 | 关键装置 | 光镜 / 电镜 |
|------|------|----------|-------------|
| 突触前膜 | 轴突终末球状膨大的膜 | 比一般细胞膜略厚；细胞质面有致密物质和规则致密突起，突起间容纳突触小泡 | 光镜见突触小体；电镜才能分前膜 |
| 突触间隙 | 前膜与后膜之间 | 宽 $15\sim 30\,\mathrm{nm}$，递质在此扩散 | 仅电镜可见 |
| 突触后膜 | 后一神经元或效应细胞的相对膜 | 比一般细胞膜略厚；含特异性递质/调质受体及离子通道 | 电镜可见膜增厚 |
:::

突触前成分（突触小体）内含许多突触小泡（synaptic vesicle），还有线粒体、微丝和微管等。突触小泡内含神经递质或神经调质。含乙酰胆碱的突触小泡多是圆形清亮小泡，含单胺类递质的则是小颗粒型小泡，含氨基酸类递质的多为扁平清亮小泡，含神经肽的往往是大颗粒型小泡。突触小泡表面附有一种蛋白质，称突触素（synapsin），将小泡连接于细胞骨架上。其细胞质面有致密物质附着，突触前膜和突触后膜比一般细胞膜略厚。突触前膜细胞质面还附着有排列规则的致密突起，致密突起间的空隙可容纳突触小泡。突触后膜中有特异性的神经递质和调质的受体及离子通道。

:::definition{label="突触小泡"}
突触小泡（synaptic vesicle）位于突触前成分内，含神经递质或神经调质。表面附有突触素，将小泡连接于细胞骨架上。另有线粒体、微丝和微管等。
:::

:::definition{label="突触素"}
突触素（synapsin）是附着于突触小泡表面的蛋白质，把小泡连在细胞骨架上。磷酸化后与小泡亲和力降低，小泡才能脱离骨架、移向突触前膜。
:::

:::compare{title="突触小泡形态与内容物"}
| 小泡形态 | 主要含有 | 对应化学分型（第一节） |
|----------|----------|------------------------|
| 圆形清亮小泡 | 乙酰胆碱 | 胆碱能神经元 |
| 小颗粒型小泡 | 单胺类递质 | 胺能、去甲肾上腺素能等 |
| 扁平清亮小泡 | 氨基酸类递质（如甘氨酸等） | 氨基酸能神经元 |
| 大颗粒型小泡 | 神经肽 | 肽能神经元 |
:::

:::pitfall{label="清亮小泡不是“空泡”，颗粒也不是溶酶体"}
圆形清亮、扁平清亮指的是电镜下内容物对比度低，不是没有递质。小颗粒、大颗粒也不是脂褐素或溶酶体残余体。脂褐素在胞体胞质里随年龄增多；突触小泡在终末里按递质化学性质分型。图 7-9 把 1、2、3 三种小泡画在不同的突触小体里，就是要按形态认内容，不要把所有终末都写成“圆形清亮、释放乙酰胆碱”。
:::

当神经冲动沿轴膜传导到轴突终末时，可引起突触前膜内的 $\mathrm{Ca}^{2+}$ 通道开放，$\mathrm{Ca}^{2+}$ 由细胞外进入突触小体，在 ATP 的参与下使突触素发生磷酸化。磷酸化的突触素与突触小泡的亲和力降低，与小泡分离，致使突触小泡脱离细胞骨架，移至突触前膜并与之融合，通过出胞作用释放小泡内容物到突触间隙。突触后膜中的受体与特异性神经递质结合后，膜内离子通道开放，改变突触后膜两侧的离子分布，使突触后神经元（或效应细胞）出现兴奋性或抑制性突触后电位。使突触后膜发生兴奋的突触称兴奋性突触，使突触后膜发生抑制的突触称抑制性突触。突触的兴奋或抑制取决于神经递质及其受体的种类。

:::definition{label="兴奋性突触"}
兴奋性突触使突触后膜发生兴奋，产生兴奋性突触后电位。是否兴奋取决于神经递质及其受体的种类，而不是单纯取决于“有没有释放”。
:::

:::definition{label="抑制性突触"}
抑制性突触使突触后膜发生抑制，产生抑制性突触后电位。同样取决于递质及其受体的种类。
:::

:::timeline{period="化学突触：一次冲动怎样写成后电位"}
- **冲动抵达** 神经冲动沿轴膜传到轴突终末
- **钙内流** 突触前膜 $\mathrm{Ca}^{2+}$ 通道开放，$\mathrm{Ca}^{2+}$ 由细胞外进入突触小体
- **突触素磷酸化** 在 ATP 参与下突触素磷酸化，与小泡亲和力降低并分离
- **出胞释放** 小泡脱离细胞骨架，移至突触前膜融合，内容物释放入突触间隙
- **后膜应答** 特异性受体结合递质，离子通道开放，出现兴奋性或抑制性突触后电位
:::

:::cause-effect{title="钙怎样把骨架上的小泡改写成间隙里的递质"}
- 因：冲动到达，突触前膜 $\mathrm{Ca}^{2+}$ 通道开放，$\mathrm{Ca}^{2+}$ 进入突触小体
- 因：ATP 参与使突触素磷酸化，磷酸化突触素与小泡亲和力降低
- 果：小泡脱离细胞骨架，移至前膜融合，出胞释放内容物到突触间隙
- 果：后膜受体结合特异性递质，离子通道开放，出现兴奋性或抑制性突触后电位
- 制约：兴奋还是抑制取决于递质及其受体的种类，不取决于“钙进得多不多”这一句
:::

:::insight{label="释放是出胞，不是小泡穿过间隙"}
小泡在前成分里移动、与前膜融合，把内容物倒进间隙；小泡膜留在前膜侧，并不钻到后膜去。后膜只认受体和离子通道。把化学突触画成“小泡从第一个细胞滚进第二个细胞”，会把出胞、间隙扩散和受体结合三步并成一步。
:::

一个神经元可以通过突触把信息传递给许多其他神经元或效应细胞，如一个运动神经元可同时支配上千条骨骼肌纤维；一个神经元也可以通过突触接受来自许多其他神经元的信息，如小脑的浦肯野细胞的树突上有数十万个突触。在这些突触信息中，兴奋性和抑制性的都有，如果兴奋性突触活动的总和超过抑制性突触活动的总和，并足以刺激该神经元的轴突起始段产生神经冲动，该神经元表现为兴奋；反之，则为抑制。

:::definition{label="突触活动的总和"}
一个神经元同时接受兴奋性和抑制性突触信息。若兴奋性突触活动的总和超过抑制性突触活动的总和，并足以刺激轴突起始段产生神经冲动，该神经元表现为兴奋；反之则为抑制。起步点仍是第一节所写的轴突起始段。
:::

:::concept{term="先问总和能不能点燃起始段"}
终末可以同时接到成千上万个突触，但神经元会不会“放电”，只问一件事：兴奋性总和减去抑制性总和，够不够点燃轴突起始段。一个运动神经元可以支配上千条骨骼肌纤维（发散）；浦肯野细胞树突上有数十万个突触（会聚）。把“有突触”听成“一定兴奋”，会把抑制性突触和起始段阈值两本账做丢。
:::

:::compare{title="发散与会聚的两个教材例子"}
| 方向 | 教材例子 | 含义 |
|------|----------|------|
| 一个神经元 → 许多靶 | 一个运动神经元可同时支配上千条骨骼肌纤维 | 同一轴突终末分支把信息写成许多神经–肌突触 |
| 许多神经元 → 一个靶 | 小脑浦肯野细胞的树突上有数十万个突触 | 树突和树突棘把会聚来的兴奋性、抑制性信息先做总和 |
| 最终判决 | 总和是否足以刺激轴突起始段 | 兴奋或抑制在起始段才变成“发不发冲动” |
:::

:::pitfall{label="兴奋或抑制不取决于“是不是化学突触”，而取决于递质和受体"}
化学突触既可以是兴奋性的，也可以是抑制性的。同一类形态的小泡，遇到不同后膜受体，后电位的符号可以相反。不要按“圆形清亮 = 一定兴奋、扁平 = 一定抑制”去背死；教材原句是：突触的兴奋或抑制取决于神经递质及其受体的种类。
:::

:::keypoint{label="突触先把连接部位、化学三件套和钙–释放–总和立住"}
- 突触是神经元之间或神经元与效应细胞之间的信息传递结构；最常见为轴-体、轴-树、轴-棘。
- 化学突触以递质为媒介（一般所说的突触）；电突触是缝隙连接，以电流促进同类神经元同步。
- 电镜三件套：突触前成分（突触小体）、间隙 $15\sim 30\,\mathrm{nm}$、突触后成分；前膜后膜都略厚。
- 小泡经突触素挂在骨架上：圆清亮–乙酰胆碱，小颗粒–单胺，扁清亮–氨基酸，大颗粒–神经肽。
- 冲动 → $\mathrm{Ca}^{2+}$ 内流 → 突触素磷酸化 → 出胞释放 → 后膜受体和离子通道 → 兴奋性或抑制性后电位。
- 会聚与发散并存；兴奋还是抑制看兴奋性与抑制性活动的总和能否点燃轴突起始段。
:::

- [ ] 化学突触以神经递质为媒介，是一般所说的突触；电突触实际是缝隙连接，以电流为载体。
- [ ] 电突触存在于中枢神经系统和视网膜内的同类神经元之间，促进同步活动。
- [ ] 电镜下化学突触 = 突触前成分（presynaptic element）+ 突触间隙（synaptic cleft）+ 突触后成分（postsynaptic element）。
- [ ] 突触前膜与突触后膜相对，间隙宽 $15\sim 30\,\mathrm{nm}$；两膜均比一般细胞膜略厚。
- [ ] 突触前成分一般是球状膨大的轴突终末；镀银切片上呈棕黑色圆形颗粒，称突触小体（synaptic knob）。
- [ ] 突触小体内含许多突触小泡（synaptic vesicle），还有线粒体、微丝和微管。
- [ ] 圆形清亮小泡多含乙酰胆碱；小颗粒型小泡含单胺类；扁平清亮小泡多含氨基酸类；大颗粒型小泡往往含神经肽。
- [ ] 突触素（synapsin）附于小泡表面，将小泡连接于细胞骨架。
- [ ] 突触前膜细胞质面有排列规则的致密突起，突起间空隙可容纳突触小泡。
- [ ] 突触后膜中有特异性递质和调质的受体及离子通道。
- [ ] 冲动抵达 → 前膜 $\mathrm{Ca}^{2+}$ 通道开放 → $\mathrm{Ca}^{2+}$ 进入突触小体 → ATP 参与使突触素磷酸化 → 小泡脱离骨架、与前膜融合、出胞释放。
- [ ] 后膜受体结合特异性递质 → 离子通道开放 → 出现兴奋性或抑制性突触后电位。
- [ ] 兴奋性突触使后膜兴奋，抑制性突触使后膜抑制；取决于递质及其受体的种类。
- [ ] 一个运动神经元可同时支配上千条骨骼肌纤维；小脑浦肯野细胞树突上有数十万个突触。
- [ ] 兴奋性活动总和超过抑制性并足以刺激轴突起始段 → 该神经元兴奋；反之则抑制。
