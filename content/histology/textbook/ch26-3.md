# 三、脊髓的发生

在脑泡形成的同时，神经管尾段仍保持较细的直管状，分化为脊髓。管腔演化为中央管，套层成灰质，边缘层成白质。本节先把基板、翼板、顶板、底板和界沟立住，再按前正中裂、后正中隔、前角／后角／侧角，以及脊髓相对脊柱上移、马尾摊开。神经沟在第 $4$ 周初闭合为神经管见第一节；周围神经节的细节见下一节。

在脑泡形成的同时，神经管尾段仍保持较细的直管状，分化为脊髓。该段神经管的管腔演化为脊髓中央管，套层分化为脊髓的灰质，边缘层分化为脊髓的白质。神经管的两侧壁由于套层中成神经细胞和成神经胶质细胞的增生而迅速增厚，腹侧部增厚形成左、右两个基板，背侧部增厚形成左、右两个翼板。神经管的顶壁和底壁则相对薄而窄，分别形成顶板（roof plate）和底板（floor plate）。由于基板和翼板的增厚，两者在神经管的内表面也出现了左右相对的两条纵行界沟（图 26-8）。

:::definition{label="神经管尾段"}
脑泡形成时，神经管尾段仍保持较细的直管状，分化为脊髓。头段走脑，尾段走脊髓，不是整条管一起膨大。
:::

:::definition{label="脊髓中央管"}
该段神经管的管腔演化为脊髓中央管。以后翼板在中线融合，管腔背侧份消失，中央管才变成细管。
:::

:::definition{label="脊髓灰质与白质的来源"}
套层分化为脊髓的灰质，边缘层分化为脊髓的白质。细胞在套层，突起在边缘层，户头与第一节三层一致。
:::

:::definition{label="基板（脊髓）"}
神经管两侧壁因套层中成神经细胞和成神经胶质细胞增生而迅速增厚，腹侧部增厚形成左、右两个基板。基板形成脊髓灰质前角（或前柱），其中的成神经细胞主要分化为躯体运动神经元。
:::

:::definition{label="翼板（脊髓）"}
背侧部增厚形成左、右两个翼板。翼板形成脊髓灰质后角（或后柱），其中的成神经细胞分化为中间神经元。
:::

:::definition{label="顶板"}
顶板（roof plate）由神经管顶壁形成，相对薄而窄。它不是翼板，也不含成排的前角运动神经元。
:::

:::definition{label="底板"}
底板（floor plate）由神经管底壁形成，相对薄而窄。左右基板在它的两侧增厚。
:::

:::definition{label="界沟（脊髓）"}
基板和翼板增厚后，在神经管内表面出现左右相对的两条纵行界沟。界沟以上（背侧）是翼板，以下（腹侧）是基板。
:::

:::concept{term="先问这是基板还是翼板，再问顶板底板有没有增厚成角"}
看见脊髓发生，先按腹背切开：腹侧增厚是基板，将来前角、躯体运动神经元；背侧增厚是翼板，将来后角、中间神经元；顶壁薄的是顶板，底壁薄的是底板。界沟在管腔内表面，把基板和翼板分开。再问基板、翼板之间聚团的那一份，才是侧角、内脏传出神经元。把翼板写成前角，或把顶板听成后正中隔，灰质四板会对错户头。
:::

:::compare{title="基板、翼板、顶板与底板"}
| 项目 | 基板 | 翼板 | 顶板 | 底板 |
|------|------|------|------|------|
| 英文 | basal plate | alar plate | roof plate | floor plate |
| 部位 | 两侧壁腹侧部 | 两侧壁背侧部 | 顶壁 | 底壁 |
| 厚度 | 迅速增厚 | 迅速增厚 | 相对薄而窄 | 相对薄而窄 |
| 以后 | 灰质前角（前柱），躯体运动神经元 | 灰质后角（后柱），中间神经元 | 参与管腔背侧的顶 | 腹侧正中，前正中裂在其两侧基板之间 |
| 界沟关系 | 界沟腹侧 | 界沟背侧 | 两翼板之间的顶 | 两基板之间的底 |
:::

## 前正中裂、后正中隔与灰白质

由于成神经细胞和成神经胶质细胞的增多，左、右两基板向腹侧突出，在两者之间形成一条纵行的深沟，位居脊髓的腹侧正中部，称前正中裂。同样，左、右两翼板也增大，但主要是向内侧推移并在中线融合，致使神经管管腔的背侧份消失。左、右两翼板在中线的融合处形成一隔膜，称后正中隔。基板形成脊髓灰质的前角（或前柱），其中的成神经细胞主要分化为躯体运动神经元。翼板形成脊髓灰质后角（或后柱），其中的成神经细胞分化为中间神经元。若干成神经细胞聚集于基板和翼板之间，形成脊髓侧角（或侧柱），其内的成神经细胞分化为内脏传出神经元。边缘层由于灰质内神经细胞突起的伸入和神经胶质细胞的产生而增厚，其中还含有脊神经节细胞伸入脊髓的中枢突和脊髓内部的联络纤维，于是边缘层内胞突数量不断增加，发育为白质。至此，神经管的尾段分化成脊髓，神经管周围的间充质则分化成脊膜。

:::definition{label="前正中裂"}
左、右两基板向腹侧突出，在两者之间形成一条纵行深沟，位居脊髓腹侧正中部，称前正中裂。它是基板腹侧突出挤出来的沟，不是顶板凹陷。
:::

:::definition{label="后正中隔"}
左、右两翼板增大后主要向内侧推移并在中线融合，神经管管腔的背侧份消失；融合处形成一隔膜，称后正中隔。这是尾段管腔背侧份的闭合，不是第 $4$ 周初神经沟合管的那一步。
:::

:::definition{label="前角（前柱）"}
基板形成脊髓灰质的前角（或前柱）。其中的成神经细胞主要分化为躯体运动神经元。
:::

:::definition{label="后角（后柱）"}
翼板形成脊髓灰质后角（或后柱）。其中的成神经细胞分化为中间神经元。
:::

:::definition{label="侧角（侧柱）"}
若干成神经细胞聚集于基板和翼板之间，形成脊髓侧角（或侧柱），其内的成神经细胞分化为内脏传出神经元。侧角夹在前、后角之间，不是顶板变来的。
:::

:::definition{label="白质的组成"}
边缘层因灰质内神经细胞突起伸入和神经胶质细胞产生而增厚，其中还含有脊神经节细胞伸入脊髓的中枢突和脊髓内部的联络纤维。胞突数量不断增加，发育为白质。
:::

:::definition{label="脊膜"}
神经管尾段分化成脊髓后，神经管周围的间充质分化成脊膜。脊膜不是神经上皮变的。
:::

::figure{src="/images/histology/textbook/p0287_02.png" caption="图26-8 脊髓的发生模式图。A. 第6周：顶板、底板、翼板、基板、界沟，管壁仍分室管膜层、套层、边缘层；B. 第9周：翼板中线融合形成后正中隔，基板腹侧突出形成前正中裂，中央管变圆，灰质分后角、侧角、前角，边缘层成白质。" alt="左第6周横切椭圆管腔，背侧翼板腹侧基板，内外三层可辨；右第9周前正中裂与后正中隔，灰质蝶形分前角侧角后角，外周白质"}

:::derivation{title="翼板内移，管腔背侧份才消失"}
基板往腹侧长，左右之间挤出前正中裂，管腔腹侧仍在。翼板主要往内侧长，左右在中线对上，背侧那一份管腔被融合掉，只留下后正中隔。中央管因此从背腹细长的裂变成较小的管。这是神经管尾段内部的再闭合，时间晚于第 $4$ 周初神经沟合管。
:::

:::cause-effect{title="四板增厚方向不同，才有前正中裂和后正中隔"}
- 因：成神经细胞和成胶质细胞增多，左右基板向腹侧突出
- 果：腹侧正中出现前正中裂
- 因：左右翼板向内侧推移并在中线融合
- 果：管腔背侧份消失，融合处成后正中隔
- 因：若干成神经细胞聚于基板与翼板之间
- 果：侧角（侧柱）出现，内脏传出神经元落在这里
:::

:::compare{title="前角、后角与侧角"}
| 项目 | 前角（前柱） | 后角（后柱） | 侧角（侧柱） |
|------|--------------|--------------|--------------|
| 来源板 | 基板 | 翼板 | 基板和翼板之间的聚集 |
| 成神经细胞去向 | 主要分化为躯体运动神经元 | 中间神经元 | 内脏传出神经元 |
| 位置 | 灰质腹侧 | 灰质背侧 | 前、后角之间 |
| 不要听成 | 感觉中继 | 躯体运动 | 顶板或底板 |
:::

:::pitfall{label="后正中隔是翼板中线融合，前正中裂是基板腹侧对挤，不要对调"}
腹侧是裂（前正中裂），背侧是隔（后正中隔）。写成“背侧也裂开一条沟”，马尾和后根进后角的空间关系会对不上图 26-8B。
:::

:::insight{label="灰质三份核团，白质是突起加胶质再加后根中枢突"}
前角运动、后角中间、侧角内脏传出，都在套层变的灰质里。白质不是“空的边缘层”，里面有灰质细胞的突起、胶质、脊神经节中枢突和内部联络纤维。只背“套层灰质、边缘层白质”，后根纤维从哪进脊髓会说不清。
:::

:::note{label="脊神经后根来自神经嵴，前根来自前角"}
脊神经前根发生于第 $4$ 周末；稍后出现来自神经嵴迁移而成的脊神经节的脊神经后根（见图 26-4）。前根是基板／前角那本账，后根是神经嵴那本账，不要写成都从基板长出。
:::

## 脊髓与脊柱长度关系的变化

胚胎第 $4\sim 5$ 周时，整个脊髓区为等粗的圆柱形管状。脊神经前根发生于第 $4$ 周末，稍后出现了来自神经嵴迁移而成的脊神经节的脊神经后根（见图 26-4）。第 $4$ 个月，出现脊髓颈膨大和腰膨大，分出颈、胸、腰、骶区和马尾。

胚胎第 $3$ 个月之前，脊髓与脊柱等长，其下端可达脊柱的尾骨。此时，所有脊神经的起始处与它们相对应的椎间孔处于同一平面。第 $3$ 个月后，由于脊柱和硬脊膜的增长比脊髓快，脊柱逐渐超越脊髓向尾端延伸，脊髓的位置相对上移。至出生前，脊髓下端与第 $3$ 腰椎平齐，仅以终丝与尾骨相连。由于呈节段分布的脊神经均在胚胎早期形成，并从相应节段的椎间孔穿出，当脊髓位置相对上移后，脊髓颈段以下的脊神经根便越来越向尾侧斜行，再穿过其相应的椎间孔离开椎管。腰、骶和尾段的脊神经根则在椎管内垂直下行，与终丝共同组成马尾（图 26-9）。

:::definition{label="等粗圆柱期"}
胚胎第 $4\sim 5$ 周，整个脊髓区为等粗的圆柱形管状。此时还没有颈膨大、腰膨大。
:::

:::definition{label="脊神经前根与后根的发生时间"}
脊神经前根发生于第 $4$ 周末；稍后出现来自神经嵴迁移而成的脊神经节的后根。前根早于后根。
:::

:::definition{label="颈膨大、腰膨大"}
第 $4$ 个月出现脊髓颈膨大和腰膨大，并分出颈、胸、腰、骶区和马尾。膨大和分区是同一时期的事。
:::

:::definition{label="脊髓与脊柱等长阶段"}
胚胎第 $3$ 个月之前，脊髓与脊柱等长，下端可达脊柱的尾骨。所有脊神经起始处与相对应的椎间孔处于同一平面。
:::

:::definition{label="脊髓相对上移"}
第 $3$ 个月后，脊柱和硬脊膜增长比脊髓快，脊柱逐渐超越脊髓向尾端延伸，脊髓位置相对上移。至出生前，脊髓下端与第 $3$ 腰椎平齐，仅以终丝与尾骨相连。
:::

:::definition{label="终丝"}
出生前脊髓下端平第 $3$ 腰椎，仅以终丝与尾骨相连。终丝不是马尾里的神经根。
:::

:::definition{label="马尾"}
脊髓相对上移后，颈段以下脊神经根越来越向尾侧斜行，再经相应椎间孔出椎管；腰、骶和尾段脊神经根在椎管内垂直下行，与终丝共同组成马尾。
:::

::figure{src="/images/histology/textbook/p0288_01.png" caption="图26-9 在胚胎发育中脊髓与脊柱的变化及与成人对比示意图。左：2～3个月胎儿，脊髓和硬膜终止于近椎管末端，脊神经起始与相应椎间孔同一平面；右上：出生时脊髓末端邻近第3腰椎；中下：成人脊髓末端约在第1腰椎水平，终丝末端附着于尾椎，腰骶神经根与终丝组成马尾。" alt="三列椎骨侧面：左胎儿脊髓几乎下达尾端；右上新生儿脊髓止于L3附近；成人脊髓止于L1，下方蓝色神经根成马尾，终丝附于尾椎"}

:::timeline{period="脊髓外形、根和相对上移"}
- **第4周初** 神经沟闭合为神经管（见第一节）
- **脑泡形成同时** 神经管尾段保持细直管状，分化为脊髓
- **第4～5周** 脊髓区等粗圆柱状
- **第4周末** 脊神经前根出现；稍后神经嵴来的脊神经节发出后根
- **第3个月之前** 脊髓与脊柱等长，下端达尾骨；神经起始与相应椎间孔同一平面
- **第3个月后** 脊柱和硬脊膜长得比脊髓快，脊髓相对上移
- **第4个月** 颈膨大、腰膨大，分出颈、胸、腰、骶区和马尾
- **出生前** 脊髓下端平第3腰椎，终丝连尾骨；腰骶尾根垂直下行与终丝组成马尾
:::

:::cause-effect{title="脊柱长得快，神经根才斜行成马尾"}
- 因：脊神经在胚胎早期即按节段形成，并从相应椎间孔穿出
- 因：第3个月后脊柱和硬脊膜增长快于脊髓，脊髓相对上移
- 果：颈段以下神经根越来越向尾侧斜行，再找原来的椎间孔
- 果：腰、骶、尾根在椎管内垂直下行，与终丝共同组成马尾
- 制约：出生前下端平第3腰椎，不是成人的第1腰椎
:::

:::compare{title="第3个月前、出生前与成体的脊髓下端"}
| 项目 | 第 $3$ 个月之前 | 出生前 | 成体（图 26-9） |
|------|------------------|--------|-----------------|
| 与脊柱长度 | 等长 | 脊髓相对短 | 更短 |
| 下端 | 达尾骨 | 平第 $3$ 腰椎 | 约第 $1$ 腰椎水平 |
| 神经根与椎间孔 | 起始处与相应椎间孔同一平面 | 颈段以下斜行找原椎间孔 | 腰骶尾根垂直下行成马尾 |
| 终丝 | 尚未以终丝连尾骨为主要叙述 | 终丝连尾骨 | 终丝末端附于尾椎 |
:::

:::pitfall{label="出生前平第3腰椎，不要写成胚胎期已经停在成人的第1腰椎"}
第 $3$ 个月前下端还在尾骨；出生前才上移到第 $3$ 腰椎。成人约第 $1$ 腰椎是出生以后继续相对上移的结果，教材图 26-9 把三期画在一起，不要并成一句“脊髓一直平 L1”。
:::

:::example{label="为什么腰穿要选腰椎间隙"}
腰、骶、尾根已经在椎管内垂直下行组成马尾，出生前脊髓下端只到第 $3$ 腰椎。成人脊髓末端更高（约第 $1$ 腰椎），终丝和马尾占满下方椎管。这不是本节临床展开，但能反证“脊髓不再与脊柱等长”。
:::

:::tip{label="脊髓四板口诀"}
腹基板、背翼板，顶底板薄不增厚；基板挤出前正中裂，翼板融合后正中隔；前角运动、后角中间、侧角内脏传出。
:::

:::keypoint{label="尾段细管成脊髓，四板分灰质，脊柱快长出马尾"}
- 神经管尾段保持细直管状 → 脊髓；管腔 → 中央管；套层 → 灰质；边缘层 → 白质。
- 腹侧基板、背侧翼板、薄的顶板和底板；内表面界沟。
- 基板腹侧突出 → 前正中裂；翼板内移中线融合 → 管腔背侧份消失、后正中隔。
- 前角躯体运动，后角中间神经元，侧角内脏传出。
- 白质：灰质突起 + 胶质 + 脊神经节中枢突 + 内部联络纤维；周围间充质 → 脊膜。
- 第 $4\sim 5$ 周等粗圆柱；第 $4$ 周末前根，稍后后根；第 $4$ 个月颈、腰膨大。
- 第 $3$ 个月前与脊柱等长、下达尾骨；此后相对上移，出生前平第 $3$ 腰椎；腰骶尾根与终丝成马尾。
:::

:::memory{label="本节必背要点"}
- [ ] 脑泡形成的同时，神经管尾段仍保持较细的直管状，分化为脊髓。
- [ ] 该段神经管的管腔演化为脊髓中央管。
- [ ] 套层分化为脊髓灰质，边缘层分化为脊髓白质。
- [ ] 两侧壁因套层中成神经细胞和成胶质细胞增生而迅速增厚。
- [ ] 腹侧部增厚形成左、右基板，背侧部增厚形成左、右翼板。
- [ ] 顶壁和底壁相对薄而窄，分别形成顶板（roof plate）和底板（floor plate）。
- [ ] 基板和翼板增厚，神经管内表面出现左右相对的纵行界沟。
- [ ] 左右基板向腹侧突出，其间形成腹侧正中的前正中裂。
- [ ] 左右翼板向内侧推移并在中线融合，管腔背侧份消失，融合处形成后正中隔。
- [ ] 基板形成灰质前角（前柱），成神经细胞主要分化为躯体运动神经元。
- [ ] 翼板形成灰质后角（后柱），成神经细胞分化为中间神经元。
- [ ] 基板和翼板之间聚集的成神经细胞形成侧角（侧柱），分化为内脏传出神经元。
- [ ] 边缘层因灰质突起伸入和胶质产生而增厚，并含脊神经节中枢突和内部联络纤维，发育为白质。
- [ ] 神经管周围的间充质分化成脊膜。
- [ ] 胚胎第 $4\sim 5$ 周，整个脊髓区为等粗的圆柱形管状。
- [ ] 脊神经前根发生于第 $4$ 周末；稍后出现来自神经嵴的脊神经节后根。
- [ ] 第 $4$ 个月出现颈膨大和腰膨大，分出颈、胸、腰、骶区和马尾。
- [ ] 第 $3$ 个月之前脊髓与脊柱等长，下端达尾骨；脊神经起始与相应椎间孔同一平面。
- [ ] 第 $3$ 个月后脊柱和硬脊膜增长快于脊髓，脊髓相对上移。
- [ ] 出生前脊髓下端与第 $3$ 腰椎平齐，仅以终丝与尾骨相连。
- [ ] 脊髓上移后，颈段以下脊神经根向尾侧斜行，再经相应椎间孔出椎管。
- [ ] 腰、骶和尾段脊神经根在椎管内垂直下行，与终丝共同组成马尾。
