# 五、主要畸形

心脏和大血管的发生过程复杂，较易形成先天畸形。房间隔、室间隔、动脉干螺旋隔和动脉导管，哪一步该融未融、该闭未闭，就会落在这一节的名单上。卵圆孔未闭要按教材写全五种机制；法洛四联症的四条必须并列，不要只背“肺动脉狭窄”。

## 1. 房间隔缺损

房间隔缺损（atrial septal defect）最常见的为卵圆孔未闭。产生的原因为：①卵圆孔瓣出现许多穿孔；②第一房间隔吸收过度，导致卵圆孔瓣过短，不能完全遮盖卵圆孔；③第二房间隔发育不全，导致卵圆孔过大；④第二房间孔过大或吸收位置异常；⑤心内膜垫发育不全，第一房间隔不能与其融合。

:::definition{label="房间隔缺损"}
房间隔缺损（atrial septal defect）最常见的是卵圆孔未闭。它不是“房间隔没长出来”这一句就能概括的，教材列出五种机制。
:::

:::definition{label="卵圆孔未闭的五种机制"}
①卵圆孔瓣出现许多穿孔；②第一房间隔吸收过度，导致卵圆孔瓣过短，不能完全遮盖卵圆孔；③第二房间隔发育不全，导致卵圆孔过大；④第二房间孔过大或吸收位置异常；⑤心内膜垫发育不全，第一房间隔不能与其融合。五条都要能对上第二房间隔、第一房间隔（卵圆孔瓣）和心内膜垫。
:::

:::compare{title="卵圆孔未闭的五种机制"}
| 编号 | 停在哪一步 | 结果 |
|------|------------|------|
| ① | 卵圆孔瓣出现许多穿孔 | 瓣在，但漏许多孔 |
| ② | 第一房间隔吸收过度 | 卵圆孔瓣过短，遮不住卵圆孔 |
| ③ | 第二房间隔发育不全 | 卵圆孔过大，瓣盖不全 |
| ④ | 第二房间孔过大或吸收位置异常 | 两孔错位关系被破坏 |
| ⑤ | 心内膜垫发育不全 | 第一房间隔不能与心内膜垫融合 |
:::

:::pitfall{label="卵圆孔未闭不等于只有“瓣太短”这一种"}
五种机制分别动卵圆孔瓣（穿孔、过短）、第二房间隔（卵圆孔过大）、第二房间孔（过大或位置异常）和心内膜垫（第一房间隔不能与其融合）。只背②，考试写出①③④⑤会对不上教材。
:::

:::concept{term="先问是卵圆孔瓣、第二房间隔、第二房间孔还是心内膜垫出了问题"}
看见房间隔缺损，先认最常见的是卵圆孔未闭，再按五条对原基：瓣上穿孔；第一房间隔吸收过度导致瓣过短；第二房间隔发育不全导致卵圆孔过大；第二房间孔过大或吸收位置异常；心内膜垫发育不全，第一房间隔不能与其融合。把五种并成“隔没长好”，第二节里第一、第二房间隔和卵圆孔瓣的正常发生会失去对照。
:::

## 2. 室间隔缺损

室间隔缺损（ventricular septal defect）包括室间隔膜部和室间隔肌部缺损。其中室间隔膜部缺损最多见，多因心内膜垫的心内膜下组织增生和伸延不良，不能与心球嵴及室间隔肌部融合而致。室间隔肌部在形成时被吸收过多可致缺损，较少见。

:::definition{label="室间隔缺损"}
室间隔缺损（ventricular septal defect）包括膜部和肌部。膜部缺损最多见；肌部缺损较少见。
:::

:::definition{label="室间隔膜部缺损"}
最多见。多因心内膜垫的心内膜下组织增生和伸延不良，不能与心球嵴及室间隔肌部融合而致。膜部本来就是心球嵴、心内膜垫和室间隔肌部延伸共同封上的，三家对不齐就会留孔。
:::

:::definition{label="室间隔肌部缺损"}
室间隔肌部在形成时被吸收过多可致缺损，较少见。它不是膜部那本“融合不良”的账。
:::

:::compare{title="室间隔膜部缺损与肌部缺损"}
| 项目 | 膜部缺损 | 肌部缺损 |
|------|----------|----------|
| 频率 | 最多见 | 较少见 |
| 机制 | 心内膜垫的心内膜下组织增生和伸延不良，不能与心球嵴及室间隔肌部融合 | 室间隔肌部形成时被吸收过多 |
| 对照正常发生 | 第 $7$ 周末心球嵴 + 心内膜垫 + 肌部上缘融合，封闭室间孔 | 第 $4$ 周末心尖处向上的肌性隔 |
:::

:::pitfall{label="室间隔缺损最多见的是膜部，不是肌部"}
膜部靠三家融合，步骤多，所以最容易留孔。写成“肌部吸收过多最常见”，和教材相反。
:::

## 3. 动脉干与心球分隔异常

动脉干和心球靠一对心球嵴、动脉干嵴对生融合，隔必须螺旋走行，才能把主动脉接到左室、肺动脉干接到右室。隔走直了、偏到一侧，就会错位、狭窄或挤出法洛四联症。

### （1）主动脉和肺动脉错位

主动脉和肺动脉错位：由于主动脉肺动脉隔不呈螺旋状走行，形成直的间隔，导致主动脉位于肺动脉的前面，由右心室发出，肺动脉干发自左心室。该畸形多伴有室间隔膜部缺损或动脉导管未闭，使肺循环和体循环之间出现直接交通。

:::definition{label="主动脉和肺动脉错位"}
主动脉肺动脉隔不呈螺旋状走行，形成直的间隔。结果：主动脉位于肺动脉的前面，由右心室发出；肺动脉干发自左心室。左右心室接到了对方的大动脉。
:::

:::note{label="错位常伴交通"}
该畸形多伴有室间隔膜部缺损或动脉导管未闭，使肺循环和体循环之间出现直接交通。没有交通，两套循环无法交换血液。
:::

### （2）主动脉或肺动脉狭窄

主动脉或肺动脉狭窄：多由于主动脉肺动脉隔的发生部位偏于一侧，造成主动脉和肺动脉的分隔不均等。常伴有室间隔膜部缺损。

:::definition{label="主动脉或肺动脉狭窄"}
多由于主动脉肺动脉隔的发生部位偏于一侧，造成主动脉和肺动脉的分隔不均等。常伴有室间隔膜部缺损。隔偏到哪一侧，哪一侧的动脉就窄。
:::

### （3）法洛四联症

法洛四联症（tetralogy of Fallot）：主要原因是主动脉肺动脉隔偏于肺动脉一侧，导致 $4$ 种畸形并存：①肺动脉狭窄；②主动脉骑跨，粗大的主动脉骑跨在室间隔膜部；③室间隔缺损；④右心室肥大，由于肺动脉狭窄，右心室排血阻力增大，致使右心室壁逐渐肥厚（图 25-18）。

:::definition{label="法洛四联症"}
法洛四联症（tetralogy of Fallot）的主要原因是主动脉肺动脉隔偏于肺动脉一侧，导致 $4$ 种畸形并存，缺一条都不叫四联症。
:::

:::definition{label="法洛四联症的四条"}
①肺动脉狭窄；②主动脉骑跨，粗大的主动脉骑跨在室间隔膜部；③室间隔缺损；④右心室肥大——由于肺动脉狭窄，右心室排血阻力增大，致使右心室壁逐渐肥厚。前三条是原发组合，右室肥大是肺动脉狭窄后的继发肥厚。
:::

:::compare{title="动脉干与心球分隔异常的三种"}
| 畸形 | 隔怎么走偏 | 结果 | 常伴 |
|------|------------|------|------|
| 主动脉和肺动脉错位 | 不呈螺旋状，形成直的间隔 | 主动脉在肺动脉前面，发自右室；肺动脉干发自左室 | 室间隔膜部缺损或动脉导管未闭（两循环交通） |
| 主动脉或肺动脉狭窄 | 发生部位偏于一侧，分隔不均等 | 一侧粗、一侧窄 | 常伴室间隔膜部缺损 |
| 法洛四联症 | 隔偏于肺动脉一侧 | 四条并存：肺动脉狭窄、主动脉骑跨、室间隔缺损、右心室肥大 | 右室肥大继发于肺动脉狭窄 |
:::

:::example{label="法洛四联症四条必须列全"}
**题目**：法洛四联症的主要原因是什么？四种畸形各是哪一条？

**解**：主要原因是主动脉肺动脉隔偏于肺动脉一侧。四种并存：①肺动脉狭窄；②主动脉骑跨（粗大的主动脉骑跨在室间隔膜部）；③室间隔缺损；④右心室肥大（肺动脉狭窄使右室排血阻力增大，室壁逐渐肥厚）。只写“肺动脉狭窄加室缺”不算四联症。
:::

:::pitfall{label="法洛四联症不是“随便四种心脏畸形”"}
四条是固定组合，源头是隔偏于肺动脉一侧。右心室肥大是因为肺动脉狭窄后排血阻力增大，不是另起的一种原发隔异常。漏掉主动脉骑跨或把肥大写成“左室肥大”，四联症就不成立。
:::

:::cause-effect{title="主动脉肺动脉隔走直、走偏，决定错位、狭窄还是四联症"}
- 因：隔不呈螺旋状，形成直的间隔
- 果：主动脉发自右室、位于肺动脉前面，肺动脉干发自左室（错位）
- 因：隔的发生部位偏于一侧
- 果：两大动脉分隔不均等 → 主动脉或肺动脉狭窄；常伴室间隔膜部缺损
- 因：隔偏于肺动脉一侧
- 果：肺动脉狭窄 + 主动脉骑跨室间隔膜部 + 室间隔缺损；右室因排血阻力大而肥厚 → 法洛四联症
:::

## 4. 动脉导管未闭

动脉导管未闭（patent ductus arteriosus）较多见，女性为男性的 $2\sim 3$ 倍。主要原因是动脉导管过于粗大或出生后动脉导管肌纤维不能收缩，致使肺动脉和主动脉保持相通状态。

:::definition{label="动脉导管未闭"}
动脉导管未闭（patent ductus arteriosus）较多见，女性为男性的 $2\sim 3$ 倍。肺动脉和主动脉保持相通。
:::

:::definition{label="动脉导管未闭的原因"}
主要原因是动脉导管过于粗大，或出生后动脉导管肌纤维不能收缩。导管来自左侧第 $6$ 弓远侧段，出生后本应闭锁为动脉韧带。
:::

:::pitfall{label="动脉导管未闭是该闭未闭，不是又长出一条瘘"}
出生后肺循环量增大，肺动脉血不再向主动脉分流，导管才闭锁成动脉韧带。未闭是这条胎儿通路还在：过于粗大，或肌纤维不能收缩。不要写成“主动脉和肺动脉之间另外打了一孔”。
:::

:::compare{title="本节主要畸形对照"}
| 畸形 | 英文 | 最关键的一步 | 要点 |
|------|------|--------------|------|
| 房间隔缺损 | atrial septal defect | 卵圆孔未闭（五种机制） | 瓣穿孔／过短、卵圆孔过大、第二房间孔异常、心内膜垫不能与第一房间隔融合 |
| 室间隔缺损 | ventricular septal defect | 膜部最多见 | 心内膜垫组织增生伸延不良，不能与心球嵴及肌部融合；肌部吸收过多较少见 |
| 主动脉和肺动脉错位 | — | 隔走直、不呈螺旋 | 主动脉发自右室且在前，肺动脉干发自左室；常伴膜部缺损或导管未闭 |
| 主动脉或肺动脉狭窄 | — | 隔偏一侧，分隔不均等 | 常伴室间隔膜部缺损 |
| 法洛四联症 | tetralogy of Fallot | 隔偏于肺动脉一侧 | 肺动脉狭窄、主动脉骑跨、室间隔缺损、右心室肥大 |
| 动脉导管未闭 | patent ductus arteriosus | 该闭未闭 | 导管过粗或肌纤维不能收缩；女多于男 $2\sim 3$ 倍 |
:::

:::concept{term="先问该融未融还是该闭未闭，再问隔是走直、偏一侧还是偏向肺动脉"}
看见心血管畸形，先分两类。该融未融：房间隔（卵圆孔五种机制）、室间隔（膜部融合不良最多，肌部吸收过多较少）。该闭未闭：动脉导管（过粗或肌纤维不收缩，女多于男 $2\sim 3$ 倍）。动脉干隔：走直 → 错位；偏一侧 → 不均等狭窄；偏于肺动脉一侧 → 法洛四联症四条。把四联症听成“错位加狭窄”，螺旋隔和偏侧隔会并成一种病。
:::

:::insight{label="畸形就是正常分隔和出生后关闭停在半路"}
第一、第二房间隔和心内膜垫对不齐，就是房缺；膜部三家融不上，就是最常见的室缺；螺旋隔走直或走偏，就是错位、狭窄和四联症；动脉导管该变成韧带却还通着，就是导管未闭。按停在哪一步来认，名单可以从第二节、第三节和第四节推出来。
:::

:::timeline{period="畸形对照：正常发生停在哪一步"}
- **卵圆孔未闭（房缺最常见）** 瓣穿孔；第一房间隔吸收过度致瓣过短；第二房间隔发育不全致卵圆孔过大；第二房间孔过大或位置异常；心内膜垫发育不全，第一房间隔不能与其融合
- **室间隔膜部缺损（最多见）** 心内膜垫心内膜下组织增生和伸延不良，不能与心球嵴及室间隔肌部融合
- **室间隔肌部缺损（较少见）** 肌部形成时被吸收过多
- **错位** 主动脉肺动脉隔不呈螺旋，成直隔：主动脉发自右室且在前，肺动脉干发自左室
- **狭窄** 隔偏一侧，两大动脉分隔不均等
- **法洛四联症** 隔偏于肺动脉一侧：肺动脉狭窄、主动脉骑跨、室间隔缺损、右心室肥大
- **动脉导管未闭** 导管过粗或出生后肌纤维不能收缩；女为男的 2～3 倍
:::

:::tip{label="法洛四联症口诀"}
隔偏肺动脉一侧：肺窄、主骑跨、室缺、右室肥。肥大是狭窄把右室累出来的。
:::

:::keypoint{label="房缺五种机制，室缺膜部最多，四联症四条并列，导管未闭女多于男"}
- 房间隔缺损最常见卵圆孔未闭，五种机制都要能写全。
- 室间隔缺损含膜部和肌部；膜部最多见，因心内膜垫组织增生伸延不良，不能与心球嵴及肌部融合。
- 隔走直 → 主动脉肺动脉错位；隔偏一侧 → 不均等狭窄；隔偏肺动脉一侧 → 法洛四联症（肺动脉狭窄、主动脉骑跨、室间隔缺损、右心室肥大）。
- 动脉导管未闭较多见，女为男的 $2\sim 3$ 倍；过粗或肌纤维不能收缩，肺动脉与主动脉保持相通。
:::

## 本章小结

血管来自胚外的血岛和胚体内的间充质。心脏来源于生心区，继而分化为一对心管和围心腔。第 $3$ 周末，形成胚体循环、卵黄囊循环和脐循环，并执行功能。

由于心管不均等生长（形成心球、心室、心房和静脉窦膨大），以及心管头尾固定，其生长速度快于围心腔，致使心管卷曲，形成近似成体心脏外形。

心脏内部的分隔：①房室管：背腹心内膜垫融合，分隔为左、右房室管。②心房：相继形成第一房间隔和第二房间隔，保留的第二房间孔和卵圆孔上下错位，第一房间隔成为卵圆孔瓣膜，出生前实现心房的功能性分隔。③心室：源于室间隔肌部和室间隔膜部（来自心球嵴、心内膜垫和室间隔肌部的延伸）。④心球和动脉干：心球、动脉干嵴对生、融合，呈螺旋状走行，分隔为彼此缠绕的主动脉和肺动脉干。⑤静脉窦左角退化，形成冠状窦和左心房斜静脉根部；右角扩大被吸收，形成永久右心房固有部；肺静脉分支被吸收，形成永久左心房固有部。

胎儿血液循环有脐动脉和脐静脉、动脉导管和静脉导管、卵圆孔 $5$ 个特有结构。出生后分别为脐外侧韧带、肝圆韧带、动脉韧带、静脉韧带和卵圆窝。

主要畸形有房间隔缺损、室间隔缺损、动脉导管未闭和法洛四联症（肺动脉狭窄、主动脉骑跨、室间隔缺损和右心室肥大）。

:::definition{label="本章小结中的血管与心脏起源"}
血管来自胚外的血岛和胚体内的间充质。心脏来源于生心区，继而分化为一对心管和围心腔。第 $3$ 周末，胚体循环、卵黄囊循环和脐循环形成并执行功能。
:::

:::definition{label="本章小结中的心管卷曲"}
心管不均等生长，形成心球、心室、心房和静脉窦膨大；头尾固定，生长速度快于围心腔，心管卷曲，外形接近成体。
:::

:::definition{label="本章小结中的心脏内部分隔"}
①房室管：背腹心内膜垫融合，分成左、右房室管。②心房：第一、第二房间隔相继出现，第二房间孔与卵圆孔上下错位，第一房间隔成为卵圆孔瓣，出生前功能性分隔。③心室：肌部 + 膜部（心球嵴、心内膜垫和肌部延伸）。④心球和动脉干：嵴对生融合，螺旋走行，分成缠绕的主动脉和肺动脉干。⑤静脉窦左角 → 冠状窦和左心房斜静脉根部；右角被吸收 → 永久右心房固有部；肺静脉分支被吸收 → 永久左心房固有部。
:::

:::definition{label="本章小结中的五个特有结构"}
脐动脉、脐静脉、动脉导管、静脉导管、卵圆孔。出生后分别为脐外侧韧带、肝圆韧带、动脉韧带、静脉韧带和卵圆窝。正文写脐动脉大部分成脐侧韧带、近侧成膀胱上动脉；小结用“脐外侧韧带”收脐动脉这一条遗迹。
:::

:::note{label="法洛四联症"}
$1672$ 年由丹麦生理学家尼尔斯·斯坦森提出，$1888$ 年法国内科医生法洛做了全面描述，包括肺动脉狭窄、室间隔缺损、主动脉骑跨和右心室肥大，因此被命名为“法洛四联症”。

因肺动脉狭窄，右心室压力升高，与左心室压力接近或者相等；由于主动脉骑跨在左、右心室之上，故在心脏收缩期，右心室一部分血液与左心室的血液同时向增宽的主动脉根部喷射（听诊时在患者胸骨左缘第 $2\sim 4$ 肋间可听到粗糙的喷射样收缩期杂音）；由于大量未经氧合的血液直接经主动脉进入体循环，因此患者表现为不同程度的缺氧。典型的症状有①发绀：即唇、指（趾）甲床、球结膜等呈青紫色。②呼吸困难和活动耐力差：由于缺氧，体力与活动耐力都较同龄儿童差，患儿多举止缓慢，不喜喧嚷而爱好静。③蹲踞：是法洛四联症患者的特征性姿态，因蹲踞时发绀和呼吸困难减轻，可防止缺氧发作。由于右心房肥大、右心室肥厚，心电图表现为电轴右偏。胸部 X 线检查可见左心腰凹陷，心尖圆钝上翘，主动脉结突出，呈“靴形心”。超声心动图可从不同切面观察到室间隔缺损的类型和大小，主动脉骑跨于室间隔之上，肺动脉狭窄部位和程度等。彩色多普勒可显示右心室进入主动脉的分流。

先天性心脏病呈现一定程度的家族性发病趋势，与父母的生殖细胞或胚胎新发生的染色体畸变和基因突变等遗传因素密切相关。法洛四联症患儿的遗传物质变化复杂：有的是染色体异常，有的是染色体微缺失或重复，有的基因点突变（如 JAG1、NKX2-5 等）。
:::

:::memory{label="本节必背要点"}
- [ ] 心脏和大血管的发生过程复杂，较易形成先天畸形。
- [ ] 房间隔缺损（atrial septal defect）最常见的为卵圆孔未闭。
- [ ] 卵圆孔未闭机制①：卵圆孔瓣出现许多穿孔。
- [ ] 机制②：第一房间隔吸收过度，卵圆孔瓣过短，不能完全遮盖卵圆孔。
- [ ] 机制③：第二房间隔发育不全，导致卵圆孔过大。
- [ ] 机制④：第二房间孔过大或吸收位置异常。
- [ ] 机制⑤：心内膜垫发育不全，第一房间隔不能与其融合。
- [ ] 室间隔缺损（ventricular septal defect）包括膜部和肌部；膜部缺损最多见。
- [ ] 膜部缺损多因心内膜垫的心内膜下组织增生和伸延不良，不能与心球嵴及室间隔肌部融合。
- [ ] 肌部形成时被吸收过多可致缺损，较少见。
- [ ] 主动脉和肺动脉错位：主动脉肺动脉隔不呈螺旋状走行，形成直的间隔。
- [ ] 错位时主动脉位于肺动脉前面、由右心室发出，肺动脉干发自左心室。
- [ ] 错位多伴室间隔膜部缺损或动脉导管未闭，使肺循环与体循环直接交通。
- [ ] 主动脉或肺动脉狭窄：隔的发生部位偏于一侧，分隔不均等；常伴室间隔膜部缺损。
- [ ] 法洛四联症（tetralogy of Fallot）主要原因是主动脉肺动脉隔偏于肺动脉一侧。
- [ ] 四联症①肺动脉狭窄；②主动脉骑跨（粗大主动脉骑跨在室间隔膜部）；③室间隔缺损；④右心室肥大。
- [ ] 右心室肥大是因为肺动脉狭窄使右室排血阻力增大，室壁逐渐肥厚。
- [ ] 动脉导管未闭（patent ductus arteriosus）较多见，女性为男性的 $2\sim 3$ 倍。
- [ ] 未闭原因：动脉导管过于粗大，或出生后肌纤维不能收缩，肺动脉与主动脉保持相通。
