# 六、脉络丛和脑脊液

脉络丛（choroid plexus）是由第 3、4 脑室顶和部分侧脑室壁的软膜与室管膜直接相贴，突入脑室而形成的皱襞状结构，室管膜则成为有分泌功能的脉络丛上皮（图 8-14）。脉络丛上皮由一层矮柱状或立方形室管膜细胞组成，细胞质含较多线粒体，相邻细胞顶部之间有连接复合体。上皮外方的结缔组织含丰富的有孔毛细血管和巨噬细胞。

脉络丛上皮细胞不断分泌无色透明的脑脊液（cerebrospinal fluid），充满脑室、脊髓中央管、蛛网膜下隙和血管周隙，脑脊液有营养和保护脑与脊髓的作用。脑脊液最后被蛛网膜粒（蛛网膜突入颅静脉窦内的绒毛状突起）吸收进入血液（见图 8-11），从而形成脑脊液循环。

:::definition{label="脉络丛上皮"}
脉络丛上皮由一层矮柱状或立方形室管膜细胞组成，细胞质含较多线粒体，相邻细胞顶部之间有连接复合体。它不断分泌无色透明的脑脊液。
:::

:::definition{label="脑脊液"}
脑脊液（cerebrospinal fluid）由脉络丛上皮细胞分泌，无色透明，充满脑室、脊髓中央管、蛛网膜下隙和血管周隙，有营养和保护脑与脊髓的作用。
:::

:::definition{label="蛛网膜粒"}
蛛网膜粒是蛛网膜突入颅静脉窦内的绒毛状突起，脑脊液经此吸收进入血液，完成脑脊液循环。图 8-11 中可见其突入上矢状窦。
:::

:::concept{term="先问谁在分泌、谁在吸收：上皮出脑脊液，蛛网膜粒回血液"}
脉络丛把室管膜改写成分泌上皮，软膜带着有孔毛细血管贴上来，脑脊液从上皮顶面滴进脑室。液流经脑室、中央管、蛛网膜下隙和血管周隙营养并保护中枢，最后由蛛网膜粒送回颅静脉窦。分泌在室管膜侧，吸收在蛛网膜侧，中间走的是上一节已经立住的那些含脑脊液的腔。
:::

:::compare{title="脉络丛与血-脑屏障的毛细血管"}
| 项目 | 脉络丛 | 血-脑屏障处 |
|------|--------|--------------|
| 毛细血管类型 | 有孔毛细血管 | 连续型，内皮以紧密连接封闭 |
| 周围结构 | 结缔组织（含巨噬细胞）+ 脉络丛上皮 | 基膜 + 星形胶质细胞脚板；软膜和血管周隙已消失 |
| 上皮/胶质 | 一层矮柱状或立方形室管膜细胞，顶部有连接复合体 | 无室管膜；胶质膜为星形胶质细胞突起 |
| 物质走向 | 血液 → 有孔内皮 → 结缔组织 → 上皮分泌 → 脑脊液 | 血液中多数物质被挡住，营养和代谢产物选择通过 |
| 功能 | 生成脑脊液 | 维持神经组织内环境稳定 |
:::

:::pitfall{label="脉络丛用有孔毛细血管，不要写成血-脑屏障那套连续内皮"}
屏障处的毛细血管必须连续、紧密连接，才能挡住台盼蓝；脉络丛要分泌脑脊液，上皮外方写的是有孔毛细血管，便于血浆成分到达上皮。把脉络丛也画成星形胶质细胞脚板包连续内皮，脑脊液会分泌不出来。另：脉络丛上皮是室管膜的特化，不是软膜间皮，也不是普通立方腺上皮的“另一种腺体”。
:::

:::note{label="上皮外方还有巨噬细胞，结缔组织不是空的"}
皱襞轴心是富含有孔毛细血管和巨噬细胞的结缔组织，外面才是分泌上皮。线粒体多为分泌供能；顶部连接复合体把细胞侧面封住，使分泌定向进入脑室，而不是漏回结缔组织。
:::

:::insight{label="脑脊液循环把室管膜、蛛网膜下隙和静脉窦写成一条回路"}
上一节血管周隙与蛛网膜下隙相通，本节把脑室和中央管也接进同一液体系统。生成（脉络丛上皮）→ 充盈（脑室、中央管、蛛网膜下隙、血管周隙）→ 吸收（蛛网膜粒 → 颅静脉窦）。循环一旦受阻，受压的是被软膜紧贴着的脑和脊髓——保护账和压力账是同一条管道的两面。
:::

## 本章小结

神经系统主要由神经组织构成，分为中枢神经系统和周围神经系统。中枢神经系统主要由大脑、小脑和脊髓等组成。

大脑皮质分为 6 层：分子层、外颗粒层、外锥体细胞层、内颗粒层、内锥体细胞层和多形细胞层。其中的锥体细胞可分大、中、小 3 型，胞体发出一条粗的顶树突伸到分子层。轴突自胞体底部发出，短者不超出所在皮质范围，长者进入白质，组成投射纤维或联合传出纤维。尤其在内锥体细胞层，由大、中型锥体细胞组成，在中央前回有被称为贝兹细胞的巨大锥体细胞。

小脑皮质分为 3 层：分子层、浦肯野细胞层和颗粒层。浦肯野细胞层是由一层排列规则的浦肯野细胞胞体构成，它们是小脑皮质中最大的神经元，胞体呈梨形，顶端发出 $2\sim 3$ 条粗的主树突伸向分子层，分支繁密，呈扇状。轴突自胞体底部发出，离开皮质进入小脑白质，终止于其中的神经核。

脊髓灰质前角内有大、中、小 3 种神经元。大的称 $\alpha$ 运动神经元，轴突较粗，分布到骨骼肌。小的称 $\gamma$ 运动神经元，轴突较细，支配肌梭内的肌纤维。最小的神经元是闰绍细胞，其短轴突与 $\alpha$ 运动神经元形成突触，通过释放甘氨酸抑制 $\alpha$ 运动神经元的活动。

神经节可分脊神经节、脑神经节和自主神经节 3 种。脊神经节和脑神经节内均为感觉神经元，绝大部分是假单极神经元。自主神经节分为交感神经节和副交感神经节，内有多极运动神经元。

脑脊膜是包裹在脑和脊髓表面的结缔组织膜，分为硬膜、蛛网膜和软膜 3 层。

血-脑屏障由连续型毛细血管内皮细胞、基膜和神经胶质膜构成，能够选择性通过血液中的某些物质，维持神经组织内环境的稳定。

:::compare{title="本章小结：大脑皮质、小脑皮质与脊髓灰质"}
| 项目 | 大脑皮质 | 小脑皮质 | 脊髓灰质 |
|------|----------|----------|----------|
| 层次 | 6 层（分子层→外颗粒层→外锥体细胞层→内颗粒层→内锥体细胞层→多形细胞层） | 3 层（分子层、浦肯野细胞层、颗粒层） | 不分层，分前角、后角、侧角 |
| 主要传出细胞 | 锥体细胞、梭形细胞（投射 / 联合传出） | 浦肯野细胞（唯一传出，至白质神经核） | 前角 $\alpha$、$\gamma$；侧角内脏运动神经元 |
| 标志性大细胞 | 贝兹细胞（中央前回第 5 层） | 梨形浦肯野细胞，扇形树突 | $\alpha$ 运动神经元（$>25\,\mu\mathrm{m}$） |
| 局部抑制 | 高尔基Ⅱ型中间神经元（兴奋或抑制） | 篮状细胞、星形细胞、高尔基细胞 | 闰绍细胞以甘氨酸抑制 $\alpha$ |
:::

- 中枢：大脑、小脑、脊髓；周围：三种神经节及相应神经。
- 大脑六层，锥体细胞顶树突到分子层、轴突自底部发出；贝兹细胞在中央前回内锥体细胞层。
- 小脑三层，浦肯野细胞梨形扇状树突，唯一传出至神经核。
- 前角大中小：$\alpha$ 到骨骼肌，$\gamma$ 到肌梭，闰绍细胞甘氨酸抑制 $\alpha$。
- 感觉节假单极，自主节多极；脑脊膜三层；血-脑屏障连续内皮为主。
:::

## 插入框：大脑中空间定位与路径整合的神经机制

近一百年来，对大脑结构与功能的研究逐步揭示神经系统编码与解码的奥秘。其中一个具有里程碑意义的事件是 2014 年的诺贝尔生理学或医学奖授予 John O’Keefe、May-Britt Moser 和 Edvard I. Moser，以表彰他们发现大脑定位系统细胞的研究工作。

John O’Keefe 于 1971 年发现了大脑空间定位系统的第一个组成部分——位于海马区的“位置细胞”（place cell），这些细胞能够编码特定空间位置。其后，May-Britt Moser 和 Edvard I. Moser 夫妇于 2005 年发现了大脑空间定位系统的另一关键构成——位于内嗅皮层的“网格细胞”（grid cell），这些神经细胞能形成坐标系，可以精确定位和寻找路径。此外，科学家们陆续发现了其他参与创建“认知地图”的细胞。例如，James Ranck 发现了能够感知自身头面部方向的头朝向细胞（head direction cell）；John O’Keefe 用理论模型所预测的边界细胞（border cell）也在后续研究中得到证实，并被发现能够编码距离自身一定距离、呈特定角度的环境边界信息；Moser 夫妇进一步探索了这些细胞之间的关系，提出内嗅皮层犹如表征空间感的计算中心，网格细胞嵌入由头朝向细胞和边界细胞等组成的网络中，并投射到海马区的位置细胞，共同实现空间定位和导航。

进一步深入揭示大脑中空间定位与路径整合的神经机制，不仅可以为神经系统疾病和心理疾病的早期诊断及治疗提供科学依据，还将为计算机科学、工程学、人工智能及行为地理学等诸多领域带来重要启示和发展机遇。

:::definition{label="位置细胞"}
位置细胞（place cell）位于海马区，是大脑空间定位系统的组成部分，能够编码特定空间位置。由 John O’Keefe 于 1971 年发现。
:::

:::definition{label="网格细胞"}
网格细胞（grid cell）位于内嗅皮层，能形成坐标系，可以精确定位和寻找路径。由 May-Britt Moser 和 Edvard I. Moser 于 2005 年发现。
:::

:::definition{label="头朝向细胞"}
头朝向细胞（head direction cell）能够感知自身头面部方向，由 James Ranck 发现，参与创建“认知地图”。
:::

:::definition{label="边界细胞"}
边界细胞（border cell）由 O’Keefe 的理论模型所预测，后被证实能够编码距离自身一定距离、呈特定角度的环境边界信息。
:::

:::note{label="内嗅皮层把网格、头朝向和边界细胞织成计算中心"}
Moser 夫妇提出：内嗅皮层犹如表征空间感的计算中心；网格细胞嵌入由头朝向细胞和边界细胞等组成的网络中，并投射到海马区的位置细胞，共同实现空间定位和导航。插入框接回第一节：皮质可塑性与神经网络，是同一套“结构和功能一起改写”的账。
:::

| 细胞 | 英文 | 主要位置 | 编码内容 | 发现线索 |
|------|------|----------|----------|----------|
| 位置细胞 | place cell | 海马区 | 特定空间位置 | O’Keefe，1971 |

:::insight{label="定位系统是网络，不是单一种细胞"}
2014 年诺奖表彰的不是“发现了海马”，而是把位置细胞和网格细胞立为定位系统的关键构件。头朝向细胞和边界细胞随后补全认知地图；内嗅皮层计算、海马区位置细胞接收投射。病理诊断、人工智能和导航工程要借的，是这张网络的编码方式，而不是某一层皮质的六层名单本身。
:::
