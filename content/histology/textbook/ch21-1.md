# 一、生殖细胞和受精

从受精卵到胎儿出生，历时约 $266$ 天，分为胚前期、胚期和胎期 $3$ 个阶段。从胚前期到胚期，受精卵发育为初具人形的胚，这是胚胎发育的关键时期。第 $21$ 章写胚胎总体的发生过程，以及胚胎与母体的关系；胚体各系统的发生放在后面各章。本节先把生殖细胞、获能、顶体反应、卵子皮质反应（透明带反应）和受精摊开；胚泡形成与植入、胚层形成各立一节。

:::definition{label="胚胎发生总论的时间尺"}
人胚胎在子宫内发育约 $266$ 天。胚前期到胚期是受精卵变成初具人形之胚的关键窗口；胎期以生长和功能完善为主。本章只写总体发生和胚与母体的关系。
:::

## （一）生殖细胞

生殖细胞（germ cell）又称配子（gamete），包括精子和卵子。二者都是单倍体，必须在限定时间内于输卵管壶腹部相遇，才谈得上受精。

:::definition{label="生殖细胞"}
生殖细胞（germ cell）又称配子（gamete），包括精子和卵子。它们是单倍体细胞，本身还不是新个体。
:::

:::definition{label="精子"}
精子为单倍体细胞，核型为 $23,\mathrm{X}$ 或 $23,\mathrm{Y}$。射出后已具备定向运动的能力和使卵子受精的潜力，但尚无释放顶体酶、穿过放射冠和透明带的能力。
:::

:::definition{label="糖蛋白衣（阻止顶体酶释放）"}
精子头的外表面被一层来自精液的糖蛋白覆盖，能阻止顶体酶释放。这层衣不脱掉，顶体反应启动不了，精子也就穿不过放射冠和透明带。
:::

精子通过子宫和输卵管时，这些糖蛋白被去除，从而使精子获得了使卵子受精的能力，此现象称获能（capacitation）。获能是女性生殖管道里发生的功能成熟，不是精子在睾丸或附睾里又造了一遍。精子在女性生殖管道内的受精能力一般可维持 $24$ 小时。

:::definition{label="获能"}
获能（capacitation）指精子通过子宫和输卵管时，头部表面来自精液的糖蛋白被去除，从而获得释放顶体酶、使卵子受精的能力。获能后的精子才能进入后面的顶体反应。
:::

:::concept{term="先问精子过没过获能，再问卵子停在第几次减数分裂"}
看见“精子和卵子”，先不要写成“碰到就会受精”。精子这边先问糖蛋白衣脱了没有——没获能，顶体酶放不出，放射冠和透明带过不去。卵子这边先问停在哪一次分裂：从卵巢排出时已经是次级卵母细胞，停在第二次减数分裂中期，要等精子穿入才完成这次分裂。把“射出的精子”听成“已经能钻透明带”，或把排出的卵子听成“已经是完成减数分裂的卵”，后面的顶体反应和原核融合都会对错户头。
:::

:::compare{title="获能前与获能后的精子"}
| 项目 | 获能前（刚射出） | 获能后（过了子宫和输卵管） |
|------|------------------|------------------------------|
| 核型 | $23,\mathrm{X}$ 或 $23,\mathrm{Y}$，单倍体 | 仍是同一套单倍体核型 |
| 运动 | 已有定向运动能力 | 仍靠鞭毛运动 |
| 糖蛋白衣 | 头部表面有精液来源的糖蛋白 | 糖蛋白被去除 |
| 顶体酶 | 被糖蛋白阻止，不能释放 | 获得释放顶体酶的能力 |
| 穿过放射冠 / 透明带 | 尚无此能力 | 具备使卵子受精的潜力 |
| 受精能力维持 | 尚未真正获得 | 在女性生殖管道内一般维持 $24$ 小时 |
:::

从卵巢排出的卵子处于第二次减数分裂的中期，进入并停留在输卵管壶腹部。当与精子相遇、受到精子穿入其内的激发，卵子才完成第二次减数分裂。若未受精，则在排卵后 $12\sim 24$ 小时退化。

:::definition{label="排出的卵子"}
从卵巢排出的“卵子”处于第二次减数分裂中期（次级卵母细胞），停留在输卵管壶腹部。它还不是完成减数分裂的雌配子；要等精子穿入才把第二次减数分裂做完。
:::

:::definition{label="输卵管壶腹部"}
壶腹部是排出的卵子停留处，也是受精的常规地点。精子必须游到这里，才能与卵子在限定时间内相遇。
:::

:::note{label="两套时钟不要并成一句"}
精子在女性生殖管道内受精能力一般维持 $24$ 小时；卵子若未受精，排卵后 $12\sim 24$ 小时退化。两边都“能活一天左右”，但起点不同：精子从射入算起，卵子从排卵算起。错过窗口，不是“还能在子宫里等着受精”。
:::

:::pitfall{label="射出的精子还不能受精，排出的卵子也还停在第二次减数分裂中期"}
精子的运动能力和获能不是一回事。刚射出的精子有鞭毛、有潜力，但头上还有糖蛋白衣，顶体酶放不出。卵子排出时已经不是初级卵母细胞，可也还没做完第二次减数分裂。把这两步写成“成熟配子一排出就能结合”，顶体反应和皮质反应就没有地方可放。
:::

:::timeline{period="从排卵到卵子退化"}
- **排卵** 次级卵母细胞 + 透明带 + 放射冠离开卵巢，进入输卵管，停在壶腹部；核停在第二次减数分裂中期
- **限定窗口** 精子需已获能并抵达壶腹；卵子等待精子穿入以完成第二次减数分裂
- **$12\sim 24$ 小时未受精** 卵子退化，受精的基本条件不再成立
:::

## （二）受精

受精（fertilization）指精子与卵子结合形成受精卵的过程，一般发生在输卵管壶腹部。正常成年男性每次射出上亿个精子，其中 $300\sim 500$ 个最强壮的精子能通过鞭毛运动抵达输卵管壶腹部。虽然最终只有一个精子能与卵子结合，但其他精子的协助作用也必不可少——没有它们一起溶蚀放射冠，那一个精子到不了透明带。

:::definition{label="受精"}
受精（fertilization）指精子与卵子结合形成受精卵的过程，一般发生在输卵管壶腹部。终点是二倍体的受精卵（合子），不是“精子贴上卵子”这一下。
:::

:::definition{label="抵达壶腹的精子数"}
每次射出上亿个精子，其中 $300\sim 500$ 个最强壮者能靠鞭毛运动抵达输卵管壶腹部。最终只有一个进入卵子，其余在溶蚀放射冠等步骤中提供协助。
:::

受精的过程可分为 $3$ 个阶段（图 21-1）。

第一阶段，大量获能的精子接触到卵子周围的放射冠时，即释放顶体酶，解离放射冠的卵泡细胞，这样部分精子可直接触及透明带。

第二阶段，接触到透明带的精子与透明带上的精子配体蛋白 ZP3 结合，后者进一步介导顶体反应，使顶体继续释放顶体酶，在透明带中溶蚀出一条孔道，使精子头部接触到卵子表面。精子释放顶体酶、溶蚀放射冠和透明带的过程称顶体反应（acrosome reaction）。在这一反应过程中，顶体的前膜与精子头部表面的细胞膜融合后破裂，形成许多小孔，顶体内含的酶类得以排出。

第三阶段，精子头侧面细胞膜与卵子细胞膜融合，随即精子的细胞核及细胞质进入卵子内，精子与卵子的细胞膜融合为一体。精卵结合后，卵子浅层细胞质内的皮质颗粒（cortical granule）立即释放溶酶体酶，使透明带结构发生变化，特别是使 ZP3 分子变性，不能再与精子结合，从而阻止了其他精子穿越透明带，这一过程称透明带反应（zona reaction），保证了正常的单精受精。皮质颗粒的释放本身也称卵子的皮质反应。偶尔也有两个精子同时进入卵子，但三倍体的胚胎或者中途流产，或者出生后夭亡。

:::definition{label="放射冠（受精现场）"}
放射冠是紧贴透明带的一层卵泡细胞。获能精子首先在这里释放顶体酶，把卵泡细胞解离，部分精子才能直接触及透明带。
:::

:::definition{label="ZP3"}
ZP3 是透明带上的精子配体蛋白。接触到透明带的精子与 ZP3 结合，进一步介导顶体反应。透明带反应后 ZP3 变性，不能再与精子结合。
:::

:::definition{label="顶体反应"}
顶体反应（acrosome reaction）指精子释放顶体酶、溶蚀放射冠和透明带的过程。机制上，顶体前膜与精子头部细胞膜融合后破裂，形成许多小孔，顶体内酶类排出。它从第一阶段接触放射冠时已经开始，并在 ZP3 介导下于透明带中继续完成。
:::

:::definition{label="皮质颗粒"}
皮质颗粒（cortical granule）位于卵子浅层细胞质，是一种溶酶体。精卵结合后立即释放溶酶体酶，启动皮质反应和随后的透明带反应。
:::

:::definition{label="皮质反应"}
皮质反应指精卵结合后，卵子浅层皮质颗粒立即释放溶酶体酶。它是卵子侧阻止多精受精的第一步，作用对象在卵子浅层胞质。
:::

:::definition{label="透明带反应"}
透明带反应（zona reaction）指皮质颗粒释放的酶使透明带结构发生变化，特别是使 ZP3 分子变性，不能再与精子结合，从而阻止其他精子穿越透明带。它保证正常的单精受精。
:::

:::definition{label="单精受精"}
正常情况下最终只有一个精子的细胞核及细胞质进入卵子。透明带反应把后续精子挡在透明带外。两个精子同时进入则形成三倍体，胚胎多中途流产或出生后夭亡。
:::

:::compare{title="受精的三个阶段"}
| 项目 | 第一阶段 | 第二阶段 | 第三阶段 |
|------|----------|----------|----------|
| 精子位置 | 接触放射冠 | 接触并穿越透明带 | 精子头侧面膜与卵膜融合，核与质进入卵内 |
| 关键分子 / 结构 | 顶体酶解离放射冠卵泡细胞 | 精子与 ZP3 结合，顶体继续释放酶，溶蚀孔道 | 皮质颗粒释放溶酶体酶 |
| 反应名称 | 顶体反应已经启动 | 顶体反应在透明带中完成 | 皮质反应 → 透明带反应 |
| 结果 | 部分精子直接触及透明带 | 精子头部接触卵子表面 | 精卵细胞膜融为一体；ZP3 变性，阻止其他精子 |
:::

:::pitfall{label="获能、顶体反应、皮质反应、透明带反应不是同一个动作"}
获能发生在子宫和输卵管，脱掉糖蛋白衣，还没有打孔。顶体反应是精子释放顶体酶，溶蚀放射冠和透明带。皮质反应是卵子浅层皮质颗粒释放溶酶体酶。透明带反应是这些酶让透明带、尤其是 ZP3 变性，把后面的精子挡在门外。四步不要并成“精子一靠近就受精”。
:::

:::insight{label="透明带先当门，再当锁"}
ZP3 让顶体完整、已经获能的精子认门、打孔；精卵一结合，皮质颗粒就把这把锁改掉，ZP3 变性，后来者进不去。同一条透明带，先是受精的通道，随即变成单精受精的屏障。把 ZP3 只写成“精子受体”而不写它随后变性，单精这本账会做丢。
:::

与此同时，卵子迅速完成第二次减数分裂，并产生一个几乎没有细胞质的第二极体。此时精子和卵子的细胞核膨大，分别称为雄原核（male pronucleus）和雌原核（female pronucleus）。两个原核逐渐在细胞中部靠拢，核膜消失，染色体混合，形成二倍体的受精卵（fertilized ovum），又称合子（zygote）（图 21-2，图 21-3），受精过程到此完成。进入卵子的精子尾部结构退化消失。

:::definition{label="第二极体"}
卵子在精子穿入激发下完成第二次减数分裂，产生一个几乎没有细胞质的第二极体。它不是雌原核，也不参与组成二倍体核型。
:::

:::definition{label="雄原核与雌原核"}
进入卵子后，精子和卵子的细胞核膨大，分别称为雄原核（male pronucleus）和雌原核（female pronucleus）。二者在细胞中部靠拢，核膜消失，染色体混合。
:::

:::definition{label="受精卵"}
受精卵（fertilized ovum）又称合子（zygote），是雌、雄原核染色体混合后形成的二倍体细胞。受精至此完成；随后才开始卵裂。进入卵子的精子尾部结构退化消失。
:::

:::compare{title="雄原核、雌原核与受精卵"}
| 项目 | 雄原核 | 雌原核 | 受精卵（合子） |
|------|--------|--------|----------------|
| 来源 | 进入卵子的精子细胞核膨大 | 完成第二次减数分裂后的卵子细胞核膨大 | 两原核靠拢，核膜消失，染色体混合 |

:::

:::timeline{period="从获能精子入壶腹到合子形成"}
- **抵达** $300\sim 500$ 个获能精子靠鞭毛到达输卵管壶腹部
- **第一阶段** 顶体酶解离放射冠，部分精子触及透明带
- **第二阶段** 与 ZP3 结合，顶体反应在透明带中溶蚀孔道，头部接触卵膜
- **第三阶段** 精子头侧面膜与卵膜融合，核与质进入；皮质颗粒释放 → 透明带反应，保证单精受精
- **同时** 卵子完成第二次减数分裂，排出第二极体；雌、雄原核形成、靠拢、核膜消失、染色体混合
- **完成** 二倍体受精卵（合子）形成；精子尾部退化消失
:::

发育正常并已获能的精子与发育正常的卵子在限定的时间相遇，是受精的基本条件。应用避孕套、子宫帽、输卵管或输精管结扎等措施，可阻止精子与卵子相遇，达到避孕目的。

:::note{label="受精的基本条件"}
三条同时成立才谈得上受精：① 精子发育正常并且已经获能；② 卵子发育正常；③ 二者在限定时间内于输卵管壶腹部相遇。缺任何一条，后面的顶体反应和原核融合都不会发生。避孕套、子宫帽、输卵管或输精管结扎，正是切断“相遇”这一条。
:::

:::pitfall{label="最终一个精子进入，不要写成只靠那一个精子就能穿过放射冠"}
教材写明：虽然最终只有一个精子与卵子结合，但其他精子的协助必不可少。第一阶段是大量获能精子一起释放顶体酶、解离放射冠。把受精写成“冠军精子独自钻进去”，会漏掉 $300\sim 500$ 个抵达者的集体溶蚀作用。
:::

受精的意义在于：① 精子与卵子结合，恢复了细胞的二倍体核型；同时，来自双亲的遗传物质随机组合，加之生殖细胞在减数分裂时曾发生染色体联合和片段交换，因此由受精卵发育而来的新个体既维持了双亲的遗传特点，又具有与亲代不完全相同的性状。② 受精决定新个体的遗传性别。带有 Y 染色体的精子与卵子结合，发育为男性；带有 X 染色体的精子与卵子结合，发育为女性。③ 精子进入卵子，使原本相对静止的卵子转入旺盛的能量代谢与生化合成，受精卵开始进行细胞分裂，启动了胚胎发育的进程。

:::definition{label="受精恢复二倍体"}
精子与卵子结合，把两个单倍体核型重新合成二倍体。新个体的基因组来自双亲的随机组合，再加上减数分裂时的染色体联合和片段交换，故既像双亲，又与亲代不完全相同。
:::

:::definition{label="受精决定遗传性别"}
带有 Y 染色体的精子与卵子结合，发育为男性；带有 X 染色体的精子与卵子结合，发育为女性。遗传性别在受精这一刻已经写下，不是植入之后才决定。
:::

:::definition{label="受精启动胚胎发育"}
精子进入使原本相对静止的卵子转入旺盛的能量代谢与生化合成，受精卵开始细胞分裂，胚胎发育的进程从此启动。没有这一步，卵子会在排卵后 $12\sim 24$ 小时退化。
:::

:::insight{label="受精同时做三件事：核型、性别、开关"}
同一过程里有三本账：核型从单倍体回到二倍体并发生遗传重组；性染色体组合写下男女；代谢从相对静止被打开，后面的卵裂才有动力。只记“精卵结合成一个细胞”，会把性别决定和启动分裂两本账漏掉。
:::

:::compare{title="受精的三项意义"}
| 意义 | 内容 | 不要听成 |
|------|------|----------|
| 恢复二倍体并重组 | 单倍体 + 单倍体 → 二倍体；双亲遗传物质随机组合，加上减数分裂时的联合与片段交换 | 只是“细胞变大了” |
| 决定遗传性别 | Y 精子 → 男性；X 精子 → 女性 | 性别由子宫环境或植入部位决定 |
| 启动发育 | 卵子从相对静止转入旺盛代谢与合成，开始细胞分裂 | 卵裂是排卵后自动发生的 |
:::

:::keypoint{label="获能开门，顶体反应打孔，皮质反应上锁，原核融合才叫受精完成"}
- 精子核型 $23,\mathrm{X}$ 或 $23,\mathrm{Y}$，有运动能力和受精潜力，但必须获能后才能释放顶体酶。
- 获能：子宫和输卵管去掉头部糖蛋白衣；受精能力一般维持 $24$ 小时。
- 排出的卵子停在第二次减数分裂中期，留在输卵管壶腹部；未受精则 $12\sim 24$ 小时退化。
- 受精一般在壶腹部；上亿精子中 $300\sim 500$ 个抵达，最终一个进入，其余协助解离放射冠。
- 三阶段：放射冠 → ZP3 / 透明带 → 膜融合；顶体反应贯穿前两段。
- 皮质颗粒释放（皮质反应）使 ZP3 变性（透明带反应），保证单精受精；双精进入成三倍体，不能正常发育。
- 卵子完成第二次减数分裂，出第二极体；雌、雄原核融合形成二倍体受精卵（合子）。
- 受精意义：恢复二倍体并重组、决定遗传性别、启动卵裂。
:::

:::memory{label="本节必背要点"}
- [ ] 从受精卵到胎儿出生约 $266$ 天，分为胚前期、胚期和胎期；胚前期到胚期是发育为初具人形之胚的关键时期。
- [ ] 生殖细胞（germ cell）又称配子（gamete），包括精子和卵子。
- [ ] 精子为单倍体，核型为 $23,\mathrm{X}$ 或 $23,\mathrm{Y}$；有定向运动能力和使卵子受精的潜力。
- [ ] 刚射出的精子尚无释放顶体酶、穿过放射冠和透明带的能力。
- [ ] 精子头外表面被一层来自精液的糖蛋白覆盖，阻止顶体酶释放。
- [ ] 获能（capacitation）：精子通过子宫和输卵管时糖蛋白被去除，从而获得受精能力。
- [ ] 精子在女性生殖管道内的受精能力一般可维持 $24$ 小时。
- [ ] 从卵巢排出的卵子处于第二次减数分裂中期，进入并停留在输卵管壶腹部。
- [ ] 卵子受到精子穿入激发才完成第二次减数分裂；未受精则在排卵后 $12\sim 24$ 小时退化。
- [ ] 受精（fertilization）指精子与卵子结合形成受精卵，一般发生在输卵管壶腹部。
- [ ] 每次射出上亿个精子，其中 $300\sim 500$ 个最强壮者抵达壶腹部。
- [ ] 最终只有一个精子与卵子结合，但其他精子的协助必不可少。
- [ ] 第一阶段：获能精子接触放射冠，释放顶体酶，解离放射冠卵泡细胞，部分精子触及透明带。
- [ ] 第二阶段：精子与透明带上的 ZP3 结合，进一步介导顶体反应，在透明带中溶蚀孔道，头部接触卵子表面。
- [ ] 顶体反应（acrosome reaction）：精子释放顶体酶、溶蚀放射冠和透明带的过程。
- [ ] 顶体反应时，顶体前膜与精子头部细胞膜融合后破裂，形成许多小孔，酶类排出。
- [ ] 第三阶段：精子头侧面细胞膜与卵子细胞膜融合，细胞核及细胞质进入卵子，两膜融为一体。
- [ ] 皮质颗粒（cortical granule）位于卵子浅层细胞质，精卵结合后立即释放溶酶体酶。
- [ ] 皮质反应：皮质颗粒释放溶酶体酶。
- [ ] 透明带反应（zona reaction）：透明带结构变化，尤其 ZP3 变性，不能再与精子结合，阻止其他精子穿越。
- [ ] 透明带反应保证正常的单精受精。
- [ ] 两个精子同时进入则形成三倍体胚胎，或中途流产，或出生后夭亡。
- [ ] 卵子迅速完成第二次减数分裂，产生一个几乎没有细胞质的第二极体。
- [ ] 精子和卵子的细胞核膨大，分别称为雄原核（male pronucleus）和雌原核（female pronucleus）。
- [ ] 两个原核在细胞中部靠拢，核膜消失，染色体混合，形成二倍体受精卵（fertilized ovum），又称合子（zygote）。
- [ ] 进入卵子的精子尾部结构退化消失。
- [ ] 受精的基本条件：发育正常并已获能的精子与发育正常的卵子在限定时间相遇。
- [ ] 避孕套、子宫帽、输卵管或输精管结扎等可阻止精卵相遇。
- [ ] 受精意义①：恢复二倍体核型；双亲遗传物质随机组合，加上减数分裂时染色体联合和片段交换，新个体既维持双亲特点又与亲代不完全相同。
- [ ] 受精意义②：决定遗传性别；Y 精子与卵子结合发育为男性，X 精子与卵子结合发育为女性。
- [ ] 受精意义③：精子进入使相对静止的卵子转入旺盛代谢与生化合成，受精卵开始分裂，启动胚胎发育。
:::
