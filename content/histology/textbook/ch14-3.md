# 三、食管

食管（esophagus）是运送食物到胃的通道。从这一段开始，管壁重新按黏膜、黏膜下层、肌层、外膜四层来读：腔面纵行皱襞可随食团展平；上皮是未角化复层扁平；黏液性食管腺埋在黏膜下层；肌层从上到下由骨骼肌过渡为平滑肌；外膜是纤维膜。下端与胃贲门的上皮骤然相接，是食管癌的易发部位。

:::definition{label="食管"}
食管（esophagus）是运送食物到胃的通道。腔面有由黏膜和黏膜下层形成的纵行皱襞，食物通过时管腔扩大，皱襞消失（图 14-8～图 14-10）。
:::

:::concept{term="先问上皮是不是未角化复层扁平，再问肌层这一段是骨骼肌还是平滑肌"}
食管不吸收营养，职分是把食团安全送到胃。上皮用未角化复层扁平抗摩擦；黏液由黏膜下层的食管腺涂在表面；肌层上 $1/3$ 骨骼肌、下 $1/3$ 平滑肌、中 $1/3$ 兼有。切片上先认皱襞和复层扁平，再在肌层里找横纹。把食管写成“单层柱状的消化管”，贲门交界和食管癌好发部位那一本账会从上皮就写反。
:::

## 1. 黏膜

上皮为未角化的复层扁平上皮，在食物通过时起机械性保护作用。食管下端的复层扁平上皮与胃贲门部的单层柱状上皮骤然相接，是食管癌的易发部位。固有层为细密的结缔组织，并形成乳头突向上皮。在食管上段与下段的固有层内可见少量黏液腺。黏膜肌层由纵行平滑肌束组成。

:::definition{label="食管黏膜上皮"}
食管上皮为未角化的复层扁平上皮，食物通过时起机械性保护作用。
:::

:::definition{label="食管–贲门上皮交界"}
食管下端的复层扁平上皮与胃贲门部的单层柱状上皮骤然相接，是食管癌的易发部位。
:::

:::definition{label="食管固有层"}
食管固有层为细密的结缔组织，并形成乳头突向上皮。上段与下段的固有层内可见少量黏液腺。
:::

:::definition{label="食管黏膜肌层"}
食管黏膜肌层由纵行平滑肌束组成，是黏膜与黏膜下层的分界。
:::

:::pitfall{label="食管固有层里那点黏液腺不是食管腺"}
上段、下段固有层可以有少量黏液腺，但教材把食管腺（esophageal gland）明确写在黏膜下层：黏液性，导管穿过黏膜开口于管腔。把黏膜下层那团腺泡当成固有层腺体，导管、淋巴细胞浸润和皱襞分层账都会错位。
:::

:::compare{title="食管两端上皮与胃贲门"}
| 项目 | 食管上皮 | 胃贲门上皮 |
|------|----------|------------|
| 类型 | 未角化复层扁平 | 单层柱状（表面黏液细胞） |
| 功能 | 机械性保护 | 分泌黏液，开始胃黏膜屏障 |
| 交界 | 下端骤然相接 | 可见胃小凹（图 14-10） |
| 临床 | 交界处是食管癌易发部位 | — |
:::

## 2. 黏膜下层

黏膜下层为较致密的结缔组织，内含黏液性的食管腺（esophageal gland），其导管穿过黏膜开口于食管腔，分泌的黏液涂布于食管表面，利于食物通过。食管腺周围常有较密集的淋巴细胞及浆细胞，甚至淋巴小结。

:::definition{label="食管腺"}
食管腺（esophageal gland）是黏膜下层内的黏液性腺。导管穿过黏膜开口于食管腔，分泌的黏液涂布于食管表面，利于食物通过。腺周围常有较密集的淋巴细胞及浆细胞，甚至淋巴小结。
:::

:::insight{label="黏液涂在复层扁平表面，食团才滑得过去"}
食管不上皮吸收，也不像胃那样用单层柱状做黏液膜。润滑靠黏膜下层食管腺把黏液送到腔面。皱襞在食团通过时展平，管腔扩大，黏液减少摩擦。把润滑只记在“上皮分泌”，会找不到食管腺的位置。
:::

## 3. 肌层

肌层分内环行与外纵行两层。上 $1/3$ 段为骨骼肌，下 $1/3$ 段为平滑肌，中 $1/3$ 段则兼具两者。食管两端的内环行肌稍厚，分别形成食管上、下括约肌。

:::definition{label="食管肌层"}
食管肌层分内环行与外纵行两层。上 $1/3$ 段为骨骼肌，下 $1/3$ 段为平滑肌，中 $1/3$ 段兼具两者。
:::

:::definition{label="食管上、下括约肌"}
食管两端的内环行肌稍厚，分别形成食管上、下括约肌。
:::

:::concept{term="上中下三段肌层，先问骨骼肌占多少"}
吞咽起始带随意成分，所以上段是骨骼肌；入胃前要持续蠕动，下段改成平滑肌；中段是过渡，两种肌纤维都有。不要把“消化管肌层=平滑肌”套到食管全程，也不要把括约肌写成第三层斜行肌——那是胃的账。
:::

:::compare{title="食管肌层上、中、下段"}
| 分段 | 肌组织 | 层次 | 附加 |
|------|--------|------|------|
| 上 $1/3$ | 骨骼肌 | 内环行、外纵行 | 近端内环行肌增厚成食管上括约肌 |
| 中 $1/3$ | 骨骼肌与平滑肌兼具 | 同左 | 过渡段 |
| 下 $1/3$ | 平滑肌 | 同左 | 远端内环行肌增厚成食管下括约肌 |
:::

:::pitfall{label="括约肌是内环行肌增厚，不要写成另加的一层斜行肌"}
食管肌层始终是内环、外纵两层。上、下括约肌只是两端内环行肌稍厚。斜行肌出现在胃（内斜、中环、外纵）。把食管下括约肌听成“胃的内斜肌延伸”，贲门交界的上皮骤变账会和肌层账缠在一起。
:::

## 4. 外膜

外膜为纤维膜。

:::definition{label="食管外膜"}
食管外膜为纤维膜，由疏松结缔组织组成，与周围组织相连，无间皮。
:::

:::compare{title="食管壁四层"}
| 层次 | 结构要点 | 光镜落点 |
|------|----------|----------|
| 黏膜 | 未角化复层扁平上皮；固有层细密、乳头突向上皮；上、下段固有层可有少量黏液腺；黏膜肌为纵行平滑肌束 | 图 14-9：1 上皮，2 固有层，3 黏膜肌层 |
| 黏膜下层 | 较致密结缔组织；黏液性食管腺，导管开口于腔面；腺周常有淋巴细胞、浆细胞甚至淋巴小结 | 图 14-8、图 14-9：4 导管，5 黏膜下层，6 腺泡 |
| 肌层 | 内环外纵；上 $1/3$ 骨骼肌，中 $1/3$ 混合，下 $1/3$ 平滑肌；两端内环行肌增厚成上、下括约肌 | 图 14-8 环行肌与纵行肌 |
| 外膜 | 纤维膜 | 图 14-8 最外层 |
:::

:::insight{label="皱襞、黏液和肌层过渡，三件事保证食团只过路、不停留伤害上皮"}
纵行皱襞让空管腔缩小、有食团时扩大；食管腺黏液减摩擦；肌层从骨骼肌过渡到平滑肌，把随意吞咽接成不随意蠕动。下端上皮骤变是结构界面，也是肿瘤好发的组织学理由。
:::

:::keypoint{label="食管按四层读：复层扁平、黏膜下腺、骨骼肌–平滑肌过渡、纤维膜"}
- 腔面纵行皱襞 = 黏膜 + 黏膜下层；食团通过时展平。
- 上皮未角化复层扁平；下端与贲门单层柱状骤然相接，为食管癌易发部位。
- 食管腺在黏膜下层，黏液性，导管开口于腔面；腺周常有淋巴组织。
- 肌层内环外纵：上 $1/3$ 骨骼肌，中 $1/3$ 混合，下 $1/3$ 平滑肌；两端内环行肌形成上、下括约肌。
- 外膜为纤维膜。黏膜肌层是纵行平滑肌束。
:::
