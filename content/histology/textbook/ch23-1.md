# 一、消化系统的发生

人胚第 $3\sim 4$ 周，圆柱状胚体形成时，卵黄囊顶部的内胚层被包卷入胚体内，形成原始消化管。头段称前肠（foregut），尾段称后肠（hindgut），与卵黄囊相连的中段称中肠（midgut）。黏膜上皮、腺上皮和肺泡上皮来自内胚层；结缔组织、肌组织、血管内皮和外表面的间皮来自中胚层。本节先把前肠、中肠、后肠的分化范围立住，再按咽囊、甲状腺、食管和胃、肠袢、泄殖腔、肝胆胰与主要畸形摊开。

人胚第 $3\sim 4$ 周时，随着圆柱状胚体的形成，卵黄囊顶部的内胚层被包卷入胚体内，形成原始消化管，其头段称前肠（foregut），尾段称后肠（hindgut），与卵黄囊相连的中段称中肠（midgut）。前肠分化为部分口腔底、舌、咽至十二指肠的上段、肝、胆囊、胆管、下颌下腺、舌下腺、胰腺以及喉以下的呼吸道、肺、胸腺、甲状腺和甲状旁腺等器官；中肠分化为从十二指肠中段至横结肠右 $2/3$ 部的肠管；后肠分化为自横结肠左 $1/3$ 至肛管上段的消化管以及膀胱和尿道的大部分（图 23-1）。这些器官中的黏膜上皮、腺上皮和肺泡上皮均来自内胚层，结缔组织、肌组织、血管内皮和外表面的间皮均来自中胚层。

:::definition{label="原始消化管"}
人胚第 $3\sim 4$ 周，圆柱状胚体形成时，卵黄囊顶部的内胚层被包卷入胚体内，形成原始消化管。它按与卵黄囊的关系分成前肠、中肠和后肠三段。
:::

:::definition{label="前肠"}
前肠（foregut）是原始消化管的头段。分化为部分口腔底、舌、咽至十二指肠的上段、肝、胆囊、胆管、下颌下腺、舌下腺、胰腺，以及喉以下的呼吸道、肺、胸腺、甲状腺和甲状旁腺等器官。
:::

:::definition{label="中肠"}
中肠（midgut）是与卵黄囊相连的中段。分化为从十二指肠中段至横结肠右 $2/3$ 部的肠管。
:::

:::definition{label="后肠"}
后肠（hindgut）是原始消化管的尾段。分化为自横结肠左 $1/3$ 至肛管上段的消化管，以及膀胱和尿道的大部分。
:::

:::definition{label="消化管与呼吸道的胚层分工"}
这些器官中的黏膜上皮、腺上皮和肺泡上皮均来自内胚层；结缔组织、肌组织、血管内皮和外表面的间皮均来自中胚层。上皮走内胚层，支架和血管走中胚层，两本账不要并成“整段肠管都是内胚层”。
:::

:::concept{term="先问这是前肠、中肠还是后肠，再问上皮是内胚层还是支架来自中胚层"}
看见原始消化管，先按卵黄囊把三段切开：头段前肠，连卵黄囊的中段中肠，尾段后肠。再问衍化物：十二指肠上段、肝胆胰、喉以下呼吸道和肺、胸腺甲状腺甲状旁腺都在前肠户头；十二指肠中段到横结肠右 $2/3$ 是中肠；横结肠左 $1/3$ 到肛管上段、膀胱和尿道大部分是后肠。最后问胚层：上皮（黏膜、腺、肺泡）内胚层，结缔组织、肌、血管内皮、间皮中胚层。把肺听成“呼吸系统所以不是前肠”，或把整条肠壁都写成内胚层，后面的咽囊和肝憩室会对错户头。
:::

:::pitfall{label="前肠不只是“从咽到胃”，喉以下呼吸道、肺和咽囊器官也在前肠户头"}
前肠名单里既有咽至十二指肠上段、肝胆胰，也有喉以下的呼吸道、肺，以及胸腺、甲状腺、甲状旁腺。把前肠听成“只管消化管”，呼吸系统发生和五对咽囊会从本章被划出去。
:::

:::insight{label="卵黄囊顶部被卷进来，才有前、中、后肠这三段管子"}
扁平胚盘卷成圆柱，卵黄囊顶的内胚层跟着进胚体，这根管子才叫原始消化管。中肠仍连着卵黄囊，所以后来会有卵黄蒂、生理性脐疝和梅克尔憩室；前肠、后肠已经不连卵黄囊，各走自己的憩室和隔。只背“有一根消化管”，卵黄蒂那本账会没有着落。
:::

## （一）原始咽的发生及咽囊的演变

原始咽为消化管头端的膨大部，起自口咽膜，止于喉气管憩室起始部；呈左右宽、腹背窄、头端宽、尾端窄的扁漏斗形。口咽膜于第 $4$ 周破裂，原始咽借原始口腔和原始鼻腔与外界相通。原始咽侧壁有 $5$ 对膨向外侧的囊状突起称咽囊，分别与外侧的鳃沟相对。随着胚胎的发育，咽囊演化出一些重要的器官（图 23-2）。

:::definition{label="原始咽"}
原始咽是消化管头端的膨大部，起自口咽膜，止于喉气管憩室起始部，呈左右宽、腹背窄、头端宽、尾端窄的扁漏斗形。口咽膜于第 $4$ 周破裂后，原始咽借原始口腔和原始鼻腔与外界相通。
:::

:::definition{label="咽囊"}
咽囊是原始咽侧壁膨向外侧的 $5$ 对囊状突起，分别与外侧的鳃沟相对。咽囊内胚层演化出咽鼓管与鼓室、腭扁桃体、甲状旁腺、胸腺和后鳃体等器官。
:::

第 $1$ 对咽囊：伸长演化为咽鼓管，末端膨大演化为中耳鼓室，第 $1$ 鳃膜分化为鼓膜，第 $1$ 鳃沟形成外耳道。

:::definition{label="第1对咽囊"}
第 $1$ 对咽囊伸长演化为咽鼓管，末端膨大演化为中耳鼓室。相对的第 $1$ 鳃膜分化为鼓膜，第 $1$ 鳃沟形成外耳道。沟、膜、囊三件套一起构成中耳与外耳道的原基。
:::

第 $2$ 对咽囊：演化为腭扁桃体，其内胚层细胞分化为扁桃体的表面上皮；上皮下的间充质分化为网状组织，淋巴细胞迁移到此处并大量增殖。

:::definition{label="第2对咽囊"}
第 $2$ 对咽囊演化为腭扁桃体。内胚层细胞分化为扁桃体的表面上皮；上皮下的间充质分化为网状组织；淋巴细胞迁移到此处并大量增殖。
:::

第 $3$ 对咽囊：背侧份细胞增生，下移至甲状腺原基背侧，分化为下一对甲状旁腺。腹侧份细胞增生，形成左右两条细胞索，向胚体尾侧延伸，在未来的胸骨柄后方，左右细胞索汇拢，形成胸腺原基，细胞索根部退化而与咽脱离。胸腺原基的内胚层细胞分化为胸腺上皮细胞，由造血器官迁来的淋巴性造血干细胞增殖分化为胸腺细胞。

:::definition{label="第3对咽囊"}
第 $3$ 对咽囊分背、腹两份。背侧份下移至甲状腺原基背侧，分化为下一对甲状旁腺；腹侧份形成左右细胞索，在未来胸骨柄后方汇拢为胸腺原基，根部退化而与咽脱离。
:::

:::definition{label="胸腺原基的两种细胞"}
胸腺原基的内胚层细胞分化为胸腺上皮细胞；由造血器官迁来的淋巴性造血干细胞增殖分化为胸腺细胞。上皮是咽囊内胚层带来的，胸腺细胞是后来迁入的。
:::

第 $4$ 对咽囊：细胞增生并迁移至甲状腺背侧上方，分化为主细胞，形成上一对甲状旁腺。

:::definition{label="第4对咽囊"}
第 $4$ 对咽囊细胞增生并迁移至甲状腺背侧上方，分化为主细胞，形成上一对甲状旁腺。它比第 $3$ 对走得近，所以落在“上一对”。
:::

第 $5$ 对咽囊：形成一细胞团，称后鳃体（ultimobranchial body）。后鳃体的部分细胞迁入甲状腺内，分化为滤泡旁细胞。也有学者认为，滤泡旁细胞来源于神经嵴细胞。

:::definition{label="第5对咽囊与后鳃体"}
第 $5$ 对咽囊形成一细胞团，称后鳃体（ultimobranchial body）。后鳃体的部分细胞迁入甲状腺内，分化为滤泡旁细胞。也有学者认为，滤泡旁细胞来源于神经嵴细胞。两说并存，考试先写后鳃体，再注明神经嵴说。
:::

原始咽的其余部分形成咽，尾端与食管相通。

:::definition{label="原始咽的其余部分"}
五对咽囊衍化走了之后，原始咽的其余部分形成咽，尾端与食管相通。咽本身不是某一对咽囊变的。
:::

:::concept{term="先问第几对咽囊，再问背侧腹侧谁走甲状旁腺、谁走胸腺"}
看见咽囊，先数对数：第 $1$ 对咽鼓管加鼓室，第 $1$ 鳃膜是鼓膜、第 $1$ 鳃沟是外耳道；第 $2$ 对腭扁桃体；第 $3$ 对背侧下一对甲状旁腺、腹侧胸腺；第 $4$ 对上一对甲状旁腺；第 $5$ 对后鳃体去滤泡旁细胞。再问第 $3$ 对的背腹：背侧下移成下一对甲状旁腺，腹侧细胞索汇成胸腺。把“第 $3$ 对”听成“上一对”，或把鼓膜写成咽囊本身，中耳和甲状旁腺两本账会对调。
:::

:::compare{title="五对咽囊的演化"}
| 咽囊 | 主要衍化 | 配套结构 | 不要听成 |
|------|----------|----------|----------|
| 第 $1$ 对 | 伸长 → 咽鼓管；末端膨大 → 中耳鼓室 | 第 $1$ 鳃膜 → 鼓膜；第 $1$ 鳃沟 → 外耳道 | 鳃膜就是咽囊 |
| 第 $2$ 对 | 腭扁桃体（内胚层 → 表面上皮；间充质 → 网状组织；淋巴细胞迁入增殖） | — | 整颗扁桃体都是咽囊内胚层 |
| 第 $3$ 对 | 背侧份 → 下一对甲状旁腺；腹侧份 → 胸腺原基 | 细胞索根部退化，与咽脱离 | 第 $3$ 对是上一对甲状旁腺 |
| 第 $4$ 对 | 主细胞 → 上一对甲状旁腺（甲状腺背侧上方） | — | 第 $4$ 对走胸腺 |
| 第 $5$ 对 | 后鳃体；部分细胞迁入甲状腺 → 滤泡旁细胞 | 另有神经嵴来源说 | 滤泡旁细胞来自甲状舌管 |
:::

:::pitfall{label="第3对走下一对甲状旁腺，第4对走上一对，不要按号数对调"}
第 $3$ 对背侧份下移更远，落到甲状腺原基背侧，成为下一对甲状旁腺；第 $4$ 对迁移到甲状腺背侧上方，成为上一对。号数大的反而停在上面。写成“第 $3$ 对是上甲状旁腺”，解剖位置和迁移距离会对反。
:::

:::pitfall{label="鼓膜是第1鳃膜，外耳道是第1鳃沟，不是第1咽囊自己变的"}
第 $1$ 对咽囊只演化咽鼓管和鼓室。鼓膜来自第 $1$ 鳃膜，外耳道来自第 $1$ 鳃沟。沟、膜、囊三件套拼成中耳与外耳道，不要把四件事都写在咽囊头上。
:::

:::note{label="滤泡旁细胞的两说"}
教材先写后鳃体部分细胞迁入甲状腺、分化为滤泡旁细胞，接着写“也有学者认为来源于神经嵴细胞”。答题以课后鳃体为主，同时能复述神经嵴说即可；不要把两说并成一句“一定是神经嵴”。
:::

:::cause-effect{title="咽囊内胚层膨出之后各自迁走"}
- 因：第 1 对咽囊伸长、末端膨大
- 果：咽鼓管和中耳鼓室；第 1 鳃膜、第 1 鳃沟配套成鼓膜和外耳道
- 因：第 3 对腹侧份细胞索向尾侧延伸，在胸骨柄后方汇拢
- 果：胸腺原基形成，根部退化后与咽脱离
- 因：第 5 对形成后鳃体并迁入甲状腺
- 果：滤泡旁细胞（另有神经嵴来源说）
- 制约：原始咽其余部分才形成咽，尾端通食管
:::

## （二）甲状腺的发生

第 $4$ 周初，在原始咽底壁正中线处（相当于第 $1$ 对咽囊平面），内胚层细胞增生，向间充质内下陷形成盲管，称甲状舌管（thyroglossal duct），即甲状腺原基。它沿颈部正中向尾端方向生长、延伸，末端向两侧膨大，形成甲状腺的侧叶。第 $7$ 周时，甲状舌管的上段退化消失，仅在起始处残留一浅凹，称舌盲孔（图 23-2）。第 $11$ 周时，甲状腺滤泡出现，内含胶质，不久即开始分泌甲状腺激素。甲状腺激素对于促进胎儿骨骼和中枢神经系统的发育有重要作用。

:::definition{label="甲状舌管"}
甲状舌管（thyroglossal duct）是第 $4$ 周初原始咽底壁正中线处（相当于第 $1$ 对咽囊平面）内胚层细胞增生、向间充质内下陷形成的盲管，即甲状腺原基。它沿颈部正中向尾端生长，末端向两侧膨大形成甲状腺侧叶。
:::

:::definition{label="舌盲孔"}
第 $7$ 周时，甲状舌管的上段退化消失，仅在起始处残留一浅凹，称舌盲孔。舌盲孔是甲状舌管的起点记号，不是甲状腺侧叶本身。
:::

:::definition{label="甲状腺滤泡出现的时间"}
第 $11$ 周时甲状腺滤泡出现，内含胶质，不久即开始分泌甲状腺激素。甲状腺激素促进胎儿骨骼和中枢神经系统的发育。
:::

:::concept{term="先问甲状舌管上段退化没有，再问残留的是舌盲孔还是囊肿"}
看见甲状腺，先认它不是咽囊变的：原基是咽底正中的甲状舌管。再问第 $7$ 周上段退没退：退了，起点留舌盲孔；没退或局部残留，上皮变成黏液细胞、黏液聚集，就是甲状舌管囊肿，过大穿孔成瘘。把甲状腺听成“第 $3$、第 $4$ 咽囊”，或把舌盲孔听成病灶，畸形和正常发生会对错户头。
:::

- **随后** 沿颈正中向尾端延伸，末端膨大为侧叶
- **第7周** 上段退化消失，起点残留舌盲孔
- **第11周** 滤泡出现，内含胶质，不久分泌甲状腺激素
- **功能** 促进胎儿骨骼和中枢神经系统发育
:::

:::pitfall{label="甲状腺来自咽底正中的甲状舌管，不是第3、第4咽囊"}
第 $3$、第 $4$ 咽囊走的是甲状旁腺，第 $5$ 对走后鳃体／滤泡旁细胞。甲状腺本体从咽底正中下陷的甲状舌管长出来。写成“甲状腺也是咽囊衍化”，舌盲孔和甲状舌管囊肿就没有原基。
:::

:::keypoint{label="五对咽囊加一条甲状舌管，甲状腺不走咽囊户头"}
- 原始咽：口咽膜至喉气管憩室起始部，扁漏斗形；第 $4$ 周口咽膜破裂。
- 第 $1$ 对：咽鼓管 + 鼓室；鳃膜 = 鼓膜，鳃沟 = 外耳道。
- 第 $2$ 对：腭扁桃体（内胚层上皮 + 间充质网状组织 + 淋巴细胞迁入）。
- 第 $3$ 对：背侧下一对甲状旁腺，腹侧胸腺（上皮内胚层，胸腺细胞由造血干细胞迁入）。
- 第 $4$ 对：上一对甲状旁腺（主细胞）。
- 第 $5$ 对：后鳃体 → 滤泡旁细胞（或神经嵴说）。
- 甲状舌管第 $4$ 周出现，第 $7$ 周上段退化留舌盲孔，第 $11$ 周滤泡、分泌激素。
:::

## （三）食管和胃的发生

原始咽尾侧的一段原始消化管起初很短，后随颈和胸部器官的发育而延长成为食管。其表面上皮由单层增生为复层，使管腔极为狭窄甚至一度闭锁。至第 $8$ 周，过度增生的上皮细胞凋亡退化，食管腔重新出现。

:::definition{label="食管的延长与再通"}
原始咽尾侧的一段原始消化管起初很短，后随颈和胸部器官的发育而延长成为食管。表面上皮由单层增生为复层，管腔极为狭窄甚至一度闭锁；至第 $8$ 周，过度增生的上皮细胞凋亡退化，食管腔重新出现。再通失败就是消化管狭窄或闭锁。
:::

第 $4$ 周时，位于食管尾侧的前肠在原始横隔（primitive septum transversum）的下方形成一梭形膨大，为胃的原基。第 $5$ 周时，胃的背侧缘生长较快，形成胃大弯；腹侧缘生长缓慢，形成胃小弯。第 $7\sim 8$ 周时，胃大弯头端膨起，形成胃底。胃背系膜发育为突向左侧的网膜囊，使胃大弯由背侧转向左侧，胃小弯由腹侧转向右侧。这样，胃沿胚体纵轴顺时针旋转 $90^{\circ}$，并由原来的垂直方位变成由左上至右下的斜行方位（图 23-3）。

:::definition{label="胃的原基"}
第 $4$ 周时，食管尾侧的前肠在原始横隔（primitive septum transversum）下方形成一梭形膨大，为胃的原基。
:::

:::definition{label="胃大弯与胃小弯"}
第 $5$ 周时，胃的背侧缘生长较快，形成胃大弯；腹侧缘生长缓慢，形成胃小弯。大弯起初在背侧，小弯起初在腹侧，还没有转到左、右。
:::

:::definition{label="胃底"}
第 $7\sim 8$ 周时，胃大弯头端膨起，形成胃底。
:::

:::definition{label="网膜囊与胃的顺时针旋转"}
胃背系膜发育为突向左侧的网膜囊，使胃大弯由背侧转向左侧，胃小弯由腹侧转向右侧。胃沿胚体纵轴顺时针旋转 $90^{\circ}$，由垂直方位变成由左上至右下的斜行方位。
:::

:::concept{term="先问食管腔第8周再通没有，再问胃大弯是背侧快长还是已经转到左侧"}
看见前肠尾段，先问食管：上皮一度增生到闭锁，第 $8$ 周凋亡再通——这一步停了就是狭窄或闭锁。再问胃：背侧缘快长才叫大弯，腹侧缘慢长才叫小弯；背系膜突向左侧成网膜囊，胃沿纵轴顺时针转 $90^{\circ}$，大弯才到左侧。把“大弯在左”写成天生如此，或把胃的顺时针和中肠袢的逆时针对调，网膜囊和肠袢旋转会对错户头。
:::

:::pitfall{label="胃沿纵轴顺时针转90°，不要写成逆时针"}
网膜囊突向左侧，大弯从背侧转到左侧，小弯从腹侧转到右侧——这是顺时针。中肠袢才是腹面观逆时针。两根管子的转向写反，左右大弯和小肠、结肠的布局会整盘对调。
:::

- **上皮增生** 单层变为复层，管腔极窄甚至一度闭锁
- **第8周** 过度增生的上皮凋亡，食管腔重新出现
- **第4周** 食管尾侧前肠在原始横隔下形成梭形胃原基
- **第5周** 背侧缘快长大弯，腹侧缘慢长小弯
- **第7～8周** 大弯头端膨起成胃底；背系膜成网膜囊，沿纵轴顺时针转90°，成左上至右下斜位
:::

## （四）肠的发生

肠是由胃以下的原始消化管分化而成。肠最初为一条直管，以背系膜连于腹后壁。由于肠的生长速度快，使肠管向腹部弯曲而形成 U 形中肠袢（midgut loop），其顶端连于卵黄蒂。肠系膜上动脉行于肠袢系膜的中轴部位。中肠袢以卵黄蒂为界，分为头支和尾支，尾支近卵黄蒂处形成一突起，称盲肠突（caecal swelling），为小肠和大肠的分界线，是盲肠和阑尾的原基。

:::definition{label="中肠袢"}
中肠袢（midgut loop）是胃以下原始消化管生长过快、向腹部弯曲形成的 U 形肠袢。顶端连于卵黄蒂；肠系膜上动脉行于肠袢系膜的中轴。
:::

:::definition{label="头支与尾支"}
中肠袢以卵黄蒂为界，分为头支和尾支。头支后来演化为空肠和回肠的大部分；尾支主要演化为结肠。
:::

:::definition{label="盲肠突"}
盲肠突（caecal swelling）是尾支近卵黄蒂处的突起，为小肠和大肠的分界线，是盲肠和阑尾的原基。近段发育为盲肠，远段形成阑尾。
:::

第 $6$ 周，肠袢生长迅速，由于肝、肾的发育和腹腔容积相对较小，致使肠袢突入脐带内的胚外体腔，即脐腔（umbilical coelom），形成生理性脐疝。肠袢在脐腔中生长的同时，以肠系膜上动脉为轴逆时针旋转 $90^{\circ}$（从腹面观），使肠袢由矢状位转为水平位，头支从上方转到右侧，尾支从下方转到左侧。第 $10$ 周，由于腹腔容积增大，肠袢陆续从脐腔返回腹腔，脐腔闭锁。在肠袢退回腹腔的过程中，头支在先，尾支继后，继续逆时针旋转 $180^{\circ}$。头支的头端转至左侧，头支演化为空肠和回肠的大部分，占据腹腔的中部；尾支的头端转向右侧，尾支主要演化为结肠，位居腹腔周边。盲肠突最初位于肝下，后降至右髂窝，升结肠随之形成。盲肠突的近段发育为盲肠，远段形成阑尾。降结肠尾段移向中线，形成乙状结肠（图 23-4）。

第 $6$ 周以后，卵黄蒂退化闭锁，脱离肠袢，最终消失。

:::definition{label="脐腔与生理性脐疝"}
脐腔（umbilical coelom）是脐带内的胚外体腔。第 $6$ 周肠袢生长迅速，肝、肾发育使腹腔相对偏小，肠袢突入脐腔，形成生理性脐疝。这是正常过程，不是畸形。
:::

:::definition{label="中肠袢的两次逆时针旋转"}
肠袢以肠系膜上动脉为轴，从腹面观逆时针旋转。第 $6$ 周在脐腔中先转 $90^{\circ}$：矢状位变水平位，头支由上转右，尾支由下转左。第 $10$ 周退回腹腔时再转 $180^{\circ}$：头支头端转至左侧，尾支头端转向右侧。两段合计 $270^{\circ}$。
:::

:::definition{label="肠袢退回后的布局"}
头支在先、尾支继后返回。头支演化为空肠和回肠的大部分，占据腹腔中部；尾支主要演化为结肠，位居腹腔周边。盲肠突最初在肝下，后降至右髂窝，升结肠随之形成；近段为盲肠，远段为阑尾。降结肠尾段移向中线，形成乙状结肠。
:::

:::definition{label="卵黄蒂的正常结局"}
第 $6$ 周以后，卵黄蒂退化闭锁，脱离肠袢，最终消失。近端不退是梅克尔憩室，全程不退是脐肠瘘。
:::

:::concept{term="先问中肠袢现在在腹腔还是脐腔，再问腹面观已经转了90°还是退回时又转了180°"}
看见肠袢，先问它在哪：第 $6$ 周在脐腔里，叫生理性脐疝；第 $10$ 周才退回腹腔，脐腔闭锁。再问转了多少：在脐腔里先逆时针 $90^{\circ}$（头支转右、尾支转左），退回时头支先行再逆时针 $180^{\circ}$（头支到左、尾支到右），合计 $270^{\circ}$，轴始终是肠系膜上动脉。把生理性脐疝写成畸形，或只记“转了 $270^{\circ}$”却说不清分两段，先天性脐疝和肠袢转位异常会对错户头。
:::

:::compare{title="头支、尾支与盲肠突的去向"}

| 分界 | 卵黄蒂头侧 | 卵黄蒂尾侧 | 尾支近卵黄蒂处的突起 |

| 项目 | 胃 | 中肠袢 |
|------|----|--------|
| 观察方向 | 沿胚体纵轴 | 从腹面观，以肠系膜上动脉为轴 |
| 转向 | 顺时针 $90^{\circ}$ | 先逆时针 $90^{\circ}$，退回再逆时针 $180^{\circ}$，共 $270^{\circ}$ |

:::pitfall{label="生理性脐疝是第6～10周的正常外突，不是先天性脐疝"}
第 $6$ 周肠袢必须进脐腔，第 $10$ 周必须退回并让脐腔闭锁。这叫生理性脐疝。先天性脐疝是退回之后脐腔仍未闭锁，腹压一高肠管从脐部膨出。把第 $6$ 周的外突写成畸形，正常旋转过程会被当成疾病。
:::

:::insight{label="轴是肠系膜上动脉，方向是腹面观逆时针，270°要拆成90°加180°"}
不先站到腹面，顺时针逆时针会对反；不记得先在脐腔转 $90^{\circ}$、退回再转 $180^{\circ}$，头支“先到右侧再到左侧”会像自相矛盾。把两段分开记，空回肠居中、结肠居周边才对得上图 23-4。
:::

:::timeline{period="中肠袢：出脐腔、旋转、退回"}
- **起初** 胃以下直管，背系膜连腹后壁；生长快而弯成U形中肠袢，顶连卵黄蒂
- **分界** 卵黄蒂分头支、尾支；尾支近卵黄蒂处出盲肠突
- **第6周** 突入脐腔，生理性脐疝；腹面观逆时针90°，矢状位变水平位，头支转右、尾支转左
- **第6周以后** 卵黄蒂退化闭锁，脱离肠袢，最终消失
- **第10周** 腹腔增大，头支先、尾支后返回，再逆时针180°；脐腔闭锁
- **退回后** 头支成空回肠居中；尾支成结肠居周边；盲肠突自肝下降至右髂窝，近段盲肠、远段阑尾；降结肠尾段成乙状结肠
:::

## （五）直肠的发生与泄殖腔的分隔

后肠末段的膨大部分为泄殖腔（cloaca），其腹侧头端与尿囊相连通，腹侧尾端以泄殖腔膜封闭。第 $4\sim 7$ 周，尿囊与后肠之间的间充质增生，向尾端生长，呈一横向镰状隔膜突入泄殖腔内，形成尿直肠隔（urorectal septum），最后与泄殖腔膜融合，将泄殖腔分隔为腹侧的尿生殖窦（urogenital sinus）与背侧的原始直肠。尿生殖窦将参与泌尿生殖管道的形成（见第 $24$ 章），原始直肠分化为直肠和肛管上段。泄殖腔膜也被分为腹侧的尿生殖膜（urogenital membrane）和背侧的肛膜（anal membrane）。肛膜的外方为外胚层向内凹陷形成的肛凹（anal pit）。第 $8$ 周末，肛膜破裂，肛管相通。肛管的上段上皮来源于内胚层，下段上皮来源于外胚层，二者之间以齿状线分界（图 23-5）。

:::definition{label="泄殖腔"}
泄殖腔（cloaca）是后肠末段的膨大部分。腹侧头端与尿囊相通，腹侧尾端以泄殖腔膜封闭。分隔前，消化与泌尿生殖还共用这一段盲腔。
:::

:::definition{label="尿直肠隔"}
第 $4\sim 7$ 周，尿囊与后肠之间的间充质增生，向尾端生长，呈横向镰状隔膜突入泄殖腔内，形成尿直肠隔（urorectal septum）。它最后与泄殖腔膜融合，把泄殖腔分成腹、背两份。
:::

:::definition{label="尿生殖窦与原始直肠"}
尿直肠隔把泄殖腔分隔为腹侧的尿生殖窦（urogenital sinus）与背侧的原始直肠。尿生殖窦参与泌尿生殖管道的形成（见第 $24$ 章）；原始直肠分化为直肠和肛管上段。
:::

:::definition{label="尿生殖膜、肛膜与肛凹"}
泄殖腔膜被分成腹侧的尿生殖膜（urogenital membrane）和背侧的肛膜（anal membrane）。肛膜外方，外胚层向内凹陷形成肛凹（anal pit）。
:::

:::definition{label="齿状线"}
第 $8$ 周末肛膜破裂，肛管相通。肛管上段上皮来源于内胚层，下段上皮来源于外胚层，二者之间以齿状线分界。齿状线是内、外胚层在肛管的分界，不是黏膜与皮肤的随意分界。
:::

:::concept{term="先问泄殖腔被尿直肠隔分成腹侧还是背侧，再问齿状线以上是内胚层还是外胚层"}
看见后肠末端，先认泄殖腔：腹侧头端通尿囊，尾端封着泄殖腔膜。再问隔：尿直肠隔从尿囊与后肠之间长下来，腹侧是尿生殖窦，背侧是原始直肠；膜也分成尿生殖膜和肛膜。最后问肛管：第 $8$ 周末肛膜破；齿状线以上内胚层（原始直肠来的上段），以下外胚层（肛凹来的下段）。把腹侧写成直肠，或把齿状线听成“随便一条皱襞”，肛门闭锁和直肠尿道瘘就对不上隔的位置。
:::

::figure{src="/images/histology/textbook/p0255_01.png" caption="图23-5 泄殖腔的分隔示意图。↑尿直肠隔。A. 泄殖腔与尿囊、后肠相通；B、C. 尿直肠隔将泄殖腔分为腹侧尿生殖窦与背侧原始直肠，外方出现肛凹；D. 泄殖腔膜分成尿生殖膜与肛膜，原始直肠成直肠上段。" alt="四幅矢状面：黄腔由通尿囊的泄殖腔，经镰状隔分成前方尿生殖窦、后方原始直肠，肛膜外侧有肛凹"}

:::compare{title="泄殖腔分隔后的腹侧与背侧"}
| 项目 | 腹侧 | 背侧 |
|------|------|------|
| 腔 | 尿生殖窦 | 原始直肠 |
| 膜 | 尿生殖膜 | 肛膜 |
| 去向 | 参与泌尿生殖管道（第 $24$ 章） | 直肠和肛管上段 |
| 外方凹陷 | — | 外胚层肛凹 |
| 相通时间 | 尿生殖膜另章再破 | 第 $8$ 周末肛膜破裂，肛管相通 |
:::

:::pitfall{label="齿状线以上内胚层、以下外胚层，不要把整段肛管都写成后肠"}
原始直肠只分化为直肠和肛管上段。肛管下段来自肛凹的外胚层。齿状线恰好卡在两套上皮之间。写成“肛管全是后肠内胚层”，下段和外胚层肛凹会消失。
:::

:::cause-effect{title="尿直肠隔下长，泄殖腔才分成粪、尿两路"}
- 因：尿囊与后肠之间的间充质向尾端长成尿直肠隔，并与泄殖腔膜融合
- 果：腹侧尿生殖窦、背侧原始直肠；膜分成尿生殖膜和肛膜
- 制约：隔发育不全可伴直肠尿道瘘；肛膜未破或肛凹未与直肠末端相通则肛门闭锁
:::

:::timeline{period="泄殖腔分隔到肛膜破裂"}
- **后肠末段** 膨大为泄殖腔；腹侧头端通尿囊，尾端以泄殖腔膜封闭
- **第4～7周** 尿直肠隔呈横向镰状突入，最终与泄殖腔膜融合
- **分隔结果** 腹侧尿生殖窦，背侧原始直肠；膜分为尿生殖膜和肛膜；肛膜外方为肛凹
- **第8周末** 肛膜破裂，肛管相通；齿状线上内胚层、下外胚层
:::

:::keypoint{label="食管第8周再通，胃顺时针90°，肠袢逆时针270°，泄殖腔一隔两分"}
- 食管上皮一度闭锁，第 $8$ 周凋亡再通。
- 胃：背侧快长大弯，腹侧慢长小弯；网膜囊突向左；纵轴顺时针 $90^{\circ}$。
- 中肠袢顶连卵黄蒂，轴为肠系膜上动脉；第 $6$ 周生理性脐疝，腹面观逆时针 $90^{\circ}$；第 $10$ 周退回再 $180^{\circ}$，共 $270^{\circ}$。
- 头支空回肠居中，尾支结肠居周边；盲肠突降右髂窝；卵黄蒂第 $6$ 周后消失。
- 尿直肠隔：腹侧尿生殖窦，背侧原始直肠；第 $8$ 周末肛膜破；齿状线分内、外胚层。
:::

## （六）肝和胆囊的发生

第 $4$ 周时，前肠末端腹侧壁的细胞增生，形成一向外突出的囊状肝憩室（hepatic diverticulum）（图 23-6），为肝和胆囊的原基。肝憩室生长迅速并伸入到原始横隔内。憩室末端膨大，分为头、尾两支。头支形成肝的原基，尾支形成胆囊及胆道的原基。头支很快形成树枝状分支，其近端分化为肝管及小叶间胆管，末端分支旺盛，形成肝索，肝索上下叠加形成肝板。肝板互相连接成网，网间隙形成肝血窦。肝板与肝血窦围绕中央静脉，共同形成肝小叶。第 $2$ 个月，肝细胞之间形成胆小管。第 $3$ 个月开始合成胆汁。

:::definition{label="肝憩室"}
肝憩室（hepatic diverticulum）是第 $4$ 周前肠末端腹侧壁细胞增生、向外突出的囊状结构，为肝和胆囊的原基。它生长迅速并伸入原始横隔内，末端分为头、尾两支。
:::

:::definition{label="肝憩室头支"}
头支形成肝的原基。很快呈树枝状分支：近端分化为肝管及小叶间胆管，末端分支旺盛形成肝索，肝索上下叠加成肝板。肝板连成网，网间隙为肝血窦；肝板与肝血窦围绕中央静脉，共同形成肝小叶。
:::

:::definition{label="胆小管与胆汁"}
第 $2$ 个月，肝细胞之间形成胆小管。第 $3$ 个月开始合成胆汁。
:::

胚胎肝的功能十分活跃，第 $6$ 周时，造血干细胞从卵黄囊壁迁入肝，在肝血窦内外形成大量原始血细胞集落。肝造血功能在第 $6$ 个月之后逐渐降低，至出生时基本停止。目前已可分离胎肝的造血干细胞并用于某些血液病的治疗。胎肝早期就开始合成并分泌多种血浆蛋白和甲胎蛋白（$\alpha$-fetoprotein，AFP）。大约第 $5\sim 6$ 个月，几乎所有肝细胞都能合成 AFP。此后，肝合成 AFP 的功能逐渐减弱，出生后不久即停止。正常成人 AFP 含量极低。在病理状态下，AFP 含量明显升高有助于原发性肝癌的诊断，也可用于提示肝癌治疗的效果。

:::definition{label="胎肝造血"}
第 $6$ 周时，造血干细胞从卵黄囊壁迁入肝，在肝血窦内外形成大量原始血细胞集落。肝造血功能在第 $6$ 个月之后逐渐降低，至出生时基本停止。胎肝造血干细胞已可用于某些血液病的治疗。
:::

:::definition{label="甲胎蛋白"}
甲胎蛋白（$\alpha$-fetoprotein，AFP）由胎肝早期开始合成并分泌，大约第 $5\sim 6$ 个月几乎所有肝细胞都能合成。此后逐渐减弱，出生后不久停止。正常成人含量极低；病理状态下明显升高有助于原发性肝癌的诊断，也可提示治疗效果。
:::

肝憩室尾支的近端伸长形成胆囊管，远端扩大形成胆囊。肝憩室的基部发育为胆总管，并与胰腺导管合并开口于十二指肠。

:::definition{label="肝憩室尾支与基部"}
尾支近端伸长形成胆囊管，远端扩大形成胆囊。肝憩室基部发育为胆总管，并与胰腺导管合并开口于十二指肠。头支成肝，尾支成胆囊胆道，基部成胆总管，三份不要并成“憩室只成肝”。
:::

:::concept{term="先问肝憩室头支、尾支、基部各去哪，再问造血和AFP是胎肝功能还是成体功能"}
看见前肠末端腹侧的囊，先切开三份：头支成肝（肝管、小叶间胆管、肝索／肝板、肝血窦、肝小叶），尾支近端胆囊管、远端胆囊，基部胆总管。再问功能时钟：第 $6$ 周卵黄囊造血干细胞迁入，第 $6$ 个月后造血下降、出生时基本停止；AFP 在第 $5\sim 6$ 个月几乎全肝都合成，出生后不久停止，成人体内升高才指向原发性肝癌。把胆囊写成头支，或把 AFP 当成正常成人肝功能，憩室三份和胎肝两本功能账会对错户头。
:::

:::compare{title="肝憩室头支、尾支与基部"}
| 部分 | 去向 | 关键后续 |
|------|------|----------|
| 头支 | 肝的原基 | 近端肝管及小叶间胆管；末端肝索 → 肝板 → 围中央静脉成肝小叶；第 $2$ 个月胆小管，第 $3$ 个月胆汁 |
| 尾支 | 胆囊及胆道的原基 | 近端胆囊管，远端胆囊 |
| 基部 | 胆总管 | 与胰腺导管合并开口于十二指肠 |
:::

:::timeline{period="肝憩室到胎肝功能"}
- **第4周** 前肠末端腹侧出肝憩室，伸入原始横隔，分头、尾两支
- **头支** 树枝状分支，建成肝板、肝血窦和肝小叶
- **第2个月** 肝细胞之间出现胆小管
- **第3个月** 开始合成胆汁
- **第6周** 卵黄囊造血干细胞迁入，肝血窦内外形成原始血细胞集落
- **第5～6个月** 几乎所有肝细胞合成AFP
- **第6个月之后** 肝造血逐渐降低，出生时基本停止；AFP 出生后不久停止
:::

:::pitfall{label="AFP 升高是病理信号，不要当成正常成人肝功能"}
胎肝几乎全都能合成 AFP，出生后不久停止，正常成人含量极低。明显升高才有助于原发性肝癌诊断和提示疗效。写成“成人肝也大量产 AFP”，这张肿瘤标志就失去对照。
:::

:::note{label="胎肝造血干细胞可分离用于治疗"}
教材写明：目前已可分离胎肝的造血干细胞并用于某些血液病的治疗。造血是胎肝的一过性功能，不是成体肝的常规工作。
:::

## （七）胰腺的发生

第 $4$ 周末，前肠末端腹侧近肝憩室的尾缘，内胚层细胞增生，向外突出形成腹胰芽（ventral pancreatic bud），其对侧细胞也增生形成背胰芽（dorsal pancreatic bud），它们将分别形成腹胰和背胰。由于胃和十二指肠的旋转和肠壁的不均等生长，使腹胰转向右侧，背胰转向左侧，进而腹胰转至背胰的下方并与之融合，形成单一的胰腺（图 23-6）。在发育过程中，胰芽反复分支，形成各级导管及其末端的腺泡；一些上皮细胞游离进入间充质，分化为胰岛，第 $5$ 个月开始行使内分泌功能。

:::definition{label="腹胰芽与背胰芽"}
第 $4$ 周末，前肠末端腹侧近肝憩室尾缘的内胚层向外突出形成腹胰芽（ventral pancreatic bud），对侧细胞增生形成背胰芽（dorsal pancreatic bud），分别形成腹胰和背胰。
:::

:::definition{label="腹胰与背胰的融合"}
胃和十二指肠旋转加上肠壁不均等生长，使腹胰转向右侧，背胰转向左侧，进而腹胰转至背胰下方并与之融合，形成单一的胰腺。
:::

:::definition{label="胰岛出现内分泌功能的时间"}
胰芽反复分支，形成各级导管及其末端的腺泡；一些上皮细胞游离进入间充质，分化为胰岛，第 $5$ 个月开始行使内分泌功能。
:::

::figure{src="/images/histology/textbook/p0256_01.png" caption="图23-6 肝、胆囊、胰腺的发生示意图。上排：第4周末肝憩室头支成肝、尾支成胆囊，腹胰芽与背胰芽随十二指肠旋转而靠拢；第5～6周腹胰转至背胰下方。下排横切：腹胰与背胰融合，形成胆总管、主胰导管与副胰导管。" alt="六图：肝憩室红头支绿尾支与蓝腹胰棕背胰，随后肝长大、胆囊分出，腹胰绕到背胰下方并融合"}

:::concept{term="先问腹胰背胰融了没有，再问胰岛第5月有没有内分泌"}
看见前肠末端近肝憩室处的两个芽，先认腹胰芽在腹侧近肝憩室尾缘，背胰芽在对侧。再问旋转：腹胰转右再转到背胰下方才融合成一个胰腺。最后问胰岛：上皮细胞游离进间充质，第 $5$ 个月才开始内分泌。把两个芽写成“一开始就是一个胰”，或把胰岛功能提前到第 $4$ 周，导管腺泡和内分泌两本账会并成一句。
:::

:::compare{title="腹胰芽与背胰芽"}
| 项目 | 腹胰芽 | 背胰芽 |
|------|--------|--------|
| 位置 | 前肠末端腹侧，近肝憩室尾缘 | 对侧 |
| 旋转 | 转向右侧，再转到背胰下方 | 转向左侧 |
| 融合 | 与背胰融合，参与单一胰腺 | 与腹胰融合 |
| 共同后续 | 反复分支 → 各级导管和末端腺泡；部分上皮入间充质 → 胰岛，第 $5$ 个月内分泌 | 同左 |
:::

:::pitfall{label="腹胰芽贴着肝憩室尾缘，不要把胆囊尾支和腹胰芽当成同一个突起"}
肝憩室尾支走胆囊和胆道，腹胰芽是紧挨其尾缘另长出来的内胚层芽。图 23-6 上尾支与腹胰芽颜色不同。写成“胆囊和腹胰是一个憩室”，胆总管与胰管在十二指肠的开口会搅在一起。
:::

:::insight{label="胃和十二指肠一转，腹胰才能绕到背胰下面"}
两个胰芽起初隔着肠管相对。胃顺时针转、十二指肠不均等生长，腹胰才从右侧绕到背胰下方。胰腺融合和胃的旋转是同一套运动的两本账，不要当成互不相关的两个事件。
:::

:::timeline{period="肝憩室与两个胰芽"}
- **第4周** 前肠末端腹侧出肝憩室，伸入原始横隔
- **第4周末** 近肝憩室尾缘出腹胰芽，对侧出背胰芽
- **随后** 头支成肝，尾支成胆囊胆道，基部成胆总管；腹胰转右、背胰转左，腹胰转到背胰下方融合
- **第2个月 / 第3个月** 胆小管出现；开始合成胆汁
- **第5个月** 胰岛开始内分泌
- **第6周起** 胎肝造血；第6个月后下降
:::

:::keypoint{label="肝憩室三份，两个胰芽合成一个胰"}
- 肝憩室：头支肝，尾支胆囊和胆道，基部胆总管。
- 肝板 + 肝血窦围中央静脉成肝小叶；第 $2$ 个月胆小管，第 $3$ 个月胆汁。
- 胎肝：第 $6$ 周造血，第 $6$ 个月后降，出生时基本停止；AFP 第 $5\sim 6$ 个月几乎全肝合成，出生后不久停。
- 腹胰芽 + 背胰芽，随胃和十二指肠旋转融合；胰岛第 $5$ 个月内分泌。
:::

## （八）主要畸形

消化管发生里，闭锁再通、甲状舌管退化、肠袢退回、卵黄蒂消失、尿直肠隔下长、神经嵴迁入，哪一步停下都会变成畸形。下面八条按原基对照摊开；插入框只补充先天性脐疝的临床注记，不另立一节。

### 1. 甲状舌管囊肿

甲状舌管囊肿（thyroglossal cyst）：甲状舌管在发育过程中没有闭锁，局部残留小的腔隙，或全部残留成为细长管道，当上皮细胞分化为黏液性细胞，黏液聚集便形成囊肿，位于舌与甲状腺之间。囊肿过于膨大时可发生穿孔，开口于皮肤或舌盲孔处，成为甲状舌管瘘。

:::definition{label="甲状舌管囊肿"}
甲状舌管囊肿（thyroglossal cyst）因甲状舌管没有闭锁：局部残留小腔隙，或全部残留成细长管道。上皮分化为黏液性细胞，黏液聚集成囊肿，位于舌与甲状腺之间。
:::

:::definition{label="甲状舌管瘘"}
囊肿过于膨大时可发生穿孔，开口于皮肤或舌盲孔处，成为甲状舌管瘘。瘘是囊肿穿出来的通道，不是另一套原基。
:::

### 2. 消化管狭窄或闭锁

消化管狭窄或闭锁主要见于食管和十二指肠，在其发生过程中曾一度出现上皮细胞过度增生而使管腔狭窄或闭锁，后来过度增生的细胞凋亡，上皮变薄，管腔恢复正常。如后一过程没有发生，则导致消化管狭窄或闭锁（图 23-7）。

:::definition{label="消化管狭窄或闭锁"}
主要见于食管和十二指肠。发生中上皮一度过度增生，管腔狭窄或闭锁；随后细胞凋亡、上皮变薄、管腔恢复。后一过程不发生，就留下狭窄或闭锁。
:::

:::note{label="图23-7 食管中段闭锁"}
教材图 23-7 为食管中段闭锁（食管内碘油造影 X 线片），碘油滞留在食管上段。原图未能收入数字版；正文仍保留“图 23-7”出处。对照第 $8$ 周正常再通：凋亡没发生，造影剂就停在闭锁上方。
:::

### 3. 先天性脐疝

先天性脐疝（congenital umbilical hernia）由脐腔未闭锁导致，脐带根部残留一孔与腹腔相通。当腹内压增高时，肠管可从脐部膨出（图 23-8，图 23-9）。

:::definition{label="先天性脐疝"}

:::note{label="先天性脐疝"}
先天性脐疝是一种发生在新生儿和婴儿的常见疾病，胎儿出生时，肠管或其他腹腔脏器通过扩大的脐环膨出体外。先天性脐疝的主要原因包括胚胎发育时期肠道未完全回归腹腔、脐带环未在出生后及时闭合、腹肌发育不全、遗传和早产或低出生体重等。

脐疝的治疗方法取决于病情的严重程度，浅表小的脐疝通常会随着患儿的成长自然恢复，而较大的或复杂的脐疝可能需要手术。手术的最佳时间因个体差异而有所不同，但通常推荐在 $2\sim 4$ 岁进行，这个年龄段儿童的腹部肌肉发育得相对较好，有助于术后的康复。同时要注意的是，一旦患儿出现嵌顿性脐疝需要尽快手术治疗。

脐疝的形成与遗传、生长发育等因素紧密相关，目前没有特别确切的预防措施。但是通过保持健康的孕期生活方式（包括适当的运动、营养均衡的饮食等），可能可以降低脐疝形成的风险。此外，保持婴儿的适宜体重并防止其过度哭闹也有一定的预防作用。
:::

### 5. 脐肠瘘

脐肠瘘（omphalomesenteric fistula）又称脐瘘（umbilical fistula），是卵黄蒂未退化，在脐和肠之间残留的瘘管。腹内压增高时，粪便可通过瘘管从脐部溢出（图 23-9）。

### 6. 先天性巨结肠

先天性巨结肠（congenital megacolon）又称希尔施普龙病（Hirschsprung disease），多见于乙状结肠。因神经嵴细胞未迁移至该段肠壁内，使肠壁内副交感神经节细胞缺如，导致该段结肠处于不能蠕动的麻痹状态，粪便淤积其内，久之造成肠壁极度扩张，成为巨结肠。

### 8. 肠袢转位异常

肠袢转位异常由肠袢在发育过程中反向转位所致，可表现为左位阑尾和肝、右位胃和乙状结肠等，并可影响胸腔器官，形成右位心。这类异常又统称内脏反位，在临床上易引起医生误诊。

:::definition{label="肠袢转位异常与内脏反位"}
肠袢转位异常由肠袢反向转位所致，可表现为左位阑尾和肝、右位胃和乙状结肠等，并可影响胸腔器官，形成右位心。这类异常又统称内脏反位，临床上易引起误诊。
:::

:::concept{term="先问卵黄蒂是近端残留、全程瘘管还是脐腔未闭，再问巨结肠是不是神经嵴没迁入"}
看见消化管畸形，先对原基：甲状舌管没闭锁 → 囊肿／瘘；上皮凋亡没发生 → 狭窄或闭锁；脐腔没闭锁 → 先天性脐疝；卵黄蒂近端残留 → 梅克尔憩室（距回盲部 $40\sim 50\,\mathrm{cm}$）；卵黄蒂全程残留 → 脐肠瘘，粪可从脐溢出；神经嵴未迁入 → 副交感节缺如 → 先天性巨结肠；肛膜未破或肛凹不通 → 肛门闭锁，可伴直肠尿道瘘；肠袢反向转 → 内脏反位。把脐疝、憩室、瘘三件都写成“脐没长好”，三张卵黄蒂／脐腔的账会并成一句。
:::

:::pitfall{label="梅克尔憩室是近端残留，脐肠瘘是全程瘘管，不要并成“卵黄蒂没掉”"}
近端未退化：回肠上一个囊，可有纤维索连脐，粪不从脐漏出。全程未退化：脐和肠之间是一条瘘管，腹压高时粪从脐溢出。只写“卵黄蒂残留”，两种畸形会对成一种。
:::

:::pitfall{label="巨结肠的扩张段是淤积的结果，缺的是神经嵴迁入的副交感节"}
神经嵴细胞没迁到该段（多见于乙状结肠），副交感神经节细胞缺如，这段不能蠕动。粪便淤在这里，久之肠壁极度扩张。不要把“变粗的那一段”写成神经节还在、只是管腔大。
:::

:::cause-effect{title="该闭的没闭、该通的没通、该迁入的没迁入"}
- 因：甲状舌管未闭锁
- 果：黏液聚集成囊肿，过大穿孔成瘘
- 因：上皮凋亡再通未发生
- 果：食管或十二指肠狭窄、闭锁
- 因：脐腔未闭锁
- 果：先天性脐疝
- 因：神经嵴未迁入肠壁
- 果：副交感节缺如，先天性巨结肠
- 因：肛膜未破或肛凹不通；尿直肠隔不全
- 果：肛门闭锁，常伴直肠尿道瘘
- 因：肠袢反向转位
- 果：内脏反位，可影响胸腔器官成右位心
:::

:::tip{label="畸形口诀"}
舌管不闭成囊肿，上皮不凋亡就闭锁。脐腔不闭成脐疝，卵黄近端憩室、全程瘘。神经嵴不到成巨结肠，肛膜不破闭肛门，肠袢反转内脏反。
:::

:::keypoint{label="八种畸形对上原基，脐疝憩室瘘不要并成一句"}
- 甲状舌管囊肿：管未闭锁，舌与甲状腺之间；过大成瘘。
- 狭窄／闭锁：食管、十二指肠再通失败。
- 先天性脐疝：脐腔未闭；生理性脐疝是第 $6\sim 10$ 周正常过程。
- 梅克尔憩室：卵黄蒂近端，距回盲 $40\sim 50\,\mathrm{cm}$。
- 脐肠瘘：卵黄蒂全程，粪从脐溢。
- 先天性巨结肠：神经嵴未迁入，副交感节缺如，多在乙状结肠。
- 肛门闭锁：肛膜未破或肛凹不通，常伴直肠尿道瘘。
- 肠袢反向 → 内脏反位，可有右位心，易误诊。
:::

- [ ] 肛门闭锁（imperforate anus）：肛膜未破或肛凹未与直肠末端相通，常伴直肠尿道瘘。
- [ ] 肠袢反向转位 → 左位阑尾和肝、右位胃和乙状结肠，可有右位心，统称内脏反位，易误诊。
