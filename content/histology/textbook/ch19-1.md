# 一、卵巢

女性生殖系统（female reproductive system）由卵巢、输卵管、子宫、阴道和外生殖器组成。卵巢产生卵子并分泌性激素；输卵管是受精的场所，并输送生殖细胞；子宫形成月经并孕育胎儿。自青春期开始，生殖器官和乳房迅速发育成熟，卵巢开始排卵并分泌性激素，子宫内膜出现周期性变化。更年期卵巢功能逐渐减退。乳腺分泌乳汁哺育婴儿，故列入本章。本节先把卵巢的白膜、皮质卵泡、排卵和黄体摊开；输卵管、子宫、阴道、乳腺各立一节。

:::definition{label="女性生殖系统"}
女性生殖系统（female reproductive system）由卵巢、输卵管、子宫、阴道和外生殖器组成。卵巢产生卵子并分泌性激素；输卵管是受精场所并输送生殖细胞；子宫形成月经并孕育胎儿。
:::

:::definition{label="卵巢"}
卵巢（ovary）是产生卵子和分泌性激素的器官。表面覆有单层扁平或立方形的上皮，上皮深部为薄层致密结缔组织构成的白膜。实质分为外周的皮质和中央的髓质，二者分界不明显。
:::

:::concept{term="先问这是产卵和激素的卵巢，还是只负责输送、受精或孕育的管道"}
看见女性生殖系统，先把两本账切开：皮质里的卵泡发育、排卵和黄体，才是“制造卵子并出激素”；输卵管负责接卵、受精和运送，子宫负责内膜周期和孕育，阴道是排出通道，乳腺另立户头哺育婴儿。把“生殖系统”听成“从卵巢到阴道都在造卵”，透明带、放射冠和功能层剥脱会并成一句。
:::

:::compare{title="卵巢、输卵管、子宫与阴道、乳腺"}
| 项目 | 卵巢 | 输卵管 | 子宫 | 阴道 | 乳腺 |
|------|------|--------|------|------|------|
| 职分 | 产生卵子；分泌雌激素、孕激素等 | 受精场所；输送生殖细胞 | 形成月经；孕育胎儿 | 排出月经与胎儿的通道 | 分泌乳汁，哺育婴儿 |
| 核心结构 | 卵泡、黄体、白体、闭锁卵泡 | 黏膜纵行皱襞、纤毛细胞与分泌细胞 | 内膜功能层 / 基底层；肌层 | 未角化复层扁平上皮 | 复管泡状腺 |
| 是否生殖器官 | 是 | 是 | 是 | 是 | 否，因泌乳列入本章 |
| 本章位置 | 第 19-1 节 | 第 19-2 节 | 第 19-3 节 | 第 19-4 节 | 第 19-5 节 |
:::

:::note{label="乳腺为什么写进本章"}
乳腺不属于女性生殖器官，职分是分泌乳汁、哺育婴儿。因青春期后与卵巢激素联动发育，妊娠期和哺乳期出现泌乳活动，教材把它放在本章末节。
:::

卵巢表面覆有单层扁平或立方形的上皮，上皮深部为薄层致密结缔组织构成的白膜。实质外周为皮质、中央为髓质，分界不明显。皮质较厚，由不同发育阶段的卵泡、黄体，以及富含梭形基质细胞和网状纤维的结缔组织等构成；髓质较薄，为疏松结缔组织，含较多弹性纤维、血管、淋巴管和神经（图 19-1）。卵巢一侧为卵巢门，此处基质内有少量平滑肌及门细胞。

:::definition{label="表面上皮"}
卵巢表面覆有单层扁平或立方形上皮。它是被覆上皮，不是卵泡细胞，也不构成白膜。
:::

:::definition{label="白膜"}
白膜是表面上皮深部的薄层致密结缔组织。它包在实质外面，皮质卵泡不长在白膜里。
:::

:::definition{label="皮质"}
皮质较厚，位于外周，由不同发育阶段的卵泡、黄体，以及富含梭形基质细胞和网状纤维的结缔组织构成。卵泡发育的周期性改变主要发生在皮质。
:::

:::definition{label="髓质"}
髓质较薄，位于中央，为疏松结缔组织，含较多弹性纤维、血管、淋巴管和神经。髓质里没有正在发育的卵泡。
:::

:::definition{label="卵巢门"}
卵巢一侧为卵巢门，此处基质内有少量平滑肌及门细胞。血管、淋巴管和神经由此进出。
:::

:::compare{title="皮质与髓质"}
| 项目 | 皮质 | 髓质 |
|------|------|------|
| 位置 | 外周，较厚 | 中央，较薄 |
| 组织 | 卵泡、黄体 + 梭形基质细胞、网状纤维 | 疏松结缔组织 |
| 内容 | 原始至成熟卵泡、闭锁卵泡、黄体、白体 | 弹性纤维、血管、淋巴管、神经 |
| 分界 | 与髓质分界不明显 | 与皮质分界不明显 |
| 不要听成 | 白膜 | 卵泡所在层 |
:::

:::pitfall{label="白膜是致密结缔组织被膜，不要写成表面上皮或卵泡壁"}
表面上皮是单层扁平或立方；白膜在它深部，是薄层致密结缔组织。卵泡壁的颗粒层和卵泡膜在皮质实质里。三张皮不要并成“卵巢外面那一层”。
:::

卵巢组织结构有明显的年龄性变化，主要是皮质中卵泡发育呈周期性改变。女性新生儿期有 $70$ 万 $\sim$ $200$ 万个原始卵泡，青春期开始约 $4$ 万个，至 $40\sim 50$ 岁时仅剩几百个。从青春期至更年期，卵巢在垂体促性腺激素影响下，按月经周期进行周期性排卵。每 $28$ 天有 $15\sim 20$ 个卵泡生长发育，一般只有一个优势卵泡能发育成熟并排卵。正常女性一生中排卵 $400$ 余个，其余大部分卵泡在发育的不同阶段退化为闭锁卵泡。绝经期后卵巢不再排卵。

:::note{label="卵泡数量与一生排卵账"}
| 阶段 | 卵泡数量或排卵 |
|------|----------------|
| 新生儿期 | $70$ 万 $\sim$ $200$ 万个原始卵泡 |
| 青春期开始 | 约 $4$ 万个卵泡 |
| $40\sim 50$ 岁 | 仅剩几百个 |
| 每个周期 | $15\sim 20$ 个生长发育，通常 $1$ 个优势卵泡成熟排卵 |
| 一生 | 排卵 $400$ 余个；其余多数闭锁 |
| 绝经期后 | 不再排卵 |
:::

:::insight{label="绝大多数卵泡走不到排卵，闭锁才是常态"}
每 $28$ 天有十几二十个卵泡启动，通常只有一个能成熟。一生排卵四百余个，相对新生儿期的百万量级原始卵泡，剩下的都在不同阶段闭锁。把“卵巢里的卵泡”听成“都会依次排出来”，闭锁卵泡和间质腺那本账会从一开始就丢掉。
:::

## （一）卵泡的发育与成熟

卵泡由一个卵母细胞（oocyte）和周围的多个卵泡细胞组成，呈球形。卵泡发育是一个连续变化的过程，大致经过原始卵泡、初级卵泡、次级卵泡和成熟卵泡 $4$ 个阶段（图 19-1），其中初级卵泡和次级卵泡又称为生长卵泡。

:::definition{label="卵泡"}
卵泡由一个卵母细胞（oocyte）和周围的多个卵泡细胞组成，呈球形。它是卵巢皮质的功能单位，不是黄体，也不是白体。
:::

:::definition{label="卵母细胞"}
卵母细胞（oocyte）是卵泡中央的生殖细胞。在排卵前绝大多数时间是初级卵母细胞；排卵前 $36\sim 48$ 小时才完成第一次减数分裂，变成次级卵母细胞。
:::

:::definition{label="卵泡细胞"}
卵泡细胞（follicular cell）包在卵母细胞周围。原始卵泡为一层扁平细胞；进入初级卵泡后变为立方或柱状并增殖成多层；次级卵泡以后改称颗粒细胞。
:::

:::definition{label="生长卵泡"}
初级卵泡和次级卵泡合称生长卵泡。原始卵泡处于静止，成熟卵泡已经进入排卵前期，不算在“生长卵泡”这个称呼里。
:::

:::concept{term="先问有没有卵泡腔，再问卵母细胞停在哪一次减数分裂"}
切片上先找球形卵泡，再问两把尺子：细胞之间有没有液腔——没有腔，最多是原始或初级；一出现卵泡腔，就是次级。再问卵母细胞：一直到成熟卵泡的排卵前，腔内仍是初级卵母细胞；排卵前 $36\sim 48$ 小时才变成次级卵母细胞，并停在第二次减数分裂中期。把“次级卵泡”听成“里面已经是次级卵母细胞”，腔的账和减数分裂的账会对错户头。
:::

:::compare{title="原始、初级、次级与成熟卵泡"}
| 项目 | 原始卵泡 | 初级卵泡 | 次级卵泡 | 成熟卵泡 |
|------|----------|----------|----------|----------|
| 别名 | 静止状态 | 生长卵泡 | 生长卵泡 | 优势卵泡进入排卵前期 |
| 位置 | 皮质浅层 | 移向皮质深部 | 皮质 | 占皮质全层并突向卵巢表面 |
| 卵泡细胞 | 一层扁平 | 立方或柱状，单层→多层 | 颗粒层；紧贴透明带者为放射冠 | 颗粒层变薄；卵丘与壁出现裂隙 |
| 卵母细胞 | 初级卵母细胞，停在第一次减数分裂前期 | 初级，增大；出现皮质颗粒 | 初级，达最大体积 $125\sim 150\,\mu\mathrm{m}$ | 排卵前 $36\sim 48$ 小时完成第一次减数分裂，成为次级卵母细胞，停在第二次减数分裂中期 |
| 透明带 | 无 | 出现 | 约 $5\,\mu\mathrm{m}$ 厚 | 有 |
| 卵泡腔 | 无 | 无 | 有（判断尺子） | 很大，卵泡液增多 |
| 卵丘 / 放射冠 | 无 | 无 | 有 | 卵丘渐与卵泡壁分离 |
| 卵泡膜 | 无 | 开始形成 | 分化为内膜层与外膜层 | 有 |
| 直径量级 | 很小 | 增大 | 继续增大 | 可达 $2\,\mathrm{cm}$ |
:::

### 1. 原始卵泡

原始卵泡（primordial follicle）处于静止状态，体积小、数量多，位于皮质浅层，由一个初级卵母细胞（primary oocyte）和周围一层扁平的卵泡细胞组成。初级卵母细胞呈圆形，体积大；核大而圆，略偏位，染色质稀疏浅染，核仁清楚；细胞质丰富，嗜酸性（图 19-2）。电镜下除一般细胞器外，核周围有层状排列的滑面内质网（环层板），可能与核及细胞质间的物质转运有关。初级卵母细胞在胚胎时期由卵原细胞分裂分化而来，随即进入第一次减数分裂并长期停留在分裂前期，直至排卵前才完成分裂。卵泡细胞单层扁平围绕初级卵母细胞，胞体小，核扁圆，着色深。卵泡细胞与周围结缔组织之间有较薄的基膜，与卵母细胞之间有较多缝隙连接，支持和营养卵母细胞。

:::definition{label="原始卵泡"}
原始卵泡（primordial follicle）是处于静止状态的卵泡，体积小、数量多，位于皮质浅层。组成：一个初级卵母细胞 + 周围一层扁平的卵泡细胞。
:::

:::definition{label="初级卵母细胞"}
初级卵母细胞（primary oocyte）呈圆形，体积大；核大而圆，略偏位，染色质稀疏浅染，核仁清楚；胞质丰富、嗜酸性。胚胎期由卵原细胞分裂分化而来，随即进入第一次减数分裂，长期停留在分裂前期，直至排卵前才完成分裂。
:::

:::definition{label="环层板"}
电镜下初级卵母细胞核周围有层状排列的滑面内质网，称为环层板，可能与核及细胞质间的物质转运有关。进入初级卵泡后，环层板大多消失。
:::

:::definition{label="原始卵泡的卵泡细胞"}
单层扁平，胞体小，核扁圆，着色深。与周围结缔组织之间有薄层基膜，与卵母细胞之间有较多缝隙连接，支持和营养卵母细胞。
:::

:::pitfall{label="原始卵泡里的生殖细胞已经是初级卵母细胞，不要写成卵原细胞"}
卵原细胞只存在于胚胎期。出生后原始卵泡中央是初级卵母细胞，并且已经停在第一次减数分裂前期。把原始卵泡写成“卵原细胞 + 扁平卵泡细胞”，减数分裂账会提前一个世代。
:::

### 2. 初级卵泡

初级卵泡（primary follicle）由原始卵泡发育形成，移向皮质深部（图 19-1，图 19-2）。主要结构变化是：① 卵泡细胞由扁平形分化为立方形或柱状，进而增殖，由单层分化为多层；电镜下胞质内粗面内质网、游离核糖体及线粒体均增多，高尔基复合体更加发达。② 初级卵母细胞增大，胞质增多；核变大，呈泡状，核仁染色深；电镜下环层板大多消失，高尔基复合体、粗面内质网、游离核糖体等均增多；浅层胞质出现皮质颗粒，这是一种溶酶体，在受精过程中有防止多精受精的作用。③ 初级卵母细胞与卵泡细胞间出现卵周间隙，内层卵泡细胞的突起和初级卵母细胞的微绒毛均伸向间隙，二者共同的分泌物形成较厚的嗜酸性膜，即透明带（zona pellucida）（图 19-2，图 19-3）。透明带由透明带蛋白（zona protein，ZP）组成，主要有 ZP1、ZP2、ZP3 和 ZP4。其中 ZP3 是第一精子受体，能与顶体完整的精子结合；ZP2 是第二精子受体，与精子顶体内膜结合。卵泡细胞的突起与初级卵母细胞膜可形成缝隙连接，有利于物质交换和信息沟通。④ 随着初级卵泡体积增大，卵泡周围基质中的梭形细胞增殖分化形成卵泡膜（follicular theca）。

:::definition{label="初级卵泡"}
初级卵泡（primary follicle）由原始卵泡发育形成，移向皮质深部。卵泡细胞变为立方或柱状并增殖成多层，出现透明带和卵泡膜，但仍没有卵泡腔。
:::

:::definition{label="皮质颗粒"}
皮质颗粒是初级卵母细胞浅层胞质中的溶酶体。受精时释放，防止多精受精。原始卵泡阶段尚未出现。
:::

:::definition{label="透明带"}
透明带（zona pellucida）是初级卵母细胞与卵泡细胞共同分泌、位于卵周间隙的较厚嗜酸性膜。由透明带蛋白（zona protein，ZP）组成，主要有 ZP1、ZP2、ZP3、ZP4。
:::

:::definition{label="ZP3与ZP2"}
ZP3 是第一精子受体，与顶体完整的精子结合；ZP2 是第二精子受体，与精子顶体内膜结合。顶体反应前后，精子先后认这两把锁。
:::

:::definition{label="卵泡膜"}
卵泡膜（follicular theca）由初级卵泡周围基质中的梭形细胞增殖分化形成。到次级卵泡才明显分成内膜层与外膜层。
:::

::figure{src="/images/histology/textbook/p0212_03.png" caption="图19-3 卵母细胞、透明带及卵泡细胞超微结构模式图。示卵母细胞、嗜酸性透明带和周围卵泡细胞。" alt="超微模式：下方卵母细胞与细胞核，中层红色均质透明带，上方不规则卵泡细胞"}

:::note{label="初级卵泡四件同时发生的事"}
| 变化 | 要点 |
|------|------|
| 卵泡细胞 | 扁平 → 立方 / 柱状 → 多层；RER、核糖体、线粒体、高尔基复合体增多 |
| 初级卵母细胞 | 增大；环层板大多消失；出现皮质颗粒 |
| 透明带 | 卵周间隙中的嗜酸性膜；ZP3、ZP2 分别为第一、第二精子受体 |
| 卵泡膜 | 周围梭形基质细胞增殖分化而成 |
:::

:::pitfall{label="有透明带、多层卵泡细胞仍叫初级卵泡，没有腔就不能升级为次级"}
透明带和卵泡膜从初级卵泡就开始出现。次级卵泡的判断尺子只有一把：卵泡细胞之间出现液腔。把“已经多层、已经有透明带”写成次级卵泡，腔的账会提前一级。
:::

### 3. 次级卵泡

初级卵泡继续生长分化，当卵泡细胞间出现液腔时，称为次级卵泡（secondary follicle）（图 19-1、图 19-2）。主要特点是：① 卵泡细胞间出现大小不等的液腔，继而汇合成一个大腔，称为卵泡腔（follicular cavity）。腔内液体为卵泡液（follicular fluid），含促性腺激素、雌激素、抗中肾旁管激素及多种生物活性物质，对卵泡的生长与成熟起重要调节作用。抗中肾旁管激素能在血清中检出，其水平间接反映生长卵泡数量和原始卵泡库存量的变化，是检测卵巢储备功能较为准确的指标。② 初级卵母细胞达到最大体积，直径 $125\sim 150\,\mu\mathrm{m}$，周围包裹一层约 $5\,\mu\mathrm{m}$ 厚的透明带；紧贴透明带的一层高柱状卵泡细胞呈放射状排列，故名放射冠（corona radiata）。卵泡腔不断扩大，迫使初级卵母细胞、透明带、放射冠与其周围的卵泡细胞逐渐居于卵泡腔一侧，突入卵泡腔，称为卵丘（cumulus oophorus）。③ 分布于卵泡腔周边的卵泡细胞构成卵泡壁，此处细胞体积较小、排列密集呈颗粒状，故又称颗粒层（granulosa layer）。颗粒层的卵泡细胞称为颗粒细胞（granulosa cell）。④ 卵泡膜分化成内、外两层：内膜层含较多血管和多边形的膜细胞（theca cell），具有分泌类固醇激素细胞的结构特点；外膜层纤维较多、血管少，并有少量平滑肌纤维。

:::definition{label="次级卵泡"}
次级卵泡（secondary follicle）是卵泡细胞之间出现液腔之后的生长卵泡。判断标准是卵泡腔，不是“已经变成次级卵母细胞”。
:::

:::definition{label="卵泡腔与卵泡液"}
卵泡腔（follicular cavity）由卵泡细胞间大小不等的液腔汇合而成。卵泡液（follicular fluid）含促性腺激素、雌激素、抗中肾旁管激素及多种生物活性物质，调节卵泡生长与成熟。
:::

:::definition{label="抗中肾旁管激素"}
抗中肾旁管激素能在血清中检出，其水平间接反映生长卵泡数量和原始卵泡库存量的变化，是检测卵巢储备功能较为准确的指标。
:::

:::definition{label="放射冠"}
放射冠（corona radiata）是紧贴透明带的一层高柱状卵泡细胞，呈放射状排列。排卵时它随次级卵母细胞和透明带一起离开卵巢。
:::

:::definition{label="卵丘"}
卵丘（cumulus oophorus）是初级卵母细胞、透明带、放射冠及其周围卵泡细胞突入卵泡腔形成的丘状结构。
:::

:::definition{label="颗粒层与颗粒细胞"}
卵泡腔周边的卵泡细胞构成卵泡壁，细胞较小、排列密集呈颗粒状，称颗粒层（granulosa layer）；其中的细胞称颗粒细胞（granulosa cell）。
:::

:::definition{label="卵泡膜内、外层"}
内膜层：血管多，含多边形膜细胞（theca cell），具类固醇激素分泌细胞结构。外膜层：纤维多、血管少，有少量平滑肌纤维。排卵时外膜层平滑肌收缩参与破壁。
:::

:::pitfall{label="次级卵泡已经有腔，不要把多层无腔的初级卵泡写成次级"}
“次级”指的是卵泡分期，尺子是液腔。次级卵泡里的生殖细胞仍是初级卵母细胞，要到排卵前 $36\sim 48$ 小时才完成第一次减数分裂。把“次级卵泡”听成“次级卵母细胞所在的卵泡”，减数分裂和卵泡腔两本账会对调。
:::

:::insight{label="放射冠贴透明带，颗粒层铺卵泡壁，膜细胞在基膜外侧造雄激素原料"}
次级卵泡把细胞分成三处干活：放射冠贴着透明带养卵母细胞；颗粒层围成卵泡腔；膜细胞在卵泡膜内膜层合成雄激素，再交给颗粒细胞的芳香化酶变成雌激素。把它们写成“都是一层卵泡细胞”，雌激素的两细胞协作账会做丢。
:::

### 4. 成熟卵泡

两侧卵巢同时存在一批次级卵泡。青春期开始，在垂体 FSH 作用下这些次级卵泡进入周期性发育，通常仅一个发育最佳的卵泡能够成熟，称为优势卵泡（dominant follicle）。成熟卵泡可释放抑制素，负反馈作用于垂体，使卵泡刺激素分泌水平降低，导致其他次级卵泡退化。成熟卵泡体积大，直径可达 $2\,\mathrm{cm}$，占据皮质全层并突向卵巢表面。卵泡腔很大，卵泡液增多；颗粒细胞停止增殖，颗粒层相应变薄，卵丘与周围卵泡细胞出现裂隙，逐渐与卵泡壁分离，处于排卵前期（图 19-1）。排卵前 $36\sim 48$ 小时，初级卵母细胞完成第一次减数分裂，形成一个次级卵母细胞（secondary oocyte）和第一极体（first polar body）；次级卵母细胞迅速进入第二次减数分裂，并停滞在分裂中期。第一极体很小，位于次级卵母细胞与透明带之间的卵周间隙内。

次级卵泡与成熟卵泡具有内分泌功能，主要是膜细胞和颗粒细胞在垂体促性腺激素作用下协同合成分泌雌激素。膜细胞合成的雄激素透过基膜进入颗粒细胞，在芳香化酶系作用下转变为雌激素。合成的雌激素小部分进入卵泡腔，大部分释放入血，调节子宫内膜等靶器官的生理活动。

:::definition{label="成熟卵泡"}
成熟卵泡（mature follicle）是能够排卵的优势卵泡。直径可达 $2\,\mathrm{cm}$，占皮质全层并突向卵巢表面；卵泡腔很大，颗粒层变薄，卵丘渐与卵泡壁分离，处于排卵前期。
:::

:::definition{label="优势卵泡"}
优势卵泡（dominant follicle）是一批次级卵泡中发育最佳、能够成熟的那一个。它释放抑制素，负反馈降低 FSH，使其他次级卵泡退化。
:::

:::definition{label="次级卵母细胞"}
排卵前 $36\sim 48$ 小时，初级卵母细胞完成第一次减数分裂，形成次级卵母细胞（secondary oocyte）和第一极体。次级卵母细胞迅速进入第二次减数分裂，停滞在分裂中期，等待受精。
:::

:::definition{label="第一极体"}
第一极体（first polar body）是一个很小的细胞，位于次级卵母细胞与透明带之间的卵周间隙内。它是第一次减数分裂的产物，不是卵子。
:::

:::definition{label="抑制素（卵泡）"}
成熟卵泡释放抑制素，负反馈抑制垂体 FSH，使同期其他次级卵泡退化。同一周期通常只有一个卵泡走完成熟。
:::

:::note{label="雌激素的两细胞协作"}
| 细胞 | 位置 | 产物 |
|------|------|------|
| 膜细胞 | 卵泡膜内膜层，基膜外侧 | 合成雄激素 |
| 颗粒细胞 | 颗粒层，基膜内侧 | 芳香化酶系把雄激素转变为雌激素 |
| 去向 | — | 小部分进入卵泡腔，大部分入血，调节子宫内膜等靶器官 |
:::

:::compare{title="初级卵母细胞、次级卵母细胞与卵子"}
| 项目 | 初级卵母细胞 | 次级卵母细胞 | 卵子 |
|------|--------------|--------------|------|
| 出现时间 | 胚胎期进入第一次减数分裂前期，一直维持到排卵前 | 排卵前 $36\sim 48$ 小时完成第一次减数分裂后 | 受精后完成第二次减数分裂 |
| 停滞点 | 第一次减数分裂前期 | 第二次减数分裂中期 | 不再停滞，形成单倍体卵子 |
| 伴随产物 | — | 第一极体 | 第二极体 |
| 所在卵泡 | 原始、初级、次级及排卵前的成熟卵泡 | 即将排卵的成熟卵泡；排出后仍是次级卵母细胞 | 已受精 |
:::

:::pitfall{label="次级卵泡里还是初级卵母细胞，次级卵母细胞要等到排卵前才出现"}
卵泡的“次级”和卵母细胞的“次级”不是同一把尺子。次级卵泡以卵泡腔命名；次级卵母细胞以完成第一次减数分裂命名。写错户头，放射冠里的那个大细胞会提前减半染色体。
:::

## （二）排卵

随着成熟卵泡的卵泡液剧增，卵泡壁、白膜和表面上皮变薄，卵巢表面局部缺血形成透明的卵泡小斑（follicular stigma）。继而小斑处的胶原被胶原酶、透明质酸酶等解聚和消化，再加上卵泡膜外层的平滑肌收缩等因素，成熟卵泡破裂。从卵泡壁脱落的次级卵母细胞连同透明带、放射冠与卵泡液一起从卵巢排出，这一过程称为排卵（ovulation）（图 19-4，图 19-5）。育龄期妇女每隔约 $28$ 天排一次卵；两侧卵巢交替排卵，一般一次只排一个，偶见排两个或两个以上。排卵一般发生在月经周期的第 $14$ 天左右。排卵后，次级卵母细胞若受精将继续完成第二次减数分裂，产生一个单倍体的卵子（ovum）和一个第二极体（second polar body）；若 $24$ 小时内未受精，则退化被吸收。排卵过程受神经内分泌调节。

:::definition{label="排卵"}
排卵（ovulation）是成熟卵泡破裂后，次级卵母细胞连同透明带、放射冠与卵泡液一起从卵巢排出的过程。
:::

:::definition{label="卵泡小斑"}
卵泡小斑（follicular stigma）是成熟卵泡使卵泡壁、白膜和表面上皮变薄、局部缺血后，在卵巢表面形成的透明区。小斑处胶原被胶原酶、透明质酸酶等解聚消化，外膜层平滑肌收缩，卵泡在此破裂。
:::

:::definition{label="排出物"}
排出的不是“裸卵”，而是次级卵母细胞 + 透明带 + 放射冠 + 卵泡液。第一极体仍在卵周间隙里。
:::

:::definition{label="第二极体与卵子"}
次级卵母细胞受精后才完成第二次减数分裂，产生单倍体卵子（ovum）和第二极体（second polar body）。$24$ 小时内未受精则退化吸收，不会形成卵子。
:::

:::

:::insight{label="小斑是缺血变薄的窗口，酶把胶原拆掉，平滑肌再推一把"}
卵泡液把壁撑薄，表面形成透明小斑；胶原酶和透明质酸酶消化小斑处胶原，外膜层平滑肌收缩，次级卵母细胞才带着透明带和放射冠出去。把排卵写成“卵泡自己裂开、裸卵掉进腹腔”，放射冠和输卵管漏斗的接卵账会对不上图 19-5。
:::

:::pitfall{label="排出的是次级卵母细胞，不是已经完成减数分裂的卵子"}
卵子（ovum）要等受精后第二次减数分裂完成才出现。未受精的次级卵母细胞 $24$ 小时内退化。写“排出一个单倍体卵子”，第二极体那本账会提前发生在卵巢表面。
:::

## （三）黄体的形成与退化

成熟卵泡排卵后，残留的卵泡壁连同卵泡膜及其血管一起向卵泡腔内塌陷。腔内血液凝固，新鲜时因血块可呈红色，即早期黄体（红体）。随后在 LH 作用下逐渐发育成一个体积较大、富含血管的内分泌细胞团，新鲜时呈黄色，故称为黄体（corpus luteum）。颗粒层卵泡细胞体积变大，胞质内含较多脂滴，着色浅，占黄体细胞的多数，位于黄体中央，即颗粒黄体细胞（granulosa lutein cell），主要分泌孕激素和松弛素，后者有抑制子宫平滑肌收缩的作用。膜细胞体积较颗粒黄体细胞小，染色较深，数量较少，位于黄体周边，即膜黄体细胞（theca lutein cell）；膜黄体细胞和颗粒黄体细胞协同合成分泌雌激素。这两种黄体细胞都具有分泌类固醇激素细胞的结构特征（图 19-1，图 19-6）。

黄体发育取决于排出的卵是否受精。如未受精，仅维持 $2$ 周即退化，称为月经黄体（corpus luteum of menstruation）；如受精则可维持 $6$ 个月，甚至更长时间，称为妊娠黄体（corpus luteum of pregnancy）。两种黄体最终都将退化消失，逐渐被增生的结缔组织取代，变成白色瘢痕，即白体（corpus albicans）（图 19-1）。白体可维持数月或数年。

:::definition{label="黄体"}
黄体（corpus luteum）是排卵后残留的卵泡壁、卵泡膜及其血管向腔内塌陷，在 LH 作用下形成的体积较大、富含血管的内分泌细胞团。新鲜时呈黄色。它不是卵泡的别名，里面已经没有卵母细胞。
:::

:::definition{label="红体（早期黄体）"}
排卵后卵泡壁塌陷，腔内血液凝固，新鲜时呈红色，即早期黄体，常称红体。图 19-1 中早期黄体可见凝固的血块与纤维蛋白。随后才在 LH 作用下发育为典型黄体。
:::

:::definition{label="颗粒黄体细胞"}
颗粒黄体细胞（granulosa lutein cell）由颗粒层卵泡细胞转化而来。体积大，胞质含较多脂滴，着色浅，数量多，位于黄体中央。主要分泌孕激素和松弛素。松弛素抑制子宫平滑肌收缩。
:::

:::definition{label="膜黄体细胞"}
膜黄体细胞（theca lutein cell）由膜细胞转化而来。体积较小，染色较深，数量较少，位于黄体周边。与颗粒黄体细胞协同合成分泌雌激素。
:::

:::definition{label="月经黄体"}
排出的卵未受精时，黄体仅维持 $2$ 周即退化，称为月经黄体（corpus luteum of menstruation）。
:::

:::definition{label="妊娠黄体"}
排出的卵受精后，黄体可维持 $6$ 个月甚至更长时间，称为妊娠黄体（corpus luteum of pregnancy）。
:::

:::definition{label="白体"}
月经黄体和妊娠黄体最终都退化，被增生的结缔组织取代，变成白色瘢痕，即白体（corpus albicans）。白体可维持数月或数年。
:::

:::compare{title="红体、黄体与白体"}
| 项目 | 红体（早期黄体） | 黄体 | 白体 |
|------|------------------|------|------|
| 时间 | 排卵后即刻 | LH 作用下发育 | 黄体退化后 |
| 外观 | 腔内血块，新鲜时偏红 | 新鲜时呈黄色 | 白色瘢痕 |
| 细胞 | 塌陷的颗粒层与卵泡膜，血块与纤维蛋白 | 颗粒黄体细胞 + 膜黄体细胞 | 结缔组织取代内分泌细胞 |
| 分泌 | 尚未成为典型内分泌团 | 孕激素、松弛素、雌激素 | 不再分泌激素 |
| 寿命 | 短暂过渡 | 月经黄体约 $2$ 周；妊娠黄体约 $6$ 个月或更长 | 数月或数年 |
:::

:::compare{title="颗粒黄体细胞与膜黄体细胞"}
| 项目 | 颗粒黄体细胞 | 膜黄体细胞 |
|------|--------------|------------|
| 来源 | 颗粒层卵泡细胞 | 卵泡膜的膜细胞 |
| 位置 | 黄体中央 | 黄体周边 |
| 形态 | 体积大，着色浅，脂滴多 | 体积较小，染色较深 |
| 数量 | 占多数 | 较少 |
| 主要分泌 | 孕激素、松弛素 | 与颗粒黄体细胞协同分泌雌激素 |
:::

:::pitfall{label="黄体不是卵泡的别名，红体、黄体、白体也不是三种卵泡"}
卵泡里有卵母细胞和卵泡细胞；排卵后卵已经离开，残留的壁在 LH 下变成内分泌细胞团，才叫黄体。红体是刚塌陷、带血块的早期黄体，白体是黄体退化后的瘢痕。把黄体写成“成熟卵泡的另一个名字”，孕激素和松弛素会算到还没排卵的卵泡头上。
:::

:::insight{label="排卵把卵送走，LH 把剩下的壁改造成激素工厂"}
颗粒细胞改行颗粒黄体细胞，主产孕激素和松弛素；膜细胞改行膜黄体细胞，继续和前者协作产雌激素。未受精只干两周（月经黄体），受精可干半年（妊娠黄体），最后都变成白体。卵泡、黄体、白体是一条时间轴上的三个户头，不是并列的三种卵泡。
:::

## （四）闭锁卵泡与间质腺

卵巢内的绝大多数卵泡不能发育成熟，它们在发育的不同阶段退化。退化的卵泡称为闭锁卵泡（atretic follicle）。原始卵泡和初级卵泡退化时，卵母细胞形态变为不规则，卵泡细胞变小而分散，最后变性消失。次级卵泡和成熟卵泡闭锁时，卵母细胞膜皱缩，核偏位且固缩解体，内质网、线粒体等扩张、肿大，胞质溶解，最后消失；透明带皱缩，颗粒细胞松散，脱落到卵泡腔内，被中性粒细胞和巨噬细胞清除。膜细胞体积增大，形成多边形细胞，胞质中充满脂滴，形似黄体细胞并被结缔组织和血管分隔成分散的细胞团索，称为间质腺（interstitial gland）（图 19-7），也能分泌雌激素。间质腺最后退化，由结缔组织代替。人的间质腺不发达。

:::definition{label="闭锁卵泡"}
闭锁卵泡（atretic follicle）是在发育不同阶段退化的卵泡。原始、初级、次级、成熟卵泡都可以闭锁；绝大多数卵泡的结局是闭锁而不是排卵。
:::

:::definition{label="间质腺"}
次级卵泡和成熟卵泡闭锁时，膜细胞增大为多边形、胞质充满脂滴，形似黄体细胞，被结缔组织和血管分隔成细胞团索，称为间质腺（interstitial gland）。也能分泌雌激素。人的间质腺不发达，最后由结缔组织代替。
:::

::figure{src="/images/histology/textbook/p0214_02.png" caption="图19-7 闭锁卵泡和间质腺。1. 闭锁卵泡；2. 间质腺。" alt="卵巢皮质光镜：右侧皱缩的闭锁卵泡含变性卵母细胞，左侧细胞团索为间质腺，浅层可见原始卵泡"}

:::compare{title="早期闭锁与晚期闭锁"}
| 项目 | 原始 / 初级卵泡闭锁 | 次级 / 成熟卵泡闭锁 |
|------|----------------------|----------------------|
| 卵母细胞 | 形态不规则，变性消失 | 膜皱缩，核偏位固缩解体，细胞器扩张，胞质溶解 |
| 卵泡细胞 / 颗粒细胞 | 变小而分散，变性消失 | 松散脱落入卵泡腔，被中性粒细胞和巨噬细胞清除 |
| 透明带 | 随卵泡消失 | 皱缩 |
| 膜细胞 | 不形成间质腺 | 增大形成间质腺，可分泌雌激素 |
:::

:::pitfall{label="闭锁卵泡不是黄体，间质腺也不是妊娠黄体"}
闭锁是卵泡走不通、中途报废；黄体是排卵成功后残留壁的转化。间质腺来自闭锁卵泡的膜细胞，人又不发达。切片上看到变性卵母细胞和皱缩透明带，户头是闭锁，不要写成“正在形成黄体”。
:::

## （五）门细胞

门细胞（hilus cell）位于卵巢门近系膜处，细胞结构与睾丸间质细胞相似，为多边形或卵圆形，核呈圆形，核仁清楚，胞质嗜酸性，脂滴丰富。妊娠和绝经期时门细胞特别显著。一般认为门细胞分泌雄激素，若门细胞增生或发生肿瘤，患者可出现男性化症状。

:::definition{label="门细胞"}
门细胞（hilus cell）位于卵巢门近系膜处。多边形或卵圆形，核圆、核仁清楚，胞质嗜酸性、脂滴丰富，结构与睾丸间质细胞相似。妊娠和绝经期特别显著。一般认为分泌雄激素；增生或肿瘤可引起男性化症状。
:::

:::compare{title="门细胞与睾丸间质细胞"}
| 项目 | 门细胞 | 睾丸间质细胞 |
|------|--------|--------------|
| 位置 | 卵巢门近系膜处 | 生精小管之间的睾丸间质 |
| 形态 | 多边形或卵圆形，嗜酸性，脂滴丰富 | 圆形或多边形，嗜酸性，类固醇细胞结构 |
| 分泌 | 雄激素 | 睾酮等雄激素 |
| 临床 | 增生或肿瘤 → 男性化 | 分泌不足 → 影响生精和第二性征 |
:::

:::pitfall{label="门细胞在卵巢门，不要写进皮质卵泡或黄体里"}
门细胞跟卵泡细胞、颗粒黄体细胞不是一类。它在卵巢门近系膜处，账本是雄激素和男性化，不是排卵和孕激素。
:::

:::keypoint{label="卵巢先立白膜皮质髓质，再把四级卵泡、排卵和黄体红体白体收口"}
- 女性生殖系统 = 卵巢 + 输卵管 + 子宫 + 阴道 + 外生殖器；乳腺泌乳，列入本章但不是生殖器官。
- 表面上皮深部为白膜；皮质含卵泡与黄体，髓质为疏松结缔组织；门细胞在卵巢门。
- 卵泡四阶段：原始（一层扁平 + 初级卵母细胞）→ 初级（多层、透明带、卵泡膜，无腔）→ 次级（出现卵泡腔、放射冠、卵丘、颗粒层、膜内/外层）→ 成熟（优势卵泡，直径可达 $2\,\mathrm{cm}$）。
- 次级卵泡已有腔；次级卵母细胞要到排卵前 $36\sim 48$ 小时才出现，并停在第二次减数分裂中期。
- 透明带 ZP3、ZP2 分别为第一、第二精子受体；放射冠随卵排出。
- 雌激素：膜细胞产雄激素，颗粒细胞芳香化酶转变为雌激素。
- 排卵约在周期第 $14$ 天；排出次级卵母细胞 + 透明带 + 放射冠；$24$ 小时内未受精则退化。
- 黄体不是卵泡别名。红体（早期黄体，含血块）→ 黄体（颗粒黄体细胞产孕激素和松弛素，膜黄体细胞协同产雌激素）→ 白体。月经黄体 $2$ 周，妊娠黄体约 $6$ 个月。
- 绝大多数卵泡闭锁；次级/成熟卵泡闭锁可形成间质腺（人的不发达）。
:::

:::memory{label="本节必背要点"}
- [ ] 女性生殖系统由卵巢、输卵管、子宫、阴道和外生殖器组成。
- [ ] 卵巢产生卵子并分泌性激素；输卵管是受精场所并输送生殖细胞；子宫形成月经并孕育胎儿。
- [ ] 自青春期开始，卵巢排卵并分泌性激素，子宫内膜出现周期性变化；更年期卵巢功能逐渐减退。
- [ ] 卵巢（ovary）表面覆有单层扁平或立方形上皮，深部为薄层致密结缔组织构成的白膜。
- [ ] 实质分外周皮质和中央髓质，二者分界不明显。
- [ ] 皮质较厚，由不同发育阶段的卵泡、黄体及富含梭形基质细胞和网状纤维的结缔组织构成。
- [ ] 髓质较薄，为疏松结缔组织，含较多弹性纤维、血管、淋巴管和神经。
- [ ] 卵巢门基质内有少量平滑肌及门细胞。
- [ ] 新生儿期有 $70$ 万 $\sim$ $200$ 万个原始卵泡；青春期开始约 $4$ 万个； $40\sim 50$ 岁仅剩几百个。
- [ ] 每 $28$ 天有 $15\sim 20$ 个卵泡生长发育，一般只有一个优势卵泡成熟并排卵。
- [ ] 一生排卵 $400$ 余个，其余大部分退化为闭锁卵泡；绝经期后不再排卵。
- [ ] 卵泡由一个卵母细胞和周围多个卵泡细胞组成，呈球形。
- [ ] 卵泡发育经历原始卵泡、初级卵泡、次级卵泡和成熟卵泡 $4$ 个阶段；初级和次级卵泡又称生长卵泡。
- [ ] 原始卵泡（primordial follicle）处于静止，体积小、数量多，位于皮质浅层。
- [ ] 原始卵泡由一个初级卵母细胞和周围一层扁平卵泡细胞组成。
- [ ] 初级卵母细胞圆形、体积大；核大而圆、略偏位，染色质稀疏浅染，核仁清楚；胞质丰富、嗜酸性。
- [ ] 电镜下初级卵母细胞核周围有环层板（层状滑面内质网）。
- [ ] 初级卵母细胞由胚胎期卵原细胞分裂分化而来，进入第一次减数分裂并长期停留在分裂前期，直至排卵前才完成分裂。
- [ ] 原始卵泡的卵泡细胞扁平，与结缔组织之间有薄层基膜，与卵母细胞之间有缝隙连接。
- [ ] 初级卵泡（primary follicle）由原始卵泡发育，移向皮质深部。
- [ ] 初级卵泡的卵泡细胞由扁平变为立方或柱状，并由单层增殖为多层。
- [ ] 初级卵母细胞增大，环层板大多消失，浅层胞质出现皮质颗粒（溶酶体，防止多精受精）。
- [ ] 初级卵母细胞与卵泡细胞间出现卵周间隙，共同分泌物形成透明带（zona pellucida）。
- [ ] 透明带由 ZP1、ZP2、ZP3、ZP4 组成；ZP3 是第一精子受体，ZP2 是第二精子受体。
- [ ] 卵泡细胞突起与初级卵母细胞膜可形成缝隙连接。
- [ ] 初级卵泡周围梭形基质细胞增殖分化形成卵泡膜（follicular theca）。
- [ ] 次级卵泡（secondary follicle）的判断标准是卵泡细胞间出现液腔。
- [ ] 液腔汇合成卵泡腔，腔内为卵泡液，含促性腺激素、雌激素、抗中肾旁管激素等。
- [ ] 抗中肾旁管激素血清水平可间接反映生长卵泡数量和原始卵泡库存，是卵巢储备功能指标。
- [ ] 次级卵泡中初级卵母细胞达最大体积，直径 $125\sim 150\,\mu\mathrm{m}$，透明带约 $5\,\mu\mathrm{m}$ 厚。
- [ ] 紧贴透明带的一层高柱状卵泡细胞呈放射状排列，称放射冠（corona radiata）。
- [ ] 卵母细胞、透明带、放射冠突入卵泡腔，称卵丘（cumulus oophorus）。
- [ ] 卵泡腔周边的卵泡细胞构成颗粒层，细胞称颗粒细胞。
- [ ] 卵泡膜分化为内膜层（血管多、含膜细胞）和外膜层（纤维多、少量平滑肌）。
- [ ] 膜细胞具有分泌类固醇激素细胞的结构特点。
- [ ] 通常仅一个优势卵泡（dominant follicle）能够成熟；成熟卵泡释放抑制素，负反馈降低 FSH。
- [ ] 成熟卵泡直径可达 $2\,\mathrm{cm}$，占皮质全层并突向卵巢表面；颗粒层变薄，卵丘与壁分离。
- [ ] 排卵前 $36\sim 48$ 小时，初级卵母细胞完成第一次减数分裂，形成次级卵母细胞和第一极体。
- [ ] 次级卵母细胞迅速进入第二次减数分裂，停滞在分裂中期；第一极体位于卵周间隙。
- [ ] 膜细胞合成雄激素，透过基膜进入颗粒细胞，经芳香化酶转变为雌激素。
- [ ] 雌激素小部分进入卵泡腔，大部分入血，调节子宫内膜等靶器官。
- [ ] 卵巢表面局部缺血形成卵泡小斑（follicular stigma）；胶原酶、透明质酸酶及外膜平滑肌收缩导致破裂。
- [ ] 排卵（ovulation）排出次级卵母细胞、透明带、放射冠和卵泡液。
- [ ] 约每 $28$ 天排一次卵，一般在月经周期第 $14$ 天左右；两侧交替，通常一次一个。
- [ ] 受精则完成第二次减数分裂，产生单倍体卵子和第二极体；$24$ 小时内未受精则退化吸收。
- [ ] 排卵后残留卵泡壁塌陷，早期因血块可呈红色，称红体（早期黄体）。
- [ ] 在 LH 作用下形成黄体（corpus luteum）；新鲜时呈黄色。
- [ ] 颗粒黄体细胞位于中央，着色浅、数量多，主要分泌孕激素和松弛素。
- [ ] 松弛素抑制子宫平滑肌收缩。
- [ ] 膜黄体细胞位于周边，体积较小、染色较深，与颗粒黄体细胞协同分泌雌激素。
- [ ] 未受精为月经黄体，维持约 $2$ 周；受精为妊娠黄体，可维持 $6$ 个月甚至更长。
- [ ] 黄体最终被结缔组织取代，变成白体（corpus albicans），可维持数月或数年。
- [ ] 黄体不是卵泡的别名。
- [ ] 绝大多数卵泡不能成熟，退化成为闭锁卵泡（atretic follicle）。
- [ ] 原始和初级卵泡闭锁时，卵母细胞形态不规则，卵泡细胞变小分散后消失。
- [ ] 次级和成熟卵泡闭锁时，透明带皱缩，颗粒细胞脱落被中性粒细胞和巨噬细胞清除。
- [ ] 闭锁时膜细胞增大形成间质腺（interstitial gland），可分泌雌激素；人的间质腺不发达。
- [ ] 门细胞（hilus cell）位于卵巢门近系膜处，结构似睾丸间质细胞，分泌雄激素。
- [ ] 妊娠和绝经期门细胞特别显著；增生或肿瘤可引起男性化症状。
:::
