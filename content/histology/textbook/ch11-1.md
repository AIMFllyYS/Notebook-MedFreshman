# 一、表皮

皮肤（skin）是人体面积最大的器官，由表皮和真皮构成，以皮下组织与深层组织相连（图 11-1）。皮肤厚度随身体部位和个体的年龄差异而异，为 $0.5\sim 4\,\mathrm{mm}$。皮肤有毛、皮脂腺、汗腺和指（趾）甲等，它们均为表皮衍生的皮肤附属器。皮肤与外界直接接触，能阻挡异物和病原体侵入，防止体液丢失，具有重要的屏障保护作用。皮肤内有丰富的感觉神经末梢，能感受外界多种刺激。皮肤还有调节体温、排出代谢产物、参与合成维生素 D 等功能。本章先把表皮的角化五层和非角质形成细胞摊开；真皮、附属器和再生各立一节。

:::definition{label="皮肤"}
皮肤（skin）是人体面积最大的器官，由表皮和真皮构成，以皮下组织与深层组织相连。厚度随部位和年龄而异，为 $0.5\sim 4\,\mathrm{mm}$。毛、皮脂腺、汗腺和指（趾）甲均为表皮衍生的皮肤附属器。
:::

:::definition{label="皮肤的主要功能"}
皮肤与外界直接接触，能阻挡异物和病原体侵入、防止体液丢失，具有屏障保护作用；内有丰富的感觉神经末梢，能感受外界多种刺激；还能调节体温、排出代谢产物、参与合成维生素 D。
:::

:::concept{term="先问皮肤有几层：表皮加真皮，还是把皮下组织也算进去"}
教材把皮肤写成表皮加真皮两层，皮下组织只是把皮肤连到深层的浅筋膜，不算进皮肤本体。附属器（毛、皮脂腺、汗腺、指趾甲）是表皮衍生出来的，不是另长的第四套器官。把皮肤听成“只有表皮”，真皮乳头和网织那一本账会做丢；把皮下脂肪也算成皮肤第三层，又和解剖学浅筋膜对着干。
:::

:::compare{title="表皮、真皮与皮下组织"}
| 项目 | 表皮 | 真皮 | 皮下组织 |
|------|------|------|----------|
| 英文 | epidermis | dermis | subcutaneous tissue |
| 是否算皮肤 | 是，浅层 | 是，深层 | 否；解剖学称浅筋膜，把皮肤连到深层 |
| 组织性质 | 角化的复层扁平上皮 | 致密结缔组织（乳头层 + 网织层） | 疏松结缔组织 + 脂肪组织 |
| 血管 | 无，靠真皮乳头毛细血管供养 | 丰富 | 丰富 |
| 本章位置 | 本节 | 第二节 | 随真皮一并交代 |
:::

:::pitfall{label="附属器是表皮衍生的，不要写成真皮里另长出来的器官"}
毛囊上皮根鞘与表皮相连续，皮脂腺、汗腺导管也与表皮相接。它们长在真皮甚至皮下，来源账却记在表皮上。把附属器听成“真皮的腺体”，毛母质干细胞和汗腺导管提供表皮再生小岛那两本账都会写错层。
:::

::figure{src="/images/histology/textbook/p0129_02.png" caption="图11-1 手掌皮肤光镜图。1. 表皮角质层；2. 真皮乳头层；3. 真皮网织层；4. 汗腺；5. 螺旋状汗腺导管；6. 皮下组织。" alt="手掌厚皮全层：厚角质层、乳头层、网织层、盘曲汗腺、表皮内螺旋导管和皮下脂肪"}

表皮（epidermis）是皮肤的浅层，由角化的复层扁平上皮构成。根据表皮的厚度，皮肤可分为厚皮和薄皮。厚皮仅位于手掌和足底，其他部位均为薄皮。表皮细胞分为两大类，一类是角质形成细胞（keratinocyte），占表皮细胞的 $90\%$ 以上；另一类是非角质形成细胞，散在于角质形成细胞之间，包括黑素细胞、梅克尔细胞和朗格汉斯细胞。

:::definition{label="表皮"}
表皮（epidermis）是皮肤的浅层，由角化的复层扁平上皮构成。细胞分两大类：角质形成细胞占 $90\%$ 以上；非角质形成细胞散在其间，包括黑素细胞、梅克尔细胞和朗格汉斯细胞。
:::

:::definition{label="厚皮与薄皮"}
根据表皮厚度，皮肤分为厚皮和薄皮。厚皮仅位于手掌和足底；其他部位均为薄皮。厚皮从基底到表面可分出基底层、棘层、颗粒层、透明层和角质层 5 层；薄皮的颗粒层和透明层不明显，角质层较薄。
:::

:::definition{label="角质形成细胞"}
角质形成细胞（keratinocyte）占表皮细胞的 $90\%$ 以上，构成表皮的主体层次。从基底层增殖、迁移，逐渐分化为角质细胞后脱落，更新周期为 $3\sim 4$ 周。
:::

:::definition{label="非角质形成细胞"}
非角质形成细胞散在于角质形成细胞之间，包括黑素细胞、梅克尔细胞和朗格汉斯细胞。它们不参与角化分层，各管黑色素、轻触觉和抗原呈递。
:::

:::compare{title="厚皮与薄皮"}
| 项目 | 厚皮 | 薄皮 |
|------|------|------|
| 部位 | 仅手掌和足底 | 身体其余部位 |
| 五层是否齐全 | 基底层、棘层、颗粒层、透明层、角质层均明显 | 颗粒层和透明层不明显 |
| 角质层 | 很厚 | 较薄 |
| 毛与皮脂腺 | 无毛、无皮脂腺 | 大多有毛和皮脂腺 |
| 汗腺 | 尤其多 | 有，密度因部位而异 |
| 光镜第一眼 | 嗜酸性均质厚板（角质层）+ 亮带（透明层） | 角质层薄，层次压缩 |
:::

:::pitfall{label="厚皮不是“毛多的皮肤”，而是无毛的手掌足底"}
厚、薄是按表皮厚度、尤其是角质层和透明层来分的。手掌足底无毛、无皮脂腺，却是全身最厚的皮；头皮毛囊密集，表皮反而是薄皮。把“厚皮”听成“长毛的粗皮”，五层账和附属器账会一起错位。
:::

:::insight{label="表皮自己没有血管，营养从真皮乳头渗上来"}
角化复层扁平上皮是屏障，不是供血面。基底细胞贴在基膜上，养分来自真皮乳头里的毛细血管（图 11-1、图 11-2）。把表皮写成“自己带血管的上皮”，或把螺旋状汗腺导管当成血管断面，手掌切片的层次账会从第一眼就乱。
:::

## （一）表皮分层和角化

手掌和足底的表皮结构，从基底到表面可分为基底层、棘层、颗粒层、透明层和角质层 5 层（图 11-2）。薄皮表皮的颗粒层和透明层不明显，并且角质层较薄（图 11-3）。

:::concept{term="先从基底往表面数五层，再问薄皮少了哪两层"}
厚皮是读层次的标准尺：基底层（干细胞）→ 棘层（桥粒和板层颗粒）→ 颗粒层（透明角质颗粒）→ 透明层（核已消失的亮带）→ 角质层（干硬角质细胞）。薄皮不是另造一套上皮，只是颗粒层、透明层不明显、角质层变薄。考试切片若一上来找不到透明层，先问是不是体皮，不要把五层硬套上去。
:::

### 1. 基底层

基底层（stratum basale）附着于基膜上，由一层矮柱状基底细胞（basal cell）组成。细胞质内因富含游离核糖体而呈嗜碱性（图 11-2），有散在或成束的角蛋白丝（keratin filament）。角蛋白丝直径 $10\,\mathrm{nm}$，属中间丝，因具有很强的张力，又称张力丝（tonofilament）。基底细胞与相邻细胞以桥粒相连，与基膜以半桥粒相连（图 11-4）。基底细胞是表皮的干细胞，不断分裂，增殖形成的部分子细胞脱离基膜后进入棘层，分化为棘细胞并失去分裂能力。在皮肤创伤愈合中，基底细胞具有重要的再生修复作用。

:::definition{label="基底层"}
基底层（stratum basale）附着于基膜上，由一层矮柱状基底细胞组成。胞质因富含游离核糖体而呈嗜碱性，含散在或成束的角蛋白丝。
:::

:::definition{label="基底细胞"}
基底细胞（basal cell）是表皮的干细胞。与相邻细胞以桥粒相连，与基膜以半桥粒相连。不断分裂，部分子细胞脱离基膜进入棘层，分化为棘细胞并失去分裂能力；在皮肤创伤愈合中承担再生修复。
:::

:::definition{label="角蛋白丝"}
角蛋白丝（keratin filament）直径 $10\,\mathrm{nm}$，属中间丝，因张力很强又称张力丝（tonofilament）。基底细胞内散在或成束；棘细胞中常成束，从核周放射状延伸至桥粒内侧。
:::

:::note{label="基底层的连接账"}
| 界面 | 连接 | 意义 |
|------|------|------|
| 基底细胞 ↔ 相邻角质形成细胞 | 桥粒 | 把即将上迁的细胞先钉在这一层 |
| 基底细胞 ↔ 基膜 | 半桥粒 | 把整张表皮锚在真皮上 |
| 黑素细胞 ↔ 角质形成细胞 | 无桥粒 | 黑素细胞不是角化系列，突起只是伸入细胞间隙 |
:::

:::pitfall{label="基底细胞嗜碱是因为核糖体，不要当成黑素颗粒"}
HE 里贴基膜的那一层矮柱状细胞胞质偏蓝，是游离核糖体在合成角蛋白，不是把黑色素造在自己家里。黑素颗粒主要在被转入的角质形成细胞里；黑素细胞本身胞质透明、突起不易辨认。把基底层的嗜碱写成“色素层”，人种肤色和多巴染色那两本账都会做反。
:::

::figure{src="/images/histology/textbook/p0130_03.png" caption="图11-4 角质形成细胞和黑素细胞超微结构模式图。示基底细胞以半桥粒连基膜、以桥粒互连；棘细胞含角蛋白丝束和板层颗粒；黑素细胞突起伸入细胞之间，含黑素体与黑素颗粒。" alt="表皮超微模式：基底细胞、棘细胞、颗粒层、角质细胞与树枝状黑素细胞"}

### 2. 棘层

棘层（stratum spinosum）由 $4\sim 10$ 层多边形、体积较大的棘细胞（spinous cell）组成。细胞表面有许多短小棘状突起，相邻细胞的突起镶嵌，细胞质呈弱嗜碱性（图 11-2）。电镜下，相邻细胞的棘状突起由桥粒相连。细胞游离核糖体较多，合成蛋白质功能旺盛。合成的角蛋白丝常呈束分布，从核周呈放射状延伸至桥粒内侧；合成的内披蛋白（involucrin）沉积在细胞膜内侧，使细胞膜增厚。细胞质内还合成一种含糖脂的膜被颗粒，呈明暗相间的板层状，故称板层颗粒（lamellated granule），主要分布于细胞周边，并以胞吐的方式将糖脂排放到细胞间隙，形成膜状物，可阻止外界物质尤其是水透过表皮，还能防止组织液外渗。棘层的深层细胞内仍有黑素颗粒，浅层细胞内黑素颗粒大多被降解。

:::definition{label="棘层"}
棘层（stratum spinosum）由 $4\sim 10$ 层多边形、体积较大的棘细胞组成。细胞表面有许多短小棘状突起，相邻突起镶嵌；胞质弱嗜碱性。
:::

:::definition{label="棘细胞"}
棘细胞（spinous cell）游离核糖体较多，蛋白质合成旺盛。角蛋白丝成束，从核周放射至桥粒内侧；内披蛋白沉积于细胞膜内侧使膜增厚；并合成板层颗粒，以胞吐把糖脂排入细胞间隙。
:::

:::definition{label="内披蛋白"}
内披蛋白（involucrin）由棘细胞合成，沉积在细胞膜内侧，使细胞膜增厚。角质层细胞膜因内面有一层内披蛋白而坚固。
:::

:::definition{label="板层颗粒"}
板层颗粒（lamellated granule）是棘细胞合成的含糖脂的膜被颗粒，呈明暗相间的板层状，主要分布于细胞周边。以胞吐将糖脂排入细胞间隙，形成膜状物，阻止外界物质尤其是水透过表皮，并防止组织液外渗。
:::

:::insight{label="棘层把两道墙同时砌上：里面是张力丝，外面是糖脂"}
桥粒加角蛋白丝束，是机械墙，让表皮扯不散；板层颗粒吐出的糖脂膜状物，是防水墙，让水和溶质过不去。内披蛋白把细胞膜本身加厚，为角质层的“死细胞外壳”预作准备。把棘层只背成“细胞长刺”，屏障功能会只剩下形态学名词。
:::

:::pitfall{label="光镜下的“棘”是桥粒把突起钉住后的收缩假象，不要当成纤毛或微绒毛"}
制片时细胞稍一缩，桥粒拉着的短突起就变成棘。电镜下棘与棘相对处是桥粒，不是游离的运动结构。也不要把板层颗粒当成黑素颗粒：前者在周边、吐糖脂；后者在深层棘细胞胞质内，到浅层大多被降解。
:::

:::note{label="黑素颗粒在棘层的纵向分布"}
棘层深层细胞内仍有黑素颗粒，浅层细胞内黑素颗粒大多被降解。所以薄皮切片上棕色带往往贴着基底侧，不要要求角质层里也铺满黑素。
:::

### 3. 颗粒层

颗粒层（stratum granulosum）由 $3\sim 5$ 层梭形细胞组成（图 11-2）。颗粒层细胞的核与细胞器已退化，细胞质内板层颗粒增多，还出现许多形状不规则、强嗜碱性的透明角质颗粒（keratohyalin granule）。电镜下，透明角质颗粒无膜包裹，呈致密均质状，角蛋白丝常埋入其中。颗粒内为富含组氨酸的蛋白质。

:::definition{label="颗粒层"}
颗粒层（stratum granulosum）由 $3\sim 5$ 层梭形细胞组成。核与细胞器已退化；胞质内板层颗粒增多，并出现许多形状不规则、强嗜碱性的透明角质颗粒。
:::

:::definition{label="透明角质颗粒"}
透明角质颗粒（keratohyalin granule）无膜包裹，电镜下呈致密均质状，角蛋白丝常埋入其中；颗粒内为富含组氨酸的蛋白质。到角质层，这些蛋白质与角蛋白丝组成均质状复合物，即角蛋白。
:::

:::pitfall{label="透明角质颗粒强嗜碱，不要和板层颗粒、黑素颗粒混成一种“皮里的颗粒”"}
三套颗粒职分不同：透明角质颗粒无膜、强嗜碱、富含组氨酸蛋白，是角化的原料；板层颗粒有膜、板层状、吐糖脂做屏障；黑素颗粒有膜、含黑色素、来自黑素细胞。HE 里颗粒层那一排深蓝不规则块，是透明角质颗粒，不是黑素，也不是板层颗粒。
:::

### 4. 透明层

透明层（stratum lucidum）由 $2\sim 3$ 层扁平细胞组成。细胞界限不清，细胞核和细胞器由于溶酶体的作用均已消失。HE 染色标本此层呈强嗜酸性，折光度高（见图 11-2）。细胞的超微结构与角质层相似。

:::definition{label="透明层"}
透明层（stratum lucidum）由 $2\sim 3$ 层扁平细胞组成。细胞界限不清，细胞核和细胞器因溶酶体作用均已消失。HE 呈强嗜酸性、折光度高；超微结构与角质层相似。厚皮明显，薄皮不明显。
:::

:::pitfall{label="透明层是厚皮的亮带，不要在薄皮切片里硬找一层"}
透明层出现在手掌、足底那种厚角质层下方，HE 发亮、嗜酸。体皮角质层薄，这一层往往压在颗粒层和角质层之间看不清。找不到透明层先问是不是薄皮，不要据此说“标本缺层”或把角质层底部误标成透明层。
:::

### 5. 角质层

角质层（stratum corneum）由多层扁平角质细胞（horny cell）组成。细胞已完全角化，变得干硬，光镜下呈嗜酸性均质状（见图 11-1、图 11-2）。电镜下，细胞内充满粗大的角蛋白丝束及均质状物质，后者主要为透明角质颗粒所含的富有组氨酸的蛋白质。角蛋白丝与均质状物质的复合物称角蛋白。细胞膜因内面有一层内披蛋白而坚固，细胞间隙充满由糖脂构成的膜状物。角质层浅表细胞间的桥粒已消失，细胞连接松散，脱落后成为皮屑。

:::definition{label="角质层"}
角质层（stratum corneum）由多层扁平角质细胞组成。细胞已完全角化、干硬，光镜呈嗜酸性均质状。细胞膜因内披蛋白而坚固，细胞间隙充满糖脂膜状物。浅表桥粒消失，细胞连接松散，脱落后成为皮屑。
:::

:::definition{label="角质细胞"}
角质细胞（horny cell）是完全角化的终末细胞。电镜下胞内充满粗大角蛋白丝束及均质状物质（主要来自透明角质颗粒中富含组氨酸的蛋白质）；核和细胞器已消失。
:::

:::definition{label="角蛋白"}
角蛋白是角蛋白丝与均质状物质（透明角质颗粒所含富含组氨酸的蛋白质）的复合物。它使角质细胞干硬坚固，表皮因而对多种物理和化学性刺激有很强的耐受性。
:::

表皮由基底层到角质层的结构变化，反映了角质形成细胞增殖、迁移，逐渐分化为角质细胞然后脱落的新陈代谢过程，与此伴随的是角蛋白及其他成分合成量与质的变化。干硬坚固的角质细胞使表皮对多种物理和化学性刺激有很强的耐受性。角质形成细胞不断脱落和更新，周期为 $3\sim 4$ 周。

:::definition{label="表皮更新周期"}
角质形成细胞从基底层增殖，经棘层、颗粒层（厚皮还经透明层）分化为角质细胞并脱落，周期为 $3\sim 4$ 周。这一过程即表皮的生理性再生。
:::

:::compare{title="表皮角质形成细胞五层"}
| 层次 | 英文 | 细胞 | 层数与形态 | 光镜 | 关键结构 | 分裂能力 |
|------|------|------|------------|------|----------|----------|
| 基底层 | stratum basale | 基底细胞 | 一层矮柱状，贴基膜 | 嗜碱性 | 游离核糖体；张力丝；桥粒、半桥粒 | 有，是干细胞 |
| 棘层 | stratum spinosum | 棘细胞 | $4\sim 10$ 层多边形 | 弱嗜碱性，细胞有棘 | 角蛋白丝束、内披蛋白、板层颗粒 | 已失去 |
| 颗粒层 | stratum granulosum | 梭形细胞 | $3\sim 5$ 层 | 强嗜碱性透明角质颗粒 | 透明角质颗粒（无膜）、板层颗粒增多；核与细胞器退化 | 无 |
| 透明层 | stratum lucidum | 扁平细胞 | $2\sim 3$ 层 | 强嗜酸、折光高，界限不清 | 核和细胞器已消失；结构近角质层 | 无 |
| 角质层 | stratum corneum | 角质细胞 | 多层扁平 | 嗜酸性均质状 | 角蛋白；内披蛋白坚膜；间隙糖脂；浅表桥粒消失 | 无，脱落为皮屑 |
:::

:::insight{label="五层不是五张墙，是同一批细胞在 $3\sim 4$ 周里改写自己"}
从嗜碱的干细胞到嗜酸的死壳，核糖体、透明角质颗粒、板层颗粒、内披蛋白和角蛋白丝按层交接。层次账一旦背成“五种不同的上皮细胞”，再生、角化不全和银屑病那种“周期缩短、鳞屑增多”就没有细胞学落点。
:::

## （二）非角质形成细胞

### 1. 黑素细胞

黑素细胞（melanocyte）是生成黑色素的细胞。细胞体多分散于基底细胞之间，其突起伸入基底细胞和棘细胞之间。在 HE 染色切片上细胞体呈圆形，细胞核深染而细胞质透明，突起不易辨认（见图 11-3）。电镜下，黑素细胞与角质形成细胞之间无桥粒连接，细胞质内有特征性小泡状黑素体（melanosome），由高尔基复合体形成，内含酪氨酸酶，能将酪氨酸转化为黑色素（melanin）。当黑素体内出现黑色素后，改称黑素颗粒（melanin granule），多巴染色法呈黄褐色（图 11-6）。黑素颗粒形成后迅速沿微管迁移并聚集于细胞突起末端，然后被角质形成细胞吞入，黑素颗粒便如此转移至角质形成细胞质内，故黑素颗粒于黑素细胞中很少，在角质形成细胞中反而较多（见图 11-3）。黑色素能吸收紫外线，防止紫外线对角质形成细胞核中 DNA 产生辐射损伤。紫外线可激活酪氨酸酶活性，促进黑色素合成和黑素颗粒快速释放。

:::definition{label="黑素细胞"}
黑素细胞（melanocyte）是生成黑色素的细胞。胞体多分散于基底细胞之间，突起伸入基底细胞和棘细胞之间。HE 上胞体圆形，核深染、胞质透明，突起不易辨认。与角质形成细胞之间无桥粒。
:::

:::definition{label="黑素体"}
黑素体（melanosome）是黑素细胞胞质内的特征性小泡，由高尔基复合体形成，内含酪氨酸酶，能将酪氨酸转化为黑色素。
:::

:::definition{label="黑素颗粒"}
黑素体内出现黑色素后改称黑素颗粒（melanin granule）。多巴染色呈黄褐色。形成后沿微管迁至突起末端，被角质形成细胞吞入，故黑素颗粒在黑素细胞中很少，在角质形成细胞中反而较多。
:::

:::definition{label="黑色素"}
黑色素（melanin）由酪氨酸经酪氨酸酶转化而来，能吸收紫外线，防止紫外线对角质形成细胞核中 DNA 产生辐射损伤。紫外线可激活酪氨酸酶，促进黑色素合成和黑素颗粒快速释放。
:::

:::concept{term="先问黑素颗粒在谁的胞质里"}
黑素细胞是“制造并交货”的细胞，不是“自己装满色素”的细胞。HE 里基底层那些装满棕粒的往往是角质形成细胞；真正的黑素细胞胞质透亮，多巴染色才把突起打成黄褐色。把“谁颜色深”当成“谁在造色素”，黑素体和酪氨酸酶那一本账会记到错误的细胞上。
:::

表皮中的黑素细胞有别于眼球壁血管膜中的黑素细胞，后者内含大量黑素颗粒。机体的黑素细胞均由胚胎时期的神经嵴细胞增殖分化而来，极少量进入眼球壁血管膜外，其余迁入表皮和毛球。但可有少量黑素细胞滞留于真皮或真皮与表皮交界处，并在该部位增殖为团状，称色素痣或黑痣，几乎所有人都有。在少数人，滞留在真皮里的黑素细胞较多，范围较大，形成的青斑称为胎记。

:::definition{label="黑素细胞的来源与去向"}
机体的黑素细胞均由胚胎神经嵴细胞增殖分化而来：极少量进入眼球壁血管膜，其余迁入表皮和毛球。滞留于真皮或真皮与表皮交界处并增殖成团者称色素痣或黑痣；滞留真皮较多、范围较大形成的青斑称为胎记。
:::

:::pitfall{label="表皮黑素细胞胞质里颗粒很少，不要和脉络膜黑素细胞画等号"}
眼球壁血管膜中的黑素细胞自己囤大量黑素颗粒；表皮黑素细胞把颗粒转交给角质形成细胞，自身反而显得“空”。来源都是神经嵴，职分和光镜像却不是同一本账。
:::

人种间的黑素细胞数量无明显差别，肤色深浅主要取决于黑素细胞合成黑素颗粒的能力及分布。黑种人的黑素颗粒多而大，分布于表皮全层；白种人的黑素颗粒少而小，主要分布于基底层；黄种人介于两者之间。此外，肤色也与表皮厚度、血液的供应量有关。

:::compare{title="人种肤色与黑素颗粒"}
| 项目 | 黑种人 | 黄种人 | 白种人 |
|------|--------|--------|--------|
| 黑素细胞数量 | 无明显差别 | 同左 | 同左 |
| 颗粒 | 多而大 | 介于两者之间 | 少而小 |
| 分布 | 表皮全层 | 介于两者之间 | 主要在基底层 |
| 其他影响因素 | 肤色还与表皮厚度、血液供应量有关 | 同左 | 同左 |
:::

:::pitfall{label="肤色深不是因为黑素细胞更多"}
人种间黑素细胞数量无明显差别。差别在合成黑素颗粒的能力、颗粒大小和分布层次，再加上表皮厚度和血供。把肤色背成“黑素细胞个数”，紫外线激活酪氨酸酶、晒黑和白癜风那几本账都没有正确的细胞学分母。
:::

### 2. 朗格汉斯细胞

朗格汉斯细胞（Langerhans cell）散在于棘层浅部，在 HE 染色切片上呈圆形，细胞核深染，细胞质清亮；用 ATP 酶组织化学染色可显示该细胞的树枝状突起（图 11-7）。电镜下，可见细胞质内有特征性伯贝克颗粒（Birbeck granule），呈杆状或网球拍形，中等电子密度，其一端或中间部可见一个圆形透明膨大。伯贝克颗粒参与处理抗原。朗格汉斯细胞能捕获皮肤中的抗原物质，处理后形成抗原肽–MHC 分子复合物分布于细胞表面，然后细胞游走出表皮，进入毛细淋巴管，随淋巴迁至淋巴结，将抗原呈递给 T 淋巴细胞，引发免疫应答。因此，朗格汉斯细胞是一种抗原呈递细胞，在多种炎症情况下数量增多，如接触性皮炎等。所以，此细胞在对抗侵入皮肤的病原微生物、监视癌变细胞中起重要作用。

:::definition{label="朗格汉斯细胞"}
朗格汉斯细胞（Langerhans cell）散在于棘层浅部。HE 上呈圆形，核深染、胞质清亮；ATP 酶组织化学染色可显示树枝状突起。是皮肤的抗原呈递细胞。
:::

:::definition{label="伯贝克颗粒"}
伯贝克颗粒（Birbeck granule）是朗格汉斯细胞胞质内的特征性颗粒，呈杆状或网球拍形，中等电子密度，一端或中间部有圆形透明膨大。参与处理抗原。
:::

:::definition{label="朗格汉斯细胞的抗原呈递"}
朗格汉斯细胞捕获皮肤中的抗原，处理后形成抗原肽–MHC 分子复合物分布于细胞表面，再游走出表皮，经毛细淋巴管迁至淋巴结，将抗原呈递给 T 淋巴细胞，引发免疫应答。接触性皮炎等多种炎症时数量增多；在对抗侵入皮肤的病原微生物、监视癌变细胞中起重要作用。
:::

:::concept{term="棘层浅部那颗透亮细胞，先问是朗格汉斯还是黑素细胞"}
两者 HE 都可以“核深、胞质清亮”，位置却不同：黑素细胞在基底细胞之间，朗格汉斯细胞在棘层浅部。要看突起，黑素细胞用多巴，朗格汉斯细胞用 ATP 酶。把所有透亮细胞都写成黑素细胞，接触性皮炎和 APC 账会从表皮里消失。
:::

:::compare{title="黑素细胞与朗格汉斯细胞"}
| 项目 | 黑素细胞 | 朗格汉斯细胞 |
|------|----------|--------------|
| 位置 | 胞体在基底细胞之间，突起伸入基底细胞和棘细胞之间 | 散在于棘层浅部 |
| HE | 胞体圆，核深染，胞质透明，突起不易辨认 | 圆形，核深染，胞质清亮 |
| 显示突起的染色 | 多巴染色（黄褐色） | ATP 酶组织化学染色 |
| 特征性细胞器 | 黑素体 → 黑素颗粒 | 伯贝克颗粒（杆状或网球拍形） |
| 与角质形成细胞的连接 | 无桥粒 | 不参与角化连接 |
| 核心职分 | 合成并转移黑色素，吸收紫外线 | 抗原呈递细胞，迁至淋巴结激活 T 细胞 |
:::

:::pitfall{label="朗格汉斯细胞要走出表皮去淋巴结，不要写成“就地杀灭抗原”"}
它捕获、处理抗原后，必须游走出表皮、经毛细淋巴管到淋巴结，把抗原肽–MHC 交给 T 淋巴细胞。职分是呈递，不是巨噬细胞那种就地吞噬杀菌。数量在接触性皮炎等炎症中增多，是监视账，不是“皮肤里的中性粒细胞”。
:::

::figure{src="/images/histology/textbook/p0132_01.png" caption="图11-7 皮肤朗格汉斯细胞光镜图（ATP 酶组织化学染色）。树枝状突起伸入角质形成细胞之间。" alt="ATP酶染色显示棘层浅部朗格汉斯细胞的树枝状突起"}

### 3. 梅克尔细胞

梅克尔细胞（Merkel cell）位于基底层，细胞数量很少，但于指尖、口腔和生殖道黏膜上皮中较多，可感受轻触觉和机械刺激。在 HE 染色标本上不易辨别。电镜下，细胞呈扁圆形，有短指状突起伸入角质形成细胞之间，并以桥粒与之相连，其基底部细胞质内有许多质膜包被的致密核芯颗粒，$50\%\sim 70\%$ 的梅克尔细胞基底部与盘状感觉神经末梢紧密接触并形成突触，称梅克尔细胞–轴突复合体（Merkel cell-neurite complexe）（图 11-9），也有一些不与神经末梢接触的梅克尔细胞，故呈明显的异质性。由于细胞表达突触素和多种神经多肽等物质，故认为梅克尔细胞是一种神经内分泌细胞。它通过在皮肤中进行旁分泌和自分泌发挥不同作用，如调节角质形成细胞增殖、通过影响朗格汉斯细胞调节抗原呈递功能等。

:::definition{label="梅克尔细胞"}
梅克尔细胞（Merkel cell）位于基底层，数量很少，于指尖、口腔和生殖道黏膜上皮中较多，可感受轻触觉和机械刺激。HE 不易辨别。电镜下呈扁圆形，短指状突起伸入角质形成细胞之间，并以桥粒相连；基底部胞质有许多质膜包被的致密核芯颗粒。
:::

:::definition{label="梅克尔细胞-轴突复合体"}
$50\%\sim 70\%$ 的梅克尔细胞基底部与盘状感觉神经末梢紧密接触并形成突触，称梅克尔细胞–轴突复合体（Merkel cell-neurite complexe）。另一些不与神经末梢接触，故该类细胞呈明显异质性。
:::

:::definition{label="梅克尔细胞的神经内分泌性质"}
梅克尔细胞表达突触素和多种神经多肽，被认为是一种神经内分泌细胞。通过旁分泌和自分泌调节角质形成细胞增殖，并影响朗格汉斯细胞的抗原呈递功能。
:::

:::compare{title="三种非角质形成细胞"}
| 项目 | 黑素细胞 | 朗格汉斯细胞 | 梅克尔细胞 |
|------|----------|--------------|------------|
| 英文 | melanocyte | Langerhans cell | Merkel cell |
| 位置 | 基底细胞之间，突起伸入棘层 | 棘层浅部 | 基底层 |
| HE | 胞质透明，突起难认 | 胞质清亮，圆形 | 不易辨别 |
| 电镜身份证 | 黑素体 / 黑素颗粒 | 伯贝克颗粒 | 致密核芯颗粒；可形成细胞–轴突复合体 |
| 与角质形成细胞 | 无桥粒 | — | 有桥粒 |
| 主要功能 | 生成并转移黑色素，抗紫外 | 抗原呈递 | 轻触觉、机械刺激；神经内分泌调节 |
| 来源提示 | 神经嵴 | 抗原呈递细胞系统 | 神经内分泌表型 |
:::

:::pitfall{label="梅克尔细胞有桥粒，黑素细胞没有，不要把基底层里的“第三者”写成同一种"}
基底层除了基底细胞，至少还可能坐着黑素细胞和梅克尔细胞。黑素细胞无桥粒、管色素；梅克尔细胞有桥粒、基底可对盘状神经末梢，管轻触和旁分泌。HE 几乎看不出梅克尔细胞，不要因为“都在基底层”就并成黑素细胞的别名。
:::

:::insight{label="非角质形成细胞把表皮从“一层死壳”改写成屏障、色素、免疫和触觉四本账"}
角质形成细胞铺五层、做角蛋白和糖脂屏障；黑素细胞给角质形成细胞配送黑素颗粒；朗格汉斯细胞把抗原带去淋巴结；梅克尔细胞接轻触，还用多肽调节增殖和呈递。缺任何一本，皮肤都只剩半张上皮。

:::keypoint{label="表皮先立五层角化，再立三种非角质形成细胞"}
- 皮肤 = 表皮 + 真皮，借皮下组织连深层；厚 $0.5\sim 4\,\mathrm{mm}$。附属器由表皮衍生。
- 表皮是角化复层扁平上皮。厚皮（仅掌跖）五层齐全；薄皮颗粒层、透明层不明显，角质层薄。
- 角质形成细胞占 $90\%$ 以上，更新周期 $3\sim 4$ 周。基底层干细胞 → 棘层（张力丝、内披蛋白、板层颗粒）→ 颗粒层（透明角质颗粒）→ 透明层 → 角质层（角蛋白，脱落为皮屑）。
- 黑素细胞在基底层，无桥粒；黑素颗粒转交角质形成细胞；人种间细胞数相近，差别在颗粒能力与分布。
- 朗格汉斯细胞在棘层浅部，伯贝克颗粒，APC，迁至淋巴结。
- 梅克尔细胞在基底层，可成细胞–轴突复合体，感受轻触，兼神经内分泌。
:::

:::memory{label="本节必背要点"}
- [ ] 皮肤（skin）是人体面积最大的器官，由表皮和真皮构成，以皮下组织与深层组织相连。
- [ ] 皮肤厚度随部位和年龄而异，为 $0.5\sim 4\,\mathrm{mm}$。
- [ ] 毛、皮脂腺、汗腺和指（趾）甲均为表皮衍生的皮肤附属器。
- [ ] 皮肤能阻挡异物和病原体、防止体液丢失（屏障保护）；有丰富感觉神经末梢；还能调节体温、排出代谢产物、参与合成维生素 D。
- [ ] 表皮（epidermis）是皮肤浅层，由角化的复层扁平上皮构成。
- [ ] 厚皮仅位于手掌和足底，其他部位均为薄皮。
- [ ] 角质形成细胞（keratinocyte）占表皮细胞 $90\%$ 以上；非角质形成细胞包括黑素细胞、梅克尔细胞和朗格汉斯细胞。
- [ ] 厚皮从基底到表面分为基底层、棘层、颗粒层、透明层和角质层 5 层；薄皮颗粒层和透明层不明显，角质层较薄。
- [ ] 基底层（stratum basale）附着于基膜，由一层矮柱状基底细胞组成；胞质因富含游离核糖体而嗜碱。
- [ ] 角蛋白丝（keratin filament）直径 $10\,\mathrm{nm}$，属中间丝，又称张力丝（tonofilament）。
- [ ] 基底细胞与相邻细胞以桥粒相连，与基膜以半桥粒相连。
- [ ] 基底细胞是表皮干细胞，部分子细胞脱离基膜进入棘层，分化为棘细胞并失去分裂能力；创伤愈合中有重要再生修复作用。
- [ ] 棘层（stratum spinosum）由 $4\sim 10$ 层多边形大棘细胞组成；表面有短小棘状突起，相邻突起镶嵌，胞质弱嗜碱。
- [ ] 电镜下棘状突起由桥粒相连；角蛋白丝成束，从核周放射至桥粒内侧。
- [ ] 内披蛋白（involucrin）沉积在细胞膜内侧使膜增厚。
- [ ] 板层颗粒（lamellated granule）含糖脂，明暗相间板层状，胞吐入细胞间隙形成膜状物，阻水并防止组织液外渗。
- [ ] 棘层深层仍有黑素颗粒，浅层大多被降解。
- [ ] 颗粒层（stratum granulosum）由 $3\sim 5$ 层梭形细胞组成；核与细胞器已退化。
- [ ] 透明角质颗粒（keratohyalin granule）强嗜碱、形状不规则、无膜包裹，呈致密均质状，角蛋白丝常埋入；内为富含组氨酸的蛋白质。
- [ ] 透明层（stratum lucidum）由 $2\sim 3$ 层扁平细胞组成，界限不清，核和细胞器已消失；HE 强嗜酸、折光高。
- [ ] 角质层（stratum corneum）由多层扁平角质细胞（horny cell）组成，完全角化、干硬，光镜嗜酸性均质状。
- [ ] 角蛋白 = 角蛋白丝 + 透明角质颗粒所含富含组氨酸的蛋白质；浅表桥粒消失，脱落成皮屑。
- [ ] 从基底层到角质层反映角质形成细胞增殖、迁移、分化、脱落；更新周期 $3\sim 4$ 周。
- [ ] 黑素细胞（melanocyte）生成黑色素；胞体在基底细胞之间，突起伸入基底细胞和棘细胞之间。
- [ ] HE 上黑素细胞胞体圆、核深染、胞质透明，突起不易辨认；与角质形成细胞无桥粒。
- [ ] 黑素体由高尔基复合体形成，含酪氨酸酶，将酪氨酸转化为黑色素；出现黑色素后称黑素颗粒，多巴染色呈黄褐色。
- [ ] 黑素颗粒沿微管至突起末端，被角质形成细胞吞入，故颗粒在黑素细胞中少、在角质形成细胞中多。
- [ ] 黑色素吸收紫外线，保护角质形成细胞核 DNA；紫外线激活酪氨酸酶，促进合成和释放。
- [ ] 黑素细胞来自神经嵴，迁入表皮和毛球；极少量入眼球壁血管膜。滞留真皮或交界处成团称色素痣或黑痣；范围较大的青斑称胎记。
- [ ] 人种间黑素细胞数量无明显差别；肤色取决于合成黑素颗粒的能力及分布，也与表皮厚度和血供有关。
- [ ] 朗格汉斯细胞（Langerhans cell）散在棘层浅部；HE 圆、核深、胞质清亮；ATP 酶染色显示树枝状突起。
- [ ] 伯贝克颗粒（Birbeck granule）呈杆状或网球拍形，参与处理抗原。
- [ ] 朗格汉斯细胞是抗原呈递细胞：捕获抗原 → 抗原肽–MHC → 游走出表皮 → 淋巴至淋巴结 → 呈递给 T 细胞；接触性皮炎等炎症时增多。
- [ ] 梅克尔细胞（Merkel cell）位于基底层，数量很少，指尖、口腔和生殖道黏膜上皮中较多，感受轻触觉和机械刺激；HE 不易辨别。
- [ ] 梅克尔细胞扁圆，短指状突起以桥粒连角质形成细胞；基底部有质膜包被的致密核芯颗粒。
- [ ] $50\%\sim 70\%$ 与盘状感觉神经末梢形成梅克尔细胞–轴突复合体；有些不接触神经，呈异质性。
- [ ] 梅克尔细胞表达突触素和神经多肽，属神经内分泌细胞，旁分泌/自分泌调节角质形成细胞增殖和朗格汉斯细胞抗原呈递。
:::
