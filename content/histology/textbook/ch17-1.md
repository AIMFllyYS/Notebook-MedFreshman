# 一、肾

泌尿系统（urinary system）包括肾、输尿管、膀胱和尿道。肾产生尿液，其余为排尿器官。本章先把肾的皮质与髓质、肾单位、滤过屏障、肾小管各段、球旁复合体、肾间质和血液循环摊开；输尿管、膀胱各立一节。

:::definition{label="泌尿系统"}
泌尿系统（urinary system）包括肾、输尿管、膀胱和尿道。肾产生尿液，输尿管、膀胱和尿道为排尿器官。主要功能是形成并排出尿液，维持机体的水和电解质平衡。
:::

:::definition{label="肾"}
肾（kidney）是人体主要的排泄器官，以形成尿液的方式排出体内的代谢废物，对人体的水盐代谢和离子平衡起调节作用，参与维持机体内环境的相对稳定。此外，肾还分泌多种生物活性物质，如肾素、前列腺素和促红细胞生成素等。
:::

:::concept{term="先问这是产尿的肾，还是只负责把尿送出去的管道"}
看见泌尿系统，先把两本账切开：肾小体滤过、肾小管和集合管重吸收与分泌，才是产尿；输尿管、膀胱、尿道只是把终尿送出体外。把“泌尿”听成“从肾到尿道都在造尿”，滤过屏障和变移上皮会并成一句。
:::

:::note{label="肾分泌的生物活性物质"}
| 物质 | 主要来源 | 职分 |
|------|----------|------|
| 肾素 | 球旁细胞分泌颗粒 | 启动肾素–血管紧张素系统，调节血压 |
| 前列腺素 | 髓质间质细胞 | 舒张血管，加快重吸收水分的转运，促进尿液浓缩 |
| 促红细胞生成素 | 髓质间质细胞 | 刺激骨髓中红细胞生成；肾病晚期往往伴有贫血 |
:::

:::compare{title="产尿器官与排尿器官"}
| 项目 | 肾 | 输尿管、膀胱、尿道 |
|------|----|--------------------|
| 职分 | 形成尿液；调节水盐和离子平衡；分泌生物活性物质 | 将终尿排出体外 |
| 核心结构 | 肾单位 + 集合管（泌尿小管） | 变移上皮衬里的黏膜管道，有肌层 |
| 本章位置 | 第 17-1 节 | 第 17-2、17-3 节 |
:::

肾呈豆形，外侧缘隆凸，内侧缘中部凹陷。肾表面有由致密结缔组织构成的被膜。肾实质分为皮质和髓质（图 17-1，图 17-2）。髓质由 $10\sim 18$ 个肾锥体（renal pyramid）组成，锥体尖端钝圆，突入肾小盏内，称肾乳头，乳头管开口于此处。肾锥体的底与皮质相连接，从肾锥体底呈辐射状伸入皮质的条纹称髓放线（medullary ray）；位于髓放线之间的肾皮质称皮质迷路（cortical labyrinth）。一条髓放线及其周围的皮质迷路组成一个肾小叶，一个肾锥体与相连的皮质组成一个肾叶，肾锥体之间的皮质部分称为肾柱。

:::definition{label="被膜"}
肾表面有由致密结缔组织构成的被膜。它是肾的结缔组织外壳，不是实质里的皮质或髓质。
:::

:::definition{label="皮质与髓质"}
肾实质分为皮质和髓质。皮质在外周，内有皮质迷路、髓放线和肾柱；髓质由 $10\sim 18$ 个肾锥体组成。
:::

:::definition{label="肾锥体"}
肾锥体（renal pyramid）构成髓质，共 $10\sim 18$ 个。锥体尖端钝圆，突入肾小盏内，称肾乳头，乳头管开口于此处。锥体的底与皮质相连接。
:::

:::definition{label="肾乳头"}
肾乳头是肾锥体尖端突入肾小盏的钝圆部分。乳头管开口于此，终尿由此排入肾小盏。
:::

:::definition{label="髓放线"}
髓放线（medullary ray）是从肾锥体底呈辐射状伸入皮质的条纹。其内主要是肾小管的直行部分与集合管。
:::

:::definition{label="皮质迷路"}
皮质迷路（cortical labyrinth）是位于髓放线之间的肾皮质。肾小体和肾小管的弯曲部分位于皮质迷路和肾柱内。
:::

:::definition{label="肾小叶"}
一条髓放线及其周围的皮质迷路组成一个肾小叶。
:::

:::definition{label="肾叶"}
一个肾锥体与相连的皮质组成一个肾叶。
:::

:::definition{label="肾柱"}
肾柱是肾锥体之间的皮质部分。其内同样有肾小体和肾小管的弯曲部分。
:::

::figure{src="/images/histology/textbook/p0193_02.png" caption="图17-1 肾冠状剖面模式图。示皮质、髓质、肾锥体、肾柱、髓放线、肾小盏、肾大盏、肾盂与输尿管。" alt="肾冠状剖面：外周皮质包绕髓质锥体，锥体之间为肾柱，髓放线呈辐射状伸入皮质，肾盏肾盂连输尿管"}

::figure{src="/images/histology/textbook/p0193_03.png" caption="图17-2 肾皮质光镜图。1. 皮质迷路；2. 髓放线；3. 肾小体。" alt="肾皮质HE切片：皮质迷路中可见球形肾小体，其间有呈条纹走行的髓放线"}

:::compare{title="肾小叶、肾叶与肾柱"}
| 项目 | 组成 | 不要听成 |
|------|------|----------|
| 肾小叶 | 一条髓放线 + 其周围的皮质迷路 | 一个肾锥体 |
| 肾叶 | 一个肾锥体 + 相连的皮质 | 一条髓放线 |
| 肾柱 | 肾锥体之间的皮质部分 | 髓质 |
:::

:::pitfall{label="肾柱是皮质伸进锥体之间，不要写成髓质"}
肾柱的本质是皮质。锥体才是髓质。切片上锥体旁边那块含肾小体的组织，仍按皮质迷路记账，不能因为“插在髓质之间”就改叫髓质。
:::

:::insight{label="皮质迷路装弯曲，髓放线和锥体装直行"}
肾实质的分区可以先按“弯的还是直的”来认：肾小体、近曲、远曲、弓形集合管走弯曲，落在皮质迷路和肾柱；近直、细段、远直、直集合管走直行，落在髓放线和肾锥体。把皮质听成“只有肾小体”，近曲远曲会从迷路里失踪。
:::

肾实质由大量肾单位和集合管构成。每个肾单位包括一个肾小体和一条与它相连的肾小管，是尿液形成的结构和功能单位。肾小管汇入集合管，它们都是单层上皮性管道，合称泌尿小管。肾单位和集合管有规律地分布于肾实质。肾小体和肾小管的弯曲部分位于皮质迷路和肾柱内，肾小管的直行部分与集合管位于髓放线和肾锥体内（表 17-1）。肾内的少量结缔组织、血管和神经等构成肾间质。

:::definition{label="泌尿小管"}
肾小管汇入集合管，二者都是单层上皮性管道，合称泌尿小管。泌尿小管 = 肾小管 + 集合管，集合管不算肾单位的成员。
:::

:::definition{label="肾间质"}
肾内的少量结缔组织、血管和神经等构成肾间质。皮质结缔组织很少，越接近肾乳头越多。
:::

:::note{label="表17-1 肾实质的组成和各段的位置"}
| 组成 | 节段 | 位置 |
|------|------|------|
| 肾单位 | 肾小体 | 皮质迷路、肾柱 |
| 肾单位 | 近端小管曲部（近曲小管） | 皮质迷路、肾柱 |
| 肾单位 | 近端小管直部（近直小管） | 髓放线、肾锥体 |
| 肾单位 | 细段 | 肾锥体 |
| 肾单位 | 远端小管直部（远直小管） | 肾锥体、髓放线 |
| 肾单位 | 远端小管曲部（远曲小管） | 皮质迷路、肾柱 |
| 集合管 | 弓形集合管 | 皮质迷路 |
| 集合管 | 直集合管 | 髓放线、肾锥体 |
| 集合管 | 乳头管 | 肾乳头 |
:::

:::pitfall{label="集合管与肾单位共同泌尿，但集合管不是肾单位的一段"}
肾单位 = 肾小体 + 肾小管。远曲小管汇入集合管，集合管再分弓形集合管、直集合管和乳头管。把集合管写进肾单位，乳头管和心房钠尿肽那本账会算错户头。
:::

## （一）肾单位

肾单位（nephron）是肾的结构与功能单位，由肾小体和肾小管组成，每个肾有约 150 万个肾单位，它们与集合管共同行使泌尿功能。

:::definition{label="肾单位"}
肾单位（nephron）是肾的结构与功能单位，由肾小体和肾小管组成。每个肾约有 150 万个肾单位，它们与集合管共同行使泌尿功能。
:::

:::concept{term="先沿一条管子从尿极走到集合管，再问这个肾小体浅还是深"}
看见肾单位，先把走行背成一条线：肾小体 → 近曲 → 近直 → 细段 → 远直 → 远曲 → 集合管。近直、细段、远直三者构成 U 形髓袢。再问肾小体在皮质的哪一层：浅中层是浅表肾单位（约占 $85\%$），深层是髓旁肾单位（约占 $15\%$）。把“一个肾单位”听成“一个肾小体”，髓袢和远曲会从账上掉下去。
:::

肾小体位于皮质迷路和肾柱内，一端与肾小管相连。肾小管的起始段在肾小体附近盘曲走行，称近端小管曲部或近曲小管；继而进入髓放线或髓质直行，称近端小管直部或近直小管；随后管径变细，称细段；细段之后管径又增粗，称远端小管直部或远直小管。近直小管、细段和远直小管三者构成 U 型的髓袢（medullary loop）。远直小管离开髓放线或髓质后，进入皮质迷路，盘曲走行于原肾小体附近，称远端小管曲部或远曲小管，最后汇入髓放线内的集合管（图 17-3）。

:::definition{label="近曲小管"}
近端小管曲部又称近曲小管（proximal convoluted tubule），是肾小管起始段在肾小体附近的盘曲部分，位于皮质迷路和肾柱。
:::

:::definition{label="近直小管"}
近端小管直部又称近直小管（proximal straight tubule），由近曲进入髓放线或髓质后直行。
:::

:::definition{label="细段"}
细段（thin segment）是近直之后管径变细的一段，位于肾锥体，构成髓袢的底部。
:::

:::definition{label="远直小管"}
远端小管直部又称远直小管（distal straight tubule），细段之后管径再增粗，位于肾锥体和髓放线，构成髓袢的升支。
:::

:::definition{label="远曲小管"}
远端小管曲部又称远曲小管（distal convoluted tubule），远直离开髓放线或髓质后，在原肾小体附近盘曲，位于皮质迷路和肾柱，最后汇入集合管。
:::

:::definition{label="髓袢"}
髓袢（medullary loop）由近直小管、细段和远直小管三者构成，呈 U 型。浅表肾单位的髓袢较短，髓旁肾单位的髓袢较长。
:::

::figure{src="/images/histology/textbook/p0194_02.png" caption="图17-3 肾单位和集合管模式图。示浅表肾单位与髓旁肾单位，近曲、近直、细段、远直、远曲，弓形集合管、直集合管与乳头管，以及致密斑。" alt="肾单位模式：左侧浅表肾单位髓袢较短，右侧髓旁肾单位髓袢深达乳头，绿色为集合管系统"}

肾小体因在皮质中的位置不同而分为两种。浅表肾单位的肾小体位于皮质浅层和中层，体积较小，髓袢较短，约占肾单位总数的 $85\%$，在尿液形成中起重要作用。髓旁肾单位的肾小体位于皮质深部，体积较大，髓袢较长，约占肾单位总数的 $15\%$，对尿液浓缩具有重要的生理意义。考试里也把浅表肾单位称作皮质肾单位，把髓旁肾单位称作近髓肾单位，户头仍是这两本。

:::definition{label="浅表肾单位"}
浅表肾单位又称皮质肾单位。肾小体位于皮质浅层和中层，体积较小，髓袢较短，约占肾单位总数的 $85\%$，在尿液形成中起重要作用。
:::

:::definition{label="髓旁肾单位"}
髓旁肾单位又称近髓肾单位。肾小体位于皮质深部，体积较大，髓袢较长，约占肾单位总数的 $15\%$，对尿液浓缩具有重要的生理意义。
:::

:::compare{title="浅表肾单位（皮质肾单位）与髓旁肾单位（近髓肾单位）"}
| 项目 | 浅表肾单位（皮质肾单位） | 髓旁肾单位（近髓肾单位） |
|------|--------------------------|--------------------------|
| 肾小体位置 | 皮质浅层和中层 | 皮质深部 |
| 体积 | 较小 | 较大 |
| 髓袢 | 较短 | 较长 |
| 约占总数 | $85\%$ | $15\%$ |
| 主要生理意义 | 尿液形成 | 尿液浓缩 |
| 出球微动脉去向 | 分支形成球后毛细血管网，分布在肾小管周围 | 既形成球后毛细血管网，又发出直小动脉进入髓质 |
:::

:::pitfall{label="浅表肾单位占 85%，不要写成髓旁占大多数"}
数量账在浅表（$85\%$），浓缩账在髓旁（$15\%$、髓袢长、直小血管袢）。把“重要”听成“数量多”，两种肾单位的百分比会对调。
:::

### 1. 肾小体

肾小体（renal corpuscle）呈球形，又称肾小球，直径约 $200\,\mu\mathrm{m}$，由肾小囊和血管球组成。肾小体有两个极，微动脉出入的一端称血管极，对侧一端和近曲小管相连，称尿极（图 17-4，图 17-5）。

:::definition{label="肾小体"}
肾小体（renal corpuscle）呈球形，又称肾小球，直径约 $200\,\mu\mathrm{m}$，由肾小囊和血管球组成。
:::

:::definition{label="血管极"}
血管极是微动脉出入肾小体的一端。入球微动脉由此进入，出球微动脉由此离开；球旁复合体也落在这一极。
:::

:::definition{label="尿极"}
尿极是血管极的对侧，与近曲小管相连。肾小囊腔在此与近曲小管腔相通。
:::

:::concept{term="先认两个极，再把血管球和肾小囊分开记账"}
切片上先找球形的肾小体，再问哪一端有微动脉（血管极），哪一端连近曲（尿极）。球是有孔毛细血管网，囊是双层上皮杯。把肾小体听成“只有一团毛细血管”，足细胞和肾小囊腔会从滤过账上失踪。
:::

#### （1）血管球

血管球（glomerulus）是肾小囊中一团盘曲的毛细血管。一条入球微动脉从血管极进入肾小囊内，分成 $4\sim 5$ 支，每支再分出袢状毛细血管，毛细血管又互相吻合为网，继而汇合，于近血管极处形成一条出球微动脉，离开肾小囊。因此，血管球是一种独特的动脉性毛细血管网。入球微动脉管径较出球微动脉粗，使得毛细血管内血压较高。毛细血管为有孔型，孔径 $50\sim 100\,\mathrm{nm}$，多无隔膜，利于血液中物质滤出。毛细血管内皮游离面的细胞衣富含带负电荷的唾液酸糖蛋白。内皮基底面除与血管系膜相接触的部位外，均有基膜。

:::definition{label="血管球"}
血管球（glomerulus）是肾小囊中一团盘曲的毛细血管，由入球微动脉分支、吻合后再汇成出球微动脉。它是一种独特的动脉性毛细血管网。
:::

:::definition{label="入球微动脉"}
一条入球微动脉从血管极进入肾小囊，分成 $4\sim 5$ 支，每支再分出袢状毛细血管。管径较出球微动脉粗，使血管球内血压较高，有利于滤过。
:::

:::definition{label="出球微动脉"}
袢状毛细血管在近血管极处汇合成一条出球微动脉，离开肾小囊。管径较入球微动脉细。
:::

:::definition{label="血管球有孔内皮"}
血管球毛细血管为有孔型，孔径 $50\sim 100\,\mathrm{nm}$，多无隔膜，利于血液中物质滤出。内皮游离面的细胞衣富含带负电荷的唾液酸糖蛋白。内皮基底面除与血管系膜相接触的部位外，均有基膜。
:::

:::compare{title="入球微动脉与出球微动脉"}
| 项目 | 入球微动脉 | 出球微动脉 |
|------|------------|------------|
| 走行 | 从血管极进入肾小囊，分成 $4\sim 5$ 支 | 毛细血管在近血管极汇成一条，离开肾小囊 |
| 管径 | 较粗 | 较细 |
| 对滤过的意义 | 粗管径使血管球内压较高，利于滤过 | 细管径维持球内高压 |
| 管壁特殊分化 | 近血管极处平滑肌分化为球旁细胞，分泌肾素 | 本身不形成球旁细胞 |
| 离开肾小体后 | — | 浅表：球后毛细血管网；髓旁：球后网 + 直小动脉 |
:::

:::pitfall{label="血管球是动脉性毛细血管网，不要写成静脉性或普通真毛细血管"}
两端都是微动脉：入球进来，出球出去。这和“动脉→毛细血管→静脉”的普通循环不是一本账。正是两端都是动脉、入球又比出球粗，球内血压才高得足以滤过。
:::

血管球毛细血管基膜较厚，在成人约为 $330\,\mathrm{nm}$。在电镜下分 3 层，中层厚而致密，内、外层薄而稀疏。基膜主要成分为Ⅳ型胶原蛋白、层粘连蛋白和蛋白聚糖（其糖胺聚糖以带负电荷的硫酸肝素为主）。Ⅳ型胶原蛋白形成网状结构，连接其他糖蛋白，共同形成孔径为 $4\sim 8\,\mathrm{nm}$ 的分子筛，在血液物质滤过中起关键作用。

:::definition{label="血管球基膜"}
血管球毛细血管基膜较厚，成人约为 $330\,\mathrm{nm}$。电镜下分 3 层：中层厚而致密，内、外层薄而稀疏。主要成分为Ⅳ型胶原蛋白、层粘连蛋白和蛋白聚糖（糖胺聚糖以带负电荷的硫酸肝素为主）。Ⅳ型胶原蛋白形成网状结构，连接其他糖蛋白，共同形成孔径 $4\sim 8\,\mathrm{nm}$ 的分子筛，在血液物质滤过中起关键作用。
:::

血管系膜（mesangium）又称球内系膜（intraglomerular mesangium），连接于血管球毛细血管之间，主要由球内系膜细胞和系膜基质组成。球内系膜细胞（intraglomerular mesangial cell）形态不规则，细胞突起可伸至内皮与基膜之间；细胞核染色较深，细胞质含较发达的粗面内质网、高尔基复合体、溶酶体和吞噬体；细胞体和突起内有微管、微丝和中间丝。目前认为系膜细胞为特化的平滑肌细胞，能合成基膜和系膜基质的成分，还可吞噬和降解沉积在基膜上的免疫复合物，防止免疫复合物沉积，以维持基膜的通透性，并参与基膜的更新和修复。系膜基质填充在系膜细胞之间，在血管球内起支持和通透作用。有些类型的肾小球肾炎，系膜细胞弥漫性增生，系膜基质增多，血管系膜区出现免疫复合物沉积，影响滤过功能。血管系膜内还可见少量巨噬细胞。

:::definition{label="血管系膜"}
血管系膜（mesangium）又称球内系膜（intraglomerular mesangium），连接于血管球毛细血管之间，主要由球内系膜细胞和系膜基质组成。
:::

:::definition{label="球内系膜细胞"}
球内系膜细胞（intraglomerular mesangial cell）形态不规则，突起可伸至内皮与基膜之间；核染色较深，胞质含较发达的粗面内质网、高尔基复合体、溶酶体和吞噬体；胞体和突起内有微管、微丝和中间丝。目前认为是特化的平滑肌细胞：合成基膜和系膜基质，吞噬降解沉积在基膜上的免疫复合物，维持基膜通透性，并参与基膜更新和修复。
:::

:::definition{label="系膜基质"}
系膜基质填充在系膜细胞之间，在血管球内起支持和通透作用。
:::

:::note{label="光镜下三种核的着色深浅"}
从细胞核着色情况看：球内系膜细胞最深，内皮细胞次之，足细胞最浅。光镜下足细胞不易与内皮细胞、球内系膜细胞相区分，先靠这把着色尺子。
:::

:::insight{label="系膜细胞既是清道夫，也是基膜的修理工"}
免疫复合物若沉在基膜上，孔径账和电荷账都会坏。系膜细胞把它吞噬降解，内皮和足细胞再铺新基膜，滤过膜才能恢复。肾小球肾炎时系膜细胞弥漫增生、基质增多、系膜区出现免疫复合物，滤过功能随之受损。把系膜听成“可有可无的填充物”，肾炎那本形态账会对不上。
:::

:::pitfall{label="球内系膜不是球外系膜，也不分泌肾素"}
球内系膜夹在血管球毛细血管之间，管滤过膜的清洁和更新。球外系膜在血管极三角区中心，可能传递信息。肾素在球旁细胞的分泌颗粒里。三家人不要并成一个“系膜细胞”。
:::

#### （2）肾小囊

肾小囊（renal capsule）是在胚胎时期肾小管的起始端膨大凹陷而成的杯状双层上皮囊。其外层（或称壁层）为单层扁平上皮，在肾小体的尿极处与近曲小管上皮相连续，在血管极处反折为肾小囊内层（或称脏层），两层上皮之间的狭窄腔隙为肾小囊腔，与近曲小管腔相通。内层细胞称足细胞（podocyte），细胞体较大，凸向肾小囊腔，细胞核染色较浅。光镜下，足细胞不易与内皮细胞、球内系膜细胞相区分。

在扫描电镜下，可见从细胞体发出几支粗大的初级突起，继而再分出许多指状次级突起，次级突起互相嵌合，呈栅栏状，紧贴在毛细血管基膜外面，其表面由一层带负电荷的唾液酸糖蛋白覆盖。次级突起间有宽约 $25\,\mathrm{nm}$ 的裂隙，称裂孔（slit pore），孔上覆盖一层 $4\sim 6\,\mathrm{nm}$ 的薄膜，即裂孔膜（slit membrane）。次级突起末端内含较多微丝，微丝收缩可使突起移动而改变裂孔的宽度，调节血管球的滤过率。足细胞还参与基膜形成和更新，维持血管球形状。

:::definition{label="肾小囊"}
肾小囊（renal capsule）是胚胎时期肾小管起始端膨大凹陷而成的杯状双层上皮囊。外层（壁层）为单层扁平上皮，尿极与近曲小管上皮相连续，血管极反折为内层（脏层）。两层之间的狭窄腔隙为肾小囊腔，与近曲小管腔相通。
:::

:::definition{label="肾小囊壁层"}
外层又称壁层，为单层扁平上皮。尿极处与近曲小管上皮相连续。
:::

:::definition{label="肾小囊脏层"}
内层又称脏层，细胞为足细胞。在血管极处由壁层反折而来。
:::

:::definition{label="肾小囊腔"}
壁层与脏层之间的狭窄腔隙。原尿滤入此腔，再经尿极进入近曲小管。
:::

:::definition{label="足细胞"}
足细胞（podocyte）是肾小囊内层细胞。胞体较大，凸向肾小囊腔，核染色较浅。从胞体发出几支粗大的初级突起，再分出许多指状次级突起；次级突起互相嵌合呈栅栏状，紧贴毛细血管基膜外面，表面覆一层带负电荷的唾液酸糖蛋白。足细胞还参与基膜形成和更新，维持血管球形状。
:::

:::definition{label="裂孔与裂孔膜"}
次级突起间有宽约 $25\,\mathrm{nm}$ 的裂隙，称裂孔（slit pore）；孔上覆盖一层 $4\sim 6\,\mathrm{nm}$ 的薄膜，即裂孔膜（slit membrane）。次级突起末端微丝收缩可改变裂孔宽度，调节血管球滤过率。
:::

:::compare{title="肾小囊壁层与脏层"}
| 项目 | 壁层（外层） | 脏层（内层） |
|------|--------------|--------------|
| 上皮 | 单层扁平上皮 | 足细胞 |
| 连续关系 | 尿极与近曲小管上皮相连续 | 血管极由壁层反折而来 |
| 与基膜 | 不构成滤过屏障 | 次级突起贴在毛细血管基膜外面 |
| 特殊结构 | — | 初级突起、次级突起、裂孔、裂孔膜 |
:::

:::pitfall{label="足细胞的裂孔膜才是滤过屏障最外一层，不要把壁层单层扁平算进去"}
滤过走的是有孔内皮 → 基膜 → 足细胞裂孔膜。壁层单层扁平围成囊的外壳，原尿已经进囊腔以后才经过它旁边，并不参与这三层屏障。
:::

#### （3）滤过屏障

肾小体犹如滤过器，当血液流经血管球的毛细血管时，管内血压较高，血浆内部分物质经有孔内皮、基膜和足细胞裂孔膜滤入肾小囊腔。这 3 层结构统称滤过屏障或滤过膜（filtration membrane）。一般情况下，分子量 $70\,\mathrm{kDa}$ 以下、直径 $4\,\mathrm{nm}$ 以下的物质可通过滤过膜，其中又以带正电荷的物质易于通过，如葡萄糖、多肽、尿素、电解质和水等。滤入肾小囊腔的滤液称原尿，原尿除不含大分子蛋白质外，其成分与血浆相似。

成人两肾一昼夜可形成约 $180\,\mathrm{L}$ 原尿。若滤过膜受损害（如肾小球肾炎），则大分子蛋白质甚至血细胞均可通过滤过膜漏出，出现蛋白尿或血尿。当系膜细胞清除了基膜内沉积物，内皮细胞和足细胞再建新的基膜后，滤过膜功能又可恢复。

:::definition{label="滤过屏障"}
滤过屏障又称滤过膜（filtration membrane），由有孔内皮、基膜和足细胞裂孔膜这 3 层结构组成。血浆内部分物质经此三层滤入肾小囊腔。
:::

:::definition{label="原尿"}
滤入肾小囊腔的滤液称原尿。原尿除不含大分子蛋白质外，其成分与血浆相似。成人两肾一昼夜可形成约 $180\,\mathrm{L}$ 原尿。
:::

:::concept{term="先数三层，再问分子量和电荷"}
滤过不是“内皮漏一下就进肾小管”。必须连续穿过：有孔内皮（孔径 $50\sim 100\,\mathrm{nm}$，多无隔膜）→ 基膜分子筛（成人约 $330\,\mathrm{nm}$ 厚，孔径 $4\sim 8\,\mathrm{nm}$，硫酸肝素带负电）→ 足细胞裂孔膜（裂孔约 $25\,\mathrm{nm}$，膜厚 $4\sim 6\,\mathrm{nm}$，表面也带负电）。能过的大致是分子量 $70\,\mathrm{kDa}$ 以下、直径 $4\,\mathrm{nm}$ 以下，正电荷更容易。少写一层，蛋白尿血尿的机制就讲不圆。
:::

::figure{src="/images/histology/textbook/p0196_03.png" caption="图17-8 滤过屏障超微结构模式图。示有孔毛细血管内皮、基膜、足细胞初级与次级突起、裂孔与裂孔膜、球内系膜细胞；右上为滤过膜三层。" alt="滤过屏障模式：内皮孔、基膜和足细胞次级突起间的裂孔膜构成三层滤过膜，足细胞胞体发出初级突起再分次级突起"}

:::compare{title="滤过屏障三层"}
| 层次（血→囊） | 结构要点 | 孔径 / 厚度 | 电荷 |
|----------------|----------|-------------|------|
| 有孔内皮 | 有孔型毛细血管，多无隔膜；游离面细胞衣含唾液酸糖蛋白 | 孔径 $50\sim 100\,\mathrm{nm}$ | 负电荷 |
| 基膜 | 中层厚而致密，内、外层薄而稀疏；Ⅳ型胶原 + 层粘连蛋白 + 蛋白聚糖 | 成人厚约 $330\,\mathrm{nm}$；分子筛孔径 $4\sim 8\,\mathrm{nm}$ | 硫酸肝素带负电荷 |
| 足细胞裂孔膜 | 次级突起嵌合成栅栏，裂孔上覆薄膜 | 裂孔约 $25\,\mathrm{nm}$；裂孔膜 $4\sim 6\,\mathrm{nm}$ | 唾液酸糖蛋白带负电荷 |
:::

:::pitfall{label="滤过屏障不是一层内皮"}
三层缺一不可：有孔内皮只是第一关，基膜的分子筛和负电荷是第二关，足细胞裂孔膜是第三关。只写“有孔内皮滤过”，大分子蛋白质和血细胞为什么平时过不去就说不清；肾炎时蛋白尿、血尿也缺少形态学落点。
:::

:::insight{label="正电荷好过、负电荷难过，是三层负电荷在挡"}
内皮细胞衣、基膜硫酸肝素、足细胞表面唾液酸糖蛋白都带负电。同电荷相斥，所以带正电荷的物质更易通过。血浆白蛋白等大分子兼有体积和负电荷两道墙。把滤过只听成“孔径够不够”，电荷选择这本账会做丢。
:::

:::note{label="滤过膜损伤与修复"}
肾小球肾炎时大分子蛋白质甚至血细胞漏出，出现蛋白尿或血尿。系膜细胞清除基膜内沉积物，内皮细胞和足细胞再建新的基膜后，滤过膜功能可恢复。修复是内皮 + 足细胞铺膜、系膜清扫，不是“内皮单独长好”。
:::

### 2. 肾小管

肾小管（renal tubule）管壁由单层上皮构成，上皮外为基膜和极少量结缔组织。肾小管有重吸收原尿成分和排泄等作用（图 17-9）。

:::definition{label="肾小管"}
肾小管（renal tubule）管壁由单层上皮构成，上皮外为基膜和极少量结缔组织。由近端小管、细段、远端小管构成，有重吸收原尿成分和排泄等作用。
:::

::figure{src="/images/histology/textbook/p0197_01.png" caption="图17-9 泌尿小管各段上皮细胞结构模式图。示近端小管曲部与直部、细段、远端小管直部与曲部、集合管的上皮差异。" alt="泌尿小管各段模式：近端刷状缘发达，细段扁平，远端无刷状缘而基部质膜内褶明显，集合管细胞分界清楚、胞质浅"}

#### （1）近端小管

近端小管（proximal tubule）分曲部（近曲小管）和直部（近直小管）两段，是肾小管中最长最粗的一段，长约 $14\,\mathrm{mm}$，约占肾小管总长的一半；管径 $50\sim 60\,\mu\mathrm{m}$，管腔不甚规则。

:::definition{label="近端小管"}
近端小管（proximal tubule）分曲部（近曲小管）和直部（近直小管），是肾小管中最长最粗的一段：长约 $14\,\mathrm{mm}$，约占肾小管总长的一半；管径 $50\sim 60\,\mu\mathrm{m}$，管腔不甚规则。是重吸收原尿成分的主要场所。
:::

**1）近曲小管** 近曲小管（proximal convoluted tubule）上皮细胞为立方形或锥形，细胞分界不清，细胞体较大，细胞质嗜酸性，细胞核圆，位于近基底部。上皮细胞腔面有刷状缘（brush border）。

电镜下，可见刷状缘由大量较长的微绒毛整齐排列构成，使细胞游离面的表面积明显扩大（两肾近曲小管表面积总计可达 $50\sim 60\,\mathrm{m}^{2}$）。刷状缘的细胞膜中有丰富的碱性磷酸酶和 ATP 酶，参与细胞的重吸收功能。微绒毛基部之间的细胞膜凹陷，形成顶小管和顶小泡，是细胞吞饮原尿中小分子蛋白质的方式。顶小泡与溶酶体结合后，吞饮物被降解。细胞侧面有许多侧突，相邻细胞的侧突相互嵌合，故光镜下细胞分界不清。细胞基部有发达的质膜内褶，含许多纵向杆状线粒体。侧突和质膜内褶使细胞侧面及基底面面积扩大，有利于重吸收物的排出（图 17-10）。基部质膜内还有丰富的 $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-ATP 酶（钠泵），可将细胞内 $\mathrm{Na}^{+}$ 泵出。

:::definition{label="刷状缘"}
近曲小管上皮细胞腔面有刷状缘（brush border）。电镜下由大量较长的微绒毛整齐排列构成，使游离面表面积明显扩大；两肾近曲小管表面积总计可达 $50\sim 60\,\mathrm{m}^{2}$。刷状缘细胞膜中有丰富的碱性磷酸酶和 ATP 酶，参与重吸收。
:::

:::definition{label="顶小管和顶小泡"}
微绒毛基部之间的细胞膜凹陷，形成顶小管和顶小泡，是细胞吞饮原尿中小分子蛋白质的方式。顶小泡与溶酶体结合后，吞饮物被降解。
:::

:::definition{label="近曲小管侧突与质膜内褶"}
细胞侧面有许多侧突，相邻细胞侧突相互嵌合，故光镜下细胞分界不清。基部有发达的质膜内褶，含许多纵向杆状线粒体。侧突和质膜内褶扩大侧面及基底面面积，利于重吸收物排出。基部质膜内有丰富的 $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-ATP 酶（钠泵），将细胞内 $\mathrm{Na}^{+}$ 泵出。
:::

::figure{src="/images/histology/textbook/p0197_02.png" caption="图17-10 近曲小管上皮细胞超微结构立体模式图。示微绒毛（刷状缘）、侧突、质膜内褶与纵向杆状线粒体。" alt="近曲小管立体超微：游离面密集微绒毛，侧面侧突嵌合，基部质膜内褶夹纵向线粒体"}

**2）近直小管** 近直小管（proximal straight tubule）结构与曲部基本相似，但上皮细胞较矮，微绒毛、侧突和质膜内褶等不如曲部发达。

:::definition{label="近直小管的结构差异"}
近直小管结构与近曲基本相似，但上皮细胞较矮，微绒毛、侧突和质膜内褶等不如曲部发达。
:::

近端小管的上述结构特点使其具有良好的吸收功能，是重吸收原尿成分的主要场所，原尿中几乎所有葡萄糖、氨基酸、蛋白质以及大部分水、离子和尿素等均在此段重吸收。尽管近端小管上皮细胞间有紧密连接，但不是完全封闭的，对水和离子通透的阻力较低。此外，近端小管还向腔内分泌 $\mathrm{H}^{+}$、$\mathrm{NH}_{3}$、肌酐和马尿酸等，还能转运和排出血液中的酚红和青霉素等药物。临床上常利用马尿酸或酚红排泄试验来检测近端小管的功能。

:::definition{label="近端小管的重吸收与分泌"}
近端小管是重吸收原尿成分的主要场所：原尿中几乎所有葡萄糖、氨基酸、蛋白质以及大部分水、离子和尿素等均在此段重吸收。细胞间紧密连接不是完全封闭，对水和离子通透的阻力较低。还向腔内分泌 $\mathrm{H}^{+}$、$\mathrm{NH}_{3}$、肌酐和马尿酸等，并能转运排出血液中的酚红和青霉素等药物。
:::

:::note{label="马尿酸或酚红排泄试验"}
临床上常利用马尿酸或酚红排泄试验来检测近端小管的功能。这本账落在近端小管的分泌与转运，不是滤过屏障，也不是远曲的激素调节。
:::

:::insight{label="近曲把表面积铺到 50～60 平方米，是为了把 180 升原尿里的营养先捞回来"}
刷状缘、侧突、质膜内褶是三面扩膜。光镜上看见嗜酸性、分界不清、管腔不规则、刷状缘，就是这本扩膜账的切片落点。把近曲听成“只是第一段管子”，葡萄糖和蛋白质重吸收会找不到细胞学依据。
:::

#### （2）细段

细段（thin segment）管径细，直径 $10\sim 15\,\mu\mathrm{m}$，管壁为单层扁平上皮，细胞核椭圆形，含核部分突向管腔，细胞质着色较浅，无刷状缘（图 17-11，图 17-12）。细段上皮薄，有利于水和离子通透。

:::definition{label="细段上皮"}
细段管径 $10\sim 15\,\mu\mathrm{m}$，管壁为单层扁平上皮；核椭圆形，含核部分突向管腔；胞质着色较浅，无刷状缘。上皮薄，有利于水和离子通透。
:::

::figure{src="/images/histology/textbook/p0198_02.png" caption="图17-12 肾髓质深部横切面光镜图。1. 直集合管；2. 远直小管；3. 细段。" alt="髓质深部横切：直集合管腔大、细胞分界清，远直小管立方形，细段壁薄呈单层扁平"}

:::pitfall{label="细段是单层扁平，不要写成近曲那种刷状缘立方"}
管径只剩 $10\sim 15\,\mu\mathrm{m}$，壁是单层扁平，核凸向管腔，没有刷状缘。它的职分是薄壁通透，不是大批重吸收葡萄糖。和血管球有孔内皮、肾小囊壁层的单层扁平也不要并成一句。
:::

#### （3）远端小管

远端小管（distal tubule）包括远直小管和远曲小管。管腔较大而规则，管壁上皮细胞呈立方形，比近端小管细胞小，细胞核位于中央或靠近管腔，细胞质染色较近端小管浅，游离面无刷状缘。

:::definition{label="远端小管"}
远端小管（distal tubule）包括远直小管和远曲小管。管腔较大而规则；上皮细胞立方形，比近端小管细胞小；核位于中央或靠近管腔；胞质染色较近端小管浅；游离面无刷状缘。
:::

**1）远直小管** 远直小管（distal straight tubule）管径约 $30\,\mu\mathrm{m}$。电镜下，细胞表面有少量短而小的微绒毛，基底部质膜内褶发达，长的内褶可伸达细胞顶部，基部质膜上有丰富的 $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-ATP 酶，能主动向间质转运 $\mathrm{Na}^{+}$。

:::definition{label="远直小管"}
远直小管管径约 $30\,\mu\mathrm{m}$。细胞表面有少量短而小的微绒毛；基底部质膜内褶发达，长的内褶可伸达细胞顶部；基部质膜上有丰富的 $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-ATP 酶，能主动向间质转运 $\mathrm{Na}^{+}$。
:::

**2）远曲小管** 远曲小管（distal convoluted tubule）直径 $35\sim 45\,\mu\mathrm{m}$，其超微结构与直部相似，但质膜内褶不如直部发达。远曲小管细胞有吸收水、$\mathrm{Na}^{+}$ 和排出 $\mathrm{K}^{+}$、$\mathrm{H}^{+}$、$\mathrm{NH}_{3}$ 等功能，是离子交换的重要部位，对维持体液的酸碱平衡发挥重要作用。远曲小管的功能活动受激素调节，醛固酮能促进此段重吸收 $\mathrm{Na}^{+}$ 和排出 $\mathrm{K}^{+}$；抗利尿激素能促进此段对水的重吸收，使尿液浓缩，尿量减少。

:::definition{label="远曲小管的功能"}
远曲小管直径 $35\sim 45\,\mu\mathrm{m}$，超微结构与远直相似，但质膜内褶不如直部发达。细胞吸收水、$\mathrm{Na}^{+}$，排出 $\mathrm{K}^{+}$、$\mathrm{H}^{+}$、$\mathrm{NH}_{3}$，是离子交换的重要部位，维持体液酸碱平衡。醛固酮促进此段重吸收 $\mathrm{Na}^{+}$、排出 $\mathrm{K}^{+}$；抗利尿激素促进此段对水的重吸收，使尿液浓缩、尿量减少。
:::

近曲、远曲都盘在原肾小体附近。近曲：腔不规则、细胞大而嗜酸、分界不清、有刷状缘。远曲：腔大而规则、细胞较小、染色浅、无刷状缘。旁边若再出现高柱状、核近顶部的椭圆斑，那是致密斑，仍属远端小管，不是近曲。
:::

## （二）集合管

集合管（collecting duct）全长 $20\sim 38\,\mathrm{mm}$，分为弓形集合管、直集合管和乳头管 3 段（图 17-3）。弓形集合管很短，位于皮质迷路内，一端连接远曲小管，另一端呈弧形弯入髓放线，与直集合管相通。直集合管在髓放线和肾锥体内下行，至肾乳头处改称乳头管，开口于肾小盏。直集合管在髓放线下行时沿途有许多弓形集合管汇入。直集合管的管径由细（直径 $40\,\mu\mathrm{m}$）变粗（直径 $200\sim 300\,\mu\mathrm{m}$），管壁上皮由单层立方上皮增高为单层柱状上皮，至乳头管处成为高柱状上皮。集合管上皮细胞分界清楚，细胞核圆，居中或靠近底部；细胞质染色浅于远端小管，甚至清亮。细胞超微结构比远端小管简单，细胞器少，细胞游离面仅有少量短微绒毛，也可见少量侧突和短小的质膜内褶。集合管能进一步重吸收水和交换离子，对尿液浓缩和维持体内酸碱平衡起重要作用。此外，其功能活动也受醛固酮和抗利尿激素的调节。另外，集合管还可受心房钠尿肽的影响，减少对水的重吸收，导致尿量增多。

:::definition{label="集合管"}
集合管（collecting duct）全长 $20\sim 38\,\mathrm{mm}$，分弓形集合管、直集合管和乳头管 3 段。能进一步重吸收水和交换离子，对尿液浓缩和维持体内酸碱平衡起重要作用。
:::

:::definition{label="弓形集合管"}
弓形集合管很短，位于皮质迷路内。一端连接远曲小管，另一端呈弧形弯入髓放线，与直集合管相通。
:::

:::definition{label="直集合管"}
直集合管在髓放线和肾锥体内下行，沿途有许多弓形集合管汇入。管径由 $40\,\mu\mathrm{m}$ 变粗为 $200\sim 300\,\mu\mathrm{m}$，上皮由单层立方增高为单层柱状。
:::

:::definition{label="乳头管"}
直集合管至肾乳头处改称乳头管，上皮成为高柱状，开口于肾小盏。终尿经此排入肾小盏。
:::

:::definition{label="集合管上皮"}
细胞分界清楚；核圆，居中或靠近底部；胞质染色浅于远端小管，甚至清亮。超微结构比远端小管简单，细胞器少；游离面仅少量短微绒毛，也可见少量侧突和短小的质膜内褶。
:::

:::note{label="调节集合管的三种激素"}
| 激素 | 对集合管的效应 |
|------|----------------|
| 醛固酮 | 促进重吸收 $\mathrm{Na}^{+}$ 和水 |
| 抗利尿激素 | 促进对水的重吸收，尿液浓缩、尿量减少 |
| 心房钠尿肽 | 减少对水的重吸收，尿量增多 |
:::

综上所述，肾小体形成的原尿，经过肾小管和集合管后，绝大部分水、营养物质和无机盐被重吸收入血，部分离子也在此进行交换；肾小管上皮细胞还排出机体部分代谢产物。最后形成浓缩的终尿，经乳头管排入肾小盏，其量为每天 $1\sim 2\,\mathrm{L}$，仅占原尿的 $1\%$ 左右。因此，肾在泌尿过程中不仅排出了机体的代谢废物，而且对维持机体水盐平衡和内环境的稳定起重要作用。

:::definition{label="终尿"}
原尿经肾小管和集合管重吸收与离子交换、并经肾小管分泌代谢产物后，形成浓缩的终尿。经乳头管排入肾小盏，每天 $1\sim 2\,\mathrm{L}$，仅占原尿的 $1\%$ 左右。
:::

:::insight{label="180 升原尿只留下 1～2 升终尿，差的那 99% 在小管和集合管里"}
滤过在肾小体一次完成；浓缩和成分改造在近端、细段、远端和集合管分段完成。近端捞回营养和大部分水，远曲和集合管听激素微调 $\mathrm{Na}^{+}$、水和酸碱。把泌尿听成“肾小球滤出来就是尿”，每天那 180 升会变成无法生存的尿崩。
:::

:::pitfall{label="终尿每天 1～2 升是原尿的约 1%，不要把 180 升当成排出量"}
$180\,\mathrm{L}$ 是两肾一昼夜的原尿；$1\sim 2\,\mathrm{L}$ 才是终尿。百分数约 $1\%$。写反或把原尿当终尿，水盐平衡那本账会从数量上崩溃。
:::

## （三）球旁复合体

球旁复合体（juxtaglomerular complex）也称肾小球旁器（juxtaglomerular apparatus），位于肾小体血管极，由球旁细胞、致密斑和球外系膜细胞组成。它们大致呈三角形，致密斑为三角形的底，入球微动脉和出球微动脉分别形成两条侧边，球外系膜细胞则位于三角区的中心（见图 17-5）。

:::definition{label="球旁复合体"}
球旁复合体（juxtaglomerular complex）也称肾小球旁器（juxtaglomerular apparatus），位于肾小体血管极，由球旁细胞、致密斑和球外系膜细胞组成。三者大致呈三角形：致密斑为底，入球微动脉和出球微动脉为两条侧边，球外系膜细胞在三角区中心。
:::

:::concept{term="先画血管极那个三角形，再问谁分泌肾素、谁感受钠、谁传信"}
球旁复合体不要拆成三个互不相干的名词。先在血管极画三角形：底是致密斑（远端小管靠血管极那一侧的离子感受器），两边是入球和出球微动脉，中心是球外系膜细胞。肾素只在入球微动脉管壁的球旁细胞颗粒里。把致密斑听成“造肾素的斑”，分泌账和感受器账会对调。
:::

### 1. 球旁细胞

球旁细胞（juxtaglomerular cell）由入球微动脉行至近肾小体血管极处、管壁中平滑肌细胞分化为上皮样细胞而成。细胞体积较大，呈立方形，细胞核大而圆，细胞质呈弱嗜碱性。电镜下，细胞内肌丝少，粗面内质网与高尔基复合体发达，有较多分泌颗粒，内含肾素（renin）。球旁细胞和血管内皮细胞之间无内弹性膜和基膜相隔，分泌物易于释放入血。

肾素是一种蛋白水解酶，能使血浆中血管紧张素原转变为血管紧张素Ⅰ，后者在肺血管内皮细胞游离面的转换酶的作用下，转变为血管紧张素Ⅱ。两种血管紧张素均可使血管平滑肌收缩，血压升高，但血管紧张素Ⅱ的作用更强。血管紧张素还可刺激肾上腺皮质分泌醛固酮，促进肾远曲小管和集合管吸收 $\mathrm{Na}^{+}$ 和水，导致血容量增大，血压升高。肾素–血管紧张素系统是机体调节血压的重要机制之一。

:::definition{label="球旁细胞"}
球旁细胞（juxtaglomerular cell）是入球微动脉近血管极处，管壁平滑肌分化成的上皮样细胞。体积较大，呈立方形，核大而圆，胞质弱嗜碱性。肌丝少，粗面内质网与高尔基复合体发达，有较多含肾素的分泌颗粒。与血管内皮之间无内弹性膜和基膜相隔，分泌物易于释放入血。
:::

:::definition{label="肾素"}
肾素（renin）是球旁细胞分泌颗粒内的蛋白水解酶，能使血浆中血管紧张素原转变为血管紧张素Ⅰ。
:::

:::definition{label="肾素-血管紧张素系统"}
血管紧张素Ⅰ在肺血管内皮细胞游离面转换酶作用下转变为血管紧张素Ⅱ。两种血管紧张素均使血管平滑肌收缩、血压升高，血管紧张素Ⅱ作用更强。血管紧张素还刺激肾上腺皮质分泌醛固酮，促进远曲小管和集合管吸收 $\mathrm{Na}^{+}$ 和水，血容量增大，血压升高。这是机体调节血压的重要机制之一。
:::

:::insight{label="球旁细胞把平滑肌身份换成内分泌，肾素才能直接入血"}
肌丝减少、分泌颗粒增多，又抽掉内弹性膜和基膜，等于在入球微动脉管壁上开了一个内分泌窗口。肾素入血后，肺里的转换酶把血管紧张素Ⅰ做成Ⅱ，外周血管收缩；醛固酮再让远曲和集合管保 $\mathrm{Na}^{+}$ 保水。血压账从血管极的颗粒开始，落到肺内皮和肾上腺皮质。
:::

:::pitfall{label="肾素是球旁细胞分泌的，不是致密斑分泌的"}
致密斑感受远端小管内 $\mathrm{Na}^{+}$ 浓度变化，把信息传给球旁细胞，改变肾素分泌水平。造肾素的是入球微动脉壁上那排上皮样平滑肌细胞。写反以后，离子感受器和内分泌会并成一个细胞。
:::

### 2. 致密斑

致密斑（macula densa）为远端小管靠近肾小体血管极侧的上皮细胞形成的椭圆形斑。此处上皮细胞呈柱状，排列紧密；细胞质色浅，细胞核椭圆形，位于近细胞顶部。致密斑处的基膜常不完整，细胞基部有细小的分支突起，并可与邻近球旁细胞和球外系膜细胞连接。致密斑是一种离子感受器，能敏锐地感受远端小管内 $\mathrm{Na}^{+}$ 浓度变化，并将信息传递给球旁细胞，改变肾素的分泌水平，继而调节远端小管和集合管对 $\mathrm{Na}^{+}$ 的重吸收。

:::definition{label="致密斑"}
致密斑（macula densa）是远端小管靠近肾小体血管极侧的上皮形成的椭圆形斑，落在远曲起始（远端小管返回原肾小体处）。上皮细胞呈柱状、排列紧密；胞质色浅；核椭圆形，位于近细胞顶部。基膜常不完整，基部有细小分支突起，可与邻近球旁细胞和球外系膜细胞连接。
:::

:::definition{label="致密斑的离子感受器职分"}
致密斑能敏锐地感受远端小管内 $\mathrm{Na}^{+}$ 浓度变化，将信息传递给球旁细胞，改变肾素分泌水平，继而调节远端小管和集合管对 $\mathrm{Na}^{+}$ 的重吸收。
:::

:::pitfall{label="致密斑在远端小管靠近血管极的远曲起始，不要写到近曲上"}
近曲在尿极与肾小囊壁层相续；致密斑在血管极，是远端小管返回原肾小体时靠血管极那一侧的高柱状斑。切片上紧贴血管极、核靠顶部、排列紧密的那一排，不是近曲刷状缘。把致密斑写到近曲或细段，三角形的底就画错边。
:::

### 3. 球外系膜细胞

球外系膜细胞（extraglomerular mesangial cell）又称极垫细胞（polar cushion cell）。球外系膜与球内系膜相延续，球外系膜细胞的形态结构也与球内系膜细胞相似，并与球旁细胞、球内系膜细胞之间有缝隙连接，因此认为它在球旁复合体功能活动中，可能起信息传递作用。

:::definition{label="球外系膜细胞"}
球外系膜细胞（extraglomerular mesangial cell）又称极垫细胞（polar cushion cell），位于球旁复合体三角区中心。球外系膜与球内系膜相延续；细胞形态结构与球内系膜细胞相似，并与球旁细胞、球内系膜细胞之间有缝隙连接，可能起信息传递作用。
:::

:::compare{title="球旁复合体三成员"}
| 项目 | 球旁细胞 | 致密斑 | 球外系膜细胞 |
|------|----------|--------|--------------|
| 位置 | 入球微动脉近血管极管壁 | 远端小管靠血管极侧，远曲起始 | 三角区中心 |
| 来源 / 本质 | 平滑肌分化的上皮样细胞 | 远端小管上皮特化 | 与球内系膜相延续 |
| 光镜要点 | 立方形，核大而圆，胞质弱嗜碱 | 柱状、紧密，核近顶部 | 填充于入球、出球与致密斑之间 |
| 超微要点 | 肌丝少，分泌颗粒含肾素；与内皮之间无内弹性膜和基膜 | 基膜常不完整，基部细突起 | 与球旁、球内系膜细胞有缝隙连接 |
| 职分 | 分泌肾素 | $\mathrm{Na}^{+}$ 离子感受器 | 可能传递信息 |
:::

## （四）肾间质

肾间质包括肾内的结缔组织、血管、神经等。皮质结缔组织很少，越接近肾乳头越多。髓质中的成纤维细胞因形态和功能较特殊，被称为间质细胞（interstitial cell）（图 17-13）。细胞呈不规则形或星形，其长轴与肾小管或集合管垂直，细胞质内除有较多细胞器外，还有较多脂滴。该细胞可合成间质内的纤维和基质，产生前列腺素。前列腺素可舒张血管，促进周围血管内的血液流动，加快重吸收水分的转运，从而促进尿液浓缩。另外，间质细胞还产生促红细胞生成素，刺激骨髓中红细胞生成。肾病晚期往往伴有贫血。

:::definition{label="肾间质细胞"}
髓质中形态和功能较特殊的成纤维细胞称为间质细胞（interstitial cell）。呈不规则形或星形，长轴与肾小管或集合管垂直；胞质除较多细胞器外，还有较多脂滴。可合成间质内的纤维和基质，产生前列腺素和促红细胞生成素。
:::

:::definition{label="前列腺素（肾间质）"}
间质细胞产生的前列腺素可舒张血管，促进周围血管内的血液流动，加快重吸收水分的转运，从而促进尿液浓缩。
:::

:::definition{label="促红细胞生成素"}
间质细胞产生促红细胞生成素，刺激骨髓中红细胞生成。肾病晚期往往伴有贫血。
:::

::figure{src="/images/histology/textbook/p0199_01.png" caption="图17-13 肾髓质光镜图。1. 直集合管；↑ 间质细胞。" alt="肾髓质光镜：直集合管细胞分界清楚、胞质浅亮，管间可见长轴与管道垂直的间质细胞"}

:::pitfall{label="促红细胞生成素和前列腺素主要记在髓质间质细胞，不要写成球旁细胞"}
球旁细胞的颗粒里是肾素。舒张血管、促红细胞生成这本旁分泌 / 内分泌账，教材写在髓质间质细胞。肾病晚期贫血，是间质细胞受损、促红细胞生成素减少，不是“肾素少了就会贫血”。
:::

:::insight{label="越靠近乳头，间质越多，浓缩和造血的细胞学生意也越明显"}
皮质结缔组织很少；越接近肾乳头越多。间质细胞长轴与管道垂直，脂滴多，既铺纤维基质，又造前列腺素加快水分转运。把肾间质听成“可忽略的填充”，尿液浓缩和肾性贫血会少一个细胞学落点。
:::

## （五）肾的血液循环

肾动脉经肾门入肾后分为数支叶间动脉，在肾柱内上行至皮质与髓质交界处，横向分支为弓形动脉。弓形动脉分出若干小叶间动脉，伸入皮质迷路（图 17-14，图 17-15），其末端抵达被膜下形成毛细血管网。小叶间动脉沿途向两侧发出许多入球微动脉进入肾小体，形成血管球，继而汇合成出球微动脉。浅表肾单位的出球微动脉离开肾小体后，又分支形成球后毛细血管网，分布在肾小管周围。毛细血管网依次汇合成小叶间静脉、弓形静脉和叶间静脉，它们与相应动脉伴行，最后形成肾静脉出肾。髓旁肾单位的出球微动脉不仅形成球后毛细血管网，而且还发出若干直小动脉直行进入髓质；而后在髓质的不同深度，折返上升为直小静脉，与直小动脉共同构成 U 形血管袢，与髓袢伴行（表 17-2）。

:::definition{label="肾内动脉主干路径"}
肾动脉经肾门入肾 → 叶间动脉（肾柱内上行至皮髓交界）→ 弓形动脉（横向）→ 小叶间动脉（伸入皮质迷路，末端在被膜下成毛细血管网）→ 入球微动脉 → 血管球 → 出球微动脉。
:::

:::definition{label="球后毛细血管网"}
浅表肾单位的出球微动脉离开肾小体后分支形成，分布在肾小管周围。血液流经血管球时大量水分被滤出，故球后毛细血管内血液的胶体渗透压很高，有利于肾小管上皮重吸收的物质进入血液。
:::

:::definition{label="直小血管袢"}
髓旁肾单位的出球微动脉除形成球后毛细血管网外，还发出若干直小动脉直行进入髓质；在髓质不同深度折返上升为直小静脉，与直小动脉共同构成 U 形血管袢，与髓袢伴行，有利于肾小管和集合管的重吸收和尿液浓缩。
:::

::figure{src="/images/histology/textbook/p0199_02.png" caption="图17-14 肾皮质血管光镜图（肾动脉墨汁灌注法）。1. 血管球；* 小叶间动脉；↑ 入球微动脉。" alt="肾动脉墨汁灌注：小叶间动脉向两侧发出入球微动脉，末端形成墨染的血管球"}

::figure{src="/images/histology/textbook/p0200_01.png" caption="图17-15 肾血液循环模式图。示叶间、弓形、小叶间动静脉，入球与出球微动脉，血管球，球后毛细血管网与直血管袢。" alt="肾血液循环模式：左侧浅表肾单位出球后成球后毛细血管网，右侧髓旁肾单位另发直血管袢伴行髓袢"}

:::note{label="表17-2 肾的血液循环"}
| 区段 | 动脉侧 | 静脉侧 |
|------|--------|--------|
| 入肾至皮质 | 肾动脉 → 叶间动脉 → 弓形动脉 → 小叶间动脉 | 小叶间静脉 → 弓形静脉 → 叶间静脉 → 肾静脉（与动脉伴行） |
| 肾小体 | 入球微动脉 → 血管球（动脉性毛细血管网） | — |
| 浅表肾单位出球后 | 出球微动脉 → 球后毛细血管网（肾小管周围） | 汇入小叶间静脉 |
| 髓旁肾单位出球后 | 出球微动脉 → 球后毛细血管网 + 直小动脉入髓质 | 直小静脉折返 → 弓形静脉 |
| 被膜下 | 小叶间动脉末端毛细血管网 | 回流入上述静脉 |
:::

肾的血液循环与肾功能密切相关，其特点是：① 血流量大，流速快，约占心输出量的 $1/4$，这是由于肾动脉直接发自腹主动脉，短而粗；此外，肾内血管行走较直，血液能很快抵达血管球。② $90\%$ 的血液供应皮质，进入肾小体后被滤过。③ 入球微动脉较出球微动脉粗，使血管球内压较高，有利于滤过。④ 两次形成毛细血管网，即入球微动脉分支形成血管球，出球微动脉分布在肾小管周围形成球后毛细血管网。由于血液流经血管球时大量水分被滤出，因此球后毛细血管内血液的胶体渗透压很高，有利于肾小管上皮细胞重吸收的物质进入血液。⑤ 髓质内的直小血管与髓袢伴行，有利于肾小管和集合管的重吸收和尿液浓缩。

:::definition{label="肾血液循环的五个特点"}
① 血流量大、流速快，约占心输出量的 $1/4$（肾动脉直接发自腹主动脉，短而粗；肾内血管行走较直）。② $90\%$ 的血液供应皮质，进入肾小体后被滤过。③ 入球微动脉较出球微动脉粗，血管球内压高，利于滤过。④ 两次形成毛细血管网：血管球 + 球后毛细血管网；球后胶体渗透压高，利于重吸收物入血。⑤ 髓质直小血管与髓袢伴行，利于重吸收和尿液浓缩。
:::

:::compare{title="血管球与球后毛细血管网"}
| 项目 | 血管球（第一次毛细血管网） | 球后毛细血管网（第二次毛细血管网） |
|------|------------------------------|--------------------------------------|
| 来源 | 入球微动脉分支 | 出球微动脉分支 |
| 类型 | 动脉性毛细血管网，有孔，多无隔膜 | 分布在肾小管周围 |
| 血压 / 渗透压 | 血压高，利于滤过 | 胶体渗透压高，利于重吸收物入血 |
| 职分 | 生成原尿 | 接住肾小管重吸收回来的物质 |
:::

:::pitfall{label="肾内是两次毛细血管网，不要写成一次滤过就回静脉"}
第一次网在肾小体里滤过；第二次网在小管周围接住重吸收。中间隔着一条更细的出球微动脉。少写一次网，球后高胶体渗透压和直小血管袢都会失去来源。
:::

:::insight{label="入球粗、出球细，既抬高球内压，又把浓缩过的血浆送给小管周围"}
同一条出球微动脉，在浅表只铺球后网，在髓旁还要抽出直小动脉去伴行髓袢。$90\%$ 的血先供皮质滤过，$1/4$ 的心输出量从腹主动脉抄近道进来。循环形态就是肾功能的管道图。
:::

:::keypoint{label="肾先立皮质髓质，再把肾单位、滤过三层、小管各段、球旁三角形和两次毛细血管网收口"}
- 实质：皮质（迷路、髓放线、肾柱）+ 髓质（$10\sim 18$ 个肾锥体）；肾小叶 = 一条髓放线 + 周围迷路；肾叶 = 一个锥体 + 相连皮质。
- 肾单位 = 肾小体 + 肾小管，每肾约 150 万；集合管不算肾单位。浅表（皮质）肾单位约 $85\%$，髓旁（近髓）约 $15\%$。
- 肾小体直径约 $200\,\mu\mathrm{m}$，血管极对尿极；血管球是入球粗、出球细的动脉性有孔毛细血管网（孔径 $50\sim 100\,\mathrm{nm}$）。
- 滤过屏障三层：有孔内皮、基膜（成人约 $330\,\mathrm{nm}$，分子筛 $4\sim 8\,\mathrm{nm}$）、足细胞裂孔膜（裂孔约 $25\,\mathrm{nm}$，膜 $4\sim 6\,\mathrm{nm}$）；$70\,\mathrm{kDa}$、直径 $4\,\mathrm{nm}$ 以下且正电荷易过；两肾原尿约 $180\,\mathrm{L}/\mathrm{d}$。
- 近曲有刷状缘，表面积 $50\sim 60\,\mathrm{m}^{2}$，重吸收主战场；远曲无刷状缘，受醛固酮和抗利尿激素调节。髓袢 = 近直 + 细段 + 远直。
- 终尿每天 $1\sim 2\,\mathrm{L}$，约占原尿 $1\%$。
- 球旁复合体在血管极：球旁细胞分泌肾素，致密斑在远曲起始感受 $\mathrm{Na}^{+}$，球外系膜可能传信。
- 髓质间质细胞造前列腺素和促红细胞生成素。
- 循环：肾动脉 → 叶间 → 弓形 → 小叶间 → 入球 → 血管球 → 出球 → 球后网 / 直小血管袢；血量约心输出量 $1/4$，$90\%$ 供皮质；两次毛细血管网。
:::

:::memory{label="本节必背要点"}
- [ ] 泌尿系统（urinary system）包括肾、输尿管、膀胱和尿道；肾产生尿液，其余为排尿器官。
- [ ] 肾（kidney）以形成尿液排出代谢废物，调节水盐代谢和离子平衡，维持内环境稳定；还分泌肾素、前列腺素和促红细胞生成素等。
- [ ] 肾呈豆形，外侧缘隆凸，内侧缘中部凹陷；表面有致密结缔组织被膜。
- [ ] 肾实质分为皮质和髓质；髓质由 $10\sim 18$ 个肾锥体（renal pyramid）组成。
- [ ] 锥体尖端钝圆突入肾小盏，称肾乳头，乳头管开口于此处。
- [ ] 从肾锥体底呈辐射状伸入皮质的条纹称髓放线（medullary ray）；髓放线之间的皮质称皮质迷路（cortical labyrinth）。
- [ ] 一条髓放线及其周围的皮质迷路组成一个肾小叶；一个肾锥体与相连的皮质组成一个肾叶；锥体之间的皮质称肾柱。
- [ ] 肾实质由大量肾单位和集合管构成；肾单位包括一个肾小体和一条相连的肾小管，是尿液形成的结构和功能单位。
- [ ] 肾小管汇入集合管，二者都是单层上皮性管道，合称泌尿小管。
- [ ] 肾小体和肾小管的弯曲部分位于皮质迷路和肾柱内；肾小管的直行部分与集合管位于髓放线和肾锥体内。
- [ ] 肾内少量结缔组织、血管和神经等构成肾间质。
- [ ] 肾单位（nephron）由肾小体和肾小管组成，每个肾约有 150 万个肾单位，与集合管共同行使泌尿功能。
- [ ] 肾小管走行：近曲小管 → 近直小管 → 细段 → 远直小管 → 远曲小管 → 集合管。
- [ ] 近直小管、细段和远直小管构成 U 型髓袢（medullary loop）。
- [ ] 浅表肾单位（皮质肾单位）的肾小体位于皮质浅层和中层，体积较小，髓袢较短，约占 $85\%$，在尿液形成中起重要作用。
- [ ] 髓旁肾单位（近髓肾单位）的肾小体位于皮质深部，体积较大，髓袢较长，约占 $15\%$，对尿液浓缩有重要生理意义。
- [ ] 肾小体（renal corpuscle）呈球形，又称肾小球，直径约 $200\,\mu\mathrm{m}$，由肾小囊和血管球组成。
- [ ] 微动脉出入的一端称血管极，对侧与近曲小管相连的一端称尿极。
- [ ] 血管球（glomerulus）是肾小囊中一团盘曲的毛细血管，为独特的动脉性毛细血管网。
- [ ] 入球微动脉分成 $4\sim 5$ 支，再分出袢状毛细血管并吻合为网，于近血管极汇成一条出球微动脉。
- [ ] 入球微动脉管径较出球微动脉粗，使毛细血管内血压较高。
- [ ] 血管球毛细血管为有孔型，孔径 $50\sim 100\,\mathrm{nm}$，多无隔膜；内皮游离面细胞衣富含带负电荷的唾液酸糖蛋白。
- [ ] 血管球毛细血管基膜成人约 $330\,\mathrm{nm}$，电镜下分 3 层（中层厚而致密，内、外层薄而稀疏）。
- [ ] 基膜主要成分为Ⅳ型胶原蛋白、层粘连蛋白和蛋白聚糖（糖胺聚糖以带负电荷的硫酸肝素为主）；Ⅳ型胶原形成孔径 $4\sim 8\,\mathrm{nm}$ 的分子筛。
- [ ] 血管系膜（mesangium）又称球内系膜，主要由球内系膜细胞和系膜基质组成。
- [ ] 球内系膜细胞形态不规则，突起可伸至内皮与基膜之间；目前认为是特化的平滑肌细胞，能合成基膜和系膜基质，吞噬降解免疫复合物，参与基膜更新修复。
- [ ] 有些肾小球肾炎可见系膜细胞弥漫性增生、系膜基质增多、系膜区免疫复合物沉积；血管系膜内还可见少量巨噬细胞。
- [ ] 光镜下核着色：球内系膜细胞最深，内皮细胞次之，足细胞最浅。
- [ ] 肾小囊（renal capsule）是肾小管起始端膨大凹陷而成的杯状双层上皮囊；壁层为单层扁平上皮，脏层为足细胞，两层之间为肾小囊腔。
- [ ] 足细胞（podocyte）胞体较大、凸向囊腔；初级突起再分指状次级突起，嵌合成栅栏状贴在基膜外面，表面覆带负电荷的唾液酸糖蛋白。
- [ ] 次级突起间裂孔（slit pore）宽约 $25\,\mathrm{nm}$，上覆 $4\sim 6\,\mathrm{nm}$ 的裂孔膜（slit membrane）；微丝收缩可改变裂孔宽度，调节滤过率。
- [ ] 滤过屏障（filtration barrier）即滤过膜，为有孔内皮、基膜和足细胞裂孔膜 3 层。
- [ ] 一般情况下，分子量 $70\,\mathrm{kDa}$ 以下、直径 $4\,\mathrm{nm}$ 以下的物质可通过滤过膜，带正电荷者更易通过（如葡萄糖、多肽、尿素、电解质和水）。
- [ ] 原尿除不含大分子蛋白质外，成分与血浆相似；成人两肾一昼夜约形成 $180\,\mathrm{L}$ 原尿。
- [ ] 滤过膜受损（如肾小球肾炎）可出现蛋白尿或血尿；系膜细胞清除沉积物、内皮和足细胞再建基膜后功能可恢复。
- [ ] 肾小管管壁为单层上皮，外为基膜和极少量结缔组织，有重吸收和排泄作用。
- [ ] 近端小管是肾小管中最长最粗的一段，长约 $14\,\mathrm{mm}$，约占肾小管总长的一半；管径 $50\sim 60\,\mu\mathrm{m}$，管腔不甚规则。
- [ ] 近曲小管上皮为立方形或锥形，分界不清，胞体较大，胞质嗜酸性，核圆近基底部，腔面有刷状缘。
- [ ] 刷状缘由大量较长微绒毛构成；两肾近曲小管表面积总计可达 $50\sim 60\,\mathrm{m}^{2}$；膜中有丰富碱性磷酸酶和 ATP 酶。
- [ ] 微绒毛基部细胞膜凹陷成顶小管和顶小泡，吞饮原尿中小分子蛋白质，与溶酶体结合后降解。
- [ ] 近曲细胞侧突相互嵌合故光镜下分界不清；基部发达质膜内褶含纵向杆状线粒体；基部质膜有丰富 $\mathrm{Na}^{+}$-$\mathrm{K}^{+}$-ATP 酶（钠泵）。
- [ ] 近直小管结构与曲部基本相似，但细胞较矮，微绒毛、侧突和质膜内褶不如曲部发达。
- [ ] 原尿中几乎所有葡萄糖、氨基酸、蛋白质以及大部分水、离子和尿素等均在近端小管重吸收。
- [ ] 近端小管紧密连接不是完全封闭，对水和离子通透阻力较低；还分泌 $\mathrm{H}^{+}$、$\mathrm{NH}_{3}$、肌酐和马尿酸，并转运排出酚红和青霉素。
- [ ] 临床上常用马尿酸或酚红排泄试验检测近端小管功能。
- [ ] 细段直径 $10\sim 15\,\mu\mathrm{m}$，单层扁平上皮，核椭圆、含核部分突向管腔，胞质浅，无刷状缘，利于水和离子通透。
- [ ] 远端小管包括远直和远曲；管腔较大而规则，细胞立方形、比近端小，核位于中央或靠近管腔，胞质较浅，无刷状缘。
- [ ] 远直小管管径约 $30\,\mu\mathrm{m}$；质膜内褶发达可伸达顶部，钠泵主动向间质转运 $\mathrm{Na}^{+}$。
- [ ] 远曲小管直径 $35\sim 45\,\mu\mathrm{m}$，质膜内褶不如直部发达；吸收水、$\mathrm{Na}^{+}$，排出 $\mathrm{K}^{+}$、$\mathrm{H}^{+}$、$\mathrm{NH}_{3}$，是离子交换的重要部位。
- [ ] 醛固酮促进远曲重吸收 $\mathrm{Na}^{+}$、排出 $\mathrm{K}^{+}$；抗利尿激素促进此段对水的重吸收，尿液浓缩、尿量减少。
- [ ] 集合管（collecting duct）全长 $20\sim 38\,\mathrm{mm}$，分弓形集合管、直集合管和乳头管 3 段。
- [ ] 弓形集合管很短，位于皮质迷路，连接远曲与直集合管；直集合管在髓放线和肾锥体内下行，至乳头改称乳头管，开口于肾小盏。
- [ ] 直集合管管径由 $40\,\mu\mathrm{m}$ 变粗为 $200\sim 300\,\mu\mathrm{m}$，上皮由单层立方增高为单层柱状，乳头管处为高柱状。
- [ ] 集合管上皮分界清楚，核圆、居中或近底部，胞质浅于远端小管甚至清亮；受醛固酮、抗利尿激素和心房钠尿肽调节。
- [ ] 终尿每天 $1\sim 2\,\mathrm{L}$，仅占原尿的 $1\%$ 左右。
- [ ] 球旁复合体（juxtaglomerular complex）位于血管极，由球旁细胞、致密斑和球外系膜细胞组成，大致呈三角形。
- [ ] 球旁细胞由入球微动脉近血管极处平滑肌分化而来，分泌颗粒内含肾素；与内皮之间无内弹性膜和基膜相隔。
- [ ] 肾素使血管紧张素原变为血管紧张素Ⅰ，后者经肺血管内皮转换酶变为血管紧张素Ⅱ；Ⅱ的缩血管作用更强，并可刺激醛固酮分泌。
- [ ] 致密斑（macula densa）为远端小管靠近血管极侧的椭圆斑（远曲起始）；柱状、排列紧密，核近顶部，是 $\mathrm{Na}^{+}$ 离子感受器。
- [ ] 球外系膜细胞又称极垫细胞，与球内系膜相延续，与球旁细胞、球内系膜细胞有缝隙连接，可能起信息传递作用。
- [ ] 皮质结缔组织很少，越接近肾乳头越多；髓质间质细胞呈不规则形或星形，长轴与管道垂直，含较多脂滴。
- [ ] 间质细胞合成纤维和基质，产生前列腺素（舒张血管、促进尿液浓缩）和促红细胞生成素；肾病晚期往往伴有贫血。
- [ ] 肾动脉 → 叶间动脉 → 弓形动脉 → 小叶间动脉 → 入球微动脉 → 血管球 → 出球微动脉。
- [ ] 浅表肾单位出球微动脉形成球后毛细血管网；静脉经小叶间静脉、弓形静脉、叶间静脉汇成肾静脉出肾。
- [ ] 髓旁肾单位出球微动脉还发出直小动脉入髓质，折返为直小静脉，构成与髓袢伴行的 U 形血管袢。
- [ ] 肾血流量约占心输出量的 $1/4$；$90\%$ 的血液供应皮质；入球粗于出球；两次形成毛细血管网；直小血管与髓袢伴行。
- [ ] 球后毛细血管内血液胶体渗透压很高，有利于肾小管重吸收的物质进入血液。
