# 六、颈的形成

第 $1$ 鳃弓在前面已经分成上、下颌突去围颜面。颈不是另长出来的一根管子，而是第 $5$ 周第 $2$ 鳃弓向尾侧盖过第 $3$、$4$、$6$ 鳃弓，与心上嵴融合，把深面封成颈窦；窦很快闭锁。随后鳃弓分化、食管气管伸长、心脏下降，颈才拉出来。本节只写这三步；四肢下一节再写。

:::definition{label="颈的形成（本节范围）"}
颈的形成发生在第 $5$ 周以后。材料来自被第 $2$ 鳃弓盖住的鳃弓区，再加上食管、气管伸长和心脏下降。它不是额鼻突长出来的，也不等于心隆起上移。
:::

第 $5$ 周时，第 $2$ 鳃弓生长迅速，向尾侧延伸，越过第 $3$、$4$、$6$ 鳃弓与下方的心上嵴融合。心上嵴是心隆起上缘的间充质增生并向头端长出的嵴状突起。当二者融合后，第 $2$ 鳃弓与深部 $3$ 个较小鳃弓之间构成封闭的腔隙，称颈窦（cervical sinus）。颈窦很快闭锁消失。随着鳃弓的分化、食管和气管的伸长及心脏位置的下降，颈逐渐形成。

:::definition{label="第2鳃弓的尾侧延伸"}
第 $5$ 周第 $2$ 鳃弓生长迅速，向尾侧延伸，越过第 $3$、$4$、$6$ 鳃弓，与心上嵴融合。被盖住的是第 $3$、$4$、$6$ 对，不是第 $5$ 对——第 $5$ 对鳃弓出现不久即消失，第 $6$ 对很小。
:::

:::definition{label="心上嵴"}
心上嵴是心隆起上缘的间充质增生、并向头端长出的嵴状突起。它不是心隆起本身，也不是第 $1$ 鳃弓。第 $2$ 鳃弓必须与它融合，颈窦才能封闭。
:::

:::definition{label="颈窦"}
颈窦（cervical sinus）是第 $2$ 鳃弓与心上嵴融合后，第 $2$ 鳃弓与深部 $3$ 个较小鳃弓之间构成的封闭腔隙。正常情况下很快闭锁消失，不留到出生。
:::

:::definition{label="深部3个较小鳃弓"}
被第 $2$ 鳃弓盖住的深部 $3$ 个较小鳃弓是第 $3$、$4$、$6$ 鳃弓。第 $5$ 对已消失，不能写成“第 $3$、$4$、$5$ 鳃弓”。
:::

:::concept{term="先问第2鳃弓盖住了哪几对弓，再问颈窦闭了没有、心脏下没下降"}
看见“颈的形成”，不要写成“鳃弓直接变成脖子”。先问第 $5$ 周第 $2$ 鳃弓有没有向尾侧越过第 $3$、$4$、$6$ 鳃弓并与心上嵴融合——融合后深面那口封闭腔隙才叫颈窦。再问两件事：颈窦很快闭锁了没有；鳃弓分化、食管气管伸长、心脏下降这三件事做了没有。把心上嵴听成心隆起，或把第 $5$ 对弓写进被盖名单，颈的户头会对错。
:::

:::compare{title="第1鳃弓、第2鳃弓与颈窦"}
| 项目 | 第 $1$ 鳃弓 | 第 $2$ 鳃弓 | 颈窦 |
|------|-------------|-------------|------|
| 主要去向 | 分成上颌突、下颌突，围口凹、造颜面 | 第 $5$ 周向尾侧延伸，盖过第 $3$、$4$、$6$ 鳃弓 | 第 $2$ 鳃弓与心上嵴融合后夹出的封闭腔隙 |
| 融合对象 | 左右下颌突中线融合；上颌突与内、外侧鼻突融合 | 与心上嵴融合 | 本身是腔，很快闭锁消失 |
| 时间 | 第 $4\sim 5$ 周颜面启动 | 第 $5$ 周 | 融合当时出现，随即消失 |
| 不要听成 | 已经是颈 | 第 $1$ 鳃弓的延续 | 永久的颈部器官 |
:::

:::compare{title="心隆起与心上嵴"}
| 项目 | 心隆起 | 心上嵴 |
|------|--------|--------|
| 是什么 | 口咽膜尾侧原始心脏发育增大并突起 | 心隆起上缘间充质增生、向头端长出的嵴状突起 |
| 位置 | 头部腹侧尾方的心脏隆起 | 心隆起上缘、朝头端 |
| 在颈形成中的角色 | 心脏稍后位置下降，帮助把颈拉长 | 作为第 $2$ 鳃弓尾侧延伸的融合对象，封闭颈窦 |
| 不要听成 | 心上嵴 | 心隆起本身 |
:::

:::cause-effect{title="第2鳃弓盖住深部弓之后，颈才能被拉出来"}
- 因：第 $5$ 周第 $2$ 鳃弓迅速向尾侧延伸，越过第 $3$、$4$、$6$ 鳃弓，与心上嵴融合
- 果：第 $2$ 鳃弓与深部 $3$ 个较小鳃弓之间出现封闭的颈窦
- 因：颈窦很快闭锁消失
- 果：颈部表面不再留鳃沟样开口
- 因：鳃弓分化、食管和气管伸长、心脏位置下降
- 果：颈逐渐形成
- 制约：三件事要一起发生；只写“第 $2$ 鳃弓长大”还拉不出颈
:::

:::pitfall{label="被盖住的是第3、4、6鳃弓，不要写成第3、4、5鳃弓"}
第一节已经写明：人胚前 $4$ 对鳃弓外观显著，第 $5$ 对出现不久即消失，第 $6$ 对很小。第 $2$ 鳃弓向尾侧越过的名单是第 $3$、$4$、$6$ 对，深部较小的也是这 $3$ 个。习惯按自然数写成“$3$、$4$、$5$”，颈窦的深部户头会多出一对已经消失的弓，又漏掉第 $6$ 对。
:::

:::pitfall{label="颈窦很快闭锁，不要当成正常颈部还留着的囊"}
教材写的是：融合后构成颈窦，颈窦很快闭锁消失。正常颈的形成以窦消失为前提。本节不把颈窦写成终身存在的器官，也不在此处展开鳃源性囊肿——主要畸形在第八节，名单里没有这一条。
:::

:::note{label="颈形成的三件并行事件"}
颈逐渐形成，靠的是：① 鳃弓的分化；② 食管和气管的伸长；③ 心脏位置的下降。第 $2$ 鳃弓与心上嵴融合、颈窦闭锁，是把鳃区表面收拾平；后面这三件才把颈的长度拉出来。心脏仍停在原来的心隆起位置，脖子出不来。
:::

:::insight{label="颜面用第1鳃弓去围，颈用第2鳃弓去盖"}
第 $1$ 鳃弓腹侧分成上、下颌突，和额鼻突一起围口凹，走的是“突起融合”的颜面账。颈走的是另一本账：第 $2$ 鳃弓当盖子，把第 $3$、$4$、$6$ 弓盖进深部，再靠咽食管气管伸长和心脏下降把这段拉长。把颈写成“左右鳃弓在腹侧中线再融一次”，会和颜面五突并成一句。
:::

:::timeline{period="第5周起：颈窦出现并消失，颈被拉出"}
- **第5周** 第 2 鳃弓生长迅速，向尾侧延伸
- **越过** 盖过第 3、4、6 鳃弓（第 5 对已消失）
- **融合** 与心隆起上缘向头端长出的心上嵴融合
- **颈窦** 第 2 鳃弓与深部 3 个较小鳃弓之间形成封闭腔隙
- **闭锁** 颈窦很快闭锁消失
- **颈形成** 鳃弓分化 + 食管和气管伸长 + 心脏位置下降，颈逐渐形成
:::

:::tip{label="颈的口诀"}
二弓当盖，盖住三四六；心上嵴一封，颈窦即消失。弓分化、管伸长、心下降，脖子才出来。
:::

:::keypoint{label="第2鳃弓盖住3、4、6弓，颈窦闭锁，三件事拉出颈"}
- 第 $5$ 周：第 $2$ 鳃弓迅速向尾侧延伸，越过第 $3$、$4$、$6$ 鳃弓。
- 心上嵴 = 心隆起上缘间充质增生并向头端长出的嵴；第 $2$ 鳃弓与之融合。
- 融合后，第 $2$ 鳃弓与深部 $3$ 个较小鳃弓之间 = 颈窦（cervical sinus）。
- 颈窦很快闭锁消失。
- 颈逐渐形成 = 鳃弓分化 + 食管和气管伸长 + 心脏位置下降。
:::
