# 二、甲状旁腺

甲状旁腺（parathyroid gland）有上下两对，分别位于甲状腺左、右两叶的背面。单个腺体呈扁椭圆形，腺表面包有薄层结缔组织被膜，实质内腺细胞排列成索团状，其间有丰富的有孔毛细血管、散在的脂肪细胞以及少量结缔组织。腺细胞分主细胞和嗜酸性细胞两种（图 13-4）。上一节滤泡旁细胞把血钙往下按，本节主细胞把血钙往上抬；两本账合在一起，才是血钙的稳定闸门。

:::definition{label="甲状旁腺"}
甲状旁腺（parathyroid gland）有上下两对，分别位于甲状腺左、右两叶的背面。单个腺体呈扁椭圆形，表面包薄层结缔组织被膜。实质内腺细胞排列成索团状，其间有丰富的有孔毛细血管、散在的脂肪细胞以及少量结缔组织。
:::

:::definition{label="甲状旁腺实质"}
甲状旁腺实质内腺细胞排列成索团状，无滤泡腔。索团之间是丰富的有孔毛细血管、散在的脂肪细胞和少量结缔组织。脂肪细胞随年龄可增多，光镜下呈大空泡，不要当成胶质滤泡。
:::

:::concept{term="先问升血钙的是主细胞，还是降血钙的滤泡旁细胞"}
看见血钙，先问细胞在哪个腺体。升钙的是甲状旁腺主细胞，产物是甲状旁腺激素；降钙的是甲状腺滤泡旁细胞，产物是降钙素。甲状旁腺本身没有滤泡，也不造甲状腺激素。把“甲旁”听成“甲状腺旁边那层滤泡”，主细胞和滤泡上皮会并成一种。
:::

:::compare{title="甲状腺与甲状旁腺"}
| 项目 | 甲状腺 | 甲状旁腺 |
|------|--------|----------|
| 位置 | 颈前，左右叶 + 峡部 | 甲状腺左右叶背面，上下两对 |
| 实质排列 | 滤泡（上皮围胶质） | 索团状，无滤泡腔 |
| 主要腺细胞 | 滤泡上皮细胞、滤泡旁细胞 | 主细胞、嗜酸性细胞 |
| 与血钙 | 滤泡旁细胞降钙素降血钙 | 主细胞甲状旁腺激素升血钙 |
| 光镜第一眼 | 大小滤泡 + 嗜酸胶质 | 密集索团 + 散在脂肪空泡 |
:::

:::pitfall{label="甲状旁腺没有滤泡，不要把脂肪空泡当成胶质腔"}
甲状旁腺实质是索团状腺细胞，HE 里较大的透明圆泡是散在脂肪细胞，不是甲状腺那种嗜酸胶质滤泡。主细胞着色浅，也不要当成滤泡旁细胞。把脂肪空泡圈成“滤泡”，碘化甲状腺球蛋白会被错安到甲状旁腺里。
:::

## 1. 主细胞

主细胞（chief cell）数量最多，呈多边形，核圆，居中，HE 染色细胞质着色浅。主细胞分泌甲状旁腺激素（parathyroid hormone），主要作用于骨细胞和破骨细胞，使骨盐溶解，并能促进肠及肾小管吸收 $\mathrm{Ca}^{2+}$，从而使血钙升高。在甲状旁腺激素和降钙素的共同调节下，机体维持血钙的稳定。

:::definition{label="主细胞"}
主细胞（chief cell）是甲状旁腺数量最多的腺细胞，呈多边形，核圆居中，HE 胞质着色浅。分泌甲状旁腺激素。属含氮激素分泌细胞。
:::

:::definition{label="甲状旁腺激素"}
甲状旁腺激素（parathyroid hormone，PTH）由主细胞分泌。主要作用于骨细胞和破骨细胞，使骨盐溶解；并能促进肠及肾小管吸收 $\mathrm{Ca}^{2+}$，从而使血钙升高。
:::

:::definition{label="血钙的稳定"}
在甲状旁腺激素和降钙素的共同调节下，机体维持血钙的稳定。升钙账在主细胞，降钙账在甲状腺滤泡旁细胞，不在甲状旁腺嗜酸性细胞。
:::

:::note{label="甲状旁腺激素升血钙的三条路"}
| 作用部位 | 效应 | 对血钙 |
|----------|------|--------|
| 骨细胞和破骨细胞 | 骨盐溶解 | 钙从骨入血 |
| 小肠 | 促进吸收 $\mathrm{Ca}^{2+}$ | 从食物补钙 |
| 肾小管 | 促进吸收 $\mathrm{Ca}^{2+}$ | 减少尿钙丢失 |
:::

:::insight{label="血钙稳定是一对反向激素，不是甲状旁腺自己和自己对打"}
主细胞把血钙抬上去，甲状腺滤泡旁细胞用降钙素把血钙按下来。两枚细胞不在同一个腺体里：一个在甲状旁腺索团中，一个在甲状腺滤泡之间或上皮之间。考试若问“降钙素来自甲状旁腺嗜酸性细胞”，就是把腺体、细胞、激素三本账同时写错。
:::

:::pitfall{label="主细胞升血钙，不要写成降钙素或醛固酮的作用"}
降钙素促成骨、抑制肠管和肾小管吸钙，方向与 PTH 相反。醛固酮管的是 $\mathrm{Na}^{+}$、$\mathrm{K}^{+}$ 和血容量，不是血钙。把 PTH 听成“保钙的盐皮质激素”，肾上腺球状带和甲状旁腺会并成一叶。
:::

## 2. 嗜酸性细胞

嗜酸性细胞（oxyphil cell）从青春期开始出现于甲状旁腺内，并随年龄增长而增多。细胞单个或成群存在于主细胞之间。嗜酸性细胞比主细胞大，核较小，染色深，细胞质呈强嗜酸性染色；电镜下，其细胞质含丰富的线粒体。此细胞的功能不明。

:::definition{label="嗜酸性细胞"}
嗜酸性细胞（oxyphil cell）从青春期开始出现于甲状旁腺，并随年龄增长而增多。单个或成群存在于主细胞之间。比主细胞大，核较小、染色深，胞质强嗜酸性；电镜下含丰富线粒体。功能不明。
:::

:::compare{title="主细胞与嗜酸性细胞"}
| 项目 | 主细胞 | 嗜酸性细胞 |
|------|--------|------------|
| 英文 | chief cell | oxyphil cell |
| 数量 | 最多 | 青春期后出现，随年龄增多 |
| 大小 | 较小 | 比主细胞大 |
| 核 | 圆，居中 | 较小，染色深 |
| HE 胞质 | 着色浅 | 强嗜酸性 |
| 电镜 | 含氮激素分泌细胞结构 | 丰富线粒体 |
| 功能 | 分泌甲状旁腺激素，升血钙 | 不明 |
:::

:::pitfall{label="嗜酸性细胞功能不明，不要把它写成分泌甲状旁腺激素或降钙素"}
升血钙的只有主细胞。嗜酸性细胞大、红、线粒体多，从青春期才登场，教材明确写功能不明。腺垂体远侧部也有嗜酸性细胞，那是生长激素细胞和催乳激素细胞，和甲状旁腺这一种同名不同腺。看见“嗜酸性”先问在哪个器官。
:::

:::compare{title="升血钙与降血钙"}
| 项目 | 甲状旁腺激素 | 降钙素 |
|------|--------------|--------|
| 细胞 | 甲状旁腺主细胞 | 甲状腺滤泡旁细胞 |
| 骨 | 作用于骨细胞和破骨细胞，骨盐溶解 | 促成骨细胞活动，骨盐沉着于类骨质 |
| 肠、肾小管 $\mathrm{Ca}^{2+}$ | 促进吸收 | 抑制吸收 |
| 血钙 | 升高 | 降低 |
| 共同意义 | 二者共同调节，维持血钙稳定 | 二者共同调节，维持血钙稳定 |
:::

:::keypoint{label="甲状旁腺先立主细胞升钙，再立功能不明的嗜酸性细胞"}
- 上下两对，贴在甲状腺左右叶背面；实质索团状，有孔毛细血管，散在脂肪细胞。
- 主细胞数量最多，浅染，分泌甲状旁腺激素：溶骨 + 促肠和肾小管吸钙 → 升血钙。
- 与甲状腺降钙素对打，维持血钙稳定。
- 嗜酸性细胞青春期后出现，大、核深、强嗜酸、线粒体丰富，功能不明。
:::
