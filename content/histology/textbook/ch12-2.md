# 二、耳

耳由外耳、中耳和内耳组成，前两者传导声波，后者感受听觉和身体位置。本节先把传音的外耳、中耳摊开，再把骨迷路与膜迷路、内淋巴与外淋巴立住，最后按耳蜗螺旋器、前庭位觉斑、半规管壶腹嵴三套感受器写开。

:::definition{label="耳"}
耳由外耳、中耳和内耳组成。外耳和中耳传导声波；内耳感受听觉和身体位置（位觉）。
:::

:::concept{term="先问声波还在传，还是已经变成毛细胞的兴奋"}
外耳道、鼓膜、听骨链把空气振动写成卵圆窗的运动，这一段没有感觉细胞。真正感音的是膜蜗管基底膜上的螺旋器；管直线变速和静止的是位觉斑，管旋转变速的是壶腹嵴。把“耳朵”听成只有耳郭，或把中耳听成感音器官，毛细胞那一本账会整段缺席。
:::

:::compare{title="外耳、中耳与内耳"}
| 项目 | 外耳 | 中耳 | 内耳 |
|------|------|------|------|
| 组成 | 耳郭、外耳道、鼓膜 | 鼓室、咽鼓管、听小骨 | 骨迷路 + 膜迷路 |
| 职分 | 收集并传递声波至鼓膜 | 听骨链传至卵圆窗 | 听觉（螺旋器）与位觉（位觉斑、壶腹嵴） |
| 腔内 | 空气 | 空气（鼓室经咽鼓管通鼻咽） | 膜迷路内淋巴；膜迷路与骨迷路之间外淋巴 |
:::

## （一）外耳

外耳由耳郭、外耳道和鼓膜构成。耳郭以弹性软骨为支架，外包薄层皮肤。外耳道的皮肤内有耵聍腺，结构类似大汗腺，分泌耵聍。鼓膜（tympanic membrane）为椭圆形的半透明薄膜，分隔外耳道与中耳。鼓膜分 3 层，外层为复层扁平上皮，与外耳道的表皮连续；中层主要由胶原纤维束组成，与鼓膜的振动有关；内层为黏膜层，由单层扁平上皮和薄层疏松结缔组织构成。鼓膜的作用是将声波的振动传递到中耳。由于鼓膜极薄，易受外力冲击（如强噪声、击打、尖锐物刺入）而破裂。

:::definition{label="外耳"}
外耳由耳郭、外耳道和鼓膜构成。耳郭以弹性软骨为支架，外包薄层皮肤。
:::

:::definition{label="耵聍腺"}
耵聍腺位于外耳道皮肤内，结构类似大汗腺，分泌耵聍。
:::

:::definition{label="鼓膜"}
鼓膜（tympanic membrane）为椭圆形的半透明薄膜，分隔外耳道与中耳，将声波振动传递到中耳。分 3 层：外层复层扁平上皮，与外耳道表皮连续；中层主要由胶原纤维束组成，与振动有关；内层为黏膜层，由单层扁平上皮和薄层疏松结缔组织构成。极薄，易受强噪声、击打、尖锐物刺入等外力冲击而破裂。
:::

:::compare{title="鼓膜三层"}
| 层次 | 组织 | 连续关系 / 功能 |
|------|------|------------------|
| 外层 | 复层扁平上皮 | 与外耳道表皮连续 |
| 中层 | 主要由胶原纤维束组成 | 与鼓膜振动有关 |
| 内层 | 单层扁平上皮 + 薄层疏松结缔组织 | 鼓室黏膜侧 |
:::

:::pitfall{label="鼓膜中层是胶原纤维束，不要写成软骨或骨"}
耳郭的支架才是弹性软骨；鼓膜是三层薄膜，靠中层胶原纤维束振动。把鼓膜听成“一小块骨头”或“软骨片”，听骨链会从锤骨附着处开始错位。
:::

## （二）中耳

中耳包括鼓室和咽鼓管（图 12-16）。鼓室内表面和 3 块听小骨表面覆有薄层黏膜。听小骨彼此形成关节连结，关节面为透明软骨。咽鼓管近鼓室段的黏膜上皮为单层柱状，近鼻咽段为假复层纤毛柱状上皮，固有层内有混合腺。

:::definition{label="中耳"}
中耳包括鼓室和咽鼓管。鼓室内有 3 块听小骨，把鼓膜振动传至卵圆窗。
:::

:::definition{label="听小骨"}
3 块听小骨彼此以关节连结，关节面为透明软骨。鼓室内表面和听小骨表面覆有薄层黏膜。锤骨、砧骨、镫骨依次把鼓膜振动传到卵圆窗。
:::

:::definition{label="咽鼓管黏膜"}
咽鼓管近鼓室段黏膜上皮为单层柱状，近鼻咽段为假复层纤毛柱状上皮，固有层内有混合腺。它使鼓室与鼻咽相通，维持鼓膜两侧气压平衡。
:::

:::note{label="中耳黏膜上皮随部位改写"}
近鼓室要的是薄层衬里，上皮为单层柱状；近鼻咽要的是和呼吸道连续的清洁面，改成假复层纤毛柱状并带混合腺。不要把整条咽鼓管都写成假复层纤毛柱状。
:::

::figure{src="/images/histology/textbook/p0144_01.png" caption="图12-16 中耳和内耳模式图（↑示声波传导方向）。鼓膜振动经锤骨、砧骨、镫骨至卵圆窗，前庭阶外淋巴振动，经蜗孔至鼓室阶，圆窗缓冲；膜迷路含内淋巴，位觉斑与壶腹嵴标于前庭和半规管。" alt="中耳听骨链与内耳迷路：声波路径、内淋巴囊、蜗孔和螺旋器"}

## （三）内耳

内耳为一系列穿行于颞骨岩部内相互通连的弯曲管道，形同迷宫，故又称迷路，分骨迷路（osseous labyrinth）和膜迷路（membranous labyrinth）两部分。骨迷路由前至后分为耳蜗、前庭和半规管，它们依次连通，内壁上都衬以骨膜。膜迷路为悬系在骨迷路内封闭的膜性管或囊，基本形态与骨迷路相似，也相应地分为 3 部分，即膜蜗管、膜前庭和膜半规管，三者也相通，内壁衬以单层上皮。膜迷路某些部位的上皮增厚，特化形成感受器。

膜迷路的腔内充满内淋巴，内淋巴由膜蜗管的血管纹产生，经内淋巴导管和内淋巴囊导入硬膜下隙。膜迷路与骨迷路之间的腔隙充满外淋巴，其成分与内淋巴不同，可能是蛛网膜下隙的脑脊液经蜗小管导入，也可能是从骨膜毛细血管渗出产生。内、外淋巴互不相通。淋巴有营养内耳和传递声波等作用。

:::definition{label="迷路"}
内耳穿行于颞骨岩部，为相互通连的弯曲管道，形同迷宫，故称迷路。分骨迷路和膜迷路两部分。
:::

:::definition{label="骨迷路"}
骨迷路（osseous labyrinth）由前至后分为耳蜗、前庭和半规管，依次连通，内壁衬以骨膜。
:::

:::definition{label="膜迷路"}
膜迷路（membranous labyrinth）是悬系在骨迷路内封闭的膜性管或囊，形态与骨迷路相似，分为膜蜗管、膜前庭和膜半规管，三者相通，内壁衬以单层上皮。某些部位上皮增厚，特化形成感受器。
:::

:::definition{label="内淋巴"}
内淋巴充满膜迷路腔。由膜蜗管的血管纹产生，经内淋巴导管和内淋巴囊导入硬膜下隙。
:::

:::definition{label="外淋巴"}
外淋巴充满膜迷路与骨迷路之间的腔隙，成分与内淋巴不同。可能是蛛网膜下隙的脑脊液经蜗小管导入，也可能从骨膜毛细血管渗出产生。内、外淋巴互不相通。淋巴有营养内耳和传递声波等作用。
:::

:::concept{term="先问这腔走内淋巴还是外淋巴，相不相通"}
膜迷路里面是内淋巴，血管纹产、内淋巴囊收。骨迷路与膜迷路之间是外淋巴，前庭阶和鼓室阶走的就是它。两套淋巴成分不同、互不相通。声波先振外淋巴，再通过前庭膜把振动交给内淋巴，螺旋器才兴奋。把两套淋巴写成“耳里的一种水”，蜗孔、圆窗和血管纹三本账都会并成一摊。
:::

:::compare{title="骨迷路与膜迷路"}
| 项目 | 骨迷路 | 膜迷路 |
|------|--------|--------|
| 英文 | osseous labyrinth | membranous labyrinth |
| 分部 | 耳蜗、前庭、半规管 | 膜蜗管、膜前庭（椭圆囊 + 球囊）、膜半规管 |
| 腔内液体 | 与膜迷路之间为外淋巴 | 内淋巴 |
| 内壁 | 骨膜 | 单层上皮；局部增厚成感受器 |
| 感受器 | 本身不是感受器 | 螺旋器、位觉斑、壶腹嵴 |
:::

:::compare{title="内淋巴与外淋巴"}
| 项目 | 内淋巴 | 外淋巴 |
|------|--------|--------|
| 位置 | 膜迷路腔内 | 膜迷路与骨迷路之间（前庭阶、鼓室阶等） |
| 来源 | 血管纹产生 | 可能为脑脊液经蜗小管导入，或骨膜毛细血管渗出 |
| 去路 | 内淋巴导管 → 内淋巴囊 → 硬膜下隙 | 与内淋巴不相通 |
| 作用 | 营养内耳；振动毛细胞纤毛 | 营养内耳；传递并增强声波振动 |
:::

:::pitfall{label="内、外淋巴互不相通，不要写成一个连通的水腔"}
蜗孔连通的是前庭阶和鼓室阶，两边都是外淋巴。膜蜗管是三角形盲管，里面才是内淋巴，只在底端与球囊相通。把蜗孔写成“内外淋巴的会合处”，高频低频那一本听弦账会先泡在错误的液体里。
:::

### 1. 耳蜗、膜蜗管及螺旋器

耳蜗（cochlea）外形如蜗牛壳，由中央圆锥形蜗轴和围绕蜗轴盘旋约两周半的蜗螺旋管（骨蜗管）及套嵌其内的膜蜗管构成（图 12-17～图 12-19）。蜗轴由松质骨构成，内有耳蜗神经节。

:::definition{label="耳蜗"}
耳蜗（cochlea）外形如蜗牛壳，由中央圆锥形蜗轴、围绕蜗轴盘旋约两周半的蜗螺旋管（骨蜗管）及套嵌其内的膜蜗管构成。
:::

:::definition{label="蜗轴"}
蜗轴是耳蜗中央的圆锥形松质骨，内有耳蜗神经节。骨螺旋板由蜗轴骨组织向外延伸而成。
:::

**（1）骨蜗管** 被膜蜗管分隔为上下两部分，上部为前庭阶（scala vestibuli），起始于卵圆窗；下部为鼓室阶（scala tympani），起自圆窗；二者均含外淋巴，并在蜗顶以蜗孔相通。

:::definition{label="前庭阶"}
前庭阶（scala vestibuli）是骨蜗管被膜蜗管分隔后的上部，起始于卵圆窗，含外淋巴，在蜗顶经蜗孔与鼓室阶相通。
:::

:::definition{label="鼓室阶"}
鼓室阶（scala tympani）是骨蜗管被膜蜗管分隔后的下部，起自圆窗，含外淋巴，在蜗顶经蜗孔与前庭阶相通。
:::

:::definition{label="蜗孔"}
蜗孔位于蜗顶，是前庭阶与鼓室阶外淋巴相通之处。
:::

:::compare{title="前庭阶、膜蜗管与鼓室阶"}
| 项目 | 前庭阶 | 膜蜗管 | 鼓室阶 |
|------|--------|--------|--------|
| 位置 | 骨蜗管上部 | 套嵌其中的三角形膜管 | 骨蜗管下部 |
| 起点 / 终点 | 起始于卵圆窗 | 底端通球囊，顶部细小止于蜗顶，为盲端 | 起自圆窗 |
| 淋巴 | 外淋巴 | 内淋巴 | 外淋巴 |
| 蜗顶 | 经蜗孔与鼓室阶相通 | 盲端，不经蜗孔开口 | 经蜗孔与前庭阶相通 |
:::

::figure{src="/images/histology/textbook/p0144_02.png" caption="图12-17 豚鼠耳蜗纵切面光镜图。↑ 蜗轴；1. 前庭阶；2. 膜蜗管；3. 鼓室阶；4. 耳蜗神经节。示盘旋约两周半的蜗螺旋管。" alt="耳蜗纵切：中央蜗轴与耳蜗神经节，周围交替出现前庭阶、膜蜗管和鼓室阶"}

::figure{src="/images/histology/textbook/p0144_03.png" caption="图12-18 耳蜗顶部光镜图。* 蜗孔；1. 前庭阶；2. 膜蜗管；3. 鼓室阶；4. 耳蜗神经节。" alt="蜗顶切面：蜗孔连通前庭阶与鼓室阶，膜蜗管仍为独立三角腔"}

**（2）膜蜗管** 为螺旋形膜性管道，其底端与球囊相通，顶部细小，止于蜗顶，为盲端。膜蜗管横切面呈三角形，有 3 个壁。

上壁为菲薄的前庭膜（vestibular membrane），由两层单层扁平上皮夹一层基板组成，前庭膜呈外高内低的斜行走向。

外侧壁上皮为特殊的含毛细血管的复层上皮，称血管纹（stria vascularis），可产生内淋巴。上皮下方为增厚的骨膜，称螺旋韧带（spiral ligament）。

下壁由内侧的骨螺旋板（osseous spiral lamina）和外侧的膜螺旋板（membranous spiral lamina）共同构成。骨螺旋板是蜗轴的骨组织向外延伸形成的螺旋形薄板。膜螺旋板（也称基底膜）内侧与骨螺旋板相连，外侧与螺旋韧带相连，由两层上皮夹一层基膜构成。朝向膜蜗管的上皮为单层柱状，并局部膨隆形成螺旋器。朝向鼓室阶的上皮为单层扁平上皮。骨螺旋板起始处的骨膜增厚，突入膜蜗管形成螺旋缘（spiral limbus），并向膜蜗管中伸出一末端游离的薄板状胶质性盖膜（tectorial membrane），覆盖于螺旋器上（图 12-19～图 12-21）。

:::definition{label="膜蜗管"}
膜蜗管是螺旋形膜性管道，底端与球囊相通，顶部细小止于蜗顶，为盲端。横切面呈三角形，有上壁（前庭膜）、外侧壁（血管纹 + 螺旋韧带）和下壁（骨螺旋板 + 膜螺旋板）。
:::

:::definition{label="前庭膜"}
前庭膜（vestibular membrane）是膜蜗管上壁，菲薄，由两层单层扁平上皮夹一层基板组成，呈外高内低的斜行走向。它把前庭阶外淋巴与膜蜗管内淋巴隔开。
:::

:::definition{label="血管纹"}
血管纹（stria vascularis）是膜蜗管外侧壁特殊的含毛细血管的复层上皮，可产生内淋巴。
:::

:::definition{label="螺旋韧带"}
螺旋韧带（spiral ligament）是血管纹上皮下方增厚的骨膜，并与膜螺旋板外侧相连。
:::

:::definition{label="骨螺旋板"}
骨螺旋板（osseous spiral lamina）是蜗轴骨组织向外延伸形成的螺旋形薄板，构成膜蜗管下壁的内侧份。
:::

:::definition{label="膜螺旋板"}
膜螺旋板（membranous spiral lamina）也称基底膜，内侧连骨螺旋板，外侧连螺旋韧带，由两层上皮夹一层基膜构成。朝向膜蜗管的上皮为单层柱状，局部膨隆形成螺旋器；朝向鼓室阶的上皮为单层扁平。
:::

:::definition{label="螺旋缘"}
螺旋缘（spiral limbus）是骨螺旋板起始处骨膜增厚并突入膜蜗管形成的结构，向膜蜗管中伸出盖膜。
:::

:::definition{label="盖膜"}
盖膜（tectorial membrane）是螺旋缘伸出的末端游离的薄板状胶质性结构，覆盖于螺旋器上。外毛细胞中较长的静纤毛插入盖膜的胶质中。
:::

::figure{src="/images/histology/textbook/p0145_01.png" caption="图12-19 膜蜗管与螺旋器模式图。三角形管腔：上壁前庭膜，外侧壁血管纹与螺旋韧带，下壁骨螺旋板与膜螺旋板；盖膜覆盖螺旋器，耳蜗神经节纤维自骨螺旋板进入。" alt="膜蜗管三角腔模式：前庭膜、血管纹、螺旋器、盖膜和骨螺旋板"}

::figure{src="/images/histology/textbook/p0145_02.png" caption="图12-20 膜蜗管与螺旋器光镜图。示螺旋韧带、血管纹、前庭膜、盖膜、螺旋器和耳蜗神经节。" alt="膜蜗管光镜：外侧血管纹，底壁螺旋器与盖膜，蜗轴侧耳蜗神经节"}

**（3）螺旋器** 螺旋器（spiral organ）又称科蒂器（organ of Corti），是基底膜上感受听觉的高度分化结构，呈螺旋状走行，由支持细胞和毛细胞组成（图 12-22）。

:::definition{label="螺旋器"}
螺旋器（spiral organ）又称科蒂器（organ of Corti），是基底膜上感受听觉的高度分化结构，呈螺旋状走行，由支持细胞和毛细胞组成。
:::

**1）支持细胞** 主要有柱细胞（pillar cell）和指细胞（phalangeal cell）。柱细胞基部较宽，中部细长，排列为内、外两行，分别称内柱细胞和外柱细胞。内、外柱细胞在基底部和顶部彼此连接，中部分离，围成 1 条三角形的内隧道（inner tunnel）。内柱细胞内侧有 1 列内指细胞，外柱细胞外侧有 $3\sim 4$ 列外指细胞。指细胞呈杯状，顶部凹陷内托着 1 个毛细胞，一侧伸出 1 个指状突起抵达螺旋器的游离面，扩展形成薄板状结构，并与邻近的指细胞和柱细胞等形成的薄板连接。支持细胞的细胞质富含张力丝，对稳定螺旋器的结构、固定毛细胞的位置具有很强的支持作用。

:::definition{label="柱细胞"}
柱细胞（pillar cell）基部较宽、中部细长，分内柱细胞和外柱细胞两行。内、外柱细胞在基底部和顶部彼此连接，中部分离，围成三角形的内隧道。
:::

:::definition{label="内隧道"}
内隧道（inner tunnel）是内、外柱细胞中部分离围成的三角形隧道，是光镜下辨认螺旋器的标志之一。
:::

:::definition{label="指细胞"}
指细胞（phalangeal cell）呈杯状。内柱细胞内侧有 1 列内指细胞，外柱细胞外侧有 $3\sim 4$ 列外指细胞。顶部凹陷托着 1 个毛细胞；一侧伸出指状突起至游离面，扩展成薄板，与邻近指细胞和柱细胞的薄板连接。
:::

:::note{label="支持细胞靠张力丝把毛细胞按在座位上"}
柱细胞围内隧道，指细胞一杯一个毛细胞。胞质富含张力丝，稳定螺旋器、固定毛细胞位置。毛细胞自己不“站”在基底膜上，是坐在指细胞顶部凹陷里。
:::

**2）毛细胞** 是感受听觉刺激的上皮细胞，坐落于指细胞顶部的凹陷内，故相应地分为 1 列内毛细胞（inner hair cell）和 $3\sim 4$ 列外毛细胞（outer hair cell）。内毛细胞呈烧瓶形，外毛细胞呈高柱状。细胞游离面有数十至上百根粗而长的微绒毛，称静纤毛（stereocilium）。内毛细胞的静纤毛有 $3\sim 4$ 行，总体上呈 U 形或弧形排列。外毛细胞的静纤毛为 $3\sim 5$ 行，呈 V 形或 W 形排列。静纤毛的排列也呈阶梯状，外侧的静纤毛较内侧的逐排增高（图 12-23），外毛细胞中较长的静纤毛插入盖膜的胶质中。毛细胞底部细胞质内有含神经递质的突触小泡，底部与来自耳蜗神经节的双极神经元的树突末端形成突触。

:::definition{label="毛细胞（螺旋器）"}
螺旋器毛细胞是感受听觉刺激的上皮细胞，坐落于指细胞顶部凹陷内。分 1 列内毛细胞和 $3\sim 4$ 列外毛细胞。游离面有数十至上百根静纤毛；底部含突触小泡，与耳蜗神经节双极神经元的树突末端形成突触。
:::

:::definition{label="内毛细胞"}
内毛细胞（inner hair cell）1 列，呈烧瓶形。静纤毛 $3\sim 4$ 行，总体上呈 U 形或弧形排列。
:::

:::definition{label="外毛细胞"}
外毛细胞（outer hair cell）$3\sim 4$ 列，呈高柱状。静纤毛 $3\sim 5$ 行，呈 V 形或 W 形排列；较长的静纤毛插入盖膜胶质中。
:::

:::definition{label="静纤毛"}
静纤毛（stereocilium）是毛细胞游离面粗而长的微绒毛，数十至上百根，呈阶梯状排列，外侧较内侧逐排增高。听觉刺激使静纤毛因与盖膜的位置变化而弯曲和伸直。
:::

:::compare{title="内毛细胞与外毛细胞"}
| 项目 | 内毛细胞 | 外毛细胞 |
|------|----------|----------|
| 列数 | 1 列 | $3\sim 4$ 列 |
| 外形 | 烧瓶形 | 高柱状 |
| 静纤毛 | $3\sim 4$ 行，总体 U 形或弧形 | $3\sim 5$ 行，V 形或 W 形 |
| 与盖膜 | — | 较长的静纤毛插入盖膜胶质 |
| 支持 | 坐在 1 列内指细胞顶部 | 坐在 $3\sim 4$ 列外指细胞顶部 |
:::

:::pitfall{label="静纤毛是特化微绒毛，不要写成能摆动的动纤毛"}
螺旋器毛细胞游离面写的是静纤毛。位觉斑和壶腹嵴才是静纤毛加 1 根动纤毛一起插入胶质膜。把螺旋器也写成“有动纤毛”，听觉感受器和位觉感受器会并成一种细胞。
:::

::figure{src="/images/histology/textbook/p0146_03.png" caption="图12-21 螺旋器光镜图。* 内隧道。示内、外柱细胞围成的三角形隧道及两侧毛细胞和支持细胞。" alt="螺旋器光镜：内隧道星标，盖膜覆盖毛细胞游离面"}

::figure{src="/images/histology/textbook/p0146_02.png" caption="图12-22 螺旋器毛细胞与支持细胞模式图。内毛细胞与内指细胞在内柱细胞内侧，外毛细胞与外指细胞在外柱细胞外侧，内隧道居中；底部神经纤维与毛细胞形成突触。" alt="螺旋器模式：内隧道两侧内、外毛细胞，指细胞托持，神经纤维入突触"}

基底膜的基膜中含有大量胶原样细丝束，称听弦（auditory string），从内向外呈放射状排列。从蜗底至蜗顶，基底膜由窄变宽，听弦由短变长，故蜗底的基底膜能与高频振动发生共振，蜗顶的基底膜能与低频振动发生共振。因此，蜗底受损可导致高音感受障碍，蜗顶受损则低音感受障碍。

螺旋器是听觉感受器，由外耳道传入的声波使鼓膜振动，经听骨链传至卵圆窗，引起前庭阶外淋巴振动，前庭膜随外淋巴一起振动，继而使膜蜗管的内淋巴发生振动，导致基底膜振动。前庭阶外淋巴的振动也经蜗孔传到鼓室阶，鼓室阶外淋巴的振动也对基底膜的振动有增强效应。基底膜振动也将带动螺旋器振动，这就使得毛细胞的静纤毛因与盖膜的位置变化而不断弯曲和伸直，从而引起毛细胞兴奋，信息经毛细胞底部的突触而传递给耳蜗神经，借此传至中枢，产生听觉。

:::definition{label="听弦"}
听弦（auditory string）是基底膜基膜中大量胶原样细丝束，从内向外呈放射状排列。从蜗底至蜗顶，基底膜由窄变宽，听弦由短变长：蜗底与高频共振，蜗顶与低频共振。蜗底受损导致高音感受障碍，蜗顶受损则低音感受障碍。
:::

:::definition{label="声波传导"}
声波路径：外耳道 → 鼓膜振动 → 听骨链 → 卵圆窗 → 前庭阶外淋巴振动 → 前庭膜振动 → 膜蜗管内淋巴振动 → 基底膜振动（鼓室阶外淋巴经蜗孔传来，增强基底膜振动）→ 螺旋器振动 → 静纤毛相对盖膜弯曲伸直 → 毛细胞兴奋 → 底部突触 → 耳蜗神经 → 中枢，产生听觉。
:::

:::note{label="声波传到毛细胞的顺序"}
| 顺序 | 环节 | 液体 / 结构 |
|------|------|-------------|
| ① | 外耳道 → 鼓膜 | 空气 |
| ② | 听骨链 → 卵圆窗 | 中耳气腔 |
| ③ | 前庭阶外淋巴振动 | 外淋巴 |
| ④ | 前庭膜 → 膜蜗管内淋巴 | 内淋巴 |
| ⑤ | 基底膜 + 鼓室阶外淋巴增强 | 外淋巴经蜗孔 |
| ⑥ | 静纤毛相对盖膜弯曲 | 螺旋器 |
| ⑦ | 突触 → 耳蜗神经节双极神经元 | 耳蜗神经 |
:::

:::insight{label="频率写在基底膜的宽窄上，不写在毛细胞种类上"}
内毛细胞、外毛细胞的差别是列数、形态和与盖膜的关系。高音低音不靠“两种毛细胞”，靠的是蜗底窄而短的听弦对高频、蜗顶宽而长的听弦对低频。损伤部位决定丢掉哪一段音阶。
:::

:::pitfall{label="蜗底是高音，蜗顶是低音，不要记反"}
基底膜从蜗底到蜗顶由窄变宽，听弦由短变长。窄短共振高频，宽长共振低频。把“蜗牛尖（蜗顶）”写成高音区，临床定位会反号。
:::

### 2. 前庭、膜前庭及位觉斑

前庭为一膨大的腔，连接半规管和耳蜗（见图 12-16）。膜前庭由椭圆囊和球囊组成。椭圆囊底壁和球囊前壁的骨膜和上皮局部增厚，呈斑块状，分别称椭圆囊斑（macula utriculi）和球囊斑（macula sacculi），均为位觉感受器，故又统称位觉斑（macula acoustica）。椭圆囊斑位于椭圆囊的底壁，其长轴呈水平位；球囊斑位于球囊的前壁，其长轴为垂直位，故两斑呈相互垂直关系。

位觉斑表面平坦，上皮为高柱状，由支持细胞和毛细胞组成（图 12-24，图 12-25）。支持细胞分泌胶状糖蛋白，在位觉斑表面形成胶质膜，称耳石膜（otolithic membrane），内有细小的碳酸钙结晶，即耳石。

毛细胞位于支持细胞之间，细胞顶部有 $40\sim 80$ 根静纤毛和 1 根动纤毛（kinocilium），皆插入耳石膜。静纤毛呈阶梯状排列，最长的静纤毛一侧为动纤毛。毛细胞基底面与传入神经末梢形成突触联系。毛细胞分为Ⅰ型和Ⅱ型。Ⅰ型细胞呈烧瓶状，细胞的绝大部分被前庭神经末梢包裹，仅露出细胞顶部。神经末梢形似酒杯，故称神经杯，与毛细胞形成突触。Ⅱ型细胞为长圆柱状，细胞基部和多个前庭神经末梢有突触联系，但不形成神经杯（图 12-26）。

位觉斑感受身体的直线变速运动和静止状态。由于耳石的比重远大于内淋巴，在直线变速运动或重力作用下，耳石膜与毛细胞胞体的位置发生相对移位，从而使纤毛弯曲，毛细胞兴奋，并将兴奋通过突触传递给传入神经末梢。由于球囊斑和椭圆囊斑互成直角，所以不管身体处在何种位置，都会有毛细胞受到刺激。

:::definition{label="前庭"}
前庭是骨迷路中膨大的腔，连接半规管和耳蜗。
:::

:::definition{label="膜前庭"}
膜前庭由椭圆囊和球囊组成，套嵌于骨性前庭内，腔内为内淋巴。
:::

:::definition{label="位觉斑"}
位觉斑（macula acoustica）是椭圆囊斑（macula utriculi）和球囊斑（macula sacculi）的统称，均为位觉感受器。椭圆囊斑在椭圆囊底壁，长轴水平；球囊斑在球囊前壁，长轴垂直；两斑相互垂直。
:::

:::definition{label="耳石膜"}
耳石膜（otolithic membrane）是位觉斑支持细胞分泌的胶状糖蛋白在表面形成的胶质膜，内有细小碳酸钙结晶，即耳石。耳石比重大于内淋巴。
:::

:::definition{label="位觉斑毛细胞"}
位觉斑毛细胞位于支持细胞之间，顶部有 $40\sim 80$ 根静纤毛和 1 根动纤毛，皆插入耳石膜。静纤毛阶梯状排列，最长静纤毛一侧为动纤毛。基底面与传入神经末梢形成突触。
:::

:::definition{label="Ⅰ型毛细胞"}
Ⅰ型毛细胞呈烧瓶状，绝大部分被前庭神经末梢包裹，仅露出顶部。神经末梢形似酒杯，称神经杯，与毛细胞形成突触。
:::

:::definition{label="Ⅱ型毛细胞"}
Ⅱ型毛细胞为长圆柱状，细胞基部与多个前庭神经末梢有突触联系，但不形成神经杯。
:::

:::definition{label="位觉斑的适宜刺激"}
位觉斑感受身体的直线变速运动和静止状态。耳石膜与毛细胞胞体相对移位 → 纤毛弯曲 → 毛细胞兴奋 → 突触传给传入神经。两斑互成直角，故身体处于何种位置都有毛细胞受刺激。
:::

:::concept{term="先问这一斑的长轴水平还是垂直，再问它管直线还是管旋转"}
椭圆囊斑躺在底壁上，长轴水平；球囊斑贴在前壁上，长轴垂直。它们读的是直线变速和重力，靠耳石比内淋巴重。旋转不归位觉斑管，那是半规管壶腹嵴和壶腹帽的账。把耳石写成半规管里的结构，直线和旋转会并成一种运动。
:::

:::compare{title="Ⅰ型与Ⅱ型毛细胞"}
| 项目 | Ⅰ型 | Ⅱ型 |
|------|-----|-----|
| 外形 | 烧瓶状 | 长圆柱状 |
| 神经末梢 | 绝大部分被前庭神经末梢包裹，形成神经杯 | 基部与多个前庭神经末梢突触，无神经杯 |
| 纤毛 | 静纤毛 + 1 根动纤毛，插入胶质膜 | 同左 |
| 分布 | 位觉斑和壶腹嵴均有 | 同左 |
:::

:::pitfall{label="耳石只在位觉斑，不要写进壶腹帽"}
位觉斑表面的胶质膜叫耳石膜，里面嵌着碳酸钙结晶。壶腹嵴的胶质结构叫壶腹帽，圆锥形，教材没有写耳石。把耳石搬进半规管，旋转感受器会多出一块不该有的石头。
:::

### 3. 半规管、膜半规管及壶腹嵴

半规管位于内耳的后外侧，为 3 个相互垂直的半环形骨管，每个半规管与前庭相连处各形成一个膨大的壶腹。相应的膜半规管及其壶腹套嵌其内。膜性壶腹部骨膜和上皮局部增厚，形成横行的山嵴状隆起，称壶腹嵴（crista ampullaris）（图 12-27，图 12-28）。

壶腹嵴上皮也由支持细胞和毛细胞组成，毛细胞也分Ⅰ型和Ⅱ型，其动纤毛和静纤毛的数量和排列情况与位觉斑类似。支持细胞分泌的糖蛋白形成圆锥形的胶质壶腹帽（cupula），动纤毛和静纤毛插入壶腹帽基部。前庭神经中的传入纤维末梢分布于毛细胞的基部。壶腹嵴也是位觉感受器，感受身体或头部的旋转变速运动。由于 3 个半规管互相垂直排列，所以不管人的身体或头部在何方向旋转，都会有半规管内淋巴流动使壶腹帽倾斜，从而刺激毛细胞产生兴奋，经前庭神经传入中枢。

:::definition{label="半规管"}
半规管位于内耳后外侧，为 3 个相互垂直的半环形骨管。每个半规管与前庭相连处形成一个膨大的壶腹。膜半规管及其壶腹套嵌其内。
:::

:::definition{label="壶腹嵴"}
壶腹嵴（crista ampullaris）是膜性壶腹部骨膜和上皮局部增厚形成的横行山嵴状隆起，为感受旋转变速运动的位觉感受器。
:::

:::definition{label="壶腹帽"}
壶腹帽（cupula）是壶腹嵴支持细胞分泌的糖蛋白形成的圆锥形胶质结构。毛细胞的动纤毛和静纤毛插入其基部。半规管内淋巴流动使壶腹帽倾斜，刺激毛细胞。
:::

:::definition{label="壶腹嵴的适宜刺激"}
壶腹嵴感受身体或头部的旋转变速运动。3 个半规管互相垂直，故无论何方向旋转，都有半规管内淋巴流动使壶腹帽倾斜，毛细胞兴奋，经前庭神经传入中枢。
:::

:::compare{title="位觉斑与壶腹嵴"}
| 项目 | 位觉斑 | 壶腹嵴 |
|------|--------|--------|
| 位置 | 椭圆囊底壁、球囊前壁 | 膜半规管壶腹部 |
| 外形 | 表面平坦的斑块 | 横行山嵴状隆起 |
| 胶质结构 | 耳石膜，内含耳石（碳酸钙结晶） | 圆锥形壶腹帽，无耳石 |
| 毛细胞 | 支持细胞之间；Ⅰ型、Ⅱ型；静纤毛 + 1 根动纤毛 | 同样 |
| 纤毛插入 | 耳石膜 | 壶腹帽基部 |
| 适宜刺激 | 直线变速运动和静止（重力） | 身体或头部旋转变速运动 |
| 空间配置 | 两斑互相垂直 | 3 个半规管互相垂直 |
:::

:::insight{label="三套感受器共用毛细胞，靠胶质膜的种类区分刺激"}
螺旋器：静纤毛对盖膜，读基底膜振动，是听觉。位觉斑：静纤毛加动纤毛对耳石膜，读直线和重力。壶腹嵴：同样的纤毛对壶腹帽，读旋转。细胞都叫毛细胞，考试问的是盖在上面的那一层胶质叫什么、里面有没有耳石。
:::

:::pitfall{label="三个半规管互相垂直，不是三个平行的圆环"}
只有互相垂直，才能覆盖任意方向的旋转。写成“三个平行半规管”，会有一整面转动盲区。位觉斑的两斑互成直角，是同一逻辑写在直线和重力上。
:::

:::keypoint{label="耳先立外中内三部，内耳再立螺旋器、位觉斑和壶腹嵴"}
- 外耳（耳郭、外耳道、鼓膜）和中耳（鼓室、听小骨、咽鼓管）传导声波；内耳感受听觉和位觉。
- 骨迷路 = 耳蜗 + 前庭 + 半规管；膜迷路 = 膜蜗管 + 膜前庭（椭圆囊、球囊）+ 膜半规管。内淋巴在膜内（血管纹产），外淋巴在两迷路之间，互不相通。
- 膜蜗管三角形：前庭膜、血管纹、基底膜（骨螺旋板 + 膜螺旋板）；盖膜覆盖螺旋器。
- 螺旋器：内 1 列烧瓶形毛细胞 + 外 $3\sim 4$ 列高柱状毛细胞；柱细胞围内隧道；蜗底高频、蜗顶低频。
- 声波：鼓膜 → 听骨链 → 卵圆窗 → 前庭阶外淋巴 → 内淋巴 → 基底膜 → 静纤毛相对盖膜弯曲 → 耳蜗神经。
- 位觉斑（耳石膜）管直线变速和静止；壶腹嵴（壶腹帽）管旋转变速；毛细胞均分Ⅰ型（神经杯）和Ⅱ型。
:::

:::memory{label="本节必背要点"}
- [ ] 耳由外耳、中耳和内耳组成；前两者传导声波，后者感受听觉和身体位置。
- [ ] 外耳由耳郭、外耳道和鼓膜构成。耳郭以弹性软骨为支架，外包薄层皮肤。
- [ ] 外耳道皮肤内有耵聍腺，结构类似大汗腺，分泌耵聍。
- [ ] 鼓膜为椭圆形半透明薄膜，分隔外耳道与中耳，将声波振动传至中耳；极薄，易破裂。
- [ ] 鼓膜 3 层：外层复层扁平上皮（与外耳道表皮连续）；中层胶原纤维束（与振动有关）；内层黏膜（单层扁平上皮 + 薄层疏松结缔组织）。
- [ ] 中耳包括鼓室和咽鼓管；鼓室内表面和 3 块听小骨表面覆薄层黏膜。
- [ ] 听小骨彼此关节连结，关节面为透明软骨。
- [ ] 咽鼓管近鼓室段上皮为单层柱状，近鼻咽段为假复层纤毛柱状上皮，固有层有混合腺。
- [ ] 内耳又称迷路，分骨迷路和膜迷路，穿行于颞骨岩部。
- [ ] 骨迷路由前至后：耳蜗、前庭、半规管，依次连通，内壁衬骨膜。
- [ ] 膜迷路悬系在骨迷路内，分为膜蜗管、膜前庭、膜半规管，三者相通，内壁衬单层上皮；局部上皮增厚成感受器。
- [ ] 内淋巴在膜迷路腔内，由血管纹产生，经内淋巴导管和内淋巴囊导入硬膜下隙。
- [ ] 外淋巴在膜迷路与骨迷路之间；可能来自脑脊液经蜗小管，或骨膜毛细血管渗出；内、外淋巴互不相通。
- [ ] 淋巴有营养内耳和传递声波等作用。
- [ ] 耳蜗由蜗轴、盘旋约两周半的骨蜗管及套嵌的膜蜗管构成；蜗轴为松质骨，内有耳蜗神经节。
- [ ] 骨蜗管被膜蜗管分为前庭阶（上，起始于卵圆窗）和鼓室阶（下，起自圆窗），均含外淋巴，蜗顶以蜗孔相通。
- [ ] 膜蜗管底端通球囊，顶部为盲端；横切面呈三角形。
- [ ] 上壁前庭膜：两层单层扁平上皮夹一层基板，外高内低斜行。
- [ ] 外侧壁血管纹为含毛细血管的复层上皮，产生内淋巴；下方增厚骨膜为螺旋韧带。
- [ ] 下壁 = 内侧骨螺旋板 + 外侧膜螺旋板（基底膜）。膜螺旋板朝向膜蜗管的上皮为单层柱状，局部膨隆成螺旋器；朝向鼓室阶为单层扁平上皮。
- [ ] 螺旋缘为骨螺旋板起始处骨膜增厚突入膜蜗管；盖膜为末端游离的薄板状胶质，覆盖螺旋器。
- [ ] 螺旋器（科蒂器）是基底膜上的听觉感受器，由支持细胞和毛细胞组成。
- [ ] 内、外柱细胞基部与顶部相连、中部分离，围成三角形内隧道。
- [ ] 内指细胞 1 列，外指细胞 $3\sim 4$ 列；杯状顶部各托 1 个毛细胞；胞质富含张力丝。
- [ ] 内毛细胞 1 列、烧瓶形，静纤毛 $3\sim 4$ 行呈 U/弧形；外毛细胞 $3\sim 4$ 列、高柱状，静纤毛 $3\sim 5$ 行呈 V/W 形，较长者插入盖膜。
- [ ] 静纤毛为粗长微绒毛，阶梯状，外侧高于内侧；毛细胞底部与耳蜗神经节双极神经元树突形成突触。
- [ ] 听弦为基底膜中放射状胶原样细丝束；蜗底窄短对高频，蜗顶宽长对低频。
- [ ] 声波：鼓膜 → 听骨链 → 卵圆窗 → 前庭阶外淋巴 → 前庭膜 → 内淋巴 → 基底膜（鼓室阶增强）→ 静纤毛相对盖膜弯曲 → 耳蜗神经。
- [ ] 膜前庭 = 椭圆囊 + 球囊；椭圆囊斑在底壁（长轴水平），球囊斑在前壁（长轴垂直），统称位觉斑。
- [ ] 位觉斑上皮高柱状，支持细胞 + 毛细胞；耳石膜含碳酸钙耳石。
- [ ] 位觉斑毛细胞顶部 $40\sim 80$ 根静纤毛 + 1 根动纤毛，插入耳石膜；Ⅰ型烧瓶状有神经杯，Ⅱ型长圆柱状无神经杯。
- [ ] 位觉斑感受直线变速运动和静止；两斑互成直角，任何体位都有毛细胞受刺激。
- [ ] 半规管为 3 个互相垂直的半环形骨管，与前庭相连处成壶腹。
- [ ] 壶腹嵴为膜性壶腹骨膜和上皮增厚形成的横行山嵴；壶腹帽为圆锥形胶质，纤毛插入其基部。
- [ ] 壶腹嵴感受旋转变速运动；3 管垂直，故任意方向旋转都有内淋巴流动使壶腹帽倾斜。
:::

## 本章小结

眼为视觉器官，包括眼球和眼附属器。眼球由眼球壁和眼内容物组成。眼球壁从外至内依次分为纤维膜、血管膜和视网膜 3 层。纤维膜主要由致密结缔组织构成，前 $1/6$ 为角膜，后 $5/6$ 为巩膜，两者之间的过渡区为角膜缘。血管膜主要由富含血管和黑素细胞的疏松结缔组织构成。从前向后依次为虹膜基质、睫状体基质和脉络膜 3 部分。视网膜位于眼球壁最内层，分为盲部与视部，视部为感光部位，即通常所称的视网膜。视网膜分为色素上皮层、视细胞层、双极细胞层和节细胞层。色素上皮层为单层立方上皮，有吞噬、保护和营养等作用。视细胞层包含视杆细胞和视锥细胞，感受光线与颜色。眼内容物包括房水、晶状体和玻璃体，均无色透明，与角膜共同组成眼的屈光系统。

耳为听觉和平衡觉器官，包括外耳、中耳和内耳。外耳和中耳主要起传导声波的作用。内耳由骨迷路和膜迷路组成。骨迷路包括耳蜗、前庭和半规管，它们互相通连。膜迷路悬系在骨迷路内，形态与骨迷路相似，也分为膜蜗管、膜前庭（椭圆囊和球囊）和膜半规管，也互相通连。膜迷路衬以单层上皮，某些部位的骨膜和上皮增厚，特化形成听觉感受器或位觉感受器。膜迷路腔内充满内淋巴，膜迷路与骨迷路之间的腔隙充满外淋巴。声波和身体位置变化均可使淋巴产生振动，从而刺激感受器，感受听觉和位觉。

:::definition{label="本章结构通式"}
眼 = 眼球（壁 + 内容物）+ 附属器。壁外→内：纤维膜（角膜、巩膜、角膜缘）、血管膜（虹膜、睫状体、脉络膜）、视网膜（色素上皮 + 视杆/视锥 + 双极 + 节细胞）。内容物与角膜组成屈光系统。耳 = 外耳 + 中耳（传音）+ 内耳（骨迷路套膜迷路）。膜迷路上皮局部特化：螺旋器感音，位觉斑感直线与静止，壶腹嵴感旋转。
:::

:::compare{title="全章感受器速查"}
| 感受器 | 位置 | 上皮细胞 | 胶质覆盖 | 适宜刺激 |
|--------|------|----------|----------|----------|
| 视杆 / 视锥 | 视网膜视细胞层 | 感觉神经元，外节膜盘 | 色素上皮突起伸入外节之间 | 弱光 / 强光与颜色 |
| 中央凹 | 黄斑中央 | 仅视锥，一对一通路 | — | 最敏锐视觉 |
| 螺旋器 | 膜蜗管基底膜 | 内 1 列 + 外 $3\sim 4$ 列毛细胞 | 盖膜 | 声波（蜗底高频、蜗顶低频） |
| 位觉斑 | 椭圆囊底壁、球囊前壁 | Ⅰ型、Ⅱ型毛细胞 | 耳石膜（含耳石） | 直线变速、静止 |
| 壶腹嵴 | 膜半规管壶腹 | Ⅰ型、Ⅱ型毛细胞 | 壶腹帽（无耳石） | 旋转变速 |
:::

:::keypoint{label="全章把眼球三层、屈光循环和内耳三感受器收口"}
- 角膜五层透明；角膜缘干细胞补充角膜；小梁网–巩膜静脉窦回流房水。

- 视杆–夜盲，视锥–色盲；中央凹敏锐，视盘盲点。

- 内、外淋巴不相通；螺旋器感音，位觉斑管直线，壶腹嵴管旋转。
:::

## 插入框：白内障

白内障是眼球中晶状体由于各种原因发生混浊而导致视觉障碍的疾病，是主要的致盲性疾病，在老年人群中尤为常见。多种因素如老化、遗传、免疫与代谢异常、眼部外伤、中毒和辐射等，都能引起晶状体代谢紊乱，导致晶状体蛋白质变性而发生混浊。白内障的早期症状一般不明显，仅为轻度的视物模糊。随着晶状体混浊逐渐加重，可出现视力下降、对比敏感度下降、屈光改变、单眼复视或多视、色觉改变、眩光、视野缺损等症状。白内障的治疗有药物和手术两种途径，手术是目前最有效的方法，最常用的手术方法是白内障超声乳化吸除并人工晶体植入术。

作为眼科公益项目，光明工程·白内障复明项目自 2018 年 3 月启动实施以来，在农业农村部、国家卫生健康委员会的指导下，中国乡村发展志愿服务促进会与 1 000 多家医疗机构签订救治协议，基本保障了农村困难白内障患者可以就近得到规范化的手术诊疗服务。截至 2023 年 12 月底，项目已在全国 25 个省（自治区、直辖市）1 100 多家项目合作医院参与实施，累计筛查 3 300 多万人次，救治农村白内障患者 235 万余例，补助困难患者 56 万余例。

:::definition{label="白内障"}
白内障是晶状体由于各种原因发生混浊而导致视觉障碍的疾病，是主要的致盲性疾病，在老年人群中尤为常见。老化、遗传、免疫与代谢异常、眼部外伤、中毒和辐射等均可引起晶状体代谢紊乱，蛋白质变性而混浊。
:::

:::note{label="白内障的表现与治疗"}
| 项目 | 要点 |
|------|------|
| 早期 | 症状一般不明显，仅为轻度视物模糊 |
| 加重后 | 视力下降、对比敏感度下降、屈光改变、单眼复视或多视、色觉改变、眩光、视野缺损等 |
| 治疗 | 药物和手术两种途径；手术最有效 |
| 常用术式 | 白内障超声乳化吸除并人工晶体植入术 |
:::

:::pitfall{label="白内障是晶状体混浊，不要写成房水回流受阻"}
晶状体无血管，靠房水营养，蛋白一变性就丢透明度。眼压升高、视神经受损那一本是青光眼，阻塞点在小梁网–巩膜静脉窦。老年人可以同时有两病，病因必须分开写。
:::

:::
