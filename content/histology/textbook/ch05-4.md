# 四、淋巴

淋巴是在淋巴管系统内流动的液体，单向性地从毛细淋巴管流向淋巴导管，然后汇入大静脉。淋巴由淋巴液与淋巴细胞构成。淋巴液实际上是血浆在毛细血管动脉端的部分渗出液，蛋白含量低于血浆。当淋巴经淋巴管流过淋巴结时，便有淋巴细胞加入。如果淋巴结正处于活跃的免疫应答状态，便会有较多淋巴细胞和大量免疫球蛋白进入淋巴（见第 10 章）。此外，小肠淋巴管的淋巴中常含数量不定的乳糜微粒，它们是小肠上皮细胞将吸收的脂溶性物质与运载蛋白结合形成的（见第 14 章）。肝的淋巴内含大量由肝细胞合成的血浆蛋白。淋巴中偶见单核细胞、中性粒细胞等血细胞。

:::definition{label="淋巴"}
淋巴（lymph）是在淋巴管系统内流动的液体，由淋巴液与淋巴细胞构成。它单向地从毛细淋巴管流向淋巴导管，然后汇入大静脉，是血浆循环的旁路。
:::

:::definition{label="淋巴液"}
淋巴液实际上是血浆在毛细血管动脉端的部分渗出液，蛋白含量低于血浆。它与加入其中的淋巴细胞一起构成淋巴。
:::

:::definition{label="乳糜微粒（小肠淋巴）"}
小肠淋巴管的淋巴中常含数量不定的乳糜微粒。它们是小肠上皮细胞将吸收的脂溶性物质与运载蛋白结合形成的，使小肠淋巴的成分不同于一般淋巴。
:::

:::concept{term="先问淋巴是管道里的液体，还是一种白细胞"}
“淋巴”两个字在切片课和临床口语里最容易和淋巴细胞撞车。本节的淋巴是淋巴管里流动的液态组织：基质是低蛋白的渗出液，细胞主要是中途加入的淋巴细胞。淋巴细胞只是其中的细胞成分，不能反过来把整管液体叫成一种白细胞。看见“淋巴”，先问在问管道里的液体，还是在问那一种有核的免疫细胞。
:::

:::pitfall{label="淋巴不等于淋巴细胞"}
淋巴 = 淋巴液 + 淋巴细胞（偶见单核、中性粒等）。淋巴细胞是白细胞的一种，产生于骨髓、胸腺和外周淋巴器官。把“淋巴增多”听成“淋巴细胞增多”，或把血涂片上的小淋巴细胞叫做“淋巴”，都会把循环旁路和组织免疫两本账叠在一起。淋巴单向汇入大静脉；淋巴细胞可以再循环，但二者不是同一个名词。
:::

:::compare{title="血液与淋巴"}
| 项目 | 血液 | 淋巴 |
|------|------|------|
| 所在管道 | 心血管，循环往复 | 淋巴管系统，单向：毛细淋巴管 → 淋巴导管 → 大静脉 |
| 组成 | 血浆 + 红细胞、白细胞、血小板 | 淋巴液 + 淋巴细胞（偶见单核、中性粒等） |
| 基质来源 | 血浆本身 | 血浆在毛细血管动脉端的部分渗出液 |
| 蛋白含量 | 血浆蛋白较高（白蛋白、球蛋白、纤维蛋白原等） | 一般低于血浆；肝淋巴含大量肝细胞合成的血浆蛋白 |
| 有形成分 | 以红细胞容积为主（约 $45\%$） | 以淋巴细胞为主，几乎无红细胞和血小板 |
| 部位差异 | 全身外周血成分相对均一（血象可测） | 流经淋巴结时可加入淋巴细胞和免疫球蛋白；小肠淋巴含乳糜微粒 |
| 功能定位 | 气体运输、防御、止血、物质运输 | 回收组织液、转运淋巴细胞和免疫球蛋白、转运小肠脂质和肝源血浆蛋白 |
:::

:::cause-effect{title="组织液怎样写成淋巴再回到血液"}
- 因：血浆在毛细血管动脉端部分渗出，成为组织液（见第 3 章）；其中进入毛细淋巴管的部分成为淋巴液，蛋白含量低于血浆
- 因：淋巴单向经淋巴管、淋巴结流向淋巴导管，汇入大静脉
- 果：组织液的旁路回流完成，血浆循环不至于在组织间隙堆住
- 果：流经淋巴结时淋巴细胞（免疫应答活跃时还有大量免疫球蛋白）加入淋巴
- 附加：小肠淋巴加入乳糜微粒；肝淋巴加入大量肝源血浆蛋白
:::

:::insight{label="同一条淋巴，路过哪里成分就不一样"}
毛细淋巴管收进来的首先是低蛋白渗出液。路过淋巴结，细胞和抗体可以大量加入；路过小肠，出现乳糜微粒；路过肝，血浆蛋白变多。所以不能把“淋巴”写成一种固定配方的液体，它是血浆循环的旁路，配方随引流区域而变。偶见的单核细胞和中性粒细胞，只是搭车的血细胞，不是淋巴的主体。
:::

:::note{label="淋巴与后续章节的接口"}
淋巴结如何把淋巴细胞和免疫球蛋白送进淋巴，见第 10 章；小肠上皮如何把脂溶性物质做成乳糜微粒，见第 14 章。本节只把“淋巴是旁路液体、不等于淋巴细胞”这本账立住。
:::

:::keypoint{label="淋巴是旁路液体，主体细胞是中途加入的淋巴细胞"}
- 淋巴在淋巴管中单向流动，最终汇入大静脉，由淋巴液和淋巴细胞构成。
- 淋巴液是毛细血管动脉端的部分渗出液，蛋白含量低于血浆。
- 流经淋巴结可加入淋巴细胞和免疫球蛋白；小肠淋巴含乳糜微粒；肝淋巴含大量肝源血浆蛋白。
- 淋巴 ≠ 淋巴细胞；偶见单核、中性粒，不等于血液的有形成分谱。
:::
