# 六、神经末梢

第五节把神经纤维和神经的三层膜立住以后，周围神经纤维走到靶器官，终末改写成各种末梢装置。神经末梢是周围神经纤维的终末部分，它们遍布全身，形成各种末梢装置，按功能分为感觉神经末梢和运动神经末梢两大类。本节先问这是传入还是传出，再问有没有被囊、落在皮肤哪一层或肌内哪一段。

:::definition{label="神经末梢"}
神经末梢是周围神经纤维的终末部分，遍布全身，形成各种末梢装置。按功能分为感觉神经末梢和运动神经末梢两大类。
:::

:::concept{term="先问传入还是传出，再问有没有被囊"}
感觉末梢是假单极神经元周围突的末端，把刺激写成冲动送回中枢；运动末梢是运动神经元轴突在肌和腺体的终末，支配收缩或调节分泌。感觉侧再问：细支裸露（游离末梢），还是外包被囊（触觉小体、环层小体、肌梭）。把所有小体都听成“触觉”，或把肌梭写成运动终板，本体感觉和随意运动两本账会互换。
:::

:::compare{title="感觉神经末梢与运动神经末梢"}
| 项目 | 感觉神经末梢 | 运动神经末梢 |
|------|--------------|--------------|
| 来源 | 感觉神经元（假单极神经元）的周围突末端 | 运动神经元的轴突终末 |
| 功能 | 与周围组织构成感受器，把刺激转化为冲动传入中枢 | 支配肌细胞收缩，调节腺细胞分泌 |
| 分型 | 游离神经末梢、触觉小体、环层小体、肌梭等 | 躯体运动神经末梢（运动终板）、内脏运动神经末梢（膨体） |
| 常见结构变化 | 入小体或肌梭前常失去髓鞘 | 抵达骨骼肌时失去髓鞘，分支成葡萄状终末 |
:::

## （一）感觉神经末梢

感觉神经末梢（sensory nerve ending）是感觉神经元（假单极神经元）周围突的末端，它们通常和周围的其他组织共同构成感受器，把接收的内、外环境刺激转化为神经冲动，通过感觉神经纤维传至中枢，产生感觉。

:::definition{label="感觉神经末梢"}
感觉神经末梢（sensory nerve ending）是感觉神经元（假单极神经元）周围突的末端。通常与周围其他组织共同构成感受器，将内、外环境刺激转化为神经冲动，经感觉神经纤维传至中枢，产生感觉。
:::

:::definition{label="感受器"}
感受器由感觉神经末梢及其周围的其他组织共同构成，负责把物理或化学刺激改写成可传导的神经冲动。末梢本身不等于完整的感受器。
:::

### 1. 游离神经末梢

游离神经末梢（free nerve ending）由较细的有髓或无髓神经纤维的终末反复分支而成。其细支裸露，广泛分布在表皮、角膜和毛囊的上皮细胞之间，或分布在各型结缔组织内，如真皮、骨膜、脑膜、血管外膜、关节囊、肌腱、韧带、筋膜和牙髓等处，感受温度、应力和某些化学物质（如高浓度的 $\mathrm{H}^{+}$ 和 $\mathrm{K}^{+}$）的刺激，参与产生冷、热、轻触和痛的感觉（见图 7-6，图 7-26）。

:::definition{label="游离神经末梢"}
游离神经末梢（free nerve ending）由较细的有髓或无髓神经纤维终末反复分支而成，细支裸露。分布于表皮、角膜和毛囊的上皮细胞之间，以及真皮、骨膜、脑膜、血管外膜、关节囊、肌腱、韧带、筋膜和牙髓等结缔组织。感受温度、应力及高浓度 $\mathrm{H}^{+}$、$\mathrm{K}^{+}$ 等化学刺激，参与冷、热、轻触和痛觉。
:::

:::pitfall{label="游离末梢不是“没有神经”，而是终末细支脱掉了被囊和髓鞘"}
游离指细支裸露，不包被囊，不是这一片组织没有神经。较细的有髓或无髓纤维都可以形成游离末梢；有髓者在终末反复分支后同样把细支裸出来。痛、温度和轻触可以走这条账，不要把痛觉独占成唯一功能。
:::

### 2. 触觉小体

触觉小体（tactile corpuscle）分布在皮肤的真皮乳头处，以手指掌侧皮肤内最多，数量随年龄递减。触觉小体呈卵圆形，长轴与皮肤表面垂直，小体内有许多扁平横列的细胞，外包结缔组织被囊（图 7-27，图 7-28）。有髓神经纤维进入小体前失去髓鞘，然后盘绕在扁平细胞之间。触觉小体感受应力刺激，参与产生触觉。

:::definition{label="触觉小体"}
触觉小体（tactile corpuscle）位于皮肤真皮乳头，手指掌侧最多，数量随年龄递减。卵圆形，长轴与皮肤表面垂直；内有许多扁平横列的细胞，外包结缔组织被囊。有髓纤维入小体前失髓鞘，盘绕于扁平细胞之间。感受应力，参与产生触觉。
:::

### 3. 环层小体

环层小体（lamellar corpuscle）广泛分布在皮下组织、腹膜、肠系膜、韧带和关节囊等处。环层小体较大，呈圆形或卵圆形，中央有一条均质状的圆柱体，周围有许多层同心圆排列的扁平细胞。有髓神经纤维进入小体时失去髓鞘，裸露的轴突进入圆柱体内（图 7-27，图 7-29）。环层小体感受较强的应力，参与产生压觉和振动觉。

:::definition{label="环层小体"}
环层小体（lamellar corpuscle）较大，圆形或卵圆形，广泛分布于皮下组织、腹膜、肠系膜、韧带和关节囊等处。中央为均质状圆柱体，周围是多层同心圆排列的扁平细胞。有髓纤维入小体时失髓鞘，裸轴突进入圆柱体。感受较强应力，参与压觉和振动觉。
:::

:::compare{title="触觉小体与环层小体"}
| 项目 | 触觉小体 | 环层小体 |
|------|----------|----------|
| 英文 | tactile corpuscle | lamellar corpuscle |
| 主要部位 | 真皮乳头；手指掌侧最多 | 皮下组织、腹膜、肠系膜、韧带、关节囊 |
| 大小与外形 | 卵圆，长轴垂直于皮肤表面 | 较大，圆或卵圆 |
| 内部 | 许多扁平横列的细胞 | 中央均质圆柱体 + 外周多层同心圆扁平细胞 |
| 被囊 | 结缔组织被囊 | 同心圆细胞层本身构成板层被囊 |
| 纤维入内 | 入小体前失髓鞘，盘绕于扁平细胞之间 | 入小体时失髓鞘，裸轴突进入圆柱体 |
| 感觉 | 应力 → 触觉 | 较强应力 → 压觉、振动觉 |
| 年龄 | 数量随年龄递减 | 教材未强调随年龄递减 |
:::

:::pitfall{label="触觉小体在乳头层，环层小体在皮下等深层，不要按“都在皮肤”一笔带过"}
同一张皮肤切片：表皮与真皮交界的乳头里找卵圆、长轴垂直的触觉小体（图 7-28）；脂肪和深层结缔组织里找巨大同心圆的环层小体（图 7-29）。把环层小体画进真皮乳头，或把触觉小体写成压觉和振动觉，层次和功能会一起错。两者都是有被囊的感受器，入内前都失髓鞘，但盘绕扁平细胞与插入圆柱体不是同一件事。
:::

### 4. 肌梭

肌梭（muscle spindle）是分布在骨骼肌内的梭形结构。表面有结缔组织被囊，内含若干条较细的骨骼肌纤维，称梭内肌纤维。梭内肌纤维的核成串排列，或集中在肌纤维的中段而使该处膨大，肌原纤维较少。感觉神经纤维进入肌梭前失去髓鞘，其轴突分成多支，分别呈环状包绕梭内肌纤维中段的含核部分，或呈花枝样附着在接近中段处。此外，肌梭内也有运动神经末梢，分布在肌纤维的两端（图 7-30～图 7-32）。梭内肌纤维与肌梭周围的肌纤维同步收缩或舒张，其张力变化可刺激感觉神经末梢，冲动传入中枢后，产生对骨骼肌伸缩状态，即身体各部位屈伸状态的感知，故肌梭属于本体感受器，在调控骨骼肌的活动中起重要作用。

:::definition{label="肌梭"}
肌梭（muscle spindle）是骨骼肌内的梭形本体感受器。表面有结缔组织被囊，内含若干条较细的梭内肌纤维。感觉纤维入梭前失髓鞘，环状包绕梭内肌中段含核部，或花枝样附着于近中段；运动末梢分布在肌纤维两端。
:::

:::definition{label="梭内肌纤维"}
梭内肌纤维是肌梭被囊内较细的骨骼肌纤维。核成串排列，或集中在中段使该处膨大，肌原纤维较少。它们与梭外肌纤维同步收缩或舒张，张力变化刺激感觉末梢。
:::

:::definition{label="梭外肌纤维"}
梭外肌纤维指肌梭周围、不在被囊内的普通骨骼肌纤维。图 7-30 标 1 为梭外肌纤维。肌梭感知的是这些纤维与梭内肌一起发生的伸缩状态。
:::

:::definition{label="本体感受器"}
本体感受器感知身体各部位的屈伸状态。肌梭属于本体感受器：梭内、梭外肌同步收缩或舒张，张力变化经感觉末梢传入中枢，在调控骨骼肌活动中起重要作用。
:::

:::note{label="肌梭里同时有感觉末梢和运动末梢"}
肌梭不是纯感觉小体。中段挂感觉（环状或花枝样），两端挂运动末梢，所以它既能上报张力，也能接受运动神经元的调节。切片上先找被囊和较细的梭内肌，再找中段成串的核。
:::

:::pitfall{label="肌梭不是运动终板，梭内肌也不是普通肌纤维的横断面"}
运动终板是躯体运动纤维在梭外骨骼肌表面的椭圆形板状隆起；肌梭是包在被囊里的梭形感受器。梭内肌较细、中段核成串或集中膨大、肌原纤维较少，不要把囊内那一丛核写成炎症或写成肌节横切。本体感觉走肌梭，随意收缩走运动终板，两套装置可以同时出现在一块骨骼肌里。
:::

## （二）运动神经末梢

运动神经末梢（motor nerve ending）是运动神经元的轴突在肌组织和腺体的终末结构，支配肌细胞的收缩，调节腺细胞的分泌。可分为躯体和内脏运动神经末梢两类。

:::definition{label="运动神经末梢"}
运动神经末梢（motor nerve ending）是运动神经元的轴突在肌组织和腺体的终末结构，支配肌细胞收缩，调节腺细胞分泌。分为躯体运动神经末梢和内脏运动神经末梢。
:::

### 1. 躯体运动神经末梢

分布于骨骼肌。位于脊髓前角或脑干的运动神经元胞体发出的长轴突，抵达骨骼肌细胞时失去髓鞘，其轴突反复分支，每一分支形成葡萄状终末，并与骨骼肌细胞建立突触连接，此连接区域呈椭圆形板状隆起，称运动终板（motor end plate）或神经肌连接（neuromuscular junction）（图 7-33，图 7-34）。一个运动神经元支配的骨骼肌细胞数目少则 $1\sim 2$ 条，多则上千条，然而一条骨骼肌细胞通常只接受一个轴突分支的支配。一个运动神经元及其支配的全部骨骼肌细胞合称一个运动单位（motor unit）。运动单位越小，如在手指和面部，产生的运动越精细。

电镜下，运动终板处的骨骼肌纤维表面凹陷成浅槽，槽底肌膜即突触后膜，形成许多皱褶，使突触后膜面积增大。轴突终末（即突触小体）嵌入浅槽，内有许多含乙酰胆碱的圆形突触小泡。当神经冲动到达运动终板时，乙酰胆碱释放，与突触后膜中的相应受体结合后，改变肌膜（突触后膜）两侧的离子分布而产生兴奋，引发肌纤维收缩。

:::definition{label="运动终板"}
运动终板（motor end plate）又称神经肌连接（neuromuscular junction），是躯体运动神经末梢与骨骼肌细胞的突触连接区，呈椭圆形板状隆起。轴突抵达肌细胞时失髓鞘，反复分支成葡萄状终末。
:::

:::definition{label="神经肌连接"}
神经肌连接（neuromuscular junction）即运动终板，是运动神经元轴突终末与骨骼肌纤维之间的化学突触。
:::

:::definition{label="运动单位"}
运动单位（motor unit）是一个运动神经元及其支配的全部骨骼肌细胞。一个神经元支配的肌细胞少则 $1\sim 2$ 条，多则上千条；一条骨骼肌细胞通常只接受一个轴突分支的支配。运动单位越小（如手指和面部），运动越精细。
:::

:::definition{label="运动终板处的乙酰胆碱"}
轴突终末（突触小体）嵌入肌膜浅槽，内有许多含乙酰胆碱的圆形突触小泡。冲动到达后乙酰胆碱释放，与突触后膜受体结合，改变肌膜两侧离子分布，产生兴奋，引发肌纤维收缩。
:::

:::concept{term="先问几个终板共用一个神经元，再问一条肌纤维接几根轴突"}
运动单位的大小决定动作能不能做细。手指和面部一个神经元只带很少几条肌纤维，所以能写字、能表情；一块大力肌里一个神经元可以带上千条。反过来，一条骨骼肌细胞通常只接受一个轴突分支——不要把“一个神经元支配多条肌”理解成“一条肌接受多个神经元”。电镜再问后膜皱褶和乙酰胆碱小泡，这是第二节化学突触在骨骼肌上的落点。
:::

:::pitfall{label="一条骨骼肌细胞通常只接受一个轴突分支，不要和“一个神经元支配多条肌”对调"}
教材两句话方向相反：一个运动神经元可以支配 $1\sim 2$ 条至上千条骨骼肌细胞；一条骨骼肌细胞通常只接受一个轴突分支。把两者记反，运动单位和终板计数会一起错。氯化金铺片（图 7-33）看到的葡萄状终末，是同一轴突的反复分支，不是许多无关神经元同时接到一条肌上。
:::

:::compare{title="化学突触通式在运动终板上的落点"}
| 突触通式（第二节） | 运动终板 |
|--------------------|----------|
| 突触前成分 | 轴突终末（突触小体）嵌入浅槽，含乙酰胆碱圆形小泡 |
| 突触间隙 | 终末与皱褶肌膜之间的间隙 |
| 突触后成分 | 槽底肌膜，即突触后膜，形成许多皱褶以增大面积 |
| 递质 | 乙酰胆碱 |
| 效应 | 肌膜离子分布改变 → 兴奋 → 肌纤维收缩 |
:::

### 2. 内脏运动神经末梢

分布于心肌、各种内脏及血管的平滑肌和腺体等处。其神经纤维较细，无髓鞘，分支末段呈串珠样称为膨体（varicosity），贴附于肌细胞表面或穿行于腺细胞之间，与效应细胞建立突触（图 7-35）。

:::definition{label="内脏运动神经末梢"}
内脏运动神经末梢分布于心肌、各种内脏及血管的平滑肌和腺体等处。纤维较细、无髓鞘，分支末段呈串珠样膨体，贴附于肌细胞表面或穿行于腺细胞之间，与效应细胞建立突触。
:::

:::definition{label="膨体"}
膨体（varicosity）是内脏运动神经纤维分支末段的串珠样膨大。内含线粒体和突触小泡，贴近效应细胞，相当于一串小型突触前成分。
:::

:::compare{title="躯体运动神经末梢与内脏运动神经末梢"}
| 项目 | 躯体运动神经末梢 | 内脏运动神经末梢 |
|------|------------------|------------------|
| 靶 | 骨骼肌 | 心肌、内脏和血管平滑肌、腺体 |
| 纤维 | 前角或脑干运动神经元的长轴突，抵达时失髓鞘 | 较细，无髓鞘 |
| 终末形态 | 葡萄状终末，形成椭圆形运动终板 | 串珠样膨体 |
| 与效应细胞 | 一条骨骼肌细胞通常只接一个轴突分支；后膜皱褶，乙酰胆碱 | 贴附肌细胞表面或穿行于腺细胞之间 |
| 精细程度 | 运动单位越小越精细（手指、面部） | 以膨体沿途释放，支配较弥散 |
:::

:::pitfall{label="膨体不是运动终板，内脏纤维也不是“细一点的有髓纤维”"}
内脏运动纤维较细且无髓鞘，终末写成串珠样膨体，不是椭圆形板状隆起。不要在平滑肌或心肌表面寻找葡萄状运动终板，也不要把膨体当成病理肿胀。图 7-35 把膨体放大成一次化学突触：前膜、间隙、后膜受体和递质分子，只是没有骨骼肌那样的后膜皱褶终板。
:::

::figure{src="/images/histology/textbook/p0095_01.png" caption="图7-35 内脏运动神经纤维及其末梢与膨体超微结构示意图。A. 内脏运动神经纤维及其末梢；B. 膨体超微结构（线粒体、突触小泡、突触前膜、间隙、后膜受体与神经递质分子）。" alt="内脏运动纤维串珠样膨体及膨体与效应细胞之间的化学突触放大"}

:::insight{label="末梢是纤维账在靶器官上的最后一笔"}
感觉侧把假单极神经元的周围突改写成游离细支或被囊小体，运动侧把轴突改写成终板或膨体。下一节切断的是这根纤维的中段：远侧整段溃变，近侧能否再长回靶，取决于胞体还在不在、周围有没有施万细胞和基膜管。末梢形态学先立住，溃变再生才知道“长回原来的靶”指的是哪一种装置。
:::

:::keypoint{label="神经末梢先把感觉四型和运动两型立住"}
- 感觉末梢 = 假单极神经元周围突末端 + 周围组织 → 感受器。
- 游离末梢：细支裸露，冷、热、轻触、痛；触觉小体：真皮乳头，触觉；环层小体：皮下等处同心圆，压觉和振动觉；肌梭：骨骼肌内本体感受器，囊内有梭内肌，中段感觉、两端运动。
- 躯体运动：运动终板（神经肌连接），乙酰胆碱；一条肌通常只接一个轴突分支；运动单位越小越精细。
- 内脏运动：细而无髓，串珠样膨体贴肌或穿腺体。
:::

:::memory{label="本节必背要点"}
- [ ] 神经末梢是周围神经纤维的终末部分，按功能分为感觉神经末梢和运动神经末梢。
- [ ] 感觉神经末梢（sensory nerve ending）是假单极神经元周围突的末端，与周围组织构成感受器，把刺激转化为冲动传入中枢。
- [ ] 游离神经末梢（free nerve ending）：较细有髓或无髓纤维终末反复分支，细支裸露；分布于表皮、角膜、毛囊上皮之间及真皮、骨膜、脑膜、血管外膜、关节囊、肌腱、韧带、筋膜、牙髓等。
- [ ] 游离末梢感受温度、应力及高浓度 $\mathrm{H}^{+}$、$\mathrm{K}^{+}$ 等，参与冷、热、轻触和痛觉。
- [ ] 触觉小体（tactile corpuscle）：真皮乳头，手指掌侧最多，数量随年龄递减；卵圆，长轴垂直皮肤；内有扁平横列细胞，外包结缔组织被囊；入内前失髓鞘并盘绕；参与触觉。
- [ ] 环层小体（lamellar corpuscle）：皮下、腹膜、肠系膜、韧带、关节囊等；较大，圆或卵圆；中央均质圆柱体，周围同心圆扁平细胞；裸轴突入圆柱体；压觉和振动觉。
- [ ] 肌梭（muscle spindle）：骨骼肌内梭形结构，表面结缔组织被囊，内含梭内肌纤维。
- [ ] 梭内肌纤维较细，核成串或集中于中段使该处膨大，肌原纤维较少。
- [ ] 感觉纤维入肌梭前失髓鞘：环状包绕中段含核部，或花枝样附着近中段；运动末梢在肌纤维两端。
- [ ] 梭内肌与梭外肌同步收缩或舒张，张力变化传入中枢，感知屈伸状态；肌梭是本体感受器。
- [ ] 运动神经末梢（motor nerve ending）是运动神经元轴突在肌组织和腺体的终末，分躯体和内脏两类。
- [ ] 运动终板（motor end plate）= 神经肌连接（neuromuscular junction）：前角或脑干运动神经元长轴突抵达骨骼肌时失髓鞘，反复分支成葡萄状终末，连接区呈椭圆形板状隆起。
- [ ] 一个运动神经元支配的骨骼肌细胞少则 $1\sim 2$ 条、多则上千条；一条骨骼肌细胞通常只接受一个轴突分支。
- [ ] 运动单位（motor unit）= 一个运动神经元 + 其支配的全部骨骼肌细胞；越小（手指、面部）运动越精细。
- [ ] 电镜：肌膜凹陷成浅槽，槽底后膜皱褶增大面积；突触小体嵌入，含乙酰胆碱圆形小泡；释放后与后膜受体结合，改变离子分布，引发收缩。
- [ ] 内脏运动神经末梢：分布于心肌、内脏及血管平滑肌和腺体；纤维细、无髓鞘；末段串珠样膨体（varicosity）贴肌或穿腺体，与效应细胞建立突触。
:::
