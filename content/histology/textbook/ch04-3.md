# 三、骨的发生和重建

## （一）骨的发生方式

骨发生起始于胚胎时期，来源于间充质，有膜内成骨和软骨内成骨两种方式。

:::definition{label="骨的发生"}
骨发生起始于胚胎时期，来源于间充质，有膜内成骨和软骨内成骨两种方式。
:::

:::concept{term="先问这块骨有没有先做过一块透明软骨"}
两种成骨都从间充质出发，分歧在中间有没有软骨雏形。额骨、顶骨、枕骨、颞骨、颌骨、锁骨等在胚性结缔组织膜里直接成骨，叫膜内成骨。四肢骨、躯干骨和部分颅底骨先做成透明软骨，再替换成骨，叫软骨内成骨。看见“成骨”，先问中间有没有软骨这个台阶。
:::

### 1. 膜内成骨

膜内成骨（intramembranous ossification）是指在间充质分化形成的胚性结缔组织膜内直接成骨，额骨、顶骨、枕骨、颞骨、颌骨、锁骨等以此种方式发生。在将要成骨的部位，间充质分化为胚性结缔组织，其中部分间充质细胞分化为骨祖细胞，后者进一步分化为成骨细胞。成骨细胞在此生成骨组织。最先形成骨组织的部位称为骨化中心（ossification center），随着骨化中心的逐渐扩大和改造，骨小梁形成并不断增长加粗，数量增多，逐步构建成多孔隙网格状的松质骨。之后，松质骨的表面部分逐步重建为密质骨，周围的结缔组织则分化为骨膜（图 4-11）。

:::definition{label="膜内成骨"}
膜内成骨（intramembranous ossification）是在间充质分化形成的胚性结缔组织膜内直接成骨。额骨、顶骨、枕骨、颞骨、颌骨、锁骨等以此种方式发生。
:::

:::definition{label="骨化中心"}
骨化中心（ossification center）是最先形成骨组织的部位。膜内成骨时，骨化中心扩大并改造，骨小梁增长加粗、数量增多，建成松质骨网格；表面再重建为密质骨，周围结缔组织分化为骨膜。
:::

:::derivation{title="膜内成骨四步"}
1. 将要成骨的部位，间充质分化为胚性结缔组织，其中含骨祖细胞（图 4-11A）。
2. 骨祖细胞分化为成骨细胞（图 4-11B）。
3. 成骨细胞生成原始骨组织（图 4-11C）。
4. 原始骨组织生长重建，骨小梁形成并增粗增多，构成松质骨网格；表面逐步重建为密质骨，周围结缔组织分化为骨膜（图 4-11D）。
:::

### 2. 软骨内成骨

软骨内成骨（endochondral ossification）由透明软骨逐步替换为骨的成骨方式。人体的大多数骨，如四肢骨、躯干骨和部分颅底骨等，都以此种方式发生。这种成骨方式比膜内成骨复杂，现以长骨发生为例予以说明（图 4-12）。

:::definition{label="软骨内成骨"}
软骨内成骨（endochondral ossification）是由透明软骨逐步替换为骨的成骨方式。人体大多数骨，如四肢骨、躯干骨和部分颅底骨等，都以此种方式发生。
:::

**（1）软骨雏形形成** 在将要成骨的部位间充质细胞聚集，分化为骨祖细胞，继而分化为成软骨细胞，成软骨细胞进一步转变为软骨细胞，后者不断增殖分裂并分泌软骨基质，形成透明软骨，因其外形与将要形成的长骨相似，故称软骨雏形（cartilage model）。软骨周围的间充质则分化为软骨膜。

:::definition{label="软骨雏形"}
软骨雏形（cartilage model）是将要成骨部位由间充质经骨祖细胞、成软骨细胞形成的透明软骨，外形与将要形成的长骨相似。周围的间充质分化为软骨膜。
:::

**（2）骨领形成** 在软骨雏形中段，软骨膜内的骨祖细胞增殖分化为成骨细胞，后者贴附在软骨组织表面形成薄层原始骨组织。这层骨组织呈领圈状包绕软骨雏形中段，故名骨领（bone collar）。骨领形成后，其表面的软骨膜改称骨膜。

:::definition{label="骨领"}
骨领（bone collar）是软骨雏形中段表面、由软骨膜内骨祖细胞分化的成骨细胞贴附形成的薄层原始骨组织，呈领圈状包绕中段。骨领形成后，其表面的软骨膜改称骨膜。
:::

:::pitfall{label="骨领是膜内成骨写在软骨中段表面，不是软骨自己钙化出来的"}
软骨雏形中段的软骨膜改走成骨细胞路线，在软骨表面直接铺一层原始骨组织，这和膜内成骨是同一套细胞账。中心的软骨随后退化、钙化、被隧道式吸收，那才是软骨内替换。不要把骨领理解成“软骨基质变成了骨”。
:::

**（3）初级骨化中心与骨髓腔形成** 软骨雏形中央的软骨细胞停止分裂，体积增大，软骨细胞逐渐凋亡，周围的软骨基质钙化。骨膜中的血管穿越骨领，进入钙化的软骨区，破骨细胞、成骨细胞和间充质细胞也一并进入。破骨细胞以打隧道的方式溶解吸收退化的软骨组织，形成许多与软骨雏形长轴方向较为一致的隧道，成骨细胞则贴附于残存的软骨基质表面成骨，形成以钙化的软骨基质为中轴、表面包绕新生骨组织的条索状结构，称过渡型骨小梁（transitional bone trabecula）。出现过渡型骨小梁的部位称初级骨化中心（primary ossification center），过渡型骨小梁之间的腔隙称初级骨髓腔，间充质细胞在此分化为网状细胞，形成网状组织。造血干细胞进入并增殖分化，形成骨髓。

初级骨化中心形成过程中，软骨雏形两端的软骨不断增生，同时不断被破坏并骨化，过渡型骨小梁也陆续被破骨细胞吸收，使许多初级骨髓腔融合成一个不断增大并加长的骨髓腔。

:::definition{label="过渡型骨小梁"}
过渡型骨小梁（transitional bone trabecula）以钙化的软骨基质为中轴、表面包绕新生骨组织，呈条索状。它是破骨细胞打隧道吸收退化软骨后，成骨细胞贴残存软骨基质成骨的产物。
:::

:::definition{label="初级骨化中心"}
初级骨化中心（primary ossification center）是出现过渡型骨小梁的部位，位于软骨雏形中央。过渡型骨小梁之间的腔隙称初级骨髓腔；间充质细胞分化为网状细胞形成网状组织，造血干细胞进入并增殖分化，形成骨髓。
:::

:::cause-effect{title="初级骨化中心怎样把软骨中段换成骨髓腔"}
- 因：中央软骨细胞停分裂、肥大、凋亡，周围基质钙化
- 因：血管穿越骨领，带来破骨细胞、成骨细胞和间充质细胞
- 果：破骨细胞沿长轴打隧道吸收退化软骨；成骨细胞在残存基质表面成骨 → 过渡型骨小梁
- 果：小梁间形成初级骨髓腔，造血干细胞进入形成骨髓
- 随后：两端软骨边增生边被破坏骨化，过渡型骨小梁陆续被吸收，初级骨髓腔融合成不断增大加长的骨髓腔
:::

**（4）次级骨化中心与骨骺形成** 次级骨化中心（secondary ossification center）出现在骨干两端的软骨组织中央，此处将形成骨骺。出现时间因骨而异，大多在出生后数月或数年。软骨替换为骨的过程与初级骨化中心的形成相似，但骨化是从中央呈放射状向四周进行的，最终形成以松质骨为主体的骨骺，以后骨骺的外侧面松质骨被改造成密质骨。骨骺末端表面的薄层透明软骨不被骨化，终身保留，参与构成关节，称关节软骨。骨骺与骨干之间也保留一定厚度的软骨层，称骺板（epiphyseal plate）或生长板，是长骨继续延长的结构基础。

:::definition{label="次级骨化中心"}
次级骨化中心（secondary ossification center）出现在骨干两端软骨组织中央，将形成骨骺。出现时间因骨而异，大多在出生后数月或数年。骨化从中央呈放射状向四周进行，最终形成以松质骨为主体的骨骺；以后外侧面松质骨被改造成密质骨。
:::

:::definition{label="骺板"}
骺板（epiphyseal plate）又称生长板，是骨骺与骨干之间保留的一定厚度的软骨层，是长骨继续延长的结构基础。
:::

:::definition{label="关节软骨（发生）"}
骨骺末端表面的薄层透明软骨不被骨化，终身保留，参与构成关节，称关节软骨。其结构差异见第五节。
:::

|------|------------------------------------------|----------------------------------------|
| 中间台阶 | 无软骨雏形，胚性结缔组织膜内直接成骨 | 先形成透明软骨雏形，再逐步替换为骨 |

## （二）长骨的生长和重建

在长骨的发生和生长过程中，明显地表现为纵向的加长和横向的增粗，在整个生长期间，又进行着持续的重建，以适应身体生长发育的需要。

:::definition{label="长骨生长的两个方向"}
长骨的发生和生长表现为纵向加长和横向增粗；整个生长期间持续重建，以适应身体生长发育的需要。
:::

### 1. 骨加长

通过骺板的不断生长并替换成骨组织而实现。这种替换过程与初级骨化中心的形成过程类似，但替换过程的顺序性更明显，从骨骺端到骨干的骨髓腔，替换的顺序性表现为五个连续的分区（图 4-12）。

:::definition{label="骨加长"}
骨加长通过骺板的不断生长并替换成骨组织而实现。替换过程与初级骨化中心类似，但顺序性更明显，从骨骺端到骨干骨髓腔表现为五个连续分区。
:::

**（1）软骨储备区（zone of reserving cartilage）** 软骨细胞小，分散存在，软骨基质呈弱嗜碱性。

**（2）软骨增生区（zone of proliferating cartilage）** 软骨细胞明显生长，变成椭圆形和圆形，随之分裂增生形成同源细胞群，细胞排列大体上呈纵向分布。

**（3）软骨成熟区（zone of maturing cartilage）** 软骨细胞明显增大成熟，同源细胞群之间的软骨基质的宽度变窄，嗜碱性增强。

**（4）软骨钙化区（zone of calcifying cartilage）** 软骨细胞开始退化、凋亡，细胞质空化，出现核固缩与核溶解，接近骨髓腔的细胞消失，仅留下空洞状的软骨陷窝，陷窝内可有破骨细胞到达。软骨基质钙化明显，呈强嗜碱性。

**（5）成骨区（zone of ossification）** 破骨细胞和成骨细胞极为活跃，光镜下易见到（见图 4-6B）。由于软骨细胞退化和破骨细胞的吸收作用，形成较为宽大的纵向隧道，残留的软骨基质则像钟乳石一样悬挂在钙化区底部。成骨细胞附着于软骨基质表面分泌类骨质，形成不断向骨髓腔延伸的过渡型骨小梁。在骨髓腔侧，过渡型骨小梁又不断被破骨细胞破坏吸收，使骨髓腔向长骨骨端方面不断拓展，长骨得以不断加长（见图 4-12）。

以上各区的变化是连续进行的，软骨的增生、退化及成骨保证了在骨干长度增加的同时，骺板能维持一定厚度。$17\sim 20$ 岁的青少年，骺板的软骨细胞停止分裂，骺软骨逐渐完全被骨组织取代，长骨的骨干和骨骺的骨组织连接融合形成薄层密质骨，在纵切面上为线性痕迹，称骺线（epiphyseal line），骺线形成意味着骨不能继续纵向生长。骺板和骺线可通过关节部位的 X 线摄影予以区分显示，对长骨的生长发育情况进行辅助判断。

:::definition{label="骺线"}
骺线（epiphyseal line）是 $17\sim 20$ 岁骺板软骨细胞停止分裂、骺软骨完全被骨组织取代后，骨干与骨骺的骨组织融合形成的薄层密质骨，纵切面上呈线性痕迹。骺线形成意味着骨不能继续纵向生长。
:::

:::compare{title="骺板五区"}
| 区 | 英文 | 细胞 | 基质 | 要点 |
|----|------|------|------|------|
| 软骨储备区 | zone of reserving cartilage | 细胞小，分散 | 弱嗜碱性 | 储备，尚未列队增生 |
| 软骨增生区 | zone of proliferating cartilage | 明显生长，椭圆/圆形，分裂成同源细胞群，大体纵向排列 | — | 加长的细胞来源 |
| 软骨成熟区 | zone of maturing cartilage | 明显增大成熟 | 同源细胞群之间变窄，嗜碱性增强 | 肥大、为钙化做准备 |
| 软骨钙化区 | zone of calcifying cartilage | 退化凋亡，胞质空化，核固缩与核溶解；近骨髓腔细胞消失，空洞状陷窝，可有破骨细胞 | 钙化明显，强嗜碱性 | 软骨让出空间 |
| 成骨区 | zone of ossification | 破骨细胞和成骨细胞极为活跃 | 残留软骨基质如钟乳石悬挂；表面成骨形成过渡型骨小梁 | 骨髓腔向骨端拓展，骨加长 |
:::

:::timeline{period="骺板从加长到闭合"}
- **生长期** 五区连续变化：增生、退化、成骨并行，骨干加长的同时骺板维持一定厚度
- **$17\sim 20$ 岁** 骺板软骨细胞停止分裂，骺软骨逐渐完全被骨组织取代
- **骺线形成** 骨干与骨骺融合为薄层密质骨，纵切面呈线性痕迹，纵向生长停止
- **X 线** 骺板与骺线可在关节部位摄影中区分，辅助判断长骨生长发育
:::

:::pitfall{label="骺板闭合后不再长长"}
骺线一旦形成，纵向生长的软骨来源就没有了。骨膜下成骨大约到 $30$ 岁也不再增粗，但那是横径账，不能把成年后的重建听成还能长高。X 线上骺板是一条软骨透亮带，骺线是骨性线性痕迹，不要把两者当成同一结构的不同名字。
:::

:::derivation{title="骺板五区如何在加长的同时保住厚度"}
1. 储备区提供幼稚软骨细胞。
2. 增生区纵向分裂，同源细胞群列队，软骨向骨骺侧“生长”。
3. 成熟区细胞肥大，基质变窄、嗜碱增强。
4. 钙化区细胞退化凋亡，基质钙化，破骨细胞进入空洞陷窝。
5. 成骨区成骨细胞贴残留基质分泌类骨质，形成过渡型骨小梁；骨髓腔侧小梁又被破骨细胞吸收，骨髓腔向骨端拓展。
6. 增生速度与替换速度匹配，骨干变长而骺板厚度保持一定；一旦增生停止，替换进行到底，骺线形成。
:::

### 2. 骨增粗

骨外膜深部的骨祖细胞分化为成骨细胞，在骨干表面添加骨组织，使骨干变粗。而在骨干的内表面，破骨细胞吸收骨小梁，使骨髓腔横向扩大。骨干外表面的骨形成略快于骨干内部的骨吸收，使得骨干的密质骨逐渐增厚，骨髓腔也逐渐扩大。大约 $30$ 岁，长骨将不再增粗。

:::definition{label="骨增粗"}
骨增粗由骨外膜深部骨祖细胞分化为成骨细胞、在骨干表面添加骨组织而实现；骨干内表面破骨细胞吸收骨小梁，骨髓腔横向扩大。外表面骨形成略快于内部骨吸收，故密质骨逐渐增厚、骨髓腔也逐渐扩大。大约 $30$ 岁，长骨不再增粗。
:::

:::cause-effect{title="为什么骨干能变粗、骨髓腔也能变大"}
- 因：骨外膜深部成骨，骨干外表面添加骨质
- 因：内表面破骨细胞吸收骨小梁
- 因：外表面骨形成略快于内部骨吸收
- 果：骨干变粗，密质骨逐渐增厚，同时骨髓腔横向扩大
- 终点：大约 $30$ 岁，长骨不再增粗
:::

### 3. 骨重建

骨重建（bone remodeling）是指骨在生长发育过程中所做的适应性结构变化，是骨形成与骨吸收的动态平衡。机体通过一系列机制调控成骨细胞与破骨细胞活动，使骨形成特定形态，以与人的整体生长发育相适应。所有的骨都会进行不同程度的重建，其中尤以长骨最为显著。

:::definition{label="骨重建"}
骨重建（bone remodeling）是骨在生长发育过程中所做的适应性结构变化，是骨形成与骨吸收的动态平衡。机体调控成骨细胞与破骨细胞活动，使骨形成特定形态，与整体生长发育相适应。所有骨都有不同程度重建，长骨最为显著。
:::

:::theorem{label="骨组织不能从内部生长"}
骨细胞在形成过程中逐渐丧失分泌类骨质的能力，也不能进行细胞分裂，故骨组织不能从内部生长。骨干加长只能通过干骺端的生长与重建实现；增粗只能在表面添加、在内表面吸收。这与软骨既有附加性生长又有间质性生长形成对照。
:::

**（1）长骨外形的重建** 由于骨细胞在形成过程中逐渐丧失了分泌类骨质的能力，也不能进行细胞分裂，故骨组织不能从内部生长，骨干的加长只能通过干骺端的生长与重建实现。长骨的骨骺和干骺端（即骺板成骨区）呈圆锥形，比骨干明显粗大，故在长骨加长的同时，干骺端必须通过重建使直径由大变小。干骺端外侧以骨吸收为主，内侧面以骨形成为主，使干骺端近骨干的一侧逐渐变细，粗细与骨干中段一致。新增骨干的两端又形成新的干骺端，如此持续不断进行重建，直到骺板停止生长，长骨不再加长（图 4-13）。

:::definition{label="干骺端外形重建"}
骨骺和干骺端（骺板成骨区）呈圆锥形，比骨干明显粗大。加长的同时，干骺端外侧以骨吸收为主、内侧面以骨形成为主，使近骨干侧逐渐变细，与骨干中段一致。新增骨干的两端又形成新的干骺端，持续重建直到骺板停止生长。
:::

::figure{src="/images/histology/textbook/p0061_01.png" caption="图4-13 长骨外形重建示意图。左侧虚线示重建前的外形轮廓；Dd. 骨干骨沉积区；Dm. 干骺端骨沉积区；Rd. 骨干骨吸收区；Rm. 干骺端骨吸收区。" alt="长骨干骺端外形重建：外侧吸收、内侧沉积，使圆锥形干骺端变细接上骨干"}

**（2）长骨内部的重建** 密质骨和松质骨都会随着骨的生长发育而不断重建。骨领最初为松质骨，随着骨小梁逐渐增粗，小梁间的网孔缩小而变致密，密质骨开始形成。骨单位的形成过程大体如下：破骨细胞分解吸收陈旧的骨组织，形成许多纵向隧道；骨内膜连同血管和骨祖细胞等进入隧道；骨祖细胞分化为成骨细胞，后者贴隧道壁成骨，逐层形成同心圆排列的骨单位骨板，原先的管道逐渐缩小成为中央管。随着骨单位的增多，骨干密质骨不断增厚。骨吸收和骨形成的协调活动导致旧的骨单位陆续被新的骨单位替代，原有的骨单位和外环骨板被破坏后的残余部分则成了间骨板。由于重建的进度差异，骨单位的直径和骨板层数并不相同，骨单位也不总是圆柱状，可有分支和相互吻合，从而形成复杂的整体构型，以顺应该长骨的应力需要（见图 4-10）。

:::derivation{title="骨单位怎样在旧骨里打出来"}
1. 破骨细胞分解吸收陈旧骨组织，形成许多纵向隧道。
2. 骨内膜连同血管和骨祖细胞等进入隧道。
3. 骨祖细胞分化为成骨细胞，贴隧道壁成骨，逐层形成同心圆骨单位骨板。
4. 原先的管道逐渐缩小成为中央管。
5. 旧骨单位和外环骨板被破坏后的残余部分成为间骨板；新骨单位直径和层数因重建进度而异，并可分支吻合，以顺应应力。
:::

:::note{label="成体仍有百分之几的骨在重建"}
插入框还写明：成人骨骼虽无明显增大或缩小，也有 $3\%\sim 5\%$ 骨组织处于不断重建中，维持微细结构、替换接近生命终期的骨质。重建失衡将在下一节以骨质疏松症展开。
:::

:::insight{label="重建是外形账加内部账，都靠成骨与破骨配对"}
外形：干骺端必须从粗变细才能接上骨干，外侧吸收、内侧沉积，像车床修圆锥。内部：松质骨领加密成密质骨，破骨细胞先打纵向隧道，成骨细胞再铺同心圆骨板。间骨板是旧单位的残片，黏合线是新旧交代的界。应力需要写进这套构型，第四节的维生素、激素和应力都是在调这两类细胞。
:::

:::keypoint{label="发生分两路，长骨生长分加长、增粗和重建"}
- 膜内成骨：胚性结缔组织膜内直接成骨（额、顶、枕、颞、颌、锁骨等）。
- 软骨内成骨：透明软骨雏形 → 骨领 → 初级骨化中心/骨髓腔 → 次级骨化中心/骨骺 + 骺板 + 关节软骨。
- 加长靠骺板五区连续替换；$17\sim 20$ 岁形成骺线后不再长长。
- 增粗靠骨外膜下成骨略快于内表面吸收；约 $30$ 岁不再增粗。
- 骨不能内部生长；干骺端外侧吸收、内侧成骨以对接骨干；骨单位由破骨打隧道、成骨铺同心圆而成，残部为间骨板。
:::

:::memory{label="本节必背要点"}
- [ ] 骨发生始于胚胎，源自间充质，分膜内成骨和软骨内成骨两种方式。
- [ ] 膜内成骨（intramembranous ossification）：胚性结缔组织膜内直接成骨；额骨、顶骨、枕骨、颞骨、颌骨、锁骨等。
- [ ] 膜内成骨过程：间充质 → 骨祖细胞 → 成骨细胞 → 骨化中心扩大 → 骨小梁构成松质骨 → 表面重建为密质骨，周围结缔组织成骨膜。
- [ ] 软骨内成骨（endochondral ossification）：透明软骨逐步替换为骨；四肢骨、躯干骨、部分颅底骨等大多数骨。
- [ ] 软骨雏形（cartilage model）：外形似未来长骨的透明软骨；周围间充质成软骨膜。
- [ ] 骨领（bone collar）：软骨雏形中段表面的薄层原始骨组织；其后软骨膜改称骨膜。
- [ ] 中央软骨细胞停分裂、肥大、凋亡，基质钙化；血管穿越骨领，破骨、成骨和间充质细胞进入。
- [ ] 过渡型骨小梁：钙化软骨基质为中轴、表面包绕新生骨；其部位即初级骨化中心；小梁间为初级骨髓腔，形成骨髓。
- [ ] 两端软骨边增生边被破坏骨化，过渡型骨小梁陆续吸收，初级骨髓腔融合成增大加长的骨髓腔。
- [ ] 次级骨化中心多在出生后数月或数年出现于两端软骨中央，放射状骨化形成骨骺（松质骨为主，外侧后改密质骨）。
- [ ] 骨骺末端薄层透明软骨终身保留为关节软骨；骨骺与骨干之间保留骺板（生长板）。
- [ ] 骨加长通过骺板生长并替换成骨；从骨骺端到骨髓腔分五区。
- [ ] 软骨储备区：细胞小、分散，基质弱嗜碱。
- [ ] 软骨增生区：细胞生长为椭圆/圆形，分裂成同源细胞群，大体纵向排列。
- [ ] 软骨成熟区：细胞明显增大成熟，群间基质变窄，嗜碱性增强。
- [ ] 软骨钙化区：细胞退化凋亡，胞质空化，核固缩与核溶解；近骨髓腔成空洞陷窝，可有破骨细胞；基质强嗜碱钙化。
- [ ] 成骨区：破骨与成骨活跃；残留基质如钟乳石；成骨细胞分泌类骨质形成过渡型骨小梁；骨髓腔侧小梁被吸收，骨髓腔向骨端拓展。
- [ ] 五区连续进行，加长的同时骺板维持一定厚度。
- [ ] $17\sim 20$ 岁骺板停止分裂，完全骨化，形成骺线（epiphyseal line），不能继续纵向生长；X 线可区分骺板与骺线。
- [ ] 骨增粗：外表面成骨、内表面吸收，外略快于内；约 $30$ 岁不再增粗。
- [ ] 骨重建是骨形成与骨吸收的动态平衡；骨细胞不能分裂、逐渐丧失分泌类骨质能力，故不能从内部生长。
- [ ] 干骺端圆锥形粗于骨干：外侧吸收（Rm）、内侧沉积（Dm），近骨干侧变细对接骨干（图 4-13）。
- [ ] 骨单位形成：破骨打纵向隧道 → 骨内膜、血管、骨祖细胞进入 → 成骨细胞贴壁铺同心圆骨板 → 管道缩小成中央管；残余为间骨板。
:::
