# 四、胎儿血液循环和出生后血液循环的变化

胎盘还在工作、肺还没呼吸时，血液必须绕开肺、把氧合血优先送给头颈上肢，并把大部分血经脐动脉送回胎盘。本节先按脐静脉 → 静脉导管／肝血窦 → 下腔静脉 → 卵圆孔／右室 → 动脉导管这条通路把氧饱和度钉住，再写出生后五条管道怎样变成韧带和卵圆窝。第三节留下的静脉导管、动脉导管和卵圆孔瓣，这里才真正派上用场。

## （一）胎儿血液循环

来自胎盘富含氧和营养物质的血液经脐静脉进入胚体，大部分血液在肝内经静脉导管进入下腔静脉，余者流经肝血窦注入下腔静脉。下腔静脉还收集来自下肢、盆腔和腹腔回流的血液。下腔静脉在右心房的入口正对卵圆孔，故大部分下腔静脉血（氧饱和度约为 $67\%$）直接通过卵圆孔进入左心房，小部分折回与右心房内来自上腔静脉和冠状窦的血液混合后进入右心室。左心房内还有少量来自肺静脉的血液，二者混合后进入左心室。

左心室的血液（氧饱和度约为 $62\%$）大部分经主动脉弓的三大分支供应头颈和上肢，以适应其发育，余者进入降主动脉。

右心室的血液进入肺动脉干。由于胚胎时期的肺尚未执行功能，故肺动脉干的血液仅有小部分（不足 $10\%$）进入肺，其余绝大部分经动脉导管注入降主动脉。

降主动脉血液（氧饱和度约为 $58\%$）除少量供应躯干、腹部和盆腔器官以及下肢外，均经脐动脉流入胎盘，与母体血液进行气体和物质交换（图 25-17）。

:::definition{label="胎儿血液循环的入口"}
来自胎盘、富含氧和营养物质的血液经脐静脉进入胚体。入口是脐静脉，不是卵黄静脉，也不是肺静脉。
:::

:::definition{label="静脉导管分流（胎儿）"}
大部分脐静脉血在肝内经静脉导管进入下腔静脉；余者流经肝血窦再注入下腔静脉。短路走静脉导管，过肝实质的是少数。
:::

:::definition{label="下腔静脉在右心房的入口"}
下腔静脉还收集下肢、盆腔和腹腔回流的血液。它在右心房的入口正对卵圆孔，所以大部分下腔静脉血直接经卵圆孔进左心房，只有小部分折回右心房。
:::

:::definition{label="卵圆孔分流（氧饱和度约67%）"}
大部分下腔静脉血氧饱和度约为 $67\%$，直接通过卵圆孔进入左心房。小部分折回，与右心房内来自上腔静脉和冠状窦的血液混合后进入右心室。
:::

:::definition{label="左心房到左心室"}
左心房内还有少量来自肺静脉的血液，与经卵圆孔进来的血混合后进入左心室。胎儿肺未执行功能，肺静脉回流量少，冲不淡这条以卵圆孔为主的通路。
:::

:::definition{label="左心室血（氧饱和度约62%）"}
左心室血液氧饱和度约为 $62\%$，大部分经主动脉弓的三大分支供应头颈和上肢，以适应其发育；余者进入降主动脉。氧合较好的血优先给头颈上肢，不是优先给降主动脉和下半身。
:::

:::definition{label="动脉导管分流（不足10%入肺）"}
右心室血液进入肺动脉干。胚胎时期肺尚未执行功能，肺动脉干的血液仅有小部分（不足 $10\%$）进入肺，其余绝大部分经动脉导管注入降主动脉。
:::

:::definition{label="降主动脉血（氧饱和度约58%）与脐动脉"}
降主动脉血液氧饱和度约为 $58\%$。除少量供应躯干、腹部和盆腔器官以及下肢外，均经脐动脉流入胎盘，与母体血液进行气体和物质交换。出口是一对脐动脉，不是一条脐静脉。
:::

:::concept{term="先问脐静脉血大部分是走静脉导管还是肝血窦，再问下腔入口是对卵圆孔还是进右室"}
看见胎儿循环，先从胎盘顺着脐静脉进胚体：大部分经静脉导管入下腔，余者过肝血窦。下腔静脉入口正对卵圆孔，所以大部分下腔血（约 $67\%$）进左房，只有小部分折回右房，与上腔静脉和冠状窦的血混合进右室。左室约 $62\%$ 的血大部分经主动脉弓三大分支养头颈上肢。右室进肺动脉干后，不足 $10\%$ 入肺，绝大部分经动脉导管进降主动脉。降主动脉约 $58\%$，大部分经脐动脉回胎盘。把“下腔静脉血全部进右室”或“肺动脉干血大部分进肺”写成成体循环，卵圆孔和动脉导管两本短路账都会消失。
:::

:::compare{title="三条短路：静脉导管、卵圆孔、动脉导管"}
| 短路 | 从哪到哪 | 大部分还是小部分 | 目的 |
|------|----------|------------------|------|
| 静脉导管 | 左脐静脉 → 下腔静脉（少过肝血窦） | 脐静脉血的大部分走这里 | 把胎盘氧合血尽快送回心 |
| 卵圆孔 | 下腔静脉血 → 左心房（再入左室） | 下腔静脉血的大部分走这里 | 让氧合较好的血进体循环，优先养头颈上肢 |
| 动脉导管 | 肺动脉干 → 降主动脉 | 肺动脉干血的绝大部分走这里（入肺不足 $10\%$） | 肺未工作，血不在肺里堆积，改送降主动脉和胎盘 |
:::

:::compare{title="教材给出的三处氧饱和度"}
| 部位 | 氧饱和度 | 去向 |
|------|----------|------|
| 大部分下腔静脉血（正对卵圆孔） | 约 $67\%$ | 大部分经卵圆孔入左心房 |
| 左心室血液 | 约 $62\%$ | 大部分经主动脉弓三大分支至头颈和上肢；余者入降主动脉 |
| 降主动脉血液 | 约 $58\%$ | 少量养躯干、腹盆和下肢；大部分经脐动脉回胎盘 |
:::

:::note{label="右心室这边没有另给一个百分数"}
教材只写：肺动脉干血液仅有小部分（不足 $10\%$）进入肺，其余绝大部分经动脉导管注入降主动脉。不足 $10\%$ 是入肺的比例，不是右心室血的氧饱和度。氧饱和度三处钉在 $67\%$、$62\%$、$58\%$。
:::

:::example{label="从胎盘走一圈再回到胎盘"}
**题目**：一滴刚从胎盘出来的氧合血，按教材的“大部分”路径，依次经过哪些结构，最后怎样回胎盘？

**解**：脐静脉入胚体 → 大部分经肝内静脉导管入下腔静脉（少部分过肝血窦）→ 下腔静脉在右房的入口正对卵圆孔 → 大部分经卵圆孔入左心房（与少量肺静脉血混合）→ 左心室（约 $62\%$）→ 大部分经主动脉弓三大分支到头颈上肢。未走卵圆孔的那一小部分下腔血折回右房，与上腔静脉、冠状窦的血混合入右心室 → 肺动脉干 → 不足 $10\%$ 入肺，绝大部分经动脉导管入降主动脉（约 $58\%$）→ 大部分经脐动脉回胎盘交换。两条短路（卵圆孔、动脉导管）把“大部分”从肺旁绕开。
:::

:::pitfall{label="大部分下腔静脉血进左房，不是进右室"}
入口正对卵圆孔，所以大部分（约 $67\%$）直接进左心房。只有小部分折回右心房，再与上腔静脉和冠状窦的血混合进右心室。写成“下腔静脉血像成体那样全进右室”，头颈上肢就得不到这条氧合较好的血。
:::

:::pitfall{label="肺动脉干绝大部分走动脉导管，入肺不足10%"}
肺尚未执行功能。不足 $10\%$ 入肺，其余绝大部分经动脉导管入降主动脉。写成“右室血大部分去肺换气”，胎儿循环会变成出生后循环。
:::

:::pitfall{label="左室约62%的血优先养头颈上肢，降主动脉约58%大部分回胎盘"}
主动脉弓三大分支先截走大部分左室血；降主动脉里剩下的血氧饱和度更低（约 $58\%$），除少量养下半身外，均经脐动脉回胎盘。不要把“降主动脉血大部分养下肢”当成胎儿循环。
:::

:::cause-effect{title="肺不工作、胎盘在工作，决定三条短路和三处饱和度"}
- 因：胎盘提供氧和营养，脐静脉入胚
- 果：大部分经静脉导管入下腔，少部分过肝血窦
- 因：下腔静脉入口正对卵圆孔
- 果：大部分下腔血（约 67%）进左房、左室，经主动脉弓三大分支优先养头颈上肢（左室约 62%）
- 因：肺尚未执行功能
- 果：肺动脉干血入肺不足 10%，绝大部分经动脉导管入降主动脉（约 58%），大部分经脐动脉回胎盘
:::

:::timeline{period="胎儿循环：从脐静脉到脐动脉"}
- **入口** 胎盘氧合血经脐静脉入胚体
- **过肝** 大部分经静脉导管入下腔静脉；余者经肝血窦入下腔静脉
- **下腔** 还收集下肢、盆腔、腹腔回流血液；入口正对卵圆孔
- **卵圆孔** 大部分下腔血（约 67%）入左心房；小部分折回，与上腔静脉和冠状窦血混合入右心室
- **左心** 左房还有少量肺静脉血；左室约 62%，大部分经主动脉弓三大分支至头颈上肢，余者入降主动脉
- **右心与肺动脉干** 入肺不足 10%；绝大部分经动脉导管入降主动脉
- **出口** 降主动脉约 58%，少量养躯干腹盆下肢，大部分经脐动脉回胎盘交换
:::

:::insight{label="同一滴血，先给头，再给胎盘，肺几乎不经过"}
卵圆孔把较好的血送到左心和主动脉弓，头颈上肢先用；动脉导管把右心的血直接送进降主动脉，准备回胎盘。肺只接收不足 $10\%$。记住“两条短路加一对脐血管”，比背整张成体循环再删几笔更不容易画反。
:::

:::tip{label="三个百分数不要记串"}
下腔／卵圆孔约 $67\%$ → 左房；左室约 $62\%$ → 头颈上肢为主；降主动脉约 $58\%$ → 脐动脉回胎盘为主。入肺只有“不足 $10\%$”，它不是氧饱和度。
:::

:::keypoint{label="脐静脉进，卵圆孔给头，动脉导管绕肺，脐动脉回胎盘"}
- 脐静脉入胚：大部分静脉导管 → 下腔；余者肝血窦 → 下腔。
- 下腔入口对卵圆孔：大部分（约 $67\%$）入左房；小部分折回，与上腔静脉、冠状窦血混合入右室。
- 左室约 $62\%$：大部分经主动脉弓三大分支至头颈上肢。
- 肺动脉干：入肺不足 $10\%$；绝大部分动脉导管 → 降主动脉。
- 降主动脉约 $58\%$：大部分脐动脉回胎盘。
:::

## （二）胎儿出生后血液循环的变化

胎儿出生后，胎盘循环停止，肺开始呼吸，导致血液循环途径发生一系列的变化：①脐静脉闭锁形成肝圆韧带。②静脉导管闭锁形成静脉韧带。③由于肺开始工作，大量血液由肺静脉回流进入左心房，左心房压力增高；胎盘血液循环中断，下腔静脉血流量骤减，右心房的血压下降；于是卵圆孔瓣紧贴卵圆孔，卵圆孔关闭；胎儿出生后约 $1$ 年，卵圆孔完全封闭形成卵圆窝。④肺呼吸开始后，肺循环量增大，肺动脉血不再向主动脉分流，使动脉导管闭锁，形成动脉韧带。⑤脐动脉的大部分退化形成脐侧韧带，近侧段保留形成膀胱上动脉。

:::definition{label="出生后循环改道的两个前提"}
胎盘循环停止，肺开始呼吸。没有这两件事，卵圆孔瓣贴不上，动脉导管也闭不了。
:::

:::definition{label="脐静脉 → 肝圆韧带"}
①脐静脉闭锁形成肝圆韧带。闭锁的是出生前一直保留的左脐静脉脐至肝段。
:::

:::definition{label="静脉导管 → 静脉韧带"}
②静脉导管闭锁形成静脉韧带。它不再把脐静脉血导入下腔静脉。
:::

:::definition{label="卵圆孔 → 卵圆窝"}
③肺开始工作，大量肺静脉血回左心房，左心房压力增高；胎盘循环中断，下腔静脉血流量骤减，右心房血压下降；卵圆孔瓣紧贴卵圆孔，卵圆孔关闭。胎儿出生后约 $1$ 年，卵圆孔完全封闭形成卵圆窝。先是瓣贴上（功能性关闭），约 $1$ 年才完全封闭（解剖性关闭）。
:::

:::definition{label="动脉导管 → 动脉韧带"}
④肺呼吸开始后，肺循环量增大，肺动脉血不再向主动脉分流，使动脉导管闭锁，形成动脉韧带。它来自左侧第 $6$ 弓远侧段。
:::

:::definition{label="脐动脉 → 脐侧韧带与膀胱上动脉"}
⑤脐动脉的大部分退化形成脐侧韧带，近侧段保留形成膀胱上动脉。不是整条脐动脉都变成韧带。
:::

:::concept{term="先问胎盘停了、肺开始呼吸没有，再问五条遗迹各是哪条管道闭锁的"}
看见出生后循环，先确认两个前提：胎盘循环停止，肺开始呼吸。再对五条账：脐静脉 → 肝圆韧带；静脉导管 → 静脉韧带；卵圆孔约 $1$ 年完全封闭 → 卵圆窝（机制是左房压升高、右房压下降，卵圆孔瓣紧贴）；动脉导管 → 动脉韧带（肺循环量增大，肺动脉不再向主动脉分流）；脐动脉大部分 → 脐侧韧带，近侧段 → 膀胱上动脉。把卵圆孔写成“出生当天就长成卵圆窝”，或把脐动脉整条写成韧带而丢掉膀胱上动脉，五条遗迹会对不齐。
:::

:::compare{title="出生后五条管道的遗迹"}
| 出生前 | 出生后 | 机制要点 |
|--------|--------|----------|
| 脐静脉（左，脐至肝段） | 肝圆韧带 | 胎盘循环停止后闭锁 |
| 静脉导管 | 静脉韧带 | 闭锁，不再导入下腔 |
| 卵圆孔（第一房间隔为瓣） | 约 $1$ 年完全封闭，成卵圆窝 | 左房压升高，右房压下降，瓣紧贴卵圆孔 |
| 动脉导管 | 动脉韧带 | 肺循环量增大，肺动脉不再向主动脉分流 |
| 脐动脉 | 大部分 → 脐侧韧带；近侧段 → 膀胱上动脉 | 大部分退化，近侧保留 |
:::

:::derivation{title="卵圆孔为什么能贴上，又为什么要大约1年才成卵圆窝"}
肺一工作，肺静脉把大量血送回左心房，左房压力升高。同时胎盘循环中断，下腔静脉血流量骤减，右心房血压下降。原来右高左低、允许右向左过卵圆孔的压差反过来，薄而软的卵圆孔瓣被压向第二房间隔，紧贴卵圆孔，血流立刻走不通（功能性关闭）。两侧隔逐渐融合，约 $1$ 年才完全封闭，留下卵圆窝（解剖性关闭）。只写“出生后卵圆孔消失”，会漏掉压力差和一年时限。
:::

:::cause-effect{title="肺呼吸与胎盘停止，改写五条通路"}
- 因：胎盘循环停止
- 果：脐静脉、脐动脉无血流可走，分别闭锁或大部分退化；下腔静脉血流量骤减，右房压下降
- 因：肺开始呼吸，肺循环量增大，大量肺静脉血回左房
- 果：左房压升高，卵圆孔瓣紧贴卵圆孔；肺动脉不再经动脉导管向主动脉分流，导管闭锁
- 制约：卵圆孔约 1 年才完全封闭成卵圆窝；脐动脉近侧段保留为膀胱上动脉
:::

:::pitfall{label="卵圆孔关闭不等于当天变成卵圆窝"}
出生后卵圆孔瓣紧贴卵圆孔，血流先停。完全封闭形成卵圆窝大约要 $1$ 年。写成“娩出即成卵圆窝”，功能性关闭和解剖性关闭会并成一步。
:::

:::pitfall{label="脐动脉不是整条都变成脐侧韧带"}
大部分退化形成脐侧韧带，近侧段保留形成膀胱上动脉。本章小结把这条遗迹写作“脐外侧韧带”，与正文“脐侧韧带”指同一条脐动脉大部分退化后的遗迹，不要另造一条血管。
:::

:::note{label="五条遗迹和本章小结一一对应"}
本章小结把胎儿特有结构记成 $5$ 个：脐动脉、脐静脉、动脉导管、静脉导管、卵圆孔。出生后分别为脐外侧韧带（正文：脐侧韧带）、肝圆韧带、动脉韧带、静脉韧带和卵圆窝。近侧脐动脉留下的膀胱上动脉写在正文⑤，小结未单列。
:::

:::insight{label="短路是胎儿用的，韧带是出生后留下的地址"}
静脉导管、卵圆孔、动脉导管三条短路，加上一对脐血管，构成胎儿循环。出生后它们并不“消失得无影无踪”，而是变成肝圆韧带、静脉韧带、卵圆窝、动脉韧带和脐侧韧带（近侧还留膀胱上动脉）。把遗迹和胎儿结构对上号，畸形那一节的卵圆孔未闭、动脉导管未闭才有“该闭未闭”的地点。
:::

:::timeline{period="出生后循环改道"}
- **两个前提** 胎盘循环停止；肺开始呼吸
- **①脐静脉** 闭锁 → 肝圆韧带
- **②静脉导管** 闭锁 → 静脉韧带
- **③卵圆孔** 左房压升高、右房压下降，瓣紧贴；约 1 年完全封闭 → 卵圆窝
- **④动脉导管** 肺循环量增大，不再向主动脉分流，闭锁 → 动脉韧带
- **⑤脐动脉** 大部分 → 脐侧韧带；近侧段 → 膀胱上动脉
:::

:::tip{label="出生后五条口诀"}
脐静脉肝圆韧带，静脉导管静脉韧带，卵圆孔一年成窝，动脉导管动脉韧带，脐动脉大部分脐侧韧带、近侧膀胱上动脉。
:::

:::keypoint{label="胎盘停、肺开呼吸；五条管道变成韧带或卵圆窝"}
- 前提：胎盘循环停止，肺开始呼吸。
- 脐静脉 → 肝圆韧带；静脉导管 → 静脉韧带。
- 卵圆孔：左房压↑、右房压↓，瓣紧贴；约 $1$ 年完全封闭 → 卵圆窝。
- 动脉导管闭锁 → 动脉韧带。
- 脐动脉大部分 → 脐侧韧带，近侧段 → 膀胱上动脉。
:::

:::memory{label="本节必背要点"}
- [ ] 来自胎盘、富含氧和营养物质的血液经脐静脉进入胚体。
- [ ] 大部分血液在肝内经静脉导管进入下腔静脉，余者流经肝血窦注入下腔静脉。
- [ ] 下腔静脉还收集来自下肢、盆腔和腹腔回流的血液。
- [ ] 下腔静脉在右心房的入口正对卵圆孔。
- [ ] 大部分下腔静脉血（氧饱和度约为 $67\%$）直接通过卵圆孔进入左心房。
- [ ] 小部分折回，与右心房内来自上腔静脉和冠状窦的血液混合后进入右心室。
- [ ] 左心房内还有少量来自肺静脉的血液，二者混合后进入左心室。
- [ ] 左心室血液（氧饱和度约为 $62\%$）大部分经主动脉弓的三大分支供应头颈和上肢，以适应其发育，余者进入降主动脉。
- [ ] 右心室血液进入肺动脉干。
- [ ] 胚胎时期肺尚未执行功能，肺动脉干血液仅有小部分（不足 $10\%$）进入肺。
- [ ] 其余绝大部分经动脉导管注入降主动脉。
- [ ] 降主动脉血液（氧饱和度约为 $58\%$）除少量供应躯干、腹部和盆腔器官以及下肢外，均经脐动脉流入胎盘，与母体血液进行气体和物质交换。
- [ ] 出生后：胎盘循环停止，肺开始呼吸。
- [ ] ①脐静脉闭锁形成肝圆韧带。
- [ ] ②静脉导管闭锁形成静脉韧带。
- [ ] ③肺开始工作，大量肺静脉血回左心房，左心房压力增高；胎盘循环中断，下腔静脉血流量骤减，右心房血压下降。
- [ ] 卵圆孔瓣紧贴卵圆孔，卵圆孔关闭；出生后约 $1$ 年完全封闭形成卵圆窝。
- [ ] ④肺循环量增大，肺动脉血不再向主动脉分流，动脉导管闭锁形成动脉韧带。
- [ ] ⑤脐动脉大部分退化形成脐侧韧带，近侧段保留形成膀胱上动脉。
:::
