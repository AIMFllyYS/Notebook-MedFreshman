# 二、致密结缔组织

致密结缔组织（dense connective tissue）以纤维为主要成分而细胞较少，纤维粗大，排列致密，以支持、连接和保护为主要功能。它和疏松结缔组织共用同一套细胞与纤维种类，差别在密度和排列：疏松结缔组织细胞种类多、纤维稀疏；致密结缔组织把纤维加粗、排紧，细胞和基质都相应减少。根据纤维的性质和排列方式，可分为规则致密结缔组织、不规则致密结缔组织和弹性组织。

:::definition{label="致密结缔组织"}
致密结缔组织（dense connective tissue）以纤维为主要成分而细胞较少，纤维粗大，排列致密，以支持、连接和保护为主要功能。按纤维的性质和排列方式分为规则致密结缔组织、不规则致密结缔组织和弹性组织。
:::

:::concept{term="先问应力从几个方向来"}
纤维跟着应力走。应力长期沿着一个方向拉，胶原纤维就平行成束，写成肌腱、腱膜和大部分韧带；应力从不同方向来，胶原纤维束就纵横交织成三维网，写成真皮、硬脑膜和器官被膜；若器官还要反复回弹，主纤维就换成弹性纤维，写成黄韧带、项韧带、声带和阴茎悬韧带。看见致密结缔组织，先问拉力的方向，再问纤维是胶原还是弹性蛋白。
:::

:::pitfall{label="致密结缔组织不是“没有细胞”，更不是骨"}
致密只是纤维粗、排得紧，细胞和基质都少，但腱细胞、成纤维细胞仍然夹在纤维束之间。不要把它记成无细胞的纤维块，也不要和软骨、骨那种特殊结缔组织混为一谈：后两者有独特的细胞外基质（坚硬或具有一定硬度），本章的致密结缔组织仍属固有结缔组织。
:::

## 1. 规则致密结缔组织

规则致密结缔组织（dense regular connective tissue）主要构成肌腱、腱膜和大部分的韧带，使骨骼肌附着于骨。其大量密集的胶原纤维聚集成束，顺着应力方向平行排列，抗牵拉力强。纤维束之间有腱细胞（tenocyte），是一种形态特殊的成纤维细胞，胞体伸出多个薄翼状突起嵌入纤维束之间（图 3-15）。纵切面上，胶原纤维束平行、波浪状走行，腱细胞的核呈长杆状、顺着纤维方向排列；横切面上，翼状突起把相邻纤维束隔开。

:::definition{label="规则致密结缔组织"}
规则致密结缔组织（dense regular connective tissue）主要构成肌腱、腱膜和大部分韧带，使骨骼肌附着于骨。大量密集的胶原纤维聚集成束，顺着应力方向平行排列，抗牵拉力强。纤维束之间有腱细胞。
:::

:::definition{label="腱细胞"}
腱细胞（tenocyte）是一种形态特殊的成纤维细胞，位于规则致密结缔组织的纤维束之间，胞体伸出多个薄翼状突起嵌入纤维束之间，维持并更新胶原纤维。
:::

## 2. 不规则致密结缔组织

不规则致密结缔组织（dense irregular connective tissue）主要构成真皮、硬脑膜及多数器官的被膜，其特点是粗大的胶原纤维（束）纵横交织，形成致密的三维网状结构，抵抗来自不同方向的应力。纤维（束）之间含少量基质和（成）纤维细胞（图 3-16）。与规则型相比，这里的“不规则”指的是纤维束走向不平行，而不是结构杂乱无章：三维交织本身就是为了把各个方向的拉力接下来。

:::definition{label="不规则致密结缔组织"}
不规则致密结缔组织（dense irregular connective tissue）主要构成真皮、硬脑膜及多数器官的被膜。粗大的胶原纤维（束）纵横交织，形成致密的三维网状结构，抵抗来自不同方向的应力。纤维束之间含少量基质和（成）纤维细胞。
:::

## 3. 弹性组织

弹性组织（elastic tissue）是以弹性纤维为主的致密结缔组织。粗大的弹性纤维平行排列成束，如黄韧带和项韧带，以适应脊柱运动。弹性组织还构成声带和阴茎悬韧带。弹性纤维间有少量的胶原纤维和（成）纤维细胞。弹性纤维提供回弹，少量胶原纤维限制过度牵拉，二者搭配才能既活动、又不至于被拉断。

:::definition{label="弹性组织"}
弹性组织（elastic tissue）是以弹性纤维为主的致密结缔组织。粗大的弹性纤维平行排列成束，见于黄韧带和项韧带（适应脊柱运动），也构成声带和阴茎悬韧带。弹性纤维间有少量胶原纤维和（成）纤维细胞。
:::

:::compare{title="规则致密、不规则致密与弹性组织"}
| 项目 | 规则致密结缔组织 | 不规则致密结缔组织 | 弹性组织 |
|------|------------------|---------------------|----------|
| 主纤维 | 胶原纤维 | 胶原纤维 | 弹性纤维（间有少量胶原纤维） |
| 排列 | 聚集成束，沿应力方向平行 | 粗大纤维束纵横交织成三维网 | 粗大弹性纤维平行成束 |
| 细胞 | 腱细胞（特殊的成纤维细胞），薄翼状突起嵌入纤维束之间 | 少量（成）纤维细胞 | 少量（成）纤维细胞 |
| 基质 | 很少 | 少量 | 很少 |
| 力学 | 抗单一方向的牵拉力强 | 抵抗来自不同方向的应力 | 富弹性，适应反复牵拉与回弹 |
| 分布 | 肌腱、腱膜、大部分韧带 | 真皮、硬脑膜、多数器官被膜 | 黄韧带、项韧带、声带、阴茎悬韧带 |
| 功能场景 | 骨骼肌附着于骨 | 皮肤和器官承受多向拉力 | 脊柱运动、发声、阴茎悬吊 |
:::

:::note{label="三种致密结缔组织的辨认口诀"}
- 平行胶原 + 腱细胞翼状突起 → 肌腱/腱膜/韧带（规则）。
- 胶原束纵横交织 + 细胞很少 → 真皮/硬脑膜/器官被膜（不规则）。
- 粗大弹性纤维成束 + 少量胶原和成纤维细胞 → 黄韧带、项韧带、声带、阴茎悬韧带（弹性组织）。
:::

:::keypoint{label="致密结缔组织按纤维性质和排列分三型"}
- 致密结缔组织纤维粗、细胞少、排列密，主要功能是支持、连接和保护。
- 规则型：胶原纤维沿应力方向平行成束，腱细胞以薄翼状突起嵌入束间；构成肌腱、腱膜和大部分韧带。
- 不规则型：胶原纤维束三维交织，抗多向应力；构成真皮、硬脑膜和多数器官被膜。
- 弹性组织：以平行成束的弹性纤维为主，适应脊柱运动等反复牵拉；构成黄韧带、项韧带、声带和阴茎悬韧带。
:::
