# 二、先天畸形的发生原因

先天畸形的发生原因包括遗传因素、环境因素以及两者的相互作用。遗传侧先问染色体数目、染色体结构还是基因突变；环境侧把致畸因子按生物、物理、药物、化学和其他五类列全；相互作用再问两面：环境能不能引起染色体畸变和基因突变，以及胚胎的遗传特性怎样决定对致畸因子的易感程度。分类十条见上一节，致畸敏感期见下一节。

先天畸形的发生原因包括遗传因素、环境因素以及两者的相互作用。

:::definition{label="先天畸形的三类原因"}
先天畸形的发生原因包括遗传因素、环境因素以及两者的相互作用。多数畸形不能只写在遗传或只写在环境一边。
:::

:::concept{term="先问是染色体、基因还是环境五类，再问两者是否在相互作用"}
看见原因，先不要写成“都是遗传”或“都是环境”。遗传先切染色体畸变（数目／结构）和基因突变；环境先对致畸因子五类，并记住它通过外环境、母体内环境和胚体微环境三条路径起作用。对不上单因素，再问相互作用：环境有没有引起畸变或突变，胚胎遗传特性有没有改变易感性。遗传度是衡量遗传因素作用大小的指标，不是“全由遗传”。
:::

## （一）遗传因素

引起先天畸形的遗传因素包括染色体畸变和基因突变。

:::definition{label="遗传因素的两份"}
引起先天畸形的遗传因素包括染色体畸变和基因突变。先问看得见的染色体外形，再问 DNA 碱基组成或排列。
:::

### 1. 染色体畸变

染色体畸变包括染色体数目的变化和染色体结构的异常。

:::definition{label="染色体畸变"}
染色体畸变包括染色体数目的变化和染色体结构的异常。数目和结构是两本账，不要并成“染色体出了问题”。
:::

（1）染色体数目的异常：细胞分裂过程中，染色体分离障碍所致，在精子发生、卵子发生以及受精卵发生卵裂过程中均可出现，包括整倍体和非整倍体。

:::definition{label="染色体数目异常"}
染色体数目异常由细胞分裂过程中染色体分离障碍所致。精子发生、卵子发生以及受精卵卵裂过程中均可出现，包括整倍体和非整倍体。
:::

:::definition{label="整倍体与非整倍体"}
整倍体是整套染色体的增减；非整倍体是个别染色体数目异常。二者都来自分离障碍，出现窗口可以在配子发生，也可以在受精卵卵裂。
:::

（2）染色体结构的异常：由于染色体断裂后发生了染色体缺失或异常的结构重组而引起的染色体结构畸变，如 $5$ 号染色体短臂末端断裂缺失可引起猫叫综合征。电离辐射、化学物质、病毒等都可能导致染色体结构的畸变而引起畸形。

:::definition{label="染色体结构异常"}
染色体结构异常是染色体断裂后发生缺失或异常的结构重组。教材举例：$5$ 号染色体短臂末端断裂缺失可引起猫叫综合征。
:::

:::definition{label="可引起染色体结构畸变的因子"}
电离辐射、化学物质、病毒等都可能导致染色体结构的畸变而引起畸形。环境因子可以先打在染色体结构上，再表现为畸形——这已进入后面“相互作用”的第一面。
:::

:::compare{title="染色体数目异常与结构异常"}
| 项目 | 数目异常 | 结构异常 |
|------|----------|----------|
| 机制 | 细胞分裂时染色体分离障碍 | 染色体断裂后缺失或异常重组 |
| 可发生窗口 | 精子发生、卵子发生、受精卵卵裂 | 断裂与错误重接发生当时 |
| 类型 | 整倍体、非整倍体 | 缺失、异常结构重组等 |
| 教材例 | — | $5$ 号染色体短臂末端断裂缺失 → 猫叫综合征 |
| 环境可诱发 | — | 电离辐射、化学物质、病毒等可导致结构畸变 |
:::

:::pitfall{label="数目异常可以出在精子、卵子，也可以出在受精卵卵裂"}
分离障碍不是“只在减数分裂里才有”。教材写明：精子发生、卵子发生以及受精卵卵裂均可出现。把非整倍体全部写成“配子本来就少一条”，会漏掉卵裂这一段。
:::

### 2. 基因突变

基因突变指 DNA 分子碱基组成或排列顺序的改变，但染色体外形无异常。其发生次数较染色体畸变多，但引起的畸形少，主要引起微观结构和功能方面的遗传性疾病，如镰状细胞贫血、苯丙酮尿症等。

:::definition{label="基因突变"}
基因突变指 DNA 分子碱基组成或排列顺序的改变，但染色体外形无异常。核型看起来可以是正常的，乱的是碱基。
:::

:::definition{label="基因突变与畸形的数量关系"}
基因突变发生次数较染色体畸变多，但引起的畸形少。主要引起微观结构和功能方面的遗传性疾病，如镰状细胞贫血、苯丙酮尿症等。
:::

:::compare{title="染色体畸变与基因突变"}
| 项目 | 染色体畸变 | 基因突变 |
|------|------------|----------|
| 看什么 | 染色体数目或结构（外形可查） | DNA 碱基组成或排列顺序 |
| 染色体外形 | 数目或结构已变 | 无异常 |
| 发生次数 | 相对较少 | 较染色体畸变多 |
| 引起的畸形 | 相对较多（形态结构畸形更常见于这一侧） | 引起的畸形少 |
| 主要疾病类型 | 如猫叫综合征（结构缺失） | 微观结构和功能遗传病，如镰状细胞贫血、苯丙酮尿症 |
:::

:::pitfall{label="突变次数多不等于畸形多，染色体外形正常不等于没有遗传问题"}
基因突变发生次数比染色体畸变多，但引起的畸形少，主要走微观结构和功能。把“染色体核型正常”写成“不是遗传因素”，会把镰状细胞贫血、苯丙酮尿症从先天异常里漏掉。
:::

:::insight{label="遗传两问：染色体看得见吗，碱基改了没有"}
看得见数目或结构，走畸变；看不见外形、只改碱基，走突变。环境里的电离辐射、化学物质、病毒可以先造成结构畸变，所以遗传和环境从这里就已经交叉。
:::

## （二）环境因素

引起先天畸形的环境因素统称致畸因子（teratogen），主要通过影响母体周围的外环境、母体的内环境以及胚体周围的微环境这 $3$ 个方面影响胚胎发育。致畸因子主要有下列 $5$ 类。

:::definition{label="致畸因子"}
引起先天畸形的环境因素统称致畸因子（teratogen）。它不是只指药物。
:::

:::definition{label="致畸因子的三条路径"}
致畸因子主要通过影响母体周围的外环境、母体的内环境以及胚体周围的微环境这 $3$ 个方面影响胚胎发育。外、内、微三层都要问到，不要只写“妈妈接触了有害物”。
:::

### 1. 生物性致畸因子

主要是指致畸微生物，目前已确定的生物性致畸因子有风疹病毒、巨细胞病毒等。

:::definition{label="生物性致畸因子"}
生物性致畸因子主要指致畸微生物。目前已确定的有风疹病毒、巨细胞病毒等。
:::

### 2. 物理性致畸因子

目前已确认各种射线尤其是离子电磁辐射、机械性压迫和损伤等对人类有致畸作用。

:::definition{label="物理性致畸因子"}
目前已确认各种射线尤其是离子电磁辐射、机械性压迫和损伤等对人类有致畸作用。射线和机械性因素是两类，不要只背辐射。
:::

### 3. 致畸性药物

主要有抗肿瘤类、抗惊厥类等药物。如抗肿瘤药物氨基蝶呤可引起胎儿无脑、小头及四肢畸形；抗惊厥药物如三甲双酮会导致胎儿智力低下、发育缓慢、面部发育不良等畸形。

:::definition{label="致畸性药物"}
致畸性药物主要有抗肿瘤类、抗惊厥类等。教材两例必须能对上药和畸形：氨基蝶呤 → 无脑、小头及四肢畸形；三甲双酮 → 智力低下、发育缓慢、面部发育不良。
:::

### 4. 致畸性化学因子

目前确认的有某些多环芳香碳氢化合物、某些亚硝基化合物、某些烷基和苯类化合物、某些含磷的农药、重金属（如铅、镉、汞）等。

:::definition{label="致畸性化学因子"}
目前确认的致畸性化学因子有：某些多环芳香碳氢化合物、某些亚硝基化合物、某些烷基和苯类化合物、某些含磷的农药、重金属（如铅、镉、汞）等。五条要列全，不要只记重金属。
:::

### 5. 其他致畸因子

酗酒、大量吸烟、咖啡因、维生素缺乏、缺氧、严重营养不良等均有致畸作用。流行病学调查显示，女性吸烟者可导致胎儿平均体重明显低于不吸烟者，且出现畸形的危险性增加，主要原因是尼古丁使胎盘血管收缩，胎儿缺血、缺氧所致。

:::definition{label="其他致畸因子"}
酗酒、大量吸烟、咖啡因、维生素缺乏、缺氧、严重营养不良等均有致畸作用。这一类不是“说不清的剩下”，教材把生活和营养因素单独列出。
:::

:::definition{label="吸烟致畸的途径"}
女性吸烟者所生胎儿平均体重明显低于不吸烟者，且出现畸形的危险性增加。主要原因是尼古丁使胎盘血管收缩，胎儿缺血、缺氧。
:::

:::compare{title="环境致畸因子的五类"}
| 类别 | 教材列出的内容 | 对题时不要漏的点 |
|------|----------------|------------------|
| 生物性 | 致畸微生物：风疹病毒、巨细胞病毒等 | 已确定的是病毒，不是所有感染都已确认致畸 |
| 物理性 | 各种射线尤其是离子电磁辐射；机械性压迫和损伤 | 辐射和机械性都算 |
| 致畸性药物 | 抗肿瘤类、抗惊厥类等；氨基蝶呤；三甲双酮 | 药名要能对上畸形谱 |
| 致畸性化学因子 | 某些多环芳香碳氢化合物、某些亚硝基化合物、某些烷基和苯类化合物、某些含磷的农药、重金属（铅、镉、汞） | 五条列全 |
| 其他 | 酗酒、大量吸烟、咖啡因、维生素缺乏、缺氧、严重营养不良 | 吸烟经尼古丁 → 胎盘血管收缩 → 缺血缺氧 |
:::

:::compare{title="氨基蝶呤与三甲双酮"}
| 项目 | 氨基蝶呤 | 三甲双酮 |
|------|----------|----------|
| 药类 | 抗肿瘤类 | 抗惊厥类 |
| 教材所列畸形 | 无脑、小头及四肢畸形 | 智力低下、发育缓慢、面部发育不良 |
:::

:::pitfall{label="药物和化学因子不要并成“吃了有毒的东西”"}
致畸性药物走抗肿瘤、抗惊厥等药，有氨基蝶呤、三甲双酮这样的对号。致畸性化学因子走多环芳香碳氢化合物、亚硝基化合物、烷基和苯类、含磷农药、铅镉汞。酗酒、吸烟、咖啡因、维生素缺乏、缺氧、严重营养不良另立“其他”。五类缺一类就算没列全。
:::

:::cause-effect{title="尼古丁收缩胎盘血管，才有低体重和畸形风险"}
- 因：女性吸烟，尼古丁使胎盘血管收缩
- 果：胎儿缺血、缺氧
- 果：平均体重明显低于不吸烟者，出现畸形的危险性增加
- 制约：这是“其他致畸因子”里教材写明的机制，不要只背“吸烟不好”
:::

:::insight{label="致畸因子打在三层环境上，五类是清单不是同义词"}
外环境、母体内环境、胚体微环境是路径；生物、物理、药物、化学、其他是清单。路径说明“怎么打到胚”，清单说明“有哪些”。只记风疹和射线，农药、铅镉汞和维生素缺乏会从清单里掉出去。
:::

## （三）环境因素与遗传因素的相互作用

多数畸形是环境因素与遗传因素相互作用的结果，主要表现在两个方面：一方面是环境致畸因子通过引起染色体畸变和基因突变而导致先天畸形；另一方面是胚胎的遗传特性决定和影响胚胎对致畸因子的易感程度。如流行病学调查显示，在同一地区同一自然条件下，同时妊娠的妇女在一次风疹流行中都受到感染，但其新生儿有的出现畸形，有的完全正常。其原因在于每个胎儿对风疹病毒的易感程度不同。在环境因素与遗传因素相互作用引起的先天畸形中，用来衡量遗传因素所起作用大小的指标称为遗传度。遗传度越高，说明遗传因素在畸形发生中的作用越大。如先天性心脏畸形的遗传度为 $35\%$，无脑儿为 $60\%$。

不同种类的致畸因素可诱发出各种各样的畸形。有时一种因素引起多种畸形，有时多种因素引起一种畸形，某种因子缺少或过多都引起畸形。

:::definition{label="相互作用的两面"}
多数畸形是环境因素与遗传因素相互作用的结果。一面：环境致畸因子通过引起染色体畸变和基因突变而导致先天畸形。另一面：胚胎的遗传特性决定和影响胚胎对致畸因子的易感程度。
:::

:::definition{label="风疹流行中的不同结局"}
同一地区、同一自然条件、同时妊娠的妇女在一次风疹流行中都受到感染，新生儿有的出现畸形，有的完全正常。原因是每个胎儿对风疹病毒的易感程度不同。这是“遗传特性决定易感性”的教材例。
:::

:::definition{label="遗传度"}
在环境因素与遗传因素相互作用引起的先天畸形中，用来衡量遗传因素所起作用大小的指标称为遗传度。遗传度越高，说明遗传因素在畸形发生中的作用越大。教材数字：先天性心脏畸形 $35\%$，无脑儿 $60\%$。
:::

:::example{label="同一场风疹，有的畸有的不畸"}
环境暴露可以相同（都感染了风疹病毒），结局可以不同。差别写在胚胎的遗传易感性上，不要写成“有的孕妇没感染”。这就是相互作用的第二面。
:::

:::compare{title="相互作用的两面与遗传度"}
| 项目 | 环境打在遗传物质上 | 遗传决定对环境的易感性 | 遗传度 |
|------|--------------------|--------------------------|--------|
| 方向 | 致畸因子 → 染色体畸变或基因突变 → 畸形 | 胚胎遗传特性 → 对同一因子易感程度不同 | 衡量相互作用中遗传因素作用的大小 |
| 教材例 | 电离辐射、化学物质、病毒导致染色体结构畸变 | 同一场风疹流行，有的新生儿畸形、有的完全正常 | 先天性心脏畸形 $35\%$；无脑儿 $60\%$ |
| 不要听成 | 有环境就不再算遗传 | 有遗传就不再算环境 | 遗传度 $60\%$ 等于“全是遗传” |
:::

:::pitfall{label="遗传度高不是“全由遗传”，低也不是“全由环境”"}
先天性心脏畸形遗传度 $35\%$，无脑儿 $60\%$，都是相互作用里遗传那一份的大小。不要把无脑儿写成纯遗传，也不要把先心病写成纯环境。风疹那一例更不能写成“感染了就一定畸”。
:::

:::note{label="一种因素多种畸形，多种因素一种畸形"}
不同种类的致畸因素可诱发出各种各样的畸形。有时一种因素引起多种畸形，有时多种因素引起一种畸形；某种因子缺少或过多都引起畸形。原因和畸形不是一对一的密码表。
:::

:::insight{label="多数畸形写在交叉处：环境能改基因，基因能改易感性"}
第一面让环境清单和染色体、基因突变接通；第二面让同一因子在不同胚胎上给出不同结局。遗传度只是给交叉处的遗传份额一个数字。把原因题做成“选遗传或选环境”，和教材“多数是相互作用”相反。
:::

:::keypoint{label="遗传看染色体和基因，环境列五类，多数是相互作用"}
- 遗传：染色体数目异常（分离障碍，整倍体／非整倍体，可在精子发生、卵子发生、卵裂中出现）；结构异常（断裂后缺失或重组，如猫叫综合征）；基因突变（碱基改变、外形无异常，次数多、畸形少）。
- 环境致畸因子经外环境、母体内环境、胚体微环境起作用，五类：生物、物理、药物、化学、其他。
- 氨基蝶呤 → 无脑、小头、四肢畸形；三甲双酮 → 智力低下、发育缓慢、面部发育不良；吸烟经尼古丁收缩胎盘血管。
- 相互作用两面：环境引起畸变／突变；遗传特性决定易感性。遗传度：先心病 $35\%$，无脑儿 $60\%$。
:::

- [ ] 遗传因素包括染色体畸变和基因突变。
- [ ] 染色体畸变包括数目变化和结构异常。
- [ ] 染色体数目异常由细胞分裂中染色体分离障碍所致，可出现于精子发生、卵子发生和受精卵卵裂，包括整倍体和非整倍体。
- [ ] 染色体结构异常由断裂后缺失或异常结构重组引起；如 $5$ 号染色体短臂末端断裂缺失可引起猫叫综合征。
- [ ] 电离辐射、化学物质、病毒等都可能导致染色体结构畸变而引起畸形。
- [ ] 基因突变指 DNA 碱基组成或排列顺序改变，染色体外形无异常。
- [ ] 基因突变发生次数较染色体畸变多，但引起的畸形少，主要引起微观结构和功能方面的遗传病，如镰状细胞贫血、苯丙酮尿症。
- [ ] 环境因素统称致畸因子（teratogen），通过母体外环境、母体内环境和胚体微环境 $3$ 个方面影响胚胎发育。
- [ ] 生物性致畸因子主要指致畸微生物，已确定的有风疹病毒、巨细胞病毒等。
- [ ] 物理性致畸因子：各种射线尤其是离子电磁辐射、机械性压迫和损伤等对人类有致畸作用。
- [ ] 致畸性药物主要有抗肿瘤类、抗惊厥类等。
- [ ] 氨基蝶呤可引起无脑、小头及四肢畸形；三甲双酮可导致智力低下、发育缓慢、面部发育不良。
- [ ] 致畸性化学因子：某些多环芳香碳氢化合物、某些亚硝基化合物、某些烷基和苯类化合物、某些含磷的农药、重金属（铅、镉、汞）等。
- [ ] 其他致畸因子：酗酒、大量吸烟、咖啡因、维生素缺乏、缺氧、严重营养不良等。
- [ ] 女性吸烟者胎儿平均体重明显低于不吸烟者，畸形危险性增加；主要因尼古丁使胎盘血管收缩，胎儿缺血、缺氧。
- [ ] 多数畸形是环境因素与遗传因素相互作用的结果。
- [ ] 相互作用一面：环境致畸因子通过引起染色体畸变和基因突变导致先天畸形。
- [ ] 相互作用另一面：胚胎的遗传特性决定和影响对致畸因子的易感程度。
- [ ] 同一场风疹流行中都受感染，新生儿有的畸形、有的完全正常，因对风疹病毒的易感程度不同。
- [ ] 遗传度衡量相互作用中遗传因素作用的大小；越高说明遗传因素作用越大。
- [ ] 先天性心脏畸形遗传度为 $35\%$，无脑儿为 $60\%$。
- [ ] 一种因素可引起多种畸形，多种因素可引起一种畸形；某种因子缺少或过多都可引起畸形。
