# 三、脊髓

脊髓横切面把中枢的灰白账写成与大脑相反的格局：灰质居中呈蝴蝶形，白质围在四周。前角、后角、侧角再把多极神经元按躯体运动、感觉接线和内脏运动分开。反射弧在上一章已经立过感觉、中间、运动三类神经元；本节把这三类具体落到脊髓灰质和上、下行纤维束上。

## （一）脊髓的结构

脊髓横切面中央有蝴蝶形的灰质，周围是白质（图 8-9）。灰质分前角、后角和侧角（侧角主要见于胸腰段脊髓），其主要成分是多极神经元的胞体、树突、无髓神经纤维和神经胶质细胞。前角内多数是躯体运动神经元，大小不一。大的神经元称 $\alpha$ 运动神经元，其胞体平均直径大于 $25\,\mu\mathrm{m}$，轴突较粗，分布到骨骼肌；小的神经元称 $\gamma$ 运动神经元，其胞体直径 $15\sim 25\,\mu\mathrm{m}$，轴突较细，支配肌梭内的肌纤维。这两种运动神经元释放的神经递质为乙酰胆碱。另有一种称闰绍细胞（Ranshaw cell）的小神经元，其短轴突与 $\alpha$ 运动神经元的胞体形成突触，通过释放甘氨酸抑制 $\alpha$ 运动神经元的活动。侧角内是内脏运动神经元，也属胆碱能神经元，其轴突组成交感神经系统的节前纤维终止于交感神经节，与节内神经元建立突触。

后角内的神经元类型较复杂，但它们主要接受感觉神经元轴突传入的神经冲动。后角内有些神经元（称束细胞）发出长轴突进入白质，形成各种神经纤维束，上行到脑干、小脑和丘脑。脊髓灰质内还有许多中间神经元，它们的轴突长短不一，短的轴突只与同节段的束细胞和运动神经元联系，长的轴突可在白质内上下穿行，到相邻或较远的脊髓节段，终止于同侧或对侧的神经元，但都不离开脊髓。

:::definition{label="脊髓灰质"}
脊髓横切面中央有蝴蝶形的灰质，被周围的白质包围。灰质分前角、后角和侧角（侧角主要见于胸腰段），主要成分是多极神经元的胞体、树突、无髓神经纤维和神经胶质细胞。
:::

:::definition{label="脊髓白质"}
脊髓白质位于灰质周围，主要由上、下行神经纤维束构成。后角束细胞的长轴突进入白质形成上行纤维束；中间神经元的长轴突也可在白质内上下穿行，但不离开脊髓。
:::

:::definition{label="前角"}
前角内多数是躯体运动神经元，大小不一，属多极神经元。大者为 $\alpha$ 运动神经元，小者为 $\gamma$ 运动神经元，另有释放甘氨酸的闰绍细胞。图 8-9 中 1 即前角。
:::

:::definition{label="后角"}
后角内神经元类型较复杂，主要接受感觉神经元轴突传入的神经冲动。其中束细胞发出长轴突进入白质，形成上行到脑干、小脑和丘脑的纤维束。图 8-9 中 2 即后角。
:::

:::definition{label="侧角"}
侧角主要见于胸腰段脊髓，内含内脏运动神经元，属胆碱能神经元。轴突组成交感神经系统的节前纤维，终止于交感神经节，与节内神经元建立突触。
:::

:::definition{label="α 运动神经元"}
$\alpha$ 运动神经元是前角内大的躯体运动神经元，胞体平均直径大于 $25\,\mu\mathrm{m}$，轴突较粗，分布到骨骼肌，释放乙酰胆碱。
:::

:::definition{label="γ 运动神经元"}
$\gamma$ 运动神经元是前角内小的躯体运动神经元，胞体直径 $15\sim 25\,\mu\mathrm{m}$，轴突较细，支配肌梭内的肌纤维，释放乙酰胆碱。
:::

:::definition{label="闰绍细胞"}
闰绍细胞（Ranshaw cell）是前角内的小神经元。短轴突与 $\alpha$ 运动神经元的胞体形成突触，通过释放甘氨酸抑制 $\alpha$ 运动神经元的活动。教材用 Ranshaw 这一拼写；文献中此细胞更常写作 Renshaw cell。
:::

:::definition{label="束细胞"}
束细胞是后角内发出长轴突进入白质的神经元。轴突形成各种神经纤维束，上行到脑干、小脑和丘脑，把感觉信息传递出脊髓。
:::

:::definition{label="脊髓中间神经元"}
脊髓灰质内有许多中间神经元，轴突长短不一：短的只与同节段的束细胞和运动神经元联系；长的可在白质内上下穿行，到相邻或较远的脊髓节段，终止于同侧或对侧的神经元，但都不离开脊髓。
:::

:::concept{term="先问角的朝向：前角出运动，后角接感觉，侧角走内脏"}
蝴蝶形灰质的两只“前爪”是前角，堆躯体运动神经元，轴突出前根到骨骼肌或肌梭；两只“后爪”是后角，接脊神经节中枢突传来的感觉；胸腰段多出来的侧角走交感节前纤维。白质围在外面，是上、下行的高速公路。把前角听成“前面的感觉核”，反射弧的传入、传出方向会整条反写。
:::

:::compare{title="前角、后角与侧角"}
| 项目 | 前角 | 后角 | 侧角 |
|------|------|------|------|
| 主要细胞 | $\alpha$、$\gamma$ 躯体运动神经元；闰绍细胞 | 类型复杂；含束细胞及多种中间神经元 | 内脏运动神经元 |
| 信息方向 | 传出到骨骼肌、肌梭 | 接受感觉传入；部分经束细胞上行 | 交感节前纤维 → 交感神经节 |
| 递质线索 | $\alpha$、$\gamma$ 为乙酰胆碱；闰绍细胞为甘氨酸 | 主要作为感觉接替与局部整合 | 胆碱能 |
| 节段特点 | 全长都有 | 全长都有 | 主要见于胸腰段 |
| 图 8-9 | 1 | 2 | 胸腰段灰质侧方突出（本图为横切全貌） |
:::

:::compare{title="前角三种神经元"}
| 项目 | $\alpha$ 运动神经元 | $\gamma$ 运动神经元 | 闰绍细胞 |
|------|---------------------|---------------------|----------|
| 大小 | 大，胞体平均直径 $>25\,\mu\mathrm{m}$ | 小，直径 $15\sim 25\,\mu\mathrm{m}$ | 更小 |
| 轴突 | 较粗，分布到骨骼肌 | 较细，支配肌梭内的肌纤维 | 短轴突，终于 $\alpha$ 胞体 |
| 递质 | 乙酰胆碱 | 乙酰胆碱 | 甘氨酸（抑制 $\alpha$） |
| 功能 | 引起骨骼肌收缩 | 调节肌梭敏感度 | 负反馈抑制 $\alpha$，防止过度放电 |
:::

:::pitfall{label="α 和 γ 都是胆碱能，不要把 γ 写成传入神经元"}
肌梭本身是感受器，但支配梭内肌纤维的 $\gamma$ 运动神经元仍是前角的传出细胞，递质同样是乙酰胆碱。感觉神经元的胞体在脊神经节，中枢突进后角，不进前角当 $\gamma$。另：闰绍细胞释放甘氨酸，是抑制性中间神经元，不要把它算进“大、中、小三种都出轴突到肌”的运动名单——本章小结把最小的一种单独写成闰绍细胞，正是为了把这本抑制账留住。
:::

:::compare{title="束细胞与脊髓中间神经元"}
| 项目 | 束细胞 | 脊髓中间神经元 |
|------|--------|----------------|
| 位置 | 后角 | 灰质内广泛存在 |
| 轴突 | 长，进入白质形成纤维束 | 长短不一 |
| 是否离开脊髓 | 上行到脑干、小脑和丘脑 | 短者留在同节段；长者在白质上下穿行至其他节段，终止于同侧或对侧，但不离开脊髓 |
| 职分 | 把感觉信息送出脊髓 | 节段内或节段间的加工与联系 |
:::

:::insight{label="脊髓灰质在内、皮质灰质在外，是同一本胞体账的两种排法"}
大脑、小脑把胞体铺在表面成皮质，纤维收到深部成白质；脊髓把胞体收到中央成蝴蝶，纤维铺在外周成白质。神经核则是白质里再出现的胞体团块。三种排法都遵守“胞体集中称灰质、纤维集中称白质”，只是灰质放在外、放在中，还是埋成团，随部位而变。
:::

## （二）脊髓的功能

脊髓主要的功能是传导上、下行神经冲动和进行反射活动。

:::definition{label="脊髓的功能"}
脊髓主要的功能是传导上、下行神经冲动和进行反射活动。上行靠后角束细胞进入白质的纤维束；下行纤维束把高级中枢的冲动送到前角和侧角的运动神经元；反射活动在灰质的感觉接替、中间神经元和运动神经元之间完成。
:::

:::concept{term="先问这根纤维是路过，还是在本节能回头"}
传导账：白质里的上、下行纤维束把冲动从脊髓送到脑，或从脑送到效应器侧的运动神经元。反射账：冲动在后角被接住，经中间神经元转到同节段或邻节段的运动神经元，不必出脊髓就能形成反射。束细胞的轴突离开脊髓上行，中间神经元的轴突即使走白质也不离开脊髓——“出不出脊髓”是这两类细胞的分界。
:::

:::pitfall{label="中间神经元走白质不等于它变成了束细胞"}
长的中间神经元可以在白质内上下穿行到较远节段，看起来像纤维束，但终点仍是脊髓内的神经元，并不上行到脑干、小脑或丘脑。只有束细胞把感觉信息送出脊髓。把所有进入白质的轴突都叫上行传导束，节段间联系和长传导束会并成一本假账。
:::

:::keypoint{label="脊髓灰质按角分功能，白质管传导，灰质里完成反射"}
- 灰质居中呈蝴蝶形，白质在外；侧角主要见于胸腰段。
- 前角：$\alpha$（$>25\,\mu\mathrm{m}$，骨骼肌）和 $\gamma$（$15\sim 25\,\mu\mathrm{m}$，肌梭）为胆碱能躯体运动；闰绍细胞以甘氨酸抑制 $\alpha$。
- 侧角：内脏运动，胆碱能，交感节前纤维 → 交感神经节。
- 后角接感觉；束细胞上行至脑干、小脑、丘脑；中间神经元不离开脊髓。
- 功能：传导上、下行冲动 + 反射活动。
:::
