# 五、神经纤维和神经

第四节把成体神经干细胞立住以后，本节沿轴突把“线路”摊开：神经纤维由长轴突及其外面的神经胶质细胞构成，再由纤维集成神经。先问有没有髓鞘、髓鞘是施万细胞还是少突胶质细胞做的，再问神经外膜、束膜和内膜这三层结缔组织支架。

## （一）神经纤维

神经纤维（nerve fiber）由神经元的长轴突及包绕它的神经胶质细胞构成。根据神经胶质细胞是否形成髓鞘（myelin sheath），可将其分为有髓神经纤维（myelinated nerve fiber）和无髓神经纤维（unmyelinated nerve fiber）两类（图 7-16）。

:::definition{label="神经纤维"}
神经纤维（nerve fiber）由神经元的长轴突及包绕它的神经胶质细胞构成。它不是“一条神经”，也不是轴突本身的别名：缺了外包的胶质，就不叫神经纤维。
:::

:::definition{label="髓鞘"}
髓鞘（myelin sheath）是神经胶质细胞的细胞膜多层同心卷绕轴突形成的板层结构。周围神经系统由施万细胞形成，中枢神经系统由少突胶质细胞形成。
:::

:::definition{label="有髓神经纤维"}
有髓神经纤维（myelinated nerve fiber）指外包胶质已形成髓鞘的神经纤维。周围者一个结间体对应一个施万细胞；中枢者由少突胶质细胞的突起薄膜包卷。
:::

:::definition{label="无髓神经纤维"}
无髓神经纤维（unmyelinated nerve fiber）指外包胶质不形成髓鞘的神经纤维。周围者一条纤维可含多条轴突，无郎飞结；中枢者轴突裸露走行于有髓纤维或胶质之间。
:::

:::concept{term="先问有没有髓鞘，再问这层鞘是谁卷的"}
看见一条神经纤维，先问胶质有没有把膜卷成髓鞘。有鞘的走跳跃式传导，无鞘的沿轴膜连续传导。第二问落在部位：周围找施万细胞，中枢找少突胶质细胞。把“有髓”听成“轴突自己分泌的脂肪管”，或把中枢、周围的成鞘细胞写成同一种，郎飞结、基膜和切迹三本账都会认错地方。
:::

:::compare{title="有髓神经纤维与无髓神经纤维"}
| 项目 | 有髓神经纤维 | 无髓神经纤维 |
|------|--------------|--------------|
| 髓鞘 | 有，胶质细胞膜多层同心卷绕 | 无 |
| 周围侧胶质 | 一个结间体 = 一个长卷筒状施万细胞 | 不规则长柱状施万细胞，纵沟内可含多条细轴突 |
| 中枢侧胶质 | 少突胶质细胞突起薄膜包卷，一个细胞可包多条轴突 | 无特异性胶质包裹，轴突裸露 |
| 郎飞结 | 有；结处轴膜部分裸露 | 周围侧因施万细胞衔接紧密而无结；中枢侧亦无结 |
| 传导 | 跳跃式，快；轴突越粗、鞘越厚、结间体越长则越快 | 沿轴膜连续传导，慢 |
| 绝缘 | 髓磷脂疏水，电阻高、电容低 | 无髓鞘绝缘 |
:::

### 1. 有髓神经纤维

**（1）周围神经系统的有髓神经纤维** 其施万细胞为长卷筒状，最长可达 $1\,500\,\mu\mathrm{m}$，它们一个接一个地套在轴突外面。相邻的施万细胞不连接，神经纤维上这一无髓鞘缩窄部位称郎飞结（Ranvier node），在这一部位的轴膜部分裸露。相邻两个郎飞结之间的一段神经纤维称结间体（internode），因此，一个结间体的外围部分即为一个施万细胞。在有髓神经纤维的横切面上，施万细胞可分为 3 层。中层为多层细胞膜同心卷绕（可达 50 层）形成的髓鞘，以髓鞘为界，细胞质分为内侧胞质和外侧胞质。内侧胞质极薄，在光镜下难以分辨；外侧胞质可略厚，细胞核位于其中。施万细胞包在轴突的外面，其外面包有一层基膜，施万细胞最外面的一层细胞膜与基膜合称神经膜（neurilemma）。电镜下，髓鞘呈明暗相间的板层状。髓鞘的化学成分主要是脂蛋白，称髓磷脂（myelin），其中类脂约占 $80\%$，其余为蛋白质。髓鞘蛋白 0（myelin protein zero）和髓鞘碱性蛋白（myelin basic protein）对髓鞘的形成和稳定具有重要作用。HE 染色标本制备时，髓鞘中类脂被溶解，仅见少量残留的网状蛋白质（图 7-17～图 7-21）。如用锇酸固定和染色，则能保存髓磷脂，使髓鞘呈黑色，并在其纵切面上见到一些不着色的漏斗形斜裂，称髓鞘切迹（incisure of myelin）或施-兰切迹（Schmidt-Lantermann incisure），它们是施万细胞内、外侧胞质间穿越髓鞘的狭窄通道。

:::definition{label="郎飞结"}
郎飞结（Ranvier node）是相邻施万细胞（或中枢相邻髓鞘节段）不连接而留下的无髓鞘缩窄部位。此处轴膜部分裸露，能与组织液接触，是跳跃式传导的兴奋落点。
:::

:::definition{label="结间体"}
结间体（internode）是相邻两个郎飞结之间的一段神经纤维。周围有髓纤维中，一个结间体的外围部分即为一个施万细胞。
:::

:::definition{label="神经膜"}
神经膜（neurilemma）是施万细胞最外面的一层细胞膜与其外面的基膜合称。它包在髓鞘之外，不要把神经膜写成髓鞘本身。
:::

:::definition{label="髓磷脂"}
髓磷脂（myelin）是髓鞘的主要化学成分，为脂蛋白：类脂约占 $80\%$，其余为蛋白质。大量类脂使髓鞘疏水，在组织液与轴膜间起绝缘作用。
:::

:::definition{label="髓鞘蛋白 0"}
髓鞘蛋白 0（myelin protein zero）是周围有髓纤维髓鞘中的重要蛋白质，与髓鞘碱性蛋白一起，对髓鞘的形成和稳定具有重要作用。
:::

:::definition{label="髓鞘碱性蛋白"}
髓鞘碱性蛋白（myelin basic protein，MBP）对周围和中枢髓鞘的形成和稳定都有重要作用。中枢髓鞘另含蛋白脂蛋白（proteolipid protein）。
:::

:::definition{label="髓鞘切迹"}
髓鞘切迹（incisure of myelin）又称施-兰切迹（Schmidt-Lantermann incisure）。锇酸固定染色的纵切面上，呈不着色的漏斗形斜裂，是施万细胞内、外侧胞质间穿越髓鞘的狭窄通道。中枢有髓纤维髓鞘内无切迹。
:::

:::pitfall{label="HE 里髓鞘常是空晕，锇酸才把髓磷脂染成黑色"}
HE 制片时类脂被溶解，光镜下只剩少量网状蛋白质，横切面轴突周围那圈空晕或淡红网就是髓鞘被抽走脂肪以后的残迹。不要把这圈空晕写成“没有髓鞘”。锇酸能保存髓磷脂，髓鞘呈黑色，切迹才显为漏斗形斜裂。认片先问染色：HE 看轴突、核和束膜，锇酸才数切迹和结。
:::

:::pitfall{label="神经膜不是髓鞘，内侧胞质光镜下几乎看不见"}
横切面上施万细胞分三层：内侧胞质（极薄，光镜难辨）、中层髓鞘、外侧胞质（可略厚，核在其中）。神经膜是最外层细胞膜加基膜。把神经膜、髓鞘、神经内膜三张皮写成同一层，再生时“基膜管还在”那本账就无处可挂。
:::

在有髓神经纤维的形成过程中，首先是伴随轴突生长，施万细胞表面凹陷成纵沟，轴突陷入纵沟，沟两侧的细胞膜贴合形成轴突系膜。此后轴突系膜不断伸长并旋转卷绕轴突，在轴突周围形成许多同心圆环绕的板层膜，即髓鞘（图 7-21）。由此可见髓鞘是由施万细胞的细胞膜构成，而细胞质被挤到髓鞘的内、外侧及两端（即靠近郎飞结处）。

:::definition{label="轴突系膜"}
轴突系膜是施万细胞表面纵沟两侧的细胞膜贴合后形成的双层膜。它不断伸长并旋转卷绕轴突，形成同心板层，即髓鞘。
:::

:::timeline{period="周围有髓纤维：施万细胞怎样把膜卷成髓鞘"}
- **凹陷成沟** 伴随轴突生长，施万细胞表面凹陷成纵沟，轴突陷入沟内
- **形成轴突系膜** 沟两侧细胞膜贴合
- **旋转卷绕** 轴突系膜伸长并旋转，在轴突周围形成许多同心圆环绕的板层膜，即髓鞘
- **胞质被挤走** 细胞质被挤到髓鞘内侧、外侧及两端（靠近郎飞结处）；切迹是内、外侧胞质间穿越髓鞘的狭窄通道
:::

:::insight{label="髓鞘是细胞膜的卷筒，不是另分泌的一条脂肪套管"}
板层来自施万细胞的细胞膜，电镜下才显明暗相间。胞质并没有消失，只是被挤到内侧、外侧和结旁。所以锇酸纵切面上那些漏斗形斜裂，是胞质通道，不是髓鞘裂开的损伤。把髓鞘听成“死的脂质管”，切迹、神经膜和后文基膜管再生都会失去细胞学来源。
:::

**（2）中枢神经系统的有髓神经纤维** 其结构与周围神经系统的有髓神经纤维基本相同，但形成髓鞘的细胞是少突胶质细胞。此外，其形成的髓鞘含有蛋白脂蛋白（proteolipid protein）和髓鞘碱性蛋白等脂蛋白。少突胶质细胞的多个突起末端的扁平薄膜可包卷多个轴突，其胞体位于神经纤维之间（图 7-22，图 7-23）。中枢有髓神经纤维外表面无基膜，髓鞘内无切迹。

:::definition{label="蛋白脂蛋白"}
蛋白脂蛋白（proteolipid protein）是中枢有髓纤维髓鞘所含的脂蛋白之一，与髓鞘碱性蛋白等共同构成中枢髓鞘的蛋白质成分。周围髓鞘强调髓鞘蛋白 0 与髓鞘碱性蛋白。
:::

:::compare{title="施万细胞与少突胶质细胞（成鞘账）"}
| 项目 | 施万细胞 | 少突胶质细胞 |
|------|----------|----------------|
| 部位 | 周围神经系统 | 中枢神经系统（脑和脊髓） |
| 形态 | 有髓纤维中呈长卷筒状，最长可达 $1\,500\,\mu\mathrm{m}$ | 胞体较小，位于神经纤维之间；多个突起末端展成薄膜 |
| 一条细胞与轴突 | 一个结间体的外围 = 一个施万细胞（一条轴突的一节） | 一个少突可包卷多条轴突 |
| 基膜 | 外表面有基膜；最外层细胞膜 + 基膜 = 神经膜 | 中枢有髓纤维外表面无基膜 |
| 髓鞘切迹 | 有（施-兰切迹） | 无 |
| 髓鞘蛋白 | 髓鞘蛋白 0、髓鞘碱性蛋白 | 蛋白脂蛋白、髓鞘碱性蛋白 |
| 再生相关 | 基膜管 + 施万细胞索诱导轴突再生（第七节） | 无基膜管；中枢再生困难 |
:::

:::pitfall{label="中枢有髓纤维外面没有基膜，髓鞘里也没有切迹"}
周围和中枢的有髓纤维在“板层包轴突、有郎飞结”上基本相同，差别写在细胞和表面：中枢换成少突、一个细胞包多条轴突、外无基膜、鞘内无切迹。把中枢白质里的纤维也画上一层神经膜，后文“中枢没有基膜管所以难再生”就无法落笔。
:::

### 2. 无髓神经纤维

**（1）周围神经系统的无髓神经纤维** 其施万细胞为不规则的长柱状，表面有数量不等、深浅不同的纵行凹沟，纵沟内有较细的轴突，施万细胞的膜不形成髓鞘。因此，一条无髓神经纤维可含多条轴突。由于相邻的施万细胞衔接紧密，故无郎飞结（图 7-24）。

**（2）中枢神经系统的无髓神经纤维** 轴突外面没有特异性的神经胶质细胞包裹，轴突裸露地走行于有髓神经纤维或神经胶质细胞之间。

:::definition{label="周围无髓神经纤维"}
周围无髓神经纤维由不规则长柱状施万细胞包裹：表面纵沟数量不等、深浅不同，沟内嵌较细的轴突，膜不卷成髓鞘。一条无髓神经纤维可含多条轴突；相邻施万细胞衔接紧密，无郎飞结。
:::

:::definition{label="中枢无髓神经纤维"}
中枢无髓神经纤维的轴突外面没有特异性的神经胶质细胞包裹，轴突裸露地走行于有髓神经纤维或神经胶质细胞之间。
:::

:::note{label="图7-24 大鼠脊神经背根横切面电镜像（原图文件为空，此处只保留教材信息）"}

:::compare{title="周围无髓与中枢无髓"}
| 项目 | 周围无髓神经纤维 | 中枢无髓神经纤维 |
|------|------------------|------------------|
| 胶质 | 施万细胞（不规则长柱状，纵沟嵌轴突） | 无特异性胶质包裹 |
| 一条纤维内的轴突 | 可含多条较细轴突 | 轴突各自裸露走行 |
| 郎飞结 | 无（施万细胞衔接紧密） | 无 |
| 基膜 | 施万细胞外仍有基膜 | 无相当于神经膜的基膜套 |
| 传导 | 沿轴膜连续传导，慢 | 沿轴膜连续传导，慢 |
:::

:::pitfall{label="一条周围无髓纤维不等于一条轴突"}
周围有髓纤维：一个结间体外面是一个施万细胞，里面通常是一条轴突。周围无髓纤维反过来：一个施万细胞用多条纵沟同时托着多条细轴突，整条“无髓神经纤维”里可以有许多轴突。把无髓听成“一根轴突外面什么都没有”，只适用于中枢无髓，不适用于周围。
:::

神经纤维的功能是传导神经冲动，这种电流的传导是在轴膜进行的。有髓神经纤维的神经冲动呈跳跃式传导，故传导速度快。这是由于有髓神经纤维的髓鞘含大量类脂而具有疏水性，在组织液与轴膜间起绝缘作用。另外，髓鞘的电阻比轴膜高得多，而电容却很低，电流只能使郎飞结处的轴膜（能与组织液接触）产生兴奋，所以轴突起始段产生的神经冲动必须通过郎飞结处的轴膜传导，从一个郎飞结跳到下一个郎飞结。有髓神经纤维的轴突越粗，其髓鞘也越厚，结间体越长，神经冲动跳跃的距离便越大，传导速度越快。无髓神经纤维因无髓鞘和郎飞结，神经冲动只能沿轴膜连续传导，故传导速度慢。

:::definition{label="跳跃式传导"}
跳跃式传导是有髓神经纤维上神经冲动的传导方式：髓鞘绝缘，电流只能使郎飞结处裸露的轴膜兴奋，冲动从一个郎飞结跳到下一个郎飞结，故传导速度快。
:::

:::definition{label="连续传导"}
连续传导是无髓神经纤维上神经冲动的传导方式：无髓鞘和郎飞结，冲动只能沿轴膜逐段连续传导，故传导速度慢。电流的传导部位仍是轴膜，不是轴质。
:::

:::concept{term="先问兴奋落在哪一段轴膜"}
冲动不在髓鞘里走，也不在轴质里流，教材写明电流的传导是在轴膜进行的。有髓纤维把可兴奋膜收成一串郎飞结，结间体越长跳得越远；无髓纤维整段轴膜都要依次去极化。轴突越粗、鞘越厚、结间体越长，跳跃距离越大、速度越快——三件事绑在一起，不要只背“有髓就快”。
:::

:::compare{title="跳跃式传导与连续传导"}
| 项目 | 跳跃式传导 | 连续传导 |
|------|------------|----------|
| 纤维类型 | 有髓神经纤维 | 无髓神经纤维 |
| 绝缘 | 髓鞘类脂疏水；电阻远高于轴膜，电容很低 | 无髓鞘绝缘 |
| 兴奋部位 | 仅郎飞结处能与组织液接触的轴膜 | 整段轴膜 |
| 路径 | 起始段 → 结 → 下一结 | 沿轴膜逐段前进 |
| 速度 | 快；轴突越粗、鞘越厚、结间体越长则越快 | 慢 |
:::

## （二）神经

周围神经系统的神经纤维集合形成神经纤维束，若干条神经纤维束聚集构成神经（nerve）。粗的神经（如坐骨神经）可含数十条神经纤维束，但分布在组织内的细小神经常常仅由一条神经纤维束构成（图 7-25）。有些神经只含感觉神经纤维或躯体运动神经纤维，但多数神经兼含二者及自主神经纤维。由于有髓神经纤维的髓鞘含髓磷脂，故肉眼观察神经通常呈白色。

包裹在神经表面的致密结缔组织称神经外膜（epineurium）。神经外膜的结缔组织延伸到神经纤维束间。神经纤维束表面有几层扁平的上皮样细胞（epithelioid cell），形成神经束膜（perineurium），这些细胞间有紧密连接，对进入神经纤维束的大分子物质起屏障作用。在神经纤维束内，每条神经纤维表面的薄层结缔组织称神经内膜（endoneurium）。在这些结缔组织中都存在小血管和淋巴管。

:::definition{label="神经"}
神经（nerve）由周围神经系统的神经纤维集合而成：纤维先集成神经纤维束，若干条束再聚成神经。粗神经（如坐骨神经）可含数十条束；组织内的细小神经常仅由一条束构成。多数神经兼含感觉、躯体运动及自主神经纤维。因髓磷脂，肉眼通常呈白色。
:::

:::definition{label="神经外膜"}
神经外膜（epineurium）是包裹在神经表面的致密结缔组织，并延伸到神经纤维束之间。
:::

:::definition{label="神经束膜"}
神经束膜（perineurium）是神经纤维束表面由几层扁平上皮样细胞形成的膜。细胞间有紧密连接，对进入神经纤维束的大分子物质起屏障作用。
:::

:::definition{label="神经内膜"}
神经内膜（endoneurium）是神经纤维束内包裹每条神经纤维表面的薄层结缔组织。神经外膜、束膜和内膜中都有小血管和淋巴管。
:::

:::definition{label="上皮样细胞"}
此处上皮样细胞（epithelioid cell）指构成神经束膜的几层扁平细胞。它们不是被覆上皮，但细胞间有紧密连接，使束膜能阻挡大分子进入神经纤维束。
:::

:::compare{title="神经外膜、神经束膜与神经内膜"}
| 项目 | 神经外膜（epineurium） | 神经束膜（perineurium） | 神经内膜（endoneurium） |
|------|------------------------|-------------------------|-------------------------|
| 包裹对象 | 整条神经；并伸入束间 | 一条神经纤维束 | 束内每一条神经纤维 |
| 组织性质 | 致密结缔组织 | 几层扁平上皮样细胞，细胞间紧密连接 | 薄层结缔组织 |
| 特殊职分 | 支持、容纳血管淋巴管 | 大分子屏障 | 紧贴纤维，含小血管淋巴管 |
| 光镜线索 | 神经最外层及束间分隔（图 7-25 之 1） | 束表面（图 7-17 之 1，图 7-25 箭头） | 单条纤维周围的薄层 |
:::

:::compare{title="神经的三层膜与骨骼肌的三层膜"}
| 层次 | 神经 | 骨骼肌 |
|------|------|--------|
| 包整块/整条 | 神经外膜（epineurium） | 肌外膜（epimysium） |
| 包束 | 神经束膜（perineurium）：上皮样细胞 + 紧密连接，有屏障 | 肌束膜（perimysium）：结缔组织分隔肌束 |
| 包一条 | 神经内膜（endoneurium）包一条神经纤维 | 肌内膜（endomysium）包一条肌纤维 |
| 易混点 | 束膜不是单纯致密结缔组织 | 三层都是结缔组织，无上皮样屏障 |
:::

:::pitfall{label="神经束膜有紧密连接，不要写成“和肌束膜一样的结缔组织”"}
三层名字与骨骼肌平行，职分并不平行。神经束膜是上皮样细胞加紧密连接，挡住进入束内的大分子；肌束膜只是包肌束的结缔组织。把束膜听成一层普通纤维膜，血–神经屏障那本账会做丢。另：一条神经 ≠ 一条神经纤维 ≠ 一条轴突。
:::

::figure{src="/images/histology/textbook/p0092_02.png" caption="图7-25 坐骨神经（局部）光镜图。1. 神经外膜；2. 神经纤维束；↑神经束膜。" alt="坐骨神经横切：外膜包绕多个神经纤维束，箭头示束表面的神经束膜"}

:::keypoint{label="神经纤维先把成鞘细胞、结与传导，再把神经三层膜立住"}
- 神经纤维 = 长轴突 + 外包胶质；有髓 / 无髓以是否形成髓鞘划分。
- 周围有髓：一个结间体 = 一个施万细胞；郎飞结处轴膜裸露；神经膜 = 最外层细胞膜 + 基膜；有施-兰切迹。
- 中枢有髓：少突胶质细胞一个可包多条轴突；外无基膜，鞘内无切迹。
- 周围无髓：一个施万细胞纵沟内可含多条轴突，无郎飞结；中枢无髓轴突裸露。
- 冲动在轴膜上传：有髓跳跃（结越长越快），无髓连续（慢）。
- 神经：外膜包神经、束膜（上皮样细胞 + 紧密连接）包束、内膜包纤维；肉眼因髓磷脂呈白色。
:::

:::memory{label="本节必背要点"}
- [ ] 神经纤维（nerve fiber）由神经元的长轴突及包绕它的神经胶质细胞构成。
- [ ] 按胶质是否形成髓鞘（myelin sheath），分为有髓神经纤维和无髓神经纤维。
- [ ] 周围有髓纤维：施万细胞长卷筒状，最长可达 $1\,500\,\mu\mathrm{m}$，一个接一个套在轴突外。
- [ ] 郎飞结（Ranvier node）：相邻施万细胞不连接造成的无髓鞘缩窄，此处轴膜部分裸露。
- [ ] 结间体（internode）：相邻两个郎飞结之间的一段神经纤维；一个结间体的外围即一个施万细胞。
- [ ] 横切面施万细胞分 3 层：中层为同心卷绕（可达 50 层）的髓鞘；内侧胞质极薄、光镜难辨；外侧胞质可略厚，核位于其中。
- [ ] 神经膜（neurilemma）= 施万细胞最外面一层细胞膜 + 基膜。
- [ ] 电镜下髓鞘呈明暗相间板层状；化学成分主要是髓磷脂（myelin），类脂约占 $80\%$，其余为蛋白质。
- [ ] 髓鞘蛋白 0 和髓鞘碱性蛋白对周围髓鞘的形成和稳定重要；中枢髓鞘含蛋白脂蛋白和髓鞘碱性蛋白。
- [ ] HE 制备时类脂被溶解，仅见少量网状蛋白质；锇酸保存髓磷脂，髓鞘呈黑色。
- [ ] 髓鞘切迹（施-兰切迹）是锇酸纵切面上不着色的漏斗形斜裂，为施万细胞内、外侧胞质间穿越髓鞘的通道。
- [ ] 髓鞘形成：施万细胞表面凹成纵沟 → 轴突陷入 → 沟两侧膜贴合成轴突系膜 → 系膜伸长旋转卷绕 → 胞质被挤到内、外侧及两端（近郎飞结处）。
- [ ] 中枢有髓纤维由少突胶质细胞成鞘：多个突起末端薄膜可包卷多个轴突，胞体位于纤维之间；外表面无基膜，髓鞘内无切迹。
- [ ] 周围无髓纤维：施万细胞不规则长柱状，纵沟内有较细轴突，膜不形成髓鞘；一条无髓纤维可含多条轴突；无郎飞结。
- [ ] 中枢无髓纤维：轴突无特异性胶质包裹，裸露走行于有髓纤维或胶质之间。
- [ ] 冲动在轴膜传导。有髓：跳跃式，快；轴突越粗、鞘越厚、结间体越长，跳跃距离越大、速度越快。无髓：连续传导，慢。
- [ ] 神经（nerve）：纤维集成束，束再聚成神经。坐骨神经可含数十条束；细小神经常仅一条束。多数兼含感觉、躯体运动及自主纤维；肉眼通常呈白色。
- [ ] 神经外膜（epineurium）：包神经表面的致密结缔组织，并伸入束间。
- [ ] 神经束膜（perineurium）：束表面几层扁平上皮样细胞，细胞间紧密连接，阻挡大分子进入束内。
- [ ] 神经内膜（endoneurium）：束内每条神经纤维表面的薄层结缔组织。三层中都有小血管和淋巴管。
:::
