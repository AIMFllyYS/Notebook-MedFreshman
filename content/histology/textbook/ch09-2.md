# 二、动脉

从心脏发出后，动脉由粗至细逐级分支，管壁也逐渐变薄。根据管径大小和管壁结构特点，动脉分为大动脉、中动脉、小动脉和微动脉 4 种类型。随着管径逐渐变小，管壁各层也发生厚度、结构与组织成分的渐变，其中以中膜变化最明显。

:::definition{label="动脉的分型"}
根据管径大小和管壁结构特点，动脉分为大动脉、中动脉、小动脉和微动脉 4 种类型。管径变小伴随管壁各层厚度、结构与组织成分渐变，其中以中膜变化最明显。
:::

:::concept{term="先问中膜是弹性膜多还是平滑肌多"}
给一条动脉分型，不要先背管径数字，先看中膜。多层窗孔弹性膜、平滑肌少，是弹性动脉，也就是大动脉； $10\sim 40$ 层环行平滑肌、内弹性膜波浪状明显，是肌性动脉，也就是中动脉。小动脉仍属肌性动脉，只是平滑肌减到 $3\sim 9$ 层；微动脉只剩 $1\sim 2$ 层，内外弹性膜都没有了。把“中动脉”听成“弹性动脉的中号”，弹性膜账和平滑肌账会整层对调。
:::

:::pitfall{label="中动脉不是弹性动脉，弹性动脉专指大动脉"}
大动脉因中膜含多层弹性膜和大量弹性纤维、平滑肌较少，又称弹性动脉（elastic artery）。中动脉因中膜平滑肌相当丰富，又名肌性动脉（muscular artery）。小动脉中膜仍是 $3\sim 9$ 层环行平滑肌，故也属肌性动脉。不要按“大、中、小”把中动脉写成弹性动脉的过渡型，更不要把颈总动脉、主动脉写成肌性动脉。
:::

## （一）大动脉

大动脉（large artery）为靠近心脏的动脉，包括主动脉、肺动脉、头臂干、颈总动脉、锁骨下动脉、髂总动脉等。大动脉管壁的中膜含多层弹性膜和大量弹性纤维，而平滑肌纤维较少，故又称弹性动脉（elastic artery）（图 9-2，图 9-3）。

大动脉的管径较大，管壁约占管径的 $1/10$。各层结构的特点如下。

:::definition{label="大动脉"}
大动脉（large artery）为靠近心脏的动脉，包括主动脉、肺动脉、头臂干、颈总动脉、锁骨下动脉、髂总动脉等。中膜含多层弹性膜和大量弹性纤维，平滑肌纤维较少，故又称弹性动脉（elastic artery）。管壁约占管径的 $1/10$。
:::

:::definition{label="弹性动脉"}
弹性动脉（elastic artery）即大动脉。中膜 $40\sim 70$ 层同心圆排列的窗孔弹性膜是其形态学身份证，功能上在心动周期中起辅助泵作用。
:::

**1. 内膜** 占管壁厚度的 $1/6$ 左右，由内皮和内皮下层构成，内膜与中膜无明显界限，内弹性膜不明显。内皮细胞的 W-P 小体尤为丰富；内皮下层较厚，为疏松结缔组织，含纵行胶原纤维和少量平滑肌纤维。

:::definition{label="大动脉内膜"}
大动脉内膜占管壁厚度的 $1/6$ 左右，由内皮和内皮下层构成；内膜与中膜无明显界限，内弹性膜不明显。内皮细胞 W-P 小体尤为丰富；内皮下层较厚，含纵行胶原纤维和少量平滑肌纤维。
:::

**2. 中膜** 最厚，含 $40\sim 70$ 层呈同心圆排列的弹性膜（图 9-3）。弹性膜由弹性蛋白组成，弹性膜上有许多窗孔，各层弹性膜由弹性纤维相连，弹性膜之间还有环行平滑肌纤维和胶原纤维。平滑肌纤维可分泌多种蛋白质，形成细胞间质成分，如弹性纤维和基质。病理状态下，中膜平滑肌纤维可迁入内膜增生，并产生细胞间质成分，使内膜增厚，是动脉粥样硬化（atherosclerosis，AS）发生过程的重要环节。由于血管收缩，横切面显示弹性膜呈波浪状。

:::definition{label="大动脉中膜"}
大动脉中膜最厚，含 $40\sim 70$ 层呈同心圆排列的弹性膜。弹性膜由弹性蛋白组成，上有许多窗孔，各层由弹性纤维相连；膜之间还有环行平滑肌纤维和胶原纤维。因管壁收缩，横切面弹性膜呈波浪状。
:::

:::definition{label="动脉粥样硬化"}
动脉粥样硬化（atherosclerosis，AS）发生过程的重要环节之一，是病理状态下中膜平滑肌纤维迁入内膜增生，并产生细胞间质成分，使内膜增厚。完整机制见本节插入框。
:::

**3. 外膜** 较薄，由疏松结缔组织构成，含纵向螺旋状排列的胶原纤维束和弹性纤维，以及成纤维细胞和少量平滑肌纤维，外弹性膜不明显。

:::definition{label="大动脉外膜"}
大动脉外膜较薄，由疏松结缔组织构成，含纵向螺旋状排列的胶原纤维束和弹性纤维，以及成纤维细胞和少量平滑肌纤维，外弹性膜不明显。
:::

:::insight{label="动脉的管壁结构与动脉粥样硬化"}
动脉粥样硬化是一种动脉血管疾病，其发生机制如下：当动脉内皮受损后，胆固醇等脂质成分容易在内皮下层沉积。同时，内皮细胞会释放趋化因子等物质，诱导血液中的单核细胞进入内皮下层，并转化为巨噬细胞。巨噬细胞吞噬被自由基氧化的胆固醇，形成泡沫细胞。此外，血管中膜的平滑肌纤维也可进入内皮下层，吞噬脂质并形成泡沫细胞。这些泡沫细胞堆积形成脂质条纹甚至脂质斑块，渐渐凸入动脉管腔内，引起管腔狭窄，还可向中膜扩展并破坏管壁。在这个过程中，动脉内膜积聚的脂质呈黄色粥样，故称为动脉粥样硬化。泡沫细胞是动脉粥样硬化斑块内的特征性病理细胞。同时，斑块内还会聚集炎性细胞，它们释放的化学物质会促进平滑肌纤维、间质细胞等细胞的增殖，导致动脉内膜和中膜变厚。

动脉粥样硬化通常开始于吸烟、高血压等危险因素对血管内皮的损伤，因此，健康的生活方式对于预防动脉粥样硬化非常重要。它会导致血管腔明显狭窄，当斑块破裂时还可引发血栓形成，从而导致血管急性闭塞，这是缺血性脑卒中、冠心病和外周动脉疾病的主要病理过程。因此，通过使用调脂药物、抗血小板药物等方法可以延缓动脉粥样硬化的进展。
:::

:::definition{label="泡沫细胞"}
泡沫细胞是动脉粥样硬化斑块内的特征性病理细胞，由巨噬细胞或迁入内皮下层的中膜平滑肌纤维吞噬被自由基氧化的胆固醇后形成。泡沫细胞堆积形成脂质条纹甚至脂质斑块。
:::

:::cause-effect{title="内皮损伤怎样写成粥样斑块和管腔狭窄"}
- 因：吸烟、高血压等损伤动脉内皮，脂质在内皮下层沉积
- 果：单核细胞入内膜成巨噬细胞，与中膜迁入的平滑肌一起吞噬氧化胆固醇，形成泡沫细胞
- 影响：脂质条纹 → 黄色粥样斑块凸入管腔，狭窄甚至破坏中膜；斑块破裂可继发血栓、急性闭塞
:::

:::note{label="内膜增厚的细胞来自中膜，不是内皮自己增生一层肉"}
教材把中膜平滑肌迁入内膜写成 AS 的重要环节。合成表型的平滑肌既能爬进内皮下层，又能产细胞间质、吞噬脂质变成泡沫细胞。不要把“内膜增厚”听成内皮细胞堆叠，也不要把泡沫细胞只记成巨噬细胞一种来源。
:::

## （二）中动脉

除大动脉外，凡在解剖学中有名称的动脉多为中动脉（medium-sized artery），管径一般大于 $1\,\mathrm{mm}$。中动脉中膜的平滑肌纤维相当丰富，故又名肌性动脉（muscular artery）（图 9-4，图 9-5）。

中动脉管壁具有典型的 3 层结构，各层的结构特点如下。

:::definition{label="中动脉"}
中动脉（medium-sized artery）管径一般大于 $1\,\mathrm{mm}$。除大动脉外，凡在解剖学中有名称的动脉多为中动脉。中膜平滑肌纤维相当丰富，故又名肌性动脉（muscular artery）。管壁具有典型的 3 层结构。
:::

:::definition{label="肌性动脉"}
肌性动脉（muscular artery）指中膜以环行平滑肌为主的动脉，包括中动脉，也包括中膜含 $3\sim 9$ 层环行平滑肌的小动脉。不要把这个别名只留给中动脉而把小动脉开除。
:::

**1. 内膜** 内皮下层较薄，在与中膜交界处有 $1\sim 2$ 层明显的内弹性膜。

**2. 中膜** 较厚，由 $10\sim 40$ 层环行平滑肌纤维构成，平滑肌纤维之间可有缝隙连接，细胞间隙含少量弹性纤维和胶原纤维，主要由平滑肌纤维产生。

**3. 外膜** 厚度与中膜接近，由疏松结缔组织构成。外膜含营养血管和较多神经纤维，神经末梢还伸入中膜，调节血管平滑肌纤维舒缩。较大的中动脉在中膜与外膜交界处有断续的外弹性膜。

:::definition{label="中动脉内膜"}
中动脉内皮下层较薄，在与中膜交界处有 $1\sim 2$ 层明显的内弹性膜。这层波浪状内弹性膜是光镜下把中动脉从大动脉里认出来的第一线索。
:::

:::definition{label="中动脉中膜"}
中动脉中膜较厚，由 $10\sim 40$ 层环行平滑肌纤维构成。平滑肌之间可有缝隙连接；细胞间隙含少量弹性纤维和胶原纤维，主要由平滑肌纤维产生。
:::

:::definition{label="中动脉外膜"}
中动脉外膜厚度与中膜接近，由疏松结缔组织构成，含营养血管和较多神经纤维，神经末梢伸入中膜调节平滑肌舒缩。较大的中动脉在中膜与外膜交界处有断续的外弹性膜。
:::

:::compare{title="大动脉与中动脉的三层对照"}
| 项目 | 大动脉（弹性动脉） | 中动脉（肌性动脉） |
|------|--------------------|--------------------|
| 典型成员 | 主动脉、肺动脉、头臂干、颈总动脉、锁骨下动脉、髂总动脉 | 除大动脉外解剖学有名称者，管径一般 $>1\,\mathrm{mm}$ |
| 内膜 | 约占管壁 $1/6$；内皮下层厚；内弹性膜不明显，与中膜分界不清 | 内皮下层薄；$1\sim 2$ 层明显内弹性膜 |
| 中膜 | $40\sim 70$ 层窗孔弹性膜，平滑肌较少 | $10\sim 40$ 层环行平滑肌，弹性纤维少 |
| 外膜 | 较薄，外弹性膜不明显 | 厚度接近中膜；较大者有断续外弹性膜 |
| W-P 小体 | 内皮中尤为丰富 | 有，不作为分型依据 |
| 功能别名 | 辅助泵 | 分配动脉 |
:::

## （三）小动脉

小动脉（small artery）管径一般为 $0.3\sim 1\,\mathrm{mm}$，结构与中动脉相似，但各层均变薄。一般而言，小动脉内弹性膜明显；中膜含 $3\sim 9$ 层环行平滑肌纤维（图 9-6），故也属肌性动脉；外膜厚度与中膜相近，无外弹性膜。

:::definition{label="小动脉"}
小动脉（small artery）管径一般为 $0.3\sim 1\,\mathrm{mm}$，结构与中动脉相似，但各层均变薄。内弹性膜明显；中膜含 $3\sim 9$ 层环行平滑肌纤维，故也属肌性动脉；外膜厚度与中膜相近，无外弹性膜。
:::

## （四）微动脉

微动脉（arteriole）管径一般小于 $0.3\,\mathrm{mm}$，各层均薄，无内、外弹性膜，中膜含 $1\sim 2$ 层平滑肌纤维（图 9-6，图 9-7）。

:::definition{label="微动脉"}
微动脉（arteriole）管径一般小于 $0.3\,\mathrm{mm}$，各层均薄，无内、外弹性膜，中膜含 $1\sim 2$ 层平滑肌纤维。其平滑肌舒缩是控制微循环血流量的总闸门。
:::

:::compare{title="大、中、小、微动脉"}
| 项目 | 大动脉 | 中动脉 | 小动脉 | 微动脉 |
|------|--------|--------|--------|--------|
| 管径 | 最大；管壁约占管径 $1/10$ | 一般 $>1\,\mathrm{mm}$ | $0.3\sim 1\,\mathrm{mm}$ | $<0.3\,\mathrm{mm}$ |
| 别名 | 弹性动脉 | 肌性动脉、分配动脉 | 肌性动脉；与微动脉合称外周阻力血管 | 外周阻力血管；微循环总闸门 |
| 内弹性膜 | 不明显 | $1\sim 2$ 层，明显 | 明显 | 无 |
| 中膜 | $40\sim 70$ 层弹性膜，平滑肌少 | $10\sim 40$ 层环行平滑肌 | $3\sim 9$ 层环行平滑肌 | $1\sim 2$ 层平滑肌 |
| 外弹性膜 | 不明显 | 较大者断续存在 | 无 | 无 |
| 外膜相对厚度 | 较薄 | 与中膜接近 | 与中膜相近 | 薄 |
:::

:::pitfall{label="小动脉仍是肌性动脉，微动脉才去掉内弹性膜"}
小动脉管径掉到 $1\,\mathrm{mm}$ 以下，但内弹性膜仍明显、中膜仍是 $3\sim 9$ 层环行平滑肌，教材明确写“也属肌性动脉”。微动脉才无内、外弹性膜，中膜只剩 $1\sim 2$ 层。把“管径小了就不是肌性动脉”，或把微动脉写成“有内弹性膜的最小肌性动脉”，切片上会把图 9-6 的 1 和 3 认反。
:::

## （五）动脉管壁结构与功能的关系

心脏的间歇性收缩导致大动脉内的血液呈搏动性流动。心脏收缩时，血液瞬间快速射入大动脉使其扩张，同时大动脉管壁积累了强大的势能；在心脏舒张期，大动脉的弹性膜反弹回缩，释放势能，使血液继续向前流动，从而保持了血流的平稳和连续。在此过程中，大动脉发挥了辅助泵作用。中动脉平滑肌纤维主要在神经支配下舒缩，可调节分配到身体各部位的血流量，因此，中动脉又称分配动脉（distributing artery）。小动脉和微动脉平滑肌纤维都受神经（图 9-8）和体液的调节而舒缩，显著调节血流的外周阻力，从而调节局部组织血流量，并维持正常血压，因此小动脉和微动脉又称外周阻力血管（resistance vessel）。

:::definition{label="辅助泵"}
辅助泵指大动脉在心动周期中的作用：收缩期管壁扩张并积累势能，舒张期弹性膜回缩释放势能，使血液继续向前流动，保持血流平稳和连续。
:::

:::definition{label="分配动脉"}
分配动脉（distributing artery）即中动脉。其平滑肌主要在神经支配下舒缩，调节分配到身体各部位的血流量。
:::

:::definition{label="外周阻力血管"}
外周阻力血管（resistance vessel）指小动脉和微动脉。其平滑肌受神经和体液调节而舒缩，显著调节血流的外周阻力，从而调节局部组织血流量并维持正常血压。
:::

:::cause-effect{title="大动脉弹性膜怎样把间歇射血写成连续血流"}
- 因：心脏间歇收缩，血液瞬间射入大动脉
- 果：大动脉扩张，管壁积累势能；舒张期弹性膜反弹回缩，释放势能
- 影响：血流保持平稳、连续，大动脉完成辅助泵职分
:::

:::concept{term="先问这层平滑肌管的是分配还是阻力"}
中动脉平滑肌改的是“血往哪送”，所以叫分配动脉。小动脉和微动脉平滑肌改的是“过这边有多难”，所以叫外周阻力血管，血压账主要写在这一段。大动脉几乎不靠平滑肌层数吃饭，靠的是 $40\sim 70$ 层弹性膜的蓄能-放能。把三类功能写成“动脉都会收缩所以都能调血压”，辅助泵、分配、阻力三本账会并成一句空话。
:::

## （六）动脉管壁内的特殊感受器

动脉管壁内有一些特殊感受器，如颈动脉体、主动脉体和颈动脉窦等。

**1. 颈动脉体** 颈动脉体（carotid body）位于颈总动脉分支处的管壁外侧部分，是直径 $2\sim 3\,\mathrm{mm}$ 的扁平小体，主要由排列不规则的上皮细胞团、索构成，上皮细胞团、索之间有丰富的血窦。透射电镜下，上皮细胞分两型：Ⅰ型细胞聚集成群，细胞质内含较多致密核芯小泡，贮存多巴胺、5-羟色胺和肾上腺素，Ⅰ型细胞可与舌咽神经和迷走神经的传入神经末梢构成突触。Ⅱ型细胞伸出突起包绕Ⅰ型细胞和裸露的神经末梢，发挥支持作用，细胞质内无颗粒或少颗粒（图 9-9）。颈动脉体是感受动脉血氧分压、二氧化碳分压和 pH 的化学感受器，参与调节心血管系统和呼吸系统功能。

:::definition{label="颈动脉体"}
颈动脉体（carotid body）位于颈总动脉分支处的管壁外侧部分，直径 $2\sim 3\,\mathrm{mm}$ 的扁平小体。由不规则上皮细胞团、索及丰富血窦构成。是感受动脉血氧分压、二氧化碳分压和 pH 的化学感受器，参与调节心血管系统和呼吸系统功能。
:::

:::definition{label="颈动脉体Ⅰ型细胞"}
Ⅰ型细胞聚集成群，胞质内含较多致密核芯小泡，贮存多巴胺、5-羟色胺和肾上腺素，可与舌咽神经和迷走神经的传入神经末梢构成突触。
:::

:::definition{label="颈动脉体Ⅱ型细胞"}
Ⅱ型细胞伸出突起包绕Ⅰ型细胞和裸露的神经末梢，发挥支持作用，胞质内无颗粒或少颗粒。
:::

**2. 主动脉体** 主动脉体（aortic body）在结构和功能上与颈动脉体相似。右侧主动脉体位于颈总动脉和锁骨下动脉之间的夹角处，左侧主动脉体位于锁骨下动脉起点内侧的主动脉壁上。

:::definition{label="主动脉体"}
主动脉体（aortic body）在结构和功能上与颈动脉体相似，同为化学感受器。右侧位于颈总动脉和锁骨下动脉之间的夹角处，左侧位于锁骨下动脉起点内侧的主动脉壁上。
:::

**3. 颈动脉窦** 颈动脉窦（carotid sinus）为颈总动脉分支和颈内动脉起始处的膨大部分，此处血管壁的中膜很薄，外膜较厚，外膜含丰富的神经末梢。颈动脉窦是压力感受器，使血压保持相对稳定。若突然持续压迫颈动脉窦，可使心率持续减慢和血压持续降低而致猝死。在主动脉弓和靠近心脏的大静脉壁中也有类似于颈动脉窦的压力感受器。

与颈动脉窦和主动脉弓的压力感受性反射不同，颈动脉体和主动脉体的化学感受性反射在生理状态下对心血管活动并没有明显的调节作用，主要在病理状态下（如低氧、动脉血压过低和酸中毒等）发挥作用。

:::definition{label="颈动脉窦"}
颈动脉窦（carotid sinus）为颈总动脉分支和颈内动脉起始处的膨大部分。此处中膜很薄，外膜较厚并含丰富神经末梢。是压力感受器，使血压保持相对稳定。突然持续压迫可使心率持续减慢、血压持续降低而致猝死。
:::

:::compare{title="化学感受器与压力感受器"}
| 项目 | 颈动脉体、主动脉体 | 颈动脉窦（及主动脉弓等处类似结构） |
|------|---------------------|--------------------------------------|
| 感受性质 | 化学感受器 | 压力感受器 |
| 感受内容 | 动脉血氧分压、二氧化碳分压和 pH | 动脉壁牵张（血压） |
| 位置 | 体：颈总动脉分支处管壁外侧；主动脉体分左、右侧 | 窦：颈总动脉分支和颈内动脉起始处膨大 |
| 结构要点 | 上皮细胞团、索 + 血窦；Ⅰ型细胞含致密核芯小泡 | 中膜很薄，外膜较厚，外膜神经末梢丰富 |
| 生理/病理 | 生理状态下对心血管活动无明显调节；主要在低氧、动脉血压过低、酸中毒等病理状态发挥作用 | 使血压保持相对稳定；突然持续压迫可致心率减慢、血压降低甚至猝死 |
:::

:::pitfall{label="颈动脉窦管压力，颈动脉体管化学，不要因为都在分叉处就并成一个感受器"}
两者都靠近颈总动脉分叉，职分完全不同。窦是管壁本身的膨大，中膜薄、外膜厚、末梢丰富，感受血压。体是管壁外侧 $2\sim 3\,\mathrm{mm}$ 的扁平小体，Ⅰ型细胞贮单胺、与Ⅸ、Ⅹ传入末梢突触，感受 $P_{\mathrm{O}_{2}}$、$P_{\mathrm{CO}_{2}}$ 和 pH。把“按压颈动脉窦抢救”和“颈动脉体感受低氧”写成同一反射，压力感受性反射和化学感受性反射会并账。
:::

::figure{src="/images/histology/textbook/p0110_01.png" caption="图9-9 颈动脉体超微结构模式图。Ⅰ型细胞含致密核芯小泡，与舌咽神经传入纤维构成突触；Ⅱ型细胞包绕Ⅰ型细胞和神经末梢；并示传出神经末梢。" alt="颈动脉体Ⅰ型细胞致密核芯小泡与传入突触，Ⅱ型细胞起支持作用"}

:::keypoint{label="动脉按中膜分型，再写成辅助泵、分配动脉和阻力血管"}
- 大动脉 = 弹性动脉：中膜 $40\sim 70$ 层窗孔弹性膜；内膜约占 $1/6$，内、外弹性膜均不明显；管壁约占管径 $1/10$；W-P 小体丰富；辅助泵。
- 中动脉 = 肌性动脉、分配动脉：管径一般 $>1\,\mathrm{mm}$；内弹性膜 $1\sim 2$ 层明显；中膜 $10\sim 40$ 层环行平滑肌；外膜厚度接近中膜。
- 小动脉 $0.3\sim 1\,\mathrm{mm}$，中膜 $3\sim 9$ 层，也属肌性动脉；微动脉 $<0.3\,\mathrm{mm}$，中膜 $1\sim 2$ 层，无内、外弹性膜。
- 小动脉和微动脉 = 外周阻力血管，神经和体液调节舒缩。
- 颈动脉体/主动脉体：化学感受器；颈动脉窦：压力感受器。
- 中膜平滑肌迁入内膜是动脉粥样硬化的重要环节；泡沫细胞来自巨噬细胞和中膜平滑肌。
:::

:::memory{label="本节必背要点"}
- [ ] 动脉由粗至细分为大动脉、中动脉、小动脉和微动脉 4 型；管壁渐变以中膜最明显。
- [ ] 大动脉（large artery）靠近心脏，包括主动脉、肺动脉、头臂干、颈总动脉、锁骨下动脉、髂总动脉等。
- [ ] 大动脉中膜含多层弹性膜和大量弹性纤维、平滑肌较少，又称弹性动脉（elastic artery）。
- [ ] 大动脉管壁约占管径的 $1/10$。
- [ ] 大动脉内膜约占管壁厚度 $1/6$，由内皮和内皮下层构成，与中膜分界不清，内弹性膜不明显；W-P 小体尤为丰富；内皮下层较厚，含纵行胶原纤维和少量平滑肌。
- [ ] 大动脉中膜最厚，含 $40\sim 70$ 层同心圆排列的窗孔弹性膜；各层由弹性纤维相连，膜之间有环行平滑肌和胶原纤维。
- [ ] 病理状态下中膜平滑肌可迁入内膜增生并产生细胞间质，使内膜增厚，是动脉粥样硬化（AS）的重要环节。
- [ ] 大动脉外膜较薄，外弹性膜不明显。
- [ ] 中动脉（medium-sized artery）管径一般 $>1\,\mathrm{mm}$；除大动脉外解剖学有名称者多为中动脉；中膜平滑肌丰富，又名肌性动脉（muscular artery）。
- [ ] 中动脉内膜：内皮下层较薄，与中膜交界处有 $1\sim 2$ 层明显内弹性膜。
- [ ] 中动脉中膜： $10\sim 40$ 层环行平滑肌；细胞间隙含少量弹性纤维和胶原纤维，主要由平滑肌产生。
- [ ] 中动脉外膜厚度与中膜接近；含营养血管和较多神经；较大者有断续外弹性膜。
- [ ] 小动脉（small artery）管径 $0.3\sim 1\,\mathrm{mm}$；内弹性膜明显；中膜 $3\sim 9$ 层环行平滑肌，也属肌性动脉；无外弹性膜。
- [ ] 微动脉（arteriole）管径一般 $<0.3\,\mathrm{mm}$，无内、外弹性膜，中膜 $1\sim 2$ 层平滑肌。
- [ ] 大动脉发挥辅助泵作用：收缩期扩张蓄能，舒张期弹性膜回缩，保持血流平稳连续。
- [ ] 中动脉又称分配动脉（distributing artery），神经支配下舒缩，调节各部位血流量。
- [ ] 小动脉和微动脉又称外周阻力血管（resistance vessel），受神经和体液调节，维持局部血流量和正常血压。
- [ ] 颈动脉体（carotid body）位于颈总动脉分支处管壁外侧，直径 $2\sim 3\,\mathrm{mm}$，为化学感受器（$P_{\mathrm{O}_{2}}$、$P_{\mathrm{CO}_{2}}$、pH）。
- [ ] Ⅰ型细胞含致密核芯小泡（多巴胺、5-羟色胺、肾上腺素），与舌咽、迷走传入末梢突触；Ⅱ型细胞支持，无颗粒或少颗粒。
- [ ] 主动脉体结构和功能与颈动脉体相似。
- [ ] 颈动脉窦（carotid sinus）为颈总动脉分支和颈内动脉起始处膨大，中膜薄、外膜厚、外膜神经末梢丰富，是压力感受器。
- [ ] 突然持续压迫颈动脉窦可使心率持续减慢、血压持续降低而致猝死。
- [ ] 化学感受性反射主要在低氧、动脉血压过低和酸中毒等病理状态发挥作用；压力感受性反射使血压保持相对稳定。
- [ ] 动脉粥样硬化：内皮受损 → 脂质沉积于内皮下层 → 巨噬细胞和中膜平滑肌形成泡沫细胞 → 脂质斑块；斑块破裂可致血栓和急性闭塞。
:::
