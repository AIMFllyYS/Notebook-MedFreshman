# 二、脑的发生

脑由神经管的头段演变而来。第 $4$ 周末先出现前脑泡、中脑泡、菱脑泡三个原脑泡；第 $5$ 周前脑泡分成端脑和间脑，菱脑泡分成后脑和末脑，加上中脑共五个脑泡。本节先把三段变五段、脑室系统和四个脑曲立住，再按基板／翼板、大脑皮质古旧新三期、小脑菱唇与外颗粒层内迁摊开。神经管尾段的脊髓见下一节。

脑由神经管的头段演变而来。

## （一）脑泡的形成及演变

第 $4$ 周末，神经管头段膨大形成 $3$ 个脑泡（brain vesicle），从头至尾依次为前脑泡、中脑泡和菱脑泡。至第 $5$ 周时，前脑泡的头端向两侧膨大，形成左、右两个端脑（telencephalon），以后演变为两个大脑半球，而前脑泡的尾端则形成间脑（diencephalon）。中脑泡演变为中脑（mesencephalon）。菱脑泡的头段演变为后脑（metencephalon），尾段演变为末脑（myelencephalon），后脑再演变为脑桥和小脑，末脑演变为延髓（图 26-5）。

:::definition{label="三个原脑泡"}
第 $4$ 周末，神经管头段膨大形成 $3$ 个脑泡（brain vesicle），从头至尾依次为前脑泡、中脑泡和菱脑泡。这是一次分区，还没有端脑、间脑、后脑、末脑。
:::

:::definition{label="端脑"}
至第 $5$ 周，前脑泡头端向两侧膨大，形成左、右两个端脑（telencephalon），以后演变为两个大脑半球。套层大部分细胞迁至外表面成大脑皮质，少部分聚集成团成神经核。
:::

:::definition{label="间脑"}
前脑泡的尾端形成间脑（diencephalon）。二次分区后，它形成丘脑、视交叉、灰白结节、乳头体、脑垂体神经部等，其腔构成第三脑室大部。
:::

:::definition{label="中脑"}
中脑泡演变为中脑（mesencephalon）。形成四叠体、被盖、大脑脚，其腔形成狭窄的中脑导水管。
:::

:::definition{label="后脑"}
菱脑泡的头段演变为后脑（metencephalon）。后脑再演变为脑桥和小脑。
:::

:::definition{label="末脑"}
菱脑泡的尾段演变为末脑（myelencephalon）。末脑演变为延髓。
:::

:::concept{term="先问现在是三个原脑泡还是五个脑泡，再问腔已经变成哪一级脑室"}
看见脑的发生，先对时间：第 $4$ 周末只有前脑泡、中脑泡、菱脑泡。第 $5$ 周前脑泡才分成端脑和间脑，菱脑泡才分成后脑和末脑，中脑泡仍是中脑，这才是五段。再问管腔：前脑泡腔 → 左、右侧脑室加第三脑室；中脑泡腔 → 中脑导水管；菱脑泡腔 → 第四脑室。把第 $4$ 周末听成已经有大脑半球，或把中脑导水管写成第四脑室，分段会对错户头。
:::

:::timeline{period="从三个原脑泡到五个脑泡"}
- **神经管头段** 仍是一条管的头端
- **第4周末** 膨大成前脑泡、中脑泡、菱脑泡
- **第5周** 前脑泡头端向两侧成左右端脑，尾端成间脑；中脑泡成中脑；菱脑泡头段成后脑、尾段成末脑
- **随后** 端脑 → 两个大脑半球；后脑 → 脑桥和小脑；末脑 → 延髓
:::

在脑泡演变的同时，其中央的管腔则演变为各部位的脑室。前脑泡的腔演变为左、右两个侧脑室和间脑中的第三脑室；中脑泡的腔形成狭窄的中脑导水管；菱脑泡的腔演变为宽大的第四脑室（表 26-1）。

:::definition{label="侧脑室与第三脑室"}
前脑泡的腔演变为左、右两个侧脑室和间脑中的第三脑室。端脑侧对应侧脑室及第三脑室前部，间脑侧对应第三脑室大部。
:::

:::definition{label="中脑导水管"}
中脑泡的腔形成狭窄的中脑导水管。它是中脑的腔，不是第四脑室的别名。
:::

:::definition{label="第四脑室"}
菱脑泡的腔演变为宽大的第四脑室，与后脑（脑桥、小脑）和末脑（延髓）相对。
:::

:::compare{title="脑泡的发生及其演变"}
| 原基 | 原始分区 | 二次分区 | 形成最后结构 | 构成脑室 |
|------|----------|----------|--------------|----------|
| 神经管头段 | 前脑泡 | 端脑 | 嗅脑、纹状体、大脑半球 | 侧脑室、第三脑室前部 |
| 神经管头段 | 前脑泡 | 间脑 | 丘脑、视交叉、灰白结节、乳头体、脑垂体神经部 | 第三脑室大部 |
| 神经管头段 | 中脑泡 | 中脑 | 四叠体、被盖、大脑脚 | 中脑导水管 |
| 神经管头段 | 菱脑泡 | 后脑 | 小脑、脑桥 | 第四脑室 |
| 神经管头段 | 菱脑泡 | 末脑 | 延髓 | 第四脑室 |
:::

脑泡演变过程中，由于胚胎头部向腹面屈曲及脑泡的各部位生长速度不同，出现了几个不同方向的弯曲。首先出现的是凸向背侧的头曲（cephalic flexure）和颈曲（cervical flexure），前者位于中脑部，故又称中脑曲，后者位于末脑与脊髓之间。之后，在端脑和脑桥之间又出现了两个凸向腹侧的弯曲，分别称端脑曲（telencephalic flexure）和脑桥曲（pontine flexure）（见图 26-5）。

:::definition{label="头曲（中脑曲）"}
头曲（cephalic flexure）首先出现，凸向背侧，位于中脑部，故又称中脑曲。
:::

:::definition{label="颈曲"}
颈曲（cervical flexure）首先出现，凸向背侧，位于末脑与脊髓之间。它不是头曲，挂的是末脑－脊髓交界。
:::

:::definition{label="端脑曲"}
端脑曲（telencephalic flexure）出现较晚，凸向腹侧，位于端脑和脑桥之间的头侧这份弯曲。
:::

:::definition{label="脑桥曲"}
脑桥曲（pontine flexure）出现较晚，凸向腹侧，与端脑曲同在端脑和脑桥之间这一段。
:::

| 英文 | cephalic flexure | cervical flexure | telencephalic flexure | pontine flexure |

:::

:::pitfall{label="头曲、颈曲凸向背侧，端脑曲、脑桥曲凸向腹侧，不要写成四个弯都朝同一面"}
先出现的两个凸向背侧：头曲在中脑，颈曲在末脑与脊髓之间。后出现的两个凸向腹侧：端脑曲和脑桥曲。写成“都是头端往下勾”，图 26-5 的侧面观会对不上。
:::

神经管头段管壁的演变较为复杂。神经管管壁的套层迅速增厚，腹侧部增厚形成左、右两个基板（basal plate），背侧部增厚形成左、右两个翼板（alar plate）。由于基板和翼板的增厚，两者在神经管的内表面出现了左、右相对的两条纵沟，称界沟（sulcus limitans）。端脑和间脑的套层大部分形成翼板，基板甚小。端脑套层中的大部分细胞都迁至外表面，形成大脑皮质，少部分聚集成团，形成神经核。中脑、后脑和末脑中的套层细胞多聚集成细胞团或柱，形成各种神经核。翼板中的神经核多为感觉中继核，基板中的神经核多为运动核（图 26-6）。

:::definition{label="基板（脑）"}
基板（basal plate）是套层腹侧部增厚形成的左、右两个板。基板中的神经核多为运动核。端脑和间脑的基板甚小。
:::

:::definition{label="翼板（脑）"}
翼板（alar plate）是套层背侧部增厚形成的左、右两个板。翼板中的神经核多为感觉中继核。端脑和间脑的套层大部分形成翼板。
:::

:::definition{label="界沟"}
界沟（sulcus limitans）是基板和翼板增厚后，在神经管内表面出现的左、右相对两条纵沟。它把腹侧运动区和背侧感觉区切开。
:::

:::definition{label="端脑套层的两种去向"}
端脑套层中的大部分细胞都迁至外表面，形成大脑皮质；少部分聚集成团，形成神经核。皮质是迁出去的，核是留下来聚团的。
:::

:::definition{label="脑干套层成核"}
中脑、后脑和末脑中的套层细胞多聚集成细胞团或柱，形成各种神经核。这里主要不是铺成一片皮质。
:::

教材写明：端脑和间脑的套层大部分形成翼板，基板甚小。把端脑也画成腹侧运动、背侧感觉各一半，大脑皮质的来路会对不到翼板。
:::

基板在腹侧、核多为运动核；翼板在背侧、核多为感觉中继核。界沟是管腔内表面的纵沟。写成“界沟就是外侧裂”，图 26-6 的横切会对错。

## （二）大脑皮质的组织发生

大脑皮质的发生分 $3$ 个阶段，依次为古皮质、旧皮质和新皮质。人类大脑皮质的发生过程重演了脑皮质的种系发生过程。海马和齿状回是最早出现的皮质结构，相当于古皮质（archicortex）。胚胎第 $7$ 周时，在纹状体的外侧，大量成神经细胞聚集并分化，形成梨状皮质，相当于旧皮质（paleocortex）。旧皮质出现不久，神经上皮细胞增殖，分期分批地迁移至表层并分化为神经细胞，形成新皮质（neocortex），这是大脑皮质中出现最晚、面积最大的部分（见图 26-6）。由于端脑套层产生的成神经细胞是分期分批地进行迁移的，因而皮质中的神经细胞呈层状分布。越早产生和迁移的细胞，其位置越深；越晚产生和迁移的细胞，其位置越表浅，即越靠近皮质表层。胎儿出生时，新皮质已形成 $6$ 层结构。古皮质和旧皮质的分层无一定规律性，有的分层不明显，有的分为 $3$ 层。

在大脑皮质内，随着神经元的不断形成，突触也随之形成。早在第 $8$ 周，皮质内即已出现突触。突触的形成过程包括：轴突生长的终止、树突和树突棘的发育、突触部位的选择和最后的突触形成。

:::definition{label="古皮质"}
古皮质（archicortex）是最早出现的皮质结构，相当于海马和齿状回。人类大脑皮质发生重演种系发生，古皮质排在第一阶段。
:::

:::definition{label="旧皮质"}
旧皮质（paleocortex）出现于胚胎第 $7$ 周：在纹状体的外侧，大量成神经细胞聚集并分化，形成梨状皮质。
:::

:::definition{label="新皮质"}
新皮质（neocortex）在旧皮质出现不久后形成：神经上皮细胞增殖，分期分批迁移至表层并分化为神经细胞。它是大脑皮质中出现最晚、面积最大的部分。出生时已形成 $6$ 层。
:::

:::definition{label="新皮质的内向外迁移"}
端脑套层产生的成神经细胞分期分批迁移，故皮质细胞呈层状：越早产生和迁移的细胞位置越深；越晚产生和迁移的细胞位置越表浅，越靠近皮质表层。
:::

:::definition{label="古皮质与旧皮质的分层"}
古皮质和旧皮质的分层无一定规律性，有的分层不明显，有的分为 $3$ 层。不要把 $6$ 层结构套到海马和梨状皮质上。
:::

:::definition{label="皮质内突触的形成"}
随着神经元不断形成，突触也随之形成。早在第 $8$ 周，皮质内即已出现突触。过程包括：轴突生长的终止、树突和树突棘的发育、突触部位的选择和最后的突触形成。
:::

:::derivation{title="为什么早迁移的细胞反而在深层"}
成神经细胞从套层分期分批往表层走。先出发的一批先在相对深的位置停下；后出发的一批越过它们，更靠近皮质表面才停下。所以“早产深、晚产浅”，不是“先来的占表层”。出生时新皮质 $6$ 层就是这样叠出来的。
:::

:::timeline{period="大脑皮质三阶段与突触"}
- **最早** 海马和齿状回，相当于古皮质
- **第7周** 纹状体外侧成神经细胞聚集分化为梨状皮质，相当于旧皮质
- **旧皮质出现不久** 神经上皮分期分批迁至表层，形成新皮质（最晚、面积最大）
- **第8周** 皮质内已出现突触（轴突终止、树突和树突棘发育、部位选择、突触形成）
- **出生时** 新皮质已形成6层；古皮质和旧皮质分层无一定规律，有的不明显，有的3层
:::

:::compare{title="古皮质、旧皮质与新皮质"}
| 项目 | 古皮质 | 旧皮质 | 新皮质 |
|------|--------|--------|--------|
| 英文 | archicortex | paleocortex | neocortex |
| 代表结构 | 海马、齿状回 | 梨状皮质 | 面积最大的六层皮质 |
| 出现 | 最早 | 第 $7$ 周，纹状体外侧 | 旧皮质出现不久，最晚 |
| 迁移 | — | 成神经细胞聚集并分化 | 分期分批迁至表层 |
| 分层 | 无一定规律，可不明或 $3$ 层 | 同左 | 出生时 $6$ 层；早迁移在深、晚迁移在浅 |
:::

:::pitfall{label="新皮质是晚迁移的在浅层，不要记成“先到的占表面”"}
越早产生和迁移的细胞位置越深，越晚的越表浅。写成“第一批细胞铺在最外面”，六层顺序会整层反掉。
:::

:::example{label="种系发生被个体发生重演一遍"}
先古（海马、齿状回），再旧（梨状皮质），最后新（六层新皮质）。考试问“最早出现的皮质”，先答海马和齿状回，不要答中央前回。
:::

## （三）小脑皮质的组织发生

小脑起源于后脑翼板背侧部的菱唇。左、右两侧菱唇在中线融合，形成小脑板（cerebellar plate），为小脑的原基。第 $12$ 周时，小脑板的两外侧部膨大，形成小脑半球；板的中部变细，形成小脑蚓（图 26-7）。起初，小脑板由室管膜层、套层和边缘层组成。而后，小脑板增厚，神经上皮细胞增生并通过套层迁移到边缘层表面，形成薄的细胞层，称浅层皮质或外颗粒层。此层细胞仍然保持分裂能力，在小脑表面形成一个细胞增殖区，使小脑表面迅速扩大并产生皱褶，形成小脑叶片。至第 $6$ 个月，套层的外层成神经细胞分化为浦肯野细胞和高尔基细胞，构成浦肯野细胞层；套层的内层成神经细胞则聚集成团，分化为小脑白质中的核团，如齿状核。外颗粒层大部分细胞向内迁移，分化为颗粒细胞，位居浦肯野细胞层深面，构成内颗粒层。外颗粒层细胞因大量迁出变得较少，存留的细胞分化为篮状细胞和星形细胞，同时浦肯野细胞的树突和内颗粒层细胞的轴突也伸入其间，共同形成分子层。原内颗粒层则改称颗粒层。此种外颗粒层细胞的内迁一直持续到生后第 $7$ 个月。

:::definition{label="菱唇"}
菱唇是后脑翼板背侧部的结构。左、右两侧菱唇在中线融合，形成小脑板。小脑不从前脑泡来。
:::

:::definition{label="小脑板"}
小脑板（cerebellar plate）由左、右菱唇中线融合形成，是小脑的原基。起初由室管膜层、套层和边缘层组成。
:::

:::definition{label="小脑半球与小脑蚓"}
第 $12$ 周，小脑板两外侧部膨大形成小脑半球，中部变细形成小脑蚓。
:::

:::definition{label="外颗粒层（浅层皮质）"}
小脑板增厚后，神经上皮细胞增生并通过套层迁移到边缘层表面，形成薄的浅层皮质或外颗粒层。此层仍保持分裂能力，在小脑表面形成细胞增殖区，使表面迅速扩大并产生皱褶，形成小脑叶片。
:::

:::definition{label="浦肯野细胞层"}
至第 $6$ 个月，套层的外层成神经细胞分化为浦肯野细胞和高尔基细胞，构成浦肯野细胞层。
:::

:::definition{label="齿状核等小脑核"}
套层的内层成神经细胞聚集成团，分化为小脑白质中的核团，如齿状核。核在白质里，不是外颗粒层变来的。
:::

:::definition{label="内颗粒层与颗粒层"}
外颗粒层大部分细胞向内迁移，分化为颗粒细胞，位居浦肯野细胞层深面，构成内颗粒层。原内颗粒层后来改称颗粒层。
:::

:::definition{label="分子层（小脑）"}
外颗粒层细胞大量迁出后变得较少，存留的细胞分化为篮状细胞和星形细胞；浦肯野细胞的树突和内颗粒层细胞的轴突也伸入其间，共同形成分子层。
:::

::figure{src="/images/histology/textbook/p0287_01.png" caption="图26-7 小脑的发生模式图。A. 第8周中脑和菱脑背面观：菱唇、小脑板、脑桥与延髓；B. 第4个月背面／侧面；C. 图A的矢状切面，见外颗粒层、套层、神经上皮层、中脑导水管与第四脑室；D. 图B的矢状切面，见小脑皮质、髓质、齿状核；E. 胚胎期小脑皮质（外颗粒层与浦肯野细胞）；F. 出生后小脑皮质（分子层、浦肯野细胞、颗粒层）。" alt="上排菱唇融合成小脑板及背面观；中排矢状面外颗粒层演变为皱褶皮质和齿状核；下排胚胎期外颗粒层对出生后三层皮质"}

:::cause-effect{title="外颗粒层内迁，才叠出分子层、浦肯野细胞层和颗粒层"}
- 因：神经上皮经套层迁到边缘层表面，外颗粒层仍能分裂
- 果：小脑表面扩大起皱，形成叶片
- 因：第6个月套层外层成神经细胞分化为浦肯野细胞和高尔基细胞
- 果：浦肯野细胞层成立
- 因：外颗粒层大部分细胞向内迁，分化为颗粒细胞
- 果：浦肯野细胞层深面出现内颗粒层（后改称颗粒层）
- 因：外颗粒层存留细胞成篮状细胞和星形细胞，加上浦肯野树突和颗粒细胞轴突伸入
- 果：分子层形成；内迁持续到生后第7个月
:::

:::compare{title="胚胎期与出生后的小脑皮质"}
| 项目 | 胚胎期（外颗粒层阶段） | 出生后（内迁基本完成） |
|------|------------------------|--------------------------|
| 表面增殖区 | 外颗粒层（浅层皮质），仍能分裂 | 外颗粒层因迁出而变少，内迁可持续到生后第 $7$ 个月 |
| 浦肯野细胞层 | 第 $6$ 个月由套层外层成神经细胞分化（含高尔基细胞） | 浦肯野细胞树突伸入分子层 |
| 深面颗粒 | 内颗粒层正在由外颗粒层内迁形成 | 改称颗粒层 |
| 分子层 | 尚未完成 | 篮状细胞、星形细胞 + 浦肯野树突 + 颗粒细胞轴突 |
| 白质核团 | 套层内层成神经细胞聚团，如齿状核 | 位于髓质 |
:::

:::timeline{period="从小脑板到皮质三层"}
- **后脑翼板背侧** 菱唇出现
- **两侧菱唇中线融合** 形成小脑板（室管膜层、套层、边缘层）
- **第12周** 外侧膨大成小脑半球，中部变细成小脑蚓
- **随后** 神经上皮经套层迁到边缘层表面，成外颗粒层；表面扩大起皱成叶片
- **第6个月** 套层外层 → 浦肯野细胞和高尔基细胞；套层内层 → 齿状核等
- **外颗粒层内迁** 大部分成颗粒细胞（内颗粒层）；存留成篮状细胞和星形细胞，参与分子层
- **生后第7个月** 外颗粒层细胞的内迁才停
:::

:::pitfall{label="小脑颗粒细胞从外往里迁，不要写成和大脑新皮质一样从套层往表层堆"}
大脑新皮质是套层成神经细胞分期分批迁向表层，晚到的更浅。小脑是神经上皮先到边缘层表面成外颗粒层，再向内迁到浦肯野细胞层深面成颗粒层。方向相反。写成“小脑也是早深晚浅六层”，分子层和颗粒层会对调。
:::

:::note{label="小脑仍先有室管膜层、套层、边缘层"}
小脑板起初也是这三层，和外层增殖区并不矛盾：外颗粒层是神经上皮穿过套层迁到边缘层表面之后才出现的增殖区。
:::

:::keypoint{label="三泡变五泡，腔变脑室；皮质古旧新，小脑外颗粒层要内迁"}
- 第 $4$ 周末：前脑泡、中脑泡、菱脑泡。
- 第 $5$ 周：端脑、间脑、中脑、后脑、末脑；后脑 → 脑桥和小脑，末脑 → 延髓。
- 腔：前脑泡 → 侧脑室 + 第三脑室；中脑泡 → 中脑导水管；菱脑泡 → 第四脑室。
- 先凸向背侧：头曲（中脑曲）、颈曲（末脑与脊髓之间）；后凸向腹侧：端脑曲、脑桥曲。
- 套层腹侧基板（运动核）、背侧翼板（感觉中继核），内表面界沟；端脑和间脑几乎全是翼板。
- 端脑套层：大部分迁出成皮质，少部分成核；脑干套层多聚集成核。
- 皮质三阶段：古（海马、齿状回）→ 旧（第 $7$ 周梨状皮质）→ 新（最晚最大，$6$ 层，早深晚浅）。
- 第 $8$ 周皮质已有突触。
- 小脑：后脑翼板菱唇 → 小脑板 → 第 $12$ 周半球和蚓；外颗粒层内迁至生后第 $7$ 个月。
:::

:::memory{label="本节必背要点"}
- [ ] 脑由神经管的头段演变而来。
- [ ] 第 $4$ 周末，神经管头段膨大形成 $3$ 个脑泡，从头至尾为前脑泡、中脑泡和菱脑泡。
- [ ] 第 $5$ 周，前脑泡头端向两侧膨大成左、右端脑（telencephalon），以后演变为两个大脑半球。
- [ ] 前脑泡尾端形成间脑（diencephalon）。
- [ ] 中脑泡演变为中脑（mesencephalon）。
- [ ] 菱脑泡头段演变为后脑（metencephalon），再演变为脑桥和小脑。
- [ ] 菱脑泡尾段演变为末脑（myelencephalon），再演变为延髓。
- [ ] 前脑泡的腔演变为左、右侧脑室和间脑中的第三脑室。
- [ ] 中脑泡的腔形成狭窄的中脑导水管。
- [ ] 菱脑泡的腔演变为宽大的第四脑室。
- [ ] 端脑形成嗅脑、纹状体、大脑半球，构成侧脑室和第三脑室前部。
- [ ] 间脑形成丘脑、视交叉、灰白结节、乳头体、脑垂体神经部，构成第三脑室大部。
- [ ] 中脑形成四叠体、被盖、大脑脚，构成中脑导水管。
- [ ] 首先出现凸向背侧的头曲（cephalic flexure，又称中脑曲）和颈曲（cervical flexure，位于末脑与脊髓之间）。
- [ ] 之后出现凸向腹侧的端脑曲（telencephalic flexure）和脑桥曲（pontine flexure）。
- [ ] 套层腹侧部增厚成左、右基板（basal plate），背侧部增厚成左、右翼板（alar plate）。
- [ ] 基板和翼板增厚使神经管内表面出现左、右相对的界沟（sulcus limitans）。
- [ ] 端脑和间脑的套层大部分形成翼板，基板甚小。
- [ ] 端脑套层大部分细胞迁至外表面形成大脑皮质，少部分聚集成团形成神经核。
- [ ] 中脑、后脑和末脑的套层细胞多聚集成细胞团或柱，形成各种神经核。
- [ ] 翼板中的神经核多为感觉中继核，基板中的神经核多为运动核。
- [ ] 大脑皮质发生分 $3$ 个阶段：古皮质、旧皮质、新皮质，重演种系发生。
- [ ] 海马和齿状回是最早出现的皮质，相当于古皮质（archicortex）。
- [ ] 第 $7$ 周在纹状体外侧形成梨状皮质，相当于旧皮质（paleocortex）。
- [ ] 新皮质（neocortex）出现最晚、面积最大；出生时已形成 $6$ 层。
- [ ] 越早产生和迁移的细胞位置越深，越晚的越表浅。
- [ ] 古皮质和旧皮质分层无一定规律，有的不明显，有的分为 $3$ 层。
- [ ] 第 $8$ 周皮质内已出现突触；过程包括轴突生长终止、树突和树突棘发育、突触部位选择和突触形成。
- [ ] 小脑起源于后脑翼板背侧部的菱唇；两侧菱唇中线融合形成小脑板（cerebellar plate）。
- [ ] 第 $12$ 周小脑板外侧部膨大成小脑半球，中部变细成小脑蚓。
- [ ] 小脑板起初为室管膜层、套层和边缘层；神经上皮迁到边缘层表面形成外颗粒层（浅层皮质）。
- [ ] 外颗粒层仍能分裂，使小脑表面扩大起皱，形成小脑叶片。
- [ ] 第 $6$ 个月套层外层成神经细胞分化为浦肯野细胞和高尔基细胞，构成浦肯野细胞层。
- [ ] 套层内层成神经细胞聚集成团，分化为齿状核等白质核团。
- [ ] 外颗粒层大部分细胞向内迁，分化为颗粒细胞，构成内颗粒层（后改称颗粒层）。
- [ ] 外颗粒层存留细胞分化为篮状细胞和星形细胞，与浦肯野树突、颗粒细胞轴突共同形成分子层。
- [ ] 外颗粒层细胞的内迁持续到生后第 $7$ 个月。
:::
