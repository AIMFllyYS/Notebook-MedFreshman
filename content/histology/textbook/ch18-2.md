# 二、生殖管道

男性生殖管道包括附睾、输精管及尿道，为精子的成熟、贮存和输送提供有利的环境。精子在睾丸里已经形成，但还不会运动、也未达到功能成熟；这本账从输出小管接到附睾管，再由输精管在射精时快速排出。

:::definition{label="男性生殖管道"}
男性生殖管道包括附睾、输精管及尿道。职分是为精子的成熟、贮存和输送提供有利环境，本身不进行精子发生。
:::

:::concept{term="先问这段管子还在造精子吗，再问它是输出小管、附睾管还是输精管"}
离开睾丸网以后，上皮里不再有生精细胞。先看管腔规则不规则：高低柱状细胞相间、腔不规则，是输出小管；腔规则、假复层柱状加静纤毛，是附睾管；壁厚腔小、内纵中环外纵三层肌，是输精管。把附睾听成“另一段生精小管”，血-附睾屏障和 8～17 天的成熟账都会写丢。
:::

:::compare{title="睾丸内通道与睾丸外生殖管道"}
| 项目 | 直精小管、睾丸网 | 附睾、输精管、尿道 |
|------|-------------------|---------------------|
| 位置 | 睾丸内，纵隔侧 | 睾丸外 |
| 有无生精上皮 | 无生精细胞 | 无生精细胞 |
| 职分 | 把已形成的精子运出睾丸 | 成熟、贮存、输送 |
| 本章位置 | 第 18-1 节 | 本节 |
:::

## （一）附睾

附睾（epididymis）位于睾丸的后外侧，分头、体、尾 3 部分。头部主要由输出小管组成，体部和尾部由附睾管组成（见图 18-1，图 18-11）。

:::definition{label="附睾"}
附睾（epididymis）位于睾丸的后外侧，分头、体、尾 3 部分。头部主要由输出小管组成，体部和尾部由附睾管组成。精子在此停留 $8\sim 17$ 天，获得运动能力并达到功能成熟。
:::

:::definition{label="附睾头、体、尾"}
头部主要由与睾丸网相连的输出小管组成；体部和尾部由极度盘曲的附睾管组成。远端附睾管与输精管相连。
:::

### 1. 输出小管

输出小管（efferent duct）是与睾丸网连接的 $8\sim 12$ 根弯曲小管，上皮由高柱状纤毛细胞及矮柱状细胞相间排列构成，故管腔不规则。高柱状纤毛细胞游离面有大量纤毛，纤毛摆动可促使精子向附睾管运行。矮柱状细胞含大量溶酶体及吞饮小泡，可吸收和消化管腔内物质。输出小管远端与附睾管相连。

:::definition{label="输出小管"}
输出小管（efferent duct）是与睾丸网连接的 $8\sim 12$ 根弯曲小管。上皮由高柱状纤毛细胞和矮柱状细胞相间排列，故管腔不规则。远端与附睾管相连。
:::

:::definition{label="输出小管高柱状纤毛细胞"}
游离面有大量纤毛。纤毛摆动促使精子向附睾管运行。这是能摆动的运动纤毛，不是附睾管主细胞表面的静纤毛。
:::

:::definition{label="输出小管矮柱状细胞"}
含大量溶酶体及吞饮小泡，可吸收和消化管腔内物质。与高柱状纤毛细胞相间排列，是管腔不规则的形态原因。
:::

### 2. 附睾管

附睾管（epididymal duct）为长 $4\sim 6\,\mathrm{m}$、极度盘曲的管道，远端与输精管相连，管腔规则，腔内充满精子和分泌物。附睾管上皮为假复层柱状上皮，由主细胞和基细胞组成。主细胞在附睾管起始段为高柱状，而后逐渐变低，至末段转变为立方形。细胞表面有成簇排列的粗而长的静纤毛，细胞有分泌和吸收功能。基细胞矮小，呈锥形，位于上皮深层。上皮外侧有薄层平滑肌和富含血管的疏松结缔组织。

精子在附睾内停留 $8\sim 17$ 天，并经历一系列成熟变化，获得运动能力，达到功能上的成熟。这不仅依赖于雄激素的存在，而且与附睾上皮细胞分泌的肉毒碱、甘油磷酸胆碱和唾液酸等密切相关。附睾的功能异常也会影响精子的成熟，导致不育。血-附睾屏障（blood-epididymis barrier）位于主细胞近腔面的紧密连接处，能保护成熟中的精子不受外界干扰，并将精子与免疫系统隔离。

:::definition{label="附睾管"}
附睾管（epididymal duct）长 $4\sim 6\,\mathrm{m}$，极度盘曲，远端连输精管。管腔规则，腔内充满精子和分泌物。上皮为假复层柱状上皮，由主细胞和基细胞组成。
:::

:::definition{label="附睾管主细胞"}
主细胞在起始段为高柱状，而后逐渐变低，至末段转变为立方形。表面有成簇排列的粗而长的静纤毛，具有分泌和吸收功能。近腔面的紧密连接构成血-附睾屏障。
:::

:::definition{label="附睾管基细胞"}
基细胞矮小，呈锥形，位于上皮深层。
:::

:::definition{label="静纤毛"}
附睾管主细胞表面成簇排列的粗而长的静纤毛。它是微绒毛样结构，不摆动，与输出小管高柱状细胞的运动纤毛不是一本账。
:::

:::definition{label="精子在附睾内的成熟"}
精子在附睾内停留 $8\sim 17$ 天（本章小结亦称约 2 周），经历一系列成熟变化，获得运动能力，达到功能成熟。依赖雄激素，并与附睾上皮分泌的肉毒碱、甘油磷酸胆碱和唾液酸等密切相关。附睾功能异常可导致不育。
:::

:::definition{label="血-附睾屏障"}
血-附睾屏障（blood-epididymis barrier）位于主细胞近腔面的紧密连接处。保护成熟中的精子不受外界干扰，并将精子与免疫系统隔离。
:::

:::compare{title="输出小管与附睾管"}
| 项目 | 输出小管 | 附睾管 |
|------|----------|--------|
| 位置 | 附睾头部，连睾丸网，$8\sim 12$ 根 | 附睾体部和尾部，长 $4\sim 6\,\mathrm{m}$，极度盘曲 |
| 上皮 | 高柱状纤毛细胞与矮柱状细胞相间 | 假复层柱状上皮：主细胞 + 基细胞 |
| 管腔 | 不规则 | 规则，充满精子和分泌物 |
| 游离面 | 运动纤毛，摆动推送精子 | 成簇粗长静纤毛，不摆动 |
| 吸收 | 矮柱状细胞：溶酶体、吞饮小泡 | 主细胞有分泌和吸收功能 |
| 屏障 | 不作为血-附睾屏障的主账 | 主细胞近腔面紧密连接 = 血-附睾屏障 |
| 下游 | 连附睾管 | 连输精管 |
:::

:::compare{title="血-睾屏障与血-附睾屏障"}
| 项目 | 血-睾屏障 | 血-附睾屏障 |
|------|-----------|--------------|
| 位置 | 生精小管与血液之间 | 附睾管主细胞近腔面 |
| 核心结构 | 支持细胞近基底部紧密连接（外加内皮及基膜、结缔组织、生精上皮基膜） | 主细胞近腔面的紧密连接 |
| 隔离对象 | 生精过程中的精子抗原；维持精子发生微环境 | 成熟中的精子；与免疫系统隔离 |
| 住在屏障腔内的细胞 | 近腔室：精母细胞、精子细胞、精子 | 附睾管腔内的成熟中精子 |
:::

:::pitfall{label="输出小管管腔不规则，不要和附睾管的规则管腔写反"}
高低柱状细胞相间，腔缘像锯齿，这是输出小管的身份证。附睾管腔规则、充满精子。只写“附睾里都是一样的小管”，头部和体尾会认错，纤毛和静纤毛也会并成一句。
:::

:::pitfall{label="附睾管的静纤毛不能摆动，不要写成输出小管那种运动纤毛"}
输出小管高柱状细胞的纤毛负责把精子推向附睾管；附睾管主细胞的静纤毛成簇、粗而长，职分是扩大表面积做分泌和吸收。把静纤毛听成“也会扫精子”，成熟所需的肉毒碱、甘油磷酸胆碱和唾液酸会失去细胞学落点。
:::

:::insight{label="睾丸交出的是还不会动的精子，附睾用八到十七天把它养成"}
离开睾丸网时精子形态已经是蝌蚪，功能并未成熟。附睾管靠雄激素加上肉毒碱、甘油磷酸胆碱、唾液酸，让它获得运动能力。血-附睾屏障把这几天的成熟过程再隔离一次。附睾一坏，精液里可以有精子，却仍可不育。
:::

:::note{label="附睾上皮外侧"}
附睾管上皮外侧有薄层平滑肌和富含血管的疏松结缔组织。肌层远薄于输精管，射精的强力收缩不在这里记账。
:::

## （二）输精管

输精管是壁厚腔小的肌性管道，管壁由黏膜、肌层和外膜组成。黏膜表面为较薄的假复层柱状上皮，固有层结缔组织中弹性纤维丰富。肌层厚，由内纵行、中环行和外纵行排列的平滑肌纤维组成（图 18-12）。在射精时，肌层强力收缩将精子快速排出。

:::definition{label="输精管"}
输精管是壁厚腔小的肌性管道，管壁由黏膜、肌层和外膜组成。射精时肌层强力收缩，将精子快速排出。
:::

:::definition{label="输精管黏膜"}
黏膜表面为较薄的假复层柱状上皮。固有层结缔组织中弹性纤维丰富。
:::

:::definition{label="输精管肌层"}
肌层厚，由内纵行、中环行和外纵行排列的平滑肌纤维组成。这是射精时把精子快速排出的结构基础。
:::

:::definition{label="输精管外膜"}
外膜为管壁最外层。与黏膜、肌层共同构成输精管的三层壁。
:::

::figure{src="/images/histology/textbook/p0207_02.png" caption="图18-12 输精管光镜图。1. 黏膜；2. 肌层（内纵行）；3. 肌层（中环行）；4. 肌层（外纵行）；5. 外膜。" alt="输精管横切：腔小，黏膜形成皱襞，外侧依次为内纵、中环、外纵三层厚平滑肌及外膜"}

:::compare{title="附睾管与输精管"}
| 项目 | 附睾管 | 输精管 |
|------|--------|--------|
| 管壁特点 | 上皮外侧仅薄层平滑肌 | 壁厚腔小的肌性管道 |
| 上皮 | 假复层柱状（主细胞 + 基细胞），有静纤毛 | 较薄的假复层柱状上皮 |
| 管腔 | 规则，充满精子和分泌物 | 小 |
| 肌层 | 薄 | 厚：内纵、中环、外纵三层 |
| 固有层 | 富含血管的疏松结缔组织 | 弹性纤维丰富 |
| 职分 | 精子停留 $8\sim 17$ 天，成熟、贮存 | 射精时强力收缩，快速排出精子 |
:::

:::pitfall{label="输精管肌层是内纵、中环、外纵，不要写成消化管那种内环外纵"}
三层顺序是内纵行、中环行、外纵行，和输尿管下 $1/3$、膀胱肌层同一模板，和消化管常见的内环外纵正好对调。套错模板，切片上靠腔的那一层会被写成环行肌。
:::

:::insight{label="附睾把精子养熟，输精管负责一次性推出去"}
附睾管盘曲数米、肌层薄，适合停留和成熟；输精管壁厚腔小、三层肌，适合射精时把贮存的精子快速排出。两段都衬假复层柱状上皮，职分却不是一本账。尿道的组织学落点主要在阴茎海绵体那一节，不在生精上皮里。
:::

:::keypoint{label="生殖管道先分输出小管和附睾管，再把血-附睾屏障和输精管三层肌收口"}
- 生殖管道 = 附睾 + 输精管 + 尿道；管成熟、贮存和输送，不造精子。
- 附睾头 = 输出小管（$8\sim 12$ 根，腔不规则，运动纤毛 + 吸收细胞）；体尾 = 附睾管（$4\sim 6\,\mathrm{m}$，腔规则，假复层柱状，静纤毛）。
- 精子在附睾停留 $8\sim 17$ 天，依赖雄激素及肉毒碱、甘油磷酸胆碱、唾液酸获得运动能力。
- 血-附睾屏障 = 主细胞近腔面紧密连接。
- 输精管壁厚腔小：较薄假复层柱状上皮，固有层弹性纤维丰富，肌层内纵中环外纵，射精时强力收缩。
:::
