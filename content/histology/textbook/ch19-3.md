# 三、子宫

子宫为肌性器官，腔小壁厚。子宫壁由内向外分为内膜、肌层和外膜 3 层（图 19-9）。自青春期开始，宫体和宫底的内膜在卵巢激素作用下按月经周期剥脱、出血、修复和增生；宫颈黏膜不周期性剥落。本节先把三层壁摊开，再把内膜三期、宫颈和神经内分泌调节收口。

:::definition{label="子宫"}
子宫是形成月经和孕育胎儿的肌性器官，腔小壁厚。壁分内膜（endometrium）、肌层（myometrium）和外膜（perimetrium）。
:::

:::concept{term="先问这是内膜、肌层还是外膜，再问内膜是哪一期"}
看见子宫，先沿半径记账：最内是单层柱状上皮加固有层（内膜），中间最厚是平滑肌（肌层），底和体部外覆浆膜、宫颈为纤维膜（外膜）。内膜还要再问两把尺子：靠近腔的是功能层还是靠近肌层的基底层；今天是周期第几天——第 $1\sim 4$ 天月经期、第 $5\sim 14$ 天增生期、第 $15\sim 28$ 天分泌期。把三层壁听成“整块都会来月经”，基底层和宫颈会被一起剥掉。
:::

:::compare{title="内膜、肌层与外膜"}
| 项目 | 内膜 | 肌层 | 外膜 |
|------|------|------|------|
| 英文 | endometrium | myometrium | perimetrium |
| 位置 | 最内，衬子宫腔 | 中间，最厚，约 $1\,\mathrm{cm}$ | 最外 |
| 组成 | 单层柱状上皮 + 固有层（基质细胞、子宫腺、螺旋动脉） | 平滑肌束 + 束间结缔组织 | 宫底、宫体为浆膜；宫颈为纤维膜 |
| 周期 | 功能层随周期剥脱与重建 | 不剥脱；妊娠时肌纤维显著增生肥大 | 不形成月经 |
| 分层 | 功能层 / 基底层 | 黏膜下层、中间层、浆膜下层 | — |
:::

## （一）子宫壁的结构

### 1. 内膜

子宫内膜（黏膜）随年龄和功能状态不同而发生结构和厚薄改变。由单层柱状上皮和固有层组成。上皮与输卵管上皮相似，也由纤毛细胞和分泌细胞构成。固有层由结缔组织及子宫腺和血管等组成。结缔组织中有大量分化程度较低的梭形或星形细胞，称为基质细胞（stromal cell），核大而圆，胞质较少，可合成及分泌胶原蛋白，并随子宫内膜周期性变化而增生与分化。子宫腺（uterine gland）为内膜表面上皮向固有层凹陷形成的单管或分支管状腺；腺上皮主要是分泌细胞，纤毛细胞较少。子宫动脉分支通过肌层进入内膜，呈螺旋状走行，称为螺旋动脉（spiral artery），对性激素反应敏感而迅速。此动脉至内膜浅部分支吻合形成毛细血管网和扩大的窦状毛细血管，然后汇入小静脉，经肌层汇合为子宫静脉（图 19-10）。

:::definition{label="内膜"}
内膜（endometrium）即子宫黏膜，由单层柱状上皮和固有层组成。上皮含纤毛细胞和分泌细胞，与输卵管上皮相似。厚薄和结构随年龄及功能状态改变。
:::

:::definition{label="基质细胞"}
基质细胞（stromal cell）是固有层中大量分化程度较低的梭形或星形细胞。核大而圆，胞质较少，合成及分泌胶原蛋白，并随内膜周期增生与分化。分泌晚期可变为前蜕膜细胞。
:::

:::definition{label="子宫腺"}
子宫腺（uterine gland）是内膜表面上皮向固有层凹陷形成的单管或分支管状腺。腺上皮主要是分泌细胞，纤毛细胞较少。
:::

:::definition{label="螺旋动脉"}
螺旋动脉（spiral artery）是子宫动脉穿过肌层进入内膜后呈螺旋状走行的分支，对性激素反应敏感而迅速。在内膜浅部吻合成毛细血管网和扩大的窦状毛细血管，再汇入小静脉，经肌层汇合为子宫静脉。
:::

::figure{src="/images/histology/textbook/p0216_01.png" caption="图19-10 子宫内膜血管与子宫腺模式图。示螺旋动脉、基底动脉、肌层动脉、毛细血管网、血窦、静脉与子宫腺。" alt="内膜立体模式：螺旋动脉盘曲上行至浅层吻合成毛细血管网和血窦，子宫腺贯穿内膜，深层可见基底动脉"}

子宫底部和体部的内膜，根据结构和功能特点可分深浅两层。浅层为功能层（functional layer），较厚，靠近子宫腔，每次月经来潮时发生脱落，胚泡也在此层内植入。深层为靠近肌层较薄的内膜部分，称为基底层（basal layer），该层在月经期和分娩时均不脱落，并有较强的增生和修复能力，可以产生新的功能层。

:::definition{label="功能层"}
功能层（functional layer）是靠近子宫腔的较厚内膜。每次月经来潮时脱落；胚泡在此层内植入。
:::

:::definition{label="基底层"}
基底层（basal layer）是靠近肌层的较薄内膜。月经期和分娩时均不脱落，增生修复能力强，可以产生新的功能层。
:::

:::compare{title="功能层与基底层"}
| 项目 | 功能层 | 基底层 |
|------|--------|--------|
| 位置 | 浅层，靠近宫腔 | 深层，靠近肌层 |
| 厚度 | 较厚 | 较薄 |
| 月经期 | 脱落、出血 | 不脱落 |
| 分娩 | 随胎盘附着部变化 | 不脱落 |
| 职分 | 植入部位；分泌期内膜主要功能面 | 保留下来，修复并产生新的功能层 |
| 血管 | 螺旋动脉伸入浅层 | 有基底动脉等，维持修复 |
:::

:::pitfall{label="功能层剥脱，基底层保留，不要写成内膜全层脱落"}
月经期坏死、出血、排出的是功能层。基底层在月经期和分娩时都不脱落，正是靠它把新的功能层长回来。写成“子宫内膜全部剥掉”，下一周期的增生期就没有出发点。
:::

### 2. 肌层

肌层最厚，约 $1\,\mathrm{cm}$，由平滑肌束与束间结缔组织组成。结缔组织中有血管和各种结缔组织细胞，其中未分化间充质细胞尤为丰富。肌层大致可分 3 层，即黏膜下层、中间层和浆膜下层。黏膜下和浆膜下肌层较薄，主要由纵行平滑肌束构成；中间层较厚，由环行和斜行平滑肌束组成，并含有丰富的血管。子宫肌层的收缩有助于精子向输卵管运行、经血排出以及胎儿娩出。

成年女性子宫平滑肌纤维长 $30\sim 50\,\mu\mathrm{m}$，妊娠时肌纤维增生，可增长数十倍，长达 $500\,\mu\mathrm{m}$，肌层增厚。增生的平滑肌纤维来自未分化间充质细胞或平滑肌纤维自身的分裂。雌激素能促使平滑肌纤维数量增加；孕激素能使平滑肌纤维体积增大，并有抑制平滑肌收缩的作用。分娩后子宫平滑肌纤维可逐渐变小，恢复原状，有部分平滑肌纤维自溶分解而被吸收。

:::definition{label="肌层"}
肌层（myometrium）最厚，约 $1\,\mathrm{cm}$，由平滑肌束与束间结缔组织组成。束间结缔组织富含血管，未分化间充质细胞尤为丰富。
:::

:::definition{label="肌层三层"}
黏膜下层、中间层、浆膜下层。黏膜下和浆膜下较薄，主要由纵行平滑肌束构成；中间层较厚，由环行和斜行平滑肌束组成，并含丰富血管。
:::

:::definition{label="妊娠期平滑肌变化"}
成年女性子宫平滑肌纤维长 $30\sim 50\,\mu\mathrm{m}$；妊娠时可增长数十倍，长达 $500\,\mu\mathrm{m}$。新增纤维来自未分化间充质细胞或平滑肌自身分裂。雌激素增加数量，孕激素增大体积并抑制收缩。分娩后逐渐变小恢复，部分自溶分解被吸收。
:::

:::note{label="雌激素与孕激素对肌层的不同账"}
| 激素 | 对平滑肌 |
|------|----------|
| 雌激素 | 促使平滑肌纤维数量增加 |
| 孕激素 | 使平滑肌纤维体积增大，并抑制收缩 |
:::

:::insight{label="中间层血管多，收缩既能帮精子上行，也能把经血和胎儿送出"}
肌层不是只会“生孩子时用力”。未孕时收缩有助于精子向输卵管运行和经血排出；妊娠时纤维又长又多，为娩出做准备。孕激素把收缩按住，免得把胚泡提前挤走。
:::

### 3. 外膜

子宫底和体部为薄层结缔组织和间皮组成的浆膜，宫颈处为纤维膜。

:::definition{label="外膜"}
外膜（perimetrium）：宫底和宫体为浆膜（薄层结缔组织 + 间皮）；宫颈处为纤维膜。
:::

:::compare{title="宫体浆膜与宫颈纤维膜"}
| 项目 | 宫底、宫体 | 宫颈 |
|------|------------|------|
| 外膜类型 | 浆膜 | 纤维膜 |
| 组成 | 薄层结缔组织 + 间皮 | 结缔组织 |
| 内膜周期剥脱 | 宫体、宫底内膜有功能层剥脱 | 宫颈黏膜不周期性剥落 |
:::

## （二）子宫内膜的周期性变化

自青春期开始，子宫内膜（宫颈除外）在卵巢分泌的激素作用下出现周期性变化，即每隔约 $28$ 天发生一次内膜剥脱、出血、修复和增生，称为月经周期（menstrual cycle）。每个月经周期从月经第 $1$ 天起至下次月经来潮前 $1$ 天止，可分为月经期、增生期和分泌期 3 个时期（图 19-11）。

:::definition{label="月经周期"}
月经周期（menstrual cycle）是自青春期开始，子宫内膜（宫颈除外）在卵巢激素作用下每隔约 $28$ 天发生的一次剥脱、出血、修复和增生。从月经第 $1$ 天起至下次月经来潮前 $1$ 天止，分为月经期、增生期和分泌期。
:::

:::concept{term="先对日期，再对卵巢：增生期对卵泡，分泌期对黄体，月经期对黄体退化"}
三期不要按“先来月经再长内膜”以外的顺序乱记。日期尺子：第 $1\sim 4$ 天月经期，第 $5\sim 14$ 天增生期，第 $15\sim 28$ 天分泌期。卵巢尺子：增生期是卵泡期，雌激素修复基底层；第 $14$ 天左右排卵后进入分泌期（黄体期），孕激素加雌激素让内膜变厚、腺腔充满糖原；黄体一退化，激素骤降，功能层缺血坏死，又回到月经期。
:::

:::compare{title="增生期、分泌期与月经期"}
| 项目 | 增生期 | 分泌期 | 月经期 |
|------|--------|--------|--------|
| 日期 | 第 $5\sim 14$ 天 | 第 $15\sim 28$ 天 | 第 $1\sim 4$ 天 |
| 又称 | 卵泡期 | 黄体期 | — |
| 卵巢 | 次级卵泡向成熟卵泡发育，分泌雌激素；第 $14$ 天排卵 | 黄体形成，分泌孕激素和雌激素 | 月经黄体退化，雌、孕激素骤降 |
| 内膜厚度 | 由约 $1\,\mathrm{mm}$ 增至 $2\sim 4\,\mathrm{mm}$ | 继续增厚达 $5\sim 7\,\mathrm{mm}$ | 功能层萎缩坏死并脱落 |
| 子宫腺 | 早期短直细少 → 中期增长轻度弯曲 → 晚期核下空泡，末期开始分泌 | 更长更弯，腺腔扩大，糖原至核上区，顶浆分泌，腔内充满黏稠液体 | 分泌停止 |
| 螺旋动脉 | 更加伸长和弯曲 | 更弯曲并伸入内膜浅层 | 先持续性收缩（缺血），再突然短暂扩张而破裂 |
| 基质 | 梭形基质细胞分裂增殖，产生大量纤维和基质 | 组织液增多呈水肿；晚期部分细胞成前蜕膜细胞 | 组织液减少，功能层坏死 |
| 结局 | 第 $14$ 天排卵后转入分泌期 | 妊娠则蜕膜化；未妊娠转入月经期 | 基底层腺上皮修复表面，转入增生期 |
:::

### 1. 增生期

增生期（proliferative phase）指月经周期的第 $5\sim 14$ 天。此期间卵巢内有一些次级卵泡开始生长，向成熟卵泡发育，并分泌雌激素，故又称卵泡期（follicular phase）。雌激素使子宫内膜由残存的基底层增生修复：梭形基质细胞分裂增殖，产生大量纤维和基质，内膜由 $1\,\mathrm{mm}$ 左右增厚达 $2\sim 4\,\mathrm{mm}$。增生早期子宫腺短、直、细而少；增生中期子宫腺增多、增长并轻度弯曲；增生晚期腺细胞顶部有分泌颗粒，核下区糖原集聚，在染色切片上糖原被溶解而显示核下空泡；增生末期子宫腺增长弯曲，腺腔增大，开始分泌；螺旋动脉更加伸长和弯曲。至月经周期第 $14$ 天，卵巢内通常有一个卵泡发育成熟并排卵，子宫内膜随之转入分泌期。

:::definition{label="增生期"}
增生期（proliferative phase）为月经周期第 $5\sim 14$ 天，又称卵泡期（follicular phase）。雌激素使残留基底层增生修复，内膜由约 $1\,\mathrm{mm}$ 增厚至 $2\sim 4\,\mathrm{mm}$。
:::

:::definition{label="核下空泡"}
增生晚期腺细胞顶部有分泌颗粒，核下区糖原集聚；染色切片上糖原被溶解，显示为核下空泡。这是增生晚期的形态标记，还不是分泌期腺腔充满黏液的状态。
:::

:::note{label="增生期子宫腺的时间轴"}
| 阶段 | 子宫腺 |
|------|--------|
| 早期 | 短、直、细而少 |
| 中期 | 增多、增长并轻度弯曲 |
| 晚期 | 顶部分泌颗粒，核下区糖原 → 切片上核下空泡 |
| 末期 | 增长弯曲，腺腔增大，开始分泌；螺旋动脉更长更弯 |
:::

### 2. 分泌期

分泌期（secretory phase）指月经周期第 $15\sim 28$ 天。此时黄体形成，故又称黄体期（luteal phase）。在黄体分泌的孕激素和雌激素作用下，子宫内膜继续增生变厚，达 $5\sim 7\,\mathrm{mm}$。子宫腺进一步变长、弯曲、腺腔扩大，糖原由腺细胞核下区转移到细胞顶部核上区，并以顶浆分泌方式排入腺腔，使腺腔内充满含有糖原等营养物质的黏稠液体。固有层内组织液增多呈水肿状态。螺旋动脉继续增长，变得更弯曲并伸入内膜浅层。基质细胞继续分裂增殖，到分泌晚期部分细胞增大变圆，胞质内充满糖原和脂滴，称为前蜕膜细胞（predecidual cell）。妊娠时此细胞变为蜕膜细胞（decidua cell）。如未妊娠，内膜功能层将脱落，转入月经期。

:::definition{label="分泌期"}
分泌期（secretory phase）为月经周期第 $15\sim 28$ 天，又称黄体期（luteal phase）。孕激素和雌激素使内膜继续增厚达 $5\sim 7\,\mathrm{mm}$，适于胚泡植入。
:::

:::definition{label="顶浆分泌与腺腔营养液"}
分泌期糖原从核下区转到核上区，以顶浆分泌方式排入腺腔，腺腔内充满含糖原等营养物质的黏稠液体。这是分泌期区别于增生期的关键形态。
:::

:::definition{label="前蜕膜细胞"}
分泌晚期部分基质细胞增大变圆，胞质充满糖原和脂滴，称为前蜕膜细胞（predecidual cell）。妊娠时变为蜕膜细胞（decidua cell）；未妊娠则随功能层脱落。
:::

:::definition{label="蜕膜细胞"}
妊娠时前蜕膜细胞转变为蜕膜细胞（decidua cell）。未妊娠不会出现这一步，功能层转入月经期脱落。
:::

### 3. 月经期

月经期（menstrual phase）指月经周期的第 $1\sim 4$ 天。此期卵巢月经黄体退化，雌激素和孕激素骤然下降，引起功能层螺旋动脉持续性收缩，使内膜缺血，子宫腺分泌停止，组织液减少，从而功能层发生萎缩坏死。继而螺旋动脉又突然短暂地扩张，致使功能层的血管破裂，血液流出并积聚在内膜浅部，最后与坏死的内膜一起剥落并经阴道排出，即月经（menstruation）。在月经期结束之前，内膜基底层残留的子宫腺上皮开始迅速增生，并向子宫腔表面推移，使子宫内膜上皮得到修复。待月经期结束，其他组织也开始增生而转入增生期。

:::definition{label="月经期"}
月经期（menstrual phase）为月经周期第 $1\sim 4$ 天。月经黄体退化，雌、孕激素骤降，功能层缺血坏死并脱落出血。
:::

:::definition{label="月经"}
月经（menstruation）是功能层坏死内膜与血液一起剥落、经阴道排出的过程。基底层不脱落。
:::

:::definition{label="螺旋动脉在月经期的两步"}
先持续性收缩 → 功能层缺血、腺体停止分泌、组织液减少、萎缩坏死；再突然短暂扩张 → 血管破裂出血。两步都发生在功能层的螺旋动脉，不是基底层被一起切断。
:::

::figure{src="/images/histology/textbook/p0217_01.png" caption="图19-11 子宫内膜周期性变化示意图。示月经期功能层脱落出血，增生早期和增生晚期腺体由短直到弯曲，分泌期内膜显著增厚、腺体极度弯曲扩张。" alt="内膜四态：月经期浅层出血脱落，增生早期薄而腺体短直，增生晚期腺体增多弯曲，分泌期最厚腺体扩张"}

:::insight{label="基底层是留种的那一层，功能层才是每个月拆掉重建的工地"}
雌激素把基底层修成增生期内膜，排卵后孕激素把工地改成适合植入的分泌期；没有受精，激素一撤，螺旋动脉先掐后放，功能层连血带组织经阴道排出。下一周期的第一块砖，仍然来自没脱落的基底层腺上皮。
:::

:::pitfall{label="月经期不是“内膜从第1天开始生长”，增生期才从第5天起修"}
周期从月经第 $1$ 天起算，前 $4$ 天是在剥功能层；修复在月经期末已经启动，真正增生增厚写在第 $5\sim 14$ 天。把月经期听成增生的开始，腺体短直和核下空泡会记到出血那几天。
:::

## （三）子宫颈

子宫颈壁由黏膜、肌层和外膜组成。黏膜由上皮和固有层组成，并突向管腔形成皱襞（图 19-12）。子宫颈管腔面上皮为单层柱状上皮，由较多分泌细胞、少量纤毛细胞以及储备细胞（reserve cell）构成。分泌细胞呈柱状，其分泌黏液的功能也随雌激素和孕激素水平改变发生周期性变化。纤毛细胞游离面的纤毛朝阴道方向摆动，可促使相邻分泌细胞的分泌物排出并流向阴道。储备细胞较小，散在于柱状细胞和基膜之间，分化程度较低，有增殖修复柱状上皮的功能。在有慢性炎症时，此细胞可增殖化生为复层扁平上皮样细胞；在增殖过程中也可发生癌变。宫颈阴道部的黏膜上皮为复层扁平上皮。宫颈外口处是单层柱状上皮与复层扁平上皮的移行区，此处是宫颈癌好发部位。肌层平滑肌纤维较少且分散，分布于致密结缔组织中。外膜是结缔组织构成的纤维膜。

宫颈黏膜不发生周期性剥落，但其分泌物的质量却随卵巢活动周期发生变化。排卵时宫颈腺分泌物增多而稀薄，有利于精子运动。黄体形成时宫颈腺上皮细胞分泌减少且黏稠，使精子难以通过。妊娠期间子宫颈内膜增厚，黏膜皱襞增多，分泌物的黏稠度更高，起到阻止精子和微生物进入子宫的屏障作用。

:::definition{label="子宫颈"}
子宫颈壁由黏膜、肌层和外膜组成。黏膜形成突向管腔的皱襞。宫颈黏膜不发生周期性剥落，这是它和宫体内膜最重要的区别。
:::

:::definition{label="宫颈管上皮"}
宫颈管腔面为单层柱状上皮，由较多分泌细胞、少量纤毛细胞和储备细胞构成。
:::

:::definition{label="储备细胞"}
储备细胞（reserve cell）较小，散在于柱状细胞和基膜之间，分化程度较低，增殖修复柱状上皮。慢性炎症时可化生为复层扁平上皮样细胞，增殖过程中也可癌变。
:::

:::definition{label="移行区"}
宫颈外口处是单层柱状上皮与复层扁平上皮的移行区，是宫颈癌好发部位。宫颈阴道部黏膜上皮为复层扁平上皮。
:::

:::definition{label="宫颈黏液的周期变化"}
排卵时分泌物增多而稀薄，利于精子运动；黄体形成时分泌减少且黏稠，精子难以通过；妊娠期内膜增厚、皱襞增多、黏液更黏稠，阻止精子和微生物进入子宫。
:::

::figure{src="/images/histology/textbook/p0217_02.png" caption="图19-12 成人子宫颈与阴道交界部示意图。示宫颈管单层柱状上皮、子宫颈腺、固有层，以及外口处移行为复层扁平上皮并与阴道上皮相续。" alt="宫颈阴道交界：左侧宫颈管皱襞衬单层柱状并有宫颈腺，外口转为复层扁平，右侧延续为阴道上皮"}

:::compare{title="宫体内膜与宫颈黏膜"}
| 项目 | 宫体 / 宫底内膜 | 宫颈黏膜 |
|------|------------------|----------|
| 上皮 | 单层柱状（纤毛细胞 + 分泌细胞） | 管腔面单层柱状（分泌细胞为主 + 少量纤毛细胞 + 储备细胞）；阴道部复层扁平 |
| 腺体 | 子宫腺，单管或分支管状 | 宫颈腺，分泌黏液 |
| 周期剥脱 | 功能层周期性脱落 | 不周期性剥落 |
| 周期变化 | 厚度、腺体、螺旋动脉、水肿、前蜕膜细胞 | 主要是黏液量与黏稠度 |
| 外膜 | 浆膜 | 纤维膜 |
| 肌层 | 约 $1\,\mathrm{cm}$，三层平滑肌 | 平滑肌少而分散，埋于致密结缔组织 |
:::

:::pitfall{label="宫颈黏膜不剥脱，不要把月经写成“宫颈也在掉一层”"}
月经只发生在宫体和宫底的功能层。宫颈跟着卵巢改变黏液稀稠，外口移行区是癌的好发部位，但不是每月出血的来源。
:::

:::insight{label="排卵窗口把黏液稀释成精子的通道，黄体和妊娠再把通道封上"}
同一群分泌细胞，排卵时稀薄开门，黄体期黏稠关门，妊娠时更黏当作屏障。储备细胞平时负责修补，炎症刺激下可以化生，化生过度就靠近癌变。外口正好是柱状和复层扁平打架的移行区，所以是宫颈癌好发部位。
:::

## （四）卵巢和子宫内膜周期性变化的神经内分泌调节

子宫内膜的周期性变化受下丘脑–垂体–性腺轴调控。下丘脑神经内分泌细胞产生促性腺激素释放激素，使腺垂体远侧部嗜碱性细胞分泌卵泡刺激素和黄体生成素。卵泡刺激素促进卵巢卵泡生长、发育成熟并分泌大量雌激素。卵巢分泌的雌激素使子宫内膜从月经期转入增生期。当血中雌激素达到一定浓度时，反馈作用于下丘脑和垂体，抑制卵泡刺激素的分泌，但促进黄体生成素的分泌。在黄体生成素和卵泡刺激素协同作用下，卵泡成熟、排卵并形成黄体。黄体产生孕激素和雌激素，促使子宫内膜进入分泌期。当血中孕激素增加到一定浓度时，反馈作用于下丘脑和垂体，抑制黄体生成素释放，于是黄体退化，血中孕激素和雌激素骤然减少，子宫内膜进入月经期。由于血中雌、孕激素减少，又反馈作用于下丘脑和垂体，促使释放卵泡刺激素，卵泡又开始生长发育。上述循环周而复始，下丘脑和垂体有节律地调节卵巢活动周期与子宫内膜周期保持同步，以适应排卵、受精、胚泡植入和生长发育的需要（图 19-13）。

:::definition{label="下丘脑-垂体-性腺轴（女性）"}
下丘脑释放促性腺激素释放激素，刺激腺垂体远侧部嗜碱性细胞分泌 FSH 和 LH。FSH、LH 调控卵巢；卵巢的雌激素、孕激素再反馈调控下丘脑和垂体，使卵巢周期与内膜周期同步。
:::

:::definition{label="卵泡刺激素（女性）"}
卵泡刺激素（FSH）促进卵巢卵泡生长、发育成熟并分泌大量雌激素。雌激素使内膜从月经期转入增生期。
:::

:::definition{label="黄体生成素（女性）"}
黄体生成素（LH）与 FSH 协同，使卵泡成熟、排卵并形成黄体。高浓度孕激素反馈抑制 LH，黄体因而退化。
:::

::figure{src="/images/histology/textbook/p0218_01.png" caption="图19-13 卵泡发育和子宫内膜周期性变化与激素的关系。示垂体 FSH、LH，卵巢卵泡–排卵–黄体–白体，雌激素与孕激素曲线，以及内膜月经期、增生期、分泌期。" alt="激素与内膜对照：LH 峰对应排卵，雌激素主峰在增生期末，孕激素主峰在分泌期，内膜厚度随三期变化"}

:::note{label="激素回路与内膜三期"}
| 环节 | 激素事件 | 内膜结局 |
|------|----------|----------|
| FSH ↑ | 卵泡生长，分泌雌激素 | 月经期 → 增生期 |
| 雌激素达一定浓度 | 反馈抑制 FSH，促进 LH | 增生期末，等待排卵 |
| LH + FSH | 卵泡成熟、排卵、形成黄体 | 转入分泌期 |
| 黄体分泌孕激素 + 雌激素 | 孕激素升至一定浓度，反馈抑制 LH | 分泌期内膜厚 $5\sim 7\,\mathrm{mm}$ |
| LH ↓，黄体退化 | 雌、孕激素骤减 | 进入月经期 |
| 雌、孕激素减少 | 反馈促使 FSH 再释放 | 新一批卵泡开始生长 |
:::

:::compare{title="FSH与LH在女性中的落点"}
| 项目 | FSH | LH |
|------|-----|-----|
| 来源 | 腺垂体远侧部嗜碱性细胞（受 GnRH 刺激） | 同左 |
| 主要效应 | 卵泡生长、发育成熟并分泌雌激素 | 与 FSH 协同：成熟、排卵、形成黄体 |
| 受雌激素反馈 | 高雌激素抑制 FSH | 高雌激素促进 LH（形成排卵前峰） |
| 受孕激素反馈 | — | 高孕激素抑制 LH，黄体因而退化 |
| 对应内膜 | 增生期（卵泡期） | 排卵及分泌期（黄体期）的启动 |
:::

:::pitfall{label="高雌激素对FSH和LH的反馈方向相反，不要写成“雌激素一律负反馈”"}
教材写明：血中雌激素达一定浓度时，抑制 FSH，但促进 LH。正是这把“按住 FSH、抬起 LH”的剪刀差，才出现排卵前 LH 峰。一律写成负反馈，排卵发动会失去激素开关。
:::

:::insight{label="卵巢先出雌激素修内膜，再出孕激素备植入，激素一撤才来月经"}
FSH 催卵泡，雌激素催增生期；LH 峰催排卵和黄体，孕激素催分泌期；孕激素回头按住 LH，黄体散场，功能层才剥脱。内膜从来不是自己在循环，它只是卵巢激素的靶器官。图 19-13 把垂体、卵巢、内膜三条时间轴画在一起，就是要看这本同步账。
:::

:::keypoint{label="子宫先立三层壁和功能层基底层，再把内膜三期、宫颈黏液和HPG轴收口"}
- 壁：内膜、肌层（约 $1\,\mathrm{cm}$）、外膜（宫体浆膜，宫颈纤维膜）。
- 内膜上皮单层柱状；固有层含基质细胞、子宫腺、螺旋动脉。
- 功能层脱落并供植入；基底层月经期和分娩时均不脱落，负责修复。
- 增生期第 $5\sim 14$ 天（卵泡期，雌激素，$2\sim 4\,\mathrm{mm}$）；分泌期第 $15\sim 28$ 天（黄体期，$5\sim 7\,\mathrm{mm}$，顶浆分泌、前蜕膜细胞）；月经期第 $1\sim 4$ 天（黄体退化，螺旋动脉先收缩后扩张）。
- 宫颈黏膜不剥脱；外口移行区是宫颈癌好发部位；排卵黏液稀薄，黄体期和妊娠黏稠。
- 储备细胞可修复，也可化生甚至癌变。
- HPG 轴：GnRH → FSH、LH → 卵巢激素 → 内膜；高雌激素抑制 FSH、促进 LH；高孕激素抑制 LH。
:::

:::memory{label="本节必背要点"}
- [ ] 子宫为肌性器官，腔小壁厚；壁由内向外分为内膜、肌层和外膜 3 层。
- [ ] 内膜（endometrium）由单层柱状上皮和固有层组成；上皮含纤毛细胞和分泌细胞。
- [ ] 基质细胞（stromal cell）为分化较低的梭形或星形细胞，核大而圆，胞质少，合成并分泌胶原蛋白，随周期增生分化。
- [ ] 子宫腺（uterine gland）为表面上皮向固有层凹陷形成的单管或分支管状腺；腺上皮以分泌细胞为主。
- [ ] 螺旋动脉（spiral artery）由子宫动脉入内膜后螺旋走行，对性激素反应敏感而迅速。
- [ ] 螺旋动脉在内膜浅部吻合成毛细血管网和扩大的窦状毛细血管，再汇入小静脉，经肌层汇合为子宫静脉。
- [ ] 功能层（functional layer）较厚、靠近宫腔，每次月经脱落，胚泡在此植入。
- [ ] 基底层（basal layer）较薄、靠近肌层，月经期和分娩时均不脱落，可产生新的功能层。
- [ ] 肌层（myometrium）最厚，约 $1\,\mathrm{cm}$，由平滑肌束与束间结缔组织组成；未分化间充质细胞丰富。
- [ ] 肌层分黏膜下层、中间层和浆膜下层；黏膜下和浆膜下较薄、以纵行为主；中间层较厚，环行和斜行，血管丰富。
- [ ] 肌层收缩有助于精子向输卵管运行、经血排出和胎儿娩出。
- [ ] 成年子宫平滑肌纤维长 $30\sim 50\,\mu\mathrm{m}$，妊娠时可长达 $500\,\mu\mathrm{m}$，增长数十倍。
- [ ] 新增平滑肌来自未分化间充质细胞或平滑肌自身分裂；雌激素增加数量，孕激素增大体积并抑制收缩。
- [ ] 分娩后平滑肌纤维逐渐变小恢复，部分自溶分解被吸收。
- [ ] 宫底和宫体对外膜为浆膜，宫颈处为纤维膜。
- [ ] 月经周期（menstrual cycle）约 $28$ 天，从月经第 $1$ 天至下次月经前 $1$ 天，分为月经期、增生期和分泌期（宫颈除外）。
- [ ] 增生期（proliferative phase）为第 $5\sim 14$ 天，又称卵泡期；雌激素使基底层修复，内膜由约 $1\,\mathrm{mm}$ 增至 $2\sim 4\,\mathrm{mm}$。
- [ ] 增生早期腺体短直细少；中期增多增长并轻度弯曲；晚期出现核下空泡；末期腺体弯曲、开始分泌，螺旋动脉伸长弯曲。
- [ ] 第 $14$ 天通常排卵，内膜转入分泌期。
- [ ] 分泌期（secretory phase）为第 $15\sim 28$ 天，又称黄体期；内膜厚达 $5\sim 7\,\mathrm{mm}$。
- [ ] 分泌期腺体更长更弯、腺腔扩大，糖原转至核上区，顶浆分泌使腺腔充满含糖原的黏稠液体。
- [ ] 分泌期固有层水肿；螺旋动脉更弯曲并伸入浅层。
- [ ] 分泌晚期部分基质细胞成为前蜕膜细胞（predecidual cell）；妊娠时变为蜕膜细胞。
- [ ] 月经期（menstrual phase）为第 $1\sim 4$ 天；月经黄体退化，雌、孕激素骤降。
- [ ] 螺旋动脉先持续性收缩使功能层缺血坏死，再突然短暂扩张而破裂出血，形成月经。
- [ ] 月经期末，基底层残留腺上皮迅速增生修复腔面，随后转入增生期。
- [ ] 子宫颈壁由黏膜、肌层和外膜组成；黏膜形成皱襞。
- [ ] 宫颈管腔面为单层柱状上皮：较多分泌细胞、少量纤毛细胞和储备细胞。
- [ ] 纤毛朝阴道方向摆动，促使分泌物排出并流向阴道。
- [ ] 储备细胞较小，位于柱状细胞与基膜之间，可增殖修复；慢性炎症可化生为复层扁平样细胞，也可癌变。
- [ ] 宫颈阴道部上皮为复层扁平；外口移行区是宫颈癌好发部位。
- [ ] 宫颈肌层平滑肌少而分散；外膜为纤维膜。
- [ ] 宫颈黏膜不周期性剥落；排卵时黏液增多而稀薄，黄体期减少且黏稠，妊娠期更黏稠起屏障作用。
- [ ] 下丘脑 GnRH 使腺垂体远侧部嗜碱性细胞分泌 FSH 和 LH。
- [ ] FSH 促进卵泡生长成熟并分泌雌激素，内膜由月经期转入增生期。
- [ ] 高雌激素抑制 FSH、促进 LH；LH 与 FSH 协同使卵泡成熟、排卵并形成黄体。
- [ ] 黄体产生孕激素和雌激素，内膜进入分泌期。
- [ ] 高孕激素抑制 LH，黄体退化，雌孕激素骤减，内膜进入月经期。
- [ ] 雌孕激素减少又促使 FSH 释放，新卵泡开始生长发育，循环周而复始。
:::
