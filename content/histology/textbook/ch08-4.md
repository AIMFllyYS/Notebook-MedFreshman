# 四、神经节

神经节可分脊神经节、脑神经节和自主神经节 3 种。神经节中的神经元常称为节细胞。周围神经系统的胞体账都写在这里：感觉通路的假单极神经元堆在脊神经节和脑神经节，自主通路的多极节后神经元堆在交感和副交感神经节。上一章的卫星细胞、施万细胞、有髓与无髓纤维，在节内变成认片的具体线索。

:::definition{label="神经节"}
神经节是周围神经系统中神经元胞体集中的结构，可分脊神经节、脑神经节和自主神经节 3 种。节中的神经元常称为节细胞。
:::

:::definition{label="节细胞"}
节细胞是神经节中的神经元。脊神经节和脑神经节的节细胞为感觉神经元，绝大部分是假单极神经元；自主神经节的节细胞主要是自主神经系统的节后神经元，属多极运动神经元。
:::

:::concept{term="先问这颗节细胞是假单极还是多极"}
切片上先数突起、再看核位。假单极、核圆居中、尼氏体细小分散、卫星细胞围成一圈——感觉神经节（脊神经节、脑神经节）。多极、核常偏位、部分双核、卫星细胞较少——自主神经节。把所有神经节都听成“一堆圆细胞”，交感节后纤维和脊神经节中枢突会认串。
:::

## 1. 脊神经节

脊神经节是脊髓两侧的脊神经背根上的膨大结构，属感觉神经节，内含许多假单极神经元（感觉神经元）胞体群和平行排列的神经纤维束。神经元胞体多呈圆形，大小不等，核圆形，位于胞体中央，核仁明显，细胞质内的尼氏体细小而分散。从胞体发出一个突起，其根部在胞体附近盘曲，然后呈 T 形分支，一支（中枢突）进入脊髓，另一支（周围突）经脊神经分布到其他器官，其终末形成感觉神经末梢。神经元胞体及其附近盘曲的胞突外面有一层卫星细胞包裹，在 T 形分支处改由施万细胞包裹。脊神经节内的神经纤维大部分是有髓神经纤维（图 8-10）。

:::definition{label="脊神经节"}
脊神经节是脊髓两侧脊神经背根上的膨大结构，属感觉神经节。内含许多假单极神经元（感觉神经元）胞体群和平行排列的神经纤维束。节内神经纤维大部分是有髓神经纤维。
:::

:::definition{label="脊神经节细胞"}
脊神经节细胞为假单极感觉神经元。胞体多呈圆形，大小不等；核圆形，位于胞体中央，核仁明显；尼氏体细小而分散。从胞体发出一个突起，根部在胞体附近盘曲，然后呈 T 形分支。
:::

:::definition{label="中枢突与周围突"}
T 形分支的一支进入脊髓，称中枢突；另一支经脊神经分布到其他器官，终末形成感觉神经末梢，称周围突。中枢突传出神经冲动，是轴突；周围突接受刺激，功能上相当于树突，但细而长、结构与轴突相同，故也称轴突。
:::

:::note{label="卫星细胞包到 T 形分叉为止，往外改施万细胞"}
胞体和附近那段盘曲的胞突，外面是一层卫星细胞；到 T 形分支处改由施万细胞包裹。上一章把周围神经系统的胶质写成卫星细胞和施万细胞两型，在脊神经节里正好接上：卫星细胞守胞体，施万细胞守纤维。图 8-10 里星号是节细胞胞体，箭头指卫星细胞。
:::

:::pitfall{label="尼氏体细小分散，不要按前角运动神经元的斑块去找"}
上一章：大神经元（如脊髓运动神经元）尼氏体呈粗大斑块状，小神经元（如神经节内神经元）呈细颗粒状。脊神经节细胞正是后者。核圆居中、核仁明显、胞体圆形大小不等，加上卫星细胞围成的“晕”，是光镜认感觉节细胞的一套，不要写成前角那种多角形、斑块尼氏体的多极运动神经元。
:::

## 2. 脑神经节

脑神经节位于某些脑神经干上，其结构与脊神经节相似。

:::definition{label="脑神经节"}
脑神经节位于某些脑神经干上，属感觉神经节，结构与脊神经节相似：假单极感觉神经元、核居中、尼氏体细小分散、卫星细胞包裹、纤维大部分有髓。
:::

:::note{label="脑神经节按脊神经节那一套认，不必另立形态标准"}
教材对脑神经节只写“结构与脊神经节相似”。认片时仍问：是不是假单极、核是不是居中、有没有卫星细胞。特殊感觉通路里的双极神经元（如耳蜗神经节）在上一章神经元分类中已经单列，不要把所有脑神经节都强制写成假单极；就本节正文而言，脑神经节与脊神经节同属感觉神经节这一型。
:::

## 3. 自主神经节

自主神经节包括交感和副交感神经节。交感神经节位于脊柱两旁及前方，副交感神经节则位于器官附近或器官内。节细胞主要是自主神经系统的节后神经元，属多极运动神经元。细胞核常偏位于细胞的一侧，部分细胞有双核，细胞质内尼氏体呈细颗粒状，均匀分布。卫星细胞数量较少，包绕节细胞胞体及其突起。节内的神经纤维有节前纤维和节后纤维，节细胞的轴突是无髓神经纤维（节后纤维）。节前纤维与节细胞的树突和胞体建立突触，节后纤维离开神经节，其末梢即内脏运动神经末梢，支配平滑肌、心肌和腺的活动。交感神经节内大部分为去甲肾上腺素能神经元，少数为胆碱能神经元。副交感神经节的神经元一般属胆碱能神经元。

:::definition{label="自主神经节"}
自主神经节包括交感神经节和副交感神经节。节细胞主要是自主神经系统的节后神经元，属多极运动神经元。节内有节前纤维和节后纤维。
:::

:::definition{label="交感神经节"}
交感神经节位于脊柱两旁及前方。节内大部分为去甲肾上腺素能神经元，少数为胆碱能神经元。
:::

:::definition{label="副交感神经节"}
副交感神经节位于器官附近或器官内。神经元一般属胆碱能神经元。
:::

:::definition{label="自主神经节细胞"}
自主神经节细胞属多极运动神经元（节后神经元）。核常偏位于细胞的一侧，部分细胞有双核；尼氏体呈细颗粒状、均匀分布。卫星细胞数量较少，包绕胞体及其突起。轴突为无髓神经纤维，即节后纤维。
:::

:::definition{label="节前纤维"}
节前纤维进入自主神经节，与节细胞的树突和胞体建立突触。侧角内脏运动神经元（胆碱能）发出的轴突即交感节前纤维，终止于交感神经节。
:::

:::definition{label="节后纤维"}
节后纤维是节细胞的轴突，为无髓神经纤维，离开神经节后其末梢即内脏运动神经末梢，支配平滑肌、心肌和腺的活动。
:::

:::compare{title="脊神经节、脑神经节与自主神经节"}
| 项目 | 脊神经节 | 脑神经节 | 自主神经节 |
|------|----------|----------|------------|
| 位置 | 脊髓两侧脊神经背根的膨大 | 某些脑神经干上 | 交感：脊柱两旁及前方；副交感：器官附近或器官内 |
| 功能类型 | 感觉神经节 | 感觉神经节（结构与脊神经节相似） | 运动（节后）神经节 |
| 节细胞 | 假单极感觉神经元 | 同左（绝大部分假单极） | 多极运动神经元 |
| 核 | 圆形，位于胞体中央，核仁明显 | 同左 | 常偏位；部分细胞有双核 |
| 尼氏体 | 细小而分散 | 同左 | 细颗粒状，均匀分布 |
| 卫星细胞 | 一层包裹胞体及附近盘曲胞突 | 同左 | 数量较少，包绕胞体及其突起 |
| 纤维 | 大部分为有髓神经纤维 | 同左 | 节前纤维入节；节后纤维为无髓 |
| 末梢 | 周围突终末形成感觉神经末梢 | 同左 | 内脏运动神经末梢，支配平滑肌、心肌和腺 |
| 递质 | 感觉传入，不按交感/副交感递质分型 | 同左 | 交感：大部分去甲肾上腺素能，少数胆碱能；副交感：一般胆碱能 |
:::

:::compare{title="感觉神经节与自主神经节的认片对照"}
| 线索 | 感觉神经节（脊/脑） | 自主神经节 |
|------|---------------------|------------|
| 突起 | 一个突起，根部盘曲后 T 形分支 | 多个突起（多极） |
| 核位 | 中央 | 常偏一侧，可有双核 |
| 卫星细胞 | 完整包一层 | 较少 |
| 节内纤维 | 大部分有髓 | 节后纤维无髓 |
| 易混点 | 圆形胞体易被看成“上皮样” | 偏核、双核不要当成病理核分裂 |
:::

:::pitfall{label="自主神经节的节后纤维是无髓，不要按脊神经节的有髓纤维来写"}
脊神经节内大部分是有髓神经纤维；自主神经节细胞的轴突明确写成无髓神经纤维（节后纤维）。把三本神经节的纤维都背成有髓，内脏运动末梢那一节会接不上。另：核偏位和双核是自主节细胞的正常形态，不是变性。
:::

:::insight{label="节前胆碱能、节后分家：交感多去甲，副交感仍乙酰胆碱"}
侧角内脏运动神经元是胆碱能，它们的轴突作为节前纤维进交感神经节。节后则分家：交感神经节大部分改释放去甲肾上腺素，少数仍为胆碱能；副交感神经节一般保持胆碱能。上一章按化学性质分类的胆碱能、去甲肾上腺素能，在自主神经节里变成位置账：问的是节前还是节后、交感还是副交感。
:::

:::keypoint{label="三种神经节先分感觉与自主，再分核位、卫星和有无髓"}
- 脊神经节、脑神经节 = 感觉神经节，假单极，核居中，尼氏体细小分散，卫星细胞一层，纤维大部分有髓。
- 脊神经节在背根；一个突起盘曲后 T 形分中枢突（进脊髓）和周围突（感觉末梢）；T 形分支处改由施万细胞包裹。
- 脑神经节在某些脑神经干上，结构与脊神经节相似。
- 自主神经节 = 交感（脊柱两旁及前方）+ 副交感（器官附近或器官内）；多极节后运动神经元，核常偏位、可双核，卫星细胞较少，节后纤维无髓。
- 交感节后大部分去甲肾上腺素能、少数胆碱能；副交感一般胆碱能。末梢支配平滑肌、心肌和腺。
:::
