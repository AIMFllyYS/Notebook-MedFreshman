# 三、主要血管的演变

早期心血管左右对称。弓动脉从主动脉囊发出，一对一对走在鳃弓里，接到同侧背主动脉；卵黄静脉和脐静脉穿过原始横隔回静脉窦。本节把六对弓动脉的保留与退化、卵黄静脉三段和脐静脉的左右命运摊开。六对弓动脉并不同时存在：后一对出现时，前一对已经退化或改道。出生后才闭锁的静脉导管，先在这里立住。

## （一）弓动脉的发生和演变

弓动脉起自主动脉囊，第 $4\sim 6$ 周相继发生 $6$ 对，分别走行于各对鳃弓内，与同侧的背主动脉相连（图 25-15）。$6$ 对弓动脉并不同时存在，常是后 $1$ 对出现时，前 $1$ 对已退化或发生演变。第 $6\sim 8$ 周，弓动脉的演变如下。

:::definition{label="弓动脉"}
弓动脉起自主动脉囊，走行于各对鳃弓内，与同侧的背主动脉相连。第 $4\sim 6$ 周相继发生 $6$ 对，并不同时存在。演变主要发生在第 $6\sim 8$ 周。
:::

:::definition{label="主动脉囊"}
主动脉囊是动脉干头端的膨大，弓动脉从这里发出。后来：部分主动脉囊加入颈总动脉；囊的左半与左侧第 $4$ 弓动脉共同形成主动脉弓；囊的右半形成头臂干。
:::

:::pitfall{label="六对弓动脉并不同时存在"}
教材写明：常是后 $1$ 对出现时，前 $1$ 对已退化或发生演变。把六对画在同一张“同时存在”的图上当标本，第 $1$、$2$ 对的退化和第 $6$ 对的动脉导管会对不成时间。
:::

（1）第 $1$、$2$ 对弓动脉：基本退化消失，但与其相连的一段背主动脉保留。

:::definition{label="第1、2对弓动脉"}
第 $1$、$2$ 对弓动脉基本退化消失，但与其相连的一段背主动脉保留。不要写成“第 $1$、$2$ 对连背主动脉一起扔掉”。
:::

（2）第 $3$ 对弓动脉：左、右各发出 $1$ 个分支，形成左、右颈外动脉。以颈外动脉的起始点为界，近侧段及部分主动脉囊发育成颈总动脉，远侧段及与其相连的背主动脉共同形成颈内动脉。

:::definition{label="第3对弓动脉"}
第 $3$ 对弓动脉本身分成三段账：发出的分支 → 左、右颈外动脉；以颈外动脉起始点为界，近侧段及部分主动脉囊 → 颈总动脉；远侧段及与其相连的背主动脉 → 颈内动脉。
:::

:::pitfall{label="颈外动脉是第3对发出的分支，不是第3对远侧段改名"}
以颈外动脉的起始点为界：近侧（加部分主动脉囊）才是颈总动脉，远侧加相连背主动脉才是颈内动脉。把第 $3$ 对整条写成颈总动脉，或把颈内动脉写成“第 $3$ 对单独变的”，头颈三条动脉会对错节段。
:::

（3）第 $4$ 对弓动脉：左侧与主动脉囊左半共同形成主动脉弓。主动脉囊右半形成头臂干。左侧背主动脉背侧发出的第 $7$ 节间动脉形成左锁骨下动脉。右侧第 $4$ 弓动脉及与其相连的尾侧背主动脉和右侧第 $7$ 节间动脉共同组成右锁骨下动脉。第 $3$、$4$ 对弓动脉之间的背主动脉萎缩消失。

:::definition{label="第4对弓动脉（左侧）"}
左侧第 $4$ 弓动脉与主动脉囊左半共同形成主动脉弓。左锁骨下动脉不来自左侧第 $4$ 弓，而来自左侧背主动脉背侧发出的第 $7$ 节间动脉。
:::

:::definition{label="第4对弓动脉（右侧）与头臂干"}
主动脉囊右半形成头臂干。右锁骨下动脉由三截拼成：右侧第 $4$ 弓动脉 + 与其相连的尾侧背主动脉 + 右侧第 $7$ 节间动脉。
:::

:::definition{label="第3、4对之间的背主动脉"}
第 $3$、$4$ 对弓动脉之间的背主动脉萎缩消失。颈内动脉因此不再经背主动脉接到降主动脉；这一段消失，是头臂与降主动脉布局能分开的关键一步。
:::

:::compare{title="左锁骨下动脉与右锁骨下动脉的来源"}
| 项目 | 左锁骨下动脉 | 右锁骨下动脉 |
|------|--------------|--------------|
| 第4弓动脉 | 不参加（左侧第 $4$ 弓走主动脉弓） | 参加（右侧第 $4$ 弓是近侧段） |
| 尾侧背主动脉 | 不作为其组成 | 与右侧第 $4$ 弓相连的那一段参加 |
| 第7节间动脉 | 左侧第 $7$ 节间动脉形成左锁骨下动脉 | 右侧第 $7$ 节间动脉参加组成 |
| 同侧还分出 | 主动脉弓（第 $4$ 弓 + 囊左半） | 头臂干（囊右半） |
:::

（4）第 $5$ 对弓动脉：发育不全并很快退化。

:::definition{label="第5对弓动脉"}
第 $5$ 对弓动脉发育不全并很快退化。六对里它几乎不留成体血管，不要在成体图上找“第 $5$ 弓的遗迹”当必考结构。
:::

（5）第 $6$ 对弓动脉：近侧段形成肺动脉的基部，左侧远侧段形成动脉导管，右侧远侧段退化。随着动脉干的分隔，肺动脉与肺动脉干通连。

:::definition{label="第6对弓动脉"}
第 $6$ 对近侧段形成肺动脉的基部；左侧远侧段形成动脉导管；右侧远侧段退化。动脉干分隔之后，肺动脉才与肺动脉干通连。
:::

:::definition{label="动脉导管（发生）"}
动脉导管来自左侧第 $6$ 弓动脉的远侧段，连接肺动脉干与降主动脉。右侧第 $6$ 弓没有对等的远侧段保留。出生后它闭锁为动脉韧带，见第四节。
:::

:::concept{term="先问这是第几对弓动脉，再问左侧保留什么、右侧退化什么"}
看见弓动脉，先按 $1$ 到 $6$ 对点名，不要六对混成“鳃弓血管”。第 $1$、$2$ 对基本退化，只留相连的一段背主动脉。第 $3$ 对按颈外动脉起始点切开：分支是颈外，近侧加部分主动脉囊是颈总，远侧加背主动脉是颈内。第 $4$ 对左右分开：左加囊左半成主动脉弓，囊右半成头臂干；左第 $7$ 节间成左锁骨下，右第 $4$ 弓加尾侧背主动脉加右第 $7$ 节间成右锁骨下；第 $3$ 与 $4$ 之间的背主动脉萎缩。第 $5$ 对很快退化。第 $6$ 对近侧成肺动脉基部，左远侧成动脉导管，右远侧退化；动脉干分隔后肺动脉接肺动脉干。把左锁骨下写成“左侧第 $4$ 弓变的”，或把动脉导管写成“左右第 $6$ 弓都有”，后面的导管未闭和锁骨下起源都会对错户头。
:::

:::compare{title="六对弓动脉的保留与退化"}
| 对 | 保留 | 退化 |
|----|------|------|
| 第 $1$、$2$ 对 | 与其相连的一段背主动脉 | 弓动脉本身基本退化消失 |
| 第 $3$ 对 | 分支 → 左、右颈外动脉；近侧段 + 部分主动脉囊 → 颈总动脉；远侧段 + 相连背主动脉 → 颈内动脉 | — |
| 第 $4$ 对 | 左侧 + 主动脉囊左半 → 主动脉弓；主动脉囊右半 → 头臂干；左第 $7$ 节间动脉 → 左锁骨下动脉；右侧第 $4$ 弓 + 尾侧背主动脉 + 右第 $7$ 节间动脉 → 右锁骨下动脉 | 第 $3$、$4$ 对之间的背主动脉萎缩消失 |
| 第 $5$ 对 | — | 发育不全并很快退化 |
| 第 $6$ 对 | 近侧段 → 肺动脉的基部；左侧远侧段 → 动脉导管 | 右侧远侧段退化 |
:::

:::derivation{title="右锁骨下动脉为什么比左锁骨下动脉多两截"}
左侧第 $4$ 弓已经交给主动脉弓，左锁骨下只靠左第 $7$ 节间动脉从背主动脉背侧发出。右侧第 $4$ 弓不形成“右主动脉弓”，于是右侧第 $4$ 弓本身、与它相连的尾侧背主动脉、再加上右第 $7$ 节间动脉，三截才拼成右锁骨下动脉。头臂干则来自主动脉囊右半，不是第 $4$ 弓改名。
:::

::figure{src="/images/histology/textbook/p0278_01.png" caption="图25-15 动脉干、主动脉囊、肺动脉和背主动脉的演变示意图。A. 动脉干接主动脉囊，弓动脉连背主动脉，下方为第7节间动脉；B. 第3弓发颈外动脉，第6弓左侧远侧成动脉导管，第7节间成锁骨下动脉的原基；C. 颈总、颈内、颈外和头臂干成形，肺动脉干经动脉导管连降主动脉；D. 成体布局：升主动脉、降主动脉、左锁骨下动脉，动脉导管闭锁为动脉韧带。绿为第3弓，紫为第4弓组织，红为动脉干组织，黄为第6弓组织。" alt="四阶段弓动脉演变：A囊上弓动脉连背主动脉，B出现颈外动脉与动脉导管，C头臂干肺动脉干成形，D成体升主动脉降主动脉与动脉韧带"}

:::example{label="按左右把第3、4、6对走一遍"}
**题目**：只看成体的主动脉弓、头臂干、左右颈总、左右锁骨下和动脉韧带，各对应胚胎哪一段？

**解**：左、右颈总来自第 $3$ 弓近侧段及部分主动脉囊，颈内来自第 $3$ 弓远侧段加相连背主动脉，颈外来自第 $3$ 弓发出的分支。主动脉弓 = 左侧第 $4$ 弓 + 主动脉囊左半；头臂干 = 主动脉囊右半。左锁骨下 = 左第 $7$ 节间动脉；右锁骨下 = 右第 $4$ 弓 + 尾侧背主动脉 + 右第 $7$ 节间动脉。动脉韧带的前身是左侧第 $6$ 弓远侧段（动脉导管）；右侧第 $6$ 弓远侧段已退化，所以没有“右动脉导管”。
:::

:::cause-effect{title="六对弓动脉不同时存在，后一对改写前一对留下的管道"}
- 因：第 4～6 周弓动脉相继发生，后 1 对出现时前 1 对已退化或演变
- 果：不能把六对当成同一时刻的六条弓
- 因：第 3、4 对之间的背主动脉萎缩
- 果：颈内动脉不再经背主动脉通降主动脉
- 因：左侧第 6 弓远侧段保留为动脉导管，右侧远侧段退化
- 果：肺动脉干与降主动脉只在左侧相通；出生后这一条闭锁为动脉韧带
:::

:::timeline{period="第4～8周：弓动脉从出现到改道"}
- **第4～6周** 6 对弓动脉相继发生，走在各对鳃弓内，连同侧背主动脉；并不同时存在
- **第1、2对** 基本退化，相连的一段背主动脉保留
- **第3对** 发分支成颈外动脉；近侧加部分主动脉囊成颈总；远侧加背主动脉成颈内
- **第4对** 左加囊左半成主动脉弓；囊右半成头臂干；左第7节间成左锁骨下；右第4弓加尾侧背主动脉加右第7节间成右锁骨下；第3与4之间背主动脉萎缩
- **第5对** 发育不全并很快退化
- **第6对** 近侧成肺动脉基部；左远侧成动脉导管；右远侧退化；动脉干分隔后肺动脉通肺动脉干
- **第6～8周** 上述演变完成，布局接近成体大动脉
:::

:::insight{label="左右不对称，是第4、6对在左右走了不同的远侧命运"}
第 $3$ 对左右对称地交出颈总、颈内、颈外。不对称从第 $4$、$6$ 对开始：左侧第 $4$ 弓进主动脉弓，右侧第 $4$ 弓进右锁骨下；左侧第 $6$ 弓远侧留动脉导管，右侧远侧扔掉。只背“六对弓动脉变成大动脉”，锁骨下来源和动脉导管的左右差会并成一句空话。
:::

:::tip{label="六对弓动脉口诀"}
一二退化留背主动脉。三对：分支颈外，近侧颈总，远侧颈内。四对：左弓右头臂干；左锁骨下靠第 $7$ 节间，右锁骨下是第 $4$ 弓加尾侧背主动脉加第 $7$ 节间；三四之间背主动脉萎缩。五对很快退化。六对：近侧肺动脉基部，左远侧动脉导管，右远侧退化。
:::

:::keypoint{label="六对不同时存在；第3对分颈，第4对分弓，第6对留导管"}
- 弓动脉起自主动脉囊，第 $4\sim 6$ 周相继 $6$ 对，走鳃弓，连同侧背主动脉；后一对出现时前一对已变。
- 第 $1$、$2$ 对基本退化，相连背主动脉保留。
- 第 $3$ 对：分支 → 颈外；近侧 + 部分主动脉囊 → 颈总；远侧 + 背主动脉 → 颈内。
- 第 $4$ 对：左 + 囊左半 → 主动脉弓；囊右半 → 头臂干；左第 $7$ 节间 → 左锁骨下；右第 $4$ 弓 + 尾侧背主动脉 + 右第 $7$ 节间 → 右锁骨下；第 $3$ 与 $4$ 之间背主动脉萎缩。
- 第 $5$ 对发育不全并很快退化。
- 第 $6$ 对近侧 → 肺动脉基部；左远侧 → 动脉导管；右远侧退化；动脉干分隔后肺动脉通肺动脉干。
:::

## （二）卵黄静脉的演变

左、右卵黄静脉与卵黄蒂一起进入胚体，穿过原始横隔注入静脉窦。在卵黄囊与原始横隔之间，左、右卵黄静脉形成许多吻合支。肝形成后，原来的卵黄静脉分化为 $3$ 段（图 25-16）：与肝相邻的一段，并入肝内形成肝血窦；出肝后的近心段，左侧支消失，右侧支形成肝静脉和下腔静脉的近心段；入肝前的远心段，形成了一条 S 形的血管，发育形成门静脉。

:::definition{label="卵黄静脉"}
左、右卵黄静脉与卵黄蒂一起进入胚体，穿过原始横隔注入静脉窦。在卵黄囊与原始横隔之间形成许多吻合支。肝出现后，原来的卵黄静脉按与肝的关系切成 $3$ 段。
:::

:::definition{label="卵黄静脉与肝相邻的一段"}
与肝相邻的一段并入肝内，形成肝血窦。它不是“消失了”，而是改造成肝内的血窦网。
:::

:::definition{label="卵黄静脉出肝后的近心段"}
出肝后的近心段：左侧支消失，右侧支形成肝静脉和下腔静脉的近心段。下腔静脉近心段这本账在右侧，不在左侧。
:::

:::definition{label="卵黄静脉入肝前的远心段"}
入肝前的远心段形成一条 S 形血管，发育形成门静脉。门静脉来自卵黄静脉远心段，不是来自脐静脉。
:::

:::compare{title="卵黄静脉三段"}
| 段 | 位置 | 演变 |
|----|------|------|
| 与肝相邻的一段 | 肝区 | 并入肝内，形成肝血窦 |
| 出肝后的近心段 | 肝与静脉窦之间 | 左侧支消失；右侧支 → 肝静脉 + 下腔静脉近心段 |
| 入肝前的远心段 | 卵黄囊／肠侧 | 形成一条 S 形血管 → 门静脉 |
:::

:::pitfall{label="门静脉来自卵黄静脉远心段，肝静脉和下腔近心段来自右侧近心段"}
三段不要并成“卵黄静脉变成门静脉”。中间一段进了肝血窦；近心段只留右侧，交出肝静脉和下腔静脉近心段；远心段才是门静脉。写成“左右卵黄静脉都变成下腔静脉”，左右差和门静脉户头都会丢。
:::

:::cause-effect{title="肝一出现，卵黄静脉就被切成三段"}
- 因：左、右卵黄静脉在卵黄囊与原始横隔之间吻合并穿过横隔入静脉窦
- 果：肝形成前已有入肝的静脉通路
- 因：肝形成，与肝相邻的一段并入肝内
- 果：该段成为肝血窦
- 因：近心段左侧支消失、右侧支保留
- 果：肝静脉和下腔静脉近心段落在右侧
- 因：远心段吻合成 S 形血管
- 果：发育为门静脉
:::

## （三）脐静脉的演变

脐静脉的分支入肝与肝血窦相通。之后右脐静脉全部退化，左脐静脉在肝与静脉窦之间的一段也退化消失，脐至肝的一段则一直保留至出生，穿行于肝内的小血管逐渐合并扩大成一条静脉导管（见图 25-16）。静脉导管一端与左脐静脉相连，另一端通入下腔静脉，将从胎盘回流的血液导入下腔静脉，再流入静脉窦右角。出生后，静脉导管闭锁。

:::definition{label="脐静脉（入肝）"}
脐静脉的分支入肝，与肝血窦相通。它和卵黄静脉一样要过肝，但左右命运与卵黄静脉不同。
:::

:::definition{label="右脐静脉"}
右脐静脉全部退化。出生前从胎盘回心的这条通路不走右侧脐静脉。
:::

:::definition{label="左脐静脉"}
左脐静脉在肝与静脉窦之间的一段退化消失；脐至肝的一段一直保留至出生。保留的是“脐到肝”这一截，不是“肝到静脉窦”那一截。
:::

:::definition{label="静脉导管"}
穿行于肝内的小血管逐渐合并扩大成一条静脉导管。一端连左脐静脉，另一端通下腔静脉，把胎盘回流的血液导入下腔静脉，再流入静脉窦右角。出生后静脉导管闭锁（第四节改称静脉韧带）。
:::

::figure{src="/images/histology/textbook/p0278_02.png" caption="图25-16 卵黄静脉及脐静脉的演变示意图。A. 第4周：左、右卵黄静脉经吻合支向肝汇聚，左、右脐静脉并行，注入静脉窦；B. 第5周：肝血窦形成，卵黄静脉中段并入肝；C. 第6周：右脐静脉已退化，左脐静脉经静脉导管通下腔静脉，门静脉由卵黄静脉远心段与肠系膜上静脉、脾静脉汇合而成。" alt="三阶段：A左右卵黄静脉和脐静脉入静脉窦，B肝血窦形成，C右脐静脉退化、静脉导管和门静脉出现"}

:::concept{term="先问卵黄静脉切成哪三段，再问脐静脉是右全退化、左留脐至肝段并靠静脉导管入下腔"}
看见胚体静脉，先把卵黄静脉和脐静脉分开。卵黄静脉：邻肝段 → 肝血窦；近心段左消失、右成肝静脉和下腔近心段；远心段 S 形 → 门静脉。脐静脉：右全部退化；左在肝与静脉窦之间的一段也退化，只留脐至肝段到出生；肝内小血管合成静脉导管，一端接左脐静脉，一端通下腔静脉，再入静脉窦右角；出生后导管闭锁。把脐静脉写成“左右都留到出生”，或把静脉导管写成门静脉的一段，胎盘血回心的短路会画错。
:::

:::compare{title="左、右脐静脉与静脉导管"}
| 项目 | 右脐静脉 | 左脐静脉 | 静脉导管 |
|------|----------|----------|----------|
| 入肝 | 早期分支可通肝血窦 | 分支入肝与肝血窦相通 | 肝内小血管合并扩大而成 |
| 归宿 | 全部退化 | 肝与静脉窦之间的一段退化；脐至肝的一段保留至出生 | 一端连左脐静脉，一端通下腔静脉，再入静脉窦右角 |
| 出生后 | 已不存在 | 闭锁为肝圆韧带（第四节） | 闭锁为静脉韧带（第四节） |
:::

:::compare{title="卵黄静脉与脐静脉不要并户"}
| 项目 | 卵黄静脉 | 脐静脉 |
|------|----------|--------|
| 伴行结构 | 与卵黄蒂一起入胚体 | 行于脐带，来自绒毛膜／胎盘 |
| 入肝后 | 邻肝段变肝血窦 | 分支与肝血窦相通 |
| 近心段 | 左消失，右成肝静脉和下腔近心段 | 左在肝与静脉窦之间的一段退化 |
| 出生前仍工作的主干 | 远心段成门静脉 | 左脐静脉脐至肝段 + 静脉导管 |
| 血从哪里来 | 卵黄囊／原始消化管 | 胎盘（富含氧和营养，见第四节） |
:::

:::pitfall{label="静脉导管不是门静脉，门静脉也不是脐静脉改名"}
门静脉来自卵黄静脉入肝前的远心段。静脉导管来自肝内小血管合并扩大，专门把左脐静脉的胎盘血导入下腔静脉。写成“脐静脉变成门静脉”或“静脉导管就是门静脉”，肝内两条通路会对成一条。
:::

:::note{label="静脉导管出生后才闭锁"}
本节先把静脉导管的连通写清楚：左脐静脉 → 静脉导管 → 下腔静脉 → 静脉窦右角。闭锁形成静脉韧带、左脐静脉形成肝圆韧带，放到第四节“出生后血液循环的变化”一起记。
:::

:::insight{label="肝把卵黄静脉切成三段，又给脐静脉造了一条短路"}
卵黄静脉被肝改造成血窦、肝静脉／下腔近心段和门静脉。脐静脉则扔掉右侧和左近心段，留下脐至肝段，再在肝里合并出静脉导管，让胎盘血少过肝实质、直接进下腔。后面胎儿循环的“大部分经静脉导管入下腔”就是这一步预先铺好的。
:::

:::timeline{period="卵黄静脉与脐静脉"}
- **入胚** 左右卵黄静脉与卵黄蒂入胚，穿原始横隔注入静脉窦；脐静脉分支入肝通肝血窦
- **吻合** 卵黄囊与原始横隔之间，左右卵黄静脉形成许多吻合支
- **肝形成后（卵黄静脉三段）** 邻肝段 → 肝血窦；近心段左消失、右成肝静脉和下腔近心段；远心段 S 形 → 门静脉
- **脐静脉改道** 右脐静脉全部退化；左脐静脉肝与静脉窦之间的一段退化；脐至肝段保留至出生
- **静脉导管** 肝内小血管合并扩大；连左脐静脉与下腔静脉，导入静脉窦右角
- **出生后** 静脉导管闭锁（详见第四节）
:::

:::keypoint{label="卵黄静脉三段，右脐全退，左脐留脐至肝段，静脉导管通下腔"}
- 卵黄静脉穿原始横隔入静脉窦；肝形成后分三段：肝血窦、右侧近心段（肝静脉 + 下腔近心段）、远心段（门静脉）。
- 右脐静脉全部退化。
- 左脐静脉：肝与静脉窦之间的一段退化；脐至肝的一段保留至出生。
- 静脉导管：肝内小血管合并扩大；一端左脐静脉，一端下腔静脉，再入静脉窦右角；出生后闭锁。
:::

:::memory{label="本节必背要点"}
- [ ] 弓动脉起自主动脉囊，第 $4\sim 6$ 周相继发生 $6$ 对，走行于各对鳃弓内，与同侧背主动脉相连。
- [ ] $6$ 对弓动脉并不同时存在，常是后 $1$ 对出现时，前 $1$ 对已退化或发生演变。
- [ ] 第 $6\sim 8$ 周完成弓动脉演变。
- [ ] 第 $1$、$2$ 对弓动脉基本退化消失，但与其相连的一段背主动脉保留。
- [ ] 第 $3$ 对弓动脉左、右各发出 $1$ 个分支，形成左、右颈外动脉。
- [ ] 以颈外动脉起始点为界，近侧段及部分主动脉囊发育成颈总动脉。
- [ ] 第 $3$ 对远侧段及与其相连的背主动脉共同形成颈内动脉。
- [ ] 左侧第 $4$ 弓动脉与主动脉囊左半共同形成主动脉弓。
- [ ] 主动脉囊右半形成头臂干。
- [ ] 左侧背主动脉背侧发出的第 $7$ 节间动脉形成左锁骨下动脉。
- [ ] 右侧第 $4$ 弓动脉及与其相连的尾侧背主动脉和右侧第 $7$ 节间动脉共同组成右锁骨下动脉。
- [ ] 第 $3$、$4$ 对弓动脉之间的背主动脉萎缩消失。
- [ ] 第 $5$ 对弓动脉发育不全并很快退化。
- [ ] 第 $6$ 对近侧段形成肺动脉的基部。
- [ ] 第 $6$ 对左侧远侧段形成动脉导管，右侧远侧段退化。
- [ ] 随着动脉干的分隔，肺动脉与肺动脉干通连。
- [ ] 左、右卵黄静脉与卵黄蒂一起进入胚体，穿过原始横隔注入静脉窦。
- [ ] 在卵黄囊与原始横隔之间，左、右卵黄静脉形成许多吻合支。
- [ ] 肝形成后，卵黄静脉分化为 $3$ 段。
- [ ] 与肝相邻的一段并入肝内形成肝血窦。
- [ ] 出肝后的近心段：左侧支消失，右侧支形成肝静脉和下腔静脉的近心段。
- [ ] 入肝前的远心段形成一条 S 形血管，发育形成门静脉。
- [ ] 脐静脉的分支入肝与肝血窦相通。
- [ ] 右脐静脉全部退化。
- [ ] 左脐静脉在肝与静脉窦之间的一段退化消失，脐至肝的一段一直保留至出生。
- [ ] 肝内小血管逐渐合并扩大成一条静脉导管。
- [ ] 静脉导管一端与左脐静脉相连，另一端通入下腔静脉，导入静脉窦右角。
- [ ] 出生后，静脉导管闭锁。
