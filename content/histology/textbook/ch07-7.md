# 七、神经纤维的溃变和再生

第六节把末梢装置立住以后，本节问这根纤维被切断以后还能不能长回去。当神经元受到物理和化学因素的伤害后，其胞体及发出的神经纤维都会发生溃变反应。当胞体直接受到严重损伤时，可迅速导致整个神经元死亡。如果在靠近胞体处损伤神经纤维，也同样会使神经元死亡。但是在成年人，远离胞体处损伤神经纤维一般不会引起神经元死亡，甚至可以发生神经纤维再生。周围侧有施万细胞和基膜管，可再生；中枢侧微环境和胶质瘢痕挡住支芽，常导致功能永久丧失。

:::definition{label="溃变反应"}
神经元受到物理和化学因素伤害后，其胞体及发出的神经纤维发生的变性过程称溃变反应。胞体严重受损，或在靠近胞体处切断纤维，可迅速导致整个神经元死亡。
:::

:::concept{term="先问胞体还在不在，再问切断点离胞体有多近"}
再生的前提是这颗神经元没有死。胞体被直接打掉，整条细胞立刻完；切断点贴着胞体，也常把神经元带走。成年人在远离胞体处切断，一般不引起神经元死亡，近侧断端才有机会长出支芽。把“神经断了就能长”写成无条件结论，会漏掉胞体死亡这一关；把所有切断都写成“神经元必死”，又会把周围神经吻合术那本账做死。
:::

:::pitfall{label="靠近胞体切断可以杀死神经元，远离胞体一般不会"}
教材把损伤部位写成决定因素之一：近胞体损伤 ≈ 伤及胞体；远胞体损伤，成年后胞体多能存活并启动再生。不要用“轴突一断神经元必亡”或“轴突一断必定再生”两句绝对化的话代替这本距离账。
:::

## （一）溃变

当神经纤维受损伤如神经被切断后，切断处远侧段的神经纤维全长发生溃变（degeneration），轴突和髓鞘发生碎裂和溶解，而与胞体相连的近侧段神经纤维则发生逆行性溃变（retrograde degeneration），但一般只影响到靠近损伤处 $1\sim 2$ 节段的髓鞘和轴突处。自损伤处向神经纤维末端方向发生的溃变称为顺行性溃变（anterograde degeneration）。此时，神经元胞体肿胀，细胞核移到胞体边缘，细胞质内尼氏体溶解，故细胞质着色浅淡（图 7-36）。

:::definition{label="溃变"}
溃变（degeneration）指神经纤维受损伤后轴突和髓鞘碎裂、溶解的过程。切断后远侧段全长发生溃变；近侧段一般只波及损伤处附近 $1\sim 2$ 节段。
:::

:::definition{label="顺行性溃变"}
顺行性溃变（anterograde degeneration）是自损伤处向神经纤维末端方向发生的溃变，即远侧段全长的轴突与髓鞘碎裂溶解。临床上常称华勒溃变（Wallerian degeneration）。
:::

:::definition{label="逆行性溃变"}
逆行性溃变（retrograde degeneration）是与胞体相连的近侧段神经纤维发生的溃变，一般只影响到靠近损伤处 $1\sim 2$ 节段的髓鞘和轴突。
:::

:::definition{label="华勒溃变"}
华勒溃变（Wallerian degeneration）即切断处远侧段全长的顺行性溃变：轴突和髓鞘碎裂、溶解，巨噬细胞吞噬碎块（图 7-36B）。近侧段那一小段逆行性溃变不算进华勒全长账。
:::

:::compare{title="顺行性溃变与逆行性溃变"}
| 项目 | 顺行性溃变（华勒溃变） | 逆行性溃变 |
|------|------------------------|------------|
| 方向 | 自损伤处 → 纤维末端 | 自损伤处 → 近胞体侧 |
| 范围 | 远侧段全长 | 一般仅靠近损伤处 $1\sim 2$ 节段 |
| 结构变化 | 轴突和髓鞘碎裂、溶解 | 近侧段局部髓鞘和轴突溃变 |
| 胞体 | 可伴随肿胀、核偏位、尼氏体溶解（着色浅淡） | 同左，是同一损伤在胞体上的反应 |
| 与再生的关系 | 远侧残屑被吞噬，基膜管腾空，供再生轴突长入 | 近侧断端保留，作为支芽的出发处 |
:::

:::insight{label="胞体肿胀、核偏位、尼氏体溶解，是切断写回代谢中心的那一笔"}
第一节把尼氏体写成胞体合成结构蛋白和递质酶的车间。纤维切断后这间车间先散掉，胞质着色浅淡，核被挤到边缘——不是另得了一种新细胞，而是代谢中心暂时停工。约 3 周后尼氏体再现、核回中央，合成重启，近侧断端才长得出支芽。看见“着色浅淡的大神经元”，先问是正常小神经元的细颗粒尼氏体，还是大神经元正在溃变。
:::

:::pitfall{label="远侧全长溃变不等于近侧也整根烂掉"}
远侧段没有了胞体的物质供应，全长华勒溃变；近侧段还连着胞体，逆行性溃变通常只啃掉靠近断端的 $1\sim 2$ 节。把近侧也写成全长溶解，再生支芽就没有出发的轴突残桩。
:::

## （二）再生

当神经元发出的神经纤维（或轴突）被离断后，如果该神经元胞体没有死亡，其受损伤的神经纤维近胞体侧（近侧段）断端可以重新长出新生支芽。

:::definition{label="神经纤维再生"}
神经纤维再生的前提是胞体未死亡。近侧段断端重新长出新生轴突支芽；周围神经中支芽沿施万细胞索和基膜管到达原来的靶，则再生成功。
:::

### 1. 周围神经纤维的再生

切断神经纤维 3 周后，其神经元胞体内的尼氏体重新出现，胞体肿胀消失，细胞核重新移位到胞体中央位置。恢复中的胞体不断合成新的蛋白质及其他产物并向轴突输送，促使残留的近侧段轴突末端生长出许多新生的轴突支芽（图 7-36）。在髓鞘和轴突发生溃变时，包裹神经纤维外面的基膜仍保留呈管状，但施万细胞大量增殖，它们吞噬碎裂的髓鞘和轴突，并在基膜管内排列成细胞索。在靠近断口处的施万细胞形成细胞桥把两断端连在一起，让近侧段神经纤维断端再生的轴突支芽越过施万细胞桥，进入基膜管内。当再生轴突沿着施万细胞索生长并到达原来支配的靶时，则再生成功（图 7-36）。因此，在周围神经受到损伤时，施万细胞和基膜对受损伤轴突的再生起重要的诱导作用。

:::definition{label="基膜管"}
基膜管是周围神经纤维外面的基膜在轴突和髓鞘溃变后仍保留下来的管状支架。施万细胞在管内排成细胞索，再生轴突沿此管道生长。
:::

:::definition{label="施万细胞索"}
施万细胞索是大量增殖的施万细胞在基膜管内排列而成的细胞链。它们吞噬碎裂的髓鞘和轴突，并诱导再生轴突向靶器官生长。
:::

:::definition{label="施万细胞桥"}
靠近断口处的施万细胞形成细胞桥，把近侧与远侧两断端连在一起，让再生的轴突支芽越过缺口，进入远侧基膜管。
:::

:::timeline{period="周围神经切断后：从溃变走到再生成功"}
- **远侧段** 全长顺行性溃变（华勒溃变），轴突与髓鞘碎裂溶解
- **近侧段** 逆行性溃变，一般只波及损伤处 $1\sim 2$ 节段
- **胞体** 肿胀、核偏位、尼氏体溶解，胞质着色浅淡
- **约 3 周** 尼氏体再现，肿胀消退，核回中央；胞体重启合成并向轴突输送
- **施万细胞** 增殖、吞噬碎屑，在残留基膜管内排成细胞索；断口处搭细胞桥
- **再生成功** 近侧支芽越过细胞桥，沿施万细胞索到达原来支配的靶；多余支芽消失
:::

:::compare{title="周围神经再生中施万细胞与基膜的职分"}
| 结构 | 溃变时 | 再生时 |
|------|--------|--------|
| 轴突、髓鞘 | 远侧全长碎裂溶解 | 由近侧断端长出新支芽替换 |
| 基膜 | 仍保留呈管状 | 提供管道，让轴突定向生长 |
| 施万细胞 | 大量增殖并吞噬碎屑 | 在基膜管内排成细胞索，断口处形成细胞桥，诱导支芽到达原靶 |
:::

:::insight{label="周围可再生，关键不是轴突自己认得路，而是施万细胞和基膜还在"}
第五节把基膜写进神经膜；第三节已提示施万细胞分泌神经营养因子。切断以后真正留下的向导是这层没塌的基膜管和增殖成索的施万细胞。没有这两样，支芽会乱长；有了它们，才谈得上“到达原来支配的靶”。这与骨骼肌损伤后靠肌卫星细胞修复是两套干细胞/向导账，不要混写成“周围组织都能再生”。
:::

### 2. 中枢神经纤维的再生

虽然中枢神经纤维同周围神经纤维一样具有再生能力，但再生过程比周围神经困难。因为这种神经纤维没有施万细胞，也无基膜包裹，而且受损伤的中枢神经微环境中存在有较多的抑制神经再生化学因子，如硫酸软骨素蛋白聚糖等。此外，损伤处星形胶质细胞增殖形成致密的胶质瘢痕，阻碍再生的轴突支芽穿越损伤区。所以，中枢神经纤维的损伤常导致脑或脊髓功能的永久性丧失。但是近年来的研究已寻找到一些能够促进中枢神经纤维再生的神经营养因子，如神经生长因子、神经营养素-3、脑源性神经营养因子和睫状神经营养因子等，也有学者把周围神经、胚胎脑或脊髓组织、胚胎干细胞、神经干细胞、骨髓间充质干细胞或嗅鞘细胞等移植到脑或脊髓内，以期促进受损伤的脑或脊髓结构和功能的修复。

:::definition{label="中枢神经纤维再生困难的原因"}
中枢纤维并非没有再生能力，而是再生过程比周围困难：①无施万细胞；②无基膜包裹；③微环境中抑制因子较多，如硫酸软骨素蛋白聚糖；④星形胶质细胞增殖形成致密胶质瘢痕，阻碍支芽穿越损伤区。故脑或脊髓损伤常导致功能永久性丧失。
:::

:::definition{label="促进中枢再生的神经营养因子"}
教材列举能促进中枢神经纤维再生的神经营养因子：神经生长因子、神经营养素-3、脑源性神经营养因子和睫状神经营养因子等。
:::

:::compare{title="周围神经纤维再生与中枢神经纤维再生"}
| 项目 | 周围神经纤维 | 中枢神经纤维 |
|------|--------------|--------------|
| 内在再生能力 | 有（胞体存活为前提） | 同样具有再生能力 |
| 成鞘细胞 | 施万细胞增殖成索、搭桥、吞噬碎屑 | 无施万细胞；少突不承担周围那种向导职分 |
| 基膜 | 残留基膜管，定向诱导 | 无基膜包裹 |
| 微环境 | 相对允许再生 | 抑制因子多，如硫酸软骨素蛋白聚糖 |
| 瘢痕 | — | 星形胶质细胞增殖形成致密胶质瘢痕，阻挡支芽 |
| 结局 | 支芽到达原靶则再生成功 | 常导致脑或脊髓功能永久性丧失 |
| 研究对策 | 保护胞体、对合基膜管与施万细胞桥 | 神经营养因子；移植周围神经、胚胎组织、胚胎干细胞、神经干细胞、骨髓间充质干细胞或嗅鞘细胞 |
:::

:::pitfall{label="中枢不是“不会再生”，而是微环境和瘢痕不让支芽过去"}
教材明确写了中枢纤维同周围一样具有再生能力，难在没有施万和基膜、又有抑制因子和胶质瘢痕。把中枢背成“轴突先天不能长”，会和第四节神经干细胞、后文移植研究对着干；把中枢背成“和周围一样容易长回去”，又忽略了永久性功能丧失这一临床结局。
:::

:::note{label="第四节的神经干细胞在这里再次出场"}
促进中枢修复的移植名单里包括神经干细胞和骨髓间充质干细胞。NSC 是神经组织自己的储备细胞；MSC 来自骨髓等，职分偏免疫调节和神经营养支持，见本节插入框。两套干细胞不要写成同一种。
:::

:::keypoint{label="溃变先问远近侧，再生先问周围还是中枢"}
- 胞体严重损伤或近胞体切断 → 神经元死亡；远离胞体切断，成年后一般可存活并再生。
- 远侧全长顺行性溃变（华勒溃变）；近侧逆行性溃变通常仅 $1\sim 2$ 节段；胞体肿胀、核偏位、尼氏体溶解。
- 约 3 周：尼氏体再现，核回中央，近侧长出支芽。
- 周围：基膜管 + 施万细胞索和细胞桥诱导轴突到达原靶。
- 中枢：无施万、无基膜，抑制因子和胶质瘢痕挡住支芽，常永久丧失功能。
:::

## 本章小结

神经组织由两类细胞——神经元和神经胶质细胞组成。神经元是神经系统的结构和功能单位。神经元由胞体、轴突和树突构成。胞体是神经元的营养和代谢中心，中央有一个大而圆的胞核，异染色质少，核仁大而明显；细胞质含有尼氏体（由粗面内质网和游离核糖体构成，可合成蛋白质）、神经原纤维（由神经丝和微管构成）、高尔基复合体、线粒体等。树突接受信息，轴突传导神经冲动。

神经元与神经元之间，或神经元与效应细胞（例如肌纤维）之间传递信息的部位称突触。电镜下化学突触的结构可分为突触前成分、突触间隙和突触后成分。突触前成分和突触后成分彼此相对的细胞膜分别称为突触前膜和突触后膜。突触前成分内有许多突触小泡，还有少量线粒体、滑面内质网、微管、神经丝和微丝等。突触小泡内含神经递质或神经调质。

神经胶质细胞有星形胶质细胞（支持、营养和分隔神经元）、少突胶质细胞（在中枢神经纤维上形成髓鞘）、小胶质细胞、室管膜细胞、施万细胞（在周围神经纤维上形成髓鞘）和卫星细胞。

神经纤维是由轴突及包绕在其外面的神经胶质细胞构成。根据其是否有髓鞘包绕，分为有髓神经纤维和无髓神经纤维。周围有髓神经纤维是由施万细胞形成多层膜结构的髓鞘包裹轴突。髓鞘在电镜下呈明暗相间的同心板层结构，化学成分主要是类脂和蛋白质，称髓磷脂。各节段髓鞘间的无髓鞘缩窄部位称郎飞结。有髓神经纤维相邻两个郎飞结之间的一段神经纤维称结间体。

周围神经系统的神经纤维被包裹在一起构成神经，分布到全身各器官和组织。神经末梢按其功能可分感觉神经末梢和运动神经末梢两大类。

:::definition{label="本章结构通式"}
神经组织 = 神经元（冲动细胞）+ 神经胶质细胞（分隔、成鞘、营养和修复）。神经元用树突接收、用轴突传出，在突触把化学信号交给下一个细胞；胶质在中枢分成星形、少突、小胶质和室管膜，在周围换成施万细胞和卫星细胞。长轴突加上外包胶质成为神经纤维，纤维集合成神经，终末改写成感觉或运动末梢；切断后周围可循基膜管再生，中枢则常被瘢痕挡住。
:::

:::compare{title="全章六种胶质与成鞘归属"}
| 细胞 | 部位 | 核心职分 |
|------|------|----------|
| 星形胶质细胞 | 中枢 | 支持、营养、分隔；脚板；损伤时胶质瘢痕 |
| 少突胶质细胞 | 中枢 | 形成中枢髓鞘（一个细胞可包多条轴突） |
| 小胶质细胞 | 中枢 | 源自单核细胞，损伤时可成巨噬细胞 |
| 室管膜细胞 | 中枢腔面 | 衬脑室和中央管；脉络丛者可产脑脊液 |
| 施万细胞 | 周围神经纤维 | 形成周围髓鞘或沟内包裹无髓轴突；基膜；诱导再生 |
| 卫星细胞 | 神经节 | 包裹神经元胞体 |
:::

:::keypoint{label="全章把神经元、突触、胶质、纤维和再生收口"}
- 神经元三分结构：胞体（尼氏体、神经原纤维）+ 树突接收 + 轴突传导；分类可按突起、轴突长短、功能和化学性质。
- 化学突触三件套：前成分（小泡）– 间隙 – 后成分（受体）；电突触即缝隙连接。
- 胶质：中枢四型、周围两型；中枢髓鞘找少突，周围髓鞘找施万。
- 有髓跳跃、无髓连续；神经三层膜中束膜有紧密连接屏障。
- 感觉四型末梢 + 运动终板 / 膨体；周围可再生，中枢难再生。
:::

## 插入框：间充质干细胞与阿尔茨海默病的治疗

间充质干细胞（mesenchymal stem cell，MSC）是一种多能干细胞，可以来源于骨髓、脐带血、脂肪组织等，获取方便。它们具有自我更新的能力，并且可以分化成多种细胞类型，包括脂肪细胞、骨细胞和软骨细胞。此外，MSC 还具有免疫调节和抗炎作用，为治疗阿尔茨海默病（Alzheimer’s disease，AD）提供了理论基础。

AD 是一种严重的神经退行性疾病，以认知功能下降和神经系统损害为特征。目前，尚没有根治 AD 的有效治疗方法，而 MSC 在 AD 治疗中的机制主要涉及其免疫调节和神经保护作用。研究发现，MSC 可以分泌多种神经营养因子，这些因子对保护和恢复受损的神经细胞至关重要。此外，MSC 还能够降解致病性蛋白质聚集物，这是 AD 的典型病理特征之一。这些机制共同作用，有助于减轻 AD 患者的病理症状，改善认知功能，并可能减缓疾病的进展。MSC 还可能通过促进神经细胞生成和修复神经连接来改善 AD 患者的认知功能，为 AD 的治疗提供了更广阔的前景。

:::definition{label="间充质干细胞"}
间充质干细胞（mesenchymal stem cell，MSC）是一种多能干细胞，可来源于骨髓、脐带血、脂肪组织等，获取方便。具有自我更新能力，可分化为脂肪细胞、骨细胞和软骨细胞，并具有免疫调节和抗炎作用。
:::

:::definition{label="阿尔茨海默病"}
阿尔茨海默病（Alzheimer’s disease，AD）是一种严重的神经退行性疾病，以认知功能下降和神经系统损害为特征。目前尚无根治的有效治疗方法。
:::

:::compare{title="神经干细胞与间充质干细胞"}
| 项目 | 神经干细胞（NSC，第四节） | 间充质干细胞（MSC，本插入框） |
|------|---------------------------|--------------------------------|
| 主要来源 | 成体海马、脑和脊髓室管膜下区 | 骨髓、脐带血、脂肪组织等 |
| 常用标志 / 获取 | 巢蛋白（nestin） | 获取方便，教材未以巢蛋白鉴定 |
| 分化去向 | 神经元、星形胶质细胞、少突胶质细胞 | 脂肪细胞、骨细胞、软骨细胞等 |
| 与神经修复 | 神经组织自身的储备细胞 | 免疫调节、抗炎、分泌神经营养因子；可降解致病蛋白聚集物 |
| 教材落点 | 改写成体神经元不能新生的旧观点 | 为 AD 治疗提供理论基础和前景 |
:::

:::insight{label="MSC 进中枢修复名单，靠的是免疫调节和神经营养，不是先变成神经元"}
中枢再生困难的那一节已经把骨髓间充质干细胞写进移植名单。插入框把机制摊开：分泌神经营养因子、降解致病蛋白聚集物、免疫调节和抗炎，并可能促进神经细胞生成和连接修复。这与巢蛋白阳性的神经干细胞直接分化为神经元、星形胶质细胞和少突胶质细胞，是两条平行的细胞治疗账。
:::

:::note{label="插入框接回溃变再生，而不是另立一种“脑内间充质”"}
AD 属于退行性疾病，第四节已说可利用神经干细胞特性研究此类疾病。MSC 获取更方便，强调免疫调节和蛋白聚集物降解，是另一条正在探索的通路，不是把海马里的 NSC 改名为 MSC。
:::
