# 四、静脉

静脉由细至粗逐级汇合并最终汇入心脏，管壁也逐渐增厚。根据管径大小和管壁结构特点，静脉可分为微静脉、小静脉、中静脉和大静脉 4 种类型。与相伴行的动脉相比，静脉数量多，管径粗，管壁薄，管腔扁或不规则；无明显的内、外弹性膜，故 3 层膜的界限不如动脉明显；中膜薄，外膜厚，中膜的平滑肌纤维和弹性膜均较少，结缔组织较多，故静脉常呈塌陷状。静脉管壁结构的变异大，甚至同一条静脉的各段也常有较大差异。

静脉的功能是将身体各处的血液导流回心脏。静脉血回流的动力主要依靠静脉内的压力差。影响静脉压力差的因素很多，如心脏收缩力、血液重力、身体体位、呼吸运动和骨骼肌的收缩挤压作用等。

:::definition{label="静脉"}
静脉由细至粗逐级汇合并最终汇入心脏。按管径和管壁结构分为微静脉、小静脉、中静脉和大静脉 4 型。功能是将身体各处的血液导流回心脏；回流动力主要依靠静脉内的压力差。
:::

:::concept{term="先问三层清不清、中膜厚不厚、腔圆不圆"}
伴行切片上先问三件事：内、外弹性膜在不在；中膜是不是薄、外膜是不是厚；管腔是圆的还是扁的。动脉腔圆、壁厚、弹性膜清楚；静脉数量多、管径粗、壁薄、腔扁或不规则，常塌陷。不要按“旁边那根细的一定是静脉”——细而壁厚、腔圆的是动脉，粗而壁薄、腔不规则的才是静脉。
:::

:::compare{title="伴行的动脉与静脉"}
| 项目 | 动脉 | 静脉 |
|------|------|------|
| 数量与管径 | 较少，管径相对细 | 数量多，管径粗 |
| 管壁 | 厚 | 薄，常塌陷 |
| 管腔 | 较圆 | 扁或不规则 |
| 内、外弹性膜 | 中动脉等明显 | 不明显，三层界限不清 |
| 中膜 vs 外膜 | 中膜相对厚（肌性/弹性） | 中膜薄，外膜厚 |
| 中膜成分 | 平滑肌或弹性膜丰富 | 平滑肌和弹性膜均较少，结缔组织较多 |
| 瓣膜 | 无静脉瓣 | 管径 $2\,\mathrm{mm}$ 以上常见静脉瓣 |
| 变异 | 分型较稳定 | 变异大，同一条静脉各段也可有较大差异 |
:::

:::pitfall{label="静脉外膜厚、中膜薄，不要按动脉的‘中膜最厚’来认静脉"}
动脉分型看中膜。静脉把厚度账翻过来：中膜薄，外膜厚，大静脉外膜里还有大量纵行平滑肌束。把静脉也按“哪层最厚哪层就是中膜”去切，会把外膜纵行平滑肌当成中膜环行平滑肌，大静脉和中动脉会认反。
:::

## 1. 微静脉

微静脉（venule）管径一般为 $50\sim 200\,\mu\mathrm{m}$，内皮细胞之间的间隙较大，故通透性大；随着管径逐渐增大，中膜出现散在的平滑肌纤维并逐渐增多；外膜薄（见图 9-6）。紧接毛细血管的微静脉称毛细血管后微静脉（postcapillary venule），管径一般小于 $50\,\mu\mathrm{m}$，管壁结构与毛细血管相似，管径略粗。在淋巴组织内，毛细血管后微静脉的内皮细胞横切面一般呈立方形。

:::definition{label="微静脉"}
微静脉（venule）管径一般为 $50\sim 200\,\mu\mathrm{m}$。内皮细胞间隙较大，通透性大；随管径增大，中膜出现散在平滑肌并逐渐增多；外膜薄。
:::

:::definition{label="毛细血管后微静脉"}
毛细血管后微静脉（postcapillary venule）紧接毛细血管，管径一般小于 $50\,\mu\mathrm{m}$，管壁结构与毛细血管相似，管径略粗。淋巴组织内其内皮细胞横切面一般呈立方形。
:::

:::note{label="淋巴组织里立方形内皮的毛细血管后微静脉是淋巴细胞出入的门户"}
普通微静脉内皮仍是扁平的。教材特别写：淋巴组织内毛细血管后微静脉内皮横切面一般呈立方形。这是后文免疫系统高内皮微静脉的伏笔，不要当成毛细血管内皮肿了，也不要在普通器官的微静脉切片上强找立方形内皮。
:::

## 2. 小静脉

小静脉（small vein）管径一般为 $200\,\mu\mathrm{m}\sim 1\,\mathrm{mm}$，中膜的平滑肌纤维逐渐增多，较大的小静脉有 1 层至数层较完整的平滑肌纤维，外膜逐渐变厚（见图 9-6）。

:::definition{label="小静脉"}
小静脉（small vein）管径一般为 $200\,\mu\mathrm{m}\sim 1\,\mathrm{mm}$。中膜平滑肌逐渐增多，较大者有 1 层至数层较完整的平滑肌纤维，外膜逐渐变厚。
:::

## 3. 中静脉

中静脉（medium-sized vein）管径一般为 $1\sim 9\,\mathrm{mm}$，内膜薄，内皮下层含少量平滑肌纤维，内弹性膜不如中动脉明显；中膜比中动脉的薄很多，环行平滑肌纤维分布稀疏；外膜一般比中膜厚，无明显的外弹性膜，结缔组织中可含纵行的平滑肌纤维束（见图 9-4，图 9-13）。除大静脉外，凡有解剖学名称的静脉大都属于中静脉。

:::definition{label="中静脉"}
中静脉（medium-sized vein）管径一般为 $1\sim 9\,\mathrm{mm}$。内膜薄，内皮下层含少量平滑肌，内弹性膜不如中动脉明显；中膜比中动脉薄很多，环行平滑肌稀疏；外膜一般比中膜厚，无明显外弹性膜，可含纵行平滑肌束。除大静脉外，凡有解剖学名称的静脉大都属于中静脉。
:::

## 4. 大静脉

大静脉（large vein）为靠近心脏的静脉，包括颈外静脉、头臂静脉、奇静脉、肺静脉、髂外静脉、门静脉和腔静脉等。大静脉内膜较薄，内皮下层含少量平滑肌纤维，内膜与中膜界限不清；中膜很不发达，含数层排列疏松的环行平滑肌纤维；外膜很厚，结缔组织内含大量纵行的平滑肌纤维束（图 9-14）。

:::definition{label="大静脉"}
大静脉（large vein）为靠近心脏的静脉，包括颈外静脉、头臂静脉、奇静脉、肺静脉、髂外静脉、门静脉和腔静脉等。内膜较薄，与中膜界限不清；中膜很不发达，仅数层疏松环行平滑肌；外膜很厚，含大量纵行平滑肌纤维束。
:::

:::compare{title="微、小、中、大静脉"}
| 项目 | 微静脉 | 小静脉 | 中静脉 | 大静脉 |
|------|--------|--------|--------|--------|
| 管径 | $50\sim 200\,\mu\mathrm{m}$（毛细血管后微静脉 $<50\,\mu\mathrm{m}$） | $200\,\mu\mathrm{m}\sim 1\,\mathrm{mm}$ | $1\sim 9\,\mathrm{mm}$ | 靠近心脏的大干 |
| 内膜 | 内皮间隙大，通透性大 | 仍薄 | 薄；内皮下层少量平滑肌；内弹性膜不如中动脉明显 | 较薄，与中膜界限不清 |
| 中膜 | 散在平滑肌，随管径增多 | 1 层至数层较完整平滑肌 | 比中动脉薄很多，环行平滑肌稀疏 | 很不发达，数层疏松环行平滑肌 |
| 外膜 | 薄 | 逐渐变厚 | 一般比中膜厚，可含纵行平滑肌束 | 很厚，大量纵行平滑肌束 |
| 对应动脉 | 微动脉 | 小动脉 | 中动脉 | 大动脉（但结构不以弹性膜为主） |
:::

:::pitfall{label="大静脉的身份证是外膜纵行平滑肌束，不是中膜弹性膜"}
大动脉靠 $40\sim 70$ 层弹性膜认。大静脉中膜很不发达，认它要看外膜里大量纵行平滑肌束。肺静脉、腔静脉、门静脉都走这本外膜账。把“靠近心脏”理解成“也应该有多层弹性膜”，会把大静脉写成弹性静脉——教材没有这个名词。
:::

## 5. 静脉瓣

静脉瓣（venous valve）常见于管径 $2\,\mathrm{mm}$ 以上的静脉，为两个彼此相对的半月形薄片，由内膜凸入管腔折叠而成，表面覆以内皮，内部为含较多弹性纤维的结缔组织。静脉瓣的游离缘与血流方向一致，可防止血液逆流。

:::definition{label="静脉瓣"}
静脉瓣（venous valve）常见于管径 $2\,\mathrm{mm}$ 以上的静脉。两个彼此相对的半月形薄片，由内膜凸入管腔折叠而成；表面覆以内皮，内部为含较多弹性纤维的结缔组织。游离缘与血流方向一致，防止血液逆流。
:::

:::cause-effect{title="静脉压力差不足时瓣膜怎样防止逆流"}
- 因：静脉回流主要靠压力差，受心脏收缩力、重力、体位、呼吸和骨骼肌挤压影响
- 果：管径 $2\,\mathrm{mm}$ 以上的静脉以内膜折叠成相对的半月瓣，游离缘顺血流
- 影响：血液只能向心，骨骼肌挤压时瓣膜阻止血液向远端倒流
:::

:::insight{label="静脉壁薄、瓣膜多，是同一本低压回流账"}
动脉把动能写在中膜（弹性膜或环行平滑肌）上；静脉把动能让给心脏、呼吸和骨骼肌，自己只负责导流。所以壁薄、弹性膜不明显、中膜稀疏，外膜反而可以很厚并出现纵行平滑肌。瓣膜是内膜做的单向闸门，不是中膜长出来的肉。把静脉瓣写成“中膜突入管腔”，层次会退回第一节的三层通式之前。
:::

:::keypoint{label="静脉四型看管径和外膜，伴行对照看腔和弹性膜"}
- 与伴行动脉比：静脉多、粗、薄、腔扁；无明显内、外弹性膜；中膜薄、外膜厚；易塌陷；结构变异大。
- 微静脉 $50\sim 200\,\mu\mathrm{m}$，通透性大；毛细血管后微静脉 $<50\,\mu\mathrm{m}$，淋巴组织内皮可呈立方形。
- 小静脉 $200\,\mu\mathrm{m}\sim 1\,\mathrm{mm}$；中静脉 $1\sim 9\,\mathrm{mm}$（有名称者多属此类）；大静脉外膜含大量纵行平滑肌束。
- 静脉瓣：管径 $2\,\mathrm{mm}$ 以上，内膜折叠的相对半月瓣，防逆流。
- 回流动力是压力差，不是静脉自己的强中膜。
:::
