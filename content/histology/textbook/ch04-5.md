# 五、关节

关节分为动关节和不动关节。动关节主要是滑膜关节，即一般所称的关节，分布广泛，活动度大，其基本构成包括关节软骨、关节囊和关节腔。

:::definition{label="滑膜关节"}
动关节主要是滑膜关节，即一般所称的关节，分布广泛，活动度大。基本构成包括关节软骨、关节囊和关节腔。
:::

:::concept{term="先问三件套：软骨面、囊、腔里的滑液"}
滑膜关节不是两块骨直接摩擦。骨端覆关节软骨，纤维囊把腔封闭，滑膜细胞往腔里分泌滑液。软骨无软骨膜、无血管，营养走滑液；深部基质钙化，连着软骨下骨。看见关节切片，先问表面是不是透明软骨、有没有软骨膜，再问囊的内层是不是滑膜。
:::

## 1. 关节软骨

关节软骨（articular cartilage）为被覆于骨端关节面的薄层透明软骨，具有一定的弹性，表面光滑，有利于关节运动。关节软骨与一般的透明软骨有一定的差异。一是同源细胞群呈单行纵向排列，方向与表面垂直；二是软骨深部与骨组织相连，此处的软骨基质钙化；三是基质中的胶原原纤维呈拱形走向，既有加固作用，也为软骨提供较大的应力支持，使关节软骨具有较大的抗压性和一定的弹性（图 4-14）。

:::definition{label="关节软骨"}
关节软骨（articular cartilage）是被覆于骨端关节面的薄层透明软骨，具有一定弹性，表面光滑，有利于关节运动。它由次级骨化中心形成骨骺时，末端表面未被骨化的透明软骨终身保留而来。
:::

:::note{label="关节软骨相对一般透明软骨的三项差异"}
- 同源细胞群呈单行纵向排列，方向与表面垂直。
- 软骨深部与骨组织相连，此处的软骨基质钙化。
- 基质中的胶原原纤维呈拱形走向，既加固，也提供较大的应力支持，使关节软骨具有较大的抗压性和一定的弹性。
:::

:::pitfall{label="关节软骨是透明软骨，但没有软骨膜"}
第一节已写：除关节软骨外，软骨表面才被覆软骨膜。关节软骨靠滑液营养，不能按软骨膜下附加性生长来理解成体关节面的修复。深部钙化基质直接连骨，表面也没有一层致密结缔组织可找。把关节软骨画上软骨膜，会和滑膜、骨外膜三层膜搅在一起。
:::

:::concept{term="拱形胶原先问压力从关节面怎么传到骨"}
胶原原纤维从表面弯成拱，再插入深部钙化基质和软骨下骨。同源细胞群顺着拱的立柱单行纵列，垂直于表面。这和气管透明软骨中部那团同源细胞群不同：关节软骨要把压应力导向骨，而不是只在凝胶里抗压。
:::

## 2. 关节囊

关节囊（articular capsule）是封闭关节腔的纤维性结缔组织构成的囊状结构。关节囊分内、外两层，外层为致密结缔组织，与骨外膜连续，可维持关节的稳定；内层较疏松，内表面光滑，称为滑膜（synovial membrane），可向关节腔内突出形成滑膜皱襞或绒毛。滑膜内层常被覆 $1\sim 4$ 层扁平或立方形的上皮样结缔组织细胞，称滑膜细胞（synovial cell）。电镜下，滑膜细胞分为两种，一种似巨噬细胞，含较多溶酶体，有吞噬能力；另一种似成纤维细胞，含粗面内质网较多，可分泌透明质酸和黏蛋白。

:::definition{label="关节囊"}
关节囊（articular capsule）是封闭关节腔的纤维性结缔组织囊。外层为致密结缔组织，与骨外膜连续，维持关节稳定；内层较疏松，内表面光滑，称为滑膜。
:::

:::definition{label="滑膜"}
滑膜（synovial membrane）是关节囊内层，较疏松，内表面光滑，可向关节腔突出形成滑膜皱襞或绒毛。内层常被覆 $1\sim 4$ 层扁平或立方形的上皮样结缔组织细胞，即滑膜细胞。
:::

:::definition{label="滑膜细胞"}
滑膜细胞（synovial cell）是滑膜内表面 $1\sim 4$ 层扁平或立方形的上皮样结缔组织细胞。电镜下分两种：一种似巨噬细胞，含较多溶酶体，有吞噬能力；另一种似成纤维细胞，粗面内质网较多，分泌透明质酸和黏蛋白。
:::

:::pitfall{label="滑膜细胞是上皮样结缔组织细胞，不是被覆上皮"}
教材写的是上皮样结缔组织细胞，不要把它记进第二章的被覆上皮分类。外层关节囊与骨外膜连续，是致密结缔组织；内层滑膜才是疏松、可形成皱襞绒毛的分泌–吞噬面。两种滑膜细胞分别对应巨噬细胞谱系的清理和成纤维细胞谱系的分泌，和骨组织里破骨细胞、成骨细胞的分工可以对照着记，但来源和位置都不同。
:::

:::compare{title="两种滑膜细胞"}
| 项目 | 巨噬细胞样滑膜细胞 | 成纤维细胞样滑膜细胞 |
|------|---------------------|----------------------|
| 超微结构 | 含较多溶酶体 | 粗面内质网较多 |
| 功能 | 吞噬能力 | 分泌透明质酸和黏蛋白 |
| 与滑液的关系 | 清理关节腔内成分 | 构成滑液中的透明质酸、黏蛋白，提供黏性和营养 |
:::

## 3. 关节腔

关节腔（articular cavity）为关节囊所封闭的腔，关节腔内含少量透明的黏性液体，称滑液（synovial fluid）。滑液以水为主，含透明质酸、黏蛋白、电解质等，具有润滑关节面和营养关节软骨等作用。

:::definition{label="关节腔"}
关节腔（articular cavity）是关节囊所封闭的腔，内含少量透明黏性滑液。
:::

:::definition{label="滑液"}
滑液（synovial fluid）以水为主，含透明质酸、黏蛋白、电解质等，具有润滑关节面和营养关节软骨等作用。
:::

:::cause-effect{title="无软骨膜的关节软骨靠什么活"}
- 因：关节软骨无软骨膜，也无血管
- 因：成纤维细胞样滑膜细胞分泌透明质酸和黏蛋白，形成滑液
- 果：滑液润滑关节面，并把营养渗入透明软骨基质
- 果：巨噬细胞样滑膜细胞吞噬，维持腔内清洁
- 制约：深部钙化基质与软骨下骨相连，拱形胶原把压应力传入骨
:::

:::example{label="滑膜皱襞和绒毛加大分泌–吞噬面积"}
滑膜可向关节腔突出形成皱襞或绒毛，把 $1\sim 4$ 层滑膜细胞铺开。分泌面增大则滑液更新更充分，吞噬面增大则腔内碎屑更易被清除。这是关节囊内层“较疏松、内表面光滑”之外，功能状态上的可塑形态。
:::

:::compare{title="关节软骨、关节囊与关节腔"}
| 构件 | 组织性质 | 关键结构 | 功能 |
|------|----------|----------|------|
| 关节软骨 | 薄层透明软骨，无软骨膜 | 同源细胞群单行垂直于表面；深部基质钙化连骨；胶原原纤维拱形走向 | 光滑、弹性、抗压，利于运动 |
| 关节囊外层 | 致密结缔组织，与骨外膜连续 | 纤维性囊壁 | 封闭关节腔，维持稳定 |
| 滑膜（内层） | 较疏松；$1\sim 4$ 层上皮样结缔组织细胞 | 皱襞或绒毛；巨噬细胞样 + 成纤维细胞样滑膜细胞 | 吞噬；分泌透明质酸和黏蛋白 |
| 关节腔 / 滑液 | 密闭腔；滑液以水为主，含透明质酸、黏蛋白、电解质 | 少量透明黏性液体 | 润滑关节面，营养关节软骨 |
:::

:::keypoint{label="滑膜关节就是软骨面 + 囊 + 滑液"}
- 动关节主要是滑膜关节：关节软骨、关节囊、关节腔三件套。
- 关节软骨是无软骨膜的透明软骨：细胞单行垂直、深部钙化连骨、胶原拱形抗压。
- 囊外层致密、连骨外膜；内层滑膜被覆两种上皮样结缔组织细胞。
- 滑液润滑并营养无血管的关节软骨。
:::

:::memory{label="本节必背要点"}
- [ ] 关节分动关节和不动关节；动关节主要是滑膜关节，分布广、活动度大。
- [ ] 滑膜关节基本构成：关节软骨、关节囊、关节腔。
- [ ] 关节软骨（articular cartilage）：骨端关节面的薄层透明软骨，有弹性、表面光滑，利于运动。
- [ ] 与一般透明软骨的差异：①同源细胞群单行纵向排列，垂直于表面；②深部与骨相连，该处基质钙化；③胶原原纤维拱形走向，加固并提供应力支持，抗压性较大并有一定弹性。
- [ ] 关节软骨无软骨膜，营养来自滑液。
- [ ] 关节囊（articular capsule）：封闭关节腔的纤维性结缔组织囊，分内外两层。
- [ ] 外层致密结缔组织，与骨外膜连续，维持稳定。
- [ ] 内层较疏松，称滑膜（synovial membrane），可形成滑膜皱襞或绒毛。
- [ ] 滑膜细胞（synovial cell）：$1\sim 4$ 层扁平或立方形上皮样结缔组织细胞。
- [ ] 巨噬细胞样滑膜细胞：溶酶体较多，有吞噬能力。
- [ ] 成纤维细胞样滑膜细胞：粗面内质网较多，分泌透明质酸和黏蛋白。

- [ ] 滑液以水为主，含透明质酸、黏蛋白、电解质等，润滑关节面并营养关节软骨。

## 本章小结

软骨由软骨细胞和软骨膜构成。软骨细胞分泌软骨基质，软骨细胞所在腔隙称软骨陷窝，陷窝周围的基质嗜碱性强，称软骨囊。软骨周边的细胞幼稚、小而扁，散在分布；中部的细胞成熟、大而圆，分裂增殖为 $2\sim 8$ 个细胞组成的同源细胞群。软骨可分为透明软骨、弹性软骨和纤维软骨 3 种类型。

骨由骨组织和骨膜等构成。骨组织的细胞包括骨祖细胞、成骨细胞、骨细胞和破骨细胞。成骨细胞分泌类骨质后变为骨细胞，类骨质钙化后形成坚硬的骨质。成熟骨组织的骨质以板层骨的形式存在。长骨由密质骨、松质骨、关节软骨、骨膜和骨髓等构成。密质骨由多层排列规则紧密的骨板构成，有环骨板、骨单位和间骨板 3 种形式。环骨板是分布在骨干内、外表面的骨板，外环骨板层数多，也较规则。骨单位由多层骨单位骨板以同心圆排列的方式环绕中央管构成，数量多，呈长筒状，是长骨骨干的主要支撑结构。间骨板是充填于骨单位之间及骨单位和环骨板之间的不规则骨板。松质骨是由薄层骨板以骨小梁的方式交织形成的网格样结构。

骨的发生分为膜内成骨和软骨内成骨两种方式。膜内成骨是在胚性结缔组织内直接成骨，是不规则骨和扁骨等的发生方式。软骨内成骨是在形成一块透明软骨的基础上，再改造替换成骨，是长骨、椎骨以及部分颅底骨的发生方式。长骨的加长是通过骺板软骨的不断增生和替换成骨的方式实现，增粗则是通过骨干表面的骨形成和骨髓腔面的骨吸收而实现。在骨的发生和生长过程始终伴随着骨的重建，是骨形成与骨吸收的动态平衡，可受多种因素影响。

关节由关节软骨、关节囊和关节腔构成。

:::definition{label="本章结构通式"}
软骨组织把细胞埋进未钙化的凝胶基质，可从内部膨胀生长；骨组织把细胞埋进钙化骨质，只能在表面成骨、在表面溶骨，内部靠陷窝–小管和中央管运输。长骨用骺板加长、骨膜下成骨增粗，并用重建把外形和骨单位写成符合应力的构型。
:::

:::compare{title="软骨与骨对照"}
| 项目 | 软骨 | 骨 |
|------|------|-----|
| 主体 | 软骨组织 + 软骨膜（关节软骨无膜） | 骨组织 + 骨膜 + 骨髓等（器官） |
| 细胞 | 软骨细胞（周边幼稚，中部同源细胞群 $2\sim 8$ 个） | 骨祖细胞、成骨细胞、骨细胞、破骨细胞（仅骨细胞在内部） |
| 基质 | 未钙化凝胶；蛋白聚糖 + 纤维 | 钙化骨质；Ⅰ型胶原 + 骨盐（羟基磷灰石） |
| 血管 | 组织内无血管淋巴管，靠渗透 | 中央管、穿通管、骨膜血管供血 |
| 生长 | 附加性 + 间质性 | 不能内部生长；骺板加长，骨膜下增粗 |
| 改建 | 软骨内成骨时被替换 | 终身骨形成与骨吸收动态平衡 |
:::

:::keypoint{label="全章把支架从软骨接到骨和关节"}
- 软骨：陷窝、软骨囊、同源细胞群；三型按纤维区分；关节软骨无软骨膜。
- 骨组织：类骨质钙化成板层骨；成骨细胞被埋入成骨细胞，破骨细胞来自单核细胞融合。
- 密质骨三种骨板 + 黏合线 + 穿通管；松质骨为骨小梁网格。
- 膜内成骨直接成骨，软骨内成骨经软骨雏形、骨领、初级/次级骨化中心和骺板。
- 骺线形成后不再长长；重建是成骨与破骨的动态平衡，受维生素、激素、细胞因子和应力影响。
- 滑膜关节：无膜的关节软骨 + 滑膜囊 + 滑液。
:::
