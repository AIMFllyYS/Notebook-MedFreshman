# 六、淋巴管系统

人体内除软骨组织、骨组织、骨髓、表皮、眼球、内耳及牙等没有淋巴管道外，其余组织或器官大多有淋巴管道或类淋巴管道，其功能主要是将组织液中的水、电解质和大分子物质等输送入血。

:::definition{label="淋巴管系统"}
淋巴管系统由毛细淋巴管、淋巴管和淋巴导管组成。功能主要是将组织液中的水、电解质和大分子物质等输送入血。除软骨组织、骨组织、骨髓、表皮、眼球、内耳及牙等没有淋巴管道外，其余组织或器官大多有淋巴管道或类淋巴管道。
:::

:::concept{term="先问这里有没有淋巴管：软骨、骨、骨髓、表皮、眼球、内耳和牙没有"}
淋巴管不是全身均匀分布。教材点名没有淋巴管道的是软骨组织、骨组织、骨髓、表皮、眼球、内耳及牙。其余大多有淋巴管道或类淋巴管道。看见组织水肿，先问这一层本来有没有毛细淋巴管可引流；把骨髓和骨也写成“淋巴管丰富”，回流账会和第三节血窦、第五章造血器官打架。
:::

:::pitfall{label="骨髓没有淋巴管道，不要因为会造淋巴细胞就给它补一套淋巴管"}
骨髓是造血器官，血窦发达，但教材明确写骨髓没有淋巴管道。淋巴细胞从骨髓进入血液走的是血管，不是淋巴管。表皮同样没有淋巴管，真皮才有。把“免疫细胞所在之处必有淋巴管”当成通式，例外名单会作废。
:::

## 1. 毛细淋巴管

毛细淋巴管（lymphatic capillary）以盲端起始于组织内，互相吻合成网，然后汇入淋巴管。与毛细血管相比，毛细淋巴管的管腔更大而不规则，管壁更薄，仅由一层内皮及不完整的基膜构成，无周细胞；内皮细胞之间的间隙更大，大分子物质易进出；内皮细胞被直径 $5\sim 10\,\mathrm{nm}$ 的锚丝（anchoring filament）锚定于结缔组织。

:::definition{label="毛细淋巴管"}
毛细淋巴管（lymphatic capillary）以盲端起始于组织内，互相吻合成网，然后汇入淋巴管。管腔更大而不规则，管壁更薄，仅由一层内皮及不完整的基膜构成，无周细胞；内皮细胞间隙更大，大分子物质易进出；内皮被直径 $5\sim 10\,\mathrm{nm}$ 的锚丝锚定于结缔组织。
:::

:::definition{label="锚丝"}
锚丝（anchoring filament）直径 $5\sim 10\,\mathrm{nm}$，把毛细淋巴管内皮细胞锚定于周围结缔组织，使盲端管腔在组织液增多时仍能保持开放。
:::

:::compare{title="毛细淋巴管与毛细血管"}
| 项目 | 毛细血管 | 毛细淋巴管 |
|------|----------|------------|
| 起始 | 连接微动脉与微静脉，成网 | 以盲端起始于组织内，再吻合成网 |
| 管腔 | 一般 $6\sim 8\,\mu\mathrm{m}$，较规则 | 更大而不规则 |
| 管壁 | 内皮 + 基膜（基板）+ 周细胞 | 仅一层内皮 + 不完整基膜，无周细胞 |
| 内皮间隙 | 连续型有紧密连接；血窦中间隙大 | 间隙更大，大分子易进出 |
| 周细胞 | 有 | 无 |
| 锚定 | 基膜完整或因类型而异 | 锚丝（$5\sim 10\,\mathrm{nm}$）锚定于结缔组织 |
| 内容物 | 血液 | 淋巴（组织液中的水、电解质和大分子等） |
:::

:::pitfall{label="毛细淋巴管无周细胞，不要按毛细血管三件套来认"}
毛细血管壁是内皮、基膜、周细胞。毛细淋巴管把周细胞去掉，基膜还不完整，靠锚丝把内皮钉在结缔组织上。管腔大而不规则、盲端起始，是光镜下和毛细血管最容易分的两点。把毛细淋巴管写成“没有红细胞的毛细血管”，锚丝和不完整基膜两本账都会做丢。
:::

:::insight{label="盲端加更大间隙，才能把组织液和大分子收进淋巴"}
心血管是封闭管道，组织液要从毛细血管滤出，再从静脉端和淋巴两条路回去。毛细淋巴管必须盲端起始，才能在组织里开口；必须间隙更大、基膜不完整，大分子才进得去；必须有锚丝，组织水肿把结缔组织拉开时管腔不会被压扁。第一节循环系统把淋巴管系统并进封闭管道，指的是最终汇入静脉，不是说它在组织里也没有盲端。
:::

## 2. 淋巴管

淋巴管（lymphatic vessel）包括粗细不等的几级分支，其管壁结构与相应管径的中、小静脉相似，也具备 3 层膜结构，但淋巴管的管壁更薄，3 层膜的界限更不明显，管腔内的瓣膜更多，在瓣膜之间的管壁常膨大呈结节状或串珠状。

:::definition{label="淋巴管"}
淋巴管（lymphatic vessel）包括粗细不等的几级分支。管壁结构与相应管径的中、小静脉相似，也具备 3 层膜，但更薄、3 层界限更不明显，瓣膜更多；瓣膜之间的管壁常膨大呈结节状或串珠状。
:::

:::note{label="串珠状是瓣膜多、瓣间膨大的外形，不是病变"}
淋巴管内瓣膜比同级静脉更多，两个瓣之间的管壁膨出，外观呈结节状或串珠状。这是正常结构，用来保证淋巴单向汇流，不要当成静脉曲张或炎症结节。
:::

## 3. 淋巴导管

淋巴导管（lymphatic duct）为靠近心脏的淋巴管道，包括胸导管和右淋巴导管，其管壁结构与大静脉相似，但管壁更薄，3 层膜的界限更不明显，中膜平滑肌纤维呈纵行和环行排列，外膜较薄，含营养血管和神经纤维。

:::definition{label="淋巴导管"}
淋巴导管（lymphatic duct）为靠近心脏的淋巴管道，包括胸导管和右淋巴导管。管壁结构与大静脉相似，但更薄，3 层界限更不明显；中膜平滑肌呈纵行和环行排列；外膜较薄，含营养血管和神经纤维。
:::

:::compare{title="毛细淋巴管、淋巴管与淋巴导管"}
| 项目 | 毛细淋巴管 | 淋巴管 | 淋巴导管 |
|------|------------|--------|----------|
| 英文 | lymphatic capillary | lymphatic vessel | lymphatic duct |
| 位置与级别 | 组织内盲端起始 | 粗细不等的几级分支 | 靠近心脏：胸导管、右淋巴导管 |
| 管壁 | 一层内皮 + 不完整基膜，无周细胞 | 3 层，但比相应中、小静脉更薄，界限更不清 | 类似大静脉但更薄，界限更不清 |
| 中膜平滑肌 | 无 | 少于同级静脉 | 纵行和环行排列 |
| 瓣膜 | 无典型静脉瓣结构 | 比同级静脉更多，瓣间呈串珠状 | 有瓣膜 |
| 外膜 | 无 | 薄 | 较薄，含营养血管和神经 |
:::

:::cause-effect{title="组织液怎样经淋巴管系统回到血液"}
- 因：毛细血管滤出的水、电解质和大分子不能全部从静脉端回收
- 果：毛细淋巴管盲端（大间隙、不完整基膜、锚丝）收入这些成分，汇入淋巴管、淋巴导管
- 影响：淋巴最终入血，既回收液体，也输送大分子；淋巴管系统功能状态直接关系到组织含水量
:::

:::keypoint{label="淋巴管系统盲端起始，对标同级静脉但更薄、瓣膜更多"}
- 无淋巴管道：软骨、骨、骨髓、表皮、眼球、内耳及牙。
- 毛细淋巴管：盲端、腔大不规则、无周细胞、基膜不完整、间隙大、锚丝 $5\sim 10\,\mathrm{nm}$。
- 淋巴管 ≈ 更薄的中、小静脉，瓣膜更多，呈串珠状。
- 淋巴导管（胸导管、右淋巴导管）≈ 更薄的大静脉，中膜平滑肌纵行和环行，外膜较薄。
- 功能：把组织液中的水、电解质和大分子输送入血。
:::
