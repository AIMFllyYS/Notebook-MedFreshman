# 三、腭的发生与口腔、鼻腔的分隔

腭来自两处突起：左右内侧鼻突融合后长出的正中腭突，只占腭前部一小部分；左右上颌突长出的外侧腭突，构成腭的大部分。外侧腭突先在舌两侧斜向下，等舌下降后才抬到水平、中线融合，再与正中腭突汇拢，三者交会残留切齿孔。前部骨化成硬腭，后部为软腭，后缘正中成腭垂。鼻中隔再与腭中线融合，把鼻腔一分为二。本节把这两块腭突和口鼻分隔摊开；舌的发生下一节再写。

## 正中腭突与外侧腭突

腭起源于正中腭突与外侧腭突两部分。左右内侧鼻突融合后，向原始口腔内长出一短小的突起，称正中腭突（median palatine process），将演化为腭前部的一小部分。之后，左右上颌突向原始口腔内长出一对扁平的突起，称外侧腭突（lateral palatine process）。起初，外侧腭突在舌的两侧斜向下方生长。随着口腔扩大及舌的位置下降，左右外侧腭突逐渐在舌的上方呈水平方向生长，并在中线融合，形成腭的大部分。其前缘与正中腭突汇拢融合，三者正中交会处残留一小孔，即切齿孔。之后，腭前部间充质骨化为硬腭，后部则为软腭。软腭后缘正中组织增生突起，形成腭垂（图 22-5，图 22-6）。

:::definition{label="正中腭突"}
正中腭突（median palatine process）是左右内侧鼻突融合后，向原始口腔内长出的短小突起。它只演化为腭前部的一小部分，不是整块硬腭。
:::

:::definition{label="外侧腭突"}
外侧腭突（lateral palatine process）是左右上颌突向原始口腔内长出的一对扁平突起，形成腭的大部分。起初在舌的两侧斜向下方生长，舌下降后才在舌的上方呈水平方向生长并在中线融合。
:::

:::definition{label="切齿孔"}
切齿孔是正中腭突与左右外侧腭突三者正中交会处残留的一小孔。它是三突汇拢的遗迹，不是后来凿出来的鼻孔，也不是腭裂。
:::

:::definition{label="硬腭、软腭与腭垂"}
腭前部间充质骨化为硬腭，后部不骨化而为软腭。软腭后缘正中组织增生突起，形成腭垂。硬、软是同一块腭的前、后份，不是两套独立的突起。
:::

:::concept{term="先问正中腭突还是外侧腭突，再问切齿孔是不是三突交会残留"}
看见腭，先问来源：内侧鼻突融合后伸进原始口腔的短突是正中腭突，只占前部一小块；上颌突伸进原始口腔的扁平突是外侧腭突，占大部分。再问中线那个孔：左右外侧腭突中线融合，前缘再与正中腭突汇拢，三者交会残留的才是切齿孔。把整块腭写成正中腭突，或把切齿孔写成“没融合的腭裂”，后面的前腭裂、正中腭裂会对错缝。
:::

:::compare{title="正中腭突与外侧腭突"}
| 项目 | 正中腭突 | 外侧腭突 |
|------|----------|----------|
| 英文 | median palatine process | lateral palatine process |
| 来源 | 左右内侧鼻突融合后向原始口腔内长出 | 左右上颌突向原始口腔内长出 |
| 形态 | 一短小的突起 | 一对扁平突起 |
| 初期方位 | 位于前方正中 | 先在舌的两侧斜向下方 |
| 后期方位 | 仍在腭前部 | 舌下降后抬至水平，在舌上方中线融合 |
| 占腭的份额 | 腭前部的一小部分 | 腭的大部分 |
| 交会遗迹 | 与左右外侧腭突交会，残留切齿孔 | 左右在中线融合，前缘再与正中腭突汇拢 |
:::

:::pitfall{label="切齿孔是正中腭突与左右外侧腭突交会残留，不是腭裂"}
三突正中交会处留一小孔，叫切齿孔，是正常残留。腭裂是该融未融：外侧腭突与正中腭突未融合为前腭裂（切齿孔至切齿之间），左右外侧腭突未在中线融合为正中腭裂（切齿孔至腭垂）。把切齿孔写成畸形，或把正中腭裂写成“切齿孔裂开”，正常遗迹和病理裂隙会并成一句。
:::

:::pitfall{label="外侧腭突不是一开始就在水平位对生"}
起初外侧腭突在舌的两侧斜向下方生长。必须等口腔扩大、舌的位置下降，它们才抬到舌的上方呈水平方向，再在中线融合。把腭写成“左右腭突始终平着长到一起”，会漏掉“先垂下、后抬平”这一步，也解释不了舌高位时腭突抬不起来。
:::

:::cause-effect{title="舌下降之后，外侧腭突才能抬平并中线融合"}
- 因：起初外侧腭突在舌的两侧斜向下方
- 果：此时还不能在中线对上
- 因：口腔扩大、舌的位置下降
- 果：左右外侧腭突在舌上方呈水平方向生长，中线融合，形成腭的大部分；前缘再与正中腭突汇拢
- 制约：三者交会处残留切齿孔，这是正常结构
:::

腭将原始口腔与原始鼻腔分隔成为永久口腔和鼻腔。

:::definition{label="永久口腔和鼻腔"}
腭融合完成后，原始口腔与原始鼻腔被分隔成为永久口腔和鼻腔。鼻腔在腭后缘与咽相通。口鼻膜破裂只是让两腔暂时相通；真正把它们分成上下两层的，是后来的腭。
:::

:::note{label="口鼻膜破裂与腭分隔不是同一步"}
上一节：口鼻膜破裂后，原始口腔与原始鼻腔相通。这一节：外侧腭突抬平融合，才把相通的两腔分成永久口腔和鼻腔。先打通、再加盖，顺序不要写反。
:::

## 鼻中隔与鼻甲

鼻腔在腭后缘与咽相通。伴随腭的形成，额鼻突和内侧鼻突的外胚层和中胚层组织增生，向原始鼻腔内长出板状隔膜，即鼻中隔。鼻中隔向下生长，最终与腭在中线融合，将鼻腔一分为二。鼻腔的两外侧壁各发生 $3$ 个皱襞，分别形成上、中、下 $3$ 个鼻甲（图 22-4，图 22-5）。

:::definition{label="鼻中隔"}
鼻中隔是额鼻突和内侧鼻突的外胚层和中胚层组织增生、向原始鼻腔内长出的板状隔膜。它向下生长，最终与腭在中线融合，将鼻腔一分为二。来源记额鼻突和内侧鼻突，不记上颌突。
:::

:::definition{label="鼻甲"}
鼻腔的两外侧壁各发生 $3$ 个皱襞，分别形成上、中、下 $3$ 个鼻甲。鼻甲是外侧壁的皱襞，不是鼻中隔的分叉。
:::

:::compare{title="腭、鼻中隔与鼻甲在分隔中的职分"}
| 项目 | 腭 | 鼻中隔 | 鼻甲 |
|------|----|--------|------|
| 主要来源 | 正中腭突（内侧鼻突）+ 外侧腭突（上颌突） | 额鼻突和内侧鼻突的外胚层与中胚层 | 鼻腔外侧壁的皱襞 |
| 作用方向 | 水平分隔：原始口腔 / 原始鼻腔 → 永久口腔和鼻腔 | 正中垂直分隔：鼻腔一分为二 | 外侧壁成形，不成隔 |
| 与咽的关系 | 鼻腔在腭后缘与咽相通 | 左右鼻腔各自经后方通咽 | — |
| 不要听成 | 只来自正中腭突 | 来自上颌突 | 把鼻腔分成左右 |
:::

:::insight{label="水平一张盖、垂直一道墙"}
外侧腭突抬平融合，等于给相通的口鼻加了一张水平的盖，上下变成口腔和鼻腔；鼻中隔再从额鼻突、内侧鼻突垂下来贴到这张盖的中线，左右才分成两鼻腔。盖和墙不是同一块突起来的。把鼻中隔写成外侧腭突的一部分，左右鼻腔那本账会算到上颌突头上。
:::

:::timeline{period="从斜向下的外侧腭突到左右鼻腔"}
- **正中腭突** 左右内侧鼻突融合后，向原始口腔内长出短小突起，日后仅占腭前部一小部分
- **外侧腭突出现** 左右上颌突向原始口腔内长出一对扁平突起，起初在舌两侧斜向下
- **舌下降** 口腔扩大、舌位下降，外侧腭突抬至水平，中线融合，形成腭的大部分
- **三突交会** 外侧腭突前缘与正中腭突汇拢，残留切齿孔
- **硬腭与软腭** 前部间充质骨化为硬腭，后部为软腭，后缘正中增生为腭垂
- **口鼻分层** 腭将原始口腔与原始鼻腔分隔为永久口腔和鼻腔；鼻腔在腭后缘通咽
- **鼻中隔与鼻甲** 额鼻突和内侧鼻突长出鼻中隔，与腭中线融合，鼻腔一分为二；外侧壁各发生 3 个皱襞，成上、中、下鼻甲
:::

:::keypoint{label="正中腭突只占前一小块，外侧腭突先下垂后抬平，切齿孔是三突交会残留"}
- 正中腭突（内侧鼻突）→ 腭前部一小部分；外侧腭突（上颌突）→ 腭大部分。
- 外侧腭突：舌两侧斜向下 → 舌下降后水平、中线融合 → 前缘与正中腭突汇拢。
- 三者正中交会残留切齿孔；前部骨化硬腭，后部软腭，后缘正中 → 腭垂。
- 腭把原始口腔与原始鼻腔分成永久口腔和鼻腔；鼻腔在腭后缘通咽。
- 鼻中隔来自额鼻突和内侧鼻突，向下与腭中线融合，鼻腔一分为二；外侧壁 $3$ 个皱襞 → 上、中、下鼻甲。
:::
