# 三、胚层的形成

第 $2$ 周，胚泡还在植入，内细胞群已经铺成圆盘状的二胚层胚盘：贴滋养层的是柱状上胚层，贴胚泡腔的是立方下胚层。上胚层里挖出羊膜腔，下胚层周缘围出卵黄囊，二者之间的空隙里铺上胚外中胚层，再挖出胚外体腔，剩下一条体蒂连着滋养层。第 $3$ 周，上胚层细胞在尾端中线聚成原条，从原沟迁移的细胞铺出中胚层、置换出内胚层，剩下的上胚层改称外胚层——三个胚层都来自上胚层。本节把二胚层胚盘、原条和三胚层摊开；三胚层如何分化成器官原基，下一节再写。

## （一）二胚层胚盘及其结构的形成

在第 $2$ 周胚泡植入过程中，内细胞群增殖分化，逐渐形成圆盘状的胚盘（embryonic disc），由两个胚层组成，也称二胚层胚盘。邻近滋养层的一层柱状细胞为上胚层（epiblast），靠近胚泡腔侧的一层立方细胞为下胚层（hypoblast）。两个胚层紧贴，中间隔以基膜（图 21-6，图 21-9）。胚盘是人体发生的原基。

:::definition{label="胚盘"}
胚盘（embryonic disc）由内细胞群增殖分化形成，呈圆盘状，是人体发生的原基。第 $2$ 周为二胚层，第 $3$ 周末成为三胚层。
:::

:::definition{label="二胚层胚盘"}
二胚层胚盘由上胚层和下胚层组成。两层紧贴，中间隔以基膜。它出现在第 $2$ 周的植入过程中。
:::

:::definition{label="上胚层"}
上胚层（epiblast）是邻近滋养层的一层柱状细胞。稍后它构成羊膜囊的底；第 $3$ 周原条的细胞也从这里迁出。三个胚层最终都起源于上胚层。
:::

:::definition{label="下胚层"}
下胚层（hypoblast）是靠近胚泡腔侧的一层立方细胞。它构成卵黄囊的顶。第 $3$ 周将被迁入的上胚层来源细胞全部置换，形成内胚层。
:::

:::concept{term="先认上胚层在背、下胚层在腹，再问腔是羊膜腔还是卵黄囊"}
看见第 $2$ 周的圆盘，先分背腹：邻滋养层、柱状的是上胚层（背侧）；邻胚泡腔、立方的是下胚层（腹侧）。再问两个囊：上胚层里头出现的液腔是羊膜腔，上胚层做底；下胚层周缘向腹侧围出来的是卵黄囊，下胚层做顶。把上、下胚层听成“将来的外胚层和内胚层已经就位”，会漏掉第 $3$ 周“三个胚层都来自上胚层”那句。
:::

::figure{src="/images/histology/textbook/p0230_01.png" caption="图21-9 二胚层胚盘（鸡胚）光镜图。两层细胞紧贴成盘，中间隔以基膜。" alt="鸡胚光镜：一条粉染的两层细胞带呈浅 V 形盘状，中央略厚"}

而后，由于上胚层细胞增殖，其内出现一个充满液体的小腔隙，称羊膜腔（amniotic cavity），腔内液体为羊水。贴靠细胞滋养层的一层上胚层细胞形状扁平，称成羊膜细胞，它们形成最早的羊膜，并与上胚层的其余部分共同包裹羊膜腔，其所形成的囊称羊膜囊。上胚层构成羊膜囊的底。

下胚层周缘的细胞向腹侧生长延伸，形成由单层扁平上皮细胞围成的另一个囊，即卵黄囊（yolk sac）。下胚层构成卵黄囊的顶。羊膜囊和卵黄囊对胚盘起保护和营养作用。

:::definition{label="羊膜腔"}
羊膜腔（amniotic cavity）是上胚层细胞增殖后在其内出现的充满液体的小腔隙，腔内液体为羊水。
:::

:::definition{label="成羊膜细胞"}
成羊膜细胞是贴靠细胞滋养层的一层扁平上胚层细胞，形成最早的羊膜，并与上胚层其余部分共同包裹羊膜腔。
:::

:::definition{label="羊膜囊"}
羊膜囊由最早的羊膜与上胚层其余部分共同包裹羊膜腔而成。上胚层构成羊膜囊的底。
:::

:::definition{label="卵黄囊"}
卵黄囊（yolk sac）由下胚层周缘细胞向腹侧延伸、以单层扁平上皮围成。下胚层构成卵黄囊的顶。羊膜囊和卵黄囊对胚盘起保护和营养作用。
:::

此时胚泡腔内出现松散分布的星状细胞和细胞外基质，充填于细胞滋养层和卵黄囊、羊膜囊之间，形成胚外中胚层（extraembryonic mesoderm）（图 21-6）。继而胚外中胚层细胞间出现腔隙，腔隙逐渐汇合增大，在胚外中胚层内形成一个大腔，称胚外体腔（图 21-10）。胚外中胚层则分别附着于滋养层内面及卵黄囊和羊膜囊的外面。随着胚外体腔的扩大，二胚层胚盘和其背腹两侧的羊膜囊、卵黄囊仅由少部分胚外中胚层与滋养层直接相连，这部分胚外中胚层称体蒂（body stalk）。体蒂将发育为脐带的主要成分。

:::definition{label="胚外中胚层"}
胚外中胚层（extraembryonic mesoderm）由松散分布的星状细胞和细胞外基质构成，充填于细胞滋养层与卵黄囊、羊膜囊之间。它还不是胚盘里的中胚层。
:::

:::definition{label="胚外体腔"}
胚外体腔是胚外中胚层细胞间腔隙逐渐汇合增大后形成的大腔。胚外中胚层因此分别贴在滋养层内面以及卵黄囊、羊膜囊外面。
:::

:::definition{label="体蒂"}
体蒂（body stalk）是胚外体腔扩大后，仍把二胚层胚盘及其背腹两侧羊膜囊、卵黄囊与滋养层直接连在一起的那少部分胚外中胚层。它将发育为脐带的主要成分。
:::

::figure{src="/images/histology/textbook/p0230_02.png" caption="图21-10 第 3 周初胚的立体模式图。示羊膜、羊膜腔、胚盘、卵黄囊、胚外体腔、胚外体壁中胚层、胚外脏壁中胚层、滋养层、绒毛膜与绒毛。" alt="立体模式：外周绿色绒毛与滋养层，粉红胚外体腔，上方蓝羊膜囊、中间胚盘、下方黄卵黄囊，囊外贴胚外中胚层"}

:::compare{title="上胚层与下胚层（第2周）"}
| 项目 | 上胚层 | 下胚层 |
|------|--------|--------|
| 位置 | 邻近滋养层（背侧） | 靠近胚泡腔（腹侧） |
| 细胞形态 | 一层柱状细胞 | 一层立方细胞 |
| 相关囊 | 构成羊膜囊的底 | 构成卵黄囊的顶 |
| 第 $3$ 周去向 | 迁出中胚层和内胚层后，自身改称外胚层 | 被置换，不作为内胚层留下 |
:::

:::compare{title="羊膜囊与卵黄囊"}
| 项目 | 羊膜囊 | 卵黄囊 |
|------|--------|--------|
| 发生 | 上胚层内出现羊膜腔，成羊膜细胞与其余上胚层共同包裹 | 下胚层周缘向腹侧延伸，单层扁平上皮围成 |
| 胚盘关系 | 上胚层为底 | 下胚层为顶 |
| 腔内 | 羊水 | 卵黄囊腔 |
| 共同作用 | 对胚盘起保护和营养作用 | 对胚盘起保护和营养作用 |
:::

:::pitfall{label="第2周的下胚层还不是内胚层，胚外中胚层也还不是胚盘里的中胚层"}
下胚层只是二胚层胚盘的腹侧一层立方细胞，第 $3$ 周会被上胚层来的细胞全部换掉才叫内胚层。胚外中胚层铺在滋养层和两个囊之间，属于胚外结构；胚内中胚层要等原条细胞在上、下胚层之间铺夹层。两对“内/外、上/下”不要并成一句。
:::

:::note{label="体蒂是后来脐带的主要成分"}
胚外体腔越扩越大，胚盘连同羊膜囊、卵黄囊只靠体蒂连着滋养层。体蒂不是原条，也不是脊索；它是胚外中胚层的残留连接，以后主要构成脐带。
:::

:::timeline{period="第2周：二胚层胚盘及其附属结构"}
- **内细胞群** 增殖分化为圆盘状二胚层胚盘（柱状上胚层 + 立方下胚层，中间基膜）
- **羊膜囊** 上胚层内出现羊膜腔；成羊膜细胞形成最早羊膜；上胚层为羊膜囊底
- **卵黄囊** 下胚层周缘向腹侧延伸；下胚层为卵黄囊顶
- **胚外中胚层** 星状细胞 + 细胞外基质充填于细胞滋养层与两囊之间
- **胚外体腔** 胚外中胚层内腔隙汇合扩大
- **体蒂** 仅剩少部分胚外中胚层连接滋养层，将发育为脐带主要成分
:::

## （二）三胚层胚盘及其结构的形成

第 $3$ 周初，上胚层部分细胞增殖较快，并向胚盘一端中线迁移，在中轴线上聚集形成一条纵行的细胞柱，称原条（primitive streak）。原条的头端略膨大，为原结（primitive node）（图 21-11）。继而在原条的中线出现浅沟，原结的中心出现浅凹，分别称原沟（primitive groove）和原凹（primitive pit）。原沟深部的细胞不断增殖，并在上、下胚层之间向周边扩展迁移。一部分细胞在上、下两胚层之间形成一个夹层，称胚内中胚层，即中胚层（mesoderm），它在胚盘边缘与胚外中胚层衔接。另一部分细胞进入下胚层，并逐渐全部置换了下胚层的细胞，形成一层新的细胞，称内胚层（endoderm）。在内胚层和中胚层出现之后，原上胚层改称外胚层（ectoderm）。于是在第 $3$ 周末，三胚层胚盘形成，$3$ 个胚层均起源于上胚层。

:::definition{label="原条"}
原条（primitive streak）是第 $3$ 周初上胚层细胞向胚盘一端中线迁移、在中轴线上聚集形成的纵行细胞柱。原条所在的一端为胚盘尾端。
:::

:::definition{label="原结"}
原结（primitive node）是原条头端略膨大的部分。其中心随后出现原凹。
:::

:::definition{label="原沟与原凹"}
原沟（primitive groove）是原条中线上的浅沟；原凹（primitive pit）是原结中心的浅凹。原沟深部的细胞经此增殖，并在上、下胚层之间向周边迁移。
:::

:::definition{label="中胚层"}
中胚层（mesoderm）即胚内中胚层，是原沟深部一部分细胞在上、下胚层之间铺成的夹层。它在胚盘边缘与胚外中胚层衔接。
:::

:::definition{label="内胚层"}
内胚层（endoderm）由进入下胚层、并逐渐全部置换下胚层细胞的那一部分上胚层来源细胞形成。置换完成后，原来的下胚层不再存在。
:::

:::definition{label="外胚层"}
外胚层（ectoderm）是内胚层和中胚层出现之后，对原上胚层的改称。它不是另外迁来的第三群细胞。
:::

:::definition{label="三胚层胚盘"}
第 $3$ 周末形成的胚盘，由外胚层、中胚层和内胚层组成。$3$ 个胚层均起源于上胚层。
:::

:::concept{term="先找原条定尾端，再问迁出的细胞是铺夹层还是换下胚层"}
第 $3$ 周先在胚盘背面找一条中线细胞柱：有原条的一端是尾端，原结朝头。细胞从原沟往下走，分成两本账：夹在上、下胚层之间的是中胚层；钻进下胚层把原有立方细胞全部换掉的是内胚层；留下来的上胚层改名外胚层。把“下胚层改名为内胚层”当成原位升级，会写错三个胚层的起源。
:::

::figure{src="/images/histology/textbook/p0231_01.png" caption="图21-11 第 16 天的胚盘示意图。A. 胚盘背面观（原结、原凹、原条）；B. 中胚层和脊索的形成（上胚层被去除，箭头示中胚层和脊索细胞的迁移方向）；C. 通过原条的胚盘横切面，示中胚层形成（箭头示原条细胞迁移方向）。" alt="三图：A 梨形胚盘背面正中原条，B 去除上胚层后见脊索与中胚层向两侧迁移，C 横切示原沟细胞迁入形成中胚层和内胚层"}

原条的出现使胚盘有头、尾端之分，原条所在的一端为尾端。由于头端大、尾端小，此时的胚盘呈梨形。从原凹向头端增生迁移的细胞，在内、外胚层之间形成一条单独的中胚层细胞索，称脊索（notochord），它在早期胚胎起一定的支持和诱导作用（图 21-11，图 21-12）。在脊索的头侧和原条的尾侧，各有一个无中胚层的小区，此处内、外胚层相贴，呈薄膜状，分别称口咽膜（oropharyngeal membrane）和泄殖腔膜（cloacal membrane）。随着胚体发育，脊索向头端生长、延长，原条相对缩短，最终消失。若原条细胞残留，在未来人体骶尾部可增殖分化，形成由多种组织构成的畸胎瘤（teratoma）（图 21-13）。

:::definition{label="脊索"}
脊索（notochord）是从原凹向头端增生迁移的细胞在内、外胚层之间形成的一条单独中胚层细胞索。早期胚胎中起一定的支持和诱导作用。
:::

:::definition{label="口咽膜"}
口咽膜（oropharyngeal membrane）位于脊索头侧，是无中胚层的小区，内、外胚层相贴呈薄膜状。
:::

:::definition{label="泄殖腔膜"}
泄殖腔膜（cloacal membrane）位于原条尾侧，同样是无中胚层、内胚层与外胚层相贴的薄膜区。不要和口咽膜对调位置。
:::

:::definition{label="畸胎瘤（原条残留）"}
随着胚体发育，脊索向头端生长延长，原条相对缩短并最终消失。若原条细胞残留，可在未来人体骶尾部增殖分化，形成由多种组织构成的畸胎瘤（teratoma）。
:::

| 项目 | 二胚层胚盘 | 三胚层胚盘 |
|------|------------|------------|
| 时间 | 第 $2$ 周（植入过程中） | 第 $3$ 周末 |
| 组成 | 上胚层 + 下胚层 | 外胚层 + 中胚层 + 内胚层 |

| 邻结构 | 靠近脊索头端 | 靠近原条 |
:::

:::pitfall{label="三个胚层都来自上胚层，下胚层不是内胚层的原位改名"}
中胚层是上胚层细胞在两层之间新铺的夹层；内胚层是上胚层细胞进入下胚层、把原有细胞全部置换后的新层；外胚层只是原上胚层改了名字。写“上胚层变外胚层、下胚层变内胚层、中间长出中胚层”看起来整齐，却把置换这一步做丢。
:::

:::pitfall{label="原条在尾端，口咽膜在头、泄殖腔膜在尾"}
原条出现才有头尾：有原条的一端是尾端，头端较大故呈梨形。口咽膜在脊索头侧，泄殖腔膜在原条尾侧，都是没有中胚层的薄膜。把原条当成“头端的原基”，口咽膜和泄殖腔膜会对调，骶尾部畸胎瘤也会失去来源。
:::

:::insight{label="原条是上胚层细胞往下走的工地入口，用完必须拆掉"}
原沟、原凹让上胚层细胞迁出，去铺中胚层、换内胚层、向前筑脊索。脊索往头端延长时，原条相对缩短直至消失。入口若残留，骶尾部可以长出含多种组织的畸胎瘤——正因为迁出的细胞本就有多种分化潜能。
:::

:::timeline{period="第3周：从原条到三胚层"}
- **第 $3$ 周初** 上胚层细胞向一端中线迁移，形成原条；头端膨大为原结
- **原沟 / 原凹** 原条中线出现浅沟，原结中心出现浅凹
- **迁移** 原沟深部细胞在上、下胚层之间扩展：一部分铺成中胚层，一部分置换下胚层成为内胚层
- **改称** 原上胚层改称外胚层；$3$ 个胚层均来自上胚层
- **第 $3$ 周末** 三胚层胚盘形成；头大尾小呈梨形
- **脊索** 细胞从原凹向头端迁移，在内、外胚层之间成索；头侧为口咽膜，原条尾侧为泄殖腔膜
- **原条消退** 脊索向头端延长，原条缩短并消失；残留可在骶尾部形成畸胎瘤
:::

:::note{label="第16天和第18天两张图怎么对着看"}
图 21-11 是第 $16$ 天：背面能看见原条全长，横切强调细胞从原沟迁出铺中胚层。图 21-12 是第 $18$ 天：脊索已经明显向前，口咽膜和泄殖腔膜出现在头、尾两个无中胚层区。两天之间，原条相对变短、脊索变长。

:::keypoint{label="第2周二胚层，第3周原条出三胚层，三层都来自上胚层"}
- 胚盘是人体发生的原基：第 $2$ 周上胚层（柱状、邻滋养层）+ 下胚层（立方、邻胚泡腔）。
- 羊膜囊底 = 上胚层；卵黄囊顶 = 下胚层；两囊保护和营养胚盘。
- 胚外中胚层充填于细胞滋养层与两囊之间，内扩胚外体腔，残留体蒂（脐带主要成分）。
- 原条定尾端；原结、原沟、原凹是细胞迁出的入口。
- 迁出细胞：夹层 → 中胚层（与胚外中胚层在边缘衔接）；置换下胚层 → 内胚层；留下的上胚层 → 外胚层。
- 第 $3$ 周末三胚层胚盘呈梨形；脊索在内、外胚层之间起支持和诱导作用。
- 口咽膜在脊索头侧，泄殖腔膜在原条尾侧，皆无中胚层。
- 原条最终消失；残留于骶尾部可形成含多种组织的畸胎瘤。
:::

:::memory{label="本节必背要点"}
- [ ] 第 $2$ 周植入过程中，内细胞群增殖分化形成圆盘状胚盘（embryonic disc），由两个胚层组成，称二胚层胚盘。
- [ ] 上胚层（epiblast）：邻近滋养层的一层柱状细胞。
- [ ] 下胚层（hypoblast）：靠近胚泡腔侧的一层立方细胞。
- [ ] 两个胚层紧贴，中间隔以基膜；胚盘是人体发生的原基。
- [ ] 上胚层细胞增殖，其内出现充满液体的羊膜腔（amniotic cavity），腔内为羊水。
- [ ] 贴靠细胞滋养层的一层扁平上胚层细胞称成羊膜细胞，形成最早的羊膜。
- [ ] 成羊膜细胞与上胚层其余部分共同包裹羊膜腔，形成羊膜囊；上胚层构成羊膜囊的底。
- [ ] 下胚层周缘细胞向腹侧延伸，形成由单层扁平上皮围成的卵黄囊（yolk sac）；下胚层构成卵黄囊的顶。
- [ ] 羊膜囊和卵黄囊对胚盘起保护和营养作用。
- [ ] 胚外中胚层（extraembryonic mesoderm）：松散星状细胞和细胞外基质，充填于细胞滋养层与卵黄囊、羊膜囊之间。
- [ ] 胚外中胚层细胞间腔隙汇合增大，形成胚外体腔。
- [ ] 胚外中胚层分别附着于滋养层内面及卵黄囊、羊膜囊外面。
- [ ] 体蒂（body stalk）：胚外体腔扩大后仍连接胚盘（及羊膜囊、卵黄囊）与滋养层的少部分胚外中胚层，将发育为脐带的主要成分。
- [ ] 第 $3$ 周初，上胚层部分细胞增殖较快，向胚盘一端中线迁移，在中轴线聚集形成原条（primitive streak）。
- [ ] 原条头端略膨大为原结（primitive node）。
- [ ] 原条中线出现原沟（primitive groove），原结中心出现原凹（primitive pit）。
- [ ] 原沟深部细胞增殖，在上、下胚层之间向周边扩展迁移。
- [ ] 一部分细胞在上、下胚层之间形成夹层，称胚内中胚层，即中胚层（mesoderm），在胚盘边缘与胚外中胚层衔接。
- [ ] 另一部分细胞进入下胚层，逐渐全部置换下胚层细胞，形成内胚层（endoderm）。
- [ ] 内胚层和中胚层出现后，原上胚层改称外胚层（ectoderm）。
- [ ] 第 $3$ 周末三胚层胚盘形成，$3$ 个胚层均起源于上胚层。
- [ ] 原条所在一端为尾端；头端大、尾端小，胚盘呈梨形。
- [ ] 从原凹向头端迁移的细胞在内、外胚层之间形成脊索（notochord），起支持和诱导作用。
- [ ] 口咽膜（oropharyngeal membrane）：脊索头侧无中胚层小区，内、外胚层相贴成薄膜。
- [ ] 泄殖腔膜（cloacal membrane）：原条尾侧无中胚层小区，内、外胚层相贴成薄膜。
- [ ] 随着胚体发育，脊索向头端生长延长，原条相对缩短，最终消失。
- [ ] 原条细胞残留可在骶尾部增殖分化，形成由多种组织构成的畸胎瘤（teratoma）。
:::
