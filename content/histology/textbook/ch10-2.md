# 二、淋巴组织

淋巴组织（lymphoid tissue）以网状组织为支架，网孔内充满大量淋巴细胞及其他免疫细胞，是免疫应答的场所。淋巴组织分为弥散淋巴组织和淋巴小结两种。上一节把 T、B、NK 和 APC 立住以后，本节先问这片组织有没有明确界限、有没有生发中心；下一节再把胸腺、淋巴结、脾和扁桃体写成器官。

:::definition{label="淋巴组织"}
淋巴组织（lymphoid tissue）以网状组织为支架，网孔内充满大量淋巴细胞及其他免疫细胞，是免疫应答的场所。分为弥散淋巴组织和淋巴小结两种。
:::

:::concept{term="先问这片淋巴组织有没有界、有没有生发中心"}
看见一片淋巴细胞密集区，先问两件事：有没有明确球形边界；有没有生发中心。没有明确界限的是弥散淋巴组织，HEV 写在这里，是再循环从血液返回的入口。有球形边界、直径 $1\sim 2\,\mathrm{mm}$ 的是淋巴小结；无生发中心称初级，有生发中心称次级。把“淋巴组织”听成“就是淋巴小结”，副皮质、动脉周围淋巴鞘那些 T 区弥散账会整层失踪。
:::

## 1. 弥散淋巴组织

弥散淋巴组织（diffuse lymphoid tissue）无明确的界限，组织中除一般的毛细血管和毛细淋巴管外，还常见直径约 $30\sim 50\,\mu\mathrm{m}$ 的高内皮微静脉（high endothelial venule，HEV），即毛细血管后微静脉，其内皮细胞为柱状，能分泌黏附分子以利于淋巴细胞穿越，是淋巴细胞从血液进入淋巴组织的重要通道。抗原刺激可使弥散淋巴组织扩大，并出现淋巴小结。

:::definition{label="弥散淋巴组织"}
弥散淋巴组织（diffuse lymphoid tissue）无明确的界限。除一般毛细血管和毛细淋巴管外，常见高内皮微静脉。抗原刺激可使它扩大，并出现淋巴小结。
:::

:::definition{label="高内皮微静脉"}
高内皮微静脉（high endothelial venule，HEV）即毛细血管后微静脉，直径约 $30\sim 50\,\mu\mathrm{m}$，内皮细胞为柱状，能分泌黏附分子以利于淋巴细胞穿越，是淋巴细胞从血液进入淋巴组织的重要通道。
:::

:::note{label="HEV 是再循环的入口，不是输入淋巴管"}
上一节再循环的返回路径就落在弥散淋巴组织内的 HEV。输入淋巴管把淋巴送进淋巴结被膜下窦，走的是淋巴；HEV 把血液里的淋巴细胞送进组织，走的是血。下一节写明：淋巴结的 HEV 在副皮质区，约 $10\%$ 的淋巴细胞在此穿越；脾的动脉周围淋巴鞘无 HEV。看见柱状内皮的微静脉，先问是不是副皮质，不要写成小结中央的毛细血管。
:::

:::pitfall{label="HEV 内皮是柱状，不要按普通微静脉的扁平内皮来认"}
普通微静脉内皮扁平；HEV 是毛细血管后微静脉，直径 $30\sim 50\,\mu\mathrm{m}$，内皮柱状、能分泌黏附分子。把柱状内皮听成“上皮化生”或“切片斜切”，再循环入口就会从切片上消失。抗原刺激时扩大的是弥散淋巴组织本身，淋巴小结是在这片扩大的背景上长出来的，不是 HEV 变成了小结。
:::

:::compare{title="弥散淋巴组织中的三类管道"}
| 管道 | 管腔内容 | 与淋巴细胞的关系 |
|------|----------|------------------|
| 一般毛细血管 | 血液 | 营养交换，不是再循环专用入口 |
| 毛细淋巴管 | 淋巴 | 淋巴细胞可经淋巴管入血（再循环的出组织端） |
| 高内皮微静脉（HEV） | 血液 | 柱状内皮 + 黏附分子；淋巴细胞从血液进入淋巴组织的重要通道 |
:::

## 2. 淋巴小结

淋巴小结（lymphoid nodule）又称淋巴滤泡（lymphoid follicle），为直径 $1\sim 2\,\mathrm{mm}$ 的球形小体，界限较明确。淋巴小结受抗原刺激后增大，并产生生发中心（germinal center）。无生发中心的淋巴小结较小，称初级淋巴小结，有生发中心的称次级淋巴小结。

:::definition{label="淋巴小结"}
淋巴小结（lymphoid nodule）又称淋巴滤泡（lymphoid follicle），为直径 $1\sim 2\,\mathrm{mm}$ 的球形小体，界限较明确。是 B 细胞识别抗原后增殖分化的主要场所。
:::

:::definition{label="初级淋巴小结"}
初级淋巴小结无生发中心，体积较小，是尚未受抗原刺激、或抗原已被清除后的淋巴小结状态。
:::

:::definition{label="次级淋巴小结"}
次级淋巴小结有生发中心。受抗原刺激后淋巴小结增大并产生生发中心；发育一般在接触抗原后 2 周达高峰。
:::

:::definition{label="生发中心"}
生发中心（germinal center）是淋巴小结受抗原刺激后出现的结构，可分为深部的暗区（dark zone）和浅部的明区（light zone）。淋巴小结增大、增多是体液免疫应答的重要标志，抗原被清除后淋巴小结又逐渐消失。
:::

生发中心可分为深部的暗区（dark zone）和浅部的明区（light zone）。暗区较小，主要由 B 淋巴细胞和 Th 细胞组成，由于细胞较大，嗜碱性较强，故暗区着色深；明区较大，除 B 淋巴细胞和 Th 细胞外，还多见滤泡树突状细胞和巨噬细胞。生发中心的周边有一层密集的小淋巴细胞，着色较深、形似新月，尤以顶部最厚，称小结帽（cap）（图 10-2，图 10-3）。

:::definition{label="暗区"}
暗区（dark zone）位于生发中心深部，较小。主要由 B 淋巴细胞和 Th 细胞组成；细胞较大、嗜碱性较强，故着色深。由紧密聚集的生发中心母细胞构成。
:::

:::definition{label="明区"}
明区（light zone）位于生发中心浅部，较大。除 B 淋巴细胞和 Th 细胞外，还多见滤泡树突状细胞和巨噬细胞。由排列不紧密的生发中心细胞构成，其间夹杂较多滤泡树突状细胞。
:::

:::definition{label="小结帽"}
小结帽（cap）是生发中心周边一层密集的小淋巴细胞，着色较深、形似新月，尤以顶部最厚。由不发生分裂增殖的 B 淋巴细胞被推向外侧形成。脾小体的小结帽朝向红髓。
:::

:::concept{term="先问暗区、明区还是小结帽"}
次级淋巴小结不是一团均匀的深染球。从深部往浅部数：暗区细胞大、嗜碱性强、着色深，是生发中心母细胞在分裂；明区细胞较小、排列松，夹着滤泡树突状细胞和巨噬细胞；周边一层密集小淋巴细胞弯成新月，顶部最厚，叫小结帽。把“生发中心”听成整个小结，帽会丢；把暗区听成“坏死”，增殖账会写成病变。
:::

:::

生发中心的形成过程如下：初始 B 细胞或记忆 B 细胞识别抗原并与 Th 细胞相互作用后，迁移到初级淋巴小结并分裂增殖，成为大而幼稚的生发中心母细胞（centroblast），它们紧密聚集构成暗区。这些细胞继续增殖分化，生成体积较小的生发中心细胞（centrocyte），后者排列不紧密，其间夹杂较多的滤泡树突状细胞，构成明区。部分 B 淋巴细胞经过不断分化发育，形成体积较小的幼浆细胞及记忆 B 细胞。幼浆细胞将迁移至附近的弥散淋巴组织，或进入淋巴后迁移至机体其他部位的淋巴组织或结缔组织，转化为浆细胞，分泌抗体。不发生分裂增殖的 B 淋巴细胞被推向外侧，形成小结帽。

:::definition{label="生发中心母细胞"}
生发中心母细胞（centroblast）是初始 B 细胞或记忆 B 细胞识别抗原并与 Th 相互作用后，迁入初级淋巴小结分裂增殖而成的大而幼稚的细胞。紧密聚集构成暗区。
:::

:::definition{label="生发中心细胞"}
生发中心细胞（centrocyte）由生发中心母细胞继续增殖分化而来，体积较小，排列不紧密，其间夹杂较多滤泡树突状细胞，构成明区。
:::

:::definition{label="幼浆细胞"}
幼浆细胞是部分 B 淋巴细胞不断分化发育形成的体积较小的细胞，将迁移至附近的弥散淋巴组织，或进入淋巴后迁移至其他部位的淋巴组织或结缔组织，转化为浆细胞，分泌抗体。脾小体产生的幼浆细胞多进入红髓的脾索。
:::

次级淋巴小结的发育一般在接触抗原后 2 周达高峰。淋巴小结增大、增多是体液免疫应答的重要标志，抗原被清除后淋巴小结又逐渐消失。

:::cause-effect{title="抗原怎样把初级淋巴小结写成次级淋巴小结"}
- 因：初始 B 细胞或记忆 B 细胞识别抗原并与 Th 相互作用，迁入初级淋巴小结分裂增殖
- 果：生发中心母细胞聚成暗区，再分化为生发中心细胞构成明区；幼浆细胞迁出分泌抗体，不分裂者被推向外侧成小结帽
- 影响：接触抗原后 2 周达高峰，淋巴小结增大、增多成为体液免疫应答的重要标志；抗原清除后小结又逐渐消失
:::

:::insight{label="生发中心是体液免疫的工厂，幼浆细胞必须迁出去上班"}
暗区负责把 B 细胞做大、做幼稚、做分裂；明区夹着滤泡树突状细胞做选择；帽是没进增殖周期的小淋巴细胞被挤到外侧。真正分泌抗体的浆细胞不堆在小结中央：幼浆细胞要迁到附近弥散淋巴组织，或随淋巴去别的淋巴组织和结缔组织。把“生发中心”听成“浆细胞堆”，髓索和脾索里那堆浆细胞就变成无来源的细胞。
:::

滤泡树突状细胞（follicular dendritic cell，FDC）与一般的树突状细胞在来源和功能上有很大差别。FDC 虽然也有很多树枝状突起，但它们并非源于骨髓细胞，也不表达 MHC-Ⅱ类分子，其细胞表面有丰富的抗体受体，可与抗原结合成抗原-抗体复合物。

:::definition{label="滤泡树突状细胞"}
滤泡树突状细胞（follicular dendritic cell，FDC）有很多树枝状突起，但并非源于骨髓细胞，也不表达 MHC-Ⅱ类分子。细胞表面有丰富的抗体受体，可与抗原结合成抗原-抗体复合物。主要见于生发中心明区。
:::

:::compare{title="一般树突状细胞与滤泡树突状细胞"}
| 项目 | 一般树突状细胞（DC） | 滤泡树突状细胞（FDC） |
|------|----------------------|------------------------|
| 英文 | dendritic cell | follicular dendritic cell |
| 来源 | 骨髓造血干细胞 | 并非源于骨髓细胞 |
| MHC-Ⅱ | 表达，用以呈递抗原肽给 T 细胞 | 不表达 MHC-Ⅱ类分子 |
| 突起 | 很多树枝状突起 | 也有很多树枝状突起（形态相似） |
| 关键分子 | 抗原肽-MHC 复合物 | 表面丰富的抗体受体，结合抗原-抗体复合物 |
| 功能 | 专职 APC，激发 T 细胞活化、增殖 | 在生发中心（尤其明区）滞留抗原-抗体复合物，供 B 细胞选择 |
| 部位别名 | 朗格汉斯细胞、面纱细胞、交错突细胞等 | 不沿那条 DC 迁移链改名 |
:::

:::pitfall{label="FDC 不是骨髓来源的 DC，不要当成专职 APC"}
上一节专职 APC 的 DC 表达 MHC-Ⅱ，把抗原肽呈递给 T 细胞。FDC 名字里也有“树突状”，突起也多，但来源不是骨髓，也不表达 MHC-Ⅱ，表面挂的是抗体受体。把 FDC 写进专职 APC 名单，会把“呈递给 T 细胞”和“把抗原-抗体复合物摆给 B 细胞看”两本账合成一句。光镜下明区里那些突起细胞，先问有没有 MHC-Ⅱ这条身份证。
:::

:::keypoint{label="淋巴组织先分有界无界，次级小结再分暗区、明区和帽"}
- 淋巴组织 = 网状支架 + 淋巴细胞等免疫细胞，是免疫应答场所。
- 弥散淋巴组织无明确界限，HEV（$30\sim 50\,\mu\mathrm{m}$，柱状内皮，分泌黏附分子）是从血液进入淋巴组织的通道。
- 淋巴小结直径 $1\sim 2\,\mathrm{mm}$，界限较明确；无生发中心为初级，有生发中心为次级。
- 暗区深、小、深染（母细胞）；明区浅、大（中心细胞 + FDC + 巨噬细胞）；帽在周边，顶部最厚。
- 接触抗原后 2 周达高峰；小结增大、增多 = 体液免疫标志；抗原清除后消失。
- FDC ≠ DC：不源于骨髓，不表达 MHC-Ⅱ，表面为抗体受体。
:::

- [ ] 生发中心周边有一层密集的小淋巴细胞，着色较深、形似新月，尤以顶部最厚，称小结帽（cap）。
- [ ] 初始 B 细胞或记忆 B 细胞识别抗原并与 Th 相互作用后，迁到初级淋巴小结并分裂增殖，成为大而幼稚的生发中心母细胞（centroblast）。
- [ ] 生发中心母细胞紧密聚集构成暗区。
- [ ] 母细胞继续增殖分化，生成体积较小的生发中心细胞（centrocyte），排列不紧密，夹杂较多 FDC，构成明区。
- [ ] 部分 B 细胞分化为体积较小的幼浆细胞及记忆 B 细胞。
- [ ] 幼浆细胞迁移至附近弥散淋巴组织，或进入淋巴后迁至其他部位的淋巴组织或结缔组织，转化为浆细胞，分泌抗体。
- [ ] 不发生分裂增殖的 B 淋巴细胞被推向外侧，形成小结帽。
- [ ] 次级淋巴小结的发育一般在接触抗原后 2 周达高峰。
- [ ] 淋巴小结增大、增多是体液免疫应答的重要标志；抗原被清除后淋巴小结又逐渐消失。
- [ ] 滤泡树突状细胞（FDC）与一般 DC 在来源和功能上有很大差别。
- [ ] FDC 虽有很多树枝状突起，但并非源于骨髓细胞，也不表达 MHC-Ⅱ类分子。
- [ ] FDC 细胞表面有丰富的抗体受体，可与抗原结合成抗原-抗体复合物。
