# 三、膀胱

膀胱为重要的排尿器官，其组织结构与输尿管基本相似，分为 3 层，即黏膜、肌层和外膜。黏膜形成许多皱襞，仅膀胱三角处的黏膜平滑。膀胱充盈时，皱襞减少或消失。膀胱空虚时变移上皮很厚，约 $8\sim 10$ 层细胞，表层盖细胞大，呈矩形；膀胱充盈时上皮变薄，仅 $3\sim 4$ 层细胞，盖细胞也变扁（见图 2-7，图 17-17）。电镜下，盖细胞游离面细胞膜有内褶和囊泡，膀胱充盈时内褶可展开拉平；细胞近游离面的细胞质较为浓密，可防止膀胱内尿液的侵蚀；细胞间有极为发达的紧密连接，防止高度浓缩的尿液中各种离子进入组织，以及组织内的水进入尿液。固有层含较多弹性纤维。肌层厚，由内纵行、中环行和外纵行 3 层平滑肌组成，各层肌纤维相互交错，分界不清。中层环行肌在尿道内口处增厚为括约肌。外膜除膀胱顶部为浆膜外，多为疏松结缔组织。

:::definition{label="膀胱"}
膀胱是重要的排尿器官。组织结构与输尿管基本相似，分为黏膜、肌层和外膜 3 层。负责贮存终尿并在适当时机排出，不参与原尿生成。
:::

:::concept{term="先问空虚还是充盈，再数变移上皮的层数和盖细胞的形状"}
看见膀胱，先问黏膜皱襞还在不在、上皮是 $8\sim 10$ 层还是 $3\sim 4$ 层、盖细胞是矩形还是变扁。空虚：皱襞多，上皮厚，盖细胞大而呈矩形；充盈：皱襞减少或消失，上皮变薄，盖细胞变扁。膀胱三角处黏膜始终平滑。把变移上皮听成“固定的复层扁平”，盖细胞的内褶、浓密胞质和紧密连接都会从防尿液侵蚀那本账上掉下去。
:::

:::definition{label="膀胱黏膜皱襞"}
黏膜形成许多皱襞，仅膀胱三角处的黏膜平滑。膀胱充盈时，皱襞减少或消失。
:::

:::definition{label="膀胱三角"}
膀胱三角处的黏膜平滑，不形成像其余黏膜那样的皱襞。这是辨认膀胱黏膜分区的形态标志。
:::

:::definition{label="膀胱变移上皮"}
空虚时很厚，约 $8\sim 10$ 层细胞，表层盖细胞大、呈矩形；充盈时变薄，仅 $3\sim 4$ 层细胞，盖细胞也变扁。层数随功能状态改变，不是复层扁平。
:::

:::definition{label="盖细胞"}
变移上皮表层的盖细胞。空虚时大、呈矩形；充盈时变扁。电镜下游离面细胞膜有内褶和囊泡，充盈时内褶可展开拉平；近游离面胞质较为浓密，防止尿液侵蚀；细胞间有极为发达的紧密连接，防止浓缩尿液中的离子进入组织，以及组织内的水进入尿液。
:::

:::definition{label="膀胱固有层"}
固有层含较多弹性纤维，配合皱襞和变移上皮，适应充盈与排空时的容积变化。
:::

:::definition{label="膀胱肌层"}
肌层厚，由内纵行、中环行和外纵行 3 层平滑肌组成，各层肌纤维相互交错，分界不清。中层环行肌在尿道内口处增厚为括约肌。
:::

:::definition{label="尿道内口括约肌"}
膀胱中层环行肌在尿道内口处增厚形成括约肌，控制尿液进入尿道。
:::

:::definition{label="膀胱外膜"}
外膜除膀胱顶部为浆膜外，多为疏松结缔组织。
:::

| 项目 | 空虚 | 充盈 |
|------|------|------|
| 皱襞 | 许多皱襞（膀胱三角除外，始终平滑） | 皱襞减少或消失 |

| 盖细胞 | 大，呈矩形 | 变扁 |

:::

:::compare{title="输尿管与膀胱"}
| 项目 | 输尿管 | 膀胱 |
|------|--------|------|
| 职分 | 输送终尿 | 贮存并排出终尿 |

:::

:::pitfall{label="膀胱变移上皮不是复层扁平，空虚与充盈的层数也不要写成输尿管那一套"}
输尿管是 $4\sim 5$ 层、扩张 $2\sim 3$ 层；膀胱空虚约 $8\sim 10$ 层、充盈仅 $3\sim 4$ 层，表层还有盖细胞。复层扁平既没有盖细胞的内褶和浓密顶端胞质，也不会随充盈把层数减到一半以下。把膀胱上皮写成复层扁平或直接套输尿管层数，防尿液侵蚀和紧密连接那两本账都会写丢。
:::

:::pitfall{label="外膜只有顶部是浆膜，不要写成膀胱全程浆膜"}
教材明确：外膜除膀胱顶部为浆膜外，多为疏松结缔组织。把全程写成浆膜，腹膜覆盖范围会和大体解剖打架。
:::

:::insight{label="盖细胞用内褶、浓密胞质和紧密连接三件套对抗浓缩尿"}
充盈时细胞膜内褶展开，面积够用；近游离面浓密胞质挡住尿液侵蚀；发达紧密连接既不让尿中离子钻进组织，也不让组织里的水被高渗尿吸走。变移上皮不是“能变的复层扁平”，而是排尿器官特化的屏障上皮。第 2 章图 2-7 已把空虚与充盈两态并排画出，本节用膀胱壁三层把它接回器官。
:::

:::note{label="膀胱三角为什么平滑"}
其余黏膜靠皱襞储备表面积，充盈时展平。膀胱三角处黏膜平滑，是输尿管口与尿道内口之间的固定区，不以皱襞作为扩张余量。辨认切片或大体时，三角平滑、其余起皱，不要当成固定伪影。
:::

:::keypoint{label="膀胱三层壁，变移上皮按空虚充盈两套层数记，盖细胞是防尿屏障"}
- 与输尿管同为黏膜、肌层、外膜 3 层。
- 皱襞多，仅膀胱三角平滑；充盈时皱襞减少或消失。
- 空虚：$8\sim 10$ 层，盖细胞大而呈矩形；充盈：$3\sim 4$ 层，盖细胞变扁。
- 盖细胞：游离面内褶与囊泡、近游离面浓密胞质、发达紧密连接。
- 固有层弹性纤维多；肌层内纵中环外纵，交错分界不清；尿道内口中环肌成括约肌。
- 外膜顶部浆膜，其余疏松结缔组织。
:::

## 本章小结

泌尿系统包括肾和排尿器官，它的主要功能是形成和排出尿液，维持机体的水和电解质平衡。肾产生尿液，表面有致密结缔组织被膜，实质分为皮质和髓质。髓质由十几个肾锥体组成，锥体尖端称肾乳头，突入肾小盏。肾实质由大量肾单位和集合管构成。肾单位包括肾小体和与它相连的肾小管，是尿液形成的结构和功能单位。肾小体由血管球和肾小囊构成，微动脉出入的一端称血管极，对侧与近曲小管相连的一端称尿极。血管球是一团盘曲的毛细血管，由入球微动脉分支形成的网状毛细血管袢构成，毛细血管汇成出球微动脉。肾小囊是肾小管起始端膨大凹陷形成的杯状双层上皮囊，两层上皮之间为肾小囊腔。外层（壁层）为单层扁平上皮，内层（脏层）细胞称足细胞。足细胞胞体伸出大的初级突起，从初级突起上再分出许多指状的次级突起，相邻初级突起发出的次级突起互相嵌合成栅栏状，紧贴在毛细血管基膜外面。突起之间的裂隙称裂孔，上有裂孔膜。进入肾小囊腔的滤液称原尿。肾小管是单层上皮性小管，由近端小管、细段、远端小管构成。肾小体的功能依赖对肾血流的滤过，生成原尿，并通过肾小管和集合管对原尿的选择性重吸收及分泌，形成终尿。球旁复合体位于肾小体血管极，由球旁细胞、致密斑和球外系膜细胞组成，能够影响肾小体血管球的滤过率和肾小管的重吸收，并调节肾的排泄功能。排尿器官包括输尿管、膀胱和尿道，是尿液排出的通道。

:::definition{label="本章结构通式"}
泌尿系统 = 肾（产尿）+ 输尿管、膀胱、尿道（排尿）。肾单位 = 肾小体 + 肾小管；滤过屏障 = 有孔内皮 + 基膜 + 足细胞裂孔膜。近曲重吸收主战场，远曲和集合管听激素微调。球旁复合体在血管极管肾素和 $\mathrm{Na}^{+}$ 感受。排尿管道衬变移上皮，不是复层扁平。
:::

:::compare{title="全章结构与细胞速查"}
| 结构 | 关键形态 | 职分 |
|------|----------|------|
| 皮质迷路 / 肾柱 | 肾小体、近曲、远曲、弓形集合管 | 弯曲部所在 |
| 髓放线 / 肾锥体 | 近直、细段、远直、直集合管 | 直行部与浓缩 |
| 浅表肾单位 | 约 $85\%$，髓袢短 | 尿液形成 |
| 髓旁肾单位 | 约 $15\%$，髓袢长 | 尿液浓缩 |
| 血管球 | 入球粗、出球细，有孔无隔膜 | 滤过 |
| 足细胞 | 初级 / 次级突起，裂孔膜 | 滤过屏障最外层 |

| 远曲小管 | 无刷状缘，腔规则 | 离子交换，受醛固酮、抗利尿激素调节 |
| 球旁细胞 | 入球壁上皮样细胞，颗粒含肾素 | 启动肾素–血管紧张素系统 |

:::

:::keypoint{label="全章把滤过三层对重吸收各段、球旁三角形对排尿变移上皮收口"}
- 肾单位产原尿，小管和集合管改造成终尿；集合管不是肾单位。
- 滤过屏障是三层，不是一层内皮；正电荷、小分子才容易过。
- 近曲有刷状缘，远曲没有；致密斑在远曲起始，不在近曲。
- 入球粗、出球细；两次毛细血管网；直小血管伴髓袢。
- 输尿管和膀胱都是变移上皮，不要写成复层扁平；层数按空虚 / 扩张两套记。
:::

## 插入框：卡介苗治疗膀胱癌的作用机制

膀胱癌是泌尿生殖系统中发病率最高的肿瘤，主要分为非肌层浸润性膀胱癌及肌层浸润性膀胱癌。其中非肌层浸润性膀胱癌患者占总数的 $70\%$，主要治疗方式为经尿道膀胱肿瘤切除术辅助卡介苗（bacillus Calmette-guérin，BCG）灌注治疗，主要作用机制如下：

**1. 卡介苗的附着与内化** BCG 膀胱内灌注后接触并靠近膀胱癌细胞和正常的尿路上皮细胞，黏附在细胞表面后通过结核分枝杆菌细胞壁表面的纤连蛋白附着蛋白与细胞膜上的纤连蛋白或整合素 $\alpha5\beta1$ 结合，进而促使细胞内化 BCG。

**2. 卡介苗激活免疫系统** 进行 BCG 灌注治疗的患者尿液中的白细胞数量显著增加，主要由粒细胞、巨噬细胞和淋巴细胞组成，并在膀胱黏膜中出现大量免疫细胞浸润，包括 CTL 细胞和 BCG 特异 NK 细胞的增加，以上均证明 BCG 灌注治疗可以激活患者局部黏膜免疫的发生。

**3. 卡介苗引发大量细胞因子参与免疫调节** 在对卡介苗治疗后患者尿液进行检测分析，发现其含有大量细胞因子，包括 IL-1、IL-2、IL-5、IL-6、IL-8、IL-10、IL-12、IL-18、TNF、IFN-$\gamma$ 和粒细胞–巨噬细胞集落刺激因子，以及巨噬细胞来源趋化因子、单核细胞趋化蛋白和干扰素诱导蛋白-10 等。

**4. BCG 的直接作用** 暴露于卡介苗的膀胱癌细胞可导致细胞增殖下降和周期阻滞，且 BCG 内化通过激活 toll 样受体 7 后，激活 caspase 8 信号通路，从而引起肿瘤细胞外源性凋亡的起始。BCG 还可诱导细胞内氧化应激反应，促使诱导型一氧化氮合酶产生一氧化氮，高浓度一氧化氮对尿路上皮癌细胞产生细胞毒作用导致癌细胞死亡。

:::definition{label="膀胱癌的分型与BCG适应"}
膀胱癌是泌尿生殖系统中发病率最高的肿瘤，主要分为非肌层浸润性膀胱癌及肌层浸润性膀胱癌。非肌层浸润性膀胱癌患者占总数的 $70\%$，主要治疗方式为经尿道膀胱肿瘤切除术辅助卡介苗（bacillus Calmette-guérin，BCG）灌注治疗。
:::

:::definition{label="BCG附着与内化"}
BCG 灌注后黏附于膀胱癌细胞和正常尿路上皮细胞表面，通过结核分枝杆菌细胞壁表面的纤连蛋白附着蛋白与细胞膜上的纤连蛋白或整合素 $\alpha5\beta1$ 结合，促使细胞内化 BCG。
:::

:::definition{label="BCG激活局部黏膜免疫"}
BCG 灌注后患者尿液中白细胞显著增加，主要由粒细胞、巨噬细胞和淋巴细胞组成；膀胱黏膜出现大量免疫细胞浸润，包括 CTL 细胞和 BCG 特异 NK 细胞增加，表明局部黏膜免疫被激活。
:::

:::definition{label="BCG相关细胞因子"}
治疗后尿液中含大量细胞因子：IL-1、IL-2、IL-5、IL-6、IL-8、IL-10、IL-12、IL-18、TNF、IFN-$\gamma$、粒细胞–巨噬细胞集落刺激因子，以及巨噬细胞来源趋化因子、单核细胞趋化蛋白和干扰素诱导蛋白-10 等。
:::

:::definition{label="BCG对肿瘤细胞的直接作用"}
BCG 使膀胱癌细胞增殖下降、周期阻滞；内化后激活 toll 样受体 7，再激活 caspase 8 信号通路，启动外源性凋亡。还可诱导氧化应激，促使诱导型一氧化氮合酶产生一氧化氮，高浓度一氧化氮对尿路上皮癌细胞产生细胞毒作用。
:::

:::note{label="BCG灌注四条机制"}
| 步骤 | 要点 |
|------|------|
| 附着与内化 | 纤连蛋白附着蛋白结合纤连蛋白或整合素 $\alpha5\beta1$ |
| 激活免疫 | 尿中白细胞↑；黏膜浸润 CTL、BCG 特异 NK |
| 细胞因子 | IL-1、2、5、6、8、10、12、18，TNF，IFN-$\gamma$，GM-CSF 等 |
| 直接杀伤 | TLR7 → caspase 8 → 外源性凋亡；iNOS → NO 细胞毒 |
:::

:::insight{label="插入框把灌注治疗接回膀胱变移上皮这本屏障账"}
BCG 要先贴上并进入尿路上皮（变移上皮）和癌细胞，才谈得上黏膜局部免疫。盖细胞的紧密连接本是防尿液的墙，灌注却利用上皮表面的纤连蛋白 / 整合素把菌苗送进去。把这则插入框只听成“一条外科治疗后的附加疗法”，膀胱黏膜和变移上皮会和免疫机制脱节。
:::

:::pitfall{label="BCG灌注主要用于非肌层浸润性膀胱癌，不要写成所有膀胱癌的首选"}
非肌层浸润性占 $70\%$，这才是经尿道切除加 BCG 灌注的主要对象。肌层浸润性膀胱癌不在这本灌注账的第一行。分型先问侵没侵到肌层，再问要不要灌注。
:::
