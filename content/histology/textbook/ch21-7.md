# 七、双胎、多胎和连体双胎

一次妊娠可以生出一个胎儿，也可以生出两个或多个。双胎约占新生儿的 $1\%$，分双卵和单卵两本账；单卵双胎又按分开的早晚分成三种羊膜腔和胎盘组合。两个原条靠得太近，还会变成连体双胎。本节把双卵双胎、单卵双胎三种成因、多胎和连体双胎摊开，并收回本章从受精到胎盘的总账。体外受精-胚胎移植作为插入阅读放在节末。

:::definition{label="双胎"}
双胎（twins）又称孪生，发生率约占新生儿的 $1\%$。按来源分为双卵双胎和单卵双胎。
:::

:::concept{term="先问来自一个受精卵还是两个，再问分开发生在胚泡、内细胞群还是原条"}
看见双胎，先问卵的本数：两个受精卵是双卵双胎，各有胎膜和胎盘，性别可同可异，像普通兄弟姐妹。一个受精卵劈成两个是单卵双胎，基因相同、性别一致。单卵再问分开的时间：两个胚泡分别植入，各有羊膜腔和胎盘；一个胚泡里两个内细胞群，各有羊膜腔、共享一个胎盘；一个胚盘上两条原条，同一羊膜腔、共享一个胎盘——这一档若原条靠得近，就会连体。把“同卵”听成“一定共用一个羊膜”，三种成因会对成一种。
:::

## 1. 双胎

双胎有两种。一种是双卵双胎（dizygotic twins），即双胎来自两个受精卵，它们有各自的胎膜与胎盘，性别相同或不同，相貌和生理特性的差异如同一般兄弟姐妹，仅是同龄而已。另一种是单卵双胎（monozygotic twins），即一个受精卵发育为两个胚胎，这种双胎儿的遗传基因完全一样，因此性别一致，相貌、体态和生理特征等也极相似。单卵双胎的成因可以是：①从受精卵发育出两个胚泡，它们分别植入，两个胎儿有各自的羊膜腔和胎盘；②一个胚泡内出现两个内细胞群，各发育为一个胚胎，位于各自的羊膜腔内，但共享一个胎盘；③一个胚盘上出现两个原条与脊索，形成两个神经管，发育为两个胚胎，双胎儿位于同一个羊膜腔内，也共享一个胎盘（图 21-31）。

:::definition{label="双卵双胎"}
双卵双胎（dizygotic twins）来自两个受精卵。各有自己的胎膜与胎盘；性别可相同或不同；相貌和生理特性的差异如同一般兄弟姐妹，只是同龄。
:::

:::definition{label="单卵双胎"}
单卵双胎（monozygotic twins）由一个受精卵发育为两个胚胎。遗传基因完全一样，性别一致，相貌、体态和生理特征极相似。
:::

:::definition{label="单卵双胎成因一：两个胚泡"}
从受精卵发育出两个胚泡，分别植入。两个胎儿有各自的羊膜腔和胎盘。分开最早，附属结构也最独立。
:::

:::definition{label="单卵双胎成因二：两个内细胞群"}
一个胚泡内出现两个内细胞群，各发育为一个胚胎。二者位于各自的羊膜腔内，但共享一个胎盘。
:::

:::definition{label="单卵双胎成因三：两个原条"}
一个胚盘上出现两个原条与脊索，形成两个神经管，发育为两个胚胎。双胎儿位于同一个羊膜腔内，也共享一个胎盘。两个原条若靠得较近，胚体形成时局部连接，即导致连体双胎。
:::

::figure{src="/images/histology/textbook/p0242_01.png" caption="图21-31 单卵双胎形成示意图。左列：两个胚泡分别植入，各有羊膜腔和胎盘；中列：一个胚泡内两个内细胞群，各有羊膜腔，共享一个胎盘；右列：一个胚盘上两个原条，同一羊膜腔，共享一个胎盘。" alt="三列模式：从受精卵分出两个胚泡、或一个胚泡两个内细胞群、或一个胚盘两个胚胎，下方对应双胎盘或单胎盘的妊娠子宫"}

:::compare{title="双卵双胎与单卵双胎"}
| 项目 | 双卵双胎 | 单卵双胎 |
|------|----------|----------|
| 英文 | dizygotic twins | monozygotic twins |
| 来源 | 两个受精卵 | 一个受精卵发育为两个胚胎 |
| 基因 / 性别 | 如同普通兄弟姐妹；性别可同可异 | 基因完全一样；性别一致 |
| 相貌与生理 | 有一般兄弟姐妹那样的差异，仅同龄 | 相貌、体态和生理特征极相似 |
| 胎膜与胎盘 | 各自的胎膜与胎盘 | 随分开早晚而不同（见下表） |
:::

:::compare{title="单卵双胎的三种成因"}
| 项目 | 两个胚泡分别植入 | 一个胚泡内两个内细胞群 | 一个胚盘上两个原条与脊索 |
|------|-------------------|-------------------------|---------------------------|
| 分开发生在 | 最早（胚泡阶段） | 内细胞群阶段 | 原条 / 神经管阶段 |
| 羊膜腔 | 各自一个 | 各自一个 | 同一个 |
| 胎盘 | 各自一个 | 共享一个 | 共享一个 |
| 神经管 | 各有各的 | 各有各的 | 一个胚盘上形成两个神经管 |
| 连体风险 | 无（已经是两个胚泡） | 无（两个内细胞群仍分开发育） | 两原条靠得近则可局部连接，成连体双胎 |
:::

:::pitfall{label="单卵双胎不一定共用羊膜，也不一定共用胎盘"}
只有“一个胚盘、两个原条”才共用一个羊膜腔并且共享胎盘。两个胚泡分别植入时，羊膜腔和胎盘都是各自的，看起来会像双卵双胎的附属结构，但基因和性别仍完全一致。把“单卵”写成“一定共羊膜共胎盘”，三种成因会并成一种。
:::

:::insight{label="分开越晚，共用的附属结构越多，连体只发生在最晚那一档"}
两个胚泡：膜和盘都分开。两个内细胞群：羊膜分开、胎盘共用。两个原条：羊膜和胎盘都共用；再近一步，胚体都分不开，就是连体。时间轴比“看像不像”更管用。
:::

## 2. 多胎

多胎（multiplets）指一次娩出两个以上新生儿。其原因可以是单卵性、多卵性或混合性，以混合性为多。多胎发生率极低，但近年随着临床应用促性腺激素治疗不孕症，以及体外受精-胚胎移植技术的应用，其发生率有所增高。

:::definition{label="多胎"}
多胎（multiplets）是一次娩出两个以上新生儿。原因可以是单卵性、多卵性或混合性，以混合性为多。
:::

:::note{label="多胎为什么近年多见了"}
自然发生率极低。促性腺激素治疗不孕症，以及体外受精-胚胎移植，使一次排出或移植多个胚的机会增加，多胎发生率随之增高。
:::

## 3. 连体双胎

连体双胎（conjoined twins）是指两个未完全分离的单卵双胎。当一个胚盘出现两个原条并分别发育为两个胚胎时，若两原条靠得较近，胚体形成时发生局部连接，则导致连体双胎。连体双胎有对称型和不对称型两类（图 21-32），对称型指两个胚胎大小相同，根据连接的部位可分为头连双胎、臀连双胎、胸连双胎、腹连双胎等；不对称型指两个胚胎一大一小，小者常发育不全，形成寄生胎；如果小而发育不全的胚胎被包裹在大的胎体内则称胎中胎。

:::definition{label="连体双胎"}
连体双胎（conjoined twins）是两个未完全分离的单卵双胎。发生在一个胚盘出现两个原条、且两原条靠得较近、胚体形成时局部连接之时。
:::

:::definition{label="对称型连体双胎"}
两个胚胎大小相同。按连接部位分为头连双胎、臀连双胎、胸连双胎、腹连双胎等。
:::

:::definition{label="不对称型连体双胎"}
两个胚胎一大一小，小者常发育不全，形成寄生胎。若小而发育不全的胚胎被包裹在大的胎体内，称胎中胎。
:::

:::definition{label="寄生胎与胎中胎"}
寄生胎是不对称型中发育不全的那个小胚胎，附于大者体外。胎中胎是这个小胚胎被包裹在大的胎体之内。二者都来自未完全分离的单卵双胎，不是双卵妊娠的一胎“吃掉”另一胎。
:::

::figure{src="/images/histology/textbook/p0242_02.png" caption="图21-32 头胸连双胎和寄生胎。示未完全分离的单卵双胎：连接可发生在头胸部，或一大一小形成寄生胎。" alt="标本正背面：较大胎儿胸腹部附着另一个较小、发育不全的胎体"}

:::compare{title="对称型与不对称型连体双胎"}
| 项目 | 对称型 | 不对称型 |
|------|--------|----------|
| 两个胚胎的大小 | 相同 | 一大一小 |
| 连接 | 头连、臀连、胸连、腹连等 | 小者发育不全，附于大者（寄生胎） |
| 特殊类型 | 按连接部位命名 | 小者被包裹在大的胎体内 → 胎中胎 |
| 前提 | 都是一个胚盘上两个靠得较近的原条，胚体局部未分开 | 同左 |
:::

:::cause-effect{title="两个原条怎样从单卵双胎滑向连体"}
- 因：一个胚盘上出现两个原条与脊索
- 果：本可形成共用一个羊膜腔、共享一个胎盘的单卵双胎
- 因：两原条靠得较近，胚体形成时局部连接
- 果：连体双胎（对称或不对称）
- 制约：两个胚泡或两个内细胞群的单卵双胎不会走这条路，因为胚盘已经分开
:::

:::pitfall{label="连体双胎是单卵未完全分开，不是双卵在子宫里粘在一起"}
双卵双胎各有胎膜与胎盘，胚体不会因为并排妊娠而连成一个。连体只发生在“一个胚盘、两个原条、靠得太近”。寄生胎和胎中胎也是这本账，不要写成肿瘤或“怀孕时又怀了一个”。
:::

:::timeline{period="单卵双胎分开越晚，共用结构越多"}
- **两个胚泡** 分别植入 → 各有羊膜腔和胎盘
- **两个内细胞群** 同一胚泡 → 各有羊膜腔，共享一个胎盘
- **两个原条** 同一胚盘 → 同一羊膜腔，共享一个胎盘
- **两原条过近** 胚体局部连接 → 连体双胎（对称：头/臀/胸/腹连；不对称：寄生胎、胎中胎）
:::

:::keypoint{label="双卵各过各的；单卵看分开早晚；连体只出在两个原条靠得近"}
- 双胎约占新生儿 $1\%$。双卵：两个受精卵，各有胎膜胎盘，性别可异。单卵：一个受精卵，基因和性别相同。
- 单卵三种成因：两个胚泡（分羊膜分胎盘）；两个内细胞群（分羊膜共胎盘）；两个原条（共羊膜共胎盘）。
- 多胎可为单卵性、多卵性或混合性，以混合性为多；促性腺激素和 IVF 使发生率升高。
- 连体双胎 = 未完全分离的单卵双胎；对称按连接部位命名，不对称为寄生胎，包在体内为胎中胎。
:::

## 本章小结

获能的精子与卵子相遇，释放顶体酶，破坏放射冠、溶蚀透明带，精子细胞核进入卵子内。精子和卵子的细胞核先膨大、后融合，受精卵形成，即为受精。受精卵在透明带内不断进行有丝分裂，即卵裂。当细胞数达到 $100$ 个左右时，细胞间出现腔隙，此时透明带消失，细胞团呈泡状结构，称胚泡。一部分细胞围成胚泡壁，称滋养层；另一部分细胞位于胚泡腔的一侧，称内细胞群，此处的滋养层称极端滋养层。此时胚泡到达子宫，黏附并植入于子宫的体部和底部，最多见于后壁的内膜。

第 $2$ 周时，内细胞群分化为由上胚层、下胚层组成的两层盘状结构，称胚盘，其上有羊膜腔，下有卵黄囊；滋养层也分化为内侧的细胞滋养层和外侧的合体滋养层。第 $3$ 周时，上胚层部分细胞增殖较快，并向胚盘一端中线迁移，在中轴线上聚集形成一条纵行的细胞柱，称原条。随着原条细胞的增殖和迁移，一部分细胞在上、下胚层之间新形成了一层中胚层，另一部分细胞取代下胚层形成内胚层，上胚层改名为外胚层，三胚层胚盘出现。胚盘是人体发生的原基。

外胚层分化为皮肤的表皮及附属器、神经系统等；中胚层分化为心血管系统、泌尿生殖系统、肌组织和各种结缔组织等；内胚层分化为消化系统、呼吸系统、部分泌尿器官的上皮组织。伴随三胚层的分化，胚盘边缘向腹侧卷折形成头褶、尾褶和左右侧褶，扁平形胚盘逐渐变为圆柱形的胚体。至第 $8$ 周末，胚体外表已可见眼、耳、鼻及四肢，初具人形。

胎膜和胎盘是对胚胎起保护、营养、呼吸、排泄等作用的附属结构，不参与胚胎本体的形成。胎膜包括绒毛膜、羊膜、卵黄囊、尿囊和脐带。胎盘是由胎儿的丛密绒毛膜与母体的基蜕膜共同组成的圆盘形结构，其胎儿面覆有羊膜，有脐带附着。胎儿血与母体血在胎盘内进行物质交换，物质交换所通过的结构，称胎盘膜或胎盘屏障。胎儿通过胎盘从母体血中获得营养和 $\mathrm{O}_2$，排出代谢产物和 $\mathrm{CO}_2$。胎盘的合体滋养层细胞还能分泌数种激素，对维持妊娠起重要作用。胎儿娩出后，胎膜、胎盘即与子宫壁分离，并被排出体外。

:::definition{label="本章一条时间轴"}
受精（壶腹，原核融合）→ 卵裂（透明带内）→ 胚泡（滋养层 + 内细胞群，极端滋养层先植入）→ 第 $2$ 周二胚层胚盘（上胚层 / 下胚层，羊膜腔，卵黄囊）→ 第 $3$ 周原条出三胚层（三个胚层都来自上胚层）→ 第 $4\sim 8$ 周三胚层分化并卷折成圆柱形胚体 → 第 $8$ 周末初具人形；胎膜和胎盘全程提供保护、营养、呼吸、排泄和部分内分泌，娩出后成为衣胞。
:::

:::compare{title="胚盘三胚层分化的总账（章小结）"}
| 胚层 | 本章强调的去向 |
|------|----------------|
| 外胚层 | 表皮及附属器；神经系统（神经管→中枢，神经嵴→周围等） |
| 中胚层 | 心血管系统、泌尿生殖系统、肌组织和各种结缔组织等 |
| 内胚层 | 消化系统、呼吸系统、部分泌尿器官的上皮组织 |
:::

:::keypoint{label="从合子到衣胞：胚盘是人体原基，胎膜胎盘是附属结构"}
- 获能精子顶体反应穿过放射冠和透明带，原核融合形成受精卵；透明带内卵裂，约 $100$ 细胞时成胚泡并植入宫体、底部，最多后壁。
- 第 $2$ 周上胚层 + 下胚层；第 $3$ 周原条迁移铺出中胚层、置换出内胚层，上胚层改称外胚层。
- 第 $4\sim 8$ 周分化并卷折，第 $8$ 周末眼、耳、鼻及四肢可见，初具人形。
- 胎膜五件套不参与本体；胎盘 = 丛密绒毛膜 + 基蜕膜；两套血隔着胎盘屏障交换；合体滋养层分泌激素维持妊娠；娩出后排出为衣胞。

:::note{label="体外受精-胚胎移植技术（试管婴儿）"}
体外受精-胚胎移植技术是一种生育辅助技术，俗称“试管婴儿”，通过超排卵、人工授精、胚胎培养和移植等步骤，帮助不孕不育夫妇实现妊娠。这项技术的出现，为人类生殖医学的发展开辟了新的道路。

在英国产科医生帕特里克·斯特普托和生理学家罗伯特·爱德华兹共同努力下，$1978$ 年 $7$ 月 $25$ 日，世界上第一位“试管婴儿”诞生，这使体外受精-胚胎移植技术从实验室走向了临床实践，对人类生殖医学产生了深远的影响。从 $1984$ 年起，我国著名的组织学与胚胎学专家刘斌教授与北京大学第三医院张丽珠团队合作进行试管婴儿的研究，在无法获得进口培养液的情况下，刘斌教授使用自己配制的培养液成功完成了人卵体外受精与培养，这是我国“试管婴儿”研究迈出的至关重要的一步。$1988$ 年 $3$ 月 $10$ 日，我国大陆首例“试管婴儿”在北京大学第三医院诞生。

随着科技的进步和医学技术的不断突破，体外受精-胚胎移植技术经历了数十年的发展和演变，发展到卵细胞质内单精子注射（ICSI）技术，以及胚胎植入前遗传学诊断（PGD）技术，诞生了第二代、第三代“试管婴儿”。随着医学技术的不断发展，体外受精-胚胎移植技术有望在疾病的预防和治疗方面发挥更大的作用。促性腺激素超排卵和一次移植多个胚胎，也与本节所述多胎发生率增高有关。
