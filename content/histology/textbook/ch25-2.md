# 二、心脏的发生

心脏发生于生心区。生心区在口咽膜头端，头端是原始横隔。围心腔先出现，腹侧间充质聚成一对生心板，再变成一对心管；头褶把它们从胚盘头端转到胸腔腹侧，侧褶再把左右心管融成一条。本节先把位置和外形（心球、心室、心房、静脉窦，袢曲成球室袢）立住，再把内部分隔摊开：房室管心内膜垫、心房两隔两孔、心室肌性部加膜性部、心球动脉干螺旋嵴，以及静脉窦和肺静脉被吸收进左、右心房。内部分隔是考试核心，每一道隔、每一道嵴、每一个孔都要能叫出名字。

心脏发生于生心区。在三胚层胚盘形成过程中，生心区（cardiogenic area）由部分中胚层细胞在胚盘前缘口咽膜的头端汇聚形成。生心区头端为原始横隔。

:::definition{label="生心区"}
生心区（cardiogenic area）由部分中胚层细胞在胚盘前缘口咽膜的头端汇聚形成。它是心脏发生的地点。此时胚盘还是扁平的，生心区在口咽膜头侧，还没有转到胸腔腹侧。
:::

:::definition{label="原始横隔（生心区头端）"}
生心区头端为原始横隔。心管尾端后来被横隔固定，袢曲时尾端不能自由移动，和头端被鳃弓固定是同一套“两端固定”的账。
:::

:::concept{term="先问心管合没合、转没转到胸腔腹侧，再问现在是外形袢曲还是内部分隔"}
看见心脏发生，先问位置：生心区原先在口咽膜头端；头褶把围心腔转到腹侧、心管转到围心腔背侧；侧褶让左右心管从头端向尾端融合，第 $22$ 天成一条。再问外形：头向尾依次是心球、心室、心房、静脉窦；两端固定、心球和心室长得快，才弯成 U 形球室袢，随后变 S 形。最后才问内部分隔：房室管心内膜垫、心房第一隔／第一孔和第二隔／卵圆孔、心室肌部加膜部、心球动脉干螺旋嵴。把“心管”听成已经有四个腔，或把袢曲听成内部分隔，后面的隔和孔会对错户头。
:::

## （一）原始心脏的形成

### 1. 心管和围心腔的发生

人胚第 $18\sim 19$ 天，生心区出现腔隙，称围心腔（pericardial coelom）；其腹侧的间充质细胞聚集成一对长条细胞索，称生心板（cardiogenic plate）（图 25-3）。生心板中央逐渐出现腔隙，形成并列的左、右两条纵管，称心管（cardiac tube）（图 25-4）。

胚体由扁平的胚盘向圆柱形胚体的转变过程中，随着头褶的发生，胚体头端向腹侧卷曲，原来位于口咽膜头侧的心管和围心腔转位约 $180^{\circ}$，围心腔转至腹侧，心管则转至围心腔的背侧（图 25-3）。当胚体发生侧褶时，左、右心管逐渐向中线靠拢，并从头端向尾端融合，于第 $22$ 天成为一条心管（图 25-4）。

围心腔不断扩大并向心管的背侧扩展，使心管与前肠之间的间充质由宽变窄，形成心背系膜，将心管悬连于围心腔的背侧壁。心背系膜中央部逐渐退化消失，形成一个左右相通的孔道，即心包横窦。心管的头、尾侧仍留有心背系膜，其余部分完全游离于围心腔内（图 25-4）。之后围心腔发育为心包腔。

:::definition{label="围心腔"}
围心腔（pericardial coelom）是人胚第 $18\sim 19$ 天生心区出现的腔隙。起初在生心板的背侧（转位前的方位）；头褶转位后转到腹侧。之后发育为心包腔。
:::

:::definition{label="生心板"}
生心板（cardiogenic plate）是围心腔腹侧的间充质细胞聚集成的一对长条细胞索。它还不是管子；中央出现腔隙之后才变成心管。
:::

:::definition{label="心管"}
心管（cardiac tube）由生心板中央出现腔隙形成，起初是并列的左、右两条纵管。胚体侧褶时，左右心管向中线靠拢，从头端向尾端融合，于第 $22$ 天成为一条心管。
:::

:::definition{label="头褶使心管转位180°"}
扁平胚盘变圆柱时，头褶使胚体头端向腹侧卷曲，原来位于口咽膜头侧的心管和围心腔转位约 $180^{\circ}$：围心腔转至腹侧，心管则转至围心腔的背侧。转完才落在未来胸腔的腹侧，不是一直停在口咽膜头端。
:::

:::definition{label="心背系膜与心包横窦"}
围心腔扩大并向心管背侧扩展，心管与前肠之间的间充质由宽变窄，形成心背系膜，把心管悬连于围心腔背侧壁。心背系膜中央部逐渐退化消失，形成一个左右相通的孔道，即心包横窦。头、尾侧仍留有心背系膜，其余部分完全游离于围心腔内。
:::

:::definition{label="心包腔"}
围心腔随后发育为心包腔。心包横窦是心背系膜中央退化留下的左右相通孔道，不是另外新长出来的腔。
:::

- **第18～19天** 生心区出现围心腔；腹侧间充质聚成一对生心板

- **随后** 围心腔向背侧扩展，形成心背系膜；中央退化成心包横窦；围心腔发育为心包腔

:::pitfall{label="转位后围心腔在腹侧、心管在围心腔背侧，不要写成心管贴着腹壁、围心腔在背侧"}
头褶转的是整套生心结构：围心腔先转到腹侧，心管落到围心腔背侧，前肠更在背侧。写成“心管转到最腹侧、围心腔在心管背侧”，图 25-3C 的腹背会反。
:::

:::pitfall{label="左右心管从头端向尾端融合，不是一下子整根并上"}
第 $22$ 天成一条心管，融合顺序是从头端向尾端。尾端静脉窦左右角仍可成对通入。写成“整根心管同时融合”，静脉窦左右角和未融合的尾段会对不上图 25-6A。
:::

### 2. 心脏壁的形成

心管合并时，心管内皮形成心内膜的内皮层。心管周围的间充质逐渐密集，形成心肌外套层，间充质分化为心肌纤维和结缔组织，以后分化为心肌膜和心外膜。心肌外膜的外套层分化出一层扁平细胞，形成心外膜的间皮。心管内皮和心肌外套层之间较疏松的胶样结缔组织称为心胶质（见图 25-4，图 25-5），将形成心内膜内皮下层的结缔组织。

:::definition{label="心内膜的内皮层"}
心管合并时，心管内皮形成心内膜的内皮层。它来自心管原有的内皮，不是后来才贴上去的一层。
:::

:::definition{label="心肌外套层"}
心管周围的间充质逐渐密集，形成心肌外套层。间充质分化为心肌纤维和结缔组织，以后分化为心肌膜和心外膜。
:::

:::definition{label="心外膜的间皮"}
心肌外膜的外套层分化出一层扁平细胞，形成心外膜的间皮。间皮是心外膜的表面，不要和心内膜内皮写成同一层。
:::

:::definition{label="心胶质"}
心胶质是心管内皮和心肌外套层之间较疏松的胶样结缔组织（图 25-4，图 25-5），将形成心内膜内皮下层的结缔组织。它夹在内皮与心肌之间，不是心包腔里的液体。
:::

::figure{src="/images/histology/textbook/p0272_02.png" caption="图25-5 原始心脏光镜图。1. 神经沟；2. 前肠；3. 围心腔；4. 心内膜原基（脱离）；5. 心肌膜与心外膜。" alt="横切光镜：背侧神经沟张开，其下前肠，腹侧围心腔内见脱离的心内膜原基及心肌膜与心外膜"}

:::compare{title="心壁三层在心管阶段的来源"}
| 成体层次 | 心管阶段的来源 | 不要听成 |
|----------|----------------|----------|
| 心内膜内皮 | 心管内皮 | 心肌外套层变的 |
| 心内膜内皮下层结缔组织 | 心胶质（内皮与心肌外套层之间的胶样结缔组织） | 心包液 |
| 心肌膜 | 心肌外套层中间充质分化的心肌纤维和结缔组织 | 心胶质变肌 |
| 心外膜（含间皮） | 心肌外套层分化为心外膜；外套层再分化出扁平细胞形成间皮 | 围心腔上皮直接变成心外膜 |
:::

:::insight{label="内皮在里，外套层在外，心胶质夹在中间"}
合并后的心管从里到外：内皮 → 心胶质 → 心肌外套层（将来的心肌膜和心外膜）。围心腔是管子外面的腔，以后变心包腔。把心胶质听成心包液，内皮下层和心包两本账会并成一句。
:::

## （二）心脏外形的建立

心管各段生长速度不同，由头向尾形成膨大，依次为心球（bulbus cordis）、心室、心房和静脉窦（sinus venosus），静脉窦末端分为左、右角，左右总主静脉、脐静脉和卵黄静脉分别通入。心球的远侧份较细长，为动脉干（truncus arteriosus），动脉干头端连接主动脉囊。

心管的头端与动脉相连，为鳃弓固定；尾端与静脉相接，为横隔固定。在心管的发生过程中，由于两端固定，而游离部，尤其是心球和心室的生长速度又远快于心包腔的扩展速度，因此心球和心室朝右、腹、尾侧弯曲，形成一个 U 形的球室袢（bulboventricular loop）（图 25-6）。

随后，心房逐渐脱离横隔，移至心室头端背侧，并稍偏左。静脉窦也从原始横隔内游离出来，位于心房的尾侧，此时心脏的外形为 S 形（图 25-6，图 25-7）。由于心房的腹侧有心球和动脉干，背侧有食管，因此生长腹背受限，即逐渐上移并膨出于心球和动脉干的两侧。随着心房扩大，其与心室之间的房室沟逐渐加深。同时，心球的尾段膨大，被心室吸收，成为原始右心室；原来的心室成为原始左心室，左、右心室之间的表面出现室间沟。此时初具成体心脏的外形。

:::definition{label="心管四段膨大"}
心管各段生长速度不同，由头向尾依次膨大为：心球（bulbus cordis）、心室、心房和静脉窦（sinus venosus）。头端是心球，尾端是静脉窦，顺序不要写反。
:::

:::definition{label="静脉窦左、右角"}
静脉窦末端分为左、右角。左右总主静脉、脐静脉和卵黄静脉分别通入。三个静脉系统都先汇入静脉窦，不是直接开口于将来的右心房。
:::

:::definition{label="动脉干"}
心球的远侧份较细长，为动脉干（truncus arteriosus）。动脉干头端连接主动脉囊。动脉干是心球远侧的一段，还没有被螺旋嵴分成主动脉和肺动脉干。
:::

:::definition{label="两端固定"}
心管头端与动脉相连，为鳃弓固定；尾端与静脉相接，为横隔固定。袢曲发生在两端之间的游离部，尤其是心球和心室。
:::

:::definition{label="球室袢"}
由于两端固定，游离部尤其是心球和心室的生长速度远快于心包腔的扩展速度，心球和心室朝右、腹、尾侧弯曲，形成一个 U 形的球室袢（bulboventricular loop）。U 形是袢曲的第一笔，随后心房上移才变成 S 形。
:::

:::definition{label="S形外形"}
心房逐渐脱离横隔，移至心室头端背侧，并稍偏左；静脉窦从原始横隔内游离出来，位于心房的尾侧。此时心脏外形为 S 形。
:::

:::definition{label="心房向两侧膨出"}
心房腹侧有心球和动脉干，背侧有食管，腹背生长受限，因而逐渐上移并膨出于心球和动脉干的两侧。左右心耳的外形从此开始。
:::

:::definition{label="房室沟与室间沟"}
随着心房扩大，心房与心室之间的房室沟逐渐加深，对应内部的房室管。心球尾段被心室吸收成为原始右心室、原来的心室成为原始左心室之后，左、右心室之间的表面出现室间沟。沟在表面，管和隔在内部，不要把沟写成已经隔开的腔。
:::

:::definition{label="原始右心室与原始左心室"}
心球的尾段膨大，被心室吸收，成为原始右心室；原来的心室成为原始左心室。右心室主要来自心球尾段，左心室主要来自原来的心室，户头不要对调。
:::

:::derivation{title="两端固定加心球心室快长，推出U形球室袢"}
心管头端被鳃弓钉在动脉侧，尾端被横隔钉在静脉侧，中间的游离部却还在长。心球和心室长得比心包腔扩展更快，多出来的长度只能朝右、腹、尾侧弯出去，于是出现 U 形球室袢。不是心管自己喜欢弯，是两端不能动、中间长得太快。心房再脱离横隔上移到心室头端背侧，U 形才改写成 S 形。
:::

| 袢曲中的角色 | 与心室一起朝右、腹、尾侧弯，成球室袢 | 同左；原来的心室后成原始左心室 | 脱离横隔，移至心室头端背侧稍偏左，向两侧膨出 | 从原始横隔游离，位于心房尾侧 |
| 被吸收后 | 尾段膨大被心室吸收 → 原始右心室 | 成为原始左心室 | 原始心房后来变心耳（粗糙部） | 右角并入右房，左角成冠状窦 |
:::

:::cause-effect{title="两端固定，游离部快长，外形才从直管变成S形"}
- 因：头端鳃弓固定、尾端横隔固定，心球和心室生长远快于心包腔扩展
- 果：心球和心室朝右、腹、尾侧弯成 U 形球室袢
- 因：心房脱离横隔，移至心室头端背侧稍偏左；静脉窦从横隔游离到心房尾侧
- 果：外形变成 S 形
- 因：心房腹背受限，向两侧膨出；心球尾段被吸收
- 果：房室沟加深；原始右心室（心球尾段）与原始左心室（原心室）出现，表面出室间沟，初具成体外形
:::

:::pitfall{label="球室袢是U形弯曲，不是已经隔开的右心室"}
袢曲只改外形。心球尾段被心室吸收成为原始右心室，是外形建立末了的一步，内部的室间隔还没有长。把 U 形袢写成“已经分成左右心室”，肌性室间隔和室间孔会没有起点。
:::

:::pitfall{label="原始右心室来自心球尾段，原始左心室来自原来的心室，不要对调"}
心球在头端，它的尾段并进心室侧才成为原始右心室；原先那一段心室留下当原始左心室。写成“心球变左心室”，后面肺动脉干接右心室、主动脉接左心室会对反。
:::

:::timeline{period="心脏外形从直管到初具成体"}
- **四段膨大** 头向尾：心球（远侧为动脉干接主动脉囊）、心室、心房、静脉窦（左、右角通总主静脉、脐静脉、卵黄静脉）
- **两端固定** 头端鳃弓，尾端横隔
- **U形球室袢** 心球和心室朝右、腹、尾侧弯曲（图25-6）
- **S形** 心房移至心室头端背侧稍偏左；静脉窦游离到心房尾侧
- **两侧膨出** 心房腹侧受心球和动脉干、背侧受食管限制，上移并膨出两侧
- **沟** 房室沟加深；心球尾段吸收为原始右心室，原心室为原始左心室，表面出现室间沟
- **第5周初** 外形初步完成，内部分隔尚不完全
:::

## （三）心脏内部的分隔

第 $5$ 周初，心脏外形的建立已初步完成，但内部的分隔尚不完全。心脏各部的分隔同时进行（图 25-8，图 25-9）。

:::note{label="各部同时分隔，不要按课文顺序理解成先房后室再动脉干"}
教材叙述顺序是房室管 → 心房 → 心室 → 心球动脉干 → 静脉窦。发生上它们同时进行。卵圆孔、室间孔、螺旋嵴可以在同一周里一起长。答题按结构分开写，时钟不要排成一条单行。
:::

:::concept{term="先问这是第一隔还是第二隔，再问眼前这个孔是第一孔、第二孔还是卵圆孔"}
看见心房分隔，先认隔：头端背侧正中长出来的薄半月形是第一房间隔；它右侧再长的较厚新月形是第二房间隔。再认孔：第一隔游离缘与心内膜垫之间是第一房间孔；第一隔上部变薄融合成的是第二房间孔；第二隔下缘与心内膜垫之间留下的是卵圆孔。卵圆孔比第二房间孔稍低，两孔交错；第一隔下部盖在卵圆孔左侧，薄而软，叫卵圆孔瓣。把“第一孔”听成卵圆孔，或把第二隔听成卵圆孔瓣，出生前后的右向左分流会对错户头。
:::

### 1. 房室管的分隔

随着心房和心室之间的房室沟逐渐加深，相应的心腔也形成一狭窄的管道，称房室管（atrioventricular canal）。第 $4$ 周，房室管的背侧壁和腹侧壁正中的心内膜组织增厚，分别形成背、腹心内膜垫（endocardial cushion）。二者相对生长，向中央靠拢，至第 $6$ 周时相互融合，将房室管分隔为左、右房室管。围绕房室管的间充质局部增生并向腔内隆起，演变成二尖瓣和三尖瓣。

:::definition{label="房室管"}
房室管（atrioventricular canal）是房室沟加深后，心房与心室之间相应形成的狭窄管道。它还是一条，要等背、腹心内膜垫融合才分成左、右房室管。
:::

:::definition{label="背、腹心内膜垫"}
第 $4$ 周，房室管背侧壁和腹侧壁正中的心内膜组织增厚，分别形成背、腹心内膜垫（endocardial cushion）。二者相对生长、向中央靠拢，至第 $6$ 周相互融合，把房室管分成左、右房室管。心内膜垫还要向上参与封第一房间孔、向下参与室间隔膜部，是内部分隔的枢纽。
:::

:::definition{label="二尖瓣与三尖瓣的原基"}
围绕房室管的间充质局部增生并向腔内隆起，演变成二尖瓣和三尖瓣。瓣膜来自房室管周围间充质，不是心内膜垫融合本身变成瓣。
:::

:::compare{title="一条房室管如何分成左右"}
| 项目 | 分隔前 | 分隔后（第 $6$ 周） |
|------|--------|---------------------|
| 管道 | 一条房室管 | 左房室管、右房室管 |
| 隔的材料 | 背侧壁、腹侧壁正中的心内膜组织增厚 | 背、腹心内膜垫相对生长并融合 |
| 瓣膜 | 尚未隆起 | 管周间充质向腔内隆起 → 二尖瓣、三尖瓣 |
| 时间 | 第 $4$ 周垫开始出现 | 第 $6$ 周垫融合 |
:::

:::pitfall{label="心内膜垫融合分成左、右房室管，不要写成它直接变成室间隔"}
垫融合的第一件事是把房室管分成左右。室间隔膜部另要心内膜垫间充质增生，再与心球嵴、室间隔肌部上缘融合。把垫写成“就是室间隔”，膜部那三家会合会少两家。
:::

### 2. 心房的分隔

在心内膜垫发生的同时，于心房头端背侧壁的正中线处发生一个薄的半月形薄膜，称第一房间隔。其向心内膜垫方向生长，游离缘与心内膜垫之间暂时留一孔，称第一房间孔。第一房间隔继续增长，隔的上部中央变薄出现若干小孔，逐渐融合成一孔，称第二房间孔。心内膜垫组织向上凸起并与第一房间隔游离缘融合，第一房间孔封闭。

第 $5$ 周末，在第一房间隔右侧，从心房的头端腹侧壁再长出一较厚的新月形隔，称第二房间隔。此隔下缘呈弧形，渐向心内膜垫方向生长，覆盖了第二房间孔，当其前、后缘与心内膜垫接触时，下方留有一卵圆孔（foramen ovale）。卵圆孔的位置比第二房间孔稍低，两孔交错重叠。第一房间隔在左侧下方覆盖卵圆孔，薄而软的第一房间隔相当于瓣膜，称卵圆孔瓣。出生前，由于肺循环不行使功能，左心房压力低于右心房，右心房的血液可经卵圆孔流入左心房，反之则不能。出生后，肺循环开始，左心房压力增大，致使两个隔紧贴并逐渐融合，卵圆孔关闭形成一个完整的房间隔，左、右心房完全分隔。卵圆孔关闭处在成体心房隔上留下卵圆窝。

:::definition{label="第一房间隔"}
第一房间隔是心房头端背侧壁正中线处发生的薄的半月形薄膜。它向心内膜垫方向生长。薄、来自背侧壁、长在先，这三点把它和第二房间隔分开。
:::

:::definition{label="第一房间孔"}
第一房间孔是第一房间隔游离缘与心内膜垫之间暂时留下的孔。心内膜垫组织向上凸起并与第一房间隔游离缘融合后，第一房间孔封闭。第一孔在下，靠垫来关。
:::

:::definition{label="第二房间孔"}
第一房间隔继续增长时，隔的上部中央变薄，出现若干小孔，逐渐融合成一孔，称第二房间孔。第二孔开在第一隔上部，发生在第一孔关闭之前：先在上方打出第二孔，再让垫把下方的第一孔封上，左右心房才始终有路可通。
:::

:::definition{label="第二房间隔"}
第 $5$ 周末，在第一房间隔右侧，从心房头端腹侧壁再长出一较厚的新月形隔，称第二房间隔。它下缘呈弧形，向心内膜垫生长，覆盖第二房间孔；前、后缘与心内膜垫接触时，下方留出卵圆孔。厚、在右侧、来自腹侧壁、长在后。
:::

:::definition{label="卵圆孔"}
卵圆孔（foramen ovale）是第二房间隔前、后缘与心内膜垫接触后，下方留下的孔。位置比第二房间孔稍低，两孔交错重叠。它是第二隔下缘的孔，不是第一隔上的第二房间孔。
:::

:::definition{label="卵圆孔瓣"}
第一房间隔在左侧下方覆盖卵圆孔，薄而软，相当于瓣膜，称卵圆孔瓣。出生前只许右心房的血经卵圆孔进左心房，反向不能。瓣是第一隔的下部，不是第二隔。
:::

:::definition{label="卵圆窝"}
出生后肺循环开始，左心房压力增大，第一、第二房间隔紧贴并逐渐融合，卵圆孔关闭，形成完整房间隔。关闭处在成体房间隔上成为卵圆窝。卵圆窝是关闭后的遗迹，不是胚胎期另一个孔。
:::

:::definition{label="出生前右向左、不能反向"}
出生前肺循环不行使功能，左心房压力低于右心房，右心房血液可经卵圆孔流入左心房，反之则不能。单向靠的是薄而软的卵圆孔瓣（第一隔下部）盖在卵圆孔左侧。
:::

|------|------------|------------|
| 出现 | 与心内膜垫同时，心房头端背侧壁正中 | 第 $5$ 周末，第一隔的右侧，头端腹侧壁 |
| 形态 | 薄的半月形薄膜 | 较厚的新月形隔，下缘呈弧形 |

| 相关的孔 | 游离缘与垫之间 = 第一房间孔；上部变薄融合 = 第二房间孔 | 前、后缘与垫接触后下方 = 卵圆孔 |
| 第一房间孔的关闭 | 垫向上凸起与游离缘融合，第一孔封闭 | 不负责关第一孔 |
| 出生前的角色 | 左侧下方覆盖卵圆孔，薄而软，成为卵圆孔瓣 | 构成卵圆孔的边缘 |
| 出生后 | 与第二隔紧贴融合 | 与第一隔融合，卵圆孔关闭成卵圆窝 |
:::

:::compare{title="第一房间孔、第二房间孔与卵圆孔"}
| 项目 | 第一房间孔 | 第二房间孔 | 卵圆孔 |
|------|------------|------------|--------|
| 开在哪一层 | 第一隔游离缘与心内膜垫之间 | 第一隔上部中央 | 第二隔下缘与心内膜垫之间 |
| 高低 | 下方 | 上方 | 比第二房间孔稍低 |
| 如何出现 | 第一隔尚未长到垫上，暂时留孔 | 第一隔上部变薄，若干小孔融合成一孔 | 第二隔前、后缘碰到垫，下方留孔 |
| 如何关闭 | 垫向上与第一隔游离缘融合 | 被第二隔覆盖；功能上由卵圆孔接替 | 出生后两隔紧贴融合；成体遗迹为卵圆窝 |
| 不要听成 | 卵圆孔 | 卵圆孔 | 第一隔上的孔 |
:::

:::cause-effect{title="两隔两孔交错，出生前才能右向左分流"}
- 因：第一隔先长，下方留第一房间孔；上部再打出第二房间孔，垫才把第一孔封上
- 果：第一孔关闭时，心房之间仍有第二孔可通，胚体不会在分隔中途把左右心房完全堵死
- 因：第二隔从右侧盖住第二房间孔，下方留下更低的卵圆孔，与第二孔交错；第一隔下部当卵圆孔瓣
- 果：出生前右房压高于左房，血只能右向左过卵圆孔；反向则瓣贴上，不能回流
- 因：出生后肺循环启动，左房压升高
- 果：两隔紧贴融合，卵圆孔关闭，遗留卵圆窝
:::

:::pitfall{label="第二房间孔在第一隔上，卵圆孔在第二隔下缘，不要把两个孔写成一个"}
第二房间孔是第一隔上部变薄融出来的。卵圆孔是第二隔弧形下缘留下的。两孔交错重叠，位置一高一低。写成“第二孔就是卵圆孔”，瓣在左侧盖哪一个孔会对错。
:::

:::pitfall{label="卵圆孔瓣是第一隔下部，不是第二隔"}
第二隔厚，构成卵圆孔的边缘；第一隔薄而软，从左侧盖住卵圆孔当瓣。把瓣写成第二隔，出生前“只许右向左”的单向结构会安错层。
:::

:::insight{label="先开上面的第二孔，再关下面的第一孔，左右心房始终留一条路"}
如果第一隔先把第一孔封死、上面还不打孔，胚胎期左右心房会过早隔绝。教材的顺序是：上部出现第二房间孔，心内膜垫再关第一房间孔。第二隔随后盖住第二孔、留下卵圆孔。三步都是为了“边隔边通”，直到出生后才完全关掉。
:::

### 3. 心室的分隔

人胚第 $4$ 周末，于心尖处心室底壁组织向上凸起形成一个较厚的半月形的肌性隔膜，称室间隔肌部。此隔向心内膜垫方向生长，游离缘凹陷与心内膜垫之间留有一半月状孔，称室间孔（见图 25-8、图 25-9，图 25-10）。

第 $7$ 周末，由于心球内部形成左、右心球嵴，彼此对向生长、融合，并向下延伸，分别与室间隔肌部的前缘和后缘融合，关闭了室间孔上部的大部分；同时，心内膜垫的间充质增生、室间隔肌部上缘向上生长，与心球嵴融合形成室间隔膜部（图 25-11）。至此，室间孔封闭，左、右心室完全分隔。

:::definition{label="室间隔肌部"}
人胚第 $4$ 周末，心尖处心室底壁组织向上凸起，形成一个较厚的半月形肌性隔膜，称室间隔肌部。它向心内膜垫方向生长，本身关不了室间孔，只构成室间隔的肌性主体。
:::

:::definition{label="室间孔"}
室间隔肌部游离缘凹陷，与心内膜垫之间留有一半月状孔，称室间孔。第 $7$ 周末才被心球嵴和室间隔膜部关闭。肌部先长、孔先留着，不要写成肌部一出现就把左右心室隔死。
:::

:::definition{label="左、右心球嵴（关室间孔）"}
第 $7$ 周末，心球内部形成左、右心球嵴，彼此对向生长、融合，并向下延伸，分别与室间隔肌部的前缘和后缘融合，关闭了室间孔上部的大部分。心球嵴既参与心球分隔，也向下帮着关室间孔。
:::

:::definition{label="室间隔膜部"}
心内膜垫的间充质增生，室间隔肌部上缘向上生长，与心球嵴融合，形成室间隔膜部。膜部是三家会合：心内膜垫 + 室间隔肌部上缘 + 心球嵴。膜部形成后，室间孔封闭，左、右心室完全分隔。
:::

:::compare{title="室间隔肌部与室间隔膜部"}
| 项目 | 室间隔肌部 | 室间隔膜部 |
|------|------------|------------|

| 形态 | 较厚的半月形肌性隔膜 | 薄的膜性部，封在肌部上方 |

:::

:::concept{term="先问室间孔是肌部游离缘留下的还是膜部已经闭上，再问心球嵴和心内膜垫融了没有"}
看见心室分隔，先问孔还在不在：第 $4$ 周末肌部从心尖向上长，游离缘与心内膜垫之间是室间孔。再问第 $7$ 周末三家会合没有：左、右心球嵴对生融合并向下接到肌部前、后缘，垫的间充质增生，肌部上缘向上，三者融成膜部，孔才关。把肌部听成已经把心室隔完，或把膜部听成只是心内膜垫自己变的，室间隔缺损的部位会对错户头。
:::

:::cause-effect{title="肌部留孔，嵴和垫来封，膜部才把室间孔关上"}
- 因：第 4 周末肌部从心尖向上长，游离缘达不到心内膜垫
- 果：留下半月状室间孔，左右心室暂仍相通
- 因：第 7 周末左右心球嵴对生融合并下延，接到肌部前、后缘；垫的间充质增生，肌部上缘向上
- 果：三者融成室间隔膜部，室间孔封闭，左右心室完全分隔
- 制约：膜部融合不良是室间隔缺损最常见的发生学位点（见第 25 章第五节）
:::

:::pitfall{label="室间孔不是肌部中间穿的洞，是游离缘与心内膜垫之间留下的半月状孔"}
肌部从心尖向上长，上缘凹陷，和垫之间空着一弯孔。写成“肌隔中央穿孔”，关闭时参与的心球嵴和膜部会对不上边缘。
:::

:::pitfall{label="膜部是心内膜垫、肌部上缘和心球嵴三家融合，不要写成一家的产物"}
缺任何一家，室间孔上部关不严。只背“膜部来自心内膜垫”，心球嵴下延和肌部上缘会从答题里消失。
:::

### 4. 心球与动脉干的分隔

第 $5$ 周，心球和动脉干的内膜组织局部增生，形成一对心球嵴和动脉干嵴。相应的嵴对向生长，在中线融合，形成螺旋状走行的隔，称主动脉肺动脉隔（aorticopulmonary septum）（图 25-12），将心球和动脉干分隔成相互缠绕的主动脉和肺动脉。主动脉和肺动脉起始处的内膜组织向腔内增生，各形成 $3$ 个薄片状隆起，逐渐演变为半月瓣。室间孔封闭后，肺动脉干与右心室相通，主动脉与左心室相通。

:::definition{label="心球嵴与动脉干嵴"}
第 $5$ 周，心球和动脉干的内膜组织局部增生，形成一对心球嵴和一对动脉干嵴。心球里叫心球嵴，动脉干里叫动脉干嵴，是同一套对生的嵴在两段管子上的名字。
:::

:::definition{label="主动脉肺动脉隔"}
相应的嵴对向生长，在中线融合，形成螺旋状走行的隔，称主动脉肺动脉隔（aorticopulmonary septum）。它把心球和动脉干分隔成相互缠绕的主动脉和肺动脉。隔必须走螺旋，直着隔就会把两大动脉接到错误的心室。
:::

:::definition{label="半月瓣"}
主动脉和肺动脉起始处的内膜组织向腔内增生，各形成 $3$ 个薄片状隆起，逐渐演变为半月瓣。每侧 $3$ 个，不是心球嵴本身变成瓣。
:::

:::definition{label="分隔后的对接"}
室间孔封闭后，肺动脉干与右心室相通，主动脉与左心室相通。螺旋嵴加上室间孔关闭，才把右心室接到肺动脉、左心室接到主动脉。
:::

|------|----------|----------|-------------------|
| 开始时间 | 与心内膜垫同时（第 $4$ 周起）；第 $5$ 周末出第二隔 | 第 $4$ 周末肌部出现 | 第 $5$ 周嵴出现 |
| 主要结构 | 第一房间隔、第一房间孔、第二房间孔、第二房间隔、卵圆孔、卵圆孔瓣 | 室间隔肌部、室间孔、左／右心球嵴、室间隔膜部 | 心球嵴、动脉干嵴、主动脉肺动脉隔、半月瓣 |
| 隔的形态 | 两层隔交错，出生前留孔 | 肌部厚、膜部薄，第 $7$ 周末关孔 | 一对嵴中线融合，隔走螺旋 |
| 关闭时间 | 出生后两隔融合，卵圆孔关，成卵圆窝 | 第 $7$ 周末室间孔封闭 | 嵴融合后即分成两大动脉；室间孔关闭后才与左右心室正确对接 |
| 出生前是否完全隔开 | 否，卵圆孔右向左分流 | 第 $7$ 周末起完全隔开 | 分成相互缠绕的主动脉和肺动脉干 |
| 枢纽结构 | 心内膜垫关第一房间孔 | 心内膜垫参与膜部 | 心球嵴向下还帮关室间孔 |
| 正确对接 | 右房 ↔ 右室，左房 ↔ 左室（经左右房室管） | 右室 ↔ 肺动脉干，左室 ↔ 主动脉 | 螺旋隔保证上述对接；直隔则错位 |
:::

:::concept{term="先问嵴是不是螺旋走行，再问室间孔关了以后谁通右心室、谁通左心室"}
看见心球和动脉干，先认一对心球嵴加一对动脉干嵴对向融合，隔必须螺旋。再问对接：室间孔封闭后，肺动脉干通右心室，主动脉通左心室。把隔写成“直着一劈两半”，或把主动脉接到右心室，错位和法洛四联症的发生学会对不上螺旋这本账。
:::

:::cause-effect{title="螺旋嵴把一条管子拧成相互缠绕的主动脉和肺动脉"}
- 因：第 5 周心球嵴和动脉干嵴对向生长，在中线融合成螺旋状主动脉肺动脉隔
- 果：心球和动脉干被分成相互缠绕的主动脉与肺动脉；起始处内膜各出 3 个薄片，演变成半月瓣
- 因：室间孔随后封闭
- 果：肺动脉干与右心室相通，主动脉与左心室相通
- 制约：隔不走螺旋则两大动脉错位；隔偏一侧则一大一小，可伴膜部缺损
:::

:::pitfall{label="主动脉肺动脉隔必须螺旋走行，直隔会把两大动脉接到错误的心室"}
嵴在中线融合还不够，隔要呈螺旋状，出来的主动脉和肺动脉才相互缠绕，并在室间孔关闭后分别接左、右心室。写成“一条直隔把管子分成前、后两根”，错位畸形就没有发生学来源。
:::

:::insight{label="心球嵴一身两用：向上拧成两大动脉，向下帮关室间孔"}
同一对心球嵴，对生融合走螺旋，是主动脉肺动脉隔的一段；向下延伸接到室间隔肌部前、后缘，又是关闭室间孔上部、参与膜部的一家。把心球分隔和心室分隔写成互不往来的两件事，膜部那张三家会合表会少一列。
:::

### 5. 静脉窦的演变和永久性左、右心房的形成

静脉窦位于原始心房尾端的背面，窦的左、右角分别与同侧的总主静脉、脐静脉和卵黄静脉相连（图 25-13）。起初，静脉窦开口于心房的中央部，两个角是对称的，后因血液多经右角回流心脏，右角逐渐扩大，窦房口逐渐移向右侧。窦左角逐渐退化萎缩，近侧段成为冠状窦，远侧段成为左心房斜静脉的根部。

第 $7\sim 8$ 周，原始右心房扩展很快，静脉窦右角被吸收并入右心房，形成永久性右心房固有部（平滑部）。原始右心房则变为右心耳（粗糙部）。

原始左心房最初只有一条原始肺静脉通入。此静脉分出左、右属支，再各分为两支。以后由于左心房扩大，逐渐把原始肺静脉根部及左、右属支吸收并入左心房，使 $4$ 条肺静脉直接开口于左心房（图 25-14）。肺静脉及其属支参与形成永久性左心房固有部（平滑部），原始的左心房则成为左心耳（粗糙部）。

:::definition{label="静脉窦的位置与通入"}
静脉窦位于原始心房尾端的背面。窦的左、右角分别与同侧的总主静脉、脐静脉和卵黄静脉相连。三个静脉系统先入静脉窦，再经窦房口进原始心房。
:::

:::definition{label="窦房口右移"}
起初静脉窦开口于心房中央，左右角对称。后因血液多经右角回流心脏，右角逐渐扩大，窦房口逐渐移向右侧。血流把对称的窦拧成右角占优。
:::

:::definition{label="静脉窦左角的结局"}
窦左角逐渐退化萎缩：近侧段成为冠状窦，远侧段成为左心房斜静脉的根部。左角不是整个消失，是改成冠状窦加斜静脉根。
:::

:::definition{label="永久性右心房固有部与右心耳"}
第 $7\sim 8$ 周，原始右心房扩展很快，静脉窦右角被吸收并入右心房，形成永久性右心房固有部（平滑部）。原始右心房则变为右心耳（粗糙部）。平滑部来自静脉窦右角，粗糙部来自原始右心房。
:::

:::definition{label="原始肺静脉被吸收"}
原始左心房最初只有一条原始肺静脉通入。此静脉分出左、右属支，再各分为两支。左心房扩大，逐渐把原始肺静脉根部及左、右属支吸收并入左心房，使 $4$ 条肺静脉直接开口于左心房。
:::

:::definition{label="永久性左心房固有部与左心耳"}
肺静脉及其属支参与形成永久性左心房固有部（平滑部）；原始的左心房则成为左心耳（粗糙部）。左房平滑部来自被吸收的肺静脉，不是静脉窦左角——左角走的是冠状窦和斜静脉根。
:::

:::concept{term="先问静脉窦哪个角并入右房，再问肺静脉是几条开口进左房"}
看见永久性心房，先问静脉窦：右角扩大并入右房成平滑部（固有部），原始右房变右心耳；左角近侧成冠状窦，远侧成左心房斜静脉根部，并不并入左房当固有部。再问肺静脉：起初一条原始肺静脉，分出左、右属支再各两支，根部和属支被左房吸收后，才是 $4$ 条肺静脉直接开口。把左房平滑部写成静脉窦左角，或把四条肺静脉写成一开始就开口于左房，吸收这本账会做错。
:::

:::compare{title="永久性右心房与永久性左心房"}
| 项目 | 右心房 | 左心房 |
|------|--------|--------|
| 平滑部（固有部）来源 | 第 $7\sim 8$ 周静脉窦右角被吸收并入 | 原始肺静脉根部及左、右属支被吸收并入 |

| 开口演变 | 窦房口由中央移向右侧后，右角并入 | 由一条原始肺静脉 → $4$ 条肺静脉直接开口 |
| 通入的静脉（早期） | 右角收总主静脉、脐静脉、卵黄静脉（后随演变改道） | 一条原始肺静脉 |
:::

:::compare{title="静脉窦左角与右角"}
| 项目 | 右角 | 左角 |
|------|------|------|
| 早期 | 与左角对称，开口于心房中央 | 与右角对称 |
| 血流 | 血液多经右角回流，右角扩大，窦房口右移 | 逐渐退化萎缩 |
| 第 $7\sim 8$ 周 | 被吸收并入右心房 → 固有部（平滑部） | 近侧段 → 冠状窦；远侧段 → 左心房斜静脉根部 |
| 不要听成 | 变成右心耳 | 并入左心房成为左房固有部 |
:::

:::cause-effect{title="右角进右房，肺静脉进左房，左右心耳都是原始心房留下的粗糙部"}
- 因：血液多经静脉窦右角回流
- 果：右角扩大、窦房口右移；第 7～8 周右角并入右房成平滑部
- 因：左角血少
- 果：左角萎缩，近侧成冠状窦，远侧成左心房斜静脉根部
- 因：左心房扩大，吸收原始肺静脉根部及左、右属支
- 果：4 条肺静脉直接开口于左房，构成左房平滑部
- 制约：两侧的粗糙部（心耳）都是原始心房本身，不要把心耳写成静脉窦或肺静脉变的
:::

:::pitfall{label="左房平滑部来自肺静脉吸收，不是静脉窦左角并入"}
静脉窦左角的近侧段是冠状窦，远侧段是左心房斜静脉根部。左房固有部（平滑部）是原始肺静脉根部和属支被吸收形成的。写成“左角并入左房”，冠状窦会没有来源，四条肺静脉开口也解释不了。
:::

:::pitfall{label="四条肺静脉不是一开始就开口于左房"}
起初只有一条原始肺静脉通入左房，先分左、右属支，再各分为两支；左房把根部和属支吸收进去之后，才变成四条直接开口。写成“左房天生四个肺静脉口”，吸收过程会从发生学里删掉。
:::

:::timeline{period="静脉窦与肺静脉并入左、右心房"}
- **早期** 静脉窦在原始心房尾端背面，左右角对称，各连同侧总主静脉、脐静脉、卵黄静脉；窦房口居中
- **血流右偏** 血多经右角回流，右角扩大，窦房口右移；左角退化
- **左角结局** 近侧段成冠状窦，远侧段成左心房斜静脉根部
- **第7～8周** 静脉窦右角并入右房 → 永久性右房固有部（平滑部）；原始右房 → 右心耳（粗糙部）
- **第5周起** 一条原始肺静脉通入左房，分出左、右属支，再各分两支
- **随后至第8周** 左房吸收肺静脉根部及属支，4条肺静脉直接开口；肺静脉参与左房固有部（平滑部），原始左房 → 左心耳（粗糙部）
:::

:::tip{label="内部分隔口诀"}
垫融房室管，瓣从管周来。房隔两层交错孔：第一隔打第二孔、垫关第一孔；第二隔留卵圆孔，第一隔当瓣。肌部留室间孔，嵴加垫成膜部关。心球动脉干走螺旋，肺动脉接右室、主动脉接左室。右角进右房，肺静脉进左房，心耳都是原始心房。
:::

:::keypoint{label="袢曲改外形，两隔两孔加螺旋嵴才改内腔"}
- 生心区在口咽膜头端；围心腔 + 一对生心板 → 一对心管；头褶转 $180^{\circ}$，侧褶第 $22$ 天融成一条。
- 心背系膜中央退化成心包横窦；内皮 → 心内膜内皮，外套层 → 心肌膜和心外膜，心胶质 → 内皮下层。
- 头向尾：心球（远侧动脉干接主动脉囊）、心室、心房、静脉窦（左右角）。两端固定，弯成 U 形球室袢，再成 S 形。
- 心球尾段 → 原始右心室，原心室 → 原始左心室；房室沟、室间沟出现。
- 背、腹心内膜垫第 $6$ 周融合，分成左、右房室管；管周间充质 → 二尖瓣、三尖瓣。
- 心房：第一隔／第一孔／第二孔，第二隔／卵圆孔／卵圆孔瓣；出生后关成卵圆窝。
- 心室：肌部留室间孔；第 $7$ 周末心球嵴 + 心内膜垫 + 肌部上缘 → 膜部，孔关闭。
- 心球动脉干：嵴融合成螺旋状主动脉肺动脉隔；各 $3$ 个薄片 → 半月瓣；肺动脉干通右室，主动脉通左室。
- 静脉窦右角并入右房（平滑部），左角 → 冠状窦和左房斜静脉根；肺静脉吸收并入左房（平滑部）；原始左、右房 → 心耳。
:::

:::memory{label="本节必背要点"}
- [ ] 心脏发生于生心区（cardiogenic area）：部分中胚层细胞在胚盘前缘口咽膜的头端汇聚形成；生心区头端为原始横隔。
- [ ] 人胚第 $18\sim 19$ 天，生心区出现围心腔（pericardial coelom）。
- [ ] 围心腔腹侧间充质聚成一对长条细胞索，称生心板（cardiogenic plate）。
- [ ] 生心板中央出现腔隙，形成并列的左、右两条纵管，称心管（cardiac tube）。
- [ ] 头褶使原来位于口咽膜头侧的心管和围心腔转位约 $180^{\circ}$：围心腔转至腹侧，心管转至围心腔背侧。
- [ ] 侧褶时左右心管向中线靠拢，从头端向尾端融合，第 $22$ 天成为一条心管。
- [ ] 围心腔向背侧扩展，心管与前肠之间的间充质变窄，形成心背系膜，将心管悬连于围心腔背侧壁。
- [ ] 心背系膜中央部退化，形成左右相通的心包横窦；头、尾侧仍留心背系膜，其余部分游离于围心腔内。
- [ ] 围心腔发育为心包腔。
- [ ] 心管合并时，心管内皮形成心内膜的内皮层。
- [ ] 心管周围间充质密集成心肌外套层，分化为心肌纤维和结缔组织，以后分化为心肌膜和心外膜。
- [ ] 心肌外膜的外套层分化出一层扁平细胞，形成心外膜的间皮。
- [ ] 心管内皮与心肌外套层之间的胶样结缔组织称心胶质，将形成心内膜内皮下层的结缔组织。
- [ ] 心管由头向尾依次膨大为心球（bulbus cordis）、心室、心房和静脉窦（sinus venosus）。
- [ ] 静脉窦末端分左、右角，左右总主静脉、脐静脉和卵黄静脉分别通入。
- [ ] 心球远侧份较细长，为动脉干（truncus arteriosus），头端连接主动脉囊。
- [ ] 头端为鳃弓固定，尾端为横隔固定。
- [ ] 心球和心室生长远快于心包腔扩展，朝右、腹、尾侧弯曲，形成 U 形球室袢（bulboventricular loop）。
- [ ] 心房脱离横隔，移至心室头端背侧并稍偏左；静脉窦从原始横隔游离，位于心房尾侧，外形呈 S 形。
- [ ] 心房腹侧有心球和动脉干、背侧有食管，腹背受限，上移并膨出于心球和动脉干两侧。
- [ ] 房室沟逐渐加深。
- [ ] 心球尾段膨大被心室吸收，成为原始右心室；原来的心室成为原始左心室；表面出现室间沟。此时初具成体心脏外形。
- [ ] 第 $5$ 周初外形初步完成，内部分隔尚不完全；各部的分隔同时进行。
- [ ] 房室沟加深后形成狭窄的房室管（atrioventricular canal）。
- [ ] 第 $4$ 周房室管背侧壁和腹侧壁正中形成背、腹心内膜垫（endocardial cushion）。
- [ ] 第 $6$ 周背、腹心内膜垫融合，将房室管分隔为左、右房室管。
- [ ] 围绕房室管的间充质局部增生并向腔内隆起，演变成二尖瓣和三尖瓣。
- [ ] 第一房间隔：心房头端背侧壁正中的薄半月形薄膜，向心内膜垫生长。
- [ ] 第一房间孔：第一房间隔游离缘与心内膜垫之间暂时留下的孔。
- [ ] 第二房间孔：第一房间隔上部中央变薄，若干小孔融合成的一孔。
- [ ] 心内膜垫向上凸起与第一房间隔游离缘融合，第一房间孔封闭。
- [ ] 第 $5$ 周末，第一房间隔右侧、心房头端腹侧壁长出较厚的新月形第二房间隔。
- [ ] 第二房间隔下缘呈弧形，覆盖第二房间孔；前、后缘与心内膜垫接触时，下方留卵圆孔（foramen ovale）。
- [ ] 卵圆孔比第二房间孔稍低，两孔交错重叠。
- [ ] 第一房间隔在左侧下方覆盖卵圆孔，薄而软，称卵圆孔瓣。
- [ ] 出生前肺循环不行使功能，左房压低于右房，右房血可经卵圆孔入左房，反向不能。
- [ ] 出生后肺循环开始，左房压增大，两隔紧贴融合，卵圆孔关闭成完整房间隔；关闭处为卵圆窝。
- [ ] 第 $4$ 周末，心尖处心室底壁向上凸起较厚的半月形肌性隔膜，称室间隔肌部。
- [ ] 室间隔肌部游离缘凹陷与心内膜垫之间留半月状室间孔。
- [ ] 第 $7$ 周末，左、右心球嵴对向生长、融合并下延，分别与室间隔肌部前缘和后缘融合，关闭室间孔上部的大部分。
- [ ] 心内膜垫间充质增生、室间隔肌部上缘向上生长，与心球嵴融合形成室间隔膜部；室间孔封闭，左右心室完全分隔。
- [ ] 第 $5$ 周心球和动脉干内膜局部增生，形成一对心球嵴和动脉干嵴。
- [ ] 相应嵴对向生长、中线融合，形成螺旋状主动脉肺动脉隔（aorticopulmonary septum）。
- [ ] 心球和动脉干被分隔成相互缠绕的主动脉和肺动脉。
- [ ] 主动脉和肺动脉起始处内膜各形成 $3$ 个薄片状隆起，演变为半月瓣。
- [ ] 室间孔封闭后，肺动脉干与右心室相通，主动脉与左心室相通。
- [ ] 静脉窦位于原始心房尾端背面；左、右角分别与同侧总主静脉、脐静脉和卵黄静脉相连。
- [ ] 起初窦房口在心房中央、两角对称；血多经右角回流，右角扩大，窦房口右移。
- [ ] 窦左角退化：近侧段成为冠状窦，远侧段成为左心房斜静脉的根部。
- [ ] 第 $7\sim 8$ 周静脉窦右角被吸收并入右心房，形成永久性右心房固有部（平滑部）；原始右心房变为右心耳（粗糙部）。
- [ ] 原始左心房最初只有一条原始肺静脉通入；该静脉分出左、右属支，再各分为两支。
- [ ] 左心房扩大，吸收原始肺静脉根部及左、右属支，使 $4$ 条肺静脉直接开口于左心房。
- [ ] 肺静脉及其属支参与形成永久性左心房固有部（平滑部）；原始左心房成为左心耳（粗糙部）。
:::
