# 一、大脑皮质

神经系统主要由神经组织构成，分为中枢神经系统和周围神经系统两部分。前者包括脑和脊髓，后者由脑神经节和脑神经、脊神经节和脊神经、自主神经节和自主神经组成。在中枢神经系统，神经元胞体集中的结构称灰质（gray matter）；不含神经元胞体、含大量神经纤维的结构称白质（white matter）。由于大脑和小脑的灰质在表层，故又称皮质（cortex），白质位于皮质下面。在大、小脑的白质内有灰质的团块，称神经核。脊髓的灰质位于中央，被白质包围。在周围神经系统，神经元胞体主要集中在神经节。

神经系统的功能活动是通过无数神经元及其突起建立的神经网络实现的。神经系统直接或间接调控机体各系统、器官的活动，对体内、外各种刺激迅速做出适应性反应。上一章把神经元、突触、胶质和纤维立住以后，本章按部位把中枢的皮质、脊髓和周围的神经节摊开，再写脑脊膜、血-脑屏障和脑脊液。

:::definition{label="神经系统"}
神经系统主要由神经组织构成，分为中枢神经系统和周围神经系统两部分。中枢包括脑和脊髓；周围由脑神经节和脑神经、脊神经节和脊神经、自主神经节和自主神经组成。功能活动通过无数神经元及其突起建立的神经网络实现，直接或间接调控各系统、器官，对体内、外刺激迅速做出适应性反应。
:::

:::definition{label="中枢神经系统"}
中枢神经系统包括脑和脊髓。神经元胞体集中处称灰质；不含胞体、含大量神经纤维处称白质。大脑和小脑的灰质在表层，又称皮质，白质在其下；白质内的灰质团块称神经核。脊髓的灰质位于中央，被白质包围。
:::

:::definition{label="周围神经系统"}
周围神经系统由脑神经节和脑神经、脊神经节和脊神经、自主神经节和自主神经组成。神经元胞体主要集中在神经节。
:::

:::definition{label="灰质"}
灰质（gray matter）是中枢神经系统中神经元胞体集中的结构。在大脑和小脑位于表层，称皮质；在脊髓位于中央，呈蝴蝶形。
:::

:::definition{label="白质"}
白质（white matter）是中枢神经系统中不含神经元胞体、含大量神经纤维的结构。大脑和小脑的白质位于皮质下面；脊髓的白质包围中央的灰质。
:::

:::definition{label="皮质"}
皮质（cortex）指大脑和小脑表层的灰质。因灰质铺在最外面而得名，与脊髓“灰质居中、白质在外”的排布相反。
:::

:::definition{label="神经核"}
神经核是大、小脑白质内的灰质团块，由神经元胞体聚集而成。小脑皮质唯一的传出纤维即终止于白质内的神经核。
:::

:::concept{term="先问胞体堆在哪：表层皮质、中央灰质，还是神经节"}
看见一张神经组织切片，先问胞体落在什么位置。表层成层排列的是大、小脑皮质；中央蝴蝶形的是脊髓灰质；周围一条神经干上成团的是神经节。白质和周围神经干里几乎没有胞体，只有纤维。把“灰质”听成“颜色深的随便一块”，会把皮质、神经核和神经节三本账并成一句。
:::

:::compare{title="中枢与周围、灰质与白质"}
| 项目 | 中枢神经系统 | 周围神经系统 |
|------|----------------|----------------|
| 组成 | 脑和脊髓 | 脑神经节和脑神经、脊神经节和脊神经、自主神经节和自主神经 |
| 胞体集中处 | 灰质（大脑小脑表层称皮质；脊髓居中；白质内团块称神经核） | 神经节 |
| 纤维集中处 | 白质（无胞体，含大量神经纤维） | 脑神经、脊神经、自主神经 |
| 灰–白排布 | 大脑小脑：灰在外、白在内；脊髓：灰在内、白在外 | 节内胞体与纤维束相间，无皮质之名 |
:::

:::pitfall{label="皮质只是表层灰质的别名，不要和白质里的神经核对调"}
皮质 = 大脑、小脑表层的灰质，不是“脑子表面那层结缔组织”（那是软膜）。白质里面还可以再出现灰质团块，叫神经核，位置在深部，不是又一层皮质。脊髓没有皮质这个词：灰质居中被白质包围。把神经核写成“深部皮质”，或把脑脊膜当成皮质，层次会整层错位。
:::

## （一）大脑皮质的神经元类型

大脑皮质中的神经元数量庞大，种类丰富，均为多极神经元。其中的高尔基Ⅰ型神经元包括大、中型锥体细胞（pyramidal cell）和梭形细胞，它们的轴突组成投射纤维，发向脑干或脊髓，或组成联合传出纤维发向同侧大脑皮质的其他部位和对侧大脑皮质，把该皮质区域形成的信息传递出去；高尔基Ⅱ型神经元主要包括大量颗粒细胞，以及水平细胞、星形细胞、篮状细胞、上行轴突细胞等，均属于中间神经元，有些是兴奋性的，有些是抑制性的，它们共同构成皮质内极其复杂的信息传递局部神经环路，主要接受来自神经系统其他部位传入的信息，并加以综合、贮存或传递给高尔基Ⅰ型神经元（图 8-1）。

:::definition{label="大脑皮质神经元"}
大脑皮质中的神经元数量庞大、种类丰富，均为多极神经元。按轴突长短分为高尔基Ⅰ型（大、中型锥体细胞和梭形细胞）和高尔基Ⅱ型（颗粒细胞、水平细胞、星形细胞、篮状细胞、上行轴突细胞等中间神经元）。
:::

:::definition{label="锥体细胞"}
锥体细胞（pyramidal cell）是大脑皮质的主要投射和联合传出神经元，属多极、高尔基Ⅰ型。胞体锥形；尖端发出较粗的顶树突伸向皮质表面，沿途发出许多小分支；周围发出水平走向的基树突；轴突自胞体底部与顶树突相对应的位置发出。大、中型者轴突可组成投射纤维或联合传出纤维。
:::

:::definition{label="顶树突"}
顶树突是锥体细胞胞体尖端发出的一条较粗树突，伸向皮质表面，沿途发出许多小分支。大、中型锥体细胞的顶树突一般伸至分子层。
:::

:::definition{label="基树突"}
基树突是锥体细胞胞体向周围发出的水平走向的树突，与顶树突共同扩展接受面积。
:::

:::definition{label="梭形细胞"}
梭形细胞是高尔基Ⅰ型神经元，主要位于多形细胞层，数量较少。树突自胞体上下两端发出，分别上行到皮质表层和下行至皮质深层；轴突起自下端树突主干根部，进入白质组成投射纤维和联合传出纤维。第 6 层的大梭形细胞是投射纤维的重要起点之一。
:::

:::definition{label="颗粒细胞"}
颗粒细胞是高尔基Ⅱ型中间神经元的主体，数量大。轴突一般很短，与邻近的锥体细胞形成突触；少数较长的轴突上行到皮质表面，与锥体细胞顶树突或水平细胞相联系。外颗粒层和内颗粒层都以颗粒细胞为主。
:::

:::definition{label="投射纤维"}
投射纤维是把该皮质区域形成的信息发向脑干或脊髓的传出纤维，主要起自第 5 层的锥体细胞和第 6 层的大梭形细胞。
:::

:::definition{label="联合传出纤维"}
联合传出纤维发向同侧大脑皮质的其他部位和对侧大脑皮质。起自第 3、5、6 层的锥体细胞和梭形细胞。进入对侧或同侧另一皮质区后即改称联合传入纤维。
:::

:::concept{term="先问轴突出不出皮质：高尔基Ⅰ型送出去，Ⅱ型在里面转"}
上一章按轴突长短把大神经元叫高尔基Ⅰ型、小神经元叫高尔基Ⅱ型。皮质里这本账立刻变成线路账：Ⅰ型的锥体细胞和梭形细胞把轴突送进白质，写成投射或联合传出；Ⅱ型的颗粒细胞、水平细胞、星形细胞、篮状细胞、上行轴突细胞都是中间神经元，轴突留在皮质里织局部环路。把“锥体细胞”听成唯一的皮质神经元，会把占数量优势的颗粒细胞和局部环路做丢。
:::

:::compare{title="高尔基Ⅰ型与高尔基Ⅱ型（大脑皮质）"}
| 项目 | 高尔基Ⅰ型 | 高尔基Ⅱ型 |
|------|------------|------------|
| 成员 | 大、中型锥体细胞；梭形细胞 | 大量颗粒细胞；水平细胞、星形细胞、篮状细胞、上行轴突细胞等 |
| 功能归属 | 把该区信息传出皮质 | 中间神经元（有兴奋性、有抑制性） |
| 轴突去向 | 投射纤维 → 脑干或脊髓；联合传出纤维 → 同侧其他部位或对侧皮质 | 主要在皮质内构成局部神经环路 |
| 主要接受 | 经Ⅱ型综合、贮存后传来的信息 | 来自神经系统其他部位的传入 |
| 所在层次线索 | 第 3、5 层锥体细胞；第 6 层梭形细胞 | 第 2、4 层颗粒细胞为主；第 1 层水平细胞和星形细胞 |
:::

:::pitfall{label="皮质神经元都是多极，不要按脊神经节的假单极来认"}
大脑皮质里没有假单极、也没有双极：全部是多极神经元。假单极堆在脊神经节和脑神经节，下一节才出场。切片上皮质里看见一个圆形小核，先想颗粒细胞，不要写成“感觉神经元的胞体跑进了皮质”。
:::

## （二）大脑皮质的分层

大脑皮质的神经元分层排列，除个别区域外，一般可分为 6 层（图 8-2，图 8-3）。

:::definition{label="大脑皮质六层"}
除个别区域外，大脑皮质一般分为 6 层，由表及里为：分子层、外颗粒层、外锥体细胞层、内颗粒层、内锥体细胞层、多形细胞层。第 1～4 层主要接受传入；投射和联合传出主要起自第 3、5、6 层。
:::

:::note{label="三种染色把六层写成三本不同的账"}
图 8-2 用三种方法看同一套层次：镀银显示神经元全貌和突起走向；尼氏染色只显示胞体，便于数细胞疏密；髓鞘染色显示纤维的水平与垂直走行。光镜 HE（图 8-3）能分出Ⅰ～Ⅵ层并认出锥体细胞，但突起和髓鞘都不如专项染色清楚。认层时先对图 8-2 的 A、B、C，再回到图 8-3 的低倍和高倍。
:::

### 1. 分子层

分子层（molecular layer）位于大脑皮质的最表面。神经元较少，主要是水平细胞和星形细胞。水平细胞的树突和轴突与皮质表面平行分布，并有许多与皮质表面平行的神经纤维。

:::definition{label="分子层"}
分子层（molecular layer）是大脑皮质最表面的一层。神经元较少，主要是水平细胞和星形细胞；水平细胞的树突和轴突与皮质表面平行，层内还有许多与表面平行的神经纤维。
:::

:::definition{label="水平细胞"}
水平细胞位于分子层，树突和轴突均与皮质表面平行走行。颗粒细胞少数较长的轴突上行到皮质表面后，可与水平细胞相联系。
:::

### 2. 外颗粒层

外颗粒层（external granular layer）由许多颗粒细胞和少量小型锥体细胞构成。锥体细胞胞体尖端发出一条较粗的顶树突，伸向皮质表面，沿途发出许多小分支。胞体还向周围发出一些水平走向的树突，称基树突。轴突自胞体底部与顶树突相对应的位置发出（图 8-4）。颗粒细胞的轴突一般很短，与邻近的锥体细胞形成突触联系，少数较长的轴突上行到皮质表面，与锥体细胞顶树突或水平细胞相联系。

:::definition{label="外颗粒层"}
外颗粒层（external granular layer）由许多颗粒细胞和少量小型锥体细胞构成。颗粒细胞轴突多很短，与邻近锥体细胞形成突触；少数较长者上行到皮质表面。
:::

:::note{label="锥体细胞的顶树突、基树突和轴突在第2层就开始认"}
教材把锥体细胞“一尖一底”的几何写在外颗粒层：尖端顶树突朝向表面，底部轴突朝向白质，侧面一圈基树突。后面第 3、5 层的中型和大型锥体细胞只是把这套几何放大，顶树突照样伸到分子层。图 8-4 用生物素标记把顶树突、基树突和轴突画全，是认锥体细胞的标准像。
:::

::figure{src="/images/histology/textbook/p0099_03.png" caption="图8-4 大脑锥体细胞光镜图（生物素标记、酶组织化学法）。示顶树突伸向皮质表面、基树突水平发出、轴突自胞体底部发出。" alt="生物素标记的锥体细胞：尖端顶树突、侧面基树突与底部轴突"}

### 3. 外锥体细胞层

外锥体细胞层（external pyramidal layer）较厚，主要包括中、小型锥体细胞，以中型占多数。它们的顶树突伸至分子层，轴突组成联合传出纤维。

:::definition{label="外锥体细胞层"}
外锥体细胞层（external pyramidal layer）较厚，主要包括中、小型锥体细胞，以中型占多数。顶树突伸至分子层，轴突组成联合传出纤维。
:::

### 4. 内颗粒层

内颗粒层（internal granular layer）细胞密集，主要是颗粒细胞。

:::definition{label="内颗粒层"}
内颗粒层（internal granular layer）细胞密集，主要是颗粒细胞。从丘脑来的感觉传入纤维主要进入此层与颗粒细胞形成突触。运动皮质此层不明显，视皮质此层特别发达。
:::

### 5. 内锥体细胞层

内锥体细胞层（internal pyramidal layer）主要由大、中型锥体细胞组成。此层锥体细胞的顶树突伸至分子层，轴突主要组成投射纤维。在中央前回运动区，此层有巨大锥体细胞，胞体高 $120\,\mu\mathrm{m}$，宽 $80\,\mu\mathrm{m}$，称贝兹细胞（Betz cell）（图 8-4）。

:::definition{label="内锥体细胞层"}
内锥体细胞层（internal pyramidal layer）主要由大、中型锥体细胞组成。顶树突伸至分子层，轴突主要组成投射纤维。运动皮质此层较发达。
:::

:::definition{label="贝兹细胞"}
贝兹细胞（Betz cell）是中央前回运动区内锥体细胞层的巨大锥体细胞，胞体高 $120\,\mu\mathrm{m}$、宽 $80\,\mu\mathrm{m}$。它是皮质里最大的锥体细胞，轴突加入投射纤维。
:::

:::pitfall{label="贝兹细胞只在中央前回第5层，不要写成所有锥体细胞都这么大"}
锥体细胞分大、中、小 3 型，遍布第 2、3、5、6 层；贝兹细胞是其中的巨型者，专写在中央前回运动区的内锥体细胞层。把每一颗锥体细胞都叫贝兹细胞，或把视皮质第 5 层那些较小的细胞也写成贝兹细胞，大小账和脑区账会一起错。
:::

### 6. 多形细胞层

多形细胞层（polymorphic layer）以梭形细胞为主，还有锥体细胞和上行轴突细胞。梭形细胞数量较少，其树突自胞体上下两端发出，分别上行到皮质表层和下行至皮质深层，轴突起自下端树突主干根部，进入白质组成投射纤维和联合传出纤维。

:::definition{label="多形细胞层"}
多形细胞层（polymorphic layer）以梭形细胞为主，还有锥体细胞和上行轴突细胞。梭形细胞树突分上下两支，轴突起自下端树突主干根部进入白质，组成投射纤维和联合传出纤维。
:::

:::definition{label="上行轴突细胞"}
上行轴突细胞是高尔基Ⅱ型中间神经元，胞体可见于多形细胞层等，轴突上行参与皮质内局部环路。
:::

:::compare{title="大脑皮质六层"}
| 层次 | 英文 | 主要细胞 | 纤维与联系要点 |
|------|------|----------|----------------|
| Ⅰ 分子层 | molecular layer | 水平细胞、星形细胞；神经元较少 | 树突、轴突及神经纤维多与表面平行 |
| Ⅱ 外颗粒层 | external granular layer | 许多颗粒细胞 + 少量小型锥体细胞 | 颗粒细胞短轴突联络邻近锥体细胞 |
| Ⅲ 外锥体细胞层 | external pyramidal layer | 中、小型锥体细胞，中型占多数；较厚 | 顶树突至分子层；轴突组成联合传出纤维 |
| Ⅳ 内颗粒层 | internal granular layer | 颗粒细胞，细胞密集 | 丘脑感觉传入主要在此与颗粒细胞突触 |
| Ⅴ 内锥体细胞层 | internal pyramidal layer | 大、中型锥体细胞；中央前回有贝兹细胞 | 顶树突至分子层；轴突主要组成投射纤维 |
| Ⅵ 多形细胞层 | polymorphic layer | 梭形细胞为主，兼有锥体细胞、上行轴突细胞 | 大梭形细胞轴突进入白质，组成投射和联合传出纤维 |
:::

大脑皮质的 6 层结构因不同脑区而存在差异，如中央前回（运动皮质）的第 4 层不明显，而第 5 层较发达；视皮质则第 4 层特别发达，而第 5 层的细胞较小。

:::compare{title="运动皮质与视皮质的层次差异"}
| 项目 | 中央前回（运动皮质） | 视皮质 |
|------|----------------------|--------|
| 第 4 层（内颗粒层） | 不明显 | 特别发达 |
| 第 5 层（内锥体细胞层） | 较发达；有贝兹细胞（$120\,\mu\mathrm{m}\times 80\,\mu\mathrm{m}$） | 细胞较小 |
| 功能对应 | 传出、投射为主，锥体细胞层加厚 | 感觉传入为主，颗粒细胞层加厚 |
:::

:::insight{label="感觉区加厚第4层，运动区加厚第5层"}
第 4 层是丘脑感觉传入的主要落点，视皮质把这一层写得很厚；第 5 层是投射纤维的主要起点，运动皮质把这一层写得很发达，还特设贝兹细胞。层次厚度不是装饰，是“进线多还是出线粗”的形态学后果。把六层背成六句与脑区无关的名单，运动区和感觉区的切片会分不开。
:::

大脑皮质的 1～4 层主要接受传入的信息。从丘脑来的感觉传入纤维主要进入第 4 层与颗粒细胞形成突触。起自同侧或对侧大脑半球的联合传出纤维，在进入皮质后即改称联合传入纤维，它们与第 2、3 层的锥体细胞形成突触。大脑皮质的投射纤维主要起自第 5 层的锥体细胞和第 6 层的大梭形细胞。联合传出纤维则起自第 3、5、6 层的锥体细胞和梭形细胞。皮质的第 2、3、4 层的颗粒细胞等高尔基Ⅱ型神经元主要与各层细胞相互联系，构成局部神经环路，对各种信息进行分析、整合和贮存（图 8-5）。通过此过程，产生高级神经活动，并经锥体细胞和梭形细胞传出，产生相应的反应。

:::definition{label="感觉传入纤维"}
从丘脑来的感觉传入纤维主要进入第 4 层，与颗粒细胞形成突触。这是皮质接受外周感觉信息的主要入口。
:::

:::definition{label="联合传入纤维"}
起自同侧或对侧大脑半球的联合传出纤维，进入另一皮质区后即改称联合传入纤维，与第 2、3 层的锥体细胞形成突触。
:::

:::concept{term="先问纤维刚进皮质还是正要离开：1～4 层接，3、5、6 层送"}
同一条联合纤维，在出发的皮质叫联合传出，进了对侧或同侧另一区就改叫联合传入——名字跟着方向走，不是两种结构。进线：丘脑感觉进第 4 层，联合传入进第 2、3 层。出线：投射主要起自第 5 层锥体细胞和第 6 层大梭形细胞；联合传出起自第 3、5、6 层。第 2、3、4 层的颗粒细胞把这些进线织成局部环路，分析、整合、贮存之后，再交给锥体细胞和梭形细胞送出去。
:::

:::compare{title="大脑皮质的传入与传出"}
| 纤维 | 进入或起自 | 主要联系 |
|------|------------|----------|
| 感觉传入（丘脑） | 进入第 4 层 | 与颗粒细胞突触 |
| 联合传入 | 进入后与第 2、3 层锥体细胞突触 | 来源是其他皮质区的联合传出 |
| 投射传出 | 主要起自第 5 层锥体细胞和第 6 层大梭形细胞 | 发向脑干或脊髓 |
| 联合传出 | 起自第 3、5、6 层锥体细胞和梭形细胞 | 发向同侧其他部位或对侧皮质 |
| 局部环路 | 第 2、3、4 层颗粒细胞等高尔基Ⅱ型 | 分析、整合和贮存，再交给Ⅰ型传出 |
:::

:::pitfall{label="联合传出进了对侧皮质就改称联合传入，不是又长出一种纤维"}
教材写“进入皮质后即改称”，强调的是同一类皮质–皮质纤维在出发端和到达端的名字。不要在切片上找“第三种联合纤维”，也不要把投射纤维（出皮质、下脑干或脊髓）和联合纤维（皮质与皮质之间）混成一条。图 8-5 里 a、b 是进来的虚线，c、d 是出去的实线，箭头标明信息传递方向。
:::

::figure{src="/images/histology/textbook/p0100_01.png" caption="图8-5 大脑皮质内局部神经元回路示意图。a. 感觉传入纤维；b. 联合传入纤维；c. 投射传出纤维；d. 联合传出纤维；↑示传递神经信息的方向；1. 分子层；2. 外颗粒层；3. 外锥体细胞层；4. 内颗粒层；5. 内锥体细胞层；6. 多形细胞层。" alt="大脑皮质六层局部回路：感觉与联合传入进入，投射与联合传出离开，箭头示信息传递方向"}

当大脑皮质受到体内、外环境因素变化的影响（如学习、运动等训练），其神经元的结构会发生相应的改变。同时，通过神经干细胞的增殖、分化，神经元的数量亦可发生变化。大脑皮质的这种适应性能力称为可塑性，在青少年时较明显，到老年时下降。

:::definition{label="大脑皮质可塑性"}
可塑性指大脑皮质随体内、外环境因素变化（如学习、运动等训练）而发生的适应性改变：神经元的结构会相应改变；通过神经干细胞的增殖、分化，神经元数量亦可变化。青少年时较明显，到老年时下降。
:::

:::insight{label="可塑性既改结构，也改数量"}
训练可以改神经元的突起和突触（结构账），神经干细胞还可以增殖分化补上或改写细胞数目（数量账）。上一章的神经干细胞在此落地：皮质不是出生后就锁死的六层积木。青少年明显、老年下降，是同一本适应性账在年龄轴上的斜率，不是两种机制。
:::

:::keypoint{label="大脑皮质先立灰白与多极分型，再立六层进出线"}
- 中枢：灰质（皮质或中央灰质、神经核）堆胞体，白质走纤维；周围：胞体在神经节。
- 皮质神经元均为多极；高尔基Ⅰ型（锥体、梭形）把信息送出皮质，高尔基Ⅱ型（颗粒细胞等）织局部环路。
- 六层：分子层 → 外颗粒层 → 外锥体细胞层 → 内颗粒层 → 内锥体细胞层 → 多形细胞层。
- 锥体细胞：顶树突朝表面、基树突水平、轴突自底部发出；贝兹细胞仅见于中央前回第 5 层（$120\,\mu\mathrm{m}\times 80\,\mu\mathrm{m}$）。
- 1～4 层接传入（丘脑→4；联合传入→2、3）；投射起自 5 和 6 层大梭形细胞；联合传出起自 3、5、6 层。
- 运动皮质第 4 层弱、第 5 层强；视皮质相反。可塑性：结构可改、数量可改，青少年明显。
:::

:::memory{label="本节必背要点"}
- [ ] 神经系统主要由神经组织构成，分中枢（脑和脊髓）和周围（脑神经节和脑神经、脊神经节和脊神经、自主神经节和自主神经）两部分。
- [ ] 灰质（gray matter）：中枢内神经元胞体集中的结构。白质（white matter）：不含胞体、含大量神经纤维。
- [ ] 大脑和小脑的灰质在表层，又称皮质（cortex），白质位于皮质下面；白质内的灰质团块称神经核。
- [ ] 脊髓灰质位于中央，被白质包围。周围神经系统的神经元胞体主要集中在神经节。
- [ ] 神经系统的功能活动通过无数神经元及其突起建立的神经网络实现；直接或间接调控各系统、器官，对体内、外刺激迅速做出适应性反应。
- [ ] 大脑皮质神经元数量庞大、种类丰富，均为多极神经元。
- [ ] 高尔基Ⅰ型：大、中型锥体细胞（pyramidal cell）和梭形细胞；轴突组成投射纤维（→脑干或脊髓）或联合传出纤维（→同侧其他部位或对侧皮质）。
- [ ] 高尔基Ⅱ型：大量颗粒细胞，以及水平细胞、星形细胞、篮状细胞、上行轴突细胞等，均属中间神经元，有兴奋性也有抑制性，构成皮质内局部神经环路。
- [ ] Ⅱ型主要接受其他部位传入，加以综合、贮存或传递给Ⅰ型。
- [ ] 除个别区域外，大脑皮质一般分 6 层。
- [ ] 分子层（molecular layer）：最表面；神经元较少，主要是水平细胞和星形细胞；水平细胞树突、轴突与表面平行，并有许多平行神经纤维。
- [ ] 外颗粒层（external granular layer）：许多颗粒细胞 + 少量小型锥体细胞。
- [ ] 锥体细胞：尖端发出较粗顶树突伸向表面并沿途分支；周围发出水平基树突；轴突自胞体底部与顶树突相对应的位置发出。
- [ ] 颗粒细胞轴突一般很短，与邻近锥体细胞突触；少数较长者上行到表面，与锥体细胞顶树突或水平细胞联系。
- [ ] 外锥体细胞层（external pyramidal layer）：较厚；中、小型锥体细胞，中型占多数；顶树突伸至分子层，轴突组成联合传出纤维。
- [ ] 内颗粒层（internal granular layer）：细胞密集，主要是颗粒细胞。
- [ ] 内锥体细胞层（internal pyramidal layer）：大、中型锥体细胞；顶树突伸至分子层，轴突主要组成投射纤维。
- [ ] 贝兹细胞（Betz cell）：中央前回运动区内锥体细胞层的巨大锥体细胞，胞体高 $120\,\mu\mathrm{m}$、宽 $80\,\mu\mathrm{m}$。
- [ ] 多形细胞层（polymorphic layer）：以梭形细胞为主，还有锥体细胞和上行轴突细胞。
- [ ] 梭形细胞数量较少；树突自上下两端发出，分别到表层和深层；轴突起自下端树突主干根部，进入白质组成投射纤维和联合传出纤维。
- [ ] 中央前回（运动皮质）：第 4 层不明显，第 5 层较发达。视皮质：第 4 层特别发达，第 5 层细胞较小。
- [ ] 第 1～4 层主要接受传入信息。
- [ ] 丘脑感觉传入纤维主要进入第 4 层与颗粒细胞形成突触。
- [ ] 联合传出纤维进入皮质后改称联合传入纤维，与第 2、3 层锥体细胞形成突触。
- [ ] 投射纤维主要起自第 5 层锥体细胞和第 6 层大梭形细胞。
- [ ] 联合传出纤维起自第 3、5、6 层的锥体细胞和梭形细胞。
- [ ] 第 2、3、4 层颗粒细胞等高尔基Ⅱ型构成局部神经环路，对信息分析、整合和贮存，产生高级神经活动，再经锥体细胞和梭形细胞传出。
- [ ] 可塑性：学习、运动等训练可改变神经元结构；神经干细胞增殖、分化可改变神经元数量；青少年较明显，老年下降。
:::
