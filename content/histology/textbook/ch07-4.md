# 四、神经干细胞

第三节把中枢四型和周围两型胶质立住以后，成体神经组织里还留着一类能自我更新、能多向分化的储备细胞。成体神经组织也和机体其他出生后组织一样，存在一类具有自我更新和多向分化潜能特性的细胞，称为神经干细胞（neural stem cell，NSC）。本节只把神经干细胞的分布、巢蛋白标志和分化去向立住；神经纤维、末梢和溃变再生各立后文。

:::definition{label="神经干细胞"}
神经干细胞（neural stem cell，NSC）是成体神经组织中具有自我更新和多向分化潜能的细胞。它们作为神经组织的一种储备细胞，替换自然死亡的细胞，并能在一定程度上参与神经组织损伤后的修复。
:::

:::definition{label="自我更新"}
自我更新指神经干细胞分裂后仍能产生保持干细胞特性的子代，使储备池在出生后长期维持，而不是一次分化就把自己做光。
:::

:::definition{label="多向分化潜能"}
多向分化潜能指神经干细胞在特定环境下可以增殖、迁移，并分化为神经元、星形胶质细胞及少突胶质细胞。它不能直接写成“什么细胞都能变成”，去向是神经组织内这三种。
:::

:::concept{term="先问巢蛋白，不要按星形胶质的外形一刀切"}
成体神经干细胞形态与星形胶质细胞相似，一般染色不易分辨。看见灰质或室管膜周围一颗“像星形胶质”的细胞，先问它有没有神经上皮干细胞蛋白（巢蛋白），再问它会不会增殖、迁移并分化成神经元、星形胶质细胞和少突胶质细胞。把形态听成鉴定，会把储备细胞账做进星形胶质里；把巢蛋白听成“所有胶质都有的中间丝”，又会和 GFAP 那本星形胶质丝账搅在一起。
:::

:::pitfall{label="成体神经组织不是一成不变，死亡神经元可以被替换"}
长期以来人们认为，包括人在内的成年哺乳动物神经组织一成不变，即神经组织中自然死亡的神经元或因病、伤死亡的神经元不能获得新生神经元的替换。神经干细胞的发现把这本旧账改写了：成体仍有储备细胞，可在一定程度上参与修复。这不等于“脑损伤都能自行长回原样”——分化需要特定环境，修复能力有限，后文中枢纤维再生仍受微环境和胶质瘢痕限制。
:::

出生后成体神经干细胞主要分布于大脑海马组织、脑和脊髓的室管膜下区（即室管膜周围区域），其形态与星形胶质细胞相似，因此一般染色不易分辨。但是，它们能够表达一种特殊的中间丝蛋白——神经上皮干细胞蛋白（neuroepithelial stem cell protein），又称巢蛋白（nestin），它已成为检测神经干细胞的常用标志物之一（图 7-15）。

:::definition{label="室管膜下区"}
室管膜下区（subependymal zone）即室管膜周围区域。出生后成体神经干细胞主要分布于大脑海马组织，以及脑和脊髓的室管膜下区。第三节的室管膜细胞衬在脑室和中央管腔面，干细胞则贴在这层上皮样衬里的深面一带，不要把衬腔的室管膜细胞直接写成神经干细胞。
:::

:::definition{label="海马中的神经干细胞"}
大脑海马组织是成体神经干细胞的主要分布部位之一。教材把它与脑和脊髓的室管膜下区并列，作为出生后仍能更新的两处储备地。
:::

:::definition{label="神经上皮干细胞蛋白"}
神经上皮干细胞蛋白（neuroepithelial stem cell protein）是神经干细胞表达的一种特殊中间丝蛋白，又称巢蛋白（nestin），是检测神经干细胞的常用标志物之一。图 7-15C 用巢蛋白免疫荧光显示细胞质。
:::

:::definition{label="巢蛋白"}
巢蛋白（nestin）即神经上皮干细胞蛋白。一般染色看不出成体神经干细胞与星形胶质细胞的差别，巢蛋白免疫细胞化学才把储备细胞从形态相似的胶质里捞出来。
:::

:::compare{title="神经干细胞与星形胶质细胞"}
| 项目 | 神经干细胞（NSC） | 星形胶质细胞 |
|------|-------------------|--------------|
| 形态 | 与星形胶质细胞相似，一般染色不易分辨 | 胞体星形，突起充填于神经元之间 |
| 常用中间丝标志 | 巢蛋白（nestin，神经上皮干细胞蛋白） | 胶质原纤维酸性蛋白（GFAP）构成胶质丝 |
| 分布 | 海马；脑和脊髓的室管膜下区 | 中枢灰质（原浆性）与白质（纤维性） |
| 增殖与分化 | 特定环境下可增殖、迁移，分化为神经元、星形胶质细胞及少突胶质细胞 | 已分化的中枢胶质；损伤时可增生形成胶质瘢痕 |
| 职分 | 储备细胞：替换自然死亡的细胞，一定程度上参与损伤修复 | 支持、绝缘、营养、脚板参与血–脑屏障；分泌神经营养因子 |
| 易混点 | 不要因外形相似就写成星形胶质细胞 | 不要因都会“修”，就把胶质瘢痕当成神经元再生 |
:::

:::note{label="一般染色不易分辨，检测靠巢蛋白"}
成体神经干细胞在 HE 等一般染色中几乎没有独立的外形线索。教材把巢蛋白写成常用标志物之一，图 7-15 用活细胞神经球、Hoechst 核染、巢蛋白免疫荧光和 BrdU 加 $\beta$ 微管蛋白Ⅲ，把“还是干细胞”和“已经变成神经元”分成两套染色账。
:::

神经干细胞在特定环境下可以增殖、迁移和分化为神经元、星形胶质细胞及少突胶质细胞。它们作为神经组织的一种储备细胞，替换自然死亡的细胞，并能够在一定程度上参与神经组织损伤后的修复。

:::definition{label="神经干细胞的三种分化去向"}
在特定环境下，神经干细胞可分化为：①神经元；②星形胶质细胞；③少突胶质细胞。这三种去向覆盖神经组织的冲动细胞和中枢主要大胶质，但不包括小胶质细胞（小胶质源自血液单核细胞）。
:::

:::compare{title="神经干细胞分化的三种去向"}
| 分化产物 | 在神经组织中的职分 | 不要写成 |
|----------|--------------------|----------|
| 神经元 | 接受刺激、整合信息、传导冲动 | 神经干细胞本身已经会发冲动 |
| 星形胶质细胞 | 支持、绝缘、营养，损伤时形成胶质瘢痕 | 分化成星形胶质就等于完成了神经元替换 |
| 少突胶质细胞 | 在中枢轴突上形成髓鞘 | 周围神经的髓鞘（周围由施万细胞形成） |
:::

:::insight{label="储备细胞改写了“成体神经元不能新生”那句旧结论"}
神经干细胞的发现，改变了人们长期以来对包括人在内的成年哺乳动物神经组织一成不变的观点。如今可以利用神经干细胞的特性，研究神经系统病伤后的修复机制，以及治疗神经系统的退行性和创伤性疾病。后文溃变再生会把这本账接到中枢微环境：干细胞和神经营养因子提供可能，胶质瘢痕和抑制因子仍挡住轴突支芽。本章插入框另写骨髓等来源的间充质干细胞与阿尔茨海默病，和本节的神经干细胞不是同一种细胞。
:::

:::pitfall{label="神经干细胞不是间充质干细胞，也不是肌卫星细胞"}
本节 NSC 住在海马和室管膜下区，标志是巢蛋白，去向是神经元和中枢胶质。插入框的间充质干细胞（MSC）来自骨髓、脐带血、脂肪组织，分化账是脂肪细胞、骨细胞和软骨细胞，并带免疫调节。骨骼肌表面的肌卫星细胞是肌组织的干细胞。三套名字都带“干细胞”，部位、标志和分化去向都不同。
:::

:::keypoint{label="神经干细胞先把分布、巢蛋白和三种去向立住"}
- 成体神经组织有 NSC：自我更新 + 多向分化，是储备细胞。
- 主要分布：大脑海马组织；脑和脊髓的室管膜下区（室管膜周围区域）。
- 形态像星形胶质细胞，一般染色不易分辨；常用标志是巢蛋白（神经上皮干细胞蛋白）。
- 特定环境下增殖、迁移，分化为神经元、星形胶质细胞及少突胶质细胞。
- 可替换自然死亡的细胞，并在一定程度上参与损伤修复；不等于中枢损伤都能自行恢复。
- 发现改写了“成体神经元不能新生”的旧观点，也为退行性和创伤性疾病的研究提供了细胞学基础。
:::
