# 二、白细胞

白细胞（leukocyte，white blood cell）是有核的球形细胞。它们从骨髓入血后一般于 24 小时内以变形运动的方式穿过微血管壁或毛细血管壁，进入结缔组织或淋巴组织，发挥防御和免疫功能。正常成人白细胞总数为 $(3.5\sim 9.5)\times 10^{9}/\mathrm{L}$（见表 5-1）。根据细胞质内有无特殊颗粒，可将其分为有粒白细胞和无粒白细胞。前者常简称粒细胞，根据其特殊颗粒的染色性，又可分为中性粒细胞、嗜酸性粒细胞和嗜碱性粒细胞 3 种。无粒白细胞有单核细胞和淋巴细胞两种，均含细小的嗜天青颗粒。

:::definition{label="白细胞"}
白细胞（leukocyte，white blood cell）是有核的球形细胞。从骨髓入血后一般于 24 小时内以变形运动穿过微血管壁或毛细血管壁，进入结缔组织或淋巴组织，发挥防御和免疫功能。正常成人 $(3.5\sim 9.5)\times 10^{9}/\mathrm{L}$。
:::

:::definition{label="有粒白细胞"}
有粒白细胞常简称粒细胞，胞质内含特殊颗粒。按特殊颗粒的染色性分为中性粒细胞、嗜酸性粒细胞和嗜碱性粒细胞 3 种。
:::

:::definition{label="无粒白细胞"}
无粒白细胞包括单核细胞和淋巴细胞两种，胞质内无特殊颗粒，但均含细小的嗜天青颗粒。
:::

:::concept{term="先问有没有特殊颗粒，再问颗粒染什么颜色"}
五种白细胞不要平铺成五个名词。第一刀：胞质里有没有特殊颗粒——有则是中性、嗜酸、嗜碱三种粒细胞；无则是单核和淋巴，只剩细小嗜天青颗粒。第二刀才问核的形状和颗粒颜色。把“白细胞”听成一种细胞，或把嗜天青颗粒当成特殊颗粒，都会把分类账做乱。
:::

:::compare{title="粒细胞与无粒细胞"}
| 项目 | 有粒白细胞（粒细胞） | 无粒白细胞 |
|------|----------------------|------------|
| 成员 | 中性粒细胞、嗜酸性粒细胞、嗜碱性粒细胞 | 单核细胞、淋巴细胞 |
| 特殊颗粒 | 有，按染色性分为中性、嗜酸性、嗜碱性 | 无 |
| 嗜天青颗粒 | 中性粒细胞约含颗粒总数的 $20\%$（溶酶体） | 均含细小嗜天青颗粒（溶酶体）；淋巴细胞可有可无 |
| 核 | 杆状或分叶（中性最典型）；嗜酸多为 2 叶；嗜碱可分叶、S 形或不规则 | 单核：肾形、马蹄铁形或不规则；淋巴：圆，一侧常有浅凹 |

:::

## 1. 中性粒细胞

中性粒细胞（neutrophilic granulocyte，neutrophil）是数量最多的白细胞，占白细胞的 $50\%\sim 70\%$。细胞直径 $10\sim 12\,\mu\mathrm{m}$。核呈深染的弯曲杆状或分叶状，分叶核一般为 $2\sim 5$ 叶，叶间由纤细的缩窄部相连，正常人多为 $2\sim 3$ 叶。核的叶数与细胞在血流中停留的时间呈正相关。当机体存在严重的细菌感染时，大量新生细胞从骨髓进入血液，杆状核与 2 叶核的细胞增多，称核左移；若 $4\sim 5$ 叶核的细胞增多，称核右移，表明骨髓造血功能发生障碍。

中性粒细胞的细胞质呈极浅的粉红色，含有许多细小颗粒，其中浅紫色的为嗜天青颗粒（azurophilic granule），浅红色的为特殊颗粒（specific granule）。嗜天青颗粒约占颗粒总数的 $20\%$，电镜下颗粒较大，直径 $0.6\sim 0.7\,\mu\mathrm{m}$，呈圆形或椭圆形，电子密度较高。它是一种溶酶体，含有酸性磷酸酶、髓过氧化物酶和多种酸性水解酶类等，能消化吞噬的细菌和异物。特殊颗粒约占颗粒总数的 $80\%$，电镜下颗粒较小，直径 $0.3\sim 0.4\,\mu\mathrm{m}$，呈哑铃形或椭圆形（图 5-4）。特殊颗粒是一种分泌颗粒，内含溶菌酶、吞噬素（phagocytin）等，吞噬素也称防御素（defensin），具有杀菌作用。

:::definition{label="中性粒细胞"}
中性粒细胞（neutrophilic granulocyte，neutrophil）是数量最多的白细胞，占 $50\%\sim 70\%$，直径 $10\sim 12\,\mu\mathrm{m}$。核呈深染的弯曲杆状或分叶状，一般为 $2\sim 5$ 叶，正常人多为 $2\sim 3$ 叶。胞质极浅粉红色，含浅紫色嗜天青颗粒和浅红色特殊颗粒。
:::

:::definition{label="核左移"}
核左移指血液中杆状核与 2 叶核的中性粒细胞增多。见于严重细菌感染时，大量新生细胞从骨髓进入血液。核的叶数与细胞在血流中停留的时间呈正相关，故“左”对应更年轻的核。
:::

:::definition{label="核右移"}
核右移指 $4\sim 5$ 叶核的中性粒细胞增多，表明骨髓造血功能发生障碍，血液中滞留的老龄细胞比例升高。
:::

:::definition{label="嗜天青颗粒"}
中性粒细胞的嗜天青颗粒（azurophilic granule）约占其颗粒总数的 $20\%$，浅紫色；电镜下较大，直径 $0.6\sim 0.7\,\mu\mathrm{m}$，圆或椭圆，电子密度高。它是溶酶体，含酸性磷酸酶、髓过氧化物酶和多种酸性水解酶，能消化吞噬的细菌和异物。单核细胞和淋巴细胞的细小嗜天青颗粒同样是溶酶体。
:::

:::definition{label="特殊颗粒（中性粒细胞）"}
中性粒细胞的特殊颗粒（specific granule）约占其颗粒总数的 $80\%$，浅红色；电镜下较小，直径 $0.3\sim 0.4\,\mu\mathrm{m}$，哑铃形或椭圆形。它是分泌颗粒，内含溶菌酶、吞噬素（phagocytin，也称防御素 defensin），具有杀菌作用。
:::

中性粒细胞和巨噬细胞一样具有很强的趋化作用和吞噬功能，其吞噬对象以细菌为主，也吞噬异物。中性粒细胞在吞噬并处理了大量细菌后，自身也死亡，成为脓细胞。中性粒细胞从骨髓进入血液，停留约 $6\sim 8$ 小时，然后离开，在结缔组织中存活 $2\sim 3$ 天。

:::definition{label="脓细胞"}
脓细胞是吞噬并处理了大量细菌后自身死亡的中性粒细胞。
:::

:::note{label="图5-5 中性粒细胞吞噬细菌电镜图（原图文件为空，此处只保留教材信息）"}
教材图 5-5 为中性粒细胞吞噬细菌电镜图，标注 1 细胞核、2 特殊颗粒、3 吞噬的细菌、4 糖原、5 大吞噬体。切片资源中对应文件为空，本页不插入该图。读法仍按：先认分叶核，再认特殊颗粒和吞噬体。
:::

:::pitfall{label="核左移不是核“长到左边”，核右移也不是核破了"}
核左移、核右移是按核分叶多少排列在谱系上的习惯说法：杆状和 2 叶偏“年轻”，$4\sim 5$ 叶偏“年老”。严重细菌感染时骨髓把新生细胞提前放进血液，杆状核和 2 叶核增多，叫核左移；骨髓造血障碍时老龄分叶核相对增多，叫核右移。不要在切片上找细胞核有没有往左侧偏，也不要把分叶核当成破碎的核。
:::

:::cause-effect{title="细菌感染时中性粒细胞怎样变成脓细胞"}
- 因：中性粒细胞有强趋化和吞噬功能，对象以细菌为主
- 因：嗜天青颗粒（溶酶体）消化细菌，特殊颗粒释放溶菌酶和防御素杀菌
- 果：吞噬并处理大量细菌后自身死亡，成为脓细胞
- 时间：入血停留约 $6\sim 8$ 小时，在结缔组织存活 $2\sim 3$ 天
:::

## 2. 嗜碱性粒细胞

嗜碱性粒细胞（basophilic granulocyte，basophil）数量最少，占白细胞的 $0\sim 1\%$。细胞直径 $10\sim 12\,\mu\mathrm{m}$，核分叶，或呈 S 形和不规则形，着色较浅。细胞质内含有嗜碱性颗粒，大小不等，分布不均，染成蓝紫色后可掩盖核（见图 5-4B）。嗜碱性颗粒属于分泌颗粒，内含有肝素、组胺、中性粒细胞趋化因子、嗜酸性粒细胞趋化因子等；细胞也可合成并分泌白三烯。嗜碱性粒细胞和肥大细胞均来源于骨髓中的同种造血祖细胞，分泌物质基本相同，作用也基本相同，既启动针对病原体的炎症反应，也参与过敏反应。嗜碱性粒细胞在组织中可存活 $10\sim 15$ 天。

:::definition{label="嗜碱性粒细胞"}
嗜碱性粒细胞（basophilic granulocyte，basophil）是数量最少的白细胞，占 $0\sim 1\%$，直径 $10\sim 12\,\mu\mathrm{m}$。核分叶，或呈 S 形、不规则形，着色较浅。胞质内嗜碱性颗粒大小不等、分布不均，蓝紫色，可掩盖核。颗粒内含肝素、组胺、中性粒细胞趋化因子、嗜酸性粒细胞趋化因子等；细胞还可合成并分泌白三烯。
:::

:::pitfall{label="嗜碱性粒细胞不是血液里的肥大细胞，只是同源、同职"}
二者来源于骨髓中的同种造血祖细胞，分泌物质基本相同，都启动炎症并参与过敏。但教材仍把它们写成两种细胞：嗜碱性粒细胞是血液中的粒细胞，肥大细胞定居在结缔组织、沿小血管分布。不要把血涂片上那颗被蓝紫颗粒盖住核的细胞直接叫肥大细胞，也不要以为二者可以互相改名。
:::

## 3. 嗜酸性粒细胞

嗜酸性粒细胞（eosinophilic granulocyte，eosinophil）直径为 $10\sim 15\,\mu\mathrm{m}$，占白细胞的 $0.5\%\sim 5\%$。核多为 2 叶，细胞质内充满粗大的鲜红色嗜酸性颗粒，直径约 $0.5\sim 1.0\,\mu\mathrm{m}$。电镜下，可见颗粒内基质中有长方形结晶体（见图 5-4C）。嗜酸性颗粒是一种特殊的溶酶体，除含一般溶酶体酶外，还含有阳离子蛋白、组胺酶、芳基硫酸酯酶。嗜酸性粒细胞也能做变形运动并具有趋化性，可受肥大细胞等释放的嗜酸性粒细胞趋化因子的作用影响，移行至有病原体或发生过敏反应的部位。该细胞能吞噬抗原抗体复合物，释放的多种溶酶体酶有杀菌作用，阳离子蛋白对寄生虫有很强的杀灭作用。在发生过敏反应的部位，其释放的组胺酶能分解组胺，芳基硫酸酯酶能灭活白三烯，从而抑制过敏反应。因此，过敏性疾病或寄生虫病患者的血液中嗜酸性粒细胞增多。嗜酸性粒细胞在血液中停留 $6\sim 8$ 小时后进入结缔组织，主要是肠道结缔组织，可存活 $8\sim 12$ 天。

:::definition{label="嗜酸性粒细胞"}
嗜酸性粒细胞（eosinophilic granulocyte，eosinophil）直径 $10\sim 15\,\mu\mathrm{m}$，占 $0.5\%\sim 5\%$。核多为 2 叶；胞质充满粗大鲜红色嗜酸性颗粒，直径约 $0.5\sim 1.0\,\mu\mathrm{m}$，电镜下颗粒基质中有长方形结晶体。颗粒是特殊溶酶体，含一般溶酶体酶、阳离子蛋白、组胺酶和芳基硫酸酯酶。
:::

:::insight{label="嗜酸性粒细胞同时杀菌、杀虫，又给过敏降温"}
阳离子蛋白杀寄生虫，溶酶体酶杀菌，吞噬抗原抗体复合物；组胺酶分解组胺、芳基硫酸酯酶灭活白三烯，把肥大细胞和嗜碱性粒细胞点燃的过敏往下压。所以过敏性疾病或寄生虫病时外周血嗜酸性粒细胞增多，读的是同一张趋化账单：细胞被召到有病原体或过敏的部位。主要归宿是肠道结缔组织，不是一直停在血液里。
:::

:::cause-effect{title="过敏或寄生虫病时为什么嗜酸性粒细胞会增多"}
- 因：肥大细胞等释放嗜酸性粒细胞趋化因子，细胞具有趋化性和变形运动
- 果：移行至有病原体或发生过敏反应的部位
- 果：阳离子蛋白杀寄生虫；组胺酶、芳基硫酸酯酶抑制过敏反应
- 果：过敏性疾病或寄生虫病患者血液中嗜酸性粒细胞增多
:::

## 4. 单核细胞

单核细胞（monocyte）是体积最大的白细胞，直径为 $14\sim 20\,\mu\mathrm{m}$，占白细胞的 $3\%\sim 8\%$。核呈肾形、马蹄铁形或扭曲折叠的不规则形，染色质颗粒细而松散，故着色较浅。细胞质丰富，因弱嗜碱性而呈灰蓝色，内含许多细小的淡紫色嗜天青颗粒，即溶酶体。单核细胞在血液中停留 $12\sim 48$ 小时，然后进入结缔组织或其他组织，分化为巨噬细胞等具有吞噬功能的细胞（见第 10 章）。

:::definition{label="单核细胞"}
单核细胞（monocyte）是体积最大的白细胞，直径 $14\sim 20\,\mu\mathrm{m}$，占 $3\%\sim 8\%$。核呈肾形、马蹄铁形或扭曲折叠的不规则形，染色质细而松散、着色浅。胞质丰富，弱嗜碱性呈灰蓝色，含细小淡紫色嗜天青颗粒（溶酶体）。入血停留 $12\sim 48$ 小时后进入组织，分化为巨噬细胞等。
:::

:::concept{term="最大那颗灰蓝细胞，先问它是不是巨噬细胞的血液前体"}
单核细胞在血液里只待 $12\sim 48$ 小时，真正的吞噬职分要等进入组织、分化为巨噬细胞之后才展开。血涂片上认它：体积最大，核肾形或马蹄铁形、着色浅，胞质灰蓝。不要把它当成“另一种粒细胞”，也不要在血液里找已经完全分化的巨噬细胞。
:::

## 5. 淋巴细胞

血液中的淋巴细胞大部分为直径 $6\sim 8\,\mu\mathrm{m}$ 的小淋巴细胞，小部分为直径 $9\sim 12\,\mu\mathrm{m}$ 的中淋巴细胞。在淋巴组织中还有直径 $13\sim 20\,\mu\mathrm{m}$ 的大淋巴细胞，但不存在于血液中。小淋巴细胞的核为圆形，一侧常有浅凹，染色质浓密呈块状，着色深。中淋巴细胞的核染色质略稀疏，着色略浅，有的可见核仁。淋巴细胞的细胞质为嗜碱性，呈晴空样蔚蓝色。小淋巴细胞的细胞质很少，在核周形成很薄的一圈，中淋巴细胞的细胞质较多；细胞质中可含嗜天青颗粒。电镜下，淋巴细胞的细胞质含游离核糖体，以及溶酶体、粗面内质网、高尔基复合体和线粒体等。

淋巴细胞不仅产生于骨髓，而且产生于淋巴器官和淋巴组织。根据发生来源、形态特点和免疫功能等方面的不同，可分为 3 类：

**（1）胸腺依赖性淋巴细胞（thymus dependent lymphocyte）** 简称 T 淋巴细胞，产生于胸腺，在血液淋巴细胞中约占总数的 $75\%$；其体积小，细胞质内含少量溶酶体。

**（2）骨髓依赖性淋巴细胞（bone marrow dependent lymphocyte）** 简称 B 淋巴细胞，产生于骨髓，约占 $10\%\sim 15\%$；其体积略大，一般不含溶酶体，有少量粗面内质网。B 淋巴细胞受抗原刺激后增殖分化为浆细胞，可产生抗体。

**（3）自然杀伤细胞（natural killer cell）** 简称 NK 细胞，产生于骨髓，约占 $10\%\sim 15\%$；为中淋巴细胞，溶酶体较多。

淋巴细胞是主要的免疫细胞，在机体防御疾病过程中发挥关键作用。

:::definition{label="淋巴细胞"}
淋巴细胞（lymphocyte）血液中大部分为直径 $6\sim 8\,\mu\mathrm{m}$ 的小淋巴细胞，小部分为直径 $9\sim 12\,\mu\mathrm{m}$ 的中淋巴细胞。大淋巴细胞直径 $13\sim 20\,\mu\mathrm{m}$，只存在于淋巴组织，不存在于血液中。胞质嗜碱性，呈晴空样蔚蓝色。不仅产生于骨髓，也产生于淋巴器官和淋巴组织，是主要的免疫细胞。
:::

:::definition{label="T 淋巴细胞"}
T 淋巴细胞即胸腺依赖性淋巴细胞（thymus dependent lymphocyte），产生于胸腺，约占血液淋巴细胞的 $75\%$。体积小，胞质内含少量溶酶体。
:::

:::definition{label="B 淋巴细胞"}
B 淋巴细胞即骨髓依赖性淋巴细胞（bone marrow dependent lymphocyte），产生于骨髓，约占 $10\%\sim 15\%$。体积略大，一般不含溶酶体，有少量粗面内质网。受抗原刺激后增殖分化为浆细胞，产生抗体。
:::

:::definition{label="NK 细胞"}
NK 细胞即自然杀伤细胞（natural killer cell），产生于骨髓，约占 $10\%\sim 15\%$。为中淋巴细胞，溶酶体较多。
:::

:::tip{label="血涂片上五种白细胞怎么认"}
- 最多、核分叶、胞质浅粉细颗粒 → 中性粒细胞。
- 核两叶、颗粒又红又粗 → 嗜酸性粒细胞。
- 最少、蓝紫颗粒盖住核 → 嗜碱性粒细胞。
- 最大、核肾形或马蹄铁、胞质灰蓝 → 单核细胞。
- 核圆深染、胞质只剩一圈晴空蓝 → 小淋巴细胞。
:::

:::keypoint{label="白细胞先按颗粒切开，再按核和颜色认人"}
- 白细胞是有核细胞，入血 24 小时内进入结缔组织或淋巴组织；按有无特殊颗粒分为粒细胞和无粒细胞。
- 中性最多：分叶核、核左移/右移、嗜天青颗粒（溶酶体）与特殊颗粒（杀菌），吞噬细菌后成脓细胞。
- 嗜酸：两叶核、鲜红粗颗粒、杀虫并抑制过敏；嗜碱：最少，颗粒含肝素、组胺等，与肥大细胞同源同职。
- 单核最大，入组织后变为巨噬细胞；淋巴分 T（约 $75\%$）、B（$10\%\sim 15\%$）、NK（$10\%\sim 15\%$），是主要免疫细胞。
:::

:::memory{label="本节必背要点"}
- [ ] 白细胞：有核球形细胞；入血后一般 24 小时内以变形运动穿过血管壁，进入结缔组织或淋巴组织，司防御和免疫。正常值 $(3.5\sim 9.5)\times 10^{9}/\mathrm{L}$。
- [ ] 有粒白细胞（粒细胞）：中性、嗜酸性、嗜碱性；无粒白细胞：单核细胞、淋巴细胞，均含细小嗜天青颗粒。
- [ ] 中性粒细胞占 $50\%\sim 70\%$，直径 $10\sim 12\,\mu\mathrm{m}$；核杆状或 $2\sim 5$ 叶，正常人多为 $2\sim 3$ 叶；叶数与血流停留时间正相关。
- [ ] 核左移：严重细菌感染时杆状核与 2 叶核增多；核右移：$4\sim 5$ 叶核增多，提示骨髓造血障碍。
- [ ] 嗜天青颗粒约 $20\%$：浅紫，直径 $0.6\sim 0.7\,\mu\mathrm{m}$，溶酶体（酸性磷酸酶、髓过氧化物酶、酸性水解酶）。
- [ ] 特殊颗粒约 $80\%$：浅红，直径 $0.3\sim 0.4\,\mu\mathrm{m}$，哑铃形或椭圆；分泌颗粒，含溶菌酶、吞噬素（防御素）。
- [ ] 中性粒细胞吞噬对象以细菌为主；大量吞噬后自身死亡成为脓细胞。入血 $6\sim 8$ 小时，结缔组织中存活 $2\sim 3$ 天。
- [ ] 嗜碱性粒细胞占 $0\sim 1\%$，直径 $10\sim 12\,\mu\mathrm{m}$；颗粒蓝紫、可掩盖核，含肝素、组胺、中性/嗜酸性粒细胞趋化因子；细胞分泌白三烯。组织中存活 $10\sim 15$ 天。
- [ ] 嗜碱性粒细胞与肥大细胞来源于同种造血祖细胞，分泌物质和作用基本相同，启动炎症并参与过敏；二者不是同一种细胞。
- [ ] 嗜酸性粒细胞占 $0.5\%\sim 5\%$，直径 $10\sim 15\,\mu\mathrm{m}$；核多为 2 叶；鲜红粗颗粒 $0.5\sim 1.0\,\mu\mathrm{m}$，内有长方形结晶体。
- [ ] 嗜酸性颗粒：特殊溶酶体，含阳离子蛋白、组胺酶、芳基硫酸酯酶；杀寄生虫、吞噬抗原抗体复合物、抑制过敏。过敏或寄生虫病时血液中增多。入血 $6\sim 8$ 小时，主要进入肠道结缔组织，存活 $8\sim 12$ 天。
- [ ] 单核细胞是体积最大的白细胞，占 $3\%\sim 8\%$，直径 $14\sim 20\,\mu\mathrm{m}$；核肾形/马蹄铁形/不规则，着色浅；胞质灰蓝，含嗜天青颗粒。入血 $12\sim 48$ 小时后入组织，分化为巨噬细胞等。
- [ ] 血液中小淋巴细胞 $6\sim 8\,\mu\mathrm{m}$，中淋巴细胞 $9\sim 12\,\mu\mathrm{m}$；大淋巴细胞 $13\sim 20\,\mu\mathrm{m}$ 只在淋巴组织、不在血液。胞质晴空样蔚蓝。
- [ ] T 淋巴细胞产生于胸腺，约占 $75\%$，体积小，含少量溶酶体。
- [ ] B 淋巴细胞产生于骨髓，约占 $10\%\sim 15\%$；一般不含溶酶体，有少量粗面内质网；受抗原刺激后分化为浆细胞，产生抗体。
- [ ] NK 细胞产生于骨髓，约占 $10\%\sim 15\%$；为中淋巴细胞，溶酶体较多。
- [ ] 淋巴细胞是主要的免疫细胞，产生于骨髓、淋巴器官和淋巴组织。
:::
