# 五、乳腺

乳腺的主要功能是分泌乳汁、哺育婴儿，不属于女性生殖器官。结构因年龄和生理状况而异。乳腺发育始于青春期。妊娠和哺乳期的乳腺有泌乳活动，称为活动期乳腺；无泌乳活动的乳腺称为静止期乳腺。

:::definition{label="乳腺"}
乳腺主要功能是分泌乳汁、哺育婴儿，不属于女性生殖器官。因与卵巢激素联动发育并在妊娠、哺乳期泌乳，教材列入本章。
:::

:::definition{label="静止期乳腺"}
静止期乳腺指绝经前没有分泌功能的乳腺。导管和腺体均不发达，腺泡小而少，脂肪组织和结缔组织极为丰富。
:::

:::definition{label="活动期乳腺"}
妊娠期和哺乳期的乳腺分泌乳汁，合称活动期乳腺。妊娠期以导管和腺泡迅速增生为主，哺乳期腺体更发达、腺腔更大并处于不同分泌时相。
:::

:::concept{term="先问此刻有没有泌乳，再问切面是脂肪多还是腺泡多"}
看见乳腺，先把两本账切开：没有泌乳是静止期，妊娠和哺乳才是活动期。再看实质：脂肪和结缔组织铺满、腺泡小而少，是静止期；小导管和腺泡迅速增多、脂肪减少，是妊娠期；结缔组织更少、腺腔扩大并充满乳汁、上皮可高柱状到扁平，是哺乳期（泌乳期）。把三种状态听成“同一种复管泡状腺切面”，初乳小体和顶浆分泌会从静止期里凭空冒出来。
:::

乳腺由结缔组织分隔为 $15\sim 25$ 个叶，每叶又分为若干小叶，每个小叶属一个复管泡状腺。腺泡上皮为单层立方或柱状上皮，腺腔很小，腺细胞基底面有基膜，腺上皮和基膜之间有肌上皮细胞。导管包括小叶内导管、小叶间导管和总导管。小叶内导管管壁多为单层立方或柱状上皮，小叶间导管管壁则为复层柱状上皮。总导管又称输乳管，开口于乳头，管壁上皮与乳头表皮相续，为复层扁平上皮。小叶间结缔组织内有大量的脂肪细胞。

:::definition{label="乳腺小叶"}
结缔组织将乳腺分成 $15\sim 25$ 个叶，每叶再分若干小叶。每个小叶是一个复管泡状腺。
:::

:::definition{label="腺泡"}
腺泡上皮为单层立方或柱状，腺腔很小。腺细胞基底面有基膜，腺上皮与基膜之间有肌上皮细胞。肌上皮收缩有助于把乳汁挤入导管。
:::

:::definition{label="肌上皮细胞"}
位于腺上皮和基膜之间。不要和卵巢门细胞、子宫平滑肌并成一类；它是腺泡外周的收缩细胞。
:::

:::definition{label="小叶内导管"}
管壁多为单层立方或柱状上皮，与腺泡上皮相近。
:::

:::definition{label="小叶间导管"}
管壁为复层柱状上皮。比小叶内导管多一层“复层”的账。
:::

:::definition{label="输乳管"}
总导管又称输乳管，开口于乳头。管壁上皮与乳头表皮相续，为复层扁平上皮。
:::

:::compare{title="三级导管上皮"}
| 导管 | 上皮 |
|------|------|
| 小叶内导管 | 单层立方或柱状 |
| 小叶间导管 | 复层柱状 |
| 输乳管（总导管） | 复层扁平，与乳头表皮相续 |
:::

## （一）静止期乳腺

静止期乳腺是指绝经前没有分泌功能的乳腺，结构特点是：导管和腺体均不发达，腺泡小而少，脂肪组织和结缔组织极为丰富（图 19-14）。静止期乳腺随月经周期有些变化：月经来潮前，腺泡与导管增生和充血，乳腺可略增大；月经停止后这一现象消失。

:::definition{label="静止期的周期微变"}
月经来潮前腺泡与导管增生和充血，乳腺可略增大；月经停止后消失。这只是轻度波动，并不等于进入活动期。
:::

::figure{src="/images/histology/textbook/p0219_01.png" caption="图19-14 静止期乳腺光镜图（低倍）。示小叶内少量导管和腺泡，小叶间大量脂肪组织和结缔组织。" alt="静止期乳腺低倍：小叶呈岛状，腺泡和导管较少，周围大量空泡状脂肪细胞和纤维间隔"}

:::pitfall{label="静止期不是没有腺，只是腺泡小而少、脂肪特别多"}
绝经前未泌乳的乳腺仍有导管和小腺泡，只是被脂肪和结缔组织衬得很稀疏。写成“静止期完全没有腺体”，和妊娠期的对照就失去起点。
:::

## （二）活动期乳腺

妊娠期和哺乳期的乳腺分泌乳汁，称为活动期乳腺。妊娠期在雌激素和孕激素作用下，乳腺内小导管和腺泡迅速增生，腺泡增大，结缔组织和脂肪组织相应减少。妊娠后期，乳腺在催乳素作用下，腺泡开始分泌。乳腺为顶浆分泌腺。第一次分泌给新生儿的乳汁叫初乳（colostrum），与规律性的泌乳相比，它含有少量脂肪和多量蛋白质，富含抗体。初乳中还常含有吞噬脂滴的巨噬细胞，称为初乳小体（colostrum corpuscle）。

哺乳期乳腺结构与妊娠期乳腺相似，但结缔组织更少，腺体发育更好，腺泡腔增大，腺泡可处于不同的分泌时期（图 19-15）。腺上皮形态随分泌周期的时相不同而异，可呈高柱状、立方形，甚至呈扁平状，腺腔内充满乳汁。电镜下，腺细胞内粗面内质网和线粒体丰富，并可见分泌颗粒和脂滴。停止哺乳后腺体停止分泌，逐渐萎缩，结缔组织增多，乳腺进入静止期。

:::definition{label="妊娠期乳腺"}
雌激素和孕激素使小导管和腺泡迅速增生，腺泡增大，结缔组织和脂肪相应减少。妊娠后期催乳素促使腺泡开始分泌。
:::

:::definition{label="顶浆分泌"}
乳腺为顶浆分泌腺。分泌时顶部胞质连同乳汁成分进入腺腔，不是单纯的局浆分泌。
:::

:::definition{label="初乳"}
初乳（colostrum）是第一次分泌给新生儿的乳汁。与规律性泌乳相比，含少量脂肪和多量蛋白质，富含抗体。
:::

:::definition{label="初乳小体"}
初乳小体（colostrum corpuscle）是初乳中吞噬脂滴的巨噬细胞。它不是脱落的腺上皮细胞，也不是脂肪细胞本身。
:::

:::definition{label="哺乳期乳腺"}
与妊娠期相似，但结缔组织更少，腺体更发达，腺泡腔增大。腺泡可处于不同分泌时期，上皮可呈高柱状、立方形甚至扁平，腺腔内充满乳汁。电镜下 RER、线粒体丰富，可见分泌颗粒和脂滴。
:::

:::definition{label="断乳后复旧"}
停止哺乳后腺体停止分泌，逐渐萎缩，结缔组织增多，乳腺回到静止期。
:::

::figure{src="/images/histology/textbook/p0219_02.png" caption="图19-15 哺乳期乳腺光镜图（低倍）。示密集扩张的腺泡，腔内充满乳汁，结缔组织很少。" alt="哺乳期乳腺低倍：腺泡极度扩张、上皮变薄，腔内红染乳汁，小叶间脂肪和纤维明显减少"}

:::compare{title="静止期、妊娠期与哺乳期（泌乳期）乳腺"}
| 项目 | 静止期 | 妊娠期 | 哺乳期（泌乳期） |
|------|--------|--------|------------------|
| 是否活动期 | 否 | 是（活动期） | 是（活动期） |
| 激素 | 随月经周期轻度波动 | 雌激素 + 孕激素促增生；后期催乳素启动分泌 | 催乳素维持泌乳 |
| 腺泡 / 导管 | 不发达，腺泡小而少 | 小导管和腺泡迅速增生、腺泡增大 | 腺体更好，腺腔更大，可处于不同分泌时相 |
| 脂肪 / 结缔组织 | 极为丰富 | 相应减少 | 更少 |
| 上皮形态 | 单层立方或柱状，腺腔很小 | 增生，后期开始分泌 | 高柱状、立方甚至扁平 |
| 分泌 | 无泌乳 | 后期开始；第一次为初乳 | 腔内充满乳汁；顶浆分泌 |
| 特殊结构 | 经前可轻度增生充血 | 初乳、初乳小体 | 电镜见 RER、线粒体、分泌颗粒和脂滴 |
:::

:::note{label="初乳与规律性乳汁"}
| 项目 | 初乳 | 规律性泌乳 |
|------|------|------------|
| 时机 | 第一次分泌给新生儿 | 哺乳期持续分泌 |
| 脂肪 | 少量 | 较多 |
| 蛋白质 / 抗体 | 多量蛋白质，富含抗体 | 相对初乳较少强调抗体 |
| 细胞成分 | 常含初乳小体（吞噬脂滴的巨噬细胞） | 不以初乳小体为特征 |
:::

:::pitfall{label="乳腺不属于生殖器官，不要把腺泡写成卵泡或子宫腺"}
卵泡在卵巢皮质，子宫腺在内膜固有层，乳腺腺泡是复管泡状腺的分泌部。初乳小体是巨噬细胞，不是“乳汁凝固体”或脱落腺细胞。三套腺体不要并成一句“女性的腺”。
:::

:::pitfall{label="妊娠期已经开始长腺体，哺乳期才是腺腔充满乳汁的高峰"}
活动期包括妊娠期和哺乳期两段。妊娠期主账是增生并在后期启动分泌（初乳）；哺乳期主账是腺腔扩大、上皮随分泌时相变形、腔内充满乳汁。把妊娠期直接写成图 19-15 那种胀满腺泡，时间轴会提前一截。
:::

:::insight{label="脂肪让位给腺泡，催乳素再下令出奶，断乳后结缔组织把地方要回去"}
静止期看脂肪，妊娠期看腺泡增生，哺乳期看腺腔和乳汁。肌上皮把乳汁挤进导管，输乳管以复层扁平上皮开口于乳头。激素一撤，腺体萎缩，脂肪和结缔组织重新铺回来，又是静止期。
:::

:::keypoint{label="乳腺先立复管泡状腺和三级导管，再把静止、妊娠、泌乳三态收口"}
- 不属于生殖器官； $15\sim 25$ 叶，每小叶一个复管泡状腺。
- 腺泡：单层立方或柱状 + 基膜 + 肌上皮。
- 导管：小叶内单层立方/柱状 → 小叶间复层柱状 → 输乳管复层扁平。
- 静止期：腺少、脂肪多；经前可轻度增生充血。
- 妊娠期：E + P 促增生，后期催乳素启动分泌；初乳脂肪少、蛋白和抗体多，含初乳小体。
- 哺乳期：结缔组织更少，腺腔大，上皮形态随分泌时相而变，顶浆分泌。
- 断乳后复旧为静止期。
:::

## 本章小结

女性生殖系统有两个重要器官：卵巢和子宫。卵巢被覆表面上皮，上皮深部为白膜。实质包括皮质和髓质。皮质中有各种卵泡：原始卵泡、初级卵泡、次级卵泡和成熟卵泡。成熟卵泡排卵，排卵后形成黄体。黄体主要有颗粒黄体细胞（主要分泌孕激素和松弛素）和膜黄体细胞（与颗粒黄体细胞协同分泌雌激素）。黄体发育取决于排出的卵是否受精，分别形成月经黄体（卵子未受精）和妊娠黄体（卵子受精），最终都将变成白体。卵泡在发育的不同阶段退化成为闭锁卵泡。髓质为疏松结缔组织。子宫壁可分内膜、肌层和外膜 3 层。自青春期开始，子宫内膜呈周期性变化，即月经周期，可分为月经期、增生期和分泌期。子宫内膜可分为功能层和基底层，月经期功能层发生脱落；增生期子宫内膜基底层增生修复，月经周期第 $14$ 天时卵巢内通常有一个卵泡发育成熟并排卵，子宫内膜随之转入分泌期；分泌期子宫内膜继续增生变厚，有利于胚泡的植入。

卵巢和子宫内膜周期性变化受下丘脑–垂体–性腺轴调控。下丘脑和垂体产生的激素可促进卵巢卵泡生长、发育成熟并分泌大量雌激素。雌激素可使子宫内膜从月经期转入增生期。雌激素达到一定浓度时，反馈作用于下丘脑和垂体，促进卵泡成熟、排卵并形成黄体，促使子宫内膜进入分泌期。同时，黄体产生的孕激素反馈作用于下丘脑和垂体，引起一系列变化，导致黄体退化，子宫内膜进入月经期。上述循环周而复始，下丘脑和垂体有节律地调节卵巢活动周期与子宫内膜周期变化，以适应排卵、受精、胚泡植入和生长发育的需要。

:::definition{label="本章结构通式"}
女性生殖系统 = 卵巢（卵泡发育 + 排卵 + 黄体激素）+ 输卵管（受精与输送）+ 子宫（内膜周期 + 孕育）+ 阴道（通道与乳酸防御）+ 外生殖器。乳腺泌乳，列入本章但不是生殖器官。卵泡四阶段以有无卵泡腔和是否优势成熟为尺子；排卵后红体 → 黄体 → 白体。内膜功能层剥脱、基底层保留；增生期对卵泡期，分泌期对黄体期，月经期对黄体退化。
:::

:::compare{title="全章结构与细胞速查"}
| 结构 | 关键形态 | 职分 |

:::keypoint{label="全章把四级卵泡对内膜三期、黄体激素对分泌期收口"}
- 次级卵泡已有腔；次级卵母细胞要到排卵前才出现。
- 黄体不是卵泡的别名；红体是早期黄体，白体是瘢痕。
- 功能层剥脱，基底层保留。
- 增生期对雌激素（卵泡期），分泌期对孕激素（黄体期），月经期对黄体退化。
- 宫颈黏膜不剥脱；外口移行区是宫颈癌好发部位。
- 阴道靠糖原和乳杆菌产酸；乳腺三态以腺泡多少和是否充奶来认。
:::

:::memory{label="本章小结必背"}
- [ ] 女性生殖系统两个重要器官是卵巢和子宫。
- [ ] 卵巢被覆表面上皮，深部为白膜；实质分皮质和髓质。
- [ ] 皮质中有原始卵泡、初级卵泡、次级卵泡和成熟卵泡。
- [ ] 成熟卵泡排卵，排卵后形成黄体。
- [ ] 颗粒黄体细胞主要分泌孕激素和松弛素；膜黄体细胞与之协同分泌雌激素。
- [ ] 未受精形成月经黄体，受精形成妊娠黄体，最终都变成白体。
- [ ] 卵泡在发育不同阶段退化成为闭锁卵泡。
- [ ] 髓质为疏松结缔组织。
- [ ] 子宫壁分内膜、肌层和外膜 3 层。
- [ ] 月经周期分为月经期、增生期和分泌期。
- [ ] 内膜分功能层和基底层；月经期功能层脱落，基底层保留并在增生期修复。
- [ ] 第 $14$ 天通常排卵，内膜转入分泌期；分泌期内膜继续增厚，利于胚泡植入。
- [ ] 卵巢和内膜周期受下丘脑–垂体–性腺轴调控。
- [ ] 雌激素使内膜从月经期转入增生期；达到一定浓度后促进成熟、排卵并形成黄体，内膜进入分泌期。
- [ ] 孕激素反馈导致黄体退化，内膜进入月经期。循环周而复始，以适应排卵、受精、植入和发育。
:::

## 插入框：HPV 感染与宫颈癌

宫颈癌是最常见的妇科恶性肿瘤之一，人乳头瘤病毒（HPV）感染是导致宫颈癌的元凶。HPV 传播方式主要有 3 种：性接触传播、垂直传播、皮肤黏膜接触传播。

HPV 根据致癌潜力分为高危型和低危型。低危型 HPV 常引起尖锐湿疣等疾病，高危型 HPV 持续感染可引起宫颈癌。$80\%$ 以上的女性一生中至少有过 1 次 HPV 感染，其中 $90\%$ 以上可在 2 年内自然清除，不足 $1\%$ 的患者发展至宫颈癌。目前对 HPV 感染尚无有效的杀灭病毒的药物。除了调整生活行为方式外，HPV 疫苗接种是宫颈癌最有效的一级防治措施。$9\sim 45$ 岁的女性都推荐接种疫苗。

目前已发现 $150$ 余种 HPV 亚型，其中 HPV 16、18 是导致宫颈癌的最主要病毒亚型。HPV 疫苗可以预防部分特定 HPV 亚型感染：二价疫苗预防 16、18 亚型；四价疫苗预防 6、11、16、18 亚型；9 价疫苗预防 6、11、16、18、31、33、45、52、58 亚型。HPV 疫苗不能 $100\%$ 预防宫颈癌，所以早期筛查是防治宫颈癌的关键，目前多采用 HPV-DNA 检测。早期宫颈癌治疗效果较好，晚期宫颈癌的治疗效果仍不理想。

:::insight{label="移行区本来就是柱状与复层扁平的交界，高危HPV在这里最容易把储备细胞的修复账改写成癌"}
第 19-3 节已经写过：宫颈外口是单层柱状与复层扁平的移行区，储备细胞可化生也可癌变。HPV 把这本形态账连到病因上：多数感染会被清除，持续的高危型感染才走向宫颈癌。疫苗挡特定亚型，筛查（HPV-DNA）补上疫苗挡不住的那一截。
:::

:::pitfall{label="接种疫苗不等于可以不做筛查"}
疫苗只能预防部分亚型，不能 $100\%$ 预防宫颈癌。教材把早期筛查写成防治关键，目前多用 HPV-DNA 检测。把疫苗听成“一针终身无癌”，晚期治疗效果不理想那本账会被忽略。
:::
