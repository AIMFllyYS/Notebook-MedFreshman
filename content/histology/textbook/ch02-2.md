# 二、腺上皮和腺

腺是以腺上皮为主要成分的器官或结构。腺上皮由腺细胞组成，以分泌功能为主，分泌物有酶类、黏液和激素等。本章只介绍外分泌腺的一般结构。

:::definition{label="腺上皮"}
腺上皮是由腺细胞组成的、以分泌功能为主的上皮。腺细胞的分泌物有酶类、黏液和激素等。
:::

:::definition{label="腺"}
腺（gland）是以腺上皮为主要成分的器官或结构。
:::

:::definition{label="外分泌腺"}
有的腺分泌物经导管排至体表或器官腔内，称外分泌腺（exocrine gland），如汗腺、唾液腺等。
:::

:::definition{label="内分泌腺"}
有的腺没有导管，分泌物（为激素）一般释放入血液，称内分泌腺（endocrine gland），如甲状腺、肾上腺等。
:::

:::pitfall{label="外分泌腺与内分泌腺不要按“是否分泌”来分"}
两类腺都有分泌功能。区分依据是排出途径：外分泌腺有导管，分泌物排至体表或器官腔；内分泌腺无导管，激素一般入血。不能把“腺”等同于外分泌腺，也不能把内分泌腺误记为没有腺上皮。
:::

## 外分泌腺的组成与形态分类

只有少数外分泌腺是在解剖学中可看到的独立器官，如 3 对大唾液腺和胰腺；大多数为器官中的微细结构，只能在显微镜下观察到，如皮肤中的汗腺和皮脂腺、胃壁中的胃腺。外分泌腺一般由分泌部和导管两部分组成。

根据导管有无分支，外分泌腺可分为单腺和复腺。分泌部的形状有管状、泡状或管泡状，因此，外分泌腺按形态可分为单管状腺、单泡状腺、复管状腺、复泡状腺和复管泡状腺等。

### 1. 分泌部

:::definition{label="分泌部"}
分泌部（secretory portion）一般由单层腺细胞组成，中央有腔。泡状和管泡状的分泌部常称腺泡（acinus）。腺细胞多呈锥形，由于分泌物不同而形态各异。
:::

:::concept{term="腺泡"}
泡状和管泡状的分泌部常称腺泡（acinus）。在消化系统和呼吸系统中，腺细胞一般可分为浆液细胞和黏液细胞；腺细胞在其他系统中各具特点，将于各章详述。
:::

:::definition{label="浆液细胞"}
浆液细胞（serous cell）的核为圆形，位于细胞偏基底部；基底部细胞质呈强嗜碱性染色，顶部细胞质含较多嗜酸性的分泌颗粒，称酶原颗粒（zymogen granule），不同的浆液细胞含不同的酶类。电镜下可见细胞质中，尤其在基底部细胞质有密集的粗面内质网；在核上区可见较发达的高尔基复合体和数量不等的分泌颗粒，这些都是蛋白质分泌细胞的超微结构特点。
:::

这些细胞器的规律性分布也反映了腺细胞合成与分泌蛋白质的过程。所有腺细胞的功能都受自主神经和激素的精细调节，属于调节型分泌细胞，因此分泌蛋白质以及糖蛋白、肽类的腺细胞在非分泌时相，细胞质内可见大量贮存的分泌颗粒。

:::definition{label="黏液细胞"}
黏液细胞（mucous cell）的核为扁圆形，位于细胞基底部；除在核周的少量细胞质呈嗜碱性染色外，大部分细胞质几乎不着色，呈泡沫或空泡状。电镜下可见基底部细胞质中有一定量的粗面内质网，核上区有发达的高尔基复合体和极丰富的粗大黏原颗粒。杯状细胞也是一种散在分布的黏液细胞。
:::

::figure{src="/images/histology/textbook/p0037_02.png" caption="图2-11 浆液细胞和黏液细胞超微结构模式图。A. 浆液细胞；B. 黏液细胞。" alt="浆液细胞与黏液细胞超微结构模式图，分别示酶原颗粒和黏原颗粒"}

浆液细胞和黏液细胞可以分别组成浆液腺泡（serous acinus）和黏液腺泡（mucous acinus）；由这两种腺细胞共同组成的腺泡，称混合腺泡（mixed acinus）。分泌部完全由浆液腺泡构成的腺体，称浆液腺（serous gland），如腮腺；完全由黏液腺泡构成的腺体称黏液腺（mucous gland），如十二指肠腺；由 3 种腺泡共同构成的腺体称混合腺（mixed gland），如下颌下腺和舌下腺。

:::concept{term="浆半月"}
大部分混合腺泡主要由黏液细胞组成，少量浆液细胞位于腺泡的底部，在切片中呈半月形结构，称浆半月（serous demilune）。黏液细胞间隙局部扩大，形成分泌小管，浆半月的分泌物可经分泌小管释放入腺泡腔内。
:::

:::concept{term="肌上皮细胞"}
在腺细胞与基膜之间有扁平、多突起的肌上皮细胞（myoepithelial cell），细胞质内含肌动蛋白丝，其收缩有助于排出分泌物。
:::

::figure{src="/images/histology/textbook/p0037_01.png" caption="图2-10 下颌下腺光镜图。S. 浆液腺泡；M. 黏液腺泡；SD. 浆半月；D. 导管。" alt="下颌下腺光镜图，示浆液腺泡、黏液腺泡、浆半月和导管"}

:::note{label="腺泡与腺体的对应"}
- 浆液腺泡、黏液腺泡、混合腺泡：按单个腺泡的细胞组成划分。
- 浆液腺、黏液腺、混合腺：按整腺所含腺泡种类划分。腮腺为浆液腺，十二指肠腺为黏液腺，下颌下腺和舌下腺为混合腺。
:::

### 2. 导管

:::definition{label="导管"}
导管（duct）直接与分泌部通连，由单层或复层上皮构成，将分泌物排至体表或器官腔内。有的导管上皮细胞还可分泌或吸收水和电解质。
:::

:::keypoint{label="核心结论"}
外分泌腺由分泌部和导管组成，按导管分支和分泌部形状分为单管状、单泡状、复管状、复泡状和复管泡状等。消化、呼吸系统中腺细胞分浆液细胞与黏液细胞，可组成浆液腺泡、黏液腺泡和混合腺泡；混合腺泡常见浆半月。肌上皮细胞收缩有助于排出分泌物。
:::

:::memory{label="本节必背要点"}
- [ ] 腺是以腺上皮为主要成分的器官或结构；腺上皮以分泌为主，分泌物有酶类、黏液和激素等。
- [ ] 外分泌腺有导管，分泌物排至体表或器官腔（汗腺、唾液腺等）；内分泌腺无导管，激素一般入血（甲状腺、肾上腺等）。
- [ ] 少数外分泌腺为独立器官（3 对大唾液腺、胰腺）；多数为器官内微细结构（汗腺、皮脂腺、胃腺）。
- [ ] 外分泌腺一般由分泌部和导管组成；按导管有无分支分为单腺和复腺。
- [ ] 按形态可分为单管状腺、单泡状腺、复管状腺、复泡状腺和复管泡状腺等。
- [ ] 分泌部一般由单层腺细胞围成，中央有腔；泡状和管泡状分泌部称腺泡，腺细胞多呈锥形。
- [ ] 浆液细胞：核圆、偏基底；基底强嗜碱性，顶部酶原颗粒嗜酸性；粗面内质网密集、高尔基复合体发达，属蛋白质分泌细胞。
- [ ] 腺细胞受自主神经和激素调节，属调节型分泌细胞，非分泌时相可见大量贮存的分泌颗粒。
- [ ] 黏液细胞：核扁圆、居基底；大部分胞质不着色呈泡沫状；核上区有粗大黏原颗粒。杯状细胞是散在的黏液细胞。
- [ ] 浆液腺如腮腺，黏液腺如十二指肠腺，混合腺如下颌下腺和舌下腺。混合腺泡常见浆半月。
- [ ] 肌上皮细胞位于腺细胞与基膜之间，含肌动蛋白丝，收缩有助于排出分泌物。
- [ ] 导管与分泌部通连，由单层或复层上皮构成；有的导管上皮可分泌或吸收水和电解质。
:::
