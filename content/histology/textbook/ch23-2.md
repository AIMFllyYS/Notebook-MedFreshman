# 二、呼吸系统的发生

第 $4$ 周，原始咽尾端底壁正中出现喉气管沟，加深为喉气管憩室，气管食管隔把它与食管分开。上端成喉，中段成气管，末端成肺芽。本节把这条呼吸道原基摊到第 $7$ 个月表面活性物质，再写气管食管瘘和透明膜病，最后收本章小结。鼻腔上皮来自外胚层，其余呼吸道上皮来自内胚层。

## （一）喉、气管和肺的发生

第 $4$ 周时，原始咽尾端底壁正中出现一纵行沟，称喉气管沟（laryngotracheal groove）。后者逐渐加深，形成一长形盲囊，称喉气管憩室（laryngotracheal diverticulum）。喉气管憩室位于食管的腹侧，两者之间的间充质称气管食管隔。喉气管憩室的上端发育为喉，中段发育为气管；末端膨大，形成两个分支，称肺芽（lung bud），是主支气管和肺的原基。肺芽呈树枝状反复分支，第 $6$ 个月时达 $17$ 级左右，分别形成肺叶支气管、段支气管，直至呼吸性细支气管、肺泡管和肺泡囊（图 23-10，图 23-11）。第 $7$ 个月时，肺泡数量增多，肺泡上皮中除Ⅰ型肺泡细胞外，还分化出Ⅱ型肺泡细胞，并开始分泌表面活性物质。此时，胎儿肺内血液循环系统发育完善，如早产也可进行正常呼吸，能够存活。

:::definition{label="喉气管沟"}
喉气管沟（laryngotracheal groove）是第 $4$ 周原始咽尾端底壁正中出现的一条纵行沟。它还不是管子，只是咽底的一条槽。
:::

:::definition{label="喉气管憩室"}
喉气管沟逐渐加深，形成一长形盲囊，称喉气管憩室（laryngotracheal diverticulum）。憩室位于食管腹侧，是喉、气管和肺的总原基。
:::

:::definition{label="气管食管隔"}
喉气管憩室与食管之间的间充质称气管食管隔。隔把腹侧的呼吸道原基和背侧的食管分开；隔发育不良，就留下气管食管瘘。
:::

:::definition{label="肺芽"}
喉气管憩室末端膨大，形成两个分支，称肺芽（lung bud），是主支气管和肺的原基。上端发育为喉，中段发育为气管，末端才是肺芽——三段不要并成“憩室只成气管”。
:::

:::definition{label="肺芽的分支级数"}
肺芽呈树枝状反复分支，第 $6$ 个月时达 $17$ 级左右，分别形成肺叶支气管、段支气管，直至呼吸性细支气管、肺泡管和肺泡囊。
:::

:::definition{label="Ⅱ型肺泡细胞与表面活性物质（发生）"}
第 $7$ 个月时肺泡数量增多，肺泡上皮中除Ⅰ型肺泡细胞外，还分化出Ⅱ型肺泡细胞，并开始分泌表面活性物质。此时肺内血液循环系统发育完善，早产也可进行正常呼吸、能够存活。
:::

:::concept{term="先问喉气管沟是不是已经隔成憩室，再问上中末三段各成什么"}
看见原始咽尾端底壁，先问那条纵行沟加深成盲囊没有——成了才叫喉气管憩室，腹侧是呼吸道，背侧是食管，中间夹气管食管隔。再问三段：上端喉，中段气管，末端两个肺芽。最后问月份：第 $6$ 个月大约 $17$ 级，到呼吸性细支气管、肺泡管和肺泡囊；第 $7$ 个月Ⅱ型细胞分泌表面活性物质，早产才站得住。把沟直接写成肺，或把第 $6$ 个月听成已经能靠表面活性物质存活，透明膜病的时间窗会对错。
:::

:::

:::insight{label="第7个月才有表面活性物质，早产能不能活，先问Ⅱ型细胞出了没有"}
第 $6$ 个月分支已经到肺泡囊，但教材把“开始分泌表面活性物质”和“早产也可存活”放在第 $7$ 个月。透明膜病主要见于妊娠 $28$ 周前早产，正是这张时间尺的反面。只记“肺芽会分支”，早产存活和 NRDS 会对不上月份。
:::

:::cause-effect{title="沟加深、隔分开、末端分叉"}

- 果：形成喉气管憩室
- 因：憩室与食管之间的间充质形成气管食管隔
- 果：腹侧呼吸道与背侧食管分开；上端喉、中段气管、末端肺芽
- 因：肺芽反复分支至第 6 个月约 17 级，第 7 个月Ⅱ型细胞分泌表面活性物质
- 果：呼吸部建成；肺循环完善后早产也可呼吸存活
- 制约：隔发育不良则气管食管瘘；Ⅱ型细胞分化不良则透明膜病
:::

## （二）主要畸形

### 1. 气管食管瘘

气管食管瘘（tracheoesophageal fistula）因气管食管隔发育不良，导致气管与食管分隔不完全，两者间有瘘管相通（图 23-12）。

:::definition{label="气管食管瘘"}
气管食管瘘（tracheoesophageal fistula）因气管食管隔发育不良，气管与食管分隔不完全，两者间有瘘管相通。隔没隔全，不是肺芽少长了一支。
:::

::figure{src="/images/histology/textbook/p0259_02.png" caption="图23-12 气管食管瘘模式图。A. 上段食管为盲端，下段食管有瘘管与气管相通；B. 食管通畅，但有瘘管与气管相通；C. 上段食管有瘘管与气管相通，下段食管为盲端；D. 食管上下段均为盲端，各自有瘘管与气管相通。" alt="四种模式：A 上段盲端下段连气管，B 食管通畅另有瘘管，C 上段连气管下段盲端，D 上下段均盲各有瘘管连气管"}

:::note{label="图23-12 四种瘘的读法"}
四种类型都是气管食管隔没隔全，差别只在食管哪一段是盲端、哪一段连着气管。A 最常见于模式记忆：上段盲端，下段瘘入气管。不要把四种写成四种不同的原基。
:::

### 2. 透明膜病

透明膜病（hyaline membrane disease）由于Ⅱ型肺泡细胞分化不良，不能产生足够的表面活性物质，导致肺泡表面张力增大。胎儿出生后，因肺泡不能随呼吸运动扩张而出现呼吸困难，故称新生儿呼吸窘迫综合征（respiratory distress syndrome）。显微镜检查显示肺泡萎缩、间质水肿，肺泡上皮表面覆盖一层透明状血浆蛋白膜。该病主要见于妊娠 $28$ 周前的早产儿。

:::definition{label="透明膜病"}
透明膜病（hyaline membrane disease）由于Ⅱ型肺泡细胞分化不良，不能产生足够的表面活性物质，肺泡表面张力增大。出生后肺泡不能随呼吸运动扩张，出现呼吸困难，故称新生儿呼吸窘迫综合征（respiratory distress syndrome，NRDS）。
:::

:::definition{label="透明膜病的镜下与高发窗口"}
显微镜检查显示肺泡萎缩、间质水肿，肺泡上皮表面覆盖一层透明状血浆蛋白膜。该病主要见于妊娠 $28$ 周前的早产儿——对照第 $7$ 个月Ⅱ型细胞才开始分泌表面活性物质。
:::

:::concept{term="先问是隔没隔全还是Ⅱ型细胞表面活性物质不够，再问早产是不是妊娠28周前"}
看见呼吸系统畸形，先分两张名单：气管食管隔发育不良 → 气管食管瘘，气管和食管有瘘管相通；Ⅱ型肺泡细胞分化不良 → 表面活性物质不够 → 表面张力大 → 肺泡不能扩张 → 透明膜病／NRDS。再问时间：NRDS 主要见于妊娠 $28$ 周前早产。把吃奶呛咳的瘘管写成“肺没成熟”，或把透明膜病写成气管食管没分开，两本账会对调。
:::

:::compare{title="气管食管瘘与透明膜病"}
| 项目 | 气管食管瘘 | 透明膜病（NRDS） |
|------|------------|------------------|
| 英文 | tracheoesophageal fistula | hyaline membrane disease；respiratory distress syndrome |
| 停在哪一步 | 气管食管隔发育不良，分隔不完全 | Ⅱ型肺泡细胞分化不良，表面活性物质不足 |
| 结构结果 | 气管与食管间有瘘管 | 肺泡表面张力增大，不能随呼吸扩张 |
| 镜下 | — | 肺泡萎缩、间质水肿，上皮表面覆盖透明状血浆蛋白膜 |
| 高发 | 与隔的发生有关，不按 $28$ 周写 | 主要见于妊娠 $28$ 周前早产儿 |
:::

:::pitfall{label="透明膜病是表面活性物质不够，不是气管食管没分开"}
瘘管是隔的问题，吃奶可呛入气道。透明膜病是Ⅱ型细胞的问题，肺泡表面盖一层血浆蛋白膜、不能扩张。两病都在本节，原基完全不同。写成“早产所以气管和食管还连着”，图 23-12 和透明膜会并成一种畸形。
:::

:::cause-effect{title="隔不全成瘘，表面活性物质不足成透明膜"}
- 因：气管食管隔发育不良
- 果：气管与食管分隔不完全，有瘘管相通
- 因：Ⅱ型肺泡细胞分化不良，表面活性物质不足
- 果：肺泡表面张力增大，出生后不能扩张，呼吸困难（NRDS）
- 制约：透明膜病主要见于妊娠 28 周前早产；第 7 个月以后Ⅱ型细胞才开始分泌表面活性物质
:::

:::tip{label="呼吸道发生口诀"}
咽底一条沟，加深成憩室。隔开腹侧气管，背侧仍是食管。上喉、中管、末端两个肺芽。六月十七级到肺泡囊，七月Ⅱ型产表面活性物质。隔不全成瘘，活性物质不够成透明膜。
:::

:::keypoint{label="瘘对气管食管隔，透明膜对Ⅱ型细胞和28周"}
- 气管食管瘘：隔发育不良，气管与食管有瘘管；图 23-12 四种盲端／瘘管组合。
- 透明膜病／NRDS：Ⅱ型细胞分化不良，表面活性物质不足；肺泡萎缩、间质水肿、透明状血浆蛋白膜；主要妊娠 $28$ 周前早产。
:::

## 本章小结

人胚第 $3\sim 4$ 周，随着圆柱状胚体形成，内胚层被包卷入胚体，形成原始消化管，分为前肠、中肠和后肠。前肠分化为部分口腔底、舌、咽至十二指肠的上段、肝、胆囊、胆管、下颌下腺、舌下腺、胰腺以及喉以下的呼吸道、肺、胸腺、甲状腺和甲状旁腺等器官。中肠分化为自十二指肠中段至横结肠右 $2/3$ 之间的消化管。后肠分化为自横结肠左 $1/3$ 至肛管上段的消化管以及膀胱和尿道的大部分。喉气管憩室至胃之间的一段原始消化管分化为食管，前肠尾段膨大形成胃。中肠头段与前肠尾段形成十二指肠。中肠袢尾支的盲肠突是盲肠和阑尾的原基。头支形成空肠和回肠的大部。尾支盲肠突以前的部分形成回肠尾段，盲肠突以后的部分形成横结肠的右 $2/3$。盲肠突的近段形成盲肠，远段则形成阑尾。后肠形成横结肠的左 $1/3$、降结肠和乙状结肠。

肝憩室是肝和胆囊的原基。肝憩室的头支为肝原基，发育为肝。尾支发育为胆囊和胆囊管。肝憩室根部则发育为胆总管。前肠尾端形成背胰芽和腹胰芽，分化成了背胰和腹胰，腹胰与背胰融合，形成胰腺。

鼻腔上皮来自外胚层，呼吸系统其他部分的上皮均来自内胚层。第 $4$ 周时，原始咽尾端底壁正中出现一纵行沟，称喉气管沟，继而分割出一长形盲囊，即喉气管憩室。喉气管憩室开口于咽的部分发育为喉，中段发育为气管。喉气管憩室末端分为左、右两支肺芽，形成支气管，肺内各级导气部、呼吸部和终末肺泡，最后发育为肺。

:::definition{label="本章小结中的前肠、中肠与后肠"}
前肠：部分口腔底、舌、咽至十二指肠上段、肝、胆囊、胆管、下颌下腺、舌下腺、胰腺，以及喉以下呼吸道、肺、胸腺、甲状腺和甲状旁腺。中肠：十二指肠中段至横结肠右 $2/3$。后肠：横结肠左 $1/3$ 至肛管上段，以及膀胱和尿道的大部分。
:::

:::definition{label="食管、胃与十二指肠在小结中的划段"}
喉气管憩室至胃之间的一段原始消化管分化为食管；前肠尾段膨大形成胃；中肠头段与前肠尾段形成十二指肠。十二指肠跨在前肠尾段和中肠头段两本账上。
:::

:::compare{title="中肠袢头支、尾支与盲肠突（小结）"}
| 部分 | 分化结果 |
|------|----------|
| 头支 | 空肠和回肠的大部 |
| 尾支盲肠突以前 | 回肠尾段 |
| 盲肠突 | 小肠与大肠分界；近段盲肠，远段阑尾 |
| 尾支盲肠突以后 | 横结肠的右 $2/3$ |
| 后肠 | 横结肠的左 $1/3$、降结肠和乙状结肠 |
:::

:::compare{title="肝憩室与胰芽（小结）"}
| 原基 | 去向 |
|------|------|
| 肝憩室头支 | 肝原基，发育为肝 |
| 肝憩室尾支 | 胆囊和胆囊管 |
| 肝憩室根部（基部） | 胆总管 |
| 腹胰芽、背胰芽 | 腹胰与背胰，融合形成胰腺 |
:::

:::definition{label="呼吸道上皮的胚层（小结）"}
鼻腔上皮来自外胚层，呼吸系统其他部分的上皮均来自内胚层。不要把整条呼吸道都写成外胚层，也不要把鼻腔上皮写成内胚层。
:::

:::definition{label="喉气管憩室三段（小结）"}
第 $4$ 周喉气管沟分割出喉气管憩室。开口于咽的部分发育为喉，中段发育为气管，末端左、右肺芽形成支气管及肺内各级导气部、呼吸部和终末肺泡，最后发育为肺。
:::

:::concept{term="先问鼻腔上皮是不是外胚层，再问其余呼吸道是不是内胚层"}
看见本章小结的呼吸账，先把鼻腔上皮单独提出来：它来自外胚层。其余——喉、气管、支气管、肺泡——上皮来自内胚层，源头是前肠的喉气管憩室。把鼻腔也写成内胚层，或把肺泡上皮写成外胚层，和本章开头“黏膜上皮、腺上皮和肺泡上皮均来自内胚层”会对不齐。
:::

:::pitfall{label="横结肠右2/3是中肠，左1/3是后肠，分界在盲肠突以后那一段"}
头支走空回肠大部；尾支在盲肠突以前补回肠尾段，盲肠突以后才是横结肠右 $2/3$。后肠接管横结肠左 $1/3$、降结肠和乙状结肠。写成“整条横结肠都是中肠”，左右 $2/3$ 与 $1/3$ 的分界会消失。
:::

:::insight{label="小结把十二指肠和横结肠的跨段写清楚了"}
十二指肠 = 前肠尾段 + 中肠头段；横结肠 = 中肠（右 $2/3$）+ 后肠（左 $1/3$）。发生学分段不是按成人解剖学“一个器官一个胚段”来切。只背“中肠变小肠、后肠变大肠”，回肠尾段和横结肠右 $2/3$ 会对错户头。
:::

:::timeline{period="本章小结对照尺"}
- **第3～4周** 内胚层卷入，前肠、中肠、后肠
- **前肠尾段** 膨大为胃；喉气管憩室至胃之间为食管
- **肝憩室** 头支肝，尾支胆囊和胆囊管，根部胆总管
- **胰芽** 腹胰与背胰融合为胰腺
- **中肠袢** 头支空回肠大部；盲肠突近段盲肠、远段阑尾；盲肠突以后为横结肠右2/3
- **后肠** 横结肠左1/3、降结肠、乙状结肠
- **第4周** 喉气管沟 → 憩室：开口成喉，中段气管，末端肺芽成肺
- **上皮** 鼻腔外胚层，其余呼吸道内胚层
:::

:::keypoint{label="前中后肠划段，肝憩室三份，胰芽融合，喉气管憩室成肺"}
- 前肠到十二指肠上段并含喉以下呼吸道、肺和咽囊器官；中肠到横结肠右 $2/3$；后肠从横结肠左 $1/3$ 到肛管上段，并含膀胱尿道大部分。
- 食管在喉气管憩室与胃之间；胃是前肠尾段膨大；十二指肠跨前肠尾段与中肠头段。
- 头支空回肠大部；尾支盲肠突以前为回肠尾段，以后为横结肠右 $2/3$；盲肠突近段盲肠、远段阑尾。
- 肝憩室头支肝、尾支胆囊胆囊管、根部胆总管；腹胰与背胰融合。
- 鼻腔上皮外胚层，其余呼吸道上皮内胚层；喉气管沟 → 憩室 → 喉、气管、肺芽。
:::

:::memory{label="本节必背要点"}
- [ ] 第 $4$ 周原始咽尾端底壁正中出现喉气管沟（laryngotracheal groove）。
- [ ] 沟加深形成长形盲囊，称喉气管憩室（laryngotracheal diverticulum），位于食管腹侧。
- [ ] 憩室与食管之间的间充质称气管食管隔。
- [ ] 憩室上端发育为喉，中段发育为气管，末端膨大成两个肺芽（lung bud），是主支气管和肺的原基。
- [ ] 肺芽反复分支，第 $6$ 个月达 $17$ 级左右，形成肺叶支气管、段支气管，直至呼吸性细支气管、肺泡管和肺泡囊。
- [ ] 第 $7$ 个月肺泡增多，除Ⅰ型肺泡细胞外分化出Ⅱ型肺泡细胞，开始分泌表面活性物质。
- [ ] 第 $7$ 个月肺内血液循环完善，早产也可正常呼吸、能够存活。
- [ ] 气管食管瘘（tracheoesophageal fistula）：气管食管隔发育不良，气管与食管分隔不完全，有瘘管相通。
- [ ] 透明膜病（hyaline membrane disease）：Ⅱ型肺泡细胞分化不良，表面活性物质不足，肺泡表面张力增大。
- [ ] 出生后肺泡不能随呼吸扩张，称新生儿呼吸窘迫综合征（respiratory distress syndrome）。
- [ ] 镜下：肺泡萎缩、间质水肿，上皮表面覆盖透明状血浆蛋白膜。
- [ ] 透明膜病主要见于妊娠 $28$ 周前的早产儿。
- [ ] 本章小结：人胚第 $3\sim 4$ 周内胚层被包卷入胚体，形成前肠、中肠和后肠。
- [ ] 前肠：部分口腔底、舌、咽至十二指肠上段、肝、胆囊、胆管、下颌下腺、舌下腺、胰腺，以及喉以下呼吸道、肺、胸腺、甲状腺和甲状旁腺。
- [ ] 中肠：十二指肠中段至横结肠右 $2/3$。
- [ ] 后肠：横结肠左 $1/3$ 至肛管上段，以及膀胱和尿道的大部分。
- [ ] 喉气管憩室至胃之间分化为食管；前肠尾段膨大形成胃。
- [ ] 中肠头段与前肠尾段形成十二指肠。
- [ ] 中肠袢尾支的盲肠突是盲肠和阑尾的原基；近段盲肠，远段阑尾。
- [ ] 头支形成空肠和回肠的大部。
- [ ] 尾支盲肠突以前形成回肠尾段，盲肠突以后形成横结肠右 $2/3$。
- [ ] 后肠形成横结肠左 $1/3$、降结肠和乙状结肠。
- [ ] 肝憩室是肝和胆囊的原基：头支为肝，尾支为胆囊和胆囊管，根部为胆总管。
- [ ] 前肠尾端背胰芽和腹胰芽分化为背胰和腹胰，融合形成胰腺。
- [ ] 鼻腔上皮来自外胚层，呼吸系统其他部分的上皮均来自内胚层。
- [ ] 喉气管沟分割出喉气管憩室；开口于咽的部分成喉，中段成气管，末端左右肺芽成支气管及肺内导气部、呼吸部和终末肺泡。
