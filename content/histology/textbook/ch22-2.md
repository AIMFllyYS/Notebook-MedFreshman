# 二、颜面的形成

第 $1$ 鳃弓腹侧份分成上颌突与下颌突。左右下颌突中线融合后，额鼻突、左右上颌突和已融合的下颌突围成口凹（stomodeum），底是口咽膜，约第 $24$ 天破裂。额鼻突下部再分出鼻板、鼻窝和内、外侧鼻突。颜面从两侧向正中汇拢：下颌突成下颌下唇，内侧鼻突成鼻梁鼻尖和上唇正中／人中，上颌突成上唇外侧与上颌，外侧鼻突成鼻侧壁和鼻翼。本节把五突围口凹和融合账摊开；腭把口腔鼻腔彻底分开，下一节再写。

## 第1鳃弓分叉与口凹

第 $1$ 鳃弓出现后，其腹侧份迅速分为上下两支，分别称上颌突（maxillary prominence）与下颌突（mandibular prominence）。左右下颌突很快在胚腹侧中线融合，将口咽膜与心隆起隔开。额鼻突、左右上颌突、已融合的左右下颌突围成的一个宽大的凹陷称口凹（stomodeum）（图 22-3）。口凹即原始口腔，其底是口咽膜。口咽膜于第 $24$ 天左右破裂，原始口腔遂与原始咽相通。

:::definition{label="上颌突"}
上颌突（maxillary prominence）是第 $1$ 鳃弓腹侧份迅速分成的上支。它将发育形成上唇的外侧部分与上颌，并向原始口腔内长出外侧腭突。
:::

:::definition{label="下颌突"}
下颌突（mandibular prominence）是第 $1$ 鳃弓腹侧份迅速分成的下支。左右下颌突很快在胚腹侧中线融合，将口咽膜与心隆起隔开，日后发育为下颌与下唇。
:::

:::definition{label="口凹"}
口凹（stomodeum）是额鼻突、左右上颌突、已融合的左右下颌突围成的宽大凹陷，即原始口腔。其底是口咽膜。开口起初宽大，颊形成后口裂才缩小。
:::

:::definition{label="口咽膜"}
口咽膜是口凹的底，分隔原始口腔与原始咽。于第 $24$ 天左右破裂，原始口腔遂与原始咽相通。不要写成口鼻膜：口鼻膜隔的是原始口腔与原始鼻腔。
:::

:::concept{term="先问五突谁围口凹，再问口咽膜破了通向哪里"}
看见颜面原基，先数五个突起：额鼻突一个，上颌突左右各一，下颌突左右各一（很快中线融合）。它们围成口凹，底才是口咽膜。再问膜破之后通的是哪一腔：口咽膜破，原始口腔通原始咽；口鼻膜破，原始口腔通原始鼻腔。两张膜、两条通道，不要并成一句“口破了就通了”。
:::

:::compare{title="额鼻突、上颌突与下颌突"}
| 项目 | 额鼻突 | 上颌突 | 下颌突 |
|------|--------|--------|--------|
| 来源 | 脑泡腹侧间充质增生 | 第 $1$ 鳃弓腹侧份上支 | 第 $1$ 鳃弓腹侧份下支 |
| 对数 | $1$ 个，位于正中 | 左右各一 | 左右各一，很快中线融合 |
| 围成口凹 | 构成口凹头侧壁 | 构成口凹两侧 | 构成口凹尾侧壁，并把口咽膜与心隆起隔开 |
| 主要衍化 | 其余部分 → 前额；下部发生鼻板、鼻窝及内、外侧鼻突 | 上唇外侧部分与上颌；外侧腭突 | 下颌与下唇 |
| 不要听成 | 已经是鼻子 | 整块上唇 | 心隆起 |
:::

:::pitfall{label="口咽膜约第24天破裂，通的是原始咽，不是鼻腔"}
口凹底的口咽膜于第 $24$ 天左右破裂，原始口腔遂与原始咽相通。口鼻膜是后来隔在原始口腔与原始鼻腔之间的菲薄膜，破裂后两腔才相通。把“第 $24$ 天”写到口鼻膜头上，或把口咽膜破裂写成“口鼻相通”，咽和鼻两本账会对调。
:::

:::cause-effect{title="口咽膜破裂开通原始口腔与原始咽"}
- 因：口凹底的口咽膜于第 24 天左右破裂
- 果：原始口腔与原始咽相通
- 制约：此时鼻窝尚未被口鼻膜完全隔开后再打通；口鼻相通是另一张膜的事
:::

## 鼻板、鼻窝与内、外侧鼻突

颜面的形成和鼻的发生密切相关。在额鼻突的下部两侧，局部表面外胚层增生，形成左右一对鼻板（nasal placode）。鼻板中央凹陷为鼻窝（nasal pit），其下缘以一条细沟与口凹相通。鼻窝周缘的间充质增生突起，其内侧和外侧的突起分别称内侧鼻突（median nasal prominence）和外侧鼻突（lateral nasal prominence），两个突起的上部相连续（图 22-3）。

:::definition{label="鼻板"}
鼻板（nasal placode）是额鼻突下部两侧、局部表面外胚层增生形成的左右一对板状增厚。它还不是鼻孔。
:::

:::definition{label="鼻窝"}
鼻窝（nasal pit）是鼻板中央凹陷形成的窝。其下缘以一条细沟与口凹相通。向深部扩大后形成原始鼻腔；随着鼻梁、鼻尖形成，原来向前开口的鼻窝转向下方，成为外鼻孔。
:::

:::definition{label="内侧鼻突"}
内侧鼻突（median nasal prominence）是鼻窝周缘间充质增生后、位于鼻窝内侧的突起，上部与外侧鼻突相连续。左右内侧鼻突渐融合，形成鼻梁和鼻尖；其下缘下迁并与上颌突融合，形成上唇的正中部分和人中。左右内侧鼻突融合后还向原始口腔内长出正中腭突。
:::

:::definition{label="外侧鼻突"}
外侧鼻突（lateral nasal prominence）是鼻窝周缘间充质增生后、位于鼻窝外侧的突起，上部与内侧鼻突相连续。发育为鼻的侧壁和鼻翼。上颌突与同侧外侧鼻突未融合，日后可致面斜裂（见本章畸形节）。
:::

:::compare{title="鼻板、鼻窝、内侧鼻突与外侧鼻突"}
| 项目 | 鼻板 | 鼻窝 | 内侧鼻突 | 外侧鼻突 |
|------|------|------|----------|----------|
| 何物 | 额鼻突下部两侧外胚层增厚 | 鼻板中央凹陷 | 鼻窝内侧的间充质突起 | 鼻窝外侧的间充质突起 |
| 与口凹的关系 | 位于口凹头侧 | 下缘以细沟通口凹 | 参与封上唇正中，把鼻窝与口凹隔开 | 与上颌突融合，参与分隔 |
| 衍化 | 继续凹陷为鼻窝 | 转向下成为外鼻孔；向深部扩大为原始鼻腔 | 鼻梁、鼻尖、上唇正中和人中；正中腭突 | 鼻的侧壁和鼻翼 |
| 上部 | — | — | 与外侧鼻突上部相连续 | 与内侧鼻突上部相连续 |
:::

:::pitfall{label="鼻窝下缘那条细沟不是口咽膜"}
鼻窝下缘以一条细沟与口凹相通，这是鼻与口尚未分隔时的通道。口咽膜是口凹的底，通向原始咽。两处“相通”不要并成一张膜。
:::

## 从两侧向正中融合

颜面的演化是从两侧向正中方向发展的。人胚第 $5$ 周，左右下颌突在中线融合，将发育为下颌与下唇。继而，左右上颌突也向中线生长，先后与同侧的外侧鼻突及内侧鼻突融合。与此同时，两侧的鼻窝亦彼此靠拢，左右内侧鼻突渐融合，形成鼻梁和鼻尖，其下缘向下方迁移并与正向中线生长的左右上颌突融合，发育形成上唇的正中部分和人中。上颌突将发育形成上唇的外侧部分与上颌。此时，鼻窝与口凹被分隔开。额鼻突的其他部分主要发育成前额。外侧鼻突发育为鼻的侧壁和鼻翼。随着鼻梁、鼻尖等结构的形成，原来向前方开口的鼻窝逐渐转向下方，成为外鼻孔。鼻窝向深部扩大，形成原始鼻腔。开始，原始鼻腔和原始口腔间隔以菲薄的口鼻膜，该膜破裂后，两腔相通（图 22-4）。

:::definition{label="人中"}
人中是左右内侧鼻突下缘下迁、与正向中线生长的左右上颌突融合后，发育形成的上唇正中结构。上唇正中部分和人中都记在内侧鼻突账上，不记在上颌突账上。
:::

:::definition{label="上唇的两段账"}
上唇正中部分和人中来自左右内侧鼻突；上唇的外侧部分来自上颌突。上颌突与同侧内侧鼻突未融合，裂沟落在人中外侧，即常见的唇裂（见本章畸形节）。
:::

:::definition{label="外鼻孔与原始鼻腔"}
鼻梁、鼻尖形成后，原来向前开口的鼻窝转向下方，成为外鼻孔。鼻窝向深部扩大，形成原始鼻腔。
:::

:::definition{label="口鼻膜"}
口鼻膜是开始时隔在原始鼻腔与原始口腔之间的菲薄膜。该膜破裂后，原始口腔与原始鼻腔相通。它不是口咽膜，破裂日期也不是第 $24$ 天那一句。
:::

:::compare{title="五突融合后的颜面去向"}
| 突起 | 融合对象 | 主要衍化 |
|------|----------|----------|
| 左右下颌突 | 第 $5$ 周中线融合 | 下颌与下唇 |
| 左右上颌突 | 先后与同侧外侧鼻突、内侧鼻突融合 | 上唇外侧部分与上颌 |
| 左右内侧鼻突 | 彼此融合；下缘再与上颌突融合 | 鼻梁、鼻尖；上唇正中部分和人中 |
| 外侧鼻突 | 与同侧上颌突融合 | 鼻的侧壁和鼻翼 |
| 额鼻突其余部分 | — | 前额 |
:::

:::note{label="鼻窝与口凹何时被隔开"}
上颌突与同侧内、外侧鼻突融合，左右内侧鼻突又彼此融合并下延与上颌突汇拢之后，鼻窝与口凹才被分隔开。在此之前，鼻窝下缘仍以细沟通口凹。
:::

:::insight{label="上唇正中是内侧鼻突的，上唇外侧才是上颌突的"}
上唇看起来像一整条，账却要切开：人中和正中份记内侧鼻突，外侧份记上颌突。把整条上唇都写成上颌突，人中外侧的唇裂就没有“两突未融合”的缝可对。
:::

## 口裂、颊、眼与外耳

起初，原始口腔的开口宽大，随着两侧上下颌突向中线汇拢以及上、下唇的形成，同侧的上下颌突从分叉处向中线方向融合形成颊，口裂逐渐缩小。眼最初发生于额鼻突的外侧，两眼相距较远，随着颅脑的迅速增大以及上颌与鼻的形成，两眼逐渐向中线靠近，并处于同一平面。外耳道由第 $1$ 鳃沟演变而成，鳃沟周围的间充质增生形成耳郭（见第 $27$ 章）。开始，外耳的位置很低，后来随着下颌与颈的发育逐渐移向后上方。至第 $8$ 周末，胚颜面初具人貌。

:::definition{label="颊"}
颊由同侧的上颌突与下颌突从分叉处向中线方向融合形成。颊一形成，原本宽大的口裂才逐渐缩小。
:::

:::definition{label="眼的位置变化"}
眼最初发生于额鼻突的外侧，两眼相距较远。随着颅脑迅速增大以及上颌与鼻的形成，两眼逐渐向中线靠近，并处于同一平面。不是一开始就长在鼻根两侧。
:::

:::definition{label="外耳道与耳郭"}
外耳道由第 $1$ 鳃沟演变而成；鳃沟周围的间充质增生形成耳郭（详见第 $27$ 章）。开始外耳位置很低，后来随下颌与颈的发育逐渐移向后上方。
:::

:::pitfall{label="颊是同侧上下颌突从分叉向中线融合，不是左右上颌突在中线接吻"}
口裂缩小靠的是同侧上、下颌突在口角处融合出颊。左右上颌突向中线生长，主要是去贴同侧的内、外侧鼻突，不是左右上颌突自己在人中处对上。把颊写成“左右脸在嘴中间长到一起”，口角会放到人中上去。
:::

:::timeline{period="从口凹到第8周末初具人貌"}
- **第1鳃弓分叉** 腹侧份分成上颌突与下颌突；左右下颌突中线融合，隔开口咽膜与心隆起
- **口凹** 额鼻突、左右上颌突、已融合的下颌突围成口凹（原始口腔），底为口咽膜
- **约第24天** 口咽膜破裂，原始口腔与原始咽相通
- **鼻板 → 鼻窝** 额鼻突下部两侧外胚层增厚为鼻板，中央凹陷为鼻窝，周缘成内侧鼻突与外侧鼻突
- **第5周起向正中** 下颌突 → 下颌与下唇；上颌突与同侧内、外侧鼻突融合；左右内侧鼻突 → 鼻梁、鼻尖、上唇正中和人中
- **口鼻膜破裂** 原始口腔与原始鼻腔相通；鼻窝转向下成为外鼻孔
- **口裂缩小** 同侧上下颌突从分叉向中线融合成颊；眼从外侧靠向中线；第1鳃沟成外耳道
- **第8周末** 胚颜面初具人貌
:::

:::keypoint{label="五突围口凹，第24天破口咽膜，两侧向正中融成人貌"}
- 第 $1$ 鳃弓腹侧份 → 上颌突 + 下颌突；左右下颌突中线融合，隔开口咽膜与心隆起。
- 口凹（stomodeum）= 额鼻突 + 左右上颌突 + 已融合下颌突；底为口咽膜；约第 $24$ 天破裂，通原始咽。
- 鼻板 → 鼻窝 → 内侧鼻突 / 外侧鼻突（上部连续）；鼻窝下缘细沟通口凹。
- 第 $5$ 周起从两侧向正中：下颌突 → 下颌下唇；上颌突 → 上唇外侧与上颌；内侧鼻突 → 鼻梁鼻尖 + 上唇正中和人中；外侧鼻突 → 鼻侧壁和鼻翼；额鼻突其余 → 前额。
- 口鼻膜破裂后原始口腔与原始鼻腔相通。颊由同侧上下颌突从分叉向中线融合。眼从外侧靠向中线。外耳道 = 第 $1$ 鳃沟。第 $8$ 周末初具人貌。
:::
