# 八、主要畸形

颜面靠五突融合，腭靠正中腭突与外侧腭突会合，四肢靠肢芽分节再凋亡分指。融合或凋亡一旦停在半路，就变成唇裂、面斜裂、腭裂或四肢畸形。本节先按机制把这几类摊开，再收本章小结；唇腭裂插入框只作为病因、预防与治疗的注记，不另立一节。

:::definition{label="本章主要畸形的范围"}
本节写颜面和四肢发生过程中的主要畸形：唇裂、面斜裂、腭裂（前腭裂、正中腭裂、全腭裂），以及无肢、短肢和四肢分化障碍。它们都是突起未融合或肢芽分化、凋亡失常的结局。
:::

## 1. 唇裂

唇裂（cleft lip）是最常见的颜面畸形，多见于上唇，常因上颌突与同侧内侧鼻突未融合所致，故裂沟位于人中外侧。唇裂多为单侧，也可见双侧者。如果左、右内侧鼻突未融合，或两侧下颌突未融合，可分别导致上唇或下唇的正中裂，但均少见。如果内侧鼻突发育不良，导致人中缺损，则出现宽大的正中唇裂。唇裂可伴有牙槽突裂和腭裂（图 22-11～图 22-13）。

:::definition{label="唇裂"}
唇裂（cleft lip）是最常见的颜面畸形，多见于上唇。常见机制：上颌突与同侧内侧鼻突未融合，裂沟位于人中外侧。可为单侧或双侧。
:::

:::definition{label="上唇或下唇的正中裂"}
左、右内侧鼻突未融合，导致上唇正中裂；两侧下颌突未融合，导致下唇正中裂。两种都少见，不要当成最常见的人中外侧唇裂。
:::

:::definition{label="宽大的正中唇裂"}
内侧鼻突发育不良、人中缺损时，出现宽大的正中唇裂。它不是“人中外侧那一条”，而是人中区本身缺了一块。
:::

:::concept{term="先问裂在人中外侧还是正中，再问未融合的是上颌突与内侧鼻突，还是左右内侧鼻突、下颌突"}
看见唇裂，先看位置：最常见的裂沟在人中外侧，对应上颌突与同侧内侧鼻突未融合，可单侧或双侧。正中裂少见，要再问是左右内侧鼻突未融（上唇正中）还是两侧下颌突未融（下唇正中）；人中缺损、裂特别宽，才是内侧鼻突发育不良。把所有唇裂都写成“鼻子没长好”，面斜裂和腭裂会对错户头。
:::

:::compare{title="常见唇裂、正中裂与宽大正中唇裂"}
| 项目 | 常见唇裂 | 上唇正中裂 | 下唇正中裂 | 宽大的正中唇裂 |
|------|----------|------------|------------|----------------|
| 频率 | 最常见 | 少见 | 少见 | 少见 |
| 部位 | 上唇，人中外侧 | 上唇正中 | 下唇正中 | 人中区宽大缺损 |
| 未融合 / 发育 | 上颌突与同侧内侧鼻突未融合 | 左、右内侧鼻突未融合 | 两侧下颌突未融合 | 内侧鼻突发育不良，人中缺损 |
| 单双侧 | 多为单侧，也可见双侧 | — | — | — |
| 可伴发 | 牙槽突裂、腭裂 | 按教材可伴牙槽突裂和腭裂 | 同左 | 同左 |
:::

## 2. 面斜裂

面斜裂（oblique facial cleft）位于眼内眦与口角之间的裂隙，因上颌突与同侧外侧鼻突未融合所致（图 22-11）。

:::definition{label="面斜裂"}
面斜裂（oblique facial cleft）是位于眼内眦与口角之间的裂隙。机制：上颌突与同侧外侧鼻突未融合。它不是人中外侧的唇裂。
:::

:::pitfall{label="上颌突对内侧鼻突是唇裂，对外侧鼻突是面斜裂，不要对调"}
同一上颌突，没融合同侧内侧鼻突 → 裂在人中外侧，叫唇裂；没融合同侧外侧鼻突 → 裂在眼内眦与口角之间，叫面斜裂。内侧对人中，外侧对眼裂到口角。写成“外侧鼻突未融合也是唇裂”，两条裂会并成一条。
:::

## 3. 腭裂

腭裂（cleft palate）也较常见，可有不同的类型。因外侧腭突与正中腭突未融合所致者称前腭裂（单侧或双侧，常伴发唇裂），表现为切齿孔至切齿之间的裂隙；因左右外侧腭突未在中线融合所致者称正中腭裂，表现为从切齿孔至腭垂间的矢状裂隙；前腭裂和正中腭裂兼有者称全腭裂（见图 22-12、图 22-13）。

:::definition{label="腭裂"}
腭裂（cleft palate）也较常见，按未融合的突起分成前腭裂、正中腭裂和全腭裂三种类型。
:::

:::definition{label="前腭裂"}
前腭裂因外侧腭突与正中腭突未融合所致，可为单侧或双侧，常伴发唇裂。表现为切齿孔至切齿之间的裂隙。
:::

:::definition{label="正中腭裂"}
正中腭裂因左右外侧腭突未在中线融合所致。表现为从切齿孔至腭垂间的矢状裂隙。
:::

:::definition{label="全腭裂"}
全腭裂是前腭裂和正中腭裂兼有者。既有切齿孔以前（至切齿）的裂，又有切齿孔至腭垂的矢状裂。
:::

:::concept{term="先问裂在切齿孔以前还是切齿孔到腭垂，再问未融合的是外侧腭突与正中腭突，还是左右外侧腭突"}
看见腭裂，先用切齿孔当尺子。切齿孔到切齿之间的裂是前腭裂，对应外侧腭突与正中腭突未融合，常伴唇裂。切齿孔到腭垂的矢状裂是正中腭裂，对应左右外侧腭突未在中线融合。两段都有就是全腭裂。把腭裂一律听成“上唇裂到嗓子眼”，前腭、正中、全腭三张类型表会并成一句。
:::

:::compare{title="前腭裂、正中腭裂与全腭裂"}
| 项目 | 前腭裂 | 正中腭裂 | 全腭裂 |
|------|--------|----------|--------|
| 未融合 | 外侧腭突与正中腭突 | 左右外侧腭突未在中线融合 | 前腭裂和正中腭裂兼有 |
| 裂隙范围 | 切齿孔至切齿之间 | 切齿孔至腭垂的矢状裂隙 | 两段都有 |
| 单双侧 | 单侧或双侧 | 中线一条 | 依兼有情况 |
| 常伴发 | 常伴发唇裂 | 教材与图 22-12B 单独画出 | 如图 22-12C：唇裂合并全腭裂 |
:::

## 4. 四肢畸形

四肢畸形包括：① 无肢畸形，表现为一个或多个肢体完全缺如或局部缺如（如无前臂、无手、无指，下肢亦然）；② 短肢畸形，表现为四肢短小、海豹样手或足畸形（手或足长在短小的肢体上，或直接长在躯干上）；③ 四肢分化障碍，如某块肌或肌群缺如、关节发育不良、骨畸形、骨融合、马蹄内翻足（即足底内翻）、多指（趾）、并指（趾）等（图 22-14）。

:::definition{label="无肢畸形"}
无肢畸形表现为一个或多个肢体完全缺如或局部缺如，例如无前臂、无手、无指，下肢亦然。缺的是整段或局部肢体，不是短小后还连着手、足。
:::

:::definition{label="短肢畸形"}
短肢畸形表现为四肢短小，包括海豹样手或足畸形：手或足长在短小的肢体上，或直接长在躯干上。
:::

:::definition{label="海豹样手或足畸形"}
海豹样手或足是短肢畸形的一种表现：手或足长在短小的肢体上，或直接长在躯干上，外观像鳍足。它归在短肢，不归在无肢，也不归在并指。
:::

:::definition{label="四肢分化障碍"}
四肢分化障碍包括：某块肌或肌群缺如、关节发育不良、骨畸形、骨融合、马蹄内翻足（即足底内翻）、多指（趾）、并指（趾）等。肢体大体还在，分化或分隔出了问题。
:::

:::definition{label="马蹄内翻足"}
马蹄内翻足即足底内翻。教材把它列在四肢分化障碍里，不是无肢，也不是海豹样足。
:::

:::compare{title="无肢、短肢与四肢分化障碍"}
| 项目 | 无肢畸形 | 短肢畸形 | 四肢分化障碍 |
|------|----------|----------|--------------|
| 表现 | 一个或多个肢体完全缺如或局部缺如 | 四肢短小；海豹样手或足 | 肌缺如、关节发育不良、骨畸形或融合、马蹄内翻足、多指、并指等 |
| 例子 | 无前臂、无手、无指（下肢亦然） | 手或足长在短小肢体上，或直接长在躯干上 | 足底内翻；多指（趾）；并指（趾） |
| 与肢芽的关系 | 肢芽未发生或远段未形成 | 肢芽过短 | 三段和手板、足板大致出现，凋亡或分化失常 |
| 不要听成 | 只是短了一截 | 完全没有手或足 | 肢体缺如 |
:::

:::example{label="并指是线间凋亡不足"}
第 $8$ 周末手指足趾靠指（趾）线间细胞凋亡才分开。线间细胞未凋亡干净，就是并指（趾）。它和“少长了一个肢芽”不是同一本账，应放在四肢分化障碍，而不是无肢。
:::

:::pitfall{label="无肢、短肢、分化障碍三张名单不要并成“四肢不好”"}
无肢是缺如（整段或局部没有）；短肢是短小，手、足还可以直接长在躯干上（海豹样）；分化障碍是肌、关节、骨、足的姿势以及多指、并指出了问题。把海豹样写成无肢，或把并指写成短肢，图 22-14 那组分化障碍会对错户头。
:::

:::note{label="图22-14 四肢分化障碍"}
教材图 22-14 为四肢分化障碍：A. 多指；B. 并指；C. 多趾和并趾。原图未能收入数字版，正文仍按教材保留“图 22-14”出处。
:::

:::cause-effect{title="未融合的那一对突起，决定裂开在哪一条线上"}
- 因：上颌突与同侧内侧鼻突未融合
- 果：唇裂，裂沟在人中外侧
- 因：上颌突与同侧外侧鼻突未融合
- 果：面斜裂，裂在眼内眦与口角之间
- 因：外侧腭突与正中腭突未融合
- 果：前腭裂（切齿孔至切齿），常伴唇裂
- 因：左右外侧腭突未在中线融合
- 果：正中腭裂（切齿孔至腭垂）
- 制约：兼有前腭裂和正中腭裂才称全腭裂；唇裂还可伴牙槽突裂和腭裂
:::

:::insight{label="裂的位置就是胚胎时那条该融未融的缝"}
人中外侧对着上颌突—内侧鼻突缝，眼内眦到口角对着上颌突—外侧鼻突缝，切齿孔以前对着外侧腭突—正中腭突缝，切齿孔到腭垂对着左右外侧腭突的中线缝。把畸形背成“脸裂了、腭裂了”而不指缝，五突和两对腭突的正常发生会失去对照。
:::

:::note{label="唇腭裂"}
唇腭裂是最常见的颜面部先天畸形。导致唇腭裂发生的原因很多，如遗传因素、孕期维生素缺乏、病毒感染、X 线照射、物理损伤、内分泌因素等。预防唇腭裂的关键在于孕期妇女的营养均衡、避免有害物质暴露，以及定期产前检查。我国不仅关注并预防唇腭裂的发生，也高度重视唇腭裂患儿的早期治疗。

唇腭裂儿童被称为“无法微笑的天使”，大量的中国医疗和非医疗志愿者致力于为患有唇腭裂和其他面部畸形的儿童提供免费手术治疗。他们通过与国内外的医疗专家合作，组织医疗团队为患有唇腭裂和面部畸形的儿童提供手术、医疗和社会支持，还为患儿及家庭提供术后治疗、康复训练、心理咨询等方面的帮助，全方位促进患儿的康复，减轻家庭的经济、精神负担等。
:::

:::timeline{period="畸形对照：该融合或该凋亡的步骤一旦停下"}
- **唇裂（最常见）** 上颌突与同侧内侧鼻突未融合 → 裂在人中外侧；可单侧或双侧
- **少见正中裂** 左右内侧鼻突未融合 → 上唇正中裂；两侧下颌突未融合 → 下唇正中裂
- **宽大正中唇裂** 内侧鼻突发育不良，人中缺损
- **面斜裂** 上颌突与同侧外侧鼻突未融合 → 眼内眦与口角之间
- **前腭裂** 外侧腭突与正中腭突未融合 → 切齿孔至切齿；常伴唇裂
- **正中腭裂** 左右外侧腭突未中线融合 → 切齿孔至腭垂
- **全腭裂** 前腭裂与正中腭裂兼有
- **无肢 / 短肢 / 分化障碍** 缺如；短小或海豹样手或足；肌、关节、骨、马蹄内翻足、多指、并指
:::

:::tip{label="裂的口诀"}
人中外：上颌对内侧鼻突（唇裂）。眼到口：上颌对外侧鼻突（面斜裂）。切齿孔前：外侧腭突对正中腭突。切齿孔到腭垂：左右外侧腭突对中线。
:::

:::keypoint{label="唇裂对人中外侧，面斜裂对眼口连线，腭裂用切齿孔分段"}
- 唇裂最常见；上颌突与同侧内侧鼻突未融合 → 人中外侧；单或双侧。少见正中裂（左右内侧鼻突或下颌突未融合）；内侧鼻突发育不良 → 宽大正中唇裂。可伴牙槽突裂和腭裂。
- 面斜裂：眼内眦与口角之间；上颌突与同侧外侧鼻突未融合。
- 前腭裂：外侧腭突与正中腭突未融合，切齿孔至切齿，常伴唇裂。正中腭裂：左右外侧腭突未中线融合，切齿孔至腭垂。全腭裂：兼有。
- 四肢：无肢（完全或局部缺如）；短肢 / 海豹样手或足；分化障碍（肌缺如、关节不良、骨畸形或融合、马蹄内翻足、多指、并指）。
:::

## 本章小结

颜面主要由胚体头端 $5$ 个突起融合演变形成，即额鼻突、左右上颌突和左右下颌突，它们围成口凹，即原始口腔。在额鼻突的下部形成一对鼻板，鼻板中央凹陷为鼻窝，鼻窝两侧的突起分别称内侧鼻突和外侧鼻突。左右下颌突在中线融合，发育为下颌与下唇。左右上颌突也向中线生长并与同侧的外侧鼻突和内侧鼻突融合，形成上唇的外侧部分与上颌。左右内侧鼻突融合、下延，形成鼻梁、鼻尖、上唇的正中部分和人中。外侧鼻突发育为鼻的侧壁和鼻翼。额鼻突发育成前额。鼻窝向深部扩大，形成原始鼻腔。至第 $8$ 周末，胚颜面初具人貌。

腭起源于正中腭突与外侧腭突两部分。正中腭突将演化为腭前部的一小部分。左右外侧腭突在中线融合，形成腭的大部分。腭将原始口腔与原始鼻腔分隔成为永久口腔和鼻腔。来源于额鼻突和内侧鼻突的鼻中隔，将鼻腔一分为二。

四肢由上肢芽和下肢芽发育形成。上肢芽的 $3$ 段分别发育为上臂、前臂和手，下肢芽则发育为大腿、小腿和足。

颜面发生过程中最常见的畸形是唇裂，常因上颌突与同侧内侧鼻突未融合所致。面斜裂位于眼内眦与口角之间，因上颌突与同侧外侧鼻突未融合所致。外侧腭突与正中腭突或左右外侧腭突未融合均可致腭裂，有前腭裂、正中腭裂和全腭裂 $3$ 种类型。四肢畸形包括无肢畸形、短肢畸形和四肢分化障碍所致畸形。

:::definition{label="五突围口凹"}
颜面主要由胚体头端 $5$ 个突起融合演变形成：额鼻突、左右上颌突和左右下颌突。它们围成口凹，即原始口腔。
:::

:::definition{label="鼻板、鼻窝与内、外侧鼻突（小结）"}
额鼻突下部形成一对鼻板，中央凹陷为鼻窝；鼻窝两侧的突起分别称内侧鼻突和外侧鼻突。
:::

:::compare{title="下颌突、上颌突与内侧鼻突的职分"}
| 突起 | 融合对象 | 发育结果 |
|------|----------|----------|
| 左右下颌突 | 中线彼此融合 | 下颌与下唇 |
| 左右上颌突 | 向中线生长，与同侧外侧鼻突和内侧鼻突融合 | 上唇的外侧部分与上颌 |
| 左右内侧鼻突 | 彼此融合并下延，下缘与上颌突融合 | 鼻梁、鼻尖、上唇的正中部分和人中 |
| 外侧鼻突 | 与同侧上颌突融合 | 鼻的侧壁和鼻翼 |
| 额鼻突其余部分 | — | 前额 |
:::

:::compare{title="腭的两突"}
| 项目 | 正中腭突 | 外侧腭突 |
|------|----------|----------|
| 来源 | 左右内侧鼻突融合后向原始口腔内长出 | 左右上颌突向原始口腔内长出 |
| 去向 | 腭前部的一小部分 | 在中线融合，形成腭的大部分 |
| 未融合 | 与外侧腭突未融合 → 前腭裂 | 左右未在中线融合 → 正中腭裂 |
:::

:::note{label="小结里的鼻中隔与第8周末"}
来源于额鼻突和内侧鼻突的鼻中隔，将鼻腔一分为二。鼻窝向深部扩大形成原始鼻腔；腭把原始口腔与原始鼻腔分成永久口腔和鼻腔。至第 $8$ 周末，胚颜面初具人貌——与手指足趾形成落在同一周末。
:::

:::keypoint{label="五突围口凹，两突成腭，肢芽三段，裂按未融合的缝来认"}
- $5$ 突：额鼻突 + 左右上颌突 + 左右下颌突 → 口凹（原始口腔）。
- 鼻板 → 鼻窝 → 内侧鼻突、外侧鼻突。下颌突 → 下颌与下唇；上颌突 → 上唇外侧与上颌；内侧鼻突 → 鼻梁、鼻尖、上唇正中和人中；外侧鼻突 → 鼻侧壁和鼻翼；额鼻突 → 前额。
- 正中腭突 = 腭前部一小部分；左右外侧腭突中线融合 = 腭的大部分；鼻中隔把鼻腔一分为二。
- 上肢芽 $3$ 段：上臂、前臂、手；下肢芽 $3$ 段：大腿、小腿、足。
- 唇裂：上颌突 × 同侧内侧鼻突。面斜裂：上颌突 × 同侧外侧鼻突。腭裂三种：前腭裂、正中腭裂、全腭裂。四肢：无肢、短肢、分化障碍。
:::

:::memory{label="本节必背要点"}
- [ ] 唇裂（cleft lip）是最常见的颜面畸形，多见于上唇。
- [ ] 常见唇裂因上颌突与同侧内侧鼻突未融合所致，裂沟位于人中外侧。
- [ ] 唇裂多为单侧，也可见双侧者。
- [ ] 左、右内侧鼻突未融合可致上唇正中裂；两侧下颌突未融合可致下唇正中裂；均少见。
- [ ] 内侧鼻突发育不良、人中缺损，则出现宽大的正中唇裂。
- [ ] 唇裂可伴有牙槽突裂和腭裂。
- [ ] 面斜裂（oblique facial cleft）位于眼内眦与口角之间，因上颌突与同侧外侧鼻突未融合所致。
- [ ] 前腭裂因外侧腭突与正中腭突未融合所致，单侧或双侧，常伴发唇裂，表现为切齿孔至切齿之间的裂隙。
- [ ] 正中腭裂因左右外侧腭突未在中线融合所致，表现为从切齿孔至腭垂间的矢状裂隙。
- [ ] 前腭裂和正中腭裂兼有者称全腭裂。
- [ ] 无肢畸形：一个或多个肢体完全缺如或局部缺如（如无前臂、无手、无指，下肢亦然）。
- [ ] 短肢畸形：四肢短小、海豹样手或足畸形（手或足长在短小的肢体上，或直接长在躯干上）。
- [ ] 四肢分化障碍：肌或肌群缺如、关节发育不良、骨畸形、骨融合、马蹄内翻足（足底内翻）、多指（趾）、并指（趾）等。
