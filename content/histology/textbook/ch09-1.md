# 一、动脉和静脉管壁的一般结构

循环系统（circulatory system）是连续而封闭的管道系统，包括心血管系统和淋巴管系统，前者由动脉、毛细血管、静脉和心脏组成，后者由毛细淋巴管、淋巴管和淋巴导管组成。本章先把动脉和静脉共有的内膜、中膜、外膜三层摊开；动脉、毛细血管、静脉、微循环、淋巴管系统和心脏各立一节。

:::definition{label="循环系统"}
循环系统（circulatory system）是连续而封闭的管道系统，包括心血管系统和淋巴管系统。心血管系统由动脉、毛细血管、静脉和心脏组成；淋巴管系统由毛细淋巴管、淋巴管和淋巴导管组成。
:::

:::definition{label="心血管系统"}
心血管系统由动脉、毛细血管、静脉和心脏组成，是循环系统中运送血液的封闭管道。
:::

:::definition{label="淋巴管系统"}
淋巴管系统由毛细淋巴管、淋巴管和淋巴导管组成，把组织液中的水、电解质和大分子物质等输送入血。详见第六节。
:::

:::concept{term="先问这根管子走血还是走淋巴"}
看见一条管，先问管腔里是血液还是淋巴。走血液的是心血管系统：心脏泵血，动脉送出，毛细血管交换，静脉导回。走淋巴的是淋巴管系统：毛细淋巴管以盲端起于组织，再汇成淋巴管和淋巴导管入血。把“循环系统”听成“只有心脏和血管”，会把淋巴那一本回流账做丢。
:::

:::compare{title="心血管系统与淋巴管系统"}
| 项目 | 心血管系统 | 淋巴管系统 |
|------|------------|------------|
| 组成 | 动脉、毛细血管、静脉和心脏 | 毛细淋巴管、淋巴管和淋巴导管 |
| 管腔内容 | 血液 | 淋巴（源自组织液） |
| 是否封闭 | 连续而封闭 | 盲端起始，最终汇入静脉 |
| 本章位置 | 第一至五节、第七节 | 第六节 |
:::

动脉和静脉管壁从管腔内向外依次分为内膜、中膜和外膜 3 层（图 9-1）。毛细血管壁只有内皮、基膜和周细胞，不按这三层来写。

:::definition{label="血管壁三层"}
动脉和静脉管壁从管腔内向外依次分为内膜（tunica intima）、中膜（tunica media）和外膜（tunica adventitia）3 层。
:::

:::pitfall{label="三层是动脉和静脉的通式，不要套到毛细血管上"}
教材把内膜、中膜、外膜写成动脉和静脉管壁的一般结构。毛细血管管径只有 $6\sim 8\,\mu\mathrm{m}$，壁由内皮细胞、基膜和周细胞构成，没有中膜平滑肌层，也没有外膜那一层疏松结缔组织。把三层通式套到毛细血管上，后面连续、有孔、血窦三本分类账会整层错位。
:::

## （一）内膜

内膜（tunica intima）最薄，从内向外又分为内皮、内皮下层和内弹性膜 3 层。

:::definition{label="内膜"}
内膜（tunica intima）是血管壁最薄、最靠近管腔的一层，从内向外又分为内皮、内皮下层和内弹性膜 3 层。
:::

:::concept{term="先问内膜三件套：内皮、内皮下层，还是内弹性膜"}
内膜不是“贴在腔面的那一层扁平细胞”一句话能打发。从腔面往外数：内皮铺腔面，内皮下层是薄层结缔组织，内弹性膜由弹性蛋白组成、是内膜与中膜的分界。大动脉内弹性膜不明显，中动脉、小动脉才亮出波浪状内弹性膜。把内膜听成“只有内皮”，内皮下层沉积脂质、内弹性膜辨认肌性动脉那两本账都会做丢。
:::

### 1. 内皮

内皮是衬贴于腔面的单层扁平上皮。光镜下，内皮细胞很薄，细胞质很少，其细胞核所在部位较明显。扫描电镜下，内皮细胞大多呈梭形，细胞核位于细胞中部致其所在部位隆起，细胞呈鹅卵石样镶嵌排列，纵轴与血流方向一致。透射电镜下，内皮细胞游离面即腔面可见稀疏而大小不等的细胞质突起，细胞膜的腔面还覆盖 $30\sim 60\,\mathrm{nm}$ 厚的细胞衣；内皮细胞基底面有基膜。相邻内皮细胞之间有紧密连接和缝隙连接。内皮细胞还具有如下的超微结构特征。

:::definition{label="内皮"}
内皮是衬贴于血管腔面的单层扁平上皮。光镜下细胞很薄、胞质很少，核所在部位较明显。扫描电镜下细胞大多呈梭形，核位于中部致该处隆起，呈鹅卵石样镶嵌排列，纵轴与血流方向一致。基底面有基膜；相邻细胞之间有紧密连接和缝隙连接。
:::

:::definition{label="内皮细胞衣"}
内皮细胞膜的腔面覆盖 $30\sim 60\,\mathrm{nm}$ 厚的细胞衣。透射电镜下，游离面还可见稀疏而大小不等的细胞质突起。
:::

**（1）质膜小泡** 内皮细胞的细胞质中含直径 $60\sim 70\,\mathrm{nm}$ 的质膜小泡（plasmalemmal vesicle）。与细胞游离面或基底面融合的质膜小泡称小凹。质膜小泡可相互串联，与小凹一起形成穿过内皮细胞的暂时性孔道，称穿内皮性小管（transendothelial channel）。其功能是输送物质，还能作为储备的细胞膜用于细胞的扩张或延伸。

:::definition{label="质膜小泡"}
质膜小泡（plasmalemmal vesicle）位于内皮细胞胞质中，直径 $60\sim 70\,\mathrm{nm}$。与游离面或基底面融合者称小凹。可相互串联，与小凹一起形成穿内皮性小管，输送物质，并作为储备细胞膜用于细胞的扩张或延伸。
:::

:::definition{label="小凹"}
小凹是与内皮细胞游离面或基底面融合的质膜小泡。与质膜小泡串联后，可形成穿过内皮细胞的暂时性孔道。
:::

:::definition{label="穿内皮性小管"}
穿内皮性小管（transendothelial channel）是质膜小泡相互串联、并与小凹一起形成的穿过内皮细胞的暂时性孔道。功能是输送物质，还能作为储备的细胞膜用于细胞的扩张或延伸。
:::

**（2）W-P 小体** 内皮细胞的细胞质中可见有膜包裹的杆状结构，为怀布尔-帕拉德小体（Weibel-Palade body），又称 W-P 小体。W-P 小体是内皮细胞特有的细胞器，长约 $3\,\mu\mathrm{m}$，直径 $0.1\sim 0.3\,\mu\mathrm{m}$，外包单位膜，内含 $6\sim 26$ 根直径约 $15\,\mathrm{nm}$ 的平行细管和中等致密的基质，其功能可能是合成和贮存与凝血相关的第Ⅷ因子相关抗原。当血管内皮受损时，第Ⅷ因子相关抗原使血小板附着于内皮下层，形成血小板栓，防止血液外流。

:::definition{label="W-P 小体"}
W-P 小体即怀布尔-帕拉德小体（Weibel-Palade body），是内皮细胞特有的细胞器：有膜包裹的杆状结构，长约 $3\,\mu\mathrm{m}$，直径 $0.1\sim 0.3\,\mu\mathrm{m}$，外包单位膜，内含 $6\sim 26$ 根直径约 $15\,\mathrm{nm}$ 的平行细管和中等致密的基质。功能可能是合成和贮存第Ⅷ因子相关抗原。大动脉内皮细胞的 W-P 小体尤为丰富。
:::

:::definition{label="第Ⅷ因子相关抗原"}
第Ⅷ因子相关抗原由 W-P 小体合成和贮存。血管内皮受损时，它使血小板附着于内皮下层，形成血小板栓，防止血液外流。
:::

:::cause-effect{title="内皮受损后第Ⅷ因子相关抗原怎样写成血小板栓"}
- 因：血管内皮受损，W-P 小体释放第Ⅷ因子相关抗原
- 果：血小板附着于内皮下层，形成血小板栓
- 影响：暂时堵住缺口，防止血液外流；若内皮损伤持续并伴脂质沉积，下一节动脉粥样硬化账从这里起笔
:::

:::pitfall{label="W-P 小体是内皮特有细胞器，不要当成溶酶体或分泌颗粒的别名"}
W-P 小体外包单位膜、内含平行细管，是内皮细胞的身份证，不是普通溶酶体，也不是质膜小泡的另一种叫法。质膜小泡管物质转运，直径只有 $60\sim 70\,\mathrm{nm}$；W-P 小体管凝血相关抗原，长度到 $3\,\mu\mathrm{m}$。把两者并成“内皮里的小泡”，大动脉“W-P 小体尤为丰富”那一句就失去辨认价值。
:::

内皮的主要功能包括：①维持血管壁的完整性而有利于血液流动；②构成屏障性结构而选择性通透物质；③细胞内的微丝收缩可改变细胞间隙宽度和细胞连接的紧密程度，影响和调节血管通透性；④合成和分泌多种生物活性物质，如具有强烈收缩血管作用的内皮素（endothelin，ET），具有舒张血管作用的内皮源性舒血管因子（endothelium-derived relaxing factor，EDRF），即一氧化氮（nitric oxide，NO）；⑤合成组织型纤溶酶原激活物（tissue-type plasminogen activator，tPA）和前列环素，降解 5-羟色胺、组胺和去甲肾上腺素等；⑥参与物质代谢，如内皮细胞表面的血管紧张素转换酶（angiotensin converting enzyme，ACE）能将血浆中的血管紧张素Ⅰ转换为收缩血管作用更强的血管紧张素Ⅱ。

:::definition{label="内皮素"}
内皮素（endothelin，ET）是内皮细胞合成和分泌的生物活性物质，具有强烈收缩血管作用。
:::

:::definition{label="内皮源性舒血管因子"}
内皮源性舒血管因子（endothelium-derived relaxing factor，EDRF）即一氧化氮（nitric oxide，NO），由内皮细胞合成和分泌，具有舒张血管作用。与内皮素构成一对缩/舒血管信号。
:::

:::definition{label="血管紧张素转换酶"}
血管紧张素转换酶（angiotensin converting enzyme，ACE）位于内皮细胞表面，能将血浆中的血管紧张素Ⅰ转换为收缩血管作用更强的血管紧张素Ⅱ。它与血管平滑肌分泌的肾素、血管紧张素原共同构成血管的肾素-血管紧张素系统。
:::

:::compare{title="内皮的六项主要功能"}
| 序号 | 功能 | 结构或分子落点 |
|------|------|----------------|
| ① | 维持管壁完整性，利于血液流动 | 单层扁平内皮铺满腔面 |
| ② | 构成屏障，选择性通透物质 | 紧密连接、基膜、细胞衣 |
| ③ | 调节通透性 | 微丝收缩改变间隙宽度和连接紧密程度 |
| ④ | 合成、分泌缩/舒血管物质 | 内皮素（缩）；EDRF 即 NO（舒） |
| ⑤ | 抗凝、降解活性胺类 | tPA、前列环素；降解 5-羟色胺、组胺、去甲肾上腺素 |
| ⑥ | 参与物质代谢 | 表面 ACE：血管紧张素Ⅰ → 血管紧张素Ⅱ |
:::

:::insight{label="内皮不只是衬里，还是活的分泌面和酶面"}
光镜下内皮薄得几乎只剩核。功能账却有六条：铺腔面、做屏障、用微丝调间隙、分泌 ET 和 NO、合成 tPA 和前列环素、用表面 ACE 把血管紧张素Ⅰ换成Ⅱ。把内皮听成“一层扁平的墙纸”，中膜平滑肌的缩舒就变成无来源的命令；把 ET 和 NO 记成中膜产物，又会把分泌面写错层。
:::

### 2. 内皮下层

内皮下层（subendothelial layer）位于内皮与内弹性膜之间的薄层结缔组织，含少量胶原纤维、弹性纤维等。

:::definition{label="内皮下层"}
内皮下层（subendothelial layer）是位于内皮与内弹性膜之间的薄层结缔组织，含少量胶原纤维、弹性纤维等。大动脉的内皮下层较厚，为疏松结缔组织，含纵行胶原纤维和少量平滑肌纤维。
:::

:::note{label="内皮下层是脂质和泡沫细胞落地的那一层"}
本节只写它是薄层结缔组织。下一节大动脉中膜平滑肌迁入内膜、插入框里胆固醇沉积、单核细胞转化为巨噬细胞，都发生在内皮下层。看见“内膜增厚”，先问是不是内皮下层被细胞间质和泡沫细胞垫厚了，不要把账做到中膜弹性膜上。
:::

### 3. 内弹性膜

内弹性膜（internal elastic membrane）由弹性蛋白组成，是内膜与中膜分界的膜状结构。HE 染色时呈亮粉红色，因血管壁收缩而常呈波浪状。

:::definition{label="内弹性膜"}
内弹性膜（internal elastic membrane）由弹性蛋白组成，是内膜与中膜分界的膜状结构。HE 染色呈亮粉红色，因管壁收缩而常呈波浪状。中动脉有 $1\sim 2$ 层明显的内弹性膜；小动脉内弹性膜明显；大动脉和微动脉内弹性膜不明显或阙如。
:::

:::pitfall{label="波浪状亮粉红是内弹性膜，不要当成皱缩伪影"}
HE 里紧贴内皮外侧的那条亮粉红色波浪线，是弹性蛋白组成的内弹性膜，管壁一收缩就皱起来。不要当成切片折叠，也不要把中膜里那几十层窗孔弹性膜（大动脉）和这一层分界膜混成一张。辨认肌性动脉，第一眼找的就是这层波浪膜。
:::

## （二）中膜

中膜（tunica media）由弹性膜、平滑肌纤维和结缔组织构成，其厚度及组成成分在不同血管之间的差异较大。中膜的弹性膜和弹性纤维使扩张的血管回缩，胶原纤维则维持血管张力。

与内脏平滑肌纤维相比，血管平滑肌纤维细长且常有分支。血管平滑肌纤维具有两种功能状态或表型，以合成及分泌功能为主的称合成表型，以收缩功能为主的称收缩表型。合成表型的血管平滑肌纤维的轮廓不规则，细胞核大，细胞核质比及平均直径均较大，细胞质内的游离核糖体较多，粗面内质网扩张，高尔基复合体发达。收缩表型的血管平滑肌纤维较小，呈纺锤形，细胞核近似长杆状，细胞核质比较小，高尔基复合体、粗面内质网和游离核糖体不发达，仅分布于细胞核周围区域，细胞质内的肌丝和中间丝均较多，肌丝的附着结构（密体和密斑）也增多。血管平滑肌纤维之间有黏着小带和缝隙连接；血管平滑肌纤维还可与内皮细胞形成肌-内皮连接，接受血液或内皮细胞的化学信息。血管平滑肌纤维具有产生胶原纤维、弹性纤维和基质等细胞间质成分的能力，发挥类似于成纤维细胞的作用。血管平滑肌纤维还可分泌多种蛋白质，如肾素和血管紧张素原，它们与内皮细胞表面的血管紧张素转换酶共同构成血管的肾素-血管紧张素系统。

:::definition{label="中膜"}
中膜（tunica media）由弹性膜、平滑肌纤维和结缔组织构成，厚度及组成成分在不同血管之间差异较大。弹性膜和弹性纤维使扩张的血管回缩，胶原纤维维持血管张力。以中膜变化最能区分大、中、小、微动脉。
:::

:::definition{label="血管平滑肌纤维"}
与内脏平滑肌纤维相比，血管平滑肌纤维细长且常有分支。纤维之间有黏着小带和缝隙连接，还可与内皮细胞形成肌-内皮连接。能产生胶原纤维、弹性纤维和基质，并分泌肾素和血管紧张素原。
:::

:::definition{label="合成表型"}
合成表型是以合成及分泌功能为主的血管平滑肌纤维：轮廓不规则，核大，核质比及平均直径较大，游离核糖体较多，粗面内质网扩张，高尔基复合体发达。
:::

:::definition{label="收缩表型"}
收缩表型是以收缩功能为主的血管平滑肌纤维：细胞较小，呈纺锤形，核近似长杆状，核质比较小；高尔基复合体、粗面内质网和游离核糖体不发达，仅分布于核周；肌丝和中间丝较多，密体和密斑也增多。
:::

:::definition{label="肌-内皮连接"}
肌-内皮连接是血管平滑肌纤维与内皮细胞之间的连接，使平滑肌能够接受血液或内皮细胞的化学信息。
:::

:::definition{label="血管的肾素-血管紧张素系统"}
血管平滑肌纤维分泌肾素和血管紧张素原，与内皮细胞表面的 ACE 共同构成血管的肾素-血管紧张素系统。ACE 将血管紧张素Ⅰ转换为作用更强的血管紧张素Ⅱ。
:::

:::compare{title="血管平滑肌的合成表型与收缩表型"}
| 项目 | 合成表型 | 收缩表型 |
|------|----------|----------|
| 主导功能 | 合成及分泌 | 收缩 |
| 轮廓 | 不规则 | 较小，纺锤形 |
| 核 | 大，核质比及平均直径较大 | 近似长杆状，核质比较小 |
| 合成装置 | 游离核糖体多，粗面内质网扩张，高尔基复合体发达 | 高尔基复合体、粗面内质网和游离核糖体不发达，仅核周 |
| 收缩装置 | 相对不突出 | 肌丝、中间丝较多；密体、密斑增多 |
| 病理含义 | 可迁入内膜增生、产生细胞间质，参与动脉粥样硬化 | 执行管径舒缩，构成外周阻力 |
:::

:::pitfall{label="血管平滑肌能当半个成纤维细胞，不要只背它会收缩"}
教材把产生胶原纤维、弹性纤维和基质写进中膜平滑肌，还让它分泌肾素和血管紧张素原。收缩只是表型之一。大动脉中膜平滑肌病理状态下迁入内膜增生，靠的就是合成表型，不是把收缩表型的纺锤细胞整条搬进内膜。把中膜听成“一层只会缩的肉”，内膜增厚和肾素-血管紧张素那两本账都会做丢。
:::

## （三）外膜

外膜（tunica adventitia）由疏松结缔组织构成，成纤维细胞具有修复外膜的能力，弹性纤维和胶原纤维沿血管纵轴呈螺旋状或纵向分布。较大的动脉在中膜与外膜交界处有外弹性膜（external elastic membrane），其厚度比内弹性膜薄。在外膜的结缔组织中还含有较小的血管、淋巴管和神经纤维，其分支可伸入中膜。

内膜一般无血管分布，其营养由血液渗透供给。为外膜和中膜提供营养的血管称营养血管（vasa vasorum）。

:::definition{label="外膜"}
外膜（tunica adventitia）由疏松结缔组织构成。成纤维细胞具有修复外膜的能力；弹性纤维和胶原纤维沿血管纵轴呈螺旋状或纵向分布。结缔组织中含较小的血管、淋巴管和神经纤维，分支可伸入中膜。
:::

:::definition{label="外弹性膜"}
外弹性膜（external elastic membrane）位于较大动脉的中膜与外膜交界处，厚度比内弹性膜薄。大动脉外弹性膜不明显；较大的中动脉可见断续的外弹性膜；小动脉、微动脉无外弹性膜。
:::

:::definition{label="营养血管"}
营养血管（vasa vasorum）是为外膜和中膜提供营养的血管。内膜一般无血管分布，其营养由管腔内血液渗透供给。
:::

:::compare{title="内膜、中膜与外膜"}
| 项目 | 内膜 | 中膜 | 外膜 |
|------|------|------|------|
| 英文 | tunica intima | tunica media | tunica adventitia |
| 位置 | 最内，贴管腔 | 中间层 | 最外 |
| 组成 | 内皮、内皮下层、内弹性膜 | 弹性膜、平滑肌纤维、结缔组织 | 疏松结缔组织；较大动脉可有外弹性膜 |
| 厚度 | 最薄 | 不同血管差异最大 | 静脉常比中膜厚 |
| 营养 | 一般无血管，靠管腔血液渗透 | 营养血管分支可伸入 | 含营养血管、淋巴管和神经 |
| 光镜线索 | 内皮核隆起；内弹性膜 HE 亮粉红、波浪状 | 大动脉多层弹性膜；中动脉多层环行平滑肌 | 纵行/螺旋胶原与弹性纤维；成纤维细胞 |
:::

:::concept{term="先问营养从哪来：腔面渗透，还是营养血管"}
内膜贴着血流，自己一般没有血管，靠管腔里的血液渗透养活。中膜和外膜要靠外膜里的营养血管供血，分支还可以伸进中膜。管壁厚到一定程度，腔面渗透够不到中膜深部，必须另开这套 vasa vasorum。把整条动脉壁都写成“靠管腔养活”，大动脉外膜和中膜外带的血供账会做空。
:::

:::insight{label="三层里变化最大的是中膜，下一节按中膜给动脉分型"}
内膜通式三件套、外膜通式疏松结缔组织，各型动脉都能对上。真正用来给大、中、小、微动脉分型的，是中膜：弹性膜层数、平滑肌层数、有没有内外弹性膜。本节先把通式立住；下一节把中膜改写成 $40\sim 70$ 层弹性膜、 $10\sim 40$ 层环行平滑肌、 $3\sim 9$ 层、 $1\sim 2$ 层那一把尺子。
:::

:::keypoint{label="管壁先立三层，内膜再立内皮、质膜小泡和 W-P 小体"}
- 循环系统 = 心血管系统（动脉、毛细血管、静脉、心脏）+ 淋巴管系统（毛细淋巴管、淋巴管、淋巴导管）。
- 动脉和静脉管壁由内向外：内膜、中膜、外膜。
- 内膜最薄：内皮（单层扁平）+ 内皮下层 + 内弹性膜（弹性蛋白，HE 亮粉红波浪状）。
- 内皮：梭形、鹅卵石镶嵌、纵轴顺血流；腔面细胞衣 $30\sim 60\,\mathrm{nm}$；邻接为紧密连接和缝隙连接。
- 质膜小泡直径 $60\sim 70\,\mathrm{nm}$，可串联成穿内皮性小管；W-P 小体长约 $3\,\mu\mathrm{m}$、直径 $0.1\sim 0.3\,\mu\mathrm{m}$，内含 $6\sim 26$ 根约 $15\,\mathrm{nm}$ 细管，贮第Ⅷ因子相关抗原。
- 内皮分泌 ET（缩）和 NO（舒），表面 ACE 转换血管紧张素Ⅰ为Ⅱ。
- 中膜：弹性膜回缩、胶原维持张力；血管平滑肌有合成表型与收缩表型，可分泌肾素和血管紧张素原。
- 外膜为疏松结缔组织；营养血管供外膜和中膜；内膜靠管腔血液渗透。
:::

:::memory{label="本节必背要点"}
- [ ] 循环系统（circulatory system）是连续而封闭的管道系统，包括心血管系统和淋巴管系统。
- [ ] 心血管系统由动脉、毛细血管、静脉和心脏组成；淋巴管系统由毛细淋巴管、淋巴管和淋巴导管组成。
- [ ] 动脉和静脉管壁从管腔内向外依次分为内膜、中膜和外膜 3 层。
- [ ] 内膜（tunica intima）最薄，从内向外分为内皮、内皮下层和内弹性膜 3 层。
- [ ] 内皮是衬贴于腔面的单层扁平上皮；光镜下很薄、胞质很少，核所在部位较明显。
- [ ] 扫描电镜下内皮细胞大多呈梭形，核位于中部致该处隆起，呈鹅卵石样镶嵌排列，纵轴与血流方向一致。
- [ ] 透射电镜下腔面有稀疏、大小不等的胞质突起；腔面覆盖 $30\sim 60\,\mathrm{nm}$ 厚的细胞衣；基底面有基膜。
- [ ] 相邻内皮细胞之间有紧密连接和缝隙连接。
- [ ] 质膜小泡（plasmalemmal vesicle）直径 $60\sim 70\,\mathrm{nm}$；与游离面或基底面融合者称小凹。
- [ ] 质膜小泡可相互串联，与小凹一起形成穿内皮性小管（transendothelial channel），输送物质，并作为储备细胞膜用于扩张或延伸。
- [ ] W-P 小体（Weibel-Palade body）是内皮特有细胞器：杆状、有膜，长约 $3\,\mu\mathrm{m}$，直径 $0.1\sim 0.3\,\mu\mathrm{m}$，内含 $6\sim 26$ 根直径约 $15\,\mathrm{nm}$ 的平行细管和中等致密基质。
- [ ] W-P 小体可能合成和贮存第Ⅷ因子相关抗原；内皮受损时该抗原使血小板附着于内皮下层，形成血小板栓。
- [ ] 内皮功能：维持完整性；屏障性选择性通透；微丝调节通透性；分泌 ET（缩血管）和 EDRF 即 NO（舒血管）；合成 tPA 和前列环素，降解 5-羟色胺、组胺和去甲肾上腺素；表面 ACE 将血管紧张素Ⅰ转换为Ⅱ。
- [ ] 内皮下层（subendothelial layer）位于内皮与内弹性膜之间，为薄层结缔组织，含少量胶原纤维、弹性纤维等。
- [ ] 内弹性膜（internal elastic membrane）由弹性蛋白组成，是内膜与中膜的分界；HE 呈亮粉红色，因管壁收缩常呈波浪状。
- [ ] 中膜（tunica media）由弹性膜、平滑肌纤维和结缔组织构成，不同血管厚度及成分差异较大。
- [ ] 中膜弹性膜和弹性纤维使扩张的血管回缩，胶原纤维维持血管张力。
- [ ] 血管平滑肌纤维比内脏平滑肌细长且常有分支；分合成表型和收缩表型。
- [ ] 合成表型：轮廓不规则，核大，核质比及平均直径较大，游离核糖体多，粗面内质网扩张，高尔基复合体发达。
- [ ] 收缩表型：较小、纺锤形，核近长杆状，核质比较小；合成装置不发达仅核周；肌丝、中间丝较多，密体和密斑增多。
- [ ] 血管平滑肌之间有黏着小带和缝隙连接，并可与内皮形成肌-内皮连接。
- [ ] 血管平滑肌可产生胶原纤维、弹性纤维和基质，并分泌肾素和血管紧张素原，与内皮 ACE 构成血管的肾素-血管紧张素系统。
- [ ] 外膜（tunica adventitia）由疏松结缔组织构成；成纤维细胞可修复外膜；弹性纤维和胶原纤维沿纵轴呈螺旋状或纵向分布。
- [ ] 较大动脉在中膜与外膜交界处有外弹性膜（external elastic membrane），比内弹性膜薄。
- [ ] 外膜含较小的血管、淋巴管和神经纤维，分支可伸入中膜。
- [ ] 内膜一般无血管，营养由血液渗透供给；营养血管（vasa vasorum）为外膜和中膜提供营养。
:::
