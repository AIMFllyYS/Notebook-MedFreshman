# 四、神经节和周围神经的发生

神经节和周围神经都挂在神经嵴这一本账上。本节先把感觉神经节（脑神经节、脊神经节）和胸段迁出的交感链、椎旁／椎前节、肾上腺髓质嗜铬细胞立住，再按周围神经纤维的突起户头和施万细胞是否转出髓鞘摊开。副交感神经节的起源教材写明尚有争议；中枢胶质与成神经细胞见第一节，脊髓前角、侧角见第三节。

## （一）神经节的发生

神经节起源于神经嵴。神经嵴细胞向两侧迁移，分列于神经管背外侧并聚集成细胞团，分化为脑神经节和脊神经节。这些神经节均属感觉神经节。神经嵴细胞首先分化为成神经细胞和卫星细胞，成神经细胞再分化为感觉神经元，卫星细胞包绕在神经元胞体的周围。神经节周围的间充质分化为结缔组织被膜。

:::definition{label="神经节的起源"}
神经节起源于神经嵴。神经嵴细胞向两侧迁移，分列于神经管背外侧并聚集成细胞团。起点是嵴，不是神经管套层。
:::

:::definition{label="脑神经节与脊神经节"}
神经嵴细胞在神经管背外侧聚集成团后，分化为脑神经节和脊神经节。二者均属感觉神经节。
:::

:::definition{label="感觉神经节内的两份细胞"}
神经嵴细胞首先分化为成神经细胞和卫星细胞。成神经细胞再分化为感觉神经元；卫星细胞包绕在神经元胞体的周围。胞体周围是卫星细胞，突起上的鞘是下一小节的施万细胞，不要并成一种。
:::

:::definition{label="神经节被膜"}
神经节周围的间充质分化为结缔组织被膜。被膜不是神经嵴变的。
:::

:::concept{term="先问这是感觉神经节还是交感链，再问细胞已经分成节细胞和卫星细胞没有"}
看见神经节发生，先对地点：紧挨神经管背外侧聚成的团，是脑神经节、脊神经节，属感觉神经节。胸段神经嵴再往腹侧迁，到背主动脉背外侧的两列节段性团才是交感神经节（椎旁神经节），纵行纤维连成交感链；再迁到主动脉腹侧的是椎前神经节。同一批胸段细胞还有一份进肾上腺原基，变成髓质嗜铬细胞和少量交感神经节细胞。再问节内：成神经细胞 → 感觉神经元或交感神经节细胞，卫星细胞围胞体，间充质成被膜。把交感链听成脊神经节，或把嗜铬细胞写成感觉神经元，户头会对错。
:::

位于胸段的神经嵴，有部分细胞迁至背主动脉的背外侧，形成两列节段性排列的神经节，即交感神经节或椎旁神经节。这些神经节借纵行的交感神经纤维彼此相连，形成左、右两条纵行的交感链。节内的部分细胞迁至主动脉腹侧，形成主动脉前的交感神经节或椎前神经节（见图 21-18）。节中的神经嵴细胞分别分化为交感神经节细胞和卫星细胞，节外也有间充质分化为结缔组织被膜。另外，还有部分神经嵴细胞迁入由脏壁中胚层细胞增生形成的肾上腺原基，分化为肾上腺髓质的嗜铬细胞及少量交感神经节细胞。关于副交感神经节的起源尚有争议。

:::definition{label="椎旁神经节（交感神经节）"}
胸段神经嵴有部分细胞迁至背主动脉的背外侧，形成两列节段性排列的神经节，即交感神经节或椎旁神经节。位置在背主动脉背外侧，不是管背外侧那一排感觉神经节。
:::

:::definition{label="交感链"}
椎旁神经节借纵行的交感神经纤维彼此相连，形成左、右两条纵行的交感链。链是节与节之间的纵行纤维连出来的，不是又迁出一排新节。
:::

:::definition{label="椎前神经节"}
交感节内的部分细胞迁至主动脉腹侧，形成主动脉前的交感神经节或椎前神经节。它在主动脉腹侧，比椎旁节更靠腹侧。
:::

:::definition{label="交感神经节内的细胞"}
节中的神经嵴细胞分别分化为交感神经节细胞和卫星细胞，节外也有间充质分化为结缔组织被膜。交感侧同样是“节细胞 + 卫星细胞 + 间充质被膜”，不要写成只有节细胞。
:::

:::definition{label="肾上腺髓质嗜铬细胞（神经嵴去向）"}
部分神经嵴细胞迁入由脏壁中胚层细胞增生形成的肾上腺原基，分化为肾上腺髓质的嗜铬细胞及少量交感神经节细胞。原基的皮质侧来自脏壁中胚层，髓质侧才是神经嵴；第五节再按周次摊开。
:::

:::definition{label="副交感神经节起源有争议"}
关于副交感神经节的起源尚有争议。第一节已写：有人认为来源于神经管，也有人认为来源于脑神经节中的成神经细胞。本节不把副交感写成“一定来自神经嵴”的通则。
:::

:::compare{title="感觉神经节、椎旁节、椎前节与肾上腺髓质"}
| 项目 | 脑神经节、脊神经节 | 椎旁神经节（交感神经节） | 椎前神经节 | 肾上腺髓质 |
|------|--------------------|---------------------------|------------|------------|
| 来源 | 神经嵴向两侧迁至管背外侧聚团 | 胸段神经嵴迁至背主动脉背外侧 | 交感节内部分细胞再迁至主动脉腹侧 | 部分神经嵴细胞迁入肾上腺原基 |
| 属性 | 感觉神经节 | 交感神经节，节段性两列 | 主动脉前的交感神经节 | 嗜铬细胞 + 少量交感神经节细胞 |
| 连接 | 各节独立成脑、脊神经节 | 纵行交感神经纤维连成左、右交感链 | 在主动脉腹侧，比椎旁更靠腹 | 原基本身由脏壁中胚层增生形成 |
| 节内细胞 | 成神经细胞 → 感觉神经元；卫星细胞围胞体 | 交感神经节细胞 + 卫星细胞 | 同交感侧 | 嗜铬细胞为主，另有少量节细胞 |
| 被膜 | 周围间充质 → 结缔组织被膜 | 节外间充质 → 结缔组织被膜 | 同交感侧 | 详见第五节皮质、髓质时间尺 |
:::

:::pitfall{label="管背外侧的团是感觉神经节，背主动脉背外侧的两列才是交感链"}
两处都在“背外侧”，户头不同。紧挨神经管背外侧的是脑、脊神经节，属感觉；再迁到背主动脉背外侧、节段性排列并用纵行纤维连起来的，才是椎旁交感节和交感链。写成“神经嵴在管旁聚的团就是交感链”，椎前节和嗜铬细胞就没有迁徙路径可放。
:::

:::note{label="肾上腺原基先有脏壁中胚层，神经嵴后迁入成髓质"}
迁入的是已经由脏壁中胚层细胞增生形成的肾上腺原基。皮质不是神经嵴变的；髓质的嗜铬细胞和少量交感神经节细胞才是。第五节会写胎儿皮质、永久皮质和髓质完善的周次，不要在这一节把整个肾上腺都写成神经嵴。
:::

:::insight{label="一份胸段神经嵴，分出链、椎前节和嗜铬细胞三本账"}
感觉神经节停在管旁。胸段还要继续走：背主动脉背外侧成椎旁节并连成链，一部分再去主动脉腹侧成椎前节，一部分进肾上腺原基成嗜铬细胞。只背“神经嵴变成周围神经”，这三步迁徙会对成一步。
:::

## （二）周围神经的发生

周围神经由感觉神经纤维和运动神经纤维构成，构成神经纤维的是神经细胞的突起和施万细胞。感觉神经纤维中的突起，是感觉神经节细胞的周围突；躯体运动神经纤维中的突起，是脑干及脊髓灰质前角运动神经元的轴突；内脏运动神经节前纤维中的突起，是脑干内脏运动核和脊髓灰质侧角中神经元的轴突，节后纤维则是自主神经节内节细胞的轴突。神经嵴细胞分化形成的施万细胞，在随神经元轴突或周围突的延长同步增殖和迁移过程中，逐渐形成有髓神经纤维和无髓神经纤维。在有髓神经纤维的形成过程中，施万细胞与轴突相贴处凹陷成一条纵沟，轴突陷入沟内，沟两侧的细胞膜贴合形成轴突系膜。轴突系膜不断增长并旋转包绕轴突，于是在轴突外周形成了由多层施万细胞细胞膜包绕而成的髓鞘。在无髓神经纤维中，一个施万细胞可与多条轴突相贴，并形成多条深沟包裹轴突，但不形成髓鞘。

:::definition{label="周围神经的组成"}
周围神经由感觉神经纤维和运动神经纤维构成。构成神经纤维的是神经细胞的突起和施万细胞。缺突起或缺施万细胞，都不叫一条完整的周围神经纤维。
:::

:::definition{label="感觉神经纤维的突起"}
感觉神经纤维中的突起，是感觉神经节细胞的周围突。它不是前角运动神经元的轴突，也不是节后纤维。
:::

:::definition{label="躯体运动神经纤维的突起"}
躯体运动神经纤维中的突起，是脑干及脊髓灰质前角运动神经元的轴突。胞体在脑干或前角，走的是轴突。
:::

:::definition{label="内脏运动节前纤维"}
内脏运动神经节前纤维中的突起，是脑干内脏运动核和脊髓灰质侧角中神经元的轴突。节前纤维的胞体还在中枢。
:::

:::definition{label="内脏运动节后纤维"}
节后纤维则是自主神经节内节细胞的轴突。胞体已经在周围的自主神经节里。
:::

:::definition{label="施万细胞形成有髓和无髓纤维"}
神经嵴细胞分化形成的施万细胞，在随神经元轴突或周围突的延长同步增殖和迁移过程中，逐渐形成有髓神经纤维和无髓神经纤维。施万细胞跟突起一起走，不是事后才贴上去。
:::

:::definition{label="轴突系膜与髓鞘"}
有髓神经纤维形成时，施万细胞与轴突相贴处凹陷成一条纵沟，轴突陷入沟内，沟两侧的细胞膜贴合形成轴突系膜。轴突系膜不断增长并旋转包绕轴突，于是在轴突外周形成由多层施万细胞细胞膜包绕而成的髓鞘。髓鞘是施万细胞膜转出来的，不是另造一层分泌物。
:::

:::definition{label="无髓神经纤维"}
在无髓神经纤维中，一个施万细胞可与多条轴突相贴，并形成多条深沟包裹轴突，但不形成髓鞘。包着，但没有轴突系膜旋转，所以没有髓鞘。
:::

:::compare{title="四类周围神经纤维的突起户头"}
| 纤维 | 突起是什么 | 胞体在哪 |
|------|------------|----------|
| 感觉神经纤维 | 感觉神经节细胞的周围突 | 脑神经节、脊神经节 |
| 躯体运动神经纤维 | 脑干及脊髓灰质前角运动神经元的轴突 | 脑干、脊髓前角 |
| 内脏运动节前纤维 | 脑干内脏运动核和脊髓灰质侧角中神经元的轴突 | 脑干内脏运动核、脊髓侧角 |
| 内脏运动节后纤维 | 自主神经节内节细胞的轴突 | 自主神经节 |
:::

:::compare{title="有髓神经纤维与无髓神经纤维"}
| 项目 | 有髓神经纤维 | 无髓神经纤维 |
|------|--------------|--------------|
| 施万细胞来源 | 神经嵴 | 神经嵴 |
| 与突起的关系 | 随轴突或周围突延长同步增殖、迁移 | 同左 |
| 一个施万细胞包几条 | 一条轴突陷入一条纵沟 | 可与多条轴突相贴，形成多条深沟 |
| 轴突系膜 | 沟两侧细胞膜贴合形成，并增长、旋转包绕 | 不形成轴突系膜旋转 |
| 髓鞘 | 多层施万细胞膜包绕而成 | 不形成髓鞘 |
:::

:::derivation{title="轴突系膜转够圈，才叫有髓"}
施万细胞先贴上轴突，相贴处凹成纵沟，轴突掉进沟里。沟两侧膜贴合，这条贴合的膜就是轴突系膜。系膜一边长一边绕轴突转，转出来的多层施万细胞膜才是髓鞘。转这一步不做，哪怕施万细胞把轴突裹在深沟里，仍是无髓纤维。
:::

:::cause-effect{title="施万细胞跟突起走，转不转系膜决定有髓还是无髓"}
- 因：神经嵴分化出施万细胞，随轴突或周围突同步增殖、迁移
- 果：周围神经纤维具备“突起 + 施万细胞”两份结构
- 因：一条轴突陷入一条纵沟，沟侧膜贴合成轴突系膜并旋转
- 果：多层施万细胞膜成为髓鞘（有髓）
- 因：一个施万细胞用多条深沟包多条轴突，但不旋转成系膜
- 果：无髓神经纤维
:::

:::pitfall{label="感觉纤维走的是周围突，运动纤维走的是轴突，不要写成都是轴突"}
感觉神经节细胞是假单极（第一节），周围突组成感觉神经纤维，中枢突进脊髓。躯体运动和内脏运动（节前、节后）才是轴突。写成“周围神经都是轴突加施万细胞”，感觉周围突这本账会消失。
:::

:::pitfall{label="一个施万细胞包多条轴突，不等于已经形成髓鞘"}
无髓纤维里施万细胞确实在包轴突，而且一条细胞可以包多条，但教材写明不形成髓鞘。把“被施万细胞包裹”听成“有髓”，轴突系膜旋转这一步就没有地方可放。
:::

:::example{label="节前、节后不要对错胞体"}
问内脏运动，先问这根纤维有没有出自主神经节。还在脑干内脏运动核或脊髓侧角的，是节前，突起是这些核团神经元的轴突。已经换成自主神经节内节细胞发出的，是节后。交感链、椎前节里的节细胞，就是节后纤维的胞体所在。
:::

:::keypoint{label="嵴成节，胸段再迁出链和嗜铬细胞；纤维看突起户头，髓鞘看系膜转没转"}
- 神经节起源于神经嵴；管背外侧聚团 → 脑、脊神经节（感觉）；成神经细胞 → 感觉神经元，卫星细胞围胞体，间充质成被膜。
- 胸段神经嵴 → 背主动脉背外侧两列椎旁交感节，纵行纤维连成左、右交感链；节内部分细胞 → 主动脉腹侧椎前节。
- 部分神经嵴迁入脏壁中胚层来的肾上腺原基 → 髓质嗜铬细胞及少量交感神经节细胞。
- 副交感神经节起源尚有争议。
- 周围神经 = 感觉纤维 + 运动纤维；每条纤维 = 突起 + 施万细胞。
- 感觉走周围突；躯体运动走脑干／前角轴突；内脏节前走脑干内脏运动核／侧角轴突；节后走自主神经节节细胞轴突。
- 有髓：一条纵沟 → 轴突系膜旋转 → 多层施万细胞膜成髓鞘。无髓：一条施万细胞包多条轴突，不形成髓鞘。
:::

:::memory{label="本节必背要点"}
- [ ] 神经节起源于神经嵴。
- [ ] 神经嵴细胞向两侧迁移，分列于神经管背外侧并聚集成细胞团，分化为脑神经节和脊神经节。
- [ ] 脑神经节和脊神经节均属感觉神经节。
- [ ] 神经嵴细胞首先分化为成神经细胞和卫星细胞。
- [ ] 成神经细胞再分化为感觉神经元，卫星细胞包绕在神经元胞体的周围。
- [ ] 神经节周围的间充质分化为结缔组织被膜。
- [ ] 胸段神经嵴有部分细胞迁至背主动脉的背外侧，形成两列节段性排列的神经节，即交感神经节或椎旁神经节。
- [ ] 这些神经节借纵行的交感神经纤维彼此相连，形成左、右两条纵行的交感链。
- [ ] 节内的部分细胞迁至主动脉腹侧，形成主动脉前的交感神经节或椎前神经节（见图 21-18）。
- [ ] 节中的神经嵴细胞分别分化为交感神经节细胞和卫星细胞，节外间充质分化为结缔组织被膜。
- [ ] 部分神经嵴细胞迁入由脏壁中胚层细胞增生形成的肾上腺原基，分化为肾上腺髓质的嗜铬细胞及少量交感神经节细胞。
- [ ] 关于副交感神经节的起源尚有争议。
- [ ] 周围神经由感觉神经纤维和运动神经纤维构成。
- [ ] 构成神经纤维的是神经细胞的突起和施万细胞。
- [ ] 感觉神经纤维中的突起是感觉神经节细胞的周围突。
- [ ] 躯体运动神经纤维中的突起是脑干及脊髓灰质前角运动神经元的轴突。
- [ ] 内脏运动神经节前纤维中的突起是脑干内脏运动核和脊髓灰质侧角中神经元的轴突。
- [ ] 节后纤维是自主神经节内节细胞的轴突。
- [ ] 神经嵴细胞分化形成施万细胞，随神经元轴突或周围突的延长同步增殖和迁移，逐渐形成有髓神经纤维和无髓神经纤维。
- [ ] 有髓纤维：施万细胞与轴突相贴处凹陷成一条纵沟，轴突陷入沟内，沟两侧细胞膜贴合形成轴突系膜。
- [ ] 轴突系膜不断增长并旋转包绕轴突，轴突外周形成由多层施万细胞细胞膜包绕而成的髓鞘。
- [ ] 无髓纤维：一个施万细胞可与多条轴突相贴，并形成多条深沟包裹轴突，但不形成髓鞘。
