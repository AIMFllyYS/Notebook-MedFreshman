# 四、影响骨生长发育的因素

影响骨生长发育的因素很多，除遗传因素外，营养与维生素、激素、细胞因子、应力作用等皆有各自的影响。这些因素最终都落在成骨细胞与破骨细胞的配对账上：谁被激活、谁被抑制，骺板能不能增生，类骨质能不能矿化，重建能不能跟上生长。

:::definition{label="影响骨生长发育的因素"}
除遗传因素外，营养与维生素、激素、细胞因子、应力作用等皆影响骨的生长发育。它们通过调控成骨与破骨、骺板软骨细胞以及类骨质矿化，改变骨的生长速度、塑形和重建。
:::

:::concept{term="先问调的是成骨、破骨，还是骺板软骨"}
维生素 D 主要把钙磷送进类骨质；维生素 A 协调成骨与破骨的节奏；维生素 C 管胶原和骨祖细胞分裂。生长激素和甲状腺激素推骺板；甲状旁腺素和降钙素对拉血钙；雌激素不足则成骨弱、破骨相对强。应力在生理高位写成骨、低位写吸收。看见一种因素，先问它动的是哪一本细胞账。
:::

## 1. 营养与维生素

营养是骨骼发育的必要条件，多种维生素对骨的生长发育至关重要。维生素 D 能促进小肠对钙、磷的吸收，提高血钙和血磷水平，有利于类骨质的矿化，儿童期若缺乏维生素 D 或饮食中缺钙，可导致佝偻病，成人缺乏则引起骨软化症。维生素 A 能协调成骨细胞和破骨细胞的活动，影响骨的生长速度和骨的塑形，在骨的重建中发挥重要作用。若维生素 A 严重缺乏，骨的重吸收和重建跟不上骨的形成，引起骨的畸形发育，也可影响骺板软骨细胞的发育，导致长骨生长迟缓。维生素 C 可影响骨祖细胞的分裂增殖，并可影响成骨细胞合成胶原纤维与基质，严重缺乏可导致骨干密质骨变薄变脆，骨折后愈合缓慢。

:::definition{label="维生素D与骨"}
维生素 D 促进小肠对钙、磷的吸收，提高血钙和血磷水平，有利于类骨质的矿化。儿童期缺乏维生素 D 或饮食缺钙可导致佝偻病；成人缺乏则引起骨软化症。
:::

:::definition{label="维生素A与骨"}
维生素 A 协调成骨细胞和破骨细胞的活动，影响骨的生长速度和塑形，在重建中发挥重要作用。严重缺乏时，骨的重吸收和重建跟不上骨的形成，引起畸形发育；也可影响骺板软骨细胞发育，导致长骨生长迟缓。
:::

:::definition{label="维生素C与骨"}
维生素 C 影响骨祖细胞的分裂增殖，并影响成骨细胞合成胶原纤维与基质。严重缺乏可导致骨干密质骨变薄变脆，骨折后愈合缓慢。
:::

:::example{label="佝偻病与骨软化症"}
儿童期缺乏维生素 D 或饮食缺钙，类骨质矿化不足，写成佝偻病；成人缺乏则引起骨软化症。两者都是矿化账出了问题，不是胶原纤维没做出来。维生素 C 严重缺乏时密质骨变薄变脆、骨折愈合慢，那才是有机质（胶原）账。
:::

:::pitfall{label="佝偻病是矿化不够，不是没做成骨细胞"}
维生素 D 的关键步骤是提高血钙、血磷，让类骨质能够矿化。成骨细胞仍可分泌类骨质，只是羟基磷灰石沉不上去。不要和维生素 C 缺乏（胶原与基质合成障碍、密质骨变薄变脆）或维生素 A 缺乏（重建跟不上形成、骺板发育差）混成“缺维生素骨头就软”。
:::

:::compare{title="维生素D、A、C对骨的作用"}
| 项目 | 维生素 D | 维生素 A | 维生素 C |
|------|----------|----------|----------|
| 主要环节 | 小肠吸收钙、磷 → 提高血钙血磷 → 类骨质矿化 | 协调成骨细胞与破骨细胞，影响生长速度、塑形和重建 | 骨祖细胞分裂增殖；成骨细胞合成胶原纤维与基质 |
| 缺乏（儿童/发育） | 佝偻病（可因缺钙同样发生） | 重吸收和重建跟不上形成 → 畸形发育；骺板软骨细胞发育受影响 → 长骨生长迟缓 | 骨干密质骨变薄变脆，骨折愈合缓慢 |
| 缺乏（成人） | 骨软化症 | — | 密质骨薄脆、修复差 |
| 易混点 | 矿化不足，类骨质可以有 | 节奏失衡，不是单纯“缺钙” | 有机质不足，不是羟基磷灰石缺乏 |
:::

:::cause-effect{title="三种维生素缺乏怎样写成不同的骨病"}
- 因：维生素 D 不足或饮食缺钙 → 血钙血磷低 → 类骨质不能充分矿化 → 儿童佝偻病 / 成人骨软化症
- 因：维生素 A 严重缺乏 → 破骨与重建跟不上成骨，骺板软骨也受累 → 畸形发育、长骨生长迟缓
- 因：维生素 C 严重缺乏 → 骨祖细胞增殖差、胶原与基质合成差 → 密质骨薄脆、骨折愈合慢
:::

## 2. 激素

生长激素和甲状腺激素可促进骺板软骨细胞的生长，促进软骨替换为骨。若生长发育期这两种激素分泌过少，可分别导致侏儒症和呆小病；儿童期生长激素分泌过多，可导致巨人症，成年期则可致肢端肥大症。甲状旁腺激素激活骨细胞和破骨细胞的溶骨作用，释放骨钙入血，使血钙升高；降钙素可抑制骨盐溶解，并刺激骨祖细胞分化为成骨细胞，促进成骨而使血钙入骨。雌激素和雄激素都能促进成骨细胞的活动，有利于骨的生长和成熟。雌激素不足可致成骨细胞活跃度降低、破骨细胞活动相对增强，故可导致骨钙流失，形成骨质疏松。糖皮质激素可抑制小肠对钙的吸收和肾小管对钙的重吸收，对骨生长发育也有影响。

:::definition{label="生长激素、甲状腺激素与骺板"}
生长激素和甲状腺激素促进骺板软骨细胞的生长，并促进软骨替换为骨。生长发育期分泌过少，分别导致侏儒症和呆小病；儿童期生长激素过多导致巨人症，成年期导致肢端肥大症。
:::

:::definition{label="甲状旁腺激素与降钙素"}
甲状旁腺激素激活骨细胞和破骨细胞的溶骨作用，释放骨钙入血，使血钙升高。降钙素抑制骨盐溶解，并刺激骨祖细胞分化为成骨细胞，促进成骨而使血钙入骨。
:::

:::example{label="侏儒症、呆小病、巨人症与肢端肥大症"}
生长发育期生长激素过少 → 侏儒症；甲状腺激素过少 → 呆小病。二者都卡在骺板软骨细胞生长和软骨替换为骨。儿童期生长激素过多，骺板尚未闭合，写成巨人症；成年期骺线已形成，过多的生长激素不能再让长骨加长，而写成肢端肥大症。
:::

:::pitfall{label="成年后再多的生长激素也不能让长骨长长"}
骺线形成后纵向生长停止。儿童期生长激素过多走巨人症，成年期过多走肢端肥大症，差别就是骺板还在不在。不要把两种病写成同一机制的不同程度。
:::

:::compare{title="调节骨的主要激素"}
| 激素 | 对骨/钙的作用 | 过少 | 过多 |
|------|----------------|------|------|
| 生长激素 | 促进骺板软骨细胞生长，促进软骨替换为骨 | 生长发育期：侏儒症 | 儿童期：巨人症；成年期：肢端肥大症 |
| 甲状腺激素 | 同上，促进骺板生长与替换 | 生长发育期：呆小病 | — |
| 甲状旁腺激素 | 激活骨细胞和破骨细胞溶骨，骨钙入血，血钙升高 | 血钙降低（教材未展开病名） | 溶骨增强，血钙升高 |
| 降钙素 | 抑制骨盐溶解；刺激骨祖细胞分化为成骨细胞，血钙入骨 | — | 成骨增强方向 |
| 雌激素、雄激素 | 促进成骨细胞活动，利于生长和成熟 | 雌激素不足：成骨弱、破骨相对强 → 骨钙流失 → 骨质疏松 | — |
| 糖皮质激素 | 抑制小肠吸钙和肾小管重吸收钙 | — | 对骨生长发育有不利影响 |
:::

:::cause-effect{title="雌激素不足如何走向骨质疏松"}
- 因：雌激素促进成骨细胞活动
- 因：雌激素不足 → 成骨细胞活跃度降低，破骨细胞活动相对增强
- 果：骨钙流失，骨量下降，形成骨质疏松
- 呼应：老年女性丢失更多；插入框指出正常每年约丢失骨矿物质总量的 $0.5\%$
:::

## 3. 细胞因子

细胞因子是由细胞分泌的一类低分子量可溶性蛋白或多肽，具有广泛的生物学活性。骨内存在的生物活性物质，如生长因子和细胞因子等，一般认为来自成骨细胞的分泌，但也可来自骨外组织。这些细胞因子可激活或抑制成骨细胞与破骨细胞，与骨的发生、生长和重建密切相关。

:::definition{label="细胞因子（骨）"}
细胞因子是细胞分泌的低分子量可溶性蛋白或多肽，具有广泛生物学活性。骨内的生长因子和细胞因子一般认为来自成骨细胞，也可来自骨外组织；可激活或抑制成骨细胞与破骨细胞，与骨的发生、生长和重建密切相关。
:::

:::note{label="成骨细胞不只造类骨质"}
上一节已写：成骨细胞除产生类骨质外，还分泌多种细胞因子，调节骨组织的形成和吸收、促进钙化。本节把这张分泌账接到全身：骨外组织来的因子同样可以激活或抑制成骨与破骨。具体因子名称教材未列，记账到“成骨–破骨被可溶性信号配对调控”即可。
:::

## 4. 应力作用

应力是结构对外部加载的负荷所产生的内部抵抗力，使物体因负荷造成的变形得以恢复到变形前的状态。骨的生长和重建皆与骨的受力状态密切相关。实验表明，骨处于生理范围内的高应力作用下，以骨形成为主；低应力条件下以骨吸收为主，长期的低应力可造成骨质疏松，如长期卧床可造成骨钙流失。应力通过影响骨形成和骨吸收，对骨的塑形和内部重建起到重要的导向作用。

:::definition{label="应力"}
应力是结构对外部加载的负荷所产生的内部抵抗力，使物体因负荷造成的变形得以恢复到变形前的状态。
:::

:::definition{label="应力对骨的导向"}
骨处于生理范围内的高应力作用下以骨形成为主；低应力条件下以骨吸收为主。长期低应力可造成骨质疏松，如长期卧床造成骨钙流失。应力通过影响骨形成和骨吸收，对塑形和内部重建起导向作用。
:::

:::example{label="长期卧床与废用性骨钙流失"}
长期卧床使骨处于低应力，吸收大于形成，骨钙流失，可造成骨质疏松。这与雌激素不足导致的骨质疏松终点相似，起点却是力学信号而不是激素信号。第三节骨单位“顺应应力需要”的分支吻合，就是这套导向写在密质骨内部的结果。
:::

:::theorem{label="生理高应力写成骨，长期低应力写吸收"}
在生理范围内，高应力以骨形成为主，低应力以骨吸收为主。塑形和内部重建都把应力当作导向，而不是把骨质写成与负荷无关的静态钙库。
:::

:::insight{label="骨的组织结构与骨质疏松症"}
为了支撑人体的运动，要求骨的组织结构同时具备强度及轻盈度。在承受负荷时，需骨组织具备刚度，抵抗承重带来的变形；在运动时，则需骨组织具备轻盈度和柔顺性，通过变形吸收冲击的能量，或发生骨折时可以释放能量。这些性能取决于骨组织无机物（矿盐）与有机基质的组成，还与骨组织终身不断重建过程中形成的骨微细结构密切相关。

在机体生长发育期间，旧骨不断被吸收，新骨不断形成，称为骨重建。骨重建始于软骨边缘，先由破骨细胞吸收骨质成腔，数月后新骨形成沉积于骨腔，如成骨作用占优势，则骨骼变粗。成人骨骼虽无明显增大或缩小，但也有 $3\%\sim 5\%$ 骨组织处于不断重建中，维持骨组织结构，移除及代替已接近生命终期的骨质，使骨处于更适合生理情况的微环境，故骨是代谢非常活跃的组织。

在骨代谢中，如骨吸收和骨形成失去动态平衡，便可出现各种代谢性骨病。骨吸收和骨形成的速率称为骨转换率。骨转换率异常可影响骨组织性能，特别是骨组织的矿盐含量。成年以后，随着年龄增加，骨转换率逐年下降，故骨密度逐年下降。正常情况下，每年骨矿物质约丢失总量的 $0.5\%$，老年女性由于雌激素缺乏，丢失更多。当骨矿物质丢失到一定程度时，骨微细结构发生变化，无法维持正常形态，骨小梁会变窄、变细、弯曲、错位甚至断裂，有的被全部吸收形成空洞，因而骨小梁数目减少，骨强度降低，脆性增加，直至发生自发性压缩性骨折或横断性骨折，此为骨质疏松症。因此，当骨质疏松发生时，其骨组织组成并没有改变，但骨量明显减少，导致骨组织外部形态、结构及功能发生变化。
:::

:::definition{label="骨转换率"}
骨转换率是骨吸收和骨形成的速率。转换率异常可影响骨组织性能，特别是矿盐含量。成年以后随年龄增加逐年下降，骨密度随之下降。
:::

:::definition{label="骨质疏松症"}
骨质疏松症是骨矿物质丢失到一定程度后，骨微细结构不能维持正常形态：骨小梁变窄、变细、弯曲、错位甚至断裂，有的被全部吸收形成空洞，骨小梁数目减少，强度降低，脆性增加，直至自发性压缩性骨折或横断性骨折。骨组织组成并未改变，但骨量明显减少，外部形态、结构及功能发生变化。
:::

:::pitfall{label="骨质疏松是骨量少，不是骨质换成了另一种成分"}
教材写明：骨质疏松发生时，骨组织组成并没有改变，但骨量明显减少。不要把它写成“钙没了只剩胶原”，或写成编织骨取代板层骨。小梁变细、断裂、空洞，是同一套板层骨在量上撑不住载荷。
:::

:::compare{title="佝偻病/骨软化症与骨质疏松症"}
| 项目 | 佝偻病（儿童）/骨软化症（成人） | 骨质疏松症 |
|------|-------------------------------|------------|
| 关键缺陷 | 类骨质矿化不足（维生素 D 或钙缺乏） | 骨形成与骨吸收失衡，骨量减少 |
| 组成 | 有机质相对多，矿盐沉着不够 | 组成不变，矿盐与有机质按比例都少 |
| 结构 | 骨质软化 | 骨小梁变窄变细、弯曲错位甚至断裂、空洞 |
| 临床 | 儿童畸形、成人骨软 | 脆性增加，自发性压缩性或横断性骨折 |
| 相关因素 | 维生素 D、饮食钙 | 增龄、雌激素缺乏、长期低应力等 |
:::

:::keypoint{label="因素最终都落到成骨、破骨、骺板和矿化"}
- 维生素 D：吸钙磷、矿化；缺则佝偻病/骨软化症。维生素 A：协调成骨与破骨及骺板；缺则畸形、长骨迟缓。维生素 C：骨祖细胞和胶原；缺则密质骨薄脆、愈合慢。
- 生长激素/甲状腺激素推骺板；甲状旁腺素溶骨升血钙，降钙素促成骨使钙入骨；雌激素不足 → 骨质疏松。
- 细胞因子（多来自成骨细胞，也可来自骨外）激活或抑制成骨与破骨。
- 生理高应力 → 骨形成；长期低应力（如卧床）→ 骨吸收、骨钙流失。
- 成人 $3\%\sim 5\%$ 骨组织持续重建；年丢失约 $0.5\%$ 骨矿；骨质疏松是骨量少而非组成改变。
:::

:::memory{label="本节必背要点"}
- [ ] 除遗传外，营养与维生素、激素、细胞因子、应力皆影响骨生长发育。
- [ ] 维生素 D：促进小肠吸收钙磷，提高血钙血磷，利于类骨质矿化。
- [ ] 儿童缺维生素 D 或饮食缺钙 → 佝偻病；成人缺乏 → 骨软化症。
- [ ] 维生素 A：协调成骨与破骨，影响生长速度、塑形和重建；严重缺乏 → 重建跟不上形成而畸形，并影响骺板 → 长骨生长迟缓。
- [ ] 维生素 C：影响骨祖细胞分裂及成骨细胞合成胶原与基质；严重缺乏 → 密质骨变薄变脆，骨折愈合缓慢。
- [ ] 生长激素和甲状腺激素促进骺板软骨细胞生长及软骨替换为骨。
- [ ] 生长发育期生长激素过少 → 侏儒症；甲状腺激素过少 → 呆小病。
- [ ] 儿童期生长激素过多 → 巨人症；成年期过多 → 肢端肥大症。
- [ ] 甲状旁腺激素：激活骨细胞和破骨细胞溶骨，骨钙入血，血钙升高。
- [ ] 降钙素：抑制骨盐溶解，刺激骨祖细胞分化为成骨细胞，血钙入骨。
- [ ] 雌激素和雄激素促进成骨细胞活动，利于生长和成熟。
- [ ] 雌激素不足：成骨弱、破骨相对强 → 骨钙流失 → 骨质疏松。
- [ ] 糖皮质激素抑制小肠吸钙和肾小管重吸收钙，影响骨生长发育。
- [ ] 细胞因子为低分子量可溶性蛋白/多肽；骨内者多来自成骨细胞，也可来自骨外；激活或抑制成骨与破骨。
- [ ] 应力：结构对外部负荷的内部抵抗力，使变形得以恢复。
- [ ] 生理范围内高应力以骨形成为主，低应力以骨吸收为主；长期低应力（如卧床）→ 骨质疏松、骨钙流失。
- [ ] 骨需同时具备强度与轻盈：刚度抗变形，柔顺性吸收冲击；取决于矿盐与有机基质组成及终身重建形成的微细结构。
- [ ] 重建始于软骨边缘：破骨吸收成腔，数月后新骨沉积；成骨占优势则骨骼变粗。
- [ ] 成人 $3\%\sim 5\%$ 骨组织持续重建；骨是代谢非常活跃的组织。
- [ ] 骨转换率 = 骨吸收和骨形成的速率；成年后逐年下降，骨密度下降。
- [ ] 正常每年约丢失骨矿物质总量的 $0.5\%$，老年女性因雌激素缺乏丢失更多。
- [ ] 骨质疏松症：骨量明显减少而组成不变；骨小梁变窄、变细、弯曲、错位、断裂或成空洞；强度降、脆性增，可自发压缩性或横断性骨折。
