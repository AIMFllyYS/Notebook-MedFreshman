# 三、血小板

血小板（blood platelet）是骨髓巨核细胞脱落下来的细胞质小块，并非严格意义上的细胞。血小板呈双凸圆盘状，直径 $2\sim 4\,\mu\mathrm{m}$，当受到机械或化学刺激时（如黏附于载玻片），则伸出突起，此时呈不规则形。在血涂片上，血小板常聚集成群。正常成人血小板计数为 $(100\sim 300)\times 10^{9}/\mathrm{L}$。血小板寿命为 $7\sim 14$ 天。

:::definition{label="血小板"}
血小板（blood platelet）是骨髓巨核细胞脱落下来的细胞质小块，并非严格意义上的细胞。呈双凸圆盘状，直径 $2\sim 4\,\mu\mathrm{m}$；受机械或化学刺激时伸出突起，变为不规则形。血涂片上常聚集成群。正常值 $(100\sim 300)\times 10^{9}/\mathrm{L}$，寿命 $7\sim 14$ 天。
:::

:::concept{term="先问是细胞，还是巨核细胞掉下来的细胞质小块"}
血涂片上那一簇蓝紫小点没有核，不是“最小的血细胞”，而是巨核细胞细胞质按小区割下来的碎片。它有膜、有颗粒、有管道系统，能黏附、聚集、释放，但没有完整细胞的核质结构。把血小板听成第三种白细胞，或听成“无核的小红细胞”，都会把止血账做成细胞分类账。
:::

:::pitfall{label="血小板是细胞质碎片，不是细胞"}
教材写明：血小板并非严格意义上的细胞。它没有细胞核，来源是巨核细胞伸出胞质突起、末端脱落。血涂片成群出现是它的习性，不是“细胞在分裂”。计数、寿命和止血功能都按细胞质小块来记，不要补一个“血小板核”。
:::

在血涂片上，血小板中央部有蓝紫色的血小板颗粒，称颗粒区（granulomere）；周边部呈均质浅蓝色，称透明区（hyalomere）。电镜下，血小板表面吸附有血浆蛋白，其中有多种凝血因子。透明区含有微管和微丝，参与血小板形状的维持和变形。颗粒区有特殊颗粒、致密颗粒和少量溶酶体。

:::definition{label="颗粒区"}
颗粒区（granulomere）是血小板中央部，血涂片上呈蓝紫色，含血小板颗粒。电镜下有特殊颗粒（α 颗粒）、致密颗粒和少量溶酶体。
:::

:::definition{label="透明区"}
透明区（hyalomere）是血小板周边部，血涂片上呈均质浅蓝色。含微管和微丝，参与血小板形状的维持和变形。
:::

特殊颗粒又称 α 颗粒，体积较大，呈圆形，电子密度中等，内含血小板因子Ⅳ、血小板源性生长因子（platelet-derived growth factor，PDGF）、血小板应答蛋白（thrombospondin）等。致密颗粒体积较小，电子密度大，内含 5-羟色胺、ADP、ATP、钙离子、肾上腺素等。

:::definition{label="α 颗粒"}
α 颗粒即血小板的特殊颗粒，体积较大，圆形，电子密度中等，内含血小板因子Ⅳ、PDGF、血小板应答蛋白（thrombospondin）等。
:::

:::definition{label="致密颗粒"}
致密颗粒体积较小，电子密度大，内含 5-羟色胺、ADP、ATP、钙离子、肾上腺素等。
:::

血小板内还有开放小管系统和致密小管系统。开放小管系统的管道与血小板表面胞膜连续，借此可增加血小板与血浆的接触面积，利于摄取血浆物质和释放颗粒内容物。致密小管系统是封闭的小管，管腔电子密度中等，能收集钙离子和合成前列腺素等（图 5-6）。

:::definition{label="开放小管系统"}
开放小管系统的管道与血小板表面胞膜连续，增加血小板与血浆的接触面积，利于摄取血浆物质和释放颗粒内容物。
:::

:::definition{label="致密小管系统"}
致密小管系统是封闭的小管，管腔电子密度中等，能收集钙离子和合成前列腺素等。
:::

:::compare{title="开放小管系统与致密小管系统"}
| 项目 | 开放小管系统 | 致密小管系统 |
|------|--------------|--------------|
| 是否与表面相通 | 管道与表面胞膜连续，向外出入口开放 | 封闭的小管，不与外界直接相通 |
| 管腔 | 与血浆相通，借此扩大接触面积 | 管腔电子密度中等 |
| 主要职分 | 摄取血浆物质；释放颗粒内容物 | 收集钙离子；合成前列腺素等 |
| 功能位置 | 把“里面的颗粒内容物”送到血浆，把血浆成分收回来 | 在封闭管道里调控钙和前列腺素 |
| 易混点 | 不是内质网，是胞膜内陷形成的开放管道 | 不是致密颗粒；致密颗粒是高电子密度的贮存颗粒 |
:::

:::compare{title="α 颗粒与致密颗粒"}
| 项目 | α 颗粒（特殊颗粒） | 致密颗粒 |
|------|---------------------|----------|
| 体积与密度 | 较大，圆形，电子密度中等 | 较小，电子密度大 |
| 内容物 | 血小板因子Ⅳ、PDGF、血小板应答蛋白 | 5-羟色胺、ADP、ATP、钙离子、肾上腺素 |
| 止血中的作用 | 因子Ⅳ对抗肝素；应答蛋白促进聚集；PDGF 刺激内皮增殖和血管修复 | 5-羟色胺促进血管收缩；ADP 等促进聚集 |
| 所在部位 | 颗粒区 | 颗粒区 |
:::

血小板参与凝血和止血。当血管内皮破裂时，血小板迅速黏附、聚集于破损处，凝固形成血栓，堵塞裂口甚至小血管管腔。在这一过程中，血小板释放颗粒内容物，其中 5-羟色胺能促进血管收缩，血小板因子Ⅳ能对抗肝素的抗凝血作用，血小板应答蛋白促进血小板聚集，PDGF 刺激内皮细胞增殖和血管修复。

:::cause-effect{title="内皮破裂后血小板怎样把裂口堵住"}
- 因：内皮破裂，血小板迅速黏附、聚集于破损处
- 因：开放小管把颗粒内容物释放到血浆
- 果：5-羟色胺促进血管收缩；血小板因子Ⅳ对抗肝素；血小板应答蛋白促进聚集 → 凝固成血栓，堵塞裂口甚至小血管管腔
- 果：PDGF 刺激内皮细胞增殖和血管修复
- 制约：血小板寿命仅 $7\sim 14$ 天，需骨髓巨核细胞持续补给
:::

:::insight{label="止血是膜、颗粒和两条管道一起做的"}
透明区的微管、微丝让双凸盘能变形、能伸出突起；颗粒区把收缩血管、对抗肝素、促进聚集和修复内皮的分子分装在 α 颗粒和致密颗粒里；开放小管把这些分子吐到血浆，致密小管在内部管钙和前列腺素。表面还吸附着多种凝血因子。缺任何一本账，血栓都写不完整。
:::

:::keypoint{label="血小板按碎片、两区和两套管道来记"}
- 血小板是巨核细胞脱落的细胞质小块，不是细胞；双凸圆盘，直径 $2\sim 4\,\mu\mathrm{m}$，涂片常成群。
- 中央颗粒区（α 颗粒、致密颗粒、少量溶酶体），周边透明区（微管、微丝）。
- 开放小管与膜连续，司摄取和释放；致密小管封闭，司集钙和合成前列腺素。
- 黏附、聚集形成血栓；5-羟色胺、血小板因子Ⅳ、应答蛋白和 PDGF 分别管收缩、抗肝素、聚集和修复。寿命 $7\sim 14$ 天。
:::
