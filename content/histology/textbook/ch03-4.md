# 四、网状组织

网状组织（reticular tissue）主要分布于骨髓、脾、淋巴结等，由网状细胞和网状纤维构成。它在体内不单独存在，而是构成造血组织和淋巴组织的支架：网孔内细胞和液体可自由流动，这就为血细胞发生和淋巴细胞发育提供了适宜的微环境。纤维是疏松结缔组织一节写过的网状纤维（Ⅲ型胶原，镀银呈黑色），细胞则是专门产生并依附于这张网的网状细胞。

:::definition{label="网状组织"}
网状组织（reticular tissue）由网状细胞和网状纤维构成，主要分布于骨髓、脾、淋巴结等。体内不单独存在，而是构成造血组织和淋巴组织的支架；网孔内细胞和液体可自由流动，为血细胞发生和淋巴细胞发育提供微环境。
:::

:::concept{term="网状组织先问：这张网是不是造血／淋巴组织的支架"}
疏松结缔组织的三种纤维里已经有网状纤维，但网状组织不是“只有网状纤维的疏松结缔组织”。它的细胞是星形的网状细胞，纤维由网状细胞产生，并可深陷于胞体和突起内，成为细胞依附的支架。看见镀银切片上的黑网，先问所在器官是不是骨髓、脾或淋巴结，再问网孔里流动的是不是血细胞或淋巴细胞。把网状组织当成独立器官，或把它和弹性组织、不规则致密结缔组织的“网状排列”混为一谈，都会把支架账做丢。
:::

:::pitfall{label="网状组织不单独成器官，HE 也看不清那张黑网"}
网状组织在体内不单独存在，只作为造血组织和淋巴组织的支架出现。网状纤维 HE 呈淡红色，必须镀银才显黑色（嗜银纤维）。不要在普通 HE 切片上找“黑网”来确认网状组织，也不要把淋巴结里的网状细胞当成巨噬细胞——后者是游走的吞噬细胞，前者是产生并依附网状纤维的固定细胞。
:::

## 网状细胞与网状纤维

网状细胞（reticular cell）是有突起的星形细胞，相邻细胞的突起连接成网。细胞核较大，圆形或卵圆形，着色浅，常见 $1\sim 2$ 个核仁。细胞质较多，粗面内质网较丰富。网状纤维由网状细胞产生。网状纤维交织成网，并可深陷于网状细胞的胞体和突起内，成为网状细胞依附的支架（图 3-19）。镀银染色下，黑色的网状纤维勾出网孔，孔内可见淋巴细胞等游离细胞。

:::definition{label="网状细胞"}
网状细胞（reticular cell）是有突起的星形细胞，相邻细胞的突起连接成网。核较大，圆形或卵圆形，着色浅，常见 $1\sim 2$ 个核仁；胞质较多，粗面内质网较丰富。它产生网状纤维，并借纤维构成自身依附的支架。
:::

:::definition{label="网状纤维（网状组织中）"}
网状纤维由网状细胞产生，交织成网，并可深陷于网状细胞的胞体和突起内。它主要由Ⅲ型胶原蛋白构成，表面被覆糖蛋白；镀银染色呈黑色。网孔允许细胞和液体自由流动。
:::

:::compare{title="网状组织与疏松结缔组织"}
| 项目 | 网状组织 | 疏松结缔组织 |
|------|----------|--------------|
| 主要细胞 | 网状细胞（星形，突起连网） | 成纤维细胞为主，另有多种固有和游走细胞 |
| 主要纤维 | 网状纤维（Ⅲ型胶原，嗜银） | 胶原纤维为主，兼有弹性和网状纤维 |
| 基质与空隙 | 网孔内细胞和液体可自由流动 | 基质中分子筛 + 组织液，纤维排列稀疏 |
| 是否单独存在 | 不单独存在，构成造血组织和淋巴组织的支架 | 广泛单独分布于器官之间、组织之间 |
| 典型部位 | 骨髓、脾、淋巴结 | 器官之间和组织之间的填充、连接处 |
| 主要功能 | 提供血细胞发生和淋巴细胞发育的微环境 | 连接、支持、防御、修复 |
:::

:::note{label="固有结缔组织四型对照"}
| 类型 | 结构要点 | 主要分布 | 主要功能 |
|------|----------|----------|----------|
| 疏松结缔组织 | 细胞种类多，纤维少而稀疏 | 器官之间、组织之间 | 连接、支持、防御、修复 |
| 致密结缔组织 | 纤维粗密，细胞少 | 肌腱、腱膜、韧带、真皮、硬脑膜、器官被膜、黄韧带等 | 支持、连接、保护 |
| 脂肪组织 | 大量脂肪细胞，疏松结缔组织分隔成小叶 | 皮下、网膜、系膜；新生儿肩胛间等（棕色） | 贮能、保温、缓冲、保护、填充；或产热 |
| 网状组织 | 网状细胞 + 网状纤维 | 骨髓、脾、淋巴结 | 造血组织和淋巴组织的支架与微环境 |
:::

:::keypoint{label="网状组织是造血和淋巴组织的支架"}
- 网状组织由网状细胞和网状纤维构成，主要在骨髓、脾、淋巴结。
- 网状细胞星形、突起成网，核大而浅染，粗面内质网较丰富，产生网状纤维。
- 网状纤维可深陷入细胞胞体和突起，镀银呈黑色；网孔内细胞和液体自由流动。
- 体内不单独存在，为血细胞发生和淋巴细胞发育提供微环境。
:::

## 本章小结

结缔组织源自胚胎时期的间充质，由多种类型的细胞和细胞分泌形成的细胞外基质构成，广泛分布于全身各组织和器官内。

结缔组织的细胞主要包括固有细胞和游走细胞两类。固有细胞指未分化间充质细胞及其分化形成的成纤维细胞（静止状态的成纤维细胞称为纤维细胞）和脂肪细胞。游走细胞包括巨噬细胞、浆细胞、肥大细胞和白细胞等，源自血液或淋巴组织。细胞散在分布于细胞外基质内，无极性。

细胞外基质是指细胞之间的结构，包括成纤维细胞分泌产生的呈丝状的纤维和无定形基质以及不断循环更新的组织液，基质内含有多种细胞的代谢产物。根据成分和结构的不同将纤维分为胶原纤维、网状纤维和弹性纤维，分布于机体不同的部位，具有不同的功能。

结缔组织分布广泛，形态多样，包括固有结缔组织（即疏松结缔组织、致密结缔组织、脂肪组织和网状组织）和其他特殊类型的结缔组织，如血液、淋巴组织、软骨组织和骨组织等。结缔组织具有连接、支持、保护、贮存、营养、物质运输等多种功能。

:::definition{label="固有结缔组织"}
固有结缔组织包括疏松结缔组织、致密结缔组织、脂肪组织和网状组织，是结缔组织中除血液、淋巴组织、软骨和骨等特殊类型以外的部分。四型都由间充质演化而来，细胞无极性，细胞外基质含纤维、基质和组织液。
:::

:::compare{title="结缔组织全章对照：细胞、纤维与四型固有组织"}
| 账本 | 要点 |
|------|------|
| 来源 | 胚胎间充质（主要源自中胚层）；成体仍保留未分化间充质细胞 |
| 结构通式 | 细胞散在 + 细胞外基质（纤维、无定形基质、组织液）；细胞无极性 |
| 固有细胞 | 未分化间充质细胞、成纤维细胞（静止为纤维细胞）、脂肪细胞 |
| 游走细胞 | 巨噬细胞（静止为组织细胞）、浆细胞（效应 B）、肥大细胞、白细胞 |
| 三种纤维 | 胶原（Ⅰ型，横纹周期约 $64\,\mathrm{nm}$）、弹性（弹性蛋白 + 微原纤维）、网状（Ⅲ型，嗜银） |
| 基质 | 蛋白聚糖聚合体构成分子筛；纤维粘连蛋白连接细胞、胶原和蛋白聚糖 |
| 固有四型 | 疏松、致密、脂肪、网状 |
| 特殊类型 | 血液、淋巴组织、软骨组织、骨组织（后续专章） |
| 功能 | 连接、支持、保护、贮存、营养、物质运输 |
:::

:::keypoint{label="全章先把“无极性的细胞 + 细胞外基质”立住"}
- 结缔组织源自间充质；细胞无极性，散在于纤维、基质和组织液之中。
- 固有细胞造基质，游走细胞做防御；成纤维细胞是产纤维和基质的主力，可在活跃与静止之间互变。
- 三种纤维分工：胶原抗拉、弹性回弹、网状搭细支架；基质的分子筛既滤过又防御。
- 固有结缔组织四型是同一套构件的不同密度和细胞组成；血液、淋巴组织、软骨和骨是特殊类型。
:::

:::memory{label="本章小结必背"}
- [ ] 结缔组织源自胚胎间充质，由多种细胞及其分泌的细胞外基质构成，广泛分布于全身。
- [ ] 固有细胞：未分化间充质细胞、成纤维细胞（静止称纤维细胞）、脂肪细胞。
- [ ] 游走细胞：巨噬细胞、浆细胞、肥大细胞、白细胞，源自血液或淋巴组织。
- [ ] 细胞散在于细胞外基质内，无极性（与上皮相对）。
- [ ] 细胞外基质 = 纤维 + 无定形基质 + 不断更新的组织液。
- [ ] 纤维分胶原纤维、网状纤维和弹性纤维，部位和功能各异。
- [ ] 固有结缔组织：疏松、致密、脂肪、网状；特殊类型：血液、淋巴组织、软骨、骨。
- [ ] 功能：连接、支持、保护、贮存、营养、物质运输。
:::
