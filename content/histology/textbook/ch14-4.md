# 四、胃

食物入胃（stomach），与胃液混合为食糜。胃可贮存食物，初步消化蛋白质，吸收部分水、无机盐和醇类。胃的腔面有许多不规则的皱襞，当胃充盈时，皱襞消失。黏膜按上皮、固有层（胃底腺、贲门腺、幽门腺）和黏膜肌层来读；固有层里把主细胞、壁细胞、颈黏液细胞、干细胞和内分泌细胞分开写。

:::definition{label="胃"}
胃（stomach）可贮存食物，初步消化蛋白质，吸收部分水、无机盐和醇类。食物与胃液混合为食糜。腔面有许多不规则皱襞，充盈时皱襞消失。
:::

:::concept{term="先问这张切片是贲门、胃底胃体还是幽门，再问腺细胞是主细胞还是壁细胞"}
胃不是“一层会分泌酸的柱状上皮”。表面是表面黏液细胞做黏液膜加紧密连接；往下胃小凹通 3～5 条腺。胃底腺（泌酸腺）才是主战场：下半部主细胞产胃蛋白酶原，上半部壁细胞产盐酸和内因子。贲门腺、幽门腺以黏液为主，幽门腺还有 G 细胞产胃泌素。把所有腺细胞都写成壁细胞，黏液屏障、内因子和恶性贫血那几本账会并成一句“胃会消化”。
:::

## （一）黏膜

黏膜表面有许多浅沟，将黏膜分成许多直径 $2\sim 6\,\mathrm{mm}$ 的胃小区。黏膜表面还遍布约 $350$ 万个不规则形的小凹陷，称胃小凹（gastric pit）。每个胃小凹底部与 $3\sim 5$ 条腺体通连（图 14-11～图 14-14）。

:::definition{label="胃小区"}
黏膜表面有许多浅沟，将黏膜分成许多直径 $2\sim 6\,\mathrm{mm}$ 的胃小区。
:::

:::definition{label="胃小凹"}
胃小凹（gastric pit）是黏膜表面遍布的约 $350$ 万个不规则形小凹陷。每个胃小凹底部与 $3\sim 5$ 条腺体通连。
:::

### 1. 上皮

上皮为单层柱状上皮，主要由表面黏液细胞（surface mucous cell）组成。该细胞椭圆形的核位于基部；顶部细胞质中充满黏原颗粒，在 HE 染色切片上着色浅淡以至透明；上皮细胞分泌物中富含糖蛋白和碳酸氢根离子，分泌至细胞表面形成一层保护性的黏液膜，可防止高浓度盐酸与胃蛋白酶对黏膜的消化以及食物对上皮的磨损。相邻柱状细胞在近游离面处形成紧密连接，起屏障作用，防止胃腔内的化学物质进入胃壁，黏液膜和紧密连接共同组成屏障，起保护作用。胃上皮每 $4\sim 7$ 天更新一次，脱落的细胞由胃小凹底部和胃腺颈部的干细胞增殖补充。

:::definition{label="胃上皮"}
胃上皮为单层柱状上皮，主要由表面黏液细胞组成。每 $4\sim 7$ 天更新一次，脱落细胞由胃小凹底部和胃腺颈部的干细胞增殖补充。
:::

:::definition{label="表面黏液细胞"}
表面黏液细胞（surface mucous cell）核呈椭圆形、位于基部；顶部胞质充满黏原颗粒，HE 着色浅淡以至透明。分泌物富含糖蛋白和碳酸氢根离子（$\mathrm{HCO}_{3}^{-}$），在细胞表面形成保护性黏液膜。
:::

:::definition{label="胃黏膜屏障"}
表面黏液细胞的黏液膜与相邻柱状细胞近游离面的紧密连接共同组成屏障：黏液膜防止高浓度盐酸与胃蛋白酶消化黏膜、减轻食物磨损；紧密连接防止胃腔内化学物质进入胃壁。
:::

:::pitfall{label="表面黏液细胞不是颈黏液细胞，也不要写成杯状细胞"}
胃上皮是单层柱状的表面黏液细胞，HE 顶部透明是黏原颗粒，不是肠上皮那种夹在吸收细胞之间的杯状细胞。颈黏液细胞在胃底腺顶部，分泌可溶性酸性黏液，数量少、常呈楔形。把两者并成“胃里的黏液细胞”，更新周期（颈黏液细胞约一周，主细胞和壁细胞约 $200$ 天）会乱。
:::

:::insight{label="黏液膜管化学，紧密连接管缝隙，两道墙缺一不可"}
盐酸和胃蛋白酶能消化蛋白质，上皮自己也是蛋白质。黏液膜把酶和酸挡在腔面，紧密连接不让化学物质从细胞旁路漏进固有层。溃疡账常常先问这两道墙还在不在，而不是先问肌层厚不厚。
:::

### 2. 固有层

固有层内有排列紧密的大量管状腺，根据所在部位和结构的不同分为胃底腺、贲门腺和幽门腺。腺之间及胃小凹之间有少量结缔组织，其细胞成分中除成纤维细胞外，还有较多淋巴细胞及一些浆细胞、肥大细胞、嗜酸性粒细胞，以及散在的平滑肌细胞。

:::definition{label="胃黏膜固有层的腺"}
固有层内有排列紧密的大量管状腺，按部位分为胃底腺、贲门腺和幽门腺。腺之间及胃小凹之间仅有少量结缔组织，含成纤维细胞、较多淋巴细胞及浆细胞、肥大细胞、嗜酸性粒细胞和散在平滑肌细胞。
:::

|------|-------------------|--------|--------|
| 部位 | 胃底和胃体，数量最多、功能最重要 | 近贲门处宽 $1\sim 3\,\mathrm{cm}$ | 幽门部宽 $4\sim 5\,\mathrm{cm}$ |

#### （1）胃底腺

胃底腺（fundic gland）又称泌酸腺（oxyntic gland），分布于胃底和胃体部，是胃黏膜中数量最多、功能最重要的腺体。胃底腺呈分支管状，由主细胞、壁细胞、颈黏液细胞、干细胞和内分泌细胞组成（图 14-13～图 14-15）；越接近贲门部的胃底腺中主细胞越多，而越毗邻幽门部的腺中壁细胞越多。

:::definition{label="胃底腺"}
胃底腺（fundic gland）又称泌酸腺（oxyntic gland），分布于胃底和胃体部，是数量最多、功能最重要的腺体。呈分支管状，由主细胞、壁细胞、颈黏液细胞、干细胞和内分泌细胞组成。越接近贲门部主细胞越多，越毗邻幽门部壁细胞越多。
:::

::figure{src="/images/histology/textbook/p0164_03.png" caption="图14-15 胃底腺光镜图。1. 壁细胞（体积大，嗜酸性）；2. 主细胞（柱状，基部嗜碱性）。" alt="胃底腺高倍：嗜酸性壁细胞与基部嗜碱性的主细胞"}

**1）主细胞** 主细胞（chief cell）又称胃酶细胞（zymogenic cell），数量最多，主要分布于腺的下半部。细胞呈柱状，核圆形，位于基部；细胞质基部呈强嗜碱性，核上方充满酶原颗粒，但在普通固定染色的标本上，颗粒多溶解消失，使该部位呈色浅淡。此细胞具有典型的蛋白质分泌细胞的超微结构特点。主细胞分泌胃蛋白酶原（pepsinogen）。

:::definition{label="主细胞"}
主细胞（chief cell）又称胃酶细胞（zymogenic cell），是胃底腺中数量最多的细胞，主要分布于腺的下半部。细胞柱状，核圆、位于基部；胞质基部强嗜碱性，核上方充满酶原颗粒。分泌胃蛋白酶原（pepsinogen）。
:::

:::pitfall{label="普通切片上主细胞顶部发淡，是酶原颗粒被溶掉了，不是它不分泌"}
核上方的酶原颗粒在普通固定染色中常溶解消失，该区呈色浅淡；基部因粗面内质网而强嗜碱性。不要把“顶部空淡”写成黏液细胞，也不要把主细胞数量最多记成“体积最大”——体积大、嗜酸性的是壁细胞。
:::

**2）壁细胞** 壁细胞（parietal cell）又称泌酸细胞（oxyntic cell），在腺的上半部较多。细胞体积大，多呈圆锥形。核圆，位于细胞中央，可有双核；细胞质呈强嗜酸性。电镜下，细胞游离缘的细胞膜内陷形成分支小管，称细胞内分泌小管（intracellular secretory canaliculus），它们可环绕核，甚至接近基部质膜，小管开口于腺腔，小管腔面有大量微绒毛。分泌小管周围有许多小管和小泡，称微管泡系统（tubulovesicular system）。壁细胞的这些结构特征随分泌活动的不同时相而变化：当细胞处于静止状态时，微绒毛少而短，分泌小管少，微管泡系统发达；若细胞处于分泌状态，微管泡系统迅速转变成细胞内分泌小管，小管内微绒毛增长、增多，微管泡系统随之减少。这表明微管泡系统的膜与小管的膜是可以融合和相互转换的。壁细胞还有极丰富的线粒体。

分泌小管膜上有大量质子泵（$H^{+}$-$K^{+}$-ATP 酶）和 $\mathrm{Cl}^{-}$ 通道，能分别把壁细胞内形成的 $\mathrm{H}^{+}$ 和从血液摄取的 $\mathrm{Cl}^{-}$ 输入小管，二者结合成盐酸后进入腺腔。线粒体为这一耗能过程提供了大量 ATP。盐酸（也称胃酸）能激活胃蛋白酶原，使之转变为胃蛋白酶，并为其活性提供所需的酸性环境，以对食物蛋白质进行初步分解；盐酸还有杀菌作用。人的壁细胞还分泌内因子（intrinsic factor），这种糖蛋白在胃腔内与食物中的维生素 $\mathrm{B}_{12}$ 结合成复合物，使维生素 $\mathrm{B}_{12}$ 在肠道内不被酶分解，并能促进回肠吸收维生素 $\mathrm{B}_{12}$，供红细胞生成所需。萎缩性胃炎患者由于壁细胞减少，内因子缺乏，维生素 $\mathrm{B}_{12}$ 吸收障碍，可出现恶性贫血。

:::definition{label="壁细胞"}
壁细胞（parietal cell）又称泌酸细胞（oxyntic cell），在胃底腺上半部较多。体积大，多呈圆锥形；核圆、居中，可有双核；胞质强嗜酸性。分泌盐酸和内因子。
:::

:::definition{label="细胞内分泌小管"}
细胞内分泌小管（intracellular secretory canaliculus）是壁细胞游离缘细胞膜内陷形成的分支小管，可环绕核甚至接近基部质膜，开口于腺腔，腔面有大量微绒毛。
:::

:::definition{label="微管泡系统"}
微管泡系统（tubulovesicular system）是分泌小管周围的许多小管和小泡。静止时发达、分泌小管少、微绒毛短少；分泌时迅速转变成细胞内分泌小管，微绒毛增长增多。两套膜可融合并相互转换。
:::

:::definition{label="质子泵与盐酸形成"}
分泌小管膜上有大量质子泵（$H^{+}$-$K^{+}$-ATP 酶）和 $\mathrm{Cl}^{-}$ 通道，分别把壁细胞内的 $\mathrm{H}^{+}$ 和从血液摄取的 $\mathrm{Cl}^{-}$ 输入小管，二者结合成盐酸进入腺腔。丰富的线粒体提供 ATP。
:::

:::definition{label="盐酸的作用"}
盐酸（胃酸）能激活胃蛋白酶原为胃蛋白酶，并提供酸性环境，对食物蛋白质作初步分解；还有杀菌作用。
:::

:::definition{label="内因子"}
内因子（intrinsic factor）是人壁细胞分泌的糖蛋白。在胃腔内与食物中维生素 $\mathrm{B}_{12}$ 结合成复合物，使维生素 $\mathrm{B}_{12}$ 在肠道内不被酶分解，并促进回肠吸收，供红细胞生成所需。
:::

:::definition{label="恶性贫血（壁细胞）"}
萎缩性胃炎患者壁细胞减少，内因子缺乏，维生素 $\mathrm{B}_{12}$ 吸收障碍，可出现恶性贫血。病在内因子，不只是“胃酸少了”。
:::

:::concept{term="壁细胞先问这一时相是静止还是分泌：膜在微管泡里，还是铺到分泌小管上"}
泌酸不是把盐酸装在颗粒里往外吐。质子泵装在膜上：静止时膜囤在微管泡系统，分泌时膜转到细胞内分泌小管，微绒毛增多，把 $\mathrm{H}^{+}$ 和 $\mathrm{Cl}^{-}$ 泵进小管合成盐酸。线粒体极多，是因为这步耗 ATP。把壁细胞听成“嗜酸性所以在分泌酶原”，主细胞和壁细胞的光镜颜色账会互换。
:::

::figure{src="/images/histology/textbook/p0165_02.png" caption="图14-18 壁细胞超微结构模式图。左：静止状态，微管泡系统发达，细胞内分泌小管少；右：分泌状态，细胞内分泌小管及微绒毛增多，线粒体丰富。" alt="壁细胞静止与分泌时相：微管泡与细胞内分泌小管膜相互转换"}

:::pitfall{label="恶性贫血找内因子和维生素 B12，不要只写成“胃酸分泌不足”"}
盐酸激活胃蛋白酶原、杀菌；内因子护送维生素 $\mathrm{B}_{12}$ 到回肠。壁细胞两样都产，萎缩性胃炎少的是整群壁细胞，贫血账走内因子–$\mathrm{B}_{12}$–红细胞生成，不是蛋白酶原没被激活那么简单。
:::

**3）颈黏液细胞** 颈黏液细胞（mucous neck cell）较少，位于胃底腺顶部，常呈楔形夹在其他细胞之间。核扁平，居细胞基底部，核上方有很多黏原颗粒，HE 染色浅淡。其分泌物为可溶性的酸性黏液，对黏膜有保护作用。

:::definition{label="颈黏液细胞"}
颈黏液细胞（mucous neck cell）较少，位于胃底腺顶部，常呈楔形夹在其他细胞之间。核扁平、居基底部，核上方有很多黏原颗粒，HE 浅淡。分泌可溶性酸性黏液，保护黏膜。
:::

**4）干细胞** 干细胞（stem cell）存在于从胃底腺顶部至胃小凹深部一带，胞体较小，呈低柱状。干细胞可不断分裂增殖，向上迁移可分化为表面黏液细胞，向下迁移可分化为其他胃底腺细胞。主细胞和壁细胞的寿命约为 $200$ 天，颈黏液细胞为一周。

:::definition{label="胃底腺干细胞"}
干细胞（stem cell）位于胃底腺顶部至胃小凹深部一带，胞体较小、呈低柱状。向上迁移分化为表面黏液细胞，向下迁移分化为其他胃底腺细胞。
:::

:::note{label="胃上皮与胃底腺细胞的寿命"}
| 细胞 | 寿命 / 更新 |
|------|-------------|
| 表面黏液细胞（胃上皮） | 每 $4\sim 7$ 天更新一次 |
| 颈黏液细胞 | 约一周 |
| 主细胞、壁细胞 | 约 $200$ 天 |
:::

内分泌细胞主要为 ECL 细胞和 D 细胞。ECL 细胞分泌组胺，主要促进邻近壁细胞的泌酸功能。D 细胞分泌生长抑素，既可直接抑制壁细胞的功能，又可通过抑制 ECL 细胞而间接作用于壁细胞。

:::definition{label="ECL 细胞"}
ECL 细胞是胃底腺中的内分泌细胞，分泌组胺，主要促进邻近壁细胞的泌酸功能。
:::

:::definition{label="D 细胞（胃底腺）"}
D 细胞分泌生长抑素，既可直接抑制壁细胞，又可通过抑制 ECL 细胞而间接抑制壁细胞。
:::

#### （2）贲门腺

贲门腺（cardiac gland）分布于近贲门处宽 $1\sim 3\,\mathrm{cm}$ 的区域，为单管或分支管状腺，分泌黏液和溶菌酶。

:::definition{label="贲门腺"}
贲门腺（cardiac gland）分布于近贲门处宽 $1\sim 3\,\mathrm{cm}$ 的区域，为单管或分支管状腺，分泌黏液和溶菌酶。
:::

#### （3）幽门腺

幽门腺（pyloric gland）分布于幽门部宽 $4\sim 5\,\mathrm{cm}$ 的区域，此区胃小凹很深；幽门腺为分支较多而弯曲的管状黏液腺，可有少量壁细胞。幽门腺中还有很多 G 细胞，产生胃泌素（gastrin），可刺激壁细胞分泌盐酸，还能促进胃肠黏膜细胞增殖。

:::definition{label="幽门腺"}
幽门腺（pyloric gland）分布于幽门部宽 $4\sim 5\,\mathrm{cm}$ 的区域。此区胃小凹很深。腺体为分支较多而弯曲的管状黏液腺，可有少量壁细胞，并有很多 G 细胞。
:::

:::definition{label="G 细胞"}
G 细胞主要位于幽门腺，产生胃泌素（gastrin），刺激壁细胞分泌盐酸，并能促进胃肠黏膜细胞增殖。
:::

以上 3 种腺体的分泌物的混合物统称胃液，成人胃液 $\mathrm{pH}$ 为 $0.9\sim 1.5$，每日分泌量为 $1.5\sim 2.5\,\mathrm{L}$，除含有盐酸、胃蛋白酶、黏液外，还有大量水、$\mathrm{NaCl}$、$\mathrm{KCl}$ 等。

:::definition{label="胃液"}
胃液是胃底腺、贲门腺和幽门腺分泌物的混合物。成人 $\mathrm{pH}$ 为 $0.9\sim 1.5$，每日分泌 $1.5\sim 2.5\,\mathrm{L}$，含盐酸、胃蛋白酶、黏液及大量水、$\mathrm{NaCl}$、$\mathrm{KCl}$ 等。
:::

:::insight{label="泌酸由壁细胞执行，命令却可以来自邻细胞或幽门 G 细胞"}
ECL 细胞的组胺就近促进壁细胞；D 细胞的生长抑素刹车；幽门 G 细胞的胃泌素从远处刺激泌酸并促黏膜增殖。把“谁产酸”和“谁下令产酸”写成同一个细胞，内分泌调节账会并进壁细胞胞质里。
:::

:::pitfall{label="幽门部小凹深、腺弯曲，不要按胃底腺的主细胞去找酶原颗粒"}
幽门腺是黏液腺，主战场不是胃蛋白酶原。此区小凹很深，切片上“腺很浅”其实是小凹占了厚度。G 细胞产胃泌素促壁细胞泌酸，所以幽门本身黏液多、酸却可以在胃底被远程加强。
:::

### 3. 黏膜肌层

黏膜肌层由内环行与外纵行两薄层平滑肌组成。

:::definition{label="胃黏膜肌层"}
胃黏膜肌层由内环行与外纵行两薄层平滑肌组成，收缩有助于胃腺分泌物排出和血液运行。
:::

## （二）黏膜下层

黏膜下层为较致密的结缔组织，内含较粗的血管、淋巴管和神经，还可见成群的脂肪细胞。

:::definition{label="胃黏膜下层"}
胃黏膜下层为较致密的结缔组织，含较粗的血管、淋巴管和神经，还可见成群的脂肪细胞。皱襞由黏膜与黏膜下层共同突向腔面形成。
:::

## （三）肌层和外膜

肌层较厚，一般由内斜行、中环行和外纵行 3 层平滑肌构成。环行肌在贲门和幽门部增厚，分别形成贲门括约肌和幽门括约肌。外膜为浆膜。

:::definition{label="胃肌层"}
胃肌层较厚，一般由内斜行、中环行和外纵行 3 层平滑肌构成。
:::

:::definition{label="贲门括约肌与幽门括约肌"}
环行肌在贲门和幽门部增厚，分别形成贲门括约肌和幽门括约肌。
:::

:::definition{label="胃外膜"}
胃外膜为浆膜：薄层结缔组织表面覆以间皮，利于蠕动时减少摩擦。
:::

:::compare{title="胃壁四层与食管的差别"}
| 层次 | 胃 | 食管 |
|------|----|------|
| 上皮 | 单层柱状（表面黏液细胞） | 未角化复层扁平 |
| 固有层腺体 | 胃底腺、贲门腺、幽门腺 | 上、下段少量黏液腺 |
| 黏膜下层腺体 | 无食管腺那样的黏膜下腺；可见脂肪细胞 | 黏液性食管腺 |
| 肌层 | 内斜、中环、外纵 3 层平滑肌；贲门、幽门环行肌成括约肌 | 内环外纵；上中下骨骼肌–混合–平滑肌 |
| 外膜 | 浆膜 | 纤维膜 |
:::

:::pitfall{label="胃肌层是三层平滑肌，不要套用内环外纵两层通例"}
通例两层：内环、外纵。胃加了一层内斜行，环行肌还在贲门和幽门加厚成括约肌。外膜是浆膜不是纤维膜。把胃写成“和小肠一样的两层肌 + 纤维膜”，贮存和幽门控制那两本账会没有肌性落点。
:::

:::keypoint{label="胃黏膜先立表面黏液屏障，再立胃底腺五种细胞"}
- 胃：贮存，初步消化蛋白质，吸收部分水、无机盐和醇类；充盈时皱襞消失。
- 胃小凹约 $350$ 万个，每个通 $3\sim 5$ 条腺；胃小区直径 $2\sim 6\,\mathrm{mm}$。
- 上皮为表面黏液细胞：黏液膜（糖蛋白 + $\mathrm{HCO}_{3}^{-}$）+ 紧密连接 = 屏障；$4\sim 7$ 天更新。
- 胃底腺（泌酸腺）：主细胞（胃蛋白酶原）、壁细胞（盐酸、内因子）、颈黏液细胞、干细胞、ECL/D 细胞。
- 壁细胞：细胞内分泌小管与微管泡系统互变；质子泵泵 $\mathrm{H}^{+}$，$\mathrm{Cl}^{-}$ 通道入小管成盐酸；内因子缺乏 → 恶性贫血。
- 贲门腺：黏液 + 溶菌酶。幽门腺：深小凹、弯曲黏液腺，G 细胞产胃泌素。
- 胃液 $\mathrm{pH}\,0.9\sim 1.5$，每日 $1.5\sim 2.5\,\mathrm{L}$。
- 肌层内斜、中环、外纵；外膜浆膜。
:::

:::memory{label="本节必背要点"}
- [ ] 食物入胃（stomach）与胃液混合为食糜；胃可贮存食物，初步消化蛋白质，吸收部分水、无机盐和醇类。
- [ ] 胃腔面有许多不规则皱襞，充盈时皱襞消失。
- [ ] 浅沟将黏膜分成直径 $2\sim 6\,\mathrm{mm}$ 的胃小区。
- [ ] 胃小凹（gastric pit）约 $350$ 万个，每个底部与 $3\sim 5$ 条腺体通连。
- [ ] 胃上皮为单层柱状，主要由表面黏液细胞（surface mucous cell）组成。
- [ ] 表面黏液细胞核椭圆居基部，顶部黏原颗粒 HE 浅淡以至透明；分泌物富含糖蛋白和 $\mathrm{HCO}_{3}^{-}$，形成保护性黏液膜。
- [ ] 黏液膜防止高浓度盐酸与胃蛋白酶消化黏膜及食物磨损；相邻细胞近游离面紧密连接，防止化学物质进入胃壁。黏液膜 + 紧密连接共同构成屏障。
- [ ] 胃上皮每 $4\sim 7$ 天更新一次，由胃小凹底部和胃腺颈部干细胞补充。
- [ ] 固有层有大量管状腺，分为胃底腺、贲门腺和幽门腺；腺间结缔组织含成纤维细胞、淋巴细胞、浆细胞、肥大细胞、嗜酸性粒细胞及散在平滑肌细胞。
- [ ] 胃底腺（fundic gland）又称泌酸腺（oxyntic gland），分布于胃底和胃体，数量最多、功能最重要，呈分支管状。
- [ ] 胃底腺由主细胞、壁细胞、颈黏液细胞、干细胞和内分泌细胞组成；近贲门部主细胞较多，近幽门部壁细胞较多。
- [ ] 主细胞（chief cell）又称胃酶细胞（zymogenic cell），数量最多，主要在腺下半部；柱状，核圆居基，基部强嗜碱，核上酶原颗粒在普通制片中常溶解而浅淡。
- [ ] 主细胞分泌胃蛋白酶原（pepsinogen）。
- [ ] 壁细胞（parietal cell）又称泌酸细胞（oxyntic cell），腺上半部较多；体积大，多呈圆锥形，核圆居中可双核，胞质强嗜酸。
- [ ] 细胞内分泌小管（intracellular secretory canaliculus）由游离缘质膜内陷形成，开口于腺腔，腔面有大量微绒毛。
- [ ] 微管泡系统（tubulovesicular system）与分泌小管的膜可融合互变：静止时微管泡发达；分泌时转变为分泌小管，微绒毛增多。
- [ ] 壁细胞线粒体极丰富；分泌小管膜上有质子泵（$H^{+}$-$K^{+}$-ATP 酶）和 $\mathrm{Cl}^{-}$ 通道，将 $\mathrm{H}^{+}$ 与 $\mathrm{Cl}^{-}$ 输入小管结合成盐酸。
- [ ] 盐酸激活胃蛋白酶原为胃蛋白酶并提供酸性环境，初步分解蛋白质；兼有杀菌作用。
- [ ] 人壁细胞分泌内因子（intrinsic factor），与维生素 $\mathrm{B}_{12}$ 结合，使之不被肠酶分解并促进回肠吸收，供红细胞生成。
- [ ] 萎缩性胃炎壁细胞减少 → 内因子缺乏 → 维生素 $\mathrm{B}_{12}$ 吸收障碍 → 恶性贫血。
- [ ] 颈黏液细胞（mucous neck cell）较少，位于腺顶部，常楔形；核扁平居底，分泌可溶性酸性黏液。
- [ ] 干细胞在腺顶至胃小凹深部，低柱状；向上成表面黏液细胞，向下成其他胃底腺细胞。
- [ ] 主细胞和壁细胞寿命约 $200$ 天，颈黏液细胞约一周。
- [ ] ECL 细胞分泌组胺，促进邻近壁细胞泌酸；D 细胞分泌生长抑素，直接或经抑制 ECL 而抑制壁细胞。
- [ ] 贲门腺（cardiac gland）在近贲门 $1\sim 3\,\mathrm{cm}$，单管或分支管状，分泌黏液和溶菌酶。
- [ ] 幽门腺（pyloric gland）在幽门部 $4\sim 5\,\mathrm{cm}$，胃小凹很深，为分支多而弯曲的管状黏液腺，可有少量壁细胞。
- [ ] 幽门腺有很多 G 细胞，产生胃泌素（gastrin），刺激壁细胞泌酸并促进胃肠黏膜细胞增殖。
- [ ] 胃液为三种腺分泌物的混合物，成人 $\mathrm{pH}\,0.9\sim 1.5$，每日 $1.5\sim 2.5\,\mathrm{L}$，含盐酸、胃蛋白酶、黏液及大量水、$\mathrm{NaCl}$、$\mathrm{KCl}$ 等。
- [ ] 胃黏膜肌层由内环行与外纵行两薄层平滑肌组成。
- [ ] 胃黏膜下层为较致密结缔组织，含较粗血管、淋巴管和神经，可见成群脂肪细胞。
- [ ] 胃肌层由内斜行、中环行和外纵行 3 层平滑肌构成；环行肌在贲门和幽门增厚，分别形成贲门括约肌和幽门括约肌。
- [ ] 胃外膜为浆膜。
