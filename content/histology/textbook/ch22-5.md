# 五、牙的发生

颜面五突围出口凹之后，口凹边缘的外胚层还要沿上下颌铺出牙板，再长出牙蕾。牙蕾被间充质从底部顶成帽状造釉器，加上牙乳头和牙囊，才叫乳牙原基。本节把釉质、牙本质、牙骨质三本发生账摊开；恒牙牙蕾和智齿放在同一条时间尺上。颈和四肢下一节再写。

:::definition{label="牙板"}
牙板（dental lamina）是第 $6$ 周口凹边缘外胚层增生、沿上下颌形成的 $U$ 形上皮板。它不是已经长出的牙齿，只是乳牙牙蕾的上皮源头。
:::

第 $6$ 周时，口凹边缘的外胚层增生，沿上下颌形成 $U$ 形的牙板（dental lamina）。牙板上皮向深部中胚层内生长，在上下颌内各先后形成 $10$ 个圆形突起，称牙蕾（tooth bud）。牙蕾发育增大，间充质从其底部进入，形成牙乳头（dental papilla），牙蕾的外胚层组织遂成为帽状的造釉器（enamel organ），造釉器和牙乳头周围的间充质形成牙囊（dental sac）。造釉器、牙乳头和牙囊共同构成乳牙原基（图 22-8，图 22-9）。

:::definition{label="牙蕾"}
牙蕾（tooth bud）是牙板上皮向深部中胚层内生长形成的圆形突起。上下颌各先后形成 $10$ 个，对应 $20$ 颗乳牙。牙蕾本身还不是乳牙原基。
:::

:::definition{label="牙乳头"}
牙乳头（dental papilla）是间充质从牙蕾底部进入后形成的间充质团。靠近内釉上皮的细胞将分化为成牙本质细胞；其余部分分化为牙髓。
:::

:::definition{label="造釉器"}
造釉器（enamel organ）是牙蕾的外胚层组织被牙乳头顶成帽状后的结构。它分化为外釉上皮、内釉上皮和釉网三部分，专职造釉质，不造牙本质。
:::

:::definition{label="牙囊"}
牙囊（dental sac）是造釉器和牙乳头周围的间充质。内侧份分化为牙骨质，外侧份分化为牙周膜。
:::

:::definition{label="乳牙原基"}
乳牙原基 = 造釉器 + 牙乳头 + 牙囊。三件套缺一不可。只有牙蕾、没有乳头和牙囊，还不能叫原基。
:::

:::concept{term="先问上皮牙板有没有被间充质顶成帽，再问三件套是否已经凑齐"}
看见“牙的发生”，不要写成“口凹边上直接长出牙齿”。先问第 $6$ 周外胚层有没有铺成 $U$ 形牙板、上下颌各有没有 $10$ 个牙蕾；再问间充质有没有从底部进入——进入了才有牙乳头，牙蕾外胚层才变成帽状造釉器，周围间充质才围成牙囊。三件套凑齐才是乳牙原基。把牙蕾听成“已经是牙”，釉质、牙本质和牙骨质会对错户头。
:::

:::compare{title="造釉器、牙乳头与牙囊"}
| 项目 | 造釉器 | 牙乳头 | 牙囊 |
|------|--------|--------|------|
| 英文 | enamel organ | dental papilla | dental sac |
| 来源 | 牙蕾的外胚层组织 | 从牙蕾底部进入的间充质 | 造釉器和牙乳头周围的间充质 |
| 形态 | 帽状 | 被帽罩住的间充质团 | 外围的间充质囊 |
| 分化去向 | 外釉上皮、内釉上皮（成釉质细胞）、釉网 → 釉质 | 成牙本质细胞 → 牙本质；其余 → 牙髓 | 内侧份 → 牙骨质；外侧份 → 牙周膜 |
| 不要听成 | 牙本质的源头 | 造釉质的上皮 | 已经是牙周膜 |
:::

## 1. 釉质的形成

造釉器分化为 $3$ 部分：① 外层为单层立方或扁平细胞组成的外釉上皮；② 内层为单层柱状细胞组成的内釉上皮，该柱状细胞称为成釉质细胞（ameloblast）；③ 内、外上皮之间为星状细胞组成的釉网。成釉质细胞具有造釉质作用，它们不断分泌基质，基质钙化后形成釉柱。釉质的形成是从牙冠尖部开始，逐渐向牙颈部扩展。随着釉质增厚，成釉质细胞渐向浅部迁移，最后与外釉上皮相贴，共同组成牙小皮，覆盖于牙釉质表面，釉网则退化消失。婴儿出牙时，牙小皮随之消失。

:::definition{label="外釉上皮"}
外釉上皮是造釉器外层，由单层立方或扁平细胞组成。后期与浅迁而来的成釉质细胞相贴，共同组成牙小皮。
:::

:::definition{label="内釉上皮"}
内釉上皮是造釉器内层，由单层柱状细胞组成。这些柱状细胞就是成釉质细胞，紧贴牙乳头一侧。
:::

:::definition{label="成釉质细胞"}
成釉质细胞（ameloblast）即内釉上皮的单层柱状细胞，专职分泌釉质基质。基质钙化后形成釉柱。釉质增厚时，胞体向浅部迁移，最后与外釉上皮相贴。
:::

:::definition{label="釉网"}
釉网位于内、外釉上皮之间，由星状细胞组成。釉质形成后期退化消失，不参与组成牙小皮。
:::

:::definition{label="釉柱"}
釉柱是成釉质细胞分泌的基质钙化后形成的釉质结构单位。形成顺序是从牙冠尖部开始，逐渐向牙颈部扩展。
:::

:::definition{label="牙小皮"}
牙小皮由浅迁后的成釉质细胞与外釉上皮共同组成，覆盖于牙釉质表面。婴儿出牙时随之消失。它不是釉网，也不是牙本质小管。
:::

::figure{src="/images/histology/textbook/p0248_02.png" caption="图22-9 牙的发生光镜图（第15天地鼠胚胎）。1. 牙乳头；2. 内釉上皮；3. 釉网；4. 外釉上皮；箭头示口腔上皮。" alt="帽状造釉器光镜：中央牙乳头，内层深染柱状内釉上皮，外侧星状釉网，最外扁平外釉上皮，右上箭头指向口腔上皮"}

:::compare{title="造釉器的三部分"}
| 项目 | 外釉上皮 | 内釉上皮 | 釉网 |
|------|----------|----------|------|
| 位置 | 造釉器外层 | 造釉器内层，邻牙乳头 | 内、外上皮之间 |
| 细胞 | 单层立方或扁平 | 单层柱状 = 成釉质细胞 | 星状细胞 |
| 职分 | 后期参与组成牙小皮 | 分泌基质，钙化成釉柱 | 衬在内外上皮之间 |
| 结局 | 与浅迁的成釉质细胞相贴成牙小皮 | 浅迁，最后贴向外釉上皮 | 退化消失 |
| 不要听成 | 成釉质细胞 | 成牙本质细胞 | 牙小皮 |
:::

:::concept{term="先问这层柱状细胞贴的是牙乳头还是口腔面，再问分泌的是釉质还是牙本质"}
切片上先找帽状造釉器。贴着牙乳头那一层单层柱状是内釉上皮，细胞叫成釉质细胞，造的是釉质；帽的外层扁平或立方是外釉上皮；中间星状区是釉网。牙乳头里贴着内釉上皮的间充质才变成成牙本质细胞，造的是牙本质。把“柱状细胞”一律听成成釉质细胞，或把釉质写成牙乳头分泌的，两本矿化账会并户。
:::

:::cause-effect{title="釉质从冠尖推向牙颈，成釉质细胞只能往浅处走"}
- 因：成釉质细胞不断分泌基质，基质钙化成釉柱
- 果：釉质从牙冠尖部开始增厚，逐渐向牙颈部扩展
- 因：釉质堆在细胞与牙乳头之间
- 果：成釉质细胞胞体向浅部迁移，最后与外釉上皮相贴，共同组成牙小皮；釉网退化消失
- 制约：婴儿出牙时牙小皮随之消失，不是终身覆盖在釉质表面的膜
:::

:::pitfall{label="成釉质细胞浅迁，成牙本质细胞深迁，方向不要写反"}
造釉的柱状细胞在内釉上皮，釉质越厚，胞体越往浅部走，去对外釉上皮会合。造牙本质的柱状细胞在牙乳头浅层，牙本质越厚，胞体越往深部走，突起留在牙本质小管里。两边都是“柱状、分泌基质、钙化”，迁移方向相反。写成同一侧、同一方向，牙小皮和牙本质纤维会对调。
:::

## 2. 牙本质的形成

牙乳头靠近内釉上皮的间充质细胞分化为一层柱状的成牙本质细胞。该细胞在其与内釉上皮相邻面生出突起，并在此部位分泌基质，基质钙化后即为牙本质。随着牙本质增厚，成牙本质细胞胞体移至深部，其突起增长，称牙本质纤维，纤维所在的管道称牙本质小管。牙乳头的其余部分分化为牙髓。

:::definition{label="成牙本质细胞"}
成牙本质细胞由牙乳头靠近内釉上皮的间充质细胞分化而来，呈一层柱状。在与内釉上皮相邻面生出突起，并在此部位分泌基质。
:::

:::definition{label="牙本质"}
牙本质是成牙本质细胞分泌的基质钙化后形成的硬组织。它在釉质内侧，来自间充质，不是造釉器的产物。
:::

:::definition{label="牙本质纤维"}
随着牙本质增厚，成牙本质细胞胞体移至深部，其突起增长，称牙本质纤维。纤维本身是细胞突起，不是胶原纤维束的别名。
:::

:::definition{label="牙本质小管"}
牙本质小管是牙本质纤维所在的管道。小管连到深部的成牙本质细胞胞体。
:::

:::definition{label="牙髓"}
牙髓由牙乳头除去成牙本质细胞层以外的其余部分分化而来。它不是牙囊，也不形成牙骨质。
:::

:::compare{title="釉质与牙本质"}
| 项目 | 釉质 | 牙本质 |
|------|------|--------|
| 细胞 | 成釉质细胞（内釉上皮，外胚层） | 成牙本质细胞（牙乳头间充质） |
| 分泌部位 | 成釉质细胞朝向牙冠的一面 | 成牙本质细胞与内釉上皮相邻面的突起处 |
| 钙化产物 | 釉柱 | 牙本质 |
| 起始部位 | 牙冠尖部 → 牙颈部 | 紧邻内釉上皮处，随增厚向深部推进 |
| 细胞去向 | 浅迁，与外釉上皮组成牙小皮 | 深迁；突起 = 牙本质纤维，管道 = 牙本质小管 |
| 其余组织 | 釉网退化 | 牙乳头其余部分 → 牙髓 |
:::

:::insight{label="同一条界面，上皮往外造釉，间充质往里造本质"}
内釉上皮和牙乳头的交界是矿化的工作面：上皮侧成釉质细胞把釉质推向冠方，间充质侧成牙本质细胞把牙本质推向髓方。界面还在，两群细胞背向迁移。把釉质、牙本质写成“牙蕾里一起钙化出来的一层硬组织”，小管和牙小皮都没有地方可放。
:::

## 3. 牙骨质的形成

牙囊的内侧份分化为牙骨质，外侧份分化为牙周膜。

:::definition{label="牙骨质"}
牙骨质由牙囊的内侧份分化而来，包在牙根表面。它不是釉质，也不是牙本质。
:::

:::definition{label="牙周膜"}
牙周膜由牙囊的外侧份分化而来，连接牙骨质与牙槽骨。教材此处称牙周膜；图 22-8 出生后 $6$ 个月一幅标注为牙周韧带，户头相同。
:::

:::compare{title="牙囊内侧份与外侧份"}
| 项目 | 内侧份 | 外侧份 |
|------|--------|--------|
| 分化 | 牙骨质 | 牙周膜 |
| 位置关系 | 贴牙根 | 介于牙骨质与牙槽骨之间 |
| 不要听成 | 牙髓（牙髓来自牙乳头） | 牙小皮（牙小皮来自造釉器） |
:::

:::pitfall{label="牙骨质和牙周膜来自牙囊，不要写成牙乳头的产物"}
牙乳头管牙本质和牙髓，牙囊管牙骨质和牙周膜。把牙骨质写成“牙乳头外侧那一层”，或把牙周膜写成“牙髓外围的膜”，三件套的分工会从根尖写乱。
:::

## 恒牙牙蕾与智齿

第 $10$ 周时，恒牙牙蕾形成，其形成和发育过程与乳牙相同。出生后约 $6$ 年，恒牙开始生长，其上方的乳牙受推挤脱落，恒牙萌出。智齿指的是第三磨牙，生长在牙槽骨的末端，萌出的年龄和数目个体差异较大，大多数人会在 $16\sim 25$ 岁时萌出 $1\sim 4$ 颗。现代人牙槽骨不同程度的退化及智齿本身的退化可导致智齿萌出异常或者不对称萌出。

:::definition{label="恒牙牙蕾"}
恒牙牙蕾在第 $10$ 周形成。形成和发育过程与乳牙相同：同样经过牙蕾、造釉器、牙乳头和牙囊。它不是乳牙原基改名，而是另起的一套牙蕾。
:::

:::definition{label="智齿"}
智齿指第三磨牙，生长在牙槽骨的末端。萌出年龄和数目个体差异较大，大多数人会在 $16\sim 25$ 岁时萌出 $1\sim 4$ 颗。
:::

:::compare{title="乳牙与恒牙"}
| 项目 | 乳牙 | 恒牙 |
|------|------|------|
| 牙蕾出现 | 第 $6$ 周牙板，上下颌各 $10$ 个 | 第 $10$ 周恒牙牙蕾 |
| 原基组成 | 造釉器 + 牙乳头 + 牙囊 | 过程相同 |
| 萌出 | 婴儿出牙；出牙时牙小皮消失 | 出生后约 $6$ 年开始生长，推挤乳牙脱落 |
| 智齿 | 无 | 第三磨牙；$16\sim 25$ 岁多数萌出 $1\sim 4$ 颗 |
| 异常 | — | 牙槽骨退化及智齿本身退化 → 萌出异常或不对称萌出 |
:::

:::example{label="智齿萌出异常"}
智齿长在牙槽骨末端。大多数人 $16\sim 25$ 岁萌出 $1\sim 4$ 颗，但年龄、数目个体差异大。现代人牙槽骨不同程度退化，加上智齿本身退化，可导致萌出异常或不对称萌出。这是教材写明的结局，不是另立的畸形节。
:::

:::timeline{period="从牙板到恒牙萌出"}
- **第6周** 口凹边缘外胚层沿上下颌形成 U 形牙板
- **随后** 牙板上皮向深部生长，上下颌各先后形成 10 个牙蕾
- **牙蕾增大** 底部进入间充质形成牙乳头；外胚层成帽状造釉器；周围间充质成牙囊；三件套构成乳牙原基
- **釉质** 造釉器分外釉上皮、内釉上皮（成釉质细胞）、釉网；基质钙化成釉柱，从牙冠尖部推向牙颈；成釉质细胞浅迁，与外釉上皮成牙小皮，釉网退化；出牙时牙小皮消失
- **牙本质** 牙乳头靠近内釉上皮的间充质 → 成牙本质细胞 → 突起分泌基质钙化成牙本质；胞体深迁，突起为牙本质纤维，管道为牙本质小管；其余牙乳头 → 牙髓
- **牙骨质** 牙囊内侧份 → 牙骨质；外侧份 → 牙周膜
- **第10周** 恒牙牙蕾形成，过程与乳牙相同
- **出生后约6年** 恒牙生长，推挤乳牙脱落并萌出
- **16～25岁** 多数人萌出智齿（第三磨牙）1～4 颗；牙槽骨及智齿退化可致萌出异常或不对称萌出
:::

:::tip{label="三件套口诀"}
上皮造釉，乳头造本质和髓，牙囊造骨质和牙周膜。成釉质细胞往浅走，成牙本质细胞往深走。
:::

:::keypoint{label="牙板出牙蕾，三件套成乳牙原基，釉、本质、骨质分户"}
- 第 $6$ 周：口凹边缘外胚层 → $U$ 形牙板 → 上下颌各 $10$ 个牙蕾。
- 牙蕾增大：底部间充质 → 牙乳头；外胚层 → 帽状造釉器；周围间充质 → 牙囊。三者 = 乳牙原基。
- 造釉器三部分：外釉上皮（单层立方或扁平）；内釉上皮 = 成釉质细胞（ameloblast，单层柱状）；釉网（星状细胞）。
- 釉质：基质钙化成釉柱，从牙冠尖部向牙颈扩展；成釉质细胞浅迁，与外釉上皮成牙小皮；釉网退化；出牙时牙小皮消失。
- 牙本质：牙乳头近内釉上皮的间充质 → 成牙本质细胞 → 突起分泌基质钙化；胞体深迁，突起 = 牙本质纤维，管道 = 牙本质小管；其余牙乳头 → 牙髓。
- 牙囊内侧份 → 牙骨质，外侧份 → 牙周膜。
- 第 $10$ 周恒牙牙蕾，过程同乳牙；出生后约 $6$ 年恒牙萌出、推落乳牙。
- 智齿 = 第三磨牙；$16\sim 25$ 岁多数萌出 $1\sim 4$ 颗；牙槽骨及智齿退化可致萌出异常或不对称萌出。
:::

:::memory{label="本节必背要点"}
- [ ] 第 $6$ 周时，口凹边缘的外胚层增生，沿上下颌形成 $U$ 形的牙板（dental lamina）。
- [ ] 牙板上皮向深部中胚层内生长，在上下颌内各先后形成 $10$ 个圆形突起，称牙蕾（tooth bud）。
- [ ] 牙蕾发育增大，间充质从其底部进入，形成牙乳头（dental papilla）。
- [ ] 牙蕾的外胚层组织遂成为帽状的造釉器（enamel organ）。
- [ ] 造釉器和牙乳头周围的间充质形成牙囊（dental sac）。
- [ ] 造釉器、牙乳头和牙囊共同构成乳牙原基。
- [ ] 造釉器分化为 $3$ 部分：外釉上皮、内釉上皮、釉网。
- [ ] 外釉上皮为单层立方或扁平细胞。
- [ ] 内釉上皮为单层柱状细胞，称为成釉质细胞（ameloblast）。
- [ ] 内、外上皮之间为星状细胞组成的釉网。
- [ ] 成釉质细胞不断分泌基质，基质钙化后形成釉柱。
- [ ] 釉质的形成从牙冠尖部开始，逐渐向牙颈部扩展。
- [ ] 随着釉质增厚，成釉质细胞渐向浅部迁移，最后与外釉上皮相贴，共同组成牙小皮。
- [ ] 牙小皮覆盖于牙釉质表面，釉网则退化消失。
- [ ] 婴儿出牙时，牙小皮随之消失。
- [ ] 牙乳头靠近内釉上皮的间充质细胞分化为一层柱状的成牙本质细胞。
- [ ] 成牙本质细胞在与内釉上皮相邻面生出突起，并在此部位分泌基质，基质钙化后即为牙本质。
- [ ] 随着牙本质增厚，成牙本质细胞胞体移至深部，突起增长，称牙本质纤维。
- [ ] 牙本质纤维所在的管道称牙本质小管。
- [ ] 牙乳头的其余部分分化为牙髓。
- [ ] 牙囊的内侧份分化为牙骨质，外侧份分化为牙周膜。
- [ ] 第 $10$ 周时，恒牙牙蕾形成，其形成和发育过程与乳牙相同。
- [ ] 出生后约 $6$ 年，恒牙开始生长，其上方的乳牙受推挤脱落，恒牙萌出。
- [ ] 智齿指的是第三磨牙，生长在牙槽骨的末端。
- [ ] 大多数人会在 $16\sim 25$ 岁时萌出 $1\sim 4$ 颗智齿；年龄和数目个体差异较大。
- [ ] 现代人牙槽骨不同程度的退化及智齿本身的退化可导致智齿萌出异常或者不对称萌出。
:::
