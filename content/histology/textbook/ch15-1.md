# 一、大唾液腺

消化系统由消化管和消化腺组成。第 14 章把管壁四层摊开；本章写把分泌物送进管腔的大消化腺。消化腺（digestive gland）包括大消化腺，即 3 对大唾液腺、胰腺和肝，以及分布于消化管壁内的许多小消化腺，如口腔内的小唾液腺、食管腺、胃腺和肠腺等。大消化腺由腺细胞组成的分泌部、导管和间质所组成，分泌物经导管排入消化管，对食物进行化学消化。此外，胰腺还有内分泌功能。本章先把大唾液腺的腺泡、闰管和纹状管摊开；胰腺、肝、胆囊与胆管各立一节。

:::definition{label="消化腺"}
消化腺（digestive gland）包括大消化腺（3 对大唾液腺、胰腺和肝）以及分布于消化管壁内的许多小消化腺（口腔内的小唾液腺、食管腺、胃腺和肠腺等）。大消化腺由腺细胞组成的分泌部、导管和间质组成，分泌物经导管排入消化管，对食物进行化学消化。胰腺还有内分泌功能。
:::

:::definition{label="大消化腺"}
大消化腺是独立成器官的外分泌腺，由分泌部、导管和间质组成。本章的主体是 3 对大唾液腺、胰腺和肝。胃腺、肠腺等小消化腺长在消化管壁内，已在第 14 章记账。
:::

:::concept{term="先问产物走导管进消化管，还是入血当激素"}
看见“消化腺”，先把两本账拆开：外分泌把酶和黏液经导管送进口腔或十二指肠，管化学消化；内分泌把激素送进血液或淋巴。大唾液腺只有外分泌；胰腺外分泌部加胰岛；肝的胆汁走胆管，血浆蛋白却直接入血。把消化腺听成“只会造消化液”，胰岛和肝的入血账会一起做丢。
:::

:::compare{title="大消化腺与管壁内小消化腺"}
| 项目 | 大消化腺 | 小消化腺 |
|------|----------|----------|
| 成员 | 3 对大唾液腺、胰腺、肝 | 口腔内小唾液腺、食管腺、胃腺、肠腺等 |
| 位置 | 独立器官，导管开口于消化管 | 分布于消化管壁内 |
| 组成 | 分泌部 + 导管 + 间质 | 多埋在固有层或黏膜下层 |
| 产物去向 | 经导管排入消化管；胰、肝另有入血账 | 直接开口于管腔或胃小凹、肠腺 |
| 本章位置 | 第 15 章 | 第 14 章已写 |
:::

## 一、大唾液腺

大唾液腺有腮腺、下颌下腺、舌下腺各一对，分泌的唾液经导管排入口腔。

:::definition{label="大唾液腺"}
大唾液腺有腮腺、下颌下腺、舌下腺各一对，分泌的唾液经导管排入口腔。三者都是复管泡状腺，被膜较薄。
:::

## （一）大唾液腺的一般结构

大唾液腺均为复管泡状腺，被膜较薄。被膜伸入结缔组织将腺实质分隔为大小不等的小叶，血管、淋巴管和神经也随同走行其间，并进入小叶内。腺实质由分支的导管及末端的腺泡组成。腺泡分浆液腺泡、黏液腺泡与混合腺泡 3 类。在腺细胞和部分导管上皮细胞与基膜之间有肌上皮细胞，其收缩有助于分泌物排出。

:::definition{label="复管泡状腺"}
大唾液腺均为复管泡状腺：导管有分支，末端腺泡呈泡状或管泡状。被膜较薄，伸入的结缔组织把实质分成大小不等的小叶；血管、淋巴管和神经随同走行，并进入小叶内。
:::

:::definition{label="腺实质"}
腺实质由分支的导管及末端的腺泡组成。腺泡分浆液腺泡、黏液腺泡与混合腺泡 3 类。
:::

:::definition{label="浆液腺泡"}
浆液腺泡由浆液细胞围成。核圆、偏基底，基底胞质强嗜碱性，顶部含嗜酸性酶原颗粒。大唾液腺中的浆液分泌物含唾液淀粉酶。第 2 章已把浆液细胞的超微账写在粗面内质网和高尔基复合体上。
:::

:::definition{label="黏液腺泡"}
黏液腺泡由黏液细胞围成。核扁圆、居基底，大部分胞质几乎不着色、呈泡沫或空泡状，含粗大黏原颗粒。分泌物以黏液为主，润滑口腔和食物。
:::

:::definition{label="混合腺泡"}
混合腺泡由浆液细胞和黏液细胞共同组成。大部分混合腺泡以黏液细胞为主体，少量浆液细胞位于腺泡底部，切片上呈半月形，称浆半月（serous demilune）。图 15-1 箭头所示即浆半月。
:::

:::definition{label="肌上皮细胞"}
肌上皮细胞位于腺细胞和部分导管上皮细胞与基膜之间，收缩有助于分泌物排出。大唾液腺有肌上皮；后文胰腺腺泡没有，不要把两本收缩账并成一句。
:::

:::concept{term="先问这一泡是浆液、黏液还是混合，再问有没有浆半月"}
切片上先认腺泡类型：胞质嗜酸、核圆偏底的是浆液；泡沫空泡、核扁贴底的是黏液；一泡里两种都有、底部那弯嗜酸帽子是浆半月。腺泡类型决定产物（酶还是黏液），还没轮到导管。把三种腺泡听成“三种腺体”，腮腺、下颌下腺、舌下腺的整腺账会从第一眼错位。
:::

:::note{label="腺泡类型与整腺类型不是同一把尺子"}
| 尺子 | 划分 | 例子 |
|------|------|------|
| 单个腺泡 | 浆液腺泡、黏液腺泡、混合腺泡 | 下颌下腺切片上三种都可见（图 15-1） |
| 整腺 | 纯浆液腺、混合腺 | 腮腺为纯浆液腺；下颌下腺、舌下腺为混合腺 |
:::

导管通常包括闰管、纹状管、小叶间导管和总导管。

:::definition{label="大唾液腺导管四级"}
大唾液腺导管通常包括闰管、纹状管、小叶间导管和总导管。起于腺泡的细起始段是闰管，接到纹状管后出小叶，再汇成小叶间导管和总导管，开口于口腔。
:::

### 1. 闰管

闰管（intercalated duct）是导管的起始部，直接与腺泡相连，管径细，管壁为单层扁平或立方上皮。

:::definition{label="闰管"}
闰管（intercalated duct）是导管的起始部，直接与腺泡相连。管径细，管壁为单层扁平或立方上皮。腮腺闰管长，下颌下腺闰管短，舌下腺无闰管。
:::

### 2. 纹状管

纹状管（striated duct）又称分泌管（secretory duct），与闰管相连，管壁为单层高柱状上皮，核圆，位于细胞顶部，细胞质嗜酸性。细胞基部可见垂直纵纹，电镜下为质膜内褶和纵行排列的线粒体，此种结构使细胞基部表面积增大，便于细胞与组织液之间进行水和电解质的转运。

:::definition{label="纹状管"}
纹状管（striated duct）又称分泌管（secretory duct），与闰管相连。管壁为单层高柱状上皮，核圆、位于细胞顶部，胞质嗜酸性。细胞基部可见垂直纵纹。
:::

:::definition{label="纹状管基部纵纹"}
纹状管基部的垂直纵纹，电镜下为质膜内褶和纵行排列的线粒体。此种结构使细胞基部表面积增大，便于细胞与组织液之间进行水和电解质的转运。所以它又叫分泌管：转运的是水和电解质，不是再造一泡酶原颗粒。
:::

:::pitfall{label="纹状管的“纹”在基部质膜内褶，不要写成腺泡顶部的酶原颗粒"}
光镜下纹状管胞质嗜酸、核被挤到顶部，容易看成“又一个浆液腺泡”。身份证件在基部纵纹：质膜内褶加纵行线粒体，职分是转运水和电解质。酶原颗粒在腺泡细胞顶部；闰管是细的单层扁平或立方起始段，没有这排纵纹。
:::

:::insight{label="纹状管把唾液的水和盐改写一遍，不是单纯的排水管"}
闰管只是细起始段。纹状管基部表面积加大，和肾近端小管那种质膜内褶是同一类转运结构。唾液最后的水分和电解质组成，有一笔账要记在这节分泌管上。把导管听成“只管往外倒”，下颌下腺“纹状管发达”就变成一句空话。
:::

### 3. 小叶间导管和总导管

纹状管汇合形成小叶间导管，行走于小叶间结缔组织内。小叶间导管较粗，初为单层柱状上皮，以后移行为假复层柱状上皮。小叶间导管逐级汇合，最后形成一条或几条总导管开口于口腔。

:::definition{label="小叶间导管"}
小叶间导管由纹状管汇合形成，行走于小叶间结缔组织内。较粗，上皮初为单层柱状，以后移行为假复层柱状上皮。
:::

:::definition{label="总导管"}
小叶间导管逐级汇合，最后形成一条或几条总导管，开口于口腔。
:::

:::compare{title="大唾液腺导管四级"}
| 节段 | 英文 | 上皮 | 要点 |
|------|------|------|------|
| 闰管 | intercalated duct | 单层扁平或立方 | 起始部，直接连腺泡，管径细 |
| 纹状管（分泌管） | striated duct (secretory duct) | 单层高柱状；核居顶部，胞质嗜酸 | 基部纵纹 = 质膜内褶 + 纵行线粒体，转运水和电解质 |
| 小叶间导管 | — | 初单层柱状，后假复层柱状 | 走小叶间结缔组织 |
| 总导管 | — | 假复层柱状延续 | 一条或几条，开口于口腔 |
:::

## （二）3 种大唾液腺的结构特点

### 1. 腮腺

腮腺（parotid gland）为纯浆液腺，闰管长，纹状管较短，分泌物含唾液淀粉酶。

:::definition{label="腮腺"}
腮腺（parotid gland）为纯浆液腺，闰管长，纹状管较短，分泌物含唾液淀粉酶。切片上应几乎全是浆液腺泡，不要去找黏液空泡来“凑混合腺”。
:::

### 2. 下颌下腺

下颌下腺（submandibular gland）为混合腺，浆液腺泡多，黏液腺泡和混合腺泡少。闰管短，纹状管发达（图 15-1）。分泌物含唾液淀粉酶和黏液。

:::definition{label="下颌下腺"}
下颌下腺（submandibular gland）为混合腺，浆液腺泡多，黏液腺泡和混合腺泡少。闰管短，纹状管发达。分泌物含唾液淀粉酶和黏液。
:::

::figure{src="/images/histology/textbook/p0174_02.png" caption="图15-1 下颌下腺光镜图。1. 黏液腺泡；2. 浆液腺泡；3. 混合腺泡；4. 纹状管；↑浆半月。" alt="下颌下腺HE切片：黏液腺泡呈空泡状，浆液腺泡嗜酸，混合腺泡底部见浆半月，左下为纹状管"}

### 3. 舌下腺

舌下腺（sublingual gland）为混合腺，以黏液腺泡为主，也多见混合腺泡，无闰管，纹状管也较短。分泌物以黏液为主。

:::definition{label="舌下腺"}
舌下腺（sublingual gland）为混合腺，以黏液腺泡为主，也多见混合腺泡，无闰管，纹状管也较短。分泌物以黏液为主。
:::

:::compare{title="三大唾液腺"}
| 项目 | 腮腺 | 下颌下腺 | 舌下腺 |
|------|------|----------|--------|
| 英文 | parotid gland | submandibular gland | sublingual gland |
| 腺类型 | 纯浆液腺 | 混合腺 | 混合腺 |
| 腺泡组成 | 几乎全是浆液腺泡 | 浆液腺泡多，黏液腺泡和混合腺泡少 | 以黏液腺泡为主，也多见混合腺泡 |
| 闰管 | 长 | 短 | 无 |
| 纹状管 | 较短 | 发达 | 较短 |
| 分泌物 | 含唾液淀粉酶 | 含唾液淀粉酶和黏液 | 以黏液为主 |
| 光镜第一眼 | 清一色嗜酸腺泡 | 三种腺泡 + 发达纹状管（图 15-1） | 泡沫状黏液腺泡占优 |
:::

:::pitfall{label="下颌下腺和舌下腺都是混合腺，不要写成同一种腺泡比例"}
两腺都叫混合腺，比例相反：下颌下腺浆液多、纹状管发达，产物里淀粉酶和黏液都有；舌下腺黏液为主、无闰管，产物以黏液为主。把“混合腺”听成“一半对一半”，三对大唾液腺的鉴别表会并成一行。腮腺才是纯浆液腺。
:::

:::concept{term="先问闰管长不长、纹状管发不发达，再给这枚腺贴名"}
三对大唾液腺不是靠“在嘴巴哪一侧”来认切片。腮腺：纯浆液 + 闰管长 + 纹状管较短。下颌下腺：浆液多的混合腺 + 闰管短 + 纹状管发达。舌下腺：黏液为主的混合腺 + 无闰管。导管长度和腺泡比例是身份证，位置是解剖学标签。
:::

唾液由大、小唾液腺分泌的混合液组成，$95\%$ 以上来自 3 对大唾液腺。唾液中的水分和黏液起润滑口腔作用，唾液淀粉酶可使食物中的淀粉分解为麦芽糖。唾液中某些成分具有一定的防御作用，如溶菌酶和干扰素，能抵抗细菌和病毒的侵入。另外，唾液腺间质内有浆细胞，分泌的 IgA 与腺细胞产生的蛋白质分泌片结合，形成 sIgA，随唾液排入口腔，具有免疫作用。下颌下腺还分泌许多生物活性多肽，对多种组织和细胞的生理活动起重要调节作用，如表皮生长因子，可促进口腔上皮的增殖与创伤修复。

:::definition{label="唾液"}
唾液由大、小唾液腺分泌的混合液组成，$95\%$ 以上来自 3 对大唾液腺。水分和黏液润滑口腔；唾液淀粉酶使淀粉分解为麦芽糖；溶菌酶和干扰素抵抗细菌和病毒。
:::

:::definition{label="唾液淀粉酶"}
唾液淀粉酶主要由浆液性分泌提供，使食物中的淀粉分解为麦芽糖。化学消化从口腔就开始，不完全等到胰淀粉酶。
:::

:::definition{label="sIgA（唾液）"}
唾液腺间质内有浆细胞，分泌的 IgA 与腺细胞产生的蛋白质分泌片结合，形成 sIgA，随唾液排入口腔，具有免疫作用。这是黏膜免疫在口腔的落点，不是腺泡自己改写成了浆细胞。
:::

:::definition{label="下颌下腺的表皮生长因子"}
下颌下腺还分泌许多生物活性多肽，对多种组织和细胞的生理活动起重要调节作用。表皮生长因子可促进口腔上皮的增殖与创伤修复。第 11 章插入框的 EGF 最初就是从颌下腺分离的。
:::

:::insight{label="唾液不只是润嗓子：消化、杀菌和 sIgA 写在同一口液体里"}
水分和黏液管润滑；淀粉酶管麦芽糖；溶菌酶、干扰素管入侵微生物；间质浆细胞把 IgA 交给腺细胞的分泌片，做成 sIgA 再排入口腔。下颌下腺额外交出表皮生长因子。把唾液听成“清水加黏液”，免疫和修复两本账会从口腔这一站漏掉。
:::

:::pitfall{label="sIgA 是浆细胞的 IgA 加上腺细胞的分泌片，不要写成腺泡直接分泌抗体"}
间质里的浆细胞造 IgA；腺细胞提供蛋白质分泌片；二者结合才成 sIgA。腺泡的本职仍是酶和黏液。把抗体账写进浆液细胞的酶原颗粒，第 3 章浆细胞和第 10 章黏膜免疫会一起错位。
:::

:::keypoint{label="大唾液腺先立三种腺泡和四级导管，再记三对腺体的差别"}
- 消化腺 = 大消化腺（3 对大唾液腺、胰、肝）+ 管壁内小消化腺；大消化腺经导管排入消化管，胰还有内分泌。
- 大唾液腺均为复管泡状腺；腺泡分浆液、黏液、混合 3 类；腺细胞与基膜之间有肌上皮。
- 导管：闰管（单层扁平或立方）→ 纹状管（单层高柱状，基部纵纹转运水和电解质）→ 小叶间导管（单层柱状→假复层柱状）→ 总导管开口于口腔。
- 腮腺纯浆液，闰管长、纹状管较短，含唾液淀粉酶。
- 下颌下腺混合、浆液多，闰管短、纹状管发达，含淀粉酶和黏液；光镜可见浆半月（图 15-1）。
- 舌下腺混合、黏液为主，无闰管，纹状管较短，分泌物以黏液为主。
- 唾液 $95\%$ 以上来自大唾液腺：润滑、淀粉→麦芽糖、溶菌酶和干扰素、sIgA；下颌下腺还分泌表皮生长因子。

:::memory{label="本节必背要点"}
- [ ] 消化腺（digestive gland）包括大消化腺（3 对大唾液腺、胰腺和肝）及消化管壁内的许多小消化腺（口腔内小唾液腺、食管腺、胃腺和肠腺等）。
- [ ] 大消化腺由腺细胞组成的分泌部、导管和间质组成，分泌物经导管排入消化管，对食物进行化学消化；胰腺还有内分泌功能。
- [ ] 大唾液腺有腮腺、下颌下腺、舌下腺各一对，分泌的唾液经导管排入口腔。
- [ ] 大唾液腺均为复管泡状腺，被膜较薄；被膜伸入的结缔组织将实质分隔为大小不等的小叶，血管、淋巴管和神经随同走行并进入小叶内。
- [ ] 腺实质由分支的导管及末端的腺泡组成；腺泡分浆液腺泡、黏液腺泡与混合腺泡 3 类。
- [ ] 腺细胞和部分导管上皮细胞与基膜之间有肌上皮细胞，收缩有助于分泌物排出。
- [ ] 导管通常包括闰管、纹状管、小叶间导管和总导管。
- [ ] 闰管（intercalated duct）是导管起始部，直接与腺泡相连，管径细，管壁为单层扁平或立方上皮。
- [ ] 纹状管（striated duct）又称分泌管（secretory duct），与闰管相连，管壁为单层高柱状上皮，核圆、位于细胞顶部，胞质嗜酸性。
- [ ] 纹状管细胞基部可见垂直纵纹，电镜下为质膜内褶和纵行排列的线粒体，增大基部表面积，便于与组织液之间进行水和电解质转运。
- [ ] 纹状管汇合形成小叶间导管，行走于小叶间结缔组织内；小叶间导管较粗，初为单层柱状上皮，以后移行为假复层柱状上皮。
- [ ] 小叶间导管逐级汇合，最后形成一条或几条总导管开口于口腔。
- [ ] 腮腺（parotid gland）为纯浆液腺，闰管长，纹状管较短，分泌物含唾液淀粉酶。
- [ ] 下颌下腺（submandibular gland）为混合腺，浆液腺泡多，黏液腺泡和混合腺泡少；闰管短，纹状管发达；分泌物含唾液淀粉酶和黏液。
- [ ] 舌下腺（sublingual gland）为混合腺，以黏液腺泡为主，也多见混合腺泡；无闰管，纹状管也较短；分泌物以黏液为主。
- [ ] 混合腺泡底部的浆液细胞在切片中呈半月形，称浆半月。
- [ ] 唾液由大、小唾液腺分泌的混合液组成，$95\%$ 以上来自 3 对大唾液腺。
- [ ] 唾液中的水分和黏液起润滑口腔作用；唾液淀粉酶可使食物中的淀粉分解为麦芽糖。
- [ ] 唾液中溶菌酶和干扰素能抵抗细菌和病毒的侵入。
- [ ] 唾液腺间质内浆细胞分泌的 IgA 与腺细胞产生的蛋白质分泌片结合，形成 sIgA，随唾液排入口腔，具有免疫作用。
- [ ] 下颌下腺还分泌许多生物活性多肽，如表皮生长因子，可促进口腔上皮的增殖与创伤修复。
