# 二、真皮

真皮（dermis）是位于表皮下方的致密结缔组织，分为乳头层和网织层，二者间无明确界限（见图 11-1）。身体各部真皮的厚度不等，一般为 $1\sim 2\,\mathrm{mm}$。上一节表皮自身没有血管，营养从本节乳头层的毛细血管渗上去；网织层则把韧性和弹性写成粗胶原束和弹性纤维。皮纹、指纹和皮下组织随真皮一并交代。

:::definition{label="真皮"}
真皮（dermis）是位于表皮下方的致密结缔组织，分为乳头层和网织层，二者间无明确界限。身体各部厚度不等，一般为 $1\sim 2\,\mathrm{mm}$。
:::

:::concept{term="先问靠上还是靠下：乳头层，还是网织层"}
真皮不是“表皮下面的一团纤维”一句话能打发。紧贴表皮的薄层向表皮突出成乳头，叫乳头层，管连接面积和营养；乳头层下方更厚、胶原束交织成网，叫网织层，管韧性和弹性。两层没有一条画得清的界线，考试却要按乳头和纤维粗细分开写。把真皮听成单层致密结缔组织，触觉小体、环层小体和皮纹都会失去层次落点。
:::

:::compare{title="表皮与真皮"}
| 项目 | 表皮 | 真皮 |
|------|------|------|
| 英文 | epidermis | dermis |
| 组织 | 角化的复层扁平上皮 | 致密结缔组织 |
| 分层 | 基底层至角质层（厚皮五层） | 乳头层、网织层（无明确界限） |
| 厚度 | 随厚皮/薄皮差异大 | 各部不等，一般 $1\sim 2\,\mathrm{mm}$ |
| 血管 | 无 | 乳头层毛细血管丰富；网织层血管、淋巴管较多 |
| 神经末梢 | 梅克尔细胞–轴突复合体在基底层 | 乳头层触觉小体；网织层深部环层小体 |
| 营养关系 | 从真皮组织液获得营养 | 自身有血管；并供养表皮 |
:::

:::pitfall{label="乳头层和网织层没有明确界限，不要在切片上找一条“真皮内弹性膜”"}
教材写明二者间无明确界限。分界靠的是位置和纤维：紧贴表皮、形成乳头、纤维较细的是乳头层；其下胶原束粗大交织、弹性纤维多的是网织层。不要把真皮套成血管那种内膜–中膜，也不要因为看不清界线就把两层并成一层。
:::

## 1. 乳头层

乳头层（papillary layer）是紧靠表皮薄层较致密的结缔组织，向表皮突出形成乳头状（见图 11-2），故称真皮乳头（dermal papilla），此种结构使表皮与真皮的连接面扩大，连接更加牢固。由于内含丰富的毛细血管，有利于表皮从真皮组织液中获得营养。手指掌侧的真皮乳头内含较多触觉小体。

:::definition{label="乳头层"}
乳头层（papillary layer）是紧靠表皮的薄层较致密结缔组织，向表皮突出形成乳头状，称真皮乳头。使表皮与真皮连接面扩大、连接更牢固；内含丰富毛细血管，利于表皮从真皮组织液中获得营养。
:::

:::definition{label="真皮乳头"}
真皮乳头（dermal papilla）是乳头层向表皮突出的乳头状结构。手指掌侧的真皮乳头内含较多触觉小体。
:::

:::note{label="真皮乳头里要记的三件事"}
| 结构 | 职分 |
|------|------|
| 乳头状突入表皮 | 扩大连接面积，锚住无血管的表皮 |
| 丰富的毛细血管 | 向表皮提供组织液营养 |
| 触觉小体（掌侧手指尤其多） | 精细触觉；与上一章神经末梢账相接 |
:::

:::insight{label="表皮的半桥粒钉在基膜上，基膜下面就是这排乳头"}
没有乳头，表皮与真皮的交界面是平的，剪切时容易整张揭开；有了乳头，交界面变成锯齿，连接牢固，毛细血管也跟着送进每一个齿尖。手掌切片上那些伸进表皮底部的浅染结缔组织突，就是乳头，不要当成上皮钉突长反了方向。
:::

:::pitfall{label="真皮乳头不是毛乳头，不要把两套“乳头”写成一个"}
真皮乳头是乳头层向表皮的突入，普遍存在于有表皮覆盖的皮肤。毛乳头是结缔组织突入毛球底面的结构，专管毛的诱导和营养。下一节附属器会单独写毛乳头。把掌跖切片里的真皮乳头写成“毛乳头”，手掌无毛那一本账会当场打架。
:::

::figure{src="/images/histology/textbook/p0130_01.png" caption="图11-2 皮肤分层光镜图。1. 角质层；2. 透明层；3. 颗粒层；4. 棘层；5. 基底层；6. 真皮乳头；7. 毛细血管。" alt="真皮乳头嵌入表皮基底侧，乳头内可见毛细血管"}

## 2. 网织层

网织层（reticular layer）为乳头层下方较厚的致密结缔组织，内有粗大的胶原纤维束交织成网（见图 11-1），并有许多弹性纤维，赋予皮肤较大的韧性和弹性。此层内还有较多血管、淋巴管和神经，深部常见环层小体（见图 7-29）。

:::definition{label="网织层"}
网织层（reticular layer）是乳头层下方较厚的致密结缔组织。粗大胶原纤维束交织成网，并有许多弹性纤维，赋予皮肤较大的韧性和弹性。内有较多血管、淋巴管和神经，深部常见环层小体。
:::

:::compare{title="乳头层与网织层"}
| 项目 | 乳头层 | 网织层 |
|------|--------|--------|
| 英文 | papillary layer | reticular layer |
| 位置 | 紧靠表皮 | 乳头层下方 |
| 厚度 | 薄 | 较厚，构成真皮主体 |
| 纤维 | 较致密的细纤维结缔组织 | 粗大胶原纤维束交织成网，弹性纤维多 |
| 与表皮的关系 | 形成真皮乳头，扩大连接面 | 不直接形成乳头 |
| 血管 | 丰富的毛细血管，供养表皮 | 较多血管、淋巴管 |
| 神经末梢 | 手指掌侧较多触觉小体 | 深部常见环层小体 |
| 功能侧重 | 连接牢固 + 营养表皮 + 精细触觉 | 韧性、弹性；深压觉 |
| 分界 | 二者间无明确界限 | 同左 |
:::

:::pitfall{label="网织层的“网”是粗胶原束交织，不是网状纤维构成的网状组织"}
网状组织是Ⅲ型胶原构成的网状纤维加网状细胞，出现在淋巴组织和骨髓。真皮网织层是致密结缔组织，主角是粗大的Ⅰ型胶原纤维束加弹性纤维。把“网织”听成“网状”，会把皮肤真皮写成淋巴结的支架。
:::

:::insight{label="触觉小体在乳头，环层小体在网织层深部，两套末梢不要换层"}
精细触觉要靠近表皮，所以触觉小体塞进真皮乳头；深压觉和振动要埋在深处，所以环层小体出现在网织层深部（见图 7-29）。切片上乳头里那团横核的椭圆形结构，和深部洋葱样小体，不是同一种末梢换了放大倍数。
:::

皮肤表面并非平坦，而是有嵴、沟相间形成的皮纹（见图 11-1）。在一条嵴内，一般有两列真皮乳头，在沟底有汗腺的开口。在手掌和足底，由于表皮很厚，皮纹格外明显，这有助于增加手足与接触物的摩擦力。在指（趾）末端，皮纹受到指（趾）甲的阻断，形成回旋，便呈现箕、斗、弓等形状，在手指称指纹（finger print）。每个人的指纹均不相同，即使单卵双胎的二人也是如此，这是因为在胚胎发育时期，受局部微环境的影响，相同基因的表型出现差异所致。因此，指纹成为辨别个体的一种标志。

:::definition{label="皮纹"}
皮纹是皮肤表面嵴与沟相间形成的纹路。一条嵴内一般有两列真皮乳头，沟底有汗腺开口。手掌和足底因表皮很厚，皮纹格外明显，有助于增加手足与接触物的摩擦力。
:::

:::definition{label="指纹"}
指纹（finger print）是指（趾）末端皮纹受指（趾）甲阻断、回旋而成的箕、斗、弓等形状。每个人的指纹均不相同，即使单卵双胎二人也是如此：胚胎发育时局部微环境使相同基因的表型出现差异。因而指纹成为辨别个体的一种标志。
:::

:::concept{term="先问嵴里有几列乳头，沟底开的是什么口"}
皮纹不是表皮自己皱出来的花纹，底下是真皮乳头在排队：一条嵴大约两列乳头，汗孔开在沟底。掌跖表皮厚，纹就清楚，摩擦也够。指端被甲板挡住，嵴回旋成箕、斗、弓，才叫指纹。把指纹只背成“基因决定、终身不变”，会漏掉微环境造成单卵双胎也不同这一笔；把汗孔画在嵴顶，又和沟底开口对着干。
:::

:::pitfall{label="单卵双胎指纹也可以不同，不要把指纹写成“纯基因型身份证”"}
教材把差异归因于胚胎局部微环境导致的表型差别，即使基因型相同也可以走出不同回旋。指纹能辨别个体，依据是表型独特，不是“基因序列一一对应某一种箕斗弓”。
:::

在真皮下方为皮下组织（subcutaneous tissue），即解剖学所称的浅筋膜，由疏松结缔组织和脂肪组织构成，将皮肤与深部组织相连（见图 11-1），并使皮肤具有一定的活动性。皮下组织还具有缓冲、保温、能量贮存等作用，其中的脂肪组织在不同个体、性别、年龄和同一个体的不同部位，有较大的量的差别。

:::definition{label="皮下组织"}
皮下组织（subcutaneous tissue）即解剖学所称的浅筋膜，位于真皮下方，由疏松结缔组织和脂肪组织构成。将皮肤与深部组织相连，使皮肤具有一定活动性；并具有缓冲、保温、能量贮存等作用。脂肪组织的量因个体、性别、年龄和部位而有较大差别。
:::

:::compare{title="真皮与皮下组织"}
| 项目 | 真皮 | 皮下组织 |
|------|------|----------|
| 解剖学名称 | 皮肤的深层 | 浅筋膜 |
| 是否属皮肤 | 是 | 否，只是把皮肤连到深层 |
| 组织 | 致密结缔组织（乳头层 + 网织层） | 疏松结缔组织 + 脂肪组织 |
| 纤维 | 乳头层较细；网织层粗胶原束交织、弹性纤维多 | 疏松，纤维不形成真皮那种致密网 |
| 功能 | 连接表皮、营养表皮、韧性与弹性、感觉末梢 | 连接、活动性、缓冲、保温、贮能 |
| 厚度/量的变异 | 各部真皮一般 $1\sim 2\,\mathrm{mm}$ | 脂肪量个体、性别、年龄、部位差别大 |
:::

:::pitfall{label="皮下组织不是皮肤的第三层"}
第一节把皮肤写成表皮加真皮。皮下组织是浅筋膜，功能是连接、缓冲、保温和贮能，脂肪量可以差很多，但不能据此说“皮肤分三层”。手掌切片最底部的脂肪小叶（图 11-1 之 6）是皮下组织，不是网织层的一部分。
:::

:::insight{label="表皮无血管、真皮供营养、皮下贮能量，三层账不要并成“皮肤都很厚”"}
掌跖看起来厚，厚的是表皮角质层；真皮一般也就是 $1\sim 2\,\mathrm{mm}$；再往下的厚薄往往是脂肪。描述“某部位皮肤厚”，先问厚在角质层、真皮还是皮下脂肪，否则保温、摩擦和静脉穿刺深度会写到错误的层次上。
:::

:::keypoint{label="真皮先分乳头层和网织层，再写下皮纹和皮下组织"}
- 真皮是表皮下方的致密结缔组织，一般厚 $1\sim 2\,\mathrm{mm}$，分乳头层与网织层，二者无明确界限。
- 乳头层薄，形成真皮乳头：扩大连接面，毛细血管营养表皮，掌侧手指含触觉小体。
- 网织层厚，粗胶原束交织加弹性纤维，赋予韧性和弹性；含血管、淋巴管、神经，深部常见环层小体。
- 皮纹 = 嵴 + 沟；嵴内一般两列乳头，沟底为汗腺开口；掌跖最明显。指纹因甲阻断而回旋，单卵双胎亦可不同。
- 皮下组织即浅筋膜，疏松结缔组织 + 脂肪，不属于皮肤本体。
:::
