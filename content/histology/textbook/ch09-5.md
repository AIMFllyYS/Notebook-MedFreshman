# 五、微循环

微循环（microcirculation）指从微动脉到微静脉之间的血液循环，是血液循环和物质交换的基本结构和功能单位，是心血管系统在组织内真正起作用的部位。其功能主要是运输氧、二氧化碳、营养物质、代谢产物、生物活性物质如激素等成分；还可随局部组织代谢变化而调整血流量，并通过局部自我调整而稳定血流和血压；由于毛细血管内的静水压及胶体渗透压差异，此处还可调节组织及血液内的含水量。因此，微循环功能状态是否正常，对机体内环境稳态的影响很大。

不同组织的微循环血管组成各有特点，但一般都由下述几部分组成（图 9-15）。

微循环（microcirculation）指从微动脉到微静脉之间的血液循环，是血液循环和物质交换的基本结构和功能单位，是心血管系统在组织内真正起作用的部位。功能状态是否正常，对机体内环境稳态的影响很大。

:::concept{term="先问血从哪进、从哪出，中间走的是哪一条通路"}
微循环不是“毛细血管的别名”。入口是微动脉（总闸门），出口是微静脉。中间至少要能数出三条路：真毛细血管构成的迂回通路（交换主路）、通血毛细血管构成的直捷通路（休息时大部分血走这里回心）、动静脉吻合构成的动-静脉短路（皮肤等处调节局部血流量）。先问这一滴血走的是哪条，再问闸门开没开。把微循环听成“全是真毛细血管”，直捷通路和动静脉吻合会从教材里消失。
:::

## 1. 微动脉

其平滑肌纤维的舒缩是控制微循环血流量的总闸门。

:::definition{label="微循环的微动脉"}
微动脉平滑肌纤维的舒缩是控制微循环血流量的总闸门。管壁结构见第二节：管径一般小于 $0.3\,\mathrm{mm}$，中膜 $1\sim 2$ 层平滑肌，无内、外弹性膜。
:::

## 2. 中间微动脉

中间微动脉（metaarteriole）是微动脉的分支，又称后微动脉，由内皮和一层不连续的平滑肌纤维构成，其平滑肌纤维舒缩可调节进入毛细血管的血流量。

:::definition{label="中间微动脉"}
中间微动脉（metaarteriole）是微动脉的分支，又称后微动脉。由内皮和一层不连续的平滑肌纤维构成，其舒缩可调节进入毛细血管的血流量。
:::

## 3. 真毛细血管

真毛细血管（true capillary）指中间微动脉分支形成的相互吻合成网的毛细血管，即通称的毛细血管。真毛细血管网的行程迂回曲折，构成迂回通路（circuitous channel），此处的血流缓慢，是物质交换的主要部位。生理状态下，约 $20\%$ 的真毛细血管处于轮流开放状态。在真毛细血管的起始端通常有 $1\sim 2$ 个平滑肌纤维，形成环行的毛细血管前括约肌（precapillary sphincter），是调节微循环血流量的分闸门。当组织处于功能活跃状态时，毛细血管前括约肌舒张，大部分血液流经真毛细血管网进行充分的物质交换。

:::definition{label="真毛细血管"}
真毛细血管（true capillary）指中间微动脉分支形成的相互吻合成网的毛细血管，即通称的毛细血管。行程迂回曲折，构成迂回通路（circuitous channel），血流缓慢，是物质交换的主要部位。生理状态下约 $20\%$ 处于轮流开放状态。
:::

:::definition{label="迂回通路"}
迂回通路（circuitous channel）由真毛细血管网构成。行程迂回曲折，血流缓慢，是物质交换的主要部位。
:::

:::definition{label="毛细血管前括约肌"}
毛细血管前括约肌（precapillary sphincter）位于真毛细血管起始端，通常由 $1\sim 2$ 个平滑肌纤维形成环行结构，是调节微循环血流量的分闸门。组织功能活跃时舒张，使大部分血液流经真毛细血管网。
:::

## 4. 通血毛细血管

通血毛细血管（thoroughfare capillary）是中间微动脉直接延伸而与微静脉相通、距离最短的毛细血管，构成直捷通路（thoroughfare channel），其管径比真毛细血管略粗。生理状态下，大部分血液通过此通路回流入心。

:::definition{label="通血毛细血管"}
通血毛细血管（thoroughfare capillary）是中间微动脉直接延伸而与微静脉相通、距离最短的毛细血管，管径比真毛细血管略粗，构成直捷通路。
:::

:::definition{label="直捷通路"}
直捷通路（thoroughfare channel）由通血毛细血管构成：中间微动脉直接延伸至微静脉，距离最短。生理状态下，大部分血液通过此通路回流入心。
:::

## 5. 动静脉吻合

动静脉吻合（arteriovenous anastomosis）指微动脉发出侧支并直接与微静脉相通的血管，构成动-静脉短路（arteriovenous shunt）。此段血管的管壁较厚，管腔较小，含丰富的纵行平滑肌纤维和调控血管运动的神经末梢。动静脉吻合血管收缩时，血液由微动脉流入毛细血管；动静脉吻合血管舒张时，微动脉血液经此直接流入微静脉。动静脉吻合血管主要分布于指、趾、耳、唇和鼻等处的皮肤，是调节局部组织血流量的重要结构。

:::definition{label="动静脉吻合"}
动静脉吻合（arteriovenous anastomosis）是微动脉发出侧支并直接与微静脉相通的血管，构成动-静脉短路（arteriovenous shunt）。管壁较厚、管腔较小，含丰富纵行平滑肌和调控血管运动的神经末梢。主要分布于指、趾、耳、唇和鼻等处的皮肤，调节局部组织血流量。
:::

:::definition{label="动-静脉短路"}
动-静脉短路（arteriovenous shunt）即动静脉吻合所构成的通路。吻合血管收缩时，血液由微动脉流入毛细血管；舒张时，微动脉血液经此直接流入微静脉。
:::

## 6. 微静脉

见“静脉”部分。

:::definition{label="微循环的微静脉"}
微静脉是微循环的出口，结构见第四节：管径一般为 $50\sim 200\,\mu\mathrm{m}$，内皮间隙较大，通透性大。
:::

:::compare{title="微循环的三条通路"}
| 项目 | 迂回通路 | 直捷通路 | 动-静脉短路 |
|------|----------|----------|--------------|
| 英文 | circuitous channel | thoroughfare channel | arteriovenous shunt |
| 构成血管 | 真毛细血管网 | 通血毛细血管 | 动静脉吻合 |
| 走行 | 中间微动脉分支，行程迂回曲折 | 中间微动脉直接延伸至微静脉，距离最短 | 微动脉侧支直接连微静脉 |
| 管径与壁 | 最细；起始端有毛细血管前括约肌 | 比真毛细血管略粗 | 壁较厚、腔较小，富含纵行平滑肌和神经末梢 |
| 血流 | 缓慢 | 生理状态下大部分血液经此回心 | 舒张时动脉血直接入微静脉 |
| 主要职分 | 物质交换的主要部位 | 使部分血液迅速回心 | 调节局部血流量（指、趾、耳、唇、鼻皮肤） |
| 闸门 | 分闸门：毛细血管前括约肌；生理状态约 $20\%$ 轮流开放 | 受中间微动脉平滑肌影响 | 吻合段自身平滑肌舒缩 |
:::

:::pitfall{label="直捷通路不是营养交换的主路，生理状态下大部分血却走这里"}
物质交换写在迂回通路：真毛细血管网曲折、血流慢，组织活跃时前括约肌打开，血才大量涌进网里交换。直捷通路距离最短、管径略粗，休息时大部分血液经此回心，并不在此充分交换。动-静脉短路更是把毛细血管整段绕开。把“微循环 = 全部拿来换物质”，或把直捷通路写成“交换最快的毛细血管”，三条通路的职分会并成一句。
:::

:::pitfall{label="总闸门是微动脉，分闸门是毛细血管前括约肌，不要对调"}
进微循环的总开关在微动脉平滑肌。每一根真毛细血管起点上那 $1\sim 2$ 个环行平滑肌才是分闸门。中间微动脉的一层不连续平滑肌调节进入毛细血管的血量，但教材没有把它叫总闸门。把前括约肌写成总闸门，或把动静脉吻合当成总开关，局部血流量账会写错层级。
:::

:::cause-effect{title="组织活跃时前括约肌怎样把血流从直捷通路改写到迂回通路"}
- 因：组织功能活跃，毛细血管前括约肌舒张
- 果：大部分血液流经真毛细血管网（迂回通路），血流缓慢，充分物质交换
- 制约：生理安静时约 $20\%$ 真毛细血管轮流开放，大部分血液走直捷通路回心；皮肤等处还可用动静脉吻合改写局部血流量
:::

:::insight{label="微循环同时管运输、血流量和含水量"}
教材给微循环写了三本功能账：运氧、二氧化碳、营养、代谢产物和激素；随局部代谢调整血流量并稳定血压；靠静水压和胶体渗透压差调节组织与血液的含水量。总闸门和分闸门管的是流量，三条通路管的是血往哪走，毛细血管壁管的是物质和水分过不过得去。内环境稳态是否守得住，看这三本账有没有同时在工作，而不是只问“毛细血管在不在”。
:::

:::note{label="图中的毛细血管前微动脉就是中间微动脉那一段"}
图 9-15 在微动脉下游标出毛细血管前微动脉和中间微动脉。教材正文把中间微动脉（metaarteriole）又称后微动脉，由内皮加一层不连续平滑肌构成。读图时把它和真毛细血管起点的前括约肌分开：前者是一段管子，后者是环行的 $1\sim 2$ 个平滑肌。
:::

:::keypoint{label="微循环先立总闸门和分闸门，再立三条通路"}
- 微循环 = 微动脉到微静脉之间的血液循环，是交换的基本单位。
- 总闸门：微动脉；分闸门：真毛细血管起始端的毛细血管前括约肌（$1\sim 2$ 个平滑肌）。
- 中间微动脉（后微动脉）：内皮 + 一层不连续平滑肌。
- 迂回通路：真毛细血管网，血流慢，交换主路；安静时约 $20\%$ 轮流开放。
- 直捷通路：通血毛细血管，距离最短，生理状态下大部分血液经此回心。
- 动-静脉短路：动静脉吻合，皮肤（指、趾、耳、唇、鼻）调节局部血流量。
:::
