# 二、小脑皮质

小脑皮质的神经元包括浦肯野细胞（Purkinje cell）、颗粒细胞、星形细胞、篮状细胞和高尔基细胞 5 种，其中浦肯野细胞是唯一的传出神经元。小脑皮质由表及里呈现明显的 3 层（图 8-6～图 8-8）。上一节大脑皮质用六层把传入、局部环路和传出摊开；小脑把这本账收成三层，但回路并不简单：颗粒细胞的平行纤维可以在一颗浦肯野细胞的扇形树突上写出几十万个突触，攀缘纤维和苔藓纤维再从延髓、脊髓和脑干把兴奋送进来。

:::definition{label="小脑皮质神经元"}
小脑皮质的神经元有 5 种：浦肯野细胞（Purkinje cell）、颗粒细胞、星形细胞、篮状细胞和高尔基细胞。其中浦肯野细胞是唯一的传出神经元，其余均为中间神经元。
:::

:::definition{label="小脑皮质三层"}
小脑皮质由表及里分为分子层、浦肯野细胞层和颗粒层。分子层纤维多、细胞少；浦肯野细胞层是单层梨形胞体；颗粒层细胞极密。
:::

:::concept{term="先问谁能走出皮质：只有浦肯野细胞"}
看见小脑切片，先数三层，再问轴突离开皮质的是哪一种细胞。答案只有浦肯野细胞：轴突自胞体底部发出，进入白质，终止于其中的神经核。颗粒细胞、星形细胞、篮状细胞、高尔基细胞都把轴突留在皮质里。把颗粒细胞听成“和小脑核对话的传出神经元”，进出账会整层反转。
:::

:::compare{title="小脑皮质五种神经元"}
| 细胞 | 所在层次 | 形态要点 | 轴突去向 | 功能归属 |
|------|----------|----------|----------|----------|
| 浦肯野细胞 | 胞体在浦肯野细胞层；树突在分子层 | 皮质中最大；梨形；主树突 $2\sim 3$ 条，扇形展开，密布树突棘 | 离开皮质进入白质，终止于神经核 | 唯一传出神经元 |
| 颗粒细胞 | 颗粒层 | 胞体很小、圆形；$4\sim 5$ 个短树突，末端爪状 | 上行分子层后 T 形分支成平行纤维 | 兴奋性中间神经元，间接兴奋浦肯野细胞 |
| 星形细胞 | 分子层浅层 | 小而多突 | 轴突较短，与浦肯野细胞树突突触 | 抑制性中间神经元 |
| 篮状细胞 | 分子层深层 | 胞体较大 | 轴突较长，向下延伸，末端呈网状包裹浦肯野细胞胞体 | 抑制性中间神经元 |
| 高尔基细胞 | 颗粒层 | 胞体较大，树突分支多 | 大部分树突入分子层接平行纤维；轴突在颗粒层内分支茂密，与颗粒细胞树突突触 | 抑制性中间神经元 |
:::

:::pitfall{label="小脑颗粒细胞不是大脑皮质那种高尔基Ⅱ型颗粒细胞的复印件"}
两边都叫颗粒细胞，账不一样。大脑皮质的颗粒细胞主要在第 2、4 层织局部环路，轴突一般很短；小脑颗粒细胞在颗粒层，轴突必须上行到分子层变成平行纤维，才能去敲浦肯野细胞的树突棘。不要按大脑六层去给小脑切片标Ⅰ～Ⅵ，也不要把小脑颗粒细胞写成传出神经元。
:::

## （一）小脑皮质的结构

### 1. 分子层

分子层较厚，含大量神经纤维，神经元则少而分散，主要有两种：一种是小而多突的星形细胞，胞体分布于浅层，轴突较短，与浦肯野细胞的树突形成突触；另一种是篮状细胞，胞体较大，分布于深层，其轴突较长，向下层延伸，末端呈网状包裹浦肯野细胞胞体，与之形成突触。

:::definition{label="小脑分子层"}
小脑分子层较厚，含大量神经纤维，神经元少而分散。浅层为小而多突的星形细胞，轴突较短，与浦肯野细胞树突形成突触；深层为胞体较大的篮状细胞，轴突较长，末端呈网状包裹浦肯野细胞胞体。层内还有平行纤维横穿浦肯野细胞的扇形树突。
:::

:::definition{label="星形细胞（小脑）"}
小脑分子层浅层的星形细胞小而多突，轴突较短，与浦肯野细胞的树突形成突触。属抑制性中间神经元。
:::

:::definition{label="篮状细胞"}
篮状细胞胞体较大，分布于分子层深层。轴突较长，向下层延伸，末端呈网状包裹浦肯野细胞胞体并与之形成突触。属抑制性中间神经元。
:::

:::note{label="篮状细胞的“篮子”套在浦肯野胞体上，不是套在树突上"}
星形细胞打在树突，篮状细胞打在胞体：一个管树突树，一个管胞体。名字来自轴突终末织成的网状“篮子”。把篮状细胞听成“形状像篮子的细胞体”，切片上会去找一种篮子形的胞体，而漏掉那圈包住梨形细胞的终末网。
:::

### 2. 浦肯野细胞层

浦肯野细胞层由一层排列规则的浦肯野细胞胞体构成。浦肯野细胞是小脑皮质中最大的神经元，其胞体呈梨形，顶端发出 $2\sim 3$ 条粗的主树突伸向分子层。主树突的分支繁密，如扁薄的扇形展开。树突上有许多树突棘。细长的轴突自胞体底部发出，离开皮质进入小脑白质，终止于其中的神经核。

:::definition{label="浦肯野细胞层"}
浦肯野细胞层由一层排列规则的浦肯野细胞胞体构成，夹在分子层与颗粒层之间。光镜下这排梨形胞体是认小脑皮质的第一标志。
:::

:::definition{label="浦肯野细胞"}
浦肯野细胞（Purkinje cell）是小脑皮质中最大的神经元，也是唯一的传出神经元。胞体呈梨形；顶端发出 $2\sim 3$ 条粗的主树突伸向分子层，分支繁密，如扁薄的扇形展开，树上有许多树突棘；细长轴突自胞体底部发出，离开皮质进入白质，终止于神经核。
:::

:::concept{term="先问扇面朝哪：树突铺进分子层，轴突沉进白质"}
浦肯野细胞像一排梨，把扇子全部打开朝向表面。扇面上的树突棘用来接平行纤维和攀缘纤维；扇柄（轴突）从底部进白质，把整合后的结果交给小脑核。HE 里往往只看见那一排梨形胞体（图 8-6），镀银才把扇面画全（图 8-7）。把 HE 里“一层大细胞”当成全部，会漏掉分子层里那张真正接受信息的树突网。
:::

::figure{src="/images/histology/textbook/p0100_03.png" caption="图8-7 小脑浦肯野细胞光镜图（镀银染色）。梨形胞体排成一层，主树突在分子层内呈扁薄扇形展开。" alt="镀银染色显示一排浦肯野细胞的梨形胞体和扇形繁密树突"}

### 3. 颗粒层

颗粒层含有密集的颗粒细胞和一些高尔基细胞。颗粒细胞胞体很小，呈圆形，有 $4\sim 5$ 个短树突，末端分支如爪状。轴突上行进入分子层后呈 T 形分支，与小脑叶片长轴平行，故称平行纤维。大量平行纤维垂直穿过一排排浦肯野细胞的扇形树突，与其树突棘形成突触。一个浦肯野细胞的树突上可形成几十万个突触，所以每一个浦肯野细胞都处于很多颗粒细胞的影响之下。高尔基细胞胞体较大，树突分支较多，大部分伸入分子层与平行纤维接触，轴突在颗粒层内分支茂密，并与颗粒细胞的树突形成突触。

:::definition{label="颗粒层"}
颗粒层含密集的颗粒细胞和一些高尔基细胞。光镜下核密集、着色深，与淡染的分子层形成对照。
:::

:::definition{label="小脑颗粒细胞"}
颗粒细胞胞体很小、呈圆形，有 $4\sim 5$ 个短树突，末端分支如爪状。轴突上行进入分子层后呈 T 形分支，与小脑叶片长轴平行，称平行纤维。
:::

:::definition{label="平行纤维"}
平行纤维是颗粒细胞轴突在分子层内的 T 形分支，与小脑叶片长轴平行。大量平行纤维垂直穿过一排排浦肯野细胞的扇形树突，与其树突棘形成突触。
:::

:::definition{label="高尔基细胞（小脑）"}
高尔基细胞胞体较大，位于颗粒层。树突分支较多，大部分伸入分子层与平行纤维接触；轴突在颗粒层内分支茂密，与颗粒细胞的树突形成突触。属抑制性中间神经元。
:::

:::insight{label="一颗浦肯野细胞可以挂几十万个突触"}
上一章写树突棘扩展接受面积，在这里写成数量级：一个浦肯野细胞的扇形树突上可形成几十万个突触，每一个都处于很多颗粒细胞的影响之下。平行纤维像纬线，垂直穿过多排扇面，把许多颗粒细胞的兴奋铺到同一颗传出神经元上。这是小脑能精细调节肌紧张和协调随意运动的形态学前提。
:::

:::compare{title="小脑皮质三层"}
| 层次 | 厚度与细胞密度 | 主要神经元 | 标志性结构 |
|------|----------------|------------|------------|
| 分子层 | 较厚；纤维多，神经元少而分散 | 浅层星形细胞，深层篮状细胞；浦肯野树突和平行纤维占据大部分体积 | 淡染；平行纤维横穿扇形树突 |
| 浦肯野细胞层 | 单层胞体 | 浦肯野细胞 | 梨形胞体规则排列（图 8-6 之 2） |
| 颗粒层 | 细胞极密 | 颗粒细胞 + 高尔基细胞；含小脑小球 | 深染小核密集（图 8-6 之 3） |
:::

## （二）小脑皮质的纤维

小脑皮质的传入纤维有 3 种：攀缘纤维、苔藓纤维和去甲肾上腺素能纤维。攀缘纤维主要起源于延髓的下橄榄核，纤维较细，进入皮质后攀附在浦肯野细胞的树突上形成突触，能直接引起浦肯野细胞兴奋，故为兴奋性纤维。苔藓纤维也是兴奋性纤维，主要起源于脊髓和脑干的神经核，纤维较粗，进入皮质后纤维末端呈苔藓状分支，分支终末膨大，与许多颗粒细胞的树突、高尔基细胞的轴突或近端树突形成复杂的突触群，形似小球，故称小脑小球（cerebellar glomerulus）（图 8-8）。一条苔藓纤维的分支可兴奋许多个颗粒细胞，通过颗粒细胞的平行纤维又可间接兴奋更多的浦肯野细胞。然而，苔藓纤维通过颗粒细胞平行纤维兴奋浦肯野细胞的同时，也可兴奋抑制性中间神经元（高尔基细胞、篮状细胞和星形细胞）。由于篮状细胞和星形细胞与浦肯野细胞有突触联系，它们兴奋后反过来抑制浦肯野细胞的活动。这样，由颗粒细胞平行纤维直接兴奋的浦肯野细胞处于兴奋状态，而其周围的浦肯野细胞则处于抑制状态。因此，通过上述抑制性中间神经元的作用，使许多不同来源的神经冲动进入小脑皮质后，引起许多区域的兴奋与抑制，这对小脑精确调节不同部位肌肉的肌紧张或协调随意运动都具有重要的意义。去甲肾上腺素能纤维（来自脑干的蓝斑核）对浦肯野细胞有抑制作用。浦肯野细胞发出的轴突组成小脑皮质唯一的传出纤维，终止于小脑白质内的神经核。

:::definition{label="攀缘纤维"}
攀缘纤维主要起源于延髓的下橄榄核，纤维较细。进入皮质后攀附在浦肯野细胞的树突上形成突触，能直接引起浦肯野细胞兴奋，为兴奋性纤维。
:::

:::definition{label="苔藓纤维"}
苔藓纤维主要起源于脊髓和脑干的神经核，纤维较粗，也是兴奋性纤维。进入皮质后末端呈苔藓状分支，终末膨大，与许多颗粒细胞的树突、高尔基细胞的轴突或近端树突形成复杂的突触群。
:::

:::definition{label="小脑小球"}
小脑小球（cerebellar glomerulus）是苔藓纤维分支终末膨大与许多颗粒细胞树突、高尔基细胞轴突或近端树突形成的复杂突触群，形似小球，位于颗粒层（图 8-8 虚线范围）。
:::

:::definition{label="去甲肾上腺素能纤维（小脑）"}
去甲肾上腺素能纤维来自脑干的蓝斑核，对浦肯野细胞有抑制作用。它是小脑皮质三种传入纤维中唯一以抑制浦肯野细胞为主的一类。
:::

:::concept{term="先问这根传入是直接抱树突，还是先敲颗粒细胞"}
攀缘纤维细，直接攀在浦肯野树突上，一对一地把它点燃。苔藓纤维粗，先在颗粒层结成小脑小球，经颗粒细胞的平行纤维间接兴奋许多浦肯野细胞，同时把篮状细胞、星形细胞和高尔基细胞也点着——周围一圈浦肯野细胞随即被抑制。蓝斑核来的去甲肾上腺素能纤维则直接抑制浦肯野细胞。三种进线，一条出线（浦肯野轴突）。
:::

:::compare{title="小脑皮质三种传入纤维"}
| 项目 | 攀缘纤维 | 苔藓纤维 | 去甲肾上腺素能纤维 |
|------|----------|----------|---------------------|
| 主要起源 | 延髓下橄榄核 | 脊髓和脑干的神经核 | 脑干蓝斑核 |
| 粗细 | 较细 | 较粗 | — |
| 落点 | 直接攀附浦肯野细胞树突 | 颗粒层：与颗粒细胞树突、高尔基细胞轴突或近端树突形成小脑小球 | 作用于浦肯野细胞 |
| 对浦肯野细胞 | 直接兴奋 | 经平行纤维间接兴奋；同时经抑制性中间神经元抑制其周围的浦肯野细胞 | 抑制 |
| 纤维性质 | 兴奋性 | 兴奋性 | 抑制性 |
:::

:::pitfall{label="苔藓纤维兴奋浦肯野细胞的同时，也在抑制它的邻居"}
不要把苔藓通路写成“只兴奋不抑制”。平行纤维直接兴奋的那一颗浦肯野细胞处于兴奋状态，周围的浦肯野细胞经篮状细胞和星形细胞被抑制。这本“中心兴奋、周围抑制”的账，才是精确调节肌紧张和协调随意运动的关键。漏掉抑制性中间神经元，小脑回路会变成一条单向加油管。
:::

:::insight{label="唯一的出口在白质的神经核，不在皮质里"}
无论攀缘、苔藓还是蓝斑核纤维如何改写浦肯野细胞的兴奋水平，离开皮质的只有浦肯野细胞的轴突，终止于白质内的神经核。大脑皮质有投射纤维和联合传出纤维两套出口，起点还分散在第 3、5、6 层；小脑把出口收成一种细胞、一个去向。
:::

:::keypoint{label="小脑三层、五型细胞、三种传入、一条传出"}
- 三层：分子层（星形细胞浅、篮状细胞深）→ 单层浦肯野胞体 → 密集颗粒层（颗粒细胞 + 高尔基细胞）。
- 浦肯野细胞：梨形，主树突 $2\sim 3$ 条扇形展开、密布树突棘；唯一传出，轴突至白质神经核。
- 颗粒细胞轴突 → 平行纤维，垂直穿过扇形树突，一颗浦肯野细胞可挂几十万个突触。
- 攀缘纤维（下橄榄核）直接兴奋；苔藓纤维（脊髓、脑干核）经小脑小球间接兴奋，并经中间神经元抑制周围；蓝斑核纤维抑制浦肯野细胞。
- 中心兴奋、周围抑制，用于精确调节肌紧张和协调随意运动。
:::

:::memory{label="本节必背要点"}
- [ ] 小脑皮质神经元 5 种：浦肯野细胞、颗粒细胞、星形细胞、篮状细胞、高尔基细胞；浦肯野细胞是唯一的传出神经元。
- [ ] 小脑皮质由表及里 3 层：分子层、浦肯野细胞层、颗粒层。
- [ ] 分子层较厚，含大量神经纤维，神经元少而分散。
- [ ] 星形细胞：小而多突，胞体在分子层浅层，轴突较短，与浦肯野细胞树突形成突触。
- [ ] 篮状细胞：胞体较大，在分子层深层；轴突较长向下延伸，末端呈网状包裹浦肯野细胞胞体并形成突触。
- [ ] 浦肯野细胞层由一层排列规则的浦肯野细胞胞体构成。
- [ ] 浦肯野细胞是小脑皮质中最大的神经元，胞体呈梨形。
- [ ] 顶端发出 $2\sim 3$ 条粗的主树突伸向分子层，分支繁密，如扁薄的扇形展开；树突上有许多树突棘。
- [ ] 细长轴突自胞体底部发出，离开皮质进入小脑白质，终止于其中的神经核。
- [ ] 颗粒层含密集颗粒细胞和一些高尔基细胞。
- [ ] 颗粒细胞胞体很小、圆形，有 $4\sim 5$ 个短树突，末端分支如爪状。
- [ ] 颗粒细胞轴突上行进入分子层后呈 T 形分支，与小脑叶片长轴平行，称平行纤维。
- [ ] 大量平行纤维垂直穿过一排排浦肯野细胞的扇形树突，与其树突棘形成突触。
- [ ] 一个浦肯野细胞的树突上可形成几十万个突触，每一个浦肯野细胞都处于很多颗粒细胞的影响之下。
- [ ] 高尔基细胞胞体较大，树突分支较多，大部分伸入分子层与平行纤维接触；轴突在颗粒层内分支茂密，与颗粒细胞树突形成突触。
- [ ] 传入纤维 3 种：攀缘纤维、苔藓纤维、去甲肾上腺素能纤维。
- [ ] 攀缘纤维主要起源于延髓下橄榄核，较细，攀附浦肯野细胞树突，直接引起兴奋，为兴奋性纤维。
- [ ] 苔藓纤维主要起源于脊髓和脑干的神经核，较粗，也是兴奋性纤维；末端苔藓状分支，终末膨大。
- [ ] 小脑小球（cerebellar glomerulus）：苔藓纤维终末与许多颗粒细胞树突、高尔基细胞轴突或近端树突形成的复杂突触群，形似小球。
- [ ] 一条苔藓纤维可兴奋许多颗粒细胞，经平行纤维间接兴奋更多浦肯野细胞。
- [ ] 同时可兴奋抑制性中间神经元（高尔基细胞、篮状细胞、星形细胞）；篮状细胞和星形细胞兴奋后反过来抑制浦肯野细胞。
- [ ] 平行纤维直接兴奋的浦肯野细胞处于兴奋状态，其周围的浦肯野细胞处于抑制状态。
- [ ] 这种区域性兴奋与抑制，对精确调节不同部位肌肉的肌紧张或协调随意运动有重要意义。
- [ ] 去甲肾上腺素能纤维来自脑干蓝斑核，对浦肯野细胞有抑制作用。
- [ ] 浦肯野细胞轴突组成小脑皮质唯一的传出纤维，终止于白质内的神经核。
:::
