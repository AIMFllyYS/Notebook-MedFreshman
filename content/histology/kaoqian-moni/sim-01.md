## 一、绪论与上皮组织

### 第1题

:::callout{kind=note label="题目"}
光镜的分辨率可达到（　　）

A. $0.2\,\mu\mathrm{m}$　　B. $2\,\mu\mathrm{m}$　　C. $0.2\,\mathrm{nm}$　　D. $2\,\mathrm{nm}$

来源：2010 绪论 · A 型 3
:::

:::callout{kind=insight label="解析"}
**【答案】A**

分辨率是能区分两点的最小间距。光镜约 $0.2\,\mu\mathrm{m}$；电镜最大分辨率约 $0.2\,\mathrm{nm}$（A 型 4 选 C）。把 µm 和 nm 对调是最常见的陷阱。
:::

:::callout{kind=note label="知识卡片：光镜与电镜"}
| | 分辨率 | 看什么 |
|--|--------|--------|
| 光镜 | $0.2\,\mu\mathrm{m}$ | 细胞、核、HE 颜色 |
| 透射电镜 | 约 $0.2\,\mathrm{nm}$ | 平面超微结构 |
| 扫描电镜 | — | 表面立体构像 |

最常用光镜制片术是石蜡切片术；HE：苏木素染核与核糖体紫蓝（嗜碱），伊红染胞质与部分基质红（嗜酸）。
:::

:::callout{kind=tip label="结论速记"}
光镜 **$0.2\,\mu\mathrm{m}$**，电镜 **$0.2\,\mathrm{nm}$**；立体形貌找扫描电镜。
:::

### 第2题

:::callout{kind=note label="题目"}
判断：上皮组织细胞排列紧密、有明显极性，并有丰富的毛细血管。（　　）

A. 正确　　B. 错误

来源：2010 上皮 · X 型 1（改判断）
:::

:::callout{kind=insight label="解析"}
**【答案】B（错误）**

上皮特点是细胞紧密、极性明显、细胞间质少、**无血管**；营养靠基膜下结缔组织渗透。把「保护层」听成「富含毛细血管」会直接丢分。
:::

:::callout{kind=note label="知识卡片：被覆上皮分类尺子"}
先问一层还是多层，再问游离面那一层是扁、立方还是柱状。假复层核高低不一，但所有细胞都贴基膜，户头仍在单层。
:::

:::callout{kind=tip label="结论速记"}
上皮：**紧密、有极性、贴基膜、无血管**。
:::

### 第3题

:::callout{kind=note label="题目"}
人体中最耐摩擦的上皮是（　　）

A. 单层扁平上皮　　B. 单层柱状上皮　　C. 复层扁平上皮　　D. 变移上皮

来源：2010 上皮 · A 型 1
:::

:::callout{kind=insight label="解析"}
**【答案】C**

复层扁平（鳞状）上皮浅层扁平、多层叠积，专司保护。角化型在皮肤表皮，未角化型在口腔、食管、阴道。单层扁平光滑减摩擦，不耐磨；变移上皮适应容积变化，不是「最耐摩擦」。
:::

:::callout{kind=pitfall label="易错警示"}
角化与未角化最大区别是**浅表层细胞是否含核**（A 型 3 选 D），不是层数或细胞数量。
:::

:::callout{kind=tip label="结论速记"}
耐摩擦 → **复层扁平**；排尿管道 → **变移上皮**。
:::

### 第4题

:::callout{kind=note label="题目"}
关于变移上皮（　　）

A. 分布于心血管腔面　　B. 游离面有大量纤毛　　C. 基底面凹凸不平　　D. 细胞层数和浅层形状可发生变化

来源：2010 上皮 · A 型 4
:::

:::callout{kind=insight label="解析"}
**【答案】D**

变移上皮在肾盂、肾盏、输尿管、膀胱。收缩时表层盖细胞较大、可双核；充盈时层数变少、细胞变扁。A 是内皮；B 是呼吸道假复层纤毛柱状；C 不是定义点。
:::

:::callout{kind=note label="知识卡片：内皮 vs 间皮"}
- **内皮**：心脏、血管、淋巴管腔面的单层扁平上皮
- **间皮**：胸膜、腹膜、心包膜表面的单层扁平上皮
:::

:::callout{kind=tip label="结论速记"}
变移上皮：**层数和浅层形状随充盈改变**；内皮 ≠ 间皮。
:::

### 第5题

:::callout{kind=note label="题目"}
填空：衬贴在心脏、血管和淋巴管腔面的单层扁平上皮称为 ______。杯状细胞可见于 ______ 上皮。

来源：2010 上皮 · 名词 1；A 型 2
:::

:::callout{kind=insight label="解析"}
**【答案】内皮；单层柱状（胃肠道等）**

杯状细胞是散在的腺细胞，见于单层柱状上皮和假复层纤毛柱状上皮，胃表面上皮**没有**杯状细胞（粘液由表面粘液细胞分泌）。
:::

:::callout{kind=note label="知识卡片：游离面两件不要并"}
| | 微绒毛 | 纤毛 |
|--|--------|------|
| 骨架 | 纵行微丝 | 微管（$9+2$） |
| 能否光镜看见 | 常不能（纹状缘是集群） | 能 |
| 功能 | 扩大表面积，利吸收 | 节律性定向摆动 |
:::

:::callout{kind=tip label="结论速记"}
心血管腔面 = **内皮**；杯状细胞在肠和呼吸道，**不在胃**。
:::

## 二、结缔组织（固有结缔、骨、血液）

### 第1题

:::callout{kind=note label="题目"}
合成和分泌抗体的细胞是（　　）

A. 肥大细胞　　B. 浆细胞　　C. 成纤维细胞　　D. 巨噬细胞

来源：2010 固有结缔 · A 型 1
:::

:::callout{kind=insight label="解析"}
**【答案】B**

浆细胞由 B 淋巴细胞分化，核偏位、异染色质辐射状（车轮核），胞质嗜碱、粗面内质网极丰富。肥大细胞产肝素、组胺、白三烯；巨噬细胞吞噬并呈递抗原，不分泌抗体；成纤维细胞产纤维和基质。
:::

:::callout{kind=note label="知识卡片：疏松结缔四种常考细胞"}
| 细胞 | 切片钥匙 | 功能 |
|------|----------|------|
| 成纤维细胞 | 核大色浅、核仁明显，粗面内质网发达 | 分泌纤维和基质；静止称纤维细胞 |
| 巨噬细胞 | 胞质嗜酸，可含空泡和异物颗粒 | 趋化、吞噬、分泌细胞因子 |
| 浆细胞 | 车轮核，核旁浅染区 | 分泌抗体 |
| 肥大细胞 | 异染性颗粒 | 过敏反应 |
:::

:::callout{kind=tip label="结论速记"}
抗体只问 **浆细胞**；异染颗粒只问 **肥大细胞**。
:::

---

### 第2题

:::callout{kind=note label="题目"}
具有嗜银性的纤维是（　　）

A. 胶原纤维　　B. 弹性纤维　　C. 网状纤维　　D. 肌纤维

来源：2010 固有结缔 · A 型 8
:::

:::callout{kind=insight label="解析"}
**【答案】C**

网状纤维由 III 型胶原构成，银染成黑色，故称嗜银纤维，构成造血器官和淋巴器官微细网架。胶原纤维新鲜时白色（白纤维），HE 粉红，韧性大，电镜有周期性横纹；弹性纤维新鲜时黄色（黄纤维），弹性大，**无**周期性横纹。
:::

:::callout{kind=note label="知识卡片：三种纤维"}
| | 胶原纤维 | 弹性纤维 | 网状纤维 |
|--|----------|----------|----------|
| 别名 | 白纤维 | 黄纤维 | 嗜银纤维 |
| HE | 粉红 | 浅红 | 不易显，需银染 |
| 电镜 | 周期横纹 | 微原纤维 + 弹性蛋白 | 周期横纹 |
:::

:::callout{kind=tip label="结论速记"}
嗜银 = **网状纤维**；周期横纹是胶原原纤维，不是弹性纤维。
:::

### 第3题

:::callout{kind=note label="题目"}
关于成骨细胞的描述，哪项错误（　　）

A. 位于骨组织内　　B. 细胞质嗜碱性　　C. 有大量粗面内质网和发达的高尔基复合体　　D. 具有分泌骨质有机成分的功能

来源：2010 软骨和骨 · A 型 7
:::

:::callout{kind=insight label="解析"}
**【答案】A**

成骨细胞排列在**骨组织表面**，分泌类骨质后自身被包埋才变成骨细胞，进入骨陷窝。胞质嗜碱是因为粗面内质网旺盛。破骨细胞才是多核、溶酶体多、溶解骨质。
:::

:::callout{kind=note label="知识卡片：骨的四种细胞"}
- **骨祖细胞**：骨组织表面，可成骨或成软骨
- **成骨细胞**：表面单层，分泌类骨质
- **骨细胞**：陷窝 + 骨小管，多突起
- **破骨细胞**：多核，皱褶缘，溶骨
:::

:::callout{kind=tip label="结论速记"}
成骨细胞在**表面**不在板层里面；胞质嗜碱。
:::

### 第4题

:::callout{kind=note label="题目"}
血液中数量最多和最少的白细胞是（　　）

A. 中性粒细胞和单核细胞　　B. 淋巴细胞和嗜碱性粒细胞　　C. 中性粒细胞和嗜碱性粒细胞　　D. 淋巴细胞和单核细胞

来源：2010 血液 · A 型 2
:::

:::callout{kind=insight label="解析"}
**【答案】C**

有粒与无粒的分界是**有无特殊颗粒**，不是嗜天青颗粒。三种有粒白细胞靠特殊颗粒的嗜色性区分。网织红细胞是未完全成熟的红细胞，成人约占红细胞的 $0.5\%\sim 1.5\%$，煌焦油蓝染成蓝网，反映骨髓造血。
:::

:::callout{kind=note label="知识卡片：五种白细胞口诀"}
中性最多，嗜碱最少。单核细胞体积最大、入组织成巨噬细胞。血清是血液凝固后析出的淡黄色液体（纤维蛋白原已变成纤维蛋白）；抗凝后上层是血浆。
:::

:::callout{kind=tip label="结论速记"}
白细胞：**中性最多、嗜碱最少**；有粒无粒看**特殊颗粒**。
:::

## 三、肌组织

### 第1题

:::callout{kind=note label="题目"}
骨骼肌纤维结构和功能的基本单位是（　　）

A. 肌原纤维　　B. 肌节　　C. 粗肌丝　　D. 细肌丝

来源：2010 肌组织 · A 型 8
:::

:::callout{kind=insight label="解析"}
**【答案】B**

肌节是相邻两条 Z 线之间的一段肌原纤维，组成是 $1/2$ 明带 + 暗带 + $1/2$ 明带。肌细胞膜又称**肌膜**（不是肌内膜/肌束膜/肌外膜，后三者是结缔组织被膜）。
:::

:::callout{kind=note label="知识卡片：明带暗带谁在缩短"}
- 只有粗肌丝、无细肌丝：**H 带**
- 只有细肌丝、无粗肌丝：**明带（I 带）**
- Z 线在**明带**中央
- 收缩时：**明带和 H 带缩短，暗带长度不变**
:::

:::callout{kind=tip label="结论速记"}
基本单位是 **肌节**；收缩只缩明带和 H 带。
:::

---

### 第2题

:::callout{kind=note label="题目"}
骨骼肌纤维收缩时（　　）

A. 暗带和 H 带缩短　　B. 明带和 H 带缩短　　C. 明带和暗带缩短　　D. 暗带缩短

来源：2010 肌组织 · A 型 7
:::

:::callout{kind=insight label="解析"}
**【答案】B**

细肌丝向粗肌丝滑行：I 带变窄、H 带变窄甚至消失，A 带（暗带）长度等于粗肌丝长度，不变。横小管由肌膜凹陷形成，开口于细胞表面；骨骼肌横小管在明暗带交界，与两侧终池成**三联体**。
:::

:::callout{kind=note label="知识卡片：粗细肌丝蛋白质"}
粗肌丝 = 肌球蛋白。细肌丝 = 肌动蛋白 + 原肌球蛋白 + 肌钙蛋白。
:::

:::callout{kind=tip label="结论速记"}
收缩：**明带 + H 带缩短**，暗带不缩。
:::

### 第3题

:::callout{kind=note label="题目"}
心肌闰盘处有（　　）

A. 紧密连接、中间连接和桥粒　　B. 中间连接、桥粒和缝隙连接　　C. 紧密连接、桥粒和缝隙连接　　D. 紧密连接、中间连接和缝隙连接

来源：2010 肌组织 · A 型 10
:::

:::callout{kind=insight label="解析"}
**【答案】B**

闰盘是心肌特有。横向接触面：中间连接和桥粒（机械连接）；纵向接触面：缝隙连接（电耦联，同步收缩）。没有紧密连接。心肌横小管在 **Z 线水平**，终池少，多成**二联体**；骨骼肌横小管在明暗交界，三联体。
:::

:::callout{kind=pitfall label="易错警示"}
骨骼肌细胞之间**不能**形成缝隙连接；心肌、平滑肌可以。把紧密连接塞进闰盘是常见干扰。
:::

:::callout{kind=tip label="结论速记"}
闰盘 = **中间连接 + 桥粒 + 缝隙连接**；心肌横小管在 Z 线。
:::

## 四、神经组织

### 第1题

:::callout{kind=note label="题目"}
神经元尼氏体在电镜下为（　　）

A. 溶酶体　　B. 粗面内质网和游离核糖体　　C. 线粒体　　D. 高尔基复合体

来源：2010 神经组织 · A 型 2
:::

:::callout{kind=insight label="解析"}
**【答案】B**

尼氏体是胞体和**树突**内的嗜碱性斑块，轴突和轴丘没有。功能是合成结构蛋白、递质相关酶和肽类调质。神经原纤维由神经丝和微管组成，构成骨架并参与物质运输。
:::

:::callout{kind=note label="知识卡片：突触"}
突触存在于神经元与神经元之间，或神经元与效应细胞之间。化学性突触靠突触囊泡里的递质；电突触即缝隙连接。
:::

:::callout{kind=tip label="结论速记"}
尼氏体 = **RER + 核糖体**，在胞体和树突，不在轴突。
:::

---

### 第2题

:::callout{kind=note label="题目"}
在有髓神经纤维上，神经冲动传导的方式是（　　）

A. 在轴膜上连续进行　　B. 在髓鞘内跳跃进行　　C. 由一个郎飞结跳到相邻的郎飞结　　D. 由一个髓鞘切迹跳到相邻的髓鞘切迹

来源：2010 神经组织 · A 型 6
:::

:::callout{kind=insight label="解析"}
**【答案】C**

郎飞结处轴膜裸露，冲动结间跳跃，既绝缘又加速。髓鞘切迹（施-兰切迹）是施万细胞内、外侧胞质间的通道，不是跳跃位点。无髓纤维才在轴膜上连续传导。
:::

:::callout{kind=note label="知识卡片：谁来做髓鞘"}
- 周围神经系统：**施万细胞**
- 中枢神经系统：**少突胶质细胞**
- 吞噬：小胶质细胞
- 周围胶质还有卫星细胞
:::

:::callout{kind=tip label="结论速记"}
跳跃在 **郎飞结**；周围施万、中枢少突。
:::

### 第3题

:::callout{kind=note label="题目"}
具有吞噬功能的神经胶质细胞是（　　）

A. 小胶质细胞　　B. 室管膜细胞　　C. 星形胶质细胞　　D. 少突胶质细胞

来源：2010 神经组织 · A 型 5
:::

:::callout{kind=insight label="解析"}
**【答案】A**

小胶质细胞是中枢的巨噬细胞。室管膜细胞衬脑室和脊髓中央管，不是扁平吞噬细胞。星形胶质参与血-脑屏障的神经胶质膜。血-脑屏障 = 连续毛细血管内皮 + 紧密连接 + 基膜 + 神经胶质膜。
:::

:::callout{kind=note label="知识卡片：运动终板"}
脊髓前角或脑干运动神经元轴突终末与骨骼肌纤维形成化学性突触，释放乙酰胆碱；一条骨骼肌纤维通常只接受一个轴突分支支配。
:::

:::callout{kind=tip label="结论速记"}
中枢吞噬 = **小胶质**；血-脑屏障内皮是连续型。
:::

## 五、循环系统

### 第1题

:::callout{kind=note label="题目"}
弹性动脉是指（　　）

A. 大动脉　　B. 中动脉　　C. 小动脉　　D. 微动脉

来源：2010 循环 · A 型 7
:::

:::callout{kind=insight label="解析"}
**【答案】A**

大动脉中膜主要由数十层弹性膜组成，属弹性动脉；中动脉中膜以环行平滑肌为主，属肌性动脉，内弹性膜清楚。能显著调节组织局部血流量的是**小动脉和微动脉**。
:::

:::callout{kind=note label="知识卡片：血管壁三层"}
除毛细血管外：内膜（内皮 + 内皮下层）、中膜、外膜（疏松结缔，含营养血管）。心骨骼的组织学本质是致密结缔组织。
:::

:::callout{kind=tip label="结论速记"}
大动脉 = **弹性动脉**；中动脉 = 肌性动脉；局部流量看小动脉/微动脉。
:::

:::callout{kind=note label="题目"}
参与毛细血管再生的细胞是（　　）

## 六、消化系统

### 第1题

:::callout{kind=note label="题目"}
胃小凹的描述，哪项错误（　　）

A. 由单层柱状上皮构成　　B. 上皮内含有分泌粘液的杯状细胞　　C. 底部有数条胃底腺开口　　D. 小凹深部有增殖活跃的干细胞

:::

:::callout{kind=tip label="结论速记"}
胃上皮**没有杯状细胞**；粘膜下腺只记食管和十二指肠。
:::

### 第2题

:::callout{kind=note label="题目"}
潘氏细胞见于（　　）

A. 胃幽门腺底部　　B. 胃底腺底部　　C. 小肠腺底部　　D. 大肠腺底部

来源：2010 消化管 · A 型 7
:::

:::callout{kind=insight label="解析"}
**【答案】C**

潘氏细胞是小肠特征性细胞，位于小肠腺**底部**，顶部充满粗大嗜酸性颗粒，分泌防御素和溶菌酶。不是柱状、也不在腺颈部（A 型 6 错误项）。结肠无绒毛，大肠腺以杯状细胞为主。

:::callout{kind=note label="知识卡片：壁细胞 vs 主细胞"}
| | 壁细胞（泌酸细胞） | 主细胞 |
|--|-------------------|--------|
| 位置 | 腺的上部/颈部较多 | 腺底部较多 |
| HE | 强嗜酸，可双核 | 基部嗜碱，顶部酶原颗粒 |
| 电镜 | 细胞内分泌小管、微管泡系统、线粒体极多 | 粗面内质网、酶原颗粒 |
| 功能 | 盐酸、内因子 | 胃蛋白酶原 |
:::

:::callout{kind=tip label="结论速记"}
潘氏细胞只在 **小肠腺底部**；壁细胞嗜酸泌酸。
:::

### 第3题

:::callout{kind=note label="题目"}
肝血窦特点是（　　）

A. 内皮有窗孔，有基膜　　B. 内皮无窗孔，无基膜　　C. 内皮有窗孔，无基膜　　D. 内皮无窗孔，有基膜

:::

:::callout{kind=insight label="解析"}
**【答案】C**

肝细胞有血窦面、胆小管面、连接面。有微绒毛的是血窦面和胆小管面。胆小管由相邻肝细胞膜凹陷围成，周围有连接复合体封闭。门管区：小叶间动脉、小叶间静脉、小叶间胆管（无小叶下静脉）。
:::

:::callout{kind=tip label="结论速记"}
肝血窦：**有孔、无基膜**；贮脂细胞在窦周隙产网状纤维。
:::

### 第4题

:::callout{kind=note label="题目"}
胰腺内分泌胰岛素的细胞是（　　）

## 七、呼吸系统

### 第1题

:::callout{kind=note label="题目"}
肺小叶的组成是（　　）

A. 每一细支气管与其下属分支至肺泡　　B. 每一终末细支气管与其下属分支至肺泡　　C. 每一呼吸细支气管与其下属分支至肺泡　　D. 每一肺泡管与其下属分支至肺泡

来源：2010 呼吸 · A 型 7
:::

:::callout{kind=insight label="解析"}
**【答案】A**

肺小叶是肺的结构单位：一条细支气管连同它以下的分支和肺泡。锥体形，尖朝肺门、底朝肺表面。调节进出肺小叶气流量的是细支气管和终末细支气管（环行平滑肌逐渐完整）。

:::callout{kind=tip label="结论速记"}
肺小叶 = **细支气管**及其下属至肺泡，不是呼吸性细支气管。

### 第2题

:::callout{kind=note label="题目"}
有关肺表面活性物质的来源和作用，正确的是（　　）

A. 来源于 I 型细胞，可提高肺泡表面张力　　B. 来源于 II 型细胞，可降低肺泡表面张力　　C. 来源于 I 型细胞，可分解肺泡表面异物　　D. 来源于 II 型细胞，可增加肺泡通气量

来源：2010 呼吸 · A 型 15

:::callout{kind=insight label="解析"}
**【答案】B**

II 型肺泡细胞呈圆形、胞质泡沫状，电镜有嗜锇性板层小体，释放表面活性物质，降低表面张力、稳定肺泡直径，并可增殖分化补充 I 型细胞。I 型细胞扁平菲薄，覆盖大部分内表面，参与气血屏障，本身不分泌表面活性物质。

:::

:::callout{kind=tip label="结论速记"}
表面活性物质 = **II 型细胞**，作用是**降低**表面张力。
:::

## 八、泌尿系统

### 第1题

:::callout{kind=note label="题目"}
组成肾单位的结构是（　　）

A. 肾小体和泌尿小管　　B. 肾小体和肾小管　　C. 肾小体和肾单位袢　　D. 肾小体和集合小管

:::callout{kind=tip label="结论速记"}
肾单位 = **肾小体 + 肾小管**；集合管不参加髓袢。

肾内可分泌肾素的细胞是（　　）

A. 球旁细胞　　B. 致密斑　　C. 球外系膜细胞　　D. 间质细胞

来源：2010 泌尿 · A 型 10

:::callout{kind=insight label="解析"}

判断：集合管系参与髓袢的组成。（　　）

## 九、生殖系统

### 第1题

:::callout{kind=note label="题目"}
精子发生是（　　）

A. 精子细胞渐变成精子的过程　　B. 从精原细胞到形成精子的过程　　C. 从初级精母细胞至精子形成的过程　　D. 从精母细胞的两次成熟分裂过程

来源：2010 男性生殖 · A 型 3
:::

:::callout{kind=insight label="解析"}
**【答案】B**

精子发生含三期：精原细胞增殖、精母细胞减数分裂、精子形成。A 只是「精子形成」（变态）。获能发生在女性生殖管道，不是精子发生的步骤（A 型 5 错误项）。青春期前生精小管一般只有支持细胞和精原细胞。
:::

:::callout{kind=note label="知识卡片：生精上皮顺序"}
基膜 → 精原细胞 → 初级精母细胞（体积最大，染色质常呈丝球状）→ 次级精母细胞 → 精子细胞（不再分裂，只变态）→ 精子。支持细胞轮廓在 HE 上往往不清。
:::

:::callout{kind=tip label="结论速记"}
精子发生 = **精原细胞 → 精子**；精子形成 = 圆形精子细胞变态。
:::

### 第2题

:::callout{kind=note label="题目"}
精子获得功能上成熟的部位在（　　）

A. 生精小管　　B. 直精小管和睾丸网　　C. 附睾　　D. 输精管

来源：2010 男性生殖 · A 型 7

:::callout{kind=insight label="解析"}
**【答案】C**

精子在附睾获得运动能力和功能成熟；射出后仍须在子宫和输卵管**获能**才能受精。间质细胞（Leydig）是分泌类固醇（雄激素）的细胞，不是蛋白质激素细胞。
:::

:::callout{kind=note label="知识卡片：血-睾屏障"}
毛细血管内皮及基膜 + 结缔组织 + 生精上皮基膜 + **支持细胞基部紧密连接**（最重要）。防止抗原外逸、维持生精微环境。
:::

:::callout{kind=tip label="结论速记"}
功能成熟在 **附睾**；获能在 **子宫和输卵管**。

### 第3题

:::callout{kind=note label="题目"}
卵巢排卵时，所排出的是（　　）

A. 成熟卵泡　　B. 卵丘　　C. 初级卵母细胞　　D. 次级卵母细胞

次级卵母细胞的第二次成熟分裂完成于（　　）

A. 排卵前，在卵巢内　　B. 受精前，在输卵管内　　C. 排卵后，在腹腔内　　D. 受精时，在输卵管内

来源：2010 女性生殖 · A 型 4、2
:::

:::callout{kind=insight label="解析"}
**【答案】B；D**

排卵排出的是卵丘结构（次级卵母细胞 + 透明带 + 放射冠）和卵泡液，不是整个成熟卵泡，也不是单独写「次级卵母细胞」那么窄的选项。第一次成熟分裂在排卵前完成；第二次必须等精子穿入才完成，地点在输卵管。
:::

:::callout{kind=note label="知识卡片：卵泡与内膜周期"}
- 卵巢中最多见：**原始卵泡**
- 生长卵泡 = 初级卵泡 + 次级卵泡
- 次级卵泡才有卵泡腔，内仍是**初级卵母细胞**
- 排卵约在月经周期**增生晚期**（约第 14 天）
- 黄体分泌**孕激素和雌激素**，无导管
- 月经期：螺旋动脉强烈收缩，功能层缺血坏死脱落
:::

:::callout{kind=tip label="结论速记"}
排出的是 **卵丘**；第二次减数分裂完成于 **受精时、输卵管内**。
:::

## 十、人胚发生

### 第1题

:::callout{kind=note label="题目"}
受精一般发生于输卵管的（　　）

A. 漏斗部　　B. 壶腹部　　C. 峡部　　D. 子宫部

来源：2010 人胚发生 · A 型 1
:::

:::callout{kind=insight label="解析"}
**【答案】B**

射出的精子已有运动能力但**无受精能力**，必须获能。获能：头表面抑制性糖蛋白被女性生殖管道酶降解。顶体反应释放顶体酶溶蚀放射冠和透明带；精子入卵后发生透明带反应，阻止多精入卵。
:::

:::callout{kind=note label="知识卡片：从受精到胚泡"}
卵裂在透明带内进行、细胞不长大。桑椹胚之后形成胚泡：滋养层 + 胚泡腔 + 内细胞群。透明带在**胚泡期**消失。
:::

:::callout{kind=tip label="结论速记"}
受精在 **壶腹**；射出精子能游但不能受精，要先获能。
:::

### 第2题

:::callout{kind=note label="题目"}
植入后子宫内膜称（　　）

A. 胎膜　　B. 蜕膜　　C. 胎盘　　D. 粘膜

胚胎植入子宫内膜的时间（　　）

A. 胚泡时期　　B. 胚盘分化时期　　C. 桑椹胚时期　　D. 受精后 24 时内

来源：2010 人胚发生 · A 型 6、5
:::

:::callout{kind=insight label="解析"}
**【答案】B；A**

植入即胚泡埋入子宫内膜功能层，约受精后第 5–6 天开始、第 11–12 天完成，通常在子宫体部和底部。植入后的分泌期子宫内膜改称蜕膜。植入近宫颈内口则成前置胎盘。
:::

:::callout{kind=note label="知识卡片：胎膜与胎盘"}
胎膜：羊膜、卵黄囊、尿囊、脐带、绒毛膜。胎盘 = **丛密绒毛膜 + 基蜕膜**。绒毛间隙充满**母体血液**。脐带最表面是羊膜；剪断脐带流出的是**胎儿**动静脉血。
:::

:::callout{kind=tip label="结论速记"}
植入发生在 **胚泡期**；植入后内膜叫 **蜕膜**；胎盘 = 丛密绒毛膜 + 基蜕膜。
:::

### 第3题

:::callout{kind=note label="题目"}
原条出现于胚胎发育的（　　）

A. 第 1 周　　B. 第 2 周　　C. 第 3 周　　D. 第 4 周

胚盘内的中胚层（胚内中胚层）是来自（　　）

A. 上胚层　　B. 外胚层　　C. 下胚层　　D. 内胚层

来源：2010 人胚发生 · A 型 7、9
:::

:::callout{kind=insight label="解析"}
**【答案】C；A**

第 3 周上胚层正中线**一侧**增厚成原条，决定头尾（原条在尾侧）。原沟深部细胞在上、下胚层之间扩展成胚内中胚层，并置换下胚层为内胚层。脊索诱导神经板。中胚层由内向外：轴旁 → 间介 → 侧板。泌尿生殖系统主要来自**间介中胚层**。
:::

:::callout{kind=note label="知识卡片：三胚层去向（常考）"}
- 外胚层：表皮、神经管、神经嵴（周围神经、肾上腺髓质等）
- 中胚层：结缔组织、肌、血管、泌尿生殖（间介）
- 内胚层：从咽到大肠的上皮，喉气管肺上皮，肝胰实质
:::

:::callout{kind=tip label="结论速记"}
原条 **第 3 周**、来自**上胚层**；间介中胚层 → 泌尿生殖。
:::

### 第4题

:::callout{kind=note label="题目"}
致畸敏感期是（　　）

A. 受精后的 1–2 周　　B. 受精后的 3–8 周　　C. 受精后的 1–2 月　　D. 受精后的 3–8 月

判断：单卵孪生的遗传基因各异。（　　）

A. 正确　　B. 错误

来源：2010 人胚发生 · A 型 41、40
:::

:::callout{kind=insight label="解析"}
**【答案】B；B（错误）**

3–8 周是器官发生期，对致畸因子最敏感。第 1–2 周损伤常致胚死亡而非畸形。单卵孪生遗传基因相同、外貌相似，可发生联体双胎或寄生胎；「基因各异」是双卵孪生的特征。胚胎最早执行功能的系统是心血管系统。
:::

:::callout{kind=note label="知识卡片：hCG"}
人绒毛膜促性腺激素主要作用是促进黄体生长发育以维持妊娠，不是促排卵。
:::

:::callout{kind=tip label="结论速记"}
致畸敏感期 **第 3–8 周**；单卵孪生基因相同。
:::
