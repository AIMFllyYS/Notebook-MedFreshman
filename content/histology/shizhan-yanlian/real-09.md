## 二、名词解释（每题 5 分，共 25 分）

### 第2题

:::callout{kind=note label="题目"}
突触
:::

:::callout{kind=insight label="解析"}
**【答案】**（源采分）

神经元传递信息的重要结构（1 分），是神经元之间或神经元与非神经元之间的一种特化的细胞连接（1 分）。分化学性突触和电突触。化学性突触包括：突触前成分（突触小泡、突触前膜，1 分）、突触间隙（1 分）、突触后成分（受体、突触后膜，1 分）。
:::

:::callout{kind=tip label="结论速记"}
突触 = 前（小泡）+ 间隙 + 后（受体）。
:::

### 第3题

:::callout{kind=note label="题目"}
黄体
:::

:::callout{kind=insight label="解析"}
**【答案】**（源采分）

卵巢内由粒黄体细胞和膜黄体细胞、毛细血管构成的内分泌细胞团（3 分），具有分泌雌激素和孕激素的功能（2 分）。
:::

:::callout{kind=note label="知识卡片：来源"}
排卵后卵泡壁塌陷：颗粒细胞 → 粒黄体细胞；膜细胞 → 膜黄体细胞。妊娠则成妊娠黄体，否则约 2 周退化成白体。
:::

:::callout{kind=tip label="结论速记"}
黄体 = 粒黄体 + 膜黄体，产**雌 + 孕**。
:::

### 第4题

:::callout{kind=note label="题目"}
中央乳糜管
:::

:::callout{kind=insight label="解析"}
**【答案】**（源采分）

绒毛中央的毛细淋巴管（2 分）。其内皮细胞之间有较大的间隙，无基膜（2 分）；上皮细胞吸收的脂肪主要由中央乳糜管转运（1 分）。
:::

:::callout{kind=tip label="结论速记"}
中央乳糜管在绒毛中轴，**无基膜、走脂肪**。
:::

---

### 第5题

:::callout{kind=note label="题目"}
卵裂
:::

:::callout{kind=insight label="解析"}
**【答案】**（源采分）

受精卵的细胞分裂（2 分），受透明带的限制（1 分），细胞数目增加，而细胞体积变小（2 分）。
:::

:::callout{kind=tip label="结论速记"}
卵裂：个数↑、每个变小，总体积被透明带卡住。
:::

### 第6题

:::callout{kind=note label="题目"}
原条
:::

:::callout{kind=insight label="解析"}
**【答案】**（源采分）

外胚层一侧中线上的细胞增殖形成一条细胞索，称原条（2 分）。（本版教材表述为**上胚层**尾端中线，不是已经改名后的外胚层——解析按教材，采分按源。）

原条的意义：① 决定胚盘的头尾方向，有原条的一侧是尾端（1 分）；② 形成中胚层（1 分）；③ 形成脊索（1 分）。
:::

:::callout{kind=pitfall label="易错警示"}
源写「外胚层一侧中线」。三胚层都出自上胚层，原条出现时还叫上胚层。脊索来自原结／原凹迁出的细胞，可以算原条复合体的下游，但原条本身不是脊索。
:::

:::callout{kind=tip label="结论速记"}
原条定尾端，往外迁出中胚层；教材户头写**上胚层**。
:::

## 三、问答题（共 35 分）

### 第7题

:::callout{kind=note label="题目"}
试述被覆上皮的一般特征及分类。（5 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**（源采分）

特征（3 分）：细胞多，形状规则，间隙少，有极性。神经末梢丰富。一般无血管。

分类（2 分）：单层上皮（单层扁平、单层立方、单层柱状、假复层纤毛柱状）；复层上皮（复层扁平、变移上皮）。
:::

:::callout{kind=tip label="结论速记"}
上皮：极性 + 基膜 + 无血管。单层四户 + 复层扁平／变移。
:::

### 第8题

:::callout{kind=note label="题目"}
试述精子发生的基本过程。（10 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**（源采分）

**精原细胞增殖（3 分）**：精原细胞紧贴基膜，圆核，染色质细密。分 A、B 两型，由 A 型（干细胞）分化成 B 型。

**精母细胞成熟分裂（4 分）**：初级精母细胞（二倍体，4n DNA，XY 配对），体积最大，染色质呈粗网状。经第一次成熟分裂形成 2 个次级精母细胞。次级精母细胞近管腔，体积较小，存在时间短不易见到。经第二次成熟分裂形成 2 个精子细胞。

**精子形成（3 分）**：精子细胞——单倍体，近管腔，体积更小。由圆形细胞转变成蝌蚪形的精子。精子——分头（含浓缩的细胞核，其表面有顶体覆盖）和尾部（主要由线粒体、轴丝构成）。
:::

:::callout{kind=note label="知识卡片：DNA"}
初级精母细胞进入减数第一次分裂前已复制，故是 4n DNA。次级是 2n DNA、单倍体染色体数。精子细胞 1n。
:::

:::callout{kind=tip label="结论速记"}
精原（贴壁）→ 初级（最大、4n）→ 次级（短命）→ 精子细胞变形。
:::

### 第9题

:::callout{kind=note label="题目"}
试述肝门管区三种管道光镜结构及其与肝小叶的关系。（8 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**（源采分）

小叶间动脉（腔小，壁厚），其血液注入肝血窦（3 分）。

小叶间静脉（腔大，壁薄），其血液注入肝血窦（3 分）。

小叶间胆管（其壁为单层立方上皮或单层柱状上皮）；肝小叶内的胆汁通过胆小管、赫令管注入小叶间胆管（2 分）。
:::

:::callout{kind=pitfall label="易错警示"}
小叶下静脉不在门管区。血从门管区两支血管进血窦，汇入中央静脉再出小叶。
:::

:::callout{kind=tip label="结论速记"}
门管区：动脉厚、静脉薄、胆管立方／柱状；血进窦，胆汁出胆管。
:::

### 第10题

:::callout{kind=note label="题目"}
比较近曲小管和远曲小管结构的区别。（12 分）
:::

:::callout{kind=insight label="解析"}
**【答案】**（源表，各 6 分）

| | 近曲小管 | 远曲小管 |
|--|----------|----------|
| 上皮细胞大小 | 单层、大（厚） | 单层、小（薄） |
| 嗜色性 | 强嗜酸性 | 弱嗜酸性 |
| 核位于 | 近基底部 | 近游离面 |
| 刷状缘 | 明显 | 不明显 |
| 基底纵纹 | 不明显 | 明显 |
| 细胞界限 | 不清楚 | 较清楚 |
:::

:::callout{kind=tip label="结论速记"}
近曲大红刷状缘；远曲小淡纵纹清。
:::
