### 第1题

:::callout{kind=note label="题目"}
白细胞核左移（　　）

A. 细胞核向左移位　　B. 有粒白细胞数目增多
C. 杆状核中性粒细胞增多　　D. 无粒白细胞数目增多
:::

:::callout{kind=insight label="解析"}
**【答案】C（答案键）**

核左移指杆状核（及更幼稚）中性粒细胞比例增高，常见于感染。不是细胞核搬家，也不是有粒／无粒总数增减。
:::

:::callout{kind=tip label="结论速记"}
核左移 = **杆状核中性粒细胞增多**。
:::

### 第2题

:::callout{kind=note label="题目"}
下列哪种细胞不产生结缔组织纤维（　　）

A. 血管壁平滑肌细胞　　B. 成骨细胞　　C. 软骨细胞　　D. 肥大细胞
:::

:::callout{kind=insight label="解析"}
**【答案】D（答案键）**

肥大细胞贮肝素、组胺，不造纤维。成纤维细胞、软骨细胞、成骨细胞、血管平滑肌都能产纤维／类骨质。
:::

:::callout{kind=tip label="结论速记"}
不产纤维：**肥大细胞**。
:::

### 第3题

:::callout{kind=note label="题目"}
关于甲状腺滤泡的描述，哪项错误（　　）

A. 大小不等　　B. 滤泡上皮细胞具有分泌类固醇激素细胞的超微结构特征
C. 滤泡上皮内有滤泡旁细胞　　D. 胶质为碘化的甲状腺球蛋白
:::

:::callout{kind=insight label="解析"}
**【答案】B（答案键）**

滤泡上皮是蛋白质分泌细胞（粗面内质网、胶质），不是类固醇型（滑面内质网、脂滴、管状嵴线粒体）。滤泡旁细胞可嵌在上皮之间，不贴腔。
:::

:::callout{kind=tip label="结论速记"}
滤泡上皮不是类固醇分泌细胞。
:::

### 第5题

:::callout{kind=note label="题目"}
关于疏松结缔组织的结构特点，哪项错误（　　）

A. 细胞种类多　　B. 细胞无极性　　C. 纤维多　　D. 分布广泛
:::

:::callout{kind=insight label="解析"}
**【答案】C（答案键）**

疏松结缔组织细胞种类多、无极性、分布广，**纤维少、基质多**（和致密结缔组织相反）。「纤维多」是致密结缔组织的账。
:::

:::callout{kind=tip label="结论速记"}
疏松结缔组织：**纤维少**，不是纤维多。
:::

### 第9题

:::callout{kind=note label="题目"}
关于骨单位，哪项错误（　　）

A. 因含有管、腔结构，故属于松质骨　　B. 相邻中央管可以相通

### 第10题

:::callout{kind=insight label="解析"}

:::

:::callout{kind=insight label="解析"}
**【答案】** 源扫描：上胚层一侧中线上细胞增生形成的细胞索。

第 3 周上胚层细胞在尾端中线聚成原条，原沟细胞迁出铺中胚层、置换内胚层。原条头端膨大为原结。原条决定胚盘中轴和头尾。
:::

:::callout{kind=tip label="结论速记"}
原条 = 上胚层中线细胞索，三胚层从此迁出。
:::

## 四、问答题（共 25 分）

### 第1题

:::callout{kind=note label="题目"}
试述巨噬细胞的光镜、超微结构及功能（5 分）。
:::

:::callout{kind=insight label="解析"}
**【答案】** 按源问答 + 教材 ch03。

**光镜**

形态不规则，有钝圆突起；核卵圆或肾形，偏位；胞质丰富，嗜酸，可含空泡、异物颗粒。

**超微**

表面皱褶、微绒毛和伪足；溶酶体极多；吞噬体、残余体常见；有吞噬泡和胞饮泡。

**功能**

变形运动、趋化、吞噬（防御）；抗原呈递；分泌细胞因子、溶菌酶等；参与免疫应答和清除衰老细胞。来自血液单核细胞。
:::

:::callout{kind=tip label="结论速记"}
巨噬：不规则、溶酶体多、吞噬 + 呈递。
:::

### 第2题

:::callout{kind=note label="题目"}
试述肺导气部的组成及管壁的变化规律（5 分）。
:::

:::callout{kind=insight label="解析"}
**【答案】** 源扫描：叶／段／小／细／终末细支气管及管壁变化。

**组成**

肺内导气部：叶支气管 → 段支气管 → 小支气管 → 细支气管 → 终末细支气管。再往下出现肺泡开口，进入呼吸部。

**管壁变化（越分越细）**

1. 上皮：假复层纤毛柱状（有杯状细胞）→ 单层纤毛柱状 → 单层柱状（终末，杯状消失，俱乐部细胞为主）。
2. 腺体、软骨：逐渐减少，细支气管以下消失。
3. 平滑肌：相对增多，细支气管／终末细支气管形成完整环行肌层（哮喘痉挛的户头）。
:::

:::callout{kind=tip label="结论速记"}
导气部到终末细支气管；软骨腺消失、平滑肌相对增多。
:::

### 第3题

:::callout{kind=note label="题目"}
指出 4 种屏障，试述其结构特点（8 分）。
:::

:::callout{kind=insight label="解析"}
**【答案】** 题干写「4 种」，源扫描列了五种，按源写全。

| 屏障 | 结构要点 |
|------|----------|
| 血–胸腺屏障 | 连续毛细血管内皮及基膜、血管周隙、上皮基膜、连续的胸腺上皮细胞。保证胸腺微环境。 |
| 气–血屏障 | 肺泡表面液体、I 型肺泡细胞及基膜、薄层结缔组织（可无）、毛细血管基膜及内皮。厚 $0.2\sim 0.5\,\mu\mathrm{m}$。 |
| 血–尿屏障（滤过屏障） | 有孔内皮、基膜、足细胞裂孔膜。原尿经此滤出。 |
| 血–睾屏障 | 毛细血管内皮及基膜、结缔组织、生精上皮基膜、**支持细胞紧密连接**（核心）。 |
| 胎盘屏障（胎盘膜） | 合体滋养层、细胞滋养层及基膜、绒毛结缔组织、胎儿毛细血管基膜和内皮。母血与胎儿血不相混。 |
:::

:::callout{kind=pitfall label="易错警示"}
题干要 4 种，源卷解答写了 5 种。答题按源写全，不要自行删一条凑「4」。
:::

:::callout{kind=tip label="结论速记"}
五道屏障：血胸腺、气血、血尿、血睾、胎盘。气血厚度 $0.2\sim 0.5\,\mu\mathrm{m}$。
:::

### 第4题

:::callout{kind=note label="题目"}
指出该图所示为哪些畸形，叙述其主要形成原因，并叙述正常发育过程（7 分）。
:::

:::figure{src="/histology/shizhan-yanlian/images/real-05-q4-anencephaly-side.jpg" alt="无脑儿侧面观" caption="源卷附图：侧面观（无脑儿）"}
:::

:::figure{src="/histology/shizhan-yanlian/images/real-05-q4-neural-tube-defects.jpg" alt="无脑儿侧面观与脊柱裂背面观" caption="源卷附图：侧面观与背面观（无脑儿 + 脊柱裂）"}
:::

:::callout{kind=insight label="解析"}
**【答案】** 源扫描：无脑儿 + 脊柱裂；前神经孔未闭／神经褶未愈合；并写神经管正常发生。

**图示畸形**

侧面观：颅顶缺失、脑组织暴露或退化，为**无脑儿**。背面观：脊柱背侧未闭合、椎管开放，为**脊柱裂**（常伴脊髓脊膜膨出）。

**成因**

无脑儿：第 4 周**前神经孔未闭**，前脑不能发育，颅骨不能形成。脊柱裂：神经沟未闭或后神经孔未闭，相应节段椎弓不能在中线愈合。叶酸缺乏是重要环境因素。

**正常发育（神经管）**

第 3 周末脊索诱导外胚层成神经板 → 神经沟、神经褶 → 第 4 周愈合为神经管，与表面外胚层分离。愈合由中段向头、尾进展；前神经孔约第 25 天闭，后神经孔约第 27 天闭。管壁神经上皮分化为中枢；神经嵴走周围神经。
:::

:::callout{kind=tip label="结论速记"}
图 = **无脑儿 + 脊柱裂**；前神经孔／神经褶未闭。正常：板 → 沟 → 管，头尾孔先后关。
:::
