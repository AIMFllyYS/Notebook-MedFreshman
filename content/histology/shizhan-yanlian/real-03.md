## 一、最佳选择题（第 1–30 题，每题 0.5 分）

### 第1题

:::callout{kind=note label="题目"}
分布于排尿管道粘膜的上皮组织是（　　）

A. 单层柱状上皮　　B. 单层立方上皮　　C. 假复层纤毛柱状上皮　　D. 变移上皮
:::

:::callout{kind=insight label="解析"}
**【答案】D**

肾盏、肾盂、输尿管、膀胱腔面是变移上皮：层数和浅层盖细胞形状随充盈改变。A 是胃、肠、子宫内膜等；B 见于肾小管、甲状腺滤泡等；C 是呼吸道（鼻、喉、气管、支气管）的典型被覆。
:::

:::callout{kind=note label="知识卡片：三种「管道上皮」不要并户"}
| 管道 | 上皮 |
|------|------|
| 排尿（肾盏→膀胱） | 变移上皮 |
| 导气（气管、支气管） | 假复层纤毛柱状 |
| 胃肠腔面 | 单层柱状 |
:::

:::callout{kind=tip label="结论速记"}
排尿管道黏膜 → **变移上皮**。
:::

### 第2题

:::callout{kind=note label="题目"}
分布于胃和肠道粘膜的上皮的主要差别是（　　）

A. 有无杯状细胞　　B. 有无内分泌细胞　　C. 有无纤毛　　D. 有无微绒毛
:::

:::callout{kind=insight label="解析"}
**【答案】A**

胃、肠腔面都是单层柱状。胃表面是表面黏液细胞，**无杯状细胞**；小肠起出现杯状细胞，大肠更多。两侧都有内分泌细胞；游离面都可有微绒毛（肠的纹状缘更典型）；纤毛都不是主场。
:::

:::callout{kind=pitfall label="易错警示"}
把胃写成「单层柱状加杯状细胞」，黏液–碳酸氢盐屏障就没有户头。杯状细胞在肠，不在胃。
:::

:::callout{kind=tip label="结论速记"}
胃无杯状、肠有杯状，这是两者上皮的**主差别**。
:::

### 第3题

:::callout{kind=note label="题目"}
与过敏反应有关的两种细胞是（　　）

A. 成纤维细胞和巨噬细胞　　B. 巨噬细胞和浆细胞
C. 浆细胞和肥大细胞　　D. 肥大细胞和成纤维细胞
:::

:::callout{kind=insight label="解析"}
**【答案】C**

浆细胞分泌 IgE；肥大细胞（及血液嗜碱性粒细胞）膜上 Fc 受体结合 IgE，再遇抗原即脱颗粒，释放组胺、白三烯等，是速发型过敏的效应户头。成纤维细胞造纤维和基质；巨噬细胞主吞噬和抗原递呈，不是这道题的一对。
:::

:::callout{kind=note label="知识卡片：过敏两步"}
浆细胞出 IgE → 结合肥大细胞 → 再次抗原 → 脱颗粒。肥大细胞颗粒常呈异染性，含肝素、组胺。
:::

:::callout{kind=tip label="结论速记"}
过敏找 **浆细胞 + 肥大细胞**。
:::

### 第4题

:::callout{kind=note label="题目"}
构成细胞外基质蛋白多糖复合物主干的是（　　）

A. 透明质酸　　B. 蛋白质　　C. 糖胺多糖　　D. 硫酸软骨素
:::

:::callout{kind=insight label="解析"}
**【答案】A**

蛋白多糖单体是核心蛋白 + 糖胺多糖侧链（硫酸软骨素、硫酸角质素等）。许多单体再经连接蛋白挂到一条很长的**透明质酸**上，才成巨大复合物。B、C、D 都是构件，但不是这条「主干」。
:::

:::callout{kind=note label="知识卡片：基质两件"}
纤维：胶原、弹性、网状。无定形基质：蛋白多糖 + 糖蛋白。蛋白多糖复合物的中轴是透明质酸。
:::

:::callout{kind=tip label="结论速记"}
蛋白多糖复合物主干 = **透明质酸**。
:::

### 第5题

:::callout{kind=note label="题目"}
有粒和无粒白细胞的主要区别依据是（　　）

A. 有无嗜天青颗粒　　B. 有无特殊颗粒　　C. 核是否分叶　　D. 胞质的多少
:::

:::callout{kind=insight label="解析"}
**【答案】B**

有粒白细胞（中性、嗜酸、嗜碱）有**特殊颗粒**；无粒白细胞（淋巴、单核）没有特殊颗粒。两类都可以有嗜天青颗粒（溶酶体）。核分叶只见于部分粒细胞，不是分类尺子。
:::

:::callout{kind=tip label="结论速记"}
有粒 / 无粒看 **特殊颗粒**，不看嗜天青颗粒。
:::

### 第6题

:::callout{kind=note label="题目"}
血液中数量最多的白细胞是（　　）

A. 中性粒细胞　　B. 单核细胞　　C. 淋巴细胞　　D. 嗜酸性粒细胞
:::

:::callout{kind=insight label="解析"}
**【答案】A**

白细胞正常分类：中性粒细胞最多（约 $50\%\sim 70\%$），其次淋巴细胞，单核细胞再次，嗜酸、嗜碱最少。问「血细胞最多」才是红细胞。
:::

:::callout{kind=tip label="结论速记"}
白细胞最多 = **中性粒细胞**。
:::

### 第7题

:::callout{kind=note label="题目"}
骨陷窝和骨小管内有（　　）

A. 血管　　B. 神经　　C. 淋巴液　　D. 组织液
:::

:::callout{kind=insight label="解析"}
**【答案】D**

骨细胞胞体在骨陷窝，突起在骨小管，陷窝–小管系统充满组织液，靠它与中央管血管做物质交换。血管、神经走中央管和穿通管，不钻进骨小管。骨组织无淋巴管。
:::

:::callout{kind=tip label="结论速记"}
骨陷窝、骨小管里是 **组织液**（和骨细胞突起）。
:::

### 第8题

:::callout{kind=note label="题目"}
长骨骨干内的血管穿行于（　　）

A. 骨小管内　　B. 骨陷窝和穿通管内　　C. 骨小管和中央管内　　D. 中央管和穿通管内
:::

:::callout{kind=insight label="解析"}
**【答案】D**

哈佛系统中央管（纵行）与穿通管（Volkmann，横行）相通，管内有血管、神经。骨小管只容骨细胞突起和组织液，没有血管。
:::

:::callout{kind=note label="知识卡片：密质骨管道"}
中央管走骨单位长轴；穿通管横穿、连通中央管与骨髓腔／骨膜。骨小管是细胞突起的细管，不是血管床。
:::

:::callout{kind=tip label="结论速记"}
骨干血管走 **中央管 + 穿通管**。
:::

### 第9题

:::callout{kind=note label="题目"}
骨骼肌纤维的肌膜向胞质内凹陷形成（　　）

A. 终池　　B. 肌浆网　　C. 横小管　　D. 纵小管
:::

:::callout{kind=insight label="解析"}
**【答案】C**

横小管（T 管）是**肌膜**内陷，把兴奋传到三联体。肌浆网是肌细胞内的滑面内质网，其膨大末端为终池；纵小管指肌浆网沿长轴的部分。终池、纵小管都不是肌膜的凹陷。
:::

:::callout{kind=note label="知识卡片：骨骼肌三联体"}
一条横小管 + 两侧终池。人骨骼肌三联体多在 A–I 交界。心肌是二联体（一条 T 管 + 一侧终池），多在 Z 线水平。
:::

:::callout{kind=tip label="结论速记"}
肌膜内陷 = **横小管**；终池属于肌浆网。
:::

### 第10题

:::callout{kind=note label="题目"}
神经元尼氏体分布于（　　）

A. 胞体和轴突内　　B. 胞体和树突内　　C. 树突和轴突内　　D. 胞体内
:::

:::callout{kind=insight label="解析"}
**【答案】B**

尼氏体是强嗜碱性斑块，电镜下为粗面内质网 + 游离核糖体，在**胞体和树突**。轴丘和轴突没有，所以轴丘染色淡。只写「胞体内」漏了树突。
:::

:::callout{kind=note label="知识卡片：神经元胞质两件"}
尼氏体：RER + 核糖体，胞体和树突。神经原纤维：神经丝 + 微管，通达树突和轴突，参与运输。
:::

:::callout{kind=tip label="结论速记"}
尼氏体在 **胞体和树突**，不在轴突。
:::

### 第11题

:::callout{kind=note label="题目"}
视网膜由内向外可分为（　　）

A. 色素上皮层、视细胞层、双极细胞层和节细胞层
B. 节细胞层、视细胞层、双极细胞层和色素上皮层
C. 节细胞层、双极细胞层、视细胞层和色素上皮层
D. 色素上皮层、双极细胞层、视细胞层和节细胞层
:::

:::callout{kind=insight label="解析"}
**【答案】C**

「内」朝向玻璃体，「外」朝向脉络膜。简化四层由内向外：节细胞层 → 双极细胞层 → 视细胞层 → 色素上皮层。光线先过节细胞、双极，才到视杆／视锥；色素上皮最靠外，贴脉络膜。A、D 从色素上皮起笔，是由外向内。B 把视细胞和双极对调。
:::

:::callout{kind=note label="知识卡片：视网膜信息方向"}
光子：节细胞层一侧进来 → 视细胞换能。神经冲动：视细胞 → 双极细胞 → 节细胞，轴突汇成视神经。
:::

:::callout{kind=tip label="结论速记"}
由内向外：**节细胞 → 双极 → 视细胞 → 色素上皮**。
:::

### 第12题

:::callout{kind=note label="题目"}
听觉感受器位于（　　）

A. 盖膜　　B. 前庭膜　　C. 基底膜　　D. 骨螺旋板
:::

:::callout{kind=insight label="解析"}
**【答案】C**

螺旋器（Corti 器）坐在膜蜗管的**基底膜**上，由支持细胞和毛细胞构成，是听觉感受器。盖膜是盖在毛细胞静纤毛上方的胶状盖；前庭膜分隔膜蜗管与前庭阶；骨螺旋板是骨性支架。
:::

:::callout{kind=note label="知识卡片：膜蜗管三壁"}
上壁前庭膜，外侧壁血管纹，下壁基底膜 + 螺旋器。毛细胞游离面是**静纤毛**，不是动纤毛。
:::

:::callout{kind=tip label="结论速记"}
听觉感受器（螺旋器）在 **基底膜**。
:::

### 第13题

:::callout{kind=note label="题目"}
哪项不属于蒲肯野纤维的特点（　　）

A. 位于心室的心内膜下层　　B. 胞质中有丰富的粗面内质网
C. 细胞间有发达的缝隙连接　　D. 将冲动快速传到心室各处引发同步收缩
:::

:::callout{kind=insight label="解析"}
**【答案】B**（不属于）

蒲肯野纤维（教材亦作浦肯野纤维）是房室束及其分支的主细胞，在心室的心内膜下层和心肌膜。短粗、糖原和线粒体多、肌原纤维少，HE 浅染；细胞间闰盘发达，缝隙连接多，把冲动快速传开、心室同步收缩。丰富的粗面内质网是蛋白质分泌细胞的账，不是传导心肌的账。
:::

:::callout{kind=pitfall label="易错警示"}
心的蒲肯野纤维 ≠ 小脑皮质蒲肯野细胞。前者是特殊心肌，后者是神经元。
:::

:::callout{kind=tip label="结论速记"}
蒲肯野纤维：**浅染、糖原多、缝隙连接发达**；不是富 RER。
:::

### 第14题

:::callout{kind=note label="题目"}
弹性动脉是指（　　）

A. 大动脉　　B. 中动脉　　C. 小动脉　　D. 微动脉
:::

:::callout{kind=insight label="解析"}
**【答案】A**

大动脉（主动脉、肺动脉等）中膜弹性膜达 $40\sim 70$ 层，又称弹性动脉。中动脉是肌性动脉；小动脉、微动脉也以平滑肌为主，管径分层不同。
:::

:::callout{kind=tip label="结论速记"}
弹性动脉 = **大动脉**；中动脉是肌性动脉。
:::

### 第15题

:::callout{kind=note label="题目"}
毛和毛囊的生长点是（　　）

A. 上皮根鞘　　B. 毛球　　C. 毛乳头　　D. 毛根
:::

:::callout{kind=insight label="解析"}
**【答案】B**

毛球是毛和毛囊的**生长点**：毛母质细胞不断增殖，分化为毛根和上皮根鞘。毛乳头是突入毛球的结缔组织，含血管、神经，诱导并营养，本身不是上皮生长点。上皮根鞘、毛根是产物，不是生长点。
:::

:::callout{kind=tip label="结论速记"}
毛的生长点 = **毛球**（毛母质）；毛乳头是诱导／营养。
:::

### 第16题

:::callout{kind=note label="题目"}
人体皮肤的表皮由深至浅可分为（　　）

A. 基底层、透明层、棘层、颗粒层和角质层
B. 基底层、棘层、颗粒层、透明层和角质层
C. 基底层、颗粒层、棘层、透明层和角质层
D. 基底层、透明层、颗粒层、棘层和角质层
:::

:::callout{kind=insight label="解析"}
**【答案】B**

厚皮（手掌、足底）由深至浅：基底层 → 棘层 → 颗粒层 → 透明层 → 角质层。薄皮无透明层。A、C、D 把棘层、颗粒层、透明层的顺序打乱。
:::

:::callout{kind=note label="知识卡片：表皮五层职分"}
基底层有干细胞和黑素细胞；棘层有桥粒；颗粒层出现透明角质颗粒；透明层只在厚皮；角质层是角化的死细胞。
:::

:::callout{kind=tip label="结论速记"}
表皮深→浅：**基底 → 棘 → 颗粒 → 透明 → 角质**（透明层在厚皮）。
:::

### 第17题

:::callout{kind=note label="题目"}
甲状腺激素的贮存形式是（　　）

A. 甲状腺球蛋白　　B. 甲状腺球蛋白前体　　C. T3和T4　　D. 碘化的甲状腺球蛋白
:::

:::callout{kind=insight label="解析"}
**【答案】D**

滤泡上皮合成甲状腺球蛋白，分泌到滤泡腔后再碘化，以**碘化甲状腺球蛋白**（胶质）形式大量贮存。需要时重吸收入细胞，水解才放出 T3、T4。A 未碘化；C 是循环中的活性激素，不是滤泡腔贮存型；B 不是卷面户头。
:::

:::callout{kind=tip label="结论速记"}
甲状腺激素贮存型 = **碘化的甲状腺球蛋白**（胶质）。
:::

### 第18题

:::callout{kind=note label="题目"}
垂体嗜酸性细胞分泌（　　）

A. 催产素和生长激素　　B. 生长激素和催乳激素
C. 生长激素和促性腺激素　　D. 生长激素和促甲状腺激素
:::

:::callout{kind=insight label="解析"}
**【答案】B**

腺垂体远侧部嗜酸细胞：生长激素细胞 + 催乳激素细胞。嗜碱细胞才分泌 TSH、FSH、LH、ACTH。催产素（缩宫素）由下丘脑视上核／室旁核合成，神经垂体释放，不是腺垂体嗜酸细胞的产物。
:::

:::callout{kind=note label="知识卡片：远侧部三色"}
| 细胞 | 激素 |
|------|------|
| 嗜酸 | GH、PRL |
| 嗜碱 | TSH、FSH/LH、ACTH |
| 嫌色 | 多为前两类的脱颗粒或储备 |
:::

:::callout{kind=tip label="结论速记"}
垂体嗜酸细胞 → **GH + PRL**；催产素不在此户。
:::

### 第19题

:::callout{kind=note label="题目"}
肾上腺分泌糖皮质激素的主要是（　　）

A. 皮质球状带　　B. 皮质束状带　　C. 皮质网状带　　D. 髓质
:::

:::callout{kind=insight label="解析"}
**【答案】B**

### 第1题

:::callout{kind=note label="题目"}
血-脑屏障
:::

:::callout{kind=insight label="解析"}
**【答案】** 由脑毛细血管内皮细胞、基膜和神经胶质膜构成。脑的毛细血管属连续型，内皮细胞之间以紧密连接封闭，是血-脑屏障的主要结构。可阻止血液中某些物质进入脑组织，但能选择性让营养物质和代谢产物通过，以维持脑组织内环境相对稳定。

源卷表述如上。本版补充：神经胶质膜主要是星形胶质细胞的血管周足。连续内皮的紧密连接是最关键一层，不要写成「有孔内皮」。
:::

:::callout{kind=note label="知识卡片：三个血管屏障不要抄串"}
血–脑：连续内皮紧密连接 + 基膜 + 胶质足。血–胸腺：连续内皮 + 基膜 + 含巨噬细胞的周隙 + 上皮基膜 + 胸腺上皮突起。血–睾：最关键是支持细胞紧密连接。
:::

:::callout{kind=tip label="结论速记"}
血-脑屏障 = **连续内皮紧密连接** + 基膜 + 胶质膜；主闸在内皮。
:::

## 四、论述题（每题 5 分；卷面分值行写共 20 分）

源卷在四道计分论述之后另列第 5 题胎盘，按原文收入，不删。

### 第1题

:::callout{kind=note label="题目"}
试述运动终板的结构和功能机制。
:::

:::callout{kind=insight label="解析"}
**【答案】** 按源卷：结构先写清，再写乙酰胆碱耦联。

**结构**

脊髓前角或脑干的运动神经元长轴突抵达骨骼肌时失去髓鞘，反复分支；每一分支形成葡萄状终末，与骨骼肌纤维建立突触，该区呈椭圆形板状隆起，称运动终板（神经肌连接）。

电镜：肌纤维表面凹陷成浅槽，槽底肌膜即突触后膜，形成许多皱褶以增大面积。轴突终末（突触小体）嵌入浅槽，内有许多含乙酰胆碱的圆形突触小泡。

**机制**

神经冲动到达运动终板 → 乙酰胆碱释放 → 与突触后膜受体结合 → 改变肌膜两侧离子分布而产生兴奋 → 引发肌纤维收缩。
:::

:::callout{kind=note label="知识卡片：化学突触三部"}
突触前膜（终末、小泡）→ 间隙 → 突触后膜（受体、皱褶）。运动终板是骨骼肌上的化学突触，递质是乙酰胆碱。
:::

:::callout{kind=tip label="结论速记"}
运动终板：轴突终末嵌浅槽，ACh 对皱褶后膜，引发骨骼肌收缩。
:::

---

### 第2题

:::callout{kind=note label="题目"}
试比较淋巴结和脾结构上的同异。
:::

:::callout{kind=insight label="解析"}
**【答案】** 源卷对照如下，按项写，不要只写「都是淋巴器官」。

**相同**

表面都有结缔组织被膜；都含淋巴小结和副皮质区（弥散淋巴组织／T 区）；都含输出淋巴管。

**相异**

| | 淋巴结 | 脾 |
|--|--------|-----|
| 间皮 | 无 | 有 |
| 被膜和小梁 | 结缔组织 | 结缔组织和平滑肌 |
| 输入淋巴管 | 有 | 无 |
| 淋巴小结位置 | 有规律地在皮质浅层 | 散在于红髓之间（白髓） |
| 副皮质区 | 小结深层 | 小结一侧，即动脉周围淋巴鞘 |
| 血窦 | 无 | 有，血窦之间是脾索 |
| 淋巴窦 | 皮质和髓质内都有 | 无 |
:::

:::callout{kind=pitfall label="易错警示"}
脾过滤血液，淋巴结过滤淋巴。把脾写成「有输入淋巴管、有淋巴窦」，两本账就并户了。
:::

:::callout{kind=tip label="结论速记"}
淋巴结滤淋巴（有输入管和淋巴窦）；脾滤血（有血窦、无输入淋巴管）。
:::

### 第3题

:::callout{kind=note label="题目"}
试比较壁细胞与主细胞的结构和功能。
:::

:::callout{kind=insight label="解析"}
**【答案】** 源卷对照（胃底腺）：

| | 壁细胞 | 主细胞 |
|--|--------|--------|
| 分布 | 主要在胃底腺颈、体部 | 主要在胃底腺体部和底部 |
| 形态 | 圆形或三角形 | 矮柱状 |
| 胞质嗜色 | 嗜酸性 | 嗜碱性，核下更明显 |
| 核 | 1～2 个，位细胞中央 | 1 个，位于基部 |
| 功能 | 分泌盐酸和内因子 | 分泌胃蛋白酶原 |

电镜侧可补（源卷未强制）：壁细胞有内分泌小管和微管泡系统；主细胞有丰富粗面内质网和顶部酶原颗粒。答题先把光镜表和盐酸／内因子、胃蛋白酶原写全。
:::

:::callout{kind=tip label="结论速记"}
壁细胞：嗜酸，盐酸 + 内因子。主细胞：嗜碱，胃蛋白酶原。
:::

### 第4题

:::callout{kind=note label="题目"}
试述次级卵泡的结构。
:::

:::callout{kind=insight label="解析"}
**【答案】** 由初级卵泡继续发育形成。卵泡细胞增至 $6\sim 12$ 层，小腔隙融合成一个大腔，称卵泡腔，腔内充满卵泡液（含营养成分、雌激素和多种生物活性物质）。卵泡液增多、卵泡腔扩大后，初级卵母细胞、透明带、放射冠及部分卵泡细胞突入腔内形成卵丘；腔周数层卵泡细胞形成卵泡壁，称颗粒层，卵泡细胞改称颗粒细胞。

周围基质细胞向卵泡聚集形成卵泡膜，分两层：内层毛细血管丰富，基质细胞分化为多边形或梭形的膜细胞，具类固醇激素分泌细胞特征；外层有环行胶原纤维和平滑肌纤维。膜细胞合成雄激素，透过基膜，在颗粒细胞内转化为雌激素，故雌激素由两种细胞联合产生。少量进入卵泡液，大部分入血，作用于子宫等靶器官。

初级卵母细胞仍停在第一次成熟分裂双线期；出现卵泡腔才叫次级卵泡，不要和成熟卵泡（次级卵母、排卵前）并户。
:::

:::callout{kind=note label="知识卡片：卵泡升级"}
原始卵泡：初级卵母 + 单层扁平卵泡细胞。初级卵泡：卵泡细胞变立方／多层，出现透明带，尚无腔。次级卵泡：有卵泡腔、卵丘、颗粒层、卵泡膜。成熟卵泡：很大，第一次成熟分裂完成。
:::

:::callout{kind=tip label="结论速记"}
次级卵泡 = **卵泡腔 + 卵丘 + 颗粒层 + 两层卵泡膜**；雌激素 = 膜细胞雄激素 → 颗粒细胞转化。
:::

### 第5题

:::callout{kind=note label="题目"}
试述胎盘的形态结构和血液循环。
:::

:::callout{kind=insight label="解析"}
**【答案】** 源卷在论述栏另列本题。OCR「从密」按教材作**丛密**，「母体而」作**母体面**，「不相相混」作**不相混**。

**形态结构**

由胎儿的丛密绒毛膜与母体的基蜕膜共同组成的圆盘形结构，中央厚、周边薄。胎儿面光滑，覆羊膜，脐带附于中央或稍偏，透过羊膜可见放射状脐血管分支。母体面粗糙，为剥离后的基蜕膜，见 $15\sim 30$ 个由浅沟分隔的胎盘小叶。

垂直切面：羊膜下为绒毛膜结缔组织，脐血管分支行于其中。绒毛膜发出 $40\sim 60$ 根绒毛干，再发细小绒毛；绒毛干末端以细胞滋养层壳固着于基蜕膜。脐血管分支沿绒毛干进入绒毛，成毛细血管。绒毛干之间为绒毛间隙，基蜕膜短隔伸入其中，称胎盘隔，将胎盘分为 $15\sim 30$ 个小叶，每小叶含 $1\sim 4$ 根绒毛干及其分支。子宫螺旋动脉与子宫静脉开口于绒毛间隙，故间隙内充满母血，绒毛浸泡其中。

**血液循环**

胎盘内有母体和胎儿两套循环。母体动脉血由子宫螺旋动脉入绒毛间隙，与绒毛内毛细血管的胎儿血交换后，经子宫静脉回母体。胎儿静脉性质的血经脐动脉及其分支入绒毛毛细血管，与间隙内母血交换后成为动脉性质的血，经脐静脉回胎儿。两套血在各自封闭管道内循环，互不相混，但可进行物质交换。
:::

:::callout{kind=note label="知识卡片：胎盘膜"}
足月胎盘膜常为：合体滋养层 + 细胞滋养层及其基膜 + 薄层绒毛结缔组织 + 毛细血管基膜和内皮。不要把小肠绒毛的中央乳糜管写进胎盘。
:::

:::callout{kind=tip label="结论速记"}
胎盘 = **丛密绒毛膜 + 基蜕膜**；两套血不相混，母血在绒毛间隙。
:::

## 五、附加题：英译汉

肝细胞段。题目卡放英文原文（源卷用词保留，含 `quire`、`um`）；解析放源译文，不另撰译文。

### 第1题

:::callout{kind=note label="题目"}
将下列英文译为中文。

Hepatocytes are polygonal cells, about 20-30 um in size. The cell surfaces that are external, i.e. facing the sinusoids, take up about 35 % of the total surface area. The remaining cell surfaces are either in contact with the surface of an adjacent cell (55%) or facing a bile canaliculus (10%). The centrally located nucleus is spherical, with a prominent nucleolus and scattered chromatin granules. About 25% of the hepatocyte population are binucleate. The cytoplasm usually stains poorly, because stored glycogen and fat are dissolved out during tissue preparation, leaving behind irregular translucent spaces and vacuoles. There are abundant mitochondria: about 1,000-2,000 can be found in each liver cell. They are the major source of energy for the cell's metabolic activities. Golgi complexes are usually distributed around the nucleus, especially near bile canaliculi. About 50 or so may be found in each hepatocyte. Both rough and smooth endoplasmic reticulum are found in abundance. Rough endoplasmic reticulum usually congregates around the nucleus and mitochondria. Smooth endoplasmic reticulum is distributed throughout the cytoplasm and there are areas of continuity between it and the rough endoplasmic reticulum. Lysosomes are quire abundant and active. They are usually located near bile canaliculi and Golgi complexes. Microbodies are spherical organelles of variable sizes, which occur, in rather high concentrations. Inclusions such as glycogen particles, lipid droplets, and pigments may be present.
:::

:::callout{kind=insight label="解析"}
**【答案】** 以下为源卷译文，不另译。

肝细胞呈多面体形，直径约 $20\sim 30\,\mu\mathrm{m}$。向外的细胞表面如朝向血窦的表面约占细胞表面积的 $35\%$，其余的细胞表面与相邻的肝细胞接触（$55\%$）或者与胆小管接触（$10\%$）。肝细胞核居中，有一个很明显的核仁和散在的染色质颗粒，约有 $25\%$ 的肝细胞有双核。肝细胞的胞质染色浅，胞浆内储存的糖原和脂肪在切片制作过程中被溶解，留下不规则的透明空泡。每个肝细胞大约含有 $1{,}000\sim 2{,}000$ 个线粒体，是细胞新陈代谢的主要能量来源。高尔基复合体常分布在核周围，尤其是胆小管附近，每个细胞大约有 50 个左右的高尔基复合体。粗面内质网和滑面内质网都很丰富。粗面内质网常成群分布在核和线粒体周围，滑面内质网散在于整个细胞胞浆内，与粗面内质网相延续。溶酶体很丰富，功能旺盛，常靠近胆小管和高尔基复合体分布。圆形的微体大小不等，其密度很高。还有糖原颗粒、脂滴和色素颗粒等包含体分布于细胞内。
:::

:::callout{kind=note label="知识卡片：肝细胞三个面"}
血窦面约 $35\%$（微绒毛伸入窦周隙）、邻接面约 $55\%$、胆小管面约 $10\%$。线粒体、高尔基、溶酶体偏向胆小管一侧，是分泌和排泄的形态学提示。
:::

:::callout{kind=tip label="结论速记"}
肝细胞：多面体，$20\sim 30\,\mu\mathrm{m}$；面部分血窦 $35\%$／邻接 $55\%$／胆小管 $10\%$；约 $25\%$ 双核。译文以源卷为准。
:::
