## 一、高频名词解释（各词只写一次）

### 第2题

:::callout{kind=note label="题目"}
气–血屏障 / blood-air barrier / air-blood barrier（06 五年制、09／10 英护、12／13／16 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

肺泡腔 $\mathrm{O}_2$ 与肺泡隔毛细血管 $\mathrm{CO}_2$ 交换所经过的最薄路径：肺泡表面液体层、Ⅰ型肺泡细胞及其基膜、薄层结缔组织（可缺如）、连续毛细血管内皮及其基膜。总厚度 $0.2\sim 0.5\,\mu\mathrm{m}$。
:::

:::callout{kind=pitfall label="易错警示"}
不是整层肺泡隔，也不含Ⅱ型细胞、尘细胞。Ⅰ型覆盖约 $95\%$ 表面积才是上皮主体。
:::

:::callout{kind=tip label="结论速记"}
气–血屏障 = **液体层 + Ⅰ型及基膜 +（可无的薄层结缔组织）+ 连续内皮及基膜**，$0.2\sim 0.5\,\mu\mathrm{m}$。
:::

### 第3题

:::callout{kind=note label="题目"}
肌节 / sarcomere / sacromere（源拼写）（06 五年制、09 临床、09／10 药学、10 英护、13 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

相邻两条 Z 线之间的一段肌原纤维，是骨骼肌／心肌收缩的基本结构单位。组成为 $\tfrac{1}{2}\mathrm{I} + \mathrm{A} + \tfrac{1}{2}\mathrm{I}$。
:::

:::callout{kind=note label="知识卡片：带区"}
I 带只有细肌丝；A 带有粗细重叠；H 带／M 线区只有粗肌丝。横小管是肌膜内陷，不是肌节本身。
:::

:::callout{kind=tip label="结论速记"}
肌节 = **两 Z 线之间** = $1/2\,\mathrm{I}+\mathrm{A}+1/2\,\mathrm{I}$。
:::

### 第4题

:::callout{kind=note label="题目"}
月经周期（几乎每年：06–18 临床／护理／英护）
:::

:::callout{kind=insight label="解析"}
**【答案】**

自青春期起，子宫内膜**功能层**在卵巢激素作用下，大约每 28 天发生剥脱出血、增生修复的周期性变化。典型分月经期、增生期、分泌期。
:::

:::callout{kind=note label="知识卡片：和卵巢对齐"}
排卵约在周期第 14 天，内膜处于**增生晚期**（源部分卷面如此）。分泌期对应黄体期。基底层不脱落。
:::

:::callout{kind=tip label="结论速记"}
月经周期改的是**功能层**，听卵巢的雌激素／孕激素。
:::

### 第5题

:::callout{kind=note label="题目"}
门管区 / portal area（06 五年制、08 护理、10 药学／英护、16 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

相邻几个肝小叶之间的结缔组织区。内含小叶间动脉（肝动脉分支）、小叶间静脉（门静脉分支）、小叶间胆管（单层立方或柱状上皮）。
:::

:::callout{kind=pitfall label="易错警示"}
小叶下静脉在小叶外独自走，**不在**门管区三联里。中央静脉在小叶轴心。
:::

:::callout{kind=tip label="结论速记"}
门管区三联：**小叶间动、静脉 + 小叶间胆管**。
:::

### 第6题

:::callout{kind=note label="题目"}
胎盘膜 / 胎盘屏障（06 五年制、08 临床／预防、17 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

胎儿血与母体血交换所通过的结构，两套血不相混。早期：合体滋养层、细胞滋养层及基膜、薄层绒毛结缔组织、毛细血管基膜与内皮。后期许多部位细胞滋养层消失，屏障变薄，主要剩绒毛毛细血管内皮、薄层合体滋养层及二者基膜。
:::

:::callout{kind=tip label="结论速记"}
胎盘膜隔开两套血；后期变薄，**不是**母血灌进脐静脉。
:::

### 第7题

:::callout{kind=note label="题目"}
闰盘（07 临床、09 补考／药学、02 试题卷亦见）
:::

:::callout{kind=insight label="解析"}
**【答案】**

相邻心肌纤维的连接处，光镜下呈深染阶梯状横线，位于 Z 线水平。横位有中间连接和桥粒（机械），纵位有缝隙连接（电耦联），使心肌成为功能合胞体。
:::

:::callout{kind=tip label="结论速记"}
闰盘在 **Z 线**；横位铆住、纵位同步。
:::

### 第8题

:::callout{kind=note label="题目"}
窦周隙（07 临床、10／11 临床、理论试卷 1 亦见）
:::

:::callout{kind=insight label="解析"}
**【答案】**

肝细胞与血窦内皮之间的狭窄间隙。含血浆、贮脂细胞、网状纤维、肝细胞微绒毛，是肝细胞与血液物质交换的场所。
:::

:::callout{kind=pitfall label="易错警示"}
Kupffer 细胞在血窦腔内贴内皮，**不在**窦周隙。胆小管在相邻肝细胞之间。
:::

:::callout{kind=tip label="结论速记"}
窦周隙 = 内皮与肝细胞之间的血浆缝，贮脂细胞住在这里。
:::

### 第9题

:::callout{kind=note label="题目"}
原条（07 临床、06 护理、09 补考、10／13／16 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

第 3 周初，上胚层细胞向胚盘一端中线迁移，聚成一条纵行细胞柱，该端为尾端。原条决定头尾；迁出的细胞形成胚内中胚层并置换下胚层成为内胚层，剩余上胚层改称外胚层。
:::

:::callout{kind=note label="知识卡片：三胚层都出自上胚层"}
下胚层会被换掉，不是「下胚层＝内胚层」的简单改名。体蒂不是原条。
:::

:::callout{kind=tip label="结论速记"}
原条在**上胚层尾端中线**；三个胚层都起源于上胚层。
:::

### 第10题

:::callout{kind=note label="题目"}
垂体门脉系统（07 临床、06 护理、11 临床、13 中西医）
:::

:::callout{kind=insight label="解析"}
**【答案】**

下丘脑促垂体区神经元的轴突终于漏斗，激素入垂体上动脉在漏斗形成的第一级毛细血管网，再经门微静脉到腺垂体远侧部第二级毛细血管网，调节嗜酸／嗜碱性细胞。
:::

:::callout{kind=tip label="结论速记"}
下丘脑管腺垂体：靠**垂体门脉**，不是神经垂体那对核团的轴突。
:::

### 第11题

:::callout{kind=note label="题目"}
中央乳糜管 / central lacteal（理论试卷 2、09 临床、09 英护、11／13 药学）
:::

:::callout{kind=insight label="解析"}
**【答案】**

小肠绒毛中轴固有层内的毛细淋巴管。内皮间隙大、无基膜，吸收的脂肪主要经此转运。
:::

:::callout{kind=tip label="结论速记"}
中央乳糜管在**绒毛中轴**，走脂肪。
:::

### 第12题

:::callout{kind=note label="题目"}
滤过屏障（02 含答案卷、08 护理、09／10 药学）
:::

:::callout{kind=insight label="解析"}
**【答案】**

肾小体有孔毛细血管内皮、基膜、足细胞裂孔膜三层。正常时血细胞和大分子蛋白不能进入肾小囊腔。
:::

:::callout{kind=pitfall label="易错警示"}
形成原尿的结构是**肾小体**（滤过），不是肾小管（重吸收）。源个别卷把「原尿」标成肾小管，按教材改，并在整卷解析里标明。
:::

:::callout{kind=tip label="结论速记"}
滤过屏障三件套：**有孔内皮 + 基膜 + 裂孔膜**。
:::

### 第13题

:::callout{kind=note label="题目"}
获能与精子形成 / spermiogenesis（09 临床、12／13 临床、18 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

**精子形成（spermiogenesis）**：圆形精子细胞变成蝌蚪形精子（核浓缩、顶体、排多余胞质、长出尾）。

**获能**：精子在女性生殖管道内去掉头部表面抑制性糖蛋白，获得受精能力。运动能力在附睾已具备，获能不是「开始会游」。
:::

:::callout{kind=tip label="结论速记"}
spermiogenesis 是变形；获能是在**女性管道**去掉抑制蛋白。
:::

### 第14题

:::callout{kind=note label="题目"}
血–睾屏障（09 补考、08 护理写「血尿」则是另一词）
:::

:::callout{kind=insight label="解析"}
**【答案】**

最重要的是支持细胞近基部的紧密连接，把生精上皮分成基底室与近腔室。保护精子发生、维持局部高雄激素微环境。
:::

:::callout{kind=tip label="结论速记"}
血–睾屏障的主墙是**支持细胞紧密连接**，不是内皮。
:::

### 第15题

:::callout{kind=note label="题目"}
动脉周围淋巴鞘（09 补考／药学、10／12／13 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

脾白髓中包绕中央动脉的弥散淋巴组织，以 T 细胞为主，相当于淋巴结的副皮质区（胸腺依赖区）。

:::callout{kind=tip label="结论速记"}
PALS = 脾的 **T 区**，围着中央动脉。

### 第16题

:::callout{kind=note label="题目"}
心内膜垫（12／13／16／17／18 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

房室管背、腹侧心内膜下组织增厚形成的垫状隆起，对向生长融合，参与分隔心房与心室，并参与膜性室间隔、房间隔的封闭。

### 第17题

:::callout{kind=note label="题目"}
卵裂（13 中西医、16／18 临床、07 护理名解）
:::

:::callout{kind=insight label="解析"}
**【答案】**

:::callout{kind=tip label="结论速记"}
卵裂：**数目↑、总体积不涨**，被透明带箍着。
:::

## 二、高频论述（按考点合并）

### 第19题

:::callout{kind=note label="题目"}
比较周围与中枢有髓／无髓神经纤维（06 五年制、07 临床、08 护理、10 药学、11 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

| | 周围有髓 | 中枢有髓 | 周围无髓 | 中枢无髓 |
|--|----------|----------|----------|----------|
| 髓鞘细胞 | 施万细胞整段包一卷 | 少突胶质细胞多个突起各包一段 | 无典型髓鞘 | 轴突基本裸露 |
| 郎飞结 | 结间体清楚 | 有，结间较短 | 无 | 无 |
| 一对多 | 1 个施万细胞包 1 段 1 根轴突 | 1 个少突可包多根 | 1 个施万细胞凹陷可裹多根轴突 | — |

化学成分以髓磷脂为主。跳跃传导发生在郎飞结。
:::

:::callout{kind=tip label="结论速记"}
周围有髓找**施万**，中枢有髓找**少突**；中枢无髓是裸轴突。
:::

### 第20题

:::callout{kind=note label="题目"}
淋巴结与脾的光镜异同（06 五年制、09／10 药学、理论试卷 2）
:::

:::callout{kind=insight label="解析"}
**【答案】**

**同**：结缔组织被膜 + 小梁；都有淋巴小结（B）和胸腺依赖区（T）；都有巨噬细胞。

| | 淋巴结 | 脾 |
|--|--------|-----|
| 被膜 | 致密结缔组织，有输入淋巴管 | 致密结缔组织 + 平滑肌，表面有间皮，无输入淋巴管 |
| 小结位置 | 浅层皮质，帽朝向被膜侧 | 白髓，散在红髓之间 |
| T 区 | 副皮质区在小结深面 | 动脉周围淋巴鞘在小结一侧 |
| 窦 | 淋巴窦 | 血窦；脾索含血 |
:::

:::callout{kind=tip label="结论速记"}
淋巴结滤**淋巴**（有输入管），脾滤**血**（有血窦、无输入淋巴管）。
:::

### 第21题

:::callout{kind=note label="题目"}
精子发生 vs 卵子发生（06 五年制、07 临床、08 临床、12／13 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

| | 精子发生 | 卵子发生 |
|--|----------|----------|
| 起止 | 青春期起，在睾丸内完成 | 胚胎期已开始；排卵出次级卵母细胞（MII），受精才完成第二次成熟分裂 |
| 场所 | 一个器官（睾丸生精小管） | 卵巢 + 输卵管（两个器官） |
| 产物 | 1 个初级精母细胞 → 4 个精子 | 1 个初级卵母细胞 → 1 个卵细胞 + 极体 |
| 形态 | 有精子形成（变形） | 体积变化大，无蝌蚪变形 |
| 周期 | 生精小管上皮有周期／节段 | 无与精子相同的上皮周期 |
| 保护 | 血–睾屏障、低于体温 2–3 ℃、高雄激素 | 透明带、放射冠 |

源 07 护理把「过程」拆成：精原细胞（A/B）→ 初级精母（4n，最大）→ 次级 → 精子细胞 → 变形。
:::

:::callout{kind=tip label="结论速记"}
精子：一器官、4 个、要变形。卵子：两器官、1 个、受精才走完 MII。
:::

### 第22题

:::callout{kind=note label="题目"}
近曲小管 vs 远曲小管（几乎每年，含 07 护理 12 分表）
:::

:::callout{kind=insight label="解析"}
**【答案】**

| | 近曲 | 远曲 |
|--|------|------|
| 细胞 | 单层大立方，界限不清 | 单层小立方，界限较清 |
| 胞质 | 强嗜酸 | 弱嗜酸 |
| 核 | 近基底 | 近游离面 |
| 游离面 | 刷状缘明显 | 无／不明显 |
| 基底纵纹 | 不清楚 | 清楚 |
| 功能 | 重吸收主战场（葡萄糖、氨基酸、大部分水盐） | 受醛固酮／ADH 微调 |

髓袢细段对水不通透的是**远直小管升支粗段**一侧的教材表述：远直小管（升支粗段）对水不通透。源理论试卷 1 选「远直小管」。
:::

:::callout{kind=tip label="结论速记"}
近曲：**大、红、刷状缘、界不清**。远曲：小、淡、纵纹清。
:::

### 第23题

:::callout{kind=note label="题目"}
神经外胚层／神经管发生；无脑儿与脊柱裂（06 五年制、09 临床、05 级 A 卷识图）
:::

:::callout{kind=insight label="解析"}
**【答案】**

脊索诱导外胚层增厚 → 神经板 → 神经沟 + 神经褶 → 神经管（中段先闭，头尾留前、后神经孔）。神经嵴是周围神经等的原基。

- **无脑儿**：前神经孔未闭。
- **脊柱裂**：后神经孔未闭／尾端神经褶未愈合，神经管开放。
:::

:::callout{kind=tip label="结论速记"}
前孔不闭 → 无脑；后孔不闭 → 脊柱裂。
:::

### 第24题

:::callout{kind=note label="题目"}
浆细胞的光镜、超微结构及功能（10 药学有较完整源答案、09 药学、10 英护）
:::

:::callout{kind=insight label="解析"}
**【答案】**

光镜：圆或卵圆；核偏位，异染色质车轮状；胞质强嗜碱，核旁浅染区。

电镜：大量粗面内质网；浅染区是高尔基复合体和中心体。

功能：合成并分泌免疫球蛋白（抗体）。
:::

:::callout{kind=tip label="结论速记"}
浆细胞 = **车轮核 + 嗜碱胞质 + 核旁浅染（高尔基）** → 抗体。

### 第25题

:::callout{kind=note label="题目"}
肝血窦的结构与功能（10 药学、09 药学）
:::

:::callout{kind=insight label="解析"}
**【答案】**

位于肝板之间，腔大不规则。内皮有窗孔、无隔膜，内皮间隙大，**无基膜**，通透性极高。窦腔有肝巨噬细胞（Kupffer）和大颗粒淋巴细胞（NK）。血浆大分子可进窦周隙与肝细胞交换。
:::

:::callout{kind=tip label="结论速记"}
肝血窦：**有孔、无基膜、有 Kupffer**；通透性在全身血窦里极高。
:::

### 第26题

:::callout{kind=note label="题目"}
肺泡结构与功能；Ⅱ型肺泡细胞（08 临床、09 英护）
:::

:::callout{kind=insight label="解析"}
**【答案】**

肺泡是气体交换单位。Ⅰ型扁平，覆盖约 $95\%$ 表面积，构成气–血屏障上皮。Ⅱ型立方形，约占 $5\%$，含嗜锇性板层小体，分泌表面活性物质降低表面张力，并可增殖补充Ⅰ型。隔内有弹性纤维、肺巨噬细胞（尘细胞）。
:::

:::callout{kind=pitfall label="易错警示"}
吞噬粉尘的是肺巨噬细胞／Ⅰ型的吞饮转运，不是Ⅱ型的主职。源 05 卷「Ⅱ型可吞噬微小粉尘」标为**错误**。
:::

:::callout{kind=tip label="结论速记"}
Ⅰ型换气，Ⅱ型产表面活性物质并补位。
:::

### 第27题

:::callout{kind=note label="题目"}
化学性突触（06 护理、08 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

神经元与神经元或效应细胞之间的细胞连接。分突触前成分（突触小泡、突触前膜）、突触间隙、突触后成分（受体、突触后膜）。冲动到前膜 → 递质出胞 → 后膜受体。运动终板是轴突与骨骼肌的化学性突触。
:::

:::callout{kind=tip label="结论速记"}
认突触前，先找**突触小泡**。
:::

### 第28题

:::callout{kind=note label="题目"}
心房分隔与卵圆孔未闭（07／08／09／10／13／16／17／18 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

第一房间隔头端长向心内膜垫，二者之间是第一房间孔；隔上吸收出第二房间孔。第二房间隔从右侧盖下来，留下卵圆孔，左侧第一隔作瓣。出生后肺循环建立，瓣贴死成卵圆窝。

未闭常见原因：卵圆孔瓣穿孔／吸收；第一隔吸收过多（第二孔过大）；第二隔发育不足（卵圆孔过大）；或合并心内膜垫发育不全致第一孔型缺损。
:::

:::callout{kind=tip label="结论速记"}
卵圆孔未闭：瓣破了、第一隔吸太多、或第二隔太短。
:::

### 第29题

:::callout{kind=note label="题目"}
透明软骨 vs 骨组织（07 临床；理论试卷 1 只问透明软骨光镜）
:::

:::callout{kind=insight label="解析"}
**【答案】**

**同**：细胞住在陷窝里；基质含胶原；都可由中胚层来的细胞发生。

**异**：透明软骨基质不钙化，纤维是胶原原纤维（光镜难见），有同源细胞群和软骨囊，软骨内无血管。骨基质钙化，有骨单位／骨板、骨小管互通，血管走中央管和穿通管。
:::

:::callout{kind=tip label="结论速记"}
透明软骨：**无血管、不钙化、同源细胞群**。骨：钙化 + 管道系统。
:::

### 第30题

:::callout{kind=note label="题目"}
巨噬细胞（05 级 A 卷问答、09 临床电镜）
:::

:::callout{kind=insight label="解析"}
**【答案】**

来自单核细胞。光镜：形态不规则，胞质嗜酸，可含异物颗粒／空泡，核小、偏位。电镜：溶酶体、吞噬体、微丝微管，表面有皱褶和突起。功能：吞噬、抗原呈递、分泌细胞因子。肝血窦里胞体仍在管腔的是肝巨噬细胞。
:::

:::callout{kind=tip label="结论速记"}
巨噬细胞：**嗜酸、核偏、会走会呈递**；肝里那只还站在血窦腔。
:::

### 第31题

:::callout{kind=note label="题目"}
次级卵泡（02 含答案卷、10 药学）
:::

:::callout{kind=insight label="解析"}
**【答案】**

卵泡细胞增至多层，出现卵泡腔与卵泡液；初级卵母细胞 + 透明带 + 放射冠被挤成卵丘；壁为颗粒层；卵泡膜分内层（膜细胞，产雄激素）和外层（纤维 + 平滑肌）。雌激素由膜细胞雄激素 + 颗粒细胞芳香化而来。初级卵母细胞仍停在第一次成熟分裂前期。
:::

:::callout{kind=tip label="结论速记"}
次级卵泡 = **有腔 + 卵丘 + 两层卵泡膜**；卵母细胞还没排卵。
:::

### 第32题

:::callout{kind=note label="题目"}
运动终板（05 级名解、13 临床画图、13 药学）
:::

:::callout{kind=insight label="解析"}
**【答案】**

脊髓前角或脑干运动神经元轴突抵达骨骼肌后失髓鞘、反复分支，与肌纤维形成椭圆形板状化学性突触。电镜：肌膜凹陷成浅槽并形成皱褶（突触后膜），终末内有含乙酰胆碱的圆形突触小泡。一条骨骼肌纤维通常只接受一个轴突分支。
:::

:::callout{kind=tip label="结论速记"}
运动终板 = 轴突终末 × 骨骼肌，递质是 **ACh**。
:::

### 第33题

:::callout{kind=note label="题目"}
子宫内膜分泌期（09 补考、17 临床）
:::

:::callout{kind=insight label="解析"}
**【答案】**

排卵后黄体分泌孕激素（及雌激素），功能层继续增厚；子宫腺弯曲、分泌（含糖原）；螺旋动脉增长更弯；基质细胞肥大、水肿。对应卵巢黄体期。若未受精，黄体退化为白体，螺旋动脉痉挛 → 月经期。

分泌期 = **黄体期**；腺弯、血管弯、基质水肿。

### 第34题

:::callout{kind=note label="题目"}
被覆上皮的一般特征及分类（07 护理问答）
:::

:::callout{kind=insight label="解析"}
**【答案】**

特征：细胞多、间隙少、有极性；基膜；神经末梢丰富；一般**无血管**。

分类：单层（扁平、立方、柱状、假复层纤毛柱状）；复层（扁平、变移）。内皮衬心血管淋巴管，间皮衬浆膜腔，都是单层扁平但户头不同。
:::

:::callout{kind=tip label="结论速记"}
上皮：**有极性、有基膜、没血管**。肾小囊壁层是单层扁平，不叫内皮。
:::
