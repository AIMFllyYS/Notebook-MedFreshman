## 一、A 类选择题

### 第1题

:::callout{kind=note label="题目"}
分泌弹性蛋白的细胞（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】成纤维细胞**（源回忆）

成纤维细胞是疏松结缔组织中数目最多的细胞，合成并分泌胶原蛋白、弹性蛋白和无定形基质。Ⅰ型胶原构成胶原纤维，Ⅲ型构成网状纤维，弹性蛋白构成弹性纤维核心。大动脉中膜平滑肌也能产弹性蛋白，本场残句按结缔组织主户给成纤维细胞。
:::

:::callout{kind=note label="知识卡片：弹性纤维两件"}
核心是均质弹性蛋白，外周是原纤维蛋白微原纤维（约 $10\,\mathrm{nm}$）。HE 淡红，醛复红染成紫色。牵拉能伸、去力能卷回去。
:::

:::callout{kind=tip label="结论速记"}
弹性蛋白主场：**成纤维细胞**。
:::

### 第2题

:::callout{kind=note label="题目"}
外胚层形成（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】表皮**（源回忆）

表面外胚层分化为表皮及附属器、角膜上皮、晶状体、内耳膜迷路、腺垂体等。神经板→神经管走脑、脊髓、视网膜；神经嵴走周围神经。残句只收回「表皮」，不要把中胚层的真皮写进来。
:::

:::callout{kind=note label="知识卡片：外胚层两本账"}
| 分支 | 去向 |
|------|------|
| 神经外胚层 | 神经管、神经嵴 |
| 表面外胚层 | 表皮及皮肤附属器等 |
:::

:::callout{kind=tip label="结论速记"}
外胚层形成 **表皮**（残句）；真皮不是外胚层。
:::

### 第3题

:::callout{kind=note label="题目"}
肾小囊壁层的上皮是（　　）

A. 内皮　　B. 间皮　　C. 单层扁平上皮　　D. 单层柱状上皮
:::

:::callout{kind=insight label="解析"}
**【答案】C. 单层扁平上皮**（源回忆标 A）

肾小囊外层（壁层）是单层扁平上皮，内层（脏层）是足细胞。内皮专指心血管和淋巴管腔面的单层扁平上皮；间皮专指胸膜、腹膜、心包膜表面。肺泡和肾小囊壁层也是单层扁平，**不叫**内皮或间皮。
:::

:::callout{kind=pitfall label="易错警示"}
源回忆把本题标成 A（内皮）。形状都是扁平，户头不同：管腔写内皮，浆膜写间皮，肾小囊壁层只写单层扁平。
:::

:::callout{kind=tip label="结论速记"}
肾小囊壁层 = **单层扁平上皮**，不是内皮。
:::

### 第4题

:::callout{kind=note label="题目"}
分泌房水（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】睫状体的非色素上皮**（源回忆）

睫状突被覆两层上皮：外层色素上皮、内层非色素上皮。非色素上皮分泌房水。房水营养晶状体和角膜、维持眼压；回流受阻是青光眼，不是白内障。
:::

:::callout{kind=note label="知识卡片：房水回路"}
睫状体非色素上皮产房水 → 后房 → 瞳孔 → 前房 → 前房角小梁网 → 巩膜静脉窦入血。
:::

:::callout{kind=tip label="结论速记"}
房水出自 **睫状体非色素上皮**。
:::

### 第5题

:::callout{kind=note label="题目"}
胸腺上皮细胞（不可以转换成胸腺细胞）
:::

:::callout{kind=insight label="解析"}
**【答案】不可以转换成胸腺细胞**（源回忆）

胸腺上皮细胞（上皮性网状细胞）来自咽囊内胚层，搭支架、表达 MHC、分泌胸腺素／胸腺肽／胸腺生成素。胸腺细胞是骨髓来的淋巴干细胞在胸腺内的 T 细胞前体。两户来源不同，上皮细胞不能变成胸腺细胞。
:::

:::callout{kind=note label="知识卡片：胸腺两群细胞"}
| | 胸腺上皮细胞 | 胸腺细胞 |
|--|--------------|----------|
| 来源 | 咽囊内胚层 | 骨髓淋巴干细胞 |
| 职分 | 微环境、选择、分泌 | 发育中的 T 细胞 |
| 皮质占比 | 支架 | $85\%\sim 90\%$ |
:::

:::callout{kind=tip label="结论速记"}
胸腺上皮细胞 **不能** 转成胸腺细胞。
:::

### 第6题

:::callout{kind=note label="题目"}
下列无丰富血窦的是（　　）

A. 甲状腺　　B. 肾上腺　　C. 垂体　　D. 肝　　E. 脾
:::

:::callout{kind=insight label="解析"}
**【答案】A. 甲状腺**（源回忆）

血窦腔大不规则，内皮间隙大，基膜不连续或缺如。肝、脾、骨髓和部分内分泌腺（肾上腺、垂体）有丰富血窦。甲状腺以滤泡为结构单位，滤泡之间是有孔毛细血管，不算「丰富血窦」。
:::

:::callout{kind=note label="知识卡片：毛细血管三型"}
连续型（肌、结缔、中枢）；有孔型（胃肠黏膜、肾血管球、多数内分泌腺）；血窦（肝、脾、骨髓、部分内分泌腺）。
:::

:::callout{kind=tip label="结论速记"}
无丰富血窦：**甲状腺**。
:::

### 第7题

:::callout{kind=note label="题目"}
胞浆含嗜碱性颗粒（　　）

A. 肥大细胞　　B. 成纤维细胞　　C. 巨噬细胞　　D. 浆细胞
:::

:::callout{kind=insight label="解析"}
**【答案】A. 肥大细胞**（源回忆）

肥大细胞胞质充满粗大嗜碱性颗粒，常呈异染性，含肝素、组胺、白三烯等。浆细胞胞质嗜碱是因为粗面内质网，**不是颗粒**。巨噬细胞胞质多嗜酸，可含异物和空泡。成纤维细胞无这类颗粒。
:::

:::callout{kind=note label="知识卡片：结缔组织细胞颜色"}
| 细胞 | 嗜色落点 |
|------|----------|
| 肥大细胞 | 粗大嗜碱／异染颗粒 |
| 浆细胞 | 胞质嗜碱（RER），核旁浅染区是高尔基 |
| 巨噬细胞 | 胞质嗜酸，溶酶体多 |
:::

:::callout{kind=tip label="结论速记"}
嗜碱性颗粒找 **肥大细胞**；浆细胞嗜碱的是内质网。
:::

### 第8题

:::callout{kind=note label="题目"}
子宫腺分泌（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】糖原**（源回忆）

子宫腺是内膜上皮陷入固有层的单管或分支管状腺。增生晚期核下区糖原集聚；分泌期糖原转到核上区，顶浆分泌入腺腔，腔内充满含糖原的黏稠液体，为胚泡着床备粮。
:::

:::callout{kind=note label="知识卡片：内膜三期腺体"}
增生期：腺短直→增长弯曲。分泌期：腺更弯、腔扩大、糖原顶浆分泌。月经期：分泌停止，功能层脱落。
:::

:::callout{kind=tip label="结论速记"}
子宫腺分泌 **糖原**（分泌期顶浆排出）。
:::

### 第9题

:::callout{kind=note label="题目"}
关于螺旋器哪个是错的（　　）

A. 基底膜上　　B. 由支持细胞和毛细胞构成　　C. 毛细胞上面有排列整齐的动纤毛　　D. 内隧道形成连续整体
:::

:::callout{kind=insight label="解析"}
**【答案】C**（源回忆）

螺旋器（Corti 器）在膜蜗管基底膜上，由支持细胞（柱细胞、指细胞）和毛细胞组成。内、外柱细胞围成三角形内隧道，沿螺旋连续。毛细胞游离面是 **静纤毛**（阶梯状；外毛细胞较长者插入盖膜），不是动纤毛。动纤毛（kinocilium）是前庭毛细胞的标志；螺旋器毛细胞成体无动纤毛。
:::

:::callout{kind=note label="知识卡片：静纤毛 vs 动纤毛"}
静纤毛本质是微绒毛（微丝）；动纤毛／纤毛骨架是微管 $9+2$。螺旋器感音靠静纤毛弯，不靠纤毛摆动。
:::

:::callout{kind=tip label="结论速记"}
螺旋器毛细胞是 **静纤毛**，写动纤毛就错。
:::

### 第10题

:::callout{kind=note label="题目"}
关于子宫哪个是错的（　　）

A. 月经期螺旋动脉持续收缩
:::

:::callout{kind=insight label="解析"}
**【答案】A 是错项**（源回忆；其余选项未记）

月经期黄体退化，雌、孕激素骤降：功能层螺旋动脉**先**持续性收缩 → 内膜缺血坏死；**继而突然短暂扩张** → 血管破裂出血，与坏死内膜一同脱落。只写「持续收缩」漏掉扩张出血，所以该叙述错误。基底层螺旋动脉不参与脱落。
:::

:::callout{kind=pitfall label="易错警示"}
收缩造成缺血，扩张造成出血。两步都要，不能把月经期写成「动脉一直缩着」。
:::

:::callout{kind=tip label="结论速记"}
月经期螺旋动脉：**先缩后扩**，不是一直缩。
:::

### 第11题

:::callout{kind=note label="题目"}
下颌下腺正确的是（混合性腺，黏液性为主）
:::

:::callout{kind=insight label="解析"}
**【答案】混合性腺，浆液性为主**（源回忆写「黏液性为主」，不准确）

三大唾液腺：腮腺纯浆液；下颌下腺混合、**浆液性腺泡较多**；舌下腺混合、**黏液性为主**。源回忆把下颌下腺和舌下腺的主次写反。
:::

:::callout{kind=note label="知识卡片：大唾液腺三户"}
| 腺 | 性质 |
|----|------|
| 腮腺 | 浆液性腺 |
| 下颌下腺 | 混合腺，浆液为主，可见浆半月 |
| 舌下腺 | 混合腺，黏液为主 |
:::

:::callout{kind=tip label="结论速记"}
下颌下腺 = **混合、浆液为主**；黏液为主是舌下腺。
:::

### 第12题

:::callout{kind=note label="题目"}
皮肤具有一定的弹性韧性，相关结构（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】真皮网织层**（源回忆）

真皮分乳头层和网织层，二者无明确界限。乳头层纤维细、突向表皮，管连接面积和营养。网织层胶原束粗大交织、弹性纤维多，把皮肤的韧性和弹性写在这里。
:::

:::callout{kind=note label="知识卡片：皮肤三层职分"}
表皮：角化复层扁平，无血管。真皮乳头层：毛细血管、触觉小体。真皮网织层：粗胶原 + 弹性纤维。皮下：疏松结缔 + 脂肪。
:::

:::callout{kind=tip label="结论速记"}
皮肤弹性韧性 → **真皮网织层**。
:::

### 第13题

:::callout{kind=note label="题目"}
没有横纹的是（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】平滑肌纤维**（源回忆）

骨骼肌、心肌有明暗相间的横纹，属横纹肌。平滑肌无肌原纤维的规则排列，光镜下无横纹。心肌有横纹和闰盘，不要写成「心肌没有横纹」。
:::

:::callout{kind=note label="知识卡片：三种肌纤维"}
| | 横纹 | 核 | 连接 |
|--|------|----|------|
| 骨骼肌 | 有 | 周边多核 | 无缝隙连接 |
| 心肌 | 有 | 中央 1～2 核 | 闰盘（含缝隙连接） |
| 平滑肌 | 无 | 中央单核 | 缝隙连接 |
:::

:::callout{kind=tip label="结论速记"}
无横纹 = **平滑肌纤维**。
:::

### 第14题

:::callout{kind=note label="题目"}
心管膨大按顺序（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】心球、心室、心房、静脉窦**（源回忆）

心管各段生长速度不同，**由头向尾**依次膨大为心球（bulbus cordis）、心室、心房、静脉窦。心球远侧份较细为动脉干。两端固定、心球和心室长得快，才弯成球室袢。顺序写反就把动脉端和静脉端对调。
:::

:::callout{kind=note label="知识卡片：心管头尾"}
头端接动脉（鳃弓固定），尾端接静脉（横隔固定）。头 = 心球，尾 = 静脉窦。
:::

:::callout{kind=tip label="结论速记"}
心管头→尾：**心球 → 心室 → 心房 → 静脉窦**。
:::

### 第15题

:::callout{kind=note label="题目"}
肝小叶中没有的结构（　　）

A. 胆小管　　B. 中央静脉　　C. 窦周隙　　D. 肝索　　E. 小叶下静脉
:::

:::callout{kind=insight label="解析"}
**【答案】E. 小叶下静脉**（源回忆）

肝小叶内有中央静脉、肝板（肝索）、肝血窦、窦周隙、胆小管。中央静脉出小叶后汇入**单独走行**的小叶下静脉，小叶下静脉在小叶间结缔组织里，**不在肝小叶内**。门管区是小叶间动脉、小叶间静脉、小叶间胆管，也没有小叶下静脉。
:::

:::callout{kind=note label="知识卡片：肝内血流"}
门静脉／肝动脉 → 小叶间静脉／动脉 → 肝血窦 → 中央静脉 → 小叶下静脉 → 肝静脉。
:::

:::callout{kind=tip label="结论速记"}
肝小叶内没有 **小叶下静脉**。
:::

### 第16题

:::callout{kind=note label="题目"}
下列是由间介中胚层分化而来（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】睾丸**（源回忆）

中胚层由内向外：轴旁（体节）→ 间介 → 侧板。间介中胚层分化为泌尿、生殖系统的主要器官，睾丸在其列。表皮来自外胚层；消化道上皮来自内胚层。
:::

:::callout{kind=note label="知识卡片：中胚层三带"}
| 带 | 主账 |
|----|------|
| 轴旁中胚层 | 真皮、中轴骨骼及骨骼肌 |
| 间介中胚层 | 泌尿、生殖主要器官 |
| 侧中胚层 | 体壁与脏壁 |
:::

:::callout{kind=tip label="结论速记"}
睾丸来自 **间介中胚层**。
:::

### 第17题

:::callout{kind=note label="题目"}
突触前膜（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】神经递质吐出的那一面**（源回忆）

化学突触三部：突触前膜、突触间隙、突触后膜。前膜是轴突终末（或树突／胞体局部）面向间隙的膜，内有突触小泡，递质以胞吐释放。后膜上才是受体。电突触是缝隙连接，没有这套胞吐账。
:::

:::callout{kind=note label="知识卡片：化学突触方向"}
冲动到终末 → $\mathrm{Ca}^{2+}$ 内流 → 小泡与前膜融合 → 递质入间隙 → 后膜受体。尼氏体不在轴突，递质相关酶可在胞体合成后运到终末。
:::

:::callout{kind=tip label="结论速记"}
突触前膜 = **递质胞吐的那一侧**。
:::

### 第18题

:::callout{kind=note label="题目"}
尼氏体存在于（　　）
:::

:::callout{kind=insight label="解析"}
**【答案】胞体和树突**（源回忆）

尼氏体是强嗜碱性斑块，电镜下为粗面内质网 + 游离核糖体，合成结构蛋白、递质相关酶和肽类调质。分布在胞体和树突；轴丘和轴突没有，所以轴丘染色淡。
:::

:::callout{kind=note label="知识卡片：神经元胞质两件"}
尼氏体：RER + 核糖体，胞体和树突。神经原纤维：神经丝 + 微管，骨架并参与运输。
:::

:::callout{kind=tip label="结论速记"}
尼氏体在 **胞体和树突**，不在轴突。
:::

### 第19题

:::callout{kind=note label="题目"}
透明软骨错误的是（有毛细血管）
:::

:::callout{kind=insight label="解析"}
**【答案】「有毛细血管」是错项**（源回忆）

软骨组织内无血管和淋巴管。蛋白聚糖分子筛渗透性好，深部软骨细胞靠渗透交换；营养来自软骨膜血管（关节软骨来自滑液）。写成「透明软骨有毛细血管」即错。
:::

:::callout{kind=note label="知识卡片：透明软骨能看见什么"}
软骨膜、陷窝、软骨囊、同源细胞群。胶原原纤维与基质折光相近，光镜下纤维看不清——这是透明之名，不是「没有纤维」。
:::

:::callout{kind=tip label="结论速记"}
透明软骨 **无血管**；营养靠渗透。
:::

### 第20题

:::callout{kind=note label="题目"}
微绒毛里面是（微丝，不是微管）
:::

:::callout{kind=insight label="解析"}
**【答案】微丝，不是微管**（源回忆）

| | 微绒毛 | 纤毛 |
|--|--------|------|
| 骨架 | 微丝 | 微管 $9+2$ |
| 光镜 | 常不能单根看见 | 能 |
| 功能 | 扩大表面积 | 节律性摆动 |
:::

:::callout{kind=tip label="结论速记"}
微绒毛里面是 **微丝**。
:::

滋养层陷窝位置（　　）

## 三、名词解释

### 第1题

:::callout{kind=note label="题目"}
黄体
:::

:::callout{kind=insight label="解析"}
**【答案】** 排卵后卵泡壁和卵泡膜向腔内塌陷，血管、结缔组织长入，发育成具有内分泌功能的细胞团，称黄体。

颗粒黄体细胞数量多、体积大、染色浅，位于中央，分泌孕激素；膜黄体细胞数量少、体积小、染色深，位于周边，分泌雌激素。未受精维持 $12\sim 14\,\mathrm{d}$ 后退化，称月经黄体，再变为白体。受精则在 hCG 作用下成为妊娠黄体，维持 $4\sim 6$ 个月后退化成白体。
:::

:::callout{kind=note label="知识卡片：黄体不是卵泡的别名"}
有腔才叫次级卵泡；黄体是排卵之后的内分泌改建。颗粒黄体细胞出孕激素，膜黄体细胞出雌激素。
:::

:::callout{kind=tip label="结论速记"}
黄体 = 排卵后卵泡壁改建；月经黄体 $12\sim 14\,\mathrm{d}$，妊娠黄体 $4\sim 6$ 个月。
:::

### 第2题

:::callout{kind=note label="题目"}
三胚层胚盘
:::

:::callout{kind=insight label="解析"}
**【答案】** 第 $3$ 周末形成的胚盘，由外胚层、中胚层和内胚层组成；$3$ 个胚层均起源于上胚层。

第 $3$ 周初上胚层中线形成原条、原结。原沟细胞一部分在上、下胚层之间铺成胚内中胚层，一部分置换下胚层成为内胚层，原上胚层改称外胚层。原条所在一端为尾端，胚盘呈头大尾小的梨形。
:::

:::callout{kind=note label="知识卡片：二胚层 vs 三胚层"}
| | 二胚层胚盘 | 三胚层胚盘 |
|--|------------|------------|
| 时间 | 第 $2$ 周 | 第 $3$ 周末 |
| 组成 | 上胚层 + 下胚层 | 外 + 中 + 内胚层 |
| 起源 | 内细胞群 | 三层都来自上胚层 |
:::

:::callout{kind=tip label="结论速记"}
三胚层胚盘：**第 3 周末**，外中内，都来自上胚层。
:::

### 第3题

:::callout{kind=note label="题目"}
卵圆孔
:::

:::callout{kind=insight label="解析"}
**【答案】** 胚胎心房分隔过程中，第二房间隔上的孔，被第一房间隔（卵圆孔瓣）遮盖；出生前允许右心房血入左心房，是胎儿循环的短路之一。

下腔静脉入口正对卵圆孔，大部分下腔血（氧饱和度约 $67\%$）经此入左房，优先养头颈上肢。出生后左房压升高、右房压下降，瓣紧贴卵圆孔（功能性关闭）；约 $1$ 年完全封闭成卵圆窝。组胚名解写心的卵圆孔，不写颅底的卵圆孔。
:::

:::callout{kind=note label="知识卡片：胎儿三条短路"}
静脉导管、卵圆孔、动脉导管。出生后分别成静脉韧带、卵圆窝、动脉韧带。
:::

:::callout{kind=tip label="结论速记"}
卵圆孔：胎儿右→左房短路；约 $1$ 年封闭成 **卵圆窝**。

### 第4题

:::callout{kind=note label="题目"}
骨单位
:::

:::callout{kind=insight label="解析"}
**【答案】** 骨单位（osteon）又称哈弗斯系统，位于内、外环骨板之间，是长骨中起支持作用的主要结构。

长筒状，可有分支，方向与骨干长轴基本一致。由 $4\sim 20$ 层同心圆骨单位骨板围绕中央管构成；相邻骨板纤维互成直角。中央管内有血管、神经。同一骨单位内最内层骨小管通中央管；黏合线处小管折返，一般不与相邻骨单位连通。
:::

:::callout{kind=note label="知识卡片：密质骨三板"}
环骨板、骨单位、间骨板。间骨板是旧骨单位或环骨板的残留。穿通管（Volkmann）横向连接各中央管。

:::callout{kind=tip label="结论速记"}
骨单位 = **$4\sim 20$ 层哈佛骨板 + 中央管**。

### 第5题

:::callout{kind=note label="题目"}
肾单位
:::

:::callout{kind=insight label="解析"}
**【答案】** 肾单位由肾小体、近端小管、细段和远端小管组成，是肾脏的基本结构和功能单位。

肾小体 + 肾小管 = 肾单位。泌尿小管 = 肾小管 + 集合管系，比肾单位多了集合管。浅表肾单位数量多、体积较小，主司成尿；髓旁肾单位数量少、体积较大，利于浓缩。
:::

:::callout{kind=note label="知识卡片：滤过膜三层"}
有孔内皮（孔处无隔膜）+ 基膜 + 足细胞裂孔膜。入球粗、出球细，利于滤过。

肾单位 = **肾小体 + 肾小管**（不含集合管）。

## 四、问答题

### 第1题

:::callout{kind=note label="题目"}
小肠和胚胎都有绒毛，写其结构和功能意义
:::

:::callout{kind=insight label="解析"}
**【答案】** 同名不同账：小肠是肠绒毛，胚胎是绒毛膜绒毛。

**小肠绒毛**

1. 结构：上皮和固有层向肠腔突起，长 $0.5\sim 1.5\,\mathrm{mm}$。上皮为单层柱状（吸收细胞 + 杯状细胞）；吸收细胞游离面纹状缘是密集微绒毛。固有层轴心有中央乳糜管（收乳糜微粒）和有孔毛细血管（收氨基酸、单糖）。
2. 意义：皱襞 + 绒毛使内表面积约扩大 30 倍（再加上微绒毛），是消化吸收的主场。脂肪走中央乳糜管，其余走血。

**胚胎（绒毛膜）绒毛**

1. 结构：滋养层向周围突起。初级绒毛仅合体滋养层 + 细胞滋养层；胚外中胚层长入成次级绒毛；绒毛内出现血管成三级绒毛。足月胎盘由丛密绒毛膜 + 基蜕膜构成，约 $40\sim 60$ 根绒毛干。
2. 意义：增大母胎交换面积；胎盘膜（胎盘屏障）进行气体和营养交换，并分泌 hCG、胎盘催乳素、孕激素和雌激素。

不要把肠绒毛的中央乳糜管写进胎盘，也不要把合体滋养层写进小肠。
:::

:::callout{kind=note label="知识卡片：两套绒毛对照"}
| | 小肠绒毛 | 绒毛膜绒毛 |
|--|----------|------------|
| 突起成分 | 上皮 + 固有层 | 滋养层 ± 胚外中胚层 ± 胎血管 |
| 腔内结构 | 中央乳糜管、有孔毛细血管 | 绒毛毛细血管（三级） |
| 功能 | 消化吸收 | 母胎交换、内分泌 |
:::

:::callout{kind=tip label="结论速记"}
肠绒毛放大吸收面；绒毛膜绒毛做 **胎盘交换**。
:::

### 第2题

:::callout{kind=note label="题目"}
列举 3 个血管参与构成的屏障并分别写出结构组成和功能
:::

:::callout{kind=insight label="解析"}
**【答案】** 任举三个即可。下列按本版教材户头写血–脑、血–胸腺、血–睾；气血屏障、滤过膜、胎盘屏障也可。

**1. 血–脑屏障**

- 组成：脑连续型毛细血管内皮（紧密连接是主要结构）+ 基膜 + 神经胶质膜（星形胶质细胞脚板）。
- 功能：阻止血液中某些物质进入脑组织，选择性让营养物质和代谢产物通过，维持中枢内环境稳定。

**2. 血–胸腺屏障**（皮质）

- 组成：①连续毛细血管，内皮紧密连接；②内皮周围连续基膜；③含巨噬细胞的血管周隙；④上皮基膜；⑤一层连续的胸腺上皮细胞突起。
- 功能：使胸腺内 T 细胞分化发育基本不受外界抗原影响。

**3. 血–睾屏障**

- 组成：毛细血管内皮及其基膜、结缔组织、生精上皮基膜、支持细胞紧密连接（最重要）。
- 功能：维持生精微环境，阻止某些物质进近腔室，并防止精子抗原引发自身免疫。

补充（多写不扣，但要分户）：气血屏障 = 肺泡表面液体层 + Ⅰ型肺泡细胞及其基膜 + 薄层结缔组织 + 毛细血管基膜与内皮，厚 $0.2\sim 0.5\,\mu\mathrm{m}$，做气体交换。滤过膜 = 有孔内皮（无隔膜）+ 基膜 + 裂孔膜，形成原尿。胎盘屏障 = 合体滋养层 + 细胞滋养层及其基膜 + 薄层绒毛结缔组织 + 毛细血管基膜和内皮。
:::

:::callout{kind=note label="知识卡片：屏障都有内皮，后面几层不要抄串"}
血–脑第五件是胶质脚板；血–胸腺第五件是胸腺上皮突起，中间夹巨噬细胞周隙；血–睾最关键是支持细胞紧密连接。
:::

:::callout{kind=tip label="结论速记"}
三个血管屏障：**血–脑、血–胸腺、血–睾**（可换气血／滤过／胎盘）。
:::

### 第3题

:::callout{kind=note label="题目"}
叙述从受精卵到二胚层胚盘和子宫在这个时期的变化
:::

:::callout{kind=insight label="解析"}
**【答案】** 时间轴停在第 $2$ 周末（胚前期终点）。胚的变化和子宫（内膜）的变化分开写。

**一、从受精卵到二胚层胚盘**

1. **受精**：一般在输卵管壶腹部。获能精子顶体反应穿过放射冠和透明带，精卵融合；透明带反应保证单精受精；完成第二次成熟分裂，雌雄原核融合成二倍体受精卵。
2. **卵裂**：受精卵边向子宫移行边分裂；透明带包裹、间期不生长，细胞数目增加、体积变小。
3. **桑葚胚**：第 $3$ 天，$12\sim 16$ 个卵裂球组成实心胚。
4. **胚泡**：第 $4$ 天入宫腔，出现胚泡腔；壁为滋养层，一侧为内细胞群；透明带溶解。
5. **植入（着床）**：第 $5\sim 6$ 天开始，第 $11\sim 12$ 天完成。通常在子宫体和底部后壁。极端滋养层先接触内膜。滋养层分化为合体滋养层（外）和细胞滋养层（内）；合体滋养层内出现滋养层陷窝，通母体小血管。
6. **二胚层胚盘**：第 $2$ 周，内细胞群分化为上胚层（柱状）和下胚层（立方）。背侧羊膜囊，腹侧卵黄囊；胚外中胚层及胚外体腔出现，体蒂将来参与脐带。

**二、同期子宫的变化**

1. 植入时子宫内膜处于**分泌期**（黄体的孕激素 + 雌激素）：内膜厚 $5\sim 7\,\mathrm{mm}$，子宫腺弯曲、腺腔扩大，糖原顶浆分泌入腺腔；螺旋动脉伸入浅层；基质水肿，部分基质细胞成前蜕膜细胞。
2. 植入后内膜改称**蜕膜**：基蜕膜（胚与肌层之间）、包蜕膜（覆盖胚泡的宫腔面）、壁蜕膜（其余内膜）。
3. 若未植入，分泌期末雌、孕激素下降，将进入月经期，功能层脱落。本题时间窗在植入完成、二胚层出现，子宫侧写分泌期 → 蜕膜即可。
:::

:::callout{kind=note label="知识卡片：胚前期时间钉"}
受精（壶腹）→ 第 3 天桑葚胚 → 第 4 天胚泡 → 第 5～6 天开始植入 → 第 11～12 天植入完成、二胚层胚盘。第 3 周才是原条和三胚层，本题不要写过。
:::

:::callout{kind=tip label="结论速记"}
受精卵→卵裂→桑葚→胚泡→植入；第 2 周 **上、下胚层**。子宫：分泌期内膜 → **蜕膜**。
:::
