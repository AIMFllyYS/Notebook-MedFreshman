## 一、最佳选择题（每题 0.5 分，共 20 分）

### 第1题

:::callout{kind=note label="题目"}
胎儿最早、最多得到氧和营养物质的器官是（　　）

A. 肝　　B. 肾　　C. 心脏　　D. 头颈
:::

:::callout{kind=insight label="解析"}
**【答案】A**

胎盘氧合血经脐静脉入胚，第一站是肝：静脉导管本身走在肝内，余部灌肝血窦后再入下腔静脉。肾不接这条脐静脉干道。心脏是中转，不是第一受血器官。头颈经卵圆孔、左心得到较高氧饱和度，是「优先供氧」而不是「最早到达」。本卷「最早、最多」按脐静脉入肝来标。
:::

:::callout{kind=note label="知识卡片：胎儿血到肝"}
脐静脉 → 肝内静脉导管（大部分）／肝血窦（余部）→ 下腔静脉 → 右房。下腔入口正对卵圆孔，大部分下腔血（氧饱和度约 $67\%$）进左房，再优先养头颈上肢。
:::

:::callout{kind=tip label="结论速记"}
胎儿氧和营养 **最早到肝**（脐静脉第一站）；头颈是卵圆孔之后的优先供氧。
:::

### 第2题

:::callout{kind=note label="题目"}
关于小肠单层柱状上皮的描述，哪项错误（　　）

A. 杯状细胞逐渐增多　　B. 柱状细胞的胞质在光镜下呈空泡状
C. 上皮游离面有纹状缘　　D. 参与分泌性免疫球蛋白的释放
:::

:::callout{kind=insight label="解析"}
**【答案】B**

吸收细胞（柱状细胞）胞质嗜酸，游离面纹状缘是密集微绒毛，不是空泡。光镜下空泡状的是杯状细胞（黏原颗粒溶解）。A：从十二指肠到回肠，杯状细胞逐渐增多。C：纹状缘是小肠柱状上皮的光镜标志。D：吸收细胞与浆细胞协作，将 $\mathrm{sIgA}$ 转运入肠腔。
:::

:::callout{kind=note label="知识卡片：小肠上皮两户"}
| | 吸收细胞 | 杯状细胞 |
|--|----------|----------|
| 光镜 | 柱状，纹状缘 | 空泡状，核被挤向基部 |
| 职分 | 吸收；转运 $\mathrm{sIgA}$ | 分泌黏液 |
:::

:::callout{kind=tip label="结论速记"}
空泡状是 **杯状细胞**，不是柱状吸收细胞。
:::

### 第3题

:::callout{kind=note label="题目"}
关于巨噬细胞主要功能的描述，哪项错误（　　）

A. 趋化运动　　B. 吞噬作用　　C. 参与调节免疫应答　　D. 分泌免疫球蛋白
:::

:::callout{kind=insight label="解析"}
**【答案】D**

巨噬细胞能趋化、吞噬、加工提呈抗原并分泌细胞因子，调节免疫应答。免疫球蛋白由浆细胞分泌。把「参与免疫」听成「自己产抗体」，户头就串到浆细胞。
:::

:::callout{kind=note label="知识卡片：谁产免疫球蛋白"}
浆细胞：动脉性偏心核 + 胞质嗜碱（粗面内质网），分泌免疫球蛋白。巨噬细胞：溶酶体多、胞质嗜酸，吞噬并提呈，不分泌抗体。
:::

:::callout{kind=tip label="结论速记"}
巨噬细胞 **不分泌免疫球蛋白**；抗体在浆细胞。
:::

### 第4题

:::callout{kind=note label="题目"}
周围神经系统来自（　　）

A. 神经沟　　B. 神经褶　　C. 神经嵴　　D. 神经管
:::

:::callout{kind=insight label="解析"}
**【答案】C**

神经板中央凹陷成神经沟，两侧神经褶在背侧愈合为神经管，管走中枢（脑、脊髓、视网膜神经部）。愈合时自褶缘脱落的细胞团是神经嵴，分化为脑脊神经节、自主神经节、施万细胞等周围神经成分。神经沟、神经褶是成管过程中的形态，不是周围神经的户头。
:::

:::callout{kind=note label="知识卡片：神经外胚层三步"}
神经板 → 神经沟／神经褶 → 神经管（中枢）。脱落的神经嵴 → 周围神经系统。
:::

:::callout{kind=tip label="结论速记"}
周围神经来自 **神经嵴**；神经管走中枢。
:::

### 第5题

:::callout{kind=note label="题目"}
关于出生以后卵巢内的初级卵母细胞的描述，哪项错误（　　）

A. 核大而圆、色浅，核仁清楚　　B. 胞质丰富、嗜酸性
C. 停留于第一次成熟分裂的前期　　D. 排卵时完成第一次成熟分裂
:::

:::callout{kind=insight label="解析"}
**【答案】D**

出生后卵巢内的卵母细胞都是初级卵母细胞，停在第一次成熟分裂前期（双线期）：核大而圆、色浅、核仁清楚，胞质丰富嗜酸。第一次成熟分裂在 **排卵前** 完成，排出的是次级卵母细胞（并停在第二次成熟分裂中期）。写成「排卵时完成」把时间钉错了，故 D 为错项。
:::

:::callout{kind=pitfall label="易错警示"}
排卵前完成第一次分裂，排出次级卵母细胞；第二次成熟分裂在受精时才完成。不要把「排卵」和「完成第一次成熟分裂」写成同一时刻。
:::

:::callout{kind=tip label="结论速记"}
卵巢内初级卵母细胞停在 **第一次分裂前期**；第一次分裂在 **排卵前** 完成。
:::

### 第6题

:::callout{kind=note label="题目"}
肌细胞膜又称（　　）

A. 肌外膜　　B. 肌束膜　　C. 肌内膜　　D. 肌膜
:::

:::callout{kind=insight label="解析"}
**【答案】D**

肌膜（sarcolemma）就是肌纤维的细胞膜，外贴基膜。肌外膜包整块骨骼肌，肌束膜包肌束，肌内膜是每条肌纤维周围的薄层结缔组织——三层都是结缔组织鞘，不是细胞膜。
:::

:::callout{kind=note label="知识卡片：骨骼肌三层膜"}
| 名称 | 包什么 |
|------|--------|
| 肌外膜 | 整块肌 |
| 肌束膜 | 一条肌束 |
| 肌内膜 | 一条肌纤维外周结缔组织 |
| 肌膜 | 肌纤维细胞膜 |
:::

:::callout{kind=tip label="结论速记"}
肌细胞膜 = **肌膜**；肌外／束／内膜是结缔组织鞘。
:::

### 第7题

:::callout{kind=note label="题目"}
关于肾上腺皮质球状带的描述，哪项错误（　　）

A. 分泌盐皮质激素　　B. 位于被膜下　　C. 细胞小、聚集成球、团形
D. 细胞球团之间含有孔毛细血管和少量结缔组织
:::

:::callout{kind=insight label="解析"}
**【答案】D**

A、B、C 与本版教材一致：球状带在被膜下，细胞较小、聚成球团，分泌盐皮质激素（主要是醛固酮）。源标 D 为错项——球状带细胞团之间「含有孔毛细血管」。

本版教材肾上腺皮质写的是 **血窦／窦状毛细血管网** 加少量结缔组织，不把球状带间隙写成有孔毛细血管。多数通论把内分泌腺毛细血管归为有孔型，与本卷口径冲突。答题按源答案选 D，复习时记住：本校教材肾上腺皮质血管户头是血窦。
:::

:::callout{kind=pitfall label="易错警示"}
源答案把「有孔毛细血管」判错，与通论内分泌腺有孔毛细血管不一致。本卷跟源标；教材对照写血窦，不要在本场改选 A–C。
:::

:::callout{kind=note label="知识卡片：皮质三带"}
| 带 | 位置与排列 | 激素 |
|----|------------|------|
| 球状带 | 被膜下，球团 | 盐皮质激素（醛固酮） |
| 束状带 | 最厚，细胞索，胞质泡沫状 | 糖皮质激素 |
| 网状带 | 近髓质，吻合成网 | 雄激素为主 |
:::

:::callout{kind=tip label="结论速记"}
本卷球状带错项：细胞团之间写 **有孔毛细血管**（源标 D；教材写血窦）。
:::

### 第8题

:::callout{kind=note label="题目"}
胞质内颗粒嗜碱性的原因一般是粗面内质网丰富，但下列哪种细胞例外（　　）

A. 肝细胞　　B. 神经元　　C. 肥大细胞　　D. 脊神经节的节细胞
:::

:::callout{kind=insight label="解析"}
**【答案】C**

嗜碱通常落在核糖体／粗面内质网：肝细胞（蛋白质合成）、神经元和脊神经节细胞（尼氏体＝粗面内质网 + 游离核糖体）。肥大细胞胞质充满粗大嗜碱性颗粒，因肝素等而异染，**不是**粗面内质网堆出来的嗜碱。
:::

:::callout{kind=note label="知识卡片：两种嗜碱"}
粗面内质网嗜碱：肝细胞、神经元、浆细胞、胰腺腺泡。颗粒嗜碱／异染：肥大细胞（肝素、组胺）。
:::

:::callout{kind=tip label="结论速记"}
颗粒嗜碱的例外：**肥大细胞**（肝素颗粒），不是内质网。
:::

### 第9题

:::callout{kind=note label="题目"}
属于周围神经系统的神经胶质细胞是（　　）

A. 小胶质细胞　　B. 少突胶质细胞　　C. 施万细胞　　D. 星形胶质细胞
:::

:::callout{kind=insight label="解析"}
**【答案】C**

中枢胶质：星形胶质细胞、少突胶质细胞、小胶质细胞、室管膜细胞。周围胶质：施万细胞（神经膜细胞）和卫星细胞。少突胶质细胞在中枢成髓鞘，施万细胞在周围成髓鞘，不要对调。
:::

:::callout{kind=note label="知识卡片：成髓鞘两户"}
| | 中枢 | 周围 |
|--|------|------|
| 成髓鞘 | 少突胶质细胞（可包多条轴突） | 施万细胞（一条纤维一段） |
| 其他 | 星形胶质、小胶质、室管膜 | 卫星细胞 |
:::

:::callout{kind=tip label="结论速记"}
周围胶质找 **施万细胞**；少突在中枢。
:::

### 第10题

:::callout{kind=note label="题目"}
髓袢的组成是（　　）

A. 近端小管直部和细段　　B. 近端小管直部、细段和远端小管直部
C. 细段和远端小管直部　　D. 远端小管直部和集合管
:::

:::callout{kind=insight label="解析"}
**【答案】B**

髓袢（Henle 袢）是肾小管中伸入髓质的 U 形段：降支为近端小管直部 + 细段降支，升支为细段升支 + 远端小管直部。集合管不属于肾小管，也不进髓袢户头。A、C 都少写一段直部。
:::

:::callout{kind=note label="知识卡片：肾小管 vs 髓袢"}
肾小管 = 近端小管（曲 + 直）+ 细段 + 远端小管（直 + 曲）。髓袢 = 近端小管直部 + 细段 + 远端小管直部。肾单位 = 肾小体 + 肾小管（不含集合管）。
:::

:::callout{kind=tip label="结论速记"}
髓袢 = **近直 + 细段 + 远直**；集合管不在袢上。
:::

### 第11题

:::callout{kind=note label="题目"}
有关肺表面活性物质的来源和作用，正确的是（　　）

A. 来源于Ⅰ型细胞，可提高肺泡表面张力
B. 来源于Ⅱ型细胞，可降低肺泡表面张力
C. 来源于Ⅰ型细胞，可分解肺泡表面异物
D. 来源于Ⅱ型细胞，可增加肺泡通气量
:::

:::callout{kind=insight label="解析"}
**【答案】B**

Ⅱ型肺泡细胞含嗜锇性板层小体，释放表面活性物质，降低肺泡表面张力，稳定肺泡直径，防止呼气末萎陷。Ⅰ型细胞扁平，覆盖大部分内表面，参与气血屏障（厚 $0.2\sim 0.5\,\mu\mathrm{m}$），不分泌该物质。D 把作用写成「增加通气量」，不是表面活性物质的直接定义。
:::

:::callout{kind=note label="知识卡片：两型肺泡细胞"}
| | Ⅰ型 | Ⅱ型 |
|--|------|------|
| 形态 | 扁平菲薄 | 立方形，板层小体 |
| 职分 | 气血屏障 | 表面活性物质；可增殖补Ⅰ型 |
:::

:::callout{kind=tip label="结论速记"}
表面活性物质：**Ⅱ型细胞产，降低表面张力**。
:::

### 第12题

:::callout{kind=note label="题目"}
蜕膜是指（　　）

A. 月经期的子宫内膜　　B. 增生期的子宫内膜
C. 分泌期的子宫内膜　　D. 胚泡植入时的子宫内膜
:::

:::callout{kind=insight label="解析"}
**【答案】D**

胚泡植入后，分泌期子宫内膜改称蜕膜，按位置分基蜕膜、包蜕膜、壁蜕膜。月经期、增生期、分泌期是未孕周期的内膜分期；分泌期是植入发生的背景，但「蜕膜」这个户头从植入开始才成立。
:::

:::callout{kind=note label="知识卡片：蜕膜三部"}
基蜕膜：胚与肌层之间，参与胎盘。包蜕膜：覆盖胚泡的宫腔面。壁蜕膜：其余内膜。
:::

:::callout{kind=tip label="结论速记"}
蜕膜 = **植入后的子宫内膜**，不是分泌期的别名。
:::

### 第13题

:::callout{kind=note label="题目"}
下列哪项不属于蒲肯野纤维的特点（　　）

A. 位于心室壁的心内膜下层　　B. 胞质中有丰富的粗面内质网
C. 细胞间有发达的缝隙连接　　D. 将冲动快速传到心室各处引发同步收缩
:::

:::callout{kind=insight label="解析"}
**【答案】B**

蒲肯野纤维（束细胞）在心室心内膜下，细胞短而粗，肌原纤维少、偏周边，胞质因糖原丰富而浅染，闰盘处缝隙连接发达，传导快，使心室同步收缩。丰富的是糖原，不是粗面内质网。B 把分泌细胞的账抄到传导纤维上。
:::

:::callout{kind=pitfall label="易错警示"}
心传导系的蒲肯野纤维 ≠ 小脑皮质蒲肯野细胞 ≠ 小肠腺帕内特细胞。看见「蒲肯野」先问在心、在小脑还是在肠。
:::

:::callout{kind=tip label="结论速记"}
蒲肯野纤维富 **糖原**，不是粗面内质网。
:::

### 第14题

:::callout{kind=note label="题目"}
关于内分泌腺，哪项错误（　　）

A. 其导管开口于有腔器官的腔面　　B. 毛细血管丰富
C. 腺细胞排列成索状、团状或滤泡状　　D. 由内分泌细胞组成的器官
:::

:::callout{kind=insight label="解析"}
**【答案】A**

内分泌腺无导管，产物直接入血。有导管开口于腔面的是外分泌腺。B、C、D 成立：内分泌腺毛细血管丰富；细胞排成索、团或滤泡；腺体本身就是内分泌细胞组成的器官。
:::

:::callout{kind=note label="知识卡片：内 vs 外分泌"}
外分泌：导管 + 开口于腔面或体表。内分泌：无导管，入血；细胞索团或滤泡，血管丰富。
:::

:::callout{kind=tip label="结论速记"}
内分泌腺 **无导管**；有导管开口是外分泌。
:::

### 第15题

:::callout{kind=note label="题目"}
下颌下腺的特点是（　　）

A. 纯浆液性腺　　B. 纹状管长
C. 混合性腺，以黏液性腺泡为主　　D. 闰管长
:::

:::callout{kind=insight label="解析"}
**【答案】B**

下颌下腺是混合性腺、**浆液性腺泡为主**，纹状管长、闰管较短。A、D 是腮腺（纯浆液，闰管长）。C 把下颌下腺写成黏液为主，那是舌下腺的账。
:::

:::callout{kind=note label="知识卡片：三大唾液腺"}
| 腺 | 性质 | 导管 |
|----|------|------|
| 腮腺 | 纯浆液 | 闰管长，纹状管长 |

:::callout{kind=insight label="解析"}
**【答案】** 肺动脉狭窄、主动脉肥大并骑跨在室间孔上、室间隔膜部缺损、右心室肥大（1.5 分）。原因：主肺动脉隔偏位（源答案）。

本版教材：主动脉肺动脉隔偏于肺动脉一侧，四条并存才叫四联症。右室肥大是肺动脉狭窄后排血阻力增大的继发改变。源答案「主动脉肥大并骑跨」与教材「粗大的主动脉骑跨在室间隔膜部」同义。
:::

:::callout{kind=note label="知识卡片：隔走偏的三种病"}
隔走直 → 主动脉／肺动脉错位。隔偏一侧 → 两大动脉分隔不均等（狭窄）。隔偏肺动脉一侧 → 法洛四联症。
:::

:::callout{kind=tip label="结论速记"}
法洛四联症：肺动脉狭窄 + 主动脉骑跨 + 室间隔膜部缺损 + 右室肥大；因 **主肺动脉隔偏位**。
:::

## 三、问答题（每题 5 分，共 10 分）

### 第1题

:::callout{kind=note label="题目"}
试比较淋巴结与脾脏的光镜结构（用表格的形式）。
:::

:::callout{kind=insight label="解析"}
**【答案】** 按源答案表格对照（每行 1 分，共 5 分）。原料「被摸」按语义作 **被膜**。

| | 淋巴结 | 脾 |
|--|--------|----|
| 被膜与小梁（1 分） | 致密结缔组织；被膜内有输入淋巴管 | 致密结缔组织 + 平滑肌；表面有间皮 |
| 淋巴小结（1 分） | 位于皮质浅层；小结帽朝向被膜 | 散在分布；朝向红髓 |
| 副皮质区（1 分） | 位于小结深层 | 位于小结一侧（动脉周围淋巴鞘一侧） |
| 髓索（1 分） | 淋巴组织 | 淋巴组织 + 血液（脾索） |
| 髓窦（1 分） | 淋巴窦 | 血窦 |

淋巴结有输入淋巴管，淋巴单向：输入管 → 被膜下窦 → 皮质淋巴窦 → 髓窦 → 门部输出管。脾无输入淋巴管，白髓滤血、红髓脾索含血；被膜和小梁含平滑肌，可收缩挤血。
:::

:::callout{kind=note label="知识卡片：一个滤淋巴、一个滤血"}
淋巴结：输入淋巴管 + 淋巴窦。脾：无输入淋巴管，红髓是血窦和脾索。副皮质／动脉周围淋巴鞘都是 T 区，位置一个在小结深面，一个在小结一侧。
:::

:::callout{kind=tip label="结论速记"}
淋巴结被膜有 **输入淋巴管、淋巴窦**；脾被膜含平滑肌、表面间皮，红髓是 **血窦**。
:::

### 第2题

:::callout{kind=note label="题目"}
试述出生后卵圆孔未闭的原因。
:::

:::callout{kind=insight label="解析"}
**【答案】** 按源答案四点给分（合计按卷面 5 分计）。

1. 卵圆孔瓣吸收（1.5 分）
2. 第二房间孔过大：第一隔过度吸收（1.5 分）
3. 卵圆孔过大：第二房间隔发育障碍（1.5 分）
4. 上述 2 与 3 同时存在（0.5 分）

出生前第一房间隔当作卵圆孔瓣，遮住第二房间隔上的卵圆孔，只许右→左分流。出生后左房压升高、瓣贴死卵圆孔，约 1 年封闭成卵圆窝。瓣被吸收、瓣过短（第一隔吸收过度使第二房间孔过大）、或第二隔发育不全使卵圆孔过大，都会让左右房继续相通。

本版教材另列五种机制：瓣上穿孔；第一隔吸收过度致瓣过短；第二隔发育不全致卵圆孔过大；第二房间孔过大或位置异常；心内膜垫发育不全、第一隔不能与其融合。答题先写源答案四点；复习可对照教材五条，不要用五条去改源给分。
:::

:::callout{kind=note label="知识卡片：第一隔与第二隔"}
第一房间隔：先出第一房间孔，后出第二房间孔；残留部分即卵圆孔瓣。第二房间隔：左侧遮盖第二房间孔，自身留卵圆孔。两孔上下错位，瓣能盖住孔。
:::

:::callout{kind=tip label="结论速记"}
卵圆孔未闭源标三点： **瓣吸收**、**第一隔吸收过度**、**第二隔发育障碍**（可并存）。
:::
