### 第 1 题

:::callout{kind=note label="题目"}
小支气管被覆的上皮是（　　）

A. 单层柱状上皮　　B. 单层纤毛柱状上皮
C. 假复层纤毛柱状上皮　　D. 假复层柱状上皮
:::

:::callout{kind=insight label="解析"}
**【答案】C**

肺内导气部从叶支气管到小支气管，上皮仍是假复层纤毛柱状，夹杯状细胞。细支气管才改成单层纤毛柱状，终末细支气管进一步变单层柱状，杯状细胞消失。D 少了「纤毛」，不是这道题的户头。
:::

:::callout{kind=note label="知识卡片：肺内导气部上皮阶梯"}
| 管道 | 上皮 |
|------|------|
| 叶／段／小支气管 | 假复层纤毛柱状（有杯状细胞） |
| 细支气管 | 单层纤毛柱状，杯状细胞减少 |
| 终末细支气管 | 单层柱状，无杯状细胞，俱乐部细胞为主 |
:::

:::callout{kind=tip label="结论速记"}
小支气管上皮：**假复层纤毛柱状**。细支气管才换成单层。
:::

### 第 2 题

:::callout{kind=note label="题目"}
管壁上有绒毛，固有层内有腺体、可以出现孤立淋巴小结，黏膜下层无腺体，这是哪段消化管？（　　）

A. 食管　　B. 十二指肠　　C. 空肠　　D. 结肠
:::

:::callout{kind=insight label="解析"}
**【答案】C**

有绒毛 = 小肠，食管和结肠都没有。十二指肠黏膜下层有十二指肠腺（Brunner 腺），本题写「黏膜下层无腺体」，把十二指肠排除。回肠以集合淋巴小结为招牌，空肠固有层可见孤立淋巴小结。结肠有肠腺、无绒毛。
:::

:::callout{kind=note label="知识卡片：消化管黏膜下层有没有腺"}
食管：黏液性食管腺。十二指肠：十二指肠腺。空肠／回肠／结肠：黏膜下层一般无腺。胃的贲门腺、胃底腺、幽门腺都在固有层。
:::

:::callout{kind=tip label="结论速记"}
有绒毛 + 黏膜下层无腺 + 孤立淋巴小结 = **空肠**。
:::

### 第 3 题

:::callout{kind=note label="题目"}
关于卵子发生，下列哪项错误（　　）

A. 在卵巢内完成　　B. 自胚胎时期就开始了卵子发生
C. 初级卵母细胞停留在第一次成熟分裂的时间可以长达几十年
D. 在卵子发生过程中没有细胞形态的变化
:::

:::callout{kind=insight label="解析"}
**【答案】A**

卵子发生从胚胎期启动，出生时卵巢内已是初级卵母细胞，并长期停在第一次成熟分裂前期（双线期），可长达几十年。排卵排出的是次级卵母细胞，第二次成熟分裂在受精后于输卵管完成，所以「在卵巢内完成」错。

D 按本卷口径算对：卵子发生不像精子形成那样经历变态，没有「精子细胞 → 精子」那种形态重塑。
:::

:::callout{kind=pitfall label="易错警示"}
排卵不等于卵子发生结束。第二次成熟分裂要等精子入卵才走完。
:::

:::callout{kind=tip label="结论速记"}
卵子发生**不在卵巢内完成**；受精后才结束第二次成熟分裂。
:::

### 第 4 题

:::callout{kind=note label="题目"}
疏松结缔组织的特点之一是（　　）

A. 细胞种类多　　B. 细胞数目多　　C. 细胞有极性　　D. 纤维多
:::

:::callout{kind=insight label="解析"}
**【答案】A**

疏松结缔组织细胞种类多（成纤维细胞、巨噬细胞、浆细胞、肥大细胞、脂肪细胞、未分化间充质细胞等），纤维少、排列稀疏，基质多。细胞数目多、纤维多是致密结缔组织的味道。极性是上皮的尺子，不是结缔组织。
:::

:::callout{kind=note label="知识卡片：疏松 vs 致密"}
| | 疏松结缔组织 | 致密结缔组织 |
|--|-------------|-------------|
| 细胞 | 种类多 | 以成纤维细胞为主，数目相对少 |
| 纤维 | 少、稀疏 | 多、排列密 |
| 基质 | 较多 | 少 |
:::

:::callout{kind=tip label="结论速记"}
疏松结缔组织：**细胞种类多**，纤维不多。
:::

### 第 5 题

:::callout{kind=note label="题目"}
下列哪种细胞呈球形，核分叶、每叶核小色深，胞质色浅、含细小的紫色和粉红色的颗粒。（　　）

A. 中性粒细胞　　B. 嗜酸性粒细胞
C. 嗜碱性粒细胞　　D. 淋巴细胞
:::

:::callout{kind=insight label="解析"}
**【答案】A**

中性粒细胞：球形，核 2～5 叶、染色质致密，胞质浅染，充满细小浅紫／浅红色的特殊颗粒。嗜酸性粒细胞颗粒粗大鲜红、核常两叶。嗜碱性粒细胞颗粒粗大蓝紫、常掩盖核。淋巴细胞核圆、胞质少、无这类特殊颗粒。
:::

:::callout{kind=note label="知识卡片：三种粒细胞一眼看"}
| 细胞 | 核 | 颗粒 |
|------|----|------|
| 中性粒细胞 | 分叶，叶小色深 | 细小紫粉 |
| 嗜酸性粒细胞 | 多两叶 | 粗大嗜酸 |
| 嗜碱性粒细胞 | 分叶不清 | 粗大嗜碱，常盖核 |
:::

:::callout{kind=tip label="结论速记"}
细小紫粉红色颗粒 + 分叶核 = **中性粒细胞**。
:::

### 第 6 题

:::callout{kind=note label="题目"}
最早产生雌激素的卵泡是（　　）

A. 原始卵泡　　B. 初级卵泡　　C. 次级卵泡　　D. 成熟卵泡
:::

:::callout{kind=insight label="解析"}
**【答案】C**

次级卵泡出现卵泡腔，卵泡膜分化出膜细胞。膜细胞合成雄激素，颗粒细胞用芳香化酶转成雌激素——两细胞学说从此能运转。原始卵泡和初级卵泡还没有完整的膜细胞层，成熟卵泡是已经在产、但不是「最早」。
:::

:::callout{kind=note label="知识卡片：卵泡何时开内分泌"}
原始卵泡：单层扁平卵泡细胞，静默。初级卵泡：颗粒细胞增多，透明带出现，膜开始形成。次级卵泡：有腔 + 膜细胞，开始产雌激素。成熟卵泡：腔极大，突出卵巢表面，待排。
:::

:::callout{kind=tip label="结论速记"}
最早产雌激素：**次级卵泡**（膜细胞 + 颗粒细胞）。
:::

### 第 7 题

:::callout{kind=note label="题目"}
心肌闰盘位于（　　）

A. Z 线　　B. M 线　　C. A 带　　D. I 带
:::

:::callout{kind=insight label="解析"}
**【答案】A**

闰盘是相邻心肌细胞的连接，光镜下是深染粗线，电镜下位于 Z 线水平：横位有中间连接和桥粒（机械），纵位有缝隙连接（电耦联）。M 线在 A 带中央，不是闰盘落点。I 带是细肌丝区，不要和「在 Z 线水平」混成「位于 I 带」。
:::

:::callout{kind=pitfall label="易错警示"}
闰盘「在 Z 线水平」≠「就是 I 带」。选位置户头写 **Z 线**。
:::

:::callout{kind=tip label="结论速记"}
心肌闰盘位于 **Z 线** 水平。
:::

### 第 8 题

:::callout{kind=note label="题目"}
衬于体腔表面的单层扁平上皮称为（　　）

A. 间皮　　B. 内皮　　C. 表皮　　D. 真皮
:::

:::callout{kind=insight label="解析"}
**【答案】A**

间皮专指胸膜、腹膜、心包膜等体腔（浆膜）表面的单层扁平上皮。内皮专指心血管和淋巴管腔面。表皮是角化复层扁平，真皮是结缔组织，都不是单层扁平上皮的别名。
:::

:::callout{kind=note label="知识卡片：扁平三户"}
管腔写内皮，浆膜写间皮，肺泡／肾小囊壁层只写单层扁平，不叫内皮或间皮。
:::

:::callout{kind=tip label="结论速记"}
体腔表面单层扁平 = **间皮**。
:::

### 第 9 题

:::callout{kind=note label="题目"}
心管在没有卷褶前，由头至尾的是（　　）

A. 心球、心房、心室　　B. 心房、心室、心球
C. 心球、心室、心房　　D. 心室、心房、心球
:::

:::callout{kind=insight label="解析"}
**【答案】C**

心管头尾方向依次膨大：心球 → 心室 → 心房 → 静脉窦。本卷选项未写静脉窦，头至尾前三段是心球、心室、心房。卷褶之后外形变成「心室在前下、心房在后上」，不要按成体位置倒推。
:::

:::callout{kind=note label="知识卡片：心管四段"}
头侧：心球（远侧参与动脉干）。中段：心室。后段：心房。最尾：静脉窦。
:::

:::callout{kind=tip label="结论速记"}
卷褶前头→尾：**心球、心室、心房**（再往后是静脉窦）。
:::

### 第 10 题

:::callout{kind=note label="题目"}
光镜下，细胞胞体形态多样，胞质含嗜碱性颗粒，胞质有一锥形的浅染区，细胞有 2 种结构和功能不同的突起。这是下列哪种细胞的结构特征？（　　）

A. 浆细胞　　B. 成纤维细胞　　C. 成骨细胞　　D. 神经细胞
:::

:::callout{kind=insight label="解析"}
**【答案】D**

神经细胞：胞体形态多样；尼氏体是嗜碱性颗粒（或斑块）；轴丘呈锥形浅染（无尼氏体）；突起分树突和轴突，结构和功能都不同。浆细胞也有嗜碱胞质和核旁浅染区（高尔基），但没有两种突起。成纤维细胞、成骨细胞都对不上「锥形浅染区 + 两种突起」。
:::

:::callout{kind=pitfall label="易错警示"}
浆细胞的浅染区是核旁高尔基，不是轴丘；也没有树突／轴突。
:::

:::callout{kind=tip label="结论速记"}
尼氏体 + 轴丘 + 两种突起 = **神经细胞**。
:::

### 第 11 题

:::callout{kind=note label="题目"}
巨噬细胞是单核细胞离开血管，在结缔组织内分化而成。但是，下列哪种器官内的巨噬细胞的胞体仍然在血管腔内。（　　）

A. 胸腺　　B. 肺　　C. 脾脏　　D. 肝脏
:::

:::callout{kind=insight label="解析"}
**【答案】D**

肝巨噬细胞（Kupffer 细胞）贴在肝血窦内皮腔面，胞体仍在窦腔内，伪足可穿过内皮。肺泡巨噬细胞在肺泡腔内，不在血管里。脾巨噬细胞主要在红髓脾索。胸腺巨噬细胞在皮质／髓质实质内。
:::

:::callout{kind=note label="知识卡片：单核吞噬系统落点"}
结缔组织：巨噬细胞。肝：Kupffer，窦腔。肺：尘细胞，肺泡腔。脑：小胶质。骨：破骨细胞。皮肤：朗格汉斯（抗原呈递）。
:::

:::callout{kind=tip label="结论速记"}
胞体还在血管腔里的巨噬细胞：**肝巨噬细胞**。
:::

### 第 12 题

:::callout{kind=note label="题目"}
杯状细胞最丰富的部位是（　　）

A. 食管　　B. 胃　　C. 小肠　　D. 结肠
:::

:::callout{kind=insight label="解析"}
**【答案】D**

杯状细胞从十二指肠向结肠逐渐增多，结肠上皮杯状细胞最密，分泌大量黏液润滑粪便。食管是复层扁平，无杯状细胞。胃上皮是表面黏液细胞，**没有**杯状细胞。小肠有，但密度低于结肠。
:::

:::callout{kind=pitfall label="易错警示"}
胃「黏液多」≠ 杯状细胞。胃没有杯状细胞。
:::

:::callout{kind=tip label="结论速记"}
杯状细胞最富：**结肠**。
:::

### 第 13 题

:::callout{kind=note label="题目"}
光镜下，下列哪种血管壁中内弹性膜最清楚（　　）

A. 大动脉　　B. 中动脉　　C. 大静脉　　D. 中静脉
:::

:::callout{kind=insight label="解析"}
**【答案】B**

中动脉（肌性动脉）内膜与中膜交界有一层完整、波浪状的内弹性膜，HE 折光强，最清楚。大动脉中膜全是弹性膜，内弹性膜反而和中膜弹性膜融在一起，不好单独辨认。静脉内弹性膜薄或不完整。
:::

:::callout{kind=pitfall label="易错警示"}
「弹性纤维最多」是大动脉；「内弹性膜最清楚」是 **中动脉**。
:::

:::callout{kind=tip label="结论速记"}
内弹性膜最清楚：**中动脉**。
:::

### 第 14 题

:::callout{kind=note label="题目"}
辨认化学性突触前成分的标志性结构是（　　）

A. 突触前膜的厚　　B. 突触后膜薄　　C. 突触小泡　　D. 微管
:::

:::callout{kind=insight label="解析"}
**【答案】C**

化学性突触的突触前成分靠突触小泡认：小泡内是神经递质，只出现在突触前终末。突触后膜常比前膜厚（致密区），A、B 的厚薄说法本身就不稳。微管在轴突里到处都有，不是突触前的身份证。
:::

:::callout{kind=note label="知识卡片：化学性突触三件"}
突触前成分（终末 + 突触小泡 + 前膜）→ 突触间隙 → 突触后膜（受体）。属于化学性突触的还有运动终板。
:::

:::callout{kind=tip label="结论速记"}
认突触前成分：看 **突触小泡**。
:::

### 第 15 题

:::callout{kind=note label="题目"}
一般血屏障的主要构成是连续型毛细血管，但下列哪种屏障是有孔毛细血管参与构成的（　　）

A. 血脑屏障　　B. 气血屏障　　C. 血尿屏障　　D. 血睾屏障
:::

:::callout{kind=insight label="解析"}
**【答案】C**

肾血管球是有孔内皮（孔上无隔膜），参与滤过膜（血尿屏障）：有孔内皮 + 基膜 + 足细胞裂孔膜。血脑屏障、血睾屏障都是连续型毛细血管。气血屏障的肺泡隔毛细血管也是连续型，厚度 $0.2\sim 0.5\,\mu\mathrm{m}$。
:::

:::callout{kind=note label="知识卡片：四种屏障的内皮"}
| 屏障 | 毛细血管型 |
|------|-----------|
| 血–脑 | 连续型，紧密连接 |
| 气血 | 连续型 |
| 血–尿（滤过膜） | **有孔**（无隔膜） |
| 血–睾 | 连续型；最要紧的是支持细胞紧密连接 |
:::

:::callout{kind=pitfall label="易错警示"}
气血屏障薄，但内皮仍是连续型，不是有孔。
:::

:::callout{kind=tip label="结论速记"}
有孔毛细血管参与的屏障：**血尿屏障**。
:::

### 第 16 题

:::callout{kind=note label="题目"}
周围神经系统有髓神经纤维的髓鞘形成细胞是（　　）

A. 星形胶质细胞　　B. 施万细胞　　C. 小胶质细胞　　D. 卫星细胞
:::

:::callout{kind=insight label="解析"}
**【答案】B**

周围神经有髓纤维的髓鞘由施万细胞（神经膜细胞）一节一节包绕轴突形成，节与节之间是郎飞结。中枢有髓纤维才是少突胶质细胞。星形胶质细胞是中枢支架／足板；小胶质细胞是吞噬；卫星细胞包在神经节细胞胞体周围，不形成髓鞘。
:::

:::callout{kind=note label="知识卡片：谁做髓鞘"}

## 三、名词解释（每题 2 分，共 10 分）

### 第 1 题

:::callout{kind=note label="题目"}
运动终板
:::

:::callout{kind=insight label="解析"}
**【答案】** 运动神经末梢失去髓鞘后，末端膨大附着于骨骼肌的部位，呈椭圆形板状隆起，属于化学性突触。

一条运动神经纤维可支配多条骨骼肌纤维。终末贴在肌膜表面，突触小泡含乙酰胆碱；肌膜侧是终板膜，有皱褶以增大受体面积。
:::

:::callout{kind=note label="知识卡片：化学性突触在肌"}
认突触前仍看突触小泡。一个运动神经元及其支配的肌纤维称运动单位。
:::

:::callout{kind=tip label="结论速记"}
运动终板 = 失髓鞘的运动末梢 + 骨骼肌，**化学性突触**。
:::

### 第 2 题

:::callout{kind=note label="题目"}
窦周隙
:::

:::callout{kind=insight label="解析"}
**【答案】** 肝细胞与血窦内皮之间的狭窄缝隙，含血浆等成分，是肝细胞与血液进行物质交换的场所。

血窦内皮有窗孔、无隔膜，血浆可进入窦周隙；肝细胞血窦面有许多微绒毛。贮脂细胞也住在这里。
:::

:::callout{kind=note label="知识卡片：窦周隙里有谁"}
血浆、肝细胞微绒毛、贮脂细胞。胆小管不在窦周隙，在相邻肝细胞之间。
:::

:::callout{kind=tip label="结论速记"}
窦周隙 = 肝细胞 ↔ 血窦内皮的换物质缝。
:::

### 第 3 题

:::callout{kind=note label="题目"}
月经周期
:::

:::callout{kind=insight label="解析"}
**【答案】** 青春期起，子宫内膜功能层在卵巢激素的作用下，每隔 28 天左右发生剥脱出血、增生修复的周期性变化。

典型 28 天：月经期（第 1～4 天）功能层脱落；增生期（第 5～14 天）雌激素主导修复；分泌期（第 15～28 天）孕激素主导腺体分泌。基底层不脱落，是修复种子。
:::

:::callout{kind=note label="知识卡片：内膜两层"}
功能层：周期剥脱。基底层：残留，负责增生。卵巢周期（卵泡期／黄体期）指挥子宫周期。
:::

:::callout{kind=tip label="结论速记"}
月经周期：功能层约 **28 天** 一剥一修，听卵巢激素。
:::

### 第 4 题

:::callout{kind=note label="题目"}
骨单位
:::

:::callout{kind=insight label="解析"}
**【答案】** 位于内、外环骨板之间，由中央管和多层哈弗骨板构成。中央管内有骨内膜；哈弗骨板上或骨板之间有骨陷窝和骨小管，其内有骨细胞的胞体和突起。

:::callout{kind=note label="知识卡片：密质骨三板"}
外环骨板、内环骨板、骨单位骨板；旧单位残留为间骨板。胶原原纤维周期横纹 $64\,\mathrm{nm}$ 是胶原的尺子，骨板里的胶原纤维按层交替取向。
:::

:::callout{kind=tip label="结论速记"}
骨单位 = **中央管 + 多层哈弗骨板**，夹在内外环骨板之间。

### 第 5 题

原条

原条：上胚层中线细胞索，**定头尾**。

## 四、问答题（每题 5 分，共 20 分）

### 第 1 题

:::callout{kind=note label="题目"}
试述透明软骨组织的光镜结构。
:::

:::callout{kind=insight label="解析"}
**【答案】** 透明软骨组织由软骨细胞和软骨基质构成。

**软骨细胞**：位于软骨陷窝内。浅层细胞小、扁圆形；中央细胞大，常以同源细胞群形式存在。胞质嗜碱性，核圆、色浅。电镜下含与合成蛋白质相关的细胞器。

**软骨基质**：嗜碱性；紧贴软骨细胞周围的基质强嗜碱性，构成软骨囊。基质形成陷窝。基质内有胶原原纤维，光镜下不可见（周期横纹 $64\,\mathrm{nm}$，折光率与基质相近故看不见）。
:::

:::callout{kind=note label="知识卡片：透明软骨没有什么"}
无血管、无淋巴管、无神经；营养靠软骨膜血管渗透。纤维软骨无软骨膜；弹性软骨有弹性纤维。
:::

:::callout{kind=tip label="结论速记"}
透明软骨：陷窝里的软骨细胞 + 嗜碱基质（软骨囊、同源细胞群）；胶原原纤维光镜不可见。
:::

### 第 2 题

:::callout{kind=note label="题目"}
用列表的形式比较近曲小管和远曲小管的光镜结构的异同。
:::

:::callout{kind=insight label="解析"}
**【答案】** 近曲小管与远曲小管光镜对照（各 2.5 分）：

| 项目 | 近曲小管 | 远曲小管 |
|------|----------|----------|
| 上皮细胞形态 | 单层，大立方 | 小立方 |
| 胞质嗜色性 | 强嗜酸性 | 弱嗜酸性 |
| 核 | 近基底 | 近游离面 |
| 游离面 | 刷状缘 | 无 |
| 核下纵纹 | 不清楚 | 清楚 |
| 细胞界限 | 不清楚 | 较清楚 |

同：都是单层立方、都在皮质迷路、都属肾小管。异：近曲管径粗、腔不规则、刷状缘和侧突发达，所以界限不清、嗜酸强；远曲管径细、腔清、无刷状缘、基底纵纹清楚。
:::

:::callout{kind=note label="知识卡片：皮质迷路两曲"}
近曲接肾小囊尿极，重吸收大户。远曲接致密斑／集合管，受激素调节。远直小管才是对水不通透的升支粗段，不要写进这张表。
:::

:::callout{kind=tip label="结论速记"}
近曲：大立方、强嗜酸、刷状缘、核近基底、界限不清。远曲相反。
:::

### 第 3 题

:::callout{kind=note label="题目"}
试述精子发生的特点。
:::

:::callout{kind=insight label="解析"}
**【答案】** 精子发生特点（十点采分）：

1. 起自青春期。
2. 在生精小管内是节段性发生，没有周期性。
3. 有胞质桥的存在。
4. 有细胞形态的变化。
5. 一个初级精母细胞形成 4 个精子。
6. 在睾丸一个器官内完成。
7. 发生的环境温度要低于体温 $2\sim 3$ 度。
8. 需要高浓度的雄激素环境。
9. 有血睾屏障的保护。
10. 有精原细胞的复制和保存。
:::

:::callout{kind=note label="知识卡片：精子发生 vs 卵子发生"}
精子：青春期才启动，形态大变，一变四，在睾丸内完成。卵子：胚胎期启动，形态不大变，一变一（加极体），不在卵巢内完成。本卷第 3 题正是对照这张表。
:::

:::callout{kind=pitfall label="易错警示"}
「节段性、没有周期性」是人精子发生的教材口径，不要写成像子宫内膜那样的周期。
:::

:::callout{kind=tip label="结论速记"}
精子发生：青春期、节段性、胞质桥、变态、一变四、睾丸内、低 $2\sim 3\,^{\circ}\mathrm{C}$、高雄激素、血睾屏障、精原细胞库存。
:::

### 第 4 题

:::callout{kind=note label="题目"}
试述卵圆孔未闭的原因。
:::

:::callout{kind=insight label="解析"}
**【答案】** 卵圆孔未闭的原因：

1. 卵圆孔瓣吸收，出现孔。
2. 第一房间隔过度吸收，导致第二房间孔过大。
3. 第二房间隔发育障碍，导致卵圆孔过大。
4. 第 2 条与第 3 条同时存在。

正常：第一房间隔上先有第一房间孔，下部吸收出第二房间孔；第二房间隔盖住第二房间孔，留下卵圆孔，左侧由第一房间隔当卵圆孔瓣。出生后左房压高，瓣贴死成卵圆窝。瓣破、孔太大或隔发育不够，左右房就关不住。
:::

:::callout{kind=note label="知识卡片：心房分隔两隔两孔"}
第一房间隔 + 第一／第二房间孔；第二房间隔 + 卵圆孔。瓣 = 第一房间隔。组胚名解的卵圆孔是心的，不是颅底的。
:::

:::callout{kind=tip label="结论速记"}
卵圆孔未闭：瓣穿了，或第二房间孔太大，或卵圆孔太大，或后两件一起。
:::
