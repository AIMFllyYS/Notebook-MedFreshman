### 第1题

:::callout{kind=note label="题目"}
其单层柱状上皮内不含杯状细胞的是（　　）

A. 胃　　B. 小肠　　C. 大肠　　D. 细支气管
:::

:::callout{kind=insight label="解析"}
**【答案】A（据教材 ch14 / ch16）**

胃上皮是单层柱状，主体是**表面黏液细胞**，教材写明不要写成杯状细胞。小肠、大肠上皮都夹杯状细胞。细支气管上皮渐变为单层纤毛柱状，杯状细胞**很少或消失**，到终末细支气管才全部消失；选项写的是「细支气管」，不是绝对不含。最佳答案是胃。
:::

:::callout{kind=note label="知识卡片：谁有杯状细胞"}
| 部位 | 上皮 | 杯状细胞 |
|------|------|----------|
| 胃 | 单层柱状（表面黏液细胞） | **无** |
| 小肠、大肠 | 单层柱状 | 有 |
| 细支气管 | 假复层 → 单层纤毛柱状 | 很少或消失 |
| 终末细支气管 | 单层柱状 | 全部消失 |
:::

:::callout{kind=pitfall label="易错警示"}
不要看见「单层柱状」就选细支气管。胃才是「单层柱状、明确无杯状」的标准户头。
:::

:::callout{kind=tip label="结论速记"}
单层柱状无杯状 → **胃**。
:::

### 第3题

:::callout{kind=note label="题目"}
位于骨骼肌表面的神经末梢主要是（　　）

A. free nerve ending　　B. tactile corpuscle
C. lamellar corpuscle　　D. motor nerve ending
:::

:::callout{kind=insight label="解析"}
**【答案】D（据教材 ch06 / ch07）**

:::

:::callout{kind=tip label="结论速记"}
骨骼肌表面主末梢 = **运动神经末梢**（运动终板）。
:::

### 第6题

:::callout{kind=note label="题目"}
关于中性粒细胞的描述，哪项错误（　　）

A. 白细胞中最多的一种
B. 细胞核分杆状核和分叶核
C. 杆状核的比例显著增高，临床上称核右移
D. 能作变形运动，具有活跃的吞噬能力
:::

:::callout{kind=insight label="解析"}
**【答案】C（据教材 ch05）**

杆状核比例显著增高是**核左移**（严重细菌感染时，大量新生细胞入血，杆状核与 2 叶核增多）。核右移是 $4\sim 5$ 叶核增多，提示骨髓造血障碍。A、B、D 都对。
:::

:::callout{kind=note label="知识卡片：核左移与核右移"}
| | 核左移 | 核右移 |
|--|--------|--------|
| 所见 | 杆状核、2 叶核增多 | $4\sim 5$ 叶核增多 |
| 含义 | 新生细胞提前入血 | 老龄细胞滞留 |
| 常见背景 | 严重细菌感染 | 骨髓造血障碍 |
:::

:::callout{kind=pitfall label="易错警示"}
左移 = 杆状核／更幼稚增多；右移 = 分叶过多。题干把左右写反。
:::

:::callout{kind=tip label="结论速记"}
杆状核增多 = **核左移**，不是右移。
:::

类骨质是指（　　）

A. 钙化的软骨基质　　B. 未钙化的软骨基质

:::callout{kind=insight label="解析"}

### 第17题

:::callout{kind=note label="题目"}
zona fasciculata in cortex of adrenal gland（　　）

A. 位于皮质最内层　　B. 分泌糖皮质激素
C. 腺细胞呈球形　　D. 腺细胞胞质嗜酸性
:::

:::callout{kind=insight label="解析"}
**【答案】B（据教材 ch13）**

束状带占皮质最厚，细胞呈索状（不是球形），分泌糖皮质激素。最内层是网状带；球状带在最外、细胞成团、泌盐皮质激素。束状带胞质因脂滴多而浅染泡沫状，不是「嗜酸性」这张身份证。
:::

:::callout{kind=note label="知识卡片：肾上腺皮质三带"}
| | 球状带 | 束状带（zona fasciculata） | 网状带 |
|--|--------|---------------------------|--------|
| 位置 | 最外、薄 | 最厚 | 最内层 |
| 排列 | 细胞成团 | 单行或双行细胞索 | 吻合成网 |
| HE | 脂滴较少 | 泡沫状浅染 | 胞质嗜酸、脂褐素多 |
| 激素 | 盐皮质激素 | **糖皮质激素**（皮质醇） | 雄激素为主 |
:::

:::callout{kind=tip label="结论速记"}
zona fasciculata = **束状带，糖皮质激素**。
:::

### 第24题

:::callout{kind=note label="题目"}
The nephron is composed of（　　）

A. renal corpuscle and uriniferous tubule
B. renal corpuscle and renal tubule
C. renal corpuscle and medullary loop
D. renal corpuscle and collecting tubule
:::

:::callout{kind=insight label="解析"}
**【答案】B（据教材 ch17）**

肾单位 = 肾小体 + 肾小管（proximal + thin + distal）。集合管另立，不写入肾单位。uriniferous tubule（泌尿小管）常指肾小管 + 集合管，和肾小体并写会重叠或越界。髓袢只是肾小管的一段。

:::callout{kind=note label="知识卡片：肾单位 ≠ 泌尿小管"}

**【答案】BC（据教材 ch21 / ch26）**

中枢神经系统来自**神经管**，不是神经嵴。教材写明神经嵴分化为脑／脊／自主神经节及周围神经；头端神经嵴还参与**颅面部骨骼和结缔组织**。另有肾上腺髓质嗜铬细胞、表皮黑素细胞，本题未列。
:::

:::callout{kind=note label="知识卡片：神经管 vs 神经嵴"}
| | 神经管 | 神经嵴 |
|--|--------|--------|
| 去向 | 脑、脊髓、神经垂体、松果体、视网膜 | 周围神经节及周围神经；肾上腺髓质；黑素细胞；头端颅面骨骼结缔组织 |
| 本题 | A 是它的账 | B、C |
:::

:::callout{kind=pitfall label="易错警示"}
D「心脏内部的分隔」在许多胚胎学讲义里会写成心脏神经嵴参与心球／动脉干隔。**本教材不这样写**：心球嵴、动脉干嵴是「内膜组织局部增生」，神经嵴衍生物名单也不含心脏。据教材不收 D。
:::

:::callout{kind=tip label="结论速记"}
神经嵴：周围神经、头面（及髓质、黑素）；中枢是神经管。本题据教材只收 **BC**。
:::

## 三、名词解释（每题 2 分，共 10 分）

### 第1题

:::callout{kind=note label="题目"}
气-血屏障
:::

:::callout{kind=insight label="解析"}
**【答案】（据教材 ch16）**

肺泡与血液之间进行气体交换所通过的结构，厚约 $0.2\sim 0.5\,\mu\mathrm{m}$。组成：肺泡表面液体层、Ⅰ型肺泡细胞及其基膜、薄层结缔组织（有处可无）、毛细血管基膜及内皮。最薄处两层基膜融合。
:::

:::callout{kind=note label="知识卡片：气–血屏障层次"}
肺泡表面液体层 → Ⅰ型肺泡细胞与基膜 →（可缺如的）薄层结缔组织 → 连续毛细血管基膜与内皮。总厚度 $0.2\sim 0.5\,\mu\mathrm{m}$，不是整层肺泡隔。
:::

:::callout{kind=tip label="结论速记"}
气血屏障 $0.2\sim 0.5\,\mu\mathrm{m}$：肺泡上皮 + 融合基膜 + 内皮。
:::

月经周期

门管区

### 第5题

:::callout{kind=note label="题目"}
胎盘膜
:::

:::callout{kind=insight label="解析"}
**【答案】（据教材 ch21）**

胎儿血与母体血进行物质交换所通过的结构，又称胎盘屏障。早期：合体滋养层 + 细胞滋养层及其基膜 + 薄层绒毛结缔组织 + 毛细血管基膜和内皮。后期／近足月：细胞滋养层在许多部位消失，常只隔以绒毛毛细血管内皮、薄层合体滋养层及两者的基膜。两套血不相混（绒毛间隙是母血）。

:::callout{kind=note label="知识卡片：胎盘膜两期"}
| | 早期 | 后期 |
|--|------|------|
| 层次 | 合体滋养层 + 细胞滋养层和基膜 + 绒毛结缔组织 + 毛细血管基膜和内皮 | 薄层合体滋养层 + 内皮 + 两者基膜 |
| 血 | 绒毛间隙 = 母血；绒毛毛细血管 = 胎儿血 | 同左，不相混 |
:::

:::callout{kind=tip label="结论速记"}
胎盘膜隔开母血（绒毛间隙）和胎儿血（绒毛毛细血管）；后期变薄。
:::

## 四、论述题（每题 5 分，共 25 分）

### 第1题

:::callout{kind=note label="题目"}
试述周围神经系统有髓和无髓神经纤维的结构。
:::

:::callout{kind=insight label="解析"}
**【答案】（据教材 ch07）**

周围神经纤维 = 轴突 + 神经膜细胞（Schwann）。

**有髓**

一条轴突由一连串 Schwann 细胞包卷，每细胞形成一段髓鞘；相邻细胞之间是郎飞结（轴膜裸露）。结间体有髓鞘切迹（施-兰切迹）。冲动在结间**跳跃传导**。

**无髓**

一个 Schwann 细胞凹陷容纳多条轴突，不形成多层髓鞘，无郎飞结。冲动沿轴膜**连续传导**，速度慢。

两者外包基膜；神经纤维外面还可有神经内膜。
:::

:::callout{kind=tip label="结论速记"}
有髓：一轴突一段髓鞘，结间跳跃。无髓：一细胞多条轴突，连续传导。
:::

### 第2题

:::callout{kind=note label="题目"}
试比较淋巴结和脾结构上的同异。
:::

:::callout{kind=insight label="解析"}
**【答案】（据教材 ch10）**

**相同**

结缔组织被膜 + 实质淋巴组织；都有淋巴小结（B 区）和 T 区（副皮质 / PALS）；都有巨噬细胞，过滤并参与免疫。

**相异**

| | 淋巴结 | 脾 |
|--|--------|-----|
| 被膜 | 结缔组织 | 结缔组织 + 平滑肌，表面有间皮 |
| 输入淋巴管 | 有 | 无 |
| 淋巴窦 | 有 | 无 |
| 血窦 | 无 | 有（脾血窦） |
| T 区 | 副皮质（有 HEV） | PALS（无 HEV） |
| 过滤对象 | 淋巴 | 血液 |

:::

:::callout{kind=tip label="结论速记"}
淋巴结滤淋巴（输入管 + 淋巴窦）；脾滤血（血窦，无输入淋巴管）。
:::

### 第3题

:::callout{kind=note label="题目"}
试比较卵子发生与精子发生的同异。
:::

:::callout{kind=insight label="解析"}
**【答案】（据教材 ch18 / ch19）**

**相同**

都由原始生殖细胞迁入性腺；都经历核型 2n → 减数分裂；最终形成单倍体配子；都受下丘脑–垂体–性腺轴调控。

**相异**

| | 精子发生 | 卵子发生 |
|--|---------|---------|
| 开始 | 青春期后连续 | 胚胎期已启动，初级卵母停在 MI 双线期 |
| 场所 | 生精小管（近腔室） | 卵巢卵泡内 |
| 1 个初级性母 | 4 个精子 | 1 个卵 + 极体 |
| 减数完成 | 在睾丸内完成 | MI 在排卵前，MII 在受精时 |
| 支持结构 | 支持细胞、血-睾屏障 | 卵泡细胞、透明带、放射冠 |
| 变态 | 有精子形成（丢胞质、长尾、顶体） | 无「变态」，体积大、贮营养 |
:::

:::callout{kind=tip label="结论速记"}
精子：连续、1 出 4、睾丸内完成。卵：胚胎已启动、1 出 1、MII 等受精。
:::

### 第4题

:::callout{kind=note label="题目"}
试比较近曲小管和远曲小管的结构特点及功能。
:::

:::callout{kind=insight label="解析"}
**【答案】（据教材 ch17）**

| | 近曲小管 | 远曲小管 |
|--|---------|---------|
| 上皮 | 单层立方或锥体，细胞大，界线不清 | 单层立方，细胞较小，界线清楚 |
| 游离面 | 发达刷状缘（微绒毛） | 无刷状缘，有少量短微绒毛 |
| 基部 | 质膜内褶发达，纵行线粒体多（纹状缘基底） | 质膜内褶更明显，线粒体排成基底纵纹 |

### 第5题

:::callout{kind=note label="题目"}
试述神经外胚层的发育。
:::

:::callout{kind=insight label="解析"}
**【答案】（据教材 ch26）**

第 3 周末，胚盘中轴背侧外胚层在脊索诱导下增厚为**神经板**，中央凹陷为神经沟，两侧隆起为神经褶。第 4 周神经褶愈合为**神经管**，与表面外胚层分离。愈合由中段向头、尾进展，头、尾各留神经孔，先后关闭。

管壁最初单层柱状，后成假复层神经上皮，再分室管膜层、套层、边缘层；套层分化成神经细胞和神经胶质，形成中枢（脑、脊髓），并参与神经垂体、松果体、视网膜等。

神经褶愈合时，一部分细胞留在管与表面外胚层之间，成**神经嵴**，迁出后形成周围神经节、肾上腺髓质、头面部间充质等——神经嵴已不算「神经管里的一层」。

表面外胚层另走表皮，不要和神经外胚层并户。
:::

:::callout{kind=note label="知识卡片：神经外胚层两本账"}
| | 神经管 | 神经嵴 |
|--|--------|--------|
| 去向 | 脑、脊髓、神经垂体、视网膜等 | 周围神经、髓质、头面间充质等 |
:::

:::callout{kind=tip label="结论速记"}
神经板 → 沟 → 管（中枢）；夹带神经嵴（周围）。表面外胚层不进这本账。
:::
