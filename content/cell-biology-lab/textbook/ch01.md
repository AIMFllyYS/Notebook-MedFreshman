# 实验一　细胞原代培养

本课是华中科技大学同济医学院基础医学院 **2021 年 3 月**《细胞生物学实验讲义（供基础医学专业使用）》，与书架上的《医学细胞生物学》理论课分开：理论课讲结构与机制，这门课在超净台里把组织做成可传代的细胞。实验一是整门课的入口——**原代培养**。

:::insight{label="为什么先做原代，而不是直接传 HeLa"}
从机体取出的细胞还没被「驯化」成细胞系。它们暂时保留二倍体核型与原组织的基本性质，也最容易被污染、消化过度或干死。后面的传代、冻存、转染、融合，全部建立在「第一次把组织离散成活细胞」之上。
:::

## 原代培养是什么

:::definition{label="原代培养"}
动物组织从机体取出后，用酶（胶原酶、胰蛋白酶）、螯合剂（EDTA）或机械方法离散成单个细胞悬液，置于合适培养基中，使细胞生存、生长、繁殖。这种对**直接从机体获得的细胞**所做的培养，称为原代培养。较严格地说，是指**成功传代之前**的培养：此时细胞保持原有基本性质，正常体细胞仍为**二倍体**。
:::

常用两条路：

:::compare{title="消化培养法 vs 组织块培养法"}
| | 消化培养法 | 组织块培养法 |
|---|---|---|
| 离散方式 | 胰酶把组织块消化成悬液，接种细胞 | 1 mm$^3$ 小块贴于瓶底，细胞从块缘爬出 |
| 本实验材料 | 乳鼠肝脏 | 同一取材，接在消化法「取材」之后 |
| 观察终点 | 计数后按 $5\times 10^5$/ml 接种 | 观察接种组织周围新长出的细胞 |
:::

## 目的要求

- 熟悉细胞原代培养的基本原理。
- 了解原代培养的方法和操作。
- **掌握**细胞培养过程中的无菌操作技术。

## 材料与设备

- **材料**：乳鼠。
- **器材**：$\mathrm{CO}_2$ 培养箱、培养瓶、15 ml 离心管、平皿、吹打管、手术器械、血球计数板、离心机、水浴箱、微量移液器、枪头。
- **试剂**：75% 酒精及喷壶、无菌 PBS、含 10% 血清的 RPMI-1640、胎牛血清、0.25% 胰酶-EDTA。

---

## 一、消化培养法

### （一）取材

1. 乳鼠**颈椎脱臼**致死，置 75% 酒精泡 **5 秒**，超净台内解剖取肝脏，置平皿。
2. 无菌 PBS 洗涤 3 次，剔除脂肪、结缔组织、血液。
3. 手术剪将肝脏剪成约 **1 mm$^3$** 小块，PBS 再洗 3 次，转入 15 ml 离心管。

:::pitfall{label="酒精浸泡不是灭菌澡"}
只泡 5 秒：够表面消毒，不够把组织泡熟。时间过长，边缘肝细胞已经固定，后面消化出来的是死细胞。
:::

### （二）消化离散细胞

1. 加入 **5 倍于组织块体积**的 0.25% 胰酶，37 ℃ 水浴 **30 min**，每隔 5 min 振荡一次。
2. 加入 3 ml **含血清**培养液，吸管吹打，**终止胰酶**。
3. 静置 3 min，组织块下沉，取**上层细胞悬液**到新离心管。
4. 平衡后 **1000 rpm × 5 min**，弃上清。
5. PBS 5 ml 冲散，再离心一次，弃上清。
6. 加入含 10% 血清的培养液 2 ml，重悬。

:::keypoint{label="血清为什么能停胰酶"}
胰酶把细胞外基质和细胞间连接切散；血清里有大量蛋白底物，把残余酶活「抢走」。没有血清的 PBS 洗不掉已经切过的酶，也不能当作终止液。
:::

### （三）计数、接种和培养

1. 血球计数板计数（方法见实验二）。
2. 调整到约 $5\times 10^5$/ml，取 4 ml 转入 50 ml 培养瓶，37 ℃ $\mathrm{CO}_2$ 培养箱培养。

$$
\text{接种密度} \approx 5\times 10^{5}\ \mathrm{ml}^{-1}
$$

---

## 二、组织块培养法

步骤接到消化法的「取材」之后：

1. 无菌取材，肝脏剪成约 1 mm$^3$，**Hank's 液**再洗 3 次，将组织块转移到培养瓶，**贴附瓶底**。
2. **翻转瓶底朝上**，加入培养液，液体**不要碰到组织块**。
3. 37 ℃ $\mathrm{CO}_2$ 培养箱静置 **3 h**，轻轻翻转，使组织浸入培养液，继续培养。
4. 观察从接种组织**周围**新生长出来的细胞。

:::insight{label="为什么先倒置 3 小时"}
组织块要先靠表面张力贴住玻璃。如果立刻让液体淹没，块会漂起来，细胞没有「爬行的岸」。贴牢后再翻转，才是从块缘长细胞，而不是一瓶浑浊碎片。
:::

## 无菌操作（本课反复考）

讲义把注意事项写在消化法后面，组织块法同样适用。

:::pitfall{label="超净台里有酒精灯"}
「超净台内**有**酒精灯，注意安全和防火。」不要把灯放在酒精喷壶正下方，也不要在火焰上烤已经吸过培养液的吸管——会烧焦培养基，碳化颗粒掉进瓶里。
:::

- 自取材起，组织细胞保持无菌；**细胞计数可以在有菌环境**进行。
- 台面布局合理，手不碰消毒器皿的工作端；吸溶液的吸管**不能混用**。
- 操作前洗手；入台后手用 75% 酒精或 0.2% 新洁尔灭擦拭。
- 操作在火焰附近；耐热物品经常烧灼，**冷却后**才能接触组织。
- 动作准确敏捷，但不要太快（气流把菌带进来）。
- 瓶子开口后尽量保持 **45° 斜位**。
- 组织、培养液不能暴露过久：蒸发会改变渗透压，损伤细胞。

:::memory{label="原代培养清单"}
- [ ] 原代 = 传代成功之前，正常体细胞仍为二倍体
- [ ] 两条路：消化法（悬液接种）/ 组织块法（块缘爬出）
- [ ] 胰酶 0.25%，37 ℃ 30 min，含血清培养液终止
- [ ] 1000 rpm × 5 min；接种约 $5\times 10^5$/ml
- [ ] 组织块：先贴底、瓶倒置 3 h，液面勿提前淹没
- [ ] 计数可在有菌环境；取材以后都必须无菌
:::

:::memory{label="无菌口诀" mode="cloze"}
开口瓶子保持 **45°** 斜位；吸过营养液的用具**不能再烧灼**；组织块培养要先让块贴壁 **3 小时**再翻转浸液。
:::
