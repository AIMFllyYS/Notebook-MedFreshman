### 第1题

:::callout{kind=note label="题目"}
"欲知大道，必先为史。灭人之国，必先去其史。"这句话揭示的道理是（　　）

A．历史无关紧要　B．历史学习与民族国家兴衰命运紧密相关，须警惕历史虚无主义　C．只有专业史学家才需要读史　D．历史可以随意假设
:::

:::callout{kind=insight label="解析"}
**【答案】B**

该名言揭示历史是一个民族的根脉与灵魂，抛弃或歪曲历史将危及民族存续，这正是我们必须坚持正确历史观、抵御历史虚无主义的原因。
:::

### 第10题

:::callout{kind=note label="题目"}
新民主主义革命之所以能够取得胜利，其基本经验（三大法宝）是（　　）

A．统一战线　B．武装斗争　C．党的建设　D．改革开放
:::

:::callout{kind=insight label="解析"}
**【答案】ABC**

统一战线、武装斗争、党的建设是中国共产党在中国革命中战胜敌人的三大法宝。改革开放是社会主义现代化建设新时期的重大决策，不属于新民主主义革命经验。
:::

:::callout{kind=note label="知识卡片：三大法宝"}
| 法宝 | 内涵 |
|------|------|
| **统一战线** | 团结一切可以团结的力量 |
| **武装斗争** | 以武装的革命反对武装的反革命 |
| **党的建设** | 思想建党、政治建军、组织建设 |
:::

:::callout{kind=tip label="结论速记"}
三大法宝 = 统一战线 + 武装斗争 + 党的建设（不含改革开放）。
:::

## 三、简答题（每题 8 分，共 32 分）

### 第1题

:::callout{kind=note label="题目"}
简述新文化运动的主要内容及其历史意义。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**兴起：** 1915年9月陈独秀创办《青年杂志》（后改名《新青年》），标志新文化运动兴起；北京大学和《新青年》成为主要阵地。（1分）

**主要内容：** ①提倡民主，反对专制（"德先生"）；②提倡科学，反对迷信盲从（"赛先生"）；③提倡新道德，反对旧道德；④提倡新文学，反对旧文学，发动文学革命、倡导白话文。（4分）

**历史意义：** ①是一次前所未有的思想解放运动，动摇了封建正统思想的统治地位；②大力宣传民主和科学，启发人们追求真理与进步；③为马克思主义在中国的传播和五四运动的爆发创造了有利条件。（3分）
:::

### 第2题

:::callout{kind=note label="题目"}
简述第一次国共合作的政治基础及大革命失败的原因。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**政治基础：** 1924年国民党一大对三民主义作出新的解释，形成新三民主义（联俄、联共、扶助农工三大政策），新三民主义与中国共产党在民主革命阶段的纲领基本一致，成为国共合作的政治基础。（2分）

**失败的客观原因：** 反革命力量比较强大；资产阶级发生了严重的动摇，国民党右派叛变革命。（3分）

**失败的主观原因：** 年幼的中国共产党缺乏应对复杂环境的政治经验，缺乏对中国社会和中国革命基本问题的深刻认识，不善于把马克思列宁主义基本原理同中国革命实际相结合；以陈独秀为代表的右倾机会主义错误在党的领导机关中占了统治地位，放弃了对革命特别是对武装力量的领导权。（3分）
:::

### 第3题

:::callout{kind=note label="题目"}
抗日战争中，中国共产党提出的全面抗战路线和持久战战略总方针的主要内容是什么？（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**全面抗战路线：** 与国民党片面抗战路线不同，中国共产党实行全面抗战路线，即人民战争路线。1937年8月洛川会议制定《抗日救国十大纲领》，强调实行全国军事总动员和全国人民总动员，改革政治机构，给人民以充分的抗日民主权利，适当改善工农大众生活，坚持统一战线中无产阶级的领导权。（4分）

**持久战总方针：** 1938年毛泽东发表《论持久战》，批驳"亡国论"和"速胜论"。指出中国是弱国、但是大国，进行的是进步的正义战争、得道多助；日本是强国、但是小国，进行的是退步的野蛮战争、失道寡助。科学预见抗战将经过战略防御、战略相持、战略反攻三个阶段，战略相持阶段是转弱为强的关键；强调"兵民是胜利之本"，最后胜利必属于中国。（4分）
:::

### 第4题

:::callout{kind=note label="题目"}
简述人民解放战争迅速取得胜利的主要原因。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

①中国共产党的正确领导：制定了正确的政治、军事路线和方针政策，坚持人民民主统一战线，采取集中优势兵力、各个歼灭敌人的作战原则。（2分）

②在解放区开展土地改革：1947年公布《中国土地法大纲》，实行耕者有其田，1亿多人口的解放区消灭了封建生产关系，赢得广大农民的衷心拥护，为战争提供了源源不断的人力物力支援。（2分）

③得到各民主党派和广大人民群众的拥护支持：中国共产党真心追求和平民主、团结各民主党派，形成了最广泛的人民民主统一战线。（2分）

④国民党方面政治腐败、经济崩溃、丧失民心：横征暴敛、通货膨胀、独裁内战，把自己推向全国人民的对立面，走向自我毁灭。（2分）
:::

:::callout{kind=tip label="结论速记"}
解放战争胜利四因 = 党的领导 + 土改赢农民 + 统一战线 + 国民党失民心。
:::

## 四、材料分析题（每题 14 分，共 28 分）

### 第1题

:::callout{kind=note label="题目"}
**材料分析题一**

材料一：1919年5月4日，北京三千多名学生在天安门前集会游行，提出"外争主权，内除国贼""取消二十一条""还我青岛"等口号，痛打卖国贼、火烧赵家楼。此后运动扩展到全国二十多个省区和一百多个城市，工人罢工、商人罢市，中国工人阶级作为独立的政治力量登上历史舞台。

材料二：习近平指出，五四运动以全民族的行动激发了追求真理、追求进步的伟大觉醒，实现了中国人民和中华民族自鸦片战争以来的第一次全面觉醒；孕育了以爱国、进步、民主、科学为主要内容的伟大五四精神，其核心是爱国主义。

（1）依据材料，概括五四运动的历史特点。（6分）

（2）结合材料，说明五四运动的历史意义及五四精神的内涵。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**（1）** ①五四运动是一场以先进青年知识分子为先锋、广大人民群众参加的彻底反帝反封建的伟大爱国革命运动；（2分）

②是一场为拯救民族危亡、捍卫民族尊严、凝聚民族力量而掀起的伟大社会革命运动；（2分）

③是一场传播新思想新文化新知识的伟大思想启蒙运动和新文化运动，工人阶级第一次作为独立政治力量登上历史舞台，表现出彻底反帝反封建的革命性、进步性和广泛性。（2分）

**（2）历史意义：** ①五四运动是中国旧民主主义革命走向新民主主义革命的转折点，是中国新民主主义革命的开端，具有里程碑意义；②促进了马克思主义在中国的传播及其同中国工人运动的结合，为中国共产党的成立作了思想上干部上的准备；③以全民族之力激发了追求真理和进步的伟大觉醒，实现了近代以来第一次全面觉醒；④培育了永久奋斗的伟大传统。（5分）

**五四精神：** 孕育了以爱国、进步、民主、科学为主要内容的伟大五四精神，其核心是爱国主义。（3分）
:::

:::callout{kind=note label="知识卡片：五四运动"}
| 要素 | 内容 |
|------|------|
| **时间** | 1919年5月4日 |
| **导火索** | 巴黎和会中国外交失败 |
| **特点** | 彻底反帝反封建 + 广泛群众性 + 工人阶级登上舞台 |
| **意义** | 新民主主义革命开端 + 为中共成立作准备 + 第一次全面觉醒 |
| **五四精神** | 爱国、进步、民主、科学（核心：爱国主义） |
:::

### 第2题

:::callout{kind=note label="题目"}
**材料分析题二**

材料一：大革命失败后，毛泽东率领秋收起义部队进军井冈山，创建了第一个农村革命根据地。他先后写下《中国的红色政权为什么能够存在？》《井冈山的斗争》《星星之火，可以燎原》等著作。

材料二：毛泽东指出："红色政权首先发生和能够长期地存在的地方，不是那种并未经过民主革命影响的地方……而是在一九二六和一九二七两年资产阶级民主革命过程中工农兵士群众曾经大大地起来过的地方。"

（1）结合材料，说明中国革命新道路的主要内容。（6分）

（2）为什么中国的红色政权能够存在和发展？（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**（1）** 中国革命新道路即农村包围城市、武装夺取政权的道路。（2分）

其主要内容是：把党的工作重心由城市转向农村，在农村建立革命根据地，开展土地革命，进行武装斗争，把武装斗争、土地革命、根据地建设三者结合起来，逐步积累和发展革命力量，最后夺取全国政权。（4分）

**（2）** ①中国是一个几个帝国主义国家间接统治的政治经济发展极端不平衡的半殖民地半封建大国，为红色政权的存在提供了缝隙和可能（根本原因）；（2分）

②国民革命（大革命）的政治影响，使有过民主革命影响、工农群众曾大大发动起来的地方具备了群众基础；（2分）

③全国革命形势的继续向前发展；（1分）

④相当力量的正式红军的存在；（1分）

⑤共产党组织的有力量和它的政策的正确，是红色政权能够存在和发展的最重要的主观条件。（2分）
:::

:::callout{kind=note label="知识卡片：红色政权存在发展的五条原因"}
| 序号 | 原因 |
|------|------|
| **一（根本）** | 政治经济发展极端不平衡的半殖民地半封建大国 |
| **二** | 大革命的政治影响，群众基础 |
| **三** | 全国革命形势继续向前发展 |
| **四** | 相当力量的正式红军存在 |
| **五（主观）** | 党的组织有力量和政策的正确 |
:::

:::callout{kind=tip label="结论速记"}
红色政权五因 = 不平衡（根本）+ 大革命影响 + 革命形势 + 红军力量 + 党的正确领导。
:::
