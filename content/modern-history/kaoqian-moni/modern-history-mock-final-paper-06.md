# 近现代史纲要2026期末押题冲刺卷三（Perplexity生成）

## 一、单项选择题（每题 2 分，共 20 分）

A．中共八大　B．中共十一届三中全会　C．中共十二大　D．中共十四大

### 第10题

## 五、论述题（每题 10 分，共 20 分）

### 第22题

:::callout{kind=note label="题目"}
试论述中共十一届三中全会实现伟大历史转折的重大意义。
:::

:::callout{kind=insight label="解析"}
**要点展开：**

**（1）重新确立了解放思想、实事求是的思想路线：** 全会冲破了长期"左"倾错误的严重束缚，彻底否定了"两个凡是"的错误方针，重新确立了马克思主义的思想路线。

**（2）作出了把党和国家工作中心转移到经济建设上来、实行改革开放的历史性决策：** 停止使用"以阶级斗争为纲"的口号，作出了把全党工作着重点和全国人民的注意力转移到社会主义现代化建设上来的战略决策。

**（3）形成了以邓小平为核心的党的第二代中央领导集体：** 全会实际上形成了以邓小平为核心的党中央领导集体，为改革开放和现代化建设提供了坚强的领导保证。

**结论：** 中共十一届三中全会是新中国成立以来党的历史上具有深远意义的伟大转折，开启了改革开放和社会主义现代化建设的新时期。
:::

:::callout{kind=note label="知识卡片：十一届三中全会"}
| 要素 | 内容 |
|------|------|
| **思想路线** | 重新确立解放思想、实事求是 |
| **战略决策** | 工作重心转移到经济建设，实行改革开放 |
| **领导集体** | 形成以邓小平为核心的第二代中央领导集体 |
| **历史定位** | 新中国成立以来党的历史上具有深远意义的伟大转折 |
:::

:::callout{kind=tip label="结论速记"}
十一届三中全会 = 解放思想 + 以经济建设为中心 + 改革开放 + 邓小平核心。
:::

### 第23题

:::callout{kind=note label="题目"}
结合史实，论述中国特色社会主义进入新时代取得的历史性成就、历史性变革及其世界意义。
:::

:::callout{kind=insight label="解析"}
应从经济实力历史性跃升、脱贫攻坚战全面胜利、全面建成小康社会、生态文明建设成效显著、国防和军队建设取得历史性成就、国际影响力显著提升、为人类和平与发展贡献中国智慧和中国方案等方面展开论述，体现中华民族伟大复兴进入不可逆转的历史进程这一核心判断。

**要点展开：**

**（1）经济实力历史性跃升：** 国内生产总值稳居世界第二，经济结构持续优化，高质量发展稳步推进。

**（2）脱贫攻坚战全面胜利：** 现行标准下农村贫困人口全部脱贫，贫困县全部摘帽，创造了人类减贫史上的奇迹。

**（3）全面建成小康社会：** 如期实现第一个百年奋斗目标，兑现了对人民的庄严承诺。

**（4）生态文明建设成效显著：** "绿水青山就是金山银山"理念深入人心，碳达峰、碳中和目标有序推进。

**（5）国防和军队建设取得历史性成就：** 人民军队体制一新、结构一新、格局一新、面貌一新。

**（6）国际影响力显著提升：** 提出构建人类命运共同体理念，"一带一路"倡议惠及全球，为人类和平与发展贡献了中国智慧和中国方案。

**结论：** 中国特色社会主义进入新时代，中华民族迎来了从站起来、富起来到强起来的伟大飞跃，中华民族伟大复兴进入了不可逆转的历史进程。
:::

:::callout{kind=note label="知识卡片：新时代历史性成就"}
| 领域 | 成就 |
|------|------|
| **经济** | GDP稳居世界第二，高质量发展 |
| **脱贫** | 农村贫困人口全部脱贫，贫困县全部摘帽 |
| **小康** | 全面建成小康社会，实现第一个百年目标 |
| **生态** | 绿水青山理念，碳达峰碳中和 |
| **国防** | 人民军队面貌一新 |
| **外交** | 人类命运共同体，"一带一路" |
:::

:::callout{kind=tip label="结论速记"}
新时代成就 = 经济跃升 + 脱贫奇迹 + 全面小康 + 生态文明 + 强军 + 大国外交 → 中华民族伟大复兴不可逆转。
:::
