| **另一对矛盾** | 封建主义与人民大众的矛盾 |
| **两大历史任务** | 争取民族独立、人民解放；实现国家富强、人民富裕 |
:::

:::callout{kind=tip label="结论速记"}

### 第5题

:::callout{kind=note label="题目"}
《天朝田亩制度》所贯穿的基本精神是（　　）

A．发展资本主义工商业　B．绝对平均主义　C．君主立宪　D．耕者有其田的近代土地私有
:::

:::callout{kind=insight label="解析"}
**【答案】B**

《天朝田亩制度》以解决土地问题为中心，否定封建地主土地所有制，主张按人口平均分配土地、财物统归圣库，贯穿的是绝对平均主义，但脱离实际，未能真正实行。
:::

:::callout{kind=tip label="结论速记"}
《天朝田亩制度》= 绝对平均主义（空想）；《资政新篇》= 最早发展资本主义方案。
:::

:::

:::callout{kind=insight label="解析"}
**【答案】D**

:::callout{kind=tip label="结论速记"}
兴中会（1894）= 第一个革命团体；同盟会（1905）= 第一个全国性政党。

## 三、简答题（每题 8 分，共 32 分）

### 第1题

:::callout{kind=note label="题目"}
比较《天朝田亩制度》与《资政新篇》，并对二者作简要评价。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**《天朝田亩制度》：** 以解决土地问题为中心，否定封建地主土地所有制，主张按人口平均分配土地、财物统归圣库，贯穿绝对平均主义。它是农民愿望的反映，但脱离实际，未能真正实行，具有空想性。（3分）

**《资政新篇》：** 1859年洪仁玕提出，主张发展近代工商业、交通银行、奖励科技、与外国平等通商，是中国近代第一个带有鲜明资本主义色彩的社会改革方案。但未反映农民土地要求，因战争环境未能实践。（3分）

**评价：** 两者反映了太平天国从农业空想到发展资本主义的转变，但都未能实施。前者体现农民阶级局限性，后者缺乏社会基础，说明农民阶级和太平天国无法找到中国现代化的正确道路。（2分）
:::

### 第2题

:::callout{kind=note label="题目"}
简述辛亥革命的历史意义。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

辛亥革命是资产阶级领导的以反对封建君主专制、建立资产阶级共和国为目的的比较完全意义上的资产阶级民主革命，是中华民族救亡图存、振兴中华的一座里程碑。（1分）

第一，推翻了封建势力的政治代表、帝国主义在中国的代理人清王朝的统治，沉重打击了中外反动势力。（1.5分）

第二，结束了中国延续两千多年的封建君主专制制度，建立了中国历史上第一个资产阶级共和政府，使民主共和的观念开始深入人心。（1.5分）

第三，推动了中国人民的思想解放，打开了禁锢思想进步的闸门，激发了人民的爱国热情和民族觉醒。（1.5分）

第四，推动了中国的社会变革，促使社会经济、思想习惯和社会风俗等方面发生新的积极变化。（1.5分）

第五，不仅在一定程度上打击了帝国主义侵略势力，而且推动了亚洲各国民族解放运动的高涨。（1分）
:::

:::callout{kind=note label="知识卡片：辛亥革命历史意义（教材五点·必背）"}
| 序号 | 要点 |
|------|------|
| **一** | 推翻清王朝，沉重打击中外反动势力 |
| **二** | 结束两千年君主专制，建立共和政府，民主共和深入人心 |
| **三** | 推动思想解放，激发爱国热情和民族觉醒 |
| **四** | 推动社会变革，经济思想风俗发生积极变化 |
| **五** | 打击帝国主义，推动亚洲民族解放运动 |
:::

:::callout{kind=tip label="结论速记"}
辛亥革命五点意义 = 推清廷 + 结帝制 + 解思想 + 变社会 + 促亚洲。
:::

### 第3题

:::callout{kind=note label="题目"}
为什么说五四运动是中国新民主主义革命的开端？（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

五四运动发生在新的社会历史条件下，具有旧民主主义革命所不具备的新的历史特点。（1分）

第一，它表现了彻底反对帝国主义、封建主义的革命性；具有追求救国强国真理的进步性；具有各族各界群众积极参与的广泛性。（2分）

第二，它促进了马克思主义在中国的传播，促进了马克思主义同中国工人运动的结合，为中国共产党的成立作了思想上干部上的准备。（2分）

第三，它是无产阶级开始登上政治舞台、并展现出伟大力量的运动，中国工人阶级作为独立政治力量登上历史舞台。（1.5分）

第四，它发生在俄国十月革命之后，属于世界无产阶级社会主义革命的一部分。因此，五四运动成为中国旧民主主义革命向新民主主义革命转变的转折点，是新民主主义革命的开端。（1.5分）
:::

### 第4题

:::callout{kind=note label="题目"}
简述遵义会议的主要内容及其历史意义。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**背景：** 1935年1月，红军长征途中中共中央在贵州遵义召开政治局扩大会议。（1分）

**主要内容：** 集中解决了当时具有决定意义的军事问题和组织问题，纠正了博古等人在军事上的"左"倾错误；肯定了毛泽东的正确军事主张；改组了中央领导机构，增选毛泽东为政治局常委，实际上确立了毛泽东在党和红军中的领导地位。（3分）

**历史意义：** 遵义会议开始确立以毛泽东为主要代表的马克思主义正确路线在党中央的领导地位，开始形成以毛泽东为核心的党中央的正确领导；在极其危急的关头挽救了党、挽救了红军、挽救了中国革命；是党的历史上一个生死攸关的转折点，标志着中国共产党在政治上开始走向成熟，是党独立自主解决中国革命问题的重要标志。（4分）
:::

:::callout{kind=tip label="结论速记"}
遵义会议 = 纠"左"倾 + 确立毛泽东领导 + 生死攸关转折点 + 党走向成熟。

## 四、材料分析题（每题 14 分，共 28 分）

### 第1题

:::callout{kind=note label="题目"}
**材料分析题一**

材料一：张之洞在《劝学篇》中说："中学为内学，西学为外学；中学治身心，西学应世事……新旧兼学，四书五经、中国史事、政书、地图为旧学，西政、西艺、西史为新学。旧学为体，新学为用，不使偏废。"

材料二：19世纪60年代起，洋务派创办了江南制造总局、福州船政局、汉阳铁厂、轮船招商局等一批近代军事和民用企业，建立了新式海陆军，开办新式学堂并派遣留学生。1895年甲午战争中，号称"亚洲第一"的北洋海军全军覆没。

（1）材料一反映了洋务运动怎样的指导思想？如何理解其实质？（6分）

（2）结合材料二，分析洋务运动的历史作用及其失败的根本原因。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**（1）指导思想：** "中学为体，西学为用"，即以中国封建纲常名教为根本，以西方近代科学技术为辅助。（2分）

**实质：** 它主张在不触动封建制度根本（"体"）的前提下，利用西方近代科技（"用"）来维护清王朝的封建统治秩序，中学始终支配、统率西学。（2分）

**评价：** 这一思想为学习西方近代技术提供了一定合法性依据，但从根本上限制了向西方学习的深度，反映了洋务派维护封建统治的阶级立场。（2分）

**（2）历史作用：** ①客观上促进了中国民族资本主义的产生和发展；②促进了中国近代教育事业（新式学堂、留学生、翻译西书）；③一定程度上抵制了外国经济势力的扩张；④传播新知识，促进了社会风气和价值观念的转变。（4分）

**失败根本原因：** 洋务运动以"中学为体、西学为用"为指导，只学西方科技而不触动封建制度，企图在维护腐朽封建统治秩序的前提下实现自强求富，先进的生产力同封建生产关系及上层建筑不相容，注定失败。此外，洋务企业管理腐败、对外国具有依赖性，甲午海战北洋海军全军覆没宣告其破产。（4分）
:::

:::callout{kind=note label="知识卡片：洋务运动"}
| 要素 | 内容 |
|------|------|
| **指导思想** | 中学为体，西学为用（张之洞《劝学篇》） |
| **实质** | 不触动封建制度，用西方科技维护封建统治 |
| **历史作用** | 促进民族资本主义、近代教育、抵制外经扩张、转变社会风气 |
| **失败根本原因** | 只学技术不变制度，生产力与封建生产关系不相容 |
| **失败标志** | 1895甲午战争北洋海军全军覆没 |
:::

### 第2题

:::callout{kind=note label="题目"}
**材料分析题二**

材料一：毛泽东在《论持久战》中指出："中日战争不是任何别的战争，乃是半殖民地半封建的中国和帝国主义的日本之间的一个决死的战争。""兵民是胜利之本"，"战争的伟力之最深厚的根源，存在于民众之中"。

材料二：2025年9月3日，习近平在纪念中国人民抗日战争暨世界反法西斯战争胜利80周年大会上指出：中国人民抗日战争是艰苦卓绝的伟大战争，"在中国共产党倡导建立的抗日民族统一战线旗帜下，中国人民以铮铮铁骨战强敌、以血肉之躯筑长城，取得近代以来反抗外敌入侵的第一次完全胜利"。

（1）依据材料一，简述中国共产党提出的全面抗战路线和持久战战略总方针的主要内容。（7分）

（2）综合两则材料，说明为什么中国共产党是全民族抗战的中流砥柱。（7分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**（1）全面抗战路线：** 即人民战争路线。1937年8月洛川会议制定《抗日救国十大纲领》，强调要实行全国军事总动员和全国人民总动员，改革政治机构，给人民以充分的抗日民主权利，适当改善工农大众生活，坚持统一战线中无产阶级的领导权。它与国民党单纯依靠政府和军队的片面抗战路线根本不同。（4分）

**持久战方针：** 毛泽东发表《论持久战》，批驳"亡国论""速胜论"，指出中国是弱国但是大国、进行的是进步的正义战争、得道多助，日本是强国但是小国、进行的是退步的野蛮战争、失道寡助；科学预见抗战将经过战略防御、战略相持、战略反攻三个阶段，最后胜利必属于中国，强调"兵民是胜利之本"。（3分）

**（2）** ①中国共产党倡导、促成并坚持维护抗日民族统一战线，坚持团结抗战、反对分裂投降，是维护全民族团结的核心力量。（2分）

②党提出并实行全面抗战路线和持久战战略总方针，为抗战胜利指明了正确方向。（2分）

③党开辟广大敌后战场、领导人民军队开展游击战争，建立抗日根据地，逐步成为坚持抗战的主要力量，抗击了大部分侵华日军和几乎全部伪军。（2分）

④党加强自身建设、推进马克思主义中国化，成为凝聚民族力量的坚强领导核心。正因如此，才取得了近代以来反抗外敌入侵的第一次完全胜利。（1分）
:::

:::callout{kind=note label="知识卡片：抗日战争中流砥柱"}
| 要素 | 内容 |
|------|------|
| **全面抗战路线** | 洛川会议《抗日救国十大纲领》，人民战争路线 |
| **持久战方针** | 《论持久战》三阶段：防御→相持→反攻 |
| **中流砥柱四点** | ①维护统一战线 ②正确路线方针 ③开辟敌后战场 ④加强自身建设 |
| **胜利意义** | 近代以来反抗外敌入侵的第一次完全胜利 |
:::

:::callout{kind=tip label="结论速记"}
中流砥柱 = 统一战线 + 全面抗战 + 敌后战场 + 党的建设；持久战 = 防御→相持→反攻。
:::
