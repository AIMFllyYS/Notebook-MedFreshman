### 第1题

:::callout{kind=note label="题目"}
1949年之前的中国历史称为中国近代史，之后称为中国现代史，划分二者的根本依据是（　　）

A．中国共产党的成立　B．抗日战争的胜利　C．中华人民共和国的成立使中国摆脱半殖民地半封建地位、赢得民族独立　D．社会主义制度的建立
:::

:::callout{kind=insight label="解析"}
**【答案】C**

1949年新中国成立，中国人民赢得民族独立、人民解放，摆脱了半殖民地半封建社会的历史地位，这是划分近代史与现代史的根本历史节点。
:::

:::callout{kind=note label="题目"}
三民主义的基本内容包括（　　）

:::callout{kind=insight label="解析"}

:::callout{kind=tip label="结论速记"}
旧三民主义 = 民族 + 民权 + 民生；新三民主义 = 联俄 + 联共 + 扶助农工。

A．通过起临时宪法作用的《共同纲领》　B．选举毛泽东为中央人民政府主席　C．确定国都、国旗、代国歌、纪年等　D．标志中国共产党领导的多党合作和政治协商制度正式确立
:::

:::callout{kind=insight label="解析"}
**【答案】ABCD**

1949年9月中国人民政协第一届全体会议通过起临时宪法作用的《共同纲领》，选举中央人民政府，确定国都国旗等，并标志新型政党制度的正式确立。

## 三、简答题（每题 8 分，共 32 分）

### 第1题

:::callout{kind=note label="题目"}
简述洋务运动的历史作用。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

洋务运动虽以失败告终，但作为地主阶级的自救运动，在客观上对中国近代社会的发展产生了积极作用。（1分）

第一，洋务派兴办近代企业，引进西方先进生产技术，客观上促进了中国民族资本主义的产生和发展。（2分）

第二，洋务运动开办新式学堂、派遣留学生、翻译西书，对中国近代教育事业的发展起了促进作用，传播了新知识。（2分）

第三，随着新式企业的兴办和商品经济的发展，社会风气和价值观念开始发生变化，工商业者的地位上升，冲击了传统的重本抑末、重义轻利观念。（2分）

第四，洋务企业在一定程度上抵制了外国经济势力的扩张。（1分）
:::

---

### 第2题

:::callout{kind=note label="题目"}
简述戊戌维新运动的意义及其失败的原因和教训。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**意义：** ①戊戌维新是一次爱国救亡运动，是对甲午战败民族危机的救亡回应；②是一次资产阶级性质的政治改良运动，提出以君主立宪制取代君主专制的主张；③是一次思想启蒙运动，传播了资产阶级新文化新思想，起了思想解放作用。（3分）

**失败原因：** 从主观上看，源于民族资产阶级的软弱性——①不敢否定封建主义，只寄希望于没有实权的皇帝，采取改良而非革命方式；②对帝国主义抱有幻想；③惧怕并脱离人民群众，仅局限于上层的少数人。客观上，封建守旧势力十分强大。（3分）

**教训：** 戊戌维新的失败表明，在半殖民地半封建的中国，企图通过统治者走自上而下的改良道路是根本行不通的，中国民族资产阶级不能领导中国革命取得胜利。（2分）
:::

### 第3题

:::callout{kind=note label="题目"}
简述中国共产党成立的历史意义。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

中国共产党的成立，是中华民族发展史上一个开天辟地的大事变，具有伟大而深远的意义。（2分）

第一，中国共产党的诞生，从根本上改变了近代以后中国人民反帝反封建斗争屡遭失败、没有先进坚强政党作为领导核心的局面，使中国革命有了坚强的领导力量。（2分）

第二，党一经成立就把实现共产主义作为最高理想和最终目标，义无反顾地肩负起实现中华民族伟大复兴的历史使命，中国人民由此踏上争取民族独立、人民解放的光明道路。（2分）

第三，中国共产党的成立，深刻改变了近代以后中华民族发展的方向和进程，深刻改变了中国人民和中华民族的前途和命运，深刻改变了世界发展的趋势和格局。（"三个深刻改变"）（2分）
:::

:::callout{kind=note label="知识卡片：中共成立意义"}
| 要素 | 内容 |
|------|------|
| **定性** | 开天辟地的大事变 |
| **三个深刻改变** | ①中华民族发展方向和进程 ②中国人民和中华民族前途命运 ③世界发展趋势和格局 |
| **核心意义** | 有了坚强领导力量 + 有了科学理论指导 + 革命面貌焕然一新 |
:::

### 第4题

:::callout{kind=note label="题目"}
为什么说中国革命必须走农村包围城市、武装夺取政权的道路？（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

这条道路是由中国半殖民地半封建社会的特殊国情决定的。（1分）

第一，必须以武装斗争为主要形式：近代中国内部没有民主制度而受封建压迫，外部没有民族独立而受帝国主义压迫，人民只能以武装的革命反对武装的反革命。（2分）

第二，必须以农民为主力军、以农村为主要阵地：中国农民占人口绝大多数，是无产阶级最可靠的同盟军；反动势力长期占据中心城市而在农村统治薄弱。（2分）

第三，中国政治经济发展的极端不平衡，以及大革命的影响、全国革命形势的继续向前发展、相当力量正式红军的存在、党的领导及其正确政策，为红色政权的存在和发展提供了可能。（2分）

结论：以毛泽东为主要代表的中国共产党人从实际出发，创造性地开辟了农村包围城市、武装夺取政权的具有中国特色的革命新道路，实现了中国革命的历史性转变。（1分）
:::

:::callout{kind=tip label="结论速记"}
农村包围城市三依据 = 无民主需武装 + 农民主力农村阵地 + 政治经济不平衡留缝隙。
:::

## 四、材料分析题（每题 14 分，共 28 分）

### 第1题

:::callout{kind=note label="题目"}
**材料分析题一**

材料一：习近平指出，历史就是历史，历史不能任意选择。一个民族的历史是一个民族安身立命的基础。不论发生过什么波折和曲折，不论出现过什么苦难和困难，中华民族5000多年的文明史，中国人民近代以来170多年的斗争史，中国共产党90多年的奋斗史，中华人民共和国60多年的发展史，都是人民书写的历史。

材料二：有人认为，鸦片战争后中国被卷入资本主义世界体系是"历史的进步"，西方殖民扩张给中国带来了"现代文明"，中国的反抗和革命"打断了现代化进程"，应当"告别革命"。

（1）依据材料一，简述中国近现代史的主题主线和主流本质。（6分）

（2）材料二反映了怎样的错误思潮？应如何认识和批判？（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**（1）主题主线：** 中国近现代史贯穿着一条主线，就是中国人民为实现中华民族伟大复兴而不懈奋斗；实现中华民族伟大复兴是近代以来中华民族最伟大的梦想。（3分）

**主流本质：** 1840年以来的中国历史，其主流和本质是中国人民为救亡图存和实现中华民族伟大复兴而英勇奋斗、艰辛探索并不断取得伟大成就的历史，尤其是在中国共产党领导下经过新民主主义革命赢得民族独立人民解放、经过社会主义革命建设改革走向繁荣富强的历史。（3分）

**（2）错误思潮：** 材料二反映的是历史虚无主义。它以"重新评价"为名，歪曲中国近现代革命史、党史、国史，否定人民革命的进步意义，美化侵略。（2分）

**批判：** ①从立场看，它没有站在中国人民、中华民族的立场上，而是以西方殖民主义者的立场看待中国，是错误的"冲击—回应"式偏见的延伸。（2分）②从事实看，近代中国并非停滞不前，帝国主义侵略给中华民族带来的是深重灾难而非"进步"，中国人民的反侵略斗争和革命推动了社会进步。（2分）③从方法看，必须坚持辩证唯物主义和历史唯物主义，坚持正确党史观、大历史观，把握历史主流本质，才能辨明历史发展的必然性，抵御历史虚无主义。（2分）
:::

:::callout{kind=note label="知识卡片：历史虚无主义批判"}
| 要素 | 内容 |
|------|------|
| **错误观点** | "冲击—回应"模式、"侵略有功论"、"告别革命" |
| **正确立场** | 人民立场、中华民族立场 |
| **正确方法** | 辩证唯物主义 + 历史唯物主义 + 正确党史观 + 大历史观 |
| **核心要义** | 把握主题主线、主流本质，反对美化侵略、否定革命 |
:::

### 第2题

:::callout{kind=note label="题目"}
**材料分析题二**

材料一：辛亥革命是20世纪中国第一次历史性巨变。它推翻了统治中国几千年的君主专制制度，建立了亚洲第一个资产阶级共和国。但是，革命果实很快被袁世凯窃取，中国半殖民地半封建社会的性质没有改变，反帝反封建的任务没有完成。

材料二：孙中山在临终遗嘱中写道："革命尚未成功，同志仍须努力。"毛泽东指出："辛亥革命没有成功，失败了。但是，辛亥革命打开了中国进步的闸门。"

（1）结合材料一，说明辛亥革命的伟大历史意义。（6分）

（2）结合材料二，分析辛亥革命失败的原因及其教训。（8分）
:::

:::callout{kind=insight label="解析"}
**【答案要点】**

**（1）** ①推翻了清王朝的反动统治，沉重打击了中外反动势力；②结束了两千多年的封建君主专制制度，建立了第一个资产阶级共和政府，使民主共和观念开始深入人心；③推动了中国人民的思想解放；④推动了中国的社会变革；⑤在一定程度上打击了帝国主义侵略势力，推动了亚洲各国民族解放运动的高涨。（每点1分，共5分；概括其为救亡图存、振兴中华的里程碑1分）

**（2）失败原因（主观，根源于民族资产阶级的软弱性妥协性）：** ①没有提出彻底的反帝反封建的革命纲领，只强调反满和建立共和政体；②不能充分发动和依靠广大人民群众尤其是农民（"没有一个大的农村变动"）；③不能建立坚强的革命政党作为团结核心，同盟会组织松散、缺乏统一领导。客观上，中外反动势力联合强大。（5分）

**教训：** 辛亥革命的失败表明，资产阶级共和国的方案在半殖民地半封建的中国行不通，资产阶级不能领导中国民主革命取得彻底胜利，中国先进分子必须进行新的探索、为中国谋求新的出路——历史最终选择了马克思主义和中国共产党。（3分）
:::

:::callout{kind=note label="知识卡片：辛亥革命"}
| 要素 | 内容 |
|------|------|
| **历史意义五点** | 推清廷 + 结帝制 + 解思想 + 变社会 + 促亚洲 |
| **失败原因三点** | ①无彻底纲领 ②不能发动群众 ③不能建坚强政党 |
| **根源** | 民族资产阶级软弱性妥协性 |
| **教训** | 资产阶级共和国方案行不通 → 选择马克思主义和中国共产党 |
:::

:::callout{kind=tip label="结论速记"}
辛亥革命 = 打开了进步的闸门，但革命尚未成功；教训 = 资产阶级共和国行不通。
:::
