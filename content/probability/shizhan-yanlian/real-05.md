## 一、单项选择题（每题 3 分，共 30 分）

### 第1题

:::callout{kind=note label="题目"}
设 $A$ 与 $B$ 为两随机事件，$P(A) = 1$，则（　　）

A. $A$ 为必然事件　　B. $AB = B$　　C. $P(A - B) = P(\bar{B})$　　D. $P(B - A) = P(B)$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：题干给出 $P(A)=1$，要判断四个关于 $A$、$B$ 的集合与概率关系。入口是识别"概率为 1 的事件"与"必然事件"的差别，再用差事件公式 $P(A-B)=P(A\cap\bar{B})$ 逐项验证。

**为何用此公式**：差事件公式 $P(A-B)=P(A)-P(AB)=P(A\cap\bar{B})$ 把 $A-B$ 转化为 $A$ 与 $\bar{B}$ 的交，配合 $P(\bar{A})=0$ 可压缩为零项，是处理"概率为 1 事件"差运算的标准工具。

**推导过程**：

1. 第一步：由 $P(A)=1$ 得 $P(\bar{A})=1-P(A)=0$ ← 依据：补事件概率公式
2. 第二步：化 $P(A-B)=P(A\cap\bar{B})$ ← 依据：差事件等价表示 $A-B=A\cap\bar{B}$
3. 第三步：分解 $P(A\cap\bar{B})=P(\bar{B})-P(\bar{A}\cap\bar{B})$ ← 依据：容斥原理 $P(\bar{B})=P(A\cap\bar{B})+P(\bar{A}\cap\bar{B})$
4. 第四步：由 $\bar{A}\cap\bar{B}\subset\bar{A}$ 得 $P(\bar{A}\cap\bar{B})\le P(\bar{A})=0$，故 $P(\bar{A}\cap\bar{B})=0$ ← 依据：概率单调性与非负性
5. 第五步：代入得 $P(A-B)=P(\bar{B})-0=P(\bar{B})$ ← 依据：等量代换

**选项分析**：

- **A（错误）**：$P(A)=1$ 仅表示 $A$ 概率为 1，不蕴含 $A=\Omega$。反例：几何概型中直线的概率为 1，但直线不等于全平面。
- **B（错误）**：$AB=B$ 是集合等式，要求 $B\subset A$。$P(A)=1$ 只能推出 $P(AB)=P(B)$（概率意义下相等），不能推出集合意义下 $AB=B$。
- **C（正确）**：由上述推导 $P(A-B)=P(A\cap\bar{B})=P(\bar{B})$ 成立。
- **D（错误）**：$P(B-A)=P(B\cap\bar{A})\le P(\bar{A})=0$，而 $P(B)$ 一般不为 0，故 $P(B-A)=P(B)$ 不成立。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **混淆"概率为 1"与"必然事件"**：误把 $P(A)=1$ 当作 $A=\Omega$ 处理 → 正确做法：$P(A)=1$ 仅是概率意义，$A$ 可严格小于 $\Omega$（差一个零测集），凡涉及集合等式的选项一律排除。
2. **混淆"概率相等"与"集合相等"**：由 $P(A)=1$ 推出 $P(AB)=P(B)$ 后误得 $AB=B$ → 正确做法：概率相等 $P(AB)=P(B)$ 只表明 $B\setminus AB$ 是零测集，不表明 $B\setminus AB=\varnothing$，集合等式需要 $B\subset A$。
3. **差事件方向搞反**：把 $P(A-B)$ 误算为 $P(B-A)$ → 正确做法：$A-B=A\cap\bar{B}$（属于 $A$ 不属于 $B$），$B-A=B\cap\bar{A}$（属于 $B$ 不属于 $A$），二者方向相反不可互换。
:::

:::callout{kind=note label="知识卡片：概率为1的事件与必然事件"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 必然事件 | $A=\Omega$，作为集合等于样本空间 | 任意样本空间 |
| 概率为 1 的事件 | $P(A)=1$，但 $A$ 未必等于 $\Omega$ | 概率空间，允许零测子集 |
| 二者关系 | $A=\Omega\Rightarrow P(A)=1$，反之不成立 | 一般概率空间 |
| 差事件公式 | $P(A-B)=P(A\cap\bar{B})=P(A)-P(AB)$ | 任意事件 |
| 几乎必然 | $P(A)=1$ 称 $A$ 几乎必然发生（a.s.） | 测度论框架 |

**概念辨析**：
- "概率为 1"是测度论概念，"必然事件"是集合论概念，二者仅在离散有限样本空间等价；在连续型或一般样本空间中，$P(A)=1$ 允许 $A$ 缺失零测子集。
- 公式 $P(A-B)=P(A)-P(AB)$ 对任意事件成立，但当 $P(A)=1$ 时化为 $P(A-B)=1-P(AB)=P(\bar{B})+P(AB)-P(AB)$ 的化简需借助 $P(\bar{A}\cap\bar{B})=0$。
:::

:::callout{kind=tip label="结论速记"}
$P(A)=1\Rightarrow P(\bar{A})=0\Rightarrow P(A-B)=P(A\cap\bar{B})=P(\bar{B})$。

**口诀**：概率为1非必然，差集等于补集算，集合等式慎断言。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$P(A)=1$"或"几乎必然"→ 联想"$P(\bar{A})=0$，零测子集可忽略，差事件 $P(A-B)=P(\bar{B})$"
- **关联考点**：事件与概率（第一章）、几何概型中零测集的处理、几乎必然收敛（大数定律）
- **复用场景**：任何涉及"概率为 1 事件"的集合与概率关系判断题，以及 a.s. 收敛的等价转化
:::

### 第2题

:::callout{kind=note label="题目"}
将一枚硬币独立重复掷 $2$ 次，$A = \{\text{第一次出现正面}\}$，$B = \{\text{第二次出现反面}\}$，$C = \{\text{最多出现一次正面}\}$，则（　　）成立。

A. $A, B, C$ 两两独立　　B. $A$ 与 $BC$ 独立　　C. $B$ 与 $AC$ 独立　　D. $C$ 与 $AB$ 独立
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：题干给出两次独立掷币的三个事件，要求判断事件运算后的独立性。入口是枚举样本空间 $\Omega=\{HH,HT,TH,TT\}$，写出 $A,B,C$ 的样本点，再对每个选项用独立性定义 $P(U\cap V)=P(U)P(V)$ 逐对验证。

**为何用此公式**：独立性定义 $P(U\cap V)=P(U)P(V)$ 是判别两事件独立的最直接工具，无需借助协方差或分布函数；对"事件运算后"的独立性（如 $A$ 与 $BC$），先化简 $BC$ 的样本点再代入定义即可。

**推导过程**：

1. 第一步：列出样本空间 $\Omega=\{HH,HT,TH,TT\}$，各样本点概率 $\dfrac{1}{4}$ ← 依据：两次独立掷币的等概性
2. 第二步：写出各事件样本点 ← 依据：事件定义
   - $A=\{HH,HT\}$，$P(A)=\dfrac{1}{2}$
   - $B=\{TH,TT\}$，$P(B)=\dfrac{1}{2}$
   - $C=\{HT,TH,TT\}$，$P(C)=\dfrac{3}{4}$
3. 第三步：对选项 B 化简 $BC=\{TH,TT\}\cap\{HT,TH,TT\}=\{TH,TT\}$，$P(BC)=\dfrac{1}{2}$ ← 依据：交事件样本点取交集
4. 第四步：计算 $P(A\cap BC)=P(\{HT\})=\dfrac{1}{4}$ ← 依据：$A\cap BC=\{HH,HT\}\cap\{TH,TT\}=\{HT\}$
5. 第五步：验证 $P(A)P(BC)=\dfrac{1}{2}\times\dfrac{1}{2}=\dfrac{1}{4}=P(A\cap BC)$ ← 依据：独立性定义

故 $A$ 与 $BC$ 独立，B 正确。

**选项分析**：

- **A（错误）**：$P(A\cap C)=P(\{HT\})=\dfrac{1}{4}\ne\dfrac{3}{8}=\dfrac{1}{2}\times\dfrac{3}{4}=P(A)P(C)$，$A$ 与 $C$ 不独立，故三事件不两两独立。
- **B（正确）**：$P(A\cap BC)=\dfrac{1}{4}=P(A)P(BC)$，独立性成立。
- **C（错误）**：$AC=\{HT\}$，$P(AC)=\dfrac{1}{4}$，$P(B\cap AC)=P(\{HT\})=\dfrac{1}{4}\ne\dfrac{1}{8}=\dfrac{1}{2}\times\dfrac{1}{4}=P(B)P(AC)$，不独立。
- **D（错误）**：$AB=\{HT\}$，$P(AB)=\dfrac{1}{4}$，$P(C\cap AB)=P(\{HT\})=\dfrac{1}{4}\ne\dfrac{3}{16}=\dfrac{3}{4}\times\dfrac{1}{4}=P(C)P(AB)$，不独立。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **混淆"两两独立"与"相互独立"**：误以为验证一两对独立即可宣布相互独立 → 正确做法：两两独立需对 $\binom{3}{2}=3$ 对逐一验证，相互独立还需验证三事件积；本题 $A$ 与 $C$ 已不独立，两两独立即不成立。
2. **事件运算后独立性想当然**：误以为 $A,B$ 独立则 $A$ 与 $BC$ 必独立 → 正确做法：$A$ 与 $BC$ 的独立性必须重新用 $P(A\cap BC)=P(A)P(BC)$ 验证，不能由 $A,B$ 独立直接推出。
3. **样本点交集算错**：把 $A\cap BC$ 误算为 $\{HH,HT\}\cap\{TH,TT\}$ 之外的多余样本点 → 正确做法：严格按样本点逐一取交集，$A\cap BC$ 仅含同时属于 $A$ 和 $BC$ 的样本点 $\{HT\}$。
:::

:::callout{kind=note label="知识卡片：事件独立性"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 两两独立 | 任两个事件满足 $P(A_i\cap A_j)=P(A_i)P(A_j)$ | $n$ 个事件中任取一对 |
| 相互独立 | 任一子集的事件积概率等于各事件概率之积 | 所有子集均成立 |
| 关系 | 相互独立 $\Rightarrow$ 两两独立，反之不成立 | 一般情形 |
| 事件运算后独立 | $A$ 与 $BC$ 独立需验证 $P(A\cap BC)=P(A)P(BC)$ | 不可由 $A,B$ 独立直接推出 |
| 伯努利试验 | 各次试验结果事件相互独立 | 独立重复试验 |

**概念辨析**：
- "两两独立"只要求成对独立，"相互独立"要求任意子集独立，二者在 $n\ge 3$ 时不等价；经典反例为两两独立但不相互独立的伯努利试验构造。
- 事件经过交、并、补运算后，独立性需重新验证：$A,B$ 独立不蕴含 $A$ 与 $BC$ 独立，也不蕴含 $A$ 与 $B\cup C$ 独立。
:::

:::callout{kind=tip label="结论速记"}
独立性验证核心：$P(A\cap BC)\stackrel{?}{=}P(A)\cdot P(BC)$，逐对代入样本点概率检验。

**口诀**：样本点先列全，交集概率乘积验，运算之后独立重新判。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"事件运算后的独立性"（如 $A$ 与 $BC$、$B$ 与 $AC$）→ 联想"先化简运算后事件的样本点，再用 $P(U\cap V)=P(U)P(V)$ 验证"
- **关联考点**：事件独立性（第一章）、伯努利试验、相互独立与两两独立的区别
- **复用场景**：任何"已知若干事件独立，判断运算后事件是否独立"的选择题或证明题
:::

### 第3题

:::callout{kind=note label="题目"}
设 $X \sim U(0, 1)$，则（　　）

A. $E\!\left(X - \dfrac{1}{3}\right)^2 < \dfrac{1}{12}$　　B. $E\!\left(X - \dfrac{1}{4}\right)^2 = \dfrac{1}{13}$　　C. $E\!\left(X - \dfrac{1}{5}\right)^2 > \dfrac{1}{12}$　　D. $E\!\left(X - \dfrac{1}{7}\right)^2 = \dfrac{1}{12}$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：题干给出 $X\sim U(0,1)$ 与四个二阶中心矩 $E(X-a)^2$ 的比较。入口是识别"二阶矩关于任意点的分解"，套用方差-期望分解公式 $E(X-a)^2=D(X)+(E(X)-a)^2$，逐个代入 $a$ 计算并与 $\dfrac{1}{12}$ 比较。

**为何用此公式**：方差-期望分解 $E(X-a)^2=D(X)+(E(X)-a)^2$ 把"任意点二阶矩"拆为"方差"加"均值偏差平方"，避免对每个 $a$ 重算积分 $\int_0^1(x-a)^2 dx$，是处理 $E(X-a)^2$ 的最简工具。

**推导过程**：

1. 第一步：算 $U(0,1)$ 的均值方差 ← 依据：均匀分布数字特征
   $$E(X)=\frac{0+1}{2}=\frac{1}{2},\quad D(X)=\frac{(1-0)^2}{12}=\frac{1}{12}$$
2. 第二步：套分解公式 ← 依据：方差-期望分解 $E(X-a)^2=D(X)+(E(X)-a)^2$
   $$E(X-a)^2=\frac{1}{12}+\left(\frac{1}{2}-a\right)^2$$
3. 第三步：逐项代入比较 ← 依据：算术运算
   - $a=\dfrac{1}{3}$：$E=\dfrac{1}{12}+\left(\dfrac{1}{6}\right)^2=\dfrac{1}{12}+\dfrac{1}{36}=\dfrac{4}{36}=\dfrac{1}{9}>\dfrac{1}{12}$
   - $a=\dfrac{1}{4}$：$E=\dfrac{1}{12}+\left(\dfrac{1}{4}\right)^2=\dfrac{1}{12}+\dfrac{1}{16}=\dfrac{7}{48}\ne\dfrac{1}{13}$
   - $a=\dfrac{1}{5}$：$E=\dfrac{1}{12}+\left(\dfrac{3}{10}\right)^2=\dfrac{1}{12}+\dfrac{9}{100}=\dfrac{25+27}{300}=\dfrac{52}{300}=\dfrac{13}{75}>\dfrac{1}{12}$
   - $a=\dfrac{1}{7}$：$E=\dfrac{1}{12}+\left(\dfrac{5}{14}\right)^2=\dfrac{1}{12}+\dfrac{25}{196}=\dfrac{196+300}{2352}=\dfrac{496}{2352}\ne\dfrac{1}{12}$
4. 第四步：仅 C 的不等式 $E\!\left(X-\dfrac{1}{5}\right)^2>\dfrac{1}{12}$ 成立 ← 依据：上述计算

**选项分析**：

- **A（错误）**：$a=\dfrac{1}{3}$ 时 $E=\dfrac{1}{9}>\dfrac{1}{12}$，方向应为大于而非小于。
- **B（错误）**：$a=\dfrac{1}{4}$ 时 $E=\dfrac{7}{48}\approx 0.1458$，而 $\dfrac{1}{13}\approx 0.0769$，二者数值不等。
- **C（正确）**：$a=\dfrac{1}{5}$ 时 $E=\dfrac{13}{75}>\dfrac{1}{12}$。
- **D（错误）**：$a=\dfrac{1}{7}\ne\dfrac{1}{2}=E(X)$，等号仅当 $a=E(X)$ 成立，此处 $E\ne\dfrac{1}{12}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **直接硬算积分**：对每个 $a$ 重新计算 $\int_0^1(x-a)^2 dx$ → 正确做法：套用 $E(X-a)^2=D(X)+(E(X)-a)^2$，只需一次分解即可批量比较。
2. **误以为任意 $a$ 都使 $E(X-a)^2=D(X)$**：忘记偏差项 $(E(X)-a)^2$ → 正确做法：等号仅当 $a=E(X)$ 成立，本题 $E(X)=\dfrac{1}{2}$，四个 $a$ 均不等于 $\dfrac{1}{2}$，故均严格大于 $\dfrac{1}{12}$。
3. **分数比较出错**：把 $\dfrac{7}{48}$ 与 $\dfrac{1}{13}$ 比较时算错 → 正确做法：通分比较 $\dfrac{7}{48}\approx 0.1458$ 与 $\dfrac{1}{13}\approx 0.0769$，显然不等。
:::

:::callout{kind=note label="知识卡片：均匀分布的矩与方差分解"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $U(a,b)$ 期望 | $E(X)=\dfrac{a+b}{2}$ | 区间 $[a,b]$ 上均匀分布 |
| $U(a,b)$ 方差 | $D(X)=\dfrac{(b-a)^2}{12}$ | 同上 |
| $U(0,1)$ 特例 | $E(X)=\dfrac{1}{2}$，$D(X)=\dfrac{1}{12}$ | 标准均匀分布 |
| 二阶矩分解 | $E(X-a)^2=D(X)+(E(X)-a)^2$ | 任意有二阶矩的随机变量 |
| 最小值点 | $a=E(X)$ 时 $E(X-a)^2$ 取最小值 $D(X)$ | 二阶矩最小化原理 |

**概念辨析**：
- 公式 $E(X-a)^2=D(X)+(E(X)-a)^2$ 表明均值 $E(X)$ 是最小化二阶矩 $E(X-a)^2$ 的唯一 $a$，这正是"均值是最小二乘最优预测"的体现。
- 该分解对任意有二阶矩的分布成立，不限于均匀分布；均匀分布只是给出了 $E,D$ 的具体值。
:::

:::callout{kind=tip label="结论速记"}
$E(X-a)^2=D(X)+(E(X)-a)^2\ge D(X)$，等号仅当 $a=E(X)$ 成立。

**口诀**：二阶矩分解方加偏，均值点处方差最小现。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$E(X-a)^2$"或"任意点的二阶矩"→ 联想"$E(X-a)^2=D(X)+(E(X)-a)^2$，均值点最小"
- **关联考点**：数字特征（第四章）、最小二乘估计、均方误差最小化
- **复用场景**：任何比较 $E(X-a)^2$ 大小或求最优预测点的题目，包括回归中常数预测的均方误差
:::

### 第4题

:::callout{kind=note label="题目"}
设 $X \sim E(\lambda)$，$Y \sim P(\lambda)$，$\operatorname{Cov}(X, Y) = 0$，则下列结论错误的是（　　）

A. $E(XY^2) = \lambda + 1$　　B. $E(XY) = 1$　　C. $D(\lambda X + Y) = \lambda + 1$　　D. $\operatorname{Cov}(X, X + \lambda Y) = \dfrac{1}{\lambda^2}$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：题干给出 $X\sim E(\lambda)$、$Y\sim P(\lambda)$ 且 $\operatorname{Cov}(X,Y)=0$，要求找出"错误"结论。入口是先用各分布的数字特征算出 $E,D$，再用协方差为零推出 $E(XY)=E(X)E(Y)$，逐项验证 B、C、D；A 涉及 $E(XY^2)$，零协方差不能推广到 $Y^2$，需判定其不成立。

**为何用此公式**：协方差定义 $\operatorname{Cov}(X,Y)=E(XY)-E(X)E(Y)$ 是连接"不相关"与"$E(XY)=E(X)E(Y)$"的桥梁；方差线性性 $D(aX+bY)=a^2D(X)+b^2D(Y)+2ab\operatorname{Cov}(X,Y)$ 适用于 $\lambda X+Y$ 这类线性组合。

**推导过程**：

1. 第一步：算各分布数字特征 ← 依据：指数分布与泊松分布的矩
   - $X\sim E(\lambda)\Rightarrow E(X)=\dfrac{1}{\lambda}$，$D(X)=\dfrac{1}{\lambda^2}$
   - $Y\sim P(\lambda)\Rightarrow E(Y)=\lambda$，$D(Y)=\lambda$，$E(Y^2)=D(Y)+[E(Y)]^2=\lambda+\lambda^2$
2. 第二步：由 $\operatorname{Cov}(X,Y)=0$ 得 $E(XY)=E(X)E(Y)=\dfrac{1}{\lambda}\cdot\lambda=1$ ← 依据：协方差定义
3. 第三步：验证 B ← 依据：第二步结果，$E(XY)=1$，B 正确
4. 第四步：验证 C ← 依据：方差线性性
   $$D(\lambda X+Y)=\lambda^2 D(X)+D(Y)+2\lambda\operatorname{Cov}(X,Y)=\lambda^2\cdot\frac{1}{\lambda^2}+\lambda+0=1+\lambda$$
   C 正确。
5. 第五步：验证 D ← 依据：协方差双线性
   $$\operatorname{Cov}(X,X+\lambda Y)=\operatorname{Cov}(X,X)+\lambda\operatorname{Cov}(X,Y)=D(X)+0=\frac{1}{\lambda^2}$$
   D 正确。
6. 第六步：判定 A ← 依据：零协方差仅给出 $E(XY)=E(X)E(Y)$，不能推广到 $E(XY^2)=E(X)E(Y^2)$
   - 若 A 成立需 $E(XY^2)=E(X)E(Y^2)=\dfrac{1}{\lambda}\cdot(\lambda+\lambda^2)=1+\lambda$，但题干 A 写的是 $\lambda+1$，表面数值相同；然而 $E(XY^2)=E(X)E(Y^2)$ 仅在 $X$ 与 $Y^2$ 不相关时成立，零协方差 $\operatorname{Cov}(X,Y)=0$ 不蕴含 $X$ 与 $Y^2$ 不相关，故该等式无依据，A 错误。

**选项分析**：

- **A（错误，即题目所求）**：$\operatorname{Cov}(X,Y)=0$ 仅给出 $E(XY)=E(X)E(Y)$，不能推广到 $E(XY^2)=E(X)E(Y^2)$；$X$ 与 $Y$ 不相关不蕴含 $X$ 与 $Y^2$ 不相关，故 $E(XY^2)=\lambda+1$ 无成立依据。
- **B（正确）**：$E(XY)=E(X)E(Y)=\dfrac{1}{\lambda}\cdot\lambda=1$。
- **C（正确）**：$D(\lambda X+Y)=\lambda^2\cdot\dfrac{1}{\lambda^2}+\lambda+0=\lambda+1$。
- **D（正确）**：$\operatorname{Cov}(X,X+\lambda Y)=D(X)+\lambda\cdot 0=\dfrac{1}{\lambda^2}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **零协方差过度推广**：由 $\operatorname{Cov}(X,Y)=0$ 误推出 $E(XY^2)=E(X)E(Y^2)$ → 正确做法：$\operatorname{Cov}(X,Y)=0$ 仅给出 $E(XY)=E(X)E(Y)$（一阶积），对 $Y^2$ 等非线性函数无效；$X$ 与 $Y$ 不相关不蕴含 $X$ 与 $Y^2$ 不相关。
2. **不相关与独立混淆**：误以为 $\operatorname{Cov}(X,Y)=0$ 就是 $X,Y$ 独立 → 正确做法：不相关仅协方差为零，独立要求所有函数 $g(X),h(Y)$ 都不相关；零协方差是独立的必要非充分条件。
3. **泊松分布 $E(Y^2)$ 算错**：误把 $E(Y^2)=\lambda$ → 正确做法：$E(Y^2)=D(Y)+[E(Y)]^2=\lambda+\lambda^2$，需用方差-期望分解。
:::

:::callout{kind=note label="知识卡片：协方差与不相关"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 协方差定义 | $\operatorname{Cov}(X,Y)=E(XY)-E(X)E(Y)$ | 二阶矩存在 |
| 不相关 | $\operatorname{Cov}(X,Y)=0$，即 $E(XY)=E(X)E(Y)$ | 仅一阶积分解 |
| 独立 $\Rightarrow$ 不相关 | 独立必不相关 | 任意有二阶矩的随机变量 |
| 不相关 $\not\Rightarrow$ 独立 | 零协方差不能推出 $X$ 与 $Y^2$ 不相关 | 一般情形 |
| 方差线性性 | $D(aX+bY)=a^2D(X)+b^2D(Y)+2ab\operatorname{Cov}(X,Y)$ | 二阶矩存在 |
| 指数分布 $E(\lambda)$ | $E=\dfrac{1}{\lambda}$，$D=\dfrac{1}{\lambda^2}$ | $\lambda>0$ |
| 泊松分布 $P(\lambda)$ | $E=D=\lambda$，$E(Y^2)=\lambda+\lambda^2$ | $\lambda>0$ |

**概念辨析**：
- "不相关"是线性意义下的独立（仅 $E(XY)=E(X)E(Y)$），"独立"是函数意义下的独立（$E[g(X)h(Y)]=E[g(X)]E[h(Y)]$ 对所有 $g,h$）；零协方差不能推广到 $Y^2$、$\cos Y$ 等非线性函数。
- 验证"不相关 $\Rightarrow$ 独立"需附加条件，如二维正态分布下二者等价；一般分布下需构造反例。
:::

:::callout{kind=tip label="结论速记"}
$\operatorname{Cov}(X,Y)=0$ 仅给出 $E(XY)=E(X)E(Y)$，不能推广到 $E(XY^2)=E(X)E(Y^2)$。

**口诀**：零协方差一阶积，非线性函数莫外推。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$\operatorname{Cov}(X,Y)=0$"或"不相关"→ 联想"仅 $E(XY)=E(X)E(Y)$，不能推广到 $Y^2$、$Y^k$ 等非线性函数"
- **关联考点**：协方差与相关性（第四章）、独立性的定义、二维正态下独立与不相关的等价性
- **复用场景**：任何"已知不相关，判断 $E(Xg(Y))$ 是否等于 $E(X)E(g(Y))$"的题目，以及"找错误结论"类选择题
:::

### 第5题

:::callout{kind=note label="题目"}
已知随机变量 $X$ 的分布函数为 $F_X(x) = \Phi(2x + 1)$，其中 $\Phi(x)$ 为标准正态分布函数，则 $X \sim$（　　）

A. $N(-1, 1)$　　B. $N\!\left(-\dfrac{1}{2}, 2\right)$　　C. $N\!\left(\dfrac{1}{2}, 2\right)$　　D. $N\!\left(-\dfrac{1}{2}, \dfrac{1}{4}\right)$
:::

:::callout{kind=insight label="解析"}
**【答案】D**

**思路**：题干给出 $F_X(x)=\Phi(2x+1)$，要求反推 $X$ 的分布。入口是识别"分布函数形如 $\Phi(ax+b)$"对应"线性变换的正态分布"，先用 $\Phi$ 的定义把 $2x+1$ 解释为标准正态变量 $Z$ 的取值，得 $2X+1\sim N(0,1)$，再用正态线性变换反解 $X$ 的参数。

**为何用此公式**：正态分布线性变换公式"若 $aX+b\sim N(\mu,\sigma^2)$，则 $X\sim N\!\left(\dfrac{\mu-b}{a},\dfrac{\sigma^2}{a^2}\right)$"直接把 $aX+b$ 的分布反推为 $X$ 的分布，是处理"分布函数含 $\Phi(ax+b)$"的标准反解工具。

**推导过程**：

1. 第一步：由 $F_X(x)=\Phi(2x+1)=P(Z\le 2x+1)$（$Z\sim N(0,1)$） ← 依据：标准正态分布函数定义
2. 第二步：把 $P(Z\le 2x+1)$ 改写为 $P\!\left(\dfrac{Z-1}{2}\le x\right)$ ← 依据：不等式变形 $Z\le 2x+1\Leftrightarrow\dfrac{Z-1}{2}\le x$
3. 第三步：识别 $F_X(x)=P\!\left(\dfrac{Z-1}{2}\le x\right)$，故 $X\overset{d}{=}\dfrac{Z-1}{2}$ ← 依据：分布函数唯一确定随机变量分布
4. 第四步：由 $Z\sim N(0,1)$ 得 $X=\dfrac{Z-1}{2}=\dfrac{1}{2}Z-\dfrac{1}{2}\sim N\!\left(-\dfrac{1}{2},\dfrac{1}{4}\right)$ ← 依据：正态线性变换 $aZ+b\sim N(b,a^2)$

或等价地：$2X+1\sim N(0,1)$，代入反解公式 $a=2,b=1,\mu=0,\sigma^2=1$：
$$X\sim N\!\left(\frac{0-1}{2},\frac{1}{2^2}\right)=N\!\left(-\frac{1}{2},\frac{1}{4}\right)$$

**选项分析**：

- **A（错误）**：均值应为 $-\dfrac{1}{2}$ 而非 $-1$；$-1$ 是把 $b=1$ 直接当作均值符号出错。
- **B（错误）**：方差应为 $\dfrac{1}{4}$ 而非 $2$；$2$ 是把 $a=2$ 直接当作方差出错。
- **C（错误）**：均值符号错误，应为 $-\dfrac{1}{2}$ 而非 $\dfrac{1}{2}$；此选项漏掉 $b=1$ 中的负号。
- **D（正确）**：均值 $-\dfrac{1}{2}$，方差 $\dfrac{1}{4}$，与上述推导一致。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **正态记号第二参数混淆**：把 $N(\mu,\sigma^2)$ 的第二参数当作标准差 → 正确做法：第二参数是方差 $\sigma^2$，本题方差 $\dfrac{1}{4}$ 对应标准差 $\dfrac{1}{2}$。
2. **反解公式符号出错**：把 $X\sim N\!\left(\dfrac{\mu-b}{a},\dfrac{\sigma^2}{a^2}\right)$ 误写为 $\dfrac{b-\mu}{a}$ → 正确做法：由 $aX+b\sim N(\mu,\sigma^2)$ 得 $X=\dfrac{(aX+b)-b}{a}$，均值 $\dfrac{\mu-b}{a}$，注意 $b$ 前为负号。
3. **$a$ 与 $\sigma$ 关系搞反**：把方差误算为 $a^2\sigma^2$ 而非 $\dfrac{\sigma^2}{a^2}$ → 正确做法：$X=\dfrac{1}{a}(aX+b)-\dfrac{b}{a}$，方差乘以 $\dfrac{1}{a^2}$，故为 $\dfrac{\sigma^2}{a^2}$。
:::

:::callout{kind=note label="知识卡片：正态分布的标准化与线性变换"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 标准化 | $X\sim N(\mu,\sigma^2)\Rightarrow Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)$ | 任意正态分布 |
| 反变换 | 若 $\dfrac{X-\mu}{\sigma}\sim N(0,1)$，则 $X\sim N(\mu,\sigma^2)$ | 标准正态的线性变换 |
| $aX+b$ 分布 | $aX+b\sim N(a\mu+b,a^2\sigma^2)$ | $X\sim N(\mu,\sigma^2)$ |
| 反解 $X$ | $aX+b\sim N(\mu,\sigma^2)\Rightarrow X\sim N\!\left(\dfrac{\mu-b}{a},\dfrac{\sigma^2}{a^2}\right)$ | $a\ne 0$ |
| 分布函数关系 | $F_X(x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)$ | $X\sim N(\mu,\sigma^2)$ |

**概念辨析**：
- 公式 $F_X(x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)$ 表明分布函数中 $\Phi$ 的自变量即为标准化量 $\dfrac{x-\mu}{\sigma}$；本题 $\dfrac{x-\mu}{\sigma}=2x+1$，解得 $\sigma=\dfrac{1}{2}$，$\mu=-\dfrac{1}{2}$。
- 正态分布的第二参数是方差而非标准差，是常见混淆点；记号 $N(\mu,\sigma^2)$ 中 $\sigma^2$ 已是平方。
:::

:::callout{kind=tip label="结论速记"}
$F_X(x)=\Phi(ax+b)\Rightarrow X\sim N\!\left(-\dfrac{b}{a},\dfrac{1}{a^2}\right)$。

**口诀**：分布函数套标准正态，反解均值负 $b$ 比 $a$，方差倒 $a$ 平方算。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$F_X(x)=\Phi(ax+b)$"或"分布函数含标准正态"→ 联想"$X\sim N\!\left(-\dfrac{b}{a},\dfrac{1}{a^2}\right)$，反解线性变换"
- **关联考点**：正态分布（第二章）、标准化与分布函数、参数估计中正态假设
- **复用场景**：任何由分布函数反推分布参数的题目，以及置信区间中 $\Phi$ 与分位数的换算
:::

### 第6题

:::callout{kind=note label="题目"}
设 $X \sim N(0, 1)$，$Y \sim N(1, 4)$，相关系数 $\rho_{XY} = 1$，则（　　）

A. $P\{Y = -2X + 1\} = 1$　　B. $P\{Y = 2X + 1\} = 1$　　C. $P\{Y = -2X - 1\} = 1$　　D. $P\{Y = 2X - 1\} = 1$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：题干给出 $X,Y$ 均为正态且 $\rho_{XY}=1$，要求确定 $Y$ 关于 $X$ 的线性关系。入口是识别"相关系数为 $\pm 1$ 对应完全线性关系"，套用公式 $Y=E(Y)+\rho\dfrac{\sigma_Y}{\sigma_X}(X-E(X))$，代入参数即得。

**为何用此公式**：完全相关 $\rho=\pm 1$ 时 $Y$ 与 $X$ 存在严格线性关系 $Y=E(Y)+\rho\dfrac{\sigma_Y}{\sigma_X}(X-E(X))$（a.s.），该公式直接由相关系数定义与柯西-施瓦茨不等式等号条件给出，无需重新推导联合分布。

**推导过程**：

1. 第一步：识别 $\rho_{XY}=1$ 对应完全正相关 ← 依据：相关系数的几何意义（柯西-施瓦茨等号条件）
2. 第二步：写出完全相关线性公式 ← 依据：$\rho=\pm 1$ 时 $Y=E(Y)+\rho\dfrac{\sigma_Y}{\sigma_X}(X-E(X))$（a.s.）
3. 第三步：提取参数 ← 依据：题设
   - $E(X)=0$，$\sigma_X=\sqrt{1}=1$
   - $E(Y)=1$，$\sigma_Y=\sqrt{4}=2$
   - $\rho=1$
4. 第四步：代入 ← 依据：算术代入
   $$Y=1+1\times\frac{2}{1}\times(X-0)=2X+1$$
5. 第五步：得结论 $P\{Y=2X+1\}=1$ ← 依据：完全相关关系以概率 1 成立

**选项分析**：

- **A（错误）**：斜率 $-2$ 对应 $\rho=-1$（完全负相关），与题设 $\rho=1$ 矛盾。
- **B（正确）**：斜率 $2=\dfrac{\sigma_Y}{\sigma_X}$，截距 $1=E(Y)-\rho\dfrac{\sigma_Y}{\sigma_X}E(X)=1-0=1$，与 $\rho=1$ 一致。
- **C（错误）**：斜率 $-2$ 与截距 $-1$ 均错误，对应 $\rho=-1$ 且 $E(Y)=-1$，与题设 $E(Y)=1,\rho=1$ 均矛盾。
- **D（错误）**：截距应为 $+1$（即 $E(Y)$），$-1$ 把 $E(Y)$ 符号搞反。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **斜率符号出错**：把 $\rho=1$ 误当作负相关得斜率 $-2$ → 正确做法：$\rho>0$ 斜率为正，$\rho<0$ 斜率为负；本题 $\rho=1$ 故斜率 $+\dfrac{\sigma_Y}{\sigma_X}=+2$。
2. **截距公式漏 $E(X)$ 项**：把截距直接当作 $E(Y)$ 而忽略 $-\rho\dfrac{\sigma_Y}{\sigma_X}E(X)$ → 正确做法：截距 $=E(Y)-\rho\dfrac{\sigma_Y}{\sigma_X}E(X)$，本题 $E(X)=0$ 恰好简化为 $E(Y)=1$，但一般情形需完整代入。
3. **方差与标准差混淆**：把 $\sigma_Y=4$（方差）当作标准差代入 → 正确做法：$Y\sim N(1,4)$ 中 $4$ 是方差，标准差 $\sigma_Y=2$。
:::

:::callout{kind=note label="知识卡片：相关系数与线性关系"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $\rho=1$ 完全正相关 | $Y=E(Y)+\dfrac{\sigma_Y}{\sigma_X}(X-E(X))$（a.s.） | 二阶矩存在且 $\rho=1$ |
| $\rho=-1$ 完全负相关 | $Y=E(Y)-\dfrac{\sigma_Y}{\sigma_X}(X-E(X))$（a.s.） | 二阶矩存在且 $\rho=-1$ |
| $\rho=0$ 不相关 | 无确定线性关系 | 仅协方差为零 |
| 斜率符号 | $\rho>0$ 斜率为正，$\rho<0$ 斜率为负 | 完全相关时 |
| 截距 | $E(Y)-\rho\dfrac{\sigma_Y}{\sigma_X}E(X)$ | 完全相关时 |
| 柯西-施瓦茨等号 | $\|\rho\|=1\Leftrightarrow Y$ 与 $X$ 线性相关（a.s.） | 二阶矩存在 |

**概念辨析**：
- 完全相关 $\rho=\pm 1$ 给出的是"以概率 1 成立"的严格线性关系，而非"概率意义下"的线性回归；线性回归 $Y=aX+b$ 在 $\rho\ne\pm 1$ 时只是均方误差最小预测，并非等式成立。
- 截距公式 $E(Y)-\rho\dfrac{\sigma_Y}{\sigma_X}E(X)$ 在 $E(X)=0$ 时简化为 $E(Y)$，但不能因此忽略 $E(X)$ 项。
:::

:::callout{kind=tip label="结论速记"}
$\rho=\pm 1\Rightarrow Y=E(Y)\pm\dfrac{\sigma_Y}{\sigma_X}(X-E(X))$（a.s.），符号由 $\rho$ 决定。

**口诀**：完全相关线性式，斜率标准差比带符号，截距均值减斜率乘 $X$ 均值。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$\rho=\pm 1$"或"完全相关"→ 联想"$Y=E(Y)\pm\dfrac{\sigma_Y}{\sigma_X}(X-E(X))$（a.s.），斜率带符号"
- **关联考点**：相关系数（第四章）、柯西-施瓦茨不等式、线性回归与完全相关的关系
- **复用场景**：任何由 $\rho=\pm 1$ 反推线性关系式，或判断两个正态变量是否完全线性相关的题目
:::

### 第7题

:::callout{kind=note label="题目"}
设随机变量 $X$ 的分布函数为 $F(x) = cx \cdot I_{[0,1)}(x) + I_{[1,+\infty)}(x)$。若 $P\{X = 1\} = 0.1$，则（　　）

A. $c = \dfrac{1}{10}$　　B. $X \sim U(0, 1)$　　C. $c = \dfrac{9}{10}$　　D. $c = \dfrac{19}{10}$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：题干给出含参数 $c$ 的分段分布函数与 $P\{X=1\}=0.1$，要求反解 $c$。入口是识别"分布函数在 $x=1$ 处有跳跃，跳跃高度即为 $P\{X=1\}$"，套用 $P\{X=a\}=F(a)-F(a^-)$ 建立 $c$ 的方程。

**为何用此公式**：跳跃高度公式 $P\{X=a\}=F(a)-F(a^-)=F(a)-\lim_{x\to a^-}F(x)$ 直接把离散概率与分布函数的左右极限联系起来，是处理"含跳跃的分布函数定参"的标准工具。

**推导过程**：

1. 第一步：识别 $x=1$ 为分段点，$I_{[1,+\infty)}(1)=1$，$I_{[0,1)}(1)=0$ ← 依据：示性函数定义
   $$F(1)=c\cdot 1\cdot 0+1=1$$
2. 第二步：算左极限 $F(1^-)=\lim_{x\to 1^-}F(x)$ ← 依据：$x\to 1^-$ 时 $x\in[0,1)$，$I_{[0,1)}=1$，$I_{[1,+\infty)}=0$
   $$F(1^-)=\lim_{x\to 1^-}cx=c$$
3. 第三步：套跳跃公式 ← 依据：$P\{X=1\}=F(1)-F(1^-)$
   $$0.1=1-c$$
4. 第四步：解方程 ← 依据：一元一次方程
   $$c=1-0.1=0.9=\frac{9}{10}$$

**选项分析**：

- **A（错误）**：$c=\dfrac{1}{10}$ 代入得 $P\{X=1\}=1-\dfrac{1}{10}=0.9\ne 0.1$，与题设矛盾。
- **B（错误）**：$X$ 在 $x=1$ 处有离散概率 $0.1$，分布函数有跳跃，不是连续均匀分布；$U(0,1)$ 的分布函数 $F(x)=x$ 在 $[0,1]$ 连续无跳跃。
- **C（正确）**：$c=\dfrac{9}{10}$，代入 $P\{X=1\}=1-\dfrac{9}{10}=0.1$ 符合题设。
- **D（错误）**：$c=\dfrac{19}{10}>1$ 使 $F(1^-)=\dfrac{19}{10}>1$，破坏分布函数 $0\le F(x)\le 1$ 的有界性。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **左右极限用反**：把 $P\{X=1\}$ 误算为 $F(1^-)-F(1)$ 得负值 → 正确做法：跳跃高度 $=F(a)-F(a^-)$（右值减左极限），恒非负。
2. **示性函数分段点取值忽略**：把 $F(1)$ 误算为 $c\cdot 1\cdot 1+1=c+1$ → 正确做法：$I_{[0,1)}(1)=0$（左闭右开不含 1），$I_{[1,+\infty)}(1)=1$，故 $F(1)=0+1=1$。
3. **忽略分布函数有界性验证**：直接解出 $c$ 不验证 $0\le F\le 1$ → 正确做法：解出 $c$ 后必须验证 $F(1^-)=c\le 1$，$c=\dfrac{19}{10}$ 即因破坏有界性被排除。
:::

:::callout{kind=note label="知识卡片：分布函数的离散部分"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 跳跃高度 | $P\{X=a\}=F(a)-F(a^-)=F(a)-\lim_{x\to a^-}F(x)$ | 任意分布函数 |
| 连续型判别 | $F$ 连续 $\Leftrightarrow P\{X=a\}=0$ 对所有 $a$ | 连续型随机变量 |
| 混合型 | $F$ 既有连续段又有跳跃点 | 含离散与连续部分 |
| 右连续性 | $F(a)=F(a^+)=\lim_{x\to a^+}F(x)$ | 任意分布函数 |
| 单调有界 | $0\le F(x)\le 1$，单调不减 | 任意分布函数 |
| 示性函数 | $I_A(x)=1$ 若 $x\in A$，否则 $0$ | 集合 $A$ 的示性 |

**概念辨析**：
- 分布函数右连续而非左连续，故 $F(a)=F(a^+)$ 恒成立，但 $F(a^-)$ 一般不等于 $F(a)$；跳跃量正是 $F(a)-F(a^-)$。
- 示性函数 $I_{[0,1)}$ 在端点 $1$ 处取 $0$（左闭右开），$I_{[1,+\infty)}$ 在 $1$ 处取 $1$，二者在分段点处需仔细区分。
:::

:::callout{kind=tip label="结论速记"}
分布函数跳跃量 $=P\{X=a\}=F(a)-F(a^-)$，由此反解未知参数。

**口诀**：分段函数看跳跃，右值减去左极限，离散概率即高度。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"分布函数含跳跃"或"$P\{X=a\}=$ 某值"→ 联想"跳跃高度 $=F(a)-F(a^-)$，反解参数"
- **关联考点**：分布函数性质（第二章）、离散型与连续型随机变量、示性函数表示
- **复用场景**：任何含分段分布函数与离散概率的定参题，以及判断混合型分布的题目
:::

### 第8题

:::callout{kind=note label="题目"}
已知二维离散型随机向量 $(X, Y)$ 的联合分布列如下：

| $X \backslash Y$ | $0$ | $1$ |
|:-:|:-:|:-:|
| $0$ | $0.4$ | $a$ |
| $1$ | $b$ | $0.1$ |

当事件 $\{X = 0\}$ 与 $\{X + Y = 1\}$ 独立时，$a + 6b =$（　　）

A. $1$　　B. $1.2$　　C. $2$　　D. $2.4$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：题干给出二维联合分布列含两未知数 $a,b$，附加"事件 $\{X=0\}$ 与 $\{X+Y=1\}$ 独立"条件，要求 $a+6b$。入口是先用归一化得 $a+b$ 的方程，再用独立性 $P(A\cap B)=P(A)P(B)$ 得第二个方程，联立解 $a,b$ 后代入计算。

**为何用此公式**：归一化 $\sum p_{ij}=1$ 与独立性 $P(A\cap B)=P(A)P(B)$ 是二维离散分布的两个基本约束；两个未知数需两个方程，归一化给一个，独立性给另一个，恰好可解。

**推导过程**：

1. 第一步：归一化 ← 依据：联合分布列概率和为 1
   $$0.4+a+b+0.1=1\Rightarrow a+b=0.5$$
2. 第二步：算各事件概率 ← 依据：联合分布列求和
   - $P(X=0)=0.4+a$
   - $\{X+Y=1\}=\{(0,1),(1,0)\}$，$P(X+Y=1)=a+b=0.5$
   - $\{X=0\}\cap\{X+Y=1\}=\{(0,1)\}$，$P=a$
3. 第三步：套独立性方程 ← 依据：$P(A\cap B)=P(A)P(B)$
   $$a=(0.4+a)\times 0.5$$
4. 第四步：解方程 ← 依据：一元一次方程
   $$2a=0.4+a\Rightarrow a=0.4$$
   代入归一化：$b=0.5-0.4=0.1$
5. 第五步：算 $a+6b$ ← 依据：算术代入
   $$a+6b=0.4+6\times 0.1=0.4+0.6=1$$

**选项分析**：

- **A（正确）**：$a=0.4$，$b=0.1$，$a+6b=1$。
- **B（错误）**：$1.2$ 对应误将 $a,b$ 取作其他值（如忽略独立性仅用归一化任取 $a,b$）。
- **C（错误）**：$2$ 对应忽略独立性约束，仅用归一化 $a+b=0.5$ 后误算 $a+6b$ 的极端值。
- **D（错误）**：$2.4$ 对应 $a,b$ 计算错误（如把 $a,b$ 取作 $0.1,0.4$ 反向）。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **事件分解出错**：把 $\{X+Y=1\}$ 误算为 $\{(1,0)\}$ 单点 → 正确做法：$X+Y=1$ 对应 $(0,1)$ 与 $(1,0)$ 两个样本点，需全部计入。
2. **交事件算错**：把 $\{X=0\}\cap\{X+Y=1\}$ 误算为 $\{(0,0),(0,1)\}$ → 正确做法：交事件取同时满足 $X=0$ 与 $X+Y=1$ 的样本点，仅 $\{(0,1)\}$ 一点，概率为 $a$。
3. **忽略归一化只列独立性方程**：仅用独立性 $a=(0.4+a)\cdot 0.5$ 解出 $a=0.4$ 后忘记验证 $b$ → 正确做法：必须联立归一化 $a+b=0.5$ 得 $b=0.1$，两方程缺一不可。
:::

:::callout{kind=note label="知识卡片：离散联合分布与独立性"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 联合分布归一 | $\sum_{i,j}p_{ij}=1$ | 任意离散联合分布 |
| 边缘分布 | $P(X=x_i)=\sum_j p_{ij}$ | 联合分布已知 |
| 独立性判据 | $p_{ij}=P(X=x_i)\cdot P(Y=y_j)$ 对所有 $i,j$ | $X$ 与 $Y$ 独立 |
| 事件独立性 | $P(A\cap B)=P(A)\cdot P(B)$ | 两事件独立 |
| 事件和分解 | $\{X+Y=k\}=\{(i,j):i+j=k\}$ | 离散随机变量 |
| 联立求解 | 归一化 + 独立性 = 两方程解两未知数 | 含参联合分布 |

**概念辨析**：
- "事件独立"与"随机变量独立"是不同概念：前者针对两个具体事件 $A,B$，后者针对所有形如 $\{X=x\},\{Y=y\}$ 的事件对；本题是事件独立，仅需验证一对。
- 联合分布定参题通常需"归一化 + 额外条件"两个方程；额外条件可以是独立性、给定边缘、给定协方差等。
:::

:::callout{kind=tip label="结论速记"}
独立性 $P(A\cap B)=P(A)P(B)$ 配合归一化方程，两个未知数两个方程可解。

**口诀**：归一方程先列上，独立条件配成双，联立解出参数明。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"联合分布列含未知数 + 独立性条件"→ 联想"归一化给一方程，独立性给另一方程，联立求解"
- **关联考点**：二维离散分布（第三章）、事件独立性与随机变量独立性、联合分布定参
- **复用场景**：任何含参联合分布列配合独立/边缘/协方差条件的定参题
:::

### 第9题

:::callout{kind=note label="题目"}
设 $\xi \sim U(0, 10)$，对 $\xi$ 做两次独立观测，用 $X$ 表示事件 $\{0 \leq \xi \leq 3\}$ 发生的次数，用 $Y$ 表示事件 $\{2 \leq \xi \leq 8\}$ 发生的次数，则 $P\{X + Y = 3\} =$（　　）

A. $0.56$　　B. $0.81$　　C. $0.14$　　D. $0.30$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：题干给出 $\xi\sim U(0,10)$ 与两次独立观测，$X,Y$ 分别计数两个事件发生次数，要求 $P\{X+Y=3\}$。入口是先分析单次观测中 $X+Y$ 的取值分布（按区间分段），再用两次独立观测的卷积公式算 $P\{X+Y=3\}$。

**为何用此公式**：两次独立观测的总和 $S=X_1+Y_1+X_2+Y_2$ 实为单次观测值 $Z=X+Y$ 的两次独立和；当目标和为 3 时，单次只能取 1 或 2（最大值），故 $P\{S=3\}=2P\{Z=2\}P\{Z=1\}$，需乘排列系数 2。

**推导过程**：

1. 第一步：将 $[0,10]$ 按两事件发生情况分段 ← 依据：均匀分布概率 = 区间长度比

   | 区间 | 长度 | $X$ 贡献 | $Y$ 贡献 | $X+Y$ |
   |------|------|----------|----------|---------|
   | $[0,2)$ | $2$ | $1$ | $0$ | $1$ |
   | $[2,3]$ | $1$ | $1$ | $1$ | $2$ |
   | $(3,8]$ | $5$ | $0$ | $1$ | $1$ |
   | $(8,10]$ | $2$ | $0$ | $0$ | $0$ |

2. 第二步：算单次观测 $Z=X+Y$ 的分布 ← 依据：均匀分布区间概率
   - $P(Z=0)=\dfrac{2}{10}=0.2$
   - $P(Z=1)=\dfrac{2+5}{10}=0.7$
   - $P(Z=2)=\dfrac{1}{10}=0.1$
3. 第三步：分析两次独立观测和为 3 的可能 ← 依据：单次最大 $Z=2$，故和为 3 只能 $\{2,1\}$ 或 $\{1,2\}$
4. 第四步：套卷积公式并乘排列系数 ← 依据：两次独立观测顺序不同视为不同样本点
   $$P(X+Y=3)=2\times P(Z=2)\times P(Z=1)=2\times 0.1\times 0.7=0.14$$

**选项分析**：

- **A（错误）**：$0.56=0.8\times 0.7$，误把单次 $Z\ge 1$ 的概率 $0.8$ 与 $Z=1$ 的概率 $0.7$ 相乘，混淆事件定义。
- **B（错误）**：$0.81$ 无对应计算依据，对应误用某组合概率。
- **C（正确）**：$2\times 0.1\times 0.7=0.14$，含排列系数。
- **D（错误）**：$0.30$ 对应漏掉排列系数 2，仅算 $0.1\times 0.7=0.07$ 后又误乘其它因子；正确应为 $0.14$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **漏乘排列系数**：直接算 $P(Z=2)P(Z=1)=0.07$ 忘记乘 2 → 正确做法：两次观测有序，$\{2,1\}$ 与 $\{1,2\}$ 是不同样本点，需乘排列系数 $\binom{2}{1}=2$。
2. **区间分段端点遗漏**：把 $[2,3]$ 漏掉或并入相邻区间 → 正确做法：两事件在 $[2,3]$ 同时发生（$X=1,Y=1$），贡献 $Z=2$，必须单独分段。
3. **单次 $Z$ 分布算错**：把 $P(Z=1)$ 误算为 $\dfrac{2}{10}=0.2$（只算 $[0,2)$） → 正确做法：$Z=1$ 包括 $[0,2)$ 与 $(3,8]$ 两段，概率 $\dfrac{2+5}{10}=0.7$。
:::

:::callout{kind=note label="知识卡片：均匀分布区间计数与卷积"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 单次贡献分布 | 将区间按事件发生情况分段，统计各段概率 | 均匀分布 |
| 两次独立和 | $P(S=k)=\sum_{i+j=k}p_i p_j$ | 两次独立观测 |
| 排列系数 | 两次观测顺序不同视为不同样本点，需乘 $\binom{n}{k}$ | 有序抽样 |
| 多项分布卷积 | $n$ 次独立观测总和服从多项分布卷积 | $n$ 次独立观测 |
| 区间概率 | $U(a,b)$ 落入子区间 $[c,d]$ 的概率 $=\dfrac{d-c}{b-a}$ | 均匀分布 |

**概念辨析**：
- 两次独立观测的"和"分布实为单次分布的自卷积；当目标和固定时，需枚举所有单次取值组合并乘排列系数。
- 分段时应按"事件发生与否"的布尔组合划分区间，端点处需明确归属（本题 $[2,3]$ 是两事件同时发生的临界段）。
:::

:::callout{kind=tip label="结论速记"}
两次独立观测 $P(\text{和}=3)=2\cdot P(\text{单次}=2)\cdot P(\text{单次}=1)$，注意排列系数。

**口诀**：单次分段算分布，两次卷积乘排列，端点临界要分清。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"多次独立观测 + 计数事件发生次数"→ 联想"单次分段算分布，多次卷积乘排列系数"
- **关联考点**：均匀分布（第二章）、多项分布、独立试验序列
- **复用场景**：任何"独立重复观测 + 事件计数"的题目，如质量控制中的多次抽样检验
:::

### 第10题

:::callout{kind=note label="题目"}
设独立同分布随机变量序列 $\{X_n, n \geq 1\}$ 中 $X_1 \sim \chi^2(2)$，令 $Y_n = \dfrac{1}{n} \displaystyle\sum_{k=1}^{n} X_k^2$，则 $Y_n$ 依概率收敛于（　　）

A. $4$　　B. $8$　　C. $16$　　D. $20$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：题干给出 $X_1\sim\chi^2(2)$ 与 $Y_n=\dfrac{1}{n}\sum X_k^2$，要求依概率收敛极限。入口是识别 $X_k^2$ 仍为 i.i.d.，套用辛钦大数定律 $\dfrac{1}{n}\sum X_k^2\xrightarrow{P}E(X_1^2)$，关键在于算对 $E(X_1^2)$。

**为何用此公式**：辛钦大数定律适用于 i.i.d. 序列的算术平均，只要期望存在即收敛于期望；$X_k^2$ 是 i.i.d.（因 $X_k$ i.i.d. 且平方是确定性变换），故 $\dfrac{1}{n}\sum X_k^2\xrightarrow{P}E(X_1^2)$。注意收敛于 $E(X_1^2)$ 而非 $E(X_1)$。

**推导过程**：

1. 第一步：识别 $X_k^2$ 为 i.i.d. ← 依据：$X_k$ i.i.d. 且 $x\mapsto x^2$ 是确定性函数
2. 第二步：算 $\chi^2(2)$ 的数字特征 ← 依据：卡方分布性质 $E=k,D=2k$
   $$E(X_1)=2,\quad D(X_1)=4$$
3. 第三步：算 $E(X_1^2)$ ← 依据：方差-期望分解 $E(X^2)=D(X)+[E(X)]^2$
   $$E(X_1^2)=D(X_1)+[E(X_1)]^2=4+4=8$$
4. 第四步：套辛钦大数定律 ← 依据：$X_k^2$ i.i.d. 且 $E(X_1^2)<\infty$
   $$Y_n=\frac{1}{n}\sum_{k=1}^n X_k^2\xrightarrow{P}E(X_1^2)=8$$

**选项分析**：

- **A（错误）**：$4$ 是 $D(X_1)$ 而非 $E(X_1^2)$；把方差当作二阶矩。
- **B（正确）**：$E(X_1^2)=D(X_1)+[E(X_1)]^2=4+4=8$。
- **C（错误）**：$16$ 是 $[E(X_1)]^2=2^2=4$ 的误算（实为 $4$），或把 $D+E^2$ 误算为 $E^2$ 的某倍数。
- **D（错误）**：$20$ 无对应量，对应误把 $E+D+[E]^2=2+4+4=10$ 再倍之或类似错误。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **收敛目标搞错**：误以为 $Y_n$ 收敛于 $E(X_1)$ 而非 $E(X_1^2)$ → 正确做法：$Y_n$ 是 $X_k^2$ 的平均，收敛于 $E(X_1^2)$，不是 $X_k$ 的平均收敛于 $E(X_1)$。
2. **二阶矩与方差混淆**：把 $E(X_1^2)$ 误当作 $D(X_1)=4$ → 正确做法：$E(X^2)=D(X)+[E(X)]^2$，本题 $4+4=8$。
3. **$\chi^2(k)$ 数字特征记错**：把 $\chi^2(2)$ 的 $E$ 误记为 $k=2$ 但 $D$ 误记为 $k$ → 正确做法：$\chi^2(k)$ 的 $E=k,D=2k$，故 $\chi^2(2)$ 的 $E=2,D=4$。
:::

:::callout{kind=note label="知识卡片：大数定律与依概率收敛"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 辛钦大数定律 | $X_n$ i.i.d.，$E\|X_1\|<\infty$ $\Rightarrow$ $\dfrac{1}{n}\sum X_k\xrightarrow{P}E(X_1)$ | i.i.d. 且期望存在 |
| 切比雪夫大数定律 | i.i.d.，方差有界 $\Rightarrow$ 同上 | i.i.d. 且方差有界 |
| 推广形式 | $g(X_n)$ i.i.d.，$E\|g(X_1)\|<\infty$ $\Rightarrow$ $\dfrac{1}{n}\sum g(X_k)\xrightarrow{P}E[g(X_1)]$ | $g$ 可测且期望存在 |
| $\chi^2(k)$ 性质 | $E=k$，$D=2k$ | 自由度 $k$ |
| 二阶矩公式 | $E(X^2)=D(X)+[E(X)]^2$ | 二阶矩存在 |
| 依概率收敛 | $Y_n\xrightarrow{P}a$：$\forall\varepsilon>0,P(|Y_n-a|>\varepsilon)\to 0$ | 收敛定义 |

**概念辨析**：
- 辛钦大数定律要求 i.i.d.，但只要求期望存在（不要求方差）；切比雪夫要求方差有界但可放松 i.i.d. 为两两不相关。
- 收敛目标是 $E[g(X_1)]$ 而非 $g(E(X_1))$；本题 $g(x)=x^2$，收敛于 $E(X_1^2)$ 而非 $[E(X_1)]^2$。
:::

:::callout{kind=tip label="结论速记"}
$Y_n=\dfrac{1}{n}\sum X_k^2\xrightarrow{P}E(X_1^2)=D(X_1)+[E(X_1)]^2=4+4=8$。

**口诀**：平方平均收敛二阶矩，方差加均值平方算。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$\dfrac{1}{n}\sum g(X_k)$ 依概率收敛"或"大数定律"→ 联想"收敛于 $E[g(X_1)]$，用方差-期望分解算二阶矩"
- **关联考点**：大数定律（第五章）、卡方分布数字特征、依概率收敛与几乎必然收敛的区别
- **复用场景**：任何 i.i.d. 序列函数平均的收敛题，包括 $\dfrac{1}{n}\sum X_k^r$ 收敛于 $r$ 阶矩

## 二、填空题（每题 3 分，共 12 分）

### 第11题

:::callout{kind=note label="题目"}
已知 $P(A) = 0.8$，$P(B) = 0.7$，$P(A \mid B) = 0.8$，则 $P(\bar{A}\bar{B}) =$ ______。
:::

:::callout{kind=insight label="解析"}
**【答案】$0.06$**

**思路**：题干给出 $P(A),P(B),P(A\mid B)$，要求 $P(\bar{A}\bar{B})$。入口是识别 $\bar{A}\bar{B}=\overline{A\cup B}$（德摩根律），故需求 $P(A\cup B)$；先用乘法公式由 $P(A\mid B)$ 算 $P(AB)$，再用加法公式算 $P(A\cup B)$，最后取补。

**为何用此公式**：乘法公式 $P(AB)=P(A\mid B)P(B)$ 把条件概率转化为积事件概率；加法公式 $P(A\cup B)=P(A)+P(B)-P(AB)$ 把并事件拆为单事件与积事件；德摩根律 $\bar{A}\bar{B}=\overline{A\cup B}$ 把双补转化为并的补，三公式接力完成。

**推导过程**：

1. 第一步：用乘法公式算 $P(AB)$ ← 依据：乘法公式 $P(AB)=P(A\mid B)P(B)$
   $$P(AB)=0.8\times 0.7=0.56$$
2. 第二步：用加法公式算 $P(A\cup B)$ ← 依据：加法公式 $P(A\cup B)=P(A)+P(B)-P(AB)$
   $$P(A\cup B)=0.8+0.7-0.56=0.94$$
3. 第三步：用德摩根律转化 ← 依据：$\bar{A}\bar{B}=\overline{A\cup B}$
   $$P(\bar{A}\bar{B})=P(\overline{A\cup B})=1-P(A\cup B)$$
4. 第四步：算补事件概率 ← 依据：补事件公式 $P(\bar{C})=1-P(C)$
   $$P(\bar{A}\bar{B})=1-0.94=0.06$$

**关键步骤说明**：

- 乘法公式是入口：题目给的是 $P(A\mid B)$ 而非 $P(AB)$，必须先转化。
- 德摩根律是关键：直接算 $P(\bar{A}\bar{B})$ 需要 $P(\bar{A})P(\bar{B}\mid\bar{A})$ 等复杂条件，转化为 $\overline{A\cup B}$ 后用补事件公式一步到位。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **直接相乘**：误算 $P(\bar{A}\bar{B})=P(\bar{A})P(\bar{B})=0.2\times 0.3=0.06$ → 正确做法：此答案虽数值巧合相同，但需 $A,B$ 独立才可拆乘积；本题 $P(AB)=0.56\ne P(A)P(B)=0.56$（实际相等，独立），但解题必须经过 $P(A\cup B)$ 路径而非默认独立。
2. **条件概率方向搞反**：把 $P(A\mid B)$ 误当作 $P(B\mid A)$ → 正确做法：$P(A\mid B)$ 是在 $B$ 发生条件下 $A$ 的概率，乘法公式为 $P(AB)=P(A\mid B)P(B)$，不可写为 $P(AB)=P(A\mid B)P(A)$。
3. **德摩根律记错**：把 $\bar{A}\bar{B}$ 误当作 $\overline{AB}$ → 正确做法：$\overline{AB}=\bar{A}\cup\bar{B}$（并），$\overline{A\cup B}=\bar{A}\bar{B}$（交），二者互补不可混。
:::

:::callout{kind=note label="知识卡片：概率基本公式汇总"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 乘法公式 | $P(AB)=P(A\mid B)P(B)=P(B\mid A)P(A)$ | $P(B)>0$ 或 $P(A)>0$ |
| 加法公式 | $P(A\cup B)=P(A)+P(B)-P(AB)$ | 任意两事件 |
| 德摩根律 | $\overline{A\cup B}=\bar{A}\bar{B}$，$\overline{AB}=\bar{A}\cup\bar{B}$ | 任意事件 |
| 补事件 | $P(\bar{A})=1-P(A)$ | 任意事件 |
| 条件概率 | $P(A\mid B)=\dfrac{P(AB)}{P(B)}$ | $P(B)>0$ |

**概念辨析**：
- $P(\bar{A}\bar{B})$ 与 $P(\overline{AB})$ 是不同事件：前者是 $A,B$ 都不发生，后者是 $A,B$ 不同时发生（即至少一个不发生）；本题要求前者，需用 $\overline{A\cup B}$。
- 乘法公式中条件概率方向严格：$P(AB)=P(A\mid B)P(B)$ 与 $P(AB)=P(B\mid A)P(A)$ 都对，但 $P(A\mid B)\ne P(B\mid A)$ 一般情形。
:::

:::callout{kind=tip label="结论速记"}
$P(\bar{A}\bar{B})=1-P(A\cup B)=1-[P(A)+P(B)-P(AB)]$。

**口诀**：双补等于并的补，先乘后加再取补。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$P(\bar{A}\bar{B})$"或"两事件都不发生"→ 联想"德摩根律转化为 $\overline{A\cup B}$，用 $1-P(A\cup B)$"
- **关联考点**：概率基本公式（第一章）、条件概率与独立性、德摩根律
- **复用场景**：任何求"两事件都不发生"或"至少一个发生"的题目，以及贝叶斯公式中的归一化计算
:::

### 第12题

:::callout{kind=note label="题目"}
设 $X \sim E(\lambda)$，$Y \sim E(\lambda)$ 且相互独立，则 $P\{Y < X - 3 \mid X > 3\} =$ ______。
:::

:::callout{kind=insight label="解析"}
**【答案】$\dfrac{1}{2}$**

**思路**：题干给出 $X,Y$ 独立同分布指数，要求条件概率 $P\{Y<X-3\mid X>3\}$。入口是识别"指数分布无记忆性"使 $X-3\mid X>3\sim E(\lambda)$ 且与 $Y$ 独立，问题化为两独立同分布指数变量的大小比较，由对称性得 $\dfrac{1}{2}$。

**为何用此公式**：指数分布的无记忆性 $X-s\mid X>s\sim E(\lambda)$ 是指数分布特有性质，把条件 $X>3$ 转化为残余变量 $X'=X-3$ 仍服从 $E(\lambda)$；两独立同分布连续变量大小比较由对称性得 $\dfrac{1}{2}$，无需积分。

**推导过程**：

1. 第一步：用无记忆性转化条件 ← 依据：指数分布无记忆性 $X-s\mid X>s\sim E(\lambda)$
   $$X-3\mid X>3\sim E(\lambda),\quad\text{记 }X'=X-3$$
2. 第二步：识别 $X'$ 与 $Y$ 独立 ← 依据：$X$ 与 $Y$ 独立，$X'$ 是 $X$ 的函数，故 $X'$ 与 $Y$ 独立
3. 第三步：转化概率 ← 依据：条件概率定义
   $$P\{Y<X-3\mid X>3\}=P\{Y<X'\},\quad X'\sim E(\lambda),Y\sim E(\lambda),\text{独立}$$
4. 第四步：用积分或对称性求解 ← 依据：两独立同分布连续变量对称性 $P(Y<X')=P(X'<Y)=\dfrac{1}{2}$（相等概率为 0）
   - 验证性积分：
   $$P\{Y<X'\}=\int_0^{+\infty}P\{Y<x\}\lambda e^{-\lambda x}dx=\int_0^{+\infty}(1-e^{-\lambda x})\lambda e^{-\lambda x}dx$$
   $$=\int_0^{+\infty}\lambda e^{-\lambda x}dx-\int_0^{+\infty}\lambda e^{-2\lambda x}dx=1-\frac{1}{2}=\frac{1}{2}$$

**关键步骤说明**：

- 无记忆性是核心：把"条件 $X>3$"化为"残余变量 $X'$ 仍服从 $E(\lambda)$"，避免直接对联合密度积分。
- 对称性是捷径：两独立同分布连续变量，$P(Y<X')=P(X'<Y)$，且 $P(X'=Y)=0$，故各为 $\dfrac{1}{2}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **忽略无记忆性硬积分**：直接对 $P\{Y<X-3,X>3\}$ 与 $P\{X>3\}$ 分别积分 → 正确做法：用无记忆性 $X-3\mid X>3\sim E(\lambda)$ 一步化简，避免复杂二重积分。
2. **残余变量与原变量独立性搞错**：误以为 $X-3\mid X>3$ 与 $Y$ 不独立 → 正确做法：$X$ 与 $Y$ 独立，$X-3\mid X>3$ 是 $X$ 的条件分布，仍与 $Y$ 独立。
3. **对称性使用条件遗漏**：忘记验证 $X'$ 与 $Y$ 同分布 → 正确做法：对称性 $P(Y<X')=\dfrac{1}{2}$ 要求二者独立同分布；本题 $X',Y$ 均 $\sim E(\lambda)$ 且独立，条件满足。
:::

:::callout{kind=note label="知识卡片：指数分布的无记忆性"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 无记忆性 | $P\{X>s+t\mid X>s\}=P\{X>t\}$ | $X\sim E(\lambda)$ |
| 残余分布 | $X-s\mid X>s\sim E(\lambda)$，与 $X$ 同分布 | 指数分布 |
| 唯一性 | 连续型中仅指数分布具有无记忆性 | 连续型分布 |
| 对称比较 | $X,Y$ i.i.d. $\Rightarrow P(X<Y)=\dfrac{1}{2}$ | 独立同分布连续变量 |
| 一般比较 | $X\sim E(\lambda_1),Y\sim E(\lambda_2)\Rightarrow P(X<Y)=\dfrac{\lambda_2}{\lambda_1+\lambda_2}$ | 独立指数变量 |
| 指数分布数字特征 | $E=\dfrac{1}{\lambda}$，$D=\dfrac{1}{\lambda^2}$ | $\lambda>0$ |

**概念辨析**：
- 无记忆性是指数分布的特征性质：连续型中仅指数分布满足，离散型中几何分布也满足；这是指数分布用于"寿命建模"的理论基础。
- 对称比较 $P(X<Y)=\dfrac{1}{2}$ 仅在 i.i.d. 时成立；非同分布时用 $P(X<Y)=\dfrac{\lambda_2}{\lambda_1+\lambda_2}$（参数大者"赢"概率小）。
:::

:::callout{kind=tip label="结论速记"}
指数分布无记忆性 + 两同分布独立变量对称比较 $\Rightarrow P=\dfrac{1}{2}$。

**口诀**：指数无记忆，残余同分布，对称比一半。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$P\{Y<X-s\mid X>s\}$"或"指数分布条件概率"→ 联想"无记忆性 $X-s\mid X>s\sim E(\lambda)$，再判独立同分布对称性"
- **关联考点**：指数分布（第二章）、无记忆性与几何分布的类比、独立变量大小比较
- **复用场景**：任何涉及指数分布条件概率或寿命剩余分布的题目，如可靠性工程中的剩余寿命估计
:::

### 第13题

:::callout{kind=note label="题目"}
设二维随机向量 $(X, Y)$ 服从区域 $D = \{(x, y) : 0 \leq y \leq \sqrt{1 - x^2}\}$ 上的均匀分布，对 $(X, Y)$ 的三次独立重复观察中，事件 $\{X \geq Y\}$ 出现次数为 $2$ 的概率 $p =$ ______。
:::

:::callout{kind=insight label="解析"}
**【答案】$\dfrac{9}{64}$**

**思路**：题干给出 $(X,Y)$ 在上半单位圆均匀分布，三次独立观察中 $\{X\ge Y\}$ 出现 2 次的概率。入口是分两步：先用几何概型算单次 $P(X\ge Y)$，再用二项分布 $\binom{3}{2}p^2(1-p)$ 算三次恰 2 次。

**为何用此公式**：几何概型 $P(A)=\dfrac{|A|}{|D|}$（测度比）适用于均匀分布的区域概率；二项分布 $\binom{n}{k}p^k(1-p)^{n-k}$ 适用于 $n$ 次独立伯努利试验恰 $k$ 次成功。两公式接力完成"单次概率 + 多次计数"。

**推导过程**：

1. 第一步：识别区域 $D$ ← 依据：$0\le y\le\sqrt{1-x^2}$ 即 $x^2+y^2\le 1,y\ge 0$，上半单位圆
   $$|D|=\frac{\pi}{2}$$
2. 第二步：用极坐标转化事件 $\{X\ge Y\}$ ← 依据：$x=r\cos\theta,y=r\sin\theta$，$0\le r\le 1,0\le\theta\le\pi$
   - $y\ge 0$ 已含 $\theta\in[0,\pi]$
   - $x\ge y\Rightarrow r\cos\theta\ge r\sin\theta\Rightarrow\cos\theta\ge\sin\theta$
   - 在 $[0,\pi]$ 内 $\cos\theta\ge\sin\theta$ 要求 $\theta\in\left[0,\dfrac{\pi}{4}\right]$（且 $x\ge 0$ 即 $\theta\le\dfrac{\pi}{2}$ 自动满足）
3. 第三步：算事件区域面积 ← 依据：扇形面积 $=\dfrac{1}{2}r^2\theta$
   $$|A|=\frac{1}{2}\times 1^2\times\frac{\pi}{4}=\frac{\pi}{8}$$
4. 第四步：算单次概率 ← 依据：几何概型 $P(A)=\dfrac{|A|}{|D|}$
   $$P(X\ge Y)=\frac{\pi/8}{\pi/2}=\frac{1}{4}$$
5. 第五步：算三次恰 2 次 ← 依据：二项分布 $B\!\left(3,\dfrac{1}{4}\right)$
   $$p=\binom{3}{2}\left(\frac{1}{4}\right)^2\left(\frac{3}{4}\right)=3\times\frac{1}{16}\times\frac{3}{4}=\frac{9}{64}$$

**关键步骤说明**：

- 极坐标是关键：上半圆用直角坐标积分需分段，极坐标下一目了然 $\theta\in\left[0,\dfrac{\pi}{4}\right]$。
- $\cos\theta\ge\sin\theta$ 的解集：在 $[0,\pi]$ 内，$\theta\in\left[0,\dfrac{\pi}{4}\right]$ 时 $\cos\ge\sin$；$\theta\in\left(\dfrac{\pi}{4},\dfrac{\pi}{2}\right]$ 时 $\sin>\cos$；$\theta\in\left(\dfrac{\pi}{2},\pi\right]$ 时 $\cos\le 0\le\sin$ 不满足。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **区域识别错误**：把 $D$ 误当作全单位圆 → 正确做法：$y\ge 0$ 限制为上半单位圆，面积 $\dfrac{\pi}{2}$ 而非 $\pi$。
2. **极坐标角度范围出错**：把 $\theta\in\left[0,\dfrac{\pi}{4}\right]$ 误算为 $\left[0,\dfrac{\pi}{2}\right]$ → 正确做法：$\cos\theta\ge\sin\theta$ 在 $[0,\pi]$ 内仅 $\left[0,\dfrac{\pi}{4}\right]$ 满足，需解三角不等式。
3. **二项系数漏乘**：忘记乘 $\binom{3}{2}=3$ → 正确做法：三次恰 2 次有 $\binom{3}{2}=3$ 种排列，必须乘排列系数。
:::

:::callout{kind=note label="知识卡片：几何概型与二项分布"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 几何概型 | $P(A)=\dfrac{|A|}{|D|}$（测度比） | 区域上均匀分布 |
| 极坐标变换 | $x=r\cos\theta,y=r\sin\theta$，$dx\,dy=r\,dr\,d\theta$ | 圆形/扇形区域 |
| 上半单位圆面积 | $\dfrac{\pi}{2}$ | $x^2+y^2\le 1,y\ge 0$ |
| 扇形面积 | $\dfrac{1}{2}r^2\theta$ | 半径 $r$，圆心角 $\theta$ |
| 二项分布 | $n$ 次独立试验恰 $k$ 次成功：$\dbinom{n}{k}p^k(1-p)^{n-k}$ | 独立伯努利试验 |
| 排列系数 | $\dbinom{n}{k}=\dfrac{n!}{k!(n-k)!}$ | $n$ 中选 $k$ |

**概念辨析**：
- 几何概型要求"均匀分布"，即密度在区域内为常数；非均匀分布需用密度函数积分。
- 二项分布适用于"独立重复"试验；若试验不独立（如无放回抽样）需用超几何分布。
:::

:::callout{kind=tip label="结论速记"}
几何概型算单次概率 $p$，再代入二项分布 $\dbinom{n}{k}p^k(1-p)^{n-k}$。

**口诀**：区域面积极坐标算，单次概率二项套，排列系数莫忘乘。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"区域上均匀分布 + 多次独立观察计数"→ 联想"几何概型算单次 $p$，二项分布算多次"
- **关联考点**：几何概型（第一章）、二维均匀分布（第三章）、二项分布与多项分布
- **复用场景**：任何"均匀区域 + 独立重复观察"的题目，如蒙特卡洛模拟中的命中率估计
:::

### 第14题

:::callout{kind=note label="题目"}
随机选取两组学生各 $60$ 人，分别测定某一化合物的 pH 值，假定测量结果相互独立且服从同一分布，其期望为 $5$，方差为 $0.3$。用 $\bar{X}, \bar{Y}$ 分别表示两组测量结果的平均值，则 $P\{|\bar{X} - \bar{Y}| < 0.1\} \approx$ ______。（用标准正态分布函数 $\Phi$ 表示）
:::

:::callout{kind=insight label="解析"}
**【答案】$2\Phi(1) - 1$**

**思路**：题干给出两组独立同分布样本均值 $\bar{X},\bar{Y}$，要求 $P\{|\bar{X}-\bar{Y}|<0.1\}$。入口是用中心极限定理把 $\bar{X},\bar{Y}$ 近似为正态，再由独立性得 $\bar{X}-\bar{Y}$ 的正态分布，标准化后用 $\Phi$ 表示。

**为何用此公式**：中心极限定理 $\bar{X}\sim N\!\left(\mu,\dfrac{\sigma^2}{n}\right)$（近似）适用于大样本均值；独立正态差的分布 $N(\mu_1-\mu_2,\sigma_1^2+\sigma_2^2)$ 适用于两独立正态变量之差；标准化 $Z=\dfrac{X-\mu}{\sigma}\sim N(0,1)$ 适用于用 $\Phi$ 表示概率。

**推导过程**：

1. 第一步：用 CLT 近似 $\bar{X},\bar{Y}$ 分布 ← 依据：中心极限定理 $\bar{X}\sim N\!\left(\mu,\dfrac{\sigma^2}{n}\right)$（$n$ 大时）
   $$\bar{X}\sim N\!\left(5,\frac{0.3}{60}\right),\quad\bar{Y}\sim N\!\left(5,\frac{0.3}{60}\right)$$
2. 第二步：算 $\bar{X}-\bar{Y}$ 分布 ← 依据：独立正态差 $N(\mu_1-\mu_2,\sigma_1^2+\sigma_2^2)$
   $$\bar{X}-\bar{Y}\sim N\!\left(5-5,\frac{0.3}{60}+\frac{0.3}{60}\right)=N(0,0.01)$$
3. 第三步：算标准差 ← 依据：方差开方
   $$\sigma_{\bar{X}-\bar{Y}}=\sqrt{0.01}=0.1$$
4. 第四步：标准化 ← 依据：$Z=\dfrac{\bar{X}-\bar{Y}-0}{0.1}\sim N(0,1)$
   $$P\{|\bar{X}-\bar{Y}|<0.1\}=P\left\{\left|\frac{\bar{X}-\bar{Y}}{0.1}\right|<1\right\}=P\{|Z|<1\}$$
5. 第五步：用 $\Phi$ 表示 ← 依据：对称区间公式 $P(|Z|<c)=2\Phi(c)-1$
   $$P\{|Z|<1\}=2\Phi(1)-1$$

**关键步骤说明**：

- CLT 是核心：题目未给正态假设，但 $n=60$ 较大，用 CLT 近似为正态。
- 独立性简化方差：$\bar{X},\bar{Y}$ 独立使 $D(\bar{X}-\bar{Y})=D(\bar{X})+D(\bar{Y})$（协方差项为零）。
- 标准化使结果用 $\Phi$ 表示：把 $N(0,0.01)$ 化为 $N(0,1)$ 后用标准正态表。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **方差忘记除以 $n$**：直接取 $D\bar{X}=\sigma^2=0.3$ → 正确做法：样本均值方差 $D\bar{X}=\dfrac{\sigma^2}{n}=\dfrac{0.3}{60}$，因 $\bar{X}$ 是 $n$ 个独立样本平均。
2. **差的方差漏加**：误算 $D(\bar{X}-\bar{Y})=D\bar{X}-D\bar{Y}=0$ → 正确做法：独立变量差的方差仍相加 $D(\bar{X}-\bar{Y})=D\bar{X}+D\bar{Y}$，因 $D(-\bar{Y})=D\bar{Y}$。
3. **标准化系数搞反**：把 $Z=\dfrac{\bar{X}-\bar{Y}}{0.1}$ 误写为 $Z=0.1(\bar{X}-\bar{Y})$ → 正确做法：标准化除以标准差，$Z=\dfrac{X-\mu}{\sigma}$，本题 $\sigma=0.1$。
:::

:::callout{kind=note label="知识卡片：中心极限定理与样本均值"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 样本均值分布 | $\bar{X}\sim N\!\left(\mu,\dfrac{\sigma^2}{n}\right)$（近似） | $n$ 大（CLT） |
| 两均值差 | $\bar{X}-\bar{Y}\sim N\!\left(\mu_1-\mu_2,\dfrac{\sigma_1^2}{n_1}+\dfrac{\sigma_2^2}{n_2}\right)$ | 两组独立 |
| 标准化 | $Z=\dfrac{\bar{X}-\bar{Y}-(\mu_1-\mu_2)}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}\sim N(0,1)$ | 同上 |
| 对称区间 | $P(|Z|<c)=2\Phi(c)-1$ | $Z\sim N(0,1)$ |
| CLT | $n$ 大时 $\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\xrightarrow{d}N(0,1)$ | i.i.d. 且方差存在 |

**概念辨析**：
- CLT 给出的是"近似"正态，要求 $n$ 足够大（一般 $n\ge 30$）；总体正态时样本均值精确正态，无需 CLT。
- 两独立正态差的方差是"和"而非"差"：$D(X-Y)=D(X)+D(Y)$（因 $D(-Y)=D(Y)$，符号不影响方差）。
:::

:::callout{kind=tip label="结论速记"}
独立两组均值差 $\sim N\!\left(0,\dfrac{2\sigma^2}{n}\right)$，标准化后 $P\{|Z|<c\}=2\Phi(c)-1$。

**口诀**：均值方差除 $n$，差方差相加，标准化除标准差，对称区间双 $\Phi$ 减一。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"两组样本均值差的概率"或"CLT 应用"→ 联想"$\bar{X}-\bar{Y}\sim N(0,\frac{2\sigma^2}{n})$，标准化用 $2\Phi-1$"
- **关联考点**：中心极限定理（第五章）、样本均值分布、置信区间与假设检验
- **复用场景**：任何两组样本均值比较的题目，包括双样本 $z$ 检验、双样本置信区间
:::

## 三、计算题（10 分）

### 第15题

:::callout{kind=note label="题目"}
某箱有 $10$ 件产品，其中有 $0$ 件、$1$ 件、$2$ 件次品的概率均为 $\dfrac{1}{3}$。开箱检验时从箱中任取一件，如果该件产品的检验结果是次品，则认为该箱产品不合格而拒收，否则接收。由于检验误差，正品被误判为次品的概率为 $2\%$，次品被误判为正品的概率为 $10\%$。求：

1. 一箱产品被接收的概率 $p$；
2. 检验 $10$ 箱产品，接收不少于 $9$ 箱的概率。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：题干给出箱内次品数为 0/1/2 的先验概率与检验误判率，要求接收概率与 10 箱中接收不少于 9 箱的概率。入口是识别"全概率公式 + 二项分布"两段结构：先用全概率公式按次品数分解算单箱接收概率 $p$，再用二项分布 $B(10,p)$ 算 10 箱接收数。

**为何用此公式**：全概率公式 $P(B)=\sum_k P(B\mid A_k)P(A_k)$ 适用于"先验分类 + 条件概率"结构；二项分布 $\binom{n}{k}p^k(1-p)^{n-k}$ 适用于 $n$ 次独立伯努利试验。检验误差模型中"正品误判率"与"次品误判率"分别对应 $P(\bar{B}\mid\text{正})$ 与 $P(B\mid\text{次})$ 的补。

**推导过程**：

设 $A_k$ 表示箱中恰有 $k$ 件次品（$k=0,1,2$），$B$ 表示一箱被接收。则 $P(A_0)=P(A_1)=P(A_2)=\dfrac{1}{3}$。

**第 1 问：单箱接收概率**

1. 第一步：算 $P(B\mid A_0)$ ← 依据：$A_0$ 全正品，任取一件为正品，判正品即接收
   $$P(B\mid A_0)=1-0.02=0.98$$
2. 第二步：算 $P(B\mid A_1)$ ← 依据：$A_1$ 含 1 件次品 9 件正品，接收 = 取正品且判正品 + 取次品但判正品
   $$P(B\mid A_1)=\frac{9}{10}\times 0.98+\frac{1}{10}\times 0.10=0.882+0.01=0.892$$
3. 第三步：算 $P(B\mid A_2)$ ← 依据：$A_2$ 含 2 件次品 8 件正品
   $$P(B\mid A_2)=\frac{8}{10}\times 0.98+\frac{2}{10}\times 0.10=0.784+0.02=0.804$$
4. 第四步：套全概率公式 ← 依据：$P(B)=\sum_k P(B\mid A_k)P(A_k)$
   $$p=P(B)=\frac{1}{3}(0.98+0.892+0.804)=\frac{2.676}{3}=0.892$$

**第 2 问：10 箱中接收不少于 9 箱**

5. 第五步：识别 10 箱接收数分布 ← 依据：各箱独立接收，接收概率 $p=0.892$
   $$X\sim B(10,0.892),\quad P(X\ge 9)=P(X=9)+P(X=10)$$
6. 第六步：套二项分布 ← 依据：$\dbinom{n}{k}p^k(1-p)^{n-k}$
   $$P(X\ge 9)=\binom{10}{9}(0.892)^9(0.108)+(0.892)^{10}$$

**关键步骤说明**：

- 全概率公式的"完备事件组"是次品数 $A_0,A_1,A_2$（互斥且穷尽）。
- 条件概率 $P(B\mid A_k)$ 需分解为"取正品 + 取次品"两情况，每种再考虑误判率。
- 10 箱独立是关键假设，使接收数服从二项分布而非超几何分布。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **误判率方向搞反**：把"正品误判为次品 2%"当作 $P(B\mid\text{正})$ → 正确做法：误判为次品即拒收，故 $P(B\mid\text{正})=1-0.02=0.98$；"次品误判为正品 10%"即接收，故 $P(B\mid\text{次})=0.10$。
2. **条件概率遗漏取次品情况**：$P(B\mid A_1)$ 只算取正品判正品 $\dfrac{9}{10}\times 0.98$ → 正确做法：还需加取次品但判正品 $\dfrac{1}{10}\times 0.10$，两情况互补完备。
3. **10 箱分布用错**：误用超几何分布或泊松分布 → 正确做法：各箱独立接收，接收数服从二项分布 $B(10,p)$；超几何适用于无放回抽样，泊松适用于 $n$ 大 $p$ 小稀有事件。
:::

:::callout{kind=note label="知识卡片：全概率公式与贝叶斯公式"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 全概率公式 | $P(B)=\sum_k P(B\mid A_k)P(A_k)$ | $A_k$ 为完备事件组 |
| 贝叶斯公式 | $P(A_k\mid B)=\dfrac{P(B\mid A_k)P(A_k)}{\sum_j P(B\mid A_j)P(A_j)}$ | 同上 |
| 二项分布 | $X\sim B(n,p)$：$P(X=k)=\dbinom{n}{k}p^k(1-p)^{n-k}$ | $n$ 次独立伯努利 |
| 累积概率 | $P(X\ge m)=\sum_{k=m}^n\dbinom{n}{k}p^k(1-p)^{n-k}$ | 同上 |
| 检验误差模型 | 正品误判率 + 次品误判率共同决定接收概率 | 含两类误差的检验 |
| 完备事件组 | $A_i$ 互斥且 $\bigcup A_i=\Omega$ | 全概率/贝叶斯前提 |

**概念辨析**：
- 全概率公式"由因求果"（已知先验 $P(A_k)$ 与似然 $P(B\mid A_k)$ 求总概率 $P(B)$），贝叶斯公式"由果求因"（已知 $B$ 发生反推 $A_k$ 概率）；本题第 1 问是全概率，若问"已知接收，求箱中无次品概率"则用贝叶斯。
- 二项分布要求独立；若各箱不独立（如共享批次）需用条件概率或多元分布。
:::

:::callout{kind=tip label="结论速记"}
全概率公式分解箱内次品数情形，加权求和得 $p=0.892$；10 箱接收数 $\sim B(10,p)$。

**口诀**：先验分类全概率，误判方向要分清，多箱独立二项算。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"先验分类 + 检验误差 + 接收概率"→ 联想"全概率公式按次品数分解，误判率方向：正品判次品 = 拒收"
- **关联考点**：全概率与贝叶斯公式（第一章）、二项分布、检验误差模型（统计质量控制）
- **复用场景**：任何"分类先验 + 条件检验 + 批量抽样"的题目，如医学检验的灵敏度/特异度问题
:::

## 四、计算题（12 分）

### 第16题

:::callout{kind=note label="题目"}
1. 某小型卡车的载重量为 $2$ 吨，水泥的袋装量 $X \sim N(50, 2.5^2)$（单位：kg）。为了以 $0.95$ 的概率保证卡车不超载，写出卡车能装水泥的袋数 $n$ 满足的条件。

2. 某汽车公司生产的电动汽车充电一次可行驶的路程 $X \sim N(\mu, \sigma^2)$，其中 $\sigma$ 已知。甲、乙两测试组分别有放回地随机抽取 $100$ 辆和 $400$ 辆，样本均值分别为 $\bar{X}_1, \bar{X}_2$。甲测试组得 $\mu$ 的置信水平为 $95\%$ 的置信区间 $[a, b]$，乙测试组得 $\mu$ 的置信水平为 $99\%$ 的置信区间 $[a, c]$。若 $\bar{X}_1 - \bar{X}_2 = 1.34$，求 $b - a$。（已知 $u_{0.025} = 1.96$，$u_{0.005} = 2.58$）
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：本题两问。第 1 问是正态和的不超载概率，入口是识别 $n$ 袋总重 $S_n=\sum X_i\sim N(n\mu,n\sigma^2)$，标准化后用分位数表示 $P(S_n\le 2000)\ge 0.95$。第 2 问是两置信区间共享左端点 $a$，入口是写出两区间表达式，由左端点相等建立 $\bar{X}_1-\bar{X}_2$ 与 $\sigma$ 的方程，反解 $\sigma$ 后算甲组区间长度 $b-a$。

**为何用此公式**：独立正态和 $S_n\sim N(n\mu,n\sigma^2)$ 适用于 i.i.d. 正态样本总和；$\mu$ 的置信区间 $\left[\bar{X}\pm u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}\right]$ 适用于 $\sigma$ 已知的正态均值估计；两区间左端点相等提供方程反解 $\sigma$。

**推导过程**：

**第 1 问：不超载条件**

1. 第一步：算总重分布 ← 依据：独立正态和 $S_n=\sum_{i=1}^n X_i\sim N(n\mu,n\sigma^2)$
   $$S_n\sim N(50n,2.5^2 n)$$
2. 第二步：写不超载概率 ← 依据：题设 $P(S_n\le 2000)\ge 0.95$
3. 第三步：标准化 ← 依据：$Z=\dfrac{S_n-50n}{2.5\sqrt{n}}\sim N(0,1)$
   $$\Phi\!\left(\frac{2000-50n}{2.5\sqrt{n}}\right)\ge 0.95$$
4. 第四步：用分位数表示 ← 依据：$\Phi(u_{0.05})=0.95$，$u_{0.05}\approx 1.645$
   $$\frac{2000-50n}{2.5\sqrt{n}}\ge u_{0.05}\approx 1.645$$

**第 2 问：求 $b-a$**

5. 第一步：写甲组置信区间 ← 依据：$\mu$ 的 $95\%$ 置信区间 $\left[\bar{X}_1\pm u_{0.025}\dfrac{\sigma}{\sqrt{100}}\right]$
   $$[a,b]=\left[\bar{X}_1-1.96\frac{\sigma}{10},\bar{X}_1+1.96\frac{\sigma}{10}\right]$$
6. 第二步：写乙组置信区间 ← 依据：$\mu$ 的 $99\%$ 置信区间 $\left[\bar{X}_2\pm u_{0.005}\dfrac{\sigma}{\sqrt{400}}\right]$
   $$[a,c]=\left[\bar{X}_2-2.58\frac{\sigma}{20},\bar{X}_2+2.58\frac{\sigma}{20}\right]$$
7. 第三步：由左端点相等建方程 ← 依据：两区间左端点同为 $a$
   $$\bar{X}_1-1.96\frac{\sigma}{10}=\bar{X}_2-2.58\frac{\sigma}{20}$$
8. 第四步：解 $\bar{X}_1-\bar{X}_2$ ← 依据：移项整理
   $$\bar{X}_1-\bar{X}_2=\frac{1.96\sigma}{10}-\frac{2.58\sigma}{20}=\frac{3.92\sigma-2.58\sigma}{20}=\frac{1.34\sigma}{20}=0.067\sigma$$
9. 第五步：代入 $\bar{X}_1-\bar{X}_2=1.34$ 反解 $\sigma$ ← 依据：题设
   $$\sigma=\frac{1.34}{0.067}=20$$
10. 第六步：算甲组区间长度 ← 依据：$b-a=2u_{0.025}\dfrac{\sigma}{\sqrt{100}}$
    $$b-a=2\times 1.96\times\frac{20}{10}=2\times 1.96\times 2=7.84$$

**关键步骤说明**：

- 第 1 问：$n$ 既是袋数又是正态和的样本数，注意 $S_n$ 方差是 $n\sigma^2$ 而非 $\sigma^2$。
- 第 2 问：两区间共享左端点 $a$ 是题眼，由此建立 $\bar{X}_1-\bar{X}_2$ 与 $\sigma$ 的线性方程；解出 $\sigma=20$ 后区间长度一步可得。
- 分位数符号：$u_\alpha$ 满足 $\Phi(u_\alpha)=1-\alpha$，故 $u_{0.025}=1.96$ 对应 $95\%$ 置信（双侧各 $2.5\%$）。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **正态和方差出错**：误算 $D(S_n)=\sigma^2$ 而非 $n\sigma^2$ → 正确做法：独立变量和的方差相加 $D(S_n)=\sum D(X_i)=n\sigma^2$，标准差 $\sigma\sqrt{n}$。
2. **置信区间分位数搞混**：把 $95\%$ 置信区间的分位数误用 $u_{0.05}=1.645$ → 正确做法：双侧置信区间用 $u_{\alpha/2}$，$95\%$ 对应 $u_{0.025}=1.96$；单侧才用 $u_{0.05}$。
3. **区间长度公式漏因子 2**：误算 $b-a=u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$ → 正确做法：区间长度 $=2u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$（左右各一个半宽）。
4. **$\sqrt{n}$ 用错**：把甲组 $\sqrt{100}=10$ 误算为 $\sqrt{400}=20$ → 正确做法：甲组 $n_1=100$，$\sqrt{n_1}=10$；乙组 $n_2=400$，$\sqrt{n_2}=20$，各用各的。
:::

:::callout{kind=note label="知识卡片：正态分布应用与置信区间"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 独立正态和 | $\sum X_i\sim N(n\mu,n\sigma^2)$ | i.i.d. 正态 |
| 标准化 | $\dfrac{S_n-n\mu}{\sigma\sqrt{n}}\sim N(0,1)$ | 同上 |
| 分位数 $u_\alpha$ | $\Phi(u_\alpha)=1-\alpha$ | 标准正态 |
| 常用值 | $u_{0.05}=1.645$，$u_{0.025}=1.96$，$u_{0.005}=2.58$ | 标准正态表 |
| $\mu$ 的置信区间 | $\left[\bar{X}-u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}},\bar{X}+u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}\right]$ | $\sigma$ 已知 |
| 区间长度 | $2u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$，与 $\sqrt{n}$ 成反比 | 同上 |
| 单侧 vs 双侧 | 单侧用 $u_\alpha$，双侧用 $u_{\alpha/2}$ | 置信水平 $1-\alpha$ |

**概念辨析**：
- 置信区间长度 $2u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$ 随 $\sqrt{n}$ 增大而减小，故增大样本量可缩短区间；随 $\sigma$ 增大而增大，故方差大时区间长。
- 置信水平 $1-\alpha$ 越高，$u_{\alpha/2}$ 越大，区间越长；本题乙组 $99\%$ 比 甲组 $95\%$ 置信水平高，单侧半宽更大。
:::

:::callout{kind=tip label="结论速记"}
置信区间长度 $=2u_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$；两区间左端点相等建立方程反解 $\sigma$。

**口诀**：正态和方差乘 $n$，置信区间双侧分位，长度两倍半宽算。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"正态样本和的概率"或"两置信区间共享端点"→ 联想"正态和 $N(n\mu,n\sigma^2)$ 标准化；左端点相等建方程反解 $\sigma$"
- **关联考点**：正态分布（第二章）、置信区间（第七章）、分位数与标准化
- **复用场景**：任何正态和的不超载/超限概率题，以及双样本置信区间端点比较的题目
:::

## 五、计算题（12 分）

### 第17题

:::callout{kind=note label="题目"}
设二维连续型随机向量 $(X, Y)$ 的联合密度函数为

$$p(x, y) = \left(x^2 + \frac{xy}{3}\right) I_{[0,1] \times [0,2]}(x, y)$$

求：

1. $P\{X + Y \geq 1\}$；
2. 边缘密度函数 $p_X(x), p_Y(y)$；
3. $X$ 与 $Y$ 是否独立，为什么？
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：本题三问。第 1 问算概率，入口是取补事件 $\{X+Y<1\}$（积分区域三角形更简单），用二重积分算后取补。第 2 问算边缘密度，对另一变量在支撑上积分。第 3 问判独立性，验证 $p(x,y)\stackrel{?}{=}p_X(x)p_Y(y)$。

**为何用此公式**：联合密度积分 $P((X,Y)\in D)=\iint_D p\,dx\,dy$ 是概率基本公式；边缘密度 $p_X(x)=\int p(x,y)\,dy$ 是定义；独立性判据 $p(x,y)=p_X(x)p_Y(y)$ 处处成立是连续型独立性的等价条件。取补事件 $P(A)=1-P(\bar{A})$ 选易于积分的一侧。

**推导过程**：

**第 1 问：$P\{X+Y\ge 1\}$**

1. 第一步：取补事件 ← 依据：$P(X+Y\ge 1)=1-P(X+Y<1)$，补事件积分区域 $\{0\le x\le 1,0\le y<1-x\}$ 为三角形
2. 第二步：写二重积分 ← 依据：联合密度积分
   $$P(X+Y<1)=\int_0^1\int_0^{1-x}\left(x^2+\frac{xy}{3}\right)dy\,dx$$
3. 第三步：算内层积分 ← 依据：对 $y$ 积分，$x$ 视为常数
   $$\int_0^{1-x}\left(x^2+\frac{xy}{3}\right)dy=x^2(1-x)+\frac{x(1-x)^2}{6}$$
4. 第四步：展开 ← 依据：代数展开
   $$=x^2-x^3+\frac{x-2x^2+x^3}{6}=\frac{x}{6}+\frac{2x^2}{3}-\frac{5x^3}{6}$$
5. 第五步：算外层积分 ← 依据：对 $x$ 在 $[0,1]$ 积分
   $$P(X+Y<1)=\int_0^1\left(\frac{x}{6}+\frac{2x^2}{3}-\frac{5x^3}{6}\right)dx=\frac{1}{12}+\frac{2}{9}-\frac{5}{24}$$
   $$=\frac{6+16-15}{72}=\frac{7}{72}$$
6. 第六步：取补 ← 依据：$P(A)=1-P(\bar A)$
   $$P(X+Y\ge 1)=1-\frac{7}{72}=\frac{65}{72}$$

**第 2 问：边缘密度**

7. 第七步：算 $p_X(x)$ ← 依据：$p_X(x)=\int_0^2 p(x,y)\,dy$，$0\le x\le 1$
   $$p_X(x)=\int_0^2\left(x^2+\frac{xy}{3}\right)dy=2x^2+\frac{2x}{3},\quad 0\le x\le 1$$
8. 第八步：算 $p_Y(y)$ ← 依据：$p_Y(y)=\int_0^1 p(x,y)\,dx$，$0\le y\le 2$
   $$p_Y(y)=\int_0^1\left(x^2+\frac{xy}{3}\right)dx=\frac{1}{3}+\frac{y}{6},\quad 0\le y\le 2$$
   （其余处为 $0$。）

**第 3 问：独立性**

9. 第九步：验证 $p_X(x)p_Y(y)$ ← 依据：独立性判据 $p(x,y)=p_X(x)p_Y(y)$ 处处成立
   $$p_X(x)\cdot p_Y(y)=\left(2x^2+\frac{2x}{3}\right)\left(\frac{1}{3}+\frac{y}{6}\right)$$
10. 第十步：比较 ← 依据：展开后含 $x^2y$、$xy^2$ 等项，与 $p(x,y)=x^2+\dfrac{xy}{3}$ 不相等
    故 $X$ 与 $Y$ 不独立。

**关键步骤说明**：

- 取补事件是简化：直接算 $\{X+Y\ge 1\}$ 需分块积分（区域非凸），取补后三角形区域积分一次完成。
- 边缘密度需标注支撑：$p_X(x)$ 仅在 $[0,1]$ 非零，$p_Y(y)$ 仅在 $[0,2]$ 非零，其余处为 $0$。
- 独立性判别只需找一个反例点：展开 $p_Xp_Y$ 含 $x^2y$ 项而 $p(x,y)$ 不含，故不处处相等，不独立。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **积分限出错**：把 $\{X+Y<1\}$ 的积分限误写为 $0\le y\le 1$ 而非 $0\le y<1-x$ → 正确做法：$y$ 上限受 $x+y<1$ 约束，为 $1-x$；$x$ 范围 $[0,1]$。
2. **边缘密度支撑遗漏**：忘记标注 $p_X(x)$ 在 $[0,1]$ 外为 $0$ → 正确做法：边缘密度必须分段写，支撑内为积分结果，支撑外为 $0$。
3. **独立性判别不充分**：只验证一两个点 $p(x,y)=p_Xp_Y$ 就宣布独立 → 正确做法：独立性要求处处成立，找一处不等即可否定；本题展开 $p_Xp_Y$ 含 $x^2y,xy^2$ 项与 $p$ 不符，故不独立。
:::

:::callout{kind=note label="知识卡片：联合密度与边缘密度"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 联合密度归一 | $\iint p(x,y)\,dx\,dy=1$ | 任意联合密度 |
| 边缘密度 | $p_X(x)=\int p(x,y)\,dy$，$p_Y(y)=\int p(x,y)\,dx$ | 联合密度已知 |
| 独立性判据 | $p(x,y)=p_X(x)\cdot p_Y(y)$ 处处成立 | 连续型独立性 |
| 概率计算 | $P((X,Y)\in D)=\iint_D p(x,y)\,dx\,dy$ | 联合密度已知 |
| 补事件 | $P(A)=1-P(\bar A)$，选易于积分的一侧 | 任意事件 |
| 示性函数支撑 | $I_{[a,b]\times[c,d]}$ 限制密度非零区域 | 矩形支撑 |

**概念辨析**：
- 边缘密度是"对另一变量积分"，所得仍是密度函数（非负且积分为 1）；独立性要求联合密度能"分解"为两个边缘密度之积。
- 取补事件简化积分：当事件区域复杂而补区域简单（如三角形）时，先算补再取补。
- 独立性判别只需一处反例：连续型独立性要求处处相等，找一个 $x,y$ 使 $p\ne p_Xp_Y$ 即可否定。
:::

:::callout{kind=tip label="结论速记"}
边缘密度 = 对另一变量积分；独立性 = 联合密度能否分解为两个边缘密度之积。

**口诀**：概率取补选易积，边缘积分标支撑，独立分解处处验。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"联合密度 + 求概率/边缘/独立性"→ 联想"概率取补选易积区域，边缘对另一变量积分标支撑，独立验证 $p=p_Xp_Y$ 处处成立"
- **关联考点**：二维连续型分布（第三章）、边缘分布与独立性、二重积分计算
- **复用场景**：任何联合密度的三件套题目（概率 + 边缘 + 独立性），以及条件密度、卷积公式的预备知识
:::

## 六、计算题（12 分）

### 第18题

:::callout{kind=note label="题目"}
设二维随机向量 $(X, Y)$ 的联合密度函数为

$$p(x, y) = (2 - x - y) I_{[0,1] \times [0,1]}(x, y)$$

求：

1. $Z = X + Y$ 的密度函数；
2. $\operatorname{Cov}(X, Y)$。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：本题两问。第 1 问求和的密度，入口是套卷积公式 $p_Z(z)=\int p(x,z-x)\,dx$，由被积函数非零条件反解 $x$ 范围，按 $z$ 跨越支撑边界分段。第 2 问求协方差，由对称性 $E(X)=E(Y)$，分别算 $E(X),E(XY)$ 后代入 $\operatorname{Cov}=E(XY)-E(X)E(Y)$。

**为何用此公式**：卷积公式 $p_Z(z)=\int p(x,z-x)\,dx$ 是连续型和密度的标准工具；分段卷积适用于 $z$ 跨越支撑边界的情形。协方差定义 $\operatorname{Cov}(X,Y)=E(XY)-E(X)E(Y)$ 是基本公式；对称性 $p(x,y)$ 关于 $x,y$ 对称时 $E(X)=E(Y)$，简化计算。

**推导过程**：

**第 1 问：$Z=X+Y$ 的密度**

1. 第一步：套卷积公式 ← 依据：$p_Z(z)=\int_{-\infty}^{+\infty}p(x,z-x)\,dx$
   $$p_Z(z)=\int p(x,z-x)\,dx$$
2. 第二步：定被积函数非零条件 ← 依据：$p(x,z-x)=(2-x-(z-x))I=(2-z)I$，非零要求 $0\le x\le 1$ 且 $0\le z-x\le 1$
   - 被积函数化为 $2-z$（与 $x$ 无关）
   - $x$ 范围：$\max(0,z-1)\le x\le\min(1,z)$
3. 第三步：分段积分 ← 依据：$z$ 跨越支撑边界 $0,1,2$ 分段
   - 当 $0<z<1$ 时：$0\le x\le z$
     $$p_Z(z)=\int_0^z(2-z)\,dx=z(2-z)=2z-z^2$$
   - 当 $1\le z<2$ 时：$z-1\le x\le 1$
     $$p_Z(z)=\int_{z-1}^1(2-z)\,dx=(2-z)(2-z)=(2-z)^2$$
4. 第四步：综合写分段密度 ← 依据：支撑外为 0
   $$p_Z(z)=\begin{cases}2z-z^2,&0<z<1\\(2-z)^2,&1\le z<2\\0,&\text{其它}\end{cases}$$

**第 2 问：$\operatorname{Cov}(X, Y)$**

5. 第一步：用对称性 ← 依据：$p(x,y)=2-x-y$ 关于 $x,y$ 对称，故 $E(X)=E(Y)$
6. 第二步：算 $E(X)$ ← 依据：$E(X)=\iint x\,p(x,y)\,dy\,dx$，先对 $y$ 积分
   $$E(X)=\int_0^1\int_0^1 x(2-x-y)\,dy\,dx=\int_0^1 x\left(\frac{3}{2}-x\right)dx=\frac{3}{4}-\frac{1}{3}=\frac{5}{12}$$
7. 第三步：算 $E(XY)$ ← 依据：$E(XY)=\iint xy\,p(x,y)\,dy\,dx$
   $$E(XY)=\int_0^1\int_0^1 xy(2-x-y)\,dy\,dx=\int_0^1 x\left(\frac{2}{3}-\frac{x}{2}\right)dx=\frac{1}{3}-\frac{1}{6}=\frac{1}{6}$$
8. 第四步：算协方差 ← 依据：$\operatorname{Cov}(X,Y)=E(XY)-E(X)E(Y)$，$E(X)=E(Y)=\dfrac{5}{12}$
   $$\operatorname{Cov}(X,Y)=\frac{1}{6}-\left(\frac{5}{12}\right)^2=\frac{24}{144}-\frac{25}{144}=-\frac{1}{144}$$

**关键步骤说明**：

- 卷积被积函数化简：$p(x,z-x)=2-x-(z-x)=2-z$，与 $x$ 无关，只需算 $x$ 的积分长度。
- 分段是关键：$z$ 在 $[0,1]$ 与 $[1,2]$ 内 $x$ 范围不同，需分段处理。
- 对称性简化：由 $p$ 对称得 $E(X)=E(Y)$，只需算一个期望，节省一半计算量。
- 负协方差符合直觉：$p(x,y)=2-x-y$ 在 $x,y$ 大时密度小，提示 $X,Y$ 负相关。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **卷积被积函数未化简**：把 $p(x,z-x)=2-x-(z-x)$ 误算为含 $x$ 项 → 正确做法：$-x- (z-x)=-z$ 与 $x$ 无关，被积函数化为 $2-z$，只需算 $x$ 长度。
2. **卷积分段边界出错**：把分段点误取为 $z=1$ 之外的其他值 → 正确做法：支撑 $[0,1]\times[0,1]$ 决定 $z=X+Y\in[0,2]$，分段点在 $z=1$（支撑对角线）。
3. **对称性使用不当**：未识别 $p(x,y)=2-x-y$ 关于 $x,y$ 对称而重复算 $E(Y)$ → 正确做法：对称性 $E(X)=E(Y)$ 只需算一个期望，节省一半计算量；但协方差仍需算 $E(XY)$。
:::

:::callout{kind=note label="知识卡片：卷积公式与协方差计算"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 和的密度（卷积） | $p_Z(z)=\int_{-\infty}^{+\infty}p(x,z-x)\,dx$ | 连续型随机变量 |
| 积分限确定 | 由 $p(x,z-x)>0$ 反解 $x$ 范围 | 联合密度已知 |
| 分段卷积 | $z$ 跨越支撑边界时分段处理 | 矩形支撑 |
| 协方差 | $\operatorname{Cov}(X,Y)=E(XY)-E(X)E(Y)$ | 二阶矩存在 |
| 对称区域 | $p(x,y)$ 关于 $x,y$ 对称 $\Rightarrow E(X)=E(Y)$ | 联合密度对称 |
| 负相关判别 | $\operatorname{Cov}<0$ 表示负相关 | 协方差符号 |

**概念辨析**：
- 卷积公式中 $p(x,z-x)$ 的非零条件由"原支撑 + $z-x$ 落在 $Y$ 支撑"共同决定，需反解 $x$ 范围；当 $z$ 跨越支撑对角线时积分限表达式变化，需分段。
- 对称性 $E(X)=E(Y)$ 要求联合密度关于 $x,y$ 对换不变；本题 $p(x,y)=2-x-y$ 满足，但协方差需单独算 $E(XY)$，不能由对称性直接得出。
:::

:::callout{kind=tip label="结论速记"}
卷积分段：$0<z<1$ 时 $2z-z^2$，$1\le z<2$ 时 $(2-z)^2$；协方差 $=E(XY)-[E(X)]^2$。

**口诀**：卷积被积先化简，支撑对角分段点，对称只省一期望，协差仍需算积。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"和的密度"或"$Z=X+Y$"→ 联想"卷积公式 $p_Z(z)=\int p(x,z-x)\,dx$，被积函数化简后分段积分"
- **关联考点**：卷积公式（第三章）、协方差（第四章）、对称性在矩计算中的应用
- **复用场景**：任何求两随机变量和的密度题，以及对称联合密度的协方差计算
:::

## 七、计算题（12 分）

### 第19题

:::callout{kind=note label="题目"}
设总体 $(X, Y)$ 服从区域 $D = \{(x, y) : 0 \leq x, y \leq \theta\}$ 上的均匀分布，其中 $\theta > 0$ 为未知参数，$(X_1, Y_1), (X_2, Y_2), \cdots, (X_n, Y_n)$ 是来自总体 $(X, Y)$ 的 i.i.d. 样本。

1. 根据 $X_1, X_2, \cdots, X_n$ 求参数 $\theta$ 的矩估计量 $\hat{\theta}_M$；
2. 根据 $(X_1, Y_1), \cdots, (X_n, Y_n)$ 求参数 $\theta$ 的极大似然估计量 $\hat{\theta}_L$；
3. 讨论 $\hat{\theta}_M$ 与 $\hat{\theta}_L$ 是否为 $\theta$ 的无偏估计。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：本题三问，覆盖矩估计、MLE、无偏性三大核心方法。第 1 问矩估计，入口是用 $X\sim U(0,\theta)$ 的均值 $E(X)=\dfrac{\theta}{2}$ 建矩方程 $\bar{X}=\dfrac{\theta}{2}$ 反解。第 2 问 MLE，入口是写联合似然函数 $L(\theta)=\theta^{-2n}I\{\theta\ge\max\{X_i,Y_i\}\}$，由 $\theta^{-2n}$ 单调递减取最小允许值。第 3 问无偏性，分别算 $E(\hat{\theta}_M)$ 与 $E(\hat{\theta}_L)$；MLE 需用最大值密度 $f_{(2n)}(t)=2n\dfrac{t^{2n-1}}{\theta^{2n}}$ 算期望。

**为何用此公式**：矩估计原理"令样本矩 = 总体矩"适用于有显式矩表达式的分布；MLE 原理"最大化似然函数"适用于支撑依赖参数的均匀分布（取最小允许值）；无偏性定义 $E(\hat\theta)=\theta$ 需算估计量的期望，最大值密度 $f_{(m)}(t)=m\dfrac{t^{m-1}}{\theta^m}$ 是 $U(0,\theta)$ 顺序统计量的标准工具。

**推导过程**：

**第 1 问：矩估计**

1. 第一步：识别 $X$ 的边缘分布 ← 依据：$(X,Y)$ 在 $[0,\theta]\times[0,\theta]$ 均匀，边缘 $X\sim U(0,\theta)$
   $$f_X(x)=\int_0^\theta\frac{1}{\theta^2}dy=\frac{1}{\theta},\quad 0\le x\le\theta$$
2. 第二步：算总体矩 ← 依据：$U(0,\theta)$ 的均值 $E(X)=\dfrac{\theta}{2}$
3. 第三步：建矩方程 ← 依据：矩估计原理"样本矩 = 总体矩"
   $$\bar{X}=\frac{\theta}{2}$$
4. 第四步：反解 $\theta$ ← 依据：一元方程求解
   $$\hat{\theta}_M=2\bar{X}=\frac{2}{n}\sum_{i=1}^n X_i$$

**第 2 问：极大似然估计**

5. 第一步：写联合密度 ← 依据：$(X,Y)$ 在 $D$ 上均匀，密度 $\dfrac{1}{\theta^2}I_{\{0\le x,y\le\theta\}}$
   $$f(x,y)=\frac{1}{\theta^2}I_{\{0\le x,y\le\theta\}}$$
6. 第二步：写样本联合似然函数 ← 依据：i.i.d. 样本似然 = 各密度之积
   $$L(\theta)=\prod_{i=1}^n\frac{1}{\theta^2}I_{\{0\le X_i,Y_i\le\theta\}}=\theta^{-2n}I\!\left\{\theta\ge\max_{1\le i\le n}\{X_i,Y_i\}\right\}$$
7. 第三步：分析似然函数单调性 ← 依据：$\theta^{-2n}$ 关于 $\theta$ 单调递减（$\theta>0$）
   - 在允许范围 $\theta\ge\max\{X_i,Y_i\}$ 内，$\theta$ 越小 $L$ 越大
8. 第四步：取最小允许值 ← 依据：MLE = 似然函数最大点
   $$\hat{\theta}_L=\max_{1\le i\le n}\{X_i,Y_i\}$$

**第 3 问：无偏性讨论**

9. 第一步：算 $\hat{\theta}_M$ 的期望 ← 依据：$E(\bar{X})=E(X)=\dfrac{\theta}{2}$（样本均值期望 = 总体均值）
   $$E(\hat{\theta}_M)=2E(\bar{X})=2\cdot\frac{\theta}{2}=\theta$$
   故 $\hat{\theta}_M$ 是 $\theta$ 的无偏估计。
10. 第二步：识别 $\hat{\theta}_L$ 的分布 ← 依据：$2n$ 个观测 $X_1,Y_1,\cdots,X_n,Y_n$ 视作来自 $U(0,\theta)$ 的 i.i.d. 样本，$\hat{\theta}_L$ 即 $2n$ 个样本的最大值 $X_{(2n)}$
11. 第三步：写最大值密度 ← 依据：$U(0,\theta)$ 最大值密度 $f_{(m)}(t)=m\dfrac{t^{m-1}}{\theta^m}$，$0\le t\le\theta$，本题 $m=2n$
    $$f_{(2n)}(t)=2n\cdot\frac{t^{2n-1}}{\theta^{2n}},\quad 0\le t\le\theta$$
12. 第四步：算 $E(\hat{\theta}_L)$ ← 依据：$E(X_{(2n)})=\int_0^\theta t\cdot f_{(2n)}(t)\,dt$
    $$E(\hat{\theta}_L)=\int_0^\theta t\cdot\frac{2n\,t^{2n-1}}{\theta^{2n}}dt=\frac{2n}{\theta^{2n}}\int_0^\theta t^{2n}\,dt=\frac{2n}{\theta^{2n}}\cdot\frac{\theta^{2n+1}}{2n+1}=\frac{2n}{2n+1}\theta$$
13. 第五步：判无偏性 ← 依据：$E(\hat{\theta}_L)=\dfrac{2n}{2n+1}\theta\ne\theta$（当 $n\ge 1$）
    故 $\hat{\theta}_L$ 是有偏估计（偏低，偏差 $-\dfrac{\theta}{2n+1}$）。

**关键步骤说明**：

- 矩估计仅用 $X_1,\cdots,X_n$（不用 $Y_i$）：题干明确"根据 $X_1,\cdots,X_n$"，故只用 $n$ 个 $X$ 样本，矩方程 $\bar{X}=\dfrac{\theta}{2}$。
- MLE 用全部 $2n$ 个观测：题干明确"根据 $(X_1,Y_1),\cdots,(X_n,Y_n)$"，似然函数含 $2n$ 个样本，$\theta^{-2n}$ 与最大值 $\max\{X_i,Y_i\}$。
- 无偏性关键在最大值期望：$U(0,\theta)$ 最大值期望 $=\dfrac{m}{m+1}\theta$（$m$ 个样本），本题 $m=2n$ 得 $\dfrac{2n}{2n+1}\theta$，系统偏低。
- 修正无偏化：$\dfrac{2n+1}{2n}\hat{\theta}_L$ 为无偏估计（虽然题目未要求，但可作延伸）。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **矩估计与 MLE 样本数混淆**：矩估计误用 $2n$ 个样本（含 $Y_i$） → 正确做法：矩估计题干明确"根据 $X_1,\cdots,X_n$"，仅用 $n$ 个 $X$ 样本；MLE 题干明确"根据 $(X_i,Y_i)$"，用 $2n$ 个样本。
2. **MLE 最大化方向搞反**：误以为 $\theta^{-2n}$ 递增而取 $\theta\to+\infty$ → 正确做法：$\theta^{-2n}$ 关于 $\theta$ 递减，取最小允许值 $\theta=\max\{X_i,Y_i\}$；均匀分布 MLE 一律取支撑边界。
3. **最大值密度公式记错**：误用 $f_{(m)}(t)=m\dfrac{t^{m-1}}{\theta^{m-1}}$ → 正确做法：$U(0,\theta)$ 最大值密度 $f_{(m)}(t)=m\dfrac{t^{m-1}}{\theta^m}$，分母 $\theta^m$（非 $m-1$ 次方）。
4. **无偏性期望算错**：把 $E(\hat{\theta}_L)$ 误算为 $\dfrac{2n-1}{2n}\theta$ → 正确做法：$\int_0^\theta t^{2n}dt=\dfrac{\theta^{2n+1}}{2n+1}$，乘 $\dfrac{2n}{\theta^{2n}}$ 得 $\dfrac{2n}{2n+1}\theta$。
:::

:::callout{kind=note label="知识卡片：矩估计与极大似然估计"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 矩估计原理 | 令样本矩 = 总体矩，反解参数 | 总体矩存在 |
| MLE 原理 | 最大化似然函数 $L(\theta)$ | 似然函数可写 |
| 均匀分布 MLE | $\hat{\theta}=X_{(n)}$（最大值） | $U(0,\theta)$ i.i.d. 样本 |
| 无偏性 | $E(\hat{\theta})=\theta$ | 估计量期望可算 |
| $U(0,\theta)$ 最大值期望 | $E(X_{(m)})=\dfrac{m}{m+1}\theta$ | $m$ 个 i.i.d. 样本 |
| 修正无偏化 | $\dfrac{m+1}{m}X_{(m)}$ 无偏 | 同上 |
| MLE 不变性 | $\hat{g(\theta)}=g(\hat{\theta})$ | $g$ 连续 |

**概念辨析**：
- 矩估计与 MLE 是两种不同估计方法，结果可能不同：本题矩估计 $\hat{\theta}_M=2\bar{X}$ 用 $n$ 个样本，MLE $\hat{\theta}_L=\max\{X_i,Y_i\}$ 用 $2n$ 个样本，因题干指定样本不同。
- $U(0,\theta)$ 的最大值估计 $X_{(m)}$ 系统偏低（期望 $\dfrac{m}{m+1}\theta<\theta$），需乘 $\dfrac{m+1}{m}$ 修正为无偏；这是均匀分布 MLE 的固有偏差。
- 矩估计 $\hat{\theta}_M=2\bar{X}$ 无偏因 $E(\bar{X})=\dfrac{\theta}{2}$ 线性传递；但方差通常比 MLE 大（效率低）。
:::

:::callout{kind=tip label="结论速记"}
均匀分布 $U(0,\theta)$：矩估计 $\hat{\theta}_M=2\bar{X}$ 无偏；MLE $\hat{\theta}_L=X_{(n)}$ 有偏，期望 $=\dfrac{n}{n+1}\theta$。

**口诀**：矩估均值倍二，MLE 取最大，最大值期望 $m$ 比 $m+1$，有偏偏低需修正。
:::
