## 一、单项选择题（每题 3 分，共 21 分）

### 第1题

:::callout{kind=note label="题目"}
设随机变量 $X \sim N(0, 1)$，则 $P(X^2 \leq 1) = $（　　）

A. $2\Phi(1)-1$　　B. $1-\Phi(1)$　　C. $\Phi(1)$　　D. $2[1-\Phi(1)]$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：看到 $X^2 \leq 1$ 形式的不等式 → 联想平方不等式等价转化为 $|X| \leq 1$ 即 $-1 \leq X \leq 1$ → 识别为标准正态双侧区间概率 → 利用对称性化简。

**为何用此公式**：标准正态分布关于原点对称，具有性质 $\Phi(-x) = 1 - \Phi(x)$，可将双侧区间概率统一为单侧 $\Phi$ 函数表达，避免查表与重复计算。

**推导过程**：

1. 第一步：$X^2 \leq 1 \iff -1 \leq X \leq 1$ ← 依据：平方不等式开方取绝对值等价转化
2. 第二步：$P(-1 \leq X \leq 1) = \Phi(1) - \Phi(-1)$ ← 依据：分布函数区间概率公式 $P(a \leq X \leq b) = F(b) - F(a)$
3. 第三步：$\Phi(-1) = 1 - \Phi(1)$ ← 依据：标准正态对称性
4. 第四步：$\Phi(1) - [1 - \Phi(1)] = 2\Phi(1) - 1$ ← 依据：代数化简

**选项分析**：

- **A（正确）**：$2\Phi(1) - 1$ 是双侧区间 $[-1, 1]$ 的标准正态概率，由对称性化简得到。
- **B（错误）**：$1 - \Phi(1) = P(X > 1)$，对应单侧右尾概率，漏算左尾 $P(X < -1)$。
- **C（错误）**：$\Phi(1) = P(X \leq 1)$，缺少 $X \geq -1$ 的下界限制，仅算半边。
- **D（错误）**：$2[1 - \Phi(1)] = P(|X| > 1)$，计算的是对立事件（双侧尾部之和），与所求互补。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **平方不等式直接套分布函数**：直接写 $P(X^2 \leq 1) = \Phi(1)$ 漏掉对称性 → 正确做法：先等价转化为 $-1 \leq X \leq 1$，再用区间概率公式 $F(b) - F(a)$。
2. **混淆区间概率与尾部概率**：将 $P(|X| \leq a)$ 与 $P(|X| > a)$ 混用 → 正确做法：$P(|X| \leq a) = 2\Phi(a) - 1$，$P(|X| > a) = 2[1 - \Phi(a)]$，二者之和为 1。
3. **遗漏对称性化简**：保留 $\Phi(-1)$ 不化简导致无法匹配选项 → 正确做法：标准正态必用 $\Phi(-x) = 1 - \Phi(x)$ 统一为 $\Phi(x)$ 形式。
:::

:::callout{kind=note label="知识卡片：标准正态分布的性质"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 对称性 | $\Phi(-x) = 1 - \Phi(x)$ | 标准正态 $N(0,1)$ |
| 标准化 | $Z = \dfrac{X - \mu}{\sigma} \sim N(0,1)$ | 任意正态分布 |
| 双侧区间概率 | $P(\|Z\| \leq a) = 2\Phi(a) - 1$ | $a > 0$ |
| 双侧尾部概率 | $P(\|Z\| > a) = 2[1 - \Phi(a)]$ | $a > 0$ |
| 分布函数定义 | $\Phi(x) = \dfrac{1}{\sqrt{2\pi}} \displaystyle\int_{-\infty}^{x} e^{-t^2/2}\, dt$ | 标准正态 |

**概念辨析**：
- $P(|X| \leq a)$ 与 $P(|X| > a)$ 互为对立事件，概率之和为 1，不可混用。
- 区间概率公式 $P(a \leq X \leq b) = F(b) - F(a)$ 对任意连续型分布成立，但化简为 $2\Phi(a) - 1$ 仅限关于原点对称的标准正态。
:::

:::callout{kind=tip label="结论速记"}
$X^2 \leq a^2 \iff -a \leq X \leq a$，标准正态双侧概率 $P(|X| \leq a) = 2\Phi(a) - 1$。

**口诀**：平方开方取绝对，对称区间 $2\Phi(a) - 1$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到 $X^2 \leq a^2$ 或 $|X| \leq a$ → 联想标准正态对称性 + 区间概率公式
- **关联考点**：与卡方分布 $\chi^2(1) = Z^2$ 关联，$P(X^2 \leq 1) = P(\chi^2(1) \leq 1)$ 可用卡方分布函数验证
- **复用场景**：所有涉及标准正态双侧概率、Z 检验置信区间的题目
:::

### 第2题

:::callout{kind=note label="题目"}
若 $P(A) = 0.7$，$P(B) = 0.6$，$P(A \cup B) = 0.9$，则 $P(A \mid B) = $（　　）

A. $\dfrac{1}{2}$　　B. $\dfrac{1}{3}$　　C. $\dfrac{2}{3}$　　D. $\dfrac{2}{5}$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：已知 $P(A)$、$P(B)$、$P(A \cup B)$ 三个量求条件概率 $P(A \mid B)$ → 条件概率定义 $P(A \mid B) = P(AB)/P(B)$ 需先求 $P(AB)$ → 用加法公式反解交事件概率。

**为何用此公式**：条件概率定义 $P(A \mid B) = P(AB)/P(B)$ 中分母 $P(B)$ 已知，缺 $P(AB)$；而加法公式 $P(A \cup B) = P(A) + P(B) - P(AB)$ 提供了由已知三量反解 $P(AB)$ 的唯一途径。

**推导过程**：

1. 第一步：由加法公式反解 $P(AB) = P(A) + P(B) - P(A \cup B) = 0.7 + 0.6 - 0.9 = 0.4$ ← 依据：概率加法公式变形
2. 第二步：代入条件概率定义 $P(A \mid B) = \dfrac{P(AB)}{P(B)} = \dfrac{0.4}{0.6} = \dfrac{2}{3}$ ← 依据：条件概率定义，分母为条件事件 $B$ 的概率

> 注：原试卷标准答案标注为 D，但严格计算结果 $2/3$ 对应选项 C，此处以严格推导为准。

**选项分析**：

- **A（错误）**：$\dfrac{1}{2}$ 无任何公式依据，属于纯凑数干扰项。
- **B（错误）**：$\dfrac{1}{3}$ 由误用 $P(A \cup B) = 0.9$ 或 $P(\bar{A}) = 0.3$ 作分母得到。
- **C（正确）**：$\dfrac{2}{3}$ 是加法公式反解 $P(AB)$ 后代入条件概率定义的严格结果。
- **D（错误）**：$\dfrac{2}{5}$ 由 $P(AB)/P(A) = 0.4/0.7$ 误算，混淆了 $P(A \mid B)$ 与 $P(B \mid A)$ 的分母。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **混淆 $P(A \mid B)$ 与 $P(B \mid A)$**：分母错用 $P(A)$ 得 $0.4/0.7 = 2/5$ → 正确做法：$P(A \mid B)$ 的分母必为条件事件 $B$ 的概率 $P(B)$。
2. **不会反求 $P(AB)$**：直接套条件概率公式却缺 $P(AB)$ 而卡住 → 正确做法：当已知 $P(A \cup B)$ 时用加法公式反解 $P(AB) = P(A) + P(B) - P(A \cup B)$。
3. **盲目相信标答**：原卷标答 D 与计算结果不符 → 正确做法：以严格推导为准，标答存在印刷错误可能。
:::

:::callout{kind=note label="知识卡片：条件概率与加法公式"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 加法公式 | $P(A \cup B) = P(A) + P(B) - P(AB)$ | 任意两事件 |
| 条件概率 | $P(A \mid B) = \dfrac{P(AB)}{P(B)}$ | $P(B) > 0$ |
| 乘法公式 | $P(AB) = P(B) \cdot P(A \mid B)$ | $P(B) > 0$ |
| 独立性判定 | $P(AB) = P(A) \cdot P(B)$ | 独立事件 |
| 对立事件 | $P(\bar{A}) = 1 - P(A)$ | 任意事件 |

**概念辨析**：
- $P(A \mid B)$ 与 $P(B \mid A)$ 是不同量，分母分别为 $P(B)$ 与 $P(A)$，二者由贝叶斯公式 $P(A \mid B) = \dfrac{P(B \mid A)P(A)}{P(B)}$ 连接。
- 加法公式对任意两事件成立，不需要独立性；独立时 $P(AB) = P(A)P(B)$ 可简化。
:::

:::callout{kind=tip label="结论速记"}
先由加法公式求 $P(AB) = P(A) + P(B) - P(A \cup B)$，再代入 $P(A \mid B) = P(AB)/P(B)$。

**口诀**：先加法求交，再条件概率定分母。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：已知 $P(A)$、$P(B)$、$P(A \cup B)$ 求条件概率 → 联想加法公式反求交事件
- **关联考点**：与贝叶斯公式、全概率公式构成"事件概率三件套"
- **复用场景**：所有给出并集概率反求交集或条件概率的题目
:::

### 第3题

:::callout{kind=note label="题目"}
设 $X$ 的概率密度为 $f(x) = 2x$，$0 < x < 1$，则 $P\!\left(X > \dfrac{1}{2}\right) = $（　　）

A. $\dfrac{3}{4}$　　B. $\dfrac{1}{2}$　　C. $\dfrac{1}{4}$　　D. $\dfrac{1}{8}$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：已知连续型随机变量的密度函数求区间概率 → 对密度函数在对应区间积分 → 注意积分上下限由支撑域与所求事件共同决定。

**为何用此公式**：连续型随机变量概率的唯一定义为 $P(a < X < b) = \int_a^b f(x)\, dx$，本题已知密度 $f(x) = 2x$ 与支撑域 $(0, 1)$，直接积分即可，无需先求分布函数。

**推导过程**：

1. 第一步：确定 $X > 1/2$ 对应积分区间 $(1/2, 1)$（因支撑域为 $(0, 1)$，超出部分密度为 0）← 依据：密度支撑域
2. 第二步：$P(X > 1/2) = \int_{1/2}^{1} 2x\, dx$ ← 依据：连续型概率积分定义
3. 第三步：求原函数 $\int 2x\, dx = x^2$，代入得 $\left[x^2\right]_{1/2}^{1} = 1 - \dfrac{1}{4} = \dfrac{3}{4}$ ← 依据：牛顿-莱布尼茨公式

**选项分析**：

- **A（正确）**：$\dfrac{3}{4}$ 是 $(1/2, 1)$ 上密度 $2x$ 的积分结果。
- **B（错误）**：$\dfrac{1}{2}$ 无计算依据，属于干扰项。
- **C（错误）**：$\dfrac{1}{4} = \int_0^{1/2} 2x\, dx = P(X < 1/2)$，计算的是对立事件。
- **D（错误）**：$\dfrac{1}{8}$ 由 $f(1/2) \cdot \dfrac{1}{2} \cdot \dfrac{1}{2} = 1 \cdot \dfrac{1}{4}$ 类型的"三角形面积"误算得到。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **积分区间错误**：忽略支撑域 $(0, 1)$，对 $(1/2, +\infty)$ 积分导致错误 → 正确做法：积分上限取支撑域上界 1，超出部分密度为 0。
2. **求对立事件而不自知**：算出 $1/4$ 误选 C → 正确做法：注意 $X > 1/2$ 与 $X < 1/2$ 互补，$P(X > 1/2) = 1 - P(X < 1/2) = 1 - 1/4 = 3/4$。
3. **用密度函数值代替积分**：直接取 $f(1/2) = 1$ 作答 → 正确做法：连续型概率是密度的积分，不是密度函数值。
:::

:::callout{kind=note label="知识卡片：连续型随机变量概率计算"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 区间概率 | $P(a < X < b) = \displaystyle\int_a^b f(x)\, dx$ | 连续型随机变量 |
| 密度归一性 | $\displaystyle\int_{-\infty}^{+\infty} f(x)\, dx = 1$ | 任意密度函数 |
| 对立事件 | $P(X > a) = 1 - P(X \leq a)$ | 任意随机变量 |
| 分布函数 | $F(x) = \displaystyle\int_{-\infty}^{x} f(t)\, dt$ | 连续型随机变量 |
| 密度非负性 | $f(x) \geq 0$ | 任意密度函数 |

**概念辨析**：
- 密度函数值 $f(x_0)$ 不是概率，概率必须积分；但 $f(x_0)$ 可大于 1（如本题 $f(1) = 2$）。
- $P(X = a) = 0$ 对连续型成立，故 $P(X > a) = P(X \geq a)$，开闭区间等价。
:::

:::callout{kind=tip label="结论速记"}
连续型求概率即密度积分：$P(a < X < b) = \int_a^b f(x)\, dx$。

**口诀**：密度积分得概率，区间端点看支撑。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：已知密度 $f(x)$ 求区间概率 → 联想直接积分
- **关联考点**：与分布函数 $F(x) = \int f$ 求导互逆；与离散型求和对比
- **复用场景**：所有连续型分布（均匀、指数、正态等）的区间概率计算
:::

### 第4题

:::callout{kind=note label="题目"}
若 $X, Y$ 独立且 $X \sim P(\lambda_1)$，$Y \sim P(\lambda_2)$，则 $X + Y$ 服从（　　）

A. $P(\lambda_1 \lambda_2)$　　B. $P(\lambda_1 - \lambda_2)$　　C. $P(\lambda_1 + \lambda_2)$　　D. $P(\lambda_1 / \lambda_2)$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：看到"独立泊松之和" → 联想泊松分布可加性 → 参数相加。可用矩母函数严格证明。

**为何用此公式**：泊松分布具有可加性，独立泊松之和仍为泊松分布，参数相加。矩母函数法是证明可加性的通用工具：独立随机变量和的矩母函数等于各分量矩母函数之积，再由唯一性定理识别分布。

**推导过程**：

1. 第一步：写出 $X$、$Y$ 的矩母函数 $M_X(t) = e^{\lambda_1(e^t - 1)}$，$M_Y(t) = e^{\lambda_2(e^t - 1)}$ ← 依据：泊松分布的矩母函数
2. 第二步：由独立性 $M_{X+Y}(t) = M_X(t) \cdot M_Y(t) = e^{\lambda_1(e^t - 1)} \cdot e^{\lambda_2(e^t - 1)}$ ← 依据：独立随机变量矩母函数可乘
3. 第三步：合并指数 $M_{X+Y}(t) = e^{(\lambda_1 + \lambda_2)(e^t - 1)}$ ← 依据：指数运算性质 $e^a \cdot e^b = e^{a+b}$
4. 第四步：识别为参数 $\lambda_1 + \lambda_2$ 的泊松分布矩母函数 → $X + Y \sim P(\lambda_1 + \lambda_2)$ ← 依据：矩母函数唯一性定理

**选项分析**：

- **A（错误）**：$P(\lambda_1 \lambda_2)$ 参数相乘无概率意义，矩母函数无此形式。
- **B（错误）**：$P(\lambda_1 - \lambda_2)$ 参数相减可能为负，泊松参数必须为正。
- **C（正确）**：$P(\lambda_1 + \lambda_2)$ 是泊松可加性的标准结论，由矩母函数严格证明。
- **D（错误）**：$P(\lambda_1 / \lambda_2)$ 参数相除无理论依据。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **参数运算错记**：误记为参数相乘或相除 → 正确做法：独立泊松和参数相加；独立泊松差（当 $\lambda_1 > \lambda_2$）需用卷积，不再为泊松。
2. **忽视独立性条件**：不独立时直接套可加性 → 正确做法：可加性要求独立，不独立时需用卷积公式或全概率分解。
3. **与二项可加性条件混淆**：以为泊松可加性也需参数相同 → 正确做法：泊松可加性仅需独立（参数 $\lambda$ 可不同），二项可加性才需独立且参数 $p$ 相同。
:::

:::callout{kind=note label="知识卡片：常见分布的可加性"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 泊松可加性 | $X + Y \sim P(\lambda_1 + \lambda_2)$ | 独立即可 |
| 二项可加性 | $X + Y \sim B(n_1 + n_2, p)$ | 独立且参数 $p$ 相同 |
| 正态可加性 | $X + Y \sim N(\mu_1 + \mu_2, \sigma_1^2 + \sigma_2^2)$ | 独立即可 |
| 指数可加性 | $X + Y \sim \Gamma(2, \lambda)$ | 独立且参数 $\lambda$ 相同 |
| 卡方可加性 | $X + Y \sim \chi^2(n_1 + n_2)$ | 独立即可 |

**概念辨析**：
- 泊松可加性只需"独立"，参数 $\lambda_1$、$\lambda_2$ 可不同；二项可加性需"独立 + 参数 $p$ 相同"。
- 矩母函数法是证明可加性的通用工具：$M_{X+Y} = M_X \cdot M_Y$ 后由唯一性识别分布。
:::

:::callout{kind=tip label="结论速记"}
独立泊松和仍泊松，参数相加：$P(\lambda_1) + P(\lambda_2) \to P(\lambda_1 + \lambda_2)$。

**口诀**：独立泊松和仍泊松，参数相加不用愁。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"独立泊松之和" → 联想可加性 + 矩母函数证明
- **关联考点**：与二项、正态、卡方、Gamma 的可加性条件对比记忆
- **复用场景**：所有独立同/异参数分布求和的分布识别题
:::

### 第5题

:::callout{kind=note label="题目"}
设 $X \sim U(0, 2)$，则 $D(X) = $（　　）

A. $\dfrac{1}{2}$　　B. $\dfrac{2}{3}$　　C. $\dfrac{1}{4}$　　D. $\dfrac{1}{3}$
:::

:::callout{kind=insight label="解析"}
**【答案】D**

**思路**：看到 $X \sim U(0, 2)$ 求方差 → 识别为均匀分布 → 套用均匀分布专用方差公式 $D = (b-a)^2/12$。

**为何用此公式**：均匀分布 $U(a, b)$ 有专用方差公式 $D(X) = (b-a)^2/12$，比用定义 $D(X) = E(X^2) - [E(X)]^2$ 重新积分计算更便捷，且不易出错。

**推导过程**：

1. 第一步：识别 $X \sim U(0, 2)$，即 $a = 0$，$b = 2$ ← 依据：均匀分布参数识别
2. 第二步：套用均匀分布方差公式 $D(X) = \dfrac{(b-a)^2}{12}$ ← 依据：均匀分布方差公式
3. 第三步：代入 $a = 0$，$b = 2$：$D(X) = \dfrac{(2-0)^2}{12} = \dfrac{4}{12} = \dfrac{1}{3}$ ← 依据：代数化简

**选项分析**：

- **A（错误）**：$\dfrac{1}{2}$ 由误用公式 $D = (b-a)/4 = (2-0)/4 = 1/2$ 得到，分母与结构均错。
- **B（错误）**：$\dfrac{2}{3}$ 由误用公式 $D = b^2/6 = 4/6 = 2/3$ 得到，公式错误。
- **C（错误）**：$\dfrac{1}{4}$ 由误用公式 $D = (b-a)^2/16 = 4/16 = 1/4$ 得到，分母错误。
- **D（正确）**：$\dfrac{1}{3}$ 是 $(b-a)^2/12$ 的正确计算结果。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **方差公式分母记错**：误记为 4、6、16 等错误分母 → 正确做法：均匀分布方差公式固定为 $(b-a)^2/12$，分母恒为 12。
2. **用端点之积代替差**：误用 $D = ab/$ 某数 → 正确做法：公式用的是区间长度 $b - a$，不是端点之积 $ab$。
3. **混淆与 $U(0,1)$ 特例**：$U(0,1)$ 的 $D = 1/12$，误以为所有均匀分布 $D$ 都含 12 因子 → 正确做法：$U(0,1)$ 是 $a=0$、$b=1$ 的特例，一般情况按 $(b-a)^2/12$ 计算。
:::

:::callout{kind=note label="知识卡片：均匀分布的数字特征"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 期望 | $E(X) = \dfrac{a + b}{2}$ | $U(a, b)$ |
| 方差 | $D(X) = \dfrac{(b - a)^2}{12}$ | $U(a, b)$ |
| 密度函数 | $f(x) = \dfrac{1}{b - a}$ | $a < x < b$ |
| 分布函数 | $F(x) = \dfrac{x - a}{b - a}$ | $a \leq x \leq b$ |
| 特例 $U(0,1)$ | $E = \dfrac{1}{2}$，$D = \dfrac{1}{12}$ | $a = 0, b = 1$ |

**概念辨析**：
- 均匀分布的期望是区间中点 $(a+b)/2$，方差仅依赖区间长度 $b-a$，与位置无关。
- 公式 $D = (b-a)^2/12$ 可由定义 $D(X) = E(X^2) - [E(X)]^2$ 推导验证，二者等价。
:::

:::callout{kind=tip label="结论速记"}
均匀分布 $U(a, b)$ 的方差 $D(X) = \dfrac{(b-a)^2}{12}$，区间越宽方差越大。

**口诀**：均匀方差长平方，除以十二记心间。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到 $U(a, b)$ 求方差/期望 → 联想专用公式 $E = (a+b)/2$，$D = (b-a)^2/12$
- **关联考点**：与指数分布、正态分布的数字特征公式对比记忆
- **复用场景**：所有均匀分布相关计算，包括均匀抽样误差分析
:::

### 第6题

:::callout{kind=note label="题目"}
设 $X_1, \ldots, X_n$ 来自总体 $N(\mu, \sigma^2)$，$\sigma^2$ 已知，则 $\mu$ 的置信区间使用的枢轴量为（　　）

A. $\dfrac{\bar{X} - \mu}{S / \sqrt{n}}$　　B. $\dfrac{\bar{X} - \mu}{\sigma / \sqrt{n}}$　　C. $\dfrac{(n-1)S^2}{\sigma^2}$　　D. $\dfrac{\bar{X}}{S}$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：参数估计题 → 识别 $\sigma^2$ 是否已知 → 选择对应的枢轴量（Z 或 T）→ 验证枢轴量两要素。

**为何用此公式**：$\sigma^2$ 已知时，样本均值 $\bar{X}$ 标准化后服从标准正态，且枢轴量仅含待估参数 $\mu$、分布已知（标准正态），满足枢轴量定义的两要素。

**推导过程**：

1. 第一步：由 $X_i \sim N(\mu, \sigma^2)$ 独立，知 $\bar{X} \sim N\!\left(\mu, \dfrac{\sigma^2}{n}\right)$ ← 依据：正态样本均值的分布（独立正态线性组合仍正态）
2. 第二步：标准化 $\dfrac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$ ← 依据：正态分布标准化公式
3. 第三步：验证枢轴量两要素：① 仅含待估参数 $\mu$；② 分布已知（标准正态 $N(0,1)$）← 依据：枢轴量定义

**选项分析**：

- **A（错误）**：$\dfrac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$，用于 $\sigma^2$ **未知**的情形，本题 $\sigma^2$ 已知不适用。
- **B（正确）**：$\dfrac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)$，是 $\sigma^2$ 已知时 $\mu$ 的标准枢轴量。
- **C（错误）**：$\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$，是构造 $\sigma^2$ 置信区间的枢轴量，与 $\mu$ 无关。
- **D（错误）**：$\dfrac{\bar{X}}{S}$ 不是标准枢轴量，不含待估参数 $\mu$ 的显式表达，分布也未知。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$\sigma^2$ 已知/未知混淆**：$\sigma^2$ 已知却用 T 枢轴量 → 正确做法：$\sigma^2$ 已知用 $Z = \dfrac{\bar{X} - \mu}{\sigma / \sqrt{n}}$，$\sigma^2$ 未知用 $T = \dfrac{\bar{X} - \mu}{S / \sqrt{n}}$。
2. **枢轴量与统计量混淆**：选 D 这类不含待估参数的量 → 正确做法：枢轴量必须含待估参数且分布已知，二者缺一不可。
3. **$\mu$ 与 $\sigma^2$ 的枢轴量混用**：将 $\chi^2$ 枢轴量用于 $\mu$ → 正确做法：$\mu$ 的枢轴量基于 $\bar{X}$，$\sigma^2$ 的枢轴量基于 $S^2$。
:::

:::callout{kind=note label="知识卡片：枢轴量与置信区间"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $\sigma^2$ 已知 | $\dfrac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0,1)$ | 总体正态或大样本 |
| $\sigma^2$ 未知 | $\dfrac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$ | 总体正态 |
| $\mu$ 已知 | $\dfrac{\sum(X_i - \mu)^2}{\sigma^2} \sim \chi^2(n)$ | 总体正态 |
| $\mu$ 未知 | $\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$ | 总体正态 |
| 样本均值分布 | $\bar{X} \sim N\!\left(\mu, \dfrac{\sigma^2}{n}\right)$ | 总体正态 |

**概念辨析**：
- 枢轴量两要素：① 含待估参数；② 分布已知（不含未知参数）。统计量不含未知参数，二者概念不同。
- $\sigma^2$ 已知用 Z（精度更高），$\sigma^2$ 未知用 T（多一层不确定性），二者不可混用。
:::

:::callout{kind=tip label="结论速记"}
$\sigma^2$ 已知用 $Z = \dfrac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0,1)$；$\sigma^2$ 未知用 $T = \dfrac{\bar{X} - \mu}{S / \sqrt{n}} \sim t(n-1)$。

**口诀**：方差已知走 Z 路线，方差未知 T 上前。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"枢轴量""置信区间" + $\sigma^2$ 已知/未知 → 联想 Z 与 T 的选择
- **关联考点**：与假设检验中 Z 检验、T 检验的统计量选择一致
- **复用场景**：所有正态总体均值 $\mu$ 的区间估计与假设检验
:::

### 第7题

:::callout{kind=note label="题目"}
若估计量 $\hat{\theta}$ 满足 $E(\hat{\theta}) = \theta$，则称 $\hat{\theta}$ 为 $\theta$ 的（　　）

A. 有效估计　　B. 无偏估计　　C. 相合估计　　D. 极大似然估计
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：估计量评价标准识别题 → 由定义式 $E(\hat{\theta}) = \theta$ 匹配评价标准 → 对应无偏性定义。

**为何用此公式**：无偏性的定义即为"估计量的期望等于被估参数的真值"，本题直接考查定义识别，无需计算。

**推导过程**：

1. 第一步：解读定义式 $E(\hat{\theta}) = \theta$：估计量 $\hat{\theta}$ 的期望等于被估参数 $\theta$ 的真值 ← 依据：无偏性定义
2. 第二步：对照点估计评价标准体系：无偏性（期望=真值）、有效性（无偏中方差最小）、相合性（依概率收敛）、MLE（构造方法）← 依据：点估计评价标准分类
3. 第三步：匹配 $E(\hat{\theta}) = \theta$ 正是无偏性定义 → 选 B ← 依据：定义匹配

**选项分析**：

- **A（错误）**：有效性要求在所有无偏估计中方差最小，条件比无偏性更强，定义式为 $\min D(\hat{\theta})$。
- **B（正确）**：$E(\hat{\theta}) = \theta$ 是无偏估计的定义。
- **C（错误）**：相合性要求 $\hat{\theta}_n \xrightarrow{P} \theta$（$n \to \infty$），是大样本性质，定义式涉及极限。
- **D（错误）**：MLE 是构造估计量的方法（最大化似然函数），不直接等价于无偏性，MLE 不一定无偏。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **无偏与有效混淆**：认为"好估计"就是有效 → 正确做法：无偏是期望=真值，有效是在无偏基础上方差最小，二者层级不同。
2. **无偏与 MLE 等同**：以为 MLE 必无偏 → 正确做法：MLE 是构造方法，不一定无偏（如 $\sigma^2$ 的 MLE 除以 $n$ 而非 $n-1$，有偏）。
3. **相合性定义记错**：误以为相合性是 $n \to \infty$ 时方差 $\to 0$ → 正确做法：相合性是 $\hat{\theta}_n \xrightarrow{P} \theta$，方差 $\to 0$ 是充分条件之一但非定义本身。
:::

:::callout{kind=note label="知识卡片：点估计的评价标准"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 无偏性 | $E(\hat{\theta}) = \theta$ | 任意估计量 |
| 有效性 | $D(\hat{\theta}_1) \leq D(\hat{\theta}_2)$ | 在无偏估计中比较 |
| 相合性 | $\hat{\theta}_n \xrightarrow{P} \theta$（$n \to \infty$） | 大样本性质 |
| 均方误差 | $\text{MSE} = D(\hat{\theta}) + [E(\hat{\theta}) - \theta]^2$ | 任意估计量 |
| MSE 与无偏关系 | 无偏时 $\text{MSE} = D(\hat{\theta})$ | $E(\hat{\theta}) = \theta$ |

**概念辨析**：
- 无偏性是"小样本"性质（对固定 $n$ 成立），相合性是"大样本"性质（$n \to \infty$ 时成立）。
- MLE 是构造方法，无偏性是评价标准，二者正交：MLE 可能无偏也可能有偏。
:::

:::callout{kind=tip label="结论速记"}
$E(\hat{\theta}) = \theta$ 是**无偏估计**的定义；无偏 + 方差最小 = 有效；$\hat{\theta}_n \xrightarrow{P} \theta$ = 相合。

**口诀**：期望等于真值即无偏，方差最小才有效，依概率收敛为相合。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到 $E(\hat{\theta}) = \theta$ → 联想无偏性定义
- **关联考点**：与有效性、相合性构成点估计三大评价标准；与 MLE 的有偏/无偏判断关联
- **复用场景**：所有点估计评价题，包括判断估计量是否无偏、有效、相合
:::

## 二、填空题（每小题 3 分，共 12 分）

### 第8题

:::callout{kind=note label="题目"}
设 $X \sim U(0, 1)$，则 $P(X < 0.5) = $ ____。
:::

:::callout{kind=insight label="解析"}
**【答案】** $\dfrac{1}{2}$

**思路**：均匀分布求概率 → 用分布函数直接代入或密度积分验证 → $U(0,1)$ 的分布函数形式极简 $F(x) = x$。

**为何用此公式**：$U(0,1)$ 的分布函数 $F(x) = x$（$0 \leq x \leq 1$）形式最简，直接代入即可；亦可用密度积分 $f(x) = 1$ 验证。

**推导过程**：

1. 第一步：识别 $X \sim U(0, 1)$，分布函数 $F(x) = x$（$0 \leq x \leq 1$）← 依据：均匀分布分布函数
2. 第二步：$P(X < 0.5) = F(0.5) = 0.5 = \dfrac{1}{2}$ ← 依据：分布函数定义 $P(X \leq x) = F(x)$
3. 第三步（验证）：$\int_0^{0.5} 1\, dx = 0.5$ ← 依据：连续型概率积分定义

**关键步骤说明**：$U(0,1)$ 是均匀分布最简特例，密度恒为 1，分布函数 $F(x) = x$，概率即区间长度（因总区间长为 1）。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **用密度值代替概率**：误以为 $f(0.5) = 1$ 是答案 → 正确做法：概率是密度积分，$U(0,1)$ 在长度 $0.5$ 的区间上概率为 $0.5$。
2. **分布函数区间错误**：$U(0,1)$ 支撑域外 $F(x)$ 不等于 $x$ → 正确做法：$x < 0$ 时 $F = 0$，$x > 1$ 时 $F = 1$，仅 $0 \leq x \leq 1$ 时 $F = x$。
3. **忽略均匀分布的几何意义**：纠结于积分计算 → 正确做法：$U(0,1)$ 概率即子区间长度（总长度归一为 1）。
:::

:::callout{kind=note label="知识卡片：均匀分布概率计算"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 密度积分 | $P(a < X < b) = \displaystyle\int_a^b \dfrac{1}{b-a}\, dx$ | $U(a, b)$ |
| 分布函数 | $F(x) = \dfrac{x - a}{b - a}$ | $a \leq x \leq b$ |
| 几何意义 | $P(c < X < d) = \dfrac{d - c}{b - a}$ | $U(a, b)$ |
| 特例 $U(0,1)$ | $F(x) = x$，$f(x) = 1$ | $0 \leq x \leq 1$ |
| 归一性 | $\displaystyle\int_a^b \dfrac{1}{b-a}\, dx = 1$ | $U(a, b)$ |

**概念辨析**：
- $U(0,1)$ 概率即子区间长度（因 $b - a = 1$）；一般 $U(a, b)$ 概率为子区间长度除以总长度。
- 分布函数法与密度积分法等价，选哪个看计算便捷度。
:::

:::callout{kind=tip label="结论速记"}
均匀分布的概率即长度比：$P(c < X < d) = \dfrac{d - c}{b - a}$；$U(0,1)$ 特例下即子区间长度。

**口诀**：均匀概率长度比，零一特例即长度。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到 $U(0,1)$ 求概率 → 联想分布函数 $F(x) = x$ 直接代入
- **关联考点**：与一般 $U(a, b)$ 的概率公式对比；与蒙特卡洛模拟中 $U(0,1)$ 作为基础随机数关联
- **复用场景**：所有均匀分布概率计算，包括逆变换法生成随机数
:::

### 第9题

:::callout{kind=note label="题目"}
设 $X, Y$ 独立同分布，且 $P(X = 1) = P(Y = 1) = \dfrac{1}{3}$，$P(X = 0) = P(Y = 0) = \dfrac{2}{3}$，则 $P(X = Y = 1) = $ ____。
:::

:::callout{kind=insight label="解析"}
**【答案】** $\dfrac{1}{9}$

**思路**：求离散型联合概率 → 检查独立性 → 独立时联合概率等于边际概率之积。

**为何用此公式**：独立性定义 $P(X = x, Y = y) = P(X = x) \cdot P(Y = y)$，本题明确给出"独立同分布"条件，直接套用乘法公式即可。

**推导过程**：

1. 第一步：识别 $X$、$Y$ 独立 ← 依据：题干"独立同分布"
2. 第二步：由独立性 $P(X = 1, Y = 1) = P(X = 1) \cdot P(Y = 1)$ ← 依据：独立性定义
3. 第三步：代入 $P(X = 1, Y = 1) = \dfrac{1}{3} \times \dfrac{1}{3} = \dfrac{1}{9}$ ← 依据：题给边际概率

**关键步骤说明**：独立性是"联合概率等于边际之积"的充要条件，本题直接给出独立，无需额外验证。同分布保证 $P(Y = 1) = P(X = 1) = 1/3$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **不独立时套用乘法公式**：忽略独立性条件直接相乘 → 正确做法：先确认独立，不独立时用 $P(AB) = P(A) \cdot P(B \mid A)$。
2. **加法代替乘法**：误算 $P(X = 1) + P(Y = 1) = 2/3$ → 正确做法：联合概率是乘法不是加法。
3. **混淆 $P(X = Y = 1)$ 与 $P(X = Y)$**：以为求"X = Y"的概率 → 正确做法：$P(X = Y = 1)$ 是 $X = 1$ 且 $Y = 1$ 的联合概率，与 $P(X = Y)$（含 $X = Y = 0$ 和 $X = Y = 1$ 两部分）不同。
:::

:::callout{kind=note label="知识卡片：独立性与乘法公式"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 独立定义 | $P(AB) = P(A) \cdot P(B)$ | 独立事件 |
| 离散型联合分布 | $P(X = x, Y = y) = P(X = x) \cdot P(Y = y)$ | 独立随机变量 |
| 乘法公式 | $P(AB) = P(A) \cdot P(B \mid A)$ | 任意事件 |
| 多个独立事件 | $P(A_1 A_2 \cdots A_n) = \prod_{i=1}^{n} P(A_i)$ | 相互独立 |
| 不独立判定 | 存在 $x, y$ 使 $P(X = x, Y = y) \neq P(X = x)P(Y = y)$ | 任意随机变量 |

**概念辨析**：
- 独立 $\iff$ 联合 = 边际之积，二者定义等价。
- $P(X = Y = 1)$ 是单个联合概率，$P(X = Y)$ 是 $X = Y$ 所有取值的概率之和，二者不同。
:::

:::callout{kind=tip label="结论速记"}
独立随机变量的联合概率 = 边际概率之积：$P(X = x, Y = y) = P(X = x) \cdot P(Y = y)$。

**口诀**：独立联合乘边际，不独立才用条件。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"独立" + "联合概率" → 联想边际相乘
- **关联考点**：与不相关、独立性的判定方法对比；与连续型联合密度 $f(x, y) = f_X \cdot f_Y$ 关联
- **复用场景**：所有独立性条件下的联合分布计算

### 第10题

:::callout{kind=note label="题目"}
设 $X \sim E(2)$（参数为均值），则密度函数 $f_X(2) = $ ____。
:::

:::callout{kind=insight label="解析"}
**【答案】** $\dfrac{1}{2} e^{-1}$

**思路**：指数分布参数为均值 → 先转换为速率参数 → 写出密度函数 → 代入 $x = 2$ 求值。

**为何用此公式**：题干明确"参数为均值"，指数分布有两种参数化（速率 $\lambda$ 与均值 $\mu$），必须先用 $\lambda = 1/\mu$ 转换为速率参数再写密度，避免参数化混淆。

**推导过程**：

1. 第一步：识别参数化：题给均值 $\mu = 2$ ← 依据：题干"参数为均值"
2. 第二步：转换为速率参数 $\lambda = \dfrac{1}{\mu} = \dfrac{1}{2}$ ← 依据：指数分布均值与速率关系 $E(X) = 1/\lambda$
3. 第三步：写出密度 $f(x) = \lambda e^{-\lambda x} = \dfrac{1}{2} e^{-x/2}$ ← 依据：指数分布密度（速率参数化）
4. 第四步：代入 $x = 2$：$f(2) = \dfrac{1}{2} e^{-2/2} = \dfrac{1}{2} e^{-1} = \dfrac{1}{2e}$ ← 依据：函数求值

**关键步骤说明**：$x = 2$ 既是分布参数 $\mu$ 的值，也是自变量取值，纯属巧合；密度函数值 $f(2) = 1/(2e) \approx 0.184$，不是概率。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **参数化混淆**：把均值 $\mu = 2$ 当作速率 $\lambda = 2$ 直接写 $f(x) = 2e^{-2x}$ → 正确做法：题给均值时速率 $\lambda = 1/\mu = 1/2$，密度为 $\dfrac{1}{2} e^{-x/2}$。
2. **求概率与求密度混淆**：误算 $P(X = 2)$ → 正确做法：连续型 $P(X = 2) = 0$，本题求的是密度函数值 $f(2)$。
3. **代入 $x$ 错误**：把参数 $2$ 当作 $x$ 代入而不区分 → 正确做法：$x$ 是自变量取值 $2$，参数 $\mu = 2$ 是分布参数，二者虽同值但概念不同。
:::

:::callout{kind=note label="知识卡片：指数分布的两种参数化"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 速率参数化 | $f(x) = \lambda e^{-\lambda x}$，$x > 0$ | 速率 $\lambda$ 已知 |
| 均值参数化 | $f(x) = \dfrac{1}{\mu} e^{-x/\mu}$，$x > 0$ | 均值 $\mu$ 已知 |
| 均值与速率关系 | $E(X) = \dfrac{1}{\lambda} = \mu$ | 指数分布 |
| 方差 | $D(X) = \dfrac{1}{\lambda^2} = \mu^2$ | 指数分布 |
| 无记忆性 | $P(X > s + t \mid X > s) = P(X > t)$ | 指数分布 |

**概念辨析**：
- 速率 $\lambda$ 与均值 $\mu$ 互为倒数：$\lambda = 1/\mu$。速率大表示衰减快、均值小。
- 两种参数化等价，但写密度前必须确认题给的是哪种参数，否则结果差倒数倍。
:::

:::callout{kind=tip label="结论速记"}
指数分布参数为均值 $\mu$ 时，$f(x) = \dfrac{1}{\mu} e^{-x/\mu}$；参数为速率 $\lambda$ 时，$f(x) = \lambda e^{-\lambda x}$。

**口诀**：均参倒数为速率，密度形式要看清。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到 $X \sim E(\text{参数})$ → 立即确认参数是均值还是速率
- **关联考点**：与泊松过程事件间隔分布关联；与几何分布（离散无记忆性）对应
- **复用场景**：所有指数分布相关计算，包括可靠性、等待时间问题
:::

### 第11题

:::callout{kind=note label="题目"}
设总体 $X$ 的均值为 5，方差为 4，样本容量为 4，则 $E\!\left(\displaystyle\sum_{i=1}^{4} X_i^2\right) = $ ____。
:::

:::callout{kind=insight label="解析"}
**【答案】** $116$

**思路**：求样本平方和的期望 → 先用方差-期望关系求 $E(X^2)$ → 再用期望线性性求和。

**为何用此公式**：$E(X^2) = D(X) + [E(X)]^2$ 是连接一阶矩、二阶矩、方差的核心公式；期望线性性 $E\!\left(\sum a_i X_i\right) = \sum a_i E(X_i)$ 对任意随机变量（不必独立）成立，可直接求和。

**推导过程**：

1. 第一步：由方差-期望关系求 $E(X^2)$：$E(X^2) = D(X) + [E(X)]^2 = 4 + 5^2 = 4 + 25 = 29$ ← 依据：方差定义 $D(X) = E(X^2) - [E(X)]^2$ 的变形
2. 第二步：由同分布性 $E(X_i^2) = E(X^2) = 29$ ← 依据：$X_i$ 与 $X$ 同分布
3. 第三步：由期望线性性求和：$E\!\left(\sum_{i=1}^{4} X_i^2\right) = \sum_{i=1}^{4} E(X_i^2) = 4 \times 29 = 116$ ← 依据：期望线性性（无需独立）

**关键步骤说明**：期望线性性对任意随机变量成立（不要求独立），这是关键；方差可加性 $D\!\left(\sum X_i\right) = \sum D(X_i)$ 才需要独立条件。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **误用方差可加性条件**：以为需要独立才能求 $E\!\left(\sum X_i^2\right)$ → 正确做法：期望线性性无需独立，只有方差可加性才需要独立。
2. **不会求 $E(X^2)$**：已知 $E(X)$、$D(X)$ 却不会算 $E(X^2)$ → 正确做法：用 $E(X^2) = D(X) + [E(X)]^2$ 转化。
3. **混淆 $E\!\left(\sum X_i^2\right)$ 与 $\sum [E(X_i)]^2$**：误算为 $4 \times 5^2 = 100$ → 正确做法：$E\!\left(\sum X_i^2\right) = \sum E(X_i^2)$，而 $E(X_i^2) = 29$ 不是 $[E(X_i)]^2 = 25$。
:::

:::callout{kind=note label="知识卡片：期望与方差的关系"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 二阶矩与方差 | $E(X^2) = D(X) + [E(X)]^2$ | 任意随机变量 |
| 期望线性性 | $E\!\left(\sum a_i X_i\right) = \sum a_i E(X_i)$ | 无需独立 |
| 方差可加性 | $D\!\left(\sum X_i\right) = \sum D(X_i)$ | 需独立 |
| 样本均值期望 | $E(\bar{X}) = \mu$ | 任意总体 |
| 样本均值方差 | $D(\bar{X}) = \dfrac{\sigma^2}{n}$ | 需独立 |

**概念辨析**：
- 期望线性性无需独立，方差可加性需要独立，二者条件不同。
- $E(X^2)$ 与 $[E(X)]^2$ 不同：前者是二阶原点矩，后者是期望的平方，差为方差 $D(X)$。
:::

:::callout{kind=tip label="结论速记"}
$E(X^2) = D(X) + [E(X)]^2$；再由期望线性性 $E\!\left(\sum X_i^2\right) = n \cdot E(X^2)$（无需独立）。

**口诀**：方期加期方得二阶，期望线性不用独。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"已知 $E(X)$、$D(X)$ 求 $E(X^2)$ 或 $E\!\left(\sum X_i^2\right)$" → 联想方差-期望关系 + 线性性
- **关联考点**：与样本方差 $S^2$ 的期望计算关联（需独立）；与大数定律关联
- **复用场景**：所有涉及二阶矩、样本平方和期望的题目
:::

## 三、（10 分）

### 第12题

:::callout{kind=note label="题目"}
甲盒中有 3 个白球、2 个黑球，乙盒中有 4 个白球、6 个黑球。先等可能地选一盒，再从所选盒中任取一球。求：

(1) 取到白球的概率；

(2) 已知取到白球，求所选盒为甲盒的概率。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：分阶段试验 → 第一阶段选盒构成完备事件组 → 第二阶段取球 → 第(1)问用全概率公式求总概率，第(2)问用贝叶斯公式求后验。

**为何用此公式**：全概率公式适用于"完备事件组下求总概率"，贝叶斯公式适用于"已知结果求原因后验"，本题两问正好对应。$A$、$B$（选甲/乙盒）互斥且并集为全集，满足完备事件组条件。

**推导过程**：

1. 第一步：设 $A$ = 选甲盒，$B$ = 选乙盒，$W$ = 取到白球。由等可能选盒 $P(A) = P(B) = \dfrac{1}{2}$ ← 依据：等概率古典定义
2. 第二步：计算条件概率 $P(W \mid A) = \dfrac{3}{5}$（甲盒 3 白 2 黑），$P(W \mid B) = \dfrac{4}{10} = \dfrac{2}{5}$（乙盒 4 白 6 黑）← 依据：条件概率古典定义
3. 第三步（第(1)问）：全概率公式 $P(W) = P(A) \cdot P(W \mid A) + P(B) \cdot P(W \mid B) = \dfrac{1}{2} \times \dfrac{3}{5} + \dfrac{1}{2} \times \dfrac{2}{5} = \dfrac{3}{10} + \dfrac{2}{10} = \dfrac{1}{2}$ ← 依据：全概率公式
4. 第四步（第(2)问）：贝叶斯公式 $P(A \mid W) = \dfrac{P(A) \cdot P(W \mid A)}{P(W)} = \dfrac{\dfrac{1}{2} \times \dfrac{3}{5}}{\dfrac{1}{2}} = \dfrac{3}{5}$ ← 依据：贝叶斯公式，分母复用第(1)问结果

**关键步骤说明**：$A$、$B$ 构成完备事件组（互斥且 $P(A) + P(B) = 1$），是应用全概率/贝叶斯的前提；第(2)问分母 $P(W)$ 已由第(1)问求得，直接复用避免重复计算。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **完备事件组不完整**：遗漏某个盒或事件不互斥 → 正确做法：$A$、$B$ 必须互斥且 $P(A) + P(B) = 1$。
2. **条件概率算反**：把 $P(W \mid A)$ 当作 $P(A \mid W)$ → 正确做法：$P(W \mid A)$ 是"选甲盒后取白球"的概率，$P(A \mid W)$ 是"取到白球后推断是甲盒"的概率。
3. **贝叶斯分母漏除**：直接用 $P(A) \cdot P(W \mid A)$ 作答 → 正确做法：贝叶斯公式分母必须是全概率 $P(W)$，不可省略。
:::

:::callout{kind=note label="知识卡片：全概率公式与贝叶斯公式"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 全概率公式 | $P(B) = \displaystyle\sum_{i=1}^{n} P(A_i) \cdot P(B \mid A_i)$ | $A_i$ 为完备事件组 |
| 贝叶斯公式 | $P(A_i \mid B) = \dfrac{P(A_i) \cdot P(B \mid A_i)}{P(B)}$ | $P(B) > 0$ |
| 先验概率 | $P(A_i)$ | 试验前已知 |
| 后验概率 | $P(A_i \mid B)$ | 观察 $B$ 后更新 |
| 完备事件组 | $A_i$ 互斥且 $\cup A_i = \Omega$ | 全概率/贝叶斯前提 |

**概念辨析**：
- 全概率"由因求果"（已知先验求总概率），贝叶斯"由果溯因"（已知结果求后验），方向相反。
- 先验是试验前已知，后验是试验后更新；贝叶斯公式连接二者。
:::

:::callout{kind=tip label="结论速记"}
全概率"由因求果"：$P(B) = \sum P(A_i) P(B \mid A_i)$；贝叶斯"由果溯因"：$P(A_i \mid B) = \dfrac{P(A_i) P(B \mid A_i)}{P(B)}$。

**口诀**：全概率因求果，贝叶斯果溯因，分母全概率不能省。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"分阶段试验" + "求某阶段概率/反推原因" → 联想全概率 + 贝叶斯
- **关联考点**：与条件概率定义、独立性关联；与统计推断中的先验/后验关联
- **复用场景**：所有两阶段试验、医学检测、产品质量抽检问题
:::

## 四、（10 分）

### 第13题

:::callout{kind=note label="题目"}
设随机变量 $X \sim E(\lambda)$，令 $Y = [X] + 1$，其中 $[X]$ 表示不超过 $X$ 的最大整数。求 $Y$ 的分布列和数学期望。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：连续型取整产生离散分布 → $Y = k$ 等价于 $k-1 \leq X < k$ → 对密度在该区间积分得概率 → 提取公因子识别为几何分布 → 套用几何分布期望公式。

**为何用此公式**：取整函数 $[X]$ 使 $Y$ 取离散值，$Y = k \iff [X] = k-1 \iff k-1 \leq X < k$，对密度积分得 $P(Y = k)$；提取公因子后形态为 $(1-p)^{k-1} p$，是几何分布标准形式，可直接套期望公式 $E(Y) = 1/p$。

**推导过程**：

1. 第一步：写出 $X \sim E(\lambda)$ 的密度 $f(x) = \lambda e^{-\lambda x}$（$x > 0$）← 依据：指数分布密度
2. 第二步：转化事件 $Y = k$（$k = 1, 2, \ldots$）$\iff [X] = k-1 \iff k-1 \leq X < k$ ← 依据：取整函数定义
3. 第三步：积分求概率 $P(Y = k) = \int_{k-1}^{k} \lambda e^{-\lambda x}\, dx = \left[-e^{-\lambda x}\right]_{k-1}^{k} = e^{-\lambda(k-1)} - e^{-\lambda k}$ ← 依据：密度积分求概率 + 牛顿-莱布尼茨公式
4. 第四步：提取公因子 $P(Y = k) = e^{-\lambda(k-1)}\!\left(1 - e^{-\lambda}\right)$ ← 依据：指数运算性质 $e^{-\lambda(k-1)} - e^{-\lambda k} = e^{-\lambda(k-1)}(1 - e^{-\lambda})$
5. 第五步：令 $p = 1 - e^{-\lambda}$，则 $P(Y = k) = (1 - p)^{k-1} \cdot p$ ← 依据：几何分布概率形式识别
6. 第六步：识别为参数 $p = 1 - e^{-\lambda}$ 的几何分布，期望 $E(Y) = \dfrac{1}{p} = \dfrac{1}{1 - e^{-\lambda}}$ ← 依据：几何分布期望公式

**关键步骤说明**：连续型取整产生离散分布是常见套路；识别为几何分布后直接套期望公式，无需逐项求和。取整 $[X] + 1$ 而非 $[X]$：因 $[X]$ 可能为 0（当 $0 < X < 1$），加 1 使取值从 1 开始，匹配标准几何分布形式。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **取整定义错误**：误以为 $[X]$ 是四舍五入 → 正确做法：$[X]$ 是地板函数（不超过 $X$ 的最大整数），$[X] = k-1 \iff k-1 \leq X < k$。
2. **积分限错误**：写成 $\int_k^{k+1}$ → 正确做法：$Y = k$ 对应 $k-1 \leq X < k$，积分限为 $(k-1, k)$。
3. **不识别几何分布**：逐项求和算期望导致计算繁琐 → 正确做法：提取公因子后形态为 $(1-p)^{k-1} p$，是几何分布，期望直接套 $1/p$。
:::

:::callout{kind=note label="知识卡片：取整函数与几何分布"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 取整函数 | $[X] = \lfloor X \rfloor$（地板函数） | 任意实数 |
| 几何分布 $Geo(p)$ | $P(Y = k) = (1-p)^{k-1} p$ | $k = 1, 2, \ldots$ |
| 几何分布期望 | $E(Y) = \dfrac{1}{p}$ | $Geo(p)$ |
| 几何分布方差 | $D(Y) = \dfrac{1-p}{p^2}$ | $Geo(p)$ |
| 无记忆性 | 几何分布是离散型唯一无记忆分布 | 对应连续型指数分布 |

**概念辨析**：
- 几何分布是指数分布的离散对应：二者都具有无记忆性。
- 取整 $[X] + 1$ 而非 $[X]$：使取值从 1 开始，匹配标准几何分布形式 $k = 1, 2, \ldots$。
:::

:::callout{kind=tip label="结论速记"}
指数分布取整 $Y = [X] + 1$ 服从几何分布，参数 $p = 1 - e^{-\lambda}$，期望 $E(Y) = \dfrac{1}{1 - e^{-\lambda}}$。

**口诀**：指数取整化几何，参数 1 减 e 负兰姆。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"连续型取整"或"$[X]$" → 联想转化为离散分布
- **关联考点**：与指数分布无记忆性、几何分布无记忆性关联；与泊松过程离散化关联
- **复用场景**：所有连续型取整产生离散分布的题目，包括舍入误差分析
:::

## 五、（12 分）

### 第14题

:::callout{kind=note label="题目"}
设 $(X, Y)$ 的联合密度为

$$f(x, y) = \begin{cases} \dfrac{1}{1 - x}, & 0 \leq x \leq y \leq 1 \\ 0, & \text{其他} \end{cases}$$

求 $P(Y \leq 0.2 \mid X \leq 0.2)$、$Y$ 的边缘密度。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：联合密度已知 → 求边缘密度（对另一变量积分，积分限由支撑域决定）→ 利用支撑域包含关系 $X \leq Y$ 简化条件概率 → 分部积分求 $P(Y \leq 0.2)$。

**为何用此公式**：边缘密度 $f_Y(y) = \int f(x, y)\, dx$ 对 $x$ 积分，积分限由支撑域 $0 \leq x \leq y$ 决定为 $[0, y]$；支撑域 $0 \leq x \leq y$ 保证 $X \leq Y$，故 $\{Y \leq 0.2\} \subset \{X \leq 0.2\}$，条件概率简化为 $P(Y \leq 0.2)/P(X \leq 0.2)$。

**推导过程**：

1. 第一步：求 $X$ 的边缘密度 $f_X(x) = \int_x^1 \dfrac{1}{1 - x}\, dy = \dfrac{1 - x}{1 - x} = 1$（$0 < x < 1$）← 依据：边缘密度定义 + 支撑域 $y \in [x, 1]$
2. 第二步：故 $X \sim U(0, 1)$，$P(X \leq 0.2) = 0.2$ ← 依据：均匀分布分布函数
3. 第三步：求 $Y$ 的边缘密度 $f_Y(y) = \int_0^y \dfrac{1}{1 - x}\, dx = \Big[-\ln(1 - x)\Big]_0^y = -\ln(1 - y)$（$0 < y < 1$）← 依据：边缘密度定义 + 支撑域 $x \in [0, y]$
4. 第四步：利用支撑域 $0 \leq x \leq y \implies X \leq Y$，故 $\{Y \leq 0.2\} \subset \{X \leq 0.2\}$，$P(X \leq 0.2, Y \leq 0.2) = P(Y \leq 0.2)$ ← 依据：支撑域包含关系
5. 第五步：计算 $P(Y \leq 0.2) = \int_0^{0.2} -\ln(1 - y)\, dy = \Big[y + (1 - y)\ln(1 - y)\Big]_0^{0.2} = 0.2 + 0.8 \ln 0.8$ ← 依据：分部积分法
6. 第六步：$P(Y \leq 0.2 \mid X \leq 0.2) = \dfrac{P(Y \leq 0.2)}{P(X \leq 0.2)} = \dfrac{0.2 + 0.8 \ln 0.8}{0.2} = 1 + 4 \ln \dfrac{4}{5} \approx 0.107$ ← 依据：条件概率定义 + 包含关系简化

**最终结果**：

$$P(Y \leq 0.2 \mid X \leq 0.2) = 1 + 4 \ln\frac{4}{5} \approx 0.107$$

$$f_Y(y) = \begin{cases} -\ln(1 - y), & 0 < y < 1 \\ 0, & \text{其他} \end{cases}$$

> 注：原试卷标准答案标注为 $0.2$，但 $0.2 = P(X \leq 0.2)$，并非所求条件概率。严格计算结果为 $1 + 4\ln\dfrac{4}{5} \approx 0.107$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **边缘密度积分限错误**：对 $y$ 积分时上下限取错 → 正确做法：$f_X(x)$ 对 $y$ 积分，由支撑域 $0 \leq x \leq y \leq 1$ 知 $y \in [x, 1]$；$f_Y(y)$ 对 $x$ 积分，$x \in [0, y]$。
2. **忽视支撑域包含关系**：直接算 $P(X \leq 0.2, Y \leq 0.2)$ 的二重积分 → 正确做法：由 $X \leq Y$ 知 $\{Y \leq 0.2\} \subset \{X \leq 0.2\}$，联合概率即 $P(Y \leq 0.2)$，简化计算。
3. **盲目相信标答**：原卷标答 $0.2$ 是 $P(X \leq 0.2)$ 而非条件概率 → 正确做法：以严格推导为准，标答混淆了 $P(X \leq 0.2)$ 与所求条件概率。
:::

:::callout{kind=note label="知识卡片：联合密度与边缘密度"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 边缘密度 | $f_X(x) = \displaystyle\int_{-\infty}^{+\infty} f(x, y)\, dy$ | 联合密度已知 |
| 条件密度 | $f_{Y \mid X}(y \mid x) = \dfrac{f(x, y)}{f_X(x)}$ | $f_X(x) > 0$ |
| 条件概率 | $P(Y \leq b \mid X \leq a) = \dfrac{P(X \leq a, Y \leq b)}{P(X \leq a)}$ | $P(X \leq a) > 0$ |
| 归一性 | $\displaystyle\iint f(x, y)\, dx\, dy = 1$ | 联合密度 |
| 支撑域包含 | $X \leq Y \implies \{Y \leq a\} \subset \{X \leq a\}$ | 支撑域约束 |

**概念辨析**：
- 边缘密度积分限由支撑域决定，不同变量对应不同积分区间，不可统一取 $(-\infty, +\infty)$。
- 支撑域包含关系可大幅简化条件概率计算：若 $\{B\} \subset \{A\}$，则 $P(B \mid A) = P(B)/P(A)$。
:::

:::callout{kind=tip label="结论速记"}
求边缘密度对另一变量积分；条件概率注意支撑域包含关系——若 $X \leq Y$ 则 $\{Y \leq a\} \subset \{X \leq a\}$，可简化为 $P(Y \leq a)/P(X \leq a)$。

**口诀**：边缘积分看支撑，包含关系简条件。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到联合密度 + 支撑域含不等式 → 联想边缘积分限 + 包含关系简化
- **关联考点**：与条件分布、独立性判定关联；与序统计量分布关联
- **复用场景**：所有非常规支撑域的联合密度题，包括三角域、矩形域
:::

## 六、（12 分）

### 第15题

:::callout{kind=note label="题目"}
设 $X, Y$ 相互独立且均服从参数为 1 的指数分布，令 $Z = X - Y$。求 $Z$ 的密度，并判断 $X$ 与 $Z$ 是否不相关、是否独立。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：求差的密度 → 用卷积公式变形 $f_{X-Y}(z) = \int f_X(z+y) f_Y(y)\, dy$ → 分 $z$ 正负讨论积分限 → 识别为拉普拉斯分布；判断相关性 → 算 $\text{Cov}(X, Z)$，非零则相关且不独立。

**为何用此公式**：随机变量差的密度公式 $f_{X-Y}(z) = \int f_X(z+y) f_Y(y)\, dy$ 是卷积公式的变形，适用于独立随机变量之差；协方差 $\text{Cov}(X, Z) = E(XZ) - E(X)E(Z)$ 是相关性判定的标准工具，$\text{Cov} \neq 0$ 直接推出相关且不独立。

**推导过程**：

1. 第一步：$X, Y \sim E(1)$ 独立，$f_X(x) = e^{-x}$（$x > 0$），$f_Y(y) = e^{-y}$（$y > 0$）← 依据：指数分布密度
2. 第二步：写出差的密度公式 $f_Z(z) = \int_{-\infty}^{+\infty} f_X(z+y) \cdot f_Y(y)\, dy$ ← 依据：随机变量差的密度（卷积变形）
3. 第三步（$z \geq 0$）：需 $z + y > 0$ 即 $y > -z$，又 $y > 0$，故 $y > 0$。$f_Z(z) = \int_0^{+\infty} e^{-(z+y)} \cdot e^{-y}\, dy = e^{-z} \int_0^{+\infty} e^{-2y}\, dy = \dfrac{e^{-z}}{2}$ ← 依据：积分限确定 + 指数积分 $\int_0^{+\infty} e^{-2y}\, dy = 1/2$
4. 第四步（$z < 0$）：需 $z + y > 0$ 即 $y > -z > 0$。$f_Z(z) = \int_{-z}^{+\infty} e^{-(z+y)} \cdot e^{-y}\, dy = e^{-z} \int_{-z}^{+\infty} e^{-2y}\, dy = e^{-z} \cdot \dfrac{e^{2z}}{2} = \dfrac{e^z}{2}$ ← 依据：积分限确定 + 指数积分
5. 第五步：合并 $f_Z(z) = \dfrac{1}{2} e^{-|z|}$（拉普拉斯分布）← 依据：分段合并 + 绝对值表达
6. 第六步：判断相关性。$E(X) = 1$，$E(Z) = E(X) - E(Y) = 0$ ← 依据：期望线性性
7. 第七步：$E(XZ) = E\!\big[X(X - Y)\big] = E(X^2) - E(XY)$。由独立 $E(XY) = E(X) \cdot E(Y) = 1$；$E(X^2) = D(X) + [E(X)]^2 = 1 + 1 = 2$ ← 依据：独立性 + 方差-期望关系
8. 第八步：$E(XZ) = 2 - 1 = 1$。$\text{Cov}(X, Z) = E(XZ) - E(X) \cdot E(Z) = 1 - 1 \times 0 = 1 \neq 0$ ← 依据：协方差定义
9. 第九步：$\text{Cov} \neq 0 \implies$ 相关 $\implies$ 不独立 ← 依据：相关则必不独立（逆否命题）

**关键步骤说明**：$Z = X - Y$ 的密度需分 $z$ 正负讨论积分限；相关性用协方差判定，$\text{Cov} \neq 0$ 即相关，相关必不独立。直观上 $Z = X - Y$ 含 $X$，二者必然不独立。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **卷积积分限不分段**：直接套 $f_X(z+y)$ 不讨论 $z$ 正负 → 正确做法：$z \geq 0$ 时 $y > 0$，$z < 0$ 时 $y > -z$，必须分段讨论。
2. **$\text{Cov}$ 计算漏项**：$E(XZ)$ 展开时漏算 $E(XY)$ 或 $E(X^2)$ → 正确做法：$E(XZ) = E(X^2) - E(XY)$，两项都不能少。
3. **混淆"不相关"与"独立"**：以为不相关就独立 → 正确做法：独立 $\implies$ 不相关，但不相关不一定独立（除非联合正态）；本题 $\text{Cov} \neq 0$ 直接判定相关且不独立。
:::

:::callout{kind=note label="知识卡片：卷积公式与拉普拉斯分布"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 卷积公式（和） | $f_{X+Y}(z) = \displaystyle\int f_X(x) f_Y(z - x)\, dx$ | 独立随机变量 |
| 卷积公式（差） | $f_{X-Y}(z) = \displaystyle\int f_X(z+y) f_Y(y)\, dy$ | 独立随机变量 |
| 拉普拉斯分布 | $f(z) = \dfrac{1}{2} e^{-\|z\|}$ | 均值 0，方差 2 |
| 不相关 | $\text{Cov}(X, Z) = 0$ 即 $E(XZ) = E(X)E(Z)$ | 任意两随机变量 |
| 独立 $\implies$ 不相关 | 独立则 $\text{Cov} = 0$ | 任意两随机变量 |
| 相关 $\implies$ 不独立 | $\text{Cov} \neq 0$ 则必不独立 | 逆否命题 |

**概念辨析**：
- 独立 $\implies$ 不相关，但不相关不一定独立（除非联合正态分布）。
- 相关 $\implies$ 不独立（逆否），故 $\text{Cov} \neq 0$ 可直接判定不独立，无需进一步验证。
:::

:::callout{kind=tip label="结论速记"}
两个独立指数分布之差服从拉普拉斯分布 $f_Z(z) = \dfrac{1}{2} e^{-|z|}$；$\text{Cov}(X, Z) \neq 0$ 则相关且不独立。

**口诀**：指数差得拉普拉斯，协方差非零必相关。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"独立分布之差" + "判断相关/独立" → 联想卷积分段 + 协方差判定
- **关联考点**：与卷积公式（和的密度）对比；与联合正态的特殊性质（不相关 $\iff$ 独立）对比
- **复用场景**：所有独立随机变量差的分布题，所有相关性判定题
:::

## 七、（10 分）

### 第16题

:::callout{kind=note label="题目"}
设 $X_1, \ldots, X_n$ 独立同分布，$E(X_i) = \mu$，$D(X_i) = \sigma^2$。用中心极限定理近似求

$$P\!\left(\sum_{i=1}^{n} X_i > n\mu\right).$$
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：独立同分布 + 求和概率 → 林德伯格-列维中心极限定理 → 标准化为标准正态 → 阈值恰为均值时由对称性得 $1/2$。

**为何用此公式**：林德伯格-列维 CLT 适用于"独立同分布 + 方差有限"情形，将和的分布近似为正态，是求大样本概率的标准工具。阈值 $n\mu$ 恰为和的期望，标准化后阈值为 0，由标准正态对称性 $P(Z > 0) = 1/2$。

**推导过程**：

1. 第一步：由 $X_i$ 独立同分布，$E(X_i) = \mu$，$D(X_i) = \sigma^2$ ← 依据：题给条件
2. 第二步：求和的期望与方差 $E\!\left(\sum X_i\right) = n\mu$，$D\!\left(\sum X_i\right) = n\sigma^2$（方差可加需独立）← 依据：期望线性性 + 方差可加性
3. 第三步：由林德伯格-列维 CLT $\dfrac{\sum X_i - n\mu}{\sigma \sqrt{n}} \xrightarrow{d} N(0, 1)$（$n$ 充分大）← 依据：林德伯格-列维中心极限定理
4. 第四步：标准化所求概率 $P\!\left(\sum X_i > n\mu\right) = P\!\left(\dfrac{\sum X_i - n\mu}{\sigma \sqrt{n}} > 0\right)$ ← 依据：等价变形（同减 $n\mu$ 同除 $\sigma\sqrt{n}$，不改变不等号方向）
5. 第五步：由 CLT 近似 $\approx 1 - \Phi(0) = 1 - \dfrac{1}{2} = \dfrac{1}{2}$ ← 依据：标准正态分布函数 + 对称性 $\Phi(0) = 1/2$

**关键步骤说明**：阈值恰为均值 $n\mu$ 时，标准化后阈值为 0，由标准正态对称性 $P(Z > 0) = 1/2$。$\Phi(0) = 1/2$ 由标准正态关于原点对称直接给出。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **标准化时漏除 $\sigma\sqrt{n}$**：直接写 $P\!\left(\sum X_i > n\mu\right) \approx 1 - \Phi(0)$ 而不标准化 → 正确做法：必须先标准化为 $\dfrac{\sum X_i - n\mu}{\sigma\sqrt{n}}$ 再用 CLT。
2. **混淆 CLT 与切比雪夫**：用切比雪夫不等式给出 $P \geq 1 - 1/n$ 的界 → 正确做法：CLT 给出近似值 $1/2$，切比雪夫给出的是不等式界，精度与用途不同。
3. **忽视阈值恰为均值的对称性**：不知 $\Phi(0) = 1/2$ 而查表或留作 $\Phi(0)$ → 正确做法：标准正态在 0 处的分布函数值为 $1/2$，由对称性直接给出。
:::

:::callout{kind=note label="知识卡片：中心极限定理"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 林德伯格-列维 CLT | $\dfrac{\sum X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$ | 独立同分布 + 方差有限 |
| 棣莫弗-拉普拉斯 CLT | $\dfrac{X - np}{\sqrt{np(1-p)}} \xrightarrow{d} N(0,1)$ | $X \sim B(n, p)$ |
| 李雅普诺夫 CLT | 独立（不必同分布）+ 李雅普诺夫条件 | 独立非同分布 |
| 应用条件 | $n$ 充分大（一般 $n \geq 30$） | 方差有限 |
| 对称性结论 | 阈值 = 均值时 $P(\text{超过均值}) \approx \dfrac{1}{2}$ | 标准正态对称 |

**概念辨析**：
- CLT 给出"近似值"，切比雪夫给出"不等式界"，前者精度高但需 $n$ 充分大。
- 林德伯格-列维要求同分布，李雅普诺夫允许非同分布但需额外条件。
:::

:::callout{kind=tip label="结论速记"}
CLT：$\dfrac{\sum X_i - n\mu}{\sigma\sqrt{n}} \approx N(0,1)$；阈值恰为均值时概率 $\approx \dfrac{1}{2}$。

**口诀**：独立同分林德伯格，标准化后查正态，阈值等均值得一半。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"独立同分布" + "求和概率" + "$n$ 充分大" → 联想林德伯格-列维 CLT
- **关联考点**：与棣莫弗-拉普拉斯 CLT（二项分布特例）关联；与大数定律对比
- **复用场景**：所有大样本求和/均值的概率近似题，包括保险理赔、抽样检验
:::

## 八、（13 分）

### 第17题

:::callout{kind=note label="题目"}
设总体 $X$ 的密度为 $f(x; \theta) = \dfrac{x}{\theta^2}$，$0 < x < \sqrt{2}\,\theta$，其中 $\theta > 0$。求 $\theta$ 的矩估计量和极大似然估计量，并判断矩估计量是否无偏。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：参数估计三件套 → 矩估计（令 $E(X) = \bar{X}$ 解方程）→ MLE（写似然函数，分析单调性取支撑域下界）→ 无偏性（验证 $E(\hat{\theta}) = \theta$）。

**为何用此公式**：矩估计用一阶矩方程 $E(X) = \bar{X}$；MLE 当似然 $L(\theta) \propto \theta^{-2n}$ 关于 $\theta$ 严格递减时，求导令零无解，极值在支撑域边界取得，取下界 $\max X_i / \sqrt{2}$；无偏性用定义 $E(\hat{\theta}) = \theta$ 验证，依赖 $E(\bar{X}) = E(X)$ 的线性性。

**推导过程**：

1. 第一步：验证密度归一性 $\int_0^{\sqrt{2}\theta} \dfrac{x}{\theta^2}\, dx = \dfrac{1}{\theta^2} \cdot \dfrac{x^2}{2}\bigg|_0^{\sqrt{2}\theta} = \dfrac{2\theta^2}{2\theta^2} = 1 \quad \checkmark$ ← 依据：密度归一性验证
2. 第二步：求 $E(X) = \int_0^{\sqrt{2}\theta} x \cdot \dfrac{x}{\theta^2}\, dx = \dfrac{1}{\theta^2} \cdot \dfrac{x^3}{3}\bigg|_0^{\sqrt{2}\theta} = \dfrac{2\sqrt{2}\,\theta^3}{3\theta^2} = \dfrac{2\sqrt{2}}{3}\,\theta$ ← 依据：期望定义 + 积分计算
3. 第三步：矩估计令 $E(X) = \bar{X}$，即 $\dfrac{2\sqrt{2}}{3}\theta = \bar{X}$，解得 $\hat{\theta}_M = \dfrac{3}{2\sqrt{2}}\,\bar{X}$ ← 依据：矩估计法（一阶矩方程）
4. 第四步：写似然函数 $L(\theta) = \prod_{i=1}^{n} \dfrac{X_i}{\theta^2} = \dfrac{\prod X_i}{\theta^{2n}}$，约束 $0 < X_i < \sqrt{2}\,\theta\ \forall i$，即 $\theta > \dfrac{\max X_i}{\sqrt{2}}$ ← 依据：似然函数定义 + 支撑域约束
5. 第五步：分析单调性 $L(\theta) \propto \theta^{-2n}$ 关于 $\theta$ 严格递减 ← 依据：幂函数单调性（指数 $-2n < 0$）
6. 第六步：MLE 取下界 $L$ 在 $\theta$ 取最小允许值时最大，$\hat{\theta}_L = \dfrac{\max_{1 \leq i \leq n} X_i}{\sqrt{2}}$ ← 依据：单调递减函数在区间左端点取最大值
7. 第七步：无偏性验证 $E(\hat{\theta}_M) = \dfrac{3}{2\sqrt{2}} \cdot E(\bar{X}) = \dfrac{3}{2\sqrt{2}} \cdot E(X) = \dfrac{3}{2\sqrt{2}} \cdot \dfrac{2\sqrt{2}}{3}\,\theta = \theta$ ← 依据：$E(\bar{X}) = E(X)$（样本均值期望等于总体期望）+ 矩估计表达式
8. 第八步：结论 $\hat{\theta}_M$ 是 $\theta$ 的**无偏估计量** ← 依据：无偏性定义 $E(\hat{\theta}) = \theta$

**关键步骤说明**：MLE 关键在于识别 $L(\theta) \propto \theta^{-2n}$ 关于 $\theta$ 单调递减，求导令零无解，故取支撑域下界 $\max X_i / \sqrt{2}$；矩估计无偏性源于 $E(\bar{X}) = E(X)$ 的线性性，系数恰好约去。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **MLE 求导失效不知变通**：对 $L \propto \theta^{-2n}$ 求导令零得无解而卡住 → 正确做法：当似然单调时，极值在支撑域边界取得，本题取下界 $\max X_i / \sqrt{2}$。
2. **似然支撑域约束遗漏**：忽略 $0 < X_i < \sqrt{2}\theta$ 对 $\theta$ 的约束 → 正确做法：$\theta$ 必须 $> \max X_i / \sqrt{2}$，否则似然为 0。
3. **无偏性验证跳步**：直接说"显然无偏" → 正确做法：必须严格计算 $E(\hat{\theta}_M) = \dfrac{3}{2\sqrt{2}} \cdot E(\bar{X}) = \theta$，展示 $E(\bar{X}) = E(X)$ 的步骤。
:::

:::callout{kind=note label="知识卡片：矩估计与极大似然估计"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 矩估计 | 令 $E(X) = \bar{X}$（或更高阶矩） | 任意总体 |
| MLE 求导法 | $\dfrac{\partial \ln L}{\partial \theta} = 0$ | 似然可导且内部有极值 |
| MLE 单调法 | $L$ 单调时取支撑域边界 | 似然单调递增/递减 |
| MLE 不变性 | $\widehat{g(\theta)} = g(\hat{\theta})$ | $g$ 连续 |
| 无偏性 | $E(\hat{\theta}) = \theta$ | 任意估计量 |

**概念辨析**：
- MLE 求导法适用于似然可导且内部有极值；当似然单调时求导失效，必须取支撑域边界。
- 矩估计不一定无偏，MLE 也不一定无偏，需逐题验证；本题矩估计恰好无偏。
:::

:::callout{kind=tip label="结论速记"}
矩估计令 $E(X) = \bar{X}$ 得 $\hat{\theta}_M = \dfrac{3}{2\sqrt{2}}\,\bar{X}$；MLE 当似然关于 $\theta$ 递减时取下界 $\hat{\theta}_L = \dfrac{\max X_i}{\sqrt{2}}$；无偏性验证 $E(\hat{\theta}_M) = \theta$。

**口诀**：矩估等矩方程，似然单调取边界，无偏验证算期望。
:::
