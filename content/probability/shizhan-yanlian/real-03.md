## 一、单项选择题（每题 3 分，共 30 分）

### 第1题

:::callout{kind=note label="题目"}
疫情期间，组织部门拟派甲、乙、丙、丁四名志愿者参加周一至周五的公共服务工作，每天派一人，每人至少工作一天，则甲连续工作两天的概率是（　　）

A. $\dfrac{1}{10}$　　B. $\dfrac{1}{5}$　　C. $\dfrac{1}{4}$　　D. $\dfrac{1}{8}$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：读题识别"5天分给4人、每人至少1天"为分组分配问题，"甲连续工作2天"为带连续约束的有利事件计数，采用古典概型 $P=\dfrac{\text{有利}}{\text{总数}}$。

**为何用此公式**：题目限定每人至少工作一天，样本点等可能且可数，适用古典概型；"连续"约束需在计数阶段处理，不能事后修正。

**推导过程**：

1. 第一步：确定分配结构 ← 依据：5天分4人每人≥1天，由鸽巢原理恰1人工作2天、其余3人各1天
2. 第二步：计算总方案数 $N=\dbinom{4}{1}\dbinom{5}{2}\cdot 3!=4\times 10\times 6=240$ ← 依据：先选工作2天的人（4选1）、再选该人的2天（5选2，不必连续）、剩余3天全排列给3人
3. 第三步：计算甲连续工作2天的有利方案数 ← 依据：相邻二日段 $\{1,2\},\{2,3\},\{3,4\},\{4,5\}$ 共4段，剩余3天排列给乙丙丁 $3!=6$
4. 第四步：$n=4\times 6=24$ ← 依据：乘法原理
5. 第五步：$P=\dfrac{24}{240}=\dfrac{1}{10}$ ← 依据：古典概型公式

**选项分析**：

- **A（正确）**：$\dfrac{1}{10}$，按"选人-选天-排列"三步计数再求比值，与上述推导一致
- **B（错误）**：$\dfrac{1}{5}$ 对应将相邻段数误算为8或漏除以总方案数中的 $\dbinom{5}{2}$ 组合因子
- **C（错误）**：$\dfrac{1}{4}$ 对应直接取甲工作2天的概率 $\dbinom{4}{1}^{-1}=\dfrac{1}{4}$，忽略了"连续"约束
- **D（错误）**：$\dfrac{1}{8}$ 对应将连续段数取5或将剩余3天排列数误计为3的错误
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **连续约束遗漏**：计算有利事件时把甲的2天当作 $\dbinom{5}{2}=10$ 种任意组合，未限制为相邻 → 正确做法：只取4个相邻段 $\{1,2\},\{2,3\},\{3,4\},\{4,5\}$
2. **总方案数漏因子**：先给甲选2天再分配其余3天时，漏乘"选工作2天的人"的 $\dbinom{4}{1}=4$ → 正确做法：按"选人→选天→排列"三步完整相乘得 $N=240$
3. **概率方向混淆**：把 $P(\text{甲工作2天})=\dfrac{1}{4}$ 当作所求 → 正确做法：所求为 $P(\text{甲连续工作2天}\mid\text{每人至少1天})$，须在限定样本空间内重新计数
:::

:::callout{kind=note label="知识卡片：分组排列与连续约束计数"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 分配结构 | 5天分4人每人≥1天，恰1人工作2天 | 鸽巢原理 |
| 总方案数 | $\dbinom{4}{1}\dbinom{5}{2}\cdot 3!=240$ | 古典概型等可能 |
| 连续2天段数 | 4段（$\{1,2\},\{2,3\},\{3,4\},\{4,5\}$） | 5天线性排列 |
| 有利方案数 | $4\times 3!=24$ | 甲固定为工作2天者 |
| 古典概型 | $P=\dfrac{\text{有利}}{\text{总数}}$ | 样本点有限等可能 |

**概念辨析**：
- "连续"约束在计数阶段处理：相邻段数为 $n-1$（$n$ 天线性），而非 $\dbinom{n}{2}$
- "每人至少1天"≠"每人恰1天"：前者允许1人工作多天，需先确定多工作者的身份
:::

:::callout{kind=tip label="结论速记"}
"每人至少1天" $\Rightarrow$ 恰1人工作2天 $\Rightarrow$ 总数 $\dbinom{4}{1}\dbinom{5}{2}\cdot 3!=240$；甲连续2天 $\Rightarrow 4\cdot 3!=24$，概率 $\dfrac{1}{10}$。

**口诀**：分组分配三步走，选人选天再排列；连续约束数相邻，古典概型求比值。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"每人至少X天/连续Y天"→联想分组分配计数+相邻段数法
- **关联考点**：古典概型、排列组合、鸽巢原理；与"圆环染色"（填空第5题）同属计数类
- **复用场景**：值班分配、座位安排、信封投放等"限定结构"的古典概型题
:::

### 第2题

:::callout{kind=note label="题目"}
已知三个随机事件 $A, B, C$，若 $P(A)=P(B)=P(C)=\dfrac{1}{8}$，$P(AB)=0$，$P(AC)=P(BC)=\dfrac{1}{16}$，则 $A, B, C$ 中恰有一个发生的概率为（　　）

A. $\dfrac{1}{8}$　　B. $\dfrac{1}{16}$　　C. $0$　　D. $\dfrac{1}{32}$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：读题识别"恰有一个发生"为仅 $A$、仅 $B$、仅 $C$ 三者之和，需用包含排斥原理的展开式逐项计算；先由 $P(AB)=0$ 推出 $P(ABC)=0$。

**为何用此公式**：仅 $A$ 发生即 $A\bar{B}\bar{C}$，其概率用 $P(A)-P(AB)-P(AC)+P(ABC)$ 展开，依据是集合差的容斥恒等式。

**推导过程**：

1. 第一步：由 $P(AB)=0$ 及 $ABC\subset AB$ 推出 $P(ABC)=0$ ← 依据：概率的单调性（子事件概率不超过母事件）
2. 第二步：$P(\text{仅 }A)=P(A)-P(AB)-P(AC)+P(ABC)=\dfrac{1}{8}-0-\dfrac{1}{16}+0=\dfrac{1}{16}$ ← 依据：容斥展开
3. 第三步：$P(\text{仅 }B)=P(B)-P(AB)-P(BC)+P(ABC)=\dfrac{1}{8}-0-\dfrac{1}{16}+0=\dfrac{1}{16}$ ← 依据：同理
4. 第四步：$P(\text{仅 }C)=P(C)-P(AC)-P(BC)+P(ABC)=\dfrac{1}{8}-\dfrac{1}{16}-\dfrac{1}{16}+0=0$ ← 依据：同理
5. 第五步：$P(\text{恰一个发生})=\dfrac{1}{16}+\dfrac{1}{16}+0=\dfrac{1}{8}$ ← 依据：三事件互斥（仅 $A$、仅 $B$、仅 $C$ 两两不相交）

**选项分析**：

- **A（正确）**：$\dfrac{1}{8}$，三项相加与上述推导一致
- **B（错误）**：$\dfrac{1}{16}$ 对应只算了仅 $A$ 或仅 $B$ 一项，遗漏其余部分
- **C（错误）**：$0$ 对应把仅 $C$ 的概率当作所求，忽略了 $A$、$B$ 单独发生的贡献
- **D（错误）**：$\dfrac{1}{32}$ 对应计算时多减了 $P(AC)$ 或 $P(BC)$ 一次
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **遗漏 $P(ABC)=0$ 的推导**：直接代入数据时未利用 $ABC\subset AB$ → 正确做法：先由 $P(AB)=0$ 及单调性得 $P(ABC)=0$
2. **仅 $C$ 计算漏减**：仅 $C$ 公式为 $P(C)-P(AC)-P(BC)+P(ABC)$，漏减 $P(BC)$ 得 $\dfrac{1}{16}$ → 正确做法：$P(AC)=P(BC)=\dfrac{1}{16}$ 均需减去，结果为0
3. **只取一项当答案**：把仅 $A$（或仅 $B$）的概率 $\dfrac{1}{16}$ 当作"恰有一个发生" → 正确做法：三个互斥事件相加
:::

:::callout{kind=note label="知识卡片：恰有一个发生的概率公式"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 仅 $A$ 发生 | $P(A\bar{B}\bar{C})=P(A)-P(AB)-P(AC)+P(ABC)$ | 容斥恒等式 |
| 仅 $B$ 发生 | $P(\bar{A}B\bar{C})=P(B)-P(AB)-P(BC)+P(ABC)$ | 同上 |
| 仅 $C$ 发生 | $P(\bar{A}\bar{B}C)=P(C)-P(AC)-P(BC)+P(ABC)$ | 同上 |
| 恰一个发生 | 三者之和 | 仅 $A$、仅 $B$、仅 $C$ 互斥 |
| 单调性推论 | $P(AB)=0\Rightarrow P(ABC)=0$ | $ABC\subset AB$ |

**概念辨析**：
- "恰有一个发生"≠"至少一个发生"：前者要求另两个不发生，后者不要求
- 容斥展开中 $+P(ABC)$ 项不可省：减去 $P(AB)$、$P(AC)$ 时多减了 $ABC$ 部分，需加回
:::

:::callout{kind=tip label="结论速记"}
"恰有一个发生" = 仅 $A$ + 仅 $B$ + 仅 $C$，逐项用 $P(A)-P(AB)-P(AC)+P(ABC)$ 展开，注意 $P(AB)=0 \Rightarrow P(ABC)=0$。

**口诀**：恰有一个三分项，容斥展开加回交；AB为零推ABC，逐项相加得答案。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"恰有一个发生/仅X发生"→联想容斥展开式 $P(A)-P(AB)-P(AC)+P(ABC)$
- **关联考点**：包含排斥原理、事件关系与概率单调性；与第6题二维正态象限分解同属事件分解类
- **复用场景**：电路通断、产品合格组合、三事件独立性判定中的"恰k个发生"问题
:::

### 第3题

:::callout{kind=note label="题目"}
为了了解疫情期间的心理需求，心理健康辅导员设计了一份调查问卷，问卷有两个问题：（1）你的生日在 7 月 1 日之前吗？（2）你需要心理疏导吗？被调查者在保密的情况下抛掷一枚质地均匀的骰子，当出现 1 点或 2 点时回答问题（1），否则回答问题（2）。某校 7800 名大一学生参加了该问卷调查，全部为有效答卷，发现有 1390 人回答"是"。由此可估计该校大一学生需要心理疏导的学生人数最可能是（　　）

A. 180　　B. 135　　C. 210　　D. 230
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：读题识别为随机化应答技术（RRT），"回答是"由两路构成（答问题1且生日在7月1日前、答问题2且需心理疏导），用全概率公式分解后由频率反解 $p$。

**为何用此公式**：回答哪道题由骰子随机决定，两路互斥且概率已知，符合全概率公式适用条件；生日均匀分布于一年，故问题1答"是"的概率近似 $\dfrac{1}{2}$。

**推导过程**：

1. 第一步：确定两路概率 ← 依据：骰子出1或2点概率 $\dfrac{2}{6}=\dfrac{1}{3}$（答问题1），出3-6点概率 $\dfrac{4}{6}=\dfrac{2}{3}$（答问题2）
2. 第二步：问题1答"是"概率为 $\dfrac{1}{2}$ ← 依据：生日在7月1日前约占全年一半
3. 第三步：设问题2答"是"概率（需心理疏导比例）为 $p$ ← 依据：待估参数
4. 第四步：全概率公式 $P(\text{是})=\dfrac{1}{3}\times\dfrac{1}{2}+\dfrac{2}{3}\times p=\dfrac{1}{6}+\dfrac{2p}{3}$ ← 依据：两路加权
5. 第五步：由频率估计概率 $\dfrac{1390}{7800}=\dfrac{1}{6}+\dfrac{2p}{3}$ ← 依据：大数定律
6. 第六步：$\dfrac{2p}{3}=\dfrac{1390}{7800}-\dfrac{1300}{7800}=\dfrac{90}{7800}=\dfrac{9}{780}$，$p=\dfrac{9}{780}\times\dfrac{3}{2}=\dfrac{9}{520}$ ← 依据：解方程
7. 第七步：人数 $=7800\times\dfrac{9}{520}=15\times 9=135$ ← 依据：比例乘总数

**选项分析**：

- **A（正确）**：B项135，与上述推导一致
- **A（错误）**：180 对应将回答"是"中问题1的部分也计入心理疏导人数（即 $7800\times\dfrac{1}{6}=130$ 误加）
- **C（错误）**：210 对应计算时混淆骰子点数对应的问题分配比例（如取 $\dfrac{1}{2}$ 与 $\dfrac{1}{2}$）
- **D（错误）**：230 对应误用 $\dfrac{1}{2}$ 代替 $\dfrac{1}{3}$ 作为回答问题1的概率
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **全概率公式漏加权**：直接用 $\dfrac{1390}{7800}$ 当作 $p$ → 正确做法：须减去问题1贡献的 $\dfrac{1}{6}$ 再除以 $\dfrac{2}{3}$
2. **生日概率取错**：把生日在7月1日前的概率取为 $\dfrac{1}{365}$ 或 $\dfrac{181}{365}$ → 正确做法：题意"7月1日之前"约占半年，近似取 $\dfrac{1}{2}$
3. **问题分配比例取反**：把答问题1的概率取为 $\dfrac{2}{3}$、答问题2取为 $\dfrac{1}{3}$ → 正确做法：1或2点共2种，概率 $\dfrac{2}{6}=\dfrac{1}{3}$
:::

:::callout{kind=note label="知识卡片：随机化应答技术（RRT）"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 答问题1概率 | $\dfrac{2}{6}=\dfrac{1}{3}$ | 骰子出1或2点 |
| 答问题2概率 | $\dfrac{4}{6}=\dfrac{2}{3}$ | 骰子出3-6点 |
| 问题1答"是"概率 | $\dfrac{1}{2}$ | 生日均匀分布于一年 |
| 问题2答"是"概率 | $p$ | 待估的心理疏导比例 |
| 全概率公式 | $P(\text{是})=\dfrac{1}{3}\cdot\dfrac{1}{2}+\dfrac{2}{3}\cdot p$ | 两路互斥加权 |

**概念辨析**：
- RRT的核心是"答题随机化"保护隐私，使个体回答不直接暴露问题归属
- 频率估计概率依据大数定律，要求样本量足够大（本题7800符合）
:::

:::callout{kind=tip label="结论速记"}
随机化应答 $\Rightarrow$ 全概率公式分解"是"的概率 $\Rightarrow$ 由频率反解 $p$ $\Rightarrow$ 人数 $=7800p=135$。

**口诀**：骰子分流两路答，全概率分是和非；频率代概解出p，人数总数乘比例。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"随机化应答/骰子决定答题/保密调查"→联想全概率公式两路分解
- **关联考点**：全概率公式、频率与概率的关系；与第3大题超几何+全概率同属全概率应用类
- **复用场景**：双盲实验、敏感问题调查、分层抽样推断等"随机分流+反解参数"题型
:::

### 第4题

:::callout{kind=note label="题目"}
已知二维随机变量 $(X,Y)$ 的概率分布函数为 $F(x,y)$，概率密度函数为

$$f(x,y) = \begin{cases} 2, & 0 \leq y \leq x \leq 1 \\ 0, & \text{其它} \end{cases}$$

则 $F\!\left(\dfrac{1}{2}, \dfrac{1}{4}\right)=$（　　）

A. $\dfrac{1}{8}$　　B. $\dfrac{3}{16}$　　C. $\dfrac{3}{8}$　　D. $\dfrac{3}{32}$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：读题识别 $F(a,b)=P(X\leq a,Y\leq b)$ 为联合分布函数定义，需在密度非零区域 $0\leq y\leq x\leq 1$ 上对 $f$ 积分；关键是确定积分限。

**为何用此公式**：联合分布函数由密度积分定义 $F(x,y)=\int_{-\infty}^{y}\int_{-\infty}^{x}f(u,v)\,du\,dv$；密度非零区域为三角形 $0\leq y\leq x\leq 1$，需用平行于坐标轴的直线截取。

**推导过程**：

1. 第一步：写出定义 $F\!\left(\dfrac{1}{2},\dfrac{1}{4}\right)=P\!\left(X\leq\dfrac{1}{2},Y\leq\dfrac{1}{4}\right)=\int_{0}^{1/4}\int_{y}^{1/2}2\,dx\,dy$ ← 依据：联合分布函数定义
2. 第二步：定积分限 ← 依据：密度非零要求 $0\leq y\leq x$，故固定 $y\in[0,\dfrac{1}{4}]$ 时 $x\in[y,\dfrac{1}{2}]$（且 $\dfrac{1}{4}<\dfrac{1}{2}$ 故 $x$ 上限为 $\dfrac{1}{2}$）
3. 第三步：内层积分 $\int_{y}^{1/2}2\,dx=2\!\left(\dfrac{1}{2}-y\right)=1-2y$ ← 依据：定积分计算
4. 第四步：外层积分 $\int_{0}^{1/4}(1-2y)\,dy=\left[y-y^{2}\right]_{0}^{1/4}=\dfrac{1}{4}-\dfrac{1}{16}=\dfrac{3}{16}$ ← 依据：幂函数积分

**选项分析**：

- **B（正确）**：$\dfrac{3}{16}$，与上述二重积分一致
- **A（错误）**：$\dfrac{1}{8}$ 对应将积分区域取为 $[0,\dfrac{1}{4}]\times[0,\dfrac{1}{4}]$ 正方形，漏掉了 $x\in[y,\dfrac{1}{4}]$ 之外的部分
- **C（错误）**：$\dfrac{3}{8}$ 对应把 $x$ 上限取为1而非 $\dfrac{1}{2}$
- **D（错误）**：$\dfrac{3}{32}$ 对应漏乘密度2或积分限取错
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **积分区域取为正方形**：把 $x$ 范围取为 $[0,\dfrac{1}{4}]$ 忽略了 $y\leq x$ 约束 → 正确做法：固定 $y$ 后 $x\in[y,\dfrac{1}{2}]$
2. **$x$ 下限取0**：由 $0\leq y\leq x$ 知 $x$ 下限应为 $y$ 而非0 → 正确做法：内层积分 $\int_{y}^{1/2}$
3. **$x$ 上限取1**：误把密度非零区域上界1当作 $x$ 上限 → 正确做法：$x$ 上限由 $X\leq\dfrac{1}{2}$ 决定，取 $\dfrac{1}{2}$
:::

:::callout{kind=note label="知识卡片：联合分布函数与密度积分"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 联合分布函数 | $F(x,y)=\int_{-\infty}^{y}\int_{-\infty}^{x}f(u,v)\,du\,dv$ | 连续型随机变量 |
| 三角区域积分 | $F(a,b)=\int_{0}^{b}\int_{y}^{\min(a,1)}f\,dx\,dy$ | $0\leq y\leq x\leq 1$，$b\leq a$ |
| 积分限确定 | 先画密度非零区域，再用平行于坐标轴的直线截取 | 任意区域 |
| 内层$x$下限 | $y$（由 $y\leq x$） | 三角区域 |

**概念辨析**：
- 联合分布函数 $F(a,b)$ 是"左下角"累积概率，积分区域为 $\{X\leq a,Y\leq b\}$ 与密度非零区域的交集
- $F(x,y)$ 与 $f(x,y)$ 关系：$f=\dfrac{\partial^{2}F}{\partial x\partial y}$（连续点处）
:::

:::callout{kind=tip label="结论速记"}
$F(a,b)=\displaystyle\int_{0}^{b}\!\int_{y}^{a} f\, dx\, dy$（三角区域 $0 \leq y \leq x$），关键是内层 $x$ 下限为 $y$ 而非 $0$。

**口诀**：分布函数化二重，先画区域定积分；三角区域x下限，固定y后从y起。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"联合分布函数+密度非零区域"→联想画区域定积分限法
- **关联考点**：联合分布与边缘分布、第4大题二维密度积分；与卷积公式（第6大题）同属二重积分类
- **复用场景**：任意二维连续型随机变量的分布函数计算、区域概率求解

### 第5题

:::callout{kind=note label="题目"}
设随机变量序列 $\{X_i,\, i \geq 1\}$ 独立且都服从标准正态分布，如果常数 $C$ 使

$$\lim_{n \to +\infty} P\!\left\{\frac{C \cdot \displaystyle\sum_{i=1}^{n}(X_i - X_{n+i})^{2} - 2n}{\sqrt{n}} \leq x\right\} = \Phi(x)$$

其中 $\Phi(x)$ 为标准正态分布函数，则 $C=$（　　）

A. $1$　　B. $2$　　C. $\dfrac{1}{2\sqrt{2}}$　　D. $\sqrt{2}$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：读题识别极限分布为 $N(0,1)$，需将 $\sum(X_i-X_{n+i})^{2}$ 化为已知分布（卡方），再用中心极限定理标准化，对比题目形式解出 $C$。

**为何用此公式**：$X_i-X_{n+i}$ 为独立正态之差仍为正态，其平方和为卡方分布的倍数；卡方分布的标准化由 CLT 保证收敛于 $N(0,1)$，依据是林德伯格-列维中心极限定理。

**推导过程**：

1. 第一步：令 $Y_i=X_i-X_{n+i}$ ← 依据：构造新变量
2. 第二步：$Y_i\sim N(0,1+1)=N(0,2)$，$\dfrac{Y_i}{\sqrt{2}}\sim N(0,1)$ ← 依据：独立正态线性组合仍正态，方差可加
3. 第三步：$\sum_{i=1}^{n}Y_i^{2}=2\sum_{i=1}^{n}\!\left(\dfrac{Y_i}{\sqrt{2}}\right)^{2}\sim 2\chi^{2}(n)$ ← 依据：标准正态平方和服从卡方
4. 第四步：$E\!\left[\sum Y_i^{2}\right]=2n$，$D\!\left[\sum Y_i^{2}\right]=2\times 2^{2}\times n=8n$ ← 依据：$\chi^{2}(n)$ 期望 $n$、方差 $2n$，倍数 $2$ 使方差变为 $2\times 4\times n=8n$
5. 第五步：由 CLT $\dfrac{\sum Y_i^{2}-2n}{\sqrt{8n}}\xrightarrow{d}N(0,1)$ ← 依据：独立同分布标准化
6. 第六步：对照题目 $\dfrac{C(\sum Y_i^{2}-2n)}{\sqrt{n}}$，需 $\dfrac{C}{\sqrt{n}}=\dfrac{1}{\sqrt{8n}}$ ← 依据：极限分布唯一性
7. 第七步：$C=\dfrac{1}{\sqrt{8}}=\dfrac{1}{2\sqrt{2}}$ ← 依据：解方程

**选项分析**：

- **C（正确）**：$\dfrac{1}{2\sqrt{2}}$，与上述标准化系数一致
- **A（错误）**：$C=1$ 对应方差归一化系数偏大 $\sqrt{8}$ 倍
- **B（错误）**：$C=2$ 方向错误，应缩小而非放大
- **D（错误）**：$\sqrt{2}$ 对应将 $\sqrt{8}$ 取倒数时算错（误为 $\dfrac{1}{\sqrt{2}}$ 的倒数）
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$Y_i$ 方差算错**：误认为 $D(X_i-X_{n+i})=1-1=0$ → 正确做法：独立变量差的方差等于方差和 $1+1=2$
2. **卡方方差混淆**：把 $2\chi^{2}(n)$ 的方差当作 $2n$（漏乘倍数的平方） → 正确做法：$D(2\chi^{2}(n))=4\times 2n=8n$
3. **标准化系数方向**：把 $C$ 当作放大系数 → 正确做法：$C$ 应使分子除以 $\sqrt{8n}$ 等价，故 $C=\dfrac{1}{\sqrt{8}}$ 为缩小
:::

:::callout{kind=note label="知识卡片：中心极限定理与 $\chi^2$ 分布"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 独立正态差 | $Y_i=X_i-X_{n+i}\sim N(0,2)$ | $X_i,X_{n+i}$ 独立同 $N(0,1)$ |
| 平方和分布 | $\sum Y_i^{2}\sim 2\chi^{2}(n)$ | $Y_i/\sqrt{2}\sim N(0,1)$ |
| 期望与方差 | $E=2n$，$D=8n$ | $\chi^{2}(n)$ 期望 $n$、方差 $2n$ |
| CLT标准化 | $\dfrac{\sum Y_i^{2}-2n}{\sqrt{8n}}\xrightarrow{d}N(0,1)$ | 独立同分布 |
| 标准化原则 | $\dfrac{\text{变量}-E}{\sqrt{D}}\to N(0,1)$ | 林德伯格-列维 |

**概念辨析**：
- $a\chi^{2}(n)$ 的方差为 $a^{2}\cdot 2n$（倍数平方乘原方差），而非 $a\cdot 2n$
- CLT要求独立同分布且方差存在有限，本题 $Y_i^{2}$ 满足
:::

:::callout{kind=tip label="结论速记"}
独立正态差的平方和 $\sim 2\chi^{2}(n)$，方差 $8n$，故 $C = \dfrac{1}{\sqrt{8}} = \dfrac{1}{2\sqrt{2}}$。

**口诀**：正态差仍正态，方差加不加；平方和卡方，倍数平方乘方差；CLT标准化，系数倒数定C。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"极限分布$\Phi(x)$+平方和"→联想卡方分布+CLT标准化
- **关联考点**：中心极限定理、卡方分布性质；与第4大题正态总体样本方差同属卡方应用类
- **复用场景**：独立正态变量函数的极限分布、统计量标准化常数确定
:::

### 第6题

:::callout{kind=note label="题目"}
已知随机变量 $(X,Y)$ 服从二维正态分布 $N(\mu_1, \mu_2, \sigma_1^{2}, \sigma_2^{2}, \rho)$，且 $P(X < \mu_1,\, Y > \mu_2) = \dfrac{1}{3}$，则 $P\{\max(X-\mu_1,\, Y-\mu_2) > 0\} =$（　　）

A. $\dfrac{1}{4}$　　B. $\dfrac{5}{6}$　　C. $\dfrac{1}{6}$　　D. $\dfrac{2}{3}$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：读题识别二维正态中心化后关于原点对称，对角象限概率相等；先用已知象限概率解出同号象限概率，再用 $\max$ 转 $P$ 的等价转化求值。

**为何用此公式**：二维正态密度 $f(x-\mu_1,y-\mu_2)$ 关于 $(\mu_1,\mu_2)$ 中心对称，故 $(X\leq\mu_1,Y\leq\mu_2)$ 与 $(X>\mu_1,Y>\mu_2)$ 概率相等；$\max(U,V)>0$ 等价于 $U>0$ 或 $V>0$，用对立事件转化。

**推导过程**：

1. 第一步：中心化后 $(X-\mu_1,Y-\mu_2)$ 关于原点对称 ← 依据：二维正态密度中心对称性
2. 第二步：对角象限概率相等 $P(X>\mu_1,Y<\mu_2)=P(X<\mu_1,Y>\mu_2)=\dfrac{1}{3}$ ← 依据：中心对称性（180度旋转不变）
3. 第三步：设同号象限概率 $P(X\leq\mu_1,Y\leq\mu_2)=P(X>\mu_1,Y>\mu_2)=a$ ← 依据：中心对称性使两同号象限相等
4. 第四步：由 $P(X\leq\mu_1)=\dfrac{1}{2}$（正态对称）得 $a+\dfrac{1}{3}=\dfrac{1}{2}$，故 $a=\dfrac{1}{6}$ ← 依据：边缘概率与象限分解
5. 第五步：$\max(X-\mu_1,Y-\mu_2)>0\Leftrightarrow X>\mu_1\text{ 或 }Y>\mu_2$ ← 依据：$\max$ 定义
6. 第六步：$P=1-P(X\leq\mu_1,Y\leq\mu_2)=1-\dfrac{1}{6}=\dfrac{5}{6}$ ← 依据：对立事件公式

**选项分析**：

- **B（正确）**：$\dfrac{5}{6}$，与上述对立事件转化一致
- **A（错误）**：$\dfrac{1}{4}$ 对应误用 $\rho=0$ 的独立情形公式 $1-\dfrac{1}{4}=\dfrac{3}{4}$ 计算混乱
- **C（错误）**：$\dfrac{1}{6}$ 对应把 $P(X\leq\mu_1,Y\leq\mu_2)$ 当作所求，方向相反
- **D（错误）**：$\dfrac{2}{3}$ 对应误算为两异号象限之和 $\dfrac{1}{3}+\dfrac{1}{3}$
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **对角象限对称性遗漏**：未利用中心对称性推出 $P(X>\mu_1,Y<\mu_2)=P(X<\mu_1,Y>\mu_2)$ → 正确做法：中心化后180度旋转不变
2. **同号象限未设相等**：把 $P(X\leq\mu_1,Y\leq\mu_2)$ 与 $P(X>\mu_1,Y>\mu_2)$ 当作不同 → 正确做法：中心对称性使二者相等，同为 $a$
3. **$\max$ 转化方向错**：把 $\max>0$ 误转为 $\min>0$ 或 $P(X>\mu_1,Y>\mu_2)$ → 正确做法：$\max(U,V)>0\Leftrightarrow U>0$ 或 $V>0$，用对立事件 $1-P(U\leq 0,V\leq 0)$
:::

:::callout{kind=note label="知识卡片：二维正态分布的象限对称性"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 中心对称性 | $(X-\mu_1,Y-\mu_2)$ 关于原点对称 | 二维正态分布 |
| 对角象限相等 | $P(X<\mu_1,Y>\mu_2)=P(X>\mu_1,Y<\mu_2)$ | 中心对称 |
| 同号象限相等 | $P(X\leq\mu_1,Y\leq\mu_2)=P(X>\mu_1,Y>\mu_2)$ | 中心对称 |
| 边缘对称 | $P(X\leq\mu_1)=\dfrac{1}{2}$ | 正态分布 |
| $\max$ 转化 | $P(\max(U,V)>0)=1-P(U\leq 0,V\leq 0)$ | 对立事件 |

**概念辨析**：
- 二维正态的中心对称性独立于 $\rho$：无论 $\rho$ 是否为0，中心化后均关于原点对称
- $\max(U,V)>0$ 用"或"转化，$\min(U,V)>0$ 用"且"转化，二者不可混淆
:::

:::callout{kind=tip label="结论速记"}
$\max(X-\mu_1, Y-\mu_2)>0 \Leftrightarrow X>\mu_1$ 或 $Y>\mu_2$，概率 $=1-P(X \leq \mu_1, Y \leq \mu_2)=1-\dfrac{1}{6}=\dfrac{5}{6}$。

**口诀**：二维正态中心称，对角同号各相等；max大于零用或，对立事件减一象限。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"二维正态+象限概率/max"→联想中心对称性+对立事件转化
- **关联考点**：二维正态分布性质、事件运算；与第2题容斥分解同属事件关系类
- **复用场景**：二维正态象限分解、$\max/\min$ 函数的概率计算
:::

### 第7题

:::callout{kind=note label="题目"}
设随机变量 $X \sim E\!\left(\dfrac{1}{2}\right)$，其分布函数为 $F(x)$，则 $E\{[F(X)]^{2} + X\} =$（　　）

A. $\dfrac{3}{2}$　　B. $\dfrac{5}{2}$　　C. $\dfrac{7}{3}$　　D. $1$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：读题识别 $F(X)$ 为概率积分变换，连续型随机变量的分布函数作用于自身服从 $U(0,1)$；再用期望线性性拆分求和。

**为何用此公式**：$X$ 为连续型，$F$ 连续严格单调，由概率积分变换 $F(X)\sim U(0,1)$；$U(0,1)$ 的 $k$ 阶矩为 $\dfrac{1}{k+1}$；指数分布 $E(\lambda)$ 期望为 $\dfrac{1}{\lambda}$。

**推导过程**：

1. 第一步：识别 $F(X)\sim U(0,1)$ ← 依据：概率积分变换（$X$ 连续型，$F$ 为其分布函数）
2. 第二步：$E\!\left([F(X)]^{2}\right)=\int_{0}^{1}u^{2}\,du=\dfrac{1}{3}$ ← 依据：$U(0,1)$ 的二阶矩 $E[U^{k}]=\dfrac{1}{k+1}$
3. 第三步：$X\sim E\!\left(\dfrac{1}{2}\right)$，参数 $\lambda=\dfrac{1}{2}$ ← 依据：指数分布参数定义
4. 第四步：$E(X)=\dfrac{1}{\lambda}=\dfrac{1}{1/2}=2$ ← 依据：指数分布期望公式
5. 第五步：$E\{[F(X)]^{2}+X\}=E\!\left([F(X)]^{2}\right)+E(X)=\dfrac{1}{3}+2=\dfrac{7}{3}$ ← 依据：期望线性性

**选项分析**：

- **C（正确）**：$\dfrac{7}{3}$，与上述线性分解一致
- **A（错误）**：$\dfrac{3}{2}$ 对应误用 $E[F(X)]=\dfrac{1}{2}$ 代替 $E[F(X)^{2}]=\dfrac{1}{3}$
- **B（错误）**：$\dfrac{5}{2}$ 对应把 $E(X)$ 误算为1（参数取错为1）
- **D（错误）**：$1$ 对应误算 $E[F(X)^{2}]=0$ 或遗漏 $E(X)$ 项
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **概率积分变换遗忘**：把 $F(X)$ 当作普通函数无法计算 → 正确做法：连续型 $X$ 的 $F(X)\sim U(0,1)$，二阶矩 $\dfrac{1}{3}$
2. **阶数混淆**：把 $E[F(X)^{2}]$ 误算为 $E[F(X)]^{2}=\left(\dfrac{1}{2}\right)^{2}=\dfrac{1}{4}$ → 正确做法：先由 $U(0,1)$ 算 $E[U^{2}]=\dfrac{1}{3}$
3. **指数分布参数取错**：把 $E\!\left(\dfrac{1}{2}\right)$ 的 $\lambda$ 当作2 → 正确做法：$E(\lambda)$ 中 $\lambda=\dfrac{1}{2}$，故 $E(X)=\dfrac{1}{\lambda}=2$
:::

:::callout{kind=note label="知识卡片：概率积分变换与指数分布期望"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 概率积分变换 | $X$ 连续型 $\Rightarrow F(X)\sim U(0,1)$ | $F$ 连续严格单调 |
| $U(0,1)$ 的 $k$ 阶矩 | $E[U^{k}]=\dfrac{1}{k+1}$ | 均匀分布 |
| 指数分布期望 | $E(X)=\dfrac{1}{\lambda}$ | $X\sim E(\lambda)$ |
| 指数分布方差 | $D(X)=\dfrac{1}{\lambda^{2}}$ | $X\sim E(\lambda)$ |
| 期望线性性 | $E(aX+bY)=aE(X)+bE(Y)$ | 任意随机变量 |

**概念辨析**：
- $E[F(X)^{2}]\neq E[F(X)]^{2}$：前者是 $U(0,1)$ 的二阶矩 $\dfrac{1}{3}$，后者为 $\left(\dfrac{1}{2}\right)^{2}=\dfrac{1}{4}$
- 概率积分变换要求 $F$ 连续严格单调，离散型不适用
:::

:::callout{kind=tip label="结论速记"}
连续型 $X \Rightarrow F(X) \sim U(0,1) \Rightarrow E[F(X)^{2}]=\dfrac{1}{3}$；$E\!\left(\dfrac{1}{2}\right) \Rightarrow E(X)=2$，总和 $\dfrac{7}{3}$。

**口诀**：概率积分变换妙，连续型化均匀分布；阶矩分之一加一，线性拆分各自算。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$F(X)$/分布函数作用于自身"→联想概率积分变换 $F(X)\sim U(0,1)$
- **关联考点**：均匀分布矩、指数分布期望、期望线性性；与第3大题全概率同属"分布性质应用"类
- **复用场景**：含 $F(X)$ 的期望计算、随机变量函数的分布推导
:::

### 第8题

:::callout{kind=note label="题目"}
设随机变量 $X, Y$ 独立同分布，则下列叙述错误的是（　　）

A. 当 $X, Y$ 是连续型随机变量时，$P(X < Y) = P(X > Y) = \dfrac{1}{2}$

B. 当 $X, Y$ 是连续型随机变量时，$P(X < Y) = P(X \geq Y)$

C. 当 $X, Y$ 是离散型随机变量时，$P(X = Y) = 0$

D. 当 $X, Y$ 是离散型随机变量时，$P(X < Y) = P(X > Y)$
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：读题识别为独立同分布随机变量比较的对称性问题，需分连续型与离散型两种情形逐一验证四个叙述。

**为何用此公式**：同分布的对称性源于 $(X,Y)\stackrel{d}{=}(Y,X)$（联合分布交换不变），故 $P(X<Y)=P(X>Y)$ 恒成立；$P(X=Y)$ 在连续型为0、离散型一般大于0，依据是密度积分与概率质量函数求和。

**推导过程**：

1. 第一步：连续型情形 $P(X=Y)=0$ ← 依据：连续型随机变量取任一固定值概率为0
2. 第二步：由同分布对称性 $(X,Y)\stackrel{d}{=}(Y,X)$ 得 $P(X<Y)=P(X>Y)$ ← 依据：联合分布交换不变
3. 第三步：$P(X<Y)+P(X=Y)+P(X>Y)=1$，故 $P(X<Y)=P(X>Y)=\dfrac{1}{2}$ ← 依据：概率完备性，A 正确
4. 第四步：$P(X\geq Y)=P(X>Y)+P(X=Y)=\dfrac{1}{2}+0=\dfrac{1}{2}=P(X<Y)$ ← 依据：事件分解，B 正确
5. 第五步：离散型 $P(X=Y)=\sum_{k}P(X=k)^{2}$ 一般大于0（退化分布时为1） ← 依据：独立同分布质量函数求和，C 错误
6. 第六步：离散型同分布对称性仍成立 $P(X<Y)=P(X>Y)$ ← 依据：$(X,Y)\stackrel{d}{=}(Y,X)$ 与连续型无关，D 正确

**选项分析**：

- **C（错误，故为答案）**：离散型 $P(X=Y)=\sum_{k}P(X=k)^{2}$ 一般大于0，退化分布时为1
- **A（正确）**：连续型 $P(X=Y)=0$ + 对称性 $\Rightarrow$ 各 $\dfrac{1}{2}$
- **B（正确）**：$P(X\geq Y)=P(X>Y)+P(X=Y)=\dfrac{1}{2}+0=P(X<Y)$
- **D（正确）**：同分布对称性在离散情形仍成立
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **离散型 $P(X=Y)=0$ 误判**：把连续型结论套到离散型 → 正确做法：离散型 $P(X=Y)=\sum_{k}P(X=k)^{2}$，退化分布时为1
2. **对称性适用范围混淆**：认为对称性只在连续型成立 → 正确做法：$(X,Y)\stackrel{d}{=}(Y,X)$ 与连续/离散无关，对称性恒成立
3. **$P(X\geq Y)$ 与 $P(X>Y)$ 混淆**：忽略 $P(X=Y)$ 的贡献 → 正确做法：$P(X\geq Y)=P(X>Y)+P(X=Y)$
:::

:::callout{kind=note label="知识卡片：独立同分布随机变量比较的性质"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 连续型 $P(X=Y)$ | $0$ | $X,Y$ 连续型 |
| 离散型 $P(X=Y)$ | $\sum_{k}P(X=k)^{2}>0$（一般） | $X,Y$ 离散型 iid |
| 同分布对称性 | $P(X<Y)=P(X>Y)$ | $X,Y$ 同分布（连续或离散） |
| 退化分布 | $P(X=Y)=1$ | $X,Y$ 同为常数 |
| 对称性来源 | $(X,Y)\stackrel{d}{=}(Y,X)$ | 联合分布交换不变 |

**概念辨析**：
- 对称性 $P(X<Y)=P(X>Y)$ 来自同分布，与连续/离散无关；$P(X=Y)=0$ 仅对连续型成立
- 退化分布是离散型特例：$P(X=Y)=1$，$P(X<Y)=P(X>Y)=0$
:::

:::callout{kind=tip label="结论速记"}
同分布 $\Rightarrow P(X<Y)=P(X>Y)$（无论连续离散）；连续型 $\Rightarrow P(X=Y)=0$，离散型 $\Rightarrow P(X=Y)$ 一般 $>0$。

**口诀**：同分布必对称，连续型等号为零；离散型等号非零，退化分布全相等。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"独立同分布+比较大小/相等"→联想对称性 $P(X<Y)=P(X>Y)$ 与 $P(X=Y)$ 的连续/离散差异
- **关联考点**：分布函数性质、连续型与离散型区别；与填空第2题几何分布 $P(X>Y)$ 同属对称性应用
- **复用场景**：iid 变量比较、随机游走对称性、博弈公平性判定
:::

### 第9题

:::callout{kind=note label="题目"}
设 $X_1, X_2, \ldots, X_n$ 为正态总体 $X \sim N(\mu, \sigma^{2})$ 的简单随机样本，其中 $\mu, \sigma^{2}$ 均未知，$\bar{X} = \dfrac{1}{n}\displaystyle\sum_{i=1}^{n} X_i$，$S^{2} = \dfrac{1}{n-1}\displaystyle\sum_{i=1}^{n}(X_i - \bar{X})^{2}$。则 $\mu$ 的置信水平为 0.95 的置信区间的置信下限为（　　）

A. $\bar{X} - \dfrac{S}{\sqrt{n}}\, t_{0.025}(n-1)$　　B. $\bar{X} + \dfrac{S}{\sqrt{n}}\, t_{0.025}(n-1)$

C. $\bar{X} - \dfrac{S}{\sqrt{n}}\, t_{0.05}(n-1)$　　D. $\bar{X} + \dfrac{S}{\sqrt{n}}\, t_{0.05}(n-1)$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：读题识别 $\sigma^{2}$ 未知时正态总体均值 $\mu$ 的置信区间问题，枢轴量为 $T=\dfrac{\bar{X}-\mu}{S/\sqrt{n}}\sim t(n-1)$；置信水平0.95对应 $\alpha=0.05$，双侧用 $\alpha/2=0.025$ 分位数。

**为何用此公式**：$\sigma^{2}$ 未知时不能用 $z$ 枢轴量，改用样本标准差 $S$ 替代，得到 $t$ 分布枢轴量；双侧置信区间的分位数取 $\alpha/2$，单侧取 $\alpha$。

**推导过程**：

1. 第一步：$\sigma^{2}$ 未知，构造枢轴量 $T=\dfrac{\bar{X}-\mu}{S/\sqrt{n}}\sim t(n-1)$ ← 依据：正态总体样本均值与样本方差构造 $t$ 分布定理
2. 第二步：置信水平 $1-\alpha=0.95$，故 $\alpha=0.05$，双侧取 $\alpha/2=0.025$ ← 依据：双侧置信区间定义
3. 第三步：$P\!\left(-t_{0.025}(n-1)\leq\dfrac{\bar{X}-\mu}{S/\sqrt{n}}\leq t_{0.025}(n-1)\right)=0.95$ ← 依据：$t$ 分布对称性与分位数定义
4. 第四步：解不等式得 $\mu\in\!\left[\bar{X}-\dfrac{S}{\sqrt{n}}t_{0.025}(n-1),\;\bar{X}+\dfrac{S}{\sqrt{n}}t_{0.025}(n-1)\right]$ ← 依据：不等式变形
5. 第五步：置信下限为 $\bar{X}-\dfrac{S}{\sqrt{n}}t_{0.025}(n-1)$ ← 依据：区间左端点

**选项分析**：

- **A（正确）**：$\bar{X}-\dfrac{S}{\sqrt{n}}t_{0.025}(n-1)$，与上述下限一致
- **B（错误）**：给出的是置信上限而非下限（符号取反）
- **C（错误）**：$t_{0.05}(n-1)$ 是单侧分位数，双侧0.95应用 $t_{0.025}$
- **D（错误）**：既用错分位数（$\alpha$ 而非 $\alpha/2$）又取错方向（上限而非下限）
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$\sigma^{2}$ 已知vs未知混淆**：$\sigma^{2}$ 未知却用 $z$ 枢轴量 → 正确做法：未知用 $S$ 替代，枢轴量为 $t$ 分布
2. **双侧vs单侧分位数**：双侧0.95置信区间误用 $t_{0.05}$ → 正确做法：双侧用 $\alpha/2=0.025$，单侧才用 $\alpha=0.05$
3. **上下限方向错**：把 $\bar{X}+\dfrac{S}{\sqrt{n}}t$ 当作下限 → 正确做法：下限为减号 $\bar{X}-\dfrac{S}{\sqrt{n}}t$
:::

:::callout{kind=note label="知识卡片：正态总体均值 $\mu$ 的置信区间"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $\sigma^{2}$ 已知枢轴量 | $\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\sim N(0,1)$ | $\sigma^{2}$ 已知 |
| $\sigma^{2}$ 未知枢轴量 | $\dfrac{\bar{X}-\mu}{S/\sqrt{n}}\sim t(n-1)$ | $\sigma^{2}$ 未知 |
| 双侧置信区间 | $\bar{X}\pm\dfrac{S}{\sqrt{n}}t_{\alpha/2}(n-1)$ | 双侧 $1-\alpha$ |
| 单侧下限 | $\bar{X}-\dfrac{S}{\sqrt{n}}t_{\alpha}(n-1)$ | 单侧 $1-\alpha$ |
| 分位数口诀 | 双侧用 $\alpha/2$，单侧用 $\alpha$ | — |

**概念辨析**：
- $\sigma^{2}$ 未知时用 $S$ 替代 $\sigma$，分布由 $N(0,1)$ 变为 $t(n-1)$，自由度为 $n-1$
- 双侧置信区间有上下两个端点，分位数取 $\alpha/2$；单侧只有一个端点，分位数取 $\alpha$
:::

:::callout{kind=tip label="结论速记"}
$\sigma^{2}$ 未知 $\Rightarrow$ 用 $t$ 分布；双侧 $0.95 \Rightarrow \alpha/2=0.025$；下限 $\bar{X} - \dfrac{S}{\sqrt{n}}\, t_{0.025}(n-1)$。

**口诀**：方差未知用t分布，自由度减一记清楚；双侧分位半阿尔法，下限减号上限加。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"置信区间+$\sigma^{2}$未知"→联想 $t$ 枢轴量+双侧 $\alpha/2$ 分位数
- **关联考点**：枢轴量法、$t$ 分布性质；与第5大题 $T\sim t(2n-2)$ 构造同属 $t$ 分布应用
- **复用场景**：正态总体均值检验、置信区间估计、单双侧分位数选择
:::

### 第10题

:::callout{kind=note label="题目"}
下面表述正确的有（　　）个。

（1）设 $A$ 为随机事件，若 $P(A)=1$，则 $A$ 为必然事件；

（2）常数与任意随机变量独立；

（3）设随机变量 $X \sim P(\lambda_1),\, Y \sim P(\lambda_2)$，且相互独立，则 $X+Y \sim P(\lambda_1+\lambda_2)$；

（4）设 $X, Y$ 为随机变量，如果 $X^{2}$ 与 $Y^{2}$ 相互独立，则 $X, Y$ 也相互独立；

（5）设随机变量 $X, Y$ 分布相同，则 $P(X=Y)=1$。

A. 2　　B. 3　　C. 4　　D. 5
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：读题识别为概率论命题辨析，需对5条叙述逐一构造反例或引用定理判定真伪。

**为何用此公式**：概率为1的"几乎必然"与集合意义的必然事件 $\Omega$ 不同（差一个零测集）；独立性可用定义验证；泊松分布具有独立可加性；函数独立不推出原变量独立（除非函数可逆）。

**推导过程**：

1. 第一步：（1）判定 ← 依据：$P(A)=1$ 表示几乎必然，存在零测集补集。反例 $X\sim U(0,1)$，$A=\{X\neq 0.5\}$，$P(A)=1$ 但 $A\neq\Omega$，故（1）错
2. 第二步：（2）判定 ← 依据：常数 $c$ 与任意 $X$ 独立，因 $P(c\in B)\in\{0,1\}$，$P(c\in B,X\in C)=P(X\in C)\cdot P(c\in B)$ 恒成立，故（2）对
3. 第三步：（3）判定 ← 依据：泊松分布独立可加性定理，$X,Y$ 独立时 $X+Y\sim P(\lambda_1+\lambda_2)$，故（3）对
4. 第四步：（4）判定 ← 依据：$X^{2},Y^{2}$ 独立不能推出 $X,Y$ 独立。反例：$X^{2},Y^{2}$ 退化（常数）时必独立，但 $X,Y$ 可相关，故（4）错
5. 第五步：（5）判定 ← 依据：同分布不代表几乎处处相等。反例 $X,Y$ 独立同分布时 $P(X=Y)$ 一般小于1，故（5）错
6. 第六步：正确的有（2）（3）共2个 ← 依据：计数

**选项分析**：

- **A（正确）**：2个，即（2）（3）
- **B（错误）**：3个对应误把（1）或（5）判为正确
- **C（错误）**：4个对应多判两条正确
- **D（错误）**：5个对应全部判正确
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$P(A)=1$ 与必然事件混淆**：把"几乎必然"当作集合意义必然事件 $\Omega$ → 正确做法：$P(A)=1$ 仅表示 $A^c$ 为零测集，$A$ 可不等于 $\Omega$
2. **函数独立反推原变量独立**：认为 $X^{2},Y^{2}$ 独立则 $X,Y$ 独立 → 正确做法：函数独立不反推原变量独立（除非函数可逆），退化情形即反例
3. **同分布等同相等**：认为同分布则 $P(X=Y)=1$ → 正确做法：同分布仅指分布函数相同，独立同分布时 $P(X=Y)$ 一般小于1
:::

:::callout{kind=note label="知识卡片：概率论常见易错命题辨析"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $P(A)=1\Rightarrow A=\Omega$ | 假，反例 $A=\{X\neq 0.5\}$ | 概率为1≠必然事件 |
| 常数与任意 $X$ 独立 | 真，$P(c\in B)\in\{0,1\}$ | 常数退化 |
| 泊松独立可加 | 真，$X+Y\sim P(\lambda_1+\lambda_2)$ | $X,Y$ 独立 |
| $X^{2},Y^{2}$ 独立 $\Rightarrow X,Y$ 独立 | 假，退化反例 | 函数不可逆 |
| 同分布 $\Rightarrow P(X=Y)=1$ | 假，iid 时 $P(X=Y)<1$ | 同分布≠相等 |

**概念辨析**：
- "几乎必然"（$P=1$）与"必然"（$=\Omega$）在离散样本空间等价，连续型不等价
- 独立性的反推：$X,Y$ 独立 $\Rightarrow g(X),h(Y)$ 独立，但反向不成立（除非 $g,h$ 可逆）
:::

:::callout{kind=tip label="结论速记"}
5 条中仅"常数独立"和"泊松可加"两条正确，答案 2 个。

**口诀**：概率为一非必然，常数独立恒成立；泊松可加需独立，函数独立不反推；同分布非相等。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"命题辨析/判断对错"→联想构造反例+引用定理双管齐下
- **关联考点**：事件独立性、分布可加性、几乎必然与必然的区别；与第8题 iid 比较同属概念辨析类
- **复用场景**：概率论概念题、反例构造、定理适用条件判定
:::

## 二、填空题（每题 3 分，共 15 分）

### 第1题

:::callout{kind=note label="题目"}
将一枚骰子重复独立抛 3 次，设随机事件 $A=\{$3 次中恰有一次点数为 2$\}$，$B=\{$3 次出现的点数各不相同$\}$，则 $P(B \mid A) = \rule{2cm}{0.15pt}$。
:::

:::callout{kind=insight label="解析"}
**【答案】$\dfrac{4}{5}$**

**思路**：读题识别条件概率，$A$ 发生后样本空间收缩为"恰一次为2、另两次为非2点数"，在缩样本空间内直接计数 $B$。

**为何用此公式**：$A$ 限定后另两次投掷结果等可能且可数，适用缩样本法 $P(B\mid A)=\dfrac{\text{有利}}{\text{总数}}$；也可用定义法 $P(B\mid A)=\dfrac{P(AB)}{P(A)}$ 验证。

**推导过程**：

1. 第一步：$A$ 发生条件下，恰一次为2（位置有3种），另两次均不为2 ← 依据：$A$ 的定义
2. 第二步：另两次每次从 $\{1,3,4,5,6\}$ 共5个等可能结果中取 ← 依据：骰子6面排除2点
3. 第三步：缩样本总数 $5\times 5=25$ ← 依据：两次独立等可能
4. 第四步：要求 $B$（三次各不相同），则另两次还需互不相同：第一次5种、第二次4种，共 $5\times 4=20$ ← 依据：排列计数
5. 第五步：$P(B\mid A)=\dfrac{20}{25}=\dfrac{4}{5}$ ← 依据：古典概型
6. 第六步（验证）：$P(A)=\dbinom{3}{1}\cdot\dfrac{1}{6}\cdot\!\left(\dfrac{5}{6}\right)^{2}=\dfrac{25}{72}$；$P(AB)=\dfrac{3\times 5\times 4}{6^{3}}=\dfrac{5}{18}$；$P(B\mid A)=\dfrac{5/18}{25/72}=\dfrac{4}{5}$ ← 依据：定义法

**关键步骤说明**：

- 缩样本法与定义法结果一致，验证了答案 $\dfrac{4}{5}$
- 关键在于 $A$ 限定后另两次的样本空间为 $5\times 5=25$ 而非 $6\times 6=36$
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **缩样本总数取错**：把另两次的样本空间取为 $6\times 6=36$（未排除2点） → 正确做法：$A$ 发生条件下另两次均不为2，每次5种，总数 $5\times 5=25$
2. **"各不相同"理解错**：只要求另两次不同而忽略与已固定的2点已不同 → 正确做法：2点已固定，另两次只需互不相同即可，共 $5\times 4=20$
3. **定义法 $P(AB)$ 计算漏因子**：漏乘位置选择 $\dbinom{3}{1}=3$ → 正确做法：$P(AB)=\dfrac{3\times 5\times 4}{6^{3}}$
:::

:::callout{kind=note label="知识卡片：条件概率的样本空间收缩法"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 定义法 | $P(B\mid A)=\dfrac{P(AB)}{P(A)}$ | 通用 |
| 缩样本法 | 在 $A$ 发生的新样本空间中直接计数 $B$ | $A$ 限定后样本点等可能 |
| 独立重复试验 | 每次 $k$ 种等可能结果，$n$ 次总数 $k^{n}$ | 骰子、硬币等 |
| 二项概率 | $P(\text{恰 }r\text{ 次})=\dbinom{n}{r}p^{r}(1-p)^{n-r}$ | 伯努利试验 |

**概念辨析**：
- 缩样本法与定义法等价，但缩样本法在 $A$ 限定后样本点等可能时更简便
- "恰一次为2"已固定2的位置和取值，缩样本只考虑另两次的结果
:::

:::callout{kind=tip label="结论速记"}
$A$ 发生后另两次只能在 5 个非 2 点数中取，要各不相同则 $5 \times 4 / 5^{2} = \dfrac{4}{5}$。

**口诀**：条件概率缩样本，限定之后重新数；排除二号剩五个，各不相同五四乘。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$P(B\mid A)$+重复试验"→联想缩样本法（在 $A$ 限定后重新计数）
- **关联考点**：条件概率、古典概型；与第1题分组分配同属计数类
- **复用场景**：骰子/硬币条件概率、限定结构下的计数问题
:::

### 第2题

:::callout{kind=note label="题目"}
设随机变量 $X, Y$ 独立同分布，且 $P(X = k) = \dfrac{1}{2^{k}}\;(k = 1, 2, \ldots)$，则 $P(X > Y) = \rule{2cm}{0.15pt}$。
:::

:::callout{kind=insight label="解析"}
**【答案】$\dfrac{1}{3}$**

**思路**：读题识别为独立同分布随机变量比较，由对称性 $P(X>Y)=P(X<Y)$，先求 $P(X=Y)$ 再由完备性求 $P(X>Y)$。

**为何用此公式**：同分布对称性 $(X,Y)\stackrel{d}{=}(Y,X)$ 保证 $P(X>Y)=P(X<Y)$；$P(X=Y)=\sum_{k}P(X=k)P(Y=k)$ 由独立性展开为等比级数求和。

**推导过程**：

1. 第一步：求 $P(X=Y)$ ← 依据：独立性 $P(X=Y)=\sum_{k=1}^{\infty}P(X=k)P(Y=k)$
2. 第二步：代入 $P(X=k)=\dfrac{1}{2^{k}}$ 得 $P(X=Y)=\sum_{k=1}^{\infty}\dfrac{1}{4^{k}}$ ← 依据：质量函数
3. 第三步：等比级数求和 $\sum_{k=1}^{\infty}\dfrac{1}{4^{k}}=\dfrac{1/4}{1-1/4}=\dfrac{1}{3}$ ← 依据：等比级数公式 $\sum_{k=1}^{\infty}r^{k}=\dfrac{r}{1-r}$（$|r|<1$）
4. 第四步：由同分布对称性 $P(X>Y)=P(X<Y)$ ← 依据：$(X,Y)\stackrel{d}{=}(Y,X)$
5. 第五步：$P(X>Y)+P(X=Y)+P(X<Y)=1$ ← 依据：概率完备性
6. 第六步：$2P(X>Y)=1-\dfrac{1}{3}=\dfrac{2}{3}$，故 $P(X>Y)=\dfrac{1}{3}$ ← 依据：解方程

**关键步骤说明**：

- $P(X=Y)=\dfrac{1}{3}$ 是核心中间量，由等比级数求和得到
- 对称性将 $P(X>Y)$ 与 $P(X<Y)$ 合并为一个未知量，简化求解
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **等比级数首项错**：把 $\sum_{k=1}^{\infty}\dfrac{1}{4^{k}}$ 首项取为1 → 正确做法：首项 $\dfrac{1}{4}$，公比 $\dfrac{1}{4}$，和为 $\dfrac{1/4}{1-1/4}=\dfrac{1}{3}$
2. **对称性遗忘**：直接对 $P(X>Y)=\sum_{k}\sum_{j<k}P(X=k)P(Y=j)$ 双重求和 → 正确做法：用对称性 $P(X>Y)=P(X<Y)$ 简化
3. **完备性漏项**：写成 $P(X>Y)+P(X<Y)=1$ 漏掉 $P(X=Y)$ → 正确做法：三项之和为1
:::

:::callout{kind=note label="知识卡片：几何型分布与对称性求和"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 几何分布 | $P(X=k)=p(1-p)^{k-1}$，本题 $p=\dfrac{1}{2}$ | $k=1,2,\ldots$ |
| 等比级数求和 | $\sum_{k=1}^{\infty}r^{k}=\dfrac{r}{1-r}$ | $|r|<1$ |
| 同分布对称性 | $P(X>Y)=P(X<Y)$ | $X,Y$ 同分布 |
| 求和分解 | $P(X>Y)=\dfrac{1-P(X=Y)}{2}$ | iid 对称 |

**概念辨析**：
- 几何分布 $P(X=k)=p(1-p)^{k-1}$ 与本题 $P(X=k)=\dfrac{1}{2^{k}}$：后者 $p=\dfrac{1}{2}$，可写为 $\dfrac{1}{2}\cdot\!\left(\dfrac{1}{2}\right)^{k-1}$
- 对称性来自同分布而非独立性：独立性用于展开 $P(X=Y)$，对称性用于合并 $P(X>Y)$ 与 $P(X<Y)$
:::

:::callout{kind=tip label="结论速记"}
独立同分布 $\Rightarrow P(X>Y)=P(X<Y)$，先算 $P(X=Y)=\dfrac{1}{3}$，再得 $P(X>Y)=\dfrac{1}{3}$。

**口诀**：同分布必对称，等号概率先求和；等比级数公式套，剩余对半即是答。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"iid + $P(X>Y)$"→联想对称性 $P(X>Y)=P(X<Y)$ + 先求 $P(X=Y)$
- **关联考点**：几何分布、等比级数、对称性；与第8题 iid 比较性质同属对称性应用
- **复用场景**：离散型 iid 变量比较、无穷级数求和的概率题
:::

### 第3题

:::callout{kind=note label="题目"}
设随机变量 $X, Y$ 独立，且 $X \sim P(2)$，$Y \sim U(-1, 1)$，则 $E(X^{2}Y^{2}) = \rule{2cm}{0.15pt}$。
:::

:::callout{kind=insight label="解析"}
**【答案】$2$**

**思路**：读题识别 $X,Y$ 独立则 $X^{2},Y^{2}$ 独立，期望可拆为乘积；分别用泊松与均匀分布的矩公式计算 $E(X^{2})$ 与 $E(Y^{2})$。

**为何用此公式**：$X,Y$ 独立 $\Rightarrow g(X),h(Y)$ 独立 $\Rightarrow E[g(X)h(Y)]=E[g(X)]E[h(Y)]$；二阶矩由 $E(X^{2})=D(X)+[E(X)]^{2}$ 计算。

**推导过程**：

1. 第一步：由 $X,Y$ 独立知 $X^{2},Y^{2}$ 独立 ← 依据：独立性定理（独立变量的函数仍独立）
2. 第二步：$E(X^{2}Y^{2})=E(X^{2})\cdot E(Y^{2})$ ← 依据：独立变量乘积期望等于期望乘积
3. 第三步：计算 $E(X^{2})$：$X\sim P(2)$，$E(X)=D(X)=2$ ← 依据：泊松分布期望与方差均为 $\lambda$
4. 第四步：$E(X^{2})=D(X)+[E(X)]^{2}=2+4=6$ ← 依据：二阶矩公式 $E(X^{2})=D(X)+[E(X)]^{2}$
5. 第五步：计算 $E(Y^{2})$：$Y\sim U(-1,1)$，$D(Y)=\dfrac{(b-a)^{2}}{12}=\dfrac{4}{12}=\dfrac{1}{3}$，$E(Y)=0$ ← 依据：均匀分布方差与期望公式
6. 第六步：$E(Y^{2})=D(Y)+[E(Y)]^{2}=\dfrac{1}{3}+0=\dfrac{1}{3}$ ← 依据：二阶矩公式
7. 第七步：$E(X^{2}Y^{2})=6\times\dfrac{1}{3}=2$ ← 依据：乘积

**关键步骤说明**：

- 独立性是拆分乘积期望的关键前提，无独立性则不能用
- 二阶矩统一用 $E(X^{2})=D(X)+[E(X)]^{2}$ 计算，避免直接积分
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **独立性遗忘**：未利用 $X,Y$ 独立直接拆分 $E(X^{2}Y^{2})$ → 正确做法：独立 $\Rightarrow X^{2},Y^{2}$ 独立 $\Rightarrow E(X^{2}Y^{2})=E(X^{2})E(Y^{2})$
2. **泊松二阶矩算错**：把 $E(X^{2})$ 误算为 $\lambda=2$ → 正确做法：$E(X^{2})=D(X)+[E(X)]^{2}=\lambda+\lambda^{2}=2+4=6$
3. **均匀分布方差取错**：把 $D(Y)$ 误算为 $\dfrac{(1-(-1))^{2}}{12}=\dfrac{1}{3}$ 漏算或取 $\dfrac{1}{2}$ → 正确做法：区间长度 $b-a=2$，$D(Y)=\dfrac{4}{12}=\dfrac{1}{3}$
:::

:::callout{kind=note label="知识卡片：常见分布的矩与独立性"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 泊松 $P(\lambda)$ | $E=\lambda$，$D=\lambda$，$E(X^{2})=\lambda+\lambda^{2}$ | $X\sim P(\lambda)$ |
| 均匀 $U(a,b)$ | $E=\dfrac{a+b}{2}$，$D=\dfrac{(b-a)^{2}}{12}$ | $X\sim U(a,b)$ |
| 指数 $E(\lambda)$ | $E=\dfrac{1}{\lambda}$，$D=\dfrac{1}{\lambda^{2}}$ | $X\sim E(\lambda)$ |
| 二阶矩公式 | $E(X^{2})=D(X)+[E(X)]^{2}$ | 任意随机变量 |
| 独立性结论 | $X,Y$ 独立 $\Rightarrow E[g(X)h(Y)]=E[g(X)]E[h(Y)]$ | $g,h$ 可测 |

**概念辨析**：
- $E(X^{2}Y^{2})=E(X^{2})E(Y^{2})$ 要求 $X^{2},Y^{2}$ 独立，由 $X,Y$ 独立保证；若 $X,Y$ 不独立则不成立
- 二阶矩公式 $E(X^{2})=D(X)+[E(X)]^{2}$ 由 $D(X)=E(X^{2})-[E(X)]^{2}$ 变形得到
:::

:::callout{kind=tip label="结论速记"}
独立 $\Rightarrow E(X^{2}Y^{2})=E(X^{2})E(Y^{2})$；泊松 $E(X^{2})=\lambda+\lambda^{2}$，均匀 $E(Y^{2})=\dfrac{(b-a)^{2}}{12}$。

**口诀**：独立变量函数独立，期望乘积可拆分；二阶矩用方差加期望方，泊松均匀套公式。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"独立+二阶矩乘积"→联想独立性拆分 + $E(X^{2})=D+[E]^{2}$
- **关联考点**：常见分布的矩、独立性定理；与第4题填空 $\bar{X}$与$S^{2}$ 独立同属独立性应用
- **复用场景**：独立变量函数的期望计算、矩估计与无偏性检验
:::

### 第4题

:::callout{kind=note label="题目"}
设 $(X_1, X_2, \ldots, X_{10})$ 是来自总体 $X \sim N(\mu, 2^{2})$ 的简单随机样本，其中 $\mu$ 未知，$\bar{X}, S^{2}$ 分别为样本均值、样本方差，则 $D(\bar{X} + S^{2}) = \rule{2cm}{0.15pt}$。
:::

:::callout{kind=insight label="解析"}
**【答案】$\dfrac{178}{45}$**

**思路**：读题识别正态总体下 $\bar{X}$ 与 $S^{2}$ 独立，方差可加；分别用样本均值方差公式与样本方差的方差公式计算后相加。

**为何用此公式**：正态总体的重要定理保证 $\bar{X}$ 与 $S^{2}$ 独立，故 $D(\bar{X}+S^{2})=D(\bar{X})+D(S^{2})$；$D(\bar{X})=\dfrac{\sigma^{2}}{n}$，$D(S^{2})=\dfrac{2\sigma^{4}}{n-1}$ 由 $\chi^{2}$ 分布性质导出。

**推导过程**：

1. 第一步：正态总体下 $\bar{X}$ 与 $S^{2}$ 相互独立 ← 依据：正态总体样本均值与样本方差独立性定理
2. 第二步：$D(\bar{X}+S^{2})=D(\bar{X})+D(S^{2})$ ← 依据：独立变量和的方差等于方差和
3. 第三步：$\sigma^{2}=4$，$n=10$ ← 依据：题目给定
4. 第四步：$D(\bar{X})=\dfrac{\sigma^{2}}{n}=\dfrac{4}{10}=\dfrac{2}{5}$ ← 依据：样本均值方差公式
5. 第五步：$(n-1)S^{2}/\sigma^{2}\sim\chi^{2}(n-1)$，$D\!\left(\dfrac{(n-1)S^{2}}{\sigma^{2}}\right)=2(n-1)$ ← 依据：正态总体样本方差分布定理与卡方方差
6. 第六步：$D(S^{2})=\dfrac{2\sigma^{4}}{n-1}=\dfrac{2\times 4^{2}}{9}=\dfrac{32}{9}$ ← 依据：方差性质 $D(aX)=a^{2}D(X)$ 反推
7. 第七步：$D(\bar{X}+S^{2})=\dfrac{2}{5}+\dfrac{32}{9}=\dfrac{18}{45}+\dfrac{160}{45}=\dfrac{178}{45}$ ← 依据：通分相加

**关键步骤说明**：

- 独立性是方差可加的前提，正态总体保证 $\bar{X}\perp S^{2}$
- $D(S^{2})$ 的推导链：$\chi^{2}(n-1)$ 方差 $2(n-1)$ → 除以 $\left(\dfrac{n-1}{\sigma^{2}}\right)^{2}$ 得 $\dfrac{2\sigma^{4}}{n-1}$
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **独立性遗漏**：未利用正态总体 $\bar{X}\perp S^{2}$，误用 $D(\bar{X}+S^{2})=D(\bar{X})+D(S^{2})+2\text{Cov}$ → 正确做法：正态总体下独立，协方差项为0
2. **$D(S^{2})$ 公式记错**：把 $D(S^{2})$ 误记为 $\dfrac{2\sigma^{4}}{n}$ 或 $\dfrac{\sigma^{4}}{n-1}$ → 正确做法：$D(S^{2})=\dfrac{2\sigma^{4}}{n-1}$
3. **$\sigma^{2}$ 代入错**：把 $\sigma^{2}=2$ 而非 $\sigma^{2}=4$ → 正确做法：题目 $N(\mu,2^{2})$ 即 $\sigma^{2}=4$
:::

:::callout{kind=note label="知识卡片：正态总体样本均值与样本方差的性质"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $\bar{X}$ 分布 | $\bar{X}\sim N(\mu,\sigma^{2}/n)$ | 正态总体 |
| $\bar{X}$ 方差 | $D(\bar{X})=\sigma^{2}/n$ | — |
| $S^{2}$ 分布 | $(n-1)S^{2}/\sigma^{2}\sim\chi^{2}(n-1)$ | 正态总体 |
| $S^{2}$ 方差 | $D(S^{2})=2\sigma^{4}/(n-1)$ | 来自 $\chi^{2}$ 方差 $2(n-1)$ |
| 独立性 | $\bar{X}$ 与 $S^{2}$ 独立 | 正态总体（重要定理） |
| 方差可加 | $D(\bar{X}+S^{2})=D(\bar{X})+D(S^{2})$ | 需独立性 |

**概念辨析**：
- $\bar{X}\perp S^{2}$ 仅对正态总体成立，非正态总体不保证
- $D(S^{2})=\dfrac{2\sigma^{4}}{n-1}$ 中分母为 $n-1$ 而非 $n$，源于样本方差定义 $\dfrac{1}{n-1}\sum$
:::

:::callout{kind=tip label="结论速记"}
正态总体 $\bar{X} \perp S^{2}$，$D(\bar{X})=\dfrac{\sigma^{2}}{n}$，$D(S^{2})=\dfrac{2\sigma^{4}}{n-1}$，相加即得。

**口诀**：正态总体均方独立，方差可加直接相加；均值方差西格玛除n，方差方差二倍四次方除n减一。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"正态总体+$D(\bar{X}+S^{2})$"→联想 $\bar{X}\perp S^{2}$ + 方差可加
- **关联考点**：正态总体抽样分布、$\chi^{2}$ 分布性质；与第5题选择题卡方方差同属抽样分布类
- **复用场景**：正态总体统计量的方差计算、置信区间构造
:::

### 第5题

:::callout{kind=note label="题目"}
将一圆周分为 4 个圆弧，再在每段弧标上从 $1, 2, 3$ 中任选一个数字，则任意两个相邻的圆弧所标数字不同的概率是 $\rule{2cm}{0.15pt}$。
:::

:::callout{kind=insight label="解析"}
**【答案】$\dfrac{2}{9}$**

**思路**：读题识别为圆环染色问题（环状相邻不同色），用圆环染色公式计数；总标法数为 $m^{n}$，相邻不同标法数为 $(m-1)^{n}+(-1)^{n}(m-1)$。

**为何用此公式**：圆环首尾相邻，需用环状相邻不同色公式 $(m-1)^{n}+(-1)^{n}(m-1)$（$n$ 段 $m$ 色）；直线情形公式 $m(m-1)^{n-1}$ 不适用，因其首尾无约束。

**推导过程**：

1. 第一步：总标法数 $N=3^{4}=81$ ← 依据：4段弧每段独立选3个数字之一，乘法原理
2. 第二步：识别为圆环染色问题（首尾相邻） ← 依据：圆周闭合，第4段与第1段相邻
3. 第三步：套用圆环相邻不同色公式 $M=(m-1)^{n}+(-1)^{n}(m-1)$ ← 依据：环状相邻不同色计数公式
4. 第四步：代入 $m=3,n=4$：$M=2^{4}+(-1)^{4}\cdot 2=16+2=18$ ← 依据：代入计算
5. 第五步：$P=\dfrac{18}{81}=\dfrac{2}{9}$ ← 依据：古典概型
6. 第六步（公式推导）：设圆环上 $n$ 段相邻不同色标法数为 $a_n$，递推 $a_n=(m-1)^{n}+(-1)^{n}(m-1)$ ← 依据：递推关系求解

**关键步骤说明**：

- 圆环与直线的关键区别：圆环首尾相邻需额外约束，公式多一项 $(-1)^{n}(m-1)$
- 直线情形 $m(m-1)^{n-1}=3\times 2^{3}=24$，与圆环18不同
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **圆环误用直线公式**：用 $m(m-1)^{n-1}=3\times 2^{3}=24$ 计数 → 正确做法：圆环首尾相邻，用 $(m-1)^{n}+(-1)^{n}(m-1)=18$
2. **公式符号记错**：把 $(-1)^{n}$ 误记为 $(-1)^{n-1}$ → 正确做法：$n=4$ 为偶数，$(-1)^{4}=+1$，故 $M=16+2=18$
3. **总数取错**：把总标法数取为 $3\times 2^{3}=24$（已限定相邻不同） → 正确做法：总数为无约束的 $3^{4}=81$
:::

:::callout{kind=note label="知识卡片：圆排列染色计数（环状相邻不同色）"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 总标法数 | $m^{n}$（$n$ 段，$m$ 种数字） | 无约束 |
| 圆环相邻不同标法数 | $(m-1)^{n}+(-1)^{n}(m-1)$ | 环状首尾相邻 |
| 直线相邻不同标法数 | $m(m-1)^{n-1}$ | 直线首尾无约束 |
| 本题代入 | $(3-1)^{4}+(3-1)=16+2=18$ | $m=3,n=4$ |
| 概率 | $\dfrac{18}{81}=\dfrac{2}{9}$ | 古典概型 |

**概念辨析**：
- 圆环公式多出 $(-1)^{n}(m-1)$ 项，源于首尾相邻的额外约束
- 当 $n$ 为偶数时 $(-1)^{n}=+1$，标法数增加；当 $n$ 为奇数时 $(-1)^{n}=-1$，标法数减少
:::

:::callout{kind=tip label="结论速记"}
圆环相邻不同色公式 $(m-1)^{n}+(-1)^{n}(m-1)$；本题 $m=3, n=4 \Rightarrow 18$ 种，概率 $\dfrac{2}{9}$。

**口诀**：圆环染色有公式，m减一n次方加减；奇减偶加看符号，直线公式不可套。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"圆周/环状+相邻不同"→联想圆环染色公式 $(m-1)^{n}+(-1)^{n}(m-1)$
- **关联考点**：排列组合、古典概型；与第1题分组分配同属计数类，但圆环与直线有别
- **复用场景**：圆桌座位安排、环状涂色、项链排列等环状计数问题
:::

## 三、（10 分）

### 第1题

:::callout{kind=note label="题目"}
设有 8 件产品，其中 4 件不合格。从中任意取出 4 件放入甲盒，剩余 4 件放入乙盒，现从两盒中各取一件。

1. 求取出的两件产品恰有 1 件不合格品的概率；
2. 已知取出的两件产品恰有 1 件不合格品，求甲、乙两盒各有 2 件不合格品的概率。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：读题识别分盒后两盒各取一件为分层抽样，甲盒不合格件数 $K$ 服从超几何分布；第1问用全概率公式对所有 $K$ 求和，第2问用贝叶斯公式反求后验概率。

**为何用此公式**：$K$ 的分布由超几何分布描述（从8件含4件不合格中取4件）；事件 $E$（恰一件不合格）的概率随 $K$ 变化，需用全概率公式加权求和；后验概率用贝叶斯公式。

**推导过程**：

1. 第一步：设 $K$ 为甲盒中不合格品件数，$K$ 服从超几何分布 $P(K=k)=\dfrac{\dbinom{4}{k}\dbinom{4}{4-k}}{\dbinom{8}{4}}=\dfrac{\dbinom{4}{k}^{2}}{70}$，$k=0,1,2,3,4$ ← 依据：超几何分布公式
2. 第二步：在 $K=k$ 条件下，甲盒 $k$ 件不合格、$4-k$ 件合格；乙盒 $4-k$ 件不合格、$k$ 件合格 ← 依据：总量约束
3. 第三步：两盒各取一件恰一件不合格的条件概率 $P(E\mid K=k)=\dfrac{k}{4}\cdot\dfrac{k}{4}+\dfrac{4-k}{4}\cdot\dfrac{4-k}{4}=\dfrac{k^{2}+(4-k)^{2}}{16}$ ← 依据：甲不合格乙合格 + 甲合格乙不合格
4. 第四步（第1问）：全概率公式 $P(E)=\sum_{k=0}^{4}P(K=k)P(E\mid K=k)$ ← 依据：全概率公式
5. 第五步：逐项计算

| $k$ | $\dbinom{4}{k}^{2}$ | $k^{2}+(4-k)^{2}$ | 乘积 |
|-----|---------------------|-------------------|------|
| 0 | 1 | 16 | 16 |
| 1 | 16 | 10 | 160 |
| 2 | 36 | 8 | 288 |
| 3 | 16 | 10 | 160 |
| 4 | 1 | 16 | 16 |

← 依据：组合数与代数计算

6. 第六步：$P(E)=\dfrac{16+160+288+160+16}{70\times 16}=\dfrac{640}{1120}=\dfrac{4}{7}$ ← 依据：求和化简
7. 第七步（第2问）：贝叶斯公式 $P(K=2\mid E)=\dfrac{P(K=2)P(E\mid K=2)}{P(E)}$ ← 依据：贝叶斯公式
8. 第八步：$P(K=2\mid E)=\dfrac{\dfrac{36}{70}\times\dfrac{8}{16}}{\dfrac{4}{7}}=\dfrac{\dfrac{18}{70}}{\dfrac{4}{7}}=\dfrac{18}{70}\times\dfrac{7}{4}=\dfrac{9}{20}$ ← 依据：代入计算

**关键步骤说明**：

- $K$ 的超几何分布是全概率公式的基础，需正确写出 $P(K=k)$
- 条件概率 $P(E\mid K=k)$ 的构造：两盒各取一件，按"甲不合格乙合格 + 甲合格乙不合格"两路相加
- 贝叶斯公式方向：由"果" $E$ 反推"因" $K=2$ 的后验概率
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$K$ 的分布写错**：把 $P(K=k)$ 误写为二项分布 $\dbinom{4}{k}p^{k}(1-p)^{4-k}$ → 正确做法：分盒为无放回抽样，用超几何分布 $\dfrac{\dbinom{4}{k}\dbinom{4}{4-k}}{\dbinom{8}{4}}$
2. **条件概率两路遗漏**：只算"甲不合格乙合格"漏掉"甲合格乙不合格" → 正确做法：两路相加 $P(E\mid K=k)=\dfrac{k^{2}+(4-k)^{2}}{16}$
3. **贝叶斯方向反**：把 $P(E\mid K=2)$ 当作 $P(K=2\mid E)$ → 正确做法：贝叶斯公式 $P(K=2\mid E)=\dfrac{P(K=2)P(E\mid K=2)}{P(E)}$
:::

:::callout{kind=note label="知识卡片：超几何分布与全概率/贝叶斯公式"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 超几何分布 | $P(K=k)=\dfrac{\dbinom{M}{k}\dbinom{N-M}{n-k}}{\dbinom{N}{n}}$ | 无放回抽样 |
| 全概率公式 | $P(E)=\sum_{k}P(K=k)P(E\mid K=k)$ | 完备事件组 |
| 贝叶斯公式 | $P(K=k\mid E)=\dfrac{P(K=k)P(E\mid K=k)}{P(E)}$ | 后验概率 |
| 条件概率构造 | 分盒后各取一件，按不合格件数分类讨论 | 两盒独立抽样 |

**概念辨析**：
- 超几何分布用于无放回抽样，二项分布用于有放回抽样；分盒问题为无放回
- 全概率公式"由因求果"，贝叶斯公式"由果溯因"，二者方向相反
:::

:::callout{kind=tip label="结论速记"}
分盒问题用超几何分布描述 $K$，全概率公式求 $P(E)=\dfrac{4}{7}$，贝叶斯反求 $P(K=2 \mid E)=\dfrac{9}{20}$。

**口诀**：分盒抽样超几何，全概率求总和；贝叶斯反推后验，果溯因方向反。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"分盒/分层抽样+恰一件"→联想超几何分布+全概率公式
- **关联考点**：超几何分布、全概率与贝叶斯公式；与第3题选择题RRT同属全概率应用
- **复用场景**：产品质量抽检、分层抽样推断、后验概率计算

## 四、（14 分）

### 第1题

:::callout{kind=note label="题目"}
已知 $(X, Y)$ 的概率密度函数为

$$f(x,y) = \begin{cases} \dfrac{1}{2\pi}\, e^{-\frac{x^{2}+y^{2}}{2}}, & x^{2}+y^{2} > 1 \\[6pt] \dfrac{1}{2\pi}\, e^{-\frac{x^{2}+y^{2}}{2}} + \dfrac{xy}{100}, & x^{2}+y^{2} \leq 1 \end{cases}$$

求：

1. 边缘密度函数 $f_X(x),\, f_Y(y)$；
2. $X, Y$ 是否独立？为什么？若不独立，求 $X, Y$ 的相关系数。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：读题识别密度由"标准二维正态主体 + 单位圆内附加项 $\dfrac{xy}{100}$"构成；第1问用边缘密度积分，附加项为奇函数在对称区间积分为0；第2问用独立性判据 $f\stackrel{?}{=}f_X f_Y$，不独立则算相关系数。

**为何用此公式**：边缘密度 $f_X(x)=\int f(x,y)\,dy$；独立性判据为 $f(x,y)=f_X(x)f_Y(y)$ 处处成立；相关系数 $\rho=\dfrac{\text{Cov}}{\sqrt{D(X)D(Y)}}$，协方差 $\text{Cov}=E(XY)-E(X)E(Y)$。

**推导过程**：

1. 第一步（第1问）：$f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy$ ← 依据：边缘密度定义
2. 第二步：附加项 $\dfrac{xy}{100}$ 关于 $y$ 在圆盘截线 $[-\sqrt{1-x^{2}},\sqrt{1-x^{2}}]$（$|x|\leq 1$）为奇函数，积分为0；$|x|>1$ 时附加项不出现 ← 依据：奇函数在对称区间积分为0
3. 第三步：$f_X(x)=\int_{-\infty}^{+\infty}\dfrac{1}{2\pi}e^{-\frac{x^{2}+y^{2}}{2}}\,dy=\dfrac{1}{\sqrt{2\pi}}e^{-x^{2}/2}$ ← 依据：正态密度归一化
4. 第四步：由对称性同理 $f_Y(y)=\dfrac{1}{\sqrt{2\pi}}e^{-y^{2}/2}$ ← 依据：$x,y$ 对称
5. 第五步：故 $X\sim N(0,1)$，$Y\sim N(0,1)$ ← 依据：标准正态密度
6. 第六步（第2问）：单位圆内 $f(x,y)=\dfrac{1}{2\pi}e^{-\frac{x^{2}+y^{2}}{2}}+\dfrac{xy}{100}\neq\dfrac{1}{2\pi}e^{-\frac{x^{2}+y^{2}}{2}}=f_X(x)f_Y(y)$ ← 依据：独立性判据
7. 第七步：故 $X,Y$ 不独立 ← 依据：密度不满足乘积分解
8. 第八步：$E(X)=E(Y)=0$，$D(X)=D(Y)=1$ ← 依据：标准正态矩
9. 第九步：计算 $E(XY)$，第一部分 $\dfrac{xy}{2\pi}e^{-(x^{2}+y^{2})/2}$ 关于 $xy$ 为奇函数在对称域积分为0 ← 依据：奇函数积分
10. 第十步：$E(XY)=\iint xy\,f(x,y)\,dx\,dy=\dfrac{1}{100}\iint_{x^{2}+y^{2}\leq 1}x^{2}y^{2}\,dx\,dy$ ← 依据：附加项贡献
11. 第十一步：极坐标 $x=r\cos\theta,y=r\sin\theta$，$dx\,dy=r\,dr\,d\theta$ ← 依据：极坐标变换
12. 第十二步：$\iint x^{2}y^{2}\,dx\,dy=\int_{0}^{1}r^{5}\,dr\int_{0}^{2\pi}\cos^{2}\theta\sin^{2}\theta\,d\theta$ ← 依据：变量分离
13. 第十三步：$\int_{0}^{1}r^{5}\,dr=\dfrac{1}{6}$ ← 依据：幂函数积分
14. 第十四步：$\int_{0}^{2\pi}\cos^{2}\theta\sin^{2}\theta\,d\theta=\int_{0}^{2\pi}\dfrac{\sin^{2}2\theta}{4}\,d\theta=\dfrac{1}{4}\cdot\pi=\dfrac{\pi}{4}$ ← 依据：三角恒等式 $\cos^{2}\theta\sin^{2}\theta=\dfrac{\sin^{2}2\theta}{4}$
15. 第十五步：$E(XY)=\dfrac{1}{100}\times\dfrac{1}{6}\times\dfrac{\pi}{4}=\dfrac{\pi}{2400}$ ← 依据：乘积
16. 第十六步：$\text{Cov}(X,Y)=E(XY)-E(X)E(Y)=\dfrac{\pi}{2400}-0=\dfrac{\pi}{2400}$ ← 依据：协方差公式
17. 第十七步：$\rho_{XY}=\dfrac{\text{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}=\dfrac{\pi/2400}{1}=\dfrac{\pi}{2400}$ ← 依据：相关系数公式

**关键步骤说明**：

- 附加项 $\dfrac{xy}{100}$ 对边缘密度无贡献（奇函数积分为0），但使 $X,Y$ 不独立
- $E(XY)$ 仅由附加项贡献，主体项因 $xy$ 奇性积分为0
- 极坐标变换是计算圆盘上 $x^{2}y^{2}$ 积分的关键
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **附加项对边缘密度贡献误判**：认为附加项 $\dfrac{xy}{100}$ 会改变 $f_X(x)$ → 正确做法：关于 $y$ 为奇函数，在对称区间积分为0，边缘密度仍为标准正态
2. **独立性判据用错**：由 $X,Y$ 均为 $N(0,1)$ 误判独立 → 正确做法：独立性需 $f(x,y)=f_X(x)f_Y(y)$ 处处成立，单位圆内附加项破坏等式
3. **$E(XY)$ 计算遗漏附加项**：只算主体项得0 → 正确做法：附加项 $\dfrac{xy}{100}\cdot xy=\dfrac{x^{2}y^{2}}{100}$ 在圆盘上积分为正，贡献 $\dfrac{\pi}{2400}$
:::

:::callout{kind=note label="知识卡片：边缘密度、独立性与相关系数"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 边缘密度 | $f_X(x)=\int_{-\infty}^{+\infty}f(x,y)\,dy$ | 连续型 |
| 独立性判据 | $f(x,y)\stackrel{?}{=}f_X(x)f_Y(y)$ 处处成立 | 充要条件 |
| 相关系数 | $\rho_{XY}=\dfrac{\text{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}$ | 方差非零 |
| 协方差 | $\text{Cov}(X,Y)=E(XY)-E(X)E(Y)$ | — |
| 奇函数积分 | 对称区间上奇函数积分为0 | 化简关键 |
| 极坐标变换 | $dx\,dy=r\,dr\,d\theta$，$x^{2}y^{2}=r^{4}\cos^{2}\theta\sin^{2}\theta$ | 圆盘区域 |
| 三角恒等式 | $\cos^{2}\theta\sin^{2}\theta=\dfrac{\sin^{2}2\theta}{4}=\dfrac{1-\cos 4\theta}{8}$ | 降幂 |

**概念辨析**：
- 边缘分布相同不代表联合分布相同：附加项改变联合密度但不改变边缘密度
- 独立性判据是"处处成立"，仅一个点不满足即不独立
- 二维正态分布中 $\rho=0$ 与独立等价，但本题非二维正态（附加项破坏），独立性需用密度判据
:::

:::callout{kind=tip label="结论速记"}
附加项 $\frac{xy}{100}$ 对边缘密度无贡献（奇函数积分为 0），但使 $X,Y$ 不独立；极坐标算 $E(XY)=\dfrac{\pi}{2400}$，即相关系数。

**口诀**：附加项奇函数积分为零，边缘密度仍正态；联合密度不分解，独立判据处处处；极坐标算协方差，相关系数即比值。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"密度分段+附加项+圆盘"→联想奇函数积分化简边缘密度 + 极坐标算 $E(XY)$
- **关联考点**：边缘密度、独立性判据、相关系数；与第6题二维正态象限同属二维分布类
- **复用场景**：含附加项的联合密度分析、圆盘区域上的二重积分、独立性判定
:::

## 五、（12 分）

### 第1题

:::callout{kind=note label="题目"}
已知随机变量 $(X, Y)$ 服从二维正态分布 $N(\mu_1, \mu_2, \sigma_1^{2}, \sigma_2^{2}, \rho) = N(1, 0, 1, 1, 0)$。求：

1. $P(XY \leq Y)$；
2. 如果有来自总体 $(X, Y)$ 的简单随机样本 $((X_1, Y_1), (X_2, Y_2), \ldots, (X_n, Y_n))$，记

$$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i, \quad \bar{Y} = \frac{1}{n}\sum_{i=1}^{n} Y_i, \quad S_X^{2} = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^{2}, \quad S_Y^{2} = \frac{1}{n-1}\sum_{i=1}^{n}(Y_i - \bar{Y})^{2}$$

则 $T = \dfrac{\sqrt{n}\,(\bar{X} - \bar{Y}) - 1}{\sqrt{S_X^{2} + S_Y^{2}}}$ 服从什么分布？说明理由。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：读题识别 $\rho=0$ 二维正态 $\Rightarrow X,Y$ 独立；第1问因式分解 $XY\leq Y\Leftrightarrow Y(X-1)\leq 0$ 后用独立性分两路相加；第2问构造差变量 $D_i=X_i-Y_i$，分子标准化为 $N(0,1)$，分母由 $\chi^{2}$ 构造，合成 $t$ 分布。

**为何用此公式**：二维正态 $\rho=0\Leftrightarrow X,Y$ 独立；独立正态差仍正态，方差可加；正态总体样本方差 $(n-1)S^{2}/\sigma^{2}\sim\chi^{2}(n-1)$；$t$ 分布由独立 $N(0,1)$ 与 $\chi^{2}/\nu$ 之比构成。

**推导过程**：

1. 第一步：$\rho=0$，二维正态 $\Rightarrow X,Y$ 独立 ← 依据：二维正态 $\rho=0$ 与独立等价
2. 第二步：$\mu_1=1,\sigma_1^{2}=1\Rightarrow X-1\sim N(0,1)$；$\mu_2=0,\sigma_2^{2}=1\Rightarrow Y\sim N(0,1)$ ← 依据：正态分布标准化
3. 第三步：$X-1$ 与 $Y$ 独立 ← 依据：$X,Y$ 独立 $\Rightarrow$ 函数独立
4. 第四步（第1问）：$P(XY\leq Y)=P\{Y(X-1)\leq 0\}$ ← 依据：因式分解
5. 第五步：$Y(X-1)\leq 0$ 等价于（$Y\geq 0$ 且 $X-1\leq 0$）或（$Y\leq 0$ 且 $X-1\geq 0$） ← 依据：乘积非正的符号分析
6. 第六步：由 $Y$ 与 $X-1$ 独立且均 $\sim N(0,1)$，$P=P(Y\geq 0)P(X\leq 1)+P(Y\leq 0)P(X\geq 1)=\dfrac{1}{2}\times\dfrac{1}{2}+\dfrac{1}{2}\times\dfrac{1}{2}=\dfrac{1}{2}$ ← 依据：独立性 + 正态对称性
7. 第七步（第2问）：令 $D_i=X_i-Y_i$ ← 依据：构造差变量
8. 第八步：$X_i\sim N(1,1)$，$Y_i\sim N(0,1)$ 独立，$D_i\sim N(1-0,1+1)=N(1,2)$ ← 依据：独立正态差仍正态，均值方差可加
9. 第九步：$\bar{X}-\bar{Y}=\dfrac{1}{n}\sum D_i\sim N\!\left(1,\dfrac{2}{n}\right)$ ← 依据：样本均值分布
10. 第十步：标准化分子 $\dfrac{\sqrt{n}\,[(\bar{X}-\bar{Y})-1]}{\sqrt{2}}\sim N(0,1)$ ← 依据：标准化
11. 第十一步：$(n-1)S_X^{2}/\sigma_1^{2}\sim\chi^{2}(n-1)$，$(n-1)S_Y^{2}/\sigma_2^{2}\sim\chi^{2}(n-1)$ ← 依据：正态总体样本方差分布
12. 第十二步：由 $\rho=0$ 知 $S_X^{2}$ 与 $S_Y^{2}$ 独立 ← 依据：二维正态独立性延伸
13. 第十三步：$\dfrac{(n-1)(S_X^{2}+S_Y^{2})}{1}\sim\chi^{2}(2n-2)$ ← 依据：独立卡方可加性（$\sigma_1^{2}=\sigma_2^{2}=1$）
14. 第十四步：$\dfrac{S_X^{2}+S_Y^{2}}{2}\sim\dfrac{\chi^{2}(2n-2)}{2n-2}$ ← 依据：标准化
15. 第十五步：$\bar{X}-\bar{Y}$ 与 $(S_X^{2},S_Y^{2})$ 独立 ← 依据：正态总体样本均值与样本方差独立
16. 第十六步：$T=\dfrac{\dfrac{\sqrt{n}\,[(\bar{X}-\bar{Y})-1]}{\sqrt{2}}}{\sqrt{\dfrac{S_X^{2}+S_Y^{2}}{2}}}=\dfrac{N(0,1)}{\sqrt{\chi^{2}(2n-2)/(2n-2)}}\sim t(2n-2)$ ← 依据：$t$ 分布定义

**关键步骤说明**：

- 第1问关键：因式分解 $XY\leq Y\Leftrightarrow Y(X-1)\leq 0$，利用独立性分两路相加
- 第2问关键：差变量 $D_i\sim N(1,2)$ 使分子标准化为 $N(0,1)$；$S_X^{2}+S_Y^{2}$ 由卡方可加性得 $\chi^{2}(2n-2)$
- 自由度 $2n-2$ 来自两个独立 $\chi^{2}(n-1)$ 相加
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$\rho=0$ 与独立等价遗忘**：未利用二维正态 $\rho=0\Leftrightarrow$ 独立 → 正确做法：$\rho=0$ 直接得 $X,Y$ 独立
2. **$XY\leq Y$ 因式分解错**：写成 $X\leq 1$ 漏掉 $Y$ 的符号讨论 → 正确做法：$Y(X-1)\leq 0$ 分 $Y\geq 0$ 与 $Y\leq 0$ 两路
3. **$t$ 分布自由度错**：取 $n-1$ 而非 $2n-2$ → 正确做法：两个独立 $\chi^{2}(n-1)$ 相加得 $\chi^{2}(2n-2)$，自由度 $2n-2$
4. **分子标准化系数错**：漏除 $\sqrt{2}$ → 正确做法：$D_i$ 方差为2，标准化需除 $\sqrt{2}$
:::

:::callout{kind=note label="知识卡片：二维正态独立性与 $t$ 分布构造"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 二维正态 $\rho=0$ | $X,Y$ 独立 | 二维正态分布 |
| 独立正态差 | $X_i-Y_i\sim N(\mu_1-\mu_2,\sigma_1^{2}+\sigma_2^{2})$ | $X_i,Y_i$ 独立 |
| 样本均值差 | $\bar{X}-\bar{Y}\sim N\!\left(\mu_1-\mu_2,\dfrac{\sigma_1^{2}+\sigma_2^{2}}{n}\right)$ | 独立正态总体 |
| 样本方差和 | $(n-1)(S_X^{2}+S_Y^{2})/\sigma^{2}\sim\chi^{2}(2n-2)$ | $\sigma_1^{2}=\sigma_2^{2}=\sigma^{2}$，独立 |
| $t$ 分布构造 | $T=\dfrac{N(0,1)}{\sqrt{\chi^{2}(\nu)/\nu}}\sim t(\nu)$ | 分子分母独立 |
| 卡方可加性 | 独立卡方相加自由度相加 | 独立性要求 |

**概念辨析**：
- 二维正态中 $\rho=0$ 与独立等价，但非二维正态分布此等价不成立（见第4大题）
- $t$ 分布构造要求分子 $N(0,1)$ 与分母 $\chi^{2}/\nu$ 独立，本题由正态总体样本均值与样本方差独立性保证
:::

:::callout{kind=tip label="结论速记"}
$\rho=0 \Rightarrow X \perp Y$，$XY \leq Y \Leftrightarrow Y(X-1) \leq 0$ 概率 $\frac{1}{2}$；差变量 $D_i \sim N(1,2)$，配 $S_X^{2}+S_Y^{2} \sim \chi^{2}(2n-2)$ 得 $T \sim t(2n-2)$。

**口诀**：rho为零即独立，因式分解两路加；差变量正态方差加，卡方相加自由度加；t分布分子分母独立。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"二维正态+$\rho=0$+统计量分布"→联想独立性 + 差变量 + $t$ 分布构造
- **关联考点**：二维正态独立性、$t$ 分布构造、卡方可加性；与第9题置信区间同属 $t$ 分布应用
- **复用场景**：两正态总体均值差检验、配对样本 $t$ 检验、独立样本 $t$ 检验
:::

## 六、（10 分）

### 第1题

:::callout{kind=note label="题目"}
设随机变量 $(X, Y)$ 的联合概率密度函数为

$$f(x,y) = \begin{cases} 3x, & 0 \leq y \leq x \leq 1 \\ 0, & \text{其它} \end{cases}$$

求：

1. $Z = X + Y$ 的概率密度函数；
2. $P\!\left(Y \leq \dfrac{1}{2}\right)$。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：读题识别第1问为连续型随机变量和的分布，用卷积公式 $f_Z(z)=\int f(x,z-x)\,dx$，需由密度非零区域 $0\leq y\leq x\leq 1$ 解出 $x$ 范围并分段讨论；第2问为区域概率，按 $x$ 与 $\dfrac{1}{2}$ 的大小关系分块积分。

**为何用此公式**：$Z=X+Y$ 的密度由卷积公式给出 $f_Z(z)=\int f(x,z-x)\,dx$；积分限由 $0\leq z-x\leq x\leq 1$ 解出 $\dfrac{z}{2}\leq x\leq\min(z,1)$；$z$ 跨越区域顶点（$z=1,2$）时密度表达式改变，需分段。

**推导过程**：

1. 第一步（第1问）：卷积公式 $f_Z(z)=\int_{-\infty}^{+\infty}f(x,z-x)\,dx$ ← 依据：和的分布卷积公式
2. 第二步：密度非零要求 $0\leq z-x\leq x\leq 1$，即 $\dfrac{z}{2}\leq x\leq z$ 且 $x\leq 1$ ← 依据：区域约束
3. 第三步：分段讨论 ← 依据：$x$ 上限为 $\min(z,1)$
4. 第四步：当 $0<z<1$ 时，$x\in\!\left[\dfrac{z}{2},z\right]$（自动满足 $x\leq 1$） ← 依据：$z<1$ 时 $z<1$
5. 第五步：$f_Z(z)=\int_{z/2}^{z}3x\,dx=\dfrac{3}{2}\!\left[z^{2}-\dfrac{z^{2}}{4}\right]=\dfrac{9}{8}z^{2}$ ← 依据：定积分计算
6. 第六步：当 $1\leq z<2$ 时，$x\in\!\left[\dfrac{z}{2},1\right]$ ← 依据：$x\leq 1$ 约束
7. 第七步：$f_Z(z)=\int_{z/2}^{1}3x\,dx=\dfrac{3}{2}\!\left[1-\dfrac{z^{2}}{4}\right]=\dfrac{3}{2}-\dfrac{3}{8}z^{2}$ ← 依据：定积分计算
8. 第八步：其它情形 $f_Z(z)=0$ ← 依据：密度非零区域外
9. 第九步（第2问）：$P\!\left(Y\leq\dfrac{1}{2}\right)=\iint_{y\leq 1/2}f(x,y)\,dx\,dy$ ← 依据：区域概率定义
10. 第十步：分块 ← 依据：$x$ 与 $\dfrac{1}{2}$ 的大小关系
11. 第十一步：当 $0\leq x\leq\dfrac{1}{2}$ 时，$y\in[0,x]$（整体满足 $y\leq\dfrac{1}{2}$） ← 依据：$x\leq\dfrac{1}{2}$ 时 $y\leq x\leq\dfrac{1}{2}$
12. 第十二步：$I_1=\int_{0}^{1/2}\int_{0}^{x}3x\,dy\,dx=\int_{0}^{1/2}3x^{2}\,dx=\left[x^{3}\right]_{0}^{1/2}=\dfrac{1}{8}$ ← 依据：累次积分
13. 第十三步：当 $\dfrac{1}{2}<x\leq 1$ 时，$y\in\!\left[0,\dfrac{1}{2}\right]$ ← 依据：$y\leq\dfrac{1}{2}$ 约束
14. 第十四步：$I_2=\int_{1/2}^{1}\int_{0}^{1/2}3x\,dy\,dx=\int_{1/2}^{1}\dfrac{3x}{2}\,dx=\dfrac{3}{4}\!\left[x^{2}\right]_{1/2}^{1}=\dfrac{3}{4}\!\left(1-\dfrac{1}{4}\right)=\dfrac{9}{16}$ ← 依据：累次积分
15. 第十五步：$P\!\left(Y\leq\dfrac{1}{2}\right)=\dfrac{1}{8}+\dfrac{9}{16}=\dfrac{2}{16}+\dfrac{9}{16}=\dfrac{11}{16}$ ← 依据：分块相加

**关键步骤说明**：

- 卷积积分限的确定：由 $0\leq z-x\leq x$ 解出 $x\geq\dfrac{z}{2}$，由 $x\leq 1$ 与 $x\leq z$ 取 $\min$
- 分段点 $z=1$：当 $z$ 跨越1时 $x$ 上限由 $z$ 切换为1
- 区域概率分块：以 $x=\dfrac{1}{2}$ 为界，$x\leq\dfrac{1}{2}$ 时 $y$ 上限为 $x$，$x>\dfrac{1}{2}$ 时 $y$ 上限为 $\dfrac{1}{2}$
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **卷积积分限取错**：把 $x$ 下限取为0而非 $\dfrac{z}{2}$ → 正确做法：由 $z-x\leq x$ 得 $x\geq\dfrac{z}{2}$
2. **分段遗漏**：未区分 $0<z<1$ 与 $1\leq z<2$ 两段 → 正确做法：$z$ 跨越1时 $x$ 上限由 $z$ 变为1，密度表达式改变
3. **区域概率分块错**：把 $y\leq\dfrac{1}{2}$ 区域当作单一积分 → 正确做法：以 $x=\dfrac{1}{2}$ 为界分两块，$y$ 上限不同
:::

:::callout{kind=note label="知识卡片：连续型随机变量和的分布与区域积分"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 卷积公式 | $f_Z(z)=\int f(x,z-x)\,dx$ | $Z=X+Y$ |
| 积分限确定 | 由 $0\leq z-x\leq x\leq 1$ 解出 $x$ 范围 | 密度非零区域约束 |
| 分段讨论 | $z$ 跨越区域顶点时密度表达式改变 | 此处 $z=1,2$ |
| 区域概率 | $P((X,Y)\in D)=\iint_D f(x,y)\,dx\,dy$ | 任意区域 |
| 分块积分 | 按 $x$ 与 $\dfrac{1}{2}$ 的大小关系分两块 | $y$ 上限不同 |

**概念辨析**：
- 卷积公式 $f_Z(z)=\int f(x,z-x)\,dx$ 与 $f_Z(z)=\int f(z-y,y)\,dy$ 等价，选哪个看密度形式
- 分段点由密度非零区域的顶点决定：区域 $0\leq y\leq x\leq 1$ 在 $z=x+y$ 方向的顶点为 $z=0,1,2$
:::

:::callout{kind=tip label="结论速记"}
和的密度用卷积，关键定 $x$ 上下限 $\left[\dfrac{z}{2}, \min(z,1)\right]$；区域概率分块积分，$P(Y \leq \frac{1}{2})=\dfrac{11}{16}$。

**口诀**：和的分布用卷积，积分限由区域定；分段讨论看顶点，区域概率分块积。
:::

- **关联考点**：卷积公式、区域概率、分段积分；与第4大题二维密度积分同属二重积分类

## 七、（12 分）

### 第1题

:::callout{kind=note label="题目"}
设总体 $X$ 的概率密度函数为

$$f(x;\, \mu, \sigma) = \frac{1}{2\sigma}\, e^{-\frac{|x-\mu|}{\sigma}}$$

其中 $-\infty < \mu < +\infty,\, \sigma > 0$ 是参数。从总体 $X$ 中抽取容量为 $n$ 的简单随机样本。

1. 求 $\mu, \sigma^{2}$ 的矩估计量；
2. $\sigma^{2}$ 的矩估计量是否为 $\sigma^{2}$ 的无偏估计量？为什么？
3. 如果有来自总体 $X$ 的简单随机样本 $(X_1, X_2, \ldots, X_9)$，其观察值为 $1.5,\, 1.2,\, 1.7,\, 1.4,\, 1.8,\, 1.4,\, 1.9,\, 1.3,\, 2$，求 $\mu, \sigma$ 的极大似然估计值。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：读题识别为拉普拉斯分布（位置参数 $\mu$、尺度参数 $\sigma$）；第1问用矩估计法（令样本矩等于总体矩）；第2问用无偏性定义 $E[\hat{\sigma}^{2}]=\sigma^{2}$ 检验；第3问构造似然函数，$\mu$ 的 MLE 为样本中位数（最小化绝对偏差和），$\sigma$ 的 MLE 由对数似然求导得到。

**为何用此公式**：矩估计令 $E(X)=\bar{X}$、$D(X)=\dfrac{1}{n}\sum(X_i-\bar{X})^{2}$；MLE 由似然函数最大化，拉普拉斯分布的 $\mu$ 使 $\sum|x_i-\mu|$ 最小（中位数性质）；无偏性用 $E[\hat{\sigma}^{2}]=\sigma^{2}$ 检验，需计算样本二阶中心矩的期望。

**推导过程**：

1. 第一步：识别分布为拉普拉斯分布（位置 $\mu$、尺度 $\sigma$） ← 依据：密度形式 $\dfrac{1}{2\sigma}e^{-|x-\mu|/\sigma}$
2. 第二步：计算总体矩 $E(X)=\mu$ ← 依据：密度关于 $\mu$ 对称
3. 第三步：$|X-\mu|\sim$ 参数 $\dfrac{1}{\sigma}$ 的指数分布，$E|X-\mu|=\sigma$，$E[(X-\mu)^{2}]=2\sigma^{2}$ ← 依据：指数分布二阶矩 $E[Y^{2}]=\dfrac{2}{\lambda^{2}}=2\sigma^{2}$
4. 第四步：故 $D(X)=E[(X-\mu)^{2}]=2\sigma^{2}$ ← 依据：方差定义

**（1）矩估计量**：

5. 第五步：令 $E(X)=\bar{X}$ 得 $\hat{\mu}=\bar{X}$ ← 依据：矩估计法（一阶矩相等）
6. 第六步：令 $D(X)=\dfrac{1}{n}\sum(X_i-\bar{X})^{2}$，即 $2\sigma^{2}=\dfrac{1}{n}\sum(X_i-\bar{X})^{2}$ ← 依据：矩估计法（二阶中心矩相等）
7. 第七步：$\hat{\sigma}^{2}=\dfrac{1}{2n}\sum_{i=1}^{n}(X_i-\bar{X})^{2}$ ← 依据：解方程

**（2）无偏性检验**：

8. 第八步：$E[\hat{\sigma}^{2}]=E\!\left[\dfrac{1}{2n}\sum(X_i-\bar{X})^{2}\right]=\dfrac{1}{2}\cdot E\!\left[\dfrac{1}{n}\sum(X_i-\bar{X})^{2}\right]$ ← 依据：期望线性性
9. 第九步：样本二阶中心矩期望 $E\!\left[\dfrac{1}{n}\sum(X_i-\bar{X})^{2}\right]=\dfrac{n-1}{n}D(X)=\dfrac{n-1}{n}\cdot 2\sigma^{2}$ ← 依据：样本方差与二阶中心矩关系 $E[S_n^{2}]=\dfrac{n-1}{n}\sigma^{2}_{总体}$
10. 第十步：$E[\hat{\sigma}^{2}]=\dfrac{1}{2}\cdot\dfrac{n-1}{n}\cdot 2\sigma^{2}=\dfrac{n-1}{n}\sigma^{2}\neq\sigma^{2}$ ← 依据：代入计算
11. 第十一步：故 $\hat{\sigma}^{2}$ 不是 $\sigma^{2}$ 的无偏估计量，存在偏差 $\dfrac{n-1}{n}\sigma^{2}-\sigma^{2}=-\dfrac{\sigma^{2}}{n}$ ← 依据：无偏性定义

**（3）极大似然估计**：

12. 第十二步：似然函数 $L(\mu,\sigma)=\prod_{i=1}^{n}\dfrac{1}{2\sigma}e^{-\frac{|x_i-\mu|}{\sigma}}=(2\sigma)^{-n}\exp\!\left(-\dfrac{1}{\sigma}\sum_{i=1}^{n}|x_i-\mu|\right)$ ← 依据：独立性乘积
13. 第十三步：对固定 $\sigma$，最大化 $L$ 等价于最小化 $\sum|x_i-\mu|$，其在样本中位数处取最小 ← 依据：绝对偏差和中位数性质
14. 第十四步：样本排序 $1.2,1.3,1.4,1.4,\mathbf{1.5},1.7,1.8,1.9,2$，中位数（第5个）为 $1.5$，故 $\hat{\mu}=1.5$ ← 依据：中位数定义
15. 第十五步：$\ln L=-n\ln(2\sigma)-\dfrac{1}{\sigma}\sum|x_i-\mu|$，对 $\sigma$ 求导令零 ← 依据：对数似然求导
16. 第十六步：$\hat{\sigma}=\dfrac{1}{n}\sum_{i=1}^{n}|x_i-\hat{\mu}|$ ← 依据：解方程
17. 第十七步：逐项计算 $|x_i-1.5|$ 之和

| $x_i$ | $|x_i-1.5|$ |
|-------|---------------|
| 1.5 | 0 |
| 1.2 | 0.3 |
| 1.7 | 0.2 |
| 1.4 | 0.1 |
| 1.8 | 0.3 |
| 1.4 | 0.1 |
| 1.9 | 0.4 |
| 1.3 | 0.2 |
| 2 | 0.5 |

← 依据：绝对值计算

18. 第十八步：$\sum|x_i-1.5|=0+0.3+0.2+0.1+0.3+0.1+0.4+0.2+0.5=2.1$ ← 依据：求和
19. 第十九步：$\hat{\sigma}=\dfrac{2.1}{9}=\dfrac{7}{30}$ ← 依据：代入公式

**关键步骤说明**：

- 矩估计 $\hat{\mu}=\bar{X}$ 与 MLE $\hat{\mu}=$ 中位数不同：前者用一阶矩，后者用绝对偏差最小化
- 无偏性检验关键：样本二阶中心矩期望为 $\dfrac{n-1}{n}D(X)$，故 $\hat{\sigma}^{2}$ 有偏
- MLE 的 $\mu$ 由中位数给出（拉普拉斯分布特性），与正态分布 $\mu$ 的 MLE 为 $\bar{X}$ 形成对比
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **矩估计与 MLE 混淆**：把 $\mu$ 的 MLE 当作 $\bar{X}$ → 正确做法：拉普拉斯分布 $\mu$ 的 MLE 为样本中位数（最小化绝对偏差和），矩估计才是 $\bar{X}$
2. **无偏性检验漏因子**：直接算 $E[\hat{\sigma}^{2}]=\sigma^{2}$ 未考虑样本二阶中心矩期望的 $\dfrac{n-1}{n}$ 系数 → 正确做法：$E\!\left[\dfrac{1}{n}\sum(X_i-\bar{X})^{2}\right]=\dfrac{n-1}{n}D(X)$，故 $E[\hat{\sigma}^{2}]=\dfrac{n-1}{n}\sigma^{2}$
3. **MLE 的 $\sigma$ 公式错**：把 $\hat{\sigma}$ 误为 $\dfrac{1}{n}\sum(X_i-\bar{X})^{2}$ → 正确做法：$\hat{\sigma}=\dfrac{1}{n}\sum|x_i-\hat{\mu}|$（绝对偏差均值，非平方偏差）
:::

:::callout{kind=note label="知识卡片：拉普拉斯分布的矩估计与极大似然估计"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 拉普拉斯密度 | $f(x)=\dfrac{1}{2\sigma}e^{-|x-\mu|/\sigma}$ | 位置 $\mu$、尺度 $\sigma$ |
| 期望与方差 | $E(X)=\mu$，$D(X)=2\sigma^{2}$ | — |
| $\mu$ 矩估计 | $\hat{\mu}=\bar{X}$ | 一阶矩相等 |
| $\sigma^{2}$ 矩估计 | $\hat{\sigma}^{2}=\dfrac{1}{2n}\sum(X_i-\bar{X})^{2}$ | 二阶中心矩相等 |
| 无偏性 | $E[\hat{\sigma}^{2}]=\dfrac{n-1}{n}\sigma^{2}\neq\sigma^{2}$（有偏） | 偏差 $-\dfrac{\sigma^{2}}{n}$ |
| $\mu$ 的 MLE | 样本中位数（最小化 $\sum\|x_i-\mu\|$） | 绝对偏差和中位数性质 |
| $\sigma$ 的 MLE | $\dfrac{1}{n}\sum\|x_i-\hat{\mu}\|$ | 对数似然求导 |
| 对比正态 | 正态 $\mu$ 的 MLE 是 $\bar{X}$，拉普拉斯 $\mu$ 的 MLE 是中位数 | 分布差异 |

**概念辨析**：
- 矩估计与 MLE 是两种不同估计方法：矩估计用样本矩等于总体矩，MLE 用似然函数最大化
- 拉普拉斯分布 $\mu$ 的 MLE 为中位数源于绝对偏差和在最小处取最小；正态分布 $\mu$ 的 MLE 为 $\bar{X}$ 源于平方偏差和最小
- 无偏性是估计量性质，矩估计与 MLE 都可能无偏或有偏
:::

:::callout{kind=tip label="结论速记"}
拉普拉斯分布：$\mu$ 矩估计 $=\bar{X}$，MLE $=$ 中位数；$\sigma^{2}$ 矩估计有偏（系数 $\frac{n-1}{n}$）；MLE $\hat{\sigma}=\dfrac{1}{n}\sum|x_i-\hat{\mu}|$。

**口诀**：拉普拉斯双参数，矩估均值方差半；MLE中位数定mu，绝对偏差均值定sigma；无偏检验看系数，n减一除n有偏差。
:::
