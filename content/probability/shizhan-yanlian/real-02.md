## 一、单项选择题（每题 3 分，共 30 分）

### 第 1 题

:::callout{kind=note label="题目"}
已知随机变量 $(X, Y)$ 服从二维正态分布，且 $DX \ne DY$，则（　　）

A. $X$ 与 $Y$ 一定独立　　B. $X$ 与 $Y$ 一定不独立　　C. $X+Y$ 与 $X-Y$ 一定独立　　D. $X+Y$ 与 $X-Y$ 一定不独立
:::

:::callout{kind=insight label="解析"}
**【答案】D**

**思路**：题干给出"二维正态 + $DX \ne DY$"，要求判断 $X+Y$ 与 $X-Y$ 的独立性。入口是识别"两个线性组合的独立性"考点，二维正态下独立性等价于协方差为零，因此只需计算 $\text{Cov}(X+Y, X-Y)$ 并判断其是否为零。

**为何用此公式**：协方差的双线性公式 $\text{Cov}(aX+bY, cX+dY) = ac\,DX + (ad+bc)\text{Cov}(X,Y) + bd\,DY$ 可直接展开 $\text{Cov}(X+Y, X-Y)$，无需分别求 $X+Y$ 与 $X-Y$ 的联合分布，计算量最小。

**推导过程**：

1. 第一步：识别 $(X+Y, X-Y)$ 的联合分布类型 ← 依据：二维正态分布的线性变换不变性（任意线性组合仍为二维正态）
2. 第二步：展开协方差 $\text{Cov}(X+Y, X-Y)$ ← 依据：协方差双线性公式
   $$\text{Cov}(X+Y, X-Y) = \text{Cov}(X,X) - \text{Cov}(X,Y) + \text{Cov}(Y,X) - \text{Cov}(Y,Y)$$
3. 第三步：化简 ← 依据：$\text{Cov}(X,X)=DX$，$\text{Cov}(Y,Y)=DY$，$\text{Cov}(X,Y)=\text{Cov}(Y,X)$
   $$\text{Cov}(X+Y, X-Y) = DX - DY$$
4. 第四步：由 $DX \ne DY$ 得 $\text{Cov}(X+Y, X-Y) \ne 0$ ← 依据：题设条件
5. 第五步：判定独立性 ← 依据：二维正态分布下"独立 $\Leftrightarrow$ 不相关 $\Leftrightarrow$ 协方差为零"
   故 $X+Y$ 与 $X-Y$ 不独立。

**选项分析**：

- **A（错误）**：二维正态下 $X$ 与 $Y$ 独立等价于相关系数 $\rho=0$，与 $DX \ne DY$ 无关。$DX \ne DY$ 既不蕴含 $\rho=0$ 也不蕴含 $\rho \ne 0$。
- **B（错误）**：$DX \ne DY$ 不蕴含 $\rho \ne 0$，独立性由相关系数决定而非方差差异。当 $\rho=0$ 时即使 $DX \ne DY$，$X$ 与 $Y$ 仍独立。
- **C（错误）**：$\text{Cov}(X+Y, X-Y) = DX - DY \ne 0$，二者相关从而不独立。此选项误把"协方差为零"当成默认成立。
- **D（正确）**：由上述推导，$\text{Cov}(X+Y, X-Y) = DX - DY \ne 0$，二维正态下协方差非零即不独立。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **混淆"边缘独立"与"联合独立"**：误以为仅凭 $DX \ne DY$ 就能判断 $X$ 与 $Y$ 的独立性 → 正确做法：二维正态下 $X$ 与 $Y$ 的独立性唯一由 $\rho$ 决定，与方差是否相等无关。
2. **忽略二维正态的特有性质**：误把"独立 $\Leftrightarrow$ 不相关"当作所有分布都成立的性质 → 正确做法：该等价仅对联合正态分布成立，一般分布下"独立 $\Rightarrow$ 不相关"但逆不真。
3. **协方差展开符号出错**：展开 $\text{Cov}(X+Y, X-Y)$ 时漏掉交叉项符号，误得 $\text{Cov}(X+Y, X-Y) = DX + DY$ → 正确做法：严格按双线性公式逐项展开，交叉项 $\text{Cov}(X,Y)$ 与 $\text{Cov}(Y,X)$ 一正一负相互抵消，结果为 $DX - DY$。
:::

:::callout{kind=note label="知识卡片：二维正态分布的性质"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 边缘分布 | $X$、$Y$ 各自服从一维正态 | $(X,Y)$ 已知为二维正态（逆不真） |
| 线性变换不变性 | $(aX+bY,\ cX+dY)$ 仍服从二维正态 | 系数矩阵非奇异 |
| 独立 $\Leftrightarrow$ 不相关 | 二维正态下二者等价 | 仅联合正态成立，一维正态无此性质 |
| 协方差公式 | $\text{Cov}(X+Y,\ X-Y) = DX - DY$ | 任意有二阶矩的随机变量 |
| 边缘独立推联合 | 边缘独立 $\Leftrightarrow$ 联合独立 | 仅当 $(X,Y)$ 已知为二维正态 |

**概念辨析**：
- "独立 $\Leftrightarrow$ 不相关"是二维正态的特有性质：一般分布下独立必不相关，但不相关不一定独立（反例：$X \sim U(-1,1)$，$Y=X^2$，则 $\text{Cov}(X,Y)=0$ 但 $Y$ 完全由 $X$ 决定）。
- 公式 $\text{Cov}(X+Y, X-Y) = DX - DY$ 对任意有二阶矩的随机变量都成立，不要求正态性；但用它判断独立性时，"协方差为零 $\Rightarrow$ 独立"仅在二维正态下成立。
:::

:::callout{kind=tip label="结论速记"}
判定 $X+Y$ 与 $X-Y$ 独立性：算 $\text{Cov}(X+Y, X-Y) = DX - DY$，非零则不独立。

**口诀**：协差双线展开，$DX$ 减 $DY$，非零即不独立，零才可独立。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"两个线性组合的独立性"→ 联想"协方差双线性展开 + 二维正态特有性质"
- **关联考点**：协方差性质（第四章）、二维正态分布（第三章）、独立性与不相关性的等价条件
- **复用场景**：任何形如"$aX+bY$ 与 $cX+dY$ 是否独立"的判断题，均可先算协方差再结合分布类型判断
:::

### 第 2 题

:::callout{kind=note label="题目"}
设随机变量 $X \sim N(100, 100)$，随机抽取容量为 10 的样本，令样本均值为 $Y$，则（　　）

A. $EY = 100,\ DY = 100$　　B. $EY = 100,\ DY = 10$　　C. $EY = 10,\ DY = 100$　　D. $EY = 10,\ DY = 10$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：题干给出总体 $X \sim N(\mu, \sigma^2)$ 即 $N(100, 100)$，样本容量 $n=10$，求样本均值 $Y=\bar{X}$ 的期望与方差。入口是识别"样本均值的数字特征"考点，直接套用样本均值期望不变、方差缩 $n$ 倍的结论。

**为何用此公式**：样本均值 $\bar{X} = \dfrac{1}{n}\sum_{i=1}^{n} X_i$ 的期望与方差有标准公式 $E\bar{X}=\mu$、$D\bar{X}=\sigma^2/n$，比用定义 $E\bar{X}=\dfrac{1}{n}\sum EX_i$ 重新推导更便捷，且对任意总体（不限于正态）都成立。

**推导过程**：

1. 第一步：识别总体参数 ← 依据：$X \sim N(\mu, \sigma^2)$ 记号约定（前一参数为均值，后一参数为方差）
   $$\mu = 100, \quad \sigma^2 = 100$$
2. 第二步：写出样本均值定义 ← 依据：$\bar{X} = \dfrac{1}{n}\sum_{i=1}^{n} X_i$
3. 第三步：计算期望 ← 依据：期望的线性性 $E\bar{X} = \dfrac{1}{n}\sum EX_i = \dfrac{1}{n} \cdot n\mu = \mu$
   $$EY = E\bar{X} = \mu = 100$$
4. 第四步：计算方差 ← 依据：样本独立性下 $D\bar{X} = \dfrac{1}{n^2}\sum DX_i = \dfrac{1}{n^2} \cdot n\sigma^2 = \dfrac{\sigma^2}{n}$
   $$DY = D\bar{X} = \frac{\sigma^2}{n} = \frac{100}{10} = 10$$
5. 第五步：对照选项得 $EY=100, DY=10$ ← 依据：数值代入

**选项分析**：

- **A（错误）**：$DY$ 计算为 $\sigma^2=100$，对应"忘记除以 $n$"的错误，正确应为 $\sigma^2/n=10$。
- **B（正确）**：$EY=\mu=100$，$DY=\sigma^2/n=100/10=10$，与推导一致。
- **C（错误）**：$EY$ 计算为 $10$，对应"把样本容量当期望"的错误；$DY=100$ 同样未除以 $n$。
- **D（错误）**：两个量都错，$EY$ 误取 $n$，$DY$ 误取 $\sigma^2/n$ 后又错算。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **正态记号混淆**：把 $N(\mu, \sigma^2)$ 的第二个参数误认为标准差 → 正确做法：$N(100, 100)$ 中第二个 $100$ 是方差 $\sigma^2$，标准差 $\sigma=10$。
2. **方差忘记除以 $n$**：直接取 $D\bar{X}=\sigma^2$ → 正确做法：样本均值方差公式 $D\bar{X}=\sigma^2/n$，因 $\bar{X}$ 是 $n$ 个独立样本的平均，方差缩 $n^2$ 倍后除以 $n^2$ 得 $\sigma^2/n$。
3. **期望与样本容量混淆**：误把 $EY$ 取为 $n=10$ → 正确做法：期望的线性性给出 $E\bar{X}=\mu$，与样本容量无关。
:::

:::callout{kind=note label="知识卡片：样本均值的数字特征"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 期望 | $E\bar{X} = \mu$ | 任意总体，样本 i.i.d. |
| 方差 | $D\bar{X} = \sigma^2/n$ | 样本独立 |
| 分布（正态总体） | $\bar{X} \sim N(\mu,\ \sigma^2/n)$ | 总体正态 |
| 标准化 | $\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$ | 总体正态或 $n$ 较大（CLT） |
| 本题结果 | $EY=100$，$DY=10$，$Y \sim N(100, 10)$ | $\mu=100, \sigma^2=100, n=10$ |

**概念辨析**：
- "期望不变、方差缩 $n$ 倍"对任意总体成立（只要样本独立同分布），不要求正态性；但"$\bar{X}$ 服从正态"仅当总体正态或 $n$ 较大时成立。
- $D\bar{X} = \sigma^2/n$ 而非 $\sigma^2/n^2$：因 $\bar{X}=\dfrac{1}{n}\sum X_i$，方差为 $\dfrac{1}{n^2}\sum DX_i = \dfrac{1}{n^2}\cdot n\sigma^2 = \sigma^2/n$。
:::

:::callout{kind=tip label="结论速记"}
样本均值期望不变、方差缩 $n$ 倍：$E\bar{X}=\mu$，$D\bar{X}=\sigma^2/n$。

**口诀**：均值不变承总体，方差缩小 $n$ 倍数。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"样本均值的期望/方差"→ 联想"$E\bar{X}=\mu$，$D\bar{X}=\sigma^2/n$"
- **关联考点**：抽样分布（第六章）、中心极限定理、正态总体的统计量分布
- **复用场景**：任何涉及样本均值数字特征的题目，包括置信区间估计、假设检验中统计量的构造
:::

### 第 3 题

:::callout{kind=note label="题目"}
设随机变量 $X$ 的分布函数为

$$F(x) = \begin{cases} 0, & x \le a, \\ x^2 - 3b, & a < x \le 2, \\ c, & x > 2, \end{cases}$$

则 $a$ 的值为（　　）

A. $-\sqrt{3}$　　B. $\sqrt{3}$　　C. $1$　　D. $0$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：分布函数含三个未知参数 $a, b, c$，需利用分布函数的三大性质（归一性、右连续性、单调不减非负性）列方程定参。入口是先由归一性定 $c$，再用右连续性建方程，最后用非负性排除增根。

**为何用此公式**：分布函数的右连续性 $F(x_0)=F(x_0^+)$ 在分段点处给出方程，是定参的标准工具；归一性 $\lim_{x\to+\infty}F(x)=1$ 直接定端点常数。比尝试密度函数积分更直接。

**推导过程**：

1. 第一步：由归一性定 $c$ ← 依据：分布函数极限性质 $\lim_{x\to+\infty} F(x) = 1$
   $$c = 1$$
2. 第二步：在 $x=2$ 处用右连续性 ← 依据：$F(2) = F(2^+) = c$
   $$F(2) = 2^2 - 3b = 4 - 3b, \quad F(2^+) = c = 1$$
   $$4 - 3b = 1 \Rightarrow b = 1$$
3. 第三步：在 $x=a$ 处用右连续性 ← 依据：$F(a) = F(a^+)$
   $$F(a) = 0, \quad F(a^+) = a^2 - 3b = a^2 - 3$$
   $$a^2 - 3 = 0 \Rightarrow a = \pm\sqrt{3}$$
4. 第四步：用非负性排除增根 ← 依据：分布函数满足 $0 \le F(x) \le 1$
   - 若 $a = -\sqrt{3}$：中段 $F(x) = x^2 - 3$ 在 $x \in (-\sqrt{3}, 0)$ 上取负值（如 $x=0$ 时 $F(0)=-3<0$），违反非负性，排除。
   - 若 $a = \sqrt{3}$：中段 $F(x) = x^2 - 3$ 在 $x \in (\sqrt{3}, 2]$ 上取值 $[0, 1]$，满足非负性与单调不减，合法。
5. 第五步：验证单调不减 ← 依据：$F$ 在各段内单调不减且分段点处不降
   - $x \le a$ 段 $F=0$；中段 $F(x)=x^2-3$ 在 $(\sqrt{3}, 2]$ 上递增；$x>2$ 段 $F=1$，合法。
   故 $a = \sqrt{3}$。

**选项分析**：

- **A（错误）**：$a=-\sqrt{3}$ 时中段 $F(x)=x^2-3$ 在 $(-\sqrt{3}, 0)$ 上取负值（如 $F(0)=-3$），违反 $F(x)\ge 0$，分布函数不合法。
- **B（正确）**：$a=\sqrt{3}$ 时各段取值合法，$F(\sqrt{3}^+)=0$，$F(2)=1$，非负单调，满足分布函数所有性质。
- **C（错误）**：$a=1$ 时 $F(1^+) = 1 - 3 = -2 < 0$，违反非负性，不合法。
- **D（错误）**：$a=0$ 时 $F(0^+) = 0 - 3 = -3 < 0$，违反非负性，不合法。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **忽略非负性排除增根**：解出 $a=\pm\sqrt{3}$ 后直接选 $-\sqrt{3}$ → 正确做法：必须用 $0 \le F(x) \le 1$ 验证候选解，$a=-\sqrt{3}$ 使中段取负值，排除。
2. **右连续性用错方向**：误用 $F(x_0^-)=F(x_0)$（左连续） → 正确做法：分布函数右连续，分段点处用 $F(x_0)=F(x_0^+)$（右极限等于函数值）。
3. **归一性遗漏**：忘记先定 $c=1$，直接对 $a$ 列方程 → 正确做法：先归一定端点常数 $c$，再右连续建方程，最后非负性排增根，三步缺一不可。
:::

:::callout{kind=note label="知识卡片：分布函数的确定方法"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 归一性 | $F(-\infty)=0$，$F(+\infty)=1$ | 任意分布函数 |
| 右连续 | $F(x_0) = F(x_0^+)$ | 任意分布函数 |
| 单调不减 | $x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)$ | 任意分布函数 |
| 非负性 | $0 \le F(x) \le 1$ | 任意分布函数 |
| 定参流程 | 归一定端点 → 右连续建方程 → 非负性排增根 | 分段分布函数 |

**概念辨析**：
- 分布函数右连续而非左连续：$F(x_0) = \lim_{x\to x_0^+} F(x)$，这是中国教材通用约定（与某些国外教材的左连续约定不同）。
- "非负性"不仅要求 $F \ge 0$，还要求 $F \le 1$；解出候选参数后必须验证全段取值在 $[0,1]$ 内，否则为增根。
:::

:::callout{kind=tip label="结论速记"}
分布函数定参：先归一定 $c=1$，再右连续列方程，最后用非负性排除增根。

**口诀**：归一定端，右连续列方程，非负排增根。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"分段分布函数 + 未知参数"→ 联想"归一性 + 右连续性 + 非负性三步定参"
- **关联考点**：分布函数定义（第二章）、连续型随机变量的密度与分布函数关系
- **复用场景**：任何含未知参数的分段分布函数定参题，包括离散型与连续型
:::

### 第 4 题

:::callout{kind=note label="题目"}
设随机变量序列 $\{X_i,\ i \ge 1\}$ 独立且都服从参数为 $\dfrac{1}{2}$ 的泊松分布。如果常数 $C$ 使

$$\lim_{n\to\infty} P\left\{ \frac{C}{\sqrt{n}} \sum_{i=1}^{n}(X_{2i} - X_{2i-1}) \le x \right\} = \Phi(x),$$

其中 $\Phi(x)$ 为标准正态分布函数，则 $C = $（　　）

A. $1$　　B. $2$　　C. $\sqrt{2}$　　D. $\sqrt{3}$
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：题干给出独立同分布序列与极限分布为标准正态，要求定常数 $C$。入口是识别"中心极限定理定常数"考点：将 $\sum (X_{2i}-X_{2i-1})$ 标准化后极限应为 $N(0,1)$，比较系数得 $C$。

**为何用此公式**：Lindeberg-Lévy CLT 适用于独立同分布序列，标准化量 $\dfrac{\sum Y_i - n\mu_Y}{\sigma_Y\sqrt{n}} \to N(0,1)$。本题 $Y_i = X_{2i}-X_{2i-1}$ 满足 iid 条件，直接套用最简洁。

**推导过程**：

1. 第一步：定义新变量 $Y_i = X_{2i} - X_{2i-1}$ ← 依据：将求和对象统一记号便于分析
2. 第二步：计算 $Y_i$ 的期望 ← 依据：$X_i$ 独立同服从 $P(1/2)$，期望 $EX_i = 1/2$
   $$EY_i = EX_{2i} - EX_{2i-1} = \frac{1}{2} - \frac{1}{2} = 0$$
3. 第三步：计算 $Y_i$ 的方差 ← 依据：独立性和方差可加性 $D(X-Y)=DX+DY$（差方差相加）
   $$DY_i = DX_{2i} + DX_{2i-1} = \frac{1}{2} + \frac{1}{2} = 1$$
   （泊松分布 $P(\lambda)$ 的方差为 $\lambda$）
4. 第四步：验证 $\{Y_i\}$ 满足 CLT 条件 ← 依据：$X_i$ 独立 $\Rightarrow$ $Y_i$ 独立；同分布 $\Rightarrow$ $Y_i$ 同分布；方差有限
5. 第五步：应用 Lindeberg-Lévy CLT ← 依据：$\dfrac{\sum_{i=1}^n Y_i - n\mu_Y}{\sigma_Y\sqrt{n}} \xrightarrow{d} N(0,1)$
   $$\frac{\sum_{i=1}^{n} Y_i - n \cdot 0}{1 \cdot \sqrt{n}} = \frac{1}{\sqrt{n}} \sum_{i=1}^{n} Y_i \xrightarrow{d} N(0, 1)$$
6. 第六步：比较系数定 $C$ ← 依据：题设 $\dfrac{C}{\sqrt{n}} \sum Y_i \to N(0,1)$，而 CLT 给出 $\dfrac{1}{\sqrt{n}} \sum Y_i \to N(0,1)$
   $$C \cdot \frac{1}{\sqrt{n}} \sum Y_i \to N(0, C^2 \cdot 1) = N(0, C^2)$$
   要求极限为 $N(0,1)$，故 $C^2 = 1$，即 $C = 1$（取正值）。

**选项分析**：

- **A（正确）**：$C=1$ 时 $\dfrac{1}{\sqrt{n}}\sum Y_i \to N(0,1)$，与 CLT 结论完全一致。
- **B（错误）**：$C=2$ 时极限为 $N(0, 4)$，方差为 4 而非 1，非标准正态。
- **C（错误）**：$C=\sqrt{2}$ 时极限为 $N(0, 2)$，方差为 2，非标准正态。
- **D（错误）**：$C=\sqrt{3}$ 时极限为 $N(0, 3)$，方差为 3，非标准正态。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **差方差误算为差**：误用 $D(X-Y)=DX-DY$ → 正确做法：独立变量差的方差仍相加，$D(X-Y)=DX+DY$，因 $D(-Y)=DY$。
2. **CLT 标准化系数搞反**：误认为 $C = \sigma$ 而非 $C = 1/\sigma$ → 正确做法：标准化量为 $\dfrac{1}{\sigma\sqrt{n}}\sum (Y_i-\mu)$，故系数 $C = 1/\sigma_Y$，本题 $\sigma_Y=1$ 故 $C=1$。
3. **忽略 $\mu=0$ 的简化**：忘记先算 $EY_i=0$，误引入非零均值项 → 正确做法：先算期望，本题 $EY_i=0$ 使标准化无需减均值项，直接 $\dfrac{1}{\sigma\sqrt{n}}\sum Y_i$。
:::

:::callout{kind=note label="知识卡片：中心极限定理（CLT）"}
| 定理 | 内容 | 适用条件 |
|------|------|---------|
| Lindeberg-Lévy | $\dfrac{\sum X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)$ | $\{X_i\}$ iid，$EX_i=\mu$，$DX_i=\sigma^2<\infty$ |
| 棣莫弗-拉普拉斯 | $\dfrac{S_n - np}{\sqrt{np(1-p)}} \xrightarrow{d} N(0,1)$ | $X_i \sim B(1,p)$，$S_n = \sum X_i$ |
| Liapunov | $\dfrac{\sum X_i - \sum \mu_i}{\sqrt{\sum \sigma_i^2}} \xrightarrow{d} N(0,1)$ | 独立（不必同分布），三阶矩有界 |
| 定常数法 | 标准化后极限方差为 1 → $C = 1/\sigma$ | 极限须为 $N(0,1)$ |

**概念辨析**：
- "iid"要求独立且同分布，二者缺一不可：仅独立不同分布用 Liapunov，仅同分布不独立需其他定理。
- CLT 标准化系数 $C=1/\sigma$ 而非 $C=\sigma$：因标准化量为 $\dfrac{1}{\sigma\sqrt{n}}\sum(Y_i-\mu)$，要求 $C^2\sigma^2=1$。
:::

:::callout{kind=tip label="结论速记"}
CLT 定常数：标准化后极限须为 $N(0,1)$，故 $C = 1/\sigma_Y$。本题 $\sigma_Y = 1$，故 $C = 1$。

**口诀**：差方差相加，标准化除 $\sigma$，极限方差 1 定 $C$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"极限分布为标准正态 + 定常数"→ 联想"CLT 标准化，$C=1/\sigma$"
- **关联考点**：大数定律与中心极限定理（第五章）、泊松分布的期望方差、独立变量差的方差
- **复用场景**：任何"求和极限分布 + 定标准化常数"的题目，包括二项分布、泊松分布、均匀分布等情形
:::

### 第 5 题

:::callout{kind=note label="题目"}
设 $X_1, X_2, \cdots, X_n$ 是来自总体 $N(\mu, \sigma^2)$ 的样本，

$$\bar{X} = \frac{1}{n}\sum_{i=1}^{n} X_i, \quad S_1^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \bar{X})^2, \quad S_2^2 = \frac{1}{n}\sum_{i=1}^{n}(X_i - \bar{X})^2$$

$$S_3^2 = \frac{1}{n-1}\sum_{i=1}^{n}(X_i - \mu)^2, \quad S_4^2 = \frac{1}{n}\sum_{i=1}{n}(X_i - \mu)^2$$

则服从 $t(n)$ 分布的随机变量是（　　）

A. $T_1 = \dfrac{\bar{X}-\mu}{S_1/\sqrt{n-1}}$　　B. $T_2 = \dfrac{\bar{X}-\mu}{S_2/\sqrt{n-1}}$　　C. $T_3 = \dfrac{\bar{X}-\mu}{S_3/\sqrt{n}}$　　D. $T_4 = \dfrac{\bar{X}-\mu}{S_4/\sqrt{n}}$
:::

:::callout{kind=insight label="解析"}
**【答案】D**（按原参考答案）

**思路**：题干给出四种样本方差定义与四种 $t$ 统计量构造，要求判断哪个服从 $t(n)$。入口是识别"$t$ 分布三要素"：分子为 $N(0,1)$、分母为 $\sqrt{\chi^2/\nu}$、分子分母独立。需逐项检验三要素是否同时满足。

**为何用此公式**：$t$ 分布的定义 $T = \dfrac{Z}{\sqrt{V/\nu}}$（$Z\sim N(0,1)$，$V\sim\chi^2(\nu)$，$Z$ 与 $V$ 独立）是判定 $t$ 统计量的唯一标准，比记忆具体公式更可靠，能识别"自由度匹配"与"独立性"两个隐藏陷阱。

**推导过程**：

1. 第一步：写出 $t$ 分布定义 ← 依据：$T = \dfrac{Z}{\sqrt{V/\nu}}$，$Z \sim N(0,1)$，$V \sim \chi^2(\nu)$，$Z \perp V$
2. 第二步：分析分子 $\bar{X}-\mu$ 的分布 ← 依据：正态样本均值性质
   $$\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$$
   即分子经标准化后为 $N(0,1)$。
3. 第三步：分析各 $S_i^2$ 对应的 $\chi^2$ 量与自由度 ← 依据：正态样本二次型分布
   - $S_1^2$：$\dfrac{(n-1)S_1^2}{\sigma^2} = \dfrac{\sum(X_i-\bar{X})^2}{\sigma^2} \sim \chi^2(n-1)$，自由度 $n-1$，且**与 $\bar{X}$ 独立**
   - $S_2^2$：$\dfrac{nS_2^2}{\sigma^2} = \dfrac{\sum(X_i-\bar{X})^2}{\sigma^2} \sim \chi^2(n-1)$，自由度 $n-1$，与 $\bar{X}$ 独立
   - $S_3^2$：$\dfrac{(n-1)S_3^2}{\sigma^2} = \dfrac{\sum(X_i-\mu)^2}{\sigma^2} \sim \chi^2(n)$，自由度 $n$，但**与 $\bar{X}$ 不独立**
   - $S_4^2$：$\dfrac{nS_4^2}{\sigma^2} = \dfrac{\sum(X_i-\mu)^2}{\sigma^2} \sim \chi^2(n)$，自由度 $n$，与 $\bar{X}$ **不独立**
4. 第四步：检验各选项的"三要素"匹配 ← 依据：$t$ 分布定义
   - **A** $T_1 = \dfrac{\bar{X}-\mu}{S_1/\sqrt{n-1}}$：分子 $\bar{X}-\mu$，分母含 $S_1$（自由度 $n-1$）。改写为 $\dfrac{(\bar{X}-\mu)/(\sigma/\sqrt{n})}{\sqrt{\dfrac{(n-1)S_1^2/\sigma^2}{n-1}} \cdot \dfrac{n-1}{n}}$，系数不匹配 $t(n-1)$ 而非 $t(n)$。
   - **B** $T_2 = \dfrac{\bar{X}-\mu}{S_2/\sqrt{n-1}}$：$S_2$ 用除数 $n$，自由度仍 $n-1$，系数匹配后 $\sim t(n-1)$ 而非 $t(n)$。
   - **C** $T_3 = \dfrac{\bar{X}-\mu}{S_3/\sqrt{n}}$：$S_3$ 含 $\mu$，对应 $\chi^2(n)$，自由度匹配 $t(n)$，但 $\bar{X}$ 与 $\sum(X_i-\mu)^2$ **不独立**，不满足第三要素。
   - **D** $T_4 = \dfrac{\bar{X}-\mu}{S_4/\sqrt{n}}$：$S_4$ 含 $\mu$，对应 $\chi^2(n)$，自由度匹配 $t(n)$。原参考答案"意图"认为二者独立从而 $T_4 \sim t(n)$。
5. 第五步：严格性说明 ← 依据：$\bar{X}$ 与 $\sum(X_i-\mu)^2$ 不独立的证明
   $$(X_i - \mu) = (X_i - \bar{X}) + (\bar{X} - \mu)$$
   故 $\sum(X_i-\mu)^2 = \sum(X_i-\bar{X})^2 + n(\bar{X}-\mu)^2$，含 $\bar{X}$ 项，二者不独立。
   严格来说四个选项均不严格服从 $t(n)$，原答案 D 有瑕疵。正确的 $t$ 统计量应为 $\dfrac{\bar{X}-\mu}{S_1/\sqrt{n}} \sim t(n-1)$。

**选项分析**：

- **A（错误）**：$T_1$ 分母用 $\sqrt{n-1}$ 而非 $\sqrt{n}$，标准化后对应 $t(n-1)$ 而非 $t(n)$，自由度不匹配。
- **B（错误）**：$T_2 = \dfrac{\bar{X}-\mu}{S_2/\sqrt{n-1}} = \sqrt{n}(\bar{X}-\mu)/S_1 \cdot \sqrt{(n-1)/n}$，化简后 $\sim t(n-1)$ 而非 $t(n)$。
- **C（错误）**：$S_3$ 含 $\mu$ 使 $\sum(X_i-\mu)^2 \sim \chi^2(n)$，自由度匹配 $t(n)$，但 $\bar{X}$ 与 $\sum(X_i-\mu)^2$ 不独立，违反 $t$ 分布第三要素。
- **D（按原答案）**：原参考答案认定 $T_4 \sim t(n)$，其逻辑是 $\sqrt{n}(\bar{X}-\mu)/\sigma \sim N(0,1)$ 与 $nS_4^2/\sigma^2 \sim \chi^2(n)$ 组合。但严格而言二者不独立，故 $T_4$ 并不严格服从 $t(n)$，此为原题瑕疵。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **忽略"分子分母独立"要素**：只看分子 $N(0,1)$ 与分母 $\chi^2$ 自由度，忽略独立性 → 正确做法：$t$ 分布三要素缺一不可，含 $\mu$ 的 $S_3, S_4$ 使 $\sum(X_i-\mu)^2$ 与 $\bar{X}$ 不独立。
2. **自由度匹配错误**：误以为 $S_1$（除数 $n-1$）对应自由度 $n$ → 正确做法：$\sum(X_i-\bar{X})^2$ 自由度恒为 $n-1$（因约束 $\sum(X_i-\bar{X})=0$），与除数无关；$\sum(X_i-\mu)^2$ 自由度为 $n$。
3. **混淆 $\sqrt{n}$ 与 $\sqrt{n-1}$**：分母根号内用 $n-1$ 而非 $n$ → 正确做法：标准 $t$ 统计量 $\dfrac{\bar{X}-\mu}{S/\sqrt{n}}$，根号内为 $n$；用 $\sqrt{n-1}$ 时自由度对应 $n-1$。
:::

:::callout{kind=note label="知识卡片：正态样本的抽样分布"}
| 统计量 | 分布 | 自由度 | 与 $\bar{X}$ 独立性 | 适用条件 |
|--------|------|--------|---------------------|---------|
| $\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}$ | $N(0,1)$ | — | — | $\sigma$ 已知 |
| $\dfrac{(n-1)S_1^2}{\sigma^2}=\dfrac{\sum(X_i-\bar{X})^2}{\sigma^2}$ | $\chi^2(n-1)$ | $n-1$ | 独立 | 正态总体 |
| $\dfrac{\sum(X_i-\mu)^2}{\sigma^2}$ | $\chi^2(n)$ | $n$ | **不独立** | $\mu$ 已知 |
| $\dfrac{\bar{X}-\mu}{S_1/\sqrt{n}}$ | $t(n-1)$ | $n-1$ | $\bar{X} \perp S_1^2$ | $\sigma$ 未知 |
| $\dfrac{\bar{X}-\mu}{S_4/\sqrt{n}}$ | 形式似 $t(n)$ | $n$ | **不独立** | 严格不服从 $t$ |

**概念辨析**：
- "$\bar{X}$ 与 $\sum(X_i-\bar{X})^2$ 独立"是正态样本的特有性质（Basu 定理的推论），非正态总体不成立。
- "$\bar{X}$ 与 $\sum(X_i-\mu)^2$ 不独立"：因 $(X_i-\mu)=(X_i-\bar{X})+(\bar{X}-\mu)$，展开后含 $\bar{X}$ 项。这是本题最易被忽略的陷阱。
- 自由度由"约束个数"决定：$\sum(X_i-\bar{X})^2$ 有约束 $\sum(X_i-\bar{X})=0$，自由度 $n-1$；$\sum(X_i-\mu)^2$ 无约束，自由度 $n$。
:::

:::callout{kind=tip label="结论速记"}
$t$ 统计量三要素：① 分子 $N(0,1)$；② 分母 $\sqrt{\chi^2/\nu}$；③ **分子分母独立**。本题严格无解，原答案 D 有瑕疵。

**口诀**：三要素齐全才 $t$ 分布，含 $\mu$ 的方差与均值不独立。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$t$ 统计量判断"→ 联想"三要素：$N(0,1)$ + $\chi^2/\nu$ + 独立性"
- **关联考点**：抽样分布（第六章）、$\chi^2$ 与 $t$ 分布定义、正态样本的独立性（Basu 定理）
- **复用场景**：任何判断统计量服从何种抽样分布的题目，特别是含 $\bar{X}$ 与 $S^2$ 的组合
:::

### 第 6 题

:::callout{kind=note label="题目"}
某人向一个目标射击，直到击中 $r$ 次为止。假设每次射击命中目标的概率为 $p$，$0 < p < 1$。$X$ 为射击停止时未命中目标的次数，则对 $k = 0, 1, 2, \cdots$，$P(X = k) = $（　　）

A. $C_{k+r}^{r}\, p^r (1-p)^k$　　B. $C_{k+r-1}^{r}\, p^r (1-p)^k$　　C. $C_{k+r}^{r-1}\, p^r (1-p)^k$　　D. $C_{k+r-1}^{k}\, p^r (1-p)^k$
:::

:::callout{kind=insight label="解析"}
**【答案】D**

**思路**：题干描述"射击到第 $r$ 次命中为止，求未命中次数 $X=k$ 的概率"。入口是识别"负二项分布（帕斯卡分布）"考点：最后一次必须命中，前 $k+r-1$ 次中恰有 $r-1$ 次命中。

**为何用此公式**：负二项分布的标准推导为"最后一次成功 + 前段组合数"，组合数上标为 $k+r-1$（前段试验次数），下标为 $r-1$（前段成功次数）。利用组合对称性 $C_{k+r-1}^{r-1}=C_{k+r-1}^{k}$ 化为选项 D 的形式。

**推导过程**：

1. 第一步：翻译事件 $X=k$ ← 依据：$X$ 为未命中次数，命中 $r$ 次停止
   "总共射击 $k+r$ 次，其中未命中 $k$ 次、命中 $r$ 次，且**最后一次（第 $k+r$ 次）命中**"
2. 第二步：拆分最后一次与前段 ← 依据：射击停止的必要条件是最后一次命中
   - 最后一次（第 $k+r$ 次）：命中，概率 $p$
   - 前 $k+r-1$ 次：恰有 $r-1$ 次命中、$k$ 次未命中
3. 第三步：计算前段概率 ← 依据：二项分布概率公式 $C_n^m p^m(1-p)^{n-m}$
   $$P(\text{前 } k+r-1 \text{ 次恰 } r-1 \text{ 次命中}) = C_{k+r-1}^{r-1} p^{r-1}(1-p)^k$$
4. 第四步：合并最后一步 ← 依据：试验独立性，概率相乘
   $$P(X=k) = C_{k+r-1}^{r-1} p^{r-1}(1-p)^k \cdot p = C_{k+r-1}^{r-1} p^r (1-p)^k$$
5. 第五步：化简组合数 ← 依据：组合对称性 $C_n^m = C_n^{n-m}$
   $$C_{k+r-1}^{r-1} = C_{k+r-1}^{(k+r-1)-(r-1)} = C_{k+r-1}^{k}$$
   故 $P(X=k) = C_{k+r-1}^{k} p^r (1-p)^k$，即选项 D。

**选项分析**：

- **A（错误）**：$C_{k+r}^{r}$ 上标为 $k+r$，对应"总试验次数"而非"前段试验次数 $k+r-1$"，多算了一次。正确上标应为 $k+r-1$。
- **B（错误）**：$C_{k+r-1}^{r}$ 上标正确但下标为 $r$，应为 $r-1$（前段命中次数）。此为"前段命中次数多算 1"的错误。
- **C（错误）**：$C_{k+r}^{r-1}$ 上标 $k+r$ 错误（多算一次），下标 $r-1$ 正确。上标下标不匹配。
- **D（正确）**：$C_{k+r-1}^{k} p^r(1-p)^k$ 与推导结果完全一致，由组合对称性 $C_{k+r-1}^{r-1}=C_{k+r-1}^{k}$ 得到。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **组合数上标多算一次**：误取 $C_{k+r}^{r}$ 把最后一次也算进组合 → 正确做法：最后一次位置固定为命中，组合数只在前 $k+r-1$ 次中选 $r-1$ 个命中位置，上标为 $k+r-1$。
2. **下标 $r$ 与 $r-1$ 混淆**：误取 $C_{k+r-1}^{r}$ → 正确做法：前段需 $r-1$ 次命中（最后一次单独命中凑足 $r$ 次），下标为 $r-1$。
3. **概率幂次错误**：误写 $p^{r-1}$ 而非 $p^r$ → 正确做法：合并最后一步命中概率 $p$ 后，总幂次为 $p^r$。
:::

:::callout{kind=note label="知识卡片：负二项分布（帕斯卡分布）"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 定义 | 试验到第 $r$ 次成功为止所需总试验次数 $N$ 的分布 | 独立重复试验，成功概率 $p$ |
| 本题变量 | $X = N - r$（失败次数），$N = X + r$ | $r$ 为停止时成功次数 |
| 分布律 | $P(X = k) = C_{k+r-1}^{k}\, p^r (1-p)^k$ | $k = 0,1,2,\cdots$ |
| 等价形式 | $C_{k+r-1}^{r-1} = C_{k+r-1}^{k}$ | 组合对称性 |
| 特例 $r=1$ | 退化为几何分布 $P(X=k) = p(1-p)^k$ | 几何分布是负二项的特例 |
| 期望与方差 | $EX = \dfrac{r(1-p)}{p}$，$DX = \dfrac{r(1-p)}{p^2}$ | — |
| 与二项区别 | 二项：定 $n$ 求 $k$；负二项：定 $r$ 求 $n$ | 试验次数固定 vs 成功次数固定 |

**概念辨析**：
- 二项分布与负二项分布互为"对偶"：二项分布固定试验次数 $n$ 求成功次数 $k$ 的概率；负二项分布固定成功次数 $r$ 求所需试验次数（或失败次数）的概率。
- 组合对称性 $C_n^m = C_n^{n-m}$ 是化简负二项分布律的关键：$C_{k+r-1}^{r-1} = C_{k+r-1}^{k}$，两种写法等价。
:::

:::callout{kind=tip label="结论速记"}
负二项分布：**最后一次必成功**，前 $k+r-1$ 次选 $r-1$ 次成功：$P = C_{k+r-1}^{k}\, p^r (1-p)^k$。

**口诀**：最后必中，前段组合，上标 $k+r-1$，下标 $r-1$ 或 $k$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"射击到第 $r$ 次命中为止"→ 联想"负二项分布，最后一次必成功"
- **关联考点**：几何分布（$r=1$ 特例）、二项分布（对偶关系）、独立重复试验模型
- **复用场景**：任何"试验到第 $r$ 次成功为止"的概率计算题，包括质量控制、医学试验等场景
:::

### 第 7 题

:::callout{kind=note label="题目"}
从一批灯泡中随机抽取 $n$ 只做寿命试验，测得寿命为 $X_1, X_2, \cdots, X_n$，$\bar{X} = \dfrac{1}{n}\sum X_i$，$S^2 = \dfrac{1}{n-1}\sum (X_i - \bar{X})^2$。设灯泡寿命服从正态分布，则灯泡寿命均值的置信水平为 $0.95$ 的置信上限为（　　）

A. $\bar{X} - \dfrac{S}{\sqrt{n}} t_{0.025}(n-1)$　　B. $\bar{X} + \dfrac{S}{\sqrt{n}} t_{0.025}(n-1)$　　C. $\bar{X} - \dfrac{S}{\sqrt{n}} t_{0.05}(n-1)$　　D. $\bar{X} + \dfrac{S}{\sqrt{n}} t_{0.05}(n-1)$
:::

:::callout{kind=insight label="解析"}
**【答案】D**

**思路**：题干要求"置信水平 $0.95$ 的置信**上限**"，$\sigma$ 未知（题中只给 $S$）。入口是识别"单侧置信上限 + $\sigma$ 未知 + $t$ 分布"考点：单侧用 $t_\alpha$（而非双侧的 $t_{\alpha/2}$），方向取加号（上限）。

**为何用此公式**：$\sigma$ 未知时枢轴量为 $T = \dfrac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$，单侧置信上限满足 $P\{\mu \le \bar{\mu}\} = 1-\alpha$，由 $T$ 的分布反解出 $\bar{\mu} = \bar{X} + \dfrac{S}{\sqrt{n}} t_\alpha(n-1)$。

**推导过程**：

1. 第一步：识别题型 ← 依据：题干"置信上限"+"$\sigma$ 未知"
   单侧置信上限，$\alpha = 1 - 0.95 = 0.05$，枢轴量用 $t$ 分布（非 $z$）。
2. 第二步：写出枢轴量 ← 依据：正态总体 $\sigma$ 未知时 $\dfrac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$
   $$T = \frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$$
3. 第三步：构造单侧上限不等式 ← 依据：$P\{\mu \le \bar{\mu}\} = 1-\alpha = 0.95$
   等价于 $P\{T \ge -t_\alpha(n-1)\} = 1-\alpha$（因 $t$ 分布对称，$P\{T \ge -t_\alpha\} = 1-\alpha$）
4. 第四步：反解 $\mu$ ← 依据：不等式变形
   $$T \ge -t_\alpha \iff \frac{\bar{X}-\mu}{S/\sqrt{n}} \ge -t_\alpha \iff \mu \le \bar{X} + \frac{S}{\sqrt{n}} t_\alpha(n-1)$$
5. 第五步：代入 $\alpha$ ← 依据：$\alpha = 0.05$
   $$\bar{\mu} = \bar{X} + \frac{S}{\sqrt{n}} t_{0.05}(n-1)$$

**选项分析**：

- **A（错误）**：减号对应置信**下限**方向，且 $t_{0.025}$ 用于双侧区间，单侧应取 $t_{0.05}$。两项错误叠加。
- **B（错误）**：方向（加号）正确但分位点用 $t_{0.025}$，对应双侧区间的分位点；单侧上限应取 $t_{0.05}$。此为"双侧分位点误用于单侧"的错误。
- **C（错误）**：分位点 $t_{0.05}$ 正确但方向为减号，对应置信**下限** $\underline{\mu} = \bar{X} - \dfrac{S}{\sqrt{n}} t_{0.05}(n-1)$，非上限。
- **D（正确）**：方向（加号）与分位点（$t_{0.05}$）均正确，$\bar{\mu} = \bar{X} + \dfrac{S}{\sqrt{n}} t_{0.05}(n-1)$ 为 $0.95$ 单侧置信上限。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **单侧与双侧分位点混淆**：单侧用 $t_\alpha$，双侧用 $t_{\alpha/2}$ → 正确做法：单侧置信上下限用 $t_\alpha(n-1)$，双侧区间用 $t_{\alpha/2}(n-1)$。本题 $\alpha=0.05$，单侧取 $t_{0.05}$ 而非 $t_{0.025}$。
2. **上下限方向混淆**：上限取加号、下限取减号 → 正确做法：置信上限 $\bar{\mu} = \bar{X} + \dfrac{S}{\sqrt{n}} t_\alpha$；置信下限 $\underline{\mu} = \bar{X} - \dfrac{S}{\sqrt{n}} t_\alpha$。
3. **$\sigma$ 已知与未知混淆**：误用 $z$ 分位点 → 正确做法：$\sigma$ 未知用 $t$ 统计量与 $t_\alpha(n-1)$；$\sigma$ 已知才用 $z$ 统计量与 $z_\alpha$。题中只给 $S$ 故 $\sigma$ 未知。
:::

:::callout{kind=note label="知识卡片：正态总体均值的区间估计"}
| 条件 | 枢轴量 | 双侧 $1-\alpha$ 区间 | 单侧上限 | 单侧下限 | 适用条件 |
|------|--------|---------------------|----------|----------|---------|
| $\sigma$ 已知 | $\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)$ | $\bar{X} \pm \dfrac{\sigma}{\sqrt{n}} z_{\alpha/2}$ | $\bar{X} + \dfrac{\sigma}{\sqrt{n}} z_\alpha$ | $\bar{X} - \dfrac{\sigma}{\sqrt{n}} z_\alpha$ | 总体正态或 $n$ 大 |
| $\sigma$ 未知 | $\dfrac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)$ | $\bar{X} \pm \dfrac{S}{\sqrt{n}} t_{\alpha/2}(n-1)$ | $\bar{X} + \dfrac{S}{\sqrt{n}} t_\alpha(n-1)$ | $\bar{X} - \dfrac{S}{\sqrt{n}} t_\alpha(n-1)$ | 总体正态 |
| 要点 | 单侧用 $t_\alpha$；双侧用 $t_{\alpha/2}$ | — | — | — | — |

**概念辨析**：
- 单侧与双侧的区别在于"分位点"：单侧用 $t_\alpha$（上侧 $\alpha$ 分位点），双侧用 $t_{\alpha/2}$（上侧 $\alpha/2$ 分位点）。这是因为双侧区间两端各分 $\alpha/2$，单侧只在一端分 $\alpha$。
- $\sigma$ 已知与未知的区别在于"枢轴量"：已知用 $z$（标准正态），未知用 $t$（用 $S$ 替代 $\sigma$ 引入额外不确定性，自由度 $n-1$）。
:::

:::callout{kind=tip label="结论速记"}
单侧置信上限 = $\bar{X} + \dfrac{S}{\sqrt{n}} t_\alpha(n-1)$；单侧用 $t_\alpha$，双侧用 $t_{\alpha/2}$。

**口诀**：单侧 $t_\alpha$ 双侧半，上限加号下限减，$\sigma$ 未知才用 $t$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"置信上限/下限 + $\sigma$ 未知"→ 联想"单侧 $t_\alpha$，上加下减"
- **关联考点**：区间估计（第七章）、$t$ 分布分位点、枢轴量法
- **复用场景**：任何正态总体均值的单侧或双侧置信区间估计题，包括 $\sigma$ 已知与未知两种情形
:::

### 第 8 题

:::callout{kind=note label="题目"}
设随机变量 $X \sim N(0, 1)$，$Y \sim N(0, 1)$，则必有（　　）

A. $X+Y$ 服从正态分布　　B. $X^2 + Y^2$ 服从 $\chi^2$ 分布　　C. $X^2, Y^2$ 都服从 $\chi^2$ 分布　　D. $\dfrac{X^2}{Y^2}$ 服从 $F$ 分布
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：题干只给 $X, Y$ 的边缘分布为 $N(0,1)$，未给联合分布或独立性。入口是识别"边缘分布确定的必然结论"考点：哪些性质只需边缘分布即可保证，哪些需要独立性或联合正态性。

**为何用此公式**：$Z \sim N(0,1) \Rightarrow Z^2 \sim \chi^2(1)$ 是 $\chi^2$ 分布的定义，由单个标准正态变量的边缘分布直接决定，**不依赖 $X, Y$ 是否独立**。其他选项都需要独立性或联合正态性保证。

**推导过程**：

1. 第一步：识别题设信息 ← 依据：$X \sim N(0,1)$，$Y \sim N(0,1)$，仅给边缘分布
   未说明 $X, Y$ 是否独立，也未说明联合分布是否为二维正态。
2. 第二步：判断选项 C ← 依据：$\chi^2(1)$ 分布的定义
   $Z \sim N(0,1) \Rightarrow Z^2 \sim \chi^2(1)$，这是 $\chi^2$ 分布的定义（标准正态平方）。
   故 $X^2 \sim \chi^2(1)$，$Y^2 \sim \chi^2(1)$，**仅依赖各自的边缘分布**，与独立性无关，C 必然成立。
3. 第三步：判断选项 A ← 依据：边缘正态之和不一定正态
   $X+Y$ 服从正态分布要求 $(X,Y)$ 联合正态（或 $X,Y$ 独立）。仅给边缘分布无法保证联合正态。
   反例：$X \sim N(0,1)$，$Y = -X$（边缘正态但非联合正态），则 $X+Y=0$ 退化为常数，非正态。
4. 第四步：判断选项 B ← 依据：$\chi^2$ 可加性要求独立
   $X^2 + Y^2 \sim \chi^2(2)$ 要求 $X^2$ 与 $Y^2$ 独立（进而 $X, Y$ 独立）。仅给边缘分布无法保证。
   反例：$Y = -X$ 时 $X^2+Y^2 = 2X^2$，分布为 $2\chi^2(1)$ 而非 $\chi^2(2)$。
5. 第五步：判断选项 D ← 依据：$F$ 分布定义要求独立
   $\dfrac{X^2/1}{Y^2/1} \sim F(1,1)$ 要求 $X^2$ 与 $Y^2$ 独立。仅给边缘分布无法保证。

**选项分析**：

- **A（错误）**：$X+Y$ 服从正态分布要求 $(X,Y)$ 联合正态或 $X, Y$ 独立。仅给边缘分布不保证联合正态，反例 $Y=-X$ 使 $X+Y=0$ 退化。
- **B（错误）**：$X^2+Y^2 \sim \chi^2(2)$ 要求 $X^2, Y^2$ 独立（即 $X, Y$ 独立）。反例 $Y=-X$ 时 $X^2+Y^2=2X^2$，非 $\chi^2(2)$。
- **C（正确）**：$X \sim N(0,1) \Rightarrow X^2 \sim \chi^2(1)$ 是定义直接结论，$Y^2$ 同理。仅依赖边缘分布，与独立性无关，必然成立。
- **D（错误）**：$\dfrac{X^2}{Y^2} \sim F(1,1)$ 要求 $X^2$ 与 $Y^2$ 独立。仅给边缘分布无法保证独立性。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **边缘正态误推联合正态**：误以为"$X, Y$ 都正态 $\Rightarrow X+Y$ 正态" → 正确做法：边缘正态之和需联合正态或独立保证，仅边缘分布不够。反例 $Y=-X$。
2. **$\chi^2$ 可加性忽略独立性**：误以为"$X^2 \sim \chi^2(1)$，$Y^2 \sim \chi^2(1) \Rightarrow X^2+Y^2 \sim \chi^2(2)$" → 正确做法：$\chi^2$ 可加性要求两个 $\chi^2$ 变量独立，本题未给独立性。
3. **$F$ 分布定义遗漏独立性**：误以为"$X^2/Y^2 \sim F(1,1)$"自动成立 → 正确做法：$F$ 分布定义要求分子分母的两个 $\chi^2$ 变量独立。
:::

:::callout{kind=note label="知识卡片：正态分布的衍生分布"}
| 结论 | 条件 | 公式 | 适用条件 |
|------|------|------|---------|
| $Z^2 \sim \chi^2(1)$ | $Z \sim N(0,1)$ | 定义 | 单个标准正态，不需独立性 |
| $\sum Z_i^2 \sim \chi^2(n)$ | $Z_i$ iid $N(0,1)$ | 可加性 | 需要 iid |
| $X^2+Y^2 \sim \chi^2(2)$ | $X,Y$ 独立 $N(0,1)$ | 可加性 | 需要独立 |
| $\dfrac{U/m}{V/n} \sim F(m,n)$ | $U \sim \chi^2(m), V \sim \chi^2(n)$ 独立 | $F$ 定义 | 需要独立 |
| 边缘正态 $\not\Rightarrow$ 联合正态 | 仅给边缘分布 | — | 需联合分布已知为正态 |

**概念辨析**：
- "边缘正态 $\not\Rightarrow$ 联合正态"：边缘分布确定不能反推联合分布。反例 $Y=-X$ 中 $X, Y$ 边缘均为 $N(0,1)$ 但联合分布非正态（在直线 $y=-x$ 上退化）。
- "$\chi^2$ 可加性"与"$F$ 分布定义"都要求独立性：这是初学者最易忽略的前提条件。仅当两个 $\chi^2$ 变量独立时，可加性与 $F$ 分布才成立。
:::

:::callout{kind=tip label="结论速记"}
$N(0,1)$ 平方必服从 $\chi^2(1)$（边缘性质）；但 $\chi^2$ 之和、$F$ 分布都需要**独立性**。

**口诀**：单个平方必 $\chi^2$，求和求比要独立。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$X, Y$ 都正态 + 判断必有性质"→ 联想"边缘确定的结论 vs 需独立性的结论"
- **关联考点**：$\chi^2$ 分布与 $F$ 分布定义（第三章）、独立性与联合正态性、边缘分布与联合分布关系
- **复用场景**：任何判断"两个正态变量的函数服从何种分布"的题目，重点区分"仅需边缘"与"需独立性"
:::

### 第 9 题

:::callout{kind=note label="题目"}
设随机变量 $X \sim N(\mu, \sigma^2)$，则随着 $\sigma$ 的增大，概率 $P(X - \mu < 2\sigma)$（　　）

A. 单调增大　　B. 单调减小　　C. 增减不定　　D. 保持不变
:::

:::callout{kind=insight label="解析"}
**【答案】D**

**思路**：题干问 $\sigma$ 变化时 $P(X-\mu<2\sigma)$ 如何变化。入口是识别"标准化消参"考点：将 $X-\mu$ 除以 $\sigma$ 标准化后，阈值 $2\sigma$ 变为常数 2，概率与 $\sigma$ 无关。

**为何用此公式**：标准化 $Z = \dfrac{X-\mu}{\sigma} \sim N(0,1)$ 是处理"含 $\sigma$ 倍数阈值"的标准方法，标准化后阈值变为无量纲常数，概率由 $\Phi$ 函数直接给出，避免对 $\sigma$ 求导判断单调性。

**推导过程**：

1. 第一步：识别概率结构 ← 依据：$P(X-\mu < 2\sigma)$ 中阈值 $2\sigma$ 是 $\sigma$ 的倍数
   阈值随 $\sigma$ 同步变化，提示用标准化消去 $\sigma$。
2. 第二步：标准化 ← 依据：$X \sim N(\mu, \sigma^2) \Rightarrow Z = \dfrac{X-\mu}{\sigma} \sim N(0,1)$
   $$P(X - \mu < 2\sigma) = P\left(\frac{X-\mu}{\sigma} < 2\right) = P(Z < 2) = \Phi(2)$$
3. 第三步：判断 $\sigma$ 依赖性 ← 依据：$\Phi(2)$ 是常数，与 $\sigma$ 无关
   $$P(X - \mu < 2\sigma) = \Phi(2) \approx 0.9772$$
   该值为常数，不随 $\sigma$ 变化。
4. 第四步：直观验证 ← 依据：$\sigma$ 增大时分布更分散，但阈值 $2\sigma$ 同步放大
   $\sigma$ 增大使分布"展宽"，但 $2\sigma$ 这一阈值也按比例放大，标准化后阈值恒为 2，二者效应抵消，概率不变。

**选项分析**：

- **A（错误）**：误以为 $\sigma$ 增大使概率增大。对应"只看到分布展宽"的片面分析，忽略阈值同步放大。标准化后概率为 $\Phi(2)$ 常数，不单调增大。
- **B（错误）**：误以为 $\sigma$ 增大使概率减小。对应"分布展宽使尾部概率增大从而左侧概率减小"的错误推理，同样忽略阈值同步放大。
- **C（错误）**：误以为增减不定。对应"未完成标准化，无法判断"的未推导状态。标准化后明确为常数 $\Phi(2)$。
- **D（正确）**：标准化后 $P(X-\mu<2\sigma) = \Phi(2)$ 为常数，与 $\sigma$ 无关，保持不变。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **未标准化直接判断**：仅凭"$\sigma$ 增大分布更分散"断定概率变化 → 正确做法：必须标准化消去 $\sigma$，看概率是否依赖 $\sigma$。本题阈值 $2\sigma$ 是 $\sigma$ 的倍数，标准化后消去。
2. **混淆"固定阈值"与"比例阈值"**：$P(X < a)$（$a$ 固定）依赖 $\sigma$；$P(X-\mu < k\sigma)$（$k$ 固定）不依赖 $\sigma$ → 正确做法：判断阈值是否含 $\sigma$，含则标准化消去，不含则保留依赖。
3. **直观判断替代推导**：凭"分布展宽"直觉选 A 或 B → 正确做法：标准化后得 $\Phi(k)$ 为常数，直观判断须与推导一致。
:::

:::callout{kind=note label="知识卡片：正态分布的标准化与不变量"}
| 量 | 公式 | 是否依赖 $\sigma$ | 适用条件 |
|----|------|------------------|---------|
| $P(X < a)$ | $\Phi\!\left(\dfrac{a-\mu}{\sigma}\right)$ | 依赖（$a$ 固定时） | $a$ 为固定常数 |
| $P(X - \mu < k\sigma)$ | $\Phi(k)$ | **不依赖** | $k$ 为固定常数 |
| $P(\|X-\mu\| < k\sigma)$ | $2\Phi(k) - 1$ | **不依赖** | $k$ 为固定常数 |
| $P\!\left(\left\|\dfrac{X-\mu}{\sigma}\right\| < k\right)$ | $2\Phi(k)-1$ | **不依赖** | $k$ 为固定常数 |
| $P(X < \mu + k\sigma)$ | $\Phi(k)$ | **不依赖** | $k$ 为固定常数 |

**概念辨析**：
- "比例阈值"（$k\sigma$）与"固定阈值"（$a$）的本质区别：前者标准化后阈值变为常数 $k$，概率不依赖 $\sigma$；后者标准化后阈值 $\dfrac{a-\mu}{\sigma}$ 仍含 $\sigma$，概率依赖 $\sigma$。
- 这一结论对应"3$\sigma$ 原则"：$P(|X-\mu|<3\sigma) \approx 0.9974$ 对任意正态分布都成立，正是因为阈值是 $\sigma$ 的倍数。
:::

:::callout{kind=tip label="结论速记"}
概率以 $\sigma$ 的倍数为阈值时，标准化后 $\sigma$ 被消去，概率与 $\sigma$ 无关。

**口诀**：阈值含 $\sigma$ 标准化，消去 $\sigma$ 成常数。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$\sigma$ 变化 + 概率是否变化"→ 联想"标准化消参，看阈值是否含 $\sigma$"
- **关联考点**：正态分布标准化（第三章）、3$\sigma$ 原则、概率的不变性
- **复用场景**：任何判断"参数变化时概率如何变化"的题目，先标准化看是否消参
:::

### 第 10 题

:::callout{kind=note label="题目"}
下面表述正确的有（　　）个。

(1) 设 $A, B$ 为任意两个随机事件，则 $A + (B - A) = B$。

(2) 连续型随机变量 $X$ 的概率密度 $f(x)$ 是连续函数。

(3) 设 $F(x)$ 是任意一维随机变量 $X$ 的概率分布函数，则 $F(x)$ 的定义域是实数域。

(4) 设随机变量 $X, Y$ 均服从一维正态分布，则 $X + Y$ 也服从正态分布。

(5) 设 $(X, Y)$ 服从二维正态分布，且 $X$ 与 $Y$ 不相关，则它们独立。

(6) 设 $X, Y$ 的相关系数为 1，则存在常数 $a, b$，使 $Y = aX + b$。

A. $2$　　B. $3$　　C. $4$　　D. $5$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：六条命题涉及事件运算、密度函数性质、分布函数定义域、正态可加性、二维正态独立性、相关系数极值。入口是逐条用定义与反例判断真假，最后数正确个数。

**为何用此公式**：每条命题对应一个独立考点，需用各自的标准结论或反例判断，无统一公式。关键是区分"必然成立"与"需附加条件成立"。

**推导过程**：

1. **判断 (1)** ← 依据：事件运算定义 $A+B = A \cup B$，$B - A = B \cap \bar{A}$
   $$A + (B - A) = A \cup (B \cap \bar{A}) = (A \cup B) \cap (A \cup \bar{A}) = A \cup B$$
   （因 $A \cup \bar{A} = \Omega$）
   故 $A + (B-A) = A \cup B$，**不等于 $B$**（除非 $A \subseteq B$）。**(1) 错**。
2. **判断 (2)** ← 依据：密度函数允许有限个第一类间断点
   连续型随机变量的密度函数只需"分段连续且非负可积"，允许有限个第一类间断点。反例：均匀分布 $U(0,1)$ 的密度 $f(x) = \begin{cases}1, & 0<x<1 \\ 0, & \text{其它}\end{cases}$ 在 $x=0, 1$ 处不连续。**(2) 错**。
3. **判断 (3)** ← 依据：分布函数定义 $F(x) = P(X \le x)$ 对任意 $x \in \mathbb{R}$ 有定义
   分布函数定义在全体实数上，定义域为 $(-\infty, +\infty)$，这是定义要求。**(3) 正确**。
4. **判断 (4)** ← 依据：边缘正态之和需联合正态或独立
   $X+Y$ 服从正态分布要求 $(X,Y)$ 联合正态或 $X,Y$ 独立。仅给边缘分布不保证。
   反例：$X \sim N(0,1)$，$Y = -X$，则 $X+Y = 0$ 退化为常数，非正态。**(4) 错**。
5. **判断 (5)** ← 依据：二维正态的特有性质"不相关 $\Leftrightarrow$ 独立"
   $(X,Y)$ 服从二维正态时，$X$ 与 $Y$ 不相关（$\rho=0$）等价于独立。这是二维正态区别于一维正态的关键性质。**(5) 正确**。
6. **判断 (6)** ← 依据：相关系数 $\rho = \pm 1$ 的性质
   $\rho_{XY} = 1$ 表示 $X, Y$ 几乎处处满足**正**线性关系 $Y = aX + b$（$a > 0$）。
   （由 Cauchy-Schwarz 不等式等号成立条件：$Y - EY = a(X - EX)$，$a = \rho \cdot \dfrac{\sigma_Y}{\sigma_X} > 0$。）**(6) 正确**。

**正确个数**：(3)、(5)、(6) 共 **3 个**。

**选项分析**：

- **A（错误）**：对应"只数对 (5)、(6) 漏掉 (3)"，把 (3) 误判为错。分布函数定义域确为 $\mathbb{R}$，(3) 正确。
- **B（正确）**：(3)、(5)、(6) 三个正确，与逐条判断结果一致。
- **C（错误）**：对应"多算一个"，可能把 (1) 或 (4) 误判为正确。(1) 实为 $A \cup B$，(4) 需联合正态保证。
- **D（错误）**：对应"多算两个"，把多个错命题误判为正确。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **(1) 事件运算误化简**：误以为 $A + (B-A) = B$ → 正确做法：$B - A = B \cap \bar{A}$，$A + (B-A) = A \cup (B \cap \bar{A}) = A \cup B$，仅当 $A \subseteq B$ 时等于 $B$。
2. **(2) 密度连续性误解**：误以为连续型随机变量的密度必连续 → 正确做法：密度允许有限个第一类间断点，均匀分布即为反例。
3. **(4) 边缘正态可加性误用**：误以为两个一维正态之和必正态 → 正确做法：需联合正态或独立保证，反例 $Y=-X$ 使 $X+Y$ 退化。
4. **(6) 相关系数极值方向**：误以为 $\rho=1$ 对应 $a<0$ → 正确做法：$\rho=1$ 对应 $a>0$（正线性关系），$\rho=-1$ 才对应 $a<0$。
:::

:::callout{kind=note label="知识卡片：概率论六大易混命题辨析"}

## 二、填空题（每空 3 分，共 12 分）

### 第 11 题

:::callout{kind=note label="题目"}
设随机变量 $X_i$（$i = 1, 2$）的分布列为 $P(X_i = -1) = P(X_i = 1) = \dfrac{1}{4}$，$P(X_i = 0) = \dfrac{1}{2}$，满足 $P(X_1 X_2 = 0) = 1$，则 $P(X_1 = X_2) = $ ______。
:::

:::callout{kind=insight label="解析"}
**【答案】$0$**

**思路**：题干给出 $X_1, X_2$ 的边缘分布列与约束条件 $P(X_1 X_2 = 0) = 1$，求 $P(X_1 = X_2)$。入口是识别"约束条件下的联合分布分析"考点：由 $P(X_1 X_2 = 0) = 1$ 推出"二者不同时非零"，再用容斥原理求联合概率。

**为何用此公式**：容斥原理 $P(A \cup B) = P(A) + P(B) - P(AB)$ 是处理"互斥事件并集"的标准工具，结合约束条件 $P(X_1 \ne 0, X_2 \ne 0) = 0$ 可直接求出 $P(X_1 = 0, X_2 = 0)$。

**推导过程**：

1. 第一步：翻译约束条件 ← 依据：$P(X_1 X_2 = 0) = 1 \Rightarrow P(X_1 X_2 \ne 0) = 0$
   $$P(X_1 \ne 0,\ X_2 \ne 0) = 0$$
   即 $X_1, X_2$ 不能同时非零。
2. 第二步：计算边缘概率 ← 依据：题给分布列
   $$P(X_i \ne 0) = P(X_i = -1) + P(X_i = 1) = \frac{1}{4} + \frac{1}{4} = \frac{1}{2}$$
   $$P(X_i = 0) = \frac{1}{2}$$
3. 第三步：用容斥原理求 $P(X_1 \ne 0 \cup X_2 \ne 0)$ ← 依据：$P(A \cup B) = P(A) + P(B) - P(AB)$
   $$P(X_1 \ne 0 \cup X_2 \ne 0) = P(X_1 \ne 0) + P(X_2 \ne 0) - P(X_1 \ne 0, X_2 \ne 0)$$
   $$= \frac{1}{2} + \frac{1}{2} - 0 = 1$$
4. 第四步：求 $P(X_1 = 0, X_2 = 0)$ ← 依据：对立事件概率 $P(\bar{A}) = 1 - P(A)$
   $$P(X_1 = 0,\ X_2 = 0) = 1 - P(X_1 \ne 0 \cup X_2 \ne 0) = 1 - 1 = 0$$
5. 第五步：分解 $P(X_1 = X_2)$ ← 依据：$X_1 = X_2$ 的三种情形
   $$P(X_1 = X_2) = P(X_1 = X_2 = -1) + P(X_1 = X_2 = 0) + P(X_1 = X_2 = 1)$$
   - $P(X_1 = X_2 = \pm 1)$：需 $X_1, X_2$ 同时非零，由约束为 $0$
   - $P(X_1 = X_2 = 0)$：由第四步为 $0$
   $$P(X_1 = X_2) = 0 + 0 + 0 = 0$$

**关键步骤说明**：

- 约束 $P(X_1 X_2 = 0) = 1$ 是核心：它把"同时非零"概率归零，使"非零事件互斥"，进而推出"同时为零"概率也为零。
- 三种"相等"情形（同为 $-1$、同为 $0$、同为 $1$）均需同时非零或同时为零，由约束两者概率均为 $0$，故 $P(X_1 = X_2) = 0$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **约束条件翻译错误**：误把 $P(X_1 X_2 = 0) = 1$ 理解为"$X_1 = 0$ 或 $X_2 = 0$"而非"不同时非零" → 正确做法：$P(X_1 X_2 = 0) = 1 \Leftrightarrow P(X_1 X_2 \ne 0) = 0 \Leftrightarrow P(X_1 \ne 0, X_2 \ne 0) = 0$。
2. **忽略容斥原理直接相加**：误算 $P(X_1 \ne 0 \cup X_2 \ne 0) = P(X_1 \ne 0) + P(X_2 \ne 0) = 1$ 而不减交集 → 正确做法：本题交集概率恰为 $0$，结果相同，但需明确写出容斥公式并标注 $P(X_1 \ne 0, X_2 \ne 0) = 0$。
3. **遗漏"同为 $0$"情形**：只考虑"同为 $\pm 1$"而忽略"同为 $0$" → 正确做法：$P(X_1 = X_2)$ 需分解为三种情形（$-1, 0, 1$），缺一不可。
:::

:::callout{kind=note label="知识卡片：离散联合分布的约束分析"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 约束翻译 | $P(X_1 X_2 = 0) = 1 \Rightarrow P(X_1 \ne 0, X_2 \ne 0) = 0$ | 乘积为零概率为 1 |
| 容斥原理 | $P(A \cup B) = P(A) + P(B) - P(AB)$ | 任意两事件 |
| 对立事件 | $P(\bar{A}) = 1 - P(A)$ | 任意事件 |
| 情形分解 | $P(X_1 = X_2) = \sum_c P(X_1 = X_2 = c)$ | 离散变量取值有限 |

**概念辨析**：
- "$P(X_1 X_2 = 0) = 1$"与"$X_1 = 0$ 或 $X_2 = 0$"：前者是概率为 1（几乎必然），后者是逻辑必然。前者允许零概率集上同时非零，后者不允许。本题用概率语言处理。
- "边缘分布 + 约束"求联合概率：本题未给联合分布列，但约束条件足以确定关键联合概率，这是离散分布的常见题型。
:::

:::callout{kind=tip label="结论速记"}
$P(X_1 X_2 = 0) = 1$ 蕴含"两者非零事件互斥"，结合各自概率推出 $P(X_1 = X_2) = 0$。

**口诀**：乘积为零概率一，非零互斥容斥求，相等三情形全归零。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"约束条件 + 求联合概率"→ 联想"约束翻译为概率等式 + 容斥原理"
- **关联考点**：容斥原理（第一章）、离散联合分布（第三章）、约束条件下的概率计算
- **复用场景**：任何含约束条件的离散联合分布概率计算题，特别是"乘积为零""之和为定值"等约束
:::

### 第 12 题

:::callout{kind=note label="题目"}
设随机变量 $X, Y$ 都服从正态分布 $N(0, \sigma^2)$，且 $P(X \le 1,\ Y \le -1) = \dfrac{1}{5}$，则 $P(X > 1,\ Y > -1) = $ ______。
:::

:::callout{kind=insight label="解析"}
**【答案】$\dfrac{1}{5}$**

**思路**：题干给 $X, Y$ 服从零均值正态，已知 $P(X \le 1, Y \le -1) = 1/5$，求 $P(X > 1, Y > -1)$。入口是识别"对称正态 + 容斥公式"考点：利用 $N(0,\sigma^2)$ 的对称性使 $P(X \le 1) + P(Y \le -1) = 1$，再用容斥公式直接得答案。

**为何用此公式**：二维容斥公式 $P(X > a, Y > b) = 1 - P(X \le a) - P(Y \le b) + P(X \le a, Y \le b)$ 是处理"互补区域概率"的标准工具。结合零均值正态的对称性 $P(X \le c) + P(X \le -c) = 1$，可消去边缘概率项。

**推导过程**：

1. 第一步：计算边缘概率 ← 依据：$X \sim N(0, \sigma^2)$ 的对称性与标准化
   $$P(X \le 1) = \Phi\!\left(\frac{1}{\sigma}\right)$$
   $$P(Y \le -1) = \Phi\!\left(\frac{-1}{\sigma}\right) = 1 - \Phi\!\left(\frac{1}{\sigma}\right)$$
2. 第二步：求边缘概率之和 ← 依据：对称性 $\Phi(-x) = 1 - \Phi(x)$
   $$P(X \le 1) + P(Y \le -1) = \Phi\!\left(\frac{1}{\sigma}\right) + 1 - \Phi\!\left(\frac{1}{\sigma}\right) = 1$$
3. 第三步：应用容斥公式 ← 依据：$P(X > a, Y > b) = 1 - P(X \le a) - P(Y \le b) + P(X \le a, Y \le b)$
   $$P(X > 1,\ Y > -1) = 1 - P(X \le 1) - P(Y \le -1) + P(X \le 1,\ Y \le -1)$$
4. 第四步：代入已知 ← 依据：$P(X \le 1) + P(Y \le -1) = 1$，$P(X \le 1, Y \le -1) = 1/5$
   $$P(X > 1,\ Y > -1) = 1 - 1 + \frac{1}{5} = \frac{1}{5}$$

**关键步骤说明**：

- 关键在于利用 $X, Y$ 同为 $N(0, \sigma^2)$ 的对称性：$P(X \le 1) + P(Y \le -1) = \Phi(1/\sigma) + \Phi(-1/\sigma) = 1$，使容斥公式中边缘项相加为 1，与首项 1 抵消。
- 最终结果仅由 $P(X \le 1, Y \le -1) = 1/5$ 决定，即 $P(X > 1, Y > -1) = P(X \le 1, Y \le -1) = 1/5$，这是对称正态的"对角对称性"的体现。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **忽略对称性直接计算**：试图求出 $\sigma$ 再算概率 → 正确做法：无需知道 $\sigma$ 具体值，利用 $P(X \le 1) + P(Y \le -1) = 1$ 即可消去边缘项。
2. **容斥公式记错符号**：误写 $P(X > a, Y > b) = 1 - P(X \le a) - P(Y \le b) - P(X \le a, Y \le b)$ → 正确做法：容斥公式中交集项为**加**，$P(X > a, Y > b) = 1 - P(X \le a) - P(Y \le b) + P(X \le a, Y \le b)$。
3. **独立性误用**：误以为 $X, Y$ 独立从而 $P(X \le 1, Y \le -1) = P(X \le 1)P(Y \le -1)$ → 正确做法：题干未给独立性，且 $P(X \le 1)P(Y \le -1) = \Phi(1/\sigma)(1-\Phi(1/\sigma))$ 不一定等于 $1/5$，独立性不能假设。
:::

:::callout{kind=note label="知识卡片：二维概率的容斥计算"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 容斥（并集） | $P(A \cup B) = P(A) + P(B) - P(AB)$ | 任意两事件 |
| 互补（交集） | $P(X > a, Y > b) = 1 - P(X \le a) - P(Y \le b) + P(X \le a, Y \le b)$ | 任意两随机变量 |
| 对称正态 | $X \sim N(0,\sigma^2) \Rightarrow P(X \le c) + P(X \le -c) = 1$ | 零均值正态 |
| 对角对称 | $P(X > a, Y > b) = P(X \le -a, Y \le -b)$（同分布零均值） | $X, Y$ 同为 $N(0,\sigma^2)$ |

**概念辨析**：
- "容斥公式"中交集项符号：并集容斥为减（$-P(AB)$），交集互补为加（$+P(X \le a, Y \le b)$）。二者方向相反，须严格区分。
- "对称正态"的特殊性：$X \sim N(0,\sigma^2)$ 的密度关于 $x=0$ 对称，故 $P(X \le c) + P(X \le -c) = 1$。非零均值正态无此性质。
:::

:::callout{kind=tip label="结论速记"}
对称零均值正态：$P(X \le a) + P(X \le -a) = 1$，使容斥公式简化为 $P(X>a, Y>b) = P(X \le a, Y \le b)$。

**口诀**：零均值对称加为一，容斥互补直接等。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"零均值正态 + 求 $P(X>a, Y>b)$"→ 联想"对称性使边缘和为 1，容斥直接得答案"
- **关联考点**：容斥原理（第一章）、正态分布对称性与标准化（第三章）、二维概率计算
- **复用场景**：任何零均值正态变量的二维区域概率计算题，特别是互补区域概率互等情形
:::

### 第 13 题

:::callout{kind=note label="题目"}
在区间 $(0, 1)$ 上随机独立地取出 $n$ 个数 $X_1, X_2, \ldots, X_n$，记最大数与最小数之间距离为 $S$，用 $Y$ 表示 $X_1, X_2, \cdots, X_n$ 中大于 $\dfrac{1}{3}$ 的个数，则 $ES = $ ______，$DY = $ ______。
:::

:::callout{kind=insight label="解析"}
**【答案】$ES = \dfrac{n-1}{n+1}$，$DY = \dfrac{2n}{9}$**

**思路**：题干含两问：$ES$（极差期望）与 $DY$（计数方差）。入口分别识别两个考点：(1) 均匀分布样本极差期望，用最大最小值密度公式；(2) 计数变量服从二项分布，用二项方差公式。

**为何用此公式**：(1) $X_i \sim U(0,1)$ iid 时，最大值 $M$ 的密度 $f_M(x)=nx^{n-1}$、最小值 $m$ 的密度 $f_m(x)=n(1-x)^{n-1}$，由期望定义直接积分得 $EM, Em$，相减得 $ES$。(2) 每个 $X_i > 1/3$ 的概率 $p=2/3$，独立计数 $Y \sim B(n, 2/3)$，方差 $np(1-p)$。

**推导过程**：

**第一问：$ES$（极差期望）**

1. 第一步：定义极差变量 ← 依据：$S = M - m$，$M = \max(X_1,\ldots,X_n)$，$m = \min(X_1,\ldots,X_n)$
2. 第二步：求 $M$ 的密度 ← 依据：$F_M(x) = P(M \le x) = P(X_1 \le x, \ldots, X_n \le x) = [F_X(x)]^n = x^n$（$X_i \sim U(0,1)$）
   $$f_M(x) = \frac{d}{dx} x^n = n x^{n-1}, \quad 0 \le x \le 1$$
3. 第三步：求 $m$ 的密度 ← 依据：$F_m(x) = 1 - P(m > x) = 1 - [1 - F_X(x)]^n = 1 - (1-x)^n$
   $$f_m(x) = \frac{d}{dx}[1 - (1-x)^n] = n(1-x)^{n-1}, \quad 0 \le x \le 1$$
4. 第四步：计算 $EM$ ← 依据：期望定义 $EM = \int_0^1 x \cdot n x^{n-1}\, dx$
   $$EM = \int_0^1 n x^n\, dx = \frac{n}{n+1}$$
5. 第五步：计算 $Em$ ← 依据：期望定义 $Em = \int_0^1 x \cdot n(1-x)^{n-1}\, dx$，或用对称性 $Em = 1 - EM = 1 - \dfrac{n}{n+1} = \dfrac{1}{n+1}$
   （$U(0,1)$ 关于 $1/2$ 对称，$\min$ 与 $\max$ 关于 $1/2$ 对称：$Em + EM = 1$）
   $$Em = \frac{1}{n+1}$$
6. 第六步：求 $ES$ ← 依据：$ES = EM - Em$（期望的线性性）
   $$ES = \frac{n}{n+1} - \frac{1}{n+1} = \frac{n-1}{n+1}$$

**第二问：$DY$**

1. 第一步：识别 $Y$ 的分布 ← 依据：$Y$ 为 $n$ 个独立 $X_i$ 中大于 $1/3$ 的个数，每个 $X_i > 1/3$ 概率相同
   $$p = P(X_i > 1/3) = 1 - P(X_i \le 1/3) = 1 - \frac{1/3 - 0}{1 - 0} = \frac{2}{3}$$
   （$X_i \sim U(0,1)$，$P(X_i \le c) = c$）
2. 第二步：判定 $Y \sim B(n, p)$ ← 依据：$n$ 次独立伯努利试验，成功概率 $p = 2/3$
   $$Y \sim B\!\left(n,\ \frac{2}{3}\right)$$
3. 第三步：计算 $DY$ ← 依据：二项分布方差公式 $DY = np(1-p)$
   $$DY = n \cdot \frac{2}{3} \cdot \left(1 - \frac{2}{3}\right) = n \cdot \frac{2}{3} \cdot \frac{1}{3} = \frac{2n}{9}$$

**关键步骤说明**：

- 第一问的关键是求最大最小值的密度：利用 $F_M(x) = [F_X(x)]^n$ 与 $F_m(x) = 1 - [1-F_X(x)]^n$，对 $U(0,1)$ 得 $f_M(x) = nx^{n-1}$ 与 $f_m(x) = n(1-x)^{n-1}$。
- 第二问的关键是识别 $Y$ 服从二项分布：每个 $X_i > 1/3$ 是一次伯努利试验，独立重复 $n$ 次得 $B(n, 2/3)$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **极差期望误用公式**：误以为 $ES = EM - Em$ 需要 $M, m$ 独立才能用 → 正确做法：期望的线性性 $E(M-m) = EM - Em$ 对任意随机变量成立，不要求独立。
2. **最大值密度公式记错**：误写 $f_M(x) = n x^{n-1}$ 为 $f_M(x) = x^n$ → 正确做法：$F_M(x) = [F_X(x)]^n = x^n$，求导得 $f_M(x) = nx^{n-1}$，注意求导后多出因子 $n$ 与幂次降 1。
3. **计数变量分布误判**：误以为 $Y$ 服从超几何分布或其他分布 → 正确做法：$n$ 个独立样本中大于阈值的个数服从二项分布 $B(n, p)$，$p = P(X_i > 1/3)$。
4. **$p$ 计算错误**：误算 $p = P(X_i > 1/3) = 1/3$ → 正确做法：$U(0,1)$ 的 $P(X_i > c) = 1 - c$，$c = 1/3$ 时 $p = 2/3$。
:::

:::callout{kind=note label="知识卡片：均匀分布样本的极差与计数"}
| 量 | 分布/公式 | 结果 | 适用条件 |
|----|-----------|------|---------|
| $F_M(x) = [F_X(x)]^n$ | 最大值分布函数 | $x^n$ | $X_i$ iid $U(0,1)$ |
| $f_M(x)$ | 最大值密度 | $n x^{n-1}$ | $0 \le x \le 1$ |
| $F_m(x) = 1 - [1-F_X(x)]^n$ | 最小值分布函数 | $1-(1-x)^n$ | $X_i$ iid $U(0,1)$ |
| $f_m(x)$ | 最小值密度 | $n(1-x)^{n-1}$ | $0 \le x \le 1$ |
| $EM$ | 最大值期望 | $\dfrac{n}{n+1}$ | — |
| $Em$ | 最小值期望 | $\dfrac{1}{n+1}$ | — |
| $ES = EM - Em$ | 极差期望 | $\dfrac{n-1}{n+1}$ | 本题 |
| $Y \sim B(n, p)$ | 计数分布 | $p = 1 - c$ | $c = 1/3 \Rightarrow p = 2/3$ |
| $DY = np(1-p)$ | 二项方差 | $\dfrac{2n}{9}$ | — |

**概念辨析**：
- "$M, m$ 不独立但 $ES = EM - Em$ 仍成立"：期望的线性性不要求独立性，这是初学者易忽略的性质。但计算 $DS = D(M-m)$ 时需考虑协方差，不能直接 $DS = DM + Dm$。
- "$U(0,1)$ 的对称性"：$Em + EM = 1$，因 $U(0,1)$ 关于 $1/2$ 对称，$\min$ 与 $\max$ 关于 $1/2$ 对称。这是简化计算的捷径。
:::

:::callout{kind=tip label="结论速记"}
均匀样本极差期望 $ES = \dfrac{n-1}{n+1}$；计数 $Y \sim B(n, 1-c)$，$DY = np(1-p)$。

**口诀**：最大密度 $nx^{n-1}$，最小对称 $1-EM$，计数二项 $np(1-p)$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"均匀样本 + 极差/计数"→ 联想"最大最小值密度公式 + 二项分布"
- **关联考点**：顺序统计量（第三章）、二项分布（第二章）、均匀分布性质
- **复用场景**：任何均匀分布样本的极值与计数问题，包括可靠性、排队论等应用题
:::

## 三、计算题（共 58 分）

### 第 14 题（10 分）

:::callout{kind=note label="题目"}
密切接触者被感染的概率是 $10\%$，核酸检测中假阴性比例为 $20\%$，假阳性的比例为 $0.001\%$。现对一密切接触者进行核酸检测，求：

1. 此人的检测结果为阴性的概率；
2. 若此人的检测结果为阴性，此人未被感染的概率；
3. 若此人的检测结果为阳性，此人已被感染的概率。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：题干给出感染先验概率、假阴性率、假阳性率，要求三问：阴性总概率、阴性后验未感染概率、阳性后验感染概率。入口是识别"全概率公式 + 贝叶斯公式"考点：第 1 问用全概率公式，第 2、3 问用贝叶斯公式由结果反推原因。

**为何用此公式**：全概率公式 $P(A) = \sum P(B_i)P(A|B_i)$ 适用于"由因求果"（已知感染状态求检测概率）；贝叶斯公式 $P(B_i|A) = \dfrac{P(A|B_i)P(B_i)}{P(A)}$ 适用于"由果溯因"（已知检测结果反推感染状态）。两公式配合完成三问。

**推导过程**：

设 $B$ 表示"此人被感染"，$A$ 表示"检测结果为阴性"。翻译题给数据：

$$P(B) = 0.1, \quad P(\bar{B}) = 0.9$$

$$P(A \mid B) = 0.2 \text{（假阴性：感染者测为阴性）}, \quad P(\bar{A} \mid \bar{B}) = 0.00001 \text{（假阳性：未感染者测为阳性）}$$

$$P(A \mid \bar{B}) = 1 - P(\bar{A} \mid \bar{B}) = 1 - 0.00001 = 0.99999 \text{（真阴性）}$$

$$P(\bar{A} \mid B) = 1 - P(A \mid B) = 1 - 0.2 = 0.8 \text{（真阳性）}$$

**第 1 问：阴性总概率**

1. 第一步：识别事件分解 ← 依据：$A = (A \cap B) \cup (A \cap \bar{B})$（阴性分感染与未感染两类）
2. 第二步：应用全概率公式 ← 依据：$P(A) = P(B)P(A|B) + P(\bar{B})P(A|\bar{B})$
   $$P(A) = 0.1 \times 0.2 + 0.9 \times 0.99999 = 0.02 + 0.899991 = 0.919991$$

**第 2 问：阴性后未感染概率**

1. 第一步：识别贝叶斯公式 ← 依据：求 $P(\bar{B} | A)$，由结果 $A$ 反推原因 $\bar{B}$
2. 第二步：代入公式 ← 依据：$P(\bar{B} | A) = \dfrac{P(A|\bar{B})P(\bar{B})}{P(A)}$
   $$P(\bar{B} \mid A) = \frac{0.99999 \times 0.9}{0.919991} = \frac{0.899991}{0.919991} \approx 0.97826$$

**第 3 问：阳性后感染概率**

1. 第一步：求阳性总概率 ← 依据：$P(\bar{A}) = 1 - P(A)$
   $$P(\bar{A}) = 1 - 0.919991 = 0.080009$$
2. 第二步：应用贝叶斯公式 ← 依据：$P(B | \bar{A}) = \dfrac{P(\bar{A}|B)P(B)}{P(\bar{A})}$
   $$P(B \mid \bar{A}) = \frac{0.8 \times 0.1}{0.080009} = \frac{0.08}{0.080009} \approx 0.99989$$

**关键步骤说明**：

- 第 1 问用全概率公式"由因求果"：将"阴性"分解为"感染且阴性"与"未感染且阴性"两部分加权求和。
- 第 2、3 问用贝叶斯公式"由果溯因"：分子为"原因导致该结果"的联合概率，分母为该结果的总概率（第 1 问已求）。
- 第 3 问阳性预测值高达 $0.99989$，因假阳性率极低（$0.001\%$）；第 2 问阴性预测值 $0.97826$，因感染率不高（$10\%$）。

**答案**：$P(\text{阴性}) = 0.919991$；$P(\text{未感染} \mid \text{阴性}) \approx 0.97826$；$P(\text{感染} \mid \text{阳性}) \approx 0.99989$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **假阴性与假阳性定义混淆**：误把"假阴性"理解为 $P(\bar{A}|\bar{B})$ → 正确做法：假阴性是感染者测为阴性 $P(A|B) = 0.2$；假阳性是未感染者测为阳性 $P(\bar{A}|\bar{B}) = 0.00001$。
2. **贝叶斯公式分母漏项**：误用 $P(B|\bar{A}) = P(\bar{A}|B)P(B)$ 漏除 $P(\bar{A})$ → 正确做法：贝叶斯公式分母必须为结果的总概率 $P(\bar{A}) = P(B)P(\bar{A}|B) + P(\bar{B})P(\bar{A}|\bar{B})$，本题用 $P(\bar{A}) = 1 - P(A)$ 简化。
3. **百分数与小数转换错误**：误把 $0.001\%$ 当作 $0.001$ → 正确做法：$0.001\% = 0.00001$（百分数除以 100）。
:::

:::callout{kind=note label="知识卡片：贝叶斯公式与医学检测"}
| 概念 | 定义 | 本题值 | 适用条件 |
|------|------|--------|---------|
| 先验概率 | 检测前感染概率 $P(B)$ | $0.1$ | 由流行病学数据给出 |
| 假阴性率 | 感染者测为阴性 $P(A\mid B)$ | $0.2$ | 检测试剂特性 |
| 假阳性率 | 未感染者测为阳性 $P(\bar{A}\mid \bar{B})$ | $0.00001$ | 检测试剂特性 |
| 灵敏度（真阳性率） | $P(\bar{A}\mid B) = 1 - \text{假阴性率}$ | $0.8$ | — |
| 特异度（真阴性率） | $P(A\mid \bar{B}) = 1 - \text{假阳性率}$ | $0.99999$ | — |
| 全概率公式 | $P(A) = \sum P(B_i) P(A\mid B_i)$ | $0.919991$ | 由因求果 |
| 贝叶斯公式 | $P(B_i \mid A) = \dfrac{P(A\mid B_i) P(B_i)}{P(A)}$ | — | 由果溯因 |
| 阳性预测值 | $P(B \mid \bar{A})$ | $\approx 0.99989$ | 阳性后真感染概率 |
| 阴性预测值 | $P(\bar{B} \mid A)$ | $\approx 0.97826$ | 阴性后真未感染概率 |

**概念辨析**：
- "灵敏度"与"阳性预测值"的区别：灵敏度是感染者中测为阳性的比例（$P(\bar{A}|B)$，由试剂决定）；阳性预测值是阳性中真感染的比例（$P(B|\bar{A})$，依赖先验感染率）。后者才是临床关心指标。
- "假阴性率"与"假阳性率"的方向：假阴性是"感染但测阴性"（$P(A|B)$），假阳性是"未感染但测阳性"（$P(\bar{A}|\bar{B})$）。条件方向不同，不能互换。
:::

:::callout{kind=tip label="结论速记"}
全概率公式求"检测为阴性"总概率；贝叶斯公式由结果反推原因。低感染率下阳性预测值高，阴性预测值亦高。

**口诀**：全概率由因求果，贝叶斯由果溯因，分母总概率不可漏。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"先验概率 + 假阴/假阳性率 + 求后验概率"→ 联想"全概率公式 + 贝叶斯公式"
- **关联考点**：条件概率与全概率公式（第一章）、贝叶斯公式、医学检测应用
- **复用场景**：任何"已知原因概率与条件概率，求结果概率或反推原因"的题目，包括医学诊断、质量控制、信号检测等
:::

### 第 15 题（14 分）

:::callout{kind=note label="题目"}
已知 $(X, Y)$ 在以点 $(0, 1), (1, -1), (1, 1)$ 为顶点的三角形区域上服从均匀分布。求：

1. 边缘密度 $f_X(x)$，$f_Y(y)$；
2. 条件密度 $f_{X \mid Y}(x \mid y)$；
3. $P\!\left(X > \dfrac{1}{2} \mid Y > 0\right)$；
4. $X, Y$ 是否独立？是否相关？为什么？
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：题干给出三角形区域上的均匀分布，要求四问：边缘密度、条件密度、条件概率、独立性与相关性。入口是先确定区域与联合密度，再按"边缘→条件→概率→独立性"的顺序逐问推进。

**为何用此公式**：(1) 边缘密度用 $f_X(x) = \int f(x,y)\,dy$，积分限由区域边界确定；(2) 条件密度用 $f_{X|Y} = f/f_Y$；(3) 条件概率用 $P(A|B) = P(AB)/P(B)$；(4) 独立性看 $f \stackrel{?}{=} f_X f_Y$，相关性看 $\text{Cov} \stackrel{?}{=} 0$。

**推导过程**：

**区域与联合密度**

1. 第一步：确定三角形区域 ← 依据：顶点 $(0,1), (1,-1), (1,1)$
   - $x$ 范围：$0 \le x \le 1$
   - 给定 $x$，$y$ 范围：下边界为连接 $(0,1)$ 与 $(1,-1)$ 的直线 $y = 1 - 2x$，上边界为 $y = 1$
   $$D = \{(x, y) : 0 \le x \le 1,\ 1 - 2x \le y \le 1\}$$
2. 第二步：求面积与联合密度 ← 依据：三角形面积 $= \dfrac{1}{2} \times \text{底} \times \text{高} = \dfrac{1}{2} \times 1 \times 2 = 1$，均匀分布 $f = 1/|D|$
   $$|D| = 1, \quad f(x, y) = 1 \text{（在 } D \text{ 内）}$$

**第 1 问：边缘密度**

3. 第三步：求 $f_X(x)$ ← 依据：$f_X(x) = \int_{1-2x}^{1} f(x,y)\, dy$
   $$f_X(x) = \int_{1-2x}^{1} 1\, dy = 1 - (1-2x) = 2x, \quad 0 \le x \le 1$$
4. 第四步：求 $f_Y(y)$ ← 依据：$f_Y(y) = \int f(x,y)\, dx$，需由 $1-2x \le y$ 解 $x \ge \dfrac{1-y}{2}$
   - $y$ 范围：$-1 \le y \le 1$
   - 给定 $y$，$x$ 范围：$\dfrac{1-y}{2} \le x \le 1$
   $$f_Y(y) = \int_{\frac{1-y}{2}}^{1} 1\, dx = 1 - \frac{1-y}{2} = \frac{1+y}{2}, \quad -1 \le y \le 1$$

**第 2 问：条件密度**

5. 第五步：求 $f_{X|Y}(x|y)$ ← 依据：$f_{X|Y}(x|y) = \dfrac{f(x,y)}{f_Y(y)}$
   当 $-1 < y \le 1$ 时，$x \in \left[\dfrac{1-y}{2},\ 1\right]$：
   $$f_{X \mid Y}(x \mid y) = \frac{1}{(1+y)/2} = \frac{2}{1+y}, \quad \frac{1-y}{2} \le x \le 1$$

**第 3 问：条件概率**

6. 第六步：求 $P(Y > 0)$ ← 依据：$P(Y > 0) = \int_0^1 f_Y(y)\, dy$
   $$P(Y > 0) = \int_0^1 \frac{1+y}{2}\, dy = \left[\frac{y}{2} + \frac{y^2}{4}\right]_0^1 = \frac{1}{2} + \frac{1}{4} = \frac{3}{4}$$
7. 第七步：求 $P(X > 1/2, Y > 0)$ ← 依据：二重积分 $\iint_{x>1/2, y>0} f(x,y)\, dx\, dy$
   - 当 $x > 1/2$ 时，$1 - 2x < 0$，故 $y > 0$ 自动满足 $y \ge 1-2x$
   - 积分区域简化为 $1/2 \le x \le 1$，$0 \le y \le 1$
   $$P\!\left(X > \frac{1}{2},\ Y > 0\right) = \int_{1/2}^{1} \int_0^1 1\, dy\, dx = \int_{1/2}^{1} 1\, dx = \frac{1}{2}$$
8. 第八步：求条件概率 ← 依据：$P(A|B) = P(AB)/P(B)$
   $$P\!\left(X > \frac{1}{2} \mid Y > 0\right) = \frac{P(X > 1/2,\ Y > 0)}{P(Y > 0)} = \frac{1/2}{3/4} = \frac{2}{3}$$

**第 4 问：独立性与相关性**

9. 第九步：判断独立性 ← 依据：独立性 $\Leftrightarrow$ $f(x,y) = f_X(x) \cdot f_Y(y)$
   $$f_X(x) \cdot f_Y(y) = 2x \cdot \frac{1+y}{2} = x(1+y) \ne 1 = f(x, y)$$
   故 $X, Y$ **不独立**。
10. 第十步：计算 $EX, EY$ ← 依据：$EX = \int x f_X(x)\, dx$，$EY = \int y f_Y(y)\, dy$
    $$EX = \int_0^1 x \cdot 2x\, dx = \frac{2}{3}$$
    $$EY = \int_{-1}^1 y \cdot \frac{1+y}{2}\, dy = \frac{1}{2}\int_{-1}^1 (y + y^2)\, dy = \frac{1}{2}\left[0 + \frac{2}{3}\right] = \frac{1}{3}$$
    （$y$ 奇函数在对称区间积分为 $0$，$y^2$ 偶函数积分 $\dfrac{2}{3}$）
11. 第十一步：计算 $E(XY)$ ← 依据：$E(XY) = \iint_D xy \cdot f(x,y)\, dx\, dy$
    $$E(XY) = \int_0^1 \int_{1-2x}^1 xy\, dy\, dx = \int_0^1 x \cdot \frac{1 - (1-2x)^2}{2}\, dx = \int_0^1 (2x^2 - 2x^3)\, dx = \frac{2}{3} - \frac{1}{2} = \frac{1}{6}$$
12. 第十二步：计算协方差 ← 依据：$\text{Cov}(X,Y) = E(XY) - EX \cdot EY$
    $$\text{Cov}(X, Y) = \frac{1}{6} - \frac{2}{3} \cdot \frac{1}{3} = \frac{1}{6} - \frac{2}{9} = \frac{3 - 4}{18} = -\frac{1}{18} \ne 0$$
    故 $X, Y$ **相关**。

**关键步骤说明**：

- 区域确定是全题基础：由顶点写出 $D = \{(x,y): 0 \le x \le 1, 1-2x \le y \le 1\}$，面积 $|D|=1$ 使 $f=1$。
- 边缘密度积分限由区域边界确定：$f_X$ 对 $y$ 积分（限 $1-2x$ 到 $1$），$f_Y$ 对 $x$ 积分（限 $(1-y)/2$ 到 $1$）。
- 独立性与相关性分别判断：不独立（$f \ne f_X f_Y$）且相关（$\text{Cov} \ne 0$）。注意"相关 $\Rightarrow$ 不独立"但逆不真。

**答案**：

$$f_X(x) = 2x\ (0 \le x \le 1);\quad f_Y(y) = \frac{1+y}{2}\ (-1 \le y \le 1);\quad f_{X\mid Y}(x\mid y) = \frac{2}{1+y}\ \left(\frac{1-y}{2} \le x \le 1\right)$$

$$P\!\left(X > \frac{1}{2} \mid Y > 0\right) = \frac{2}{3};\quad X, Y \text{ 不独立且相关}$$
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **区域边界写错**：误把下边界写为 $y = 2x - 1$ 或 $y = x - 1$ → 正确做法：连接 $(0,1)$ 与 $(1,-1)$ 的直线斜率 $k = \dfrac{-1-1}{1-0} = -2$，截距 $b=1$，故 $y = 1-2x$。
2. **$f_Y$ 积分限搞反**：误把 $x$ 范围写为 $0 \le x \le (1-y)/2$ → 正确做法：由 $1-2x \le y$ 解 $x \ge (1-y)/2$，结合 $x \le 1$ 得 $(1-y)/2 \le x \le 1$。
3. **独立性判断用"看区域形状"**：误以为"三角形区域一定不独立" → 正确做法：必须严格验证 $f(x,y) \stackrel{?}{=} f_X(x) f_Y(y)$，虽本题确实不独立，但不能凭形状判断。
4. **协方差计算漏项**：误算 $E(XY)$ 时积分限用错 → 正确做法：$E(XY) = \int_0^1 \int_{1-2x}^1 xy\, dy\, dx$，内层对 $y$ 积分限为 $1-2x$ 到 $1$。
:::

:::callout{kind=note label="知识卡片：二维均匀分布的综合计算"}
| 步骤 | 方法 | 关键点 | 适用条件 |
|------|------|--------|---------|
| 联合密度 | $f(x,y) = 1/|D|$ | 先求区域面积 | 有界区域 |
| 边缘密度 | $f_X(x) = \int f(x,y)\, dy$ | 确定 $y$ 的积分上下限 | 由区域边界定 |
| 条件密度 | $f_{X\mid Y} = f / f_Y$ | 注意 $x$ 范围依赖 $y$ | $f_Y(y) > 0$ |
| 条件概率 | $P(A\mid B) = P(AB)/P(B)$ | 二重积分计算 | — |
| 独立性 | $f \ne f_X \cdot f_Y$ 则不独立 | 联合密度与边缘乘积比较 | 任意二维分布 |
| 相关性 | $\text{Cov} = E(XY) - EX \cdot EY$ | $\text{Cov} \ne 0$ 则相关 | 有二阶矩 |
| 重要结论 | 不独立 $\not\Rightarrow$ 相关；相关 $\Rightarrow$ 不独立 | — | — |

**概念辨析**：
- "不独立"与"不相关"的关系：相关（$\text{Cov} \ne 0$）必不独立，但不独立不一定相关（如 $f$ 关于 $x$ 或 $y$ 对称但非乘积的情形）。本题既不独立又相关。
- "边缘密度的积分限"：必须由区域边界确定，不能机械套用矩形区域的固定限。本题 $f_X$ 的 $y$ 限为 $1-2x$ 到 $1$，依赖 $x$。
:::

:::callout{kind=tip label="结论速记"}
二维均匀分布：联合密度为 $1/|D|$；判定独立性看 $f \stackrel{?}{=} f_X f_Y$；判定相关性看 $\text{Cov} \stackrel{?}{=} 0$。

**口诀**：均匀密度面积分，边缘积分看边界，独立看乘积相关看协差。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"三角形/区域上均匀分布 + 求边缘/条件/独立性"→ 联想"面积定密度，边界定积分限，乘积定独立，协差定相关"
- **关联考点**：二维连续型随机变量（第三章）、边缘与条件分布、独立性与相关性
- **复用场景**：任何二维均匀分布的综合计算题，包括矩形、三角形、圆形等区域

### 第 16 题（12 分）

:::callout{kind=note label="题目"}
已知随机变量 $X$ 与 $Y$ 相互独立，其分布函数分别为

$$F_X(x) = \begin{cases} 0, & x < 0, \\ \frac{1}{4}, & 0 \le x < 1, \\ 1, & x \ge 1, \end{cases} \qquad F_Y(y) = \begin{cases} 0, & y < 0, \\ y, & 0 \le y < 1, \\ 1, & y \ge 1. \end{cases}$$

记 $Z = Y - X$，其概率分布函数为 $F_Z(z)$，求：

1. $F_Z(z)$；
2. $DZ$；
3. $\text{Cov}(Z, X)$。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：$X$ 为离散型（分布函数有跳跃），$Y$ 为连续型（$U(0,1)$），$Z = Y - X$ 为混合型。入口是识别"离散+连续混合和的分布"考点：用全概率公式对离散变量 $X$ 求和；方差与协方差用独立性简化。

**为何用此公式**：(1) $F_Z(z) = P(Y - X \le z) = \sum_x P(Y \le z + x | X = x) P(X = x)$，全概率公式处理混合型；(2) $DZ = D(Y-X) = DY + DX$（独立时差方差相加）；(3) $\text{Cov}(Z, X) = \text{Cov}(Y-X, X) = \text{Cov}(Y,X) - DX = -DX$（独立时 $\text{Cov}(Y,X)=0$）。

**推导过程**：

**第一步：识别 $X, Y$ 的类型与数字特征**

1. 由 $F_X$ 的跳跃确定 $X$ 的分布律 ← 依据：$P(X = a) = F(a) - F(a^-)$
   - $P(X = 0) = F_X(0) - F_X(0^-) = \dfrac{1}{4} - 0 = \dfrac{1}{4}$
   - $P(X = 1) = F_X(1) - F_X(1^-) = 1 - \dfrac{1}{4} = \dfrac{3}{4}$
2. 由 $F_Y$ 的形式确定 $Y \sim U(0,1)$ ← 依据：$F_Y(y) = y$（$0 \le y < 1$）为均匀分布的分布函数
   $$EY = \frac{1}{2}, \quad DY = \frac{1}{12}$$
3. 计算 $X$ 的数字特征 ← 依据：$EX = \sum x P(X=x)$
   $$EX = 0 \cdot \frac{1}{4} + 1 \cdot \frac{3}{4} = \frac{3}{4}$$
   $$EX^2 = 0^2 \cdot \frac{1}{4} + 1^2 \cdot \frac{3}{4} = \frac{3}{4}$$
   $$DX = EX^2 - (EX)^2 = \frac{3}{4} - \frac{9}{16} = \frac{12 - 9}{16} = \frac{3}{16}$$

**第 1 问：$F_Z(z)$**

4. 第四步：写出全概率公式 ← 依据：$F_Z(z) = P(Z \le z) = P(Y - X \le z) = \sum_x P(Y \le z + x | X = x) P(X = x)$
   $$F_Z(z) = P(Y \le z) P(X = 0) + P(Y \le z + 1) P(X = 1) = \frac{1}{4} P(Y \le z) + \frac{3}{4} P(Y \le z + 1)$$
5. 第五步：写出 $Y \sim U(0,1)$ 的分布函数 ← 依据：$P(Y \le t) = \begin{cases} 0, & t < 0 \\ t, & 0 \le t < 1 \\ 1, & t \ge 1 \end{cases}$
6. 第六步：分段讨论 ← 依据：按 $z$ 与 $z+1$ 落入 $[0,1)$ 的情况分段
   - **$z < -1$**：$z < 0$ 且 $z + 1 < 0$，$P(Y \le z) = 0$，$P(Y \le z+1) = 0$
     $$F_Z = \frac{1}{4} \cdot 0 + \frac{3}{4} \cdot 0 = 0$$
   - **$-1 \le z < 0$**：$z < 0$ 故 $P(Y \le z) = 0$；$0 \le z+1 < 1$ 故 $P(Y \le z+1) = z + 1$
     $$F_Z = \frac{1}{4} \cdot 0 + \frac{3}{4}(z + 1) = \frac{3}{4}(z + 1)$$
   - **$0 \le z < 1$**：$0 \le z < 1$ 故 $P(Y \le z) = z$；$z + 1 \ge 1$ 故 $P(Y \le z+1) = 1$
     $$F_Z = \frac{1}{4} z + \frac{3}{4} \cdot 1 = \frac{1}{4} z + \frac{3}{4}$$
   - **$z \ge 1$**：$z \ge 1$ 且 $z + 1 \ge 1$，$P(Y \le z) = 1$，$P(Y \le z+1) = 1$
     $$F_Z = \frac{1}{4} + \frac{3}{4} = 1$$
7. 第七步：汇总分段表达式 ← 依据：分段函数定义
   $$F_Z(z) = \begin{cases} 0, & z < -1, \\ \frac{3}{4}(z + 1), & -1 \le z < 0, \\ \frac{3}{4} + \frac{1}{4} z, & 0 \le z < 1, \\ 1, & z \ge 1. \end{cases}$$

**第 2 问：$DZ$**

8. 第八步：应用方差可加性 ← 依据：$X, Y$ 独立时 $D(Y-X) = DY + DX$（差方差相加，符号不影响）
   $$DZ = D(Y - X) = DY + DX = \frac{1}{12} + \frac{3}{16} = \frac{4}{48} + \frac{9}{48} = \frac{13}{48}$$

**第 3 问：$\text{Cov}(Z, X)$**

9. 第九步：展开协方差 ← 依据：协方差双线性 $\text{Cov}(Y-X, X) = \text{Cov}(Y, X) - \text{Cov}(X, X)$
   $$\text{Cov}(Z, X) = \text{Cov}(Y - X, X) = \text{Cov}(Y, X) - \text{Cov}(X, X)$$
10. 第十步：代入独立性 ← 依据：$X, Y$ 独立 $\Rightarrow \text{Cov}(Y, X) = 0$；$\text{Cov}(X, X) = DX$
    $$\text{Cov}(Z, X) = 0 - DX = -\frac{3}{16}$$

**关键步骤说明**：

- 第 1 问用全概率公式处理混合型：对离散变量 $X$ 求和，连续变量 $Y$ 用分布函数分段表达。
- 第 2 问用方差可加性：独立变量差的方差等于方差之和（非差），$D(Y-X) = DY + DX$。
- 第 3 问用协方差双线性：$\text{Cov}(Y-X, X) = \text{Cov}(Y,X) - DX$，独立性使 $\text{Cov}(Y,X)=0$。

**答案**：$F_Z(z)$ 见上；$DZ = \dfrac{13}{48}$；$\text{Cov}(Z, X) = -\dfrac{3}{16}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **混合型求和用错方法**：试图对 $Y$ 求积分而非用全概率公式对 $X$ 求和 → 正确做法：离散+连续混合和的分布，用全概率公式对离散变量求和 $F_Z(z) = \sum_x P(Y \le z+x) P(X=x)$。
2. **差方差误算为差**：误用 $D(Y-X) = DY - DX$ → 正确做法：独立变量差的方差仍相加，$D(Y-X) = DY + DX$，因 $D(-X) = DX$。
3. **协方差符号出错**：误算 $\text{Cov}(Y-X, X) = \text{Cov}(Y,X) + DX$ → 正确做法：$\text{Cov}(Y-X, X) = \text{Cov}(Y,X) - \text{Cov}(X,X) = 0 - DX = -DX$，第二项为减。
4. **分段讨论遗漏或重复**：分段点 $z=-1, 0, 1$ 处理不当 → 正确做法：按 $z$ 与 $z+1$ 落入 $Y$ 的支集 $[0,1)$ 分四段：$z<-1$、$-1\le z<0$、$0\le z<1$、$z\ge 1$。
:::

:::callout{kind=note label="知识卡片：混合型随机变量和的分布"}
| 方法 | 内容 | 适用条件 |
|------|------|---------|
| 全概率公式 | $F_Z(z) = \sum_i P(Y \le z + x_i) P(X = x_i)$ | 离散+连续混合 |
| 分段讨论 | 按 $z + x_i$ 落入 $Y$ 的密度支集分段 | $Y$ 支集有限 |
| 方差性质 | $X, Y$ 独立时 $D(Y - X) = DY + DX$ | 独立 |
| 协方差性质 | $\text{Cov}(Y-X,\ X) = \text{Cov}(Y,X) - DX$ | 任意 |
| 独立推论 | 独立 $\Rightarrow \text{Cov}(Y,X) = 0$ | 独立 |
| 由分布函数定离散律 | $P(X = a) = F(a) - F(a^-)$ | 分布函数有跳跃 |

**概念辨析**：
- "差方差相加"与"和方差相加"相同：$D(X \pm Y) = DX + DY$（独立时），符号不影响方差。这与"差协方差相减"不同：$\text{Cov}(Y-X, X) = \text{Cov}(Y,X) - DX$。
- "由分布函数定离散律"：$F_X$ 在 $x=0$ 处跳跃 $\dfrac{1}{4}$、在 $x=1$ 处跳跃 $\dfrac{3}{4}$，跳跃高度即为该点的概率。这是离散型分布函数的特征。
:::

:::callout{kind=tip label="结论速记"}
离散+连续混合：用全概率公式对离散变量求和；方差与协方差利用独立性简化。

**口诀**：混合全概率对离散求和，差方差相加，协差双线展开。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"离散+连续混合 + 求 $Z=Y-X$ 分布"→ 联想"全概率公式对离散求和 + 分段讨论"
- **关联考点**：全概率公式（第一章）、方差与协方差性质（第四章）、混合型随机变量
- **复用场景**：任何离散与连续随机变量组合的分布计算题，包括和、差、积等运算
:::

### 第 17 题（10 分）

:::callout{kind=note label="题目"}
设随机变量 $(X, Y)$ 的联合密度函数为

$$f(x, y) = \begin{cases} e^{-(x+y)}, & x, y > 0, \\ 0, & \text{其它}, \end{cases}$$

求：

1. $Z = X + Y$ 的密度函数；
2. $W = (X + Y)/3$ 的密度函数。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：联合密度 $f(x,y) = e^{-(x+y)}$ 可分离为 $e^{-x} \cdot e^{-y}$，故 $X, Y$ 独立且均服从 $E(1)$。第 1 问求和的密度可用卷积公式或 Gamma 可加性；第 2 问是第 1 问结果的线性变换，用变量替换法。

**为何用此公式**：(1) 卷积公式 $f_Z(z) = \int f_X(x) f_Y(z-x)\, dx$ 适用于独立变量之和；Gamma 可加性 $X,Y \sim \Gamma(1,1)$ 独立 $\Rightarrow X+Y \sim \Gamma(2,1)$ 更简洁。(2) 变量替换 $W = Z/3$ 时 $f_W(w) = f_Z(3w) \cdot |dz/dw|$ 是单调变换的标准方法。

**推导过程**：

**第一步：识别 $X, Y$ 的分布**

1. 分离联合密度 ← 依据：$f(x,y) = e^{-x} \cdot e^{-y} = f_X(x) \cdot f_Y(y)$（$x, y > 0$）
   故 $X, Y$ 独立，且 $f_X(x) = e^{-x}$，$f_Y(y) = e^{-y}$（$x, y > 0$）。
2. 识别分布类型 ← 依据：指数分布 $E(\lambda)$ 的密度 $f(x) = \lambda e^{-\lambda x}$，本题 $\lambda = 1$
   $$X \sim E(1) = \Gamma(1, 1), \quad Y \sim E(1) = \Gamma(1, 1) \text{（独立）}$$

**第 1 问：$Z = X + Y$ 的密度**

3. 第三步（方法一：卷积公式）← 依据：$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x)\, dx$
   - 积分限：$f_X(x) > 0$ 要求 $x > 0$；$f_Y(z-x) > 0$ 要求 $z - x > 0$ 即 $x < z$
   - 故 $0 < x < z$（要求 $z > 0$）
   $$f_Z(z) = \int_0^z e^{-x} \cdot e^{-(z-x)}\, dx = \int_0^z e^{-z}\, dx = z e^{-z}, \quad z > 0$$
4. 第四步（方法二：Gamma 可加性）← 依据：$X \sim \Gamma(\alpha_1, \beta), Y \sim \Gamma(\alpha_2, \beta)$ 独立 $\Rightarrow X+Y \sim \Gamma(\alpha_1+\alpha_2, \beta)$
   - $X \sim \Gamma(1, 1)$，$Y \sim \Gamma(1, 1)$ 独立 $\Rightarrow Z \sim \Gamma(2, 1)$
   $$f_Z(z) = \frac{1}{\Gamma(2) \cdot 1^2} z^{2-1} e^{-z/1} = \frac{1}{1!} z e^{-z} = z e^{-z}, \quad z > 0$$
5. 第五步：写出完整密度 ← 依据：$z \le 0$ 时 $f_Z = 0$
   $$f_Z(z) = \begin{cases} z e^{-z}, & z > 0, \\ 0, & \text{其它}. \end{cases}$$

**第 2 问：$W = Z/3$ 的密度**

6. 第六步：识别变换类型 ← 依据：$W = Z/3$ 是单调递增变换，可用变量替换法
7. 第七步：求反函数与雅可比 ← 依据：$W = Z/3 \Rightarrow Z = 3W$，$\dfrac{dz}{dw} = 3$
8. 第八步：应用变量替换公式 ← 依据：$f_W(w) = f_Z(g^{-1}(w)) \cdot \left|\dfrac{dz}{dw}\right| = f_Z(3w) \cdot 3$
   - 当 $w > 0$ 时 $3w > 0$，$f_Z(3w) = 3w \cdot e^{-3w}$
   $$f_W(w) = 3w \cdot e^{-3w} \cdot 3 = 9 w e^{-3w}, \quad w > 0$$
9. 第九步：写出完整密度 ← 依据：$w \le 0$ 时 $f_W = 0$
   $$f_W(w) = \begin{cases} 9 w e^{-3w}, & w > 0, \\ 0, & \text{其它}. \end{cases}$$

**关键步骤说明**：

- 第 1 问两种方法等价：卷积公式从定义出发，Gamma 可加性利用已知结论。后者更简洁，但需记忆 Gamma 分布的可加性条件（同率参数 $\beta$）。
- 第 2 问用变量替换：$W = Z/3$ 单调递增，反函数 $Z = 3W$，雅可比 $|dz/dw| = 3$。注意密度要乘雅可比的绝对值。
- $W \sim \Gamma(2, 3)$：由 $Z \sim \Gamma(2,1)$ 经 $W = Z/3$ 得 $W \sim \Gamma(2, 3)$，密度 $9we^{-3w}$ 与 Gamma 分布定义一致。

**答案**：$f_Z(z) = z e^{-z}$（$z > 0$）；$f_W(w) = 9 w e^{-3w}$（$w > 0$）。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **卷积积分限错误**：误把积分限写为 $0$ 到 $+\infty$ → 正确做法：$f_Y(z-x) > 0$ 要求 $z-x > 0$ 即 $x < z$，结合 $x > 0$ 得 $0 < x < z$。
2. **变量替换漏乘雅可比**：误写 $f_W(w) = f_Z(3w)$ 漏乘 $|dz/dw| = 3$ → 正确做法：$f_W(w) = f_Z(3w) \cdot |dz/dw| = f_Z(3w) \cdot 3$，必须乘雅可比绝对值。
3. **Gamma 可加性条件遗漏**：误以为任意两个 Gamma 分布都可加 → 正确做法：Gamma 可加性要求**同率参数 $\beta$**，即 $X \sim \Gamma(\alpha_1, \beta)$ 与 $Y \sim \Gamma(\alpha_2, \beta)$ 独立时才可加。
4. **密度定义域遗漏**：只写 $f_Z(z) = ze^{-z}$ 不标注 $z > 0$ → 正确做法：完整密度需标明定义域，$z \le 0$ 时 $f_Z = 0$。
:::

:::callout{kind=note label="知识卡片：连续型随机变量和的分布"}
| 方法 | 公式 | 适用场景 | 适用条件 |
|------|------|----------|---------|
| 卷积公式 | $f_Z(z) = \int f_X(x) f_Y(z-x)\, dx$ | 独立变量之和 | $X, Y$ 独立 |
| 分布函数法 | $F_Z(z) = \iint_{x+y \le z} f(x,y)\, dx\, dy$ | 一般情形 | 任意联合密度 |
| 变量替换 | $f_W(w) = f_Z(g^{-1}(w)) \cdot \left\|\dfrac{dz}{dw}\right\|$ | 单调变换 | $g$ 单调可导 |
| Gamma 可加性 | $X \sim \Gamma(\alpha_1, \beta), Y \sim \Gamma(\alpha_2, \beta)$ 独立 $\Rightarrow X+Y \sim \Gamma(\alpha_1+\alpha_2, \beta)$ | 同率参数 Gamma 和 | 同 $\beta$ |
| 指数分布特例 | $E(\lambda) = \Gamma(1, \lambda)$，$n$ 个独立指数之和 $\sim \Gamma(n, \lambda)$ | — | 独立同 $\lambda$ |

**概念辨析**：
- "卷积公式"与"分布函数法"：卷积公式要求独立，分布函数法适用于任意联合密度（含不独立情形）。独立时二者等价，但卷积公式计算更简便。
- "Gamma 可加性"的"同 $\beta$"条件：若 $X \sim \Gamma(\alpha_1, \beta_1)$，$Y \sim \Gamma(\alpha_2, \beta_2)$ 且 $\beta_1 \ne \beta_2$，则 $X+Y$ 不服从 Gamma 分布。这是初学者易忽略的条件。
- "变量替换"的雅可比：$W = g(Z)$ 单调时 $f_W(w) = f_Z(g^{-1}(w)) \cdot |(g^{-1})'(w)|$，必须乘反函数导数的绝对值。
:::

:::callout{kind=tip label="结论速记"}
独立指数 $E(1)$ 之和 $\sim \Gamma(2, 1)$，密度 $z e^{-z}$；线性变换 $W = Z/c$ 密度乘 $c$：$f_W(w) = c \cdot f_Z(cw)$。

**口诀**：独立指数和为 Gamma，卷积积分限 $0$ 到 $z$，线性变换乘雅可比。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"独立指数/伽马变量之和 + 线性变换"→ 联想"Gamma 可加性 + 变量替换乘雅可比"
- **关联考点**：卷积公式与变量替换（第三章）、Gamma 分布与指数分布关系、随机变量函数的分布
- **复用场景**：任何独立连续变量之和或单调变换的密度计算题，包括正态、指数、均匀等分布
:::

### 第 18 题（12 分）

:::callout{kind=note label="题目"}
设总体 $X$ 的概率密度函数为

$$f(x; \theta) = \begin{cases} 2\theta, & 0 < x < 1, \\ 1 - 2\theta, & 1 \le x < 2, \\ 0, & \text{其它}, \end{cases}$$

其中 $\theta \in \left(0, \dfrac{1}{2}\right)$ 是未知参数，$X_1, X_2, \cdots, X_n$ 为来自总体 $X$ 的简单随机样本，记 $N$ 为样本中小于 1 的个数。求：

1. $\theta$ 的矩估计量 $\hat{\theta}_M$；
2. $\theta$ 的极大似然估计量 $\hat{\theta}_L$；
3. 验证 $\hat{\theta}_M$ 和 $\hat{\theta}_L$ 是否具有无偏性。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：总体密度分段定义，参数 $\theta$ 出现在两段高度中。第 1 问矩估计令 $\bar{X} = EX$；第 2 问 MLE 构造似然函数求导；第 3 问用 $E\bar{X} = EX$ 与 $EN = np$ 验证无偏性。入口是识别"分段密度 + 矩估计/MLE/无偏性"综合考点。

**为何用此公式**：(1) 矩估计用 $EX = \int x f(x;\theta)\, dx$ 计算期望后令 $\bar{X} = EX$；(2) MLE 用 $L(\theta) = \prod f(X_i;\theta)$，因密度分段需引入计数 $N$ 简化表达；(3) 无偏性用 $E\bar{X} = EX$（样本均值无偏）与 $EN = np$（二项分布期望）验证。

**推导过程**：

**第 1 问：矩估计**

1. 第一步：计算 $EX$ ← 依据：$EX = \int x f(x;\theta)\, dx$ 分段积分
   $$EX = \int_0^1 x \cdot 2\theta\, dx + \int_1^2 x \cdot (1 - 2\theta)\, dx$$
2. 第二步：分别计算两段积分 ← 依据：幂函数积分 $\int x\, dx = \dfrac{x^2}{2}$
   $$\int_0^1 2\theta x\, dx = 2\theta \cdot \frac{1}{2} = \theta$$
   $$\int_1^2 (1-2\theta) x\, dx = (1-2\theta) \cdot \frac{2^2 - 1^2}{2} = (1-2\theta) \cdot \frac{3}{2}$$
3. 第三步：合并 ← 依据：期望的线性性
   $$EX = \theta + \frac{3}{2}(1-2\theta) = \theta + \frac{3}{2} - 3\theta = \frac{3}{2} - 2\theta$$
4. 第四步：令 $\bar{X} = EX$ 解 $\theta$ ← 依据：矩估计原理（用样本矩替换总体矩）
   $$\bar{X} = \frac{3}{2} - 2\theta \quad \Rightarrow \quad 2\theta = \frac{3}{2} - \bar{X} \quad \Rightarrow \quad \hat{\theta}_M = \frac{1}{2}\left(\frac{3}{2} - \bar{X}\right) = \frac{3}{4} - \frac{1}{2}\bar{X}$$

**第 2 问：极大似然估计**

5. 第五步：构造似然函数 ← 依据：$L(\theta) = \prod_{i=1}^n f(X_i; \theta)$，密度分段需计数
   - 设 $N$ 为样本中 $X_i < 1$ 的个数（密度 $2\theta$），$n - N$ 为 $X_i \ge 1$ 的个数（密度 $1-2\theta$）
   $$L(\theta) = (2\theta)^N (1 - 2\theta)^{n - N}, \quad 0 < \theta < \frac{1}{2}$$
6. 第六步：取对数似然 ← 依据：$\ln L$ 对 $\theta$ 求导更简便
   $$\ln L = N \ln(2\theta) + (n - N) \ln(1 - 2\theta)$$
7. 第七步：求导令零 ← 依据：MLE 必要条件 $\dfrac{d}{d\theta} \ln L = 0$
   $$\frac{d}{d\theta} \ln L = \frac{N}{\theta} - \frac{2(n - N)}{1 - 2\theta} = 0$$
8. 第八步：解方程 ← 依据：交叉相乘
   $$N(1 - 2\theta) = 2\theta (n - N) \quad \Rightarrow \quad N - 2N\theta = 2n\theta - 2N\theta \quad \Rightarrow \quad N = 2n\theta$$
   $$\hat{\theta}_L = \frac{N}{2n}$$

**第 3 问：无偏性验证**

9. 第九步：验证 $\hat{\theta}_M$ 无偏 ← 依据：$E\bar{X} = EX$（样本均值是总体期望的无偏估计）
   $$E\hat{\theta}_M = E\left(\frac{3}{4} - \frac{1}{2}\bar{X}\right) = \frac{3}{4} - \frac{1}{2} E\bar{X} = \frac{3}{4} - \frac{1}{2} EX$$
   $$= \frac{3}{4} - \frac{1}{2}\left(\frac{3}{2} - 2\theta\right) = \frac{3}{4} - \frac{3}{4} + \theta = \theta$$
   故 $\hat{\theta}_M$ **无偏**。
10. 第十步：识别 $N$ 的分布 ← 依据：每个 $X_i < 1$ 的概率 $p = \int_0^1 2\theta\, dx = 2\theta$，独立计数
    $$N \sim B(n, 2\theta), \quad EN = n \cdot 2\theta = 2n\theta$$
11. 第十一步：验证 $\hat{\theta}_L$ 无偏 ← 依据：$EN = 2n\theta$
    $$E\hat{\theta}_L = E\left(\frac{N}{2n}\right) = \frac{1}{2n} EN = \frac{1}{2n} \cdot 2n\theta = \theta$$
    故 $\hat{\theta}_L$ **无偏**。

**关键步骤说明**：

- 矩估计的关键是计算 $EX$：分段密度需分段积分，本题 $EX = \dfrac{3}{2} - 2\theta$。
- MLE 的关键是构造似然函数：分段密度需引入计数 $N$（样本落入各段的个数），似然函数 $L = (2\theta)^N (1-2\theta)^{n-N}$ 类似二项分布形式。
- 无偏性的关键是识别 $N \sim B(n, 2\theta)$：每个 $X_i < 1$ 是伯努利试验，$p = 2\theta$，故 $EN = 2n\theta$。
- 本题矩估计与 MLE 不同（$\hat{\theta}_M = \dfrac{3}{4} - \dfrac{\bar{X}}{2}$ vs $\hat{\theta}_L = \dfrac{N}{2n}$），但二者均无偏。

**答案**：$\hat{\theta}_M = \dfrac{3}{4} - \dfrac{1}{2}\bar{X}$；$\hat{\theta}_L = \dfrac{N}{2n}$；二者均无偏。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$EX$ 分段积分遗漏**：只算一段而漏掉另一段 → 正确做法：$EX = \int_0^1 x \cdot 2\theta\, dx + \int_1^2 x \cdot (1-2\theta)\, dx$，两段都要算。
2. **似然函数构造错误**：直接相乘 $f(X_i;\theta)$ 而不引入计数 $N$ → 正确做法：分段密度的似然函数用计数 $N$ 简化为 $L = (2\theta)^N (1-2\theta)^{n-N}$，其中 $N$ 为 $X_i < 1$ 的个数。
3. **MLE 求导漏链式法则**：误算 $\dfrac{d}{d\theta} \ln(1-2\theta) = \dfrac{1}{1-2\theta}$ → 正确做法：链式法则 $\dfrac{d}{d\theta} \ln(1-2\theta) = \dfrac{-2}{1-2\theta}$，内层导数 $-2$ 不可漏。
4. **$N$ 分布识别错误**：误以为 $N$ 服从超几何分布 → 正确做法：$n$ 个独立样本中 $X_i < 1$ 的个数服从二项分布 $B(n, p)$，$p = P(X_i < 1) = 2\theta$。
5. **无偏性验证用错期望**：误用 $E\hat{\theta}_L = \dfrac{EN}{n}$ 漏除 $2$ → 正确做法：$\hat{\theta}_L = \dfrac{N}{2n}$，故 $E\hat{\theta}_L = \dfrac{EN}{2n} = \dfrac{2n\theta}{2n} = \theta$。
:::

:::callout{kind=note label="知识卡片：参数估计的矩法与极大似然法"}
| 方法 | 步骤 | 本题应用 | 适用条件 |
|------|------|----------|---------|
| 矩估计 | ① 算 $EX$；② 令 $\bar{X} = EX$；③ 解出 $\theta$ | $EX = \frac{3}{2} - 2\theta \Rightarrow \hat{\theta}_M = \frac{3}{4} - \frac{\bar{X}}{2}$ | 期望存在 |
| 极大似然 | ① 写 $L(\theta)$；② 取 $\ln L$；③ 求导令 0 | $L = (2\theta)^N (1-2\theta)^{n-N} \Rightarrow \hat{\theta}_L = \frac{N}{2n}$ | 似然函数可导 |
| 无偏性 | 验证 $E\hat{\theta} = \theta$ | 用 $E\bar{X} = EX$ 和 $EN = np$ | — |
| 二项分布 | $N \sim B(n, p)$，$p = P(X_i < 1)$ | $p = 2\theta$，$EN = 2n\theta$ | 独立伯努利 |
| 分段密度似然 | $L = \prod f(X_i;\theta)$，用计数简化 | $L = (2\theta)^N (1-2\theta)^{n-N}$ | 密度分段 |

**概念辨析**：
- "矩估计"与"MLE"不一定相同：矩估计用样本矩替换总体矩，MLE 用似然函数极大化。本题 $\hat{\theta}_M = \dfrac{3}{4} - \dfrac{\bar{X}}{2}$（连续型统计量）与 $\hat{\theta}_L = \dfrac{N}{2n}$（离散型统计量）形式不同，但二者均无偏。
- "无偏性"是对估计量的期望要求：$E\hat{\theta} = \theta$ 表示估计量在平均意义上等于真值。无偏性不保证每次估计都准确，但避免系统性偏差。
- "分段密度的似然函数"：当密度分段定义时，似然函数需按样本落入各段的情况分类，引入计数 $N$ 可简化为幂乘积形式，类似二项分布的似然函数。
:::

:::callout{kind=tip label="结论速记"}
矩估计令 $\bar{X} = EX$；MLE 对 $\ln L$ 求导；无偏性用 $E\bar{X} = EX$ 和 $EN = np$ 验证。

**口诀**：矩估算期望令等号，似然取对数求导，无偏用样本均值与二项期望。
:::

**长期记忆锚点**：

- **触发词**：看到"分段密度 + 矩估计/MLE/无偏性"→ 联想"分段积分算期望 + 计数构造似然 + 二项期望验无偏"
- **关联考点**：参数估计（第七章）、矩估计与极大似然估计、无偏性、二项分布应用
- **复用场景**：任何分段密度总体的参数估计题，包括均匀分段、指数混合等情形；以及任何需验证估计量无偏性的题目
:::
