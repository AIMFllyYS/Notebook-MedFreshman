## 一、单项选择题（每题 3 分，共 30 分）

### 第1题

:::callout{kind=note label="题目"}
设有 $A, B, C$ 三个事件，$A, C$ 相互独立，$B, C$ 相互独立，则 $A \cup B$ 与 $C$ 相互独立的充分必要条件是（　　）

A. $A, B$ 相互独立　　B. $AB = \varnothing$　　C. $AB$ 与 $C$ 相互独立　　D. $AB$ 与 $C$ 互不相容
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：题干已知 $A,C$ 与 $B,C$ 两两独立，要求 $A \cup B$ 与 $C$ 独立的充要条件。入口是识别"并与事件独立性"考点，将 $P((A\cup B)C)$ 与 $P(A\cup B)P(C)$ 分别展开后比较，化简即得充要条件。

**为何用此公式**：事件并的概率 $P(A\cup B)=P(A)+P(B)-P(AB)$ 与分配律 $(A\cup B)C=AC\cup BC$ 是处理"并与事件"的标准工具，能把 $A\cup B$ 与 $C$ 的独立性化归为 $AB$ 与 $C$ 的关系。

**推导过程**：

1. 第一步：写出独立性等式 ← 依据：独立性定义 $P((A\cup B)C)=P(A\cup B)P(C)$
2. 第二步：左侧用分配律展开 ← 依据：$(A\cup B)C=AC\cup BC$，再容斥
   $$P((A\cup B)C)=P(AC\cup BC)=P(AC)+P(BC)-P(ABC)$$
3. 第三步：右侧用并事件概率展开 ← 依据：$P(A\cup B)=P(A)+P(B)-P(AB)$
   $$P(A\cup B)P(C)=\big(P(A)+P(B)-P(AB)\big)P(C)=P(A)P(C)+P(B)P(C)-P(AB)P(C)$$
4. 第四步：代入两两独立性 ← 依据：$P(AC)=P(A)P(C)$，$P(BC)=P(B)P(C)$
   $$\text{左}=P(A)P(C)+P(B)P(C)-P(ABC),\quad \text{右}=P(A)P(C)+P(B)P(C)-P(AB)P(C)$$
5. 第五步：左右相等的充要条件 ← 依据：两端相同项相消
   $$P(ABC)=P(AB)P(C)$$
   即 $AB$ 与 $C$ 相互独立。

**选项分析**：

- **A（错误）**：$A,B$ 独立只保证 $P(AB)=P(A)P(B)$，与 $P(ABC)=P(AB)P(C)$ 无关，是充分性不成立的强条件。
- **B（错误）**：$AB=\varnothing$ 时 $P(AB)=0$ 使等式成立，但这只是充分条件而非必要条件（$AB\neq\varnothing$ 时也可能独立）。
- **C（正确）**：$AB$ 与 $C$ 独立即 $P(ABC)=P(AB)P(C)$，与推导结果完全一致。
- **D（错误）**：互不相容仅保证 $P(ABC)=0$，是独立的特殊情形而非等价刻画，要求过强。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **混淆"两两独立"与"相互独立"**：把 $A,C$ 与 $B,C$ 两两独立误认为可推出 $A,B,C$ 三者相互独立 → 正确做法：两两独立不蕴含相互独立，$P(ABC)=P(A)P(B)P(C)$ 需单独验证，本题正是求此条件。
2. **分配律展开遗漏交集项**：误写 $P((A\cup B)C)=P(AC)+P(BC)$ 漏掉 $-P(ABC)$ → 正确做法：$(A\cup B)C=AC\cup BC$ 仍是并集，必须用容斥 $P(AC\cup BC)=P(AC)+P(BC)-P(ABC)$。
3. **充分条件与充要条件混淆**：把 $AB=\varnothing$（充分条件）当作充要条件 → 正确做法：充要条件须双向成立，$AB\neq\varnothing$ 时 $AB$ 与 $C$ 仍可能独立，故 $AB=\varnothing$ 非必要。
:::

:::callout{kind=note label="知识卡片：事件独立性的判定"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 两两独立 | $P(AB)=P(A)P(B)$ 等 | 仅两两乘积分解 |
| 相互独立 | 任意子族乘积分解 | $P(ABC)=P(A)P(B)P(C)$ 等 |
| 并与事件独立 | $P((A\cup B)C)=P(A\cup B)P(C)$ | 已知 $A,C$、$B,C$ 两两独立时化归为 $AB$ 与 $C$ 独立 |
| 分配律 | $(A\cup B)C=AC\cup BC$ | 任意事件，容斥展开的核心 |
| 容斥公式 | $P(A\cup B)=P(A)+P(B)-P(AB)$ | 任意两事件 |

**概念辨析**：
- "两两独立"仅要求每对事件乘积分解，"相互独立"要求任意子族乘积分解，二者在三个及以上事件时不等价。
- 本题结论 $A\cup B$ 与 $C$ 独立 $\Leftrightarrow$ $AB$ 与 $C$ 独立，依赖前提 $A,C$ 与 $B,C$ 两两独立；若去掉该前提，结论不成立。
:::

:::callout{kind=tip label="结论速记"}
已知 $A,C$ 与 $B,C$ 两两独立时，$A\cup B$ 与 $C$ 独立 $\Leftrightarrow$ $AB$ 与 $C$ 独立。

**口诀**：并与独立看交集，分配容斥化 $AB$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$A\cup B$ 与 $C$ 独立的充要条件"→ 联想"分配律 $(A\cup B)C=AC\cup BC$ 容斥展开后化归为 $AB$ 与 $C$ 独立"
- **关联考点**：事件独立性（第一章）、容斥原理、两两独立与相互独立的区别
- **复用场景**：任何"并与事件或和事件与第三事件独立性"的判断题，均可先用分配律展开再代入两两独立性化简
:::

### 第2题

:::callout{kind=note label="题目"}
设随机变量 $X$ 的分布函数 $F(x) = a + be^{-x}\ (x>0)$，$F(x)=0\ (x \leq 0)$，则 $P(X>6 \mid X \geq 4) =$（　　）

A. $\dfrac{1}{2}$　　B. $e^{-2}$　　C. $1-e^{-2}$　　D. $\dfrac{1}{2e}$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：题干给出含参分布函数 $F(x)=a+be^{-x}$，要求条件概率。入口是先用分布函数的边界条件定参，再识别出指数分布后套用无记忆性，或直接用条件概率定义计算。

**为何用此公式**：分布函数满足 $\lim_{x\to+\infty}F(x)=1$ 与右连续性 $\lim_{x\to 0^+}F(x)=F(0)=0$，这两个边界条件可唯一确定 $a,b$；定参后若得 $F(x)=1-e^{-\lambda x}$ 即为指数分布，无记忆性 $P(X>s+t\mid X>s)=P(X>t)$ 直接给出条件概率。

**推导过程**：

1. 第一步：用边界条件定参 ← 依据：分布函数极限性质
   $$\lim_{x\to+\infty}(a+be^{-x})=a=1,\qquad \lim_{x\to 0^+}(a+be^{-x})=a+b=0$$
2. 第二步：解方程组 ← 依据：$a=1$ 代入 $a+b=0$
   $$a=1,\ b=-1\Rightarrow F(x)=1-e^{-x}\ (x>0)$$
3. 第三步：识别分布类型 ← 依据：指数分布分布函数 $F(x)=1-e^{-\lambda x}$，对照得 $\lambda=1$
   $$X\sim E(1)$$
4. 第四步：用无记忆性求条件概率 ← 依据：$P(X>s+t\mid X>s)=P(X>t)$，此处 $s=4,\ t=2$
   $$P(X>6\mid X\geq 4)=P(X>6-4)=P(X>2)=e^{-2}$$
5. 第五步：用定义验证 ← 依据：$P(X>x)=1-F(x)=e^{-x}$
   $$P(X>6\mid X\geq 4)=\frac{P(X>6)}{P(X\geq 4)}=\frac{e^{-6}}{e^{-4}}=e^{-2}$$

**选项分析**：

- **A（错误）**：$\frac{1}{2}$ 对应把条件区间按线性长度比例 $\frac{6-4}{6}$ 计算，未用分布函数，正确应为 $e^{-2}$。
- **B（正确）**：由无记忆性或定义计算均得 $e^{-2}$，与推导一致。
- **C（错误）**：$1-e^{-2}$ 是 $P(X\leq 2)$ 即 $F(2)$，方向与所求 $P(X>2)$ 相反。
- **D（错误）**：$\frac{1}{2e}$ 对应混淆指数参数 $\lambda$ 与时间长度，正确应为 $e^{-\lambda t}=e^{-2}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **边界条件用错**：误用 $F(0)=0$ 而忽略 $F$ 在 $x=0$ 处右连续应取 $x\to 0^+$ 的极限 → 正确做法：$F(0)=0$ 且 $F$ 右连续，故 $\lim_{x\to 0^+}F(x)=F(0)=0$，即 $a+b=0$。
2. **无记忆性方向记反**：误写 $P(X>s+t\mid X>s)=P(X>s+t)$ → 正确做法：无记忆性为 $P(X>s+t\mid X>s)=P(X>t)$，条件去掉已等待时间 $s$，只保留增量 $t$。
3. **条件区间错算**：把 $P(X>6\mid X\geq 4)$ 中的增量算成 $6-4=2$ 时漏写 $P(X>2)$，误取 $P(X>6)$ → 正确做法：增量 $t=6-4=2$，所求为 $P(X>2)=e^{-2}$。
:::

:::callout{kind=note label="知识卡片：指数分布与无记忆性"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 分布函数 | $F(x)=1-e^{-\lambda x}$ | $x>0$，参数 $\lambda>0$ |
| 密度函数 | $f(x)=\lambda e^{-\lambda x}$ | $x>0$ |
| 无记忆性 | $P(X>s+t\mid X>s)=P(X>t)$ | 仅指数分布成立（连续型中唯一） |
| 期望/方差 | $E(X)=\dfrac{1}{\lambda},\ D(X)=\dfrac{1}{\lambda^2}$ | 任意 $\lambda>0$ |
| 尾概率 | $P(X>x)=1-F(x)=e^{-\lambda x}$ | $x>0$ |
| 边界定参 | $\lim_{x\to+\infty}F(x)=1$，$\lim_{x\to 0^+}F(x)=0$ | 任意分布函数 |

**概念辨析**：
- 无记忆性是指数分布的特征性质：连续型随机变量中，只有指数分布满足无记忆性，反之满足无记忆性的连续分布必为指数分布。
- $P(X\geq 4)$ 与 $P(X>4)$ 在连续分布下相等（单点概率为零），故条件用 $\geq$ 或 $>$ 不影响结果。
:::

:::callout{kind=tip label="结论速记"}
指数分布无记忆性：$P(X>6\mid X\geq 4)=P(X>2)=e^{-2}$。

**口诀**：边界定参识指数，无记忆性减去已等时。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"含参分布函数 $a+be^{-x}$ 求条件概率"→ 联想"边界定参得指数分布，套无记忆性"
- **关联考点**：分布函数性质（第二章）、指数分布特征性质、条件概率计算
- **复用场景**：任何给出含参分布函数的题目，先用 $\lim_{x\to+\infty}F=1$ 与 $\lim_{x\to\text{左端点}^+}F=0$ 定参；指数分布的条件概率直接用无记忆性
:::

### 第3题

:::callout{kind=note label="题目"}
已知 $F_X(x) = \Phi\!\left(\dfrac{x}{4}-2\right)$，其中 $\Phi$ 为标准正态分布函数，则 $X$ 服从（　　）

A. $N(2, 16)$　　B. $N(8, 4)$　　C. $N(2, 4)$　　D. $N(8, 16)$
:::

:::callout{kind=insight label="解析"}
**【答案】D**

**思路**：题干给出分布函数形如 $F_X(x)=\Phi\!\left(\dfrac{x}{4}-2\right)$，要求识别 $X$ 的分布。入口是对照正态分布标准变换公式 $F_X(x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)$，将题给形式通分改写后比较常数项即得 $\mu,\sigma$。

**为何用此公式**：正态分布的分布函数与标准正态分布函数的关系 $F_X(x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)$ 是一一对应的，给定 $F_X$ 即可反解 $\mu,\sigma$，无需积分。

**推导过程**：

1. 第一步：写出标准形式 ← 依据：$X\sim N(\mu,\sigma^2)\Rightarrow F_X(x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)$
2. 第二步：将题给式通分改写 ← 依据：$\dfrac{x}{4}-2=\dfrac{x-8}{4}$（提取 $\dfrac{1}{4}$ 后常数项为 $-8$）
   $$\Phi\!\left(\frac{x}{4}-2\right)=\Phi\!\left(\frac{x-8}{4}\right)$$
3. 第三步：对照标准形式 ← 依据：$\dfrac{x-\mu}{\sigma}=\dfrac{x-8}{4}$
   $$\mu=8,\quad \sigma=4$$
4. 第四步：写出分布 ← 依据：$\sigma^2=4^2=16$
   $$X\sim N(8,16)$$

**选项分析**：

- **A（错误）**：$N(2,16)$ 把减号常数 $-2$ 当作均值 $\mu=2$，混淆了截距与均值，正确应为 $\mu=-\text{截距}\times\sigma=8$。
- **B（错误）**：$N(8,4)$ 颠倒 $\mu$ 与 $\sigma$，把 $8$ 当作 $\sigma$、$4$ 当作 $\mu$，未完成通分对比。
- **C（错误）**：$N(2,4)$ 同时错认 $\mu$ 与 $\sigma$，既未通分又混淆位置与尺度参数。
- **D（正确）**：$\mu=8,\ \sigma^2=16$，与通分对比结果一致。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **截距当作均值**：把 $\dfrac{x}{4}-2$ 中的常数 $-2$ 直接当作 $\mu$ → 正确做法：标准形式为 $\dfrac{x-\mu}{\sigma}=\dfrac{x}{\sigma}-\dfrac{\mu}{\sigma}$，截距 $-\dfrac{\mu}{\sigma}=-2$ 与斜率 $\dfrac{1}{\sigma}=\dfrac{1}{4}$ 联立解得 $\sigma=4,\ \mu=8$。
2. **混淆 $\sigma$ 与 $\sigma^2$**：把 $\sigma=4$ 当作方差 → 正确做法：正态记号 $N(\mu,\sigma^2)$ 第二参数是方差，$\sigma=4$ 时 $\sigma^2=16$。
3. **$\mu$ 与 $\sigma$ 颠倒**：把 $\mu$ 与 $\sigma$ 互换 → 正确做法：分子 $x-\mu$ 决定位置（$\mu$），分母 $\sigma$ 决定尺度，二者不可互换。
:::

:::callout{kind=note label="知识卡片：正态分布的标准化"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 标准变换 | $F_X(x)=\Phi\!\left(\dfrac{x-\mu}{\sigma}\right)$ | $X\sim N(\mu,\sigma^2)$ |
| 拆分对照 | $\dfrac{x-\mu}{\sigma}=\dfrac{x}{\sigma}-\dfrac{\mu}{\sigma}$ | 由截距反推均值 |
| 截距与斜率 | 斜率 $\dfrac{1}{\sigma}$，截距 $-\dfrac{\mu}{\sigma}$ | 题给 $\Phi$ 复合形式 |
| 反推参数 | $\sigma=\dfrac{1}{\text{斜率}},\ \mu=-\text{截距}\times\sigma$ | 已知 $F_X=\Phi(ax+b)$ |
| 记号约定 | $N(\mu,\sigma^2)$ 第二参数为方差 | 任意正态分布 |

**概念辨析**：
- 标准变换 $\dfrac{x-\mu}{\sigma}$ 中，$\mu$ 是位置参数（平移），$\sigma$ 是尺度参数（缩放），二者作用不同不可混淆。
- $N(\mu,\sigma^2)$ 的第二参数是方差 $\sigma^2$ 而非标准差 $\sigma$，这是常见记号陷阱。
:::

:::callout{kind=tip label="结论速记"}
$\Phi\!\left(\dfrac{x}{4}-2\right)=\Phi\!\left(\dfrac{x-8}{4}\right)\Rightarrow X\sim N(8,16)$。

**口诀**：通分对照标准式，斜率定 $\sigma$ 截距定 $\mu$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$F_X(x)=\Phi(ax+b)$ 求 $X$ 分布"→ 联想"通分为 $\dfrac{x-\mu}{\sigma}$ 形式，对照得 $\mu,\sigma$"
- **关联考点**：正态分布标准化（第三章）、分布函数与密度函数关系
- **复用场景**：任何给出 $\Phi$ 复合形式分布函数的题目，均用通分对照法反解 $\mu,\sigma$；同理 $F_X(x)=\Phi(ax+b)$ 时 $\sigma=1/a,\ \mu=-b/a$
:::

### 第4题

:::callout{kind=note label="题目"}
设 $X \sim P(\lambda)$，每个感染者为无症状者的概率为 $\dfrac{1}{4}$，$Y$ 为无症状者人数。下列结论正确的是（　　）

其中：(1) $X, Y$ 相互独立；(2) $Y \sim P(\lambda/4)$；(3) $E(X^2) = \lambda^2 + \lambda$；(4) $P(Y=2500 \mid X=10000) = 1$。

A. (1)(2)　　B. (2)(3)　　C. (3)(4)　　D. (1)(4)
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：题干给出 $X\sim P(\lambda)$，每个个体以概率 $\frac{1}{4}$ 标记为无症状，$Y$ 为标记数。需逐条判定四个结论。入口是识别"泊松稀疏化"考点判定 (2)，用条件分布判定 (1)(4)，用二阶矩公式判定 (3)。

**为何用此公式**：泊松稀疏化定理处理"泊松源 + 独立标记"模型；二阶矩公式 $E(X^2)=D(X)+(EX)^2$ 处理泊松二阶矩；条件分布 $Y\mid X=n\sim B(n,p)$ 处理给定 $X$ 时 $Y$ 的分布。

**推导过程**：

1. 第一步：判定 (1) ← 依据：$Y$ 由 $X$ 个个体筛出，给定 $X=n$ 时 $Y\mid X=n\sim B(n,\frac{1}{4})$ 依赖于 $X$
   - $Y$ 的条件分布依赖于 $X$，故 $X,Y$ 不独立。(1) 错。
2. 第二步：判定 (2) ← 依据：泊松稀疏化定理 $X\sim P(\lambda)$，每个独立以概率 $p$ 标记 $\Rightarrow Y\sim P(\lambda p)$
   - $p=\frac{1}{4}$，故 $Y\sim P\!\left(\lambda\cdot\frac{1}{4}\right)=P(\lambda/4)$。(2) 对。
3. 第三步：判定 (3) ← 依据：泊松分布 $E(X)=\lambda,\ D(X)=\lambda$，二阶矩公式 $E(X^2)=D(X)+(EX)^2$
   $$E(X^2)=\lambda+\lambda^2=\lambda^2+\lambda$$
   - (3) 对。
4. 第四步：判定 (4) ← 依据：给定 $X=10000$ 时 $Y\sim B(10000,\frac{1}{4})$
   $$P(Y=2500\mid X=10000)=\dbinom{10000}{2500}\left(\frac{1}{4}\right)^{2500}\left(\frac{3}{4}\right)^{7500}$$
   - 这是一个很小的正数（并非 $1$）；$E(Y\mid X=10000)=2500$ 是期望而非必然取值。(4) 错。
5. 第五步：组合正确项 ← 依据：(2)(3) 正确
   - 选 B。

**选项分析**：

- **A（错误）**：含错误的 (1)，$X,Y$ 不独立。
- **B（正确）**：(2)(3) 均正确，与推导一致。
- **C（错误）**：含错误的 (4)，$P(Y=2500\mid X=10000)\neq 1$。
- **D（错误）**：(1)(4) 均错。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **派生量独立性误判**：误以为 $Y$ 由 $X$ 派生但仍与 $X$ 独立 → 正确做法：$Y\mid X=n\sim B(n,p)$ 明显依赖 $X$，故 $X,Y$ 不独立；稀疏化只保证 $Y$ 仍服从泊松，不保证与 $X$ 独立。
2. **期望与必然值混淆**：把 $E(Y\mid X=10000)=2500$ 当作 $P(Y=2500\mid X=10000)=1$ → 正确做法：期望是平均值而非必然取值，二项分布取单点概率为 $\dbinom{n}{k}p^k(1-p)^{n-k}$，远小于 $1$。
3. **泊松二阶矩公式记错**：误用 $E(X^2)=\lambda^2$ 漏掉 $D(X)$ 项 → 正确做法：$E(X^2)=D(X)+(EX)^2=\lambda+\lambda^2$，方差项不可漏。
:::

:::callout{kind=note label="知识卡片：泊松分布的稀疏化"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 泊松稀疏化 | $X\sim P(\lambda)$，每个独立以概率 $p$ 标记 $\Rightarrow Y\sim P(\lambda p)$ | 标记相互独立 |
| 条件分布 | $Y\mid X=n\sim B(n,p)$ | 给定 $X=n$ |
| 二阶矩 | $E(X^2)=D(X)+(EX)^2=\lambda+\lambda^2$ | 任意随机变量 |
| 独立性 | $Y$ 由 $X$ 派生，一般不与 $X$ 独立 | 派生关系 |
| 期望与单点 | $E(Y\mid X=n)=np$ 是均值，$P(Y=k\mid X=n)=\dbinom{n}{k}p^k(1-p)^{n-k}$ | 二项分布 |

**概念辨析**：
- 稀疏化定理保证 $Y$ 仍服从泊松（参数 $\lambda p$），但不保证 $Y$ 与 $X$ 独立；独立性需另用条件分布判断。
- 期望 $E(Y\mid X=n)=np$ 描述"平均取值"，单点概率 $P(Y=k\mid X=n)$ 描述"恰好取 $k$"，二者不可混为一谈。
:::

:::callout{kind=tip label="结论速记"}
泊松稀疏：$Y\sim P(\lambda p)$；泊松二阶矩 $E(X^2)=\lambda^2+\lambda$；派生量不与母量独立。

**口诀**：稀疏参数乘 $p$，二阶矩加方差，派生不独立。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"泊松源 + 独立标记计数"→ 联想"泊松稀疏化 $Y\sim P(\lambda p)$，条件分布 $Y\mid X=n\sim B(n,p)$"
- **关联考点**：泊松分布（第三章）、二项分布、条件期望与条件分布、数字特征
- **复用场景**：任何"泊松到达 + 分类筛选"模型，如排队论分流、保险理赔分类、传染病检测
:::

### 第5题

:::callout{kind=note label="题目"}
设 $X \sim U(1, 3)$，$F(x)$ 为其分布函数，下列说法正确的是（　　）

其中：(1) $F(X) \sim U(1, 3)$；(2) $X^2 \sim U(1, 9)$；(3) $\left|F(X)-\dfrac{1}{2}\right| \sim U\!\left(0, \dfrac{1}{2}\right)$；(4) $D(X) = \dfrac{1}{3}$。

A. (1)(2)　　B. (2)(3)　　C. (3)(4)　　D. (1)(4)
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：题干给出 $X\sim U(1,3)$，要求判定关于 $F(X)$、$X^2$、$|F(X)-\frac{1}{2}|$、$D(X)$ 的四个结论。入口是识别"概率积分变换"考点判定 (1)(3)，"非线性变换保均匀性"判定 (2)，"均匀分布方差公式"判定 (4)。

**为何用此公式**：概率积分变换 $F(X)\sim U(0,1)$（$X$ 连续时）是核心工具；均匀分布方差 $D(X)=\dfrac{(b-a)^2}{12}$；非线性变换 $Y=g(X)$ 的密度 $f_Y(y)=\sum \dfrac{f_X(x_i)}{|g'(x_i)|}$ 判断是否保均匀。

**推导过程**：

1. 第一步：判定 (1) ← 依据：概率积分变换，$X$ 连续 $\Rightarrow F(X)\sim U(0,1)$
   - $F(X)\sim U(0,1)$ 而非 $U(1,3)$。(1) 错。
2. 第二步：判定 (2) ← 依据：$Y=X^2$ 的密度公式 $f_Y(y)=\dfrac{f_X(\sqrt{y})}{2\sqrt{y}}$（$y\in[1,9]$，$X\geq 0$ 单调）
   $$f_Y(y)=\frac{f_X(\sqrt{y})}{2\sqrt{y}}=\frac{1/2}{2\sqrt{y}}=\frac{1}{4\sqrt{y}}$$
   - 密度含 $\dfrac{1}{\sqrt{y}}$ 不是常数，故 $X^2$ 不服从均匀分布。(2) 错。
3. 第三步：判定 (3) ← 依据：$F(X)\sim U(0,1)$，线性变换 $F(X)-\frac{1}{2}\sim U(-\frac{1}{2},\frac{1}{2})$，绝对值变换 $|U|\sim U(0,c)$（$U\sim U(-c,c)$）
   - $\left|F(X)-\dfrac{1}{2}\right|\sim U\!\left(0,\dfrac{1}{2}\right)$。(3) 对。
4. 第四步：判定 (4) ← 依据：均匀分布方差 $D(X)=\dfrac{(b-a)^2}{12}$
   $$D(X)=\frac{(3-1)^2}{12}=\frac{4}{12}=\frac{1}{3}$$
   - (4) 对。
5. 第五步：组合正确项 ← 依据：(3)(4) 正确
   - 选 C。

**选项分析**：

- **A（错误）**：含错误的 (1)，$F(X)\sim U(0,1)$ 非 $U(1,3)$。
- **B（错误）**：含错误的 (2)，$X^2$ 不服从均匀分布。
- **C（正确）**：(3)(4) 均正确，与推导一致。
- **D（错误）**：含错误的 (1)。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **概率积分变换区间错记**：误以为 $F(X)$ 与 $X$ 同分布 → 正确做法：$X$ 连续时 $F(X)\sim U(0,1)$，与 $X$ 的分布无关，区间恒为 $(0,1)$。
2. **非线性变换保均匀性误判**：误以为 $X\sim U(a,b)$ 则 $X^2\sim U(a^2,b^2)$ → 正确做法：只有线性变换 $aX+b$ 保持均匀性，非线性变换 $g(X)$ 的密度 $f_Y(y)=\dfrac{f_X(g^{-1}(y))}{|g'(g^{-1}(y))|}$ 一般非常数。
3. **绝对值变换区间错算**：误以为 $|F(X)-\frac{1}{2}|\sim U(0,1)$ → 正确做法：$F(X)-\frac{1}{2}\sim U(-\frac{1}{2},\frac{1}{2})$，取绝对值后折叠到 $[0,\frac{1}{2}]$，得 $U(0,\frac{1}{2})$。
:::

:::callout{kind=note label="知识卡片：均匀分布与概率积分变换"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 概率积分变换 | $X$ 连续 $\Rightarrow F(X)\sim U(0,1)$ | $F$ 严格单调连续 |
| 均匀分布方差 | $D(X)=\dfrac{(b-a)^2}{12}$ | $X\sim U(a,b)$ |
| 线性变换 | $aX+b\sim U(a\cdot l+b,\ a\cdot u+b)$（$a>0$） | $X\sim U(l,u)$ |
| 非线性变换 | $g(X)$ 一般不保持均匀性 | $g$ 非线性 |
| 绝对值变换 | $U\sim U(-c,c)\Rightarrow |U|\sim U(0,c)$ | 对称均匀分布 |
| 密度公式 | $f_Y(y)=\dfrac{f_X(g^{-1}(y))}{|g'(g^{-1}(y))|}$ | $g$ 单调可微 |

**概念辨析**：
- 概率积分变换 $F(X)\sim U(0,1)$ 要求 $X$ 连续（$F$ 严格单调）；离散型随机变量无此性质。
- 线性变换保持均匀性，非线性变换一般破坏均匀性，原因是密度公式中雅可比项 $|g'|$ 引入 $y$ 的依赖。
:::

:::callout{kind=tip label="结论速记"}
$F(X)\sim U(0,1)\Rightarrow \left|F(X)-\dfrac{1}{2}\right|\sim U(0,\dfrac{1}{2})$；$U(1,3)$ 方差为 $\dfrac{1}{3}$。

**口诀**：积分变换恒 $(0,1)$，线性保均匀非线性破，方差底宽平方除十二。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$F(X)$ 的分布"→ 联想"概率积分变换 $F(X)\sim U(0,1)$"
- **关联考点**：均匀分布（第三章）、随机变量函数的分布、概率积分变换
- **复用场景**：任何涉及 $F(X)$ 或 $g(F(X))$ 分布的题目；蒙特卡洛抽样中由 $U(0,1)$ 生成任意分布的反函数法
:::

### 第6题

:::callout{kind=note label="题目"}
设二维随机向量 $(X_1, Y_1)$ 与 $(X_2, Y_2)$ 相互独立且同分布，则不一定成立的是（　　）

A. $X_1$ 与 $Y_1$ 独立　　B. $X_1$ 与 $Y_2$ 独立　　C. $X_1$ 与 $X_2$ 同分布　　D. $Y_1$ 与 $Y_2$ 同分布
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：题干给出两个二维随机向量 $(X_1,Y_1)$ 与 $(X_2,Y_2)$ 彼此独立且同分布，要求判断哪个结论不一定成立。入口是区分"向量间独立"与"向量内部独立"，前者由题设给出，后者需额外条件。

**为何用此公式**：向量间独立 $\Rightarrow$ 跨向量任意分量独立；同分布 $\Rightarrow$ 对应边缘同分布；向量内部独立需单独验证，题设未给。

**推导过程**：

1. 第一步：明确题设 ← 依据：$(X_1,Y_1)\perp(X_2,Y_2)$ 且同分布
   - 向量间独立 + 同分布。
2. 第二步：判定 A ← 依据：向量内部独立 $X_1\perp Y_1$ 需额外条件，题设未限定
   - 取反例 $Y_1=X_1$（退化情形），则 $X_1,Y_1$ 完全相关，不独立。故 A 不一定成立。
3. 第三步：判定 B ← 依据：向量间独立 $\Rightarrow$ 跨向量分量独立
   - $X_1$ 属第一个向量，$Y_2$ 属第二个向量，两向量独立故 $X_1\perp Y_2$。B 成立。
4. 第四步：判定 C ← 依据：同分布 $\Rightarrow$ 对应边缘同分布
   - $X_1$ 与 $X_2$ 是两向量的对应分量，同分布故 $X_1\stackrel{d}{=}X_2$。C 成立。
5. 第五步：判定 D ← 依据：同分布 $\Rightarrow$ 对应边缘同分布
   - $Y_1$ 与 $Y_2$ 是对应分量，同分布故 $Y_1\stackrel{d}{=}Y_2$。D 成立。

**选项分析**：

- **A（正确，即不一定成立）**：向量内部 $X_1,Y_1$ 的独立性题设未约束，反例 $Y_1=X_1$ 时完全不独立。
- **B（错误，必然成立）**：跨向量分量由向量间独立保证。
- **C（错误，必然成立）**：对应边缘由同分布保证。
- **D（错误，必然成立）**：对应边缘由同分布保证。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **混淆"向量间独立"与"向量内部独立"**：误以为向量间独立可推出向量内部分量独立 → 正确做法：向量间独立只保证跨向量分量独立，向量内部关系需单独给定。
2. **同分布误解为独立**：误以为同分布即独立 → 正确做法：同分布只保证边缘分布相同，不约束分量间关系；独立与同分布是两个不同概念。
3. **反例构造缺失**：无法构造反例验证"不一定成立" → 正确做法：取退化情形 $Y_1=X_1$（完全相关），仍满足两向量同分布且独立，但 $X_1,Y_1$ 不独立。
:::

:::callout{kind=note label="知识卡片：随机向量独立性的层级"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 向量间独立 | $(X_1,Y_1)\perp(X_2,Y_2)$，跨向量任意分量独立 | 题设给定 |
| 同分布 | 对应边缘分布相同 | 题设给定 |
| 向量内部独立 | $X_i\perp Y_i$ | 需额外条件 |
| 反例 | 取 $Y_1=X_1$，则 $X_1,Y_1$ 完全相关 | 退化情形 |
| 跨向量分量 | $X_i\perp Y_j$（$i\neq j$） | 向量间独立 |

**概念辨析**：
- "向量间独立"是联合分布的分解 $(X_1,Y_1)$ 与 $(X_2,Y_2)$ 独立，"向量内部独立"是 $X_i$ 与 $Y_i$ 独立，二者层级不同。
- "同分布"只约束边缘，不约束联合；两个同分布的向量内部结构可以完全不同（一个独立一个相关）。
:::

:::callout{kind=tip label="结论速记"}
向量间独立 $\neq$ 向量内部独立；同分布只保证边缘相同，不约束分量间关系。

**口诀**：跨向量独立同分布，向量内部另当论。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"两个随机向量独立同分布"→ 联想"跨向量分量独立 + 对应边缘同分布，但向量内部关系未定"
- **关联考点**：随机向量独立性（第四章）、边缘分布与联合分布、独立性与同分布的区别
- **复用场景**：任何涉及多维随机向量独立性判断的题目，特别是"独立同分布样本"的语义辨析
:::

### 第7题

:::callout{kind=note label="题目"}
设 $(X_1, X_2, X_3, X_4)$ 来自 $N(0, 3^2)$，$\bar{X}, S^2$ 为样本均值和样本方差，则正确的是（　　）

A. $E(\bar{X}S^2) = 9$　　B. $\dfrac{X_1+X_2}{\sqrt{X_3^2+X_4^2}} \sim t(2)$　　C. $\dfrac{2\bar{X}}{S} \sim t(4)$　　D. $\dfrac{X_1^2+X_2^2}{X_3^2} \sim F(2, 1)$
:::

:::callout{kind=insight label="解析"}
**【答案】B**

**思路**：题干给出 $X_i\sim N(0,9)$ i.i.d.，要求判定四个抽样分布结论。入口是先标准化 $X_i/3\sim N(0,1)$，再分别用 $t$ 分布、$F$ 分布定义与样本均值方差独立性定理验证各选项。

**为何用此公式**：$t$ 分布定义 $\dfrac{N(0,1)}{\sqrt{\chi^2(k)/k}}\sim t(k)$ 与 $F$ 分布定义 $\dfrac{\chi^2(m)/m}{\chi^2(n)/n}\sim F(m,n)$ 是判定抽样分布的标准工具；正态样本中 $\bar{X}$ 与 $S^2$ 独立用于判定 A。

**推导过程**：

1. 第一步：标准化 ← 依据：$X_i\sim N(0,9)\Rightarrow \dfrac{X_i}{3}\sim N(0,1)$，故 $\left(\dfrac{X_i}{3}\right)^2\sim\chi^2(1)$
2. 第二步：验证 B ← 依据：$X_1+X_2\sim N(0,18)$（独立正态和），标准化 $\dfrac{X_1+X_2}{\sqrt{18}}\sim N(0,1)$
   $$\frac{X_3^2+X_4^2}{9}=\left(\frac{X_3}{3}\right)^2+\left(\frac{X_4}{3}\right)^2\sim\chi^2(2)$$
   $$\frac{X_1+X_2}{\sqrt{X_3^2+X_4^2}}=\frac{(X_1+X_2)/\sqrt{18}}{\sqrt{(X_3^2+X_4^2)/(9\cdot 2)}}=\frac{N(0,1)}{\sqrt{\chi^2(2)/2}}\sim t(2)$$
   - B 正确。
3. 第三步：验证 A ← 依据：正态样本 $\bar{X}\perp S^2$，$E(\bar{X}S^2)=E(\bar{X})E(S^2)$
   - $E(\bar{X})=0$，$E(S^2)=\sigma^2=9$，故 $E(\bar{X}S^2)=0\cdot 9=0\neq 9$。A 错。
4. 第四步：验证 C ← 依据：$\bar{X}\sim N(0,\frac{9}{4})$，$\dfrac{2\bar{X}}{3}\sim N(0,1)$；$\dfrac{3S^2}{9}=\dfrac{S^2}{3}\sim\chi^2(3)$
   $$\frac{2\bar{X}}{S}=\frac{2\bar{X}/3}{\sqrt{S^2/(3\cdot 3)}}=\frac{N(0,1)}{\sqrt{\chi^2(3)/3}}\sim t(3)$$
   - 自由度为 $3$ 而非 $4$。C 错。
5. 第五步：验证 D ← 依据：$\dfrac{X_1^2+X_2^2}{9}\sim\chi^2(2)$，$\dfrac{X_3^2}{9}\sim\chi^2(1)$
   $$\frac{X_1^2+X_2^2}{X_3^2}=\frac{(X_1^2+X_2^2)/9}{X_3^2/9}=\frac{\chi^2(2)}{\chi^2(1)}=2\cdot\frac{\chi^2(2)/2}{\chi^2(1)/1}=2F(2,1)$$
   - 多了因子 $2$，不等于 $F(2,1)$。D 错。

**选项分析**：

- **A（错误）**：$E(\bar{X}S^2)=0$ 而非 $9$，对应忽略 $\bar{X}\perp S^2$ 与 $E\bar{X}=0$ 的错误，正确应为 $0$。
- **B（正确）**：标准化后构造 $\dfrac{N(0,1)}{\sqrt{\chi^2(2)/2}}\sim t(2)$，与定义一致。
- **C（错误）**：自由度错算为 $4$，实际为 $3$（样本方差自由度 $n-1=3$）。
- **D（错误）**：少了标准化因子，$\dfrac{\chi^2(2)}{\chi^2(1)}=2F(2,1)\neq F(2,1)$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **t 分布定义漏除自由度**：误写 $\dfrac{N(0,1)}{\sqrt{\chi^2(k)}}\sim t(k)$ → 正确做法：$t(k)=\dfrac{N(0,1)}{\sqrt{\chi^2(k)/k}}$，分母必须除以自由度 $k$。
2. **样本方差自由度错算**：把 $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ 的自由度误为 $n$ → 正确做法：自由度为 $n-1$（本题 $n=4$，自由度 $3$）。
3. **F 分布定义漏除自由度**：误写 $\dfrac{\chi^2(m)}{\chi^2(n)}\sim F(m,n)$ → 正确做法：$F(m,n)=\dfrac{\chi^2(m)/m}{\chi^2(n)/n}$，分子分母都要除以各自自由度，漏除会产生常数因子。
4. **忽略 $\bar{X}\perp S^2$**：误用 $E(\bar{X}S^2)\neq E\bar{X}\cdot ES^2$ → 正确做法：正态样本中 $\bar{X}$ 与 $S^2$ 独立，期望可拆分。
:::

:::callout{kind=note label="知识卡片：正态样本的抽样分布"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 样本均值 | $\bar{X}\sim N\!\left(\mu,\dfrac{\sigma^2}{n}\right)$ | $X_i\sim N(\mu,\sigma^2)$ i.i.d. |
| 样本方差 | $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ | 同上 |
| 均值与方差独立 | $\bar{X}\perp S^2$ | 正态总体 |
| t 分布定义 | $\dfrac{N(0,1)}{\sqrt{\chi^2(k)/k}}\sim t(k)$ | 分子分母独立 |
| F 分布定义 | $\dfrac{\chi^2(m)/m}{\chi^2(n)/n}\sim F(m,n)$ | 分子分母独立 |
| 独立正态和 | $X_i+X_j\sim N(\mu_i+\mu_j,\ \sigma_i^2+\sigma_j^2)$ | $X_i\perp X_j$ |

**概念辨析**：
- $t$ 分布与 $F$ 分布定义中"除以自由度"不可省略：$\dfrac{\chi^2(m)}{\chi^2(n)}=\dfrac{m}{n}F(m,n)$，漏除会引入常数因子。
- $\bar{X}\perp S^2$ 仅在正态总体下成立，非正态总体不保证；本题总体正态故可用。
:::

:::callout{kind=tip label="结论速记"}
$N(0,\sigma^2)$ 样本：$\dfrac{\sum X_i/\sigma}{\sqrt{\sum X_j^2/(\sigma^2 k)}}\sim t(k)$，注意 $\sigma$ 与自由度的配比。

**口诀**：t 除自由度 F 双除，均值方差正态独立。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"正态样本统计量的分布"→ 联想"标准化为 $N(0,1)$ 与 $\chi^2$，再用 $t$、$F$ 定义构造"
- **关联考点**：抽样分布（第六章）、$t$ 分布与 $F$ 分布定义、正态样本均值与方差独立性
- **复用场景**：任何涉及正态样本统计量分布判定的题目，包括置信区间与假设检验中统计量的构造
:::

### 第8题

:::callout{kind=note label="题目"}
设 $X_n$ 独立同分布，$E(X_n^k) = \mu_k,\ k=1,2,3,4$。对 $\dfrac{1}{n}\sum_{i=1}^{n} X_i^2$ 用切比雪夫不等式，可得方差上界（　　）

A. $\dfrac{\mu_2 - \mu_1^2}{n\varepsilon^2}$　　B. $\dfrac{\mu_3^2 - \mu_2^2}{n^2\varepsilon^2}$　　C. $\dfrac{\mu_2 - \mu_1^2}{n^2\varepsilon^2}$　　D. $\dfrac{\mu_4 - \mu_2^2}{n\varepsilon^2}$
:::

:::callout{kind=insight label="解析"}
**【答案】D**

**思路**：题干给出 $X_n$ i.i.d. 且 $k$ 阶矩 $E(X_n^k)=\mu_k$，要求对 $\dfrac{1}{n}\sum X_i^2$ 用切比雪夫不等式得方差上界。入口是令 $Y_i=X_i^2$ 把问题转化为 $\bar{Y}$ 的切比雪夫上界，需计算 $Y_i$ 的期望与方差。

**为何用此公式**：切比雪夫不等式 $P(|\bar{Y}-E\bar{Y}|\geq\varepsilon)\leq\dfrac{D\bar{Y}}{\varepsilon^2}$，其中 $D\bar{Y}=\dfrac{DY_1}{n}$；$Y_i=X_i^2$ 的期望 $EY_i=\mu_2$、方差 $DY_i=EY_i^2-(EY_i)^2=\mu_4-\mu_2^2$。

**推导过程**：

1. 第一步：变量替换 ← 依据：令 $Y_i=X_i^2$，则 $Y_i$ 亦 i.i.d.
   $$\bar{Y}=\frac{1}{n}\sum_{i=1}^n Y_i=\frac{1}{n}\sum_{i=1}^n X_i^2$$
2. 第二步：计算 $Y_i$ 的期望 ← 依据：$E(Y_i)=E(X_i^2)=\mu_2$
3. 第三步：计算 $Y_i$ 的方差 ← 依据：$D(Y_i)=E(Y_i^2)-(EY_i)^2$，$E(Y_i^2)=E(X_i^4)=\mu_4$
   $$D(Y_i)=\mu_4-\mu_2^2$$
4. 第四步：计算 $\bar{Y}$ 的方差 ← 依据：i.i.d. 样本均值方差 $D\bar{Y}=\dfrac{DY_1}{n}$
   $$D(\bar{Y})=\frac{\mu_4-\mu_2^2}{n}$$
5. 第五步：代入切比雪夫不等式 ← 依据：$P(|\bar{Y}-E\bar{Y}|\geq\varepsilon)\leq\dfrac{D\bar{Y}}{\varepsilon^2}$
   $$P\!\left(\left|\frac{1}{n}\sum_{i=1}^n X_i^2-\mu_2\right|\geq\varepsilon\right)\leq\frac{\mu_4-\mu_2^2}{n\varepsilon^2}$$

**选项分析**：

- **A（错误）**：分子 $\mu_2-\mu_1^2$ 是 $X$ 的方差 $D(X_1)$，对应 $\bar{X}$ 的切比雪夫上界，而非 $\overline{X^2}$，正确分子应为 $\mu_4-\mu_2^2$。
- **B（错误）**：分子 $\mu_3^2-\mu_2^2$ 量纲与构造不符，三阶矩平方差不对应任何合理变量的方差。
- **C（错误）**：分母多了 $n^2$，未进行样本均值方差缩放 $D\bar{Y}=\dfrac{DY_1}{n}$（只除一次 $n$）。
- **D（正确）**：分子 $\mu_4-\mu_2^2=D(X_1^2)$，分母 $n\varepsilon^2$，与推导一致。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **变量替换后矩的对应错乱**：误以为 $\overline{X^2}$ 的方差分子是 $D(X_1)=\mu_2-\mu_1^2$ → 正确做法：令 $Y_i=X_i^2$，$DY_i=E(Y_i^2)-(EY_i)^2=\mu_4-\mu_2^2$，是新变量的方差。
2. **样本均值方差缩放次数错**：误除 $n^2$ 得 $\dfrac{DY_1}{n^2}$ → 正确做法：$D\bar{Y}=\dfrac{1}{n^2}\sum DY_i=\dfrac{1}{n^2}\cdot n\,DY_1=\dfrac{DY_1}{n}$，只除一次 $n$。
3. **矩的阶数混淆**：把 $\mu_4$ 误认为 $E(X^4)$ 的高阶展开 → 正确做法：题设 $E(X_n^k)=\mu_k$，故 $\mu_4=E(X^4)$，$\mu_2=E(X^2)$，直接代入。
:::

:::callout{kind=note label="知识卡片：切比雪夫不等式与样本均值"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 切比雪夫不等式 | $P(|X-EX|\geq\varepsilon)\leq\dfrac{DX}{\varepsilon^2}$ | 任意有方差随机变量 |
| 样本均值方差 | $D\bar{X}=\dfrac{DX_1}{n}$ | i.i.d. 样本 |
| 变量替换 | 令 $Y_i=g(X_i)$，$\bar{Y}$ 的矩由 $Y$ 的矩决定 | $g$ 可测 |
| $\bar{X}$ 上界 | $\dfrac{\mu_2-\mu_1^2}{n\varepsilon^2}$ | $D(X_1)=\mu_2-\mu_1^2$ |
| $\overline{X^2}$ 上界 | $\dfrac{\mu_4-\mu_2^2}{n\varepsilon^2}$ | $D(X_1^2)=\mu_4-\mu_2^2$ |

**概念辨析**：
- 切比雪夫不等式对任意有方差的随机变量成立，不要求独立同分布；但求 $\bar{Y}$ 方差时需用 i.i.d. 性质 $D\bar{Y}=\dfrac{DY_1}{n}$。
- $\overline{X^2}$ 的切比雪夫上界用 $D(X_1^2)=\mu_4-\mu_2^2$，而非 $D(X_1)=\mu_2-\mu_1^2$；变量替换后矩的阶数要相应提升。
:::

:::callout{kind=tip label="结论速记"}
对 $\dfrac{1}{n}\sum X_i^2$ 用切比雪夫，上界为 $\dfrac{\mu_4-\mu_2^2}{n\varepsilon^2}$（把 $X_i^2$ 视为新变量 $Y_i$）。

**口诀**：换元升阶算方差，缩 $n$ 除 $\varepsilon^2$ 得上界。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"对 $\overline{g(X)}$ 用切比雪夫不等式"→ 联想"令 $Y=g(X)$，算 $DY=E(Y^2)-(EY)^2$，上界 $\dfrac{DY}{n\varepsilon^2}$"
- **关联考点**：切比雪夫不等式（第五章）、样本均值数字特征、矩的计算
- **复用场景**：任何对样本均值函数用切比雪夫或大数定律的题目，统一用变量替换法处理
:::

### 第9题

:::callout{kind=note label="题目"}
设 $X_n$ 相互独立。根据辛钦大数定律，若 $X_n$ 满足下列条件即可服从大数定律的是（　　）

A. 有相同数学期望　　B. 服从同一离散型分布　　C. 服从同一泊松分布　　D. 服从同一连续型分布
:::

:::callout{kind=insight label="解析"}
**【答案】C**

**思路**：题干要求根据辛钦大数定律判定哪个条件可保证 $X_n$ 服从大数定律。入口是回忆辛钦大数定律的两个核心条件：独立同分布 + 期望存在有限，逐项验证。

**为何用此公式**：辛钦大数定律要求"独立同分布且期望存在"，是判定 i.i.d. 序列大数定律的直接工具；同分布保证期望相同，特定分布（如泊松）保证期望有限。

**推导过程**：

1. 第一步：回忆辛钦大数定律条件 ← 依据：$X_n$ 独立同分布且 $E|X_1|<+\infty$ $\Rightarrow$ $\bar{X}_n\xrightarrow{P}E(X_1)$
2. 第二步：验证 A ← 依据：仅有相同期望，分布可以不同
   - 不满足"同分布"条件。A 错。
3. 第三步：验证 B ← 依据："同一离散型分布"表述含糊
   - 若理解为"同为某一离散分布"则同分布成立，但若仅"都是离散型"则分布未必相同；表述不明确，且未保证期望存在。B 不选。
4. 第四步：验证 C ← 依据：同一泊松分布 $P(\lambda)$ 满足同分布，且 $E(X_1)=\lambda<+\infty$
   - 完全符合辛钦大数定律两条件。C 对。
5. 第五步：验证 D ← 依据：同为连续型不等于同分布，期望也未必存在
   - 反例：柯西分布连续但期望不存在。D 错。

**选项分析**：

- **A（错误）**：相同期望不保证同分布，辛钦要求"同分布"。
- **B（错误）**："同一离散型分布"表述含糊，未明确"同分布"且未保证期望存在，C 更明确。
- **C（正确）**：同泊松分布既同分布又保证期望有限，完全符合辛钦条件。
- **D（错误）**：同为连续型不保证同分布，且柯西分布期望不存在。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **辛钦条件记漏"同分布"**：误以为独立 + 期望存在即可 → 正确做法：辛钦大数定律要求"独立同分布 + 期望存在"，三者缺一不可。
2. **"同类型分布"与"同分布"混淆**：误以为"都是离散型"或"都是连续型"即同分布 → 正确做法：同分布指具体分布相同（如同为 $P(\lambda)$），而非同属一个大类。
3. **忽略期望存在性**：误以为同分布即满足辛钦 → 正确做法：同分布后还需期望存在，柯西分布是反例（连续对称但期望不存在）。
:::

:::callout{kind=note label="知识卡片：大数定律比较"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 切比雪夫大数定律 | $\bar{X}\xrightarrow{P}E(\bar{X})$ | 独立、方差一致有界 $D(X_i)\leq C$ |
| 辛钦大数定律 | $\bar{X}\xrightarrow{P}E(X_1)$ | 独立同分布、期望存在 |
| 强大数定律（柯尔莫哥洛夫） | $\bar{X}\xrightarrow{a.s.}E(X_1)$ | 独立同分布、期望存在 |
| 伯努利大数定律 | 频率 $\xrightarrow{P}$ 概率 | $n$ 重伯努利试验 |
| 期望存在 | $E|X_1|<+\infty$ | 辛钦、强大数必要条件 |

**概念辨析**：
- 切比雪夫大数定律不要求同分布，但要求方差一致有界；辛钦大数定律要求同分布，但不要求方差存在（只要求期望存在）。
- "期望存在"指 $E|X_1|<+\infty$，柯西分布 $E|X|=\infty$ 故不满足，辛钦大数定律不适用。
:::

:::callout{kind=tip label="结论速记"}
辛钦大数定律 $=$ 独立 $+$ 同分布 $+$ 期望存在；同泊松分布满足全部条件。

**口诀**：辛钦三件套，独立同分布期望在。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"辛钦大数定律"→ 联想"独立同分布 + 期望存在"
- **关联考点**：大数定律（第五章）、切比雪夫不等式、柯西分布反例
- **复用场景**：任何判定某序列是否服从大数定律的题目，先检查独立、同分布、期望存在三条件
:::

### 第10题

:::callout{kind=note label="题目"}
设总体 $X \sim N(\mu, \sigma^2)$，$\mu$ 未知、$\sigma^2$ 已知。给定 $n$ 与置信水平时，$\mu$ 的双侧置信区间长度随 $\bar{X}$ 增加而（　　）

A. 不变　　B. 增加　　C. 减少　　D. 无法确定
:::

:::callout{kind=insight label="解析"}
**【答案】A**

**思路**：题干给出方差已知时 $\mu$ 的双侧置信区间，要求判断区间长度随 $\bar{X}$ 变化的趋势。入口是写出置信区间公式，提取长度表达式，观察其依赖变量。

**为何用此公式**：方差已知时 $\mu$ 的双侧 $1-\alpha$ 置信区间为 $\bar{X}\pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$，区间长度 $L=2z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$，只依赖 $\sigma,n,\alpha$，与 $\bar{X}$ 无关。

**推导过程**：

1. 第一步：写出枢轴量 ← 依据：$\sigma^2$ 已知，$\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\sim N(0,1)$
2. 第二步：构造置信区间 ← 依据：$P\!\left(\left|\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\right|\leq z_{\alpha/2}\right)=1-\alpha$
   $$\left[\bar{X}-z_{\alpha/2}\cdot\frac{\sigma}{\sqrt{n}},\ \bar{X}+z_{\alpha/2}\cdot\frac{\sigma}{\sqrt{n}}\right]$$
3. 第三步：计算区间长度 ← 依据：上限减下限
   $$L=\left(\bar{X}+z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right)-\left(\bar{X}-z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right)=2z_{\alpha/2}\cdot\frac{\sigma}{\sqrt{n}}$$
4. 第四步：分析依赖关系 ← 依据：$L$ 表达式中不含 $\bar{X}$
   - $L$ 只依赖 $\sigma,n,\alpha$，与 $\bar{X}$ 无关。$\bar{X}$ 增加时区间整体平移，长度不变。

**选项分析**：

- **A（正确）**：长度 $L=2z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$ 与 $\bar{X}$ 无关，$\bar{X}$ 仅平移中心。
- **B（错误）**：误认为 $\bar{X}$ 增大时区间变宽，未察觉 $\bar{X}$ 只是平移中心，正确应为不变。
- **C（错误）**：方向错误，长度与 $\bar{X}$ 无关而非反向变化。
- **D（错误）**：长度有确定表达式 $L=2z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$，并非无法确定。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **区间长度与中心混淆**：误以为 $\bar{X}$ 增大时区间变宽 → 正确做法：$\bar{X}$ 是区间中心，中心平移不改变半宽 $z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$，长度恒定。
2. **方差已知与未知混淆**：误用 $\sigma^2$ 未知时的区间 $\bar{X}\pm t_{\alpha/2}\dfrac{S}{\sqrt{n}}$（含随机量 $S$）→ 正确做法：本题 $\sigma^2$ 已知，用 $z$ 区间，长度确定；$\sigma^2$ 未知时长度含 $S$ 才随机。
3. **混淆"长度"与"位置"**：把区间端点随 $\bar{X}$ 变化误认为长度变化 → 正确做法：两端点同步平移，差值（长度）不变。
:::

:::callout{kind=note label="知识卡片：正态总体均值置信区间"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $\sigma^2$ 已知枢轴量 | $\dfrac{\bar{X}-\mu}{\sigma/\sqrt{n}}\sim N(0,1)$ | 总体正态 |
| $\sigma^2$ 已知区间 | $\bar{X}\pm z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$ | 同上 |
| $\sigma^2$ 已知长度 | $2z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$（确定值） | 与 $\bar{X}$ 无关 |
| $\sigma^2$ 未知枢轴量 | $\dfrac{\bar{X}-\mu}{S/\sqrt{n}}\sim t(n-1)$ | 总体正态 |
| $\sigma^2$ 未知区间 | $\bar{X}\pm t_{\alpha/2}(n-1)\dfrac{S}{\sqrt{n}}$ | 同上 |
| $\sigma^2$ 未知长度 | $2t_{\alpha/2}\dfrac{S}{\sqrt{n}}$（含随机量 $S$） | 随机 |

**概念辨析**：
- $\sigma^2$ 已知时区间长度是确定值（不含随机量），与 $\bar{X}$ 无关；$\sigma^2$ 未知时长度含 $S$ 是随机的。
- 区间长度随 $n$ 增大而减小（$L\propto\dfrac{1}{\sqrt{n}}$），随 $\sigma$ 增大而增大，随置信水平 $1-\alpha$ 增大而增大（$z_{\alpha/2}$ 增大）。
:::

:::callout{kind=tip label="结论速记"}
$\sigma^2$ 已知时置信区间长度 $L=2z_{\alpha/2}\dfrac{\sigma}{\sqrt{n}}$，与 $\bar{X}$ 无关，仅随 $n$ 增大而减小。

**口诀**：方差已知长度定，$\bar{X}$ 只移中心不变形。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"方差已知时 $\mu$ 的置信区间长度"→ 联想"$L=2z_{\alpha/2}\sigma/\sqrt{n}$，与 $\bar{X}$ 无关"
- **关联考点**：参数估计（第七章）、枢轴量法、正态总体抽样分布
- **复用场景**：任何涉及置信区间长度或样本量确定的题目，方差已知用 $z$ 区间，方差未知用 $t$ 区间
:::

## 二、填空题（每题 3 分，共 12 分）

### 第11题

:::callout{kind=note label="题目"}
已知 $P(\bar{A}) = 0.3$，$P(B) = 0.4$，$P(A\bar{B}) = 0.5$，则 $P(B \mid A \cup \bar{B}) =$ ____。
:::

:::callout{kind=insight label="解析"}
**【答案】$\dfrac{1}{4}$**

**思路**：题干给出 $P(\bar{A}),P(B),P(A\bar{B})$，要求条件概率 $P(B\mid A\cup\bar{B})$。入口是先用对立事件求 $P(A)$，再用差事件公式求 $P(AB)$，最后用条件概率定义与分配律计算分子分母。

**为何用此公式**：差事件公式 $P(A\bar{B})=P(A)-P(AB)$ 可由 $P(A\bar{B})$ 反解 $P(AB)$；分配律 $B\cap(A\cup\bar{B})=AB\cup B\bar{B}=AB$ 简化分子；并事件公式 $P(A\cup\bar{B})=P(A)+P(\bar{B})-P(A\bar{B})$ 算分母。

**推导过程**：

1. 第一步：求 $P(A)$ ← 依据：对立事件 $P(A)=1-P(\bar{A})$
   $$P(A)=1-0.3=0.7$$
2. 第二步：求 $P(AB)$ ← 依据：差事件公式 $P(A\bar{B})=P(A)-P(AB)$
   $$P(AB)=P(A)-P(A\bar{B})=0.7-0.5=0.2$$
3. 第三步：求 $P(\bar{B})$ ← 依据：对立事件
   $$P(\bar{B})=1-P(B)=1-0.4=0.6$$
4. 第四步：求分母 $P(A\cup\bar{B})$ ← 依据：并事件公式 $P(A\cup\bar{B})=P(A)+P(\bar{B})-P(A\bar{B})$
   $$P(A\cup\bar{B})=0.7+0.6-0.5=0.8$$
5. 第五步：求分子 $P(B\cap(A\cup\bar{B}))$ ← 依据：分配律 $B\cap(A\cup\bar{B})=AB\cup B\bar{B}$，$B\bar{B}=\varnothing$
   $$P(B\cap(A\cup\bar{B}))=P(AB)+P(B\bar{B})=P(AB)+0=0.2$$
6. 第六步：代入条件概率 ← 依据：$P(B\mid C)=\dfrac{P(BC)}{P(C)}$
   $$P(B\mid A\cup\bar{B})=\frac{0.2}{0.8}=\frac{1}{4}$$

**关键步骤说明**：

- 关键在于用分配律把分子 $B\cap(A\cup\bar{B})$ 化简为 $AB$：因 $B\bar{B}=\varnothing$ 自动消去，只剩 $AB$。
- 分母用并事件公式展开，三项中 $P(A\bar{B})$ 已知可直接代入。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **差事件公式方向错**：误写 $P(AB)=P(A\bar{B})-P(A)$ → 正确做法：$P(A\bar{B})=P(A)-P(AB)$，故 $P(AB)=P(A)-P(A\bar{B})=0.7-0.5=0.2$。
2. **分配律展开遗漏互斥项**：误写 $B\cap(A\cup\bar{B})=AB\cup B\bar{B}$ 后未消去 $B\bar{B}$ → 正确做法：$B\bar{B}=\varnothing$，$P(B\bar{B})=0$，分子只剩 $P(AB)$。
3. **并事件公式漏项**：误写 $P(A\cup\bar{B})=P(A)+P(\bar{B})$ 漏去 $-P(A\bar{B})$ → 正确做法：$P(A\cup\bar{B})=P(A)+P(\bar{B})-P(A\bar{B})$，交集项必须减去。
:::

:::callout{kind=note label="知识卡片：条件概率与事件运算"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 条件概率 | $P(B\mid C)=\dfrac{P(BC)}{P(C)}$ | $P(C)>0$ |
| 差事件 | $P(A\bar{B})=P(A)-P(AB)$ | 任意两事件 |
| 并事件 | $P(A\cup B)=P(A)+P(B)-P(AB)$ | 任意两事件 |
| 对立事件 | $P(\bar{A})=1-P(A)$ | 任意事件 |
| 分配律 | $B\cap(A\cup\bar{B})=AB\cup B\bar{B}$ | 任意事件 |
| 互斥分解 | $B\bar{B}=\varnothing,\ P(B\bar{B})=0$ | 互斥定义 |

**概念辨析**：
- 差事件公式 $P(A\bar{B})=P(A)-P(AB)$ 与并事件公式 $P(A\cup B)=P(A)+P(B)-P(AB)$ 共享交集项 $P(AB)$，二者可互推。
- 分配律 $B\cap(A\cup\bar{B})=(BA)\cup(B\bar{B})$ 中，$B\bar{B}=\varnothing$ 自动消去，是简化分子的关键。
:::

:::callout{kind=tip label="结论速记"}
先由 $P(AB)=P(A)-P(A\bar{B})$ 求交集，再分配律 $B\cap(A\cup\bar{B})=AB$，得 $\dfrac{0.2}{0.8}=\dfrac{1}{4}$。

**口诀**：差事件反解交集，分配律消互斥项。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"已知 $P(A\bar{B})$ 求 $P(B\mid A\cup\bar{B})$"→ 联想"差事件反解 $P(AB)$，分配律化分子为 $AB$"
- **关联考点**：条件概率与事件运算（第一章）、差事件公式、分配律
- **复用场景**：任何涉及条件概率与事件并交运算的题目，统一用差事件公式 + 分配律化简
:::

### 第12题

:::callout{kind=note label="题目"}
设 $(X_1, X_2)$ 来自 $B(1, p)$，$Y = \max(X_1, X_2) + \min(X_1, X_2)$，则 $P(Y=1) =$ ____。
:::

:::callout{kind=insight label="解析"}
**【答案】$2p(1-p)$**

**思路**：题干给出 $Y=\max(X_1,X_2)+\min(X_1,X_2)$，要求 $P(Y=1)$。入口是识别恒等式 $\max+\min=$ 和，把 $Y$ 化简为 $X_1+X_2$，再用二项分布求单点概率。

**为何用此公式**：恒等式 $\max(a,b)+\min(a,b)=a+b$ 对任意两实数成立，可省去分类讨论 $\max$ 与 $\min$ 的取值；$X_1,X_2$ 独立同服从 $B(1,p)$，其和 $X_1+X_2\sim B(2,p)$，单点概率用二项分布公式。

**推导过程**：

1. 第一步：应用恒等式 ← 依据：$\max(a,b)+\min(a,b)=a+b$（任意两数）
   $$Y=\max(X_1,X_2)+\min(X_1,X_2)=X_1+X_2$$
2. 第二步：识别和的分布 ← 依据：$X_1,X_2$ 独立同服从 $B(1,p)$，二项分布可加性
   $$Y=X_1+X_2\sim B(2,p)$$
3. 第三步：求单点概率 ← 依据：二项分布 $P(B(n,p)=k)=\dbinom{n}{k}p^k(1-p)^{n-k}$
   $$P(Y=1)=\dbinom{2}{1}p^1(1-p)^{2-1}=2p(1-p)$$
4. 第四步：直观验证 ← 依据：$Y=1$ 即一次成功一次失败
   - 两种排列 $(1,0)$ 与 $(0,1)$，概率各 $p(1-p)$，合计 $2p(1-p)$。

**关键步骤说明**：

- 关键在于识别 $\max+\min=$ 和 恒等式，避免分类讨论 $X_1\geq X_2$ 与 $X_1<X_2$ 两种情形。
- 化简后 $Y=X_1+X_2\sim B(2,p)$，单点概率直接套二项公式。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **未识别恒等式硬分类讨论**：分 $X_1\geq X_2$ 与 $X_1<X_2$ 讨论导致计算繁琐易错 → 正确做法：用 $\max+\min=$ 和 恒等式直接化简 $Y=X_1+X_2$。
2. **二项分布可加性漏条件**：误以为任意两随机变量和服从二项 → 正确做法：二项分布可加性要求独立同分布（或独立同参数），$X_1,X_2$ 独立同 $B(1,p)$ 才有 $X_1+X_2\sim B(2,p)$。
3. **单点概率组合数漏**：误写 $P(Y=1)=p(1-p)$ 漏去 $\dbinom{2}{1}=2$ → 正确做法：$P(B(2,p)=1)=\dbinom{2}{1}p(1-p)=2p(1-p)$，包含两种排列。
:::

:::callout{kind=note label="知识卡片：两点分布与二项分布"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 恒等式 | $\max(a,b)+\min(a,b)=a+b$ | 任意两实数 |
| $B(1,p)$ 卷积 | $X_1+X_2\sim B(2,p)$ | $X_i$ 独立同 $B(1,p)$ |
| 二项可加性 | $\sum_{i=1}^n X_i\sim B(n,p)$ | $X_i$ 独立同 $B(1,p)$ |
| 单点概率 | $P(B(n,p)=k)=\dbinom{n}{k}p^k(1-p)^{n-k}$ | $k=0,1,\ldots,n$ |
| 排列解释 | $P(Y=1)=2p(1-p)$ 含两种排列 | 一次成功一次失败 |

**概念辨析**：
- 二项分布可加性要求"独立 + 同参数"，独立但参数不同时和仍服从泊松二项分布而非二项。
- $\max+\min=$ 和 恒等式对任意两实数成立，是简化 $\max$、$\min$ 复合表达式的通用工具。
:::

:::callout{kind=tip label="结论速记"}
$\max+\min=$ 和，$Y=X_1+X_2\sim B(2,p)$，$P(Y=1)=2p(1-p)$。

**口诀**：极大极小和为加，二项单点含组合。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$\max+\min$ 复合表达式"→ 联想"恒等式 $\max+\min=$ 和，化简为求和"
- **关联考点**：两点分布与二项分布（第三章）、二项可加性、$\max$/$\min$ 运算
- **复用场景**：任何含 $\max$、$\min$ 的随机变量表达式，先用恒等式化简再求分布
:::

### 第13题

:::callout{kind=note label="题目"}
设 $X \sim N(1, 2^2)$，$P(Y=-2) = p$，$P(Y=2) = 1-p$，且 $X, Y$ 独立，则 $\dfrac{X-1}{Y} \sim$ ____。
:::

:::callout{kind=insight label="解析"}
**【答案】$N(0, 1)$**

**思路**：题干给出 $X\sim N(1,4)$ 与 $Y$ 取 $\pm 2$ 的两点分布，$X,Y$ 独立，要求 $\dfrac{X-1}{Y}$ 的分布。入口是先用 $Y$ 的取值分类讨论条件分布，再利用正态对称性判定混合分布。

**为何用此公式**：$X,Y$ 独立时条件分布 $\dfrac{X-1}{Y}\mid Y=y$ 等于 $\dfrac{X-1}{y}$；标准正态变量取相反号仍为 $N(0,1)$（对称性）；若条件分布与分类变量取值无关，则边缘分布同此。

**推导过程**：

1. 第一步：标准化 $X$ ← 依据：$X\sim N(1,4)\Rightarrow \dfrac{X-1}{2}\sim N(0,1)$
   $$Z=\frac{X-1}{2}\sim N(0,1)$$
2. 第二步：按 $Y$ 取值分类 ← 依据：$X,Y$ 独立，条件分布 $\dfrac{X-1}{Y}\mid Y=y=\dfrac{X-1}{y}$
   - 当 $Y=2$ 时：$\dfrac{X-1}{Y}=\dfrac{X-1}{2}=Z\sim N(0,1)$
   - 当 $Y=-2$ 时：$\dfrac{X-1}{Y}=\dfrac{X-1}{-2}=-Z$，由正态对称性 $-Z\sim N(0,1)$
3. 第三步：判定混合分布 ← 依据：两种情形条件分布均为 $N(0,1)$，与 $Y$ 取值无关
   - 无论 $Y=\pm 2$，$\dfrac{X-1}{Y}\mid Y\sim N(0,1)$，故边缘分布仍为 $N(0,1)$。
4. 第四步：验证独立性条件 ← 依据：$X,Y$ 独立保证条件分布可直接代入
   $$\frac{X-1}{Y}\sim N(0,1)$$

**关键步骤说明**：

- 关键在于两种条件分布相同（均为 $N(0,1)$），故混合权重 $p$ 与 $1-p$ 不影响边缘分布。
- 正态对称性 $-Z\sim N(0,1)$ 是核心，使 $Y=-2$ 的条件分布与 $Y=2$ 时一致。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **忽略独立性直接相除**：误以为 $\dfrac{X-1}{Y}$ 可直接对分布相除 → 正确做法：$X,Y$ 独立时用条件分布分类讨论，$\dfrac{X-1}{Y}\mid Y=y=\dfrac{X-1}{y}$。
2. **正态对称性漏用**：误以为 $-Z$ 服从 $N(0,-1)$ 或其他分布 → 正确做法：$Z\sim N(0,1)$ 时 $-Z\sim N(0,1)$（标准正态关于原点对称），方差为 $(-1)^2\cdot 1=1$。
3. **混合分布权重误算**：误以为最终分布含 $p$ → 正确做法：两种条件分布相同（均 $N(0,1)$），混合权重 $p(1-p)$ 不影响结果，边缘分布仍为 $N(0,1)$。
:::

:::callout{kind=note label="知识卡片：正态变量的对称性"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 标准化 | $X\sim N(\mu,\sigma^2)\Rightarrow \dfrac{X-\mu}{\sigma}\sim N(0,1)$ | 任意正态 |
| 对称性 | $Z\sim N(0,1)\Rightarrow -Z\sim N(0,1)$ | 标准正态 |
| 线性变换 | $aZ+b\sim N(b,\ a^2)$ | $Z\sim N(0,1)$ |
| 混合不变 | 条件分布与分类变量取值无关 $\Rightarrow$ 边缘同此 | 条件分布恒定 |
| 独立性 | $X,Y$ 独立保证条件分布可代入 | 独立假设 |

**概念辨析**：
- 正态分布的对称性 $-Z\sim N(0,1)$ 是标准正态的特有性质（密度关于原点对称）；非零均值正态 $-X\sim N(-\mu,\sigma^2)\neq X$ 的分布。
- "条件分布与分类变量无关 $\Rightarrow$ 边缘同此"是混合分布的特殊情形，要求两种条件分布完全相同。
:::

:::callout{kind=tip label="结论速记"}
$\dfrac{X-1}{2}\sim N(0,1)$，除以 $\pm 2$ 仍是 $N(0,1)$，故 $\dfrac{X-1}{Y}\sim N(0,1)$。

**口诀**：标准正态对称取反不变，分类同分布权重不显。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"随机变量除以取 $\pm$ 值的两点分布"→ 联想"分类讨论 + 正态对称性使条件分布相同"
- **关联考点**：正态分布标准化与对称性（第三章）、条件分布、独立性
- **复用场景**：任何"连续变量除以离散 $\pm$ 值变量"的分布判定，统一用分类讨论 + 对称性
:::

### 第14题

:::callout{kind=note label="题目"}
设 $X_1, \ldots, X_{10}$ 独立同分布，$\bar{X}$ 为样本均值。若 $E(X_1 \bar{X}) = 35$，$D(X_1 - \bar{X}) = 90$，则 $E(X^2) =$ ____。
:::

:::callout{kind=insight label="解析"}
**【答案】$125$**

**思路**：题干给出 $E(X_1\bar{X})=35$ 与 $D(X_1-\bar{X})=90$，要求 $E(X^2)$。入口是设 $E(X)=\mu,\ D(X)=\sigma^2$，建立两个方程分别解出 $\sigma^2$ 与 $\mu^2$，再用 $E(X^2)=\sigma^2+\mu^2$ 求解。

**为何用此公式**：$E(X^2)=D(X)+(EX)^2=\sigma^2+\mu^2$ 是核心目标；$E(X_1\bar{X})$ 展开用 $\bar{X}$ 定义与独立性；$D(X_1-\bar{X})$ 用方差和公式与协方差 $\text{Cov}(X_1,\bar{X})=\dfrac{\sigma^2}{n}$。

**推导过程**：

1. 第一步：设参数 ← 依据：$E(X)=\mu,\ D(X)=\sigma^2$，则 $E(X^2)=\sigma^2+\mu^2$
2. 第二步：展开 $X_1\bar{X}$ ← 依据：$\bar{X}=\dfrac{1}{10}\sum_{j=1}^{10}X_j$
   $$X_1\bar{X}=\frac{1}{10}\left(X_1^2+\sum_{j=2}^{10}X_1X_j\right)$$
3. 第三步：求 $E(X_1\bar{X})$ ← 依据：独立同分布 $E(X_1X_j)=\mu^2$（$j\neq 1$），$E(X_1^2)=\sigma^2+\mu^2$
   $$E(X_1\bar{X})=\frac{1}{10}\big(E(X^2)+9\mu^2\big)=\frac{\sigma^2+\mu^2+9\mu^2}{10}=\frac{\sigma^2}{10}+\mu^2$$
4. 第四步：建立方程一 ← 依据：$E(X_1\bar{X})=35$
   $$\frac{\sigma^2}{10}+\mu^2=35\quad\cdots(\star)$$
5. 第五步：计算协方差 ← 依据：$\text{Cov}(X_1,\bar{X})=\dfrac{1}{10}\text{Var}(X_1)=\dfrac{\sigma^2}{10}$，$D(\bar{X})=\dfrac{\sigma^2}{10}$
6. 第六步：求 $D(X_1-\bar{X})$ ← 依据：方差和公式 $D(X-Y)=DX+DY-2\text{Cov}(X,Y)$
   $$D(X_1-\bar{X})=\sigma^2+\frac{\sigma^2}{10}-2\cdot\frac{\sigma^2}{10}=\sigma^2-\frac{\sigma^2}{10}=\frac{9\sigma^2}{10}$$
7. 第七步：建立方程二 ← 依据：$D(X_1-\bar{X})=90$
   $$\frac{9\sigma^2}{10}=90\Rightarrow\sigma^2=100$$
8. 第八步：代入求 $\mu^2$ ← 依据：代入 $(\star)$
   $$\frac{100}{10}+\mu^2=35\Rightarrow\mu^2=25$$
9. 第九步：求 $E(X^2)$ ← 依据：$E(X^2)=\sigma^2+\mu^2$
   $$E(X^2)=100+25=125$$

**关键步骤说明**：

- 关键在于把 $E(X_1\bar{X})$ 拆分为 $X_1^2$ 项（用 $E(X_1^2)=\sigma^2+\mu^2$）与 $X_1X_j$ 项（$j\neq 1$ 用独立性得 $\mu^2$）。
- $D(X_1-\bar{X})$ 的化简依赖 $\text{Cov}(X_1,\bar{X})=\dfrac{\sigma^2}{n}$，因 $\bar{X}$ 含 $X_1$ 故协方差非零。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$E(X_1\bar{X})$ 展开遗漏 $X_1^2$ 项**：误写 $E(X_1\bar{X})=\mu^2$ → 正确做法：$X_1\bar{X}=\dfrac{1}{n}(X_1^2+\sum_{j\neq 1}X_1X_j)$，$X_1^2$ 项期望为 $E(X^2)=\sigma^2+\mu^2$，其余项为 $\mu^2$。
2. **协方差当作零**：误以为 $X_1$ 与 $\bar{X}$ 独立故 $\text{Cov}=0$ → 正确做法：$\bar{X}$ 含 $X_1$，二者不独立，$\text{Cov}(X_1,\bar{X})=\dfrac{\sigma^2}{n}\neq 0$。
3. **方差和公式漏交叉项**：误写 $D(X_1-\bar{X})=DX_1+D\bar{X}$ → 正确做法：$D(X-Y)=DX+DY-2\text{Cov}(X,Y)$，含 $-2\text{Cov}$ 项。
:::

:::callout{kind=note label="知识卡片：样本均值与样本方差的矩关系"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $E(X_1\bar{X})$ | $\dfrac{\sigma^2}{n}+\mu^2$ | i.i.d. 样本 |
| $\text{Cov}(X_1,\bar{X})$ | $\dfrac{\sigma^2}{n}$ | i.i.d. 样本 |
| $D(\bar{X})$ | $\dfrac{\sigma^2}{n}$ | i.i.d. 样本 |
| $D(X_1-\bar{X})$ | $\dfrac{(n-1)\sigma^2}{n}$ | i.i.d. 样本 |
| $E(X^2)$ | $\sigma^2+\mu^2$ | 任意随机变量 |
| 方差和公式 | $D(X\pm Y)=DX+DY\pm 2\text{Cov}(X,Y)$ | 任意两随机变量 |

**概念辨析**：
- $X_1$ 与 $\bar{X}$ 不独立（$\bar{X}$ 含 $X_1$），故 $\text{Cov}(X_1,\bar{X})=\dfrac{\sigma^2}{n}\neq 0$；但任意两个不同样本 $X_i$ 与 $X_j$（$i\neq j$）独立。
- $D(X_1-\bar{X})=\dfrac{(n-1)\sigma^2}{n}$ 反映 $X_1$ 与 $\bar{X}$ 的"重叠"使方差小于 $\sigma^2$。
:::

:::callout{kind=tip label="结论速记"}
$D(X_1-\bar{X})=\dfrac{(n-1)\sigma^2}{n}\Rightarrow\sigma^2$；$E(X_1\bar{X})=\dfrac{\sigma^2}{n}+\mu^2\Rightarrow\mu^2$；二者相加得 $E(X^2)$。

**口诀**：方差和反解 $\sigma^2$，均值积反解 $\mu^2$，相加得二阶矩。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"$E(X_1\bar{X})$ 与 $D(X_1-\bar{X})$ 反求 $E(X^2)$"→ 联想"$\bar{X}$ 含 $X_1$ 故协方差非零，建立双方程解 $\sigma^2,\mu^2$"
- **关联考点**：样本均值数字特征（第六章）、协方差与方差和公式、二阶矩分解
- **复用场景**：任何由样本均值/方差矩反解总体矩的题目，统一用 $\text{Cov}(X_1,\bar{X})=\dfrac{\sigma^2}{n}$ 处理
:::

### 第15题

:::callout{kind=note label="题目"}
（12 分）有两批数量相同的产品，其中第一批全部合格，第二批有 25% 不合格。从两批中任取一件，求取到合格品的概率；若取得合格品后放回原处，再从其所在批次中任取一件，求取到不合格品的概率。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：题干是经典的两批产品抽取问题。第一问求取到合格品的概率，入口是识别"完备事件组 + 全概率公式"；第二问求已知合格后放回再取不合格的概率，入口是"贝叶斯公式求后验 + 全概率公式求第二次"。

**为何用此公式**：两批产品构成完备事件组 $\{A_1,A_2\}$，第一问直接用全概率公式 $P(G)=\sum P(A_i)P(G\mid A_i)$；第二问需先用贝叶斯公式求合格品来自第二批的后验概率 $P(A_2\mid G)$，再用全概率公式求第二次不合格的概率。

**推导过程**：

设 $A_i$ 表示取到第 $i$ 批产品（$i=1,2$），$G$ 表示取到合格品。由题意 $P(A_1)=P(A_2)=\dfrac{1}{2}$，$P(G\mid A_1)=1$，$P(G\mid A_2)=\dfrac{3}{4}$。

**第一问：取到合格品的概率**

1. 第一步：识别完备事件组 ← 依据：$\{A_1,A_2\}$ 互斥且并为必然事件
2. 第二步：套全概率公式 ← 依据：$P(G)=\sum_i P(A_i)P(G\mid A_i)$
   $$P(G)=P(A_1)P(G\mid A_1)+P(A_2)P(G\mid A_2)=\frac{1}{2}\cdot 1+\frac{1}{2}\cdot\frac{3}{4}$$
3. 第三步：计算 ← 依据：分数运算
   $$P(G)=\frac{1}{2}+\frac{3}{8}=\frac{4}{8}+\frac{3}{8}=\frac{7}{8}$$

**第二问：取得合格品后放回，再从同批取一件为不合格品的概率**

1. 第一步：用贝叶斯公式求后验 ← 依据：$P(A_2\mid G)=\dfrac{P(A_2)P(G\mid A_2)}{P(G)}$
   $$P(A_2\mid G)=\frac{\frac{1}{2}\cdot\frac{3}{4}}{\frac{7}{8}}=\frac{\frac{3}{8}}{\frac{7}{8}}=\frac{3}{7}$$
2. 第二步：求 $P(A_1\mid G)$ ← 依据：$P(A_1\mid G)=1-P(A_2\mid G)$
   $$P(A_1\mid G)=1-\frac{3}{7}=\frac{4}{7}$$
3. 第三步：分析第二次抽取 ← 依据：放回后从同批再取，第一批 $P(\bar{G}\mid A_1)=0$，第二批 $P(\bar{G}\mid A_2)=\dfrac{1}{4}$
4. 第四步：用全概率公式求第二次不合格 ← 依据：$P(\bar{G}_2)=\sum_i P(A_i\mid G)P(\bar{G}\mid A_i)$
   $$P(\text{第二次不合格})=P(A_1\mid G)\cdot 0+P(A_2\mid G)\cdot\frac{1}{4}=\frac{3}{7}\cdot\frac{1}{4}=\frac{3}{28}$$

**关键步骤说明**：

- 第一问关键是识别完备事件组 $\{A_1,A_2\}$，两批各以 $\frac{1}{2}$ 概率被选中。
- 第二问关键是"放回"意味着第二次仍从同批抽取，故用后验 $P(A_i\mid G)$ 作为第二次选批的权重；第一批全合格故贡献为 $0$，只有第二批贡献 $\dfrac{3}{7}\cdot\dfrac{1}{4}$。

**答**：取到合格品的概率为 $\dfrac{7}{8}$；取得合格品后放回再取一件为不合格品的概率为 $\dfrac{3}{28}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **后验与先验混淆**：第二次抽取仍用先验 $P(A_2)=\frac{1}{2}$ → 正确做法：已知第一次为合格品后，批次后验更新为 $P(A_2\mid G)=\frac{3}{7}$，第二次应用后验权重。
2. **"放回"语义误读**：误以为放回后重新随机选批 → 正确做法："放回原处，再从其所在批次中任取一件"指从同一批次再取，批次已由第一次确定（用后验表示不确定性）。
3. **第一批不合格率错算**：误以为第一批也有不合格品 → 正确做法：题干明确"第一批全部合格"，$P(\bar{G}\mid A_1)=0$，对第二次不合格概率无贡献。
:::

:::callout{kind=note label="知识卡片：全概率公式与贝叶斯公式"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 全概率公式 | $P(B)=\sum_i P(A_i)P(B\mid A_i)$ | $\{A_i\}$ 为完备事件组 |
| 贝叶斯公式 | $P(A_i\mid B)=\dfrac{P(A_i)P(B\mid A_i)}{P(B)}$ | 同上，$P(B)>0$ |
| 后验更新 | 先验 $P(A_i)$ $\to$ 后验 $P(A_i\mid B)$ | 观测到 $B$ 后 |
| 完备事件组 | 互斥且并为必然事件 | $\bigcup A_i=\Omega,\ A_iA_j=\varnothing$ |
| 两批模型 | $P(A_1)=P(A_2)=\dfrac{1}{2}$，合格率 $1$ 与 $\dfrac{3}{4}$ | 题设给定 |

**概念辨析**：
- 全概率公式"由因推果"（已知各原因概率求结果），贝叶斯公式"由果推因"（已知结果求原因后验），二者方向相反。
- "放回"与"不放回"的区别：放回指同一批次内独立再抽（批次不变），不放回指同一批次内抽取改变该批组成。
:::

:::callout{kind=tip label="结论速记"}
全概率 $P(G)=\dfrac{7}{8}$；贝叶斯 $P(A_2\mid G)=\dfrac{3}{7}$；放回再取不合格 $=\dfrac{3}{7}\cdot\dfrac{1}{4}=\dfrac{3}{28}$。

**口诀**：全概率由因推果，贝叶斯由果推因，放回同批用后验。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"两批产品 + 已知结果求第二次概率"→ 联想"贝叶斯求后验 + 全概率求第二次"
- **关联考点**：全概率公式与贝叶斯公式（第一章）、完备事件组、后验更新
- **复用场景**：任何"多源混合 + 观测后反推来源 + 再预测"的题目，如医学检测、质量控制、信号检测
:::

### 第16题

:::callout{kind=note label="题目"}
（12 分）在人群中，用 $Y$ 表示性别指标（0 表示男性，1 表示女性），用 $X$ 表示色盲指标（0 表示无色盲，1 表示有色盲）。联合分布为

| $X \backslash Y$ | 0 | 1 |
|------|------|------|
| 0 | $\dfrac{3}{8}$ | $\dfrac{15}{32}$ |
| 1 | $\dfrac{1}{8}$ | $\dfrac{1}{32}$ |

求 $P(Y=0 \mid X=1)$ 和相关系数 $\rho_{XY}$。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：题干给出二维 0-1 指标变量 $(X,Y)$ 的联合分布表，要求条件概率与相关系数。入口是第一问用条件概率定义 $P(Y=0\mid X=1)=\dfrac{P(X=1,Y=0)}{P(X=1)}$；第二问用相关系数公式 $\rho_{XY}=\dfrac{\text{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}$，需先求各阶矩。

**为何用此公式**：0-1 指标变量有简化性质 $E(X^2)=E(X)$（因 $X^2=X$）；协方差 $\text{Cov}(X,Y)=E(XY)-E(X)E(Y)$；相关系数定义 $\rho=\dfrac{\text{Cov}}{\sqrt{DX\cdot DY}}$。

**推导过程**：

**第一问：条件概率 $P(Y=0\mid X=1)$**

1. 第一步：求 $P(X=1)$ ← 依据：边缘分布 $P(X=1)=\sum_j P(X=1,Y=j)$
   $$P(X=1)=P(X=1,Y=0)+P(X=1,Y=1)=\frac{1}{8}+\frac{1}{32}=\frac{4}{32}+\frac{1}{32}=\frac{5}{32}$$
2. 第二步：代入条件概率 ← 依据：$P(Y=0\mid X=1)=\dfrac{P(X=1,Y=0)}{P(X=1)}$
   $$P(Y=0\mid X=1)=\frac{\frac{1}{8}}{\frac{5}{32}}=\frac{\frac{4}{32}}{\frac{5}{32}}=\frac{4}{5}$$

**第二问：相关系数 $\rho_{XY}$**

1. 第一步：求 $E(X)$ ← 依据：0-1 变量 $E(X)=1\cdot P(X=1)$
   $$E(X)=P(X=1)=\frac{5}{32}$$
2. 第二步：求 $E(Y)$ ← 依据：$E(Y)=1\cdot P(Y=1)$，$P(Y=1)=\dfrac{15}{32}+\dfrac{1}{32}=\dfrac{16}{32}=\dfrac{1}{2}$
   $$E(Y)=\frac{1}{2}$$
3. 第三步：求 $E(XY)$ ← 依据：0-1 变量 $E(XY)=1\cdot P(X=1,Y=1)$
   $$E(XY)=P(X=1,Y=1)=\frac{1}{32}$$
4. 第四步：求协方差 ← 依据：$\text{Cov}(X,Y)=E(XY)-E(X)E(Y)$
   $$\text{Cov}(X,Y)=\frac{1}{32}-\frac{5}{32}\cdot\frac{1}{2}=\frac{1}{32}-\frac{5}{64}=\frac{2-5}{64}=-\frac{3}{64}$$
5. 第五步：求 $E(X^2),E(Y^2)$ ← 依据：0-1 变量 $X^2=X,\ Y^2=Y$，故 $E(X^2)=E(X),\ E(Y^2)=E(Y)$
   $$E(X^2)=\frac{5}{32},\qquad E(Y^2)=\frac{1}{2}$$
6. 第六步：求方差 ← 依据：$D(X)=E(X^2)-(EX)^2$
   $$D(X)=\frac{5}{32}-\left(\frac{5}{32}\right)^2=\frac{5}{32}\cdot\frac{27}{32}=\frac{135}{1024}$$
   $$D(Y)=\frac{1}{2}-\frac{1}{4}=\frac{1}{4}$$
7. 第七步：求相关系数 ← 依据：$\rho_{XY}=\dfrac{\text{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}$
   $$\rho_{XY}=\frac{-\frac{3}{64}}{\sqrt{\frac{135}{1024}\cdot\frac{1}{4}}}=\frac{-\frac{3}{64}}{\sqrt{\frac{135}{4096}}}=\frac{-\frac{3}{64}}{\frac{\sqrt{135}}{64}}=\frac{-3}{\sqrt{135}}=\frac{-3}{3\sqrt{15}}=-\frac{1}{\sqrt{15}}$$

**关键步骤说明**：

- 0-1 指标变量的简化：$X^2=X$ 故 $E(X^2)=E(X)$，省去高阶矩计算。
- 协方差为负 $\text{Cov}=-\frac{3}{64}$ 说明色盲与女性负相关（本题中色盲多见于男性）。
- 相关系数化简 $\sqrt{135}=3\sqrt{15}$ 是关键技巧。

**答**：$P(Y=0 \mid X=1) = \dfrac{4}{5}$，$\rho_{XY} = -\dfrac{1}{\sqrt{15}}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **0-1 变量二阶矩未简化**：误以为 $E(X^2)$ 需另行展开 → 正确做法：0-1 变量 $X^2=X$，故 $E(X^2)=E(X)$，方差 $D(X)=E(X)(1-E(X))$。
2. **边缘概率漏加项**：误算 $P(X=1)=\dfrac{1}{8}$ 漏去 $P(X=1,Y=1)$ → 正确做法：边缘 $P(X=1)=P(X=1,Y=0)+P(X=1,Y=1)=\dfrac{1}{8}+\dfrac{1}{32}=\dfrac{5}{32}$。
3. **相关系数化简出错**：$\sqrt{135}$ 未分解为 $3\sqrt{15}$ → 正确做法：$135=9\times 15$，$\sqrt{135}=3\sqrt{15}$，故 $\dfrac{-3}{\sqrt{135}}=-\dfrac{1}{\sqrt{15}}$。
4. **协方差符号错**：误算 $\text{Cov}$ 为正 → 正确做法：$E(XY)=\dfrac{1}{32}$ 小于 $E(X)E(Y)=\dfrac{5}{64}$，协方差为负。
:::

:::callout{kind=note label="知识卡片：二维离散型随机变量的数字特征"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 边缘分布 | $P(X=i)=\sum_j P(X=i,Y=j)$ | 任意离散型 |
| 条件概率 | $P(Y=j\mid X=i)=\dfrac{P(X=i,Y=j)}{P(X=i)}$ | $P(X=i)>0$ |
| 0-1 变量二阶矩 | $E(X^2)=E(X)$（因 $X^2=X$） | $X$ 取 0 或 1 |
| 协方差 | $\text{Cov}(X,Y)=E(XY)-E(X)E(Y)$ | 任意有二阶矩 |
| 相关系数 | $\rho_{XY}=\dfrac{\text{Cov}(X,Y)}{\sqrt{D(X)D(Y)}}$ | $D(X),D(Y)>0$ |
| 0-1 变量方差 | $D(X)=E(X)(1-E(X))$ | $X$ 取 0 或 1 |

**概念辨析**：
- 0-1 指标变量 $X^2=X$ 是核心简化，使二阶矩等同于一阶矩，方差 $D(X)=E(X)(1-E(X))$（伯努利方差 $p(1-p)$）。
- 协方差符号反映相关性方向：正协方差正相关，负协方差负相关；本题 $\text{Cov}<0$ 说明色盲与女性负相关。
:::

:::callout{kind=tip label="结论速记"}
0-1 指标变量：$E(X^2)=E(X)$；先求 $E(X),E(Y),E(XY)$，得 $\text{Cov}$ 再除以 $\sqrt{D(X)D(Y)}$。

**口诀**：0-1 二阶等一阶，协方差除根号方差。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"0-1 指标变量 + 联合分布表求相关系数"→ 联想"$X^2=X$ 简化二阶矩，$E(XY)=P(X=1,Y=1)$"
- **关联考点**：二维离散型分布（第四章）、协方差与相关系数、0-1 变量性质
- **复用场景**：任何 0-1 指标变量的数字特征计算，如分类数据相关性分析、列联表分析
:::

### 第17题

:::callout{kind=note label="题目"}
（12 分）设二维连续型随机向量 $(X, Y)$ 的联合密度为

$$f(x, y) = \frac{1}{2\pi}\exp\!\left(-\frac{x^2 + (y-x)^2}{2}\right)$$

求 $f_X(x), f_Y(y)$；判断 $X, Y$ 是否独立；求 $Z = X+Y$ 的密度。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：题干给出二维正态型联合密度，指数含 $x^2+(y-x)^2$。入口是令 $U=X,\ V=Y-X$ 做线性变换使二次型对角化，分离出独立标准正态；再由 $Y=X+V$ 求 $f_Y$；用协方差判定独立性；用正态可加性求 $Z=X+Y$ 的分布。

**为何用此公式**：线性变换 $U=X,\ V=Y-X$ 的雅可比 $|J|=1$，使指数 $x^2+(y-x)^2=U^2+V^2$ 可分离，密度分解为两个独立 $N(0,1)$ 的乘积；正态变量不相关等价于独立；独立正态和仍正态，方差相加。

**推导过程**：

**第一步：变量替换识别独立结构**

1. 第一步：令 $U=X,\ V=Y-X$ ← 依据：使二次型 $x^2+(y-x)^2$ 对角化
   - 反变换 $X=U,\ Y=U+V$，雅可比行列式 $\left|\dfrac{\partial(x,y)}{\partial(u,v)}\right|=\begin{vmatrix}1&0\\1&1\end{vmatrix}=1$
2. 第二步：代入指数 ← 依据：$x^2+(y-x)^2=U^2+V^2$
   $$f_{U,V}(u,v)=\frac{1}{2\pi}e^{-(u^2+v^2)/2}=\frac{1}{\sqrt{2\pi}}e^{-u^2/2}\cdot\frac{1}{\sqrt{2\pi}}e^{-v^2/2}$$
3. 第三步：判定独立性 ← 依据：密度可分离为 $g(u)h(v)$ 形式
   - $U\sim N(0,1),\ V\sim N(0,1)$ 且 $U,V$ 独立。

**第二步：求 $f_X(x)$ 与 $f_Y(y)$**

1. 第一步：求 $f_X$ ← 依据：$X=U$，故 $f_X(x)=f_U(x)$
   $$f_X(x)=\frac{1}{\sqrt{2\pi}}e^{-x^2/2}$$
2. 第二步：求 $f_Y$ ← 依据：$Y=U+V=X+V$，$U,V$ 独立正态，可加性 $Y\sim N(0,1+1)=N(0,2)$
   $$f_Y(y)=\frac{1}{\sqrt{2\pi\cdot 2}}e^{-y^2/(2\cdot 2)}=\frac{1}{\sqrt{4\pi}}e^{-y^2/4}$$

**第三步：判断独立性**

1. 第一步：计算协方差 ← 依据：$\text{Cov}(X,Y)=\text{Cov}(U,U+V)=\text{Cov}(U,U)+\text{Cov}(U,V)$
   $$\text{Cov}(X,Y)=D(U)+0=1\neq 0$$
2. 第二步：判定 ← 依据：二维正态下协方差非零 $\Rightarrow$ 不独立（正态情形"不相关 $\Leftrightarrow$ 独立"）
   - $X,Y$ 不独立。

**第四步：求 $Z=X+Y$ 的密度**

1. 第一步：用 $U,V$ 表示 $Z$ ← 依据：$Z=X+Y=U+(U+V)=2U+V$
2. 第二步：判定分布 ← 依据：$U,V$ 独立正态，$Z=2U+V\sim N(2\cdot 0+0,\ 2^2\cdot 1+1)=N(0,5)$
   $$f_Z(z)=\frac{1}{\sqrt{2\pi\cdot 5}}e^{-z^2/(2\cdot 5)}=\frac{1}{\sqrt{10\pi}}e^{-z^2/10}$$

**关键步骤说明**：

- 关键是变量替换 $V=Y-X$ 使二次型对角化，把 $f(x,y)$ 分离为两个独立 $N(0,1)$ 的乘积。
- 独立性判定用协方差：$\text{Cov}(X,Y)=\text{Cov}(U,U+V)=1\neq 0$，二维正态下即不独立。
- $Z=X+Y=2U+V$ 用独立正态可加性得 $N(0,4+1)=N(0,5)$。

**答**：

$$f_X(x) = \frac{1}{\sqrt{2\pi}}e^{-x^2/2},\qquad f_Y(y) = \frac{1}{\sqrt{4\pi}}e^{-y^2/4}$$

$X, Y$ 不独立；$Z = X+Y \sim N(0, 5)$，$f_Z(z) = \dfrac{1}{\sqrt{10\pi}}e^{-z^2/10}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **直接对 $f(x,y)$ 积分求边缘**：硬算 $\int f(x,y)dy$ 导致计算复杂 → 正确做法：先做线性变换 $U=X,\ V=Y-X$ 使密度可分离，再读出 $U,V$ 的边缘。
2. **独立性误判**：误以为 $f(x,y)$ 可因式分解为 $f_X\cdot f_Y$ 故独立 → 正确做法：$f_X(x)f_Y(y)=\dfrac{1}{\sqrt{2\pi}\cdot\sqrt{4\pi}}e^{-x^2/2-y^2/4}$ 与 $f(x,y)=\dfrac{1}{2\pi}e^{-(x^2+(y-x)^2)/2}$ 不相等（指数项不同），故不独立；用协方差判定更便捷。
3. **$Z$ 方差计算漏交叉项**：误算 $D(Z)=D(X)+D(Y)$ 漏去 $2\text{Cov}(X,Y)$ → 正确做法：$X,Y$ 不独立，$D(X+Y)=D(X)+D(Y)+2\text{Cov}(X,Y)=1+2+2\cdot 1=5$；或用 $Z=2U+V$ 由独立正态可加性得 $D=4+1=5$。
4. **雅可比行列式算错**：误认为 $|J|\neq 1$ → 正确做法：$X=U,\ Y=U+V$ 的雅可比 $\begin{vmatrix}1&0\\1&1\end{vmatrix}=1$，密度无需调整。
:::

:::callout{kind=note label="知识卡片：二维正态与变量分解"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 线性变换分离 | 令 $U=X,\ V=Y-X$ 使指数二次型对角化 | 二次型可对角化 |
| 密度可分 | $f(x,y)=g(u)h(v)\Leftrightarrow U,V$ 独立 | 变换后密度因式分解 |
| 雅可比 | $\left|\dfrac{\partial(x,y)}{\partial(u,v)}\right|=1$ | $X=U,\ Y=U+V$ |
| 协方差判定 | $\text{Cov}(X,Y)\neq 0\Rightarrow$ 不独立 | 二维正态下"不相关 $\Leftrightarrow$ 独立" |
| 正态可加性 | 独立正态和仍正态，方差相加 | $U,V$ 独立正态 |
| 线性组合分布 | $aU+bV\sim N(a\mu_U+b\mu_V,\ a^2\sigma_U^2+b^2\sigma_V^2)$ | $U,V$ 独立正态 |

**概念辨析**：
- "二维正态下不相关 $\Leftrightarrow$ 独立"是特有性质，一般分布下"独立 $\Rightarrow$ 不相关"但逆不真；本题 $(X,Y)$ 是二维正态（$U,V$ 独立正态的线性变换），故可用协方差判定独立性。
- $D(X+Y)=D(X)+D(Y)+2\text{Cov}(X,Y)$ 适用于任意两随机变量；独立时交叉项为零退化为可加性。
:::

:::callout{kind=tip label="结论速记"}
令 $V=Y-X$ 把 $f(x,y)$ 分解为两个独立 $N(0,1)$；$Y=X+V\sim N(0,2)$，$\text{Cov}(X,Y)=1\neq 0$ 不独立；$Z=2X+V\sim N(0,5)$。

**口诀**：线性变换对角化，独立正态和相加，协差非零不独立。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"二维正态型密度含 $x^2+(y-x)^2$"→ 联想"令 $V=Y-X$ 对角化分离为独立正态"
- **关联考点**：二维正态分布（第四章）、线性变换与雅可比、协方差与独立性、正态可加性
- **复用场景**：任何二维正态型密度的处理，统一用线性变换对角化分离独立分量
:::

### 第18题

:::callout{kind=note label="题目"}
（10 分）设 $X_1, \ldots, X_n$ 来自 $N(0, \sigma^2)$，$\bar{X}, S^2$ 分别为样本均值和样本方差。求 $\bar{X}$ 与 $\dfrac{(n-1)S^2}{\sigma^2}$ 的分布并说明独立性；证明 $X_1+X_2$ 与 $|X_1-X_2|$ 独立，且 $\dfrac{X_1+X_2}{|X_1-X_2|} \sim t(1)$。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：题干分两部分。第一部分求 $\bar{X}$ 与 $\dfrac{(n-1)S^2}{\sigma^2}$ 的分布与独立性，入口是正态总体抽样分布三大定理。第二部分证明 $X_1+X_2$ 与 $|X_1-X_2|$ 独立及 $t(1)$ 分布，入口是构造正交变换 $U=\dfrac{X_1+X_2}{\sqrt{2\sigma^2}},\ V=\dfrac{X_1-X_2}{\sqrt{2\sigma^2}}$。

**为何用此公式**：正态总体抽样分布定理给出 $\bar{X}\sim N(\mu,\sigma^2/n)$、$\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$、$\bar{X}\perp S^2$；正交变换保持正态性与独立性（旋转后协方差为零即独立）；$t$ 分布定义 $\dfrac{N(0,1)}{\sqrt{\chi^2(1)/1}}\sim t(1)$。

**推导过程**：

**第一部分：$\bar{X}$ 与 $\dfrac{(n-1)S^2}{\sigma^2}$ 的分布与独立性**

1. 第一步：求 $\bar{X}$ 的分布 ← 依据：正态总体样本均值 $\bar{X}\sim N\!\left(\mu,\dfrac{\sigma^2}{n}\right)$，本题 $\mu=0$
   $$\bar{X}\sim N\!\left(0,\frac{\sigma^2}{n}\right)$$
2. 第二步：求 $\dfrac{(n-1)S^2}{\sigma^2}$ 的分布 ← 依据：正态总体样本方差 $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$
   $$\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$$
3. 第三步：说明独立性 ← 依据：正态样本的样本均值与样本方差独立性定理（可用正交变换证明）
   - $\bar{X}$ 与 $S^2$ 相互独立，故 $\bar{X}$ 与 $\dfrac{(n-1)S^2}{\sigma^2}$ 独立。

**第二部分：证明 $X_1+X_2$ 与 $|X_1-X_2|$ 独立，且 $\dfrac{X_1+X_2}{|X_1-X_2|} \sim t(1)$**

1. 第一步：构造正交变换 ← 依据：令 $U=\dfrac{X_1+X_2}{\sqrt{2\sigma^2}},\ V=\dfrac{X_1-X_2}{\sqrt{2\sigma^2}}$（旋转 $45°$ 加伸缩）
2. 第二步：求 $U,V$ 的分布 ← 依据：正态变量的线性组合仍正态
   $$U\sim N(0,1),\quad V\sim N(0,1)$$
   - $E(U)=\dfrac{0+0}{\sqrt{2\sigma^2}}=0$，$D(U)=\dfrac{D(X_1)+D(X_2)+2\text{Cov}(X_1,X_2)}{2\sigma^2}=\dfrac{\sigma^2+\sigma^2+0}{2\sigma^2}=1$
3. 第三步：求协方差 ← 依据：$\text{Cov}(U,V)=\dfrac{1}{2\sigma^2}\text{Cov}(X_1+X_2,\ X_1-X_2)$
   $$\text{Cov}(X_1+X_2,\ X_1-X_2)=D(X_1)-D(X_2)=\sigma^2-\sigma^2=0$$
   $$\text{Cov}(U,V)=0$$
4. 第四步：判定独立性 ← 依据：正态变量不相关 $\Leftrightarrow$ 独立
   - $U,V$ 独立。
5. 第五步：转化原变量 ← 依据：$X_1+X_2=\sqrt{2\sigma^2}\,U$，$X_1-X_2=\sqrt{2\sigma^2}\,V$
   - $X_1+X_2$ 与 $X_1-X_2$ 独立（$U,V$ 独立的线性函数仍独立）。
   - 进一步 $X_1+X_2$ 与 $|X_1-X_2|=\sqrt{2\sigma^2}\,|V|$ 独立（$|V|$ 是 $V$ 的函数）。
6. 第六步：构造 $t$ 统计量 ← 依据：$\dfrac{X_1+X_2}{|X_1-X_2|}=\dfrac{\sqrt{2\sigma^2}\,U}{\sqrt{2\sigma^2}\,|V|}=\dfrac{U}{|V|}$
   - $V\sim N(0,1)\Rightarrow V^2\sim\chi^2(1)$，$|V|=\sqrt{V^2}=\sqrt{\chi^2(1)}$
   - $U$ 与 $V^2$ 独立（$U$ 与 $V$ 独立 $\Rightarrow$ $U$ 与 $V$ 的函数 $V^2$ 独立）
7. 第七步：套 $t$ 分布定义 ← 依据：$\dfrac{N(0,1)}{\sqrt{\chi^2(k)/k}}\sim t(k)$，此处 $k=1$
   $$\frac{U}{|V|}=\frac{U}{\sqrt{V^2}}=\frac{U}{\sqrt{\chi^2(1)/1}}\sim t(1)$$

**关键步骤说明**：

- 关键是构造正交变换 $U=\dfrac{X_1+X_2}{\sqrt{2\sigma^2}},\ V=\dfrac{X_1-X_2}{\sqrt{2\sigma^2}}$，使 $U,V$ 成为独立标准正态。
- $\text{Cov}(X_1+X_2,\ X_1-X_2)=D(X_1)-D(X_2)=0$ 是核心计算，依赖 $X_1,X_2$ 同方差。
- $|V|=\sqrt{V^2}=\sqrt{\chi^2(1)}$ 把绝对值转化为 $\chi^2$ 的根号，套用 $t(1)$ 定义。

**答**：$\bar{X} \sim N\!\left(0, \dfrac{\sigma^2}{n}\right)$，$\dfrac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$，二者独立；$X_1+X_2$ 与 $|X_1-X_2|$ 独立，且 $\dfrac{X_1+X_2}{|X_1-X_2|} \sim t(1)$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **正交变换构造错误**：未除以 $\sqrt{2\sigma^2}$ 导致 $U,V$ 方差非 1 → 正确做法：$U=\dfrac{X_1+X_2}{\sqrt{2\sigma^2}}$ 中分母 $\sqrt{2\sigma^2}$ 抵消分子方差 $D(X_1+X_2)=2\sigma^2$，使 $D(U)=1$。
2. **协方差计算错**：误算 $\text{Cov}(X_1+X_2,\ X_1-X_2)\neq 0$ → 正确做法：$\text{Cov}(X_1+X_2,\ X_1-X_2)=D(X_1)-D(X_2)=\sigma^2-\sigma^2=0$，依赖 $X_1,X_2$ 同方差。
3. **$|V|$ 与 $\chi^2$ 关系错**：误以为 $|V|\sim\chi(1)$（卡方分布的根号） → 正确做法：$V^2\sim\chi^2(1)$，$|V|=\sqrt{V^2}$，故 $\dfrac{U}{|V|}=\dfrac{U}{\sqrt{V^2}}=\dfrac{U}{\sqrt{\chi^2(1)/1}}\sim t(1)$。
4. **独立性传递错误**：误以为 $U$ 与 $|V|$ 不独立 → 正确做法：$U,V$ 独立 $\Rightarrow$ $U$ 与 $V$ 的任何函数（含 $|V|$、$V^2$）独立。
:::

:::callout{kind=note label="知识卡片：正态样本抽样分布三大定理"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| 样本均值分布 | $\bar{X}\sim N\!\left(\mu,\dfrac{\sigma^2}{n}\right)$ | $X_i\sim N(\mu,\sigma^2)$ i.i.d. |
| 样本方差分布 | $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ | 同上 |
| 均值与方差独立 | $\bar{X}\perp S^2$ | 正态总体 |
| 正交变换 | 二维正态经正交变换后分量仍独立正态 | 变换矩阵正交 |
| t 分布构造 | $\dfrac{N(0,1)}{\sqrt{\chi^2(k)/k}}\sim t(k)$ | 分子分母独立，此处 $k=1$ |

**概念辨析**：
- 正交变换保持正态性与独立性：旋转后协方差为零，正态变量不相关即独立。
- $t(1)$ 分布是 $t$ 分布自由度为 1 的特例，其密度比标准正态更厚尾。
:::

:::callout{kind=tip label="结论速记"}
正交变换 $U=\dfrac{X_1+X_2}{\sqrt{2\sigma^2}}$，$V=\dfrac{X_1-X_2}{\sqrt{2\sigma^2}}$ 独立标准正态；$U/|V|\sim t(1)$。

**口诀**：正交变换得独立，$|V|$ 开方套 $t(1)$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"证明 $X_1+X_2$ 与 $|X_1-X_2|$ 独立"→ 联想"正交变换 $U=(X_1+X_2)/\sqrt{2\sigma^2}$，$V=(X_1-X_2)/\sqrt{2\sigma^2}$ 独立标准正态"
- **关联考点**：抽样分布三大定理（第六章）、正交变换与独立性、$t$ 分布定义
- **复用场景**：任何涉及正态样本线性组合独立性与 $t$ 分布构造的证明题
:::

### 第19题

:::callout{kind=note label="题目"}
（12 分）在可列重伯努利试验中，每次成功概率为 $p$，用 $X$ 表示第 2 次成功以前失败的次数。设 $X_1, \ldots, X_n$ 来自总体 $X$，求总体分布列和 $p$ 的极大似然估计。
:::

:::callout{kind=insight label="解析"}
**【解】**

**思路**：题干要求在可列重伯努利试验中，求"第 2 次成功以前失败次数" $X$ 的分布列，并求 $p$ 的 MLE。入口是第一问用负二项分布模型写出 $P(X=k)$；第二问构造似然函数，取对数求导令零解 MLE。

**为何用此公式**：负二项分布 $NB(r,p)$ 描述"第 $r$ 次成功前失败次数"的分布，本题 $r=2$；MLE 标准流程为似然函数 $\to$ 对数似然 $\to$ 求导令零 $\to$ 解方程。

**推导过程**：

**第一步：求总体分布列**

1. 第一步：分析 $X=k$ 的含义 ← 依据：$X=k$ 表示第 2 次成功前恰有 $k$ 次失败
   - 即前 $k+1$ 次试验中恰 1 次成功、$k$ 次失败，且第 $k+2$ 次为成功（使成功总数达 2）。
2. 第二步：写概率 ← 依据：前 $k+1$ 次中选 1 次成功 $\dbinom{k+1}{1}$，概率 $p(1-p)^k$；第 $k+2$ 次成功概率 $p$
   $$P(X=k)=\dbinom{k+1}{1}p(1-p)^k\cdot p=(k+1)p^2(1-p)^k,\quad k=0,1,2,\ldots$$
3. 第三步：识别分布 ← 依据：负二项分布 $NB(2,p)$ 即此形式

**第二步：求 $p$ 的极大似然估计**

1. 第一步：构造似然函数 ← 依据：$L(p)=\prod_{i=1}^n P(X=x_i)$
   $$L(p)=\left[\prod_{i=1}^n(x_i+1)\right]p^{2n}(1-p)^{\sum_{i=1}^n x_i}$$
2. 第二步：取对数 ← 依据：$\ln L$ 与 $L$ 同极值点
   $$\ln L(p)=C+2n\ln p+\left(\sum_{i=1}^n x_i\right)\ln(1-p)$$
3. 第三步：求导令零 ← 依据：$\dfrac{d\ln L}{dp}=0$
   $$\frac{2n}{p}-\frac{\sum_{i=1}^n x_i}{1-p}=0$$
4. 第四步：解方程 ← 依据：$2n(1-p)=p\sum x_i$
   $$2n=p\!\left(2n+\sum_{i=1}^n x_i\right)\Rightarrow\hat{p}=\frac{2n}{2n+\sum_{i=1}^n x_i}=\frac{2}{2+\bar{X}}$$
5. 第五步：验证极值 ← 依据：$\dfrac{d^2\ln L}{dp^2}=-\dfrac{2n}{p^2}-\dfrac{\sum x_i}{(1-p)^2}<0$，故为极大值。

**关键步骤说明**：

- 第一问关键是把"$X=k$"翻译为"前 $k+1$ 次恰 1 次成功 + 第 $k+2$ 次成功"，组合数 $\dbinom{k+1}{1}=k+1$。
- 第二问关键是似然函数中 $p$ 的幂次为 $2n$（每样本贡献 $p^2$），$(1-p)$ 的幂次为 $\sum x_i$。

**答**：总体分布列 $P(X=k)=(k+1)p^2(1-p)^k,\ k=0,1,\ldots$；$p$ 的 MLE $\hat{p}=\dfrac{2n}{2n+\sum_{i=1}^n X_i}=\dfrac{2}{2+\bar{X}}$。
:::

:::callout{kind=pitfall label="易错警示"}
本题典型易错点：

1. **$X=k$ 含义误读**：误以为 $X=k$ 表示"前 $k$ 次试验中失败 $k$ 次" → 正确做法：$X=k$ 表示第 2 次成功前恰 $k$ 次失败，即前 $k+1$ 次恰 1 次成功且第 $k+2$ 次成功，总试验次数为 $k+2$。
2. **组合数错算**：误写 $\dbinom{k+1}{1}=k$ 漏去 $+1$ → 正确做法：前 $k+1$ 次中选 1 次成功，$\dbinom{k+1}{1}=k+1$。
3. **似然函数 $p$ 幂次错**：误写 $p^n$ 漏去每样本含 $p^2$ → 正确做法：每个 $P(X=x_i)=(x_i+1)p^2(1-p)^{x_i}$ 含 $p^2$，$n$ 个样本合计 $p^{2n}$。
4. **MLE 求导漏项**：误对 $\ln(1-p)$ 求导为 $\dfrac{1}{1-p}$ 漏负号 → 正确做法：$\dfrac{d}{dp}\ln(1-p)=\dfrac{-1}{1-p}$，故 $\dfrac{d\ln L}{dp}=\dfrac{2n}{p}-\dfrac{\sum x_i}{1-p}$。
:::

:::callout{kind=note label="知识卡片：负二项分布与极大似然估计"}
| 性质 | 内容 | 适用条件 |
|------|------|---------|
| $NB(r,p)$ 分布列 | $P(X=k)=\dbinom{k+r-1}{k}p^r(1-p)^k$ | $k=0,1,\ldots$ |
| 本题 $r=2$ | $P(X=k)=(k+1)p^2(1-p)^k$ | 第 2 次成功前失败次数 |
| 期望 | $E(X)=\dfrac{r(1-p)}{p}=\dfrac{2(1-p)}{p}$ | 任意 $r$ |
| 似然函数 | $L(p)\propto p^{rn}(1-p)^{\sum x_i}$ | i.i.d. 样本 |
| MLE 通式 | $\hat{p}=\dfrac{rn}{rn+\sum x_i}=\dfrac{r}{r+\bar{X}}$ | 对数似然求导 |
| 二阶条件 | $\dfrac{d^2\ln L}{dp^2}<0$ 确认极大值 | 任意 MLE |

**概念辨析**：
- 负二项分布 $NB(r,p)$ 有两种等价定义：一是"第 $r$ 次成功前的失败次数"（本题用法），二是"达到 $r$ 次成功所需的总试验次数"。二者差一个平移 $r$。
- MLE 的不变性：若需求 $g(p)$ 的 MLE，直接代入 $\hat{p}$ 得 $g(\hat{p})$；但 MLE 不一定无偏，无偏估计需另外构造（如用阶乘矩）。
:::

:::callout{kind=tip label="结论速记"}
负二项 $NB(2,p)$：$P(X=k)=(k+1)p^2(1-p)^k$；MLE $\hat{p}=\dfrac{2}{2+\bar{X}}$（成功次数作分子，总试验均数作分母）。

**口诀**：负二项 $r$ 次成功前，MLE 分子 $r$ 分母 $r+\bar{X}$。
:::

:::callout{kind=memory label="记忆卡"}
**长期记忆锚点**：

- **触发词**：看到"第 $r$ 次成功前失败次数 + 求 MLE"→ 联想"负二项 $NB(r,p)$ 分布列 + 似然求导得 $\hat{p}=\dfrac{r}{r+\bar{X}}$"
- **关联考点**：负二项分布（第三章）、极大似然估计（第七章）、对数似然求导法
- **复用场景**：任何"等待第 $r$ 次成功"型离散分布的 MLE 求解，统一用似然函数取对数求导令零
:::
